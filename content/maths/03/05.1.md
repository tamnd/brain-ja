コンパクト性定理は、一次論理の中心的な構造結果の 1 つであり、理論の有限と無限の動作の間の正確な関係を表し、大域的充足可能性が有限フラグメントによって完全に制御されることを示します。 

### 定義 5.1 (構造と満足度)

 しましょう$\mathcal{L}$を一次言語とし、$\mathcal{M}$になる$\mathcal{L}$-構造。 

一文に関しては$A$で$\mathcal{L}$、次のように書きます。$$
\mathcal{M} \models A
$$それを意味する$A$は本当です$\mathcal{M}$。 

もし$\Gamma$が一連の​​文である場合、次のように書きます。$$
\mathcal{M} \models \Gamma
$$それは次のことを意味します:$$
\mathcal{M} \models A
$$あらゆる人にとって$A \in \Gamma$。 

したがって$\mathcal{M}$のモデルです$\Gamma$のすべての文を満たすとき、正確に$\Gamma$。 

### 定義 5.2 (満足性と一貫性)

 一連の文$\Gamma$が存在する場合は満たされます$\mathcal{L}$-構造$\mathcal{M}$次のような:$$
\mathcal{M} \models \Gamma
$$一連の文$\Gamma$そのような構造が存在しない場合は満足できません。 

一連の文$\Gamma$次の場合、構文的に一貫性があります。$$
\Gamma \nvdash \bot
$$一次論理では、完全性定理は、一連の文が構文的に一貫している場合に正確に満たされると言うことで、これら 2 つの概念を結びつけます。 

### 定義 5.3 (有限充足可能性)

 一連の文$\Gamma$すべての有限部分集合が次の場合に有限充足可能です。$$
\Gamma_0 \subseteq \Gamma
$$満足です。 

これは、人が有限の数の文だけを選択するときはいつでも、ということを意味します。$\Gamma$、選択されたすべての文が同時に真であるという構造があります。 

### 定理 5.4 (コンパクト性定理)

 しましょう$\Gamma$一次文のセットであること。 

もし$\Gamma$が有限に満たされる場合、$\Gamma$満足です。 

同様に、すべての有限サブセットが$\Gamma$モデルがある場合、すべての文のモデルである単一の構造が存在します。$\Gamma$。 

この定理は、一次要件の無限セットがモデルを持たない可能性があるのは、それらの要件の有限部分がすでにモデルを持たない場合に限られる、ということです。 

次のように仮定します。$\Gamma$は有限に充足可能であり、矛盾について次のように仮定します。$\Gamma$満足できません。 

それから：$$
\Gamma \models \bot
$$一次ロジックの完全性定理により、次のようになります。$$
\Gamma \vdash \bot
$$形式的な証明は有限であるため、この矛盾の導出では、有限の数の仮定のみを使用できます。$\Gamma$。 したがって、有限のサブセットが存在します。$$
\Gamma_0 \subseteq \Gamma
$$次のような:$$
\Gamma_0 \vdash \bot
$$健全性、または反対方向に適用される完全性によって、この有限のサブセットは満足されません。$$
\Gamma_0 \models \bot
$$これは、すべての有限サブセットが$\Gamma$満足です。 したがって$\Gamma$満足できるものでなければなりません。 

### 定理 5.5 (結果形式のコンパクト性)

 しましょう$\Gamma$一連の文にして、$A$文であること。 

もし：$$
\Gamma \models A
$$この場合、有限のサブセットが存在します。$$
\Gamma_0 \subseteq \Gamma
$$次のような:$$
\Gamma_0 \models A
$$仮定する：$$
\Gamma \models A
$$その場合、次のモデルは存在しません。$$
\Gamma \cup \{¬A\}
$$したがって：$$
\Gamma \cup \{¬A\}
$$満足できないです。 

コンパクトさによって、一部の有限サブセットはすでに満足できなくなります。 したがって、有限集合が存在します。$$
\Gamma_0 \subseteq \Gamma
$$次のような:$$
\Gamma_0 \cup \{¬A\}
$$満足できないです。 

これは、すべてのモデルが$\Gamma_0$～のモデルでなければなりません$A$したがって、次のようになります。$$
\Gamma_0 \models A
$$### 例 5.6 (有限条件からの無限モデル)

 言語に単項述語記号を 1 つ含めます$P$。 

それぞれの自然数について$n \geq 1$、 させて$A_n$次の文になります:$$
\exists x_1 \cdots \exists x_n
\left(
\bigwedge_{1 \leq i < j \leq n} x_i \neq x_j
\land
\bigwedge_{1 \leq i \leq n} P(x_i)
\right)
$$文$A_n$少なくともあると言う$n$満足のいく明確な要素$P$。 

させて：$$
\Gamma = \{A_n : n \geq 1\}
$$のすべての有限サブセット$\Gamma$有限個の文のみが含まれます:$$
A_{n_1}, A_{n_2}, \dots, A_{n_k}
$$させて：$$
N = \max(n_1,n_2,\dots,n_k)
$$を備えた構造$N$要素、すべて満足$P$は、これらすべての有限個の文のモデルです。 

したがって、すべての有限部分集合は、$\Gamma$満足です。 

コンパクトさにより、$\Gamma$それ自体は満足です。 どのモデルでも$\Gamma$、すべての自然数に対して$n$少なくともあります$n$満足のいく明確な要素$P$。 したがって、次を満たす要素の集合は、$P$は無限です。 

### 例 5.7 (非標準の算術モデル)

 しましょう$\mathcal{L}$通常の算術言語であり、新しい定数記号を追加することで拡張されます。$c$。 

させて$\Gamma$算術の公理と文で構成されます。$$
c > 0,\quad c > 1,\quad c > 2,\quad \dots
$$のすべての有限サブセット$\Gamma$有限個の不等式のみを言及しています。$$
c > 0,\quad c > 1,\quad \dots,\quad c > n
$$この有限集合は、次のように解釈することで標準自然数で満たすことができます。$c$より大きい数として$n$。 

したがって、すべての有限部分集合は、$\Gamma$満足です。 

コンパクトさにより、セット全体が$\Gamma$モデルがあります。 そのモデルでは、 で示される要素は、$c$はすべての標準自然数よりも大きいです。 

このようなモデルは標準モデルにはなり得ません$\mathbb{N}$なぜなら、通常の自然数はすべての通常の自然数よりも大きいものはないからです。 したがって、一次算術には非標準モデルが存在します。 

### 系 5.8 (有限性は一次公理可能ではない)

 モデルが正確に有限構造である一次文のセットは存在しません。 

矛盾しますが、次のように仮定します。$\Gamma$構造が次の条件を満たすような一次文のセットです。$\Gamma$まさに有限のとき。 

それぞれについて$n \geq 1$、 させて$B_n$少なくともあるという文になる$n$異なる要素:$$
\exists x_1 \cdots \exists x_n
\bigwedge_{1 \leq i < j \leq n} x_i \neq x_j
$$考慮する：$$
\Gamma \cup \{B_n : n \geq 1\}
$$この理論のすべての有限サブセットは、有限個の異なる要素のみを必要とするため、次を満たす有限モデルを持ちます。$\Gamma$。 

コンパクトさによって、理論全体にモデルが存在します。 

そのモデルはすべてを満たします$B_n$, つまり無限です。 それも満足です$\Gamma$したがって、想定される特性により、$\Gamma$それは有限でなければなりません。 

これは不可能です。 したがって、有限性は一次理論によって特徴付けることはできません。 

### 系 5.9 (任意に大規模な有限モデルは無限モデルを与える)

 しましょう$\Gamma$一次理論になります。 

もし$\Gamma$任意の大きいサイズの有限モデルがある場合、$\Gamma$無限モデルを持っています。 

それぞれについて$n \geq 1$、 させて$B_n$少なくともあるという文になる$n$異なる要素:$$
\exists x_1 \cdots \exists x_n
\bigwedge_{1 \leq i < j \leq n} x_i \neq x_j
$$考慮する：$$
\Gamma \cup \{B_n : n \geq 1\}
$$この理論のすべての有限サブセットでは、モデルのサイズの下限のみが必要です。 以来$\Gamma$任意の大きなサイズの有限モデルがある場合、そのようなすべての有限サブセットは満足可能です。 

コンパクトさによって、理論全体が満たされます。 

理論全体のモデルには少なくとも次のものがあります。$n$それぞれに異なる要素$n$、したがってそれは無限です。 

### 概念的な意味

 コンパクト性は、一次充足可能性が有限の情報によって制御されることを示します。 

これは強力なモデル構築原則です。 無限に多くの要件を含むモデルを構築するには、それらの要件のすべての有限の選択が満たされることを示すだけで十分です。 

同時に、コンパクトさは一次ロジックの限界を明らかにします。 有限と無限の動作の間の真にグローバルな区別を必要とするプロパティは、通常、一次文では表現できません。
