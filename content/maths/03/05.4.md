非標準モデルは、一次理論がすべての公理を満たしているが、意図された解釈や標準的な解釈とは異なるモデルを許容する場合に発生します。また、非標準モデルの存在は、コンパクト性定理とローエンハイム スコレムの定理から自然に導き出されます。 

### 定義 5.22 (標準モデル)

 標準モデルは、理論の通常の解釈を表すことを目的とした構造です。 

たとえば、算術の標準モデルは次のとおりです。$$
\mathbb{N} = \{0,1,2,\dots\}
$$通常の操作と関係で。 

非標準モデルとは、標準モデルと同型ではない同じ理論のモデルです。 

### コンパクトさによる構築

 非標準的な算術モデルの構築を説明します。 

させて$\mathcal{L}$算術言語であり、新しい定数記号を追加して拡張します$c$。 

一連の文を考えてみましょう。$$
\Gamma = \text{Th}(\mathbb{N}) \cup \{c > 0, c > 1, c > 2, \dots\}
$$ここ$\text{Th}(\mathbb{N})$は、標準モデルにおける算術のすべての真の文を表します。 

のそれぞれの有限部分集合$\Gamma$有限個の不等式のみが含まれます。$$
c > 0, c > 1, \dots, c > n
$$このような有限集合は次のように満たされます。$\mathbb{N}$解釈することで$c$より大きい数値として$n$。 

したがって、すべての有限部分集合は、$\Gamma$満足です。 

コンパクトさにより、$\Gamma$モデルがいる$\mathcal{M}$。 

で$\mathcal{M}$、解釈する要素$c$はすべての標準自然数より大きいため、$\mathcal{M}$と同型であることはできません$\mathbb{N}$。 

これにより、非標準的な算術モデルが得られます。 

### 定義 5.23 (非標準要素)

 算術の非標準モデルでは、要素が標準の自然数に対応するすべての要素よりも大きい場合、その要素は非標準と呼ばれます。 

このような要素は、外部の観点からは無限数のように動作します。 

### 非標準モデルの構造

 非標準の算術モデルには豊富な内部構造があります。 

これらには、標準の自然数と同型の初期セグメントが含まれています。$$
0,1,2,\dots
$$この最初のセグメントを超えて、順序を無限に拡張する非標準の要素があります。 

標準要素と非標準要素の間にギャップはなく、順序付けは無限の部分が追加された離散線形順序のように動作します。 

### 例 5.24 (無限の整数)

 非標準モデルでは、要素を考慮できます。$c$次のような:$$
c > n
$$あらゆる標準自然数に対して$n$。 

この要素は無限整数のように動作します。 

次のような式を作成することもできます。$$
c + 1, \quad c + 2, \quad 2c, \quad c^2
$$これらもすべて非標準元素であり、通常の自然数と同じ代数法則を満たします。 

### スコレムのパラドックス再訪

 非標準モデルは、スコーレムのパラドックスを明確にするのに役立ちます。 

理論は不可算集合の存在を証明するかもしれませんが、それでも可算モデルが存在します。 

モデル内では、特定のセットと自然数の間に全単射がないため、これらのセットはモデル内では不可算であるとみなされます。 

ただし、外側から見ると、モデル全体は数えることができます。 

したがって、可算性の概念は、構造を見る視点に依存します。 

### 一次物件の譲渡

 非標準モデルの重要な特徴は、理論が完全であれば、標準モデルとまったく同じ一次文を満たすことです。 

したがって、標準モデルで真である一次ステートメントはすべての非標準モデルでも真であり、その逆も同様です。 

これは、一次特性だけでは非標準モデルを標準モデルと区別できないことを意味します。 

### 例 5.25 (標準部品を超える誘導の失敗)

 帰納法は、すべての 1 次の定義可能なプロパティに対して非標準モデルで成立しますが、定義できず、帰納法が失敗する可能性のあるドメインのサブセットが存在します。 

これは、一次ロジックの帰納法が定義可能なプロパティにのみ適用され、任意のサブセットには適用されないことを示しています。 

### 帰結 5.26 (非標準モデルの存在)

 一次理論に無限モデルがある場合、それは非標準モデルになります。 

これは、異なるサイズのモデルを構築したり、標準モデルでは実現できない追加要素を使用して理論を拡張したりできるため、ローエンハイム スコレムの定理とコンパクトさに由来します。 

### 概念的な意味

 非標準モデルは、同じ公理を満たすが重要な点で異なる代替モデルが常に存在するため、一次論理が多くの数学的構造を一意に特徴付けることができないことを示しています。 

また、無限小要素と無限要素を導入して新しい方法で限界と連続性を研究する、非標準解析などの数学における便利なツールも提供します。 

したがって、非標準モデルの存在は、制限であると同時に新しい数学的アイデアの源でもあり、論理システムが当初の予想よりも豊かな解釈を可能にすることが多いことを示しています。
