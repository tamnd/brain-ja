満足度は、一次論理における構文とセマンティクスを結び付ける形式的な関係であり、自由変数へのオブジェクトの指定された割り当ての下で、構造内で式がいつ真であるかを教えてくれます。 

### 満足

 しましょう$\mathcal{M}$ドメインを持つ構造体であること$M$、そしてさせてください$s$割り当てになる:$$
s : \mathrm{Var} \to M
$$表記:$$
\mathcal{M}, s \models A
$$という式が意味します$A$構造的には満足です$\mathcal{M}$任務の下で$s$。 

この表記法が使用されるのは、式には自由変数が含まれる可能性があり、そのような式の真偽は、ドメインのどの要素がそれらの変数に割り当てられるかによって決まるためです。 

### 定義 2.29 (原子式の満足度)

 しましょう$\mathcal{M}$構造体であるとしましょう$s$課題にしてみましょう$t_1, \dots, t_n$条件があります。 

もし$P$です$n$-ary 述語記号の場合:$$
\mathcal{M}, s \models P(t_1, \dots, t_n)
$$次の場合にのみ:$$
(t_1^{\mathcal{M}, s}, \dots, t_n^{\mathcal{M}, s}) \in P^{\mathcal{M}}
$$原子式が等しい場合:$$
t_1 = t_2
$$それから：$$
\mathcal{M}, s \models t_1 = t_2
$$次の場合にのみ:$$
t_1^{\mathcal{M}, s} = t_2^{\mathcal{M}, s}
$$したがって、原子式は、最初にその項を評価し、次に対応する関係または等価性が構造内で成立するかどうかをチェックすることによって評価されます。 

### 定義 2.30 (接続詞の満足度)

 満足関係は、論理接続詞の真理規則に従うことによって、原子式から複合式まで拡張されます。 

否定の場合:$$
\mathcal{M}, s \models ¬A
$$次の場合にのみ:$$
\mathcal{M}, s \not\models A
$$接続詞の場合:$$
\mathcal{M}, s \models A \land B
$$次の場合にのみ:$$
\mathcal{M}, s \models A
\quad \text{and} \quad
\mathcal{M}, s \models B
$$選別の場合:$$
\mathcal{M}, s \models A \lor B
$$次の場合にのみ:$$
\mathcal{M}, s \models A
\quad \text{or} \quad
\mathcal{M}, s \models B
$$暗黙的に:$$
\mathcal{M}, s \models A \to B
$$次のいずれかの場合にのみ:$$
\mathcal{M}, s \not\models A
$$または：$$
\mathcal{M}, s \models B
$$双条件の場合:$$
\mathcal{M}, s \models A \leftrightarrow B
$$次の場合にのみ:$$
\mathcal{M}, s \models A
$$そして：$$
\mathcal{M}, s \models B
$$同じ真理値を持ちます。 

### 定義 2.31 (割り当ての変更)

 しましょう$s$課題にしてみましょう$x$変数にして、$a \in M$。 

私たちはこう書きます：$$
s[x \mapsto a]
$$送信する課題の場合$x$に$a$そして同意する$s$以外のすべての変数について$x$。 

したがって：$$
s[x \mapsto a](x)=a
$$そしてもし$y \ne x$、 それから：$$
s[x \mapsto a](y)=s(y)
$$量指定子は 1 つの変数に割り当てられる値を変更し、他の変数は固定したままにするため、この表記法は量指定子のセマンティクスを定義するために使用されます。 

### 定義 2.32 (数量詞の満足度)

 汎用数量指定子の場合:$$
\mathcal{M}, s \models \forall x \, A
$$すべての場合に限り$a \in M$:$$
\mathcal{M}, s[x \mapsto a] \models A
$$したがって$\forall x \, A$が真の場合$A$ドメインのどの要素が割り当てられているかに関係なく、 true になります。$x$。 

存在量指定子の場合:$$
\mathcal{M}, s \models \exists x \, A
$$存在する場合にのみ$a \in M$次のような:$$
\mathcal{M}, s[x \mapsto a] \models A
$$したがって$\exists x \, A$が真の場合$A$に割り当てられたドメインの少なくとも 1 つの要素に対して true です。$x$。 

### 例 2.33

 しましょう$\mathcal{N}$自然数の通常の構造になります。$$
\mathcal{N} = (\mathbb{N}; 0, S, +, \times, <)
$$次の式を考えてみましょう。$$
\forall x \, \exists y \, (x < y)
$$満足度を確認するには、任意の要素を選択してください$a \in \mathbb{N}$のために$x$。 

何らかの要素を見つける必要があります$b \in \mathbb{N}$次のような:$$
a < b
$$取得:$$
b = a + 1
$$あらゆる自然数に対して機能します$a$したがって、次のようになります。$$
\mathcal{N} \models \forall x \, \exists y \, (x < y)
$$この文は、自然数には最大元がないという事実を表現しています。 

### 例 2.34

 しましょう$\mathcal{A}$有限順序構造になる:$$
\mathcal{A} = (\{0,1,2\}; <)
$$どこ$<$セットに限定された通常の順序です$\{0,1,2\}$。 

その文:$$
\forall x \, \exists y \, (x < y)
$$は間違っています$\mathcal{A}$。 

確かに、もし$x$値が割り当てられます$2$の場合、要素はありません$y \in \{0,1,2\}$次のような:$$
2 < y
$$したがって：$$
\mathcal{A} \not\models \forall x \, \exists y \, (x < y)
$$したがって、同じ式が、ある構造では真であり、別の構造では偽となる可能性があります。 

### 補題 2.35 (自由変数への依存)

 しましょう$A$式にして、$s$そして$s'$構造体の代入であること$\mathcal{M}$。 

もし$s$そして$s'$のすべての自由変数に同意する$A$、 それから：$$
\mathcal{M}, s \models A
$$次の場合にのみ:$$
\mathcal{M}, s' \models A
$$証明

 証明は次の式の構造帰納法によって行われます。$A$。 

For atomic formulas, the truth of the formula depends only on the values of the variables occurring in its terms, and these variables are free in the atomic formula, so the two assignments give the same values to all relevant terms.

 否定および二項結合語の場合、結果は直接の部分式に適用された帰納法仮説から直接導き出されます。 

次のような定量化された式の場合:$$
\forall x \, B
$$変数$x$はバインドされているため、自由変数は$\forall x \, B$は自由変数です$B$を除いて$x$。 

全称量指定子を評価するために、以下を比較します。$$
\mathcal{M}, s[x \mapsto a] \models B
$$そして：$$
\mathcal{M}, s'[x \mapsto a] \models B
$$それぞれに$a \in M$。 

変更された割り当ては、次のすべての自由変数に一致します。$B$、両方とも送信するため、$x$に$a$そしてなぜなら$s$そして$s'$残りの自由変数について同意します。 

実存の場合も同様です。 

### 帰結 2.36 (文の真実性)

 もし$A$が文である場合、構造におけるその真偽は代入の選択に依存しません。 

証明

 文には自由変数はありません。 

したがって、任意の 2 つの代入は、次のすべての自由変数に一致します。$A$、何もないからです。 

補題 2.35 により、次の真理値は次のようになります。$A$すべての割り当てで同じです。 

### モデル

 モデルは、文または文のセットが真である構造です。 

### 定義 2.37 (文のモデル)

 しましょう$A$文であること。 構造$\mathcal{M}$のモデルです$A$もし：$$
\mathcal{M} \models A
$$これはつまり、$A$は本当です$\mathcal{M}$。 

### 定義 2.38 (理論のモデル)

 理論とは文章の集合です。 

させて$T$理論であってください。 構造$\mathcal{M}$のモデルです$T$もし：$$
\mathcal{M} \models A
$$すべての文に対して$A \in T$。 

この場合、次のように書きます。$$
\mathcal{M} \models T
$$したがって、理論のモデルは、その理論内のすべての文を満たす構造です。 

### 例 2.39

 群公理は、二項関数記号、単項関数記号、および定数記号を使用して言語で一次理論を形成します。 

構造は、その領域と操作がグループを形成するとき、まさにこの理論のモデルとなります。 

同様に、リング、体、半順序、およびグラフの公理は一次理論として記述することができ、それらのモデルはまさに対応する数学的構造です。 

### 例 2.40

 しましょう$T$次の文を含む理論になります。$$
\forall x \, \exists y \, (x < y)
$$通常の自然数構造:$$
(\mathbb{N}; <)
$$のモデルです$T$。 

有限順序構造:$$
(\{0,1,2\}; <)
$$のモデルではありません$T$。 

したがって、同じ理論がモデルとしていくつかの構造を持ち、他の構造を除外する可能性があります。
