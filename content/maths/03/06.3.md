飽和モデルは、構造内でどの型が実現されるかを制御する方法を提供し、小さなパラメータ セットにわたるすべての一貫した記述がすでに実現されている標準的な大規模モデルとして機能するため、これらの型を監視するためにこれ以上の拡張は必要ありません。 

このセクション全体を通して、$L$一次言語とする$T$になる$L$-理論、そしてみましょう$\mathcal M \models T$になる$L$-ドメインを含む構造$M$。 私たちは、型のサブセットがどのように変化するかを研究します。$M$中で行動する$\mathcal M$。 

### 定義 6.52 (セット上の型の実現)

 しましょう$A \subseteq M$、そしてさせてください$p(x)$部分的な型であること$A$。 私たちはそう言います$p(x)$で実現される$\mathcal M$存在するなら$a \in M^n$次のような:$$
\mathcal M \models \varphi(a)
$$あらゆる式に対して$\varphi(x) \in p(x)$。 

この定義は、以前の実現の概念を周囲の構造が固定されている場合に特化し、実現がタイプと構造の両方に依存することを強調しています。 

### 定義 6.53 (飽和モデル)

 しましょう$\kappa$無限の枢機卿になろう。 構造$\mathcal M$と言われています$\kappa$すべてのサブセットの場合は -saturated$A \subseteq M$と：$$
|A| < \kappa,
$$あらゆるタイプ$p(x)$以上$A$それは一致します$\operatorname{Th}(\mathcal M)$で実現される$\mathcal M$。 

したがって$\kappa$-飽和とは、それを意味します$\mathcal M$厳密に小さいサイズのパラメータ セットですべての型を実現します。$\kappa$、それらの型が一貫している場合に限ります。 

いつ$\kappa = |M|$、モデルは単に飽和と呼ばれます。 

### 解釈

 飽和モデルには、それが満たす理論に関して可能な限り多くの要素が含まれています。これは、小さなパラメーター セットにわたる一貫した記述がすでにモデル内に証人を持っているため、その記述を実現するために拡張が必要ないという意味です。 

### 例6.54

 しましょう:$$
\mathcal N = (\mathbb N; <).
$$タイプを検討してください$\mathbb N$:$$
p(x) = \{x > n : n \in \mathbb N\}.
$$このタイプは次の理論と一致します。$(\mathbb N; <)$かつ有限に満たされますが、次の場合には実現されません。$\mathbb N$すべての自然数より大きい自然数はないからです。 

したがって$(\mathbb N; <)$ではありません$\aleph_0$-飽和した。 

### 例6.55

 しましょう$\mathcal M$非標準的な算術モデルである可能性があります。 それから$\mathcal M$には、すべての標準自然数よりも大きい要素が含まれており、そのような要素は次の型を実現します。$$
\{x > n : n \in \mathbb N\}.
$$したがって、非標準モデルは型の実現に関してより豊富であり、十分に大きいモデルは飽和する可能性があります。 

### 補題 6.56 (飽和は有限充足可能な型の実現を意味する)

 しましょう$\mathcal M$なれ$\kappa$-飽和しました、しましょう$A \subseteq M$と$|A| < \kappa$、そしてさせてください$p(x)$タイプオーバーになる$A$それは有限に満たされる$\mathcal M$。 それから$p(x)$で実現される$\mathcal M$。 

証明

 以来$p(x)$は有限に満たされる$\mathcal M$、のすべての有限部分集合$p(x)$で実現される$\mathcal M$。 コンパクトさによって、次のことがわかります$p(x)$と一致しています$\operatorname{Th}(\mathcal M)$。 

以来$\mathcal M$は$\kappa$-飽和しており、$|A| < \kappa$、すべてのタイプ以上$A$それは一致します$\operatorname{Th}(\mathcal M)$で実現される$\mathcal M$。 したがって$p(x)$で実現される$\mathcal M$。 

### 定義 6.57 (可算飽和モデル)

 モデル$\mathcal M$であれば可算飽和です$\aleph_1$-saturated、つまり、有限または可算パラメータセットにわたるすべての型が次のように実現されます。$\mathcal M$。 

この概念は、多くの構築に可算パラメータのセットが含まれる解析や代数において特に重要です。 

### 補題 6.58 (飽和モデルへの拡張)

 しましょう$\mathcal M$理論のモデルになる$T$、そしてさせてください$\kappa$無限の枢機卿になろう。 次に、基本的な拡張が存在します$\mathcal N \succ \mathcal M$そのような$\mathcal N$は$\kappa$-飽和した。 

証明

 私たちは建設します$\mathcal N$超有限プロセスによって、型の実現を段階的に追加します。 

のサブセットにわたるすべての型を列挙します。$M$以下のサイズの$\kappa$、論理的に等価になるまで、次のようになります。$$
(p_\alpha : \alpha < \lambda),
$$どこ$\lambda$十分に大きな序数です。 

基本的な拡張機能のチェーンを構築します。$$
\mathcal M = \mathcal M_0 \prec \mathcal M_1 \prec \mathcal M_2 \prec \cdots
$$ステージにて$\alpha$、タイプの場合$p_\alpha$ではまだ実現されていない$\mathcal M_\alpha$、その後延長します$\mathcal M_\alpha$モデルに$\mathcal M_{\alpha+1}$どの中で$p_\alpha$実現される。 これが可能なのは、$p_\alpha$理論と一致しています。 

限界ステージでは、共用体を使用します。$$
\mathcal M_\beta = \bigcup_{\alpha < \beta} \mathcal M_\alpha.
$$基本チェーンの結合もまた、各ステージの基本拡張です。 

構築の最後に、以下を定義します。$$
\mathcal N = \bigcup_{\alpha < \lambda} \mathcal M_\alpha.
$$構造上、以下のサイズのサブセットにわたるすべての型は、$\kappa$で実現される$\mathcal N$、 それで$\mathcal N$は$\kappa$-飽和した。 

### 補題 6.59 (前後法)

 しましょう$\mathcal M$そして$\mathcal N$二人になる$\kappa$- 同じ完全な理論の飽和モデル$T$、 と：$$
|M| = |N| = \kappa.
$$それから$\mathcal M$そして$\mathcal N$同型です。 

証明

 間の同型写像を構築します。$\mathcal M$そして$\mathcal N$前後の議論によって。 

列挙します:$$
M = \{a_\alpha : \alpha < \kappa\},
\quad
N = \{b_\alpha : \alpha < \kappa\}.
$$一連の部分同型写像を構築します。$$
f_\alpha : M_\alpha \to N_\alpha,
$$どこ$M_\alpha \subseteq M$そして$N_\alpha \subseteq N$有限または小さな集合です。 

各ステップで、マップを拡張して 1 つの構造からの次の要素を含めます。飽和を使用して、すでに一致した要素と同じタイプを満たす、もう 1 つの構造内で一致する要素を見つけます。 

より正確に言うと、$f_\alpha$と定義されています。 拡張して含めるには$a_\alpha$のタイプを考慮してください。$a_\alpha$以上$M_\alpha$、この型を次のように転送します。$f_\alpha$タイプオーバーする$N_\alpha$。 以来$\mathcal N$は$\kappa$-飽和、このタイプは次のように実現されます。$\mathcal N$, だから私たちは選択することができます$b$で$N$マッチング$a_\alpha$。 

同様に、主観性を確保するために他の方向にも拡張します。 

限界段階では、部分マップの和集合を取得します。 

最後に、全単射を取得します。$$
f : M \to N
$$これはすべての関係と関数を保存するため、同型です。 

### 飽和と定義可能性

 飽和は定義可能性と強く相互作用します。 飽和モデルでは、小さなパラメーター セットにわたるすべての一貫した記述がモデルの実際の要素に対応するため、型を点として扱うことができます。 

特に、定義可能なセットはタイプの観点から理解できます。定義可能なセットは、特定の式をすべて含むタイプのコレクションに対応し、飽和モデルでは、そのようなタイプはすべて要素によって実現されます。 

この観点により、式や型によって与えられる構文上の記述と、モデルの要素やサブセットによって与えられる意味論的なオブジェクトの間を自由に移動できるようになります。 

### 備考 6.60

 飽和モデルは、小さいサイズによって引き起こされる偶発的な制限を排除し、小さなパラメーター セットに対して論理的に可能なすべての構成がモデル内にすでに存在していることを保証するため、理論の標準的な代表としてよく使用されます。 

実際には、モデル理論の多くの引数は、構造を離れることなく型を実現できる、十分に飽和したモデル内で作業することによって単純化されます。
