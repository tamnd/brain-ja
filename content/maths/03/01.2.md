セマンティクスは、真理値を命題変数に割り当て、論理接続子に従ってこの割り当てをすべての式に拡張することによって、命題論理の式に意味を割り当てます。 

### 真理値

 次の 2 つの真理値を使用します。$$
\mathrm{T}
$$そして：$$
\mathrm{F}
$$値$\mathrm{T}$は true を意味し、値は$\mathrm{F}$は false を意味し、古典的な命題論理のすべての式は、評価が決定されると、これら 2 つの値のうちの 1 つを正確に受け取ります。 

### 定義 1.10 (評価)

 評価は関数です。$$
v : \mathrm{Var} \to \{\mathrm{T}, \mathrm{F}\}
$$命題変数の集合から真理値の集合へ。 

したがって、評価は各命題変数に次のいずれかを割り当てます。$\mathrm{T}$または$\mathrm{F}$、そしてそれは、言語のアトミックステートメントへの真理値の割り当ての 1 つとして理解されるべきです。 

たとえば、変数が次の場合、$p$、$q$、 そして$r$の場合、考えられる評価の 1 つは次のようになります。$$
v(p)=\mathrm{T}, \quad v(q)=\mathrm{F}, \quad v(r)=\mathrm{T}
$$### 定義 1.11 (式の評価)

 あらゆる評価$v$すべての数式上の関数に一意に拡張され、次のようにも表されます。$v$、式の構造の再帰によって。 

もし$A$が命題変数である場合、$v(A)$すでに割り当てられている値です$A$評価によって。 

もし$A = ¬B$、 それから：$$
v(A)=\mathrm{T}
$$次の場合にのみ:$$
v(B)=\mathrm{F}
$$もし$A = (B \land C)$、 それから：$$
v(A)=\mathrm{T}
$$次の場合にのみ:$$
v(B)=\mathrm{T}
\quad \text{and} \quad
v(C)=\mathrm{T}
$$もし$A = (B \lor C)$、 それから：$$
v(A)=\mathrm{T}
$$次の場合にのみ:$$
v(B)=\mathrm{T}
\quad \text{or} \quad
v(C)=\mathrm{T}
$$もし$A = (B \to C)$、 それから：$$
v(A)=\mathrm{F}
$$次の場合にのみ:$$
v(B)=\mathrm{T}
\quad \text{and} \quad
v(C)=\mathrm{F}
$$もし$A = (B \leftrightarrow C)$、 それから：$$
v(A)=\mathrm{T}
$$次の場合にのみ:$$
v(B)=v(C)
$$この再帰的定義が可能なのは、式が帰納的に定義されているためであり、変数の真理値から式の真理値を正確に計算する方法が得られます。 

### 例 1.12

 しましょう$v$は次のように定義される評価になります。$$
v(p)=\mathrm{T}
\quad \text{and} \quad
v(q)=\mathrm{F}
$$それから：$$
v(¬p)=\mathrm{F}
$$なぜなら$p$は true です$v$、否定は真理値を反転します。 

また：$$
v(p \land q)=\mathrm{F}
$$なぜなら、接続詞は両方の接続詞が真である場合にのみ真であるからです。 

我々は持っています：$$
v(p \lor q)=\mathrm{T}
$$なぜなら、少なくとも 1 つの選言が真である場合、選言は真であるからです。 

ついに：$$
v(p \to q)=\mathrm{F}
$$なぜなら、前件が true で後件が false の場合、含意はまさに false になるからです。 

### 真理値表

 真理値表には、式内で発生する変数のすべての可能な評価に基づく式の値が記録されます。 

数式に次のものが含まれる場合$n$個別の変数の場合、次のものが存在します。$$
2^n
$$これらの変数への真理値の割り当てが可能なため、真理値表は次のようになります。$2^n$行。 

真理値表は、少なくとも変数の数が十分に少ないため表を管理しやすい場合には、式の完全な意味論的記述を有限かつ明示的な形式で提供するため便利です。 

### 例 1.13

 次の式を考えてみましょう。$$
(p \land q) \to p
$$真理値表は次のとおりです。 

|$p$|$q$|$p \land q$|$(p \land q) \to p$|
 |---|---|---|---|
 |$\mathrm{T}$|$\mathrm{T}$|$\mathrm{T}$|$\mathrm{T}$|
 |$\mathrm{T}$|$\mathrm{F}$|$\mathrm{F}$|$\mathrm{T}$|
 |$\mathrm{F}$|$\mathrm{T}$|$\mathrm{F}$|$\mathrm{T}$|
 |$\mathrm{F}$|$\mathrm{F}$|$\mathrm{F}$|$\mathrm{T}$|

 最後のコラムは、$\mathrm{T}$すべての行にあるため、式はすべての評価で true になります。 

### 定義 1.14 (満足可能性、妥当性、矛盾)

 公式$A$評価が存在する場合は満たされます$v$次のような:$$
v(A)=\mathrm{T}
$$公式$A$すべての評価に対して有効である$v$:$$
v(A)=\mathrm{T}
$$公式$A$すべての評価について矛盾している$v$:$$
v(A)=\mathrm{F}
$$これら 3 つの概念は、考えられるすべての評価における挙動に従ってフォーミュラを分類します。 

### 例 1.15

 式:$$
p \lor ¬p
$$すべての評価について次のいずれかが行われるため、これは有効です。$p$本当ですか、または$p$は false であり、どちらの場合も論理和は true です。 

式:$$
p \land ¬p
$$両方を実現できる評価は存在しないため、これは矛盾しています。$p$そして$¬p$同時に真実です。 

式:$$
p \land q
$$は満たせますが、有効ではありません。両方の場合に真となるためです。$p$そして$q$は真ですが、他の多くの評価の下では偽です。 

### 補題 1.16 (独自の評価)

 あらゆる評価に対して$v$そしてあらゆる公式$A$、真理値$v(A)$一意に決まる。 

証明

 証明は次の式の構造帰納法によって行われます。$A$。 

もし$A$が命題変数である場合、$v(A)$評価の定義によって一意に決定されます。 

もし$A = ¬B$、次に帰納仮説により値が$v(B)$は一意に決定されるため、 の値は$v(¬B)$は否定の真理規則によって一意に決定されます。 

もし$A = (B \circ C)$二項接続詞の場合$\circ$、次に帰納仮説によって値が$v(B)$そして$v(C)$は一意に決定されるため、 の値は$v(B \circ C)$接続詞の真理規則によって一意に決定されます。$\circ$。 

### ブール関数ビュー

 数式の場合$A$以下の変数が含まれます。$$
p_1, p_2, \dots, p_n
$$それから$A$ブール関数を決定します。$$
f_A : \{\mathrm{T}, \mathrm{F}\}^n \to \{\mathrm{T}, \mathrm{F}\}
$$この関数は、変数に割り当てられた真理値の各タプルを、対応する評価に基づく式の真理値に送信します。 

This viewpoint is useful because it connects propositional logic with Boolean algebra, digital circuits, and computation, where formulas can be studied as functions from binary inputs to binary outputs.
