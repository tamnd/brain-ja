量化子は、一次ロジックで多くのオブジェクトに関するステートメントを一度に表現できるようにする記号であり、一次ロジックを命題ロジックから区別する主な機能です。 

### 普遍的かつ存在的な数量詞

 基本的な量指定子は 2 つあります。$$
\forall
$$そして：$$
\exists
$$普遍的な数量指定子$\forall$は「for all」と読み、検討中のドメイン内のすべてのオブジェクトに式が適用されることを示すために使用されます。 

存在量指定子$\exists$は「存在する」と読み、検討中のドメイン内の少なくとも 1 つのオブジェクトに対して式が成り立つことを示すために使用されます。 

例えば：$$
\forall x \, P(x)
$$すべてのオブジェクトにはプロパティがあると言う$P$、 その間：$$
\exists x \, P(x)
$$少なくとも 1 つのオブジェクトがプロパティを持っていることを示します$P$。 

### 定義 2.9 (範囲)

 量指定子のスコープは、量指定子が適用される式の一部です。 

式では次のようになります。$$
\forall x \, (P(x) \to Q(x))
$$の範囲$\forall x$は：$$
P(x) \to Q(x)
$$したがって、両方の発生が$x$この式の は量指定子によって制御されます。 

対照的に、式では次のようになります。$$
(\forall x \, P(x)) \to Q(x)
$$の範囲$\forall x$のみです:$$
P(x)
$$の発生$x$で$Q(x)$は量指定子の範囲外であるため、無料です。 

### 定義 2.10 (フリーオカレンスとバインドオカレンス)

 数式内の変数の出現は、それが同じ変数の量指定子のスコープ内にある場合にバインドされます。 

バインドされていない場合、変数の出現は自由です。 

たとえば、次のようになります。$$
\forall x \, P(x, y)
$$の発生$x$拘束されている間、$y$無料です。 

で：$$
\exists y \, (P(x, y) \land Q(y))
$$の出来事$y$が発生している間、$x$無料です。 

自由変数を含む数式の真偽は、それらの変数への値の割り当てに依存するため、この区別は重要です。 

### 例 2.11

 次のことを考慮してください。$$
\forall x \, (x < y)
$$変数$x$の範囲内で発生するため、バインドされています。$\forall x$。 

変数$y$バインドする量指定子がないため、自由です。 

したがって、式は、すべてのオブジェクトが、割り当てられたオブジェクトよりも小さいことを示します。$y$、そしてその真偽はどのオブジェクトによって決まりますか$y$を指します。 

### 定義 2.12 (文)

 文は自由変数のない式です。 

例えば：$$
\forall x \, (x = x)
$$という文です。 

式:$$
x = x
$$変数は文ではないので、$x$自由に発生します。 

文は、自由変数への追加の割り当てを必要とせずに、構造内の真理値を割り当てることができる式です。 

### 量指定子の順序

 量指定子の順序は重要です。 

式:$$
\forall x \, \exists y \, R(x, y)
$$それはすべてのオブジェクトに対して言います$x$、何かオブジェクトがあります$y$に関連した$x$。 

式:$$
\exists y \, \forall x \, R(x, y)
$$オブジェクトが 1 つあると言う$y$それはあらゆるオブジェクトに関係します$x$。 

これら 2 つの式は通常、異なる意味を持ちます。 

たとえば、次の場合$R(x, y)$手段：$$
x < y
$$それから：$$
\forall x \, \exists y \, (x < y)
$$すべてのオブジェクトにはより大きなオブジェクトがあると述べています。 

しかし：$$
\exists y \, \forall x \, (x < y)
$$あらゆる物体よりも大きな物体が 1 つ存在するということです。 

自然数では、最初のステートメントは true ですが、2 番目のステートメントは false です。 

### 定義 2.13 (制限された数量詞)

 制限された汎用数量指定子:$$
\forall x \in S \, A(x)
$$は次の略語です。$$
\forall x \, (x \in S \to A(x))
$$制限された存在量指定子:$$
\exists x \in S \, A(x)
$$は次の略語です。$$
\exists x \, (x \in S \land A(x))
$$これらの翻訳における含意と接続詞の違いは重要です。 

普遍的なステートメントの場合、外部のオブジェクト$S$重要ではないため、含意が使用されます。 

存在ステートメントの場合、オブジェクトは両方に属している必要があります。$S$そして満足する$A(x)$, そこで接続詞が使われます。 

### 例 2.14

 声明:$$
\forall x \in \mathbb{N} \, (x + 0 = x)
$$手段：$$
\forall x \, (x \in \mathbb{N} \to x + 0 = x)
$$声明:$$
\exists x \in \mathbb{N} \, (x^2 = 4)
$$手段：$$
\exists x \, (x \in \mathbb{N} \land x^2 = 4)
$$これらは一次ロジックの新しい原始的な形式ではなく、便利な略語です。 

### 補題 2.15 (量指定子の否定)

 あらゆる式について$A(x)$、次の等価性が成り立ちます。$$
¬\forall x \, A(x) \equiv \exists x \, ¬A(x)
$$そして：$$
¬\exists x \, A(x) \equiv \forall x \, ¬A(x)
$$証明

 式:$$
¬\forall x \, A(x)
$$そうではないと言う$A(x)$すべてのオブジェクトに当てはまります$x$。 

これは、オブジェクトが少なくとも 1 つあることを意味します$x$誰のために$A(x)$失敗します。 

したがって：$$
¬\forall x \, A(x) \equiv \exists x \, ¬A(x)
$$同様に、式は次のようになります。$$
¬\exists x \, A(x)
$$オブジェクトがないと言う$x$誰のために$A(x)$が成立する。 

これは、すべてのオブジェクトが$x$満足できない$A(x)$。 

したがって：$$
¬\exists x \, A(x) \equiv \forall x \, ¬A(x)
$$### 例 2.16

 以下の否定:$$
\forall x \, P(x)
$$は：$$
\exists x \, ¬P(x)
$$これは、すべてのオブジェクトがプロパティを持っているわけではないことを示しています$P$少なくとも 1 つのオブジェクトがプロパティを持たないとき$P$。 

以下の否定:$$
\exists x \, P(x)
$$は：$$
\forall x \, ¬P(x)
$$これは、プロパティを持つオブジェクトが存在しないことを示しています$P$まさに、すべてのオブジェクトがプロパティを持たないとき$P$。 

### 定義 2.17 (変数キャプチャ)

 変数キャプチャは、置換により自由だった変数が量指定子によって束縛される場合に発生します。 

たとえば、次のことを考えてみましょう。$$
\forall x \, P(x, y)
$$変数$y$無料です。 

置き換えると$y$による$x$最初にバインドされた変数を変更せずに、次を取得します。$$
\forall x \, P(x, x)
$$新たに挿入されたのは、$x$現在は ～ の範囲内にあります$\forall x$, ということで束縛されてしまいました。 

これにより、変数の構文上の役割が変わり、式の意味が変わる可能性があります。 

### 補題 2.18 (バインドされた変数の名前変更)

 自由変数がキャプチャされない限り、バインドされた変数の名前は変更できます。 

例えば：$$
\forall x \, P(x, y)
$$次のように名前を変更できます。$$
\forall z \, P(z, y)
$$という条件で$z$混乱や混乱を引き起こすような形ですでに発生していない。 

証明

 バインドされた変数は、ドメイン全体にわたるオブジェクトのプレースホルダーとしてのみ機能します。 

バインドされた変数の名前を変更しても、その変更が量指定子のスコープ全体にわたって一貫して行われ、自由変数をキャプチャしない限り、量化の構造は変わりません。 

したがって、式は次のようになります。$$
\forall x \, P(x, y)
$$そして：$$
\forall z \, P(z, y)
$$同じ論理内容を持ちます。 

置き換えのためキャプチャに関する制限が必要です。$x$式内ですでに自由になっている変数を使用すると、どのオカレンスがバインドされ、どのオカレンスが自由のままになるかを変更できます。
