妥当性と含意は、1 つの固定構造内ではなく、すべての構造にわたって式を比較する意味論的な概念です。 満足度は、特定の割り当ての下で特定の構造において式が真であるかどうかを教えてくれますが、妥当性と含意は、言語のあらゆる可能な解釈において真理が強制されるかどうかを尋ねます。 

### 有効性

 文は、その言語のすべての構造において真である場合に有効です。 

### 定義 2.41 (有効性)

 しましょう$A$文であること。 私たちはそう言います$A$次の場合に有効です。$$
\mathcal{M} \models A
$$あらゆる構造に$\mathcal{M}$の言語のために$A$。 

この場合、次のように書きます。$$
\models A
$$妥当性とは、次の真実であることを意味します。$A$は、その論理形式のみに依存し、特定の構造の特別なプロパティには依存しません。 

### 例 2.42

 その文:$$
\forall x \, (x = x)
$$等価性はあらゆる構造に​​おいて再帰的であるため、これは有効です。 

その文:$$
\forall x \, P(x)
$$は無効です。述語が次のような構造を選択する可能性があるためです。$P$ドメインのすべての要素に当てはまるわけではありません。 

たとえば、ドメインを次のようにします。$$
M = \{0,1\}
$$そして次のようにしましょう:$$
P^{\mathcal{M}} = \{0\}
$$それから：$$
\mathcal{M} \not\models \forall x \, P(x)
$$なぜなら$1$入っていない$P^{\mathcal{M}}$。 

### 対抗モデル

 文が無効であることを示すには、その文が偽である構造を 1 つ与えるだけで十分です。 このような構造をカウンターモデルと呼びます。 

### 定義 2.43 (対抗モデル)

 しましょう$A$文であること。 ～に対する対抗モデル$A$構造物です$\mathcal{M}$次のような:$$
\mathcal{M} \not\models A
$$カウンターモデルは、文が論理だけから導かれるものではないという具体的な証拠を提供するため、重要です。 

### 意味的含意

 含意は、仮定を許容することによって妥当性を一般化します。 

### 定義 2.44 (意味含意)

 しましょう$\Gamma$一連の文にして、$A$同じ言語の文であること。 

私たちはそう言います$\Gamma$意味的には$A$すべてのモデルの場合$\Gamma$のモデルでもあります$A$。 

この場合、次のように書きます。$$
\Gamma \models A
$$同様に:$$
\Gamma \models A
$$あらゆる構造に​​ついて$\mathcal{M}$、 もし：$$
\mathcal{M} \models B
$$あらゆる人にとって$B \in \Gamma$、 それから：$$
\mathcal{M} \models A
$$したがって$A$の意味論的な結果です$\Gamma$まさにいつ$A$は、すべての仮定が適用されるすべての構造で真です。$\Gamma$本当です。 

### 例 2.45

 しましょう$\Gamma$次の 2 つの文が含まれます。$$
\forall x \, \forall y \, (x < y \to ¬(y < x))
$$そして：$$
\forall x \, \forall y \, \forall z \, ((x < y \land y < z) \to x < z)
$$最初の文にはこう書かれています$<$は非対称であり、2 番目の文は次のように述べています。$<$推移的です。 

それから：$$
\Gamma \models \forall x \, ¬(x < x)
$$これを見るには、$\mathcal{M}$のいずれかのモデルになる$\Gamma$、矛盾があるため、要素があると仮定します。$a$次のような:$$
a < a
$$非対称性により、次のようになります。$$
a < a
$$以下を取得します。$$
¬(a < a)
$$それは不可能だからそんなことはない$a$が存在するため、次のようになります。$$
\mathcal{M} \models \forall x \, ¬(x < x)
$$以来$\mathcal{M}$は任意であり、含意は成り立ちます。 

### 無仮定からの含意としての妥当性

 有効性は含意の特殊なケースです。 

一文に関しては$A$:$$
\models A
$$は以下と同じ意味です:$$
\varnothing \models A
$$これは、空集合内のすべての文を満たすすべての構造もまた満たすことを意味します。$A$。 すべての構造は空の仮定セットを満たすため、これはまさに次のステートメントです。$A$あらゆる構造に​​当てはまります。 

### 論理的等価性

 2 つの文が相互に含意する場合、論理的には同等です。 

### 定義 2.46 (論理的等価性)

 しましょう$A$そして$B$文であること。 私たちはそう言います$A$そして$B$次の場合、論理的に同等です。$$
A \models B
$$そして：$$
B \models A
$$同様に:$$
\models A \leftrightarrow B
$$これはつまり、$A$そして$B$すべての構造で同じ真理値を持ちます。 

### 例 2.47

 文:$$
¬\forall x \, P(x)
$$そして：$$
\exists x \, ¬P(x)
$$は論理的に同等です。 

実際、構造は次の条件を満たします。$$
¬\forall x \, P(x)
$$すべての要素が満たされない場合$P$、そしてこれは、いくつかの要素が満たさない場合に正確に当てはまります。$P$。 

したがって：$$
\models ¬\forall x \, P(x) \leftrightarrow \exists x \, ¬P(x)
$$### 満足度

 文のセットは、少なくとも 1 つのモデルがあれば満たされます。 

### 定義 2.48 (満足可能性)

 しましょう$\Gamma$文の集合であること。 私たちはそう言います$\Gamma$構造が存在すれば満たされる$\mathcal{M}$次のような:$$
\mathcal{M} \models \Gamma
$$そのような構造が存在しない場合は、$\Gamma$満足できないです。 

充足性は、ある構造においてすべての仮定が同時に真になるかどうかを問います。 

### 例 2.49

 セット:$$
\Gamma = \{\exists x \, P(x), \forall x \, ¬P(x)\}
$$満足できないです。 

最初の文は、少なくとも 1 つのオブジェクトが次の条件を満たすことを示しています。$P$、2番目の文は、オブジェクトが満たされないと言っています$P$。 

両方の文を同時に真にする構造はありません。 

### 補題 2.50 (含意と不充足性)

 しましょう$\Gamma$一連の文にして、$A$文であること。 それから：$$
\Gamma \models A
$$次の場合にのみ:$$
\Gamma \cup \{¬A\}
$$満足できないです。 

証明

 まず次のように仮定します。$$
\Gamma \models A
$$次に、次のすべての文を満たすすべての構造$\Gamma$も満たす$A$。 

したがって、次のすべての文を満たす構造はありません。$\Gamma$そして満足する$¬A$満足できるから$¬A$ということです$A$は誤りです。 

したがって、次のようになります。$$
\Gamma \cup \{¬A\}
$$満足できないです。 

逆に、次のように仮定します。$$
\Gamma \cup \{¬A\}
$$満足できないです。 

させて$\mathcal{M}$次のような任意の構造にすることができます。$$
\mathcal{M} \models \Gamma
$$もし$\mathcal{M} \not\models A$、 それから：$$
\mathcal{M} \models ¬A
$$したがって:$$
\mathcal{M} \models \Gamma \cup \{¬A\}
$$これは次の仮定と矛盾します$\Gamma \cup \{¬A\}$満足できないです。 

したがって、すべてのモデルの$\Gamma$満足する$A$、 など：$$
\Gamma \models A
$$### 例 2.51

 以下を示します。$$
\{p \to q, p\} \models q
$$満足できないことを利用する。 

次のことを示すだけで十分です。$$
\{p \to q, p, ¬q\}
$$満足できないです。 

評価が 3 つの式すべてを満たすと仮定します。 それから：$$
p
$$が真であり、かつ:$$
q
$$は誤りです。 

しかし、もし$p$それは真実であり、$q$が false の場合:$$
p \to q
$$は誤りです。 

これは次の仮定と矛盾します。$$
p \to q
$$それは本当です。 

したがって、3 つの公式をすべて満たす評価は存在しないため、次のようになります。$$
\{p \to q, p\} \models q
$$### 自由変数による含意

 自由変数を含む数式の場合、含意は構造体と代入の両方を使用して定義されます。 

させて$\Gamma$一連の式にして、$A$式になる。 私たちはこう書きます：$$
\Gamma \models A
$$すべての構造の場合$\mathcal{M}$そしてすべての課題$s$、 いつでも：$$
\mathcal{M}, s \models B
$$あらゆる人にとって$B \in \Gamma$、 それから：$$
\mathcal{M}, s \models A
$$文は代入に依存しないため、この定義は文に関する以前の定義を拡張します。 

### 例 2.52

 結果:$$
x < y, \quad y < z \models x < z
$$任意の二項関係を持つすべての構造で成り立つわけではない$<$。 

推移性が仮定として含まれている場合、これは有効になります。$$
\forall x \, \forall y \, \forall z \, ((x < y \land y < z) \to x < z), \quad x < y, \quad y < z \models x < z
$$この例は、含意が含まれている仮定に依存し、公理がその動作を制約しない限り、関係記号には固定的な意味がないことが示されています。
