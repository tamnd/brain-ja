## 4.2 射と写像

 射は構造を保存するマップです。 これは、特定の数学的設定に対する変換の正しい概念です。 

プレーン関数は、あるセットの要素を別のセットの要素に送信します。$$
f : X \to Y
$$射影はさらに多くのことを行います。 構造を定義する操作、関係、法則を尊重します。$X$そして$Y$。 

群の場合、射は群準同型です。 地図$f : G \to H$が群準同型である場合$$
f(a \ast b) = f(a) \cdot f(b)
$$みんなのために$a,b \in G$。 操作$\ast$に属します$G$、および操作$\cdot$に属します$H$。 

ベクトル空間の場合、射は線形マップです。 地図$T : V \to W$の場合は線形です$$
T(v+w) = T(v) + T(w)
$$そして$$
T(\lambda v) = \lambda T(v)
$$みんなのために$v,w \in V$そしてすべてのスカラー$\lambda$。 

位相空間の場合、射は連続マップです。 関数$f : X \to Y$すべての開いたセットの逆イメージの場合、連続的になります。$Y$で開いています$X$。 

| 構造 | 変形 | 保存されたデータ |
 | ----------------- | ------------------------------------------ | ---------------------------------- |
 | セット | 機能 | 要素のみ |
 | グループ | 準同型性 | 操作 |
 | リング | リング準同型 | 足し算と掛け算 |
 | ベクトル空間 | 線形マップ | 加算とスカラー乗算 |
 | 位相空間 | 連続マップ | オープンセット構造 |
 | メートル空間 | アイソメトリ、リプシッツ マップ、または連続マップ | 距離に関係する構造 |
 | グラフ | グラフの準同型性 | 隣接 |

 射法の選択により、実行される数学の種類が決まります。 射が変化すると理論も変化します。 

たとえば、計量空間はアイソメトリ、リプシッツ マップ、または連続マップを使用して研究できます。 それぞれの選択により、保持される構造の量が異なります。 

| マップの種類 | 保存されるもの |
 | -------------- | -------------------------------------------------- |
 | アイソメトリ | 正確な距離 |
 | リプシッツの地図 | 制御された歪みまでの距離 |
 | 連続マップ | 近くの点はトポロジー的な意味で近くに残ります。 

したがって、同じオブジェクトでも、どのマップが許可されるかに応じて、異なる理論をサポートできます。 

### 比較としての射影

 射影は構造を比較します。 からの地図$A$に$B$情報がどのように入っているかを教えてくれます$A$内部で表現できる$B$。 

単射射は、多くの場合、ある構造を別の構造に埋め込みます。 全射射では、多くの場合、構造が商に崩壊します。 同型写像により、可逆的な比較が可能になります。 

| タイプ | 意味 |
 | ------------------- | -------------------------------------- |
 | 射影射法 | 要素間の区別を保持します |
 | 全射射影 | ターゲットをカバーします |
 | 同型写像 | 構造を可逆的に保存します |
 | 準同型性 | オブジェクトからそれ自体への射影 |
 | 自己同型性 | オブジェクトからそれ自体への同型写像 |

 群準同型性の場合$f : G \to H$、カーネルは何が折りたたまれているかを測定します。$$
\ker(f) = {g \in G : f(g) = e_H}.
$$画像はどの部分を計測していますか$H$に達します:$$
\operatorname{Im}(f) = {f(g) : g \in G}.
$$これらの構造は、射を構造データに変換します。 

### 構成

 形態は構成されます。 もし$f : A \to B$そして$g : B \to C$が同じ種類の射である場合、それらの合成も射です。$$
g \circ f : A \to C.
$$組成は次のように定義されます。$$
(g \circ f)(a) = g(f(a)).
$$この単純なルールが、射が中心となる主な理由の 1 つです。 これにより、短い変換から長い変換を構築できるようになります。 

構成は連想的です:$$
h \circ (g \circ f) = (h \circ g) \circ f.
$$各オブジェクトには恒等射もあります。$$
\operatorname{id}_A : A \to A.
$$恒等射は何も行いません。$$
\operatorname{id}_A(a) = a.
$$オブジェクト、射、恒等写像、および合成が一緒になって圏理論の基本パターンを形成します。 

### 保存と反映

 射は、プロパティを保存することも、プロパティを反映することも、あるいはその両方を行うこともできます。 

ソース内のプロパティがターゲット内の対応するプロパティを暗黙的に示す場合、マップはプロパティを保持します。 

ターゲット内のプロパティがソース内の対応するプロパティを暗黙的に示す場合、マップはプロパティを反映します。 

たとえば、連続関数は、多くのよく知られた空間でシーケンスの収束を保存します。$$
x_n \to x \quad \Rightarrow \quad f(x_n) \to f(x).
$$同型性は通常、理論の言語で表現可能なすべての構造を保存し、反映します。 

これが、同型オブジェクトを構造的に同一のものとして扱うことができる理由です。 

### 射による輸送

 射影により情報の移動が可能になります。 

もし$f : A \to B$は同型写像、上の任意の構造です$A$に輸送することができます$B$。 転送された構造は次のように定義されます。$f$構造が保存されるようになる。 

二項演算の場合$\ast$の上$A$、操作を定義します$\star$の上$B$による$$
b_1 \star b_2 = f(f^{-1}(b_1) \ast f^{-1}(b_2)).
$$これにより、$A$そして$B$構造化オブジェクトと同等です。 

輸送は線形代数では一般的です。 基底を選択すると同型写像が得られます$$
V \cong k^n.
$$これにより、抽象ベクトルが座標タプルに変換されます。 計算は次のように実行できます。$k^n$そして逆に解釈した$V$。 

### 忘れやすい地図と追加された構造

 一部のマップは構造を忘れています。 グループは、その操作を無視することでセットとして見ることができます。 位相空間は、その開集合を無視することによって集合として見ることができます。 

この操作は、カテゴリ言語では忘却関手と呼ばれることがよくあります。 

| 構造化オブジェクト | 忘れられたビュー |
 | ----------------- | -------------------------------- |
 | グループ | 基礎となるセット |
 | リング | 基礎となる加法グループまたはセット |
 | ベクトル空間 | 基礎となるセット |
 | 位相空間 | 基礎となるセット |
 | メートル空間 | 基礎となる位相空間 |

 構造を忘れると、利用できる関数は増えますが、適用できる定理は少なくなります。 

基礎となるセット間の関数は、より豊富な構造の射である必要はありません。 ベクトル空間間のマップは、線形でなく集合関数であってもよい。 

### 自己同型性と対称性

 自己同型性は、オブジェクトからそれ自体への同型性です。$$
f : X \to X
$$自己同型性は対称性を記述します。 これらは、オブジェクトを同じ構造タイプ内に残す、構造を保持する変換です。 

例:

 | オブジェクト | 自己同型 |
 | ----------------- | -------------------------------------- |
 | セット | 順列 |
 | グループ | 群の自己同型 |
 | ベクトル空間 | 可逆線形マップ |
 | グラフ | 隣接関係を維持する頂点の順列 |
 | 位相空間 | 空間からそれ自体への準同型性 |

 オブジェクトの自己同型性は、多くの場合、グループを形成します。 このグループはオブジェクトの対称性を測定します。 

たとえば、正方形の対称性は、合成時にグループを形成します。 それぞれの対称性により、正方形の幾何学的構造が維持されます。 

### 射影が理論を決定する

 射を選択せずにオブジェクトを選択すると、不完全な理論が得られます。 

たとえば、オブジェクトが計量空間であると仮定します。 いくつかの選択肢が考えられます。 

| 射影 | 結果として生じる強調 |
 | ------------------------- | ----------------------- |
 | アイソメトリクス | 正確なメートル幾何学形状 |
 | リプシッツの地図 | 量的な歪み |
 | 連続マップ | トポロジ |
 | 一様連続マップ | 均一な構造 |

 それぞれの選択により、同一性について異なる概念が生成されます。 

アイソメトリでは、距離が正確に保存されている場合にのみ 2 つの空間が等価になります。 準同型性では、開集合構造のみが問題となります。 線分と曲線円弧は、計量的には異なる場合がありますが、位相的には同じです。 

### 実際のワークフロー

 構造を研究するときは、常に次のことを尋ねてください。 

| 質問 | 目的 |
 | ------------------------- | ---------------------------------- |
 | オブジェクトとは何ですか? | 研究分野を特定する |
 | 射とは何ですか? | 許可される変換を識別します。 
| 射は何を保持しますか? | 構造を識別します |
 | 同型写像とは何ですか? | 同一性を識別する |
 | 自己同型とは何ですか? | 対称性を識別します |

 このワークフローは、理論で構造の保存が必要な場合に、あらゆる関数を許容できるものとして扱うというよくある間違いを防ぎます。 

射はマップの規律ある形式です。 オブジェクトを数学的にする構造を尊重しながら、オブジェクトをある設定から別の設定に運びます。
