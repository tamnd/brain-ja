## 4.4 不変条件と分類

 不変条件とは、選択された変換クラスの下で変化しない特性、量、または構造です。 

不変条件は構造的思考の中心です。 これにより、表現に依存せずにオブジェクトを比較できるようになります。 

2 つのオブジェクトが同型である場合、それらの構造的不変条件は一致します。 したがって、不変式が異なる場合、オブジェクトは同型であることはできません。 

たとえば、カーディナリティが異なる 2 つの有限集合は全単射になることはできません。 同じフィールド上の異なる次元を持つ 2 つのベクトル空間は同型であってはなりません。 連結成分の数が異なる 2 つのグラフを同型にすることはできません。 

| 構造 | 変換 | 不変 |
 | ----------------- | ------------------ | -------------------------------------- |
 | 有限集合 | 全単射 | カーディナリティ |
 | ベクトル空間 | 線形同型写像 | 寸法 |
 | マトリックス | 基礎の変更 | ランク、トレース、決定要因 |
 | グラフ | グラフの同型性 | 次数順序、連結成分 |
 | 位相空間 | 準同型写像 | コンパクトさ、つながりやすさ |
 | グループ | 群同型写像 | 順序、アーベル特性、部分群格子 |

 不変式は、表現が変更されても存続するため便利です。 

行列は、塩基が選択された後でのみ線形マップを表します。 基数を変更すると行列のエントリが変更される可能性がありますが、ランクなどの構造量は変更されません。 

もし$A$そして$B$異なる基底で同じ線形演算子を表す場合、それらは似ています。$$
B = P^{-1}AP.
$$類似性の下では、トレースと行列式は不変です。$$
\operatorname{tr}(B) = \operatorname{tr}(A)
$$そして$$
\det(B) = \det(A).
$$これは、トレースと行列式が単に選択された行列表現に属するのではなく、演算子に属することを意味します。 

### 不変条件はオブジェクトを区別します

 不変式の最初の使用は否定的です。これは 2 つのオブジェクトが等価ではないことを証明します。 

仮定する$V$そして$W$同じフィールド上の有限次元ベクトル空間です$k$。 もし$$
\dim V \neq \dim W,
$$それから$$
V \not\cong W.
$$理由は簡単です。 線形同型写像は次元を保持します。 次元が異なる場合、線形同型性は存在できません。 

同じパターンがフィールド間で表示されます。 

| 観察 | 結論 |
 | ------------------------------------------ | ------------------------------------------------ |
 | 有限集合にはさまざまなサイズがある | 全射なし |
 | グループには異なる順序があります。 グループ同型性なし |
 | グラフには異なる次数のシーケンスがあります。 グラフ同型性なし |
 | スペースのコンパクトさの動作は異なります。 準同型性なし |
 | 行列にはさまざまなランクがある | 行操作と列操作では等価性はありません。 

多くの場合、これがオブジェクトを分離する最も速い方法です。 

### 不変条件は不完全である可能性があります

 不変式は、オブジェクトが同型でない場合でもオブジェクトを区別できないことがあります。 

たとえば、2 つの有限群は同じ次数を持つことができますが、構造は異なります。 循環秩序群$4$とクライン 4 群はどちらも 4 つの要素を持ちますが、同型ではありません。$$
\mathbb{Z}/4\mathbb{Z} \not\cong \mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z}.
$$順序は同じですが、要素の順序が異なります。 で$\mathbb{Z}/4\mathbb{Z}$、順序の要素があります$4$。 クラインの 4 群では、すべての非同一要素には順序があります。$2$。 

したがって、順序だけでは有限群にとって完全な不変条件ではありません。 

| 不変 | | 失敗する可能性があります。 
| ------------------------- | -------------------------------------------------------------- |
 | セットのカーディナリティ | 有限集合の完全な |
 | ベクトル空間の次元 | 固定フィールド上の有限次元ベクトル空間を完全にする |
 | グループの順序 | 異なるグループ構造は順序を共有できます。 
| グラフの次数列 | 非同型グラフは次数シーケンスを共有できます。 
| 空間のつながり | 多くの非同型空間が接続されています。 

不完全な不変式にも値はあります。 等価性を除外し、分類をガイドし、より強力な不変条件を提案できます。 

### 完全な不変式

 完全不変式は、選択された等価性までオブジェクトを完全に分類します。 

有限セットの場合、カーディナリティは完全です。$$
A \cong B \quad \text{if and only if} \quad |A| = |B|.
$$固定フィールド上の有限次元ベクトル空間の場合$k$、寸法が完成しました。$$
V \cong W \quad \text{if and only if} \quad \dim V = \dim W.
$$完全な不変条件は両方の方向を示します。 

| 方向 | 意味 |
 | ------------------------------------------ | ---------------------- |
 | オブジェクトが等しい場合、不変式は一致します | 不変式が保持される |
 | 不変式が一致する場合、オブジェクトは等価です。 インバリアントが完了しました |

 通常、2 番目の方向はより困難です。 

たとえば、同型ベクトル空間が同じ次元を持つことを証明することは保存です。 同じ有限次元を持つ 2 つのベクトル空間が同型であることを証明するには、同型を構築する必要があります。 

### 分類

 分類は、クラス内のすべてのオブジェクトを同等になるまで記述するプロセスです。 

分類定理は通常、次の形式になります。```text
Objects of type X are classified up to equivalence by invariant I.
```例:

 | オブジェクト | 分類不変 |
 | --------------------------------------------------- | ------------------------ |
 | 有限集合 | カーディナリティ |
 | 有限次元ベクトル空間$k$| 寸法 |
 | 有限生成されたアーベル群 | ランクとねじり係数 |
 | 直交相似のもとの実対称行列 | 固有値 |
 | コンパクトな接続面 | 属と方向性 |

 分類により、オブジェクトの大規模なコレクションがより単純なパラメータのリストに縮小されます。 

有限次元ベクトル空間の場合、分類は特に明確です。 

すべての有限次元ベクトル空間$k$と同型である$k^n$ユニークな$n$。 

ここ$n = \dim V$。 

### 正規形式

 正規形式は、各等価クラスの選択された代表です。 

有限次元ベクトル空間の場合、$k^n$寸法を表す標準です$n$。 

行列の場合、行縮小エシェロン形式は、行等価性の下での標準形式です。 

行列の一部のクラスでは、ジョルダン正規形は、条件付きの代数的に閉じた体上で正準形を与えます。 

| 設定 | 正規形 |
 | ------------------------------------ | ------------------------ |
 | 有限集合 |${1,\dots,n}$|
 | ベクトル空間 |$k^n$|
 | 行等価性のある行列 | 削減された行階層フォーム |
 | 特定の線形演算子 | ジョーダン標準形 |
 | 適切なフィールド上の二次形式 | 斜めのフォルム |

 正規形式は、等価性の質問を代表者間の平等性の質問に変えるため便利です。 

かどうかを尋ねるのではなく、$A$そして$B$が同等である場合、それらの正規形式を計算して比較します。 

### 強い不変量と弱い不変量

 不変条件の強さは異なります。 

弱い不変式は計算が簡単ですが、区別できるオブジェクトの数は少なくなります。 強力な不変式はより多くのオブジェクトを区別しますが、計算が難しくなる可能性があります。 

| 不変 | 強さ | コスト |
 | -------------------- | -------------------------------- | -------------- |
 | カーディナリティ | コンテキストに応じて低から高へ | 通常は低い |
 | 寸法 | ベクトル空間に強い | 低い |
 | 学位順序 | グラフに弱い | 低い |
 | 行列のスペクトル | 中程度から強い | 中 |
 | 基本グループ | 強力なトポロジー的不変式 | 高 |
 | 相同性グループ | 強力だが不完全 | 中～高 |

 数学の実践では、多くの場合、一連の不変式が使用されます。 安価な不変式から始めます。 オブジェクトを分離できない場合は、より強力なオブジェクトに移動します。 

### マップの下の不変性

 不変条件は、マップのクラスに対して相対的に定義されます。 

プロパティは、ある種類の変換では不変であっても、別の種類では不変ではない場合があります。 

たとえば、距離はアイソメトリでは不変ですが、同相同型では不変ではありません。 接続性は同相同型のもとでは不変ですが、計量距離を決定しません。 

| プロパティ | 保存者: |
 | ------------- | ------------------------------------ |
 | 距離 | アイソメトリ |
 | 角度 | 適切な設定での等角マップ |
 | つながり | 準同型写像 |
 | 寸法 | 線形同型写像 |
 | ランク | 行列の等価性 |
 | グループ注文 | 群同型写像 |

 これは、不変式は常にその同値関係とともに読み取られる必要があることを意味します。 

問題は「何が保存されるのか」だけではありません。 しかし、「どのような変換の下で保存されているのでしょうか?」

 ### 分類ワークフロー

 典型的な分類問題は次のパターンに従います。 

| ステップ | アクション |
 | ---- | ------------------------------------ |
 | 1 | オブジェクトを定義する |
 | 2 | 同値関係を定義する |
 | 3 | 不変条件を特定する |
 | 4 | 不変条件が保存されていることを証明する |
 | 5 | 不変条件が完全であるかどうかをテストする |
 | 6 | 正規の代表者を見つける |
 | 7 | 代表者の一意性を証明する |

 このワークフローでは、問題を管理可能な部分に分割します。 

たとえば、有限次元ベクトル空間を分類するには、次のようにします。 

| ステップ | 結果 |
 | ------------------------ | -------------------------------------- |
 | オブジェクト | 有限次元ベクトル空間$k$|
 | 等価性 | 線形同型写像 |
 | 不変 | 寸法 |
 | 保存 | 同型写像は基底を保存します。 
| 完全性 | 同じ次元は同型写像を与える |
 | 正規代表 |$k^n$|
 | 独自性 |$n$ユニークです |

 その結果、完全な分類が得られます。 

### 分類の限界

 すべての分類問題に単純な答えがあるわけではありません。 一部のクラスは大きすぎたり、ワイルドすぎたり、小さな変化に敏感すぎたりします。 

有限次元ベクトル空間は分類が簡単です。 有限群ははるかに困難です。 一般的にグラフは難しいです。 位相空間は非常に広いです。 

難しい状況では、分類が部分的になる可能性があります。 特殊なケースを分類したり、不変条件を定義したり、選択した制約の下では合理的な完全な分類が存在しないことを証明したりすることができます。 

| 状況 | 結果 |
 | ------------------------ | -------------------------------------- |
 | 単純なクラス | 完全な分類 |
 | 中級クラス | いくつかの不変式による分類 |
 | ワイルドクラス | 部分的な分類のみ |
 | 計算量の多いクラス | アルゴリズムによる分類 |
 | 基礎に敏感なクラス | 分類は公理に依存します。 

このような場合、完全な分類を行わなくても、不変式は引き続き役立ちます。 

### 実際のルール

 数学的オブジェクトを比較するときは、次のように尋ねてください。 

| 質問 | 目的 |
 | -------------------------------------- | ------------------------------- |
 | どのような同値関係が使用されていますか? | 同一性の定義 |
 | どのようなプロパティが保存されますか? | 不変条件を与える |
 | 不変条件は完全ですか? | 分類力を決定します |
 | それらを計算することはできるでしょうか? | 実用性を判断する |
 | 正規の代表者はいますか? | 比較を簡素化します |

 不変量は構造の測定可能な残余です。 それらは表現が変わっても残るものです。 分類では、これらの残基によってオブジェクトを整理し、それらが全体のストーリーを伝えるかどうかを尋ねます。
