## 1.4 有限オブジェクトと無限オブジェクト

 数学は有限の物体と無限の物体を明確に区別します。 多くの定義はどちらの設定でも似ていますが、本質的な点で動作が異なります。 この境界を理解することは、推論、証明設計、アルゴリズム的思考に必要です。 

要素が完全にリストされ、自然数で数えられる場合、集合は有限です。```text id="m7kq2p"
|A| = n   for some n ∈ N
```そのような有限数が存在しない場合、セットは無限になります。 より正確には、集合がそれ自体の適切な部分集合と 1 対 1 に対応できる場合、集合は無限になります。```text id="w8p1sx"
A is infinite  if  ∃B ⊂ A such that A ≅ B
```この性質は有限集合では発生しません。 これは、infinity の核となる機能、つまり縮小下での自己相似性を捉えています。 

例で区別を明確にします。 

| セット | サイズ | 観察 |
 | ------------------- | -------- | ----------------------------- |
 |`{1,2,3}`| 有限 | 完全な列挙が可能 |
 | 自然数`N`| 無限 |`N ≅ N \ {0}`|
 | 偶数 | 無限 | と同じサイズ`N`|
 | 実数 | 無限 | より厳密に大きい`N`|

 有限集合は徹底的な推論をサポートします。 すべての要素を直接確認できます。 証明は多くの場合、列挙、事例分析、または帰納法によって進められます。 

無限集合にはさまざまな方法が必要です。 直接列挙することは不可能です。 証明は構造、限界、コンパクトさ、または不変条件に依存します。 

この違いは基本的な性質に現れます。 

| プロパティ | 有限の場合 | 無限の場合 |
 | ---------------------------- | ----------------------------- | ----------------------- |
 | サブセットのサイズ | 等しくない限り、厳密に小さい | 全体のサイズを一致させることができます |
 | 射出は射出を意味します。 本当 | 偽 |
 | 射出は射出を意味します。 本当 | 偽 |
 | 有界シーケンス | 常に有限 | 無限かもしれない |
 | 終了 | 保証付き | 証拠が必要です |

 有限集合の場合、ドメインとコドメインのサイズが等しい場合、単射関数は自動的に全射になります。 これは無限セットの場合は失敗します。 たとえば、地図は次のとおりです。```text id="h3v8td"
f(n) = n + 1
```は自然数に対して単射的ですが、全射的ではありません。 

カーディナリティはセットのサイズを測定します。 有限セットの場合、基数は自然数です。 無限セットの場合、カーディナリティは全単射を使用してサイズを比較します。 

2 つのセット間に全単射が存在する場合、2 つのセットは同じカーディナリティを持ちます。```text id="b9q4rn"
A ≅ B  ⇔  ∃ bijection f : A → B
```これは驚くべき結果につながります。 自然数の集合と偶数の集合は同じ基数を持ちます。 The mapping:```text id="z2l6yx"
f(n) = 2n
```は全単射です。 

無限セットでもサイズが異なる場合があります。 実数は厳密には自然数よりも大きくなります。 これは、それらの間に全単射が存在しないことを示す対角線引数から生じます。 

| セット | カーディナリティのタイプ |
 | ---------------- | ---------------- |
 | 自然数 | 可算 |
 | 整数 | 可算 |
 | 有理数 | 可算 |
 | 実数 | 数え切れない |

 可算性とは、シーケンスが決して終わらない場合でも、シーケンス内の要素をリストできることを意味します。 不可算性とは、そのようなリストが存在しないことを意味します。 

有限と無限の区別は、代数と幾何学にも影響します。 

線形代数では、すべての有限次元ベクトル空間には、固定数の要素を持つ基底があります。 無限次元空間には、明示的に構築できない基底があり、追加の公理が必要になる場合があります。 

グラフ理論では、有限グラフを直接保存して処理できます。 無限グラフにはローカルルールと構造特性が必要です。 

解析では、有限和は無限級数とは異なる動作をします。 コンバージェンスが中心的な問題になります。 有限和の項を並べ替えても結果は変わりません。 無限級数を並べ替えると、値が変更されたり、収束が破壊されたりする可能性があります。```text id="p6n2cf"
∑_{i=1}^{n} a_i     (finite sum)
∑_{i=1}^{∞} a_i     (infinite series)
```限界は、無限プロセスに関する推論を形式化します。 数列は、その項が固定値に近づくと収束します。```text id="r4x8ko"
lim_{n→∞} a_n = L
```これにより、直接計算が近似計算に置き換えられます。 

コンパクト性は、有限推論と無限推論を分けるもう 1 つの原則です。 有限の設定では、議論をカバーすることは簡単です。 無限設定では、コンパクト性により、特定の無限コレクションが有限コレクションのように動作することが保証されます。 たとえば、トポロジでは、コンパクトなスペースにより、開いているすべてのカバーを有限のサブカバーに減らすことができます。 

計算により違いが強調されます。 アルゴリズムは、無限のオブジェクトをモデル化する場合でも、常に有限のデータに対して動作します。 実数は有限近似によって表現されます。 関数はコードで表現されます。 無限の構造には、有限の記述を通じてアクセスします。 

これにより、2 つの推論モードが導き出されます。 

| モード | 説明 |
 | -------- | --------------------------------- |
 | 有限 | 直接計算、列挙 |
 | 無限 | 近似、極限、不変式 |

 これらのモードの橋渡しが中心的なタスクです。 多くの定理は、有限の動作と無限の構造を結びつけます。 たとえば、多項式は有限多くの係数によって決定されますが、関数は無限領域で定義されます。 

構成的な数学では、無限を追加の制約とともに扱います。 無限オブジェクトは、その要素を生成するルールによって指定されなければなりません。 古典数学では、選択公理などの原理を使用して、明示的な構築を行わずに存在を許可します。 

この違いは、何が有効な証拠としてカウントされるかに影響します。 

| アプローチ | 無限の眺め | 写真 無限の眺め
 | ------------ | ---------------------------------- |
 | 建設的 | 明示的な構造を提供する必要があります |
 | クラシック | 間接的に存在を主張する可能性があります |

 有限オブジェクトは計算中は安定します。 無限のオブジェクトには解釈が必要です。 無限の構造に関する証明は、多くの場合、それを有限の近似または有限の証人に還元します。 

実践的なガイドライン:

 | 質問 | 有限の答え | 無限の答え |
 | -------------------------------- | ------------- | --------------- |
 | すべての要素をリストしてもいいですか? | はい | いいえ |
 | すべてのケースを確認できますか? | はい | いいえ |
 | 制限や収束は必要ですか? | いいえ | はい |
 | 注射は全単射を意味しますか? | はい | いいえ |

 有限の直感を無限の設定に適用すると、多くの間違いが発生します。 慎重な記述により、どの制度が適用されるかが区別されます。 

数学は、制御されたツールを使用して有限の推論を無限の領域に拡張することによって進歩します。 これには、制限、カーディナリティ、コンパクト性、および抽象化が含まれます。
