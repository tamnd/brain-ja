## 7.3 帰納と再帰

 帰納法は、段階的に構築されるオブジェクトの標準的な証明手法です。 再帰はマッチング構築手法です。 これらは共に、自然数、リスト、ツリー、構文、アルゴリズム、およびその他の生成された構造に関するステートメントを定義、計算、証明する方法を説明します。 

最も単純な形式は、自然数に対する数学的帰納法です。 

発言を証明するには$P(n)$あらゆる自然数に対して$n$、2つのことを証明します。 

まず、基本ケースを証明します。$$
P(0).
$$次に、帰納法ステップを証明します。$$
P(n) \Rightarrow P(n+1).
$$両方が確立されると、結論は次のようになります。$$
P(n) \text{ holds for all } n \in \mathbb{N}.
$$基本ケースが連鎖を開始し、帰納ステップが真実をある段階から次の段階に運ぶという考え方です。 

たとえば、次のことを証明してください$$
1 + 2 + \cdots + n = \frac{n(n+1)}{2}
$$すべての整数に対して$n \geq 1$。 

のために$n=1$、左側は$1$、右側は$$
\frac{1(1+1)}{2} = 1.
$$したがって、基本ケースが成り立ちます。 

ここで、この式がいくつかの場合に当てはまると仮定します。$n$:$$
1 + 2 + \cdots + n = \frac{n(n+1)}{2}.
$$それから$$
1 + 2 + \cdots + n + (n+1)
==========================
\frac{n(n+1)}{2} + (n+1).
$$右辺を因数分解します。$$
\frac{n(n+1)}{2} + (n+1)
========================
# (n+1)\left(\frac{n}{2}+1\right)
\frac{(n+1)(n+2)}{2}.
$$これは望ましい式であり、$n+1$の代わりに$n$。 したがって、この公式はすべてに当てはまります$n \geq 1$。 

という一時的な仮定は、$P(n)$が成り立つことを帰納法仮説といいます。 それは次の事件を証明するためにのみ使用されなければなりません。 すべての値について結果がすでにわかっているという前提ではありません。 

自然数は後続演算の繰り返し適用によって開始点から生成されるため、帰納法は機能します。 証明はオブジェクトの構造を反映します。 

再帰は同じアイデアの構築側です。 再帰的に定義されたオブジェクトは、基本データとより大きなケースを生成するためのルールによって指定されます。 

たとえば、階乗関数は次のように定義されます。$$
0! = 1
$$そして$$
(n+1)! = (n+1)n!.
$$この定義は、以前の値から各段階の値を計算する方法を示します。 帰納法は、それらの値の特性を証明する方法を教えてくれます。 

強力な誘導は、誘導ステップで以前のすべてのケースを使用できるバリアントです。 証明するには$P(n)$みんなのために$n$、次のことを証明します。$P(k)$あらゆるものに当てはまります$k < n$、 それから$P(n)$が成立する。 

これは、次のケースが直前のケース以上に依存する場合に便利です。 

たとえば、多くの割り算や因数分解の引数では、数値が正確に 1 減らない小さな因数に削減される可能性があるため、強力な帰納法が使用されます。 

構造帰納法は、同じ考え方を自然数を超えて拡張します。 オブジェクトがコンストラクターによって構築される場合、証明はそれらのコンストラクターに従います。 

リストの場合、空のリストの性質を証明し、それがリストに当てはまるかどうかを証明します。$L$に 1 つの要素を追加して形成されたリストにも当てはまります。$L$。 

木の場合は、葉の性質を証明し、それがサブツリーに当てはまる場合は、それらから構築された木にも当てはまることを証明します。 

正式な構文の場合、アトミック式のプロパティを証明し、次に各形成規則がプロパティを保持することを証明します。 

このため、帰納法は論理とコンピューター サイエンスにおける主要な証明手法の 1 つになります。 プログラム、文法、数式、データ構造に関する定理の多くは構造帰納法です。 

帰納法における主な規律は、正しいステートメントを選択することです。 このステップではより強力な仮説が必要なため、目的の主張が帰納法によって証明するには弱すぎる場合があります。 その場合、解決策は誘導文を強化することです。 

たとえば、アルゴリズムに関する定理には、実行のすべての段階で保存されるプロパティである不変式が必要になる場合があります。 不変式は最終結果よりも強力になる可能性がありますが、これにより帰納ステップが可能になります。 

よくある失敗は、基本ケースを証明した後、ステップを証明する代わりに結論を仮定することです。 帰納ステップでは、プロパティがある段階から次の段階まで維持されることを示す必要があります。 

もう 1 つのよくある失敗は、間違ったパラメータに対して帰納法を使用することです。 パラメータは、サイズ、長さ、深さ、ステップ数、または自然数インデックスなど、オブジェクトの構造を測定する必要があります。 

帰納法は、オブジェクトが再帰的な構造を持つ場合に有効です。 これは、無限の主張群を有限の証明パターンに変換します。つまり、正しく開始し、すべてのステップで正しさを維持します。 

再帰によりオブジェクトが構築されます。 帰納法は、そのように構築されたオブジェクトの性質を証明します。
