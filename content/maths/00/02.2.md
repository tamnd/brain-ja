## 2.2 形式的なシステムとセマンティクス

 数学は形式的なシステムを通じて機能します。 正式なシステムは、ステートメントの記述方法と証明の構築方法を指定します。 セマンティクスは、構造内でのステートメントが何を意味するかを説明します。 

正式なシステムには 4 つのコンポーネントがあります。 

| コンポーネント | 役割 |
 | --------------- | ----------------------------------- |
 | アルファベット | 式を記述するために使用される記号 |
 | 構文 | 有効な式を作成するための規則 |
 | 公理 | 最初のステートメントは true であると仮定されました。 
| 推論ルール | 新しいステートメントを導出するメソッド |

 これらのコンポーネントは構文層を定義します。 これらは、どのシンボルのシーケンスが有効な式としてカウントされ、どの導出が証明としてカウントされるかを決定します。 

簡単な例は命題論理に現れます。 アルファベットには次のような記号が含まれます。`P`、`Q`、`¬`、`∧`、`∨`、`→`。 構文は式の作成方法を指定します。```text id="a1z9rk"
If P and Q are formulas, then (P ∧ Q), (P ∨ Q), (P → Q) are formulas.
If P is a formula, then ¬P is a formula.
```公理は基本的な真理を提供します。 modus ponens などの推論ルールにより、導出が可能になります。```text id="c8m2ht"
From P and (P → Q), infer Q
```証明は数式の有限シーケンスであり、各ステップは公理であるか、推論規則によって前のステップからたどります。 

セマンティクスはこれらのシンボルに意味を割り当てます。 構造体は、シンボルをオブジェクトと操作にマッピングすることによって言語を解釈します。 

命題論理の場合、構造は真理値を変数に割り当てます。```text id="v5p3ld"
P = true
Q = false
```次に、化合物の式が真理値表に従って評価されます。 

一次ロジックの場合、セマンティクスはより豊富になります。 構造には以下が含まれます。 

| コンポーネント | 意味 |
 | --------- | ------------------------------------- |
 | ドメイン | オブジェクトのセット |
 | 定数 | ドメインの特定の要素 |
 | 機能 | 要素間のマッピング |
 | 関係 | ドメイン上のプロパティまたは関係 |

 次のようなステートメント:```text id="t2n7gw"
∀x (P(x) → Q(x))
```ドメイン内のすべての要素をチェックすることによって評価されます。 すべての要素が満たされていれば真です`P`も満たす`Q`。 

満足関係は構文とセマンティクスを結び付けます。```text id="f0r8ks"
M ⊨ φ
```これは「構造」と読みます。`M`ステートメントを満たします`φ`」 それはモデル内の真実を定義します。 

形式的なシステムは、意味を考慮せずにシンボルを操作します。 セマンティクスはモデル内のこれらのシンボルを解釈します。 2 つの層間の相互作用が中心となります。 

| レイヤー | フォーカス |
 | --------- | ------------------- |
 | 構文 | シンボルの操作 |
 | セマンティクス | 意味と真実 |

 システムは、構文上の派生が意味上の真実に対応するように設計されています。 これは、前述した健全性と完全性につながります。 

システムが異なれば、使用する言語も異なります。 算術では、数値、加算、乗算、順序に記号を使用します。 群理論では二項演算と恒等式が使用されます。 集合論はメンバーシップを使用する`∈`。 

各言語には表現できる内容が制限されています。 一次ロジックでは、サブセットや関数をエンコードせずに直接定量化することはできません。 高次システムではより豊かな表現が可能になりますが、より複雑になります。 

モデルは柔軟性を提供します。 1 つの形式言語に多くのモデルを含めることができます。 

| 言語 | 可能なモデル |
 | ------------ | -------------------------------------------- |
 | 算数 | 標準自然数、非標準モデル |
 | 群理論 | すべてのグループ |
 | グラフ理論 | すべてのグラフ |
 | 秩序理論 | 部分的に順序付けされたすべてのセット |

 ステートメントは、一部のモデルでは true である場合もあれば、他のモデルでは false である場合もあります。 これはモデル依存の真実につながります。 

理論とは、特定の言語における一連の公理です。 そのモデルは、すべての公理が成り立つ構造です。```text id="u9d4eq"
M ⊨ T   means   M satisfies all axioms in T
```理論は構造のクラスを説明します。 たとえば、群理論の公理はすべての群を記述します。 実閉体の公理は、実数と同様の構造を記述します。 

セマンティクスにより、理論と構造間の比較が可能になります。 次のような質問に答えます。 

| 質問 | 意味 |
 | ------------------------------------------ | ------------------- |
 | モデルは存在しますか? | 一貫性 |
 | すべてのモデルがステートメントを満たしていますか? | 有効性 |
 | ステートメントは特定のモデルに当てはまりますか? | そのモデルの真実 |

 形式的なシステムは理論間の解釈もサポートします。 シンボルをマッピングし、構造を保持することで、ある理論を別の理論に変換できます。 これは代数や論理学ではよくあることです。 

形式化と非公式推論の間には実際的な違いがあります。 数学者が完全に正式な証明を書くことはほとんどありません。 これらは意味論についての共通の理解に依存しています。 正式なシステムは、必要なときに厳密さを保証する基盤を提供します。 

証明アシスタントはこれを明確にします。 すべてのステップは構文規則に従う必要があります。 すべてのオブジェクトには型が必要です。 セマンティクスは定義と構造を通じてエンコードされます。 

動作パターン:

 | ステップ | アクション |
 | ---- | --------------------------------- |
 | 1 | 言語を選択してください |
 | 2 | 公理を定義する |
 | 3 | 構文的に結果を導き出す |
 | 4 | モデル内の結果を解釈する |

 このパターンは数学のあらゆる分野に現れます。 代数では演算と公理を定義し、その結果を研究します。 分析では限界と連続性を定義し、機能を研究します。 幾何学は空間と関係を定義し、それらの特性を研究します。 

正式なシステムは精度を提供します。 セマンティクスは意味を提供します。 数学には両方が必要です。
