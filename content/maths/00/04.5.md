## 4.5 例: グループ、スペース、グラフ

 構造的思考は例を通してより明確になります。 このセクションでは、同じ原則がさまざまな分野でどのように現れるかを示します。 

私たちは、グループ、位相空間、グラフという 3 つの領域に焦点を当てます。 それぞれに独自のオブジェクト、射、不変式、分類問題があります。 
### 1. グループ

 グループはセットです$G$結合性、恒等性、および逆数を満たす二項演算を使用します。 

#### オブジェクトとマップ

 * オブジェクト: グループ$(G, \ast)$※射影：群準同型写像$$
  f(a \ast b) = f(a) \cdot f(b)
  $$※同型写像：全単射準同型写像

 #### インスタンスの例

 | グループ | 説明 |
 | ---------------------------- | -------------------------------------- |
 |$(\mathbb{Z}, +)$| 加算中の整数 |
 |$(\mathbb{Q}^\times, \cdot)$| 乗算における非ゼロの有理数 |
 |$S_n$| の順列$n$要素 |
 |$D_4$| 正方形の対称性 | 正方形の対称性

 これらは、同じ構造タイプの異なる表現です。 

#### 不変条件

 | 不変 | 意味 | | |
 | ------------------ | --------------------- | - | -------------------------------- |
 | 注文$            | G                     | $| 要素の数 (有限の場合) |
 | アーベルのプロパティ | かどうか$ab = ba$| | |
 | サブグループ構造 | 内部組織 | | |
 | 要素の順序 | 周期的な動作 | | |

 #### 分類例

 ※プライムオーダーのグループごと$p$と同型である$\mathbb{Z}/p\mathbb{Z}$* 有限アーベル群は周期因子への分解により分類可能

 これは、不変条件による構造分類を示しています。 
### 2. 位相空間

 位相空間は集合である$X$オープンセットのコレクションと一緒に。 

#### オブジェクトとマップ

 * オブジェクト: スペース$(X, \mathcal{T})$* 射的写像: 連続写像
 ※同型写像：同型写像

 地図$f : X \to Y$の場合は連続です$$
f^{-1}(U) \text{ is open in } X \quad \text{for every open } U \subseteq Y.
$$#### インスタンスの例

 | スペース | 説明 |
 | -------------- | -------------------------------------- |
 |$\mathbb{R}$| 通常のトポロジーの実線 |
 |$[0,1]$| 閉じた間隔 |
 | 丸$S^1$| 単位距離の点$\mathbb{R}^2$|
 | 離散空間 | すべてのサブセットはオープンです |

 #### 不変条件

 | 不変 | 意味 |
 | -------------------- | -------------------------------------- |
 | つながり | 互いに素な開集合に分割することはできません。 
| コンパクトさ | 有限サブカバー プロパティ |
 | コンポーネントの数 | バラバラに分解 |
 | 基本グループ | ループ構造（上級） |

 #### 比較例

 *$[0,1]$そして$(0,1)$同相ではない
 *$\mathbb{R}$そして$(0,1)$同型である

 これは、トポロジでは距離は無視されますが、開集合構造は維持されることを示しています。 
### 3. グラフ

 グラフは頂点と辺で構成されます。 

#### オブジェクトとマップ

 * オブジェクト: グラフ$G = (V, E)$※射影：グラフ準同型性
 * 同型性: 隣接性を維持する全単射

 #### インスタンスの例

 | グラフ | 説明 |
 | -------------------- | ----------------------- |
 | パスグラフ | 頂点のチェーン |
 | サイクルグラフ | 閉ループ |
 | 完全なグラフ$K_n$| すべてのペアが接続されました |
 | 木 | 接続された非巡回グラフ |

 #### 不変条件

 | 不変 | 意味 |
 | -------------------- | ------------------------- |
 | 頂点の数 | サイズ |
 | エッジの数 | 接続レベル |
 | 学位順序 | 頂点度 |
 | 接続されたコンポーネント | 接続の構造 |
 | サイクルの存在 | ループ構造 |

 #### 比較例

 次数の異なる 2 つのグラフを同型にすることはできません。 
ただし、同じ次数シーケンスを持つグラフは依然として非同型である可能性があります。 

これは、不変条件が不完全である可能性があることを示しています。 
### 4. クロスドメイン比較

 同じ構造パターンが 3 つのドメインすべてに現れます。 

| コンセプト | グループ | トポロジー | グラフ |
 | -------------- | ------------------- | ------------------------ | ------------------- |
 | オブジェクト | グループ | スペース | グラフ |
 | 射影 | 準同型性 | 連続マップ | グラフの準同型性 |
 | 同型写像 | 群同型写像 | 準同型写像 | グラフの同型性 |
 | 不変条件 | 秩序、アーベル人 | コンパクトさ、つながりやすさ | 度数、成分 |
 | 分類 | 部分的または完全 | 部分的なことが多い | しばしば難しい |

 この表は、構造的思考が分野を問わず均一であることを示しています。 
### 5. 表現と構造

 各ドメインには複数の表現があります。 

| オブジェクト | 代表 | 構造 |
 | ------ | -------------------- | ------------------ |
 | グループ | 九九 | 抽象的な操作 |
 | スペース | 座標 | オープンセット |
 | グラフ | 隣接リスト | 接続性 |

 異なる表現で同じ構造を記述することができます。 

たとえば、グラフは次のように保存できます。 

* 隣接リスト
 * 隣接行列
 ・エッジセット

 これらは表現が異なりますが、同じ構造をエンコードしています。 
### 6. 重要な教訓

 * 構造は何が重要かを定義します
 * 射影は許可される変換を定義します
 * 同型性は同一性を定義します
 * 不変式は差異を検出します
 * 分類はオブジェクトを整理します

 これらの考え方は数学全体で繰り返されます。 

ある領域の問題は、別の領域にも類似の問題があることがよくあります。 構造的思考により、結果が伝達されます。 

たとえば:

 * グループでの分解はベクトル空間での分解と同等です
 * グラフの接続性はトポロジの接続性と同等です
 * 幾何学の対称性は代数の自己同型性と類似している
 ### 7. 実際のワークフロー

 新しい構造に直面したとき:

 | ステップ | アクション |
 | ---- | ---------------------- |
 | 1 | オブジェクトを識別する |
 | 2 | 射を識別する |
 | 3 | 不変条件を決定する |
 | 4 | 不変式による比較 |
 | 5 | 試みの分類 |

 このワークフローはドメイン全体に適用されます。 
構造的思考は、同じパターンを異なる文脈で見るときに効果的になります。 グループ、スペース、グラフは表面上は異なって見えますが、基本的なデザインは同じです。
