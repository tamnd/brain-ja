## 1.2 セット、タイプ、およびユニバース

 数学には、物体がどのようなものであるかを示す方法が必要です。 ステートメントを証明したり、関数を定義したり、2 つのオブジェクトを比較したりするには、その前に議論の領域が必要です。 セット、タイプ、およびユニバースは、そのドメインを編成するためのさまざまな方法を提供します。 

セットとは、要素と呼ばれるオブジェクトのコレクションです。 私たちはこう書きます：```text
x ∈ A
```それを意味する`x`セットの要素です`A`。 

例えば：```text
3 ∈ N
-2 ∈ Z
1/2 ∈ Q
π ∈ R
```セットは、オブジェクトがどこに存在するかを示します。 また、どのような操作やステートメントが意味をなすことが期待されるのかもわかります。 加算は、自然数、整数、有理数、実数、複素数、ベクトル、行列、その他多くの構造に対して定義されますが、各設定は加算に特定の意味を与えます。 

タイプも同様の役割を果たしますが、フォーメーション ルールにより重点が置かれます。 そう言うには`x`タイプがあります`T`ということです`x`有効な種類のオブジェクトです`T`。```text
x : T
```この表記法は、型理論、証明アシスタント、およびプログラミング言語のセマンティクスで一般的です。 

非公式数学では、集合と型は同様に動作することがよくあります。 ステートメント「させてください」`x ∈ R`」とステートメント「させてください」`x : R`」と二人とも宣言しています`x`は実数です。 しかし、それらは異なる基盤から来ています。 

| アイデア | 集合論的見解 | 型理論的見解 |
 | -------------- | -------------------------------------------------- | -------------------------------------- |
 | メンバーシップ |`x ∈ A`| 通常は「 | 」と入力することで置き換えられます。 
| 分類 | オブジェクトはセットに属します | オブジェクトにはタイプがあります |
 | 平等 | 多くの場合、グローバル | 通常は型を区別します。 
| 機能 | 製品のサブセットまたはセット間のマッピング | ある型を別の型に変換する用語 |
 | エラー処理 | 不適切な形式の表現は依然として非公式に現れる可能性があります。 不正に入力された式は拒否されます。 

集合論では、多くのオブジェクトが集合の 1 つの大きな宇宙に存在します。 数値、関数、関係、順序ペア、グラフ、空間はすべてセットとしてエンコードできます。 これにより均一な基盤が得られます。 グラフはセットのペアとして表現できます。 関数は順序付きペアのセットとして表すことができます。 トポロジは、サブセットのセットとして表すことができます。 

型理論では、各オブジェクトは型に属します。 式は入力規則に照らしてチェックされます。 自然数から実数への関数には次のような型があります。```text
f : N → R
```これはそれを言います`f`自然数を受け入れ、実数を返します。 表現`f(3)`もしそうなら意味がある`3 : N`。 表現`f(circle)`そうでなければ意味がありません`circle`タイプがあります`N`、通常はそうではありません。 

この型の規律は、無意味な表現を防ぐのに役立ちます。 これは、形式化された数学や検証済みのソフトウェアにおいて特に重要です。 

宇宙はサイズの問題を解決します。 すべてのコレクションを同じ種類のセットとして扱うことができる場合、矛盾が生じます。 古典的な例は、「自分自身を含まないすべての集合の集合」です。 このような矛盾を避けるために、財団ではレベルを区別します。 

宇宙は、多くの数学的オブジェクトを含むのに十分な大きさの領域ですが、それ自体を無制限に含むほど大きくはありません。 

集合論では、これは累積階層を通じて現れます。 セットは段階的に構築されます。 各段階で、以前のもののサブセットを収集します。 レベルが大きくなるほど、より複雑なセットが生成されます。```text
V0, V1, V2, V3, ...
```正確な正式な構造はさまざまですが、考え方は単純です。オブジェクトはサイズまたはランクによって階層化されます。 

型理論では、宇宙は次のように記述されることがよくあります。```text
Type 0
Type 1
Type 2
...
```小型タイプが生息する可能性があります`Type 0`。 小型タイプが生息する可能性があるタイプ`Type 1`。 これにより、1 つの型にそれ自体が無制限に含まれることが回避されます。 

| レベル | 非公式の役割 |
 | ------------- | -------------------------------------- |
 |`Type 0`| 通常の数学的オブジェクト |
 |`Type 1`| 要素が通常の型である型 |
 |`Type 2`| より大きな型コレクションの型 |
 | より高いレベル | さらなる階層化 |

 通常の数学では宇宙は目に見えません。 教科書には、群、環、位相空間がどの宇宙に属するかが記載されていることはほとんどありません。 しかし、この問題は、基礎を構築したり、証明アシスタント コードを作成したり、大きなオブジェクトのカテゴリについて議論したりするときに重要になります。 

たとえば、すべてのグループのカテゴリは大きいです。 そのオブジェクトはグループであり、各グループ自体には一連の要素が含まれています。 「すべてのグループ」を安易に通常の集合として扱うと、サイズの問題が発生する可能性があります。 圏論では、小さな圏、大きな圏、宇宙を区別することでこれを扱います。 

集合は拡張推論に便利です。 同じ要素を持つ 2 つのセットは等しいです。```text
A = B  exactly when  every element of A is an element of B,
and every element of B is an element of A.
```型は意図的な推論に便利です。 オブジェクトの構築方法が重要になる場合があり、平等にはより多くの構造が必要になる場合があります。 多くの正式なシステムでは、型間の変換を明示的に行う必要があります。 

たとえば、自然数`3`、整数`3`、有理数`3`、および実数`3`強制によって接続された異なる型のオブジェクトとして扱われる場合があります。```text
3 : N
3 : Z
3 : Q
3 : R
```非公式数学では、これらの区別が抑制されることがよくあります。 通常、証明アシスタントはそれらを指定することを強制します。 

この抑制は便利ですが危険です。 これにより数学は読みやすくなりますが、仮定が隠れてしまう可能性があります。 定理が関数が連続であると述べている場合、ドメインとコドメイン上のトポロジーを知る必要があります。 数列が収束するという定理が述べられている場合、周囲空間を知る必要があります。 定理が行列が可逆であると述べている場合、係数の体または環を知る必要があります。 

「させてください」というフレーズ`x`be an object」は設定がわかるまでは不完全です。 

優れた数学的ステートメントは、そのシンボルが意味を持つために十分なコンテキストを宣言します。 たとえば:```text
Let V be a finite-dimensional vector space over a field k.
Let T : V → V be a linear map.
```これにより、キャリア、スカラー場、次元仮定、および構造保存マップが得られます。 固有値、不変部分空間、または行列式に関する後のステートメントには、定義された設定が含まれるようになりました。 

コンテキストの指定が不十分だと、誤った主張や曖昧な主張につながります。 方程式:```text
x^2 + 1 = 0
```実数では解がありませんが、複素数では 2 つの解があります。 発言の真実は、それが解釈される世界に依存します。 

| 声明 | コンテキスト | 結果 |
 | --------------------------------------------------- | ---------------- | --------------- |
 |`x^2 + 1 = 0`|`x ∈ R`| 解決策はありません |
 |`x^2 + 1 = 0`|`x ∈ C`| 解決策は存在します |
 | すべての非ゼロ要素には逆の | があります。 整数 | 偽 |
 | すべての非ゼロ要素には逆の | があります。 有理数 | 本当 |
 | すべての有界シーケンスには収束サブシーケンスがあります。 実数 | 本当 |
 | すべての有界シーケンスには収束サブシーケンスがあります。 有理数 | 偽 |

 教訓は直接的です。オブジェクト、ステートメント、証明は、選択されたコンテキスト内に存在します。 

セット、タイプ、およびユニバースは、単に競合する表記法ではありません。 それらは数学的組織に対するさまざまな態度を表しています。 

セットは「このコレクションにどの要素が属しているか?」と尋ねます。 

型は、この式にどのような種類のオブジェクトが許可されるのかを尋ねます。 

宇宙は「私たちが定量化している領域はどれくらいの大きさなのか?」と尋ねます。 

現役の数学者は、多くの場合、3 つのアイデアすべてを非公式に使用します。 正式なシステムでは、区別を正確にすることが強制されます。 ベスト プラクティスは、どのオブジェクトが存在するか、どの操作が有効か、どの等価関係が使用されているかを読者が理解できるように十分なコンテキストを記述することです。 

すべての記号に居場所があると、数学はより安全になります。
