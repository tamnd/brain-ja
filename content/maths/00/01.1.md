## 1.1 抽象オブジェクトと構造

 数学は、無関係な細部を取り除いてオブジェクトを研究します。 数、関数、グラフ、空間、群は物理的なものとして研究されません。 それらは、それらが満たすルール、それらがサポートする関係、およびそれらを維持する変換を通じて研究されます。 

抽象オブジェクトとは、物質的な形式ではなく、その数学的特性を通じて考慮されるオブジェクトです。 整数`3`リンゴ、ポイント、ドル、または歩数を数えることができます。 それぞれの場合において、物理的オブジェクトは異なります。 の役割があるため、数学的オブジェクトは変わりません。`3`は自然数系における位置によって決まります。 

構造とは、関係、操作、またはルールを備えたオブジェクトのコレクションです。 たとえば、自然数は加算、乗算、順序、帰納法によって構造を形成します。 グラフは頂点と辺からなる構造を形成します。 ベクトル空間は、ベクトル、スカラー倍算、ベクトル加算、およびこれらの演算を接続する公理を含む構造を形成します。 

同じ基礎セットが異なる構造をサポートできます。 実数の集合は、有理数上の順序集合、体、計量空間、位相空間、またはベクトル空間として見ることができます。 それぞれの視点から異なる情報が得られます。 

| 実数の見方 | 主な構造 | よくある質問 |
 | --------------------- | ----------------------------- | -------------------------------- |
 | オーダーセット |`<`| どの要素が大きいでしょうか? |
 | フィールド |`+`、`*`、`0`、`1`| 方程式はどのように動作するのでしょうか? |
 | メートル空間 | 距離 | 収束とはどういう意味ですか? |
 | 位相空間 | オープンセット | どのプロパティが連続的ですか? |
 | ベクトル空間以上`Q`| 加算と有理スケーリング | どのような線形関係が存在しますか? |

 抽象的思考により、数学はアイデアを再利用できるようになります。 すべての群に関する定理を証明すると、それは加算の整数、乗算の非ゼロ有理数、正方形の対称性、およびその他の多くの系に適用されます。 定理は、要素の具体的な性質ではなく、グループの構造に依存します。 

これが抽象化の主な経済性です。 適切なレベルで証明された結果は何度も適用されます。 

通常、構造は 3 つの層で構成されます。 

| レイヤー | 意味 | 例 |
 | ----------------------- | ------------------------------ | --------------------------------- |
 | キャリア | 基礎となるオブジェクト | セットの要素 |
 | 操作または関係 | オブジェクトが相互作用する方法 | 追加、順序、隣接 |
 | 法則または公理 | 相互作用が満たすルール | 結合性、同一性、対称性 |

 グループの場合、キャリアはセットです。 この操作では、2 つの要素を別の要素に結合します。 法則では結合性、恒等要素、および逆元が必要です。 これらの要件によって構造が定義されます。```text
Group = set + binary operation + group axioms
```要素自体は、数値、行列、順列、関数、または幾何学的対称の場合があります。 グループの概念は、その具体的な起源を無視し、操作に関連する動作のみを保持します。 

オブジェクトと構造の間のこの分離が中心です。 数学では、オブジェクトが「何であるか」ということよりも、オブジェクトがシステム内でどのように動作するかを重視することがよくあります。 

2 つの構造間に構造が保存された対応関係がある場合、それらの構造は同じものとして扱うことができます。 この考え方は同型性をもたらします。 たとえば、偶数の整数の加法グループは、すべての整数の加法グループと同様に動作します。`n`偶数の整数に対応します`2n`、加算は保存されます。```text
n + m  corresponds to  2n + 2m
```オブジェクトは数値のサブセットとして異なりますが、グループ構造は同じです。 

この原則はどこにでも現れます。 線形代数では、体上の有限次元ベクトル空間は、その次元によって同型まで分類されます。 グラフ理論では、エッジを保持したまま頂点の名前を変更できる場合、2 つのグラフは構造的には同じです。 トポロジーでは、空間は連続写像と同相写像によって比較されます。 

抽象オブジェクトは、それを記述するために使用される言語にも依存します。 三角形は、ユークリッド幾何学、座標、ベクトル、変換、または計量関係を通じて研究できます。 各言語は異なる構造を強調します。 自動的に最終的なものはありません。 役立つ言語は問題によって異なります。 

定義によって、どの構造が重要であるかが決まります。 

たとえば、計量空間を定義するときは、3 つの基本法則を満たす集合と距離関数のみを保持します。 角度、座標、滑らかさは、後で追加しない限り無視します。 これにより、この概念はユークリッド空間、経路距離を含むグラフ、関数空間、その他多くの例を含めることができるほど広範になります。 

優れた抽象化にはコストがかかります。 それは具体的な直感を隠すことができます。 非常に一般的な定理は強力かもしれませんが、理解するのが難しくなります。 具体的な例は、計算するのは簡単ですが、転送するのは難しいかもしれません。 数学の練習はこれらのレベル間を移動します。 

| レベル | 強さ | リスク |
 | ------------------ | ----------------------------- | ----------------------- |
 | 具体例 | 計算と視覚化が簡単 | 一般化できないかもしれません |
 | 抽象的な構造 | ドメイン間で再利用可能 | 直感を隠すかもしれない |
 | 正式なシステム | 正確かつ確認可能 | 読みにくくなる可能性があります |

 スキルは、タスクに適切な抽象レベルを選択することです。 

数学の新しい分野を学ぶときは、次の 4 つの質問をしてください。 

| 質問 | 目的 |
 | --------------------------------- | -------------------------------------- |
 | オブジェクトとは何ですか? | 通信事業者を識別します |
 | 彼らはどのような構造を担っているのでしょうか？ | 操作と関係を識別する |
 | どのマップが構造を保存しているのでしょうか? | 自然な変換を識別する |
 | どのようなプロパティが不変のままでしょうか? | 理論が研究する内容を特定する |

 これらの質問は、主題を使用可能なシステムに変えます。 群理論では、マップは準同型写像であり、不変量には順序、部分群、商構造が含まれます。 トポロジーでは、マップは連続関数であり、不変条件には接続性、コンパクト性、ホールが含まれます。 線形代数では、マップは線形変換であり、不変量には次元、ランク、固有値、および標準形式が含まれます。 

オブジェクトを構造を通して見ると、数学は一貫したものになります。 抽象化とは意味を取り除くことではありません。 あるクラスの問題にとって重要なのは、意味の選択です。
