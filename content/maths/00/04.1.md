## 4.1 構造とインスタンス

 構造とはパターンのことです。 インスタンスは、そのパターンを具体的に実現したものです。 

この区別は数学的推論の中心です。 これにより、結果を構造レベルで一度証明してから、多くの例に適用できます。 

グループとは構造です。 加算中の整数は、その構造体のインスタンスです。 乗算における非ゼロの有理数は別の例です。 正方形の対称性はまた別です。 

| 構造 | インスタンス |
 | ----------------- | ----------------------------------------------- |
 | グループ |$(\mathbb{Z}, +)$|
 | グループ | 乗算における非ゼロの有理数 |
 | グループ | 正方形の対称性 | 正方形の対称性
 | ベクトル空間 |$\mathbb{R}^n$以上$\mathbb{R}$|
 | グラフ | 道路網 |
 | 位相空間 | 通常のオープンセットを備えたリアルライン |

 この構造は、どのようなデータと法律が必要であるかを指定します。 インスタンスは、これらの要件を満たす実際のオブジェクトを提供します。 

グループの場合、構造には次のものが必要です。 

| パート | 要件 |
 | ------------- | ------------------------------------------------------------------- |
 | キャリア | セット$G$|
 | 操作 | 二項演算$\ast : G \times G \to G$|
 | 結合性 |$(a \ast b) \ast c = a \ast (b \ast c)$|
 | アイデンティティ | 存在する$e \in G$そのような$e \ast a = a \ast e = a$|
 | インバース | あらゆる人にとって$a \in G$、存在します$a^{-1}$と$a \ast a^{-1} = e$|

 インスタンスは、法律を満たしている場合にのみ有効です。 

例えば、$(\mathbb{Z}, +)$グループです。 運送業者は、$\mathbb{Z}$。 演算は加算です。 その正体は、$0$。 の逆$n$は$-n$。 

対照的に、$(\mathbb{N}, +)$次の場合はグループではありません$\mathbb{N} = {0,1,2,\dots}$ほとんどの要素は内部に加法逆関数を持たないため、$\mathbb{N}$。 

これは、一般的な規則を示しています。同じような表記法があっても、同じ構造が保証されるわけではありません。 

表現$a + b$両方に現れるかもしれない$\mathbb{Z}$そして$\mathbb{N}$、しかし構造法則は異なります。 

### 区別が重要な理由

 構造的推論はパターンのレベルで機能します。 

定理がすべてのグループに対して証明された場合、その定理はすべての有効なグループ インスタンスに適用されます。 

例:

 どのグループでも、アイデンティティ要素は一意です。 

この定理が構造的に証明されれば、整数、行列、順列、または対称性についてそれを非難する必要はありません。 各インスタンスは結果を継承します。 

これが抽象化の主な利点です。 

| レベル | 完了した作業 |
 | ----------- | ---------------------- |
 | 構造 | 一般定理を証明する |
 | インスタンス | 公理を検証する |
 | アプリケーション | 継承された結果を使用する |

 構造体を使用すると、インスタンスをチェックする必要があるというコストがかかります。 群定理を適用する前に、オブジェクトが群であることを知っておく必要があります。 ベクトル空間の定理を適用する前に、オブジェクトがベクトル空間の公理を満たすことを知っておく必要があります。 

### インスタンスは多くの構造を保持できます

 同じオブジェクトで複数の構造をインスタンス化できます。 

実際の数字$\mathbb{R}$次のように表示できます。 

| 見る | 構造 |
 | -------------------------------- | ----------------- |
 |$(\mathbb{R}, +)$| 添加剤群 |
 |$(\mathbb{R}, +, \cdot)$| フィールド |
 |$(\mathbb{R}, <)$| オーダーセット |
 |$(\mathbb{R}, d)$| メートル空間 |
 |$\mathbb{R}$間隔を開けて | 位相空間 |
 |$\mathbb{R}$以上$\mathbb{Q}$| ベクトル空間 |

 各構造は異なる定理をサポートします。 

治療すれば$\mathbb{R}$フィールドとして、非ゼロ要素の乗法逆数について議論できます。 これを位相空間として扱うと、開集合と連続性について議論できます。 これを順序集合として扱う場合、上限と単調性について議論できます。 

インスタンスだけではアクティブな構造は決まりません。 テキストではそれを明示するか、文脈から明らかにする必要があります。 

### 構造の忘却

 場合によっては、構造の一部を意図的に無視することがあります。 これを忘却構造といいます。 

フィールドはリングとして見ることができます。 環は加法基として見ることができます。 計量空間は位相空間として見ることができます。 

| より充実した構造 | 忘れられた構造 |
 | ---------------- | ---------------------------- |
 | フィールド | リング |
 | リング | 加算中のアーベル群 |
 | メートル空間 | 位相空間 |
 | ベクトル空間 | セット |
 | グループ | セット |

 構造を忘れると、利用できる操作が少なくなります。 また、より多くのマップが有効になる可能性もあります。 

線形マップはベクトル空間構造を保存します。 基礎となるセット間の関数は何も保持する必要はありません。$$
T : V \to W
$$線形マップはより制限が厳しいため、$$
f : |V| \to |W|
$$基礎となるセット間の単純な関数として。 

表記$|V|$の基礎となるセットを意味するために使用されることもあります$V$余分な構造を忘れた後。 

### 構造の追加

 逆のプロセスは構造を追加することです。 セットには、トポロジ、グループ操作、順序、またはメトリックを与えることができます。 

たとえば、セット$\mathbb{R}$通常のトポロジ、ディスクリート トポロジ、またはその他のトポロジを搭載できます。 これらは、同じ基礎となるセット上に異なる位相空間を生成します。 

| 基礎となるセット | 追加された構造 | 結果 |
 | --------------- | ----------------- | ------------------ |
 |$\mathbb{R}$| 通常のトポロジ | 標準実線 |
 |$\mathbb{R}$| 離散トポロジ | 離散空間 |
 |$\mathbb{Z}$| 追加 | 添加剤群 |
 | 有限集合 | エッジ | グラフ |
 | 点のセット | 距離関数 | メートル空間 |

 構造を追加すると、言えることが増えます。 また、地図によって保存しなければならないものも増えます。 

### インスタンスとしてのモデル

 論理学では、理論のインスタンスはモデルと呼ばれることがよくあります。 

理論は公理を与えます。 モデルはこれらの公理を満たすオブジェクトを与えます。$$
M \models T
$$という構造を意味します$M$理論を満たします$T$。 

たとえば、群公理は理論を定義します。 どのグループもその理論のモデルです。 

これは構造的思考と形式的論理を結びつけます。 構造は、通常の数学における単なるパターンではありません。 形式言語の解釈である場合もあります。 

### 正規インスタンスと非正規インスタンス

 いくつかの例は自然に発生します。 選択を必要とするものもあります。 

ベクトル空間$k^n$のスタンダードモデルです$n$-次元ベクトル空間上の$k$。 毎$n$-次元ベクトル空間上の$k$と同型である$k^n$, しかし、同型性は通常、基底の選択に依存します。$$
V \cong k^n
$$これは構造的には正しいですが、基礎が選択されない限り正規ではありません。 

区別が重要です。 

| 声明 | 意味 |
 | --------------------------------- | -------------------------------------- |
 |$V \cong k^n$| 同型写像が存在します。 
|$V = k^n$| オブジェクトは文字通り等しい |
 | 根拠により特定される$V$と$k^n$| 選択により具体的な表現が得られます。 

構造的な同一性が自動的に文字通りの同一性を与えるわけではありません。 

### 表現と構造

 多くの場合、インスタンスには表現があります。 表現とは、それを保存または書き込む方法です。 構造とは表現が意味するものです。 

基底が選択された後、行列は線形マップを表すことができます。$$
A \in M_{m \times n}(k)
$$地図を表します$$
T : k^n \to k^m
$$基数を変更すると行列は変更されますが、基礎となる線形マップは変更されません。 

したがって、行列表現は座標に依存します。 線形マップは構造的なものです。 

| オブジェクト | 代表 | 構造的な意味 |
 | ----------------- | ----------------- | -------------------------------- |
 | ベクトル | 座標列 | ベクトル空間の要素 |
 | マトリックス | スカラーの配列 | 線形変換 |
 | グラフ | 隣接リスト | 隣接関係のある頂点 |
 | 多項式 | 係数リスト | 形式的な式または関数 |
 | 位相空間 | オープンセット一覧 | 近隣の構造 |

 表現と構造を混同すると、推論が脆弱になります。 

### 構造物の輸送

 同型性により、構造をあるオブジェクトから別のオブジェクトに転送できます。 

もし$f : A \to B$は全単射であり、$A$手術があります$\ast$での操作を定義できます。$B$通過することで$f$:$$
b_1 \star b_2 = f(f^{-1}(b_1) \ast f^{-1}(b_2)).
$$これにより、$B$構造的には同等$A$。 

構造の輸送は、同型オブジェクトが同じ構造特性を共有する理由を説明します。 また、数学にとって平等がしばしば厳しすぎる理由も説明されています。 

### 実際のルール

 新しいトピックに入るときは、4 つのレイヤーに分けます。 

| レイヤー | 質問 |
 | ------------------ | ------------------------------------------------ |
 | 基礎となるオブジェクト | 要素とは何ですか? |
 | 構造 | どのような操作、関係、法則が存在しますか? |
 | 表現 | オブジェクトはどのように書き込まれたり保存されたりするのでしょうか? |
 | 等価性 | 2 つのインスタンスが同じとみなされるのはどのような場合ですか? |

 これにより、カテゴリエラーが防止されます。 

たとえば、グラフを研究するときは、頂点にラベルが付いているかどうかを調べます。 ベクトル空間を研究するときは、基底が固定されているかどうかを考えてください。 トポロジー空間を研究するときは、どのトポロジーが使用されているかを尋ねてください。 

同じデータが異なる構造をサポートできます。 同じ構造でも異なる表現が可能です。 同じ構造オブジェクトが多数の同型インスタンスを持つことができます。 

これらのレベルが分離されたままであれば、数学はより明確になります。
