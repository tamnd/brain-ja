## 2.4 独立現象

 システムがステートメントもその否定も証明しない場合、ステートメントは公理システムから独立しています。 独立性とは、まさに決断不能の形態です。```text
T ⊬ φ
T ⊬ ¬φ
```ここ`T`は理論であり、`φ`はその理論の言語で書かれた文です。 表記にはこう書いてあります`φ`から導き出すことはできません`T`、 そして`¬φ`から導き出すことはできません`T`どちらか。 

独立性とは、声明が曖昧であることを意味するものではありません。 これは、選択された公理には、それを決定するのに十分な情報が含まれていないことを意味します。 

独立性を証明する一般的な方法は、モデルの構築です。 それを示すために`φ`から独立しています`T`、1 つは 2 つのモデルを構築します。```text
M ⊨ T + φ
N ⊨ T + ¬φ
```最初のモデルは次の公理を満たします。`φ`。 2 番目のモデルは次の公理を満たします。`¬φ`。 両方のモデルが存在する場合、`T`一人では決められない`φ`、背景の推論が正しいと仮定します。 

| 目標 | 方法 |
 | ----------------- | ------------------------ |
 | 見せる`T ⊬ φ`| のモデルを構築する`T + ¬φ`|
 | 見せる`T ⊬ ¬φ`| のモデルを構築する`T + φ`|
 | 独立性を示す | 両方の種類のモデルを構築する |

 平行公準は古典的な幾何学的例です。 ユークリッド幾何学はそれを受け入れます。 双曲幾何学はそれを拒否し、平行線の異なる動作に置き換えます。 残りの公理はどちらかの選択を強制するものではありません。 

| ジオメトリ | 並列動作 |
 | ---------------- | --------------------------------------------------- |
 | ユークリッド | 線の外側の点を通るちょうど 1 つの平行線 |
 | 双曲線 | このような点を通る複数の平行線 |
 | ニュートラルジオメトリ | 質問を決めない |

 これは、ステートメントが、より小さな公理ベースから独立していながらも、なじみのあるモデルのために幾何学的に明白に見える可能性があることを示しています。 

集合論はより深い例を提供します。 連続体仮説は、無限集合のサイズに関するものです。 カーディナリティが厳密に自然数と実数の間にある集合が存在するかどうかを尋ねます。 標準の ZFC 公理内では、ZFC が一貫していると仮定すると、連続体仮説は証明も反駁もできません。 

これは重要な結果をもたらします。 どちらの拡張も形式理論として可能です。```text
ZFC + CH
ZFC + ¬CH
```それぞれは、一貫性の仮定に基づいて、正当な数学的世界として研究することができます。 

独立性は算数にも現れます。 ゲーデル スタイルのステートメントは、事実上、特定のシステムでは証明できないと言えるように構築されています。 システムに一貫性があり、算術を表現するのに十分な強度がある場合、そのようなステートメントは意図した自然数では真である可能性がありますが、システム内では証明できません。 

これにより、次のものが区別されます。 

| ステータス | 意味 |
 | ------------------ | -------------------------------------------------------- |
 | 偽 | 意図した解釈で反駁される |
 | 未証明 | 現在判明している証拠はありません |
 | 証明不能`T`| 次の公理からの証明は存在しません`T`|
 | から独立した`T`| この声明もその否定も次からは証明できません`T`|

 「証明されていない」と「証明できない」の区別は特に重要です。 推測は今日は証明できなくても、明日には証明できるかもしれません。 公理または形式的設定を変更せずに独立したステートメントを解決することはできません。 

独立性は常に理論と相対的です。 1 つの理論から独立した声明は、より強力な理論によって決定される場合があります。```text
T ⊬ φ
S ⊢ φ
```どこ`S`伸びる`T`。 

たとえば、公理を追加すると、以前は独立していたステートメントを決定できます。 その代償として、より強力な理論は新しい公理の受け入れやすさと一貫性の強さに依存することになります。 

| アクション | 効果 |
 | ------------------------------ | -------------------------------------- |
 | 追加`φ`公理として | 勢力`φ`新しい理論では真実です |
 | 追加`¬φ`公理として | 勢力`φ`新しい理論では誤りである |
 | より強力な構造公理を追加する | 決めるかもしれない`φ`間接的に |
 | ロジックまたは基盤を変更する | 証拠としてカウントされるものが変更される可能性があります |

 独立現象は、公理が単なる出発点ではないことを示しています。 それらは研究対象の数学的世界を形作ります。 

実際には、独立性にはいくつかの用途があります。 

まず、理論の限界を明確にします。 ステートメントが独立している場合、同じ公理システム内でさらに作業を行ってもステートメントは解決されません。 

第二に、定理の証明と公理の選択を分離します。 独立性が判明すると、質問は「これを証明できるか?」から変わります。 「意図された目的に適した理論を与える拡張はどれですか?」

 第三に、隠れた前提を明らかにします。 証明は初歩的な推論のみを使用しているように見えますが、実際にはより強力な原則に依存しています。 

選択の公理は有用な例を提供します。 代数、トポロジー、解析の多くの結果で、場合によっては暗黙的にそれが使用されます。 一部の定理は、選択の弱い形式または強い形式に相当します。 選択を省略すると、それらの定理は失敗するか、独立してしまう可能性があります。 

| 声明または原則 | 選択との関係 |
 | ------------------------------ | -------------------------------------- |
 | すべてのベクトル空間には基底があります。 選択を使用します |
 | ティコノフの定理 | 共通設定の選択肢に相当 |
 | ゾーンの補題 | 選択肢 | と同等
 | 整序定理 | 選択肢 | と同等

 したがって、独立性は数学的なスタイルに影響を与えます。 建設的な証明により、より強力な公理が回避される可能性があります。 古典的な証明はそれらを自由に使用できます。 基本的に慎重な証明によって、どの原則が必要であるかが示されます。 

独立性は分類にも影響します。 独立したステートメントを持つ理論では、複数の非等価な拡張が認められます。 最終的な 1 つの宇宙の代わりに、一貫した数学的世界のファミリーが存在する可能性があります。 

これは集合論では一般的であり、強制メソッドと内部モデルメソッドが異なるプロパティを持つモデルを構築します。 同じ基本公理が、基数、定義可能性、および組み合わせ原理に関する質問に対する異なる回答をサポートできます。 

独立性に関する質問に役立つワークフローは次のとおりです。 

| ステップ | 質問 |
 | ---- | -------------------------------------------------- |
 | 1 | どういう理論`T`使用されていますか？ |
 | 2 | 正確にはどのような声明ですか`φ`テストされていますか？ |
 | 3 | できる`T + φ`モデル化される？ |
 | 4 | できる`T + ¬φ`モデル化される？ |
 | 5 | ステートメントを決定する追加の公理は何ですか? |
 | 6 | これらの公理はどのような数学的コストをもたらしますか? |

 独立性が数学を弱めるわけではありません。 これにより、公理の役割が明確になります。 これは、いくつかの疑問は論理だけでは解決できないことを示しています。 フレームワークの選択が必要です。 

成熟した理論は、その仮定に名前を付け、拡張を比較し、どの結果がどの公理に依存するかを追跡することによって独立性を処理します。
