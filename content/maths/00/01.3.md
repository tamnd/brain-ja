## 1.3 平等、同一性、および等価性

 数学は同一性の正確な概念に依存します。 シンボル`=`シンプルに見えますが、文脈に応じて異なる意味を持ちます。 このセクションでは、平等、同一性、等価性の 3 つのレベルに分けます。 

平等は最も厳格な概念です。 2 つのオブジェクトは、基礎となるシステム内で同じオブジェクトである場合、等しいと見なされます。```text
a = b
```集合論では、平等は外延的です。 2 つのセットは、まったく同じ要素を持っている場合、等しいと見なされます。```text
A = B  if and only if  ∀x (x ∈ A ↔ x ∈ B)
```この定義では、セットの記述方法が無視されます。 セット`{1,2,3}`そして`{3,2,1}`メンバーシップが一致するため、等しいです。 

平等は予測どおりに動作します。 

| プロパティ | 意味 |
 | ------------ | ------------------------------------------ |
 | 再帰的 |`a = a`|
 | 対称 |`a = b`暗示する`b = a`|
 | 推移的 |`a = b`そして`b = c`暗示する`a = c`|
 | 置換 | 任意の式内の等しいを等しいに置き換えます。 

交代は重要です。 もし`a = b`、その後、に関する任意のステートメント`a`次の場合は true のままです`a`に置き換えられます`b`。 

アイデンティティはさらに微妙です。 構造内で 2 つのオブジェクトを同じと見なすべきかどうかを尋ねます。 アイデンティティは、オブジェクトの構築方法またはラベル付け方法に依存する場合があります。 

たとえば、順序付きペアを考えてみましょう。```text
(1,2) ≠ (2,1)
```要素はセットとして一致します`{1,2}`, しかし、順序が重要です。 アイデンティティにはメンバーシップを超えた構造が含まれます。 

代数では、恒等性は演算の中立要素を指すことがよくあります。```text
a + 0 = a
a * 1 = a
```ここ、`0`そして`1`加算と乗算の恒等要素です。 これは「アイデンティティ」という言葉の別の使い方です。 文脈が意味を決定します。 

タイプ理論の設定では、アイデンティティには証拠や証人が必要になる場合があります。 2 つのオブジェクトは、値が等しい場合がありますが、構造が同一ではありません。 この違いは、正式な検証と証明アシスタントに現れます。 

平等とは、平等を制御して弱めることです。 2 つのオブジェクトが等しくなくても、対象のプロパティを共有する場合は同等です。 

同値関係とは関係です`~`それは以下を満たす：

 | プロパティ | 意味 |
 | ---------- | --------------------------------- |
 | 再帰的 |`a ~ a`|
 | 対称 |`a ~ b`暗示する`b ~ a`|
 | 推移的 |`a ~ b`そして`b ~ c`暗示する`a ~ c`|

 等価性はセットをクラスに分割します。 各クラスには、選択された関係に基づいて同じとみなされるオブジェクトが含まれています。 

例は数学全体に現れます。 

| ドメイン | 等価関係 | 解釈 |
 | -------------- | -------------------- | ------------------------ |
 | 整数 |`a ≡ b (mod n)`| 同じ余り |
 | ジオメトリ | 合同 | 同じ形とサイズ |
 | 線形代数 | 行の等価性 | 同じ解空間 |
 | トポロジー | 準同型写像 | 同じトポロジー構造 |
 | 代数 | 同型写像 | 同じ代数構造 |

 等価性により複雑さが軽減されます。 すべてのオブジェクトを個別に研究するのではなく、与えられた基準の下で同じように動作するオブジェクトのクラスを研究します。 

同型性はその中心的な例です。 構造を保存する全単射写像が存在する場合、2 つの構造は同型です。```text
f(a ⋆ b) = f(a) ⋆ f(b)
```この式は演算の保存を表します`⋆`。 正確な形状は構造によって異なります。 グループでは、`⋆`グループ操作です。 ベクトル空間では、加算とスカラー乗算が含まれます。 グラフでは隣接性が維持されます。 

同型オブジェクトは、構造上の目的から同じものとして扱われます。 この考え方により、分類結果が得られます。 たとえば、体上のすべての有限次元ベクトル空間は、その次元によって同型写像まで決定されます。 

平等、同一性、同等性は階層を形成します。 

| レベル | 厳格さ | 使用 |
 | ----------- | ----------------- | ------------------- |
 | 平等 | 最強 | 正確な置換 |
 | アイデンティティ | コンテキスト依存 | 構造的同一性 |
 | 等価性 | 最弱 | 分類 |

 これらのレベルが混在すると混乱が生じます。 たとえば、書くこと`A = B`when only an isomorphism exists hides important structure. 注意深く書くと、次のことが区別されます。```text
A = B        (exact equality)
A ≅ B        (isomorphism)
A ~ B        (equivalence)
```各シンボルは異なる主張を示します。 

実際には、数学者は、文脈が明確になると、これらの区別を曖昧にすることがよくあります。 2 つの構造が同型であることが証明された後、それらは互換性があるものとして扱うことができます。 これは推論を単純化しますが、構造を保存するマップがすでに確立されていることを前提としています。 

正確なアプローチは次のパターンに従います。 

| ステップ | アクション |
 | ---- | ------------------------------------------------ |
 | 1 | オブジェクトと構造を定義する |
 | 2 | 等価性の概念を定義する |
 | 3 | 等価性の下でプロパティが不変であることを証明する |
 | 4 | オブジェクトを同等になるまで分類する |

 このパターンは多くの分野で見られます。 群理論では、群は同型まで分類されます。 トポロジーでは、空間は同相写像まで分類されます。 線形代数では、行列は類似度まで分類されます。 

同一性の正しい概念を選択することは、設計上の決定です。 厳密すぎると理論が硬直化します。 弱すぎると区別がなくなってしまいます。 適切なレベルは問題によって異なります。 

数学は、可能な限り生の等価性を構造化された等価性に置き換えることによって進歩します。 この変化により、より深い不変条件が明らかになり、複雑さが軽減されます。
