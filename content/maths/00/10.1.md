## 10.1 論文の構成

 数学的論文は、アイデアを文書化したものです。 結果を列挙するだけではありません。 どのような問題が研究されているのか、その問題がなぜ重要なのか、どのようなツールが使用されているのか、何が証明されているのかについて説明します。 

初心者にとって、論文は丁寧に整理された説明であると考えると便利です。 それぞれの部分に役割があります。 タイトルは読者にその論文の内容を伝えます。 導入部分で主な問題が明らかになります。 定義によって言語が準備されます。 定理は主な主張を述べています。 証拠は、これらの主張がなぜ真実であるかを説明します。 例は、読者が結果の意味を理解するのに役立ちます。 

### タイトルと要約

 タイトルは読者に主な主題を伝える必要があります。 タイトルがあいまいだと、論文が見つけにくくなり、理解しにくくなります。 

たとえば、「代数の結果」というタイトルは広範すぎます。 より適切なタイトルは、「二項定理の簡単な証明」または「有限グラフ内のパスの数え方」です。 これらのタイトルは、読者に明確な期待を与えます。 

要約は論文の短い要約です。 どのような問題が研究され、どのような結果が得られたかを記述する必要があります。 高度な論文では、要約が技術的なものになる場合があります。 初心者が文章を書く場合は、直接的かつシンプルにする必要があります。 

### はじめに

 はじめにではこの論文の目的を説明します。 基本的な質問に答えます。 

私たちはどんな問題を研究しているのでしょうか？ 
なぜこの問題は興味深いのでしょうか?
 主な結果は何ですか?
 どのようなアイデアが使用されるのでしょうか?

 和の計算式が論文で証明されたとします。$$
1 + 2 + 3 + \cdots + n.
$$導入部分では、この論文は最初の要素を追加する方法を研究していると言えるかもしれません。$n$正の整数を計算し、その合計が次であることを証明します。$$
\frac{n(n+1)}{2}.
$$これにより、詳細が始まる前に読者に何を期待するかを伝えます。 

### 背景と定義

 何かを証明する前に、論文はその言葉を明確にしなければなりません。 ここで定義が登場します。 

たとえば、論文で偶数について説明している場合、「偶数」が何を意味するかを定義する必要があります。 

整数$n$整数が存在する場合でも$k$そのような$$
n = 2k.
$$定義は混乱を防ぎます。 これらにより、論文の残りの部分がより正確になります。 読者は、重要な単語がどのように使用されているかを推測する必要はありません。 

### 主な結果

 主な結果は通常、定理、命題、または補題として述べられます。 

定理は重要な結果です。 補助定理は、より大きな結果を証明するために使用される小さな結果です。 命題は、多くの場合、重要性が中程度の有用な結果です。 

たとえば:

 **定理** すべての正の整数に対して$n$、$$
1 + 2 + 3 + \cdots + n = \frac{n(n+1)}{2}.
$$優れた定理ステートメントは、証明を開始する前に明確である必要があります。 何が想定されているか、何が主張されているかを正確に述べるべきです。 

### 証明

 証拠とは、主張が正当化される部分です。 既知の事実から望ましい結論に向かって段階的に進む必要があります。 

たとえば、次の式を証明するには、$$
1 + 2 + 3 + \cdots + n,
$$考えられる方法の 1 つは誘導です。 まず式を証明してください$n = 1$。 そしてそれが一部の人にとっては真実であると仮定してください$n$そしてそれを証明してください$n + 1$。 

証明は説明のつかない記号の集合であってはなりません。 各ステップがなぜ続くのかを読者に伝えるには言葉が必要です。 

### 例

 例は、読者が結果の意味を理解するのに役立ちます。 

式については$$
1 + 2 + 3 + \cdots + n = \frac{n(n+1)}{2},
$$私たちはテストできます$n = 5$:$$
1 + 2 + 3 + 4 + 5 = 15.
$$式は次のようになります$$
\frac{5(5+1)}{2} = \frac{30}{2} = 15.
$$この例は定理を証明するものではありませんが、定理を理解しやすくします。 

### 結論

 結論は読者に何が示されたかを思い出させます。 また、考えられる次の質問についても言及する場合があります。 

たとえば、最初の和の公式を証明した後、$n$正の整数の場合、結論として二乗和が求められる場合があります。$$
1^2 + 2^2 + 3^2 + \cdots + n^2.
$$良い結論は論文全体を繰り返すものではありません。 議論を終了し、次に何が起こるかを示します。 

### 実用的な構造

 初心者の数学的記述の場合、多くの場合、単純な構造で十分です。 

1. 問題を述べます
 2. 必要な定義を入力します。 
3. 主な結果を述べます
 4. 結果を証明する
 5. 例を挙げる
 6. 学んだことを説明する

 この構造により、紙は読みやすくなります。 これは、書き手がすぐに記号に飛び込むことを避けるのに役立ち、読者が最初から最後まで数学的議論を追うのに役立ちます。
