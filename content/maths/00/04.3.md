## 4.3 同一性としての同型性

 同型性は、構造的同一性の数学的概念です。 2 つのオブジェクト間に、関連する構造を保持する可逆マップがある場合、2 つのオブジェクトは同型です。 

通常、平等は厳しすぎる。 2 つのオブジェクトは異なる表現を持つことができ、理論の目的上は同じように動作します。 

たとえば、整数の加法グループと偶数整数の加法グループはセットとして等しくありません。$$
\mathbb{Z} \neq 2\mathbb{Z}
$$しかし、それらはグループとして同型です。 地図$$
f : \mathbb{Z} \to 2\mathbb{Z}, \quad f(n) = 2n
$$は全単射で加算を保存します:$$
f(n+m) = 2(n+m) = 2n + 2m = f(n) + f(m).
$$したがって、2 つのグループは同じグループ構造を持ちます。 

### 定義

 同型射は、逆射を伴う射です。 

もし$A$そして$B$は構造化されたオブジェクトであり、$A$に$B$射です$$
f : A \to B
$$射が存在するような$$
g : B \to A
$$と$$
g \circ f = \operatorname{id}_A
$$そして$$
f \circ g = \operatorname{id}_B.
$$そのようなマップが存在する場合、次のように書きます。$$
A \cong B
$$これはつまり$A$そして$B$構造的には同じです。 

### 同型性は構造に依存する

 同型性の意味は、研究対象のオブジェクトのカテゴリによって異なります。 

| 構造 | 同型写像 |
 | ----------------- | -------------------------------------------------------- |
 | セット | 全単射 |
 | グループ | 全単射群準同型 |
 | リング | 互換性のある演算による全単射リング準同型 |
 | ベクトル空間 | 可逆線形マップ |
 | 位相空間 | 準同型写像 |
 | メートル空間 | アイソメトリ |
 | グラフ | 逆を使用した隣接関係を保持する全単射 |

 同じ 2 つの基礎となるセットが、ある構造では同型であり、別の構造では同型ではない場合があります。 

たとえば、2 つの空間は同型であっても等長ではない場合があります。 これらは同じトポロジー構造を持っていますが、異なる計量構造を持っています。 

これは、同型性が絶対的なものではないことを示しています。 それは、どのような構造を保持することを選択するかに関係します。 

### 等価性と同型性

 平等とは、基礎となる形式システムにおいて 2 つのオブジェクトが文字通り同じオブジェクトであることを意味します。 

同型性とは、2 つのオブジェクトが同じ構造を持つことを意味します。 

| 関係 | 意味 | 強さ |
 | ----------- | ----------------------- | -------- |
 |$A = B$| 文字通りの等価性 | より強力 |
 |$A \cong B$| 構造的同一性 | 弱い |
 |$A \sim B$| 選択された等価性 | 最弱 |

 通常の数学的実践では、同型オブジェクトは、一旦同型が確立されると同じものとして扱われることがよくあります。 これは効率的ですが、慎重に行う必要があります。 

例えば：$$
V \cong k^n
$$あらゆる人にとって$n$-次元ベクトル空間$V$以上$k$。 しかし$V$文字通りに等しいわけではありません$k^n$そのように定義されていない限り。 

基底を選択すると同型写像が得られます。$$
V \to k^n.
$$異なる塩基は異なる同型性を与えます。 したがって、識別は通常非正規的です。 

### 正準同型性

 同型写像は、任意の選択なしに、与えられた構造によって自然に決定される場合に標準的です。 

たとえば、有限次元ベクトル空間$V$は当然その double double と同型です。$$
V \cong V^{**}
$$マップは各ベクトルを送信します$v \in V$の評価関数へ$V^*$:$$
\phi \mapsto \phi(v).
$$この構築では基礎を選択する必要はありません。 

対照的に、同型写像$$
V \cong k^n
$$基礎を選択する必要があります。 したがって、一般的には非標準的です。 

| 声明 | 選択が必要ですか? | 正統派？ |
 | -------------------------------------------------------------- | ----------------------: | ---------: |
 |$V \cong k^n$| はい、基準を選択してください | いいえ |
 |$V \cong V^{**}$有限次元の場合$V$| 根拠は必要ありません | はい |
 | 有限集合$n$要素は全単射です${1,\dots,n}$| はい、順序を選択してください | いいえ |

 正準同型写像は、隠れた選択肢に依存しないため、識別として使用するのがより安全です。 

### 同型性の下での不変量

 不変式は、同型性によって保存されるプロパティです。 

もし$A \cong B$、その後の任意の構造的不変式$A$の対応する不変量と等しい$B$。 

例:

 | 構造 | 不変 |
 | ----------------------- | -------------------------------------------------------- |
 | 有限集合 | カーディナリティ |
 | ベクトル空間 | 寸法 |
 | 類似度の行列 | トレース、行列式、固有値 |
 | グループ | 順序、アーベル性、サブグループ構造 |
 | 位相空間 | コンパクトさ、つながりやすさ |
 | グラフ | 頂点の数、次数順序、連結成分 |

 不変条件は、2 つのオブジェクトが同型ではないことを証明するのに役立ちます。 1 つの不変量が異なる場合、同型性は存在できません。 

たとえば、同じフィールド上の異なる次元のベクトル空間は同型ではありません。$$
k^m \cong k^n \quad \text{if and only if} \quad m = n.
$$次元は、固定フィールド上の有限次元ベクトル空間の完全な不変条件です。 

### 完全不変式と不完全不変式

 不変条件は、同型写像までオブジェクトを完全に分類する場合に完全です。 

次元は、固定フィールド上の有限次元ベクトル空間に対する完全な不変式です。 

グループの順序は、有限グループにとって完全な不変条件ではありません。 同じ数の要素を持つ非同型グループが存在する可能性があります。 

| フィールド | 不変 | 完了？ |
 | -------------------------------------- | ---------------------------- | --------- |
 | 有限次元ベクトル空間$k$| 寸法 | はい |
 | 有限集合 | カーディナリティ | はい |
 | 有限群 | 注文 | いいえ |
 | グラフ | 頂点と辺の数 | いいえ |
 | 位相空間 | つながり | いいえ |

 分類問題では、完全な不変式または標準的な代表が求められます。 

### 同型クラス

 個々のオブジェクトを研究する代わりに、私たちはしばしば同型クラスを研究します。 

オブジェクトの同型クラス$A$と同型のすべてのオブジェクトのコレクションです。$A$:$$
[A] = {B : B \cong A}.
$$分類定理はこれらのクラスを説明します。 

たとえば:

 すべての有限次元ベクトル空間$k$次元によって決定される、正確に 1 つの同型クラスに属します。 

つまり、分類は次のようになります。$$
0, 1, 2, 3, \dots
$$どこ$n$に対応する$k^n$。 

### 同型性と輸送

 同型写像により、構造と定理の転送が可能になります。 

もし$f : A \to B$は同型写像であり、その後、$A$～についての対応する事実がある$B$。 

たとえば、次の場合$G \cong H$そして$G$アーベル人であれば、$H$アーベル人です。 

証拠スケッチ:

 しましょう$h_1,h_2 \in H$。 以来$f$全射的です、選択してください$g_1,g_2 \in G$と$$
f(g_1)=h_1,\quad f(g_2)=h_2.
$$それから$$
h_1h_2 = f(g_1)f(g_2)=f(g_1g_2)=f(g_2g_1)=f(g_2)f(g_1)=h_2h_1.
$$それで$H$アーベル人です。 

グループ操作が保存されるため、プロパティは保存されます。 

### 自己同型

 自己同型性は、オブジェクトからそれ自体への同型性です。$$
f : A \to A
$$自己同型は内部対称性を記述します。 

| オブジェクト | 自己同型性 |
 | ----------------- | -------------------------------------- |
 | セット | 順列 |
 | グループ | 構造保存全単射 |
 | ベクトル空間 | 可逆線形マップ |
 | グラフ | エッジを維持した頂点の再ラベル付け |
 | 位相空間 | 空間からそれ自体への準同型性 |

 オブジェクトの自己同型性は、合成の下でグループを形成します。$$
\operatorname{Aut}(A).
$$このグループは、次の対称性を測定します。$A$。 

### 構造的な実践

 構造数学では、通常、ステートメントは同型性の下では不変である必要があります。 オブジェクトが同型コピーに置き換えられたときにプロパティが変化する場合、そのプロパティは構造ではなく表現に依存します。 

たとえば、「の最初の座標」というフレーズは、$v$「ゼロである」は選択した基底に依存します。ベクトルの構造的特性ではありません$v \in V$座標系が固定されていない限り。 

対照的に、次のステートメントは、「$v = 0$」は構造的なものです。 

| 声明 | 構造的な？ |
 | -------------------------------------------------- | ------------------------: |
 |$v = 0$| はい |
 | 最初のコーディネートは、$v$ゼロです | いいえ、根拠が修正されない限り |
 |$T$は単射です | はい |
 | の行列$T$左上のエントリにゼロがあります | いいえ、ベースが固定されていない限り |
 |$\dim V = n$| はい |

 この区別は、表現に依存する引数を防ぐのに役立ちます。 

### 実際のルール

 2 つのオブジェクトが似ているように見える場合は、次のように尋ねてください。 

| 質問 | 目的 |
 | ------------------------------------- | ----------------------------------------------- |
 | どのような構造が保存されているのでしょうか？ | 同型写像の意味を決定する |
 | マップは反転可能ですか？ | 同型射と一般射を区別する |
 | 同型性は標準的ですか? | 隠れた選択肢を検出 |
 | どのような不変条件が保存されますか? | 転送プロパティ |
 | 等価性または同型性を使用していますか? | 誇張を防ぐ |

 同型性は、オブジェクトの表現は異なっていても構造は同一であるという考えを形式化します。 これは、抽象化を正確にするための主要なツールの 1 つです。
