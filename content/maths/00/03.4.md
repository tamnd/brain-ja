## 3.4 精度と可読性

 数学的な記述は、証明をサポートするのに十分な正確さと、理解をサポートするのに十分な読みやすさが必要です。 これらの目標は関連していますが、多くの場合、異なる方向に進みます。 

精度とは、各ステートメントが明確な意味を持つことを意味します。 オブジェクトが宣言され、前提が述べられ、その前提に基づいて結論が導き出されます。 

可読性とは、読者が隠されたコンテキストをあまり再構築せずに議論を理解できることを意味します。 

ステートメントは正確でも判読できない場合があります。$$
\forall \varepsilon > 0,\ \exists \delta > 0,\ \forall x \in X,\ d_X(x,a) < \delta \Rightarrow d_Y(f(x), f(a)) < \varepsilon
$$これは正確ですが、最初に導入したときは解析するのが難しいかもしれません。 読み取り可能なバージョンをその前に置くことができます。 

機能$f$で連続しています$a$ポイントが十分に近い場合$a$に近いポイントに送信されます$f(a)$。 

その後、形式的な条件が続きます。 散文はアイデアを与えます。 公式は意味を固定します。 

| スタイル | 強さ | リスク |
 | -------------- | ----------------- | ------------------- |
 | 完全に象徴的 | 正確かつコンパクト | 読みにくい |
 | 完全に口頭で | 読みやすい | 曖昧かもしれない |
 | 混合 | 明確かつ正確 | 規律が必要 |

 優れた数学的記述は通常、混合スタイルを使用します。 アイデアを散文で紹介し、それを記号で正確に述べてから、それがどのように使用されるかを説明します。 

悪い:

 しましょう$f$優しくしてね。 その後、結果が続きます。 

より良い:

 しましょう$f : X \to Y$継続的であること。 以来$X$コンパクトで、$Y$ハウスドルフ、イメージです$f(X)$コンパクトです$Y$。 

2 番目のバージョンは長くなりますが、定理を有効にする前提が述べられています。 

ステートメントがさまざまなコンテキストの下で真理値を変更する可能性がある場合、精度が最も重要になります。 

| あいまいなフレーズ | 正確な交換 |
 | ------------------------- | -------------------------------------- |
 | 全員にとって$x$| 全員にとって$x \in X$|
 | 関数は制限されています |$f$に制限されています$A$|
 | 数列は収束する |$(a_n)$に収束する$X$|
 | マップは構造を保持します |$f(a \cdot b) = f(a) \cdot f(b)$|
 | オブジェクトは一意です | 指定された等価性までの一意 |

 正式なステートメントで主要なアイデアが隠されている場合、読みやすさが最も重要です。 議論が単純な構造であれば、証明は記号の壁であってはなりません。 

たとえば、単に書くのではなく、次のようにします。$$
\forall x,y \in V,\ \forall \lambda \in k,\ T(x+y)=T(x)+T(y),\ T(\lambda x)=\lambda T(x)
$$次のように書くことができます:

 地図$T : V \to W$線形です: ベクトル加算とスカラー乗算が保存されます。 

その後、必要に応じて方程式を指定できます。 

正確さは、すべての行で最大限の形式性を意味するものであってはなりません。 それは曖昧さを取り除くのに十分な形式的であることを意味します。 

読みやすさとは、曖昧な言語を意味するものであってはなりません。 それは議論の構造が見えることを意味します。 

便利なパターンは次のとおりです。 

| ステップ | 目的 |
 | ---------------------- | -------------------------------------- |
 | 設定を述べます | オブジェクトと仮定を宣言します。 
| 直感を与えてください | このステートメントが true である必要がある理由を説明します。 
| 正式な主張を述べる | 正確な意味を修正 |
 | 明確な手順で証明する | 仮定を結論に結び付ける |
 | 名前の依存関係 | 使用されたものを示します |

 たとえば:

 しましょう$G$グループになってみましょう$H \leq G$。 の剰余類がいつになるかを知りたいのです$H$乗算することができます。 これはまさに次の場合に機能します$H$正常です。 その場合の商は、$G/H$～からグループ構造を継承します$G$。 

この段落はモチベーションを与えるので読みやすいです。 正確なので、$G$、$H$、正常性、そして$G/H$文脈の中で標準的な意味を持ちます。 

精度の主な障害モードは、低レベルの詳細情報でリーダーに過負荷が早すぎることです。 可読性の主な障害モードは、正確さに影響を与える前提を省略していることです。 

バランスの取れたテキストがレイヤーを分離します。 

| レイヤー | 例 |
 | ------------- | -------------------------------------------------------------- |
 | コンセプト | 連続性とは、小さな入力変化が小さな出力変化を与えることを意味します。 
| 定義 | あらゆる人にとって$\varepsilon > 0$、存在します$\delta > 0$|
 | 定理 | 連続関数はコンパクトさを維持します |
 | 証明 | 画像の開いたカバーを使用して、後ろに引きます。 
| 形式化 | 位相空間、マップ、カバー、コンパクト性をエンコードする |

 毎回すべてのレイヤーが必要になるわけではありません。 教科書のセクションでは、それらすべてが必要になる場合があります。 研究論文には定理と証明だけが必要な場合があります。 リファレンス ページでは定義が強調されている場合があります。 

シンボルの密度は読者の課題と一致する必要があります。 計算時には密記法が便利です。 説明中に、密な表記がアイデアを曖昧にする可能性があります。 

比較する：$$
(a+b)^2 = a^2 + 2ab + b^2
$$この式は短くて読みやすい表記です。 

ただし、多くの名前のないコンポーネントを含む長い式は、名前付きの部分に分割する必要があります。 名前を付けると認知的負荷が軽減されます。 

貧しい：$$
\phi(x)=\int_A K(x,y)g(y),dy+\lambda\int_B L(x,z)h(z),dz
$$より良い:

 定義する$$
F(x)=\int_A K(x,y)g(y),dy
$$そして$$
G(x)=\int_B L(x,z)h(z),dz.
$$それから$$
\phi(x)=F(x)+\lambda G(x).
$$2 番目のバージョンは長くなりますが、推論は簡単です。 構造を露呈させます。 

同様の原則が証明にも当てはまります。 同じアイデアが複数回出現する場合、またはサブクレームに独立した値がある場合、長い引数は補題に分解する必要があります。 

| 状況 | より良い構造 |
 | --------------------- | ------------------------- |
 | 繰り返し計算 | 表記法を定義する |
 | 繰り返しの引数 | 補題を抽出する |
 | 多くの仮定 | それらをセットアップにグループ化する |
 | 多くのケース | それぞれのケースに名前を付けます |
 | 長い依存関係チェーン | 中間の主張を述べる |

 精度には、明示的な量指定子の順序も必要です。 量指定子の順序によって意味が変わります。$$
\forall x \in X,\ \exists y \in Y,\ P(x,y)
$$それぞれを意味します$x$独自のものがあるかもしれない$y$。$$
\exists y \in Y,\ \forall x \in X,\ P(x,y)
$$1つを意味します$y$あらゆる用途に適しています$x$。 

これらは異なるステートメントです。 散文ではこの区別を維持する必要があります。 

「各入力には出力がある」が最初のステートメントに相当します。 「すべての入力に対して機能する出力が 1 つある」が 2 番目に相当します。 

数量詞が明確な散文に翻訳されると読みやすさが向上しますが、順序が重要な場合は記号バージョンを利用できるようにする必要があります。 

精度は等価性と等価性にも依存します。 2 つのオブジェクトが「同じ」であると言うのは、多くの場合、あまりにも曖昧です。 テキストには、それが等しい、同型、同型、等価、一致、または正規の識別まで等しいを意味するかどうかを記載する必要があります。 

| フレーズ | より良いフォーム |
 | -------------------------------------- | -------------------------------------- |
 |$A$そして$B$同じです |$A = B$|
 | グループは同じです |$G \cong H$|
 | スペースは同じです |$X$そして$Y$は同相である |
 | 機能はローカルでも同じです。 彼らは近所について同意します。 
| オブジェクトは座標だけが異なります | 基準変更の下では同等です |

 読みやすい文章では、正確な関係が述べられた後、非公式に「同じ」を使用する場合があります。 その前に、ショートカットを回避する必要があります。 

最良のルールはローカルな明示性です。 すべての文で基礎全体を改めて述べるのではなく、曖昧さが生じる箇所で読者が必要としているものを述べます。 

数学的な記述は境界部分が正確で、途中で読みやすくなければなりません。 定義、定理の記述、および最終的な結論には高い精度が必要です。 動機と証明のスケッチでは、主張を変更しない限り、より散文を使用することができます。 

精度は正確さを守ります。 可読性が伝送を保護します。 どちらかが欠けている場合、数学的テキストは失敗します。
