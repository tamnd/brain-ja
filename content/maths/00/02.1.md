## 2.1 真実と証明可能性

 数学的ステートメントには、真である可能性と証明可能であるという 2 つの異なるステータスがあります。 これらの概念は関連していますが、同一ではありません。 

ステートメントが特定の解釈または構造に当てはまる場合、ステートメントは **true** になります。 これは意味論的な概念です。 それは意味によって異なります。 

推論規則を使用して公理から導出できる場合、そのステートメントは **証明可能** です。 これは構文上の概念です。 それはシンボルの形式的な操作に依存します。 

| 概念 | ドメイン | 定義 |
 | ----------- | --------- | --------------------- |
 | 真実 | セマンティクス | 構造内に保持します |
 | 確率 | 構文 | 公理から導出 |

 これを正確にするために、言語と構造を修正します。 

させて`L`形式言語であること。 させて`M`その言語を解釈する構造体である必要があります。 声明の場合`φ`:```text
M ⊨ φ      (φ is true in M)
⊢ φ        (φ is provable in the system)
```これらのシンボルは、意味と派生を区別します。 

基本的な例は算術に由来します。 次のステートメントを考えてみましょう。```text
∀x (x + 0 = x)
```自然数の標準構造では、この記述は真実です。 これは通常の算術公理からも証明可能です。 この場合、真実と証明可能性は一致します。 

この調整は常に維持されるわけではありません。 

すべての証明可能なステートメントがその意図された解釈において真である場合、システムは**健全**です。```text
⊢ φ  ⇒  M ⊨ φ
```健全性により、証明によって虚偽の記述が生じないことが保証されます。 

すべての真のステートメントが証明可能であれば、システムは**完全**です。```text
M ⊨ φ  ⇒  ⊢ φ
```完全性により、証明によってすべての真実にアクセスできることが保証されます。 

これらのプロパティはシステムとドメインによって異なります。 

| システム | サウンド | 完了 |
 | ------------------------- | ----- | -------- |
 | 命題論理 | はい | はい |
 | 一次論理 | はい | はい |
 | 算術 (リッチ システム) | はい | いいえ |

 命題論理および一次論理の場合、完全性は正確な技術的な意味で保持されます。 算術などの十分に表現力豊かなシステムの場合、完全性は失われます。 システム内では証明できない真実の記述が存在します。 

この制限は、クルト ゲーデルに関連する不完全現象などの結果から得られます。 これらの結果は、基本的な算術を表現できる一貫したシステムには、そのシステム内では真であるが証明できないステートメントがあることを示しています。 

真実と証明可能性の間のギャップは、独立性によって説明できます。 

声明`φ`どちらでもない場合はシステムから**独立**します`φ`また、その否定も証明できません。```text
⊬ φ   and   ⊬ ¬φ
```このような場合、システムはステートメントを決定しません。 システムの拡張が異なると、異なる真理値が割り当てられる場合があります。 

例は集合論に現れます。 特定の命題は、標準公理だけでは解決できません。 追加の公理は、さまざまな一貫した理論につながります。 

真実と証明可能性の区別は解釈にも依存します。 ステートメントは、ある構造では true であり、別の構造では false になる場合があります。 

| 声明 | 構造 | ステータス |
 | ------------------ | ------------------- | ------ |
 |`x^2 + 1 = 0`| 実数 | 偽 |
 |`x^2 + 1 = 0`| 複素数 | 本当 |
 | 平行公準 | ユークリッド幾何学 | 本当 |
 | 平行公準 | 双曲幾何学 | 偽 |

 対照的に、証明可能性は、特定の構造ではなく、選択された公理と規則にのみ依存します。 

これにより、2 つの相補的な視点が生まれます。 

| 見る | フォーカス |
 | --------- | ------------------ |
 | セマンティック | 意味とモデル |
 | 構文 | 形式的な導出 |

 証明は構文的に機能します。 ルールに従ってステートメントを変換します。 真実は意味的に評価されます。 ステートメントが構造内で保持されるかどうかをチェックします。 

適切に設計されたシステムでは、これらのビューが可能な限り調整されます。 健全性により、証拠が真実を保持することが保証されます。 完全性により、証拠によって真実に到達できることが保証されます。 完全性が保てない場合は、何が真実で何が証明できるのかを慎重に区別する必要があります。 

実際には、数学者は標準的な解釈の範囲内で作業を行うことがよくあります。 算術の場合、これは自然数です。 分析のために、これは実際の数値です。 このような状況では、たとえ正式なシステムが真実のすべてを捉えることができなかったとしても、真実には意図された意味があります。 

作業ガイドライン:

 | 質問 | 解釈 |
 | ------------------------ | ------------------------- |
 | その陳述は証明可能ですか? | 公理と規則に依存します |
 | その発言は本当ですか？ | 構造による |
 | システムが判断できるのでしょうか？ | 完全性に依存します |

 定理を読むときは、両方の側面を識別すると役立ちます。 定理は通常、証明可能性を主張します。 その重要性は、多くの場合、それが構造について表現する真実にあります。 

数学は両面を磨くことで進歩します。 より多くのステートメントを証明するためのより強力なシステムと、それらを解釈するためのより豊富な構造を開発します。 真実と証明可能性の境界は、形式的推論の限界を示します。
