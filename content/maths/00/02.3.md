## 2.3 一貫性と完全性

 正式なシステムは、部分的には何を証明できるかによって判断され、部分的には何を証明することを避けているかによって判断されます。 2 つの中心的な特性は、一貫性と完全性です。 

一貫性とは、システムが矛盾を証明しないことを意味します。 ステートメントがなければシステムは一貫しています`P`両方とも`P`そして`¬P`証明可能です。```text
not both:  ⊢ P  and  ⊢ ¬P
```矛盾は差別を破壊するため、一貫性のないシステムは通常の数学には使用できません。 古典論理では、矛盾からあらゆる命題を導き出すことができます。 この原理を爆発といいます。```text
P, ¬P ⊢ Q
```システムが矛盾を証明すれば、すべてのステートメントが証明可能になります。 偽の算術、偽の幾何学、そして恣意的な主張がすべて続きます。 Proof では、有効なステートメントと無効なステートメントが区別されなくなりました。 

完全性にはいくつかの意味があり、その区別が重要です。 

論理的に有効なすべてのステートメントが証明可能であれば、証明システムは意味的に完全です。```text
If every model satisfies φ, then ⊢ φ.
```この意味で一階論理は完成します。 あらゆる解釈のもとであらゆる構造に​​おいて一次文が真である場合、その正式な証明が存在します。 

すべての文について理論が構文的に完全である場合`φ`その言語で、`φ`または`¬φ`証明可能です。```text
For every φ:  ⊢ φ  or  ⊢ ¬φ
```これは、理論がその言語で表現可能なすべてのステートメントを決定することを意味します。 

完全性のこれら 2 つの用法を混同しないでください。 

| プロパティ | 適用対象 | 意味 |
 | ---------------------- | ------------------ | -------------------------------------- |
 | 意味上の完全性 | 証明システム | 論理的に有効な式はすべて証明可能です。 
| 構文の完全性 | 理論 | すべての文章が決まります |
 | 一貫性 | システムまたは理論 | 矛盾は証明できない |

 理論には一貫性があっても不完全な場合があります。 これは一般的です。 これは、理論が矛盾を回避しているものの、まだ決定されていないステートメントがいくつか残っていることを意味します。 

算術が中心的な例を示します。 十分に表現力があり、効果的に公理化され、一貫した算術理論がすべての算術ステートメントを決定することはできません。 一部のステートメントは理論から独立しています。```text
T ⊬ φ
T ⊬ ¬φ
```声明`φ`では決定不可能です`T`。 

これは意味がありません`φ`意味がありません。 それは、選択された公理ではそれを解決するには不十分であることを意味します。 より強力な公理がそれを決定する可能性があります。 

通常、一貫性は最低要件です。 完全性はより強力であり、入手できないことがよくあります。 

| システム | 一貫性のある？ | 完了？ |
 | ------------------- | ------------------------ | ------------------------ |
 | 命題論理 | はい、標準ルールを使用します。 意味的に完全 |
 | 一次論理 | はい、標準ルールを使用します。 意味的に完全 |
 | ペアノ算術 | 期待される一貫性 | 構文的に不完全 |
 | ZFC 集合理論 | 期待される一貫性 | 構文的に不完全 |

 強力な理論の場合、通常、同じ理論の内部から一貫性を証明することはできません。 十分に強力な一貫した理論は、それが必要な形式的な方法で表現されていると仮定すると、それ自体の一貫性を証明することはできません。 これは、形式化の主要な制限の 1 つです。 

一貫性を証明するために、より強力なメタ理論に取り組むことがよくあります。 たとえば、理論にはモデルがあることを示すことができます。 モデルが存在する場合、そのモデルではすべての公理が真であり、有効な推論ルールが真実を保持するため、理論は一貫しています。```text
Model exists  ⇒  theory is consistent
```これは一貫性とセマンティクスを結びつけます。 

完全性は証明と決定を結びつけます。 完全な理論では、その言語のすべての文に対して答えが得られます。 不完全な理論はギャップを残します。 これらのギャップは必ずしも欠陥ではありません。 これらは、その言語が、答えを得るために追加の原則を必要とする質問を表現するのに十分な豊かさを持っていることを示しているのかもしれません。 

幾何学は有用な例を提供します。 ユークリッド幾何学には平行公準が含まれます。 その公準が削除されると、ユークリッド幾何学と非ユークリッド幾何学の両方が可能になります。 残りの公理は平行公準を決定しません。 

| 公理システム | 平行公準ステータス |
 | ------------------- | ----------------------------- |
 | ユークリッド幾何学 | 真と仮定 |
 | 双曲幾何学 | 別の公理に置き換えられる |
 | ニュートラルジオメトリ | 独立 |

 独立性は、複数の一貫した拡張が存在できることを示しています。```text
T + φ      consistent
T + ¬φ     consistent
```両方の拡張が一貫している場合、元の理論はステートメントを決定しません。 

完全性はカテゴリ性にも関連します。 すべてのモデルが同型写像に至るまで本質的に同じである場合、理論はカテゴリカルです。 理論に多くの非同型モデルがある場合、その公理は 1 つの構造を一意に分離しません。 

これは算術と集合論において重要です。 一次理論には非標準的なモデルが含まれることがよくあります。 たとえ意図したモデルが非公式的に明確であっても、形式的な公理は他のモデルを許容する可能性があります。 

実際の読書戦略は次のとおりです。 

| 質問 | 何を確認するか |
 | -------------------------------------------------- | ---------------------- |
 | システムは矛盾を証明できるでしょうか? | 一貫性 |
 | 証明システムはすべての有効な推論を捕捉しますか? | 意味上の完全性 |
 | 理論はすべての文を決定しますか? | 構文の完全性 |
 | モデルは複数ありますか? | カテゴリ |
 | 発言は未定ですか？ | 独立 |

 数学的基礎により、強度と安全性のバランスが保たれます。 より強力な公理はより多くの定理を証明しますが、より大きな一貫性の仮定を保持する可能性があります。 公理が弱いほど安全ですが、決定する質問は少なくなります。 

一貫性は推論を崩壊から守ります。 完全性は、システムがどの程度決定できるかを測定します。 両者間の緊張関係は、形式数学がなぜ力と限界の両方を持っているかを説明しています。
