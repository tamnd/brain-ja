## 2.5 フィールドにわたる例

 真実、証明可能性、独立性の区別は、数学的論理に限定されません。 これは、ステートメントが公理、解釈、または選択された構造に依存する場合は常に、数学全体に現れます。 

算術では、通常、対象となる構造は自然数です。```text
N = {0, 1, 2, 3, ...}
```標準自然数に関しては正しいかもしれないが、選択された形式系では証明できないステートメントもあるかもしれません。 これが不完全さの中心的な教訓です。 算術は基本的な事実を述べるのに十分単純ですが、証明、プログラム、自己言及を符号化するのに十分な表現力があります。 

幾何学では、真実は空間の公理に依存します。 ユークリッド幾何学、球面幾何学、双曲幾何学では異なる仮定が使用されます。 平行線に関するステートメントは、あるジオメトリでは成立しても、別のジオメトリでは成立しない可能性があります。 

| フィールド | 声明 | によって異なります |
 | ---------- | ----------------------------------- | ------------------------ |
 | 算数 | 一部の真実の記述は証明不可能です。 正式なシステム |
 | ジオメトリ | 平行線の動作 | 幾何学公理 |
 | 集合論 | 連続体仮説 | 集合論の公理 |
 | 代数 | 拠点の存在 | 選択の原則 |
 | 分析 | 病理学的機能 | 集合論の仮定 |
 | トポロジ | コンパクト性定理 | 選択公理とカバー公理 |

 集合論は、最も直接的な例をいくつか提供します。 ZFC が一貫していると仮定すると、連続体仮説は ZFC から独立しています。 これは、集合論の通常の公理では、自然数と実数の間に厳密に基数が存在するかどうかを決定しないことを意味します。 

代数では基本的な前提が隠されていることがよくあります。 「すべてのベクトル空間には基底がある」という表現は古典数学では標準的ですが、それは完全に一般的に選択する公理に依存します。 有限次元ベクトル空間の場合、そのような問題は発生しません。 基礎は有限の手順で構築できます。 

分析には、証明に非建設的な原理を使用する多くの存在定理が含まれています。 一部の定理は、計算可能な構造を与えずにオブジェクトが存在すると主張します。 これは古典的な分析では許容されますが、建設的分析や計算可能な分析では解釈が変わります。 

トポロジでは、もう 1 つの一般的なパターンが得られます。 コンパクト性ステートメントは、多くの場合、無限データを有限データに変換します。 建設的な形式もあれば、選択のような原則を必要とする形式もあります。 正確なステータスは、スペースとカバーの概念によって異なります。 

実際的なルールは、定理を解釈する前にフレームワークを特定することです。 

| 質問 | なぜそれが重要なのか |
 | ----------------------------------------------- | ------------------------------------------ |
 | 公理とは何ですか? | 何を証明できるかを決定する |
 | 対象モデルは何ですか? | 意味上の真実を決定する |
 | 証拠は建設的ですか? | 証人がいるかどうかを判断します |
 | 選択原則が使用されていますか? | 基礎強度を決定します |
 | ステートメントは等価性の下で不変ですか? | 構造的な意味を決定する |

 分野を超えて、同じ教訓が繰り返されます。 定理は決して単なる文章ではありません。 それは言語、構造、証明システムに属します。 

これらが明示的であれば、数学的ステートメントは移植可能になります。 非表示にすると、同じ文でもフィールドによって意味が変わる可能性があります。
