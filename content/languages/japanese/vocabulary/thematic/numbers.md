日本語の数字は単純ですが、カウンター システム (オブジェクトのカテゴリーごとに異なる数え言葉) は、この言語特有の課題の 1 つです。

 ## カウンターシステム

 日本語では、オブジェクトのカテゴリーごとに異なる「カウンター」 (助数詞、josushi) を使用します。 数字の後に、適切なカウンターを付けます。 

### 〜本 (hon) — 長い円筒形の物体

 | 日本語 | ローマ字 | |の場合
 |----------|----------|-----|
 | 一本 | 一本 | 鉛筆、ペン、ボトル、木、道路、映画 (フィルム) |
 | 二本 | 日本 | |
 | 三本 | サンボン | |
 | 四本 | よんほん | |
 | 五本 | ゴホン | |

 例: ペン一本 (1 本のペン)、ビール二本 (2 本のビール)、木三本 (3 本の木)

 ### 〜枚 (mai) — 平らなオブジェクト

 | 日本語 | ローマ字 | |の場合
 |----------|----------|-----|
 | 一枚 | いちまい | 紙、チケット、切手、皿、薄いもの |
 | 2枚 | ニマイ | |
 | 3枚 | さんまい | |

 例：切手一枚（切手1枚）、紙二枚（紙2枚）、Tシャツ三枚（Tシャツ3枚）

 ### 〜冊 (サツ) — 製本された本

 | 日本語 | ローマ字 | |の場合

 | 三冊 | サンサツ | |

 一番は副詞として「最高/最も」という意味もあります: 一番好き = 最も好き

 ## タイムカウンター

 | 単位 | カウンター | 例 |
 |------|--------|----------|
 | 分 | 〜分 (楽しい/ダジャレ) | 一分（いっぷん）、三分（さんぷん）、五分（胡粉） |
 | 営業時間 | 〜時間（じかん） | 一時間（いちじかん）、二時間（にじかん） |
 | 日々 | 〜日（にち/か） | 一日（いちにち/ついたち）、二日（ふつか）、三日（みっか） |
 | 週間 | 〜週間（週刊） | 一週間 (isshuukan)、二週間 (nishuukan) |
 | 月 | 〜月（花月） | 一ヶ月（いっかげつ）、二ヶ月（にかげつ） |
 | 年 | 〜年 (ねん) | 一年（イチネン）、二年（ニネン） |
