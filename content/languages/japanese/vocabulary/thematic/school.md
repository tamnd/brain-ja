 ## 対話の練習

 **A:** 卒業論文の進捗はどうですか？ 
(そつぎょうろんぶんのしんちょくはどうですか? / そつぎょうろんぶんのしんちょくはどうですか?)
 卒業論文の進捗はいかがですか？ 

**B:**とりあえず引用文献の整理が終わったところで、考察が考えます。 
(まだいんようぶんけんのせいが終わったところで、こうさつがふじゅうぶんです。 / まだいんようぶんけんのせいりが終わったところで、こうさつがふじゅうぶんです。)

**A:** 指導教官にはもう相談しましたか？

## 独学のヒント

 1. **文脈の読み方:** 日本の大学のシラバスや学部の Web サイト (東京大学や京都大学の Web サイトなど) を読んで、これらの用語が自然で正式な管理上の文脈で使用されているかどうかを確認してください。 
2. **テーマ別のグループ化:** これらの単語を「管理」(履修、単位、事務局) と「学術」(論文、考察、引用) にグループ化します。 これは言語のレジスターを理解するのに役立ちます。 
3. **積極的な使い方:** N1 レベルの学術動詞を少なくとも 5 つ使って、読んだ本や記事を要約してみてください (例: 考察する、引用する、覚悟)。 
4. **フラッシュカード アソシエーション:** Anki を使用して、漢字と単なる英語訳ではなく日本語での正式な定義を組み合わせたカードを作成し、より深い認知的リンクを構築します。
