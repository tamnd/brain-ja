## 〜と

 | プロパティ | 値 |
 |----------|----------|
 | パターン | 〜と |
 | JLPTレベル | N4 |
 | タイプ | 条件付き |
 | フォーマル | ニュートラル |
 | 登録 | 両方 |

 ## 意味

 の`〜と`条件付きは、自然、必然、または機械的な結果を表します。 「Xが起こると必ずYが続く」または「Xが起こると直接の結果としてYが起こる」と言うのに使われます。 

## 構造式```
[Verb dictionary form] + と
[い-adj (dictionary form)] + と
[な-adj (stem)] + だ + と
[Noun] + だ + と
```* **動詞:** 辞書形式 (過去以外) を使用します。 
* **形容詞/名詞:** 平文を使用してください (例:`静かだ`(静だ) +`と`）。 
* **制限:** 2 番目の句 (結果) には、自発的な表現、要求、命令、または招待を **含めることはできません** (例:`〜てください`、`〜ましょう`、`〜たい`）。 

## 詳細な説明

 の`〜と`条件付きは、「自然な結果」条件付きと呼ばれることがよくあります。 結果が予測可能、客観的、または事実である状況を指します。 自動的な結果を暗示するため、科学的事実、指示、または機械の使用方法の説明によく使用されます。 

このパターンは非常に客観的です。 とは異なり`〜ば`または`〜たら`、個人的な意図や仮説的なシナリオを表現できます。`〜と`「if/when」の関係に焦点を当てます。 ボタンを押すとライトが点灯します。 左に曲がれば、公園はそこにあります。 これらは会話の文脈における普遍的な真実です。 

なぜなら`〜と`は避けられない結果を暗示しているため、何かをしたいという自分の願望を表現したり、他の人に何かを依頼したりするために使用することはできません。 たとえば、「雨が降ったら、家に帰りましょう」ということはできません。`〜と`「行きましょう」は提案だからです。

## 類似パターンとの比較

 ### 〜と vs 〜ば vs 〜たら

 | パターン | ニュアンス | フォーカス |
 |----------|----------|----------|
 | **〜と** | 必然/自然な結果 | 事実/機械 |
 | **〜ば** | 仮説/条件 | 要件 |
 | **〜たら** | シーケンス/X が起こった後 | 個人/特定 |

 * **〜と:** 「X を行うと、必ず Y が起こります。」 （目的）
 * **〜ば:** 「X が起こったら Y (Y の条件)」。 (仮説)
 * **〜たら:** 「X が起こったら、次に Y。」 (最初のアクションを完了することに集中してください)

 ## よくある間違い

 ❌ **雨が降ったら、傘を買いましょう。** → ✓ **雨が降ったら、傘を買いましょう。**
 *説明:*`〜と`提案を続けることはできません (`〜ましょう`）。 使用`〜たら`提案のために。 

❌ **明日、時間があると、映画が見たいです。** → ✓ **明日、時間があれば、映画が見たいです。**
 *説明:*`〜と`それは個人的な願望や将来の意図ではなく、普遍的な事実のためです。`〜ば`仮定の個人的な計画に適しています。 

❌ **ボタンを押すと、押してください。** → ✓ **ボタンを押すと、電気がつきます。**
 *説明:* は使用できません。`〜と`条件をリクエストにリンクします。 

## 練習問題

 **空白を埋めてください** (〜とまたは正しい形式を使用してください):

 1. この道をまっすぐ（行く）＿＿＿、駅があります。 
2. 寒く（なる）＿＿＿、ストーブをつけます。 
3. 毎日練習する（だ）＿＿＿、上手になります。 
4. 授業に（決意）＿＿＿、先生に怒られます。 
5. 信号が赤（だ）＿＿＿、中断してください。 (待ってください! これは正しいですか? なぜですか?)

 **回答キー:**
 1. **行くと** (まっすぐ歩くことの当然の結果)。 
2. **になります** (気温低下の自然な結果)。 
3. **と** (お待ちください:`練習すると`正しいです。`練習するだ`は間違っています。 訂正: **練習すると**)。 
4. **遅れと** (遅刻の当然の結果)。 
5. **赤です、言ってください**は**不正確**です。 なぜなら`〜と`コマンド/リクエストを続けることはできません。使用してください。`赤なら、止まってください`または`赤の時は、止まってください`。 

## JLPTレベルノート

 JLPT N4では、`〜と`文章の「並べ替え」や文法セクションの「穴埋め」で頻繁にテストされます。 2 番目の句に要求または意志動詞が含まれる罠に注意してください (`〜たい`、`〜ましょう`、`〜てください`）。 文の後半にこれらの項目が表示された場合は、**選択しないでください**`〜と`。
