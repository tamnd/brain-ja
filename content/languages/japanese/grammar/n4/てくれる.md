## 〜てくれる

 | プロパティ | 値 |
 |----------|----------|
 | パターン | 〜てくれる |
 | JLPTレベル | N4 |
 | タイプ | 受信 |
 | フォーマル | 中立 (〜してますと活用すると丁寧) |
 | 登録 | 両方 (話し言葉と書き言葉) |

 ## 意味

 **〜てくれる** というパターンは、誰かが話者、または話者の「内グループ」（家族、親しい友人、同僚）の誰かに好意を寄せることを表します。 話し手の感謝の気持ちや恩恵を受けたという事実を強調します。 

## 構造式```
[Verb て-form] + くれる
```* **活用:** 動詞を *て形 * (例: 読んで → 読んで、食べて → 食べて) に「くれる」を付けます。 
* **丁寧さ:** 丁寧にするには、*ます形式*: **〜くれます** (てくれます) を使用します。 
* **過去/否定:** 「くれる」を活用できます（例：〜してくれた、〜してくれない）。 

## 詳細な説明

 1. **主な意味:** このパターンは、誰かが話し手または話し手に近い人に利益をもたらす行動を実行するときに使用されます。 それは、その行動が親切心や好意から行われたことを暗示しています。 
2. **「グループ内」の視点:** 日本文化では、「グループ内」(ウチ) と「グループ外」(ソト) が区別されます。 **〜てくれる**は、好意が話者またはそのグループに向けて*内側に*流れる場合に使用されます。 
3. **ニュアンス:** 単に行動を述べるのとは異なり (例: 「彼は私のコンピューターを直してくれた」)、**〜てくれる** を使用すると、感謝の気持ちが加わります。 相手の努力を認めます。 
4. **形式:** **〜てくれる**は中立ですが、目上の人に対して使用すると少しぶっきらぼうに聞こえる可能性があります。 正式な場面では、謙虚/丁寧なバージョンを使用する必要があります: **〜て協力してください** (te-kudasaru) または **〜てくださいました** (te-kudasaimamata)。 
5. **比較:** これは、**〜てあげる** (誰かのために好意を示す) と **〜てもらう** (好意を受け取る、してもらうという行為に焦点を当てる) に相当します。

 ## 類似パターンとの比較

 ### 〜てくれる vs 〜てもらう

 * **〜てくれる**は**贈り主**に焦点を当てています（贈り主は私のために何かをしてくれました）。 
* **〜てもらう**は**受け手**（誰かに何かをしてもらった）に焦点を当てています。 

| パターン | フォーカス | 例 |
 |----------|----------|----------|
 | 〜てくれる | 贈り主 | 友達が直してくれました (友達が直してくれました) |
 | 〜てもらう | 受信機 | 友達に直してもらった (友達に直してもらいました) |

 ## よくある間違い

 1. **目上の人に対して「〜てくれる」を使う:**
 ❌ 先生が教えてくれた → ✓ 先生が教えてくれた
 ※解説：「〜てくれる」は目上の人にとってはカジュアルすぎる。 敬称は「〜て協力者」を使用してください。 
2. **他の人に何かをしてあげるときに「〜てくれる」を使う:**
 ❌ 私が彼にプレゼントを買ってくれた → ✓ 私が彼にプレゼントを買ってくれた
 ※説明：〜てくれるは好意を寄せられた場合のみです。 あなたが好意を寄せるときは、〜てあげるを使用してください。*
 3. **件名を混乱させています:**
 ❌ 私は彼に仕事を引き受けてくれた → ✓ 彼は私に仕事を引き受けてくれた
 *説明: 好意を寄せている人が主語 (「が/は」でマーク) でなければなりません。*

 ## 練習問題

 **空白を埋めてください:**

 1. 妹が私のためにケーキを＿＿＿＿＿＿。(妹が私のためにケーキを焼いてくれました。)
 2. 誰がこの重い荷物を持って＿＿＿＿＿＿か。(この重い荷物を私に代わって運んでくれるのは誰ですか?)
 3. 友達が道（みち）を＿＿＿＿＿＿。(友達が道を教えてくれました。)
 4. 先生が難しい漢字を＿＿＿＿＿＿。(先生は私に難しい漢字を説明してくれました。)

 **回答キー:**
 1. 作ってくれた
 2. くれます - *丁寧なお願い*
 3. 教えてくれた (教えてくれた)
 4. 説明してくれました(せつめいしてくれました)

 ## JLPTレベルノート

JLPT N4 では、このパターンは「並べ替え」問題や「穴埋め」文法セクションでよく出てきます。 覚えておいてください: **文が話し手から受け取った好意を暗示している場合は、「くれる」を探してください。** 常に主語の助詞 (が/は) をチェックして、アクションを実行している人が好意を与えている人であることを確認します。
