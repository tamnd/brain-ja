## 〜はずだ

 | プロパティ | 値 |
 |----------|----------|
 | パターン | 〜はずだ |
 | JLPTレベル | N4 |
 | タイプ | 期待 |
 | フォーマル | ニュートラル |
 | 登録 | 両方 |

 ## 意味

 **〜はずだ**（はずだ）というパターンは、理由や証拠に基づいた強い期待や論理的結論を表します。 これは「すべきである」、「するべきである」、または「それが期待されている」と訳されます。 これは、話者が自分が持っている情報から何かが真実である、または起こるだろうと確信している場合に使用されます。 

## 構造式```
[Verb dictionary form] + はずだ
[Verb た-form] + はずだ
[い-adj] + はずだ
[な-adj] + な + はずだ
[Noun] + の + はずだ
```* **動詞:** 現在/未来の期待には辞書形式を使用し、過去の期待には過去 (た) 形式を使用します。 
* **い形容詞:** 形容詞に直接付けます。 
* **な形容詞:** はずだの前に **な** (na) が続く必要があります。 
* **名詞:** はずだの前に **の** (いいえ) が続く必要があります。 

## 詳細な説明

 **〜はずだ**は、自分の信念に論理的な根拠がある場合に使用されます。 単純な推測とは異なり、このパターンは、何かが当てはまると考える理由があることを意味します。 たとえば、電車が 8:00 に予定されていることがわかっている場合は、「8 時に来るはずだ」 (8:00 に到着するはずです) と言います。 

そのニュアンスは「論理的確実性」の一つです。 自分の予想が間違っていたことに驚いた場合は、過去形**〜はずだった**（はずだった）を使用できます。「[そうなる/起こるだろう]と予想していましたが...」という意味です。 

このパターンは形式的には中立です。 丁寧語では**～はずです**（はずです）を使います。 カジュアルなスピーチでは、語尾の**だ** (da) を省略できますが、これを残すと信念が強調されます。 

**〜はずだ**は通常、客観的な期待に対して使用されることに注意することが重要です。 自分自身の内面や主観的な欲求について話す場合は、「*〜つもりだ*」のような他のパターンの方が適切です。

 ## 類似パターンとの比較

 ### 〜はずだ vs 〜にちがいない

 | パターン | ニュアンス |
 |----------|----------|
 | **〜はずだ** | 証拠に基づいた論理的な期待。 |
 | **〜にちがいない** | 強い主観的な確信/確信。 |

 * **〜はずだ:** 「予定によれば、お店は開いているはずです。」 (論理的)
 * **〜にちがいない:** 「彼は汗をかいています。緊張しているに違いありません。」 (個人的な強い結論)

 ### 〜はずだ vs 〜つもりだ (tsumori da)

 ※**～はずだ**は世界や他人に対する客観的な期待を表します。 
* **〜つもりだ**は、あなた自身の意図、またはあなた自身の行動についての主観的な信念です。 
* *例:* 「行くはずだ」 (彼は行く予定だ) と 「行くつもりだ」 (私は行くつもりだ)。 

## よくある間違い

 ❌ 彼は学生のはずだ。 → ✓ 彼は**学生のはずだ**。 
* *訂正:* 名詞は「はず」の前に「**の**」で接続する必要があります。 

❌ 彼は忙しいはずだ。 → ✓ 彼は**忙しいはずだ**。 
* *訂正:* い形容詞は「はず」の前に「な」を付けません。 

❌ 私は明日行くはずだ。 → ✓ 私は明日**行くつもりだ**。 
* *訂正:* (外部の期待を意味する) *はず* ではなく、*tsumori* を自分自身の意図のために使用してください。 

## 練習問題

 **空白を埋めてください:**

 1. 彼は今日（来る）______。 
2. この店は（有名）_______はずです。 
3. 昨日は（雨）______はずだったのに、晴れていた。 
4. 彼は（先生）______はずだ。 
5. この料理は（おいしい）______はずだ。 

**回答キー:**
 1. **来るはずだ** (予定に基づく予想)
 2. **有名な** (な-adj には 'na' が必要です)
 3. **雨だった** (過去形の期待)
 4. **先生の** (名詞には「いいえ」が必要です)
 5. **おいしい** (i-adj が直接接続します)

 ## JLPTレベルノート

 JLPT N4 では、読解や文章の順序付けのタスクでよくこれが見られます。 「スケジュール」、「いつも」、「聞いた話ですが…」など、期待の「証拠」となるキーワードを探してください。 「私は...するつもりです」で始まる文を見つけた場合は、*はず*を選択しないでください。
