## プロパティ

 | プロパティ | 値 |
 |----------|----------|
 | レベル | JLPT N5 |
 | タイプ | 粒子 |
 | 置き換え | は、が、を (に、で、へ、と、から、までに続く) |

 ---

 ## 意味

 にも 3 つの主な用途があります。 

### 1. また/あまりにも

 「は」、「が」、または「を」を置き換えて、同じステートメントが追加の項目に適用されることを示します。 

**構造：**```
[Noun] も + [Predicate]
```> 私は行く → 私**も**行く
 > 私は行きます → 私も**行きます**

 ---

 ### 2. X と Y の両方 / X でも Y でもない

 AもBもパターンで使用され、ステートメントがAとBの両方に適用されることを表します。 

**構造 (ポジティブ):**```
[Noun A] も [Noun B] も + [Affirmative Predicate]
→ Both A and B ...
```**構造 (ネガティブ):**```
[Noun A] も [Noun B] も + [Negative Predicate]
→ Neither A nor B ...
```---

 ### 3. 大量の強調

 驚きや強調を表す数量語に付けられます（「同じくらい」、「同じくらい」）。 

**構造：**```
[Quantity / Number] も + [Predicate]
```---

 ## 例

 1. 田中さんは学生です。山田さん**も**学生です。 
※田中さんは学生です。 山田さんは****学生です*。 

2. 私は英語**も**日本語**も**話せます。 
*私は**英語**と**日本語**の両方を話すことができます*。 

3. 彼はコーヒー**も** お茶**も** 飲みません。 
*彼はコーヒー**も**紅茶も**飲みません**。 

4. パーティーに100人**も**来た。 
***100人もの人がパーティーに来ました。*

 5. 駅に**も**バス停に**も**人がいません。 
***駅**にも**バス停*にも誰もいません。

 ## 注: 置き換えるものと従うもの

 | 元の粒子 | とも |
 |---------------------|----------|
 | は | →も（置き換える） |
 | が | →も（置き換える） |
 | を | →も（置き換える） |
 | に | →にも（続く） |
 | で | →それでも（続く） |
 | へ | →へも（フォロー） |
 | と | →とも（フォロー） |
 | から | →からも (フォロー) |
 | まで | → ずっと (続く) |

 ## よくある間違い

 - **「は」も**を続ける — ～～私はも行く～～とは言わないでください。 ドロップは完全に：私も行く。 
- **たとえでも**と混同 — それでも (demo) は、それ自体で「でも」または「さえ」を意味します。 コンテキストが重要です。 
- **強調の誤り** — 量の後にある場合も、話者がその量が（多いか少ないか）驚くべきであると感じていることを意味します。 通常の数値と一緒に使用すると、不自然に聞こえる可能性があります。 
- **AもBも**の語順 — どちらの名詞も「も」を付け、述語の前に出現する必要があります。 文節をまたがって分割することはできません。
