 ## 意味

 〜しているには動詞の種類によって主に2つの解釈があります。 

### 1. 継続的なアクション (漸進的)

 アクション動詞と一緒に使用して、アクションが現在進行中であることを表現します。英語の「-ing」に相当します。 

- 食べている — 食べています（食べるという行為はまだ起こっています）
 - 進行中 — 実行中

 ### 2. 結果の状態

 状態の変化を表す動詞と一緒に使用されます。 動作はすでに完了しており、その結果生じる状態を表します。 

- 結婚している — 結婚しています（結婚した結果）
 - 知っている — 知っている (学んだ/知るようになった結果)
 - 死んでいる — 死んでいる (死んだ結果)

 ## 手形形成リマインダー (グループ 1 動詞)

 | 動詞語尾 | て形変化 | 例 |
 |---------------|----------------|----------|
 | う、つ、る | →って | 買う → 買って |
 | む、ぶ、ぬ | →で | 飲む → 飲むで |
 | く | →いて | 書く → 書いて |
 | ぐ | → いで | ぐ → 泳いで |
 | す | →して | 話す→話すして |

 グループ 2 動詞: 落とす、追加して (食べる → 食べて)。 
不規則：する→して、くる→きて。

 ## 結果の状態の意味のみを使用する動詞

 一部の動詞は進行中のアクションではなく 1 回限りの変更を表すため、「している」は常に結果の状態を指し、進行中のプロセスを指すことはありません。 

| 動詞 | している意味 |
 |------|---------------|
 | 知る（知る） | 知っている — 知っている |
 | 結婚する | 結婚している — 結婚しています |
 | 死ぬ（死ぬ） | 死んでいる — 死んでいる |
 | 着る（服を着る） 着ている — 着ています |
 | 住む（定住する/引っ越しする） | 生きている — 住んでいる (場所に) |

 ---

 ## カジュアル収縮: いる → てる

 カジュアルな会話では、「I」が省略されることがよくあります。 

- 食べている → 食べている
 - 知っている → 知っている
 - 何してる？ — 何をしてるの？ 

この縮約は日常会話では非常に一般的ですが、正式な文書やスピーチでは避けるべきです。 

---

 ## よくある間違い

 - **て形式の代わりに普通形式を使用する:** ✗ 食べている → ✓ 食べている
 - **結果の状態を過去形と混同する:** 結婚しているというのは「結婚した」という意味ではなく、「（現在）結婚している」という意味です。 完了したイベントには「結婚した」を使用します。 
- **書き言葉の「い」を忘れる:** カジュアルな会話では「てる」は問題ありませんが、フォーマルな文脈では常に「いる / います」と書きます。 
- **状態変化動詞に進行的な意味を適用する:** 知っているは「知るようになる」という意味ではなく、単に「知っている」という意味です。
