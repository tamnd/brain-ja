## プロパティ

 | プロパティ | 値 |
 |----------|----------|
 | JLPTレベル | N5 |
 | タイプ | 粒子 |
 | 発音 | o (ローマ字: wo) |
 | 機能 | 直接オブジェクトマーカー。 ルート/パスマーカー |
 | フォーマル | すべてのレベル |

 ## 意味

 **を**は他動詞の**直接目的語**、つまり動作を受けるものをマークします。 「何？」という質問に答えます。 または「誰？」 動詞の場合。 

また、移動動詞 (例: 歩く、走る、渡す、飛ぶ) と一緒に使用すると、動作が発生する **ルートまたはパス** をマークします。 

＃＃ 構造```
[Object] + を + [Transitive Verb]
[Route/Path] + を + [Motion Verb]
```## 例

 | 日本語 | 読書 | 英語 |
 |----------|-----------|----------|
 | 水を飲みます。 みずをのむ。 私は水を飲みます。 |
 | これを読みます。 ほんとをよみます。 本を読みました。 |
 | 音楽を聞いています。 おんがくをきいています。 私は音楽を聴いています。 |
 | 公園を散歩する。 えんこうをさんぽする。 私は公園を散歩します。 |
 | 橋を渡ってください。 はしをわたってください。 橋を渡ってください。 |

 ## 注意事項

 ### 発音

 「を」はひらがな「**を**」で書きますが、現代日本語では**常に「お」**と発音され、母音「お」と同じです。 ローマ字表記の「wo」は、助詞と母音文字を区別するためにのみ使用されます。 

### 他動詞のみ

 「を」は、**他動詞**、つまり直接目的語をとる動詞 (食べる、見る、書くなど) でのみ使用されます。 自動詞 (例: 起きる、来る、笑う) は「を」を使用しません。 

### ルートの使用状況

 動作動詞と組み合わせると、「を」は目的地ではなく、**通過したルートまたは空間**を示します。 比較してください:

 | 文 | 粒子 | 意味 |
 |----------|----------|----------|
 | 駅に行く。 に | 駅（目的地）に**行き** |
 | 道を歩く。 を | 道路 (ルート) に沿って**歩く |

 ## よくある間違い

 | 間違い | 訂正 | 説明 |
 |----------|-----------|---------------|
 | ✗学校に行くのが好きです。 ✓学校に行くのが好きです。 動詞節の後に「を」を使用することはできません。 代わりに「のが」を使用してください。 |
 | ✗ 水が飲みます。 ✓水を飲みます。 「が」は他動詞の直接目的語ではなく主語を示します。 |
 | ✗ 公園に散歩する。 ✓ 公園を散歩する。 ルート/パスのトラバーサルでは、「に」ではなく「を」を使用します。 |
