## 〜は

 | プロパティ | 値 |
 |----------|----------|
 | パターン | 〜は |
 | JLPTレベル | N5 |
 | タイプ | パーティクル / トピックマーカー |
 | フォーマル | ニュートラル |
 | 登録 | 両方 |

 ## 意味

 文の**トピック**をマークします。 トピックには、文法的な主題や、話者がコメントしたいその他の要素を指定できます。 「は」の後のすべては、そのトピックについて何かを述べています。 

## 構造式```
[Topic] + は + [Comment / Predicate]
```## 使用上の注意

 - 「は」はひらがなの「は」で書きますが、助詞として使用する場合は**「は」と発音します(「は」ではありません)。 
- トピックが舞台を設定します。 文の残りの部分はそれについてコメントしています。 
- 紹介と説明の **X は Y です** (「X は Y」) パターンで最も一般的に見られます。 
- トピックは文法的な主題である必要はありません。それは単にその文が「何について」いるかです。 

## 例

 | 日本語 | ローマ字 | 英語 |
 |----------|----------|----------|
 | わたしはがくせいです。 私は学生です。 | 私は学生です。 |
 | これは本当です。 これは本です。 | これは本です。 |
 | やまださんはにほんじんです。 山田さんは日本人です。 | 山田さんは日本人です。 |
 | きょうはげつようびです。 今日は月曜です。 | 今日は月曜日です。 |
 | このレストランはおいしいです。 このレストランはおいしいです。 | このレストランはおいしいです。 |

 ## は対が

 - **は (トピック)** は文の内容を発表します。 **が (件名)** は、誰/何がアクションを実行するか、または説明に適合するかを示します。 
- 新しい情報を紹介するとき、または主題そのものに焦点を当てているときに「が」を使用します。「だれがきましたか → たなかさんがきました。」
 - 「は」は、しばしばコントラストや背景の文脈を暗示します: わたし**は** いきます (私に関しては、私は行きます - 他の人は行かないかもしれないことを暗示します)。 
- 両方が同じ文に現れる可能性があります: ぞうははながながい (象に関しては、鼻が長い) — 「は」は主題を示し、「が」は主語を示します。 

## よくある間違い

 ❌ わたしはくせいです。 → ✓ わたし**は** がくせいです。 
- **説明:** 助詞は「わ」と発音しますが、「わ」ではなく「は」と書かなければなりません。 

❌ だれはきましたか。 → ✓ だれ**が** きましたか。 
- **説明:** 主語を尋ねる「だれ」や「なに」などの疑問詞は、「は」ではなく「が」となります。 

❌ 形式的なスピーチでは「は」を完全に削除する → 完全な文には常に助詞を含めます。 
- **説明:** 非常にカジュアルな日本語の話し言葉では「は」を省略できますが、書き言葉やフォーマルな文脈で「は」を省略すると不自然に聞こえます。
