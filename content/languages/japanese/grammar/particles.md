助詞 (助詞、情) は、日本語文法の最も基本的な要素の 1 つです。 これらは、名詞、代名詞、および句の末尾に付加され、文の残りの部分との文法的関係を示す短い音節です。 英語には助詞がありません。助詞の機能は語順と前置詞によって処理されます。 

## 核となる文の助詞

 ### は (わ) — トピックマーカー

 文のトピック、つまり文の内容を示します。 注：「は」は助詞として使用される場合は「は」と読みます（「は」ではありません）。 

**機能**: 「X については、...」 トピックは、その後に続くコメントのフレームを設定します。 

| 文 | ローマ字 | 翻訳 |
 |----------|----------|---------------|
 | 私**は**学生です。 私**は**学生です。 | 私は学生です。 (私に関して言えば、[私は]学生です。) |
 | 東京**は**大きいです。 東京＊＊は＊＊おうきいです。 | 東京は広いですよ。 |
 | これ**は**何ですか？ これ○○は○○なんですか？ | これは何ですか？ |
 | お茶**は**好きですか？ お茶○○は○○好きですか? | お茶は好きですか？ |

 **「は」はコントラスト**: 「は」は、2 つのものの間のコントラストも示します。 
- 私は行くが、彼は行かない。 — 私は行きますが、彼は行きません。 
- コーヒーは飲むが、お茶は飲めない。 — 私はコーヒーを飲みますが、お茶は飲みません。 

### が (ga) — 件名マーカー

 文法上の主語、つまりアクションを実行する人または内容、またはプロパティを持つ人または内容をマークします。 

**「は**」との主な違い: 「が」は**新しい情報**または**強調**をマークします。 「は」は **確立されたトピック** を示します。 

| 文 | ローマ字 | 翻訳 |
 |----------|----------|---------------|
 | 猫**が**います。 ネコ○○ガ○○います。 | 猫がいます（犬がいるわけではありません）。 |
 | 誰**が**来た？ あえて**が**キタ? | 誰が来たの？ |
 | 日本語**が**好きです。 日本語**が**好きです。 | 私は日本語が好きです。 (日本語は私が好きなものです。) |
 | 雨**が**降っています。 雨**が**ふれてます。 | 雨が降っています。 |

 **特別な用途 — が、潜在性/願望/らしさ**:
 特定の形容詞と潜在動詞は、目的語として「を」ではなく「が」を使用します。 
- 〜が好き (X が好き、X のように): 日本語が好き — 私は日本語が好きです
 - 〜が欲しい (X が欲しい、X が欲しい): 新しい車が欲しい — 新しい車が欲しいです
 - 〜ができる (X ができる、X ができる): 日本語ができる — 私は日本語を話せます

 **は対がの概要**:
 - は = トピック (既知、確立、または対比): 象**は**鼻が長い — ゾウに関しては、鼻が長いです。 
- が = 件名 (新しい情報、強調、焦点): 誰が来た?**田中さんが**来た。 田中さんが来ました。 

### を (o) — オブジェクト マーカー

 他動詞の直接目的語をマークします。 注：「を」は現代標準語では「お」と読みます。 

| 文 | ローマ字 | 翻訳 |
 |----------|----------|---------------|
 | ご飯**を**食べる。 ごはんを食べます。 | ご飯を食べる/食事をする。 |
 | この**を**読む。 ほん＊＊お＊＊よむ。 | 本を読みましょう。 |
 | 日本語**を**勉強する。 にほんご*お**べんきょうする。 | 日本語を勉強してください。 |
 | 映画**を**見ました。 映画を○○してみた。 | 映画を見ました。 |
 | バス**を**降りる。 バス○オ○リる。 | バスを降りてください。 (空間を通過する/空間から離れる移動) |

 ### に (ni) — 方向 / 時間 / 間接対象 / 存在位置

 いくつかの異なる用途を持つ最も多用途な粒子の 1 つ:

 **1. 移動方向 (行き先)**:
 - 東京**に**行く — 東京に行く
 - 家**に**帰る — 家に帰る

 **2. 具体的な時間**:
 - 3時**に**来てください — 3時に来てください
 - 月曜日**に**会議がある — 月曜日に会議があります

 **3. 間接オブジェクト (受信者)**:
 - 友達**に**プレゼントをあげる — 友達にプレゼントをあげます
 - 先生**に**質問する — 先生に質問する

 **4. 存在場所(ある/いる)**:
 - 机の上**に**本があります。— 机の上に本があります。 
- 公園**に**子供がいます。 — 公園に子供たちがいます。 

**5. 受動態文のエージェント**:
 - 先生**に**褒められました。— 先生に褒められました。 

**6. 動作の目的 (動作動詞を使用)**:
 - 映画を見に**に**行く — 映画を見に行く (見に = 見る)

 **にvs.で**:
 - には、静的な存在の場所をマークします (あります/います): 東京**に**住んでいます (live in Tokyo)
 - ではアクションが行われる場所を示します: 東京**で**働いている (work in Tokyo)

 ### で (de) — 行動の場所 / 手段 / 原因

 **1. アクションが発生する場所**:
 - 学校**で**勉強する — 学校で勉強する
 - レストラン**で**食べる — レストランで食べる

 **2. 手段または方法**:
 -**電車で**行く — 電車で行く
 - 日本語**で**話す — 日本語で話します
 - 箸**で**食べる — お箸で食べる

 **3. 素材**:
 - 木**で**作られた机 — 木で作られた机

**4. 原因/理由 (限定使用)**:
 - 病気**で**休みました — 病気のため欠席しました

 **5. 合計範囲/範囲**:
 - 世界で**で**一番高い山 — 世界で一番高い山
 - クラス**で**一番速い — クラスで最も速い

 ### へ (e) — 方向 (により柔らかい)

 方向性「に」と同じように使用されますが、より柔らかく、より文学的な雰囲気があります。 に向かう方向を示します。 

- 日本**へ**行く — 日本へ（向かって）行きます
 - 未来**へ** — 未来に向かって

 実際には、「に」と「へ」は物理的な方向を表す場合に交換可能であることがよくあります。 「へ」はもう少し文学的または詩的に聞こえます。 

### と (to) — そして (網羅的) / 付き / 引用

 **1. そして (網羅的なリスト)**:
 - 猫**と**犬**と**うさぎがいる。— 猫、犬、ウサギがいます。 (メンバー全員記載)
 - 参照。 や (非網羅的および): 猫**や**犬がいる — (とりわけ) 猫と犬がいます

 **2. **と一緒に:
 - 友達**と**行く — 友達と行く
 - 一人**と**話す — 1人で話す

 **3. 引用/思考マーカー**:
 - 「ありがとう」**と**言いました。—「ありがとう」と言った。 
- 難しい**と**思う — 難しいと思う
 - 行く**と**言った — 言った ([私/彼/彼女] が行くと)

 ### も (mo) — また / 偶数 / どちらでもない ... どちらでもない

 **1. また; も**:
 - 私**も**行きます。 — 私も行きます。 
- これ**も**いいです。 — これもいいですね。 

**2. 強調/包含を表す「は」または「が」を置き換えます**:
 - 彼**も**来た。 (もがを置き換えます)
 - 日本語**も**できる — 日本語も話せます

 **3. 量の強調 (数字付き)**:
 - 100人**も**来ました。— 100人も来てくれました！ (驚くべき量を強調)
 - ひとつ**も**ない — ひとつもありません

 **4. 否定: 「1 つもありません / ... もありません」**:
 - 誰**も**いない — そこには誰もいません
 - どこ**にも**行かない — どこにも行かない
 - 何**も**食べない — 何も食べていない

 ### の (いいえ) — 所有/名目化

 **1. 所有/所有物**:
 - 私**の**本 — 私の本
 - 東京**の**レストラン — 東京のレストラン
 - 先生**の**話 — 先生の話

 **2. 説明修飾子**:
 - 日本語**の**本 — 日本語による/日本語に関する本
 - 昨日**の**ニュース — 昨日のニュース

 **3. 名詞化 (動詞/形容詞句を名詞に変換)**:
 - 食べる**の**が好き — 食べることが好き (代替として食べること、同じ機能)
 - 早く起きる**の**は難しい — 早く起きるのは難しいです
 - 走る**の**が得意 — 走るのが得意です

 **4. 文末の（カジュアルな質問または説明）**:
 - どこに行く**の**? — どこに行きますか? (カジュアル)
 - 体調が悪い**んです** (の → ん + です) — (言っておきますが) 体調が良くありません。 

### から (から) — から / なぜなら

 **1. 出発点 (場所または時間)**:
 - 東京**から**来た — 東京から来ました
 - 9時**から**始まる — 9時から始まります
 - 来月**から**日本語を勉強する — 来月から日本語を勉強します

 **2. なぜなら（主観的な理由、話者自身の理由/感情）**:
 - 疲れた**から**帰る — 疲れたので家に帰ります
 - 好き**だから**買う — 好きだから買う

 **から vs. ので**: からはより断定的/個人的に聞こえます。 そのため、より客観的で丁寧に聞こえます。 

### まで (できた) — まで / 限り

 **1. (時間エンドポイント)** まで:
 - 5時**まで**働く — 5時まで働きます
 - 明日**まで**待つ — 明日まで待つ

 **2. (エンドポイントの配置)** に関して:
 - 東京**まで**行く — 東京まで行く
 - ここ**まで**歩く — ここまで歩いてください

 **3. 平; (強調)** の程度:
 -あんなこと**まで**する — そんなことまでする
 - 子供**まで**知っている — 子供でも知っています (それは)

 ### から〜まで (... から ...)
 - 東京**から**大阪**まで**電車で3時間 — 東京から大阪までは電車で3時間です
 - 月曜日**から**金曜日**まで**働く — 月曜日から金曜日まで働く

 ## 終了パーティクル

 ### か (ka) — クエスチョンマーカー

 あらゆる発言を「はい/いいえ」の質問に変えます。 カジュアルな会話では、多くの場合、イントネーションが省略され、上昇イントネーションに置き換えられます。 
- 学生です**か**?— あなたは学生ですか?
 - 食べました**か**？— 食べましたか？ 
- カジュアル: 行く？ (iku?) — 行きますか? [かは必要ありません]

 ### ね (ne) — 確認/共有知識を求めています

 同意を求めたり、共通の理解を示したりします。 「そうだね？」みたいな。 または「そうですよね?」:
 - 寒いです**ね**。— 寒いですね。 
- 美味しいです**ね**。 — 美味しいですよね？ 
- 田中さんも行く**ね**？ — 田中さんも行くんですよね？ 

### よ (よ) — アサーション / 新しい情報

聞き手が知らないかもしれないことを伝えたり主張したりしていることを示します。 「あなたは知っています」または「私はあなたに言います」のように：
 - それは間違いです**よ**。— それは間違っています (私はあなたに言います)。 
-もう8時ですよ。 — もう8時です（知っているはずです）。 
- 大丈夫ですよ。 — 大丈夫です (保証します)。 

### よね (yone) — アサーションと確認を組み合わせたもの
 - そうです**よね**？ — そうですよね？ （私はそう信じていますが、同意しますか？）

 ## パーティクルの結合

 一部の粒子は結合して複合粒子を形成します。 

| 化合物 | = | 意味 |
 |----------|---|----------|
 | には | に + は | "in/at (トピック)" — 東京**には**行ったことがない |
 | では | で + は | 「at/by (トピック/コントラスト)」 — 日本語**では**難しい |
 | からは | から + は | "(トピック)から" |
 | も | に＋も | "また/でも/に" |
 | それでも | で+も | "さえ; さえ; しかし（接続詞）" |
 | とは | と + は | 「（と呼ばれるものについては）」 — 愛**とは**何か |
 | ずっと | まで + も | "偶数; 偶数の範囲まで" |
