敬語（敬語、文字通り「尊敬語」）は、日本語の敬語体系です。 これは、大人の日本語コミュニケーションの基本的な部分であり、ビジネス、サービス業、フォーマルな場、および社会的階層が重要となるあらゆるやり取りで使用されます。 JLPT N2 では敬語パターンの認識が必要です。 N1 ではより深い理解が必要です。 

## 敬語の 3 つのレベル

 | レベル | 日本語 | 目的 | いつ使用するか |
 |----------|----------|-----------|-------------|
 | ていねいご | 丁寧語 | 丁寧な言葉遣い | 見知らぬ人、知人に対する標準的な敬語 |
 | ソンケイゴ | 尊敬語 | 敬意を持った言葉遣い | 他者（上司、顧客）の行動を高める |
 | 謙譲語 | 謙譲語 | 謙虚な言葉 | 自分の行動を他人と比べて低くする |

 ## ていねいご (丁寧語) — 標準的な丁寧語

 これは初級日本語で習う「ます/です」の形です。 これは敬語の基本であり、よく知らない人に対して使用されます。 

- 食べます (食べます) — 食べる (丁寧な)
 - 行きます (行きます) — 行きます (丁寧な)
 - 学生です (ガクセイです) — 学生です (丁寧な)

 ていねいごは以下の最低レベルです。 
- 公共の場で見知らぬ人と話す
 - 先生、先輩、顧客への対応
 - ビジネスメールやフォーマルな手紙

 ## 尊敬語 (尊敬語) — 尊敬語

 尊敬語は**他人**の行動を高めます。 上司、クライアント、顧客、またはそれよりも地位の高い人の行動を説明するときに使用します。 

### 重要な尊敬語の動詞の置換

 | 規則動詞 | ソンケイゴ | 意味 |
 |-----------|-----------|----------|
 | います (ある/存在する) | いらっしゃいます | なれ; 存在します (敬意を表して) |
 | 行きます (行きます) | いらっしゃいます | 行きます（敬意を表して） |
 | 来ます (来ます) | いらっしゃいます | 来てください（敬意を表して）
 | 言います (言います) | ご了承ください | 言う（敬意を持って） |
 | します (する) | そうですか | する（敬意を持って） |
 | 食べます | 食べます いただきます | 食べる（敬意を表して） |
 | 飲みます | いただきます | 飲み物（敬意を表して） |
 | 知っています (知っています) | 承ります | 知っています（敬意を表して） |
 | くれます してください | 与える（敬意を持って） |
 | 見ます ご覧になります | 見る/見る（敬意を表して） |
 | 着ます | お召しになります | 着用（敬意を込めて） |
 | もらいます（受け取ります） | お受け取りになります | 受け取ります（敬意を持って） |

 注: 「いらっしゃいます」は「います/行きます/来ます」をカバーします — 文脈によってどの意味が決まるかが決まります。 

### ソンケイゴ構築パターン

 **パターン 1: お/ご + 動詞語幹 + になります**
 ほとんどの通常の動詞は、次の式で敬意を表すことができます。 
- 読む → お読みになります — [謹んで]読みます
 - 使う → お使いになります — use [敬意を持って]
 - お待ちください→になります — [謹んで]

 中国語（漢語）動詞の場合、「お」の代わりに「ご」を使用します。 
- 利用する → ご利用になります — [敬意を持って]使用/利用します
 - 連絡する → ご連絡 — [謹んで] ご連絡させていただきます

 **パターン 2: 敬意を表す受動態**
 多くの文脈において、受動態は (N2+ 認識) を尊重します。 
- 先生は何時に来られましたか？ - 先生は何時に来ましたか? (レ = 受動態/敬意)
 - 部長は書きましたか？ — 部長が（それを）書きましたか？ 

この用法はスピーチでは一般的ですが、明示的なソンケイゴほどフォーマルではありません。 

### 例文（尊敬語）

 | 状況 | ソンケイゴ | 規則的/礼儀正しい |
 |----------|----------||-----|
 | 大統領は入っていますか？ | 社長はいらっしゃいますか？ 社長はいますか？ 
| 顧客は何と言いましたか? | お客さんは何と思ってますか？ お客様は何を言いましたか？ 
| お茶をどうぞ | お茶をお召し上がりください | お茶を飲んでください |
 | 田中さんを知っていますか？ | 田中様をよろしいですか？ 田中さんを知っていますか？ 
| この文書をご覧ください | この資料をご覧ください | この資料を見てください |

 ## 謙譲語 (謙譲語) — 謙譲語

 謙譲語は、上司や顧客と話すときに**自分自身の行動を低く**します。 あなたはアクションを実行しています。 謙譲語は、あなたの行動を相手の前で控えめ/謙虚に見せます。 

### 主要な謙譲語動詞の置換

| 規則動詞 | 謙譲語 | 意味 |
 |-----------|-----------|----------|
 | います（である） | よろしく | なれ; 存在する（謙虚） |
 | 行きます (行きます) | まいります | 行く（謙虚） |
 | 来ます (来ます) | まいります | 来てください（謙虚） |
 | 言います (言います) | 申します | 言う（謙虚に） |
 | します (する) | あります | する（謙虚） |
 | 食べます | 食べます いただきます | 食べる/受け取る（謙虚） |
 | 飲みます | いただきます | 飲み物（謙虚） |
 | 知っています (知っています) | 勝てます。 知っています（謙虚） |
 | もらいます（受け取ります） | いただきます | 受け取ります（謙虚） |
 | あげます | さしあげます | 与える（謙虚） |
 | 見せます (ショー) | お目にかけます | ショー（謙虚） |
 | 聞きます | ご了承ください。 尋ねる・訪問する・聞く（謙虚に） |
 | 訪問します | 食べます | 訪問（謙虚） |
 | お借りします (借ります) | 拝借します | 拝借（謙虚） |
 | 見ます | 拝見します | 見る/見る（謙虚） |

 ### Kenjougo 構築パターン

 **パターン 1: お/ご + 動詞語幹 + します/いたします**
 -伝えます — (あなたに)伝えます
 - ご案内します — 私が（あなたを）ご案内します
 - お持ちします — (あなたのために) 持ち歩きます/持ちます
 - ご説明いたします — (あなたに) 説明させていただきます [もっと謙虚にいたします]

 **パターン 2: 〜させていただきます**
 非常に謙虚な形式: 「謹んで X を行う許可を受け取ります」:
 - 休ませていただきます — ご自由にお休みさせていただきます (= 休む必要があります; 許可を求めています)
 - 確認させていただきます — 確認させてください (= 確認させていただきます)
 - 日程を変更させていただきたいのですが — 日付をご自由に変更していただきたいのですが

 この形式は、現代の日本のビジネスで、時には皮肉にも過剰に使用されています。 

### 例文（謙譲語）

 | 状況 | 謙譲語 | 規則的/礼儀正しい |
 |----------|----------||-----|
 | 私の名前はタナカです | 田中と申します | 田中です |
 | 今行きます | あります | これから行きます |
 | 私はオフィスにいます | 補償会社におります | 保障会社にいます |
 | 説明します | ご説明いたします | 説明します |
 | 書類を受け取りました | 書類を拝受いたしました | 書類をもらいました |
 | 何か聞いてもいいですか？ | お気軽にどうぞ | 聞いてもいいですか |
 | あなたの文書を見ました | 資料を拝見しました | 資料を見ました |

 ## 一般的なビジネス表現

 これらの敬語フレーズは、日本のビジネス現場で常に使用されています。 

| 式 | 使い方 |
 |----------|----------|
 | よろしくお願いいたします | 標準的な営業終了: 「よろしくお願いします」 |
 | お世話になっております | 標準的なビジネスメール/電話の冒頭: 「今後ともよろしくお願いいたします」 |
 | おかげさまで | 「あなたのおかげ/あなたの助けに感謝します」 |
 | ご連絡ありがとうございます | 「ご連絡いただきありがとうございます」 |
 | よろしくお願いします。 「少々お待ちください」 |
 | お待たせいたしました | 「お待たせしました / 大変お待たせしました」 |
 | ご不便をおかけして申し訳ございません | 「ご迷惑をおかけして誠に申し訳ございません」 |
 | よろしくお願いいたします | 「お願いは以上です。よろしくお願いします。」 |
 | 危険を訴えます | 「ご迷惑をおかけして申し訳ありません」 |
 | ご確認のほどよろしくお願いいたします。 「ご確認のほどよろしくお願いいたします」 |

 ## 謝罪の 4 つのレベル

 日本人の謝罪の強さには複数のレベルがあります。 
1. ごめん（ごめん） — 親しい友人の間でのカジュアルな謝罪
 2. すみません (すみません) — 標準的な謝罪/すみません (注意を引きます: すみません!)
 3. 申し訳ありません (もうしわけありません) — 心からの謝罪 (ビジネス/真剣)
 4. 深くお詫びします (深々おわびもうしあげます) — 深い謝罪 (正式な手紙、重大な間違い)
