## 概要

 法律的および学術的な日本語は、言語全体の中で最も特徴的な言語の 1 つを構成します。 話し言葉の日本語はあいまいさ、含意、文脈の共有の原則に基づいて機能しますが、法律日本語はその逆を行い、すべての条件、例外、および適用範囲を非常に正確に指定する文法構造を使用して、あいまいさを完全に排除しようとします。 この登記簿は、明治時代 (1868 ～ 1912 年) に成文化された正式な書き言葉 (*bungo*) の伝統に基づいており、このとき日本の国会議員はヨーロッパの法モデル、特にドイツとフランスの民法を緊急に日本語に適応させました。 その法典化の過程で得られた文法構造は、日本の現行の民法 (*煩*)、刑法 (*刑法*)、憲法 (*憲法*) で、ほとんど変わることなく今日でも使用されています。 

学術日本語は、法律日本語といくつかの文法的特徴を共有しています。特に、非人称的、受動態構文を好むこと、話題の構成に「〜において/〜に関して」を使用すること、日本語ネイティブの動詞ではなく日中の抽象名詞を使用することです。 しかし、学術的な日本語にも独自の慣例があります。つまり、ヘッジ表現（〜と考えられる、〜の可能性がある）、引用公式（〜によれば、〜に瑞い）、そして論理接続詞（ゆえに、したがって、これに対して）の細心の注意です。 N1 レベルでは、読解文章は学術要旨、法律条項、公式発表から引用されることが多く、語彙だけでなく、これらの登録で使用される文法論理の理解も必要とされます。 

このレッスンでは、法律、学術、公式テキストに現れる 5 つの重要な文法パターンを紹介し、サンプルの法律および学術文章に注釈を付け、この要求の厳しい登録に必要な語彙を構築します。 

## 学習目標

 このレッスンを終了するまでに、次のことができるようになります。 
- 法的および形式的な仮説の文脈で「〜ものとする」と「〜ものとして」を使用した文を理解し、作成する。 
- 原則を特定のケースに適用することを表現するには、「〜に即して/〜に即した」を使用します。 
- 違反または違反を説明するには、〜に反して/〜に反省を使用して文を作成します。 
- 〜までを展開して、正式な手段、開始、または結論を表現します。 
- 無条件に適用できることを表現するには、「〜いかんによらず」と「〜いかんに勝つ」を使用します。

 ## 文法ポイント

 ### 1. 〜ものとする / 〜ものとして (と規定されています / と仮定します)

 **構造:**
 - 動詞(普通形) + ものとする
 - 名詞 + である + ものとする
 - 動詞(普通形) + ものとして + [後続節]

**古典的な起源:**
 このパターンは、先行する文節を名目化する古典的な助動詞「物/者」に、形式的な規範機能として「するする/する」と組み合わせたものから派生しています。 古典や明治時代の法律書では、「〜ものとす」が規則や手続きを規定する標準的な表現でした。 現代の〜ものとする形式は、この規範的な機能を本質的に変えずに保持しています。 

**説明:**
 〜ものとするものは、法律、契約、規制における規則、義務、手順を規定するための標準的な公式として機能します。 「このように定められている」または「そのとおりである」という意味です。 それは第三者の規範的なものであり、個人的な決定ではなく、組織的または法的な決定です。 

対照的に、「〜ものとして」は、計算、議論、または計画の目的で仮説的な仮定を導入します。 これは、「X をあたかもそうであるかのように扱う」または「この目的のために〜であると仮定する」ことを意味します。 これは、学術論文で公理を確立したり、仮定を単純化するときに頻繁に現れます。 

**例文:**

 | 日本語 | 読書 | 英語 |
 |----------|-----------|----------|
 | 本契約に定めのない事項については、その他の関係法令の規定によるものとする。 ほんけいやくにさだめのないじこうについては、みんぽうそのほかのかんけいほうれいのきていによるものとする。 本規約に定めのない事項については、民法その他の関係法令によるものとします。 |
 | 期日までに通知がない場合は、承諾したものと諦めます。 | きじつまでにつうちがないばあいは、しょうだくしたものとチップ。 期限までにご連絡がない場合は、同意があったものとみなします。 |
 | 歩みでは、言語習得は段階的なプロセスであるものとして論を進めていく。 ほんこうでは、げんごしゅうとくはだんかいてきプロセスであるものとしてロンを注意してください。 この論文では、言語習得は段階的なプロセスであるという前提で議論を進めます。 |
 | 当事者双方が合意した内容は、書面によって確認されたものとします。 とうじしゃそうほうがごういしたのではないは、しょめんによってかくにんされたものとします。 両当事者が合意した内容は書面により確認されたものとみなされます。 |
 | 反証がない限り、当該書類は真正に成立したものとします。 | はんしょうがないかぎり、とうがいしょるいはしんせいにせいりしたものとします。 反対の証拠がない限り、問題の文書は有効に確立されたものとみなされます。 |

 **❌ 一般的なエラー → ✓ 修正:**
 - ❌ 彼は休暇一日のものとする。— 個人的な主題を法的な処方箋で使用すると、レジスターの衝突が発生します。 
- ✓ 休暇の申請は特殊な書式を置くものとする。 — 非個人的で制度的な主語は、〜ものとするのが正しい。 

**N2相当品との比較 〜ことにする:**
 〜ことにするは個人的な決断を表します：「早起きすることにした」（私は早く起きることに決めました）。 〜ものとするのは制度上の処方箋であり、個人の決定ではありません。 代替することはできません。

 ### 2. 〜に即して / 〜に即した (に従って / 特に適用される)

 **構造:**
 - 名詞 + に即して + [節]
 - 名詞 + に即した + 名詞

 **古典的な起源:**
 即 (*ソク*) には、「同調している」、「押し付けられている」、または「直接対応している」という古典的な意味があります。 複合語では「即」は即時、瞬時に、即興となります。 〜に即して、この方向性の調整を抽象的な原則、ルール、または状況に適用します。 

**説明:**
 〜に即しては、「〜に直接対応する」、「特に〜に適用される」、または「〜の特定の場合に照らして」を意味します。 これは、「〜に従って」や「〜に基づいて」よりも強力です。「〜に即して」は、単にルールに従うだけでなく、目の前の特定の状況に原則を「適用」することを意味します。 法的使用法: 法律を具体的な状況に適用すること。 学術的利用: 理論的フレームワークを特定のデータセットまたはケーススタディに適用します。 

**例文:**

| 日本語 | 読書 | 英語 |
 |----------|-----------|----------|
 | 各事件の具体的な状況に即して、適切な対処法を判断するものとする。 | かくじあんのぐたいじょうてききょうにそくして、てきせつなたいしょほうをはんだんするものとします。 適切な対応は、それぞれのケースの具体的な状況に応じて決定されるものとします。 |
 | 現実に即した指導法を採用することで、学習効果が向上しました。 げんじ定めそくしたしどうほうをさいようすることで、がくしゅうこ注目こうじょうした。 現実世界の状況に即した指導方法を採用することで、学習成果が向上しました。 |
 | | 正義精神に即して解釈するならば、本条項はこのように読むべきである。 | ほうのせいしんにそくしてかいしゃくするなら、ほんじょうこうはこのようによむべきである。 法の精神に従って解釈すると、この条項は次のように解釈されるべきです。 |
 | 時代の変化に即した規則の改正が急務だ。 | じだいのへんかにそくしたきそくのかいていがきゅうむだ。 社会の変化に合わせた規制の見直しが急務となっている。 |

 **〜に従ってとの比較:**
 〜に従って = ルールへの受動的準拠（「与えられたルールに従う」）。 〜に即して = 原則を積極的にケースごとに適用すること。 裁判官は法律に従います (〜に従って)。 裁判官は法律を特定の事実に適用します（〜に即して）。

 ### 3. 〜に反して / 〜に違反（に反する / 違反している）

 **構造:**
 - 名詞 + に反して + [節]
 - 名詞 + にかと + 名詞

 **説明:**
 「反」は「敵対する」「反対する」という意味です。 〜に反しては、行動、結果、状態が期待、合意、規則、原則に反することを表します。 これには主に 2 つの範囲があります。(a) 正式な規則または合意の違反。 (b) 期待または意図に反する結果。 

**例文:**

 | 日本語 | 読書 | 英語 |
 |----------|-----------|----------|
 | | 本規定に定める行為は、損害賠償の対象となります。 | ほんきていにはんするつもりは、そんがいばいしょうのたいしょうになります。 この規定に違反した行為は損害賠償請求の対象となります。 |
 | 予想に反して、実験結果は一時をサポートするものだった。 | よそうにはんして、じっけんけっかはかせをしじるものだった。 予想に反して、実験結果は仮説を裏付けました。 |
 | 条約の精神に反した行動は、国際的批判を主導しよう。 | じょうやくのせいしんにはんしたこうどうは、こくさいてきひはんをまねくだろう。 条約の精神に反する行為は国際的な批判を招くことになる。 |
 | 公序良俗に一切契約条項は有効とされる。 こうじょりょうぞくにはんするけいやくじょうこうはむこうとされる。 公序良俗に反する契約条項は無効とみなされます。 |
 | 期待して反して参加者が少なく、主催者は落胆した。 | きたいにはんしてさんかしゃがすくなく、しゅさいしゃはらくたんした。 予想に反して参加者は少なく、主催者は残念がった。 |

 **〜に先立ってとの比較:**
 〜に禁止しては、具体的には法律/規制違反です。 「〜に反して」はより広範で、期待、精神、原則への違反を含みます。 どちらも法律で動作します。 〜に反してのみ、予想または期待で機能します。

 ### 4. 〜まで (〜によって / 現在 — 正式な完了または開始)

 **構造:**
 - 名詞 + と + [手段または時間に関する節]
 - 名詞 + と + 〜とする / 〜に代える

 **古典的な起源:**
 「もって」 (*motte*) は「持つ」(*motsu*、持つ/持つ) の古典的な動名詞形です。「X を持っている」または「X のおかげで」。 古典的および文学的な日本語では、「〜では」は達成の手段または手段、また開始または終了の正式な瞬間を表します。 

**説明:**
 〜ではには 3 つの主な用途があります: (1) 手段/方法 — 「〜で」の非常にフォーマルな代替語。 (2) 時間的境界 — 「現在」、「から有効」。 (3) 形式的な置き換え — 〜それで〜に代える: 「X は Y として機能します。」

 **例文:**

 | 日本語 | 読書 | 英語 |
 |----------|-----------|----------|
 | 本書ではこれをもって、正式な解約通知といたします。 ほんしょめんとともに、せいしきなかいやくつうちといたします。 この文書は、キャンセルの正式な通知を構成します。 |
 | これをもって、当プロジェクトは終了となります。 ほんとつによって、とうプロジェクトをしゅうりょうとします。 本日をもちまして、本プロジェクトは終了とさせていただきます。 |
 | 誠意をもって交渉に存します。 せいいそれでこうしょうにのぞむしょぞんです。 誠意を持って交渉に臨んでまいりたいと考えております。 |
 | 同封の書類とともに入学手続きに代えるものとします。 どうふうのしょるいことでにゅうがて続ききにかえるものとする。 同封の書類が入会手続きとなります。 |
 | 全会一致で反省されたことを報告する。 ぜんかいいちことでけつぎされたことをほうこくする。 決議案が全会一致で採択されたことを報告いたします。 |

**〜によって:**との比較
 〜によっては一般的な文章で手段・原因を表します。 〜までは正式な登録に相当し、公式文書、法律文書、正式な発表のために予約されています。

 ### 5. 〜いかんによらず / 〜いかんに敵対 (どうやっても/関係なく)

 **構造:**
 - 名詞 (の) + いかんによらず
 - 名詞 (の) + いかんに敵対
 - 名詞（の） + いかん（近い同義語）

 **古典的な起源:**
 「いかん」 (*ikan*) は日中古典複合語で、「どう」 (中国語では *rú hé*) で、「どうであるか」または「状況はどうであるか」を意味します。 したがって、「〜いかんによらず」は「物事がどのようになろうとも」という意味になります。 このパターンは日本の正式な法律および官僚言語に入り、本質的には変わっていない。 

**説明:**
 「〜いかんによらず」と「〜いかんに不利」はどちらも無条件の適用性を表します。 〜いかんに攻撃はもう少し正式で法的に正確です。 補足的な「〜いいかんによっては」は（方法に応じて）条件付き適用のために同じ法文に現れます。 

**例文:**

 | 日本語 | 読書 | 英語 |
 |----------|-----------|----------|
 | 国籍のいかんに対抗し、本法規定は適用される。 こくせきのいかんに敵対、ほんほうのきいてはてきようされる。 この法律の規定は国籍に関係なく適用されます。 |
 | 理由のいかんによらず、提出期限を超えた申請は受け付けません。 りゆうのいかんによらず、ていしゅつきげんをこえたしんせいはじゅりしない。 締切を過ぎた場合は理由の如何を問わず受け付けません。 |
 | 結果のいかんに忠実、参加者全員に修了証を授与する。 けっかのいかんに対抗、さんかしゃぜんいんにシューりょうしょうをじゅよする。 結果に関わらず、参加者全員に修了証が授与されます。 |
 | 経緯のいかんを踏まえ、当事者間の合意が最優先される。 いいけのいかんをとらず、とうじしゃかんのごういがさいゆうせんされる。 背景事情に関わらず、当事者間の合意が優先されます。 |

 **〜に対抗(N2)との比較:**
 「〜にいじめ」は多くの文脈で代用できますが、「〜いかんにいじめ」はよりフォーマルで、具体的には何かの *やり方* や *性質* の変化を暗示します。 法律文書では「〜いかんに対抗」が標準です。 

## 本物のテキスト

 ### サンプル 1: 契約条項 (契約条項)

 > **第十三条（損害賠償）**
 > 本契約の規定に違法行為によって相手方に損害を与えた場合、当事者は、その損害賠償の賠償を負うものとする。 損害賠償の範囲は、通常損害に限るものとし、特別賠償については、当事者がその事情を予見し、または予見できた場合に限り、これを賠償するものとする。 

**注釈:**
 - **本契約の規定に違反行為によって** — 〜に違反する + 〜によって (by means of)
 - **当事者は…罰を負うものとする** — 〜ものとするは法的義務を規定します
 - **通常損害に限るものとし** — 〜に限る（〜に限る） + 〜ものとし（定められている）
 - **理由のいいかん** — 無条件の損害賠償上限
 - **当該契約の総額を上限とする** — 上限式; 施設内処方箋

 **訳注：** 第 13 条（損害）：本契約の規定に違反する行為により、当事者の一方が相手方に損害を与えた場合には、その損害を賠償する責任を負います。 損害賠償の範囲は通常の損害に限定されます。 特別損害は、当事者が関連する状況を予見した、または予見できた場合にのみ補償されます。 理由の如何を問わず、本条に基づく補償金の額は、当該契約の総額を超えないものとします。 

### サンプル 2: 学術要旨 (学術論文要旨)

 > 本研究は、現代日本語における受動構文の使用頻度の変化を、コーパスデータに即して分析したものである。 ことばにおける受動化率は意識的に増加傾向を示した。 

**注釈:**
 - **コーパスデータに即して** — コーパスに直接/コーパスに照らして分析を適用する
 - **計量的手法によって調査した** — 定量的手法を「使用して」
 - **正義に反するものではない** — 否定された違反: 規範に反していない
 - **乖離のいかんを精査する** — 乖離の性質/程度を調査する

 ## 対話

 ### ダイアログ 1: 契約審査会議 (契約審査会議)

 ** 弁護士:** 第七条の「本契約に定めのない事項は問題によるものとする」という規定ですが、これは通常の記載です。 

**社内法務担当:** はい、標準的な改正条項です。当事者双方が自覚的に合意した事項以外は、法律の規定が自動的に適用されるものとする、という観念です。 

** 弁護士:** ただ、本件の特殊行為を即して考えると、懸念の原則だけでは慎重な場面が起こることはないので注意してください。 

**社内法務担当:** ご指摘は考えております。 特に損害賠償の範囲については、第十三条まで特別規定として優先適用するという解釈で問題ないと考えております。 

**弁護士:** 理由のいかんに基づく上限を無視した条項については、公序良俗に主張という主張がなされる可能性はありませんか。 

**社内法務担当:** その点は精査済みです。上限額がほとんど不当でない限り、裁判は当事者の合意を尊重する傾向があり、本件では問題がないものと判断しております。

### ダイアログ 2: 学位論文審査

 **審査委員:** 第三章の分析手法ですが、暫定設定の段階で「言語は社会的価格であるものとして」という前提を置かれていますね。この前提の検討性についてはどう考えますか。 

**候補者:** はい、この前提は研究目的に即した方法論的仮説であり、哲学的命題としての検証は視野の範囲外としております。 

**審査委員:** なるほど。ただ、その前提に沿って事例が第五章に気づかれますが、これはどう説明されますか。 

**候補者:** 第五章の事例は、当面限界的な事例として進めており、議論核の主張を損なうものではないと考えております。 

**審査委員:**当面の課題として、個人のいかんによらず成立する一般的な原理の探索を視野に入れていただければ、研究の発展が期待できます。

 ## 翻訳の練習

 ### 英語→日本語 (法律/学術)

 1.「本条の規定は、被った損害の性質や額に関わらず適用されるものとします。」 →本条の規定は、発生した損害の性質又は金額のいかんに準拠、適用されるものとする。 

2.「評価基準は、応募者の具体的な事情に応じて委員会が定めるものとする。」 →委員会は、各申請者の具体的な事情に即して、評価基準を判断するものとします。 

3. 「本契約の精神に反する行為は、即時終了の理由となるものとします。」 →本契約の精神に違反する行為は、即時解除の事となるものとします。 

4. 「署名日の時点で、両当事者はここに規定されているすべての権利と義務を承諾します。」 → 意思の日に従い、当事者双方は本書に規定するすべての権利および義務を受諾したものとする。 

5. 「この研究は、分析目的で変数が統計的に独立していることを前提としており、それに応じて進められます。」 → 本研究は、分析目的のため、変数間は統計的に独立であるものとして論を進めていく。 

### 日本語→英語（法律/学術）

 1. 「本規程に定めのない事項については、別途協議の上、決定するものとする。」 → 本規程に定めのない事項については、当事者間で別途協議の上決定するものとする。 

2. 「時代の変化に即した規定のは、行政の責任において行うべきである。」 → 社会変化の整備に合わせた規制の制定は行政が果たすべき責任である。 

3. 「公益に違法行為は、極めて合法であるとしても、倫理的批判を免れない。」 → たとえ合法であっても、公益に反する行為は倫理的批判を免れない。 

4. 「本証明書ひいては、これからを証明するものとする。」 → この証明書は入学の証明として機能します。 

5. 「提出書類のいかん如何、申請の最終判断は審査委員会が行う。」 → 提出された書類に関わらず、申請の最終判断は審査委員会が行うものとします。 

## 文化的および歴史的メモ

日本の法文の独特の文法は、1870 年から 1900 年にかけての明治政府の法近代化という異例のプログラムに起源を持っています。日本は、ペリー来航後に課せられた「不平等条約」――西側列強が日本の法制度を「文明化されていない」とみなしたために、日本の関税自主権を否定し、外国人に治外法権を課す条約――を改正するという厳しい外部圧力にさらされていました。 法の近代性を実証するために、日本の国会議員はドイツとフランスの法学者（特に商法についてはドイツの法学者ヘルマン・ロエスラー、初期刑法についてはフランスの学者ギュスターヴ・ボアソナード）と協力して、日本語による包括的な西洋式法制度の草案を作成した。 これらの起草者が選んだ文法構造 — 〜ものとする、〜とともに、〜いかんに勝つ — は、これまで成文化された法律の西洋の伝統が欠如していた言語で法的正確さを伝える能力を考慮して選択されました。 これらと同じ構造が今日の日本の現行法典に残っており、明治の変革の生きた言語記念碑となっています。 

アカデミックな日本語は、平行ではあるが明確な軌跡に沿って発展しました。 明治大学のシステムはドイツの研究大学をモデルとしており、日本語での初期の学術論文はドイツの学術スタイルの影響を強く受けていました。ドイツの学術スタイルでは、個人的な口頭での発言よりも長い体言、受動的な構文、抽象名詞が好まれていました。 これにより、日本の学術散文の特徴が生み出された。それは、日本語本来の動詞よりも日中の複合名詞が好まれること、非人称受動構文（〜と考えられる、〜が示唆される）の使用、そして一人称の主張の回避である。 西周のような明治時代の学者（「哲学」を意味する哲学*テガク*や「理由」を意味する理性*理性*などの用語を作った）は、日本の学術的言説の語彙を確立しました。 今日の N1 リーディング文章は、この伝統を直接活用しています。 

## セルフチェック

 1. 〜ものとする と 〜ことにする の主な違いは何ですか? 適切な文脈でそれぞれの例を示します。 
*(予想: 〜ものとする = 制度的/法的処方箋; 〜ことにする = 個人的な決定。例: 「提出期限を五月一日とするものとする。」 vs. 「五月一日に提出することにした。」)*

 2. 「現実に即した政策を実現する必要がある」という文で、即したは何を修飾しますか?なぜここで、〜に即した方が〜に合ったよりも好まれるのですか?
 *(期待: 即したは政策を修正します。〜に即したは、特定の現実世界の条件との積極的な調整を意味します。〜に合ったは、ケース固有の適用を意味するものではなく、単に「適合/適切」を意味します。)*

 3. 契約書には「本日契約を解除します」と記載されています。 ここで「〜では」にはどのような法的効果がありますか?また、〜でそれを置き換えることができますか?
 *(予想: 〜以降、今日が正確な正式な発効日となります。〜では、法的文書では文体的に不適切です。〜以降、正式な登録を示します。)*

 4. 次の契約条項を英語に翻訳します: 「利用者の責任に帰すべき事由のいかんに応じ、当社は本サービスに賠償する損害について一切の責任を負わない。」
 ※（想定：利用者の責に帰すべき事由に関わらず、本サービスにより生じた損害については、当社は一切の責任を負いません。）※

 5. 〜に反して と 〜に見通して はどう違いますか？ 両方を使用できるコンテキストはどれですか?また、一方のみを使用できるコンテキストはどれですか?
 *(予想: 〜に反して = 具体的には法律/規制違反。〜に反して = より広範 — 期待、精神、または原則の違反が含まれます。両方: 法律に反して / 法律に予告して。〜に反してのみ: 予想に反して、期待に反して。)*
