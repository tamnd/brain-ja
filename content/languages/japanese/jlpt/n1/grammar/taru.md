## 〜たる

 **形式レベル:** 形式的 / 文学的 / 古風 — 形式的なスピーチ、文学的な散文、高度な説明

 **古典的な起源:**
 「たる」は古典的なコピュラ「たり」（*tari*）の連体形（連体形）であり、それ自体は「にて」（*nite*、古典的な楽器存在）+あり（*ari*、「であること」）から派生しています。 古典日本語では、「たり」は「X の状態にある」または「X として存在する」という状態を表します。 その連体形「たる」は、「X であるもの」または「本来の完全な意味で X であること」を意味する名詞修飾句を作成します。 それは万葉集の詩、平安の散文、中世の武家文学のいたるところに現れています。 

---

 ## 構造

 | フォーム | 例 |
 |-----|----------|
 | 名詞 + たる + 名詞 | 学者たる者 |
 | 名詞 + たる | たるい態度 |
 | 名詞/形容詞 + たる | たる完璧仕事 |

 **注意:** たるは、次の名詞を直接修飾します (名詞の位置)。 また、強調的な文脈で語句を終了することもあります:「誇ったり」(述語として、古い文学)。 

---

 ## 意味

 「真の/適切な/完全な意味でのXであること/Xにふさわしいこと/Xがそうあるべきであること」

 「たる」は、それに付けられる名詞にふさわしい本質的な品質や威厳の感覚を加えます。 これは、その名詞がそのカテゴリの完全、適切、または理想的な表現を表すことを意味します。

 ## 例文

 | 日本語 | 英語 |
 |----------|----------|
 | 堂々たる演説に、聴衆は深く感動した。 威厳に満ちた堂々としたスピーチに聴衆は深い感動を覚えました。 |
 | 教師たる者、常に公平であることが求められる。 （本当の意味で）教師である者には、常に公平であることが求められます。 |
 | 勝手研究は完璧たる論理構成を誇っていた。 彼の研究は論理的に完璧な（完璧な、傑作にふさわしい）構造を誇っていました。 |
 | 悠然たる山の姿が、旅人の心を慰めました。 落ち着いた穏やかな山の姿が旅人の心を慰めてくれました。 |
 | 武士たる者の誇りを、最後まで捨てなかった。 彼は最後まで真の戦士としての誇りを捨てなかった。 |
 | 彼女は堂々たる態度で壇上にいた。 彼女は威厳のある威厳のある態度で表彰台に上がりました。 |
 | 国家の指導者に不安があるとは何か質問されれば、私はまず先に言う。 本当の意味で国家指導者にふさわしい資質は何かと問われれば、私はまず誠実さを挙げます。 |

 ## N2相当品との比較

 | パターン | 登録 | 意味 | 主な違い |
 |----------|------|----------|-----|

 ## 使用しない場合

 - **ネガティブまたは品位のない属性には使用しないでください:** ❌ 卑怯たる行為 (たるは尊厳/適切さを暗示します。ネガティブな性質には卑怯な行為を使用します)
 - **カジュアルなスピーチでは使用しないでください:** 会話では「たる」は芝居がかったように聞こえます。 〜らしい、〜として、または単に〜なに置き換えます。 
- **「到着する」を意味する助動詞たると混同しないでください:** いくつかの古典的な文脈では、たり/たるは完了/到着を示すことがあります。 ここで説明する形容詞形は状態的用法です。
