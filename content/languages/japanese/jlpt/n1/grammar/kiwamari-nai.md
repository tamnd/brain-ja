## 〜極まりない / 〜極まる

 **形式的なレベル:** 準形式的 / 公式 — 形式的な批評、社説執筆、形式的な苦情

 **古典的な起源:**
 極まるとは「極限に達する・限界に達する」という意味です。 極まりないは、極まり（限界/極限）+ない（ない/なし）を組み合わせたもので、「限界がない」→「極限の」です。 否定的な「ない」は、品質に「上限がない」という感覚を追加します。それはあまりにも極端で、これ以上修飾することはできません。 

---

 ## 構造

 | パターン | フォーム | 例 |
 |----------|------|----------|
 | 〜極まりない | な-形容詞 + 極まりない | 危険極まりない |
 | 〜極まる | な-形容詞 + 極まる | 非礼極まる |
 | 〜極まる | い-adj い→く + 極まる | 見苦極まる (あまり一般的ではない) |

 **注意:** な形容詞語幹は、ななしで直接使用されます: 危険(な)→危険極まりない; 無礼(な)→無礼極まりない。 

---

 ## 意味

 「極度の【負の性質】/【負の性質】の極み/極限状態」

 どちらのパターンも、何かが (通常はネガティブな) 品質の極限にあることを表します。 話し手の強い感情的反応（多くの場合、憤り、当惑、道徳的怒りなど）が表現されます。 

**〜極まりない** (より一般的): 「制限なし/上限なし」 — 品質があまりにも極端で、測り知れないほどです。 
**〜極まる** (ややフォーマルな): 「極限に達する」 — やや控えめな表現。 

---

 ## 例文

 | 日本語 | 英語 |
 |----------|----------|
 | 事前の説明なしにキャンセルすると、失礼**極まりない**行為だ。 事前の説明なしにキャンセルすることは非常に失礼な行為です。 |
 | | あの時の彼の態度は、無礼**極まりない**ものだった。 その時の彼の態度は失礼の極みでした。 |
 | 公衆の面前でそのような発言をすると、恥知らず**極まる**。 公の場でそのような発言をすることは恥知らずの極みです。 |
 | 危険**極まりない**行為を子どもの前でする。 お子様の前で非常に危険な行為を行わないでください。 |
 | その決断は不決定**極まりなく**、議員たちの怒りを買った。 この対応は不誠実の極みであり、議員らの怒りを買った。 |
 | 非常に識**極まる**要求に、担当者は当惑した。 あまりにも無理難題の極みの要求に警官は困惑した。 |

 ## 一般的なコロケーション

 | 式 | 意味 |
 |----------|----------|
 | 失礼極まりない | 非常に失礼です |
 | 無礼極まる | 失礼の極み |
 | 危険極まりない | 危険なほど極端 |
 | 不謹慎極まりない | 極めて不適切・不適切 |
 | 恥知らず極まる | 恥知らずの極み |
 | 遺憾極まりない | 誠に遺憾です |

 ## 使用しない場合

 - **ポジティブな性質には使用しないでください:** ×美しさ極まりない (不自然 — ポジティブな美しさは極まりない)。 ポジティブな極端な場合は、「この上のない美しさ」を使用します。 
- **カジュアルな会話では使用しないでください:** 非常に堅苦しく聞こえ、道徳的非道を告発します。 カジュアルな同等語: 〜すぎる、〜ひどい。
