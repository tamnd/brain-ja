## 〜に足る / 〜に足らない

 **形式レベル:** 形式/文学 — 形式的な評価、批評、文学的散文

 **古典的な起源:**
 足る (*たる*) は不足る (*たりる*、十分であること) の古典的/文学的な形です。 古典的な形式「足る」は、定型表現の形式的および文語的な日本語で使用され続けています。 〜に足るは「Xに十分/十分である」→「Xに値する」という意味です。 〜に足らない は「Xには足りない」→「〜に値しない/以下」という意味です。 

---

 ## 構造

 | フォーム | 使い方 | 例 |
 |------|-------|-----------|
 | V-dict + に足る | する/受け取る価値がある | 信頼に足る |
 | V-dict + に足らない | |に値しない 問題とするに足らない |
 | 名詞 + に足る/足らない | (稀) | — |

 ---

 ## 意味

 **〜に足る:** 「〜の基準を満たすに値する / 正当化するのに十分な / の基準を満たす」
 **〜に足らない:** 「価値がない / 正当化するには十分ではない / 基準を下回っている」

 ---

 ## 例文

 | 日本語 | 英語 |
 |----------|----------|
 | 彼は信頼**に足る**人物だ。 悲惨な状況でも約束を守る。 彼は信頼に値する人物だ。 彼はどんな状況でも約束を守ります。 |
 | その証拠は、法廷で採用される**に足る**信憑性を持っていない。 証拠には法廷で認められるほどの信頼性がありません。 |
 | 取るに足らない問題に時間費やしのは賢明ではない。 心配する価値のない問題に時間を費やすのは賢明ではありません。 |
 | 彼女の業績は、その後に語り継がれる**に足る**ものだ。 彼女の功績は後世に語り継がれるに値します。 |
 | 敵と負け**に足らない**相手に、力を使う必要はない。 敵とみなすに値しない相手に努力をする必要はない。 |
 | この発言は、真剣に取り組む**に足る**ものではない。 この発言は深刻な反論に値しない。 |

 ## 使用しない場合

 - **カジュアルなスピーチでは使用しないでください:** 「足る」と「足らない」は文語体です。 日常的な日本語: 〜する価値がない、〜にふさわしくない。 
- **「取るに足らない」という定型表現に注意してください:** この定型文は「取るに足りない/取り上げる価値もない」という意味で、定型熟語としてセミフォーマルな文脈でも広く使われています。
