## 〜して

 **形式レベル:** 形式/文学 - 形式的なスピーチ、伝記、文学的散文、学術文書

 **古典的な起源:**
 「して」は、古典日本語の「に」（*ni*、位置助詞）+「して」（古典的な動名詞/「する」の接続詞）に由来します。 古典的な日本語では、「して」は同時の状態や条件を表します。「X の状態にあり、また...」。このパターンは万葉集や平安時代の散文全体に現れます。 現代にしては、この二重状態の機能を保持しており、特定の瞬間またはしきい値の重要性も表現しています。 

---

 ## 構造

 | 使い方 | フォーム | 例 |
 |------|------|-----------|
 | デュアル品質 (X と Y) | 名詞 + して + 名詞/形容詞 | 偉大な哲学者にして政治家 |
 | 同時状態 | 名詞/形容詞 + して | 若くてもう有名 |
 | |のまさにその段階で。 名詞（時間・数字）＋して | 三十歳にして悟った |
 | X の場合でも (強調) | 名詞 + して + 否定 | 天才にして良かった |

 ---

 ## 意味

 〜としてには、関連しつつも異なる 3 つの用途があります。 

1. **二重述語:** 「X であると同時に Y である」 — X と Y は同じ主語に対して同時に真です。 並外れた二重の資質を持つ人を表すのによく使われます。 
2. **段階/閾値:** 「X のまさに段階/時点」 — X (多くの場合、時間、年齢、または立場) は、何かが発生する重要な閾値です。 
3. **偶数を強調:** 「X として誰か/何かにとっても...」 — 次のステートメントをより印象的または驚くべきものにするために、X の極限を強調します。 

---

 ## 例文

 | 日本語 | 英語 |
 |----------|----------|
 | 彼は偉大な哲学者**にして**優れた文学者でもあった。 彼は偉大な哲学者であると同時に、傑出した文学者でもありました。 |
 | 三十歳**にして**やっと自分の天職を見つけた。 30歳になってようやく彼は自分の本当の天職を見つけた。 |
 | 長年の研究者**して** 洞察できなかった謎が、若い学生によって解かれた。 長年研究を続けた研究者ですら解けなかった謎が、若い学生によって解けた。 |
 | 彼女は二十代**にして**すでに業界の重鎮として知られていた。 まだ20代ながら、彼女はすでに業界の重鎮として知られていました。 |
 | 初めての挑戦**して**、優勝という偉業を果たした。 まさに最初の試みで、彼はチャンピオンシップの偉業を達成しました。 |
 | 天才**にして**なお謙虚であることは、まことに稀なことだ。 天才が謙虚さを保つのは本当に珍しいことだ。 |

 ## N2相当品との比較

 | パターン | 登録 | 意味 | 主な違い |
 |----------|------|----------|-----|
 | 〜して | フォーマル/文学 | X であると同時に Y であること。 Xの段階で。 Xでも | 複数の用途。 古典的な優雅さ。 常に高いレジスタ |
 | 〜で/〜であり | すべてのレジスタ | X と... / X と... | 中立結合。 特別な強調やしきい値の意味はありません。 
| 〜ながら | すべてのレジスタ | X をしながら、X でありながら | 同時状態。 矛盾を表現できる。 上昇していない |
 | 〜である途中 | セミフォーマル | 同時に X | 明示的な二重ステートメント。 あまりエレガントではありません。 より明示的な |

 ---

 ## 使用しない場合

 - **カジュアルな会話では使用しないでください:** しては常に登録を高めます。 文学性を高めることを目的としない場合は、通常のフォーマルな文章で「〜で/〜ついでにである」を使用します。 
- **二重述語用法では、否定的な同時状態には使用しないでください。** 二重述語での「して」（哲学者であり作家でもある）の使用は、印象的な性質や補完的な性質を表現する傾向があります。 通常の属性の単純な共起には、〜であり〜でもあるを使用します。 
- **「X でも」の用法には、著しく極端な X が必要です:** ❌ 普通の人にして難しいことだ は、 ❌ → 〜でも難しい よりも自然ではありません。 強調しては、X がその失敗/達成が注目に値するほど十分に印象的であることを要求します。
