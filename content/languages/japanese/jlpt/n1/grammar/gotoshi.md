## 〜ごとし / 〜ごとく

 **形式レベル:** 文学 / 形式 — 文学的な散文、ことわざ、形式的な説明、古典的な引用

 **古典的な起源:**
 「ごとし」は、「好き」または「として」を意味する古典的な日本語の「ごとし」（*如し*）に由来しています。 これは、*万葉集*、*古事記* (*古代事項の記録*、西暦 712 年)、および *日本書紀* (西暦 720 年) など、最古の日本の文書全体に登場します。 日本で読まれる漢文（*漢文*）では、如（*rú*）という文字が比較を表していました。 「ごとし」は、比喩や類推を表す標準的な古典的な日本語表現になりました。 その副詞形ごとく (*ごとく*) と連体形形ごとき (*ごとき*) は、正式な現代日本の散文で今も使用されている文学的な比較を作成します。 

---

 ## 構造

 | フォーム | 機能 | 例 |
 |------|----------|----------|
 | 名詞 + の + ごとし (述語) | 述語の直喩 | 光陰矢の如し |
 | 名詞 + の + ごとく (副詞) | 副詞的直喩 | 矢を飛ぶ |
 | 名詞 + の + ごとき (形容詞) | 名詞修飾子 | 嵐のとき勢い |
 | V-dict + が + ごとし | 言葉による直喩 | 燃えることがごとし |

 ---

 ## 意味

 「X のように / X のように / X のように」 - 形式的で文学的な直喩。 

フォームの違い:
 - ごとし — 述語: 「X のようです」/「X のようです」 (文節の終わり)
 - ごとく — 副詞: 「X のやり方で」 (動詞または形容詞を修飾する)
 - ごとき — 連体形:「X のように」 (名詞を修飾する)

 ---

 ## 例文

 | 日本語 | 英語 |
 |----------|----------|
 | 光陰矢の如し。 歳月は人を待たず。 時間は矢のように過ぎていきます。 何ヶ月も何年も誰も待ってくれません。 (古典のことわざ) |
 | 彼は嵐の**ごとく**が現れ、業界に革命をもたらした。 彼は嵐のように現れ、業界に革命をもたらしました。 |
 | 群衆は波の**ごとき**うねりとともに広場をやり続けた。 波のような波で群衆が広場を埋め尽くした。 |
 | 燃えるが**ごとき**情熱で、彼女は五年間研究に熱心だった。 火のように燃える情熱を持って、5年間研究に打ち込んだ。 |
 | 自分の演説は滔滔たる大河の**ごとく**、聴衆を圧倒した。 彼のスピーチは大河のように聴衆を圧倒した。 |
 | 人の心は鏡の**ごとく**、磨かなければ曇る。 人の心は鏡のように磨かなければ曇ってしまいます。 |

 ## ごとし/ごとくを使った諺

 | ことわざ | 読書 | 意味 |
 |----------|----------|----------|
 | 光陰矢の如し | リスクんやのごとし | 時間は矢のように過ぎていきます |
 | 柔よく剛を制すが如し | 十分ごうをせいすがごとし | 柔らかいものは硬いものに勝つ（石よりも水） |
 | 命は風前の灯火の如し | いのちはふうぜんのともしびのごとし | 人生は風に揺れるキャンドルのようなもの |
 | 百聞は一見に如かず | ひゃくぶんはいっけんだけず | 一度見ることは百回聞くことよりも優れています |

 ## N2相当品との比較

 | パターン | 登録 | 意味 | 主な違い |
 |----------|------|----------|-----|
 | 〜ごとし/ごとく | 文学/フォーマル | まるで/まるでのよう (古典的な直喩) | クラシック; 文学的な優雅さ。 ことわざ、文学的散文で使用される |
 | 〜みたいに/〜みたいな | カジュアル | 似ている/似ている | とてもカジュアルです。 会話 |
 | 〜ように/〜ような | すべてのレジスタ | まるで/のように | 中性; あらゆる状況における一般的な比較 |
 | 〜かのように/〜かのような | セミフォーマル | あたかも/あたかも | 仮定法/仮説比較。 「ように」よりもニュアンスが異なります。

 ## 使用しない場合

 - **カジュアルな会話では「ごとし/ごとく」を使用しないでください:** これらの形式は、すぐに文学的登録を示します。 スピーチでは「ように」または「みたいに」が適切です。 
- **「ごとき」を、「～など」（軽蔑的）を意味する助詞「ごとき」と混同しないでください。** 現代の日本語の話し言葉では、「こんなごとき」は否定的な意味合い（「～のようなもの」）を含むことがあります。 文語比較フォーム「ごとき」は使用方法と登録方法が異なります。 
- **形式要件:** ごとき (前名詞) は名詞を修飾します。 ごとく（副詞）は動詞/形容詞を修飾します。 「ごとし」は文節を終了します。 これらは交換可能ではありません。
