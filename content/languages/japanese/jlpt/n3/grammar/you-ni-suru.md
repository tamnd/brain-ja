## パターン: 〜する

 **構造:**
 - 動詞 (辞書形式) + する → 「～をしようとする、～をするように心がける」
 - 動詞（否定がない） + する → 「～をしないようにしてください、～をしないようにしてください」

 **形式:** 標準 (口頭および書面)

 **意味:** 「～するために努力する、～を確実にするよう努める、～を主張する」

 ## 説明

 〜するようには、何かを実現したり、何かを回避したりするための*持続的で意図的な努力*を表します。 単一の意図的な行動 (〜ようとする) とは異なり、このパターンは *継続的な習慣的な努力*、つまりライフスタイルやルーチンの一部として継続的に行おうとしていることを表します。 

進行形〜ようしているは、最も一般的で自然な形式です。「私は〜しようとします / 私はポイントを作ります」。 

否定: 〜しない — 「〜しないようにしてください、〜しないようにしてください」

 ## 例文

 | 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 健康のために、毎日野菜を食べているように。 けんこうのために、まいにちやさいを食べられるようにしています。 健康のために、毎日野菜を食べているよ。 | 健康のために、私は毎日野菜を食べるようにしています。 |
 | |遅刻しないように、早めに家を出しました。 ちこくしせずに、はやめにいえをでした。 知国しないようにして、はやめに家をでた。 | 私は遅刻しないように早めに家を出ました。 |
 | | 次の本を読むようにしようと思います。 次ほんをよむようにしましょう。 もっと本を読んでみようと思う。 | もっと本を読んでみようと思います。 |
 | 仕事中、スマホを見ないようにしています。 しごとちゅう、すまほを見ないようにしている。 仕事中、スマホを見ているようになってます。 | 仕事中はスマホを見ないようにしています。 |
 | 毎晩7時間寝ています。 まいばん7じかんねできるようにしています。 マイバン7時間ねるよにしています。 | 私は毎晩7時間寝るようにしています。 |

 ## よくある間違い

 (完了した過去 — 継続的ではなく、単一の決定のように聞こえます)
 ✓毎日運動しているようにしている。 — 継続的な努力には〜を使用します。 

❌ 彼女に電話するようにしました。 (「彼女に電話した」のつもり)
 ✓ 彼女に電話した。 — 完了した単一のアクションには単純な過去を使用します。 

## 類似パターンとの比較

 | パターン | 意味 | 進行中ですか？ |
 |----------|----------|----------|
 | 〜するように | 意図的な継続的な努力 | はい |
 | 〜ようになる | 変化の結果（起こった） | — (結果の状態) |
 | 〜ようとする | 試し中/試行中 (進行中) | 1 回の試行 |
 | 〜ことにする | ～することを決める（決断） | 決定のみ |
 | 〜にしている | ～することを規則にしました | 確立されたルール |
