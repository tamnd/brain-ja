## パターン: 〜て以来

 **構造:** 動詞 (TE 形) + それ以来 / 名詞 + それ以来

 **フォーマルさ:** 標準からフォーマルまで

 **意味:** 「～以来、～以来[状態は現在まで続いている]」

 ## 説明

 「〜て以来」は、過去の転換点以来*状態や状況が途切れることなく続いていることを表します。 それは常に現在の瞬間から変化を引き起こした特定の過去の出来事を振り返り、その時に確立された変化が現在も進行中であることを暗示します。 

主な特徴:
 - 過去の出来事が *ターニングポイント*
 - 以下の状態が*現在まで続いています*
 - 感情的な重みを伴うことが多い（懐かしさ、後悔、決意）
 - 第 2 節は通常、現在進行形 (〜ている、〜ていない) です。 

## 例文

 | 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 日本に来て以来、日本語を勉強し続けています。 にほんにきらい、にほんごをべんきょうし続けている。 日本に来て、日本を勉強して続けています。 | 日本に来て以来、私は日本語を勉強し続けています。 |
 | 彼女と別れて以来、連絡を取っていません。 かのじょとわかれてい、れんらくをとっていない。 彼女とわかれていない、恋愛を言っていない。 | 別れてからは連絡を取っていません。 |
 | あの事故以来、車を運転するのが怖くなった。 そのじこいらい、くるまをうんてんするのがこわくなった。 その時、車を運んでくるのが怖かった。 | あの事故以来、私は運転するのが怖くなってしまいました。 |
 | 大学を卒業して以来、故郷に帰っていない。 だいがくをそつぎょうしてます、こきょうにはいません。 大学を卒業していない、高校には行っていない。 | 私は大学を卒業して以来、一度も地元に帰っていません。 |
 | | 任天堂のころ以来、彼に会っていない。 こどものころい、かれにあっていない。 こどものころいらない、かれにあってない。 | 私たちが子供の頃以来、彼に会ったことがありません。 |

 ## よくある間違い

 ❌昨日以来、元気だ。 (期間が短すぎます — 以来、継続的な状態が延長されていることを意味します)
 ✓ 回復して以来、ずっと元気だ。 — 以来とは、かなりの期間にわたって続いた状態を指します。 

❌ 日本に来て以来、来週旅行する。 
✓ 日本に来て以来、旅行していない。 — 結果節は進行中の現在の状態を説明する必要があります。 

## 類似パターンとの比較

 | パターン | 意味 | 期間 | 例 |
 |----------|-----------|----------|-----------|
 | 〜て以来 | 以来 (過去からの継続状態) | 現在まで延長 | 卒業して以来会ってない |
 | 〜てから | ~ を実行した後 (次のアクション) | 継続的ではありません | 食べてから出かけた |
 | 〜てから〜している | ～をやってから（継続中） | 以来と重複する可能性があります | 来てからずっと雨だ |
 | 〜ぶりに | インターバル後（復帰） | ギャップ+再会 | 3年ぶりに会った |
