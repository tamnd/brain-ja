## パターン: 〜のため(に)

 **構造:**
 - **目的:** 動詞（辞書形式） + ために → 「～するために」
 - **原因:** 動詞 (過去の「た」) + のために / 名詞 + の + ため(に) → 「〜のせいで、〜のせいで」

 **形式性:** フォーマル / 標準 (フォーマルな文章では「から/ので」よりも好まれます)

 **意味:** 目的: 「～するため」 / 原因: 「～のため、～のため」

 ## 説明

 重要な違いは、「ために」の前の **動詞時制** によって決まります。 
- **辞書形式** (非過去) + ために → **PURPOSE**: 「X は Y を達成するという目標を持って行われます」
 - **過去形(た)** + のために or **名詞 + の + ため** → **原因**: 「X が起こったので、Y が生じました」

 フォーマルな文書 (レポート、新聞、学術文書) では、原因を表現するために「から」や「ので」よりも「〜のため」が強く好まれます。 より客観的で中立的に聞こえます。

 ## よくある間違い

 ❌ 雨が降るために、試合が中止になった。 (間違っています — 原因に使用される辞書形式)
 ✓ 雨が降ったために、試合が中止になった。 — 理由として、動詞は過去形でなければなりません。 

❌ 疲れたために、早く帰りたい。 (不自然 — 個人的な欲望のため、堅苦しく聞こえます)
 ✓ 疲れたので、早く帰りたい。 — なので、個人的な主観的な理由で使用します。 

## 類似パターンとの比較

 | パターン | 使用 | フォーマル |
 |----------|-----|----------|
 | 〜のために（目的） | 目標/意図 | フォーマル/ニュートラル |
 | 〜のために（原因） | 客観的な原因 | フォーマル (書面での方が望ましい) |
 | 〜から | 主観的な個人的な理由 | カジュアルニュートラル |
 | 〜なので | 丁寧で客観的な理由 | 礼儀正しい/中立的 |
 | 〜によって | 原因・手段・原因 | フォーマル (受動的なコンテキスト) |
