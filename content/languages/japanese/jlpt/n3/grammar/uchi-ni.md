## パターン: 〜うちに

 **構造:**
 - 動詞（いる/辞書）+うちに→「[状態が続く間]」
 - I-adj + うちに / Na-adj + な + うちに / 名詞 + の + うちに
 - 動詞（否定がない） + うちに → 「[何かが起こる前に]」

 **形式:** 標準 (話し言葉と書き言葉の両方)

 **意味:** 「～の間、～が起こる間、手遅れになる前に/～が起こる前に」

 ## 説明

 〜うちには、*終了が予想される時間枠内*に実行されるアクションを表します。 暗黙のニュアンスは緊急性です。Y は永遠に続くわけではないので、条件 Y がまだ維持されている間に X を実行してください。 

2 つの用途:
 1. **肯定:** 「若いうちに」(若いうちに) — (若いという状態は) 必ず終わるので、今すぐ行動しましょう
 2. **ネガティブ (〜ないうちに):** 「忘れないうちに」(忘れる前に) — 望ましくない出来事が起こる前にやること

 このパターンは「〜とき」とは異なります。「〜うちに」は常に窓が *一時的* であり、話者がその限界を認識していることを意味するからです。

 ## よくある間違い

 ❌勉強しているうちに、試験を受けました。 (時間的な偶然であり、「窓」のニュアンスではありません)
 ✓ 勉強しているうちに、日本語が楽しくなりました。 — うちには、状態が変化するか終了すると予想される場合に最適に機能します。 

## 類似パターンとの比較

 | パターン | 意味 | 例 |
 |----------|----------|----------|
 | 〜うちに | 機会の窓 (期間限定) | 若いうちに行動しよう |
 | 〜あいだ(に) | 期間中（中立） | その間寝てしまった |
 | 〜とき(に) | When ~ (中立時間マーカー) | 安心のとき、海外に住んでいた |
 | 〜前に | ～の前に（シンプルオーダー） | 寝る前に歯を磨く |
