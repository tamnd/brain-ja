## パターン: 〜得る / 〜承

 **構造:**
 - 動詞 (ます語幹) + 得 (*える* or *うる*) → 「～できる可能性がある、～であることが考えられる」
 - 動詞（ます語幹） + まさか（*enai*）→「～はありえない、～であることは考えられない」

 **形式:** 正式 / 書面 (カジュアルな同等物: ある / ありえない)

 **意味:** 〜得: 論理的・理論的可能性 / 〜いけない: 論理的不可能性

 ## 説明

 〜得る（潜在的な形で「えられる」、あるいは接尾辞として単に「える/うる」と発音される）は、*論理的または理論的な可能性*を表します。「これは潜在的に起こる可能性があります/そうなる可能性があります。」 それは身体的な能力 (〜できる) や許可の問題ではなく、何かが理性や論理の範囲内で *考えられる*かどうかです。 

〜恐るは否定語です。「これは論理的に、または本質的に不可能です」。 

**発音:**
 - 得る (独立動詞): おえる/うる
 - 接尾語として: 動詞-ます-語幹 + える (口語) または うる (形式的/文学的)
 - まさか: ありません

 これらのパターンは形式的なもので、執筆、分析、学術的な文脈に現れます。 カジュアルな会話では、「ありえる / ありえない」を使用します。 

## 例文

 | 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | そのような事態は十分にあり得る。 そのようなじたいはじゅうぶんおこりできる。 そのような状況は十分にある。 | このような状況は十分に起こり得る。 |
 | 彼が嘘をつくとは考えた。 かれがうそ作るとはええない。 彼が嘘をついてはカンガエナイ。 | 彼が嘘をつくとは考えられない。 |
 | このような事態は既に起こっているはずだ。 こんなじたいは起こせないはずだ。 このような状況は起こりえないはずだ。 | そのような状況は起こり得ないはずです。 |
 | 完全な解決などありえない。 かんぜんなかいけつなどありえない。 カンゼンナカイケツナドアリエナイ。 | 完全な解決策はまったく不可能です。 |
 | この方法では成功しません。 このほうほうではせいこうしません。 このほほうでわせいこうしえません。 | この方法で成功するのは不可能です。 |

 ## よくある間違い

 ❌ 私は泳ぎ得ます。 (「私は泳ぐことができます」のつもりです — これは不自然に聞こえます)
 ✓ 私は泳げる。 — 個人の能力には潜在的な形 (〜できる/〜える/〜される) を使用します。 

(フォーマルとカジュアルのぎこちない混合)
 ✓ ありませんか？ または あります。 — カジュアルな会話では、ありえるはスタンドアロンとして正常に機能します。 

## 類似パターンとの比較

 | パターン | 意味 | フォーマル |
 |----------|----------|----------|
 | 〜を得る | 論理的可能性 (形式的) | フォーマル/書面 |
 | ある/ない | 考えられる/考えられない | カジュアルニュートラル |
 | 〜できる/〜できない | 身体能力・許可 | ニュートラル |
 | 〜はずがない | 論理的に不可能（より強力） | ニュートラルフォーマル |
 | 〜わけがない | 不可能（発言者の確信） | ニュートラル |
