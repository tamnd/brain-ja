## パターン: 〜に対して / 〜に対して

 **構造:** 名詞 + に対して / 名詞 + に対する + 名詞 (連体詞)

 **フォーマルさ:** 標準からフォーマルまで

 **意味:** 「～に対して、～に対して、～とは対照的に、～に応じて」

 ## 説明

 〜に対しては、アクション、態度、または比較の対象となる *ターゲットまたはオブジェクト* をマークします。 単純な助詞「〜に」（方向または間接的な対象を示す）とは異なり、「〜に対して」は、対象に向けられた *反応またはスタンス* を特に強調します。 主な用途は次の 3 つです。 

1. **対象者に対する態度・対応** 「批判には応える」「生徒には親切にする」
 2. **コントラスト:** 「A と比較すると、B は ~」
 3. **何かに向けられた政策/措置:** 「～に向けた措置」

 連体形〜に対しては名詞の前に置きます：「批判に対する返答」（批判に対する返答）。 

## 例文

 | 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 彼は批判に対して冷静に答えた。 カレはひはんにたいしてれいせいにこたえた。 彼は非日常を愛していた。 | 彼はその批判に対して冷静に答えた。 |
 | 自主に対する教育方針を見直す必要がある。 |こどもにしたいきょういくほうしんをみなおすひつようがある。 こどもにたいする教育保健をみなおすひつよがいる。 | 子どもたちに対する教育政策の見直しが必要だ。 |
 | 収入に対して、支出が多すぎる。 しゅにゅうにしたいして、ししゅつがおおすぎる。 思春期にたいして、思春期が大杉る。 | 収入に比べて支出が多すぎる。 |
 | 新しい政策に対して、国民からの反発があった。 しんせいさくにしたいして、こくみんからはんぱつがあった。 新制作に取り組んで、国民からの出発があった。 | 新しい政策に対して国民からの反発があった。 |
 | 先生に対して礼儀正しく話すべきだ。 | せんせいにたいしてれいぎならばくはなすべきだ。 先生に会いに来てほしいんだ。 | 教師に対しては丁寧に話す必要があります。 |

 ## よくある間違い

 ❌彼に対して好きです。(「彼が好き」のつもり)
 — 〜に対しては、人に関する個人的な感情/感情には使用されません。 

(気まずい — 困っているのは内部状態です)
 ✓ 問題にお困りです。 — 内部状態には単純な 〜 を使用します。 

## 類似パターンとの比較

 | パターン | 意味 | 例 |
 |----------|----------|----------|
 | 〜に | 大まかな方向性・目標 | 友達に話す (友達に話す) |
 | 〜に対して | 指示されたスタンス/応答/コントラスト | 友達の発言に対して全般する (友達の発言に反論する) |
 | 〜に向けて | (目標/目標) に向けて | 目標に向かって努力する | 目標に向かって努力する
