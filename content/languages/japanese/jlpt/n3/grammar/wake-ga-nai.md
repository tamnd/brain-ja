## パターン: 〜わけがない / 〜わけはない

 **構造:**
 - 動詞 / 形容詞 / 名詞 + わけがない
 - 共通: 平文 + わけがない

 **形式:** 標準 (口頭および書面)

 **意味:** 「～なんてありえない、～なんてありえない、～する理由がない」

 ## 説明

 〜わけがないは、何かが*論理的または根本的に不可能*であるという話者の強い確信を表します。 「わけ」は「理由/論理」を意味するため、わけがないは文字通り「これが事実である論理的理由がない」という意味です。 これは、状況は考えられないという発言者の個人的な評価を反映しています。 

これは、「〜はずがない」（期待に焦点を当てている）より *強い* もので、「〜わけではない」（不可能ではなく、部分否定である）とは異なります。 

口語: わけないじゃん / わけないよはカジュアルな形です。 

## 例文

 | 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 彼がそんなことをするわけがない。 あれがそんなことをするわけがない。 彼がそんなことをするわけがない。 | 彼がそんなことをするはずがない。 |
 | こんな難しい問題が解けるわけがない。 どうも困ってもいないがとけるわけがない。 こんなムズカシイモンダイがわかるわけがない。 | そんな難しい問題を私に解けるわけがない。 |
 | 練習もしないで上手になれるわけがない。 れんしゅうもしないでじょうずになれるわけがない。 錬州もしないで上手になれるわけがない。 | 練習しないで上達するわけがない。 |
 | 彼女がそんな嘘は作れない。 かのじょがそんなそう作ってない。 カノジョがそんな嘘をつくわけがない。 | 彼女がそんな嘘をつくはずがない。 |
 | 一日で日本語をマスターできるわけがない。 |いちにちでにほんごをますたーできるわけがない。 Ichinichi de Nihongo o masuta dekiru wake ga nai. | 日本語を一日でマスターできるわけはありません。 |

 ## よくある間違い

 ❌ 「わけがない」と「わけではない」を混同する:
 - わけがない = 論理的に/完全に不可能 (「ありえない」)
 - わけではない = 部分的に否定（「それは私〜ではありません」）

 ## 類似パターンとの比較

 | パターン | 強さ | 例 |
 |----------|----------|----------|
 | 〜わけがない | 不可能性が強い（発言者の確信） | 彼が嘘をつくわけがない |
 | 〜はずがない | すべきではありません (論理的な期待は否定されます) | 彼がここにいるはずがない |
 | 〜わけではない | 部分否定（完全否定ではない） | 嫌いじゃない |
 | 〜覚悟 | 論理的に不可能（形式的/書面） | 解決しなければ問題 |
