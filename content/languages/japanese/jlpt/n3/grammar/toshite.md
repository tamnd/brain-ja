## パターン: 〜として / 〜としての / 〜とした

 **構造:**
 - 名詞 + として + [述語/動作]
 - 名詞 + としての + 名詞（連体詞）
 - 名詞 + とした + 名詞 (連体形、多くの場合「～を基準とする」)

 **フォーマルさ:** 標準からフォーマルまで

 **意味:** 「～として、～の立場で、～の役割を果たし、～を～として扱う」

 ## 説明

 〜としては、誰か/何かが行動する、またはみなされる*役割、能力、アイデンティティ、機能、または基礎*を示します。 一般的な用途:

 1. **役割または職業:** 「専門家として参加する」— 専門家として参加する
 2. **機能または目的:** 「証拠として使う」— 証拠として使用する
 3. **前提または根拠:** 「前提として」— 前提として取る
 4. **一般規則/基準:** 「原則として」— 原則として、原則として

 〜としての＋名詞の形で「教師としての責任」と連体詞になります。 

## 例文

 | 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 彼は専門家として、会議に参加しました。 かれはせんもんかとして、かいぎにさんかしました。 彼はセンモンカとシテ、カイギニサンカシタ。 | 彼は専門家として会議に参加した。 |
 | 日本代表として大会に出場する。 にほんのだいひょうとしてたいかいにしゅつじょうする。 日本の大評とシテ大会議に合格する。 | 日本代表として出場します。 |
 | 一般的なルールとして、遅刻は禁止されています。 いっぱんてきなるとして、ちこくはきんしされている。 イッパンテキなルールとシテ、チコクはキンシサレテいる。 | 原則として遅刻は禁止です。 |
 | 教師としての責任を果たした。 きょうしとしてのせきにんをはたしました。 京師とシテの関人を旗下しました。 | 教師としての責任を果たしました。 |
 | この問題を前提として、計画を立てた。 このもんだいをぜんとして、けいかくをたてた。 このモンダイをゼンテイにして、ケイカクを立てた。 | 私はこの問題を前提として計画を立てました。 |

 ## よくある間違い

 ❌ 私は先生として好きです。 (不自然 — 好き/嫌いと直接組み合わせることができません)
 ✓ 先生としての彼が好きです。 または彼を先生として尊敬しています。 

❌ これをとして使う。 (としてはその前に名詞が必要です)
 ✓ これを証拠として使う。 

## 類似パターンとの比較

 | パターン | 意味 | 例 |
 |----------|----------|----------|
 | 〜として | 役割・能力・機能 | 専門家として話す |
 | 〜に | 間接的なオブジェクト/方向 | 彼に話す (彼と話す) |
 | 〜のように | 類似 (「〜のような」) | 先生のように話す (先生のように話す) |

 **注:** 〜としては実際の役割またはアイデンティティを示します。 〜のように類似性や態度を表します。
