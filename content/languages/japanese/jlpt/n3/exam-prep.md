JLPT N3 は年 2 回（7 月と 12 月）開催され、N4 よりも戦略的な準備が必要です。 リーディングセクションは大幅に長くなり、リスニングパッセージはより速く、より自然になり、文法問題では単なる認識ではなくニュアンスがテストされます。 このページには、試験前の最後の 90 日間に必要なものがすべて記載されています。 

## N3 試験形式

 | セクション | 時間 | ポイント | パスしきい値 |
 |----------|------|----------|-----|
 | 言語知識（語彙） | 30分 | 0 ～ 60 ポイント | ≥ 19 ポイント |
 | 言語知識（文法）+読解 | 70分 | 0 ～ 60 ポイント | ≥ 19 ポイント |
 | リスニング | 40分 | 0 ～ 60 ポイント | ≥ 19 ポイント |
 | **合計** | **140 分** | **0 ～ 180 ポイント** | **合計 95 点以上 + 各セクションで 19 点以上** |

 **キーポイント**: 3 つのセクションすべてを個別に通過し、合計 95 点に達する必要があります。 リスニングのスコアが高くても、語彙のスコアの低下を補うことはできません。

 ## セクション 1: 言語知識 — 語彙 (30 分、約 35 問)

 ### 質問の種類

 **1. 漢字の読み方** (漢字の読み方): 下線付きの単語の正しいひらがな読みを選択してください。 
- 焦点: 2 ～ 3 の漢字熟語。 一般的だが明白ではない読み取り
 - 検証例：経済、政策、調査、環境、統計、判断

 **2. 正書法** (表記): ひらがなで読む場合、正しい漢字を選択してください。 
- 注目: 似ている漢字。 他動詞/自動詞のペア
 - 一般的なトラップ: 変わる vs 変える、増える vs 増やす

 **3. 語形成** (語形成): 複合語を完成させるか、適切な接辞を選択します。 
- フォーカス: 〜化、〜的、〜性、〜感の接尾辞。 〜化化合物、特に

 **4. 文脈上の定義** (迷規定): 文脈に基づいて空白に最適な単語を選択してください。 
- 焦点：抽象名詞（条件、場面、判断、印象）。 同義語の区別

 **5. パラフレーズ/類義語** (概要類義語): 下線付きの単語に意味が最も近い単語を選択してください。 
- 焦点: 利用する ↔ 使う、依頼する ↔ お願いする

 **6. 用法** (用法): 下線付きの単語を正しく使用している文を選択してください。 
- 焦点: 使用上の微妙な制限がある動詞と形容詞

 ### 試験で優先度の高い語彙

 **抽象名詞 (ほぼ常にテストされます)**:
 意識、感覚、印象、判断、想像、記憶、理解、認識、表現、主張、可能性、条件、限界、価値、根拠

 **社会/制度名詞**:
 政治、経済、環境、制度、規則、責任、義務、権利、組織、文化、伝統

 **仕事上の語彙**:
 採用、退職、出張、残業、昇進、上司、部下、同僚、担当、報告、連絡、相談、提案

 **試験でよく混同されるペア**:

 | 単語A | 単語 B | 主な違い |
 |--------|--------|----------------|
 | 意見（個人的な意見） | 主張 (強い主張/主張) | 主張はより強力です |
 | 理由（記載された理由） | 原因 (根本的な原因) | 理由 = なぜそう言うのか。 原因 = 根本原因 |
 | 目的（目的・目的） | 目標 (ターゲット/目標) | 目的 = なぜ; 目標 = 具体的に何を達成するか |
 | チャンス（機会） | 場合 (事例/状況) | 機会 = するチャンス。 場合 = 状況が発生した場合/いつ |
 | 結果 (結果) | 成果（成果・成果） | 成果は積極的な努力を意味します。 
| 方法（メソッド） | 手段（手段/方法） | 手段はより手段的/実用的になる可能性があります。 
| 実現（実現） | 達成 (達成) | 実現 = 実現すること。 達成 = 目標を達成する |
 | 増えました (経由) | 増 (trans.) | 人口が多い vs 収入を増やす |
 | 続き（翻訳） | 続ける | 雨が続く vs 勉強を続ける |
 | 変わる | 変える (trans.) | 天気が変わる vs 計画を変える |

 ### 語彙ドリル — 20 の質問

 各空白に最適な単語を選択してください:

 1. 新しいプロジェクトに ___ を持って戦っている。 
2. いけない ___ は非常に説得力があった。(主張 / 意見 / 考え)
 3. この問題を解決するための ___ を考えてください。(方法 / 手段 / 場合)
 4. 申し訳ありませんが、この件については ___ できません。 
5. 雨が__、試合が中止になった。(ために / によって / せいで)
 6. 部長はいつも ___ に考えてから判断する。(注意 / 注意 / 丁寧)
 7. 状況 ___対応を変えることが大切だ。 
8. 先生の言葉が__になって、諦めずに続けることができました。 
9. 売上が___ならぬ、コストは増え続けている。(減少した / 落ちた / 低下した)
 10. 彼女は英語 ___ フランス語も話せます。 (だけでなく / しか / ばかり)

 *(答え: 1.活発 2.主張 3.方法 4.承知 5.によって 6.注意 7.に応じて 8.きっかけ 9.減少した 10.だけでなく)*

 ## セクション 2: 言語知識 - 文法 (70 分のセクションの一部)

 ### 文法問題の種類

 **1. 文法 1** (文の文法 1): 空白に最適な文法形式を選択してください。 
- 4 つのオプション; 意味とパターンのつながりの両方を知る必要があります
 - 最も一般的なトラップ: パターンの後のパーティクル (〜に対して vs 〜に対して)

**2. 文法 2** (文の文法 2): 4 つのごちゃ混ぜなフレーズを一貫した文に再配置します。 
- 文法パターンが長文にどのように適合するかをテストします。 
- 戦略: まず主要な動詞を見つけてから、逆方向に作業します。 

**3. テキスト文法** (文章の文法): 空白を含む短い文章。 コンテキストに合ったものを選択してください。 
- 談話レベルの理解をテストします — 一貫性、論理的流れ
 - 空白の前後の文からヒントを探します

 ### 最もテストされた N3 文法の区別

 #### グループ 1: 形式前置詞 — 「によって / について / において / に対して / にとって」

 | パターン | コアの使用 | 例 |
 |----------|----------|----------|
 | 〜によって | によって / により / に応じて | この法律によって、権利が守られる |
 | 〜について | について / について | 環境問題について話し合った |
 | 〜において | in / at (正式な場所/ドメイン) | 会議において重要な決定がなされた |
 | 〜に対して | に向かう / 反対する / と比較して | に対して批判的、冷静に答えた |
 | 〜にとって | | の観点から / のために 私にとって、健康が一番大切だ |

 **試験のヒント**: 空白の後に何が来るかを見てください。 関係節 (〜する + 名詞) の場合は、連体形が必要です: による / における / に対する / にとっての。 

#### グループ 2: 因果 — から / ので / のために / によって

 | パターン | 登録 | 主な特長 |
 |----------|----------|---------------|
 | 〜から | カジュアル | 主観的。 コマンドの前に置くことができます |
 | 〜なので | 礼儀正しい | 理解を求めます。 コマンドはありません |
 | 〜のために | 公式/書面 | 中性; 原因または目的 |
 | 〜によって | フォーマル | エージェントまたは原因。 パッシブ構造 |

 **試験の罠**: 〜からは、だなしでな形容詞または名詞の後に直接続けることはできません:
 - ✓病気だから休む / 便利だから使う
 - ✗ 便利から使う (誤)

 #### グループ 3: 条件文 — と / たら / ば / なら

 | パターン | キーの使用 | ... と一緒に使用することはできません |
 |----------|----------|--------|
 | 〜と | 事実。 自動結果 | リクエスト、提案（くださいなど） |
 | 〜たら | 順序; 発見 | — (最も柔軟) |
 | 〜ば | 仮説 | 主節の感情や状態が不自然に感じられる場合がある |
 | 〜なら | トピック条件 | 条件 | の前に発生したアクション

 **古典的な試験の罠** (〜と):
 - ✗ 右に曲がると、教えてください。 (間違っています - 要求を与えることができません)
 - ✓ 右に曲がると、駅がます。 (自然な結果 = 正しい)

 #### グループ 4: 範囲/範囲 — さえ〜ば / だけでなく / だけか / 留意

 | パターン | 意味 | 方向 |
 |----------|----------|----------|
 | 〜さえ〜ば | X だけであれば十分です | 最低条件 |
 | 〜だけでなく | XだけでなくYも | 拡張 |
 | 〜ばかりか/〜ばかりでなく | X だけではありません (より強調) | 拡張 (強調) |
 | 〜気づき | X からは遠い (Y です) | 矛盾・逆転 |

 **主な違い: だけか vs 注目**:
 - ばかりか: 「X だけでなく Y も」 (Y は追加の、驚くべきものです)
 > 日本語だけか、英語も話せます。 — 日本語だけでなく英語も話せます。 
- 予告: 「X とは程遠い、実際には Y です」 (Y は X と矛盾します)
 > 良くなるどころか、悪化した。 

#### グループ 5: 義務/不可能 — わけだ / わけではない / わけがない / わけにはいかない

 | パターン | 意味 |
 |----------|----------|
 | 〜わけだ | 当然そうなる。 つまり; 不思議ではありません |
 | 〜わけではない | そういう意味ではありません。 必ずしもそうではない |
 | 〜わけがない | 方法はありません。 論理的に不可能 |
 | 〜わけにはいかない | できません (社会的/道徳的義務によりそれが妨げられます) |

 **メモリーフック**:
 - わけだ = 「...それは理にかなっています」
 - わけではない = 「...しかし完全にではない / 必ずしもではない」
 - わけがない = 「...まさか! 論理的に不可能です」
 - わけにはいかない = 「...したくても、すべきではない/できない」

 ### 文法穴埋めドリル — 20 問

 最適な文法表現を選択してください:

 1. 日本の文化 ___ 深く理解したいと思っている。(について / において / によって)
 2. 彼女は一人暮らしを始めた ___ 、料理が上手になった。(一緒 / きっかけに / によって)
 3. 飽きていて疲れても、仕事を休む ___ 。(わけにはいかない / わけがない / わけではない)
 4. あの選手があんなミスをする ___。信じられない。 (わけではない / わけがない / わけにはいかない)
 5. 努力 ___ 、夢は必ず叶う。 (さえあれば / だけでなく / によって)
 6. 雨が降る ___ 、試合が中止になります。(と / たら / なら) [自然な自動結果]
 7. 国際化が進む ___ 、日本語教育も変わってきた。 
(に反している / について / に応じている) [否定的な意味]
 9. この仕事は給料が低い ___ 、残業も多い。 
10. 勉強すれば ___ 、成績が上がる。 

*(答え: 1.について 2.きっかけに 3.わけがない 4.わけがない 5.さえあれば 6.と 7.勝手 8.に反している 9.上に 10.するほど)*

 ## セクション 3: 読解 (70 分のセクションの一部)

 ### N3 リーディングセクションの構造

| テキストタイプ | 長さ | 質問 | 戦略 |
 |----------|----------|---------------|----------|
 | 短い文章 (短文) | 最大 100 文字 | 2 | よく読んでください。 両方答えてください |
 | 中パッセージ (中文) | 最大 200 文字 | 3 | 最初にスキミングします。 スキャンして答えを探します |
 | 長い文章 (長文) | ~350 文字 | 4 | 構造を読み取ります。 立ち往生しないでください |
 | 情報検索（情報検索） | 表/注意事項 | 2 | 特定の情報をスキャン |

 ### 時間予算: 70 分のセクション

 | タスク | 推奨時間 |
 |------|---------------|
 | 文法に関する質問 (11 ～ 15 項目) | 20分 |
 | 短い読書の一節 | 10分 |
 | 中程度の読書文章 | 15分 |
 | 長い読書の一節 | 15分 |
 | 情報検索 | 5分 |
 | チェック/バッファ | 5分 |

 ### 質問タイプ別の回答戦略

 **「作家の要点は何ですか?」**
 →各段落の最後の文と最終段落を確認してください。 日本語の正式な文章は最後に要点を述べます。 

**「この文脈での〜はどういう意味ですか?」**
 →前後の文を読み直してください。 言い換えシグナルを探してください:「なんとなく、想像すると、つまり」。 

**「パッセージに関する正しい記述を選択してください」**
 → 極端すぎる選択肢（常に/決してない）、または本文にない情報を含む選択肢は削除します。 JLPT では、外部の知識が必要なことを試験することはほとんどありません。 

**「なぜ筆者は X について言及したのですか?」**
 → 通常は例を示すため (たとえば X の前)、または主張を裏付けるためです。 X の前にどの接続詞があるかを確認します。 

### パッセージを読む練習

 **パッセージ A** (最大 150 文字):

 > 日本では、昔から「はたらく」という言葉に「傍を楽にする（はたを楽にする）」という意味があると言われている。 

**質問**:
 1. この一節によると、「はたらく」（働く）の伝統的な意味は何ですか?
 a) 自分のためにお金を稼ぐ
 b) 周りの人を快適にする
 c) 政府を助ける
 d) 個人的な目標の達成

 2. 著者は現代の仕事におけるどのような問題を指摘していますか？ 
a) 人々は伝統的な意味を知りません
 b) 長時間労働と精神的プレッシャーにより人々は疲弊している
 c) 労働者は他人の快適さを重視しすぎている
 d) 企業は伝統的な考え方を重視しない

 *(答え: 1. b、2. b)*

 **パッセージ B** (最大 200 文字):

 >、日本の若者の間で「タイムパフォーマンス」、略して「タイパ」という概念が注目されている。これは、ある問題に費やした時間に対して得られる満足度や成果を重視する考え方だ。最近動画を倍速で見たり、概要を読んだりすることがその、代表的な例だ。この傾向には賛否両論がある。 

**質問**:
 1.「taipa」（タイパ）とは何ですか？ 
a) 新しいタイプのエンターテイメント
 b) 費やした時間当たりの満足感・成果を重視する
 c) 動画を倍速で見る
 d) 日本の読書における新たな傾向

 2. この文章で言及されていない見解はどれですか?
 a) 情報を得る効率的な方法です
 b) 若者はこの方法でお金を使わなくなります
 c) 物事に深く関わる機会が失われる可能性がある
 d) 支持者も批判者もいる

 *(答え: 1. b、2. b)*

 ## セクション 4: リスニング (40 分、約 36 問)

 ### N3 リスニングセクションの構造

 | パート | タイプ | カウント | メモ |
 |------|------|------|------|
 | パート 1 (課題理解) | 対話 + 次に何をするか | ~6 | その人がすべきことを選択してください |
 | パート 2 (ポイント理解) | 対話 + スピーカーの発言 | ~6 | キーの内容を特定する |
 | パート 3 (概要理解) | モノローグ+一般的な話題 | ~3 | 要点を理解する |
 | パート 4 (即時応答) | 短い質問 → 最良の回答 | ~12 | 非常に迅速 — 3 秒で選択 |
 | パート 5 (統合理解) | 長い対話 + 複数の質問 | ~4 | 会話ごとに 2 つの質問 |

 ### N3 におけるリスニングの主な課題

 1. **自然な発話速度**: N3 のリスニングは N4 よりもかなり高速です。 
2. **埋め込まれた質問**: 質問は表面的な内容だけでなく、話者の *理由* や *感情* について尋ねます。 
3. **2 人の話者の曖昧さ回避**: 複数人での対話では、どの人が何を言ったかを追跡します。 
4. **ネガティブ + ネガティブ = ポジティブ**: 「〜はない」 = 完全に嘘ではない
 5. **条件の罠**: パート 1 では、その人が「するであろうこと」が会話全体で変わる可能性があります。 

### リスニング戦略

**オーディオの再生前**:
 - 質問と選択肢があればそれを読みます
 - 予測: この質問はどのような内容をテストしますか?

 **音声中**:
 - すべての単語を理解しようとせず、要点に集中してください
 - 番号、時間、名前をメモします。これらは質問によく出てきます。 
- 接続詞を聞きます: でも / しかし /しかし = コントラスト (重要な情報が続きます)

 **音声の後**:
 - パート 1 (課題理解) では、通常、スピーカーが最後に行うべきことは答えです。 
- パート 4 (即時応答) では、考えすぎずに直感ですぐに応答します。 

### 一般的な N3 リスニング トラップ

 **「おとり商法」**: 話者は選択肢 A を言いましたが、その後選択肢 B に変わります。答えは B です。 
> 「水曜日に会議しましょう。あ、でも水曜日は難しいな。木曜日はどうですか」
 > 答え: 水曜日ではなく木曜日 (木曜日)

 **丁寧な断り方**: 日本語話者が直接「ノー」と言うことはめったにありません。 
> 「ちょっと、今日は用事があって...」= 今日は無理です（間接的な拒否）

 **否定的な質問**:
 > 「この中で正しいものはどれですか。」= 間違った選択肢を選んでください
 → 質問を注意深く読んでください。 N3 には否定的な質問がよくあります (〜ないもの、〜間違っているもの)

 ### リスニングの練習 — 質問付きのトランスクリプト

 **トランスクリプト**:
 > A: 来週の発表の準備、どこまで進んでるの？ 
> B: とりあえず資料が半分しかできてないんだよね。 
> A: 発表まで1週間しかないよ。手伝おうか？ 
> B: それは助かる。グラフの部分をしてもらって嬉しいんだけど担当。 
> A: わかりました。今日の夜一緒にやろう。何時がいいですか？ 
> B: 7時からで十分な。 

**質問**:
 1. B 社の準備状況はどうなっていますか?
 a) ほぼ完成
 b) 半分終わった
 c) 未開始
 d) 昨日完了しました

 2. A は何を手伝いますか?
 a) プレゼンテーション全体
 b) 書き込み部分
 c) グラフセクション
 d) すべて

 3. 彼らはいつ会いますか?
 a) 今日の午後
 b) 明日の朝

 ## 一般的な N3 エラー パターン — 何が問題なのか

 ### 語彙セクションのエラー

 **エラー タイプ 1: 他動詞と自動詞の混同**
 > ✗ 人口を減らした。(減少は自動詞またはする動詞として使用されます)
 > ✓ 人口が減少した。 / 人口を減らした。 

**エラー タイプ 2: 形式レベルの不一致**
 > ✗ 正式なエッセイの場合: 「利用する」の代わりに「使う」
 > ✓ デジタルツールを利用することで、効率が上がります。 

**エラー タイプ 3: 見た目が似ている漢字**
 > 症状（ショウジョウ - 症状）vs 状況（ジョウキョウ - 状況） - 漢字の順番が違う！ 

### 文法セクションのエラー

 **エラー タイプ 1: コンテキストの条件が間違っています**
 > ✗ 駅に着いたら、電話をしてください。 
> ✓ 駅に着いたら、電話をしてください。(〜たら = リクエストのあるシーケンスの場合は正しい)

 **エラー タイプ 2: 〜わけにはいけないの否定語を忘れています**
 > ✗休むわけにはなる。 
> ✓ 休むわけにはいかない。(常に否定的)

 **エラーの種類 3: 〜によって / 〜について混同**
 > 環境問題について研究している。 
> 環境問題によって生態系が変わった。(生態系はDUE TOにより変化した) ✓

 ### セクションの読み取りエラー

 **エラー タイプ 1: 極端なオプションの選択**
 > 必ず (always)、絶対に (absolutely)、全員 (everyone) のオプションは、テキストに明示的に記載されていない限り、通常は間違っています。

**エラー タイプ 2: 外部知識の使用**
 > N3 リーディングでは、パッセージに記載されている内容のみがテストされます。 たとえ実際の答えがわかっていても、テキストに基づいて選択してください。 

**エラー タイプ 3: 否定的な質問が欠落しています**
 > 「正しいものは？」= 間違ったオプションを選択してください
 > 疑問文を注意深く読んでください: 正しい (正しい) vs 正しくない (正しくない)
