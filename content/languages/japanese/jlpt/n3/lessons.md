これら 10 のレッスンは、N4 レベルの学習を完了し、JLPT N3 の準備をしている学習者を対象に設計されています。 各レッスンは、N3 試験の問題タイプと実践的な日本語の使用に直接対応する実際のスキルに焦点を当てています。 順番に学習してください。後のレッスンは前のレッスンに基づいて構築されます。 

**1 レッスンあたりの時間**: 2 ～ 3 時間 (学習 + 演習)
 **前提条件**: N4 の文法と語彙。 ひらがな、カタカナ、漢字約 284 文字

 ## レッスン 1: ニュースの見出しを読む — 漢字熟語を分解する

 ### 学習目標
 - 2～4 文字の漢字複合名詞の構成要素を識別する
 - 未知の化合物の構成漢字から意味を推測する
 - NHK Web Easyの記事を段落レベルで読む

 ### 語彙重視 (20 単語)

 | 日本語 | 読書 | 英語 |
 |----------|-----------|----------|
 | 温暖地球化 | ちきゅうおんだんか | 地球温暖化 |
 | 少子化 | しょうしか | 少子化 |
 | 高齢化社会 | こうれいかしゃかい | 高齢化社会 |
 | 経済成長 | けいざいせいちょう | 経済成長 |
 | 人口を減らす | じんこうげんしょう | 人口減少 |
 | 環境問題 | かんきょうもんだい | 環境問題 |
 | 政策 | せいさく | ポリシー |
 | 影響 | えいきょう | 影響; 効果 |
 | 調査 | ちょうさ | 調査; アンケート |
 | 統計 | とうけい | 統計 |
 | 発表する | はっぴょうする | 発表する。 発表する |
 | 実施する | じっしする | 実装する。 実行する |
 | 反省 | みなおす | 見直すこと。 再考する |
 | 増加する | ぞうかする | 増やす |
 | 減少する | げんしょうする | 減らす |
 | 課題 | かだい | 問題; チャレンジ |
 | 対策 | たいさく | 対策; 対策 |
 | 取り組み | とりくむ | 取り組むこと。 取り組む |
 | 解決する | 活かす | 解決する; 解決するには |
 | 報告する | ほうこくする | 報告する |

 ### 重要な文法: 見出しの受動態

 ニュースの見出しでは、誰がそれを引き起こしたかではなく、その出来事に焦点を当てるために受動態 (〜れる/〜される) がよく使用されます。 

> 新法律が施行された。 
> シン・ホリツ・ガ・シコウ・サレタ。 
> 新しい法律が制定されました。 

>調査結果が発表されました。 
> 蝶々が幸せになった。 
> 調査結果が発表されました。 

### テクニック: 化合物の分解

 見出しに未知の漢字複合体が含まれている場合は、それを構成要素に分割します。 

**例**: 少子高齢化社会
 - 少子 (しょうし) = 子供が少ない
 - (こうれい) = 高齢者
 - 化 (ka) = 変化する/なる
 - 社会（しゃかい）＝社会
 ～あわせて「少子高齢化社会」＝少子高齢化社会

 **一般的な複合パターン**:
 - 〜化 (ka) = 温化、国際化、情報化のなりつつある/傾向
 - 〜化社会 = 以下の特徴を持つ社会
 - 〜問題 = 問題/課題: 環境問題、少子化問題
 - 〜対策 = 対策：温化対策
 - 〜率 = 割合/比率: 就職率 (失業率)、合格率 (合格率)

 ### リアルワールドテキスト — NHK Web らくらくスタイル

 > 日本の人口が減っています。政府の調査によると、昨年の出生数は過去最低になりました。少子高齢化が進む中、政府は様々な対策を講じております。子育て支援を充実させることが重要な課題となっています。 

※日本の人口は減少しています。 政府の調査によると、昨年の出生数は過去最低を記録した。 少子高齢化が進む中、政府はさまざまな対策に取り組んでいます。 子育て支援の強化は重要な課題となっています※。 

### 演習

 **A. これらの化合物をコンポーネントに分解して、意味を推測してください:**
 1. 情報化社会
 2. 経済格差
 3. 自然災害対策
 4. 人口問題研究所

 **B. これらの文を受動態として書き直します:**
 1. 政府は新しい法律を作った。 
2. 研究者がその問題を発見した。 

**C. 今日、NHK Web Easy の記事を 1 つ読んでください。** 3 文字以上の漢字を含むすべての複合名詞に下線を引きます。 それぞれの部分から意味が推測できますか？

 ## レッスン 2: 公式スピーチと非公式スピーチ — いつ登録を切り替えるか

 ### 学習目標
 - 正式な（です/ます）と普通の（カジュアルな）日本語を区別する
 - 各レジスタがいつ適切であるかを認識します
 - N3 レベルの状況で敬語の基本を正しく使用する

 ### 語彙重視 (15 単語)

| 日本語 | 読書 | 英語 | 登録 |

 | いた | — | 来る/行く/来る（敬語） | 圭吾 |
 | いただく | — | 受け取る（謙虚に） | 圭吾 |
 | 申す | います | と言う（謙虚に） | 圭吾 |
 | 参る | まいる | 行く/来る（謙虚） | 圭吾 |
 | 見るになる | ごらんになる | 見る（敬語） | 圭吾 |
 | 拝見する | はいけない | 見る（謙虚） | 圭吾 |
 | 承知する | しょうちする | 理解/同意する | 圭吾 |
 | 恐れ入りますが | 勝ちますが | すみません; ご迷惑をおかけして申し訳ありません | 非常にフォーマル |

 | 状況 | カジュアル | 礼儀正しい | フォーマル/敬語 |
 |----------|----------|----------|-------------|

 | 減少中 | いや | ちょっと... | あいにくですが... |

 ### ダイアログ A — カジュアル (友達)

 > A: 昨日の試合、見ましたか？ 
> B: 見た見た！すごかったよね。 
> A: できる。あんなに熱くなれるもんかと思ったよ。 
> B: そういえば、来週また試合あるって。一緒に行かない？ 

*A: 昨日の試合を見ましたか?*
 *B: やった、やった! すごかったですよね*
 *A: 本当です。 本当にそんなに興奮できるの?*と思いました。 
*B: そういえば、来週も試合がありますね。 一緒に行きませんか？*

 ### 対話 B — 公式 (職場/新しい知り合い)

 > A: 本日はお時間をいただきまして、ありがとうございます。 
> B: いえ、こちらこそ。どうぞよろしくお願いいたします。 
> A: 早速ですが、ご提案の件についてお伺いできればと思います。 
> B: はい、承知いたしました。ご説明させていただきます。 

*A: 本日はお時間をいただきまして誠にありがとうございます。*
 *B: まったく、そうではありません。同様に、あなたと一緒に仕事ができることを楽しみにしています。*
 *A: 早速ですが、ご提案の件についてお伺いしたいと思います。*
 *B: はい、もちろんです。 説明させてください。*

 ### 重要なルール: レジスタの一貫性

 **意図的に切り替える場合を除き、同じスピーチ/ライティング内で音域を混在させないでください**。 よくあるエラー:
 - です/ますを使用し、最後に〜じゃないと言います
 - いただきましたが、なりましたの代わりに使いました

 ## レッスン 3: 複雑な因果表現 — 〜のため、〜から、〜ので、〜によってのニュアンス

 ### 学習目標
 - レジスタとコンテキストに適切な因果表現を選択します
 - 主観的な原因と客観的な原因の違いを理解する
 - 受動構造のエージェントと原因に対して「〜によって」を正しく使用する

 ### 語彙重視 (18 単語)

 | 日本語 | 読書 | 英語 |
 |----------|-----------|----------|
 | 遅刻する | ちこくする | 遅刻する |
 | 渋滞 | じゅうたい | 交通渋滞 |
 | 台風 | たいふう | 台風 |
 | 中止する | ちゅうしする | キャンセルする。 中止する |
 | 延期する | えんきする | 延期する |
 | 原因 | げんいん | 原因; 係数 |
 | 理由 | りゆう | 理由 |
 | 不注意 | ふちゅい | 不注意 |
 | 事故 | じこ | 事故 |
 | 結果 | けっか | 結果; 結果 |
 | 影響を受ける | えいきょうをうける | 影響を受ける |
 | 得 | しょうじる | 起きる。 起こる |
 | 思いつき | まねく | 引き起こす; 招待する |
 | やあ | 続く | 与える; 原因（結果） |
 | 損害賠償 | そんがい | ダメージ; 損失 |
 | 回避する | かいひする | 避けるべき |
 | 真剣 | しんこく | 深刻な; お墓 |
 | 悪いことする | ああかする | 悪化する |

 ### 文法の詳細

 **〜から** (カジュアル、主観):
 - 理由が話し手の個人的な感情や判断である場合に使用されます。 
- リクエスト、コマンドで使用可能
 - フォーマルな文章では少し子供っぽい

 > 眠いから、もう寝る。 — 眠いから寝ます。 

**〜ので**（丁寧、理解を求める）:
 ・話者は客観的事実として理由を提示し理解を求める
 - 命令/コマンドの直前に置くことはできません
 - からよりも柔らかく、思いやりがあります

 > 体調が悪いので、早めに退出させていただけませんか。 
> 体調が悪いので早退してもいいでしょうか？

**〜のために** (正式、書面、中立):
 - 3 つの中で最もフォーマルな形式
 - 原因と目的の両方を表現できる (文脈を参照)
 - ニュース執筆、ビジネス文書で一般的

 > 大雨のために、河川が氾氾濫した。 

**〜によって** (エージェント/バリエーション/原因 — 形式的):
 - 受動的エージェントに使用: "by ~"
 - 重要な出来事の原因に使用されます:「～による、～による」
 - バリエーションに使用:「～に応じて」

 > 地震によって、多くの建物が倒壊した。 

### 対話 — 適切な表現の選択

 > 主人公: いかにも遅刻しませんか。 
> 後輩: 申し訳ありません。電車が遅延したため、遅れてしまいました。 
> 議長: そうですね。渋滞による遅延はありません。次回は早めに出てください。 
> 部下: はい、今後も気をつけます。 

*上司:なぜ遅刻したのですか?*
 ※職員：大変申し訳ございません。 電車が遅れたので遅れました。*
 ※上司：なるほど。 渋滞による遅れは仕方がありません。 次回からは早めに出発してください。*
 *従業員:はい、今後は気をつけます。 

### 演習

 **A. 最適な表現を選択してください (から / ので / ために / によって):**
 1. この映画は多くの人に見られた_______、有名になった。 
2. 病気な_______、学校をお休みします。(先生に)
 3. ご注意ください_______、事故が起きました。 
4. 眠い_______、今夜は早く寝ます。(カジュアル)

 **B. 正しい因果表現を使用して翻訳してください:**
 1. 台風の影響で、すべての飛行機が欠航になりました。 
2. 緊張していたため、うまく話すことができませんでした。 (カジュアル)
 3. 大変お世話になり、大変感謝しております。 (丁寧な)

 ## レッスン 4: 意見と議論の表現

 ### 学習目標
 - 複数の確実性レベルで意見を表明する
 - N3 の意見パターンを使用します: 〜のことではない、〜と思われる、〜と考えられる

 ### 語彙重視 (16 単語)

 | 日本語 | 読書 | 英語 |
 |----------|-----------|----------|

 | 意見を考える | 我慢をのべる | 意見を述べる |
 | 賛成する | さんせいする | 同意する。 サポートする |
 | 反対する | はんたいする | 反対する。 同意しない |
 | 根拠 | こんきょ | 基礎; 根拠 |
 | 確かに | 然 | 確かに; 確かに |
 | その際 | そのいっぽうで | 一方 |
 | なんか〜ない | 天国しも〜ない | 必ずしもそうではない |
 | いん | — | おそらく; おそらく |
 | | — | それよりも; 代わりに |
 | 〜とは限らない | 〜とはかぎらない | 必ずしもそうではない |
 | 指摘する | できる | 指摘する |

 ### 意見表現スケール

 | 日本語 | 確実性 | 英語 |

 | 〜と思う | 中（個人） | 私はそう思います〜 |

 | 〜と思われる | 中（非個人的） | ～のようです/のようです |

| 〜のではないか | ソフトな主張 | ～ということはないでしょうか？ / かな～ |

| 〜にちがいない | 非常に高い | それは間違いありません〜 |

 ### 対話 — 社会問題について議論する

 > A:最近、テレワークが増えていますね。これからもっと普及すると思いますか。 
> B: そうですね。確かに便利な面もあるのではないかと思います。しかし、コミュニケーションが正義なら考えられます。 
> A: それは大丈夫、仕事時間がなくなることで生産性が上がるという意見もありますよね。 
> B: 構いません。ただ、これまで全員に目を向けているとは限らないと思います。 

※A：最近は在宅勤務が増えています。 今後さらに広がっていくと思いますか？*
 *B: そうですよ。 便利な面もあるかと思います。 ただし、コミュニケーションが困難になる可能性があると考えられます※。 
*A: 一方で、通勤がなくなることで生産性が上がるという意見もあります。*
 *B: 確かに。 しかし、必ずしもすべての人に当てはまるわけではないと思います。 職種によって違うんじゃないでしょうか？ 

### 段落作成テンプレート

 N3 の意見を書く場合は、次の構造を使用します。 

1. **トピックセンテンス**: 〜について、〜と思う/考える
 2. **理由 1**:せっかく〜からだ / 〜のためだ
 3. **譲歩**: 確かに〜という意見もある

 ## レッスン 5: 高度な条件文 — 〜さえ〜ば、〜さえさえいれば

 ### 学習目標
 - 「必要な唯一の条件」を表現するには、〜さえ〜ばを使用します
 - 5 つの条件形式 (たら・ば・と・なら・さえ〜ば) をすべて区別する
 - リクエストやアドバイスで条件文を正しく使用する

 ### 語彙重視 (15 単語)

 | 日本語 | 読書 | 英語 |
 |----------|-----------|----------|
 | 条件 | じょうけん 状態; 要件 |
 | 場合 | ばあい | 場合; 状況 |
 | 状況 | じょうきょう | 状況 |
 | ほぼ | さいていげん | 最小 |
 | 十分 | じゅうぶん | 十分な; 十分 |
 | 実現する | じつげんする | 実現すること。 実現する |
 | 失敗する | しっぱいする | 失敗する |
 | 成功する | せいこうする | 成功するために |
 | 可能性 | かのうせい | 可能性 |
 | 乗り越える | のりこえる | 克服する |
 | 諦める | 諦める | 諦める |
 | 続ける | 続ける | 続ける |
 | 努力する | どりょくする | 努力する |
 | 目標 | もくひょう | ゴール; ターゲット |
 | 達成する | たっせいする | 達成する |

 ### 文法: 5 つの条件文の概要

 **〜と**: 自然/自動結果。 事実。 提案のためではありません
 > 春になると、桜が咲く。 — 春になると、桜が咲きます。 

**〜たら**: X が発生したとき/発生した場合 (シーケンス; 発見)
 > 宿題が終わったら、遊びに行ってもいいよ。 — 宿題が終わったら、遊びに行ってもいいよ。 

**〜ば**: 仮説。 規範的な条件 (「X であれば Y」)
 >何回練習すれば、上手になります。 — もっと練習すれば、上達します。 

**〜なら**: トピック条件付き (「それが私たちが話していることであれば」)
 > 東京に行くなら、スカイツリーに行ってみて。 — 東京に行くなら、スカイツリーに行ってみてください。 

**〜さえ〜ば**: 「必要なのはXだけです」
 > お金さえあれば、旅行できる。 — お金さえあれば、旅行できるのに。 

### ダイアログ — 条件の設定

 > A: JLPT N3、本当に受かるかな。

 ## レッスン 8: 読解戦略

 ### 学習目標

 ### 語彙重視 (15 単語)

 | 日本語 | 読書 | 英語 |
 |----------|-----------|----------|
 | 段落 | だんらく | 段落 |

 | 要約する | なんとかする | 要約すると |
 | 根拠 | こんきょ | 基礎; 根拠 |

 | 具体例 | ぐたいれい | 具体例 |
 | 推測する | すいそくする | 推測する。 推測する |
 | 競争 | ぶんみゃく | コンテキスト |
 | 相互接続 | ぎゃくせつ | 矛盾; 逆境 |
 | 順接 | じゅんせつ | シーケンシャル（以下） |
 | 接続詞 | せつぞくし | 接続詞 |
 | かえる | 快適できる | 言い換えると; 言い換える |

 ### 読書戦略

 **1. スキミング** (速読速読): 各段落の最初と最後の文を読みます。 すべての単語を読まなくても主要なアイデアを理解してください。 

**2. スキャン** (探し読み sagashiyomi): すべてを読まずに、番号、名前、キーワードなどの特定の情報を探します。 

**3. 接続詞の追跡**: 接続詞を丸で囲むか下線を付けます。 これらは、パッセージの論理構造を示しています。 
- しかし /突然 = コントラスト (要点は多くの場合続きます)
 -結果 / そのため = 結果
 -例 / のため = 例 (流し読みしても安全)
 - また / さらに = 同じものをさらに追加する

 **4. 文脈からの推論**: 未知の単語を見つけた場合は、次の点を確認してください。 
―それはどんな言葉ですか？ (名詞?動詞?形容詞?)
 - その前/後には何がありますか?
 - 漢字のヒントはありますか？

**質問**:
 1. この一節によると、コミュニケーションに関して何が変わりましたか?
 2. デジタル通信の問題として何が特定されていますか?
 3. 著者は何が重要だと示唆していますか?

 ### エッセイのサンプル: SNS と人間関係

 > **序論**
 > 現代社会において、SNSは人々のコミュニケーションに不可欠な存在となっている。 しかし、SNSの普及によって、人間関係はどのように変化しているのだろうか。 
>
 > **本論**
 > 確かに、SNSには多くのメリットがあります。 例えば、遠く離れた友人や家族と簡単に連絡が取れるようになりました。 さらに、共通の趣味を持つ人たちと会う機会も増えました。 
> その通り、問題点もある。SNS上の関係は表面的になりがちで、深い人間関係を築くことが難しいという意見がある。 
>
 > **結論**
 > 以上のように、SNSには長所と短所の両面がある。 

**翻訳**:
 ※はじめに：現代社会において、SNSは人々のコミュニケーションに欠かせないものとなっています。 しかし、SNSの普及により人間関係はどう変わったのでしょうか？ 
※本文：確かにSNSにはメリットがたくさんあります。 たとえば、遠く離れた友人や家族と連絡を取るのが簡単になりました。 また、同じ趣味を持つ人々と出会う機会も増えました。 一方で、問題もあります。 オンライン上の人間関係は表面的なものになりがちで、深いつながりを築くのが難しいという人もいます。 また、SNSの利用時間の増加に伴い、直接会う機会が減っているとも指摘されています※。 
※結論：上記のように、SNSにはメリットもあればデメリットもあります。 大切なのは、直接のコミュニケーションを大切にしながら、SNSを上手に活用することですよね。
