## 概要

 N3 レベルでの中心的なコミュニケーション タスクの 1 つは、*物事がどのように変化したか*、*物事がどのように起こる傾向*、*何かがどれほど簡単または可能であるか*を正確に説明することです。 これらは、単純なオン/オフの説明ではなく、時間の経過とともに徐々に変化するニュアンス、習慣的な傾向 (多くの場合否定的な意味合いを伴う)、行動の本質的な容易さまたは難しさ、論理的な可能性または不可能性を含みます。 これらの概念は、正式な文章、ニュースの解説、日常の会話を通じて繰り返し使用されます。 

このレッスンでは、5 つの基本的なパターンを取り上げます。〜ようになる（できるようになる / できるようになる — 能力や習慣が徐々に変化する）、〜するように（確実にできるよう努力する / そうしようとする）、〜がちだ（傾向がある、傾向がある — しばしば否定的なニュアンスを含む）、〜やりやすい / 〜難しい（簡単 / 難しい — 固有の性質）、および〜得 / 〜承（できるかもしれない / できないかもしれない — 論理的な可能性）。 このレッスンの語彙は変化の言語を中心としています:「変わる」、「増える」、「増える」、「下がる」、「改善する」、「悪化する」、「続ける」、「やめる」、「習慣」。 

## 学習目標

 このレッスンを終了するまでに、次のことができるようになります。 
- 能力、習慣、状況が徐々に変化することを表現するには、「〜ようになる」を使用します。 
- 意図的に継続的な努力や意図を表現するには、〜するを適用します。 
- 〜がちだの否定的な意味合いを認識し、適切に使用します。 
- 〜やすい/〜難しい（本質的な性質）と〜ようになる（徐々に変化する）を区別します。 
- 論理的な可能性と不可能性を表現するには、〜できる/〜無理を使用します。

 ## 文法ポイント

 ### 1. 〜ようになる — できるようになる / できるようになる (段階的な変化)

 **構造:**
 - 動詞（辞書形） + **ようになる** → 「～するために来る」（習慣/状況の徐々に変化）
 - 動詞（潜在的形） + **ようになる** → 「〜できるようになる」（能力が徐々に変化する）
 - 動詞（否定がない） + **ようになる** → 「～をしないようになりました」（徐々にやめる）

 **説明:** 〜ようになるは、以前の状態から新しい状態への「徐々に変化」することを表します。 突然の切り替えではなく、移行のプロセスを強調します。 時間の経過とともに獲得した新しい能力（潜在力+ようになる）、形成された新しい習慣（辞書+ようになる）、やめた習慣（ネガティブ+ようになる）に使用されます。 重要なのは、変更が「意図的ではない」、または少なくとも焦点ではないことを意味しており、変更の「結果」に重点が置かれています。 

**〜のようにする:** と対比してください:** 〜ようになるは、*何が起こった* (変化の結果) を説明します。 〜のようにするは、*実現しようとしていること* (継続的な努力) を表します。 あなたは努力します → そうする; 変化が起こる→ようになる。

| 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 毎日練習して、ピアノが弾けるようになりました。 まいにちれんしゅうして、ぴあのがひけるようになりました。 毎日練習して、ピアノが弾けるようになったよ。 | 私は毎日練習してピアノを弾けるようになりました。 |
 | 日本に来てから、箸が使えるようになりました。 にほんに来てから、はしがつかえるようになりました。 日本に来てから、橋がつかえるようになったよ。 | 日本に来てから、お箸を使えるようになりました。 |
 | 最近、野菜を食べるようになりました。 さいきん、やさいをたべられるようになりました。 さいきん、野菜を食べるようになったよ。 | 最近、野菜を食べるようになりました。 |
 | | 故障のころは好きじゃなかったが、コーヒーが好きになった。 こどものころはすきじゃなかったが、こーひーがすきなようになりました。 こどものころは好きじゃなかったが、こどもが好きになった。 | 子供の頃はあまりコーヒーが好きではなかったのですが、今ではコーヒーが好きになりました。 |
 | たまたまなってから、運動しないようになりました。 いそがしくなってから、うんどうしないようになりました。 いそがしくなってから、うんどうしないようになった。 | 忙しくなってから運動をしなくなった。 |

 ### 2. 〜するようにする — 確実にしようとする / 努力する

 **構造:**
 - 動詞（辞書形式） + **ようにする** → 「～をしようとする、～をすることにする」
 - 動詞（否定がない） + **ようにする** → 「～をしないようにしてください、～をしないようにしてください」

 **説明:** 〜するようにするは、何かを実現する、または何かを回避するための *継続的で意図的な努力* を表します。 それは、単一の意図的な行動（〜ようとする、または単に意志形の動詞を使用する）ではなく、継続的な習慣的な努力です。 ライフスタイルの目標、ルール、自己改善について話すときによく使われます。 否定形 (〜しない) は、「[何か] が起こらないように努める」という意味です。 

| 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 健康のために、毎日野菜を食べているように。 けんこうのために、まいにちやさいを食べられるようにしています。 健康のために、毎日野菜を食べているよ。 | 健康のために、私は毎日野菜を食べるようにしています。 |
 | |遅刻しないように、早めに家を出しました。 ちこくしせずに、はやめにいえをでした。 知国しないようにして、はやめに家をでた。 | 遅刻しないように私は早めに家を出ました。 |
 | | 次の本を読むようにしようと思います。 次ほんをよむようにしましょう。 もっと本を読んでみようと思う。 | もっと本を読んでみようと思います。 |
 | 睡眠時間を十分にとっているようにしています。 すいみ漢字をじゅうぶんとしている。 すいみん時間を十分にしているようです。 | 十分な睡眠をとるように努めています。 |
 | 仕事中、スマホを見ないようにしています。 しごとちゅう、すまほを見ないようにしている。 仕事中、スマホを見ているようになってます。 | 仕事中はスマホを見ないようにしています。 |

 **よくある間違い:** ❌毎日運動するようにしました。(完了した過去の決定として) — これは 1 つの過去の決定のように聞こえます。 使用: 毎日運動するようにしている (継続中) または毎日運動するようになった (変化はすでに起こっています)。 — *〜する + しているは、現在その取り組みが進行中であることを意味します。*

 ### 3. 〜傾向だ — 傾向がある / 傾向がある (ネガティブなことが多い)

 **構造:**
 - 動詞（ます語幹） + **傾向だ** → 「～する傾向がある、～する傾向がある」
 - 名詞 + **傾向だ** → 「～（否定的な状態）になる傾向がある」

 **説明:** 〜がちだは、通常 *否定的* に見られたり、注意すべき問題として見られたりする傾向や傾向を表します。 単に「よくある」という意味ではなく、その傾向が望ましくない、不幸である、あるいは注意すべきであるというニュアンスが込められています。 これは一般的に、悪い習慣、健康状態、否定的な社会パターン、個人の弱点を説明するために使用されます。 関連形式「〜がちな(名詞)」は属性的に機能することに注意してください。

| 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 彼は約束を忘れがちだ。 かれはやくそくをわすれがちだ。 彼はやくそくをわすれがちだ。 | 彼は約束を忘れる傾向があります。 |
 | 忙しい人は睡眠不足になりがちだ。 いそがしいひとはすいみんぶそくになりがちだ。 イソガシイヒトはスイミンブソクニナリガチだ。 | 忙しい人は睡眠不足になりがちです。 |
 | 冬は病気になりがちなので、気をつけてください。 ふゆはびょうきになりがちなので、つけてください。 冬は恐怖になるから、気を付けてください。 | 冬は体調を崩しやすいので気をつけてください。 |
 | 暮らしは食生活が乱れがちだ。 ひとりぐらしはしょくせいつがみだれ傾向だ。 ひとりぐらしは職業生活がミダレガチだ。 | 一人暮らしの人は食生活が不規則になりがちです。 |
 | 最悪しがちな状況に早めに対処する大切だ。 あかしがちなジョーにはやめにたいしょすることがたいせつだ。 アッカ・シ・ガチな状況に早目に大正することが大雪だ。 | 悪化する傾向にある状況には早めに対処することが重要です。 |

 **よくある間違い:** ❌ 私はラーメンを食べがちだ。 (単に「私はラーメンをよく食べる」という意味) → ✓ 私はラーメンを食べすぎる傾向がある。 中立的な傾向がある場合は、〜傾向があるを使用します。*

 ### 4. 〜やりやすい / 〜難しい — 簡単 / 難しい (固有の品質)

 **構造:**
 - 動詞（ます語幹） + **やりやすい** → 「～しやすい、～しやすい」（I形容詞として機能）
 - 動詞（ます語幹） + **難しい** →「〜するのは難しい/難しい」（I形容詞として機能します）

 **説明:** 〜簡単および〜しにくいは、何かの *固有の性質*、つまり特定の主題について、または特定の主題に対して何かを行うのがどれほど簡単であるか、難しいかを表します。 これらはi-形容詞として機能し、それに応じて活用できます（〜やすかった、〜つらくないなど）。 〜やすいは、「起こりやすい」、つまり簡単に起こったり壊れたりすることを意味することもあります。 〜ことができるとは異なり、これらのパターンは人の能力ではなく、*物事の品質*に焦点を当てています。 

| 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | このフォントは読みやすいです。 このふぉんとはよみやすい。 このフォントはヨミヤスイ。 | このフォントは読みやすいです。 |
 | そこでの説明はわかりにくかった。 カレのせつめいはわかりにくかった。 カレノセツメイはワカリニクカッタ。 | 彼の説明は理解するのが難しかった。 |
 | このペンは書きやすい。 このぺんはかきやすい。 このペンはかきやすい。 | このペンは書きやすいです。 |
 | 細かい文字は読みにくい。 こまかいもじは読みにくい。 駒界文字はよみにくい。 | 小さい文字は読みにくいです。 |
 | 雨の日は事故が起きやすい。 あめのひはじこが起こりやすい。 アメノヒはジコがオキヤスイ。 | 雨の日は事故が起こりやすいです。 |

 **よくある間違い:** ❌ 私はこの本が読みやすい。 (「この本は読みやすいと思います」のつもり) → ✓ この本は読みやすい。 — *〜読みやすいは、話者の能力ではなく、主題 (本​​) の質を表します。 人物を主要被写体に追加しないでください。*

 **〜がちだ:** との比較 どちらも傾向を表すことができますが、〜起こりやすいは本質的な容易さ/可能性に焦点を当てます (雨が降ると事故が起こりやすくなります)、〜がちだは望ましくない個人的または社会的な傾向 (遅刻する傾向がある) に焦点を当てます。

 ### 5. 〜もらえる / 〜いけない — もしかしたらできる / たぶんできない

 **構造:**
 - 動詞 (ます語幹) + **もらえる** (*うる* / *える*) → 「～できる可能性があります、～できる可能性があります」
 - 動詞 (ます語幹) + **いけない** (*エナイ*) → 「～することは不可能です、～することは不可能です」

 **説明:** 〜得る (「うる」または「える」と発音) は、*論理的な可能性*、つまり潜在的に起こる、またはそうなる可能性のあることを表します。 〜「まさか」は、論理的な*不可能性*、つまり根本的に起こり得ないことを表します。 これらは、身体的な能力（〜できる）や許可とは異なり、論理的に考えられることを表現します。 〜を得るは形式的なもので、文書の文脈、ニュース、学術的な談話によく登場します。 カジュアルな会話では、「ありえない」（不可能/信じられない）の方が一般的です。

| 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | そのような事態は十分にあり得る。 そのようなじたいはじゅうぶんおこりできる。 そのような状況は十分にある。 | このような状況は十分に起こり得る。 |
 | 彼が嘘をつくとは考えた。 かれがうそ作るとはええない。 彼が嘘をついてはカンガエナイ。 | 彼が嘘をつくとは考えられない。 |
 | とりあえずこのような問題は解決しました。 こんごこのようなもんだいはふえる。 金剛このようなもんだいはふえる。 | このような問題は今後さらに増える可能性があります。 |
 | 完全な解決などありえない。 かんぜんなかいけつなどありえない。 カンゼンナカイケツナドアリエナイ。 | 完全な解決策はまったく不可能です。 |
 | この方法では成功しません。 このほうほうではせいこうしません。 このほほうでわせいこうしえません。 | この方法で成功するのは不可能です。 |

 **よくある間違い:** ❌ あり得るんじゃない (「それは可能ですよね?」のつもり) → ✓ あり得んじゃない? または あり得ます。 カジュアルな文脈では、「ありえる」または「ありえない」を単独の表現として使用します。*

 ## 対話

 ### ダイアログ 1: 健康と習慣

 *小林医師は患者の林さんにアドバイスします。*

 **小林先生:**最近、体の調子はどうですか。 
*博士 小林：＊最近の調子はどうですか？ 

**リン:**仕事がよくて、運動しなくなりました。 
＊林：＊ 仕事が忙しくなって、運動しなくなったんです。 

** 小林先生:** それは体に良くないですね。忙しい人は睡眠不足になりがちですが、運動不足も起こりやすいです。 
*博士 小林：※それは体に良くないですよ。 忙しい人は睡眠不足になりやすく、運動不足も深刻化しがちです。 

**リン:** わかりました。毎日少しずつ歩いているようですが、なかなか続いてもいいですね。 
＊林：＊ 分かりました。 毎日少しずつ歩こうと思っているのですが、続けるのは難しいです。 

**小林先生:**無理のない習慣を続けることが大切です。小さな変化が体を改善できます。 
*博士 小林：※無理のない習慣を続けることが大切です。 小さな変化があなたの体を改善する可能性があります。 

**リン:** 先生のアドバイスに従い、生活習慣を変えます。 
*林:* アドバイスに従って、生活習慣を変えてみます。

 ### ダイアログ 2: ニュース記事について話し合う

 *2 人の同僚、リョウとアカネが若者のトレンドに関するニュースについて話し合っています。*

 **亮:** この記事によると、最近の若者は外出しないようになっているのだ。 
*Ryo:* こちらの記事によると、最近は若者の外出が減っているそうです。 

**茜:** そうだね。一人暮らしの人は特に孤独しがちらしい。 
*あかね:* そうですね。 一人暮らしの人は特に孤立しやすいようです。 

**亮:** どうも問題、解決しにくいですよね。政府だけじゃ対応しないと思います。 
*Ryo:* この種の問題は解決するのが難しいです。 政府だけでは到底対応できないと思います。

**亮:** うん。とにかく、誰もが繋がりやすい環境を作ることが大切だと思います。 
*リョウ:* そうですね。 とにかく誰でも簡単に繋がれる環境を作ることが大切だと思います。

5. そのようなミスはあり得る。

7. 早起きしようとしているのですが、続けるのが難しいです。

## 読書パッセージ

 > 現代人は忙しいため、運動不足になりがちだ。毎日少し歩くようにだけで、体の状態が改善し得ると専門家は言う。小さな習慣が大きな変化につながろう。

**読み方:** げんだいじんはいそがしいため、うんどうぶそくになりがちだ。まいにちすこしあるようにするだけで、からだのじょうたいがかいぜんしえるとせんもんかはいう。 

**理解に関する質問:**
 1. 現代人にはどんな傾向がありますか。 
2. 専門家は何をするだけで体が改善すると言っていますか。 
3. 「小さな習慣」について書いてありますか。 

**答え:**
 1.運動不足になりがちです。 
2.毎日少しずつ歩くようにするだけで改善できますと言っています。 
3. 大きな変化につながるように書いてあります。 

## 文化的なメモ

 「〜する」というパターンは、日本の自己改善文化（自己開発）に深く組み込まれています。 日本には、「〜しましょう」のような文がよく使われる自己規律の本（自己啓発書）の豊かな伝統があります。 これらのフレーズは、漠然とした意図と、全か無かの誓約ではなく、穏やかに継続的な取り組みである確固たる決意との間の中間点を表しています。 

一方、「〜がちだ」は、社会的文脈において自分の弱さを公然と認める日本の文化的習慣を反映しています。 日本の会話では、自慢するよりも、否定的な傾向を自虐的に認めることがよくあります。 「私は遅刻しがちなので、気をつけます」（「私は遅刻しがちなので気をつけます」）と言うのは社会的に受け入れられており、さらには愛嬌があり、自己認識と改善への取り組みを示しています。 この謙虚な自己開示のパターン (謙虚半分、*kenson*) は、N3 レベルの重要なコミュニケーション スキルです。
