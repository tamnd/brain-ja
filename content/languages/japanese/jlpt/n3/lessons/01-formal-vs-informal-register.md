## 概要

 JLPT N3 の決定的な課題の 1 つは、単一の登録簿に依存できないことです。 N5 と N4 では、丁寧な「です/ます」の話し方を主なモードとして学びました。 N3 では、多層システムを積極的にナビゲートする必要があります。同じ考えは、カジュアル (*くだけた*)、標準的な丁寧語 (*ていねいご*)、およびフォーマル/書き言葉 (*こうご*) の少なくとも 3 つの異なるレジスターで表現できます。 「〜てる」のようなカジュアルな短縮形と書かれたコピュラ「〜である」との間の距離は非常に大きいですが、教育を受けた日本語話者は 1 日で両方を流動的に使用します。 このスペクトルを理解することは必須ではありません。N3 試験全体を通して、文章を読んだり文法に関する問題が出題されます。 

2 番目の重要な洞察は、書き言葉 (*kakikotoba*、書き言葉) と話し言葉 (*hanashikotoba*、話し言葉) の区別です。 新聞の社説、学術論文、正式な報告書など、日本語の書き言葉は、自然な口頭での会話とは大きく異なる慣例に従っています。 日本語の書き言葉は、平文、コピュラ〜である、名詞的な文末を使用する傾向があります。 日本語の話し言葉では、省略、短縮、文末助詞の多用が許可されています。 この区別をマスターすると、N3 試験のリーディングとリスニングの両方のセクションのロックが解除されます。 

## 学習目標

 このレッスンを終了するまでに、次のことができるようになります。 
- カジュアル、標準的な丁寧語、フォーマル/書き言葉の 3 つの異なるレジスタで文章を識別して生成します。 
- 書かれた文脈における形式的なコピュラパターン「〜である」、「〜ではない」、および「〜と考え」を認識し、適用する。 
- 口語短縮形 (〜てる、〜ちゃう、〜とく) とその完全形を変換します。 
- 書き言葉と話し言葉の特徴を説明し、特定のテキストがどのレジスタに属するかを特定します。

 ## 文法ポイント

 ### 1. 形式的なコピュラ: 〜である / 〜ではない / 〜と思い込み

 **構造:**
 - 名詞 / な形容詞 + **である** (形式肯定: "です")
 - 名詞 / な形容詞 + **ではない** (形式否定:「ではない」)
 - 名詞 / な形容詞 / 節 + **と当然** (〜であると言える / それは〜であると言える)

 **説明:** 新聞、報告書、学術論文などの日本語の書き言葉では、カジュアルなコピュラ「だ (*da*)」や丁寧な「です (*です*)」さえも「である (*である*)」に置き換えられます。 これは正式な登録の最も重要なマーカーの 1 つです。 「ではない (*dewa nai*)」は形式的な否定形であることに注意してください。 丁寧な言葉遣いでは「ありません」と言いますが、フォーマルな文章では「ない」が標準です。 〜と言うパターンは、「…と言える/論じられる」という評価的なニュアンスを加えます。

| 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | これは重要な問題である。 これはじゅうようなもんだい。 これはじゅうよな問題である。 | これは重要な問題です。 |
 | 自分の行動は正しいとはいえない。 カレのこうどうはそのままでは無理。 カレの鼓動は正しいと言えない。 | 彼の行動は正しいとは言えません。 |
 | 環境問題は現代社会の課題である。 かんきょうもんだいはげんだいしゃかいのかだいである。 環境問題は現代社会の課題である。 | 環境問題は現代社会の課題です。 |
 | 努力なしに成功は不可能ではない。 どりょくなくせいこうはふかのうではない。 Doryoku nashi ni seiko wa fukano dewa nai. | 努力なしで成功することは不可能ではありません。 |
 | 日本語の習得には時間がかかると注意。 にほんごのしゅう特にはじかんがかかると思います。 日本語の修得には時間がかかると言える。 | 日本語を習得するには時間がかかると言えます。 |

 **よくある間違い:** ❌ このレポートはよいです。(正式な学術文書で) → ✓ このレポートはよいと考えます。 — *学術文書および正式な文書は丁寧な語尾を避け、代わりに平文または〜と観念を使用します。 

**「だ/です」との比較:** 「です」は丁寧で、ほとんどの会話の文脈に適しています。 「である」は正式な文書で使用され、カジュアルな会話では決して使用されません。 「だ」は平易でカジュアルな表現で、対等な者同士の直接的な会話で使用されます。

 ### 2. 書き言葉と話し言葉: 書き言葉と話し言葉の特徴

 **構造:** これは単一のパターンではなく、概念的な文法事項です。 書き言葉 (*かき言葉*) と話し言葉 (*はなし言葉*) は、いくつかの次元で体系的に異なります。 

**主な対照:**

 | 特集 | 話す言葉 (話し言葉) | 書く言葉 |
 |-------|-----------------|------|
 | コピュラ | だ/です | である |
 | ネガティブ | じゃない / ではありません | ではない |
 | 接続詞 | だから/それでも | どうですか / しかし |
 | て形原因 | 〜て | 〜により / 〜によって |
 | 件名マーカー | は（よく落とされる） | は / が (明示的に記載) |
 | 文末 | 粒子が多い (ね、よ、か) | 単純な述語 / 体言止め |

 | 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 話し言葉：今日はちょっと行けない。 きょうはいそがしくていけない。 今日はイソガシクテイケナイ。 | 音声：今日は忙しいので行けません。 |
 | 書き言葉：本日は多忙のため参加できません。 ほんとじつはたぼうによりさんかできない。 ホントはタブーよりサンカデキナイ。 | 文：本日は多忙のため出席できません。 |
 | 話す言葉：でも、それは難しいんじゃない？ でも、それはつまらないですか？ デモ、それはムズカシイんじゃない? | 音声：でも、それは難しくないですか？ |
 | 書き言葉：しかし、それは難しいと言いましょう。 しかし、それはこんなんであると言おう。 しかし、それはこんなことではないよ。 | 文：しかし、それは難しいとも言えます。 |
 | 書き言葉：調査の結果、問題が明らかとなった。 ちょうさのけっか、もんだいがあきらかとなった。 チョーサノケッカ、モンダイガアキラカとナッタ。 | 執筆：調査の結果、問題が判明しました。 |

 ### 3. 口語短縮音: 〜てる / 〜ちゃう / 〜とく / 〜しなきゃ

 **構造:**
 - 〜している → **〜てる** (進行/結果状態、カジュアル)
 - 〜てしまう → **〜ちゃう** / 〜で終わる → **〜じゃう** (完了/後悔、カジュアル)
 - 〜保管 → **〜とく** / 〜でおく → **〜どく** (事前準備、カジュアル)
 - 〜しなくても → **〜しなければならない** (しなければならない、カジュアル)

 **説明:** これらの短縮形は、日本での自然なカジュアルな会話で最も頻繁に見られる特徴の 1 つです。 これらを理解することは、日本語の話し言葉を理解し、日常会話で不自然に聞こえないようにするために不可欠です。 これらは、正式な文章やビジネスの文脈では決して適切ではありません。 

| 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | もう食べてる？ もうたべてる？ もう食べてる？ | もう食べていますか？ |
 | あ、傘忘れちゃった！ あ、かさをわすれちゃった！ あ、かさを忘れちゃった！ | あ、傘忘れた！ |
 | 明日のために準備しとく。 あしたのためにじゅんびしとく。 明日のために、十分に。 | 明日に備えて事前に準備しておきます。 |
 | 早く起きなきゃ。 はやくおきなくては。 はやくおきゃく。 | 早く起きなければなりません。 |
 | 報告書もう書いてる？ ほうこくしょもうかいてる？ ほうこくしょもかいてる？ | もうレポートを書いていますか？ |

 **よくある間違い:** ❌ 会議の前に準備しておいてください。(上司に) → ✓ 会議の前に準備しておいてください。 — *丁寧語やフォーマルなスピーチでは、短縮形は不適切です。 ビジネスシーンでは必ず展開してください。*

 ## 読書パッセージ

 次の短い文章を読んで、以下の質問に答えてください。 

> 言語はシーンによって使い分けられるものである。 日本語において、書き言葉と話し言葉の差は特に大きいと思われる。正式な文書では「〜である」という表現が用いられる方、日常会話では「〜だ」や短縮形が自然に使われる。

 **読み方:** げんごはばめんによってつかいわけである。 にほんごにおいて、かきことばとはなしことばのさは特におおきいと思われる。せいしきなぶんしょでは「〜である」というひょうげんがもちいられるいっぽう、にちじょうかいわでは「〜だ」やたんくけいがしぜんにつかされる。 

**ローマ字:** ゲンゴはバーメンニヨッテカイワケルモノデアル。 にほんごにあって、かきことばとはなしことばのさは、とくとくにおうきいとえる。 Seishiki na bunsho dewa "〜de aru" to iu hyōgen ga mochiiraeru ippō, nichijō kaiwa dewa "〜da" ya tanshukukei ga shizen ni tsukawareru.

 **理解に関する質問:**
 1. 言語をどのように使い分けるべきですか。 
2. 正式な文書ではどんな表現が使われますか。 — 正式な文書ではどのような表現が使われますか?
 3. 日常会話では自然に使えると書いてありますか。 

**答え:**
 1. 場面によって使い分けです。 
2. 「〜である」という表現が使われます。 
3. 「〜だ」や短縮形が自然に使われます。 

## 文化的なメモ

 「場の空気」（場の空気、「その場の空気」）の概念は、日本のコミュニケーション文化に深く組み込まれています。 日本人は話す前に、暗黙のうちにいくつかの合図を読みます。「参加者は誰ですか?」 設定は何ですか? 力関係はどうなっているのでしょうか？ 親しい同僚とカジュアルに会話している上級従業員は、マネージャーが部屋に入るとすぐに正式な登録に切り替わります。このコードの切り替えはアナウンスなしで流動的に行われます。 この切り替えを適切に行えないことは、非母語話者が犯す可能性のある最も顕著な社会的間違いの 1 つです。 

*soto/uchi* (外側/内側、外側/内側) の区別もレジスターの選択を決定します。 自分のグループについて部外者に話すときは、目上の人に対しても謙譲語を使います。 内グループに対して外グループについて話すときは、彼らに対して敬意を持った言葉を使います。 この階層化されたシステムは、登録が単に「どの程度フォーマルになりたいか」というものではなく、社会的関係全体をすべての文にエンコードしていることを意味します。 N3 では、このシステムのロックを解除し始めています。これが、N3 の文法が N4 からの大幅な飛躍のように感じられる理由の 1 つです。
