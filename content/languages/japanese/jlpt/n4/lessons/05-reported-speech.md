## 概要

 報告スピーチは、N4 レベル以降の中核となるコミュニケーション スキルの 1 つです。 実生活では、誰かが言ったことを伝えたり、自分の考えを共有したり、聞いたことを報告したり、出典を引用したりする必要が常にあります。 日本語では、**引用助詞「と**」を使用して、報告された内容を「言う」、「思う」、「聞く」、「考える」、「感じる」などの動詞にリンクします。 これらすべてのパターンを統合する重要なルールは、文の残りの部分がどれほど丁寧であっても、「と」の前の内容は常に **平易な形式** でなければならないということです。 

このレッスンでは、よくある混乱の原因、つまり「〜と言う」（直接/間接的に報告されたスピーチ）、「〜によると〜そうだ」（出典の引用）、「〜らしい」（見かけ上の伝聞）の重複についても取り上げます。 直接話法​​を間接話法に変換する練習をし、報告された文節で時制がどのように機能するかを学び、情報をその情報源に正しく帰属させる能力を養います。 このレッスンのドリルは、N4 で最もよくある間違いの 1 つである、「と」句内で「ます」形式を使用するエラーに特に焦点を当てています。 

## 学習目標

 このレッスンを終了するまでに、次のことができるようになります。 
- 〜と言う/言ったを使用して、直接音声と間接音声の両方を正しい平文埋め込みで報告します。 
- 自分の意見や推論を表現するには、「〜と思う/思った」を使用します。 
- 情報源を引用し、伝聞情報を伝えるには、「〜と聞く/聞いた」と「〜によると〜そうだ」を使用します。 
- 直接話法文 (「 」引用符付き) を平文 + を使用して自然な間接話法に変換します。

 ## 文法ポイント

 ### 1. 〜と言う / 〜と言った (報道されたスピーチ — 直接的および間接的)

 **構造:** [普通形節] + 言う / 言った / 言ってる / 言っていた

 **説明:**

 ここでの助詞「と」は**引用符**であり、接続詞の「および」ではありません。 「」より前のすべては、話された内容の*内容*であり、この内容は平易な形式でなければなりません。 「と」に続く動詞は、言語行為との関係を示します。 

- と言う = 「そう言う」（現在/習慣）
 - 言った = 「言った」（過去の報告）
 - 言っている = 「それを言っています/それを言っています」
 - 言っていた = 「それを言っていた」

 直接話法を間接話法に変換すると、引用符内の「ます」と「です」の形式はすべて、平文の等価物になります。 報告されたコンテンツの時制は、報告されたときではなく、*アクションが発生したとき*を反映します。 

**直接音声→間接音声変換の例:**

 | 直接スピーチ | 間接話法 |
 |--------------|----------------|
 | 「明日行きます」と言った。 明日行くと言った。 
| 「美味しくないです」と言った。 美味しくないと言った。 
| 「学生でした」と言った。 学生だったと言った。 
| 「雨が降りますか」と聞きました。 雨が降ると聞いた。 

**その他の例:**

| 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 田中さんは来週来ると言った。 たなかさんはらいしゅうくると言った。 田中さんはいつも笑ってる。 | 田中さんは来週来ると言った。 |
 | 先生は試験は馬鹿ないと言っていました。 せんせいはしけんはむずかしくない思いました。 先生は先生はムズカシクナイとイッテマシタ。 | 先生は試験は難しくないと言っていた。 |
 | 彼女は「疲れた」と言った。 かのじょは「つかれた」と言った。 カノジョは「つかれた」かった。 | 彼女は「疲れた」と言った。 |
 | 母は早く帰ってきて言ってました。 はははやくかえいっていた。 はははやく帰ってイタ。 | 母は早く帰ってくると言っていた。 |
 | 彼はもう戻ってきました。 カレはもうかえったといいました。 彼はもう消えたと言いました。 | 彼はもう家に帰ったと言った。 |
 | 山田さんが結婚していると言っている。 やさんがまだけっこんしているところ。 山田さんがケッコンしていると言ってる。 | 山田さんは結婚すると言っています。 |

 **よくある間違い:**
 ❌ 彼は来ますと言った → ✓ 彼は来ると言った
 (報告されたスピーチでは「」の前には決して「ます」を使用しない)

 ### 2. 〜と思う / 〜と思った (Think That — 意見と推論)

 **構造:** [平文] + と思う (現在の考え) / と思った (過去の考え)

 **説明:**

 と思うは次のような用途に使用されます。 
1. **発言者の現在の意見**を表現します: 私はこれは正しいと思います (私はこれが正しいと思います)
 2. 証拠から**暫定的な結論**を表現します: 明日は雨だと思う (私は明日は雨が降ると思います)
 3. 第三者で、誰かが考えていることを報告します: 彼はいいと思っている (彼はそれが良いと思っています)

 重要: 「と思った」が一人称で使用される場合、「私は考えた」(変更された可能性のある過去の信念) を意味することも、意見を形成した瞬間を表すこともできます。 

**例:**

 | 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 私はこの映画は面白いと思います。 私はこのえいがは面白いとおもいます。 私はこの映画は面白いと思います。 | この映画は面白いと思います。 |
 | 明日は雨が降ると思います。 あしたはあめがふるとおもう。 明日は雨が降ると思う。 | 明日は雨が降ると思います。 |
 | 彼は来ないと思った。 かれはそうですねとおもった。 彼はこんなことを思っていない。 | 彼は来ないと思った。 |
 | 彼女はもう家に着ていたと思います。 かのじょはもういえにつきました。 彼女はもう家にいると思っています。 | 彼女はもう家に着いたと思います。 |
 | 先生はそれは正しいと思っている。 せんせいはそれはともかくおもっている。 先生はそれを正しいと思っている。 | 先生はそれが正しいと思います。 |

 **よくある間違い:**
 ❌ 私は明日は雨が降りますと思います → ✓ 私は明日は雨が降ると思います
 (と思う前の普通形、いつも)

 ### 3. 〜と聞く / 〜と聞いた / 〜によると〜そうだ (それを聞いた / によると)

 **構造:**
 - [普通形] + と聞く/聞いた = 「それを聞いた/聞いた」
 - [出典] + によると + [平文] + そうだ/そうだ = "[出典] によると、..."

 **説明:**

 「聞く/聞いた」は、誰かから聞いた情報を報告し、話者はそれを聞いたことに対してある程度の個人的な責任を負います。 これは個人的な伝聞です。誰かがあなたに直接言った話です。 「によると〜そうだ」は、外部の、多くの場合正式な情報源（ニュース、本、天気予報、第三者）を引用するためのもので、情報はより腕を伸ばして感じられます。 どちらも「」の前に平文が必要です。 

**例:**

 | 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 田中さんが転職すると聞きました。 たなかさんがてんしょくするときた。 田中さんは転生するって聞いた。 | 田中さんが転職したと聞きました。 |
 | 先生から、試験が来週あると聞きました。 せんせいから、しけんがらいしゅうあるときでした。 先生から、試験が集中していると聞きました。 | 先生から来週試験​​があると聞きました。 |
 | | 天気予報によると、明日は雪が降るそうです。 てんきよほうによると、あしたはゆきがふるそうです。 天気予報に夜と、明日は雪が降るそうです。 | 天気予報によると、明日は雪が降るそうです。 |
 | ニュースによると、地震があったそうだ。 にゅーすによると、じしんがあったそうだ。 乳に夜と、自分があったんだ。 | ニュースによると、地震があったそうです。 |
 | 友達によると、あの店は高いですね。 ともだちによると、あの見せはたかいそうだよ。 トモダチの夜と、あの店はとても美味しいですよ。 | 友達によると、あの店は高いらしい。 |

 **よくある間違い:**
 ❌ 天気予報によると、明日は雪が降ると言いました → ✓ 天気予報によると、明日は雪が降るそうです
 (外部ソースには「によると」を使用して「そうだ」を使用します。「言いました」は特定の人が話していることを意味します)

 ## 文法ドリル

 括弧で囲まれた直接音声を間接音声に変換するか、不足している助詞/形式を埋めます。 答えは以下。 

1. 田中さんは「明日来ます」と言った。→ 田中さんは明日_____と言った。 
2. 先生から、仕事が多い___聞きました。 
3. ニュース___よると、明日は晴れる___です。 
4. 彼女は「映画が好きです」と言っていた。→ 彼女は映画が_____言っていた。 
5. 私はこの本はつまらない___思います。 
6. 母は「早く起きなさい」と言った。→ 母は早く起き___言った。 
7. 友達が教えてくれました。その店は安い___。（そうだ）→ ___
 8. 「電車が遅れています」と駅員が言った。→ 電車が遅れている___駅員が言った。 
9. 先生は試験は来週___言っている。 
10. 田中さんが転勤する___聞きましたが、本当ですか。 

**回答キー:**
 1.来ると（普通形：くる）
 2. とを（と）
 3.によると / そうです
 4. 好きだ（普通形）
 5. と（と思います）
 6. よう（よう + に）
 7. 友達が教えてくれたが、その店は安いそうだ。 
8. と（電車が遅れていると）
 9. あると（あることを言っている）
 10. と（転勤すると）

 ## 翻訳の練習

 ### 英語→日本語

 1. 田中さんはパーティーに来ないと言った。 
2. 明日は寒くなると思います。 
3. ニュースによると、その店は昨日閉店したそうです。 
4. 試験はとても難しかったと聞きました。 
5. 彼女は「日本に行ったことがない」と言っていました。

**答え:**
 1. 田中さんはパーティーに来ないと言った。 
2. 明日は寒いと思います。 
3. ニュースによると、その店昨日は閉まっていたそうだ。 
4. 試験はとても難しかったと聞きました。 
5. 彼女は「日本に行ったことがない」と言っていた。 

### 日本語→英語

 1. 先生は「来週は休みだ」と言いました。 
2. 友達から、あの映画は面白くないと聞いた。 
3. 天気予報によると、今夜は雪が降るそうです。 
4. 私は彼女はもう大学を卒業したと思っていた。 
5. 彼は「気づかない」とだけ言った。 

**答え:**
 1. 先生は「来週は休みです」と言った。 
2. 友達からその映画は面白くないと聞きました。 
3. 天気予報によると、今夜は雪が降るそうです。 
4. 彼女はもう大学を卒業したと思っていました。 
5. 彼は「分かりません」とだけ言いました。

 ## 文化的なメモ

 報告された日本のスピーチは、**情報源と信頼性**に対する深い文化的敏感さを反映しています。 日本語は、個人的に観察したこと、論理的に結論付けたこと、友人から聞いたこと、権威ある情報源が報告したことを文法的に区別することで、**認識論的責任**、つまり情報に対する責任の所在をすべての文にエンコードします。 すべてに「そうだ」と単純に言うことができないのはこのためです。日本語の文法では、情報をどこで入手したかを明確にする必要があります。 

これは、「と思います」がなぜ日本語の会話に広く使われるのかも説明しています。 発言を「私は思う」と組み立てることで、講演者は知的な謙虚さと間違いに対する寛容さを示します。 これは弱いコミュニケーションではありません。日本文化では、異なる意見を持つ聞き手の権利を尊重していることを示す**思いやりのあるコミュニケーション**です。 自信過剰な絶対的な発言は攻撃的に見えるかもしれませんが、適切な位置にあると思いますは社会の調和を保ちます。

 ## セルフチェック

 1. たとえそれが丁寧な文であっても、報告されたスピーチでは、平文が常に「と」の前に置かれなければならないのはなぜですか?
 2. 田中さんが来ると聞いた と 田中さんが来るそうだ はどう違いますか？ 
3. 変換：「もう食べました」と言った→間接話法。 
4. 「と聞いた」ではなく「によると〜そうだ」を使うのはどんなときですか?
 5. 「思った」と「思っている」はどう違いますか? それぞれに例を示します。
