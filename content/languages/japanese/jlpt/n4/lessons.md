 ## レッスン 1: N5 から N4 — 平易な形式と礼儀正しさのレベル

 ### 目的
 - 平文（辞書）形式と丁寧語（〜ます/〜です）の違いを理解する
 - 各レジスタをいつ使用するかを理解する
 - テキスト（小説、ブログ、ニュース）を読んで平文を認識する
 - 丁寧語でも従属節では平易な形式を使用する

 ### 重要な語彙
 | 日本語 | 読書 | 英語 |
 |----------|-----------|----------|
 | 普通体型 | 普通にいたい | プレーンフォームスタイル |
 | 丁寧体 | ていねいたい | 丁寧なフォームスタイル |
 | 敬語 | けいご | 敬語 |
 | タメ語 | ためご | カジュアルスピーチ (対等/友達) |
 | 目上 | めうえ | 優れた; 地位の高い人 |
 | 目下 | めした | 下位; 身分の低い人 |
 | 同僚 | どうりょう | 同僚 |
 | 初対面 | しょたいめん | 最初の会議。 初めて会う |

 ### 文法復習
 - **単純な肯定**: 食べる / 食べた / 食べている
 - **単純な否定**: 食べない / 食べなかった / 食べていない
 - **丁寧な肯定**: 食べます / 食べました / 食べています
 - **丁寧な否定文**: 食べません / 食べませんでした / 食べていません

 ### プレーンフォームを使用する場合
 1. **親しい友人や家族との会話** (同年や友達)
 2. **従属節** — 丁寧語でも: 食べると思います (彼は食べると思います — 丁寧な言葉の中で普通に食べる)
 3. **書かれた日本語**: 小説、日記、エッセイ、ニュース記事
 4. ストーリー内の **内部独白**

 ### ダイアログ 1: 新しい学校での初日 (正式な学校から普通の学校への移行)
 **シーン**: ケイコ（新入生）はユキ（クラスメイト）と出会い、友達になります。 

**会議（公式）**

 **シーン**: アレックス（外国人学習者）は、いつ普通の形式を使用するべきかについて教師に尋ねます。

## レッスン 2: Te 形式の複合アクション

 ### 目的
 - 4つの主要なテ形複合パターンをマスターします: 〜てから、〜てなる、〜保管、〜てみる
 - 両者のニュアンスの違いを理解する
 - カジュアルな短縮形「〜ちゃう、〜じゃう、〜とく」を自然に使う

 ### 重要な語彙
 | 日本語 | 読書 | 英語 |
 |----------|-----------|----------|
 | 準備 | じゅんび | 準備 |
 | 後悔 | こうかい | 後悔 |
 | うっかり | うっかり | 不用意に; 偶然 |
 | | | 多大な努力を払って。 特に |
 | 失敗 | しっぱい | 失敗; 間違い |
 | 念のため | ねんのため | 安全のために。 念のため |

 ### 文法重視
 - 〜てから: 厳密な順序 (最初に A を完了する必要があります)
 - 〜てしまう: 完全に完了した、または偶然/後悔した行動
 - 〜備: 意図的に準備すること。 状態をそのままにしておく
 - 〜てみる：実験的な試み

 ### ダイアログ 1: 旅行の計画を立てる
 **シーン**: リョウとハナは京都への旅行を計画しています。

リョウ：京都に行く前にホテルを予約したほうがいいですね。 

花: そうだね。でも、行き先を決めてから予約しようよ。 
ハナ：そうだね。 デモ、イキサキをキメてからヨヤクしようよ。 
ハナ：いい指摘ですね。 ただし、予約する前にどこに行くかを決めましょう。 

涼: 念のため、観光地も調べてこう。 
Ryou: ネンノタメ、カンコウチモシラベテオコウ。 キョネン、ヨヤクシナイデイッテ、ゼンブマンインデガッカリシテシマッタンだよ。 
リョウ：念のため観光スポットを調べておきましょう。 去年は予約せずに行ったら満席で、本当にがっかりしました。 

花: そうか。それでは、まずは地図を見てみよう。 
ハナ：そうか。 じゃぁ、まづちずをみてみよう。 
ハナ：なるほど。 それでは、まずは地図を見てみましょう。

 ## レッスン 3: 与えることと受け取ること

 ### 目的
 - 3つの動詞をマスターする：あげる、もらう、くれる
 - 複合アクションを作成するためにそれらを適用します。 
- 日本語でこの概念を表す動詞が 3 つある理由を理解する
 - よくある間違いを避ける（利益の方向を混同する）

 ### 重要な語彙
 | 日本語 | 読書 | 英語 |
 |----------|-----------|----------|
 | 恩 | おん | 好意; グレース |
 | 親切 | しんせつ | 優しさ |
 | お礼 | おれい | 感謝の気持ち |
 | 迷惑 | めいわく | トラブル; 不便 |
 | 申し訳ない | もうしわけない | 本当に申し訳ありません。 言い訳はありません |
 | ご遠慮する | えんりょする | 控える。 我慢する |
 | お互い | おたがい | お互い; 相互 |

 ### 文法重視
 **利益の方向性:**
 - 与える：私/私たちは与える→他の人（または：他の人が与える→他の人）
 - 与える: 他の人が与える → 私 (または私のグループ内)
 - 受け取る: ←他人から受け取ります

 **Te 形式のバージョン:**
 - 〜てあげる: 私は誰かのためにXをします
 - 〜てくれる: 誰かが私にXをしてくれる
 - 〜てもらう: 私は誰かにXをしてもらいます/私はそのアクションを受け取ります

 ### 「グループ内」の概念
 日本語には「うち（内集団）」と「外（外集団）」という概念があります。 話者と話者の近親者/グループは「グループ内」です。 グループ内に利益が流入する = 与える/受け取る。 利益が流出する＝与える。

### ダイアログ 1: 誕生日のサプライズ
 **シーン**: マヤは友人からプレゼントと助けを受け取ります。 

マヤ: 誕生日なのに、来てくれてありがとう！ 
マヤ：たんじょうびなのに、来てくれてありがとう！ 
マヤ：誕生日なのに来てくれてありがとう！

ユジン：モチロンだよ。 コレ、プレゼント。 つくってきたよ。 
友人：もちろんですよ！ プレゼントです。 作って持ってきました。 

マヤ: 手作り！ うれしい。ケーキも作ってくれたの？ 
マヤ：手づくり！ うれしい。 けーきもつくってくれたの?
 マヤ「手作り！」 私はとても幸せです。 私にもケーキを作ってくれましたか？ 

友人:うん。それと、準備も頑張ってあげるよ。何かある？ 
ユジン：うん。 それまで、準備もしてあげるよ。 ナニカある？ 
友人: そうだね。 そして準備もお手伝いさせていただきます。 何かすることはありますか？ 

マヤ: じゃあ、飾りを飾るのを受けて？ 
マヤ：じゃぁ、かざりをかざるのをつだってもえる?
 マヤ：それでは、飾りつけを手伝ってもらってもいいですか？ 

友人: いいよ一緒に！

### ダイアログ 2: 助けを求め、与える
 **シーン**: 学校で、生徒が教師に助けを求めます。 

生徒: 先生、この問題はわからないので、説明していただけますか。 
セイト：先生、このモンダイが分からないので、セツメイシテいただきますか。

### 演習
 1. 正しい動詞 (与える/くれる/もらう) を選択してください:
 - 友達が私に本を貸して＿＿＿た。(私の友達 → 私)
 - 私は妹の本を読んで＿＿＿た。(私 → 私の妹)
 - 私は先生に推薦状を書いて＿＿＿た。 (先生から受け取りました)

 2. 翻訳: 「母が私のために夕食を作ってくれました。」 / 「観光客のために道を説明しました。」 / 「医者は私に薬を処方してくれました。」

 3. 日本語にはなぜ 3 つの別々の与える/受け取る動詞があるのですか? 学んだことをもとに英語で短い説明を書きます。

 ## レッスン 4: 可能性と確率の表現

 ### 目的
 - 〜かもしれない、〜はずだ、〜でしょう/だろうを正しく使いましょう
 - 0% から 100% までの確実性のスケールを理解する
 - 推論パターンを区別する: たぶん無理 vs. はずだ vs. そうだ vs. ようだ vs. らしい

 ### 重要な語彙
 | 日本語 | 読書 | 英語 |
 |----------|-----------|----------|
 | 可能性 | かのうせい | 可能性 |
 | 確実 | かくじ | ある; 明確な |
 | 不確か | ふたしか | 不確か |
 | 予測 | よそく | 予測; 予測 |
 | 秘密 | しょうこ | 証拠; 証明 |
 | 推測 | すいそく | 推論; 推測 |

 ### 確実性スケール
 | 式 | 信頼レベル | 基礎 |
 |-----------|------|------|
 | 〜に違いない | ~95% | 非常に自信のある推理 |
 | 〜はずだ | ~80% | ロジック/期待 |
 | 〜だろう | ~70% | 発言者の判断 |
 | 〜ようだ | ~60% | 自分自身の観察 |
 | 〜らしい | ~60% | 伝聞/間接証拠 |
 | 〜そうだ（出演） | ~60% | 直接的な視覚的手がかり |
 | 〜できないかも | ~50% | 不確実性 |

 ### ダイアログ 1: 天気当てゲーム
 **シーン**: 2 人の友人が窓の外を見て、明日の天気を予測します。

田中：空が暗いですね。 明日は雨が降るかもしれない。 

林：天気予報によると、晴れるらしいよ。 
林：天気予報の夜と、晴れるらしいよ。 
林：天気予報によると晴れるそうですよ。 

田中: えっ、本当？でも、今夜は曇ってるから、朝には変わらないかもしれない。 
田中：え、ホント？ デモ、今夜は曇ってるから、朝にはかわるかもしれない。 
田中：本当ですか？ でも今夜は曇りなので朝には変わるかもしれません。

林：まあ、朝になればわかるですよ。 デモ、ネンのためかさをもっといくべきじゃないかな。 
林：そうですね、朝までにはわかるでしょう。 でも、念のために傘を持って行ったほうがいいんじゃないでしょうか？

田中: そうだね。持ってないとくよ。

 ## レッスン 5: 報道されたスピーチと引用

 ### 目的
 - 発言や考えを報告する場合は、「言う、と思う、と聞く」を使用します。 
- 引用されたコンテンツは常に平文であることを理解する
 - 出典を引用するには「〜によると」を使用します

 ### 文法重視

| パターン | 使用 |

 ## レッスン 9: 複雑な名詞の修飾

 ### 目的
