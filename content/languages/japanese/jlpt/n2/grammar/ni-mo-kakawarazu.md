## パターン

 **〜ではない**
 (ニモカワラズ)

 ## 構造

 - **名詞 + 違う**
 - **動詞 (普通形) + ならぬ**
 - **I-形容詞 (普通形) + ならぬ**
 - **な形容詞 + である + 違う** (形式的)
 - **な形容詞 + な + ならぬ** (ややフォーマル度が低い)

 ## 形式レベル

 **フォーマル** — 書かれた日本語、ニュース、学術的、法律的な文脈。 口頭での同等の表現は「〜のに」（よりくだけた、感情的な表現）です。 

## 意味

 「Xにもかかわらず」、「Xにもかかわらず」、「Xにもかかわらず」。 **対照的で予想外の結果**を表します。X は、通常は異なる結果につながると予想される実際の事実または条件ですが、Y はその予想に反して予期せず発生します。 

コントラストのニュアンスが強いため、このパターンは、コントラストが本当に印象的または注目に値する場合に適しています。 些細なコントラストや予想されるコントラストには使用しないでください。 

## 例

 | 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 多大な努力なしに、プロジェクトは失敗した。 いだけとかりょくなく、プロジェクトはしっぱいした。 タダイナドリヨクにもかかわらず、プロジェクトは頑張った。 | 多大な努力にもかかわらず、プロジェクトは失敗に終わりました。 |
 | 警告を受けても、彼は行動を改めませんでした。 けいこくを受け取った以外は、かれはこうどうをあらためなかった。 けいこくをうけたにもかかわらず、彼はこうどうをあらためなかった。 | 警告を受けたにもかかわらず、彼は態度を変えなかった。 |
 | 当面困難がなく、政府は新たな支出を計画している。 ざいせいなんでもない、せいふはあらたなししゅつをけいかくしている。 在世半にも関わらず、人生は新たな活動を計画している。 | 財政難にもかかわらず、政府は新たな支出を計画している。 |
 | 反対意見が多いですが、計画は承認されました。 はんたいいやがおおいではなく、けいかくはしょうにんされました。 ハンタイ・イケン・ガ・オーイ・ニモ・カワラズ、ケイカク・ワ・ショウニン・サレタ。 | 広範な反対にもかかわらず、その計画は承認された。 |

 ## 〜に対抗するための重要な区別

 | | 〜に対抗 | 〜ではない |
 |-|--------------|--------------|
 | 意味 | 関係なく (X は関係ありません) | それにもかかわらず (X は重要であるべきでしたが、とにかく Y が発生しました) |
 | X | 変数/スペクトル (経験、天気、性別) | 具体的な実際の障害または期待 |
 | 結果 | 普遍的に同じ | X が提案するものと予想外に異なる |
 | | に置き換えます 「関係なく」 | 「にもかかわらず」 / 「にもかかわらず」 / 「にもかかわらず」 |

 **記憶トリック:** もも (も) = 「それさえも」 — にもかかわらず、障害を強調します: 「その事実が [与えられても]、[予期せぬ結果] であっても」。 

## 〜のにとの比較（音声）

 | パターン | 登録 | 感情的なトーン |
 |----------|----------|---------------|
 | 〜ではない | フォーマル/書面 | ニュートラルで客観的なコントラスト |
 | 〜のに | 非公式/口語 | イライラしたり、驚いたり、非難したり |

 例:
 - 努力した以外、失敗した（書かれた、客観的な）
 - 努力したのに、失敗した（感情的な欲求不満を伴う口語）

 ## よくある間違い

 - ❌ 雨が降る代わりに、傘を持ってきた → 雨が降ったので傘を持ってきたら、意外な事はありません。 使い方：〜なので（だから）。 
- ✓ 大雨無し、屋外での作業を続けた (大雨にもかかわらず屋外での作業を続ける — まさに予想外のコントラスト)
