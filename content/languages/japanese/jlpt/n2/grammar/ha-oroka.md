## パターン

 **〜はおろか**
 (わおろか)

 ## 構造

 - **名詞 A + はおろか + 名詞 B + も/さえ/すら + [否定または極端な述語]**
 - **名詞 A + はおろか + 名詞 B + も/さえ + [正極述語]** (正の方向はあまり一般的ではありません)

 通常、述語は A と B の両方に適用されますが、B (より簡単またはより基本的なものである必要があります) も不可能または真であることに焦点を当てます。 

## 形式レベル

 **形式的/文章** — 文学的およびジャーナリズム的な日本語。 日本語の話し言葉では、同じ意味で「〜お知らせ」が代わりに使用されます。 

## 意味

 「Xどころか、Yさえも」 X (より極端/難しいケース) と Y (より基本的/簡単なケース) を提示することで極端なコントラストを生み出し、Y ですら不可能であれば X は明らかに問題外であると主張します。 

**2方向:**

 **否定的な方向 (最も一般的):** 「X (難しいこと) はおろか、Y (簡単な方) さえもできません。」
 - 日本語はおろか、日本語さえ話せない (英語はおろか、日本語も話せません)
 → 英語は難しいです。 もっと簡単な日本語もできない

 **ポジティブエスカレーション:** 「X (予想されるもの) だけでなく、Y (より極端なもの) もです。」
 - 国内はおろか、海外でも評価された (国内だけでなく海外でも評価されました)

 ## 〜のみならずと〜だけかとの重要な区別

 | パターン | 構造 | 主な機能 |
 |----------|-----------|---------------|
 | 〜のみならず | A + のみならず + B (中立) | 中立的な範囲の拡大: 「A だけでなく B も」 |
 | 〜ばかりか | A + ばかりか + B も/まで | 驚くべきエスカレーション: B は予想以上に過激 |
 | 〜はおろか | A + はおろか + B さえ/すら | スケールのコントラスト: B (簡単な) ですら不可能な場合、A は明らかに問題外です。 

**おろかのための重要なテスト:** A と B は同じスケールですが、A がより極端であるという明確な **スケールまたは階層** はありますか? 「はい」の場合、おろか。 中性添加の場合はのみを使用してください。 

## よくある間違い

 - ❌ 環境はおろか、経済も重要 → スケールのコントラストなし (どちらも同様に重要なトピック)。 用途:環境のみならず、経済も重要だ。 
- ✓ 話せないはおろか → 活用が間違っています。 名詞 + はおろかが正しいです。 動詞の場合は、普通の形式を使用するか名詞化します。 
- ✓ 会話はおろか、文字の認識すらわからない (正しい尺度: 会話はおろか文字さえ読めない)
