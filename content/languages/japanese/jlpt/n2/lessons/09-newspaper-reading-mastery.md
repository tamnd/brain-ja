## 概要

 JLPT N2 の読解セクションでは、時間のプレッシャーの下で、緻密で形式的な日本語の文章から意味を抽出する能力をテストします。 テキストが比較的単純な N3 とは異なり、N2 のパッセージでは受動態のヘッジ、名詞化、形式的な接続詞、学術的な距離を置く手段が広範囲に使用されています。 読者がすべての単語を解析しようとすると時間切れになってしまいます。 主要な構造マーカーを特定できない読者は、著者の立場を誤解するでしょう。 このレッスンでは、戦略的な読解テクニックとともに日本語の散文の正式な文法を教えることで、両方の課題に対処します。 

このレッスンの文章は、実際の新聞の社説や政策レポートのスタイル (N2 試験に出題されるジャンルとまったく同じ) をモデルにしています。 〜とされているや〜によると〜というようなヘッジ手段を認識し、受動的な構文がジャーナリズムの文章でどのように客観性を生み出すのかを理解し、名詞化を使用して複雑な文の論理構造を識別することを学びます。 最後のセクションの時間を決めて読む戦略と組み合わせると、このレッスンは理解の正確さと読む速度の両方を大幅に向上させるはずです。 

## 学習目標

 このレッスンを終了するまでに、次のことができるようになります。 
- 学術的なヘッジパターン「〜とされている」と「〜によると〜」を文脈の中で認識し、解釈する。 
- 受動的な構文と名詞化が正式な日本語の書き言葉でどのように機能するかを理解します。 
- N2 の長さの文章に流し読み→スキャン→詳細読み取り戦略を効率的に適用します。 
- 練習された構造認識を使用して、N2 リーディングセクションで時間を効果的に管理します。

 ## 文法ポイント

 ### 1. 〜とされている (—学術的なヘッジであると考えられている/言われている)

 **構造:** 動詞/形容詞/名詞 + とされている / とされ続けた

 〜とされているは、「〜であると考えられる」、「〜であると言われる」、または「X は Y であるとみなされる」を意味する非人称受動構造です。 情報源を特定せずに、信念や評価を一般的な合意、学術コミュニティ、または確立された見解に帰するものです。 このパターンは、著者が個人的に保証することなく、情報を一般的な知識や合意として提示する学術論文や新聞報道で非常によく見られます。 

過去進行形〜とされてきたは、これが時間の経過とともに確立された見解であることを示します。「長い間そう考えられてきた」。 

**登録:** 学術、ジャーナリズム、公務員。 正式な日本語の書き言葉には必須です。 

**〜と言われているとの違い:** 〜と言われている（「〜と言われている」）は口頭での伝達/噂を強調します。 〜とされているは、形式的な分類や公式/学術的な合意を強調します。

 ### 2. 〜によると〜という / 〜によれば〜とのことだ (Xによれば、Yだそうです)

 **構造:**
 - 出典 + によると / によれば + 文 + という / のことだ / とされている

 このパターンでは、報告された情報が新聞、政府報告書、専門家、調査などの特定の情報源に帰属します。 これは、情報源を引用するための標準的なジャーナリズム手段です。 語尾の「という」または「とのことだ」は、情報が報告された音声であることを示します。 という使用中に出典属性マーカーを省略すると、文が引用ではなく事実の陳述のように見える可能性があります。 

**登録:** ジャーナリズム、フォーマル。 ニュース形式の日本語を理解し、書くために必須。 

| 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 政府の発表によると、今年の経済成長率は2.3%になるという。 せいふのはっぴょうによると、ことしのけいざいせいちょうりつにてんさんぱーせんとになるという。 制服の幸せの夜と、ことの経済 生活リズムは 2.3% になるということです。 | 政府の発表によると、今年の経済成長率は２．３％と予想されている。 |
 | 報告書によれば、問題の拡大は今後10年で加速する恐れがあるということだ。 ほうこくしょによれば、かくさのかくだいはこんご10ねでかそくする権利があるとのことだ。 法国書に寄れば、くさのかくだいは金剛10年でかそくする恐ろしさがあるということだ。 | 報告書によると、今後10年間で格差拡大が加速するリスクがあるという。 |
 | 専門家の見解によると、現在の当面の政策は持続可能とされているという。 せんもんかのけんかいによると、げんこうのざいせいせいさくはじぞくふかのうとされているという。 宣告のかげんかいに夜と、元寇の在世生活は現実にふかのうとされていると言う。 | 専門家の意見によれば、現在の財政政策は持続不可能であると考えられていると言われています。 |

 ### 3. ニュース形式の受動構文 (客観性のために〜れる/される)

 ニュース日本語では、受動態は単に主題が何かに反応していることを示すためだけでなく、*客観性と距離感を生み出すための文体的な手段**としても使用されます。 著者は「私はこう思う」や「政府は○○をした」と言うのを避け、代わりに受動態を使って情報を事実的で非個人的なものとして表現しています。

よくあるパターン:
 - 〜と指摘されている→「〜と指摘されています」
 - 〜と見られている → 「見られている/見られている」
 - 〜と懸念されている → 「〜と懸念が表明されている」
 - 〜と判断される → 「〜と判断される」
 - 〜と考えられる→「〜と考えられる」

 | 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 今回の失策は、事前調整の不足によるものと見られている。 こんかいのしっさくは、じぜんちょうせいのふそくによるものとみられている。 こんかいの仕事は、じぜんちょうせいのふそくに夜のものと奇跡がある。 | 最近の政策の失敗は、事前の調整が不十分だったためとみられている。 |
 | 新しい臨時の施行により、中小企業への影響が懸念されている。 しんぜいせいのしこうにより、ちゅうしょうきぎょうへのえいきょうがけんねんされている。 新時代の任務より、中正期への栄光が健在である。 | 新税制の施行による中小企業への影響が懸念されている。 |
 | このデータから、社会的不安がさらに拡大する恐れがあると指摘されている。 このデータから、しゃかいてきかくさがさらにかくだいする権利があるとしてきられている。 このだから、シャカイテキ・クサ・ガ・サラに、恐ろしさがあるとされている。 | このデータから、社会的格差がさらに拡大する危険性が指摘されています。 |

 ### 4. 見出しと密集した文章の名詞化

 日本の学術文書やニュース文書では、名詞化が多用されています。つまり、〜こと、〜の、形式名詞語尾を使用して動詞や節を名詞句に変換することです。 これにより、正式に書かれた日本語の特徴である、高密度で情報が詰まった文章が作成されます。 

**正式なテキストにおける一般的な名詞化パターン:**
 - 動詞（普通形）+こと/の→Xをする行為
 - 動詞（普通形） + ため → for the purposes of / because of
 - 〜化 (接尾語) → X になる過程 (例: 少子化, 高齢化, グローバル化)
 - 〜性 (接尾辞) → X の性質/性質 (例: 持続可能性、実効性、重要性)

 **密文分析の例:**

 「少子高齢化の急速な進展に伴う労働力不足の現実化が、日本経済の持続可能性に対する最大の展望の一つとされている。」

 読み方：しょうしこうれいかのきゅうそくなしんてんともなうろうどうりょくぶそくのしんこくかが、にほんけいざいのじぞくかのうせいにたいさいするだいのきょういのひとつとされている。 

訳：「急速な少子高齢化の進展に伴う労働力不足の深刻化は、日本経済の持続可能性に対する最大の脅威の一つであると考えられます。」

 **構造の内訳:**
 - 少子高齢化の急速な進歩 = 少子高齢化の急速な進行
 - 〜に伴う (レッスン 3 の復習) = 伴う
 - 労働力不足の深刻化 = 深刻化する労働力不足（〜化で名詞化）
 - 日本経済の持続可能性 = 日本経済の持続可能性 (〜性名詞化)
 - とされている＝（学術的ヘッジ）とみなされる

 ## 本物のテキストのサンプル

 ### テキスト 1: 経済学の編集スタイル

 > 政府の最新統計によると、今年度の実質GDP成長率は適宜比0.8%増に止まったという。専門家の間では、この数値は景気回復の鈍化を示すものとされており、当面の動きの是非をめぐって議論が正常化している。 

**読み方:** せいふのさいしんとうけいによると、こんねんどのじっしつGDPせいちょうりことぜんねんひ0.8ぱーせんとぞうに止まったという。 ざいせいしゅつどうのぜひをめぐってぎろんがかっぱつかっている。いっぽうで、ぶっかじょうしょうがかけいに予想えいきょうをけねんするこえもおく、きんゆうせいさくのみやり直しがきっきんのかだいとみをしている。 

**分析:**
 - **によると〜という** → 政府統計への帰属
 - **とされています** → 学術的コンセンサスヘッジ（継続フォーム）
 - **をめぐって** → レッスン 3 の復習: 議論のあるトピックの周囲/それについて
 - **憂慮する声も多く** → 懸念のジャーナリズム受動的：「懸念を表明する声が多い」
 - **と見守っている** → 「であると考えられている」 — 学術的距離の別の形態

 **全訳：** 「最新の政府統計によると、今年度の実質GDP成長率は前年度比0.8％増にとどまったと伝えられている。専門家の間ではこの数字は景気回復の鈍化を示すものと考えられており、財政出動の是非について議論が過熱している。一方で、物価上昇による家計への影響を懸念する声も多く、金融政策の見直しが喫緊の課題とされている。」

 ### テキスト 2: 社会政策報告書のスタイル

 > 急速な少子高齢化の進展に伴い、社会安全費の増大が予測されているとしている。

**読み方:** きゅうそくなしょうしこうれいかのしんてんにはない、しゃかいほしょうひのぞうだいがざいせいをあっぱくしているとされている。 しょうひがGDPのさんじゅぱーせんとをこえるかのうせいがある。 

**分析:**
 - **に続く** → レッスン 3 の復習: 同時/結果的な変化
 - **とされている** → アカデミックヘッジ：「あると考えられる」
 - **よければ〜という** → 出典: 政府推計による
 - **しわざ** → レッスン 6 の復習: ありえない (形式的な 〜うる否定)
 - **〜つつある** → 漸進的変化：徐々に広がっている

 **全訳：** 「少子高齢化の急速な進展に伴い、社会保障費の増大が財政を圧迫していると考えられている。政府の試算によれば、このまま対策を講じなければ、2040年には社会保障費がGDPの30％を超える可能性があると伝えられている。社会保障制度の抜本改革なくして財政の持続可能性は確保できないとの見方が、関係者の間で徐々に広がりつつある。」

 ## N2 リーディング戦略

 ### 戦略 1: スキム → スキャン → 詳細 (3 パス法)

 **パス 1 — スキミング (30 秒):** 各段落の最初と最後の文だけを読みます。 トピックと著者の全体的な立場を特定します。 

**パス 2 — スキャン (60 秒):** 論理構造を示す談話マーカーを探します。 
- 断 / そのかわり (on the other hand) → コントラスト
 -だから / そのため (したがって) → 結論/原因
 - しかし / ただし (ただし / ただし条件付き) → 逆転
 - また / さらに (また / さらに) → 追加
 -ため (なぜなら) → 説明

 **パス 3 — 詳細 (残り時間):** 各質問に答えるために必要な特定の段落を読んでください。 全文を読み直さないでください。 

### 戦略 2: 著者のスタンスを特定する

 N2 編集スタイルの文章では、通常、著者の意見が次の部分に組み込まれます。 
- 受動態構文: 〜とされている、〜と見られている — これらは現時点での合意であり、必ずしも著者の見解ではありません
 - 直接的な主張の語尾: 〜である、〜と結論、〜らしいだ — これらは著者の結論を表します
 - 質疑応答の構造: 問題提起 → 反対意見の提示 → 最終段落で著者の立場を主張

 ### 戦略 3: N2 リーディング セクションの時間管理

 N2 読み取りセクションには、通常、長さが増加する 3 ～ 5 個のパッセージがあります。 推奨される時間配分:

 | テキストタイプ | おすすめの時間 |
 |----------|------|
 | 短い文章 (200-300 文字) | 5～7分 |
 | 中程度の文章 (400-500 文字) | 8～10分 |
 | 長い文章 (600-700 文字) | 12～15分 |
 | 比較/情報の一節 | 10～12分 |

 **重要なルール:** 1 つの質問に 2 分以上費やさないでください。 答えを判断できない場合は、最も近い推測をマークして次に進みます。 

## 対話

 ### ダイアログ 1: 正式な職場 — ニュース記事について話し合う

 **設定:** 会議の前に経済学の論文について話し合う 2 人の研究者。

[読み方]：けさのしんぶんによると、せいふはあたらしいいざいたいさくをはっぴょうしたとのこと。 
[日本語]: 今朝の新聞によると、政府は新たな経済政策を発表したと報じられています。 

[研究員B]: そうですね。専門家の間では、現行の金融緩和政策は限界に近いとしているようです。 
[読み方]：そうですね。せんもんかのあいでは、げんこうのきんゆうかんせいさくはげんかいにちかいとされているようです。 
[英語]: そうですね。 専門家の間では、現在の金融緩和政策は限界に近づいているとの見方があるようです。 

[研究員A]: 問題の拡大をめぐって、議論が続いていますね。この問題は簡単には解決しない課題です。

## 文化/登録メモ

 日本の新聞の社説は、帰属とヘッジに関して慎重に調整されたシステムに基づいて運営されています。 著者の意見を直接述べることがある英語の社説とは異なり、日本の社説は、引用の積み重ね（〜によると）、合意主張（〜とされている）、受動態観察（〜と見られている）を通じて主張を提示することが多く、〜べきだ、〜が求められるなどのパターンで最後の段落で著者の直接の推奨を明らかにするだけです。 文章の最初の数段落だけを読んだ N2 学習者は、重要な主張が最後に来るため、記事の主要な議論を誤って認識することがよくあります。 

アカデミックな日本語には、「ヘッジされたコミットメント」と呼ばれる特徴もあります。つまり、作家は絶対的な主張を避け、その代わりに、〜と考えられている、〜とされている、〜の可能性が示唆されているなど、複数の層の距離を置くことを使用します。 これは不誠実や曖昧さではなく、現在の証拠の限界を認識する知的正確さです。 N2 の試験問題では、読者が本文で提示されている内容が「確立された合意」、「考えられる 1 つの解釈」、「著者自身の立場」を区別できるかどうかが頻繁にテストされます。 これらの違いを識別できるように自分を訓練することは、リーディングセクションにとって最も価値のあるスキルの 1 つです。
