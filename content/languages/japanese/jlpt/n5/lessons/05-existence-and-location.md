## 概要

 日本語の最も基本的な動詞の 2 つは「あります」と「います」で、どちらも大まかに「存在する」または「存在する」と訳されます。 主な区別は簡単ですが、絶対に必要です。**あります**は無生物、植物、抽象的なものに使用され、**あります**は生き物、つまり人、動物、および自ら動くことができるものには使用されます。 この区別を正しく理解することは、N5 レベルで最も重要なスキルの 1 つであり、自然な日本語の発音がすぐに向上します。 

このレッスンでは、場所** (何かが存在する場所) を表す **に助詞と、アクションの場所** (何かが起こる場所) を表す **で助詞もマスターします。 右 (右)、左 (左)、前 (前)、後ろ (後ろ)、上 (上)、下 (下)、中 (内側) などの相対的な位置を表す単語を使用して、オブジェクトの位置を説明する方法を学びます。 このレッスンが終わるまでに、道案内をしたり、部屋の説明をしたり、人や物がどこにあるのかを伝えたり、読解課題で場所に基づいた文章を理解したりできるようになります。 

## 学習目標

 このレッスンを終了するまでに、次のことができるようになります。 

- 無生物と生物の存在を表現するには、「あります」と「います」を正しく使用してください。 
- に助詞を使用して、何かが存在する場所をマークします。 
- で助詞を使用して、アクションが行われる場所をマークします。 
- オブジェクトの相対位置をXの右/左/前/後ろ/上/下/中で記述します。

 ## 文法ポイント

 ### 文法ポイント 1: あります vs います — 無生物と生物の存在

 **構造 (あります):** [場所] に + [無生物] が + あります
 **構成(います):** [場所] に + [アニメーションである] が + います
 **質問:** [物/人] は + [場所] に + あります/いますか

 ルールはシンプルですが重要です。**あります**は、物体、植物、建物、お金、時間、出来事など、単独で移動できないものに対して使用されます。 **です** は、人、動物、昆虫など、動くことのできる生き物を指します。 この区別は、日本の自主的な動きの概念から来ています。犬は自分で動くことを決めることができます。 椅子ではできません。 

主語の後の助詞「が」は「存在が」です。これは、存在すると主張されているものを示します。 助詞「に」が位置を示します。 順序は柔軟ですが、最も自然な文構造は場所を最初に置きます: 「テーブルの上に本があります」 (テーブルの上に本があります)。 「X はどこですか?」と尋ねる場合、「本はどこにありますか (本はどこですか?)」と X が話題になります。 

カジュアルなスピーチでは、区別が曖昧になることがあります。一部の話者は、非常にアニメーション性の低いエンティティに対して「ある」と言い、ロボットや乗り物は文脈に応じてどちらかの動詞を取ることがあります。 N5 では、常に厳密なルールを適用します。生き物 = います、その他すべて = あります。

| 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 机の上に本があります。 つくえの上にほんがあります。 つくえの上に本がございます。 | 机の上に本があります。 |
 | 公園に犬がいます。 こうえんにいぬがいます。 公園に犬がいます。 | 公園に犬がいます。 |
 | 冷蔵庫の中に何かありますか。 れいぞうこの中にもありますか。 れいぞうこの中に何がありますか。 | 冷蔵庫の中には何が入っていますか？ |
 | 教室に学生がいます。 きょうし一点がくせいがさんにいます。 教室に学生が三人います。 | 教室には3人の生徒がいます。 |
 | 銀行はどこにありますか。 ぎんこうはどこにありますか。 銀杏はどこにいるか。 | 銀行はどこですか? |
 | 田中さんはここにいますか。 たなかさんはここにいますか。 田中さんはココにいるのか。 | 田中さんはここにいますか？ |

 ❌犬がいます / 椅子がいます

 ### 文法ポイント 2: に (存在の場所) vs で (動作の場所)

 **構造 (に):** [場所] に + [物/人] が + あります/います
 **構造 (で):** [場所] で + [動作の動詞]

 助詞 ** に ** は、静的な場所、つまり何かまたは誰かが単に存在するか配置されている場所をマークします。 助詞 **で** は、アクションまたはイベントが発生する場所を示します。 テスト: 動詞を「there is/are」に置き換えることができる場合は、「に」を使用してください。 動詞が活動 (食べる、勉強する、働く、遊ぶ) を表す場合は、「で」を使用します。 

比較: 図書館に本があります (図書館に本があります — 静的な存在、に) と 図書館で勉強します (私は図書館で勉強します — そこで起こっている行為、で)。 人物は両方に現れる可能性があります: 田中さんは図書館にいます (田中さんは図書館にいます) と 田中さんは図書館で本を読みます (田中さんは図書館で本を読みます — アクション)。 

便利な記憶術: に = 何かをある場所に固定する。 で = アクションが起こる段階。 どちらも日本語の話し言葉と書き言葉で非常に頻繁に使用されるため、この区別を早期にマスターすることは大きな利益をもたらします。 

| 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 公園に猫がいます。 こうえんにねこがいます。 公園に猫がいます。 | 公園に猫がいます。 (存在) |
 | 公園で遊びます。 こうえんであそびます。 公園であそびます。 | (私は) 公園で遊びます。 (アクション) |
 | 駅の前にコンビニがあります。 えきのまえにコンビニがあります。 駅の前にコンビニがあります。 | 駅前にコンビニがあります。 |
 | 学校で日本語を勉強します。 がっこうでにほんごをべんきょうします。 学校で日本語を勉強します。 | 私は学校で日本語を勉強しています。 |
 | このレストランでお食事しましょう。 このレストランでしょくじしましょう。 このレストランで食堂しましょう。 | このレストランで食事をしましょう。 |
 | 部屋には誰もいない。 へやに誰でもない。 へやにだってもういない。 | 部屋には誰もいません。 |

 **よくある間違い:**
 ❌ 図書館に勉強します
 ✓ 図書館で勉強します — 勉強は行為であるため、「で」は必須です。 にここではあなたが図書館にいることだけを意味します

 ## 翻訳の練習

 ### 英語→日本語

 1. 「椅子の下に猫がいます。」 →椅子の下に猫がいます。 
2.「病院はどこですか？」 →病院はどこにありますか。 
3. 「私は学校で昼食を食べます。」 →学校で昼ご飯を食べます。 
4. 「部屋には 3 人がいます。」 →部屋に三人います。 
5. 「この近くにコンビニはありますか?」 →この近くにコンビニはありますか。 

### 日本語→英語

 1. 本棚の横に窓があります。→ 「本棚の横に窓があります。」
 2. 公園で友達と会います。→ 「私は公園で友達に会いました。」
 3. 机の上に何もありません。→ 「机の上には何もありません。」
 4. 田中さんはどこですか。 → 「田中さんはどこですか?」
 5. 駅と病院の間に銀行があります。→ 「駅と病院の間に銀行があります。」

 ## 文化的なメモ

 日本のアパートや住宅は通常、**LDK (リビング、ダイニング、キッチン)** と呼ばれる部屋カウント システムと独立した部屋の数を組み合わせて表されます。たとえば、1K はキッチンだけのあるワンルーム、2LDK は 2 つの部屋とリビング、ダイニング、キッチンから構成されます。 日本では、初めて誰かの家を訪問するとき、家に足を踏み入れたときに、**お邪魔します(お邪魔します)** (文字通り「お邪魔します」) と言うのが通例です。 このフレーズは、誰かのプライベートな空間に立ち入ることを認めており、基本的な礼儀正しさであると考えられています。 帰るときは「お邪魔しました」と言います。 

**うち（内、内部/ホームグループ）** 対 **ソト（外、外/外グループ）** という概念は、日本の社会的交流の基本です。 あなたの内とは、家族、親しい同僚、チームメイトなどのグループ内です。 ソトはその輪の外側にいる全員です。 これは言語にも当てはまります。部外者に自分の（内）家族について話すときは謙譲語を使い、他人（外）の家族について話すときは敬意を持った形を使います。 したがって、このレッスンで物理的な場所の言葉として学んだ「内」と「外」という言葉は、日本文化において深く社会的な概念でもあります。
