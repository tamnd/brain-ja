## 概要

 このレッスンでは、単純な名詞や動詞を超えて、日本語の文章に色と詳細を加えます。 形容詞は、意見、身体的状態、性質を表現するための主なツールです。 これらの使用方法を理解することは、環境を説明し、好みを表現し、基本的な社会的交流を行うために不可欠です。 

日本語の形容詞は、**い形容詞 (i-形容詞)** と **な形容詞 (na-形容詞)** の 2 つの異なるカテゴリに分類されます。 名詞を修飾するときや文を終了するときは、それぞれ異なる動作をします。 これら 2 つのグループをマスターすると、「A は B です」という基本的な文から、よりニュアンスのある説明に移行できるようになり、JLPT N5 試験や日常会話に必要な説明言語の基礎が得られます。 

## 学習目標

 このレッスンを終了するまでに、次のことができるようになります。 
- い形容詞とな形容詞を区別します。 
- 形容詞を現在/過去、肯定/否定形に活用します。 
- 程度副詞 (とても、あまり、少し) を使用して、説明の強さを変更します。 
- 2 つの形容詞を 1 つの文で接続して、より複雑な情報を提供します。

 ## 文法ポイント

 ### 1. い形容詞 (i-形容詞)

 **構造:** [い-adj] + です / [い-adj] + 名詞

 「い」形容詞は常にひらがなの「い」で終わります。 文が終わるときは「です」が続きます。 否定的にするには、最後の「い」を削除し、「ないです」を追加します。 過去形にするには、最後の「い」を削除して「楽しかったです」を追加します。 

| 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | この本は新しいです。 このほんはあたらしいです。 この本は新しいです。 | この本は新しいです。 |
 | 今日は暑かったです。 きのうはあつかったです。 きのうは熱かったです。 | 昨日は暑かったですね。 |
 | この店は安くないです。 この見せ方は無理です。 この店はヤスクナイです。 | この店は安くない。 |
 | 昨日は寒くなかったです。 きのうはさむくなかったです。 きのうはさむくなかったです。 | 昨日は寒くありませんでした。 |

 **よくある間違い:** ❌ おいしいです → ✓ おいしいです — ですの前に余分な i を追加しないでください。 

### 2. な形容詞 (な形容詞)

 **構造:** [な-adj] + です / [な-adj] + な + 名詞

 な形容詞は名詞のように働きます。 名詞を修飾する場合は必ず「な」を付けます。 文が終わるときは、「な」を落として「です」を追加します。 否定の場合は、「じゃないです」を使用します。 過去には「でした」を使います。 

| 日本語 | 読書 | ローマ字 | 英語 |
 |----------|----------|----------|----------|
 | 彼は有名です。 カレはゆうめいです。 カレはユウメイです。 | 彼は有名です。 |
 | 静かな部屋です。 しずかなへやです。 しずかなあへやです。 | 静かなお部屋です。 |
 | 今日は暇じゃなかったです。 きのうはひまじゃなかったです。 きのうはひまじゃなかったです。 | 昨日は暇じゃなかった。 |
 | この町はきれいでした。 このまちはきれいでした。 この街はきれいでした。 | この町は美しかったです。 |

 **よくある間違い:** ❌ きれいなです → ✓ きれいな部屋です / きれいです — 名詞が続く場合にのみ「な」を使用します。 

## 対話

 ### ダイアログ 1: レストランにて
 **田中:** このレストランは有名ですね。 
**読み/ローマ字:** このレストランはゆうめいです。 / このレストランはゆうめいですね。 
**英語:** このレストランは有名ですね。 

**佐藤:** はい、とてもおいしいです。 
**読み/ローマ字:** はい、とてもおいしいです。 / はい、とってもおいしいです。 
**英語:** はい、とてもおいしいです。

**田中:** この料理は高いですか。 
**読み/ローマ字:** このりょうりはたかいですか。 / このりょうりはたかいですか。 
**英語:** この料理は高いですか?

**読み/ローマ字：** いいえ、あまりたかくないです。 / いいえ、あまりたくないです。 
**英語:** いいえ、それほど高価ではありません。

 **Ken:** 新しいアパートはどうですか。

 **英語:** 新しいアパートはどうですか?

 **ユミ:** とても静かです。でも、ちょっと小さいです。 
**読み/ローマ字:** とてもしずかです。でも、ちょっとちいさいです。 / とってもしずかです。 デモ、ちょっとちいさいです。 
**英語:** とても静かです。 でも、ちょっと小さいですね。 

**ケン:** 便利ですか。 
**読み/ローマ字:** べんりですか。 / べんりですか。 
**英語:** 便利ですか？ 

**ユミ:** はい、とても便利です。 
**読み/ローマ字:** はい、とてもべんりです。 / はい、とてもべんりです。

## 文法ドリル

 **演習 1: 空白を埋めてください**
 1. この町は（ ）です。 
2.昨日の試験は（ ）でした。 
3. この靴は（ ）ないです。（高価ではありません - i-adj）
 4. 彼は（ ）人です。 
5. 今日は（ ）です。（暑くない - い-形容詞否定）

 **回答キー:**
 1. 静か (しずか) 2. やさしかった (やさしかった) 3. 高い (たかく) 4. 親切 (しんせつ) 5. 暑くない (あつくない)

2. 昨日、公園はにぎやかでした。 
3. とても有名なお店です。

## 文化的なメモ

 日本文化では、形容詞は「回避」や謙虚さを表現するためによく使用されます。 自分の仕事や持ち物について尋ねられるとき、発言を和らげるために「ちょっと」などの言葉を使うのが一般的です。 たとえば、誰かがあなたの家を褒めた場合、「小さいです」と言うのは謙虚さを示す方法です。 

さらに、い形容詞とな形容詞の区別は、言語の歴史的発展を反映しています。 い形容詞は「本当の」形容詞（日本語ネイティブ）とみなされますが、な形容詞は名詞や外来語に由来することが多いため、他の名詞に接続するのに「な」が必要であるなど、名詞のような性質を保持しています。
