 ## 書き順に関する注意事項

 漢字を書くときは、次の一般的なルールに従ってください。 
1. **上から下** — ストロークは通常、上から下に進みます。 
2. **左から右** — 水平ストロークは左から右に進みます。 複数の縦画と横画が交差する場合、通常は横画が最初になります。 
3. **内側より外側** — 囲まれた漢字 (国など) の場合、最初に枠を描画し、次に内容を描画してから下部を閉じます。 
4. **側面の前の中央** — 上下対称の漢字 (小など) の場合は、中央のストロークを最初に描きます。 

## パターンの読み取り

 ### 音読み(音読み) vs 訓読み(訓読み)
 - **音読み**は主に2つ以上の漢字を組み合わせる場合に使用されます：学校（gak**KOU**）、電車（den**SHA**）
 - **訓読み**は日本語ネイティブの読み方を持つ単一の漢字に使用されます:学ぶ (mana**bu**)、車 (**kuruma**)
 - 今日 (kyou)、今年 (kotoshi)、大人 (otona) などの一部の漢字には、標準パターンに従わない特殊な読み方 (熟字訓) があります。

 ## 学習のヒント

 ### N5 漢字について知っておくべき部首
 多くの N5 漢字は、意味を示唆する共通の部首 (構成要素) を共有しています。 

| ラジカル | 意味のヒント | 例 |
 |----------|---------------|----------|
 | 人（イ） | 人 | 休（休む＝木にもたれる人） |
 | 口 | 口/開口部 | 話、言、語 |
 | 日 | 太陽/日 | 明、時、昨 |
 | 木 | 木/木材 | 休、本、校、東 |
 | 水 (氵) | 水 | 海、泳ぐ、飲む |
 | 火 (灬) | 火 | 燃焼、照 |
 | 女 | 女性 | 好、姉、始めます |
 | 山 | 山 | 島、炭 |
 | 土 | 地球 | 地、場 |
 | 金 (釒) | 金属 | 鉄、銀、銀行 |

 ### ニーモニックの例
 - **山** (山): 3 つの山の峰を単純に描いたもの
 - **川** (川): 流れる水のような三本の線
 - **木** (木): 上に枝があり、下に根がある幹
 - **日** (太陽/日): 中心線を持つ太陽を表す長方形
 - **月** (月/月): 三日月の形
 - **人** (人): 二本足で歩く人
 - **山** + **川** = 風景; これらの部首の周りに自然語彙が集まっています
 - **休** (休憩): 人 (人) が木 (木) に寄りかかる = 休む
 - **明** (明るい): 日 (太陽) + 月 (月) = 両方とも明るいもの = 明るい
 - **林** (木立): 2 つの木 (木)。 **森** (森): 3 本の木 (N5 レベルの認識)
