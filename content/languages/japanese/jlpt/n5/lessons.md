 ## レッスン 1: ひらがなマスター + 初めての挨拶

 ### 学習目標
 - 基本的なひらがな 46 文字すべての読み書きができる
 - 10の基本的な挨拶と表現を正しく使用する
 - フォーマルなスピーチとカジュアルなスピーチをいつ使用するかを理解する

 ### ひらがな表

 | — | | 私 | あなた | e | o |
 |---|---|---|---|---|---|
 | (なし) | あ | い | う | え | お |
 | k | か | き | く | け | こ |
 | s | さ | し | す | せ | そ |
 | t | た | ち | つ | て | と |
 | n | な | に | ぬ | ね | の |
 | h | は | ひ | ふ | へ | ほ |
 | メートル | ま | み | む | め | も |
 | y | や | — | ゆ | — | よ |
 | r | ら | り | る | れ | ろ |
 | w | わ | — | — | — | を |
 | n | ん | — | — | — | — |

 **濁音**: が行 (ga/gi/gu/ge/go)、ざ行 (za/ji/zu/ze/zo)、だ行 (da/ji/zu/de/do)、ば行 (ba/bi/bu/be/bo)

 **P音**：ぱ行（pa/pi/pu/pe/po）

 **結合音 (ようおん)**: きゃ (きゃ)、きゅ (きゅ)、きょ (きょ)。 他の子音+や/ゆ/よも同様に

 ### 新しい語彙

 | 日本語 | ローマ字 | 英語 |
 |----------|----------|----------|
 | おはようございます | おはようございます | おはようございます（丁寧） |
 | おはよう | おはよう | おはようございます（カジュアル） |
 | こんにちは | こんにちは | こんにちは / こんにちは |
 | こんばんは | コンバンワ | こんばんは |
 | おやすみなさい | おやすみなさい | おやすみなさい（丁寧） |
 | さようなら | さようなら | さようなら |

 | はい | はい | はい |
 | いいえ | いえ | いいえ |
 | どうぞ | どうぞ | どうぞ（どうぞ） ここにいます |
 | どうも | ドウモ | ありがとう（カジュアル） |

 ### 文法重視
 - 丁寧さのレベル: ございます (非常に丁寧)、です/ます (標準的な丁寧さ)、平文 (カジュアル)
 - 文末助詞：ね（合意を求める）、よ（主張する）

 ### 対話例

 **ダイアログ 1: 朝の挨拶**

 > A: おはようございます。 
> B: おはようございます。今日もいい天気ですね。 
> A:そうですね！ 

A: おはようございます。 - おはよう。 
B: おはようございます。 今日もいい天気ですね。 - おはよう。 今日もいい天気ですね。 
A:そうだね！ - はい、そうです！ 

**対話 2: 誰かとの出会い**

 > A: こんにちは。 
> B: こんにちは。お元気ですか？ 
> A: 元気です。ありがとうございます。あなたは？ 
> B: 私も元気です。 

A：こんにちは。 - こんにちは。 
B: こんにちわ。 お元気ですか？ - こんにちは。 元気ですか？ 
A：元気です。 ありがとうございます。 あなたは？ - おかけさまで元気です。 あなたも？ 
B：私も元気です。 —私も元気です。 

**ダイアログ 3: 一日の終わり**

 > A: おやすみなさい。 
> B: おやすみなさい。また明日！ 

A：おやすみなさい。 - おやすみ。 
B: おやすみなさい。 またあした！ - おやすみ。 また明日ね！ 

### 練習問題

 **演習 1 — 空白を埋めてください** (上記の語彙から選択):

 1. 朝、あなたはこう言います:____________
 2. 誰かに丁寧に感謝したいとき: ____________
 3. 誰かにぶつかったとき、または注意を引きたいとき: ____________
 4. 誰かが「どうぞ」と言ってあなたに何かを申し出たら: ____________

 **練習 2 — ひらがな読み** (ローマ字を書きます):
 1. あした → ___
 2. きょう → ___
 3.ありがとう → ___
 4. すみません → ___
 5. おはよう → ___

 **練習問題 3 — ひらがなで書きます**:
 1. 駅 → ___
 2. hana (花) → ___
 3.テレビ（テレビ）→＿＿
 4. ごはん → ___

 ### 重要なポイントとよくある間違い
 - **こんにちは**は「は」と綴られますが、「わ」と発音します。「こんにちわ」とは書かないでください。 
- 午前中は「おはようございます」（午前10時から11時まで）、「こんにちは」は正午から午後、「こんばんは」は夕方に使用してください。 
- さようならは最終的でややフォーマルです。「またね」には「またね」または「またね」の方が一般的です。 
- 「すみません」は、「すみません」（注目を集める）と「ごめんなさい」（軽い謝罪）の両方を意味します。

 - 組み合わせ文字: 外来音のウィ (wi)、ファ (fa)、ティ (ti)

 ### 対話例

うえいたぁ：いらっしゃいませ。 ナニになりますか? - いらっしゃいませ。 何をいただきますか？ 
客：こおひいおください。 — コーヒーをください。 
うえいたぁ：ほっとですか、愛ですか？ — ホットですか、それともアイスですか？ 
客：ほっとをください。 — 熱くしてください。 

**ダイアログ 2: 外来語の認識**

 > A:あのビルはデパートですか？ 
> B: いいえ、ホテルです。デパートはそこです。 

A: あのビルはデパアトですか? ――あの建物はデパートですか？ 
B: いいえ、ホテルです。 デパパトはそこです。 — いいえ、ホテルです。 デパートはそこにあります。

 **演習 3 — 外来語の起源を特定する**:

 3. アイスクリーム → 「___」より

 ### 重要なポイントとよくある間違い
 - カタカナの長母音は反復母音ではなくーを使用します: コーヒー (正解) vs コヒイ (不正解)
 - 二重子音はッを使用します: ベッド (ベッド)、カップ (カップ)、ビッグ (大きな)
 - カタカナの小さな「ヤ」は、組み合わせ音としてひらがなの場合と同じように機能します。 
- いくつかのカタカナ語は英語の起源と異なります: テレビ (TV、「television」から)、パソコン (PC、「personalcomputer」から短縮)

 ## レッスン 3: 自己紹介 (自己紹介)

 ### 学習目標
 ・自己紹介（名前、国籍、年齢、職業）
 - は〜です構造体を使用します
 - 基本的な個人的な質問をしたり、答えたりする

 ### 新しい語彙

 | 日本語 | ローマ字 | 英語 |
 |----------|----------|----------|
 | 私 | わたし | 私; 私 |
 | 名前 | なまえ | 名前 |
 | 国 | クニ | 国 |
 | 出身 | しゅっしん | 起源; 故郷 |
 | 〜歳 | 〜サイ | ～ 歳 |
 | 学生 | 学生 | 学生 |
 | 会社員 | かいしゃいん | 会社員 |
 | 先生 | 先生 | 先生 |
 | はじめまして | はじめまして | ごきげんよう; 初めまして |
 | よろしくお願いします。 よろしくお願いします | よろしくお願いします |
 | どうぞよろしく | どうぞよろしく | 初めまして(カジュアル) |
 | 〜から来ました | ～からきました | ～から来た |
 | 〜語 | 〜行く | ~ 言語 |
 | 〜語を話します | ～行ってきます | 私は話します〜 |
 | 趣味 | シュミ | 趣味 |
 | 好き | すき | のように; 好き |

### 文法重視
 - 〜は〜です: X は Y です (X は Y)
 - 〜から来ました: 私は〜から来ました
 - 〜の学生です: 私は〜の学生です
 - 〜歳です: 私は〜歳です
 - も: も、も (X も Y です = X も Y)

 ### 対話例

 **ダイアログ 1: 最初のミーティング**

 > A: はじめまして。私はマリアです。 
> B: はじめまして。田中です。よろしくお願いします。 
> A: こここそ、よろしくお願いします。どこから来ましたか？ 
> B: 東京から来ました。マリアさんは？ 
> A: ブラジルから来ました。 

A:はじめまして。 私はマリアです。 - ごきげんよう。 私はマリアです。 
B:はじめまして。 田中です。 よろしくお願いします。 - ごきげんよう。 田中です。 はじめまして。 
A：こちらこそ、よろしくお願いします。 どこからきましたか？ ――同じく、初めまして。 どこの出身ですか？ 
B: 東京から来ました。 マリアさんは？ — 私は東京から来ました。 それで、マリアさんは？ 
A: ぶら汁からきました。 — 私はブラジルから来ました。 

**ダイアログ 2: 詳細**

 > A: 学生はいますか？ 
> B: 日本語の学生です。今、大学で日本語を勉強しています。 
> A: そうですか。何歳ですか？ 
>B:二十二歳です。 

A: なんの学生ですか? —どんな学生ですか？ 
B: にほんごのがくせいです。 いま、大学で日本語を勉強してます。 — 私は日本語を勉強している学生です。 私は現在大学で日本語を勉強しています。 
A: そうですか。 ナンサイですか？ - そうですか。 何歳ですか？ 
B: にじゅうにさいです。 — 私は22歳です。 

**ダイアログ 3: 趣味**

 > A: 趣味は何ですか?
 > B: 音楽を聴くことと、映画を見ることが好きです。 
> A: そうですね。私も映画が好きです。 

A: シュミはなんですか? — 趣味は何ですか？ 
B: 音楽を聴くこと、映画を観ることが好きです。 — 私は音楽を聴くことと映画を見ることが好きです。 
A: そうですか。 私も映画が好きです。 - そうですか。 映画も好きです。 

### 練習問題

 **演習 1 — あなた自身について記入してください**:
 - 私は＿＿＿です。(あなたの名前)
 - ＿＿＿から来ました。(あなたの国/都市)
 - ＿＿＿歳です。(あなたの年齢)
 - ＿＿＿の学生/会社員です。(あなたの職業/学校)

 **演習 2 — 日本語に翻訳**:
 1. 私は学生です。 
2. 私は（あなたの国）から来ました。 
3. 私は25歳です。 
4. 初めまして。 
5. 私は音楽が好きです。 

**演習 3 — 文章を作成する** (これらの単語を並べ替えます):
 1. です / 田中 / 私 / は → ___
 2. 来ました / から / 東京 → ___
 3. 好きです / 音楽 / が / 私 / は → ___

 ### 重要なポイントとよくある間違い
 - 日本語では姓が最初に来ます: 山田 田中 = ヤマダ タナカ
 - 「はじめまして」は**初めて**会うときにのみ使用します。すでに会った人には決して使用しないでください。 
- よろしくお願いします 文字通り「よろしくお願いします」を意味します - 新しい誰かに会うとき、または関係/取引を開始するときに常に使用されます
 - 年齢: 〜歳 (sai) を使用します。 20歳の読み方は「はたち」
 - どこから来ましたかという質問には、国 (アメリカから来ました) または都市 (ニューヨークから来ました) で答えることができます。

 ## レッスン 4: 数字、時刻、日付

 ### 学習目標
 - 0から10,000以上まで数えます
 - 時間を教えてください (何時ですか)
 - 日付と曜日を記載します
 - カウンターの使用: 〜つ、〜人、〜本、〜枚

 ### 新しい語彙

 | 日本語 | ローマ字 | 英語 |
 |----------|----------|----------|
 | 何時 | ナンジ | 何時 |
 | 今 | 今 | 今 |
 | 〜時 | 〜じ | 時 |
 | 〜分 | 〜楽しい/駄洒落 | 分 |
 | 午前 | 御膳 | 午前 |
 | 午後 | ゴーゴー | 午後 |
 | 半 | ハン | 半分 |
 | 〜曜日 | ～ようび | 曜日 |
 | 今日 | キョウ | 今日 |
 | 明日 | あした | 明日 | 明日
 | 昨日 | きのう | 昨日 |
 | 〜月 | ～ガツ | 月 (名前) |
 | 〜日 | ～にち/か | 日付 (月の何日) |
 | 誕生日 | たんじょうび | 誕生日 |
 | 何日 | 七日 | 何日 |
 | 何月 | 南月 | 何月 |
 | 何曜日 | なんようび | 何曜日 |

 ### 文法重視
 - 何時ですか: 今何時ですか?
 - 〜時〜分です：〜時〜分です
 - 時刻 + に: ～ (特定の時刻)
 - から〜まで: ～から/～まで

 ### 数値とカウンターの確認

 **基本的な数値**:
 0=れい/ゼロ、1=いち、2=に、3=さん、4=し/よん、5=ご、6=ろく、7=しち/なな、8=はち、9=く/きゅう、10=じゅう、100=ひゃく、1000=せん、10000=いちまん

 **ものを数える(〜つ)**:
 一つ、二つ、三つ、四つ、よっつ、五つ、いつつ、六つ、七つ、八つ、九つ、ここのつ、十

 **人 (〜人)**:
 一人(ひとり)、二人(ふたり)、三人(さんにん)、四人(よにん)、五人(ごにん)、何人(なんにん)

 ### 対話例

 **会話 1: 今何時ですか?**

 > A: すみません、今何時ですか？ 
> B: 午後三時十五分です。 
> A: ありがとうございます。

A: すみません、今何かですか? — すみません、今何時ですか？ 
B: ごごさんじじゅうごふんです。 — 午後 3 時 15 分です。 
A: ありがとうございます。 - ありがとう。 

**ダイアログ 2: スケジュール**

 > A: 授業は何時から何時までですか？ 
> B: 9時から10時半までです。 
> A: 昼ご飯は何時ですか？ 
> B: 十二時です。 

A: 十五は何時から何時までですか? —授業は何時から何時までですか？ 
B：くじからじゅうじはんまでです。 — 9時から10時半まで。 
A: 昼ごはんはなんですか? — 昼食は何時ですか？ 
B: じゅうじです。 — 12時です。 

**ダイアログ 3: 日付**

 > A: 今日は何月何日ですか?
 > B: 五月三十日です。 
> A: 何曜日ですか？ 
> B: 金曜日です。 
> A: 誕生日はいつですか?
 > B: 七月七日です。 

A: 今日は七月七日ですか? — 今日は何の日ですか？ 
B: 五月三十日です。 — 5月30日です。 
A: なんようびですか? — 今日は何曜日ですか？ 
B: 金曜日です。 — 金曜日です。 
A: 誕生日はいつもですか? - あなたの誕生日はいつですか？ 
B: 七月なのかです。 — 7月7日です。 

### 練習問題

 **練習 1 — 時間を日本語で書きます**:
 1. 午前9:00 → ___
 2. 午後 3 時 30 分 → ___
 3. 12:45 → ___
 4. 午前7時15分 → ___

 **演習 2 — 日付を日本語で書きます**:
 1. 1月1日 → ___
 2. 3月3日 → ___
 3. 8月15日 → ___
 4. 12月25日 → ___

 **演習 3 — 数える**:
 1. 3冊(本) → ___
 2. 5人 → ___
 3. 鉛筆 2 本 → ___
 4. 4 平らなもの (枚) → ___

 ### 重要なポイントとよくある間違い
 - には **特定** の時間とともに使用されます: 三時に来ます (3 時に来ます)。 今日、明日、毎日などには「に」を使用しないでください
 - 特別な日の読み方: 1日=ついたち、2日=ふつか、3日=みっか、4日=よっか、14日=じゅうよっか、20日=はつか、24日=にじゅうよっか
 - 4 は「し」または「よん」です。 電話番号やフロアでは「よん」の方が安全です。 「し」は「死」に聞こえるため、文脈によっては「よん」の方が好まれます。

B: カイワの練習が一番好きです。 ブンポウはアマリスキじゃないです。 — 会話の練習が一番好きです。 私は文法があまり好きではありません。

### 重要なポイントとよくある間違い
 - i-adj のて形は〜てで終わります: 大きくて (大きくでではありません)
 - な-adj のて形は〜でで終わります: きれいで (きれいくてではありません)
 - 良い/いいの否定: 決して行かない — いつもよくない

 - あまりは常に否定的な言葉と組み合わされます: あまり好きじゃないです (あまり好きではありません) — NOT あまり好きです

### 重要なポイントとよくある間違い
 - 食べませんでした = 食べませんでした (丁寧な否定過去) — 食べませんと言ったり、形式を混ぜたりしないでください

 ## レッスン 10: 願望と計画を表現する

 ### 学習目標
 ・やりたいことを表現する（〜したい）
 - あなたが望むものを表現してください (〜がほしい)
 - 招待状や提案をする (〜ましょう/〜ませんか)
 - 丁寧なリクエストをしてください (〜てください)

 ### 新しい語彙

 | 日本語 | ローマ字 | 英語 |
 |----------|----------|----------|
 | 〜たい | 〜たい | やりたい〜 |
 | ほしい | 星井 | (何か)が欲しい |
 | 〜ましょう | ～ましょう | ～しましょう |
 | 〜ませんか | 〜ませんか | しませんか～？ |

 ### 文法重視
 - Vステム+たい：やりたいこと

 ### 対話例

 **練習 1 — あなたの願いを表現してください** (〜たいまたは〜がほしいを使用):

**演習 2 — 招待状を作成する** (「〜ませんか」または「〜ましょう」を使用):

**演習 4 — 書くタスク**: 将来の計画や願望について短い段落 (5 ～ 7 文) を書きます。 やりたいこと、行きたい場所、欲しいもの、そして友達への招待状を 1 つ含めます。 

### 重要なポイントとよくある間違い
 - たい（やりたい）は、い形容詞のような活用形です：たい、たくない、たかった、たくなかった
 - たいは目的語に「が」または「を」を使用します: 寿司が食べたい / 寿司を食べたい — どちらも正しいです
 - 欲しい (物が欲しい) は常に「が: 本が欲しい」 (本を欲しいではありません) を使用します。 
- 三人称の欲求を直接表現する場合は、「したい」や「ほしい」を使用しないでください。「〜がっています」（彼は...したいようです）と言います。 
- ましょう（しましょう！）は宣言です。 しませんか (しませんか?) は招待/質問です — 相手に心から尋ねる場合は、「ませんか」を使用します。 
-つもりですは、確固たる意図/計画を表します。 たいですは願望/願望を表します
