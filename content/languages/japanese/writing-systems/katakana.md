 ## 外来語の転写パターン

 ### 終端子音
 英語の単語の末尾の子音には母音が追加されます。 

| 英語 | カタカナ | ルール |
 |----------|----------|------|
 | ケーキ | ケーキ (ケーキ) | 最後の k → ki |
 | 牛乳 | みるく（みるく）｜ 最終ク→ク |
 | テスト | テスト（テスト） | 最後の t → へ |
 | チェック | チェック（チェック） | 最終 ck → kku (促音) |
 | ベッド | ベッド (ベッド) | 最後の d → do (強調されている場合は dd) |
 | バス | バス（ばす） | 最後のス→ス |
 | クラブ | クラブ（くらぶ） | 最後のb→bu |

 ### 促音 → ッ
 英語の二重/強勢子音はッ（小さいツ）になります。 
- バター → バターまたはバッター (battā)
 - ピザ → ピザまたはピッツァ (pittsa)
 - コーヒー → コーヒー (kōhī、「f」+長母音)
 - pocket → ポケット (poketto) — 「t」が 2 つ付いています
 ・チケット → チケット（ちけっと）
 - サッカー → サッカー (sakka)

 ### RとL → ラ行
 日本語には個別の L と R がなく、両方ともラ行 (ra/ri/ru/re/ro) になります。 
- 米 → ライス（ライス）
 ・いいね→ライク(raiku)
 - 愛 → ラブ（らぶ）
 ・ライト→ライト（らいと）
 - ロビー → ロビー (robī)
 - ライブラリ → ライブラリー (ライバラリー)
