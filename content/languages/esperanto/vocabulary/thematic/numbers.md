 **数字の形成規則:**
 - 化合物番号の連結: 21 = dudek unu、243 = ducent kvardek tri
 - パート間に「And」は使用されません: 101 = cent unu (cent *kaj* unu ではありません)

 ### 序数 (-a 接尾辞を使用)

 | エスペラント語 | 英語 |
 |----------|----------|
 | うぬあ | 最初 |
 | デュア | 2番目 |
 | トリア | 3番目 |
 | クヴァラ | 4番目 |
 | クビナ | 5番目 |
 | セサ | 6番目 |
 | セパ | 7番目 |
 | わかりました | 8番目 |
 | ナジャ | 9番目 |
 | デカ | 10番目 |
 | デク・ヌア | 11番目 |
 | センタ | 100 番目 |
 | ミラ | 千分の一 |

 **例:** *La tria de marto* = 3 月 3 日。 

### 分数 (-on- 接尾辞)

 | エスペラント語 | 英語 |
 |----------|----------|
 | デュオノ | 半分 |
 | トリオノ | 3 番目 (1/3) |
 | クヴァロノ | 四半期 (1/4) |
 | クビノノ | 5 番目 (1/5) |
 | でこの | 10 番目 (1/10) |
 | チェント | 100 分の 1 (1/100) — 100 を表す「セント」も意味します。 
| プロチェント | パーセント |

 **例:** *Du trionoj de la torto* = ケーキの 3 分の 2。
