## 概要

 エスペラント語の単語構築システムは、その最も有名な機能です。 主に他の言語から借用することによって新しい語彙を獲得する英語とは異なり（「偶然」、「ユビキタス」、「一時的な」など、学習者には不透明な場合が多い）、エスペラント語は、学習者がすでに知っている少数の語根と接辞を組み合わせて新しい単語を構築します。 これは、*malakcepteblaĵo* (受け入れられないもの) のような単語は、*mal-* (反対語)、*akcepti* (受け入れる)、*-ebl-* (可能)、*-a* (形容詞)、および *-ĵo* (具体的なもの) を知っている人には完全に透過的であることを意味します。 B2 では、個々の接辞だけでなく、接辞が形成する *チェーン* や *スタック*、つまり正確な抽象語彙を生み出す 4、5、または 6 つの形態素の組み合わせを命令する必要があります。 

このレッスンは、-ig-/-iĝ- レッスン (L3) に直接基づいて構築されており、文体レジスターのレッスン (L7) に接続されています。 高度な単語構築により、エスペラントは正確な哲学言語であると同時に、効率的な日常言語にもなります。 このレッスンを終えると、既成の用語が足りないときにその場で新しい単語を作り、なじみのない複雑な単語の意味を分解して特定し、B2 の学術的および政治的議論に必要な抽象的な語彙の全範囲を使用できるようになります。 

## 学習目標

 このレッスンを終了するまでに、次のことができるようになります。 
- 各形態素の寄与を分析することにより、4 つ以上の接辞を持つエスペラント語を分解して解釈します
 - 指定されたルートから正しい慣用的な派生チェーンを生成します (例: libera → libereco → liberigi → liberiĝi → liberigisto)
 - -ebl-、-eco、-ado、-ismo、-ano、pli- パターンを効果的に使用して、抽象的な概念を表現します
 - 国際語を採用するためのエスペラント語の基準を説明し、外来語をエスペラント語の形態に適応させる

 ## 文法重視

 ### 複数接辞の積み重ね: 複雑な単語の構築

 **構造:** [接頭辞] + ルート + [接尾辞] + 単語クラスの語尾

 エスペラントでは、結果が論理的に透過的である限り、実質的に無制限の接辞の積み重ねが可能です。 実際には、3 ～ 4 形態素を超える単語のほとんどは、技術的、哲学的、またはユーモア的な用途のために予約されていますが、B2 の学習者は、それらを解読して生成するための原則を理解する必要があります。

B2 レベルでの複雑なスタッキングのキー接辞は次のとおりです。 
- **mal-** (反対): マルボナ (悪い)、マルグランダ (小さい)
 - **-eg-** (増強、極度): bona → bonega (素晴らしい)、granda → grandega (巨大な)
 - **-et-** (小柄、軽度): varma → varmeta (わずかに暖かい)
 - **re-** (もう一度、戻る): skribi → reskribi (書き直す)
 - **-ad-** (継続的または反復的なアクション): skribi → skribadi (書き続ける)
 - **pli-** (比較動作接頭語): bona → plibona (より良い) → plibonigi (改善する)
 - **-ebl-** (可能、-able): fari → farebla (実行可能)、akcepti → akceptebla (許容可能)
 - **-ec-** (-ness、-ity、quality): リベラ → リベレコ、ボナ → ボネコ
 - **-ism-** (イデオロギー、システム): 社会主義、エスペランティズム
 - **-an-** (メンバー、住民): エスペラント語 → esperantano (エスペランティスト、メンバー)、urbo → Urbano (都市居住者)
 - **-ist-** (専門家、常習者): muziko → muzikisto、kuracisto (*kurac-* の医師)
 - **-ĵo** (具体的なもの/インスタンス): belo → belaĵo (美しいもの)、neebla → neeblaĵo

 完全な分析を含むスタッキング例:

 *malakceptebla* = mal- (反対) + akcepti (受け入れる) + -ebl- (可能) + -a (形容詞) → 「受け入れられない、受け入れられない」。 5 つの形態素、完全に透明。 

*plibonigado* = pli- (より多く/比較) + bona (良い) + -ig- (使役) + -ad- (進行中) + -o (名詞) → 「より良いものを作り続ける継続的な改善のプロセス」。 形態素は 6 つ。 

*re-skrib-ad-i* = re- (もう一度) + skribi (書く) + -ad- (連続) + -i (不定詞) → 「書き続けること、書いて書き直すことを繰り返す」。 

*lib-er-ec-o* = libera (自由) + -ec- (品質/状態) + -o (名詞) → 「自由」。 3 つの形態素、非常に一般的な単語。 

| エスペラント語 | 英語 | 形態素解析 |
 |----------|-----------|--------|
 | マラクセプテブラ | 受け入れられない | マル + アクセプティ + -ebl + -a |
 | プリボニアド | 継続的な自己改善 | プリ + ボナ + -ig + -iĝ + -ad + -o |
 | マルファシレギ 非常に困難にする | マル + ファシラ + -eg + -ig + -i |
 | レクリード | レクリエーション（繰り返し作成） | レ + エクレ + -ad + -o |
 | ネファレブラォ | 取り消し可能なこと | ネ + ファー + -ebl + -a + -ĵo |
 | リベリギスト | 解放者 | liber + -ig + -ist + -o |

 **よくある間違い:** ❌ *malbonigadi* (「悪さをし続ける」つもり) — この組み合わせは文法的には解析可能ですが、非常に不自然であり、ネイティブ スピーカーを混乱させる可能性があります。 ルール: スタッキングが *可能*だからといって、それが *慣用的*であるとは限りません。 複雑さが本当に精度を高める場合を除き、より単純な構造を好みます。

 ### 生産的な派生チェーン

 **構造:** ルートを選択 → 各主要な派生経路を適用 → 完全なファミリーを生成

 B2 では、単一の語根から完全な単語ファミリーを生成できるはずです。 これは単なる語彙のトリックではなく、形態体系を深く理解していることを示しています。 *libera* の完全なチェーンは次のとおりです。 

| フォーム | 形態素 | 意味 |
 |------|-----------|-----------|
 | リベラ | 自由 + -a | 無料 (形容詞) |
 | リベーレ | 自由 + -e | 自由に (上級) |
 | リベレコ | liber + -ec + -o | 自由、自由 | 写真
 | リベリジ | 自由 + -ig + -i | 解放する、解放する (tr.) |
 | リベリイ | 自由 + -iĝ + -i | 自由になるために（内部） |
 | リベリギスト | liber + -ig + -ist + -o | 解放者 (職業/習慣) |
 | リベリガント | liber + -ig + -ant + -o | 解放している人（現在） |
 | リベリギント | liber + -ig + -int + -o | 解放した人（過去） |
 | マリバー(ec)o | マル + リベル + (-ec) + -o | 自由のない、捕らわれの状態 |
 | マリベリジ | マル + リベル + -ig + -i | 投獄する、自由を奪う |
 | リベラリズム | 自由 + -al + -ism + -o | リベラリズム (派生形容詞ベースには -al- 接尾辞が必要です) |

 同じチェーン パターンが事実上どのルートにも当てはまります。 *sana* (健康) から: saneco、sanigi、saniĝi、sanigisto (治療者)、malsana、malsaneco、malsanulo (病人)、malsanulejo (病院)、malmalsanigi... など。 1 つのルートのパターンを内面化すると、すべてのルートのパターンが得られます。

| エスペラント語 | 英語 |
 |----------|----------|
 | La unueco de la movado estas nia plej granda forto. | 運動の団結が私たちの最大の強みです。 |
 | ベリは非常に冗長です。 plej はしばしば罪を犯します。 | Beli は珍しい動詞です。 ほとんどの場合、人は beligi を使用したり、自分自身を美化したりします。 |
 | アカデミオの情報を学べます。 | 言語の継続的な改善はアカデミーの法定目標です。 |
 | エスタス・エブレコ、ケイ・リ・アクセプトス・ニアン・プロポノン。 | 彼らは私たちの提案を受け入れる可能性があります。 |

 **よくある間違い:** ❌ *La liberigistoj liberigadis la kaptitojn dum jaroj.* → ✓ *La liberigistoj daŭre liberigis la kaptitojn dum jaroj.* — *liberigi* の *-ad-* は文体の影響のように聞こえます。 長期間にわたって「やり続ける」には *daŭre* + 単純動詞の方が自然です。

 ### 国際語と新造語

 **構造:** 外来語の適応 = 音韻適応 + エスペラント語の単語クラスの語尾

 エスペラントは、主にラテン語、ギリシャ語、フランス語、ドイツ語、英語、その他広く話されている言語から国際語を借用していますが、それらを体系的に適応させています。 基準: 単語は、派生可能なエスペラント語形式がその概念にとって自然または透明ではない場合、かつその単語が真に国際的である (複数の言語族で認識される) 場合に借用されます。 適応ルールは次のとおりです。 

1. 外来接尾辞がエスペラント語の単語クラスの語尾に置き換えられている場合は、その接尾辞を削除します: *nation* → *nacio*、*possible* → *ebla* (いいえ、これは派生したものです)、*telephone* → *telefono*
 2. 音韻論をエスペラントの音素に適応させる: 英語の "sh" → *ŝ* (*ショッピング* → *ŝoping*、口語表現、または正式には *aĉeto*)、由来に応じて "ch" → *ĉ* または *ĥ*
 3. エスペラント語の語尾を追加します: 名詞の場合は *-o*、形容詞の場合は *-a*、動詞の場合は *-i*

 エスペラント コミュニティによる新しい造語 (新造語): アカデミオ デ エスペラントは、公式単語リストに *Oficialaj Aldonoj* (公式追加) を公開します。 コミュニティの新語は *Monato*、オンライン フォーラム、PIV (Plena Ilustrita Vortaro) を通じて広まっています。 なじみのないエスペラント語に出会った場合は、調べる前に単語を分解してみてください。多くの場合、形態論から意味の 80% が得られます。 

| エスペラント語 | 出典 | メモ |
 |----------|----------|----------|
 | インターレート | 内部貨幣 | インターネット: inter- (間) + reto (ネット) — 英語から借用したものではありません |
 | コンプティロ | 内部貨幣 | コンピューター: komput- + -il- (ツール) + -o |
 | 電話 | 国際融資 | 電話: 直接適応 |
 | テレビ | 内部貨幣 | テレビ: tele- (遠く) + vid- (見る) + -o |
 | ブログ | 英語からのローン | ブログ: 直接借用、コミュニティで受け入れられる |
 | レポシュト | 内部貨幣 | 電子メール: ret- (ネット/ウェブ) + poŝto (ポスト/メール) |

 **よくある間違い:** ❌ 生産的なエスペラント派生がうまく機能するときに不必要に借用する: 「チェックする」の *ĉekumi* → ✓ *kontroli* または *verifi* がすでに確立されています。 エスペラント形態論では効率的にカバーできない真に新しい概念については外来語を予約してください。 

## 本物のテキスト

 La vorto *komputilo* は、プルント エル ラ アングラ、インテルナ デリバドごとに定義されたスクリプト¹: komput- (el latino *computare*、kalkuli) + -il- (ilo、instrumento) + -o。 最高のエスペランタを見つけてください: あなたの言語ジャムは、あなたのラジオ局の機能を使い、最も重要な概念を理解し、安全に保つことができます。 Aliaj internacie konataj vortoj — kiel *interreto* (inter + reto) kaj *retpoŝto* (reto + poŝto) — montras la saman logikon. 簡単な操作で新しい情報を得ることができます。 La vorto *blogo* — ペルソナの情報を定期的に更新し、さまざまなエスペランティストを簡単に理解して、*ret-ĵurnalo* と同じように、長い時間を過ごします。 緊張感を表現する⁴ インテル ラ プレソ デ インターナ デリバド カイ ラ プラクティケコ デ インターナシアジ プルントジ。

*「komputilo」という言葉は、英語から借用したものではなく、komput- (ラテン語の computare、計算する) + -il- (道具、器具) + -o という内部派生によって作られました。 これはエスペラント語の原則の一例です。言語に概念を表現するために必要な語根と接辞がすでにある場合は、借用する代わりにそれらを使用します。 interreto (inter + reto) や retpoŝto (reto + poŝto) など、国際的に知られている他の単語も同じ論理を示しています。 ただし、新しいものすべてがそう簡単に翻訳できるわけではありません。 「ブログ」という言葉は、インターネット上で通常のエントリが含まれる個人の Web サイトに使用されますが、「ret-ĵurnalo」や類似の複合語は長すぎると思われるため、多くのエスペランティストには単純な借用語として受け入れられています。 これは、内部デリバティブの純粋性と国際融資の実際性との間に継続的な緊張があることを示しています。 

¹ *per interna derivado* — 借用ではなく、「内部導出を通じて」
 ² *anstataŭ pruni* — 「借りる代わりに」 — *pruni* = 借りる（単語）、*prunto* = ローン
 ³ *tradukеblaj* — tr- + aduk + -ebl + -aj: 翻訳可能 (*novaĵoj* と一致する複数形)
 ⁴ *la daŭran resistance* — 現在進行中の緊張: *daŭra* (継続) 修飾 *tensio* (外来語)

## 文化的なメモ

 エスペラント語の体系的な単語構築は、言語学者や言語プランナーから特に関心を集めています。 ドイツ系ユダヤ人の文献学者ラザロ・ルートヴィヒ・ザメンホフは、ロシア語、ポーランド語、イディッシュ語、ドイツ語、ヘブライ語、フランス語、ラテン語、ギリシャ語を話せましたが、どの派生プロセスがヨーロッパの言語間で共有されているかを観察し、それらを正規化することによって接辞システムを設計しました。 その結果、論理的な一貫性を保ちながら、ロマンス語、ゲルマン語、スラブ語のいずれの言語を話す人にとっても自然に感じられるシステムが生まれました。 

高度なエスペラント語彙の最大の単一リソースは、エスペラントの包括的な図入り辞書である *Plena Ilustrita Vortaro de Esperanto* (PIV) です。現在、vortaro.net でオンラインで入手できます。 PIV には、完全な導出テーブル、認証された文献からの例文、語源メモを含む 16,000 を超えるルート エントリが含まれています。 B2 ～ C1 の本格的な学習者にとって、週に 30 分をかけて PIV エントリを探索する (単語を調べるだけでなく、派生ファミリー全体を読む) ことは、利用できる最も効率的な語彙拡張戦略の 1 つです。
