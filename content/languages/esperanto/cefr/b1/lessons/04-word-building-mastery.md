## 概要

 エスペラントの最も有名な機能は、体系的な派生形態学です。つまり、単語クラスの語尾を変更するだけで、あらゆる語根を名詞、動詞、形容詞、または副詞に変換し、接頭辞と接尾辞を付けて数学的精度で新しい意味を作成できる機能です。 このシステムをマスターした学習者は、語彙を効果的に増やします。1 つの語根と少数の接辞を知ることで、数十の関連単語にアクセスできるようになります。 

このレッスンでは、すでに知っている基本的な A レベルの接辞 (mal-、re-、-ist-、-in-、-ej-、-aĵ-、-eg-、-et-) を超えたエスペラント語の単語構築についての理解を強化し、深めます。 B1 では、接辞を積み重ね、接頭辞と接尾辞を組み合わせ、単一の語根から完全な単語ファミリーを導き出す方法を学びます。 このスキルは、中級エスペラント語話者と上級エスペラント語話者を区別するものです。その場で正確な単語を作り、すぐに理解できる能力は、自信を持って流暢であることの特徴です。

 ## 学習目標

 - 単語クラスの語尾を変更することで、特定の語根から名詞、動詞、形容詞、副詞を派生します
 - 2 つ以上の接辞を 1 つのルートに正しく、正しい順序でスタックします。 
- キー B1 サフィックス (-ad-、-ebl-、-ind-、-em-、-iĝ-、-ig-) を効果的に使用します。 
- 4形態素単語(接頭辞+語根+接尾辞+接尾辞)を分析して生成します

 ## 文法重視

 ### 1. 派生ツールとしての 4 つの単語クラス語尾

 エスペラント語の語根はすべて、適切な語尾を付けることで名詞、形容詞、副詞、または動詞になります。 これは比喩的なものではなく、基本的な構造ルールです。 

| エンディング | 品詞 | ルート *bel-* | からの例
 |----------|------|---------------|
 | **-o** | 名詞 | ベロ（美容） |
 | **-a** | 形容詞 | ベラ（美しい）
 | **-e** | 副詞 | ベレ（美しく） |
 | **-i** | 動詞（不定詞） | beli (美しくあること) |

 ルート *verd-* (緑) から:
 > **verd®** = 緑色 / 緑色
 > **verda** = 緑 (形容詞)
 > **verde** = 環境に優しい方法で
 > **verdi** = 緑になる / 緑に変わる

 ルート *rapid-* (高速/クイック) から:
 > **速さ** = 速度
 > **rapida** = 速い、早い
 > **急速** = 素早く
 > **rapidi** = 急ぐ、速い

 これは事実上すべてのルートで機能しますが、一部の組み合わせは他の組み合わせよりも自然です。 いつでもその形式を作成でき、エスペラント語話者は、特定の形式が辞書でまだ一般的でない場合でも理解できます。

 ### 2. キー B1 サフィックス

 **-ad-** (反復、進行中、または継続的なアクション):
 > kuri → **kurad**i (走り続ける/習慣的に走る)
 > skribi → **skribad**i (書き続けること/書き続けること)
 > パロリ → **パロラッド**i (延々と話す)
 > フラパド = ノックを繰り返す

**-ebl-** (可能、-able/-ible):
 > fari → far**ebl**a (実行可能、実行可能)
 > kompreni → kompren**ebl**a (理解できます)
 > manĝi → manĝ**ebl**a (食用)
 > videbla (可視)、aŭdebla (可聴)、solvebla (解決可能)

 **-ind-** (やる価値がある、値する):
 > vidi → vid**ind**a (一見の価値あり)
 > Legi → Leg**ind**a (読む価値あり)
 > アドミリ → アドミール**ind**a (立派な)
 > laŭdinda (賞賛に値する)、puninda (罰を受けるに値する)

 **-em-** (傾向、傾向):
 > Labori → Labor**em**a (勤勉な、勤勉な)
 > dormi → dorm**em**a (眠い、眠い)
 > パロリ → パロル**em**a (おしゃべり)
 > forgesi → forges**em**a (忘れっぽい)

 **-iĝ-** (なる、自動詞/再帰的な状態変化):
 > ruĝa → ruĝ**iĝ**i (赤くなる/赤くなる)
 > riĉa → riĉ**iĝ**i (金持ちになる)
 > sidiĝi (座る — 座る姿勢に変える)
 > edziĝi (結婚する — 男性)
 > kunĝi (団結する、団結する)

 **-ig-** (作る、原因、推移的原因):
 > ruĝa → ruĝ**ig**i (赤くする、赤くする)
 > puri → pur**ig**i (きれいにする、きれいにする)
 > granda → grand**ig**i (拡大表示)
 > mortigi (殺す — 死を引き起こす)
 > edziĝigi (誰かと結婚すること)

 **-iĝ-/-ig-** のペアは非常に生産的で重要です。 
> ラ・パノ・セキイス。 — パンが乾いてしまった。 (自動詞 — ドライになった)
 >ミ・セキギス・ラ・パノン。 — パンを乾かしました。 (他動詞 — ドライにした)
 > akvo varm**iĝis** です。 — 水が温まりました。 (暖かくなった)
 > ミ・ヴァーム**イギス**・ラ・アクヴォン。 — 水を温めました。 (暖かくなりました)

 ### 3. 接辞の積み重ね

 接辞は順番に積み重ねることができます。 順序は論理的な導出に従います。新しい接辞はそれぞれ、その直前の形式に適用されます。 

**instrui → instruisto → instruistino → instruistinejo**

 段階的に:
 1. instrui (教える)
 2. instrui + **-ist-** + -o = instruisto (教師 — 専門的に教える人)
 3. instrui + -ist- + **-in-** + -o = instruistino (女性教師)
 4. instrui + -ist- + -in- + **-ej-** + -o = instruistinejo (女性教師専用の学校。珍しいが文法的には正しい)

 より実践的な例:

 **ボナ → ボニギ → プリボニギ → プリボニガド**:
 1. ボナ（良い）
 2. bon- + -ig- + -i = bonigi (改善する、良くする)
 3. pli- + bonigi = plibonigi (さらに改善する、より良くする)
 4. plibonig- + -ad- + -o = plibonigado (継続的改善のプロセス)

 **mal- + bon- + -ig- + -i = malbonigi** (悪化する、悪くする)
 **mal- + fortika + -ig- + -i = malfortikigi** (弱める、堅牢さを失う)
 **re- + akari = レアキリ** (回復する、元に戻る)
 **re- + konstrui + -i = rekonstrui** (再構築する、再構築する)

 ## 対話

 *エスペラント語の授業中に 2 人の学生が単語の組み立てについて話し合います。*

**ミア:** 「マルティリジ」を私に与えてください。 キオン・シニファス?
 **トム:** ニ・アナリズ・イン。 「Utila」は「役に立つ」という意味です。 「ユーティリ」 — エスティ・ユーティラ。 「Utiligi」 — igi ion utila、便利にすること。 「マルティリジ」 — イギイオンマルティラ。 何かを無駄にすること。 
**ミア:** ああ、ラ・マルニアス・ラ・ラディコン、トランジティバ・バーボでカジ・ラ・イグ・イガス・イン？ 
**トム:** ギュステ！ Kaj vi povas eĉ plu iri: 「malutiliĝi」 — iĝi malutila — 役に立たなくなること。 
**ミア:** カイ "malutilado" — la procezo de iom-post-iom fariĝi malutila?
 **トム:** ブラボー! 完璧な分析を行います。 ラ・アド・アルドナス・ラ・イデオン・デ・ダウラド。 
**ミア:** とてもエレガントです。 アン・ラ・アングラ・オニ・ベゾヌス・トゥテ・マルサマン・ヴォートン。 
**トム:** ジュステ。 Tio estas unu el la plej belaj ecoj de Esperanto — el marmultaj radikoj oni kreas grandegan vortaron.
 **ミア:** Ĉu vi diras, ke la lingvo estas "vort-kre-ad-kapabla"?
 **トム:** はは！ はい、それは正しいことです!

 ## 練習する

 ### 演習 1: Word ファミリを構築する

 各語根について、4 つの単語クラス形式をすべて導出し、2 つの接尾辞付き異体字を追加します。 

1. ルート：**san-**（健康/健康）
 2. ルート: **lum-** (光)
 3. ルート: **pac-** (平和)

 *例（ルートボン）：*
 - bona (良い — 形容詞)、bono (良い/善さ — 名詞)、bone (よく — adv)、boni (良いこと — 動詞)
 - bonigi (良いものを作る)、boneco (品質としての良さ)

 ---

 ### 演習 2: 化合物を分析する

 それぞれの単語を形態素に分解し、意味を説明します。 

1.センティリギ
 2.エクブルレマ
 3.マルコムプレネブラ
 4. プリロンガディ
 5.再考

 *答え:*
 1. sen- (なし) + util- (使用) + -ig- (作成) + -i = 役に立たなくなる
 2. ek- (始まり) + brul- (燃焼) + -em- (傾向) + -a = 突然燃えやすい / 着火が早い
 3. mal- (わからない) + kompren- (理解できる) + -ebl- (可能性がある) + -a = 理解できない
 4. pli-（もっと）+long-（長い）+-ig-（作る）+-ad-（継続中）+-i = 長く作り続ける/長くし続ける
 5. re- (再度) + konstrui (構築) + -ad- (進行中) + -o = 再構築のプロセス

 ---

 ### 演習 3: 接辞を使用して翻訳する

 適切な接辞を使用してこれらをエスペラント語に翻訳してください。 

1. その問題は解決不可能です。 (-ebl-を使用)
 2. 彼女は勤勉な学生です。 (-em-)
 3. 水は徐々に温まってきました。 (-iĝ-)
 4. 先生は何時間も教え続けました。 (-広告-)
 5. 彼らは古い橋を再建しました。 (リ+コンストルイ)

 *答え:*
 1. 問題が解決しない。 
2. 学生の労働力。 
3. La akvo iom post iom varmigis。 / La akvo iom-post-iome varmiĝis。 
4. ホロイの指示を与える。 
5. Ili rekonstruis la malnovan ponton。

 ## 文化的なメモ

 フランスの言語学者であり、長年のエスペラント愛好家であるクロード・ピロンは、エスペラントの単語構築システムが、言語設計における根本的な問題、つまり、最小限の記憶負荷で話者に最大限の表現範囲を与える方法に対する最適な解決策であるとエッセイの中で主張しました。 彼は、500 の語根を持ち、エスペラント語の約 40 の接辞を完全に知っている話者は、10,000 以上の異なる単語にアクセスできると推定しました。これは、自然言語の数年間の学習に相当する語彙範囲です。 ほとんどの国語が 600 ～ 2,000 時間かかるのに対し、エスペラントは 150 ～ 200 時間で流暢な会話ができるまで「学習可能」と言われるのはこのためです。 単語構築システムは近道ではありません。暗記よりも理解を重視する、慎重に設計されたアーキテクチャです。
