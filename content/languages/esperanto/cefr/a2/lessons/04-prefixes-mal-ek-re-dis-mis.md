## 概要

 エスペラント語の接辞は最大の強みの 1 つです。 明確で一貫した意味を持つ少数の接頭辞と接尾辞を互換性のある語根に付加して、何千もの新しい単語を作成できます。 このレッスンでは、**mal-** (反対)、**ek-** (突然の開始または短い動作)、**re-** (再度または戻る)、**dis-** (離れている、または散らばっている)、**mis-** (間違っている、または間違っている) の 5 つの重要な接頭辞を取り上げます。 

これら 5 つの接頭辞をマスターするだけで、アクティブな語彙が劇的に広がります。 *bona* とその逆の両方を別々に覚える代わりに、*malbona* を自動的に導き出します。 「誤解」という単語を調べる代わりに、*mis-* + *kompreni* をその場で組み合わせます。 この生産的な単語構築は、エスペラント語を効率的に学習できる特徴の 1 つです。 

## 学習目標

 - **mal-** を形容詞や動詞に適用して、正反対のことを表現します
 - アクションの突然の始まりを伝えるには **ek-** を使用します
 - **re-** を使用して繰り返しや戻りの動きを表現します
 - 分散または分離を伝えるには **dis-** を使用します
 - アクションが間違って実行されたことを示すには、**mis-** を使用します

 ## 文法重視

 ### パターン 1: mal- — 逆の接頭辞

 **mal-** は、形容詞または動詞の正確な対義語を作成します。 事実上すべての形容詞と多くの動詞を使用すると生産的です。 

**形容詞を含む:**
 - ボナ → **マル**ボナ (良い → 悪い)
 - グランダ → **マル**グランダ (大きい → 小さい)
 - varma → **mal**varma (暖かい→冷たい)
 - Rapida → **mal**rapida (速い→遅い)
 - ジュナ → **マル**ジュナ (若い → 老人)
 - riĉa → **mal**riĉa (金持ち→貧しい)
 - facila → **mal**facila (簡単→難しい)
 - プロクシマ → **マル**プロクシマ (近い→遠い)
 - アルタ → **マル**アルタ (背が高い→低い)
 - nova → **mal**nova (新品 → 古い/中古)

 **動詞の場合:**
 - アミ → **マル**アミ (愛する→憎む)
 - ĝoji → **mal**ĝoji (嬉しい → 悲しい)
 - フェルミ → **マル**フェルミ (閉じる→開く)
 - komenci → **mal**komenci (to begin → to end/terminate)
 - helpi → **mal**helpi (助ける→邪魔する)

 **全文例:**
 - La vetero estas **malvarma** hodiaŭ — ni restu hejme. — The weather is cold today — let's stay home.
 - Li **malamis** sian najbaron, ĉar ĉiam li ludis laŭtan muzikon. — 彼はいつも大音量で音楽をかけていたので、隣人を憎んでいました。 
- **Malfermu** la fenestron, bonvolu — estas varme ĉi tie! — Open the window, please — it's warm in here!

**よくある間違い:** 真の反対ではないものを否定するために *mal-* を使用します。 *ne bona* (良くない) は *malbona* (積極的に悪い) とは異なります。 単純な否定には *ne* を使用し、反対が実際に存在する場合にのみ *mal-* を使用します。 

### パターン 2: ek- — 突然の開始または短い動作

 **ek-** は、動作 (無作為な側面) の始まり、または短い突然の出来事を示します。 これは、動き、音、感情を表す動詞で特によく見られます。 

- iri → **ek**iri (出発する、行き始める)
 - kuri → **ek**kuri (走り始める)
 - リディ → **エク**リディ (爆笑する)
 - ドルミ → **エク**ドルミ (眠りにつく)
 - brili → **ek**brili (輝き始める、点滅する)
 - paroli → **ek**paroli (話し始める、声を上げる)
 - plori → **ek**plori (泣き出す)
 - カンティ → **エク**カンティ (歌を歌い始める)
 - アミ → **エク**アミ (恋に落ちる)

 **全文例:**
 - キアム ミ ディリス ラ シェルコン、チウジ **エクリディ**ス。 — 私がその冗談を言うと、みんな大笑いしました。 
- Ŝi **ekamis** lin je la unua renkontiĝo. ――彼女は初対面で彼に恋に落ちた。 
- La pluvo 後の La suno **ekbrilis**。 — 雨が上がった後、太陽が輝き始めました。 
- **エキリス** ラ グルポ ジェ ラ オカ マテネ。 — グループは朝8時に出発しました。 

**よくある間違い:** 進行中のアクションまたは習慣的なアクションに *ek-* を使用します。 *Li ĉiam ekiras frue* はぎこちないです。つまり、規則的なパターンではなく、始まりを意味します。 *Li ĉiam foriris frue* と言います (彼はいつも早く出発しました)。 

### パターン 3: もう一度 — もう一度または戻る

 **re-** には 2 つの関連した意味があります。*もう一度* 何かをする (繰り返し) または *後ろに* 何かをする (戻る動作)。 

**繰り返しの意味:**
 - Legi → **re**legi (再読する)
 - ファリ → **リ**ファリ（やり直す）
 - komenci → **re**komenci (最初からやり直す)
 - konstrui → **re**konstrui (再構築する)
 - skribi → **re**skribi (書き直す)

 **リターン/バックセンス:**
 - veni → **re**veni (戻る、戻る)
 - doni → **re**doni (お返しする、何かを返す)
 - iri → **re**iri (戻る)
 - porti → **re**porti (持ち帰る)
 - telefoni → **re**telefoni (折り返し電話する)

 **全文例:**
 - Post la vojaĝo ŝi **revenis** ĝoja kaj energiplena. — 旅行の後、彼女は幸せでエネルギーに満ちて戻ってきました。 
- 私は**レレギス**、トリフォジェ・リブロン・トリフォジェを読んでいます。 — この本を3回読み直しました — とてもいい本です。 
- **Redonу** al mi mian krajoнon、bonvolu! — 私の鉛筆を返してください！ 
- ポスト・ラ・ファジロ、ラ・コムヌモ**rekonstruis**ラ・ポントン。 — 火災の後、コミュニティは橋を再建しました。 

### パターン 4: バラバラ、分散、四方八方

 **dis-** は、分散、分離、または複数の方向への同時送信を意味します。 

- sendi → **dis**sendi (ブロードキャストする、多くの人に送信する)
 - ロンピ → **ディス**ロンピ（粉々になる、粉々になる）
 - iri → **dis**iri (分散する、四方八方に行く)
 - doni → **dis**doni (配布する、配る)
 - ŝiri → **dis**ŝiri (引き裂く)
 - fali → **dis**fali (ばらばらになる、崩壊する)
 - lerni → **dis**lerni（知識を広く広めるため）

 **全文例:**
 - マルサマジンの指示に従って、**disiri** を投稿してください。 — 会議の後、全員は別の方向に散っていきました。 
- 組織**反対**の新しいメンバー。 — 組織はそのニュースをすべてのメンバーにブロードキャストしました。 
- La malforta branĉo **disrомpis** sub la pezo de la neĝo。 — 弱い枝が雪の重みで折れました。 
- 紙の文書を**ディスドニス**で説明します。 — 先生は試験問題を配りました。 

### パターン 5: 間違い — 間違った、間違った

 **mis-** は、アクションが間違って、誤って、または間違った方法で実行されたことを示します。 

- kompreni → **mis**kompreni (誤解する)
 - uzi → **mis**uzi (誤用、悪用)
 - ディリ → **ミス**ディリ (言い間違える)
 - traduki → **mis**traduki (誤訳)
 - lerni → **mis**lerni (間違って学習する)
 - kalkuli → **mis**kalkuli (計算を間違える)
 - コンドゥティ → **ミス**コンドゥティ (不正行為をする)
 - skribi → **mis**skribi (スペルミス、書き間違い)

**全文例:**
 - 私は**ミスコンプレニス**の要求に応じて、不正行為を要求します。 — 質問を誤解し、間違って答えてしまいました。 
- テクストで **misskribita** を楽しみましょう。 — この単語は本文中でスペルが間違っています。 
- レズルトンのコンプティル プログラム **ミスカルクロス** は、不正なデータを無視します。 — 間違ったデータを入力すると、コンピュータ プログラムは結果を誤って計算します。

 ### 演習 2: 接頭辞を使用して翻訳する

 適切な接頭辞とルートの組み合わせを使用して各フレーズを翻訳します。 

1. 彼女はその街に一目惚れした。 
2. 聴衆は拍手を送りました。 
3. 私の傘を返してください。 
4. 嵐の中で建物が倒壊した。

6. そのニュースは何千人ものリスナーに放送されました。

### 演習 3: Word ファミリを構築する

 ルート *diri* (言う) から始めて、学習した接頭辞と知っている接尾辞を使用して単語を作成します。 それぞれの単語を使って文を書きます。 

例: ディリ → ミスディリ (言い間違える) → ミ ミスディラス ケルクフォジェ キアム ミ エスタス ネルヴォザ。 

試してみてください: re + diri、mal + diri (これは意味がありますか?)、dis + diri。 

## 文化的なメモ

接頭辞 **mal-** はエスペラント語にとって非常に中心的なものであるため、文化的な試金石のようなものになっています。 有名なエスペラント語のスローガン「**Malami neniun**」（誰も憎まない）と**malamo kontraŭ malamo**（憎しみに対する憎しみ）の理想は、ザメンホフの初期の著作に遡るエスペラント語の文学やスピーチに登場します。 ザメンホフ自身も反ユダヤ主義に苦しんでおり、中立的な共通言語によって集団間の敵対関係が軽減されるのではないかと夢見ていた。 *マラミ*という言葉は、文字通り「愛をなくす」という言葉に、そのビジョンの一部を捉えています。憎しみは愛を反転させたものであり、理論的には反転させることができるものです。
