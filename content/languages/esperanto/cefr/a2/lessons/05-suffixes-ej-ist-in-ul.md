## 概要

 エスペラントの接尾辞は接頭辞とまったく同じように機能します。一貫した意味を持つ単一の要素が互換性のあるルートに付加されて、新しい単語が生成されます。 このレッスンでは、生産性の高い 4 つの接尾語、**-ej-** (何かに関連する場所)、**-ist-** (開業医または専門家)、**-in-** (女性の性別マーカー)、および **-ul-** (特質によって特徴付けられる人) を取り上げます。 これら 4 つの接尾辞を組み合わせると、単一の語根から豊富な単語ファミリーを構築できます。 

エスペラント語の接辞の最もエレガントな機能の 1 つは、接辞を *連鎖* できることです。 ルート *instruui* (教える) から、*instruisto* (教師)、*instruistino* (女性教師)、および *instruistejo* (学校/教育場所) を構築できます。 各ステップは透過的かつ予測可能であり、各接辞の意味を知る以外に暗記する必要はありません。 

## 学習目標

 - **-ej-** を使用して、活動または目的のルートから場所名詞を導き出します
 - **-ist-** を使用して専門名詞または専門名詞を派生します
 - 人または動物の名詞の女性形をマークするには、**-in-** を使用します。 
- **-ul-** を使用して、形容詞または名詞の語根から人名詞を導き出します
 - 複数の接辞を連鎖させて複数ステップの単語派生を構築する

 ## 文法重視

 ### パターン 1: -ej- — アクションまたは物事に関連付けられた場所

 動詞または名詞の語根に接尾辞 **-ej-** を付けると、「その活動が行われる場所」または「その物事に関連する場所」を意味する単語が作成されます。 

**動詞から:**
 - lerni (学ぶ) → **lern**ejo (学校)
 - クイリ (料理する) → **クイル**エジョ (キッチン)
 - bani (入浴する) → **ban**ejo (浴室、浴場)
 - preĝi (祈る) → **preĝ**ejo (教会、礼拝所)
 - Labori (働く) → **labor**ejo (職場、オフィス)
 - ludi (遊ぶ) → **lud**ejo (遊び場、ゲームエリア)
 - trovi (見つける) → **trov**ejo (落とし物、物が見つかる場所)

 **名詞から:**
 - kuracisto (医師) → **kuracist**ejo (クリニック、医師の外科)
 - libro (本) → **libr**ejo (書店、図書館 — *biblioteko* も使用されます)
 - Birdo (鳥) → **bird**ejo (鳥小屋、鳥保護区)
 - ポルコ (豚) → **ポーク**エジョ (豚小屋)

 **全文例:**
 - ラ インファノイ ラス アル ラ **レルネホ** チウン マテノン。 — 子供たちは毎朝学校に行きます。 
- ニア **クイレジョ** エスタス マルグランダ、セド ファンクシア。 — 我が家のキッチンは小さいですが機能的です。 
- En la **banejo** estas varma akvo. — バスルームにはお湯が出ます。 
- Li Laboras en **kuracistejo** proksime al la centro。 — 彼はセンター近くの診療所で働いています。

**よくある間違い:** すでに場所を意味している場所の単語 (*urbo*、*domo*) に、新たな特定の目的を持たずに -ej- を追加する。 *ウルボエジョ* は *ウルボ* 以上の意味ではありません。 特定のアクティビティや目的が場所を定義する場合は、-ej- を使用します。 

### パターン 2: -ist- — 実践者、専門家、支持者

 **-ist-** は、「X という職業、専門分野、または強いこだわりを持つ人」を意味する名詞を作成します。 

**分野または分野の名詞から:**
 - ムジコ → **ムジーク**イスト (ミュージシャン)
 - dento → **dent**isto (歯科医)
 - komerco → **komerc**isto (商人、貿易業者)
 - arto → **art**isto (アーティスト)
 - サイエンス(o) → **サイエンス**イスト (科学者)
 - Sporto → **sport**isto (スポーツ選手、アスリート)
 - ŝtato → **ŝtat**isto (政治家)
 - historio → **histori**isto (歴史家)

 **動詞から:**
 - 楽器 → **楽器**イスト (先生)
 - kuri → **kur**ist (ランナー、配達員)
 -vendi → **vend**isto (販売員、ベンダー)
 -programi → **program**isto (プログラマー)

 **イデオロギーのルーツから:**
 - socio → **soci**isto (社会主義者)
 - エスペラント語 → **Esperant**isto (エスペラント)

 **全文例:**
 - Mia patrino estas **dentisto** — 歯科医師として働いています。 — 私の母は歯科医です — 彼女は週に 3 日働いています。 
- Li estas fama **muzikisto** kaj ludas la violonon。 — 彼は有名な音楽家で、ヴァイオリンを弾きます。 
- ニア **instruist** は、穏やかな気持ちを大切にしています。 — 私たちの先生はいつもとても辛抱強く説明してくれます。 
- キール**エスペランティスト**、私はコングレサン・クンヴェナドン・チウジャレのパートプレナスです。 — 私はエスペランティストとして、毎年議会の会合に参加しています。 

### パターン 3: -in- — 女性の性別マーカー

 **-in-** は名詞を女性としてマークします。 女性の性別を指定するために人または動物の名詞に付加されます。 基本形 (-in- なし) は、多くの語根で性別に中立か、伝統的に男性的です。 

**人/家族の言葉:**
 - frato (兄弟/兄弟) → **frat**ino (妹)
 - patro (親/父親) → **patr**ino (母親)
 - filo (子供/息子) → **fil**ino (娘)
 ・amiko（友達） → **amik**ino（女友達）
 - kuzо (いとこ) → **kuz**ino (いとこ女性)
 - reĝo (君主/王) → **reĝ**ino (女王)
 - instruisto (教師) → **intruist**ino (女性教師)

 **動物の言葉:**
 - kato (猫) → **kat**ino (彼女の猫)
 - hundo (犬) → **hund**ino (雌犬、雌犬)
 - leono (ライオン) → **leon**ino (雌ライオン)
 - kok® (鶏) → **kok**ino (鶏)

 **全文例:**
 - ミア **フラティーノ** スタダ メディシノン アン ヴァルソヴィオ。 — 私の妹はワルシャワで医学を勉強しています。 
- ラ **レオニーノ** チャシス ラ アンティロポ。 — 雌ライオンはカモシカを狩りました。 
- ニア **instruistino** ベニス エル ブラジル カイ パロラス ポルトガル語 カイ エスペラントン。 — 私たちの女性の先生はブラジル出身で、ポルトガル語とエスペラント語を話します。 
- La **reĝino** malfermis la novan muzeon。 — 女王は新しい博物館を開館しました。 

**性別中立性に関するメモ:** 現代のエスペランティストの中には、明らかに男性的な形式に対して接尾辞 **-iĉ-** (非公式) を使用し、基本形式を完全に性別中立なものにしています。 これはコミュニティで進行中の議論ですが、伝統的なシステム (女性の場合は - 、それ以外の場合は原形) がほとんどのテキストで標準のままです。 

### パターン 4: -ul- — ある特質を特徴とする人

 **-ul-** は、「X によって特徴付けられる人」を意味する名詞を作成します。これは、多くの場合形容詞からですが、名詞からも作成されます。 それはその人の*決定的な特徴*に焦点を当てています。 

**形容詞から:**
 - ジュナ (若者) → **ジュン**ウロ (若者)
 - マルジュナ (老人) → **マルジュン**ウロ (老人)
 - riĉa (金持ち) → **riĉ**ulo (金持ち)
 - malriĉa (貧しい) → **malriĉ**ulo (貧しい人)
 - bela (美しい) → **bel**ulo (美しい人、美しい)
 - stulta (愚か者) → **stult**ulo (愚か者、愚かな人)
 - kolera (怒っている) → **koler**ulo (怒っている人、短気な人)
 - malsana (病気) → **malsan**ulo (病人、患者)

 **名詞から:**
 - strango (見知らぬ人) → **strang**ulo (奇妙な/奇妙な人)
 - hero (英雄) → **hero**ulo (英雄的な人)

 **単語連鎖 — エスペラント接辞の真の力:**

*instrui* (教える) から始める:
 1. instrui → **instru**isto (教師 - 男性または一般)
 2. 楽器奏者 → **楽器奏者**ino (女性教師)
 3. instruisto → **instruist**ejo (学校、教育場所)
 4. instruistino → **instruistin**ejo (専門的には: 女性教師の場所 — 珍しいが文法的には正しい)

 *juna* (若い) から始める:
 1.ジュナ→**ジュン**ウロ(若者)
 2. ジュヌロ → **ジュヌル**イノ（若い女性）
 3. junulo → **junul**aro (集団としての若者) — *-ar-* はレッスン 6 で説明します

 ## 練習する

 ### 演習 1: 接尾辞を使用して単語を作成する

 正しいサフィックス (-ej-、-ist-、-in-、-ul-) を追加して、要求された意味を作成します。 

1. スポーツ + ___ = スポーツ選手、運動選手
 2. クイル + ___ = キッチン
 3. riĉ + ___ = 裕福な人
 4. reĝ + ___ = 女王
 5. 販売店 + ___ = 販売員
 6. preĝ + ___ = 教会
 7. マルサン + ___ = 病気の人
 8. フラット + ___ = 姉妹
 9. 歴史家 + ___ = 歴史家
 10. ベル + ___ = 美しい人

 *答え: 1.isto 2.ejo 3.ulo 4.ino 5.isto 6.ejo 7.ulo 8.ino 9.isto 10.ulo*

 ### 演習 2: チェーンの導出

 各ルートから派生した単語のチェーンを構築します。 チェーンごとに少なくとも 2 つのサフィックスを使用します。 

1. *kuiri* (料理する) から始める: → 料理人 (人) → 女性料理人 → キッチン
 2. *カンティ* (歌う) で始めます: → 歌手 → 女性歌手 → コンサートホール (ヒント: カント = 歌)
 3. *juna* (若者) から始めます: → 若者 → 若い女性 → 若者のグループ (*-ar-*)

 *回答例:*
 1. クイリスト → クイリスティノ → クイレジョ
 2.カンティスト→カンティスティノ→カンテージョ
 3. ジュヌロ → ジュヌリノ → ジュヌラロ

 ### 演習 3: 人物について説明する

 説明ごとに、-ul- または -ist- を使用してエスペラント語の名詞を作成します。 

1. 常に勇敢な人 (kurĝa)
 2. コンピュータのプログラムを行う人（プログラミ）
 3. とても怒っている人 (コレラ)
 4. 科学に熱中する人（サイエンコ）
 5. 貧しい人 (マリチャ)

 *答え: 1.クラジュロ 2.プログラム 3.コレルーロ 4.サイエンススト 5.マルリチュロ*

 ## 文化的なメモ

 接尾辞 **-ist-** はエスペラント文化において特別な意味を持っています。 **エスペランティスト** — エスペラント語の話者および擁護者 — は、コミュニティで使用される最も一般的な自己識別の 1 つです。 ザメンホフ自身も初期の文通には「Doktoro Esperanto」（希望に満ちたもの）として署名し、この言語を中心に成長したコミュニティは自然に **-isto** を自分自身の名前に採用しました。 今日、**エスペランティスト**は言語知識だけでなく、多くの場合、その言語が表す国際理解の理想への取り組みを意味します。 講演者が議会で集まり、「サルトン、サミダーノ！」とお互いに挨拶するとき。 (こんにちは、思想家諸君!)、共有された「主義」というアイデンティティは、彼らを結び付けるものの一部です。
