## 概要

 このレッスンでは、さらに 5 つの接尾辞を使用してエスペラント語の単語形成ツールキットを構築していきます。 **-aĵ-** は、抽象的な概念や行動を具体的な有形のものに変えます。 **-ar-** は、個々のアイテムを集合的な全体にグループ化します。 **-an-** は、誰かをグループまたは場所のメンバーとして識別します。 **-eg-** は強調または拡大します。 **-et-** は減少または軟化します。 レッスン 5 の接尾辞と合わせて、ほぼすべての語根をさまざまな関連語に変換できる 10 個の生産的な接尾辞ができました。 

**-ar-** 接尾辞は、エスペラント語で最も愛されている単語の 1 つである *vortaro* (辞書、文字通り「単語のコレクション」) を生成します。 これは、辞書とは何か、つまり単語の集まりであることを完全に捉えています。 同様に、*arbaro* (森林 – 文字通り「木のコレクション」) と *homaro* (人類 – 「人間のコレクション」) は、これらの接尾辞がどれほど概念的な明確さを提供するかを示しています。 

## 学習目標

 - **-aĵ-** を使用して、抽象語根、動詞、形容詞から具体的な名詞を作成します
 - **-ar-** を使用して、個々の項目のルートから集合名詞を形成します
 - **-an-** を使用して、グループ、場所、組織のメンバーを識別します
 - **-eg-** と **-et-** を使用して、強度、サイズ、感情記録を変更します

 ## 文法重視

 ### パターン 1: -aĵ- — 具体的な物または製品

 **-aĵ-** は、抽象的な性質、動作、または概念を、具体的で有形のもの、つまりその概念の物理的な現れまたは産物に変換します。 

**動詞 (アクションの結果または目的語) から:**
 - manĝi → **manĝ**aĵo (食べ物 — 食べるもの)
 - trinki → **trink**aĵo (飲み物 — 飲むもの)
 - Vesti → **vest**aĵo (衣服、衣料品 - 着るもの)
 - クイリ → **kuir**aĵo (調理済みの料理)
 - vidi → **vid**aĵo (光景、見るもの)

 **形容詞より (その特質の具体例):**
 - dolĉa → **dolĉ**aĵo (甘い - 甘いもの、キャンディー)
 - bela → **bel**aĵo (美しいもの)
 - nova → **nov**aĵo (ニュース — 新しいこと; *novaĵoj* = ニュース)
 - interesa → **interes**aĵo (何か面白いもの)
 - malbona → **malbon**aĵo (何か悪いこと、悪いこと)

 **全文例:**
 - **manĝaĵo** を読んでいますか? — 何か食べ物が欲しいですか？ 
- La **novaĵoj** de hodiaŭ estas surprizaj. — 今日のニュースは驚きです。 
- En la butiko estas multaj **dolĉaĵoj**。 — 店内にはお菓子がたくさんあります。 
- 新しい映画をベラ**ベラ***でご覧ください。 — 彼女の新しい映画は本当に美しいものです。 

**よくある間違い:** すでに具体的な名詞 (*pomo* — apple など) と一緒に -aĵ- を使用します。 *Pomaĵo* は、単に「リンゴ」ではなく、「リンゴ製品」(リンゴソースなど) を意味します。 抽象化を具体化するには、-aĵ- を使用します。 

### パターン 2: -ar- — 集合的なグループまたはセット

**-ar-** は、ルートの複数の個別のインスタンスを、統一された集合全体にグループ化します。 

**典型的な例:**
 - arbo (木) → **arb**aro (森 — 木の集合)
 - ホモ (人) → **ホム**アロ (人類、全体としてのすべての人々)
 - vorto (単語) → **vort**aro (辞書 — 単語の集合)
 - insulo (島) → **insul**aro (群島 — 島のグループ)
 - ŝipo (船) → **ŝip**aro (艦隊 — 船の集合)
 - stelo (星) → **stel**aro (星座 - 星のグループ)
 - dento (歯) → **dent**aro (歯のセット、歯列)
 - fingro (指) → **fingr**aro (すべての指、指をまとめて)
 - letero (手紙) → **leter**aro (手紙集、通信)

 **全文例:**
 - La **arbaro** proksime al la vilaĝo estas antikva kaj bela. — 村の近くの森は古くて美しいです。 
- Ĉia **homaro** ベゾナス・パコン。 — 全人類は平和を必要としています。 
- 私は**vortaron** kiam mi skribas en fremdaj lingvojを使います。 — 外国語で書くときは辞書を使います。 
- ニア **シパロ** は、何も持っていません。 — 私たちの艦隊は夜明けに港を出航しました。 

### パターン 3: -an- — グループ、場所、またはコミュニティのメンバー

 **-an-** は、誰かが場所、組織、運動、または期間に属している、またはそれに関連していることを示します。 

**地名より:**
 - urbo (都市) → **urb**ano (都市居住者、都会人)
 - lando (国) → **land**ano (国の住民)
 - vilaĝo (村) → **vilaĝ**ano (村人)
 - Eŭropo → **Eŭrop**ano (ヨーロッパ)
 - Azio → **Azi**ano (アジア人)
 - アメリコ → **アメリカ**アノ (アメリカ人)

 **組織から:**
 - klubo → **klub**ano (クラブ会員)
 - kongreso → **kongres**ano (会議参加者)
 - familio → **famili**ano (家族)
 - komunumo → **komunum**ano (コミュニティメンバー)

 **全文例:**
 - キール**都市**、私のクティマス・アル・ブルーカジ・アジタド。 — 私は都会に住んでいるので、騒音や喧騒には慣れています。 
- Ĉiuj **kongresanoj** プログラムのライス。 — 会議参加者全員がプログラムを受けました。 
- ムルタージ **ユーロパノイ** レルナス エスペラントン キール ドゥアン フレムダン リンヴォン。 — 多くのヨーロッパ人は第二外国語としてエスペラント語を学びます。 
- ŝako-klubo での活動は **klubano** です。 — 彼女は地元のチェスクラブの活発なメンバーです。 

### パターン 4: -eg- (増補) および -et- (減容)

 これら 2 つの反対の接尾辞は、ルート概念の *程度またはサイズ* を変更します。 **-例-** は拡大します。 **-et-** は減少または軟化します。 

**-例- 例 (より大きく、より強力に、より強烈に):**
 - domo → **dom**ego (豪邸、巨大な家)
 - varma → **varm**ega (灼熱)
 - ボナ → **ボン**エガ (素晴らしい、素晴らしい)
 - ダンコン → **ダンケグ**オン (たくさんの感謝、感謝)
 - granda → **grand**ega (巨大な、巨大な)
 - vento → **vent**ego (嵐、強風)
 - pluvo → **pluv**ego (土砂降り、土砂降りの雨)
 - リディ → **リディ**エギ (爆笑する)

 **-et- 例 (より小さく、より優しく、より繊細に):**
 - domo → **dom**eto (コテージ、小さな家)
 - varma → **varm**eta (ぬるい、暖かい)
 - リディ → **rid**eti (微笑む — 小さな笑い)
 - plori → **plor**eti (泣き叫ぶ、涙を流す)
 - libro → **libr**eto (冊子)
 - Rivero → **river**eto (小川、小川)
 - pluvo → **pluv**eto (霧雨、小雨)
 - vento → **vent**eto (そよ風)

 **全文例:**
 - La vetero estis **varmega** — pli ol 40 gradoj! — 天気は灼熱で、気温は 40 度を超えていました。 
- ĉambro を翻訳するために **ridetis** を使います。 — 彼女は部屋の向こう側で私に微笑みました。 
- En la **dometo** ĉe la arbaro loĝas maljunulo. — 森のそばの小屋に老人が住んでいます。 
- **Dankegon** por via helpo — vi savis la projekton! — ご協力ありがとうございます — プロジェクトが保存されました。 
- La **rivero** estas malgranda — nur **riveret** —、sed tre pura。 — その川は小さい、ただの小川ですが、とてもきれいです。 

**-eg- と -et- と副詞:**
 - iom (少し) → **iom**ete (少し)
 - tre (非常に) → *tre* は *tre* のままです。 ただし: **for**ta → **fort**ega (非常に強い)、**fort**eta (やや強い/しっかり)

**よくある間違い:** -eg- と *tre* (非常に) を混同します。 *Tre granda* = とても大きい (形容詞を修飾する単なる副詞)。 *Grandega* = 巨大 (サイズの品質は単語自体に組み込まれています)。 単に副詞によって修飾されるのではなく、名詞または形容詞の基本的なアイデンティティの一部として意味を表現したい場合は、-eg- を使用します。

### 演習 3: Word ファミリーの構築

 各語根から始めて、レッスン 5 と 6 の接尾辞をすべて使用して、できるだけ多くの派生語を作成します。 

1. *kanti* (歌う) — 何単語組み立てることができますか?

 ## 文化的なメモ

**vortaro** という言葉は特筆に値します。 最も有名なエスペラント語辞書は *La Plena Ilustrita Vortaro de Esperanto* (PIV) で、エスペラント コミュニティによって数十年にわたって編集された膨大な学術著作です。 しかし、単語そのものである *vortaro*、単語の集合体 – は 1887 年にザメンホフによって最初のエスペラント語教科書 (*Unua Libro*) の中で作られ、そこに小さな語彙の付録が含まれていました。 したがって、接尾辞 **-ar-** は、この言語の最も初期の歴史に深いルーツを持っています。 今日、世界中の学習者が *Vortaro.net* やその他のオンライン ツールを使用していますが、この言葉のエレガントな透明性 (すぐにそれが何であるかがわかります) は、世界中のエスペランティストの誇りであり続けています。
