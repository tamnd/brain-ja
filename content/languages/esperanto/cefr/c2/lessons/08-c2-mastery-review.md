## 概要

 この最後のレッスンは、総括の復習であると同時に出発点でもあります。 これは、C2 エスペランティストの完全な能力プロファイルをマッピングし、検証と改訂のための包括的な文法リファレンスを提供し、習熟を定義する語彙領域を調査し、C2 認定スピーカーと *デナスクロ* (家庭言語としてエスペラントで育った人) とを区別するものは何かという哲学的に興味深い問題に取り組んでいます。 また、すべての C2 スピーカーが最終的に直面する長期的な課題、つまり、学習過程を定義する構造化された進行なしで習得を維持する方法にも対処します。 

エスペラント語の C2 の習熟を定義するものは、正確性が高いにもかかわらず、主に間違いがないことではなく、自発性、範囲、正確さ、文化的深み、言語に創造的に貢献する能力などの *肯定的な資質* の存在です。 C2 話者は言語の構造を十分に内面化しているため、文法的な決定が自動的に行われ、意味、スタイル、効果のための認知リソースが解放されます。 この自動性は習熟の最も深い成果であり、C2 レビューではこれを対策します。 

## 学習目標

 このレッスンを終了するまでに、次のことができるようになります。 
- 完全な C2 インベントリに対して個人のコンピテンシー プロファイルをマッピングし、残っているギャップを特定します
 - 完全な文法リファレンスを使用して、エスペラント語の構造上の質問を確認または説明します
 - C2 とネイティブ スピーカー (*denaskulo*) の製品の違いと、その違いが何を意味するのかを正確に説明します。 
- C2 レベルのエスペラント語の持続可能な長期維持計画を設計する

 ### 2. 完全な文法リファレンス

 **16 のルール (エスペラント語基礎より)**

 エスペラントの完全な文法は 16 の規則に記載されています。 C2 スピーカーはそれらすべてを内面化しており、それらを正確に説明できます。 

1. **定冠詞**: *la* (不変)。 不定冠詞はつきません。 
2. **名詞は -o** で終わります: *libro* (本)、*hundo* (犬)。 複数形: *-oj* (*libroj*)。 
3. **形容詞は-a**で終わります: *bona* (良い)。 名詞と数字が一致します: *bonaj libroj*。 
4. **基本的な数字は不変です**: *unu、du、tri、kvar、kvin、ses、sep、ok、naŭ、dek、cent、mil*。 
5. **人称代名詞**: *mi、vi、li、ŝi、ĝi、ni、vi、ili、oni*; 反射的 *si*; *-a* を伴う所有格: *mia、via...*
 6. **動詞の形式**: 現在: *-as*; 過去: *-は*; 将来: *-os*; 条件付き: *-us*; 命令法/仮定法: *-u*; 不定詞: *-i*。 
7. **副詞は -e** で終わります: *bone* (よく)、*rapide* (素早く)。 比較: *pli... ol*、*malpli... ol*、*kiel*。 
8. **対格**: *-n* は、名詞、形容詞、代名詞の直接目的語をマークします。 運動の方向にも使用されます。 
9. *-n* が動作に使用される場合を除き、**前置詞は主格を支配します** (前置詞の後に大文字と小文字が変わりません)。 
10. **月、日、または国籍の名前に大文字は使用できません**。 
11. **複合語**: 単語を結合して形成され、末尾の主な意味: *vaporŝipo* (蒸気船)。 
12. **接辞**: 接頭辞と接尾辞は通常の派生を作成します。 
13. **外国語**はエスペラント語の正書法と文法に適応されています。 
14. **-n は引用符**: 相関形式: 規則 15 を参照。 
15. **相関関係**: *ki-、ti-、i-、ĉi-、neni-* × *-o、-u、-a、-e、-om、-el、-am、-al、-es* の体系的な表 (45 形式)。 
16. **強勢**: 常にすべての単語の最後から 2 番目の音節にあります。 

**完全なプレフィックス システム:**
 - *bo-*: 婚姻関係 (*bopatro* = 義父)
 - *dis-*: 分散、分離 (*disiri* = 異なる方向に進む)
 - *ek-*: 突然の始まりまたは始まり (*ekplori* = 突然泣き出す)
 - *eks-*: 元 (*eksprezidanto* = 元大統領)
 - *fi-*: 道徳的不承認 (*fiulo* = 悪党、*fihomo* = 下劣な人)
 - *ge-*: 男女混合または性別中立のグループ (*gepatroj* = 両親 [両方])
 - *mal-*: 反対 (*malgranda* = 小さい、*malbona* = 悪い)
 - *mis-*: 間違って、間違って (*miskompreni* = 誤解する)
 - *pra-*: 古代の、偉大な- (*praarbaro* = 原生林、*pragrandpatrino* = 曾祖母)
 - *re-*: もう一度、戻る (*relegi* = もう一度読む、*redoni* = 返す)
 - *sen-*: なし (*senpova* = 無力、*senespera* = 絶望)
 - *super-*: 超える、上、超える (*supermankis* = 非常に欠けていた)

**完全なサフィックス システム:**
 - *-aĉ-*: 軽蔑、低品質 (*hundaĉo* = 汚い犬)
 - *-ad-*: 継続または繰り返しのアクション (*kanti* = 歌うこと、*kantadi* = 歌い続けること)
 - *-aĵ-*: 具体的なインスタンスまたは表現 (*bela* → *belaĵo* = 美しいもの)
 - *-an-*: メンバー、住民 (*klubano* = クラブメンバー、*Parizado* = パリジャン)

 - *-ĉj-*: 愛情深い男性の小柄な人 (*patro* → *paĉjo*)
 - *-ec-*: 抽象的な性質または状態 (*bela* → *beleco* = 美、*libera* → *libreco* = 自由)
 - *-eg-*: 増大 (*granda* → *grandega* = 巨大)
 - *-ej-*: 関連付けられた場所 (*lerni* → *lernejo* = 学校; *manĝi* → *manĝejo* = 食堂)
 - *-em-*: 傾向または気質 (*パロリ* → *パロレマ* = おしゃべり)
 - *-end-*: 実行する必要があります (*pagi* → *pagenda* = (これは) 支払わなければなりません)
 - *-er-*: 塊の個々の要素 (*sablo* → *sablero* = 砂粒)
 - *-estr-*: リーダー、ヘッド (*urbo* → *urbestro* = 市長; *ŝipo* → *ŝipestro* = 船長)
 - *-et-*: 小さい（*domo* → *dometo* = 小さな家）
 - *-id-*: (*hundo* → *hundido* = 子犬; *Izrael* → *Izraelido*) の子孫、若者
 - *-ig-*: なる/なるようにする (*granda* → *grandigi* = 拡大する)
 - *-iĝ-*: なる (*ruĝa* → *ruĝiĝi* = 赤くなる; *enamiĝi* = 恋に落ちる)
 - *-il-*: ツールまたは器具 (*tranĉi* → *tranĉilo* = ナイフ; *ŝlosi* → *ŝlosilo* = 鍵)
 - *-ind-*: 価値がある、値する (*ami* → *aminda* = 愛すべき、*legi* → *leginda* = 読む価値がある)
 - *-ing-*: 1 つのアイテムのホルダー (*kandelo* → *kandelingo* = 燭台)
 - *-ism-*: イデオロギー、教義、制度 (*共産主義*、*資本主義*)
 - *-ist-*: 専門家または信者 (*ムジコ* → *ムジキスト*; *エスペラント* → *エスペランティスト*)
 - *-nj-*: 愛情深い小柄な女性 (*パトリーノ* → *パンジョ*)
 - *-obl-*: 複数 (*du* → *duobla* = ダブル)
 - *-on-*: 分数 (*du* → *duono* = 半分、*kvar* → *kvarono* = 4 分の 1)
 - *-op-*: 集合数字 (*du* → *duope* = ペア)
 - *-uj-*: 何かに関連付けられたコンテナ、または国/木 (*mono* → *monujo* = 財布; *pomo* → *pomujo* = リンゴの木; *Franco* → *Francujo* / *Francio* = フランス)
 - *-ul-*: 特徴のある人 (*bona* → *bonulo* = 良い人; *junulo* = 若い人)
 - *-um-*: 雑多、固定された意味なし (*kolo* → *kolumo* = 首輪、*plena* → *plenumi* = 満たす)

 ### 3. デナスクロの質問

 **デナスクロジ** - 家庭言語としてエスペラントを話して育ったエスペランティスト、通常はエスペランティストの両親の子供 - は世界中で数千人います。 これらは魅力的な言語現象を表しています。つまり、国語話者と同じメカニズム（幼児期の没入）を通じて計画された言語を獲得した話者です。 

デナスクロのスピーチに関する研究 (特に *Esperantologio* ジャーナルの Suzette Haden Elgin 氏、Anna Löwenstein 氏らによる) では、デナスクロのスピーチを最も高度な学習済みの話者と区別するいくつかの一貫した特徴が特定されました。 

**自発的な接辞の創造性**: デナスクロイ コインは、学習した話者よりも自発的に、より自信を持って接辞フォームを作成します。 C2 の学習者は *re-ekdormeti* (もう一度少し居眠りするため) を使用する前にためらうかもしれませんが、デナスクロはそれが珍しいかもしれないという認識なしにそれを使用します。

**直感的なコロケーション**: デナスクロイは、エスペラント語でどの単語の組み合わせが「正しいと感じる」かを内面化しました。これは、明示的なルール学習ではなく、子供時代の経験から構築された直感です。 彼らのコロケーションの選択は、学習した話者とは微妙に異なりますが、一貫して異なります。 

**音韻上の自然さ**: デナスクロイの発音、リズム、イントネーションにはどの国語にも由来しない特徴があり、新たなエスペラント語の音韻規範を形成しています。 

**明示的なメタ言語意識の低下**: 興味深いことに、デナスクロジの多くは、暗黙的に学習したため、その用法を支配する文法規則を説明できません。 C2 学習者は通常、文の中で *si/sia* が使用される *理由* を説明できます。 デナスクロはそれを正しく使用しているだけです。 

C2 学習者とデナスクロ学習者の違いは、劣っていることではなく、違いです。 C2 話者は、デナスクロに通常欠けているもの、つまり明確なメタ言語的認識と、言語を説明し、教え、分析する能力を持っています。 理想的なエスペラント語教師は、おそらく C2 の学習済み話者能力を持ち、デナスクロ語の発話パターンに精通している人でしょう。 

デナスクロジの存在は、哲学的に重要な疑問を引き起こします。それは、エスペラント語は今や自然言語なのでしょうか? 技術的な言語的な意味では、意図的な指導を受けずに幼少期に言語を習得したネイティブスピーカーの場合、答えは「はい」です。 エスペラント語は、純粋に計画されたものから部分的に習得されたものへと一線を越え、人類の言語の歴史における真のハイブリッド現象となっています。 

### 4. C2での長期メンテナンス

 積極的なエスペラント語の使用をやめた C2 話者は、数か月以内に *lingva Rusto* (言語の錆び)、つまり流暢さ、語彙の正確さ、生産的な自発性の目に見える低下を経験するでしょう。 これは正常であり、元に戻すことができますが、修復よりも予防​​の方が効果的です。 

**持続可能なメンテナンス戦略:**

 *毎日の受動的インプット* (最小): 毎日 15 分間エスペラント語を読んだり聞いたりすると、受動的理解を維持し、語彙の消耗を遅らせます。 *Monato* を購読して毎日 1 つの記事を読むか、通勤時間にエスペラント語のポッドキャストをフォローすることで、最小限の手間でこれを達成できます。 

*毎週のアクティブな制作*: 週に 1 つのエスペラント語での文章または 1 つの会話により、アクティブな流暢さを維持します。 これは、毎週のブログ投稿、Pasporta Servo ホストへの手紙、または定期的な言語交換パートナーへの手紙によって実現されます。 

*年に一度の集中*: 1 ～ 3 年ごとにユニバーサルラ コングレソ、ソメラ エスペラント スタッド (SES)、またはその他の住宅イベントに参加すると、集中的なリフレッシュが得られ、年間の段階的な消耗を補うことができます。 

*コミュニティへの参加*: モデレーター、ライター、教師、イベント主催者など、コミュニティでの役割を維持することで、継続的なモチベーションが得られ、定期的に高品質のエスペラント語を使用できるようになります。 

*対象を絞った語彙の維持*: 間隔をあけて繰り返してドメイン固有の語彙リストを定期的に確認することで (エスペラント語には Anki デッキが利用可能です)、特殊な語彙の浸食を防ぎます。 

**空白期間後の再活性化**: C2 話者が長期間エスペラントから離れていた場合、受動的な理解を完全な C2 レベルに回復するには、通常 1 ～ 2 週間集中的に読むだけで十分です。 アクティブな本番環境の回復にはさらに時間がかかります。通常、2 ～ 4 週間の定期的なスピーキングまたはライティングの練習により、失われた流暢さのほとんどが回復します。 基本的な文法を忘れてしまう低レベルの学習者とは異なり、C2 話者が構造的な能力を失うことはほとんどありません。 侵食されるのは、語彙へのアクセスのしやすさと慣用句の生成の自動性です。 

## 分析用の本物のテキスト

 **ザメンホフ、最初のエスペラント文法 (1887 年)、『La Antaŭparolo』の序文より** (抜粋)

> 最高のパフォーマンスを楽しみ、フェリアのテンポを大切にし、ポポロジの間でマラペロスを楽しみましょう。 私はポストに参加し、ポポロと世界のさまざまな場所で大きなバロを過ごし、さまざまな言語での生活を決定します。 ムルタジ・ジャロジ・パシス。 私はたくさんの労働をします。 ミ・スフェリス・マレスペロン・カイ・センクラニオン。 ミ・コメンシス・ラ・タスクン・ムルタイン・フォジョン・デ・ラ・コメンコ。 国際的な意見を共有し、深く理解して、自分自身の意見を理解してください。 素晴らしいです、私はあなたのリングヴォンを、あなたはあなたの人生を楽しみます。 

**英語訳:**
 私はまだ子供の頃、民族間の垣根がなくなる幸せな時代を夢見ていました。 その後、私は人々の間の最大の障壁は言語の多様性であることを理解し、その大きな目標に人生を捧げることに決めました。 何年も経ちました。 私は一生懸命働きました。 私は絶望と落胆に苦しみました。 最初から何度もその作業を始めました。 しかし、国際語という考えは私の心に深く根付いていたので、決して捨てることができませんでした。 ついに私は、今日あなたが手に持っている言語を作成しました。 

**注釈:**

 1. **「レヴァディス」** — *re-* + *vad-* + *-is*? いいえ: *revi* (夢/空想へ) + *-ad-* (継続) + *-is* (過去) = 彼は夢を見続け、習慣的に夢を見ていました。 *-ad-* は、子供時代に繰り返し見られる習慣的な夢の性質を示しています。 

2. **「マラペロス」** — *mal-* (反対) + *aperis* (出現) → *malaperi* (消滅) + *-os* (未来)。 *kiam* (とき) の後の埋め込み節内の未来時制 — 英語では現在 (「障壁が消えるとき」) を使用するのに対し、エスペラント語では未来時制が正しく使用されます。 

3. **「sian vibon」** — *sia* (再帰所有格) は、文節の主語 (*mi* / Zamenhof) を指します。 *Offerti sian vibon* = 自分の命を差し出すこと。 再帰的な *sia* は、これを *oferti lian vivon* (他人の命を差し出す) と区別します。 

4. **"enradikiĝinta"** — *en-* (into) + *radiko* (root) + *-iĝ-* (become) + *-int-* (完全能動分詞) + *-a*: 「having-become-rooted-into」 = 深く根付いている。 完全な文法的規則性を備えた複雑な状態をエンコードする 6 つの形態素構造。 

5. **「hodiaŭ tenas en la manoj」** — ここでは現在形が読者に直接語りかけており、ザメンホフの 1887 年の執筆と読者の永続的な現在形の読書との間の距離が崩壊しています。 これは意図的な修辞装置です。 

6. **口調と音域**: ザメンホフの散文は真剣で直接的で、修辞的な装飾がありません。 短い文 (*「Multaj jaroj pasis; mi multe Laboris」*) が蓄積のリズムを生み出します。毎年の努力がリストとして表示されます。 この文体の選択は、壮大さよりもシンプルさによる忍耐力を強調しています。 

## マスタリー演習

 **演習 1:** C2 コンピテンシーの自己評価をすべて完了します (このレッスンにリストされている 50 のスキルすべて)。 各スキルについて、自分自身を次のように評価します: 4 (完全に自動)、3 (努力すれば快適)、2 (かなり努力すれば可能)、1 (まだ達成されていない)。 ドメインごとにスコアを計算します。 自分の最も強い分野 3 つと最も弱い分野 3 つを特定し、今後 3 か月間でそれぞれの弱点に対処するための具体的な活動を提案する 200 語の自己分析を作成します。 

**練習問題 2:** 次のテーマについてエスペラント語で 600 語の個人エッセイ (*persona ese®*) を書きます: *「Kionsignifas por mi esti Esperantisto je C2-nivelo?」* (私にとって C2 レベルのエスペランティストであることは何を意味しますか?)。 このエッセイでは、文体の表現の幅を最大限に発揮する必要があります。文の長さを変化させ、珍しい語彙を正確に使用し、少なくとも 1 つの拡張比喩を展開し、書くまで考えていなかった何かを述べた結論で終わります。 これはあなたの熟練度を示す文書です。保管しておいてください。

**演習 3:** 個人の 12 か月メンテナンス プランを設計します。 (a) 毎日の入力習慣 (何を、どのくらい、いつ)。 (b) 毎週の制作習慣（書くか話すか、誰と、どこで）。 (c) 今後 6 か月以内に行うコミュニティへの貢献 1 つ。 (d) 参加する年次イベント 1 つ。 (e) あなたが探索する 1 つの新しい領域 (読んだことのないジャンル、書いたことのないトピック)。 計画をエスペラント語で書きます。 6 か月後に見直して、遵守状況と進捗状況を評価します。 

## 文化的マスタリーノート

 ザメンホフは序文の最後に次のように書いた: *「Se nia lingvo estas bona — ĝi estos. Se ĝi ne estas bona — ni Laboru, ke ĝi fariĝu bona.」* (私たちの言語が良ければ、それは生き残るでしょう。それが良くない場合は、それを良くするために働きましょう。) 1887年に書かれたこれらの言葉は、今でもエスペラント語の最も簡潔な声明です。 言語とコミュニティの関係: 言語の存続に対する消極的な自信ではなく、言語の使用、文学、教育、コミュニティを通じて言語を存続に値するものにするという積極的な取り組み。 

エスペラント語の**A1からC2への旅**は、振り返ってみると、言語体系だけでなく完全な文化を巡る旅でもあります。 *Saluton, mi nomiĝas...* から始まり、議会のスピーチを解釈し、出版可能な短編小説を書き、Vikipedio に寄稿し、ザメンホフの哲学をデナスクロで議論する能力に到達した学習者は、単に言語を学んだだけではありません。彼らは同じ旅をし、理想主義、実用主義、そして小さな注目すべき言語への愛情深い愛着の特別な混合物を共有する、同じ旅をしてきた人々の世界的なコミュニティに参加したことになります。 

エスペラント運動は、戦争、イデオロギーの隆盛と衰退、インターネット革命、そして差し迫った無価値性の無数の予測を乗り越えてきました。 この言語が生き残ってきたのは、各世代がその言語を次の時代に引き継ぐのに十分な献身的な人々を輩出してきたからです。 このレビューを完了した C2 スピーカーは、その伝達チェーンに加わります。 あなたが習得した言語は、ある程度はあなたのものとなり、継承されることになります。 *La lingvo vibu!* — 言語を生きましょう!
