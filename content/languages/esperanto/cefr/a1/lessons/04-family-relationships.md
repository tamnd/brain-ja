## 概要

 家族の語彙は普遍的です。誰もが何らかの家族を持っており、親戚について話すことは、人々がお互いを知るときに最初に行うことの 1 つです。 エスペラント語の家族辞典は、この言語の最もエレガントで生産的な 2 つの手段を美しく示しています。それは、あらゆる語根から女性形を作り出す接尾辞 **-in-** と、男女混合グループを指す接頭辞 **ge-** です。 「父」と「母」、「兄弟」と「妹」、「息子」と「娘」を別々の単語で覚えるのではなく、1 つの語根を学習して接尾辞を適用します。 家系図全体は、いくつかの根と 2 つの接辞で説明できます。 

このレッスンでは、複数の語尾 **-j** も紹介します。これは、複数の名詞を指すときにすべての名詞 (およびそれに一致する形容詞) に追加されます。 所有形容詞 (mia、via、lia、ŝia…) と組み合わせることで、自分の家族について話したり、他人の家族について尋ねたりするための文法ツールが得られます。これは、初期の言語学習を定義する個人的な会話に不可欠なスキルです。 

## 学習目標

 このレッスンを終了するまでに、次のことができるようになります。 
- 直系家族および親戚の名前を男性形と女性形の両方で指定します
 - **-in-** 接尾辞を適用して、家族名詞の女性形のバリエーションを作成します
 - 男女混合の家族グループを指す場合は、**ge-** 接頭辞を使用します
 - 名詞に **-j** を追加して複数名詞を形成します
 - 9 つの所有形容詞をすべて使用します (mia、via、lia、ŝia、ĝia、nia、via、ilia、onia)

 ## 文法重視

 ### パターン 1: 女性形の「-in-」接尾語

 **構造:** 男性名詞 (または中性名詞) ルート + **-in-** + **-o** = 女性名詞

 エスペラント語の文法上のジェンダーへのアプローチは、エレガントに最小限に抑えられています。 名詞は、フランス語やスペイン語のように本質的に男性的または女性的ではありません（「テーブル」は女性的で、「ブック」は男性的であり、意味上の動機はありません）。 代わりに、エスペラント語の名詞の語根はデフォルトで性別に中立であるか、人々を表す場合は一般的/男性的であるとみなされる可能性があります。 女性の性別を指定するには、**-o** で終わる名詞の前に接尾辞 **-in-** を追加します。 これにより、関連するすべての名詞に対して完全に予測可能なペアが生成されます。

このシステムには、女性形が基本である例外が少数あります (例: **virino** = 女性、**vir-** = 男性 + **-in-** = 女性 → 「女性の人」、および **knabo** / **knabino** = 男の子 / 女の子) ですが、実際には **-in-** ルールが A1 レベルで遭遇する大部分のケースをカバーします。 

| 男性的/中性的 | フェミニン | 英語ペア |
 |---------------------|----------|---------------|
 | パトロ | パトリノ | 父 / 母 |
 | フラト | フラティーノ | 兄/妹 |
 | フィロ | フィリノ | 息子 / 娘 |
 | アボ | アビノ | 祖父/祖母 |
 | オンクロ | オンクリノ | 叔父/叔母 |
 | えぞ | エジノ | 夫 / 妻 |
 | 楽器 | インストルスティノ | (男性) 教師 / (女性) 教師 |
 | あみこ | アミキノ | (男性) 友人 / (女性) 友人 |

 よくある間違い: 語根を男性特有のものとして扱い、女性を説明するときに -in- を省略する → ❌ 「Mia patrino estas bona patro」 (私の母は良い父親です) → ✓ 「Mia patrino estas bona patro」 (私の母は良い母です)

 ### パターン 2: 男女混合グループの ge- 接頭辞

 **構造:** **ge-** + 複数名詞 = 男性と女性の両方を含むグループ

 接頭辞 **ge-** は、多くの言語に共通する問題を解決します。それは、(フランス語やスペイン語のように) 男性複数形をデフォルトにせずに、男性と女性の両方を含むグループをどのように参照するのでしょうか? エスペラント語では、**ge-** は男女混合グループを明示的に示します。 **Gepatroj** は「両親」（父親と母親を合わせたもの）を意味します。 **Gefratoj** は「兄弟」（兄弟と姉妹の総称）を意味します。 **Geamikoj** は男女の「友達」を意味します。 

単一の個人が「両方の性別」になることはできないため、**ge-** 接頭辞はほとんどの場合、複数形の **-j** 語尾とともに使用されます。 唯一の例外は **gepatro** (性別中立の親、理論的) で、これはめったに使用されません。 実際には **gepatroj** (ペアまたはグループとしての親) が表示されます。 **ge-** という単語には複数の所有形容詞形も必要であることに注意してください。 

| ゲワード | 英語 | 例文 |
 |----------|-----------|------|
 | ゲパトロジ | 両親 | Miaj gepatroj estas bonaj homoj. |
 | ゲフラトジ | 兄弟 | ニ・エスタス・トリ・ゲフラトジ。 |
 | ゲフィロイ | 子供たち（自分自身） | イリ・ハヴァス・ドゥ・ゲフィローン。 |
 | ゲヴォジ | 祖父母 | Miaj geavoj loĝas en Italio。 |
 | ゲドゾイ | 夫婦 | 写真 ラ・ゲドゾイ・フェスタス・シアン・ダトレヴノン。 |
 | げみこじ | 友達（混合） | Miaj geamikoj estas tre interesaj. |

 よくある間違い: 一人の人を指すときに単数形名詞とともに **ge-** を使用する → ❌ 「Mia gepatro estas kuracisto」 (珍しい、両性の片方の親を意味する) → ✓ 片方の親を表す「Mia patro/patrino estas kuracisto」。 両方とも「Miaj gepatroj」

 ### パターン 3: 複数形 -j と所有形容詞

 **構造:** 名詞 + **-j** = 複数形。 **ミア、ヴィア、リア、ŝia、ĝia、ニア、イリア** + 名詞 = 所有

 エスペラント語のすべての名詞は、**-j** (英語の「y」のように発音) を追加することで複数形を形成します。**libro** → **libroj** (本)、**patro** → **patroj** (父親)、**infano** → **infanoj** (子供)。 これは例外なく完全に規則的です。 形容詞が複数名詞を修飾する場合は、**-j** も使用します。**bonaj libroj** (良い本)、**grandaj familioj** (大家族)。 

所有形容詞は代名詞に **-a** を追加して形成されます: **mi** → **mia** (私の)、**vi** → **via** (あなたの)、**li** → **lia** (彼の)、**ŝi** → **ŝia** (彼女の)、**ĝi** → **ĝia** (その)、**ni** → **nia** (私たちの)、 **ili** → **ilia** (彼ら)。 すべての形容詞と同様に、これらは修飾する名詞と数が一致します: **mia libro** (私の本) → **miaj libroj** (私の本)。 

| 所有欲 | 例 (単数) | 例 (複数) |
 |-----------|---------------------|------|
 | ミア（私） | ミア・パトロ | ミアジュ・ゲパトロジ |
 | (あなたの)経由 | フラティーノ経由 | ヴィアジ・ゲフラトジ |
 | リア (彼の) | リア・フィーロ | リアジ・ゲフィロイ |
 | ŝia (彼女) | シア・アヴィノ | ジヤヴォイ |
 | ニア（私たち） | ニア・ファミリオ | ニアジ・パレンコジ |
 | イリア (彼ら) | イリア・エゾ | イリアジ・ゲゾジ |

 よくある間違い: 名詞が複数の場合に所有格の **-j** を忘れる → ❌ "mia gepatroj" → ✓ "miaj gepatroj"

 ## 対話

**家族の写真を表示しています**

 — 写真を経由して写真を撮りますか?
 — 写真を見せてもらってもいいですか？ 

— コンプレネブル！ 私は家族を愛しています。 私は、私と同じように、自分自身を結びつけます。 
- もちろん！ これが私の家族です。 こちらが私の両親です。 

— キアジ・アファブラジ・ホモジ！ パトロ経由のキール・ノミシャス?
 —なんてフレンドリーな人たちでしょう！ あなたのお父さんの名前は何ですか?

 — リ・ノミアス・ロベルト。 リ・エスタス・クラシスト。 カイ・チはマルタ・ミア・パトリーノと結びついています。 
— 彼の名前はロベルトです。 彼は医者です。 そしてこちらが私の母、マルタです。 

— Kaj ĉu vi havas gefratojn?
 —そして兄弟はいますか？ 

— そうですね、私はフラトン・カジ・ドゥ・フラティノインを持っています。 パウロは、私を愛する人です。 リ・ハバス・ドゥデク・クビン・ジャロジン。 
— はい、私には兄が 1 人、妹が 2 人います。 こちらは私の弟のパウロです。 彼は25歳です。 

— カイ・ラ・フラティノイン？ 
――そして姉妹は？ 

— Ĉi tiu estas Ana、ŝi havas dek ok jarojn. ソフィアはあなたを愛し、私はクビン・ジャロジンを知っています。 
— こちらはアナ、18歳です。 そして最年少はソフィアで、15歳です。 

— グランダ・ファミリオ！ ネクタイはありますか?
 — 大家族ですね！ あなたの祖父母もここに住んでいますか？ 

— ねえ、私は、クラコヴォのプロクシメ、カンパロでの仕事を楽しみます。 
— いいえ、私の祖父母はクラクフ近くの田舎に住んでいます。

 ## 文化的なメモ

 **-in-** 接尾辞システムは、数十年にわたってエスペラント コミュニティ内で興味深い議論を引き起こしてきました。 一部の講演者は、「デフォルト」の男性語または中性語の語根に女性形が明示的に示されているのは、この言語の 19 世紀の起源に組み込まれた文化的偏見を反映していると主張しています。 これに応えて、コミュニティは代替の慣例を開発しました。現代の話者の中には、**iĉ-** を明示的な男性記号として使用する人もいます (つまり、性別に関係なく、**patriĉo** = 父親、**patrino** = 母親、**patro** = 親) ですが、この用法は標準エスペラント語の一部ではなく、依然として個人およびコミュニティの選択の問題です。 

一方、**ge-** 接頭辞はその実用性から愛されています。 英語などの言語では、混合グループを指すには回りくどい表現 (「兄弟姉妹」、「母親と父親」) が必要ですが、エスペラント語では、**gefratoj**、**gepatroj** という 1 つの単語で同じ考えを表します。 エスペランティストが国際会議で自分たちの家族について話すとき、この効率性は心から高く評価されます。これは、計画言語が自然言語に見られる曖昧さと非対称性をどのように改善できるかを示す小さな例の 1 つです。
