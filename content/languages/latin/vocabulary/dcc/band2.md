バンド 2 は、DCC ラテン コアで 201 ～ 500 位にランクされている単語をカバーしています。これは、カエサル、キケロ、リウィウス、ウェルギリウスの流暢な読解を可能にする高頻度語彙です。 Band 1 がしっかりしてからこれらをマスターしてください。 ここでの 300 単語は、間隔をあけて繰り返しチャンクするために 50 個のセットにグループ化されています。

 ## バンド 2 スティックを作成する

 ### バンド 2 が重要な変曲点である理由

 バンド 1 (単語 1 ～ 200) は、機能語、*esse* の形式、一般的な前置詞、最も基本的な動詞といったインフラストラクチャに関するものでした。 バンド 2 では、ラテン語が本物の言語のように感じられ始めます。 カエサルの戦いの物語、キセロの議論、ウェルギリウスの感情記録を理解するための語彙を獲得します。

悪いニュース: バンド 2 では、さらに屈折が複雑になります。語幹が予測できない 3 変化形の名詞、主要部分が不規則な 3 変化活用動詞、受動的に見えて能動態を意味する抑揚動詞などです。 良いニュースです。文脈に富んだ読書が可能になり、読書は最も効率的な長期的な語彙戦略です。 

---

 ### Words 201–500 の学習戦略

 #### 1. セマンティック フィールド別のチャンク

 300 語すべてをランダムに学習しないでください。 このファイル内のグループは意図的に編成されています。 

- **グループ 1** (動詞): 主要な部分を執拗にドリルします。 ラテン語→英語だけでなく、ラテン語→主要部分のフラッシュカード。 
- **グループ 2** (軍事/政治名詞): カエサル *ガリア戦争* の本 I を並行して読みます。 グループ 2 のすべての名詞は最初の 10 章に登場します。 
- **グループ 3** (抽象名詞): Cicero *Pro Archia* または *De Amicitia* と組み合わせてください。短く、これらの単語がいっぱいです。 
- **グループ 4** (形容詞): 各形容詞の比較表 (肯定→比較→最上級) を作成します。 
- **グループ 5** (代名詞/限定詞): パラダイム テーブルを書きます。 代名詞は、単なる語義表現ではなく、形を通して学習されます。 
- **グループ 6** (副詞/接続詞): *iam / mox*、*hinc / inde*、*postquam / antequam* を反対の意味または関連する意味のペアで学習します。

 | *セクア* | フォローする | sequitur (それは続く)、secutī sunt (彼らは続く) |
 | *プロフィススコア* | 始める | proficīscitur (彼は出発する)、profectus est (彼は出発する) |
 | *パティオ* | 耐える | patitur (彼女は耐える)、passus est (彼は苦しんでいる) |
 | *モリ* | 死ぬ | moritur (彼は死ぬ)、mortuus est (彼は死んだ) |
 | *がうで* | 喜ぶ | gaudet (彼女は喜ぶ) — *semideponent* (完璧は受動的な形です) |

 #### 4. 複合動詞ファミリー

 多くのバンド 2 動詞はバンド 1 の語根の複合体です。 ルートを学習すると、家族全員のロックが解除されます。 

**ルート *mittou*** (送信する):
 *ミット → デミット、レミット、アミット、許可、コミットトウ*

 **ルート *ポノ*** (置く):
 *pōnō → expōnō, impōnō, propōnō, dēpōnō, compōnō*

 **ルート *dōcō*** (リードする):
 *ドゥコ → アブドゥコ、アドゥコ、レドゥコ、プロドゥコ、インドゥコ、エードゥコ*

 新しい化合物を見つけたら、ルートとプレフィックスを特定します。 接頭辞 (*ab-* = アウェイ、*re-* = バック、*ad-* = 方向、*ex-* = アウト、*in-* = イント、*pro-* = フォワード) は、核となる意味を変更しますが、逆転することはほとんどありません。 

#### 5. 名詞の性と語形変化のパターン

 第 3 変化名詞がバンド 2 を支配しています。次のパターンに注意してください。 

| エンディング (-はジェネレーション sg.) | 典型的な性別 | 例 |
 |----------------------|---------------|----------|
 | *-オーニス* | 男性的な | *レギオ、オラティオ、レシオ* |
 | *-オーリス* | 男性的な | *愛、悲しみ、労働、恐怖* |
 | *-アーティス* | フェミニン | *シヴィタース、ヴェリタース、リベルタース* |
 | *-ウティス* | フェミニン | *ヴィルトゥス、サルース* |
 | *-is* (i-stem) | 男性的か女性的か | *ホスティス、ナビス、マイルズ* |
 | *-eris、-oris、-inis* | 中性的 | *属、コーパス、名前、流路* |

 中性第 3 変化名詞は常に主格 = 対格を持ちます。

 #### 8. 避けるべきよくある間違い

 - ** *lēx* と *iüs*** の混同: *lēx* は特定の法規です。 *iüs* は、抽象的な概念/システムとしての権利または法です。 
- ** *hostis* と *inimīcus*** の混同: *hostis* は公的/外国の敵です。 *inimīcus* (バンド 1) は個人的な敵です。 
- ** *timor* と *metus*** の混同: 同義語ですが、*metus* は多くの場合、より物理的な恐怖を指します。 *ティモール* より一般的な恐怖。 
- ***vīs* を忘れることは不規則です**: 対格 *vim*、奪格 *vī*; 複数形の場合のみ規則的になります (*vīrēs, vīrium*)。 
- **依存者の混乱**: *sequitur* と書いて、それが「彼が尾行されている」という意味だと考えないでください。 「彼は従う」という意味です。 受動態には能動的な意味が含まれます。 
- ***mālō / malō*** でマクロンが欠落しています: *mālō* (私が好む) と短い *a* を含む *malō* は存在しませんが、マクロンは *lāx* と *lux*、*vīs* と *vis* などを区別します。
