## 概要

 ラテン語には豊富な代名詞システムがあります。 人称代名詞は一人称と二人称を完全にカバーします。 三人称の場合、ラテン語は指示詞を使います。 再帰代名詞は主節の主語を指します。 指示詞 *hic*、*ille*、および *is* は、近接性と強調に応じて異なる役割を果たします。 

---

 ## 1. 人称代名詞 (一人称と二人称)

 人称代名詞は名詞と同様に拒否されます。 主語代名詞は、動詞の語尾が人称を明確にする場合、通常**省略**されます。 これらは**強調またはコントラスト**のためにのみ表示されます。 

| ケース | 1番目のsg。 | 2nd sg. | 1番目のpl。 | 2番目のpl。 |
 |------|--------|----------|----------|---------|
 | ノム。 | エゴ | トゥ | ノス | ヴォス |
 | 将軍 | メイ | トゥイ | nostrī / ノストルム | ベストリ / ベストルム |
 | だった。 | ミヒ | ティビ | ノビーズ | ヴォビーズ |
 | 準拠 | メー | て | ノス | ヴォス |
 | アブル。 | メー | て | ノビーズ | ヴォビーズ |

 **注:**
 - *nostrum* と *vestrum* は部分属格 (「私たちのうちの 1 人/あなた」) です。 *nostrī/vestrī* は目的属格 (「私たち/あなたの記憶」) です。 
- 主格 (*ego*、*tō*) は強調です: *ego hoc fēcī* = **私** (あなたではありません) がこれをしました。 

---

 ## 2. 三人称人称代名詞は使用しない

 ラテン語には **「彼」、「彼女」、または「彼ら」を表す人称代名詞 (*ego* や *tō* に相当する)** はありません。 代わりに、デモがこの機能を果たします。 

- *is、ea、id* — 「彼/彼女/それ/彼ら」に最も近い、中立的な三人称の指示表現
 - *ille、illa、ilud* — 「あの人」 (遠く離れた、多くの場合威信的な意味合いを含む)
 - *hic、haec、hoc* — 「これ」（スピーカーの近く）

 ---

 ## 3. 再帰代名詞: *スイ、シビ、セー、セー*

 再帰代名詞は **主節の主語**を参照します。 **主格**がなく(主語がラテン語の代名詞形で自分自身に再帰的に現れることはありません)、**三人称のみ**です。 

| ケース | フォーム |
 |------|------|
 | 将軍 | スイ |
 | だった。 | シビ |
 | 準拠 | セー (またはセーセー) |
 | アブル。 | セー (またはセーセー) |

 **主な違い:**
 - *ego mē lavō* — 私は自分自身を洗います (一人称: *mē* を使用します)
 - *tē tē lavās* — あなたは自分自身を洗います (二人称: *tē* を使用します)
 - *Caesar sē amat* — カエサルは自分自身を愛しています (三人称: *sē* を使用し、Caesar を指します)
 - *Caesar eum amat* — シーザーは彼を愛しています (シーザーではなく他の誰か)

 *sē* (再帰的、主語を指す) と *eum/eam* (非再帰的、別の人を指す) の区別は、ラテン語を読む上で重要です。

 ## 6. 実証的: *is、ea、id* (中立 — 「彼/彼女/それ/これ/あれ」)

 | ケース | M | ふ | N |
 |------|---|---|---|
 | ノム。 sg. | は | えあ | ID |
 | 将軍 | エイウス | エイウス | エイウス |
 | だった。 sg. | ええ | ええ | ええ |
 | 準拠 sg. | ウム | えむ | ID |
 | アブル。 sg. | えお | えー | えお |
 | ノム。 お願いします。 | えー / いい | イーエ | えあ |
 | Gen.pl. | エオルム | イヤーム | エオルム |
 | 日付/概要 お願いします。 | イース / イース | イース / イース | イース / イース |
 | 準拠 お願いします。 | イオス | イース | えあ |

 *Is/ea/id* は、中立的で非強調的な文脈における「彼/彼女/それ」および「これ/あれ」のデフォルトの代名詞です。 

---

 ## 7. *兼* エンクリティック

 *cum* (with) が人称代名詞または再帰代名詞と一緒に使用される場合、**enclitic** になり、代名詞の前ではなく末尾に付加されます。

| フレーズ | いいえ |
 |--------|-----|
 | メーカム (私と一緒に) | ~~カムミー~~ |
 | テカム (あなたと一緒に) | ~~カムテー~~ |
 | ノビスカム (私たちと一緒に) | ~~カムノビス~~ |
 | vōbīscum (一緒にお願いします) | ~~カムヴォビス~~ |
 | sēcum (彼自身/彼女自身/彼ら自身) | ~~カムセー~~ |

 名詞の場合は通常、*cum* が前に付きます: *cum puella*、*cum militibus*。

 | ラテン語 | 英語 |
 |------|-----------|
 | エゴ | 私 |
 | トゥ | あなた（代表） |
 | ノス | 私たち / 私たち |
 | ヴォス | あなた (pl.) |
 | セー | 彼自身 / 彼女自身 / 自分自身 (再帰的) |
 | ヒック / ハエク / ホック | これ（スピーカーの近く） |
 | イレ / イラ / イリュード | それ (リモート) |
 | は/ea/id | 彼 / 彼女 / それ / これ / あれ |
 | ラボー、ラヴァーレ | 洗う |
 | アマット | 彼/彼女は愛しています |

 ## 例文

 1. *エゴ・ロマンス・サム; tō Graecus es.* — 私はローマ人です。 あなたはギリシャ人です。 
2. *Caesar sē in speculō videt.* — シーザーは鏡の中に自分自身を見ます。 
3. *Puella eam amat.* — 女の子は自分（他の人）を愛しています。 
4. *自由に生きてください。 ille liber est tuus.* — この本は私のものです。 その本はあなたのものです。 
5. *Nobīscum venit.* — 彼は私たちと一緒に来ました。 
6. *Eacum discipulīs labōrat.* — 彼女は生徒たちと協力しています。 
7. *Mīlitēs sēcum arma portābant.* — 兵士たちは武器を携行していました。 
8. *Huius casae dominus est Marcus.* — この家の所有者はマーカスです。 
9. *Illī virī fortēs erant.* — あの人たちは勇敢でした。 
10. *Tibi pecuniam do.* — 私はあなたにお金をあげます。
