## 概要

 ラテン語の形容詞には、肯定 (良い)、比較級 (より良い)、最上級 (最高) の 3 つの **比較度** があります。 形容詞から派生した副詞にも比較級と最上級の形があります。 ラテン語には、「より」を表現するための 2 つの構文、助詞 *quam* と比較の奪格があります。 

---

 ## 1. 比較形容詞 — 規則的な形成

 **-ior** (M/F) と **-ius** (N) を正の語幹に追加します (属格単数形から *-is* を削除することで見つかります)。 

| ポジティブ | ステム | 比較(M/F/N) |
 |----------|------|-----------|
 | ロングス、-a、-um | 長い- | ロング**イオル** / ロング**イウス** |
 | フォルティス、フォルテ | 写真 フォルティス、フォルテ 砦- | フォート**イオル** / フォート**イウス** |
 | フェリックス、フェリシス | フェリック- | フェリック**イオール** / フェリック**ウス** |
 | オーダックス、オーダシス | オーダック- | オーダック**イオール** / オーダック**イウス** |

 **比較級の変化:** これらは **第 3 変化形容詞** (2 語終端: M/F が同じ、N が異なる) として減少しますが、i 語幹の特徴は * ありません (gen. pl. は *-ium* ではなく *-um*、abl. sg. は *-ī* ではなく *-e* です)。 

モデル: *ロンギオール、ロンギウス* (長い)

 | ケース | 男女 | N |
 |------|-----|---|
 | ノム。 sg. | 長い | ロンギウス |
 | 将軍 | ロンギオリス ロンギオリス
 | だった。 sg. | ロンギオーリー | ロンギオーリー |
 | 準拠 sg. | ロンギオーレム | ロンギウス |
 | アブル。 sg. | ロンギオール | ロンギオール |
 | 公称値/定格値 お願いします。 | ロンギオーレ | ロンギオラ |
 | Gen.pl. | ロンギオルム | ロンギオルム |
 | 日付/概要 お願いします。 | ロンギオバス | ロンギオバス |

 ---

 ## 2. 最上級形容詞 — 規則的な形成

 ほとんどの形容詞: **-issimus/-issima/-issimum** を語幹に追加します。 

| ポジティブ | 最上級 |
 |----------|---------------|
 | ロングス | ロング**イシムス/a/um** |
 | フォルティス | フォート**イシムス/a/um** |
 | フェリックス | fēlic**issimus/a/um** |

 **特別なルール — *-er*:** で終わる形容詞は、*-rimus/-rima/-rimum* を男性主格 (語幹ではない) に追加します。 

| ポジティブ | 最上級 |
 |----------|---------------|
 | アーサー、アークリス | ああc**errimus/a/um** |
 | セロリ、セロリ | 写真 セレル**リムス/a/um** |
 | ケチな、ミゼラ | 守銭奴**リムス/a/um** |

 **特別ルール — *-ilis*:** で終わる形容詞には *-limus/-lima/-limum* を追加します:

 | ポジティブ | 最上級 |
 |----------|---------------|
 | ファシリス | fac**illimus/a/um** |
 | ディフィシリス ディフィシル**リムス/a/um** |
 | 似たもの | simil**limus/a/um** |

 最上級形容詞は、通常の第 1/2 変化形容詞 (*-us/-a/-um*) として減少します。 

---

 ## 3. 不規則な比較

 これらは暗記しなければなりません。 比較級と最上級はまったく異なる語幹から構築されています。 

| ポジティブ | 比較(M/F/N) | 最上級 |
 |----------|----------------------|---------------|
 | ボーナス、-a、-um (良い) | メリオア / メリウス | オプティマス/a/um |
 | malus、-a、-um (悪い) | ペイオル / ペイウス | ペシマス/a/um |
 | マグナス、-a、-um (素晴らしい) | マイヨール / マイウス | 最大/a/um |
 | parvus、-a、-um (小) | マイナー/マイナス | ミニマス/a/um |
 | multus、-a、-um (たくさん/たくさん) | — / プラス | プルリムス/a/um |

 ***plus* に関する特別な注意:** 単数形では、*plus* は形容詞ではなく **中性名詞** として機能します。 **部分属格**を使用します。 
- *plus vīnī* — もっとワイン (直訳すると「もっとワイン」)
 - *一時的に* — より多くの時間を

 複数形の *plus* は、通常、*plürēs mīlitēs* (より多くの兵士) という形容詞として機能します。 

---

 ## 4. 副詞の形成

 **肯定副詞:** 第 1/2 変化形容詞から: 語幹に *-ē* を追加します (*longus* → *longē*)。 第 3 変化形容詞から: *-iter* を追加するか、中性対格 (*fortiter*、*feliciter*、*facile*) を使用します。 

**比較副詞:** = 比較形容詞の**中性対単単数**:
 - *longior* → 比較副詞: *longius* (もっと/かなり長い)
 - *メリア* → *メリウス* (より良い)
 - *maior* → *magis* (その他 — 不定期)

 **最上級副詞:** 最上級語幹 + *-ē*:
 - *longissimus* → *longissimē* (最も/非常に長い)
 - *optimus* → *optimē* (最高、非常に良い)
 - *fortissimus* → *fortissimē* (最も勇敢に)

 | 学位 | 形容詞 | 副詞 |
 |----------|----------|----------|
 | ポジティブ | ロングス | ロンギ |
 | 比較 | 長い | ロンギウス |
 | 最上級 | 最長筋 | 長い |

 ---

 ## 5. 「より」を表現する 2 つの方法

**A. *quam* の構築:** 比較級の後に *quam* (「than」) を使用します。 比較される 2 つのことは **同じ場合**である必要があります:

 *Caesar fortior est quam Pompeius.* — カエサルはポンペイウスよりも勇敢です。 
(*カエサル* 名 = *ポンペイウス* 名)

 **B. 比較の奪格:** *quam* を省略します。 2 番目の要素を **アブレーティブ** に置きます。 

*カエサル・ポンペイオの要塞* — カエサルはポンペイウスよりも勇敢です。 
(*ポンペイオ* 奪格は「ポンペイより」を意味します)

 比較の奪格は、比較の基準が主格または対格である場合にのみ可能です。 それ以外の場合は *quam* が必要です。

 ## 重要な語彙

 | ラテン語 | 英語 |
 |------|-----------|
 | ボーナス / メリオア / オプティマス | 良い / より良い / 最高 |
 | マラス / ペオール / ペシマス | 悪い/最悪/最悪 |
 | マグナス / マイオール / マキシマス | 素晴らしい / 素晴らしい / 最高 |
 | パーヴァス / マイナー / ミニムス | 小さい / 小さい / 最小 |
 | ムルトゥス / プラス / プルリムス | たくさん/たくさん/もっと/ほとんど |
 | ロングス、-a、-um | 長い |
 | クアム | よりも; どうやって; |として
 | バルデ | 非常に（ポジティブな点も含めて） |
 | プラス (+ 世代) | もっと（何かについて） |
 | 最適化 | 非常によく、非常に |

 ## 例文

 1. *Via haec longior est quam illa.* — この道はあの道よりも長いです。 
2. *シーザー オムニバス ミリティブス フォーティオール エラット.* — シーザーはどの兵士よりも勇敢でした。 
3. *Liber Marcī brevior est librō Lōcī.* — マーカスの本はルシウスの本より短い。 
4. *Melius est tacēre quam sturta dicere.* — 愚かなことを言うよりは沈黙する方が良いです。 
5. *Maxima urbs Imperī erat Rōma.* — 帝国最大の都市はローマでした。 
6. *Puer celerius cucurrit quam puella.* — 少年は少女よりも速く走った。 
7. *Optimus magister discipulōs laudat.* — 最高の教師は生徒を褒めます。 
8. *一時的なダビムスを追加* — もう少し時間を与えます。 
9. *Pessimus servus ā dominō pōnītur. * — 最悪の奴隷は主人によって罰せられます。 
10. *Nihil melius est amīcitiā.* — 友情ほど素晴らしいものはありません。

 ## 練習する

 **A. 比較級と最上級を作成します (名詞の 3 つの性別をすべて指定します):**
 1. *グラヴィス、墓*
 2. *アーサー、アークリス、アーカー*
 3. *簡単、簡単*

 **B. 副詞の 3 つの次数を形成します:**
 1. *fortis* → 副詞: 肯定的/比較級/最上級
 2. *ボーナス* → *ベネ* / \_\_\_\_ / \_\_\_\_

 **C. *quam*:** の代わりに比較の奪格を使用して書き直します。 
1. *Cornelia prudentior est quam Marcus.*
 2. *長い間自由に過ごすことができます。*

 **D. 翻訳:**
 1. *最適なラボラヴィスティー*
 2. *プラスペクニアエ・ハベオ・クアム・トゥー。*
 3. 最悪の兵士は最高の兵士よりも臆病です。
