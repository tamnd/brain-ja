## 対格の場合

 対格はラテン語で**最も多用される**です。 その中心的な機能は **ダイレクト オブジェクト**ですが、他にもいくつかの重要な用途があります。 

### 1. 直接オブジェクト

 対格は動詞の動作の受け手を表します。 

*Puella librum は合法です。* — 女の子は **本**を読みます。 

*Agricolae agrum count.* — 農民は **畑**を耕します。 

### 2. 前置詞を伴う対格 (動詞と拡張)

 **対格**をとる前置詞は通常、**への動き、**範囲**、または休符のない**空間関係**を表します。 

| 前置詞 | 意味 | 例 |
 |-----------|-----------|----------|
 | *広告* | に、向かって | *ad oppidum* — 町の方へ |
 | *で* | (動き) | *シルヴァム*で — 森の中へ |
 | *あたり* | を通して、全体を通して | *経由* — 道路経由 |
 | *プロペラ* | のせいで | *propter bellum* — 戦争のため |
 | *アンティ* | 前、前 | *アンテ ポルタム* — ゲートの前 |
 | *投稿* | 後、後ろ | *南北戦争後* — 戦後 |
 | *トランス* | 横に | *トランス・フルーメン* — 川を渡って |
 | *反対* | 反対 | *contrā hostēs* — 敵に対して |
 | *インター* | 間、間 | *inter amīcos* — 友達の間で |
 | *周回* | 周り | *島周* — 島の周り |

 **重要なルール:** *in* + 対格 = 動き **into**; *in* + アブレーティブ = **in/on** に置きます (残り)。

 ## 属格の場合

 属格は **名詞間の関係**を表し、最も一般的には「of」または英語の所有格 ('s) で翻訳されます。 

### 1. 所有の属格

 最も一般的な用途: 何かを所有または所属している人。 

*liber puerī* — **少年**の本 / **少年**の本

 *レギナ・ロマンノールム* — **ローマ人**の女王

 ### 2. 主観的属格と客観的属格

 修飾される名詞が動詞名詞の場合 (*amor*、*timor*、*odium* など):

 - **主観属格**: 属格は動作を実行します — *amor patriae* = 国への愛 (国は比喩的な意味で愛することを行っています。国は **愛しています**)
 - **目的属格**: 属格はアクションを受け取ります — *timor hostium* = 敵に対する恐怖 (敵は恐れられています)

 通常、コンテキストは明確になり、初心者レベルでは両方とも「の」として自然に翻訳されます。 

### 3. 部分属格

 属格は、部分が取り出される **全体** をマークします。 「一部」、「かなり」、「一部」、「何も」を意味する単語でよく見られます。 

| ラテン語 | 翻訳 |
 |------|-----------|
 | *ニヒル アクア* | 水がない → 水が全くない |
 | *プラスヴィニー* | ワインをもっと → ワインをもっと |
 | *ムルタム アクア* | 大量の水 → 大量の水 |
 | *液体シビ* | 食べ物の一部 → 食べ物の一部 |
 | *パースミリタム* | 兵士の一部 |
 | *ニーモ・サーボラム* | 奴隷は誰もいません。 

### 4. 記述の属格 (品質)

 形容詞と一緒に使用して、特性、特に抽象的な性質を説明します。 

*puer magnae virtütis* — **大きな勇気の少年** (非常に勇敢な少年)

 *vir summae sapientiae* — **最高の知恵を持つ男**

 *oppidum mīlle passuum* — **千歩**の町 (1マイル離れた)

 この使用法は、**サイズ、体重、年齢、性格**の説明で一般的です。

 ## 分析付きの 10 の例文

 **1.** *民兵の救急車。*
 - *意見の相違* — acc. *広告* 付き、次への動き
 - **翻訳:** 兵士たちは町に向かって歩きます。 

**2.** *agrum currit ごとのアグリコラ。*
 - *agrumごと* — 準拠。 *ごと*、スルー
 - **翻訳:** 農夫は畑を駆け抜けます。

**3.** *シルヴァム・カリットのプエラ。*
 - *シルバムで* — acc. *in* で (動きを入れて)
 - **翻訳:** 少女は森に逃げ込みます。 

**4.** *農業活動休止中の適切な軍事活動。*
 - *適切なベルム* — による。 *プロパティ*を使用すると、原因
 - **翻訳:** 戦争のため、兵士たちは野原で寝ています。 

**5.** *レックスは、ベラムの前に不意を突かれました。*
 - *ベラム前* — による。 *アンティ*付き、その前の時間
 - **翻訳:** 王様は戦前の町を見た。 

**6.** *ドミニー マグナ オペラの指導者として働きます。*
 - *ドミニ* — 将軍。 上級、所持品
 - **翻訳:** 主人の奴隷は素晴らしい仕事をします。 

**7.** *オッピドー通りのニヒル・アクアエ*
 - *アクア* — 世代。 sg.、部分的 (*ニヒル*付き)
 - **翻訳:** 町には水がありません。 

**8.** *プラスヴィーニーナウテビバント。*
 - *ヴィニー* — 世代。 sg.、部分的 (*プラス*付き)
 - **翻訳:** 船員はより多くのワインを飲みます。 

**9.** *Rōma oppidum magnae gloriae est.*
 - *magnae gloriae* — gen. 説明の
 - **翻訳:** ローマは偉大な栄光の都市です。 

**10.** *愛国者ミリテスが動きます。*
 - *パトリエ* — 世代。 所有権/主観的世代。 
- **翻訳:** 祖国への愛が兵士たちを動かします。

 ## 練習する

 **A. 対格の使用を特定します:**
 1. *ナウタ アド インシュラム ナビガット.* (*アド インシュラム*)
 2. *民兵は逃亡中です。* (*適切なティモレム*)
 3. *シルバムごとに。* (*シルバムごとに*)
 4. *Puella silvam amat.* (*シルヴァム*)

 **B. 属格の使用を特定します:**
 1. *Scholā est.のLiber magistrī*
 2. *ムルトゥム・チビ・ハベムス。*
 3. *ヴィル・マグナエ・ヴィルトゥティス・プニャット。*
 4. *武装勢力の逃亡者。*

 **C. ラテン語に翻訳すると:**
 1. 兵士たちは野原を行進します。 (*mīlitēs、agrum、per、ambulāre*)
 2. 町にはワインがたくさんあります。 (*multus、vīnum、in + 奪格*)
 3. 敵に対する恐怖は大きい。 

**答えキー B:**
 1. *magistrī* = 所有の属格
 2. *cibī* = 分格属格
 3. *magnae virtütis* = 説明の属格
 4. *mīlitum* = 分詞属格

 **解答キー C:**
 1. *農業救急車ごとのミリテス*
 2. *オッピドー通りのムルトゥム・ヴィニー*
 3. *ティモール ホスティウム マグヌス推定値*

 ## 概要

 - **対格**は直接目的語をマークし、動きと範囲の前置詞を伴います: *ad、in (into)、per、propter、ante、post、trans*。 
- **属格**は、所有（「の」）、分割（*nihil aquae*）、および記述（*magnae virtōtis*）を表します。 
- 単一の前置詞 *in* は、対格 (動詞) と奪格 (休符/休符) の 2 つの異なる場合を制御します。 
- 部分属格は量と量を表す単語の後に続きます。 
- 説明の属格には、常に属格名詞の横に **修飾形容詞** が必要です。
