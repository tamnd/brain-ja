## 概要

 **与格**と**奪格**は、初心者が最も混同しやすい 2 つの格です。見た目が似ているからではなく (通常、語尾が異なるため)、それぞれにいくつかの異なる用途があるためです。 このレッスンでは、両方のケースの最も重要な用途を初心者レベルで図示します。 

---

 ## 与格の場合

 ### 1. 間接目的語の与格

 最も一般的な使用法: 与格は、**誰に対して**、または**誰のために**何かをする人を表します。 英語では「to」や「for」で表現されることが多いです。 

*ナウタ プエラエ ローサム ダット*
 — 船乗りは**女の子**にバラを贈ります。 

*マジスター プエリス リブロスが発行されます。*
 — 先生は **男子向け**の本を買います。 

間接オブジェクトは直接オブジェクトの「受信者」です。 パターン: 与える、示す、伝える、または送信する動詞 + 直接目的語 (対格) + 間接目的語 (与格)。 

### 2. 所有の与格

 *esse* の形式で使用され、誰かが**持っているもの**を表現します。 「所有者」は与格になります。 持っている物が主体です。 

*ミヒノーメンエストマーカス。*
 — **私にとって** 名前はマーカスです → 私の名前はマーカスです。 

*ミリティー グラディウス エラット。*
 — **兵士へ** そこには剣がありました → 兵士は剣を持っていました。 

*ティビ・ムルティ・アミシー・サント。*
 ――友達がたくさんいるんですね。 （文字通り：「あなたのためにたくさんの友達がいます。」）

 ### 3. 参照与格 (関心の与格)

 与格は、ある行動が **誰にとって利益になるか、不利になるか**、または **誰の目から見て**、何かが真実であるかを示します。 

*ミヒプラセット。*
 — **私にとって**楽しいです → 好きです。 / それは私を喜ばせます。 

*ホク ティビ ディコ。*
 — 私は**あなたの利益のために**/あなたに言及してこれを言います。 

*オムニバスは真実ではありません。*
 — 真実は**皆**に知られています/誰もが推測しています。

 ## 奪格の場合

 奪格はラテン語の中で最も汎用性の高い格で、英語がさまざまな前置詞 (「by」、「with」、「from」、「in」、「at」) で表現する関係をカバーします。 **前置詞あり**と**なし**の両方で使用されます。 

### 4. 伴奏の奪格

 **with** *cum* (常に)、**誰が同行する**かを表現します。 

*カムアミコベニット。*
 — 彼は**友達と一緒**に来ています。 

*ミリテスはその活動を続けています。*
 — 兵士たちは**王とともに**旅をしました。 

注: *cum* は、接語として人称代名詞に付加されます: *mēcum* (私と一緒に)、*tēcum* (あなたと一緒に)、*nobīscum* (私たちと一緒に)。 

### 5. 手段（手段）の剥奪

 使用した**ツールまたは器具**を表します。 ラテン語には **前置詞** はありません。 

*グラジオ・プナト。*
 — 彼は **with a Sword** (剣を使って) 戦います。 

*ペディバス アンブラムス。*
 — 私たちは**自分の足で/その上** (足を使って) 歩きます。 

*アクアナビガント。*
 — 彼らは**水によって** / **水の上**で航海します。 

### 6. マナーの奪格

 アクションが**どのように実行されるか**を表します。 通常は形容詞が必要です。 *cum* は、形容詞 (*magnācum cār* または *cum magnā cā*) と一緒に使用される場合、**名詞の前**に挿入されますが、形容詞が存在する場合、*cum* はオプションです。 

*Magnā 兼 cārā scribit.*
 — 彼は**細心の注意を払って**書いています。 

*Summā virtüte pugnāvērunt.*
 — 彼らは**最大の勇気**で戦った。 

*サイレンティオ イントラビット*
 — 彼は**沈黙**に入りました（形容詞はありません→*絶頂*は必要ありません）。 

### 7. 前置詞を伴う奪格 — 休符と分離

 これらの前置詞は常に奪格を取ります。

| 前置詞 | 意味 | 例 |
 |-----------|-----------|----------|
 | *a/ab* | から、離れて | *ab oppidō* — 街から |
 | *で* | から下へ。 について | *dē monte* — 山から下りる |
 | *ē/元* | から、から | *ex silvā* — 森の外へ |
 | *で* | で、オン (休憩) | *農業* — 畑で |
 | *サブ* | 下（残り） | *サブアーボア* — 木の下 |
 | *兼* | |付き *兼民兵* — 兵士たちとともに |
 | *正弦* | | なし *sine aqua* — 水なし |
 | *プロ* | 前に; | を代表して *pro patriā* — 祖国を代表して |
 | *スーパー* | 上（休憩） | *スーパー テラム* — 地球の上 |

 覚えておいてください: *in* + 奪格 = **place where** (静止状態); *in* + 対格 = **動き**。 

### 8. 時間の奪格

 **時点**を表します(前置詞なし)。 名詞は通常、時間の単語 (*nox、diēs、annus、hora*) です。 

*Eā nocte militēs vēnērunt.*
 — **その夜**、兵士たちがやって来た。 

*Prīmā lōce profectī sumus.*
 — 私たちは**最初の明るいうちに**出発しました。 

*Eōdem anno Caesar in Galliam vēnit.*
 — **同じ年** カエサルがガリアにやって来ました。 

### 9. 分離の奪格

 **誰から、または何から**、何かが分離または削除されることを表します。 多くの場合、*ab、dē、ex*、または解放、不足、削除の動詞を伴います。 

*ミリテス・ホスト・リベラヴィット。*
 — 彼は兵士たちを**敵**から解放しました。 

*カレットアクア*
 — 彼には **water** が不足しています (*carere* の後に前置詞がありません)。

 ## 12 の例文 — 与格と奪格の使用の分析

 **1.** *Puellae librum do.*
 - *puellae* = 間接目的語の与格 → **翻訳:** 私は**女の子**に本をあげます。 

**2.** *ミヒノーメンエストイウリア。*
 - *ミヒ* = 所有の与格 → **翻訳:** 私の名前はジュリアです。 

**3.** *ティビ・ムルティ・アミシー・サント*
 - *Tibi* = 所有の与格 → **翻訳:** あなたにはたくさんの友達がいます。 

**4.** *ミヒプラセットヘクビア。*
 - *ミヒ* = 参照/関心の与格 → **翻訳:** この道は私を喜ばせます/私はこの道が好きです。 

**5.** *オッピドー・アンブラバットでカム・アミシーを。*
 - *amīcīs* = 伴奏の奪格 (*cum* 付き)
 - *おっぴど* = *in* (場所) の奪格
 - **翻訳:** 彼は**友人たち**と町を歩いていました。 

**6.** *Gladio miles hostēs vīcit.*
 - *Gladio* = 手段の奪格 (前置詞なし)
 - **翻訳:** 兵士は **剣**で敵を征服しました。 

**7.** *Magnācum cārā magister puerōs docēbat.*
 - *Magnācum cārā* = マナーの奪格
 - **翻訳:** 先生は**とても注意深く**少年たちを教えていました。 

**8.** *ミリテスの元不法行為者。*
 - *ex oppidō* = *ex* によるアブレーティブ、からの分離/動作
 - **翻訳:** 兵士たちは**町から逃げ出しました**。 

**9.** *シネ アクア ホモー ヴィヴェレ ノン ポテスト。*
 - *aqua* = *sine* による奪格
 - **翻訳:** 水がなければ人は生きていけません。 

**10.** *Eā nocte rēxepistulam scrīpsit.*
 - *Eā nocte* = 時間の奪格
 - **翻訳:** **その夜**、王は手紙を書きました。 

**11.** *Prō patriā mīlitēs pugnāvērunt.*
 - *patriā* = *proō* (に代わって) を伴う奪格
 - **翻訳:** 兵士たちは**祖国を代表して**戦った。 

**12.** *シルヴァム イントラヴィットのサイレンティオ。*
 - *Silentiō* = マナーの奪格 (形容詞、*cum* はありません)
 - **翻訳:** 彼は**黙って**森に入った。

 ## 練習する

 **A. それぞれの与格または奪格の使用を確認します:**
 1. *Rēgī servus donum dedit.* (*Rēgī*)
 2. *ミリティー グラディウス ロングス エラット.* (*ミリティー*)
 3. *Cum rēgīnā fēminae ambulābant.* (*rēgīnā*)
 4. *マグナー ヴィルトゥテ プグナヴィット。* (*マグナー ヴィルトゥテ*)
 5. *元不法都市逃亡者。* (*おっぴど*)
 6. *Eō annō bellum fuit.* (*annō*)

 **B. ラテン語に翻訳すると:**
 1. 女の子は船乗りに水をあげます。 
2. 私たちにはたくさんの友達がいます。 (所有の与格を使用)
 3. 兵士たちは非常に勇敢に敵と戦った。 
4. 王がいなければ国民は平和に暮らすことはできません。 
5. その夜、私たちは声を聞きました。 

**答えキー A:**
 1. *Rēgī* = 与格間接目的語
 2. *Mīlitī* = 所有の与格
 3. *rēgīnā* = 伴奏の奪格 (*cum* 付き)
 4. *Magnā virtüte* = マナーの奪格
 5. *oppido* = *ex* の奪格、分離
 6. *annō* = 時間の奪格

 **答えキー B:**
 1. *Puella nautae aquam dat.*
 2. *Nobīs multī amīcī sunt.*
 3. *民兵は最高の美徳を持っています。*
 4. *ペースを維持しながら活動します。*
 5. *Eā nocte vōcēs audīvimus.*

 ## 概要

 - **与格**は、間接目的語 (「to/for」)、所有物 (*esse* 付き)、および参照/関心をカバーします。 
- **奪格**には、伴奏 (*cum*)、意味 (前置詞なし)、方法 (*cum* + 形容詞)、場所 (*in/sub*)、​​動きからの動き (*ab/ex/dē*)、および時刻 (前置詞なし) が含まれます。 
- 奪格の用法を区別する鍵: **前置詞の存在** と **意味的文脈** (人対物、動き対静止、時間対場所)。 
- *Cum* は常に伴奏として存在します。 形容詞が存在する場合、これはオプションです (ただし一般的です)。 それは手段としては存在しない。 
- レッスン 2 と 6 を合わせて、6 つのラテン語の格とその主な機能をすべて理解できるようになりました。
