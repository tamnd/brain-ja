## 4 つの主要な部分

 すべてのラテン語動詞は、**4 つの主要な部分**で辞書にリストされています。これは、各動詞が他の動詞からは予測できないことを示しているためです。 

| パート | 例 (*アマレ*) | それがあなたに与えるもの |
 |-----|-------------------|--------|
 | **1 番目** — 1sg が現在アクティブ | *あもう* | 現在、不完全、将来のアクティブなステム |
 | **2番目** — 不定詞 | *アマレ* | 活用の識別 |
 | **3 番目** — 1sg パーフェクト アクティブ | *アマヴィー* | パーフェクト、プルパーフェクト、フューチャーパーフェクトアクティブ |
 | **4th** — 完了受動分詞 | *アマタム* | パッシブパーフェクトシステム+仰臥位 |

 各動詞の 4 つの主要な部分をすべて暗記する必要があります。 **3 番目の主要部分** は予測不可能です。現在から完璧を与える単一のルールはありません。 

---

 ## 完全時制アクティブエンディング

 パーフェクト アクティブには、現在のシステムとはまったく異なる、**独自のユニークなエンディング セット**があります。 それらは完全な語幹 (第 3 主部から **-ī** を引いたもの) に直接接続されます。 

| 人物 | 単数 | 複数 |
 |----------|----------|----------|
 | 1位 | **-ī** | **-アイマス** |
 | 2位 | **-イスティ** | **-istis** |
 | 3番目 | **-それ** | **-ērunt** (または **-ēre**) |

 **式:** 完全語幹 (= 第 3 主部マイナス -ī) + 完全語尾

 *amāvī* → 語幹 *amāv-* → *amāvī, amāvistī, amāvit, amāvimus, amāvistis, amāvērunt*

 ## 不完全と完璧: 重要な違い

 この区別は、ラテン語を正しく読むための基本です。 

| 側面 | 不完全 | 完璧 |
 |----------|----------|----------|
 | ラテン名 | *不完全* (未完成) | *perfectum* (終了) |
 | 意味 | 進行中の、習慣的な、繰り返された、試みられた | 完了したイベント、時間厳守、「完了しました」 |
 | サイン | -バー- | ユニークな完璧な結末 (-ī、-istī…) |
 | *amō* の翻訳 | *amābam* = 私は愛していました / 私は愛していました | *amāvī* = 私は愛しました / 私は愛しました |

 **並べて:**

 - *Mīlitēs pugnābant.* — 兵士たちは **戦っていました** (進行中の戦闘シーン)。 
- *Mīlitēs pugnāvērunt.* — 兵士は **戦った** / **戦った** (交戦を完了)。 

- *Puella carmina cantābat.* — その少女は**歌を歌っていました** (習慣的に)。 
- *Puella carmen cantāvit.* — 少女は歌を **歌いました** (1 つの完結した行為)。

 ## 完璧な形成パターン (認識用)

 | パターン | 結成経緯 | 例 |
 |----------|-----------|----------|
 | **-対-完璧** | *-v-* を現在の語幹に追加します | *amō → amāvī*、*audīō → audīvī* |
 | **-u- 完璧です** | *-u-* を現在の語幹に追加します | *モネオ → モヌイー*、*ハベオ → ハブイー* |
 | **-s- / -x- 完璧** | 子音 + s (x と書かれることが多い) | *dīcō → dīxī*、*regō → rēxī* |
 | **長母音** | 語幹母音が長くなる | *capiō → cēpī*、*video → vīdī* |
 | **重複しました** | ステムの重複 | *ドー→デディー*、*カノー→セシニー* |

 この段階では、これらのパターンを予測するのではなく**認識**することに重点を置きます。 常に完璧を辞書で調べてください。

 ## 10 の例文

 **1.** *シーザー・ガロスの言葉。*
 - *vīcit* = 完全な 3 番目の sg。 (*vincere, vīcī*) → **翻訳:** カエサルはガリア人を征服しました。 

**2.** *Mīlitēs oppidum cēpērunt.*
 - *cēpērunt* = 完全な 3 番目の PL。 (*capere, cēpī*) → **翻訳:** 兵士たちは町を占領しました。 

**3.** *ヴェーニー、ヴィディー、ヴィシー。*
 - 3 つの完璧な、1 番目の sg。 — カエサルの有名な報告書 → **翻訳:** 私は来た、見た、征服した。 

**4.** *カルミナ カンタヴィットの魔法。*
 - *cantāvit* = 完全な 3 番目の sg。 (第 1 結合) — 単一の完成した行為 (cf. *cantābat* = 歌っていた)
 - **翻訳:** その女の子は歌を歌いました。 

**5.** *マジスター・プエロス・モヌイット。*
 - *monuit* = 完全第 3 sg.、第 2 conj. → **翻訳:** 先生は少年たちに注意しました。 

**6.** *聖書の書簡?*
 - *Scrīpsistī* = 完璧な 2 番目の sg。 (*スクリベレ、スクリプシー*); *-ne* = 質問
 - **翻訳:** あなたはその手紙を書きましたか?

 **7.** *オリム ローマ トゥトゥム オルベム レクシット。*
 - *rēxit* = 完璧な 3 番目の sg。 (*レゲレ、レクシー*)
 - **翻訳:** かつてローマは全世界を支配していました。 

**8.** *私はローマです。 トゥ ノンドゥム ヴェニスティ.*
 - 2 つの完了形、1st および 2nd sg。 
- **翻訳:** 私はすでにローマに来ています。 あなたはまだ来ていません。 

**9.** *Nautae per maria multa iter fēcērunt.*
 - *fēcērunt* = 完全な 3 番目の PL。 (*ファチェレ、フェシー*)
 - **翻訳:** 船乗りたちは多くの海を旅しました。 

**10.** *ローママグナフルーツ。*
 - *fuit* = 完璧な 3 番目の sg。 *esse* の — 完成した状態
 - **翻訳:** ローマは素晴らしかったです。 (ローマは素晴らしかった - もはやそうではない、あるいは声明が完了したことを暗示している)

 ## 練習する

 **A. 不完全または完璧である理由を翻訳して説明してください:**
 1. *Servus labourābat.*
 2. *Servus labourāvit.*
 3. *Puer librum Legēbat.*
 4. *Puer librum lēgit.*

 **B. 次の完全な 3 番目の複数形を教えてください:**
 1. *アマレ* → ?
 2. *モネーレ* → ?
 3. *レジェレ* → ?
 4. *ヴェネーレ* → ?
 5. *エッセ* → ?

 **C. ラテン語に翻訳すると:**
 1. 兵士たちは王の声を聞きました。 
2. 私はたくさんの手紙を書きました。 
3. 女王はローマ人を統治していましたか?

 **答えキー A:**
 1. *labōrābat* = 不完全 → 「奴隷は働いていた」（継続的、記述的）。 
2. *labourāvit* = 完璧 → 「奴隷は働いた」(完了したタスク)。 
3. *legēbat* = 不完全 → 「少年は本を読んでいた」(進行中)。 
4. *lēgit* = 完璧 → 「少年は本を読みました」（読み終えました）。 

**答えキー B:**
 1. *アマヴァルント* | 2. *記念品* | 3. *レクセーラント* | 4. *ヴェネラント* | 5. *燃料*

 **解答キー C:**
 1. *ミリテスの声は聞こえます。*
 2. *Multāsepistulās crīpsī.*
 3. *ロマンスはもう終わりですか? *

 ## 概要

- **完了**時制は、**第3主部**から-īを引いたものを語幹として使用します。 
- 完璧な結末はユニークです: **-ī、-istī、-it、-imus、-istis、-ērunt**。 
- 完了は、**完了した、時間厳守**の過去の行動を表します。 不完全なものは、**継続的で習慣的な**過去の行動を表します。 
- 完了形は不規則であることがよくあります。常に 4 つの主要な部分をすべて暗記してください。 
- *Esse* 完全: *fuī、fuistī、fuit、fuimus、fuistis、fuērunt*。
