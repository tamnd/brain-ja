## 概要

 ラテン語には 4 つの **分詞**があります。これは、動詞の特性 (時制、音声) と形容詞の特性 (性別、数、格の一致) を組み合わせた動詞の形容詞です。 これらにより、ラテン語は複雑なアイデアを分詞句に圧縮することができます。 分詞を含む最も重要な構文は **奪格絶対**です。 

---

 ## 1. 4 つの分詞の概要

 | 分詞 | 時制/声 | ステム | エンディング |
 |-----------|---------------|------|-----------|
 | PAP (現在アクティブ) | 進行中/同時 + アクティブ | 現在の語幹 | 12月3日、1学期。 (-ns/-ntis) |
 | PPP (パーフェクトパッシブ) | 完了 + パッシブ | 第4主要部 | 12月1日/2日 (-us/-a/-um) |
 | FAP (フューチャーアクティブ) | 予想 + アクティブ | パフォーマンス。 ステム | 12月1日/2日 (-ウラス/-ウラ/-ウラム) |
 | FPP/ゲルンディーブ (未来パッシブ) | 必要性 + 受動的 | 現在の語幹 | 12月1日/2日 (-ndus/-nda/-ndum) |

 ---

 ## 2. 現在能動分詞 (PAP)

 **フォーメーション:** 現在の語幹 + *-ns* (名目値) / *-ntis* (名目値)。 1 語終端の第 3 変化形容詞として辞退します。 

| 活用 | PAP (公称値/一般標準値) | 意味 |
 |-----------|---------------------|----------|
 | 1位 (*あもう*) | アマンス / アマンティス | 愛する |
 | 2nd (*もねお*) | モネン / モネンティス | 警告 |
 | 3rd (*デュコ*) | ドゥセン / ドゥセンティス | 先頭 |
 | 3rd-io (*カピオ*) | カピエンス / カピエンティス | 取る |
 | 4 番目 (*音声*) | オーディエンス / オーディエンティス | 聴覚 |

 **PAP の語形変化** (モデル: *amāns*):

 | ケース | 男女 | N |
 |------|-----|---|
 | ノム。 sg. | アマンス | アマンス |
 | 将軍 | アマンティス | アマンティス |
 | だった。 sg. | アマンティー | アマンティー |
 | 準拠 sg. | アマンテム | アマンス |
 | アブル。 sg. | アマンティー (属性) / アマンテ (絶対) | アマンティー / アマンテ |
 | 公称値/定格値 お願いします。 | アマンティース | アマンティア |
 | Gen.pl. | アマンチウム | アマンチウム |

 **奪格に関する注意:** PAP が連体的 (句内の名詞と一致する) 場合、奪格 sg. *-ī* で終わります。 **アブレーティブ絶対**の一部である場合、*-e* で終わります。 

**使用法:** PAP は、*主動詞と同時に発生するアクション**を記述します。 
- *Puer canēns per viam ambulat.* — 少年は**歌いながら**、道に沿って歩いています。 
- *Vidī mīlitēs pugnantēs.* — 私は兵士たちが**戦っている**のを見ました。 

---

 ## 3. 完了受動分詞 (PPP)

 PPP は **4 番目の主要部分**です。 *ボーナス/ボーナス/ボーナス*として減少します。 これは、**すでに完了した**および**受動的な**アクションを記述しています。 

| 動詞 | PPP | 意味 |
 |------|-----|-----------|
 | アモ | アマトゥス/a/um | 愛されて |
 | もねお | モニトゥス/a/um | 警告された |
 | デュコ | 管/a/um | 導かれて |
 | カピオ | キャプトゥス/a/um | 取られた |
 | オーディオ | オーディタス/a/um | 聞いたことがある |

 **使用方法:**
 - *Oppidum captum Erat magnīs moenibus.* — **占領された**町には大きな城壁がありました。 
- *Mīlitēs victī fgiēbant.* — **敗北した**兵士たちは逃走中だった。 

---

 ## 4. 未来能動分詞 (FAP)

 **形式:** 完了受動分詞語幹 (= 4 番目の主部マイナス *-um*) + *-urus/-ura/-urum*。 第 1/2 変化形容詞として断ります。 

| 動詞 | FAP | 意味 |
 |------|-----|-----------|
 | アモ | アマトゥルス/a/um | 恋をしようとしている、恋をしようとしている |
 | もねお | モニトゥールス/a/um | 警告しようとしています |
 | デュコ | 管/a/um | リードしようとしています |
 | カピオ | カプトゥルス/a/um | 取ろうとしています |
 | オーディオ | オーディトゥルス/a/um | 聞くところです |

 **使用法:** 多くの場合、*esse* と一緒に **能動的周縁詞** (「私は... しようとしています」) を形成するために使用されます。 
- *シーザー・プグナトゥルス・エラト* — シーザーはまさに戦おうとしていた。 
- *Mīlitēs profectī sunt.* — 兵士たちは出発しようとしています。 

---

 ## 5. 動名詞 / 未来受動分詞 (FPP)

 **形成:** 現在の語幹 + *-ndus/-nda/-ndum*。 第 1/2 変化形容詞として断ります。 **必要性または義務** (「_____ でなければならない」または「_____ である価値がある」と訳されることもあります):

 | 動詞 | ゲルンディーブ | 意味 |
 |------|-----------|-----------|
 | アモ | アマンダス/a/um | 愛される必要がある、愛されなければならない |
 | レゴ | レジェンダス/a/um | 必ず読んでください |
 | カピオ | カピエンダス/a/um | 取らなければなりません |

*esse* とともに **述語的に**使用される動名詞は、義務を表す **受動態周縁詞**を形成します。 
- *Hoc opus faciendum est.* — この作業は必ず実行する必要があります。 
- *Caesar Romam redeundus est.* — カエサルはローマに戻らなければなりません。 （直訳：「カエサルはローマに戻らなければならない人物である」）

 受動周縁語を持つエージェントは、**エージェントの与格** (*a/ab* ではない) を使用します。 
- *Carthāgō dēlenda est Romānīs.* — カルタゴはローマ人によって破壊されなければなりません。 (Romānīs = 代理人の与格)

 ---

 ## 6. アブレーティブな絶対性

 **絶対奪格**は、主語が**主節の主語**と異なる奪格の分詞句です。 主なアクションの時間的、因果的、または状況的な背景を設定します。 

**3 種類:**

 **A. アクティブ (PAP + 奪格の名詞):**
 *Hostibus figientibu***s**、Caesar victoriam nuntiavit.*
 敵は**逃走中**(=敵が逃走している間/逃走中)、シーザーは勝利を発表した。 

**B. 受動態 (PPP + 奪格の名詞):**
 *Oppidō captō、mīlitēs laetī erant.*
 **町が占領された**（=町が占領された後）で、兵士たちは幸せでした。 

**C. 名詞 + 名詞 (分詞なし):**
 *Caesare duce, exercitus vīcit.*
 **カエサルがリーダーである** (= カエサルをリーダーとして)、軍は征服しました。 

**重要なルール:** 奪格絶対の主語は、主節の主語と同じであってはなりません。

 ## 重要な語彙

 | ラテン語 | 英語 |
 |------|-----------|
 | カノー、カネレ、セシニ、カントゥム | 歌うこと |
 | フギオ、フジェレ、フギ、フギツム 逃げる |
 | リバート / リデオ | 戻る |
 | ヌンティオ、ヌンティアレ | 発表する |
 | デレオ、デレレ、デレヴィー、デレトゥム | 破壊する |
 | ファシオ、ファセラ、フェシー、ファクトム | する、作る |
 | デュックス、デュシス M. | リーダー、将軍 |
 | ビクトリア、-ae f. | 勝利 |
 | 作品、作品n. | 仕事、タスク |
 | ダム | while (+ 現在の直説法) |

 ## 例文

 1. *Puer librumlegēns tacēbat.* — 少年は**本を読んで**、黙っていた。 (PAP)
 2. *Mīlitēs victī Romam rediērunt.* — **敗北した**兵士たちはローマに戻りました。 (PPP)
 3. *Caesar pugnātōrus mīlitēs hortātus est.* — カエサルは **これから戦う**と兵士たちを激励した。 (FAP)
 4. *Oppidō captō, dux praemia distribuit.* — **町は占領されました**、一般に配布された報酬。 (アブレーションアブソリュート、PPPタイプ)
 5. *Hostibus fugientibu***s**, Romānī victōriam celebrāvērunt.* — **敵が逃げる**、ローマ人は勝利を祝いました。 (アブレーションアブソリュート、PAPタイプ)
 6. *Caesare duce, Romānī nunquam vincebantur.* — **カエサルが指導者である**ため、ローマ人は決して敗北しませんでした。 (名詞 + 絶対名詞)
 7. *Hoc opusomnibus faciendum est.* — この作業は全員で行う必要があります。 (動名詞 + 代理人の与格)
 8. *Carthāgō dēlenda est.* — カルタゴは破壊されなければなりません。 （カトー長老の有名な言葉）
 9. *Puella canēns pulchraerat.* — **歌っている** 女の子は美しかった。 
10. *Librum lectum reposuit.* — 彼は **読んだ** 本 (= 彼が読んだ本) を置きました。 
11. *Mīlitēs profectī arma sōmpsērunt.* — 兵士たちは**出発しようとして**、武器を取った。 
12. *Pāce fatā, omnēs laetī erant.* — **平和が築かれた**、誰もが幸せでした。 (アブレーティブ・アブソリュート)

 ## 練習する

 **A. 分詞の種類 (PAP/PPP/FAP/FPP) を特定し、次のように翻訳します。**
 1. *ミリテス・ヴィンセンテス*
 2. *アーブスキャプタ*
 3. *デュックス・ロチュルス*
 4. *オプス・ファシエンダム*

 **B. アブレーティブな絶対値を翻訳し、そのタイプを識別します (上記の A/B/C):**
 1. *Romānīs vincentibu***s**、Gallī fugērunt。 
2. *事実を理解してください。*
 3. *Caesare imperātōre、exercitus fortiter pugnāvit。*

 **C. 分詞を使用してラテン語に翻訳します:**
 1. 女の子は庭に座って本を読んでいました。 
2. 都市が占領された後、兵士たちは休息しました。 
3. リーダーは話そうとし、兵士たちの前に立った。
