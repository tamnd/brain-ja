## 概要

 **仮定法** は、単に事実 (指示的) または命令 (命令的) として述べられるのではなく、主観的な、可能、望ましい、恐れられる、疑われる、または別の条項に従属する行為を表します。 初級レベルでは、仮定法の 2 つの時制 (現在と不完了) と 2 つの主な用法: **目的節** (*ut/nē*) と **間接命令** (*iubeō/rogō/hortor* + *ut*) を学びます。 

---

 ## 1. 仮定法が表現するもの

 仮定法は、英語の翻訳で直説法が使用されている場合でも、多くのラテン語の従属節で必要です。 これは、英語の用語で単に「疑い」や「不確実性」を意味するものではなく、特定の文節タイプにおける文法上の要件です。 

| 使用 | トリガー | 時制 |
 |-----|----------|----------|
 | 目的 | *ut/nē* | 現在または不完全 |
 | 間接コマンド | 命令動詞 + *ut / nē* | 現在または不完全 |
 | 結果 | *ut / ut non* | 現在または不完全 |
 | 間接的な質問 | 疑問詞 + 文節 | 現在または不完全 |
 | Cum-clauses (因果関係/譲歩) | *兼* | 不完全または完全完全 |

 このレッスンでは、最初の 2 つに焦点を当てます。

 ## 4. 目的節 (*ut / nē* + 仮定法)

 **目的節**は、主なアクションの理由または目標を表します。 これは *ut* (肯定: 「そのために」) または *nē* (否定: 「そのために … ではない / そうでない」) によって導入されます。 

**ルール:** 主動詞が主時制 (現在、未来、未来完了) である場合は、**仮定法現在** を使用します。 主動詞が二次時制 (不完了、完了、プル完了) の場合は、**不完了仮定法** を使用します。 

| 動詞の主時制 | 目的節の時制 |
 |-----------------|---------------------|
 | 現在、未来 | 現在仮定法 |
 | 不完全、完璧、プルパーフェクト | 不完了仮定法 |

**例:**
 - *生徒たちは教師を喜ばせるために**働きます**。 
- *Discipulī labōrābant **ut** magistrum placeērent.* — 生徒たちは**教師を喜ばせるために**働いていました。 
- *Fuge **nē** capiāris.* — 捕らえられないように**逃げてください。 
- *Flungit **nē** caperētur.* — 彼は捕らえられないように**逃げました (= 捕らえられないように)。

 ## 5. 間接コマンド (*iubeō、rogō、hortor、imperō* + *ut / nē*)

 命令する、尋ねる、促す、または命令する動詞の後に、ラテン語では *ut / nē* + 接続法 (英語とは異なり不定詞ではありません) を使用します。 これは、**間接命令**または**判断名詞節**と呼ばれます。 

一般的なトリガー動詞:
 | ラテン語 | 英語 |
 |------|-----------|
 | インペロ、インペラレ (+ データ) | （誰かに）注文する |
 | ロゴ、ロガーレ | 尋ねる、要求する |
 | ホルトル、ホルターリー | 促す、励ます |
 | 説得する、説得する (+ データ) | 説得する |
 | モネオ、モネレ | アドバイスする、警告する |

 **例:**
 - *Dux mīlitibus imperāvit **ut** fortiter pugnārent.* — 将軍は兵士たちに**勇敢に戦う**ように命じた。 （直訳：「彼らは勇敢に戦う」）
 - *Magister discipulōs hortātus est **ut** labōrārent.* — 教師は生徒たちに **働くように**しました。 
- *Rogō tē **nē** discēdās.* — **立ち去らないようにお願いします**。 （直訳：「あなたが去らないように」）

 **不定詞との対比:** 英語では不定詞が使用されます (「私は彼に行くように命じた」)。 ラテン語では、間接コマンドでは *ut/nē* + 接続法を使用します。 

---

 ## 6. 時制のシーケンス (導入)

 | シーケンス | 主な動詞時制 | 下位節時制 |
 |----------|------|---------------|
 | **プライマリ** | 現在、未来、未来完璧 | 現在仮定法 |
 | **セカンダリ** | 不完全、完璧、プルパーフェクト | 不完了仮定法 |

 順序は、どの仮定法時制が従属節に現れるかを制御します。 アクションがいつ起こったかに基づいて選択するのではなく、主な動詞の時制に基づいて選択します。 

*Rogō ut venias.* (来てください — 現在の主 → 現在の副)
 *Rogāvī ut venīrēs.* (私はあなたに来るように頼んだ — 完全主 → 不完全副)

 ## 重要な語彙

 | ラテン語 | 英語 |
 |------|-----------|
 | ut (+ サブジェクト) | そのために、それで |
 | ネー (+ 副詞) | そうならないためには…ではありません |
 | インペロ、インペラレ (+ データ) | 注文する、命令する |
 | ロゴ、ロガーレ | 尋ねる |
 | ホルトル、ホルターリー | 促す、励ます |
 | モネオ、モネレ | 警告する、アドバイスする |
 | 説得する、説得する | 説得する |
 | ディスクド、ディスクデレ | 出発する、出発する |
 | 場所、場所 (+ データ) | お願いします |
 | ティメオー、ティメーレ | 恐れる |

 ## 例文

 1. *Vēnimus ut Romam vidēāmus.* — 私たちは**ローマを見るために**来ました。 
2. *Mīles fōgit nē caperētur.* — 兵士は**捕らえられないように**逃げました。 
3. *Caesar mīlitibus imperāvit ut Castra Mōnīrent.* — カエサルは兵士たちに野営地を**強化する**ように命じた。 
4. *Magister discipulōs monuit nē pigritiam amarent.* — 教師は生徒たちに**怠惰を好まないように**警告しました。 
5. *Rogāmus tē ut nobīscum maneas.* — **私たちと一緒にいてください**。 
6. *Puer domum festīnat ut cenam edat.* — 少年は **夕食を食べる**ために急いで家に帰りました。 
7. *Hortor vōs ut fortēs sitis.* — **勇気を持って**ください。 
8. *Exercitus procēdēbat ut oppidum caperet.* — 軍隊は**町を占領するために**進軍していました。 
9. *Nē timeātis, militēs!* — **恐れるな**、兵士たち! (接続法 - 節内ではなく直接使用する)
 10. *Persuāsit amīcīs nē Romā discēderent.* — 彼は友人にローマを離れないよう説得しました。 
11. *Scrībit nē oblīviscātur.* — 彼は **忘れないように** 書いています。 
12. *Rogāvī eum ut librōs redderet.* — 私は彼に**本を返す**ように頼みました。
