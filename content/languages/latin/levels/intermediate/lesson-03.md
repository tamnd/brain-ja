## 概要

 中級者にとって、他のどの構文よりもつまずくのは 2 つの構文です。*ne* と *ut* が通常の意味を交換する **恐怖節**、もう 1 つは命令の動詞が *ut/ne* に仮定法を加えた **間接コマンド ** です。*iubeō* は例外で、動作が異なります。 両方をマスターすると、本格的なラテン語の散文の大部分が解放されます。 

---

 ## パート 1: 恐怖条項

 ### 恐怖動詞を伴う *ne* と *ut* のパラドックス

 目的節では、*ut* は「～するために」を意味し、*ne* は「～しないために」を意味します。 恐れを表す動詞を使用すると、**これは逆になります**。 

| 接続詞 | 恐怖動詞付き | ニーモニック |
 |---------------|----------------|----------|
 | **ね** | 「それ」（そのことが起こるのではないかという恐怖） | 悪いことに対する恐怖 → *ね* |
 | **まあ** | 「そんなことはない」（そのことが起こらないのではないかという不安） | 良いことが起こらないのではないかと心配 → *ut* |

 > *Timeō **nē** veniant.* — 彼らが来るのではないかと心配です。 （彼らが来るのが怖いです。）
 > *Timeō **ut** veniant.* — 彼らは来ないのではないかと心配です。 （彼らは来ないと思います。）

 **記憶術:** 恐怖動詞の場合、*ne* は「私が恐れている悪いこと」です。 あなたはいつも「ね」ことを恐れています。 *Ut* 恐怖を伴うのは、よりまれな前向きな希望のバージョンです。「良い結果は起こらないのではないかと心配しています。」

 ### なぜこのようなことが起こるのでしょうか?

 歴史的に、恐怖条項は、*ne* が「私は恐れています - 来させないでください!」というホルト的な接続法を導入した古い構文に由来しています。 →「彼らが来ないか心配です。」 英語ではこれを古風な「彼が来ないのが怖い」という言葉で保存しています。 *ut* 構文は、「彼らが来ることを祈っています/願っていますが、彼らが来ないのではないかと心配しています」という意味の、後から発展したものです。 

### 恐怖を表す一般的な動詞

 | ラテン語 | 意味 |
 |------|-----------|
 | ティメオー、ティメーレ | 恐れる |
 | メトゥオ、メトゥエレ | 恐れる、恐れる |
 | ヴェレオール、ヴェレリー (dep.) | 恐れる、尊敬する |
 | ホラースコ、ホラーショー | 震える |
 | ペリキュラムエスト | 危険があります（それは） |
 | メトゥエッセで | 恐怖を感じる |

 ### 恐怖節を含む時制のシーケンス

 同じ順序ルールが適用されます。 

| 主な動詞 | *nē* 節 (恐れられることが起こる) | *ut* 節 (恐れられていたことは起こらない) |
 |----------|------------------------------------------|-----------------------------------------------------|
 | プライマリー | *nē* + 現在の主語。 | *ut* + 現在の主語。 |
 | 二次 | *nē* + 不完全な主語。 | *ut* + 不完全なサブジェクト。 |

 ### 実用的な例

 **例 1 — 基本的な恐怖、主な恐怖:**
 > *時間は無駄です。*
 > 彼らが来るのではないかと心配です。 (*timeō* = 主; *nē* + 現在の主語)

 **例 2 — 二次シーケンス:**
 > *時間はホストのトランシーレントです。*
 > 敵が越えてくるのではないかと心配しました。 (*timēbam* = 二次的; 不完全な主題)

 **例 3 — *恐れを抱いて**:**
 > *法定通貨を取得してください。*
 >平和が実現しないのではないかと心配しています。 (*vereor* プライマリ; *ut* = "そうではない")

 **例 4 — シセロ、Att. 5.18:**
 > *Timeō nē Parthi nobīs 交渉出品者*
 > パルティア人が私たちに問題を引き起こすのではないかと心配しています。 

**例 5 — *ペリキュラム est*:**
 > *ペリキュラム・エラット・ネー・オッピダム・カペリトゥール*
 > 町が占領される危険がありました。 (二次的、不完全なサブジェクト、受動的)

 **例 6 — *metuō* と受動態:**
 > *Metuēbant nē ā tergo oppugnārentur.*
 > 彼らは後方から攻撃されることを恐れた。 

**例 7 — シセロ、家族:**
 > *正確な調査を行ってください。*
 > あなたがこれを承認しないのではないかと思います。 

**例 8 — 恐怖条項の Pluperfect:**
 > *Timebam nē parum diligenter scrīpsissem.*
 ＞あまりにも軽率に書いてしまったのではないかと心配になりました。 (前のアクション → plperfect サブジェクト)

 ## パート 2: 間接コマンド (慣用名詞節)

 ### 定義と構造

 **間接命令** (*使用名詞節* または *自発名詞節* とも呼ばれる) は、命令する、促す、尋ねる、アドバイスする、または説得する動詞の目的語として機能する従属的な *ut/ne* 節です。 

**構造:** [命令/促す主動詞] + **ut** (肯定的) / **nē** (否定的) + 仮定法

 > *Imperāvit ut disēderent.* — 彼は彼らに立ち去るよう命じた。 / 彼は彼らに立ち去るように命じた。

英語とは異なり、ラテン語ではこれらの動詞に不定詞を使用できません (*iubeō* を除く — 以下を参照)。 接続法 *ut* 節は必須です。 

### *ut/ne* + 仮定法をとる動詞

 | ラテン語の動詞 | 意味 | メモ |
 |-----------|-----------|----------|
 | インペロ (+ データ) | 注文する、命令する | 人の与格をとる |
 | マンドー (+ データ) | 委託する、注文する | |
 | プラエシペレ (+ データ) | 指示する | |
 | ホルトール、コホルトー | 促す、励ます | |
 | もねお | 警告する、アドバイスする | |
 | ロゴ (+ acc.) | 尋ねる、要求する | 人の対格を取る |
 | おうろ (+ acc.) | 懇願する、懇願する | |
 | ペトー (+ ab + abl.) | 求める、要求する | |
 | 説得力 (+ データ) | アドバイスする、説得する | |
 | ポストロ | 要求する | |
 | ポスコ | 要求する、要求する | |
 | ヴォロー、クピオ | したいこと（誰かがしたいこと） | |

 ### *iubeō* 例外

 **重要なルール:** *iubeō* (命令する、命令する) は *ut* + 仮定法を**取りません**。 **対格 + 不定詞** (間接的なステートメントの構造) を使用します。 

| 動詞 | 建設 | 例 |
 |------|---------------|----------|
 | *インペロ* (+ データ) | だって。 + ut + サブジェクト | *軍事政権は強力な軍事力を持っています。* |
 | *いうべおう* (+ acc.) | 準拠 + 不定詞 | *ミリテスは攻撃を行っています。* |

 どちらも「彼は兵士たちに戦うよう命じた」という意味ですが、文法は全く異なります。 

**思い出のフック:** *Imperō* は、指揮系統 (与格、接続法、より形式的) を通じて命令を下す将軍のように統治します。 *Iubeō* は直接的かつ個人的なものです (対格 + 不定詞 — より直接的)。 

### 否定的な間接コマンド

 **nē** + 仮定法を使用します (*ut nōn* ではありません):

 > *Monuit nē id faceret.* — 彼は彼にそんなことをしないように警告した。 
> *Rogāvit nē discēderēmus.* — 彼は私たちに、帰らないでくれと懇願した。 

### 時制のシーケンス

 同じ順序ルールが適用されます。 主動詞→接続法現在。 二次→不完全。 

| 主な動詞 | 間接コマンド |
 |----------|------|
 | *命令* (彼は命令する) | *とてもありがたい* (彼らが来るとは) |
 | *imperāvit* (彼は命令した) | *ut venīrent* (彼らが来ること/来たこと) |

 ### 実用的な例

 **例 1 — *imperō* 基本:**
 > *Ducī imperāvit ut pontem dēstrüeret.*
 > 彼は将軍に橋を破壊するように命令した。 
> (*imperāvit* → 二次; 与格 *ducī*; 不完全主語)

 **例 2 — *iubeō* コントラスト:**
 > *Mīlitēs trānsīre iussit.*
 > 彼は兵士たちに渡るように命じた。 (*いいべおう* + 対格 + 不定詞)

 **例 3 — *ホルトル*:**
 > *ミリテスは強力な防御力を備えています。*
 > 彼は兵士たちに勇敢に戦うよう促した。 
> (*hortātus est* = 非完全形 → 副次的; 不完全主語)

 **例 4 — *ロゴ* + 否定:**
 > *Tē rogō nē id facias.*
 >そんなことはしないようにお願いします。 (*ロゴ* = 主; 現在の主)

 **例 5 — *moneō*:**
 > *Senātus monuit nē bellum gererent.*
 ＞上院は戦争をしないよう警告した。 (二次的、不完全な主題)

 **例 6 — *説得する* (+ データ):**
 > *Cīvibus persuāsit ut nova lēge üterentur.*
 > 彼は国民に新しい法律を使うよう説得した。 

**例 7 — *volō* + 間接コマンド:**
 > *Volō ut hoc facias.*
 >これをやってほしいです。 (*volō* = 主; 現在の副)

 **例 8 — シーザー、BG 1.31:**
 > *Petīvit ut sibi... auxilium ferrent.*
 > 彼は彼らに助けを持ってくるように頼んだ。 (二次的、不完全な主題)

 ## 間接的なコマンドから恐怖条項を伝える

 どちらも *ne* + 仮定法を使用します。 重要なのは **メイン動詞** です。 

| 主な動詞 | *nē* 句の種類 |
 |----------|------|
 | 恐れる動詞 (*timeō、metuō、vereor*) | 恐怖条項 |
 | 命令/促す動詞 (*imperō、hortor、moneō*) | 間接コマンド |

 > *Timebat nē discēderent.* — 彼は彼らが去ってしまうのではないかと心配しました。 (恐怖条項)
 > *Monuit nē discēderent.* — 彼は彼らに立ち去らないように警告した。 (間接コマンド)

 ## 練習問題

 ### 演習 A — 句のタイプを特定する
 恐怖 (F)、間接命令 (IC)、または目的 (P) としてラベルを付けます。

1. *Imperāvit ut celerīter venirent.* → **IC**
 2. *Vereor nē pluvia veniat.* → **F**
 3. *Cucurrit nē caperētur.* → **P**
 4. *オーラヴィット・ネー・ベラム・ゲレント* → **IC**
 5. *時間はかかります。* → **F**
 6. *Cohortātus est militēs ut fortiter stārent.* → **IC**

 ### 演習 B — 正しいフォームを選択してください
 正しい接続詞 (*nē* または *ut*) を入力してください。 

1. *Timeō \_\_\_ Caesar vincat.* (シーザーが勝つのではないかと心配です) → *nē*
 2. *Timeō \_\_\_ Caesar vincat.* (シーザーは勝てないだろう) → *ut*
 3. *Imperāvit \_\_\_ discēderent.* (彼は彼らに去るように命じた) → *ut*
 4. *Monuit \_\_\_ id faceret.* (彼はそれをしないように警告した) → *nē*

 ### 演習 C — cue 動詞を使用して変換する
 1. *Discēde!* (imperāvit) → *Imperāvit ut discēderet.*
 2. *Nōlī pugnāre!* (ōrāvit) → *Ohrāvit nē pugnāret.*
 3. *Venīte!* (iussit) → *Venīre iussit.* (*iubeō* は不定詞を使用します)

 ## 概要

 | 建設 | 主な動詞 | 接続詞 | サブジェクト 気分 | 特記事項 |
 |-----------|-----------|---------------|------------|------|
 | 恐怖(*nē*) | タイムオ/メトゥオ/ベレオール | いいえ | 仮定法 | *nē* = "それ" |
 | 恐怖 (*ut*) | タイムオ/メトゥオ/ベレオール | うーん | 仮定法 | *ut* = "そうではありません" |
 | 間接コマンド（正） | インペロ/ホルトル/ロゴetc | うーん | 仮定法 | *imperō*との与格 |
 | 間接コマンド（否定） | インペロ/ホルトル/ロゴetc | いいえ | 仮定法 | |
 | *いうべお* | うべお | (なし) | 不定詞 | 準拠 + 不定詞のみ |
