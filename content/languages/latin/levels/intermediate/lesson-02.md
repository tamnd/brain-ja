## 概要

 ラテン語の最も生産的な従属構文のうち 2 つは、同じ仮定法的なムードを通じて機能しますが、まったく異なる目的を果たします。 **結果句** (連続句とも呼ばれます) は、結果として *実際に何が起こったのか* を表します。 **間接的な質問** は、ステートメント内の質問を報告します。 どちらも仮定法を必要としますが、信号単語と文法は明らかに異なります。 

---

 ## パート 1: 結果節 (連続節)

 ### 主要な違い: 結果と目的

 | | 目的条項 | 結果句 |
 |-|---------------|--------------|
 | 質問に答える | *なぜ* 被験者は行動したのでしょうか? | *その結果何が起こりましたか?* |
 | 急行 | 意図、目標 | 実際の結果、結果 |
 | 主要な接続詞 | *ut/nē* | *ut* (ポジティブ) / *ut non* (ネガティブ) |
 | 注意喚起語 | (主節にはなし) | *タム、イタ、シック、タントゥス、タリス、トット、アデオ* |

 **重要なルール:** 結果句は、主句内の「so/that」という単語によって *常に* 通知されます。 *tam、ita、tantus、talis、tot*、または *adeō* が表示された場合は、次の *ut* + 仮定法を探してください。これは結果節であり、目的節ではありません。 

### 注意喚起語 (相関語)

 | ラテン語 | 意味 | | を変更します
 |----------|-----------|----------|
 | タム | だから (程度の副詞) | 形容詞と副詞 |
 | イタ/シック | それで、そのような方法で | 動詞 |
 | アデオ | それほど | 動詞 |
 | タンタス、-a、-um | とても素晴らしい | 名詞 (形容詞) |
 | タリス、-e | そのような種類のもの | 名詞 (形容詞) |
 | トット (断腸の思い) | とてもたくさん | 名詞 (形容詞) |

 ### 否定的な結果条項

 - 肯定的な結果: *ut* + 仮定法 (「だから... した/する」)
 - 否定的な結果: *ut non* + 仮定法 (「だから...はした/しなかった」)
 - また: *ut nēmō* (誰もいないように)、*ut nihil* (何もないように)、*ut numquam* (決してないように) — 否定語は句の *内部* に移動します

 ### 実用的な例

 **例 1:**
 > *私はヴィンセレットを守ります。*
 > 彼はとても勇敢だったので、誰も彼を征服できませんでした。 
> (*ita* → 結果; *nemō* = 内部否定)

 **例 2:**
 > *常に重要な要素が含まれています。*
 > 彼らはあまりにも長い行進をしたので全員が疲れきっていた。 
> (*tam* + 形容詞 *longum* → 二次シーケンスの結果節)

 **例 3:**
 > *これは問題ではありません。*
 > この問題はあまりにも重大だったので、誰も躊躇しませんでした。 
> (*タンタ*、述語形容詞→結果)

 **例 4 — シーザー、BG 1.2:**
 > *地域での多面的な取り組みは...農業文化を維持するために必要な能力を持っています。*
 > その地域には非常に多くの人々が住んでいたため、農業では維持することができませんでした。 

**例 5:**
 > *あなたは、あなたの財産を受け入れます。*
 > 彼は立つこともできないほどの傷を負った。 

**例 6:**
 > *キケロ: Adeō perturbātus Erat ut verba invenīre non posset.*
 > 彼は言葉が見つからないほど動揺した。 

**例 7:**
 > *Tālis erat ōrātiō ut omnēs commoverentur.*
 > そのスピーチは誰もが感動するような種類のものでした。 

**例 8 — 受動的な結果:**
 > *Sīc dictum est ut nēmō intellegeret.*
 ＞誰も理解できないような言い方をされました。 
> (*sīc* → 副詞結果)

 ## パート 2: 間接的な質問

 ### 間接的な質問とは何ですか?

 **直接的な質問**は直接尋ねられます: *Quid facis?* (何をしているのですか?)

 **間接的な質問**は別の文の中に埋め込まれており、質問されたこと、知っていること、疑問に思ったこと、発見されたことを報告します。 
> *Rogāvit quid facerēs.* — 彼はあなたが何をしているのかと尋ねました。 

単に時制を変えるだけの英語とは異なり、ラテン語の間接疑問文は**仮定法**を使用します。 疑問詞 (誰が、何を、どこで、なぜ、どのように) が埋め込み節の先頭に残ります。 

### 間接的な質問で使用される疑問語

| ラテン語 | 意味 | タイプ |
 |------|-------|------|
 | キ/クイ | 誰が/何を | 代名詞 |
 | 子宮 / 子宮 / 子宮 | （2つのうち）どれ | 形容詞/代名詞 |
 | quī / quae / quod | どれ、どんな種類 | 形容詞 |
 | ユビ | ここで | 副詞 |
 | ウンディー | どこから | 副詞 |
 | クォ | どこへ | 副詞 |
 | Quando | いつ | 副詞 |
 | クール/クァレー | なぜ | 副詞 |
 | クォモド / ut | どのように | 副詞 |
 | 引用 (含まず) | いくつ | 形容詞 |
 | 量子論 | なんて素晴らしい | 形容詞 |
 | ウトラム...アン | ...それとも | 粒子 |
 | 番号 | どうか (「いいえ」を予期します) | 粒子 |
 | -ne (エンクリティック) | かどうか | 粒子 |

 ### 間接疑問を導入する動詞

 **尋ねる、知る、伝える、発見する、不思議に思う、または認識する**という動詞は、間接的な質問を導入することができます。 

*rogo、quaerō、petō、sciscitor* (尋ねる); *sciō、nesciō、cognoscō* (知っている/知らない); *dīcō、nārrō* (伝える)。 *ビデオ、オーディオ* (見る、聞く); *mīror、dubitō* (不思議、疑い); *dēmōnstro、ostendou* (ショー、デモンストレーション)。 

### 間接的な質問における時制の順序

 レッスン 1 と同じ順序ルールが適用されます。 

| 主な動詞 | 従属アクションの同時実行 | 従属アクション以前 |
 |----------|-------------------------------------|--------------------------|
 | プライマリー (プレス/フット/フットパフォーマンス) | 現在仮定法 | 完了仮定法 |
 | セカンダリ (imperf/perf/pluperf) | 不完了仮定法 | Pluperfect仮定法 |

 ### 間接疑問と関係節

 どちらも従属語+接続法を使用できます。 違い:

 | | 間接的な質問 | 関係節 |
 |-|-----------------|----------------|
 | 言葉の紹介 | 疑問文 (quis、ubi、cā) | 関係代名詞 (quī、quae、quod) |
 | 意味 | *何を/誰が/どこで/なぜ*を尋ねます。 *どれを説明する* |
 | テスト | 「私は___を気になりますか？」を挿入してもらえますか？ | 「誰が/どの____をする人」と言えますか？ |

 ペアの例:
 - *Rogāvit **quī** hoc fēcissent.* → 「彼は**誰**がこれをやったのかと尋ねました。」 (間接疑問 — *quī* = 疑問文 *who*)
 - *Hominēs **quī** hoc fēcissent punītī sunt.* → 「これを行った**人**は罰せられた。」 (特性の関係節)

 ### 実用的な例

 **例 1 — 基本的な間接的な質問、二次的:**
 > *ロガビットの重要な事実*
 > 彼は何が行われたのか尋ねた。 
> (*rogāvit* = 副次的; *quid* = 疑問文; 先行動作 → 完全主語)

 **例 2 — プライマリ シーケンス:**
 > *ネスシオ ビシース*
 >どこにいるのか分かりません。 
> (*nesciō* = 主; 同時代 → 現在のサブ)

 **例 3 — シーザー、BG 1.18:**
 > *Quaerēbat ex eō quam ob causam Caesar exercitum dēduxisset.*
 > 彼はカエサルがなぜ軍隊を率いたのかと尋ねていた。 
> (*quaerēbat* = 副次的; *quam ob causam* = なぜ; 前例 → pluperfect 副次的)

 **例 4 — *num* は "no" を期待しています:**
 > *ホストはとても親切です。*
 > 彼は敵が来るかどうか疑問に思っています (そしてそうではないと疑っています)。 

**例 5 — *utrum...an*:**
 > *Quaesīvit utrum pācem vellent an bellum.*
 > 彼は彼らが平和を望んでいるのか、それとも戦争を望んでいるのかを尋ねました。 

**例 6 — 主語としての間接的な質問:**
 > *私は事実を知りません。*
 > それがどうやって行われたのか、私はうんざりします。 

**例 7 — *sciō* + 間接的な質問:**
 > *キセロ: Scīs quam tardē haec Romā exeant。*
 > こういったものがローマから離れるのがいかに遅いかご存知でしょう。 

**例 8 — 発見動詞:**
 > *認識は、カストラポジタの本質を認識します。*
 > 彼らはキャンプが張られていた場所を突き止めた。 
> (二次; 前 → プルパーフェクト サブジュ. 受動的)

 ---

 ## 間接的な質問と結果の区別

 どちらも仮定法を使用しますが、次の点を確認すれば混同することはありません。 

1. **主節の注意喚起語** (*tam、ita、tantus*) → 結果
 2. **疑問詞** (*quid、ubi、cā*) → 間接疑問文
 3. **導入動詞** (尋ねる/知る) → 間接疑問文
 4. 注意喚起語の後の **Ut** → ほぼ確実に結果が得られる

 ## 練習問題

 ### 演習 A — 句のタイプを特定する
 それぞれに結果 (R)、間接的な質問 (IQ)、または目的 (P) のラベルを付けます。

1. *Tam duruserat ut nēmō eum amāret.* → **R**
 2. *Vēnit ut amīcum vidēret.* → **P**
 3. *ロガビットの活動* → **IQ**
 4. *Adeō perturbātus est ut loquī non posset.* → **R**
 5. *Nesciō quid dicam.* → **IQ**
 6. *タンタエラットマルチトゥドゥウトフルメントランシーレノン所持。* → **R**

 ### 演習 B — 直接質問を間接質問に変換する
 括弧内の動詞を使用して、各直接の質問を変換します。 

1. *Ubi est Caesar?* (ロゴ) → *Rogō ubi Caesar sit.*
 2. *Quid fēcistī?* (quaesīvit) → *Quaesīvit quid fēcissēs.*
 3. *Cā vēnistī?* (nescit) → *Nescit cā vēneris.*
 4. *「ホストの広告を引用しますか?」 (認識) → *「ホストの広告を認識します。*」

 ### 演習 C — 翻訳
 1. *タムロンガムは休眠中です*
 2. *ミリテスの科学者、ユビ・デュックス・セット。*
 3. *Ita pugnavit ut omnēs mirārentur.*
