Tengwar は、トールキンのシンダール語向けの主要な文字です。 Sindarin Tengwar モードは 2 つあります。 このページでは両方について詳しく説明します。 カジュアルに学習する場合は、まず **標準モード** をマスターしてください。 **ベレリアンドの旋法** (ドゥリンの扉で使用) はより美しく、読みやすいですが、あまり一般的には教えられていません。 

## シンダーリン・テングワールとクエンヤの違い

 トールキンはテングワールのサンプルのほとんどをクエンヤで作成したため、多くのオンライン リソースがクエンヤ テングワールのルールについて説明しています。 シンダーリン・テングワールの動作は異なります。 

| 特集 | クエンヤ・テンワール | シンダール語標準モード |
 |-------|--|----------------------|
 | **母音の配置** | *先行*子音の上の Tehtar | *後続*子音の上の Tehtar |
 | **二重子音** | 下のバーで一度書き込まれています | 同じ |
 | **最後の母音** | 前の子音の上 | 上記サイレントキャリア(*通信会社*) |
 | **モードタイプ** | Ómatehtar (母音 = マーク) | オマテタール (同じタイプ) |
 | **単語末尾の短母音** | テタ付きショートキャリア | テタ付きショートキャリア |

 これは、子音クラスターを含むシンダール語の単語を見た場合、母音記号は単語内の母音の**前**の子音ではなく、**後続**の子音の上にあることを意味します。

 ### 追加のシンダーリン・テンワール

 シンダール語標準モードでは、クエンヤ語の対応する文字と異なる文字がいくつか使用されています。 
- *hwesta sindarinwa* ([x] の特殊文字) は、*ch* 音 [x] のシンダール語固有の Tengwa です。音の分布がわずかに異なる Quenya *harma* とは異なります。 
- *Anto* (多くの分析では通常 *nd*) はシンダール語の *dh* [ð] に使用されます。

 ## 標準モードの母音記号 (*Tehtar*)

 | 母音 | *テタ* | 配置 |
 |----------|-----------|----------|
 | | 3 つの点 (上) | 上に続く子音 |
 | e | 急性脳卒中 | 上に続く子音 |
 | 私 | シングルドット | 上に続く子音 |
 | o | 右カール | 上に続く子音 |
 | あなた | 左カール | 上に続く子音 |
 | y | 特別なマーク | 上に続く子音 |

 **重要なルール**: シンダール語の *Tehtar* は **次の子音**の上に置きます。 

母音が **単語の終わり** (後続の子音がない) にある場合: **短い無音搬送波** (*telco*) の上に *tehta* を書きます。 

### 長母音

 長母音 (アキュートアクセントが付いている: á、é、í、ó、ú) は次のように示されます。 
- *tehta* を、それが置かれている文字の下**にバーを付けて書きます、または
 - ショートキャリアの代わりに **ロングキャリア** (*anna*) を使用する

## ベレリアンドのモード: フルモード

 ベレリアンドのモードでは、母音は **完全な文字** (発音区別符号ではありません) です。 これによりテキストは読みやすくなりますが、追加の文字の割り当てを学習する必要があります。 

### ベレリアンドモードの特別ルール

 1. **母音**は特定の *tengwar* を完全な文字として使用します。 
- *a* → アンナ (特定のテンワ)
 - *e* → ヤンタ (バリアント)
 - *i* → 別の形式
 - *o* → *ore* バリアント
 - *u* → *úre*

 2. このモードでは、文字 *óre* は *n* を表し、*vala* は *m* を表します (標準モードとは異なります)。 

3. **鼻音化された子音** (nd、mb、ng) は、基本文字 + 上のバーで書かれます。 

4. **二重母音** *ae* と *oe* は、2 つの別々のテンワールとして書かれることがあります。 

### ドゥリンの扉の碑文

 ベレリアンドのモードの最も有名な例。 碑文には次のように書かれています。```
Ennyn Durin Aran Moria: pedo mellon a minno.
Im Narvi hain echant: Celebrimbor o Eregion teithan i thiw hin.
```翻訳: 「モリアの領主、ドゥリンの扉。友達よ、話して、入ってください。
 私、ナルヴィが作りました。 エレギオンのセレブリンボールがこれらの看板を描きました。」

 これは、トールキンがベレリアンド テングワール旋法で書かれたシンダール語の最も完全な例です。

 ## 初心者にありがちな間違い

 1. **Quenya 母音の配置を使用する** — *後続* の子音ではなく、*前方* の子音の上に tehtar を配置します。 
2. **間違ったモードの使用** — 標準モードとベレリアンドのモードでは文字の割り当てが異なります。 
3. 単語最後の母音の **サイレントキャリアを忘れる**
 4. ***anto* と *ampa*** に Quenya 割り当てを使用する — シンダール語標準モードでは、これらは Quenya の音ではなく、それぞれ *dh* と *v* を表します。
