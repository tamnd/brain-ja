シンダール語の前置詞は、後続の名詞の特定の子音変異を制御します。 どの前置詞がどの突然変異を引き起こすかを知ることは、文法的に正しいシンダール語を構成するために不可欠です。 

## ソフトミューテーションを引き起こす前置詞 (Lenition)

 | 前置詞 | 意味 | 例 |
 |-----------|-----------|----------|
 | *アブ* | 後 | *ab vaur* (素晴らしいものの後に) — *baur* → *vaur* |
 | *アデル* | 後ろ | *adel dhûn* (西の後ろ) — *dûn* → *dhûn* |
 | *午前* | 上、上 | *am vereth* (宴会まで) — *mereth* → *vereth* |
 | *お父さん* | ダウン | *お父さんダラス* (平地まで) |
 | *ディ* | 下、下 | *di vunn* (ピークの下) — *munn* → *vunn* |
 | *な* | に、向かって | *na valinor* (ヴァリノールに向かって) |
 | *ネッド* | で、その間 | *ネッド・ゴバンナス* (フェローシップ内) |
 | *ヌ* | |の下で *nu 'aladh* (木の下) — *galadh* → *'aladh* |
 | *トリ* | |を通して *trî 'ondram* (石を通して) |
 | *ú-* (接頭辞) | なし、なし | *ú-veleg* (良くない) — *beleg* → *veleg* |

 ## 鼻音変異を引き起こす前置詞

 | 前置詞 | 意味 | 例 |
 |-----------|-----------|----------|
 | *an* | に、のために、目的 | *an bengolodh* (教師へ/教師へ) — *pengolodh* → *bengolodh* |
 | *in* (定冠詞複数) | (pl.) | *i Nedain* (the Men) — *Edain* → *Nedain* |

 *An* はシンダール語で最も重要な前置詞です。**間接目的語** (与格) を示します。 
- *Annon 'ylf an benn* — 「私は男性にゴブレットをあげます」 (*ylf* 直接の目的語。*an* の後に *benn*)
 - *An* + 鼻の突然変異 = 与格構文

 ## 明確な前置詞 (前置詞 + 冠詞の融合)

 前置詞が名詞の前に冠詞 *i* (the) を付けると、前置詞と冠詞が融合することがよくあります。 

| 前置詞 | + 記事 | 明確な形式 | 突然変異が誘発されました |
 |-----------|-----------|---------------|--------|
 | *o* (から) | + *i* | *オン* または *オン* | 混合 |
 | *な* (へ) | + *i* | *なん* (?) | 混合 |
 | *trî* (スルー) | + *i* | *トレン* | 混合 |
 | *午前* (そのとき) | + *i* | *あみん* (?) | 混合 |

 確定前置詞 (融合前置詞 + 冠詞) は、後続の単数名詞に **混合突然変異** を引き起こします。 複数の名詞の前では形が異なり、鼻音の突然変異を引き起こす可能性があります。 

## 突然変異のない一般的な前置詞 (または母音頭文字の単語)

 母音で始まる名詞の前では、ほとんどの突然変異は目に見えません (突然変異は母音にあり、母音は突然変異しません)。 前置詞はそのまま使用されます。 

- *o Edhil* (エルフから) — 変化させる子音はありません
 - *an Edain* (男性向け/男性向け) — 母音の前に *an*。 目に見えない鼻の突然変異

 ## 与格構文の詳細

 与格 (間接目的語 = 「誰かに」) は前置詞 *an* + 鼻音の突然変異を使用します。 

*アンノン・ア・フェンゴロッド・デギル*
 - *annon* = 私は（*ann-* の第 1 節）を差し上げます
 - *an* = to/for (与格前置詞)
 - *phengolodh* = *pengolodh* (教師) *an* 鼻の突然変異後: p→b → でも *ph* と書かれていますか? —これには異論がある。 一部の分析では *bengolodh* が得られます
 - ソフト突然変異後の直接オブジェクトとしての *degil* = *tegil* (ペン): t→d

 全文:「私は先生にペンをあげます。」

 ## 属格: *en* 助詞

 属格 (「of」) は、混合突然変異をトリガーする助詞 **en** (場合によっては単に **e**) を使用します。

- *カラス ガラドン アン ガラドリム* — 「ガラドリムの樹木の都市」
 - *アンノン アン ゴンドール* — 「ゴンドールの門」
 - *ミナス・エン・ティテン・エライン* — 「小さな王の塔」

 固有名詞では、属格助詞が省略されることがよくあります (代わりに複合体が形成されます)。 
- *Barad-dûr* (タワーダーク = 闇の塔)
 - *ミナス・ティリス* (監視の塔)
 - *オスギリアス* (星の城塞)
