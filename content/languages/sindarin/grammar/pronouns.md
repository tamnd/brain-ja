シンダール語の代名詞は部分的に証明され、部分的に再構築されています。 主語代名詞は独立した単語ではなく動詞の接尾辞として現れることが多く、目的語と所有代名詞はより適切に文書化されます。 

## 主語代名詞

 シンダール語の主語代名詞は次のように表現できます。 
1. **動詞接尾辞** (最も一般的)
 2. **独立した代名詞** (強調または明確にするため)

 ### 動詞接尾辞 (主語)

 | 人物 | サフィックス | 例 | 翻訳 |
 |----------|----------|----------|-------------|
 | 1番目のsg。 (I) | *-n、-on* | *トロン* | 来ます |
 | 2nd sg. ファム。 (あなた) | *-g、-og* | *トログ* | あなた（おなじみ）来てください |
 | 2nd sg. ポール。 (あなた) | *-odh* | *トロッド* | あなたは（礼儀正しく）来てください |
 | 3番目のsg。 (彼/彼女/それ) | (なし - 裸の茎) | *トール* | 彼/彼女は来ます |
 | 1番目のpl。 (私たち) | *-m、-om* | *トロム* | 来ます |
 | 2番目のpl。 (あなたはお願いします) | *-dh* | *トロッド* | あなた (複数) 来てください |
 | 3番目のpl。 (彼ら) | *-r、-ir* | *トリル* | 彼らは来る |

 注: 二人称には、**親しみやすい** (*-g*: 親しい友人、家族、対等な者に呼びかける) と **丁寧** (*-dh*: 形式的、敬意を表する) との区別があります。 これはフランス語の *tu/vous* やドイツ語の *du/Sie* に似ています。 

### 独立した主語代名詞

 | 人物 | 代名詞 | メモ |
 |----------|-----------|----------|
 | 1番目のsg。 | *私* | 「私」（強調）。 クエンヤ *ニ*関連 |
 | 2nd sg. ファム。 | *ル* (?) | 論争があった。 *le* はオブジェクトとして証明されています |
 | 3番目のsg。 マスク。 | *e* または *ho* | 「彼」 |
 | 3番目のsg。 フェム。 | *彼* または *彼* | 「彼女」 |
 | 1番目のpl。 | *メン* または *アンメン* | 「私たち/私たち」 |
 | 2番目のpl。 | *le* (pl.) | 論争中 |
 | 3番目のpl。 | *ハイン* | 「彼ら」（証明済み） |

 独立した主語代名詞の証明は制限されています。 *Im* が最もよく証明されています (「I」が強調表示されています)。

 ## オブジェクト代名詞

 目的語の代名詞はよりよく証明されます。 これらは動詞の後に独立した単語として現れます。 

| 人物 | オブジェクト代名詞 | 例 | 翻訳 |
 |----------|------|----------|---------------|
 | 1番目のsg。 (私) | *ニン* | *アンノンニン* | 私があげる？ (=*an nin* かもしれません) |
 | 2nd sg. (あなた/あなた) | *ル* | *ル・リンナソン* | 私はあなたに歌います |
 | 3番目のsg。 マスク。 (彼) | *e* | — | |
 | 3番目のsg。 フェム。 (彼女) | *彼* | — | |
 | 1番目のpl。 (私たち) | *メン*、*アンメン* | *ボーアンメン* | それは私たちにとって必要です |
 | 3番目のpl。 (彼ら) | *ハイン* | — | |

 **証明された主な例**: *le linnathon* — 「私はあなたに歌います」 (*A Elbereth Gilthoniel* より)
 - *le* = あなた/あなた (二人称単数、目的語)
 - *linnathon* = 私は歌います (*lin-* + 未来 *-tha-* + 1 番目の詩 *-n*)

 ## 所有代名詞

 所有格は名詞の**接尾辞**として形成されます。 

| 人物 | サフィックス | 例 | 翻訳 |
 |----------|----------|----------|-------------|
 | 1番目のsg。 (私) | *-n* (母音の後)、*-in* (子音の後) | *イオンニン* | 私の息子 (*イオン* + *-in*) |
 | 2nd sg. ファム。 (あなた) | *-g* | *イオンノグ* (?) あなたの息子 |
 | 2nd sg. ポール。 (あなたの) | *-dh* | — | |
 | 3番目のsg。 (彼/彼女) | *-e、-o* | — | |
 | 1番目のpl。 (私たち) | *-m* | *イオンノム* (?) | 私たちの息子 |
 | 3番目のpl。 (彼ら) | *-in* | — | |

 注: これらのフォームは限られた証拠に基づいて再構成されたものです。 所有格システムは、シンダール語文法の中で最も不確実性の高い部分の 1 つです。 

**証明済み**: *Ionnath nín* — 「私の息子たち」または「私の息子たち」 — *nín* は、名詞に続く別の所有代名詞 (my、mine) です。 このパターン (名詞 + 独立所有格) は、接尾辞パターンよりも一般的である可能性があります。 

### 独立した所有代名詞

 | 人物 | 所有欲 | メモ |
 |----------|-----------|----------|
 | 1番目のsg。 | *ニン* | 「私の、私の」 — *Ionnath nín* で証明されています。 
| 2nd sg. | *林* | 「あなたの、あなたの」（おなじみ） |
 | 3番目のsg。 | *ティン* | 「彼/彼女、彼らのもの」 |
 | 1番目のpl。 | *分* | 「私たちの、私たちの」 |

 これらは名詞の後に続きます: *galadh nín* (私の木)、*galadh lín* (あなたの木)。

 ## 関係代名詞

シンダール語では *i* を関係代名詞として使用します (定冠詞と同じ - 文脈によって区別されます)。 
- *i chennas* — 「住んでいる人」または「住んでいる人」
 - *i·pheriain i aníra iest lín* — 「あなたの願いを望むホビットたち」 (複雑な関係節)

 ## 代名詞を使った例文

 | シンダール語 | 翻訳 | メモ |
 |----------|---------------|----------|
 | *ル・アブドレン* | あなたは遅刻しています | *le* (あなた、2 軍曹) + *abdollen* (過去分詞「遅れた」) |
 | *ル・リンナソン・ネフ・アイヤー* | 海のこちら側であなたに歌います | *le* = オブジェクト「あなたへ」; *リンナソン* = 私は歌います |
 | *ボエアンメンティルノ* | 私たちは守らなければなりません | *アンメン* = 私たちに; 非人間的な *boe* |
 | *ナルヴィはとても魅力的です* | 私、ナルヴィが作りました | *im* = I (強調); *ハイン* = 彼ら |
 | *イオナト ニン* | 私の息子たち | *nín* = my (所有格が名詞に続きます) |

 *Im Narvi hain echant* というフレーズがドゥリンの扉に刻まれています。これは、トールキンのシンダール語のテキストで完全に証明されている、強調代名詞を伴う唯一の一人称です。
