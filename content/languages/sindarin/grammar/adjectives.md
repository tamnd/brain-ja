シンダール語の形容詞には、英語とは異なる 3 つの重要な特性があります。 

1. 修飾する名詞の**後**に来ます(前ではありません)。 
2. 名詞の後に **ソフト突然変異** (寛解) を受けます。 
3. 彼らは**複数形**を持っています（i-affectionを介して複数の名詞に同意します）

 ## 位置: 名詞の後の形容詞

 | 英語 | シンダール語 | メモ |
 |----------|----------|----------|
 | 偉大な男 | *アダン ベレグ* | *beleg* (素晴らしい) → 名詞の後に *veleg* |
 | 緑の葉 | 写真 緑の葉 *ラス・ガレン* | *calen* (緑) → *galen* |
 | 白い塔 | 写真 白い塔 *ミンドン・ティレン* | *thîren* (白/明るい) が続きます |
 | 美しいエルフ | 写真 美しいエルフ *エーデル・ヴェイン* | *bain* (美しい) → *vain* |

 ## Lenition: 形容詞のソフト突然変異

 形容詞が名詞の後に続く場合、その最初の子音に**ソフト突然変異**が発生します。 

| 形容詞 | 基本フォーム | 名詞の後 (寛解語) |
 |-----------|-----------|-----------|
 | *ベレグ* (素晴らしい) | ベレグ | **v**エレグ |
 | *ベイン* (美しい) | ベイン | **v**ain |
 | *calen* (緑) | カレン | **アレン |
 | *dûr* (暗い) | その間 | **dh**ûr |
 | *ゴーン* (石; 形容詞「石のような」という意味) | ゴーン | **(∅)**orn (g が消える) |
 | *前* (熟練) | 前 | **v**aen |
 | *朝* (ダーク、ブラック) | 朝 | **v**オーン |
 | *パラン* (遠くまで) | パラン | **バ**アラン |
 | *sîr* (流れる; 形容詞) | 先生 | **h**îr |
 | *tîr* (見てる) | ティア | **d**îr |

 ### 形容詞が省略される理由

 歴史的な理由: 古シンダール語の名詞は通常、母音で終わります。 これらの名詞終母音に続く形容詞は「母音間」の位置にあり、突然変異で見られる子音の弱化（緩和）を引き起こしました。 名詞の最後の母音が失われると、その変異は文法マーカーとして残りました。

 ## 形容詞の複数形

 名詞が複数形の場合、形容詞も複数形でなければなりません。 複数形容詞は、名詞と同じ i 愛情母音変化によって形成されます。 

| 調整 (単数形) | 調整 (複数形) | 母音の変化 |
 |--------------|--------------|--------------|
 | *ベレグ* (素晴らしい) | *ベリグ* | e→i |
 | *ベイン* (美しい) | *bein* | あい→えい |
 | *calen* (緑) | *セリン* | a→e、e→i |
 | *朝* (暗い) | *ミルン* | o→y |
 | *dûr* (暗い) | *デュイル* | 長い û→ui |
 | *前* (熟練) | *ミン* | あ→う |

 ### 複数形容詞の例

 | 名詞句 (単数) | 名詞句 (複数) | 翻訳 |
 |--------------------------|-----------|---------------|
 | *アダン ベレグ* | *エデイン・ヴェリグ* | 偉人 / 偉人 |
 | *エーデル・ヴェイン* | *エドヒル静脈* | 美しいエルフ / 美しいエルフ |
 | *アモン・ガレン* | *エミン・ゲリン* | 緑の丘 / 緑の丘 |

 完全な名詞句では、名詞は複数形 (i-affection 付き) で、形容詞も複数形であり、形容詞は依然として寛容です。

 ## 述語形容詞: 「To Be」

 シンダール語は、単純なステートメントで目に見える動詞なしで「X は Y」(コピュラ文) を表現します。 

- *ベレグ アラン* — 「王は偉大です」 (直訳:「王は偉大だ」)
 - *Bain i edhel* — 「エルフは美しい」

 過去と未来のコピュラには、動詞 *na-* または *nar-* (「である」) が使用されます。 

- *ナウン・ベレギ* — 「私は素晴らしかった」 (再構成)
 - *ナルサ・ベレグ* — 「彼はきっと素晴らしいでしょう」

 これは活発な再構築が行われている分野であり、その形式は学者によって異なります。

 ## 比較級と最上級

 シンダール語には、十分に証明された比較/最上級システムがありません。 ネオシンダール語では次のものが使用されます。 

- **比較級** (「more X」): 前置詞 *na* または *och* + 形容詞、または複合形
 - *beleg nach* (より大きい) — 投機的
 - 構文を使用する場合があります: *[adj] na [名詞]* (X は名詞と比較して/名詞よりも形容詞です)

 - **最上級** (「最も X」): 接頭辞 *er-* または *ar-* (最も、最高)
 - *arveleg* = 最も偉大な (推測的な新シンダール語)

 ## 副詞

 シンダール語の副詞は次のように形成されます。 
1. 変化のない形容詞から（副詞の位置で述語的に使用されます）
 2. 否定の接頭辞 *al-* (not) を付ける: *alveleg* (良くない)
 3. いくつかの独立した副詞: *sí* (今、ここ)、*palan* (遠くて広い)、*nef* (こちら側)、*ab* (後)

 副詞は通常、修飾する動詞の後に続きます。 
- *Tôl Aragorn vorn* — 「アラゴルンは暗く/密かにやってくる」 — *vorn* (暗い) 副詞として (動詞に続くので寛容 — 議論あり)
