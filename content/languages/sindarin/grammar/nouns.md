シンダール語には文法的な性別も名詞の格もありません（ラテン語やドイツ語とは異なります）。 文法関係は語順、変異、前置詞によって表現されます。 シンダール語の名詞の最も顕著な特徴は、**母音変化による複数形成**、つまり i-affection と呼ばれるシステムです。 

## I-affection: 複数形の仕組み

 シンダール語の複数形は、接尾辞を追加するのではなく、単語内の母音を変更することによって形成されます。 これは歴史的に、最後の *-i* (現在は失われています) によって、前の母音が *i* に「シフト」したために起こりました。 

### 母音変更ルール

 | 単数母音 | 複数母音 | メモ |
 |-||--------------|------|
 | **a** | **e** | *adan* → *ed*ain (a→e、2番目のa→ai) |
 | **a** (最後の音節) | **愛** | *ガラド* → *ゲライド* |
 | **e** | **私** | *エドヘル* → *エドヒル* |
 | **o** | **はい** | *orch* → *yrch*、*amon* → *emyn* |
 | **う** | **はい** | *トゥルス* → *ティリス* |
 | **au** | **おえ** | *aur* → *oeir* (日/日) |
 | 長母音: **â、ê、î、ô** | 短い等価物 + 変更 | |

 ### 私への愛情の例

 | 単数 | 複数 | 意味 |
 |----------|----------|----------|
 | *アダン* | *エダイン* | 男性 / 男性 |
 | *エドヘル* | *エドヒル* | エルフ / エルフ |
 | *オーク* | *年* | オーク / オーク |
 | *アモン* | *エミン* | 丘/丘 |
 | *ガラド* | *ジェライ* | 木/木 |
 | *カラス* | *セライス* | 環濠都市 / 都市 |
 | *ベン* | *ビン* | 男性（夫） |
 | *トログ* | *テリグ* | トロル/トロル |
 | *ノゴス* | *ノギス* | ドワーフ/ドワーフ |
 | *フェリアン* | *フェリアン* | ハーフリング / ハーフリング |
 | *ドゥン* | *ドゥイン* | West / Wests (川の名前に使用) |
 | *ティリス* | *ティリス* | watch (変更なし - 一部の単語は変更されません) |

 ### 複数形変化が見えない単語

 単語によっては、単数形と複数形が同じ形になるものもあります（まれです）。 コンテキストによって数値が決まります。 

### *-ath* を使用したクラス複数形

 シンダール語には、「～のグループ全体」を意味する集合複数形の接尾辞 *-ath* が付いています。 
- *elenath* = すべての星 (集合; *el* + *-ath* から)
 - *periannath* = すべてのハーフリング (*pherian* + *-ath*、突然変異あり)
 - *ゴンダス* = すべての石

 これは、通常の複数形（グループの特定のメンバー）と集合体（全体として考えられる種族/種/グループ全体）とは異なります。 

### *-rim* および *-gwaith* を使用したクラス複数形

 - *-rim* = 民族、民族 (集合体): *ガラドリム* (木の民 = ロスローリエンのエルフ)、*ロヒリム*
 - *-gwaith* = 人々 (ホスト): *Gwaith-i-Mírdain* (宝石鍛冶屋の人々)

 ## 明確な記事

 シンダール語には定冠詞 (*the*) が 1 つありますが、不定冠詞 (*a/an*) はありません。 

| コンテキスト | フォーム | 注 |
 |-------|------|------|
 | 子音の前 (単数) | **私** | 次の名詞でソフトミューテーションをトリガーします |
 | 母音の前 (単数) | **私** | 突然変異はありません。 母音は単に | に続きます。 
| 子音の前 (複数) | **in** または **i** | 鼻の突然変異を引き起こす |
 | 母音の前 (複数) | **私** | 突然変異なし |

 ### 記事 + 突然変異の例

 | ベース | 記事付き | ルール |
 |------|---------------|------|
 | *ガラド* (木) | *私はアラド* | ソフトミュート: g が消える |
 | *ペリアン* (ホビット) | *私ベリアン* | ソフトミュート: p→b |
 | *アダン* (男性) | *私はダン* | 母音の頭文字: 突然変異なし |
 | *エダイン* (男性) | *i ネダイン* または *i edain* | 複数; 鼻のムット。 または母音の前に変化がない |
 | *yrch* (オーク) | *私は* | ソフトマット。 クリスマスに？ それとも鼻？ — 論争中 |

 複数冠詞の正確な形式とその変異は、新シンダール語で最も議論の分かれている点の 1 つです。

 ## 文法上の性別はありません

 フランス語、スペイン語、ドイツ語とは異なり、シンダール語の名詞には男性/女性/中性の文法上の性別がありません。 名詞 *edhel* (エルフ) は、エルフの性別に関係なく同じように機能します。 性差のある単語は存在しますが、別の語彙項目です。 
- *ベン* (男性、夫) vs. *ベス* (女性、妻)
 - *hir* (領主、男性) vs. *hiril* (女性、女性)
 - *アラン* (王) 対 *ベレス* (女王)

 ## 属格: 「の」構造

 所有と「の」関係には助詞 **en** (*e* とも) が使用され、これにより次の名詞の混合突然変異が引き起こされます。

- *galadh en Lothlórien* — 「ロスローリアンの木」
 - *Aran en Gondor* — 「ゴンドールの王」 (ただし、通常は *Aran Gondor* 名に助詞が含まれません)

 名前では、属格が暗黙的に含まれることがよくあります (助詞はありません)。 
- *Barad-dûr* = "Tower (of) Dark" — *dûr* は *dorn* からソフト突然変異を受けますか? いいえ、*dûr* はここでは形容詞「暗い」です。 化合物として使用される
 - *Imladris* = "Deep-cleft Dell" — 粒子のない化合物

 助詞 *en* は、名前よりもフレーズでよく使用されます。

 ## 直接オブジェクト

 直接目的語は動詞の後に**ソフト突然変異**を受けます。 語順だけがあいまいな場合に、文法的にオブジェクトを識別する方法は次のとおりです。 

- *Cenin galadh* — 「木が見えます」 — *galadh* は直接目的語です
 - ガラドが特別に突然変異した場合: *Cenin 'aladh*

 実際には、直接目的語の突然変異は、ネオシンダーリン語で最も議論されている点の 1 つです。 一部のテキストでは一貫してそれが示されています。 他の人は基本形式を使用します。 RealElvish Academy (Jallings) がそれを適用します。 他の学者はそれほど厳格ではありません。

 ## 主格的用法と絶対的用法

 シンダール語には大文字と小文字の接尾辞がありません。 「主語」の場合と「目的語」の場合は形式が同一であり、文中では語順と突然変異のみが区別されます。 

件名: 動詞の前に来るか、動詞の一致によってマークされます
 目的語: 動詞の後に来ます。 ソフト突然変異を起こす可能性がある
