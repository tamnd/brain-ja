子音の突然変異は、シンダール語文法の特徴です。 辞書形式とは異なる子音で始まる単語に遭遇した場合、それは突然変異です。 それは間違いではなく、文法です。 

トールキンは、「シンダール語の緩和語または『変異』は、音声の起源と文法的用法がウェールズ語のそれに似るように意図的に考案されたが、音声の起源も文法的用法も同じではない。」と書いている。 

## 突然変異が存在する理由

 古シンダール語では、ほとんどの単語は母音で終わりました（クエンヤなど）。 これらの母音が時間の経過とともに失われると、それに続く子音は周囲の母音によってすでに「弱められ」ており、その弱まりは文法上の特徴として保存されていました。 単語のソフトな突然変異は、本質的には、かつてその単語に先行していた失われた母音の化石化したエコーです。 

これは、ウェールズ語に突然変異がある理由とまったく同じです - トールキンが意図的に組み込んだ並行進化です。 

## 5 つの突然変異タイプ

 | 突然変異 | 周波数 | プライマリトリガー |
 |----------|-----------|------|
 | **ソフト (レニション)** | 非常に一般的な | 名詞の後の形容詞、直接目的語、多くの前置詞、冠詞 *i* |
 | **鼻** | 共通 | 複数冠詞 *in*、前置詞 *an* (to/for) |
 | **混合** | 中程度 | 定前置詞 + 単数名詞 |
 | **停止** | 珍しい/論争中 | *d* または *t* に続く |
 | **液体** | 理論的 | *l* または *r* に続く |

 ---

 ## ソフトミューテーション (レニション)

 最も重要な突然変異。 1つだけを学ぶ場合は、これを学習してください。 

歴史的に、ソフト突然変異は母音の間にある子音から生じました。 無声停止が有声になりました。 有声停止がスピラントになりました。 

### ソフトミューテーションテーブル

 | 頭の子音 | ソフトミューテーション後 | IPA変更 | メモ |
 |---------------------|---------------------|---------------|----------|
 | **p** | **b** | [p] → [b] | 無声→有声 |
 | **t** | **d** | [t] → [d] | 無声→有声 |
 | **c** | **g** | [k] → [g] | 無声→有声 |
 | **b** | **v** | [b] → [v] | 有声停止 → 有声スピラント |
 | **d** | **dh** | [d] → [ð] | 有声停止 → 有声スピラント |
 | **g** | **(消える)** | [g] → ∅ | 完全に削除されました |
 | **m** | **v** | [m] → [v] | 鼻音 → 有声音 |
 | **h** | **ち** | [h] → [x] | 軟膏摩擦音まで柔らかくなる |
 | **s** | **h** | [s] → [h] | スピラントが弱まる |
 | **lh** | **l** | [ɬ] → [l] | 無声→有声 |
 | **rh** | **r** | [r̥] → [r] | 無声→有声 |

 ソフト突然変異下で**突然変異しない**文字: **n、l、r、f、v、dh、th** (すでに「ソフト」)

 ### 実際の例: ソフトミューテーション

 | 基本フォーム | ソフト突然変異 | コンテキスト | 翻訳 |
 |----------|---------------|---------------|---------------|
 | *ガラド* (木) | *'アラド* | *私はアラド* | 木 (記事の後に g が消えます) |
 | *ペリアン* (ホビット) | *ベリアン* | *私ベリアン* | ホビット |
 | *カラン* (日) | *ガラン* | *私はガラン* | その日 |
 | *ベレグ* (素晴らしい) | *ベレグ* | *ガラド ベレグ* | 大きな木 (名詞の後ろに形容詞) |
 | *ドゥン* (西) | *ドゥーン* | *私は* | 西 |
 | *ティリス* (時計) | *ディリス* | *セニン・ディリス* | 私は見ます (私は見ています-ウォッチミュート) |
 | *ミンドン* (タワー) | *ヴィンドン* | *私はビンドン* | 塔 (m→v) |
 | *スル* (風) | *フル* | *私は* | 風 (s→h) |
 | *ホルン* (追跡) | *ホーン* | (h ワード: 若干の論争) | |

 ### ソフトミューテーションのトリガー

 **1. 名詞の後の形容詞** (最も頻繁):
 - *adan* (男性) + *beleg* (偉大な) = *adan veleg* (偉大な男) — *beleg* → *veleg*

 **2. 動詞の後の直接目的語**:
 - *cenin galadh* (木が見えます) — 直接オブジェクト *galadh* は寛大な扱いを受けます: *cenin 'aladh*
 - 実際には、これについては議論があります。 多くのテキストは基本形式を示しています

 **3. 定冠詞 *i*** (単数) の後:
 - *i 'aladh* (木)、*i berian* (ホビット)、*i galan* (日)

 **4. 前置詞の後**: ab、adel、am、dad、di、nu、trî、ú-
 - *ab galadh* → *ab 'aladh* (木の後に)
 - *ú-beleg* (あまり良くありません) — 接頭辞 ú- は寛大な扱いを引き起こします

 **5. *na*** (である / になる) の後:
 - *na veleg* (素晴らしいこと)

 **6. 所有格と特定の助詞の後**

 ## 鼻の突然変異

先行する *-n* が原因です。 その結果はアイルランドの日食に似ています。 

### 鼻の変異テーブル

 | 頭の子音 | 鼻の突然変異後 | メモ |
 |----|----------------------|------|
 | **p** | **b** (または **ph**) | 論争があった。 b は新シンダール語では一般的です。 
| **t** | **d** | |
 | **c** | **g** | |
 | **b** | **m** | |
 | **d** | **ん** | |
 | **g** | **NG** [ŋg] | |
 | **m** | **m** | 変更なし |
 | **s** | **h** | |
 | **f** | **f** (変更なし) | |

 母音頭の単語: *in* または *an* の前に *n* が表示され、後続の単語ではなく、前の単語に突然変異が表示されます: *in + edain* = *i Nedain* (ただし、これについては議論があります)。 

### 鼻の突然変異のトリガー

 **1. 複数定冠詞 *in*** (子音の前):
 - *edain* (men, pl.) → *i Nedain* (the Men) — 冠詞 *in* は後続の名詞の鼻音変異を引き起こします

 **2. 前置詞 *an*** (目的、目的、目的):
 - *an pengolodh degil* (教師にペン) — *tengolodh* の *pengolodh*; *テギル*からの*デギル*
 - *t* → *d* (鼻の突然変異); *p* → 鼻... = *an bengolodh* (実際: p→b 鼻の下 = *an bengolodh*)

 ### 実際の例: 鼻の突然変異

 *アンノン・ア・フェンゴロッド・デギル* — 「私は先生にペンをあげます」
 - *pengolodh* (教師): *an* 後 → 鼻の突然変異: p→b = *bengolodh*
 - *テギル* (ペン): 直接オブジェクト → ソフト突然変異: t→d = *デギル*
 - フル: *アンノン・アン・ベンゴロッド・デギル*

 ## 混合突然変異

 単数名詞との明確な前置詞（前置詞と冠詞が融合したもの）の後に発生します。 結果は、鼻の突然変異とソフトの突然変異を組み合わせたようなものです。 

### 混合突然変異テーブル

 | 頭の子音 | 混合突然変異後 |
 |---------------------|---------------------|
 | **p** | **b** |
 | **t** | **d** |
 | **c** | **g** |
 | **b** | **m** |
 | **d** | **ん** |
 | **g** | **NG** |
 | **m** | **m** |
 | **s** | **h** |
 | **f** | **v** |
 | **lh** | **l** |
 | **rh** | **r** |

 ### 混合突然変異のトリガー

 単数名詞の前の前置詞の明確なバージョン (前置詞 + *i* = "the"):
 - *o* (from) + *i* = *o'n* または類似 → 後続の名詞の混合突然変異
 - *tren* (スルー) = *trî* + *i* → 混合突然変異

 例: *o'n dûn* (西から) — 混合突然変異後の *dûn* は *dûn* のままです (混合変異と鼻変異では d は変わりません...これは分析によって異なります)

 ## 突然変異を停止する

 先行する *d* または *t* の後に (接頭辞または前置詞として) 発生します。 あまり証明されておらず、多少の議論もあります。 

### 突然変異テーブルの停止

 | 頭の子音 | 停止突然変異後 |
 |---------------------|---------------------|
 | **p** | **b** |
 | **t** | **d** |
 | **c** | **g** |
 | **b** | **b** → **mb** (プレフィックス表示) |
 | **d** | **d** → **nd** |
 | **g** | **g** → **ng** |
 | **m** | **m**のまま |

 デビッド・サロは停止突然変異を 5 つのうちの 1 つとして扱います。 トールキンからの限定的な証明しかありません。 

---

 ## リキッドミューテーション

 理論的には、先行する *l* または *r* によって引き起こされます。 証明された最も弱い突然変異 — 存在する可能性もあれば、存在しない可能性もあります。 ほとんどの新シンダール語作家は、それが非常にまれに現れるため、構成においてそれを無視します。 

存在する場合:
 - **p** → **b**; **t** → **d**; **c** → **g** (ソフト突然変異と同様)

 ## よくある間違い

 1. **ソフト突然変異では *g* が消えることを忘れる** — *i galadh* は間違っています。 *i 'aladh* (アポストロフィは削除されています g) である必要があります。 

2. **b** の紛らわしいソフト変異と鼻変異 — *b* = **v** のソフト変異。 *b* = **m** の鼻の突然変異。 これらは違います! *i veleg* (偉大な人、名詞として使用される形容詞 — b→v ソフト) vs. *in Mellyn* (友達、*Bellyn* の鼻音? — b→m 鼻音)

3. **すべてに突然変異を適用する** — 突然変異は特定の文法コンテキストによって引き起こされます。 他の単語の近くにあるすべての単語が突然変異するわけではありません

 4. **子音頭文字と母音頭文字を忘れる** — 突然変異は *子音*頭文字の単語にのみ影響します。 母音で始まる単語は変化しません（ただし、その前の助詞は形を変える可能性があります）

 ## 練習する

 [Sindarin Crash Course 変異ツール](https://sindarincrashcourse.neocities.org) を使用して作業します。任意の単語を入力すると、適用された 5 つの変異すべてを確認できます。 

ミューテーションを練習するための重要な動詞:
 - *cenin* (なるほど) — 直接オブジェクトをテストする
 - *annon* (私が与える) — *an* (与格) でテストします
 - *i* (the) — 記事を使用してすべての突然変異タイプをテストします

 寛容を実践するための重要な形容詞:
 - *beleg* (素晴らしい) → 名詞の後の *veleg*
 - *bain* (美しい) → 名詞の後に *vain*
 - *calen* (緑) → 名詞の後に *galen*
 - *gorn* (石) → 名詞の後に *'orn*
