## 基本語順: VSO

 シンダール語は **動詞-主語-目的語** です。通常、動詞が最初に来て、次に主語、次に目的語になります。 これは古典アラビア語、ウェールズ語、アイルランド語と同じです。 

| ポジション | 要素 | 例 |
 |----------|-----------|----------|
 | 1 | 動詞 | *セニン* (なるほど) |
 | 2 | 件名 (動詞の接尾語に暗黙的に含まれます) | — (件名は *-n* 接尾辞でエンコードされています) |
 | 3 | オブジェクト | *ガラド* / *'アラド* (木) |

 全文: *Cenin 'aladh* — 「木が見えます」

 主語が名前付き名詞 (代名詞接尾辞だけでなく) の場合、動詞の後に続きます。 

*トル・アラゴルン* — 「アラゴルンが来る」 (動詞-主語)
 *Cenin Aragorn i 'aladh* — 「アラゴルンは木を見る」 (動詞-主語-目的語)

 ---

 ## 簡単な文

 ### 主語 + 述語 形容詞 (コピュラ)

 シンダール語では、単純なステートメントでは「to be」動詞が省略されることがよくあります。 

| シンダール語 | リテラル | 英語 |
 |----------|----------|----------|
 | *ベレグ アラン* | 偉大な王 | 王様は偉大です |
 | *ベイン・イ・エーデル* | 美しいエルフ | 写真 美しいエルフ エルフは美しい |
 | *待ってください* | 熟練した人々 | 人々は熟練しています |

 ### 主語 + 動詞

 | シンダール語 | 英語 |
 |----------|----------|
 | *トール・アラゴルン* | アラゴルンが来る |
 | *セニール・レゴラス* | レゴラスは見る |
 | *ペド・ガラドリエル* | ガラドリエルは話す |

 ### 主語 + 動詞 + 目的語

 オブジェクトはソフトミューテーションを受けます:

 | シンダール語 | 英語 | 注 |
 |-------|-------|------|
 | *チェニン・アラド* | 木が見えます | 写真 木が見えます *galadh* → *'aladh* (直接オブジェクトを許可) |
 | *アノン・イルフ・アン・ベン* | 私は男性にゴブレットを与えます | 写真 私は男性にゴブレットを与えます *ylf* = ゴブレット (オブジェクト); *アン ベン* = 与格 |
 | *ペド・アラゴルンは死んだ* | アラゴルンは結末を語る | *methed* → *vethed* (直接オブジェクトを許可) |

 ## 質問

 シンダール語の質問は、イントネーション (上昇音調) または最初に疑問詞を付けて形成されます。 語順は同じままでも構いません。 

| タイプ | シンダール語 | 英語 |
 |------|--------|----------|
 | はい/いいえ | *トール・アラゴルン?* | アラゴルンも来るのか？ |
 | 誰 | *マン・セニール?* | 誰が見ますか？ |
 | 何を | *マ・センニッチ?* | 何を見たのですか？ |
 | どこ | *ミーヴァン?* | どこ？ |
 | いつ | *ナミンイル?* | いつ？ |
 | なぜ | *アンマン?* | どういう理由でしょうか？ (なぜ) |

 *man* (誰) と *ma* (何を) は、通常、文の先頭に置かれる疑問詞です。

 ## 否定

 シンダール語の否定は以下を使用します。 

1. 動詞または形容詞の **接頭辞 *ú-*** (なし、ない):
 - *ウーセニン* (わかりません)
 - *ú-veleg* (良くない)

 2. **否定助詞 *al-、avo-、na-*** (さまざま; 議論あり):
 - *avo garo!* — 「やめてください!」 (必須否定)

 3. **Úgarnen** — 「うまくいきませんでした」 (*ú-* + 過去の動詞)

 接頭辞 *ú-* は、次の子音で **ソフト ミューテーション**をトリガーします。 
- *ú-* + *beleg* = *ú-veleg* (あまり良くありません)
 - *ú-* + *gar-* (ある) = *ú-'ar-* (ない) — *ú-* 後のソフト突然変異により *g* が消える

 ## 接続詞

 | 接続詞 | 意味 | メモ |
 |-----------|-----------|------|
 | *a/ar* | と | 子音の前の *a*。 *ar* または母音の前 (議論あり) |
 | *エゴール* | または | |
 | *ダン* | しかし、反対 | |
 | *パン* | いつ、いつから | 従属節を導入します |
 | *私* | として、一方 | |
 | *に* | それで | 最終条項/目的条項 |
 | *be* | | によると、 比較 |

 ### 等位接続詞

 *A* は 2 つの名詞または動詞を接続します。 
- *アラゴルンとレゴラス* — 「アラゴルンとレゴラス」
 - *Cenin a linnon* — 「私は見て、私は歌う」

 ---

 ## 下位節

 シンダール語には、次のように導入された相対的および時間的従属節があります。 

### *i* との関係節

 関係代名詞 *i* (定冠詞と同じ単語 - 文脈によって区別される) は関係節を導入します。 

*I pherian i aníra iest lín* — 「あなたの願いを望むホビット」
 - *i pherian* = ホビット (記事 *i* + lenited *pherian*)
 - *i aníra* = 誰が望むのか (関係 *i* + 動詞)
 - *iest lín* = あなたの願い (*lín* = あなたの所有格)

 ### *pan、im* を含む時間節

 *パン トル アラゴルン、リンノン* — 「アラゴルンが来るとき、私は歌う」
 *Im cenin i 'aladh、maeron* — 「木を見ている間、私は幸せです」

 ## 複雑な文の例

 ### トールキンのテキストより

**ペド メロン ア ミノ** (ドゥリンの扉)
 - *ペド* = 話します! (*ped-* の必須)
 - *メロン* = 友達
 - *a* = および
 - *minno* = 入ります! (*minno-*の命令)
 - 翻訳: 「話しなさい、友達になりなさい、そして入ってください」

 **Le abdollen** (裂け谷 — エルフからガンダルフ)
 - *le* = あなた/あなた (2 番目のオブジェクト)
 - *abdollen* = 「遅れた/遅刻した」 (*ab-* + *tol-* + *-nnen* の過去分詞)
 - 翻訳：「あなたは遅れています」（文字通り「あなたは引き止められています」）

 **Nef aear, sí nef aearon** (*A Elbereth Gilthoniel* より)
 - *nef* = のこちら側
 - *aear* = 海、海
 - *sí* = 今ここ
 - *aearon* = 大海 (拡張形式)
 - 翻訳: 「海のこちら側、大海のこちら側」

 **エルベレス・ギルソニエル** — 最初のスタンザの完全な解析:

 | 単語 | 分析 | 翻訳 |
 |------|----------|---------------|
 | *A* | 感嘆詞 | おお！ |
 | *エルベレス* | 名前 (スタークイーン) | エルベレス |
 | *ギルソニエル* | 名前の合成: *ギル* (星) + *トニエル* (火をつけた人) | スターキンドラー |
 | *シリヴレン* | *セレブ* (シルバー) + *-ren* (形容詞) | スパークリングシルバー |
 | *ペナ* | 落ちる、傾く | 写真 斜め下 |
 | *ミリエル* | *mîr* (宝石) + *-iel* (娘/女性) | 宝石のように輝く |
 | *メネル* | (*o*) + 天 (*メネル*) から | 天国から |
 | *アグラー* | 輝き、栄光 | 栄光 |
 | *エレナス* | スターホスト (集合) | 星の |

 直訳すると「おおエルベレスの星を焚く者よ、銀が斜めに落ち、宝石のように輝き、天から星の栄光が！」

 ## 文パターンのまとめ

 | パターン | シンダール語 | 英語 |
 |----------|----------|----------|
 | シンプルなステートメント | *トール・アラゴルン* | アラゴルンが来る |
 | 推移的 | *チェニン・アラド* | 木が見えます | 写真 木が見えます
 | 述語形容詞 | *ベレグ アラン* | 王様は偉大です |
 | 与格 | *アノン・イルフ・アン・ベン* | 私は男性にゴブレットを与えます | 写真 私は男性にゴブレットを与えます
 | 否定 | *ウセニン アラド* | 木が見えない |
 | 質問 | *マン・セニール?* | 誰が見ますか？ |
 | 相対 | *私はベリアンとアニラ* | 欲望のホビット |
 | コマンド | *ペドメロン!* | 話してください、友達！ |
