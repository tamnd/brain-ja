## 2 つの動詞クラス

 シンダール語の動詞は、不定詞の形式 (引用形式) によって決定される 2 つの主要な活用クラスに分類されます。 

### クラス 1: 主動詞 (子音語幹)

 これらの動詞は語根が子音で終わります。 不定詞 (辞書形式) では、*tir-*、*ped-*、*cen-*、*car-* のように、ハイフンを付けた裸の語根で引用されます。 これらは動詞の古い「強力な」クラスです。 

例:
 - *tir-* — 監視する、守る
 - *ped-* — 話す、言う
 - *cen-* — 見る、見る
 - *car-* — 作る、行う、構築する
 - *cab-* — 跳躍する、ジャンプする
 - *men-* — 行く、進む
 - *tol-* — 来る予定

 ### クラス 2: A 語幹動詞 (派生動詞)

 これらの動詞は、不定詞の *-a* または *-o* で終わります (または主題母音を含む完全な語幹で引用されます)。 これらは、名詞、形容詞、または古い語源に由来する「弱い」動詞です。 これらはより生産的なクラスであり、新しい動詞は A 語幹として形成される傾向があります。 

例:
 - *linna-* — 歌うこと
 - *sogo-* — 飲む
 - *mato-* — 食べること
 - *teitho-* — 書くこと、描くこと
 - *noro-* — 乗る、走る
 - *garo-* — 持つ、持つ
 - *anno-* — 与える

 ## アオリスト (シンプルなプレゼント)

 **アオリスト** (「単純な現在」または「一般的な現在」とも呼ばれます) は次のように表現します。 
・習慣的な行動：「毎日見る」
 - 一般的な真実: 「火は燃える」
 - 時代を超えたステートメント
 - 物語のプレゼント

 これはデフォルトの現在形です。 

### アオリストの人称接尾辞

 | 人物 | サフィックス |
 |----------|----------|
 | 1番目のsg。 | *-オン* |
 | 2nd sg. おなじみ | *-og* |
 | 2nd sg. 礼儀正しい | *-odh* |
 | 3番目のsg。 | 裸のステム (または *-a*) |
 | 1番目のpl。 含む | *-om* |
 | 1番目のpl。 除く | *-onc* |
 | 2番目のpl。 | *-odh* |
 | 3番目のpl。 | *-ir* |

 ### 主動詞 *tir-* (見る) — アオリスト活用

 | 人物 | フォーム | 翻訳 |
 |----------|------|---------------|
 | 1番目のsg。 | *タイロン* | 私は見ます |
 | 2nd sg. ファム。 | *ティログ* | あなたは見守っています |
 | 2nd sg. ポール。 | *ティロッド* | あなたは見ます |
 | 3番目のsg。 | *ティル* | 彼/彼女/それは見ます |
 | 1番目のpl。 含む | *ティロム* | 私たちは見ます (包括的) |
 | 1番目のpl。 除く | *ティロンク* | 私たちは見ます (独占) |
 | 2番目のpl。 | *ティロッド* | あなた (pl.) 見てください |
 | 3番目のpl。 | *ティリル* | 彼らは見ています |

 **作り方:** 主動詞語幹 + 人称接尾語。 アオリストでは語幹母音は変わりません。 

### 主動詞 *ped-* (話す) — アオリスト活用

 | 人物 | フォーム | 翻訳 |
 |----------|------|---------------|
 | 1番目のsg。 | *ペドン* | 私は話します |
 | 2nd sg. ファム。 | *ペドック* | あなたは話します |
 | 2nd sg. ポール。 | *ペドー* | あなたは話します |
 | 3番目のsg。 | *ペド* | 彼/彼女は話します |
 | 1番目のpl。 含む | *ペドム* | 私たちは話します |
 | 1番目のpl。 除く | *ペドンク* | 私たちは話します (除く) |
 | 3番目のpl。 | *ペディル* | 彼らは話します |

 ### A-幹動詞 *linna-* (歌う) — アオリスト活用

 A 語幹動詞の場合、主題の *-a-* は子音の頭文字の接尾辞の前にあり、母音の頭文字の接尾辞の前に短縮されます。 

| 人物 | フォーム | 翻訳 |
 |----------|------|---------------|
 | 1番目のsg。 | *リノン* | 私は歌う |
 | 2nd sg. ファム。 | *リノグ* | あなたは歌う |
 | 2nd sg. ポール。 | *リンノッド* | あなたは歌う |
 | 3番目のsg。 | *リンナ* | 彼/彼女は歌います (基本形) |
 | 1番目のpl。 含む | *リンノム* | 私たちは歌う |
 | 1番目のpl。 除く | *リノン* | 私たちは歌う (除く) |
 | 3番目のpl。 | *リンニル* | 彼らは歌う |

 **形成方法:** A 語幹の動詞語幹 (最後の *-a* を省略) + 人称接尾辞 (3 番目の sg を除く)。 これにより、完全な茎の形が *linna* に保たれます。

 ## 継続的な現在

 **継続現在** (「不完全」または「現在進行形」とも呼ばれます) は、「私は (今) 見ています」と話す瞬間の進行中の動作を表します。 

### 主動詞の形成

 根母音を**長く**（短母音→長母音）、接尾辞*-a*を追加して新たな連続語幹を作成します。 次に、人称接尾辞がこの語幹に付加されます。 

母音の長さ:
 - *i* → *î*
 - *e* → *ê*
 - *a* → *â*
 - *o* → *ô*
 - *u* → *û*

 ### 主動詞 *tir-* — 継続現在形

 継続語幹: *tîra-* (*i* → *î*、プラス *-a*)

| 人物 | フォーム | 翻訳 |
 |----------|------|---------------|
 | 1番目のsg。 | *タイロン* | 私は見ています |
 | 2nd sg. ファム。 | *タイログ* | あなたは見ています |
 | 2nd sg. ポール。 | *ティロッド* | あなたは見ています |
 | 3番目のsg。 | *ティラ* | 彼/彼女は見ています |
 | 1番目のpl。 含む | *ティロム* | 私たちは見ています |
 | 1番目のpl。 除く | *ティロンク* | 私たちは見ています（除く） |
 | 3番目のpl。 | *ティリル* | 彼らは見ています |

 ### 主動詞 *cen-* — 継続現在形

 連用語幹: *cêna-* (*e* → *ê*)

 | 人物 | フォーム | 翻訳 |
 |----------|------|---------------|
 | 1番目のsg。 | *セノン* | 私は見ています |
 | 3番目のsg。 | *セナ* | 彼/彼女は見ています |
 | 3番目のpl。 | *セニール* | 彼らは見ています |

 ### 連用形の A ステム動詞

 A 語幹動詞の場合、アオリストと現在進行形はかなり重複します。 3 番目の単数 *linna* (「彼は歌う / 彼は歌っている」) はどちらの意味も表現できます。 A 語幹動詞に明確な連用形があるかどうかについては、学者の意見が異なります。 実用的な目的のために、コンテキストは曖昧さを解消します。

 ## 非人称動詞: *boe* (それは必要です)

 *Boe* は活用しない非人称動詞です。 これは常に三人称単数 (「必要である」) で現れ、その主語は別の動詞の不定詞になります。 

**構造:** *boe* + [エージェントの与格] + [不定詞/動詞]

 | 例 | 翻訳 |
 |----------|---------------|
 | *ボーペディム* | 私たちは話さなければなりません（話すことが必要です） |
 | *ボエアニムティラド* | 見なければなりません（見なければなりません） |
 | *ボーアンメン* | それは私たちにとって必要です |
 | *ボエ・レ・ティラド* | 必見です |

 証明済み: *boe ammen tírad* (私たちが見る必要がある) — トールキンの草稿より。 

与格は、前置詞代名詞の形で表現されます (*anim* = 私のため、*ammen* = 私たちのために、*le* = あなたのために)。

 ## 動詞 *nâ* (to be) — プレビュー

 コピュラ *nâ* (is、am、are) は最も重要な不規則動詞です。 完全な治療はレッスン 26 で行います。 現在:
 - *Nân* — 私は (1 節目)
 - *Nâ* — それは/彼は/彼女は(3番目の詩)
 - *I aran nâ beleg* — 王は偉大です

 ## 動詞-主語-目的語の語順

 シンダール語は、英語 (SVO) とは異なり、**VSO (動詞-主語-目的語)** の順序に従います。 動詞が最初に来て、次に主語、最後に目的語が来ます。 オブジェクト名詞はソフト突然変異を受けます (レッスン 11)。 

| VSO の構造 | 例 | 翻訳 |
 |--------------|--------|---------------|
 | 動詞 | *ティロン* | 私は見ます |
 | 動詞 + 目的語 | *ティロン・ヴァラド* | 私は塔を見ます |
 | 動詞 + 主語 | *リンナとエーデル* | エルフは歌う |
 | 動詞 + 主語 + 目的語 | *セナ、エドヘル、ヴァラド* | エルフは塔を見ている | 写真

 主語が動詞の人称接尾辞 (1 人称/2 人称) で表される場合、別個の主語代名詞は必要ありません。 
- *Tiron* = 「私は見ています」 — *-on* 接尾辞は主語を第一単数として識別します
 - *Linnir* = 「彼らは歌う」 — *-ir* 接尾辞は 3 番目の複数形を識別します

強調のために別の主語代名詞を追加することもできます。 
- *Im tiron* = 「私 (自分) が見ています」 — *im* は強調第一単数代名詞です
