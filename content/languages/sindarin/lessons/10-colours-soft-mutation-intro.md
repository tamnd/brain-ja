## 色の語彙

 シンダール語には豊富な色彩用語があり、その多くは中つ国の場所や登場人物の名前に直接現れます。 色を学習すると、すぐに実践的な効果が得られます。レッスン 3 からさらに深く地名の分析を始めることができます。 

| シンダール語 | 英語 | 期間 | メモと外観 |
 |----------|-----------|----------|--------------------------|
 | *カレン* | グリーン（一般、リビンググリーン） | S./N. | *Calenardhon* = 「緑の州」（ローハンの旧名）。 *eryn lasgalen* には *galen* (寛解形) があります。 
| *ラグ* | 緑（鮮やか、新鮮、明るい） | S. | *calen* よりもさらに具体的で、新芽や新鮮な葉の緑です。 *Laegrim* = グリーンエルフ |
 | *グラン* | 白、きれい、純粋 | S./N. | *Glanduin* (白い川)、*glân* は、いくつかの分析では「境界線、縁」も意味します。 
| *ニム* / *ニンプ* | 白、淡い | S. | *Nimrodel* (白い洞窟?)、*Nimrais* (白い峰)、*Finduilas* には *finn-* (髪) + *las* があります *nim* ではありません |

| *その間* | 暗い、憂鬱な、陰鬱な | S. | *Barad-dûr* (暗い塔)、特に抑圧的で脅迫的な暗闇に使用されます。 
| *セレブ* | シルバー | S. | *セレブルン* (シルバー ツリー)、*セレブラント* (シルバー コース)、*セレブディル* (シルバー チップ) |
 | *カラン* | 赤 | S. | *Caradhras* (*caran* + *ras*)、*Carantaur* (赤い森 — ᴺS.) |
 | *収集* | レッド、スカーレット（深めの赤） | N. | *カラン*とは区別されます。 血のような赤またはより深い深紅に使用されます。 
| *バラン* | 茶色、金茶色、黄褐色 | S./N. | *バランドゥイン* (金茶色の川 = ブランディワイン川) |

| *グウェイン* | 青白い、色褪せた、薄れている | ᴺS. | 色あせた色、青白い肌、薄暗い光に使用 |
 | *メレグ* | 素晴らしい、黄金色 | N. | 時には金色に適用されることもあります。 主に「強力な」という意味です。 
| *光沢* | 輝く金色の光 | S. | *Galadriel* には、この金の輝きのコンセプトに関連する *gal-* (光) が含まれています |
 | *モルト* | ゴールド（メタルカラー） | N. | *glaur* (輝き) とは区別されます。 *モルト* はメタリックなコインゴールドの色合いです。 
| *も* | ダーク、ブラック (名詞/語根) | S. | ルート名詞; 複合語の接頭辞として使用: *モルドール*、*モリア*、*モルゴス* (*モル* + *ゴス*) |

 **色の区別に関する注意:**

 **緑** — シンダール語には少なくとも 2 つの緑の単語があります。 *Calen* は一般的な緑色です。成長するもの、森林、シャイアの色です。 *Laeg*は、鮮やかな新緑、つまり春の新葉や澄んだ水の明るい緑です。 グリーンエルフ (*Laegrim*) の名前は、おそらく彼らの家の森の明るい緑に由来しています。 地名に *galen* がある場合 (*Eryn Lasgalen*、*Calenardhon*)、それは *calen* の軽音化形です。 

**白** — *glân* と *nim/nimp* は両方とも白を意味しますが、ニュアンスがあります。 *Glân* は、清潔で純粋な白、つまり輝く白を意味します。 *ニム/ニンプ*は淡く冷たい白、つまり冬や石のような白です。 *Nimrodel* と *Nimrais* は *nim-* を使用します。 明るく輝くような「白い塔」を求めるなら*glân*が良いかもしれません。 

**暗い** — *morn* と *dûr* は両方とも暗いことを意味しますが、*dûr* には特に暗く、脅威的な意味合いがあります。 *Barad-dûr* は Gloomy Tower、暗くて抑圧的な塔です。 *朝*は単に暗い（死の暗闇、夜）です。 この区別は、英語の「dark」と「gloomy」のようなものです。

 ## 名詞の後に色の形容詞を置く

 これは、英語話者がシンダール語を勉強する際に最初に学ばなければならない文法規則の 1 つです。 英語では、形容詞は修飾する名詞の **前** に来ます。 

- 英語: 「**緑**の森」
 - シンダール語: *eryn **galen*** = 「森の緑」 → 「緑の森」

 名詞が最初に来ます。 形容詞が続きます。 これは標準的なケルト語 (およびシンダール語) の語順です。

**その他の例:**
 - *アモン カラン* = "赤い丘" = "赤い丘"
 - *ered luin* = "マウンテンズ ブルー" = "青い山々" (*l* の突然変異なし — 以下を参照)
 - *バラド ニム* = "タワー ホワイト" = "白い塔"
 - *taur morn* = 「暗い森」 = 「暗い森」

 **地名の場合:** これが、中つ国の地名が名詞の後に「説明的な単語」を付ける理由です。 
- *アモン・スル* = 「風の丘」（「風の丘」ではありません）
 - *エリン・ラスガーレン* = 「緑葉の森（の）」（「緑葉の森」ではありません）
 - *Ered Luin* = "マウンテンズ ブルー" = "ブルー マウンテンズ"

 ## ソフトミューテーションとは何ですか?

 シンダール語には、**子音突然変異**と呼ばれるシステムがあり、文法的文脈に応じて単語の**最初の子音が変化**します。 シンダール語にはいくつかの種類の突然変異がありますが、最も一般的で最も重要なのは **ソフト突然変異** で、**lenition** (ラテン語の *lenis* = 優しい、柔らかい) とも呼ばれます。 

**ソフト突然変異** は、形容詞が名詞のすぐ後に続くときに、形容詞の最初の子音に起こる変化です。 この位置では、子音は「柔らかく」なり、明瞭さがなくなり、多くの場合、有声音になったり、弱くなったりします。 

### 突然変異はなぜ存在するのでしょうか?

 シンダール語の初期の段階では、形容詞の前にある名詞の終わりに母音がありました。 名詞のこの最後の母音が、次の単語の最初の子音を（同化の過程を通じて）変化させました。 その後、最後の母音は侵食されて消えましたが、それによって引き起こされた子音の変化は*化石として残りました*。 その結果、現代のシンダール語では目に見える変化はありませんが、それでも「この形容詞が名詞の後に続く」ことを示す変化が生じました。 

これはまさにウェールズ語で起こっていることです。 ウェールズ語の *coch* (赤) は、「y」(定冠詞) の後および多くの複合位置では *goch* になります。 突然変異は、文法化された歴史的な残留物であり、現在も存在する音によって「引き起こされる」のではなく、その位置を「マーク」するようになりました。 

### ソフトミューテーションではないもの

 ソフト突然変異は、単語が理解しにくくなるという意味ではなく、単語が予測どおりに定期的にその形を変えることを意味します。 変化表を学習すると、いつでも非突然変異 (基本、「ラジカル」) 形式を再構築できます。

 ## ソフトミューテーションの変更 (プレビュー)

 完全なソフト突然変異テーブルには 11 の変更があります。 ここでは、学習したばかりの色の単語に影響を与える 5 つの単語のプレビューを示します。 

| 部首（基本） | ソフト突然変異 (lenited) | 例 |
 |-----|--------------------------|----------|
 | **b** | **v** | *バラン* → *バラン* |
 | **c** | **g** | *カレン* → *ガレン*; *カラン* → *ガラン* |
 | **d** | **dh** | *dûr* → *dhûr* (*dûr* が名詞の後に続く場合に使用) |
 | **g** | ∅（消える！） | *グラン* → *ラン* |
 | **m** | **v** | *朝* → *ヴォルン*; *ミス* → *ヴィス* |
 | **l** | **l** (変更なし) | *ルイン* → *ルイン* |
 | **ん** | **n** (変更なし) | *ニム* → *ニム* |
 | **r** | **r** (変更なし) | — |
 | **s** | **h** | *セロン* → *サギ* |
 | **t** | **d** | *タイド* → *ダイド* |
 | **p** | **b** | *パラン* → *バラン* |

 最も劇的な変化は次のとおりです。 
- **g** は完全に消えます: *glân* (白) → *lân*; *galen* はすでに *calen* の軽音化形です (c→g は *c* の突然変異です)
 - **c** → **g**: ソフト突然変異では、文字 *c* は常に *g* になります。 
- **b**、**m** → **v**: *b* と *m* は両方とも *v* になります
 - **d** → **dh**: 有声停止音 *d* は有声摩擦音 *dh* に柔らかくなります。 

**待ってください — 重要な説明です:** *calen* (緑) がソフト突然変異を受けると、*galen* (c→g) になります。 しかし、*glân* (白) は *gl-* で始まり、ソフト突然変異の *g* が消えて *lân* になります。 それで:

 - *barad **galen*** = "緑の塔" (*calen* → *galen* 名詞の後に、c→g)
 - *barad **lân*** = 「白い塔」 (*glân* → *lân* 名詞の後、g→∅)
 - *amon **vorn*** = 「暗い丘」 (*morn* → *vorn* 名詞の後に、m→v)
 - *ered **luin*** = "青い山々" (*luin* → *luin*、l は変更されません)
 - *taur **varan*** = 「黄褐色/茶色の森」 (*baran* → *varan*、b→v)

 ## トリガー: 名詞の後の形容詞

このレッスンでは、ソフト ミューテーションのトリガーは次のとおりです: **名詞の直後に続く形容詞**。 これは基本的なトリガーの 1 つです。 他にも多くのトリガーがあります (レッスン 11 と 13 で説明します) が、これが最もすぐに役立つものです。 

**ルール**: **説明する単語** (形容詞、または任意の修飾語) が **名詞**の直後に続く場合、説明する単語の最初の子音はソフト突然変異を受けます。 

| 名詞 + 形容詞 | 変異していない形容詞 | 突然変異した形容詞 | フレーズの意味 |
 |-----------------|-------------------|---------------------|----------------|
 | *バラド* + *カレン* | *カレン* | *ガレン* | 緑の塔 |
 | *バラド* + *グラン* | *グラン* | *ラン* | 白い塔 | 写真
 | *アモン* + *カラン* | *カラン* | *ガラン* | 赤い丘 |
 | *アモン* + *モーン* | *朝* | *ヴォルン* | 暗い丘 |
 | *タウル* + *バラン* | *バラン* | *バラン* | 茶色の森 |
 | *エレッド* + *ルイン* | *ルイン* | *ルイン* (変更なし) | ブルーマウンテン |
 | *ミナス* + *ニム* | *ニム* | *vim* ... | 待ってください — *n* → *n* は変化しませんか? |

 実際の確認: *n* はソフトミューテーションでは変化しません。 したがって、*ニム* → *ニム*: *ミナス ニム* = 「白い塔」。 ただし、*nimp* → *nimp* (変更なし)。 ただし、*ニムロデル* は固有名詞として使用される完全な単語であり、寛解形ではありません。 

ソフトミューテーションの *morn*: *m* → *v* も確認してみましょう。 それで:
 - *taur morn* (変異していない、トリガーなし) ただし、形容詞として直接続く場合: *taur vorn* ✓

 しかし、ちょっと待ってください。よく証明されている複合語 *Mordor* では、*môr* は形容詞ではなく最初の要素 (名詞) です。 *Barad-dûr* では、*dûr* は *barad* の後に来ます。*dûr* は変異していますか? ソフト突然変異の *d* → *dh*。 ハイフンなしの形式は *barad dhûr* になります。 しかし、証明された形式は *Barad-dûr* でハイフンなしの *d* です。 これは、**化合物名**に突然変異が常に適用されるとは限らないこと、または突然変異の前に化合物が化石化していることを示唆しています。 

これは重要なニュアンスです。**自由属性形容詞** (文中の一般名詞に続く形容詞) はソフト突然変異をとりますが、**適切な複合名** は突然変異されていない形式を保持する可能性があります。 「名詞の後の形容詞 = ソフト突然変異」というルールは、凍結された固有名詞複合体ではなく、生きた生産的な構文に適用されます。

 ## カラーワードのソフトミューテーションの証明された例

 **1. *エリン・ラスガーレン*** (青葉の森)
 - *エリン* = 森
 - *las* = 葉
 - *galen* = 緑 (*calen* から引用; c→g)
 - *galen* の *g-* は、*calen* の *c-* のソフト突然変異です。 

これは証明された最も重要な例の 1 つです。*Eryn Lasgalen* の *galen* は明らかに *calen* の緩解形であり、c→g が *c* のソフト突然変異であることが確認されます。 

**2. *エレド・ニムライス*** (ホワイト・マウンテンズ)
 - *ered* = 山
 - *nim-* = 白 + *rais* = ピーク
 - 複合体 *nimrais* は、*nim-* を接頭辞として扱います。 純粋な形容詞の突然変異ではなく、単語全体が複合境界で変化します。 

**3. *Calenardhon* によって暗示される → 州名が変更**
 - *Calenardhon* = *calen* (緑) + *ardhon* (レルム、地域): ここで *calen* は最初の要素 (接頭辞) であり、後続の形容詞ではないため、突然変異はありません

 ## 色の練習文

 必要に応じてソフトミューテーションを適用して、これらの名詞 + 色のフレーズを構築します。

**1.** "灰色の放浪者" — *mithrandir* は *mith* (灰色) + *randir* (放浪者) を使用します。 ただし、複合固有名としては、突然変異は適用されません。 一般的なフレーズ: *randir vith* = 「灰色の放浪者」 (*mith* → *vith*, m→v)

 **2.** 「赤い山」 — *オロド* + *カラン* → *オロド ガラン* (c→g)

 **3.** 「暗い森」 — *タウル* + *モーン* → *タウル・ヴォルン* (m→v)

 **4.** 「白い塔」 — *minas* + *glân* → *minas lân* (g→∅)

 **5.** "青い山々" — *ered* + *luin* → *ered luin* (l は変更されません)

 **6.** 「緑の谷」 — *ナン* + *カレン* → *ナン・ガレン* (c→g)

 **7.** "silver Tree" — *orn* + *celeb* → *orn geleb* (c→g) — ただし、証明された固有名 *Celeborn* は最初に *celeb* を持ちます (修飾語頭複合体として、順序は異なります)

 **8.** 「茶色の川」 — *サー* + *バラン* → *サー・ヴァラン* (b→v) — cf. *Baranduin* は *baran* を最初の要素として使用するため、そこには突然変異はありません

 |--------|--------|------|
 | 「灰色の放浪者」 | *ランディル・ヴィス* | m→v |
 | 「赤い山」 | *オロド ガラン* | c→g |
 | 「暗い森」 | *タウル・ボーン* | m→v |
 | 「白い巨塔」 | *ミナスラン* | g→∅ |
 | 「青い山脈」 | *エレド・ルイン* | なし (変更なし) |

 | 「銀の木」 | *オルン・ゲレブ* | c→g |

 ## 概要

 | コンセプト | 重要な事実 |
 |----------|----------|
 | 形容詞の順序 | シンダール語で名詞の後に形容詞が続きます。 
| ソフトミューテーショントリガー (このレッスン) | 名詞の直後に形容詞 |
 | c→g | *カレン* → *ガレン* |
 | m → v | *朝* → *ヴォルン* |
 | b → v | *バラン* → *バラン* |
 | g → ∅ | *グラン* → *ラン* |
 | l、n、r | ソフト突然変異でも変化なし |
 | 凍結された固有名詞 | 突然変異を示さない可能性があります (例: *Barad-dûr*)。 

これで、最も自然な文脈、つまり名詞に続く形容詞でのソフトミューテーションに遭遇しました。 レッスン 11 では、11 個の変更すべて、すべてのトリガー (名詞の後の形容詞だけでなく)、およびシステム全体にわたる多くの実際の例を含む完全なソフト突然変異テーブルを示します。
