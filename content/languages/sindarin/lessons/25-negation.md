## はじめに

 どの言語にも、「いいえ」、「違う」、「しないでください」と言う方法が必要です。 シンダール語には豊富で多様な否定戦略があり、それぞれが異なる文法文脈で使用されます。 重要なことに、これらの否定形式のいくつかはトールキンのテキストで**直接証明**されています。つまり、研究対象となる実際に出版されたシンダール語の否定文があることを意味します。 

このレッスンでは、シンダール語の 6 つの主要な否定戦略をすべて説明します。 

1. **ú-** — 動詞を否定し、否定的な複合語を形成するための接頭辞
 2. **avo** — 否定命令助詞 (「しないでください!」)
 3. **baw** — 強い禁止（「ダメ！絶対ダメ！」）
 4. **法律** — シンプルな「ノー」の返答
 5. **pen** — 複合語の私格「なし、欠如」
 6. **ú-boe** — 必要性の否定

 ## 2. 負の接頭辞 *ú-*

 最も汎用性の高いシンダール語の否定は、接頭辞 **ú-** です。 動詞（または名詞/形容詞）に直接接続して、それを否定します。 

### *ú-* はソフトミューテーションをトリガーします

 可変子音で始まる単語の先頭に *ú-* を付けると、その子音で **ソフト ミューテーション**がトリガーされます。 

| オリジナル | *ú-*後 | 突然変異ルール |
 |----------|-----------|--------------|
 | *ティリオン* | *ウー-チリオン* | t→th |
 | *ベッドドッグ* | *ú-vedog* | b → v |
 | *ガラド* | *ú-'aladh* | g → ' (ゼロ) |
 | *ダウル* | *ウーダウル* | D→Dh |
 | *ヘブ* | *ú-cheb-* (以下を参照) | h→ch |

 > **重要な警告:** *ú-* の突然変異の挙動については、シンダール語の学者の間で議論されています。 いくつかの情報源は、*ú-* が標準的なソフト突然変異ではなく、明確な「負の突然変異」を引き起こすことを示唆しています。 トールキンの証明された *ú-chebin* からの証拠 (以下を参照) は、*ú-* が後続の子音に影響を与えることを裏付けていますが、正確なシステムでは、証明された各形式を注意深く読む必要があります。 

### 証明済み: *ú-chebin estel anim*

 シンダール語全体で最も有名な否定的な証拠は、*『王の帰還*』の付録 A にある **ギルレンの *linnod*** (預言的な対句) です。 

> **オネン・イ・エステル・エダイン、ウー・チェビン・エステル・アニム**

 **全文と翻訳:**
 - *Onen* = 「私は与えました」 — 過去 1sg の *anna-* (与える); レッスン 22 を参照
 - *i-Estel* = 「希望」 — *i* (記事) + *Estel* (希望、信頼) 特別なハイフンでつながれた記事形式
 - *Edain* = 「ドゥネダインへ」 — *Adan* (三族の男) の複数与格。 ソフト突然変異 *A-* → 変更はありませんが、「男性へ」を意味します
 - *ú-chebin* = 「私は保管していません」 — *ú-* (否定) + *chebin* (私は保管しています、*heb-* の過去現在形); 注 *ú-* の後に *h* → *ch*
 - *estel* = "hope" — *Estel* という名前とは対照的に、普通名詞 (小文字)
 - *anim* = 「自分用」 — *an* (for、to) + *im* (自分、再帰 1sg)

 **翻訳:** 「私はドゥーネダインに希望を与えましたが、私自身には何の希望も残していません。」

 **文法上の注意:**
 - *chebin* は **過去-現在** (完了形) 形式です。「私は保持しています」 — 過去の行為の結果として生じた状態を表します。 これはまれですが重要なシンダール語の口頭形式です。 
- *エステル* (名前、贈り物) 対 *エステル* (普通名詞) の対比は感動的です。ギルレンは自分の希望 (息子のアラゴルンとして擬人化され、ニックネームは *エステル*) を捨て、何も残っていません。 
- *ú-chebin*: *ú-* + *chebin* — *heb-* (保持する) の *h* は、*ú-* の影響で *ch* になりました。 否定されたこの特定の突然変異 (*h → ch*) は独特の特徴です。 

この *linnod* は、トールキンの著作の中で最も感動的な文章の 1 つです。 覚えておいてください。 

### その他の *ú-* の例

 **動詞の否定:**

| ポジティブ | ネガティブ | 翻訳 |
 |----------|----------|---------------|
 | *てぃろん* (私は見ます) | *ú-thron* | 「見ません」 |
 | *セニン* (なるほど) | *ウーシェニン* | 「見えません」 |
 | *リノン* (私は歌います) | *ウーリノン* | 「私は歌いません」 |
 | *トーレン* (来ました) | *ウートーレン* | 「来ませんでした」 |
 | *iston* (知っています) | *ウーイストン* | 「分かりません」 |
 | *ガーネン* (私が作りました) | *ウーアーネン* | 「私は作りませんでした」（g → ' ゼロ） |

 **否定名詞 (私称):**

 *ú-* を名詞の前に付けると、「un-X」または「ill-X」を意味する否定的な複合語を形成できます。 

| 化合物 | 意味 | メモ |
 |-------|-------|------|
 | *オーマルス* | 「不運、邪悪な運命」 | *ú-* + *アマール* (運命) |
 | *ウーガース* | 「悪行、不法行為、罪」 | *ú-* + *ガース* (行為?) |
 | *ウラス* | 「悪事」 | *ú-* + *rath* (コース、行為) |
 | *ウーベン* | 「誰もいない」 | *ú-* + *ペン* (人) |

 **否定形容詞:**

 | 化合物 | 意味 |
 |----------|----------|
 | *ウヴァール* | 「良くない、良くない」 (*ú-* + *maer* → *vaer*) |
 | *ウガレン* | "緑ではない、枯れた" (*ú-* + *calen* → *galen*) |

 ## 3. 否定命令法 *avo*

 シンダール語で **「X をしないでください!」** と言いたい場合、*ú-* + 命令形は使用しません。 代わりに、専用の否定命令助詞 **avo** を使用します。 

### *Avo* + ソフト突然変異

 *Avo* の後には、**ソフト突然変異**を伴う動詞の不定詞/命令語幹**が続きます。 

| 肯定的命令法 | 否定命令法 | 翻訳 |
 |---------------------|------|---------------|
 | *ティロ!* (見てください!) | *アボ ディロ!* | 「見ないで！」 (t→dh?) |
 | *ガロ!* (やれよ!) *アボガロ!* | 「やめてください！」 |
 | *ベド!* (話せ!) | *アボ ヴェド!* | 「話すな！」 (b → v) |
 | *ペド!* (言って!) | *アボベド!* | 「言わないで！」 (p → b) |

 > ***avo* の証明:** トールキンは、言語ノートの中で *avo* が否定命令助詞であると証明しています。 それが引き起こす正確な突然変異については議論されていますが、*avo* の後のソフト突然変異がコンセンサスです。 

**文の例:**

 - *アボ ガロ!* = 「(それは)しないでください!」 — 最もよく引用される証明された形式
 - *Avo vedo i thiw!* = 「サインを話さないでください!」 (*bedo* = 話す; *b→v*; *thiw* = *têw*、記号の複数形)
 - *Avo menno!* = 「行かないでください!」 (*menno* = go; 最初の *m* はソフト突然変異の下では突然変異しません — *m* にはソフト突然変異がありません)
 - *Avo tiriad i varad!* = 「塔を見ないでください!」 (*avo* の後に動詞名詞 *tiriad* を使用)

 ### *Avo* と命令型活用

 *avo* が動詞の命令形 (2sg) と結合していると再構築する学者もいますが、不定詞/動名詞形をとると言う学者もいます。 最も安全なアプローチ: *avo* + 該当するソフト突然変異を含む動詞語幹を使用します。 

---

 ## 4. 強力な禁止 *baw*

 **Baw** は強調した「ノー!」です。 または「やめて！」 強い不承認、嫌悪感、または絶対的な禁止を表明する。 *avo* よりも強力で感情的です。 

### 認証

 *Baw* は、トールキンの言語ノートでシンダール語の間投詞/禁止詞であることが証明されています。 「拒否する、禁止する」という意味の語源に由来しているようです。 

### 使用法

 *Baw* は次の場合に使用できます。 
1. 間投詞としての **一人**: *Baw!* = 「いいえ! 絶対にダメです! やめてください!」
 2. 強力な否定コマンドの **動詞の前**: *Baw cerio!* = 「走らないでください! (強調)」
 3. **提案が拒否された場合**: *Baw, ú-boe* = 「いいえ、その必要はありません」

 ### *Baw* vs. *Avo* vs. *Ú-*

 | フォーム | 強さ | コンテキスト |
 |------|----------|----------|
 | *ú-* | ニュートラル | ステートメント: 「私はしません/彼はしません」 |
 | *アボ* | マイルドコマンド | 「やめてください / やめてください」 |
 | *バウ* | 強い命令/介入 | 「絶対ダメ！ダメ！」 |

 英語を比較してください:「見えません」 (*ú-*) と「見ないでください!」 (*avo*) vs. 「やめて！ダメ！」 (*バー*)。

 ## 5. 単純な否定的な返信 *法律*

 **Law** (時には *lav*) は、はい/いいえの質問に対する単純な **「いいえ」** として使用されます。 特定の動詞を否定するものではありません。 質問全体に否定的に答えます。

| 状況 | シンダール語 | 英語 |
 |----------|-----------|----------|
 | Q: *Ma cenig i aran?* (王様が見えますか?) | *法律* | 「いいえ（私はしません）」 |
 | Q: *マ・トーレン?* (来ましょうか?) | *ロー、ウーボエ* | 「いいえ、その必要はありません」 |
 | 強い拒否 | *バウ!* | 「いいえ！（強調）」

 **証明:** *法*は、トールキンの言語ノートの中でシンダール語の否定応答助詞として証明されています。 

### 肯定的な返信: *前*

 完全を期すために、シンダール語での肯定的な応答「はい」は **mae** です (一部の情報源では *ôl* も使用されますが、*mae* の方が一般的に引用されます)。 
- *Mae* = 「はい、それは良いです/確かに」
 - *Mae govannen* (よく会った!) の *mae* (よく) と混同しないでください。

 ## 6. プライベートプレフィックス *pen*

 要素 **pen** は、「X なし、X がない、X がない」という私格として機能します。 主に**複合語**および複合名で使用されます。 

### *ペン* + ソフトミューテーション

 *Pen* は、次の要素でソフトミューテーションをトリガーします (ほとんどのプレフィックスと同様)。 

| 化合物 | 意味 | 分析 |
 |----------|----------|----------|
 | *ペニノール* | 「年を経ず、まだ成人していない」 | *ペン* + *nínor*? = 年なし |
 | *ペニバース* | 「誓いなしで」（仮説） | *ペン* + *i* + *ピュス* → *ブシュ* |
 | *ペント*? | 「歯がない」？ | ᴺS. |

 関連する形式 **pín** (小さい、小さい – おそらく「サイズが足りない」) や *Pinnath Gelin* (Green Ridges — *pinnath* = 尾根、*ペン* 複合物?) のような名前でより明確に証明されています。 

### *ペン* 代名詞/名詞として

 これとは別に、*pen* はシンダール語で **「一人、人」** (不定代名詞) も意味します。 
- *ペン ティリタ* = 「誰かが見ているだろう」 / 「見ている人」
 - これは *úben* (誰もいない) の反対です — *ú-* + *pen*

 > **注意:** 「人/一人」を意味する *ペン* と「なし」を意味する *ペン* は、起源的には関連していますが、別の使用法です。

 ## 7. 否定された必然性: *ú-boe*

 レッスン 21 で確立したように、*boe* は「必要である」という意味です。 その否定 **ú-boe** は「必要ない」を意味し、標準の *ú-* 否定として機能します。 

| シンダール語 | 英語 |
 |----------|----------|
 | *ボエアンメンティロ* | 「私たちは見なければなりません」 |
 | *ウーボエ アンメン ティロ* | 「見る必要はない/見る必要はない」 |
 | *Ú-boe i aran* | 「王はその必要はありません（そうする必要はありません）」 |

 **認証:** *Boe* は認証されています。 *ú-boe* は、同じ *ú-* 接頭辞を使用した単純な否定です。

 ## 8. 複合名詞と地名の *Ú-*

 否定的な接頭辞 *ú-* は、トールキンが与えたいくつかの名前や単語に現れており、その使用に関する追加の証拠が得られます。 

| 単語 | 分析 | 意味 |
 |------|--------|----------|
 | *ウマルス* | *ú-* + *アマール* (運命) | 「不運、邪悪な運命」 |
 | *アンゴリアン* | *ú-* + *ngoliant* (蜘蛛の巣?) | 大蜘蛛。 *ú-* は邪悪な意味合いを与えます。 
| *ウルイ* | *ú-* + *るい*? それとも *ûr* (熱) + *ui* だけでしょうか? | 「8月」（暑い月） — *るい* 形は不確か |

 **名前 *Ungoliant* 分析:** 従来はクウェンヤ/ヴァラリンとして分析されていましたが、*un-* 要素はシンダール語の *ú-* と同じ否定語根に関連している可能性があります。 原始的な否定根 *√UGU/UMU* は、クエンヤ語 *um-* とシンダール語 *ú-* の両方の基礎となります。

 ## 9. 複雑な文の否定

 否定は、重要な方法で複雑な文構造と相互作用します (レッスン 24)。 

### 否定された下位節

 - *Tolen、ú-thiron* = 「私は見ていないので、来ます」（因果関係条項は否定されています）
 - *Ú-iston ma tolen* = 「来るかどうかわかりません」（主節の否定）
 - *I aran i ú-thirant* = 「見ていなかった王」 (関係節は否定されています)

 ### 二重否定

 シンダール語では、(一部の自然言語とは異なり) 肯定的な表現に二重否定を使用しません。 *Ú-* は、否定された要素ごとに 1 回使用されます。 
- *Ú-thiron、ú-linnon* = 「私は見ません、私は歌いません」 (2 つの別々の否定)

 ## 10. 完全否定システムの概要

| 建設 | シンダール語 | 英語 | メモ |
 |-----------|-----------|-----------|----------|

 | 否定的な複合名詞 | *ú-* + 名詞 | 「非X、病気X」 | (*úmarth*) | 証明済み

 ## 11. 練習問題

 **演習 1:** *ú-* を使用してこれらの動詞を否定します (必要に応じてソフト突然変異を適用します)。 

1. *メノン* (私は行きます)
 2.＊セリサム＊（作ります）
 3. とろん(来ます)
 4. *ベッド* (彼は言う)

 **演習 2:** *avo* を使用して、これらの肯定的な命令文を否定的な命令文に変換します。 

1. *ティロ!* (見てください!)
 2. *リンナ!* (歌ってください!)
 3. *メノ!* (ゴー!)
 4. *ペド!* (話せ!)

 **練習問題 3:** 各コンテキストに対して正しい否定形式 (*ú-*、*avo*、または *baw*) を選択してください。 

1. 友人に走らないように丁寧に伝える: ___
 2. 王には会わないと述べる: ___
 3. 「絶対にダメ！」と叫ぶ 恐怖で: ___
 4. 行く必要はないと言う: ___

 **演習 4:** Gilraen の *linnod* を記憶から翻訳 (または再構築):
 - 「私はドゥーネダインに希望を与えましたが、自分自身には何の希望も残していません。」

 **練習問題 5:** これらの複合名詞を否定してください:
 1. *アマール* (運命) → 不運
 2. *maer* (善) → 悪い/悪

 ### 回答キー

 1.
 - *ú-venon* (ソフト突然変異下では *m* → *v*? 実際: *m* は標準のソフト突然変異テーブルではレンナイト化しないため、*ú-menon*)
 - *ú-cheritham* (ソフト突然変異下では *c* → *ch*? ソフト突然変異: *ch* ではなく、*c* → *g*。つまり、*ú-geritham*)
 - *ú-thon* (*t* → *th*: 正しいソフト突然変異)
 - *ú-vêd* (*b* → *v*: 正しいソフト突然変異)

 > 解答に関するメモ: ソフト突然変異: p→b、t→d、c→g、b→v、d→dh、g→'(ゼロ)、m→v、s→h。 つまり: *menon* → *ú-menon* (m→v: *ú-venon*); *セリタム* → *ú-ゲリタム* (c→g); *トロン* → *ウードロン* (t→d); *bêd* → *ú-vêd* (b→v)。 

2.
 - *Avo dhíro!* (または *Avo dhiro!*) — t→dh? ソフト mut: t→d、だから *Avo diro!*
 - *Avo linna!* — l は変異しません
 - *アボ ヴェノ!* — m→v
 - *アボ ベド!* — p→b

 3.
 1. *Avo* (丁寧な命令形の否定)
 2. *ú-* (ステートメントの否定)
 3. *Baw!* (強い禁止/介入)
 4. *ú-boe* (必然性の否定)

 4. *オネン・イ・エステル・エダイン、ウー・チェビン・エステル・アニム。*
 (「私はドゥーネダインに希望を与えましたが、私自身には何の希望も残していません。」)

 5.
 - *úmarth* = 不運 (*ú-* + *amarth*)
 - *úvaer* = 悪い (*ú-* + *maer* → ソフト突然変異後の *vaer*)

 | シンダール語 | 英語 | ステータス |
