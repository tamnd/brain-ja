 ## 単音節の複数形

 単音節 (単一音節の単語) は、多音節の単語と同様に i 影響を受けますが、母音が 1 つしかないため、シフトは 1 つだけ発生します。 最初は結果に驚くかもしれません。 

### 短母音の単音節

 | 単数 | 複数 | 英語 | メモ |
 |----------|----------|----------|----------|
 | *オーク* | *年* | オーク / オーク | o→y; LotR で証明済み |
 | *ベス* | *ビス* | 女性 / 女性 | e→i |
 | *ペス* | *髄* | 言葉 / 言葉 | e→i |
 | *オーン* | *年* | (背の高い) 木 / 木 | 写真 o→y |
 | *ゴーン* | *女の子* | 尊敬される（もの） | o→y |
 | *退屈* | *ダイリン* | 硬い/硬いもの | o→y |
 | *落ちた* | *記入* | 崖/崖 | e→i |
 | *ベル* | *請求書* | 強い（1） | e→i |
 | *アン* | *アイン* | ギフト/贈り物 | a→ai→単​​音節で… *a*→*ei*? |

 ***a* を含む単音節に関する注意:** 母音が *a* のみである単音節では、複数形は音節が開いている (母音で終わる、単音節では非常にまれ) か閉じている (子音で終わる) かによって異なります。 *a* を含むほとんどの閉じた単音節では、複数形は *ai* ではなく **ei** を生成します。 

- *alph* → *eilph* (swan / swans) — *l* クラスターの前の *a* → *ei*
 - *ann* → *ein* (ギフト / ギフト) — *a* → *ei*
 - *am* → *aim* (丘、詩形) — *a* → *ai* または *ei*

 単音節の *a* → *ei* シフトは、古シンダール語の *a* が短い閉じた音節で複数の接尾辞の前でどのように動作するかを反映する特定のサブパターンです。

 ## 複数形の二重母音の変化

 二重母音も i 感情を受けます。 パターン:

 | 二重母音 (単数) | 複数形 | 例 |
 |---------------------|---------------|----------|
 | **au / AW** | **oe** / **ui** | *ナウル* お願いします。 *noer* (火災/火災 — ᴺS.); *ガウル* お願いします。 *goer* (人狼/人狼) |
 | **ae** | **愛** | *raen* → *rain* ... (コンテキスト依存) |
 | **愛** | 変更なし、または **î** | *雨* (放浪者) → *リン* — ᴺS. |
 | **おえ** | **うぃ** | レア; *oew* (巣) → *uiw* — ᴺS. |

 au/aw → oe シフトは、最も証明されている二重母音の複数パターンです。 
- *gaur* (狼男) → *goer* (狼男) — ᴺS. ただし規則的なパターンに基づいています
 - *naur* (火) → *noer* (火) — ᴺS.
 - *caul* (負担) → *coel* (負担) — ᴺS.

 ## 母音侵入 / 母音侵入複数形

 シンダール語の単語の中には、異なる複数形のパターンを示すものもあります。つまり、母音を移動する代わりに (またはそれに加えて)、単数形で失われた**母音を復元**します。 これは、単語の歴史的な単数形が母音を削除し、複数形では保持されている場合に発生します。 

最も重要な例は、*-on* で終わる語根から派生した名詞で、*o* は歴史的に重要です。 

### *アモン* → *エミン*

 - 単数形 *amon* (丘) — 2 番目の音節の *o* は語根の一部です
 - 複数形: 両方の母音が移動し、復元された形式が表示されます: *em-yn*
 - *a* (非最終) → *e*: *emon-*
 - *o* (最終) → *y*: *emyn*
 - 待ってください: *amon* には **a** + **on** があります: *a*→*e*、*o*→*y* → *emyn* ✓
 - これは実際には、2音節の単語を処理する通常のパターン 3 + パターン 1 の組み合わせです。 
- 結果: *amon* → *emyn* (丘 / 丘) ✓ 証明済み

 ### *アンノン* → *エニン*

- 単数形 *annon* (偉大な門)
 - *a* → *e* (非最終)、*o* → *y* (最終): *ennyн*? しかし、証明された複数形は *ennnyn* です
 - *a*→*e* は *ennon* を返します。その後、*o*→*y* は *ennyn* を返します ✓
 - 結果: *annon* → *ennyn* (グレート ゲート / グレート ゲート) ✓ 証明済み (*Ennnyn Durin* = Gates of Durin)

 ### *エイシル* → *エイシル*

 - 単数形 *eithel* (春、井戸)
 - 最初の音節の二重母音 *ei*: 通常、終端以外の位置では変更されません。 
- 最後の *e* → *i*: *eithil*
 - 結果: *eithel* → *eithil* (スプリング / スプリング)

 これらの「母音侵入」形式は、一見すると不規則に見えますが、同じ i-affection ルールに従います。この異常な外観は、関係する特定の母音と単語の歴史的構造に起因します。

 ## クラス複数形 (集合複数形)

 通常の複数形の i-affection システムに加えて、シンダール語には、接尾辞を追加することによって形成される **集合複数形** (「クラス複数形」とも呼ばれる) という別のシステムがあります。 これらは、単に「複数の X」を言うためではなく、物事の**クラス、グループ、または全体**を指すために使用されます。 

違いは次のとおりです。 
- **普通複数形**: *edhil* = "エルフ" (一部のエルフ、複数の個別のエルフ)
 - **クラス複数形**: *edhellath* または *Eledhrim* = 「民族としてのエルフ、エルフ族、グループ全体」

 ### サフィックス *-ath*: 完全な集合体

 *-ath* はクラスの全体性、つまり「すべての X」、「すべての X を一緒に考える」ことを示します。 

| ベース | 複数クラス | 意味 |
 |------|---------------|----------|
 | *エル* (スター) | *エレナス* | すべてのスター (全体として)、スターホスト |
 | *ゴンド* (石) | *ゴンダース* | すべての石、石の多いホスト |
 | *per* (ハーフリング要素) | *ペリアンナス* | 民族としてのハーフリング (LotR で証明済み!) |
 | *貸します* (道) | *レナス* | あらゆる方法、道路網全体 |
 | *ノルン* (ドワーフ要素) | *ノーナス* | ᴺS. すべてのドワーフ |
 | *グワス* (影) | *グワサ* | すべての影、影の全体 |
 | *レム* (メッシュ) | *リマス* | ネット/メッシュ全体 |

 *Periannath* は、シンダール語で最も重要な証明されたクラス複数形の 1 つであり、Cormallen シーン (*Cuio i Pheriannath anann!*) で使用されており、この接尾辞が生産的で証明されていることが確認されています。 

### 接尾辞 *-rim*: 人々、民俗

 *-rim* は **人々と人種**の集団を形成し、多くの場合「の人々」または「として知られる人々」という意味を持ちます。 

| ベース | *-リム* フォーム | 意味 |
 |------|-----------|----------|
 | *ガラド* (木) | *ガラドリム* | 樹木人（ロスローリエンのエルフ） — 証明されています！ |
 | *roch* (馬) → *roh-* | *ロヒリム* | 馬主（ローハンの人々） — 証明されました！ |
 | *ノゴス* (ドワーフ) | *ノゴスリム* | 民族としてのドワーフ |
 | *イスロン* (魔法使い) | *Ithryn* (普通のpl.) vs. *Ithronrim* | クラスとしてのウィザード — ᴺS. |
 | *ドゥネダイン* 要素 | *ドゥーネダイン* | West-men (= *dún* + *edain* pl.) — 異なる構造 |

 *Galadhrim* と *Rohirrim* はどちらも LotR で直接証明されており、*-rim* はシンダール語全体で最もよく確認されている接尾辞の 1 つとなっています。 

***ロヒリム*に関する注:** ロヒリムは古英語 (物語の中の実際の言語) で自分たちを *エオルリンガ* と呼んでいました。 *ロヒリム*は彼らのシンダール語の名前です。 *roch* (馬) → 語幹 *rohi-* (母音変化あり) + *-rim* (民族) から来ています。 二重の *rr* は、*r* とサフィックス *-rim* を組み合わせた結果です。 

### サフィックス *-hoth*: ホスト、大群 (通常は負)

 *-hoth* は **敵対的なグループまたは敵のホスト**の集団を形成します。 

| ベース | *-hoth* フォーム | 意味 |
 |------|---------------|----------|
 | *グラム* (喧騒、大騒ぎ) | *グラムホス* | オークの宿主である「ディン・ホード」が証明されました！ |
 | *ガウル* (狼男) | *ガウルホス* | 狼男ホスト、サウロンの狼軍団が証明されました！ |
 | *ドル* | *ドルーデイン*... | 異なる構造 |
 | *バルログ* 要素 | *バルログス* | ᴺS. バルログのホスト |

 *グラムホス* (「騒動の主催者」 = オーク) は、トールキンの言語ノートにオークのシンダール語集団として登場します。 *ガウルホス* は、ルーシエンの冒険に関連した詩やメモに登場します。 どちらも *-hoth* が証明されていることが確認されます。 

### サフィックス *-gwaith*: 会社、人物

 *-gwaith* は **企業またはフェローシップ** のコレクティブを形成します。

| ベース | *-gwait* フォーム | 意味 |
 |------|---------------|-----------|
 | *ミルダイン* (宝石細工師) | *グワイス・イ・ミルダイン* | Jewel-Smiths の人々 — 証明されています! |
 | *echad* (キャンプ) | *グワイス・イ・エチャド* | ᴺS. 野営地の人々 | 写真 野営地の人々

 *Gwaith-i-Mírdain* は、ケレブリンボールの下で力の指輪を鍛造したエレギオンのエルフの職人の名前です。 それは *Unfinished Tales* で直接証明されています。

 ## 冠詞 + 複数形: 複数形定冠詞 *in*

 シンダール語の**単数**定冠詞は**i*** (= "the")であり、次の単語に対してソフトミューテーションを引き起こします:
 - *i orch* = 「オーク」 (*i* の後に *orch*)

 **複数形**の定冠詞は**in*** (= 複数形の「the」) であり、次の単語で **鼻音突然変異** (レッスン 15 で詳しく説明します) を引き起こします。 

| 単数 | 複数形 (裸) | *in* を使用した複数形 | メモ |
 |----------|--------------|------|------|
 | *i orch* (オーク) | *yrch* (オーク) | *年に* → *年に* | 鼻の突然変異は初期値 *y* を変更します — 複雑 |
 | *i galadh* (木) | *gelaidh* (木) | *ゲライドで* → *エライドで* | *G* は *in* 後に消失します (鼻の突然変異) |
 | *私はエドヘル* (エルフ) | *エドヒル* (エルフ) | *エディルで* | 母音の頭文字: 突然変異は見られません |
 | *i aran* (王様) | *エレイン* (キングス) | *イレイン* | 母音の頭文字 |

 **鼻音変異のプレビュー:** *in* の後、子音は次のように変化します (レッスン 15 の完全な表):
 - *b-* → *m-* (*ビレイド* → *メレイド*)
 - *d-* → *n-* (*in daur* → *in naur*)
 - *g-* → 消滅 (*in gelaidh* → *in elaidh*)
 - *p-* → *b-* (*in perianath* → *in beriannath*)... 証明された形式は *i Pheriannath* と *ph-* (単数形 *i* の後のソフト突然変異) です。 

ここでは、*in* = 複数形の「the」であること、およびこれにより後続の子音に変化が生じることを覚えておいてください。 詳細はレッスン 15 で説明します。

 ## 概要: 適切な複数形の選択

 シンダール語の名詞を複数形にする必要がある場合は、次の決定プロセスを使用します。```
Is it a proper collective (the race/people as a whole)?
   → Yes: Use -rim, -hoth, -gwaith, or -ath depending on sense
   → No: Continue

Does the noun end in a consonant whose last vowel is...
   a or â → Pattern 1: a→ai (final), a→e (non-final)
   e or ê → Pattern 2: e→i
   o or ô → Pattern 3: o→y (final), o→e (non-final)
   u or û → u→y or û→ŷ
   Diphthong au/aw → Plural: oe
   Long vowel î or ŷ → Often unchanged or special form
   
Is the word monosyllabic?
   → Apply the same shift to the single vowel
   → Note: a → ei (not ai) in some closed monosyllables

Is it an irregular noun (êl, hên, etc.)?
   → Learn individual irregular forms
```---

 ## 概要表: クラスの複数形

 | サフィックス | 意味 | 証明された例 |
 |----------|-----------|---------------------|
 | *-ath* | 全体性、すべての X | *ペリアンナス* (すべてハーフリング) |
 | *-リム* | 人々、民族 | *ガラドリム*、*ロヒリム* |
 | *-ホス* | 敵のホスト、大群 | 写真 *グラムホス*、*ガウルホス* |
 | *-グワイス* | 会社、フェローシップ | *グワイス・イ・ミルダイン* |

 レッスン 8 では、主語 (主格) 代名詞システムから始めて、名詞から代名詞に進みます。シンダール語で「私」、「あなた」、「彼/彼女」、「私たち」を独立した単語として、また動詞の接尾語としてどのようにマークするかについて説明します。
