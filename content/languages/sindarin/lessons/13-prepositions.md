## 前置詞と突然変異

 シンダール語では、すべての前置詞が特定の突然変異を制御します。 これはオプションではありません。前置詞がどの突然変異を引き起こすかを知ることは、前置詞の意味を知ることと同じくらい基本です。 シンダール語話者が正しい前置詞を使用しているにもかかわらず、間違った突然変異により、間違った前置詞を完全に使用した場合と同等のエラーが発生します。 

前置詞が引き起こす可能性のある 3 つの突然変異タイプは次のとおりです。 
1. **ソフト突然変異** (レニション) — ほとんどの前置詞
 2. **鼻の突然変異** — 主に *an* (与格「to/for」)
 3. **混合突然変異** — 前置詞が定冠詞 *i* と融合する場合

 このレッスンでは、各グループを体系的に説明し、組み合わせたリファレンスを提供します。

 ## ソフトミューテーション前置詞

 これらの前置詞は、後続の名詞の最初の子音に標準的なソフト突然変異を引き起こします。 

| 前置詞 | 意味 | 突然変異 | 例 | 翻訳 |
 |---------------|-----------|----------|-----------|-------------|
 | *アブ* | 後、後ろ | ソフト | *アブディール* | 男のその後 (d→dh) |
 | *アデル* | 後ろ、後ろに | ソフト | *アデル・ヴァラド* | 塔の後ろ (b→v) |
 | *午前* | 上、上、上 | ソフト | *私は生まれています* | 暗闇の中で (m→v) |
 | *お父さん* | 下へ、下へ | ソフト | *父のゲーレン* | 下向きの緑 (c→g) |
 | *ディ* | 下、下 | ソフト | *ディ ダール* | 森の下 (t→d) |
 | *な* | に、向かって | ソフト | *ナヴァール* | 海に向かって (b→v) |
 | *ヌ* | 下、下 | ソフト | *ヌードール* | アンダー・ザ・ランド (d→dh) |
 | *o / od* | から、の | ソフト | * ベレグ * | 偉大な方から (b→v) |
 | *トリ* | |を通して ソフト | *トリ・ヴァラン* | パスを通して (b→v) |
 | *ú-* | なし、非 (プライベート) | ソフト | *ú-'aladh* | 木なし (g→ゼロ) |

 ### 拡張例

 **前置詞 *na* (に、向かって):**
 - *na vaear* — 海に向かって (*baear* "海" は b→v)
 - *na Valinor* — Valinor に向けて (理論上、名前は /v 交互に)
 - *na vedui!* — 「ついに!」 (na + *medui* "last" → *vedui*, m→v) — これはトールキンで証明されています。 
- *Na vedui、Dúnadan!* = 「ついに、ドゥナダン!」 (*リングのフェローシップ*)

 **前置詞 *o / od* (from、of):**
 - *o Menel* — 天国/空から (*Menel* は m で始まり、厳密なソフト突然変異の下では *o Venel* になります。証明された形式 *o Menel* は、*o* の後の *m* が突然変異しない可能性があること、または *o* が可変的に適用されることを示しています)
 - *o Eregion* — Eregion より (母音の頭文字: 変化する子音なし)
 - *od* は母音の最初の単語の前に使用されます: *od Ithilien* (Ithilien より)

 **前置詞 *nu* (下):**
 - *nu dhôr* — 大地の下 (d→dh)
 - *nu Haudh-en-Ndengin* — 「殺害されたマウンドの下」: *nu* + *H-* → *nu Ch-*... ただし、*Haudh* は固有名詞であり、h→ch の変化は抑制される可能性があります。 証明された化合物は *H* を保存します

 **前置詞 *ú-* (なし、私否定):**
 - *ú-'aladh* — 木なし / 木なし (*galadh* の g が消える)
 - *ú-chebin* — 「私は飼っていません」 (証明: *ú-chebin estel anim* = 「私は自分自身に何の希望も保っていない」) — ここで *ú-* は *hebin* (私は飼っている) を伴う言語否定接頭辞であり、*chebin* は h→ch 変異を示します。 

**前置詞 *ab* (後、後):**
 - *ab dhîr* — 男の後 (d→dh)
 - *ab varad* — 塔の後ろ (b→v)

 **前置詞 *am* (上、上):**
 - *am vorn* — 暗闇の上/暗闇の上で (m→v)
 - *am benn* — 下向き...待て、*am* は上を意味します。 *am* + *pend* (坂道、下り勾配) → *am bend* (坂道を上る、p→b)

 ## 鼻の突然変異前置詞: *an*

 前置詞 *an* (to、for — 与格) は、鼻の突然変異の主な引き金です。 これはソフト突然変異とは別個の突然変異です。 変更はストップに与える影響が異なります。 

### 鼻の変異テーブル (*an* が原因)

| オリジナルのイニシャル | *an* 後 (鼻の突然変異) | プロセス |
 |-----------------|--------------------------|----------|
 | **p** | **b** | 無声停止 → 有声 (歴史的 *np* → *mb* → *b*) |
 | **t** | **d** | 無声停止→有声 |
 | **c** | **g** | 無声停止→有声 |
 | **b** | **m** | 有声停止→鼻音（同じ場所） |
 | **d** | **ん** | 有声停止→鼻音（同じ場所） |
 | **g** | **NG** | 有声停止→鼻音（同じ場所） |
 | **m** | **m** | すでに鼻になっている。 変更なし |
 | **GW** | **ngw** | 唇蓋 → 鼻唇蓋 |
 | **s** | **h** | (ソフトミューテーションと同じ) |

 ストップの鼻突然変異とソフト突然変異を比較します。 

| オリジナル | ソフトミューテーション | 鼻の突然変異 |
 |----------|--------------|--------------|
 | p | b | b (ここでも同じ結果) |
 | t | d | d (同じ結果) |
 | c | g | g (同じ結果) |
 | b | v | **m** (違う!) |
 | d | え | **n** (違う!) |
 | g | (ゼロ) | **NG** (違う!) |

 決定的な違いは**有声音符**にあります。ソフト突然変異では声音 (v、dh、zero) に変わりますが、鼻音突然変異では鼻音 (m、n、ng) に変わります。 

### *an* を使用した例

 | *an* + 名詞 | 結果 | 翻訳 |
 |---------------|--------|---------------|
 | *アン* + *ペリアン* | *ベリアン* | ホビットのために (p→b) |
 | *アン* + *ティル* | *ディレクター* | 男の場合 (t→d) |
 | *アン* + *カレン* | *ガレン* | 緑の場合 (c→g) |
 | *アン* + *バラド* | *マラド* | タワー用 (b→m) |
 | *アン* + *ディル* | *アンニール* | 男の場合 (d→n) |
 | *アン* + *ゴンドール* | *ゴンドール* | ゴンドールへ (g→ng) |
 | *あん* + *メロン* | *メロン* | 友人のために (m 変更ありません) |
 | *アン* + *グワイス* | *待ち遠しい* | 国民のため（gw→ngw） |
 | *アン* + *スル* | *フル* | 風のために (s→h) |

 ### 証明済み: トールキンの *an*

 与格 *an* は証明されたシンダール語で表示されます。 
- *Guren bêd enni* — 「私の心は私に伝えます」 — ここでの *enni* は *an* + *ni* (私) を短縮したものです
 - *nin* (「私に」) のような与格接尾辞の形式は、歴史的に *an* + 代名詞に由来します

 ## 属格構文: *en* (of、所有格)

 属格助詞 *en* (単数形の「の」) は、名詞間に所有/結合関係を作成します。 次の名詞に対してソフトミューテーションを引き起こします。 

| 属格句 | 分析 | 翻訳 |
 |-----|----------|---------------|
 | *私はアランアンドール* | 土地の王 | 国の王 |
 | *私はゴンドールのバラド* | ゴンドールの塔 | 写真 ゴンドールの塔 |
 | *私はアラン* | 王の心 | |
 | *en Eglamar* | エグラマーの | 地名から |

 属格 *en* は、地名やタイトルでよく見られます。 
- *Haudh-en-Ndengin* = 「殺された人の塚」 (*en* + *Ndengin*、*deng-* グループの鼻の突然変異を示す → *Ndengin*。これは例外的であり、歴史的な形式を反映しています)
 - *Cerin Amroth* = アムロートの丘 (ここに *en* はありません。並置による属格)
 - *アモン ヘン* = 視界の丘 (*エン*なしの並置)

 ## 明確な前置詞 (混合突然変異 — プレビュー)

 特定の前置詞が定冠詞 *i* (「the」) と融合すると、その結果生じる短縮形が **混合突然変異** を引き起こします。これは、ストップの鼻音突然変異と他の場所でのレニションの組み合わせです。 詳細はレッスン 30 で説明しますが、重要な表は次のとおりです。 

| 前置詞 | + 記事 *i* | 契約フォーム | 突然変異が誘発されました |
 |-------------|--------------|----------------|--------|
 | *an* | + *i* | *エリン* | 混合（ストップの鼻音、他の場所でのレニション） |
 | *o* | + *i* | *ういん* | 混合 |
 | *な* | + *i* | *ネイ* / *ニン* | ミックスまたはソフト |
 | *ヌ* | + *i* | *ヌイン* | 混合 |
 | *午前* | + *i* | *エイム* / *目的* | 混合 |

 例: *erin Dolothen* = 「8 番目のとき」 — *erin* = *am* + *i* (on the)、*dolothen* の混合突然変異をトリガーします (d で始まります → 混合処理: どの突然変異が適用されるかに応じて、d→n または d→dh)。 

現時点では、これらの縮約前置詞 + 冠詞形式を見た場合は、レッスン 30 で学習する特別な突然変異のトリガーとして認識してください。

 ## 前置詞 + 代名詞の融合

一部の前置詞は人称代名詞と融合して短縮与格/前置詞代名詞を作成します。 代名詞自体が形を変えるため、これらは突然変異を必要としません。 

| 前置詞 + 代名詞 | 契約フォーム | 翻訳 |
 |----------------------|----------------|---------------|
 | *an* + *in* (私) | *エンニ* / *ニン* | 私に |
 | *アン* + *ル* (あなた) | *ル* / *アニル* | あなたへ |
 | *an* + *den* (彼) | *アンデン* | 彼に |
 | *ナ* + *イン* | *ニン* | 私へ/私のために |
 | *o* + *nin* | *オニン* | 私から |

 証明済み: *Guren bêd enni* = 「私の心が教えてくれます」 (*enni* = 私に、*an* + 代名詞から)。

 ## 練習する

 正しい前置詞と突然変異を適用します。 

1. 「友人に向けて」 — *na* + *mellon* を使用します
 2. 「塔から」 — *o* + *barad* を使用します
 3. 「王のために」 — *an* + *aran* を使用します (aran は母音で始まります — 突然変異なし、直接使用します)
 4. 「地面の下」 — *nu* + *dôr* を使用します
 5. 「希望なし」 — *ú-* + *estel* を使用します
 6. 「その男の後」 — *ab* + *dîr* を使用します
 7. 「門を通って」 — *trî* + *annon* を使用します
 8. 「ホビットの場合」 — *an* + *perian* を使用します

 **答え:**
 1. *ナベロン* (m→v)
 2. *o varad* (b→v)
 3. *an aran* (母音 - 子音の突然変異なし。ただし *a* は変化しません)
 4. *ヌードール* (d→dh)
 5. *ú-estel* (母音の頭文字 - 子音の突然変異なし、*u-* + 母音)
 6. *ab dhîr* (d→dh)
 7. *trî annon* (母音 - 子音変化なし)
 8. *ベリアン* (p→b、鼻の突然変異)
