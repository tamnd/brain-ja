## 位置: 常に名詞の後ろ

 シンダール語では、形容詞は常に修飾する名詞の後に**続きます。 これは英語の反対であり (「偉大な王」対 *aran veleg* — 文字通り「偉大な王」)、強いケルトの影響を反映しています。 たとえば、ウェールズ語も名詞の後に形容詞を置きます: *brenin mawr* = 「偉大な王」 (文字通り「偉大な王」)。 

この名目上の位置はオプションでも文体上のものでもありません。これは文法上の規則です。 名詞の前に形容詞を置くと、標準シンダール語では文法的ではなくなります。 

| 英語 | シンダール語 (間違っています) | シンダール語 (正しい) |
 |---------|-----------------|--------|
 | 偉大なる王 | ~~*ベレグ・アラン*~~ | *アラン・ベレグ* |
 | 緑の森 | 写真 ~~*カレンタウル*~~ | *タウル・ガレン* |
 | ダークタワー | ~~*朝のバラッド*~~ | *バラド・ボーン* |
 | 美しいエルフ | 写真 ~~*ベイン・エーデル*~~ | *エーデル・ヴェイン* |

 名詞が最初に来て、形容詞が続き、形容詞の最初の子音はソフト突然変異を受けます（レッスン 11）。 

---

 ## 頭子音の減音

 形容詞は名詞のすぐ後に続くため、ソフトミューテーションが適用されます。 トリガーは名目上の位置です。名詞の環境により、次の形容詞がレナイトになります。 

一般的な形容詞の頭文字に適用されるソフト突然変異の簡単な要約:

 | 形容詞 | イニシャル | 突然変異 | 例 |
 |----------|-----------|-----------|-----------|
 | *ベレグ* | b | v | *アラン・ヴェレグ* (偉大な王) |
 | *カレン* | c | g | *イスロン・ガレン* (緑の魔法使い) |
 | *グラン* | g | ゼロ | *エドヘル・ラン* (ホワイトエルフ) |
 | *朝* | メートル | v | *アモン・ボーン* (ダークヒル) |
 | *その間* | d | え | *barad dhûr* (ダークタワー) |
 | *ベイン* | b | v | *elleth vain* (美しいエルフの女性) |
 | *スル* | s | h | *amon hûl* (風の丘 — s→h) |
 | *タウル* | t | d | *dôr daur* (偉大な土地) |
 | *ホーレン* | h | ch | *アンノン・チョレン* (閉ざされたゲート) |
 | *ラグ* | l | l | *galadh laeg* (l 変更なし — 新緑の木) |

 f、l、r、n、v、または w で始まる形容詞は変化しません。

 ## 形容詞の複数の同意

 シンダール語の形容詞は名詞と**数が一致**します。 名詞が複数の場合、形容詞も複数でなければなりません。 シンダール語の形容詞は、**i-affection** (i-mutation または umlaut とも呼ばれます) を使用して複数形を形成します。これは名詞の複数形に使用されるのと同じプロセスです。 

i-affection では、最後の音節 (または音節のみ) の母音が *i* または *e* の方向にシフトします。 
- *a* → *e* (または最終位置の *ai*)
 - *o* → *y* (または *oe*)
 - *u* → *y*
 - *au* → *oe* または *ui*
 - *アン* → *アイン*
 - *on* → *yn*

 さらに、複数形形容詞は、その（現在は複数形の）名詞に続くときに依然としてソフト突然変異を受けます。

 ## 述語形容詞 (*nâ* の後)

 形容詞を使用するには 2 つの方法があります。 

1. **連体形**: 形容詞が名詞を直接修飾する → *i aran veleg* (「偉大な王」)
 2. **述語**: 形容詞はコピュラを介して名詞にリンクされています → 「王は偉大です」

 述語的な使用のために、シンダール語では共形動詞 *nâ* (「である」) が使用されます。 述語形容詞はコピュラの**後**に現れますが、重要なことに、この位置では緩和を引き起こす直接の名詞が存在しないため、この位置ではソフト突然変異**を受けません**。 

| 属性 | 述語 | 英語 |
 |---------------|---------------|----------|
 | *私はアラン・ベレグ* | *私は何もできません* | 偉大な王 / 王は偉大です |
 | *エーデル・ヴェイン* | *私はエドヘル・ナ・ベイン* | 美しいエルフ / エルフは美しい |
 | *タウル・ガレン* | *私はタウルナカレン* | 緑の森 / 森は緑です |
 | *アモン・ボーン* | *私は朝になりました* | 暗い丘 / 丘は暗い |

 注意: *i aran veleg* (連体詞) には *veleg* (突然変異) がありますが、*I aran nâ beleg* (述語) には *beleg* (非突然変異) があります。これは、コピュラ *nâ* が名詞と形容詞の間にあり、ソフト突然変異トリガー環境が壊れているためです。

 ## 副詞の形成

 シンダール語には、英語の *-ly* に匹敵する生産副詞接尾辞が 1 つもありません。 代わりに、副詞はいくつかの方法で形成されます。 

### 1. 副詞的に使用される形容詞

 一部の形容詞は、変更せずに副詞的な位置で直接使用できます。 
- *maer* (良い) → 「よく」として使用: *Pedin maer* (「私はよく話します」)

 ### 2. 独立した副詞

 シンダル語の副詞の多くは、形容詞から派生したものではなく、独立した語彙項目です。 

| 副詞 | 意味 | 証明書 |
 |----------|----------|---------------|
 | *アンアン* | 長い間、長い間 | *Cuio i Pheriannath anann!* (「ハーフリングが長生きしますように!」) |
 | *パラン* | 遠く、遠く | *palan-díriel* (「遠くまで見つめた」) |
 | *し* | 今、ここで | *sí nef aearon* (「ここ、大海のこちら側」) |
 | *ネフ* | こちら側 | *nef aear* (「海のこちら側」) |
 | *はん* | 向こう側、向こう側 | *nef* と対照的 |
 | *いいえ* | 下、下（副） | いろいろ |
 | *ボーイ* | それは必要です | 非人称動詞/副詞: *boe anim* |
 | *な* | それは (コピュラ) | *nâ* は動詞と場所格の両方として機能します。 
| *前* | まあ | *Mae govannen!* (「よく会いました!」) — *mae* = まあ |
 | *ú* | ない、なし | *ú-chebin estel anim* (「私は自分自身に希望を持ち続けていません」) |

 ### 3. 接頭辞付き副詞

 接頭辞 *palan-* は、「遠く/遠くに届く」場合に特に効果的です。 
- *palan-díriel* = 遠くを見つめた (palan + dir- 「見る」 + 過去分詞接尾辞)
 - *palan-tîr* = 遠くを見つめる (ケニング)

 ## 度修飾子

 ### 増圧器

 接頭辞としての *an-* は、新シンダール語の用法で最上級 (「最も」) を示すことができます。 
- *an-* + *beleg* → *ambeleg* (最大/最強) — 注: *b* の前の *an-* は鼻の突然変異を引き起こし、*am-* を与えます
 - *an-* + *calen* → *angalen* (最も緑色)
 - *an-* + *morn* → *amorn* (最も暗い)

 ### 証明された最上級のような形式

 トールキンは、「素晴らしい/非常に」という意味を強めて、名前に接頭辞 *an-* を使用しました。 
- *Annûn* (「西」ですが、*an-* はここでは「長い、伸びた」という意味です)
 - *アンドゥイン* = *アン-* + *ドゥイン* (長い川/大きな川)
 - *アンファグリス* = *アン-* + *ファウグリス* (息を呑む/窒息する粉塵 — ひどい)

 学習者にとって、*an-* + 形容詞を最上級に使用することは、十分に証明されているわけではありませんが、新シンダール語の慣例として受け入れられています。

 ## 比較 (比較度)

 シンダール語で証明された比較構文は限られています。 最も一般的なアプローチ (既知の文法から類推して) は次のとおりです。 
- **比較級**: 形容詞の後に *na* (「より」) を使用します: *I aran nâ veleg na i hîr* (「王は主よりも偉大である」)
 - 一部の学者は比較接頭辞 *thar-* (「sur-、over-」) を再構成していますが、これは推測です。

実際に使用する場合、形容詞はその基本的な形式と文脈に加えて、比較助詞が程度を伝えます。

 ## 練習: 名詞 + 形容詞句

 正しい名詞 + 形容詞句を形成します (ソフトな突然変異と、複数形の場合は i-affection を適用します)。 

**単数形:**
 1. *アラン* (王) + *カラン* (赤) = ?
 2. *elleth* (エルフの女性) + *mithren* (灰色) = ?
 3. *ithron* (魔法使い) + *morn* (ダーク) = ?
 4. *galadh* (木) + *bain* (美しい) = ?
 5. *dôr* (土地) + *iaur* (古代) = ?

 **複数形:**
 6. *edhil* (エルフ、*edhel* の pl.) + *bain* (美しい) = ?
 7. *エレイン* (キングス、*アラン*のpl.) + *カラン* → *セリン* (緑) = ?
 8. *emyn* (丘、*amon* の pl.) + *morn* (暗い) = ?
 9. *yrch* (オーク、*orch* の pl.) + *morn* (暗い) = ?
 10. *gelaidh* (*galadh* の木、pl.) + *glân* (白) = ?

 **答え:**
 1. *アランガラン* (c→g)
 2. *エレス・ヴィトレン* (m→v)
 3. *アイスロン・ヴォルン* (m→v)
 4. *ガラド・ヴァイン* (b→v)
 5. *dôr iaur* (私は変わらない)
 6. *edhil vîn* (b→v; bain→bîn 複数形)
 7. *エレイン ゲリン* (c→g; calen→celin 複数形)
 8. *emyn vyrn* (m→v; morn→myrn 複数形)
 9. *yrch vyrn* (m→v; morn→myrn 複数形)
 10. *gelaidh lîn* (g→ゼロ、glân→glîn 複数形、突然変異で g- がドロップ)
