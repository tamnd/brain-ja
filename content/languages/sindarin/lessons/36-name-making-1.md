## はじめに

 シンダール語の地名を作成することは、この言語を応用する最も有益な作業の 1 つであり、注意せずに行うと最も危険な作業の 1 つです。 中つ国のファン フィクション、RPG キャンペーン、世界構築プロジェクトはすべて、本物だと感じられるエルフの名前から恩恵を受けています。 このレッスンでは、地名を構成するための**トールキン独自の方法**、つまり要素の語彙、2 つの複合パターン、継ぎ目での突然変異、およびすべての一般的な記述修飾子を学びます。 

このレッスンは、**20 の完全に機能する名前の構成**で終了し、各ステップを順を追って説明するので、自分でプロセスを再現できます。 

---

 ## 1. なぜシンダール語の名前を作成するのでしょうか?

 トールキン自身は、中つ国の何千もの場所をシンダール語（およびクエンヤ語）で命名しました。 彼はこれらを無作為に発明したわけではありません。それぞれの名前は一貫した言語パターンに従っており、本物の意味を持っています。 トールキンが *ミナス ティリス* (「監視の塔」)、*カラス ガラドン* (「木の要塞」)、または *ヘネス アヌーン* (「夕焼けの窓」) と名付けたとき、あらゆる要素が意味に貢献しました。 

あなたも同じことができます。 これは、トールキン自身の意味での**二次創作**です。つまり、本物の言語ツールを使用して、言語的に*現実である*ため、本物のように感じられる何かを作ることです。 

---

 ## 2. トールキンの 2 つの複合パターン

 シンダール語の地名では、2 要素の複合語に対して 2 つの異なる語順が使用されます。 

### パターン A: モディファイア + ヘッド

 **説明する要素が最初に来ます**、**説明される内容が 2 番目に来ます**:

 > [形容詞/性質] + [名詞/地名タイプ] → [修飾地名]

 例:
 - *Dol Guldur* = *dol* (頭、丘) + *guldur* (魔術) = "魔術の丘" (記述要素 *guldur* が続きます)

 待ってください — *Dol Guldur* は実際にはパターン B です。わかりやすい例で説明しましょう。 

**パターン A (形容詞/修飾子が最初)**:
 - *Minas* Tirith = *minas* (塔) + *tirith* (watch) = "Tower of Watch" — 最初に頭、次に修飾子 — これもパターン B
 - *Emyn* Muil = 丘 + 灰色/混乱 = 灰色の混乱する丘

 実際にはパターンが重なっています。 トールキンは**両方の命令**を使用しましたが、区別は次のとおりです。 
- **適切な複合** (属格なし): 2 つの要素が直接融合します (*Gondor* = *gond* + *dor*)
 - **属格構文** (*en/i* "of" を含む): 主要名詞が最初に来て、次に属格句が来ます (*Minas Tirith* = Tower of the Watch; *Bar-en-Danwedh* = Home of the Ransom)

 ### パターン B: 頭部 + 修飾語 (属格)

 > [主要名詞] + *en* (of-the) + [属格名詞/句]

 例:
 - *Bar-en-Danwedh* = home + of-the + ransom = 「身代金の家」
 - *Amon Hen* = Hill + of-sight = "Hill of Sight" (*hen* が直接修飾しているため、*en* はありません)
 - *トールインガウルホス* = 島 + *in* (の) + ウェアウルフホスト = "ウェアウルフホストの島"

 前置詞/属格要素は次のように異なります。 
- *en* = (次の単語の許可): *Bar-en-Danwedh*
 - *-in-* = (古い/詩的な形式): *Tol-in-Gaurhoth*
 - 粒子を含まない直接化合物: *ゴンドール*、*モルドール*、*カラドラス*

 ### 実践的なルール

 独自の名前を作成する場合:
 1. **直接複合物** (2 つの要素が融合): パーティクルなし、継ぎ目での突然変異なし — *ゴンドール*、*ファンゴルン*
 2. **属複合体** (*en/i* + ソフト突然変異): 主要名詞 + *en* + ソフト突然変異のある 2 番目の要素

 ## 3. 複合継ぎ目での突然変異

 2 つの要素が複合語で結合すると、**2 番目の要素** の最初の子音が変化する可能性があります。 

### 直接化合物内

 トールキンの証明された地名では、**継ぎ目での突然変異は一貫性がありません**。それを示す名前もあれば、そうでない名前もあります。 その理由としては、突然変異ルールが体系的に適用される前に、古くから確立されている名前が結晶化してしまったことが考えられます。あるいは、複合名が単一の語彙単位として扱われている (単一の単語が内部的に変化しない) ことが考えられます。 

突然変異なしの例: *Gondor* (*'ondor* ではない)、*Fangorn* (lenited *o*... を含む *Fanghorn* ではない)

突然変異を伴う例: *Barad-dûr* — ハイフンは、これらが 2 つの単語として感じられることを示唆しています。 *dûr* は、属格のソフト変異の後では *dhûr* になりますが、独立した形容詞 *dûr* (暗い) はここでは変異していません (*barad* を修飾する形容詞です)。 

### 属格構文の場合

 *en* + 名詞を使用すると、次の名詞はソフトミューテーションを受けます:

 > *en* + *tol* → *en dol* (丘の; 注 *t* → *d*)
 > *i* + *ペリアンナス* → *i フェリアンナス* (P → Ph)
 > *en* + *galadh* → *en 'aladh* (ソフト突然変異下では g → ')

 **実際的なルール**: *en* と *i* (属格/冠詞マーカー) の後にソフトミューテーションを適用します。 助詞のない直接的な化合物の場合、突然変異を起こさないというトールキンの慣例に従うことも、より「ネイティブ」な雰囲気を得るためにソフト突然変異を適用することもできますが、それが ᴺS であることを一貫して正直に述べてください。

 ## 6. 段階的な名前作成プロセス

 新しいシンダール語の地名を作成するたびに、次の 5 つの手順に従ってください。 

### ステップ 1: その場所が何であるかを特定する

 **地理的なタイプ**を決定します。それは丘、川、森、要塞、湖、渓谷、峠ですか?

 適切な地理的要素を選択してください:
 ・ヒル → アモン
 - 川 → *sîr* / *duin* (大きな川)
 - 森 → エリン / タウル (大いなる古代の森)
 - タワー/都市 → *ミナス* / *オスト*
 - パス → *cirith*
 - 湖 → *ネン* / *リン*
 - 谷 → *ナン* / *イムラッド*
 - 島 → *トル*

 ### ステップ 2: 場所の重要な品質を特定する

 この場所の特徴は何ですか? その色は？ 方位（北/南）は？ 自然の特徴（風、水、石）? 歴史的な出来事？ 生き物？ 

### ステップ 3: 要素と語順を選択する

 - **直接複合物** (融合): *[品質要素] + [場所のタイプ]* — 例: *Mornnan* (Dark Valley)
 - **属格構築** (*en* + ソフト突然変異): *[場所の種類] + en + [説明]* — 例: *Nan en Morchond* (ブラック ハートの谷)

 ### ステップ 4: 継ぎ目での突然変異を確認する

 *en* (of-the) を使用する場合:
 - 次の単語の最初の子音にソフトミューテーションを適用します。 
- *en* + *galadh* → *en 'aladh*
 - *en* + *barad* → *en varad*
 - *en* + *caras* → *en garas*

 ### ステップ 5: 言語期間とラベルを確認する

 - トールキン自身の著作で証明されている要素を優先します (S. = 固有のシンダール語)
 - ノルドリンの要素のみを使用する場合: N とラベルを付けますが、類似性に注意してください。 
- すべての新しく構築されたフォーム: ラベル ᴺS。 
- 1 つの名前にクエンヤ語とシンダール語の要素を混在させることは避けてください (ただし、トールキンはいくつかの過渡的な名前でこれを行いました)

 ## 7. 20 の作業名構造

 すべてᴺS。 形式が証明された名前と正確に一致しない限り。

### 1.「緑の森」
 - タイプ：フォレスト → *エリン*
 - 品質: green → *calen* (*en* 後の *c* → *g* のソフト突然変異)
 - 建設: *エリン・ガレン* ᴺS.
 - 注: トールキンは実際にミルクウッド *エリン・ラスガーレン* = 「緑の葉の森」と名付けました。これはパターンを裏付けています。 *エリン・カレン* ᴺS. 「グリーンウッド」になります（少し違います）

 ### 2.「ダークタワー」
 - タイプ：タワー → *バラド*
 - 品質: ダーク → *dûr*
 - 建設: *Barad-dûr* — **認定済み** (サウロンの要塞!)

 ### 3.「西の塔」
 - タイプ: タワー → *ミナス*
 - 品質：西→*annûn*（日没/西）
 - 建設: *Minas Annûn* ᴺS. （西の塔・夕日）

 ### 4.「赤い山脈」
 - タイプ: 山 (複数形) → *ered* (*orod* の複数形)
 - 品質: 赤 → *caran* (ソフト突然変異: *en* と一緒に使用した場合、*c* → *g*)
 - 建設: *Ered Garan* ᴺS. (*c* → *g* のソフト突然変異: *en* + *caran* → *en garan*)
 - 粒子を含まない直接化合物: *Ered Caran* ᴺS.

 ### 5.「沈黙の谷」
 - タイプ：谷→*ナン*
 - 品質: サイレント → *dínen* (*dîn* より)
 - 建設: *Nan Dínen* ᴺS. (サイレントバレー)
 - 注: *Rath Dínen* は証明されています (「Silent Street」) — *dínen* の使用は十分にサポートされています

 ### 6.「灰色の川」
 - タイプ: 川 → *sîr* (小さい) または *duin* (大きい)
 - 品質：グレー→*ミット*
 - 建設: *Sîr Mith* ᴺS. または *ミスシール* ᴺS。 
- 比較: *Mithlond* (Grey Havens) は接頭辞として *mith-* を使用しています。つまり、*Mithduin* ᴺS です。 = 「グレイ・リバー」

 ### 7.「白い島」
 - タイプ: アイランド → *トール*
 - 品質: ホワイト → *ニム* (または *グラン*)
 - 建設: *トル・ニム* ᴺS。 または *トルニム* ᴺS。 (ホワイトアイル)

 ### 8.「ロングパス」
 - タイプ: パス → *cirith*
 - 品質: 長い → *および*
 - 建設: *Cirith And* ᴺS。 または *Cirith Annen* ᴺS。 

### 9.「星の湖」
 - タイプ：湖→*ねん*
 - 品質: スター → *エレン* / *エル*
 - 建設: *Nen Elenath* ᴺS.? — しかし、*elenath* はクラスの複数形です。 *elen* (シングルスター) を使用します。 
- より良い: *Nen Elent* ᴺS.? それとも*エレンネン* ᴺS.?
 - 最も単純: *Nenelenath* ᴺS。 = オール・ザ・スターズの湖 (詩的)
 - 実用的: *Nen Elen* ᴺS。 = スターレイク（裸茎使用）

 ### 10.「北の森」
 - タイプ：フォレスト → *エリン*
 - 品質：北→*フォロッド*
 - 建設: *エリン・フォロッド* ᴺS. (ノーザンウッド)

 ### 11.「鉄の門」

 ## 8. 名前を付けるよくある間違い

 ### 間違い 1: 言語期間を混合する

 1 つの名前でシンダール語要素を含む Quenya 要素を使用する (例: *Calas* Sindarin + *-rin* Quenya)。 解決策: 各要素のソースを確認し、1 つの方言内に収めてください。 

### 間違い 2: *en* の後の突然変異を忘れる

 *Bar-en-Daer* の代わりに *Bar-en-Daer* と書く — 待って、*daer* は *d* で始まります: *en* + *daer* → *en Naer* (鼻音の突然変異による d → n?)。 いいえ — *en* (属格「の」) の後は、**ソフト突然変異**: *d* → *dh* です。 したがって、*en* + *daer* → *en Dhaer* ᴺS。 

実際: 属格粒子 *en* はソフト突然変異を引き起こします: b→v、d→dh、g→'(g-drops)、m→v、p→b、t→d、c→g。 

したがって、*Bar-en-Danwedh* は正しいです: *en* + *danwedh* (身代金) → *en Danwedh* — 待て、*d* は *dh* になるはずです: *en Dhanwedh*。 しかし、証明された形式は *Bar-en-Danwedh* です! これは、トールキンが地名に突然変異を適用する際に必ずしも 100% 一貫していなかったこと、または *d* が (突然変異しない) *-an-* 接頭辞の一部とみなされたことを示しています。 

**レッスン**: 証明された名前フォームを参照してください。 トールキンが変異していない場合、たとえ変異していないように見えても、確立された名前については彼のやり方に従うことができます。 

### 間違い 3: 通常の複数形 + 接尾辞の使用

 単数形の語幹の代わりに *Gelaidh-orn* (複数形 + 木の接尾語) を書きます。複数形ではなく、*galadh* (単数形) + *-orn* を使用します。 

### 間違い 4: *dûr* (暗闇) と *dor* (土地) を混同する

 *Barad-dûr* = ダークタワー。 「暗い土地」は *Mордor*... これは *mor-* (暗い/黒) + *dor* (土地) になります。トールキンは *Durdor* ではなく *Mordor* を使用しました。 組み合わせる前に、証明された使用方法を確認してください。 

### 間違い 5: 複雑すぎる

 初心者の名前メーカーは、あまりにも多くの要素を詰め込もうとします。 トールキンの名前は通常 **2 つの要素**で構成されます。 本当に具体性が必要な名前には 3 つ以上の要素を予約する必要があります (*Taur-e-Ndaedelos* = 「大恐怖の森」のように、3 つの要素ですが、それぞれが適切な位置を占めます)。

 ## 覚えておくべき重要なポイント

 1. **2 つのパターン**: 直接合成 (融合) または属格構築 (*en* + ソフト突然変異)
 2. **地理語彙表を使用します** — その中のすべての要素はトールキンのテキストで証明されています
 3. ***en*** の後の変異: 次の単語の最初の子音にソフト変異を適用します。 
4. **通常は 2 つの要素で十分です**: 過度に複雑にしないでください
 5. **あなたの名前が証明されたトールキンの形式と一致しない限り、すべてにᴺS.**というラベルを付けてください
 6. **最高のテスト**: あなたの名前はシンダール語に *聞こえますか? 声に出して読んでください。 シンダール語は、流動的な子音 (*l*、*r*、*dh*) と特定の母音パターンを備えた独特の流れるような性質を持っています。
