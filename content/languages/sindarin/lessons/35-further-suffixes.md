## はじめに

 レッスン 32 と 34 では、所有格、指小格、抽象接尾辞を紹介しました。 このレッスンでは、残りの主要な派生接尾辞である **拡張 *-on***、**木接尾辞 *-orn***、**人/男性接尾辞 *-dir***、**息子接尾辞 *-ion***、**領土接尾辞 *-an* / *-wait*** を使用して調査を拡張します。 レッスン 32 ～ 35 を合わせて、接尾辞によるシンダール語の単語形成のほぼ完全なリファレンスを提供します。 

このレッスンのハイライトは、最後の **名前分析セクション**です。接尾辞の知識をすべて使って、10 人の有名なシンダール語の名前を分析します。これは、トールキン言語の中級者にとって最も満足のいく演習の 1 つです。 

---

 ## 1. 導出形態学: なぜそれが重要なのか

 シンダール語の語彙は、比較的少数の **語根** (トールキンの *語源* および関連文書に見られる原エルフ語の語幹) に基づいて構築されています。 単一のルートによって次のような問題が発生する可能性があります。 
- 単純な名詞
 - 形容詞
 - 動詞
 - 異なる接尾辞による複数の派生名詞

 たとえば、ルート *GAL-* (輝く、明るい、成長する) は次のようになります。 
- *gal* (光、輝き) — 名詞/動詞幹
 - *galad* (輝き、光) — 名詞
 - *galadh* (木 — 輝く/成長するもの) — 名詞
 - *ガラドリエル* — 名前 (輝く花輪のあるもの)
 - *ガラ* ᴺS。 (輝き、光の質) — 抽象名詞
 - *Galadhrim* — 複数クラス (ロスローリエンの樹木人)

 すべてはひとつの根から。 接尾辞を理解すると、この派生ウェブを読み、自信を持って新しい語彙を構築できるようになります。

 ## 2. 拡張接尾辞 *-on*

 ### 意味

 接尾辞 **-on** は **増強** です。何かを **より大きく、より重要で、より強烈にします**。 拡張語は単語のカテゴリーを変更しません (名詞は名詞のままです) が、その指示対象を拡大します。 

これは、名前を付けたいものが、そのタイプの **偉大で、そびえ立つ、卓越した** バージョンである場合に使用する接尾辞です。 

### 実証済みの例

 **1. *アンノン* — グレート ゲート**

 > *and* (長い、素晴らしい) / *ann* (ゲート) + *-on* → *annon*

 *エニン・ドゥリン、アラン・モリア: ペド・メロン・ア・ミンノ* — 「モリアの主、ドゥリンの門: 友達と言って入ってください。」 *Ennnyn* という単語は *annon* (偉大な門) の複数形です。 
- *annon* (大きな門、扉) → 複数形 *ennnyn* (i 愛情による: 強勢音節の a→e)
 - *-on* は、より小さい *and* または *fen* (ドア、敷居) に対して「偉大な門」になります。 

**2. *サウロン* — 大いなる忌まわし者**

 > *saur* (忌まわしい、汚い) + *-on* → *サウロン*

 *サウロン* は文字通り「忌まわしい者」です。*saur* (不快な、邪悪な臭いがする、忌まわしい) + 拡張語 *-on* = 「極めて忌まわしい者」です。 トールキンは手紙とメモでこの語源を確認しました。 堕落する前の *サウロン* の名前は *マイロン* = *マイア* (賞賛に値する、優れた) + *-on* = 「賞賛に値する者」でした。 

**3. *タウロン* — 森の主**

 > *タウル* (大森林) + *-on* → *タウロン*

 オロメ（ヴァラ、森と狩猟の主）の称号。 *タウロン* として、オロメは「森の偉大な者」、つまり最高の森主です。 これは、*-on* が場所の種類の名詞を人名に拡張できることも示しています。 

**4. *エルロンド* — Star-Vault**

 > *エル* (星、またはエルフ) + *ロンド* (金庫、洞窟、アーチ型ホール) → *エルロンド*

 直接の拡張 *-on* ではありませんが、*rond* (金庫/ドーム) という単語は、*ナルゴスロンド* = *ナログ* + *スロンド* (大きな金庫/洞窟) のように他の形式で拡張 *-on* と一緒に現れることがよくあります。 *-ond* / *-ond* エンディングは、拡張パターンの変形です。 

### フォーメーションルール

 - シンプルなステム + *-on*
 - 語幹が母音で終わる場合: *-on* がスムーズに融合する場合があります: *saur-* + *-on* = *Sauron*
 - *-on* 名詞の複数形: *-on* → *-yn* (i-affection): *annon* → *ennnyn*; *イスロン* → *イスリン*
 - *-on* 複数形は不規則であることに注意してください。*-on* 接尾辞は別個の複数形マーカーを取りません。 代わりに、単語全体が i-affection を受けます。

 ## 3. ツリーサフィックス *-orn*

 ### 意味

*-orn* は、シンダール語の *orn* (木) に由来します。 **接尾語**として使用すると、何かを**木の種類**、または**木の精霊または木のような存在**としてマークします。 これは、トールキンで最も一貫して使用される名前要素の 1 つです。 

### 実証済みの例

 **1. *セレブル* — シルバーツリー**

 > *セレブ* (シルバー) + *オーン* (木) → *セレブルン*

 ロスローリエンのセレボルン — 彼の名前は「銀の木」を意味します。 これが彼自身の木のような性質なのか、彼の銀髪への言及なのか、それとも朽ちた木々に対する彼の支配権を詩的に表現したものなのか、この言葉は明確です。 

*セレボルン* は、**ヌーメノールの白い木** の名前でもあります (行の 1 つ: *ガラティリオン* → *セレボルン* (木) → *ニムロス* → *ゴンドールの白い木*)。この木とエルフの王は名前を共有しています。 

**2. *ヒリローン* — ドリアスの大ブナ**

 > *híril* (貴婦人、高貴な女性) + *orn* (木) → *Hírilorn*

 ルーシエンがシンゴルによって投獄されたドリアスにある三本の幹を持つブナの大木。 この木の名前は「木の女王」または「貴婦人の木」を意味し、ドリアスの高貴で傑出した木です。 

**3. *ファンゴルン* — ひげの木 / 木のひげ**

 > *ファング* (ひげ、長い髪) + *オーン* (木) → *ファンゴルン*

 霧の山脈の東にある大森林のシンダール語の名前、およびツリービアード自身に対するエルフの名前。 *ファンゴルン* = 「ヒゲの木」または「ヒゲだけの木」 — ツリービアードの毛むくじゃらの外見と森の苔むした木々の両方がこのイメージを呼び起こしました。 

**4. *タウロン* — 再訪**

 *Taur* (偉大な森) + *-on* (増補) — *-orn* (木) ではありませんが、2 つの接尾辞は森林語彙の中で関連しています。つまり、森の主と木の接尾辞はどちらも同じ意味フィールドに遡ります。 

**5. ᴺS. *-orn*** を使用したツリー名

 | 単語 | 要素 | 意味 |
 |------|----------|----------|
 | *キュヴィエオルン* ᴺS. | *キュイヴィ* (覚醒) + *オーン* | 目覚めの木 (架空) |
 | *マルトホルン* ᴺS. | *モルト* (ゴールド/イエロー) + *オーン* | ゴールドツリー |
 | *エレノーン* ᴺS. | *エレン* (スター) + *オーン* | スターツリー |
 | *モルコンドルン* ᴺS. | *モルコンド* (ダークハート) + *オーン* | ダークウッドの木 | 写真 ダークウッドの木

 ## 4. 人物接尾辞 *-dir*: 「男、監視者、人物」

 ### 意味

 接尾辞 *-dir* (*dîr*、男性、成人男性に由来) は、**「[X] の男/人」** または **「[X] を監視/守る人」** を意味する名詞を作成します。 *-ron* よりも具体的なエージェントの風味があり、多くの場合、警戒心や献身的な注意を意味します。 

### 実証済みの例

 **1. *ハルディール* — 背の高い監視者**

 > *hal* (背が高く、高い — ᴺS. *khall-* ルートから) + *dîr* (男性) → *Haldir*

 ガラドリムのロスローリアンの行軍監督。 *Haldir* = 「背の高い男」、またはおそらく「高貴な監視者」。 *dîr* 要素は、彼を彼のクラスの *person* (成人男性) として明確にマークします。 

**2. *ディリエル* — ウォッチング・メイデン**

 > *dír* (見ています; または *tir-* からの *dir* 見ますか?) + *-iel* (乙女) → *Díriel*

 要素 *díriel* は、*palan-díriel* (*A Elbereth* の「遠くを見つめる」) に現れます: *palan-* (遠くて広い) + *díriel* (見つめた、見ている — *tir-* の分詞)。 ここでの *-dir-* は、人称接尾辞 *-dir* ではなく、*tir-* (見る) の分詞形である可能性があります。 

**3. *リンディル* — 歌う人/フェアシンガー**

 > *lind* (歌う、メロディアス) + *dîr* (男性/人) → *Lindir*

 裂け谷の吟遊詩人リンディルは、*『ロード・オブ・ザ・リング』* に少しだけ登場します。彼の名前は、歌う男という名前で彼を完璧に表しています。 

**4. *ドゥナダン* — 西の男**

 > *Dún* (西) + *adan* (人間、定命の者) → *Dúnadan* (西の男)

 *Adan* (*pl. Edain*) は人間 (死すべき人間) を表す一般的な単語です。 *-dir* は特に成人男性です。 どちらも人称接尾辞として使用されますが、*adan* はやや古めかしく、男性という人種に特有のものです。 

***-dir* 単語の複数形**: *dîr* の *î* は複合語で短縮されますが、複数形は単語全体の i-affection に続きます。 
- *リンディル* → 複数形 ᴺS. *Lindîr* (複数形の 2 番目の音節の i が長くなりますか?) または *Lyndyr* — 不規則です。 ケースバイケースで治療します。

 ## 5. サフィックス *-ion*: 「の息子」

 ### 意味

接尾辞 **-ion** は「[X] の息子」という愛称を形成します。 血統が非常に重要である文化 (そしてエルフは何世代も覚えている) では、この接尾辞は名前や称号に頻繁に現れます。 

### 例

 **1. *ディオリオン* ᴺS. — ディオールの息子**

 > *ディオール* + *-イオン* → *ディオリオン* ᴺS. （ディオールの息子）

 (注: ディオールの実の子供たちはトールキンの文章の中で名前が付けられていますが、父称接尾語として *-ion* というパターンが確立されています。)

 **2. *アリオン* ᴺS. — 高貴な息子 / 王の息子 **

 > *アラン* (王) を *ar-* + *-ion* → *Arion* ᴺS に短縮します。 (王の息子)

 **3. *エレディオン* ᴺS. — 山の息子 (比喩的)**

 *-ion* が詩的な用法で地名にどのように付加され、「出身者」または「生まれてきた息子」を意味するかを示します。 

### *-iel* との対比: 息子と娘

 | サフィックス | 意味 | 例 |
 |----------|-----------|----------|
 | *-イオン* | | の息子 *レゴラシオン* ᴺS. (レゴラスの息子) |
 | *-エル* | | の娘 *ニニエル* (ニエノール、涙の娘と呼ばれる) |

 どちらも、より一般的な名前要素 (厳密には父称ではありません) として使用することもできます。特に *-iel* は、「娘」がより比喩的な名前に使用されます。

 ## 6. 地域接尾辞 *-an* と *-wait* 単語

 ### リージョンの *-an* 接尾辞

 接尾辞 *-an* (バリアント *-ian*) は **領土、地域、または土地** を示します。 

| フォーム | 意味 |
 |-----|----------|
 | *ドリアス* | *Thingol* の土地 (*dor* 土地 + *iath* フェンス/ガードル → フェンスで囲まれた土地) |
 | *エリアドール* | 山間の孤立した土地 (*er-* 単独 + *iador* 土地?) |
 | *ルン* | 東; 東の土地 |
 | *ゴンドール* | Stone-land: *gond* (石) + *dor* (土地) |
 | *モルドール* | ブラックランド: *mor* (暗い、黒) + *dor* (土地) |

 接尾辞 *-dor* (*dôr*、土地から) は主要な土地接尾辞です。 *-an* はよりソフトなバリアントとして表示されます。 
- *Arthedain* = *Arthedain* = *arth* (領域) + *e* (of) + *dain* (土地)? — 複雑な歴史的形成
 - *アムルン* → *ローヴァニオン* (荒野): *ローワン* + *-イオン* 領土

 ### *-wait* / *gwaith* 地域の人々のため

 *gwaith* (人々、会社 — レッスン 31 を参照) という単語は、地域を示す人々の接尾辞としても機能します。 
- *グワトゥイリム* (ミンヒリアスの影の民)
 - *Gwaith-i-Mírdain* (エレギオン地方の*出身の宝石細工師の会社)

 ## 8. *-riel* / *-rîf* 接尾辞: 花輪付き / 王冠付き

 いくつかの有名な名前に使用される、より特殊な接尾辞。 

*-riel* は、ルート *RIG-* (麻ひもの、花輪を掛ける) → *riel* (花輪をかぶった乙女、花輪/花輪を戴く人) に由来します。 これは、次の場合に接尾辞として表示されます。 
- *ガラドリエル*: *ガラド* (輝き) + *リエル* (花輪の乙女) = 「輝く花輪の乙女」
 - *セレブリンダル* (*-riel* ではありませんが、関連しています): *セレブ* (シルバー) + *皮* (円) + *-al*

 ## 10. 練習: これら 10 のシンダール語の名前を分析してください

 接尾辞と要素の知識を使用して、各名前をそのコンポーネントに分析します。 次に、文字通りの意味を与えます。 

**1. *レゴラス***
 コンポーネント: *lego-/laeg-* (キーン、グリーン?、または「緑の葉」として光沢のあるトールキン) + *lass* (葉)
 トールキン自身のグロス: **「グリーンリーフ」**

 **2. *アラゴルン***
 構成要素: *ara-* (高貴な、王) + *gorn* (尊敬、恐怖? — *gor-* から恐怖へ、または *gorn* = 「恐怖を抱いている」)
 意味：「尊敬される王」または「Noble-Terror」（恐怖を抱かせる貴族）

 **3. *セレブリンボル***
 コンポーネント: *セレブ* (シルバー) + *リム* (多数、集合的な手/指?) + *ボル* (手、拳)
 トールキン自身の表現: **「シルバー フィスト」** (*セレブ* シルバー + *リムボール* 拳 — ここでの *リム* は別のルーツに由来している可能性があります)

 **4. *エルロンド***
 コンポーネント: *el* (スター、またはエルフ) + *rond* (金庫、ドーム型ホール、洞窟)
 意味: **「スタードーム」** または「星の金庫」 — 空/星の伝承の存在の名前

 **5. *グロールフィンデル***
 コンポーネント: *glor-* (黄金の栄光、*glor-* ルートから) + *find* (髪の毛、房) + *-el* (人/存在)
 意味: **「金色の髪」** — 彼の金色の髪は彼の最も際立った特徴でした

 **6. *ファンゴルン***
 コンポーネント: *牙* (ひげ) + *オーン* (木)
 意味: **「Treebeard」** または「Beard-tree」 — ツリービアードとその森を表すエルフの名前

 **7. *ハルディール***
 構成要素: *hal-* (背が高く、高貴 — *khall-* より) + *dîr* (男性、成人男性)
 意味: **「高尚な人」** または「背の高い人」 — 背の高い行進監視員

 **8. *ニニエル***
 構成要素: *nîn* (涙、水っぽい) + *-iel* (乙女、娘)
 意味: **「涙の乙女」** — 記憶喪失のニーノールに付けられた名前。 嘆きの名前

 **9. *イスロン***
 コンポーネント: *ith-* (伝承、知恵? — 正確な語源は不明) + *-ron* (エージェント: 1 人)
 意味: **「魔法使い」** (知恵/伝承の 1 つ)。 複数 *イスリン*

 **10. *ミナス・ティリス***
 構成要素: *minas* (塔、塔が 1 つある都市) + *tirith* (監視、後見 — *tir-* + *-ith* より)
 意味: **「守護の塔」** または「監視の塔」

 ## 覚えておくべき重要なポイント

 1. ***-on* は物事を大きく、より重要なものにします** (拡張): *saur* → *Sauron*、*and* → *annon*
 2. ***-orn* は木と木の精霊をマークします**: *-orn* で名前が終わるかどうか、名前が付けられたものに木とのつながりがあるかどうかを常に尋ねます。 
3. ***-dir* は「男性/監視者」** を意味します。*-dir* で終わる名前は通常、何らかの役割 (監視、歌うなど) を備えた男性です。 
4. ***-ion* は「息子」** で、*-iel* は「娘」** です。これらは一緒に父称/母称システムを形成します。 
5. **名前分析は実際の語彙です**: 中つ国の有名な名前はすべて分析できます。 この分析を行うことで、シンダール語と伝承の両方の知識が同時に深まります
