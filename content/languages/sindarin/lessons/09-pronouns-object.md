## 復習: レッスン 8 の主語代名詞

 レッスン 8 では、次のことを確認しました。 
- 件名情報は通常、**動詞語尾**で伝えられます: *tiron* = "私は見ています"、*tirog* = "あなたは見ています"
 - **独立した代名詞** (*im*、*le*、*hain*) は強調またはコントラストを追加します
 - 証明されている主要な代名詞: *im* (私)、*le* (あなた/あなた)、*hain* (彼ら)

 次に、これらの同じ人が行動の**対象**、または何かの**受信者**である場合に何が起こるかに目を向けます。つまり、「私/あなた/彼/私たち/彼ら」が形成されます。 

---

 ## 目的代名詞と与格代名詞とは何ですか?

 英語では、代名詞はその役割に基づいて形を変えます。 
- 件名: 「私は見えます」/「彼は見えています」/「彼らは見えています」
 - オブジェクト: 「**私**に会ってください」 / 「**彼**に会ってください」 / 「**彼ら**に会ってください」
 - 間接的 (与格): 「**私**に指輪を下さい」 / 「**彼**にニュースを下さい」

 シンダール語でも同様にこれらの役割を区別します。 目的語代名詞 (代名詞が動詞の動作の直接の受け手である場合に使用されます) は、人によっては主語代名詞と異なります。 与格 (間接目的語 - 「私に」、「あなたに」) は通常、前置詞 *an* + 鼻音の突然変異で表現されます。

 ## 直接目的語代名詞

 | 人物 | オブジェクト代名詞 | 例 | 翻訳 |
 |----------|------|----------|---------------|
 | 単数形 | *ニン* | *セノニン!* | 会いましょう！ / 私を見て！ |
 | 単数形 | *ル* | *ル・ハノン* | ありがとうございます/あなた |
 | 3単数形のマスコ。 | *はん* | *セノハン!* | 会いましょう！ |
 | 3単数fem。 | *彼* / *せ* | *セノヘ!* | 彼女に会いましょう！ |
 | 1番目の複数 | *ヴェン* / *男性* | *ナウル アン エドライス アンメン!* | 私たちを救うために火をつけてください！ (*ammen* = 私たちの場合、与格) |
 | 2番目の複数 | *ガール* | ᴺS. | — |
 | 3番目の複数 | *ハイン* | *ナルヴィはとても魅力的です* | 私はナルヴィが**それら**を作りました |

 **個々のフォームに関する注意事項:**

 **1sg *nin***: *nin* (私、私へ) という形式は、*guren bêd enni* (「心が告げる」) で使用される前置詞/代名詞と密接に関連しています。ここで、*enni* = 「私に」(与格形)。 *Nin* は直接目的語の形式です。 *enni* / *anim* / *nin* は文脈に応じて重複します。 *nin* という形式自体は新シンダール語の作品に現れます。 

**2sg *le***: *le* が主語 (強調) と目的語代名詞の両方として機能することに注意してください。 これは奇妙なことではありません。多くの言語では、1 つの代名詞が二人称の両方の機能をカバーします。 文の文脈によって常に役割が明確になります。*hannon le* では、*le* が動詞の後に続き、明らかに目的語です。 

**3sg *han* / *he***: 男性目的語 *han* と女性目的語 *he* は、トールキンのエルフ代名詞システムから再構築されています。 *han* (彼) と *he* (彼女) の区別は、シンダール語よりもクエンヤでより顕著に見られる、より広範なジェンダー体系を反映していますが、それでもなお存在します。 

**3pl *hain***: これは、シンダール語全体で最も確実に証明されている目的語代名詞です。 *Im Narvi hain echant* — 「私はナルヴィが **彼ら** を作りました」 -- 直接の目的語 (ドア) として *hain* を使用します。 *hain* が 3pl 目的語代名詞であり、一部の分析では独立した主語代名詞としても現れるという事実は、文脈によって解決されます。

 ## 重要な証明: *Le linnathon* (A Elbereth Gilthoniel)

 シンダール語全体で証明されている最も重要な代名詞の使用の 1 つは、シャイアと裂け谷のエルフによって歌われた賛美歌 *A Elbereth Gilthoniel* に由来しています。 フレーズ:

 > *ファヌイロス、ル・リンナソン*

 **単語分析:**
 - *Fanuilos* — ヴァルダ (星の女王) の形容詞で、「常白色」を意味します (*fan* = 白/雲 + *uilos* = 常雪)。 呼びかけ — 彼女は話しかけられています。 
- *le* — 代名詞、目的語/与格: 「あなたへ、あなたのために」
 - *linnathon* — *lin-* の未来時制 1sg 「歌う」: 「私は歌います」

 **翻訳:** 「ファヌイロス、あなたに私は歌います」または「エバーホワイト、あなたに私は歌います」。 

ここで *le* は、厳密な直接目的語ではなく、**間接目的語** (与格)、つまり「誰に向かって歌うか」として機能します。 この曖昧さはシンダール語の典型です。*le* は二人称単数の直接目的語と間接目的語の両方をカバーします。 *le* が与格であるか対格であるかは、別の代名詞の形式ではなく、動詞と文脈に依存します。

このフレーズは、**未来時制の形成**を確認するため、言語学的にも重要です。 *linnathon* = *lin-* (語幹) + *-atha-* (未来マーカー) + *-n* (1sg 接尾語) = 「私は歌います。」 (未来時制についてはレッスン 20 で詳しく説明します。)

 ---

 ## 賛美歌の全文: *エルベレス・ギルソニエル*

 完全な賛美歌は *The Fellowship of the Ring* に掲載されており、シンダール語で最も長く続いているテキストの 1 つです。 これは、オブジェクト代名詞の研究に重要なコーパスを提供します。 関連する行:

 > *エルベレス・ギルソニエル*
 > *シリレン・ペンナ・ミリエル*
 > *メネル・アグラー・エレナス!*
 > *ナ・チェレド・パラン・ディリエル*
 > *おお、ガラドレンミン・エノラス、*
 > *ファヌイロス、ル・リンナソン*
 > *まあまあ、まあまあだ！*

 ここで重要な代名詞は 6 行目の *le* です。以下にも注意してください。 
- *o* = from (前置詞、2 回出現:「天から」、「木で編まれた中つ国から」)
 - *nef* = (方向性前置詞) のこちら側
 - *sí* = 今ここ

 この賛美歌は本質的には祈りです。エルフたちは遠く中つ国からヴァルダ/エルベレスを呼び、彼女の保護を求め、彼女に歌を誓います。

 ## 与格: *an* + 鼻音の突然変異

 間接目的語 — 「誰かに ** に何かを与える」、「誰かに ** のために何かをする」 — の場合、シンダール語では前置詞 ***an*** の後に名詞が続きます (レッスン 15 で説明する鼻音の変異も含まれます)。 

**構造:** 動詞 + 直接目的語 + *an* + 間接目的語

 例:
 - *Anna eneth lín anim!* = 「あなたの名前を教えてください!」 (*anna* = あげます!、*eneth* = 名前、*lín* = あなた、*anim* = 私に)
 - *Hannon le an i mellyrn* = 「マローンの木をありがとう」 (*an* = のために、*i mellyrn* = マローンの木を)

 **前置詞 *an* は鼻の突然変異を引き起こします:**
 - *an* + *b-* → *an m-*: *an beleg* → *am meleg* (偉い人へ/のために)
 - *an* + *d-* → *an n-*: *an aran* → *an naran*... お待ちください — *an* 母音の前に *an* だけを付けます。 鼻の突然変異は、すべての場合において *an* だけではなく、*in* (記事) によって引き起こされます。 与格 *an* 自体は、分析に応じて突然変異を引き起こす場合もあれば、引き起こさない場合もあります。 

最も保守的な分析: 「to、for」を意味する単純な前置詞としての *an* は、(冠詞 *in* とは異なり) 必ずしもそれ自体で突然変異を引き起こす**わけではありません**。 *ammen* (for us) = *an* + *men* (us) という形式は、*an* + *m* → *am* の鼻同化を示します。 

***an* + 代名詞から派生した主要な与格代名詞:**

 | 代名詞 | 与格 | 導出 | 意味 |
 |-----------|-----------|---------------|---------|
 | *にん* (私) | *エンニ* / *アニム* | *アン* + *ニム* | 私に、私のために |
 | *ル* (あなた) | *ル* / *アンル* | *アン* + *ル* | あなたに、あなたのために |
 | *男性* (私たち) | *アンメン* | *an* + *男性* | 私たちにとって、私たちにとって |
 | *ハイン* (彼ら) | *アンハイン* | *アン* + *ハイン* | 彼らへ、彼らのために |

 **有名な *アンメン***: ガンダルフの叫び声 *Naur an edraith ammen!* (私たちの救いのために火を!):
 - *naur* = 火
 - *an* = の
 - *edraith* = 救う、救助する（動詞名詞）
 - *ammen* = of/for us = *an* + *men* (同化あり)

 これは *ammen* が与格 1pl 代名詞であることを証明します。 これは、シンダール語の認証の中で最も有名な小さな言葉の 1 つです。

 ## 直接目的語、間接目的語、与格の区別

 | 役割 | 説明 | シンダール語法 | 例 |
 |------|-------------|------|----------|
 | 直接オブジェクト | 動詞が何に作用するのか | 動詞の後に置かれる代名詞 | *セノニン* (私を見てください) |
 | 間接オブジェクト (受信者) | 直接オブジェクトを受け取る人 | *an* + 名詞/代名詞 | *Anna i lembas ammen* (ウェイブレッドを私たちに渡してください) |
 | 関心の与格 | 誰の利益のためにその行動が行われるのか | *an* + 代名詞 | *Naur an edraith ammen* (私たちを救うための火) |
 | *le* の与格 (2sg) | 歌や祈りの「あなたへ」に使用 | *le* 単独 (*an* なし) | *Le linnathon* (私はあなたに歌います) |

 **注:** *le linnathon* の与格に裸の *le* を使用していることは、二人称単数の場合、*le* が *an* を追加することなく直接目的語と間接目的語の両方として機能することを示唆しています。 これはトールキンの実践と一致していますが、*アンメン*ほどしっかりと確立されていません。

 ## 文中の目的語代名詞

 **目的語代名詞の位置:**

シンダール語の目的語代名詞は通常、**動詞の直後** (または動詞に密接に接続されている副詞の後)、名詞目的語の前に現れます。 

- *セノニン* = 「見てください!」 (動詞 + 1sg 目的語)
 - *Hannon le* = 「あなたに感謝します」 (動詞 + 2sg 目的語)
 - *Im Narvi hain echant* = 「私がナルヴィが作った」 (主語 + 主語の同置 + 3pl 目的語 + 動詞)

 モリアの碑文では、*hain* が動詞 *echant* の前に現れていることに注意してください。 これは強調配置であり、劇的な効果を得るためにオブジェクトが前に置かれています（「私、ナルヴィ、彼らが作った」）。 これは文体的に特徴付けられた語順です。 

**オブジェクトの標準語順:**

 VSO: 動詞 + 主語 (表現されている場合) + 目的語

 - *Echant im hain* = 通常の注文 (made I them = 「私が作りました」)
 - *Im Narvi hain echant* = 主語と目的語の前面を強調、動詞終止形 (より文学的)

 ## 要約表: すべての代名詞の形式

 | 人物 | 件名 (接尾辞) | 主題 (独立) | 直接オブジェクト | 与格 (*an* +) |
 |------|------|-----------|---------------|------|
 | 1sg | *-(o)n* | *私* | *ニン* | *エンニ/アニム* |
 | 2sg | *-(o)g/-(o)dh* | *ル* | *ル* | *ル/アンル* |
 | 3sgm。 | *-(o)r* または裸 | *e* | *はん* | *アン・ハン* |
 | 3sg f. | *-(o)r* または裸 | *エッセ* | *彼* | *彼* |
 | 1pl | *-(o)m / -(o)nc* | *分* | *ヴェン / 男性* | *アンメン* |
 | 2pl | *-(o)dh* | *ギル* (ᴺS.) | *ギル* (ᴺS.) | *女の子* |
 | 3pl | *-(o)r* | *ハイン* | *ハイン* | *アンハイン/アンハイン* |

 **認証レベル:**
 - **直接証明**: *im* (私、主体)、*le* (あなた、対象)、*hain* (彼ら、対象)、*ammen* (私たちの場合)
 - **強力にサポート**: *nin* (私)、*e* (彼)、*men/ven* (私たち)
 - **ᴺS. 再構築**: *han* (彼)、*he* (彼女)、*gîr* (あなた)、*esse* (彼女)

 ## 練習問題

 **練習問題 1:** 各文の下線付き代名詞の文法的役割を特定します。 

1. *私は **le*** です — *le* の役割は何ですか?
 2. ***Im** tiron* — *im* の役割は何ですか?
 3. *私はナルヴィ **ハイン** エチャント* — *ハイン*の役割は何ですか?
 4. *ナウル・アン・エドライス **アンメン*** — *アンメン*の役割は何ですか?

 **答え:**
 1. *le* = 直接目的語 (私は **thee** を見ます)
 2. *im* = 強調された主語 (私自身が見ています)
 3. *hain* = 直接オブジェクト (**彼ら** — ドア — は私が作った)
 4. *ammen* = 関心の与格 (**私たち**を救うための火)

 **練習 2:** シンダール語に翻訳します:

 1.「見てください！」 (*cen-* = 見るという命令; 1sg オブジェクト)
 2.「ありがとう。」 （定型文）
 3. 「私たちを救ってくれた火よ！」 (ガンダルフの叫び)
 4. 「あなたに私は歌います。」 (賛美歌より — *リンナソン* = 私は歌います)
 5. 「彼が作りました。」 (*echad-* = 作る; 3sg 動詞 + 3pl オブジェクトを使用)

 **答え:**
 1. *セノニン!*
 2. *ハノン・ル*
 3. *ナウル・アン・エドライス・アンメン!*
 4. *ル・リンナソン*
 5. *Echant hain* (過去形: *echant* = 作られた; *hain* = 彼ら)

 **練習問題 3:** シンダール語のフレーズとその翻訳を一致させます。 

| シンダール語 | 翻訳オプション |
 |----------|----------|
 | *ハノン ル* | (a) 彼が見えます |
 | *セノハン* | (b) ありがとう (私はあなたに感謝します) |
 | *私は、私* | (c) 彼ではなく私が話します |
 | *アンナ・アンメン・イ・レンバス* | (d) レンバをください |

 **答え:** 1→b、2→a、3→c、4→d

 ## 概要

 | 代名詞の種類 | キーフォーム | 証明書 |
 |---------------|-----------|---------------|
 | 直接オブジェクト 1sg | *ニン* | ᴺS. (*enni*に基づく) |
 | 直接/間接オブジェクト 2sg | *ル* | S. — 証明済み (*hannon le*, *le linnathon*) |
 | ダイレクトオブジェクト3pl | *ハイン* | S. — 証明済み (*私はナルヴィの魅力を知っています*) |
 | 与格 1pl | *アンメン* | S. — 証明済み (*Naur an edraith ammen*) |
 | 与格構文 | *an* + 名詞/代名詞 | S. |
 | 文学的なオブジェクトの前面 | 動詞の前の目的語 | S. (*ハイン・エチャント*) |

 主語、目的語、与格代名詞を理解したら、レッスン 10 では、色の語彙というレンズを通して、シンダール語の子音突然変異システムの最初で最も重要な **ソフト突然変異** (レニション) を紹介します。
