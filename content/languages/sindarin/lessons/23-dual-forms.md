## はじめに

 レッスン 6 と 7 では、シンダール語の複数形、つまり内部母音変化 (*i* 愛情) と複数名詞を特徴づける子音変異の複雑なシステムを学びました。 ただし、シンダール語には実際には 2 つだけではなく、**3** の文法数字があります。 

- **単数形**: 1 つの物事/人
 - **複数形**: 3 つ以上の物/人
 - **デュアル**: 正確に 2 つの物/人

 **双対**はエルフ語文法の最も古風な特徴の 1 つです。 これは、古代インド・ヨーロッパ語族 (サンスクリット語、古代ギリシャ語、古アイルランド語、ゴシック語)、セム語族 (アラビア語、ヘブライ語)、および世界中の他の多くの言語族に見られる文法番号です。 ほとんどの現代ヨーロッパ言語では、双対性は完全に消えています。 歴史言語学に造詣が深かったトールキンは、エルフ語に古風で古代の雰囲気を与えるために意図的に双対語を取り入れました。 

このレッスンでは、シンダール語の二重性について私たちが知っていること (証明され、再構成されたもの) について説明します。 

---

 ## 1. デュアルとは何ですか?

 双対は、**正確に 2 つ** の実体を表す文法上のカテゴリです。 複数形とは異なる理由は次のとおりです。 

- **複数形:** 「3 つ以上」 (双対語のない言語では「2 つ以上」の場合もあります)
 - **デュアル:** 「正確に 2 つ」 — ペア

 英語での「両手」、「一対の目」、または「二人の王」の違いを考えてみましょう。 英語には文法上の双対性がありません。回避策として「両方」、「ペア」、または「ツー」を使用します。 シンダール語はこれを形態論を通じて直接表現できます。 

シンダール語では双対性が最も重要です。 
1. **代名詞** (「私たち二人」、「あなたたち二人」、「あの二人」)
 2. 自然にペアになる **名詞** (手、目、耳、翼)
 3. 主語が明示的にペアである場合の **動詞**

 ## 2. シンダール語二重説の証拠

 トールキンはクエンヤ文法の中で双対性について広範囲に議論しました（双対性はクエンヤでより完全に証明されています）。 シンダール語の場合、証拠は少ないものの存在します。 

**直接的な証拠:**
 - トールキンの言語論文 (*Vinyar Tengwar* および *Parma Eldalamberon* に掲載) では、ノルドリン/シンダール語の二重形式について言及しています。 
- トールキンの文章の中のいくつかの名詞のペアは、双対的な構成のように見えるものを示しています。 
- シンダール語の前身であるノルドリンは二重形式を文書化していました

 **導出された証拠:**
 - 名前のペアは二重の概念を示唆しています: *Amon Hen* (目の丘) と *Amon Lhaw* (耳の丘) — 自然に二重のペア
 - *Celebrant* + *Anduin* を双子の川として — 二重カウントのコンテキスト
 - ペアを含む個人名: 双子の息子 *エラダン* と *エルロヒル*。 双子の木*ガラティリオン*と*セレボルン*

 ## 3. 二重代名詞

 シンダール語の二重代名詞システムは、トールキンのノルドリン資料から部分的に再構築され、クエンヤ二重形式と相互参照されています。 次の表は、現在の最良の学術的合意を表しています。 

### 個人二重代名詞 (主語形式)

 | 人物 | シンダーリンデュアル | 英語 | メモ |
 |----------|---------------|----------|----------|
 | 1 番目のデュアルを含む | *グウェント* | 「私たち二人」（あなたと私） | ᴺS. N より *グウェント* |
 | 1st デュアルエクスクルーシブ | *UNC* / *ウェット* | 「私たち二人」（あなたではなく、彼/彼女と私） | ᴺS. |
 | 2番目のデュアル | *濡れた* | 「あなたたち二人」 | ᴺS. |
 | 3番目のデュアル | *送信* / *ヘント* | 「あの二人」、「あの二人」 | ᴺS. |

 ### 包括的と排他的の説明

 一人称複数 (および二重) の包括的/排他的区別は、トールキンが彼のエルフ語に組み込んだもう 1 つの古風な特徴です。 

- **包括的な「私たち二人」** (*グウェント*): 「私とあなた」 — リスナーも含まれます
 - **独占的な「we two」** (*unc*): 「私と彼/彼女」 — リスナーは含まれません。 第三者および発言者を指します

 この区別は、オーストロネシア語と一部のアメリカ先住民の言語で一般的ですが、クエンヤ語にも同様に現れます（トールキンはそこで明示的にマークしています）。 シンダール語の場合、学者は類推によってそれを再構成します。 

### 斜格の二重代名詞 (目的語/与格)

 | 代名詞 | 目的語/与格形式 | 翻訳 |
 |----------|--------|---------------|
 | *グウェント* | *グウェン* / *グウェン* | 「us two」（私たち二人へ） |
 | *濡れた* | *ウェン* | 「you two」（二人へ） |
 | *送信済み* | *セン* | 「あの二人」 / 「あの二人」 |

 ### ポゼッシブデュアル

二重所有格は、二重代名詞に属格マーカーを追加するパターンに従います。 

| 代名詞 | 所有欲 | 翻訳 |
 |----------|-----------|---------------|
 | *グウェント* | *グウェニン* | 「私たち二人」 / 「私たち二人」 |
 | *濡れた* | *ウェニン* | 「お二人の」 |
 | *送信済み* | *仙人* | 「あの二人のうち」 |

 より一般的には、二重所有接尾辞 *-em* または *-em* が名詞に付加されることがあります (Quenya パターン *-t* 二重所有接尾辞 + *-va* 所有格に従います)。 

- ᴺS. *bedhwen* = 「私たちの 2 人 (人々) の言葉/道」 (*bêd* + *-wen* = 二重所有格?)

 これらの形式は大部分が再構築されています。 学習者はこれらを注意深く使用し、ネオシンダール語としてマークする必要があります。

 ## 4. 二重名詞

 トールキンのシンダール語では、名詞の二重表現は完全には文書化されていません。 ただし、いくつかのソースから情報を抽出できます。 

### サフィックス *-at* / *-ad*

 トールキンは二重名詞の接尾辞を文書化しています (クエンヤでは *-t* であることが最も明確です)。 シンダール語/ノルドリン語の場合、二重名詞の接尾辞は **-ad** (原始的な *-at* から) のように見えます。 

| 単数 | デュアル | 翻訳 |
 |----------|------|---------------|
 | *カウ* (カラス?) | ᴺS. *カワド* | 「一対のカラス」 |
 | *ラム* (舌) | ᴺS. *ラマド* | 「一対の舌」 |
 | *ペス* (単語) | ᴺS. *ペサド* | 「一対の単語 / 2 つの単語」 |

 この *-ad* サフィックスは再構築されます。 実際のシンダール語では、ペアは形態学的双対ではなく、*tad* (2) + 名詞で表現されることがよくあります。 

### ボディパーツ: ナチュラルペア

 自然にペアになっているボディ パーツはデュアルを使用できます。 

| 体の部位 | 単数 | デュアル/ペアフォーム | メモ |
 |----------|-----------|------|------|
 | 目 | *編* | *ヘント* (?) | *hent* = 「アイペア」? 参照。 アモン *ロー* |
 | 手 | *カム* | *camaд* (ᴺS.) | |
 | 耳 | *まあ* | — | *アモン・ロー* = 「耳の丘」 |
 | ウィング | *ローヴァル* | *ロヴァルト*? (ᴺS.) | トロンドールには 2 つの翼があります。

 ## 5. 動詞の二重形式

 動詞の主語が二重である場合、動詞は二重の接尾辞を取ることがあります。 ノルドリン語/シンダール語では、これは断片的にのみ文書化されています。 トールキンのメモから再構成された、ありそうなパターン:

 ### 二重動詞接尾辞

 **一人称二重:** 動詞の接尾辞 *-m* または *-nc*:

 - ᴺS. *tirionc* = 「二人で見ます」 (*tir-* + *-ionc*)
 - ᴺS. *linnenc* = 「二人で歌う」 (*linn-* + *-enc*)

 **三人称二重:** 動詞の接尾辞 *-nt* または *-t*:

 - ᴺS. *tirint* = 「あの二人が見ている」 (*tir-* + *-int*)

 これらの形式は非常に不確実であり、ほとんどの新シンダール語作家は二重代名詞を伴う通常の複数形を使用することを好みます。 

- *Sent tirir* = 「彼らは 2 人で見ています」 (複数形 *tirir* + 二重代名詞 *sent*)

 これはより安全で、学習者にとってより一般的に推奨されるアプローチです。

 ## 6. トールキンの名前の二重性

 トールキンはシンダール語で常に二重形式を明示的にラベル付けしているわけではありませんが、「その 2 つ」の概念は彼の地名と登場人物の名前に浸透しています。 

### *アモン・ヘン* と *アモン・ロー*

 ラウロスの滝にあるこれら 2 つの丘は、明示的に名前が付けられたペアを形成します。 
- *アモン ヘン* = 「目の丘」 (*アモン* = 丘、*ヘン* = 目)
 - *アモン・ロー* = 「耳の丘」 (*アモン* = 丘、*ロー* = 耳)

 それらは「見る座」と「聞く座」、つまり知恵と認識に対応する 2 つの大きな感覚として説明されています。 これらは一緒になって概念的な二重構造を形成します：目 + 耳 = 充実した知覚。 

### *エフェル・ドゥアス* と *エレッド・リスイ*

 モルドールを囲む 2 つの山脈、影の山脈と灰の山脈は、概念的に二重の取り囲むペアを形成します。 

### *エラダン* と *エルロヒル*

 エルロンドの双子の息子 - 二人組のエルフの戦士。 それらの名前は並列しています。 
- *Elladan* = *El-* (スター/エルフ) + *dân* (男性、ダニアンエルフ)
 - *エルロヒル* = *エル-* (スター/エルフ) + *ロヒル* (馬主)

 ### *Galathilion* と *Celeborn* (Two Trees の前身)

 2 本の木 *テルペリオン * と *ローレリン * (クエンヤの名前) は、シンダール語で *ガラティリオン * (テルペリオンのイメージ) と呼ばれ、トールキンの神話全体に登場する銀と金の二重性を持っています。

 ## 7. 文化的背景: エルフのペア愛

 トールキンはエルフを**バランスと二元性**に深く同調した民族としてデザインしました。

- 光と影 (*calad* / *dúath*)
 - シルバーとゴールド (*セレブ* / *ローラ*)
 - 海と陸 (*gaear* / *dor*)
 - 記憶と希望 (*dîr* / *estel*)
 - 星と太陽 (*êl* / *anor*)

 このペアの文化的な愛は、文法上の双対性、つまりエルフが単数形と複数形では表現できない「2 つを 1 つのユニットとして」表現できるようにする機能に反映されています。 エルフが *アモン ヘン、アモン ロー* と言うとき、彼らは単に 2 つの丘を挙げているわけではありません。 それらは概念的な全体、つまり完全な知覚装置を表現しています。

 ## 8. 最新の使用法: 学習者はデュアルを使用する必要がありますか?

 **新シンダール語学習者への実践的なアドバイス:**

 シンダール語の双対は、**最も証明されていない** 文法数です。 最も経験豊富な新シンダール語の作家や教師は、次のアプローチを推奨しています。 

| 状況 | 推薦 |
 |----------|------|
 | カジュアル/会話的な新シンダール語 | デュアルをスキップします。 複数形を使用する |
 | 詩的/形式的な構成 | 代わりに *tad* (2) + 名詞を使用してください。 
| 学術/学術活動 | 二重の証拠に注意し、再構成を明確にマークする |
 | 自然なペアについて | 二重代名詞 *sent* を通常の複数動詞と一緒に使用することもできます。 

**最も安全な戦略:** 動詞の通常複数形 + 二重代名詞を使用します。 例:

 - 不確かな *tirionc* (二人で見ます) の代わりに、次のように言います: *Gwent tirir* = "二人で見ます" (動詞の複数形 + 二重代名詞)
 - 不確実な二重名詞の代わりに、次のように言います: *tad edhil* = 「二人のエルフ」 (数字 + 名詞)

 ## 10. 練習問題

 **練習問題 1:** 必要に応じて二重代名詞を使用して、次の文を翻訳してください。 

1.「二人で歌う」（あなたと私）
 2.「あの二人が塔に来た」
 3.「両目の時計」

 **演習 2:** これらのシンダール語の地名/人名に含まれる概念的な二重性を特定します。 ペアを形成する 2 つのものは何ですか?

 1. *アモン・ヘン* と *アモン・ロー*
 2. *エラダン*と*エルロヒル*
 3. *Nef aear, sí nef aearon* (*A Elbereth Gilthoniel* より — 何がペアになっているかを特定する)

 **演習 3:** より安全な戦略 (複数動詞 + 二重代名詞) を使用して、次のように表現します。 
1. 「二人は行かなければなりません」 (*boe* + *wet* + *men-* を使用)
 2. 「あの二人が王様だ」 (*sent* + *na-* + *erain* を使用)

 ### 回答キー

 1.
 - *Gwent linnir* (包括的: あなたと私が歌う) または *Unc linnir* (排他的: 彼/彼女と私)
 - *Sent tolant erin varad* (複数過去 *tolant* + 二重主語 *sent*)
 - *I hent tirr* (「アイペアウォッチ」の場合は複数形を使用、または単位として扱う場合は 3sg で *I hent tir*)

 2.
 - 目 / 耳 — 視覚と聴覚の 2 つの感覚
 - ダニアンのエルフ / 馬の王 — 双子の兄弟で結ばれた 2 つの異なる文化遺産
 - *Nef aear* (海のこちら側) / *nef aearon* (大海のこちら側) — 憧れの修辞単位を形成する、近い/遠い参照のペア

 3.
 - *濡れた男たち* = 「二人で行く必要があるよ」
 - *Sent nârerain* = 「あの二人は王だ」 (二重主語には複数形の *nâr* を使用)
