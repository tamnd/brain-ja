## レニションとは何ですか?

 ソフト突然変異 - **lenition** (ラテン語の *lenis*、「柔らかい」に由来) とも呼ばれる - は、シンダール語で最も一般的かつ重要な音の変化です。 それはランダムではありません。 これは、先行する単語が適切な音韻環境を作り出すときに、単語の最初の子音が弱くなるか移動する、体系的で歴史的に条件づけられたプロセスです。 

ケルト言語にもまったく同じ特徴があります。 ウェールズ語、アイルランド語、ブルトン語はすべて、先行する文法上の単語によって引き起こされる最初の子音突然変異のシステムを持っています。 トールキンは、シンダール語の突然変異システムをケルト言語、特にウェールズ語に直接モデル化しました。 

古シンダール語 (シンダール語の祖先) では、前の単語の特定の最後の母音または子音によって、次の最初の子音が弱くなりました。無声終止符は有声終止符になり、有声終止符は霊音になり、一部の子音は完全に消えました。 古典シンダール語までに、これらの誘発音はしばしば侵食されてしまいましたが、それらが引き起こした突然変異は、形態学にコード化された文法の化石として残りました。 

結果: 名詞の後に形容詞、動詞の後に直接目的語、定冠詞 *i* の後に名詞、または特定の前置詞の後に名詞がある場合、次の単語の最初の子音は予測可能な表に従って変化します。

 ## 完全なソフト突然変異テーブル

 | オリジナル | 突然変異 | プロセス |
 |----------|-----------|----------|
 | **p** | **b** | 無声ストップ → 有声ストップ |
 | **t** | **d** | 無声ストップ → 有声ストップ |
 | **c** | **g** | 無声ストップ → 有声ストップ |
 | **b** | **v** | 有声停止 → 有声スピラント |
 | **d** | **dh** | 有声停止 → 有声スピラント |
 | **g** | **(消える / ')** | 有声停止→ゼロ（完全に失われる） |
 | **m** | **v** | 鼻音 → 有声音 |
 | **h** | **ち** | 声門摩擦音 → 軟口蓋摩擦音 |
 | **s** | **h** | 歯擦音 → 声門摩擦音 |
 | **lh** | **l** | 無声横→有声横 |
 | **rh** | **r** | 無声トリル → 有声トリル |

 **ソフト突然変異下で突然変異しない子音:** f、l、r、n、v、w - これらは変更されません。 

最も劇的な変化は **g → ゼロ** です。ソフト突然変異が *g* で始まる単語に適用されると、最初の *g* が単に消え、ギャップを示すために声門閉鎖またはアポストロフィが書き込まれることがあります。 これは、ソフト突然変異トリガー後の *'aladh* (*galadh*、「木」から) のような形式のソースです。

 ## トリガー カテゴリ 1: 名詞の後の形容詞

 日常のシンダール語で最も一般的なトリガー。 名詞に続いて名詞を修飾する形容詞は、その最初の子音でソフト突然変異を受けます。 これは、名詞の最後の母音が次の単語の寛容を引き起こす古シンダール語のパターンを直接反映しています。 

| 名詞 | 形容詞（ベース） | 名詞 + 形容詞 | 英語 |
 |------|---------------|------|------|
 | *アラン* | *ベレグ* (素晴らしい) | *アラン・ベレグ* | 偉大なる王 |
 | *アイスロン* | *calen* (緑) | *イスロン・ガレン* | 緑の魔法使い |
 | *ガラド* | *glân* (白) | *ガラドラン* | 白い木（Gが消える！）
 | *アモン* | *朝* (暗い) | *アモン・ボーン* | 暗い丘 |
 | *エドヘル* | *ベイン* (美しい) | *エーデル・ヴェイン* | 美しいエルフ | 写真
 | *ドール* | *タウル* (偉大な、広大な) | *ドールダール* | t→d: 素晴らしい土地 |
 | *ペン* | *スル* (風が強い) | *ペンハル* | s→h: 風が強い頭/頂上 |
 | *オーク* | *dûr* (暗い) | *オルク・ドゥール* | d→dh：ダークオーク |
 | *こんにちは* | *hain* (熟練) | *ヒアチェーン* | h→ch: 熟練の領主 |
 | *ラグ* | *廃墟* (赤い炎) | *廃墟* | rh→r: 紅炎の竜 (ここでは lh 自体が基本形です) |

 **g → zero** が明らかに変化していることに注意してください。 *galadh* + *glân* → 形容詞 *glân* は *gl-* で始まりますが、*g* のみが変化します。 *lh* は、最初の子音のみが突然変異のターゲットであるため、ここでは影響を受けません。 *Glân* は *g* で始まるため、ソフト突然変異後は *glân* → *lân* となります。

 ## トリガー カテゴリ 2: 動詞の直接目的語

シンダール語では動詞-主語-目的語 (VSO) の語順が使用されます。 直接オブジェクト、つまりアクションを受ける名詞はソフトミューテーションを受けます。 これは、古シンダール語で、物体をマークする先行粒子によって引き起こされ、その後侵食されて消えていきました。 

| 動詞句 | オブジェクト (ベース) | 全文 | 翻訳 |
 |-----------|--------------|------|---------------|
 | *ティロン* (私は見ます) | *バラド* (タワー) | *ティロン・ヴァラド* | 私は塔を見ます |
 | *セニン* (なるほど) | *calen* (緑の[物]) | *セニン・ガレン* | 緑色の[もの]が見えます |
 | *ペディン* (私が話します) | *pân* (板/単語) | *ペディンバン* | 私は言葉を話します |
 | *Cawin* (私が作ります) | *dôr* (土地) | *カウィンドール* | 私は土地を作る/形を作る |
 | *ゲリン* (私は持っています) | *ミル* (愛) | *ジェリンヴィル* | 私には愛があります |
 | *リノン* (私は歌います) | *tîr* (監視/警備) | — | (自動詞的な意味) |

 代名詞が目的語として機能する場合 (例: *hain*、「them」)、代名詞には独自の形式があるため、代名詞自体に子音の突然変異は発生しません。 直接オブジェクトのソフト突然変異は、**名詞** オブジェクトの特徴です。 

---

 ## トリガー カテゴリ 3: 単数定冠詞 *i*

 単数定冠詞 *i* (the) は、後続の名詞のソフト突然変異を引き起こします。 完全なパラダイム:

 | 頭の子音 | 冠詞 + 名詞 (ベース) | 突然変異したフォーム | 例 |
 |-----------------|----------------------|--------------|----------|
 | **p** | *i* + *ペリアン* | *私ベリアン* | ホビット |
 | **t** | *i* + *タウル* | *だわ* | 森 |
 | **c** | *i* + *coth* | *わかった* | 敵 |
 | **b** | *i* + *バラド* | *私はバラド* | 塔 |
 | **d** | *i* + *dîr* | *私は* | 男 |
 | **g** | *i* + *ガラド* | *私はアラド* | 木 |
 | **m** | *i* + *メロン* | *私はベロン* | 友人 |
 | **h** | *i* + *hir* | *ちーる* | 主 |
 | **s** | *イ* + *スル* | *私は* | 風 |
 | **lh** | *i* + *lhug* | *私は* | ドラゴン |
 | **rh** | *i* + *ルン* | *私は走ります* | 東 |

 変異しない子音: *i lass* (葉 — l 変化なし)、*i nîn* (水 — n 変化なし)、*i vorn* — 待て、*vorn* にはすでに v があります。 *i fêr* (ブナの木 — f 変化なし)。 

---

 ## トリガー カテゴリ 4: ソフト突然変異を管理する前置詞

 いくつかのシンダール語前置詞では、次の名詞にソフト突然変異が必要です。 この突然変異は、古シンダール語において前置詞自体の音韻的形状によって引き起こされました。 

| 前置詞 | 意味 | 例 | 分析 |
 |---------------|-----------|----------|----------|
 | *アブ* | 後、後ろ | *アブディール* | d → dh: 男の後 |
 | *アデル* | 後ろ、後ろに | *アデル・ヴァラド* | b → v: 塔の後ろ |
 | *午前* | 上、上 | *私は生まれています* | m → v: 暗闇の上で |
 | *お父さん* | 下へ、下へ | *父のゲーレン* | c→g: 緑色の下り坂 |
 | *ディ* | 下、下 | *ディ ダール* | t → d: 森の下 |
 | *な* | に、向かって | *ナヴァール* | b→v:海に向かって |
 | *ヌ* | 下、下 | *ヌードール* | d → dh: 陸地の下 |
 | *トリ* | |を通して *トリ・ヴァラン* | b → v: ゲートを通過 |
 | *ú-* | なし、非 (否定) | *ú-'aladh* | g → ゼロ: ツリーなし |
 | *o / od* | から、の | *メネル* | mは変化しません。 *o Eregion* (E 変更なし) |

 注: *o/od* はソフトミューテーションをトリガーしますが、多くの単語は母音または非ミュータブル子音で始まるため、トールキンの例では変更されていない子音が表示されることがよくあります。 *o* + *barad* のソフト突然変異は、(塔からの) *o varad* を与えます。 

---

 ## トリガー カテゴリ 5: 特定の前置詞の組み合わせの後 (プレビュー)

 いくつかの前置詞が定冠詞 *i* (the) と結合すると、その結果生じる融合形式は、純粋なソフト突然変異ではなく **混合突然変異** を引き起こす可能性があります。 このトピックについては、レッスン 30 (混合突然変異) で詳しく説明します。 例:

 - *na + i* → *nei/nî* → 混合突然変異をトリガーします
 - *o + i* → *uin* → 混合突然変異をトリガーします
 - *an + i* → *erin* → 鼻の突然変異を引き起こします (レッスン 15 を参照)

 現時点では、前置詞が不定名詞の前に単独で存在する場合にソフトミューテーションが適用されることを知っておいてください。 定冠詞が前置詞と融合すると、突然変異の種類が変わることがあります。 

---

 ## トリガー カテゴリ 6: 指示/直接アドレス

誰かを名前または肩書きで直接呼ぶ場合、ソフトミューテーションが名前の最初の子音に適用されることがあります。 これはおそらく、古シンダール語の先行する助詞 *a* によって引き起こされたと考えられます。 

| 基本フォーム | アドレス指定されたフォーム | コンテキスト |
 |----------|------|----------|
 | *セリル* | *ゲリルです!* | Celir という名前の人に宛てて |
 | *ペリアン* | *ベリアンです!* | ホビットに話しかける |
 | *ドゥナダン* | *ドゥナダン!* | ドゥーネダインに対処する |

 証明済み: *A Elbereth!* — *Elbereth* は母音で始まるため、子音の突然変異は見られません。 呼び助詞 *a* がトリガーです。 

---

 ## トリガー カテゴリ 7: 感嘆符の *o* の後

 感嘆符内の名前の前に使用される間投詞 *o* (O!、oh!) もソフト突然変異を引き起こします。 

- *O Hîr Vithren!* = 「おお灰色の主よ!」 (*ミスレン* → *ヴィトレン*、m → v)

 ## ソフト突然変異と突然変異なし

 ソフト ミューテーションを適用すべきでない場合を知ることは、適用すべき場合を知ることと同じくらい重要です。 

**変異させないでください:**
 1. **文の最初の単語** — 突然変異は、先行する単語によって引き起こされるサンディ効果です。 文頭の単語の前には何もありません
 2. **複合名詞内の単語** — 複合名詞の内部の継ぎ目は常に突然変異を引き起こすわけではありません。 *Barad-dûr* には、継ぎ目で *dûr* が変異していない (ただし、一部の化合物には変異が見られる)
 3. **単独の固有名詞** — 名前が先行するトリガーワードなしで独立した固有名詞として使用される場合、その名前は引用形式で表示されます。 
4. **非トリガー前置詞の後** — すべての前置詞がソフトミューテーションをトリガーするわけではありません。 *an* はソフト突然変異ではなく、鼻の突然変異を引き起こします (レッスン 15)
 5. **子音はソフト突然変異から免除されます** — f、l、r、n、v、w は、トリガーに関係なく、ソフト突然変異の下で突然変異することはありません

 ---

 ## よくある間違い

 | 間違い | 訂正 | 説明 |
 |----------|-----------|---------------|
 | *f* を *v* に変更します | *f* は突然変異しません | *f* はソフト突然変異から除外されます。 
| *g*を忘れるのは消えます | *g* → ゼロ (*g* → *gh* ではない) | 結果は子音ではなく、「 |」でマークされます。 
| 文の最初の単語に突然変異を適用する | トリガーされた単語のみが変化します | 最初の単語には先行するトリガーがありません |
 | 鼻の突然変異のコンテキストで *d* を *dh* と書く | *dh* はソフト突然変異です。 *d* → *n* 鼻音 | さまざまなトリガー、さまざまな変更 |
 | 複合名詞内の変異 | 化合物は多くの場合、基本的な形式を保持します。 証明された例を確認してください。 仮定しないでください |
 | 形容詞を変化させるのを忘れて名詞を変化させる | 名詞は変化しません。 形容詞はそうする | トリガーは名詞です。 ターゲットは形容詞です |

 ## 練習問題

 各フレーズにソフト ミューテーションを正しく適用します。 

1. *i* + *taur* (森) = ?
 2. *amon* (丘) + *calen* (緑) = ?
 3. *i* + *galadh* (木) = ?
 4. *na* + *barad* (塔) = ?
 5. *エドヘル* (エルフ) + *スル* (風) = ?
 6. *i* + *morn* (暗い) = ?
 7. *nu* + *dôr* (土地) = ?
 8. *アラン* (王) + *バイン* (美しい) = ?
 9. *ú-* + *gûr* (心/意志) = ?
 10. *i* + *hîr* (主) = ?

 **答え:** (1) *i daur* (2) *amon galen* (3) *i 'aladh* (4) *na varad* (5) *edhel hûl* (6) *i vorn* (7) *nu dhôr* (8) *aran vain* (9) *ú-'ûr* (10) *i chîr*
