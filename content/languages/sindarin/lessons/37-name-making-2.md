## はじめに

 シンダール語の個人名は贈り物です。つまり、人の性質、外見、血統、運命についての重要な点を捉えた圧縮された詩です。 トールキンのエルフは命名を高度な芸術として扱い、彼が登場人物のために考案した名前は、あらゆる人工言語の中でも最も美しい言葉の 1 つです。*ガラドリエル*、*ルーシエン*、*セレブリンボール*、*グロールフィンデル*、*ティンヌヴィエル*。 それぞれが意味のミニチュア世界です。 

このレッスンでは、トールキンが *Unfinished Tales* で説明したエルフの命名伝統、主な男性名と女性名の名前要素とその光沢、父称の仕組み、エルフがどのように形容名を獲得するかを学びます。 レッスンは、独自のエルフの個人名を作成するための段階的なガイダンスで終了します。

 ## 1. エルフの命名の伝統

 ### 3 つの名前

 トールキンは、エッセイ「フェアノールのシボレス」と、*未完成の物語*と*中つ国の人々*の関連メモでエルフの命名習慣を詳細に説明しました。 エルフは **最大 3 つの名前**を持つことができます:

 **1. *アタレス* — 父親の名前**

 出生時に父親によって与えられる言語は、通常はクエンヤ語（ノルドール族の高級言語）またはシンダール語（シンダール族の言語）です。 父親の名前は、血統における子供の位置を反映しています。多くの場合、父親自身の名前を反映しているか、父系の要素が含まれています。 この名前は「公式」であり、正式な文脈で使用されます。 

例:
 - *エルロンド* はエルロンドの父親の名前です (父親のエアレンディルによって与えられました)
 - *フィンドゥイラス*は父親のオロドレスから父親の名前を受け取ります

 **2. *Óressë* — 母親の名前**

 多くの場合、父親の名前よりも遅く、母親の直観が子供の内面の性質や運命について何かを把握したときに、母親によって付けられます。 母親の名前は**予言的な**ことが多く、子供の運命や性格、場合によっては母親の悲しみや予知を反映している場合もあります。 

有名な母親の名前:
 - *マエドロス*は、母親の名前をネルダネルから受け取りました（*ルサンドル*、彼の珍しい赤みがかった髪から「銅のトップ」、典型的なノルドリンではありません）
 - ミリエルが付けたフェアノールの母親の名前: "フェアノール" = *ファエノール* (クエンヤ *フェアナーロ*、「火の精霊」のシンダール語形) — 彼女は彼の燃えるような創造性を予見していました

 **3. *キルメッセ* — 選ばれた名前 (エペセ)**

 大人になってからエルフ自身が選んだもの、または他人から与えられて受け入れられたもの、行為や性質に基づく**形容**。 *epessë* (「名前にちなんだ」) とも呼ばれます。 これは、伝説の人物に最も関連付けられる名前です。 
- *エルカミオン* = 「片手」 (カルカロトに手を失った後のベレンのエペッセ)
 - *Cúthalion* = 「強い弓」 (ベレグのエペッセ、弓の腕前)
 - *ミスランディル* = 「灰色の放浪者」 (ガンダルフのシンダール語エペッセ、彼を知るエルフによって与えられたもの)

 ### シンダール語とクエンヤ語の名前

 第三紀までに、シンダール語を話す文化 (シンダール、中つ国のノルドール、グレイエルフ) では、日常生活で主にシンダール語の名前が使用されました。 クエンヤは伝承、儀式、高尚な談話のために保存されました。 トールキンがエルフ文字のシンダール語形式を教えてくれたとき、これらは日常的に使用される名前です。 
- ハイエルフ *アルタニス* → シンダール語 *ネルウェン* → エペッセ *ガラドリエル*
 - *Curufinwë* → シンダール語 *Curufin*

## 4. 有名人の分析 - 詳細な内訳

 ### 1. *アラゴルン*
 > *ara-* (高貴な、王のような — *アラン* 王に関連する) + *gorn* (*gor-* またはおそらく「衝動的な」からの尊敬/恐怖)

 トールキン自身のメモ: *アラゴルン* は、「尊敬される王」または「王の恐怖」に関連する語源に由来している可能性があります。 アラゴルンは高貴 (*ara-*) であると同時に、敵に恐怖を引き起こす (*gorn*) という名前がぴったりです。 彼は「畏怖の念を抱かせる王」です。 

### 2. *レゴラス*
 > *lego* または *laeg* (鋭い、敏捷性 — おそらく「グリーン」、*laeg* = 鋭い、新鮮/緑から) + *lass* (葉)

 トールキンのグロス: **「Greenleaf.」** *Lasgalen* (*Eryn Lasgalen* = Wood of Green Leaves のように) は同じ *las/lasg/laeg* ルートを使用します。 レゴラスは、森の緑の葉、機敏で自然な生き物です。 

### 3. *ガラドリエル*
 > *galad* (輝き、光 — *cal-/gal-* ルートから) + *riel* (花輪の乙女 — *rig-* から wreathe + *-iel*)

 トールキンの説明：「輝く花輪を冠した乙女」。 *galad* 要素は *Galadrim* (木の人々) に接続します。両方とも光/成長ルート *GAL-* を共有します。 ガラドリエルは単なる「美しいエルフ」ではなく、まさに輝く創造的な光の体現であり、彼女の性質が彼女の名前に凝縮されています。 

### 4. *エルロンド*
 > *el* (星、エルフ — *EL-* ルートから) + *rond* (金庫、ドーム状のアーチ、空のように湾曲した洞窟の天井)

 意味: **「スタードーム」** または「星の金庫」。 エルロンドの兄弟は *エルロス* (*エル* + *ロス* = "星の泡") です。 兄弟はどちらも *el* (星) の要素を持っています。彼らは天の下で生まれた星の船乗りエアレンディルの子供です。 エルロンドの名前は、星空が広がる広大なドーム状の空をイメージしています。 

### 5. *セレブリンボール*
 > *celeb* (シルバー) + *rim* (大きな数字? またはここから *rimbor* = 拳) + *bor* (手/拳)

 トールキンの光沢: **「銀の拳」** *リム* 要素は、強力で熟練した手である *リンボール* (拳) の変形である可能性があります。 ケレブリンボルは第二紀の最も偉大な鍛冶屋でした。 彼の拳/手は銀細工に熟練していた。 彼の名前は彼のクラフトアイデンティティです。 

### 6. *グロールフィンデル*
 > *glor-* (黄金の栄光、*GLOR-* ルートから、金と輝きに関連) + *find* (髪、房、髪の房) + *-el* (存在/人)

 意味: **「金色の髪」** 彼の金色の髪は有名でした。 3 つの要素の名前は珍しいですが、それぞれの部分は必須です: *glor-* (髪の色の品質)、*find* (髪そのもの)、*-el* (この髪を持つ人)。 

### 7. *ハルディール*
 > *hal-* (背の高い、高い — *KHAL-* ルートから: 持ち上げる、高める) + *dîr* (男性、成人男性)

 意味: **「背の高い男」**、より正確には「高貴な人」。 ハルディールはローリアンの行軍監督であり、高い地位と体格を備えた人物です。 この名前は完全に機能的です。 

### 8. *フィンドゥイラス*
 > *find* (髪、房) + *ui* (常に、常に、永久 — 時間的要素) + *las* (葉)

 トールキン自身のテキストには決定的な光沢がまったくありません。 考えられる意味: **「Ever-leaf of Hair」** (永遠の葉のような髪)、または永遠に美しいものを表す詩的な複合語。 この名前には、若くして亡くなったオロドレスの悲劇の娘であるフィンドゥイラスにぴったりの、流れるような憂いのある性質があります。 

### 9. *メーグリン*
 > *maed/maeg* (鋭い、刺すような – 目、知性の) + *glin* (輝き、輝き – 目、剣; 閃光と洞察力)

 トールキンの魅力: **「鋭い視線」** メーグリンは、その鋭い視線と二重の心で知られていました。彼の知性は彼の最大の才能であり、彼の破滅でもありました。 彼の名前には、彼の認識と危険な内なる性質の両方が凝縮されています。 

### 10. *ティンヌヴィエル*
 > *tinn-* / *tin-* (火花、小さな星の点 — ナイチンゲールの目の小さな光?) + *dúv-* (*dû*、夜、日暮れ、夕暮れの薄暗さに関連) + *-iel* (乙女)

 トールキンの表現: **「ナイチンゲール」** (文字通り「黄昏の火花の娘」または「黄昏の火花の彼女」)。 ベレンは、夕暮れの森の中でナイチンゲールの歌のような声で踊る彼女を初めて見たときに、ルーシエンにこの名前を付けました。 *-iel* はそれを個人的で親密なものにします。彼女は *ナイチンゲールの乙女です。

 ## 5. 父称の構築

 ### 息子: *-ion*

 > 父親の名前 + *-ion* → 「[父親] の息子」

- *レゴラシオン* ᴺS. = レゴラスの息子
 - *エルロンディオン* ᴺS. = エルロンドの息子 — ただし、トールキンはエルロンドの息子として *エラダン* と *エルロヒル* を使用しています。 
- *エルダリオン* = エルダールの息子? いいえ、*エルダリオン*はアラゴルンの息子です。 分析: *Eldar* (エルフの人々) + *-ion* = 「エルダールの息子」 (比喩的に: エルフの血統の息子)

 ###: *-iel* の娘

 > 父親の名前 + *-iel* → 「[父親] の娘」

 - *エアレンディリエル* ᴺS. = エアレンディルの娘
 - *アラニエル* ᴺS. = 王の娘 (一般: *aran* + *-iel*)

 ### 完全属格構造

 父称の別の形式では属格を使用します。 
> *[子供の名前] [イオン/アイエル] en [父親の名前]*

 - *アルウェン・エル・エン・エルロンド* ᴺS. = アルウェン、エルロンドの娘

 *Ion* (息子) と *iell* (娘) は息子と娘を表すシンダール語です。 
- *イオン* = 息子 — ᴺS. (証明された形式については議論があり、学者によっては *ион*/*yôn* を好む人もいます)
 - *iell* = 娘 — ᴺS. (*エール*または関連フォームから)

 ## 6. 異名: エルフはどのようにしてわかりやすい名前を獲得するのか

 エルフの形容詞 (クエンヤ語では *epessë*、シンダール語では単に追加の名前) は、次の方法で得られます。 

### 行為に基づく形容詞

 注目に値する行為を行ったエルフは、それを説明する形容詞を受け取ります。 

| 別名 | 意味 | ベアラー |
 |----------|--------|----------|
 | *クータリオン* | 強い弓 | 偉大な射手ベレグ | 写真 偉大な射手ベレグ
 | *エルカミオン* | 片手 | ベレン (カルチャロスが手を噛みちぎった後) |
 | *モルメギル* | 黒の剣 | トゥーリン (黒い刃 *グルタン*) |
 | *シンゴル* | 灰色のマント | エルウェ (シルバーグレーのローブの場合) |

 ### 外観に基づく形容詞

 | 別名 | 意味 | ベアラー |
 |----------|--------|----------|
 | *セレブリンダル* | シルバーフット | イドリル (銀白色の足) |
 | *サルガント* | — | — |

 ### 役割/機能の略語

 | 別名 | 意味 | ベアラー |
 |----------|--------|----------|
 | *ミスランディル* | 灰色の放浪者 | ガンダルフ |

 ### 独自のエピテットの作成

 エピテットは次のことを行う必要があります。 
1. 本質的な性質、行為、または外観の特徴を 1 つ説明します
 2. 2つの要素（品質＋人・物）から形成されること
 3. レッスン 35 で学習したパターン (サフィックス *-dir*、*-wen*、*-ion*、*-iel* など) を使用します。 
4.大声で話したときに自然に聞こえる

 ## 7. 名前作成の演習: 5 つの完全なエルフの個人名を作成します

 ### プロセス

 **ステップ 1**: キャラクターの本質的な性質または最も注目すべき性質を選択してください
 **ステップ 2**: これを表すシンダール語の単語を見つけます
 **ステップ 3**: キャラクターに適した男性的または女性的な結末を選択してください
 **ステップ 4**: 結合、音韻チェック、音読
 **ステップ 5**: ᴺS にラベルを付けます。 そして意味に注目してください

 ### 使用例 1: 歌が上手な男性のエルフ

 1. 歌唱力
 2. 要素: *lind-* / *glin-* (歌、歌) + *-dir* (男) または *-ron* (素晴らしい)
 3. 男性的
 4. *リンドロン* ᴺS. = 「偉大な歌手」または *リンディル* (すでに名前として証明されています!)
 5. *グリンディル* ᴺSを使用します。 = 「Gleam-Singer、その歌が輝く人」より詩的なものを表現する

 ### 作業例 2: スターライトに関連付けられた女性のエルフ

 1.品質: スターライト
 2. 要素: *elen* (星) + *-iel* (乙女) → *Eleniel* ᴺS。 (スターメイデン) — または
 *ギルウェン* ᴺS. (*ギル* 明るい星 + *-ウェン* 乙女) — 音韻的によりスムーズ
 3.フェミニン
 4. *ギルウェン* ᴺS. ――「輝星の乙女」
 5.マークᴺS。 注: *gil* (星、明るい火花) はシンダール語で証明されています。 *-wen* が証明されました

 ### 制作例 3: 銀髪の男性エルフ領主

 1.品質: 銀髪
 2. 要素: *セレブ* (シルバー) + *検索* (ヘア) + 男性的なエンディング
 3. *セレブ検索* ᴺS。 または *セレブフィンディル* ᴺS。 (銀髪の男)
 4. チェック: *セレブ* + *検索* = *セレブ検索* ᴺS。 — 珍しい子音クラスター *-bf-* は、次のように単純化される可能性があります: *Celebfind* → おそらく *Celebinn* ᴺS.?
 5. 代替アプローチ: *ミセラス* ᴺS。 — 髪が灰色がかった銀色の場合、灰色の葉 (*ミス* + *ラス*)

 ### 使用例 4: 黄昏と神秘を本性とする女性エルフ

1. 品質: トワイライト、ミステリー
 2. 要素: *dû-* (夜、夕暮れの薄暗さ) + *fain* (白、輝く - 逆説的: 彼女は暗闇の中で輝く)
 3. フェミニン: + *-iel* または *-wen*
 4. *ドゥファイニエル* ᴺS. = 「黄昏の輝きの乙女」 - *ティンヌヴィエル*のパターンのような名前
 5. またはもっと簡単: *Dúwen* ᴺS。 =「夜巫女、黄昏少女」

 ### 使用例 5: 素早い馬術で有名な男性のエルフ

 1.品質: 速い馬
 2. 要素: *roch-* (馬) + *-dir* (男) または *caer-* (速い/偉大) + *roch-*
 3. *ロクディル* ᴺS。 =「ホースマン」（単刀直入に）
 4. さらに刺激的: *Rochallor* — 待て、*Rochallor* はフィンゴルフィンの馬の名前であることが証明されている! 個人名のテンプレートとして使用します: *roch* + *-allor* (標準ではない *alor*? から)
 5. ベスト: *ロシオン* ᴺS. =「馬の息子」（比喩的：馬に捧げる人）または*Brethilroch* ᴺS。

 ## 8. クイック リファレンス: 名前構築のチートシート

 ### 男性的な名前の場合:
 - 品質要素から始めます: *ar-*、*beleg-*、*celeb-*、*el-*、*glor-*、*hal-*、*thal-*
 - 末尾: *-dir* (男)、*-gon* (領主)、*-on* (偉人)、*-rond* (保管庫)、*-ron* (キーパー)

 ### 女性の名前の場合:
 - 光/自然要素から始めます: *cal-*、*fair-*、*lúth-*、*mith-*、*nim-*、*tin-*
 - 末尾: *-el* (人)、*-iel* (娘)、*-wen* (乙女)、*-del* (最愛の人)

 ### 目指すサウンド:
 - 流れる: *-nd-*、*-lm-*、*-rn-*、*-nth-* のような子音クラスター
 - 母音: *a*、*e*、*i* が最も一般的です。 *ó* と *û* は重力を加えます
 - 避けてください: 液体なしで複数回の過酷な停止 (*bktr* など)。 シンダール語の流れ

 ## 覚えておくべき重要なポイント

 1. **3 種類の名前**: 父親の名前 (*atressë*)、母親の名前 (*óressë*)、選ばれた愛称 (*kilmessë*)
 2. **母親の名前は予言的です**: 最も詩的に複雑な名前は運命を暗示していることがよくあります
 3. **男性性と女性性**: 最後の接尾辞 (*-dir/-ron* 対 *-el/-wen/-iel*) が主要な性別マーカーです
 4. **称号は行為によって獲得されます**: 中つ国で最も記憶に残る名前はエペッセです
 5. **作成前に分析**: 証明された名前を分解することは、どのルールリストよりも多くのことを教えます
