## このリファレンスの使用方法

 この補足は**マスター参考資料**であり、レッスンではありません。 レッスン 17 ～ 22 (動詞: 現在、過去、自動詞、未来、条件、不規則) を完了しており、完全なパラダイムを調べるための 1 つの場所が必要であることを前提としています。 レッスンの代わりとしてではなく、レッスンと並行して使用してください。 

ここでのすべてのパラダイムは、特別な注記がない限り、主要なフレームワークとして **RealElvish Academy / Strack 再構築** に従い、二次情報源として Jallings の *Learning Sindarin* に従います。 学者の意見が異なる場合は、その不一致にフラグが立てられ、実用的な推奨事項が与えられます。 トールキンの著作で直接証明されていない形式はすべて ᴺS とマークされています。 （新シンダール語の復元）。 

**必要なものを見つける方法:**
 - 特定の動詞については、動詞検索表 (セクション 9) を参照してください。 
- 動詞クラスの完全なパラダイムについては、セクション 3 ～ 6 を参照してください。 
- 時制マーカーのみ: クイックリファレンス表 (セクション 8) を参照してください。 
- 学術的な意見の相違については、セクション 7 を参照してください。 

表記に関する注記: **S.** = トールキンで直接証明されています。 **N.** = ノルドリン (シンダール語の初期の形式) で証明されています。 **ᴺS.** = ネオシンダール語の再構成。 注の前の**←** = 出典情報。

 ## 12 の動詞クラス

 シンダール語動詞は、**主動詞 (P) 動詞** と **派生 (A/D) 動詞** という 2 つの大きなグループに分けられ、その後、語根の終子音と派生履歴に基づいてより細かいサブクラスに分けられます。 

| クラス | 名前 | 説明 | 主な例 |
 |----------|------|---------------|---------------|
 | **P1** | プライマリー、ストップ-ファイナル | ルートは無声または有声停止で終わります (*p, t, c, b, d, g*) | *ped-* (話す)、*cab-* (跳躍)、*dag-* (殺す)、*mat-* (食べる) |
 | **P2** | 初等、鼻音/摩擦音-終音 | 根は鼻音 (*m, n*) または摩擦音 (*f, v, s, h*) で終わります。 *haf-* (座る)、*hen-* (目→見る) |
 | **P3** | 一次、最終液体 | ルートは *l* または *r* で終わります | *hal-* (リフト)、*pel-* (フェード) |
 | **A1** | P1 有声音からの類似 | P1 動詞は類推によって拡張されます。 歴史的に有声根 | *sog-* (飲み物) |
 | **A1a** | P1 無声からの類推 | P1 動詞の拡張。 歴史的に無声ルート | *tob-* (カバー) |
 | **A2** | P2からの類推 | 鼻/摩擦音の付け根をアナログ的に拡張 | *ドラフ* (ヒュー) |
 | **A3** | P3からの類推 | 類似拡張子を備えた液体ルート | *gar-* (ホールド、持つ) |
 | **A3a** | P3 (多音節) からの類推 | 長い A3 ルート | *トレナー-* (再集計) |
 | **D1** | 派生推移 (-a) | 名詞/形容詞から形成される動詞。 能動的/推移的な意味 | *teitha-* (書く)、*linna-* (歌う)、*noro-* (走る) |
 | **D2** | 派生自動詞 (-a) | 状態態/自動詞の意味を持つ動詞 | *muda-* (労働)、*esta-* (電話、名前) |
 | **D2a** | 強い過去を持つ使役 | 特別な使役 D クラス動詞 | *nimmid-* (白くする)、*orthad-* (上げる) |
 | **D3** | 派生、母音強化 | 不規則な派生動詞、多くの場合古代の複雑な語源に由来 | *anna-* (与える)、*elia-* (雨) |

 ### プライマリと派生: 主要な違い

 **一次動詞** は子音で終わる語根を持ち、通常は活用されていない語幹形式で 1 音節を持ちます: *ped-*、*cab-*、*mat-*。 過去形は **鼻注釈** によって形成されます。つまり、鼻音子音が語根の最後の子音の前に挿入されます。 これは古代の形成で、クエンヤの鼻の存在と同族です。 

**派生動詞** は *-a* で終わる語根を持ち (ただし、この *-a* は隠されている場合があります)、通常は名詞、形容詞、またはより複雑な動詞の語根に由来します。 過去時制は、**-ant 接尾辞** (D1/D2) または不規則な母音交代 (D3) によって形成されます。 接尾辞 *-ant* 自体は古い形式です (IE 言語の分詞 *-ant* に関連しています)。

 ## 完全なパラダイム: クラス P1 — *ped-* (話す)

 *ped-* はモデル P1 動詞です。 そのルートは *-d* (有声歯音停止音) で終わります。 証明された形式には、ドゥリンの扉の碑文にある *pedo!* (話す!) と *pedin* (私が話す) が含まれます。 

### アオリスト (簡単な現在/一般的な声明)

アオリストは、習慣的、一般的、または時代を超えた行動を表現します。「私は（一般的に）話します」、「彼女は（習慣的に）話します」、「話すことは私たちがしていることです」。 

形成: 語幹に直接付けられる人称接尾語。 P1 動詞では、語幹の母音が 3 人称単数 (「裸の」形式) で **長くなります**。 

| 人物 | フォーム | 翻訳 | メモ |
 |----------|------|---------------|----------|
 | 1sg | *ペディン* | 私は話します | ← S. 証明 (ドゥリンの扉) |
 | 2sgおなじみ | *pediг* → *pedigl* (議論; §7 を参照) | あなたは話します（親密な） | ᴺS. |
 | 2sg 丁寧 | *ペディル* | あなたは話します（フォーマル） | ᴺS. |
 | 2sg 古風なフォーマル | *ペディ* | あなたは話します (非常にフォーマル/詩的) | ᴺS. |
 | 3sg | *ペド* | 彼/彼女/それは話します | ᴺS.; 母音の長さに注意してください: *e* → *ê* |
 | 1pl限定 | *ペディフ* | 私たちは話します（あなたではありません） | ᴺS. |
 | 1pl込み | *ペディブ* | 私たちは話します（あなたも含めて） | ᴺS. |
 | 2pl | *ペディヒル* | 皆さんは話します | ᴺS. |
 | 3pl | *ペディル* | 彼らは話します | ᴺS. |

 The 3sg vowel lengthening (*e* → *ê*) is a regular feature of P-class aorists: the bare 3sg form represents the root in its "strong" grade, with a long vowel. これは、古いゲルマン語やインド・ヨーロッパ語の動詞における強/弱の等級交代に似ています。 

### 継続現在 (漸進的)

 継続現在は、「私は今話している」「彼女は今この瞬間に走っている」という継続的な行為を表現します。 これは、**語幹の長母音** (3sg アオリストと同じ長さ) と **-a** 語尾、その後に続く人称接尾辞で形成されます。 

| 人物 | フォーム | 翻訳 |
 |----------|------|---------------|
 | 1sg | *ペドン* | 私は話しています |
 | 2sgおなじみ | *ペドッグ* | あなたは話しています |
 | 2sg 丁寧 | *ペドル* | あなたは話しています（フォーマル） |
 | 3sg | *ペダ* | 彼/彼女/それは話しています |
 | 1pl限定 | *ペドフ* | 私たちは話しています |
 | 1pl込み | *ペドブ* | 私たちは話しています (含む) |
 | 3pl | *ペダール* | 彼らは話しています |

 ここでの形式はすべて ᴺS です。 このパターンは一貫しており、証明された D1 動詞との類似性によって十分に裏付けられています。 

### 過去形 (鼻注)

 P1 動詞は、語根の**最後の子音**の直前に鼻音子音を挿入することによって過去を形成します。 鼻はストップの調音位置と一致します。 
- *-d* (歯科) → *-n-* を挿入: *ped-* → *penn-*
 - *-b* (両唇) → *-m-* を挿入: *cab-* → *camm-* → *camp-*
 - *-g* (velar) → *-ŋ-* を挿入: *dag-* → *daŋg-* → *danc* (最終クラスター簡略化あり)
 - *-t* (歯科) → *-n-* を挿入: *mat-* → *mant-*

 最後の子音も変更される可能性があります: *-d* + 鼻音 → *-nn-* (2 倍になると子音が硬くなる場合があります)。 正確なメカニズムは特定のストップによって異なります。 

| 人物 | フォーム | 翻訳 | メモ |
 |----------|------|---------------|----------|
 | 1sg | *ペニン* | 私は話しました | ᴺS. |
 | 2sgおなじみ | *ペニッチ* | あなたは話しました | ᴺS. |
 | 2sg 丁寧 | *ペン* | あなたは話しました（公式） | ᴺS. |
 | 3sg | *ペント* | 彼/彼女は話しました | ᴺS. (cf. たぶん *men-* からの *ment* が証明されています) |
 | 1pl限定 | *ペンニム* | 私たちは話しました | ᴺS. |
 | 1pl込み | *ペニブ* | 私たちは話しました (含む) | ᴺS. |
 | 3pl | *ペニール* | 彼らは話しました | ᴺS. |

 1sg 接尾辞 *-in* (過去) と *-in* (アオリスト) は同一に見える場合があります。文脈によって曖昧さがなくなり、音声の強弱が異なる場合があります。 

### 未来時制 (-itha- 中置詞)

 未来は、**-itha-** を動詞の語幹と人称接尾辞の間に挿入することによって形成されます。 この *-itha-* は古代の形成であり、おそらく将来の側面を示す接尾語に関連しています。 

| 人物 | フォーム | 翻訳 |
 |----------|------|---------------|
 | 1sg | *ペディソン* | 話します |
 | 2sgおなじみ | *ペディネズミ* | あなたは話します |
 | 2sg 丁寧 | *ペディソール* | あなたは話します（公式） |
 | 3sg | *ペディタ* | 彼/彼女は話します |
 | 1pl限定 | *ペディトホフ* | お話します（除く） |
 | 1pl込み | *ペディソブ* | 話します (含む) |
 | 3pl | *ペディタール* | 彼らは話すでしょう |

 All future forms are ᴺS., but the pattern is supported by analogy with D-class futures (see *linnathon*, *nathon*) and is widely used in Neo-Sindarin composition.

 ### 非有限形式

| フォーム | 表面形状 | 翻訳 | メモ |
 |-----|----------|---------------|----------|
 | 不定詞 / 動名詞 | *足を踏み入れた* | （話すこと） 話す | ᴺS.; ステムの重複 |
 | 命令 2sg | *ペド!* | 話す！ | ← S. 証明 (ドゥリンの扉) |
 | 必須の 2pl | *ペドフ!* または *ペドド!* | 話す！ (皆さん) | ᴺS. |
 | 継続能動分詞 | *ペデル* | 話す（継続中） | ᴺS. |
 | 完了能動分詞 | *ピディエル* | 話した | ᴺS.; 長母音 + *-iel* を使用します。 
| 受動分詞 sg. | *ペネン* | 話した | ᴺS.; 鼻中置 + *-en* |
 | 受動分詞pl. | *ペニン* | 話し言葉 (pl.) | ᴺS.; *ペンネン*のi-affection |

 *-iel* で終わる **完了能動分詞** は最も豊かな分詞形の 1 つで、*A Elbereth* の *palan-díriel* (遠くを見つめた) のような複合語で使用されます。 その形成: 強級語幹母音 → 長くなり、*-iel* を追加します (*-iell* < *-ielle* < 分詞接尾辞 + *-i* 母音から)。

 ## 完全なパラダイム: クラス D1 — *teitha-* (書く)

 *teitha-* はモデル D1 (派生他動詞) 動詞です。 3sg での過去形は **直接証明**: *teitant i thiw hin* が「これらの標識を書いた」(Doors of Durin) です。 これにより、パラダイム全体の中で最もアンカーされた動詞になります。 

### アオリスト (D1 動詞)

 D クラス動詞の場合、**アオリスト** と **継続現在形 3sg** は **同一**です。どちらも、3sg に追加の接尾辞を持たない単純な *-a* 語幹です。 他の人が接尾辞を追加します。 

| 人物 | フォーム | 翻訳 | メモ |
 |----------|------|---------------|----------|
 | 1sg | *ていさん* | 私は書きます | ᴺS. |
 | 2sgおなじみ | *テイタグ* | あなたは書きます | ᴺS. |
 | 2sg 丁寧 | *テイタル* | あなたは書きます（正式） | ᴺS. |
 | 3sg | *テイサ* | 彼/彼女はこう書きます | ᴺS. (継続と同じ!) |
 | 1pl限定 | *テイトフ* | 私たちは書きます | ᴺS. |
 | 1pl込み | *テイタブ* | 私たちは書きます（含む） | ᴺS. |
 | 2pl | *テイサディル* | 皆さんは書いています | ᴺS. |
 | 3pl | *テイタール* | 彼らはこう書きます | ᴺS. |

 ### 継続現在 (D1 動詞)

 *-a* 語尾はすでに語幹に存在するため、D1 動詞は継続用にさらに *-a* 接尾辞を追加しません。 3sg フォーム *teitha* は 2 つの役割を果たします。 必要に応じて、文脈と副詞（*sí*「今」継続、*nef*「すでに」など）によってこの 2 つが区別されます。 

### 過去形 (D1 動詞 — *-ant* 形成)

 D1 動詞と D2 動詞は、**-ant 接尾辞** (3sg) を使用して過去を形成し、他の人に関連する形を形成します。 

| 人物 | フォーム | 翻訳 | メモ |
 |----------|------|---------------|----------|
 | 1sg | *ていさん* | 私は書きました | ᴺS. |
 | 2sgおなじみ | *テイサネク* | あなたが書きました | ᴺS. |
 | 2sg 丁寧 | *テイチャンネル* | あなたは書きました（公式） | ᴺS. |
 | 3sg | *帝人* | 彼/彼女はこう書きました | ← **S. 証明済み** (ドゥリンの扉の碑文) |
 | 1pl | *テイタネム* | 私たちは書きました | ᴺS. |
 | 1pl含む | *テイサンネブ* | 私たちは書きました (含む) | ᴺS. |
 | 3pl | *テイサナー* | 彼らはこう書きました | ᴺS. |

 非 3sg 形式の *-nn-* は、*-ant* 接尾辞の *-n* と人称接尾辞の鼻音開始を組み合わせたものです: *-ant* + *-en* (1sg) → *-ann-en* と母音調整。 

### 未来時制 (D1 動詞 — *-atha-* 接置辞)

 派生動詞は **-atha-** を使用します (主動詞の *-itha-* に対して):

 | 人物 | フォーム | 翻訳 | メモ |
 |----------|------|---------------|----------|
 | 1sg | *テイタソン* | 書きます | ᴺS.; 参照。 *linnathon* ← S. 証明済み |
 | 2sg 丁寧 | *テイサトール* | あなたは書きます | ᴺS. |
 | 3sg | *テイタタ* | 彼/彼女は書きます | ᴺS. |
 | 1pl | *テイザット* | 書きます | ᴺS. |
 | 3pl | *テイタタール* | 彼らはこう書きます | ᴺS. |

 **キーアンカー:** *linnathon* 「私は歌います」 (*linna-* の 1sg 未来) は、*A Elbereth Gilthoniel* 行 6 で直接証明されています。これは、疑いの余地なく D1 動詞の *-atha-* + *-on* (1sg) 未来パターンを確認します。 

### 非有限形式 (D1 動詞)

| フォーム | 表面形状 | 翻訳 | メモ |
 |-----|----------|---------------|----------|
 | 不定詞 / 動名詞 | *テイサッド* | （）書くこと。 書く | ᴺS.; 語幹 + *-d* (動名詞接尾辞) |

 ## 完全なパラダイム: クラス D3 — *anna-* (与える)

 *anna-* は、その過去形が D1/D2 の通常の *-ant* パターンに従っておらず、代わりに **母音交替**、つまり古代の「強力な」過去形成を示しているため、D3 に分類されます。 これは、シンダール語で *na-* (to be) に続く最も重要な不規則動詞です。 

### アオリスト (*anna-*)

 | 人物 | フォーム | 翻訳 |
 |----------|------|---------------|
 | 1sg | *アンナン* | 私は与えます |
 | 2sgおなじみ | *アナグ* | あなたは与えます |
 | 2sg 丁寧 | *年代記* | あなたは与えます（正式） |
 | 3sg | *アンナ* | 彼/彼女は与えます |
 | 1pl | *アンナム* | 私たちは与えます |
 | 1pl含む | *アナブ* | 私たちは（含む）を与えます |
 | 3pl | *アンナー* | 彼らは与えます |

 ### 過去形 (*anna-* — 不規則)

 | 人物 | フォーム | ソース/メモ |
 |-------|------|------|
 | 1sg | *オーネン* | ← **S. 証明済み** (LotR 付録 A、Gilraen のリンノッド: *Ónen i-Estel Edain*) |
 | 2sg | *オネク* (家族) / *オネル* (ポール) | ᴺS. 類推により |
 | 3sg | *あうん* | ← **S. 証明済み** VT44/21 (トールキン自身のメモ) |
 | 1pl | *オネム* | ᴺS. |
 | 3pl | *オーナー* | ᴺS. |

 母音交代: アオリスト語幹 *anna-* (短い *a*)、過去 *ón-* / *au-* (長母音、異なる質)。 これは補足的な強い過去であり、過去形は異なるグレードの語根から来ています。 1sg *ónen* と 3sg *aun* は、過去の語幹に人固有のバリエーションを示しています。これは、ゲルマン語の強い動詞が 1sg と 3sg の過去で異なる母音を示す場合があるのと似ています。 

### 未来 (*anna-*)

 | 人物 | フォーム | 翻訳 |
 |----------|------|---------------|
 | 1sg | *アンナソン* | あげます |
 | 3sg | *アンナサ* | 彼/彼女は与えます |
 | 3pl | *アンナサー* | 彼らは与えます |

 すべてᴺS.; *-atha-* 接尾辞を含む通常の D クラスの Future パターンに従います。

 ## 完全なパラダイム: *na-* (なる予定)

 「である」という動詞は言語全般で不規則であり、シンダール語も例外ではありません。 *na-* には直接証明された形式がいくつかあり、その不規則さにもかかわらず、この言語で最も文書化された動詞となっています。 

| 時制 / 形式 | 人物 | シンダール語 | 出典 |
 |-----------|--------|----------|--------|
 | 現在 | 3sg | *な* | ← S.PE17、各種テキスト |
 | 現在 | 1sg | *なん* | ᴺS. (類推: *nâ* + *-n*) |
 | 現在 | 2sgファム。 | *ナグ* | ᴺS. |

 **コピュラとしての *nâ* に関する注意:** シンダール語では、特に形容詞を含む述語構文では、コピュラ *nâ* は **省略**されることがよくあります。 *Aran Aragorn* 「アラゴルンは王です」は *nâ* なしの文法です。 コピュラは、代名詞 (*Im nân Aragorn* 「私はアラゴルンです」) や形式的/強調的な文脈で最も必要です。

 ## 競合する再構築: 二人称接尾辞の議論

二人称動詞の接尾辞は、新シンダール語動詞パラダイムの中で最も議論の多い点です。 トールキンはこの問題を決定的に解決するには不十分なデータを残しましたが、学者によって再構築の仕方が異なります。 

| 学者 / 情報源 | 2sgおなじみ | 2sg 丁寧 | 2pl | 基礎 |
 |-----||----------||----------|-----|----------|
 | Derdzinski (elvish.org/gwaith) | *-ch* | *-l* | *-ディル* | CE の類似、保守的 |
 | Strack (RealElvish Academy) | *-g* | *-l* | *-ディル* | ノルドリンの証明書 |
 | ジャリングス (2017 教科書) | *-g* | *-l* | *-ディル* | Strack + 独自の分析 |
 | 新シンダーリン文法 (sindarin.elvish.nz) | *-g* | *-l*、*-dh* 代替。 | *-ディル* | 広範な認証調査 |
 | ベルトラン (古い復元) | *-ch* | *-dh* | *-ir* | 異なる CE 読み取り値 |

 **作業上の推奨事項:** **-g** (2sg の親しみやすい) および **-l** (2sg の丁寧な) を使用します。 これらは、2024 年から 2025 年の時点で、主要なアクティブなネオ シンダール語作曲コミュニティ全体で最も広く受け入れられている形式です。 *-ch* (おなじみの) 形式は、古いテキストや 2010 年より前に作成された一部の翻訳に現れています。 これらを読んだ場合、*-ch* はエラーではなく有効な古い規則であると認識してください。 

シンダール語では、親しみやすさと丁寧さの区別に意味があります。 
- **Familiar (*-g*):** 対等な関係者、友人、親密な関係者、家族の間で使用されます。 子供、動物、または社会的に劣った人々に話しかけるときにも使用されます
 - **丁寧語 (*-l*):** 関係が確立されるまで年長者、領主、見知らぬ人に話しかけるときに敬意を示すために使用されます。 正式な文脈におけるマークのないデフォルト

 *Le* (敬意を表す 2sg 代名詞) は通常、丁寧な動詞の形と共起します。

 ## 動詞形態学: 特別なトピック

 ### *e-* 完全接頭辞

 接頭語 *e-* (または子音の前の *ec-*) は、単に過去の動作ではなく **完了した動作** を示すために、一部の過去形で表示されます。*echant*「作られた/形作られた」(ドゥリンの扉では: *Im Narvi hain echant*) は、*e-* + *car-* の過去を使用します。 *e-* 接頭辞は、完了または結果のニュアンスを加えるように見えます。単に「やった」ではなく、「やった、そしてそれは完了しました」。 

この接頭辞は、補完が意味論的に重要な動詞の新シンダール語構成で効果的です: *eteg* (永続的な構造で作られた/構築された)、*eglenno* (去った、最終性を暗示する)。 

### 過去形の *a-* / *o-* 拡張子

一部の動詞は、より古代の形式に特徴的な、過去形で母音**増音** (付加された最初の母音) を示します。 
- *car-* (do) → 過去 **agor** (*\*cart* ではない): *a-* 拡張 + *gor* (強グレード過去)
 - *tog-* (もたらす) → 過去 *\*antog* または *\*odog*: 拡張 + 過去の語幹

 これらの増補形式は、古い完了体形成の名残です (ギリシャ語の完了増補 *e-* と同源です)。 これらは主に最も一般的な古代の動詞に現れます。 

### 動詞の否定形

 否定には、接頭辞 *ú-* (単一要素の否定) または *al-* (全体の否定 / 禁止) または助詞 *avo* (禁止的な「禁止!」) を使用します。 

- *ú-* + 動詞: 動詞の最初の子音は**ソフト突然変異**を受けます: *ú-* + *ped-* → *ú-bêd* 「話さない」。 *ú-* + *セニン* → *ú-ゲニン* 「見えません」
 - *al-*: 句全体を変更します: *alcarel* "それを行っていない"
 - *avo* + 命令形: *Avo garo!* 「やめてください!」 (禁止)

 *ú-* + ソフト突然変異が証明されています: Gilraen の linnod の *ú-chebin* (*ú-* + *hebin*、*ú-* の緩和効果の下で *h* → *ch* を伴います... 実際: *ú-* + *h-* 頭文字 → *h* はすでに摩擦音であり、*ch* に緩和音です? または: 形式は単に *ú-* + 有気音です *ú-* + *h* の正確なメカニズムについては議論があり、証明された形式 *ú-chebin* はデータとして表されます。

 ## 証明されていない動詞形式の再構築に関する注意事項

 上記の検索テーブルにない動詞の形式が必要な場合は、次の決定ツリーに従ってください。 

1. **Eldamo を確認してください** (eldamo.org) — トールキンの言語著作の最も包括的なデータベースです。 英語の意味を検索し、シンダール語/ノルド語のすべてのエントリを確認します。 

2. **ノルドリン (N.) 同族体が存在する場合:** 音の変更 N. → S. を適用してネオシンダール語形式を取得します。 ラベル ᴺS.[N.]。 

3. **Quenya 同族のみが存在する場合:** Quenya 形式から PE ルートを特定し (Eldamo のルート エントリを使用)、シンダール音の変更を適用します。 これはより推測的です。 ᴺS.[Q.] にメモを付けます。 

4. **何も存在しない場合:** 次のことを検討してください。 
- 証明された動詞と一緒に婉曲を使用できますか? (*iston* 「ᴺS.!」の代わりに「私は知っています」! *\*istog* 「私は学びます」)
 - 証明された名詞/形容詞から D クラスの派生動詞を使用できますか? (*glas*「喜び」→*glassa-*「喜ぶ」ᴺS.)
 - コンセプトはシンダール語で直接表現する必要がありますか、それとも構成でそれを回避できますか?

 5. **新しい形式を作成する必要がある場合:** シンダール語音韻論に厳密に従い (補足 5 を参照)、それに ᴺS.! とマークを付け、公開する前に Vinyë Lambengolmor Discord コミュニティに相談することを検討してください。
