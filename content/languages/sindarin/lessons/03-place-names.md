## シンダール人の起源

 トールキンのエルフ語は、*ロード・オブ・ザ・リング*のために一度に発明されたわけではありません。 これらは、LotR が公開される 30 年以上前の 1915 年頃、民間の言語実験として始まりました。 シンダール語の最も古い祖先はトールキンが *グノーミッシュ* と呼んだ言語で、後にトールキンがそれを *ノルドリン* に改訂し、神話を洗練させるにつれて最終的には *シンダール語 * になりました。 

これらすべての改訂を通じて、変わらないことが 1 つありました。それは、シンダール語が音韻論的に **ウェールズ** に基づいてモデル化されたということです。 トールキンは幼少期からウェールズ語が大好きで、バーミンガムの石炭トラックでウェールズ語に出会ったことがきっかけです（ウェールズ語は貨物ラベルに使用されていました）。 彼はウェールズ語を正式に学び、中世のウェールズ詩を読み、最終的には英語圏におけるウェールズ文学の第一人者となりました。 

言語的な影響は深いです。 
- ウェールズ語には **最初の子音変異**のシステムがあります — シンダール語にも同じものがあります (レッスン 10–15)
 - ウェールズ語では複数形に **母音愛情** を使用します。シンダール語ではまさにこれが行われます (レッスン 6 ～ 7)
 - ウェールズ語の単語は子音をクラスター化することが多く、*ll* (無声横方向、[ɬ]) と *rh* (無声 r) を使用します。シンダール語では *lh* と *rh* を同じように使用します
 - ウェールズ語は VSO (動詞-主語-目的語) 言語です — シンダール語も同じ基本順序に従います

 トールキンはシンダール語を *「灰色エルフ」* と呼びました。これは、ノルドールがヴァリノールに行った間、中つ国に残っていた灰色のエルフである **シンダール** の言語です。 *シンダール*自体は、「灰色」を意味する根*THIN/SIND-*に由来します。これらは、中つ国の灰色の空の下、海の近く、森の中、星空の下に住んでいたエルフでした。 最も有名なシンダール語を話す人々は、ドリアスのシンゴルとメリアンの宮廷、リンドンのエルフ、そして後には裂け谷とロスローリエンのエルフの混合集団でした。

 ## トールキンが地名をどのように構築したか

 トールキンは地名について非常に体系的でした。 彼は、中つ国のほぼすべての場所に、たとえ本文で使用されている英語の名前が翻訳である場合でも、文字通りの意味を持つエルフ語 (シンダール語またはクウェンヤ) の名前を付けました。 *ロード・オブ・ザ・リング*、*未完の物語*、および*中つ国の歴史*の付録を使用すると、これらの構成を追跡できます。 

### パターン 1: 主要名詞 + 修飾語 (シンダール語順)

 シンダール語の形容詞と修飾語は通常、修飾する名詞の後に続きます。これは英語とは逆です。 ほとんどの地名は、**先頭 + 修飾子** の順序に従います。 

- *Barad-dûr* = *barad* (塔) + *dûr* (暗い、暗い) = 「ダークタワー」
 - *ミナス ティリス* = *ミナス* (塔、要塞) + *ティリス* (監視、警備) = 「衛兵の塔」
 - *Ered Luin* = *ered* (山、*orod* の pl.) + *luin* (青) = "青い山脈"
 - *Eryn Lasgalen* = *eryn* (森) + *las* (葉) + *galen* (緑、*calen* から抽出) = 「緑の葉の森」

 ### パターン 2: 属格 *in/en* を含む複合語

 「X of Y」構造の場合、シンダール語では *in* (明確な属格助詞、鼻音の突然変異を引き起こす) または裸の属格構造を使用します。 

- *ミナス・モルグル* = *ミナス* (塔) + *モルグル* (ダークソーサリー、*môr* ダーク + *gûl* ソーサリーより) = 「ダークソーサリーの塔」
 - *Henneth Annûn* = *henneth* (窓) + *annûn* (西、夕日) = 「夕日の窓」
 - *Gwaith-i-Mírdain* = *gwaith* (人々、民族) + *i* (の) + *mírdain* (宝石細工師、pl.) = 「宝石細工師の人々」

 ### パターン 3: 接頭辞付きの複合語

 一部の名前は、リンク要素を持つ単一の化合物として記述されるか、融合されます。 

- *Osgiliath* = *ost* (要塞、都市) + *i* + *giliath* (星、*gîl* の総称) = 「星の要塞」
 - *Fornost* = *forn* (北) + *ost* (要塞) = "北の要塞"
 - *アングレノスト* = *アン* (鉄) + *レン-* + *オスト* = 「甲鉄城」

 ## 重要な構造レッスン: シンダール語の名前の読み方

 見慣れないシンダール語の地名に遭遇した場合は、次の手順に従ってください。 

1. **ハイフンまたは明らかな要素境界で分割します。** ハイフンは常に複合境界を示します: *Barad-dûr*、*Taur-nu-Fuin*、*Gwaith-i-Mírdain*。 

2. **既知の要素を探します。** 上記の語彙表を使用して、認識可能なコンポーネントを特定します: *amon*、*minas*、*ered*、*dol*、*nan*、*nen* など。 

3. **助詞に注意してください。** 単語 *nu* (under)、*o* (of、from)、*i* (the/of the)、*a* (and)、*e* (of、属格リンカー) は化合物で非常に一般的です。 *タウル・ヌ・フイン* = 「夜の森」 (*タウル* + *ヌ* + *フイン*)。 

4. **突然変異を覚えておいてください。** 複合語や冠詞の後で、最初の子音が緩和される (ソフト突然変異) 場合があります。 *Galen* は *calen* (緑) の軽音化形です。 *vaer* は *maer* (良い) となります。 *Periannath* は *Periannath* となります。 

5. **順序を確認してください。** シンダール語は頭からです。主名詞が最初に来て、修飾語が 2 番目に来ます。 つまり、*ミナス ティリス* = 監視の塔ではなく、監視の塔です。

 ## 練習: これらの名前を解読する

 **演習 1:** *エミン・ベレイド*
 - *Emyn* = 丘 (*amon* の複数形)
 - *Beraid* = 塔 (*barad* の複数形、i-affection : *barad* → *beraid*; *emyn* に続くため、最初の *b* の緩和がここには存在しないことに注意してください)
 - 答え: 「タワーの丘」 — エルフの塔が立っていたシャイアのタワーヒルズ

 **演習 2:** *ネン・ヒトヘル*
 - *Nen* = 水、湖
 - *Hith* = 霧 (上記の *Hithaeglir* を参照)
 - *oel* = ? — この要素は不明瞭です。 おそらく*oel*「クール」または「プール」を意味する古い言葉に関連している可能性があります
 - 組み合わせ: 「霧の涼しい湖」または「霧の湖」 - ラウロスの滝の上にある広い湖

 **演習 3:** *エリン・ラスガーレン*
 - *エリン* = 森林、森林
 - *ラス* = 葉
 - *Galen* = green (*calen* からの緩和; 緩和は、*galen* が名詞句内の複合修飾子 *las* の後に続くために発生します)
 - 答え: 「緑の葉の森」 — リング戦争後に闇の森と改名されました。 影が消えたとき、スランドゥルはその名前を変更しました

 **演習 4:** *エレッド・ニムライス*
 - *Ered* = 山 (*orod* の pl.)
 - *ニム* = 白、青白い
 - *Rais* = ピーク (*ras* の数)
 - 答え: 「白峰山脈」 = ホワイト山脈 (エレド・ニムライスは、人間がホワイト山脈/ゴンドールの山脈と呼んだもののエルフ語の名前です)

 **演習 5:** *ドール・デイデロス*
 - *Dor* = 土地、地域
 - *Daedeloth* = 大きな恐怖/恐怖 (*daer* = 素晴らしい/恐ろしい + *lhoth/loth* または影と恐怖に関連するルートから)
 - 答え: 「大いなる恐怖の地」 — 第一紀のモルゴスの王国、極北の暗い土地

 ## 概要

 シンダール語の地名は恣意的なものではありません。すべての音節には意味があり、すべての複合語は一貫した文法規則に従っています。 覚えておくべき最も重要なこと:

 1. **先頭名詞が最初、修飾語が 2 番目**: *Minas Tirith* ではなく「Tirith Minas」
 2. **いくつかの要素があらゆる場所に表示されます**: *amon、minas、ered、nan、nen、dôr、orn、barad*
 3. **突然変異は頭子音に影響します**: lenited *calen* → *galen*、lenited *barad* → *varad* など。 
4. **英語名は翻訳されることが多い**: Rivendell = Imladris (同じ意味)、Silverlode = Celebrant、Treebeard = Fangorn
 5. **すべての名前は、その場所の性格、歴史、または外観についての物語を語ります**

 レッスン 4 では、名前から会話の構造、特にシンダール語で質問する方法について説明します。
