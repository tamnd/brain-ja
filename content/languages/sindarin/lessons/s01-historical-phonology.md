## 歴史的な音韻論が重要な理由

 ほとんどの学習者は、表の壁としてシンダール語の突然変異に遭遇します。ソフト突然変異はこれを行い、鼻音突然変異はこれを行い、混合突然変異はまったく別のものです。 コンテキストがなければ、これらの表は暗記すべき任意のルールであり、覚えてもすぐに忘れてしまいます。 

歴史的な音韻論はすべてを変えます。 突然変異が存在する*理由*を理解すると、それは数千年にわたってエルフの言語を席巻した古代の音の変化の化石化した残骸であるということを理解すると、その規則は予測可能になります。 もう、冠詞 *i* の後に **p** が **b** になることを覚える必要はありません。 その代わりに、*i* は歴史的に母音で終わること、古シンダール語では母音間の無声消音は有声消音に弱くなること、そして *i* の最後の母音が失われると、次の子音の変異形が保存されたことを理解します。 「突然変異」とは、もはや存在しない単なる母音です。 

この補足は、レッスン 1 ～ 41 を完了し、システムをより深いレベルで理解したい学習者を対象としています。 また、次の準備も不可欠です。 

- トールキンの言語エッセイを読む (*パルマ・エルダランベロン*、*ヴィンヤール・テングワール*、*宝石戦争*)
 - 独自のネオシンダール復興活動を行う
 - 異なる学者が論争のある形式を異なる方法で再構築する理由を理解する

 表記に関する注意: **PE** = 原始エルフ (原始クエンディアンとも呼ばれます)。 **CE** = 一般的なエルダーリン。 **CT** = 一般的なテレリン。 **OS** = 古シンダール語。 **S.** = 古典シンダール語 (*ロード・オブ・ザ・リング*時代の言語)。 再構築されたフォームにはアスタリスク (*) が付いています。

 ## エルフ語の家系図

 トールキンはプロの文献学者であり、歴史言語学者がインド・ヨーロッパ語族などの実際の言語族に適用するのと同じ厳密な家系図の論理に基づいて言語を構築しました。 以下のツリーは、シンダール語を生成した分岐を示しています。```
Primitive Quendian (language of the first Elves at Cuiviénen)
    │
    ├── Avarin languages (Elves who refused the Great Journey westward)
    │       Six known Avarin languages; mutually unintelligible by the Third Age
    │
    └── Common Eldarin (language of the Eldar who began the westward march)
            │
            ├── Quenya branch
            │       ├── Quenya proper (Noldor + Vanyar in Valinor)
            │       └── Vanyarin Quenya (slightly divergent dialect of the Vanyar)
            │
            └── Common Telerin
                    │
                    ├── Telerin proper (Falmari, coastal Elves of Aman)
                    │
                    └── Sindarin / Noldorin branch
                                │
                                ├── Classical Sindarin (LotR period; Gondor and Rivendell)
                                ├── Doriathrin (archaic dialect of Thingol's court in Doriath)
                                └── Falathrin (coastal dialect of the Falas; Círdan's people)
```私たちの目的にとって重要な分岐点は、**Quenya** と **Common Telerin** の間の分割です。 この分岐の後、2 つの枝は何千年にもわたって独立して進化しました。劇的な違いを生み出すのに十分な長さでありながら、同じ根幹の語彙を共有していました。 これが、シンダール語とクエンヤ語が表面的には非常に異なっているように見えますが、根底には体系的な対応関係がある理由です。*elen* (Q.) と *êl* (S.) は同じ単語であり、両方とも PE *\*elen* から派生したものです。 

シンダール語の内部の多様性も重要です。**ドリアスリン**は古く、より保守的です（古典シンダール語が失ったいくつかの特徴が保存されています）が、**ファラスリン**はいくつかの独自の革新を示しています。 ほとんどの新シンダール語構成は古典シンダール語をターゲットとして使用します。

 ## ステージ 1: 一般的なエルダリンから一般的なテレリンへ

 Common Eldarin からの分岐の第 1 段階では、Telerin と Sindarin の両方の祖先である **Common Telerin** が生み出されました。 この段階での最も重要な変更は次のとおりです。 

### 唇唇子音

 原始エルフには、*\*kw*、*\*gw*、*\*ŋgw* (英語の「queen」、「Gwen」、および鼻音化された「Gwen」のように) という唇唇シリーズがありました。 Common Eldarin では、これらは維持されました。 Quenya ブランチは最終的にこれらの一部を簡素化しました (一部の環境では *\*kw* と *\*p* をマージしました) が、Common Telerin は完全なシステムをより長く保存しました。 

シンダール語は最終的に唇蓋を別の方法で単純化しました。 
- *\*kw* → **c** (*u* 以外の母音の前) または **cw** (一部の初期シンダール語テキストにまだ書かれている)
 - *\*gw* → **gw** (維持; *gwaith* "people" を参照)
 - *\*ŋgw* → **ngw** (初期位置を維持)

 ### インターボーカル *\*b*

 母音間の古代の *\*b* は、共通テレリンでは **v** に弱められました。 この母音間の鼓音化（停止→摩擦音）は、スペイン語で見られる類型学的に一般的なプロセスです（母音間のラテン語 *b* が *v*/[β] になりました）。 これは、後に古シンダール語でソフト突然変異システム全体を推進した**同じプロセス**です。

 ## ステージ 2: 共通テレリンから古シンダール語へ — 大母音喪失

 これはシンダール語の発展において最も重要な段階です。 それを理解しなければ、それ以外のことは意味がありません。 

### 終端短母音の喪失

 古シンダール語では、**単語末尾の短母音はすべて失われていました**。 短い *-a*、*-e*、*-i*、*-o*、または *-u* で終わる単語はすべて、最後の母音を完全に削除します。 

その影響は甚大でした。 

**2 音節の単語が 1 音節になりました:**
 - CE *\*atar* (父、2 音節) → OS → S. *adar* (母音の変化は別々です。これは構造上のポイントを示しています)
 - CE *\*elen* (スター) → OS *\*eln* → (母音調整) → S. *êl*
 - CE *\*ondo* (岩、石) → OS *\*ond* → S. *ond*

 **3 音節の単語が 2 音節になりました:**
 - CE *\*eleni* (星、複数形) → *-i* のステージごとの喪失 → ステージ 3 で詳述される変更

 **長母音は一般に保存され**、**最後の長母音** (*-â*、*-ê*、*-ô* など) は、後の段階で最終的に短縮されるまでより長く存続しました。 

この最後の短母音の喪失が、**シンダール語がクエンヤ語と大きく異なって見える理由**です。 Quenya はヴァリノールで開発され、言語は比較的保守的な方向に進化しました。Quenya の単語は今でも母音 (*elen*、*ando*、*findo*) で終わるのが一般的です。 シンダール語は、何千年にもわたるグレート ジャーニーとその後の歴史を経て中つ国で発展し、それらの母音をすべて失い、歯切れの良い、しばしば単音節の単語 (*êl*、*annon*、*​​find*) の言語になりました。 

### 語尾の子音クラスター

 最後の母音が失われると、それまで単語の中間であった子音クラスター (次の母音によって保護されていた) が単語の末尾になりました。 これらの多くは簡素化されています。 
- ほとんどの環境では *-nd* (最終) → *-nn*
 - *-mb* (最終) → *-mm*
 - *-ng* (最終) *-ng* のまま (この鼻腔クラスターは安定していました)

 これらの単純化により、多くの明らかな不規則性が説明されます。 単語が派生形で予期せずクラスターを獲得する場合、多くの場合、単一子音語末自体が、派生形で復元される以前のクラスターの簡略化であることが原因です。

## ステージ 3: I-Affection (プレスタネス)

 **I-affection** (シンダール語 *prestanneth*「妨害/影響」) は、シンダール語の複数形を理解するための最も重要なプロセスです。 これは **ウムラウト** の形式であり、英語の「foot/feet」、「mouse/mice」、およびドイツ語の *Mutter/Mütter* を生成するのと同じプロセスです。 これらすべての場合において、後の音節の母音が前の音節の母音をシフトさせ、その後、トリガーとなる母音が失われる可能性があります。 

### 仕組み

 一般的なテレリンでは、複数形の接尾辞は *-î* (前部高母音) でした。 言葉には次のような形式がありました。 
- *\*elessî* (星、複数形) と複数形を示す *-î*

 この *-î* は **前部高母音** で、舌を高く上げて口の前で発音されました。 先行する音節にさらに後ろまたは低く発音される母音が含まれている場合 (*a*、*o*、*u*、*e*)、それらの母音は予期的調音の影響を受けて *-î* の位置に向かって移動しました。 

その後、古シンダール語時代に最後の短母音が失われると、*-î* 自体が消滅し、複数音節の唯一の目印として、前の音節の変更された母音だけが残されました。 

**複数のマーカーは、言い換えれば、もはや存在しない接尾辞の幽霊です。**

 ### I-Affection からの特定の母音の変化

 | 失われる前の母音 *-î* | 結果 | 例 (sg → pl) |
 |------------------------|--------|--------|
 | *a* (非終音節) | → *e* | *アラン* (王) → *エレイン* (王) |
 | *a* (最後の開音節) | → *あい* | *タル* (足) → *テール* (足) |
 | *â* (長い *a*) | → *あい* | *ダン* → *ダン* |
 | *e* (非終音節) | → *i* | *エドヘル* (エルフ) → *エドヒル* (エルフ) |
 | *ê* (長い *e*) | → *î* → *i* と書きました | *têw* (文字) → *tîw* (文字) |
 | *o* (任意の位置) | → *y* (フロントラウンド) | *orch* (オーク) → *yrch* (オーク) |
 | *ô* (長い *o*) | → *ŷ* | *dôr* (土地) → *dŷr* (土地) |
 | *う* | → *y* | *トゥルス* → *タイリス* |
 | *û* (長い *u*) | → *うい* | *dûr* (暗い) → *dûr* |
 | *au* (二重母音) | → *おえ* | *naug* (ドワーフ) → *noeg* (ドワーフ) |

 *y* 母音 (以下のステージ 7 を参照) は、このプロセスの最も特徴的な生成物です。 

### これが学習にとって重要な理由

 単数形とはまったく似ていないシンダール語の複数形を見た場合、ほとんどの場合、i-affection が原因です。 上の表を理解すると、それぞれを個別の語彙項目として学習するのではなく、単数形から複数形、複数形から単数形を**予測**できます。 
- *yrch* を参照すると、単数形が *orch* であることがすぐにわかります
 - *edhil* を参照すると、単数形が *edhel* であることがすぐにわかります
 - *erain* を参照すると、単数形が *aran* であることがすぐにわかります

 ## ステージ 4: ソフトミューテーションの起源 (Lenition)

 ソフト突然変異は、シンダール語のテキストで最も頻繁に遭遇する突然変異です。 次のように表示されます。 
- 定冠詞 *i* の後
 - 動詞の直接目的語について
 - 多くの一般的な前置詞の後 (特定の用法では *o*、*na*、*nu*、*an*)
 - 名詞の後に続く形容詞について

 **これらはどれも恣意的なものではありません。** これらはすべて、古シンダール語における単一の音韻プロセスに遡ります。 

### 音韻環境

 古シンダール語では、**子音の先頭の単語**の直前にある**母音の最後の単語**により、2 番目の単語の最初の子音の両側に母音が隣接する環境が作成されました: [母音] + [子音] + [母音]。 これは古典的な**間声**の位置、つまりすべての人間の言語において子音が最も弱まりやすい位置です。 

弱体化は予測可能な経路をたどりました。 

**ステップ 1: 無声ストップを有声ストップに弱める:**
 *\*p* → *\*b*, *\*t* → *\*d*, *\*c* (*k*) → *\*g*

 これは自然な弱音化であり、有声化の特徴が周囲の母音から子音へと広がります。 すべての停止が音声化されました。 

**ステップ 2: 有声ストップがさらに弱まり、有声摩擦音 (スピラント) になります:**
 *\*b* → *\*v* (両唇スピラント)、*\*d* → *\*dh* (歯スピラント)、*\*g* → *\*ɣ* (軟口蓋スピラント、最終的に削除)

スピラントは「漏れる」音です。気流を完全に止めてから解放するのではなく、調音器官が完全に閉じずに近づき、乱気流を伴う継続的な気流を可能にします。 有声音は有声音よりも弱いです。 

**ステップ 3: トリガーワードの最後の母音が失われます:**

 ここが正念場です。 弱化の原因となった母音、冠詞 *i*、前置詞 *o*、代名詞 *le* を終了する母音自体は、ステージ 2 で説明したのと同じ最終母音喪失プロセスによって削除されました。しかし、*変異した子音は残りました*。 

**結果:** 定冠詞 *i* は歴史的に母音で終わります (*\*ī* または *\*ia* など)。 この最後の母音は次の子音の許しを引き起こし、その後失われます。 ここで、*i* は何も終わりません。しかし、次の子音は、あたかも母音がまだそこにあるかのように、依然として緩韻形のままです。 

これが **突然変異** です。もはや存在しない音韻環境で機能した化石化した音の変化です。 

### 完全なソフトミューテーションカスケード

 | 元の子音 | 発声後（ステップ1） | スピラティス化後 (ステップ 2) | シンダール語の結果 |
 |---------------------|---------------------|----------------------------|----------------|
 | *p* | *b* | (*p* のためここで停止) | *b* |
 | *t* | *d* | (*t* のためここで停止します) | *d* |
 | *c* (*k*) | *g* | (*c* についてはここで停止します) | *g* |
 | *b* | (すでに声が出ています) | *v* | *v* |
 | *d* | (すでに声が出ています) | *dh* | *dh* |
 | *g* | (すでに声が出ています) | *ɣ* → 削除されました | （消える） |
 | *m* | (鼻、別の経路) | *v* | *v* |
 | *lh* | *l* (有声音) | *l*のままです | *l* |
 | *rh* | *r* (有声音) | *r*のまま | *r* |
 | *hw* | *w* (有声音) | そのまま*w* | *w* |

 突然変異した *g* の消失は、次のカスケードによって説明されます。*g* は有声軟口蓋停止音でした。 その有気音形 *ɣ* (スペイン語の *lago* やギリシャ語の *γ* の音のような) は非常に弱く、簡単に完全に削除されます。 したがって、*i* + *galadh* → *i 'aladh* (木。アポストロフィは失われた *g* を示します)。

 ## ステージ 5: 鼻の突然変異の起源

 古シンダール語の定複数冠詞は *\*in* で、最後の鼻音が保存された形式です。 この鼻音終冠詞が子音頭語の前にある場合、鼻音は子音が弱まるのではなく（ソフト突然変異のように）次の子音に同化しました。 

### 鼻同化

 ストップの直前の鼻音は、そのストップを自分の方に引っ張る傾向があり、**前鼻音化ストップ**を作成するか、**完全な鼻音化**を引き起こします。 

**無声停止:**
 - *in* + *p* → *\*imp* → *\*imb* → *mb* → 無声停止音は鼻から始まります
 - *in* + *t* → *\*int* → *\*ind* → *nd*
 - *in* + *c* → *\*iŋk* → *\*iŋg* → *ng* (*ŋg*)

 **音声停止:**
 - *in* + *b* → *\*imb* → *mb* → 最終的に *b* は *m* に完全に同化します
 - *in* + *d* → *\*ind* → *nd* → *n*
 - *in* + *g* → *\*iŋg* → *ng* → *ng* (鼻軟蓋クラスターとして残ります)

 ### 学術論争

 無声停止の鼻の突然変異は、新シンダール語の復元において最も議論されている点の 1 つです。 トールキン自身のメモにはいくつかの矛盾があり、証明されたデータはまばらです。 2 つの主要な立場が存在します。 

**位置 A (吸引):** *p* → *ph*、*t* → *th*、*c* → *ch* (*in* 後)。 これは、鼻を有声音ではなく無声音を吸引したものとして扱います。 

**ポジション B (有声音):** *in* の後の *p* → *b*、*t* → *d*、*c* → *g*。 これは、無声停止の鼻音突然変異をソフト突然変異 (有声音のみ) と同等として扱います。 

**中間形式** (*mb*、*nd*、*ŋg*) では、次に何が起こったかについてこれらの立場が一致しない場合があります。 *mb* → *m* + 吸引 *p* (*ph* を与える) でしょうか、それとも *mb* → *b* (鼻音を失い、有声音のみを残す) でしょうか?

 **ネオ・シンダール語の作曲家への作業上の推奨事項:** 鼻音変異下の無声音符には *p* → *b* (または *ph*)、*t* → *d*、*c* → *g* を使用します。 位置に関係なく、有声ストップは議論の余地がありません: *b* → *m*、*d* → *n*、*g* → *ng*。

 ## ステージ 6: 混合突然変異の起源

混合突然変異は、*定冠詞を組み込んだ前置詞**の後に発生します: *erin* (*er* + *in*)、*uin* (*o* + *in*)、*nan* (*na* + *in*)、および同様の化合物。 

「混合」特性は、次の 2 つの同時圧力から生じます。 
1. **前置詞**自体は歴史的に母音終端でした（またはソフトミューテーションを引き起こす形式を持っていました）
 2. *in* に組み込まれた記事** は、鼻終端でした (鼻の突然変異を引き起こした)

 両方の圧力が次の名詞に同時に適用された場合:
 - **無声停止**はソフトミューテーションの圧力(有声)を感じました: *p* → *b*、*t* → *d*、*c* → *g*
 - **有声停止**は鼻の突然変異の圧力（鼻音化）を感じました: *b* → *m*、*d* → *n*、*g* → *ng*

 この「分裂」動作、つまり無声音を楽にするが、有声音を鼻音にするという動作は、まさに混合突然変異を他の 2 つから区別するものです。 これは、異なる発声の子音に対して異なる動作を行った歴史的な 2 段階のプロセスを保存しています。

 ## ステージ 7: *y* 母音 — シンダール語の最も特徴的な機能

 シンダール語で *y* と綴られる母音 (ドイツ語では *ü*、フランス語では *u*、または IPA [y] と発音されます) は、原始エルフ語では前例がありません。 それは完全に後円母音に作用する i-affection によって生じました。 

### *y* の導出

 *o* または *u* が i 愛情を受けたとき (ステージ 3)、非円唇母音のように単に *e* または *i* に前方に移動するわけではありません。 代わりに、**唇を丸めたまま**前方に移動し、**前方円唇母音** [y]を生成します。 これは類型学的に正常な結果です。フランス語は、接尾辞 *-i* の影響を受けて、ラテン語 *u* から同じ方法で [y] を発展させました。 

- *o* + *-î* → [y] (*y*と書きます)
 - *u* + *-î* → [y] (*y* とも表記)
 - *ô* (長い) + *-î* → [ŷ] (前が長い)
 - *û* (長母音) + *-î* → *ui* (長母音を単母音のままではなく二重母音化)

 **実際の例:**
 - *orch* "orc" (*o* 付き) → *yrch* "orcs" (*y* 付き)
 - *tulus* "ポプラの木" → *tylys* "ポプラの木"
 - *mund* → *mynd* (一部の派生)

 この母音は、元の *u* または *o* がフロンティングを引き起こした環境にあった場所であればどこでも、**非複数の文脈**でも見られます。これは、一部のシンダール語の単語が、クエンヤ語の同族語に *o* または *u* があるのに *y* を持つ理由を説明します。 

ウェールズ語は非常によく似た母音を使用します。ウェールズ語の *u* は、北ウェールズ (中央付近) では [ɨ] と発音され、南ウェールズでは [y] に近似することがよくあります。 ウェールズ語の愛好家であるトールキンは、特に彼が目指していた独特の「ケルト」風味を生み出すために、この音を含むようにシンダール語の音韻論を設計しました。

 ## ステージ 8: その他の重要な最新の変更

 ### *ae* と *oe* の開発

 二重母音 *ae* と *oe* はシンダール語の特徴です (Quenya にはそれらがありません)。 これらは以下から発展しました。 
- 特定の位置の *\*ai* → *ae*: CE *\*aira* → S. *aer* (聖なる; 二重母音が移動しました)
 - *\*au* with i-affection → *oe*: CE *\*nauki* → *naug* → *noeg* (ドワーフ) (*au* は i-affection によって *oe* に引き寄せられた)

 ### 吸引された液体 *lh* および *rh*

 原始エルフは、通常の液体である *l* と *r* を発声していました。 シンダール語の初期の位置では、これらは無声/有気音の変種を開発しました。 
- 特定の頭文字 *l* → *lh* [ɬ] (ウェールズ語の *ll* 音、無声横摩擦音)
 - 特定の頭文字 *r* → *rh* [r̥] (ウェールズ語の *rh* のような無声 *r*)

 これらは、歴史的に子音の前に無声子音が後に失われ、残った液体に無声性が願望として残された位置で発生しました。 ソフト突然変異では、*lh* → *l* および *rh* → *r* (弱音化環境が有声音を追加すると、吸引は除去されます)。

 ## 音声対応: シンダール語対クエンヤ語

 どちらの言語も Common Eldarin から派生しているため、**体系的な対応**があり、同じルートでも規則に従って言語ごとに表面が異なります。 これらの対応は次の場合に重要です。 
1. 同族語の特定 (同じルート、異なる言語)
 2. 証明されたクエンヤ語源から新シンダール語を再構築する

| クエンヤの特徴 | シンダール語対応機能 | 例 (Q. / S.) |
 |----------------|----------------------------|----------------|
 | 単語末尾の母音が保存される | 単語末尾の母音が失われる | *エレン* / *エル* (スター) |
 | *qu* [kw] | *p* (前母音の前) | *quet-* / *ped-* (話す) |
 | *ñ* (頭文字) → *n* | *ñ* → *g* (最初の軟膏鼻→停止) | *ノルド* / *ゴロド* |
 | *nd-* (イニシャル) → *n* | *nd-* → *d* | *ノルナ* / *ドルン* (ハード) |
 | *mb-* (初期値) → *m* | *mb-* → *b* | *mbār* → *már* / *bâr* (ホーム) |
 | *ld* 内側 → *ll* | *ld* → *lth* または *ll* | *アルダ* / *ガラド* (木) |
 | *r* (すべての位置) | *r* または *rh* (位置依存) | *アラン* / *アラン* (王、同じ) |
 | *-e* 最終 (名詞) | 失われた | *quenye* / *peth* (*kwet* + 母音変更) |
 | *-o* 最終 (名詞) | 失われた | *ノルド* / *ゴロド* |
 | *nw-* (初期値) | *dh-* または *n-* | *nwalme* / *gwalch* |
 | 二重母音 *ai* | *え* | *ナイラ* / *ナール* (悲しい) |
 | *au* | *o* または *au* に応じて | *aure* / *or* (日; 化合物で) |

 最も実用的な対応は **Q です。 *qu-* = S. *p-*** (*u* 以外の母音の前)。 *qu* で始まるクエンヤ語を見たときは、シンダール語の同族語 (存在する場合) は、*p* で始まる可能性があります: *quenta* (物語) → *pent* (物語; *belegpent* を参照)、*quel-* (消え去ること) → *pel-* (衰退すること。*Pelennor* を参照)。

 ## 学習者への影響: 歴史を実践に結びつける

 次のリストは、歴史的事実を学習者の一般的な質問に対する実践的な回答に変換したものです。 

**「ソフト突然変異ではなぜ *g* が消えるのですか?」**
 *g* は有声軟口蓋停止音だからです。 ソフト突然変異環境 (声間) では、有声音は有声音化されます: *g* → *ɣ*。 軟口蓋摩擦音 *ɣ* は非常に弱いため、完全に削除されました。 「消滅」は魔法ではなく削除です。 

**「ソフト突然変異では *m* が *v* になるのに、鼻突然変異では *m* のままになるのはなぜですか?」**
 ソフト突然変異（声間音）では、*m* は鼻音子音であり、緩和環境では *v* (両唇連続音) に有声化されます。 鼻音の突然変異では、鼻音の冠詞 *-n* が *m* の鼻音性を強化し、*m* としての安定性を維持しました。 

**「なぜシンダール語の複数形は接尾辞ではなく母音の変化によって形成されるのですか?」**
 接尾辞 (*-î*) が前の音節でウムラウトを引き起こし、その後終母音喪失によってそれ自体が削除されたためです。 母音の変化は接尾辞の *残余* です。 もともと接尾辞がありました。 それは単にもう存在しません。 

**「なぜ一部の単語の最初に *lh* と *rh* が付いているのですか?」**
 これらは、無声子音が *l* または *r* に先行する歴史的な子音クラスターから生じる無声液体です。 前の子音が削除されました。 その無声性は、残った液体に吸引として保存されました。 

**「なぜこの記事はソフトミューテーションを引き起こすのですか?」**
 なぜなら、記事は歴史的に母音で終わっており、声の合間の寛容な環境を作り出していたからです。 母音が失われていました。 突然変異はそうではありませんでした。 

**「シンダール語とウェールズ語はなぜ似ているのですか?」**
 なぜなら、トールキンは、ウェールズ語の音韻的感覚、特にその突然変異システム、前円母音、無声液体、ウムラウトの複数形を捉えるようにシンダール語を設計したからです。 これらは**設計上の選択**であり、偶然ではありません。ウェールズ語を深く理解することは、シンダール語を理解するのに役立ちます。
