## はじめに

 このレッスンでは、シンダール語の突然変異システムを完成させます。 レッスン 11、15、および 30 では、以下について説明しました。 
- **ソフト突然変異** (Lenition) — 最も一般的です。 冠詞、前置詞、多くの助詞によって引き起こされる
 - **鼻音の突然変異** — *an* (与格/恩恵) と複数冠詞 *in* によって引き起こされます
 - **混合突然変異** — 冠詞と融合した前置詞 (*erin*、*uin*、*ammin*) によってトリガーされます。 

ここで、2 つの最後の突然変異を追加します。 
- **リキッドミューテーション** — *-r* (リキッド子音) で終わる単語または接頭辞によってトリガーされます。 
- **停止突然変異** — *-t* または *-d* で終わる単語によってトリガーされます (歯の停止)

 正直にまとめると、**リキッド変異とストップ変異は、5 つの変異の中で最も証明されていない**です。 それらの証拠は限られており、突然変異が「何をするか」について同意する学者でさえ、その正確なきっかけや範囲については同意しないことがあります。 このレッスンでは、学術的な合意を提示し、不確実性が残っている箇所に注意し、学習者に実践的なアドバイスを提供します。

 ## 1. 5 つの突然変異: 完全なレビュー

 最後の 2 つを学ぶ前に、私たちの立ち位置は次のとおりです。 

| 突然変異 | プライマリトリガー | 主な機能 |
 |----------|------|---------------|
 | ソフト (レニション) | *i* (記事の定義)、多くの前置詞、形容詞と名詞の位置、*a* (呼格) の後に | ほとんどの子音は有声音/摩擦音になります。 
| 鼻 | *an* (与格)、*in* (pl. 記事) | 停止→鼻音+有声音; *b*→*m*、*d*→*n*、*g*→*ng* |
 | 混合 | *erin*、*uin*、*ammin* (準備 + 記事の融合) | 柔らかい変化と鼻の変化の混合 |
 | 液体 | *-r* で終わる単語/接頭辞の後 | 停止用のソフトに似ています。 詳細は以下をご覧ください |
 | 停止 | *-t* または *-d* で終わる単語の後 | 無声停止は有声になるだけです |

 ## 2. 液体の突然変異: 定義と歴史的起源

 ### それは何ですか?

 **液体突然変異**は歴史的に、液体子音で終わる単語 (または接頭辞) (具体的には *-r*) の後に可変子音で始まる単語が続いたときに引き起こされました。 最初の単語の最後の *-r* が 2 番目の単語の最初の子音に影響を与え、予測可能な音の変化を引き起こしました。 

「液体突然変異」という名前は、*l* と *r* を **液体** (流れるような有声音の性質を持つ子音) として音声的に分類したことに由来しています。 これらのうち、*-r* だけがシンダール語でこの特定の突然変異を引き起こすと思われます。 *-l* は初期の段階でそうした可能性がありますが、証拠はそれほど明確ではありません。 

### 歴史的メカニズム

 原エルフ語（共通エルダーリン語）では、単語の接合部の音は相互作用しました。 *-r* で終わる単語が次の単語と文法的に密接な関係にある場合、*-r* は **同化** と呼ばれるプロセスを通じて後続の頭子音に影響を与えます。つまり、後続の音は前の音により似たものになります。 

古典的な歴史言語学の用語では: *-r* は有声子音です。 隣接する有声子音が有声音になった後 (*p*、*t*、*c*) に続く無声停止 (*b*、*d*、*g*)。 これは、ソフト突然変異を引き起こすのと同じ発声メカニズムです。違いは、正確な歴史的条件付け環境にあります。

 ## 3. リキッドミューテーション: 変化

 ### 子音の変化

 | 頭の子音 | 液体突然変異後 |
 |---------------------|----------------------|
 | *p* | → *b* |
 | *t* | → *d* |
 | *c* | → *g* |
 | *b* | → *v* |
 | *d* | → *dh* |
 | *g* | → *' (ドロップ)* |
 | *m* | → *v* |
 | *す* | → *h* |
 | *lh* | → *l* |
 | *rh* | → *r* |
 | *h* | → *ch* |

 ### ソフトミューテーションとの比較

 注意深い学習者は、**液体突然変異はソフト突然変異と同じ変化を生み出す**ことにすぐに気づきます。 

これが学術論争の核心だ。 トールキンの言語を研究している多くの言語学者は、実用的な目的では、リキッドミューテーションとソフトミューテーションは**機能的に同一**であり、同じ子音交替を生成すると結論付けています。 この違いは歴史的なものです (それらを引き起こしたメカニズムは異なります) が、**出力**は同じです。

これが本当であれば、ソフト ミューテーションを知っている学習者はすでにリキッド ミューテーションを知っていることになります。唯一の問題は、それをいつ適用するか (トリガーとなるか) です。 

### 考えられる *p* → *ph* の区別

 一部の学者は、リキッドミューテーションは次のような微妙な点でソフトミューテーションと異なると示唆しています。 
- ソフトミューテーション: *p* → *b* (有声破裂音)
 - 液体の突然変異: *p* → *ph* (無声摩擦音) または *p* → *b* — **議論中**

 リキッド突然変異が *p* → *ph* (*p* → *b* ではない) を与える場合、少なくともこの 1 つの子音についてはソフト突然変異とは異なります。 ただし、この区別は、明確に証明されたシンダール語の例ではなく、比較証拠からの理論的再構築に基づいています。 ネオシンダーリン語の実用的なガイドのほとんどは、液体突然変異をソフト突然変異と同一のものとして扱い、*p* の問題を学術的な脚注として記載しています。

 ## 4. 液体の突然変異: トリガー

 液体の突然変異は、*-r* で終わる特定の **前置詞と接頭辞**によってトリガーされます。 

### 証明されたトリガー

 **1. *または* — 「上、上」**

 > *or* (over) + 名詞 → 名詞の最初の子音の液体突然変異

 例ᴺS.:
 - *or* + *barad* (塔) → *or varad* (塔の上) — *b* → *v* = ソフト突然変異と同じ
 - *or* + *tûr* (パワー) → *or dhûr* (オーバーパワー) — *t* → *dh* = ソフト突然変異と同じ

 **2. *ior* — 「超えて、超えて」（異体字/古語）**

 > *ior* (以上、古風) + 名詞 → 液体の突然変異

 あまり使用されていません。 同じ変化。 

**3. *ar-* 接頭辞 — 「そばに、そばに」または「高貴な」（口頭/名目接頭辞として使用される場合）**

 動詞複合語の接頭辞 *ar-* は、後続のルートで液体突然変異を引き起こす可能性があります。 証拠は限られており、ほとんどが理論的です。 

### 実践的な課題

 液体突然変異の課題は、証明されたシンダール語のテキストではその**トリガーがまれである**ことです。 前置詞 *or* はいくつかの複合形式で出現しますが、明らかに突然変異を示す形で名詞の前に直接単独で出現することはほとんどありません。 私たちの証拠のほとんどは、ネオシンダール語の復元から来ています。

 ## 5. リキッドミューテーション: 正直な評価

 学術的な状況は次のとおりです。 

**位置 1 (Jallings、*基本シンダール語*)**: 液体突然変異 = ソフト突然変異。 同じ変化、異なる歴史的起源。 実際には、液体突然変異が示されている場合はどこにでもソフト突然変異を適用します。 

**意見 2 (Fauskanger、*Ardalambion*)**: リキッド突然変異は別個の突然変異ですが、理論的な *p* → *ph* 対 *p* → *b* の問題においてのみソフト突然変異とは異なります。 他のすべての子音では、ソフト突然変異と一致します。 違いは非常に小さいため、実際的な影響はほとんどありません。 

**意見 3 (Thorsten Renk、*Pedin Edhellen*)**: 液体変異はケースバイケースで分析されるべきです。 確固たる規則を定めるには証明された証拠が少なすぎる。 

**学習者への推奨事項**: リキッド ミューテーションがトリガーされる場所 (主に *or*、*ior*、および *-r* で終わるプレフィックスの後) にソフト ミューテーションを適用します。 保守的かつ技術的に正確にしたい場合は、*p* を *b* ではなく、おそらく → *ph* としてマークしてください。 不確実性に注意して次に進みましょう。

 ## 6. 突然変異の停止: 定義と歴史的起源

 ### それは何ですか?

 **ストップ突然変異**は、**デンタルストップ** (*-t* または *-d*) で終わる単語または接頭辞の直後に、可変子音で始まる単語が続いた場合に歴史的にトリガーされました。 最後の歯科停止は、次の最初の歯に影響を与えました。 

「ストップ突然変異」という名前は、*歯止め*、つまり子音*t*と*d*に由来しており、これらは上の歯の後ろの歯列で生成される「止め」（完全に咬合された子音）です。 

### 歴史的メカニズム

 エルフ祖語では、単語が *-t* または *-d* で終わる場合、次の単語の最初の子音は **接触同化** または **弱体化** のプロセスを通じて変化しました。 
- *-d/-t* が **有声**になった後の無声停止 (*p*、*t*、*c*): *p*→*b*、*t*→*d*、*c*→*g*
 - 有声停止 (*b*、*d*、*g*) — ほとんどの分析によると — **変化しませんでした** (すでに有声化されています)

 これがソフト ミューテーションとの主な違いです。**停止ミューテーションは無声停止にのみ影響し、有声停止には影響しません**。

 ## 7. 突然変異の停止: 変化

### 子音の変化

 | 頭の子音 | 停止突然変異後 |
 |---------------------|---------------------|
 | *p* | → *b* |
 | *t* | → *d* |
 | *c* | → *g* |
 | *b* | 変化なし |
 | *d* | 変化なし |
 | *g* | 変化なし |
 | *m* | → *v* (議論中) |
 | *す* | → (変更なし、それとも → *h*?) (議論中) |
 | *lh* | 変化はありませんか？ |
 | *rh* | 変化はありませんか？ |
 | *h* | 変化はありませんか？ |

 有声停止の **ソフト突然変異** と比較します。 
- ソフト突然変異: *b* → *v*、*d* → *dh*、*g* → *'* (ドロップ)
 - 突然変異の停止: *b* → *b*、*d* → *d*、*g* → *g* (変化なし)

 **これが決定的な違いです**: 停止突然変異は、有声停止音、摩擦音、または鼻音には影響しません。 無声停止(*p*、*t*、*c*)のみが変化します。

 ## 8. 突然変異の停止: トリガー

 ### 限定的な証明書

 停止変異は、5 つの変異の中で **最も証明されていない**です。 以下は、歴史的分析と限られた文書証拠に基づいて提案されたトリガーです。 

**1. 数字の *cened* / *ad-* 接頭辞**

 数字の接頭辞 *ad-* (*adan* = "セカンドマン"? または方向を示す "戻る" のように、「もう一度」を意味します) と、*-d* または *-t* で終わる特定の数字の単語は、後続の名詞の突然変異を停止します。 

**2. *-t***で終わる言葉

 *-t* で終わる少数の機能語または接頭辞が停止突然変異を引き起こす可能性があります。 証拠は非常に限られています。 

**3. 口頭接頭辞 *o(d)-***

 接頭辞 *od-* (*od*、方向/空間:「から、離れて」に関連) は、後続の動詞ルートで停止突然変異をトリガーする可能性があります。 ᴺSです。 再建。 

### なぜ Stop Mutation がほとんど見られないのか

 1. **証明された文書にはトリガーがほとんどない**: トールキンの出版されたシンダール語では、停止突然変異を引き起こす条件がめったに発生しません。 
2. **無声ストップの変更はソフト突然変異と同じです**: ソフト突然変異でもストップ突然変異でも、a *p* は *b* になります。 結果だけから常にそれらを区別できるわけではありません
 3. **有声停止の非変化は突然変異がないように見えるかもしれません**: *-d* で終わる単語の後に *b* がある場合、それは停止突然変異 (b は b のまま) ですか、それともまったく突然変異ではありませんか? 結果は同じです。

 ## 9. まれな突然変異についての正直な学習者向けガイド

 実践的な学習者向けの率直な優先順位は次のとおりです。 

### 完全に知っておく必要があります

 **ソフトミューテーション** — 単数形の冠詞 *i* の後、ほとんどの前置詞 (*o*、*na*、*an*) の後、多くの複合句など、あらゆる場所で使用されます。 トールキンのシンダール語のテキストのすべてのページでこれに遭遇します。 

### よく知っておく必要があります

 **鼻音変異** — 与格助詞 *an* と複数冠詞 *in* の後に使用されます。 これは文章の中で定期的に必要になります。 

### 概念的に理解する必要があります

 **混合突然変異** — 前置詞と冠詞の融合形式 (*erin*、*uin* など) の後に使用されます。 中周波。 

### 知っておいてください。 疑わしい場合はソフトミューテーションを適用する

 **液体の突然変異** — それが存在することを知っています。 *-r* で終わる単語によってトリガーされることを知ってください。 実際にソフトミューテーションを適用すると、正しいか、非常に近い結果が得られます。 

**突然変異を阻止** — 突然変異が存在することを知ってください。 無声ストップ (*p*、*t*、*c*) のみに影響し、有声ストップは変更されないことがわかります。 トリガーに確信がある場合に適用します。 それ以外の場合は不確実性に注意してください。 

### 「疑わしい場合」のルール

 どのミューテーションを適用すればよいかわからない場合は、**ソフト ミューテーションが最も安全なデフォルト**です。 ソフト突然変異は次のとおりです。 
1. 最も一般的なもの
 2. 多くの子音の他の突然変異と重複する変更を生成します。 
3. シンダール人の耳に異質に聞こえる形式を生成する可能性は低い

 ## 10. 完全な変異リファレンス: 5 つの変異すべて

 これは、5 つのシンダール語の突然変異すべてのマスター テーブルです。 ソフトコラムを完璧に暗記しましょう。 鼻をよく学びましょう。 混合、液体、停止を概念的に理解します。

| イニシャル | ソフト | 鼻 | 混合 | 液体 | 停止 |
 |----------|------|----------|----------|--------|------|
 | *p* | *b* | *b* | *b* | *b* (*ph*?) | *b* |
 | *t* | *d* | *d* | *d* | *d* | *d* |
 | *c* | *g* | *g* | *g* | *g* | *g* |
 | *b* | *v* | *m* | *m* | *v* | *b* (変更なし) |
 | *d* | *dh* | *n* | *n* | *dh* | *d* (変更なし) |
 | *g* | *'* | *NG* | *NG* | *'* | *g* (変更なし) |
 | *m* | *v* | *m* | *m* | *v* | *v*? |
 | *す* | *h* | *h* | *h* | *h* | *h*? |
 | *lh* | *l* | *lh* | *l* | *l* | *lh* |
 | *rh* | *r* | *rh* | *r* | *r* | *rh* |
 | *h* | *ち* | *h* | *ち* | *ち* | *h*? |
 | 母音 | 変更なし | 変更なし | 変更なし | 変更なし | 変更なし |

 **主な所見**:
 1. ソフト突然変異と液体突然変異は、係争中の *p* ケースを除いて同一です
 2. 停止突然変異は *p/t/c* のみを変更します。 すべての有声子音は残ります
 3. 混合突然変異 = 無声の場合はソフト。 有声音の鼻音 (2 つの「混合」)
 4. 鼻の突然変異により、有声音のストップ音がそれに相当する鼻音に変わります (*b*→*m*、*d*→*n*、*g*→*ng*)

 ## 11. 実践: リキッドミューテーションとストップミューテーションの例

 **リキッド ミューテーションの例** (ソフト ミューテーションを適用します。ᴺS として注意してください):

 1. *または* + *パラン* (遠く) → *またはバラン* ᴺS. (*p* → *b*:ソフトと同じ)
 2. *or* + *tirith* (見る) → *or dhirith* ᴺS. (*t* → *dh*:ソフトと同じ)
 3. *or* + *caras* (要塞) → *or garas* ᴺS. (*c* → *g*:ソフトと同じ)
 4. *or* + *barad* (塔) → *or varad* ᴺS. (*b* → *v*:ソフトと同じ)
 5. *or* + *galadh* (木) → *or 'aladh* ᴺS. (*g* → *'*:ソフトと同じ)

 **停止突然変異の例** (*p/t/c* のみ変更; 音声は変更なし; ᴺS.):

 1. [トリガー] + *peth* (単語) → *beth* (p → b)
 2. [トリガー] + *tol* (島) → *dol* (t → d) — *dol* は既存の単語であることに注意してください。 結果があいまいになる可能性がある
 3. [トリガー] + *セレブ* (シルバー) → *ゲレブ* (c → g)
 4. [トリガー] + *barad* (タワー) → *barad* (b → b; 変更なし!)
 5. [トリガー] + *galadh* (木) → *galadh* (g → g; 変更なし!)

 項目 4 と 5 の対照: ソフト突然変異は *varad* と *'aladh* を与えます。 突然変異を停止すると、変更されないままになります。 これが診断上の違いです。

 ## 12. なぜこのような複雑さが存在するのでしょうか?

 学生は当然のこととして、「なぜシンダール語には 5 つの突然変異があるのですか?」と尋ねるかもしれません。 1 つでは十分ではありませんか?

 答えはトールキンの**歴史言語学手法**にあります。 トールキンはシンダー語を便利なコミュニケーションツールとして設計したわけではありません。 彼はこの言語を、完全な**内部の歴史**を持つ言語、つまり実際の言語と同様に、数千年にわたる音の変化を経て進化した言語として設計しました。 それぞれの突然変異は *異なる歴史的プロセス* を表します。 

- **ソフト突然変異**は、特定の構文環境における最初の子音の全体的な弱化と有声化から生じました（ケルト言語で広く普及しているプロセスであり、トールキンの突然変異に影響を与えました）
 - **鼻音変異**は、単語境界における初期の鼻音子音クラスターから生じました
 - **混合突然変異**は、特定の音韻環境 (前置詞と冠詞の融合) から生じました。 
- **液体突然変異**は、後続のイニシャルに対する先行する *-r* の影響から生じました。 
- **停止突然変異**は、次の初期歯に対する前の歯科停止の影響から生じました。 

それぞれは**歴史的に正当化されています**。 これが、シンダール語がその複雑さにもかかわらず、非常に現実的に感じられる理由です。実際に存在した言語の質感を持っています。 

---

 ## 覚えておくべき重要なポイント

1. **液体突然変異**は、先行する *-r* によってトリガーされます。 ソフト突然変異と同じ変更を生成します (ほとんどの学習者が無視する *p* の区別を伴う可能性があります)
 2. **停止突然変異**は、先行する *-t/-d* によってトリガーされます。 無声停止のみを変更します (*p*→*b*、*t*→*d*、*c*→*g*)。 有声停止は**変更されません** (これがソフトミューテーションとの主な違いです)
 3. **疑わしい場合は、ソフト突然変異を使用してください** — これは液体突然変異と完全に重複しており、無声停止の場合は停止突然変異にも一致します
 4. **合計 5 つの突然変異**: ソフト > 鼻 > 混合 > 液体 > 停止 (頻度と実際的な重要性の順)
 5. **複雑さは歴史を反映しています**: それぞれの突然変異は異なる歴史的な音韻過程から生じたものであり、それがシンダール語が実際の言語のような重層的で現実的な深みを持っている理由です。
