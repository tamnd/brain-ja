## シンダール語での主語代名詞の扱い方

 英語では主語の代名詞が必須です。「彼は見ています」を単に「Watches」と言うわけにはいきません。代名詞「彼」が存在する必要があります。 シンダール語では動作が異なります。 ラテン語、スペイン語、ウェールズ語と同様に、**シンダール語では主語を動詞自体の終わりにエンコードします**。 動詞形式 *tiron* はすでに「私は見る」を意味します。*-on* 語尾には一人称単数の情報が含まれているため、強調したい場合を除き、別個の「I」代名詞は必要ありません。 

これは、シンダール語には主語を表現するための 2 つの並列システムがあることを意味します。 

1. **接尾辞システム**: 主語情報は動詞の語尾に組み込まれます。 これがデフォルトの通常モードです。 
2. **独立した代名詞システム**: 「私」、「あなた」、「彼」などを別々の単語にします。これらは**対比または強調のみ**に使用されます。たとえば、「見ているのは私であり、彼ではありません」と言うようにです。 

これはまさにウェールズ語 (トールキンの主要モデル) が代名詞を扱う方法です。動詞は人称を活用し、独立した代名詞は強調を加えます。

 ## 主語代名詞の接尾辞

 接尾辞は動詞の語幹に直接付加されます。 以下のパラダイムでは、*tir-* (見る) をモデル動詞として使用し、各接尾辞がどのように完全な動詞形を生成するかを示しています。 

正確な接尾辞は、動詞語幹が母音で終わるか子音で終わるかによって異なりますが、主動詞 (*tir-*、*ped-*、*mat-*、*sog-* などの子音終端語幹) の場合、接尾辞は次のようになります。 

| 人物 | サフィックス | 動詞形 (*tir-*) | 翻訳 |
 |----------|----------|--------|---------------|
 | 単数形 | *-(o)n* | *タイロン* | 私は見ます |
 | 2 単数 (おなじみ) | *-(o)g* | *ティログ* | あなたは見守っています |
 | 2 単数形 (形式) | *-(o)dh* | *ティロッド* | 見てください（丁寧） |
 | 単数形 | マークなし、または *-(o)r* | *ティル* / *ティロル* | 彼/彼女/それは見ます |
 | 最初の複数を含む | *-(o)m* | *ティロム* | 私たちは (あなたも含めて) 見ています |
 | 1 番目の複数形の排他的 | *-(o)nc* | *ティロンク* | 私たちは見ています (あなたではありません) |
 | 2番目の複数 | *-(o)dh* | *ティロッド* | あなた (pl.) が見てください |
 | 3番目の複数 | *-(o)r* | *恐怖* | 彼らは見ています |

 **パラダイムに関する注意事項:**

 - 括弧内の *-(o)-* は、語幹が子音クラスターで終わるときに現れる「緩衝母音」です。 *tir-* のような単純な語幹の場合、*o* が表示されます: *tir-* + *-on* → *tiron*。 
- 3sg (三人称単数) は、多くの場合、接尾辞のない裸の動詞形式で表現されます: *tir* = 「彼/彼女は見ている」。 *-or* 接尾辞を追加すると、多くの場合、より明確な三人称の言及が示されます。 
- 1pl inclusive (*tirom*) は、「話している相手を含む私たち」を意味します。 排他的な (*tironc*) は、「あなたを含まない私たち」を意味します。 
- 2sg 形式 (*tirodh*) と 2pl (*tirodh*) は、多くのパラダイム再構成で同じ接尾辞を共有し、文脈が明確になります。 

**出典注:** このパラダイムは主にヘルゲ・ファウスカンガーとロマン・ラウシュの著作に基づいており、*Parma Eldalamberon* 13 に掲載されたトールキンのノルドリン言語パラダイムと関連する言語注記を参考にしています。 新シンダール語コミュニティでは広く受け入れられていますが、すべての形式が直接証明されているわけではありません。 直接証明されている (または非常に密接に証明されている) ものについては、以下に記載されています。

 ## 独立した主語代名詞

 これらは強調やコントラストが必要な場合にのみ使用されます。 これらは動詞の前または後に単独で存在します。

| 人物 | 独立した代名詞 | メモ |
 |--------|---------|----|
 | 単数形 | *私* | 「私自身です、私は（強調して）」 **証明済み**: *Im Narvi hain echant* = 「私がナルヴィが作った」 (モリア門の碑文) |
 | 2 単数 (おなじみ) | *ル* | また目的語の代名詞「thee/you」。 コンテキストは曖昧さを解消します。 |
 | 2 単数形 (形式) | *ル* | シンダール語でおなじみのものと同じ形式。 レジスタはコンテキストと関係によって伝えられます。 
| 3単数形のマスコ。 | *e* | "彼。" 言語ノートで証明されています。 |
 | 3単数fem。 | *エッセ* / *エ* | "彼女。" それほど明確には証明されていません。 *esse* が一部のノートに表示されます。 |
 | 1番目の複数 | *分* | 「我々は（強調して）」 語根 *MI-* + 複数形​​から。 |
 | 2番目の複数 | *le* (文脈を添えて) / *gir* | *le* の複数形は不確かです。 一部の学者は *gîr* を再構成しています。 |
 | 3番目の複数 | *ハイン* | 「彼ら（強調主語）」 **証明済み**: *ハイン*、*ナルヴィ・ハイン・エチャント*。 |

 ## ゲートウェイ認証: *ナルヴィ・ハイン・エチャントです*

 モリアのドゥリンの扉に刻まれたこの文は、証明されているシンダール語の中で最も言語的に豊かな短いフレーズの 1 つです。 

> *私はナルヴィです、歌っています: セレブリンボール、エレギオン、私はこれを知っています*

 **単語ごとの分析:**

 | 単語 | 文法上の役割 | 意味 |
 |------|------|-----------|
 | *私* | 1sg 独立主語代名詞 (強調) | 「私自身」 |
 | *ナルヴィ* | 固有名詞、主語 (*im* と同置) | ナルヴィ (ドワーフの職人) |
 | *ハイン* | 3pl 直接目的語代名詞 | 「彼ら」（ドア） |
 | *エッチな* | *echad-* の動詞、3sg または 1sg 過去「作る、ファッション」 | 「作られた、作られた」 |
 | *セレブリンボール* | 固有名詞、第 2 項の主語 | ケレブリンボル |
 | *o* | 前置詞 | 「の、から」 |
 | *地域* | 固有名詞 | エレギオン (ホーリン) |
 | *帝人* | *teitho-* の動詞、過去形「描く、刻む」 | "描いた、刻まれた" |
 | *私* | 確定記事 | 「その」 |
 | *ティウ* | 名詞、*têw* (文字、記号) の複数形 | 「文字、記号」 |
 | *ヒン* | 指示形容詞 | 「これら」 |

 **翻訳:** 「私、ナルヴィがそれら[ドア]を作りました。エレギオンのケレブリンボールがこれらの標識を描きました。」

 この一文から次のことがわかります。 
- 強調 1sg 代名詞として *im* ✓
 - 3pl オブジェクト代名詞としての *hain* ✓
 - 過去形としての *echant* ✓
 - *o* を前置詞「of/from」として使用 ✓
 - 別の過去形として *taithant* ✓
 - 定冠詞としての *i* ✓
 - 複数形の *thiw* (*têw* → *tîw* または *thiw*) ✓
 - 実証的な *hin* ✓

 これは学習者にとって非常に情報量の多い碑文です。

 ## 二人称: 慣れた人 vs 正式な人

 ヨーロッパの多くの言語では、親しみやすい「thou/tu/du」（親しい友人、家族、子供たちに対して、または祈りの中で使用）とフォーマルな「you/vous/Sie」（見知らぬ人、目上の人に対して、正式な文脈で使用）を区別しています。 トールキンはこの区別を彼のエルフ語に組み込みました。 

シンダール語:
 - **おなじみの**形式では、接尾辞 *-og* (動詞) と代名詞 *le* が使用されます。 
- **正式**形式では、接尾辞 *-odh* (動詞) と同じ代名詞 *le* が使用されます。 

したがって、*le* という単語は、馴染みのある正式な二人称代名詞の両方として機能し、動詞の接尾辞が活用形の区別を持ち、残りは文脈/関係によって行われます。 

**トールキンは、いつおなじみの *le* を使用しますか?** 最も有名な例は、フロドからガラドリエルへの *Hannon le* (あなた/あなたに感謝します) です。 フロドが古代のエルフの女王に対して使い慣れた「あなた」を使ったことは意外に思えるかもしれませんが、トールキンのエルフは、侮辱としてではなく、心からの愛情と敬意を持って抱いていた人々に対して使い慣れた音域を使いました。 親密な「あなた」は尊敬と親密さのしるしであり、見下すものではありませんでした。 これは、クエーカー教徒のスピーチ（神や愛する友人に呼びかける）、詩、祈りにおける英語の「thee/thou」の使用と類似しています。 

**重要なポイント:** *hannon le* の *le* は親密な敬意を表しており、カジュアルで失礼ではありません。 これを理解すると、フレーズ全体の感情表現が変わります。

 ## 独立形式と接尾辞形式を使用する場合

| 状況 | どの形式 | 例 |
 |----------|-----------|----------|
 | 通常のステートメント、コントラストは必要ありません | サフィックスのみ | *ティロン* = "私は見ています" |
 | コントラスト: 「私は (彼ではなく) 見ています」 | 独立 + サフィックス | *Im tiron, ú e* = 「私は見ています、彼ではありません」 |
 | 自己紹介 | 独立 | *私はアラゴルン* = "私はアラゴルンです" |
 | *na-*の後「である」 | 独立 | *Im na aran* = 「私は王です」 |
 | 強い強調 | 独立 | *Im pêd!* = 「私（自分）が話します！」 |
 | 通常の三人称 | 裸の動詞 | *Tir* = 「彼/彼女は見ています」 |
 | コントラスト: 「彼 (私ではありません) が見ています」 | 独立 + 動詞 | *E tiror, ú im* = "私ではなく彼が見ています" |
 | 文中で「あなた」に呼びかける | サフィックス | *ティログ* = "あなたは見守っています" |
 | 「あなた」を強調する | *ル* 独立 | *Le、úim、tirog* = 「私ではなく、あなたが見てください」 |

 ## 言語パラダイム: *tir-* の完全な表 (見る)

 これは、各人をどのように表現するかを示す完全な現在時制のパラダイムです。 

| 人物 | 意味 | 動詞のみの形式 | 独立代名詞付き |
 |------|-----------|-----|----------------------|
 | 1sg | 私は見ます | *タイロン* | *私はティロン* (強調) |
 | 2sg (家族) | あなたは見守っています | *ティログ* | *ル ティログ* (強調) |
 | 2sg（正式） | あなたは見ます | *ティロッド* | *ル・ティロド* |
 | 3sg | 彼/彼女は見ています | *ティル* | *エ ティル* / *エッセ ティル* |
 | 1pl含む | 私たちは見ます（すべて） | *ティロム* | *ミンティロム* |
 | 1pl除く | 私たちは見ています (あなたではありません) | *ティロンク* | *ミンティロン* |
 | 2pl | あなた (pl.) 見てください | *ティロッド* | *ギル ティロッド* (ᴺS.) |
 | 3pl | 彼らは見ています | *恐怖* | *ハインティロール* |

 ## 追加の証明済みまたはほぼ証明された代名詞形式

 | 代名詞 | 意味 | 証拠 |
 |----------|----------|----------|
 | *私* | 私 (強調主語) | 直接証明 (*私はナルヴィ...*、トールキンの代名詞リストでは *私*) |
 | *ル* | あなた/あなた | 直接証明済み (*hannon le*、*le abdollen*、*le linnathon*) |
 | *ハイン* | それら (オブジェクト) | 直接証明済み (*私はナルヴィが大好きです*) |
 | *e* | 彼 | 言語ノート (PE17 および関連) で証明済み |
 | *分* | 私たちは（強調して） | 代名詞のメモで証明されています。 
| *ガール* | あなた (pl.) | ᴺS. — 関連フォームから再構成 |
 | *エッセ* | 彼女 | 不確か; いくつかのメモに登場します。 他の学者は両方の性別に *e* を使用します。

 ## 練習問題

 **練習問題 1:** 6 人全員に対して動詞 *lin-* (歌う) を現在形で活用してください。 *tir-* と同じパターンに従います。 

| 人物 | フォーム | 翻訳 |
 |----------|------|---------------|
 | 1sg | *リノン* | 私は歌う |
 | 2sg (家族) | *リノグ* | あなたは歌います |
 | 2sg（正式） | *リノド* | あなたは歌う |
 | 3sg | *リン* | 彼/彼女は歌います |
 | 1pl含む | *リノム* | 私たちは歌います |
 | 1pl除く | *リノン* | 私たちは歌います（除く） |
 | 3pl | *リノール* | 彼らは歌う |

 **練習問題 2:** 必要に応じて独立代名詞または接尾代名詞を選択して、これらの文を翻訳してください。 

1.「私は話します。」 (通常のステートメント)
 2. 「あなたではなく、私が話します。」 (コントラスト - 強調)
 3. 「私たちはレンバを食べます。」 (通常のステートメントを含む)
 4. 「彼らではなく、私たちが食べる。」 (コントラスト - 強調)
 5. 「あなたは王です。」 (identity ステートメント — *im/nâ* 構造を使用)

 **答え:**
 1. *Pedon* (接尾辞のみ)
 2. *Im pedon, ú le* (独立 + 接尾辞; *ú* = ではない)
 3. *Matham lembas* (接尾辞のみ)
 4. *Mín matham, ú hain* (独立 + 接尾語)
 5. *Le na aran* (強調のための独立した *le*:「汝が王である」)

 ## 概要

 | 特集 | シンダール語パターン | 写真 シンダール語パターン
 |-------|------|
 | 件名情報 | 動詞の語尾にキャリーされる (接尾辞) |
 | 独立した代名詞 | 強調/対照的な使用のみ |
 | キー 1sg | サフィックス *-on*; 独立した *im* (証明済み) |
 | キー2sg | サフィックス *-og/-odh*; 代名詞 *le* (証明済み) |
 | キー3pl | 接尾辞 *-or*; 代名詞 *hain* (証明済み) |
 | 有名な証明 | *Im Narvi hain echant* — 1sg サブジェクト + 3pl オブジェクト |
 | 馴染みのあるものと正式なもの | *-og/-odh* 接尾辞の区別。 同じ代名詞 *le* |

 レッスン 9 では、**目的語と与格**の代名詞、つまり「I」が「me」になり、「you」が「thee」になると何が起こるか、そしてシンダール語が前置詞 *an* (to、for) を使って間接目的語をどのように扱うかについて説明します。
