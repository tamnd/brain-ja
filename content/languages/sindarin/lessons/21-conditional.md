## はじめに

 レッスン 17 ～ 20 では、シンダール語の 4 つの主要な時制、現在、過去、未来、継続的側面をマスターしました。 しかし、他の自然言語と同様に、シンダー語でも、単に起こっていることや確かなこと「ではない」ことを表現する方法が必要です。 「もし私が見ていたら」、「私は歌うだろう」、「彼らが長生きしますように」、または「おそらく彼が来るでしょう」と言う必要があります。 これらの仮説、願望、または不確かな状況は、シンダール語文法の **条件法および仮定法** の領域に属します。 

このレッスンでは、シンダール語がこれらの気分にどのように対処するかについて、私たちが知っていること、つまり証明され、慎重に再構築されたものすべてを取り上げます。 

---

 ## 1. 仮定法ムードとは何ですか?

 **直示的**のムードは事実を述べます: *「王は見ています。」* **条件付き**のムードは、特定の条件下で*何が起こる*かを表します: *「王が見ていたら、彼は見るでしょう。」* **仮定法**のムードは、願望、疑い、または仮定を表します: *「王が見守ってくれますように!」* または *「彼が来ないのではないかと心配です。」*

 英語では、これらはしばしば一緒にぼやけています。 シンダール語でトールキンは、主に次の方法でそれらがどのように機能するかについて部分的な証拠を提供しています。 

1. 助詞 **aen** — トールキンの言語論文で証明された条件法/接続法マーカー
 2. 助詞 **ce** (ᴺS.) — 条件付きプロターゼの「if」
 3. 命令形 **no!** (be!) — 選択的 (願望を表現する) 助詞として使用されます。 
4. 命令形 **cuio!** (生きろ!) — 祝福/願い事に使用される
 5. 仮説的な意味を伝える分詞構文と不定詞構文

 ---

 ## 2. 粒子 *aen*

 最も重要なシンダール語の仮定法マーカーは **aen** です。 トールキンは、言語学に関する論文 (*Vinyar Tengwar* および *Parma Eldalamberon* に掲載) でこの助詞について議論しています。 これは動詞の前 (または文節の境界) に置かれ、アクションが条件付き、仮説、または願望であることを示します。 

### *aen* の配置

 *Aen* は **活用動詞の直前**に来ます:```
aen + [verb with person suffix]
```これは、シンダール語が一般に動詞の修飾語をどのように配置するかを反映しています。修飾語は、それが支配する動詞の前に置かれます。 

### *Aen* + 現在/アオリスト語幹

 単純な条件文 ("would do"、"might do") を表現する場合、*aen* は動詞の現在形/アオリスト形と適切な人称接尾辞を組み合わせます。 

| シンダール語 | 光沢 |
 |----------|----------|
 | *アエンティリトン* | 「もし私が見ていたとしたら」 / 「私は見ていただろう」 |
 | *アエン ティリトール* | 「もしあなたが見ていたとしたら」 / 「あなたなら見ていたでしょう」 |
 | *アエン ティリタ* | 「もし彼/彼女が見ていたとしたら」 / 「彼/彼女は見ていただろう」 |
 | *アーエン ティリタム* | 「もし私たちが見ていたとしたら」 / 「私たちは見ていただろう」 |
 | *アエンティリティル* | 「もし彼らが見ていたとしたら」 / 「彼らは見ていただろう」 |

 ここでの動詞の形式は、未来の語幹 (*tirith-*) に人称接尾辞を加えたもののように見えることに注意してください。 学者の間では、条件文が未来の語幹を使用するか、それとも別の接続法語幹を使用するかについて議論があります。 現在の学術的なコンセンサスは、多くの自然言語と同様に、シンダール語が条件文の未来語幹を再利用した可能性が高いということです。 

### *Aen* + Future Stem

 より明示的に未来志向の条件文の場合:

 | シンダール語 | 光沢 |
 |----------|----------|
 | *アエンティリトン* | 「見るべきなら」 / 「見ます」 |
 | *アエン・セニサム* | 「もし私たちが見られたら」 / 「私たちは見るだろう」 |
 | *アーエン・リンナソン* | 「もし私が歌えたら」 / 「私は歌うだろう」 |
 | *アーエンメニソン* | 「もし私が行くとしたら」 / 「私は行きます」 |

 > **証明メモ:** *Aen* は、条件付き/仮定法を持つ助詞としてトールキンの言語ノートに記載されています。 上記の正確なパラダイムは、シンダール語の通常の言語形態と組み合わせた、その証拠に基づいた最良の学術的再構築を表しています。

 ## 3. 条件文の構造: *If…Then*

 シンダール語の完全な条件文には 2 つの節があります。 

- **Protasis** (「if」節): 条件を示します。 
- **Apodosis** (「then」節): 結果を述べます

 ### 両方の句に *aen* を使用する

 1 つの再構成では、アポドーシス (結果節) に動詞を含む *aen* が配置されますが、プロタシスでは接続詞が使用されます。```
[ce / protasis] + [aen + result verb]
```### 接続詞 *ce* (If)

 助詞 **ce** (ᴺS.) は、条件付きプロタシスの「if」として機能します。 それ自体が突然変異を引き起こすようには見えません**。 例:

 | シンダール語 | 英語 |
 |----------|----------|
 | *Ce tolen、linnon an le* | 「私が来たら、あなたに歌います」
 | *Ce cenitham、boe ammen tiriad* | 「（それが）見えたら、見なければなりません」 |
 | *セナヴァエル、セリン* | 「それが良いことなら、そうします」 |

 これらの例では、プロタシス動詞は単純な現在/アオリスト (現実/オープン状態を表現) を使用し、アポドーシスは結果を表現していることに注意してください。 

### アポドーシスで *aen* を使用する

 より仮説的/反事実的な条件 (可能性が低い、または事実に反するもの) の場合:

 | シンダール語 | 英語 |
 |----------|----------|
 | *アエン ティリトン、セニトン ル* | 「私が見ていたら、あなたに会えるでしょう」 |
 | *Ce bain na laur、aen linnathon* | 「もしすべてが金色だったら、私は歌うだろう」 |
 | *Ce tolant e、aen cenitham* | 「もし彼が来ていたら、私たちは（彼に）会えただろう」 |

 この構造は自然言語の条件パターンを反映しています。*aen* は「would」句 (仮説の結果) を示し、*ce* は「if」句 (条件) を示します。

 ## 4. *aen* の使用が証明されている

 トールキンの *aen* は、シンダール語の文法を説明する文脈で彼の言語論文に登場します。 この粒子は、特に **仮定法または選択的な力** を持ち、条件付き (「だろう」) と選択的な (「かもしれない、かもしれない、させて」) 機能の両方をカバーします。 この多義性は言語を超えて共通です (願いと条件の両方をカバーするラテン語の *utinam* と比較してください)。 

**トールキンの発言:** トールキンはメモの中で、*aen* を、言語行為が事実として主張されるのではなく、要望、仮説、または条件として主張されることを示すために使用される助詞であると説明しています。 助詞は、強い強調のために文の最初に現れることも、動詞の前の文節の中間に現れることもあります。 

**学術情報源:** David Salo (*A Gateway to Sindarin*) と Helge Fauskanger (Ardalambion) は両方とも *aen* について議論しています。 ファウスカンガーのシンダール語コースでは、*aen* を主接続法/条件助詞として扱います。 この助詞は、経験豊富なトールキン言語学者によって再構築されたシンダール語のテキストにも登場します。

 ## 5. 願望とオプション: *いいえ!* と *クイオ!*

 シンダール語では、**願いや祝福**を表現するために特定の命令形を使用します。 これらは古典的なラテン語のオプティブと同様に機能し、望ましい状態を表現します。 

### *いいえ!* オプションとして

 命令形 **no!** (be! — from *na-*) は、述語が後に続くときに願いを表現するために使用されます。 

| シンダール語 | 英語 | メモ |
 |----------|-----------|----------|
 | *ベルはありません!* | 「（あなたが）愛されますように！ / 愛されますように！」 | *vell* = *bell* のソフト突然変異 (強力、勇敢); または *メル* → *ヴェル* |
 | *ジェネディアドのドラムネイルはありません!* | 「カウントが完了しますように！」 | 仮定の祝福 |
 | *ナイ ティルバンテル!* | (クエンヤパラレル) | シンダール語を比較 *ティリウバンテルなし* |

 ### 証明済み: *Cuio i Pheriannath anann!*

 これは証明されたシンダール語の文章の中で最も有名なものの 1 つです。 トールキンのテキストより (*コーマレンの野原にて、*『王の帰還*』):

 > *ライタテ、ライタテ！ アンダブ・ライトヴァルメット！ コルマコリンドール、ライタ・タリエンナ！ Cuio i Pheriannath anann!*

 シンダール語部分: **Cuio i Pheriannath anann!**

 - *クイオ* = 「生きてください！（彼らが）生きますように！」 — *cuia-* (生きる) の命令形であり、選択命令として機能します
 - *i* = 定冠詞「the」
 - *Pheriannath* = 「ハーフリング」 — *Perian* (ハーフリング) の複数形。 記事の後の *P* → *Ph* (ソフトミューテーション: p → ph)
 - *anann* = "長い" (時間副詞) — 証明された副詞

 **全文訳:** 「ハーフリングの命が長く続きますように!」 あるいは「ハーフリングが長生きできますように！」

 この文は、シンダール語が **願い/祝福**をどのように表現するかを見事に示しています。動詞の命令形を選択詞として使用するだけです。 この記事には主題 (フェリアンナス) が続きます。 特別なオプションの接尾辞は必要ありません。 

### その他のオプションの構造

| シンダール語 | 英語 |
 |----------|----------|
 | *クイオ!* | 「生きてください！（彼/彼女/彼ら）が生きますように！」 |
 | *いいえ、フェリアンナスです!* | 「ハーフリングが（繁栄しますように）！」 |
 | *ティロ!* | 「見守ってください！（彼/彼女が）見守ってくれますように！」 |
 | *ノロリム!* | 「乗って！早く走って！」 — 証明済み (アラゴルンからアスファロート) |

 ## 6. 必要性の表現: *Boe*

 非人称動詞 **boe** は **必要性** (「必要である」、「しなければならない」) を表します。 その後に不定詞または与格構文が続きます。 

| シンダール語 | 英語 | メモ |
 |----------|-----------|----------|
 | *ボエアンメンティロ* | 「私たちは見なければなりません」 | *boe* + 与格代名詞 *ammen* + 動詞 |
 | *ボエ・イ・アラン・ティロ* | 「王は見なければなりません」 | *boe* + 主語 + 不定詞 |
 | *Ú-boe* | 「その必要はありません」 | 否定形 |
 | *ボイメン* | 「行かなければなりません」 | *boe* + 与格 *men* (私たちにとって = 私たちはしなければならない) |

 **証明:** *Boe ammen i phith dithen* = 「ちょっとした言葉が必要です」 — トールキンの草稿で証明されています。 *Boe* はシンダール語の非人称動詞としてよく知られています。 

> **文法上の注意:** *Boe* は **非個人的**です。「彼/彼女/それは見ている」という主語がありません。 代わりに、「must」する人は与格で表現されます: *ammen* (私たちに = 私たちはしなければならない)、*enni* (私に = 私はしなければならない)、*le* (あなたに = あなたはしなければならない)。

 ## 7. 不確実性と可能性

 何かが**起こるかもしれない**、または**おそらく**そうなることを表現するために、シンダール語(新シンダール語再構築)はいくつかの戦略を使用します。 

### 副詞的なヘッジ

 | シンダール語 | 英語 | ステータス |
 |----------|-----------|----------|
 | *ᴺS. ボーニン* | "おそらく (文字通り、それは私が言うことではないかもしれません)" | ᴺS. 構築する |
 | *ま* | 「もしかして？ どうか？」 | 疑問詞として証明される |

 ### *Ma* 可能性マーカーとして

 助詞 **ma** (レッスン 27 も参照) は、シンダール語で複数の機能を果たします。 質問ではなく発言の冒頭で使用すると、「X が真実かどうかはわかりません」という不確実性の雰囲気をもたらす可能性があります。 これはその疑問機能と密接に関係しています。 

| シンダール語 | 英語 |
 |----------|----------|
 | *マ・トーレン* | 「来るか来ないかも」 |
 | *ウーイストン マ セニサム* | 「会えるかどうかは分かりません」 |
 | *マ・ナ・ヴァール?* | 「いいですか? / いいかもしれません?」 |

 ## 8. 要約: 条件付き戦略と仮定法戦略

 | 機能 | 建設 | 例 |
 |----------|---------------|----------|
 | 単純な条件 ("would") | *aen* + 未来動詞語幹 | *アエンティリトン* |
 | オープン条件 (「if... then」) | *ce* + 現在動詞 | *セ・トーレン* |
 | 完全な条件文 | *ce* [プロタシス] + *aen* [アポドーシス] | *ce tolen、aen linnathon* |
 | 願い/祝福 | 必須とオプション | *Cuio i Pheriannath anann!* |
 | 必要性 (「しなければならない」) | *boe* + 与格 + 不定詞 | *ボエアンメンティロ* |
 | 不確実性 (「かどうか」) | 動詞の前に *ma* | *ウーイストン マ トーレン* |
 | 必要性の否定 (「必要ない」) | *ú-boe* | *ú-boe* |

 ## 9. 全文分析: 仮説的なエルフの詩

 学習した構造を使用して、完全な仮説的な条件付き詩を構築してみましょう。```
Ce cenin i galadh, linnon anann.
Aen linnathon, nathog glassen.
No vell i Edhil!
Cuio i Pheriannath anann!
```**翻訳:**
 - *Ce cenin i galadh* = 「もし木を見たら」 (*ce* + present *cenin* + *i galadh*)
 - *linnon anann* = 「私は長く歌います」 (現在の単純な結果)
 - *Aen linnathon* = 「私は歌います」 (*aen* + future *linnathon*)
 - *nathog glassen* = 「あなたは喜ぶだろう」 (*nathog* = あなたはそうなるだろう; *glassen* = 嬉しい)
 - *No vell i Edhil!* = 「エルフが愛されますように!」 (*no* 命令形 + *vell* + *i Edhil*)
 - *Cuio i Pheriannath anann!* = 「ハーフリングの命が長続きしますように!」 (完全に証明されています)

 ## 10. 練習問題

 以下のシンダール語の条件文を作成します。 答えにマークを付けて、下のキーをチェックしてください。 

**練習問題 1:** 「私が歌えば、彼は聞くでしょう。」 (条件には *ce* + 現在を使用し、結果には単純な未来を使用します。)

 **練習問題 2:** 「もしエルフが来たら、私たちは彼に会えるでしょう。」 (仮説の結果には *aen* を使用し、条件には *ce* を使用します。)

 **練習問題 3:** 「王様が長生きできますように!」 (オプションで *cuio* または *no* を使用できます。)

 **練習問題 4:** 「私たちは見張らなければなりません。」 (*boe* + 与格 + 不定詞を使用します。)

 **練習問題 5:** 「あなたが来るかどうかわかりません。」 (*ú-iston* + *ma* + 動詞を使用します。)

 **練習問題 6:** 「それが良いことであれば、そうします。」 (条件には *ce nâ vaer* を使用し、結果には *aen* + *cerin* を使用します。)

 ### 回答キー

 1. *シー・リノン、セニサ・e.*
 2. *Ce tol i edhel、aen cenitham e.*
 3. *Cuio i aran anann!* または *No bell i aran!*
 4. *ボエ・アンメン・ティロ。*
 5. *ウーイストン マ トリル レ。*
 6. *Ce nâ vaer、aen gerin.*
