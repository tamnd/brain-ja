## はじめに

 レッスン 6 と 7 では、**i-affection plural**、語幹の母音変化によって形成される標準的なシンダール語の複数形 (*aran* → *erain*、*galadh* → *gelaidh*) を学習しました。 この複数形は単に「複数の X」を示します。 しかし、シンダール語には、**クラス複数** (または **集合複数**) と呼ばれる、まったく異なる 2 番目の複数システムがあります。 クラス複数形は単に項目を数えるだけではありません。 それらは**ユニット全体として見なされるグループ**を表します。つまり、人種のすべてのメンバー、敵対的な軍隊を集団、仲間、または物事の全体的な集合体として見ます。 

トールキンの文章を読むには、クラス複数形を理解することが不可欠です。 中つ国で最も有名な名前の多く (*ガラドリム*、*ペリアンナス*、*グラムホス*、*グワイス・イ・ミルダイン*) は複数の階級を形成しています。 このレッスンでは、トールキンの出版された著作から証明されたすべての例を使用して、4 つの主要な類複数接尾辞をすべて取り上げます。 

---

 ## 1. クラス複数形とは何ですか?

 クラス複数形は、**意味論的な範囲**において通常の複数形とは異なります。 

| タイプ | 例 | 意味 |
 |------|--------|----------|
 | 正規複数 | *ジェライ* | （いくつかの）木 |
 | 複数クラス | *ガラドリム* | ツリーピープル (ロスローリエンのエルフ全体) |

 通常の複数形 (*gelaidh*) は、庭にある 3 本の木を表すことができます。 複数のクラス (*ガラドリム*) は、ガラドリムを民族として表します。特定の数ではなく、集合的なアイデンティティです。 英語での *「エルフ」* (一部のエルフ) と *「エルフキンド」* または *「エルフの民族」* (全体として考えられる民族) の違いを考えてみましょう。 

シンダール語には **4 つの主要な類複数接尾辞**があり、それぞれに独自のニュアンスがあります。 

| サフィックス | コアの意味 | 一般的な使用法 |
 |----------|---------------|---------------|
 | *-ath* | 総集合体: すべて、全体 | 星、土地、名前付きの合計グループ |
 | *-リム* | 血族、人種、人々 (中立または肯定的) | 人種/民族の指定 |
 | *-ホス* | 敵対的なホスト、好戦的な大群 | 敵、オーク、狼男 |
 | *-グワイス* | 会社、組織された親睦団体 | 特定の人々のグループ |

 ## 2. サフィックス *-ath* — 合計集合体

 ### 意味と機能

 接尾辞 *-ath* は **全体性**、つまり、分割されていないグループとして見なされた、あるクラスの物事の *すべて* を表します。 これは類複数接尾辞の中で最も抽象的なもので、人だけでなく物 (星、土地) にも適用できます。 

トールキン自身も、メモの中で *-ath* を「集合的複数形」または「全体的なグループ」を示すものとして光沢を出しています。 それは多くの場合、一部の星だけではなく、*天国のすべての星*に壮大な感覚をもたらします。 

### 実証済みの例

 **1. *エレナス* — スター全員**

 最も有名な例は、賛美歌 *A Elbereth Gilthoniel* に登場します。 

> *メネル・アグラー・エレナス!*
 > 「天からすべての星々の栄光が！」

 ここで *elenath* = *elen* (星) + *-ath* です。 *elen* の最後の *-n* が *-ath* に同化し、*elenath* が与えられることに注意してください (別個の *n* を持つ *elenath* ではありません)。 その効果は、単に多くの星々を呼び出すだけでなく、**多数の星々**を単一の輝かしい全体として呼び出すことです。 

**2. *ennorath* — 中部地方すべて**

 *A エルベレス ギルソニエル* からも:

 > *ファヌイロス、ル・リンナソン / ネフ・エア、シ・ネフ・エアロン! / いいえ、私はユルマ ニン エンクァントゥバ / エルベレス ギルソニエル / ... いいえ、アーロン、いいえ、アーロン!*

 そして詩の前半ではこう言っています。 

> *A Elbereth Gilthoniel / o menel palan-díriel / le nallon sí di'nguruthos! / ティロニン、ファヌイロス!*

 *ennorath* (中つ国全体) の形式は次のとおりです。 
- *ennor* (中地、中つ国、*ened* 中部 + *dor* 土地から) + *-ath*
 - 意味: すべての中部地方、人の住む世界全体

 **3. *ペリアンナス* — すべてのハーフリング**

 *『王の帰還』* の有名な叫びで証明されています。 

> *Cuio i Pheriannath anann!* — 「ハーフリングが長生きしますように!」

 分析:
 - *ペリアン* (ハーフリング、ホビット) + *-ath*
 - *perian* の *n* は *-ath* の前に強化されます: *perian* + *-ath* → *Periannath* (鼻同化から二重の *-nn-* が表示されます)
 - 記事 *i* の下のソフト突然変異: *P* → *Ph* (*i Pheriannath*)
 - 叫び声はホビットたちを**完全な人々**として扱い、種族全体を尊重します。

**4. 理論上の *ゴンダス* — すべての石**

 *gond* (石、岩) + *-ath* → *gondath* — すべての石、すべての石 (ᴺS.; トールキンの出版されたテキストでは証明されていませんが、パターンによってよく形成されています)。 

### *-ath* の形成ルール

 1. **簡単な足し算**: 語幹 + *-ath* (*elenath*, *gondath*)
 2. **鼻同化**: *-n* で終わる語幹は *-ath* より前に促音になる場合があります (*perian* からの *Periannath*)
 3. **母音の変化**: 接尾辞が追加されると語幹の最後の母音が変化することがあります (シンダール語の他の言語で接尾辞によって母音が変化するのと同様)
 4. **ストレス**: *-ath* 単語では、単語が十分に長い場合、通常、ストレスは *-ath* の前の音節にかかります: *e·LE·nath*、*en·NO·rath*、*pe·ri·AN·nath*

 ## 3. 接尾語 *-rim* — 人物/親族

 ### 意味と機能

 接尾辞 *-rim* は、**人種、血族、または民族**、つまり共通のアイデンティティ、起源、または性質を共有する存在のグループを表します。 *-ath* (物事に適用できる) とは異なり、*-rim* はほぼ**知覚のある人々**にのみ使用されます。 その意味合いは中立から肯定的です。 *-rim* は敵意 (*-hoth* のドメイン) を意味するものではありません。 

### 実証済みの例

 **1. *ガラドリム* — 樹木人 (ロスローリエンのエルフ)**

 > *ガラド* (木) + *-リム* → *ガラドリム*

 トールキンは、*ロード・オブ・ザ・リング*を通じて、ロスローリエンのエルフにこの名前を使用しています。彼らの文化は、偉大なマローンの木によって定義されています。 この名前は「たくさんの木」を意味するものではなく、木に関わる**人々**を指します。 

*Galadhrim* 自体の不規則複数形は *Galadhrim* になります (クラス複数形はすでに集合的であり、2 番目の複数形マーカーは必要ありません)。 

**2. *ナウグリム* — ドワーフ**

 > *naug* (ドワーフ、発育不全者) + *-rim* → *Naugrim*

 *シルマリル*全体でドワーフの種族として使用されます。 代替の *Nogothrim* (ドワーフの別の単語である *nogoth* から) を比較してください。 両方とも証明されています。 *Naugrim* は、トールキンの出版されたテキストではより一般的です。 

**3. *オノドリム* — エンツ**

 > *オノド* (エント、木飼い) + *-リム* → *オノドリム*

 *Unfinished Tales* と *The Silmarillion* で使用される、種族としてのエントのシンダール語の名前。 個々の Ent は *onod* です。 集団種族は*オノドリム*です。 

**4. *Nogothrim* — ドワーフ (代替)**

 > *ノゴス* (ドワーフ) + *-リム* → *ノゴスリム*

 ドワーフの代替集団。 トールキンは *Naugrim* と *Nogothrim* の両方を使用しました。 それらは意味において同義です。 

**5. *グワトゥイリム* — 影の人々**

 > *グワトゥイ* (影) + *-リム* → *グワトゥイリム*

 トールキンのノートの一部でドルエダイン (野生人) に使用され、影や隠れた場所との関連性を示しています。 これは、*-rim* がエルフやドワーフだけでなく男性にも適用できることを示しています。 

**6. *ロヒリム* — 馬の主**

 ローハンの人々を表すシンダール語 (またはシンダール語の影響を受けた) の名前。 分析:
 - *roch* (馬) + *-ir-* (いくつかの名前に見られる接続要素) + *-im* (*-rim* の変形)
 - ロヒリムは自らを*エオルリンガ*と呼んでいます。 シンダール語の名前はゴンドールによって付けられました
 - 注: ここではサフィックスは *-im* (最初の *r-* なし) として表示されます。 *Rohirrim* = *Rohir-* + *-rim* ここで、*Rohir* = horse-lord (合成語 *roch* + *hîr* lord、音の変化: 合成語では *roch* → *rohi-*)

 ### *-rim* の編成ルール

 1. **簡単な追加**: ステム + *-rim* (*Naugrim*、*Onodrim*)
 2. **語幹形式**: 単数形の語幹を使用します (i 複数形ではありません): *noeg* ではなく *naug*
 3. **有声化**: 語幹終子音は *-rim* の前では変更されません。 *ガラド* + *-リム* = *ガラドリム* (dh 保存)
 4. ***-im*** に関する注意: 名前によっては、接尾辞が *-im* のみ (*-rim* の *r-* なし) として表示される場合があります。 これは、変形、または *r* が前の音節に吸収されていることを反映している可能性があります。

 ## 4. サフィックス *-hoth* — 敵対的なホスト

 ### 意味と機能

 接尾語 *-hoth* には **否定的で威嚇的な響き**が含まれます。**敵の大群、好戦的なホスト、脅迫的な群衆**を指します。 エルフ語話者が *-hoth* を使用するとき、彼らはグループが存在するだけでなく、それが**危険で敵対的である**ことを表現しています。 それは戦争と恐怖の階級複数の接尾辞です。

### 実証済みの例

 **1. *グラムホス* — 騒々しい大群 (オーク)**

 > *glam* (喧騒、大騒ぎ、喧噪、オークの言葉としても使用) + *-hoth* → *Glamhoth*

 シンダール語のエルフ語でのオークの名前。 *Glam* は、彼らの戦いの叫び声の文字通りのノイズと、混沌とした野蛮な騒乱の一般的な感覚の両方を捉えています。 *-hoth* を追加すると、「騒音ホスト」、つまり騒音と恐怖の大群になります。 関連する単語を比較します。 
- *glamor* (エコー; 共鳴) — 音韻的に関連した語根
 - *グラムドリング* (剣名: *グラム* + *ドリング* ビート/ハンマー = "敵のハンマー")

 **2. *ガウルホス* — ウェアウルフホスト**

 > *ガウル* (狼男) + *-ホス* → *ガウルホス*

 *シルマリル*より: トル・イン・ガウルホス (人狼の島) でサウロンに仕える狼人間のホスト。 トールキンは *Tol-in-Gaurhoth* = 「狼男ホストの島」 (*tol* 島 + *in* of-the + *Gaurhoth*) と書いています。 

**3. *バルコス* — 残酷な大群**

 > *balch* (残酷、横暴) + *-hoth* → *Balchoth*

 バルコス族は、TA 2510 (セレブラントの野の戦い) でゴンドールに侵攻したイースターリング人の連合です。 ゴンドリアの歴史家は彼らにシンダール語の *-hoth* 接尾辞を適用し、彼らを敵の大群としてマークしました。 *balch* (残酷) という要素は、トールキンの *語源* で証明されています。 

**4. 命名における *-hoth* の意味**

 トールキンが *-hoth* をエルフ、西洋人、ドワーフ、ホビットに対して決して使用せず、敵に対してのみ使用していることは重要です。 この接尾語は、言語にエンコードされた **文化的および道徳的判断** です。 グループを*[何か]-ホス*と呼ぶエルフは、彼らを敵としてマークしています。 

### *-hoth* の形成ルール

 1. 単純な加算: 語幹 + *-hoth*
 2. 語幹は通常、敵グループの「本質」を伝える単音節の語根または短い単語です。 
3. *-hoth* は語幹が特定の子音で終わる必要はありません。 それは自由に従う

 ## 5. 接尾辞 *-gwaith* — 会社/フェローシップ

 ### 意味と機能

 接尾辞 (または独立語) *gwaith* は、**人々、民俗、人々の集団**、具体的には共通の目的、技術、またはアイデンティティによって定義される**組織されたグループ**を意味します。 *-rim* (血または出身による人種/親族) とは異なり、*-gwaith* は、**活動内容** または **特定の親睦** によって組織されたグループを指すことがよくあります。 

*Gwaith* は、単独で「人々、ホスト、人々の地域」を意味する名詞としても使用できます。 

### 実証済みの例

 **1. *グワイス・イ・ミルダイン* — 宝石細工師の会社**

 > *gwaith* (会社) + *i* (属格冠詞の) + *mírdain* (宝石細工師、*mírdan* の pl.)

 リング・オブ・パワーを鍛造した、エレギオン（第二紀）のエルフ職人のケレブリンボルのギルドの名前。 フルネーム:
 - *gwaith* = 会社、人々
 - *i* = of the (属格冠詞に制限を付けたもの)
 - *mírdain* = 宝石細工師: *mír* (宝石、宝物) + *-dan* (職人、鍛冶屋) → pl. *ミールデイン*

 これは、*-gwaith* が実際に動作している**主要な例です。 

**2. *gwaith* としての独立名詞**

 トールキンは、「人々」または「人々の集団」を意味するために、いくつかの文脈で *gwaith* のみを使用します。 一部の複合地名では、*-wait* が「[場所] の人々」を表す接尾辞として表示されます。 
- *Gwathuirim* (上記のように *-rim* を使用しますが、*gwath-* 要素は *waith* ルートに関連します)

 ### フォーメーションノート

 *Gwaith* は、語幹に付加される実際の接尾辞としてではなく、**属格構文** (*gwaith* + 冠詞 *i* + 属格名詞) で最も一般的に使用されます。 それは「X 社」という複合的な責任者として機能します。

 ## 6. 適切なサフィックスの選択

 ネオシンダール語クラスの複数形を作成する場合、または証明された複数形を解釈する場合は、このガイドを使用してください。 

| コンテキスト | サフィックス | 例 |
 |----------|----------|----------|
 | グループのすべてのメンバー (合計集合体) | *-ath* | *エレナス* (オール ザ スターズ) |
 | 人種、血族、民俗 (中立/肯定的) | *-リム* | *ガラドリム* (木の民) |
 | 敵対的な大群または好戦的な敵グループ | *-ホス* | *Glamhoth* (オークの大群) |
 | 組織化された会社（目的別・技術別） | *-グワイス* | *Gwaith-i-Mírdain* (宝石鍛冶ギルド) |

 ### 実際の例

1. 「鷲の民」（中立、鷲の種族）: → *トロンドリム* ᴺS. (*トロン* イーグル + *-リム*)
 2. 「すべての山」（物事の総集合体）: → *エレダス* ᴺS。 (*ered* 山 + *-ath*)... でも待ってください — *ered* はすでに複数形です。 単数 *orod* のクラス複数形の場合: *Orodath* ᴺS。 
3. 「蜘蛛の大群」 (蜘蛛の敵軍): → *Ungoliath-hoth* ᴺS. または *ungolhoth* ᴺS。 
4. 「放浪者の交わり」: → *Gwaith i rambor* ᴺS. (放浪者の会社)

 ## 7. 冠詞のクラス複数形

 定冠詞 *i* が類複数名詞の前にある場合、**ソフト突然変異** が名詞の最初の子音に適用されます (*i* の後のすべての名詞と同様)。 

| 裸の形 | 記事付き | 突然変異 |
 |----------|---------------|----------|
 | *ペリアンナス* | *フェリアンナス* | P → Ph (ソフト突然変異) |
 | *ガラドリム* | *私はアラドリム* | G → ' (ソフト突然変異、g ドロップ) |
 | *グラムホス* | *私はラムホス* | Gl → 'l (ソフト突然変異) |

 例 *i Pheriannath* はトールキンのテキストで **完全に証明**されています (*Cuio i Pheriannath anann!*)。

 ## 8. クラス複数形成パターン — 概要

 ### パターンA: 直接取り付け
 語幹 + 接尾辞、語幹は変更なし:
 - *ナウグ* + *-リム* → *ナウグリム*
 - *ガウル* + *-ホス* → *ガウルホス*
 - *バルチ* + *-ホス* → *バルコス*

 ### パターン B: *-ath* 前の鼻同化
 *-n* で終わる語幹は鼻音を発音します。 
- *ペリアン* + *-ath* → *ペリアンナス* (*ペリアンナス*ではありません)
 - *elen* + *-ath* → *elenath* (ここでは *n* + *ath* は促音ではありません。*n* は語幹に属します)

 実際には、*Periannath* の促音は、*perian* + *-nath* (鼻音を接続した *-ath* の変形) → *Periannath* として説明する方が適切です。 これは学術的な議論の問題です。 結果 *Periannath* は完全に証明されています。 

### パターン C: ステムの切り詰め
 場合によっては、語幹が接尾辞の前で短縮されることがあります。 
- *Rohirrim*: *roch* (馬) は直接現れず、*-rim* の前に *Rohir-* (馬の主を意味する変形語幹形) として表示されます。

 ## 9. 完全な証明済みクラスの複数形リスト

 トールキンの出版された著作で強力な証明があるすべてのクラス複数形:

 | フォーム | 要素 | 意味 | 出典 |
 |------|----------|----------|----------|
 | *エレナス* | *エレン* + *-アス* | すべての星 | *エルベレス・ギルソニエル* |
 | *エンノラス* | *エンナー* + *-ath* | すべての中部地方 | *エルベレス・ギルソニエル* |
 | *ペリアンナス* | *ペリアン* + *-ath* | すべてのハーフリング | *RotK* |
 | *ガラドリム* | *ガラド* + *-リム* | 木の民 (ローリアン エルフ) | *LotR* パシム |

 ## 10. 練習: クラス複数形の形成

 指定された接尾辞を使用してクラスの複数形を作成します。 それぞれの ᴺS にラベルを付けます。 (ネオシンダール語) これらは独自の編成であるため、次のようになります。 

**演習 1** — *-ath* (合計)
 - *lhaw* (耳) → __________ (すべての耳)
 - *orn* (木) → __________ (森のすべての木)

 **演習 2** — *-rim* (血族/人種)
 - *edhel* (エルフ) → __________ (エルフの民)
 - *adan* (男性) → __________ (男性の種族)

 **演習 3** — *-hoth* (敵対的なホスト)
 - *drag-* / *draug* (オオカミ) → __________ (オオカミの大群)
 - *orch* (orc) — すでに *Glamhoth* を使用していますが、*orchoth* ᴺS を試してください。 

**演習 4** — *-gwaith* (会社)
 - 「エルフ領主の会社」 → *Gwaith i* + __________ ᴺS.

**模範解答**:
 1. *ラワス* ᴺS.; *オルナス* ᴺS. (複数形の場合は *yrn-ath*)
 2. *エドヘリム* ᴺS. (*edhel* + *-rim*、*l* + *r* 同化からの *ll* を含む) または *Edhel・rim*; *エダイン・リム* ᴺS. (ただし、*Edain* はすでに複数形になっています。単数形の *adan* から: *Adan·rim* ᴺS。)
 3. *ドラウホス* ᴺS。 または *ドラウゴス* ᴺS.; *オーコス* ᴺS.
 4. *グワイスとヘリン・エドヘレン* ᴺS. (エルフ領主の会社)

 ---

 ## 覚えておくべき重要なポイント

 1. **クラス複数形 ≠ 通常の複数形**: 数ではなく、集合的なアイデンティティを表現します。 
2. **4 つの接尾辞**: *-ath* (全体)、*-rim* (血族)、*-hoth* (敵対)、*-gwaith* (会社)
 3. **道徳的重み**: *-hoth* は常に軽蔑的です。 それを使用すると、グループが敵としてマークされます
 4. **冠詞 + クラス複数形**: ソフト突然変異をトリガーします (*i Pheriannath*)
 5. **ほとんどのクラス複数形は固有名詞です**: 特定のグループの名前です。 *-rim*/*-hoth* などを使用して一般的なクラスの複数形を形成することは可能ですが、通常はトールキンの世界では名前付きの人々のために予約されています。
