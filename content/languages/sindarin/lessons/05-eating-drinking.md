## なぜ語彙領域のレッスンなのか?

 言語を学習するには、**文法** (単語を組み合わせるルール) と **語彙** (単語そのもの) という 2 つの並行したトラックが必要です。 何も言うことがないと、純粋な文法の練習はすぐに抽象的になってしまい、やる気がなくなります。 文法の枠組みを持たない純粋な語彙リストでは、構成要素は得られますが、構造はありません。 最善のアプローチはそれらを交互に行います。 

このレッスンでは、レッスン 1 ～ 4 の文法を軽く復習して応用しながら、食べ物、飲み物、食事などの特定の語彙領域に焦点を当てます。 新しい単語を学び、実際の文で使われているのを見て、自分で単語を組み立てる練習をします。 *lembas* (エルフのウェイブレッド) は正典の中で最もよく証明されているシンダール語の名詞の 1 つであり、いくつかの関連単語がテキストに登場するため、食べ物/飲み物の領域もトールキンの世界では特に満足のいくものです。 

表記上の注意:
 - **S.** = トールキンの出版作品でシンダール語であることが証明されています
 - **N.** = 証明されたノルドリン (シンダール語の前身)
 - **ᴺS.** = ネオ シンダール語 (学術的な再構成。トールキン自身の造語ではありません)
 - **ᴺS.[N.]** = 証明されたノルドリンのルートに基づいて構築されたネオ シンダール語形式

 ## 食べることと飲むことの重要な動詞

 これら 3 つの動詞がレッスンの核心です。 それぞれはノルドリン語で証明され、通常のシンダール語形式を使用して新シンダール語で受け入れられます。 

### *mat-* — 食べること

| フォーム | シンダール語 | メモ |
 |------|----------|------|
 | 不定詞/語幹 | *マット* | 根。 化合物および誘導体で使用される |
 | 命令的（例） | *まど!* | "食べる！" — 命令型は、裸の語幹に *-o* を追加します (*mat-* + 母音短縮 + *-o*) |
 | 現在1sg | *マトン* | 「私は食べる」 |
 | プレゼント 1pl | *マサム* | 「私たちは食べる」 |
 | 現在の3sg | *マタ* または *マタ* | 「彼/彼女は食べる」 |
 | 過去形 | *マント* | "ate" — 鼻注を伴う強い過去 (*mat-* → *mant*) |

 過去形 *mant* は、シンダール語の強い過去形形成の最も明確に理解されている例の 1 つです (レッスン 18 で詳しく説明します)。 語幹の *t* と挿入された鼻音 *-n-* が組み合わさって *-nt* になります。 

### *sog-* — 飲む

 | フォーム | シンダール語 | メモ |
 |------|----------|------|
 | ステム | *ソグ* | ルート *SUK-* 「飲む」 (通常のシンダール語 *k* → *g* 母音の間と語幹の終わり) |
 | 命令的（例） | *そうだ!* | "飲む！" |
 | 現在1sg | *ソゴン* | 「私は飲みます」 |
 | プレゼント 1pl | *ソゴム* | 「私たちは飲みます」 |
 | 現在の3sg | *曽我* | 「彼/彼女は飲み物を飲みます」 |
 | 過去形 | *サンク* | "drank" — 母音変化 (*o* → *u*) と最後の *-c* を伴う強い過去 |

 ### *ped-* — 話す、言う

 | フォーム | シンダール語 | メモ |
 |------|----------|------|
 | ステム | *ペド* | 「話す、言う」 - 食事の文脈で「これは美味しいと言ってください！」に関連します。 |
 | 命令的（例） | *ペド!* | "話す！" — 有名なドゥリンの扉の碑文 |
 | 現在1sg | *ペドン* | 「私は話します」 |
 | 過去形 | *ペント* | 「スポーク」 |

 ## レンバス: 最も証明されているシンダール語の食べ物の言葉

 *レンバス* は、トールキンのシンダール語の中で最も豊かな単一単語の 1 つであるため、特別な扱いに値します。証明され、語源が解明され、文化的に説明され、別のエッセイ (*中つ国の人々* の *レンバス*について) でさえ議論されています。 

### 構成

 *レンバス* = *レン-* + *ムバス*

 - **lenn-** は *lend*「旅、道」から来ています。ルート *LED-*「行く、旅行する」から来ています。 同じ語根から *Lenwë* (出発した人)、*lendin* (道路) などが得られます。複合語では、最後の *d* が次の子音の前で消えます。 
- **mbas** = "パン" — パンを意味するシンダール語 (*mb-* の頭文字は、いくつかの複合語で生き残った古風な子音クラスターです。独立した単語では、第三紀シンダール語で *b-* に簡略化され、*bas* になります)。 
- 一緒に: *lembas* = 「旅のパン」 — 旅のために作られたパン。 

### ストーリー内のプロパティ

 *ロード・オブ・ザ・リング*では、レンバは次のように説明されています。 
- *マローン*の葉で包まれた金白色のウエハース
 - 古代のレシピを使用してエルフの手によって作られました
 ・栄養価抜群：「一口で大人のお腹を満たす」
 - 体だけでなく精神を維持する - 悪の生き物がフルパワーに近づくにつれて、食べるのが難しくなります
 - 長持ち: 適切に包装すれば、何週間も新鮮なままです。 

*lembas* という単語がテキスト自体に現れており、物語に直接シンダール語を借用していることがわかります。 

### 文化的背景

 トールキンのエッセイ「レンバスについて」では、このレシピはもともとヴァラールによってヴァリノールから持ち込まれたもので、第一紀のエルフに与えられ、熱心に守られていたことが明らかにされています。伝統的にエルフと彼らが完全に信頼する旅の仲間にのみ与えられていました。 フェローシップにレンバを与えることは、ガラドリエルからの深い信頼による行為でした。 

### 文中で *lembas* を使用する

 - *Matham lembas* = 「私たちはレンバを食べます」 (*matham* = 私たちは食べる + *lembas* = ウェイブレッド)
 - *Lembas naur veth* = 「Lembas [is] the last fire」 — *naur* (火) を比喩的に使用した詩的なもの
 - *Nân im maton lembas* — 「でも私はレンバスを食べる」 (*nân* = でも、逆接)

 ## エルフ文化における食事とおもてなし

 トールキンのエルフの描写で繰り返されるテーマの 1 つは、彼らと親切なもてなし、特に食べ物、飲み物、歌に関わるもてなしとの関連です。 裂け谷とロスローリエンにある偉大なエルフの広間は、次のような特徴があります。 

- ヴァリノールの饗宴を思い起こさせる、多くのゲストとの**共同食事**
 - **食事中の音楽** — エルフの食卓では歌は食事と同じくらい重要でした
 - **スペシャルドリンク**: 裂け谷の*ミルバー*は、偉大な旅の前に与えられる元気を与える心のこもった飲み物でした。 ロスローリエンの*ガレナ*（パイプウィードだが、典型的にはエルフのものではない）はエルフの習慣と対比されている

 *suilon le* (レッスン 2 より) という単語は、自然な食卓のオープニングになります。 *mado* (食べる!) と *sogo* (飲む!) が続くこれらの動詞は、エルフのもてなしの温かさを表現します。

 ## 練習問題

 **演習 1:** シンダール語に翻訳します:
 1. 私はパンを食べます。 (*アファドン* = パン)
 2.水を飲みましょう！ （必須、1名様に）
 3. 私たちはコーディアルを飲みます。 (*ミルヴァー*)
 4. 王様は食べました。 (過去形)
 5. レンバを食べますか? (レッスン 4 の *ma* 疑問助詞を使用)

 **答え:**
 1. *メイトン・アファドン*
 2. *そうだね!*
 3. *ソゴム・イ・ミルヴォル*
 4. *マント・イ・アラン*
 5. *Ma matag lembas?* (*matag* = あなたは食べる、2sg プレゼント)

 **演習 2:** 英語に翻訳してください:
 1. *Sunc im nen celw* = ?
 2. *まど、まど、メロン!* = ?
 3. *Mat i edhel lembas anann* = ? (*anan* = 長い間、長い間)

 **答え:**
 1. 「湧き水を飲みました」 (*sunc* = *sog-* の過去、*im* = 私、*nen celw* = 湧き水)
 2. 「食べて、食べて、友達！」
 3. 「エルフは長い間レンバを食べた」 (または: 「...長い間レンバを食べた」)

 | 単語/フレーズ | 意味 |

 | *ソゴ* / *ソゴ* | 飲む/飲む！ |
 | *マサム* | 私たちは食べる |
 | *ソゴン* | 私は飲みます |

 これで、日常生活の最も実用的な領域の 1 つについて実用的な語彙を習得し、命令形と現在形が使用されているのを見てきました。 レッスン 6 では、シンダール語の最も特徴的かつ重要な文法的特徴の 1 つである複数体系、特に単数名詞から複数形を作り出す i 愛情母音変化を紹介します。
