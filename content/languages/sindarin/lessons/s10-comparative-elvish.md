## 2 つの偉大なエルフ言語

 トールキンは、歴史言語学者が実際の言語族に適用するのと同じ注意を払って、2 つの主要なエルフ言語、シンダール語 (グレイエルフ語) とクエンヤ語 (高エルフ語) を設計しました。 ラテン語がウェールズ語と親戚であるように、それらは関連しています。どちらもインド・ヨーロッパ語族ですが、あまりにも長い間分岐していたので、異なる音声システム、異なる文法構造、そして根本的に異なる美学を持ち、相互に理解できないほどです。 

両方の言語を理解し、それらを明確に区別することは、トールキンのエルフ語を真剣に学ぶ人にとって最も重要なスキルの 1 つです。 トールキンの最も有名な「エルフ」のフレーズの多くは、シンダール語ではなくクエンヤ語です。これらを混同することは、ラテン語とイタリア語を混同するようなものです。

 ## 歴史的関係

 ### 家系図

 どちらの言語も、**原始クエンディアン** (エルフの第一言語) から **共通エルダーリン** (ヴァリノールに向けて出発したエルダール人の言語の共通の祖先) を経て派生しています。 

分岐点:
 - **テレリ** (最後に来た人々、中にはシンダール人として中つ国に残った人々もいます) 中つ国、ドワーフとの接触、そして数千年にわたる彼ら自身の進化を通じてシンダール語を発展させました
 - **ヴァンヤールとノルドール** (ヴァリノールに早く到着し、滞在した人々) は言語をより保守的に保ち、ヴァラールの影響下でクエンヤを発展させました

 第三紀までに:
 - **Quenya** = ラテン語または古典ギリシャ語に相当します。儀式的、古代の、権威ある、伝承や儀式に使用されます。 日常的に使用されているが、知識のある人には深く知られている「死んだ」言語
 - **シンダール語** = 現存する言語に相当します。ウェールズ語に似た、毎日話される、中つ国のエルフとドゥーネダインの共通言語です。 

ノルドール人が第一紀に中つ国に戻ったとき、すでにそこでシンダール語を話しているシンダール人を発見しました。 彼らは敬意を表して（そして親族殺害事件をめぐる政治情勢のため）、日常会話としてシンダール語を採用した。 クエンヤはキンスレのことを知った後、ドリアスのシンゴル王によって禁止された。 第三紀までに、裂け谷とロスローリエンのノルドールでさえ毎日シンダール語を話します。

 ## 識別: クエンヤからシンダール語を伝える

 | 特集 | シンダール語 | クエンヤ |
 |----------|----------|----------|
 | 全体的な音韻感 | ウェールズ語/ケルト語: 厳しい子音、鼻音 | フィンランド語/ラテン語: 滑らかな母音語尾、流れるような |
 | TH [θ]、DH [ð]、LH [ɬ]、RH [r̥] があります | はい - 非常に一般的です | まれに欠席する |
 | QU [kw]、NY [nj]、LY [lj]、TY [tj] を持つ | 珍しい | 共通 — 特徴 |
 | 母音 Y [y] あり (前が丸い) | はい — 独特です | いいえ |
 | 二重母音 AE [aɛ] を持っています。 はい — 一般的な | いいえ (代わりに AI を使用します) |
 | 単語は子音で終わることが多い | はい | まれに、ほとんどの単語は母音で終わります。 
| 確定記事(ザ) | *i* (sg)、*in* (pl) | なし — Quenya には記事がありません |
 | 突然変異システム | はい — 5種類、主な特徴 | 最小限 — 系統的な突然変異なし |
 | 語順 | VSO (デフォルト) | SOV (デフォルト) |
 | 形容詞の位置 | 名詞の後 | 名詞の前 |
 | 事件の結末 | いいえ — 前置詞を使用します | はい — 5 件以上 |
 | 複数形 | 内母音変化（i-affection） | 外部サフィックス (-r、-i、-ë) |
 | 属格構文 | *en* + ソフト突然変異 | 大文字と小文字の接尾辞 *-o* または *-va* |

 ### 簡易識別テスト

 フレーズまたは単語の場合:
 - **母音で終わる** → おそらくクエンヤ (ただし常にではありません)
 - **DH または LH を含む** → ほぼ確実にシンダール語
 - **NY または TY を含む** → おそらく Quenya
 - **単語の途中に母音として Y がある** → シンダール語の可能性が高い
 - **系統的な突然変異（最初の子音の変化）がある** → シンダール語
 - **名詞の後に格語尾がある** → Quenya

 ### *kw→p* シフト — シンダール語の最も劇的な音の変化

 シンダール語とクエンヤを分ける最も特徴的な特徴の 1 つは、シンダール語による共通エルフ語 *kw-* (および *tw-、pw-*) の扱いです。 クエンヤ語が *qu-* [kw] を維持した場合、シンダール語は *kw→p* にシフトしました。 その理由は次のとおりです。 
- CE *kwet-* (話す) → Q *quet-*、S *ped-*
 - CE *kwenê* (エルフ、話す人) → Q *クエンディ*、S *ペント*、それとも*ペニ*?

 この変化は、トールキンがシンダール人の一部、つまり異なる音韻習慣にとってクエンヤが「発音できない」と書いた理由でもある。

 ## 文法の比較

 ### 主な構造の違い

| 特集 | シンダール語 | クエンヤ |
 |----------|----------|----------|
 | **複数形** | 内部母音変化 (*i-affection*): *aran→erain* | 外部サフィックス: *elen→eleni* または *eldar→eldari* |
 | **ケースシステム** | なし — すべての関係に前置詞を使用します。 5 つ以上の格: 主格、対格、属格、与格、頭格、位置格 |
 | **語順** | VSO (文の最初に動詞) | SOV (文の最後に動詞) |
 | **確定記事** | *i* (sg)、*in* (pl) — 突然変異をトリガーします | なし — クエンヤに記事はありません |
 | **動詞の一致** | 動詞の人称接尾辞 | 人称接尾辞 + 代名詞的な主語 |
 | **突然変異システム** | ソフト、点鼻、混合、液体、ストップの5種類 | 最小限/なし — 体系的な頭子音の突然変異なし |
 | **形容詞の位置** | 名詞の後 (*aran veleg* = 偉大な王) | 名詞の前 (*alta aran* = 大王) |
 | **属格** | 前置詞 *en* + ソフト突然変異 | 格接尾辞 *-o* (短属格) または *-va* (形容詞属格) |
 | **コピュラ「to be」** | *na-*、不規則。 しばしば省略される | *ná*、より普通 |
 | **動詞の時制** | 現在、過去 (歯科接尾辞 *-ant-*)、過去の受動態 | より精巧な時制システム |

 ### 記事: 重要な診断

 定冠詞 (*i*、*in*) の存在は、直接のシンダール語マーカーです。 クエンヤには記事がありません。 それで:
 - *i aran* = 王 (シンダール語)
 - *aran* = 王または王 (Quenya — 無冠詞)

 クエンヤ語には冠詞がなく、シンダール語の冠詞は突然変異を引き起こすため、明確な名詞を含むほぼすべてのシンダール語文では、名詞の最初の子音が突然変異して表示されます。 これは実用的な迅速な識別テストです。

 ## いつどの言語を使用するか

 ### 文化的および歴史的背景

 **シンダール語を使用する場合:**
 - 中つ国 (第三紀) での日常のスピーチ
 - 裂け谷、ロスローリエン、ミルクウッド、グレイヘブンのエルフに宛てて
 - ドゥーネダイン (北のレンジャー、高い血統のゴンドリアン) と話す
 - 中つ国に住むエルフとの実践的なコミュニケーション
 - シンダール語を話すエルフによって付けられた人名

 **Quenya を次の目的で使用します:**
 - 正式な儀式、宣誓、高尚な儀式
 - ヴァラールへの呼びかけ、または祈りの中で
 - エルフの伝承詩 (*Namárië* の嘆きのような)
 - ヌーメノール人の記録と碑文
 - 遠い昔のエルフの工芸品の名前
 - トールキン自身が「ハイエルフ」レジスターを使用するあらゆる文脈

 **中世ヨーロッパとの類似点:**
 教養のある中世ヨーロッパ人は、ラテン語（学習、教会、儀式の言語）と独自の言語（フランス語、英語、ドイツ語）の両方を知っていました。 彼らはパンを買うためにラテン語を使用しませんでしたが、大衆文書や法的文書にはラテン語を使用しました。 同様に、教養のあるエルフやドゥーネダインは、シンダール語 (日常) とクエンヤ (儀式) の両方を知っていますが、朝食時にクエンヤ語を使用しません。

 ## 誤った同族体と混同点

 次のような単語や状況は、多くの学習者をつまずかせます。

| トラップ | 説明 |
 |------|---------------|
 | *le* = 両方の「あなた」 | S. と Q. はどちらも「あなた/あなた」を表す *le* を使用しますが、構文上の役割と形式は異なります。 Quenya の *le* は丁寧/敬意を表す形式です。 シンダール語では標準的な二人称代名詞です。 
| 名前の *ar* 対 Quenya *ar* | クエンヤでは、*ar* = "and"; シンダール語では *ar-* in names = "高貴/王室の接頭語" (*アラゴルン、アルウェン*); ただし、シンダール語の "and" = *a* (*ar* ではありません) |
 | *アラン* = 両方の王 | 同じように保存されている単語の 1 つ。 コンテキスト (フレーズの残りの部分の言語) によって、使用している言語が決まります。 
| *menel* = 両方の空 | 別の保存された形式。 どちらの言語も空/大空を表すのに *menel* を使用します。 
| *lómë* = 夜 (Q. のみ) | クエンヤは夜を表す言葉。 シンダール語では *fuin* (暗闇) または *dû* (夕暮れ) を使います。 *lómë* をシンダール語として決して使用しないでください。 
| *ナマリエ* = クエンヤ | ロスローリエンからの出発時にガラドリエルが歌った有名な別れの嘆きは、完全にクエンヤ語であり、シンダール語ではありません。 シンダール語の別れ = *ナヴァール* |
 | *エレン・シラ...* = クエンヤ | フロドの挨拶（「私たちの出会いの時間に星が輝きます」）は、ビルボ/ガンダルフから教えられたクエニヤです。 シンダール語ではありません |
 | *エルベレス...* = シンダール語 | 星の賛美歌（シャイアと裂け谷のエルフによって歌われる）はシンダール語です。 これはシンダール語が使用される一般的な例です。 

### *Namárië* について知っておくべき 3 つの最も重要な事柄

 1. シンダール語ではなく、すべての単語がクエンヤ語です。 
2. これは、あらゆる言語で証明されたトールキンの最長の連続エルフ文書です。 
3. *Namárië* 自体は、「元気でいてください」 (*namba-* be good + *-rë* オプション) を意味します。つまり、「お別れしますように」は「あなたと一緒にいられますように」という意味です。 

シンダール語に相当する別れは *Navaer* — *na-* (be) + *vaer* (*maer* の良い、柔らかい突然変異) — 同じ意味内容ですが、数千年にわたる分岐のため、まったく異なる響きの単語です。

 ## トールキンのバイリンガル文章を読む

 トールキンは、同じ場面でシンダール語とクエンヤ語を混ぜることがよくありました。 どの言語がどの言語であるかを認識することが重要です。 

| テキスト | 言語 | キーマーカー |
 |------|----------|---------------|
 | *エルベレス ギルソニエル / シリレン ペンナ ミリエル...* | シンダール語 | *A* (助詞)、*penna* (斜め下)、*míriel* (*-iel* 女性接尾辞) |
 | *Namárië / アイ！ ラウリエ・ランタール・ラッシ・スリネン...* | クエンヤ | 滑らかな母音の多い行、*-inen* 位置接尾辞、*lantar* (fall, pl.) |
 | *Elen síla lúmenn' omentielvo* | クエンヤ | *-elvo* 属格の二重接尾辞。 *lúmenn'* = *lúmenna* (正時、比喩) |
 | リングの刻印: *Ash nazg durbatulûk...* | 黒人のスピーチ | まったくエルフ的ではありません。 耳障りな、裏子音、異質な構造 |
 | *Cuio i Pheriannath anann!* | シンダール語 | *i Pheriannath* = 冠詞 + 突然変異を持つホビット |
 | *ペドメロンとミンノ* | シンダール語 | 記事 *a* = "および" (クエンヤ *ar* ではなくシンダール語); *minno* の *m* の突然変異 |

 ### ノルドールのエルフのバイリンガリズム

 第一紀に中つ国に戻ったノルドール人は、もともとクエンヤ語を話していましたが、シンダール語を採用しました。 第三紀までに、エルロンド、ガラドリエル、グロールフィンデルはバイリンガルになっています。 彼らがクエンヤを使用するときは、儀式、詩、伝承、または感情の高揚など、常に特定の理由があります。 

したがって、フェローシップがロスローリエンから出発する際に、ガラドリエルがクエンヤで「ナマリエ」を歌うという選択には意味がある。彼女は記憶と不死の地の言葉で歌う。なぜなら、彼女はヴァリノールを目にし、そこに戻ることを知っている者として話しているからである。 シンダール語の別れの*ナヴァール*だけでは、その瞬間の重みを表現するには不十分でしょう。
