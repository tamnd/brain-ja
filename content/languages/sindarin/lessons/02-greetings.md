## トールキンの証明されたフレーズ

 多くの人工言語と比較して、シンダール語の最も興味深い特徴の 1 つは、トールキンが *『指輪物語*』、その付録、および未発表の原稿 (その多くは *中つ国の歴史* シリーズや *パルマ エルダランベロン* 誌に掲載されている) 全体に、文法的に分析可能な実際のフレーズを埋め込んでいることです。 これは、学習者の最初の文章が、後のファンの創作ではなく、本物のトールキンである可能性があることを意味します。 

このレッスンのすべてのフレーズは、トールキンの著作で**直接証明**されているか、**最小限の再構成**です。つまり、独創的な飛躍はなく、証明された文法規則によって結合された証明された単語のみが使用されています。 フレーズに不確実性がある場合は、その旨を明記します。 証明されたシンダール語は **S.** とマークされ、証明されたノルドリン (シンダール語に組み込まれた初期のバージョン) は **N.** とマークされ、再構成された新シンダール語は **ᴺS.** とマークされます。

 ## ご挨拶

 | シンダール語 | 発音 | 翻訳 | メモ |
 |----------|------|---------------|------|
 | *前ゴバンネン!* | /まい ɡɔˈvannɛn/ | よく会ったね！ | **S.** 標準的なエルフの挨拶。 LotR 全体で使用されます (グローフィンデルはこれでホビットたちに挨拶します)。 点灯。 「よく会ったね。」 |
 | *ヴェドゥイ'!* | /ˈvɛdui/ | 雹！ こんにちは！ | **S.** ブライネンの浅瀬でグロールフィンデルがフロドに使用。 アポストロフィは最後の母音の省略を示します (*vedui・e* → *vedui'*)。 |
 | *スイラッド!* | /ˈスイラド/ | こんにちは！ | **N./ᴺS.** 動詞*suila-*から「挨拶する、敬礼する」。 *vedui'* よりもフォーマルです。 |
 | *電子政府による統治* | /ɛːl ˈsiːlɑ ˈɛrin luː ɛ ɡɔˈvɑnɛd viːn/ | 待ち合わせの時間に星が輝く | **S.** 古典的なエルフの挨拶をシンダール語で表現したもの。 *êl* = 星、*síla* = 輝く、*erin* = (+ ソフトな突然変異)、*lû* = 時間、*e-govaned* = 会議、*vîn* = 私たち。 |

 ** *Mae govannen* に関する文化的メモ:** エルフは、何年も離れていた後の出会いや、特別な人物との初めての出会いなど、出会いがまれで有意義であることが多かったので、この挨拶を使いました。 文法はこれをエンコードします。*govannen* は *govad-* (一緒に会う、一緒に来る) の過去受動分詞なので、このフレーズは文字通り「よく会ったね」または「よく会ったね」を意味します。 相互的で受動的な構造は、会議が共有のイベントであり、ある人が別の人に何かをするわけではないことを強調します。

 ## さようなら

 | シンダール語 | 発音 | 翻訳 | メモ |
 |----------|------|---------------|------|
 | *ナバール!* | /ˈnavaɛr/ | 別れ！ | **S.** *na* (be) + *vaer* (*maer* の良寛容形) で構成されます。 つまり文字通り「元気になれ！」 または「いいかも！」 — 相手の幸福を願う気持ち。 *na* の後の *m* → *v* の突然変異は通常のソフト突然変異です (レッスン 10–11)。 |
 | *ノヴァエル!* | /ˈnɔvaɛr/ | 別れ！ | **S./ᴺS.** *navaer* のバリアント。 *no-* 形式は、代替の命令/選択を表します。 どちらの形式もトールキンの言語ノートに引用されています。 |

 ***ナバール*の内訳:**
 - *na* = "be" (動詞 *na-* の命令法/選択法、レッスン 26)
 - *vaer* = *maer* の緩格形 (良い、素晴らしい、優れた)
 - 合体：「頑張れよ！」 → 別れの挨拶として「ご無事でありますように！」
 - ここでの *m* → *v* のソフト突然変異は、あなたが遭遇する最初の突然変異トリガーです。単語 *na* は次の単語にソフト突然変異を引き起こします。 (これについてはレッスン 10 ～ 11 で詳しく説明します。)

 ## 感謝と礼儀正しさ

 | シンダール語 | 発音 | 翻訳 | メモ |
 |----------|------|---------------|------|
 | *ハノン ル* | /ˈhannɔn lɛ/ | ありがとうございました（1名様に） | **S.** LotR で直接証明されています。 *Hannon* = 感謝します (*hanna-* の 1 sg プレゼント)、*le* = thee/you (sg. 代名詞)。 フロドが鏡の前でガラドリエルに使用した。 |
 | *ル・ハノン* | /lɛ ˈhannɔn/ | ありがとうございます (「あなた」を強調) | **ᴺS.** わずかに強調するために代名詞を前に付けた変形 — 「私はあなたに感謝します。」 |
 | *紅蓮のベッドエンニ* | /ˈɡurɛn bɛːd ˈɛnni/ | 私の心は私に告げます | **S.** 「The Road Goes Ever On」（トールキンの連作歌曲）より。 *紅蓮* = 私の心 (*gûr* + 所有格 *-en*)、*bêd* = 言う/言う、*enni* = 私に。 |

***hannon le* について:** このフレーズは、トールキンの世界において非常に直接的で親密な性質を持っています。 *Le* は、親しみのある/親密な二人称代名詞であり、*mae govannen* やその他の親密なフレーズに現れるのと同じ単語です。 フロドがガラドリエルに *hannon le* と言うとき、より正式な構文ではなく *le* (おなじみの) を選んだのは、エルフ特有の親密さを反映しています。エルフは、愛する先生や親に対してフランス語で *tu* を使うように、親密な範囲で尊敬する人々に呼びかけます。

 ## *ロード・オブ・ザ・リング* の一般的なフレーズ

 以下は、本文中の最も有名な証明されたシンダール語の一節です。 

| シンダール語 | 発音 | 翻訳 | 出典 |
 |----------|------|---------------|----------|
 | *ル・アブドレン* | /lɛabˈdɔllɛn/ | 遅れました | 付録のアルウェンからアラゴルンまで。 *Le* = あなた、*abdollen* = 「遅れて到着」（「遅れて到着する」を意味する *ab-tol-* の過去分詞）。 |
 | *ペドメロンとミンノ* | /ˈpɛdɔ ˈmɛllɔn a ˈminnɔ/ | 話して、友達になって、入ってください | ドゥリンの扉の碑文。 *ペド* = 話す! (*ped-* の命令)、*メロン* = 友達、*a* = そして、*minno* = 入ってください! (*min-* の必須)。 |
 | *Cuio i Pheriannath anann!* | /ˈkuiɔ i ˈfɛriannɑθ ˈɑnɑnn/ | ハーフリングが長生きしますように！ | コーマレンのお祝い。 *クイオ* = ライブ! (*cuia-* のオプション/必須)、*i Pheriannath* = ハーフリング (*ph-* は *p-* となります)、*anan* = ロング (副詞)。 |
 | *ライタ テ、ライタ テ!* | /ɑ ˈlaitɑ tɛ ˈlaitɑ tɛ/ | 褒めて褒めて！ | コーマレン。 *A* = 感嘆詞、*laita* = 賞賛! (*laita-* の命令)、*te* = 彼ら。 |
 | *アンダブ・ライトヴァルメット!* | /ɑnˈdɑvɛ lɑiˈtuvɑlmɛt/ | いつまでも彼らを讃えましょう！ | 同じシーンです。 *Andave* = 長い（副詞、*and* から）、*laituvalmet* = 私たちは彼らを賞賛します（複雑な動詞形）。 注: 一部の学者は、このフレーズをクエンヤ語、または正式な儀式で使用されるクエンヤ語とシンダール語の混合語として分類しています。 |

 ### 詳細分析: *ペド メロンとミノ*

 これはトールキンの作品の中で最も有名なフレーズの 1 つ、「ドゥリンの扉の謎」です。 ガンダルフの間違いは、それが実際には指示（「『友達』と言って入ってください」、つまり単に「メロン」という単語を言うだけ）であるのに、説明（「『友達』と言って入ってください」）として読んだことです。 

- **Pedo**: *ped-*「話す、言う」の命令形 (命令形)。 主動詞の命令形は *-o* を追加することで形成されます: *ped-* → *pedo*。 (これについてはレッスン 17 で詳しく説明します。)
 - **メロン**: 「友達。」 ルート*MEL-*から「愛すること」。 *mel-* (愛する) と *meleth* (愛) に関連しています。 同じ語根からクエンヤ *メルコール* が得られます (力の中で生じる者 — 別のルート — 実際には *メルコール* は *メル-* から来たものではありませんが、*メロン* 自体は明らかです)。 
- **a**: 接続詞「そして」。 シンダール語では非常に一般的です。 
- **minno**: *minna-* の命令形「入る、入る」。 *みんな-* + 命令語*-o* → *みんな*。 

命令形 (動詞 + *-o*) は、*cuio* (ライブ!)、*sogo* (ドリンク!)、*mado* (食べる!) にも再び表示されます。これは生産的で規則的なパターンです。

 ## コーマレンでの賛美

 *『王の帰還*』のコーマレンの祝賀シーンには、証明されたシンダール語が驚くほど集中して含まれています。 指輪が破壊された後、ゴンドールとローハンの主人は指輪持ちたちを称賛します。 

*ライタテ、ライタテ！ アンダブ・ライトヴァルメット！ コルマコリンドール、ライタ タリエンナ!*

 これを内訳すると次のようになります。 
- *A* — 感嘆詞「O! Ah!」
 - *laita te* — 「彼らを褒める」 (*laita* = 命令形、*te* = 彼ら、3pl オブジェクト代名詞)
 - *laita te* — 強調のために繰り返します
 - *Andave* — 「長い間、長い間」（副詞）
 - *laituvalmet* — 「私たちは彼らを賞賛します」 (未来時制 1pl に 3pl オブジェクト接尾辞。おそらく Quenya 形式)
 - *Cormacolindor* — 「リングベアラー」 (おそらくクウェンヤ: *corma* = リング + *col-* = bear + *-indo-r* pl.)
 - *a laita tárienna* — 「そして高みへの賛美/高みへの賛美」 (*tári* = 女王/高さ、*-enna* = 与格接尾語)

**言語上の注意:** 儀式のスピーチにおけるシンダール語とクエンヤ語の形式の混合は意図的です。 ゴンドールのヌーメノール系民族の間の正式な儀式では、高尚なスタイルとしてクウェンヤがよく使用されましたが、一般的なスピーチはシンダール語でした。 このシーンはそのバイリンガリズムを表しています。

 ## *メイ・ゴバンネン* を一言ずつ打ち破る

 このフレーズにはいくつかの重要な文法的特徴が含まれているため、詳細に研究する価値があります。 

**前** [まい]
 - 副詞: 「まあ、良い、素晴らしい」
 - 上記の *Navaer* にも見られる *maer* (形容詞「良い、良い」) に関連します (*vaer* = lenited *maer*)
 - Quenya *máre*「良い、まあ」と同源

 **ゴバンネン** [ɡɔˈvannɛn]
 - *govad-* の過去受動分詞 (会う、集まる)
 - *Go-* は「一緒に、一緒に」を意味する接頭辞です (ルート *WO-*「一緒に」から)
 - *-pad-* または関連ルートは「会議」の意味を与えます
 - *-(n)nen* はシンダール語の過去受動分詞語尾です。 
- つまり: *go-* + 動詞語根 + *-nnen* → *govannen* = 「一緒に出会った、一緒に出会った」

 **フレーズ全体:** 明示的な主語代名詞はありません。動詞形式 *govannen* は「私たち」を暗示します。 この文は受動態/分詞構造になっています:「(私たちは) (一緒に) よく会っています。」 それは事実の表明（「私たちはよく会えました」）でもあり、また喜びの表現（「私たちは何と素晴らしいものに出会えたでしょう！」）でもあります。 

この二重の特質、つまりステートメントと感情表現の両方が組み合わさったものは、非常にエルフ的です。 トールキンのエルフは、個別の感情的な言葉を追加するのではなく、その文法そのものに感情をコード化する正確な言語を好む傾向があります。

 ## 対話の練習

 レッスン 1 の発音ルールを適用して、この短いやりとりを声に出して読んでください。 

> **アランディル:** *メイ ゴバンネン!*
 >
 > **エレンミル:** *メイゴバンネン！ エレンミールです。 マン・アイ・ネス・リン?*
 >
 > **アランディル:** *私はアランディルです。 ハノン・ル*
 >
 > **エレンミル:** *ゲリルは私です。 ナヴァール!*
 >
 > **アランディル:** *ナヴァール!*

 翻訳:
 - 「よく会ったよ！」
 - 「よく会った！私はエレンミアです。あなたの名前は何ですか？」 (*man* = 何、*i eneth* = 名前、*lín* = あなたの)
 - 「私はアランディルです。ありがとう。」
 「よかったです。さようなら！」
 - "別れ！"

 別れ際に両方の話者が *Navaer* と言っていることに注意してください。 これは通常のパターンです。去る者だけでなく、双方がお互いに別れを告げます。 エルフの別れの文化は相互的で温かい傾向があります。

 ## 概要

 これで、基本的なシンダール語の会話を開始、終了、ナビゲートするための本物のトールキンのフレーズのコア セットが完成しました。 覚えておくべき主なパターン:

 1. **Mae govannen** = 「よく会いました」 - エルフの普遍的な挨拶
 2. **Hannon le** = 「ありがとうございます」 — 動詞の後に直接目的語代名詞 *le* が続きます
 3. **Navaer** = 「別れ」 — *na-* + 寛容な *maer* の命令形
 4. **Pedo mellon a minno** = 「友達と話して入ってください」 — 命令形 + 名詞 + および + 命令形
 5. **Im ...** = 「私は ...」 — 自己紹介の強調代名詞、動詞は不要

 レッスン 3 では、シンダール語が地名を構築する方法を見て、中つ国の地理を解読するためのツールを提供します。
