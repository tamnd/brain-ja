## はじめに

 これはシンダール語コアコースの最後のレッスンです。 最後に、これまで学んだことすべてに関わるトピックで終わります。**省略** — スピーチや詩の中で単語が一緒に流れるときに母音を脱落または短縮することです。 エリシオンはシンダール語の「結合組織」です。 それが言語を停止させるのではなく、流動的で音楽的に聞こえるようにするのです。 

また、トールキンがシンダール語のテキストで使用している 3 つの句読点、アポストロフィ (*'*)、ハイフン (*-*)、および凸ドット (*・*) についても再検討します。それぞれは、頻繁に混同される別個の機能を持っています。 

省略分析の後、このレッスンは 41 レッスン コース全体の簡単な振り返りと推奨される次のステップで終了します。

 ＃＃１．エリシオンとは何ですか？ 

**省略** とは、2 つの単語が近接して話されるときに、1 つ以上の音 (通常は母音) が省略または短縮されることです。 ぎこちない母音の休止（異なる単語からの 2 つの隣接する母音）を除去することで、音声をよりスムーズにします。 

英語では、省略は短縮形としてよく知られています。 
- 「私は」→「私は」（*a*の省略）
 - 「しない」→「しない」（*o*の省略）

 詩では、拍子を維持するために省略が不可欠です。 
- シェイクスピア: 「精神の支出」 — *the* の *e* は *expense* の前に省略されます

 **シンダール語**では、省略が表示されます。 
1. **詩** (*linnad*) — 音節数と音楽の流れを維持するため
 2. **散文** — 特定の一般的な短い単語が母音頭の単語の前にある場合
 3. **文法化された融合**として — 省略が文法形式の固定特徴となっている場合

 ## 2. シンダール語の 3 つの句読点

 トールキンは、シンダール語のテキストの中で、学生がよく混同する 3 つの特別な記号を使用しています。 

### アポストロフィ *'*

 トールキンのシンダール語のアポストロフィは、**2 つのまったく異なる機能** を果たします。 

**機能 1: *g-*** のソフト突然変異

 ソフト突然変異が最初の *g-* に適用されると、*g* は消え、アポストロフィが付けられます。 
- *galadh* (木) → ソフト突然変異後の *'aladh*
 - *i galadh* → *i 'aladh* (木; g はソフト突然変異でドロップ)

 これは**省略ではありません** - 子音の突然変異です。 アポストロフィは、*g* が存在したが削除されたという事実を示します。 

**機能 2: 詩における母音の省略**

 詩的なテキストでは、アポストロフィを使用しないと 2 つの母音が衝突する場合に、省略された母音をマークすることがあります。 
- 母音の最初の単語の前に *-a* または *-e* で終わる単語: 最後の母音が削除されます。 
- 何かが省略されていることを示すためにアポストロフィが付いています

 ### ハイフン *-*

 ハイフンは、1 つの単語に完全には融合されていないものの、近い単位として話される 2 つの要素間の **緊密な文法的つながり** を示します。 

**動詞の形に付けられる接頭辞**:
 - *palan-díriel* (遠くを見つめる、遠くを見つめた彼女) — *palan-* 接頭辞 + *díriel* 分詞
 - *na-chaered* (遠く離れた場所) — *na-* + *chaered* (軟/鼻の突然変異あり: *c*→*ch*)

 **属格助詞を含む複合体**:
 - *Bar-en-Danwedh* — ホーム + *en* (of-the) + *Danwedh* (身代金)
 - *トールインガウルホス* — 島 + *イン* (の) + *ガウルホス*

 **名前内の 2 つの形容詞または要素**:
 - *Iarwain-Ben-adar* (最年長で父親なし — トム・ボンバディルの完全なシンダール語の称号)

 ハイフンは省略や突然変異を示すものではありません**。 **複合結合**または**プレフィックス接続**をマークします。 

### 盛り上がったドット *・*

 トールキンは、**接点**を示すために、原稿の中で**隆起点** (・) または**中点**を使用することがありました。これは、構文的に非常に密接に結合しているため、ほとんど 1 つとして発音される 2 つの別々の単語です。 

- *i·Mbair Annui* — 「西部の土地」: *i* (記事) *·* (近い接続点) *Mbair* (鼻音の変異のある土地: *b*→*mb*)
 - *an·i·laes* ᴺS. — 「葉へ」: 前置詞 *an*、次に *i* (冠詞)、次に *laes* (葉)、すべてが密接に結合しています

 現代のシンダール語の編集者や学者は、完全な融合を行わずにこの緊密な結合を表すために浮き上がった点を使用します。 これはトールキン自身の原稿の一部にシンダール語のフレーズが登場しており、学術上の慣例として採用されています。

 ## 3. シンダール語の母音省略: 基本ルール

 ### ルール 1: 冠詞 *i* + 母音の頭文字

冠詞 *i* (the) が母音で始まる単語の前にある場合、正式な散文では **省略はありません** - 2 つの母音が中断されます。 
- *i aran* (王) — *i* + *a* → 休止、両方の母音を発音

 ただし、**早口**や**詩**では、*i* が次の母音の前に半母音 *y* になる場合や、この 2 つが混在する場合があります。 トールキンは証明されたテキストの中でこれを体系的にマークしていないため、主に自然な発音の問題です。 

### ルール 2: 前置詞 + 母音の頭文字

 一部の前置詞は、母音の前で自然に短縮または省略されます。 

**前置詞 *a* (および、助詞)**

 母音頭語の前の呼称/接続詞 *a*: *a* + *Elbereth* = *A Elbereth* — この場合 **省略なし**。 トールキンは、*a* を別に立てて *A Elbereth* と書きます。 *a* が保持されるのは、これが呼びかけ (誰かに呼びかけること) を示しており、中断が意図的であるためです。 

**前置詞 *o* (from)**

 *o* + 母音の頭文字: トールキンは *o* の立ち位置で *o Imladris* (裂け谷から) と書きます。 省略はありません。 またしても休止状態が維持されます。 

**前置詞 *na* (at、to、for)**

 子音の前に *na-* があり、その後変異します: *na-chaered* = na + *caered* (ソフト/鼻音変異 *c*→*ch* あり)。 これは、省略ではなく、ハイフンでつながれた接頭辞形式です。 

### ルール 3: 詩的な省略

 **エルフの詩** (*linnad*) では、拍子の音節数を調整するために省略が使用されます。 
- 母音の最初の単語の前に *-a* で終わる単語: *-a* は省略される場合があります
 - アポストロフィを使用して記述する: *o'Imladris* は、*I* の前の *o* を省略することを示します。 

トールキンは、詩的省略の十分に機能した例をあまり示していませんが、その原理は彼の詩形式の一般規則から明らかです。

 ## 4. *A Elbereth Gilthoniel*: 行ごとの省略分析

 音韻接合部を研究するのに最適なシンダール語のテキストは、賛美歌 *A Elbereth Gilthoniel* です。 接合現象のすべてのインスタンスについて調べてみましょう。 

### 全文 (*ロード・オブ・ザ・リング*、「多くの会議」より)```
A Elbereth Gilthoniel,
silivren penna míriel
o menel aglar elenath!
Na-chaered palan-díriel
o galadhremmin ennorath,
Fanuilos, le linnathon
nef aear, si nef aearon!
```### 分析

 **1行目**: *エルベレス・ギルソニエル*
 - *A* = 呼びかけ助詞（エルベレスに呼びかける）; *E* の前の休止 — 省略されません。 一時停止には意味がある
 - *エルベレス* = ヴァルダ (シンダール語) の名前。 *エル* (スター) + *ベレス* (クイーン) より — スタークイーン
 - *Gilthoniel* = *gîl* (星) + *thon-* (燃え上がる、火を起こす) + *-iel* (X をした人、女性分詞) = 「星を燃やした彼女」からのヴァルダの形容詞
 - **この行には省略はありません**。 アポストロフィのない接続点は、重みと明瞭さのために意図的に使用されています。 

**行 2**: *シリレン ペンナ ミリエル*
 - *silivren* = きらめく (星のように): *silif-* (銀色の輝き) + *-ren* (形容詞接尾語)
 - *ペナ* = 傾斜、傾斜; ここでは「斜めに/降り注ぐ」
 - *míriel* = 宝石のように輝く: *mîr* (宝石) + *-iel* (like-a、形容詞的に使用される分詞形)
 - **接続メモ**: *silivren Penna* — 両方とも子音で終わる/始まります。 省略はありません。 *penna míriel* — *penna* は *-a* で終わります。 *míriel* は *m* で始まります。母音の衝突や省略は必要ありません。 
- **頭韻**: *silivren...sil...* — *s/s* 頭韻は意図的な詩的な音楽です

 **行 3**: *メネル アグラー エレナス!*
 - *o* = from (前置詞)
 - *メネル* = 天、大空
 - *aglar* = 栄光、輝き (*aglar* = 輝きから、*agar* の血に関連していますか? いいえ — *aglar* = 栄光、*'gl-* ルートから)
 - *elenath* = すべての星 (クラス複数形: *elen* + *-ath*)
 - **接続点分析**: *o menel* — *o* + *m*: 母音の衝突なし。 *menel aglar* — *-el* 語尾 + *a-* 頭文字: hiatus *el.a* — 早口で話す場合、これは省略される可能性がありますが、トールキンはこれを 2 つの単語として書いています。 *aglar elenath* — *-ar* 末尾 + *e-* 頭文字: hiatus *ar.e* — これも省略なしで書かれています。 
- **重要**: トールキンは一貫してこれらの分岐点を**無視しません**。 中断は詩的なリズムのために意図的に行われています

 **行 4**: *Na-chaered palan-díriel*
 - *Na-chaered*: *na-* (接頭語: 離れた場所; 場所的) + *chaered* (*na-* の後に *c*→*ch* 変異を伴う *caered*)
 - *caer-* ルート: 巨大、広大。 *caered* = 広大な距離
 - *Na-chaered* = 「遠く、遠くに」
 - *palan-díriel*: *palan-* (遠く広く) + *díriel* (見つめた — *tir-* 見る、女性完了分詞 *díriel* = 見つめた彼女)
 - **ハイフンの使用**: *na-* と *palan-* の両方で、省略ではなく接頭辞の添付を示すためにハイフンを使用します。 
- **変異**: *na-* の後の *c* → *ch*: これは混合/鼻変異です (*na* の歯の接頭辞 *n-* + 後続の *c* → *ch*)

 **行 5**: *o galadhremmin ennorath*
 - *o* = から
 - *galadhremmin* = 木格子、木で織られたもの: *galadh* (木) + *remmin* (網状、織物 — *rem* メッシュ + *-min* 受動分詞)
 - *ennorath* = 中部地方全体: *ennor* + *-ath* (クラス複数形)
 - **ジャンクション**: *galadhremmin ennorath* — *-in* 末尾 + *e-* 頭文字: hiatus *in.e* — 省略なしで書かれています。 休止期間は維持される
 - **頭韻/音**: 5 行目の *gal/gal* エコーは 1 行目の *Gilthoniel* に戻ります。 

**6行目**: *ファヌイロス、ル・リンナソン*
 - *ファヌイロス* = ヴァルダの別の名前/別名: *ファン-* (雲、白?) + *ウイロス* (永遠の雪? または *ウイレス*、*ウイ* エバー + *ロス* 雪)
 - *le* = あなた、あなた (二人称代名詞、正式)
 - *linnathon* = 私は歌います: *linna-* (歌う) + *-thon* (1sg 未来接尾語) — **完全に証明された未来時制形式**
 - **接続点**: *Fanuilos, le* — カンマ休止。 音韻上の接合点の問題ではありません。 *le linnathon* — *le* は母音 *e* で終わります。 *linnathon* は *l* で始まります: *e.l* — 母音 + 子音、省略は必要ありません

**7行目**: *ネフ・アー、シ・ネフ・アーロン!*
 - *nef* = のこちら側
 - *aear* = 海
 - *si* = 今、ここ
 - *aearon* = 大海、大洋 (*aear* + *-on* 拡張)
 - **接続点**: *nef aear* — *nef* は子音 *f* で終わります。 *aear* は母音 *a* で始まります: *f.a* — 省略は必要ありません (子音と母音の結合)。 *si nef* — *si* は *i* で終わります。 *nef* は *n* で始まります: *i.n* — 省略なし。 *nef aearon* — 上記の *nef aear* と同じ。 
- **繰り返し**: *nef aear, si nef aearon* — 2 番目の *aearon* (大海) を増補したほぼ繰り返されるフレーズは、クライマックスの構造を作成します。「海のこちら側、大海のこちら側!」

 ### 概要: *A Elbereth* のエリシオン

 トールキンはこの詩の母音結合部分を**省略しません**。 すべての休止点 (母音で終わる単語とそれに続く母音で始まる単語) が完全に書き出されます。 これは次のことを反映している可能性があります。 
1. **正式な賛美歌レジスタ** — これは信仰の歌です。 省略するとカジュアルすぎるように感じるかもしれません
 2. **意図的なリズム** — 中断が詩の長さと重みに貢献します
 3. **トールキンの作曲実践** — 彼は拍子の省略を必要としないようにこの詩を設計した可能性があります

 ## 5. 属格構文における省略

 ### *en* + 母音

 属格助詞 *en* (of-the) + 次の母音頭文字の単語は、潜在的な省略環境を作成します。 

標準形式: *en* + *Edhil* (エルフ、属格: 「エルフの」) → *en Edhil* または *en・Edhil* または *en'Edhil*?

 トールキンの実践: 証明された形式は**省略されません**。 *en* は独立して立っています。 

ただし、**早口でカジュアルなスピーチ**や**詩**では、*en* が母音の前で *'n* になる場合があります。 
- *Gwaith-i-Mírdain*: ここで属格は *-i-* (*en* ではありません) です。助詞ではなく、使用される冠詞形式です。 属格形のバリエーションが存在することを示します

 ### フュージョン vs. エリシオン

 省略のように見えるいくつかの形式は、実際には**文法化された融合**です。2 つの単語は時間の経過とともに 1 つの形式に融合し、もはや生きた省略ではありません。 

- *エリン* = *エル* + *イン*? いいえ — *erin* = *ar-* (on) + *i-* (the) が *erin* (on the) に融合 — 証明済み
 - *uin* = *o* (from) + *i* (the) → *uin* (from the) — *o* と *i* を融合したもの
 - *ammin* = *am* (up/upon) + *i* + *n* → 融合位置限定形式

 これらは、混合突然変異トリガー (レッスン 30) を生成した **歴史的な融合** です。 それらは「生きた」省略ではありません。話者は意識的に母音を省略しません。 現在の形式は単なる語彙形式です。

 ## 6. 複合語の省略

 シンダール語 **複合語** (2 つの語幹が 1 つの語彙項目に融合する) では、複合継ぎ目の母音が次のようになります。 
1. **単純に休止状態**: *galadhremmin* — *galadh* (木) + *remmin* (ネット) — *galadh* の *dh* + *remmin* の *r* は両方とも残ります。 継ぎ目は子音と子音であるため、母音の省略はありません
 2. **母音を 1 つ失う**: 両方の要素が母音で終わり、母音で始まる場合、一方が縮小または削除される可能性があります。 

複合語での母音接触の例:
 - *Nindalf* (*nîn* ウェット + *dalf* 平面) — *n* + *d* シーム; 母音の衝突がない
 - *Elanor* (*el* star + *anor* sun) — *el* + *an* → *elanor* — *anor* の母音 *a* は *el* の *l* の直後に続きます。 彼らは休止状態にあります: *el.a* 省略なし

 ## 7. エルフの詩におけるエリシオンとメーター

 ### *リンナド*: エルフの詩形式

 *リンナド* (文字通り「歌う」) は、エルフの詩を表すシンダール語の用語です。 トールキンはエルフの詩のいくつかの特徴について次のように述べています。 
1. **頭韻** (行をまたいだ子音の繰り返し)
 2. **内部韻または共鳴** (行内の母音パターン)
 3. **音節数ベースの拍子** (ただし、古典的なラテン拍子などより厳密ではありません)
 4. 繰り返しパターンを含む **定常構造**

 音節カウントの目的で、**省略は韻律ツールとして利用できます**: 行に 1 音節が多すぎる場合、詩人は接続点で母音を省略してカウントを 1 つ減らすことができます。 

### *Namárië* の省略 (Quenya 参照)

 トールキンのクエンヤ詩 *Namárië* (ガラドリエルの嘆き) には、エルフの詩における省略の明確な例があります。 

>*アイ！ ラウリエ・ランタール・ラッシ・スリーネン*

ここでは、*laurië* は *-ie* で終わり、*lantar* は *l* で始まります。つまり、子音で始まり、母音が衝突しません。 しかし、後の行では、-e/-a の接点が詩のリズムに合わせて慎重にナビゲートされます。 

*Namárië* はシンダール語ではなくクエンヤ語ですが、これはトールキンの一般的なアプローチを示しています。言葉の選択とサウンド デザインを通じて **詩の激しい中断を避け**、最終手段として省略するというものです。

 ## 8. 文法化された省略: 冠詞と前置詞の融合

 セクション 5 で述べたように、シンダール語の一部の「省略」は固定された文法形式になっています。 これらはカタログ化する価値があります。 

| フォーム | 分析 | 意味 | 突然変異が誘発されました |
 |------|----------|----------|----------|
 | *エリン* | *ar-* + *i-n* | | に応じて 混合突然変異 |
 | *ういん* | *o* + *i* + *n*? | |から 混合突然変異 |
 | *アンミン* | *am-* + *i-* | | まで 混合突然変異 |
 | *アン・イ* | *アン* + *イ* | |へ/のために 鼻の突然変異 |
 | *en* | (属格) | — | 次の単語のソフト突然変異 |
 | *ディ* | 下、下 (+ 記事) | — | — |

 これらの形式は、講演者が作成するその場限りの省略ではありません。 これらは、歴史的に 2 つの単語の融合から偶然生じた **固定された語彙形式** です。

 ## 9. 盛り上がったドットの詳細

 盛り上がった点 *·* (または中点) は、トールキンのシンダール語原稿の一部で、次のような文脈で表示されます。 

> *イ・ムバイル・アンヌイ* (「西の地」)

 ここで:
 - *i* = 記事「その」
 - *・* = 終了点マーカー (冠詞と名詞は構文的に結合されています)
 - *Mbair* = 土地 (複数冠詞の後に *B-* の鼻音変異がある: *bair* → *mbair*; *M* は冠詞がすでに吸収されていることを示します)

 浮き上がったドットは、*i* と *Mbair* が 2 つのトークンとして書かれていても、構文的には 1 つの単位 (冠詞 + 名詞句) であることを示しています。 これは**韻律的および構文的**のマーカーであり、音韻上の省略マーカーではありません。 

現代のシンダール語学者と新シンダール語作家は、特に後続の名詞が冠詞によって突然変異を起こした子音で始まる場合、省略せずに冠詞の結合を示すために一貫して *·* を使用します。

 ## 10. 3 つの句読点ツール: 概要

 | マーク | 名前 | 機能 | 例 |
 |------|------|----------|----------|
 | *'* | アポストロフィ | (1) ソフト突然変異の下で *g* が削除されました。 (2) 詩的な母音の省略 | *i 'aladh* (木、g が落ちた); *o'Imladris* ᴺS. (裂け谷の詩) |
 | *-* | ハイフン | プレフィックス添付。 複合接合; 近い化合物 (完全融合ではない) | *パラン・ディリエル*; *な、困った*; *バーアンダンウェズ* |
 | *·* | 浮き上がったドット | 交差点を閉じる。 融合を伴わない冠詞と名詞の結合 | *i・Mbair* |

 **経験則**:
 - 非複合語の母音の前にある *'* を参照 → おそらく *g* が削除されました (ソフト突然変異)
 - 要素間の *-* を参照 → 接頭辞または複合語を閉じる
 - *・* → 密接な構文上の冠詞/助詞 + 名詞を参照

 ## 11. 練習: これらのテキスト内の省略と結合点を特定する

 次の 5 つのパッセージを分析して、省略 (アポストロフィ)、結合 (浮き上がりのドット)、および複合/接頭辞ハイフンを調べます。 各マークが何を表しているかに注目してください。 

**パッセージ 1**: *エドライス アンメンをナウル!*
 (「私たちの救いのために火をつけてください!」 — ガンダルフ、カラドラス)
 - 分析: *Naur* = 火 (スタンドアロン)。 *an* = for/to (前置詞)。 *edraith* = 救助、保存 (*e-* + *draith* から *dar-* から保存)。 *ammen* = us (*am-* + *men* → 私たちの場合、1pl オブジェクト)。 省略記号はありません。 アポストロフィはありません。 すべての子音の接合部または休止部が維持されます。 

**パッセージ 2**: *エニン・デュリン・アラン・モリア: ペド・メロン・ア・ミンノ!*
 (「モリアの領主ドゥリンの門: 友達と言って入ってください!」)
 - *Ennnyn* = ゲート (*annon* の pl.、i-affection: *a*→*e*)。 *ドゥリン* = 固有名詞。 *アラン* = 王/主。 *モリア* = ブラック キャズム (*mor* ダーク + *ia* キャズム)。 *ペド* = 話す! (必須)。 *メロン* = 友達。 *a* = そして。 *minno* = 入ってください! (必須 *min-* + *-no*)。 この証明されたテキストには省略記号はありません。

**パッセージ 3**: *Cuio i Pheriannath anann!*
 (「ハーフリングが長生きしますように!」)
 - *Cuio* = [彼ら] が生きられますように: *cuia-* + 仮定法 *-o*。 *i* = (記事)。 *Pheriannath* = P→Ph (*i* 後の *P* のソフト突然変異)。 *anan* = 長い、長い間 (*an-* + *ann* ロング)。 省略はありません。 *Ph-* は、省略ではなくソフト突然変異を示します。 

**パッセージ 4**: *ティロニン、ファヌイロス!*
 （「おお、こちらを向いてください、ファヌイロス！」）
 - *A* = 助詞（呼びかけ）。 *tiro* = 見てください! 見て！ (必須 *tir-* + *-o*)。 *nin* = me (1sg オブジェクト代名詞: *ni* + *n* アタッチメント)。 *ファヌイロス* = ヴァルダの名前。 省略記号はありません。 

**パッセージ 5** (ᴺS. 作曲): *I 'aladh maer nâ faer sui i·'waew.*
 （「その木は風のように速い。」）
 - *I* = 記事。 *'aladh* = ツリー (アポストロフィ: ソフト突然変異の下でドロップされた *galadh* の *g*)。 *maer* = 良い/良い。 *nâ* = は (3sg コピュラ) です。 *ファール* = 速い。 *すい* = として、のように。 *i・'waew* = 風: *i* (記事) *・* (クローズジャンクション) *'waew* (アポストロフィ: *gwaew* 風の *g* が *i* の後のソフト突然変異でドロップされました)。 2 つのアポストロフィ: 両方とも母音省略ではなく、*g* を省略したマークです。

 ## 覚えておくべき重要なポイント

1. **異なる機能を持つ 3 つの句読点**: *'* (子音の省略または詩的な省略)、*-* (接頭語/複合語)、*·* (結合点の終了)
 2. **トールキンは、証明されたシンダール語のテキストで母音の省略をほとんど使用しません** — 通常、特に形式的/詩的な記録では休止が維持されます
 3. **文法化された融合体** (*erin*、*uin*) は歴史的に省略/融合から生じましたが、現在は固定形式です
 4. **詩の省略** は、音節数の調整が必要な場合に韻律ツールとして利用できます。 
5. **ソフト突然変異のアポストロフィ** (*g* を省略) は、トールキンのテキストで最も一般的な *'* の使用法です。母音省略と混同しないでください。
