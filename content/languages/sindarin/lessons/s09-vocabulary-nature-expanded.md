## トールキンのビジョンにおける自然

 トールキンは植物学を愛し、情熱的な博物学者であり、イギリスの田舎で育ちました。 彼のエルフの性質に関する語彙は、シンダール語で最も豊富で最も徹底的に証明された領域の 1 つです。 その理由は構造的なものです。証明されているシンダール語のフレーズの多くは地名に由来しており、中つ国の地名は丘、川、樹木、星、天気などの自然の特徴に関するものが圧倒的に多いのです。 

*Amon Sûl* (風の丘)、*Hithaeglir* (霧の山々、文字通り「霧のベールの頂上」)、*Eryn Lasgalen* (緑の葉の森)、*Nen Hithoel* (霧の湖)、*Nîn-in-Eilph* (スワンフリート) — これらの名前はどれも、解き明かされるのを待っている自然語彙のレッスンです。 

この付録は環境分野ごとに構成されており、中つ国の地図と合わせて読めるように設計されています。 それぞれの単語を学びながら、それが使われている地名を見つけてください。

### 星に対するエルフの崇拝

トールキンのエルフは太陽や月以上に、星の光の生き物です。 エルフたちは初めて星空の下で目覚めました（太陽と月が存在する前）。 ヴァラールに最も愛されているヴァルダは、*エルベレス・ギルソニエル*、つまり「星の女王、星のキンドラー」 (*ギル* + *ソン* キンドル + *-iel*) です。 偉大なエルフの賛美歌 (*A Elbereth Gilthoniel / silivren Penna míriel / o menel aglar elenath...*) の冒頭全体は、星、銀色の輝き、宝石のような光、大空の栄光といった自然の語彙のカスケードです。

### 地図上で水の名前を読む

 シンダール語の水に関する語彙の豊富さは、中つ国の地図から最もよく理解できます。 これらの名前を見つけて解析してみてください。 
- *Nen Hithoel* = *nen* (水/湖) + *hîth* (霧) + *-oel* (形容詞接尾辞) = "霧の灰色の湖"
 - *Nîn-in-Eilph* = *nîn* (水っぽい/水) + *in* (pl. 記事) + *eilph* (白鳥、*alph* の pl.) = "Swanfleet" = 白鳥の水っぽい場所
 - *アンドゥイン* = *アンド* (長い) + *ドゥイン* (大きな川) = 「長い川」
 - *バランドゥイン* = *バラン* (金茶色) + *ドゥイン* = 金茶色の川 = ブランディワイン

 ### ロスローリエンの花

 『黄金の森』で言及されている 2 つの花は、シンダール語の名前を証明しています。 
- *エラノール*: 黄金の花、「サンスター」。 サムはロスローリエンで見た娘にこの名前を付けました。 
- *ニフレディル*: 白い花、「蒼白の散乱」。 ドリアスでルーシエン・ティヌヴィエルが踊った場所で咲きました。 ロスローリエンにも生えていました。 

これら 2 つの花は、トールキンが最も慎重に命名した植物の細部であり、シンダール語の語源が注目を集めています。

 ### *Yrch!* — レゴラスの有名な警告

 *The Fellowship of the Ring* でオークが近づいてくるのを見たとき、レゴラスは一言叫びます: *Yrch!* これはシンダール語で *orch* (orc) の複数形であり、i 愛情を示します: *o→y*。 この言葉は完全に証明されており、恐怖と警告の中で叫ばれており、i-affection 複数形が真に生きた複数形であることを示しています。極限状態にあるシンダール語話者は自動的に自然な複数形に手を伸ばします。

 ### 語彙のレッスンとしての地名の解析

シンダール語の主要な地名はすべて語彙文です。 解析を練習します。 
- *Hithaeglir* = *hîth* (霧) + *aeleg* (とげのある/鋭い) + *-ir* (複数形?) = 「霧のとげのある峰」 = 霧深い山脈
 - *Imladris* = *imlad* (深い谷) + *ris* (裂け目) = 「裂け目の深い谷」 = 裂け谷
 - *ミスロンド* = *ミス* (グレー) + *ロンド* (ヘブン) = "グレイヘブン"
 - *Caradhras* = *caran* (赤) + *rass* (角の峰) = "レッドホーン"

 ## 練習: 自然の語彙演習

 語彙を中つ国の地図上の知っている場所に結びつけます。 

1. *Amon Sûl* は文字通りどういう意味ですか? この場所の一般的なスピーチ名は何ですか?
 2. *Nen Hithoel* には 3 つのコンポーネントがあります。それらは何で、何を意味しますか?
 3. *Eryn Lasgalen* が *Taur-e-Ndaedelos* という名前を置き換えました。 両方の名前を解析し、何が変更されたのか、なぜ変更されたのかを説明します。 
4. *orch* の複数形は *yrch* です。 どのような突然変異や母音の変化がこれを生み出すのでしょうか? *in yrch*ではどのような突然変異が起こるでしょうか?
 5. *アルフィリン*と*ニフレディル*は両方とも白い花です。 それらの語源はどのように異なって表現されているのでしょうか？ 
6. *Andúril* (剣) と *Anduin* (川) は要素 *and-* を共有します。 それぞれの化合物にはどんな意味があるのでしょうか？ 
7. *ミスロンド*を完全に解析し、それがどのような場所を表しているのか説明します。 
8. *naur* という単語は、感嘆符 *Naur an edraith ammen!* と天気関連の語彙の両方に現れます。 中心的な意味は何ですか?また、文脈によって用途がどのように区別されるのでしょうか?

 **答え:**
 1. *アモン スル* = 風の丘 (*アモン*) (*スル*) = ウェザートップ
 2. *Nen* (水/湖) + *hîth* (霧) + *-oel* (「灰色の霧」を意味する形容詞接尾語) = 霧のかかった灰色の水の湖。 霧の隙間にある静かな湖
 3. *Eryn Lasgalen* = 森 (*eryn*) + *las* (葉) + *calen* (緑、形容詞) = 「緑の葉の森」; *Taur-e-Ndaedelos* = great-forest (*taur*) + *en* (of) + *ndaedelos* (*daedel* 恐怖 + *-os* 集合体?) = 「大いなる恐怖/恐怖の森」; サウロンの堕落後、暗い名前は楽しい名前に置き換えられました
 4. I-愛情（内部母音変化）： *o→y*; 単語が母音で始まるため、*in* の後の *yrch* には子音の突然変異はありません (突然変異は最初の子音にのみ適用されます)
 5. *アルフィリン* = *al-* (なし) + *フィリン* (死すべきもの) = 「不滅のもの」 — それが何(死すべきもの)ではないかによって定義される。 *niphredil* = *niph-* (蒼白) = 「蒼白/蒼白の散乱」 — 色と外観によって定義される
 6. どちらも *and* = ロングを使用します。 *Andúril* = ロングファイア (長い炎)。 *アンドゥイン* = ロングリバー (長い大きな川)
 7. *Mîth* (灰色) + *lond* (天国) = 灰色の天国; 灰色の海が広がる守られた港、不死の国へ向かう船が出航する中つ国の最西端の港
 8. *ナウル* = 火。 *Naur an edraith ammen!* = 文字通りの火（防御として点火する）。 天気/医療の文脈では = 「発熱」または「灼熱感」(比喩的な熱)
