## プレフィックスが重要な理由

 シンダール語は、**複合語と接頭辞**によって語彙の大部分を構築します。 派生のために接尾辞に大きく依存する言語とは異なり、シンダール語は形態論をフロントローディングします。つまり、特殊な意味または拡張された意味を持つ新しい単語を作成するために、基本単語の先頭に意味が頻繁に追加されます。 

これは学習者にとって実際的な影響をもたらします。 
1. 接頭辞を知ることで、なじみのない名前や見たことのない単語を解読できるようになります
 2. トールキンに登場する多くの有名な名前 — *Anduin*、*Mirkwood* (シンダール語 *Taur-nu-Fuin*)、*Fornost*、*Dúnedain* – は、接頭辞が分かれば透過的に分析可能です
 3. 新シンダール語の造語は同じ接頭辞パターンに従っているため、新しい語彙を生産的に構築できます

 重要な原則: **接頭辞は基本単語の意味を変更します**。 基本単語の最初の子音は、音韻環境に応じて変化する場合と変化しない場合があります。 多くのコンパウンドは、継ぎ目部分の基本形状を変更せずに保存します。 いくつかはソフト突然変異を示します。

 ## 方向プレフィックス

 これらの接頭語は、空間内の方向、位置、または方向を示します。 

| プレフィックス | 意味 | 主な例 | 分析 |

 ### 詳細な例: コンパスの接頭辞

 **北 (*for-*):**
 - *Fornost* = *for-* + *nost* (要塞/家) → 北の要塞; アルノールの首都
 - *Forod* = 独立した名詞としての北 (おそらく *for-* + *od* 「離れて」)
 - *フォロチェル* = 北 + *オチェル* (寒い?) → 北の氷の湾

 **西 (*dún-*):**
 - *ドゥネダイン* = *ドゥン-* + *エダイン* (男性) → 西洋の男性; ヌーメノール人の子孫
 - *Annûn* = *an-* + *nûn* (日没の方向) → 西; *エニン・ドゥリン・アラン・モリア：ペド・メロン・ア・ミノ。 私はナルヴィ・ハイン・エチャントです。 Celebrimbor o Eregion taithant i thiw hin.* — モリアの西門は、他の参考文献では *Ennnyn Annûn* です

 **南 (*ハラド-*):**
 - *ハラド* = 南 (単純な語幹)
 - *ハラドワイス* = 南 + *グワイス* (人々、民俗) → 南部の人々。 ハラドリム
 - *ウンバール* = アドゥナイ語では南に関連している可能性がありますが、シンダール語では別の名前が付けられています

 **東 (*rhûn-*):**
 - *Rhûn* = 東 (スタンドアロン)
 - *Amrûn* = *am-* + *rûn* = 東方向、東方向

 ## 負のプレフィックス

 これらの接頭辞は、ベース単語を否定するか、プライベートに変更します。 

| プレフィックス | 意味 | 突然変異が誘発されました | 主な例 |
 |----------|-----------|--------|-------------|
 | *ú-* | なし、ない、ない | **ソフト突然変異** | *ú-chebin* (私は飼っていません)、*Úmarth* (不運) |
 | *アル-* / *アル-* | ない、なし（代替） | ソフト突然変異 | シンダール語の使用は限定的。 *アルフィリン* (不死:不死) |
 | *u-* / *û-* | 悪、悪い（病気の増強剤）| — | *Ungoliant* (大蜘蛛) |

 ### プライマリネガティブプレフィックス: *ú-*

 *ú-* は、生産的なシンダール語の私用接頭辞です。 これは、名詞、形容詞、動詞に「〜がない、欠けている、〜がない」という意味で付けられます。

| ベース | 接頭辞付き形式 | 意味 |
 |-----|--------------|----------|
 | *chebin* (私は *hebin* のソフト突然変異を保持します) | *ウーチェビン* | 保管しません |
 | *アマールス* (運命、運命) | *ウマルス* | 不運、悪い運命 (ú- + アマルス) |
 | *ガラド* (木) | *ú-'aladh* | ツリーレス (ú- + ガラダ → G ドロップ) |
 | *エステル* (希望) | *ú-エステル* | 絶望、希望のない |
 | *まあ* (良い) | *ú-maer* → *ú-vaer* | 良くない、病気 (m→v) |

 証言: *ú-chebin estel anim* = 「私は自分自身に何の希望も持ち続けていない」 — *『中つ国の人々』* におけるトールキンのメモより。 

### *al-* / *ail-*: 形態学的代替案

 *al-* はいくつかの形式で表示されます。 
- *alfirin* (不死) = *al-* + *firin* (死すべき) → 「死なない」 — トールキンが使用した花の名前
 - この接頭辞は Quenya *il-* (負の接頭辞) と同族です。 
- 証明されたシンダール語では *ú-* よりも生産性が低い

 ## 強化および拡張的な接頭辞

 これらの接頭辞は、塩基の意味を増幅または拡張します。 

| プレフィックス | 意味 | 主な例 |
 |----------|----------|---------------|
 | *アン* | 長い、素晴らしい。 最も（最上級） | *Anduin* (長い川)、*Annûn* (西 - 遠い方向)、*andave* (大きく、長い) |
 | *ar-* | 高貴な、高貴な、高い | *アラゴルン* (高貴な王?)、*アルウェン* (高貴な乙女)、*アルノール* (王の国) |
 | *tar-* | 高い、高尚な、高貴な | *Tarcil* (高位の男、ヌーメノリアン)、*Tartir* (高位の監視者) |
 | *もー* | 暗い、黒 | *モルドール* (黒い土地)、*モリア* (黒い穴/裂け目)、*モルグル* (黒い魔術) |
 | *ギャル* | 光、輝き、輝き | *Galadriel* (gal + riel = 輝く花輪の乙女)、*Galadh* (木 — 上向きに成長する/輝くもの) |
 | *グリン* / *グロー-* | ゴールド、栄光 | 写真 *Glorfindel* (金色の髪 — *glor-* + *findel*)、*Glorhíril* (理論的) |
 | *マル* | ゴールド（イエローゴールド） | *Malen* (黄色)、*Mallorn* (金の木 — mal + lorn)、*Malvorn* |
 | *セレブ* | シルバー | *セレブルン* (銀の木)、*セレブラント* (シルバーコース - シルバーロード川)、*セレブリンボル* (銀の拳) |

 ### 詳細な分析: *an-* (長い、素晴らしい)

 *an-* は非常に生産的です。 それは次の場所に表示されます。 
- *アンドゥイン* = *アン-* + *ドゥイン* (川) → ロングリバー / グレートリバー
 - *Annûn* = *an-* + *nûn* (下、西方向) → 西 (太陽が長く下る方向)
 - *アンファウグリス* = *アン-* + *ファウグリス* (あえぐ粉塵) → 窒息するような広大な灰の平原 (荒廃後のアード・ガレン)
 - *アンファラス* = *an-* + *ファラス* (海岸) → ロングショア (沿岸地域)
 - *andave* = *an-* + *dave* (時間、発生) → 大きく、何度も
 - *Andrath* = *an-* + *rath* (道路、コース) → 長い道のり

 **最上級の接頭辞** (新シンダール語の慣例): *an-* + *beleg* → *ambeleg* (最大。*an-* の前の鼻音 *n* からの鼻音の突然変異 b→m に注意)。 

### 詳細分析: *celeb-* (シルバー)

 *celeb-* は、トールキンの命名で最も目立つ接頭辞の 1 つであり、次の作品に登場します。 
- *セレブルン* = *セレブ-* + *オーン* (木) → シルバーツリー; ホワイトツリーの祖先。 ガラドリエルの夫の名前でもある
 - *セレブラント* = *セレブ-* + *暴言* (コース、川底) → シルバーロード; ウェストロンの翻訳は「シルバーロード」です
 - *セレブリンボール* = *セレブ-* + *リンボール* (拳の、*リム*「拳」から) → 銀の拳; オルドリン・スミス
 - *セレブディル* = *セレブ-* + *ディル* (ポイント、スパイク) → シルバータイン; モリア三峰の一つ

 ### 詳細分析: *mor-* (ダーク、ブラック)

 *mor-* は、地名に広く現れるルート形式の接頭辞です。 
- *モルドール* = *モル-* + *ドール* (土地) → 黒い土地; サウロンの領域
 - *モリア* = *mor-* + *ia* (ボイド、ピット/キャズム) → ブラックキャズム; ドワロウデルフ
 - *Morgoth* = *mor-* + *goth* (恐ろしい敵) → Dark Enemy (クウェンヤ形式。シンダール語はパラレル)
 - *Morgul* = *mor-* + *gûl* (魔術、幽霊魔術) → 黒魔術; *ミナス・モルグル*のように
 - *モラノン* = *mor-* + *アンノン* (大門) → モルドールの黒門

 ## *go-* / *gwa-* 接頭辞: 一体感

 この接頭語は、最も有名なシンダール語のフレーズの 1 つで役割を果たしているため、特別な注目に値します。

| バリアント | 使い方 | 例 |
 |----------|-------|----------|
 | *ゴー* | 子音の前 | *govad-* (会うには、go + パッド) |
 | *グワ* | 母音の前 | *Gwaur* (汚染された、gwa + ? ルート) |
 | *グワ* | 化合物中 | *グワイス* (人、会社 — グワ + ?) |

 ***govad-* と *Mae govannen* の語源:**
 - *govad-* = *go-* + *pâd-* (歩く、歩く) → 「一緒に歩く」= 会う
 - 過去分詞は *govannen* (会った、一緒に会った)
 - *Mae govannen!* = 「よく会いました!」 — *mae* (まあ) + *govannen* (*govad-* の過去分詞)
 - *Mae* は *maer* (良い) と同じ語源から来ています。 
- この挨拶は、*『ロード・オブ・ザ・リング*』全体で証明されていますが、文字通り「よく一緒に歩きました！」です。 

その他の *go-* / *gwa-* フォーメーション:
 - *Gwaith-i-Mírdain* = *gwaith* (会社、民族) + *i* (the) + *mírdain* (宝石細工師) → 宝石細工師の会社
 - *goheno nin* = 「許してください」 — *go-* + *heno* (赦す/解放する) + *nin* (私)
 - *gohenam* — 「私たちは許します」（逆:「私たちは許しの中で一緒に歩みます」）

 ## 新しい単語の構築: ネオシンダール語の接頭辞

 確立された接頭辞パターンを使用した正当な新シンダール語の単語構成の 5 つの例:

1. **「北人」** = *for-* + *dîr* (男性) → *Fordîr* (北方の男); 注: *Dúnedain* は「西洋人」を表す確立された用語なので、「北部人」も同じ *direction + edain/dîr* パターンに従います。 

2. **「遠くを見る」** = *palan-* + *tîr* (見る) → *Palantír* — これは実際に証明されています。 パランティリ (見る石) = 「遠くを見るもの」

 3. **「シルバーハンド」** = *セレブ* + *カム* (手) → *セレブカム* — *セレブリンボール* (銀の拳) との類推により。 トールキン自身はイドリルに *セレブリンダル* (銀の足) を使用しました

 4. **「Black-gate」** = *mor-* + *annon* (門) → *Morannon* — これはモルドールの黒門の名前であることが証明されています

 5. **「Long-road」** = *an-* + *rath* (道路、コース) → *Andrath* — 地名として証明される (カルドラン語の長い汚名)

 これらの例は、接頭語システムが恣意的ではないことを示しています。それは一貫したルールに従っており、トールキン自身がこれらのパターンを繰り返し使用し、学習者や新シンダール語の作曲家にとって信頼できるものになっています。
