## レベル: 中級 (*Peleth* — 開発)

 **所要時間の目安**: 100 ～ 300 時間 (初心者基礎後)
 **重要なマイルストーン**: 正しい変異と文法を含む短いシンダール語の段落を書きます。 時折辞書を借りながら、ファンの新シンダール語のテキストを読む

 ---

 ## 前提条件

 中間作業を開始する前に:
 - すべてのシンダール音を正しく発音します
 - 語彙を約 200 語知っています
 - ソフトミューテーション（寛容）を理解する — 少なくとも名詞の後の形容詞について
 - *エルベレス・ギルソニエル*を理解して読むことができる
 - 基本的な名詞の複数形を知っている

 ---

 ## 目標

 中間段階の終わりまでに:

 - [ ] 5 つの突然変異タイプ (ソフト、鼻、混合、停止、液体) とそのトリガーをすべて知る
 - [ ] 完全な動詞システムを理解する: アオリスト、現在進行形、過去 (強 + 弱)、未来
 - [ ] 代名詞を正しく使用します (主語、目的語、所有格)。 
- [ ] シンダール語で簡単なオリジナルの文章を作成する
 - [ ] 正しい文法で短い段落 (3 ～ 5 文) を書きます
 - [ ] 時折辞書を調べながら新シンダール語のテキストを読む
 - [ ] Tengwar 標準モードを知っています — シンダール語の読み書きができます
 - [ ] 属格と与格の構文を理解する
 - [ ] すべてのテーマ カテゴリにわたって約 600 ～ 1,000 の語彙を知っています
 - [ ] 証明された S./N を区別します。 ᴺSさんからの言葉。 再建

 ---

 ## マスターするためのコア文法

 ### 5 つの突然変異タイプすべて

 | 突然変異 | 最も一般的なトリガー |
 |----------|----------|
 | **ソフト (レニション)** | 調整 名詞、直接目的語、冠詞 *i*、前置詞 *ab、am、dad、di、nu、trî* の後 |
 | **鼻** | 複数冠詞 *in*、前置詞 *an* (与格) |
 | **混合** | 明確な前置詞 (前置詞 + 冠詞の融合) |
 | **停止** | *d* または *t* プレフィックスの後 (限定使用) |
 | **液体** | *l* または *r* の後 (理論上、合成では無視できます) |

 [Sindarin Crash Course ミューテーション ツール](https://sindarincrashcourse.neocities.org) を使って練習します。任意の単語を入力すると、適用されたすべてのミューテーションが表示されます。 

### 動詞システム: すべての時制

 | 時制 | プライマリ (*tol-*) | A-ステム (*ティリア-*) |
 |------|------|------|
 | アオリスト/現在 | *tôl* (彼が来る) | *ティリア* (彼は見ています) |
 | 1番目のsg。 現在 | *とろん* (来ます) | *ティリアン* (私は見ています) |
 | 現在進行形 | *トーラ* (来ます) | — |
 | 過去の強さ | *túle* (彼は来ました) | — |
 | 過去の弱い | — | *ティリアント* (彼は見ていた) |
 | 将来 | *トルタ* (来るでしょう) | *ティリアサ* (見ます) |
 | 命令的 | *トロ!* (来てください!) | *ティリオ!* (見てください!) |

 ### 与格: *an* + 鼻音変異

 間接目的語は前置詞 *an* (「to/for」) + 鼻音の突然変異を使用します。 
- *アンノン・イルフ・アン・ベン* — 「私は男性にゴブレットを贈ります」
 - *ylf* = 直接オブジェクト (ソフトミュート、暗黙)
 - *an benn* = 与格: *an* の後の *benn* (b は鼻音の下で b のままです。? — b→m 鼻の下で; したがって、*an menn*... 分析によって異なります)

 詳細な実際の例については、RealElvish Academy 文法コースを使用してください。 

### 属格: *en* + 混合突然変異

 所有では助詞 *en* (の/に属する) を使用します。 
- *エニン・ドゥリン・アラン・モリア* — 「ドゥリン・ロード・オブ・モリアの扉」
 - *アラン* (王) + *モリア* (属格 = 主 *of* モリア)

 ## 書き込み: Tengwar 標準モード

 中級レベルでは、**テンワール標準モード**でシンダール語の読み書きを学びます。 

重要なポイント:
 1. シンダール語では母音 (*tehtar*) が **次の子音の上**になります (クエンヤの反対!)
 2. 最後の母音は短い無音キャリアの上にあります (*telco*)
 3. 長母音には識別マークがあります（下のバーまたは長い母音）
 4. シンダール語で最も一般的な 20 文字の *tengwar* と 6 文字の *tehtar* を学習します

 リソース: [Tengwar ページ](../../writing/tengwar/) および [Tecendil](https://tecendil.com)

 ## 語彙目標: 600 ～ 1,000 語

 中級レベルでは、基本的な約 200 語から約 600 ～ 1,000 語まで拡張します。 

**優先的な追加事項:**
 - 過去形を持つすべての[証明された動詞](../../語彙/証明/)
 - [時間の語彙](../../vocabulary/thematic/time/) 月と季節を含む
 - [拡張された場所の語彙](../../vocabulary/thematic/places/) — 地理的特徴
 - 複合語要素 (接頭辞と接尾辞) — 語彙を増やす
 - 50 個以上の形容詞とその長文および複数形

 **単語構築戦略**: 最も生産的な約 30 個の単語要素を学習すると、何百もの複合語を認識または構築できるようになります。 
- *mor-* (暗い) + 任意の名詞 → 「暗い ___」
 - *gal-* (光/輝き) + 任意の名詞 → 「輝く ___」
 - *dol-* (頭/丘) + 任意の名詞 → 「___ 丘/頂上」

 ## 中級の作文練習

 1. **LotR の文章を翻訳** — 本から英語の文章を取り出してシンダール語に翻訳します
 2. **キャラクターの説明を書く** — アラゴルン、レゴラスなどをシンダール語で説明します
 3. **エルフ名の作成** — 複合要素を使用してオリジナルのキャラクターの名前をデザインする
 4. **Tengwar で書く** — 標準モードで書いたものを転記します。 
5. **コミュニティに投稿** — Vinyë Lambengolmor Discord および r/Tolkienlinguistics からフィードバックを得る

 ## よくある中間的な間違い

 1. **b の紛らわしいソフト変異と鼻変異 — ソフト変異: b→v; 鼻の突然変異: b→m
 2. **形容詞の複数形の同意を忘れる** — 名詞が複数の場合、形容詞も複数形にしなければなりません *そして* 省略形でなければなりません
 3. **シンダール語テングワールのクウェンヤ テフタル ルールの使用** — シンダール語では、母音記号を *次の* 子音の上に置きます。 *前*の上のクエンヤ
 4. **一貫性のない突然変異の適用** — 突然変異は文法によって必須であり、オプションではありません。 1 つ欠けている場合は文法エラーです
 5. **ᴺSの治療。 単語を標準**として — 常に新シンダール語の単語にラベルを付け、再構成であることを明確にします
