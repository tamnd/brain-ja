## 必須のご挨拶

 | シンダール語 | 期間 | 英語 | メモ |
 |----------|----------|----------|----------|
 | *前ゴバンネン!* | S. | よく会ったね！ | 標準的なエルフの挨拶。 点灯した。 「出会えてよかった」 *前* = まあ; *govannen* = 私たちは会いました (過去分詞) |
 | *ハノン ル* | S. | ありがとう（1人に） | *ハノン* = 感謝します。 *le* = あなた |
 | *ル・ハノン* | S. | ありがとう | 別の語順 |
 | *ナバール* | S. | さようなら | *na-* (to) + *vaer* (*maer* の良い/ソフトな変形) |
 | *クイオ・ヴァエ* | ᴺS. | よく生きる | *cuio* (ライブ、命令型) + *vae* (まあ、寛容) |
 | *ノヴァエル* | ᴺS. | お元気で | *na* (である) + *vaer* (良い) |

 ## 最も有名なシンダール語のテキスト: *エルベレス・ギルソニエル*

 ヴァルダ (星の女王エルベレス) へのこの賛歌は、*ロード・オブ・ザ・リング* に何度も登場します。 これは証明されている中で最も完全なシンダール語の詩です。 

### 全文```
A Elbereth Gilthoniel,
silivren penna míriel
o menel aglar elenath!
Na-chaered palan-díriel
o galadhremmin ennorath,
Fanuilos, le linnathon
nef aear, sí nef aearon!
```### 単語ごとの分析

 | 単語 | 分析 | 翻訳 |
 |------|----------|---------------|
 | *A* | 感嘆助詞 | おお！ |
 | *エルベレス* | 複合: *エル* (スター) + *ベレス* (クイーン) | スタークイーン (ヴァルダの称号) |
 | *ギルソニエル* | *gil* (スター) + *thoniel* (*thôni-* "kindle" の女性能動分詞) | スターキンドラー |
 | *シリヴレン* | *celeb* (シルバー) + *-ren* (形容詞接尾辞); S. 突然変異 cell→sil | 輝くシルバー、キラキラ | 写真
 | *ペナ* | 3番目のsg。 *pen(n)a-*の現在（斜め、落下） | 斜めに落ちる | 写真 斜めに落ちる、落ちる
 | *ミリエル* | *mîr* (宝石) + *-iel* (女性接尾語) → "宝石娘" | 宝石のように輝く |
 | *o* | 前置詞「から」 | から |
 | *メネル* | 天国、大空 | 写真 天国 |
 | *アグラー* | 輝き、栄光 | 栄光 |
 | *エレナス* | *el* (スター) + *-ath* (集合複数形) | すべてのスター、スターホスト |
 | *なちゃーる* | *na* (to) + *chaered* (許された *haered*、遠隔、遠距離) | 遠隔地へ/遠隔地へ向かう。 「遠くを見つめた」 |
 | *パランディリエル* | *palan* (遠くまで) + *díriel* (*tîr-* 「見る」の女性能動分詞) | 遠くまで見つめて |
 | *o* | から | から |
 | *ガラドレミン* | *galadh* (木) + *remmin* (形容詞「もつれた、網状の」) | 木が絡まった (形容詞) |
 | *エンノラス* | *en-* (中央) + *norath* (土地) | 中つ国、中地 |
 | *ファヌイロス* | ヴァルダのタイトル: *ファン* (雲?) + *イロス* (いつも白い?) | 常白色 (アルダの縁の山) |
 | *ル* | 二人称代名詞 (あなた、あなた) | あなたへ |
 | *リンナソン* | *linna-* (歌う) + *-tha-* (未来) + *-n* (第一詩) | 私は歌います |
 | *ネフ* | 前置詞「この側」 | | のこちら側
 | *aear* | 海、海 | 写真 海、海洋 海 |
 | *し* | 副詞「今、ここ」 | ここに |
 | *ネフ* | | のこちら側 | のこちら側
 | *アーロン* | *aear* + *-on* (拡張) = グレート オーシャン | 大海 |

 ### 完全な翻訳

 *おお、エルベレスの星の焚き火よ、銀が斜めに落ち、宝石のように輝き、大空からすべての星の栄光が！ 遠くを見つめた中つ国の木々の絡まった土地から、ファヌイロスよ、私は海のこちら側で、ここ大海のこちら側で、あなたに歌います！ 

### 短縮版 (ロリアン、フェローシップ第 7 章より)```
A Elbereth Gilthoniel
o menel palan-diriel,
le nallon sí di'nguruthos!
A tiro nin, Fanuilos!
```| 単語 | 翻訳 |
 |------|---------------|
 | *ル・ナロン* | あなたに私は叫びます (訴えます) — *nalla-* + *-n* 1sg |
 | *し* | 今、ここで |
 | *ディングルトス* | 死の影の下 — *di* (下) + *nguruthos* (鼻音が変異した *guruthos*: 死の恐怖) |
 | *ティロニン* | 私を見てください — *tiro!* (*tîr-* の命令形) + *nin* (私、与格) |

 ## 一般的なフレーズ (新シンダール語)

 これらのフレーズは新シンダール語を話すコミュニティで広く使用されていますが、すべてがトールキンから直接証明されているわけではありません。 

| シンダール語 | 英語 | メモ |
 |-------|-------|------|
 | *ゲーリッヒ ヴェレス ニン* | あなたには私の愛があります | *gerich* (あなたが持っている) + *veleth* (*meleth* から与えられた愛) + *nîn* (私の) |
 | *ギ・メリン* | 愛しています | *gi* (あなた、直接目的語) + *melin* (愛しています) |
 | *Elen síla lúmenn' omentielvo* | 待ち合わせの時間に星が輝く | シンダール語ではなく、クエンヤ (ギルドールへのフロドの挨拶) |
 | *ボエ ル トーゴ* | | を持参する必要があります。 *boe* (必要です) + *le* (あなた/あなたへ) + *togo* (持ってくる、不定詞) |
 | *ガラド・ヴィン* | 私たちの光よ | |
 | *私はトゥリエル* | 来ました | |

 ## 名前を与えるフレーズ

 シンダール語の名前は複合語句であることがよくあります。 有名な例:

 | 名前 | 内訳 | 意味 |
 |------|-----------|-----------|
 | *アラゴルン* | *ara-* (ロイヤル) + *gorn* (石) | ロイヤルストーン |
 | *レゴラス* | *レゴ* (放す) + *ラス* (葉っぱ) | 緑の葉 / 自由に飛ぶ葉 |
 | *ガラドリエル* | *calad* (光) + *riel* (花輪の乙女) | 輝く花輪を戴冠した乙女 |
 | *エルロンド* | *el* (星) + *rond* (金庫、アーチ) | スタードーム |
 | *アルウェン* | *ar* (高貴/王室) + *wen* (乙女) | 高貴な乙女 |
 | *ミスランディル* | *mithren* (灰色) + *randir* (放浪者、巡礼者) | 灰色の巡礼者 |
 | *グロールフィンデル* | *glaur* (金色の光) + *findel* (髪) | 金色の髪 |
 | *セレブルン* | *セレブ* (シルバー) + *オーン* (ツリー) | シルバーツリー |
 | *セレブリアン* | *セレブ* (シルバー) + *リアン* (女王の贈り物) | シルバーギフト |
