 ## 有名な地名分析

 ### 裂け谷/イムラドリス
 - *Imlad* (深い谷) + *ris* (急流、裂け目) = 「深く裂かれた谷」
 - 英語「Rivendell」 = 古英語訳 (riven = 裂け目、dell = 谷)

 ### ミナス・ティリス
 - *ミナス* (眺めの良い塔) + *ティリス* (衛兵/監視) = 「衛兵の塔」
 - 第三紀以前のかつての*ミナス・アノール* (太陽の塔)

 ### ロスローリエン
 - *Loth* (花/花) + *Lórien* (夢の国/エルフの名前) = "花/夢のロリアン"
 - シンダール語のフルネーム: *Caras Galadhon* (City of Trees)

 ### カラス・ガラドン
 - *カラス* (環状都市) + *ガラドン* (樹木の、属格) = 「環状の環状都市」

 ### ミルクウッド / エリン・ラスガーレン
 - *Eryn* (森) + *las* (葉) + *galen* (緑、*calen* から抽出) = 「緑の葉の森」
 - 以前は *Greenwood the Great* (シンダール語: *Eryn Galen*)、その後は *Taur-nu-Fuin* (Mirkwood)

 ### バラドゥル
 - *Barad* (塔/要塞) + *dûr* (暗い、暗い) = 「ダークタワー」

 ### モルドール
 - *Mor* (ダーク、ブラック) + *dor* (ランド) = 「ブラックランド / ダークランド」

 ### ゴンドール
 - *Gond* (石、岩) + *or* / *dor* (土地) = 「石の国」

 ### ロハン
 - 実際にはロヒリック語/古英語に由来しています。 シンダール語に相当するのは *Rochan* (馬の国) です。 
- *Roch* (馬) + *-an* (土地の接尾語) = 「馬の国」

 ### ヘルムズ・ディープ / アグラロンド
 - *Aglar* (栄光、輝き) + *rond* (アーチ型の洞窟/ホール) = "きらめく洞窟"

 ### オルサンク
 - *Or* (ハイ) + *thanc* (分岐。一部の分析では「マインド」とも) = 「ハイ ソーン / 鉄のマインド」

 ### アイゼンガルド / アングレノスト
 - *Angren* (鉄の) + *ost* (要塞) = 「鉄の要塞」

 ### ミナス・モルグル
 - *Minas* (塔) + *Morgul* (*morn* dark + *gûl* レイスマジック) = "Tower of Sorcery/Wraith-Magic"
 - 元 *ミナス・イシル* (月の塔)

 ### ウェザートップ / アモン・スル
 - *Amon* (丘) + *Sûl* (風) = 「風の丘」

 ### 裂け谷/イムラドリス
 - *Imlad* (深い谷) + *ris* (急いで切り裂く) = "深いクローブンの谷"

 ### 霧の山々 / ヒテグリル
 - *Hith* (霧) + *aeglir* (*aeg* = 頂上 + *-lir* = 行) = 「霧の峰の列」

 ### ザ・シャイア / スーザ (シンダール語ではなくホビティッシュ)
 - シンダール語では、シャイアの風景を *Talath* (平地) または *Lad* (平原) と言うことがあります。
