HSK 3 文法は、自信のある中間コミュニケーションのための約 70 の核となるパターンをカバーしています。 このレベルでは、「握る」構造、受動態、結果/方向/程度/潜在的な補語、およびより広範囲の複雑な文構造が導入されます。 

## 1. 握 (bà) 構造

 前置詞はオブジェクトを動詞の前に移動し、オブジェクトの処分、変換、または配置を強調します。 

### 1.1 コアハンドルパターン

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | S + 握 + O + V + 結果 | |私たちは桌子の上に解放されました。 私は本を​​テーブルの上に置きました。 |
 | S + 握 + O + V + 完 | 他は完了しました。 彼は食べ物を食べ終えた。 |
 | S + 握 + O + V + 好 | | 作為は良好です。 宿題をきちんと終わらせてください。 |
 | S + 握 + O + V + 掉 | | 私は钱花掉了しました。 お金は全部使ってしまいました。 |
 | S + 握 + O + V + 成 | | 她掴我当成朋友。 彼女は私を友達として扱ってくれます。 |

 ### 1.2 把文のルール

 - 動詞の後には**補語または他の要素**が必要です(裸の動詞ではありません)
 - オブジェクトは **明確** (特定/既知) である必要があります
 - 知覚を表す動詞 (听、見る、想) または是、有、在と一緒に「把」を使用することはできません。 

### 1.3 一般的な「握る」動詞と補語

 | 動詞 + 補語 | 意味 | 例 |
 |---------------------|----------|----------|
 | 掴…拿出来 | テイクアウト | 本を取り出してください |
 | 掴…放进去 | 入れてください | 衣類を手に入れて放进去 |
 | 掴…写下来 | 書き留める | ハンドル名字写下に名前を書き留めてください。 
| 掴…告诉 | 伝える | 握消息告诉我ニュースを教えてください |
 | 掴…带走 | 奪う | 把东西带走 物を奪う |

 ## 2.被（bèi）の受動態

 「被」は受動的な構造を示します。つまり、主体がそのアクションを受け取るか、またはそれに耐えます。 

### 2.1 コアの被パターン

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | S + 被 + エージェント + V + 補体 | 私は老师承認を受けました。 私は先生に批判されました。 |
 | S + 被 + V + 補体 (エージェントなし) | | 钱包は承認されました。 財布が盗まれました。 |

 ### 2.2 被センテンスの規則

 - 多くの場合、**望ましくない** 結果を暗示します (逆受動態)
 - 動詞の後には通常、補語または「了」が必要です
 - エージェントが不明または明らかな場合は省略できます

 ### 2.3 中立受動構造 (被なし)

 | 構造 | 例 | 英語 |
 |----------|-----------|----------|
 | 让 + エージェント + V | 他は私等一時間完了しました。 彼は私を1時間待たせた。 |
 | 叫 + エージェント + V | 他に叫びます。 彼は私に行くように言いました。 |
 | 给 + エージェント + V | |他にも走った。 その本は彼に取られました。 |

 ## 3. 結果の補足

 結果の補語は動詞の後に直接続き、アクションの結果を説明します。 

### 3.1 一般的な結果の補足

 | 補足 | 意味 | 例 |
 |-----------|-----------|----------|
 | 良い | 適切に行われました | 適切に終了しました |
 | 完了 | 完了しました | 吃完了 食べ終わった |
 | へ | 到達しました | 买到了 なんとか購入できました |
 | 见 | 認識された | 听见了それを聞きました |
 | 懂 | 理解しました | 読むことで理解できる看懂了 |
 | 错 | 間違って行われた | 写错了は間違って書きました |
 | 住 | しっかり/止まった | 记住了暗記しました |
 | 开 | 開いた/分離された | 打开了 開いた (it) |
 | 掉 | | は削除されました / 廃止されました 扔掉了は捨てました |

 ### 3.2 潜在的な形式 (V + 得/不 + 補数)

 | ポジティブ | ネガティブ | 意味 |
 |----------|----------|----------|
 | 完了しました | 不成立 | 完了できる / 完了できない |
 | 听得懂 | 听不懂 | 理解できる / 理解できない (音声) |
 | 見る | 見ない | 見える/見えない |
 | 记得住 | 记不住 | 思い出せない / 思い出せない |
 | 走得 | 走不了 | 離れることができる/できない |

 ## 4. 方向の補数

 方向の補足は、アクションの結果として生じる動きの方向を表します。 

### 4.1 単純な方向の補完

 | 補足 | 意味 | 例 |
 |-----------|-----------|----------|
 | V+上 | 上向き / 上向き | 走って登ってください。 
| V + 下 | 下向き | 座って座る |
 | V+进 | 内側へ | 走进去ウォークイン |
 | V+出 | 外側へ | 拿出来テイクアウト |
 | V + 回 | 戻る | 跑回去走って戻る |
 | V + 过 | 過去、終わった | 走过去歩いて通り過ぎる |
 | V+起 | 上がる、上がる | 站起来 立ち上がる |

 ### 4.2 複合方向の補数

 単純な補語と来/去を組み合わせて、話者に対する方向を示します。

| 補足 | 意味 | 例 |
 |-----------|-----------|----------|
 | V + 上来 | ここに来て | 跑上来ここに駆け上がる |
 | V + 上去 | そこに行きます | そこに登って行ってください。 
| V+下来 | ここに来てください | 走下来てここを歩いてください。 
| V+进来 | 入ってください | 请进来てください |
 | V + 出去 | 出かける | 跑出去
 | V + 起来 | やり始める。 |のように聞こえる 唱起来 歌い始めます。 听起来は次のように発音します |

 ## 5. 得を使った度数の補数

 ### 5.1 補数を取得 — どれくらい効果 / どれくらい

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | V + 得 + 調整 | | 非常に良い結果が得られます。 彼女はとても速く走ります。 |
 | V + 得 + VP | 他说得我哭了。 彼が話したので私は泣きました。 |
 | V + O + V + 得 + 調整 | 他说中文说得很流利。 彼はとても流暢に中国語を話します。 |
 | 形容詞 + 得 | | 忙しくて時間がかかりません。 とても忙しいので、食べる時間がありません。 |

 ### 5.2 极了 / 死了 / 坏了 — 非常に

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | Adj + 极了 | 好极了 | 非常に良い |
 | Adj + 死了 | 蓄積死了 | 疲れきった (死ぬほど疲れた) |
 | Adj + 坏了 | 急坏了 | 非常に不安です |

 ## 6. 譲歩的パターンと因果的パターン

 ### 6.1 尽管…还是/仍然 — それでも…それでも

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 尽管 + 譲歩、还是/仍然 + 結果 | 非常に高価ですが、他も承認されています。 高価だったにもかかわらず、彼はそれでもそれを購入した。 |

 ### 6.2 既然…就 — 以来…それから

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 既然 + 前提、就 + 結論 | | けれども、来ました、それでは吃饭吧。 せっかく来たんだから一緒に食べましょう。 |

 ### 6.3 只要…就 — 限り…その後

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 只要 + 条件、就 + 結果 | 只要努力、就能成功。 一生懸命働く限り、成功することができます。 |

 ### 6.4 只有…才 — Only If … then

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 只有 + 条件、才 + 結果 | 努力するだけ、才能がある。 一生懸命働くことによってのみ改善できます。 |

 ## 7. 条件文

 ### 7.1 如果/要是…就/那么 — もし…ならば

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 如果 + 条件、就 + 結果 | 如果明天下雨，就不去了。 もし明日雨が降ったら、私は行きません。 |
 | 要は…就 | | 要是你不来，我就走。 あなたが来ないなら、私は立ち去ります。 |

 ### 7.2 除非…否则/不然 — ただし…そうでない場合

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 除非 + 条件、否则 + 結果 | | 除非你道歉，否我不原谅你。 あなたが謝らない限り、私はあなたを許しません。 |

 ## 8. 表現シーケンス

 ### 8.1 先…その後…再 — まず…その後…その後

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 先 V1、その後 V2、さらに V3 | | 最初に手を洗い、その後停止して、もう一度テレビを見ました。 まず手を洗い、それから食事をし、それからテレビを見る。 |

 ### 8.2 一…就 — できるだけ早く

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 一 + V1 + 就 + V2 | 他に家就寝。 彼は家に帰るとすぐに寝ます。 |

 ### 8.3 刚/刚才 — ただ(完了)

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 刚 + V | 他は走った。 彼はちょうど立ち去ったところだ。 |
 | 刚才 + V | 刚才下雨了。 ちょうど雨が降りました。 |

 ### 9.2 正在 / 在 — 進行中のアクション

 ## 10. 重要な構造

 重要な文には、最初の動詞の目的語と 2 番目の動詞の主語の両方である 1 つの名詞句があります。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | S1 + V1 + N + V2 | | 老师让我回答问問題。 先生は私にその質問に答えさせた。 |
 | 请/叫び/让 + 人 + V | | 请你坐下。 座ってください。 |
 | 有 + N + V | | 有人敲门。 誰かがドアをノックしています。 |

 ### 11.2 越来越 — もっともっと

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 越来越 + Adj/V | 天気を越え来て熱。 天気はますます暑くなってきました。 |

### 11.3 越…越 — もっと…もっと

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 越 + V/調整 + 越 + V/調整 | 他にもっと高いです。 話せば話すほど彼は幸せになっていきました。 |
