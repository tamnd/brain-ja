## 概要

 方向補語 (趋向补语、qüxiàng bƔyƔ) は、話者の位置に対する動作の方向を示します。 単純な方向の補数では、1 方向の単語が使用されます。 複合補語には「来」または「去」を追加して、話者に近づく、または話者から遠ざかる動きを指定します。 これらの補語は身体の動きを説明する上で中心的なものであり、比喩的にも使用されます。 

## 学習目標

 - 単純な方向の補語を使用します:「进、出、上、下、回、过、起」
 - 単純な補語を「来」または「去」と組み合わせて、複合方向の補語を形成します。 
- 複合方向補完フレーズ内でオブジェクトを正しく配置します
 - 「起来」や「下去」などの方向補語の比喩的な拡張を理解する

 ## 文法重視

 ### パターン 1: 動詞 + 単純な方向の補語

 **構造:** 動詞 + 进/出/上/下/回/过/起

 単純な方向補語は動詞に直接付加されます。 「来」または「去」を追加すると、話者に向かう動きや遠ざかる動きを指定でき、複合補語を形成します。 「来/去」がないと、方向は示されますが、話者との関係は不特定になります。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 来て、门は着ています。 清金来、メンカイゼネ。 | どうぞお入りください、ドアは開いています。 |
 | | 椅子の上ステーションから来ました。 ター・コン・イージ・シャン・ザン・キライ・レ。 | 彼女は椅子から立ち上がった。 |
 | | 大家都出去看熱了。 Dàjiā dōu pō chōqù kàn rènào le。 | 誰もがその興奮を見守るために外に飛び出しました。 |

 **よくある間違い:** オブジェクトを間違った位置に配置する。 进来の場合、目的語は動詞と来の間にあります: 走进教室来 (一部の方言では自然) ですが、標準形は走进教室または掴书拿进来です。 

### パターン 2: 動詞 + 方向補語 + 目的語の配置

 **構造:** 動詞 + 进/出/回/过 + 目的語 + 来/去

 動詞句に目的語（場所や物）がある場合、その目的語は単純補語と「来/去」の間に位置します。 このルールは重要であり、結果の補完構造とは異なります。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 藺椅子運び房の間来ます。 青柏益子板金方尖来。 | 椅子をお部屋まで運び入れてください。 |
 | 他は大门去りました。 Tāzàuchōdàménqùle。 | 彼は正門を通って出て行った。 |
 | 孩子跑回家去った。 Háizi pío huí jiā Qù le。 | その子は走って家に帰りました。 |

 **よくある間違い:** オブジェクトを「来/去」の後に配置します。 運び来房间は間違っています。 正しい順序は「運び进房间来」です。 

### パターン 3: 「起来」と「下去」の比喩的使用

 **構造:** 動詞/形容詞 + 起来 (状態の始まり) または 動詞 + 下去 (状態の継続)

 動詞または形容詞の後の起来は、動作または状態の始まりを示します。 「下去」は、進行中のアクションの継続を示します。 これらは非常に一般的であり、言語に動的な性質を与えます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 天気熱起来了。 天啓レキライレ。 | 天気も暑くなり始めました。 |
 | 他们起唱歌来了。 塔門長旗来来。 | 彼らは歌い始めました。 |
 | | 要坚持下去，解放できません。 Nǐ yào jiānchí xiàqù、bù néng fàngqì。 | 続けなければなりません、諦めないでください。 |

 **よくある間違い:** 起来 (開始/始まり) と下去 (継続) を混同します。 「学起来」は勉強を始めることを意味します。 学下去とは勉強を続けるという意味です。 これらは交換可能ではありません。

## 練習する

 **演習 1: 方向の補完を完了します**

 コンテキストに基づいて正しい方向の補語 (来または去) を追加します。 

1. 老师走进教室___了。(生徒がいる部屋に入る教師)
 2. 他跑出门___了。(彼は出て行って今外にいる)
 3. 外側の本を運びます__。 (発言者に向かって本を持っていきます)

 **演習 2: オブジェクトの配置**

 オブジェクトを正しい位置に配置します。 

1. 他は＿＿（教室）に来ました。 
2.请搬出＿＿（この塌子）去ります。 
3. 孩子跑回 ___（家）は去りました。 

**練習問題 3: 起来、それとも下去?**

 正しい補語を選択してください:

 1. 春天来了，花开___了。 
2. これまでずっと努力してきました、___ を守ってください。 
3. 他突然笑___了，大家都很奇怪。 

## 文化的なメモ

 方向補語は中国語の空間言語にとって非常に基本的なものであるため、これを削除すると文が不完全になったり、外国語のように聞こえたりします。 中国語話者は空間を関係性の観点から認識し、常に基準点 (通常は話者) に固定されています。 これは、英語の空間文法には存在しない「来/去」の区別に反映されています。 方向の補語を学ぶときは、対話や物語における話者の立場に注意してください。それによって「来」と「去」が適切かどうかが決まります。
