## 概要

 学術的および専門的な話題は、特に学生や若い専門家にとって、日常の中国語会話の中心です。 このレッスンでは、大学の語彙、キャリア用語、およびある行動が別の目的のために行われることを表す文法パターン「了…」を取り上げます。 专业 (専攻/分野) のコロケーションは、自己紹介や専門的な会話では特に重要です。 

## 学習目標

 - 大学生活に関する語彙を使用する: 専攻、成績、卒業、奨学金、インターンシップ
 - 目的のある行動を表現するには、「為了...」を使用します。 
- 「专业」と自然なコロケーションを形成する
 - 学業上およびキャリア上の業績と目標について説明する

 ## 文法重視

 ### パターン 1: ために…するために — 行うために

 **構造:** 為了 + 目的 + 主語 + 而 + 動作動詞

 「為了」は目的や目標を紹介します。 では、それをその目的を達成するためにとった行動に結び付けます。 「」はカジュアルな会話では省略可能ですが、フォーマルな中国語や書き言葉では定期的に現れます。 而がなければ、文は依然として正しい: 為了考上好大学，他每天学习十小時。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 学貨を獲得するために、毎日が行われます。 Wèile huòdé jiƎngxuéjīn、tāměitiān xuéxí dào Hěn Wàn。 | 奨学金を獲得するために、彼女は毎日遅くまで勉強しています。 |
 | | 動作テストを蓄積するには、これを無視するのが賢明な選択です。 Wèile jīlěi gōngzuò jīngyàn ér qù shíxí, shì hěn míngzhì de xuànzé. | 実務経験を積むためにインターンシップに参加するのは非常に賢明な選択です。 |
 | | 他は良い工作に到達するために真学中国語を認めています。 Tā weile zhōodào hƎo gōngzuò érènzhēn xuéxí Zhōngwén。 | 彼は良い仕事を見つけるために中国語を熱心に勉強しています。 |

 **よくある間違い:** 為了と因を同じ意味で使用します。 「為了」は、アクションの将来の目標を指します。 因は何かの過去の理由を説明します。 為了健康而锻炼 (健康のために運動する) vs. 因為生病而请假 (病気のために休暇を取る)。 

### パターン 2: 专业 コロケーション

 **構造:** 专业を名詞として使用するさまざまなコロケーション

 「专业」は、教育やキャリアに関する会話で最も一般的な名詞の 1 つです。 選択について話しているのか、勉強について話しているのか、あるいはその分野で働くことについて話しているのかに応じて、さまざまな動詞と連語されます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | どうですか？ ニュエ・デ・シー・シェンメ・ズァンイェ？ | あなたの専攻は何ですか? |
 | | の仕事はコンピューター科学です。 Tā de zhuānyè shì jìsuànjī kēxué。 | 彼女の専攻はコンピュータサイエンスです。 |
 | 他大学のビジネスの後は、事後のビジネスはありません。 Tā dàxué bìyè hòu méiyƒu cóngshì běn zhuānyè de gōngzuò。 | 大学を卒業した後、彼は自分の分野で働いていませんでした。 |

 **よくある間違い:** 我的专业是经济学または我学的是经济ではなく、我的专业是学经济と言ってしまいます。 专业は動詞句ではなく名詞 (主語名) を受け取ります。 

### パターン 3: 毕业 + 以降/後 — 卒業式

 **構造:** 毕业上 + 機関 (正式) / 毕业後 + 行動 (卒業後)

 「毕业から」は「卒業した」という意味の正式な表現です。 「毕业後」とは「卒業後」という意味で、その後の活動を紹介します。 どちらも履歴書、自己紹介、学術的な文脈でよく使われます。

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 北京大学から提供されており、法律です。 Tā bìyè yú Běijīng Dàxué、zhuānyè shì fƎló。 | 彼女は北京大学で法学を専攻し卒業しました。 |
 | | 成功した後、他の人は大城市の作戦を去った。 Bìyè hòu、tā dƎsuàn qù dà chéngshì zhƎo gōngzuò。 | 卒業後は大都市で職を探す予定だ。 |
 | | 非常に多くの学生がその後に拒否し、再度正式に要求しました。 Hěn duō xuésheng bìyè hòu xiān qù shíxí、zài zhèngshì qiúzhí。 | 多くの学生は卒業後、まずインターンシップを行い、その後正式に就職活動を行います。 |

 **よくある間違い:** 文脈なしで「毕业了」を使用する。 我毕业了は単に「卒業した」という意味です。 詳細については、機関 (毕业以)、年 (昨年毕业)、またはその後のアクション (毕业後...) を追加してください。 

## 対話

 **A:** 你现在哪里上学?学何么专业?
 尼仙才ザイ ニュルシャンシュエ? 雪神女展？ 
あなたは今どこで勉強していますか？ あなたの専攻は何ですか?

 **B:** 私は上海大学读书、业是國际贸易。 
Wƒ zài ShànghƎi Dàxué dúshu, zhuānyè shì guójì màoyì。 
私は上海大学で勉強しており、専門は国際貿易です。 

**A:** 那你学中文是為了工作还是為了兴趣?
 那珂雪中文士健康匡海石微力?
 それで、あなたは仕事のために中国語を勉強していますか、それとも興味のために勉強していますか？ 

**B:** 両方ありますが、主にその後の運用のために重要です。 
効果的な治療法、治療法、治療法を学びましょう。 Zhōngguó shìchƎng tài zhòngyào le。 
どちらもですが、主に将来就職するために勉強しています。 中国市場は非常に重要です。 

**A:** 你有没有想过去中国实习？ 
NƐ Yƒu méiyƒu xiƎng guò qù Zhōngguó shíxí?
 中国でインターンシップをしてみたいと考えたことはありますか？ 

**B:** 想う！私はトラフィックを計算した後、六月を過ぎて蓄積し、再度正式に申請しました。 
祥果！ ウー・ドゥ・スアン・ビー・ホー・シェン・チ・シシー・リュー・ゲ・ユエ、ジリー・ジンジアン、ザイ・ジョンシー・キウジー。 
私は持っている！ 卒業後はまず半年間のインターンシップで経験を積み、その後正式に就職する予定です。 

**A:** ご了承ください。成績がよければ、学金を申請することもできます。 
ヘンユージフア！ Rúguƒ nƐ chéngjì hƎo、hái kěyƐ shēnqƐng jiƎngxuéjīn。 
とてもよく計画されています！ 成績がよければ奨学金に応募することもできます。 

## 練習する

 **練習 1: ため了** で完了してください

 各アクションの目的ステートメントを書きます。 

1. 他每天练习書汉字，___。（書き方を改善する）
 2. 準備のため、___。(広範な調査を行いました)
 3. ___，她放弃了假期旅游。（プロジェクトを終了するため）

 **演習 2: 专业のコロケーション**

 正しい動詞 (学、换、从事、选) を入力してください:

 1. 打算___何ですか？ 
2. 二番目の時期に、コンピューターは化学的に改良されました。 
3. トラフィックの後、引き続きこのトラフィックに関連する操作が行われます。 

**演習 3: 翻訳**

 中国語に翻訳すると：

 1. 彼女は昨年清華大学を卒業しました。 
2. インターンシップに参加するために、彼は慎重に履歴書を準備しました。 
3. 卒業後、多くの学生は自分の専攻に関連する仕事を探します。 

## 文化的なメモ

 口語的に「内卷 (nèijuiqn、「革命」)」として知られる中国の学力圧力システムは、大学や雇用市場における激しい競争力学を表しています。 学生たちはトップの成績、名誉あるインターンシップ、そして有名企業での限られた数の望ましいポジションを目指して競い合います。 「考研」（kƎo yán、大学院入学試験を受ける）というフレーズはこのプレッシャーの象徴となっており、毎年何百万人もの卒業生が就職の可能性を高める手段としてさらなる勉強を選択しています。 この文化的背景を理解すると、なぜ教育用語が中国語の日常会話に頻繁に登場するのかを説明できます。
