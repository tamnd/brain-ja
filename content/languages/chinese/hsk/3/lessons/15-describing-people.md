## 概要

 中国語で人物を描写するには、性格形容詞の幅広い語彙と、描写を強めたり修飾したりする程度の表現を使いこなす必要があります。 このレッスンでは、重要な文字の形容詞を紹介し、形容词 + 极了 (非常に) と V + 得 + 程度補語 (動作の実行方法を説明する) という 2 つの重要な文法構造を教えます。 これらを組み合わせることで、微妙で生き生きとした人物描写が可能になります。 

## 学習目標

 - 性格形容詞を使用します: 活泼、认真、懒、聪明、勇敢、细心
 - 形容詞を強めるには「极了」を適用します
 - 動作の方法を説明する形式 V + 得 + 程度の補数
 - 性格とともに外見を説明する

 ## 文法重視

 ### パターン 1: 形容詞 + 极了 — 非常に

 **構造:** 形容詞 + 极了

 「极了」は形容詞の後に直接続き、「非常に」または「最大限に」を意味します。 「很」よりも強く、話者の強い感情的な反応を表します。 「极了」は否定語と一緒に使用できず、「非常」よりもフォーマルではありません。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 承認が完了しました。 Tā cōngmíng jí le、shénme dou yī xué jiù huì。 | 彼女は非常に聡明で、何でもすぐに理解します。 |
 | | この子アクティブは完了し、一時も停止しません。 Zhège hái​​zi huópō jí le、yī kè yě tíng bu xiàlái。 | この子はとても活発で、じっとしていられません。 |
 | | 今日の仕事は終わりました、私は三時間行いました。 Jīntiān de zuòyè nán jí le、wƒ zuò le sān ge xiƎoshí。 | 今日の宿題は非常に難しくて、3時間かけて取り組みました。 |

 **よくある間違い:** 形容詞の前に「极了」を置きます。 极了聪明は間違っています。 形容詞「聪明极了」の後に続く必要があります。 また、「极了」は動詞には付きません。 代わりに動詞には「得很」または「得不行」を使用してください。 

### パターン 2: V + 得 + 次数の補数 — アクションの方法

 **構造:** 動詞 + 得 + 形容詞/句 (アクションの実行方法を説明)

 得補語は、アクションの方法、質、程度を表します。 これは結果の補体とは異なります。ここで得られるのは構造粒子であり、潜在的な補体マーカーではありません。 通常、動作動詞、コミュニケーション動詞、パフォーマンス動詞の後に続きます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 非常に流動性の高い会話を実現します。 Tā HànyƔ shuō de fēicháng liúlì。 | 彼女は中国語をとても流暢に話します。 |
 | 他は笑得很开心、露呈した二酒窝。 Tā xiào de hěn kāixīn、lòu chō le liƎng kē jiōwō。 | 彼は二つのえくぼを見せてとても幸せそうに微笑んだ。 |
 | これは老师课教が生むものです。 ZhèwèilƎoshīkèjiāodehěnshēngdòng。 | この先生はとても生き生きと授業を進めます。 |

 **よくある間違い:** 動詞に目的語がある場合、動詞を繰り返すか、目的語を移動する必要があります。 她说汉语说得很流利（動詞の繰り返し）または汉语她说得很流利（オブジェクトを前に置く）。 她说汉语得很流利とは言えません。 

### パターン 3: 有点 + Adj vs. 比较 + Adj — 修飾された説明

 **構造:** 有点 + Adj (わずかに、穏やかな否定的な意味合いを含む) / 比较 + Adj (比較的、中立的な)

 中国語話者は人物を説明するとき、わずかに否定的または驚くべき特質を表すために「有点」を使い、中立的な比較を表すために「比较」を使います。 どちらを選択するかによって、説明のトーンが大きく変わります。

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 内向きの点があり、人が多い地方の話はあまり好きではありません。 Tā yƒudiƎn nèixiàng、bù tài xƐhuān zài rén duō de dìfāng shuōhuà。 | 彼女は少し内向的で、混雑した場所で話すのが好きではありません。 |
 | | 他比較真，做何事都很仔细。 Tā bíjiào rènzhēn、zuò shénme shì dou hěn zixì。 | 彼はとても誠実で、何事も慎重に行います。 |
 | | この人は非常に粗暴な性格で、小さな犯罪を頻繁に犯します。 Zhège rén yudiƎn cōxīn、jīngcháng fàn yīxiē xiào cuòwù。 | この人は少々不注意で、小さなミスをよくします。 |

 **よくある間違い:** 有点を肯定的な形容詞と一緒に褒め言葉で使用する。 有点聪明は恩着せがましく聞こえるか、「賢いけどそれほど賢くない」ということを暗示します。 肯定的な性質については、「很」、「非常」、または「比较」を使用します。 

## 対話

 **A:** 你觉得你们の新しい同じ事怎么样？ 
NĐ juéde nƐmen de xīn tóngshì zěnmeyàng?
 新しい同僚についてどう思いますか?

 **B:** 性格の活性化は完了しており、すべての意志を得ることができます。 
Tā xìnggé huópō jí le、gēn shéi dou néng liáo de hěn kāixīn。 
性格はとても活発で、誰とでも楽しく話せます。 

**A:** 作業面呢？ 
Gōngzuò fāngmià ne?
 仕事ではどうですか？ 

**B:** 物事は非常に真実であり、報告はその詳細を取得しており、非常に良いです。 
Zuò shì fēicháng rènzhēn、bàogào xiě de jíqí xiángxì、shàngsi hěn mƎnyì。 
彼女は非常に誠実に働き、報告書は非常に丁寧に書かれており、上司も非常に満足しています。 

**A:** 听起来很厉害！ 
ティン・クライライ・ヒン・リーハイ！ Yōméiyōu shénme xiào quēdiƎn?
 それは印象的ですね！ 小さな欠陥はありますか？ 

**B:** 点があります、つまり、時々粗暴な点があり、二度の交換時間があります。 
Yƒu diƎn、jiùshì yƒushíhou yƒudiƎn cüxīn、yĒu yī liƎng cì tíjiāo shíjiān jìcuò le。 
ちょっと。 彼女は時々少し不注意で、提出時間を一度か二度間違えました。 

**A:** この人は、ゆっくりと良い人です。全体的に言えば、彼は非常に潜伏力のある人です。 
Zhège ma、mànmàn jiù huì hào de。 ZƒngtƐ lái shuō、tā shì ge hěn yƒu qiánlì de rén。 
まぁ、徐々に良くなっていきますね。 全体として、彼女は素晴らしいポテンシャルを持った人です。 

## 練習する

 **演習 1: 极了を適用する**

 それぞれの状況を強く説明するには「极了」を追加します。 

1. これはひどいです。→ これはひどい___。 
2. 他唱歌很好听。 他→唱歌好听___。 
3. 那个孩子可爱。→ 那个孩子可爱___。 

**練習問題 2: V + 得の文**

 V + 得 + 度を使用して文を作成します。 

1. 她 / 跑 / 快 (速く走る)
 2. 他 / 中文说 / 流利 (中国語を流暢に話します)
 3. 这位厨师 / 做菜 / 好吃 (おいしい食べ物を作る)

 **練習問題 3: 有点または比较?**

 適切な単語を選択して、その選択を説明してください。 

1. 他___心、来る不犯错。 
2. 她___懒、作品全体は最後の才交です。 
3. この孟子___明、学西很快。 

## 文化的なメモ

 中国語での性格の説明は、文化的価値観を顕著に反映しています。 「真面目」（真面目、誠実）は、学業や仕事の場面で常に最高の褒め言葉の 1 つです。 プロフェッショナルな環境では「細心」（細部へのこだわり）が重視されます。 逆に、「懒」（怠惰）は道徳的な重みを伴う重大な批判です。 形容詞「内向」は伝統的な中国文化では一般に中立か、穏やかに肯定的であり、静かな思慮深さへの敬意を反映していますが、「外向」と「活泼」は現代のより国際的な文脈で賞賛されます。 こうした価値観の変化は、世代ごとに会話の中で性格語彙がどのように使われているかを見ればわかります。
