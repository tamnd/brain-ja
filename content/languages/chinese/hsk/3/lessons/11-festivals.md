## 概要

 中国の伝統的な祭りには、文化的意味、特有の語彙、独特の習慣が豊富にあります。 このレッスンでは、HSK 3 レベルで最も重要な 3 つの伝統的な祭り、春节 (春祭り)、中秋节 (中秋祭り)、端午节 (端午の節句) を紹介します。 文法の焦点は、習慣的な習慣や時間に基づいた活動を説明する方法をカバーします。 

## 学習目標

 - 中国の主要な伝統的な祭りとその習慣の名前と説明をしてください
 - フェスティバル中に何が起こるかを説明するには「在...的候」を使用します。 
- 習慣や伝統について議論するには、「习惯」と「习俗」を使用します。 
- フェスティバルの食べ物やアクティビティを適切な語彙で説明する

 ## 文法重視

 ### パターン 1: 在 + 祭り + 的時候 — 祭り中

 **構造:** 在 + [祭り/時間] + 的候, + 主節

 この time 句は、メイン アクションを特定の期間に固定します。 「的時候」は、時間表現を「その時点で」または「いつ」を意味する従属節に変換します。 これは、フェスティバルやイベント中に何が起こるかを説明する標準的な方法です。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 春節の季節には、家族全員が集まります。 Zài Chunjié de shíhou、Quan jiā rén huì yīqƐ chī niányèfàn。 | 春節には家族全員で大晦日の夕食を食べます。 |
 | 中秋の候、人は月、月を買います。 Zài Zhōngqiō Jié de shíhou、rénmen xíguàn chī yuèbƐng、shāng yuè。 | 中秋の名月には、人々は月餅を食べて月を愛でるのが習慣です。 |
 | | 午の刻の季節、南方の人たちは舟を漕ぎます。 Zài Duānwō Jié de shíhou、nánfāng rén huì sài lóngzhōu。 | 端午節の期間中、南部の人々はドラゴンボートのレースをします。 |

 **よくある間違い:** time 句で「会」を使用して、将来のイベントに「的時候」を使用します。 「他会来時候」は間違いです。 時間句は予測的なものではなく、説明的なものにしてください。 

### パターン 2: 习惯 + V / 有...的习惯 — 習慣

 **構造:** 主語 + 习惯 + 動詞 (慣れている) / 主語 + 有 + V + 的习惯 (の習慣がある)

 動詞としての「习惯」は「慣れる」という意味です。 「有…的习惯」は「何かをする習慣がある」という意味の名詞パターンです。 どちらも、文化的に組み込まれた規則的な行動を表しています。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 中国人䃯は春节に互角の年です。 Zhōngguó rén xíguàn zài Chunjié shí hùxiāng Bàinián。 | 中国人は春節にお互いに新年の挨拶を交わすことに慣れています。 |
 | | 他には、前日に大幅に削除されたものがあります。 Tāmen yƒu zài jiérì qián dà sƎochú de xíguàn。 | 彼らには祭りの前に大掃除をする習慣がある。 |
 | 私は毎年受信パケットを送信しました。 ウー・イジン・シグアン・レ・ミニアン・ショウ・ホンバオ。 | 毎年赤い封筒を受け取るのにはもう慣れています。 |

 **よくある間違い:** 习惯 (習慣/習慣) と习俗 (社会的習慣/伝統) を混同します。 「习惯」は個人の習慣を指しますが、「俗」は共同体の文化的伝統を指します。 贴春联是中国的传统习俗（春の対句を掲げるのは中国の伝統）では、习惯ではなく习俗を使用します。 

### パターン 3: 一家人 / 全家 — 家族再会の文法

 **構造:** 一家人/全家 + 都 + 動詞 (家族の集団的な行動を強調)

中国のお祭りは家族の再会が中心です。 「一家人」（家族全員）と「全家」（家族全体）というフレーズの後に「都」が続き、家族全員が一緒に参加することを示します。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 春節の季節、一家人都回来。 春節で考えて、一家仁の道を目指してください。 | 春節の時期に、家族全員が一緒に戻ってきました。 |
 | | すべて一起包子は非常に重要な俗物です。 Quan jiā yīqƐ bāo jiàozi shì hěn zhòngyào de xísú。 | 家族みんなで団子を作るのは大切な習慣です。 |
 | | 那天晚上全家人都坐在一緒に見春晚。 Nà tiān wƎnshàng quán jiā rén dōu zuò zài yīqƐ kàn ChunwƎn。 | その夜、家族全員が一緒に座って春祭りの祝賀行事を鑑賞しました。 |

 **よくある間違い:** すべて的家人を代わりに使用します。 「全家」と「一家人」は文法的には可能ですが、この文脈では自然かつ文化的に埋め込まれた用語です。 

## 対話

 **A:** 你最喜欢哪个中国节日?
 ニュズィ・シフアン・ニャ・ゲ・ジョングォ・ジエリー?
 中国のどのお祭りが一番好きですか?

 **B:** 我最喜欢春节！全家人都会回来，大家一起包饺子，看春晚。 
五瑞西環春節！ 銀維全家仁藤会会来、大家一揆保子子、甘春万。 
春節が一番好きです！ 家族全員が戻ってくるので、みんなで団子を作り、春祭りのお祭りを一緒に見ます。 

**A:** 你们家に何か特別な俗物がありますか？ 
ニュメン・ジア・ユウ・シェンメ・デ・キシス・マ?
 あなたの家族には何か特別な習慣がありますか？ 

**B:** あります！私たちは除夕の季節には必ず燭台を放ち、门の上に春を待ちます。 
ゆう！ ウィメン ザイ チューシー デ シーハウ イーディング ヨーファン イェンファー、ハイ ヤオ ザイ メン シャンティ チュンリアン。 
はい！ 大晦日にはいつも花火を打ち上げますし、玄関に春の対句も飾ります。 

**A:** 那中秋节呢？ 
ナ・ジョンチウ・ジエね？ 
中秋節はどうでしょうか？ 

**B:** 中秋節の時期、私たちは外面摆桌子、一月一月饼に在ります。 
Zhōngqiō Jié de shíhou、wōmen xíguàn zài wàimiàn bài zhuōzi、yībiān shƎng yuè yībiān chī yuèbƐng。 
中秋節には、外にテーブルを出して月を眺めながら月餅を食べるのが習慣です。 

**A:** 太浪漫了！在你的国家有似节日吗？ 
タイランマンレ！ 在留資格は何ですか？ 
なんてロマンチックなんでしょう！ あなたの国にも同様のお祭りがありますか?

## 文化的なメモ

 春節 (春节) は中国で最も重要な祝日であり、地球上で年間最大の人類の大移動である春运 (Chunnyùn、春節の旅行ラッシュ) には 10 億人を超える人々が故郷に帰ります。 中秋節の月餅は、単純な民間食品から手の込んだ贈答品産業へと進化し、高級ブランドが華やかな缶に入った月餅を製造しています。 红包（赤い封筒）の伝統はデジタル化しました。WeChat の赤い封筒機能（微信红包）は 2014 年に開始され、最初の春節だけで 10 億枚のデジタル赤い封筒を配布し、何世紀にもわたる習慣をソーシャル メディア現象に変えました。
