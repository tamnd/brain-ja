## 概要

 結果補語 (结果补语、jiéguƒ bƔyƔ) は、アクションが成功したか、失敗したか、または特定の結果が生じたかを示すために動詞の直後に付けられる単語です。 英語が単に文脈を使用する多くの中国語の文では、これらは必須です。 結果の補数をマスターすると、あなたの中国語が途切れ途切れから自然な中国語に変わります。 

## 学習目標

 - 一般的な結果の補語（好、完、懂、到、住、错）を動詞に正しく付ける
 - 補足は、継続的なアクションではなく、成功または結果を表すものであることを理解する
 - 結果の補足を含む否定文と質問を作成します
 - 結果の補体と潜在的な補体を区別する (レッスン 5 で説明)

 ## 文法重視

 ### パターン 1: 動詞 + 好/完 — 補完補語

 **構造:** 動詞 + 好 (適切に完了) または 動詞 + 完 (完全に完了)

 動詞の後の「好」は、アクションが正しく行われたか、準備ができたことを意味します。 完は、アクションが何も残さずに完了したことを意味します。 これらは最も一般的な結果の補数であり、中国語のすべてのレジスタに表示されます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 私はすでに準備ができています。 ウー・イジン・ジョンベイ・ハオ・レ。 | もう準備はできています。 |
 | 他ハンド告告写完了。 Tā bí bàogào xiěwán le。 | 彼は報告書を書き終えた。 |
 | | 饭行動好了，快来吃吧。 Fàn zuòhƎo le、kuài lái chī ba。 | 食事の準備ができました、食べに来てください。 |

 **よくある間違い:** 「好」と「完」を混同します。 「吃好」は満足して食べることを意味し（多くの場合、食後の丁寧な表現）、「完」は食べ物をすべて食べ終えることを意味します。 日常会話ではニュアンスが大切です。 

### パターン 2: 動詞 + 懂/到/住 — 達成を補う

 **構造:** 動詞 + 懂 (理解する)、動詞 + 到 (到達/取得)、動詞 + 住 (保持/保持)

 これらの補足は、認知的目標または身体的目標が達成されたかどうかを示します。 「懂」は知覚動詞（听、看、学）とともに使用されます。 「到」は目標に到達することを示すために使用されます。 「住」は何かを掴んだり保持したりすることを表します。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 老师说的话，你听懂了吗？ Lōshī shuō de hua, ni tīngdƒng le ma? | 先生の言ったことは分かりましたか？ |
 | | 私はネット上で那本に到達しました。 五才望生、女弁書。 | 私はその本をネットで見つけて購入しました。 |
 | この法を承認しておいてください。 ニャオ・バ・ザ・ゲ・イ・ファ・ジシュウ。 | この文法事項を暗記する必要があります。 |

 **よくある間違い:** 単独で「ある場所に到着する」という意味で「到」を使用します。 結果として、補語は「到達」だけでなく、「走到」(歩いて行きました)、「跑到」(走って行きました)という動詞の後に続く必要があります。 

### パターン 3: 動詞 + 错/坏/明確 — 品質結果の補完

 **構造:** 動詞 + 错 (間違って行われた)、動詞 + 坏 (有害に行われた)、動詞 + 明確 (明確に行われた)

 これらの補足は、結果の品質または正確さを表します。 「错」は学術的および日常的な文脈で非常に一般的です。 「坏」は身体的または精神的なダメージを表します。 明確とは、徹底性または明確さを表します。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | アドレスを書き込み完了しました。 NƐ bí dìzhƐ xiěcuò le。 | 住所を間違えて書きました。 |
 | | 孩子は花瓶を手に持った。 Háizi bà huaping shuāihuai le。 | 子供が花瓶を割ってしまいました。 |
 | この問題の内容を明確にしてください。 青女博之、Shuōqīngchó。 | この件について明確に説明してください。 |

**よくある間違い:** 動詞と補語の間に「了」を入れます。 写了错は間違っています。 補語は動詞に直接付加されます:「写错了」。 

## 対話

 **A:** 次の検討试你考得怎么样？ 
Zhè cì kƎoshì nƐ kƎo de zěnmeyàng?
 今回の試験の成績はどうでしたか？ 

**B:** あまり良くありません。私は 3 番目の質問を完了し、2 つの文字の書き込みも完了しました。 
ブタイハオ。 五百日三日、海游良、ハンズィ・シチェキュオ・レ。 
素晴らしいとは言えません。 3問目は間違って答えてしまい、2文字も書き間違えてしまいました。 

**A:** 那老师讲的语法你听懂了吗？ 
Nà lƎoshī jiƎng de yƔfó nƐ tīngdƒng le ma?
 先生が教えた文法は理解できましたか？ 

**B:** 大部分は修正されていますが、文章の一部も完全には不明瞭です。 
Dàbùfen tīngdƒng le、dànshì bƔyƔ de bùfen hái méi wánquán nòngqīngchƔ。 
ほとんど理解できましたが、補足部分が完全には理解できませんでした。 

**A:** 那你家に帰りましたら、メッセージを受信してください。 
Nà nƐ huí jiā hòu yào bƎ bƐjì fùxí hào、bƎ lìjù dōu jìzhù。 
そして家に帰ってからノートをしっかり見直して例文を全て暗記しましょう。 

**B:** 良かったです。今回は必ず準備が整いました。次回は再実行できません。 
好徳、zhè cì wóyīdìng yào zuòhƎo zhōnbèi、xià cì bù néng zài cuò le。 
よし、今度は絶対にしっかり準備して、二度と失敗しないようにするよ。 

## 練習する

 **演習 1: 正しい補語を追加します**

 意味に基づいて、空白に好、完、懂、到、住、错、または坏を入力します。 

1. 私は___那本から来ました。 
2. 你刚才说的我没___。 
3. 孩子は玩具を持っています___了。 

**演習 2: 文章の作成**

 提供されるヒントを使用して完全な文章を作成します。 

1. 彼 / 握る / 作业 / 做 / (完全に)
 2. 我 / 握 / 地址 / 写 / (間違って)
 3. 你 / 要 / 握 / 这首歌 / 记 / (暗記してください)

 各文の間違いを見つけて修正します。

2. 他听错了懂老师的。 
3. 問題は明らかです。 

## 文化的なメモ

 中国語の結果補完に埋め込まれた「完全性」の概念は、より広範な文化的価値観を反映しています。つまり、結果が明示的に述べられたり目に見えたりしない限り、タスクは完了したとはみなされません。 中国の仕事や勉強の文化では、単に「做了」（やった）と言うのではなく、会話の中で「做好了（適切にやった）」や「準备好了（準備ができた）」などの結果の補語を使って完了を明示的に確認するのが一般的です。 この言葉の正確さは、専門的および学術的な環境における徹底性と説明責任に対する期待を反映しています。
