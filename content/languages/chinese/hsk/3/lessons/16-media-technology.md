## 概要

 デジタルツールが日常生活に深く組み込まれている現代の中国では、テクノロジーの語彙はコミュニケーションに不可欠です。 このレッスンでは、デバイス、アプリ、デジタル アクティビティに関する重要な語彙と、2 つの生産的な文法パターン、用 + ツール + V (何かをするためにツールを使用する) および关について + トピック (トピックについて/トピックに関して) を取り上げます。 

## 学習目標

 - テクノロジーに関する語彙を使用する: アプリ、ダウンロード、ソフトウェア、アップデート、デバイス
 - アクションに使用されるツールを説明するには、「用」+「楽器」+「V」を使用します。 
- ディスカッションのトピックを構成するには、「について + 名詞/フレーズ」を使用します。 
- デジタル習慣について話し合い、テクノロジーの問題について説明します

 ## 文法重視

 ### パターン 1: 用 + 楽器 + 動詞 — ツールを使用して行う

 **構造:** 主語 + 用 + ツール/楽器 + 動詞句

 アクションを実行するために使用されるツールまたは方法を紹介します。 これは英語の「use...to」または「by using...」に相当し、テクノロジーの文脈では非常に一般的です。 ツールは「用」の後に続き、アクション動詞の前に置きます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 私はハンドマシンコード付款を使用しています。 ウー・ヨン・シュウジ・サオ・モフクアン。 | 携帯電話を使用して QR コードをスキャンして支払います。 |
 | |電子書き込みレポート。 多永点岛西宝高。 | 彼女はレポートを書くためにコンピュータを使います。 |
 | | 他は翻訳モジュールの追加説明を使用しています。 Tā yòng fānyì ruínjiàn xuéxí wàiyƔ。 | 彼は外国語を学ぶために翻訳ソフトウェアを使用しています。 |

 **よくある間違い:** 主語と動詞の後に「用」を置く。 我写报告用电脑は不自然に聞こえます。 正しい順序は「我用电脑写报告」です。 

### パターン 2: について + トピック + ... — について/関連

 **構造:** 「について + 名詞/フレーズ + 主句 (または: トピック設定フレーズとしての + 名詞/フレーズ)」

 「これについて」は、主節で説明するトピックを紹介します。 トピックフレームとして文の先頭に現れることも、文の途中に現れることもあります。 これは、中国語の話し言葉でも書き言葉でも、話題を変えたり、主題に関する情報を提示したりするときによく見られます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | この款新软件に関して、何か見る法はありますか？ Guānyú zhè kƎn xīn ruànjiàn、nƐyóushénme kànfƎ? | この新しいソフトウェアについてどう思いますか? |
 | 人工知能に関する文章を読みました。 ウーカン・レ・イー・ピアン・グァニュ・レン・ジネン・デ・ウェンチャン。 | 人工知能に関する記事を読みました。 |
 | 秘密暗号の安全性に関しては、大家がこれに注意を払っています。 Guānyú mìmƎ ānquán、dàjiā dōu Yīnggāi zhùyì。 | パスワードのセキュリティについては、誰もが注意する必要があります。 |

 **よくある間違い:** 关に関して (あるトピックについて/それに関して) と 对 について (誰かの視点に関して、に関して) を混同します。 主題を紹介します。 多くの場合、視点や態度が導入されます。 对この件事，我有不同意见（私はこの件に関しては異なる見解を持っています）。 

### パターン 3: 出问题了/出故障了を含むテクノロジーの問題の説明

 **構造:** 件名 + 出问题了 / 出故障了 / 坏了 - デバイスの故障について説明します

 これらの固定的な表現は、テクノロジーの故障を表します。 出问题了はより一般的 (何かが間違っている)、出故障了はより技術的 (故障)、坏了は最もカジュアルな (壊れた) です。

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 私の手は電気が入っていない、出ています。 ウォデシュジチョンブリョディアン、チュウウェンティレ。 | 携帯電話が充電できません。何か問題があります。 |
 | システムに障害が発生し、ホイールが開かなくなりました。 Xìtƒng chō gùzhàng le、ruĎnjiàn dƎ bu kāi。 | システムが故障したため、ソフトウェアが開きません。 |
 | | 画面が閉じました、何も見ません。 Píngmù huai le、shénme dou kàn bu jiàn。 | 画面が割れて何も見えない。 |

 **よくある間違い:** 電子機器に対して「破了」を使用します。 「破了」とは、（紙や布など）物理的に破れたり、ひび割れたりすることを意味します。 電子機器の場合は、「坏了」、「出问题了」、または「出故障了」を使用します。 

## 対話

 **A:** 你最近在用物么应用学中文?
 ニュウジンザイ・ヨンシェンメ・インギョン・シュエ・ジョンウェン?
 最近中国語を勉強するためにどのアプリを使っていますか？ 

**B:** 私は主に「汉字宝典」のファイルを毎日使用して手書きします。 
Wōzhōyào Yòng yī ge jiào "Hànzì BƎodiƎn" de ruànjiàn、měitiān yòng shƒujī liànxí xiě zì。 
私は主に「Hanzi Baodian」というソフトを使って、毎日スマホで文字を書く練習をしています。 

**A:** これらのソフトウェアに関しては、私たちは非常に良いと考えています。 
Guānyú nà ge ruƎnjiàn、wōtīng shuō guò、tīng shuō hěn hào Yòng。 
そのソフトウェアについて聞いたことがあります。とても便利だと聞きました。 

**B:** ただし、最近のシステムは更新中にいくつかの小さな問題が発生することがあります。 
Duì、dànshì zuìjìn xìtƒng yīzhí zài gēngxīn、yƒushíhou huì chō yīxiē xiƎo wèntí。 
そうですが、最近システムが更新され続けており、時々小さな問題が発生することがあります。 

**A:** 私は知っています、私たちの携帯電話の用途もそうです、一新して故障しました。 
ウー・ジーダオ、ウー・デ・ショージ・インギョン・イー・シー、イー・ガングシン・ジウ・チュー・グーチャン・ル。 
わかっています、私の電話アプリも同じです。 アップデートがあるたびに何かが壊れます。 

**B:** 你有没有用微信做过直播?
 NƐ Yƒu méiyƒu Yòng Wēixìn zuòguò zhíbō?
 WeChatでライブストリームをしたことがありますか?

 **A:** ありませんが、マイクロシグナルを使用して意図的に作成されたビデオに関しては、意思があると考えています。 
Méiyƒu、dàn wƒ kànguò guānyú yòng Wēixìn zuò shēngyì de shìpín、hěn yƒu yìsi。 
いいえ、でも、WeChat を通じたビジネスに関するビデオを見たことはあります。 とても興味深いです。

 **演習 1: 用**を使用して文を作成する

 **演習 2: トピックセンテンスについて**

 以下を使用して各トピックを紹介します。 

1. トピック: 人工智能 — 誰かの意見を求める文章を書く
 2. トピック: 网络安全 — 読んだ記事について文章を書きます
 3. トピック: 智能手机 — 問題を説明する文を書く

 **演習 3: テクノロジーの問題の説明**

 それぞれの問題を中国語で説明してください。 

1. 携帯電話の電源が入りません。 
2. アップデート後にソフトウェアがクラッシュしました。 
3. パスワードを忘れてログインできません。 

## 文化的なメモ

 中国のデジタル エコシステムは、グレート ファイアウォールのせいで世界のインターネットから大きく分離されており、一連の支配的なプラットフォームが並行して形成されています。 WeChat (微信、Wēixìn) は、メッセージング、支払い、ソーシャル メディア、ミニプログラムを組み合わせたスーパー アプリとして機能します。 Alipay (支付宝、Zhīfùbào) はモバイル決済の主流を占めています。 Douyin (抖音、TikTok の中国版) と Bilibili (哔哩哔哩) は、主要な短編ビデオおよび長編ビデオ プラットフォームです。 これらのプラットフォームはデジタルコミュニケーション、商業、文化のバックボーンを形成しているため、中国と通信したり中国で働いたりする人にとってこれらのプラットフォームを理解することは不可欠です。
