## 概要

 中国のメディア、教育、日常会話において、環境に関する話題がますます取り上げられるようになってきています。 このレッスンでは、環境問題や自然現象に関する語彙と、徐々に変化する様子を説明する 2 つの文法パターン、越来越 + 形容詞 (ますます多くなる) と变得 + 形容詞 (なった) を紹介します。 どちらのパターンも、環境問題だけでなくトレンドを議論するのに不可欠です。 

## 学習目標

 - 環境用語を使用する: 汚染、保護、自然、気候変動
 - 越来越 + adj を使用して、漸進的な変化を表現します。 
- 状態の変換を記述するには、变得 + adj を使用します。 
- 適切な語彙を使用して環境問題とその解決策について話し合う

 ## 文法重視

 ### パターン 1: 越来越 + Adj/V — More and More

 **構造:** 主語 + 越来越 + 形容詞 (または動詞句)

 「越来越」は、度合いが連続的かつ段階的に変化することを表します。 その後に形容詞または動詞句を続けることができます。 この文は、一度限りの変化ではなく、継続的な傾向を説明しています。 これは常に前の状態との比較を意味します。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 全球気候越来熱。 Quánqiú qìhòu yuèlái yuè rè。 | 地球規模の気候はますます暑くなっています。 |
 | | 空気汚染はますます重くなり、多くの人の心を支えます。 Kōngqì wōrƎn yuèlái yuè yánzhòng、ràng hěn duō rén dānxīn。 | 大気汚染はますます深刻化し、多くの人々を不安にさせています。 |
 | | 人はこれからも注意して保護されています。 Xianzài rénmen yuèlái yuè zhùyì huánbao le。 | 今日、人々は環境保護にますます注目しています。 |

 **よくある間違い:** 度を表す単語が既に含まれている形容詞と一緒に越来越を使用します。 「越来越非常热」は間違いです。 越来越はすでに次数修飾子として機能しているため、追加の強化子は必要ありません。 

### パターン 2: 变得 + 形容詞/状態 — になっています

 **構造:** 件名 + 变得 + 形容詞/説明

 「变得」は、対象が新しい状態に変化したことを表します。 「变得」は明確な状態の変化を示すのに対し、「越来越」は段階的な進行を示すという点で「越来越」とは異なります。 「变得」の後には、新しい状態を説明する形容詞または短いフレーズが続きます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 城市の空気はますます大きくなっています。 Chéngshì de kōngqì bàn de yuèlái yuèchà le。 | 街の空気はどんどん悪くなっていきました。 |
 | | 植林地からの活動が始まってから、ここはさらに進化しました。 Zìcóng zhí shù zào lín huódòng kāishᐐ hòu, zhèlƐ bàn de gèng lĜ le。 | 植樹運動が始まってから、この場所も緑が増えてきました。 |
 | 海洋が進歩するにつれて、魚の種類は大幅に減少しています。 HĎiyáng bàn de yuèlái yuè zāng、yúlèi jiƎnshƎo le hěn duō。 | 海はますます汚くなり、魚の数は大幅に減少しました。 |

 **よくある間違い:** 变得と成為を混同します。 变得 + 形容詞は品質の変化を表します。 成になる + 名詞は、アイデンティティまたは役割の変化を表します。 变得更好 (より良くなった) vs. 成為专家 (専門家になった)。 

### パターン 3: 应该 + V で環境責任を表現

 **構造:** 我们应该 + 動詞 / 大家都应该 + 動詞

 レッスン 13 のこのモーダル パターンは、環境に関する議論に不可欠です。 中国語での環境責任に関する記述には、ほとんどの場合、「应该」、「必须」、または「需要」が使用されます。

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 私たちは一次性プラスチックの使用を減らすことに取り組んでいます。 ウーメン・インガイ・ジアンシャオ・シャヨン・イーシーシン・スリーリャオ。 | 私たちは使い捨てプラスチックの使用を削減すべきです。 |
 | | 大家はこの学会の分野に属しています。 Dàjiā dōu Yīnggāi xuéhuì lājī fēnlèi。 | 誰もがゴミの分別を学ぶべきです。 |
 | 政府はこれを犯罪行為の計画に追加します。 Zhèngfō yīnggāi jiādà duì wōrƎn qƐyè de chófá。 | 政府は汚染企業に対する罰則を強化すべきである。 |

 **よくある間違い:** 責任の所在を付け加えずに「应该保护环境」と言う。 主体（我们、政府、每个人）を明記することで、中国の環境に関する議論においてその発言がより具体的かつ自然になります。 

## 対話

 **A:** 你觉得现在的環境跟以前比怎么样?
 あなたは今、どのようなことを考えていますか?
 以前と比べて現在の環境はどうだと思いますか？ 

**B:** あまり評価されません。 很多城市の空気はますます変化し、圃場の問題もますます重くなります。 
ブタイレグァン。 Hěn duō chéngshì de kōngqì yuèlái yuèchà、lājī wèntí yě yuèlái yuè yánzhòng。 
あまり楽観的ではありません。 多くの都市の大気環境はますます悪化しており、ゴミ問題もますます深刻になっています。 

**A:** ただし你有無し注意，现在人们对环保越来越重視了？ 
丹志女医道、仙在仁門、歓喜、越境、忠誠心？ 
しかし、今では人々が環境保護にますます注目していることに気づいていますか?

 **B:** そうですね、多くの地域で境界線が広がっています。私が住んでいる小区もさらに厳しい状況になっています。 
Yěu、hěn duō dìfāng dōu zài tuīxíng lājī fēnlèi。 ウー・ズー・デ・シャオク・イー・ビアン・デ・ゲン・ガンジン・ル。 
はい、多くの場所でゴミの分別が実施されています。 私の住んでいる地域もきれいになりました。 

**A:** これは素晴らしいですね。環境を守るためにこれをやろうとしているのですか？ 
鄭和豪。 どのような問題がありますか?
 それは素晴らしいことです。 環境を守るために個人は何をすべきだと思いますか?

 **B:** これは、少数の単一性の製品、多空間の公共交通、およびこの近傍の水用の電気にも適用されます。 
Yīnggāi shāo Yòng Yīcìxìng ChƎnpƐn、duō zuò gōnggòng jiāotōng、Hái Yīnggāi jiéyuē Yòng shuiqiòng diàn。 
私たちは使い捨て製品の使用を減らし、公共交通機関の利用を増やし、水と電気も節約する必要があります。 

**A:** 一人ひとりが行動すれば、環境は徐々に良くなるでしょう。 
デュイ。 ルーグー・ミー・ゲ・レン・ドウ・ズオイン・イディアン、歓喜九厘、广场片、gèng hào。 
右。 みんなが少しずつやれば環境は少しずつ良くなっていきます。 

## 練習する

 **練習 1: 越来越で完成**

 空白に適切な形容詞を入力してください。 

1. 全球暖気のせいで、海面が越えて来る___。 
2. 健康への関心が高まっているため、野菜や水果の量が増加しています__。 
3. この城市の交通はますます___、毎日とても重いです。 

**演習 2: 变得を使用して変換する**

 变得 + 形容詞を使用して各文を書き直します。 

1. 空気の量は以前とは異なります。 
2. この地方に比べて以前よりも美しくなりました。 
3. 彼の誠実さは以前よりも優れており、さらに強化されています。 

**演習 3: 環境に関する立場**

 「应该」、「越来越」、「变得」を使って環境への責任について 3 文を 1 文ずつ書きます。 

## 文化的なメモ

 中国は世界最大の二酸化炭素排出国であるが、再生可能エネルギーへの最大の投資国でもある。 中国政府のカーボンニュートラル公約（2060年までに碳中和）とピーク炭素排出目標（2030年までに碳达峰）は主要な政策公約である。 地元では、2019年に上海で導入され、その後全国に拡大されたゴミの分別義務（垃圾分类）は文化的な発火点となり、人々はソーシャルメディアでその分類について議論した。 「你是什么垃圾（あなたは何のゴミですか？）」というフレーズはバイラルミームとなり、文字通りの分類の質問からインターネット上の侮辱に変わり、環境政策が予想外の方法で大衆文化とどのように交差するかを示しました。
