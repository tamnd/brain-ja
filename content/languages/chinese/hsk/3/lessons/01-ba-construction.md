## 概要

 「握」 (bƎ) 構文は、中国語の最も重要な文法パターンの 1 つです。 オブジェクトを動詞の前に移動して、アクションの結果としてそのオブジェクトに何が起こるかを強調します。 この構造は日常の会話に常に現れ、意図的で結果志向の行動を説明するのに不可欠です。 

## 学習目標

 - 標準的な主語-動詞-目的語の文の代わりに「把」をいつ使用するのか、なぜ使用するのかを理解する
 - 結果の補語、方向の補語、処分動詞を使って正しい「把」文を形成する
 - 掴構文の後の必須の動詞補語を認識する
 - 状態動詞と一緒に、または補語なしで「把」を使用するというよくある間違いを回避します。

 ## 文法重視

 ### パターン 1: 握 + 目的語 + 動詞 + 結果の補語

 **構造:** 主語 + 把 + 目的語 + 動詞 + 結果の補語

 最も一般的な把パターンです。 結果の補語 (好、完、干净、明など) は、オブジェクトに対して実行されたアクションの結果を示します。 オブジェクトは、一般的な概念ではなく、特定の明確なアイテムです。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 作業は完了しました。 QƐng nƐ bɎ zuòyè zuòwán。 | 宿題を終わらせてください。 |
 | |私は房を打ちました。 五宝剣打手ガンジンレ。 | 私は部屋を徹底的に掃除した。 |
 | 他は完了しました。 ターバーナベンシュウカンワンレ。 | 彼はその本を読み終えました。 |

 **よくある間違い:** 補語を省略します。 「我掴书看」と言うのは文法的ではありません。 「我握书看完了」または「我握书看了一遍」と言わなければなりません。 

### パターン 2: 把 + 目的語 + 動詞 + 方向の補語

 **構造:** 主語 + 把 + 目的語 + 動詞 + 进/出/上/下/回 + 来/去

 方向の補足は、話者に対する相対的な動きを示します。 「把」と組み合わせると、物体を特定の方向に意図的に動かすことを表します。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | これらの荷物を運びます。 青柏zhèxiēshubānjìnlái。 | これらの本は屋内に持ち込んでください。 |
 | | 箱は钟包を包んだ。 Tā bíqiánbāo fàng jìn bāo lƐle。 | 彼女は財布をカバンの中に入れました。 |
 | 他は自家用車を押し出しました。 Tā bƎ zìxíngchē tuī chüqù le。 | 彼は自転車を押して外に出た。 |

 **よくある間違い:** 位置フレーズを動詞の後ではなく前に置く。 正解: 桌子上に湦放します。 誤: 桌子上放。 

### パターン 3: 握 + 目的語 + 動詞 + 给 + 受信者

 **構造:** 主語 + 把 + 目的語 + 動詞 + 给 + 受信者

 物を誰かに譲渡することを表現した文様です。 送、交、还、给などの動詞が頻繁に現れます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 私はお礼品を送りました。 ウー・バー・リー・ウー・ソン・ギー・レ・ター。 | 私は彼女に贈り物をあげました。 |
 | | 老师に仕事を渡します。 QƐng bƎ zuòyè jiāo gěi lƎoshī。 | 宿題を先生に渡してください。 |
 | |他は私も成功しました。 ターベシュフアンガイウレ。 | 彼はその本を私に返してくれた。 |

 **よくある間違い:** 不定の目的語で「把」を使用します。 その本が以前に確立されていない場合、「握り一本书放好」は間違っています。 「把那本书放好」または単に「放好一本书」を使用します。 

## 対話

 **A:** 小明，你把作业做完了吗？ 
小梅、娘、作物、何ですか？ 
シャオミン、宿題はもう終わりましたか？ 

**B:** はありません。私は数学を完了しましたが、文章は実行していません。 
ハイメイユウ。 Wƒ bƎ shùxué zuòwán le、dànshì Yówén hai mei zuò。 
まだ。 数学は終わったのですが、中国語の勉強がまだ終わっていません。 

**A:** 幸いです。文章も完成してから、部屋を下に整理しました。 
Kuài diƎn、bƎyƔwén Yě zuòwán、ránhòu bàngjiān zhěnglƐyīxià。 
急いで中国語も終わらせて、部屋を片付けてください。

**B:** 良いですね、妈妈。私は子の上の西放好吗を先制することができますか？ 
ハオデ、ママ。 呉能仙北庄子上で東西の方角馬ですか？ 
わかりました、お母さん。 Can I first put the things on the desk away?

 **A:** 可能ですが、かなり早いです。 
Kěyǐ, dànshì yào kuài. BĎ chuānghù Yě Guānshàng、Jīntiān fēng Hěn dà。 
できますが、急いでください。 Close the window too, the wind is strong today.

 **B:** 明白了！我马上すべて把握事情都好。 
明白！ Wƒ mƎshàng bƎ suƒyƒu shìqing dou zuòhƎo。 
わかった！ I'll get everything done right away.

 ## 練習する

 **Exercise 1: Sentence transformation**

 Rewrite each sentence using 把:

 1. 我洗干净了那些碗。
 2. 他握那本书拿走了。 (確認: これはすでに正しいですか?)
 3. 她送给了朋友一束花。

 **Exercise 2: Fill in the blank**

 適切な結果または方向を補って各「把」文を完成させます。 

1. 请你把灯___。(turn off)
 2. 我已经把作业___了。(hand in)
 3. 他把手机___包里了。(put into)

 **Exercise 3: Error correction**

 Find and correct the mistake in each sentence:

 1. 我把一杯茶喝了。
 2. 見てください。 
3. 她把钱在钱包里放。

 ## 文化的なメモ

 「拿」の構造は、行動に関する中国独特の考え方を反映しています。つまり、行動そのものだけでなく、特定のオブジェクトの処分や変換に重点が置かれています。 日常の中国語コミュニケーションでは、標準的な SVO 文と把文のどちらを選択するかによって、話者が結果や状態の変化を強調したいかどうかがわかります。 中国語話者が「吃完」ではなく「把饭完」（ご飯を完食する）と言う場合、「把」バージョンのほうがより強い義務感や緊急性を伴うため、親や教師がこの言葉を頻繁に使用します。
