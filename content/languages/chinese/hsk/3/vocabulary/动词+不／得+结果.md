## 動词+不/得+結果 (動詞 + 潜在的な補語)

 潜在的な補語は、動詞とその結果補語の間に「得 (de)」または「不 (bù)」を挿入して、その動作が意図した結果を達成できるかどうかを表します。 信号の可能性を取得します。 「なし」は不可能を示します。 

## 構造

 - **肯定:** 動詞 + 得 + 結果の補語
 - **否定:** 動詞 + 不 + 結果の補語

 一般的な結果の補語: 完 (wán、完了)、到 (dào、到達/達成)、了 (liƎo、なんとかする)、懂 (dƒng、理解する)、好 (hƎo、うまくやる)、见 (jiàn、認識する)。 

## 例文

 **この本は非常に危険です、私は見ません。**
 Zhè běn shō tài nán le、wƒ kàn bù dóng。 
この本は難しすぎます。 理解できません。 

**安心してください、この点の作業は完了しました。**
 Fàngxīn、zhè diƎn gōngzuò wƒ zuò de wan。 
心配しないでください、この量の仕事は私が終わらせることができます。 

**音太小声了，我听不见。**
 Yīnyuè tài xiiqoshēng le、wótīng bù jiàn。 
音楽が静かすぎる。 聞こえません。 

**今日の作品は多くありませんが、必ず書写が完了しました。**
 Jīntiān de zuòyè bù duō、nƐyīdìng xiě de wan。 
今日の宿題はそれほど多くありません。 必ず書き終えることができます。 

## 一般的な潜在的な補体

 | パターン | 意味 |
 |----------|----------|
 | 听得懂 / 听不懂 | （聞いて）理解できる/できない |
 | 見得见 / 見不見 | 見える/見えない |
 | 做得完 / 做不完 | | やり終えることができます / やり終えることができません |
 | 吃得了 / 吃不了 | なんとか食べられる/食べられない(すべて) |
 | 写得好 / 写不好 | 上手に書ける / 書けない |

 ## メモリーフック

 得 (de) はアクションと結果の間のゲートを開きます。 閉じません。 動詞とその結果の間にドアがあると想像してください。「得」はドアが開くことを意味し、「不」はドアが閉まったままであることを意味します。
