## 概要

 目的条項は、アクションが実行される理由を説明します。 中国語の 3 つの主な目的パターンは、為了 (するため)、以便 (都合よくするため、そのため)、および以免 (避けるため、しないため) です。 重要な課題は、為了が肯定的 (Y を達成するために X を行う) であるのに対し、以免が否定的 (Y が起こらないように X を行う) であることを理解することです。 以便はその中間に位置します。X を実行すると、他のことが可能になったり、より簡単になったりします。 これら 3 つはすべて、正式な中国語の文章に一般的であり、これらを制御することで散文に大幅な表現力が追加されます。 

## 学習目標

 - 「ため」を使用して肯定的な目的条項を作成します。 
- 後続のアクションを促進することを表現するには、「以便」を使用します。 
- 予防目的を表現するために「以免」を適用します。 
- 防止と免を区別し、結果指向の目的条項では确保を使用します。

 ## 文法重視

 ### パターン 1: 為了 + 目標/目的 + VP

 **構造:** 為了 + [目的 NP または VP]、件名 + メイン VP

 為了は目標を紹介します。 文の先頭 (主語の前) または主語の後に表示されます。 先頭に置くと目的が強調されます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 英語のレベルを上げるために、毎日少しずつゲストを招待します。 Wèile tígāo YīngyƔ ShuƐpíng、tā měitiān tīng yī xióshí bokè。 | 英語を上達させるために、彼女は毎日 1 時間ポッドキャストを聞いています。 |
 | 彼の努力は、より良い生活のためです。 Tā nólì gōngzuò shì weile gěi jiārén gèng hódeshēnghuó。 | 彼は家族により良い生活を与えるために一生懸命働いています。 |
 | | 最後の班地鉄のために、私たちは立ち上がった。 Wèile gƎnshàng zuìhòu yī bān dìtiě、wômen pƎo le qílái。 | 最終の地下鉄に乗るために、私たちは走り始めました。 |

 **よくある間違い:** 結果句の前に「為了」を使用しないでください。 為了他考上了大学は間違っています。 「ため」は結果ではなく目的（意図）に先行します。 結果には「結果」または「結果」を使用します。 

### パターン 2: 便 + 促進されたアクション

 **構造:** メイン VP、便便 + [促進された結果 VP]

 「以便」は、主なアクションが後続のアクションを可能にする、または容易にする条件を作成する場合に使用されます。 これは常にメインアクションの後に続き、それによって有効になるものを紹介します。 「以便」は正式な表現であり、ほとんど専ら書かれます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 時間処理のため、書き込みテーブルの値を先に入力してください。 QƐng tíqián tiánxiě biàogé、yƐbiàn wómen jíshí chƔlƐ。 | 迅速に対応させていただきますので、事前にフォームにご記入ください。 |
 | | 便宜上、すべての要点を承認しました。 Tā jì xià le suàyƒu yàodiƎn、yĐbiàn zhīhòu fùxí。 | 彼は重要なポイントをすべて書き留めて、後で確認できるようにしました。 |
 | | 公社は、労働者が変化を理解できるように、新しい政策を公開しました。 Gōngsī gōngbù le xīn zhèngcè、yƐbiàn yuángōng liƎojiě biànhuà。 | 会社は従業員が変更を理解できるように新しい方針を発表した。 |

 **「為了」と対比してください:** 「為了」は話し手の目標や動機を表します。 「便宜」は、誰かの利益または実際的な便宜のために作成された条件を表し、多くの場合、2 つの節の主語が異なります。 

### パターン 3: 以免 / 回避 / 防止

 **以免構造:** メイン VP、以免 + [負の結果 VP]
 ** 防止構造:** 防止 + [否定的な結果 NP/VP]
 **回避構造:** 回避 + NP/VP (一般回避)

 3 つはいずれも予防目的を示しています。 「以免」は接続詞です。主なアクションに続き、何が妨げられているかを紹介します。 防止と回避は動詞です。これらは直接目的語を取ります。

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | いくつかの帯の衣類を避けてください。 QƐng duō dài yī jiàn yīfu、yƐmiƎn zháoliáng。 | 風邪をひかないように、着替えなどをご持参ください。 |
 | 私たちは同様の事故が再び起こらないよう対策を講じています。 Wƒmen cƎiqƔ le cuòshī、fángzhƐ lèisì shìgù zàicì fāshēng。 | 二度と同様の事故が起こらないよう対策を講じました。 |
 | | プラグインを避けるために、パイナップル対。 ZƐxì héduì、yƐmiàn chuxiàn cuòwù。 | 間違いがないよう慎重に確認してください。 |

 **よくある間違い:** 以免は動詞として単独で使用できません。 我以免迟到とは言わないでください。 正しい形式は「我提前出门，以免迟到」（遅刻しないように早く出発しました）です。 

## 対話

 **内容:** 製品の発売前にチームに説明するチーム リーダー。 

A: 製品のオンライン時間を確保するには、さらに時間がかかることがあります。 
ウェイル・ケバオ・チャンピン・アンシー・シャンシャン、Dàjiā zhè zhōu xōyào jiākuài jìndù。 
*製品を予定通りにリリースするために、今週は全員がスピードを上げる必要があります。*

 B: 私たちは問題をできるだけ早く発見するために、機能を事前にテストしてきました。 
ウィメン イージン ザイ ティキアン チェーシー ゴンネング、イービアン ジョン ザオ ファーシャン ウェンティ。 
※問題点を早期に発見できるよう、事前に機能テストを行っております。 

A: 非常に良いですね。同時に大家は、技術的な迅速な障害を回避するために、テストの結果を注意深く検討しました。 
ハオ。 Tóngshí qƐng dàjiā xiángxì jìlù cèshì jiéguà、yƐbiàn jìshù tuánduì kuàisù dìngwei gùzhàng。 
*良い。 また、技術チームが迅速に障害を特定できるように、テスト結果を詳細に記録してください。*

 B: 明白。私たちも、情報を遮断するために、ホスト経由で通信することがあります。 
明白。 ウィメン・イエ・フイ・ズホドン・グートン、イミアン・シンシー・ブウ・トンブ、ザオチェン・イェンウー。 
*理解した。 また、情報が同期していないことによる遅延を避けるために、積極的にコミュニケーションをとっていきます。*

 A: 最後の瞬間に緊急事態が発生するのを防ぐために、私たちは主要な機能を完了する前に 2 日間争う必要があります。 
Duì、wèile fángzhƐ zuìhòu yī kè chōxiàn jƐnjí qíngkuàng、wƒmen yào zhēngqó tíqián liƎng tiān wánchéng zhƔyào gōngnéng。 
*右。 土壇場での緊急事態を避けるために、主要な業務は 2 日前までに完了するように努めるべきです*。 

B: 良いです。 この目標を達成するために、私たちは毎日早い時間に短い会議を始めることにしました。 
好徳。 健康な生活、健康な生活、健康的な生活を楽しみましょう。 
*わかった。 この目標を達成するには、毎日朝に簡単な進捗会議を開催することをお勧めします。*

 A: 同意します。時間を調整するために、会議の通知を事前に発行します。 
トンギ。 QƐng tíqián fā huìyì tōngzhī、yƐbiàn dàjiā ānpái hào shíjiān。 
*同意しました。 全員がスケジュールを調整できるよう、事前に会議通知を送信してください。*

 ## 多読

 城市の交通渋滞を減らすために、多くの城市で公共交通の誘導が始まった。政府は、市民がより便利に公共交通機関を利用できるように、さまざまな対策を講じている。 これらの対策の目的は、都市の発展を維持するために、市民の自動運転やウォーキングを奨励することである。 

Wèile jiƎnshƎo chéngshì jiāotōng yōngdōng、hěn duō chéngshì kāishƐ tuīguƎng gōnggòng jiāotōng。 正福忠泰、一喜一会、易ビアン・シーミン・ガン・ファンビアン・デ・シャイン・ディティエ・ヘ・ゴンジャオ。 Tóngshi、bùfen chéngshì xiànzhì sījiāchē jìnrù shì zhōngxīn、yƐmiƎn dàolù guòyú yōngjƐ。 Wèile fángzhƐ huánjìng jìnyībù èhua、yīxiē dìfang hái gólì shìmín qí zìxíngchē huò bùxíng。 Zhèxiē cuòshī de mùdì shì tígāo chōxíng xiàolƜ、quèbƎo chéngshì kě chíxù fāzhƎn。 ウェイル・シーシェン・ジー・イー・ムービアオ、シーミン・デ・ジージー・ペイヘ・イー・ジ・フィイン・グァン・ジョンヤオ。 

*都市交通渋滞を緩和するために、多くの都市は公共交通機関の普及を促進し始めています。 政府は住民が地下鉄やバスをより便利に利用できるよう一連の措置を導入している。 同時に、一部の都市では、道路の過度の渋滞を防ぐために、市内中心部への自家用車の進入を制限しています。 環境のさらなる悪化を防ぐために、一部の地域では住民に自転車や徒歩を奨励しています。 これらの措置の目的は、旅行の効率を向上させ、都市の持続可能な発展を確実にすることです。 この目標を達成するには、住民の皆様の積極的な協力も重要です※。

 ## 文化的なメモ

 「トラブルが発生する前に防ぐ」という防罹患未然 (fánghuàn yú wèirán) の概念は、中国の計画文化に深く組み込まれています。 このことわざは古典文献に登場し、プロジェクト管理から公衆衛生政策に至るまであらゆるものに引用されています。 中国語の正式な文章における「以便」と「免」の普及は、問題が起こってから対応するのではなく、問題を予測し、それを防ぐための行動を構築するというこの文化的な好みを反映しています。 中国政府の文書や会社の方針を読むと、随所にこうした構造があり、前向きでリスク回避の論理を示していることに気づくでしょう。
