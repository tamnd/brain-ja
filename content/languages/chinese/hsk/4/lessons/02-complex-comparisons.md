## 概要

 比との基本的な比較 (A比B + 形容詞) は A2 スキルです。 B1 では、どれだけ大きいか、何倍か、およびおおよその等価性を表現する必要があります。 「…的N倍」、「比…V得多」、「差不多」のパターンを使用すると、学術論文、ニュース、日常の説得などで常に現れる定量的で段階的な比較を行うことができます。 難しいのは語順の制御です。中国語の比較構造では、英語のように度数語を動詞の前に置くのではなく、動詞の後に置きます。 

## 学習目標

 - 是...的N倍を使用して乗算比較を構築します。 
- 程度の大きな違いを表すには、「比」+「得多/得少」を使用します。 
- 差不多と相差を適用して、おおよその平等と測定可能なギャップを表現します。 
- 程度補語を付けるときによくある語順の間違いを回避します。

 ## 文法重視

 ### パターン 1: A は B の N 倍

 **構造:** A + 是 + B + 的 + [数値] + 倍

 これを使用して、A が B の N 倍であると言います。「...」N 倍は、N 倍ではなく、正確に N 倍であることに注意してください。 したがって、是两倍は「2倍」という意味ではなく、「2倍」という意味になります。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 中国の人口はさらに30倍に増加した。 Zhōngguó de rénkƒu shì Jiānádà de sānshiduō bèi。 | 中国の人口はカナダの30倍以上です。 |
 | この目的の計算は上記の 2 倍です。 Zhège xiàngmù de yùsuàn shàng cì de liàng bèi。 | このプロジェクトの予算は前回の2倍です。 |
 | 他の薪水は私たちの三倍です。 ター・デ・シンシュイ・シー・ウ・デ・サン・ベイ。 | 彼の給料は私の３倍です。 |

 **よくある間違い:** 「N 倍」という意味で「是B多N倍」とは言わないでください。 これは英語からの「3倍以上」の頻繁な妨害です。 中国語で「是...的三倍」は合計の3倍を意味します。 

### パターン 2: A 比 B + 動詞 + 得多 / 多了

 **構造:** A + 比 + B + [動詞/形容詞] + 得多 OR A + 比 + B + [動詞/形容詞] + 多了

 これは、「より多い/より少ない」という重要な違いを表します。 ここでは「得多」と「多了」は同じ意味ですが、「多了」の方が少し口語的に聞こえます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 今年のエントリーは昨年よりも多かったです。 Jīnnián de shōurù bàqùnián duō de duō。 | 今年の収入は昨年よりもはるかに多いです。 |
 | この条路は那条路に比べて短いです。 Zhè tiáo lù bƐ nà tiáo lù duín duō le。 | この道はあの道よりずっと短いです。 |
 | 她的中文比我好得多。 Tā de Zhōngwén bƐ wƒ hào de duō。 | 彼女の中国語は私よりずっと上手です。 |

 **よくある間違い:** 比構造内に「很」または「非常」を挿入することは避けてください。 比我很好は間違っています。 すべての程度表現は形容詞の後に続きます: 比我好得多。 

### パターン 3: 差不多と相差

 **構造A:** A + 和/跟 + B + 差不多 (AとBはほぼ同じ)
 **構造 B:** A + 跟 + B + 相差 + [量/很大/不多] (A と B の違いは...)

 | 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | この二項ハンドマシンの欠点は数多くありません。 Zhè liƎng kuƎn shƒujī de jiàgé chàbuduō。 | これら 2 つの携帯電話の価格はほぼ同じです。 |
 | 他の二人のレベルにはそれほど差はありません。 Tāmen liƎng gèrén de shuƐpíng xiāngchā bù duō。 | 両者のスキルレベルにはほとんど差がありません。 |
 | 彼の年の差は十近です。 Tāmen de niánlíng xiāngchā jiāngjìn shí suì。 | 彼らの年齢は10歳近く違います。 |

 **コントラスト:** 差不多は、独立した副詞として「およそ」を意味することもあります (差不多三点钟 = 3 時頃)。そのため、それがおおよその平等を表現するのか、それともおおよその量を表現するのかは文脈によって決まります。 

## 対話

 **内容:** 受け取った求人オファーを比較する 2 人の友人。

A: 你最終決定受哪家公司のオファーは完了しましたか？ 
NƐzuìhòu juédìng jiēshòu nƎ jiā gongsī de Offer le?
 *最終的にどの会社のオファーを受けることになりましたか?*

 B: 私は那家初公司を選択しましたが、薪水と大公司の差はあまりありませんが、股权の方が優れています。 
ウーシュアン・レ・ナ・ジア・チュチュアン・ゴンシー、スイーラン・シンシュイ・ヘ・ダ・ゴンシー・チャブドゥオ、ダン・グォクアン・ゲン・ハオ。 
※私はスタートアップを選択しました。 給与は大企業とほぼ同じですが、資本は大企業より優れています。*

 A: 真の吗？ 私は初公司工科であり、一般に大公司よりも低いです。 
ジェンデマ？ ウー・イーウェイ・チュチュアン・ゴンシー・ゴンジー・イーバン・バイ・ダ・ゴンシー・ディ・デ・ドゥオ。 
*本当に？ スタートアップの給与は通常、大企業に比べてはるかに低いと思っていました*。 

B: 以前はそうでしたが、激しい争いでは差はそれほど大きくありませんでした。 
YĐqián shì zhèyàng、dàn xiànzài jìngzhēng jīliè、chājù méi name dà le。 
*以前はそうでしたが、今では競争が激しく、その差はそれほど大きくありません。*

 A: 那福利呢？ 
ないですか？ 
*特典についてはどうですか?*

 B: 大企業の福利は初公社の二倍であり、この点でも差が顕著です。 
Dà gōngsī de fúlì shì chuchuàng gōngsī de liàng bèi bù zhƐ、zhè fāngmiàn chājù hái shì hěn míngxiƎn。 
※大企業のメリットはスタートアップの2倍以上です。 この分野におけるギャップは依然として非常に明らかです。*

 A: 那你不后悔しいですか？ 
那个部后会?
 *後悔してない?*

 B: 残念です。長い空間では大公司よりもはるかに多く、これは私にとってより重要です。 
ブフフイ。 ChéngzhƎng kōngjiān bà dà gōngsī dà de duō、zhè duì wólái shuō gèng zhòngyào。 
*後悔はありません。 成長の余地は大企業よりもはるかに大きく、私にとってはそれがより重要です。*

 A: 合理的です。各個人の程度や目標は異なり、法的に直接比較することはできません。 
ユウドーリ。 Měi gè rén de chéngdù hé mùbiāo bù yīyàng、méi bànfƎ zhíjiē bƐ。 
*理にかなっています。 状況や目標は人それぞれ異なります。 直接比較することはできません。*

## 文化的なメモ

 中国のビジネスや学術の文脈での比較がカジュアルに行われることはめったにありません。 特定の倍数 (つまり...の N 倍) やデータに裏付けられた次数の違いを引用することは、信頼性を示します。 交渉において、中国の専門家は客観的な事実を述べるのではなく、立場を和らげるために戦略的に差不多を利用することが多い。 「我们的价格和市场价差不多」という言葉は、「ほぼ同じ」から「同じ球場にある」まであらゆる意味を持ち、意図的に解釈の余地を残しています。 この曖昧さを認識することは、文法を正しく作成することと同じくらい重要です。
