## 概要

 连...也/都パターンは、極端さと意外性をマークするための中国語で最も表現力豊かなツールの 1 つです。 最も可能性の低い、または極端なケースを表す項目を選び出し、その項目さえもステートメントに該当すると主張します。 このパターンを B1 レベルで難しくしているのは、「连」がどこに付くのか (名詞句、代名詞、動詞の前)、文脈の中で「也」と「都」を区別する方法、そして機械的に聞こえることなく音声でこのパターンを自然に使用する方法を正確に知ることです。 

## 学習目標

 - 文内の注目している要素の前に「连」を正しく配置します。 
- 動詞の後に「也」と「都」を使用する場合を区別します。 
- 「连...也/都」を否定と肯定と組み合わせると、2 つの異なる意味が生まれます。 
- 話し言葉と散文の両方でパターンを認識し、生成します。

## 文法重視

 ### パターン 1: 连 + NP + 也/都 + 動詞 (否定)

 **構造:** 连 + [焦点を絞った NP] + 也/都 + 不/没 + 動詞

 これは最も一般的な使用法です:「X さえない」。 「连」以降の項目は極端な例であり、否定はこの最小項目ですら条件を満たさないことを示しています。 ここでは「也」と「都」は同じ意味ですが、文章では「都」の方が若干強調されて聞こえます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 他は何もありません。 Tā lián fàn dou mei chī。 | 彼は食事さえしませんでした。 |
 | 私は他の名前も知りません。 我蓮太明子yěbùzhīdào。 | 彼の名前さえ知りません。 |
 | | 次の句も実行されません。 Tā lián yī jù huayě méi shuō jiù zƒu le。 | 彼女は一言も言わずに立ち去った。 |

 **よくある間違い:** 学習者は「连」を省略して「他都没吃饭」と書くことがよくありますが、これは「さえ」を強調せずに単に「彼は食べなかった」という意味です。 その強い集中力を生み出すのが「连」です。 

### パターン 2: 连 + NP + 也/都 + 動詞 (肯定)

 **構造:** 连 + [焦点を当てた NP] + 也/都 + 動詞

 肯定的な文では、このパターンは「X さえ（する/である）...」を意味し、最もありそうもない項目も当てはまることを示唆し、普遍性を暗示します。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | |小孩都はこの道理を知っています。 Lián xiàohhai dou zhīdào zhège dàolí。 | この原理は子供でも知っています。 |
 | 我妈も同意します。 リアン・ウー・マー・イー・トンジー・レ。 | 私の母も同意しました。 |
 | | 最も優秀な学生が時々仕事をしました。 リアン・ズィ・ラン・デ・Xuésheng dou ànshí jiāo le zuòyè。 | 最も怠け者の生徒でも宿題を時間通りに提出しました。 |

 **よくある間違い:** 主語の後に「连」を置かないでください。 正しい順序は、主語 + 连 + [注目の要素] + 也/都 + 動詞です。 「他」が注目要素そのものである場合は「连他也」と言うのは問題ありませんが、文脈がサポートしていなければ「他连饭也吃」（否定なし）はぎこちなく聞こえます。 

### パターン 3: よりソフトな代替手段として甚至

 **構造:** 甚至 + [極端な場合] + 動詞

 甚至は同様の「そこまで行く」というニュアンスを伝えますが、也/都フレームは必要ありません。 これは、段階的に項目をリストする場合に効果的です。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 他学は三度の外言を完了し、一日の会話さえも行った。 Tā xué le sān mén wàiyō、shènzhì hái huì iīdiƎn Rìyō。 | 彼は 3 つの外国語を学び、日本語も少し知っています。 |
 | | 非常に忙しく、周末まで加班にあります。 Tā hěn máng、shènzhì zhōumò yě zài jiābān。 | 彼女はとても忙しく、週末も残業しています。 |
 | | 天気は凍りつくまでに達した。 天啓冷道神志界姐楽。 | 凍ってしまうほど寒くなってきました。 |

**コントラスト:** 连...也/都は、固定構文スロット内の特定のフォーカスされた要素を必要とします。 「甚至」はより柔軟で、文節内の独立した副詞として使用できます。

 ## 練習する

 **練習問題 1: 強調するために書き直す。** 下線付きの要素を強調するには、「连...也/都」を追加します。 

1. 他不知道答案。(他) → ___
 2. 孩子喜欢この首歌。 (孩子) → ___
 3. 她没睡觉。(一分钟) → ___

 **練習問題 2: 也または都を選択してください。** どちらも正しいかもしれません。 音色の違いに注意してください。 

1. 更老师___不知道この道を行っています。 
2. 最も単純な問題は___回答なしです。 
3. 蓄積されました、___ 望ましくありません。 

**練習問題 3: 翻訳。** 「连...也/都」または「甚至」を使用して中国語に翻訳します。 

1. 監督もこの決定については知りませんでした。 
2. 彼女は先生も感心するほど練習しました。 
3. 彼は一日も休まなかったほど一生懸命働きました。 

## 文化的なメモ

 中国語のコミュニケーションでは、「连...也/都」を使用すると、評価上の重要性が高まります。 「连他都做不到」（彼にもそれはできない）ということは、その人の能力についての社会的理解が共有されていることを意味します。 職場や家族の文脈では、尊敬される人物についてこのパターンを展開すると、賞賛 (たとえそれができたとしても) または危機 (たとえ失敗したとしても) のいずれかを示す可能性があります。 話者は文化的にこれらの含意に適応しているため、パターンは単なる文法構造ではなく、強力な修辞ツールとなります。
