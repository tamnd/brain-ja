## 概要

 譲歩的なパターンは、自分の要点を主張しながら反論を認めることができるため、B1 レベルでは最も重要です。 3 つの核となるパターンは微妙に異なります。即使...也 (たとえ場合でも) は、仮定の極端なケースを表します。 不管/無论...都 (何があっても) 結果は変動に関係なく成立すると主張します。 尽管...还是/仍然 (にもかかわらず、しかし) は仮説ではなく実際の事実を認めます。 これら 3 つを混同することが最も一般的な間違いであり、この混乱は、英語が 3 つすべてに対して「たとえ」を大雑把に使用する傾向から生じています。 

## 学習目標

 - 仮説的譲歩 (即用) と普遍的譲歩 (不管/無论) および事実上の譲歩 (尽管) を区別します。 
- 即用と也、不管と都、尽管と还是または仍然を正しく組み合わせてください。 
- 即使の口語表現として「哪怕」と「就算」を適用します。 
- 議論を強化するためにこれらのパターンがどのように使用されるかを認識します。

 ## 文法重視

 ### パターン 1: 即用/哪怕/就算 + 仮説 + 也 + 結果

 **構造:** 即用/哪怕/就算 + [仮説上の最悪のケース]、也 + [依然として真の結果]

 譲歩条項は仮説的なものです。たとえ X が真であったとしても (そうでない可能性もあります)、結果条項は成立します。 「哪怕」はより感情的で口語的な表現で、話し手が決意を表明するときによく使用されます。 「就算」も同様に口語的ですが、もう少し中立的です。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | たとえ失敗しても、私たちも解放されません。 JíshƐ shībài le、wóyě bú huì fàngqì。 | たとえ失敗しても諦めません。 |
 | | 成功は百分の一だけであり、他の人も熱心に試みています。 NƎpà zhƐyƒu bƎifēnzhī yī de chénggōngló、tā yě yuànyì shiìshi。 | たとえ成功の可能性が1パーセントしかなかったとしても、彼はそれでも挑戦するつもりだろう。 |
 | | 計算は再蓄積され、毎日継続されます。 九年生、他愛者。 | 彼女は疲れ果てていても、まだ毎日運動しています。 |

 **よくある間違い:** 実際に正しい事実を説明する場合は「即用」を使用しないでください。 状態が実際の場合は、尽管を使用します。 即使用は、厳密に仮説または極端なケースを示します。 

### パターン 2: 不管/無论 + [包括的なフレーズ] + 都 + 結果

 **構造:** 不管/無论 + [疑問詞 / A还是B / 任意の範囲の句], + 都 + [一貫した結果]

 このパターンは、条件がどのように変化しても結果が同じであることを主張します。 すべてを含むフレーズは通常、疑問詞 (什么、怎么、谁、哪里) を使用するか、二者択一 (A还是B、好还是坏) を提示します。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 日中の空気が抜けて、他都標準時に来ます。 BùguƎn tiānqì zěnmeyàng、tā dōu zhōnshí lái shàngbān。 | 天気がどうであろうと、彼はいつも時間通りに仕事に来ます。 |
 | | 無论遇到何困難，我们都要坚持下去。 ウーロン・ヨーダオ・シェンメ・クンナン、ウーメン・ドゥ・ヨー・ジアンチ・シャクゥ。 | たとえどんな困難に遭遇しても、私たちは前進し続けなければなりません。 |
 | | 結果は良好で、私たちは受け入れることができます。 BùguƎn jiéguà hƎo háishi huai、wóu dōu néng jiēshòu。 | 結果が良くても悪くても、受け入れることができます。 |

 **無论 vs 不管:** 無论はよりフォーマルで、中国語の書き言葉でよく使われます。 「不管」も同様に正しく、音声ではより一般的です。 どちらも結果節に都（または也）が必要です。 

### パターン 3: 尽管 + 事実上の譲歩 + 还是/仍然 + 結果

 **構造:** 尽管 + [現実の、認められた事実]、还是/仍然 + [期待に反する結果]

尽管は（仮説ではなく）実際の状況を認めます。 次に、結果条項では、この実際の障害にもかかわらず、結果は依然として有効であると述べています。 この文脈では、「还是」と「仍然」はどちらも「それでも/それでも」という意味で、「仍然」の方が若干フォーマルです。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 蓄積されても、動作は完了し続けます。 JōnguƎn hěn lèi、tā réngrán jiānchí wánchéng le gōngzuò。 | 彼女はとても疲れていましたが、それでも粘り強く仕事をやり遂げました。 |
 | | 反撃にもかかわらず、私たちはこの決定を下しました。 JƐnguƎn tā fƎnduì、wômen haishi zuò chō le zhège juédìng。 | 彼は反対しましたが、それでも私たちはこの決定を下しました。 |
 | | 多くの困難があったにもかかわらず、この目標はなんとか達成されました。 JĐnguƎn miànlín xƔduō tiƎozhàn、gāi xiàngmù réngrán ànshí wánchéng le。 | 多くの課題に直面しましたが、プロジェクトは予定通りに完了しました。 |

 **3 つすべてを比較してください:** 即使用面临失败，我也不放弃 (仮説)。 不管面临什么，我都不放弃（普遍的）。 尽面临失败，我还是没放弃（事実、それは起こった）。 

## 対話

 **内容:** 2 人の同僚が、深刻な障害に直面したが、それでも成功したプロジェクトについて話し合っています。 

A: 听说项目组は很多难を克服しました、最後に困難は成功しましたか？ 
Tīngshuō xiàngmù zōkèfú le hěn duō kùnnán, zuìhòu haishi chénggōng le?
 *プロジェクトチームは多くの困難を乗り越え、それでも成功したと聞きましたが?*

 B: そうですが、途中で高度な技術的課題が明らかになったにもかかわらず、依然として挑戦を続けています。 
Shì de, jǐnguǎn zhōng tú chūxiàn le hǎo jǐ cì jìshù wèntí, tāmen réngrán jiānchí xiàlái le.
 *はい。 途中でいくつかの技術的な問題が発生しましたが、それでも問題は解決しませんでした。*

 A: 团队里有人想放弃吗?
 トゥアンドゥイ・リー・ユー・レン・シェン・ファンチー・マ?
 *チームの中に辞めたいと思った人はいますか?*

 B: 有、不队長说、不看到何事问問題、我们都是先解解方式、再考虑放。 
YĒu、búguò duìzhƎng shuō、bùguƎn yùdào shénme wèntí、wƒmen dou yào xiān zhƎo jiějué fāng'àn、zài kƎolófàngqì。 
*はい、でもチームリーダーは、どんな問題が起きても、辞めることを考える前にまず解決策を探すべきだと言いました。*

 A: この精神は、たとえうまくいかなくても、それ自体に価値がある。 
Zhè zhƒng jīngshén hěn nándé。 JíshƐ zuìzhōng méiyƒu chénggōng、zhège jīnglì běnshēn yě hěn yƒu jiàzhí。 
※その精神は素晴らしいですね。 たとえ結果的に成功しなかったとしても、その経験自体は非常に価値のあるものになったでしょう*。 

Ｂ： 問題なし。 単にカクカクの動作能力が向上しただけでもある。 
メイキュオ。 Nāpà zhƐshì tígāo le tuánduì de xiézuò nénglì、yě yƐjīng zhídé le。 
*その通り。 たとえそれがチームのコラボレーション スキルを向上させるだけだったとしても、それだけの価値はすでにあったはずです*。 

A: 結果は不明ですが、このアイテムはすべて、宝箱のテストを経て蓄積されています。 
Wúlùn jiéguƒ rúhé、zhège xiàngmù dou gěi zhěnggè bùmén jīlěi le bƎoguì de jīngyàn。 
*結果に関わらず、このプロジェクトは部門全体にとって貴重な経験を蓄積しました。*

 Ｂ：対。プロセスは非常に困難であるが、結果は良好であり、これは最大の受信率である。 
デュイ。 Bìjìng、jƐnguƎn guòchéng hěn jiānnán、dàn jiéguà shì hào de、zhè jiùshì zuìdà de shōuhuò。 
*右。 結局のところ、プロセスは大変でしたが、結果は良かったです。 それが最大のメリットです*。 

## 多読

 非常に新しい技術であり、どのような方法であれ、継続的に投入する時間と精力が必要ですが、最初は非常に早いです。 しかし、大多数の人は、一時的な停滞を感じていても、環境がどのように変化しても、容易に解放されることはありません。 安定した状態での継続的な再生は重要です。 熟練の蓄積は長期間にわたるものであり、スタンドロッドのような効果は見られませんでしたが、そのたびに最終的な突破口が開かれました。 

Xuéxí yī mén xīn jìnéng、wúlùn xuƎnzé shénme fāngfƎ、dōu xōyào chíxù tóurù shíjiān hé jīnglì。 JĐnguƎn yōxiē rén zài chuqī jìnbù hěn kuài、dàn dàduōshù rén réngrán xōyào jīnglì Yī Duàn Píngtái qī。 JíshƐ gƎndào tíngzhì bù qián、yě bù yīnggāi qīngyì fàngqì。 BùguƎn wàijiè huánjìng rúhé biànhuà、bƎochí wěndìng de liànxí jiézòu cái shì guānjiàn。 Nāpà měitiān zhƐyƒu sānshí fēnzhōng、zhƐyào jiānchí xiàqù、jiù néng kàndào míngxiƎn de jìnbù。 

*新しいスキルを学ぶときは、どの方法を選んだとしても、時間とエネルギーの継続的な投資が必要です。 初期段階で急速に進歩する人もいますが、ほとんどの人は依然として停滞期を経験する必要があります。 行き詰まりを感じても、簡単に諦めてはいけません。 外部環境がどんなに変化しても、安定した練習リズムを維持することが重要です。 たとえ1日30分でも、続けていけば目に見えて上達します*。

 ## 文化的なメモ

 中国文化は、粘り強さ (坚持) と困難に耐える能力 (吃苦) を重視します。 このレッスンの譲歩的なパターンは、この文化的理想を言語的にエンコードしています。 「不管多难都要坚持」（どんなに難しくても、続けなさい）や「即使用败也不后悔」（たとえ失敗しても、後悔はしません）などのフレーズは、モチベーションを高めるスピーチから卒業式の辞、ソーシャルメディアの投稿に至るまで、あらゆるものに登場します。 これらのパターンを知ることは、中国語の議論の構造を理解するのに役立つだけではありません。 また、中国の公的な議論の中で、決意と回復力がどのように組み立てられ、称賛されているかを知る機会にもなります。
