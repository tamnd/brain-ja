## 概要

 A2 レベルでは、否定は単純です。「不」と「没有」です。 B1 では、ニュアンスを伴った否定、疑い、確率的否定、限定的否定を表現する必要があります。 「不见得」、「未必」、「不確実」、「也许」などのパターンはすべて、明確な肯定と明確な否定の間のスペースを占めます。つまり、「必ずしもではない」、「絶対ではない」、「可能ではあるが確実ではない」です。 これらのパターンを制御することで、リスクを回避し、懐疑的な意見を丁寧に表現し、確実性を誇張することを避けることができます。これらはすべて、中国語の議論において重要です。 

## 学習目標

 - 形式と強さの観点から、「不见得」、「未必」、「不定」を区別します。 
- 何かが一定の程度に達していないことを表現するには、「没有...那么」を使用します。 
- 也许、说不定、大概のヘッジ表現を適切に組み合わせます。 
- これらのパターンが説得や丁寧な反対の際にどのように使用されるかを認識します。

 ## 文法重視

 ### パターン 1: 没有 + NP + 那么/这么 + Adj

 **構造:** 件名 + 没有 + [参照 NP] + 那么/这么 + Adj

 これは、対象が参照点によって暗示される程度に達していないことを示します。 那么は、すでに言及または理解されているもの (「そのレベル」) を指します。 これは、現在または現在議論されているもの (「このレベル」) を指します。 これは比比較の負の値です。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | この問題は望まれたものではありません。 Zhège wèntí méiyƒu nƐ xiƎng de name nán。 | この問題はあなたが思っているほど難しくありません。 |
 | 他に大家の贔屓はない。 Tā méiyƒu dàjiā shuō de name lìhai。 | 彼はみんなが言うほど印象的な人ではない。 |
 | | 状況はありません。 Qíngkuàng méiyƒu name zāogāo。 | 状況はそれほど悪くない。 |

 **よくある間違い:** このパターンでは「比」を使用しないでください。 他没有比你那么高は間違っています。 没有你那么高を使用します。 

### パターン 2: 不见得 / 未必 / 不確実

 **構造:** 件名 + 不见得/不必/不定 + VP

 3 つはすべて「必ずしも」という意味ですが、形式と程度が異なります。 「不一定」は最も口語的で、中立的な立場です。 「不见得」は口語的で、多くの場合、話者がその主張を積極的に疑っていることを意味します。 「未必」は形式的かつ文学的で、中国語の書き言葉では一般的です。 この 3 つはすべて、動詞の前に「就」を続けることで強化できます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 钱多不見得就幸福。 Qián duō bùjiànde jiù xìngfú。 | お金が増えることが必ずしも幸せを意味するわけではありません。 |
 | | 名牌大学毕业は良い仕事に到達する必要はありません。 Míngpái dàxué bìyè wèibì néng zhàodào hào gōngzuò。 | 有名大学を卒業したからといって、必ずしも良い職に就けるとは限りません。 |
 | 他に会うことがありますが、私は他に不確実な真の訪問を受け取ります。 Tā shuō tā huì lái、dàn wƒ juéde tā bù yīdìng zhēn de lái。 | 彼は来ると言ったが、本当に来るとは限らないと思う。 |

 **コントラスト:** 绝对不 (絶対にそうではない) は確実性の対極にあり、ヘッジではありません。 何かが真実ではないことを表現したい場合は、「绝对不」を使用します。 確率的な疑いを投げかけたい場合は、不见得/未必/不確実を使用します。 

### パターン 3: + VP に達しない

 **構造:** 主語 + 不至以下 + VP (何かが起こるまでには至らないことを表現)

 恐れられている、または極端な結果が起こる可能性が低いことを表現するものではありません。 誇張された懸念を安心させたり、押し返したりするために使用されます。

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 他の人はこれを批判しますが、炒め物には至りません。 Tā huì pīpíng nƐ、dàn bùzhìyú chƎo nƐyóuyú。 | 彼はあなたを批判するでしょうが、解雇まではしません。 |
 | 問題は依然として重いですが、解決できないほどではありません。 Wèntí suīrán yánzhòng、dàn bùzhìyú wúf͎ jiějué。 | 問題は深刻だが、解決できないほどにはならないだろう。 |
 | 他人はこの么简单の事都不知道吧にいませんか？ 他にどのような問題がありますか? | きっと彼は、こんな簡単なことを知らないとは思いませんか？ |

 **使用上の注意:** 不至以下は、先行する譲歩的な節 (虽然...、ただし不至以下) とペアになることがよくあります。 これは、発言者が問題を認識している一方で、懸念されているほど極端ではないと主張していることを意味します。 

## 対話

 **内容:** 2 人の友人が、仕事でミスをした後、共通の友人が解雇されるかどうかについて話し合っています。 

A: 听说小王在项目里出了大错误，会不会被开除？ 
Tīngshuō Xiiqo Wáng zài xiàngmù lƐ chō le dà cuòwù、huì bú huì bèi kāichú?
 *シャオ・ワンはプロジェクトで大きな間違いをしたと聞きました。 彼は解雇される可能性がありますか?*

 B: 入手できませんでした。これは長年にわたって公社で保管されていますが、一度の失敗はそれほど重くはありませんでした。 
ブジアンデ。 多才GōngsīGànlezhèmeduō年、yīcìshīwùbùzhìyúnàmeyánzhòng。 
※必ずしもそうとは限りません。 彼はその会社に何年も勤めている。 1 つの間違いはそこまで深刻なものではありません。*

 A: ただし、損失が大きく、予定の半分を超えています。 
Dànshì sƔnshī tƐng dà de、jùshuō chāoguò le yùsuàn de Yī bàn。 
※しかし、損失はかなり大きいです。 予算の半分を超えてしまったそうです*。 

B: 必ずしも必須ではなく、項目管理上も問題がある可能性があると考えています。 
ウィー・ジュエデ・ウェンティ・ウェイブ・クァン・シー・ター・デ・ゼレン、xiàngmù guƎnlƐ shàng kěnéng yě yƒu wèntí。 
*私は、問題が必ずしも完全に彼のせいではないと思います。 プロジェクト管理にも問題がある可能性があります。*

 A: それも許可します。 
イェシュバ。 Shuōbudìng gōngsī huì ràng tā jiēshòu péixùn、ér búshì zhíjiē kāichú。 
*多分。 会社が彼を直接解雇するのではなく、研修を受けさせる可能性もある*。 

B: 対して、公社は非常に大きな問題を解決することができない。 
Duì、gōngsī guīmó name dà、bù yīdìng fēi děi kāichú rén cái néng jiějué wèntí。 
*そうです、これほど大きな会社であれば、問題を解決するために必ずしも誰かを解雇する必要はありません。*

 A: 何も私が望んでいないものはなく、等官方からも通知されています。 
Búguò Qíngkuàng méiyāu wōmen xiàng de name jiƎndān、Háishi Děng guānfāng tōngzhī ba。 
※状況は私たちが思っているほど単純ではありません。 正式な通知を待ちましょう*。 

## 多読

 洞察力のある管理者は、一度失敗したからといって、そのプロセスのすべての価値を否定する必要はありません。 もちろん、問題は、いくつかの失われたセッションのかなりの重さであるが、このように、完全に無法に保存されるわけではない。 

Zài zhíchƎng zhōng、Hěn duō rén duì shībài de hòuguƒ guòyú dānxīn。 Qíshí、fàncuò bùjiànde jiù yìwèizhe zhíyè shēngyá jiéshù。 Yīgè míngzhì de guƎnlƐzhě weibì huì yīnwei yī cì shīwù jiù fōudìng yīgè yuángōng de quánbù jiàzhí。 Wèntí méiyƒu xiƎngxiàng de name kěpà、guānjiàn zàiyú rúhé cóng cuòwù zhōng xuéxí。 Dāng rán、yƒuxiē shīwù díquè bƐjiào yánzhòng、dàn jíbiàn rúcƐ、yě bùzhìyú wánquán wúfƎ bƔjiù。 BƎochí lěngjìng、jījí miànduì、shuōbudìng fƎn'ér néng cóng wēijī zhōng zhƎodào xīn de jīhuì。 

*職場では、失敗の結果を過度に心配する人が多くいます。 実際、間違いを犯したからといって、必ずしもキャリアの終わりを意味するわけではありません。 賢明なマネージャーは、たった 1 つのミスで従業員の価値をすべて帳消しにする必要はありません。 この問題は想像されているほど恐ろしいものではありません。 重要なのは、エラーからどのように学ぶかです。 もちろん、中には本当に重大なミスもありますが、それでも完全に修復不可能になるとは限りません。 落ち着いて前向きに対処すれば、危機の中で新たなチャンスを見つけることもできるかもしれません。*

 ## 文化的なメモ

ヘッジと確率的否定は、中国人のコミュニケーションにおいて重要な社会的役割を果たします。 誰かに「不是」（それは真実ではありません）と直接反論すると、面目を傷つける可能性があります。 「不见得（必ずしもそうであるとは限らない）」または「未必如」と言うことで、面子を失わずに元の話者部屋を離れて位置を調整しながら、同じコミュニケーション目標を達成できます。 これが、これらの表現が中国人の議論、交渉、丁寧な議論で不釣り合いに一般的である理由です。 ヘッジを学ぶことは間接的なことではありません。 それは、中国の社会的文脈において意見の相違がどのように管理されるかを理解することです。
