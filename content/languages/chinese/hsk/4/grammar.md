HSK 4 の文法は、自信を持って中上級のコミュニケーションを図るための約 80 の核となるパターンをカバーしています。 このレベルでは、複雑な比較、正式なレジスタ、高度な条件構造、トピックコメント文、微妙なアスペクトの使用法に焦点を当てます。 

## 1. 高度な比較

 ### 1.1 比と具体的な違い

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | A + 比 + B + Adj + 一点儿 | 他比我高い点儿。 彼は私より少し背が高いです。 |
 | A + 比 + B + Adj + 得多 | |他よりもはるかに多くのオプション。 彼女は彼よりもずっと賢いです。 |
 | A + 比 + B + Adj + 多了 | 今天比昨天熱多了。 今日は昨日よりもずっと暑いです。 |
 | A + 比 + B + 多/少 + V + 数 | 他比我多学了二年。 彼は私より2年多く勉強しました。 |

 ### 1.2 不如 (bùrú) — それほど良くない

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | A + 不如 + B (+ Adj) | |私は他に例のないほど快速を取得します。 私は彼ほど速くは走れません。 |
 | A + 不如 + B | この計画はそのようなものではありません。 この計画はあの計画ほど良くありません。 |

 ### 1.3 は…の構造 — 状況を強調する

 **過去**の行動の時間、場所、方法、または主体を強調するために使用されます。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | 是 + [強調] + V + 的 | 彼は昨天来ました。 彼は（ちょうど）昨日来ました。 (時間重視) |
 | 是 + [強調] + V + 的 | 私は北京の中国語です。 私は北京で中国語（特に）を学びました。 |
 | 是 + [強調] + V + 的 | これは谁写ですか? | これを書いたのは誰ですか? （これは誰の文章ですか？） |

 ## 2. 複雑な接続詞

 ### 2.1 ではない…しかも — だけではなく…だけではなく、

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | ただし + A，しかも + B | | 他は中国語、そして会議日の言葉。 彼は中国語だけでなく日本語も理解します。 |
 | 不仅…还 | | 説明するだけでなく、一生懸命働きます。 彼女は頭が良いだけでなく、勤勉でもあります。 |

 ### 2.2 虽然…却/但是 — とはいえ…まだ

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 虽然 + 譲歩、却 + コントラスト | |それでも蓄積され、心を打ち負かします。 疲れてはいますが、（私は）まだ幸せです。 |
 | ずっと…仍然 | | 雨が降ったにもかかわらず、（私は）それでも来ました。 |

 ### 2.3 は…また — 両方…そして

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | ある + A + 又 + B | この道菜は好吃また便宜です。 この料理は美味しくて安いです。 |
 | また…また | 他また高また帅。 彼は背が高くてハンサムです。 |

 ### 2.4 宁可/宁愿…也 — むしろ…

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 宁可 + A + 也 + B | | 早まってもいいし、早まらなくてもよい。 遅れるよりは早く到着する方が良いでしょう。 |
 | 宁愿 + A + 也不 + B | | 一人の人、また行動しません。 落ち着くよりも一人でいることを好みます。 |

 ## 3. トピックコメント文

 トピックは、何が議論されているかを確立するために最初に配置され、その後にそれに関するコメントが続きます。 

### 3.1 基本的なトピック - コメント

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | トピック + コメント | 那本书，我看完了。 その本 - 私は読み終えました。 |
 | トピック + コメント | 中文、他学了三年了。 中国語 — 彼は 3 年間中国語を勉強しました。 |
 | トピック + コメント | この件については、私たちはよくわかりません。 この件については、私にはよくわかりません。 |

 ### 3.2 二重主語の文

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | S1 + S2 + VP | 那栋楼、门坏了。 あの建物 - ドアが壊れています。 |
 | S1 + S2 + 調整 | | 大物、鼻子が長い。 ゾウは鼻がとても長いです。 |

 ## 4. 越…越パターン

 ### 4.1 越来越 — もっともっと

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 越来越 + Adj | 天気越来越冷。 天気はますます寒くなってきました。 |
 | 越来越 + V | 他越来越不想上班。 彼はますます仕事に行きたくなくなりました。 |

 ### 4.2 越…越 — 多ければ多いほど…多ければ多いほど

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 越 + V + 越 + Adj | | 越学以上の意思があります。 勉強すればするほど面白くなります。 |
 | 越 + Adj + 越 + V | | ますます望ましくありません。 高ければ高いほど、買いたくなくなります。 |

 ## 5. 形式的否定パターン

 ### 5.1 不…也不 — どちらでもない … どちらでもない

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 不 A + 也不 B | 他不吃も不喝。 彼は食べたり飲んだりしません。 |

 ### 5.2 非…不可 — 必須。 仕方ないけど

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 非 + V + 不可 | この件は実行不可能です。 この問題は必ず実行しなければなりません（回避することはできません）。 |
 | 非要 + V | 他は去りたくない。 彼は行くと言い張った。 |

 ### 5.3 無论/不管…都/也 — 構わない…それでも

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | 無论 + 条件 + 都 | | あまり忙しくなく、ずっと待っています。 どんなに忙しくても食べなければなりません。 |
 | 不管 + 条件 + 也 | 他に何も言わず、私も不信です。 彼が何と言おうと、私は信じません。 |
 | 無论…还是… + 都 | | 無論风も下雨です、都要来。 風が強くても雨が降っても、（あなたは）来なければなりません。 |

 ## 6. 後悔と希望的観測を表明する

 ### 6.1 要是/如果…就好了 — もしそうなら

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 要是 + 条件 + 就好了 | 要是我有钱就好了。 お金さえあれば。 |
 | 如果…多好啊 | | 在れば多好。 あなたがここにいてくれたらどんなに素晴らしいだろう。 |

 ### 6.2 早知道…就 — もっと早く知っていたら

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 早知道 + 条件 + 就 + 結果 | | このことを早く知りました、不来ました。 こんなに大変だと知っていたら、来なかったでしょう。 |

 ## 7. 目的と目標の表現

 ### 7.1 了 — するため / 目的のために

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 為了 + 目標 + V | | 肥やすために、毎日実行します。 体重を減らすために、彼女は毎日走っています。 |
 | 為了 + 人/物 | | 家人のために、さらなる努力。 家族のために、彼は一生懸命働いています。 |

 ### 7.2 便宜 — の便宜のために/

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | V + 以便 + ゴール | | 早めに通知します。 スケジュールを調整できるよう、早めに連絡してください。 |

 ## 8. 倒是/是による譲歩

 ### 8.1 崩壊 — 確かに / 本当ですが…

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | Adj + 倒是 + Adj, ただし… | | 便宜倒は便利ですが、量は良くありません。 安いですが、品質は悪いです。 |
 | ステートメント + 倒是 | | 前は来ました、許可はありません。 彼は来ましたが、何も言いませんでした。 |

 ## 9. 中心文と使役文

 ### 9.1 让/叫び/使 + 人 + V — 使役

 | 動詞 | 登録 | 例 | 英語 |
 |------|----------|----------|----------|
 | 让 | ニュートラル | 老师让我重写。 先生は私に書き直させた。 |
 | 叫 | 口語 | | 妈妈叫び我回家。 お母さんは私に家に来るように言いました。 |
 | 使う | フォーマル | これはとても感動的です。 これには私は深く感動しました。 |
 | 令 | 公式/書面 | | このレマンは考えています。 これは驚くべきことです。 |

 ## 10. 什么…都/也 — Any/Every

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 什么 + 都/也 + V | 他何か都吃。 彼は何でも食べます。 |
 | 谁 + 都/也 + V | | 谁都知道。 誰もが知っています。 |
 | 哪里 + 都/也 + V | | 里都でも構いません。 どこでもいいです。 |
 | 怎么 + 都/也 + V | | 怎么も到達できません。 どうやっても見つからない。 |

 ## 11. 時間表現と時制

 ### 11.1 已经…了 — すでに

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 已经 + V + 了 | | 他はすでに解除されました。 彼はすでに出発しました。 |
 | 都 + 已经 + V + 了 | |都すでに十点完了。 もう10時だ。 |

 ### 11.2 快/快要/将要…了 — これから

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 快 + V + 了 | | 快く報告しました。 授業がもう終わります。 |
 | 快要 + V + 了 | | 我快要毕业了。 もうすぐ卒業です。 |
 | 将要 + V | 他に公開します。 彼はこれから出発するところです。 (正式) |

 ### 11.3 曾经 — 一度（過去に）

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 曾经 + V + 过 | 私は曾那里を去りました。 私は一度そこに行きました。 |

 ## 12. 強調構造

 ### 12.1 连…都/也 — さえ… (それでも/また)

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 连 + N + 都 + V | | 子都知道。 子供でも知っています（それは）。 |
 | 连 + V + 都 + V-Neg | | 長い時間がかかりません。 食べる時間さえない。 |

 ### 12.2 強調/制限の場合

 | 使い方 | 例 | 英語 |
 |----------|-----------|----------|
 | 制限 | | これはこれです。 これだけ。 |
 | 状態重視 | 私は去らない。 私はただ行くことを拒否します。 |

 ## 13. 文末助詞

 | 粒子 | トーン | 機能 | 例 |
 |----------|------|----------|----------|
 | 了 | — | 状態の変化 | 下雨了。今雨が降っています。 |
 | 吧 | — | 提案/仮定 | 走吧。行きましょう。 / 你是老师吧?|
 | 呢 | — | 進行中の状態 / 軽い質問 | 他呢？彼はどこですか？ / 在呢。まだここにいます。 |
 | 嘛 | — | 「明らかに」 / 説明 | 他は来ません、私は知っています。明らかに彼は来ません。 |
 | 啊 | — | 驚き、感嘆、和み | 真漂亮啊！とても美しいです！ |

 ## 14. 主要なパターンのまとめ

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | それでも…しかも | それでも努力し、そして説明します。 勤勉なだけでなく、頭も良い。 |
 | …である | | 在哪儿学的ですか？ どこでそれを学びましたか？ |
 | 连…都 | これもわかりません。 これも知りません。 |
 | 無论…都 | | 何も必要はありません。 何があっても、粘り強く続けなければなりません。 |
 | 越来越 | | 越来ますます良い。 ますます良くなりました。 |
 | 不可…不可 | | 去れません。 行かなければなりません。 |
 | のために了 | | 成功のために努力します。 成功に向けて一生懸命働きましょう。 |
