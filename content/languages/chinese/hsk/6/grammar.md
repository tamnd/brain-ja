HSK 6 の文法は、C1 レベルの熟練度、つまり複雑で形式的、分析的、文学的、修辞的な中国語をネイティブに近い理解と作成に必要なパターンをカバーしています。 このレベルでは、古典文法の化石、高度な従属、正式な登録、洗練された談話構成が統合されています。 

## 1. 現代中国語における古典中国語の文法の化石

 現代の中国語の書き言葉には、特に形式的および文学的な文脈において、多くの古典的な構造が保存されています。 

### 1.1 之 (zhī) — 古典的な所有格/名詞化マーカー

 | 機能 | 例 | 英語 |
 |----------|-----------|----------|
 | 所有的 (= 的) | 民主之路 | 民主主義の道 |
 | 動詞の後（正式） | 求之不得 | 求めても手に入らない |
 | ノミナライザー | 言之有物 | (スピーチ) 内容がある |
 | イディオムの化石 | 一石二鸟之计 | 一石二鳥の計画 |

 ### 1.2 乃 (nƎi) — 古典的な「である / したがって」 (= である/就)

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | N + 乃 + N (正式なコピュラ) | ここ乃关键にあります。 まさにこれが重要なポイントです。 |
 | 乃至 | 乃至全国范围 | 国家レベルにまで |

 ### 1.3 から (yú) — 古典的な前置詞 (= 在/到/比/对)

 | 機能 | 例 | 英語 |
 |----------|-----------|----------|
 | 場所 | | 問題はここにあります。/ 問題はここにあります。 問題はここにあります。 |
 | 比較 | 予定より大きい。| 予想以上に素晴らしい。 |
 | 方向性（正式） | | 委员会に引き渡しました。 委員会に提出されました。 |
 | パッシブエージェント | |人によって作られました。 他人に束縛される。 |

 ### 1.4 以 (yƐ) — 古典的な「～によって / するために」

 | 機能 | 例 | 英語 |
 |----------|-----------|----------|
 | 手段 | 以理服人 | 理性で説得する |
 | 目的 | 以期达到目标 | 目標を達成するために |
 | 修正: 以…である | 以量が根本 | 品質を基本として扱う |
 | 以降 | 以至以無法規制 | 制御不能になるまで |

 ### 1.5 それ (qí) — 古典的な三人称代名詞 / That

 | 機能 | 例 | 英語 |
 |----------|-----------|----------|
 | 所有欲 (= 他/她/它的) | その观点 | 彼/彼女/その視点 |
 | 実証的 | その理由は | その理由は | にあります。 
| 修正: 尤其 | 重要 | 特に重要 |

 ## 2. 正式な従属節の構造

 ### 2.1 虽…然 (古典的な譲歩)

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 虽…然（文学） | (引用) | 虽千万人、吾往矣。 一万人いるけど行きます。 |
 | 現代のエコー: 虽然…然然 | | 確かに危険ですが、退くことはできません。 難しいとはいえ、尻込みしてはいけません。 |

 ### 2.2 コネクタとして

 | 機能 | 例 | 英語 |
 |----------|-----------|----------|
 | 逆境 (= ただし) | | 易行难、而して行者鲜。 言うのは簡単ですが、実行するのは難しいです。 そしてそれを行う人は少数です。 |
 | シーケンシャル (= その後) | 考えて後行 | 考えてから行動する |
 | 手段 (= 通过) | 理服人ではなく非力 | 力ずくで理性で説得 |

 ### 2.3 则 — フォーマルなその後 / コントラスト

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 条件 + 则 + 結果 | | 志願者は成功しました。 決意を持った人が成功します。 |
 | コントラスト A 対 B | |このように、エチレンはありません。 A はこのようになります。 Bはそうではありません。 |
 | イディオムで | 不破则不立 | (古いもの) を壊さなければ、(新しいもの) を確立することはできません。

 ## 4. 複雑な句の種類

 ### 4.1 強調のための文の裂け目

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | そう…使/令 | | 苦しい環境が長寿をもたらします。 過酷な環境が彼を成長させた。 |
 | 正是…才 | | これはまさにこの問題であり、才能は今日の成功を収めています。 まさにこの粘り強さが今日の成功につながりました。 |

 ### 4.2 文体効果のための文の反転

 ## 6. 名詞化と複雑な名詞句

 ### 6.1 长定语 (長い限定語句)

 正式な中国語では、長い修飾句が名詞の前に置かれ、複数の句が含まれることがよくあります。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | [長い句] + 的 + N | 政府主導による、多方面からの参加による共同治療案 | 複数の政党が参加する政府主導の包括的なガバナンス計画 |
 | [V + 的] + N (動作名詞) | すでに完了した任務 | 完了したタスク |

 ### 6.2 の主語/目的語としての節

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | [句 + 的] を件名として | これは完全に正しいものではありません。 彼の言ったことは完全に正しいわけではありません。 |
 | [句 + 的] オブジェクトとして | | 私たちは提案の構築をサポートします。 私はあなたが提出した提案を支持します。 |

 ## 8. レトリックと文体の工夫

 ### 8.1 並列構造 (排比 páibĐ)

 正式な中国語では、修辞効果を得るためにトリコロンの並列表現が多用されます。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | 3 つの並列 VP | 私たちは努力する必要があり、真学を認め、新しい。 私たちは一生懸命働き、熱心に勉強し、積極的に革新しなければなりません。 |
 | 3 つの並列 NP | 有理想、有道德、有纪律の新時代青年 | 理想と道徳と規律を持った新時代の若者たち |

 ### 8.2 修辞的質問 (反问 fƎnwèn)

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 难道…吗？ 难道我们就此放弃吗?| 本当にこの時点で諦めてしまうのでしょうか？ |
 | 岂…乎?(文学) | 岂能置之不理乎?| どうしてそれを単純に無視できるのでしょうか？ |
 | 何…之有？(クラシック) | 何难之ありますか？ どのような困難があるのでしょうか？ |

 ### 8.3 アンチテーゼ (对比 duìbà)

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | A…、B… | | 知っているなら、知らないで退場します。 事前に知っている人は。 そうでない者は撤退する。 |
 | 有…有無し… | | 有志者事成、無志者一事無成。 決意を持った人は達成します。 持たざる者は何も達成しない。 |
