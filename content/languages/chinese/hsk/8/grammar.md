HSK 8 文法は、C2 エキスパートレベルの習得を表しており、口語から古典まで、専門領域にわたるあらゆる音域を完全に生産的に制御します。 このレベルでは、文法の研究は、本物のネイティブの文章、専門家レベルの学術的言説、現代の文脈における古典的な構造の積極的な使用を特徴づける微妙な違いに焦点を当てます。 

## 1. 完全な本番環境での古典文法

 HSK 8 では、学習者は、学術的な序文、正式なスピーチ、文学的エッセイ、専門的なコミュニケーションなど、適切な現代の文脈で古典文法を生み出す (認識するだけでなく) ことができます。 

### 1.1 積極的に使用するための古典的な文パターン

 | パターン | 古典的な例 | 現代のコンテキスト |
 |---------|-------------------|----------------|
 | S + 以 + 意味 + V | 柔克刚 | 以创新驱アニメーション公開展 |
 | 不可…不可 | 非此不可 | 非解决此问题不可 |
 | 有…者 | 有志者 | 有识之士 |
 | 莫 + V (= 没有人…) | 莫能胜之 | 莫能阻止挡的历史潮流 |
 | 何…之有 | 何难之ありますか？ 何か疑問がありますか？ 
| V + 之 + V (古典的相対化) | 求之不得 | 梦寐以求之理想 |

 ### 1.2 現代の散文に組み込まれた古風な語彙

 | 古典的な言葉 | 現代の同等物 | エキスパートの使い方 |
 |--|----|-----------|
 | 彼 | 那/那个 | あの時は。 お互いにこれ |
 | ここ | これ/これ | 此举この動き。 その後その後 |
 | 乃 | 是/就 | これは歴史的に必然である。 |
 | い | 说 | 子曰く孔子はこう言った。 
| 亦 | 也/也である | 亦有道理も合理的 |
 | 盖 | 大概/因 | 盖のせいで… (それは) おそらく… |
 | 特別 | 特別/非常 | 殊途同归 異なる道、同じ目的地 |

 ## 2. 専門家のアカデミックライティングの慣例

 ### 2.1 要約と導入パターン

 | 機能 | パターン | 例 |
 |----------|-----------|----------|
 | 研究目的 | 本研究/论文拟 | このテキストは…展システム分析に適用されます。 
| 研究上の質問 | 核心问题は/本文试图回答 | 核心问题は：…どのように影響しますか…？ 
| 範囲の制限 | この研究は | に焦点を当てています/限定されています この研究は 2010 年から 2020 年のデータに焦点を当てています。 
| 重要性 | … 重要な理性と実践意を持っています。 この問題は、実際の概念と一致する重要な理論です。 
| 構造プレビュー | 全文共分…部分/章节 | 全文は 5 つの部分に分かれています。 

### 2.2 文献レビューの言語

 | 機能 | パターン | 例 |
 |----------|-----------|----------|
 | 以前の作業を承認する | 既有研究已/前人已证明 | | 研究により、両者間の相関関係が明らかになりました。 
| ギャップを特定する | しかし、…仍有厘清/悬而未决 | ただし、深層マシンにはまだ改善の余地があります。 
| 自分の作品を差別化する | 有有研究異，本… | | これまでの研究とは異なり、ここでは新しい値を導入します。 

### 2.3 方法論と分析言語

 | 機能 | パターン | 例 |
 |----------|-----------|----------|
 | データソース | データの出典/ベース | | データは国家局から提供されています。 
| 分析アプローチ | 用…架台/モデル…加以分析 | | リバースモデルを使用してデータを追加して分析します。 
| 可変制御 | 制御…变量/干扰因素を排除 | 年と性質の変化量を制御します。 
| 堅牢性 | 稳健性检验の証拠 | | 耐久性試験により、結果が一致していることが示されました。

 ## 3. 登録間の流暢さ

 HSK 8 の特徴は、1 つのテキストまたは会話でレジスタ間を正確にコード切り替えできる機能です。 

### 3.1 レジスタ連続体の例

 | 登録 | 例 (同じアイデア) | コンテキスト |
 |----------|---------------------|----------|
 | クラシック | 此事宜缓议。 正式文書 |
 | 正式な書面 | この事は不適当です。 学術的または公式 |
 | フォーマルな会話 | この問題は一時的なものではありません。 役員室 |
 | ニュートラル | この事は急遽決定されました。 オフィス |
 | 口語 | この事は一縷です。 カジュアル |

 ### 3.2 形式文と口語のペア

 | フォーマル/文学 | 口語 | 意味 |
 |------|-----------|----------|
 | 貫管如此 | 虽然这样 | それでも |
 | しかし | でも/できる | ただし |
 | したがって | 所以 | したがって |
 | 予以 | 给 | （正式に）与える |
 | 加以 + V | 对…V | 対処する/対処する |
 | なし + V | 没办法V | |する方法がありません。 
| 不足 | 有欠 | | の不足はありません。

 ## 4. 微妙な側面とモダリティ

 ### 4.1 過去の参考文献における微妙な違い

 | パターン | 意味 | 例 |
 |----------|---------------|----------|
 | 了（アクションファイル） | 完了 | 彼は報告書を書きました。 |
 | 了 + 了 (ダブルル) | 完了 + 状態の変化 | 彼は報告書を書き終えた。 |
 | 过（体験） | ある時点での経験 | 彼は同様の報告書を書いています。 |
 | 曾 (かつて、文学) | 過去に（公式） | 彼はかつて大きなプロジェクトを率いていました。 |
 | 曾几何時 | 少し前（文学） | 少し前まで、この場所は荒野でした。 |

 ### 4.2 高度なモーダルの組み合わせ

| パターン | 意味 | 例 |
 |----------|----------|----------|
 | 必須ではありません | 必ずしもそうではない (= おそらく) | 決して悪いことではないかもしれない。 |
 | 不無 + N/Adj | なしではありません (= いくつかあります) | 不無道理 理由がないわけではない |
 | 無し + VP | 例外なく | 众人無不敬佩。例外なく、誰もが（彼を）賞賛した。 |
 | 莫不是 | それはあり得るでしょうか？ | 莫不是他出了什么事？もしかして、彼の身に何か起こったのでしょうか？ |
 | 岂非 | まさにそうではないですか？ | 岂非绝佳タイム机？これはまさに理想的な瞬間ではないでしょうか？ |

 ## 5. 句読点と表記規則

 ### 5.1 书名号《》 — タイトルマーカー

 作品、法律、文書のタイトルに使用することが義務付けられています。 

| 使い方 | 例 |
 |------|-----------|
 | 本/映画 | 《红楼梦》 |
 | 法律・規制 | 《中华人民共和国合同法》 |
 | 記事・エッセイ | 《论改革の必要性》 |

 ### 5.2 カンマ vs 顿号 (、) vs セミコロン

 | マーク | 機能 | 例 |
 |------|----------|----------|
 | 、 | 並列名詞リスト | 苹果、香蕉、橘子 |
 | ，| 句区切り文字 | 他来了，我才道。 
| ；| 個別の並列句 | 理想は一灯、努力は前進の原動力。 
| ：| 一覧または説明を紹介 | 有三点：其一…其二…其三… |

 ## 6. 談話凝集装置

 ### 6.1 参照および共同参照

 | デバイス | 例 | 機能 |
 |----------|----------|----------|
 | 前者…後者 | | 前者は量を調整し、後者は効率を入力します。 前述の 2 つの項目を参照してください。 
| 前述/前述 | 前述の問題は解決されました。 前述の | を参照してください。 
| 该 + N | 该研究 / 该机构 | 前述の N | への正式な参照
 | ここ / 彼 | | 今度は、彼も一度。 古典的なあれこれ |

 ### 6.2 凝集性の代替

 | デバイス | 例 | 機能 |
 |----------|----------|----------|
 | 如此/此样 | このような場合は、負担する必要はありません。 前述の状況を置き換える |
 | ここ | これに対して、各方面からの反発が相次いでいる。 これに関して（前述） |
 | ここにある | これに従って出决策 | これに基づいて（結論） |
 | ここまで | このために、私たちは対策を講じました。 この目的のために / この目的のために |
