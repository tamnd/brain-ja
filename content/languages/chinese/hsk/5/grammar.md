HSK 5 文法は、高度な B2 レベルのコミュニケーションのための約 85 のコア パターンをカバーしており、正式な文書記録、複雑な文節構造、学術的な談話接続詞、微妙な様相表現に重点を置いています。 

## 1. 正式な接続詞

 ### 1.1 因果関係と結果 (正式)

 | パターン | 登録 | 例 | 英語 |
 |-----------|----------|-----------|-----------|
 | したがって | フォーマル | | 市は不定であるため、投球者は慎みます。 市場は不安定です。 したがって、投資家は慎重です。 |
 | | 書かれた | | 効率が向上し、コストが削減されます。 効率が向上し、コストが削減されます。 |
 | 致致/致使 | 書かれた | 管理が不適切なため、目が失われます。 不適切な管理がプロジェクトの失敗につながりました。 |
 | です | ニュートラルフォーマル | | 他は成功しました、その後承認されました。 彼は遅刻したので批判された。 |
 | 进而 | 書かれた | | 問題を理解し、解決策を見つけます。 問題を理解し、さらに解決策を見つけます。 |

 ### 1.2 譲歩 (正式)

 | パターン | 登録 | 例 | 英語 |
 |-----------|----------|-----------|-----------|
 | しっかり…しかし/しかし | フォーマル | しっかりするのは難しいですが、必要があります。 確かに困難はありますが、耐え忍ばなければなりません。 |
 | 诚然…然而 | 文学 | | このように、しかし、決して不可能です。 確かにその通りですが、一般化することはできません。 |
 | 貫管如此 | 書かれた | このようにしても、スケジュールは正常に実行されます。 それにもかかわらず、計画は通常通りに進行します。 |

 ### 1.3 コントラストとトランジション

 | パターン | 登録 | 例 | 英語 |
 |-----------|----------|-----------|-----------|
 | しかし | フォーマル | | とても良いですが、実行は困難です。 計画は良いです。 しかし、実行は困難です。 |
 | 反之 | 書かれた | | 努力は成功しましたが、反撃は失敗しました。 一生懸命働けば成功します。 逆に失敗します。 |
 | 反対 | ニュートラル | | 良いではなく、逆に、良いです。 改善されませんでした。 逆に悪くなりました。 |
 | そして | 口語形式 | | すでに完了しており、さらに雨が降っています。 もう遅いし、しかも雨が降っている。 |

 ## 2. 複雑な条件付き構造

 ### 2.1 仮説と事実に反する

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 假如/假设…就/那么 | | 有機的な会議のように、私たちは留学を去ります。 チャンスがあれば、留学したいです。 |
 | 倘若/倘使 (正式) | 倘若失败，当如何应对？ 失敗したらどう対応すればいいのでしょうか？ |
 | いつか…就/便 | 一度決定したら、そのままにしておく必要があります。 一度決めたら、粘り強く続けなければなりません。 |
 | さあ…就/也 | | どこかに失敗した、また不要な解放。 たとえ失敗しても、諦めないでください。 |

 ### 2.2 段階的な条件

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 即使…也 | | たとえさらに堅くても、堅持されなければなりません。 たとえそれが難しくても、それでも耐えなければなりません。 |
 | 哪怕…也 | | 雪も降るし、また出るだろう。 たとえ雪が降っても、私たちは出発しなければなりません。 |
 | 就算…也 | | 計算は完了しましたが、停止することもできません。 疲れても止まらない。 |

 ## 3. 高度な様相表現と認識論的表現

 ### 3.1 可能性と確実性

 | 式 | 登録 | 意味 | 例 |
 |-----------|----------|-----------|-----------|
 | 必須ではありません | フォーマル | 必ずしもそうではない | 彼は必ずしも知っているわけではありません。 |
 | 势必 | フォーマル | 必然的に | これは必然的に結果に影響を与えます。 |
 | 必ず | 書かれた | きっと | 努力は必ず報われる。 |
 | 理应 | フォーマル | そうすべきです、当然そうすべきです 正当に報われるべきである。 |
 | 难免 | ニュートラル | 避けられない、| に束縛される 間違いを犯すことは避けられません。 |

 ### 3.2 主観的評価の副詞

 | 式 | 意味 | 例 |
 |-----------|-----------|----------|
 | 似乎/仿佛 | まるで | 彼は不幸のようです。 |
 | 显然 | 明らかに | これは明らかに間違っています。 |
 | 明显 | 明らかに/明らかに | 明らかに改善がありました。 |
 | 大概/约 | およそ / おそらく | おそらく 3 日かかります。 |
 | 究竟 | 結局のところ / まさに | 究竟是谁？一体誰ですか？ |

 ## 4. 形式的否定パターン

 ### 4.1 不在/不在（形式的）

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 毫無 + N | 毫無疑问 | 間違いなく |
 | 毫不 + V | 毫不犹豫 | 迷わず |
 | 绝非 | これはあまり好みではありません。 これは決して偶然ではありません。 |
 | 并非 | | 問題はありますが、このようには単一ではありません。 問題は決して単純ではありません。 |
 | 非但/不但不…反而 | それでも改善されず、逆にさらに悪化します。 改善しないどころか悪化してしまいました。 |

 ## 5. 関係節と名詞化

 ### 5.1 をノミナライザーとして使用

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | V + 的 → 名詞 | | 来るべき是我朋友。 来たのは私の友達です。 |
 | Adj + 的 → 名詞 | | 良い要多学䠠。 優秀な学生はもっと勉強すべきです。 |
 | 句 + 的 → 名詞 | | 私が言う都は真です。 私が言ったことはすべて本当です。 |

 ### 5.2 所 + V (正式な関係節マーカー)

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 所 + V + 的 + N | 他所の话 | 彼が言った言葉 |
 | 所 + V + 的 + N | 我们所面临的挑戦战 | 私たちが直面する課題 |
 | 所+V | それぞれ全力。 それぞれが全力を尽くします。 (文字通り、それぞれができることを発揮します) |

 ## 6. 受動的構造 (正式)

 ### 6.1 正式な文脈に含まれる

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 被 + V + である/作 | 最高と誉められます。 最高と絶賛されました。 |
 | 被迫 + V | | 条件が課せられています。 条件を受け入れることを強制されました。 |

 | 遭到/遭受 + N | | 反撃に遭いました。 反対に遭った。 |

 ## 7. 程度と範囲の表現

 ### 7.1 程度副詞 (程度副詞)

 | 副詞 | 意味 | 例 |
 |----------|-----------|----------|
 | 相当 | かなり、かなり | かなり重要 かなり重要 |
 | 颇 | かなり、かなり（文学的） | 颇有成效 非常に効果的です。 
| 格外 | 特に、特に | 格外重要 特に重要 |
 | 尤です/尤其 | 特に、特に | 特に重要です。 
| 极其 | 非常に | 非常に複雑です。 
| 十分 | とても、完全に | 十分満足です |

 ### 7.2 范围副词 (範囲副詞)

 | 副詞 | 意味 | 例 |
 |----------|-----------|----------|

 | 皆 | すべて（文学） | 皆大欢喜。 |

 | 一概 | 例外なく | 例外なくどれも受け入れません。 |
 | 一律 | 一様に、すべて同じように | 一律規定処理。 すべて規定に従って処理します。 |

 ## 8. 高度な側面と時間的パターン

 ### 8.1 複雑な構造における 了

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | V1 + λ + V2 (シーケンシャル) | | もう一度去ります。 まず食べてから行きましょう。 |
 | V + 了 + 数字 + 之後 | | 等了三時間後才来。 3時間待ってやっと来ました。 |

 ### 8.2 将 (jiāng) — 正式な未来

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 将 + V | | 会議は明白に行われる予定です。 会議は明日開催されます。 |
 | 将要 + V | 工程これから要竣工。 プロジェクトはもうすぐ完了します。 |
 | 即将 + V | | 結果をすぐに公開します。 結果はもうすぐ発表されます。 |

 ### 8.3 正值/ぴったり — ちょうどそのとき、ちょうど

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 正值 + N | 正值国庆节期 | 国慶節休暇中 |

 ## 9. 形式的な談話マーカー

 ### 9.1 テキスト整理マーカー

 | マーカー | 機能 | 例 |
 |----------|----------|----------|
 | 最初…その次…最後 | リストの順序 | | 最初に分析し、次に検証し、最後に終了します。 
| 一方…另一方 | 両面 | 一方面要…另一方面も要… |
 | 就…言 | |に関しては 教育的言論、政策改革が必要。 
| 综上記載 | 要約すると | | 上で述べたように、この項目は実行可能です。 
| こちらからご覧いただけます | これからわか​​ります | これにより、問題の場所がわかります。 
| 换言之 | 言い換えれば | | 換言すれば、これは可能です。 

### 9.2 引用と帰属

 | パターン | 例 | 英語 |
 |----------|----------|----------|

 | これは、…认です | ここ、学界认… | これに関して、学者たちは次のように考えています… |

 ## 10. 修辞的および議論的な構造

 ### 10.1 譲歩と反論のパターン

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 诚然/堅然 + 譲歩，但/然然 + 反論 | 確かに改革には問題がありますが、改革の方が大きいわけではありません。 確かに改革にはリスクが伴いますが、改革をしないことにはより大きなリスクが伴います。 |

 ### 10.2 仮説の議論

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 试想/试问 | 试想，若無规则，社会将どう?| 想像してみてください。もしルールがなかったら、社会はどうなるでしょうか? |
 | 倘若如此 | このままでは、結果は予想通りです。 もしそうなら、その結果は想像するのが難しいでしょう。 |

 ### 10.3 反転による強調

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | 正是…才… | まさにこの精神で、才能は成功します。 まさにこの精神こそが彼を成功させたのだ。 |
 | 之所以…是故 | | それは準備不足のため失敗しました。 失敗の原因は準備不足でした。 |
