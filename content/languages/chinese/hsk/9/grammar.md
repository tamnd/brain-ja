HSK 9 は中国語習得の頂点、つまり C2+ / ネイティブに近い熟練度を表します。 このレベルでは、文法学習とは、古典中国語 (文言文 wényán wén) を完全に内面化すること、文学的および修辞的な散文を作成する能力、およびあらゆる音域の本物の操作を意味します。 このレベルの「文法ポイント」は、学ぶべきルールではなく、多読と制作を通して身につける深い構造です。 

## 1. 古典中国語 (文言文) の基本文法

 ### 1.1 古典的な文の構造

 古典中国語は大部分が SVO ですが、現代中国語よりもはるかに圧縮されています。 主な特徴:

 | 特集 | クラシック | 現代の同等物 |
 |----------|-----------|--------|
 | 個別の「である」はありません | この吾友也。 これは私たちの友人です。 
| 動詞と目的語の柔軟性 | 唯利是图 | 只追求利益 |
 | 裸の名詞 (測定語なし) | 有书三卷 | 有三本书 |
 | 暗黙的なサブジェクト | 问曰く (他)问道 |
 | クラシックネガ | 未/弗/非/莫/無 | 没有/不/不是/没人/没有 |

 ### 1.2 古典的な助詞の全文

 | 粒子 | 機能 | 古典的な例 | 翻訳 |
 |----------|-----------|------|---------------|
 | 之 | 所有格; 物体; SとVの間。 ノミナライザー | 学之精髓 / 吾之见 | 学びの本質／私の考え |
 | 乎 | 質問; 前置詞 (= から); 文末の感嘆符 | 子は何乎と言いましたか？ マスターは何と言っていますか？ |
 | 者 | 名目指定子「誰が / どれが」 | 知者不安 | 知っている人には何の疑いもありません。 |
 | や | 文末肯定 | | 仁者、愛する人も。 仁とは人を愛することです。 |
 | や | 一連; 逆境; 意味 | 学而時习之 | 学んで繰り返し練習しましょう。 |
 | わたし | 手段; 原因; 目的 | 以德服人 | 美徳によって説得する。 |
 | |から で; で; よりも; | によって 忧患から生まれた | 悩みと苦しみの中で生まれました。 |
 | それ | 3人目。 実証的な; 修辞的 | それは人也 | あの人 (= 彼/彼女) |
 | である | あること; すること; |のための 己所不欲、勿体ない人 | — |
 | 乃 | したがって; になる | ここ乃要害が存在します。 まさにこれが重要なポイントです。 |
 | 则 | それから; コントラスト | 知之则行之 | それを知ってから、それに基づいて行動します。 |
 | そして | さらに; 当分の間 | 姑そしてこんな | とりあえずこのままにしておきます。 |
 | れん | そこで; そこには; 文末 | | 积土成山、风雨兴然。 土を山に積み上げると、そこから風と雨が発生します。 |
 | 所 | それはどれか。 次の動詞を名詞化します | 所言 / 所為 | (1 人) が言うこと / (1 人) がすること |
 | 何 | 何; どうやって; なぜ | 何得之?| どのような手段で入手できるのでしょうか？ |

 ### 1.3 古典的な負の粒子

 | 粒子 | 使い方 | 例 | 英語 |
 |----------|----------|----------|----------|
 | 未 | まだ/していない | 未能如愿 | 願いは叶いませんでした |
 | 弗 | しません (古風な) | 学而弗思 | 学ぶが考えない |
 | 非 | | ではありません / ではありません 非我族类 | 私たちの種類ではありません |
 | 莫 | 誰も; 何もない; なし | 莫能胜之 | 誰もそれに勝つことはできません。 
| 毋 | しないでください (古風な不要) | 毋须多言 | 多くの言葉は必要ありません |
 | 罔 | それなし; ネット | 学為不思则罔 | 何も考えずに学ぶと道に迷ってしまいます |

 ## 2. 文学的な散文の構造

 ### 2.1 骈文 (Piánwén) — 並列散文

 古典的な並列散文では、厳密に計測された対句、音調のバランス、および意味の並列性が使用されます。 

| ペア | 例 | メモ |
 |------|-------|------|
 | 4+4 | | 落霞と孤霰风、秋水は同じ長さの色。 王波「滕王閣序文」 |
 | 4+4 | | 穷と益坚、不坠青云之志。 貧困はあるものの、より堅固であり、野心は捨てられていません。 |
 | 6+6 | | 渔舟唱晚、响穷彭衡之滨；雁阵寒寒、音断阳之浦。 拡張並列対句 |

 ### 2.2 散文 (SĎnwén) — 古典散文談話マーカー

 | マーカー | 機能 | 例 |
 |----------|----------|----------|
 | 夫（ふ） | 談話冒頭「さて、では…」 | (戦いは勇気の問題です。)
 | 盖 (ガイ) | "それは (おそらく) なぜなら…" | (おそらくこれのためです。)
 | 故 (グー) | したがって (正式) | 故曰く… (だから言われる…) |
 | 然 | しかし、その場合 / その場合 | 然则何以处之?(その場合、どう対処しますか?)
 | まで | （書面による談話で）については (残りについては、詳しく説明する必要はありません。) |

 ### 2.3 古典的な引用フレーム

 | フレーム | 例 | 英語 |
 |----------|-----------|----------|
 | 子曰く 子曰く：「学ならず思戙罔。」 師は、「何も考えずに学ぶことは、労力を無駄にすることだ」と言いました。 |
 | …と言う | 孟子の言う / 庄子の言う | 孟子は言った / 荘子は言った |
 | 有言実行 | 有言実行：「天下無难事、只怕有心人。」 「決意を持った人にとって、この世で難しすぎるものはない」と言われています。 |

 ## 3. オーラルディフェンスの習得

 ### 3.1 学術的な口頭防御パターン (答辩)

 | 機能 | パターン | 例 |
 |----------|-----------|----------|
 | 質問を了承します | 感谢您提出这一问题 | 感覚的には、これには価値のある問題があると考えられます。 
| 質問を再度述べます | 您の问問題に関係するのは… | この問題は、本明細書に記載されているコア設定に関係している。 
| 直接答える | 我的回答是… / 对此，我认 | これについては、以下の 2 つの観点から理解できると考えています。 
| 制限を認識する | 正に您が指摘するように、本研究は存在します。 指摘されているように、この研究にはサンプル量に関する限界が存在する。 
| 今後の取り組みを示す | これは、今後の研究で注目を集める方向です。 これはまさに、深層探査を実現するための将来の研究の方向性です。 

### 3.2 口頭発表における修辞的動き

 | 移動 | 中国語マーカー | 例 |
 |-----|-----|----------|
 | 聴衆を魅了する | 请大家思考这样一个问题 | 请大家思考：何… |
 | 構造を発表 | 我将以下三方展开 | | 私たちは、プロセス、方法、および経路の 3 つの側面から展開していきます。 
| 信号遷移 | 次下来 / 下我将探讨 | 次に、実際のデータを見てみましょう。 
| 重要なポイントを強調する | 特に注目すべき点は | 特に注目を集めているのは、この例外的な状況です。 
| 結論と招待 | 以上です…欢迎批评指正 | 以上は我の告発、欢迎批判指示正。

 ## 4. 間テクスト性と暗示

 HSK 9 では、典故 (diƎngù、古典的な暗喩) を流暢に使用することで、教育を受けたネイティブ レベルの表現を示します。 

### 4.1 現代文でよく使われる暗示

 | 暗示 | 由来 | 現代の意味/用法 |
 |----------|----------|--------|
 | 卧薪尝胆 | 越王勾稽古 | 将来の目標のために困難に耐える |
 | 塞翁失马 | 《淮南子》 | 挫折は姿を変えた祝福かもしれない |
 | 班门弄斧 | 鲁班传说 | 専門家の前でスキルを披露 |
 | 破釜沉舟 项羽 | 背水の陣をしく; オールインする |
 | 纸上谈兵 | 赵括 | 実際の経験なしに理論を立てる |
 | 一鸣惊人 | 楚庄王 | 突然の目覚ましい成果でみんなを驚かせる |

 ### 4.2 現代散文における暗示の使用

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 正所谓… | 正所谓「塞翁失马、延知非福」。 ことわざにあるように、「老人が馬を失ったとき、それが祝福でなかったことがどうしてわかるでしょうか？」 |
 | 犹如… | その行事は破砕舟のようなものです。 彼のアプローチはボートを燃やすようなものだ。 |
 | 耐えられない… | | これは耐えられない称号班门弄斧。 この技は名人の前で披露したともいえる。 |

 ## 5. 完全なレジスタ マトリックス

 HSK 9 では、学習者は完全なレジスタ マトリックスを制御し、意図的にシフトすることができます。 

| 寸法 | 口語 | 正式な書面 | クラシック |
 |----------|---------------|-----|----------|
 | 「私」 | 私 | 本人/笔者 | 吾/余/予 |
 | 「あなた」 | 你 | 您/阁下 | 汝/尔/君 |
 | 「彼/彼女」 | 他/她 | 该人士/当事人 | 彼/彼ら |
 | 「これ」 | これ | 此/该 | ここ/し |
 | 「言うこと」 | 说 | 表示/称 | 言う/云 |
 | 「だから」 | 理由 | から/から | 盖/以 |
 | "したがって" | 所以 | したがって/故故 | 故/是故 |

 ## 6. 主要なパターンのまとめ

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 知之者不如好之者 | — | それを知っている人も、それを愛する人ほど優れているわけではありません。 |
 | 学為不思则罔 | — | 何も考えずに学ぶのは労力の無駄です。 |
 | 正所谓… | 正所谓「功自然成」。 正しく言われているように、「十分に努力すれば、それは自然に得られるでしょう」。 |
 | 本研究…展开系统分析 | — | この研究は、…の体系的な分析を行うことを目的としています。 
| 一定程度上/就目前言 | — | ある程度まで / 現在の証拠に関する限り |
 | 不足/無し | | 不用なサービスはありません。 例外なく、全員が感嘆の声を上げた。 |
