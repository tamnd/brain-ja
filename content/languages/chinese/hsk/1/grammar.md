HSK 1 文法は、基本的なコミュニケーションに必要な約 66 の核となるパターンをカバーしています。 これらはすべての中国語文の構成要素です。 

## 1. 基本的な文構造

 ### 1.1 主語-動詞-目的語 (SVO) — デフォルトの語順

 中国語は、主語 + 動詞 + 目的語の厳密な順序に従います。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | S + V + O | |私吃米饭。 ご飯を食べます。 |
 | S + V + O | | 見てください。 彼女は本を読みます。 |
 | S + V + O | 他学习中文。 彼らは中国語を勉強しています。 |

 ### 1.2 動詞 是 (shi) — 「であること」

 名詞と名詞句を同一視するために使用されます。 **形容詞と一緒に使用しないでください** (代わりに「很」を使用してください)。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | N + あれ + N | 私は学生です。| 私は学生です。 |
 | N + あれ + N | |她は老师です。 彼女は教師です。 |
 | N + 不是 + N | 他は医師ではありません。 彼は医者ではありません。 |

 > **重要:** 「私は良いです」を ~~我是好~~ とは言わないでください。 代わりに「我很好」を使用してください。 

### 1.3 動詞「有」 (yƒu) — 「To Have」および「There Is/Are」

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | S + 有 + N | 私は一本书を持っています。 本を持っています。 |
 | S + 有 + N | 他には子が 2 つあります。 彼には 2 人の子供がいます。 |
 | 場所+有+N | | 桌子上に有ります。 テーブルの上に本があります。 |
 | S + なし + N | |私には钱がありません。 お金がありません。 |

 ### 1.4 形容詞述語文

 形容詞は述語として機能します。 「很」を使用します（強調していない場合でも、構造的に必要です）。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | S + 很 + Adj | 他は高い。 彼は背が高いです。 |
 | S + 很 + Adj | 今天很冷。 今日は寒いです。 |
 | S + 不 + Adj | これは良くありません。 これは良くありません。 |

 ## 2. 質問の形成

 ### 2.1 吗 (ma) を含むはい/いいえの質問

 はい/いいえの質問を形成するには、ステートメントの最後に「吗」を追加します。 

| 声明 | 質問 | 英語 |
 |----------|-----------|----------|
 | |你は学生です。 |你是学生吗?| あなたは学生ですか？ |
 | 他吃了。 他吃了吗?| 彼は食べましたか？ |
 | 天気好。 天气好吗?| 天気は良いですか？ |

 ### 2.2 A ではない質問

 動詞を肯定形と否定形で繰り返します。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | V + 不 + V | 你去不去?| 行きますか？行きませんか？ |
 | 是不是 | 彼は学生ではありませんか?| 彼は学生ですか（それともそうではありませんか）？ |
 | なし | | 你有無し時間?| 時間はありますか？ |

 ### 2.3 疑問詞 (疑问词 yíwèncí)

 | 単語 | ピンイン | 意味 | 例 | 英語 |
 |------|--------|-----------|-----------|---------|
 | 何か | シェンメ | 何を | これは何ですか? | これは何ですか？ |
 | 谁 | シェイ | 誰 | 他は谁ですか？ 彼は誰ですか？ |
 | 哪 | な | どの | 你は哪国人ですか？ あなたはどこの国から来たのですか？ |
 | 哪儿/哪里 | ナル / ナル | ここで | 你去哪儿？ どこに行くの？ |
 | 几 | 吉 | 何個 (≤10) | 你有几本书?| 何冊本を持っていますか？ |
 | いくら | ドゥオシャオ | どれくらい/いくら | どのくらい钱?| お金はいくらですか？ |
 | 怎么 | ゼンメ | どのように/なぜ | | 怎么去?| どうやって行きますか？ |
 | 怎么样 | ゼンメイヤン | どうですか | 你怎么样?| 元気ですか？ |
 | 何か | ウェイシェンメ | なぜ | | 你何何么学中文?| なぜ中国語を勉強するのですか？ |
 | いつか天気 | シェンメシホウ | いつ | | 你什么候来ますか？ いつ来ますか？ |

 ### 2.4 呢 (ne) を使って質問を和らげる

 「…はどうですか？」と尋ねるのによく使われます。 または会話の話題を続けます。 

| 例 | 英語 |
 |----------|----------|
 | 我很好、你呢?| 私は元気です、あなたは？ |
 | これ?| これはどうでしょうか？ |

 ## 3. 否定

 ### 3.1 不 (bù) — 動詞と形容詞の否定

 | 使い方 | 例 | 英語 |
 |----------|-----------|----------|
 | 動詞の否定 | 私は去りません。 行かないよ。 |
 | 形容詞を否定する | 天気は良くありません。 天気が良くありません。 |
 | 否定です | 他は老师ではありません。 彼は教師ではありません。 |
 | Negate 想/喜欢 | | 私は不喜欢。 私はそれが気に入りません。 |

 > **音調の変更:** 「不」は第 4 音 (bù) ですが、次の第 4 音の前に第 2 音 (bú) に変わります: 不是 (bú shì)、不要 (bú yào)。 

### 3.2 没 (méiyƒu) / 没 (méi) — 有と完了したアクションの否定

 | 使い方 | 例 | 英語 |
 |----------|-----------|----------|
 | 否定有 | |私には钱がありません。 お金がありません。 |
 | 完了したアクションを無効にする | | 私はいません。 私は（まだ）食べていません。 |
 | 過去の出来事を否定する | 他には来ません。 彼は来ませんでした。 |

 > **ルール:** 過去時制/完了したアクションには没を使用します。 習慣的な否定や将来の計画には「不」を使用します。 
> - 我不吃肉。= 私は肉を食べません（習慣）。 
> - 我没吃肉。= (今回は) 肉を食べませんでした。 

## 4. 構造粒子的 (de)

 ### 4.1 所有 (名詞/代名詞 + 的 + 名詞)

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | 代名詞 + 的 + N | 私的书 | 私の本 |
 | N + 的 + N | 老师的书 | 先生の本 |
 | 名前 + 的 + N | 王红のハンドマシン | 王紅の電話 |

 ### 4.2 名詞句の修飾 (形容詞/動詞句 + 的 + N)

 | 例 | 英語 |
 |----------|----------|
 | 好天气 | 良い天気 |
 | 聪明的学生 | 賢い学生 |

 > **ショートカット:** 親密な関係の前では、「我的」を「我」に短縮できます。 
> - 我妈妈 (私のお母さん)、我朋友 (私の友達)

 ## 5. アスペクト助詞 了 (le)

 ### 5.1 完了したアクション (動詞 + 了)

 | 例 | 英語 |
 |----------|----------|
 | |私は完了しました。 食べました。 /食べました。 |
 | 他来了。 彼は来ました。 / 彼は到着しました。 |
 | 私は一本书を獲得しました。 本を買いました。 |

 ### 5.2 状態の変化 (文 + 了)

 | 例 | 英語 |
 |----------|----------|
 | 他来了。 彼は（来ました）。 (= 彼は今ここにいます) |
 | 春天了。 春がやって来ました。 |
 | |私は完了しました。 今ならわかります。 |

 ## 6. 数字とメジャーワード

 ### 6.1 数値 + メジャーワード + 名詞の構造

 中国語では、数字と名詞の間には必ず計量語（量词）が必要です。 

| 数値 + MW + 名詞 | ピンイン | 英語 |
 |--------|--------|----------|
 | 一人 | 一月仁 | 1人 |
 | 两本书 | 梁本秀 | 2冊 |
 | 三杯の水 | 三北水 | 水3杯 |
 | 四张纸 | 四長志 | 4枚の紙 |

 ### 6.2 一般的なメジャーワード

 | MW | ピンイン | 用途 | 例 |
 |----|--------|----------|----------|
 | 个 | ゲ | 一般（人、物） | リンゴ一個
 | 本 | ベン | 本、巻 | 一本书 1冊 |
 | 张 | 張 | 平らな物体 | 一张票 チケット 1 枚 |
 | カップ | 北 | カップ | 一杯のお茶 | 一杯のお茶
 | 件 | 建 | 服装、事柄 | 一件事 |
 | 只 | 志 | 動物 | 一只猫 一匹の猫 |
 | 条 | ティアオ | 長い柔軟な物体 | 一条鱼 一匹の魚 |
 | 块 | 快 | 断片。 元 (非公式) | 五块钱 5 元 |
 | 口 | くう | 家族 | 三口人三人家族 |

 ### 6.3 2 対 2 — 2 対 2

 | 二（えー） | 两 (liàn​​g) |
 |----------|----------|
 | 数え方: 一二三 | メジャー前の単語: 两个人 |
 | 序数: 2 | 時間の表現: 两点 |
 | 数学: 二加二 | お金: 两块钱 |

 ## 7. 時間の表現

 ### 7.1 時節は動詞の前に来ます

 中国語では、時間の表現は常に動作の前にあります (英語とは逆です)。 

| ✓ 正しい | ✗ 不正解 |
 |----------|---------------|
 | (明日行きます。) ~~私去明天。~~ |
 | (彼は昨日来ました。) ~~他来了昨天。~~ |

 ### 7.2 時間を知る

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | Nポイント | 三点 | 3時 |
 | N点N分 | 三点二十分 | 3:20 |
 | N点半 | 三点半 | 3:30 |
 | N点一刻 | 三点一刻 | 3:15 (4分の1) |
 | 差分点 | 差五分三点 | 2:55 (5 対 3) |

 ### 7.3 日付形式 (年→月→日→時刻)

 中国の日付は、最大単位から最小単位へと進みます。 
- 2026年5月30日下午三点 = 2026年5月30日、午後3時

 ## 8. 位置表現
