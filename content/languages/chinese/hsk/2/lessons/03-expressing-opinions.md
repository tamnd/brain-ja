## 概要

 自分の考えを表現することは、最も重要なコミュニケーション スキルの 1 つです。 中国語には意見を伝える方法がいくつかあります。口語では「觉得」（感じる、考える）が最も一般的ですが、「认為」（考える、信じる）はもう少しフォーマルです。 このレッスンでは、自然かつ敬意を持って他の人の意見に同意したり、反対したり、反応する方法についても説明します。 

## 学習目標

 - 個人的な意見や感情を紹介するには「觉得」を使用します
 - もう少しフォーマルなステートメントでは「认」を使用します
 - 同意に同意し、不同意または我觉得不是这样に同意しません。 
- 正しさについてコメントするには「对」と「错」を使用します。

## 文法重視

 ### パターン 1: 我觉得 + 条項

 **構造:** 我觉得 + 主語 + 形容詞/動詞句

 「觉得」は個人的な感情や意見を紹介します。 カジュアルであり、中国語の話し言葉で広く使用されています。 「觉得」以降の条項の主語は、主語と同じでも異なっていても構いません。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 私たちはこの電気効果をよく見ました。 Wƒ juéde zhège diànyƐng hěn hàkàn。 | この映画は素晴らしいと思います。 |
 | | 她觉得学中文不难。 Tā juéde xué Zhōngwén bù nán。 | 彼女は中国語を学ぶのは難しくないと考えています。 |
 | | 私は得ました。 Wƒ juéde nƐ shuō de duì。 | あなたが言ったことは正しいと思います。 |
 | | 你觉得これ主意怎么样?| どういうことですか? | このアイデアについてどう思いますか? |

 **よくある間違い:** 名詞オブジェクトで「觉得」を直接使用しないでください。 述語なしでは「我觉得这个电影」とは言えません。 「觉得」の後には常に完全な句を続けます。 

### パターン 2: 我认である + 節

 **構造:** 我认 + 主語 + 動詞/形容詞句

 「认得」は「觉得」よりもフォーマルです。 これは、ディスカッションや文章の中で、より強く、より検討された意見を主張したいときに使用されます。 通常、感情的な反応には使用されません。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 私たちはこの方法には反対だと考えています。 我仁為zhège fāngfƎ bù duì。 | このアプローチは間違っていると思います。 |
 | 他の人はこれが初期の成果であると考えています。 Tārènwei yīnggāi zƎo diƎn chufā。 | 彼は私たちがもっと早く出発すべきだと思っている。 |
 | 私たちは努力よりも重要だと考えています。 我仁威那力吞天府庚忠行。 | 私は才能よりも努力が大切だと信じています。 |

 **よくある間違い:** 「认」と「认识」（人を知る/認識する）を混同しないでください。 それらは似ていますが、意味は大きく異なります。 

### パターン 3: 同意と不同意

 **構造:**
 - 同意: 我同意 / 你说得对 / 有道理
 - 同意しない: 我不同意 / 我觉得不是这样 / ただし是...

 | 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 私は完全に同意します。 Wànquán tóngyì nƐ de kànfƎ。 | 私もあなたの意見に完全に同意します。 |
 | | 私は同意しません、その状況は不一致です。 Wƒ bù tóngyì、qíshí qíngkuàng bù yīyàng。 | 私は同意しません; 実際には状況が異なります。 |
 | これは合理的ですが、私たちはさらに別の方法を見つけました。 NĐ shuō de yƒu dàolƐ、dànshì wƒ juéde hái​​ yóiu bié de fāngfƎ。 | おっしゃることはもっともですが、他の方法もあると思います。 |

 ## 対話

 **A:** 你觉得我们应该坐地铁还是打车去机场？ 
**NƐ juéde wômen Yīnggāi zuò dìtiě Háishì diqhē Qù jīchƎng?**
 *空港までは地下鉄とタクシーどちらを利用したほうが良いと思いますか?*

 **B:** 私たちは、車のロックの代わりに、より便利だと考えています。 
**Wōrènwei zuò dìtiě gèng hào。 Piányí、erqiě bù dóchē.**
 ※地下鉄の方が良いと思います。 安くて渋滞もありません*。 

**A:** ただし、ローカルは 2 回変更される必要があります。 
**Dànshì dìtiě yào zhuƎn liƎng cì, hěn máfan.**
 ※でも地下鉄は乗り換えが2回必要なので面倒です※

**B:** 許可を取得します。李多数の指示を実行しないでください。 
**NƐ shuō de yƒu dàolĐ。 Búguò XínglĐ duō de hua, dìtiě quèshí bù fāngbiàn.**
 *それは理にかなっています。 でも荷物が多いと地下鉄は本当に不便です*。 

**A:** そのため、車両の交換に適していると考えております。 
**SuƒyƐ wƒ rènwei dƎchē gèng héshì.**
 *したがって、タクシーを利用する方が適していると思います。*

 **B:** いいですね、同意します。打车吧！ 
**ハオ、ウォトンジー。 だちば!**
 *わかりました、同意します。 タクシーに乗りましょう!*

 ## 練習する

 ### 演習 1: 空白を埋める

 各文を完了するには、「觉得」、「认是」、「同意」、または「不同意」を使用します。 

1. 我 ______ 今天的考察不难。(今日の試験は難しくなかったと思います。)
 2. 老师 ______ 学生应该多练习。(教師は学生がもっと練習するべきだと信じています。)
 3. 私は完全に ______ 你的意見。(私はあなたの意見に完全に同意します。)
 4. 彼はこの計画に同意しません。なぜなら、それは高すぎるからです。 
5. 你 ______ 这个电影怎么样?(この映画についてどう思いますか?)

 ### 演習 2: 中国語に翻訳する

 1. 中国語を学ぶのはとても面白いと思います。 
2. 彼女はこの方法が間違っていると信じています。 
3. あなたが言ったことは理にかなっていますが、私は違う意見を持っています。 
4. この計画に同意しますか?

 ### 演習 3: 中国語で答えてください

 1. 你觉得现在学中文难吗？ 
2. 你认是周末应该工作还是休息?(週末は働くべきだと思いますか、それとも休むべきだと思いますか?)
 3. 如果朋友的想法是错的，你会直接说吗？（友人の考えが間違っている場合、あなたは直接そう言いますか？）

 ## 文化的なメモ

 中国人のコミュニケーション、特にグループ環境では、意見の相違を直接表現すると唐突に感じられることがあります。 一般的な戦略は、対照的な意見を紹介する前に、まず「你说得有道理」（あなたの言ったことは理にかなっています）または「我理解你的意思」（あなたの言いたいことは理解しています）で相手の主張を認めることです。 これは不誠実ではありません。 それは、自分の立場を維持しながら、関係に敬意を示す方法です。 正式な会議では、「我有異的看法」（私は異なる見解を持っています）というフレーズは、気まずい思いをさせずに意見を異にするための洗練された方法です。
