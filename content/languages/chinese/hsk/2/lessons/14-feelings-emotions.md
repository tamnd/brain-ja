## 概要

 自分の気持ちを表現し、他の人の気持ちを理解することは、真のコミュニケーションの基礎です。 中国語には豊富な感情語があり、このレッスンでは個人の感情と状況によって引き起こされる感情の両方を表現するための重要な構造を説明します。 特に「感到」と「让我」のパターンは汎用性が高く、実際の会話の中で常に登場します。 

## 学習目標

 - 感到 + 感情という言葉を使って自分の気持ちを説明します
 - 感情の原因を説明するには、让我 + V/feel を使用します。 
- 楽しい、悲しいだけではないさまざまな感情を表現します
 - 原因と反応を「故...所為...」で説明します。

## 文法重視

 ### パターン 1: 感到 + 感情 / 状態

 **構造:** 主語 + 感到 + 形容詞/感情

 感到 (feel/sense) は、感じられた状態や感情を示します。 形容詞を直接使用するよりも、少しフォーマルで意図的な表現になります。 感情だけでなく身体的な感覚も表現できます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 私は非常に疲労を感じています。 ウーガンダオヘンピジュアン。 | とても疲れています。 |
 | | 彼は非常に期待を感じています。 ターガンダオヘンシーワン。 | 彼はとても残念に思っています。 |
 | | 私はある点を感じました。 Wƒ gƎndào ユウディアン ジンチャン。 | 少し緊張しています。 |
 | | 非常に興味深いと感じます。 Tā gĎndào fēicháng mānyì。 | 彼女はとても満足していると感じています。 |

 **よくある間違い:** 通常、正式な文書では「感到」の後に肯定形容詞の前に「很」が続くことはありませんが、スピーチでは「感到很高兴」は完全に自然です。 「感到」の後の形容詞を省略しないでください。 常に補数が必要です。 

### パターン 2: 让我 + 動詞/感情 (使役構造)

 **構造:** 主語/状況 + 让 + 私 + 感じ/動詞

 让 (ràng) は使役動詞で、「誰かに何かをさせる/させる/させる」です。 「我」と感情が続く場合、その感情の原因を表します。 主体は体験者ではなくきっかけです。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | このメッセージは非常に高いです。 Zhège xiāoxi ràng wóhěn gaoxing。 | このニュースは私にとってとてもうれしかったです。 |
 | 他の人の発言は非常に感動的です。 Tā de hua ràng wƒ gƎndào hěn gƎndòng。 | 彼が言ったことは本当に私を感動させました。 |
 | この件については私たちが心を担っています。 Zhè jiàn shìràng wōhěn dānxīn。 | この件はとても心配です。 |
 | | 失敗しました、私はさらに努力しました。 Shībài ràng wōgèng nólì le。 | 失敗のおかげでもっと頑張れるようになりました。 |

 **よくある間違い:** 让文の主語は原因であり、感情を感じている人ではありません。 「我让这个消息高兴」とは言わないでください。 正しい形式は原因を最初に置きます:这个消息让我高兴。 

### パターン 3: 因...所以... (なぜなら...したがって...)

 **構造:** 因 + 理由 + 所以 + 結果

 これは、感情的な反応を説明するための一般的な構造です。 原因は原因を紹介します。 結果を紹介します。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 考慮されていないため、非常に困難です。 Yīnwei kƎoshì méi guò、suƒyƐ tā hěn nánguò。 | 彼は試験に落ちたのでとても悲しんでいます。 |
 | | 我々は成功したので、私は興奮しています。 Yīnwei nƐ bāng le wƒ、suƒyƐ wƒ hěn gƎnjī。 | あなたが私を助けてくれたので、とても感謝しています。 |
 | | 天気がとても良いので、私たちの心もとても良いです。 Yīnwei tiānqì hěn hƎo、suƒyƐ wƒ xīnqíng yě hěn hƎo。 | 天気が良いので気分も良いです。 |

 **よくある間違い:** 文脈が非常に明確でない限り、原因と所以を両方とも存在せずに別々の節で使用しないでください。 中国語では通常、両方の単語が述べられます。 1 つを削除すると、文が不完全に感じられる可能性があります。 

＃＃ 対話

**A:** 今日は最高でしたか？ 
**NƐjīntiānzěnmele? Kàn qálái bù tài gāoxìng.**
 *今日は何かあったの？ あなたはあまり幸せそうには見えません。*

 **B:** 私は失望を感じています。今日の結果はあまり良くありませんでした。 
**Wƒ gƎndào yƒudiƎn shīwàng。 Jīntiān miànshì de jiéguƒ bù tài hao.**
 ※少し残念な気持ちになりました。 今日の面接はあまりうまくいきませんでした。*

 **A:** 真的吗？ 
** ジェンデマ? Fāshēng le shenme?**
 *本当ですか？ 何が起こったのですか？*

 **B:** あまりにも長かったので、あまり多くの質問はありませんでした。 
**Yīnwei wƒ tài jƐnzhāng le、suƒyƐ hěn duō wèntí méiyƒu dá hƎo.**
 ※緊張しすぎて、質問にうまく答えられないことが多かったです※

 **A:** は完了しました。最初の面でのテストは正常です。これはテストを通じて蓄積されたものです。 
**ビエナングォレ。 Dì yī cì miànshì jƐnzhāng hěn zhèngcháng。 ZhèràngnƐjīlěilejīngyàn.**
 *悲しまないでください。 初めての面接で緊張するのはごく普通のことです。 これにより、経験が得られました。*

 **B:** 了解しました。それから私は残念ながら事前の準備はありません。 
**NĐ shuō de duì。 Qíshí wƒ hòuhuƐ méiyƒu tíqián duō zhƔnbèi。 YƐhòu wƒ huì gèng rènzhēn.**
 *その通りです。 実はもっと事前に準備しておかなかったことを後悔しています。 次回はもっと詳しく説明します*。 

**A:** このような傾向に私は感銘を受けました。必ず成功しました。 
**Zhè zhƒng tàidu ràng wƒ hěn gƎndòng! Nīyīdìng huì chénggōng de.**
 *その姿勢は本当に感動します！ あなたは必ず成功します。*

 ## 練習する

 ### 演習 1: 空白を埋める

 1. 我 ______ 有点紧张，因為明天要考。(明日試験なので少し緊張しています。)
 2. 那部電影 ______ 我很感動、差哭了。(その映画は本当に感動しました。泣きそうになりました。)
 3. ______他帮了我很多，______ 我很感谢他。(彼は私をとても助けてくれたので、彼にとても感謝しています。)
 4. 听到你要来，我感到非常 ______! (あなたが来ると聞いて、とても嬉しいです!)
 5. 我 ______ 早点報告なし。(この件をもっと早く伝えなかったことを後悔しています。)

 ### 演習 2: 中国語に翻訳する

 1. 私は毎回試験の前にとても緊張します。 
2. 悪いニュースがあるといつも心配になります。 
3. 彼女は一生懸命働いたので、その結果に満足しています。 
4. その経験は私に深い感動を与え、今でも覚えています。 

### 演習 3: 中国語で答えてください

 1. 什么事情最让你高兴？（何があなたを一番幸せにしますか？）
 2. 你一般怎么处理紧张または担心的情绪？（緊張や心配の感情に普段どのように対処しますか？）
 3. 你有没後悔过一件事?可以说说吗?(何か後悔したことはありますか?それについて共有できますか?)

 ## 文化的なメモ

 中国文化は伝統的に、公共の場での感情の抑制を重視します。 怒り、悲しみ、さらには激しい喜びを強く表現することは、公式または職業上の場面では不適切であるか、自制心が欠如しているとみなされることがあります。 ただし、これは地域、世代、関係の親密さによって大きく異なります。 親しい友人や家族の間では、中国人は非常に表現力豊かです。 面子（顔）という概念が一因となっています。人前で目に見えて動揺すると、冷静さを失ったように感じられ、その人の社会的地位に影響を及ぼします。 これは中国人が強い感情を持っていないという意味ではありません。 単に、より個人的または間接的に表現される傾向があるだけです。
