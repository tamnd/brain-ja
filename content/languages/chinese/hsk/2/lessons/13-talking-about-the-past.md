## 概要

 中国語には、過去について話す 2 つの異なる方法があります。完了記号「了」 (レッスン 4 で説明) と経験記号「过 (guò)」です。 了が何かが起こったと言うところ、过は人生のある時点で何かを経験したと言う。 このレッスンでは、「前」と「以降」の対比である「过」、そして思い出や人生経験について話し合うための語彙に焦点を当てます。 

## 学習目標

 - ある時点で経験があったことを表現するには「过」を使用します
 - 过を「没有」で正しく否定します
 - 以前 (前/過去) と以後 (後/将来) を正確に対比します
 - 曾经と记得を使って自然に思い出について話し合う

## 文法重視

 ### パターン 1: V + 过 (経験的側面)

 **構造:** 主語 + 動詞 + 过 + (目的語)

 動詞の直後に置かれた「过」は、対象者が人生のある時点でその経験をしたことを示します。 時期は明記されていない。 焦点は、いつ起こったかという詳細ではなく、それが起こったかどうかにあります。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 私は中国を去ります。 Wà qù guò Zhōngguó。 | 私は中国に行ったことがあります。 |
 | 你吃过北京烤鸭吗?| NƐ chī guò Běijīng kàoyā ma? | 北京ダックを食べたことがありますか？ |
 | | 勉強のない日々。 Tā méiyƒu xué guò RìyƔ。 | 彼女は日本語を勉強したことがありません。 |
 | 私は以前那个城市に住んでいました。 ウー・イチアン・シュウ・グオ・ナ・ゲ・チェンシィ。 | 私はかつてその街に住んでいたことがあります。 |

 **よくある間違い:** 「过」と「了」を混同しないでください。 我去了中国は「中国に行った」（旅行を完了した）という意味です。 我去过中国は「中国に行ったことがある」（人生経験）という意味です。 違いはコンテキストにおいて重要です。 

### パターン 2: 以前 vs.以降

 **構造:**
 - (時間/出来事) + 以前 = (その時/出来事) より前、過去
 - (時間/出来事) + 以後 = (その時間/出来事) 後、将来

 どちらも文の先頭で単独で使用することも、時間参照に従うこともできます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 以前は私は不喜欢吃裣でした。 YƐqián wƒ bù xƐhuan chī là de。 | 昔は辛い食べ物があまり好きではありませんでした。 |
 | | 大学以前、私は来国しませんでした。 Dàxué yƐqián、wƒ cónglái méiyƒu chō guò guó。 | 大学に入るまで、私は海外に行ったことがありませんでした。 |
 | | 毕业後に打算した何をする?| BìyèyƐhòudísuànzuòshénme? | 卒業後は何をするつもりですか？ |
 | | その後、私は多国家旅行を去りたいと思います。 YƐhòu wƒ xiƎng qù hěn duō guójiā lóyóu。 | 将来、私は多くの国を旅行したいです。 |

 **よくある間違い:** 以前と前 (前、空間的に前) を混同しないでください。 以前は一時的なものだけです。 

### パターン 3: 曾经 + V (過去のある時点で 1 回)

 **構造:** 主語 + 曾经 + 動詞 + 过 + (目的語)

 「曾经」は、過去のある時点で何かが起こったことを強調する副詞で、多くの場合、懐かしい距離や重要性のニュアンスを伴います。 「过」と対になることが多いです。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 私は曾て那家公司で活動してきました。 呉清正在在家公司公祖国。 | 私はかつてその会社で働いていたことがあります。 |
 | 前曾经学钢琴。 Tā céngjīng xué guò gāngqín。 | 彼はかつてピアノを習っていた。 |
 | 私は曾经はとても良い友人です。 Wōmen céngjīng shì hěn hào de péngyou。 | 私たちはかつてとても良い友達でした。 |

 ## 対話

 **A:** 你去过哪国家？ 
**Nāqù guò nƎxiē guójiā?**
 *どこの国に行ったことがありますか?*

 **B:** 私は去日本、泰国にも越南があります。你呢？ 
**Wƒ qù guò Rìběn、Tàiguó hái yƒu Yuènán。 ない?**
 ※日本、タイ、ベトナムに行ったことがあります。 あなたはどうですか？*

**A:** 私はまた、国を出ていません。しかし、その後、私は去欧洲を計算しました。 
**Wōhái méiyƒu chu guò guó。 Dànshì yƐhòu wƒ dƎsuàn qù ouzhōu.**
 ※海外に行ったことはありません。 でも将来的にはヨーロッパに行く予定です*。 

**B:** 那你之前有没在过别的城市？ 
**Nà nƐ zhīqián yƒu méiyƒu zhù guò bié de chéngshì?**
 *別の都市に住んだことがありますか?*

 **A:** あります！私は以前西安住に三年間いました。中期の印象は深かったです。 
**ゆう！ 呉前在在西国三年。 Nà duàn shíjiān wƒ yìnxiàng hěn shēn.**
 *はい！ 私はかつて西安に3年間住んでいました。 その時代は私に深い印象を残しました。*

 **B:**以前の西安和现在变化大吗？ 
**YĐqián de Xī'ān hé xànzài biànhua dà ma?**
 *西安は以前と比べて大きく変わりましたか?*

 **A:** 変化は非常に大きいです。かつてここには路地しかなく、すでに存在していました。 
**ビアンフアヘンダー！ Céngjīng nàlƐ zhƐ yƒu jƐ tiáo lù、xiànzài yƐjīng yƒu dìtiě le.**
 *すごい！ かつては道路が数本しかありませんでした。 今ではすでに地下鉄が通っています*。 

## 練習する

 ### 演習 1: 空白を埋める

 过、前、以後、または曾经を使用します。 

1. 你吃 ______ 火锅吗?(鍋を食べたことがありますか?)
 2. ______ 我不喜欢喝咖啡、现在每天都喝。 (以前はコーヒーが好きではありませんでしたが、今は毎日飲んでいます。)
 3. 毕业 ______ 你打算什么?(卒業後は何をする予定ですか?)
 4. 她 ______ は名演者であり、その後転職しました。 (彼女はかつて女優でしたが、後にキャリアを変えました。)
 5. 我 ______ 见 ______ この么漂亮の場所。 

### 演習 2: 中国語に翻訳する

 1. 本格的な四川料理を食べたことがありますか?
 2. 北京に移る前、私は成都に住んでいました。 
3. 彼女はかつて医学を学んでいましたが、後に法律に転向しました。 
4. このプロジェクトを終えたら、休暇を取る予定です。 

### 演習 3: 中国語で答えてください

 1. 你去过哪これら地方旅游?(どこへ旅行したことがありますか?)
 2. 你前学过その他语言吗?(過去に他の言語を勉強したことがありますか?)
 3. 你最忘れの一回经历は何ですか?(あなたの最も忘れられない経験は何ですか?)

 ## 文化的なメモ

 中国人はよく、「以前」と「现在」（以前と今）の対比を使って、人生の大きな変化を振り返ります。 これは、中国の急速な発展について議論するときに特によく見られます。 古い世代は故郷がどのように変わったかについて頻繁に話し、しばしば「以前这里什么都没有」（ここには何もなかった）のようなフレーズを使用し、その後に現在の繁栄について説明します。 このコントラストは、中国の経済開放と都市化を経験した人々にとって感情的な重みを持ち、それを理解することは、学習者がより深く、より個人的なレベルで中国語話者とつながるのに役立ちます。
