## 概要

 比較は日常会話の中心です。 中国語では、比較する主な方法が 3 つあります。「比」を使用して何かが他のものより大きいと言い、「没有」を使用して他のものよりも劣っていると言い、一样 (yīyàng) を使用して 2 つのものが同じであると言います。 3 つすべてをマスターすれば、最初から柔軟で自然な表現が可能になります。 

## 学習目標

 - 直接比較するには、A比B + 形容詞を使用します
 - 何かが品質に欠けていることを表現するには「没有」を使用します。 
- 一样と不一样を使用して類似点と相違点を表現します
 - 比の直後に More を挿入するという一般的なエラーを回避します。

## 文法重視

 ### パターン 1: A + 比 + B + 形容詞

 **構造:** 主語 A + 比 + 主語 B + 形容詞

 これが核となる比較パターンです。 形容詞は両方の主語が導入された後、最後に来ます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 私は他より高いです。 五百高。 | 私は彼より背が高いです。 |
 | 今天比昨天寒い。 ジンティアン・バイ・ズオティアン・レン。 | 今日は昨日より寒いです。 |
 | | 果樹は香料よりも高価です。 Píngguà bí xiāngjiāo guì。 | リンゴはバナナよりも高価です。 |
 | | 火車比公共自動車快。 HuĒchē bǐ gōnggòng qìchē kuài。 | 電車はバスより早いです。 |

 **よくある間違い:** 「我比他もっと高い」とは言わないでください。 「もっと」という単語はすでに比較を暗示しているため、「比」の後にこの単語を使用するのは冗長であり、正しくありません。 「我比他高」とだけ言ってください。 

### パターン 2: A + 無し + B + 形容詞

 **構造:** 主語 A + 没有 + 主語 B + 形容詞

 このパターンは、A が B のレベルに達していないことを表します。 「AはBほど[形容詞]ではない」と考えてください。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 私には他に高いものはありません。 五美勇太高。 | 私は彼ほど背が高くありません。 |
 | ここには北京の寒さはありません。 ZhèlƐ méiyƒu Běijīng lěng。 | ここは北京ほど寒くない。 |
 | 地铁には税金が出ていません。 ディティエ・メイユ・チューズ・チェ・クァイ。 | 地下鉄はタクシーほど速くありません。 |

 **よくある間違い:** ここで「不」を使用して否定しないでください。 私不有他高は間違っています。 正しい形式は「不有」ではなく「没有」です。 

### パターン 3: A + 跟 + B + 一样 / 不一样

 **構造:** A + 跟 + B + 一样 + (形容詞)

 2 つのものが何らかの性質において同じであると言うには、「一样」を使用します。 異なると言うには、一样の前に「不」を付けます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 私は他に一样高い。 Wō gēn tā yīyàng gao。 | 私は彼と同じ身長です。 |
 | この二つのアイテムは衣服が違います。 Zhè liƎng jiàn yīfu bù yīyàng。 | この２つの服は違います。 |
 | | 你跟我想法一样。 NƐ gēn wƒ xiƎngfƎ yīyàng。 | あなたの考えは私と同じです。 |

 ## 対話

 **A:** 你觉得哪个城市更好？北京还是上海？ 
**NƐ juéde nƎge chéngshì gèng hƎo? 北京海士上海?**
 *どの都市が良いと思いますか? 北京か上海?*

 **B:** 上海比北京有意思。 
**Wƒ juéde ShànghƎi bƐ Běijīng yƒuyìsi.**
 *私は北京よりも上海の方が面白いと思います。*

 **A:** 真的吗？私は北京の历史比上海長を獲得しました。 
** ジェンデマ? Wƒ juéde Běijīng de lìshƐ bƐ ShànghĎi cháng.**
 *本当ですか？ 北京は上海よりも歴史が長いと思います*。 

**B:** 对、これに同意します。 
**Duì、zhè yīdiiqn wƒ tóngyì。 Nà ni juéde nƎge chéngshiì xiāofei gèng gao?**
 *確かに、私もそれに同意します。 それで、どの都市の生活費が高いと思いますか?*

 **A:** 上海の消費には北京費は含まれていません。 
**ShànghƎi de xiāofèi méiyƒu Běijīng guì, wà juéde.**
 *上海の生活費は北京ほど高くないと思います。*

 **B:** 哈哈，我们的想法不一样！ 
**ははは、女性は元気です!**
 *ははは、私たちの意見は違います!*

 ## 練習する

 ### 演習 1: 空白を埋める

 各文を完成させるには、「比」、「没有」、または「一样」を使用します。

1. 我弟弟 ______ 我高两厘米。(私の弟は私より 2 センチ背が高いです。)
 2. この道 ______ 那条路宽。(この道はあの道ほど幅がありません。)
 3. 他跟我年龄 ______。(彼と私は同い年です。)
 4. 飛行機 ______ 火車はたくさんあります。 (飛行機は電車よりもはるかに速いです。)
 5. 今天の天気 ______ 昨天好。(今日の天気は昨日ほど良くありません。)

 ### 演習 2: 中国語に翻訳する

 1. 私の妹は私より賢いです。 
2. このレストランはあのレストランほど安くありません。 
3. 彼の中国語は私の中国語と同じです。 
4. 今日の天気は昨日よりさらに寒いです。 

### 演習 3: 中国語で答えてください

 あなた自身についてのこれらの質問に完全な文章を使って答えてください。 

1. 你跟你的朋友、谁もっと高い?(あなたとあなたの友達、どちらが背が高いですか?)
 2. 你觉得学中文难还是学英文难?(中国語を学ぶのと英語を学ぶのはどちらが難しいと思いますか?)
 3. 今天的天气比昨天好吗?(今日の天気は昨日より良いですか?)

 ## 文化的なメモ

 中国人が比較するとき、文脈は文字通りの表現を超えていることがよくあります。 誰かを比較して「賢い」と言うと、口調や文脈によっては暗黙の褒め言葉や批判が含まれる場合があります。 年齢に関する比較は特にデリケートです。「你比我老」（あなたは私より年上です）と言うのは事実に中立ですが、中国の社会規範は年長者を尊重することに大きな価値を置いているため、枠組みが重要です。 会話では、「我觉得」（私はそう思います）や「好像」（そう思われます）と比較して和らげるのが一般的で礼儀正しいです。
