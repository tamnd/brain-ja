## 概要

 中国語にはヨーロッパ言語のような時制がありません。 代わりに、完了と変更は助詞「了」（le）でマークされます。 このレッスンでは、完了したアクションを示す口頭の「了」、完了したアクションを「没有」で否定する方法、そして最近の過去の出来事をアンカーする「刚才」（今）や「已经」（すでに）などの時間語に焦点を当てます。 

## 学習目標

 - 完了したアクションを説明するには、V + 了 + (オブジェクト) を使用します。 
- 没有 + V (了なし) で過去の行動を正しく否定します
 - 刚才と已经を使用してタイミングを指定します
 - 口頭の「了」（完了）と文末の「了」（状態の変化）を区別する

 ## 文法重視

 ### パターン 1: V + λ + (オブジェクト)

 **構造:** 主語 + 動詞 + 了 + (目的語)

 動詞の直後の助詞「ラム」は、動作が完了したことを示します。 直接目的語がある場合、動詞と目的語の間に「ラム」が入ります。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 私は早饭を完了しました。 ウーチーレゾーパン。 | 朝食を食べました。 |
 | | 一品ずつ新しい衣服を獲得しました。 ターマイレイージアンシンイーフ。 | 彼女は新しい服を買いました。 |
 | 他告了私この件。 Tā gaosù le wōzè jiàn shì。 | 彼はこの件について私に話してくれました。 |
 | | 私は任務を完了しました。 Wàmen wánchéng le rènwù。 | 私たちは任務を完了しました。 |

 **よくある間違い:** 是、有、觉得などの状態動詞や形容詞の後に「了」を付けないでください。 了は状態動詞ではなく、動作動詞の完了を示します。 

### パターン 2: 無し + V (過去の行為を否定)

 **構造:** 主語 + 没有 + 動詞 + (目的語)

 何かが起こらなかったと言うには、動詞の前に没有を使用します。 重要なのは、「了」を否定形で使用しないことです。 この 2 つは同じ条項内で共存できません。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 私には吃早饭はありません。 Wàméiyƒu chī zƎofàn。 | 朝食を食べませんでした。 |
 | | 告発はありません。 Tā méiyƒu gàosù wƒ。 | 彼女は私に教えてくれませんでした。 |
 | 昨日昨日は来ませんでした。 Tā zuótiān méiyƒu lái。 | 彼は昨日来ませんでした。 |
 | | 私には利益がありません。 呉美勇美菜本酒。 | 私はその本を買いませんでした。 |

 **よくある間違い:** 決して「我没有吃了」または「没有买了」とは言わないでください。 否定するために没有を使用する場合は、「了」を完全に削除します。 

### パターン 3: 「刚才」と「已经」

 **構造:** 刚才 + S + V + 了 (今) / S + 已经 + V + 了 (すでに)

 「刚才」（今）は、ごく最近過ぎた瞬間、通常は最後の数分以内の瞬間を指します。 已经 (すでに) は、現在の瞬間または期待より前に何かが完了したことを強調します。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 刚才他は成功しましたが、そうではありません。 Gāngcái tā lái le、dàn nƐ bú zài。 | 彼は今来たところですが、あなたはここにいませんでした。 |
 | | 私はすでに完了しました。 ウー・イジン・チ・レ、ブ・エ・レ。 | もう食べました、お腹は空いていません。 |
 | | 火車はすでに走り去っています。 HuĒchē yƐjīng kāi zƒu le。 | 電車はもう出発しました。 |
 | | 刚才発生了何么? Gāngcái fāshēng le shenme? | 一体何が起こったのでしょうか？ |

 ## 対話

 **A:** 你刚才去哪儿了?我找了你好久。 
**NƐgāngcái QùnƎr le? Wƒ zhƎo le nƐ hƎo jiƔ.**
 *さっきどこに行ったの？ 長い間あなたを探していました。*

 **B:** 对不起，我去便利店买了点东西。 
**DuìbuqƐ、wƒ qù biànlì diàn mƎi le diƎn dōngxī**
 *ごめんなさい、コンビニに買い出しに行きました。*

 **A:** 会議はすでに開始されており、老板は去った。 
**Huìyì yƐjīng kāishƐ le、lƎobƎn wèn nƐ qù nƎr le.**
 ※会議はすでに始まっています。 上司はあなたがどこに行ったのかと尋ねました。*

 **B:** 啊?我忘れ今天有会议！你是何么没有告诉我?
 **? 頑張れ金天勇会！ NĐ weishénme méiyàu gaosù wà?**
 *何? 今日会議があるの忘れてた！ なぜ教えてくれなかったのですか?*

**A:** 我昨天了短信，你没有看吗？ 
**Wƒ zuótiān fā le duƎnxìn, nƐ méiyƒu kàn ma?**
 ※昨日メッセージを送りました。 見てなかったの？*

 **B:** 無し！我無し收到。快走吧！ 
**メイユ！ 呉美勇祥道。 Kuài Zàu ba!**
 *いいえ！ 受け取れませんでした。 早速行きましょう*

 ## 練習する

 ### 演習 1: 空白を埋める

 必要に応じて「了」を追加するか、否定するには「没有」を追加します。 

1. 私は昨天 ______ 吃晚饭、不饿。(昨日夕食を食べました、お腹は空いていません。)
 2. 彼はこの件について私に教えてくれませんでした。 
3. 你 ______ 完了作业了吗?(宿題はもう終わりましたか?)
 4. 她刚才 ______ 来ますが、あなたはいません。 (彼女は今来たところですが、あなたはここにいませんでした。)
 5. 私は ______ 半時間、まだ見つかりません。(30 分探しましたが、まだ見つかりません。)

 ### 演習 2: 中国語に翻訳する

 1. 私はすでに彼に電話しました。 
2. 彼女は昨日授業に来ませんでした。 
3. 今何が起こったのですか?
 4. 私たちは先週プロジェクトを完了しました。 

### 演習 3: 中国語で答えてください

 1. 你今天早上吃了早饭吗?(今朝朝食を食べましたか?)
 2. 你今天有没忘れ忘れ带什么东西?(今日何か持ってくるのを忘れましたか?)
 3. 昨日天你做了何么有意思的事？（昨日どんな面白いことをしましたか？）

 ## 文化的なメモ

 中国語の日常会話では、「你吃了吗」（食べましたか？）という質問は、特に年配の世代の間で最も一般的な挨拶の 1 つです。 この言葉は、食料安全保障が大きな懸念となっていた時代に生まれ、食事について尋ねることは真の気遣いの表現でした。 今では「調子はどうですか？」と尋ねるように機能します。 食事についての文字通りの質問ではなく。 誰かがあなたにこれを言ったら、典型的な反応は「吃了、你呢」（はい、私は持っています。それであなたは？）であり、最後の食事の実際の説明ではありません。
