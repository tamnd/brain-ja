## 概要

 ストリートマーケット、ショッピングモール、小さなお店などどこにいても、中国語で価格について話し合い、交渉する方法を知っていれば、日常のやり取りの幅が広がります。 このレッスンでは、ショッピングの重要な語彙、丁寧な交渉の仕方、高すぎることを表現する方法、交換や返金の処理について説明します。 

## 学習目標

 - 価格を尋ね、太贵了で反応を表現します
 - 能不能便宜一点と打折を使って交渉する
 - ショッピングメジャーの用語を理解して使用する
 - 返品・交換は「换」「退」で対応します。

 ## 文法重視

 ### パターン 1: 太 + 形容詞 + 了 (過剰)

 **構造:** 太 + 形容詞 + 了

 「太...了」は、何かが過剰である、または驚くほどであることを表します。 ショッピングでは、「太贵了」は価格に対する衝撃を表す標準的な方法です。 最後の「ラム」が表現を強めます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | これは太贵了！ 大変なことです！ | これは高すぎます! |
 | 太便宜了，买！ タイピアンイレ、マイ！ | すごく安いので買ってみます！ |
 | このアイテムは衣服が薄くなっています。 濟建一福太小楽。 | この服は小さすぎます。 |
 | 多多了，我不必要那么多。 Tài duō le、wƒ bù xōyào name duō。 | それは多すぎる、そんなに多くは必要ない。 |

 **よくある間違い:** 「了」のない「太」は感嘆符として不完全に感じられる可能性があります。 カジュアルなスピーチでは、常にこれらをペアにして、「太贵」ではなく「太贵了」とします。 

### パターン 2: できない + 動詞 + 一点? (柔軟な要求をする)

 **構造:** できない + 動詞句 + 一点？ 

これは、何かを頼むための丁寧でソフトな言い方で、通常は交渉で使用されます。 これは文字通り「できるか、できないか」を意味し、実際には優しいお願いとして機能します。 ある点が質問を和らげます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 能能便宜一点? Néng bù néng piányí yīdiƎn? | もう少し安くしてもらえませんか？ |
 | | 能力はできませんか？ Néng bù néng kuài yīdín? | もう少し早く行ってもらえますか？ |
 | | 能力は给我换一件できませんか？ 能书能书书约一建? | これを交換してもらえますか？ |

 **よくある間違い:** 「能力できない」は疑問形なので、最後に「吗」は必要ありません。 能できないに「吗」を付けると冗長で不自然に聞こえます。 

### パターン 3: 打折と割引表現

 **構造:** 打 + 数字 + 折

 中国語では、割引は 10 分の 1 で表されます。 打八折とは、元の価格の80％（20％オフ）を意味します。 打五折は50%オフを意味します。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 八折にあります。 仙匡打者zhé。 | 今なら定価の80％（20％オフ）です。 |
 | このアイテムの衣服は七折を打ち終えました。 哲剣一福打楽奇策。 | この衣類は 30% オフです。 |
 | 今天全场打折！ ジンティアン・クァン・チャン・ダイジェ！ | 本日は店内全品特売品です！ |
 | | 打折のない东西? 勇美勇dàzhé de dōngxī? | 何かセール品はありますか？ |

 **よくある間違い:** 打折と折扣 (zhékòu) を混同しないでください。 「打折」は動詞（割引する）です。 折扣は名詞（割引）です。 どちらも使用されますが、中国語の話し言葉では打折の方が一般的です。 

## 対話

 **A:** 老板、这条围巾どれくらい钱ですか？ 
**LƎobōn、zhè tiáo weijīn duōshao qián?**
 *ボス、このスカーフはいくらですか?*

 **B:** この条は二百块です。 
**Zhè tiáo liƎng bài kuài.**
 ※こちらは200元です※

 **A:** 两百？太贵了！能力不能便宜一点？ 
**涼貝? タイギレ！ Néng bù néng piányí yīdiƎn?**
 *200? それは高すぎます! もう少し安くしてもらえませんか？*

 **B:** これは本物で、量もとても良いです。最も便利な百七。 
**Zhè shì zhēn sī de、zhìliàng hěn hào。 Zuì piányí yī biqi qī.**
 ※本物のシルクですので、とても品質が良いです。 最低は 170 です。*

**A:** 一百五怎么样?我现在就买。 
**イー・バイ・ウー・ゼンメイヤン? Wànzài jiù mài.**
 ※150はどうでしょうか？ すぐに購入します。*

 **B:** 好吧、一百五、便宜你了。 
**HƎo ba、yī bĎi wƔ、piányí nƐ le。 ヤオショウジュマ?**
 *それでは 150 でお願いします。 領収書は必要ですか?*

 **A:** ところで、もし量に問題がある場合は、中止してもよいでしょうか？ 
**ヤオ、シェシェ。 Lìngwài、rúguƒ zhìliàng yƒu wèntí、kěyƐ tuì ma?**
 *はい、ありがとう。 また、品質に問題があった場合は返品は可能でしょうか？ 

**B:** 当然のことですが、七曜内の都は退場することができます。 
**Dāngrán kěyƐ、qī tiān nei dōu kěyƐ tuìhuàn.**
 ※もちろん7日以内なら返品・交換可能です※

 ## 練習する

 ### 演習 1: 空白を埋める

 1. 这双鞋 ______ 贵了！(この靴は高すぎます!)
 2. 能 ______ 能便宜 ______ 点？（もう少し安くしてもらえますか？）
 3. 今朝このジャケットは ______ 八折です。 (このジャケットは今日 20% オフです。)
 4. 如果尺码不合适，可 ______ 吗?(サイズが合わない場合、交換できますか?)
 5. 你想用现金还は______方式付ですか?(現金で支払いますか、それとも別の方法で支払いますか?)

 ### 演習 2: 中国語に翻訳する

 1. このシャツは小さすぎます。 大きいサイズはありますか？ 
2. 割引してもらえますか? 2つ買います。 
3. このジャケットを返品したいのですが。 こちらが領収書です。 
4. 今日は店内にあるものはすべて特売品ですか?

 ### 演習 3: 中国語で答えてください

 1. 你喜欢在商店购物还是在网上购物?(店舗での買い物とオンラインのどちらが好きですか?)
 2. 在市场买东西，你会讨价还价吗？（市場で物を買うとき、値切り交渉しますか？）
 3. 你买东西的時候最注意何么？价格还是质量？ 

## 文化的なメモ

 中国の伝統的な市場（市场、shìchƎng）、小規模の個人商店、観光地では、値切り交渉が期待され、受け入れられている習慣です。 ただし、価格が固定されているスーパーマーケット、チェーン店、ショッピングモールでは適切ではありません。 交渉するときは、社交的なやりとり自体が重要です。フレンドリーで、品物に心からの関心を示し、ベンダーに尊敬されていると感じさせることが、価格について強気になるよりも良い結果につながることがよくあります。 提示価格の約 50 ～ 60% で開始し、その中間のどこかで会うのが一般的なアプローチです。
