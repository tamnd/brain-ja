## 概要

 中国語圏の都市を移動するには、道を尋ねて理解する方法を知る必要があります。 このレッスンでは、主要なコンパスと方向転換の語彙、ルートを説明するための「从...到... (...から...へ)」の構造、および実際のナビゲーション状況で使用される方向動詞について説明します。 これらのフレーズは、道路標識、ライドシェア アプリ、カジュアルな会話などで常に表示されます。 

## 学習目標

 - 左、右、直走、转弯を使用してターンバイターンの道順を示します
 - 旅やルートを説明するには「从...到...」を使用します。 
- 「请问」で丁寧に道を尋ねます
 - 前、後、旁边を使用して相対的な位置を記述します。

## 文法重視

 ### パターン 1: 从 + 場所 A + 到 + 場所 B

 **構造:** 从 + 開始点 + 到達 + 目的地 + (動詞句)

 この構造は、ある場所から別の場所への移動を表します。 距離、移動時間、ルートの説明に使用できます。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | ここから地上駅までは十分に歩きます。 Cóng zhèlƐ dào dìtiě zhàn yào zƒu shí fēnzhōng。 | ここから地下鉄の駅までは徒歩10分です。 |
 | 北京から上海までは五時間かかります。 Cóng Běijīng dào ShànghƎi zuò gāotiě yào wƔ gè xiɎoshí。 | 北京から上海まで高速鉄道に乗ると5時間かかります。 |
 | | 公社から家まではありません。 Cóng gongsī dào jiā bù yuàn。 | オフィスから自宅までは遠くない。 |

 **よくある間違い:** 開始点を記載する場合は从を省略しないでください。 「这里到地铁站」と言うのは理解できますが、不完全です。 形式的かつ自然なスピーチでは、「从」を含めます。 

### パターン 2: 方向コマンド (方向/往 + 方向 + 转/走)

 **構造:** 向/往 + 左/右 + 转または直走

 これらはターンバイターンの指示の構成要素です。 ここでは「方向」と「往」の両方が機能します。 「往」のほうが口語的です。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 往左转。 王祖。 | 左折してください。 |
 | |右に向かって。 香友珠。 | 右折。 |
 | |一直走。 イージズ。 | 真っ直ぐ進んで下さい。 |
 | | 到路口右转。 道空翔君。 | 交差点で右折します。 |

 **よくある間違い:** 「走左」または「走右」とは言わないでください。 方向を表す言葉には方向を表す動詞「转」が必要です。 直走のみ、方向を指定して直接走らせます。 

### パターン 3: 在 + 場所 + 方位词を使用した場所

 **構造:** 主語 + 在 + 基準点 + 旁边/前面/後面/对面

 位置語 (方位词) は、基準点の前ではなく、常に基準点の後にあります。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 超市の範囲で実行されます。 Yínháng zài chāoshì pángbiān。 | 銀行はスーパーマーケットの隣にあります。 |
 | | 地铁站は前にあります。 Dìtiězhànzàiqiánmiàn。 | この先に地下鉄の駅があります。 |
 | | 咖啡店は学校对面にあります。 Kāfei diàn zài xuéxiào duìmiàn。 | コーヒーショップは学校の向かいにあります。 |

 ## 対話

 **A:** 请问、去天安门广场怎么走?
 **QƐngwèn、qù Tiān'ānmén GuƎngchƎng zěnme zƒu?**
 *すみません、天安門広場にはどうやって行けますか?*

 **B:** ここからまっすぐ走って、左回りの道路に着きました。 
**NƐ cóng zhèlƐ yīzhí zƒu、zƒu dào lùkƒu xiàng zuƒ zhuƎn.**
 ※ここから直進し、交差点を左折してください※

 **A:** 向左转之後呢？ 
**Xiàng zuà zhuiqn zhīhòu ね?**
 *左折した後、その後は何ですか?*

 **B:** 再びおよそ五分間走って、场は右蹠にいます。 
**Zài zƒu dàgài wƔ fēnzhōng、guƎngchƎng jiù zài yòubiān.**
 ※さらに5分ほど歩くと、右側に広場があります※

 **A:** 从这里走过去大概要多长時間?
 **Cóng zhèlƐ Zàu guòqù dàgài yào duō cháng shíjiān?**
 *ここから歩いてどのくらいかかりますか?*

 **B:** 大概十五分钟。 
**Dàgài shíwōfēnzhōng。 富原、ヒンジンデ。**
 ※15分くらいです。 遠くない、かなり近い*。 

**A:** 谢谢您！ 
**謝謝!**
 *ありがとうございます!*

**B:** 不客气！ 
**Bù kèqì!**
 *どういたしまして!*

 ## 練習する

 ### 演習 1: 空白を埋める

 1. ______ こちら ______ 火車駅まで歩く必要があります。 (ここから鉄道駅までは歩くと20分かかります。)
 2. 到路口 ______ 右 ______。(交差点を右折します。)
 3. 図书馆は学校 ______ にあります。(図書館は学校の隣にあります。)
 4. 一直進、前 ______ は銀行です。 (直進してください、この先の建物は銀行です。)
 5. 你的公司离家 ______ 还是 ______?(あなたのオフィスは家から遠いですか、それとも近いですか?)

 ### 演習 2: 中国語に翻訳する

 1. ここから空港へはどうやって行けますか?
 2. 交差点を右折して直進します。 
3. レストランは病院の向かいにあります。 
4. 北京から西安までは電車で約5時間かかります。 

### 演習 3: 中国語で答えてください

 1. 从你家到学校/公司怎么走?(家から学校/職場までどうやって行きますか?)
 2. 你家附近有何か么？（あなたの家の近くには何がありますか？）
 3. 你觉得用地图找路方便吗？（地図を使って移動するのは便利だと思いますか？）

 ## 文化的なメモ

 中国の都市では、人々は通りの名前ではなくランドマークを使用して道順を示すことがよくあります。 「Road X に曲がってください」よりも、「KFC が見えるまで直進してから左折してください」というような言葉をよく耳にします。 多くの通りの名前は長く、似たような名前なので、これは実用的です。 道を尋ねるときは、「请问」（すみません、聞いてもいいですか）から始めるのが標準的な丁寧な使い方です。 道を尋ねてきた人に詳細な案内を返すことは親切で親切であると考えられており、多くの中国人は目的地を確実に見つけるために全力を尽くします。
