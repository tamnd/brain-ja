## 概要

 医療現場では、具体的で明確なコミュニケーションが必要です。 このレッスンでは、何が問題なのかを説明する方法、症状がどのくらい続いているかに関する質問に答える方法、医師の指示を理解する方法について説明します。 A1+ レベルであっても、これらのフレーズを知っておくことは、緊急時や定期的なクリニック訪問において非常に重要です。 

## 学習目標

 - 体の症状を体の部位+痛み/不舒服で明確に説明します
 - 哪里不舒服と痛了多长時間の質問に答えます
 - 投薬と休息に関する一般的な医師の指示を理解する
 - V + 了 + 期間を含む期間表現を使用します。

## 文法重視

 ### パターン 1: 体の部位 + 痛み / 不舒服

 **構造:** 身体部分 + 痛み / 不舒服

 これは身体的な不快感を最も直接的に説明する方法です。 「痛」（tòng）は痛みを意味します。 不舒服は、一般的な不快感、吐き気、または体調不良をカバーします。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 私は痛みを感じます。 呉頭衡東。 | 頭がひどく痛いです。 |
 | |肚子はサービスを提供しません。 都子不首府。 | お腹が不快です。 |
 | | 嗓子は二日間痛んだ。 松子同楽、梁天楽。 | 2日前から喉が痛いです。 |
 | 私は全身都不服服です。 呉泉神豆酒婦。 | 全身の調子が悪いです。 |

 **よくある間違い:** 「頭が痛い」という意味で「我的头痛」を名詞句として単独で言わないでください。 これは、「頭が痛い」ではなく、「頭が痛い」（名詞）という意味です。 症状を表現するには、「我头痛」または「我头很痛」と言います。 

### パターン 2: V + 了 + 期間 + 了 (これまでの期間)

 **構造:** 動詞 + 了 + 継続時間 + 了

 両方の「了」が出現する場合、最初の文は動詞が開始され進行中であることを示し、2 番目の文 (文末) は状況が現在関連していることを示します。 これらは一緒に、何かが現在に至るまでどれくらいの期間続いているかを表します。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 私は咳嗽了三天了。 Wōkésou le sān tiān le。 | 3日間咳が続いています。 |
 | | 人は一つ上を達成しました。 Tā fāshāo le Yī gè Wānshang le。 | 彼は昨夜から熱を出しています。 |
 | | 私は痛かった好几一時間終わりました。 Wƒ Tóutòng le hao jƐ gè xiƎoshí le。 | 頭が数時間ずっと痛かった。 |

 **よくある間違い:** 2 番目の「了」を省略しないでください。 最後の「了」を付けずに「我咳嗽了三天」と言うと、咳が続いているのではなく、終わっていることを意味します。 

### パターン 3: 哪里不舒服? 質問パターン

 **構造:** 哪里 + 動詞/形容詞 / 多长時間间了?

 医師はこれらの質問パターンを使用して症状を評価します。 学習者はそれらを理解し、自然に反応する必要があります。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | 哪里不舒服?| ナルブシュフ? | どこが痛みますか？ / どうしたの？ |
 | 痛了多長時間了?| Tòng le duō cháng shíjiān le? | どれくらい痛かったのですか？ |
 | 以前は过这种情况吗がありましたか？ YƐqián yu guò zhè zhƒng qíngkuàng ma? | 以前にもこのようなことが起こったことがありますか? |
 | | 何か?| Duìshénmeyàoguòmànma? | 何かの薬に対してアレルギーはありますか? |

 ## 対話

 **医師:** 你好，哪里不舒服？ 
**NƐhƎo、nàlƐbùshufu?**
 *こんにちは、何が問題のようですか?*

 **患者:** 私嗓子は痛みがあり、咳嗽もあり、点状の痛みもあります。 
**Wƒ sƎngzi hěn tòng、hái késou、tóu yě yƒudiƎn tòng.**
 *喉がとても痛くて、咳も出ます、そして頭も少し痛いです。*

 **医師:** 咳嗽了多长時間了?
 **Késou le duō cháng shíjiān le?**
 *どれくらい咳をしていましたか?*

 **患者:** 大概三日間終了。昨晩から発表が始まりました。 
**Dàgài sān tiān le。 Zuótiān kāishĐ fāshāo le.**
 ※3日くらいです。 昨日から熱が出始めました。*

**医師:** 体温は一次です。いいですね、三十八度五。何に対しての薬は敏感ですか？ 
**Liáng yīxià tƐwēn。 ハオ、サンシーバードゥウー。 Duì shénme yào guòmƐn ma?**
 ※体温を測らせていただきます。 はい、38.5度です。 何かの薬に対してアレルギーはありますか?*

 **患者:** 感覚がありません。ボタンを押す必要がありますか?
 **Méiyƒu guòmƐn。 徐曜、真真?**
 ※アレルギーはありません。 注射が必要ですか?*

 **医師:** 役に立ちません。私は最初の薬を使い、何度も歓声を上げ、多くの休息をとりました。三日後に再び検査を受けました。 
**ブヨン。 Wƒ gěi nƐ kāi diĎn yào、huíqù duō hē shuiq、duō xiüxi。 三天后在来莢.**
 ※必要ありません。 薬を処方します。 家に帰って、水をたくさん飲んで、ゆっくり休んでください。 3日後にまた検査を受けに来てください*。 

## 練習する

 ### 演習 1: 空白を埋める

 1. 我肚子 ______ 了好几二時間了。(私の胃は数時間痛んでいます。)
 2. 医生问我 ______ 不舒服。(医者はどこが痛いのか尋ねた。)
 3. 你 ______ 了多长時間间了?(どのくらい熱がありますか?)
 4. 回帰多 ______、多喝熱水。 (家に帰って、もっと休んで、もっとお湯を飲みます。)
 5. 我对青霉素 ______。(私はペニシリンにアレルギーがあります。)

 ### 演習 2: 中国語に翻訳する

 1. 2日間喉が痛くて困っています。 
2. 注射が必要ですか、それとも薬だけですか?
 3. 医者は私に3日間休むように言いました。 
4. どこが痛いですか? どこを指しますか。 

### 演習 3: 中国語で答えてください

 1. 你最近身体怎么样？（最近の健康状態はどうですか？）
 2. 你一般発行烧的時候会怎么做？（熱があるとき、いつも何をしますか？）
 3. 你觉得去医院方便吗？（病院に行くのが便利ですか？）

 ## 文化的なメモ

 中国では、西洋のシステムでは軽症とみなされるような病気のために病院（医院）に行くのが一般的です。 地域の診療所は少なくなり、病院には日常的な苦情に対応する外来部門が設けられています。 医師の診察を受ける前に、患者はまず挂号（登録）をし、少額の登録料を支払う必要があります。 伝統的な中国医学（中医、zhōngyī）は西洋医学と並んで広く実践されており、多くの中国人が慢性的な痛みや疲労などの症状のために漢方薬や鍼治療を求めて中医を訪れます。 「多喝热水」（もっとお湯を飲みましょう）というフレーズは、中国では広く普及している医学上のアドバイスであり、穏やかな文化的なジョークとなっています。
