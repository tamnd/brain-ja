## 概要

 中国では外食は日常的な活動であり、レストランは中国語学習者が自信を持ってコミュニケーションをとる必要がある現実世界の最初の場面の 1 つです。 このレッスンでは、サーバーの注意を引く方法、料理を注文する方法、材料について尋ねる方法、特別なリクエストを行う方法、および請求書の支払い方法について説明します。 ここで紹介するパターンは使用頻度が高く、すぐに役立ちます。 

## 学習目標

 - 给我 + 名詞を使用して食べ物を注文したりリクエストしたりできます
 - 許可または可能性を求めるには、「可...吗?」を使用します。 
- サーバーを呼び出して請求書を自然に処理します
 - 質問パターンで辛さ、食材、料理について尋ねます

## 文法重視

 ### パターン 1: 给我 + 名詞 / 動詞フレーズ (注文と要求)

 **構造:** 给我 + 項目 (+ 測定単語) / 给我 + 動詞

 「给我」は文字通り「ちょうだい」を意味しますが、レストランの文脈では、直接的で完全に自然な注文フレーズとして機能します。 項目の前に「来」を追加すると、さらに口語的になります:「给我来一杯面」。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | |我一份炒饭。 Gěi wƒ yī fèn chƎofàn。 | チャーハンを一つください。 |
 | |我来一杯牛肉面。 Gěi wƒ lái yī wƎn niúròu miàn。 | 牛肉麺を持ってきてください。 |
 | | 私たちは次の菜食を見ました。 Gěi wƒ kàn yīxià càidān。 | メニューを見てみましょう。 |
 | また来ました一瓶の水。 在来比水。 | もう一本水を持ってきてください。 |

 **よくある間違い:** レストラン以外の正式な文脈では、「给我」は唐突に聞こえることがあります。 麻烦（máfan、「ごめんなさい」）を加えて柔らかくします：麻烦给我一份菜单。 

### パターン 2: 可...吗? (許可または可能性を求める)

 **構造:** 可 + 動詞句 + 吗?

 これは中国語で最も多用途なパターンの 1 つです。 何かが許可されているか、可能であるかをチェックし、「してもよいか」と「できるか」の両方をカバーします。 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | | 可以换一张桌子吗? Kěyiquànyīzhāngzhuōzima? | 別のテーブルに切り替えてもいいですか？ |
 | この道菜は不放辣吗？ 哲道菜のページへのリンク | この料理は唐辛子なしでも作れますか? |
 | 微信サポート付吗を使用できますか？ KěyƐ Yòng Wēixìn Zhīfù ma? | WeChat Payで支払うことはできますか? |
 | | 包吗を打ってもいいですか？ KěyĐ dàbāo ma? | これを持ち帰り/梱包してもらえますか? |

 **よくある間違い:** 可（許可/可能性）と会（能力/スキル）を混同しないでください。 「我可吃辣」は、辛い食べ物を食べることが許可されている/食べられることを意味します。 「我会做饭」は、私は料理の仕方を知っているという意味です。 

### パターン 3: 食べ物の詳細に関する質問パターン

 **構造:** 这道菜 + 辣吗 / 有無し... / 是何ですか？ 

| 中国語 | ピンイン | 英語 |
 |----------|----------|----------|
 | この道菜辣吗?| 哲道菜々？ | この料理は辛いですか？ |
 | | 不辣的菜はありませんか？ 余命宣告菜? | 辛くない料理はありますか？ |
 | 你们这里有素食菜吗?| 女門之志菜は? | ここにはベジタリアンのオプションはありますか? |
 | これはどういうことですか? | どのようなことを考えていますか? | これは何からできていますか? |

 ## 対話

 **A:** 服务员！麻烦过来一下。 
**富源！ Máfan guòlái yīxià.**
 *すみません、ウェイターさん！ ちょっと来てもらえますか？*

 **B:** 良い、您好！可以点菜了吗？ 
**ハオデ、ニンハオ! KěyĐ diƎncài le ma?**
 ※もちろん、こんにちは！ 注文する準備はできていますか?*

 **A:** 可能です。これでブランチボックスが保護されますか?
 **KěyĐ. Zhèdào gōngbao jīdīng là ma?**
 *はい。 このカンパオチキンは辛いですか?*

 **B:** 一点あります。もしそれができない場合は、解放を減らすことができます。 
**Yīu yīdiƎn là。 Rúguà nín bù néng chī là、wƒmen kěyƐ shƎo fàng là.**
 ※少し辛めです。 辛いものが苦手な方は唐辛子の量を減らしても大丈夫です*。

**A:** いいですね、私たちは鸡丁をずっと保っていて、放散量は少ないです。一杯の米饭もあります。 
**HƎo、gěi wƒ lái yī fèn gōngbào jīdīng、shāo fàng là。 Háiyƒu Yī wƎn màfàn.**
 *分かった、唐辛子少なめのクンパオチキンを1つ持ってきて。 そしてご飯一杯*。 

**B:** 良いですね、何か必要ですか？ 
**Hōde,háixōyàoshénmema?**
 *注記。 他に何か必要なものはありますか?*

 **A:** 二瓶の泉水が戻ってきました。 
**ザイライリャンピンクアンクアンシュイ。 シェシェ**
 ※あとミネラルウォーター2本。 ありがとうございます。*

 **B:** 良い、訍等。 
**HƎo de、qƐng shāo děng.**
 ※もちろん、少々お待ちください※

 ## 練習する

 ### 演習 1: 空白を埋める

 1. ______ 我見一下菜单。(見るメニューを教えてください。)
 2. 这道菜 ______ 不放葱吗？（この料理はネギなしでも作れますか？）
 3. 你们这里 ______ 素食吗?(ここにベジタリアン料理はありますか?)
 4. 我们想 ______，可以吗?(請求書を支払いたいのですが、よろしいですか?)
 5. 做这道鱼 ______ 什么的?(この魚料理は何でできていますか?)

 ### 演習 2: 中国語に翻訳する

 1. ウェイター、麺を 1 杯持ってきてください。 
2. クレジットカードで支払うことはできますか?
 3. メニューに辛くないものはありますか?
 4. ご飯をあと2杯持ってきてください。 

### 演習 3: 中国語で答えてください

 1. 你最喜欢吃什么菜？（一番好きな食べ物は何ですか？）
 2. 你能吃辣吗？（辛いものは食べられますか？）
 3. 在餐厅吃饭，你一般喜欢点什么？（レストランで食事をするとき、いつも何を注文しますか？）

 ## 文化的なメモ

 中国では、レストランで会計を支払うこと自体が社交的なイベントです。 友人や同僚が、今度は自分の番だと主張して支払いを競うのをよく見かけます。 この実践は、面子（面子、mianzi）と互恵性の概念に関連しています。 請求書を折半すること（AA制、AA zhì、オランダ風）は若い世代、特に都市部でますます一般的になってきていますが、年配の世代やフォーマルな場面では、通常、1人がテーブル全体の代金を支払います。 あなたがゲストの場合、最初の機会にホストに支払いを許可するのが通常は適切な行動です。
