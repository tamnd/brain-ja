HSK 2 文法は、日常の状況をより流暢に処理するために必要な約 55 の核となるパターンをカバーしています。 HSK 1 構造に基づいて構築されているこのレベルでは、比較、アスペクト マーカー、補体、およびより広範囲の粒子が導入されています。 

## 1. 比較

 ### 1.1 比 (bĐ) の比較 — 「A は B よりも優れています」

 標準の比較構造では、比較される 2 つの項目間に「比」が使用されます。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | A + 比 + B + Adj | 他比我高い。 彼は私より背が高いです。 |
 | A + 比 + B + Adj + 程度 | | 她比我高多了。 彼女は私よりもずっと背が高いです。 |
 | A + 比 + B + V + 以上/以下 | 私より多喝了一杯。 私は彼より一杯多く飲みました。 |

 > **注意:** 比文では「很」を使用しないでください。 ~~他比我很高~~ は間違っています。 

### 1.2 否定的な比較 — 「A は B ほどではない」

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | A + 没有 + B + Adj | この条路には那条路がありません。 この道はあの道ほど広くありません。 |
 | A + 没有 + B + V + それほど | 他に何も得られません。| 私は彼ほど速くは走れません。 |

 ### 1.3 一样 (yīyàng) — 「同じ」

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | A + 跟/和 + B + 一样 (+ Adj) | これは同じような値段です。 これはあれと同じくらい高価です。 |
 | A + 跟 + B + 不一样 | | 私は他に何もありません。 私は彼とは違います。 |

 ## 2. アスペクトマーカー

 ### 2.1 了 (le) — 完了したアクション

 動詞の後の「ラム」は、アクションが完了したことを示します。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | V + 了 (+ オブジェクト) | | 我吃了饭。 食べてきました。 |
 | V + λ + 数 + MW + N | 他は三本䦦を獲得しました。 彼は本を３冊買いました。 |
 | 没 + V (了なし) | | 私はいません。 食べていません。 |

 > 文末の「了」は状態の変化を示すこともあります (状況的な「了」): 下雨了 「今雨が降っています。」

 ### 2.2 过 (guò) — 経験的な側面

 「过」は人生経験、つまり過去のある時点で少なくとも一度は行われたことを記録します。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | V + 过 (+ オブジェクト) | 私は北京を去ります。 私は（ある時点で）北京に行ったことがあります。 |
 | 没 + V + 过 | 私は北京烤鸭を通りません。 私は北京ダックを食べたことはありません。 |
 | V+过+吗? | 你学过中文吗?| あなたは中国語を勉強したことがありますか？ |

 ### 2.3 着 (zhe) — 進行中の状態

 着は、行為の結果として継続する状態（物事がどのようになっているのか）を示します。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | V + 着 (+ オブジェクト) | |门着。 ドアは開いています。 |
 | V1+着+V2 | 他笑着論。 彼は笑いながら言いました。 |
 | 着/拿着 | | 茶色の衣服を着ています。 彼女は赤い服を着ています。 |

 ## 3. 可能性と程度の補数

 ### 3.1 得 (de) 次数の補数

 「得」は動詞を、そのアクションがどの程度うまく行われたかを示す説明にリンクします。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | V + 得 + Adj/VP | 他はとても良かったです。 彼はとても上手に話します。 |
 | V + 得 + Adj + 了 | | 来ました太晚了。 来るのが遅すぎました。 |
 | 否定: V + 得 + 不 + Adj | 他に書き込みはありません。 彼はきれいに字を書きません。 |

 ### 3.2 結果の補数

 主動詞の直後に続く 2 番目の動詞または形容詞が結果を示します。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | V + 好 | | 作品は良好でした。 宿題は終わりました。 |
 | V + 完 | この本を完了しました。| 私はこの本を読み終えました。 |
 | V + 到達 | 他は工作完了しました。 彼は仕事を見つけた。 |
 | V+见 | | 了解しました。 聞こえました。 |
 | V+错 | | 書き込み完了。 間違って書きましたね。 |

 ### 3.3 潜在的な補完 — 成功できるかできないか

 動詞と結果の補語の間に得（肯定）または不（否定）を挿入します。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | V + 得 + 結果 | 听得懂 | （聞いて）理解できる |
 | V + 不 + 結果 | 听不懂 | （聞いて）理解できない |
 | 見得见 / 見不見 | 你看得见吗?| 見えますか？ |
 | 做得完 / 做不完 | これは多すぎて不完全です。 とても多すぎて、終わりません。 |

 ## 4.法助動詞

 ### 4.1 想 (xiƎng) — したい / したい

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | S+想+V | 私は北京を去ろうと思います。 北京に行きたいです。 |
 | S + 不想 + V | 他は嫌いです。 彼は勉強したくないのです。 |

 ### 4.2 要 (yào) — したい/する必要がある/するつもり

| 使い方 | 例 | 英語 |
 |----------|-----------|----------|
 | 欲しい | 我要一杯咖啡。 コーヒーが飲みたいです。 |
 | 必要/必須 | 你要好好休息。 しっかり休む必要があります。 |
 | 意志（未来） | | 明天要下の雨。 明日は雨が降ります。 |

 ### 4.3 会 (huì) — やり方を知る / するつもり (おそらく)

 | 使い方 | 例 | 英語 |
 |----------|-----------|----------|
 | 能力 | |私会说中文。 私は中国語を話すことができます。 |
 | 可能性 | | 他の人に会った。 彼は（おそらく）来るでしょう。 |

 ### 4.4 能力 (néng) — (物理的/状況的に) できる

 | 使い方 | 例 | 英語 |
 |----------|-----------|----------|
 | 身体能力 | 私は二杯の饭をすることができます。 ご飯2杯は食べられます。 |
 | 状況に応じた許可 | 这里能抽烟吗?| ここで喫煙できますか? |

 ### 4.5 应该 (yīnggāi) — すべき/すべきである

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | S + 应该 + V | 你应该早点睡。 もっと早く寝たほうがいいよ。 |
 | S + 不应该 + V | 他はこのようなことをしませんでした。 彼はこんなことをすべきではない。 |

 ## 5. 期間と頻度

 ### 5.1 期間の表現

 タイムスパンは動詞の後に（目的語がある場合は目的語の後に）来ます。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | V + タイムスパン | 私等は二時間終了しました。 2時間待ちました。 |
 | V + O + V + タイムスパン | 他学中文学は三年間を終えた。 彼は３年間中国語を勉強しています。 |

 ### 5.2 頻度の表現

 | 式 | 意味 | 例 |
 |-----------|-----------|----------|
 | 每天 | 毎日 | 私は毎日跑步。 
| 常々 | 頻繁に | | 頻繁に到着します。 
| 有時候 | 時々 | |私は時々考えています。 
| 偶尔 | 時々 | 他アップ尔喝酒。 
| 从来不 | 決して（習慣的に） | 私は来ません喝酒。

 ## 6. 場所と方向

 ### 6.1 在 (zai) + 場所

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | S + 在 + 場所 + V | 他は図䦦学习にあります。 彼は図書館で勉強しています。 |
 | S + 在 + 場所 | | 书子上にあります。 本はテーブルの上にあります。 |

 ### 6.2 場所の単語 (方位词)

 | 単語 | 意味 | 例 |
 |------|--------|----------|
 | 上面/上边 | 上、上 | テーブルの上の桌子 |
 | 下面/下边 | 以下、| の下 ベッドの下 | 床下
 | 里面/里边 | 内側 | バッグの中の包里面 |
 | 外面/外边 | 外側 | 门外面 ドアの外側 |
 | 前/前边 | 前に | 学校の前 | 学校の前
 | 後面/後边 | 後ろ | 椅子の後面 | 椅子の後ろ
 | 左边 | 左側 | 左边的人 | 左の人
 | 右边 | 右側 | 右边 右側 |
 | 旁边 | 横 | 私の隣に私旁边 |
 | 对面 | 反対側 | 銀行の向かいの银行对面 |

 ### 6.3 方向の補数

 | 補足 | 意味 | 例 |
 |-----------|-----------|----------|
 | V + 上来 | 出てくる | 走ってここまで歩いて来る |

 ## 7. 接続詞と接続子

 ### 7.1 ゆえに…所以 — なぜなら… したがって

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 因 + 理由、所以 + 結果 | 下雨のため、所以去没。 雨が降ったので行かなかった。 |
 | 1 つを省略できます: 理由… | | 太ったので、私は勝ちません。 高すぎたので買わなかった。 |

 ### 7.2 虽然…しかし — ただし…しかし

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 虽然 + 譲歩、但是 + コントラスト | 確かに値段は高いですが、とても良いです。 高価ですが、良いですよ。 |

 ### 7.3 如果…就 — もし…ならば

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 如果 + 条件、就 + 結果 | 如果明天下雨，就不去了。 もし明日雨が降ったら、私たちは行きません。 |

 ### 7.4 一边…一边 — 同時に

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | 一边 + V1 + 一边 + V2 | | 他の人はテレビを見ます。 彼はテレビを見ながら食事をします。 |

 ## 8. 助詞 つか (はじめに)

 「握る」は目的語を動詞の前に移動して、何かの処分や処理を強調します。 

| パターン | 例 | 英語 |
 |----------|----------|----------|
 | S + 把 + O + V + 補語 | |私たちは桌子の上に解放されました。 私は本を​​テーブルの上に置きました。 |
 | S + 握 + O + V + 了 | | 她ハンドル完了。 彼女はご飯を食べ終えました（食べてしまいました）。 |

 > HSK 3 で完全な構造の習得が可能です。HSK 2 では、その基本形式を認識します。

 ## 9. 質問と回答

 ### 9.1 吧に関する修辞/提案の質問

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | ステートメント + 吧? | |你是学生吧?| あなたは学生ですよね？ |
 | 提案 + 吧 | 私は走吧。 さあ行こう。 |

### 9.2 还是 (háishi) — または (質問で)

 | パターン | 例 | 英語 |
 |----------|----------|----------|
 | A + 还是 + B? | 你喝茶还は咖啡?| お茶かコーヒーが飲みたいですか？ |

 > 質問では または (huòzhě) を使用し、ステートメントでは または (huòzhě) を使用します: 茶または咖啡都可。 

### 9.3 怎么了 — 何が問題ですか?

 | 式 | 使い方 |
 |-----------|----------|
 | | 怎么了？ どうしたの？ どうしたの？ |
 | | 你怎么了？ どうしたの？ |
 | 没事。/ 没何么。| 何もない。 /大したことはありません。 |
