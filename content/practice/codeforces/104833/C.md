### なぜ効果があるのか

 有効なペアに寄与できるすべての整数は、次の約数でなければなりません。$k$、外にある素因数があるため、$k$またはそれを超える指数$k$LCM は次のものとは異なります$k$。 除数に制限されると、各数値は有界指数ベクトルによって一意に表現されます。 LCM 条件は、これらのベクトルに対する決定論的な関数になり、有効な状態のすべてのペアを合計すると、考えられるすべての寄与が 1 回だけで使い果たされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from collections import defaultdict
import math

def factorize(x):
    f = {}
    i = 2
    while i * i <= x:
        if x % i == 0:
            cnt = 0
            while x % i == 0:
                x //= i
                cnt += 1
            f[i] = cnt
        i += 1
    if x > 1:
        f[x] = 1
    return f

def gen_divisors(primes, idx, cur, res):
    if idx == len(primes):
        res.append(cur)
        return
    p, e = primes[idx]
    val = 1
    for _ in range(e + 1):
        gen_divisors(primes, idx + 1, cur * val, res)
        val *= p

def lcm(a, b):
    return a // math.gcd(a, b) * b

def solve():
    T = int(input())
    for _ in range(T):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        pf = factorize(k)
        primes = list(pf.items())

        divisors = []
        gen_divisors(primes, 0, 1, divisors)

        freqA = defaultdict(int)
        freqB = defaultdict(int)

        def process(arr, freq):
            for x in arr:
                if k % x != 0:
                    continue
                freq[x] += 1

        process(a, freqA)
        process(b, freqB)

        ans = 0
        for d1 in divisors:
            for d2 in divisors:
                if lcm(d1, d2) == k:
                    ans += freqA[d1] * freqB[d2]

        print(ans)

if __name__ == "__main__":
    solve()

次に、両方の配列をフィルタリングして、分割する値のみを保持します。$k$。 この枝刈りステップは、その後のすべての計算を小さな境界のあるユニバースに縮小するため、不可欠です。 周波数は、除数の値をキーとしたハッシュ マップに保存されます。 

最後に、すべての約数ペアを反復処理し、それらの LCM が等しいかどうかをテストします。$k$。 除数の数が少ないため、この二重ループは元の入力サイズに比べて安価です。 

微妙な点は、Python の整数 LCM に依存していることです。`gcd`安全ですが、より最適化されたソリューションでは、 gcd を繰り返し呼び出す代わりに指数ベクトルを事前計算できます。
