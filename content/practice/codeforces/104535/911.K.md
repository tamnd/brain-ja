 ## 解決策
 ## 問題の理解

 各参加者は平面内の固定点から出発し、すべての参加者が出発地からこの共有の目的地まで同じユークリッド距離を移動できるように、単一の集合場所を選択するように求められます。 出発位置は固定されていますが、目的地と一般的な移動距離は自由に選択できます。 

幾何学的に、これは点を探していることを意味します$E(x_e, y_e)$与えられたすべての点が、次の点を中心とする円上に位置するようにします。$E$、半径が同じ$d$。 タスクは、そのような円が存在するかどうかを判断し、存在する場合はその中心と半径を出力することです。 

制約により、最大で$10^5$したがって、すべてのペアを比較したり、単純な方法でポイントごとにジオメトリを再計算したりするソリューションは、事前処理後に線形を維持する必要があります。 座標は小さな整数ですが、答えは浮動小数点精度で要求されます。$10^{-6}$これにより、組み合わせ検索ではなく、直接的な幾何学的計算に向けたソリューションが推進されます。 

いくつかの危険な状況は、単純な推論を打ち破ります。 すべての点が同一の場合、正解は自明です。中心はその点であり、距離はゼロです。 ちょうど 2 つの点がある場合は、有効な中心が無限に存在するため、中点を選択すると機能します。 より微妙な失敗は、共線性により点がほぼ同一円であるが正確には同一円ではない場合に発生します。たとえば、(0,0)、(1,0)、(2,0) のような 3 つの同一線上にある点は、3 つの異なる点すべてから等距離にある有限の中心を持つ円上に存在することはできません。そのため、2 点推論が誤って YES を示唆したとしても、答えは NO でなければなりません。 

## アプローチ

 強引な解釈では、中心を推測しようとします。$E$すべての距離が一致するかどうかを確認します。 中心は面内で連続しているため、直接数えることはできません。 もう 1 つの素朴なアイデアは、すべての点のペアを選択し、それらから候補となる円の中心を構築し、それをすべての点に対して検証することです。 各ペアについて、距離を等しくする中心を推定することもできますが、$O(n^3)$最悪の場合、幾何学的チェックが不可能になります。$n = 10^5$。 

重要な観察は、そのような点がある場合、$E$すべての点に対して存在する場合、同一線上にない 3 つの点のサブセットの条件も満たさなければなりません。 同一直線上にない 3 つの点によって円は一意に決定されるため、有効な三重点を 1 つ見つけることができれば、その外中心が答えとなるはずです。 この候補中心を計算したら、残りの作業は、すべての点がそこから同じ距離にあることを確認することだけです。 

すべての点が同一線上にある場合、正の半径の円は 3 つ以上の異なる点を通過できないため、有効な構成はすべての点が一致する場合のみとなります。 その縮退は別のチェックになります。 

これにより、問題は最大 3 つの点から安定した幾何学的構造を見つけ、その後に線形検証パスが続くようになります。

 | 3点からの外周+検証 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ポイントをスキャンし、すべてのポイントが同一であるかどうかを確認します。 そうであれば、答えはすぐにわかります。中心はその点であり、距離はゼロです。 これは、すべての構成が単一の自明な解決策に崩壊する唯一の状況です。 
2. 2 つの異なる点を見つけます。 存在しない場合は、その 1 点を中心とし、距離を 0 として YES を返します。 
3. 同一線上にない 3 つの点を見つけてください。 3 つの点が形成する三角形の符号付き面積がゼロの場合、3 つの点は直線上に位置するため、共線性はベクトルの外積を使用して検出されます。 
4. そのようなトリプルが存在しない場合、すべての点は同一線上にありますが、同一ではないため、有効な円の中心は存在しません。 NOを返します。 
5. 標準の垂直二等分線交差公式を使用して、最初の同一直線上にないトリプルの外心を計算します。 これにより、これらの 3 点を通過する円の一意の中心が得られます。 
6. この中心から入力点のいずれか 1 つまでの距離を計算します。 これが候補半径になります。 
7. すべての点を確認します。中心までの距離を再計算し、すべての値が数値許容範囲内で一致していることを確認します。$10^{-6}$。 逸脱が生じた場合は拒否します。 

### なぜ効果があるのか

 円は、同一線上にない 3 つの点によって一意に決定されます。 すべての点に対して有効な解が存在する場合、同一線上にない 3 つの点のサブセットは同じ円上にある必要があり、したがって同じ外心を共有する必要があります。 構築ステップでは、その一意の候補を見つけます。 検証ステップでは、追加のポイントが制約に違反していないことを確認し、偶発的な位置合わせや構成の縮退を排除します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def circumcenter(ax, ay, bx, by, cx, cy):
    d = 2 * (ax * (by - cy) + bx * (cy - ay) + cx * (ay - by))
    if abs(d) < 1e-18:
        return None

    ax2ay2 = ax * ax + ay * ay
    bx2by2 = bx * bx + by * by
    cx2cy2 = cx * cx + cy * cy

    ux = (ax2ay2 * (by - cy) + bx2by2 * (cy - ay) + cx2cy2 * (ay - by)) / d
    uy = (ax2ay2 * (cx - bx) + bx2by2 * (ax - cx) + cx2cy2 * (bx - ax)) / d
    return ux, uy

n = int(input())
pts = [tuple(map(int, input().split())) for _ in range(n)]

if n == 1:
    x, y = pts[0]
    print("YES")
    print(f"{x:.6f} {y:.6f} 0.000000")
    sys.exit()

all_same = all(p == pts[0] for p in pts)
if all_same:
    x, y = pts[0]
    print("YES")
    print(f"{x:.6f} {y:.6f} 0.000000")
    sys.exit()

x0, y0 = pts[0]
x1, y1 = None, None
for x, y in pts:
    if x != x0 or y != y0:
        x1, y1 = x, y
        break

if n == 2:
    cx = (x0 + x1) / 2
    cy = (y0 + y1) / 2
    d = ((x0 - cx) ** 2 + (y0 - cy) ** 2) ** 0.5
    print("YES")
    print(f"{cx:.6f} {cy:.6f} {d:.6f}")
    sys.exit()

found = False
ax, ay = pts[0]
bx = by = cx = cy = 0

for i in range(1, n):
    for j in range(i + 1, n):
        x2, y2 = pts[i]
        x3, y3 = pts[j]
        cross = (x2 - ax) * (y3 - ay) - (y2 - ay) * (x3 - ax)
        if abs(cross) > 1e-12:
            bx, by = x2, y2
            cx, cy = x3, y3
            found = True
            break
    if found:
        break

if not found:
    print("NO")
    sys.exit()

center = circumcenter(ax, ay, bx, by, cx, cy)
if center is None:
    print("NO")
    sys.exit()

cx0, cy0 = center
dx = pts[0][0] - cx0
dy = pts[0][1] - cy0
d = (dx * dx + dy * dy) ** 0.5

for x, y in pts:
    dx = x - cx0
    dy = y - cy0
    dist = (dx * dx + dy * dy) ** 0.5
    if abs(dist - d) > 1e-6:
        print("NO")
        sys.exit()

print("YES")
print(f"{cx0:.6f} {cy0:.6f} {d:.6f}")

コア部分では、縮退していない三角形を検索します。 外積テストにより、数値的に不安定で幾何学的に無効となる、同一線上の点から外心を計算しないことが保証されます。 有効なトリプルが見つかると、外心公式によって一意の中心が計算されます。 

最後に、ソリューションは計算された半径に対してすべてのポイントを検証します。 この手順は、点のサブセットに対してのみ有効な円が存在する場合の誤検知を防ぐため、不可欠です。

 ## 特殊なケース

 すべての点が直線上にあるが同一ではない場合、微妙な失敗のケースが発生します。 たとえば、(0,0)、(1,0)、(2,0)。 アルゴリズムは、同一線上にないトリプルを検索しますが、見つからない場合、NO 出力をトリガーします。 これは正しいです。なぜなら、有限円は 3 つの異なる同一線上の点を通過できないからです。 

もう 1 つの重要なケースは、有効な円を形成する 1 つの外れ値を除いて、複数の点が同一である場合です。 有効なトリプルから計算された外心により、中心が依然として正しいことが保証され、検証ステップで外れ値によってもたらされた不一致が検出されます。 

最後のエッジ ケースは、点が同一線上に非常に近い場合の浮動小数点の不安定性です。 外積しきい値により、不安定なトリプルの選択が防止され、許容誤差を伴う最終距離チェックにより、小さな数値ドリフトが誤った拒否につながらないことが保証されます。
