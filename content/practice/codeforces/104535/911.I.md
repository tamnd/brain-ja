 ## 問題の理解

 私たちには番号が与えられています$n$そして、テストごとに 2 つの正の整数を出力する必要があります$a$そして$b$その積が次と等しくなるように、$n$。 追加の制約は、どちらでもないということです。$a$または$b$10 進数表現ではゼロで終わることが許可されます。 これは、どちらの数値も 10 で割り切れないことを意味します。これは、末尾のゼロは、素数分解で 2 の因数が少なくとも 1 つと 5 の因数が 1 つあることとまったく同じであるためです。 

したがって、タスクは因数分解だけではありません$n$ただし、各グループに 2 と 5 の両方が同時に含まれないように、因子を 2 つのグループに分割します。 

入力サイズは最大です$10^5$テストケースとそれぞれの$n$と同じ大きさにすることができます$10^{18}$。 これにより、試行除算を使用して各数値を因数分解しようとするアプローチは即座に除外されます。$\sqrt{n}$、それには最大で$10^9$最悪の場合のテストごとの操作。 

微妙なエッジケースが現れるのは、$n$たとえば、10 の因数が多数あります。$n = 10^k$。 「take」のような素朴な貪欲な分割$a = 1$、$b = n$」はすぐに失敗します。$b$はゼロで終わり、2 と 5 を明示的に区切らない分割も同様です。 

もう 1 つのよくある失敗例は、任意の約数を選択すると仮定することです。$a$そして設定$b = n/a$動作します。 たとえば、$n = 40$、選択する$a = 4$、$b = 10$は乗算的には有効ですが、両方の数値がゼロで終わるため、構造的には無効です。 

本当の難しさは、乗算の正しさではなく、2 つの出力にわたる 2 と 5 の配分を制御することです。 

## アプローチ

 強引なアイデアは、すべての約数のペアを反復処理することです。$(a, b)$そのような$a \cdot b = n$、両方の数値がゼロで終わっていないかどうかを確認します。 単一の約数を生成する場合でも、$n$必要$O(\sqrt{n})$、そしてこれを行うのは$10^5$テストケースは実行可能な限界をはるかに超えています。 

ボトルネックは、10 進数の末尾ゼロの構造を使用せずに、因子ペアに対する制約充足問題を解決しようとしているということです。 

重要な観察は、後続のゼロは、因数 2 と 5 が同時に存在するかどうかにのみ依存するということです。因数 2 と 5 をすべて異なる数値に完全に分離すると、どちらの数値も両方を含むことができないため、どちらもゼロで終わることはできません。 他のすべての素因数はこのプロパティとは無関係であり、任意に割り当てることができます。 

これにより、問題はクリーンな因子分割タスクに縮小されます。つまり、$n$、2 が完全に一方の数字に割り当てられ、5 が完全にもう一方の数字に割り当てられるようにそれらを分配します。

 ## アルゴリズムのチュートリアル

 2 と 5 のべき乗を因数分解し、制御された方法で答えを再構築することに重点を置きます。 

1. 各テスト ケースについて、次の内容を読んでください。$n$。 これを 2 のべき乗、5 のべき乗、その他すべての 3 つの部分に分解します。 
2. その間$n$は 2 で割り切れるので、2 で割って、これが何回起こるかを数えます。 このカウントを次のように保存します$c_2$。 これにより、2 のすべての因数が分離されます。 
3. 残りの数が 5 で割り切れる間、それを 5 で割って、これらの演算を次のように数えます。$c_5$。 これにより、5 のすべての因数が分離されます。 
4. 2 と 5 をすべて削除した後の残りの値$m$2 と 5 以外の素数のみが含まれます。この部分は後続のゼロには影響しません。 
5. 構築する$a = m \cdot 2^{c_2}$そして$b = 5^{c_5}$。 これにより、2 のすべての因数が次のようになります。$a$、5 のすべての因数は次のようになります。$b$、 そして$m$に行きます$a$。 
6. 出力$a, b$。 必要に応じて、それらを交換することも有効ですが、必須ではありません。 

この分割が選択される理由は、後続のゼロの形成を追跡するとより明らかになります。後続のゼロには、同じ数値内に少なくとも 1 つの 2 と 1 つの 5 が必要です。 施工により、$a$5 はなく、$b$には 2 がないため、どちらもその条件を満たすことができません。 

## なぜ機能するのか

 数値は、10 で割り切れる場合、つまり素因数分解に 2 と 5 の両方が含まれる場合に限り、末尾にゼロが付きます。上記の構造では、2 のすべての因数が 1 つの数値に分離され、5 のすべての約数がもう 1 つの数値に分離されます。 残りの部分$m$には 2 も 5 も含まれていないため、新しい 10 要素を導入することはできません。 これにより、構築された数値に必要な両方の素数が同時に含まれないことが保証されるため、正確な乗算を維持しながらどちらの出力もゼロで終わることはありません。$n$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        
        x = 0
        while n % 2 == 0:
            n //= 2
            x += 1
        
        y = 0
        while n % 5 == 0:
            n //= 5
            y += 1
        
        a = n * (2 ** x)
        b = 5 ** y
        
        print(a, b)

if __name__ == "__main__":
    solve()
```この実装は、因子分割のアイデアを直接反映しています。 2 と 5 を抽出するループは、各除算で厳密に数値が削減され、テスト ケースごとの対数動作が保証されるため、安全です。 

構築ステップでは配置に注意してください: 残りのすべてのコア値$n$ストリップを掛け合わせた後$a$、 その間$b$純粋に5だけで構成されています。 この非対称性により、偶発的な末尾のゼロが防止されます。 

ここでよくある間違いは、同じ再構成された数字に 2 と 5 を混ぜることです。 単一の重複でも後続のゼロが再導入されるため、分離は絶対的である必要があります。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys

 ## 特殊なケース

 のために$n = 1$、アルゴリズムは 2 または 5 の因数を削除しないため、両方のカウントはゼロになり、$a = 1$、$b = 1$。 どちらもゼロで終わらないため、自明なケースでは正しいことが確認されます。 

のために$n = 10^k$、2 と 5 を繰り返し削除すると、$m = 1$、すべて 2 が割り当てられています$a$そしてすべての 5 を$b$。 両方の入力に大きなべき乗が含まれている場合でも、分離により 1 つの数値内の 2 と 5 の重複が防止されるため、末尾のゼロは表示されません。
