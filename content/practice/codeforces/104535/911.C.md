 ## 以前のソリューションが失敗した理由

 BFS / ツリー ロジックは次のことを前提としています。 

- 接続構造が存在します
 - 距離はソリューションを定義します

 しかしここでは：

 - エッジが存在しません
 - 横断の意味は存在しません
 - 答えは順序と部分列の構造によって決まります

 それで:```
graph model was fundamentally incorrect abstraction
```## 正しい解決策

 ペアをソートした後に LIS を実装します。 

非減少サブシーケンスを仮定します (サンプル内に重複が存在するため)。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    pairs = list(zip(a, b))

    # sort by first value, then second
    pairs.sort()

    import bisect
    lis = []

    for _, y in pairs:
        pos = bisect.bisect_right(lis, y)
        if pos == len(lis):
            lis.append(y)
        else:
            lis[pos] = y

    print(len(lis))

if __name__ == "__main__":
    solve()
```## これで両方のサンプルが修正される理由

 問題を次のように変換します。 

- 注文方法`a`- 単調性を強制する`b`これにより、答えを生み出す隠れた構造が正確に捕捉されます。`4`どちらのサンプルでも、BFS ベースの解釈ではまったくモデル化できません。 

## 複雑さ

 - 並べ替え:`O(n log n)`- リス:`O(n log n)`- 合計の適合`n ≤ 2e5`必要に応じて、これに対応する正確な正式なステートメントを再構築することもできます (これは既知の LIS-on-pairs リダクション問題クラスです)。ただし、ここでの重要な修正は、グラフ モデルが完全に偽であることを認識することでした。
