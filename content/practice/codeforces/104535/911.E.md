 ## 解決策
 ## 問題の理解

 整数グリッド上に正確に 6 つの頂点を持ち、その面積が正確に指定された整数になるような凸多角形を明示的に構築するように求められます。$S$。 私たちに与えられる唯一の自由は座標を選択することです。 凸性、順序付け、完全性を含むその他すべては固定されています。 

重要な問題は、何も最適化もカウントもしていないことです。 私たちは、すべての頂点を整数に保ち、多角形が凸面を維持しながら、面積が制御可能で正確な幾何学的形状を「設計」する必要があります。 

制約$S \le 10^9$あらゆる構築が線形であるか、最悪の場合でもテスト ケースごとに一定時間である必要があることがすぐにわかります。 候補ポリゴンを検​​索したり反復したりすることはできません。 すべては閉じた幾何学的構造から生まれなければなりません。 

この種のタスクにおける微妙な落とし穴は、整数面積の三角形は簡単に六角形に拡張できると仮定していることです。 凸面性を維持せずに、またはエッジ上にあることを確認せずに余分なポイントを恣意的に挿入すると、ポリゴン構造は簡単に壊れてしまいます。 もう 1 つの失敗モードは、複数のコンポーネントに面積を分散しようとして、誤って自己交差が発生してしまうことです。これにより、面積の計算がまだ一致している場合でも、凸性が無効になってしまいます。 

したがって、本当の課題は、面積の計算が簡単で正確に調整できる凸六角形を構築することです。$S$6 つの頂点すべてが格子点のままであることを確認しながら。 

## アプローチ

 素朴な考えは、面積の凸多角形を形成する 6 つの整数点を直接検索することです。$S$。 座標範囲内の候補 6 タプルの数は天文学的に多く、候補ごとの凸性と面積をチェックするだけでも制限時間を超えてしまうため、これは絶望的です。 

より構造化されたアイデアは、三角形などの制御可能な領域を持つ既知の形状から開始して、それを六角形に変換することです。 難しいのは、頂点を追加すると、追加された点が既存のエッジ上に正確に存在しない限り、通常は形状が変化することです。 

この観察は重要な単純化につながります。整数の面積を持つ凸三角形を構築するとします。$S$次に、追加の同一線上の点を挿入することで、そのエッジを安全に細分化できます。 これらのポイントはポリゴンのジオメトリや面積を変更しませんが、凸面を維持しながら頂点の数を増やします。 これはまさに私たちが必要としているものです。面積を変更せずに三角形を六角形に「膨張」させる方法です。 

残りのタスクは、正確に 3 つの追加の個別の頂点を配置できるように、三角形のエッジに十分な整数の格子点があることを確認することです。 

したがって、2 つの辺が軸と一致するように選択された頂点で直角三角形を構築します。 これにより、これらのエッジ上に多くの整数点が保証され、追加の頂点の選択が容易になります。 

三角形は次のように定義されます。$$A(0,0), \quad B(S,0), \quad C(0,2)$$そのエリアは次のとおりです。$$\frac{S \cdot 2}{2} = S$$次に、エッジに沿って整数点を挿入することで、この三角形を六角形に強化します。 

- オン$AB$のように複数のポイントを挿入できます。$(1,0), (2,0)$- の上$CA$、挿入できます$(0,1)$- 角$BC$変わらない

 挿入されたすべての点は三角形のエッジ上にあるため、凸面性が維持され、面積は変化しません。 

これにより、正確に 6 つの異なる頂点が生成されます。

 ## アルゴリズムのチュートリアル

 ### 重要なアイデア

 正確な面積の三角形を作成します$S$、エッジを格子点で分割して六角形に変換します。 

### ステップ

 1. 直角三角形を形成する 3 つの点を修正します。$$A(0,0), \quad B(S,0), \quad C(0,2)$$これにより、エリアが正確に確保されます。$S$。 
2. エッジ上のすべての整数点をリストします。$AB$。 水平なので全点$(x,0)$整数の場合$x \in [0,S]$その上に横たわってください。 
3. 上の 2 つの中間点を選択します。$AB$、 例えば：$$P_1(1,0), \quad P_2(2,0)$$これらは追加の頂点になります。 
4. エッジ上の整数点を 1 つ選択します$CA$、これは垂直方向です:$$P_3(0,1)$$5. 三角形の境界に沿って次の順序で歩いて多角形を構築します。$$(0,0) \to (1,0) \to (2,0) \to (S,0) \to (0,2) \to (0,1)$$6. この 6 点を順番に出力します。 挿入されたすべての点が凸型三角形の境界エッジ上に位置するため、結果として得られる多角形は凸型になります。そのため、新しいターンは導入されません。 

### なぜ効果があるのか

 不変条件は、追加されたすべての点が凸三角形の境界セグメント上にあるということです。 エッジの細分割によって多角形の支持線が変更されたり、新しい角度が追加されたりすることはないため、凸状の多角形はエッジの細分割でも凸状のままになります。$180^\circ$。 幾何学的領域を変更せず、その境界表現を調整するだけであるため、領域は保存されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

S = int(input().strip())

# Triangle vertices
A = (0, 0)
B = (S, 0)
C = (0, 2)

# Subdivide edges to get 6 vertices
P1 = (1, 0)
P2 = (2, 0)
P3 = (0, 1)

# Construct convex boundary walk
points = [
    A,
    P1,
    P2,
    B,
    C,
    P3
]

for x, y in points:
    print(x, y)
```最初の 3 つの点は三角形の底辺にあり、直線の水平セグメントが維持されます。 ポイント$(S,0)$基地を閉めます。 次に、次の場所に移動します$(0,2)$、一番上の頂点、そして最後に挿入します$(0,1)$暗黙的に最初に戻る前に、垂直エッジで。 この順序付けは、三角形の境界を時計回りに通過することを尊重します。 

実装の微妙な詳細は、単に選択された点のシーケンスではなく、順序付けが境界に従わなければならないことです。 これらの点が順列すると、自己交差または不正な凸順序が発生する危険があります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    S = int(input().strip())

    A = (0, 0)
    B = (S, 0)
    C = (0, 2)

    P1 = (1, 0)
    P2 = (2, 0)
    P3 = (0, 1)

    pts = [A, P1, P2, B, C, P3]

    return "\n".join(f"{x} {y}" for x, y in pts) + "\n"

# minimum-ish case
assert run("3") != "", "basic construction"

# sample-style case
assert run("22").count("\n") == 6, "should output 6 points"

# large case
assert run("1000000000").count("\n") == 6, "handles max S"

# edge case small
assert run("1").count("\n") == 6, "works for smallest S (if allowed)"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 3 | 6点 | 基本的な正しさ |
 | 22 | 6点 | サンプル構造の一貫性 |
 | 1e9 | 6点 | 大きな座標の処理 |
 | 1 | 6点 | 最小境界動作 |

 ## 特殊なケース

 非常に小さな値の場合、$S$の場合でも、三角形は有効なままであり、追加されたすべての点が有効なエッジ セグメント内にあるため、構築は依然として正しく動作します。 たとえば、次のようなとき$S = 3$、三角形は次のようになります$(0,0),(3,0),(0,2)$、および挿入されたポイント$(1,0),(2,0),(0,1)$境界に沿って明確で整然とした状態を保ちます。 新しい回転角度は導入されず、エッジの改良のみが導入されるため、凸面構造は変化しません。
