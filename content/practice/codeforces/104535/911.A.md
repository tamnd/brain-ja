 ## 解決策
 ## 問題の理解

 次のサイズの長方形領域が与えられます。$H \times W$。 タスクは、一連のドローンを使用して、この長方形内のすべての点をカバーすることです。 各ドローンは柔軟性があり、ルール内であれば、任意のサイズの正方形の領域を監視するように構成でき、どこにでも配置できます。 

実現可能性を定義する制約が 2 つあります。 まず、長方形内のすべての点が、少なくとも 1 台のドローンの正方形の範囲でカバーされる必要があります。 第二に、ドローンの正方形のどの部分も長方形の外にはみ出すことはできません。 したがって、選択した各正方形は完全に内側になければなりません。$H \times W$エリア。 

目標は、このような正方形のカバーの数を最小限に抑えることです。 

このステートメントは連続的なカバレッジについて述べていますが、それを離散的に解釈すると、構造がより明確になります。長方形は次のように動作します。$H \times W$単位セルのグリッド。 各ドローンは、グリッド内に完全に含まれる連続した正方形のサブグリッドをカバーします。 可能な限り少数の正方形タイルを使用してグリッドをタイル表示したいと考えています。 

制約$H, W \leq 1000$これは、単純な走査を超えた 3 次または 2 次の因数を含む解はまだ合格する可能性がありますが、網羅的な分割やすべてのサブスクエアの明示的な検索を伴うものは遅すぎることを意味します。$O(HW)$細胞と$O(H^2W^2)$可能な正方形。 

重要な点は、大きな正方形を貪欲に配置すると失敗する可能性があることです。 たとえば、可能な限り最大の正方形を常に左上隅から配置しようとすると、残った領域をさまざまな正方形の形状に分割したほうがよい可能性があるため、次善の分解が簡単に得られます。 したがって、問題はドローンあたりの面積を貪欲に最大化することではありません。 

もう 1 つの落とし穴は、答えが領域にスムーズに依存すると仮定していることです。$H \cdot W$。 例えば、$3 \times 9$そして$4 \times 3$どちらもそれぞれ面積 27 と 12 を持っていますが、サンプルで見られるように、分解の構造は総面積よりも重要です。 

## アプローチ

 ブルートフォース手法では、長方形を正方形の部分に再帰的に分割しようとします。 すべてのステップで、正方形のサイズと位置を選択し、残りの覆われていない領域からそれを差し引き、グリッド全体が覆われるまで続行できます。 これは、正方形ごとの長方形のすべてのタイリングに対する検索になります。 

正方形を配置する方法の数$H \times W$グリッドはすでにあります$O(HW)$サイズごとに、$O(\min(H,W))$可能な正方形のサイズ。 再帰は残った形状に大きく依存して分岐し、指数関数的な状態空間を生成します。 メモ化したとしても、明らかになった個別の構成の数は、その数をはるかに超えて非常に急速に増加します。$H, W \leq 1000$許可します。 

問題の構造は簡略化を示唆しています。実際には、組み合わせの意味でさまざまな正方形のサイズに制約されるわけではありません。 代わりに、正確なタイリングではなく、最小数のみが求められます。 これは多くの場合、検索ではなくジオメトリに基づいて構築的不変条件を示します。 

重要な観察は、最適なタイリングは系統的な分解パターンに合わせて配置された正方形のみを使用すると想定できることです。 Euclid のアルゴリズムが長さを分解する方法と同様に、一方の次元から他方の次元に対して最大の正方形を繰り返し切り取ることで、長方形を縮小できます。 各「カット」は、同一のドローンのバッチを配置することに対応します。 

長方形を可能な限り最大の正方形ブロックを繰り返し削除するものと解釈すると、そのプロセスは、次のブロック間の最大公約数構造を計算することを反映します。$H$そして$W$。 各ステップは最適性を維持しながら 1 次元を削減し、ステップ数は必要な正方形バッチの数に対応します。 

これにより、問題は幾何学的タイル検索からユークリッド アルゴリズムと同一の決定論的プロセスに変換され、各分割ステップは特定の数の正方形ドローンの使用に対応します。

 ## アルゴリズムのチュートリアル

 長方形を解釈します$(H, W)$最大二乗除去を使用して反復的に削減するものとして。 

1. ペアから始めます$(H, W)$。 私たちは常に、大きい方の寸法を「コンテナの方向」として扱い、小さい方の寸法を正方形の辺の制約として扱います。 これにより、可能な限り最大の正方形が常に最初に配置されるようになります。 
2. もし$H < W$、交換します。 これにより、解釈の一貫性が保たれ、対称的なケースを個別に処理することがなくなります。 
3. いくつあるかを計算します$W \times W$正方形は高さに沿ってフィットします。$H // W$。 このような各正方形は、正方形のブロック全体をカバーする 1 つのドローンに対応します。 
4. 更新してこれらのカバーされた部分を減算します。$H = H \bmod W$。 これにより、完全にタイル化された正方形のストリップが削除され、小さな長方形が残ります。 
5. 1 つの次元がゼロになるまで、縮小された長方形に対して同じロジックを繰り返します。 各反復は貢献します$H // W$ドローンを使用し、残りの部分でもプロセスが続行されます。 
6. 反復にわたるすべての寄与を合計します。 この合計が、必要な正方形ドローンの最小数です。 

このプロセスが正しい理由は、各ステップで少なくとも次のものを使用する必要があるためです。$H // W$辺の正方形$W$いつ$W$より小さい正方形は適合せず、より小さい正方形は完全なカバレッジを回避してカウントを減らすことができないため、より小さい寸法になります。 代替タイリングは同じ全幅ストリップをカバーする必要があるため、再配置してもカウントは不変です。 

このアルゴリズムは基本的に、問題を軽減する前に常に 1 次元を最大の正方形で飽和させる貪欲なタイリングをエンコードします。この飽和ステップを全体的に改善することはできません。これは、より小さな分解では同じ領域をカバーするのに必要な正方形の数が増加するだけであるためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    H, W = map(int, input().split())
    ans = 0

    while H and W:
        if H < W:
            H, W = W, H
        ans += H // W
        H %= W

    print(ans)

if __name__ == "__main__":
    solve()
```コアループはユークリッド還元プロセスを反映しています。 この交換により、常に小さい方の辺が正方形のサイズとして扱われるようになります。 整数除算は、長辺に沿って適合する最大正方形の数をカウントし、係数は完全に覆われたストリップを削除します。 

重要な実装の詳細は、次の不変条件を維持することです。$H \geq W$各部門の前に。 これがないと、整数の除算が間違った方向で適用され、分解は有効な正方形の配置に対応しなくなります。

これは、長方形が剰余なしで同一の正方形に正確に分解されるきれいなケースを示しており、アルゴリズムが完全な割り算を処理していることが確認されます。

 ## 特殊なケース

 特殊なケースは、1 つの次元が 1 の場合に発生します。たとえば、次のようになります。$H = 1, W = 1000$。 アルゴリズムが切り替わってカウントされる$1000$単位正方形を 1 ステップで実行できるため、$1000 // 1 = 1000$。 係数はすぐにゼロになるため、プロセスは正しく終了します。 素朴な幾何学的なタイリング手法では、誤ってより大きな正方形を形成しようとする可能性がありますが、高さが低すぎるため、それは不可能です。 

もう 1 つのケースは、次のように寸法が等しい場合です。$H = W = 7$。 アルゴリズムはただちに 1 つの正方形を追加して終了します。 これは、単一の$7 \times 7$ドローンは領域全体をカバーし、単一の正方形のカバーでは分解を改善できません。 

より微妙なケースは、次のように比率が 1 に近い場合です。$H = 1000, W = 999$。 アルゴリズムは 1 つの大きな正方形の配置を実行し、残りの正方形を残します。$1 \times 999$、999 個の単位正方形に解決されます。 これは、正方形に近い長方形が 1 つの大きな正方形と薄いストリップに折りたたまれることが多く、最適なタイリングは依然としてそのストリップを明示的に考慮する必要があることを示しています。
