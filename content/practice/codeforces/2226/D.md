 ## 解決策
 ## 問題の理解

 それぞれが配列で構成されるいくつかのテスト ケースが与えられています。 タスクは、特定の演算を使用して各配列を非減少順序に変換できるかどうかを決定することです。任意の部分配列を選択し、その最小値と最大値を計算し、それを逆にすることができますが、これら 2 つの値の合計が奇数パリティである場合に限ります。 

2 つのうちの一方が偶数で、もう一方が奇数の場合、合計は正確に奇数となるため、この演算は、最小値と最大値が異なるパリティを持つセグメントに対してのみ使用できます。 

各テスト ケースの出力は、単純な実現可能性チェックです。つまり、このような制約のある反転のシーケンスによって配列を並べ替えられるかどうかです。 

この制約は、すべてのテスト ケースにわたる配列の合計長が最大 2×10^5 であることを意味するため、どのソリューションもテスト ケースごとに線形またはほぼ線形の時間で実行する必要があります。 すべてのセグメントを試行したり、操作をシミュレートしたりする O(n^2) 戦略は、直ちに実行不可能になります。 

このタイプの問題でよくある失敗モードは、「偶数と奇数の両方がある」ことで自動的に完全な柔軟性が得られると想定していることです。 演算は両方のパリティの存在だけでなく、セグメント内の極値にも依存するため、これは明らかに真実ではありません。 もう 1 つの微妙な落とし穴は、リバーサルが任意のスワップのように動作すると考えることです。 彼らはそうではありません。 パリティ制約は、配列が柔軟に見える場合でも、特定のローカルな再配置をブロックする可能性があります。 

## アプローチ

 ブルート フォースの観点は単純です。すべての有効なセグメントを繰り返し試行し、それらを逆にして、配列がソートされるかどうかを確認します。 各ステップでは、すべての O(n^2) セグメントをスキャンし、最小値と最大値を計算し、反転をシミュレートする必要があります。 各セグメント クエリが最適化されたとしても、反転によって到達できる状態の数は爆発的に増加するため、このアプローチは最大 2×10^5 の n に対して使用できなくなります。 

重要な構造上の観察は、あらゆる移動を可能にするために重要なのは、少なくとも 1 つの有効なセグメントを見つけられるかどうかだけであるということです。 セグメントは、その最小値と最大値が逆のパリティを持つ場合にのみ有効です。 選択できる最小のセグメントは長さ 2 のセグメントで、最小値と最大値は 2 つのエンドポイントにすぎません。 これにより、操作条件が非常に単純な形に即座に縮小されます。つまり、2 つの隣接する値が異なるパリティを持つ場合に、隣接スワップが可能になります。 

これが分かると、反転操作をグローバルに分析する必要はなくなります。 有効な反転は、パリティが異なる位置にわたる一連の隣接スワップに分解できます。 これは、システムの真の能力は、逆パリティの隣接要素を交換できることに由来しており、少なくとも 1 つの偶数要素と 1 つの奇数要素が存在する限り、配列全体で要素を徐々にシャッフルできることを意味します。 

配列全体が同じパリティを持つ数値で構成されている場合、少なくとも 2 の長さのセグメントは条件を満たすことができないため、演算は不可能です。 配列は初期状態で固定されており、すでに非減少である場合にのみソートが可能です。 

両方のパリティが存在する場合、少なくとも 1 つの有効な隣接スワップが存在し、そのようなスワップを繰り返し使用すると、任意の並べ替えが可能になります。反対パリティの隣接要素間でスワップすることで要素を配列内で「運ぶ」ことができ、最終的には標準的なバブル ソート スタイルの並べ替えが可能になります。

 ## アルゴリズムのチュートリアル

1. 各テスト ケースについて、配列をスキャンし、少なくとも 1 つの偶数と少なくとも 1 つの奇数が存在するかどうかを判断します。 長さ 2 のセグメントが反転の最小候補であるため、この 1 つのチェックで有効な操作が存在するかどうかが捕捉されます。 
2. 配列に偶数のみ、または奇数のみが含まれている場合は、直ちに演算が不可能であると結論付けます。 この状況では配列は変更できないため、すでにソートされている場合にのみ答えは「YES」になります。 
3. 両方のパリティが表示される場合、配列は常にソート可能であると結論付けます。 少なくとも 1 つの偶数と 1 つの奇数が存在することにより、配列内のどこかで隣接するスワップが可能であることが保証され、これらのスワップは、ローカル交換の繰り返しによる置換を実現するのに十分です。 
4. すべての混合パリティ配列および既にソート済みの単一パリティ配列の場合は「YES」を出力し、それ以外の場合は「NO」を出力します。 

### なぜ効果があるのか

 決定的な不変条件は、配列に両方のパリティが含まれるかどうかです。 両方が存在する場合、何らかの再配置の後、反対パリティの隣接するペアが常に少なくとも 1 つ存在し、そのようなペアを使用して要素を配列全体に伝播できます。 これにより、位置の固定性がなくなり、要素が固定領域内に閉じ込められなくなります。 パリティが 1 つだけ存在する場合、すべてのサブアレイは同一のパリティ極値を持つため、いかなる演算も適用できず、構成は不変です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_sorted(a):
    return all(a[i] <= a[i+1] for i in range(len(a)-1))

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    has_even = False
    has_odd = False

    for x in a:
        if x % 2 == 0:
            has_even = True
        else:
            has_odd = True

    if has_even and has_odd:
        print("YES")
    else:
        # no operations possible at all
        print("YES" if is_sorted(a) else "NO")
```このソリューションでは、まず単一パスでパリティの多様性をチェックします。 唯一の微妙な分岐は、すべての数値が同じパリティを共有する退化ケースです。この場合、配列は不変であり、すでにソートされている必要があります。 

の`is_sorted`チェックは、その縮退ブランチでのみ必要です。それ以外の場合、答えは常に肯定的であるためです。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

すべてのテスト ケースにわたる合計の複雑さは、合計入力サイズにおいて線形であり、2×10^5 要素の制約内に快適に収まります。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        has_even = any(x % 2 == 0 for x in a)
        has_odd = any(x % 2 == 1 for x in a)

        if has_even and has_odd:
            out.append("YES")
        else:
            out.append("YES" if all(a[i] <= a[i+1] for i in range(n-1)) else "NO")

    return "".join(out)

# provided sample (format assumed)
assert run("1\n4\n1 1 2 3\n") == "YES", "sample-like 1"

# all same parity, sorted
assert run("1\n4\n2 4 6 8\n") == "YES"

# all same parity, unsorted
assert run("1\n4\n8 6 4 2\n") == "NO"

# mixed parity, unsorted
assert run("1\n3\n3 1 2\n") == "YES"

# mixed parity, already sorted
assert run("1\n5\n1 2 3 4 5\n") == "YES"

 | すべての偶数をソート | はい | 不変だがすでにソート済み |
 | すべて偶数未ソート | いいえ | 操作が存在しません |
 | 混合パリティ | はい | 常にソート可能 |
 | 増加シーケンス | はい | 些細な陽性例 |

 ## 特殊なケース

 完全に均一なパリティのアレイは、システムのモビリティがゼロになる唯一の構成です。 このような場合、アルゴリズムは純粋な並べ替えチェックに正しくフォールバックします。 

たとえば、入力`[8, 6, 4, 2]`偶数のみが含まれます。 どのセグメントもパリティ条件を満たすことができないため、配列は変更できません。 アルゴリズムはこれを検出し、すでにソートされているかどうかを直接評価し、ここでは「いいえ」を生成します。 

対照的に、`[3, 1, 2]`両方のパリティが含まれています。 配列がソートされていない場合でも、少なくとも 1 つの偶数と 1 つの奇数が存在することにより、有効な隣接スワップが存在することが保証されるため、アルゴリズムは正しく「YES」を返します。
