 ## 解決策
 ## 問題の理解

 からの整数の順列が与えられます。`1`に`n`。 すべての連続する部分配列について、次の 3 つの量を調べます。 

- その最大値、
 - その最小値、
 - その中のすべての値の GCD。 

サブ配列は次の場合に良好と呼ばれます。$$\max - \min = \gcd(\text{all elements})$$タスクは、この条件を満たすサブ配列の数を数えることです。 

最初の直感は、すべてのサブ配列を調べて、その最小値、最大値、GCD を計算することです。 それはすぐに不可能になります。 順列の長さは最大で`2·10^5`、すべてのテスト ケースの長さの合計も`2·10^5`。 すべてをチェックするソリューション`O(n^2)`GCD と極値の計算コストを考慮する前でさえ、サブ配列はすでに遅すぎます。 

この問題の興味深い部分は、配列が順列であることです。 すべての値は個別です。 この制限により、状態は当初の見た目よりもはるかに強力なものになります。 

よくある間違いは、より長いサブ配列が条件を満たす可能性があると想定することです。 部分配列を考えてみましょう`[2,4,6]`。 その最大値から最小値を引いたものは、`4`、その GCD は`2`, だからダメなんです。 さらに重要なことは、順列では、長さが少なくとも 3 の適切な部分配列は実際には不可能であるということです。その理由は後で導き出します。 

もう 1 つの簡単な間違いは、単一要素のサブ配列は決して良いものではないということを忘れていることです。 例えば、`[5]`もっている$$\max - \min = 0$$しかし$$\gcd(5)=5.$$条件は失敗します。 

実際の構造を明らかにする小さな例は次のとおりです。`[2,1]`。$$\max-\min = 1, \qquad \gcd(2,1)=1.$$このサブアレイは良いですね。 同じことが起こります`[4,2]`:$$\max-\min = 2, \qquad \gcd(4,2)=2.$$これらの例は、次の形式のペアのみが存在することを示唆しています。`(x,2x)`働くことができます。 

## アプローチ

 ブルート フォース ソリューションでは、すべてのサブ配列がチェックされます。 それぞれについて、最小値、最大値、GCD を計算し、条件をテストします。 がある`O(n^2)`サブアレイ。 範囲情報が増分的に維持されたとしても、合計作業量は少なくとも 2 次です。 と`n = 2·10^5`、つまり、おおよその意味です`4·10^10`最悪の場合はサブアレイになりますが、これは完全に不可能です。 

何かをより早く見つけるには、条件が何を意味するのかを理解する必要があります。 

サブ配列が良好で、その GCD が`g`。 

GCD はすべての要素を分割するため、部分配列内のすべての要素は次の倍数になります。`g`。 

条件が言うには$$\max - \min = g.$$最小限にしておきます`m`。 なぜなら`g`すべての要素を分割します、それは分割します`m`。 そのときの最大値は、`m + g`。 

今度は間隔を見てください`[m, m+g]`。 の倍数のうち、`g`、この間隔には 2 つの値のみが含まれます。$$m,\quad m+g.$$部分配列のすべての要素は次の倍数でなければなりません`g`、すべての要素は最小値と最大値の間にある必要があります。 これにより、これら 2 つの値だけが残ります。 

配列は順列であるため、値は個別です。 サブ配列には、いずれかの値のコピーを繰り返し含めることはできません。 

したがって、適切な部分配列には最大 2 つの要素を含めることができます。 

長さ 1 は不可能です。`max-min=0`while the GCD is positive. したがって、適切なサブ配列には必ず 2 つの要素があります。 

これら 2 つの値を次のようにします`a < b`。 

条件はこうなります$$b-a=\gcd(a,b).$$この共通の値を`g`。 それから$$a=gk,\qquad b=g(k+1).$$連続する整数は互いに素であるため、$$\gcd(a,b)=g\cdot\gcd(k,k+1)=g.$$これと組み合わせると、`b-a=g`与える$$a=g,\qquad b=2g.$$したがって、ペアは正確に次のようにする必要があります`(g,2g)`。 

全体の問題は、値が 2 倍の関係にある隣接する位置をカウントすることに帰着します。

 ## アルゴリズムのチュートリアル

 1. 答えをゼロに初期化します。 
2. すべての隣接するペアをスキャンします`(p[i], p[i+1])`。 
3. しましょう`x = min(p[i], p[i+1])`そして`y = max(p[i], p[i+1])`。 
4. かどうかを確認します。`y = 2x`。 

これはまさに上で導き出された特徴です。 適切な部分配列は長さが 2 でなければならず、その値は次のとおりでなければなりません。`(x,2x)`。 
5. 条件が成立する場合、答えをインクリメントします。 
6. すべての隣接するペアを処理した後、答えを出力します。 

### なぜ効果があるのか

 私たちは、すべての適切なサブ配列の長さが正確に 2 でなければならないことを証明しました。 その理由は、すべての要素が部分配列 GCD の倍数であるためです。`g`、最小値と最大値の間の距離はわずかです`g`。 その間隔には、次の 2 つの倍数のみが含まれます。`g`、つまり最小値と最大値そのものです。 

値を含む 2 要素の部分配列の場合`a < b`、状態になります。$$b-a=\gcd(a,b).$$この方程式は次の場合にのみ成立します。`b=2a`。 

アルゴリズムは、それらの隣接するペアを正確にカウントします。 カウントされたすべてのペアは良好であり、すべての良好なサブ配列はそれらのペアの 1 つである必要があります。 したがって、カウントは正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))

        cur = 0
        for i in range(n - 1):
            a = p[i]
            b = p[i + 1]

            if max(a, b) == 2 * min(a, b):
                cur += 1

        ans.append(str(cur))

    sys.stdout.write("\n".join(ans))

solve()
```解決策は数​​学的特性に直接従うものです。 

すべての適切な部分配列の長さは 2 であるため、ループは隣接するペアのみを検査します。 各ペアについて、小さい値と大きい値を取得して正規化します。 大きい値が小さい値の 2 倍である場合、ペアは正確に良好です。 

使用する`max(a,b) == 2 * min(a,b)`両方の注文が自動的に処理されるため、両方とも`[x,2x]`そして`[2x,x]`カウントされます。 

最終的な実装では GCD 計算は必要ありません。 数論的分析はそれを完全に排除します。

 ## 特殊なケース

 ### 単一要素のサブ配列

 次のことを考慮してください。```
[5]
```単純な導出では長さ 1 の部分配列を忘れてしまう可能性があります。 

ここ：$$\max-\min=0, \qquad \gcd=5.$$条件は失敗します。 私たちのアルゴリズムは隣接するペアのみを検査するため、それらをカウントすることはありません。 

### 逆順ダブリングペア

 入力:```
n = 2
p = [4,2]
```このペアは次の条件を満たします。$$4-2=2, \qquad \gcd(4,2)=2.$$値が大きい方が優先されても問題ありません。 

実装では以下を使用します。```
max(a, b) == 2 * min(a, b)
```したがって、両方の注文は同じように処理されます。 

### 有望と思われる長い部分配列

 次のことを考慮してください。```
[2,4,6]
```すべての値は次の倍数です`2`, これは、サブ配列が優れていると誰かに思わせる可能性があります。 

実際には:$$\max-\min=4, \qquad \gcd=2.$$条件は失敗します。 

この証明は、より強力なことを示しています。少なくとも 3 つ以上の長さの部分配列は、順列では決して適切ではありません。 そのため、隣接するペアのみをチェックするだけで十分です。 

### 差が 1 に等しいペア

 次のことを考慮してください。```
[2,3]
```違いは`1`、 しかし$$\gcd(2,3)=1.$$このペアは次の形式ではありません`(x,2x)`それでも、次の方程式は満たされます。 

待って、確認しましょう:$$3-2=1, \qquad \gcd(2,3)=1.$$これは実際に良いペアです。 以来`x=1`、特性化により値が得られます`(1,2)`、 ない`(2,3)`。 

間違いは、違いだけで十分だと想定していることです。 この条件は GCD と等しいことが必要です。 のために`[2,3]`、GCD が次のとおりであるため、このペアは確かに優れています。`1`。 

2 要素配列の導出を振り返ると、次のようになります。$$b-a=\gcd(a,b).$$させて`g = gcd(a,b)`。 書き込み`a=gk`そして`b=g(k+1)`力`k=1`したがって、`a=g`そして`b=2g`。 

のために`[2,3]`、 我々は持っています`g=1`、 しかし`a=2`、 ない`1`、したがって、特性はそれが良くないはずであると述べています。 直接確認する場合:$$3-2=1,\quad \gcd(2,3)=1.$$実際にその条件が成り立ちます。 

これにより、重要な代数ステップが明らかになります。 

から$$a=gk,\quad b=g(k+1),$$私たちは得ます$$b-a=g$$ごとに自動的に`k`だけでなく、`k=1`。 

したがって、2 要素の部分配列の実際の特徴は次のようになります。$$\gcd(a,b)=|a-b|.$$させる`a=gk`そして`b=g(k+1)`これは、連続する倍数に対して常に真であることを示しています。`g`。 

配列は順列であるため、適切な部分配列でも長さは 2 しかありませんが、ペア条件は次のようになります。$$\max(a,b)-\min(a,b)=\gcd(a,b).$$順列の場合、これは、その式を直接満たす隣接するペアをカウントすることを意味します。 

最終的に承認された実装では、以下を使用する必要があります。```
from math import gcd

if abs(a - b) == gcd(a, b):
    ans += 1
```ペアが好きだから`[2,3]`も有効です。
