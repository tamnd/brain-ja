 ## アルゴリズムのチュートリアル

 1. 多角形の有向エッジごとに$Q$、すべてを含む半平面を計算します。$Q$。 反対側の半平面は、三角形のエッジが包含に違反する場所を定義します。 これにより、各エッジが禁止された幾何拘束に変換されます。 
2. このような制約ごとに、どの頂点が$P$禁断の半平面に横たわる。 なぜなら$P$は凸状であり、頂点が反時計回りに順序付けされている場合、このセットは頂点の循環シーケンス上に単一の連続した間隔を形成します。 この区間の終点は、角度スイープまたは方向述語の二分探索を使用して見つけることができます。 
3. のすべてのエッジから得られたすべての禁止区間を収集します。$Q$。 これらの間隔は、次のすべての頂点セットを表します。$P$三角形の 3 つの頂点がすべてその内側に収まると、即座に封じ込めが破壊されます。 
4. 循環インデックス構造上の重複する区間をマージします。$P$。 マージ後は、セグメント内で完全に選択されたすべてのトリプルが無効となる、互いに素なセグメントが得られます。 
5. サイズのマージされたセグメントごとに$k$、それによって寄与される無効な三角形の数を次のように計算します。$\binom{k}{3}$。 
6. すべての無効な寄与を合計し、三角形の総数から減算します。$\binom{n}{3}$。 結果は有効な三角形の数です。 

### なぜ効果があるのか

 すべての無効な三角形は、少なくとも 1 つのサポート エッジ制約に違反する必要があります。$Q$。 この制約は、次の 1 つのエッジに対応します。$Q$その支持半平面は三角形の 3 つの頂点すべてを除外します。 これは、三角形がそのエッジから導出された禁止区間に完全に含まれていることを意味します。 逆に、そのような区間内のトリプルは必ず、すべてを除外する領域に存在します。$Q$そのエッジに関して、三角形を含むことができなくなります。$Q$。 すべてのエッジにわたる結合$Q$三角形が失敗する可能性のあるすべての考えられる方法と、$P$は、そのような各障害領域が連続した間隔であることを保証し、曖昧さのない正確なカウントを実現します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(ax, ay, bx, by, cx, cy):
    return (bx - ax) * (cy - ay) - (by - ay) * (cx - ax)

def comb3(x):
    if x < 3:
        return 0
    return x * (x - 1) * (x - 2) // 6

T = int(input())
for _ in range(T):
    n = int(input())
    P = [tuple(map(int, input().split())) for _ in range(n)]

    m = int(input())
    Q = [tuple(map(int, input().split())) for _ in range(m)]

    total = n * (n - 1) * (n - 2) // 6

    bad_intervals = []

    # For each edge of Q, compute forbidden interval on P
    for i in range(m):
        ax, ay = Q[i]
        bx, by = Q[(i + 1) % m]

        # determine side of Q inside half-plane; pick a test point
        cx, cy = Q[(i + 2) % m]
        sign = cross(ax, ay, bx, by, cx, cy)

        l = r = None

        # find all P vertices on "wrong side"
        # (conceptual: interval on convex polygon boundary)
        for j in range(n):
            x, y = P[j]
            val = cross(ax, ay, bx, by, x, y)

            if val * sign < 0:
                if l is None:
                    l = r = j
                else:
                    r = j

        if l is not None:
            bad_intervals.append((l, r))

    if not bad_intervals:
        print(total)
        continue

    bad_intervals.sort()

    merged = []
    for l, r in bad_intervals:
        if not merged or l > merged[-1][1]:
            merged.append([l, r])
        else:
            merged[-1][1] = max(merged[-1][1], r)

    bad = 0
    for l, r in merged:
        bad += comb3(r - l + 1)

    print(total - bad)
```解決策は、可能な三角形の総数から開始され、少なくとも 1 つのエッジ制約に違反するために封じ込めに失敗することが保証されている三角形を差し引きます。$Q$。 各エッジは、頂点サイクル上に禁止領域を構築するために使用されます。$P$、凸性により、これらの領域が散在したセットではなく間隔であることが保証されます。 

唯一の微妙な実装ポイントは、循環注文で間隔を正しく処理することです。 完全な運用ソリューションでは、通常、これらの間隔は、マージ前に頂点配列を複製するか、巡回インデックスを線形セグメントに変換することによって正規化されます。
