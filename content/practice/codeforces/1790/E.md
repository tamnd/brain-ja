 ## 解決策
 ## 問題の理解

 この問題では、2 つの正の整数を見つけるように求められます。`a`そして`b`、数値が与えられる`x`、次の 2 つの条件が同時に成立します。`a XOR b = x`そして`(a + b)/2 = x`。 言い換えれば、Vlad は 2 つの数値の XOR を記憶しており、有効なペアを再構築するように求めます。`(a, b)`XOR と算術平均の両方に一致します。 入力は複数のテスト ケースで構成され、それぞれが 1 つの整数を持ちます。`x`。 各テスト ケースの出力は、条件を満たす正の整数のペアである必要があります。または、`-1`そのようなペアが存在しない場合。 

制約により許可されるのは、`x`まで`2^29`そして`t`まで`10^4`。 これらの境界は、反復処理を行うすべてのソリューションが、`a`または`b`まで直線的に`x`遅すぎるでしょう。 テスト ケースごとに一定時間で解を計算するアプローチが必要です。 特殊なケースには数字が含まれます`x`これらは奇数、または 2 の累乗マイナス 1 です。これらはペアが存在しないシナリオを作成する可能性があるためです。`(a, b)`両方の制約を満たすものが存在します。 たとえば、次のようなとき`x = 5`、整数はありません`a`そして`b`等式を満たすため、出力は次のようになります。`-1`。 

## アプローチ

 ブルートフォース手法では、すべての正の整数が列挙されます。`a`未満`2 * x`かどうかを確認してください`(a XOR (2*x - a)) == x`。 これは原理的には機能しますが、複雑さはテスト ケースごとに O(x) であり、これでは遅すぎます。`x`まで可能です`2^29`。 ブルートフォースは数学的には正しいですが、パフォーマンスの点では失敗します。 

重要な観察は代数的です。 2番目の条件から、`a + b = 2 * x`。 最初の条件を使用すると、`a XOR b = x`。 示す`b = 2 * x - a`、XOR 方程式は次のようになります。`a XOR (2*x - a) = x`。 これは、XOR が等しいというビット操作の問題に帰着します。`x`、`a`ここにのみビットが必要です`x`ゼロがあります。 構築できます`a`として`x + y`そして`b`として`x - y`、 どこ`y`それを満たす`x & y = 0`。 これにより、XOR の一致が保証されます`x`。 

この洞察により、テスト ケースごとに O(1) 時間で問題をビットマスク構築に変換できます。 もし`x`奇妙です、`(a + b)/2 = x`暗示する`(a + b)`は均等ですが、次の場合には達成できません。`x`奇数なので、答えは`-1`。 それ以外の場合は、選択できます`a = (x XOR (x/2))`そして`b = x/2`一つの有効な構造として。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取り、`t`。 
2. 各テスト ケースについて、整数を読み取ります。`x`。 
3. 次のことを確認します。`x`奇数です。 その場合は印刷してください`-1`なぜなら`(a + b)/2 = x`整数は保持できません`a`そして`b`。 
4. それ以外の場合は計算します`a`として`x + y`そして`b`として`x - y`、 どこ`y`次のような任意の数値です`x & y = 0`。 簡単な選択は、`y = x/2`。 
5. ペアを印刷します`(a, b)`。 

**なぜ機能するのか**: 不変条件は次のとおりです。`a = x + y`そして`b = x - y`と`x & y = 0`、 我々は持っています`(a + b)/2 = x`自動的にそして`a XOR b = x`。 これにより、XOR はオペランドの 1 つが 1 を持つビットのみを反転するため、正確さが保証されます。`x & y = 0`XOR が生成することを保証します。`x`正確に。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x = int(input())
        if x % 2 == 1:
            print(-1)
            continue
        # a + b = 2*x
        # Choose y = x / 2, which has no bits overlapping with x
        y = x // 2
        a = x + y
        b = y
        print(a, b)

if __name__ == "__main__":
    solve()
```この解決策は次のようになります`t`各テスト ケースを一定時間で処理します。 浮動小数点の問題を回避するために整数の除算を使用します。 選択する`y = x // 2`保証する`x & y = 0`なぜなら`x`は均等です。 これにより、両方が保証されます`(a + b)/2 = x`そして`a XOR b = x`所有。

## 特殊なケース

 のために`x = 1`、アルゴリズムは出力します`-1`なぜなら合計は`a + b = 2*x = 2`XOR を行って 2 つの正の整数に分割して 1 にすることはできません。`x = 2^29`、アルゴリズムは次のように構成します`a = 3 * 2^28`、`b = 2^28`、64 ビット整数でオーバーフローすることなく XOR および合計条件を満たします。 これらのエッジ ケースは、整数の除算とビット単位の構築を使用することで正しく処理されます。
