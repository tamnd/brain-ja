 ## 解決策
 ## 問題の理解

 小文字の文字列が与えられます$S$。 この文字列から、エリックは少し変わった方法で「禁止された単語」のファミリーを定義します。$S$、その任意の順列を形成し、その順列の任意の部分列を取得します。 この方法で形成できる個別の文字列はすべて禁止されているとみなされます。 

課題は、あらゆる長さをカウントすることです$k$1から$|S|$、長さの個別の禁止文字列の数$k$存在します。モジュロ 998244353。 

これを言い換えると、元の文字列内の位置にまったく制約されないということが分かります。 各キャラクターが何回登場するかだけを気にします$S$というのは、順列によって順序が消去され、サブシーケンスによって後で位置のサブセットを選択できるようになるからです。 したがって、構造は文字数に関して純粋に組み合わせになります。 

入力サイズ$|S| \le 10^5$すべてのサブシーケンスまたはすべての順列を明示的に反復するものは直ちに除外されます。 マルチセットの部分列の数は指数関数的に増加するため、正しい解を得るには、その構造を度数分布の計数式または生成関数 (通常は階乗や畳み込みのような推論を含む) に圧縮する必要があります。 

単純な間違いは、順列の部分列が固定文字列の部分列のように動作すると考えることです。 これは、配置ごとの単純な二項カウントを示唆しますが、ここでは順列によって位置のバイアスが完全に除去されるため、残っているのは、グローバルな長さの制約の下で各文字の多重度を独立して選択することだけです。 

すべての文字が区別できる場合、別の微妙な特殊なケースが発生します。 その場合、すべての順列はマルチセット構造の観点から同一であり、答えは二項係数に帰着します。 逆に、すべての文字が同一の場合、順列のすべてのサブシーケンスは長さのみによって決定され、同じ長さのすべての文字列が 1 つのタイプに集約されます。 

## アプローチ

 定義を直接シミュレートしようとすると、まず文字のマルチセットのすべての順列を生成し、次に順列ごとにすべてのサブシーケンスを列挙します。 たとえ小さな文字列であっても、この二重爆発は絶望的です。順列はすでに次のようにスケールされています。$\frac{n!}{\prod c_i!}$、およびサブシーケンスは別の要素を追加します$2^n$。 

重要な観察は、順列により位置が無関係になるということです。 重要なのは、選択した部分シーケンス内で各文字が何回出現するかだけであり、その文字がどこから来たのかではありません。 したがって、配置について考えるのではなく、選択した長さを文字タイプ全体に分散することを考える必要があります。 

文字の頻度を仮定します$c$は$f_c$。 有効な禁止語は、文字ごとに非負の整数を選択することに相当します。$x_c \le f_c$、合計の長さが次の文字列を形成します。$k = \sum x_c$。 固定ベクトルの場合$(x_c)$、生成される個別の文字列の数は次のとおりです。$$\frac{k!}{\prod x_c!}$$なぜなら、選択したカウントによって定義されるマルチセットの個別の順列をカウントしているからです。 

したがって、それぞれの長さに対して$k$、すべての整数ベクトルを合計しています。$x$合計金額で$k$、この多項係数の文字頻度によって制限されます。 

これはまさに、切り捨てられた指数母関数の積からの係数抽出です。$$\prod_{c} \left(\sum_{x=0}^{f_c} \frac{t^x}{x!}\right)$$私たちが望むのは、それぞれ$k$、乗算される係数$k!$。 したがって、次のように計算します。$$ans_k = k! \cdot [t^k] \prod_{c} \left(\sum_{x=0}^{f_c} \frac{t^x}{x!}\right)$$この構造は、文字に対する動的プログラミングを示唆しています。各文字は、その周波数で切り捨てられた多項式に寄与し、畳み込みは次のように行われます。$O(n^2)$素朴に、それは遅すぎます。 ただし、アルファベットのサイズは最大 26 であるため、長さにわたって DP 配列を維持し、文字ごとに有界たたみ込みを使用して更新できます。 制約$n \le 10^5$慎重な最適化が必要ですが、重要なのは、各文字がその頻度に基づいて小さな限定された更新に寄与し、効率を維持するために階乗と逆階乗を再利用することです。 

より効率的なビューは、文字を頻度別にグループ化し、貢献を段階的に蓄積する DP 遷移を実行し、部分積を表す多項式を更新することです。

 ## アルゴリズムのチュートリアル

 問題を長さにわたる周波数ベースの DP に圧縮します。 

### 1. 文字の頻度を数える

 私たちは計算します$f_c$文字ごとに。 これにより、有効なサブシーケンスのすべての制約が定義されます。 

このステップが重要なのは、順列によって順序が完全に削除され、周波​​数だけが構造として残されるためです。 

### 2. 階乗と逆階乗を事前計算する

 階乗を事前計算します。$n$およびその逆モジュール。 これにより、多項係数の高速計算が可能になります。 

これがなければ、各期$k! / \prod x_c!$繰り返し評価するには高価すぎるでしょう。 

### 3. DP の初期化

 私たちは定義します$dp[k]$全長を形成する処理された文字からの寄与の合計として$k$、ただし、正規化された形式のままです (次のように除算されます)。$k!$):$$dp[k] = [t^k] \prod_c \left(\sum_{x=0}^{f_c} \frac{t^x}{x!}\right)$$から始めます$dp[0] = 1$。 

### 4. 各文字種の処理

 頻度のある文字ごとに$f$、DP を更新します。 

新しい配列を計算します$ndp$、ゼロに初期化され、以前の可能な長さごとに$i$を追加してみます$j \in [0, f]$:$$ndp[i+j] += dp[i] \cdot \frac{1}{j!}$$全長を超えないようにする$n$。 

これは本質的に、事前に計算された逆階乗重みを使用した有界たたみ込みです。 

### 5. 実際の回答に戻す

 すべての文字を処理した後、次のように乗算します。$$ans[k] = dp[k] \cdot k! \pmod{998244353}$$これにより、組み合わせの意味が復元されます。以前は、畳み込みを管理しやすくするために階乗によって正規化していました。 

### なぜ効果があるのか

 DP のどの時点でも、$dp[k]$選択方法の加重合計を表します$k$処理された文字全体での出現の合計。$x$キャラクターからの出現が要因に寄与する$1/x!$。 この正規化により、独立した選択のマージが、より複雑な組み合わせではなく畳み込みに対応することが保証されます。 すべての文字が独立して選択されるため、積の構造が正確に保持され、次のように乗算されます。$k!$最後に、選択した文字数のマルチセットごとに異なる順列の正しい数を復元します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    s = input().strip()
    n = len(s)

    freq = [0] * 26
    for ch in s:
        freq[ord(ch) - 97] += 1

    fact = [1] * (n + 1)
    invfact = [1] * (n + 1)

    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD

    invfact[n] = pow(fact[n], MOD - 2, MOD)
    for i in range(n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    dp = [0] * (n + 1)
    dp[0] = 1

    for f in freq:
        if f == 0:
            continue
        ndp = [0] * (n + 1)
        for i in range(n + 1):
            if dp[i] == 0:
                continue
            val = dp[i]
            for j in range(f + 1):
                if i + j > n:
                    break
                ndp[i + j] = (ndp[i + j] + val * invfact[j]) % MOD
        dp = ndp

    res = []
    for k in range(1, n + 1):
        res.append(str(dp[k] * fact[k] % MOD))

    print(" ".join(res))

if __name__ == "__main__":
    solve()
```問題は多重度のみに依存するため、実装は文字の頻度をカウントすることから始まります。 階乗および逆階乗は一度計算されるため、正規化された DP 値と実際のカウントの間の高速変換が可能になります。 

DP 配列には、生成関数の係数が正規化された形式で格納されます。 各文字は、その可能な使用回数に対する制限された畳み込みに寄与します。 ネストされたループオーバー$i$そして$j$安全なので$j$は単一文字の頻度によって制限されます。 

最後に、各係数が次のように乗算されます。$k!$指数母関数表現を実際の組み合わせカウントに変換します。

MOD = 998244353

def solve_input(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    s = input().strip()
    n = len(s)

    freq = [0] * 26
    for ch in s:
        freq[ord(ch) - 97] += 1

    fact = [1] * (n + 1)
    invfact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD
    invfact[n] = pow(fact[n], MOD - 2, MOD)
    for i in range(n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    dp = [0] * (n + 1)
    dp[0] = 1

    for f in freq:
        if f == 0:
            continue
        ndp = [0] * (n + 1)
        for i in range(n + 1):
            if dp[i] == 0:
                continue
            for j in range(f + 1):

def run(inp: str) -> str:
    return solve_input(inp)

 ## 特殊なケース

 次のような単一文字列の場合`a`、DP は次から始まります`dp[0]=1`1 つの周波数 1 文字を処理し、`dp[1]=1`。 乗算後$1!$、出力は`1`これは、長さ 1 の空ではない禁止語が 1 つだけ存在するという事実と一致します。
