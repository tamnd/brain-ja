 ## 解決策
 ## 問題の理解

 2 つの正の整数を作成する必要があります`x`そして`y`それらの二乗の差が指定された非負の整数に等しくなるようにする`n`:\[
x^2-y^2=n
\]出力では式自体の値は求められません。 それを生成する実際の数値のペアを要求します。 そのような正のペアが存在しない場合は、次のように出力します。`No`。 

入力値は次のように大きくできます。\(2^{60}\)なので、次の値を試してみます`x`または`y`一つ一つは無理です。 解決策では、検索ではなく式の数学的構造を使用する必要があります。 答えの値自体は次のとおりです。\(2^{62}-1\)、これは依然として Python 整数に快適に適合します。 

主なエッジ ケースは、パリティと非常に小さな値から発生します。 例えば、`n = 2`解決策がありません。 魅力的なアプローチとしては、次のように書こうとするかもしれません。`2 * 1`、ただし、二乗の差の 2 つの要素は同じパリティを持たなければなりません。 のために`n = 4`、因数分解`2 * 2`与える`x = 2, y = 0`、これは無効です。`y`ポジティブである必要があります。 のために`n = 1`、通常の構造では次のようになります。`x = 1, y = 0`、これも陽性要件を満たしません。 のために`n = 0`ただし、ペア`x = 1, y = 1`動作します。 

これらのケースの例は次のとおりです。 

| 入力 | 正しい出力 |
 |---|---|
 |`2`|`No`|
 |`4`|`No`|
 |`1`|`No`|
 |`0`|`Yes`に続く`1 1`|

 ## アプローチ

 直接的なアプローチは、可能な値を試してみることです。`y`かどうかを確認してください`y^2+n`は正方形です。 可能な最大値は次のとおりです。\(2^{60}\)したがって、何百万もの候補者をチェックするアプローチであっても、あまりにも時間がかかりすぎます。 

有用な変換は二乗の差の公式から得られます。\[
x^2-y^2=(x-y)(x+y)
\]させて：\[
a=x-y,\quad b=x+y
\]次に、次のものが必要です。\[
a \cdot b=n
\]そして次のように回復できます。\[
x=\frac{a+b}{2},\quad y=\frac{b-a}{2}
\]2つの要因`a`そして`b`それらの和と差は両方とも偶数でなければならないため、同じパリティを持つ必要があります。 

もし`n`が奇数である場合、その要素はすべて奇数です。 最も簡単な選択は、`a = 1`そして`b = n`。 これにより、次のようになります。\[
x=\frac{n+1}{2},\quad y=\frac{n-1}{2}
\]これは次の場合を除いて機能します`n = 1`を生成するため、`y = 0`。 

もし`n`が偶数である場合、両方の要素が偶数である必要があります。 これはまさに次の場合に可能です`n`は 4 で割り切れます。選択できます`a = 2`そして`b = n/2`。 これにより、次の限り有効なペアが作成されます。`b > a`を除きます。`n = 4`。 

ブルートフォース手法は定義を直接チェックするため機能しますが、式の中に隠された因数分解は無視されます。 因数分解により、問題は定数時間のパリティ チェックに変わります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 |---|---|---|---|
 | ブルートフォース | O(√n) 以上 | お(1) | 遅すぎる |
 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`n`。 ハンドル`n = 0`別途出力することで`x = 1, y = 1`なぜなら、等しい正の数は二乗差がゼロだからです。 

2. もし`n`奇数である場合は、因数ペアを使用してください`1`そして`n`。 計算:\[
   x=(n+1)/2,\quad y=(n-1)/2
   \]次の場合は結果を拒否します`y`必要な数値は正の値でなければならないため、ゼロになります。 

3. もし`n`が偶数である場合、まず 4 で割り切れるかどうかを確認します。割り切れない場合は、次の 2 つの要素を計算します。`n`両方を偶数にすることはできないため、有効な因子のペアは存在しません。 

4. 4 で割り切れる数には因数を使用します`2`そして`n/2`。 計算:\[
   x=\frac{2+n/2}{2},\quad y=\frac{n/2-2}{2}
   \]次の場合は拒否します`y`はゼロです。 

5. 構築されたペアを印刷します。 

なぜ機能するのか: 二乗の差の有効な表現はすべて 2 つの要素に対応します`(x-y)`そして`(x+y)`等しいパリティで。 このアルゴリズムでは、考えられるすべてのパリティ クラスに対して最も単純な因子のペアが考慮されます。 奇数には常に奇数の因数ペアが含まれます。 4 で割り切れる数値には偶数の因数ペアがあります。 残りの数値はすべてパリティ要件を満たすことができないため、2 つの正の二乗の差として表すことができません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    if n == 0:
        print("Yes")
        print("1 1")
        return

    if n & 1:
        x = (n + 1) // 2
        y = (n - 1) // 2
        if y > 0:
            print("Yes")
            print(x, y)
        else:
            print("No")
        return

    if n % 4 != 0:
        print("No")
        return

    b = n // 2
    x = (2 + b) // 2
    y = (b - 2) // 2

    if y > 0:
        print("Yes")
        print(x, y)
    else:
        print("No")

if __name__ == "__main__":
    solve()
```最初のブランチはゼロのケースのみを処理します。 等しい値を使用します。`x`そして`y`これにより、両方の数値が正の値に保たれます。 

奇数分岐は因数分解を使用します`n = 1 * n`。 パリティによって結果が整数であることが保証されるため、計算は整数の除算で記述されます。 明示的な`y > 0`チェックにより、無効な出力が防止されます`n = 1`。 

偶数分岐は 4 で割り切れない数値を拒否します。残りの値には因数ペアが含まれます。`2`そして`n/2`。 最終チェックでは無効なケースが削除されます`n = 4`、ここで唯一可能なペアは`y = 0`。 

Python の整数はオーバーフローしないため、上限に近い値は直接処理されます。 重要な境界は数値オーバーフローではなく、`y`ポジティブなままです。

import sys
import io

def solve_data(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    n = int(sys.stdin.readline())

    if n == 0:
        ans = "Yes\n1 1"
    elif n & 1:
        x = (n + 1) // 2
        y = (n - 1) // 2
        if y > 0:
            ans = f"Yes\n{x} {y}"
        else:
            ans = "No"
    elif n % 4 != 0:
        ans = "No"
    else:
        b = n // 2
        x = (b + 2) // 2
        y = (b - 2) // 2
        if y > 0:
            ans = f"Yes\n{x} {y}"
        else:
            ans = "No"

    sys.stdin = old_stdin
    return ans

 ## 特殊なケース

 のために`n = 2`、アルゴリズムは偶数分岐に入ります。 以来`2`4 で割り切れない場合、すぐに出力されます`No`。 これにより、因子を使用するという誤った考え方を回避できます。`1`そして`2`、パリティが異なります。 

のために`n = 4`、アルゴリズムは数値が 4 で割り切れることを検出し、偶数の因数のペアを試行します。`2`そして`2`。 これにより、`x = 2`そして`y = 0`, そのため、陽性チェックでは拒否されます。 出力は`No`。 

のために`n = 1`、奇妙な構造により、`x = 1`そして`y = 0`。 アルゴリズムは 2 番目の値が無効であることを検出し、次の値を出力します。`No`。 

のために`n = 0`の場合、因子ペアのアプローチは不要であるため、アルゴリズムは因数分解を使用しません。 直接返却します`x = 1`そして`y = 1`、満足：\[
1^2-1^2=0
\]次のような大きな値の場合、`n = 2^60`、アルゴリズムはいくつかの算術演算のみを実行します。 構築された値は依然として必要な値を下回っています\(2^{62}-1\)制限があるため、同じロジックが最大入力サイズでも機能します。
