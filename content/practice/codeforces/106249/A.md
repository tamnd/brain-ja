 ## 問題の理解

 文字だけからなる文字列が与えられます`M`、`I`、 そして`T`。 操作により部分文字列が変更される場合があります`MIT`の中へ`TIM`またはその逆。 目標は、任意の数の操作を実行し、多数の操作を連続して発生させることです。`MITIT`できるだけ大きく。 

重要な観察は、操作は単にデータを交換するだけであるということです。`M`そして`T`固定のあたり`I`。 を含むポジション`I`決して変わらない。 すべてのテスト ケースの入力サイズは最大でも$10^5$、だから、$O(n^2)$操作のシミュレーションや、多くの最終文字列の試行は不可能です。 各文字を一定の回数だけ処理する必要があります。 

よくある間違いは、操作によって文字の順序が変更されるため、文字を自由に並べ替えることができると考えることです。`M`そして`T`。 それはできません。 たとえば、`MIMT`、`I`位置は固定されたままなので、最初の`I`最初の 2 つの非`I`ポジション。 合計数をカウントするだけのソリューション`M`、`I`、 そして`T`失敗します。 

文字列を考えてみましょう`MIMTI`。 2つあります`I`文字はありますが、作成することはできません`MITIT`、決勝だから`T`2回目以降`I`存在しません。 正しい答えは、`0`。 カウントのみに基づいた不注意な解決策では、発生が 1 つであるため、誤って 1 つの発生を期待する可能性があります。`M`、 二`I`、そして2つ`T`文字。 

もう 1 つの特殊なケースは、必要な文字は存在するが、`I`立場によって会うことが妨げられます。 のために`MMITT`、カウントは十分です`MITIT`、しかし2つではありません`I`文字を必要な距離に配置します。 答えは`0`、運営が動けないので。`I`文字。 

## アプローチ

 ブルート フォース アプローチでは、操作を通じて到達可能なすべての文字列を理解しようとします。 すべての操作で 2 つの文字が交換されるため、さまざまな交換を試して、見つかった最良の結果を維持する可能性があります。 これは正しいです。すべての有効な最終的な配置は、何らかの一連の操作によって到達可能ですが、可能な配置の数は指数関数的に増加するため、長さの文字列には使用できません。$10^5$。 

重要な構造は、単一の操作が実際に何を行うのかを調べることで得られます。 変革`MIT <-> TIM`2つの非を交換するだけです`I`1つあたりの文字`I`。 これが意味するのは、`I`ポジションは永久に固定されます。 非`I`位置は、キャラクターが動き回ることができるグループを形成します。 

2 つ以外のものを接続すると、`I`ちょうど 1 つがある場合は常に位置を指定します`I`それらの間では、すべての操作は 1 つの接続されたコンポーネント内での単なるスワップです。 コンポーネント内では、すべて`M`そして`T`文字を任意に並べ替えることができます。 

あ`MITIT`発生では 3 つの非`I`ポジション。 これらの位置は 2 つずつ区切られています`I`文字なので、常に同じコンポーネントに属します。 これは、すべてのコンポーネントを独立して解決できることを意味します。 

1 つのコンポーネント内で、その長さが次のようになっているとします。`len`そしてそれには含まれています`m`キャラクター`M`そして`t`キャラクター`T`。 長さ 3 つのパターンの数を最大化する必要があります`MTT`。 このようなパターンには必ず 1 つ必要です`M`そして2つ`T`文字、および異なるオカレンスが同じ開始位置を共有することはできません。 最大値は次のとおりです。$$\min(m,\lfloor t/2\rfloor,\lfloor len/3\rfloor)$$この値は、それぞれを配置することで常に達成可能です。`M`続いて2つ`T`文字を削除し、未使用の文字には残りの位置を使用します。

 ## アルゴリズムのチュートリアル

 1. 文字列をスキャンし、非接続コンポーネントを構築します。`I`ポジション。 2 つの非`I`位置が 1 つだけ存在する場合、同じコンポーネントに属します。`I`彼らの間で。 これは、連続する非をグループ化することと同等です。`I`を介して接続されている同じパリティを持つポジション`I`ポジション。 
2. 各コンポーネントのサイズと数を数えます。`M`キャラクターと`T`その中の文字。 操作によりコンポーネント内でこれらの文字を再配置できるため、現在の配置は無関係です。 
3. コンポーネントの寄与を利用可能な数の最小値として計算します。`M`使用可能な文字の半分`T`文字数、コンポーネントの長さの 3 分の 1。 各値は、必要な 1 つのリソースを表します。`MITIT`パターン。 
4. すべてのコンポーネントの寄与を追加します。 どのオカレンスも 2 つの異なるコンポーネントの文字を使用できないため、合計がグローバル最大値になります。 

機能する理由: 不変条件は、すべての操作ですべての情報が維持されることです。`I`ポジションは固定され、スワップのみ`M`そして`T`接続されたコンポーネント内で。 可能性のある`MITIT`発生には 3 つ以外のものが必要です`I`2つで繋がる位置`I`したがって、単一のコンポーネント内に留まる必要があります。 各コンポーネントは自由に並べ替えることができるため、唯一の制限はコンポーネントの数だけです。`M`、`T`、利用可能な長さ。 この式はこれらの制限を正確に捉えているため、計算された合計は最適になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(s):
    n = len(s)
    seen = [False] * n
    ans = 0

    for i in range(n):
        if s[i] == 'I' or seen[i]:
            continue

        stack = [i]
        seen[i] = True
        length = 0
        m = 0
        t = 0

        while stack:
            x = stack.pop()
            length += 1
            if s[x] == 'M':
                m += 1
            else:
                t += 1

            for y in (x - 2, x + 2):
                if 0 <= y < n and not seen[y] and s[(x + y) // 2] == 'I' and s[y] != 'I':
                    seen[y] = True
                    stack.append(y)

        ans += min(m, t // 2, length // 3)

    return ans

def main():
    data = sys.stdin.read().split()
    if not data:
        return
    t = int(data[0])
    out = []
    for i in range(1, t + 1):
        out.append(str(solve_case(data[i])))
    print("\n".join(out))

main()
```このソリューションでは、非暗黙的なグラフに対して深さ優先検索を使用します。`I`ポジション。 エッジは 2 つの位置が一致する場合にのみ存在します。`I`このため、近隣チェックでは距離 2 が使用されます。 

DFS は、1 つのコンポーネントのサイズと各文字の量を収集します。 コンポーネント内の文字の実際の順序は、入れ替えによって再配置できるため不要です。 最終的な最小計算では、ビルドのリソース制限が直接適用されます。`MTT`に対応するトリプル`MITIT`部分文字列。 

隣接ループの境界チェックにより、文字列の外側へのアクセスが防止されます。 真ん中のインデックス`(x + y) // 2`安全なので`y`は常にからちょうど 2 位置離れています`x`。

 ## 特殊なケース

 のために`MIMTI`、アルゴリズムは非コンポーネントからコンポーネントを作成します。`I`ポジション。 を含むコンポーネント`M`そして`T`ポジションのスペースが不十分であり、`T`完全な文字`MTT`パターンなので貢献度はゼロです。 

のために`MMITT`、二人`I`文字が必要な位置にありません`MITIT`。 コンポーネントは固定を中心に構築されているため、`I`アルゴリズムがこれらの文字を誤ってマージし、ゼロを返すことはありません。 

すでに等しい文字列の場合`MITIT`、3つとも非`I`位置は 1 つのコンポーネントに属します。 コンポーネントの長さは 3 で、1 つあります`M`そして2つ`T`文字、与えるもの:$$\min(1, 2/2, 3/3)=1$$したがって、答えは1つです。 これにより、メソッドが最も単純な発生を処理することが確認されます。
