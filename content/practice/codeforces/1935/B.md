 ## 解決策
 ## 問題の理解

 0 から 0 までの整数の配列が与えられます。$n-1$、すべてのサブセグメントが同じ MEX を持つように、それを少なくとも 2 つの連続するサブセグメントに分割する必要があります。 サブ配列の MEX は、そのサブ配列から欠落している最小の非負の整数です。 たとえば、MEX([0, 1, 3]) = 2 となります。0 と 1 は存在しますが、2 は存在しないためです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは配列の長さを提供します$n$そして配列自体。 適切な分割が存在しない場合、出力は -1 になるか、各サブセグメントが同じ MEX を持つ一連のサブセグメント境界のいずれかでなければなりません。 サブセグメントは連続していて、配列全体をカバーする必要があります。 

制約が教えてくれる$n$まで行くことができます$10^5$、との合計$n$すべてのテスト ケースでは、次の制限もあります。$10^5$。 これにより、テスト ケースあたりの時間が線形よりも悪いソリューションは除外されます。 MEX を計算してセグメント境界を大まかに決定するアプローチが必要です。$O(n)$時間。 

微妙なエッジ ケースには、要素が繰り返される配列、0 または 1 が欠落している配列、0 から最大値までの全範囲の整数が既に含まれている配列などがあります。 たとえば、配列 [0, 1, 2] は、同じ MEX を持つ複数のサブセグメントに分割できません。配列全体の MEX が 3 であるためです。ただし、各セグメントに 0、1、2 が含まれる少なくとも 2 つのセグメントに分割する方法はなく、3 が MEX のままになります。 単純なアプローチでは恣意的に分割しようとする可能性がありますが、このような場合には失敗します。 

## アプローチ

 強引な解決策は、配列の可能なすべてのセグメント化を試し、各セグメントの MEX を計算し、それらが等しいかどうかを確認することです。 これは、あらゆる可能な分割を考慮しているため、原理的には正しいです。 ただし、分割数は指数関数的になります。$n$、以下の長さの配列は不可能になります。$10^5$。 

最適なソリューションのための重要な洞察は、MEX の定義から得られます。 配列全体の MEX がわかっている場合は、それを呼び出します$m$、0 から 0 までのすべての数字を含まないセグメント$m-1$MEXは持てません$m$。 逆に、0 から 0 までのすべての数字を含むセグメントは、$m-1$MEXを持っています$m$、追加番号に関係なく。 したがって、問題は、それぞれに 0 から 0 までのすべての数字が含まれる連続したブロックを見つけることになります。$m-1$。 

その後、アルゴリズムは配列をスキャンし、すべての数値が 0 から 0 までになるまで現在のセグメントを拡張します。$m-1$そのセグメントで見られました。 それらが完了すると、セグメントは終了し、新しいセグメントが開始できます。 配列を少なくとも 2 つのそのようなセグメントに分割できれば、有効な解決策が得られます。 最後まで到達してもセグメントが 2 つ未満の場合は不可能です。

 ## アルゴリズムのチュートリアル

 1. MEX を計算する$m$配列全体の。 これは、0 から 0 までの数値の周波数配列を作成することによって行われます。$n$そして、出現回数がゼロの最初のインデックスを見つけます。 これにより、すべてのセグメントのターゲット MEX が得られます。 
2. もし$m = 0$、すべての要素は少なくとも 1 です。この場合、どのセグメントも MEX 0 を持つため、配列を任意に 2 つのセグメント [1,1] と [2,n] に分割できます。 この分割を返します。 
3. 0 から 0 までの数値のカウンタ辞書を初期化します。$m-1$、現在のセグメントで必要な各数値が何回出現したかを追跡します。 また、セグメント境界と現在のセグメントの左境界の変数を格納するために空のリストを初期化します。 
4. 配列を左から右に繰り返します。 各要素について、それが以下の場合$m$、カウンターをインクリメントします。 各増分後、0 から 0 までのすべての数値が正しいかどうかを確認します。$m-1$現在のセグメントで見られます。 「はい」の場合は、右側の境界を記録してセグメントを閉じます。 次のインデックスから新しいセグメントを開始し、カウンターをリセットします。 
5. アレイをスキャンした後、少なくとも 2 つのセグメントが形成されているかどうかを確認します。 「はい」の場合は返却してください。 セグメントが 1 つだけ存在する場合は、問題には少なくとも 2 つのサブセグメントが必要であるため、-1 を出力します。 
6. セグメントの数とセグメント境界を出力します。 

正確さは、各閉じたセグメントに 0 から 0 までのすべての数値が含まれるという不変条件を維持することで得られます。$m-1$、その MEX が$m$。 左から右にスキャンすることで、セグメントの数が最大になり、セグメントが連続していることが保証されます。 結果のセグメントが 2 つ未満の場合は、有効な分割が存在しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        present = [0] * (n + 1)
        for x in a:
            if x <= n:
                present[x] += 1
        mex = 0
        while present[mex]:
            mex += 1
        if mex == 0:
            print(2)
            print(1,1)
            print(2,n)
            continue
        from collections import defaultdict
        counter = defaultdict(int)
        required = set(range(mex))
        segments = []
        l = 0
        for r, x in enumerate(a):
            if x < mex:
                counter[x] += 1
            while all(counter[i] > 0 for i in range(mex)):
                segments.append((l+1, r+1))
                l = r+1
                counter = defaultdict(int)
        if l != n:
            segments.append((l+1, n))
        if len(segments) < 2:
            print(-1)
        else:
            print(len(segments))
            for seg in segments:
                print(seg[0], seg[1])

if __name__ == "__main__":
    solve()
```コードは最初に配列全体の MEX を計算します。 MEX がゼロの場合、単純な分割が使用されます。 それ以外の場合は、配列をスキャンし、必要なすべての数値が 0 から 0 までになるまでセグメントを拡張します。$m-1$が含まれています。 各閉じたセグメントが記録されます。 最後にチェックを行うと、少なくとも 2 つのセグメントが存在することが確認されます。 カウンタは各セグメントの後にリセットされ、次のサブアレイを独立して追跡します。
