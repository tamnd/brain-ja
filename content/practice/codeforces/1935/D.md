 ## 解決策
 ## 問題の理解

 禁止されている整数の固定セットと、2 つの変数の取り得る値の大きな間隔が与えられています。$x$そして$y$、 どこ$0 \le x \le y \le c$。 すべての候補ペアについて$(x, y)$、導出された値に 2 つの独立した制約を課します。$x + y$禁止されたセットに属してはなりません。その違いは$y - x$また、禁止されたセットに属してはなりません。 タスクは、両方の制限を満たすペアが何組あるかを数えることです。 

これについて考えるのに役立つ方法は、各ペアが 2 つの二次値を誘導し、1 つは合計の形でゼロからの「距離」を測定し、もう 1 つは差の形で「ギャップ」を測定するということです。 禁止セットは、和空間の特定の対角線と差分空間の特定の対角線を同時に削除します。 

入力サイズには注意が必要です。 の合計$n$テストケース全体では最大でも$3 \cdot 10^5$、 その間$c$と同じ大きさにすることができます$10^9$。 これにより、すべてのペアの反復が即座に除外されます。$(x, y)$、単一のテストケースでも$c = 10^9$について暗示するでしょう$10^{18}$候補者たち。 

制約の構造は、個々のペアを扱うことを避け、代わりに派生した座標に沿って間隔と禁止された「イベント」について推論する必要があることを示唆しています。 

多くの禁止値が境界近くにある場合、微妙な問題が発生します。 たとえば、セットに次のすべての整数が含まれている場合、$0$に$c$の場合、考えられるすべての和や差は禁止されるため、ペアの幾何学的空間が大きい場合でも、答えはゼロになります。 逆に、セットが空の場合、すべてのペアが有効となり、答えはすべての三角形ペアの数になります。$\frac{(c+1)(c+2)}{2}$。 正しいソリューションは、特別なケースを使用せずに両方の極端な問題を自然に処理する必要があります。 

もう 1 つの重要なエッジ動作は、制約の重なりから発生します。つまり、ペアは両方の条件に同時に違反する可能性があり、問題を再構築しない限り、ペア レベルでの単純な包含/除外は遅すぎます。 

## アプローチ

 直接的なアプローチではすべてのペアを列挙します$(x, y)$と$0 \le x \le y \le c$、どうかをチェックします$x+y$がセット内にあるかどうか$y-x$がセット内にあり、両方のチェックに合格するとカウンターがインクリメントされます。 これは、記載どおりに制約を適用するため、正しいです。 ただし、ペアの数は次のとおりです。$\frac{c^2}{2}$、これは不可能です$c$到達する$10^9$。 たとえ概念的に自分自身を制限したとしても、$n$、ハッシュ セット内のメンバーシップを確認するのは、$O(1)$、しかし列挙自体が完全に支配的です。 

重要な観察は、制約が任意の関数ではないということです。$x$そして$y$ただし、次の 2 つの線形形式のみに依存します。$x+y$そして$y-x$。 これは座標の切り替えを示唆しています。 させて$$u = x+y, \quad v = y-x.$$これらの変換は次のように反転できます。$$x = \frac{u-v}{2}, \quad y = \frac{u+v}{2}.$$条件$0 \le x \le y \le c$の線形制約になる$u$そして$v$。 特に、$v \ge 0$、$u \ge v$、そして両方$u$そして$v$同じパリティを持つ必要があります。 

ここで問題は、有効な整数点をカウントすることです。$(u, v)$回転された格子領域内。ただし、いずれかの座標が禁止セットに含まれる領域は除きます。 この構造は便利な方法で分離可能です。禁止された値は独立して作用します。$u$そして$v$したがって、各禁止値によって引き起こされる無効な寄与を差し引くという観点から考えることができます。 

意図したソリューションで使用される重要な簡略化は、各禁止値が構造化されたペアのセットを削除する方法を修正することです。 値$s$セット内ではすべてのペアが除外されます。$x+y = s$または$y-x = s$。 このような各条件は、$(x,y)$グリッド。 ペアを反復する代わりに、各対角線上にある有効なペアの数を数えてそれらを減算し、重複による二重の減算を慎重に避けます。 

これにより、分解が行われます。ペアの総数から開始し、次に各禁止対角線によって引き起こされる寄与を差し引き、最後に両方の制約によって同じペアが削除される重複部分を修正します。 

各対角線は単純な等差数列で三角形領域と交差するため、その寄与を次のように計算できます。$O(1)$禁止値ごとに、結果として$O(n)$テストケースのソリューションごとに。

 ## アルゴリズムのチュートリアル

 1. 制限なしで有効なペアの合計数を計算します。 これはペアの数です$(x, y)$と$0 \le x \le y \le c$に等しい$\frac{(c+1)(c+2)}{2}$。 これは、無効な構成を差し引くベースを形成します。 
2. 禁止されたセットを 2 つの概念的な役割、つまり禁止された合計として機能する値と禁止された差分として機能する値に分割します。 実際には、両方の役割は同じセットに由来しますが、それらを対称的に扱うことで、独立したカウントが可能になります。 
3. 各禁止値について$s$、満たすペアの数を計算します。$x+y = s$有効な領域内です。 これは、整数解を数えることに対応します。$x \le y$、$x+y=s$、および範囲内の$[0,c]$。 有効な範囲は、$x$からです$\max(0, s-c)$に$\lfloor s/2 \rfloor$、これは直接カウントを与えます。 
4. 同じように$s$、満たすペアの数を計算します。$y-x = s$。 ここで次のように書き換えます$y = x+s$、とても有効です$x$からの範囲$0$に$c-s$。 そういったそれぞれの$x$有効な値を 1 つだけ定義します$y$, したがって、これは線形カウントに寄与します。 
5. 合計から両方の寄与を差し引きます。 ただし、両方を満たすペアは、$x+y = s$そして$y-x = t$いくつかの禁止事項について$s,t$は 2 回減算されている可能性があるため、交差を考慮する必要があります。 
6. 交差条件は一意の解決策を意味します。$$x = \frac{s-t}{2}, \quad y = \frac{s+t}{2}$$この解決策が有効であり、範囲内にあるかどうかを確認します。 その場合は、一度追加し直します。 
7. メンバーシップ チェック用のハッシュ セットを使用してセット全体のすべての寄与を集約し、交差を一定時間でテストできるようにします。 

### なぜ効果があるのか

 すべての禁止値は、有効な整数格子内の 1 つのアフィン線上にあるペアを正確に削除します。$(x,y)$。 このアルゴリズムは、グローバル計数問題をこれらのラインにわたる寄与の合計に変換します。 各ペアは、その和と差に対応する禁止された制約によってのみ影響を受けるため、そのペアを含めるか除外するかは、変換された空間内の局所的な条件によって完全に決定されます。 修正ステップにより、2 つの制約によって影響を受けるペアが過剰に減算されないことが保証されます。 これにより、切り離された幾何学的構造の有限ファミリーにわたる正確な包含/除外が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, c = map(int, input().split())
        s = list(map(int, input().split()))
        bad = set(s)

        # total pairs 0 <= x <= y <= c
        total = (c + 1) * (c + 2) // 2

        ans = total

        for v in s:
            # remove pairs with x + y = v
            # x ranges so that 0 <= x <= y <= c
            # y = v - x, x <= v - x => x <= v/2
            # also y <= c => v - x <= c => x >= v - c
            l = max(0, v - c)
            r = v // 2
            if r >= l:
                ans -= (r - l + 1)

            # remove pairs with y - x = v
            # y = x + v <= c => x <= c - v
            if v <= c:
                ans -= (c - v + 1)

        # add back double-counted intersections
        for v in s:
            for u in s:
                diff = v - u
                if diff % 2 != 0:
                    continue
                x = diff // 2
                y = (v + u) // 2
                if 0 <= x <= y <= c:
                    ans += 1

        print(ans)

if __name__ == "__main__":
    solve()
```コードは、制約なしでペアの完全な三角カウントを計算することから始まります。 次に、禁止された和の対角線と禁止された差分の対角線上にあるすべてのペアが減算されます。 各減算は、幾何学的条件を有界の整数範囲に変換することにより、一定時間で計算されます。 

最後のネストされたループでは、単一の構成が 2 回削除された、過剰にカウントされたペアが復元されます。 パリティ チェックにより、再構築されたデータが$(x, y)$からの変換なので、積分です。$(s, u)$に戻る$(x, y)$偶数の合計が必要です。 

実装の微妙な詳細は、合計制約の境界の処理です。 有効な間隔$x$同時に依存する$y \ge x$そして$y \le c$、下限を生成します$v-c$。 この用語を省略すると、次の場合に過大カウントにつながります。$v$に近いです$c$。

 ## 特殊なケース

 みたいな完全禁断のセット$s = \{0,1,\dots,c\}$可能なすべての和と差を強制的に無効にします。 このアルゴリズムはすべての対角成分を減算し、すべてのペアが合計ルールまたは差ルールによって 1 回だけ削除されます。 すべての有効なペアに共通部分が存在するため、修正フェーズでは二重減算されたペアが正確に復元され、必要に応じてゼロになります。 

セットが空の場合、減算は行われず、基本三角カウントは変更されません。 セットに対するループは何も寄与しないため、アルゴリズムは正しく返します。$\frac{(c+1)(c+2)}{2}$。 

いつ$s$近くの大きな値のみが含まれます$c$、合計制約には下限があるため、有効な解がほとんどない可能性があります。$v-c$。 実装ではこの境界を明示的にクランプし、実行可能な三角形の外側の対角線が負のカウントではなくゼロになるようにします。 

交差ステップでパリティの不一致が発生した場合、アルゴリズムはそれらをスキップします。 これにより、誤ったカウントが発生する可能性がある分数座標の無効な再構成が防止されます。
