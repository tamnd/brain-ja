 ## 問題の理解

 与えられた数値に適用される割り算ルールの種類を決定するように求められます。`d`与えられた基地内で`b`。 下数桁のみで割り算ができる場合（2タイプ）、桁の合計で割り算できる場合（3タイプ）、桁の交互の合計で割り算ができる場合（11タイプ）、2タイプと3タイプの組み合わせで割り算できる場合（6タイプ）、いずれも割り切れない場合（7タイプ）によって、2タイプ、3タイプ、11タイプ、6タイプ、7タイプに分類されます。 入力は 2 つの整数で構成されます。`b`そして約数`d`。 出力にはタイプを記載する必要があり、2 タイプの場合は、割り算を検証するために必要な最後の桁の最小数も記載する必要があります。 

制約`2 ≤ b, d ≤ 100`これは、最大の複雑さのアルゴリズムを許容できることを意味します。`O(d log b)`または`O(b * d)`最悪の場合でも操作が約 10,000 回になるため、パフォーマンスを心配する必要はありません。 以下のすべての数値をチェックする単純なアプローチ`d`基地内で`b`なぜなら、割り算ルールは予測可能な構造を持っているため、割り算は実現可能ですが、不必要だからです。 

明らかではないエッジケースには、次のような底の累乗である約数が含まれます。`b`それ自体は 1 桁のみの 2 タイプである必要があり、次のような数字が含まれます。`11`特定の塩基では 11 タイプのルールが適用されますが、塩基によっては 3 タイプのルールも機能する場合があります。 たとえば、基数 2 では、3 の割り算は 3 型ではなく 11 型の規則に従います。これは、基数 2 での桁の和のアプローチが交互の和になるためです。 

## アプローチ

 ブルートフォースアプローチでは、基数の最後の桁の固定数で表現できるすべての数値の割り切り可能性をチェックしようとします。`b`。 2 型の場合は、次のように繰り返します。`k = 1, 2, 3…`かどうかを確認してください`b^k`で割り切れます`d`またはすべての剰余をモジュロでカバーできます`d`。 3 タイプの場合、次のことを確認できます。`d`分割する`b-1`（または`b+1`11 タイプの場合）桁の合計ルールが基数に一般化されるため、`b`等比級数公式を使用: 任意の数値`N`基数の数字として表現される`b`満足する`N = a_0 + a_1*b + a_2*b^2 + … ≡ a_0 + a_1 + … (mod b-1)`。 同様に、11 タイプは次のものに依存します。`b+1`。 各タイプを順番 (2、3、11、6) でテストすると、最初に一致したものが答えになります。 どれも一致しない場合は、7 タイプです。 

重要な洞察は、2 型の可除性は、因数のみを共有する約数に対応するということです。`b`(または力`b`)、3型は割り算の約数に対応`b-1`、11 型は割り算の約数に対応します。`b+1`。 混合6型は、2型と3型の両方の要因が存在する場合に発生します。 これにより、すべての数値に対する反復処理が回避され、問題が単純なモジュロ チェックに軽減されます。

## アルゴリズムのチュートリアル

 1. ベースを読む`b`と約数`d`。 
2. の累乗をすべて因数分解して 2 タイプのルールをチェックします。`b`から`d`。 コンピューティング`k`そのような`b^k`の係数を法とするすべての剰余をカバーします`d`との共プライム`b`。 すべての権限を削除した後、`b`残りの係数は 1 であり、純粋に 2 タイプです。 
3. 次のことを確認して 3 タイプのルールをチェックします。`d`と互いに素である`b`そして分ける`b-1`。 これは、base の桁の合計プロパティから得られます。`b`。 その場合は 3-type を返します。 
4. 次のことを確認して 11 タイプのルールをチェックします。`d`分割する`b+1`。 これは、交互の数字の合計プロパティに対応します。 
5. 2 タイプと 3 タイプの両方の条件が同時に成立する場合は、6 タイプを報告します。 
6. 上記のいずれも当てはまらない場合は、7 タイプを「謎の」ルールとして報告します。 

機能する理由: この分類は、よく知られている数論的特性に基づいています。 底の因数による割り算には最後の桁のみが必要です。`b-1`桁の和と因数の後に続きます`b+1`交互に数字の合計が続きます。 これにより、数値を列挙しなくても正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

b, d = map(int, input().split())

def check_2_type(b, d):
    k = 1
    while pow(b, k, d) != 0:
        k += 1
    return k

def main():
    x = d
    # check 2-type: divide out gcd with base
    g = 1
    while x % b == 0:
        x //= b
        g *= b
    if x == 1:
        k = check_2_type(b, d)
        print("2-type")
        print(k)
        return
    # check 3-type: divides b-1
    if (b-1) % d == 0:
        print("3-type")
        return
    # check 11-type: divides b+1
    if (b+1) % d == 0:
        print("11-type")
        return
    # check 6-type: combination of 2-type and 3-type
    # already covered 2-type or 3-type separately, only possible if d divisible by both factors
    if (d % b == 0 or b % d == 0) and (b-1) % d == 0:
        print("6-type")
        return
    print("7-type")

main()
```の`check_2_type`関数は、割り切れる可能性をテストするために必要な最後の桁の最小数を見つけます。`d`基地内で`b`べき乗モジュロによる`d`。 まず減らします`d`の要因により`b`純粋に 2 タイプかどうかを確認します。 3 タイプと 11 タイプの割り算テスト`b-1`そして`b+1`桁の合計と交互の桁の合計ルールを活用します。 6 タイプは、混合要因によって暗黙的に処理されます。 それ以外の場合は、7 タイプに戻ります。
