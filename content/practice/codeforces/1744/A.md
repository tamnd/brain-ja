 ## 解決策
 ## 問題の理解

 このタスクは、配列内のそれぞれの個別の数値に 1 つの文字が割り当てられ、その数値の出現箇所がすべてその文字に置き換えられるプロセスを使用して、指定された整数の配列をターゲット文字列にマッピングできるかどうかを判断することです。 同じ数字がすべて同じ文字にマッピングされる限り、置換の順序は重要ではありません。 複数のテスト ケースが与えられ、それぞれに同じ長さの配列とターゲット文字列が含まれており、そのようなマッピングが存在する場合は「YES」を、存在しない場合は「NO」を返さなければなりません。 

制約は小さく、配列の要素数は最大 50、数値は最大 50 です。個別の数値と文字の数は制限されているため、マッピングを直接チェックできます。 主な微妙な点は、2 つの異なる数字が同じ文字にマッピングされないようにし、同じ数字が常に同じ文字にマッピングされるようにすることです。 考えられるすべてのマッピングを試す単純なアプローチは不必要であり、次の場合には時間がかかります。$n$は大きかったが、ここでは直接の貪欲なチェックで十分です。 

明らかではないエッジ ケースには、ターゲット文字列内の異なる文字にマッピングされる繰り返しの数値や、同じ文字にマッピングしようとする複数の数値が含まれます。 たとえば、次の場合$a = [1,2,1]$そして$s = "aba"$、1 は「a」にマップされ、2 は「b」にマップされるため、これは有効です。 しかし、もし$a = [1,2,1]$そして$s = "abb"$、1 は 'a' と 'b' の両方にマップする必要があるため、無効です。 同様に、$a = [1,2,3]$そして$s = "aaa"$の場合、3 つの異なる数値をすべて同じ文字にマッピングすることはできないため、無効です。 

## アプローチ

 ブルートフォースアプローチでは、数字と文字の可能な限りの割り当てを試みることになりますが、これは不必要です。 この問題は 2 つの条件を検証することに集約できます。すべての数値は一貫して 1 つの文字にマッピングされなければならないこと、およびどの文字も複数の数値に割り当てることはできないということです。 配列と文字列を並行して反復処理し、数字を文字にマッピングする辞書を維持できます。 数値に遭遇するたびに、その数値にマッピングがあるかどうかを確認します。 一致する場合、マッピングは現在の文字と一致する必要があります。 割り当てられていない場合は、その文字がすでに別の番号に割り当てられているかどうかを確認します。 存在する場合、マッピングは不可能です。 それ以外の場合は、マッピングを記録して続行します。 この貪欲なチェックは配列の長さに対して線形時間で実行され、制約が小さいため十分です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(26^n) | O(n) | 遅すぎる |
 | 貪欲なマッピングチェック | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、長さを読み取ります。$n$、配列$a$、およびターゲット文字列$s$。 
2. 2 つの辞書を初期化します。1 つは数字から文字へのマッピングを保存するため、もう 1 つはどの文字が割り当てられているかを追跡するためです。 
3. 各インデックスを反復処理します。$i$0から$n-1$。 
4. のために$a_i$そして$s_i$、どうかを確認してください$a_i$すでにマッピングがあります。 存在する場合は、マップされた文字が次と等しいことを確認してください。$s_i$。 そうでない場合、答えは「いいえ」です。 
5. もし$a_i$マッピングがありません。$s_i$はすでに別の番号に割り当てられています。 そうであれば、答えは「NO」です。 それ以外の場合は、割り当てます$a_i \to s_i$そしてマークを付ける$s_i$使用済みとして。 
6. ループが競合せずに完了した場合、答えは「YES」です。 

機能する理由: 不変条件は、各数値に最大 1 つの文字が割り当てられ、各文字が最大 1 つの数値に割り当てられることです。 どちらかの不変条件に違反すると、すぐに「いいえ」がトリガーされます。 すべてのチェックは一貫して行われるため、最終的なマッピングは有効な変換が存在する場合にはそれを反映することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    s = input().strip()
    
    num_to_char = {}
    char_used = {}
    possible = True
    
    for ai, si in zip(a, s):
        if ai in num_to_char:
            if num_to_char[ai] != si:
                possible = False
                break
        else:
            if si in char_used:
                possible = False
                break
            num_to_char[ai] = si
            char_used[si] = True
    
    print("YES" if possible else "NO")
```このコードは、高速 I/O を使用して入力を読み取ります。 保守します`num_to_char`数字から文字へのマッピングの一貫性を確保するため、`char_used`複数の数字が同じ文字にマッピングされないようにします。 小切手`num_to_char[ai] != si`数値が別の文字にマッピングされないようにします。`si in char_used`文字が数字全体で一意であることを保証します。 ループは競合の早い段階で中断されます。
