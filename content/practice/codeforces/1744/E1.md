 ## 解決策
 ## 問題の理解

 4 つの正の整数が与えられます$a, b, c, d$そのような$a < c$そして$b < d$。 課題は 2 つの数字を見つけることです$x$そして$y$満足のいく$a < x \le c$そして$b < y \le d$製品が$x \cdot y$で割り切れます$a \cdot b$。 そのようなペアが存在しない場合は、返さなければなりません$-1 -1$。 

本質的には、よりわずかに大きい数値を見つける必要があります。$a$そして$b$その積は次の倍数と一致します$a \cdot b$。 課題は単に複数を選択することではありません$a$そして$b$ただし、によって与えられた厳密な境界を尊重する必要があります。$c$そして$d$。 

制約は中程度です。$a, b, c, d \le 10^5$そして最大まで$10$テストケース。 これにより、おおよそ次のようなアルゴリズムが可能になります。$O(c-a + d-b)$最悪でもテストケースごと、ただしそれに近いものは$O(c \cdot d)$遅すぎるので$c \cdot d$近づくことができた$10^{10}$。 

明らかではないエッジケースには、次のような状況が含まれます。$a$そして$b$許容範囲内に倍数はありません。 たとえば、次の場合$a = 12$、$c = 14$、$b = 21$、$d = 24$、の最小倍数$a$より大きい$a$は 24 であり、これを超えています$c$。 ただ選ぶだけの素朴なアプローチ$x = 2a$そして$y = 2b$範囲外になると失敗する可能性があります。 

## アプローチ

 ブルートフォースアプローチはすべてを反復します$x$で$(a, c]$そしてすべて$y$で$(b, d]$かどうかを確認します$x \cdot y$で割り切れます$a \cdot b$。 これは、すべての候補を明示的にテストするため、正確性を保つために機能します。 ただし、最悪の場合、次のようなことが考えられます。$(c-a) \cdot (d-b)$ペア。 もし$c-a \approx 10^5$そして$d-b \approx 10^5$、これは次の結果をもたらします$10^{10}$実行不可能な操作。 

重要な観察点は、修正すると、$x$の倍数になる$a$より大きい$a$、そのような最小の倍数を試すことができます。 同様に、$y$の倍数である必要があります$b$より大きい$b$。 選ぶことができます$x = \lceil \frac{a+1}{a} \rceil \cdot a = 2a$第一候補として。 それから私たちは選びます$y$の最小倍数として$b$それは作る$x \cdot y$で割り切れる$a \cdot b$。 

なぜなら$x$の倍数です$a$、必要なのは$y$の倍数になる$b$。 それで$y = \lceil \frac{b+1}{b} \rceil \cdot b = 2b$範囲内であれば機能します。 どちらかの候補が許容範囲を超えた場合$(a, c]$または$(b, d]$、解決策は存在しません。 

これにより、問題がすべてのペアのチェックから変数あたり最大数個の倍数のチェックに減り、非常に高速な解決策が得られます。

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、整数を読み取ります。$a, b, c, d$。 
2. 次の最小倍数を計算します。$a$厳密にそれより大きい$a$。 これは$x = a \cdot 2$。 もし$x > c$、出力$-1 -1$そして続けます。 
3. 次の最小倍数を計算します。$b$厳密にそれより大きい$b$。 これは$y = b \cdot 2$。 もし$y > d$、出力$-1 -1$そして続けます。 
4. 戻る$x, y$解決策として。 

機能する理由: 以下の任意の倍数$a$より大きい$a$～の任意の倍数を乗じる$b$より大きい$b$で割り切れる積を生成します$a \cdot b$。 範囲内に収まるように最小の倍数を選択します。 最小の倍数がすでに境界を超えている場合、それより大きな倍数は収まらないため、$-1 -1$は正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c, d = map(int, input().split())
    
    # smallest multiple of a greater than a
    x = ((a + a) // a) * a
    if x <= a:
        x += a
    if x > c:
        print(-1, -1)
        continue
    
    # smallest multiple of b greater than b
    y = ((b + b) // b) * b
    if y <= b:
        y += b
    if y > d:
        print(-1, -1)
        continue
    
    print(x, y)
```説明: 次の最初の倍数を計算します。$a$その上$a$それを2倍にすることで。 同じことが当てはまります$b$。 境界を明示的にチェックします$c$そして$d$戻る前に。 この式では、off-by-one エラーが発生しないことが保証され、整数演算により浮動小数点数が回避されます。
