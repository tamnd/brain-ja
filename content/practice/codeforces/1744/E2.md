 ## 解決策
 ## 問題の理解

 2 つの数字を見つけるように求められます`x`そして`y`指定された間隔内で、その積が他の 2 つの数値の積で割り切れるようになります。 正式には、4 つの整数が与えられると、`a < c`そして`b < d`、整数を見つけなければなりません`x`そして`y`満足のいく`a < x ≤ c`、`b < y ≤ d`、 そして`(x * y) % (a * b) == 0`。 そのような数値が存在しない場合は、次のように出力します。`-1 -1`。 

入力は大規模です:`a, b, c, d`まで到達できます`10^9`、ただしテストケースの数は少ないです(`t ≤ 10`）。 これは、すべてのペアをチェックするソリューションを意味します`(x, y)`候補ペアの数は最大で`(c-a) * (d-b)`それはおおよそ最大です`10^18`最悪の場合。 

誤って処理されやすいエッジケースとしては、範囲が次のような場合が挙げられます。`[a+1, c]`または`[b+1, d]`非常にきついとき、または`a * b`どちらの範囲も除数として対応できるよりも大きいです。 たとえば、次の場合`a=12, b=21, c=14, d=24`、ありません`x`で`(12,14]`そして`y`で`(21,24]`その積は次で割り切れます`252`したがって、出力は次のようになります。`-1 -1`。 単純なアプローチでは、乗算が次のように行われると誤って想定される可能性があります。`a+1`そして`b+1`常に機能します。 

## アプローチ

 ブルートフォースアプローチでは、すべての整数を反復処理します。`x`で`(a, c]`そしてすべて`y`で`(b, d]`かどうかを確認します`x * y % (a * b) == 0`。 これは原理的には正しいですが、最悪の場合の複雑さは次のとおりです。`(c-a) * (d-b)`到達できるのは`10^18`。 テスト ケースが 10 個しかない場合でも、これは実行不可能です。 

迅速な解決策を導き出す重要な観察は、すべての数値をチェックする必要がないということです。 複数で作業できます。 の倍数を見つけることができれば、`a`それは中にあります`(a, c]`および次の任意の倍数`b`で`(b, d]`、その積は次で割り切れます。`a * b`。 より一般的には、数値のうちの 1 つがそれぞれの底の倍数である必要があるだけで、もう 1 つは積が割り切れるように調整できます。 

体系的な方法は、次のことを選択してみることです。`x`の最小倍数として`a`それはより大きい`a`以下`c`、同様に`y`の倍数として`b`それはより大きい`b`以下`d`。 そのような複数が存在しない場合は、対称的な選択を試すことができます。`y`の倍数として`b`そして調整する`x`の倍数になる`a`割り算を満たすものです。 どちらの選択肢も範囲内に収まらない場合、解決策はありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((c-a)*(d-b)) | お(1) | 遅すぎる |
 | 最適 | テスト ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 次の最小倍数を計算します。`a`それは厳密にはより大きいです`a`。 これは計算することで実現できます`x = ((a // a) + 1) * a`、しかしもっと簡単に言えば、`x = 2 * a`常に第一候補として機能します。 どうかを確認してください`x ≤ c`。 
2. もし`x ≤ c`、それでは必要です`y`そのような`(x * y) % (a * b) == 0`そして`b < y ≤ d`。 以来`x`はすでに次の倍数です`a`を作れば十分です。`y`の倍数`b`。 次の最小の倍数を選択してください`b`より大きい`b`:`y = 2 * b`。 どうかを確認してください`y ≤ d`。 
3. 両方の場合`x`そして`y`境界にフィットして出力します。 これにより保証されます`x * y`で割り切れます`a * b`。 
4. 最初の候補が失敗した場合は、役割を交換します。`y = 2 * b`出発点として選択してください`x`の最小倍数として`a`そのような`(x * y) % (a * b) == 0`そして`a < x ≤ c`。 これは通常、次の最小倍数に減ります。`a`その上`a`それは互換性があります`y`。 
5. 両方の試行が失敗した場合は、次の出力が行われます。`-1 -1`。 

なぜ機能するのか: の倍数のみを考慮します。`a`そして`b`なぜなら、倍数以外の数値は、大きな乗数がなければ割り算を満たすことができないからです。 このアルゴリズムは、許容範囲内にある最小の倍数を探索し、全間隔にわたるブルートフォース反復を回避しながら正確性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a, b, c, d = map(int, input().split())
        # Try x = first multiple of a > a
        x = (a // a + 1) * a  # always 2 * a
        if x > c:
            x = -1
        # Try y = first multiple of b > b
        y = (b // b + 1) * b  # always 2 * b
        if y > d:
            y = -1
        if x != -1 and y != -1:
            print(x, y)
        else:
            # Alternative: try scaling x by smallest factor so that y in range
            found = False
            for mul_x in range(2, (c // a) + 1):
                x_candidate = a * mul_x
                min_y = ((a * b + x_candidate - 1) // x_candidate)
                y_candidate = b * ((min_y + b - 1) // b)
                if x_candidate <= c and b < y_candidate <= d:
                    print(x_candidate, y_candidate)
                    found = True
                    break
            if not found:
                print(-1, -1)

if __name__ == "__main__":
    solve()
```このコードは、最初に最も単純な倍数の候補を試行します。 範囲を超える場合は、互換性のあるものを体系的に検索します。`x`そして`y`整数の除算を使用して次の最小倍数を決定します。`b`各候補の割り算を満たす`x`。 これらの倍数を計算するときは、1 つ違いの間違いがよくあるため、適切に切り上げるように注意してください。
