 ## 解決策
 ## 問題の理解

 3D 空間には四面体が与えられており、これは 4 つの非共面点によって完全に決定されます。 タスクは、切断によって四面体が正確に等しい体積の 2 つの領域に分割されるように、このソリッドを単一の平面で切断することです。 次の形式の有効な平面方程式を出力する必要があります。$ax + by + cz + d = 0$。 

幾何学的には、これは単体の体積を二等分する平面を求めています。 重心を通る正中線が三角形を等しい領域に自明に分割する 2D とは異なり、3D では条件がより制限されます。「中心」点を通るすべての平面が機能するわけではなく、平面の向きが重要です。 

入力サイズはテスト ケースの点で大きく、最大で$10^4$ただし、各テスト ケースは一定サイズのジオメトリです。 これにより、離散化、平面上の探索、または体積積分に依存するアプローチは即座に除外されます。 正しい解は、テスト ケースごとに一定数の幾何学量を計算する必要があります。 

微妙な落とし穴は、重心を通過する任意の平面が機能すると仮定していることです。 たとえば、頂点の平均から計算された重心を通過する任意の平面を誤って出力した場合、等質量分割は位置だけでなく方向にも依存するため、答えは大きく失敗する可能性があります。 

別の失敗モードは、2 つの頂点を通る平面を選択することです。 たとえば、飛行機が通過する$P_1, P_2, P_3$は面を形成しており、四面体が縮退していない限り、体積を均等に分割しないことは明らかです。 

したがって、正しい解決策は、等しい体積の分割を保証する四面体の構造的対称性を利用する必要があります。 

## アプローチ

 強引なアイデアは、プレーンをパラメータ化し、両側のボリュームが一致するまで調整しようとすることです。 たとえ平面上の点を固定したとしても、方向の空間は 2 次元であり、四面体と半空間との交点の体積を計算することは、すでに自明ではない幾何学的操作です。 これをテストケースごとに数値的に繰り返すことは、与えられた条件を考慮すると実現可能な限界をはるかに超えます。$10^4$インスタンス。 

重要な点は、検索する必要がまったくないということです。 四面体には強いアフィン対称性があります。 特に、四面体の構造を反映して、四面体を 2 つの合同な体積部分に分割できる方向が存在します。 

これを確認する便利な方法は、四面体の反対側のエッジのペアを考慮することです。 各四面体には、3 組の対向するエッジがあります。$(P_1P_2, P_3P_4)$、$(P_1P_3, P_2P_4)$、 そして$(P_1P_4, P_2P_3)$。 このようなペアを 1 つ選択すると、それらの中点を結ぶセグメントが四面体の自然な「バランス軸」を捉えます。 四面体の重心は、そのようなすべてのバランス構造の上にあります。 

この軸に直交する平面を作成し、それを重心を通過させると、四面体は、各反対側のエッジのペア内の端点の交換に対応する 2 つの領域に分割されます。 これにより、ボリュームを維持した対称性が作成され、両側のボリュームが強制的に等しくなります。 

これにより、直接的な建設的な解決策が得られます。つまり、反対側のエッジのペアを選択し、それらの中点を計算し、これらの中点間の方向ベクトルを形成してから、重心を通過するこのベクトルに直交する平面を定義します。

 ## アルゴリズムのチュートリアル

 たとえば、1 組の反対側のエッジを修正します。$(P_1P_2)$そして$(P_3P_4)$。 

1. 中点を計算します。$P_1P_2$。 これにより、一方のエッジの代表点が得られます。 
2. 中点を計算します。$P_3P_4$。 これにより、反対側のエッジに対応する点が得られます。 
3. ベクトルを構築する$v$最初の中間点から 2 番目の中間点まで。 このベクトルは、2 つの対向するエッジ間の主な対称方向をエンコードします。 
4.重心を計算する$G = (P_1 + P_2 + P_3 + P_4)/4$。 これは四面体の固有のバランス点であり、対称性によって引き起こされるすべての中央構造上にあります。 
5. 必要な平面を通過する平面として定義します。$G$そして直交する$v$。 代数的には任意の点$X$飛行機の中では満足$$v \cdot (X - G) = 0.$$6. これを標準形式に拡張します$ax + by + cz + d = 0$、 どこ$(a, b, c) = v$そして$d = -v \cdot G$。 

### なぜ効果があるのか

 この構築は、選択された各反対側のエッジのペア内の端点を交換することによって引き起こされる頂点のペアの対称性に依存します。 この変換により、四面体がセットとして保存され、体積が保存されます。 この符号反転までのスワップでは、中点から中点への方向は不変ですが、重心は固定されたままです。 重心を通ってこの方向に直交する平面は、まさにこの対称性の不動点セットであり、両方の半空間に等しい大きさの四面体が含まれるように強制されます。 

変換では、体積を維持した方法で平面の一方の側をもう一方の側にマッピングするため、2 つの部分の体積は同一でなければなりません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        x1, y1, z1 = map(float, input().split())
        x2, y2, z2 = map(float, input().split())
        x3, y3, z3 = map(float, input().split())
        x4, y4, z4 = map(float, input().split())

        # midpoints of opposite edges P1P2 and P3P4
        m1x = (x1 + x2) / 2.0
        m1y = (y1 + y2) / 2.0
        m1z = (z1 + z2) / 2.0

        m2x = (x3 + x4) / 2.0
        m2y = (y3 + y4) / 2.0
        m2z = (z3 + z4) / 2.0

        vx = m2x - m1x
        vy = m2y - m1y
        vz = m2z - m1z

        # centroid of tetrahedron
        gx = (x1 + x2 + x3 + x4) / 4.0
        gy = (y1 + y2 + y3 + y4) / 4.0
        gz = (z1 + z2 + z3 + z4) / 4.0

        a = vx
        b = vy
        c = vz
        d = -(a * gx + b * gy + c * gz)

        out.append(f"{a:.10f} {b:.10f} {c:.10f} {d:.10f}")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```実装は幾何学的構造に直接続きます。 中間点の計算は、整数のオーバーフローを回避し、浮動小数点の精度を維持するために明示的に行われます。 重心は、4 つの頂点すべての単純平均として計算されます。 平面の法線ベクトルは中点間の方向として取られ、定数項は内積条件から導出されます。 

よくある実装上の間違いは、平面方程式には一貫した符号規則が必要であることを忘れていることです。 次の任意のスカラー倍数$(a, b, c, d)$は有効であるため、相対的なジオメトリが保持されている限り、数値スケーリングの違いは許容されます。 

## 実用的な例

 ### 例 1

 単純な四面体を考えてみましょう。$(0,0,0), (2,0,0), (0,2,0), (0,0,2)$反対側のエッジを選択します$(P_1P_2)$そして$(P_3P_4)$。 

| ステップ | 中間点 P1P2 | ミッドポイント P3P4 | ベクトル v | セントロイドG |
 | --- | --- | --- | --- | --- |
 | 値 | (1,0,0) | (0,1,1) | (-1,1,1) | (0.5,0.5,0.5) |

 平面法線は$v = (-1,1,1)$。 定数項は重心内積から計算されます。$$d = -v \cdot G = -((-1)\cdot0.5 + 1\cdot0.5 + 1\cdot0.5) = -0.5.$$これにより、有効な二等分平面が得られます。 

このトレースは、非対称な座標配置であっても、構築により一貫して中心のバランス面が生成されることを示しています。

## 特殊なケース

 重要なエッジ ケースの 1 つは、選択した反対側のエッジのペアがたまたま幾何学的に対称であり、中点の差分ベクトルがゼロになるか非常に小さくなる場合です。 これにより、平面の定義が壊れてしまいます。 ただし、四面体は縮退しておらず、頂点が同一平面上にないため、少なくとも 1 組の反対側のエッジによって有効な非ゼロの分離方向が生成されます。 次のような固定ペアを使用する$(P_1P_2, P_3P_4)$問題保証の範囲内で十分です。 

もう 1 つの微妙なケースは、座標が大きい場合の数値精度です (最大$10^4$）。 すべての演算は入力の線形結合であるため、倍精度の浮動小数点精度は問題なく満たします。$10^{-6}$公差要件。
