 ## 解決策
 ## 問題の理解

 内部位置に正確に極大値と b 個の極小値を持つ 1 から n までの数値の順列を構築するように求められます。 極大値はそのすぐ隣のものよりも大きい数値であり、極小値はそのすぐ隣のものよりも小さい数値です。 最初と最後の要素は、近傍が 1 つしかないため、局所極値とはみなされません。 

入力は 3 つの整数 n、a、b を持つ t 個のテスト ケースです。 最大値と最小値のカウントを満たす有効な順列を出力するか、そのような順列が存在しない場合は -1 を出力する必要があります。 

制約は重要です。 n は 10^5 まで大きくなり、すべてのテスト ケースにわたる n の合計は 10^5 となるため、テスト ケースごとに O(n log n) または O(n) の解は許容されますが、O(n^2) のようなものは遅すぎます。 さらに、a と b は、n が与えられた場合に達成可能でなければなりません。 すべての順列を生成する単純なアプローチでは、複雑さは O(n!) になりますが、これは明らかに実行不可能です。 

注意すべきエッジケースには、要求された山と谷の数が配列の長さに対して大きすぎる状況が含まれます。 たとえば、n=4 で、a=2 の最大値と b=1 の最小値を求める場合、長さ 4 の配列内の内部極値の最大数は 2 であり、山と谷が交互に存在するため、それは不可能です。 また、a または b がゼロの場合、厳密に途中で増加または減少しているシーケンスを正しく処理する必要があります。 

## アプローチ

 ブルートフォースアプローチは、1 から n までの数値のすべての順列を生成し、各順列の山と谷の数を数えるというものです。 原理的には正しいですが、複雑さは O(n!) であり、n > 10 では決して終了しません。n が小さい場合でも、順列の数は階乗的に増加するため、これはすぐに除外されます。 

重要な洞察は、山と谷が自然に交互に現れるという観察から得られます。 各内部要素は、山、谷、または単調シーケンスの一部のいずれかになります。 山または谷の最大数は、交互に配置できる位置の数によって制限されます。配列の中央にある山または谷の場合、これは ⌊(n-1)/2⌋ となります。 これが分かれば、順列を貪欲に構築できます。つまり、山が必要な位置に最大の数値を配置し、谷が必要な位置に最小の数値を配置し、残りの数値を順番に埋めていきます。 これにより、すべての可能性をチェックすることなく、線形時間で順列が生成されます。 

高い数値と低い数値を交互に配置することで、各ピークが近隣よりも大きく、各谷が近隣よりも小さいことが保証されます。 また、内部位置はインデックス 2 ～ n-1 に制限されているため、a + b ≤ n - 2 であることも確認する必要があります。 リクエストがこの制限を超える場合、並べ替えは不可能になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 |---|---|---|---|
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | 貪欲な建設 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. まず、リクエストが実行可能かどうかを確認します。 a + b > n - 2 の場合、両方のカウントを満たすのに十分な内部位置がないため、すぐに -1 を出力します。 

2. 空の配列を初期化する`p`長さ n の 山、谷、残りの数字の 3 つのセグメントに記入します。 

3. 2 つのポインタを維持します。`low = 1`利用可能な最小の数値、および`high = n`最大の場合。 これらは、山と谷を確保するために番号を割り当てるために使用されます。 

4. a ≥ b の場合、ピーク パターンから開始します。 すべての山と b の谷が配置されるまで、山を表す高値、次に谷を表す低値から始まり、高値と低値を交互に番号を配置します。 残りの要素の数は n - (a + b + 1) です。 

5. b > a の場合、谷パターンから開始します。 すべての谷と頂点が配置されるまで、低い番号から始まり、次に高い番号を交互に配置します。 

6. 余分な山や谷ができないように、残りの位置に必要に応じて昇順または降順で数字を入力します。 

7. 最終的な配列を出力します。 これにより、正確に a の山と b の谷が保証されます。 このアルゴリズムは、各ピークが隣接するものよりも大きい数値を取得し、各谷がその隣接するものよりも小さい数値を取得するという不変式に依存します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, a, b = map(int, input().split())
        if a + b > n - 2 or abs(a - b) > 1:
            print(-1)
            continue

        p = [0] * n
        low, high = 1, n
        idx = 0

        # Determine starting pattern
        if a >= b:
            # start with peak
            for i in range(a + b + 1):
                if i % 2 == 0:
                    p[idx] = high
                    high -= 1
                else:
                    p[idx] = low
                    low += 1
                idx += 1
        else:
            # start with valley
            for i in range(a + b + 1):
                if i % 2 == 0:
                    p[idx] = low
                    low += 1
                else:
                    p[idx] = high
                    high -= 1
                idx += 1

        # Fill remaining numbers
        for i in range(low, high + 1):
            p[idx] = i
            idx += 1

        print(' '.join(map(str, p)))

if __name__ == "__main__":
    solve()
```最初のセクションでは、山と谷の差が 1 を超えてはいけない、そうでない場合は変更が不可能であるという微妙な制約を含め、実現可能性をチェックします。 次の部分では、山と谷の交互のシーケンスを構築します。 谷よりも山の数が多い場合は、正しい交互配置を確保するために、山から開始することを選択します。 残りの数値は、さらなる極値を防ぐために昇順に配置されます。 この順序では、意図した山と谷がすべて保存されます。 

## 実用的な例

 | ステップ | いずみ | 満たされた | 低い | 高い | アクション |

 | 4 | 3 | [4,1,3,2] | 2 | 2 | 残り 2 を埋める |

 結果：`[4,1,3,2]`要求どおりに 1 つの山と 1 つの谷があります。
