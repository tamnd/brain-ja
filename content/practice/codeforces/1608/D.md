 ## 解決策
 ## 問題の理解

 ドミノのコレクションが与えられ、それぞれが左と右の 2 つのセルで表されます。 一部のセルはすでに黒または白に色付けされていますが、その他のセルは未定です。 目標は、円の中に各ドミノの右のセルの色が次のドミノの左のセルと異なるようにドミノを配置できるように、未決定のセルを埋めることです。 配置は円形であるため、最後のドミノの右のセルは最初のドミノの左のセルとは異なる必要があります。 答えは、有効な色の数のモジュロ 998244353 です。 

最初の微妙な点は、ドミノを回転できないことです。 左右の位置が固定されているため、色合わせの自由度が制限されます。 もう 1 つの微妙な点は、一部のドミノでは両方のセルが未決定であり、組み合わせ爆発が発生する可能性があることです。 n が 10^5 までの場合、すべての色を明示的に生成したり、ドミノのすべての並べ替えを試みたりする解決策は、直ちに実行不可能になります。 列挙ではなく、数と組み合わせの可能性の観点から推論する必要があります。 

エッジ ケースには、一方または両方のセルが不明な単一のドミノが含まれます。 例えば、`?W`有効なカラーリングは 1 つだけです。`BW`。 ドミノ`??`できる`BW`または`WB`しかしそれはできません`BB`または`WW`循環制約があるため。 ドミノ全体の制約を無視する単純なアプローチでは、これらの構成を誤って数えることになります。 

## アプローチ

 ブルートフォースアプローチでは、未知のセルの可能なすべての色を生成し、ドミノの循環順列をすべてチェックし、色の違いを検証しようとします。 単一のドミノの場合は簡単ですが、n 個のドミノで k 個のセルが未決定の場合、可能性は O(2^k) になります。 n が 10^5 までで、すべてのセルが未決定である可能性がある場合、これはまったく実行不可能です。 

重要な観察は、この問題が 2 部サイクルの色を数えるのと似た構造をしているということです。 各ドミノは制約に影響を与えます。左右のセルは隣接するドミノとは異なっていなければなりません。 固定セルを無視すると、2 つの未決定セルを持つすべてのドミノは、正確に 2 つの選択肢を提供します (`BW`または`WB`）。 1 つの固定セルを持つドミノでは、他のセルが条件を満たすための選択肢が 1 つに減ります。 難しいのは、両側ですでに拘束されているドミノを処理することです (`BB`または`WW`) 循環制約に違反する可能性があるためです。 

また、組み合わせ生成関数を使用して、円を選択シーケンスの合計として扱い、未知のセルが有効なパターンを形成できる方法の数を数えることもできます。 主な洞察は、制約されていないドミノの総数がドミノごとに 2 倍寄与するということです (`BW`または`WB`) ですが、循環制約に違反する構成を差し引く必要があります。つまり、すべてのドミノが色付けされているという 2 つです。`BB`またはすべて`WW`すべてのドミノが完全に無料であれば。 これにより、カウントが 2 のべき乗によるモジュラー演算に削減され、エッジ構成が若干補正されます。

 ## アルゴリズムのチュートリアル

 1. 入力を解析し、各ドミノを文字のペアとして保存します。 完全に未知のドミノ、部分的に既知のドミノ、および固定ドミノの数を数えます。 
2. 3 つのカウンターを初期化します。`cnt_BB`BB として固定されたドミノの場合、`cnt_WW`WW として固定されたドミノの場合、`cnt_question`少なくとも 1 つ含まれるドミノの場合`?`。 
3. 循環制約を無視して、色の総数を計算します。 2 つの未知数を持つ各ドミノは 2 つの選択肢を提供します (`BW`または`WB`)、未知の 1 つを持つ各ドミノは、有効な色を 1 つ提供します。 これらのカウントを 998244353 を法として乗算します。 
4.すべてのドミノが着色されているかどうかを確認します`BB`あるいはすべてのドミノは`WW`許可されています。 その場合、これらの無効な循環構成ごとに 1 を減算します。 
5. さらに、すべてのドミノを交互に配置できるかどうかを確認します。`BW`そして`WB`円の周りの模様。 このパターンは、セルが事前に入力されているためにこのパターンと競合するドミノがない場合にのみ有効です。 この特殊なケースが有効な場合は、カウントに 1 を加えます。 
6. 最終カウントのモジュロ 998244353 を出力します。 

機能する理由: 固定隣接セルによって制約されない限り、すべての未知のセルはオプションの総数に独立して寄与します。 完全に未知のドミノでは 2 つの組み合わせの選択肢が与えられ、部分的に既知のドミノでは固定セルによって選択が強制されます。 循環接続によって課せられるグローバル制約を調整するだけで済みます。これは、2 つの極端に無効なパターンを明示的にチェックすることで処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    dominoes = [input().strip() for _ in range(n)]
    
    total_unknowns = 0
    cnt_BB = cnt_WW = 0
    
    can_all_BW = True
    can_all_WB = True
    
    for left, right in dominoes:
        if left == '?' and right == '?':
            total_unknowns += 1
        elif left == 'B' and right == 'B':
            cnt_BB += 1
        elif left == 'W' and right == 'W':
            cnt_WW += 1
        
        if left != '?' and right != '?':
            if not ((left, right) == ('B', 'W')):
                can_all_BW = False
            if not ((left, right) == ('W', 'B')):
                can_all_WB = False
        elif left != '?' or right != '?':
            if left == 'B' or right == 'W':
                can_all_WB = False
            if left == 'W' or right == 'B':
                can_all_BW = False
    
    total_ways = pow(2, total_unknowns, MOD)
    
    if cnt_BB == 0:
        total_ways -= 1
    if cnt_WW == 0:
        total_ways -= 1
    
    total_ways = (total_ways + can_all_BW + can_all_WB) % MOD
    print(total_ways)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず未知のドミノと固定されたドミノをカウントします。`BB`または`WW`。 未知のドミノに対する独立した選択肢は次のように計算されます。`2^total_unknowns`。 循環制約に違反する可能性のある不可能な構成を削除します (`BB`どこでも、または`WW`どこでも）。 最後に、事前に色付けされたセルで可能であれば、特殊な交互構成を再度追加します。 モジュロにより、出力が制約内に収まることが保証されます。
