## Python ソリューション```python
import sys
input = sys.stdin.readline

def pow_fast(a, e):
    res = 1
    while e > 0:
        if e & 1:
            res *= a
        a *= a
        e >>= 1
    return res

def solve():
    k = int(input())
    n = int(input())
    i = int(input())

    p = pow_fast(k, n)
    print(i * p)

if __name__ == "__main__":
    solve()

 ## 特殊なケース

 いつ$n = 0$、すべての整数の底に少なくとも 0 個の末尾ゼロがあるため、すべての数値は有効です。 この公式は今でも機能します。$k^0 = 1$、したがって、答えは次のようになります$i \cdot 1 = i$、予想されるシーケンスと一致します。 

いつ$k = 2$そして$n$大きいです、と言う$n = 60$、計算します$2^{60}$、これはまだ 64 ビットの範囲内です。 数列は次の倍数になります$2^{60}$、そして$i$-th 項は単にスケーリングされた整数です。 このアルゴリズムはバイナリ表現構造に直接依存しないため、後続のゼロを誤解する危険はありません。 

いつ$i = 1$、答えはまさにそのとおりです$k^n$。 これは有効な最小の数値であり、インデックス作成は最初の倍数から開始されるため、アルゴリズムは 1 単位の調整を行わずにこの数値を正しく返します。
