 ## 解決策
 ## 問題の理解

 毎年同じ日に祝う 2 人の兄弟の 2 つの異なる誕生日のスナップショットが提供されます。これは、彼らの年齢が常に同期して毎年ちょうど 1 歳ずつ増加することを意味します。 

ある誕生日のとき、ヴィティアは`n`歳で彼の兄弟は`m`歳。 あれから何年か経ち、今日はまた誕生日を迎え、ヴィティアも弟も同じだけ年齢が上がった。 今日、私たちは彼らの年齢の関係について語られています。ヴィティアは兄よりも何倍も若いです。`k`、つまり、兄弟の現在の年齢は正確に`k`ヴィティアの現在の年齢の倍。 

課題は、そのようなタイムラインが可能かどうかを判断し、可能であれば、Vitya の現在の年齢を計算することです。 制約が矛盾している場合は、出力する必要があります。`-1`。 

主要な制約構造は非常に厳密です。すべての年齢は最大 10,000 歳であり、`k`も最大でも 10,000 です。 これは、O(1) または O(log n) の代数解が期待されることを直ちに示唆しています。なぜなら、問題のより一般的なバージョンでは、何年にもわたるシミュレーションは不必要であり、遅すぎるからです。 

微妙な失敗のケースは、導出された年齢が整数ではない場合、または負の時間進行を生成する場合に発生します。 たとえば、次の場合`n = 1, m = 10, k = 2`の場合、方程式は今日の小数年齢を暗示しますが、この離散年次モデルでは不可能です。 別の失敗例は、計算された「タイムシフト」で時間を遡る必要がある場合、つまり、導出された現在の年齢が記録された過去の年齢よりも小さい場合に発生します。 

## アプローチ

 過去の状態から順にシミュレーションしてみると`(n, m)`比率条件が満たされるまで、両方の年齢を毎年増加させます。`brother = k * Vitya`満たされています。 最悪の場合、有効な構成間のギャップは最大 10,000 年と大きくなる可能性があり、問題を一般化したバージョンでは、その範囲はさらに大きくなる可能性があります。 ここではまだ実行可能ですが、このアプローチは不必要であり、問​​題の構造を隠してしまいます。 

重要な観察は、両方の年齢が時間とともに直線的に増加することです。 させたら`t`Vitya の現在の年齢と`x`が記録された状態から経過した年数である場合、システムは 2 つの線形方程式になります。 

ヴィティア:`t = n + x`兄弟：`k * t = m + x`これにより、問題が動的プロセスから単純な線形システムの解決に縮小されます。 排除する`x`の直接方程式を与えます`t`これにより、構成が有効かどうかが完全に判断されます。

 ## アルゴリズムのチュートリアル

 1. 値を読み取る`n`、`m`、 そして`k`。 これらは、過去のスナップショットと今日の固定乗数関係を表します。 
2. 未知の部分をタイムシフトで表現する`x`、現在の年齢が`t = n + x`そして`k * t = m + x`。 これは、両方の年齢が時間の経過とともに等しく増加するという事実を捉えています。 
3. 排除する`x`方程式を減算すると、次のようになります。`k * t - t = m - n`。 このステップでは、未知のタイムシフトを削除し、現在の年齢を分離します。 
4. 左辺を因数分解して取得します`t * (k - 1) = m - n`。 これにより、問題は 1 つの整数解が存在するかどうかを確認するだけになります。 
5. コンピューティング`t = (m - n) / (k - 1)`場合のみ`(m - n)`で割り切れます`(k - 1)`。 割り切れない場合、シナリオは整数の年間成長に対応できないため、答えは無効になります。 
6. 計算された値が`t`少なくとも`n`時間は記録された状態から前に進むだけだからです。 もし`t < n`の場合、暗黙のシフトは負になり、設定と矛盾します。 
7. 両方の条件が成立する場合、出力`t`。 それ以外の場合は出力`-1`。 

### なぜ効果があるのか

 中心となる不変条件は、両方の兄弟が時間の経過とともに同じ割合で老化するということです。これは、兄弟の年齢差が一定のままであることを意味します。 これにより、システムが同じ傾きを持つ 2 つのアフィン線形関数に変わります。 有効な解はこれらの線の交点に存在する必要があります。 交点が整数でない場合、または負の経過時間を意味する場合、有効な年次増分シーケンスによって必要な比率を生成することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
m = int(input())
k = int(input())

# t * (k - 1) = m - n
num = m - n
den = k - 1

if num % den != 0:
    print(-1)
else:
    t = num // den
    if t < n:
        print(-1)
    else:
        print(t)
```実装では、導出された方程式を直接エンコードします。 唯一のデリケートな部分は、境界が小さい場合でも浮動小数点演算では精度の問題が発生するため、除算を実行する前に整数の割り算が可能であることを確認することです。 2 番目のチェックでは、時間的な一貫性が強制され、計算された現在の年齢が記録された年齢より前でないことが保証されます。

## テストケース```python
import sys, io

 ## 特殊なケース

 エッジ ケースの 1 つは、比率によって非整数の結果が強制される場合です。 例えば、`n = 3, m = 10, k = 2`につながる`t = 7/1 = 7`これは有効に見えますが、次のようなわずかな変更が加えられています。`n = 3, m = 11, k = 2`与える`t = 8/1`これは数値的には有効ですが、元のシステムでは導出された時間シフトが小数になるため、開始状態からの整数の年次調整に対応しません。 

もう 1 つのケースは、計算された現在の年齢が記録された年齢よりも古い場合です。 例えば、`n = 5, m = 20, k = 2`収量`t = 15`これは有効ですが、入力が`n = 10, m = 20, k = 2`、私たちは得ます`t = 10`これは経過時間がゼロであることを意味し、これは有効ですが、結果が小さい場合は時間の逆方向の動きを示すため、拒否する必要があります。 

これらのケースは、可分性チェックと単調性チェックによって直接処理されます。`t >= n`、受け入れられたすべてのソリューションが物理的に一貫した誕生日の進行に対応していることを保証します。
