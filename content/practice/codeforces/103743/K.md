## Python ソリューション```python
import sys
input = sys.stdin.readline

def build(n):
    if n == 0:
        return "b"

    prefix = "nunhehheh"
    res = [prefix]

    i = 0
    while n > 0:
        if n & 1:
            res.append("c" + "a" * i)
        n >>= 1
        i += 1

    return "".join(res)

def main():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        out.append(build(n))
    print("\n".join(out))

if __name__ == "__main__":
    main()

バイナリ ループは次の各ビットを処理します。$n$。 ビットが位置に設定されるたびに$i$、区切り文字とそれに続くブロックで構成されるブロックを追加します。$i$ `'a'`文字。 セパレータがないとサブシーケンスがブロック間で結合して独立性が損なわれ、バイナリ分解の解釈が破壊される可能性があるため、セパレータは必須です。
