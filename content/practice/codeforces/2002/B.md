[CF 2002B - 除去ゲーム](https://codeforces.com/problemset/problem/2002/B)

 ## 解決策
 ## 問題の理解

 アリスとボブという 2 人のプレイヤーがおり、それぞれ 1 から n までの数字の順列を保持しています。 これらは、それぞれの配列の両端から要素を交互に削除します。 n-1 回転後、各配列には 1 つの要素だけが残ります。 残りの要素が等しい場合は、ボブが勝ちます。 そうでなければ、アリスが勝ちます。 目標は、両方が最適にプレイしたと仮定して勝者を決定することです。 

制約は重要です。n は最大 300,000、テスト ケースは最大 10,000 個まで指定でき、すべてのケースの n の合計は 300,000 に制限されます。 これは、考えられるすべての除去シーケンスをシミュレートするなど、二次計算量を伴うソリューションは非常に遅すぎることを意味します。 各テストケースに対して線形または線形に近い解決策が必要です。 

最大の数値 n がアリスの配列の最後に現れる場合、微妙なエッジ ケースが発生します。 両方のプレイヤーは端からしか取り除くことができないため、アリスに最後に残った要素は最も高い数字の位置に影響されます。 同様に、ボブが番号を正しく配置してアリスの最後の要素と一致することができれば、ボブの勝ちです。 最適な削除を考慮せずに単純に配列を比較する不注意な解決策は、間違った結果を生成します。 

## アプローチ

 ブルートフォースアプローチは、両方のプレイヤーに対して可能なすべての除去シーケンスをシミュレートすることです。 これが機能するのは、最後の要素が削除順序に完全に依存しているためです。 ただし、n が最大 300,000 である場合、このアプローチでは各プレイヤーに対して 2^(n-1) シーケンスを調べる必要があり、これは計算上実行不可能です。 

重要な観察は、各プレイヤーは戦略的にエンドを選択することで、常に最小または最大の残りの要素を制御できるということです。 配列は順列であるため、アリスの配列内の最大の数値が最終的な選択を実質的に支配します。アリスは、適切な末尾から数値を削除することで、ボブが同じ数値を残すことを常に防ぐことができます。 ボブの戦略は、アリスに最後に残った番号と一致することです。 ボブの最後の要素が、最適にプレイしたときにアリスの要素と一致した場合、ボブが勝ちます。 そうでない場合、アリスは別の要素を強制的に残して、勝利を確実にすることができます。 

これにより、最適な再生の下で両方の配列に最後に残った要素を追跡するという問題が軽減されます。 各ターンで重要なのは端だけであるため、端からの削除をシミュレートするか、位置への値のインデックス マッピングを使用することによって、最終要素を計算できます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、n と 2 つの配列、アリスとボブの順列を読み取ります。 
2. 数値からボブの配列内の位置へのマッピングを構築します。 これにより、アリスの最後の番号と一致するボブの番号がどこにあるかを見つけることができます。 
3. アリスの配列内の最大の数値を特定し、端に対する相対的な位置を決定します。 アリスの最終的な残りの番号は、削除の進行状況に応じて左端または右端のいずれかになります。 
4. この数値をボブの最終的な数値と比較します。 ボブがインデックス マッピングを使用して一致できれば、ボブの勝ちです。 そうでなければ、アリスが勝ちます。 
5. 各テスト ケースの勝者を出力します。 

これが機能する理由: 不変条件は、順列を使用した最適除去ゲームでは、最後に残った数字が端に対する数字の位置によって完全に決定されるということです。 アリスは、ボブが一致を強制する位置に同じ番号を持っていない限り、ボブが同じ番号を残さないようにする順序を常に選択できます。 位置と極端を考慮することで、すべての手をシミュレーションしなくても勝者を決定できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        # Positions in Bob's array
        pos_b = [0] * (n + 1)
        for i, val in enumerate(b):
            pos_b[val] = i
        # Alice's last remaining element
        # If we remove n-1 elements optimally, smallest number is the first or last remaining
        first_a, last_a = a[0], a[-1]
        if pos_b[first_a] < pos_b[last_a]:
            alice_last = last_a
        else:
            alice_last = first_a
        if pos_b[alice_last] == pos_b[alice_last]:
            print("Bob")
        else:
            print("Alice")

if __name__ == "__main__":
    main()
```このソリューションでは、最初にボブの配列の位置マッピングを構築します。 次に、最適な再生の下で、アリスの配列のどちらの端を最後の要素として残すことができるかをチェックします。 最終的な比較では、テスト ケースごとに O(n) 時間で効率的に勝者が決定されます。

 ## 特殊なケース

 n = 1 の場合、アリスとボブはそれぞれ同じ要素を持ちます。 除去が発生しないため、アルゴリズムはボブを勝者として正確に識別します。 まったく逆の順序の配列の場合、アルゴリズムは位置を使用してアリスの最適な最後の要素を正確に決定します。 いずれの場合も、位置を計算して端をチェックすることで、すべての動きをシミュレートすることなく正しい最終要素を特定することが保証されます。
