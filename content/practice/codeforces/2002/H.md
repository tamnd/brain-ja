 ## 解決策
 ## 問題の理解

 非常に特殊な結合特性を持つ整数のシーケンスを数えるように求められます。 指定された長さのシーケンスに対して`n`、間の各要素`1`そして`m`、連続する 3 つの要素を繰り返し取得することができます。`a_i, a_{i+1}, a_{i+2}`それらを次のように定義される単一の数値にマージします。`max(a_i + 1, a_{i+1}, a_{i+2} + 1)`。 問題 101 の目標は、結果の数が超過することなく、これらのマージをできるだけ多く実行することです。`m`。 

101 を数えるということは、より高度な質問をします。特定のシーケンスのマージの最大数を計算する代わりに、考えられるすべてのマージ数について求めます。`k`から`0`に`floor((n-1)/2)`、長さのシーケンスの数`n`正確に達成する`k`合併します。 

制約は小さいです`m`(最大 30) および中程度`n`(最大130)。 これは、動的プログラミングを利用したアプローチが、`n`そして`m`すべてのシーケンスを直接反復すると指数関数的になるため、値を指定することは可能です。`m^n`到達できた`30^130`、それは完全に不可能です。 各テスト ケースは、一連のカウントのモジュロを出力する必要があります。`10^9+7`これは、カウントが大きくなる可能性があることを示します。 

明らかではないエッジケースには、次のようなシーケンスが含まれます。`n < 3`(マージは不可能で、答えは常にゼロ操作です) またはシーケンス`m = 1`(値はすべて 1 なので、特定のマージ カウントのみが発生します)。 例えば、`n = 3, m = 1`シーケンスが 1 つだけになる`[1,1,1]`マージは 1 回だけ可能で、出力が得られます。`0 1`。 小さなことを扱わない不用意な解決策`n`個別にインデックス エラーや不正なカウントが発生する可能性があります。 

別の微妙なシナリオは、最大数の場合に発生します。`m`に比べて非常に小さいです`n`、実行できるマージの数が制限されます。 たとえば、次の場合`m = 2`そして`n = 5`、最初のマージで既にある程度の数値が増加しているため、2 つのマージを実行することは不可能です。`3`を超える`m`。 無制限のマージを前提とした強引なアプローチでは、これらのシーケンスのカウントが誤ります。 

## アプローチ

 ブルートフォース手法では、考えられるすべての長さのシーケンスを列挙します。`n`からの要素を含む`1`に`m`、可能なすべてのマージをシミュレートし、各シーケンスで可能なマージの数を数えます。 これは原理的には正しいですが、まったく実行不可能です。`n = 130`そして`m = 30`、処理する必要があります`30^130`シーケンス。 複数のマージ位置を考慮する必要があるため、シーケンスごとのシミュレーションでもコストがかかります。 

重要な洞察は、マージ操作の構造を観察することで得られます。 マージは 3 つの連続する要素のみに依存します。 現在の位置、実行されたマージの数、および最後の 2 つの要素の値を追跡する DP 状態を定義すると、シーケンスを明示的に列挙することなく体系的にシーケンスの数を計算できます。 

具体的には、DP は次のように定義できます。`dp[pos][k][x][y]`= 位置までのシーケンスの数`pos`最後の 2 つの要素は次のとおりです`x`そして`y`、そしてまさに`k`これまでにマージが実行されてきました。 次の要素については`z`、最後の 2 つの要素とのマージを実行します (`max(x+1, y, z+1) <= m`) またはマージせずにシーケンスを拡張します。 全体を反復処理する`x, y, z`値は実現可能であるため、`m`小さいし、`n`中程度です。 これにより、指数関数的な問題が多項式の問題に縮小されます。 

DP を慎重に位置にロールし、状態を最後の 2 つの要素と現在のマージ数だけに圧縮することで、実用的なソリューションを実現できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(m^n * n) | O(m^n) | 遅すぎる |
 | 最適なDP | O(n * m^3 * n/2) ≈ O(n^2 * m^3) | O(n/2 * m^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 必要に応じて階乗とモジュラー逆行列を事前計算しますが、このソリューションでは動的プログラミングによる組み合わせ論を回避します。 
2. 3D DP 配列を初期化する`dp[k][x][y]`どこ`k`は実行されたマージの数であり、`x`そして`y`は、現在のシーケンスの最後の 2 つの要素です。 セット`dp[0][x][y] = 1`すべてのペアに`(x, y)`長さ 2 のシーケンスを想像すると。 
3. 位置 2 から位置 2 までを繰り返します。`n-1`(0 からインデックスが付けられます)。 各 DP 状態について`(k, x, y)`、新しい要素の追加を検討してください`z`1から`m`。 マージ候補を計算する`merge_val = max(x + 1, y, z + 1)`。 もし`merge_val <= m`そうすると、merge:increment を実行できます。`dp[k+1][y][merge_val]`による`dp[k][x][y]`。 それ以外の場合は、マージせずに拡張します: インクリメント`dp[k][y][z]`による`dp[k][x][y]`。 
4.DPを位置まで充填した後`n-1`、全体の合計`dp[k][x][y]`それぞれに`k`長さのシーケンスの総数を取得するには`n`正確に生産する`k`合併します。 
5. これらのカウントをモジュロで返します`10^9+7`。 

なぜ機能するのか: DP は各状態の不変条件を維持します。`(k, x, y)`は、最後の 2 要素構成に到達するシーケンスの数を正確に表します。`k`合併します。 次の要素を体系的に検討し、マージ条件を考慮することで、すべての有効なシーケンスが正確に 1 回カウントされ、無効なシーケンスが含まれないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve(n, m):
    max_k = (n - 1) // 2
    dp = [[ [0]*(m+2) for _ in range(m+2) ] for _ in range(max_k+2)]
    
    # Base: sequences of length 2
    for x in range(1, m+1):
        for y in range(1, m+1):
            dp[0][x][y] = 1
    
    for pos in range(2, n):
        ndp = [[ [0]*(m+2) for _ in range(m+2) ] for _ in range(max_k+2)]
        for k in range(max_k+1):
            for x in range(1, m+1):
                for y in range(1, m+1):
                    val = dp[k][x][y]
                    if val == 0:
                        continue
                    for z in range(1, m+1):
                        merge_val = max(x+1, y, z+1)
                        if merge_val <= m and k+1 <= max_k:
                            ndp[k+1][y][merge_val] = (ndp[k+1][y][merge_val] + val) % MOD
                        else:
                            ndp[k][y][z] = (ndp[k][y][z] + val) % MOD
        dp = ndp
    
    result = []
    for k in range(max_k+1):
        total = 0
        for x in range(1, m+1):
            for y in range(1, m+1):
                total = (total + dp[k][x][y]) % MOD
        result.append(total)
    return result

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    res = solve(n, m)
    print(' '.join(map(str, res)))
```このコードは、長さ 2 のシーケンスを初期化し、一度に 1 位置ずつ拡張します。 各ステップで、マージ遷移と非マージ遷移の両方が考慮されます。 2 つの 3D 配列を使用すると、効率的にロールフォワードを行うことができます。 オーバーフローを防ぐために、加算のたびにモジュロが適用されます。 ネストされたループは安全です。`m`せいぜい30歳であり、`n`多くても130。
