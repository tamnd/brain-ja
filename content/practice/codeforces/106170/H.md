 ## 問題の理解

 次のサイズの長方形グリッドが与えられます。$N \times M$、各セルは次のいずれかでペイントできます。$K$色。 ひねりを加えれば、長方形が平らなシートとして使用されないことです。 接着前に長辺の 1 つを回転させて、メビウス バンドを作成します。 この識別は、長さ方向に移動して回り込むと、幅の座標が反転することを意味します。 

したがって、表面は依然としてグリッドです$N$長さに沿った位置と$M$左右の端は幅方向に反転して接続されています。 カラーリングはすべてのセルにカラーを割り当てますが、バンドの長さに沿ってスライドさせることで一方を他方に変換できる場合、2 つのカラーリングは同じとみなされます。 これは長さ方向に沿った循環シフトであり、各シフトには固有のメビウス反転も伴います。 

タスクは、この対称性のもとで、いくつの異なる色が存在するかを数えることです。$10^9+7$。 

この制約により、グリッドを明示的に扱うものから遠ざけられます。$N$と同じ大きさにすることができます$10^9$、 その間$M$そして$K$と同じ大きさにすることができます$10^{18}$。 これにより、セルを反復したり、変換をシミュレートしたりするソリューションは即座に除外されます。 唯一の実行可能な方法は、対称グループを推論し、サイクル構造を使用して色をカウントすることです。 

素朴な解釈では、すべてを生成することになります。$K^{NM}$シフトによるカラーリングと商。 軌道ごとに代表者を 1 人に制限することさえ不可能です。$NM$は大きすぎます。 本当の構造は、各シフトがセルをどのように並べ替えるかを理解することにあります。 

微妙な点は、メビウスのねじれが長さに沿ったシフトと相互作用することです。 長さに沿って 1 回ステップを実行すると、境界を囲むときに幅のインデックスが反転し、シフトを繰り返すとこの効果が交互に起こります。 これにより、置換が自明ではなくなります。つまり、単純な 2D 巡回シフトではなく、ねじれたシフトになります。 

エッジケースは次の場合に発生します。$N = 1$または$M = 1$。 たとえば、次の場合$N = 1$、バンドはひねりを加えて単一のリングに折りたたまれ、各セルを反転した対応するセルと識別します。 もし$M = 1$、幅には反映の余地がなく、問題は単純なサイクルに帰着します。 どのソリューションでも、こうした縮退したケースを正しく処理する必要があります。 

もう一つの微妙なケースは次のような場合です。$M$幅の反射には固定点 (中央の列) があるかどうかがあり、対称性の下での軌道数に影響を与えるため、 は偶数と奇数の関係にあります。 

## アプローチ

 ブルートフォースアプローチでは、すべてを考慮しようとします。$N$メビウスバンドの可能な循環シフトを計算し、各シフトによって固定されるカラーリングの数を計算します。 シフトごとに、どのように並べ替えるかを明示的にシミュレートします。$N \times M$グリッドとカウントサイクル。 これはすでに組み合わせの爆発を示唆しています。各シフトがすべてに影響を及ぼします。$NM$セルなので、単一の評価は次のようになります。$O(NM)$すべてのシフトでそれを行うと、$O(N^2 M)$、ましてや小さなインスタンスであっても実現不可能です。$N = 10^9$。 

重要な洞察は、グループアクションの下で色を数えているということです。 これはまさにバーンサイドの補題の設定です。つまり、個別のカラーリングの数は、各対称操作によって固定されるカラーリングの平均数に等しいということです。 それぞれの対称操作が貢献します$K^{\text{number of cycles}}$したがって、すべては順列の計算サイクル分解に帰着します。 

メビウスの構造は依然として複雑に見えますが、重要な単純化は、グループが循環的であるということです。つまり、次のシフトを考慮するだけで済みます。$k$バンドに沿って進みます。 このような各シフトは、サイクル構造がセルの算術特性のみに依存するセルに順列を引き起こします。$k$そして$N$に、メビウス反転が適用される回数のパリティを加えます。 

これにより、問題が幾何学から数論に縮小されます。セルを追跡する代わりに、インデックスがどのようにラップするか、および各軌道に沿って反射が何回適用されるかを追跡します。

 ## アルゴリズムのチュートリアル

 私たちは各シフトを次のように扱います$k$長さに沿った位置。 そのようなシフトごとに、それがどのように並べ替えるかを理解する必要があります。$N \times M$グリッド。 

### 1. バーンサイドの補題をすべてのシフトに適用する

 私たちは計算します$$\frac{1}{N} \sum_{k=0}^{N-1} K^{\text{cycles}(k)}$$どこ$\text{cycles}(k)$シフトによって引き起こされるサイクル数です$k$。 

これにより、サイクル数を効率的に計算するという問題が軽減されます。 

### 2. gcd 構造によるシフトの削減

 固定シフトの場合$k$、 させて$g = \gcd(N, k)$。 長さ方向の動きにより分解されます。$N$に位置する$g$それぞれの長さの独立したサイクル$L = N/g$。 

重要な観察は、順列の構造は次のもののみに依存するということです。$g$の正確な値ではありません$k$。 同じ gcd を持つすべてのシフトは同じように動作します。 

このようなシフトの数は、$\varphi(N/g)$、 どこ$\varphi$はオイラーのトーティエント関数です。 

### 3. メビウス反転の蓄積を追跡する

 長さに沿った各ステップにより、ラッピング時に幅方向の潜在的な反転が適用されます。 後$L$1 サイクルあたりのステップ、幅に対する全体的な効果は適用される反射です$L$回。 

それで:

 - もし$L$が偶数である場合、最終的な効果は幅に対する同一性です。 
- もし$L$奇数です。最終的な効果は 1 回の反射です$j \mapsto M-1-j$。 

これにより、幅インデックスが各サイクル内でどのように動作するかが完全に決まります。 

### 4. 1 つの長さのサイクル内のサイクルを数える

 次に、そのうちの 1 つを修正します$g$長さ方向に独立したサイクル。 

もし$L$が偶数の場合、サイクルの完了後に幅には何も起こりません。 それぞれの$M$幅の位置は長さの独立したサイクルを形成します$L$。 したがって、各長さサイクルは正確に寄与します$M$サイクル。 

もし$L$が奇数の場合、幅は完全な走査後の反射の影響を受けます。 反射ペアの位置$j$そして$M-1-j$ただし、固定の中間要素の場合を除きます。$M$奇数です。 

させて：

-$f = 1$もし$M$奇数、そうでない場合$f = 0$次に、1 つの長さサイクル内で次のようになります。 

-$f$位置は反射下でも固定され、長さのサイクルを形成します。$L$- 残り$M - f$位置はペアを形成し、それぞれが長さのサイクルを生成します$2L$したがって、1 つの長さサイクルによって寄与されるサイクル数は次のようになります。$$f + \frac{M - f}{2}$$### 5. 貢献を結合する

 特定の合計サイクル数$g$は：$$g \cdot \text{baseCycles}(g)$$ここで、baseCycles はパリティに依存します。$L = N/g$。 

このような変更によって修正された各構成は、次のような影響を及ぼします。$$K^{g \cdot \text{baseCycles}(g)}$$### 6. 除数の合計

 すべての約数を反復処理します$g$の$N$、そしてそれぞれの計算について:

 -$L = N/g$- 貢献の重み$\varphi(L)$- カラーリングを修正$K^{g \cdot \text{baseCycles}}$すべての寄与分をモジュロで合計します$10^9+7$。 

### なぜ効果があるのか

 このアルゴリズムは 2 つの不変式に依存します。 まず、すべての対称性は 1 つの巡回シフトのべき乗であるため、Burnside は計数の問題を 1 つの置換ファミリーの分析に縮小しました。 第 2 に、メビウス ツイストは長さサイクルの完了後に幅インデックスが反映されるかどうかにのみ影響し、これは個々の位置ではなくサイクル長のパリティのみに依存します。 これら 2 つのプロパティにより、同じ gcd を持つすべてのシフトが同一のサイクル構造を生成し、除数に対する集計が正しく完全になることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mod_pow(a, e):
    res = 1
    a %= MOD
    while e > 0:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def euler_phi(n):
    result = n
    p = 2
    while p * p <= n:
        if n % p == 0:
            while n % p == 0:
                n //= p
            result -= result // p
        p += 1
    if n > 1:
        result -= result // n
    return result

def divisors(n):
    small = []
    large = []
    i = 1
    while i * i <= n:
        if n % i == 0:
            small.append(i)
            if i * i != n:
                large.append(n // i)
        i += 1
    return small + large

def solve():
    t = int(input())
    for _ in range(t):
        N, M, K = map(int, input().split())

        divs = divisors(N)
        ans = 0

        for g in divs:
            L = N // g
            phi = euler_phi(L)

            if L % 2 == 0:
                cycles = g * M
            else:
                if M % 2 == 1:
                    cycles_per_block = 1 + (M - 1) // 2
                else:
                    cycles_per_block = M // 2
                cycles = g * cycles_per_block

            ans = (ans + phi * mod_pow(K, cycles)) % MOD

        invN = pow(N, MOD - 2, MOD)
        ans = ans * invN % MOD
        print(ans)

if __name__ == "__main__":
    solve()
```実装は除数集計に直接続きます。 除数の列挙は、次の範囲にあるすべての可能な gcd 値を抽出します。$k$そして$N$。 このような構造ごとに、誘発された順列のサイクル数を計算し、$K$その力に。 

各サイクルは、次のいずれかで独立して色付けできるため、べき乗が必要です。$K$色。 モジュラーの逆$N$バーンサイドの平均化ステップから表示されます。 

リフレクションの場合の処理​​には注意が必要です。$L$が奇数の場合、幅の位置はリフレクションの下でペアになり、$M$が奇数である場合、別のサイクルに寄与する固定中間点が 1 つだけ存在します。 

## 実用的な例

 小さなケースを考えてみましょう$N = 4, M = 3, K = 2$。 約数$N$は$1, 2, 4$。 

各約数について$g$、計算します$L = N/g$。 

| g | Ｌ | M パリティ効果 | ブロックごとのサイクル | 合計サイクル |
 | --- | --- | --- | --- | --- |
 | 1 | 4 | Lでも反転な​​し | 3 | 3 |
 | 2 | 2 | Lでも反転な​​し | 3 | 6 |
 | 4 | 1 | 奇数 L、反射 | 2 | 8 |

 さて、仮定してください$K = 2$。 各用語が寄与する$2^{cycles}$、で重み付けされます$\varphi(L)$。 

のために$g=2$、$L=2$、$\varphi(2)=1$、貢献度は$2^6 = 64$。 これは、バンドを 2 つの独立したサイクルに分割するシフトによって厳格な構造が強制され、サイクルごとに多くの独立したカラー割り当てが可能になるという事実に対応しています。 

のために$g=4$、$L=1$、長さのすべての位置はすぐに固定されますが、メビウスの反射では幅の位置がペアになり、独立した自由度が減少します。 指数は、対称性によって個別のセルが軌道にどのように崩壊するかを反映します。 

このトレースは、アルゴリズムが長さ方向のサイクル分割と幅方向の反射制約の両方に敏感であることを確認します。

 ## 特殊なケース

 いつ$N = 1$、構造には長さの移動がないため、すべてのセルは幅方向のメビウス識別を通じてのみ相互作用します。 アルゴリズムは単一の約数の場合に帰着します$g = 1$、$L = 1$、それはすぐに私たちを反省体制に置きます。 サイクル式は、幅インデックスを固定点またはペアに正しく折りたたんで、実際のジオメトリに一致させます。 

いつ$M = 1$、列が 1 つしかないため、幅の反映は無関係になります。 奇妙なことに-$L$この場合、反射は形式的にはまだ存在しますが、単一の位置が固定されるため、式は長さのブロックごとに 1 サイクルに正しく減少します。 これにより、ペアが存在すると仮定することによる過剰なカウントが回避されます。 

いつ$K = 1$、対称性に関係なく、すべての構成は同一です。 べき乗$K^{\text{cycles}}$は常に 1 と評価され、バーンサイドの重みの合計は正規化後に 1 に減り、カラーリングが 1 つだけ存在するという予期された結果と一致します。 

大型用$N$、除数ベースのグループ化により、すべてのシフトを反復しようとすることがなくなります。 いつでも$N$が素数の場合、構造は 2 つの場合のみに単純化されます。$g = 1$そして$g = N$、アルゴリズムが大きさではなく純粋に算術構造によってスケールされることを示しています。
