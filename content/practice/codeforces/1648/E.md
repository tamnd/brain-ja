 ## 解決策
 ## 問題の理解

 接続された無向グラフから始めます。 グラフはベルラフロットの航空券を表しており、すべての端に価格が付いています。 

2 つの都市間の旅行費用は異常です。 ルートには多くのフライトが含まれる場合がありますが、そのコストはエッジの重みの合計ではありません。 代わりに、それはそのルートに現れる最大エッジの重みです。 2 つの都市間のすべての可能なルートの中で、そのような最小値を採用します。 

重み付きグラフの場合、この量は古典的な **最小最大距離** です。 

次に補数グラフを構築します。 Berlaflot エッジによって接続されていない都市のすべてのペアが S8 エッジになります。 S8 エッジの重量`(u,v)`は正確に間の最小距離です`u`そして`v`元のグラフでは。 

補グラフは接続されることが保証されています。 

最後に、元のエッジごとに`(u,v)`、間の最小距離を計算する必要があります。`u`そして`v`S8 グラフ内。 それらの値が新しいベルラフロットの価格となります。 

入力は、すべてのテスト ケースにわたって最大 200,000 個の頂点と 200,000 個のエッジを持つ接続されたグラフです。 出力には、元のエッジごとに 1 つの回答が必要です。 

制約により、全ペアの最短パスに近いものは直ちに除外されます。 すべてのペアごとの距離を保存する場合でも、Θ(n²) メモリが必要になりますが、これは不可能です。`n = 200000`。 どのようなソリューションでも、最小距離とグラフの補数の強力な構造特性を利用する必要があります。 

危険な間違いは、最小距離を通常の最短経路の問題として扱うことです。 

考慮する：```
1 --(1)-- 2 --(100)-- 3
1 --(50)-- 3
```からの最短経路`1`に`3`は重みの直接のエッジです`50`、ただし、最小距離も`50`、代替パスには最大のエッジがあるため`100`。 最短経路の計算はここでは関係ありません。 

もう 1 つの簡単な罠は、補数グラフを明示的に構築することです。 と`n = 200000`、補体にはほとんどを含めることができます`n²/2`エッジ。 すべての補数エッジを反復処理することさえ不可能です。 

3 番目の微妙な点は、グラフ内の最小距離が最小スパニング ツリーによって完全に決定されることです。 この事実が欠けていると、元のグラフのパス問題を繰り返し解決するアルゴリズムが非常に遅くなってしまいます。 

## アプローチ

 まず総当たり的な解決策を想像してみましょう。 

頂点のペアごとに、Berlaflot グラフの最小距離を計算します。 これらの値を使用して、すべての補完エッジに重みを割り当てます。 次に、元のエッジごとに、補数グラフ内の最小距離を再度計算します。 

これは概念的には簡単です。 残念ながら、補グラフには Θ(n²) エッジが含まれる可能性があります。 建設することさえ不可能です。 すべてのペア間の最小距離を計算するには、少なくとも 2 次メモリと 3 次スタイルの作業が必要になります。 

重要な観察は、最小距離の古典的な特性に基づいています。 

重み付きグラフの最小スパニング ツリーを取得します。 任意の 2 つの頂点について`u`そして`v`、それらの間の最小距離は、それらの間の一意の MST パス上の最大エッジに等しくなります。 

なぜこれがここで役立つのでしょうか?

 させて`T`元のグラフの MST になります。 すべての補完エッジ`(u,v)`間のパス上の最大エッジに等しい重みを受け取ります。`u`そして`v`で`T`。 

MST エッジを昇順に処理するとします。 ウェイトのMSTエッジ時`w`2 つのコンポーネントを結合します`A`そして`B`、すべてのペア`(a,b)`と`a∈A`、`b∈B`最小距離が正確にあります`w`。 

これらのペアのうち、一部は元のグラフ エッジであり、一部は補完エッジです。 

この時点で作成されたすべての補完エッジにウェイトがかかります`w`。 

これは、すべての補完エッジを具体化することなく、MST でのコンポーネントのマージを通じて S8 グラフ全体を記述できることを意味します。 

次の問題は、補数グラフ内の最小距離を計算する方法です。 

ここでも MST 原則を使用します。 補グラフの MST を構築できれば、元のエッジの答えは、単純に、その MST 内の対応するパス上の最大エッジになります。 

素晴らしい点は、同じコンポーネントのマージ プロセス中に補完グラフ MST も構築できることです。 コンポーネントに対する分割統治構造が自然に現れます。 結果として得られるグラフには O(n log n) 個の補助エッジしかなく、DSU ベースの Kruskal プロシージャによって必要なツリーが効率的に構築されます。 

ソリューション全体は、一連の MST 構築とツリー クエリとなり、すべてほぼ線形になります。

 ## アルゴリズムのチュートリアル

 ### ステップ 1

 最小スパニングツリーを構築する`T`Kruskal を使用して元のグラフを作成します。 

ミニマックス距離の場合、元のグラフを完全に次のように置き換えることができます。`T`。 

### ステップ 2

 MST エッジを重みの増加順に処理します。 

ウェイトのMSTエッジ時`w`コンポーネントを結合します`A`そして`B`、端点が異なる辺にある頂点のすべてのペアは最小距離を取得します。`w`。 

これはまさに、クラスカル再構成ツリー内の LCA がこのマージを表すノードであるペアのセットです。 

### ステップ 3

 元のグラフのクラスカル再構築ツリーを構築します。 

マージごとに、マージに使用された MST エッジの重みと同じ値を持つ新しいノードが作成されます。 

元の 2 つの頂点の場合、元のグラフの最小距離は、この再構成ツリーの LCA に格納されている値です。 

### ステップ 4

 すべての補エッジを列挙せずに表す必要があります。 

コンポーネントに対応する子を持つすべてのマージ ノードに対して`A`そして`B`、すべてのペア`(a,b)`と`a∈A`、`b∈B`すでに元のグラフ エッジであるペアを除き、マージ値と等しい補エッジの重みを受け取ります。 

DSU-on-tree スタイル セットのマージを使用して、各マージと交差する元のグラフのエッジを維持します。 これにより、欠落しているペア、つまり補数エッジを正確に識別できるようになります。 

### ステップ 5

 補グラフ MST の候補エッジのスパース セットを生成します。 

古典的な分割統治の議論では、そのような候補エッジが O(n log n) だけ必要であることが示されています。 すべての補エッジは再構成ツリーのマージ ノードに属し、適切なサブセット間の代表を接続します。 

生成されたエッジの重みがマージ値になります。 

### ステップ 6

 これらの候補エッジで Kruskal を再度実行します。 

これにより、完全補数グラフを構築することなく、S8 グラフの MST が構築されます。 

この MST を次のようにします`T₂`。 

### ステップ 7

 Kruskal 再構成ツリーを構築します。`T₂`。 

ここで、任意の頂点のペアについて、S8 グラフ内の最小距離は、この 2 番目の再構成ツリー内のそれらの頂点の LCA に格納されている値と等しくなります。 

### ステップ 8

 あらゆるオリジナルのエッジに`(u,v)`、LCA をクエリします。`u`そして`v`2 番目の再構築ツリーで。 

その LCA に保存された値は、ステートメントで要求される新しい価格とまったく同じです。 

### なぜ効果があるのか

 最初の再構成ツリーは、元のグラフ内のすべての最小距離をエンコードします。これは、最小距離が MST パス上の最大エッジに等しく、クラスカル再構成ツリーがそれらの最大値を正確に LCA 値として保存するためです。 

すべての補エッジの重みはそのような最小距離によって定義されるため、すべての補エッジは最初の再構成ツリー内のマージ ノードに対応します。 

スパース候補生成では、補グラフの最小スパニング ツリーに参加できるすべてのエッジが保存されます。 したがって、これらの候補に対する Kruskal は、完全補数グラフから得られるのと同じ MST を生成します。 

次に、2 番目の再構成ツリーは、S8 グラフ内のすべての最小距離をエンコードします。 元のエッジ エンドポイント ペアごとに LCA をクエリすると、それらの間のルート上で可能な最小限の最大 S8 エッジが正確に返されます。これは、必要な再構成された価格です。

import sys

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.sz = [1] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.sz[a] < self.sz[b]:
            a, b = b, a
        self.p[b] = a
        self.sz[a] += self.sz[b]
        return True

 ## 特殊なケース

 木について考えてみましょう。```
4 3
1 2 1
2 3 2
3 4 3
```元のグラフはすでに MST と等しくなります。 ミニマックス ロジックの代わりに最短パス ロジックを使用しようとするソリューションでは、誤った補数エッジの重みが導出されます。 再構築ツリーは値を正しく割り当てます`2`、`3`、 そして`3`補完エッジまで。 

エッジの重みが等しいことを考慮します。```
4 4
1 2 5
2 3 5
3 4 5
1 4 5
```すべての最小最大距離は等しい`5`。 クラスカル再構成ノードはすべて値を保持します`5`、すべての補エッジが重みを受け取ります`5`、そしてすべての答えは`5`。 コンポーネントのマージ中に等しい重みを誤って処理すると、このケースが簡単に壊れる可能性があります。 

多くのペアが欠落しているグラフを考えてみましょう。```
5 4
1 2 1
2 3 2
3 4 3
4 5 4
```補完グラフは元のグラフよりもはるかに密度が高くなります。 明示的な構築では、大規模なインスタンスではすでに Θ(n²) の作業が必要になります。 受け入れられた解決策は、欠落しているペアをすべて列挙することはなく、コンポーネントのマージから MST 関連の構造のみを導き出します。
