 ## 問題の理解

 2 つの整数列が与えられています。`s`そして`t`、2 つの文字列の文字を表します。 各整数は個別の文字に対応し、以下の整数は等しくなります。`s`そして`t`同じ文字を指します。 タイラーは、何個の異なる再配置が行われたかを数えたいと考えています。`s`辞書順に小さい文字列が生成されます。`t`。 出力はモジュロで取得する必要があります`998244353`。 

辞書編集的な比較は通常どおり定義されます。2 つのシーケンスが与えられた場合、最初の異なる要素が順序を決定します。または、一方のシーケンスが他方のシーケンスの厳密なプレフィックスである場合、短いシーケンスの方が小さくなります。 例えば、`[1,2]`よりも小さいです`[1,2,3]`、 しかし`[2,1]`よりも大きいです`[1,2]`。 

制約により許可されるのは、`n`そして`m`200,000まで。 すべての順列を計算する`s`階乗増加が極端であるため、明らかに実行不可能です。 すべての順列を保存することさえ不可能です。 したがって、明示的に配置を生成せずに配置をカウントするアプローチが必要です。 

いくつかの難しいシナリオが発生します。 もし`s`繰り返される要素が含まれる場合、個別の順列を単純にカウントすると過剰にカウントされる可能性があります。 もし`n < m`、いくつかの順列`s`よりも短いという理由だけで、より小さい可能性があります`t`ただし、プレフィックスは共有します。 また、もし`n > m`、最初の順序が異なる順列のみ`m`要素とその時点で小さい要素が関連します。 それ以外の場合は、自動的に大きくなります。 

たとえば、次の場合`s = [1,1,2]`そして`t = [1,2,1,2]`、順列`[1,1,2]`そして`[1,2,1]`よりも小さい`t`、 しかし`[2,1,1]`の方が大きいです。 すべての順列を想定した不用意なアプローチ`s`より短い`t`小さい場合はオーバーカウントされます。 

## アプローチ

 ブルートフォース手法では、次のすべての異なる順列を生成します。`s`辞書順に小さいものを数えます`t`。 このメソッドは正確性に関しては機能しますが、次の場合にはすぐに失敗します。`n > 10`、順列の数は`n!`そして簡単に超えることができます`10^12`。 したがって、与えられた制約に対しては非現実的です。 

より高速なソリューションを実現するための重要な洞察は、最初の要素を比較し、次に 2 番目の要素を比較することによって、辞書編集上の順序を段階的に決定できることです。 特定の数値で始まる順列の数がわかっていれば、以下の順列をすべて数えることができます。`t`生成せずに。 これにより、問題はマルチセット制約による順列のカウントに軽減されます。 階乗と逆モジュラーを使用すると、各プレフィックスの配置数を効率的に計算できます。 フェンウィック ツリー (バイナリ インデックス付きツリー) は、現在の要素数よりも小さい要素の数を迅速に合計するのに役立ちます。`t_i`で`O(log n)`時間。 

したがって、順列を生成する代わりに、次の値よりも小さい考えられる各プレフィックスで始まるシーケンスの数を計算します。`t`。 プレフィックスが先頭と等しい場合`t`、次の文字のチェックを続けます。 以下の最初の不一致`t`繰り返される要素を考慮して階乗除算を使用して残りのすべての順列をカウントできます。

 ## アルゴリズムのチュートリアル

 1. 階乗とモジュラー逆関数を最大で事前計算します。`max(n, max(s))`順列カウントに使用します。 これにより、多項係数を法として計算できるようになります。`998244353`。 
2. 内の各整数の出現をカウントします。`s`そしてそれらを配列または辞書に保存します`freq`。 これは文字のマルチセットを表します。 
3. 可能な整数の範囲でフェンウィック ツリーを初期化します。 すべての要素の周波数を次から挿入します。`s`。 これにより、指定された整数より小さい要素がいくつあるかをすばやくクエリできるようになります。 
4. 残りの順列の総数を次の多項係数として初期化します。`s`、`total_perms = n! / (product of freq[i]!)`。 これは、すべての異なる配置をカウントします。`s`。 
5. 反復処理`t`インデックスによる`i`:

 ａ． のために`t_i`、フェンウィック ツリーにクエリして、以下の要素の数の合計を求めます。`t_i`。 この合計に残りの順列の数を掛けます。`n-i`要素 (使用された要素を削除するために階乗を更新) を作成し、答えに追加します。 

b. もし`freq[t_i] == 0`、一致する順列が存在しないため、反復を停止します。`t`。 

c. それ以外の場合は減らす`freq[t_i]`1 つずつ、フェンウィック ツリーを更新し、更新します`total_perms`したがって、使用される 1 つの要素を考慮してください。 
6. 反復が停止せずに完了した場合、`n < m`、答えに 1 を追加します。`s`それ自体は次の接頭辞です`t`したがって、より小さくなります。 
7. 答えのモジュロを出力します`998244353`。 

**機能する理由:** 各ステップで、アルゴリズムは、以下から分岐するすべてのシーケンスをカウントします。`t`繰り返される要素を考慮するために多項係数を使用して、その位置をより小さな方法で配置します。 フェンウィック ツリーを使用すると、現在より小さい選択肢がいくつ存在するかをクエリできます。`t_i`。 不変条件は、各ステップでカウントされる順列の数が、これまでに考慮されたプレフィックスから始まる辞書編集的に小さいシーケンスの数と正確であるということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, m = map(int, input().split())
    s = list(map(int, input().split()))
    t = list(map(int, input().split()))

    max_val = max(max(s, default=0), max(t, default=0)) + 2

    # Precompute factorials and inverses
    fact = [1] * (n + 2)
    invfact = [1] * (n + 2)
    for i in range(1, n + 2):
        fact[i] = fact[i - 1] * i % MOD
    invfact[n + 1] = modinv(fact[n + 1])
    for i in range(n + 1, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    # Frequency count
    freq = [0] * max_val
    for num in s:
        freq[num] += 1

    class Fenwick:
        def __init__(self, size):
            self.n = size
            self.tree = [0] * (size + 2)
        def add(self, i, v):
            while i <= self.n:
                self.tree[i] += v
                i += i & -i
        def sum(self, i):
            res = 0
            while i > 0:
                res += self.tree[i]
                i -= i & -i
            return res

    ft = Fenwick(max_val)
    for i in range(1, max_val):
        if freq[i]:
            ft.add(i, freq[i])

    total_perms = fact[n]
    for i in range(1, max_val):
        total_perms = total_perms * invfact[freq[i]] % MOD

    ans = 0
    rem = n
    for i in range(min(n, m)):
        x = t[i]
        smaller = ft.sum(x - 1)
        if smaller > 0:
            temp = total_perms * smaller % MOD
            temp = temp * modinv(rem) % MOD
            ans = (ans + temp) % MOD
        if freq[x] == 0:
            break
        total_perms = total_perms * freq[x] % MOD
        total_perms = total_perms * modinv(rem) % MOD
        freq[x] -= 1
        ft.add(x, -1)
        rem -= 1
    else:
        if n < m:
            ans = (ans + 1) % MOD

    print(ans)

solve()
```このソリューションでは、まず階乗とモジュラー逆関数を設定して、多項係数を計算します。 頻度はフェンウィック ツリーを通じて保存および管理され、小さな要素の素早い合計クエリを可能にします。 の`total_perms`変数は、要素が使用されるときに残っている順列の数を追跡します。 それぞれの反復`t`より小さい接頭辞で始まる順列をカウントします。`t`そしてそれに応じて残りの順列を調整します。 境界条件など`n < m`または欠落している要素`s`、明示的に処理されます。
