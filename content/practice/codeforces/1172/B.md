 ## 解決策
 ## 問題の理解

 ノード間に直線として描かれたエッジが交差しないように、指定されたツリーのノードを円の周りに配置する方法が何通りあるかを数えるよう求められます。 木には、`n`～のラベルが付いたノード`1`に`n`、 そして`n-1`それらを接続するエッジ。 入力はエッジのリストであり、出力は円を法とするノードの有効な順列の数です。`998244353`。 

円上にノードを配置し、交差せずにエッジを描画することは、交差を引き起こすエッジが別のノードを「飛び越えない」ようにノードに位置を割り当てることと同じです。 小さな例を観察すると、隣接ノードが連続する円弧を占有している限り、隣接ノードに接続されているノードは円の周りに自由に配置できることがわかります。 

重要な制約は次のとおりです。`n`と同じ大きさにすることができます`2*10^5`。 これは、複雑度が O(n^2) 以上のアルゴリズムは遅すぎることを意味します。 おおよそ O(n) または O(n log n) の解が必要です。 エッジ ケースには、高度なノードを持つツリー (星型) と長いチェーン (線形ツリー) が含まれます。 単純な階乗ベースのソリューションは、モジュラー演算や次数カウントを正しく考慮していないと失敗する可能性があります。 たとえば、中央ノード 1 に接続された 4 つのノードからなるスター ツリーには、`3!`葉を前後に並べる方法を 1 に、円上のどこからでも中央ノードを開始する 4 つの選択肢を掛け合わせます。 

## アプローチ

 ブルートフォースアプローチは、すべてを生成することです。`n!`ノードの順列を確認し、順列に従ってエッジを描画すると交差が生じるかどうかを確認します。 各エッジのペアを比較する必要があるため、各順列の交差をチェックするには O(n^2) の操作が必要です。 このアプローチは明らかに不可能です`n = 2*10^5`なぜなら`n!`どの多項式よりも速く増大するため、すべての順列を反復処理することさえ不可能になります。 

重要な洞察は、各ノードによって課されるローカル制約に焦点を当てることです。 ノードの場合`d`隣接する場合、隣接者は交差を避けるためにその周囲の連続した位置を占める必要があります。 つまり、次数のノードに対して、`d`、`d`子供たちを配置することができます`d!`それを回避する方法。 さらに、円自体を自由に回転させることができます。`n`開始ノードを選択する方法。 これらを掛け合わせると、有効な順列の合計数が得られます。`n * product(deg[i]!)`すべてのノードに対して`i`。 

これにより、問題は次数、つまり O(n) に基づく単純な計算に帰着します。 DFS、DP、または組み合わせ生成は、度法乗の階乗を計算する以外には必要ありません。`998244353`。 この問題のツリー構造により、各エッジが正確に 2 つのノードの次数に寄与することが保証されるため、次数のカウントは簡単かつ安全です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * n^2) | O(n) | 遅すぎる |
 | 度数の数え方 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. リストを初期化する`deg`サイズの`n+1`各ノードの次数を格納します。最初はすべて 0 です。 
2. 各エッジを読み取ります`(u, v)`入力と増分から`deg[u]`そして`deg[v]`。 各ノードの次数は、そのノードが持つ直接隣接ノードの数です。 
3. 階乗モジュロを事前計算する`998244353`まで`n`。 これにより、効率的な計算が可能になります。`deg[i]! % MOD`すべてのノードに対して。 
4. 答えを次のように初期化します。`ans = n`を説明するために`n`円を回転させる方法。 
5. 乗算`ans`各ノードの次数の階乗による剰余`998244353`。 具体的には、`ans = ans * factorial[deg[i]] % MOD`みんなのために`i`から`1`に`n`。 
6. 出力`ans`。 

機能する理由: 不変条件は、各ノードについて、その子を周囲の連続した位置に任意の順序で配置できることです。 ツリーは接続されており非循環であるため、エッジ交差をグローバルに防ぐには、各ノードでローカルな非交差を確保するだけで十分です。 円を回転させると、すべての対称配置が考慮されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def main():
    n = int(input())
    deg = [0] * (n + 1)
    for _ in range(n - 1):
        u, v = map(int, input().split())
        deg[u] += 1
        deg[v] += 1

    # Precompute factorials modulo MOD
    factorial = [1] * (n + 1)
    for i in range(1, n + 1):
        factorial[i] = factorial[i-1] * i % MOD

    ans = n
    for i in range(1, n + 1):
        ans = ans * factorial[deg[i]] % MOD

    print(ans)

if __name__ == "__main__":
    main()
```このソリューションでは、最初にエッジを読み取り、度をカウントします。 階乗を事前計算することで、階乗計算の繰り返しを確実に回避できます。 乗算する`n`各次数の階乗を使用すると、正しいカウントのモジュロが得られます。`998244353`。 

微妙な点には、factorial 配列のサイズの初期化が含まれます。`n+1`含める`0!`、モジュロ乗算を正しく処理し、ノード インデックスを反復処理します。`1`に`n`入力ラベルと一致します。

 ## 特殊なケース

 2 ノードのツリー (`2\n1 2`) 結果は 2 つの有効な順列になります: ノード 1 が最初かノード 2 が最初です。 アルゴリズムは正しく計算します`n=2`乗算`deg[1]! * deg[2]! = 1*1 = 1`、与える`2`。
