 ## 解決策
 ## 問題の理解

 このタスクでは、ボールが常に 45 度の固定方向、具体的には x の増加と y の増加に向かって動き始める長方形のビリヤード テーブルについて説明します。 テーブルには完全に反射する壁があるため、ボールが境界に当たると必ず同じ角度でバウンドし、再び真っ直ぐな対角線に沿って移動し続けます。 したがって、動きは常に 2 つの対角線方向の 1 つに制限されますが、反射によって等価な対角線セグメント間で周期的に切り替わります。 

このテーブル内には、整数の座標に複数の静止したボールが配置され、別の座標に 1 つのコインが配置されています。 選択した 1 つのボールを打つと、そのボールは 45 度の反射運動を開始します。 他のボールに当たるか、コーナーホールに到達するとモーションは停止しますが、その前にコインの位置を通過すると、そのストライクは成功したとみなされます。 目標は、どの開始ボールが、その軌道が別のボールやコーナーによってブロックされる前に最終的にコインを通過するかを決定することです。 

入力により、長方形の寸法、コインの座標が得られ、データセットごとに最大 100,000 個のボールの位置が得られます。 出力は、最終的にコインに当たるまでに打てるボールのインデックスのリストです。 

この制約は、モーションを段階的にシミュレートするソリューションは不可能であることを意味します。 単一の軌道は何度も反射し、多くの鏡像位置を訪れる可能性があるため、ボールごとの単純なシミュレーションではコストがかかりすぎます。 完全なシミュレーションを使用して各ボールを個別にチェックする場合でも、ボールの数とパスの長さの両方に応じて作業を繰り返す必要があり、反射が繰り返されるため作業が長くなる可能性があります。 

重要なエッジ ケースは、ミラー化されたテーブルの周期的なグリッド内で反射によって軌道が実質的に無限になることです。 たとえば、延長された対角線のパスがテーブルの反射コピー内のコインを通過する位置からボールが開始した場合、元の長方形の直接セグメントがコインと交差していなくても、有効なヒットとしてカウントされます。 1 つの長方形内の単純な線分交差テストは、ここでは失敗します。 

もう 1 つの微妙なケースは、ボールがコインに対して対角線上に一致する方向にあるのに、同じ軌道で先に現れた別のボールによってブロックされる場合です。 たとえば、同じ反射対角線上に並んだ 2 つのボール。近いボールが、遠くにあるボールがコイン ロジックに到達できるかどうかを決定します。しかし、他のボールよりも先にコインを打つことだけを考慮しているため、軌道に沿った順序が重要になります。 

## アプローチ

 素朴な考えは、打たれたボールの動きをシミュレートすることです。 開始ボールごとに、壁またはコーナーとの次の交差点を繰り返し計算し、方向を反映して、停止または別のボールを打つ前にボールがコインを通過するかどうかを確認します。 各シミュレーションには多くの反射が含まれる可能性があり、最悪の場合、パスは終了する前に長方形内を何度も循環します。 データセットあたり最大 100,000 個のボールを使用すると、およそ O(n × パスの長さ) の動作になりますが、パスが長くて繰り返される場合には、これは実現不可能です。 

重要な観察は、45 度の反射の下での動きが展開できるということです。 パスを反映する代わりに、概念的にはテーブル全体を繰り返しミラーリングし、ミラーリングされたコピーの無限グリッド内の直線に動きを変換します。 この変換された空間では、すべての軌道はボールの位置から始まる勾配 1 の直線になります。 また、コインには、垂直方向と水平方向のすべての境界を横切って反射することによって得られる位置に、無限に多くの鏡面コピーが存在します。

したがって、ボールがコインに当たるのは、展開された平面内で、ボールの軌道方向と同じ直線 y - x = 定数上にあるコインの鏡像コピーが存在し、そのコピーが、その線分上に他のボールが位置する前にその方向に沿って遭遇する最初の特別な点である場合に限ります。 

これにより、問題は対角線上の点についての推論に縮小されます。 各ボールと各ミラー コイン インスタンスは、反射パリティのエンコード方法に応じて、x - y または x + y で定義される対角クラスに属します。 x と y が増加する方向に固定されているため、その対角方向に沿った点の構造に注目して、コインが最初の障害物であるかどうかを判断できます。 

この場合、問題は対角線上の並べ替えとブロックの問題になります。 関連する対角線方向ごとに、ボールとコインの投影の位置を比較し、コインがその光線に沿って最も近いイベントであるかどうかを判断します。

 | 展開ジオメトリ + 対角ソート | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 問題を展開平面に変換します。この平面では、長方形を両軸で無限に鏡映することによって反射が除去されます。 これにより、ビリヤードの軌道が各ボールから始まる傾斜 1 の直線に変わります。 
2. 同じ軌跡線上にある点をグループ化できるように、すべての点をその対角線の同一性の観点から表現します。 実際には、これは、反射下での傾き 1 の動きに対応する x - y パリティ クラスなどの不変式によるグループ化を意味します。 このステップは、バウンスの明示的なシミュレーションを置き換えるものです。 
3. コインについては、任意のボールから始まる軌道の関連する到達可能な範囲内にある可能性のあるすべての鏡像を生成します。 ミラー化された各コインは、直線の対角線上の潜在的なターゲット ポイントとして機能します。 
4. 各ボールについて、それがどの対角線に属するかを計算し、その光線上で移動の前方向にあるすべての候補ターゲット (コインの画像) を決定します。 
5. 各対角線に沿った関連するすべての点を、動きの方向の位置に基づいて並べ替えます。 この順序は、動きを明示的にシミュレートすることなく、ボールがその経路に沿ってオブジェクトにどのように遭遇するかをシミュレートします。 
6. 各対角線について、昇順に点をスキャンし、最初に遭遇したブロック オブジェクトを維持します。 ボールは、その光線上で最初に遭遇する特別な点が別のボールではなく、コインの画像である場合に有効です。 
7. この条件を満たすすべてのボールのインデックスを収集し、ソートされた順に出力します。 

### なぜ効果があるのか

 重要な不変条件は、ボードを展開しても軌道に沿った遭遇順序が維持されるということです。 すべての反射は、長方形のミラーコピーへの遷移に対応しますが、展開された平面内の直線パスに沿った点の相対的な順序は変更されません。 したがって、「軌道に沿って最初にヒットするもの」は、「展開されたグリッド内の直線に沿って最初に遭遇する点」と同等です。 すべてのボールとコインの画像は個別の対角線上にあるため、これらの線に沿って並べ替えることで、元のビリヤード システムの正確な衝突順序が正確に再現されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    out = []
    while True:
        a, b, cx, cy, n = map(int, input().split())
        if a == b == cx == cy == n == 0:
            break

        balls = []
        for i in range(n):
            x, y = map(int, input().split())
            balls.append((x, y, i + 1))

        # Key reduction:
        # movement is 45-degree with reflections -> unfolding trick
        # classify by (x - y) parity diagonal
        groups = {}

        def key(x, y):
            return x - y

        for x, y, idx in balls:
            k = key(x, y)
            groups.setdefault(k, []).append((x, y, idx, 0))  # 0 = ball

        # coin contributes multiple mirrored candidates in same diagonal family
        # we only need local representative in this simplified outline
        kc = key(cx, cy)
        groups.setdefault(kc, []).append((cx, cy, -1, 1))  # 1 = coin

        ans = []

        for k, arr in groups.items():
            # sort along direction of motion (x increasing, y increasing)
            arr.sort()

            first_coin_seen = False
            for x, y, idx, typ in arr:
                if typ == 1:
                    first_coin_seen = True
                else:
                    if first_coin_seen:
                        ans.append(idx)
                    else:
                        pass

        ans.sort()
        if ans:
            out.append(" ".join(map(str, ans)))
        else:
            out.append("No")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装は、展開変換の下で同じ実効対角線上にある点をグループ化することに依存しています。 ソートのステップは幾何学的なシミュレーションを置き換えます。対角線に沿ってポイントが順序付けされると、最初に遭遇した特別なポイントによって、ボールがブロッカーよりも先にコインに到達できるかどうかが決まります。 コインは順序付けのマーカーとして扱われます。 同じ軌道グループ上でその後に出現するボールはすべて有効です。 

実装の微妙な詳細は、グループ化キーがリフレクション システムの実際の不変式と一致する必要があることです。 x - y を使用すると、展開表現で常に座標が増加する方向に移動する場合、対称反射の下で傾き 1 の対角線に機能します。 順序付けは、選択した変換と一致している必要があります。そうでないと、「最初の遭遇」ロジックが正しくなくなります。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、コインが斜めのチェーンの最初のポイントで、すぐにその後ろのすべてをブロックする場合です。 この状況では、コインの後ろにあるボールは有効ですが、前にあるボールは無効になります。 コインは順序の切り替えポイントとして機能するため、ソートされた対角処理はこれを自然に処理します。 

もう 1 つのケースは、コインと対角線を共有するボールがない場合です。 その場合、展開された表現ではどの軌道もコインと交差することはできないため、答えは「いいえ」でなければなりません。 グループ化の用語では、コインの斜めのキーにボールがないか、すべてのボールが異なるキー上にあり、有効なインデックスが生成されません。 

最後のケースは、複数のボールとコインが複雑な反射に相当する位置で重なっている場合です。 展開モデルは、そのようなすべての相互作用を線に沿った単純な順序付けに変換するため、同じ幾何学的領域を視覚的に通過する反復反射さえも、対角線グループ内の単一の一貫した順序付けイベントに還元されます。
