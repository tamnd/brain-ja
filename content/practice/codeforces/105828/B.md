 ## 問題の理解

 私たちに与えられているのは、$n \times n$すべてのセルに次の整数が含まれるグリッド$1$に$k-1$。 2 人の異なる人が 2 つの異なる集計ルールを使用して、この同じグリッドからスコアを抽出します。 

1 人が各列を調べ、その列の最小値を見つけて、これらを合計します。$n$ミニマ。 もう一人も同じプロセスを、列ではなく行に沿って実行します。 最初の合計を合計と呼びます$X$そして2番目の合計$Y$。 タスクは、次のような比率でグリッドを構築することです。$X / Y$できるだけ大きいです。 

グリッドは指定されていません。 のみ$n$そして$k$が提供されます。 これは、問題は完全に、固定行列を評価するのではなく、制約の下で値の最適な配置を設計することに関するものであることを意味します。 

制約$n \le 100$そして$k \le 10$は十分に小さいため、値パターンに対する指数関数的推論または組み合わせ推論が許容されます。 ただし、すべてを対象とした単純な完全検索は、$k^{n^2}$グリッドは不可能であり、行と列の最小値が密結合しているため、構造のないセルごとの貪欲な選択でも失敗します。 

すべての値が等しい場合、微妙なエッジケースが発生します。 すべてのセルが同じ数字の場合$x$、その後両方$X$そして$Y$等しい$n \cdot x$したがって、比率は正確に$1$。 このような場合、正しい解決策は対称性を正しく維持する必要があります。 

もう 1 つのエッジ シナリオは次のような場合です。$k = 2$、すべての細胞がいずれかであることを意味します$1$。 次に、両方の合計が固定されて等しくなり、比率が強制されます。$1$。 価値観の多様性を前提としたソリューションは、改善を誤って過大評価することになります。 

本当の難しさは、通常、列の最小値を改善すると行の最小値が悪化すること、またその逆も同様であるため、最適な構造を局所的に調整できないことです。 

## アプローチ

 強引なアイデアは、考えられるものをすべて列挙することです$n \times n$値を含むグリッド$[1, k-1]$、計算する$X$そして$Y$、最適な比率を追跡します。 これは原理的には正しいですが、グリッドの数は$(k-1)^{n^2}$、それも$n = 4$、$k = 5$天文学的に大きいです。 この空間のごく一部であっても計算することは不可能です。 

進歩するには、個々のセルの観点から考えるのをやめ、代わりに最小値がどのように「割り当てられる」のかという観点から考える必要があります。 各行の最小値は正確に 1 つの列に影響し、各列の最小値は正確に 1 つの行に由来します。 これは、重要なのは完全な行列ではなく、値が行と列で強制的に最小値になる頻度であることを示唆しています。 

重要な点は、行の最小値をできるだけ小さく保ちながら、列の最小値をできるだけ大きくする必要があるということです。 値は以下によって制限されるため、$1$、最良の戦略は、制御されたパターンで小さな値を集中させ、列の最小値よりも行の最小値に影響を与えることです。 これにより、行が列よりも低い値に「影響を受ける」という非対称性が生じます。 

最適な構築は単純な組み合わせ構造に帰着します。閾値を選択します。$t$各行に小さな値が 1 つだけ存在するようにグリッドを配置します。$1$、残りは最大化され、列の最小値がほとんど影響を受けないように配置を制御します。 これらの低い値が行と列にどのように伝播するかを調整することで、比率は次の条件のみに依存する関数に単純化されます。$n$そして$k$、最適な構成は、シミュレーションではなく分析的に導き出すことができます。 

最終的な解決策では、明示的なグリッド構築を回避し、代わりに達成可能な最良の比率を求める閉形式を導出します。

 ## アルゴリズムのチュートリアル

 1. 各行が 1 つの値だけを寄与していることを観察します。$Y$、その行の最小値。 グリッドを制御するので、広がりを制限しながら、これらの行の最小値をできるだけ小さくしようとします。 
2. 各行に意図的に小さい値が 1 つだけ含まれ、他のすべての値が許容される限り大きいパターンを構築します。$k-1$。 これにより、行の最小値が固定され、最小になることが保証されます。 
3. これらの小さな値を周期的または均等に分散して個別の列に配置し、各列ができるだけ少ない値の影響を受けるようにします。 この構造により、ほとんどの列の最小値が大きく保たれます。 
4. コンピューティング$Y$行の最小値の合計として直接計算されます。 各行には強制的に小さい値が 1 つだけ含まれるため、$Y$になる$n \cdot 1 = n$。 
5. コンピューティング$X$少なくとも 1 行で実際に小さい値を受け取る列の数を分析します。 それらの列のみが貢献します$1$、未処理の列が寄与する一方、$k-1$。 
6. 小さな値を完全に避ける列の数を最大化します。 これにより、削減された列の最小値の数が減り、増加します。$X$。 
7. 結果の比率を表現します$X/Y$「クリーンな」状態を維持できる列の数と、小さなエントリを含めることを強制される列の数の関数として。 

### なぜ効果があるのか

 この構造により、行の最小値が可能な限り低い値に固定されると同時に、列全体にわたるそれらの低い値の広がりが最小限に抑えられます。 各セルは正確に 1 つの行の最小値と 1 つの列の最小値に影響を与えるため、問題は重複パターンの制御に帰着します。 低い値を最適に分散することから逸脱すると、行の最小値が増加するか、より多くの列が汚染され、どちらも比率が減少します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

# If k == 2, only value is 1, ratio is always 1
if k == 2:
    print(1.0)
else:
    # Optimal ratio derived from optimal placement structure
    # X = n*(k-1) - (n-1)
    # Y = n
    # ratio = (n*(k-1) - (n-1)) / n
    x = n * (k - 1) - (n - 1)
    y = n
    print(x / y)
```コードは縮退ケースの処理から始まります$k = 2$すべてのセルが同一であるため、意味のある最適化は不可能です。 この場合、両方の構造が同じ値に崩壊します。 

のために$k > 2$、この式は、行ごとに正確に 1 つの最小限の外乱を強制しながら、列の最小値を最大化することから得られます。 用語$n \cdot (k-1)$すべての列の最小値が最大化され、減算される理想的なケースを表します。$n-1$行の最小値制約を維持する方法で行全体に最小値を分散することによって引き起こされる避けられない汚染を考慮します。 

除算$n$計算された列の集計を最終的な比率に変換します。
