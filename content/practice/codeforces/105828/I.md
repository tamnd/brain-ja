 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、$2n$学生と、同じ研究グループに所属できないペアのリスト。 課題は、すべての生徒を 2 つのグループに分け、それぞれのグループに正確な内容を含めることです。$n$禁止されたペアが単一のグループ内に入ることがないようにするためです。 分割を構築するように求められるのではなく、有効な分割がいくつ存在するかをカウントし、その結果を剰余として取得するだけです。$10^9 + 7$。 2 つのグループの名前を入れ替えるだけで異なる 2 つのスプリットは、同一とみなされます。 

グラフの観点から見ると、各スチューデントは頂点であり、各禁止ペアは無向エッジです。 有効なパーティションは、すべてのエッジが異なる辺の頂点を接続し、両方の辺が同じサイズになるように、すべての頂点を 2 つの辺のいずれかに割り当てる方法です。$n$。 

制約は、非常に特殊な計算構造を意味します。 頂点の数は最大です$2000$、エッジの数が到達する可能性がありますが、$10^5$。 これにより、生徒のサブセットに対する指数関数的な列挙が除外されます。 選択する方法が無数にあるため、すべてのパーティションの二次検査さえ不可能です。$n$のうち$2n$すでに天文学的な規模になっています。 このソリューションは、グラフ構造と、集約されたコンポーネントに対する動的プログラミングに依存する必要があります。 

グラフが 2 部構成でない場合、微妙なエッジ ケースが発生します。 例えば、生徒同士の対立のトライアングルがあったとします。$1, 2, 3$、すべてのエッジを 2 つのグループにまたがって配置することは不可能なので、答えはゼロでなければなりません。 二者構成をチェックせずにグループサイズのバランスを取るだけの単純なアプローチでは、そのようなケースは誤ってカウントされてしまいます。 

もう 1 つの重要なエッジ ケースは、グラフが 2 部構成であるが接続されていない場合です。 各連結コンポーネントは、どの色をグループ A に入れるかを個別に決定できます。ただし、これらの選択はグループ A の最終的なサイズに影響するため、コンポーネントの反転の組み合わせによっては、グループ A を上回るか下回る場合があります。$n$。 コンポーネントごとの素朴な貪欲な割り当ては、ローカルな決定がグローバルな制約に影響を与えるため、ここでは失敗します。 

## アプローチ

 直接的なブルートフォースソリューションでは、あらゆる方法を試して選択することになります。$n$の学生$2n$、次に、選択したグループまたはその補体の内側に完全に禁止されたエッジがないかどうかを確認します。 これには反復処理が必要です$\binom{2n}{n}$サブセットとすべてのチェック$m$各サブセットのエッジ。 たとえ$2n = 20$、これは実行不可能になり、実際の制約では$2n = 2000$、それはまったく不可能です。 

重要な観察は、禁止エッジは二部制約を課すだけであるということです。 グラフに奇数のサイクルが含まれている場合、有効な割り当てはまったく存在しません。 それ以外の場合、接続された各コンポーネントは構造の観点から独立して動作します。1 つの頂点の辺を修正すると、コンポーネント全体がグローバルな反転まで決定されます。 

接続されたコンポーネントごとに、BFS または DFS を使用して 2 つのパーティションを計算できます。 コンポーネントの 1 つの任意の有効なカラーリングで、カラーリングされた頂点の数が 0 であると仮定します。$a_i$、コンポーネントのサイズは$s_i$。 そのコンポーネントの色を反転すると、グループ A に対するこのコンポーネントの寄与は次のようになります。$s_i - a_i$。 したがって、各コンポーネントは、グループ A の合計サイズに影響を与える二者択一の選択に寄与します。 

これにより、選択した値の合計が正確に等しくなるように、コンポーネントごとに 2 つの値のうち 1 つを選択するという問題が軽減されます。$n$。 これは、コンポーネントに関する古典的なナップザック スタイルの動的プログラミングの問題です。 唯一残っている微妙な点は、最終的な色付けが 2 つのグループのグローバル スワップごとに 1 回ずつ計 2 回カウントされるため、最終的な答えを 2 で割る必要があることです。

 ## アルゴリズムのチュートリアル

 まずスチューデントをグラフの頂点として扱い、禁止されたペアから隣接リストを構築します。 

1. 未訪問の各頂点に対して BFS または DFS を実行して、接続されているコンポーネントを調べます。 この走査中に、各頂点に 2 部カラー 0 または 1 を割り当てます。 エッジが同じ色の 2 つの頂点を接続する競合に遭遇した場合、グラフは 2 部ではなく、答えは即座に 0 になります。 このステップにより、禁止されたペアが構造だけによって 1 つのグループ内に強制的に入れられることがなくなります。 
2. 各連結コンポーネントについて、カラー 0 を受け取った頂点の数を数えます。この値を次のようにします。$a_i$、コンポーネントのサイズを次のようにします$s_i$。 このペアを 2 つの可能な寄与として暗黙的に保存します。$a_i$グループAに貢献する、または$s_i - a_i$コンポーネントを反転するかどうかに応じて、そうします。 
3. 動的プログラミング配列を初期化します。$dp[x]$コンポーネントの一部のプレフィックスを処理する方法の数を表します。$x$学生はグループ A に割り当てられます。最初は、$dp[0] = 1$。 
4. コンポーネントごとに、新しい DP アレイを構築します。 既存のすべての合計から$x$に移行します$x + a_i$そして$x + (s_i - a_i)$に応じてウェイの数を追加します。 このステップでは、コンポーネントを反転するかどうかの決定をエンコードします。 
5. すべてのコンポーネントを処理した後、値は$dp[n]$グループ A が正確に持つ有効な色の割り当ての数を返します。$n$学生たち。 
6. 2 つのグループを交換しても新しい有効なパーティションは作成されないため、この DP ではすべての有効なパーティションが 2 回 (グローバル カラー スワップごとに 1 回) カウントされます。 最終的な答えに 2 の逆剰余を掛けます。 

### なぜ効果があるのか

 2 部構成のカラーリング ステップでは、すべての禁止エッジが各コンポーネント内の反対の色の間にあることが保証されるため、コンポーネントがどのように反転されるかに関係なく、どのエッジも条件に違反することはありません。 各接続コンポーネントは構造的に独立していますが、グループ A に 2 つの可能なサイズの固定選択肢を提供します。DP はこれらの独立した選択肢の一貫した組み合わせをすべて列挙し、最終的な制約によって全体的なバランスが保証されます。 唯一の過剰カウントは 2 つのグループの交換の対称性から生じており、これはすべての解に均一に影響を与えます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
INV2 = (MOD + 1) // 2

n, m = map(int, input().split())
N = 2 * n

g = [[] for _ in range(N + 1)]
for _ in range(m):
    a, b = map(int, input().split())
    g[a].append(b)
    g[b].append(a)

color = [-1] * (N + 1)
components = []

from collections import deque

for i in range(1, N + 1):
    if color[i] != -1:
        continue
    q = deque([i])
    color[i] = 0
    cnt0 = 0
    size = 0
    ok = True

    while q:
        v = q.popleft()
        size += 1
        cnt0 += (color[v] == 0)

        for to in g[v]:
            if color[to] == -1:
                color[to] = color[v] ^ 1
                q.append(to)
            elif color[to] == color[v]:
                ok = False

    if not ok:
        print(0)
        sys.exit(0)

    cnt1 = size - cnt0
    components.append((cnt0, cnt1))

dp = [0] * (n + 1)
dp[0] = 1

for a, b in components:
    ndp = [0] * (n + 1)
    for i in range(n + 1):
        if dp[i] == 0:
            continue
        if i + a <= n:
            ndp[i + a] = (ndp[i + a] + dp[i]) % MOD
        if i + b <= n:
            ndp[i + b] = (ndp[i + b] + dp[i]) % MOD
    dp = ndp

ans = dp[n] * INV2 % MOD
print(ans)
```グラフ構築ステップでは、二部チェックがエッジの数において線形になるように隣接リストを構築します。 BFS セクションは、実現可能性をチェックすると同時に、各コンポーネントのサイズ分割を計算します。 動的プログラミング配列は次のように制限されます。$n$、 ない$2n$1 つのグループのサイズのみを追跡するためです。 

最終的な乗算$INV2$2 つのグループのラベルを交換すると同じパーティションが生成されるという固有の対称性が修正されます。

 ## 特殊なケース

 主なエッジケースは、禁止されたペアがない場合です。 この状況では、グラフは次のようになります。$2n$各頂点は、サイズ 1 のコンポーネントとして機能します。各頂点は、反転の選択に応じてグループ A に 0 または 1 を与えるため、DP は二項係数の計算になります。 のために$n=2$、 がある$\binom{4}{2} = 6$割り当てを行い、2 で割ると 3 つの有効なパーティションが得られ、予想される組み合わせ結果と一致します。 

もう 1 つのエッジ ケースは、三角形などの単一の奇数サイクルです。 BFS カラーリング中、アルゴリズムは最終的にエッジの 2 つの端点に同じ色を割り当て、即時拒否をトリガーします。 これにより、DP は 2 部構造を想定しているため必要となる DP の計算が妨げられます。 

最後の微妙なケースは、すべてのコンポーネントが偶数のサイクルまたはツリーであるが、そのサイズの影響により正確に到達することが不可能な場合です。$n$。 その場合、DP 配列は単純に次のように終わります。$dp[n] = 0$これは、ローカルの二部性が成立するにもかかわらず、サイズ制約を満たすグローバル割り当てがないことを正しく示しています。
