## アルゴリズムのチュートリアル

 DFS を使用して空のプレフィックスから開始し、次の数字を繰り返し追加して、ゼロ桁を含まないすべての数値を構築します。`1`に`9`。 構築中は現在の数値を維持します。 

1. 空の数値とゼロに初期化されたカウンターから開始します。 これは、数字列の検索ツリーのルートを表します。 
2. 現在の数値ごとに、次の各桁を追加してみます。`1`に`9`新しい番号を形成します。 私たちは明示的に避けます`0`これにより、後でフィルタリングするのではなく、構築時に数字の制約が適用されます。 
3. 新しい数値が以下の場合`n`、これ以上延長するのはやめます。 これ以上拡張しても値が増加するだけなので、子孫を有効にすることはできません。 
4. 新しい番号が少なくとも`2`, 平方根までの試行除算を使用して、それが素数であるかどうかをテストします。 素数の場合、応答カウンターをインクリメントします。 
5. この新しい番号から再帰的に DFS を続行します。 

再帰では、すべての有効な数字文字列が長さの昇順に自然に探索されますが、次のように枝刈りが行われます。`n`爆発を防ぎます。

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def is_prime(x: int) -> bool:
    if x < 2:
        return False
    if x % 2 == 0:
        return x == 2
    r = int(math.isqrt(x))
    d = 3
    while d <= r:
        if x % d == 0:
            return False
        d += 2
    return True

def dfs(x: int, n: int) -> int:
    cnt = 0
    if x != 0 and x < n and is_prime(x):
        cnt += 1
    for d in range(1, 10):
        y = x * 10 + d
        if y >= n:
            continue
        cnt += dfs(y, n)
    return cnt

def main():
    n = int(input().strip())
    print(dfs(0, n))

if __name__ == "__main__":
    main()
