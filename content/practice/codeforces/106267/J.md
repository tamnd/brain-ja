 ## 解決策
 ## 問題の理解

 平面内にはいくつかの円が与えられます。 各円には固定の中心と半径があり、単一の非負の係数によってすべての半径をスケールすることができます。$k$。 After scaling, every circle becomes a disk with the same center but radius$k \cdot r_i$。 

次に、すべての円盤と交差する単一の直線が存在するかどうかを尋ねます。 ここでの交差とは、線が円盤を横切るか、円盤に接することを意味します。 もし$k = 0$、すべての円が点になるため、線はすべての中心を通過する必要があります。 

タスクは最小のものを見つけることです$k$such that at least one line can simultaneously intersect all scaled disks.

 重要な幾何学的制約は、ディスクの中心からラインまでの垂直距離がその半径以内である場合にのみ、ラインがディスクと交差するということです。 So for a fixed line, each circle imposes an upper bound on the allowed distance of its center from the line.

 と$n$2000 年頃までは、円のペアまたはトリプルによって決定されるすべてのラインに対する素朴なチェックは、慎重に行えばすでに実現可能性の限界に達していましたが、任意のラインに対する直接的な幾何学的検索は不可能でした。 The structure of the constraint forces us to convert the problem into something that depends only on pairwise relationships.

 A subtle edge case appears when all centers are identical. その場合、どの行でも機能します$k = 0$、すべての円が同じ位置の点に折りたたまれるためです。 ペアワイズ ジオメトリを前提とした不用意な解決策はまだ機能する可能性がありますが、次のような式で除算する実装は問題ありません。$r_i + r_j$下流ステップでのゼロまたは縮退動作を回避する必要があります。 

もう 1 つのエッジ ケースは、すべての半径が等しい場合です。 答えは必ずしもゼロではありません。スケーリングが等しい場合でも、線はすべての中心から一定の距離内を通過する必要があり、これは点セットの純粋な幅の問題になります。 

## アプローチ

 ブルートフォースの観点は定義から始まります。 直線を推測し、最小値を計算します。$k$その行に必要な値をすべての行で最小化します。 固定回線の場合$L$、各サークル$i$制約に貢献する$k \ge \frac{d_i}{r_i}$、 どこ$d_i$中心から線までの距離です。 それで最高$k$その線はこれらの比率の最大値であるためです。 難しいのは、行の間隔が連続しているため、組み合わせ的に意味のある候補に限定しても、結果が残らないことです。$O(n^2)$またはそれ以上の可能性があります。 

重要な観察は、線をその法線方向によってパラメータ化できるということです。 ユニットの方向を固定する$n$、すべての点をその軸に投影します。 次に、この方向に沿ったシフトによってラインが決定され、実現可能性は区間交差条件にまで下がります。 これにより、ジオメトリが各方向の 1D 最適化問題に変換されます。 

固定方向の場合$n$、各点$p_i$スカラーへのプロジェクト$t_i = p_i \cdot n$。 に直交する線$n$シフトの選択に対応します$c$、そして実現可能性は次の形式の制約のセットになります。$|t_i + c| \le k r_i$。 各ポイントは有効な間隔に寄与します。$c$、すべての間隔が交差する必要があります。 

これにより、問題はペアごとの差に関する制約に変換されます。$$|t_i - t_j| \le k (r_i + r_j)$$したがって、一定の方向については、$$k(n) = \max_{i,j} \frac{|(p_i - p_j)\cdot n|}{r_i + r_j}.$$次にベクトルを定義します$$u_{ij} = \frac{p_i - p_j}{r_i + r_j}.$$すると式は次のようになります$$k(n) = \max_{i,j} |u_{ij} \cdot n|.$$したがって、円について推論する代わりに、一連の点について推論します。$u_{ij}$飛行機の中。 方向性を決めたい$n$これにより、このセットの最大投影が最小限に抑えられます。 幾何学的には、これは回転中の点セットの最小幅となります。 

残された問題は、$u_{ij}$もっている$O(n^2)$要素ですが、$n$は十分小さいため、すべてのペアを構築できます。 セットが構築されると、問題は古典的な凸型ハルの幅の問題になり、回転キャリパーで解決できます。

 ## アルゴリズムのチュートリアル

 1. すべてのペアごとのベクトルを構築します$u_{ij} = \frac{(x_i - x_j, y_i - y_j)}{r_i + r_j}$みんなのために$i < j$、暗黙的または明示的に対称的な否定も含まれます。 このステップでは、円拘束を単一の幾何学的点セットに変換します。 
2. すべてを治療する$u_{ij}$平面内の点として。 目標は、このセット全体の最大絶対内積を最小化する方向を見つけることです。 
3. これらすべての点の凸包を計算します。 厳密にハルの内側にあるポイントは極値投影に影響を与えないため、答えを変更せずに破棄できます。 
4. 凸包に回転キャリパーを適用して、全方向にわたる最小幅を計算します。 船体の各エッジについて、その方向を法線方向の候補として扱い、支持線間の距離を計算します。 
5. 得られる最小幅は、投影の可能な最小範囲です。 セットは対称であるため（交換のため）$i$そして$j$ベクトルを否定します)、最大の絶対投影はこの幅の半分に等しくなります。 
6. 戻る$k = \frac{\text{minimum width}}{2}$。 

これが機能する主な理由は、固定方向に対する最悪の制約が常に点のペアによって実現され、一度正規化されるためです。$r_i + r_j$、これらのペアごとの制約は、有限平面点セットの線形投影のように動作します。 最適な方向は、そのセットの凸包の支持方向と一致する必要があるため、内部構成はハルのエッジよりも優れたソリューションを定義できません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def convex_hull(points):
    points = sorted(points)
    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def dot(a, b):
    return a[0] * b[0] + a[1] * b[1]

def width(points):
    n = len(points)
    if n <= 1:
        return 0.0

    j = 1
    best = float("inf")

    for i in range(n):
        ni = (points[(i + 1) % n][0] - points[i][0],
              points[(i + 1) % n][1] - points[i][1])

        while True:
            k1 = abs(ni[0] * (points[(j + 1) % n][0] - points[i][0]) +
                     ni[1] * (points[(j + 1) % n][1] - points[i][1]))
            k2 = abs(ni[0] * (points[j][0] - points[i][0]) +
                     ni[1] * (points[j][1] - points[i][1]))
            if k1 > k2:
                j = (j + 1) % n
            else:
                break

        cur = abs(ni[0] * (points[j][0] - points[i][0]) +
                  ni[1] * (points[j][1] - points[i][1])) / (ni[0]**2 + ni[1]**2)
        best = min(best, cur)

    return best * 2

n = int(input())
circles = [tuple(map(int, input().split())) for _ in range(n)]

pts = []
for i in range(n):
    x1, y1, r1 = circles[i]
    for j in range(i + 1, n):
        x2, y2, r2 = circles[j]
        denom = r1 + r2
        dx = (x1 - x2) / denom
        dy = (y1 - y2) / denom
        pts.append((dx, dy))

hull = convex_hull(pts)
ans = width(hull)
print(ans)
```構築フェーズでは、すべての正規化された差分ベクトルを構築します。 凸包は、非極端なペアの相互作用をすべて削除し、最大射影を定義できる候補だけを残します。 次に、回転キャリパーのステップで、すべての方向にわたってこの船体の可能な最小幅を見つけます。 

最終的な乗算と除算のロジックは、対称性の引数から直接得られます。すべてのベクトルの差はその否定とともに現れるため、幅は最大絶対射影の 2 倍に等しくなります。 

## 実用的な例

 ### 例 1

 ペアごとのベクトルを見やすくするために、小さな整数の座標を持つ 3 つの円を考えます。 2 つの点が特定の方向に支配的な正規化された差を生成すると仮定します。 このアルゴリズムは最初にすべてのペアごとのベクトルを構築し、次に凸包を介して内部のベクトルを破棄します。 

| ステップ | 状態 |
 | --- | --- |
 | ベクトルのペア | すべての正規化された差分$u_{ij}$|
 | 凸包 | 極端な方向ベクトルのみが残ります。 
| キャリパー | 各船体のエッジ方向をテストします。 
| 答え | 最小半角 |

 これは、内部ペア関係が、元の定式化に存在する場合でも、最終制約に決して影響を与えないことを示しています。 

### 例 2

 すべての円の半径が同一であるが、一列に分散している場合、ペアごとの正規化はスケールされた座標の差に帰着し、船体は 1D のような細長い形状になります。 

| ステップ | 状態 |
 | --- | --- |
 | ベクトルのペア | 共線集合 |
 | 凸包 | 2 つのエンドポイントが優勢 |
 | キャリパー | 垂直方向に沿って計算された幅 |
 | 答え | 極端な分離によって制御される |

 これは、ジオメトリが縮退すると、ソリューションが自然に古典的な幅の最小化に減少することを示しています。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべての半径が同一で、すべての中心が直線上にある場合です。 この場合、すべての正規化ベクトルは変換された空間内の単一の線上にあり、凸包はセグメントに縮退します。 回転キャリパーはまだ機能しますが、問題となるのは 2 つの対蹠方向のみであり、答えは純粋に極端なペアから得られます。 

複数の円が同じ中心を共有しているが、半径が異なる場合、別のエッジ ケースが発生します。 その後、多くのペアごとのベクトルがゼロになり、船体には影響を与えなくなります。 正しく実装するには、除算の問題を回避し、ゼロ ベクトルによってハルの計算が歪められないようにする必要があります。 

最後のケースは、1 つの円が非常に大きな半径で他のすべての円を支配する場合です。 すると、その円に関係するすべての正規化された差が非常に小さくなり、それに応じて船体が縮小します。 スケーリングはペアごとの正規化ステップにすでに組み込まれているため、アルゴリズムはこれを自然に処理します。
