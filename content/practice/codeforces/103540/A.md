 ## 解決策
 ## 問題の理解

 正確に構成されたトーナメントをシミュレートしています$n$ゲームでは、各ゲームが線形ランキング スケールでの順位を個別に増減させます。 ランクからスタートします$n+1$。 勝つたびにランクが 1 下がってトップに一歩近づきますが、負けるたびにランクが 1 上がってトップから遠ざかります。 

結局のところ、トーナメントは正常に終了します$n$ゲームでは、最終的には正確にランク 1 になります。$n+1$、ランク 1 に到達するということは、すべてのゲームでの正味の動きが正確である必要があることを意味します。$-n$、すべての勝利に相当します$n$ゲーム。 ゲーム数は固定されており、ターゲット ディスプレイスメントと対称であるため、損失が発生するとすぐに +1 のシフトが発生し、後で補うことは不可能になります。 

各ゲームは確率で勝ちます$p/q$、確率的に負けます$1 - p/q = (q - p)/q$。 出力は、すべてのゲームに勝つ確率をモジュロで表したものです。$10^9 + 7$分数として$x \cdot y^{-1}$、 どこ$x/y$は、簡略化された代数形式の確率です。 

制約により、最大で$2 \cdot 10^5$テストケース、$n, p, q$まで$10^{18}$。 これにより、階乗または組み合わせの DP が即座に除外されます。$n$。 平$O(n)$テスト ケースごとに実行することは不可能であるため、ソリューションでは各テスト ケースを定数時間モジュラー演算に削減する必要があります。 

微妙なエッジケースが現れるのは、$p = 0$、以下の場合を除き、勝率はゼロです。$n = 0$、 しかし$n \ge 1$常に、したがって、答えは 0 でなければなりません。別の例外的なケースは次のとおりです。$p = q$、ここで確率は 1 になり、モジュラー逆論理は誤ってゼロで除算してはなりません。 

単純な間違いは、プロセスをランダム ウォークとして解釈し、複数の状態にわたる DP を介してランク 1 に到達する確率を計算しようとすることです。 それはパスの長さに暗黙的に依存します$n$、不必要な指数時間または多項式時間につながります。 

## アプローチ

 トーナメントの直接シミュレーションは、すべてにわたって繰り返されます。$n$ゲーム、勝敗の結果に応じて確率を乗算します。 これはすぐに実行不可能になります。$n$と同じ大きさにすることができます$10^{18}$, したがって、すべての状態を書き出すことさえ不可能です。 

より構造化された試みは、ランクをランダム ウォークとしてモデル化し、その後の確率を計算することです。$n$これには通常、ゲームのどのサブセットが勝つかを選択するという二項推論が必要になります。 まさにその確率$k$勝利が起こるのは$\binom{n}{k}(p/q)^k((q-p)/q)^{n-k}$。 ただし、ランク 1 に到達するには、次のすべてが必要です。$n$勝利へのステップ、意味$k=n$。 その場合、損失がターゲットを無効にするため、二項係数は 1 に崩壊し、他の項はすべて消滅します。 

したがって、問題は多くの構成を合計するのではなく、単一の構成、つまりすべての勝利のシーケンスに集約されます。 その出来事が起こる確率は単純に$(p/q)^n$。 残っている唯一のタスクは、分子と分母の累乗を分割することによって行われる、分数のべき乗剰余の計算です。 

次のように計算します。$$\left(\frac{p}{q}\right)^n = p^n \cdot (q^n)^{-1} \pmod{10^9+7}$$これにより、各テスト ケースが 2 つの高速累乗に減らされます。

 ## アルゴリズムのチュートリアル

 ### 重要なアイデア

 負けるとすぐにランク 1 に到達することが不可能になるため、すべてのゲームで勝つ確率だけが必要です。 

### ステップ

 1. 整数の読み取り$n, p, q$テストケースごとに。 これらは、ゲームごとの指数と成功確率を定義します。 
2. コンピューティング$p^n \bmod M$、 どこ$M = 10^9 + 7$。 これは、すべてのゲームに勝つ確率の分子を表します。 2進累乗を使用する理由は、$n$まで可能です$10^{18}$、乗算を繰り返すと遅すぎます。 
3. コンピューティング$q^n \bmod M$。 これは確率を まで引き上げた後の分母を表します。$n$-乗。 
4. モジュラー逆関数を計算します。$q^n$モジュロ$M$。 以来$M$が素数である場合、フェルマーの定理を使用します。$$(q^n)^{-1} \equiv (q^n)^{M-2} \pmod{M}$$1. 乗算$p^n$モジュラー逆関数を使用して$q^n$、結果を出力します。 

### なぜ効果があるのか

 ランク条件により、独自の成功軌道が強制されます。つまり、すべてのゲームが勝利する必要があります。 ランク 1 で終了する混合結果の組み合わせの選択はありません。確率は独立したイベント全体で乗算されるため、確率の合計は同一項の 1 つの積に因数分解されます。 モジュラー演算では乗算構造が保持されるため、分子と分母を別々に計算し、モジュラー逆関数を介して組み合わせることで、モジュラー形式で正確な確率が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mod_pow(a, e):
    res = 1
    a %= MOD
    while e > 0:
        if e & 1:
            res = (res * a) % MOD
        a = (a * a) % MOD
        e >>= 1
    return res

t = int(input())
for _ in range(t):
    n, p, q = map(int, input().split())

    if p == 0:
        print(0)
        continue

    num = mod_pow(p, n)
    den = mod_pow(q, n)

    ans = num * mod_pow(den, MOD - 2) % MOD
    print(ans)
```実装では両方に 2 進累乗を使用します。$p^n$そして$q^n$。 逆モジュラーはフェルマーの小定理を使用して計算されます。これは有効です。$10^9+7$プライムです。 特別な場合$p = 0$不要なべき乗を回避し、直接ゼロを出力します。 

よくある落とし穴は、計算を試みることです。$(p/q)^n$最初に除算してから累乗する方法ですが、モジュラー算術では無効です。 正しいアプローチは、分子と分母を別々に累乗し、逆関数で結合することです。 

## 実用的な例

 ### 例 1

 入力:$n=2, p=1, q=2$次のように計算します。 

| ステップ | 値 |
 | --- | --- |
 |$p^n$|$1^2 = 1$|
 |$q^n$|$2^2 = 4$|
 | の逆数$4$|$4^{MOD-2}$|
 | 答え |$1 \cdot 4^{-1}$|

 これは確率と一致します$1/4$、両方のゲームに勝つ必要があり、それぞれに確率があることを意味します$1/2$。 

トレースは、損失があると必要な最終条件を破るため、中間ランクの状態は問題にならないことを確認します。 

### 例 2

 入力:$n=3, p=2, q=2$| ステップ | 値 |
 | --- | --- |
 |$p^n$|$2^3 = 8$|
 |$q^n$|$2^3 = 8$|
 | の逆数$8$|$8^{-1}$|
 | 答え |$8 \cdot 8^{-1} = 1$|

 これにより、次のことが確認されます。$p=q$, すべてのゲームで勝利が保証されているため、トーナメントに勝つ確率は 1 です。

## テストケース```python
import sys, io

MOD = 10**9 + 7

def mod_pow(a, e):
    res = 1
    a %= MOD
    while e > 0:
        if e & 1:
            res = (res * a) % MOD
        a = (a * a) % MOD
        e >>= 1
    return res

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n, p, q = map(int, input().split())

        if p == 0:
            out.append("0")
            continue

        num = mod_pow(p, n)
        den = mod_pow(q, n)
        ans = num * mod_pow(den, MOD - 2) % MOD
        out.append(str(ans))

    return "\n".join(out)

 ## 特殊なケース

 いつ$p = 0$の場合、アルゴリズムはべき乗せずにすぐに 0 を返します。 これによりコンピューティングが不要になります$0^n$大型用$n$、安全ですが不要です。 たとえば、入力$n=100, p=0, q=7$すべてのゲームに勝つことは不可能であるため、結果は 0 になります。 

いつ$p = q$、分子と分母の両方が等しい累乗になるため、結果は 1 に単純化されます。$n=10^{18}, p=5, q=5$、 両方$5^n$逆モジュラーで正確にキャンセルすると、アルゴリズムは正しく 1 を返します。 

いつ$n = 1$、結果は単純になります$p \cdot q^{-1}$、アルゴリズムは構造を変更することなく単一のモジュラー分数に正確に縮小されます。
