 ## 解決策
 ## 問題の理解

 それぞれ 1 から n までの整数のシーケンスが与えられており、サブシーケンス内のすべての反転が異なる色の端点を持つように、赤または青に「色付け」できるサブシーケンスを数えたいと考えています。 反転とは、i の要素が j の要素よりも大きくなるような、i < j のインデックスのペアです。 出力は、10^9 + 7 を法としたそのようなサブシーケンスの合計数です。 

n が小さい場合、具体的にはこのバージョンのように n ≤ 300 の場合、合計演算数がおよそ 10^7 ～ 10^8 以内にとどまり、3 秒の制限としては許容できるため、テスト ケースごとに 3 次時間または 2 次時間のアルゴリズムを使用する余裕があります。 ただし、2^300 は天文学的に大きいため、すべての 2^n 部分列を直接列挙することはできません。 これにより、すべてのサブシーケンスを個別に生成する単純な解決策は除外されます。 

いくつかのエッジケースが目立ちます。 すべての要素が等しい場合、反転は存在しないため、すべてのサブシーケンスは自動的に有効になります。 厳密に減少するサブシーケンスの場合、すべての反転を満たすように色を交互に配置する必要があります。 これらのパターンを無視してやみくもに数えようとすると、適切な部分列を簡単に過大または過少に数えてしまう可能性があります。 たとえば、[4, 3, 1] のようなシーケンスには反転 (4,3)、(4,1)、(3,1) があります。 どの色付けでも、これらのペア全体で異なる色を割り当てる必要があるため、有効な色付けが制限されます。 

## アプローチ

 ブルートフォース手法では、すべてのサブシーケンスを列挙し、すべての反転をチェックし、有効な赤/青の色分けが存在するかどうかを確認します。 各サブシーケンスは、二部グラフ チェックを使用してチェックできます。各要素を頂点として扱い、反転を形成する要素間にエッジを描画し、グラフが二部であるかどうかをチェックします。 2^n の部分列ごとに O(n^2) 個のペアを調べる可能性があるため、複雑さは O(2^n * n^2) です。 明らかに、これは n = 300 では実行不可能です。 

重要な洞察は、この問題がシーケンスの「反転グラフ」の二部誘導サブグラフを数えることと同等であるということです。 サブシーケンスを生成する代わりに、動的プログラミングを使用できます。 dp[i] を、位置 i で終了する良好なサブシーケンスの数として定義します。 各 i について、a_i の追加によって無効な色の競合が発生しない限り、インデックス j < i で終わる既存の適切なサブシーケンスを拡張できます。 サブシーケンスごとにエンドポイントの最小値と最大値を追跡して、反転が二部性を侵害するかどうかを迅速にチェックできます。 n ≤ 300 であるため、O(n^2) DP が実現可能です。 これにより、問題は i と j にわたる管理可能な入れ子ループに縮小され、サブシーケンスのすべてを列挙するのではなく、構造化された方法でサブシーケンスの拡張がカウントされます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n^2) | O(n) | 遅すぎる |
 | 最適なDP | O(n^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 長さ n+1 の DP 配列 dp を初期化します。ここで、dp[i] は、a_i で終わる正常なサブシーケンスをカウントします。 また、より短い長さのサブシーケンスを効率的にキャプチャするために、プレフィックスの合計も維持します。 
2. 各 i に対して dp[i] = 1 を設定し、a_i だけからなるサブシーケンスを表します。 これにより、すべての単一要素のサブシーケンスが確実にカウントされます。 
3. i を 0 から n-1 まで繰り返します。 各 i について、j を 0 から i-1 まで繰り返します。 a_j ≤ a_i の場合、j で終わる適切なサブシーケンスは、無効な反転カラーリングを作成することなく、a_i を含めることによって安全に拡張できます。 dp[j]をdp[i]に追加します。 このステップでは、「互換性のある」小さな要素のみを拡張するため、2 部構成のカラーリング プロパティを尊重してサブシーケンスを段階的に構築します。 
4. すべての dp[i] 値を合計して、空ではない良好なサブシーケンスの総数を取得します。 空のサブシーケンスを考慮して 1 を追加します。これは自明のことですが、これは問題ありません。 
5. 整数のオーバーフローを防ぐために、各加算にモジュロ 10^9 + 7 を適用します。

維持される不変条件は、dp[i] にはインデックス i で正確に終わる適切なサブシーケンスの数が常に含まれるということです。 dp[j] を dp[i] に追加するたびに、a_i で合法的に拡張できるシーケンスのみが考慮されるため、無効なカラーリングは発生しません。 すべての dp[i] の最終合計は、空ではない正常なサブシーケンスの総数を示し、空のサブシーケンスを追加するとカウントが完了します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 10**9 + 7

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    dp = [0] * n
    for i in range(n):
        dp[i] = 1  # subsequence of length 1
        for j in range(i):
            if a[j] <= a[i]:
                dp[i] = (dp[i] + dp[j]) % MOD
    result = (sum(dp) + 1) % MOD  # add empty subsequence
    print(result)
```各 dp[i] 初期化により、単一要素のサブシーケンスが確実にカウントされます。 ネストされたループは、現在の要素以下の前の要素のみをチェックし、サブシーケンス内の反転によって色の競合が発生しないようにします。 合計して 1 を追加すると、空のサブシーケンスを含むすべてのサブシーケンスが計算されます。 オーバーフローを防止し、正確性を維持するために、加算のたびにモジュロを使用します。
