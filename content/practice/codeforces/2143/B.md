 ## 解決策
 ## 問題の理解

 割引券などを利用して総額を最小限に抑えながら、個別価格のセット商品を購入していただきます。 各バウチャーを使用すると、一定数の製品を選択し、その中で最も安い製品を無料で入手できます。 各バウチャーは 1 回のみ使用でき、製品を複数のバウチャー グループに含めることはできません。 目標は、すべての製品でクーポンを最も安く使用する方法を見つけ出すことです。 

入力は複数のテスト ケースで構成されます。 それぞれのケースについて、製品の数、価格、伝票の価値がわかります。 出力は、各テスト ケースの最小コストです。 までの制約付き$2 \cdot 10^5$すべてのテスト ケースにわたって製品とバウチャーを組み合わせた場合、どのソリューションもおおよそ線形または線形時間で機能し、二次関数を排除する必要があります。$n$または$k$。 

多くのバウチャーがサイズ 1 である場合、微妙なエッジ ケースが発生します。その場合、各バウチャーで 1 つの製品を無料で受け取ることができます。 不注意なアプローチでは、グループ化を無視し、無料の単一製品の可能性を考慮せずに、より大きなバウチャーを最初に適用する可能性があります。 たとえば、価格が 5、3、2、1 の商品とクーポン [1、1、3] がある場合、最適な解決策は、2 つの最も安い商品に 2 つの 1 サイズのクーポンを使用し、残りの 2 つと 1 つの既に無料の商品に 3 サイズのクーポンを使用することです。 伝票サイズの注文を無視すると、総コストが高くなる可能性があります。 

もう 1 つのエッジ ケースは、バウチャーの数が製品の数を超えている場合、またはバウチャーのサイズが残りの製品の数より大きい場合です。 利用可能な以上の製品を決して割り当てないようにして、これらを適切に処理する必要があります。 

## アプローチ

 ブルートフォース ソリューションでは、商品の伝票への割り当てをすべて試み、各組み合わせの合計コストを計算します。 これは明らかに正しいですが、実行不可能です。 たとえば、20 個の製品と 10 個のクーポンがある場合、グループ化の数は天文学的なものとなり、明示的な検索は不可能になります。 

重要な点は、バウチャーを使用するとグループ内の最も安い商品が無料になるため、最も安い商品を最初に最大のクーポンと組み合わせる必要があるということです。 製品を降順で並べ替え、バウチャーを昇順で並べ替えると、最小のバウチャーを最も安価な未割り当ての製品に積極的に割り当てることができ、未割り当ての製品の中で無料の製品が実際に最も安価になるようにすることができます。 これにより、各クーポンで最大限の節約が可能になります。 どのバウチャーにも収まらない商品については、全額をお支払いいただきます。 

この問題構造により、2 ポインタの貪欲な解決策が可能になります。1 つのポインタは最も高価な未割り当ての製品を指し、もう 1 つは最も安価な未割り当ての製品を指します。 大きいものから小さいものまで慎重にバウチャーを割り当てることで、バウチャーを決して無駄にせず、常に総コストを最小限に抑えることができます。

 | 最適 | O(n log n + k log k) | O(n + k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 製品の価格を降順に並べ替えます。 これにより、左端の製品が最も高価になり、常に伝票グループで支払います。 一番右側の製品は、最も安価で無料になる可能性のあるアイテムになります。 
2. 伝票のサイズを昇順に並べ替えます。 最小のクーポンを最も安価な商品に割り当てます。これは、無料になるのは 1 つの製品のみであり、大きなクーポンはより高価な商品をカバーするためです。 
3. 2 つのポインターを初期化します。`i`製品配列の先頭 (最も高価)、および`j`最後に（最安）。 
4. 伝票を最大のものから最小のものまで繰り返します。 サイズの伝票ごとに`x`を追加します。`x-1`割り当てられていない最も高価な製品を合計コストに加えます。 これは以下に対応します`a[i]`を通して`a[i+x-2]`から数えると`i`。 次にインクリメントします`i`による`x-1`これらの有料製品をスキップするには、
 5. バウチャーごとに、支払い後、`x-1`製品の場合、グループ内で最も安価な製品は暗黙的に無料であるため、以下に相当します。`a[j]`。 デクリメント`j`使用済みとしてマークします。 
6. すべての伝票を割り当てた後、残りの製品は次のとおりです。`i`そして`j`全額個別に支払われます。 合計コストに追加してください。 

機能する理由: 各ステップで、割り当てられていない可能な限り安価な製品がバウチャーによって無料になり、より高価な製品が最初に支払われることを保証します。 伝票を昇順に、製品を降順に並べ替えることで、伝票が無駄にならず、安価な製品が不必要に支払われることがなくなります。 2 ポインタ アプローチにより、各製品が 1 回だけ使用されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        a.sort(reverse=True)
        b.sort()
        
        total = 0
        i = 0
        j = n - 1
        
        # process vouchers from largest to smallest
        for voucher in reversed(b):
            if voucher == 1:
                # free the cheapest remaining product
                total += a[i]
                i += 1
            else:
                # pay for the most expensive x-1 products
                total += sum(a[i:i + voucher - 1])
                i += voucher - 1
                j -= 1  # free the cheapest in this group
        
        # pay full price for remaining products
        while i <= j:
            total += a[i]
            i += 1
        
        print(total)

if __name__ == "__main__":
    solve()
```このソリューションでは、貪欲な割り当てを容易にするために、まず製品と伝票の両方を並べ替えます。 2 点アプローチにより、最も高価な製品が最初に支払われ、バウチャーにより最も安価な製品が効率的に解放されます。 微妙な点は、単一の製品を直接無料にするサイズ 1 のバウチャーを正しく処理し、`i`そして`j`ポインタが誤って重複することはありません。
