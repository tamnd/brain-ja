 ## 解決策
 ## 問題の理解

 私たちは飛行機で数頭の牛を与えられます。 各牛は固定座標から開始し、指定された半径の円形領域を占めます。 すべての牛は、最大でも毎秒 1 メートルの速度で任意の方向に移動でき、すべての牛が同時に移動します。 

私たちは、すべての牛が単一の共通点に位置することが可能になる最も早い時期を知りたいと考えています。 つまり、ある時、$t$、点が存在する必要があります$P$すべての牛が到達できるように$P$時間内に$t$、その半径も考慮します。 

状況を再解釈する便利な方法は、次のように言うことです。$t$、それぞれの牛は、その初期位置を中心とする円盤を効果的に「カバー」しますが、その半径は拡大されます。$r_i + t$。 牛は距離内の任意の地点に移動できます$t$、次にその半径の本体$r_i$は依然として適合する必要があるため、条件は単純な幾何学的包含になります。 

したがって、問題は最小のものを見つけることに帰着します$t$これらの拡張ディスクすべてに空ではない交差があるようにします。 

制約により、最大で$10^3$これにより、牛のトリプルすべてに対する立体チェックまたはそれより悪い幾何学的チェックが即座に除外されます。 すべての候補時間または点に対して単純にジオメトリを再計算するアプローチは、慎重に避けなければなりません。 これにより、高速な実現可能性チェックを伴う時間をかけて二分探索を行うか、多くの凸型制約を効率的に処理できる幾何最適化手法のどちらかが推進されます。 

よくある失敗例は、ペアごとの推論が全体的な正しさであると誤解される場合に発生します。 牛のペアごとに 2 つのディスクが交差する可能性がありますが、すべてのディスクを合わせても空の交差が存在する可能性があります。 たとえば、大きな三角形の頂点に配置された 3 つの等しい円は、ペアで交差できますが、それでも共通の交点はありません。 ペアごとの距離チェックのみに依存するソリューションは、そのような構成では失敗します。 

もう 1 つの微妙なエッジ ケースは、最適な会議時間がゼロの場合です。 これは、すべての初期ディスクがすでに共通点で交差している場合に発生します。 正しいソリューションでは、正の時間を仮定したり、不必要な拡張を実行したりせずに、これを処理する必要があります。 

## アプローチ

 直接的な強引なアイデアは、候補時間を試すことです$t$、すべての牛の半径を次のように拡大します。$r_i + t$をクリックし、展開されたすべてのディスクが交差するかどうかを確認します。 これをチェックする単純な方法は、すべての円盤の内側に点が存在するかどうかをテストすることです。これには、円の境界によって引き起こされるすべての候補交差点をスキャンする必要があります。 

円のペアのすべての交点を列挙し、すべての牛に対してテストしようとすると、候補点の数は次のようになります。$O(n^2)$、各検証コスト$O(n)$、 その結果$O(n^3)$時間。 と$n = 1000$、これでは遅すぎます。 

重要な観察は、これが組み合わせ交差問題ではなく、凸型の実現可能性問題であるということです。 各制約「点からの距離」$P$中央に$i$せいぜい$r_i + t$” は凸領域を定義します。実現可能な領域は、$n$平面内の凸集合。 この交差点は空いているかどうかを尋ねています。 

これは古典的な 2 次元の LP タイプの問題です。 最適なソリューションは、一定数の厳しい制約によって決定されます。つまり、システム全体に最大 1,000 の制約が含まれている場合でも、答えは少数の牛のサブセットにのみ依存します。 これにより、ランダム化された増分法または Welzl スタイルのアプローチが実現可能な最小値を見つけることが可能になります。$t$効率的に。 

この構造を使用する実際的な方法は、二分探索を行うことです。$t$、およびそれぞれの固定$t$、実現可能性の問題を解決します。つまり、拡張されたすべてのディスクにポイントが存在するかどうかを判断します。 この実現可能性チェックは、凸距離制約を除いて目的が制約されていない 2D LP タイプの問題として実装できます。

## アルゴリズムのチュートリアル

 一定の時間が与えられると、次のような機能が維持されます。$t$、点が存在するかどうかを決定します$P$すべての牛が時間内にそこに到達できるように$t$。 

1. の値を固定します。$t$そして、各牛を中心にある円盤として再解釈します。$(x_i, y_i)$半径あり$R_i = r_i + t$。 問題は、これらのディスクが共通の交点を共有しているかどうかです。 
2. この実現可能性問題を幾何最適化タスクとして解決します。点を探しています。$P$最大違反値を最小限に抑える$\max_i (\text{dist}(P, c_i) - r_i)$、そしてこの最小値が最大かどうかを確認します$t$。 そうであれば、構成は実行可能です。 
3. 各牛の制約を平面上の凸関数として扱います。 凸関数の最大値は凸のままであるため、探索空間は凸であり、制約の小さなサブセットによって決定される明確に定義された最適値を持ちます。 
4. ランダム化された増分 LP タイプの戦略を使用します。 牛をランダムにシャッフルし、現在のサブセットによって定義された最もよく知られている実行可能な点を維持します。 新しい牛が現在の解決策に違反するたびに、その牛の制約を厳しくしながら最適値を再計算します。 2 次元では、解は常に最大 3 つのアクティブな制約によって決定されるため、再帰の深さは制限されたままになります。 
5. 特定の条件の実現可能性をチェックしたら$t$が実装されている場合は、バイナリ検索を実行します。$t$。 述語「時間的には実現可能」$t$”はモノトーン：牛たちが時に合えば$t$、いつでも会うことができます。 
6. 最小値を返す$t$実現可能性テストに合格したもの。 

### なぜ効果があるのか

 重要な特性は、すべての拡張されたディスクの交差点が凸領域であるということであり、実現可能性の問題は、この凸領域が空であるかどうかに帰着します。 2 次元では、この形式の凸実現可能性問題は、組み合わせ次元が一定の LP タイプの問題です。 これにより、最適なソリューションが一定数の制約によって定義されることが保証されます。$n$牛の場合、溶液の構造は小さいです。 ランダム化された増分更新では、違反している各制約がアクティブになるか一貫して破棄されるため、正確さが維持され、真の最適値への収束が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import random
import math

def dist2(ax, ay, bx, by):
    dx = ax - bx
    dy = ay - by
    return dx * dx + dy * dy

def feasible(cows, t):
    # LP-type style solver in 2D, randomized incremental
    pts = cows[:]
    random.shuffle(pts)

    def solve_upto(i, p=None):
        if i < 0:
            return p
        x, y, r = pts[i]
        if p is not None:
            px, py = p
            if math.hypot(px - x, py - y) <= r + t + 1e-12:
                return p

        # Otherwise, must satisfy i-th constraint tightly
        best = None

        for j in range(i):
            x2, y2, r2 = pts[j]

            # intersection of circles boundaries (expanded radii)
            R1 = r + t
            R2 = r2 + t

            dx = x2 - x
            dy = y2 - y
            d2 = dx * dx + dy * dy
            if d2 > (R1 + R2) * (R1 + R2):
                continue
            if d2 < 1e-18:
                continue

            d = math.sqrt(d2)
            a = (R1 * R1 - R2 * R2 + d2) / (2 * d)
            h2 = R1 * R1 - a * a
            if h2 < 0:
                h2 = 0
            h = math.sqrt(h2)

            ux = dx / d
            uy = dy / d

            px1 = x + a * ux + h * (-uy)
            py1 = y + a * uy + h * (ux)

            px2 = x + a * ux - h * (-uy)
            py2 = y + a * uy - h * (ux)

            for cand in [(px1, py1), (px2, py2)]:
                cx, cy = cand
                ok = True
                for k in range(i + 1):
                    xk, yk, rk = pts[k]
                    if math.hypot(cx - xk, cy - yk) > rk + t + 1e-12:
                        ok = False
                        break
                if ok:
                    if best is None:
                        best = cand
        return best

    return solve_upto(len(pts) - 1) is not None

def solve():
    n = int(input())
    cows = []
    for _ in range(n):
        x, y, r = map(int, input().split())
        cows.append((x, y, r))

    lo, hi = 0.0, 1e7

    for _ in range(60):
        mid = (lo + hi) / 2
        if feasible(cows, mid):
            hi = mid
        else:
            lo = mid

    print(f"{hi:.10f}")

if __name__ == "__main__":
    solve()
```コードはまず、一定時間の幾何学的実現可能性チェッカーを定義します。$t$。 各牛は拡張されたディスクとして扱われ、ソルバーは、処理されたすべての制約を満たす候補点を段階的に維持します。 新しい制約に違反した場合、2 次元では最適な点は最大 2 つのアクティブな境界の交点に存在する必要があるため、円の境界によって引き起こされる候補交点が再計算されます。 

次に、外部二分探索により、ディスク拡張の単調性に基づいて、この実現可能条件が成立する最小時間を見つけます。 

交差の計算には平方根と幾何学的等価性チェックが含まれるため、浮動小数点の許容誤差は重要です。 距離を比較する場合は小さなイプシロンが使用されます。
