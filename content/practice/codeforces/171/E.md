 ## 解決策
 ## 問題の理解

 これは、Codeforces の古典的な「特別な」問題の 1 つです。 通常のアルゴリズム タスクとは異なり、処理すべき意味のある入力はなく、解決すべきデータ構造や最適化の課題もありません。 

このコンテストでは、カスタム テスト環境を通じて **Secret** と呼ばれる言語へのアクセスが提供されます。 実際の課題は、「Secret」というプログラミング言語が実際に何であるかを判断し、その言語で書かれたプログラムを提出して、その言語の名前を出力することです。 

入力ストリームが空です。 プログラムは何も読み取る必要はありません。 出力全体は、単一の固定文字列、つまり Secret が対応する言語の名前で構成されます。 

問題の難易度はアルゴリズム的なものではありません。 意図された解決策は、Secret 言語環境を実験し、その構文と動作からそれを特定することです。 

入力サイズや計算がないため、複雑さの制約は無関係です。 必要な言語名を正常に出力するプログラムはどれでも受け入れられます。 

間違いの唯一の本当の原因は、言語を誤って識別することです。 たとえば、2 つの言語が変数宣言またはループの同様の構文を共有する場合があります。 出場者が早計な推測をすると、プログラム自体は正しく実行される場合でも、間違った言語名を出力する可能性があります。 

例として、Secret が実際には Python であり、出場者がそれが Ruby であると結論付けたとします。 両方の言語で受け入れられる構文を偶然使用した場合、プログラムはその環境で正常に実行される可能性がありますが、必要な答えは正確な言語名であるため、出力は間違っています。 

## アプローチ

 強引な考え方では、小さなテスト プログラムを繰り返し送信し、コンパイル エラー、実行時の動作、利用可能なライブラリ、構文規則、その他の手がかりを観察します。 十分な証拠を収集することで、言語が一意に識別されるまで可能性を狭めることができます。 

言語が識別されると、それ以上のアルゴリズム作業は必要ありません。 最適な解決策は、単純に言語名を出力することです。 

この特定の問題では、秘密の言語が **Brainfuck** であることが判明しました。 したがって、受け入れられた送信は、次の文字列を出力する Brainfuck プログラムになります。```
Brainfuck
```全体的な課題は、アルゴリズムの設計ではなく、実行環境のリバース エンジニアリングです。

 ## アルゴリズムのチュートリアル

 1. Secret 言語環境を調べて、実際に実装されているプログラミング言語を判断します。 
2. その言語が Brainfuck であることを発見します。 
3. テキストを出力する Brainfuck プログラムを作成する`Brainfuck`。 
4. そのプログラムを送信します。 

### なぜ効果があるのか

 審査員は入力を提供せず、単一の固定出力を期待します。 言語が Brainfuck として正しく識別されると、文字列を出力する Brainfuck プログラムが実行されます。`Brainfuck`必要な出力と正確に一致します。 テスト ケースが 1 つだけであり、入力に依存する動作がないため、正確性はすぐに得られます。 

## Python ソリューション

 提出自体は Brainfuck で書かれなければならないため、意味のある Python ソリューションはありません。 同等の動作を Python で表現すると、次のようになります。```python
import sys
input = sys.stdin.readline

print("Brainfuck")
```Codeforces で実際に承認された提出物は Brainfuck プログラムであり、Python プログラムではありません。 上記の Python バージョンは、固定出力を生成して終了するという必要な動作を示しています。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    print("Brainfuck")

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out

    solve()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return out.getvalue()

# provided sample
assert run("") == "Brainfuck\n", "sample"

# custom cases
assert run("") == "Brainfuck\n", "empty input"
assert run("\n") == "Brainfuck\n", "extra newline ignored"
assert run("random data") == "Brainfuck\n", "input unused"
assert run("1 2 3 4 5") == "Brainfuck\n", "still fixed output"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 空の入力 | ブレインファック | 公式の行動 |
 | 改行のみ | ブレインファック | 入力は無視されます |
 | ランダムデータ | ブレインファック | 出力は一定です |
 | 1 2 3 4 5 | ブレインファック | 入力に依存しない |
