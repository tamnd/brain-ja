 ## 解決策
 ## 問題の理解

 グラフは、接続されている間に (n) 個の頂点と正確に (n-1) 個のエッジを持つため、ツリーになります。 すべてのエッジにはタフネス (a) があり、ダニエルは自分のターン中にそのエッジを最大で (a) 回横切ることができることを意味します。 開始頂点 (R) を選択するか、(R=0) の場合は任意の頂点を選択できます。 彼はいつでも停止することができ、彼のスコアは単に彼がエッジを横切った数だけです。 

重要な問題は、木の端にはその向こう側に入る方法が 1 つしかなく、戻る方法も 1 つしかないことです。 ダニエルが入ったときと同じサイドでフィニッシュした場合、そのエッジを偶数回越える必要があります。 ダニエルが反対側でゴールした場合は、奇数回越えなければなりません。 したがって、問題は、探索されたすべてのサブツリーで使用可能な交差点の数を最大化しながら、歩行の終了点を選択することです。 

公式の制約では、(n) は (10^5) まで、エッジの靭性は (10^9) まで許容され、制限時間は 2 秒です。 これにより、(n) 内の二次関数は除外されます。 考えられるすべての開始頂点に対して (O(n)) 個の作業を費やすソリューションは、最悪の場合でも約 (10^{10}) 個の演算を実行することになります。 意図したソリューションでは、ツリーを一定回数だけ処理する必要があります。 

エッジ容量の単純な合計で間違った答えが得られるエッジケースがいくつかあります。 頂点が 1 つある場合はエッジがまったくありません。```
1
1
```答えは`0`。 空のツリーを処理せずにすべてのエッジが何かに寄与すると仮定する式は、すぐに失敗します。 

ダニエルが他のエンドポイントで停止した場合、タフネスを持つ単一のエッジを 1 回使用できます。```
2
1 2 1
1
```答えは`1`。 通過するすべてのエッジを 2 回使用する必要があると仮定する不用意な解決策は、ゼロを返します。 

タフネス 1 エッジは、大きなサブツリーへの一方向ゲートウェイとしても機能します。 考慮する：```
3
1 2 1
2 3 9
1
```ダニエルは (1)-(2) を 1 回交差し、次に (2)-(3) を 9 回交差して頂点 3 で終了し、スコアは次のようになります。`10`。 入力して完全に戻ることができるサブツリーのみをカウントするソリューションでは、2 番目のエッジ全体が見逃されてしまいます。 

値 (R=0) では、最適な開始頂点が実装で使用される任意のルートである必要がないため、別の微妙な点が生じます。 例えば：```
3
1 2 3
1 3 3
0
```ダニエルは頂点 2 から始めて、頂点 3 で終わるまで両方のエッジを 3 回使用でき、スコアは`6`。 中心から開始すると、`5`したがって、単に頂点 1 でツリーをルート化し、そこで答えを取得するだけでは十分ではありません。 

## アプローチ

 直接的なアプローチは、開始頂点を固定し、各子サブツリーを訪問してそこから戻るかどうか、または最後のウォークがその子に入るかどうかを決定するツリー DP を実行することです。 この DP は正しいです。なぜなら、木の上を歩くたびに開始点からの一意の最終方向があり、探索された他のすべての枝には同じ回数だけ入ったり出たりする必要があるからです。 この計算を可能な開始頂点ごとに独立して繰り返した場合、各実行には (O(n)) かかり、(O(n^2)) 個の作業が生成されます。 (n=10^5) では、およそ (10^{10}) 回の操作となり、制限時間をはるかに超えています。 

有益な観察は、同じ DP が 2 つの隣接する頂点間のメッセージとして表現できることです。 エッジ(UV)を削除します。 ツリーは 2 つの独立したコンポーネントに分割されます。 (u) 側から必要な情報は 2 つだけです。(u) で開始して終了する歩行の最高スコアと、(u) で開始しそのコンポーネント内の任意の場所で終了する歩行の最高スコアです。 

これらの値を (F(u\to v)) および (G(u\to v)) と呼びます。 頂点に着信するすべてのメッセージが判明すると、いずれか 1 つの近傍に送信されるメッセージは、その近傍の寄与を除外することによって取得されます。 これはまさに、リルート DP が設計された構造です。 

靭性のエッジ (a) について、その最良の偶数使用法と最良の奇数使用法を定義します。 最良の偶数の使用法は、(a) が偶数の場合は (a)、(a) が奇数の場合は (a-1) です。 (a=1) の場合、この値はゼロとなり、エッジは閉じたエクスカーションではまったく使用できません。 最適な奇数の使用法は、(a) が奇数の場合は (a)、(a) が偶数の場合は (a-1) です。 

隣接するコンポーネントが閉じた値 (F) を提供すると仮定します。 エッジが往復として使用される場合、その寄与は、最良偶数使用量に (F) を加えたものになります。ただし、最良偶数使用量が 0 の場合は除きます。この場合、コンポーネントに出入りすることはできません。 エッジがエンドポイントへの最終パスとして使用される場合、その寄与は、その最良の奇数使用法に隣接 (G) 値を加えたものになります。 

これにより、リルート後に両方のメッセージが直線的な時間で表示されます。 最初のツリー トラバーサルでは、子から親へのメッセージが計算されます。 2 番目のトラバーサルでは、親から子へのメッセージが提供され、すべての頂点で、そこから始まる最適なウォークが評価されます。 (R) が固定されている場合は、その頂点の値を取得します。 (R=0) の場合、すべての頂点の最大値を取得します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(n^2)) | (O(n)) | 遅すぎる |
 | 最適な再ルート DP | (O(n)) | (O(n)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ツリーを一時的に頂点 1 にルートします。このルートは単なる実装デバイスです。 それはダニエルの必要な開始頂点とは何の関係もありません。 
2. すべての有向ツリー エッジ (u\to v) について、(uv) を削除した後に (u) を含むコンポーネントのみを使用して、(u) で開始および終了する閉じたウォークの最大スコアとして (F(u\to v)) を定義します。 (G(u\to v)) を、(u) で開始し、同じコンポーネント内の任意の場所で終了するウォークの最大スコアとして定義します。 

閉じた子エクスカーションは現在の頂点のウォークにアタッチできる一方、開いたウォークの最終エンドポイントを含めることができる子は最大 1 つであるため、これら 2 つの値で十分です。 
3. 靭性のエッジ (a) によって接続されている近傍 (w) について、その閉じた寄与を計算します。 

[
 C =
 \begin{ケース}
 a + F(w\to u), & a\text{ 偶数},\
 a-1 + F(w\to u), & a\text{ 奇数かつ }a>1,\
 0、&a=1。 
\end{件}
 】

 特殊なケース (a=1) の理由は、コンポーネントに入るには 1 つの交差が必要ですが、戻るには存在しない 2 番目の交差が必要になるためです。 
4. 対応するオープン寄与度を計算する

 [
 O = \演算子名{奇数}(a) + G(w\to u)、
 】

 ここで、(\operatorname{odd}(a)) は (a) を超えない最大の奇数です。

この寄与を選択すると、ウォークは最終的に隣接コンポーネント内で終了するため、接続エッジを奇数回横切る必要があります。 
5. 根の生えた木をボトムアップで処理します。 すべての頂点 (u) について、すべての子のクローズド寄与を合計します。 これにより、(F(u\toparent[u])) が得られます。 子の中で、(O-C) の最大値を見つけます。 1 つのクローズされた子エクスカーションをオープン エクスカーションに置き換えると、次のようになります。 

F(u\から親[u])+\max(0,\max(O-C))。 
】

 最終エンドポイントを含めることができる子は 1 つだけであるため、クローズされたコントリビューションは 1 つだけ置き換えることができます。 
6. ツリーをトップダウンで処理します。 頂点 (u) では、その親と子からのすべての受信メッセージが利用可能になります。 クローズド寄与を合計して、(u) で開始および終了する最良のクローズド ウォークを取得します。 
7. すべての入射エッジについて、(O-C) を計算します。 (u) で始まる最適なウォークは、閉じたままになるか、最終エンドポイントに到達する入射エッジを 1 つだけ選択します。 したがって、

 閉じた[u]+\max(0,\max(O-C))。 
】
 8. メッセージ (子供への子供) を生成するとき、その子供の貢献を合計から除外します。 他のすべての近傍の中で最良 (O-C) が必要なため、実装では 2 つの最大値が維持されます。 除外された子から最良の値が得られた場合は、2 番目に良い値が使用されます。 
9. (R\neq0) の場合、出力`answer[R]`。 (R=0) の場合、最大値を出力します。`answer[u]`ダニエルは開始点を自由に選択できるため、すべての頂点にわたって実行されます。 

### なぜ効果があるのか

 固定頂点から始まる有効なウォークを考えてみましょう。 グラフはツリーであるため、開始頂点から最後の頂点までのパス上にないすべてのエッジを偶数回横切る必要があります。 そのパス上のすべてのエッジを奇数回横断する必要があります。 オフパス エッジの場合、考えられる最良の選択はまさに閉じた寄与 (C) です。 パス エッジの場合、考えられる最良の選択はまさにオープン コントリビューション (O) です。 すべての頂点で、最終エンドポイントを含めることができる入射方向は 1 つだけであるため、DP は最大でも 1 つのクローズド コントリビューションをオープン コントリビューションに置き換える必要があります。 値 (F) と (G) は、すべての有向コンポーネント内のこれら 2 つの可能性を正確に捉えています。 再ルートすると、考えられるすべての開始頂点から同じステートメントが利用できるようになります。`answer[u]`はその開始に最適であり、(R=0) の場合は最大値をとることが正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    graph = [[] for _ in range(n)]

    for _ in range(n - 1):
        u, v, a = map(int, input().split())
        u -= 1
        v -= 1
        graph[u].append((v, a))
        graph[v].append((u, a))

    R = int(input()) - 1

    # Root the tree at vertex 0.
    parent = [-1] * n
    parent_w = [0] * n
    order = [0]
    parent[0] = -2

    for v in order:
        for to, w in graph[v]:
            if to == parent[v]:
                continue
            parent[to] = v
            parent_w[to] = w
            order.append(to)

    # down_f[v] = F(v -> parent[v])
    # down_g[v] = G(v -> parent[v])
    down_f = [0] * n
    down_g = [0] * n

    for v in reversed(order):
        total = 0
        best_delta = 0

        for to, w in graph[v]:
            if parent[to] != v:
                continue

            even = w - (w & 1)

            if even == 0:
                closed = 0
            else:
                closed = even + down_f[to]

            odd = w if (w & 1) else w - 1
            opened = odd + down_g[to]

            total += closed
            delta = opened - closed
            if delta > best_delta:
                best_delta = delta

        down_f[v] = total
        down_g[v] = total + best_delta

    # up_f[v] = F(parent[v] -> v)
    # up_g[v] = G(parent[v] -> v)
    up_f = [0] * n
    up_g = [0] * n

    answer = [0] * n

    for v in order:
        total = 0

        # Store the two largest O - C values.
        best1 = 0
        best2 = 0
        best_source = -1

        for to, w in graph[v]:
            if to == parent[v]:
                even = w - (w & 1)

                if even == 0:
                    closed = 0
                else:
                    closed = even + up_f[v]

                odd = w if (w & 1) else w - 1
                opened = odd + up_g[v]
            else:
                even = w - (w & 1)

                if even == 0:
                    closed = 0
                else:
                    closed = even + down_f[to]

                odd = w if (w & 1) else w - 1
                opened = odd + down_g[to]

            total += closed
            delta = opened - closed

            if delta > best1:
                best2 = best1
                best1 = delta
                best_source = to
            elif delta > best2:
                best2 = delta

        answer[v] = total + best1

        # Build messages from v to each child.
        for to, w in graph[v]:
            if parent[to] != v:
                continue

            even = w - (w & 1)

            if even == 0:
                child_closed = 0
            else:
                child_closed = even + down_f[to]

            out_f = total - child_closed

            if best_source == to:
                best_delta = best2
            else:
                best_delta = best1

            out_g = out_f + best_delta

            up_f[to] = out_f
            up_g[to] = out_g

    if R == -1:
        print(max(answer))
    else:
        print(answer[R])

if __name__ == "__main__":
    solve()
```隣接リストには、両方向の各ツリー エッジが格納されます。 一時的なルートは頂点 1 であり、`parent`と共に`order`反復的な DFS オーダーを与えます。 再帰的 DFS ではなく反復により、(10^5) 頂点を含むパスでの Python の再帰の深さの問題が回避されます。 

最初の逆走査の計算`down_f`そして`down_g`。 子エッジの場合、`closed`子サブツリーをラウンドトリップとして取得することを表しますが、`opened`最終エンドポイントをそのサブツリー内に配置することを表します。 両者の違いは、その子を最終的な方向として選択することでどれだけ得られるかを正確に教えてくれます。 

2 番目のトラバーサルでは、反対方向のメッセージが計算されます。 各頂点では、`total`あらゆる入射方向からのすべてのクローズドエクスカーションが含まれます。 最大の2つ`delta = opened - closed`1 人の子に向けたメッセージを作成する場合、その子を除外する必要があるため、値は保持されます。 2 つの最大値を維持すると、他のすべての近傍を個別にスキャンすることがなくなり、線形の複雑さが維持されます。 

すべてのスコアは 32 ビット整数の範囲を超えることができます。 実際、(10^5-1) 個のエッジが存在し、それぞれのタフネスが (10^9) に近づく可能性があるため、ここでは Python の任意精度の整数が便利です。 パリティ計算には次のものを使用します。`w & 1`、 そして`w - (w & 1)`以下を超えない最大の偶数値を与える`w`。 

表現`answer[v] = total + best1`場合にも安全です`best1`はゼロです。 これは、別のコンポーネントに入るのではなく、現在の頂点で終了することに対応します。 これは、考えられるすべてのオープン方向がスコアを悪化させる可能性のあるリーフとケースを処理します。 

## 実用的な例

 ### サンプル 1

 ツリーは頂点 1 を中心とする星形で、エッジの靭性は (3,4,3,4) です。 ダニエルは、(R=0) であるため、開始頂点を選択できます。 

センターの場合、各支店は非公開のツアーとして利用できます。 ダニエルが戻ったとき、タフネス 3 のエッジは 2 に寄与し、タフネス 4 のエッジは 4 に寄与します。したがって、中心の閉じた値は (2+4+2+4=12) になります。 最終方向としてタフネス 3 のブランチを選択すると、その寄与が 2 から 3 に変更され、スコアが 1 増加します。 

| 頂点 | 閉じた値 | ベスト (O-C) | ベストスタートスコア |
 | --- | --- | --- | --- |
 | 1 | 12 | 1 | 13 |
 | 2 | 12 | 2 | 14 |
 | 3 | 12 | 0 | 12 |
 | 4 | 12 | 2 | 14 |
 | 5 | 12 | 0 | 12 |

 最大値は 14 です。1 つの最適なウォークは頂点 2 から開始し、エッジ (2-1) を 3 回横切り、残りのブランチをクローズド エクスカーションとして使用します。 実装が最初にツリーを頂点 1 にルートしていても、再ルート計算ではこの可能性がわかります。公式サンプルでは出力が得られます。`14`。 

### サンプル 2

 ここで、ツリーはタフネス (2,1,2,1) を持つパスであり、ダニエルは頂点 1 から開始する必要があります。 

靭性 2 エッジのクローズド寄与は 2 です。靭性 1 エッジは 2 回交差できないため、クローズエクスカーションへの寄与はゼロです。 頂点 1 から開始して、最初のエッジを 2 回横切ることができ、2 つのポイントが得られます。 その後、ダニエルはタフネス 1 のエッジを 1 回越えて停止し、1 ポイントを追加できます。 あるいは、頂点 3 に到達した後、靭性 2 のエッジを適切な方向に使用して、同じ最適値 4 に到達することもできます。 

| エッジ | 靭性 | 最適な均等な使用法 | ベストの奇妙な使い方 |
 | --- | --- | --- | --- |
 | 1-2 | 2 | 2 | 1 |
 | 2-3 | 1 | 0 | 1 |
 | 3-4 | 2 | 2 | 1 |
 | 4-5 | 1 | 0 | 1 |

 頂点 1 での固定開始の場合、DP は次を取得します。`answer[1] = 4`。 公式のサンプル出力は次のとおりです`4`。

            even = w - (w & 1)
            closed = 0 if even == 0 else even + down_f[to]

            odd = w if (w & 1) else w - 1
            opened = odd + down_g[to]

            total += closed
            best = max(best, opened - closed)

        down_f[v] = total
        down_g[v] = total + best

    up_f = [0] * n
    up_g = [0] * n
    ans = [0] * n

    for v in order:
        total = 0
        best1 = 0
        best2 = 0
        source = -1

        for to, w in graph[v]:
            if to == parent[v]:
                even = w - (w & 1)
                closed = 0 if even == 0 else even + up_f[v]

                odd = w if (w & 1) else w - 1
                opened = odd + up_g[v]
            else:
                even = w - (w & 1)
                closed = 0 if even == 0 else even + down_f[to]

                odd = w if (w & 1) else w - 1
                opened = odd + down_g[to]

            total += closed
            delta = opened - closed

            if delta > best1:
                best2 = best1
                best1 = delta
                source = to
            elif delta > best2:
                best2 = delta

        ans[v] = total + best1

        for to, w in graph[v]:
            if parent[to] != v:
                continue

            even = w - (w & 1)
            child_closed = 0 if even == 0 else even + down_f[to]

            out_f = total - child_closed
            best_delta = best2 if source == to else best1
            out_g = out_f + best_delta

            up_f[to] = out_f
            up_g[to] = out_g

    if R == -1:
        return str(max(ans))
    return str(ans[R])

def run(inp: str) -> str:
    return solve_data(inp).strip()

 ## 特殊なケース

 頂点が 1 つのツリーの場合```
1
1
```隣接リストが空です。 閉じた DP 値と開いた DP 値は両方ともゼロであるため、`answer[0]`はゼロです。 (R=1) なので、プログラムは次のように出力します。`0`。 通常の DP を超える特別な場合の分岐は必要ありません。 

のために```
2
1 2 1
1
```唯一のエッジは、最良の偶数使用量が 0 であり、最良の奇数使用量が 1 です。 頂点 1 から始まり、閉じた値は 0 ですが、エッジを通る開いた値は 1 です。 DP はオープンな方向を選択し、`1`。 だからこそ、タフネスワンエッジを簡単に捨ててはいけないのです。 

のために```
3
1 2 1
2 3 9
1
```エッジ (1-2) は閉じたエクスカーションとして使用できないため、その閉じた寄与はゼロです。 そのオープン寄与は (1+G(2\to1)) です。 頂点 2 をルートとするコンポーネントの内部では、タフネス 9 エッジを最終エッジとして 9 回使用でき、(G(2\to1)=9) となります。 頂点 1 での結果の値は (1+9=10) になります。 DP は、往復には役に立たないエッジでも、最終パスの一部として非常に価値があるという事実を捉えています。 

のために```
3
1 2 3
1 3 3
0
```中心には 2 つの靭性、3 つのエッジがあります。 ウォークが中心から始まり葉で終わる場合、一方の端は 3 回使用できますが、もう一方の端は 2 回しか使用できないので、5 回になります。 ウォークが 1 つのリーフで開始され、もう 1 つのリーフで終了する場合、両方のエッジがエンドポイント パス上にあり、それぞれを 3 回使用できるため、6 回使用できます。 最初のボトムアップ パスだけでは、頂点 1 にルートされているためこれを検出できませんが、トップダウンの再ルート パスは中心から各リーフに向かうメッセージを計算します。 結果として得られる`answer`葉の場合は 6 で、(R=0) はその最大値を選択します。 

提供された 3 番目のサンプルには、開始頂点のすぐ下に 2 つの靭性 1 のエッジと、その下に 4 つの靭性 9 のエッジが含まれています。 タフネス 1 のエッジは復路をサポートできませんが、最終パスの最初のエッジにはなり得ます。 ダニエルがそれを越えると、タフネス 9 エッジを 9 回使用して、そこでフィニッシュすることができます。 DP を再ルートすると、必要なスコアが得られます。`18`、公式サンプルと一致します。
