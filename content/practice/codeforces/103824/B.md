 ## 解決策
 ## 問題の理解

 次元を持つグリッドが与えられます$n \times m$。 各操作により、Rabbit は正の数の行または正の数の列を削除することでグリッドを縮小できます。 重要な点は、この操作では任意の行や列を 1 つずつ削除するのではなく、単一のステップで選択した量だけ高さまたは幅を縮小するだけであるということです。 各操作の後、グリッドは完全な長方形のままになります。 

このプロセスは、残りの長方形の面積が 40 ～ 60 になるまで繰り返されます。 タスクは、必要なこのような縮小操作の最小数を決定するか、それが不可能であると報告することです。 

ルールは「行または列のセットを削除する」ように聞こえますが、効果はより単純です。各操作で置き換えることができます。$x$内の任意の整数によって$[1, x-1]$、または交換します$y$内の任意の整数によって$[1, y-1]$。 したがって、最終的な長方形は任意のものにすることができます$x' \times y'$そのような$1 \le x' \le n$そして$1 \le y' \le m$、次元にタッチするたびに、1 回の操作を支払います。 

制約は大きく、最大で$10^6$テストケースと最大寸法$10^9$したがって、段階的に縮小をシミュレートしようとするソリューションは直ちに不可能になります。 この構造は、操作をシミュレートするのではなく、候補となる最終次元に直接ジャンプする必要があることを示唆しています。 

微妙な点は、各操作で 1 つの次元のみが変更されることです。 最終ペアに到達$(x', y')$行を変更したかどうかと列を変更したかどうかのみに依存し、中間状態には依存しません。 

長方形を徐々に縮小しなければならないと考えるのは単純な誤解ですが、1 回の操作で任意の小さい値に直接ジャンプできるため、その必要はありません。 

したがって、出力は純粋に、領域を含む到達可能な最終的な長方形を選択することに関するものです。$[40, 60]$これにより、変更する次元の数が最小限に抑えられます。 

エッジ ケースは、最初の四角形がすでに有効である場合、1 つの次元のみを調整する必要がある場合、および両方の次元を変更する必要がある場合に発生します。 

たとえば、次の場合$n = 10, m = 5$の場合、面積は 50 なので、答えは 0 になります。$n = 10, m = 4$、面積は 40 なので、やはり 0 になります。$n = 10, m = 6$、面積は60なので0です。$n = 10, m = 7$、面積は 70 なので、少なくとも 1 次元を縮小する必要があります。 

よくある間違いは、領域を直接調整することで、1 回の操作で常に有効な長方形を実現できると想定していることです。 これは誤りです。1 つの寸法だけを変更すると、もう 1 つの寸法が固定されたままになり、結果として生じる領域がターゲット範囲を完全にスキップする可能性があるからです。 

## アプローチ

 強引な解釈では、行と列の削減の考えられるすべてのシーケンスをシミュレートします。 から$(n, m)$、各ステップで任意のステップに移行できます。$(x', m)$または$(n, y')$、そしてすべての可能性を再帰的に探索します。 各状態が次のように分岐するため、これはすぐに爆発します。$O(n + m)$可能性があり、値が小さくなったとしても、分岐係数は依然として巨大です。 このアプローチは、制約が適用されるとすぐに失敗します。 

重要な観察は、操作が次元ごとに独立しているということです。 最終的な高さを決めると$x$の場合、1回の操作で支払います$x \ne n$。 同様に、最終的な幅を選択します$y$場合は 1 回の操作が必要です$y \ne m$。 したがって、最終的な長方形の候補にはすべてコストがかかります。$\{0, 1, 2\}$元の寸法とどれだけ異なるかに応じて。 

これにより、問題は小規模な有限探索に縮小されます。つまり、面積が 40 ～ 60 の長方形だけを考慮します。面積範囲が小さいため、考えられるすべてのターゲット領域とそれらの領域のすべての因子ペアを列挙できます。 

有効な因数分解ごとに$t = x \cdot y$かどうかを確認します。$x \le n$そして$y \le m$、次にコストを計算します。 

費用は$[x \ne n] + [y \ne m]$。 

すべての有効な構成の最小値を採用します。

 | --- | --- | --- | --- |
 | ブルートフォース状態探索 | 指数 | 高 | 遅すぎる |
 | [40,60] 上の因数の列挙 | テストごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### アルゴリズムのチュートリアル

 1. これらの最終状態のみが重要であるため、有効なターゲット領域の範囲を 40 から 60 までに修正します。 
2. 各整数について$t$この範囲内で、すべての因子ペアを列挙します$(x, y)$そのような$x \cdot y = t$。 これは、次まで繰り返すことで実行できます。$\sqrt{t}$。 各ペアは、可能な最終的な長方形を表します。 
3. 各因子ペアについて、現在のグリッドに埋め込むことができるかどうかを確認します。$x \le n$そして$y \le m$。 そうでない場合は破棄してください。 
4. 有効な場合、それに到達するまでのコストを計算します。 

もし$x = n$、行操作は必要ありません。 それ以外の場合は、1 行の操作が必要です。 

もし$y = m$、列操作は必要ありません。 それ以外の場合は 1 列の操作が必要です。 
5. すべての有効なペアにわたる最小コストを追跡します。 
6. 有効なペアが存在しない場合は、-1 を出力します。 それ以外の場合は、最小コストを出力します。 

### なぜ効果があるのか

 すべての操作で変更されるのは 1 つの次元だけですが、1 回の操作で任意の小さな値に設定できます。 これにより、各ディメンションは操作回数に関して独立したものになり、変更されないか、変更されるのは 1 回だけです。 したがって、到達可能なすべての最終四角形は、各次元を維持するか変更するかの選択に正確に対応し、変更された次元の数に等しいコストがかかります。 実現可能なすべての最終状態は、固定された狭い範囲内の領域を持たなければならないため、すべての候補を列挙することで、最適な構成を見逃さないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    LOW, HIGH = 40, 60
    
    # Precompute all candidate (x, y) pairs for areas 40..60
    candidates = []
    for t in range(LOW, HIGH + 1):
        for x in range(1, int(t ** 0.5) + 1):
            if t % x == 0:
                y = t // x
                candidates.append((x, y))
                if x != y:
                    candidates.append((y, x))
    
    for _ in range(T):
        n, m = map(int, input().split())
        
        ans = 10**9
        
        for x, y in candidates:
            if x <= n and y <= m:
                cost = 0
                if x != n:
                    cost += 1
                if y != m:
                    cost += 1
                if cost < ans:
                    ans = cost
        
        print(-1 if ans == 10**9 else ans)

if __name__ == "__main__":
    solve()
```このソリューションは、面積が許容範囲内にあるすべての可能な最終的な長方形形状を事前計算します。 これにより、テスト ケースごとに係数ペアを再計算する必要がなくなります。 

各テスト ケースでは、これらの候補四角形のどれが元のグリッド内に収まるかを確認するだけです。 コスト計算には、行削減、列削減、またはその両方を実行する必要があるかどうかが直接反映されます。 

よくある実装の落とし穴は、因子ペアの両方の方向を含めることを忘れることです。$x \times y$そして$y \times x$さまざまなグリッド形状を表します。 もう 1 つの微妙な問題は、「ディメンションに対する操作がない」ことをコスト ゼロとして正しく処理することです。これは、そのディメンションが元のディメンションと一致する場合に発生します。 

## 実用的な例

 ### 例 1

 入力:```

```有効な対象領域をテストします。 考えられるターゲットの 1 つは、$4 \times 10 = 40$, でも10は20を超えますよね？ 実際には 10 ≤ 20、4 ≤ 20 なので有効です。したがって、到達可能です。 ただし、両方の次元が変化するためコストは 2 です。 

もう一人の候補は、$5 \times 8 = 40$、コスト2でも有効です。 

[40,60] 内のすべてのペアをチェックし、少なくとも 1 つが適合するため、答えは 2 になります。

 最終的な答え: 2

 これは、アルゴリズムが単一の分解を探しているのではなく、可能なすべての因数分解の中で最も安価な分解を探していることを示しています。

## 特殊なケース

 開始長方形がすでに有効範囲内の領域を持っている場合、アルゴリズムはすぐに候補を見つけます。$(n, m)$それが [40,60] にある場合、それ自体の領域の因子ペアの間でコストが 0 になります。これにより、削減の不必要な考慮が回避されます。 

1 つの寸法のみを調整する必要がある場合など$100 \times 1$、アルゴリズムは次のような有効な因数分解を識別します。$50 \times 1$または$40 \times 1$可能であれば、1 つの次元のみが異なるため、コスト 1 が正しく割り当てられます。 

範囲内に収まる因数分解が存在しない場合。$6 \times 6$、すべての候補者は期間中に拒否されます。$x \le n, y \le m$チェックすると、演算についてさらに深い推論を必要とせずに、アルゴリズムは正しく -1 を返します。
