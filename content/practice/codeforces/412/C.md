 ## 解決策
 ## 問題の理解

 疑問符の数を最小限に抑えながら、複数のパターンをそれらすべてと交差する単一のパターンにマージするように求められます。 各パターンは小文字と疑問符で構成され、疑問符は任意の文字と一致します。 両方に一致する文字列が少なくとも 1 つ存在する場合、2 つのパターンは交差します。 言い換えれば、できる限り少ない疑問符を実際の文字に置き換えて、あらゆる特定のパターンに「適合」できるパターンが必要です。 

入力により得られるのは、`n`同じ長さのパターン。 出力は、すべてのパターンと交差する同じ長さのパターンであり、疑問符が最小限に抑えられている必要があります。 この制約では、最大 100,000 のパターンと最大 100,000 文字の合計長が許可されます。 以来`n`非常に大きくなる可能性があるため、パターンのすべてのペアを検査するアルゴリズムは遅すぎます。 各文字列を個別に処理するソリューションが必要です。 

単純なアプローチでは、微妙な入力では失敗する可能性があります。 たとえば、次のような 2 つのパターンがあるとします。`a?c`そして`?bc`、不注意なアルゴリズムが選択する可能性があります`abc`すべての文字が揃っているかどうかを確認せずに、または選択する`???`盲目的に。 正しい最小交差パターンでは、文字が一致する位置は解決され、文字が異なる場合は疑問符が残るはずです。 同様に、すべてのパターンの列に疑問符がある場合、どの文字でも適合できますが、最小パターンでは疑問符の数が減るため、疑問符ではなく任意の 1 文字を使用する必要があります。 

## アプローチ

 ブルートフォース手法では、各パターンに一致する可能性のあるすべての文字列を列挙し、交差をチェックします。 これが機能するのは、問題定義で任意の文字を使用できるためです。`?`、しかしすぐに失敗します。 各パターンに長さがある場合`m`複数の疑問符が含まれている場合、候補文字列の総数は次のように指数関数的に増加します。`26^k`のために`k`疑問符。 と`n`10^5 までは、これは完全に不可能です。 

重要な洞察は、パターンが列ごとに独立して交差するということです。 すべてのパターンの最初の文字に注目すると、質問以外の文字がすべて同じであれば、その位置での交差が存在します。 それらが異なる場合、交差は存在しませんが、問題によって解決策が存在することが保証されるため、このようなことは起こり得ません。 したがって、すべての文字が次の場合、その位置の最小交差パターンは単に任意の文字になります。`?`、または一意の文字が存在する場合はその文字。 これをすべての位置に対して繰り返すと、疑問符ができるだけ少ないパターンが得られます。これは、同じ列に異なる文字が出現する場合にのみ疑問符を配置するためです。 この観察により、問題は総文字数における指数時間から線形時間に減少します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(26^m * n) | O(26^m) | 遅すぎる |
 | 最適 | O(n * m) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.長さを決める`m`最初のパターンからのパターン。 すべてのパターンがこの長さを共有します。 
2. リストの初期化`result`長さの`m`最終パターンの文字を保持します。 
3. 文字位置ごとに`i`0から`m-1`、すべてを反復処理します`n`パターンを検索し、疑問符を無視してその位置にある文字のセットを収集します。 
4. 文字のセットが空の場合は、すべてのパターンのこの位置に疑問符があることを意味します。 任意の文字を選択できます。たとえば、`'a'`に置きます`result[i]`。 
5. セットに文字が 1 つだけ含まれている場合は、その文字を`result[i]`すべてのパターンで一致する必要があるためです。 
6. セットに複数の文字が含まれている場合、問題は有効な入力ではそのような状況が発生しないことを保証します。 そうでなければ、交差点は不可能になります。 
7. すべてのポジションを処理した後、`result`リストを文字列に変換して出力します。 

機能する理由: アルゴリズムは、すべてのステップで不変条件を維持します。`result`これまでに処理されたすべてのパターンと一致しています。 各列を独立して処理することで、必要な場合にのみ疑問符を配置しながら、最終的なパターンがすべての入力パターンと交差することを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
patterns = [input().strip() for _ in range(n)]
m = len(patterns[0])

result = []
for i in range(m):
    letters = set()
    for pat in patterns:
        if pat[i] != '?':
            letters.add(pat[i])
    if not letters:
        result.append('a')
    else:
        result.append(letters.pop())

print(''.join(result))
```このソリューションはすべてのパターンを読み取り、列ごとに処理します。 各列について、疑問符を無視して、すべてのパターンにわたってその位置に表示される文字のセットを構築します。 文字が表示されない場合は、デフォルトで`'a'`。 それ以外の場合は、一意の文字を採用します。 セットを使用すると、入力が無効な場合に競合を確実に捕捉できますが、問題により一貫性が保証されます。 最終的なパターンは、すべての文字を順番に結合することによって構築されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    patterns = [input().strip() for _ in range(n)]
    m = len(patterns[0])
    result = []
    for i in range(m):
        letters = set()
        for pat in patterns:
            if pat[i] != '?':
                letters.add(pat[i])
        if not letters:
            result.append('a')
        else:
            result.append(letters.pop())
    return ''.join(result)

# provided sample
assert run("2\n?ab\n??b\n") in {"aab","bab","cab","dab","eab"}, "sample 1"

# custom cases
assert run("1\n?\n") == "a", "single pattern single question"
assert run("2\nabc\nabc\n") == "abc", "identical patterns"
assert run("2\n???\n???\n") == "aaa", "all question marks"
assert run("3\n?x?\ny??\n??z\n") == "yxz", "mixed letters and question marks"
assert run("2\na?c\n?bc\n") in {"abc","bbc","cbc"}, "column resolution"
```| テスト入力 | 期待される出力 | 検証内容 |

 | 全て`?`|`aaa`| デフォルトの文字選択は機能します。 
| 混合文字 |`yxz`| 独立した列の処理 |
