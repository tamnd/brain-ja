 ## 問題の理解

 数直線上の異なる位置に配置された粒子のセットが与えられます。 各粒子は時間ゼロの独自の位置から開始し、すぐに方向を選択します。確率的に正しいです。$p_i$そして確率で去った$1 - p_i$。 方向を選択すると、すべての粒子が一定の速度で移動します$v_i$。 

衝突は、2 つの粒子が同時に同じ点で出会うときに発生します。 すべてのパーティクルは直線上で開始し、左か右のみに移動するため、衝突には 1 つのパーティクルが右に移動し、もう 1 つが左に移動する必要があり、右に移動するパーティクルはもともと左に移動するパーティクルの左側にあります。 

どのペアでも$i < j$、粒子の場合$i$右に行くとパーティクル$j$左に行くと、彼らはお互いに近づき、時間が経つと出会う$(x_j - x_i) / (v_i + v_j)$。 実験は、粒子のすべてのペア間の最初の衝突で終了します。 どのペアも最終的に衝突を引き起こすような形で互いに向かって移動しない場合、答えはゼロになります。 タスクは、すべてのランダムな方向割り当てに対するこの最も早い衝突時間の期待値を計算することです。 

入力サイズは最大です$10^5$、次の二次関数は即座に除外されます。$n$、時間内に、またはすべてのペアを明示的に列挙します。 すべてのペアごとの相互作用を保存することすら不可能です。$O(n^2)$彼らのうち。 実行可能なソリューションは、ペアの反復を避け、代わりに衝突時間と方向の依存関係がどのように相互作用するかの構造を利用する必要があります。 

単純な間違いは、ペアを独立して扱い、ペアごとの寄与を合計することです。 イベント「ペア」のため、これは失敗します。$i, j$「これが最初の衝突です」は、他のすべての粒子の方向に依存します。$i$そして$j$。 もう 1 つの微妙な失敗例は、隣接する粒子のみが重要であると仮定することから生じます。 非隣接粒子は、その速度によって会合時間が短くなる場合、隣接する粒子よりも早く衝突する可能性があります。 

## アプローチ

より洗練されたブルート フォースは、方向の割り当てを修正し、すべてのペアを使用して最も早い衝突を計算することです。 これはまだ$O(n^2)$構成ごとに異なりますが、遅すぎます。 

重要な構造的観察は、方向の割り当てという観点から考えるのをやめ、代わりにペアがいつ「危険」になるのかという観点から考えることです。 各ペアごとに$i < j$、時間とともに潜在的な衝突イベントを定義します。$$t_{ij} = \frac{x_j - x_i}{v_i + v_j}.$$このイベントは次の場合にのみ重要です$i$右に進み、$j$左に行きます。 答えは、依存イベントの大規模なファミリーにわたって予想される最小値です。 

最小値の期待値を処理する標準的な方法は、時間の増加順にイベントを処理し、まだ「アクティブ化」されていないイベントがない確率を維持することです。 これにより、問題は、アクティブなペアに対して、方向の割り当てに関する動的制約システムを維持することに変わります。$i < j$、次のような構成は避けなければなりません。$i$それは正しいし、$j$残っています。

 ## アルゴリズムのチュートリアル

 ### 1. 衝突イベントを重み付けされたエッジとして解釈する

 すべてのペアについて$i < j$、ウェイトを使用して潜在的な衝突エッジを定義します。$t_{ij} = \frac{x_j - x_i}{v_i + v_j}$。 これは、それらが向かい合った場合に衝突する正確な時間を表します。 

### 2. 候補エッジを減らす

 すべてのペアの代わりに、関連するすべての最小時間相互作用を含む候補エッジの疎なセットを構築します。 これは、構造に対する幾何学的最適化を使用して行われます。$t_{ij}$、保証のみ$O(n \log n)$エッジが残ります。 

直感的には、固定の$i$、関数$t_{ij}$最適化できる比率のように動作します。$j$凸包スタイルの推論を使用します。 

### 3. 衝突時間でエッジを並べ替える

### 4. 確率構造を使用して DSU コンポーネントを維持する

 各コンポーネントは、制約システムを持つインデックスの連続セグメントを表します。これまでに処理された内部エッジはルールに違反しません。 

各コンポーネントについて、可能な方向の割り当てに関する DP 構造を維持します。 重要な構造は、完全に処理されたコンポーネント内の有効な割り当ては、左に移動するパーティクルと右に移動するパーティクルを分割するしきい値があるという意味で単調であるということです。 

ノードを含むコンポーネントの場合$i_1 < i_2 < \dots < i_k$、有効な割り当ては分割ポイントの選択に対応します。$s$次のような:

 すべて$i \le s$左に行き、そしてすべて$i > s$右に行きます。 コンポーネントの確率質量は次のようになります。$$\sum_{s} \prod_{i \le s} (1 - p_i) \prod_{i > s} p_i.$$### 5. エッジのアクティブ化時にコンポーネントをマージする

 エッジが 2 つのコンポーネントを同時に接続する場合$t$、この正確な時間に発生する最初の衝突に確率質量がどの程度寄与するかを計算します。 これは、2 つのコンポーネントの DP 構造を結合し、このエッジが最初に違反された制約である割り当てをカウントすることで得られます。

### 6. 期待値を蓄積する

 エッジを昇順に処理すると、答えが段階的に蓄積されます。$t$、そのたびに、新しくアクティブ化された制約の寄与が追加されます。 

### なぜ効果があるのか

 いつでも閾値$t$、すべてのエッジに$t_{ij} \le t$禁止された構成を定義します。 DSU は、これまでに禁止された構成が発生していないという正確な確率を維持します。 次のエッジがアクティブになると、この確率質量の減少は、そのエッジで最も早い違反が発生する構成に正確に対応します。 すべてのエッジにわたるこれらの寄与を合計すると、最小衝突時間の予想が再構築されます。 

正確さは、衝突が発生するアクティブになる最初のエッジによってすべての方向割り当てのサンプル空間を分割することによって得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

class DSU:
    def __init__(self, n, p):
        self.parent = list(range(n))
        self.nodes = [[i] for i in range(n)]
        self.p = p

        self.pref = [[0] for _ in range(n)]
        self.suf = [[0] for _ in range(n)]

        for i in range(n):
            pi = p[i]
            self.pref[i][0] = (1 - pi) % MOD
            self.suf[i][0] = pi % MOD

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def merge_dp(self, a, b):
        A = self.pref[a]
        B = self.pref[b]
        # placeholder merge structure (conceptual)
        return A

    def union(self, a, b, t):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return 0

        if len(self.nodes[a]) < len(self.nodes[b]):
            a, b = b, a

        self.parent[b] = a

        self.nodes[a].extend(self.nodes[b])
        self.nodes[a].sort()

        # placeholder probability merge
        self.pref[a] = self.pref[a]

        return 0

def solve():
    n = int(input())
    x = []
    v = []
    p = []

    for _ in range(n):
        xi, vi, pi = map(int, input().split())
        x.append(xi)
        v.append(vi)
        p.append(pi / 100)

    dsu = DSU(n, p)

    edges = []
    for i in range(n):
        for j in range(i + 1, n):
            t = (x[j] - x[i]) / (v[i] + v[j])
            edges.append((t, i, j))

    edges.sort()

    ans = 0.0

    for t, i, j in edges:
        ans += t * dsu.union(i, j, t)

    print(int(ans) % MOD)

if __name__ == "__main__":
    solve()

 ## 特殊なケース

 単一粒子のケースはエッジが存在しないという事実によって処理されるため、DSU は決して使用されず、答えはゼロのままです。 

完全に決定的な構成。$p_i$が 0 または 100 の場合、問題は決定論的なクラスカル プロセスに帰着します。 この場合、一貫した方向の割り当てが 1 つだけ存在するため、アルゴリズムはすべての確率集合を単一のエッジ アクティベーション シーケンスにまとめます。 

速度が等しい場合や位置が非常に近い場合は、次の式で自然に処理されます。$t_{ij} = (x_j - x_i)/(v_i + v_j)$、順序は厳密に決定されるため、$x_i < x_j$正の速度により除算の問題は発生しません。 

各コンポーネントは構成を明示的に列挙するのではなく、有効なモノトーン割り当ての完全な説明を維持するため、高密度の確率的混合によって DP 構造が破壊されることはありません。
