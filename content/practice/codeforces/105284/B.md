 ## 解決策
 ## 問題の理解

 配列と 3 つの識別された値が与えられています。$X$、$Y$、 そして$K$、注文とともに$Y < K < X$。 各テスト ケースについて、2 つの極値条件が同時に成立する部分配列を数える必要があります。部分配列内では、最大値が正確に一致する必要があります。$X$、最小値は正確に次のようにする必要があります$Y$、および値$K$内部のどこでも禁止されています。 

部分配列は、すべての要素が閉じた範囲内にある場合にのみ答えに寄与します。$[Y, X]$、両方のエンドポイントは実際にはサブ配列内で「実現」されており、少なくとも 1 回の$X$そして1回の発生$Y$、および次のような現象は発生しません。$K$が表示されます。 

この制約は、すべてのテスト ケースにわたる配列の合計長が最大で次であることを意味します。$5 \cdot 10^5$これにより、テストごとの 2 次または 2 次に近いアプローチが除外されます。 どのソリューションも、合計入力サイズが線形またはほぼ線形である必要があります。 すべてのサブ配列を明示的に検査するソリューションには、$O(N^2)$テスト ケースあたりの時間は、$10^{10}$最悪の場合は操作が不可能になり、実行できなくなります。 

配列に有効なデータが含まれていない場合、微妙なエッジケースが発生します。$X$または$Y$禁止された要素の間のセグメント内の出現。 たとえば、次の場合$A = [5, 4, 6]$、$X=6$、$Y=4$、$K=5$、サブ配列$[4,6]$は有効ですが、5 を含むセグメントは他の要素に関係なく無効です。 明示的に処理せずに最小値と最大値のみを追跡する単純なスライディング ウィンドウ$K$を含む無効なサブ配列が誤って含まれてしまう可能性があります。$K$。 

別の故障モードは、「最大値は次のとおりです」という条件を扱うことです。$X$”と”分は$Y$たとえば、セグメントには次のものが含まれる場合があります。$X$そして$Y$、ただし、より大きな要素も含まれています。$X$またはそれより小さい$Y$、境界が慎重に適用されない場合、正当性が損なわれます。 

## アプローチ

 ブルートフォースソリューションは、すべてのサブ配列を列挙し、その最小値と最大値を計算し、次のものが存在するかどうかをチェックします。$K$。 サブ配列ごとに$[l, r]$、レンジのコストをスキャンする$O(r-l+1)$したがって、全体の複雑さは次のようになります。$O(N^3)$最も文字通りの実装では、または$O(N^2)$増分メンテナンス付き。 と$N = 5 \cdot 10^5$、 平$O(N^2)$実現可能な限界をはるかに超えています。 

重要な観察は次のとおりです$K$ハードセパレーターとして機能します。 有効な部分配列はインデックスを越えることができません。$A[i] = K$。 これにより、配列が独立したセグメントに分割されます。 各セグメント内では、次の値のみを考慮します。$[Y, X]$この範囲外の値は、直ちに最小要件または最大要件に違反するためです。 

自由なセグメント内で$K$、問題を要素が含まれる部分配列を数えるということに縮小します。$[Y, X]$少なくとも 1 つが含まれる$X$そして少なくとも1つ$Y$。 これは古典的な 2 ポインターのカウント問題に変換されます。スライディング ウィンドウを維持し、最後の位置を追跡します。$X$そして$Y$、すべての要素が境界内に留まるようにします。 

最小条件と最大条件の両方を動的に直接適用する代わりに、カウント ロジックを反転します。 有効な領域内のすべてのサブ配列をカウントし、含まれていないサブ配列を減算します。$X$または含めることに失敗します$Y$。 最後に確認されたポジションを追跡することで、インデックスごとに一定時間で有効な寄与を計算できます。

 ## アルゴリズムのチュートリアル

 各テスト ケースを独立して処理し、セグメント境界と発生情報を維持しながら配列を左から右にスキャンします。 

1. 現在の有効なセグメントの開始をマークするポインターを維持し、セグメントに遭遇するたびにそれをリセットします。$K$サブ配列にそれを含めることができないためです。 これにより、無効なスパンが考慮されることがなくなります。 
2. セグメント内で、最後に確認されたインデックスを追跡します。$X$そして$Y$。 これらの位置により、現在のインデックスで終わる部分配列が両方の制約を満たすことができるかどうかがわかります。 
3. インデックスごとに$r$、最初に次のことを確認します。$A[r]$以内にあります$[Y, X]$。 外側にある場合は、セグメントの開始を次のようにリセットします。$r+1$なぜなら、この点を越えるサブ配列は最小/最大制約に違反することになるからです。 
4. もし$A[r] = X$、最後に確認された位置を更新します。$X$。 もし$A[r] = Y$、最後に確認された位置を更新します。$Y$。 
5. 各エンドポイントについて$r$、有効な開始位置の数を計算します。$l$両方が存在するように存在します$X$そして$Y$に登場する$[l, r]$そして$l$最後に発生した後です$K$および範囲外の要素。 次で終わる有効なサブ配列の数$r$は$\max(0, \min(lastX, lastY) - start)$。 

で終わる各有効なサブ配列$r$遅くとも、最後に発生したもののうち最も早い時間までに開始する必要があります。$X$そして$Y$そうでないと、そのうちの 1 つが欠落してしまいます。 

### なぜ効果があるのか

 あらゆるポジションで$r$、アルゴリズムは、で終わるすべての有効な部分配列を暗黙的に特徴付けます。$r$2 つの制約によって、現在のクリーン セグメント内に完全に存在する必要があります ($K$または範囲外の要素)、それらの左端点は、両方の必要な値が部分配列内に表示されるように配置する必要があります。 最終出現インデックスによって、部分配列に少なくとも 1 つが含まれるかどうかが完全に決まります。$X$そして1つ$Y$なぜなら、これらの最後の出現の最小値より前に開始されるサブ配列には両方が含まれますが、それ以降に開始される場合にはそれらのうちの 1 つが除外されるからです。 この不変式により、カウントされたすべてのサブ配列がすべての制約を 1 回だけ満たすことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, X, Y, K = map(int, input().split())
        a = list(map(int, input().split()))
        
        last_x = -1
        last_y = -1
        start = 0
        ans = 0
        
        for i, v in enumerate(a):
            if v == K:
                start = i + 1
                last_x = -1
                last_y = -1
                continue
            
            if v < Y or v > X:
                start = i + 1
                last_x = -1
                last_y = -1
                continue
            
            if v == X:
                last_x = i
            if v == Y:
                last_y = i
            
            if last_x != -1 and last_y != -1:
                ans += max(0, min(last_x, last_y) - start + 1)
    
        print(ans)

if __name__ == "__main__":
    solve()
```この実装では、と呼ばれる左に移動する境界が維持されます。`start`、禁止された値に遭遇するたびに強制的に前進させられます。$K$または許容範囲外の値$[Y, X]$。 これにより、考慮されるすべてのサブ配列が境界および除外ルールに関して有効であることが保証されます。 

変数`last_x`そして`last_y`～の最新の位置を保存する$X$そして$Y$現在のセグメント内。 両方が定義されている場合、次のすべてのインデックスが`start`まで`min(last_x, last_y)`で終わる部分配列を生成する左端点として機能できます。`i`両方の必要な値が含まれています。 

表現`min(last_x, last_y) - start + 1`このような開始位置がいくつ存在するかをカウントします。 の`+1`両方のエンドポイントが包括的であり、これが欠けていると単一長の有効な展開が体系的に過小評価されることにつながるため、これは重要です。

 ## 特殊なケース

 主なエッジケースは次のような場合です$K$が繰り返し表示され、配列が多数の小さなセグメントに分割されます。 このような場合、アルゴリズムはリセットされます`start`、`last_x`、 そして`last_y`毎回、サブ配列が禁止値にまたがらないようにします。 のような入力の場合$A = [7, 2, 4, 2, 7]$、有効な部分配列は以下に限定されます。$[7]$、$[4]$、 そして$[7]$アルゴリズムがセグメントを誤ってマージすることはありません。 

もう 1 つのエッジケースは次のような場合です$X$または$Y$セグメント内には決して現れません。 例えば、$A = [3, 3, 3]$と$X=3, Y=1$有効な部分配列の寄与は生成されません。`last_y`決して有効にはなりません。 条件が満たされていないため、アルゴリズムは正しくゼロを返します。`last_x != -1 and last_y != -1`決して成立しません。 

最後の微妙なケースが発生するのは、$X$そして$Y$逆の順序で表示されます。 のために$A = [1, 5]$と$X=5, Y=1$、貢献度は両方が確認されて初めて蓄積され始め、式は自然に順序付けを処理します。`min(last_x, last_y)`その中で最も初期の要件を捉えています。
