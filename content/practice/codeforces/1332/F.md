 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、$n$頂点。 エッジの空ではないすべてのサブセットに対して$E'$では、これらのエッジと、選択した少なくとも 1 つのエッジに表示されるすべての端点で構成されるエッジ誘発サブグラフを構築します。 

そのサブグラフについては、その独立したセットを数えます。 タスクは、空ではないすべてのエッジ サブセットにわたってこの量を合計することです。 

直接的な解釈は次のとおりです。$$\sum_{\emptyset \neq E' \subseteq E} w(G[E'])$$どこ$w(H)$は独立した集合の数です$H$。 

木には最大で$3 \cdot 10^5$頂点。 木には含まれているので、$n-1$エッジの場合、エッジのサブセットの数は$$2^{n-1}.$$たとえ$n=60$これはすでに列挙することが不可能です。 サブセットを明示的に反復するソリューションは直ちに除外されます。 と$n=3\cdot10^5$、意図した複雑さは線形または線形に近いものでなければなりません。 

この問題の微妙な部分は、少なくとも 1 つの選択されたエッジが頂点に触れた場合にのみ、頂点が誘導サブグラフに表示されることです。 分離された元の頂点はサブグラフにまったく属しません。 

最小の木を考えてみましょう。```
2
1 2
```単一のエッジを含む、空ではないエッジ サブセットは 1 つだけあります。 誘導された部分グラフは 1 つのエッジです。 その独立したセットは次のとおりです。$$\emptyset,\{1\},\{2\}.$$答えは$3$。 

よくある間違いは、誘導されたサブグラフではなく、元のツリーで独立したセットを数えることです。 元のツリーには、カウントを変更する孤立頂点の解釈も含まれています。 

もう 1 つの陥りやすい落とし穴は、空のエッジ サブセットです。 例えば：```
3
1 2
2 3
```空のサブセットは、独立集合の数が以下に等しい空のサブグラフを生成します。$1$。 ステートメントではこのケースを明示的に除外しているため、最終的な答えではこのケースを減算する必要があります。 

3 番目の微妙なケースは、頂点が誘導されたサブグラフから完全に消えるときに発生します。 たとえばエッジだけの場合$(1,2)$パスで選択されています$1-2-3$、頂点$3$はサブグラフに存在しません。 それを孤立した頂点として扱うと、独立したセットの数が過剰になります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 すべてのエッジ サブセットを列挙し、対応するエッジ誘発サブグラフを構築してから、標準ツリー DP を実行して独立したセットをカウントします。 

数えること自体は簡単ですが、$2^{n-1}$サブセット。 のために$n=3\cdot10^5$、これは次のようになります$$2^{299999},$$それは完全に不可能です。 

重要な観察は、カウントプロセスを逆にできるということです。 

エッジのサブセットを固定して独立したセットを数える代わりに、ペアを数える$$(E', I)$$どこ$E'$は空ではないエッジサブセットであり、$I$によって生成される誘導サブグラフの独立したセットです。$E'$。 

すべての有効なペアは、最終的な合計に 1 つだけ寄与します。 

これで、各頂点は自然に 3 つのカテゴリのいずれかに分類されます。 

黒い頂点は独立セットに属します。 

白い頂点は誘導部分グラフに属しますが、独立集合には属しません。 

赤い頂点は、誘導されたサブグラフにまったく属しません。 

元のグラフはツリーであるため、ルート付きツリー DP はこれら 3 つの状態をローカルで処理できます。 頂点と子の間の相互作用は、接続エッジが選択されているかどうかにのみ依存します。 

これにより、指数サブセット列挙問題が線形ツリー DP に変わります。 結果の遷移には頂点ごとに 3 つの状態のみが含まれ、すべてのエッジが 1 回処理されます。

 ## アルゴリズムのチュートリアル

 ツリーの頂点をルート化します$1$。 

頂点ごとに$v$、3 つの DP 値を維持します。 

させて：$$dp[v][0]$$は構成の数になります。$v$白いです。 

させて：$$dp[v][1]$$は構成の数になります。$v$黒です。 

させて：$$dp[v][2]$$は構成の数になります。$v$は赤いです。 

最初は 3 つの値すべてが$1$葉っぱのために。 

### 状態の意味

 白は、頂点が誘導されたサブグラフに存在するが、独立セットには選択されていないことを意味します。 

黒は、頂点が独立したセットに属していることを意味します。 

赤は、誘導されたサブグラフに頂点が存在しないことを意味します。 

### トランジション

 子をマージするとします$u$の中へ$v$。 

させて$$A = dp[u][0], \quad B = dp[u][1], \quad R = dp[u][2].$$それから：$$dp[v][2] \mathrel{*}= A+B-R$$

$$dp[v][1] \mathrel{*}= 2A+B-R$$

$$dp[v][0] \mathrel{*}= 2A+2B-R$$すべてのモジュロ$998244353$。 

係数は、エッジかどうかを決定することによって得られます。$(v,u)$が選択または切り取られます。 

いつ$v$が赤色の場合、赤色の頂点は誘導されたサブグラフに属することができないため、エッジをカットする必要があります。 

いつ$v$が黒の場合、独立したセットには隣接する頂点が含まれるため、接続された子も黒にすることはできません。 

いつ$v$が白である場合、接続された子は白または黒のいずれかになります。 

すべての子を処理すると、独立した選択肢の数が増加します。 

### 最終的な答え

 ツリー全体を処理した後:$$ans = dp[1][0] + dp[1][1] - dp[1][2] - 1.$$の引き算$dp[1][2]$ルートが完全に存在しない構成を削除します。 

最終的な減算は、$1$空のエッジサブセットを削除します。 

### なぜ効果があるのか

 DP はすべての有効なペアをカウントします$(E', I)$まさに一度。 

各頂点の色は、頂点が存在しないのか、存在するが選択されていないのか、あるいは存在し選択されているのかを一意に決定します。 

すべてのエッジについて、遷移では、そのエッジが誘導されたサブグラフに属しているかどうかが明示的に考慮されます。 唯一禁止されている状況は、2 つの黒い頂点を接続する選択されたエッジです。これは独立性を侵害するためです。 

グラフはツリーであるため、親頂点の状態が固定されると、異なる子サブツリーは独立します。 子供の拠出金の乗算は有効です。 

すべての有効なペアは、1 つの固有のカラーリングと 1 つの固有のエッジ決定シーケンスを生成します。 すべての DP 状態は有効なペアに対応します。 これにより、カウントされた DP 構成と必要なオブジェクトの間の全単射が確立されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

n = int(input())
g = [[] for _ in range(n)]

for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append(v)
    g[v].append(u)

parent = [-1] * n
order = [0]
parent[0] = 0

for v in order:
    for to in g[v]:
        if to == parent[v]:
            continue
        parent[to] = v
        order.append(to)

dp0 = [1] * n
dp1 = [1] * n
dp2 = [1] * n

for v in reversed(order):
    a0 = 1
    a1 = 1
    a2 = 1

    for to in g[v]:
        if to == parent[v]:
            continue

        A = dp0[to]
        B = dp1[to]
        R = dp2[to]

        a2 = a2 * (A + B - R) % MOD
        a1 = a1 * (2 * A + B - R) % MOD
        a0 = a0 * (2 * A + 2 * B - R) % MOD

    dp0[v] = a0
    dp1[v] = a1
    dp2[v] = a2

ans = (dp0[0] + dp1[0] - dp2[0] - 1) % MOD
print(ans)
```最初の部分では、ルート付きツリーを繰り返し構築します。 再帰的 DFS は、長さのチェーンに対する Python の再帰制限をオーバーフローします。$3 \cdot 10^5$したがって、明示的な走査順序の方が安全です。 

DP は逆の順序で評価され、その親が計算されるときにすべての子がすでに処理されていることを保証します。 

各状態は次から始まります$1$、子がマージされる前の乗法恒等式を表します。 

遷移式には減算が含まれています。 申請中`% MOD`すべての乗算の後、値はモジュラー範囲内に保持され、負の中間結果が自動的に処理されます。 

最後の式は、組み合わせの解釈を反映しています。 すべての頂点が赤色である構成を削除し、次に禁止されている空のエッジ サブセットを削除します。

# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    MOD = 998244353

    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n = int(input())
    g = [[] for _ in range(n)]

    for _ in range(n - 1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    parent = [-1] * n
    order = [0]
    parent[0] = 0

    for v in order:
        for to in g[v]:
            if to == parent[v]:
                continue
            parent[to] = v
            order.append(to)

    dp0 = [1] * n
    dp1 = [1] * n
    dp2 = [1] * n

    for v in reversed(order):
        a0 = a1 = a2 = 1

        for to in g[v]:
            if to == parent[v]:
                continue

            A = dp0[to]
            B = dp1[to]
            R = dp2[to]

            a2 = a2 * (A + B - R) % MOD
            a1 = a1 * (2 * A + B - R) % MOD
            a0 = a0 * (2 * A + 2 * B - R) % MOD

        dp0[v] = a0
        dp1[v] = a1
        dp2[v] = a2

    return str((dp0[0] + dp1[0] - dp2[0] - 1) % MOD)

# path of length 2
assert run("3\n1 2\n2 3\n") == "11"

# star with 3 vertices
assert run("3\n1 2\n1 3\n") == "11"

# chain of 4 vertices
assert run("4\n1 2\n2 3\n3 4\n") == "41"

 ## 特殊なケース

 最小ツリーをもう一度考えてみましょう。```
2
1 2
```唯一の有効なエッジ サブセットには単一のエッジが含まれます。 DP は以下を計算します。$$(dp0, dp1, dp2) = (2,2,1)$$根元で生み出している$$2+2-1-1=3.$$空のサブセットは最後の減算によって削除されます。 

ここでパスを考えてみましょう。```
3
1 2
2 3
```エッジのみを選択する$(1,2)$頂点を作る$3$誘導された部分グラフから消えます。 赤色の状態はまさにこの状況をモデル化しています。 頂点$3$を通じて貢献する$dp2$、孤立した頂点としてではありません。 それにより、数えすぎを防ぐことができます。 

最後に、星について考えてみましょう。```
3
1 2
1 3
```実装を不注意にすると、接続エッジが選択されているときに中心と葉が同時に黒くなる可能性があります。 黒の親のトランジションでは接続された黒の子が除外されるため、隣接する黒の頂点はカウントされません。 独立セット制約は、すべてのエッジでローカルに適用されます。
