 ## 解決策
 ## 問題の理解

 非常に特殊なサークル構成を構築しています。 半径の中心円が 1 つあります$r$。 その周りには、$n$同じ円がリングを形成するように配置されます。 これらの外側の円はそれぞれ中央の円と接触しており、すべての外側の円は隣接する 2 つの外側の円にも接触しています。 

タスクは半径を決定することです$R$この幾何学的配置が正確に可能になるように、各外側の円を配置します。 

重要な制約は、外側の円の中心が内側の円の中心の周りの正多角形上にあることです。 修正したら$n$、ジオメトリは剛体なので、$R$によって一意に決定されます$r$。 

制約$3 \le n \le 100$そして$1 \le r \le 100$は十分小さいため、定数時間の幾何学的公式で十分です。 数値的に解かれた方程式でも許容されますが、問題の構造では直接三角関数の導出が認められるため、探索は必要ありません。 

よくある間違いは、次の間で線形スケーリングを仮定することです。$r$そして$R$または、外側の円を点の周りの独立した接円として扱います。 これは、外側の円が中心の接線と隣接性の両方によって制約され、厳密な角度間隔が強制されるという事実を無視しています。 

唯一の本当のエッジケースは次の場合に発生します。$n$特に小さいです$n = 3$、不注意に実装すると、ジオメトリがきつくなり、三角関数の数値が不安定になる可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、候補の半径を試します。$R$、 場所$n$半径円の周囲に均等に点を配置します$r + R$、半径の円が隣接しているかどうかを確認します$R$接線です。 これは、隣接する中心間の距離を計算し、それらが等しいかどうかをチェックすることで検証できます。$2R$。 

問題は、これが根本原因探しの問題になることです。 それぞれの推測について$R$、幾何学的条件を評価する必要があり、収束するには二分探索やニュートン法などの反復探索が必要になります。 それぞれのチェックは、$O(n)$十分な精度が必要な場合は、数十回の反復が必要になる場合があります。 まだ実現可能ではありますが、閉じた形式の構造を持つ問題にとっては不必要に間接的になります。 

重要な観察は、外側の円の中心が半径の円上にあるということです。$r + R$、角度ごとに等間隔に配置$\frac{2\pi}{n}$。 隣接する中心間の距離は、この大きな円の弦になります。 その和音は等しくなければなりません$2R$隣接する外側の円が接しているためです。 

したがって、直接幾何方程式が得られます。$$2R = 2 (r + R)\sin\left(\frac{\pi}{n}\right)$$これは、弦の長さの公式、つまり弦の範囲を定める角度から得られます。$\theta$半径の円の中で$S$長さがある$2S\sin(\theta/2)$。 ここ$S = r + R$そして$\theta = \frac{2\pi}{n}$。 

方程式を解くと、すべての検索が代数的に削除されます。$$R = (r + R)\sin\left(\frac{\pi}{n}\right)$$

$$R - R\sin\left(\frac{\pi}{n}\right) = r\sin\left(\frac{\pi}{n}\right)$$

$$R(1 - \sin(\frac{\pi}{n})) = r\sin\left(\frac{\pi}{n}\right)$$

$$R = \frac{r\sin(\frac{\pi}{n})}{1 - \sin(\frac{\pi}{n})}$$この閉じた形式は安定しており、一定時間で評価されます。

 | 最適 (閉じた形状の形状) |$O(1)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 隣接する外側の円の中心間の角度ステップを計算します。これは、$\frac{\pi}{n}$。 これは全角を半分にすることから来ます$\frac{2\pi}{n}$弦長には半角正弦が使用されるためです。 
2. 評価する$s = \sin\left(\frac{\pi}{n}\right)$。 この値は、隣接する中心がその配置の外半径に対してどれだけ離れているかを捕捉します。 
3. ジオメトリを次の線形方程式に変換します。$R$: 隣接する中心間の距離は両方とも$2R$(接線条件)と$2(r+R)s$（弦長条件）。 
4. 方程式を解く$R = (r+R)s$代数的に分離する$R$。 これにより、反復を行わずに直接式が生成されます。 
5. 浮動小数点演算を使用して最終値を計算し、十分な精度で出力します。 

### なぜ効果があるのか

 全体の構造は規則的なものに縮小されます。$n$- 外側の円の中心によって形成されるゴン。 すべての外側の円は同一であり、サイクル内で相互に接しているため、それらの中心は等しい角度間隔の円上になければなりません。 この厳格な対称性により、単一の弦の長さの制約が強制され、その制約により、次のような比率が一意に決定されます。$R$そして$r$。 一度は代替構成が存在しない$n$そして$r$固定されています。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

n, r = map(int, input().split())

s = math.sin(math.pi / n)
R = (r * s) / (1 - s)

print(R)
```コードは、派生した式を直接エンコードします。 唯一の微妙な点は、`math.pi / n`それよりも`2*pi/n`, なぜなら、弦の公式は半角に依存するからです。 よくある実装上の間違いは、この半分を忘れて中心角全体を使用することです。これにより、結果に系統的なスケーリング エラーが発生します。 

すべての計算は倍精度で行われます。必要な許容誤差は次のとおりであるため、これで十分です。$10^{-6}$、浮動小数点イプシロンをはるかに上回ります。

## テストケース```python
import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, r = map(int, input().split())
    s = math.sin(math.pi / n)
    R = (r * s) / (1 - s)
    return str(R)

# provided sample
assert abs(float(run("3 1\n")) - 6.4641016) < 1e-6, "sample 1"

# minimum n
assert run("3 1\n")  # already covered extreme structure

# larger n

# equal scaling
assert abs(float(run("6 2\n")) - 2.0) < 1e-9

# another random case
assert abs(float(run("10 5\n")) - (5*math.sin(math.pi/10)/(1-math.sin(math.pi/10)))) < 1e-9

 ## 特殊なケース

 のために$n = 3$、構成は、中心の周りの外側の円が可能な限り密に配置された三角形になります。 ここ$\sin(\pi/3)$大きいので分母は$1 - s$が小さくなり、浮動小数点の感度が増幅されます。 分子と分母の両方が安定した浮動小数点の範囲内にあるため、数式は引き続き正しく動作します。 

大型用$n$、$\sin(\pi/n) \approx \pi/n$、 それで$R \approx \frac{r \cdot \pi/n}{1 - \pi/n}$、次のように 0 に近づきます。$n$成長します。 分子と分母の両方がキャンセルされることなくスムーズに縮小するため、計算は安定したままになります。 

次のような中間値の場合$n = 6$、対称性により、次のような厳密な単純化が行われます。$\sin(\pi/6) = 1/2$、きれいな整数の結果が生成されます。 この数式は、特別なケースを使用せずにこれらのケースを処理し、完全なジオメトリを均一にキャプチャしていることを確認します。
