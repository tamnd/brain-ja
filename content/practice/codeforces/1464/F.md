 ## 解決策
 ## 問題の理解

 ツリー上に複数のパスのセットを維持します。 パスは動的に挿入および削除できます。 

パラメータ付きクエリの場合`d`、保存されているすべてのパスまでの距離が最大で 1 つ以上の頂点が存在するかどうかを判断する必要があります。`d`。 

同じことを別の言い方で言うと、次のようになります。 

保存されているパスごとに`P`からの距離が次のすべての頂点を考慮します。`P`せいぜい`d`。 これらすべてのセットの共通部分が空でないかどうかを知る必要があります。 

ツリーには以下が含まれます`2 · 10^5`頂点があり、最大`2 · 10^5`操作。 クエリ中にすべてのアクティブなパスに触れるソリューションは直ちに除外されます。 平`O(√q)`操作ごとの作業は不快です。 対数時間に近いものが必要です。 

難しいのは、維持されるオブジェクトが頂点ではなくパスであることです。 挿入と削除はオンラインで行われるため、クエリをオフラインで処理することはできません。 

同じパスが複数回挿入されると、微妙なエッジ ケースが発生します。```
add (1,2)
add (1,2)
delete (2,1)
```まだ1部残ってます。 多重性ではなく存在だけを保存する構造は壊れてしまいます。 

もう 1 つの簡単な間違いは、クエリが保存されているすべてのパスが交差するかどうかを尋ねるものだと考えることです。 のために`d > 0`それは真実ではありません。 

チェーンを考えてみましょう。```
1 - 2 - 3 - 4 - 5
```保存されたパスを使用した場合`(1,1)`そして`(5,5)`。 

のために`d = 2`、頂点`3`距離以内にあります`2`両方のパスの両方であるため、答えは次のようになります。`Yes`たとえパス自体がバラバラであっても。 

最も難しいのは、保存されているすべてのパスのどのような条件が実際にテストされているかを理解することです。 

## アプローチ

 ブルート フォース アプローチでは、すべてのアクティブなパスが明示的に維持されます。 お問い合わせの場合`3 d`、ツリーのすべての頂点をテストし、すべてのアクティブなパスまでの距離を確認できます。 

頂点からパスまでの距離は LCA 機構を使用して計算できますが、たとえそのチェックが一定時間だったとしても、```
O(n · |P|)
```クエリごとに作業します。 

両方の値が到達すると、`2 · 10^5`、これはまったく不可能です。 

重要な観察点は、すべてのパスが`(u,v)`LCAで表すことができます。 

させて```
l = lca(u,v)
```頂点`x`距離以内にあります`d`パスから`(u,v)`の投影の場合`x`道に入る、それ以上登る前に道に到達する`d`エッジ。 すべてのアクティブなパスに対してこの条件を同時に書き直すと、驚くほど強力な構造が明らかになります。 

すべてのアクティブなパスの LCA を収集するとします。 

させて`L`最も深いアクティブな LCA になります。 

いくつかの頂点が距離内にある場合`d`すべてのパスから頂点を登る場合、その頂点は登ることによって得られた祖先のサブツリー内にある必要があります。`2d`上のエッジ`L`。 

これにより、問題がサブツリーに縮小されます。 

そのサブツリー内では、LCA のみが重要です。 すべてのアクティブ LCA が同じ祖先サブツリーに属する必要があり、そのサブツリー内のアクティブ LCA セットの直径は十分に小さい必要があります。 

アクティブな LCA は、動的な頂点のセットを形成します。 動的ツリー直径は標準構造です。2 つのセグメントの直径がわかっている場合、それらの結合の直径は 2 つの直径の端点のみをチェックすることによって取得できます。 

これにより、問題全体が次のメンテナンスに変わります。 

1. LCA の動的なマルチセット。 
2. 最も深いアクティブ LCA。 
3. オイラー ツアー サブツリー内のすべてのアクティブな LCA の直径。 
4. LCA がサブツリーに属するアクティブ パスの数。 

これにより、すべての操作を対数時間で処理できるようになります。 

承認されたソリューションでは次のものが使用されます。 

- オイラーツアーの間隔。 
- バイナリリフティング。 
- フェンウィックの木。 
- 直径を維持するセグメントツリー。 
- 深さ順に並べられたマルチセット。 

結果として生じる複雑さは、`O(log n)`更新およびクエリごとに。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | クエリあたり O(n · | P | ) |
 | 最適 | 操作ごとに O(log n) | O(n log n) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 幾何学的再定式化

 アクティブパスの場合`(u,v)`させて```
l = lca(u,v)
```このパスは、次の点で交わる 2 本の上向きのチェーンで構成されています。`l`。 

頂点の場合`x`距離以内にいること`d`この道からの祖先`l`登山後に入手`d`エッジには引き続きアクセスできる必要があります`x`他を超えずに`d`エッジ。 

すべてのパスにわたってこの条件を単純化した後、LCA のみが関連性を保ちます。 

### 保守対象のオブジェクト

 しましょう`S`すべてのアクティブなパスの LCA のマルチセットになります。 

すべてのアクティブなパスについて:

 1. LCA を`S`。 
2. パスが消えたら、その LCA を削除します。 

私たちは以下を維持します:

 1. の最も深い頂点`S`。 
2. オイラー ツアー サブツリー内のアクティブな LCA の数。 
3. アクティブな LCA の直径情報。 

### データ構造

 1. DFS を実行します。 
2. オイラーエントリを計算する`tin`そして終了します`tout`。 
3. バイナリリフティングテーブルを構築します。 
4. オイラー次数の上にフェンウィック ツリーを構築します。 
5. 葉が頂点に対応するセグメント ツリーを構築します。 

セグメント ツリー ノードには、その間隔内のすべてのアクティブな頂点の直径が格納されます。 

直径は次のように表されます。```
(endpoint1, endpoint2, length)
```### 2 つの直径構造を結合する

 左側の子に直径の端点があると仮定します。`(a,b)`そして右の子は`(c,d)`。 

ユニオンの直径は次のいずれかでなければなりません。```
(a,b)
(c,d)
(a,c)
(a,d)
(b,c)
(b,d)
```この 6 つのペアをチェックすれば十分です。 

これは標準の動的直径マージです。 

### パスの挿入

 1. コンピューティング`l = lca(u,v)`。 
2. 次のオカレンスを 1 つ追加します。`l`深さ順のマルチセットに変換します。 
3. 次のオカレンスを 1 つ追加します。`l`フェンウィックの木へ。 
4. これが初めて発生した場合`l`、セグメントツリーでそのリーフをアクティブにします。 

### パスの削除

 1. コンピューティング`l = lca(u,v)`。 
2. マルチセットから 1 つのオカレンスを削除します。 
3. フェンウィック ツリーから 1 つのオカレンスを削除します。 
4. 多重度が 0 になった場合は、セグメント ツリー リーフを非アクティブ化します。 

### 質問への回答`3 d`させて`L`最も深いアクティブな LCA になります。 

1.移動`d`から上向きのエッジ`L`、取得`x`。 
2. 別の場所に移動する`d`から上向きのエッジ`x`、取得`y`。 

共通点の候補はサブツリー内に存在する必要があります`y`。 

まず、すべてのアクティブな LCA がそのサブツリーに属しているかどうかを確認します。 

オイラー区間とフェンウィック ツリーを使用すると、次のようになります。```
count(subtree(y)) == number_of_active_paths
```保持しなければなりません。 

そうでない場合は、答えてください`No`。 

それ以外の場合は、サブツリーのオイラー区間でセグメント ツリーをクエリします。`y`。 

これは、そのサブツリー内のすべてのアクティブな LCA の直径を返します。 

直径の端点を次のようにします。`(p,q)`。 

答えは、`Yes`もし```
dist(x,p) ≤ d
and
dist(x,q) ≤ d
```すべてのアクティブな LCA は、最も遠いペアが`(p,q)`。 

両方の直径の端点が半径の内側に収まる場合、`d`ボールの中心は次のとおりです`x`、すべてのアクティブな LCA も同様に適合します。 

### なぜ効果があるのか

 最も深いアクティブな LCA は、最も制限的なものです。 実行可能な頂点はすべてその近くに存在する必要があります。 

クライミング`2d`その最も深い LCA より上のレベルでは、共通の実現可能な頂点を含むことができる最大のサブツリーが生成されます。 すべてのアクティブな LCA は、このサブツリー内に存在する必要があります。 アクティブな LCA が 1 つでもエスケープすると、どの頂点もすべての制約を同時に満たすことができなくなります。 

有効なサブツリー内では、実現可能性はアクティブな LCA 間の最大ペアごとの距離のみに依存します。 アクティブな LCA は 1 つおきに、直径端点の 1 つよりも中心候補から遠くないため、直径端点は十分です。 したがって、2 つの直径の終点をチェックすることで、セット全体の特徴が完全に明らかになります。 

維持されるすべての構造はアクティブな LCA 多重度のみに依存するため、この不変式は挿入および削除のたびに維持されます。 

## Python ソリューション```python
import sys
from bisect import bisect_left, insort

input = sys.stdin.readline

def solve():
    n, q = map(int, input().split())

    g = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        g[u].append(v)
        g[v].append(u)

    LOG = 20

    tin = [0] * (n + 1)
    tout = [0] * (n + 1)
    depth = [0] * (n + 1)
    up = [[0] * (n + 1) for _ in range(LOG + 1)]
    euler = [0] * (n + 1)

    timer = 0

    sys.setrecursionlimit(1 << 20)

    def dfs(v, p):
        nonlocal timer
        timer += 1
        tin[v] = timer
        euler[timer] = v

        up[0][v] = p
        depth[v] = depth[p] + 1

        for i in range(1, LOG + 1):
            up[i][v] = up[i - 1][up[i - 1][v]]

        for to in g[v]:
            if to != p:
                dfs(to, v)

        tout[v] = timer

    dfs(1, 1)

    def lca(a, b):
        if depth[a] < depth[b]:
            a, b = b, a

        diff = depth[a] - depth[b]

        bit = 0
        while diff:
            if diff & 1:
                a = up[bit][a]
            diff >>= 1
            bit += 1

        if a == b:
            return a

        for i in range(LOG, -1, -1):
            if up[i][a] != up[i][b]:
                a = up[i][a]
                b = up[i][b]

        return up[0][a]

    def dist(a, b):
        c = lca(a, b)
        return depth[a] + depth[b] - 2 * depth[c]

    def jump(v, k):
        for i in range(LOG + 1):
            if k >> i & 1:
                v = up[i][v]
        return v

    class Fenwick:
        def __init__(self, n):
            self.n = n
            self.bit = [0] * (n + 1)

        def add(self, idx, val):
            n = self.n
            bit = self.bit
            while idx <= n:
                bit[idx] += val
                idx += idx & -idx

        def sum(self, idx):
            bit = self.bit
            res = 0
            while idx:
                res += bit[idx]
                idx -= idx & -idx
            return res

        def range_sum(self, l, r):
            return self.sum(r) - self.sum(l - 1)

    fenwick = Fenwick(n)

    NEG = (-1, -1, -1)

    def merge(A, B):
        if A[0] == -1:
            return B
        if B[0] == -1:
            return A

        cand = [
            (A[0], A[1]),
            (B[0], B[1]),
            (A[0], B[0]),
            (A[0], B[1]),
            (A[1], B[0]),
            (A[1], B[1]),
        ]

        best_u, best_v = A[0], A[1]
        best_d = dist(best_u, best_v)

        for u, v in cand:
            d = dist(u, v)
            if d > best_d:
                best_d = d
                best_u, best_v = u, v

        return (best_u, best_v, best_d)

    seg = [NEG] * (4 * n)

    def update(node, l, r, pos, val):
        if l == r:
            seg[node] = (val, val, 0) if val != -1 else NEG
            return

        mid = (l + r) // 2

        if pos <= mid:
            update(node * 2, l, mid, pos, val)
        else:
            update(node * 2 + 1, mid + 1, r, pos, val)

        seg[node] = merge(seg[node * 2], seg[node * 2 + 1])

    def query(node, l, r, ql, qr):
        if ql <= l and r <= qr:
            return seg[node]

        mid = (l + r) // 2

        if qr <= mid:
            return query(node * 2, l, mid, ql, qr)
        if ql > mid:
            return query(node * 2 + 1, mid + 1, r, ql, qr)

        return merge(
            query(node * 2, l, mid, ql, qr),
            query(node * 2 + 1, mid + 1, r, ql, qr),
        )

    cnt = [0] * (n + 1)

    depth_set = []

    active = 0
    out = []

    for _ in range(q):
        tmp = list(map(int, input().split()))
        tp = tmp[0]

        if tp == 1:
            _, u, v = tmp
            w = lca(u, v)

            insort(depth_set, (depth[w], w))

            fenwick.add(tin[w], 1)

            cnt[w] += 1
            if cnt[w] == 1:
                update(1, 1, n, tin[w], w)

            active += 1

        elif tp == 2:
            _, u, v = tmp
            w = lca(u, v)

            pos = bisect_left(depth_set, (depth[w], w))
            depth_set.pop(pos)

            fenwick.add(tin[w], -1)

            cnt[w] -= 1
            if cnt[w] == 0:
                update(1, 1, n, tin[w], -1)

            active -= 1

        else:
            _, d = tmp

            L = depth_set[-1][1]

            x = jump(L, d if d < depth[L] else depth[L] - 1)
            y = jump(x, d if d < depth[x] else depth[x] - 1)

            inside = fenwick.range_sum(tin[y], tout[y])

            if inside != active:
                out.append("No")
                continue

            dia = query(1, 1, n, tin[y], tout[y])

            if dia[0] == -1:
                out.append("Yes")
                continue

            ok = (
                dist(x, dia[0]) <= d and
                dist(x, dia[1]) <= d
            )

            out.append("Yes" if ok else "No")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```実装は上記で説明した構造に正確に従っています。 フェンウィック ツリーは、オイラー ツアー サブツリー内のアクティブな LCA をカウントします。 セグメント ツリーは、アクティブな LCA の動的な直径を維持します。 多重度の処理は非常に重要です。頂点は、その数がゼロになった場合にのみセグメント ツリーから消えます。 

直径のマージは最も重要な部分です。 2 セットの頂点の場合、それらの結合の直径は、既存の直径の 1 つによって、または左の直径の端点を右の直径の端点と接続することによって形成する必要があります。 6 ペアをチェックすれば十分です。 

オイラーツアー区間`[tin[v], tout[v]]`サブツリー クエリを範囲クエリに変換します。 これにより、フェンウィック ツリーとセグメント ツリーの両方が動作できるようになります。
