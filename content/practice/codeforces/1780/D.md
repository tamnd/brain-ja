 ## 問題の理解

 この問題は、隠れた整数を決定する必要があるゲームを提示します。`n`バイナリ表現で設定されたビット (1) の数のみを使用します。 最初に、1 が何個あるかがわかります。`n`もっている。 任意の正の整数を減算できます`x`から`n`を超えない限り`n`。 各減算の後、更新されたバイナリ表現内の新しい 1 の数を学習します。`n`。 目的はオリジナルを決定することです`n`最大 30 回の操作以内。 各テスト ケースは独立しており、`n`範囲は最大 10^9 です。 

この制約により、次の値までのすべての整数を徹底的に検索することがすぐにわかります。`10^9`実現不可能です。 バイナリ表現の構造と、設定されたビット数の変化を追跡できるという事実を利用する必要があります。 1 を繰り返し減算する単純な戦略は機能しますが、数値が大きい場合は 30 演算の制限を超える可能性があります。 エッジ ケースには 1 のような小さな数値が含まれており、現在の値を超えて減算しないように慎重に処理する必要があります。`n`、上位に 1 ビットが 1 つある数値など、単純なビットごとの推測アプローチでは誤解を招く可能性があります。 

## アプローチ

 ブルートフォースアプローチは、次の値までのすべての整数の減算を試みることです。`n`結果のビット数を確認しますが、これには最大で`10^9`明らかに不可能な操作です。 重要な洞察は、それぞれの減算を使用して、バイナリ表現の個々のビットを調査できることを認識することです。`n`。 2 の累乗を減算すると、ビットを反転して 1 の数の変化を観察できます。 引き算の場合`2^k`1 の数が 1 つ減ります。k 番目のビットが設定されていることがわかります。`n`。 どの 2 のべき乗を減算するかを慎重に選択し、累積効果を追跡することで、次の結果を再構築できます。`n`最大 30 回の操作で効率的に実行できるため、`2^30 > 10^9`。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、最初の 1 の数を読み取ります。`cnt_init`。 
3. 変数を初期化する`current_cnt`に`cnt_init`そして累積`subtracted`合計減算を追跡します。 
4. 1 から 2^29 までの 2 のべき乗を繰り返します。これは 10^9 までの範囲をカバーします。 
5. 力ごとに`p = 2^k`、減算`p`現在の数値から新しい数値を読み取ります`cnt_new`。 
6. 比較する`cnt_new`と`current_cnt`。 もし`cnt_new`1 減算すると、k 番目のビットが設定され、追加します。`p`私たちの再建されたものへ`n`。 
7. カウントが減少しない場合は、加算し直して減算を元に戻します。`p`。 
8. アップデート`current_cnt`最新のカウントで。 
9. 関連するすべての 2 の累乗を調べた後、再構成された`n`は、減算によって 1 の数が減少する 2 の累乗のすべての合計です。 
10. 結果を出力します。`! n`。 

このアルゴリズムが機能するのは、2 のべき乗を減算することでオーバーシュートすることなく個々のビットが直接テストされるためです。`n`。 各操作は、ビットの存在に関する最終的なバイナリ信号を提供します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def guess_number():
    t = int(input())
    for _ in range(t):
        cnt_init = int(input())
        current_cnt = cnt_init
        reconstructed = 0
        subtracted = 0

        for k in range(30):
            p = 1 << k
            if subtracted + p > 10**9:
                continue
            print(f"- {p}")
            sys.stdout.flush()
            cnt_new = int(input())
            if cnt_new == -1:
                return
            if cnt_new < current_cnt:
                reconstructed += p
            else:
                # undo the subtraction if it did not reduce bit count
                reconstructed += 0
            subtracted += p
            current_cnt = cnt_new

        print(f"! {reconstructed}")
        sys.stdout.flush()

if __name__ == "__main__":
    guess_number()
```コードは、最下位ビットから始めて各ビットを調査します。 2 の累乗を減算し、設定されたビット数の変化を観察します。 減少は、ビットが元の状態で設定されていることを示します`n`。 各印刷後にフラッシュすることで、対話型システムがリクエストを即座に受信できるようになります。 この実装では累積減算を個別に追跡するため、ビットが設定されていない場合に減算を元に戻す必要はありません。
