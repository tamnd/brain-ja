 ## 解決策
 ## 問題の理解

 整数の配列内で、合計が奇数である 3 つの異なる要素を見つけるように求められます。 入力は複数のテスト ケースで構成され、それぞれが配列を提供します。 出力では、そのようなトリプルが存在するかどうかを示す必要があり、存在する場合は、有効な 3 つのインデックスのセットを提供する必要があります。 

重要な特性は、整数が 2 で割り切れない場合は奇数であるということです。したがって、3 つの数値の合計が奇数であるのは、奇数が 1 つと偶数が 2 つだけ含まれる場合、または 3 つすべてが奇数である場合です。 この観察により、問題は、考えられるすべてのトリプルをテストするのではなく、奇数と偶数を数えるという問題に直ちに帰着します。 

制約は中程度です。各配列には最大 300 個の要素を含めることができますが、すべてのテスト ケースの合計が 200,000 を超えることはありません。 ブルートフォースのトリプル列挙では、以下のチェックが必要になります。$\binom{300}{3} \approx 4.5 \times 10^6$テストケースごとの合計。 これは 1 つのテスト ケースでは実現可能ですが、10,000 のテスト ケースでは実現できないため、より賢明なアプローチが必要です。 さらに、エッジ ケースには、偶数のみを含む配列、3 つ未満の奇数を含む配列、またはインデックスの慎重な選択が重要な混合を含む配列が含まれます。 

たとえば、配列が [2, 4, 6, 1] の場合、最初の 3 つの要素を単純にテストする単純なアプローチは失敗する可能性があります。 最初の 3 つを選択すると偶数の合計が得られますが、最後の要素を含む有効なトリプルが存在します。 したがって、アルゴリズムはパリティに基づいてインデックスを選択的に選択する必要があります。 

## アプローチ

 ブルートフォース手法は、インデックスのすべてのトリプルを反復処理します。$(i, j, k)$、要素を合計し、合計が奇数かどうかを確認します。 これにより、あらゆる可能性が考慮されるため、正確さが保証されます。 欠点は、最悪の場合、$n = 300$10,000 のテスト ケースでは、数十億の操作が必要となり、遅すぎます。 

最適なアプローチではパリティを使用します。 奇数と偶数のインデックスを数えます。 奇数が少なくとも 3 つある場合、任意の 3 つを選択すると奇数の和が得られます。 それ以外の場合、少なくとも 1 つの奇数と少なくとも 2 つの偶数がある場合、1 つの奇数と 2 つの偶数を選択すると、奇数の合計も得られます。 どちらの条件も当てはまらない場合、有効なトリプルは存在しません。 これにより、問題は単純な線形スキャンと条件付きロジックに削減され、入れ子になったループが完全に回避されます。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、要素の数を読み取ります。$n$そして配列$a$。 
2. 2 つのリストを初期化します。`odd_indices`そして`even_indices`奇数と偶数の位置を保存します。 
3. 1 から始まるインデックスを使用して配列を反復処理します。 要素が奇数の場合は、そのインデックスを次のように追加します。`odd_indices`。 偶数の場合は追加します`even_indices`。 
4.長さを確認してください`odd_indices`。 少なくとも 3 つの要素がある場合は、「YES」と最初の 3 つのインデックスを出力します。`odd_indices`。 
5. それ以外の場合は、次のことを確認してください。`odd_indices`少なくとも 1 つの要素があり、`even_indices`少なくとも 2 つの要素があります。 そうである場合は、「YES」、最初の奇数インデックス、および最初の 2 つの偶数インデックスを出力します。 
6. どちらの条件も満たされない場合は、「NO」と出力します。 

不変条件は、これらの条件が 3 つの数値から奇数の合計を形成するすべてのケースをカバーするということです。 3 つの奇数の合計は常に奇数になります。 1 つの奇数と 2 つの偶数の合計も奇数になります。 他の組み合わせでは、合計が偶数になるか、3 つの異なるインデックスを形成できません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    odd_indices = []
    even_indices = []
    
    for i, num in enumerate(a, 1):
        if num % 2 == 0:
            even_indices.append(i)
        else:
            odd_indices.append(i)
    
    if len(odd_indices) >= 3:
        print("YES")
        print(odd_indices[0], odd_indices[1], odd_indices[2])
    elif len(odd_indices) >= 1 and len(even_indices) >= 2:
        print("YES")
        print(odd_indices[0], even_indices[0], even_indices[1])
    else:
        print("NO")
```コードはまずパリティによってインデックスを分離し、次に説明したロジックを適用します。 1 ベースのインデックスを使用すると、off-by-one エラーが回避されます。 条件の順序により、アルゴリズムは大文字と小文字が混在する前に 3 つの奇数を優先的に選択します。 列挙する`start=1`配列の位置を必要な出力形式に合わせます。
