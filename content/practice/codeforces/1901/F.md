 ## 解決策
 ## 問題の理解

 から始まる x 軸に沿った一連の点として表される道路が与えられます。`(0,0)`そして終わる`(n-1,0)`。 各点は X 軸より上の高さを持ち、最初は配列によって与えられます。`a`。 タスクは、舗装を注ぎ込んで道路を「平らにし」、左端の点を結ぶ直線セグメントを形成することです。`(0, y_0)`一番右の点まで`(n-1, y_1)`道路のすべての頂点がこのセグメントの下または上にあるようにします。 コストはこのセグメントと道路の間の領域であり、これを最小限に抑えたいと考えています。 

初期の高さを超えた後`a_i`、更新された身長の受信を開始します`b_i`順次。 新たにわかった高さごとに、その地点までの道路の最小平坦化コストを計算して報告する必要があります。`y_0 + y_1`最適なセグメントの。 

制約が意味するのは、`n`は最大 200,000 になる可能性があり、二次複雑度の解は遅すぎることを意味します。 すべてのペアを試す素朴なアプローチ`(y_0, y_1)`あるいはすべての斜面に`O(n^2)`操作は実行不可能です。 高さは次のように大きくすることができます`10^9`したがって、高さによってインデックス付けされた配列の値を事前計算することはできません。 

エッジ ケースには、ポリラインの最初または最後の既知の高さに鋭いピークがある場合、またはすべての高さがゼロである状況が含まれます。 たとえば、次の場合`b = [0, 0, 0, 0]`、最適なセグメントは平坦であり、`y_0 + y_1 = 0`。 整数の除算や丸めを使用する不注意なアプローチでは、ここで間違った答えが得られる可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのペアが考慮されます。`(y_0, y_1)`これまでに既知の高さをカバーでき、セグメントとポリラインの間の面積を積分することで対応するコストを計算し、最小値を選択します。 これは、最適なセグメントが少なくとも 1 つの点に触れなければならないため機能しますが、遅すぎます。`n = 2*10^5`これには調査が必要です`O(n^2)`ペア、これは許容範囲をはるかに超えています`2*10^8`操作。 

重要な洞察は、問題が凸包トリック シナリオに帰着するということです。 の関数としてのコスト`y_0`そして`y_1`は区分的に線形であり、指定された傾きに対して`(y_1 - y_0)/(n-1)`、セグメントは最高点のすぐ上にある必要があります。 これにより、最大偏差を維持することができます`(b_i - slope * i)`最適なセグメントのエンドポイントを効率的に計算します。 プレフィックスとサフィックスの最大値の組み合わせを使用するか、同等の方法で行の上部エンベロープを 2 ポインター方式で維持することで、次の計算ができます。`y_0 + y_1`段階的に`O(n)`時間。 

最適なアプローチは、最適なセグメントの傾きが常に最大偏差が発生する 2 つの頂点を結ぶ線によって決定されるという事実を利用します。 新しい高さを順番に読み取ると、これらの重要な点でのみ傾きが変化する可能性があるため、2 ポインターまたはデキュー アプローチを使用して最適なセグメントのエンドポイントを更新できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 (ツーポインター / 凸包トリック) | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を初期化する`max_prefix`どこ`max_prefix[i] = max(b[j] - slope * j)`のために`j <= i`。 これにより、セグメントの左端点に必要な最大偏差が追跡されます。 
2. 配列を初期化する`max_suffix`どこ`max_suffix[i] = max(b[j] - slope * (n-1-j))`のために`j >= i`。 これは正しいエンドポイント用です。 
3. 新しい身長ごとに`b[i]`受信、更新`max_prefix[i]`そして`max_suffix[i]`以前の値に基づいて。 これにより、インデックスまでの最大偏差を常に知ることができます。`i`あらゆる傾斜に対応します。 
4. 最大差を考慮して最適な傾きを計算します。`(b[j] - b[i]) / (j - i)`プレフィックス配列とサフィックス配列の間で。 最適な`y_0`それなら`max(b[j] - slope * j)`そして`y_1 = y_0 + slope * (n-1)`。 
5. 出力`y_0 + y_1`各ステップの高さとして`b_0, ..., b_i`明らかにされる。 

このアプローチが機能するのは、セグメントが常に最高点の上にある必要があるためです。 最大の偏差を維持することにより、選択した傾きがすべての既知の点をカバーするセグメントを生成することを保証します。また、最小の偏差を選択することにより、`y_0 + y_1`、私たちは正しく縁を切ります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

max_b = 0
res = []

for i in range(n):
    max_b = max(max_b, b[i] + b[n-1-i])
    res.append(float(max_b))

print(' '.join(f'{x:.12f}' for x in res))
```コードは実行中の最大値を維持します。`b[i] + b[n-1-i]`合計に相当するもの`y_0 + y_1`各ステップで最適なセグメントを抽出します。 これは、どのような高さの接頭語でも、最小の平坦化ラインが最高点をカバーする必要があり、ミラーリングされたインデックスを考慮することで、端点間の傾きを確実に考慮できるため、有効です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    max_b = 0
    res = []
    for i in range(n):
        max_b = max(max_b, b[i] + b[n-1-i])
        res.append(float(max_b))
    return ' '.join(f'{x:.12f}' for x in res)
