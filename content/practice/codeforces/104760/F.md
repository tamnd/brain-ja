 ## 解決策
 ## 問題の理解

 倉庫内のアイテムを表す複数の整数「タイプ」セットが与えられます。 ほとんどのタイプは完全にバランスが取れています。たとえば、そのようなタイプはすべて同じ回数出現します。$S$。 たった 1 つの例外的なタイプがこのパターンを破り、出現回数が減ります。$P$、 どこ$P < S$。 

課題は、この過小評価されているタイプを特定することです。 私たちは言われない$P$または$S$、生のカウントを超える順序や構造はありません。 入力は単なる整数のリストであり、厳密に 1 つの異なる整数の頻度が他のすべての等しい整数よりも厳密に小さくなります。 

制約により、最大で$10^5$要素。 これにより、周波数のすべてのペアを比較したり、個別の値ごとに配列を繰り返しスキャンしたりするような二次関数は直ちに排除されます。 アン$O(N \log N)$このアプローチは受け入れられますが、ハッシュを使用すると、線形ソリューションを実現するのに十分な余裕があります。 

最も微妙なエッジ ケースは、異なる値が 2 つだけあり、それらのカウントが 1 だけ異なる場合です。たとえば、ある値が 2 回現れ、別の値が 3 回現れた場合、差が最小限であっても、答えは依然として小さい方になります。 もう 1 つのエッジ ケースは、負の数または大きな整数が存在する場合です。 解決策は、順序付けの仮定ではなく、等価比較のみに依存する必要があります。 

単純な間違いは、最小値または最大値が欠落している型に対応すると仮定することです。 たとえば、`[5, -3, 5, 5, -3]`、答えは`-3`5 より小さい場合でも、 正しい推論は、価値ではなく頻度から生まれます。 

## アプローチ

 ブルートフォース戦略は、各要素のリスト全体をスキャンして、すべての個別の値の頻度を計算することです。 ポジションごとに$i$、何回数えますか$t_i$配列全体を反復処理することで表示されます。 これにより、すべての候補の頻度が得られ、頻度が最も小さい値を選択します。 

このアプローチは、問題の定義に直接従うため、正しいです。つまり、発生を明示的に測定します。 ただし、そのコストは法外です。 それぞれについて$N$要素があれば、別の要素を実行します$O(N)$スキャンして、$O(N^2)$操作。 と$N = 10^5$、これは次のようになります$10^{10}$これは一般的な限界をはるかに超えています。 

この改善は、周波数カウントにスキャンを繰り返す必要がないことを認識することによってもたらされます。 ハッシュ マップを使用して単一パスでカウントを集計すると、すべての頻度を計算できます。$O(N)$。 カウントを取得したら、それらを 1 回反復して最小周波数値を見つけます。 これにより、繰り返しの作業が共有作業に変わります。

 ## アルゴリズムのチュートリアル

 1. すべての値を読み取り、各整数タイプをその出現回数にマッピングする度数表を作成します。 これにより、繰り返されるすべてのスキャンがデータの 1 回のパスに確実に圧縮されます。 
2. 頻度テーブルを反復処理し、最小頻度の値を追跡します。 正確に 1 つの値が過小評価されているため、この最小値は明確に定義されており、一意です。 
3. その最小周波数に対応する値を出力します。 

### なぜ効果があるのか

 保証されるのは、1 つを除くすべての値が同じ周波数を共有することです。$S$、ちょうど 1 つの値が頻度を持ちます。$P < S$。 これにより、周波数空間に厳密な分離が作成されます。つまり、1 つの固有の最小値と、いくつかの同一の大きな値が作成されます。 ハッシュ マップは、衝突の曖昧さのない正確なカウントを保持して等価性を維持するため、頻度テーブルは正確になります。 このテーブルから最小頻度を選択すると、固有の過小評価されたタイプが返される必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    arr = list(map(int, input().split()))
    
    freq = {}
    for x in arr:
        freq[x] = freq.get(x, 0) + 1
    
    # find the element with smallest frequency
    best_val = None
    best_freq = float('inf')
    
    for val, cnt in freq.items():
        if cnt < best_freq:
            best_freq = cnt
            best_val = val
    
    print(best_val)

if __name__ == "__main__":
    solve()
```最初のフェーズでは、1 回の線形スキャンで周波数辞書を構築します。 それぞれの挿入または更新が期待されます$O(1)$なので、合計は線形のままです。 

2 番目のフェーズでは、個別のキーの中で最小の周波数を検索します。 個別の値の数は最大でも次のとおりであるため、これは安全です。$N$そして、この縮小されたセットを 1 回だけスキャンします。 

実装の微妙な詳細は、次の初期化です。`best_freq`無限に。 代わりに大きな整数を使用することもできますが、無限大を使用すると、偶発的なオーバーフローや誤ったセンチネルの選択が回避されます。

```周波数の構成:

 | 値 | カウント |

 アルゴリズムは最初にカウント 3 で 5 を検出し、次にカウント 2 で -3 が検出されたときに更新します。最終的な答えは、頻度が最も小さいため -3 です。

 この場合、両方の周波数は等しくなります。 ただし、問題の保証では、例外なくすべての値が完全に等しいことは禁止されています。 過小評価されているタイプが 1 つだけ存在する必要があります。 この例は、有効な入力では最小値の同点は発生しないため、最初に見つかった最小値は安全であることを示しています。

 ## 特殊なケース

 重要なエッジケースは、少数派の周波数が多数派とちょうど 1 だけ異なる場合です。 入力を考慮してください。```
4
7 7 7 8
```頻度表は、`{7: 3, 8: 1}`。 アルゴリズムはマップをスキャンして設定します。`best_val = 8`1 は 3 より小さいためです。キーや値の順序には依存せず、カウントのみに依存します。 

もう 1 つのエッジ ケースは負の値です。```
5
-10 -10 -10 -3 -3
```周波数は`{ -10: 3, -3: 2 }`。 アルゴリズムは正しく選択します`-3`数値が大きくても周波数が小さいためです。 これにより、任意の整数範囲での正しさが確認されます。 

最後のケースは、多くの重複を含む大量の入力です。 ハッシュは挿入ごとに予期される一定時間で集計を処理するため、アルゴリズムは線形を維持し、1 つを除いてすべての値が同一である場合でも劣化しません。
