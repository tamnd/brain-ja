 ## 解決策
 ## 問題の理解

 私たちには、各惑星が双方向の直接ルートによって他の惑星と接続されている惑星のグラフが与えられています。 各惑星について、私たちはその惑星に直接到達するルートが何本あるか、つまりグラフで言えばその次数だけを気にします。 

このタスクは、P から Q までの指定された間隔内に度数を持つ惑星がいくつあるかを数えるというものです。 

したがって、入力は N 個の頂点と M 個のエッジを持つ無向グラフを記述します。 各エッジは両方のエンドポイントの次数を 1 ずつ増やします。 このグラフを構築または処理した後、すべての頂点の次数を計算し、必要な範囲内に入る頂点の数を数えます。 

この制約により、最大 10^4 の惑星と最大 10^5 の接続が許可されます。 このスケールは、O(N + M) ソリューションが容易に十分に高速であることを意味します。 すべての頂点のすべてのエッジをスキャンするなど、ネストされた方法でノードごとの隣接情報を再計算するものはすべて、最悪の場合約 10^9 の操作を必要とし、制限時間内に実行されません。 

惑星にまったくつながりがない場合、微妙なエッジケースが現れます。 その次数は 0 であるため、P が 0 であるか、間隔に 0 が含まれている場合は、孤立したノードをカウントする必要があります。 もう 1 つのエッジ ケースは、M が 0 に等しく、N が大きい場合で、すべての度が同時に 0 になります。 また、P と Q は 1 以上にできるため、すべてのノードの次数が 0 であるグラフは、P が 0 でない限り出力 0 を正しく生成するはずです。 

## アプローチ

 この問題を解決する最も直接的な方法は、すべてのエッジをスキャンしてすべての頂点の次数を計算することです。 各ノードについて、すべてのエッジを反復処理し、それがエンドポイントとして表示される回数をカウントできます。 各発生が 1 つの入射エッジに対応するため、これにより正しい度数が生成されます。 

ただし、このアプローチではすべての頂点に対して同じスキャンが繰り返されます。 N 個の頂点と M 個のエッジを使用すると、O(NM) 個の作業が発生し、最悪の場合、約 10^9 回の演算に達します。 それは遅すぎます。 

重要な点は、次数の計算に頂点ごとのスキャンが必要ないことです。 各エッジは、2 つの頂点に正確に 1 つのユニットを提供します。 したがって、次数配列を維持し、エッジごとに 1 回更新できます。 これにより、問題はエッジ リストの 1 回のパスに軽減されます。 

度数が計算されたら、[P, Q] 内にいくつあるかを単純に数えます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (ノードごとにエッジをスキャン) | O(NM) | O(N) | 遅すぎる |
 | 学位の累積 | O(N + M) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 エッジを読み取りながら段階的に次数を計算します。 

1. ゼロに初期化されたサイズ N の配列を作成します。 これにより、各惑星に接触するエッジの数が保存されます。 
2. 各エッジ (a、b) を読み取ります。 グラフは無向であるため、degree[a] を 1 つずつ増やし、degree[b] を 1 つ増やします。 これにより、隣接ストレージを必要とせずに次数の定義が直接エンコードされます。 
3. すべてのエッジを処理した後、1 から N までのすべての惑星を反復処理します。 
4. 各惑星について、degree[i] が P と Q の間にあるかどうかを確認します。 「はい」の場合、回答カウンターを増やします。 
5. 最終カウンターを出力します。 

重要な考え方は、各エッジが 1 回だけ処理され、その寄与が両方のエンドポイントに即座に分散されるということです。 

### なぜ効果があるのか

 無向グラフの頂点の次数は、入射エッジの数として定義されます。 すべての入力エッジは、その各端点に対して 1 つの入射のみに寄与し、他の頂点には寄与しません。 入力処理中に両方のエンドポイントに 1 を加算することで、次数の定義を正確に蓄積します。 エッジが欠落したり、その 2 つの端点を超えて二重にカウントされたりすることはないため、結果として得られる配列はすべての頂点に対して正しいものになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    deg = [0] * (n + 1)

    for _ in range(m):
        a, b = map(int, input().split())
        deg[a] += 1
        deg[b] += 1

    p, q = map(int, input().split())

    ans = 0
    for i in range(1, n + 1):
        if p <= deg[i] <= q:
            ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```このソリューションでは、惑星 ID でインデックス付けされた単純な度数配列を使用します。 実装の最も重要な詳細は、次数カウントのみが重要であるため、隣接リストをまったく構築しないことです。 これにより、余分なメモリのオーバーヘッドが回避され、ソリューションが線形に保たれます。 

境界チェック`p <= deg[i] <= q`両方のエンドポイントを含める必要があります。 ここでの 1 つ違いの間違いは、特に間隔が包括的であるかどうかを解釈する場合によくあります。 この問題では包括的であることが明示されているため、両方の比較は非厳密である必要があります。

 ## 特殊なケース

 エッジがない場合、すべての惑星の度数は 0 になります。 アルゴリズムは引き続きすべての次数をゼロに初期化し、更新を実行しません。 最後のループでは、P ≤ 0 ≤ Q を満たすノードの数をカウントします。これは正しいことです。孤立したノードは、区間内に 0 が存在する場合にのみ有効な候補となるためです。 

単一ノード グラフの場合、エッジ上のループは完全にスキップされます。 次数は 0 のままで、最終的な答えは区間に 0 が含まれるかどうかによって決まります。 これは、ソリューションが少なくとも 1 つのエッジが存在することを前提としていないことを確認します。 

すべてのノードが高度に接続されている場合 (たとえば、完全なグラフ)、各ノードは対称更新を繰り返すことで次数 N-1 を蓄積します。 各エッジは正確に 2 つの増分に寄与するため、オーバーカウントは発生せず、最大密度でもフィルタリングは正確なままです。
