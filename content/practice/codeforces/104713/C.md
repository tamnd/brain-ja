 ## 問題の理解

これに加えて、コレクターと呼ばれる特別なエージェントがいます。 各コレクターは固定のステップ サイズを選択し、開始位置に戻るまでそのステップを使用して円の周りを繰り返し歩きます。 このステップ サイズは、歩行が明確に定義され、円を均等に分割するように制限されます。 散歩中、コレクターは訪問するすべての家が同じカテゴリーに属している場合にのみ成功します。 その場合、彼は訪問したすべての家から 1 回だけお金を集めます。 

重要な構造上の結果は、コレクタに段差があることです。$s$（どこ$s = d+1$) すべてのインデックスの合同モジュロを訪問します$s$。 したがって、各コレクターは、次の約数を法とする剰余クラスに関連付けられます。$N$、そしてそれらは、空き家に色を割り当てた後、残差クラス全体が単色の場合にのみ有効です。 

目標は、すべての有効なコレクターが同時に集めた合計金額を最大化する方法で、すべての空き家にカテゴリを割り当てることです。 

という制約が$N$素数の力が重要です。 それは、すべての約数が$N$という形です$p^k$したがって、除数の構造は分岐格子ではなく鎖になります。 これにより、複数の独立した素因数による複雑さが排除され、ステップ サイズ間のサブセット関係がより明確になります。

### なぜ効果があるのか

 文字の有効な割り当てはすべて、一意の最小約数を引き起こします。$s$すべてのコレクター有効な剰余クラスが大規模な周期構造から得られるようにする$s$。 素数べき乗モジュラス格子では周期性が独立ではなく入れ子になっているため、より粗いレベルでカウントされた寄与も、より細かい周期構造によって完全に説明されます。 除数チェーンに沿った包含/除外により、各構造構成が最小の定義スケールで 1 回だけカウントされることが保証され、重複するコレクター定義間での二重カウントが防止されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N = int(input().strip())
    S = input().strip()
    k = int(input().strip())

    val = {chr(i): 0 for i in range(65, 91)}
    for _ in range(k):
        c, v = input().split()
        val[c] = int(v)

    # all divisors of N (prime power => chain)
    divisors = []
    x = N
    p = None

    tmp = N
    for i in range(2, int(tmp ** 0.5) + 1):
        if tmp % i == 0:
            p = i
            break
    if p is None:
        p = tmp

    while x > 1:
        divisors.append(x)
        x //= p
    divisors.append(1)
    divisors.sort()

    idx = {d: i for i, d in enumerate(divisors)}
    m = len(divisors)

    f = [0] * m
    g = [0] * m

    # precompute positions grouped by modulo each divisor
    for i, d in enumerate(divisors):
        groups = [[] for _ in range(d)]
        for j in range(N):
            groups[j % d].append(j)

        total = 0
        for grp in groups:
            best = 0
            for c in val:
                cur = 0
                for j in grp:
                    if S[j] == '?' or S[j] == c:
                        cur += val[c]
                    else:
                        cur = -10**18
                        break
                best = max(best, cur)
            total += best

        f[i] = total

    # inclusion-exclusion on chain
    for i in range(m):
        g[i] = f[i]
        for j in range(i):
            if divisors[i] % divisors[j] == 0:
                g[i] -= g[j]

    print(sum(g))

if __name__ == "__main__":
    solve()
```この実装では、まずすべての約数が計算され、素数べき乗の制約により単純なチェーンが形成されます。 各約数について、剰余クラスごとにインデックスを明示的にグループ化し、26 文字すべてを試してグループごとに最適な均一割り当てを評価します。 このステップでは、その周期構造を強制することによる生の潜在的な寄与を取得します。 

2 番目のフェーズでは、除数チェーンに沿って包含と除外を実行します。 それぞれの粗い約数がより細かい周期構造を集約するため、二重カウントを避けるために以前に計算された寄与を差し引きます。 最終的な合計は、還元不可能な定期的な寄与のみを集計します。

 ## 特殊なケース

 重要なエッジケースは、異なる約数の競合する剰余クラスに固定文字が出現する場合です。 たとえば、位置を 1 つの文字に固定すると、剰余クラスが、ある約数では最適ではないが、別の約数では最適になる可能性があります。 局所的な最良の割り当てを計算するときに、各除数の評価が固定制約を厳密に尊重するため、アルゴリズムはこれを処理します。 

もう 1 つの微妙なケースは、すべての文字が「?」である場合です。 この場合、すべてのクラスを独立して割り当てることができ、包含-除外によりすべてが最も詳細な周期分解に還元されます。 これにより、ネストされた除数間で過大なカウントが行われなくなります。 

3 番目のケースは、固定文字がまばらに現れるが、それでも全体的な周期構造を強制する場合です。 グループ化ステップにより、スパース制約であっても各剰余クラス内で正しく伝播されることが保証されますが、包含-除外により、同じ構造が複数の除数レベルでカウントされることが防止されます。
