 ## 解決策
 ## 問題の理解

 3 つの独立して見える制限を満たす区間 ([A,B]) 内の正の整数 (N) をカウントする必要があります。 

まず、(N) のすべての 10 進数は、指定されたセット (S) に属している必要があります。 次に、(N) は (X) で割り切れなければなりません。 第三に、右から位置に番号を付ける場合、位置 (i) の数字は (i) と互いに素でなければなりません。 つまり、右からi番目の桁(d_i)については、(\gcd(d_i,i)=1)が必要となります。 答えは、そのような整数の数を剰余 (10^9+7) で割ったものです。 

公式の制約では、(B) は最大 101 桁の 10 進数を持つことができますが、(X) は (10^5) までの大きさにすることができます。 これにより、間隔の列挙が直ちに除外されます。 すべての数値を保存または反復する場合でも、最大約 (10^{100}) 個の候補が必要になります。 コストが (B) の数値サイズではなく、桁数と (X) に依存するアルゴリズムが必要です。 

誤って処理されやすい境界ケースがいくつかあります。 1 つ目は先行ゼロです。 ゼロは内部位置では有効な数字である可能性がありますが、正の整数の最上位桁にすることはできません。 たとえば、入力の場合```
1 9 1
0
```答えは`0`。 不用意に実装すると、`0`有効な 1 桁の数値として扱うか、次のような表現を考慮します。`01`通常の正の整数として。 

2 番目の問題は、共素条件が左からではなく右から数えられることです。 例えば、`12`は、右端の数字が (2) および (\gcd(2,1)=1) であり、左端の数字が (1) および (\gcd(1,2)=1) であるため、位置条件に関して有効です。 これが、単純に左から右への表現のインデックスに対して数字をチェックすると間違った結果が得られる理由です。 

3 番目の問題は、右からの数字を処理する場合の上限です。 考慮する`B = 20`そして一桁の数字`8`。 下位桁の比較`8`下位の数字で`0`引き算をします`0 - 8`借りますが、`8`よりも明らかにまだ小さいです`20`。 右から左への境界 DP は、短い数値が長い正の上限よりも自動的に下に収まることを覚えておく必要があります。 

## アプローチ

 直接的なアプローチは、(A) から (B) までのすべての整数を列挙することです。 各候補について、その桁を検査し、(S) のメンバーシップを検証し、すべての位置での共素性条件をチェックし、(X) で割り切れる可能性をテストします。 すべての候補が 1 回だけ検査され、すべての必要な条件が明示的にチェックされるため、これは正しいです。 

問題は間隔の大きさです。 (B) が 101 桁の場合、(10^{100}) 個のオーダーの候補が存在します。 1 つの候補のチェックに (O(100)) 回の操作しかかからなかったとしても、最悪のケースはおよそ (O(100\cdot10^{100})) となり、これはまったく実行不可能です。 

重要な観察は、割り算を除いて制限が桁ローカルであるということです。 位置 (i) では、(\gcd(d,i)=1) をチェックすることで、どの桁が正しいかをすぐに判断できます。 割り算は、剰余 (X) で表すこともできます。 これにより、状態に剰余と限界との比較に関する少量の情報のみが含まれる数字 DP が得られます。 

ここには特に便利なトリックがあります。 位置条件は右から定義されるため、左から右へ境界を処理する代わりに、構築された数値と右から左への境界の両方を処理します。 この比較は、構築された数値を境界から減算する際に生成されるボローによって表すことができます。 

現在処理されている境界の下位 (i) 桁が (B_{\text{low}}) であり、構築された数値の対応する桁が (N_{\text{low}}) であるとします。 減算 (B_{\text{low}}-N_{\text{low}}) で次の位置への借用が必要かどうかを維持します。 これにより、通常の左から右へのタイトな状態が 2 状態の借入状態に変わります。 

残りも右からが便利です。 すでに選択されている (i-1) の下位桁が剰余 (r) のある値を形成し、位置 (i) の新しい桁が (d) である場合、新しい値は次のようになります。 

[
 r+d\cdot10^{i-1}。 
]

 したがって、剰余 (X) を維持するだけで済みます。 

同じ DP は、境界の長さまでのあらゆる可能な長さをカウントできます。 構築された数値の桁数が境界よりも少ない場合、最終的な借用に関係なく、数値は自動的に小さくなります。 最終的にゼロを借用する必要があるのは、境界とまったく同じ桁数を持つ数値のみです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(100\cdot10^{100})) | (O(1)) | 遅すぎる |
 | 最適 | (O(LX | S | )) 境界ごと | (O(X)) | 承認済み |

 ここ (L\le101)。 (B) と (A-1) に対して有界 DP を実行しますが、これは定数係数のみを変更します。 

## アルゴリズムのチュートリアル

 1. 定義する`dp0[r]`そして`dp1[r]`右からいくつかの位置を処理した後。`dp0[r]`境界の対応する下位桁からの現在の減算に借りがない構造をカウントします。`dp1[r]`借入のある建設をカウントします。 どちらの配列も剰余モジュロ (X) によってインデックスが付けられます。 

最初は桁が選択されておらず、剰余はゼロであり、借用もありません。`dp0[0] = 1`そして他のすべての状態はゼロです。 
2. 位置 (i=1,2,\ldots,L) を右から左に処理します。 すべての位置について、(\gcd(d,i)=1) を満たす (S) からの数字のリストを作成します。 これらは、まさにこの位置に表示される数字です。 

これにより、異常な位置条件が遷移に直接組み込まれるため、無効な数字が DP に入力されることはありません。 
3. (p=10^{i-1}\bmod X) を維持します。 現在の桁が (d) の場合、それをすでに構築されている下位の桁に加算すると、余りが (r) から に変わります。 

[
 (r+d p)\bmod X.
 ]

 パワーは、各位置の後に 10 を乗算して更新されます。 
4. (b) を境界の右から (i) 番目の桁とします。 前回の借用が (c) であるとします。 この位置での減算は、

 [
 b-d-c。 
]

 新しい借入は、この値が負であるかどうかによって決まります。 ケースは3つだけです。 

(d<b) の場合、考えられる古い借用は両方とも新しい借用を生成しません。 

(d=b) の場合、古い借入は借入のままですが、古い借入がない場合は借入ではないままになります。 

(d>b) の場合、考えられる両方の古い借用により新しい借用が生成されます。 

これは、通常の数字 DP におけるよく知られたタイトな状態遷移に相当する右から左への遷移です。 
5. 位置 (i) を処理した後、長さが正確に (i) である数を数えます。 位置 (i) を最上位位置にするには、選択した桁が 0 以外でなければなりません。 すべての正当なゼロ以外の数字 (d) について、どの前の剰余が剰余ゼロにつながる可能性があるかを正確に知っています。 

[
 r\equiv-d\cdot10^{i-1}\pmod X.
 ]

 このような余りは 1 つだけであるため、正確な長さの割り切れる数を数えるには、桁ごとに一定数の追加演算のみが必要になります。 
6. (i<L) の場合、すべての (i) 桁の正の数は (L) 桁の境界よりも小さくなります。 したがって、この長さの寄与をカウントする際には、両方の借用状態が受け入れられます。 

(i=L) の場合、数値は境界と同じ長さになるため、最終ボロー ゼロを持つ状態のみが受け入れられます。 
7. コンピューティング`count_leq(B)`、次に (A) を 10 進数の文字列として 1 つ減算して計算します。`count_leq(A-1)`。 必要な間隔の答えは次のとおりです。 

[
 \text{count_leq}(B)-\text{count_leq}(A-1)。 
]

 減算は (10^9+7) を法として実行されます。 

これが機能する理由: 右から最初 (i) の位置を処理した後、各 DP 状態はそれらの位置に対する有効な選択肢の 1 セットを正確に表し、その剰余モジュロ (X) と境界からの減算の借入によって分類されます。 遷移では、すべての有効な次の桁が 1 回だけ考慮され、それが数学的に正しい新しい剰余および借用状態に送信されます。 数値が (i) 桁の後に停止する場合、その最上位桁はゼロ以外であることが明示的に要求されます。 短い数値の場合、境界の未処理の上位部分に少なくとも 1 つの正の数字が含まれるため、両方の借用状態が有効になります。 等しい長さの数値の場合、ゼロを借用することは、構築された数値が上限以下であるという正確な条件となります。 したがって、有効な数値はすべて 1 回カウントされ、無効な数値はカウントされません。 

## Python ソリューション```python
import sys
from math import gcd

input = sys.stdin.readline

MOD = 1_000_000_007

def dec_one(s):
    s = s.lstrip('0')
    if not s:
        return None

    a = list(s)
    i = len(a) - 1

    while i >= 0 and a[i] == '0':
        a[i] = '9'
        i -= 1

    if i < 0:
        return None

    a[i] = str(ord(a[i]) - ord('0') - 1)

    res = ''.join(a).lstrip('0')
    return res if res else '0'

def count_leq(t, x, source_digits):
    if t is None or t == '0':
        return 0

    t = t.lstrip('0')
    if not t:
        return 0

    length = len(t)

    allowed = [[] for _ in range(length + 1)]
    for pos in range(1, length + 1):
        cur = allowed[pos]
        for d in source_digits:
            if gcd(d, pos) == 1:
                cur.append(d)

    # dp0[r]: low processed digits have no borrow.
    # dp1[r]: low processed digits have a borrow.
    dp0 = [0] * x
    dp1 = [0] * x
    dp0[0] = 1

    power = 1
    answer = 0

    # Digits of t indexed from the right.
    bound_digits = [ord(c) - 48 for c in reversed(t)]

    for pos in range(1, length + 1):
        bd = bound_digits[pos - 1]
        digits = allowed[pos]

        ndp0 = [0] * x
        ndp1 = [0] * x

        # Count numbers that stop at this position.
        # For pos < length, both borrow states are valid.
        # For pos == length, only borrow 0 is valid.
        if pos < length:
            length_count = 0

            for d in digits:
                if d == 0:
                    continue

                add = (d * power) % x
                prev = (-add) % x

                v = dp0[prev] + dp1[prev]
                if v >= MOD:
                    v -= MOD

                length_count += v
                if length_count >= MOD:
                    length_count -= MOD

            answer += length_count
            if answer >= MOD:
                answer -= MOD
        else:
            length_count = 0

            for d in digits:
                if d == 0:
                    continue

                add = (d * power) % x
                prev = (-add) % x

                if d < bd:
                    v = dp0[prev] + dp1[prev]
                elif d == bd:
                    v = dp0[prev]
                else:
                    v = 0

                if v >= MOD:
                    v -= MOD

                length_count += v
                if length_count >= MOD:
                    length_count -= MOD

            answer += length_count
            if answer >= MOD:
                answer -= MOD

        # Build the DP for the next position.
        for d in digits:
            add = (d * power) % x

            if d < bd:
                # Both old borrow states become borrow 0.
                src0 = dp0
                src1 = dp1
                dest = ndp0

                for r in range(x):
                    j = r + add
                    if j >= x:
                        j -= x

                    v = src0[r] + src1[r]
                    if v >= MOD:
                        v -= MOD

                    v += dest[j]
                    if v >= MOD:
                        v -= MOD

                    dest[j] = v

            elif d == bd:
                # No old borrow stays at 0, old borrow stays at 1.
                src0 = dp0
                src1 = dp1

                for r in range(x):
                    j = r + add
                    if j >= x:
                        j -= x

                    v = ndp0[j] + src0[r]
                    if v >= MOD:
                        v -= MOD
                    ndp0[j] = v

                    v = ndp1[j] + src1[r]
                    if v >= MOD:
                        v -= MOD
                    ndp1[j] = v

            else:
                # Both old borrow states become borrow 1.
                src0 = dp0
                src1 = dp1
                dest = ndp1

                for r in range(x):
                    j = r + add
                    if j >= x:
                        j -= x

                    v = src0[r] + src1[r]
                    if v >= MOD:
                        v -= MOD

                    v += dest[j]
                    if v >= MOD:
                        v -= MOD

                    dest[j] = v

        dp0, dp1 = ndp0, ndp1

        power = (power * 10) % x

    return answer

def solve_case(a, b, x, s):
    digits = [ord(c) - 48 for c in s]

    right_of_a = dec_one(a)

    upper = count_leq(b, x, digits)
    lower = count_leq(right_of_a, x, digits)

    return (upper - lower) % MOD

def main():
    A, B, X = input().split()
    X = int(X)
    S = input().strip()

    print(solve_case(A, B, X, S))

if __name__ == "__main__":
    main()
```の`allowed`配列は位置ルールの直接実装です。 位置 1 は、すべての桁が 1 と互いに素であり、数学的にゼロも許容されるため、特別です。 ゼロは最下位位置に対して有効なままですが、正確な長さのカウントステップでは、その位置が最上位桁になるたびにゼロがスキップされます。 

残りの 2 つの配列が中心の DP 状態です。 各遷移は直前の位置のみに依存するため、配列はすべての位置で再作成されます。 現在の残余と借入を超える履歴は必要ありません。 

アップデート`j = r + add`続いて次の 1 回の減算が続きます`x`最も内側のループ内の比較的高価なモジュロ演算を回避します。 両方なので`r`そして`add`いる`[0,x-1]`、それらの合計は以下より小さい`2x`, したがって、1 つの減算で十分です。 

ゼロは内部的には有効ですが、先頭の数字としては無効であるため、正確な長さのカウントは遷移とは別のものです。 ゼロ以外の候補数字の場合`d`、最終剰余ゼロを生成する唯一の前の剰余は、`(-d * power) % x`。 これにより、剰余 0 を生成する有効な先行桁の数を判断するためだけに剰余配列全体を 2 回スキャンする必要がなくなります。 

借用遷移は特に注目に値します。 のために`d < bd`、既存の借入であっても吸収されます。`bd - d - 1`はまだ非負です。 のために`d == bd`、既存の借用は存続します。 のために`d > bd`, どちらの場合も借入が必要です。 これら 3 つのケースを混同すると、右から左への実装で誤った答えが生じる可能性が最も高くなります。 

Python の整数はオーバーフローしませんが、加算のたびにすべての DP カウントがモジュロ (10^9+7) で減らされます。 10 進数のデクリメントは文字列に対して直接行われます。これが必要なのは、(A) が 101 桁であり、固定幅の整数に収まる必要がないためです。

 ## 特殊なケース

 先頭のゼロは、ゼロをグローバルに禁止するのではなく、正確な長さのカウント ステップによって処理されます。 例えば、```
