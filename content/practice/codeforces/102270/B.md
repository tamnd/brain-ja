 ## アルゴリズムのチュートリアル

 1. カメラに向かってツリーを根付かせる`1`そしてすべての頂点の親を決定します。 また、各頂点の完了する必要がある子の数もカウントします。 反復構造により、ある長さのパスでの Python 再帰の深さの問題が回避されます`50,000`。 
2. すべての頂点の DP を、その頂点のみを含む接続セットで初期化します。 頂点にラベルがある場合`0`、その初期配列は`[1]`パスワードカメラの提供がゼロだからです。 そのラベルが`1`、その初期配列は`[0, 1]`なぜなら、この頂点を含むセットは必然的に 1 単位のエネルギーを使用するからです。 
3. すべてのリーフを処理キューに入れます。 リーフには受信すべき子情報が残っていないため、その DP はすでに完了しており、親に直接送信できます。 
4.子供が完成したとき`v`親に到達する`u`、2 つの DP 配列をマージします。 現在の親状態が使用している場合`i`パスワードカメラと子国家が使用するもの`j`、 追加`current[i] * dp[v][j]`のために州に`i + j`。 配列はインデックスの後ろで切り捨てられます`K`より大きな値は必要な答えに決して貢献できないためです。 
5. マージの実行中、古い親 DP を保持します。 これは、子サブツリーからカメラを取得しないオプションを表します。 畳み込みは、子を含む接続セットを取るすべての選択肢を表します。 
6. 未完成の子の数を減らす`u`。 ゼロになると、すべての子供が法人化されるため、`dp[u]`完了です。 インデックスの係数`K`選択された頂点の最上位にあるすべての有効な接続セットをカウントします。`u`。 その係数をグローバルな答えに追加して合格します`dp[u]`その親に。 
7. ルートが終了すると、空ではないすべての接続セットが 1 回だけカウントされます。 蓄積された回答を印刷します。 

### なぜ効果があるのか

 不変条件とは、`dp[u][k]`のサブツリー内に接続された頂点セットが正確に含まれます。`u`を含む`u`そしてまさに`k`パスワードカメラ。 利用可能なセットは`{u}`。 子のマージ中、以下を含むすべての有効なセットが`u`その子サブツリーの頂点が含まれていないか、子を含む接続セットが含まれています。 これら 2 つのケースは素であり、網羅的です。なぜなら、間のエッジを削除するからです。`u`そして子はツリーを 2 つのコンポーネントに分割します。 畳み込みでは、2 つの独立した選択肢のすべての組み合わせが 1 回だけカウントされます。 最後に、空ではないすべての接続セットには一意の最高頂点が 1 つあるため、合計すると`dp[u][K]`完了しすぎた頂点はセットを二重にカウントできません。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

def solve(data: str) -> str:
    it = iter(data.split())
    n = int(next(it))
    k = int(next(it))

    color = [0] * n
    for i in range(n):
        color[i] = int(next(it))

    graph = [[] for _ in range(n)]
    for _ in range(n - 1):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        graph[u].append(v)
        graph[v].append(u)

    # Root the tree at 0.
    parent = [-1] * n
    parent[0] = -2
    children_left = [0] * n

    order = [0]
    for u in order:
        for v in graph[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            order.append(v)

    for u in range(n):
        cnt = 0
        for v in graph[u]:
            if parent[v] == u:
                cnt += 1
        children_left[u] = cnt

    # dp[u] is the current connected-subtree DP containing u.
    # Only states 0..K are stored.
    dp = []
    for c in color:
        if c == 0:
            dp.append([1])
        else:
            if k == 0:
                dp.append([0])
            else:
                dp.append([0, 1])

    q = deque()
    for u in range(n):
        if children_left[u] == 0:
            q.append(u)

    answer = 0

    while q:
        u = q.popleft()

        if k < len(dp[u]):
            answer += dp[u][k]

        p = parent[u]
        if p < 0:
            continue

        child = dp[u]
        current = dp[p]

        a = len(current)
        b = len(child)

        new_len = min(k + 1, a + b - 1)
        new_dp = current[:new_len]

        # Take a nonempty connected part containing u from the child.
        # The copy above represents taking nothing from the child.
        for i in range(a):
            x = current[i]
            if x == 0:
                continue

            max_j = min(b - 1, k - i)
            for j in range(max_j + 1):
                y = child[j]
                if y:
                    new_dp[i + j] += x * y

        dp[p] = new_dp
        dp[u] = None

        children_left[p] -= 1
        if children_left[p] == 0:
            q.append(p)

    return str(answer)

def main():
    data = sys.stdin.buffer.read().decode()
    sys.stdout.write(solve(data))

if __name__ == "__main__":
    main()

初期DPはラベルごとに意図的に異なります`0`そして`1`。 保護されていないカメラの場合、`{u}`コストはゼロなので、`dp[u][0] = 1`。 保護されたカメラの場合、`{u}`コストが 1 なので、`dp[u][1] = 1`。 いつ`K = 0`、後者の状態は必要な範囲外であるため、初期配列にはゼロのみを含めることができます。 

マージは次から始まります`current[:]`。 このコピーは、単なる最適化の詳細ではありません。 それは子供から何も奪わないという選択を表しています。 次に、ネストされたループは、子を含む接続セットが選択される可能性をすべて追加します。 上限`k - i`目標エネルギー予算を超えた書き込みを防ぎます。 

ライン`dp[u] = None`は、その寄与が親に組み込まれた後、子の DP を解放します。 これは、大きなツリーでのメモリ使用量にとって重要です。 パスには多くの頂点が含まれる場合がありますが、各ステージで大きいままにする必要があるのは、現在アクティブな親ステートのみです。 

このアルゴリズムは再帰的ではなく反復的です。 以下を含むパス上の再帰的 DFS`50,000`頂点を使用するには、Python の再帰制限を増やす必要があり、インタープリタ スタックに不必要な圧力がかかる可能性があります。 キューはそのリスクを冒すことなく、ツリーをリーフからルートに向かって処理します。 

Python の整数はオーバーフローしません。問題では正確な数が要求され、係数が指定されていないため、これはここでは役に立ちます。 接続されたサブセットの数は指数関数的に大きくなる可能性があるため、Python の任意精度の整数を使用する必要があります。

                y = child[j]
                if y:
                    new_dp[i + j] += x * y

        dp[p] = new_dp
        dp[u] = None

        children_left[p] -= 1
        if children_left[p] == 0:
            q.append(p)

    return str(answer)

def run(inp: str) -> str:
    return solve(inp).strip()
