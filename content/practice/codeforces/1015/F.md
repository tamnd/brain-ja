 ## 問題の理解

 長さの完全な有効な括弧シーケンスを構築するように求められます。`2n`そして、それらのシーケンスのうち、指定された文字列が含まれる数を数えたいとします。`s`それらの内部のどこかにある連続したブロックとして。

制約`n ≤ 100`最終的な文字列の長さが最大 ​​200 であることを意味します。パターン`|s| ≤ 200`は全長に匹敵するため、部分文字列制約は小さな局所的な摂動ではなく、ほぼ全体の構造と効果的に相互作用する可能性があります。 カタロニア語サイズのスペースは指数関数的に増大するため、シーケンスを直接列挙するアプローチは即座に除外されます。 すべての有効な括弧シーケンスを洗練して生成したとしても、限界をはるかに超えています。 

微妙なエッジケースが現れるのは、`s`それ自体は、有効な括弧シーケンスのどの接頭辞とも互換性がありません。 たとえば、次の場合`s`から始まる`)`この場合、有効なシーケンスでは位置 1 から開始することはできませんが、その後に表示される可能性はあります。 もう一つのケースは次のような場合です。`s`より長いです`2n`これにより、答えは自明にゼロになります。 さらに興味深い故障モードは次のような場合です。`s`は、先行する文字によって吸収されるよりも深い負の接頭辞バランスを持っています。 と仮定する素朴なDP`s`残高を追跡せずにどこにでも配置できます。互換性は大幅にオーバーカウントされます。 

## アプローチ

 ブルート フォース アプローチでは、有効な長さのブラケット シーケンスがすべて生成されます。`2n`標準のカタロニア語再帰を使用し、生成されたシーケンスごとに次のことを確認します。`s`部分文字列として表示されます。 この世代だけで約`O(C_n)`シーケンス、ここで`C_n ≈ 4^n / n^{3/2}`。 のために`n = 100`、これは天文学的に大きいため、部分文字列チェックなしでもこれは実行不可能です。 

問題の構造は、2 つの相互作用する制約を示唆しています。それは、括弧シーケンスのグローバルな正確性、もう 1 つは、連続して出現する必要がある固定の禁止パターンまたは必須パターンです。 重要なアイデアは、パターンがすでに一致しているかどうかを同時に追跡しながら、左から右へシーケンスを構築することです。`s`その中に。 

これは自然に、構築された文字列内の位置、開き括弧の現在のバランス、パターン マッチング オートマトン内の進行状況という 3 つの次元にわたる動的プログラミングの定式化につながります。`s`。 パターン マッチング コンポーネントは、KMP とまったく同じように動作します。新しい文字ごとに、どれだけの文字が含まれているかを表す状態間を遷移します。`s`現在の位置で終わるサフィックスとして一致しました。 

DP 状態は、パターンがすでに少なくとも 1 回完全に一致しているかどうかも追跡する必要があります。`s`どこにでも出現する場合は、今後の配置によって完了の可能性が無効にならないようにするだけで済みます。 ただし、オーバーラップが遷移に影響する可能性があるため、成功後にオートマトンを単純に無視することはできません。そのため、KMP 状態は引き続き保持しますが、ブール値を「すでに見つかった」とマークします。 

これにより、問題は制約付きオートマトン内のウォーク数のカウントに軽減されます。ブラケットのバランスは有効なままでなければならず、パターンの状態遷移はプレフィックス関数の規則に従う必要があります。

 ## アルゴリズムのチュートリアル

 プレフィックス長、バランス、パターン マッチング状態に関する DP を定義します。 

1. のプレフィックス関数を事前計算します。`s`これにより、「(」または「)」を追加した後に一致するパターンの量を効率的に更新できます。 これにより、遷移が文字ごとに線形になることが保証され、部分文字列の再スキャンが回避されます。 
2. 定義する`dp[i][b][k][f]`長さのプレフィックスを構築する方法の数として`i`、現在の残高あり`b`、KMP 状態`k`つまり一致しました`k`の登場人物`s`サフィックスとして、およびフラグとして`f`かどうかを示す`s`はすでにプレフィックスのどこかに現れています。 
3.初期化`dp[0][0][0][0] = 1`。 最初は空の文字列、残高ゼロ、一致するパターンはありません。 
4. ポジションごとに`i`から`0`に`2n - 1`、「(」または「)」のいずれかを追加しようとします。 遷移ごとに、それに応じて残高を更新し、残高がマイナスになるか超過する状態を拒否します。`n`。 これにより、有効なブラケット シーケンスを形成できるプレフィックスのセットが離れることがなくなります。 
5. 追加された文字ごとに、プレフィックス関数ロジックを使用して KMP 状態を更新します。 この文字を追加すると、一致するプレフィックスの長さが次の値に達する場合`|s|`、フラグを立てます`f = 1`パターンが発生してこの位置で終了するためです。 
6. すべてのポジションを処理した後の答えは、次の時点のすべての状態の合計になります。`i = 2n`ここで残高はゼロであり、`f = 1`。 

これが機能する理由は、結局は関心事の分離にあります。バランス ディメンションにより、有効なブラケット シーケンスのプレフィックスのみが構築されることが保証され、KMP オートマトンにより、ストリーミング文字列マッチャーと同様に部分文字列の出現が正確に追跡されることが保証されます。 すべての有効な完全なシーケンスはこの DP 内の 1 つのパスに正確に対応し、すべての DP パスは有効なシーケンスに対応するため、パスをカウントすることは、以下を含む有効なブラケット シーケンスをカウントすることと同じです。`s`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def build_kmp(s):
    m = len(s)
    pi = [0] * m
    for i in range(1, m):
        j = pi[i - 1]
        while j > 0 and s[i] != s[j]:
            j = pi[j - 1]
        if s[i] == s[j]:
            j += 1
        pi[i] = j
    return pi

def next_state(pi, s, k, ch):
    while k > 0 and s[k] != ch:
        k = pi[k - 1]
    if s[k] == ch:
        k += 1
    return k

def solve():
    n = int(input())
    s = input().strip()
    m = len(s)

    if m > 2 * n:
        print(0)
        return

    pi = build_kmp(s)

    # dp[i][balance][k][flag]
    # We roll only over i
    dp = [[[[0] * 2 for _ in range(m + 1)] for __ in range(n + 1)] for ___ in range(2)]
    cur = 0
    dp[cur][0][0][0] = 1

    for i in range(2 * n):
        nxt = 1 - cur
        for b in range(n + 1):
            for k in range(m + 1):
                for f in range(2):
                    dp[nxt][b][k][f] = 0

        for b in range(n + 1):
            for k in range(m + 1):
                for f in range(2):
                    val = dp[cur][b][k][f]
                    if not val:
                        continue

                    # add '('
                    nb = b + 1
                    if nb <= n:
                        nk = next_state(pi, s, k, '(')
                        nf = f or (nk == m)
                        if nk == m:
                            nk = pi[m - 1]
                        dp[nxt][nb][nk][nf] = (dp[nxt][nb][nk][nf] + val) % MOD

                    # add ')'
                    if b > 0:
                        nb = b - 1
                        nk = next_state(pi, s, k, ')')
                        nf = f or (nk == m)
                        if nk == m:
                            nk = pi[m - 1]
                        dp[nxt][nb][nk][nf] = (dp[nxt][nb][nk][nf] + val) % MOD

        cur = nxt

    ans = 0
    for k in range(m + 1):
        ans = (ans + dp[cur][0][k][1]) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```このコードはパターンのプレフィックス関数を構築し、それを使用してブラケット シーケンスの構築中にパターン マッチングをシミュレートします。 DP レイヤーは位置を交互に切り替えて、現在のレイヤーと次のレイヤーのみを保持します。 残高は以下に制限されています`[0, n]`、無効なプレフィックスが決して拡張されないようにします。 

微妙な実装ポイントは、次の瞬間を処理することです。`nk == m`。 境界外の状態を許可する代わりに、次を使用してそれを有効なサフィックス状態にすぐに変換します。`pi[m - 1]`マーキングしながら`nf = 1`。 これにより、状態空間の境界を維持しながら、KMP の正確さが維持されます。

 ## 特殊なケース

 主なエッジケースは次のような場合です`s`有効なシーケンスのプレフィックスが許容できる以上に不均衡を強制するため、出現する可能性はありません。 例えば、`s = "((("`と`n = 2`長さ 4 の有効なシーケンスには、バランス制約を破らずに開始が遅すぎる 3 つの連続したオープンを含めることはできないため、すでにそれは不可能になっています。 バランス > n を必要とする状態は決して作成されないため、DP はこれを自然に処理します。そのため、有効なパスはそのような部分文字列を埋め込むことができません。 

もう一つのケースは次のような場合です。`s`完全なシーケンスの境界でのみ一致します。 パターン検出は位置に依存せず、位置合わせの仮定ではなく遷移のみに依存するため、DP は引き続き正しくカウントします。 

最後の微妙なケースは、次のような自己重複パターンです。`"()()"`ここで、単純な部分文字列追跡では出現回数が 2 倍にカウントされます。 KMP ベースのオートマトンは、各プレフィックスの状態が重複しても一貫していることを保証することでこれを防ぎ、同じ出現構造が過剰にカウントされなくなります。
