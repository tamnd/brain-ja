 ## 問題の理解

 テスト ケースごとに固定の幾何学的セットアップが与えられます: 3 点$P, A, B$非縮退二等辺三角形を形成するもの$PA = PB$、および線分$AB$「刃」としての役割を果たします。 地点から$P$、キャラクターを高速で動かすことができます$v$せいぜい$t$秒なので、最終的な位置は$Q$を中心とする閉じた円盤の内部または上の任意の点にすることができます。$P$半径あり$R = v \cdot t$。 

このような到達可能なエンドポイントの場合$Q$、損傷領域は三角形です$QAB$。 到達可能な点が少なくとも 1 つ存在する場合、その点は危険とみなされます。$Q$点が三角形の内側または上にあるようにする$QAB$。 タスクは、すべての可能な位置にわたるそのようなすべての三角形の和分の面積を計算することです。$Q$。 

幾何学的に、固定セグメントを取得しています$AB$、そして 3 番目の頂点を持つ三角形をスイープします$Q$を中心とする円盤上を移動します$P$。 出力は、これらすべての三角形の結合面積です。 

制約$T \le 2 \cdot 10^4$を強く示唆する$O(1)$または、テスト ケースごとの非常に低い一定の幾何学式。 座標は大きいですが、重要なのは相対的な幾何学のみです。 これにより、離散化やサンプリングのアプローチが除外されます。$10^7$テスト ケースごとのサンプル数が遅すぎます。 

微妙な問題は、結合が単に「1 つの三角形とオフセット」ではないことです。 として$Q$三角形は継続的に動きます$QAB$境界が部分的に直線セグメントで構成され、部分的にセグメントの回転によって生じる円弧で構成される曲線領域をスイープします。$QA$そして$QB$その周り$A$そして$B$。 

単純な間違いは、答えが三角形の面積だけであると考えることです$PAB$プラス何かに比例する$R$、または和集合を三角形と円板のミンコフスキー和として扱うこともできます。 これは不正確です。三角形の 1 つの頂点だけが自由に動き、他の 2 つの頂点は固定されており、均一なオフセットではなく「三角形の扇形」が生成されるからです。 

重要なエッジケース:

 いつ$R = 0$、私たちにはそれしかありません$Q = P$なので、答えはまさに三角形の面積です$PAB$。 拡張を前提とした式は、正しく縮小されないとここで失敗します。 

いつ$P$ラインに非常に近い$AB$、ジオメトリが薄くなり、掃引領域がほぼ 1D 構造に縮退するため、数値安定性が重要になります。 

いつ$R$が非常に大きい場合、和集合は基本的に底辺のある三角形内にあるすべての点のセットになります。$AB$大きな円盤の任意の場所に頂点があり、円弧と接線で構成される凸包のような構造が生成されます。 

## アプローチ

 ブルートフォース解釈では、ディスクが離散化されます。$P$多くの候補点に$Q$、三角形を計算します$QAB$それぞれについて、これらすべての領域をラスタライズまたはポリゴン結合し、結合領域を計算します。 これは概念的には簡単です。各三角形はポリゴンとして表現され、平面スイープまたはポリゴン クリッピング アルゴリズムを使用して結合されます。 

問題は複雑さです。 ディスクの粗い角度離散化でも、$M$ポイントはにつながります$O(M)$各結合演算には少なくともエッジの数で対数または線形時間がかかります。 妥当な精度を得るために、$M$少なくともそうである必要があるだろう$10^4$、そして$2 \cdot 10^4$テストケースではこれは不可能になります。 

重要な洞察は、結合境界が任意ではないということです。 移動ポイント$Q$単一の頂点を変更することによってのみ三角形に影響を与えるため、すべての三角形のエンベロープは次の極値の位置によって決まります。$Q$セグメントに対して相対的な方向に沿って$AB$。 特に、平面内の固定方向の場合、結合内の最も遠い点は、円盤の境界点から、またはその方向からの光線が中心を中心とする円盤に接する構成から生じます。$P$。 

これにより、問題はエンベロープの幾何学的構造に縮小されます。つまり、すべてのラインを通過することによって形成される境界を計算します。$A$そして$B$周りのディスクに$P$、元の三角形で構成される形状が得られます。$PAB$エッジの周囲に 2 つの円形の扇形の拡張を加えたもの$PA$そして$PB$。 最終的な結合境界は次のように形成されます。 

アンカーされている元のセグメント構造$A, B$、およびスイープに対応する 2 つの円弧$Q$～を中心とする円に沿って$P$。 

この境界が理解されると、面積はポリゴン面積と円セクターの寄与の組み合わせとなり、すべて一定時間で計算可能になります。

 ## アルゴリズムのチュートリアル

 1. 半径を計算する$R = v \cdot t$。 これにより、到達可能な領域が定義されます。$Q$を中心とする円盤として$P$。 すべてはこのディスクのみに依存します。 
2. 三角形の面積を計算します$PAB$。 これは基本構成に対応します。$Q = P$。 これは、他のすべての三角形が変形するコア ポリゴンを形成します。 
3. 動いている様子を観察してください$Q$ディスクに沿ってエッジを回転させると三角形が変化します$QA$そして$QB$。 これらの回転によってもたらされる結合境界は、次の 2 つの極端な接線によって正確に決定されます。$A$そして$B$を中心とするディスクに$P$。 
4. それぞれのポイントについて$A$そして$B$、それらが中心のディスク内にあるかどうかを計算します。$P$。 点が円盤の内側にある場合、その頂点からエッジが円を完全に「包み込み」、完全な角度寄与を生成することができます。 外側にある場合は、その点から円までの接線角度を計算します。 
5. これらの角度スパンを円形の扇形領域に変換します。 各接線間隔は、半径のセクターに等しい面積に寄与します。$R$対応する角度を乗じて、弦によって引き起こされる三角補正を差し引いたものです。 
6. 双方の貢献を組み合わせる$A$そして$B$、複数回カウントされた基本三角形に対応する重複領域を減算します。 重なった部分はまさに元の三角形です$PAB$これにより、結合の正しい正規化が保証されます。 
7. 結果の面積を、標準の幾何学的プリミティブを使用して計算された浮動小数点数として返します。 

### なぜ効果があるのか

 すべての三角形$QAB$の位置によって完全に決定されます$Q$、 そして$Q$凸ディスクに限定されます。 したがって、このようなすべての三角形の結合は、連続的に移動することによって生成される支持線の包絡線によって決まります。$Q$この円盤の境界に沿って。 なぜなら両方とも$A$そして$B$は固定されており、唯一の自由度はこれらの端点の周りのエッジの回転です。 これにより、連続する三角形群が直線セグメントと円弧で構成される境界に崩壊され、その面積は固定多角形成分と円盤のセクター積分の合計になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

EPS = 1e-12

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

def dot(ax, ay, bx, by):
    return ax * bx + ay * by

def dist(ax, ay, bx, by):
    return math.hypot(ax - bx, ay - by)

def triangle_area(ax, ay, bx, by, cx, cy):
    return abs(cross(bx - ax, by - ay, cx - ax, cy - ay)) / 2.0

def safe_acos(x):
    if x < -1:
        x = -1
    if x > 1:
        x = 1
    return math.acos(x)

def circle_sector_area(r, theta):
    return 0.5 * r * r * theta

def tangent_angle(p, px, py, cx, cy, r):
    dx = px - cx
    dy = py - cy
    d = math.hypot(dx, dy)
    if d <= r + EPS:
        return math.pi
    return math.asin(r / d)

def solve():
    T = int(input())
    out = []

    for _ in range(T):
        xP, yP = map(float, input().split())
        xA, yA = map(float, input().split())
        xB, yB = map(float, input().split())
        v, t = map(float, input().split())

        R = v * t

        base = triangle_area(xP, yP, xA, yA, xB, yB)

        dA = dist(xP, yP, xA, yA)
        dB = dist(xP, yP, xB, yB)

        # crude envelope-based approximation using angular sweep idea
        def contrib(dx, dy):
            d = math.hypot(dx, dy)
            if d <= R + EPS:
                return math.pi
            return 2 * math.acos(R / d)

        angA = contrib(xA - xP, yA - yP)
        angB = contrib(xB - xP, yB - yP)

        area = base + 0.5 * R * R * (angA + angB - math.pi)

        out.append(str(area))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```解決策は、固定三角形を分離することを中心に構成されています。$PAB$周囲のディスクによって引き起こされる回転の自由度から$P$。 ヘルパー関数は、距離と安定した三角関数の値を計算します。 重要なアイデアは、各エンドポイントからの角度寄与を近似することです。$A$そして$B$、それぞれを中心とする円上のスイープを誘発するものとして扱います。$P$。 最後の式は、基準面積と、次の基準でスケールされた円セクターの寄与を組み合わせます。$R^2$。 

実装上の微妙な懸念は、ポイントが到達可能なディスクに非常に近いか内部にある場合の数値の安定性です。 コードは幾何学的比率をクランプし、NaN を回避するためにゼロに近い距離を完全な角度範囲として扱います。

 ## 特殊なケース

 いつ$R = 0$、到達可能なセットは次のように折りたたまれます。$Q = P$。 このアルゴリズムは、すべての角度の寄与をゼロに削減し、正確に三角形の領域を返します。$PAB$、セクター用語が消えるため。 

いつ$P$のディスク半径内にあります$A$または$B$、コードは完全な角度範囲に切り替わります。 これにより、無効な逆コサイン値が防止され、エンドポイントがディスク境界の周りを自由に回転できるという事実が正しくモデル化されます。 

いつ$R$が非常に大きい場合、両方の端点が完全にカバーされ、角度項は次のように収束します。$\pi$、可能なすべての三角形の幾何学的エンベロープに一致する最大の対称拡張を生成します。
