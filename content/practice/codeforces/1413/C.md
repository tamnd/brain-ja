 ## 解決策
 ## 問題の理解

 この問題では、使用される最大のフレットから使用される最小のフレットを引いた値が最小になるように、一連の音符を 6 つの弦を持つギターにマッピングするように求められます。 各文字列には基本値があり、インデックスでフレットが付けられます。`j`追加します`j`弦のベースに。 メモ`b_i`どの弦でも演奏できる`a_k`に限って`b_i ≥ a_k + 1`ですので、必要なフレットは`b_i - a_k`。 目標は、使用されるフレットの範囲ができるだけ小さくなるように、各音をどの弦で演奏するかを選択することです。 

入力には、文字列のベースを表す 6 つの整数があり、その後に音符の数が続きます。`n`そして音符の並び。 制約により許可される`n`まで`10^5`ストリングベースとノートまで`10^9`つまり、O(n log n) の解決策は実行可能ですが、O(n * 6) または O(n^2) のブルートフォースでは遅すぎることになります。 エッジケースには、すべてのノートが等しい場合、すべての弦のベースが等しい場合、および 1 つのノートが優勢な場合が含まれます。そのため、常に最小限のフレットの弦を選択するような単純なアプローチでは、次善の結果が生じる可能性があります。 

## アプローチ

 強引なアプローチでは、各ノートについて 6 つの可能性をすべて考慮し、フレット割り当てのすべての組み合わせを生成し、範囲を計算します。 これは正しいですが、6^n 通りの可能性があり、指数関数的に実行不可能です。 

重要な洞察は、各音符について、各弦のフレット インデックスが小さな範囲を形成していることを観察することです。 可能なすべてを事前計算できます`(fret_index, note_index)`ペアを作成し、フレット インデックスで並べ替えます。 問題は、各音符に少なくとも 1 つのフレット割り当てを含む最小間隔を見つけることになります。 これは、「k リストの要素をカバーする最小範囲」問題に似ています。 マルチセットまたは優先キューを使用すると、ソートされたフレット インデックス上でウィンドウをスライドさせ、ウィンドウ内に含まれる最大の音を追跡し、最大フレットと最小フレットの差を最小限に抑えることができます。 これにより、各音符が 6 つのエントリを生成するため、指数関数的探索は O(n log n) で解決できる問題に変換されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(6^n) | O(n) | 遅すぎる |
 | ソートされたペア + スライディング ウィンドウ | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 6 つの文字列ベースを配列に読み取ります。`a`そしてメモを配列に入れる`b`。 
2. 各音符について`b_i`、フレットインデックスを計算します`b_i - a_j`各文字列ごとに`j`、ペアを形成します`(fret, i)`すべてをリストに保存します。 
3. このペアのリストをフレット インデックスで並べ替えます。 
4. 2 つのポインターを使用したスライディング ウィンドウ アプローチを使用します。 count 配列を維持する`cnt[i]`現在のウィンドウ内のノートに属するフレット インデックスの数を追跡する`i`。 追跡`total`現在ウィンドウに表示されているユニークなメモ。 
5. すべてのノートがカバーされるまで右ポインタを展開します (`total == n`）。 
6. すべての音符をカバーしたまま、左ポインタをできるだけ収縮させます。 
7. 現在のウィンドウの最大フレットと最小フレットの間の最小の差を記録します。 
8. 右ポインタが並べ替えられたリストの最後に到達するまで続けます。 記録された最小の差が答えです。 

これが機能するのは、リストがフレットによってソートされているためです。そのため、右ポインタを拡大すると最大フレットが増加し、左ポインタを縮小すると最小フレットが減少する可能性があります。 カバレッジを追跡することで、すべてのノートが少なくとも 1 フレットに割り当てられていることを確認します。 不変条件は、現在のウィンドウに各音符に対して少なくとも 1 つのフレット割り当てが常に含まれており、考慮された最小範囲が実行可能であることを保証することです。 

## Python ソリューション```python
import sys
import heapq
from collections import defaultdict
input = sys.stdin.readline

def solve():
    a = list(map(int, input().split()))
    n = int(input())
    b = list(map(int, input().split()))

    frets = []
    for i in range(n):
        for j in range(6):
            fret = b[i] - a[j]
            frets.append((fret, i))
    frets.sort()
    
    count = [0] * n
    unique = 0
    ans = float('inf')
    l = 0
    
    for r in range(len(frets)):
        fret, idx = frets[r]
        if count[idx] == 0:
            unique += 1
        count[idx] += 1
        
        while unique == n:
            ans = min(ans, frets[r][0] - frets[l][0])
            left_fret, left_idx = frets[l]
            count[left_idx] -= 1
            if count[left_idx] == 0:
                unique -= 1
            l += 1
    
    print(ans)

if __name__ == "__main__":
    solve()
```このコードは、考えられるすべてのフレット位置を計算して並べ替え、2 ポインター アプローチを使用してすべての音符をカバーする最小限のウィンドウを維持します。 同じ音符を生成する複数のフレットや大きな音符値などのエッジ条件は、ソートとスライディング ウィンドウによって自動的に処理されます。 

## 実用的な例

 **サンプル 1:**```
a = [1, 4, 100, 10, 30, 5]
b = [101, 104, 105, 110, 130, 200]
```すべての音は、フレット インデックスが 100 の弦で演奏でき、最大フレットと最小フレットが等しいため、差 = 0 になります。 

**引き違い窓のトレース:**

 | l | r | フレット[l] | フレット[r] | ユニーク | 現在の差分 | 答え |
 | --- | --- | --- | --- | --- | --- | --- |
 | 0 | 0 | 101-1=100 | ... | 1 | - | インフ |
 | ... | ... | ... | ... | 6 | 0 | 0 |

 これにより、最適な割り当てが存在することが確認されます。 

**サンプル 2:**```
a = [1,1,2,2,3,3]
b = [4,11,11,12,12,13,13]
```最初の音を弦 1 に割り当て、残りを弦 6 に割り当てると、最大フレットは 10、最小値は 3、差は 7 になります。

 ## 特殊なケース

 すべての弦のベースが等しい場合、各音符には 0..5 だけ異なる 6 つの可能なフレットがあります。 アルゴリズムは、すべてのノートをカバーする最小ウィンドウを正確に見つけます。 大きく離れたノートの場合、ソートによりスライディング ウィンドウが最小範囲を確実に捕捉します。 同じフレットの 1 つの弦ですべて演奏できる音の場合、最小の差は 0 であり、2 ポインター ウィンドウによって正しく計算されます。
