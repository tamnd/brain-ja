 ## 問題の理解

 1 から 2 までの数字を数えるように求められます。$n$正確に 2 つの異なる素因数を持ちます。 たとえば、6 は次のように因数分解できるため、ほぼ素数です。$2 \cdot 3$、2と3は両方とも素数です。 4 や 8 のような数字は、単一の素数のべき乗であるため、ほとんど素数ではありません。 入力は単一の整数です$n$最大 3000、出力は最大 3000 までのほぼ素数の数を表す単一の整数です。$n$。 

3000 という上限は小さいです。 までの各数値を調べるアルゴリズムさえも$n$ここで実行可能なすべての可能な約数をチェックします。 ただし、素因数分解を注意深くチェックする必要があります。素数性をチェックせずに単に約数や倍数を数えるだけでは、誤った結果が生成されてしまうからです。 

考慮すべきエッジケースは次のとおりです$n = 1$。 1 以下のほぼ素数は存在しないため、正しい出力は 0 です。もう 1 つの微妙なケースは、4、8、または 9 のような素数の繰り返しの積である数値です。個別の素数を追跡せずに因数をカウントする単純なアプローチでは、それらが誤ってほぼ素数であるとみなされる可能性があります。 たとえば、9 は$3^2$したがって、合計因数が 2 つであっても、異なる素因数は 1 つだけです。 

## アプローチ

 最も簡単なアプローチは、1 から 2 までのすべての数値を反復処理することです。$n$、各数値を因数分解し、因数分解で個別の素数を数えます。 数値を因数分解するには$x$、2 から まで繰り返すことができます。$x$そして割り算を確認します。 各約数について、それが素数であるかどうか、およびそれが割り算であるかどうかをテストします。$x$。 この強引なアプローチは正しいですが、各約数の素数性をテストして個別の素因数を数えるのは非効率的です。 最悪の場合、$n = 3000$、これにはおおよその内容が含まれます$\sum_{i=2}^{3000} i \approx 4.5 \cdot 10^6$繰り返し。 これは制限時間内であれば機能しますが、洗練されていないため、簡素化することができます。 

重要な洞察は、各数値を完全に因数分解する必要がないということです。 までのすべての素数を事前計算できます。$n$エラトステネスの篩を使って。 すると、それぞれの数字に対して、$x$、以下の素数を反復できます。$x$割る数を数えてください$x$。 正確に 2 つの異なる素数が除算する場合$x$、結果カウンターをインクリメントします。 ふるいを使用すると、素数チェックの繰り返しが回避され、因子のカウントが簡素化されます。

 ## アルゴリズムのチュートリアル

 1. まず、次の値までのすべての素数を生成します。$n$エラトステネスの篩を使って。 これにより、どの数値が素数であるかを効率的に知ることができ、それらの数値が割り切れるかどうかだけをチェックすることができます。 ふるいはすべての数値を反復処理し、倍数を非素数としてマークします。 
2. カウンタを 0 に初期化します。これにより、1 と 2 の間の数値がいくつあるかが追跡されます。$n$ほぼプライムです。 
3. 各整数を反復処理します。$x$2から$n$。 それぞれについて$x$、個別の素因数のローカルカウントを初期化します。 
4. 各素数について$p$以下$x$、どうかを確認してください$p$分割する$x$。 存在する場合は、個別の素因数カウンターをインクリメントします。 
5. いずれかの時点でカウンタが 2 を超えた場合は、内側のループを中断します。 正確に 2 つの異なる素約数を持つ数値のみを考慮するため、続行する必要はありません。 
6. すべての素数を確認した後、$x$、カウンタが 2 に等しい場合、全体のほぼ素数のカウンタをインクリメントします。 
7. すべての数値を繰り返した後、カウンターを出力します。 

なぜ機能するのか: ふるいは、以下の素数をすべて知っていることを保証します。$n$。 各素数で割り切れる可能性を数えることで、約数の合計だけでなく、異なる素因数を数えることができます。 カウントが 2 を超えたら早めに休憩することで、無駄な作業を防ぐことができます。 範囲内のすべての数値をチェックすることにより、ほぼすべての素数が正確に計算されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

# Sieve of Eratosthenes
is_prime = [True] * (n + 1)
is_prime[0] = is_prime[1] = False
for i in range(2, int(n**0.5) + 1):
    if is_prime[i]:
        for j in range(i*i, n + 1, i):
            is_prime[j] = False

primes = [i for i, val in enumerate(is_prime) if val]

almost_prime_count = 0

for x in range(2, n + 1):
    prime_factors = 0
    for p in primes:
        if p > x:
            break
        if x % p == 0:
            prime_factors += 1
        if prime_factors > 2:
            break
    if prime_factors == 2:
        almost_prime_count += 1

print(almost_prime_count)
```ふるいの構築では、以下の素数が事前計算されます。$n$、可分性チェックが有効であることを確認します。 すべての数値ではなく素数を反復処理することで、素数以外の誤ったカウントを回避できます。 2 つ以上の素因数が見つかった場合に早期に中断すると、不必要な計算が削減されます。 このソリューションは、2 から開始することで下限を正しく処理します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    for i in range(2, int(n**0.5) + 1):
        if is_prime[i]:
            for j in range(i*i, n + 1, i):
                is_prime[j] = False
    primes = [i for i, val in enumerate(is_prime) if val]
    count = 0
    for x in range(2, n + 1):
        pf = 0
        for p in primes:
            if p > x:
                break
            if x % p == 0:
                pf += 1
            if pf > 2:
                break
        if pf == 2:
            count += 1
    return str(count)

assert run("2") == "0", "only one prime, no almost prime"

assert run("30") == "7", "medium input"
