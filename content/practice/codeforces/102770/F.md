 ## 解決策
 ## 問題の理解

 入力は 2 つのバイナリ分類子を記述します。 各分類器は N 次元のサンプル ベクトルを取得し、その座標の重み付けされた合計を計算し、その値をバイアスによってシフトします。 この最終的な数値の符号が分類子の答えになります。 2 つの分類子がゼロの反対側になる 1 つのサンプル ベクトルを構築する必要があります。 必要な 2 つの答えの積は厳密に負である必要があるため、値 0 では十分ではありません。 

特徴の数は 200 に達する可能性がありますが、テスト ケースの数は最大 10 です。これにより、可能なサンプルを列挙したり、座標範囲のサイズに依存したりするアプローチが除外されます。 座標は実数であるため、有用な操作は検索ではなく代数変換と線形解決です。 係数は小さな整数です。これは、慎重に作成された答えが必要な出力制限内に収まることも意味します。 

いくつかのケースでは、2 つのパーセプトロンが代数的に異なるかどうかのみをチェックする実装が壊れる可能性があります。 両方のパーセプトロンが常にゼロを出力する場合、条件を満たしません。 例えば：```
1
1
0 0
0 0
```正しい出力は次のとおりです。```
No
```なぜなら、すべてのサンプルは出力 0 と 0 を返し、その積は負ではないからです。 

もう 1 つの罠は、重みベクトルが異なると常に解が存在することを意味すると仮定することです。 重みが同じでも、バイアスによって分類器が分離されている場合、解決策が存在する可能性があります。 例えば：```
1
1
1 0
1 -1
```x = 1 を選択すると、分類子の値は 1 と 0 になりますが、これはまだ無効です。 x = 2 を選択すると、値 2 と 1 が与えられますが、これも無効です。 2 つの分類子は常に等しいため、答えは次のようになります。```
No
```パラメータを比較するだけの不注意な実装では、誤った結論に達する可能性があります。 

逆の状況も現れます。 バイアスが十分に異なる場合、重みが同じでも反対の結果が生じる可能性があります。 例えば：```
1
1
1 0
1 2
```x = -1 を選択すると、値は -1 と 1 になるため、答えは存在します。 アルゴリズムは、係数だけでなく実際の線形関数について推論する必要があります。 

## アプローチ

 直接的なアプローチでは、サンプル座標の値を推測し、両方のパーセプトロンを評価しようとします。 すべての座標は実数であるため、有限の検索空間はありません。 検索をグリッドに制限した場合でも、膨大な数の候補が必要となり、グリッド ポイント間の有効な回答を見逃してしまいます。 

有益な観察は、符号を適用する前の各パーセプトロン出力がアフィン関数であるということです。 個々の座標ではなく、結果として得られる 2 つの値のみを考慮します。 サンプルベクトルは２次元平面上の点（f1(x)、f2(x)）に変換される。 最初の値が正で 2 番目の値が負である象限、またはその反対の象限に入るには、この点が必要です。 

2 つの重みベクトルが独立している場合、これら 2 つの値を独立して制御できます。 2 つの独立した行はランク 2 を与えるため、パーセプトロン値の任意のペアを解決するためにその寄与を使用できる 2 つの座標が存在します。 値 1 と -1 を直接リクエストできます。 

重みベクトルのランクが 1 の場合、両方の重み付き合計は 1 つの変数に依存します。 問題は、2 つの 1 次元線形関数が反対の符号を持つ値 t を見つけることになります。 符号が変化するのは根元だけなので、その根が作る間隔を確認するだけで十分です。 

ランクが 0 の場合、両方の分類子は定数であり、構築するものは何もありません。

 ## アルゴリズムのチュートリアル

 1. 2 つのパーセプトロンを読み取り、それらの重みベクトルをバイアスから分離します。 
2. 2 つの重みベクトルに 2 つの独立した座標があるかどうかを確認します。 対応する 2 行 2 列の行列の行列式が 0 以外である 2 つのインデックス i と j を見つけます。 存在する場合は、他のすべての座標をゼロに設定し、パーセプトロン値を強制的に 1 と -1 にする 2 つの方程式を解きます。 2 つの重みベクトルは 2 次元出力空間全体に及ぶため、これら 2 つの座標で十分です。 
3. ランクが 0 の場合、両方の重みベクトルは 0 になります。 答えは 2 つのバイアスで決まります。 一方のバイアスが正で、もう一方のバイアスが負の場合、ゼロ座標を出力します。 それ以外の場合は「いいえ」を出力します。 
4. ランクが 1 の場合、ゼロ以外の重みベクトル u を選択します。 すべての加重和は u dot x の倍数であるため、t = u dot x を導入します。 2 つの分類子の値は a_t+b1 と c_t+b2 になります。 いずれかの式がゼロになる根を計算し、これらの根の周囲の区間をテストします。 
5. ランク 1 のケースで有効な t が見つかった場合、最大の絶対値を持つ u の座標にすべての寄与を配置することによってサンプル ベクトルを作成します。 その座標を t/u[i] に設定すると、出力される値を小さく保ちながら u dot x = t が得られます。 

なぜ効果があるのか:

 このアルゴリズムが機能するのは、パーセプトロン値のペアがサンプル ベクトルからの線形マップによって完全に決定されるためです。 ランク 2 では、マップは (1,-1) を含む出力平面内のすべての点に到達できます。 ランク 1 では、到達可能な点が線を形成し、一次関数の符号はゼロでのみ変更できます。 ゼロ間のすべての間隔をテストすることで、考えられるすべての符号パターンがカバーされます。 ランク 0 では出力が変化しないため、定数を確認するだけで十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(n, a, b):
    w1, b1 = a[:n], a[n]
    w2, b2 = b[:n], b[n]

    nz1 = any(x != 0 for x in w1)
    nz2 = any(x != 0 for x in w2)

    if not nz1 and not nz2:
        if b1 > 0 and b2 < 0 or b1 < 0 and b2 > 0:
            return " ".join(["0"] * n)
        return "No"

    if nz1 and nz2:
        p = -1
        q = -1
        for i in range(n):
            for j in range(i + 1, n):
                det = w1[i] * w2[j] - w1[j] * w2[i]
                if det != 0:
                    p, q = i, j
                    break
            if p != -1:
                break
        if p != -1:
            det = w1[p] * w2[q] - w1[q] * w2[p]
            r1 = 1 - b1
            r2 = -1 - b2
            x = [0.0] * n
            x[p] = (r1 * w2[q] - w1[q] * r2) / det
            x[q] = (w1[p] * r2 - r1 * w2[p]) / det
            return " ".join("{:.10f}".format(v) for v in x)

    if nz1:
        u = w1[:]
        c = None
        for i in range(n):
            if u[i] != 0:
                c = w2[i] / u[i]
                break
    else:
        u = w2[:]
        c = None
        for i in range(n):
            if u[i] != 0:
                c = w1[i] / u[i]
                break
        b1, b2 = b2, b1
        c, _ = 1 / c, None

    roots = []
    if abs(c) > 1e-15:
        roots.append(-b2 / c)
    roots.append(-b1)

    roots = sorted(set(roots))
    candidates = [0.0]
    if roots:
        candidates.append(roots[0] - 1)
        for i in range(len(roots) - 1):
            candidates.append((roots[i] + roots[i + 1]) / 2)
        candidates.append(roots[-1] + 1)

    for t in candidates:
        v1 = b1 + t
        v2 = b2 + c * t
        if v1 * v2 < 0:
            idx = max(range(n), key=lambda i: abs(u[i]))
            x = [0.0] * n
            x[idx] = t / u[idx]
            return " ".join("{:.10f}".format(v) for v in x)

    return "No"

def main():
    t = int(input())
    ans = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        ans.append(solve_case(n, a, b))
    print("\n".join(ans))

if __name__ == "__main__":
    main()
```このコードは、サンプルが出力に影響を及ぼさない唯一のケースであるため、最初にゼロランクの状況を処理します。 ランク 2 の検索では、ゼロ以外の行列式が検索されます。これは、まさに 2 つの座標が 2 つの分類子の値を独立して制御できる条件です。 

ランク 1 セクションでは、単一のパラメーター t を使用して問題を書き直します。 選択されたベクトル u は重みの非ゼロ方向であるため、考えられるすべてのサンプルは到達可能な t に対応します。 サインが変化するのは根だけなので、その周囲の間隔を確認すれば十分です。 

t を座標に変換し直すとき、実装では u の最大の係数が使用されます。 これにより、出力される座標の大きさが減り、結果が許容範囲内に保たれます。

 ## 特殊なケース

 すべてゼロの場合は、線形代数の前に処理されます。 入力の場合:```
1
1
0 0
0 0
```アルゴリズムは、どちらの重みベクトルもその出力を変更できないことを確認します。 両方のバイアスがゼロであるため、正と負のペアは存在せず、「No」と出力されます。 

ランク 1 のケースは、間違った解決策が失敗する主な場所です。 考慮する：```
1
1
1 0
2 0
```このアルゴリズムは問題を t に縮小します。 値は t と 2t です。 唯一の根は t = 0 であり、両方の区間の符号は一致します。 有効な間隔が存在しないため、正しく「いいえ」と報告されます。 

独立した重みのケースは、検索の代わりに 2 つの方程式を解くことによって処理されます。 例えば：```
1
2
1 0 0
0 1 0
```行列式はゼロ以外であるため、アルゴリズムは最初の出力と 2 番目の出力を別々に強制できます。 ターゲット値を 1 および -1 に設定すると、有効なサンプルがすぐに得られます。
