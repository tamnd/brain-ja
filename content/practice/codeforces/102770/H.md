 ## 解決策
 # 問題の理解

 空は、星である点と雲である線分の集合によって表されます。 X 軸上の点は、DreamGrid が立つことができる場所です。 その時点から、星は視点と星を結ぶ直線が雲に触れない場合にのみ見えます。 

タスクは、目に見える星自体を見つけることではなく、すべての星が隠れている x 軸位置の合計の長さを見つけることです。 言い換えれば、各星は x 軸上にいくつかのブロック化された間隔を作成し、それらのブロック化されたセットの交差が必要になります。 

星と雲の数は両方とも 500 に達する場合がありますが、大きなケースはまれです。 大きな入力が得られるケースはほとんどないため、二次アルゴリズムまたはわずかに高次のアルゴリズムが実用的です。 X 軸は連続であるため、考えられるすべての視点を試す解決策は不可能です。 雲の配置によってあらゆる位置が隠される可能性があるため、答えは無限になる可能性もあり、アルゴリズムは無制限の間隔をサポートする必要があります。 

いくつかの幾何学的詳細により、単純なソリューションが失敗します。 雲が星に触れると、その星はどこにいても見えなくなります。 例えば：```
1 1
0 3
-1 3 1 3
```出力は次のとおりです。```
-1
```雲と光線の交差のみをチェックする不注意な実装では、すべての光線が星自体を通過することを見逃す可能性があります。 

2 番目の罠は、星の高さを越える雲です。 このような雲の投影は、必ずしも通常の有限間隔であるとは限りません。 例えば：```
1 1
0 3
1 2 1 4
```ブロックされた位置は両方向に無限に広がります。 2 つのクラウド エンドポイントを個別に扱うと、この動作が見逃される可能性があります。 

もう 1 つのエッジ ケースは、支持線が星を通過するものの、セグメントに星が含まれない雲です。 ブロックされた視点のセットの長さはゼロであるため、答えには影響しません。 雲の線までの距離でやみくもに割る方法では、分母がゼロになる可能性があります。 

## アプローチ

 直接的なアプローチは、星を選択し、すべての雲を考慮し、その星に対して雲がブロックする視点を計算することです。 これをすべての星に対して実行した後、すべてのブロックされたセットを交差させることができました。 最終的な影はまさに個々の影の交差点であるため、これはすでに正しい一般的な構造です。 

難しいのは、1 つの雲の遮断された間隔を見つけることです。 X 軸は無限で連続しているため、多くの X 座標に対するブルートフォース幾何学的検索は機能しません。 サンプリング ポイントでは、任意の小さな間隔も欠落する可能性があります。 

有益な観察は、視点が星からの光線の方向によって決定されるということです。 雲を直接投影する代わりに、星から見たときに雲が占める角度間隔を調べることができます。 その角度間隔内のあらゆる方向が雲に当たります。 X 軸は下方向に正確に対応します。 有効な角度範囲を x 座標に変換し直すと、ブロックされた間隔が得られます。 

ブルートフォースアプローチは同じ幾何学的な作業を行いますが、連続したラインを検索しようとします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 連続的な X 軸では不可能 | お(1) | 遅すぎる |
 | 角度間隔スイープ | O(nm + nK) ここで、K は生成された間隔の合計です | O(K) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての星について、雲のセグメントにその星が含まれているかどうかを確認します。 これが起こった場合は、星を永久に不可視としてマークし、実際の線全体をそのブロックされた間隔として使用します。 
2. 残りのすべてのクラウドについて、星から両方のクラウド エンドポイントまでの方向を計算します。 これらの方向の間のより小さい角度間隔が、星から雲に当たる可能性のある一連の光線になります。 間隔が角度の境界を越える場合は、使いやすい表現に分割します。 
3. 最終的には下向きの光線のみが X 軸に到達するため、雲の角度間隔を下向きの半平面と交差させます。 次の関係を使用して、残りの角度間隔を x 軸間隔に変換します。$$x = x_s - y_s \cdot \cot(\theta)$$どこ$(x_s,y_s)$は星の位置であり、$\theta$光線角度です。 

1. この星に対して生成されたすべての間隔を結合します。 これにより、この星がブロックされている視点の完全なセットが生成されます。 
2. すべてのスターのマージされたブロックされた間隔リストを交差させます。 残りの間隔は、まさに星が見えない位置です。 
3. 最終的な間隔の長さを加算します。 全長が無限大またはそれを超える場合$10^9$、印刷`-1`。 

それが機能する理由: 恒星の場合、考えられるすべての遮られた視点は、少なくとも 1 つの雲に接触するその星からの光線に対応します。 このような光線のセットは、まさに雲によって作成された角度間隔の結合です。 これらの方向を x 軸に一致する光線に制限し、それらを座標に変換し直すと、その星のブロックされた位置が正確に得られます。 視点が影になるのは、そこにすべての星がブロックされている場合に限られます。そのため、すべての星のブロックされたセットを交差させると、必要な答えが得られます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

PI = math.pi
TWOPI = 2 * PI
EPS = 1e-12
INF = float("inf")

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

def on_segment(px, py, ax, ay, bx, by):
    if abs(cross(bx - ax, by - ay, px - ax, py - ay)) > EPS:
        return False
    return min(ax, bx) - EPS <= px <= max(ax, bx) + EPS and min(ay, by) - EPS <= py <= max(ay, by) + EPS

def angle_to_x(sx, sy, a):
    if abs(math.sin(a)) < EPS:
        if a <= PI + EPS:
            return -INF
        return INF
    return sx - sy * math.cos(a) / math.sin(a)

def star_intervals(sx, sy, clouds):
    ans = []

    for ax, ay, bx, by in clouds:
        if on_segment(sx, sy, ax, ay, bx, by):
            return [(-INF, INF)]

    for ax, ay, bx, by in clouds:
        a1 = math.atan2(ay - sy, ax - sx) % TWOPI
        a2 = math.atan2(by - sy, bx - sx) % TWOPI

        if abs(cross(ax - sx, ay - sy, bx - sx, by - sy)) < EPS:
            continue

        if abs(a1 - a2) <= PI:
            ranges = [(min(a1, a2), max(a1, a2))]
        else:
            ranges = [(max(a1, a2), min(a1, a2) + TWOPI)]

        for l, r in ranges:
            for shift in (-TWOPI, 0, TWOPI):
                nl = max(l + shift, PI)
                nr = min(r + shift, TWOPI)
                if nr - nl > EPS:
                    x1 = angle_to_x(sx, sy, nl)
                    x2 = angle_to_x(sx, sy, nr)
                    ans.append((min(x1, x2), max(x1, x2)))

    ans.sort()
    merged = []
    for l, r in ans:
        if not merged or l > merged[-1][1] + EPS:
            merged.append([l, r])
        else:
            merged[-1][1] = max(merged[-1][1], r)
    return [(x[0], x[1]) for x in merged]

def intersect_lists(a, b):
    res = []
    i = j = 0
    while i < len(a) and j < len(b):
        l = max(a[i][0], b[j][0])
        r = min(a[i][1], b[j][1])
        if r - l > EPS or (math.isinf(l) and math.isinf(r)):
            res.append((l, r))
        if a[i][1] < b[j][1]:
            i += 1
        else:
            j += 1
    return res

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n, m = map(int, input().split())
        stars = [tuple(map(int, input().split())) for _ in range(n)]
        clouds = [tuple(map(int, input().split())) for _ in range(m)]

        shadow = [(-INF, INF)]

        for sx, sy in stars:
            cur = star_intervals(sx, sy, clouds)
            shadow = intersect_lists(shadow, cur)
            if not shadow:
                break

        total = 0.0
        for l, r in shadow:
            if math.isinf(l) or math.isinf(r):
                total = INF
                break
            total += r - l

        if total > 1e9 or math.isinf(total):
            out.append("-1")
        else:
            out.append("{:.10f}".format(total))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装では、まず、雲に星が含まれているという特殊なケースを処理します。 星自体では方向が定義されていないため、これは角度計算の前に行う必要があります。 

角度表現により、X 軸のスキャンが回避されます。 機能`angle_to_x`下向きの光線から x 軸に達する位置まで逆マッピングを実行します。 無限の場合は光線が水平になるときに発生します。そのため、関数はこれらの境界で符号付き無限大を返します。 

同一線上にある雲セグメントは、星が含まれていない限りスキップされます。 このようなセグメントは単一の視点方向のみをブロックし、x 軸上の長さがゼロであり、答えには寄与しません。 

区間交差ルーチンが機能するのは、すべての星が結合後に互いに素な区間の結合に寄与するためです。 最後の交差は増分的に維持されるため、メモリ使用量は少ないままです。 

## 実用的な例

 最初のサンプルケースの場合:```
1 2
0 3
-2 1 -1 1
2 1 1 1
```単一の星は 2 つのブロックされた間隔を生成します。 

| スター | クラウド | 角度の結果 | X 間隔 |
 | --- | --- | --- | --- |
 | (0,3) | (-2,1)-(-1,1) | 左側 | [-3、-1.5] |
 | (0,3) | (2,1)-(1,1) | 右側 | [1.5,3] |

 マージされたブロックセットは次のとおりです。`[-3,-1.5] ∪ [1.5,3]`、全長は`3`。 

2 番目のサンプルの場合:```
1 2
0 3
-2 1 -1 1
1 2 2 1
```| スター | クラウド | 角度の結果 | X 間隔 |
 | --- | --- | --- | --- |
 | (0,3) | (-2,1)-(-1,1) | 左側 | [-3、-1.5] |
 | (0,3) | (1,2)-(2,1) | 対角線 | [0.75,1.5] |

 2 つの間隔は次のように接触します。`1.5`、したがって、それらは 1 つの長さのシャドウ間隔にマージされます。`4.5`? いいえ、重複しません。 目に見えるギャップは残り、最終的な影の長さは 2 つの間隔の長さの合計になります。`1.5`。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(nm log m) | すべての星はすべての雲をチェックし、生成された間隔を並べ替えます。 
| スペース | O(m) | 最大の間隔リストは 1 つの星に属します。 

最大でも有用なケースには 500 個の星と 500 個の雲しかないため、幾何学的作業は管理可能です。 大規模なテストを制限する保証により、合計実行時間を実用的な範囲内に保ちます。

 ## 特殊なケース

 雲に星が含まれている場合、アルゴリズムはその星の実線全体を即座に返します。 最後の交差点では、すべての星がどこでもブロックされている場合、答えは無限のままです。 これは次のようなケースを処理します。```
1 1
0 3
-1 3 1 3
```出力あり:```
-1
```雲が星の高さを越える場合、エンドポイントのみの投影は信頼できません。 角度間隔法は、セグメントに当たる可能性のあるすべての光線を記述するため、引き続き機能します。 水平方向の制限光線は無限の X 値になるため、最終的な間隔表現は正しいままになります。 

星を含まない同一直線上にある雲の場合、外積チェックによりそれらが削除されます。 このような雲は 1 つの光線方向のみに対応するため、X 軸上の最大 1 点の可視性が変化します。 この問題では全長が求められるため、その寄与はゼロで無視できます。
