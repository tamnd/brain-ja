 ## 解決策
 ## 問題の理解

 最初の洗濯段階の後、すべての靴下の色が正確に 2 回表示されますが、同じ色の 2 つの靴下が異なるペアに配置される場合があります。 元の各ペアを 2 つの色のつながりとして見ることができます。 色が入ったペア`a`そして`b`頂点間のエッジになります`a`そして`b`グラフで。 

すべての色は正確に 2 つの靴下に表示されるため、すべての頂点の次数は正確に 2 になります。 したがって、グラフは独立したサイクルで構成されます。 同じ色の靴下は特殊なケースです。これは、自己ループで表される長さ 1 のサイクルです。 

魔法の盆地は、そのコレクション内のすべての色が偶数回出現する場合にのみ、ペアのコレクションを受け入れます。 グラフの用語では、選択されたエッジはすべての頂点に均等な次数を与える必要があります。 このようなコレクションはオイラー部分グラフです。 

タスクは、盆地の可能な限り最小の容量を見つけることです。容量とは、1 回の魔法の操作で使用される元のペアの最大数を意味します。 

到達できるペア数$10^5$。 可能なエッジ選択の数が指数関数的に増加するため、多くの可能なサブセットを試したり、任意のグループ化をシミュレートしたりするアルゴリズムはすぐに不可能になります。 可能なすべてのグループ化についてグラフ全体を繰り返しスキャンするアルゴリズムであっても、コストが高すぎます。 各ペアが一定の回数だけ処理されるように、グラフの構造を使用する必要があります。 

難しいのは、サイクルをより小さな有効なグループに分割できないことを認識することです。 たとえば、次の 3 つのエッジがあるサイクルの場合:```
1 2
2 3
3 1
```答えがあります`3`。 これらのエッジのうち 2 つだけを使用しようとすると、そのうちの 1 つの色のカウントが奇数になるため、盆地は失敗します。 

もう 1 つのエッジ ケースは自己ループです。 入力```
1
1
1 1
```答えがあります`1`。 不注意なグラフの実装では、自己ループが 2 つの異なる頂点を接続していないため無視される可能性がありますが、同じ色のペアはすでにそれ自体で有効なグループを形成しています。 

さらに、複数のサイクルが独立して存在する場合もあります。 例えば：```
1
4
1 2
2 1
3 4
4 3
```答えがあります`2`。 2 つの平行エッジ サイクルはそれぞれ個別に処理できます。 グラフ全体を 1 つのサイクルとして扱うと、誤って返されます。`4`。 

## アプローチ

 直接的な総当たりアプローチでは、すべての色が偶数回出現するペアのグループを見つけようとします。 エッジの可能なサブセットを生成し、すべての色が偶数回出現するかどうかを確認し、最大のサブセット サイズを最小化するパーティションを検索します。 これは、洗面器のあらゆる使用方法を検討しているため、正しいです。 ただし、すべてのサブセットをチェックする場合でも、すでに$2^n$可能性。 と$n=10^5$、これは実装で処理できる範囲をはるかに超えています。 

グラフ表現から有益な観察が得られます。 すべての頂点には次数 2 があるため、すべての連結成分はサイクルになります。 サイクルには特別な特性があります。つまり、そのエッジから作成される空でないオイラー部分グラフはサイクル全体だけです。 サイクルから 1 つのエッジでも削除すると、その削除されたエッジの 2 つの端点がパスの端点になり、それらの頂点は選択したエッジ内で奇数次数になります。 

これは、すべてのサイクルを全体として 1 つのマジック操作に配置する必要があることを意味します。 2 つのサイクルを結合すると、その操作に必要な容量が増加するだけであるため、サイクルを結合してもメリットはありません。 したがって、可能な最小の容量は、グラフ内の最大サイクルのサイズになります。 

最適な解決策は、単純にすべての接続コンポーネントを見つけて、コンポーネント内の最大数のエッジを記録することです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 靴下のペアからグラフを作成します。 各色は頂点であり、各ペアが 1 つのエッジに寄与します。 同じ色のペアはすでに完全なサイクルであるため、自己ループは通常のエッジとして保存されます。 
2. 深さ優先検索を使用して、未訪問の色をすべてスキャンします。 走査中に、その接続コンポーネントに属するエッジの数を数えます。 グラフはサイクルのみで構成されているため、この数は、一緒に配置する必要があるペアの数と正確に一致します。 
3. すべての走査中に検出された最大コンポーネント エッジ数を維持します。 その値は、可能な最小の盆地容量です。 
4. コンポーネントの最大サイズを出力します。 

なぜ効果があるのか:

 すべての頂点には次数 2 があるため、すべての連結成分はサイクルになります。 エッジを削除すると奇数次数の頂点が作成されるため、サイクルをより小さな有効なマジック操作に分割することはできません。 したがって、すべてのコンポーネントは、そのエッジの数に等しい避けられない下限に寄与します。 各コンポーネントを個別に処理するとその制限が達成されるため、最大のコンポーネント サイズが必要かつ十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        graph = {}

        for _ in range(n):
            a, b = map(int, input().split())
            if a not in graph:
                graph[a] = []
            if b not in graph:
                graph[b] = []
            graph[a].append(b)
            graph[b].append(a)

        visited = set()
        best = 0

        for start in graph:
            if start in visited:
                continue

            stack = [start]
            visited.add(start)
            vertices = 0

            while stack:
                u = stack.pop()
                vertices += 1
                for v in graph[u]:
                    if v not in visited:
                        visited.add(v)
                        stack.append(v)

            best = max(best, vertices)

        ans.append(str(best))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```グラフは隣接リストとして保存されます。 エッジを追加すると、自己ループの場合も含めて両方向にエッジが追加されます。 自己ループの場合、同じ頂点は 2 つのエントリを受け取ります。これはまさにその次数の寄与です。 

深さ優先検索では、連結コンポーネント内の頂点がカウントされます。 このグラフ ファミリでは、すべてのコンポーネントがサイクルであるため、頂点の数はエッジの数と等しくなります。 また、自己ループ コンポーネントには 1 つの頂点と 1 つのエッジが含まれるため、このコンポーネントも正しく処理されます。 

トラバースでは、頂点がスタックにプッシュされるとすぐに頂点をマークします。 これにより、同じサイクルに複数回アクセスすることが回避され、合計作業量が線形に保たれます。
