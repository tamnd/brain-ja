 ## 解決策
 ## 問題の理解

 2 つの整数のコレクションが与えられています。 通常の数値で積を比較するのではなく、最小の素数から順に素数指数ベクトルを見て比較します。 2 の指数が最初に決定され、3 の指数は 2 の累乗が等しい場合にのみ考慮され、次に 5 の指数が考慮されます。 

最初のコレクションの 1 つの要素と 2 番目のコレクションの 1 つの要素で構成されるペアごとに、それらの製品が形成されます。 タスクは、この特別注文を使用してこれらの製品をすべて並べ替えた後、位置 k に表示される製品を見つけることです。 

主な制約は、両方のコレクションに 100000 個の値を含めることができ、すべてのテスト ケースの合計サイズも 100000 であることです。1 つのケースに 10^10 の値が存在する可能性があるため、すべての積を生成することは不可能です。 それらを保存するだけでもすでにコストがかかりすぎるため、ソリューションでは個々のペアに触れるのを避け、入力値を少数回のみ処理する必要があります。 

いくつかのケースでは、誤って対処されやすいものがあります。 すべてのペアが 1 つの要素に寄与するため、重複する製品は個別にカウントする必要があります。 たとえば、入力の場合```
1 2 1
2
2 3
```製品は`[4, 6]`、したがって、答えは次のとおりです`4`。 重複を削除するソリューションでは、リストに 2 つの異なる値しか含まれていないと誤って認識され、間違った位置が返される可能性があります。 

もう 1 つの微妙なケースは、通常の整数の並べ替えが必要な順序とは無関係であることです。 例えば、```
1 2 1
6
5
```製品しか持っていない`30`、ただし、次のようなより大きな例を比較すると、`14`そして`15`違いを示しています。 順序付けでは、数値の大きさではなく、小さな素数のべき乗が最初にチェックされます。 

## アプローチ

 直接的なアプローチは、すべての製品を作成することです`a[i] * b[j]`、カスタム比較を使用して結果の配列を並べ替え、k 番目の要素を取得します。 これは、文字通り要求されたリストを構築するため、正しいです。 ただし、商品数は`n * m`、到達できる`10^10`。 それらを書き出すことさえ不可能であり、分類するには使用できる時間をはるかに超える時間がかかります。 

重要な観察は、比較自体の定義から得られます。 最初に重要なことは、最小の素数の指数 (2) です。小さい方の指数 2 を持つすべての積は、大きい方の指数 2 を持つ積より前に表示されます。指数 2 を修正した後、残りの比較は、因数 2 を削除して次の素数を考慮したまったく同じ問題です。 

これは、問題を再帰的に解決できることを意味します。 現在の値に現れる最小の素数の指数によって数値をグループ化します。 積は、2 つの指数の合計が特定の値になるグループに属します。 どの指数グループに k 番目の積が含まれているかを見つけた後、選択した数値からその素数べき乗を削除し、残りの因数について同じ問題を解きます。 

各ステップで数値から少なくとも 1 つの素因数が削除されるため、再帰は短くなります。 数値は最大でも 10^6 であるため、可能な因子除去ステップはわずかしかありません。

 | 再帰的な素数グループ化 | O((n + m) * 素因数の数) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. いずれかのコレクションの現在の値を割る最小の素数を見つけます。 これより小さい素数はどこでも指数 0 を持つため、順序付けに影響を与えることはできません。 
2. この素数の指数に従って、両方のコレクションをグループに分割します。 たとえば、素数 2 を処理する場合、値`8`、`12`、 そして`18`それぞれの指数は 3、2、1 です。 
3. 考えられる各合計指数に属する積の数を数えます。 一方が指数に寄与する場合`x`もう一方は指数に寄与します`y`、すべてのペアには指数があります`x + y`。 
4. k 番目の積を含む指数グループを見つけます。 前のグループのサイズを k から減算します。これらの積はすでに完全に小さいことが決定されているためです。 
5. 両方のグループから選択した素数べき乗を削除し、残りの因数について同じ問題を再帰的に解きます。 
6. 再帰的な答えに、選択した素数を選択した指数で乗算します。 これにより、現在の再帰レベルで修正された積の部分が復元されます。 

なぜ効果があるのか:

 すべての再帰レベルで、すべての積は、異なる可能性がある最初の素数指数によって分割されます。 これはまさにステートメントの比較ルールです。 正しい指数グループが選択されると、そのグループ内のすべての積は現在の素数と同じ値を持つため、残りの素数指数のみが順序を決定できます。 再帰呼び出しは、残りの比較を正確に処理します。 すべてのレベルで次の素数指数が永続的に固定されるため、最終的に再構築された数値は正しい k 番目の積になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXV = 10**6

spf = list(range(MAXV + 1))
for i in range(2, int(MAXV ** 0.5) + 1):
    if spf[i] == i:
        for j in range(i * i, MAXV + 1, i):
            if spf[j] == j:
                spf[j] = i

def divide_by_prime(x, p):
    c = 0
    while x % p == 0:
        x //= p
        c += 1
    return c, x

def solve_recursive(a, b, k):
    prime = 10**9
    for x in a:
        if x > 1 and spf[x] < prime:
            prime = spf[x]
    for x in b:
        if x > 1 and spf[x] < prime:
            prime = spf[x]

    if prime == 10**9:
        return 1

    ga = {}
    gb = {}

    for x in a:
        c, y = divide_by_prime(x, prime)
        if c not in ga:
            ga[c] = []
        ga[c].append(y)

    for x in b:
        c, y = divide_by_prime(x, prime)
        if c not in gb:
            gb[c] = []
        gb[c].append(y)

    counts = {}
    for x, va in ga.items():
        for y, vb in gb.items():
            counts[x + y] = counts.get(x + y, 0) + len(va) * len(vb)

    chosen = None
    for e in sorted(counts):
        if k > counts[e]:
            k -= counts[e]
        else:
            chosen = e
            break

    na = ga.get(chosen, [])
    nb = gb.get(chosen, [])

    return (prime ** chosen) * solve_recursive(na, nb, k)

def main():
    t = int(input())
    ans = []

    for _ in range(t):
        n, m, k = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        ans.append(str(solve_recursive(a, b, k)))

    print("\n".join(ans))

if __name__ == "__main__":
    main()
```ふるいは、10^6 までのすべての値の最小の素因数を計算します。 これにより、次に関連する素数を見つけて素数累乗を迅速に削除できるようになります。 

再帰関数は製品を作成しません。 2 つの入力リストの残りの因子のみを保存します。 辞書`ga`そして`gb`グループを現在の素数指数で表します。 の`counts`辞書は、考えられるすべての指数和に属するペア積の数を表します。 

選択ループでは、1 つのベースのインデックスを使用します。`k`。 完全な指数ブロックがスキップされると、そのサイズが減算されます。 答えを含むブロックが見つかると、残りのブロックが`k`は、そのブロック内の正確な位置です。 

Python の整数はオーバーフローしないため、可能な最大の積が約 10^12 であっても、最終積を再構築するのは安全です。

 ## 特殊なケース

 素因数を削除してすべての数値が 1 になると、再帰は直ちに停止します。 これは、残りのすべての積が同じ素数指数を持つ状況に対応するため、残りの部分の答えは単純に 1 になります。 

重複した製品の場合、アルゴリズムは一意の値を保存しません。 グループ サイズはグループの長さの乗算を使用して計算されるため、すべてのペアがカウントされたままになります。 たとえば、次の 2 つのコピー`2`片面と2枚のコピー`3`もう一方では、次の 4 つの製品を提供します`6`。 

次のような大きな素数を含む値の場合、`999983`、アルゴリズムは、より小さな素数ごとに反復処理を行いません。 ふるいから最小の素因数を直接取得し、不必要な再帰レベルを回避します。 

通常の数値順序が必要な順序と異なる積の場合でも、アルゴリズムは指数階層に従います。 完全な製品を直接比較することは決してないので、通常の整数順序を誤って使用することはできません。
