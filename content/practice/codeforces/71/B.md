 ## 解決策
 ## 問題の理解

 グラフィカルな進行状況バーを正方形の配列として構築するように求められます。各正方形には彩度の値があります。 バーには合計があります`n`正方形、最大彩度は`k`。 プロセスの完了は次のように測定されます。`t`パーセントであり、正方形の彩度を使用してそのパーセントを視覚的に反映する必要があります。 

ルールは次のとおりです。 

- 最初のいくつかの正方形は完全に飽和しています (`k`)、完了した部分を表します。 
- 最後の数マスは空です (`0`)、未完了の部分を表します。 
- パーセンテージと正確に一致させるために、最大 1 つの正方形を部分的に塗りつぶすことができます。`t`。 

入力は 3 つの整数で構成されます。`n`、`k`、 そして`t`、すべて [0, 100] の範囲内`t`および [1, 100]`n`そして`k`。 出力は次の配列です。`n`各正方形の彩度を表す整数。 

なぜなら`n`そして`k`両方とも最大 100 であれば、単純な算術と反復で O(n) 解を得ることができます。 パフォーマンスに関する懸念はありません。 制約により直接シミュレーションが可能になります。 

明らかではないエッジケースが発生する場合`t`0 または 100、または部分的に塗りつぶされた正方形の小数部分がちょうど 0 または`k`。 たとえば、次の場合`t = 0`、すべての正方形は 0 でなければなりません。`t = 100`、すべての正方形は次のようになります。`k`。 不注意な解決策では、このような場合でも「部分平方」を計算しようとする可能性があり、その結果、off-by-one エラーが発生します。 

## アプローチ

 ブルートフォース手法では、各正方形を反復処理し、パーセンテージに従ってその正方形に必要な正確な彩度を計算し、配列を埋めます。 これは問題を分割として扱うことができるので機能します。`t`全体の彩度全体のパーセント`n`しかし、1 つの正方形しか部分的に埋めることができない場合、不必要な小数演算と複雑さが発生します。 

重要な洞察は、問題が線形であることに気づくことです。各正方形は正確に寄与します。`k`潜在的に 1 つの部分的な正方形を除く、彩度の単位。 合計の「飽和単位」は次のように計算できます。`(t / 100) * (n * k)`。 次に、完全に塗りつぶされた正方形の数は、この値を整数で割ったものになります。`k`、部分的に塗りつぶされた正方形が残りであり、残りの正方形は空です。 これにより、分数を繰り返したり複雑な比較を実行したりすることなく、O(n) で答えを構築することができます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n) | O(n) | 受け入れられるが冗長 |
 | 最適 | O(n) | O(n) | 受け入れられ、明確かつ簡潔 |

 ## アルゴリズムのチュートリアル

 1. 必要な飽和の合計単位を計算します。`t`完了率:`total_saturation = (t * n * k) // 100`整数除算が機能するのは、彩度が整数でなければならず、小数部分は自然に部分的に塗りつぶされた正方形になるためです。 
2. 完全に塗りつぶされた正方形の数を除算して決定します。`total_saturation`による`k`:`full_squares = total_saturation // k`これにより、最初のそれぞれの`full_squares`正方形は最大限に飽和しています。 
3. 部分的に塗りつぶされた正方形の残りの彩度を計算します。`partial_saturation = total_saturation % k`これがゼロの場合、部分正方形は存在しません。 ゼロ以外の場合、完全な正方形の後の次の正方形がこの値を取得します。 
4. 長さの配列を初期化する`n`ゼロ付き。 
5.最初の項目を入力します`full_squares`と`k`。 
6. もし`partial_saturation`がゼロでない場合は、次の正方形に割り当てます。 
7. 配列の残りの部分はゼロのままです。 

機能する理由: アルゴリズムは、彩度値の合計が一致するという不変式を維持します。`(t / 100) * (n * k)`。 完全な 1 の後の各正方形は部分的に満たされているかゼロであり、部分的な正方形が 1 つだけ存在するため、出力は常に問題の条件を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k, t = map(int, input().split())

# Total saturation units
total_saturation = (t * n * k) // 100

# Number of fully filled squares
full_squares = total_saturation // k

# Remaining saturation for the partial square
partial_saturation = total_saturation % k

# Initialize the progress bar
progress = [0] * n

# Fill full squares
for i in range(full_squares):
    progress[i] = k

# Fill partial square if it exists
if full_squares < n:
    progress[full_squares] = partial_saturation

print(' '.join(map(str, progress)))
```コードはまず、合計彩度をユニット単位で計算します。これは、次のスケーリングされた整数バージョンです。`t%`。 で割る`k`完全に塗りつぶされた正方形を部分的な正方形から分離します。 配列をゼロで初期化すると、塗りつぶされていない正方形がすでに正しいことが保証されます。 の`if`条件によりインデックスエラーが回避される`t = 100`。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, k, t = map(int, input().split())
    total_saturation = (t * n * k) // 100
    full_squares = total_saturation // k
    partial_saturation = total_saturation % k
    progress = [0] * n
    for i in range(full_squares):
        progress[i] = k
    if full_squares < n:
        progress[full_squares] = partial_saturation
    return ' '.join(map(str, progress))

# Provided samples
assert run("10 10 54\n") == "10 10 10 10 10 4 0 0 0 0"
# Custom cases
assert run("5 20 0\n") == "0 0 0 0 0", "zero progress"
assert run("5 20 100\n") == "20 20 20 20 20", "full progress"
assert run("4 5 37\n") == "5 5 3 0", "partial square rounding"
assert run("1 1 50\n") == "0", "single square half progress"
assert run("3 10 33\n") == "10 0 0", "fractional rounding down"
```| テスト入力 | 期待される出力 | 検証内容 |

 ## 特殊なケース

 いつ`t=0`、総彩度はゼロです。 アルゴリズムは計算します`full_squares=0`そして`partial_saturation=0`。 完全な正方形のループは何も行わず、部分的な正方形の条件はスキップされます。`full_squares < n`それは本当ですが、`partial_saturation`がゼロの場合、配列はそのままになります`[0, 0, ...]`、まさにその通りです。 

いつ`t=100`、`total_saturation = n*k`、`full_squares = n`、`partial_saturation = 0`。 ループはすべての正方形を次のように塗りつぶします。`k`、条件チェックでは配列は変更されません。`full_squares`等しい`n`、範囲外のエラーを回避します。 

次のような小数パーセントの場合`t=37`と`n=4`そして`k=5`、総彩度は`(37*4*5)//100 = 7`。 フルスクエア`7//5=1`、 部分的`7%5=2`。 配列は次のようになります`[5,2,0,0]`、1 つの完全な正方形と 1 つの部分的な正方形を正しく反映しています。 

これにより、0、100、または部分的な彩度のエッジ ケースがすべて正しく処理されることが確認されます。
