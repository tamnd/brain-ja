 ## 解決策
 ## 問題の理解

 既知の原子番号を持つ原子のセットと、核融合を使用して生成したい原子のターゲット セットが与えられます。 各融合操作では、正確に 2 つの原子が 1 つに結合され、結果として得られる原子の原子番号は、元の 2 つの番号の合計になります。 原子を分割することはできません。 ターゲット原子を生成するには、すべての初期原子を 1 回だけ使用する必要があるため、基本的に初期セットを必要な原子番号の合計となるサブセットに分割します。 

入力は元素の記号を提供し、周期表のルックアップ テーブルを介して元素の原子番号に変換します。 小さな限界、$n \le 17$、サブセットを列挙する指数アルゴリズムが実現可能であることをすぐに示唆します。 初期原子の原子番号の合計は、ターゲット原子の原子番号の合計と等しくなります。これにより、解が存在する場合、純粋にサブセットの並べ替えと合計によってその解を表現できることが保証されます。 主な困難は、すべてのアトムが正確に 1 回使用され、各サブセットの合計がターゲット アトムに正確に一致することを保証することです。 

複数のターゲット原子が同じ値を持つ場合、微妙なエッジケースが発生します。 最初に最大の数値を割り当てる単純な貪欲なアプローチでは、間違った要素が選択され、後のサブセットが解決できないままになる可能性があります。 たとえば、最初の数値が`[1,2,3,4]`そしてターゲットは`[5,5]`、ピッキング`[4,1]`最初の5枚の葉について`[2,3]`2 つ目は機能しますが、次のような間違った選択です。`[3,2]`最初の葉`[1,4]`2番目に。 徹底的なアプローチまたは DP ベースのアプローチは、これを正しく処理します。 

## アプローチ

 ブルートフォース手法では、初期セットのすべてのパーティションが列挙されます。$k$サブセットを作成し、各サブセットの合計がターゲットになるかどうかを確認し、対応する融合演算を出力します。 分割方法の数$n$アイテムを$k$空でない集合は第 2 種スターリング数によって与えられ、大まかに言うと非常に速く増加します。$k^n$。 と$n=17$、これは次の順序です。$17^{17} \approx 10^{20}$、実行可能な計算をはるかに超えています。 全部チェックしても$2^n$サブセットを単純に複数回実行すると、すでにコストが高くなります。 

実現可能な解決策を可能にする洞察は 2 つあります。 初め、$n$は小さいため、サブセットをビットマスクとして表すことができます。 2 番目に、ビットマスクに対して動的プログラミングを使用して、原子のどのサブセットを合計すると各ターゲット原子番号が得られるかを追跡できます。 これにより、問題は次のように簡略化されます。ターゲット原子ごとに、合計がそれに一致する初期原子の重複しないサブセットを見つけます。 あるので$2^n$可能なサブセットがある場合、それらを反復処理することは可能です ($2^{17} = 131072$）。 各サブセットの合計を事前に計算し、再計算を避けるためにメモ化を使用してこれらのサブセットをターゲットに割り当てることを試みることができます。 最後に、融合シーケンスの再構築は、残りの 2 つの最大の原子を 1 つが残るまで常に融合することで貪欲に行うことができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべてのパーティション) | O(k^n) | O(k^n) | 遅すぎる |
 | ビットマスク DP + サブセットの合計 | O(k * 2^n * n) | O(2^n * n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 元素記号を原子番号に変換します。 解を再構築するために、記号と数値の両方を保存します。 
2. 初期セットの各サブセットをビットマスクとして表します。 各サブセット内の数値の合計を事前計算します。 これにより、どのサブセットが各ターゲット原子を生成できるかを迅速に検索できます。 
3. 再帰 DP を使用して、ターゲット原子へのサブセットの割り当てを試みます。 各ステップで、ターゲット原子を選択し、合計がその原子番号と一致し、ビットがまだ使用されていないすべてのサブセットを試します。 サブセットを使用済みとしてマークし、残りのターゲットを再帰的に実行します。 すべてのターゲットが一致する場合、有効な割り当てが得られます。 
4. ターゲットに一致するサブセットがない場合、または残りのターゲットを完了できない場合は、バックトラックします。 メモ化は、同じ部分問題の再計算を防ぐために、未使用のアトムのマスクとターゲット アトムのインデックスに適用できます。 
5. ターゲットへのサブセットの有効な割り当てが見つかったら、融合シーケンスを再構築します。 各サブセットについて、1 つの原子が残るまで 2 つの最大の数値を繰り返し融合します。 元の原子記号を追跡して、シーケンスを次のように出力します。`A+B+...->Target`。 
6. 「YES」と k 個の融合シーケンスを出力します。 割り当てが見つからない場合は、「NO」を出力します。 

機能する理由: DP は、すべてのターゲットが正しく合計された原子の素のサブセットを取得することを保証します。また、融合再構築では、合法的なペアワイズ融合を使用して、常に各サブセットを単一の原子に縮小します。 不変条件は、すべての初期アトムが 1 回使用され、その合計がターゲットと一致することです。

target_numbers = [periodic_table[s] for s in target_symbols]

from itertools import combinations

# precompute subset sums
subset_sum = {}
for mask in range(1, 1<<n):
    total = 0
    for i in range(n):
        if mask & (1<<i):
            total += initial_numbers[i]
    subset_sum[mask] = total

memo = {}
assignment = [0]*k

def solve(mask, idx):
    if idx == k:
        return mask == 0
    key = (mask, idx)
    if key in memo:
        return False
    t = target_numbers[idx]
    submask = mask
    while submask:
        if subset_sum[submask] == t:
            if solve(mask ^ submask, idx+1):
                assignment[idx] = submask
                return True
        submask = (submask - 1) & mask
    memo[key] = False
    return False

if not solve((1<<n)-1, 0):
    print("NO")
    sys.exit(0)

print("YES")

# reconstruct fusion sequence
for idx in range(k):
    mask = assignment[idx]
    elems = []
    for i in range(n):
        if mask & (1<<i):
            elems.append((initial_numbers[i], initial_symbols[i]))
    elems.sort(reverse=True)
    sequence = []
    while len(elems) > 1:
        a = elems.pop(0)
        b = elems.pop(0)
        elems.append((a[0]+b[0], f"{a[1]}+{b[1]}"))
        elems.sort(reverse=True)
    print(f"{elems[0][1]}->{target_symbols[idx]}")
