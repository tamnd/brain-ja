 ## 解決策
 ## 問題の理解

 いくつかの小文字の単語が与えられているので、「長すぎる」と思われる単語だけを短くする必要があります。 単語の長さが 10 を超える場合は長すぎます。 

短縮ルールは非常に具体的です。 最初の文字と最後の文字を保持し、その間のすべてを削除された文字の数に置き換えます。 例えば、`"localization"`は 12 文字なので、`'l'`そして`'n'`、それらの間には10文字があります。 結果は次のようになります`"l10n"`。 

各入力単語は独立して処理されます。 すべての単語について、変更せずに出力するか、省略形を出力します。 

制約は非常に小さいです。 単語は最大 100 個あり、各単語の長さは最大 100 です。単純な 1 文字ずつの解決策でも、簡単に制限内に収まります。 処理されるテキストの総量は少量であるため、線形時間アプローチで十分です。 

難しい部分はパフォーマンスではなく、境界条件を正しく処理することです。 

よくある間違いの 1 つは、長さがちょうど 10 の単語を省略することです。この条件では、厳密に 10 を超えることが示されています。 

入力例:```
1
abcdefghij
```正しい出力:```
abcdefghij
```を使用した不注意な実装`>= 10`誤って生成されます:```
a8j
```もう 1 つの間違いは、中間カウントを間違って計算することです。 挿入される数値は、最初の文字と最後の文字の間の文字数です。`len(word) - 2`。 

入力例:```
1
localization
```正しい出力:```
l10n
```誰かが使ったら`len(word) - 1`とすると、次のように誤って出力されてしまいます。```
l11n
```単一文字の単語もチェックする価値のある特殊なケースです。 

入力例:```
1
a
```正しい出力:```
a
```この単語は省略できるほど長くないため、変更しないでください。 最初と最後の文字は同じ文字であるため、ここでもアクセスは有効です。 

## アプローチ

 問題を解決する最も直接的な方法は、総当たりシミュレーションです。 すべての単語について、その長さをチェックします。 長さが最大 ​​10 の場合は、単語を変更せずに出力します。 それ以外の場合は、最初の文字を取得し、中間にある文字の数を計算し、最後の文字を追加することによって略語を作成します。 

制約が非常に小さいため、これはすでに効率的に機能します。 たとえすべての単語の長さが 100 だったとしても、合計で最大 10,000 文字を処理することになります。 それは事実上即時です。 

より遅い総当たり攻撃の亜種では、算術を使用する代わりに、文字通り中央の文字を 1 つずつ数えます。 たとえば、長さ 20 のワードの場合、インデックス 1 からインデックス 18 までループし、カウンターをインクリメントできます。 入力が小さいため、これでも合格しますが、不必要な作業が実行されます。 

重要な点は、削除された文字の数を手動でカウントする必要がないことです。 単語の長さがわかったら、中間の数は常に次のようになります。```
length - 2
```これにより、入力自体の読み取りを除けば、操作がワードあたりの一定時間に短縮されます。 

すべての単語が独立しているため、強引なアイデアが機能します。 単語間の相互作用、複雑なデータ構造、隠れた最適化トリックはありません。 唯一のタスクは、固定された変換ルールを一貫して適用することです。

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`、単語の数。 
2. 繰り返します`n`を繰り返し、反復ごとに 1 つの単語を読みます。 
3. 単語長を確認します。 

長さが 10 以下の場合は、長すぎるとはみなされないため、単語を変更せずに出力します。 
4. それ以外の場合は、略語を作成します。 

次を使用して最初の文字を取得します`word[0]`。 
5. 最初の文字と最後の文字の間に何文字あるかを計算します。 

この値は`len(word) - 2`最初と最後の 2 文字だけを除外しているためです。 
6. 次のコマンドを使用して最後の文字を取得します。`word[-1]`。 
7. 最初の文字、文字列に変換された中間の数、および最後の文字を連結し、結果を出力します。 

### なぜ効果があるのか

 アルゴリズムは略語の定義に直接に従います。 すべての長い単語は次のように変換されます。```
first letter + number of middle letters + last letter
```中間の文字の数は常に、全長から保存された 2 つの境界文字を差し引いたものになります。 すべての単語が独立して処理され、変換が必要な形式に正確に一致するため、アルゴリズムは常に正しい出力を生成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

for _ in range(n):
    word = input().strip()

    if len(word) <= 10:
        print(word)
    else:
        abbreviated = word[0] + str(len(word) - 2) + word[-1]
        print(abbreviated)
```プログラムは単語数を読み取ることから始まります。 次に、各単語を個別に処理します。 

の`strip()`呼び出しにより、入力から末尾の改行文字が削除されます。 これがないと、改行が文字列長の一部となり、誤った結果が生成されます。 

条件`len(word) <= 10`問題文と正確に一致します。 使用する`< 10`または`>= 10`オフバイワンバグが発生する可能性があります。 

長い単語の場合、省略形は 3 つの部分から構成されます。`word[0]`最初の文字を与えると、`len(word) - 2`スキップされた中間文字の数を示します。`word[-1]`最終的な文字を与えます。 

使用する`word[-1]`は単語の長さに関係なく常に最後の文字を参照するため便利です。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())
    out = []

    for _ in range(n):
        word = input().strip()

        if len(word) <= 10:
            out.append(word)
        else:
            out.append(word[0] + str(len(word) - 2) + word[-1])

    print("\n".join(out))

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    return sys.stdout.getvalue()

# provided sample
assert run(
"""4
word

internationalization
pneumonoultramicroscopicsilicovolcanoconiosis
"""
) == (

p43s
"""
), "sample 1"

# minimum-size input

"""1
a
"""
) == (
"""a
"""
), "single character word"

# boundary length 10 should not abbreviate
assert run(
"""2

codeforces
"""
) == (
"""abcdefghij
codeforces
"""
), "length exactly 10"

# length 11 should abbreviate
assert run(
"""1
abcdefghijk
"""
) == (
"""a9k
"""
), "length 11"

"""

 ## 特殊なケース

 長さがちょうど 10 の単語は変更されない必要があります。 

入力：```
1
abcdefghij
```アルゴリズムチェック`len(word) <= 10`。 長さがちょうど 10 であるため、条件は true となり、元の単語が出力されます。 

出力：```
abcdefghij
```これにより、変更しないはずの単語を省略するというよくある間違いを回避できます。 

非常に長い単語は中間カウントを正しく計算する必要があります。 

入力：```
1
internationalization
```長さは 20 です。アルゴリズムは次のように計算します。```
20 - 2 = 18
```次に、以下を組み合わせます。```
i + 18 + n
```出力：```
i18n
```これにより、カウントは最初の文字と最後の文字の間の文字のみを参照していることが確認されます。 

単一文字の単語も正しく機能します。 

入力：```
1
a
```長さは 1 であるため、単語は省略されません。 アルゴリズムは元の単語を直接出力します。 

出力：```
a
```この条件により不必要な省略ロジックが防止されるため、特殊なケースの処理は必要ありません。
