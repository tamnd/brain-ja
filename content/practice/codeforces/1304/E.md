 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、$n$頂点。各頂点は、任意の 2 つの頂点間に 1 つのパスが存在するように接続されます。 次に、複数の質問が行われます。 各クエリは 2 つの頂点を指定します$x$そして$y$ここでは、新しい双方向エッジと 2 つの頂点を追加することを想像しています。$a$そして$b$その間に道を見つけたいと思っています。 クエリは整数も提供します$k$からのパスが存在するかどうかを判断する必要があります。$a$に$b$それは正確に使用します$k$エッジ。 パスは頂点またはエッジを再訪する可能性がありますが、正確に横断する必要があります$k$エッジ。 

木のサイズ$n$まで可能です$10^5$まであります$10^5$クエリ。 これは、クエリごとにパスを単純に検査したり、ツリー上の歩行をシミュレートしたりするアルゴリズムは遅すぎることを意味します。クエリごとに線形スキャンを行ったとしても、$10^{10}$最悪の場合の運用。 長さ$k$までのパスが到達できます$10^9$したがって、パスを明示的に生成することは不可能です。 

明らかではない詳細は、パスがノードとエッジを再訪問できることです。これは、余分なエッジを複数回追加することによって作成されたサイクルを横断できることを意味します。 これにより、正確な長さに到達するために適切な回数サイクルを横断する限り、単純な最短パスよりも長いパスが許可されます。$k$。 間の最短経路長だけを考慮する不用意なアプローチ$a$そして$b$クエリでは失敗します。$k$より大きくなりますが、追加されたエッジをループすることで実現できます。 

もう一つの微妙なケースは次のような場合です。$a$そして$b$は同じノードです。 サイクルを横断する場合、パスの長さは依然としてゼロでない可能性があるため、長さゼロが必要であると想定することはできません。 3 つのノードを持つ小さなツリーでは、追加のエッジが追加されると、すでに複数のパスが生成される可能性があります。 

## アプローチ

 ブルート フォース アプローチでは、ツリーを構築し、クエリ エッジを追加し、BFS または DFS を実行して、そこからのすべてのパスを列挙します。$a$に$b$パスの長さに達するまで$k$。 これはすべての可能性をチェックするため正しいですが、実行不可能です。 クエリごとに、すべての最短パスだけを探索することさえ困難です。$O(n)$、そして$q = 10^5$、私たちはここにいます$10^{10}$操作。 最大の長さのパスを明示的に処理する$10^9$不可能です。 

重要な洞察は、木には任意の 2 つの頂点間に一意の単純なパスがあるということです。 1 つのエッジを追加すると、まさに 1 つの単純なサイクルが作成されます。 間の任意のパス$a$そして$b$元のツリー パスとこの単一サイクルの 0 回以上のトラバースの組み合わせとして表現できます。 これにより、問題は間の最短距離の計算に減ります。$a$そして$b$ツリー内で、$k$サイクルを利用することで実現可能です。 具体的には、最短のツリー パスが$d$、サイクルには長さがあります$c$の場合、到達可能なパスの長さは次の条件を満たす必要があります。$k \ge d$そして$(k - d) \mod 2 = 0$サイクル エッジを通過するたびに、単純なパスに 2 つのエッジが追加されるためです。$a$に$b$。 

形式的に言うと、サイクルの長さは、からの距離の合計です。$x$に$y$ツリーと追加されたエッジを通過します。 次に、クエリごとに 3 つの候補パス長をチェックします。$a$に$b$木を通って、小道を通って$a \to x \to y \to b$、およびパス$a \to y \to x \to b$。 もし$k$が少なくとも候補の長さであり、同じパリティを持っている場合、答えは YES です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(q * n) | O(n) | 遅すぎる |
 | 最適 | O(n + q) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ツリーを隣接リストとして構築します。 これにより、高速な移動と距離の計算が可能になります。 ツリーには方向がないため、エッジを両方向に保存します。 
2. 任意のルート (頂点 1) から単一の DFS または BFS を実行して、各ノードと各ノードの親の深さを事前計算します。 ルートとすべてのノードの間の距離を保存します。 これらの距離により、次の式を使用して、任意の 2 つのノード間の木の距離を一定時間で計算できます。$\text{dist}(u,v) = \text{depth}[u] + \text{depth}[v] - 2 \cdot \text{depth}[\text{lca}(u,v)]$ここで、LCA は最下位の共通祖先です。 
3. 任意の 2 つのノード間の距離を計算する関数を実装します。 LCA にバイナリ リフティングを使用すると、木の距離を取得できます。$O(\log n)$クエリごとに。 以来$n \le 10^5$、これは効率的です。 
4. 各クエリについて$(x, y, a, b, k)$、間の木の最短距離を計算します。$a$そして$b$、私たちはこれを呼んでいます$d_0$。 次に、追加のエッジを使用するパスの距離を計算します。$d_1 = \text{dist}(a,x) + 1 + \text{dist}(y,b)$そして$d_2 = \text{dist}(a,y) + 1 + \text{dist}(x,b)$。 
5. 各候補距離について$d$で$[d_0, d_1, d_2]$、どうかを確認してください$k \ge d$そして$(k - d) \mod 2 = 0$。 いずれかの候補がこれらの条件を満たす場合は、YES と出力します。 それ以外の場合は、NO を出力します。 これにより、最短パスよりも長いパスは、完全なサイクルで延長して正確に到達できる場合にのみ考慮されるようになります。$k$。 

機能する理由: 1 ツリー内のすべてのパスは、ベース ツリー パスと単一サイクルの 0 個以上の完全な走査に分解できます。 パリティ条件により、エッジの総数が正確に達することが保証されます。$k$部分走査なしで。 3 つの候補パスをすべて考慮すると、追加されたエッジを通る両方向が確実に考慮されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

n = int(input())
adj = [[] for _ in range(n + 1)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    adj[u].append(v)
    adj[v].append(u)

LOG = 17
parent = [[-1] * (n + 1) for _ in range(LOG)]
depth = [0] * (n + 1)

def dfs(u, p):
    parent[0][u] = p
    for v in adj[u]:
        if v != p:
            depth[v] = depth[u] + 1
            dfs(v, u)

dfs(1, -1)

for k in range(1, LOG):
    for v in range(1, n + 1):
        if parent[k - 1][v] != -1:
            parent[k][v] = parent[k - 1][parent[k - 1][v]]

def lca(u, v):
    if depth[u] < depth[v]:
        u, v = v, u
    for k in range(LOG - 1, -1, -1):
        if parent[k][u] != -1 and depth[parent[k][u]] >= depth[v]:
            u = parent[k][u]
    if u == v:
        return u
    for k in range(LOG - 1, -1, -1):
        if parent[k][u] != -1 and parent[k][u] != parent[k][v]:
            u = parent[k][u]
            v = parent[k][v]
    return parent[0][u]

def dist(u, v):
    return depth[u] + depth[v] - 2 * depth[lca(u, v)]

q = int(input())
for _ in range(q):
    x, y, a, b, k = map(int, input().split())
    d0 = dist(a, b)
    d1 = dist(a, x) + 1 + dist(y, b)
    d2 = dist(a, y) + 1 + dist(x, b)
    ok = False
    for d in [d0, d1, d2]:
        if k >= d and (k - d) % 2 == 0:
            ok = True
            break
    print("YES" if ok else "NO")
```DFS は、すべてのノードの深さと親の配列を事前計算します。 バイナリリフティングにより、LCA クエリが可能になります。$O(\log n)$。 距離関数は木の距離を素早く計算します。 3 つの候補パスは、最短パスと、追加されたエッジをいずれかの方向に横断する 2 つのオプションをキャプチャします。 パリティ チェックにより、正確に到達するまでのサイクルを使用してパスを拡張できることが保証されます。$k$エッジ。
