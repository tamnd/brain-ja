 ## 解決策
 # 問題の理解

 このタスクは、5 つの観測値から 4 次多項式の係数を回復することです。 5 つの観測値は、x = 1、2、3、4、および 5 で評価された多項式に対応しますが、各観測値には最大 1 つの誤差が含まれる可能性があります。 実多項式には [-100, 100] の範囲の整数係数があり、ノイズの多い観測値を生成した可能性がある一意の係数セットを出力する必要があります。 

入力には複数のテスト ケースが含まれています。 各テスト ケースでは、観測値を表す 5 つの整数が得られます。 各ケースの出力は定数係数から 4 次係数までであり、多項式 a0 + a1x + a2x² + a3x³ + a4x⁴ の a0、a1、a2、a3、および a4 を意味します。 

観測値の数が少ないことが重要な制約です。 値は 5 つしかないため、数学的自由度は非常に限られています。 一般的な 4 次関数は 5 つの正確な点によって完全に決定されますが、ここではノイズのためにすべての点が 1 単位ずつ移動する可能性があります。 したがって、可能な修正の数は十分に少ないため、検討することができます。 修正された可能性のあるすべてのデータセットを試す方法では、テスト ケースごとに数百のチェックしか実行されません。 より複雑な多項式回復方法は不要です。 

不注意に実装すると、場合によっては失敗する可能性があります。 ノイズが無視され、指定された 5 つの値が直接補間される場合、単一の破損した値によって完全に異なる 4 次が作成される可能性があります。 

例えば：```
1 4 9 16 24
```正しい出力は次のとおりです。```
0 0 1 0 0
```値は x² とほぼ一致しますが、最後の値は 25 より 1 小さいです。直接補間では、不正な測定値が真実として扱われ、別の 4 次が生成されます。 

もう 1 つのエッジ ケースは、定数項と線形項により多項式の値が高く見える場合です。 

入力：```
25 16 9 4 1
```出力は次のとおりです。```
36 -12 1 0 0
```正方形などの単純なパターンをチェックするだけのソリューションや、次数を推測しようとするソリューションは、ここで失敗する可能性があります。 多項式は依然として 2 次ですが、その係数はシフトされています。 

ノイズは一度に複数の位置に発生することもあります。 最後の値だけが間違っていると仮定するメソッドは失敗します。これは、すべての観測値が真の値と異なることが許容されるためです。 

## アプローチ

 直接的な強引なアイデアは、5 つの観測値が正確であると仮定し、多項式補間を実行することです。 5 つの点によって 4 次関数が一意に定義されるため、このアプローチはクリーン データに対して数学的に有効です。 問題は、入力値がクリーンであることが保証されていないことです。 単一のノイズのある点によって補間された多項式が変化し、間違った 4 次項と実際の 4 次項を区別する方法はありません。 

より強力なブルートフォース手法では、小さなノイズ範囲が使用されます。 各観測値は、-1、0、または +1 で補正できます。 観測値が 5 つしかないため、修正可能なシーケンスは 3⁵ = 243 通りになります。 各候補シーケンスについて、4 次を内挿し、結果の係数がすべて許容範囲内の整数であるかどうかを確認します。 この問題では、少なくとも 1 つの有効な多項式が存在することが保証されているため、最初に見つかった有効な候補が答えになります。 

重要な観察は、不確実性は多項式次数ではなく入力値にあるということです。 考えられるすべての係数を検索するのではなく、それは膨大になるでしょうが、考えられる測定誤差の小さな空間を検索します。 真の 5 つの値が見つかると、補間は簡単になります。 

補間自体は有限差分を使用して行われます。 等間隔の x 値の場合、4 次多項式は一定の 4 番目の差分を持ちます。 補正された値を使用して、多項式のニュートン形式を計算し、それを x の正規累乗に変換します。 分数演算により精度の問題が回避され、係数が本当に整数であることを確認できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 係数に対するブルートフォース | お(201⁵) | お(1) | 遅すぎる |
 | ノイズのある値の直接補間 | お(1) | お(1) | 間違っています |
 | ノイズ補正を列挙して補間する | O(3⁵) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 5 つの観測値の可能なすべての修正バージョンを生成します。 位置ごとに、-1、0、+1 を加えてみてください。 測定誤差は 1 を超えることができないため、これらはまさに考えられる真の値です。 
2. 現在の補正値の多項式を補間します。 x 座標は 1、2、3、4、5 に固定されているため、有限差分を使用して 4 次関数を構築するコンパクトな方法が得られます。 
3. 多項式をニュートン基底から正規の係数形式に変換します。 必要な出力形式は a0、a1、a2、a3、および a4 であるため、x⁰ から x⁴ までの係数が必要です。 
4. すべての係数が整数であるかどうか、およびすべての係数が [-100, 100] の範囲内にあるかどうかを確認します。 すべてのチェックに合格した場合、この多項式は元の条件をすべて満たしており、答えになります。 
5. 5 つの係数を出力し、検索を停止します。 有効な解が保証されるということは、列挙によって有効な解が見つかる必要があることを意味します。 

機能する理由: すべての有効な多項式は、ノイズの多い観測値が真の値に戻されるように調整される、正確に 1 つの修正シーケンスを生成します。 列挙ではそのシーケンスが検査されます。 補間により、これら 5 つの真の点を通過する唯一の 4 次関数が再構築されます。 係数の検証では、元の制限を満たさないすべての候補が削除されます。 有効な多項式が存在することが保証されているため、アルゴリズムは正しい係数を見つけずに終了することはできません。 

## Python ソリューション```python
import sys
from fractions import Fraction

input = sys.stdin.readline

def multiply_poly(a, b):
    res = [Fraction(0)] * (len(a) + len(b) - 1)
    for i, x in enumerate(a):
        for j, y in enumerate(b):
            res[i + j] += x * y
    return res

def add_poly(a, b):
    n = max(len(a), len(b))
    res = [Fraction(0)] * n
    for i in range(len(a)):
        res[i] += a[i]
    for i in range(len(b)):
        res[i] += b[i]
    return res

def interpolate(values):
    diff = [Fraction(x) for x in values]
    coeff = []
    while diff:
        coeff.append(diff[0])
        diff = [diff[i + 1] - diff[i] for i in range(len(diff) - 1)]

    result = [Fraction(0)]
    basis = [Fraction(1)]
    denominator = 1

    for i, c in enumerate(coeff):
        if i > 0:
            basis = multiply_poly(basis, [Fraction(-i), Fraction(1)])
            denominator *= i
        term = [x * c / denominator for x in basis]
        result = add_poly(result, term)

    return result

def solve_case(arr):
    def dfs(idx, cur):
        if idx == 5:
            poly = interpolate(cur)
            poly += [Fraction(0)] * (5 - len(poly))
            if all(x.denominator == 1 and -100 <= x <= 100 for x in poly[:5]):
                return [int(x) for x in poly[:5]]
            return None

        for delta in (-1, 0, 1):
            cur.append(arr[idx] + delta)
            ans = dfs(idx + 1, cur)
            if ans is not None:
                return ans
            cur.pop()
        return None

    return dfs(0, [])

def main():
    t = int(input())
    ans = []
    for _ in range(t):
        values = list(map(int, input().split()))
        ans.append(" ".join(map(str, solve_case(values))))
    print("\n".join(ans))

if __name__ == "__main__":
    main()
```の`multiply_poly`そして`add_poly`関数は係数形式で多項式演算を処理します。 これらの操作を分離しておくと、補間ロジックの検証が容易になります。 

の`interpolate`関数はニュートン有限差分表現を構築します。 すべての差分レイヤーの最初の値がニュートン係数になります。 基底多項式は次のように乗算されます。`(x - i)`各層の後で、点 x = 1、2、3、4、および 5 を照合します。最終的な答えは整数である必要がある場合でも、2、6、または 24 による除算などの中間値が表示されるため、分数が使用されます。 

深さ優先検索では、観測ごとに 3 つの可能な修正が試行されます。 5 つの修正値が選択されると、多項式が再構築され、チェックされます。 範囲チェックは分母が 1 であることを確認した後に行われるため、分数係数を誤って受け入れることがなくなります。 

浮動小数点演算がないため、丸め誤差によって誤った結果が生じることはありません。 Python の整数は、すべての中間算術も安全に処理します。

 ## 特殊なケース

 入力の場合:```
1 4 9 16 24
```アルゴリズムは、あらゆる観測値の修正を調査します。 候補シーケンスに到達すると、次のようになります。```
1 4 9 16 25
```有限差分は x² の有限差分になり、復元される係数は次のようになります。```
0 0 1 0 0
```間違った直接内挿アプローチでは、24 が真の値として保持され、別の 4 次が返されます。 

入力の場合:```
25 16 9 4 1
```アルゴリズムは、多項式が x² に似ている必要があるとは想定していません。 5 つの修正された点から多項式を再構築し、次を取得します。```
36 -12 1 0 0
```これは、x² - 12x + 36 を表します。これは、シフト二次関数が自然に処理されることを示しています。 

次のように、いくつかの値にノイズがある入力の場合:```
2 3 8 15 24
```検索では、調整のあらゆる組み合わせが考慮されます。 特定の位置が破損していることに依存しません。 5 つの真の値がすべて選択されると、補間と検証によって候補が受け入れられるかどうかが決定されます。 

概念的な最小サイズのケースは、5 つの観測値がすべて同一である場合です。 アルゴリズムは引き続き同じ検索および内挿プロセスを実行し、係数が必要な範囲を満たしている場合は定数多項式を受け入れます。
