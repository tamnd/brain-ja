 ## 解決策
 ## 問題の理解

 小文字の文字列が与えられます`s`。 文字列の部分文字列は、その正確な文字シーケンスが文字列内に 1 回だけ出現する場合、固有部分文字列と呼ばれます。 タスクは、次のすべての接頭辞を調べることです。`s`そして、そのプレフィックス内の最短の固有部分文字列の長さを見つけます。 

たとえば、プレフィックスが`ababb`、部分文字列`b`は何度も出てくるので無効ですが、`ba`は 1 回だけ発生するため有効です。 このプレフィックスの答えは、`2`。 

入力には、文字列の長さと文字列自体が含まれます。 出力には、プレフィックスごとに 1 つの数値が含まれます。この数値は、そのプレフィックスに 1 回だけ出現する最短の部分文字列を表します。 

文字列の長さは次のとおりです。`10^6`。 このサイズの文字列には約`n²/2`部分文字列。 考えられるすべての部分文字列を保存してチェックするだけでも、すでに約`10^12`操作。 ソリューションでは、各文字を定数または対数回処理する必要があります。 

難しいケースは長い文字列だけではありません。 繰り返されるパターンでは、間違った解決策が失敗することがよくあります。 一意だった部分文字列は、さらに文字を追加すると一意でなくなる可能性があり、一意ではなかった部分文字列は、より長い部分文字列が一意になるため無関係になる可能性があります。 

例えば：```
1
a
```答えは次のとおりです。```
1
```唯一の部分文字列は`a`と1回出現します。 

別の例:```
4
aaaa
```答えは次のとおりです。```
1
2
3
4
```最初の文字の後に、`a`ユニークです。 2文字目以降は、`a`2回出現するので、`aa`最も短い一意の部分文字列です。 文字列が大きくなるにつれて、同じ推論が続きます。 最新のサフィックスのみをチェックするソリューションでは、以前の部分文字列が一意性を失う可能性があることを見逃してしまいます。 

最後の重要なケースは、さまざまな文字を含む文字列です。```
5
abcde
```答えは次のとおりです。```
1
1
1
1
1
```すべての文字はすでに一意であるため、長い部分文字列で置き換えることはできません。 

## アプローチ

 直接的なアプローチでは、現在のプレフィックスのすべての部分文字列が生成され、それぞれが何回出現するかをカウントし、カウント 1 で最も短いものを保持します。 これは定義に正確に従っているため、正しいです。 問題はコストです。 長さのプレフィックスの場合`n`、 がある`O(n²)`部分文字列の出現をチェックすると、別の要素が追加される可能性があります。 最悪の場合は想定をはるかに超えてしまう`n = 10^6`。 

重要な点は、部分文字列を個別に保存する必要がないということです。 接尾辞オートマトンは、同一の出現動作を持つ部分文字列をグループ化します。 各状態は部分文字列の長さの間隔を表します。 状態が 1 回出現する部分文字列に対応する場合、その間隔内のすべての長さも一意になります。 州が表す最も短い候補は次のとおりです。`link_length + 1`。 

オートマトンは、文字列を左から右にスキャンしながら構築できます。 構築中、表現された部分文字列が現在一意である状態を維持します。 キャラクターを追加すると、一部の状態が一意でなくなるため削除する必要がありますが、拡張機能によって作成された新しい状態が候補になります。 残りの候補の最小値が現在のプレフィックスの答えになります。 

これがオンラインで機能する理由は、別のオカレンスが同じ同値クラスに到達したときに、接尾辞オートマトンの状態が一意から非一意に変化するためです。 構築プロセスでは、サフィックス リンクをたどり、クローンを処理する際に、これらの変更がすでに公開されています。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n3) | O(n²) | 遅すぎる |
 | サフィックス オートマトンのメンテナンス | O(n log n) 順序付きセット | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 文字列を一度に 1 文字ずつ読み取りながら、サフィックス オートマトンを構築します。 各挿入は、現在の文字を現在のプレフィックスに追加することを表します。 
2. 新しいオートマトン状態が作成されるたびに、その最も短い表現された部分文字列長が候補構造に挿入されます。 状態は部分文字列ファミリーを表し、そのファミリーの最も短いメンバーが、答えを改善できる唯一の長さです。 
3. 出現回数が 1 つではなくなったため、挿入によって既存の状態が変更される場合は、その状態を候補構造から削除します。 複数の出現がある状態は固有部分文字列に寄与できません。 
4. 接尾辞オートマトンの構築中にクローン状態が作成された場合、クローンは表現された部分文字列間隔を分割するため、影響を受ける元の状態の候補構造を更新します。 
5. 各文字を処理した後、保存されている最小の長さが現在のプレフィックスの答えとなります。 

不変条件は、候補構造が、表現された部分文字列が現在のプレフィックス内に 1 回出現するすべてのサフィックス オートマトン状態の最も短い長さを正確に含むことです。 考えられるすべての固有部分文字列はこれらの状態のいずれかに属し、保存されているすべての候補はそれ自体が固有部分文字列になります。 したがって、最小値を取得すると、正しい最短の長さが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import heapq

def solve():
    n = int(input())
    s = input().strip()

    nxt = [dict()]
    link = [-1]
    length = [0]

    unique = [False]
    heap = []

    def add_candidate(v):
        if unique[v]:
            heapq.heappush(heap, (length[link[v]] + 1, v))

    def extend(c, last):
        cur = len(nxt)
        nxt.append({})
        length.append(length[last] + 1)
        link.append(0)
        unique.append(True)

        p = last
        while p != -1 and c not in nxt[p]:
            nxt[p][c] = cur
            p = link[p]

        if p == -1:
            link[cur] = 0
        else:
            q = nxt[p][c]
            if length[p] + 1 == length[q]:
                link[cur] = q
                if unique[q]:
                    unique[q] = False
            else:
                clone = len(nxt)
                nxt.append(nxt[q].copy())
                length.append(length[p] + 1)
                link.append(link[q])
                unique.append(unique[q])

                while p != -1 and nxt[p].get(c) == q:
                    nxt[p][c] = clone
                    p = link[p]

                link[q] = clone
                link[cur] = clone

                unique[q] = False
                unique[clone] = False

        add_candidate(cur)
        return cur

    last = 0
    for i, ch in enumerate(s):
        last = extend(ch, last)

        while heap:
            val, state = heap[0]
            if unique[state]:
                break
            heapq.heappop(heap)

        print(heap[0][0])

if __name__ == "__main__":
    solve()
```オートマトン配列には、状態ごとの遷移マップ、サフィックス リンク、および最大長が格納されます。 の`unique`配列は、状態が現在固有部分文字列を生成できるかどうかを表します。 

ヒープには考えられる答えが保存されます。 挿入後に多くの状態が無効になる可能性があるため、遅延削除が使用されます。 すべての古い値を検索してすぐに削除するのではなく、無効なエントリは最小位置に達した場合にのみ削除されます。 

表現`length[link[v]] + 1`状態によって表される最小の部分文字列長です`v`。 状態自体はさまざまな長さを表す可能性がありますが、これが現在の答えを改善できる唯一の値です。 

クローンの処理は、実装の中で最もデリケートな部分です。 クローンは部分文字列同値クラスを分割するため、以前の一意性情報を調整せずに単純にコピーすることはできません。
