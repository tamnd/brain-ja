 ## 問題の理解

 この問題では、多くの独立した質問に答えることが求められます。 各クエリでは、素数係数`P`は固定されており、値を定義します`f(i,r,P)`ペアの数として`(a,b)`モジュロ`P`次のモジュラー方程式を満たす`a^r`、`b`、 そして`b^2`。 最終的な答えは、個々の値を尋ねることではありません。`f`; の積を求めます`Y`ごとにこれらの値に引き上げられます`i`から`1`に`N`、モジュロ`10^9+7`。 

便利な最初の変換は、指数を結合することです。 以来$$\prod_{i=1}^{N}Y^{f(i,r,P)}=Y^{\sum_{i=1}^{N}f(i,r,P)},$$各クエリでは、1 つの指数、つまりすべての指数の合計を見つけるだけで済みます。`f(i,r,P)`価値観。 

到達できるクエリの数`100000`、 その間`P`に近づくことができます`10^9`。 すべての剰余をモジュロでループする解`P`、あるいはその大部分においてさえ不可能です。 の小さな算術特性のみに依存する式が必要です。`P`、`r`、 そして`N`。 制限`r <= 3`は、高価な計算を実行せずに有限体におけるべき乗について推論できるため、重要な手がかりとなります。 

方程式は$$a^r(b+b^2)^i \equiv b^i \pmod P.$$式が縮退する場合には特別な処理が必要です。 もし`b=0`、両辺がゼロなので、すべて`a`動作します。 もし`b=-1`、 それから`b+b^2=0`しかし`b^i`はゼロではないので、いいえ`a`動作します。 他のすべての値については、次のように割り算できます。$$a^r \equiv (b/(b+b^2))^i.$$なぜなら`b+b^2=b(b+1)`、これは次のようになります$$a^r \equiv (b+1)^{-i}.$$したがって、問題は、値がどのくらいの頻度で`r`体の乗法群の - 乗。 

不用意に実装すると、例外的な値が忘れられる可能性があります。 たとえば、次の場合`P=5`、`r=2`、 そして`i=1`、入力クエリには係数が含まれています`5`。 値`b=0`5 つの有効なペアが提供されます。`a`動作します。 ゼロ以外の残基だけを数えてゼロを無視すると、これら 5 つのペアが失われ、間違った指数が得られます。 

もう 1 つのよくある間違いは、誤った取り扱いです`b=-1`。 のために`P=7`、`r=3`、 そして`i=1`、選択する`b=6`与える`b+b^2=0`、 その間`b^i=6`, したがって、この値からの有効なペアはありません。 のように扱うと、`b=0`この場合、無効なソリューションが追加される可能性があります。 

## アプローチ

 直接的なアプローチは、考えられるすべてのことを繰り返すことです。`b`の数を数えます。`a`式を満たす値。 固定の場合`b`、すべてをテストできます`a`そして一致を確認します。 これは正しいです。なぜなら、次の定義を正確に調べているからです。`f`。 ただし、単一のクエリには約`P^2`これは可能なことをはるかに超えています。`P`に近いです`10^9`。 

重要な観察は、2 つの例外的な値を削除した後、`b=0`そして`b=-1`、残りすべて`b`ちょうど 1 つの非ゼロ フィールド要素に対応します`x=b+1`とは違う`1`。 解の数$$a^r=t$$乗法群内の値は、次のいずれかによってのみ決定されます。`t`のサブグループに属します`r`-番目の力。 

のために`r=1`、すべての値には 1 つのルートがあります。 のために`r=2`、ゼロ以外の値のちょうど半分は正方形です。 のために`r=3`、次の場合、すべての値が一意の立方根を持ちます。`3`分けない`P-1`、または値の 3 分の 1 が立方体であり、各立方体には 3 つのルートがあります。`3`分割する`P-1`。 

これにより、考えられるものをすべて数えることができます`b`パリティまたは割り算のみを使用した値`i`。 

のために`r=2`、 もし`i`偶数、ゼロ以外のすべて`x`正方形が得られるので、`x^i`は正方形です。 もし`i`は奇数です。の二乗値のみです`x`仕事。 

のために`r=3`、 もし`P-1`で割り切れない`3`、立方体演算は順列であるため、すべての値が機能します。 それ以外の場合、ゼロ以外の値の 3 つおきのみが立方体になります。 パターンは次のいずれかによって決まります。`i`で割り切れます`3`。

 ## アルゴリズムのチュートリアル

 1. 指数を計算する`E = sum(f(i,r,P))`製品を直接使用するのではなく、 最終的な答えは、`pow(Y, E, 1e9+7)`。 
2.ハンドル`r=1`。 ゼロ以外のすべての`b`を除外する`-1`有効な 1 つを提供します`a`、 そして`b=0`貢献する`P`有効なペア。 それぞれの値`i`したがって、 は一定です。 
3.ハンドル`r=2`。 いつもあるよ`P`からのソリューション`b=0`。 残った中では`P-2`値、いくつ数えますか`(b+1)^(-i)`は正方形です。 いつ`i`すべての値が機能することさえあります。 いつ`i`奇数の場合は、ゼロ以外の二次剰余のみが機能します。 
4.ハンドル`r=3`。 もう一度、から始めます`P`からのソリューション`b=0`。 もし`P-1`で割り切れない`3`、ゼロ以外のすべての値は立方体です。 それ以外の場合、ゼロ以外の値の 3 分の 1 だけが立方体であり、これは次の場合にのみ発生します。`i`の倍数ではありません`3`。 
5. 寄与度に、各プロパティを持つインデックスの数を掛けます。 たとえば、偶数ごとに繰り返すのではなく、`i`、偶数値がいくつ現れるかを計算します。`1..N`。 

なぜ効果があるのか:

 置換後`x=b+1`、有効な非ゼロの場合はすべて、`x^{-i}`のサブグループに属します`r`-番目の力。 循環グループでは、逆関数を取得してもサブグループのメンバーシップは変更されないため、この質問は次のことを尋ねることと同じです。`x^i`です`r`-乗。 正方形と立方体のサブグループ サイズは次のように固定されます。`gcd(r,P-1)`、上で使用した式が得られます。 可能な限りの`b`は 1 つのケースでカバーされるため、合計された指数は正確になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve_query(Y, N, r, P):
    if r == 1:
        exp = N * (2 * P - 2)
        return pow(Y, exp, MOD)

    if r == 2:
        even = N // 2
        odd = N - even

        per_even = P + 2 * (P - 2)
        per_odd = P + (P - 3)

        exp = even * per_even + odd * per_odd
        return pow(Y, exp, MOD)

    if (P - 1) % 3 != 0:
        exp = N * (2 * P - 2)
    else:
        div3 = N // 3
        other = N - div3

        per_div3 = P + 3 * (P - 2)
        per_other = P + (P - 4)

        exp = div3 * per_div3 + other * per_other

    return pow(Y, exp, MOD)

def main():
    t = int(input())
    ans = []
    for _ in range(t):
        Y, N, r, P = map(int, input().split())
        ans.append(str(solve_query(Y, N, r, P)))
    print("\n".join(ans))

if __name__ == "__main__":
    main()
```このソリューションでは、まず積を単一のべき乗剰余に変換します。 これが、コードが次のシーケンスを格納する必要がない理由です。`f(i,r,P)`価値観。 

のために`r=1`、指数はすべての場合に一定です`i`。 のために`r=2`の場合、平方プロパティは指数のパリティに応じて正確に変化するため、コードは奇数位置と偶数位置を分離します。 偶数インデックスの数`1..N`は`N//2`、残りのインデックスは奇数です。 

のために`r=3`、コードは最初にキューブ マップが全単射であるかどうかをチェックします。 もし`P-1`で割り切れない`3`、ゼロ以外の剰余はすべて立方体です。 それ以外の場合、インデックスは次のように割り切れます。`3`他のインデックスとは異なる動作をします。 

すべての算術演算は整数として保持されます。 Python は大きな中間値を安全に処理しますが、最後の指数は対数時間で実行されるべき乗剰余演算でのみ必要となります。

import sys
import io

MOD = 10**9 + 7

def solve_query(Y, N, r, P):
    if r == 1:
        return pow(Y, N * (2 * P - 2), MOD)

    if r == 2:
        even = N // 2
        odd = N - even
        return pow(Y, even * (3 * P - 4) + odd * (2 * P - 3), MOD)

    if (P - 1) % 3:
        return pow(Y, N * (2 * P - 2), MOD)

    return pow(
        Y,
        (N // 3) * (4 * P - 6) + (N - N // 3) * (2 * P - 4),

    )

    out = []
    for _ in range(t):
        Y, N, r, P = map(int, input().split())
        out.append(str(solve_query(Y, N, r, P)))
    return "\n".join(out)

 ## 特殊なケース

 のために`b=0`、アルゴリズムには修正が含まれています`P`のすべての値で有効なペア`f`。 たとえば、`P=5`、`r=2`、 そして`N=1`、この単一残基からの寄与は 5 ペアであり、式には残りの残基を数える前にそれが含まれます。 

のために`b=-1`、ペアは追加されません。 代替品`x=b+1`に該当するため、このケースは当然削除されます。`x=0`、これはカウントされる乗法グループの一部ではありません。 

いつ`P-1`で割り切れます`3`、キューブのカウントが変更されます。 たとえば、`P=7`、非ゼロ剰余の 3 分の 1 だけが立方体であり、インデックスは次で割り切れます。`3`分離しなければならないので、`x^3`は常に立方体ですが、`x`それ自体は必ずしも 1 つである必要はありません。 このアルゴリズムは、すべてのインデックスが同じように動作すると仮定するのではなく、3 の倍数を直接カウントすることでこれを処理します。 

いつ`N`は非常に大きく、から反復されます`1`に`N`不可能でしょう。 このソリューションは、偶数インデックスや 3 の倍数など、各カテゴリを満たすインデックスの数のみをカウントするため、ランタイムは独立したままになります。`N`。
