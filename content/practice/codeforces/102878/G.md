 ## 解決策
 ## 問題の理解

 ゲームは、以下を含む単一の山でプレイされます。`n`紙のボール。 Long Long 氏と Mao Mao 氏は同じ法的動きを共有していない。 Long Long には削除が許可されている一連の数字があり、Mao Mao には別のセットがあります。 ターンでは、プレーヤーは自分のセットから 1 つの数字を選択し、ちょうどその数のボールを取り除きますが、これは山に十分なボールが含まれている場合に限られます。 行動できなかったプレイヤーは負けます。 課題は、最初のプレイヤーである Long Long が最適なプレイで勝利を強制できるかどうかを判断することです。 

入力により、ボールの初期数、両方の移動セットのサイズ、および 2 つのセット自体が与えられます。 出力は、必要な形式の勝者の名前です。 問題の重要な部分は、プレイヤーが異なる動きの選択肢を持っているため、通常の公平なニム理論が直接適用できないことです。 状態は誰の番かによって異なります。 

制約は動的プログラミングにとって十分小さいものです。 パイル サイズは 5000 に達する可能性があり、各移動セットには最大 100 個の値があります。 これは、次のような解決策を意味します`n * m`、これは約 500,000 のトランジションですが、十分に高速です。 考えられるすべての試合の流れをシミュレーションすることは不可能です。なぜなら、考えられる手の順序の数は指数関数的に増加するからです。 

いくつかの特殊なケースでは、不用意な実装が失敗する可能性があります。 プレイヤーが現在の山よりも大きな動きを持っている場合、その動きは使用できません。 例えば：```
5 1
6
7
```正しい出力は次のとおりです。```
Mao Mao nb!
```ロングロングはサイズ 5 の山から 6 個のボールを取り除くことができないため、すぐに負けます。 現在のパイル サイズをチェックせずに、セット内に手が存在するかどうかだけをチェックする実装では、間違った答えが得られます。 

もう 1 つの注意が必要なケースは、プレーヤーが現在移動できるものの、結果として生じるすべての状態が対戦相手に勝利の位置を与える場合です。 例えば：```
1 1
1
1
```正しい出力は次のとおりです。```
Long Long nb!
```ロングロングは唯一のボールを取り除き、マオマオは動くことができなくなります。 アルゴリズムは、現在のプレーヤーが少なくとも 1 つの正当な手を持っているかどうかだけでなく、将来のポジションを評価する必要があります。 

3 番目の重要な状況は、2 人のプレイヤーが同じ手のセットを持っている場合に発生します。 最初のプレーヤーのアドバンテージは現在のパイル サイズに依存するため、勝者はセットを比較することによって決定されません。 例えば：```
2 1
1
1
```正しい出力は次のとおりです。```
Mao Mao nb!
```Long Long はボールを 1 つ取り除き、Mao Mao にボールを 1 つ残し、Mao Mao がそれを取り除いて勝ちます。 

## アプローチ

 直接的なアプローチは、ゲーム ツリーを再帰的に探索することです。 すべての州について、現在のプレイヤーに対してあらゆる合法的な手を試みます。 何らかの手が相手を負け状態に送った場合、現在のプレイヤーが勝ちます。 あらゆる可能なゲーム継続が考慮されているため、これは正しいです。 

問題は繰り返される状態の数です。 同じパイル サイズが、さまざまな一連の動きを通じて現れる可能性があります。 メモ化を行わないと、再帰によって同じ位置が指数関数的に何度も再訪される可能性があります。 メモ化を行ったとしても、自然状態にはプレイヤー ターンに 2 つの可能性があり、最大 5000 のパイル サイズがあるため、計算を整理するには動的プログラミングが適切な方法です。 

重要な観察は、歴史全体が無関係であるということです。 必要な情報は、残りのボールの数と誰の順番であるかだけです。 これらの状態は、パイル サイズの大きい順に計算できます。 移動するたびにパイル サイズが減少するため、すべての遷移はすでに解決された状態を指します。 

させて`winL[x]`つまり、ロングロングは、`x`ボールが来たら彼の番だ。 させて`winM[x]`つまり、猫がいるときは毛猫が勝つことができます。`x`ボールが来たら彼の番だ。 

Long Long にとって、毛毛を負けた州のままにする法的排除が存在する場合、州は勝利したことになります。`winL[x] = true`多少なら`a`満足する`a <= x`そして`winM[x-a] = false`。 

同じ考えがマオマオにも当てはまります。`winM[x] = true`多少なら`b`満足する`b <= x`そして`winL[x-b] = false`。 

基本状態は`0`ボール。 ボールがゼロのプレーヤーは移動できないため、そのプレーヤーはすぐに負けます。 これは両方を意味します`winL[0]`そして`winM[0]`は誤りです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | メモ化による O(状態の数) | DP 構造がないと遅すぎる |
 | 最適 | O(nm) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つの動的プログラミング配列を作成します。`winL[i]`Long Long が勝つかどうかを格納します`i`彼の移動前のボール、そして`winM[i]`マオマオが勝つかどうかを保存します`i`彼の移動前のボール。 ボールを持たないプレーヤーは移動できないため、どちらの値も false として開始されます。 
2. パイルサイズを次から処理します。`1`に`n`。 サイズごとに、Long Long で可能なすべての動きを試してください。 移動が現在のパイルより大きくなく、その結果の Mao Mao 状態が負けている場合は、マークを付けます。`winL[i]`本当のように。 これは、1 つの勝ち手で十分であるという通常のゲーム ルールに従います。 
3. 同じ山のサイズに対して、マオマオが利用できるすべての動きを試します。 1 つの手でロング ロングが負けた状態になった場合は、マークを付けます。`winM[i]`本当のように。 
4. すべての状態が計算されたら、チェックを入れます。`winL[n]`。 それが本当であれば、Long Long は勝利を強制することができます。 そうでなければ、マオマオは勝利を強要することができます。 

なぜ効果があるのか:

 動的計画法の不変条件は、状態を計算するとき`i`、すべての移動がパイル サイズを縮小するため、考えられるすべての次の状態がすでに計算されています。 プレイヤーが勝つためには、相手が勝利を強制できない相手の状態につながる手が少なくとも 1 つ存在する必要があります。 遷移はこれらの可能性を正確にチェックするため、すべての状態が正しく分類されます。 最初のゲームは単純に Long Long のターンなので、`n`ボール、`winL[n]`答えを出します。 

## Python ソリューション```python
import sys

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    win_l = [False] * (n + 1)
    win_m = [False] * (n + 1)

    for i in range(1, n + 1):
        for x in a:
            if x <= i and not win_m[i - x]:
                win_l[i] = True
                break

        for x in b:
            if x <= i and not win_l[i - x]:
                win_m[i] = True
                break

    if win_l[n]:
        print("Long Long nb!")
    else:
        print("Mao Mao nb!")

if __name__ == "__main__":
    solve()
```2 つの配列は、2 人の異なるプレイヤーのターンを表します。 別々の配列を維持することが必要なのは、同じパイル サイズでも、手のセットが異なるため、一方のプレイヤーが勝ち、もう一方のプレイヤーが負ける可能性があるためです。 

ループは小さな山から大きな山へと上向きに進みます。 計算するとき`win_l[i]`、すべての州`win_m[i - x]`すでに知られているので、`i - x < i`。 同じ性質が毛猫の国家にも当てはまります。 

条件`x <= i`不法な持ち出しを防ぐ境界確認です。 初期の`break`単なる最適化です。 勝ち手が見つかったら、他の手をチェックしても結果は変わりません。

 ## 特殊なケース

 Long Long に使用可能な動きがない場合、トランジションは正しく終了します。`winL[n]`間違い。 入力では:```
5 1
6
7
```Long Long の唯一の移動は 5 より大きい 6 です。アルゴリズムはそれをスキップします。`x <= i`は false であるため、州は負けたままになります。 

両方のプレイヤーが同じ手を打つ場合、アルゴリズムは対称性に基づいた仮定を行いません。 で：```
2 1
1
1
```ボールが 1 つある状態はそのターンのプレーヤーの勝ちですが、ボールが 2 つある状態は最初のプレーヤーが相手にボール 1 つの勝ち状態を与えなければならないため負けます。 

移動によって残りのボールがすべて削除される状態の場合、アルゴリズムは基本ケースを通じてそれを処理します。 プレイヤーが山全体を削除すると、相手は状態に到達します`0`、負けています。 これにより、その動きが勝利トランジションとして正しく表示されます。
