 ## 解決策
 ## 問題の理解

 私たちは本のコレクションを与えられ、それぞれの厚さは 1 または 2 単位、幅は横に何ページを占めるかを表します。 シャースはすべての本を 1 つの本棚に並べたいと考えています。 配置は 2 層になっており、一部の本は下に縦に配置され、残りの本は上に横に積み重ねられます。 制約は、横長の本の幅の合計が、その下の縦長の本の厚さの合計を超えてはいけないということです。 

課題は、すべての横向きの本を上部に収容できるようにしながら、縦向きの本の合計の厚さを最小限に抑えることです。 入力すると、本の数と各本の厚さと幅が続きます。 出力は、必要な最小垂直厚さを表す単一の整数です。 

主要な制約は管理可能です。$n$は 100 まで、厚さは 1 または 2、幅は最大 100 です。$n \times \text{width}$小規模で時間のかかるソリューション$O(n \cdot W)$は許容されますが、$W$幅の合計です。 

エッジ ケースには、すべての本が厚い (2) または薄い (1) 場合、水平方向の本の幅の合計が垂直方向の厚さと正確に等しい場合、および厚さ 1 の 2 冊の代わりに厚さ 2 の垂直方向の 1 冊の本を選択すると、垂直方向の合計の厚さが減少するシナリオが含まれます。 最も厚い本を縦に配置するだけの単純な貪欲なアプローチは、横の本の幅が不均等に分布している場合に失敗する可能性があります。 

## アプローチ

 強引なアプローチでは、書籍の可能なすべてのサブセットを垂直に配置して、そのサブセットの合計の厚さを計算し、残りの本が上に収まるかどうかを検証します。 これには反復処理が必要です$2^n$サブセット、これは完全に不可能です$n = 100$。 

重要な洞察は、本の厚さが非常に制限されており (1 または 2)、この問題はナップザック問題の変形として再構成できるということです。 厚さの合計が最小化されているが、残りのすべての水平方向の本をサポートするのに十分な大きさの本のサブセットが必要です。 水平方向の本の幅は、事実上、垂直方向の厚さでカバーする必要がある「重さ」になります。 したがって、本の合計幅は次の制限を受けるため、垂直方向の厚さと幅の合計に対する動的プログラミングは効率的に機能します。$n \times 100 = 10,000$、厚みは薄いです。 

DP 配列を定義します`dp[t]`合計の厚みを持つ垂直の本に配置できる幅の最大合計を表します。`t`。 当初は、`dp[0] = 0`そして他の人は`-inf`。 すべての本を反復処理し、厚みのある各本の DP を更新します。`th`と幅`w`、全員にとって`t`高から低まで、設定します`dp[t + th] = max(dp[t + th], dp[t] + w)`。 すべての本を処理した後、最小の`t`そのような`dp[t] >= total_width`(すべての幅の合計) が答えになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 動的プログラミング | O(n * 合計幅) | O(合計幅) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての書籍データを読み取り、幅の合計を計算します。`total_width`。 
2. DP 配列を初期化する`dp`長さの`sum(thicknesses) + 1`、で満たされています`-inf`、 を除外する`dp[0] = 0`。 
3. 各ブックを繰り返し処理します。 厚みのある本の場合`t`と幅`w`、DP アレイを厚い層から薄い層まで横断します。`T`。 アップデート`dp[T + t] = max(dp[T + t], dp[T] + w)`これにより達成可能な幅が増加する場合。 
4. すべての本が処理された後、考えられるすべての厚さの合計を反復処理します。`T`0から始まります。`T`どこ`dp[T] >= total_width`必要な最小垂直厚さです。 
5. この値を出力します。 

なぜ機能するのか: DP は次の不変条件を維持します。`dp[T]`合計厚さの垂直の本でサポートできる水平幅の最大合計です。`T`。 DP アップデートを通じてすべての組み合わせを調査するため、最小の組み合わせが保証されます。`T`すべての幅をカバーするものが見つかりました。 反復的なボトムアップ DP 構造により、見逃されるサブセットはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
books = []
total_width = 0
for _ in range(n):
    t, w = map(int, input().split())
    books.append((t, w))
    total_width += w

max_thickness = sum(t for t, _ in books)
dp = [-float('inf')] * (max_thickness + 1)
dp[0] = 0

for t, w in books:
    for T in range(max_thickness - t, -1, -1):
        if dp[T] != -float('inf'):
            dp[T + t] = max(dp[T + t], dp[T] + w)

for T in range(max_thickness + 1):
    if dp[T] >= total_width:
        print(T)
        break
```最初のセクションは入力を読み取り、計算します。`total_width`すべての本に。 次に、次のように DP 配列を設定します。`-inf`到達不可能な状態として、`0`厚さゼロの場合。 ネストされたループの更新`dp`同じ本を 2 回使用しないように、本ごとに高い値から低い値へ繰り返します。 最後に、最小値を検索します。`T`幅の要件を満たしています。
