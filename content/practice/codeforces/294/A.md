 ## 解決策
 ## 問題の理解

 私たちは一連の水平ワイヤーを与えられ、それぞれのワイヤーの上に数羽の鳥が止まっています。 ワイヤーには上から下に番号が付けられ、各ワイヤーには鳥が左から右に並んでいます。 シャースは鳥を一羽ずつ撃ちます。 特定のワイヤー上の鳥が撃たれると、その左側にあるすべての鳥が上のワイヤーに飛び上がり(上にワイヤーがない場合は消えます)、その右側にあるすべての鳥が下のワイヤーに飛び降ります(または下にワイヤーがない場合は消えます)。 撃たれた鳥自体が消滅する。 すべてのショットの後、各ワイヤー上の最終的な鳥の数を計算するように求められます。 

入力はワイヤの数を示します`n`、各ワイヤーの鳥数のリスト、ショット数`m`、各ショットのワイヤ番号とそのワイヤ上の鳥の位置。 位置は左から右に 1 から始まります。 出力は、すべてのショット後の各ワイヤー上の鳥の数です。 

制約は小さいです。`n`≤ 100、`m`≤ 100、および鳥の数 ≤ 100。これは、最悪の場合、最大 100 回の操作を実行し、各操作には長さ 100 の配列に対する数回の算術演算が含まれるため、プロセスを直接シミュレートできることを意味します。任意の O(n * m) 解が許容されます。 

ショットがワイヤ上の最初または最後の位置で発生する場合、微妙なエッジ ケースが発生します。 最初の鳥が撃たれた場合、その左側には鳥がいないため、何も飛び立ちません。 最後の鳥を撃っても、何も飛んでいきません。 同様に、上部または下部のワイヤーに鳥を撃つと、上下にワイヤーがないため、鳥が飛び去る可能性があります。 不用意に実装すると、配列の外側にインデックスを付けようとする可能性があります。 

## アプローチ

 ブルート フォース アプローチは直接シミュレーションです。ショットごとに、ショットの左右にある鳥の数を計算し、それらを適切な隣接するワイヤーに移動し、ショットされた鳥を削除します。 このアプローチは問題のサイズが小さく、単純な配列操作のみが必要なため機能します。 単純なソリューションの失敗点は通常、鳥が上部または下部のワイヤーから飛び立ったときに配列の境界を超えてインデックスを作成したり、左右の鳥をカウントするときに 1 つずつずれたりするエラーです。 

最適なアプローチは、制約によって許可されるため、この問題における総当たりアプローチと本質的に同じです。 重要な洞察は、個々の鳥の位置を追跡する必要がないということです。 各ワイヤー上の鳥の数だけが必要です。 ショットごとに、`y`は撃たれた鳥の位置、すると`y - 1`鳥が飛び立ち、`ai - y`鳥が飛び降りる。 それに応じて鳥の数の配列を更新できます。 これにより、不要なループや鳥の位置の詳細な追跡が回避され、シミュレーションが簡潔かつ効率的になります。

 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O(n * m) | O(n) | 承認済み |
 | 最適なカウントベースのシミュレーション | O(m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ワイヤの数を読み取ります`n`そしてリスト`birds`各ワイヤー上の鳥の初期数を表します。 
2. ショット数を読み取る`m`。 
3. ショットごとに、ワイヤーインデックスを読み取ります。`x`(1 ベース) と鳥の位置`y`(1 ベース)。 変換する`x`配列のインデックス付けの場合は 0 から始まります。 
4. 飛び立つ鳥の数を計算します (`left = y - 1`) と飛び降りる鳥の数 (`right = birds[x] - y`）。 
5. 上にワイヤーがある場合 (`x > 0`）、 追加`left`それに鳥たち。 下にワイヤーがある場合（`x < n - 1`）、 追加`right`それに鳥たち。 
6.セット`birds[x] = 0`撃たれた鳥と他のすべての鳥の移動を考慮するため。 
7. すべてのショットを処理した後、各ワイヤーに鳥の数を出力します。 

機能する理由: 各ショットは、現在のワイヤと最大でも隣接するワイヤにのみ影響します。 個々の鳥ではなく数を転送することで、正確な合計を維持します。 境界条件は、隣接するワイヤが存在するかどうかをチェックすることによって処理されます。 不変条件は、各ショットの後、各ワイヤー上の鳥の総数が現在の状態を正確に表すということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
birds = list(map(int, input().split()))
m = int(input())

for _ in range(m):
    x, y = map(int, input().split())
    x -= 1  # convert to 0-based index
    left = y - 1
    right = birds[x] - y
    if x > 0:
        birds[x - 1] += left
    if x < n - 1:
        birds[x + 1] += right
    birds[x] = 0

for count in birds:
    print(count)
```このソリューションはまず、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 各ショットは、配列外のインデックス付けを避けるために慎重に境界チェックを行いながら、上下に飛ぶ鳥の数を計算することによって処理されます。 のアップデート`birds`配列は明確さと効率性のためにその場で実行されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    n = int(input())
    birds = list(map(int, input().split()))
    m = int(input())
    for _ in range(m):
        x, y = map(int, input().split())
        x -= 1
        left = y - 1
        right = birds[x] - y
        if x > 0:
            birds[x - 1] += left
        if x < n - 1:
            birds[x + 1] += right
        birds[x] = 0
    for count in birds:
        print(count)
    return output.getvalue().strip()
