 ## 解決策
 # 問題の理解

 2 つの斜めの壁で作られた収納形状の中に、同じ正方形のボックスを配置したコレクションがあります。 座標系は、各ボックスを 2 つのインデックスで表します。1 つは左側の壁からレイヤーを数え、もう 1 つは右側の壁からレイヤーを数えます。 配置が安定しているため、占有位置は、別のボックスをサポートするすべてのボックスがすでに存在する階段状の形状を形成します。 

一番下のボックス、つまり両方の壁に触れているボックスが削除されます。 それが残した空の位置は穴になります。 重力により、穴は山の中を上に移動します。つまり、片側のすぐ上の箱が落ちるか、反対側のすぐ上の箱が落ちます。 箱が落ちると、穴は箱の前の位置に移動します。 穴が落ち込む可能性のあるボックスがない位置に到達すると、プロセスは停止します。 

タスクは、落下する選択肢の異なるシーケンスが何通りあるかを数えることです。 答えはモジュロで出力する必要があります$10^9+7$。 

入力には最大で次のものが含まれます$10^5$ボックス、およびすべての座標は最大でも$n$。 二次シミュレーションは不可能です。$10^{10}$最大のケースでは、すでに操作が必要になります。 各ボックスを少数回だけ処理するソリューションが必要です。これは、$O(n)$または$O(n \log n)$アプローチ。 

主なエッジケースは、最終位置を下降シーケンスと混同することから発生します。 たとえホールが同じ位置で終了したとしても、選択が異なれば、異なる歴史が生じる可能性があります。 たとえば、次のことを考えてみましょう。```
5
1 1
1 2
2 1
2 2
3 1
```正しい答えは次のとおりです。```
3
```不注意な方法では、最終的に空になる可能性のあるセルのみがカウントされる可能性があります。 ホールは次の時点で終了できます`(2,2)`または`(3,1)`、これは 2 つの最終状態を与えますが、穴が到達する可能性があるため、考えられる落下シーケンスは 3 つあります。`(2,2)`2つの異なる方法で。 

もう 1 つの例外的なケースは、単一のボックスです。```
1
1 1
```答えは次のとおりです。```
1
```選択の余地はありません。 考えられる唯一のシナリオは、ボックスが取り外されて保管室が空になることです。 

3 番目のケースはまっすぐな杭です。```
3
1 1
2 1
3 1
```答えは次のとおりです。```
1
```すべての穴の位置には、落下する可能性のあるボックスが 1 つだけ存在するため、プロセスには分岐がありません。 

# アプローチ

 直接シミュレーションでは、考えられるすべての落下シーケンスを追跡します。 削除された一番下のボックスから始めて、穴を埋めることができるすべての可能なボックスを再帰的に試します。 これは正しいです。すべての有効なシナリオは、まさにこれらの選択肢の 1 つのシーケンスであるためです。 

問題は、この再帰が何度も分岐する可能性があることです。 密集した階段状の山では、さまざまなパスが存在する可能性があり、それらを個別に探索すると膨大な時間がかかる場合があります。 異なるシーケンスによって同じ穴の位置に繰り返し到達するため、総当たり法で作業を繰り返します。 

重要な観察は、どの時点においても重要なのは、ホールの現在の位置だけであるということです。 穴が特定のボックスの位置に到達した場合、そこに到達する方法の数は、穴を生成した正確な順序とは無関係です。 これにより、すべての同等の状態をマージすることができます。 

この問題は、占有セルに対する動的プログラミングの問題になります。 セルは、下降プロセスでその下のセルからウェイの合計を受け取ります。 穴は座標を 1 つ増やすだけで移動するため、グラフにはサイクルがありません。 セルを昇順に処理できます。`x + y`。 

各セルについて、穴がそこに到達できる方法の数を保存します。 セルに次の動きが考えられない場合、それはシナリオが終了したことを表すため、その値が答えに寄与します。

 | ブルートフォース | 分岐セルの数の指数関数 | O(n) 再帰の深さ | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 隣接するボックスが存在するかどうかを確認するのに一定の時間がかかるように、すべての占有ボックス位置をセットに保存します。 移動するたびに次のいずれかが増加するため、座標は有向非巡回グラフを形成します。`x`または`y`。 
2. ボックスを大きい順に並べ替えます。`x + y`。 これにより、動的計画法に有効な順序が与えられます。なぜなら、ホールは、より小さい座標和からより大きな座標和にのみ移動できるからです。 
3. 削除された最下部の位置に到達する方法の数を設定します`(1,1)`1つに。 これは落下プロセスの開始を表します。 
4. 並べ替えられた順序ですべてのボックスにアクセスします。 現在のポジションについては`(x,y)`、現在のウェイ数を追加します。`(x+1,y)`そのボックスが存在する場合。 これは、左側のボックスが穴に落ちていることに対応します。 
5. 現在のウェイ数を追加します。`(x,y+1)`そのボックスが存在する場合。 これは右側の箱が穴に落ちた状態に相当します。 
6. すべての遷移が処理された後、直下にボックスがないすべてのボックスの値をいずれかの方向に合計します。 これらはホールが停止する位置であるため、そこで終わるすべてのパスには 1 つの有効なシナリオがあります。 

なぜ効果があるのか:

 不変条件というのは、`dp[x][y]`穴を元の空の位置から次の位置に移動させる可能性のある落下シーケンスの数に等しい`(x,y)`。 開始状態には空のシーケンスが 1 つあります。 穴がセルに到達すると、次の状態として考えられるのは、そのセルに入る可能性がある 2 つの隣接するボックスだけです。そのため、これらのセルに現在のカウントを加算すると、考えられるすべての継続が 1 回だけ計算されます。 考えられるすべてのシナリオは次からのパスであるため、`(1,1)`終端セルに対して、すべての終端状態を合計すると最終的な答えが得られます。 

# Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input())
    boxes = []
    box_set = set()

    for _ in range(n):
        x, y = map(int, input().split())
        boxes.append((x, y))
        box_set.add((x, y))

    boxes.sort(key=lambda p: p[0] + p[1])

    dp = {}

    for x, y in boxes:
        dp[(x, y)] = 0

    dp[(1, 1)] = 1

    for x, y in boxes:
        cur = dp[(x, y)]

        if (x + 1, y) in box_set:
            dp[(x + 1, y)] = (dp[(x + 1, y)] + cur) % MOD

        if (x, y + 1) in box_set:
            dp[(x, y + 1)] = (dp[(x, y + 1)] + cur) % MOD

    ans = 0

    for x, y in boxes:
        if (x + 1, y) not in box_set and (x, y + 1) not in box_set:
            ans = (ans + dp[(x, y)]) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```セット`box_set`一定時間の近隣チェックを提供します。 どの位置からでも可能な移動は 2 つだけであるため、隣接リストは必要ありません。 

ソートのステップは、暗黙的なグラフのトポロジカルな順序付けです。 落下中は常に座標が増加するため、処理は小さくなります`x + y`値は、まず、状態へのすべての受信遷移が使用前にすでに考慮されていることを保証します。 

辞書`dp`各占有位置に到達するパスの数を格納します。 Python の整数はオーバーフローしませんが、すべての更新は剰余化されます。$10^9+7$保存される値を小さく保つためです。 

最終状態チェックでは、あるポジションから可能な 2 つの動きを正確に使用します。 ボックスは、隣接するボックスがどちらも存在しない場合の停止点です。 DP の後にこれをチェックすると、移行中の特別な処理が回避されます。 

# 実用的な例

```ソートされた順序はすでに次のようになります。

 |`(1,1)`| 1 |`(2,1)`1を取得します |`(1,2)`1を取得します |

この例は、終端位置のみを合計するだけでは十分ではない理由を示しています。 複数の選択肢によって、同じ最終的な空の場所に到達することができます。

 | セル | 現在の方法 | 次のセル |
 | --- | --- | --- |

 |`(2,1)`| 1 |`(3,1)`|

# 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | 各ボックスは 1 回ソートされ、2 つの隣接チェックで処理されます。 
| スペース | O(n) | ボックスのセットと DP テーブルには、それぞれボックスごとに最大 1 つのエントリが含まれます。 

の制約$10^5$ボックスは、線形解が一般的なコンテストの制限内に容易に収まることを意味します。 このアルゴリズムは、個々の落下シナリオを調査することはなく、すべてのシナリオに共有される状態のみを調査します。 

# テストケース```python
import sys
import io

MOD = 10**9 + 7

def solution(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    try:
        data = sys.stdin.readline
        n = int(data())
        boxes = []
        box_set = set()

        for _ in range(n):
            x, y = map(int, data().split())
            boxes.append((x, y))
            box_set.add((x, y))

        boxes.sort(key=lambda p: p[0] + p[1])

        dp = {p: 0 for p in boxes}
        dp[(1, 1)] = 1

        for x, y in boxes:
            cur = dp[(x, y)]
            if (x + 1, y) in box_set:
                dp[(x + 1, y)] = (dp[(x + 1, y)] + cur) % MOD
            if (x, y + 1) in box_set:
                dp[(x, y + 1)] = (dp[(x, y + 1)] + cur) % MOD

        ans = 0
        for x, y in boxes:
            if (x + 1, y) not in box_set and (x, y + 1) not in box_set:
                ans = (ans + dp[(x, y)]) % MOD

        return str(ans) + "\n"
    finally:
        sys.stdin = old_stdin

# エッジケース

 単一ボックスの場合:```
1
1 1
```DP は一方通行で始まります。`(1,1)`。 このセルには隣接セルがないため、端末状態としてカウントされます。 答えは残っている`1`。 

複数のパスが同じ終点に到達する例の場合:```
5
1 1
1 2
2 1
2 2
3 1
```アルゴリズムは 2 つの異なる到達方法を保存します。`(2,2)`別途DP加算にて。 セルが処理されると、その値は次のようになります。`2`、 ない`1`, したがって、両方の履歴がカウントされます。 

真っ直ぐな杭の場合:```
3
1 1
2 1
3 1
```すべての状態には、出力エッジが 1 つだけあります。 DP値はそのまま`1`チェーン全体を通して、最後のセルだけが答えに寄与します。 これにより、分岐がない場合のオーバーカウントが防止されます。
