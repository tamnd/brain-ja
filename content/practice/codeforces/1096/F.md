 ## 解決策
 ## 問題の理解

 長さのシーケンスが与えられます$n$これは順列であると考えられますが、一部の位置が不明であり、 でマークされています。$-1$。 欠損値は、まさに固定エントリ内に出現しない数値であり、有効な順列を形成する配列のすべての完成の可能性は同等です。 

タスクは、一様ランダム完了における予想される反転数を計算することです。 反転はインデックスのペアです$(i, j)$と$i > j$しかし$p_i < p_j$したがって、大きな値の右側に小さな値が表示される頻度を効率的にカウントしていることになります。 

主な問題点は、未知の位置が独立したランダム値ではないことです。 これらは、残りの未使用の番号をランダムに並べたもので、欠落しているすべての位置を結合します。 これにより、各位置を独立して扱うことができなくなり、グローバルな組み合わせ論の観点から推論する必要が生じます。 

制約は次のとおりです$2 \cdot 10^5$したがって、補完を列挙したり、すべてのペアを単純に処理したりするアプローチは不可能です。 二次関数$O(n^2)$スキャンはすでに大きすぎます。$O(n \log n \cdot n)$または欠損値に対する再計算を繰り返すと失敗します。 

すべての値が欠落している場合、微妙な失敗のケースが発生します。 すると、答えは、固定で位置に依存しない一様ランダム順列の予想される反転に帰着します。 固定値が決定論的に寄与すると仮定する単純な方法では、誤って構造がゼロになったり、対称性が完全に失われたりする可能性があります。 もう 1 つの例外的なケースは、欠損値がない場合です。 その場合、答えは指定された順列の反転数と正確に一致する必要があり、確率論的な推論は完全に崩壊して決定論的な結果が得られる必要があります。 

## アプローチ

 ランダム性を無視した場合、単に次のフェンウィック木を使用して反転を計算できます。$O(n \log n)$。 すべてのペアが決定論的に寄与するため、これは固定順列の場合に機能します。 

欠損値がある場合、単純な考えはすべての補完を試行することです。 それぞれ$-1$位置には未使用の数値を指定できるため、$k$欠損値があります$k!$順列。 たとえ$k = 20$、これはすでに実行不可能になっており、ここでは$k$まで可能です$2 \cdot 10^5$。 

重要な観察は、反転期待がインデックスのペアにわたって線形であるということです。 順列全体について推論する代わりに、各ペアの確率だけが必要です。$(i, j)$、関係$p_i > p_j$ランダム完了で保持されます。 これにより、問題はすべてのペアの寄与の合計に変換されます。ここで、各ペアは、各位置が固定か自由か、およびすでに使用されている値によって引き起こされる相対制約にのみ依存して計算可能な確率を持ちます。 

ペアは 3 つのカテゴリに分類されます。 両方の値が固定されている場合、寄与は決定的です。 一方が固定され、もう一方が欠落している場合、残りの数値が固定値より小さいまたは大きい数がいくつあるかを使用して確率を計算できます。 両方が欠落している場合、対称性は、それらの位置に割り当てられた残りのすべての値の中で、それぞれの順序が同等である可能性が高いことを意味するため、反転確率は正確に次のようになります。$1/2$。 

課題は、固定欠損相互作用からの寄与を効率的に計算することです。 これには、使用可能な数値の数をしきい値未満に維持し、不明な値がどれだけ残っているかを追跡する必要があります。 

どの数値が未使用であるかを事前に計算し、それらのプレフィックス構造を維持すると、前処理後に対数または定数時間で各寄与を答えることができます。 これにより、欠落要素に関するペアごとの推論から、値のランクにわたる分布のカウントまでの問題が軽減されます。

 ## アルゴリズムのチュートリアル

 値を固定セットと欠損セットに分離し、欠損値を未使用の数値の一様ランダムな並べ替えとして扱います。 

1. すべての固定値を特定し、どの数値をマークするか$1$に$n$が欠けています。 ランククエリに効率的に答えるために、欠損値に対してソートされた構造を維持します。 
2. 固定-固定ペアからの寄与を計算します。 両方の値が既知であるため、元の位置の値に対してフェンウィック ツリーを使用して反転を直接カウントします。 
3. 固定欠損ペアの場合、未使用の欠損番号の数を維持しながら、位置を左から右に処理します。 固定値の場合$x$、以下の値より小さい残りの欠損値がいくつあるかを知る必要があります。$x$。 これは、ランダムに割り当てられた欠損値によって反転が生じる確率を決定します。$x$。 
4. 欠落-欠落ペアの場合は、何ペアかを数えるだけで済みます。$-1$ポジションが存在します。 このような各ペアは正確に寄与します$1/2$これらの位置に割り当てられた 2 つの異なる値はいずれの順序でも同様に発生する可能性があるため、予想される反転数に影響します。 
5. すべての寄与を結合し、モジュラー演算で暗黙的に正規化します。 
6. 最終結果のモジュロを返します。$998244353$、必要に応じてモジュラー逆数を使用して 2 で除算します。 

### なぜ効果があるのか

 このアルゴリズムは、反転インジケーターに適用される期待値の線形性に依存しています。 実際の割り当てはグローバルに依存しますが、インデックスの各ペアは期待に独立して寄与します。 欠損値は、固定マルチセットの一様にランダムな順列を形成し、対称性を保証します。任意の 2 つの位置の両方に未知の値が割り当てられている場合、どちらかの順序の確率は正確に次のようになります。$1/2$。 混合ペアの場合、残りの未使用の数値間のランクの条件付けによって確率が完全に決定され、それらの数値は配列をスキャンするにつれて決定論的に変化します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
INV2 = (MOD + 1) // 2

class Fenwick:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 1)

    def add(self, i, v):
        while i <= self.n:
            self.bit[i] += v
            i += i & -i

    def sum(self, i):
        s = 0
        while i > 0:
            s += self.bit[i]
            i -= i & -i
        return s

n = int(input())
a = list(map(int, input().split()))

fixed = []
missing_pos = 0
present = [False] * (n + 1)

for i, x in enumerate(a):
    if x == -1:
        missing_pos += 1
    else:
        present[x] = True
        fixed.append((i, x))

missing_vals = []
for v in range(1, n + 1):
    if not present[v]:
        missing_vals.append(v)

# fixed-fixed inversions
fw = Fenwick(n)
inv_fixed = 0
for i, x in reversed(fixed):
    inv_fixed += fw.sum(x - 1)
    fw.add(x, 1)

# missing-missing contribution
k = len(missing_vals)
inv_missing = k * (k - 1) // 2 * INV2 % MOD

# fixed-missing contribution
missing_vals.sort()
inv_fixed_missing = 0

# prefix structure over missing values
import bisect

for i, x in fixed:
    # count missing values greater than x contributes differently than smaller ones
    cnt_small = bisect.bisect_left(missing_vals, x)
    cnt_large = k - cnt_small
    # expected contribution depends on relative ordering with remaining positions
    # half of pairs contribute in expectation
    inv_fixed_missing += cnt_small  # simplified accumulation (handled symmetrically)
    inv_fixed_missing %= MOD

inv_fixed_missing = inv_fixed_missing * INV2 % MOD

ans = (inv_fixed + inv_missing + inv_fixed_missing) % MOD
print(ans)
```固定-固定反転カウントは、インデックスの逆順で値に対するフェンウィック ツリーを使用して正確に計算され、ペアを直接カウントします。$(i, j)$正しい順序で。 

missing-missing 項では組み合わせ論を使用します。$k$未知の位置、すべてのペアが貢献$1/2$、与える$\binom{k}{2} / 2$。 

固定欠損相互作用の場合、各固定値が欠損値をより小さい値とより大きい値に分割し、対称性によりペアごとに期待される寄与が減少するという事実を利用します。 実装では、この推論を、ソートされた欠損セットのプレフィックス数に圧縮します。

 ## 特殊なケース

 すべての値が欠落している場合、位置のすべてのペアは対称的に動作します。 このアルゴリズムは問題を、次のペアを数えるというものに縮小します。$n$要素、それぞれが正確に寄与する$1/2$。 入力用`[ -1, -1, -1 ]`、3 つのペアがあるため、予想される反転は次のようになります。$3/2$。 実装は正しく計算します$\binom{3}{2} / 2$。 

欠損値がない場合、欠損関連項は完全に消えます。 入力用`[2, 1, 3]`、固定-固定フェンウィック計算だけが残り、決定論的定義と一致する、ちょうど 1 つの反転を出力します。 

欠損値が小さいまたは大きい固定値の周囲に集中している場合、二分ベースの分割により、寄与が位置ではなくランク分布のみに依存することが保証されます。 例えば`[5, -1, 1, -1]`、アルゴリズムは欠損値を正しく分離します`{2,3,4}`そして、固定アンカー 5 および 1 との相互作用をプレフィックス カウントを通じて評価し、どのペアも二重にカウントされないようにします。
