 ## 解決策
 ## 問題の理解

 複数の独立したクエリが与えられ、それぞれが次からの数値間隔を記述します。$l$に$r$。 間隔ごとに、その中の 2 つの異なる整数を、一方が他方の約数となるように選択する必要があります。 各クエリの出力は 1 つの有効なペアだけです。 複数存在する場合は、どれでも構いません。 

この制約では最大 1000 個のクエリが許可され、各間隔のエンドポイントはおおよそ次のような大きさにすることができます。$10^9$。 これにより、各間隔内のすべてのペアを検査しようとするアプローチが即座に排除されます。 一定範囲のサイズにわたる二次スキャン$k$費用がかかるだろう$O(k^2)$、これは中程度に広い範囲でも実行不可能です。 クエリごとの線形スキャンでも、間隔が大きな値にまたがると遅くなりすぎます。 

重要な構造上の保証により、問題は大幅に単純化されます。すべてのクエリには、少なくとも 1 つの有効なペアがあることが保証されます。 これにより、割り切れるペアが存在しない場合のフォールバック処理の必要がなくなります。 

主な微妙なケースは、間隔が非常に小さい場合に発生します。 もし$l = r$、有効なペアがまったくありませんが、この状況は除外されます。 もし$r = l + 1$、答えは、一方の数字がもう一方の数字を割るかどうかによって決まります。これは、次のような小さな値を除いてまれです。$1$そして$2$。 構造を確認せずに不注意で貪欲な選択をすると、このような狭い範囲で失敗する可能性があります。 

## アプローチ

 ブルートフォースのアイデアは簡単です。すべてのペアを反復処理します。$(x, y)$と$l \le x < y \le r$かどうかを確認してください$y \bmod x = 0$。 すべての候補者を徹底的にチェックするので、これは正しいです。 ただし、サイズ範囲内のペアの数は$n$は$O(n^2)$、そして間隔が長い場合、これは完全に非現実的になります。 

改善は、単純な乗法構造を観察することで実現します。$x$、その後は有効です$y$値は次の倍数です$x$。 間隔内で複数回の滞在を保証する最も自然な方法は、次のことを選択することです。$y = 2x$2 倍は最小の非自明な倍数であるためです。 

これは建設的な戦略につながります。恣意的に検索する代わりに、フォームのペアを強制的に見つけようとします。$(x, 2x)$。 唯一の問題は、両方の値が内部に存在するかどうかです$[l, r]$。 私たちが選ぶなら$x$インターバルの左半分から、$2x$まだ正しいエンドポイント内に収まる可能性があります。 最もクリーンな保証は、$x = l$、どうかを確認してください。$2l \le r$。 「はい」の場合、すぐに有効なペアが得られます。 

もし$2l > r$の場合、左端で 2 倍するには間隔が小さすぎます。 この状況では、構造を変更します。少し大きい構造から始めて最小の多重構造を見つけようとします。$x$。 この問題では有効なペアの存在が保証されているため、$x = r // 2$機能します。$2x \le r$、そしてまた$x \ge l$存在保証の下で保持する必要があります。 これにより、検索なしで決定的な構築が得られます。 

全体的な考え方は、任意の割り算を求める代わりに、有効なペアを含む十分に大きな区間に存在する必要がある単純な乗法構造を強制するというものです。

 ## アルゴリズムのチュートリアル

 私たちは、有効なペアを常に単純な乗法関係に強制できるという事実に依存しています。 

1. クエリ間隔を読み取る$[l, r]$。 目標は、一方の数字がもう一方の数字を割るペアを見つけることです。 
2. 最小の候補を選択してみてください$x = l$。 もし$2l \le r$、次に設定します$y = 2l$。 これが機能するのは、2 倍にすることで割り切れる可能性が維持され、両方の値が範囲内に収まることが保証されるためです。 
3. もし$2l > r$の場合、間隔が狭すぎて、左のエンドポイントからの 2 倍に対応できません。 この場合、選択してください$x = \lfloor r/2 \rfloor$。 
4.セット$y = 2x$。 これにより、$y \le r$建設によって、そして$x \ge l$有効なペアが間隔内に存在することが保証されるという問題があるため、この問題は保持されます。 
5. 出力$(x, y)$。 

### なぜ効果があるのか

 重要な不変条件は、常に構築することです。$y = 2x$、これは割り算を保証します。 唯一の制約は、両方のエンドポイントがその範囲内にあることを確認することです。$[l, r]$。 間隔が十分に広い場合は、$2l$、左側の境界を直接使用します。 それ以外の場合、間隔には有効なペアが含まれている必要があり、整数の構造により、一定以上の値が保証されます。$r/2$は、有効な割り切れるペアの小さい要素として機能します。 有効なペアであれば$(a, b)$満たさなければなりません$a \le r/2$（さもないと$2a > r$多重近似なし)、選択$x = r/2$この構造的限界と一致し、実現可能性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        l, r = map(int, input().split())
        
        if 2 * l <= r:
            x = l
            y = 2 * l
        else:
            x = r // 2
            y = x * 2
        
        print(x, y)

if __name__ == "__main__":
    solve()
```コードは建設的なアイデアを直接実装します。 最初の分岐は、左端の 2 倍が区間内に留まるケースを処理します。 2 番目のブランチは、次の整数の半分に依存します。$r$有効なペアが依然として適合することを保証します。 

微妙な点は、Python の整数の除算です。 使用する`r // 2`境界内に留まり、浮動小数点エラーを回避できるようにします。 2 を掛けると、割り切れるペア構造が復元されます。

 間隔は単純な 2 倍化を含めるのに十分な幅があるため、アルゴリズムは有効なペアをすぐに見つけます。 これにより、左下限の小さな間隔が最初の分岐によって処理されることが確認されます。

 ここで、3 を 2 倍にすると区間を超えてしまうため、中点ベースの作図に切り替えます。 結果のペアは依然として可分性を満たし、境界内に留まり、狭い間隔での正しさを示します。

 ## 特殊なケース

 みたいな間隔で$[1, 2]$、アルゴリズムが選択します$x = 1$以来$2 \cdot 1 \le 2$、生産$(1, 2)$。 これは、可分性の要件を直接満たします。 

などの狭い間隔の場合$[5, 6]$、5 を 2 倍することは 6 を超えるため無効です。フォールバックは$x = 3$、 以来$6 // 2 = 3$、および出力$(3, 6)$。 このペアは区間内に留まり、必要な可分性が維持されます。 

より長い間隔の場合は、$[8, 20]$、最初の分岐が適用され、結果が得られます。$(8, 16)$これにより、区間に十分なスペースがある場合は常に、最も単純な乗法ペアで常に十分であることが確認されます。
