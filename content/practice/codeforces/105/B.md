 ## 解決策
 ## 問題の理解

 私たちには、_n_ 人の上院議員からなる小規模な集まりがあり、それぞれがレベルと忠誠度スコアによって定義されています。 忠誠度は、上院議員が提案に賛成票を投じる確率であり、10% 刻みで与えられます。 上院議員の半数以上が賛成票を投じれば、その提案は可決される。 投票が失敗した場合、プレイヤーは反対者の「排除」を試みることができます。その成功確率は、プレイヤーの合計レベルと反対者の合計レベルに基づいています。 

投票する前に、プレーヤーは最大 _k_ 個のキャンディーで上院議員に賄賂を渡すことができます。 各キャンディーは忠誠度を 10% 増加させ、最大で 100% 増加します。 課題は、キャンディーを最適に分配した後、提案が通過する最大確率を決定することです。 

制約は小さく、_n_ と _k_ は最大 8 です。これは、キャンディーを配布するあらゆる可能な方法を検討することが実行可能であることを直ちに示唆しています。 上院議員のレベルと忠誠度の値はそれぞれ最大 9999 と 100 ですが、確率は 10% 単位で量子化されます。 

明らかではないエッジケースとしては、最初に賛成票を投じる上院議員がいなかったり、忠誠心がすでに 100% で追加のキャンディーが無効になったりするシナリオが含まれます。 _k_ がすべての忠誠心を最大化するのに必要な値を超えた場合、別の微妙なケースが発生します。 余ったキャンディーを分配しても確率は変わりません。 

## アプローチ

 強引な方法は簡単です。上院議員にキャンディーを配布するあらゆる方法を試し、配布ごとに投票が通過する確率を計算し、最大値を追跡します。 キャンディーの配布ごとに、すべてのことを考慮する必要があります。$2^n$上院議員の一部が賛成か反対で投票し、投票の成功確率を計算します。 その後、提案がサブセットで失敗した場合、反対者を殺害する確率を計算します。 

_n_ ≤ 8 および _k_ ≤ 8 の場合、キャンディー分布の数は組み合わせになりますが、十分に小さいです。 具体的には、各上院議員は 0 ～ min(k, 10 - 忠誠心 / 10) 個のキャンディーを取得できます。 分布を再帰的に生成できます。 各分布について、賛成票を投じた上院議員のすべてのサブセットを合計し、結合確率を計算します。 最悪の場合でも、複雑さは許容されます。$8 \times 2^8 \times 9^8$操作は数百万回以内で、最新の CPU では 2 秒以内に処理できます。 

最適化のための重要な洞察は、境界が小さいため、この強引なアプローチを超える派手な枝刈りや動的プログラミングは必要ないということです。 課題は、各シナリオの確率を正しく計算し、10% 単位で四捨五入を処理することです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(キャンディーの選択肢 × 2^n) | O(n) | 承認済み |
 | メモ化による最適化 | お(同じ) | O(n × k) | これらの境界には不要です |

 ## アルゴリズムのチュートリアル

 1. 入力を読み取り、各上院議員のレベルと忠誠心を保存します。 ロイヤルティの割合を小数の確率に変換して計算します。 
2. 忠誠度 100% の上限を尊重して、_n_ 人の上院議員に最大 _k_ 個のキャンディーを配布するすべての可能な方法を生成します。 キャンディーごとに忠誠度が 10% 追加されます。 これは再帰的に実装できます。上院議員 i に対して、最小 (残りのキャンディー, 10 - current_loyalty/10) 個のキャンディーまで 0 を与えてから、上院議員 i+1 まで再帰的に実行します。 
3. キャンディーの配布ごとに、提案が通る確率を計算します。 すべてをループします$2^n$賛成票を投じる集団を代表する上院議員の一部。 個々の上院議員の確率の積として、各サブセットが発生する確率を計算します。はいセットの上院議員の場合は、忠誠度を掛けます。 セットに含まれていない上院議員の場合は、(1 - 忠誠心) を掛けます。 
4. 賛成票が厳密に半分を超えるサブセットについては、その確率を累計に加算します。 
5. 提案が失敗したサブセットについて、すべての反対者を首尾よく殺害できる確率を計算します。 それらのレベルを合計して _B_ を取得し、計算します$A / (A + B)$、この投票パターンの確率を乗算し、累計に加算します。 
6. すべてのキャンディー配布における最大確率を追跡します。 この確率を小数点以下 10 桁で出力します。 

機能する理由: このアルゴリズムは、考えられるすべてのキャンディの割り当てとすべての投票結果を明示的に列挙します。 各確率は問題のルールに従って正確に計算されます。 すべてのキャンディーの割り当てを考慮することで、最適な配分が必ず見つかります。 すべての結果の確率の合計は各分布で 1 に等しく、シナリオが見逃されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from itertools import product

def solve():
    n, k, A = map(int, input().split())
    senators = []
    for _ in range(n):
        b, l = map(int, input().split())
        senators.append([b, l])

    max_prob = 0.0

    # Recursive candy distribution
    def distribute(i, remaining_candies, loyalties):
        nonlocal max_prob
        if i == n:
            # Evaluate this loyalty distribution
            prob = 0.0
            for mask in range(1 << n):
                yes_count = 0
                p_mask = 1.0
                dissenters_level = 0
                for j in range(n):
                    if mask & (1 << j):
                        yes_count += 1
                        p_mask *= loyalties[j] / 100
                    else:
                        p_mask *= 1 - loyalties[j] / 100
                        dissenters_level += senators[j][0]
                if yes_count > n // 2:
                    prob += p_mask
                else:
                    if A + dissenters_level > 0:
                        prob += p_mask * A / (A + dissenters_level)
            max_prob = max(max_prob, prob)
            return

        max_add = min(remaining_candies, 10 - loyalties[i] // 10)
        for candies in range(max_add + 1):
            loyalties[i] += candies * 10
            distribute(i + 1, remaining_candies - candies, loyalties)
            loyalties[i] -= candies * 10

    distribute(0, k, [sen[1] for sen in senators])
    print(f"{max_prob:.10f}")

solve()
```コードはまず入力を読み取り、上院議員のレベルと忠誠心を保存します。 再帰関数を使用して、すべての有効なキャンディーの配布を試します。 分布ごとに、ビット マスクを使用してすべての投票サブセットを列挙します。 各投票パターンの確率は、個々の上院議員に対して乗算されます。 投票が可決されると、確率が直接加算されます。 そうでない場合は、反対者を排除する可能性が考慮されます。 

慎重に実装することで、ロイヤルティの上限が 100% になり、確率が 10 進数で計算され、各分岐後のロイヤルティの変更が再帰によって正しくバックトラックされることが保証されます。
