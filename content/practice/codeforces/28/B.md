 ## 解決策
 ## 問題の理解

 配列から始めます。`i`最初に値が含まれています`i`。 各ポジションには固定ジャンプ距離もあります`d[i]`。 ポジション間の交換は許可されています`i`そして`j`場合のみ`|i - j| = d[i]`。 

ターゲット配列は順列です。 許可されたスワップが、最初の順序付けされた配列をその順列に変換するのに十分であるかどうかを判断する必要があります。 

重要な最初の詳細は、ステートメント内でスワップ ルールが非対称であることです。 位置`i`どれとでも交換できます`j`距離条件を満たしていること。 しかし、そのようなペアが存在すると、交換自体は完全に正常であり、両方の値が入れ替わります。 位置の場合`i`到達できる`j`、次に位置`i`そして`j`同じ運動構造に属します。 

制約は非常に小さいですが、`n ≤ 100`。 三次解でも制限時間内に余裕で収まります。 つまり、高度な最適化は必要ありませんが、グラフの正しい解釈は必要です。 すべての順列にわたるブルートフォース状態検索は不可能です。`n!`州。 たとえ`n = 10`、これはすでに大きくなりすぎています。 

重要な観察は、スワップはポジションの接続された領域内の値のみを移動するということです。 位置の場合`1`最終的にはポジションに到達できる`3`そして`5`一連のスワップを通じて、それらの位置間で値を任意に再配置できます。 2 つの位置が異なる連結成分に属している場合、一連のスワップによってその境界を越えて値を移動することはできません。 

よくある間違いは、スワップのチェーンではなく直接スワップのみをチェックすることです。 

考慮する：```
3
2 3 1
1 1 1
```正しい答えは、`YES`。 

位置`1`と交換できます`2`、 そして`2`と交換できます`3`。 それでも`1`と直接交換することはできません`3`、値`1`中間スワップを通じてそこに移動することはできます。 

もう 1 つの簡単な間違いは、実際にはグラフに方向性がないことを忘れていることです。 

例：```
2
2 1
1 2
```答えは`NO`。 

位置`1`と交換できます`2`なぜなら`|1 - 2| = 1`、しかし位置`2`と交換できません`1`なぜなら`|2 - 1| ≠ 2`。 声明にはこう書かれているので、`i`-番目のセルは次のものと交換できます`j`、有効なエッジから生成されたエッジのみ`i`案件。 ここでは一方向のみが存在しますが、スワップ自体は依然としてポジションを接続します。 1 回の法的な交換の後、両方の位置の値が交換されるため、これを無向エッジとして扱います。 

もう 1 つの微妙なケースは、孤立したノードです。```
4
1 3 2 4
4 1 1 4
```答えは`YES`。 

ポジション`2`そして`3`ポジションを交換しながら、`1`そして`4`孤立している。 ターゲットの順列は、接続されたペア内の値のみを交換します。`{2,3}`, なので到達可能です。 

## アプローチ

 ブルート フォース アプローチでは、状態を超えた BFS または DFS を使用して、到達可能なすべての順列をシミュレートします。 各状態は順列であり、法的な交換ごとに別の状態が生成されます。 これは正しいです。最終的には、到達可能なすべての構成が調査されることになります。 

問題は状態数です。 がある`n!`順列。 でさえ`n = 10`、それはすでに 300 万以上の州であり、各州は多くのスワップを生成する可能性があります。 実際の制限は`100`, そのため網羅的な検索は絶望的です。 

スワップの構造は、はるかに単純な解釈を与えます。 

位置をグラフの頂点と考えてください。 あらゆるポジションについて`i`、それをすべての有効な位置に接続します`j`満足のいく：```
|i - j| = d[i]
```2 つの位置が同じ連結成分内にある場合、一連のスワップを通じて値がそれらの間で移動する可能性があります。 接続されたコンポーネント内では、パスに沿ったスワップにより、含まれる値を自由に並べ替えることができるため、任意の再配置が可能になります。 

それは問題を完全に変えます。 順列を追跡する代わりに、すべての値が元の位置と同じ連結成分内に収まることを確認するだけで済みます。 

価値`x`位置から始まります`x`。 対象順列のどこかの位置に出現する`pos`。 この取り決めは、次の場合にのみ到達可能です。`x`そして`pos`同じ接続コンポーネントに属します。 

DFS または DSU を使用してグラフを構築し、連結成分を計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! · n²) | お(ん!) | 遅すぎる |
 | 最適 | O(n²) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 順列を読み取る`p`そして好きな距離`d`。 
2. 位置に関するグラフを作成する`1 ... n`。 

あらゆるポジションについて`i`、位置を確認してください:```
i - d[i]
i + d[i]
```境界内にある場合は、それらを次のように接続します。`i`。 

これらのエッジは法的なスワップを表します。 
3. DFS または DSU を使用して接続コンポーネントを計算します。 

同じコンポーネント内の位置は、一連のスワップを通じて値を交換できます。 
4. ポジションごとに`i`、価値を見てください`p[i]`。 

価値`p[i]`元々はその位置で開始されました`p[i]`。 所定の位置に配置するには`i`、両方の位置が同じ連結成分に属している必要があります。 
5. いずれかの位置がこのチェックに失敗した場合は、印刷します。`NO`。 
6. それ以外の場合は印刷します`YES`。 

### なぜ効果があるのか

 すべてのスワップ エッジがそのコンポーネントの内部に留まるため、正当なスワップでは値が接続されたコンポーネントの外に移動することはありません。 したがって、値が`x`位置で終了する必要があります`i`、 それから`x`そして`i`同じコンポーネントに属している必要があります。 

逆方向も成立します。 接続されたコンポーネント内で、グラフの端に沿ってスワップを繰り返すと、そのコンポーネント内の任意の場所に値を移動できます。 接続されたコンポーネントは独立しているため、各コンポーネントを個別に希望の順序に並べ替えることができます。 

これにより、接続コンポーネント条件が必要かつ十分になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)

        if a != b:
            self.parent[b] = a

def solve():
    n = int(input())

    p = list(map(int, input().split()))
    d = list(map(int, input().split()))

    dsu = DSU(n)

    for i in range(n):
        left = i - d[i]
        right = i + d[i]

        if left >= 0:
            dsu.union(i, left)

        if right < n:
            dsu.union(i, right)

    for i in range(n):
        target_value = p[i] - 1

        if dsu.find(i) != dsu.find(target_value):
            print("NO")
            return

    print("YES")

solve()
```DSU は位置の連結成分を保存します。 有効なスワップごとに 2 つのインデックス間にエッジが作成されるため、ユニオン操作により移動グラフが段階的に構築されます。 

この実装では内部でゼロベースのインデックスが使用されます。 そのため、位置の値は`i`になる`p[i] - 1`コンポーネントを比較する前に。 この変換を忘れることは、この問題で最も一般的な off-by-one バグの 1 つです。 

インデックスごとに、可能な両方の宛先を試します。`i - d[i]`そして`i + d[i]`。 一部のジャンプは配列から離れるため、境界チェックは重要です。 

最後の検証ステップでは、コアの不変式を直接エンコードします。 価値`p[i]`位置からスタート`p[i] - 1`。 元の位置と現在の宛先が異なるコンポーネントに属している場合、一連の正当なスワップによってその位置に配置することはできません。

 ## 特殊なケース

 間接接続の場合を考えてみましょう。```
3
2 3 1
1 1 1
```グラフの端は次のとおりです。```
1 <-> 2
2 <-> 3
```すべての位置は 1 つの連結成分に属します。 ポジションなのに`1`と直接交換することはできません`3`、 価値`1`以下を使用して移動できます。```
[1 2 3]

[2 1 3]

[2 3 1]
```DSU は 3 つの位置すべてを正しくマージするため、アルゴリズムは次のように出力します。`YES`。

```すべてのジャンプは配列の外に出るため、エッジは作成されません。 各位置は独自のコンポーネントを形成します。
