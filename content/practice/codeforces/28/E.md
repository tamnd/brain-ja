 ## 解決策
 ## 問題の理解

 平面上に保育器領域を表す単純な多角形が与えられます。 DravDe はポイントから始まります$A$、これは厳密にポリゴンの外側にあることが保証されています。 

飛行機は一定の 3D 速度で移動します$V=(x_v,y_v,z_v)$。 飛行機は地上からスタートするので、$z_v>0$、時間後の高度$t_1$は$$h = z_v \cdot t_1$$その瞬間、DravDeは飛び上がります。 

ジャンプ後、まずフリーフォールに入ります。 このフェーズでは、垂直方向の速度のみが指定されるため、水平方向の位置はまったく変化しません。 彼は猛スピードで垂直下に落下する$F_{down}<0$。 彼が時間を待っていたら$t_2$、その後彼の高度は減少します$$|F_{down}| \cdot t_2$$落下中のいつでもパラシュートを開けることができます。 それから着地まで一定速度で移動します$U=(x_u,y_u,z_u)$、 どこ$z_u<0$。 

私たちは何らかの選択をするかどうかを判断しなければなりません$t_1\ge 0$そして$t_2\ge 0$多角形の内側または境界上に着陸できるようになります。 すべての実現可能な計画の中で最小限に抑えます$t_1$、そしてそれらの中から最小化します$t_2$。 

ポリゴンには最大でも$10^4$頂点。 これにより、エッジのすべてのペアや 2 次処理を伴う高価な幾何学構造が即座に除外されます。 線形に近いものが必要です。$O(n \log n)$。 制限時間はわずか 1 秒なので、すべてのエッジを数回通過する場合でも、軽量である必要があります。 

動き自体は連続的ですが、すべてが直線的です。 すべての軌道セグメントは時間のアフィン関数であり、これは、到達可能な着陸点が数値的に時間をかけて検索する代わりに直接分析できる何らかの幾何学的領域を形成していることを強く示唆しています。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

パラシュートが開かれないと仮定します。 その後、全体の降下は垂直になります。 着地点はジャンプ点と同じです。 常に割る不注意な解決策$z_u$そのようなケースはクラッシュしたり、誤って拒否されたりする可能性があります。

## アプローチ

 強引なアイデアは、ジャンプ時間を超えて検索することです$t_1$および自由落下持続時間$t_2$、結果の着地点を計算し、それが多角形の内側にあるかどうかを確認します。 

時間が経ってから飛行機の位置を決めましょう$t_1$なれ$$P=A+t_1(V_x,V_y)$$その高度は$z_v t_1$。 

DravDe が時間切れでフリーフォールした場合$t_2$、パラシュート展開までの残り高度は$$z_v t_1 + F_{down} t_2$$以来$F_{down}<0$、この量は減少します。 

パラシュートを開いた後、高度ゼロに達するまでの残り飛行時間は$$t_3 = -\frac{z_v t_1 + F_{down} t_2}{z_u}$$なぜなら$z_u<0$。 

そのときの最終着地点は、$$L = A + t_1(V_x,V_y) + t_3(U_x,U_y)$$すべての有効な軌道は次のように一意に決定されるため、ブルート フォース手法は概念的には正しいです。$(t_1,t_2)$。 問題は、実数値パラメータの空間が連続していることです。 数値検索には、ジオメトリに対するバイナリ検索またはサンプリングのいずれかが必要ですが、どちらも浮動小数点精度での正確な最適化には十分な信頼性がありません。 

重要な観察は次のとおりです$t_2$パラシュートフェーズの長さにのみ影響します。 それを代数的に消去することができます。 

させて$$h = z_v t_1$$ジャンプ時の高度になります。 

垂直自由落下中は高度が下降します。$h$ある値に$h'\ge 0$。 その後、パラシュート降下は正確に消費されます$h'/(-z_u)$時間。 

結果として得られる水平着陸位置は次のようになります。$$L = A + t_1(V_x,V_y) + \frac{h'}{-z_u}(U_x,U_y)$$以来$0\le h'\le h$、到達可能なすべての着陸地点が固定されています$t_1$セグメント上にあります:$$L(t_1,\lambda) = A+t_1(V_x,V_y) + \lambda t_1(U_x,U_y)$$どこ$$0 \le \lambda \le \frac{z_v}{-z_u}$$これが重要な単純化です。 固定の場合$t_1$、到達可能なセットは 2 次元ではありません。 それは単なる線分です。 

定義する$$D_1=(V_x,V_y)$$そして$$D_2=(V_x,V_y)+\frac{z_v}{-z_u}(U_x,U_y)$$すると、実現可能な着地点はすべて次と等しくなります。$$A+t_1((1-s)D_1+sD_2)$$一部の人にとっては$s\in[0,1]$。 

したがって、到達可能なすべての点は、次の点を頂点とする円錐を形成します。$A$、方向の光線によって境界が定められています$D_1$そして$D_2$。 

ここで、最適化は幾何学的になります。 

多角形とこの円錐の間の最初の交点が必要です。 最小限の$t_1$は、円錐内の任意の光線に沿った最も近い交差点に対応します。 

固定方向の場合$D$、光線は$$A+tD,\quad t\ge0$$レイとポリゴンの交差は、すべてのエッジにわたって線形時間で実行できます。 ポリゴンには$10^4$頂点の場合、すべてのエッジを円錐の境界と関連する角度間隔の両方に対してチェックするのは十分に高速です。

 ## アルゴリズムのチュートリアル

 1. 到達可能な 2 つの極端な水平方向を計算します。 

1 つ目は、パラシュートを開かないことに対応します。$$D_1=(V_x,V_y)$$2 番目は、ジャンプの直後に開くことに対応します。$$D_2=(V_x,V_y)+\frac{z_v}{-z_u}(U_x,U_y)$$到達可能な着陸方向はすべて、これら 2 つのベクトルの間にあります。 
2. 各ポリゴン エッジについて、エッジ セグメントと次の方法で生成された円錐を交差させます。$D_1$そして$D_2$。 

実行可能な着陸点は、ポリゴンと到達可能な円錐に同時に属している必要があります。$A$。 
3. 各ポリゴンのエッジをパラメータ化します。 

エッジが発生する場合$P_i$に$P_{i+1}$、エッジに点を次のように書きます。$$E(t)=P_i+t(P_{i+1}-P_i), \quad 0\le t\le1$$4. エッジ上のすべての点について、その方向が次の方向かどうかを判断します。$A$円錐の中にあります。 

これは外積を使用します。 両方の境界に対するベクトルの向きが正しい符号を持つ場合、ベクトルは 2 つの光線の間にあります。 
5. 実現可能な点について、対応する飛行機の時間を計算します。$t_1$。 

到達可能な点はどれでも満たす$$L=A+t_1D$$どこ$D$の凸の組み合わせです$D_1,D_2$。 

これを解くと必要なものが得られます$t_1$。 
6. 最低限のものを守る$t_1$。 

複数の点が同じ場合$t_1$、小さいほうが好ましい$t_2$。 
7.回復する$t_2$補間係数から。 

もし$$D=(1-s)D_1+sD_2$$パラシュートを早く開くと、より大きくなります$s$。 以来$$t_2 = \frac{z_v t_1(1-s)}{-F_{down}}$$最小化する$t_2$最大化することを意味します$s$。 

### なぜ効果があるのか

 すべての軌道は、ジャンプ高度とパラシュートが開く高度によって完全に決定されます。 これらの垂直方向の変数を除去すると、着地点が 2 つの水平方向の間の単一の補間パラメータに線形的に依存することがわかります。 

到達可能な集合はまさに円錐です$A$。 適切な自由落下時間を選択することで、その円錐内の任意の着地点を生成できます。 逆に、すべての物理的な軌道はその円錐の内側に到達します。 アルゴリズムは多角形とこの円錐の間のすべての交点を検索するため、実行可能な解決策が見逃されることはありません。 

最適化基準も幾何学的になります。 より小さい$t_1$着地点が近くにあることを意味します$A$到達可能な光線に沿って。 平等の間で$t_1$、パラシュートの寄与を最大化すると、自由落下時間が最小限に抑えられます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

EPS = 1e-9

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

def dot(ax, ay, bx, by):
    return ax * bx + ay * by

def solve():
    n = int(input())

    poly = [tuple(map(float, input().split())) for _ in range(n)]

    ax, ay = map(float, input().split())
    vx, vy, vz = map(float, input().split())
    fdown = float(input())
    ux, uy, uz = map(float, input().split())

    d1x, d1y = vx, vy

    k = vz / (-uz)
    d2x = vx + k * ux
    d2y = vy + k * uy

    cone_cross = cross(d1x, d1y, d2x, d2y)

    best_t1 = float('inf')
    best_s = -1.0

    def inside_cone(px, py):
        vx1 = px - ax
        vy1 = py - ay

        if abs(cone_cross) < EPS:
            if abs(cross(d1x, d1y, vx1, vy1)) > EPS:
                return False
            return dot(d1x, d1y, vx1, vy1) >= -EPS

        c1 = cross(d1x, d1y, vx1, vy1)
        c2 = cross(vx1, vy1, d2x, d2y)

        if cone_cross > 0:
            return c1 >= -EPS and c2 >= -EPS
        else:
            return c1 <= EPS and c2 <= EPS

    def process_point(px, py):
        nonlocal best_t1, best_s

        rx = px - ax
        ry = py - ay

        denom = cross(d1x, d1y, d2x, d2y)

        if abs(denom) < EPS:
            denom2 = d1x * d1x + d1y * d1y
            if denom2 < EPS:
                return

            t1 = dot(rx, ry, d1x, d1y) / denom2

            s = 1.0
        else:
            t1 = cross(rx, ry, d2x - d1x, d2y - d1y) / denom

            if abs(t1) < EPS:
                return

            dx = rx / t1
            dy = ry / t1

            vxm = d2x - d1x
            vym = d2y - d1y

            if abs(vxm) > abs(vym):
                s = (dx - d1x) / vxm
            else:
                s = (dy - d1y) / vym

        if t1 < -EPS:
            return

        if s < -EPS or s > 1 + EPS:
            return

        if t1 < best_t1 - EPS:
            best_t1 = t1
            best_s = s
        elif abs(t1 - best_t1) < EPS and s > best_s:
            best_s = s

    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]

        process_point(x1, y1)
        process_point(x2, y2)

        for j in range(2):
            if j == 0:
                rx, ry = d1x, d1y
            else:
                rx, ry = d2x, d2y

            ex = x2 - x1
            ey = y2 - y1

            denom = cross(rx, ry, ex, ey)

            if abs(denom) < EPS:
                continue

            qx = x1 - ax
            qy = y1 - ay

            t = cross(qx, qy, ex, ey) / denom
            u = cross(qx, qy, rx, ry) / denom

            if t < -EPS:
                continue

            if u < -EPS or u > 1 + EPS:
                continue

            px = ax + t * rx
            py = ay + t * ry

            process_point(px, py)

    if best_t1 == float('inf'):
        print("-1 -1")
        return

    t2 = vz * best_t1 * (1.0 - best_s) / (-fdown)

    if t2 < EPS:
        t2 = 0.0

    print(f"{best_t1:.10f} {t2:.10f}")

solve()
```実装は幾何学的定式化に直接に従います。 

ベクトル`d1`そして`d2`到達可能な 2 つの極端な方向を説明します。 有効な着地点はすべて、それらがまたがる円錐の内側にあります。 

機能`inside_cone`外積を使用して角の包含を処理します。 これは、三角関数の精度の問題を回避し、角度の計算よりも安全です。$-\pi,\pi$不連続。 

機能`process_point`候補着地点を対応する地点に変換します$(t_1,s)$。 補間係数`s`パラシュートがどれくらい早く開くかを測定します。 より大きな`s`つまり、パラシュートでの移動が増え、自由落下が減ります。 

メイン ループは、すべてのポリゴンの頂点と、ポリゴンのエッジと円錐の境界の間のすべての交差をチェックします。 最適化は、これらの重要な点のいずれかで発生する必要があります。 円錐光線がポリゴンの内部を通過する場合、エッジとの最初の交差により最も早い実行時間が得られます。 

最もデリケートな部分は、次のような退化したケースです。`d1`そして`d2`は平行です。 その後、円錐は単一の光線に崩壊します。 コードでは、ゼロに近い行列式で除算するのではなく、それを個別に処理します。 

正しい答えがポリゴンのエッジまたは頂点に正確に存在する可能性があるため、境界処理ではあらゆる場所でイプシロン比較が使用されます。
