 ## 解決策
 ## 問題の理解

 各生徒は独立して、均一にランダムにバスルームの 1 つを選択します。 部屋には複数の洗面台がある場合があるため、その部屋に入る学生はいくつかの列に分かれます。 学生はその部屋の最大のキューの長さを最小限に抑えるように調整するため、キューのバランスは可能な限り均等になります。 

部屋に次のものがある場合`x`学生と`a[i]`盆地の場合、その部屋内の最大キュー サイズは次のようになります。$$\left\lceil \frac{x}{a[i]} \right\rceil$$1 つのランダムな割り当てのグローバル値は、すべてのルームの最大キュー サイズです。 この最大値の期待値を計算する必要があります。 

制約は動的プログラミングを可能にするのに十分小さいですが、総当たりの列挙には大きすぎます。 学生数は最大 50 名、部屋数は 50 です。 可能な割り当ての数は次のとおりです。$$m^n$$と`n = m = 50`、これは次のようになります`50^50`、これを直接列挙することはまったく不可能です。 

小さな境界は、状態ベースの確率 DP が意図されていることを示唆しています。 あらゆるアルゴリズム`O(n^3 m)`または`O(n^4)`2 秒以内であれば問題ありません。 何か指数関数的なもの`n`または`m`そうではありません。 

問題の最も危険な部分は、部屋内の最大キュー サイズを正確に決定するものを理解することです。 不用意に実装すると、フロア分割が誤って使用される可能性があります。 

考慮する：```
2 1
3
```生徒は 2 名、洗面器は 3 つあります。 キューの最大サイズは次のとおりです。`0`、 それでも`2 // 3 = 0`。 各生徒は単に別々の洗面器を占有しているだけなので、答えは次のようになります。`1`。 

もう 1 つの微妙なケースは、生徒の分布が不均等である場合に現れます。```
5 1
2
```5 人の生徒と 2 つの洗面台の場合、最適な分割はサイズに合わせたキューです`3`そして`2`。 最大の行列は、`3`、 ない`2`。 

より確率的なエッジケースは、多くの部屋に大きな洗面台数がある場合です。```
2 2
100 100
```学生がどのように部屋を選んだとしても、占有されている部屋はキューのサイズが最大になります。`1`。 期待値はまさに`1`。 単純なシミュレーションや不適切な遷移により、誤って空のキューがカウントされ、より小さなキューが生成される可能性があります。 

概念的な最も大きな間違いは、最大値を固定した後で部屋が独立していると仮定することです。 各部屋の生徒数の合計は次のようにする必要があるため、独立していません。`n`。 DP は、すでに割り当てられた学生の数を追跡する必要があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。 生徒ごとに、次のいずれかを選択します。`m`部屋。 完全な課題を作成した後、各部屋に入った生徒の数を数えます。 部屋用`i`、次を計算します。$$\left\lceil \frac{cnt_i}{a_i} \right\rceil$$次に、各部屋の最大値を取得し、すべての割り当ての平均を求めます。 

これが機能するのは、すべての割り当ての可能性が等しいためです。 問題は割り当ての数です。$$m^n$$最大制約の場合、これは天文学的に大きくなります。 

重要な観察は、私たちは学生の正確な身元を気にしていないということです。 各部屋に入る生徒の数だけが重要です。 

部屋を想定します`i`受け取る`k`学生たち。 このイベントの確率は二項です。$$\binom{n}{k}\left(\frac1m\right)^k$$さらに重要なのは、そのルームによって生成される最大キュー サイズは、`k`そして`a[i]`。 

これは問題を再構成することを示唆しています。 予想される最大値を直接計算する代わりに、次のように計算します。$$P(\text{maximum queue size} \le t)$$あらゆる閾値に対して`t`。 

固定閾値の場合`t`、 部屋`i`最大で次のものを受け入れることができます:$$a_i \cdot t$$学生、そうでない場合は最大キューが超過します`t`。 

ここで問題は、すべての部屋が許容収容人数内に収まる確率を計算することになります。 

これにより、問題は古典的な多項 DP に変換されます。 私たちは部屋を 1 つずつ処理し、すでに配布された生徒の数を追跡します。 

各部屋に割り当ててみます`k`学生には以下の条件を提供します。$$\left\lceil \frac{k}{a_i} \right\rceil \le t$$同様に:$$k \le a_i t$$正確に割り当てるための確率寄与`k`この部屋の学生は組み合わせ論の出身です。 残りのどの生徒がこの部屋に入るかを選択します。 

計算できるようになると、次のようになります。$$P(\max \le t)$$期待値は次から得られます。$$E[\max] = \sum_{t \ge 1} P(\max \ge t)$$または同等の意味で:$$E[\max] = \sum_{t=1}^{n} \left(1 - P(\max \le t-1)\right)$$2 番目の定式化は、最大キュー サイズが常に次の範囲内にあるため便利です。`1`そして`n`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(m^n \cdot (n+m)) | O(m) | 遅すぎる |
 | 最適 | O(m \cdot n^3) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 二項係数を事前計算する`C[n][k]`みんなのために`0 ≤ n,k ≤ 50`。 

これらの係数は、特定の部屋に入る生徒を選択できる方法が何通りあるかを表します。 
2. 事前計算力`m`。 

すべての割り当てには確率があるため、次のようになります。$$\frac1{m^n}$$繰り返し乗って割ります`m`。 
3. しきい値ごとに`t`から`0`に`n`、次を計算します。$$P_t = P(\max \le t)$$これは、どの部屋も最大キュー サイズが最大でなければならないことを意味します`t`。 
4. ルーム上で動的プログラミングを使用します。 

定義する：$$dp[i][j]$$正確に分配するための有効な方法の数として`j`最初の生徒たち`i`敷居を尊重しながら部屋を整える`t`。 
5. 初期化します。$$dp[0][0] = 1$$部屋を処理する前に、1 つの有効な方法で学生が割り当てられていません。 
6. 部屋を 1 つずつ処理します。 

私たちが部屋にいると仮定してください`i`そしてすでに割り当てられています`j`学生たち。 置いてみる`k`追加の生徒がこの部屋に入る可能性があります。 

この移行は、次の場合にのみ許可されます。$$\left\lceil \frac{k}{a_i} \right\rceil \le t$$これは以下と同等です:$$k \le a_i t$$7. トランジションを追加します。$$dp[i+1][j+k] += dp[i][j] \cdot \binom{n-j}{k}$$どちらかを選択します`k`残りの生徒はこの部屋に入ります。 
8. すべての部屋の処理が完了したら、`dp[m][n]`最大キュー サイズが最大になる割り当ての数に等しい`t`。 
9. 次の値で割ります。$$m^n$$確率を取得するには:$$P_t$$10. 以下を使用して期待値を回復します。$$E = \sum_{x=1}^{n} \left(1 - P_{x-1}\right)$$用語`1 - P_{x-1}`は、最大キュー サイズが少なくとも次の確率である確率です。`x`。 

### なぜ効果があるのか

 固定閾値の場合`t`、DP は、すべての部屋が制限を遵守している割り当てを正確にカウントします。 トランジションでは、現在の教室に入室する学生の数が選択され、そうする可能性のある残りの学生のすべてのサブセットがカウントされます。 

各部屋には一意に決定された生徒数が割り当てられるため、すべての完全な課題は DP を通る 1 つのパスに正確に対応します。 逆に、すべての DP パスは有効な割り当てを構築します。 

期待公式は、非負の整数確率変数に対して次のように機能します。$$E[X] = \sum_{x \ge 1} P(X \ge x)$$ここ`X`最大キュー サイズです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXN = 55

# binomial coefficients
C = [[0] * MAXN for _ in range(MAXN)]

for n in range(MAXN):
    C[n][0] = C[n][n] = 1
    for k in range(1, n):
        C[n][k] = C[n - 1][k - 1] + C[n - 1][k]

n, m = map(int, input().split())
a = list(map(int, input().split()))

total = float(m ** n)

# prob[t] = P(max <= t)
prob = [0.0] * (n + 1)

for t in range(n + 1):
    dp = [[0.0] * (n + 1) for _ in range(m + 1)]
    dp[0][0] = 1.0

    for i in range(m):
        limit = a[i] * t

        for used in range(n + 1):
            if dp[i][used] == 0:
                continue

            for take in range(n - used + 1):
                if take > limit:
                    break

                ways = C[n - used][take]
                dp[i + 1][used + take] += dp[i][used] * ways

    prob[t] = dp[m][n] / total

ans = 0.0

for x in range(1, n + 1):
    ans += 1.0 - prob[x - 1]

print(f"{ans:.15f}")
```最初のセクションでは、パスカルの三角形を使用して二項係数を事前計算します。 必要な値は 50 までなので、コストはほとんどかかりません。 

DP はしきい値ごとに独立して再構築されます`t`。 州`dp[i][used]`最初の割り当てを処理した後に有効な割り当てがいくつ存在するかを格納します。`i`部屋と割り当て`used`学生たち。 

トランジションは、中核となる組み合わせステップです。 仮定する`used`学生はすでに割り当てられています。 がある`n - used`学生はまだ自由です。 正確に選択する`take`現在のルームについては、次の方法で実行できます。$$\binom{n-used}{take}$$方法。 

条件`take <= a[i] * t`室内の最大キューが次の値を超えないことを保証します。`t`。 

よくある間違いは、多項係数を直接使用しようとすることです。 増分二項構造はより単純であり、部屋を順番に処理する間に各生徒が 1 回だけ割り当てられるため、過剰なカウントが回避されます。 

もう 1 つの微妙な点は、次の意味です。`t = 0`。 この閾値は生徒がいない限り不可能です。 以来`n ≥ 1`、`prob[0]`自動的にゼロになります。 このケースを維持すると、期待値の式が簡素化されます。 

最終的な合計には以下が使用されます。$$E[X] = \sum_{x \ge 1} P(X \ge x)$$次のように実装されます。```
ans += 1 - prob[x - 1]
```## 実用的な例

 ### 例 1

 入力:```

2
```生徒は 1 人、洗面台が 2 つある部屋が 1 つあります。 

閾値用`t = 0`:

 | 部屋の処理済み | 割り当てられた学生 | 有効な方法 |
 | --- | --- | --- |
 | 0 | 0 | 1 |
 | 1 | 1 | 0 |

 この部屋には学生を 1 人も受け入れることができません。`2 * 0 = 0`。 

それで：$$P(\max \le 0) = 0$$閾値用`t = 1`:

 | 部屋の処理済み | 割り当てられた学生 | 有効な方法 |
 | --- | --- | --- |
 | 0 | 0 | 1 |
 | 1 | 1 | 1 |

 現在、お部屋は以下まで受け入れ可能です`2`学生なので、課題は有効です。$$P(\max \le 1) = 1$$期待：$$1 - P(\max \le 0) = 1$$出力：```
1.000000000000000
```これは、学生より多くの盆地がある場合でも、最大のキュー サイズは依然として少なくとも`1`。 

### 例 2

 入力:```
2 2
1 1
```各部屋には洗面器が 1 つあるため、キューのサイズはその部屋にいる生徒の数と同じになります。 

閾値用`t = 1`、各部屋には最大でも 1 人の生徒を含めることができます。 

| 部屋 | 以前に生徒を使用しました | 学生が追加されました | 結果の状態 |
 | --- | --- | --- | --- |
 | 1 | 0 | 0 | dp[1][0] += 1 |

 | 2 | 0 | 0 | dp[2][0] += 1 |
 | 2 | 1 | 1 | dp[2][2] += 2 |

 がある`2^2 = 4`割り当ての合計。 

ちょうど 2 つの課題により、生徒は部屋全体に均等に分割されます。

したがって、次のようになります。$$E = 1 \cdot \frac12 + 2 \cdot \frac12 = 1.5$$出力：```

```この例は、確率を直接計算することが、しきい値有効な割り当てを計算するよりも難しい理由を示しています。

def solve():

    MAXN = 55

    C = [[0] * MAXN for _ in range(MAXN)]

    for n in range(MAXN):
        C[n][0] = C[n][n] = 1
        for k in range(1, n):
            C[n][k] = C[n - 1][k - 1] + C[n - 1][k]

    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    total = float(m ** n)

    prob = [0.0] * (n + 1)
