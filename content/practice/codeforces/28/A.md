 ## 解決策
 ## 問題の理解

 平面上の一連の釘 (それぞれが整数の座標を持つ) と、まっすぐな棒の集合が与えられます。 ネイルは、水平または垂直セグメントに沿ってのみ移動する閉じたポリラインの頂点を定義します。 目標は、いくつかのロッドをいくつかの釘に割り当て、各ロッドを釘のところで正確に 1 回折りたたんで 90 度の角を形成し、ロッドの端が 2 つの隣接する釘に取り付けられるようにすることです。 各釘は 1 つのロッドの折り目のみをホストでき、各ロッドは 1 回しか使用できません。 タスクは、有効な割り当てを見つけるか、それが不可能であると判断することです。 

入力制約では最大 500 個のネイルと 500 個のロッドが与えられますが、これはネイルまたはロッドの数で二次時間を持つアルゴリズムを許可するのに十分小さいです。 釘の座標とロッドの長さは大きな整数で、座標の場合は最大 10^4、ロッドの長さの場合は 2 × 10^5 です。 正確な長さだけが必要なため、長さを整数として扱うことができ、浮動小数点の精度の問題を回避できます。 

明らかではないエッジケースは、2 つの主なシナリオで発生します。 まず、ポリラインの連続したセグメントの長さが非常に短くなり、正確なサイズのロッドが必要になる場合があります。 長すぎたり短すぎたりするロッドを使用すると、割り当てが中断されます。 たとえば、ポリラインが辺の長さ 1 の正方形であるが、使用できる棒が長さ 2 のものだけである場合、出力は NO でなければなりません。 第 2 に、コーナーを形成する釘にロッドを割り当てる必要があるため、コーナーよりもロッドが多い場合、またはロッドよりもコーナーが多い場合、ソリューションはロッドなしで釘を慎重にスキップするか、不可能性を検出する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、ロッドのすべてのサブセットを列挙し、すべての釘に配置しようとし、結果として得られるロッドの長さが必要な水平距離と垂直距離に一致するかどうかを確認します。 これは、コーナーが n/2 しかなく、各ロッドが最大 1 回しか使用されないため機能しますが、サブセットの数は指数関数的に (O(2^m)) 増加し、m=20 の場合でも扱いにくくなります。 

重要な洞察は、ポリラインのすべての角がちょうど 2 つのセグメントによって形成される直角に対応しており、その角に必要なロッドの長さがこれら 2 つのセグメントの長さの合計であることを観察することで得られます。 これにより、各コーナーのマンハッタン距離 (水平方向と垂直方向の長さの合計) を計算し、これらの距離に正確に等しいロッドを割り当てようとする問題が軽減されます。 ロッドは一度しか使用できないため、コーナー長のマルチセットが利用可能なロッドのマルチセットに含まれているかどうかを確認するだけで済みます。 これにより、問題は計数問題に変わり、ソートまたはハッシュ マップを使用して効率的に実装できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^m * n) | O(n + m) | 遅すぎる |
 | コーナー長さのマッチング | O(n log n + m log m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

1. マンハッタン距離公式を使用して、連続する釘間の各ポリライン セグメントの長さを計算します。 ポリラインは軸に沿って配置されているため、マンハッタン距離は水平または垂直のみになります。 
2. ポリラインが閉じてからの最初と最後の釘を除く各釘について、前のセグメントと次のセグメントが垂直であることを確認して、角を形成しているかどうかを識別します。 その場合、この釘で必要なロッドの全長を、隣接する 2 つのセグメントの長さの合計として計算します。 
3. すべてのコーナーに必要なロッドの長さをすべてリストにまとめます。 
4. 必要な長さのリストと利用可能なロッドのリストの両方を並べ替えます。 
5. 必要な長さを繰り返し、必要な長さと少なくとも同じ長さの利用可能な最小のロッドを選択することにより、ロッドをコーナーに貪欲に割り当てます。 いずれかの時点でロッドが一致しない場合は、NO を出力します。 
6. 必要なロッドがすべて一致した場合は、各コーナー ネイルに使用されるロッドのインデックスが割り当てられ、他のネイルには -1 のマークが付けられるネイルの出力配列を作成します。 
7. YES に続いてロッド インデックスの配列を出力します。 

機能する理由: 各コーナーのロッドの長さは、2 つの垂直セグメントの合計によって正確に決まります。 ロッドの長さと必要なコーナーの長さの両方を分類することで、各ロッドが 1 回のみ使用されるという制約を尊重しながら、各コーナーに正確に適合するロッドが確実に取り付けられるようにします。 各釘はコーナーを形成する場合にのみロッドとして考慮されるため、同じ釘に複数のロッドを配置することは避けます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
nails = [tuple(map(int, input().split())) for _ in range(n)]
rods = list(map(int, input().split()))

# Compute lengths of segments
seg_lengths = []
for i in range(n):
    x1, y1 = nails[i]
    x2, y2 = nails[(i + 1) % n]
    seg_lengths.append(abs(x1 - x2) + abs(y1 - y2))

# Identify corners and required rod lengths
corners = []
for i in range(n):
    x0, y0 = nails[i - 1]
    x1, y1 = nails[i]
    x2, y2 = nails[(i + 1) % n]
    dx1, dy1 = x1 - x0, y1 - y0
    dx2, dy2 = x2 - x1, y2 - y1
    if dx1 * dx2 + dy1 * dy2 == 0:  # perpendicular
        corners.append((i, seg_lengths[i - 1] + seg_lengths[i]))

# Sort rods and required lengths
rods_sorted = sorted((length, idx) for idx, length in enumerate(rods, start=1))
corners_sorted = sorted(corners, key=lambda x: x[1])

assignment = [-1] * n
rod_used = [False] * m
ri = 0
success = True

for nail_idx, req_len in corners_sorted:
    while ri < m and rods_sorted[ri][0] < req_len:
        ri += 1
    if ri == m:
        success = False
        break
    rod_idx = rods_sorted[ri][1]
    assignment[nail_idx] = rod_idx
    ri += 1

if not success:
    print("NO")
else:
    print("YES")
    print(" ".join(map(str, assignment)))
```このソリューションでは、まず連続する釘間のマンハッタン距離を計算します。 次に、垂直に隣接するセグメントをチェックしてコーナーを検出します。 ロッドは、より長いロッドが必要なコーナーで小さなロッドが無駄にならないように、必要な長さの増加順に割り当てられます。 出力配列は、コーナー ネイルにロッド インデックスを配置し、それ以外の場所には -1 を配置します。 モジュロ演算子では、閉じたポリラインを包み込み、問題の要件に一致するようにロッド インデックスを 1 から開始するように特別な注意が払われます。
