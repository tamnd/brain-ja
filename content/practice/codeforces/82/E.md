 ## 解決策
 ## 問題の理解

 家を表す水平ストリップの外側に対称的に配置された 2 つの光源によって照らされる家の床の面積を計算するように求められます。 家は水平方向には無限に広がりますが、垂直方向には線で囲まれています$y = h$そして$y = -h$。 窓はこれらの上下の壁にあります。 各ウィンドウは水平セグメントであり、ウィンドウは水平正中線に関して対称です。$y = 0$。 光源は点にあります$(0, f)$上と$(0, -f)$家の下。 光は窓からしか入ってこないので、私たちの仕事はどのくらいの床面積が照らされるかを見つけることです。 

入力はウィンドウ ペアの数を指定します$n$、半分の高さ$h$、ライトの距離$f$、 そして$n$ウィンドウの左右の座標のペア。 制約は小さい$n$(最大 500)、ネストされたループを含むアルゴリズムが許可されます。$O(n^3)$あるいはさらに悪いことに。 家の高さは小さい (最大 10) ですが、ライトは遠くにある (最大 1000) 可能性があるため、交差点を正確に計算する必要があります。 重要なエッジ ケースは、ウィンドウが非常に小さい場合、またはライトが非常に遠くにある場合で、ライトの円錐が狭く、丸め誤差が大きくなる場合です。 

単純な間違いは、複数のウィンドウからの重複する寄与を無視することです。 たとえば、2 つの窓が近くにあると、床に照明が重なる台形が作成されることがあります。 個々の領域を不用意に合計すると、重複部分が二重にカウントされてしまいます。 単一のウィンドウに座標がある場合$[-1, 1]$そして$h = 1, f = 2$、台形面積の公式は期待どおりに機能します。 2 つのウィンドウが接触しているか非常に接近している場合、それらの照らされた領域を正しく結合することが重要です。 

## アプローチ

 強引な方法は、床を密な水平ストリップとしてシミュレートし、すべての窓セグメントから床に光線を投射し、照らされた点をマークすることです。 このアプローチは概念的には単純ですが、フロアが無限であるため実行不可能であり、スイープのポイントに離散化することさえ非効率的です。 と$n = 500$フロアに沿った何千ものポイントが存在する可能性があるため、操作数は爆発的に増加します。 

重要な洞察は、各窓が台形の照明領域を床に投影していることです。 台形の上部はウィンドウ自体であり、下端はウィンドウの端点から対応する光源まで線を延長することによって取得されます。 各台形は垂直方向に次の境界にあります。$y = 0$そして床は$y = -h$上のウィンドウの場合、または$y = h$下の窓用。 窓がついているので$y = h$そして$y = -h$、上部と下部の光源からの台形は鏡像であるため、1 つのセットを計算して 2 倍にすることができます。 台形の重複には、床レベルでの結合間隔が必要です。 

したがって、問題は、各窓セグメントを間隔として床に投影し、重複する間隔をマージし、台形面積公式を使用して総照明面積を計算することに帰着します。 窓から床への投影は、相似な三角形から導出される線形変換です。$(0, f)$そして窓は次の場所にあります$y = h$、次にウィンドウエンドポイント$x_i$次のようにフロアにマップされます$x_f = x_i * f / (f - h)$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O(n * 離散化) | O(離散化) | 遅すぎる |
 | 台形投影とマージ | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力値を読み取る$n$、$h$、$f$、そして$n$ウィンドウセグメント。 各セグメントは、$[l_i, r_i]$上壁と下壁の両方に。 
2. 各窓について、投影された床間隔を計算します。 上のウィンドウの場合、$y = h$そして明るい$(0, f)$、ライトからの光線を左右の端点を通って延長します。 相似な三角形を使用すると、これらの端点の床座標は次のようになります。$[l_i * f / (f - h), r_i * f / (f - h)]$。 下のウィンドウのマッピングは対称です。$[l_i * f / (f - h), r_i * f / (f - h)]$ミラーリングされた$y = 0$、同じ間隔を与えます。 
3. すべての間隔をリストに収集し、左側のエンドポイントで並べ替えます。 
4. 重複する間隔を結合します。 最初の間隔から開始して、ソートされたリストを繰り返し処理します。 現在の間隔が前のマージされた間隔と重複する場合は、前の間隔を延長してそれをカバーします。 それ以外の場合は、現在の間隔を新しいマージされた間隔として追加します。 
5. 結合された区間ごとに、台形の面積を計算します。 台形の上の幅は元の窓セグメントの長さと同じで、下の幅は投影された床セグメントと同じです。 台形の高さは$h$、エリアを与える$A = (top + bottom)/2 * height$。 これらの領域を合計します。 
6. 上部と下部のウィンドウの両方を考慮して、合計に 2 を掛けます。 

機能する理由: 光源を通して各ウィンドウを投影することで、照らされた領域を正確にキャプチャします。 間隔をマージすると、二重カウントが発生しなくなります。 台形の面積公式を使用すると、照明の実際のジオメトリが保存されます。 不変条件は、各ステップで、マージされた間隔が床上の別々の照明されたスパンを表すということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, h, f = map(int, input().split())
windows = [tuple(map(int, input().split())) for _ in range(n)]

# Compute projected floor intervals
intervals = []
for l, r in windows:
    scale = f / (f - h)
    intervals.append((l * scale, r * scale))

# Merge overlapping intervals
intervals.sort()
merged = []
for l, r in intervals:
    if not merged or l > merged[-1][1]:
        merged.append([l, r])
    else:
        merged[-1][1] = max(merged[-1][1], r)

# Compute total area using trapezoid formula
area = 0
for l, r in merged:
    idx = windows.index((l * (f - h) / f, r * (f - h) / f))
    top_width = r * (f - h) / f - l * (f - h) / f
    bottom_width = r - l
    area += (top_width + bottom_width) / 2 * h

# Double the area for both sides
print("%.10f" % (area * 2))
```このソリューションでは、まず光源比を使用して各窓を床に投影します。 間隔を並べ替えて結合することで、二重カウントを回避できます。 台形の面積は、上部と下部の幅の両方を使用して計算されます。 二重化により、上部と下部のウィンドウの対称性が考慮されます。
