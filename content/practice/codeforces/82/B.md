 ## 解決策
 ## 問題の理解

 いくつかの隠れた素集合のすべてのペア和集合が与えられます。 元のセット自体は表示されていません。 

隠れたセットが次のようになると仮定します。$S_1, S_2, \dots, S_n$。 すべてのペアについて$i \neq j$、セットが与えられています$S_i \cup S_j$。 これらの結合はシャッフルされるため、どのペアがどの行を生成したかはわかりません。 

元のセットはペアごとに素であり、これが重要な構造特性です。 すべての数値は、正確に 1 つの隠れたセットに属します。 

私たちのタスクは、元のセットの有効なコレクションを再構築することです。 

制約は十分に小さいため、入力行数で二次関数を処理することができます。 がある$n(n-1)/2$労働組合、および$n \le 200$, つまり最大でも約20,000行です。 各行には最大 200 個の整数が含まれます。 アン$O(m^2)$すべての結合に対するアルゴリズムはすでに不快なものになっているでしょう。$m \approx 20{,}000$、何億もの比較を行います。 すべてのペアを他のすべてのペアと照合するのではなく、素結合の構造を利用する必要があります。 

最も危険なエッジケースは、非表示のセットに要素が 1 つだけ含まれている場合です。 次に、その要素を含むすべての共用体は、値が 1 つだけ異なる他の集合と異なります。 

例えば：```
n = 3
A = {1}
B = {2}
C = {3,4}
```組合は次のとおりです。```
{1,2}
{1,3,4}
{2,3,4}
```周波数のみからセットを推測しようとする不用意なアプローチでは、シングルトン セットが誤ってマージされやすくなります。 

別の微妙なケースが現れるのは、$n=2$。 この場合、結合は 1 つだけ、つまり 2 つの隠れたセットの結合だけになります。 その共用体を 2 つの空でないサブセットに分割することは有効です。 

例：```
2
3 1 2 3
```有効な答えの 1 つは次のとおりです。```
1 1
2 2 3
```すべての元のセットを一意に識別するのに十分な情報が存在すると仮定したソリューションは、ここでは失敗します。 

3 番目のトラップは、すべての元のセットが入力のどこかに直接出現すると仮定することです。 そんなことは決してありません。 すべての行は常に 2 つの異なるセットの和集合です。 

考慮する：```
A = {1,2}
B = {3}
C = {4}
```入力共用体:```
{1,2,3}
{1,2,4}
{3,4}
```セット`{1,2}`明示的に現れることはありませんが、それでも再構築する必要があります。 

## アプローチ

 ブルートフォース戦略では、すべての数値を非表示のグループに分割し、生成されたペアごとの和集合が入力と一致するかどうかを検証しようとします。 各値を次のいずれかに割り当てることだけを考えたとしても、$n$を設定すると、検索スペースは指数関数的に増加します。 最大 200 個の異なる番号がある場合、完全な再構成は不可能です。 

ブルートフォースのアイデアは、入力の主なプロパティを公開するため、概念的には依然として有用です。つまり、すべての数値は常に、それ自体の非表示セットのすべての要素と一緒に移動します。 

元のセットが次のようなものであると仮定します。$$S = \{a,b,c\}$$を含むすべての共用体`a`も含まれています`b`そして`c`なぜなら、和集合は集合全体から形成されるからです。 その逆もまた真です。 一方のセットを含み、他方のセットを含まない結合が存在するため、異なる非表示セットの要素が常に一緒に表示されるわけではありません。 

この観察により、問題はグループ化タスクに変わります。 

それぞれの値について$x$を含むすべての和集合線のインデックスを収集します。$x$。 2 つの数値は、これらのコレクションが同一である場合に限り、同じ非表示セットに属します。 

なぜこれが機能するのでしょうか?

 もし$x$そして$y$同じ元のセットに属している場合、すべての共用体には両方が含まれるか、どちらも含まれません。 それらの出現パターンは同一です。 

それらが異なるセットに属している場合は、以下を含むセットによって形成される和集合を考慮します。$x$そしてそれとは関係のない3番目のセット$y$。 その結合には次のものが含まれます$x$しかしそうではありません$y$。 それらのパターンは異なります。 

したがって、隠れたセットはまさに、等しい出現パターンの同値クラスです。 

唯一の例外は、$n=2$。 和集合行は 1 つだけであるため、すべての数値はまったく同じ行セットに表示されます。 元のセットを一意に区別することはできません。 空でないパーティションは機能します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | 指数 | 遅すぎる |
 | 最適 |$O(M \cdot K)$|$O(M \cdot K)$| 承認済み |

 ここ$M = n(n-1)/2$は和集合線の数であり、$K$すべての行にわたる整数の合計数です。 

## アルゴリズムのチュートリアル

 1. すべての共用体行を読み取り、各行にインデックスを割り当てます。 

これらのインデックスが必要なのは、各値が表示される場所を比較することであるためです。 
2. すべての整数値について$x$、行インデックスのリストを作成します。$x$が発生します。 

例：```
value 7 -> [0, 3, 5]
value 2 -> [1, 2, 4]
```これらの出現パターンは、隠れたセットを一意に識別します。 
3. 値を同一の出現パターンごとにグループ化します。 

キーが行インデックスのタプルである辞書を使用できます。 

この方法で作成されたすべてのグループは、1 つの元の隠しセットに対応します。 
4. 特殊なケースに対処する$n=2$。 

和集合線は 1 つだけであるため、すべての値は同じパターンになります。 元のパーティションを一意に復元することはできません。 

有効なパーティションはどれでも受け入れられるため、1 つの数値を最初のセットに配置し、残りのすべての数値を 2 番目のセットに配置します。 
5. 再構成されたすべてのグループを出力します。 

### なぜ効果があるのか

 すべての和集合線は、2 つの完全な隠れセットを取得することによって形成されます。 

2 つの数値が同じ非表示セットに属している場合、それらは常にすべての和集合行に一緒に表示されます。 それらの出現パターンは同一です。 

2 つの数値が異なる隠しセットに属している場合、一方を含み他方を含まない和集合線が少なくとも 1 つ存在します。 それらの発生パターンは異なります。 

したがって、出現パターンが等しいということは、同じ隠れたセットに属していることとまったく同じです。 これらのパターンでグループ化すると、すべての元のセットが正しく再構成されます。 

## Python ソリューション```python
import sys
from collections import defaultdict

input = sys.stdin.readline

def solve():
    n = int(input())

    m = n * (n - 1) // 2

    lines = []
    occ = defaultdict(list)

    for idx in range(m):
        arr = list(map(int, input().split()))
        vals = arr[1:]

        lines.append(vals)

        for x in vals:
            occ[x].append(idx)

    # Special case: n = 2
    if n == 2:
        all_values = sorted(occ.keys())

        print(1, all_values[0])

        second = all_values[1:]
        print(len(second), *second)
        return

    groups = defaultdict(list)

    for x, pattern in occ.items():
        groups[tuple(pattern)].append(x)

    result = list(groups.values())

    for group in result:
        print(len(group), *group)

if __name__ == "__main__":
    solve()
```最初のセクションでは、すべての和集合行を読み取り、各数値が出現する場所を記録します。 辞書`occ`値を、その値を含む行インデックスのリストにマップします。 

実装の重要な詳細は、インデックスの順序を維持することです。 行は順次処理されるため、すべての出現リストは自動的にソートされます。 これにより、タプルを辞書キーとして安全に使用できるようになります。 

特別な場合`n == 2`別途取り扱いが必要です。 これがないと、和集合線が 1 つしかないため、すべての値が 1 つのグループにまとめられてしまいます。 問題ステートメントは有効な再構成を受け入れるため、1 つの値を残りから分離するだけで十分です。 

グループ化フェーズはソリューションの中心です。 2 つの数値は、出現タプルが一致する場合に、同じ再構築セットに正確に配置されます。 

出力は任意の順序で実行できるため、グループを並べ替える必要はありません。

import sys
import io
from collections import defaultdict

def solve():
    input = sys.stdin.readline

    n = int(input())

    m = n * (n - 1) // 2

    occ = defaultdict(list)

    for idx in range(m):
        arr = list(map(int, input().split()))

        for x in arr[1:]:
            occ[x].append(idx)

    if n == 2:
        vals = sorted(occ.keys())

        print(1, vals[0])

        other = vals[1:]
        print(len(other), *other)
        return

    groups = defaultdict(list)

    for x, p in occ.items():
        groups[tuple(p)].append(x)

    for g in groups.values():
        print(len(g), *g)

    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out

    solve()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.getvalue().strip()

 ## 特殊なケース

 最小の有効な入力を考えてみましょう。```
2
2 1 2
```ユニオンラインは 1 つだけです。 両方の数字がまったく同じ場所に表示されます。 

| 値 | パターン |
 | --- | --- |
 | 1 | (0,) |
 | 2 | (0,) |

 一般的なグループ化ロジックでは、誤って単一のセットが生成されてしまいます。`{1,2}`。 アルゴリズムが検出するのは、`n == 2`代わりに、空ではないセットを 2 つ手動で作成します。 

ここでシングルトンの隠れセットを考えてみましょう。```
3
2 1 2
2 1 3
2 2 3
```隠れたセットは、`{1}`、`{2}`、`{3}`。 

パターン:

 | 値 | パターン |
 | --- | --- |
 | 1 | (0,1) |
 | 2 | (0,2) |
 | 3 | (1,2) |

 すべてのパターンは異なるため、すべてのシングルトンが正しく再構築されます。 

最後に、セット サイズが等しくない場合を考慮します。```
3
3 1 2 3
3 1 2 4
2 3 4
```隠れたセットは、`{1,2}`、`{3}`、`{4}`。 

パターン:

 | 値 | パターン |
 | --- | --- |
 | 1 | (0,1) |
 | 2 | (0,1) |
 | 3 | (0,2) |
 | 4 | (1,2) |

 価値観`1`そして`2`同じ出現パターンを共有するため、それらは一緒にグループ化されます。 シングルトン セットはパターンが異なるため、分離されたままになります。
