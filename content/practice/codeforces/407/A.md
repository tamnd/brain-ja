 ## 解決策
 ## 問題の理解

 2 つの正の整数が与えられます。`a`そして`b`、直角三角形の足の長さです。 タスクはそのような三角形が存在するかどうかを確認することではなく、明らかに存在します。 代わりに、3 つの頂点すべてが整数座標を持ち、どの辺もどちらの座標軸にも平行にならないように、その三角形を整数格子上に配置する必要があります。 

この問題を考えるのに役立つ方法は、長さが正確に一致する 2 つの垂直ベクトルを構築することです。`a`そして`b`。 1 つの頂点を原点に配置すると、これらのベクトルに沿って移動することで他の 2 つの頂点を取得できます。 結果として得られる三角形は自動的に直角になります。 

制限は非常に小さいです。 両方`a`そして`b`これは、平方和が以下になるすべての整数座標ペアを列挙する余裕があることを意味します。`a²`または`b²`。 たとえ`O(1000²)`検索は完全に安全です。 

主な困難はパフォーマンスではなく、ジオメトリです。 整数の座標、直角、規定の辺の長さが必要であり、さらに、どの辺も水平または垂直であってはなりません。 

簡単な間違いの 1 つは、明らかな三角形を構築することです```
(0,0), (a,0), (0,b)
```たとえば、入力の場合```
3 4
```これは辺の長さは正しいですが、2 つの辺が座標軸に平行であるため、無効です。 

もう 1 つの罠は、正しい長さの整数ベクトルを見つけても、それらが同じ線上にあることを許可することです。 たとえば、両方のベクトルが同じ方向を向いている場合、3 つの点は同一線上にあり、三角形を形成しません。 

より微妙なケースは、整数分解が存在しない場合です。 入力用```
1 1
```長さ 1 の整数ベクトルは次のとおりです。`(±1,0)`そして`(0,±1)`。 これらを使用した構築では、必然的に軸に平行な側面が作成されます。 正しい答えは、```
NO
```また、「軸に平行な辺がない」条件を強制せずに長さのみをチェックするソリューションでは、誤って三角形が出力されます。 

## アプローチ

 強引なアイデアは、大きなボックス内の 3 つの頂点のすべての整数座標を検索し、あらゆる可能性をテストすることです。 最終的にはすべての有効な三角形が検査されるため、このようなアプローチは明らかに正しいです。 問題は、辺の長さが 2000 のボックスにも数百万の格子点が含まれており、トリプルの数が天文学的に大きくなるということです。 

問題の構造により、より適切に表現できるようになります。 三角形は直角なので、原点に直角を置くことができます。 1 本の脚をベクトルで表すとします。```
(x1, y1)
```長さのある`a`、もう一方はベクトルによる```
(x2, y2)
```長さのある`b`。 

ベクトルは次の条件を満たさなければなりません```
x1² + y1² = a²
x2² + y2² = b²
```そしてそれらは垂直でなければなりません:```
x1*x2 + y1*y2 = 0
```重要な観察は、次のような場合です。`(x1, y1)`が既知の場合、垂直ベクトルは次のようになります。```
(-y1, x1)
```または```
(y1, -x1)
```これらは次とまったく同じ長さです`(x1, y1)`。 

整数を見つけたとします`(x, y)`そのような```
x² + y² = a².
```次にベクトル```
(-y, x)
```長さがある`a`。 長さの垂直ベクトルを取得するには`b`、それをスケールすることができます`b / a`:```
(-y*b/a, x*b/a)
```このベクトルが整数の座標を持つには、両方の`y*b`そして`x*b`で割り切れる必要があります`a`。 

分数で推論するのではなく、すべての整数のペアを直接列挙できます。`(x, y)`満足のいく```
x² + y² = a²
```すべての整数のペア`(u, v)`満足のいく```
u² + v² = b².
```次に、ペアを見つけるだけで済みます。```
x*u + y*v = 0.
```境界が狭いため、この検索は簡単です。 

最も受け入れられている解決策で使用されているさらに単純な観察があります。 ゼロ以外の整数のペアをすべて列挙します`(x, y)`と```
x² + y² = a².
```それから取ってください```
(u, v) = (-y, x).
```これは自動的に垂直になり、長さが決まります`a`。 

長さが欲しい場合`b`、スケーリング係数を探すことができます```
k = b / a
```それは座標を統合的に保ちます。 同様に、次の別の分解を検索します。`b²`直角方向と一致しているか確認してください。 

標準的に受け入れられている実装では、次のすべての分解が列挙されます。`a²`そして、対応するスケーリングされた垂直座標が整数であるかどうかを直接テストします。

 | 円上の格子ベクトルを列挙する | O(a + b) から O(1000²) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 直角の頂点を次の位置に固定します。`(0,0)`。 
2. すべての正の整数を列挙します`x`から`1`に`a-1`。 
3. コンピューティング```
y² = a² - x².
```もし`y²`これは完全な正方形ではありません`x`長さの整数ベクトルに属することはできません`a`。 
4. しましょう`y = sqrt(y²)`。 ケースをスキップする`y = 0`それは軸に平行な側面を作成することになるからです。 
5. 垂直方向を考慮する`(-y, x)`。 その長さもまた、`a`。 
6. この垂直ベクトルをスケールします。`b / a`。 候補となる座標は、```
X = -y*b/a
Y = x*b/a.
```7. 両方があるかどうかを確認します`X`そして`Y`は整数です。 これはチェックに相当します```
(y*b) % a == 0
(x*b) % a == 0.
```8. 両方の割り算条件が成立し、どちらの座標もゼロにならない場合、出力```
(0,0)
(x,y)
(X,Y)
```そして終了します。 
9. すべての分解が成功せずに実行された場合、出力`"NO"`。 

### なぜ効果があるのか

 最初の脚はベクトルです`(x,y)`、長さは正確に`a`満足するから`x²+y²=a²`。 

2 番目の脚は垂直ベクトルから取得されます。`(-y,x)`そしてスケール`b/a`。 スケーリングすると長さが次のように変わります。`a`に`b`直角度を維持しながら。 したがって、2 つの脚ベクトルの内積はゼロのままであるため、原点での角度は直角になります。 

割り算チェックにより、整数座標が保証されます。 ゼロ座標を除外すると、どの辺も水平または垂直になることがなくなります。 原点で直角を持つすべての有効な構造は、ある長さの格子ベクトルに対応します。`a`したがって、列挙では解を見逃すことはできません。 

## Python ソリューション```python
import sys
from math import isqrt

input = sys.stdin.readline

a, b = map(int, input().split())

for x in range(1, a):
    y2 = a * a - x * x
    y = isqrt(y2)

    if y * y != y2 or y == 0:
        continue

    if (y * b) % a != 0:
        continue
    if (x * b) % a != 0:
        continue

    X = -(y * b) // a
    Y = (x * b) // a

    if X == 0 or Y == 0:
        continue

    print("YES")
    print(0, 0)
    print(x, y)
    print(X, Y)
    sys.exit()

print("NO")
```コードは幾何学的構造に直接従います。 

ループは、長さのすべての整数格子ベクトルを列挙します。`a`正の座標で。 各候補について、式は次のようになります。```
y2 = a * a - x * x
```残りの平方を計算します。 使用する`isqrt`かどうかをテストする際の浮動小数点精度の問題を回避します。`y2`は完全な正方形です。 

可算性チェックはソリューションの中核です。 彼らは、垂直ベクトルを次のようにスケーリングすることを検証します。`b/a`両方の座標を整数に保ちます。 これらのチェックがないと、整数の除算によって値が自動的に切り捨てられ、不正な三角形が生成されてしまいます。 

最後の守り人```
if X == 0 or Y == 0:
```軸に平行な側面を導入する構造を削除します。 

有効な構成が見つかると、プログラムはそれをすぐに出力して終了します。 有効な三角形であればどれでも受け入れられるため、検索を続ける必要はありません。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io
from math import isqrt

def solve():
    a, b = map(int, input().split())

    for x in range(1, a):
        y2 = a * a - x * x
        y = isqrt(y2)

        if y * y != y2 or y == 0:
            continue

        if (y * b) % a != 0:
            continue
        if (x * b) % a != 0:
            continue

        X = -(y * b) // a
        Y = (x * b) // a

        if X == 0 or Y == 0:
            continue

        print("YES")
        print(0, 0)
        print(x, y)
        print(X, Y)
        return

    print("NO")

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout
    return out

# provided sample
assert run("1 1\n") == "NO\n"

# custom cases
assert run("5 10\n").startswith("YES")
assert run("2 2\n") == "NO\n"
assert run("3 4\n") == "NO\n"
assert run("1000 1000\n").startswith("YES")

 |`3 4`| いいえ | 古典的なピタゴラスの長さですが、制約の下では配置は不可能です |
