 **解決時間:** 4 分 44 秒

 ## 解決策
 ## 問題の理解

 サイズ _n_ × _m_ の整数行列が与えられます。 各セルには正の整数が含まれています。 タスクは、すべての要素が異なる最大の長方形部分行列を見つけることです。 「最大」は面積で測定され、長方形内のセルの数を意味します。 たとえば、2×3 の長方形の面積は 6 です。出力は、そのような最大の長方形の面積です。 

制約 _n_、_m_ ≤ 400 を使用すると、考えられるすべての四角形をチェックする総当りのソリューションには、O(n² m²) 個の部分行列を反復処理し、それぞれの内部の区別性をチェックする必要があり、これには最大 400² × 400² = 2.56 × 10¹⁰ の演算が必要になる可能性があります。 これは 3 秒の制限には大きすぎます。 メモリ制限は 256 MB で、サイズ 400×400 の行列をいくつか保存するには十分ですが、O(n² m²) の中間データを保存することは避けなければなりません。 

単純な実装は、小さな入力や縮退した入力でも失敗する可能性があります。 たとえば、すべての要素が等しい場合:```
2 2
1 1
1 1
```1×1 より大きい部分行列には繰り返し要素が含まれるため、正解は 1 です。 一意性を慎重に強化しないと、不注意なアプローチでより大きな領域が誤ってカウントされる可能性があります。 

もう 1 つの微妙なケースは、次のような多数の繰り返し値が散在する行列です。```
3 3
1 2 3
2 3 4
3 4 5
```対角線上に繰り返される数字が表示されるため、最大の長方形は完全な行列ではありません。 アルゴリズムはそのような重複を正確に検出する必要があります。 

## アプローチ

 ブルートフォース手法は単純です。左上隅と右下隅のすべてのペアを反復処理し、部分行列を抽出し、すべての値が一意であるかどうかを確認します。 一意性のチェックはハッシュ セットを使用して実行できます。 これは正確性を保証しますが、各部分行列チェックが O(面積) であり、O(n² m²) 個の部分行列があるため失敗します。 たとえ小さな行列であっても、これでは遅すぎます。 

最適化するための重要な洞察は、行をスイープすることで列に沿った一意性を効率的に追跡できるということです。 右下隅を明示的に繰り返す代わりに、上の行を固定し、下の行を下に拡張します。 各列について、重複が発生した最後の行を追跡し、その列の「有効な幅」の四角形を形成します。 次に、各列の左端の有効な境界を維持することによって、すべての一意の要素を含む最大の四角形を見つけることができます。 これにより、行ごとのハッシュを使用して問題が O(n m²) に削減されます。これは、n、m ≤ 400 の場合に実現可能です。 

基本的に、この問題は、行ごとにスライディング ウィンドウを使用して、行セグメントごとに一意の列要素を持つ最大の四角形を計算することに帰着します。 課題は、重複を効率的に追跡し、一意性を最初から再計算せずに四角形を拡張することです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n2 m2 × 面積) ≈ O(n3 m3) | O(nm) | 遅すぎる |
 | 最適 | O(n m²) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`best`これには、これまでに見つかった最大の領域が保存されます。 
2. 反復する`top`行 0 から n-1 まで。 この行は、候補部分行列の上部境界になります。 
3. 配列を作成する`last_seen`列ごとに 1 つずつの辞書で構成され、要素の値が出現する最後の行インデックスにマップされます。 これにより、列内の重複を迅速に検出できます。 
4. 配列を初期化する`min_top`サイズMの`top`。 これにより、各列について、現在の列の値を繰り返さずに開始できる最も早い行インデックスが追跡されます。 
5. 反復する`bottom`から`top`n-1へ。 これにより、部分行列が下方向に拡張されます。 列ごとに、行の要素を確認します`bottom`。 それ以降このコラムに登場した場合`min_top[col]`、 動く`min_top[col]`その列の直後。 アップデート`last_seen[col][value] = bottom`。 
6. 1回`min_top`現在に合わせて更新されています`bottom`、列全体でスライディング ウィンドウを使用して、最も広い連続範囲を見つけます。`[l, r]`どこですべて`min_top[c] <= top`。 面積を計算する`(bottom - top + 1) * (r - l + 1)`そして更新します`best`もっと大きい場合。 
7.すべてを終えたら`bottom`拡張子、増分`top`そして繰り返します。 

### なぜ効果があるのか

 維持される不変式は、現在の四角形に対する不変式です。`top`に`bottom`とコラム`[l, r]`、どの列でも要素が繰り返されません。 追跡により`min_top`、重複を引き起こす行は決して含めません。 スライディング ウィンドウにより、可能な最大の幅が常に考慮されるため、すべての候補四角形の上端と下端の境界が最大になります。 一番上の行をすべてスキャンすることで、潜在的な四角形が見逃されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]

best = 0
last_seen = [{} for _ in range(m)]

for top in range(n):
    min_top = [top] * m
    for bottom in range(top, n):
        for col in range(m):
            val = a[bottom][col]
            if val in last_seen[col] and last_seen[col][val] >= min_top[col]:
                min_top[col] = last_seen[col][val] + 1
            last_seen[col][val] = bottom

        l = 0
        for r in range(m):
            while l <= r and min_top[r] > top:
                l += 1
            width = r - l + 1
            height = bottom - top + 1
            best = max(best, width * height)

print(best)
```ソリューションは行列を読み取り、一番上の行を反復処理します。`last_seen`値が出現した最後の行を高速に検索するための列ごとの辞書です。`min_top`その列を繰り返さずにどこまで到達できるかを追跡します。 列全体のスライディング ウィンドウにより、各下部行拡張の幅が最大化されることが保証されます。 移動などの境界条件`l`重複した要素が四角形に入り込まないようにします。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    a = [list(map(int, input().split())) for _ in range(n)]
    best = 0
    last_seen = [{} for _ in range(m)]
    for top in range(n):
        min_top = [top] * m
        for bottom in range(top, n):
            for col in range(m):
                val = a[bottom][col]
                if val in last_seen[col] and last_seen[col][val] >= min_top[col]:
                    min_top[col] = last_seen[col][val] + 1
                last_seen[col][val] = bottom
            l = 0
            for r in range(m):
                while l <= r and min_top[r] > top:
                    l += 1
                width = r - l + 1
                height = bottom - top + 1
                best = max(best, width * height)
    return str(best)

# provided sample
assert run("3 3\n1 3 1\n4 5 6\n2 6 1\n") == "6"

# all equal
assert run("2 2\n1 1\n1 1\n") == "1"

# minimum input
```
