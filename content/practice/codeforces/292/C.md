 ## 解決策
 ## 問題の理解

 10 進数のセットが与えられます。 0 ～ 255 の 4 つの整数で構成されるすべての IP アドレスを検索し、ドットなしで 4 つの数字を並べて書いた後の文字列が回文になるようにする必要があります。 

桁制限が厳しいです。 指定されたセットのすべての数字はアドレス内のどこかに少なくとも 1 回出現する必要があり、セット外の数字は出現してはなりません。 

明らかな解釈は、すべての可能な IP アドレスを反復処理することです。 つまり、すべての 4 回転をチェックすることになります。`(a, b, c, d)`それぞれの値を`[0, 255]`。 がある`256^4 ≈ 4.3 × 10^9`2秒以内に候補者を決定することは完全に不可能です。 

制約により、はるかに小さな検索スペースが隠蔽されます。 各 IP 部分には 1 ～ 3 桁の 10 進数があるため、連結された文字列の長さは 4 ～ 12 になります。最大 12 の長さの回文は、その前半部分によって完全に決まります。 10 桁すべてが許可される場合でも、回文の数はおよそ$$10^2 + 10^3 + 10^3 + 10^4 + \cdots + 10^6 \approx 1.1 \times 10^6,$$十分小さいです。 

簡単な間違いがいくつかあります。 

よくあるのは、通常の小数表現の規則を忘れることです。 部分文字列`"01"`複数桁の数字はゼロで始まることができないため、IP 部分を表すことはできません。 たとえば、回文文字列`"0110"`次のように分割できます`"0"`、`"1"`、`"1"`、`"0"`、しかしそうではありません`"01"`、`"1"`、`"0"`。 

もう 1 つの罠は、許可された数字を超えるすべての回文が有効であると想定していることです。 桁セットを考慮する`{9}`。 回文`"9999"`存在しますが、分割`"999"`、`"9"`、`"9"`、`"9"`は無効です。`999 > 255`。 

3 番目の間違いは、必要なすべての数字が表示されていることだけをチェックし、他の数字を禁止するのを忘れていることです。 この問題では、アドレスで使用される数字セットが指定されたセットと正確に一致する必要があります。 

## アプローチ

 ブルート フォース ソリューションでは、すべての IP アドレスが列挙されます。 それぞれの 4 倍数について、4 つの 10 進表現を連結し、結果の文字列が回文であるかどうかを確認し、桁セットを検証できます。 すべての候補者が検査されるため、正しさはすぐにわかります。 

問題は探索空間のサイズです。 40 億を超えるアドレスをチェックする必要がありますが、これは制限をはるかに超えています。 

重要な観察は、回文条件が IP 条件よりもはるかに強いということです。 連結された文字列の長さは最大 12 であるため、最初に回文を生成し、その後で 4 つの有効な IP 部分に分割できるかどうかを尋ねる方が自然です。 

固定長の場合`L`、最初だけ`ceil(L/2)`ポジションは自由です。 これらの数字が選択されると、残りの回文が強制されます。 以来`L ≤ 12`、自由部分の長さは最大 6 です。 

回文文字列を生成した後は、その長さをサイズ 1、2、または 3 の 4 つの部分に分割する可能な方法をテストするだけで済みます。そのような長さのパターンは 19 個しかありません。$$l_1+l_2+l_3+l_4=L,\qquad 1\le l_i\le 3.$$各パターンから得られる候補 IP アドレスは最大 1 つです。 

すべての有効なアドレスが何らかの回文に対応するため、ブルート フォースは機能しますが、膨大な IP 空間を探索するため失敗します。 回文優先ビューでは、検索がおよそ 100 万個の生成された文字列に削減され、管理が容易になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべての IP に対するブルート フォース | O(256⁴) | お(1) | 遅すぎる |
 | 回文を生成して分割する | O(∑ n^⌈L/2⌉) | O(答え) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 許可されている数字を読み取り、マスク内の各数字にビットを割り当てます。 
2. 可能なすべての回文の長さについて`L`4時から12時まで、`h = (L + 1) // 2`。 最初だけ`h`ポジションを選択する必要があります。 
3. 深さ優先検索を使用して、同じ長さのすべての文字列を生成します`h`許可された数字のみを使用します。 半文字列を構築する際、許可された数字が表示されるビットマスクを維持します。 
4. 半文字列が完成したら、そのマスクが許可されているすべての数字のマスクと等しい場合にのみ、それを保持します。 回文に現れる数字はすべて前半にすでに現れている必要があるため、この条件により、必要なすべての数字が存在することが保証されます。 
5. 半分の文字列から完全な回文を構築します。 
6. 長さの 4 倍をすべて列挙する`(l₁, l₂, l₃, l₄)`各値は 1 ～ 3 で、全長は`L`。 
7. それらの長さに応じて回文を分割します。 
8. 各セグメントについて、それが数値の有効な 10 進表現であるかどうかを確認します。`[0,255]`。 1 を超える長さのセグメントは、以下で始めることはできません。`'0'`。 
9. 成功したすべての分割は、有効な美しい IP アドレスに対応します。 保管してください。 
10. すべての長さと回文を処理した後、収集したアドレスを印刷します。 

### なぜ効果があるのか

 すべての有効な回答は、長さが 4 ～ 12 の回文文字列を生成します。生成フェーズでは、すべての回文がそのような長さの許可された桁数にわたって列挙されるため、対応する文字列が生成されることが保証されます。 

固定回文文字列の場合、考えられるすべての IP 表現で、文字列を長さが 1 ～ 3 の 4 つの部分に分割する必要があります。アルゴリズムは、そのような長さの組み合わせをすべてテストします。 分割は、4 つのセグメントすべてが 0 ～ 255 の有効な 10 進表現である場合にのみ受け入れられます。 

したがって、すべての有効なアドレスが見つかり、生成されたすべてのアドレスがすべての要件を満たします。 アルゴリズムは完全かつ健全です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

digits = list(map(int, input().split())) if False else None

def solve():
    n = int(input())
    digs = list(map(int, input().split()))

    chars = [str(x) for x in digs]

    bit = {}
    for i, d in enumerate(digs):
        bit[str(d)] = 1 << i

    full_mask = (1 << n) - 1

    patterns = [[] for _ in range(13)]
    for a in range(1, 4):
        for b in range(1, 4):
            for c in range(1, 4):
                for d in range(1, 4):
                    patterns[a + b + c + d].append((a, b, c, d))

    ans = []

    for L in range(4, 13):
        h = (L + 1) // 2
        half = [''] * h

        def dfs(pos, mask):
            if pos == h:
                if mask != full_mask:
                    return

                left = ''.join(half)

                if L % 2 == 0:
                    s = left + left[::-1]
                else:
                    s = left + left[:-1][::-1]

                for lens in patterns[L]:
                    p = 0
                    parts = []
                    ok = True

                    for ln in lens:
                        seg = s[p:p + ln]
                        p += ln

                        if ln > 1 and seg[0] == '0':
                            ok = False
                            break

                        if int(seg) > 255:
                            ok = False
                            break

                        parts.append(seg)

                    if ok:
                        ans.append('.'.join(parts))
                return

            for ch in chars:
                half[pos] = ch
                dfs(pos + 1, mask | bit[ch])

        dfs(0, 0)

    out = [str(len(ans))]
    out.extend(ans)
    sys.stdout.write("\n".join(out))

solve()
```外側のループは、可能なすべての回文長にわたって反復されます。 後半は対称性によって強制されるため、各長さについて前半のみが生成されます。 

DFS は数字マスクを維持します。 これは、桁の周波数を数えるよりもはるかに安価です。 半文字列が完成すると、マスクは必要なすべての数字が少なくとも 1 回出現したかどうかをすぐに示します。 

回文の再構築は、偶数長と奇数長でわずかに異なります。 奇数長の場合、中央の文字を重複させてはなりません。 

スプリットフェーズでは、事前に計算された長さのパターンが使用されます。 該当するパターンは全部で 19 個しかないので、すべてをチェックするのはコストがかかりません。 

先行ゼロのルールは見落とされやすいです。 文字列`"0"`有効ですが、`"00"`そして`"01"`そうではありません。 実装では、セグメントを整数に変換する前にこれを処理します。

 ## 特殊なケース

 次の数字セットを考えてみましょう。```
1
0
```回文`"0000"`存在します。 分割`"0"`、`"0"`、`"0"`、`"0"`有効ですが、`"00"`複数桁の数値はゼロで始めることができないため、有効なセグメントではありません。 アルゴリズムは、先行ゼロ チェックを通じてそのようなセグメントを拒否します。 

考慮する：```
1
9
```回文`"9999"`が生成されます。 セグメント`"999"`255 を超えるため、そのセグメントを使用した分割は拒否されます。 数値範囲チェックはこれを自動的に処理します。 

考慮する：```
2
1 2
```回文`"1111"`DFS 中に生成されますが、その数字マスクには数字のみが含まれます`1`。 マスクは必要な完全なマスクと等しくないため、回文は分割が試行される前に破棄されます。 これにより、必要なすべての数字が少なくとも 1 回出現することが保証されます。
