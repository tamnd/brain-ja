 ## 解決策
 ## 問題の理解

 昨日ガリア人が敗北した`n`ローマの兵士たちと、`n`は素数であることが保証されています。 今日彼らは負けた`m`兵士、どこ`m > n`。 どうかを決める必要があります。`m`まさにその直後に来る次の素数です`n`。 

重要な詳細は「次のプライム」というフレーズです。 両方の数値が素数であるだけでは十分ではありません。 それらの間に他の素数があってはなりません。 

制約はわずかです。 どちらの数値も最大 50 であるため、非常に遅い総当たりチェックでも制限時間内であれば快適に動作します。 ここでは、数値の平方根までの試算による素数性テストに必要な操作はわずかです。 すべての数字をチェックしても`n + 1`上向きは事実上瞬時です。 

主な危険は、何が次のプライムに該当するかを誤解することです。 

次の入力を考えてみましょう。```
3 7
```正しい答えは次のとおりです。```
NO
```3 と 7 は両方とも素数ですが、5 はそれらの間にあり、素数でもあります。 かどうかをチェックするだけの不用意な実装`m`素数だと誤って印刷されてしまう`YES`。 

もう 1 つの簡単な間違いは、次の素数を探しているときに停止するのが遅すぎることです。 

例えば：```
7 11
```8、9、10 は合成であるため、7 の次の素数は実際には 11 になります。 アルゴリズムは、素数が連続する奇数であると仮定するのではなく、素数以外の数を正しくスキップする必要があります。 

最後のエッジ ケースは、最小の有効な入力です。```
2 3
```答えは次のとおりです。```
YES
```2 が最初の素数なので、その次の素数は 3 になります。 

## アプローチ

 最も直接的なアプローチは、以下の素数をすべて生成することです。`n`到達するまで`m`。 各整数の素数性を繰り返しテストし、素数を収集することができます。 より大きい最初の素数が見つかったら、`n`と比較します。`m`。 

制約が非常に小さいため、これが機能します。 最悪の場合、最大 50 までの数値をチェックし、素数性テストでは少数の約数のみを検査します。 非効率な実装でも即座に実行されます。 

少し異なる総当たりのアイデアは、ネストされたループを使用して最大 50 までのすべての素数を事前計算し、リストをスキャンして`m`すぐに続きます`n`。 それも制限内であれば快適に動作します。 

よりクリーンな解決策は、すべての素数が必要ないという単純な観察を使用します。 必要なのは、次より大きい最初の素数だけです`n`。 

したがって、すべてを生成するのではなく、次のことから始めます。`n + 1`素数が見つかるまで上方向に検索します。 最初の素数は、定義上、次の素数です。`n`。 等しい場合`m`、答えは`YES`; それ以外の場合はそうです`NO`。 

これにより、タスクが 2 つの小さなコンポーネントに減ります。 

1. 数値が素数かどうかをチェックする関数。 
2. より大きい最初の素数を見つけるループ`n`。

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`そして`m`。 
2. ヘルパー関数を作成する`is_prime(x)`かどうかをチェックします`x`プライムです。 

2 と 2 の間に約数がない数値は素数です`√x`。 約数が存在する場合、その数値は合成されます。 
3. 次から整数のチェックを開始します。`n + 1`上向きに。 

より大きい最初の素数を探しています。`n`。 
4. 候補番号ごとに、次の電話番号に電話します。`is_prime(candidate)`。 

数値が素数でない場合は、検索を続けます。 
5. 最初の素数が見つかったらすぐに、それを次のものと比較します。`m`。 

それらが等しい場合、出力します`YES`。 それ以外の場合は印刷します`NO`。 
6. 最初の素数を見つけたらすぐに停止します。 

直後の次の素数のみを考慮します。`n`。 

### なぜ効果があるのか

 このアルゴリズムは、整数を次から昇順に検索します。`n + 1`。 素数性テストに合格する最初の数値は、正確に次の値より大きい最小の素数です。`n`、次の素数の数学的定義と一致します。 

この数値が等しい場合`m`、 それから`m`の次の素数です`n`。 異なる場合は`m`、その後、どちらか`m`が素数ではないか、間に別の素数が存在します`n`そして`m`。 どちらの場合も正しい答えは次のとおりです`NO`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_prime(x):
    if x < 2:
        return False

    d = 2
    while d * d <= x:
        if x % d == 0:
            return False
        d += 1

    return True

def solve():
    n, m = map(int, input().split())

    candidate = n + 1

    while True:
        if is_prime(candidate):
            if candidate == m:
                print("YES")
            else:
                print("NO")
            return

        candidate += 1

solve()
```の`is_prime`関数は試行除算を実行します。 2 から数値の平方根までのすべての約数をチェックします。 約数が均等に割れる場合、その数値は合成されます。 

メインループは次から始まります`n + 1`より厳密に大きい数値のみを考慮しているため、`n`。 各候補は素数かどうかテストされます。 最初に遭遇した素数は自動的に次の素数になります。`n`。 

実装の微妙な詳細の 1 つは、最初の素数を見つけた直後に停止することです。 後続の素数は無関係であるため、さらに続行すると不正確になります。 もう 1 つの細かい点はループ条件です。`d * d <= x`。 これにより、49 に対する 7 などの完全 2 乗の約数の欠落が回避されます。

import sys
import io

def run(inp: str) -> str:

    def is_prime(x):

            return False

            if x % d == 0:

            d += 1

        if is_prime(candidate):
            return "YES\n" if candidate == m else "NO\n"

        candidate += 1
