 ## 解決策
 ## 問題の理解

 単位長のセグメント (1×1 エッジ) と 2 つのセグメントを直角に結合して形成される L 字型ピースの 2 種類のタイルが与えられます。 Roger wants to use all of these tiles to completely fill an axis-aligned rectangular grid of size$n \times m$いくつかの正の整数の場合$n$そして$m$。 各セグメントとL字型ピースは回転できますが、ピースを分割したり部分的に使用したりすることはできません。 タスクは、そのような四角形が存在するかどうかを判断し、存在する場合は有効な寸法を返すことです。 

入力は次のとおりです。$p$そして$q$、セグメントと L 字型タイルの数を表します。 どちらの数値も最大で$10^8$これは十分に大きいため、単純に四角形を列挙したり、ピースを 1 つずつ配置しようとしたりすることは不可能です。 テスト ケースごとに基本的に定数時間の計算を行うソリューションが必要です。 

エッジ ケースは、セグメントのみまたは L 字型タイルのみがある場合に発生します。 たとえば、次の場合$p = 5$そして$q = 0$、1×5 または 5×1 グリッドが機能します。 もし$p = 0$そして$q = 1$、1 つの L 字型タイルを収容できる最小のグリッドは 2×2 です。 不注意なアルゴリズムでは、これらの最小限のケースが見逃されたり、非整数の次元が生成されたりする可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのことを列挙します。$n$そして$m$ある程度の妥当な範囲まで設定し、セグメントと L 字型のピースの数がグリッドの周囲と内部接続を正確に埋めることができるかどうかを確認します。 これは原理的には正しいです。$n \times m$グリッドには$2nm - n - m$エッジのうちのいくつかは L 字型によって寄与され、いくつかは単位セグメントによって寄与されなければなりません。 ただし、$p, q \le 10^8$、列挙する$n$そして$m$まで$10^4$または$10^5$少なくとも必要になります$10^8$制限時間を超えるテスト ケースごとの操作。 

重要な洞察は、各 L 字型の部分が 2 つのセグメントを直角にカバーしているということです。 したがって、グリッドのエッジの総数を数えると、$total\_edges = 2nm - n - m$、L 字型の部分によって提供されるセグメントの数に、スタンドアロンのユニット セグメントを加えた数と等しくなければなりません。 各 L はちょうど 2 つのエッジに寄与するため、使用されるセグメントの合計は次のようになります。$p + 2q$。 これにより、ディオファントス方程式が得られます。$$2nm - n - m = p + 2q$$ファクタリングの利回り:$$(2n - 1)(2m - 1) = 4(p + 2q) + 1$$ここで問題は、単一の整数を因数分解し、それが次のように表現できるかどうかを確認することになります。$(2n-1)(2m-1)$正の整数の場合$n$そして$m$。 数値を因数分解すると、$4\cdot10^8+1$で行うのに十分効率的です$O(\sqrt{N})$テストケースごとに。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(N²) | お(1) | 遅すぎる |
 | ディオファントス方程式による因数分解 | O(√(p+q)) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、使用されるセグメントの合計数を計算します。$S = p + 2q$。 これは、グリッドを埋めるために必要なすべてのエッジを表します。 
2. エッジ方程式を因数分解形式に変換します。$X = 4S + 1$。 これにより保証されます$X$奇数です。 
3. のすべての整数因数を列挙します。$X$。 それぞれの要因について$f$と$f \le \sqrt{X}$、補因子は$X // f$。 
4. 因子の各ペアについて$(f, X//f)$、両方とも次のように記述できるかどうかを確認してください$2n-1$そして$2m-1$正の整数の場合$n$そして$m$。 これは次の場合に有効です$f$そして$X//f$奇数です。 次に計算します$n = (f+1)//2$、$m = (X//f + 1)//2$。 
5. このような整数の場合$n$そして$m$存在する場合は出力します。 因数分解で正の整数が得られない場合は、-1 を出力します。 

なぜ機能するのか: 方程式$2nm - n - m = p + 2q$グリッド内のすべてのセグメントを正確にカウントします。 に変換します$(2n-1)(2m-1) = 4(p+2q)+1$整数解のみを考慮することを保証します。 因子を列挙すると、有効なグリッドが存在する場合はすべて確実に見つかるようになります。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        p, q = map(int, input().split())
        S = p + 2*q
        X = 4*S + 1
        found = False
        for f in range(1, int(math.isqrt(X)) + 1):
            if X % f == 0:
                g = X // f
                if f % 2 == 1 and g % 2 == 1:
                    n = (f + 1) // 2
                    m = (g + 1) // 2
                    if n > 0 and m > 0:
                        print(n, m)
                        found = True
                        break
        if not found:
            print(-1)

if __name__ == "__main__":
    solve()
```コードは因数分解アプローチを直接実装します。 使用する`math.isqrt`浮動小数点エラーを回避します。 両方の因数が奇数であることを確認することで、`n`そして`m`は整数です。 この問題では有効な次元が許容されるため、最初の有効なペアを早期に終了するだけで十分です。 

## 実用的な例

 ### 例 1

 入力:```
1
1 1
```コンピューティング`S = 1 + 2*1 = 3`。 それから`X = 4*3 + 1 = 13`。 13 の約数は 1 と 13 です。どちらも奇数です。 コンピューティング`(n,m) = ((1+1)//2, (13+1)//2) = (1,7)`それは有効です。 出力`1 7`。 

| f | g | n | メートル | 有効？ |
 | --- | --- | --- | --- | --- |
 | 1 | 13 | 1 | 7 | はい |

 これは、因数分解によって直接解が得られることを示しています。 

### 例 2

 入力:```
1
2 2
```コンピューティング`S = 2 + 2*2 = 6`。 それから`X = 4*6 + 1 = 25`。 25 の因数: (1,25)、(5,5)。 コンピューティング`(n,m)`:

 - (1,25) → (1,13) 有効
 - (5,5) → (3,3) 有効

 コードは最初の有効なペアを返します`(1,13)`。 これは、複数の解決策が可能であり、どれも受け入れられることを示しています。
