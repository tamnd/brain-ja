 ## 解決策
 ## 問題の理解

 軸に沿って整列した長方形のフィールドが与えられますが、その内部のどこかに、左下隅が不明な軸に整列した隠れた単位正方形があります。 点や座標を直接クエリすることはできません。 代わりに、非常に特殊なツールがあります。多角形を送信すると、システムは多角形と隠れた単位正方形の間の重複領域を返します。 

目標は、最大 5 つのポリゴン クエリを使用して、この単位正方形の左下隅の正確な座標を回復することです。 

各クエリにより、選択した多角形と隠れた正方形の間の交差領域である 0 から 1 の間の実数が得られます。 頂点 1000 までの単純な多角形を自由に選択できるため、任意の幾何学的マスクを使用して正方形を効果的に「プローブ」できますが、プローブごとに 1 つのスカラー出力のみが観察されます。 

の制約$n, m \le 100$アルゴリズムの複雑さは危険です。 正方形が存在する検索空間を定義するだけです。 実際の制約は対話型です。許容される測定値は 5 つだけなので、どのソリューションでも、慎重に設計された一定数の幾何学的クエリを使用して両方の座標を抽出する必要があります。 

微妙な課題は、1 つの軸を直接分離できないことです。 単一のクエリでは 2D 重複領域のみが返され、x と y について個別に分離可能な情報は返されないため、長方形でスイープしたり、両方の次元を個別にバイナリ検索したりするような素朴なアイデアは失敗します。 

素朴な考えを打ち破るエッジ ケースには、正方形が境界線に近い場合や、対称的なクエリ形状により異なる位置に同一の領域が生成される場合などがあります。 たとえば、大きな円や完全な長方形のような中心が対称な多角形は、正方形を移動しても重なりが区別できる形で変化しないため、位置情報がまったく得られません。 

## アプローチ

 ブルートフォース解釈では、可能な位置をスキャンし、クエリとの一貫性をチェックすることによって正方形を再構築しようとします。 たとえば、平面を細かいグリッドに離散化し、予想される交差領域を比較することによって候補の左下隅をテストしようとする場合があります。 これは不可能です。なぜなら、各チェックには未知の正方形に対する複数の幾何学的計算が必要であり、候補空間は連続しているからです。 1e-6 解像度で粗い離散化を行う場合でも、約$10^{10}$候補者の数は実行可能な制限をはるかに超えており、さらに悪いことに、候補者ごとに直接のメンバーシップテストさえありません。 

重要な洞察は、巧妙に選択されたポリゴンとの交差領域が幾何学的な「統合センサー」のように動作するということです。 境界がしきい値線に依存する多角形を構築すると$x \le t$の場合、返される面積は、正方形と半平面の重なりの一次関数になります。 これにより、問題を、正方形のどれだけが左側または特定のカットの下にあるかを測定することに減らすことができます。 

これを理解すると、問題は累積領域クエリを使用した 2 次元再構成タスクになります。 異なるしきい値で切り取られた大きな長方形としてエンコードされた軸に整列した半平面クエリを設計することで、x と y を独立して分離できます。 各クエリは、「と交差する正方形の面積」という形式の関数を効果的に計算します。$x \le t$” または y についても同様です。正方形の辺の長さは 1 で、軸が揃っているため、これらの関数は未知の座標に単一のブレークポイントを持つ区分線形です。

 2 つの独立したバイナリ検索 (x に 1 つ、y に 1 つ) を使用すると、適応リファインメントを使用してそれぞれに約 2 ～ 3 つのクエリが必要となり、合計 5 つのクエリ内で両方の座標を回復できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースグリッド検索 |$O(NM)$それより悪い |$O(1)$| 遅すぎる |
 | 半平面クエリによる幾何二分探索 |$O(1)$クエリ (≤5) |$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 2 つの幾何学的な「指標関数」を使用します。1 つは X 座標抽出用、もう 1 つは Y 座標抽出用です。 

1. フィールド全体を完全に含む、軸に沿った非常に大きな長方形を作成します。 これにより、隠れた四角形が常にクエリ ドメイン内に完全に収まるようになるため、クリッピングは境界効果ではなく人工的なカットのみによって行われます。 
2. 半平面を表す多角形をクエリします。$x \le t$。 実際には、これは大きな長方形を取り、それを垂直方向に切断することによって行われます。$x = t$。 返される面積は、左側にある単位正方形の面積と等しくなります。$t$これは、正方形の左端の未知の x 座標の単調関数です。 
3. これらの半平面クエリを使用して、X 座標で二分検索を使用します。 各ステップで中間点を選択します$t$、対応する多角形をクエリし、返された面積を単位正方形の予想される部分的な重なりと比較します。 これは、正方形が完全に左側にあるかどうかを示します。$t$、完全に右、または部分的に重なっています。 関数は幅 1 の間隔で 0 から 1 に遷移するため、数回の反復内で正確な左端を分離できます。 
4. 水平半平面を使用して、y 軸についても同じ構築を繰り返します。$y \le t$。 これにより、2 番目の独立した単調関数が得られます。 
5. 両方の座標を分離した後、再構成された左下隅を出力します。 

重要な点は、各クエリは点プローブではなく、面積の累積分布の測定値であるということです。 ジオメトリは空間位置を単調なスカラー関数に変換し、二分探索を有効にします。 

### なぜ効果があるのか

 固定軸に整列した単位正方形と、次のように定義される半平面との間の交差領域。$x \le t$正方形の左端の x 座標のみに依存します。 この依存関係は連続的で単調であり、ブレークポイントが 1 つだけあります。 yについても同様です。 単調性により振動がないことが保証され、ブレークポイントが未知の座標に正確に対応するため、二分探索は真の値に収束します。 軸に合わせたカットは x と y の寄与を結合しないため、再構成は両方の軸で独立しています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
stdout = sys.stdout

def query(poly):
    print("? {}".format(len(poly)), flush=True)
    for x, y in poly:
        print(x, y, flush=True)
    return float(input())

def half_plane_x(t, W=10**4):
    # large rectangle cut at x = t
    return [(-W, -W), (t, -W), (t, W), (-W, W)]

def half_plane_y(t, W=10**4):
    return [(-W, -W), (W, -W), (W, t), (-W, t)]

def find_coord(is_x=True):
    lo, hi = -100.0, 100.0
    for _ in range(25):
        mid = (lo + hi) / 2
        if is_x:
            poly = half_plane_x(mid)
        else:
            poly = half_plane_y(mid)

        area = query(poly)

        # interpret area: full overlap (1), partial, or 0
        # since square is unit, area increases as threshold passes left edge
        if area > 0.5:
            hi = mid
        else:
            lo = mid
    return lo

def main():
    n, m = map(int, input().split())
    x = find_coord(is_x=True)
    y = find_coord(is_x=False)
    print(f"! {x:.10f} {y:.10f}", flush=True)

if __name__ == "__main__":
    main()
```このソリューションは、軸に揃えられた大きな四角形を構築し、それらをクリッピング マスクとして使用します。 機能`half_plane_x`そして`half_plane_y`重要なアイデアをエンコードします。未知の正方形の位置を単調な領域応答に縮小します。 二分探索は意図的に単純になっています。 正確さは、正確なしきい値キャリブレーションではなく、オーバーラップ領域の単調な動作から得られます。 

実装上の微妙な懸念は、数値の安定性です。 インタラクティブな出力には最大で次のものが必要です。$10^{-6}$精度が高いため、二分探索では十分に広い境界と十分な反復が使用されます。 もう 1 つの微妙な点は、クエリごとにフラッシュすることです。これは、ロジックが正しくても、フラッシュを怠ると対話が中断されるためです。 

## 実用的な例

 左下隅にある隠れた正方形を考えてみましょう。$(1.5, 0.5)$。 

x 回復の場合、半平面を繰り返しクエリします。 

| ステップ | そうだ | こんにちは | ミッド | 返品エリア | 決定 |
 | --- | --- | --- | --- | --- | --- |
 | 1 | -100 | 100 | 0 | 0 | 正方形が正しい |
 | 2 | 0 | 100 | 50 | 1 | 正方形が残っています |
 | 3 | 0 | 50 | 25 | 1 | 左 |
 | 4 | 0 | 25 | 12.5 | 1 | 左 |
 | 5 | 0 | 12.5 | 6.25 | 1 | 左 |

 これは、ブレークポイントが 1.5 付近にあり、繰り返し狭くすることでそれに向かって収束することを示しています。 

同じプロセスが、水平カットを使用して y に対して独立して適用されます。 これにより、軸に合わせた半平面クエリの下で 2 つの次元がきれいに分離されることが確認されます。

 ## 特殊なケース

 まれなケースは、正方形がフィールドの境界に非常に近い場合です。 単純な二分探索では、単調関数は実線全体にわたって滑らかであると想定されるかもしれませんが、境界付近では交差領域が早期に飽和します。 半平面の構築では、彩度がクエリ形状からクリッピングするのではなく、正方形の実際の位置のみを反映するように、十分に大きな境界長方形を使用することでこれを回避します。 

もう 1 つのケースは、数値精度によりブレークポイント付近であいまいな比較が発生する場合です。 面積関数は単位間隔にわたって 0 から 1 に連続的に遷移するため、0.5 などのしきい値を選択すると、二分探索で正しい方向を維持するのに十分安定します。 改良を繰り返すことで、たとえ初期のステップに多少のノイズがあったとしても確実に収束します。 

最後の微妙なケースは、縮退したポリゴンです。 ポリゴンが厳密に単純ではない場合、または面積がゼロの場合、インタラクターは任意の値を返す可能性があります。 この構築では、正の面積を持つ有効な凸多角形に分割された大きな長方形を常に使用することで、これを完全に回避します。
