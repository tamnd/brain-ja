 ## 解決策
 ## 問題の理解

 長さの配列を構築するように求められます`n`負でない整数で構成されます。 2 つのグローバル制約を同時に満たす必要があります。 

まず、すべての要素の合計が正確に一致する必要があります。`s`。 次に、各要素を次のように割ると、`k`これらの商の合計は正確に次のようになります。`b`。 2 番目の条件は、サイズの完全なブロックの数をカウントすると解釈できます。`k`アレイ全体に存在します。 

各要素は独立して寄与します: 値`x`貢献する`x // k`美しさに貢献します`x`合計額に。 タスクは合計金額を分配することです`s`横切って`n`フルスロットの合計数を確保しながら、`k`-ブロックは等しい`b`。 

制約は大きいです:`n`テスト全体で最大 1e5、`k`1e9 まで、および`s`1e18まで。 これにより、すべての分布を試行したり、位置ごとの可能な値に対して入れ子になったループで候補を構築したりするアプローチは直ちに除外されます。 テスト ケースごとに直線的な構築が唯一の実行可能な方向です。 

建設前であっても実現可能性が不可能な場合には、微妙なエッジケースが発生します。 たとえば、次の場合`k = 6`、`b = 3`、 そして`s = 12`と`n = 3`、美しさを実現するための最小限の金額`3`すでに大きすぎるか構造が一致しすぎています`s`。 これは、すべての美の単位には少なくとも次の要素が必要であるという事実から来ています。`k`合計貢献度は配列内のどこかにあるため、`s`サポートするのに十分な大きさでなければなりません`b`フルブロック。 

別の故障モードが発生する場合`b`全体に分散するには大きすぎます`n`要素。 もし`b > s // k`、その場合、すべての質量を 1 つの要素に集中させても、十分な完全な分割を作成することはできません。 

本当の困難は、実現可能性を計算することではなく、「ブロック寄与」と残りの値の両方をどちらの制約も破ることなく分配することです。 

## アプローチ

 強引なアイデアは、各要素を変数として扱い、値を段階的に割り当ててみるというものです。 各位置について、次の値を試すことができます。`0`に`s`、現在の合計と美しさを計算し、バックトラックします。 これは原理的には正しいですが、完全に実行不可能です。 たとえ`n = 100`、状態空間が爆発し、`n = 10^5`、それは不可能です。 

重要な観察は、美しさへの貢献はサイズの塊で構成されているということです。`k`。 任意の数`x`次のように分解できます。`x = (x // k) * k + (x % k)`これにより、各要素が「ブロック部分」と「残り部分」に分割されます。 美しさはブロック部分のみに依存し、残りの部分は美しさにまったく影響しません。 

そこで問題は、正確に割り当てる必要があるということです。`b`サイズのブロック`k`配列全体に残りの合計を剰余として自由に分配し、合計を次の値に等しく保ちます。`s`。 

最初にできるだけ多くの完全なものを割り当てると、きれいな構造が現れます。`k`ブロックを可能な限り 1 つの要素にまとめ、残りのブロックを次のように分配します。`k`他の位置では -size が増加します。 美しさを修正した後、床の分割構造に影響を与えることなく、残った合計を任意の要素に分配します。 

美しさのために必要な最低限の合計を確保すればいいだけです`b`は`b * k`、残りのたるみ`s - b * k`任意に配布することができます。 

もし`s < b * k`、解決策はありません。 それ以外の場合は、次の基本配列を構築します。`b`の単位`k`、残りの合計を分配します。 

最後に、要素が次のオーバーフローにより誤って余分なブロックを取得しないようにします。`k`、各位置に最大 1 つの大きな値を慎重に配置します。

 ## アルゴリズムのチュートリアル

 満杯になる配列の数を制御しながら、貪欲に配列を構築します。`k`-blocks 各要素が寄与します。 

1. 次のことを検証して実現可能性を確認します。`b * k ≤ s`。 そうでない場合、配列は合計を超えずに十分な完全なブロックを生成できません。 なぜなら、美しさの各単位には少なくともコストがかかるからです。`k`価値において。 
2. サイズの配列を初期化します`n`すべてゼロで。 まず必要な美しさを割り当てます`b`最初の要素に集中して入力します。 これにより、ブロックが時期尚早に配布されることが回避され、追跡が簡素化されます。 
3.セット`a[0] = b * k`。 これにより、この要素によってもたらされる美しさがまさに保証されます。`b`、 以来`(b * k) // k = b`。 他に美しさに寄与する要素はまだありません。 
4. 残りの合計からこの寄与分を引きます。`remaining = s - b * k`。 
5. 配布します`remaining`美しさを変えることなく、アレイ全体にわたって。 どのような値であっても`< k`美しさへの貢献はゼロですが、安全に価値を置くことができます`[0, k-1]`どのポジションでも。 
6. 要素を左から右に埋めていき、合計すると`k-1`要素ごとに`remaining`疲れ果てています。 これにより、新たな問題が発生しないことが保証されます`k`-block が誤って作成されました。 
7. 結果の配列を出力します。 

### なぜ効果があるのか

 この構造は、すべての美しさへの貢献を単一の制御された要素に分離します。 以来`a[0]`≥ であることが許可されます`k`、それだけで床の合計が決まります。 他のすべての要素は厳密に以下に保持されます`k`、美しさへの貢献がゼロであることを保証します。 残りの合計は、余分なブロックを作成するしきい値を超えることなく分配されます。 これにより、両方の制約が独立して保存され、構築が安全かつ決定的になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k, b, s = map(int, input().split())

        min_sum = b * k
        if min_sum > s:
            print(-1)
            continue

        res = [0] * n

        # allocate all beauty into first element
        res[0] = b * k
        remaining = s - b * k

        # distribute remaining without creating new k-blocks
        for i in range(n):
            if remaining == 0:
                break
            add = min(k - 1, remaining)
            res[i] += add
            remaining -= add

        if remaining > 0:
            print(-1)
        else:
            print(*res)

if __name__ == "__main__":
    solve()
```解決策は、必要な数の完全な数が満たされているかどうかを確認することから始まります。`k`総額があれば寄付も可能です。 そうでない場合は、直ちにケースを拒否します。 

構築ステップでは、必要なすべての美しさを、次の正確な倍数を使用して最初の要素に配置します。`k`。 これにより、フロア分割の合計が正確に計算されます。`b`残りの値がどのように分配されるかには依存しません。 

配布するループ`remaining`～によって慎重に制限されています`k - 1`、新しい要素が美しさに寄与するのを防ぎます。 これは実装の中心的な詳細です: しきい値を超える`k`静かに美しさを増し、正しさを壊すでしょう。

 ## 特殊なケース

 重要なエッジケースの 1 つは次のような場合です。`b * k == s`。 この場合、たるみは残りません。 アルゴリズムは次のように割り当てます。`a[0] = s`他の要素はすべてゼロのままにします。 他のすべての値は以下であるため、`k`、それらは何も寄与せず、最初の要素だけで正確に生成されます。`b`美しさ。 構築は引き続き有効です。 

もう 1 つのエッジケースは次のような場合です`k = 1`。 ここでは、あらゆる整数が美しさに完全に貢献しています。 条件はこうなります`sum(a) = s`そして美しさは等しい`s`。 これにより、`b = s`。 そうでない場合、解決策は存在しません。 アルゴリズムはこれを自然に処理します。`b * k = b`等しい必要があります`s`。 

最後のエッジケースは次のような場合です`n = 1`。 可能な配列は単一の値のみです`s`。 条件は次のことを確認することになります。`s // k == b`、唯一の要素を に設定しているため、これは構造と一致します。`b * k`そして要求する`s = b * k`。
