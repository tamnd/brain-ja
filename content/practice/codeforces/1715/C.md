 ## 解決策
 ## 問題の理解

 整数の配列が与えられ、その配列を分割できる連続した同一ブロックの最小数としてその素晴らしさを定義します。 例えば、`[1,1,2,2,2,3]`に分割できるため、素晴らしさ 3 があります。`[1,1]`、`[2,2,2]`、`[3]`。 この問題では、配列の 1 つの要素を変更するクエリをサポートし、変更するたびにすべての部分配列の awesomeness 値の合計を計算するように求められます。 

配列の長さとクエリの数は最大です。$10^5$。 各クエリの後にすべてのサブ配列を考慮する総当りアプローチでは、最大で$10^5 \cdot 10^{10}$最悪の場合の動作は明らかに遅すぎます。 このため、前処理を行った後に、理想的にはクエリごとに O(1) または O(log n) で合計を効率的に計算する方法を見つける必要があります。 

明らかでないエッジ ケースには、すべてが同一の要素を持つ配列、すべての要素が異なる配列、配列要素の値を変更しない更新が含まれます。 たとえば、配列が次の場合、`[5,5,5]`そして 2 番目の要素を再度 5 に設定すると、素晴らしさの合計は変わらないはずです。 同様に、配列の端での更新は影響を受けるサブ配列の数が少なくなる可能性があるため、慎重な取り扱いが必要です。 

## アプローチ

 ブルート フォース手法では、各クエリの後にすべてのサブ配列を反復処理し、ブロックをカウントします。 長さの配列の場合$n$、 がある$\frac{n(n+1)}{2}$サブ配列ごとにブロックを数えると、最大で 3 分かかります。$O(n)$。 これにより、最悪の場合の複雑さは次のようになります。$O(n^3)$クエリごとに、これは非現実的です$n = 10^5$。 

重要な洞察は、すべての部分配列の素晴らしさの合計は次のように表現できるということです。$n(n+1)/2$さらに、要素がその隣接要素と比較して値を変更するすべての位置からの寄与も加えます。 具体的には、インデックスでブロック境界が発生します。$i$もし$a[i] \neq a[i+1]$。 このような各境界は、それを含むすべてのサブ配列に影響し、そのようなサブ配列の数は正確に$i \cdot (n-i)$ポジション間の境界線に$i$そして$i+1$。 

これにより、問題は等しくない隣接するペアのセットを追跡することになります。 各クエリは最大で 2 つのペア (更新されたインデックスの左側のペアと右側のペア) を変更します。 すべての境界からの寄与の現在までの合計を維持することにより、クエリごとに O(1) で答えを更新できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | お(1) | 遅すぎる |
 | 最適 | O(n + m) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.凄さの合計を初期化します。 から始める`total = n*(n+1)//2`。 これにより、すべてのサブ配列が少なくとも 1 つのブロックとしてカウントされます。 
2. すべての隣接するペアを反復処理します。`(a[i], a[i+1])`。 それらが異なる場合は、その寄与を次のように計算します。`i * (n-i)`そしてそれを追加します`total`。 このステップでは、すべてのブロック境界の寄与を計算します。 
3. クエリごとに`(idx, x)`、影響を受ける 2 つの境界を考慮してください。`(idx-1, idx)`そして`(idx, idx+1)`、存在する場合。 から古い寄与分を差し引く`total`アップデート前。 
4.アップデート`a[idx] = x`。 
5. 潜在的に新しい境界の寄与を追加する`(idx-1, idx)`そして`(idx, idx+1)`に`total`。 
6. 印刷`total`。 

それが機能する理由: 素晴らしさの合計は、隣接する要素のあらゆる変化からの寄与に分解できます。 単一の要素を更新すると、その要素に接する境界にのみ影響します。 各境界の寄与を維持し、影響を受ける境界のみを更新することにより、アルゴリズムは、影響を受けない部分配列に対する再計算を回避しながら正確さを維持します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
a = list(map(int, input().split()))

total = n * (n + 1) // 2

def contrib(i):
    if 0 <= i < n - 1 and a[i] != a[i+1]:
        return (i + 1) * (n - (i + 1))
    return 0

for i in range(n - 1):
    total += contrib(i)

for _ in range(m):
    idx, x = map(int, input().split())
    idx -= 1
    
    total -= contrib(idx - 1)
    total -= contrib(idx)
    
    a[idx] = x
    
    total += contrib(idx - 1)
    total += contrib(idx)
    
    print(total)
```機能`contrib(i)`ペアの境界寄与を計算します`(a[i], a[i+1])`。 更新前に古い貢献度を減算し、更新後に新しい貢献度を追加します。 0 から始まるインデックスを使用するには調整が必要です`idx`クエリから。
