 ## 問題の理解

 与えられたグリッドでは、各セルが 4 つの方向のいずれかに強制的に移動するか、まだ決定されていません。 任意のセルから開始して、トークンは矢印に従って段階的に進み、グリッドの外に出るとすぐにグリッドから離れます。 一部のセルはトークンが決してグリッドから出ないサイクルを形成する場合がありますが、他のセルは最終的に境界につながる場合があります。 

タスクは、グリッドを任意に固定した後の動きをシミュレートすることではありません。 代わりに、永久に閉じ込められる開始位置の数を最大化する方法で、未知のセルに方向を割り当てることができます。 すべての疑問符を最適に割り当てた後、そこから開始してグリッド内での無限の移動が保証される場合、セルは良好であると見なされます。 

すべてのテスト ケースにわたる合計セル数が最大 100 万であるという制約は、テスト ケースごとに線形または線形に近いグラフの走査が必要であることを意味します。 各割り当てを評価したり、構成ごとに到達可能性を再計算しようとしたソリューションは、すぐに制限を超えてしまいます。 

重要な微妙なエッジケースは、サイクルがどこでも自動的に最適化されるわけではないということです。 「疑問符が表示される場所では常にローカルでサイクルを形成できる」という素朴な仮定は、エスケープ パスがすでに存在し上書きできない境界または強制方向領域では失敗します。 

## アプローチ

 強引なアイデアでは、すべてを割り当てようとします。`?`あらゆる方法でセルを探索し、すべてのノードからの到達可能性をシミュレートします。 これは明らかに未知数の指数関数的です。`?`には 4 つの可能性があり、10x10 グリッドでさえこれはすでに実行不可能です。 

本当の観察は視点を逆転させることから生まれます。 細胞が閉じ込められるかどうかを問うのではなく、未知数をどのように割り当てても最終的に細胞が脱出せざるを得なくなるかどうかを問うのです。 

細胞を境界に決して到達しない方向性のある構造に強制的に入れることができれば、細胞を安全にトラップすることができます。 これは、遷移時に閉じられる領域にそれが属していることを確認することと同じです。 これにより、問題は次の方法を使用してグリッドのどの部分を境界から「密閉」できるかを理解することに帰着します。`?`細胞。 

中心となるアイデアは、境界から内側へ「脱出の必然性」を伝播させることです。 方向が固定されており、既に外側またはエスケープチェーン内を向いているセルは、本質的に安全ではありません。 疑問符は、フローをブロックまたはリダイレクトできる柔軟性として機能します。 最適な戦略は、グリッドを強制エスケープの逆グラフとして扱い、割り当てに関係なくどのセルが必然的に外部に接続されるかを計算することです。 

これは、境界エスケープ状態からマルチソース BFS/DFS になり、どの割り当てにもトラップできないすべてのセルをマークします。 答えは、合計セルから強制エスケープ セルを引いたものです。

 ## アルゴリズムのチュートリアル

 私たちはグリッドを、すべてのセルがその性質に応じて外向きのエッジを持つ有向システムとして再解釈します。 

重要な難点は、`?`セルは固定エッジではありません。 代わりに、4 つの方向のいずれかに割り当てることができます。つまり、潜在的に逃走への寄与を回避したり、逆に動きをブロックするために使用したりすることができます。 

したがって、どのように割り当てても逃げることが保証されているセルに焦点を当てます。`?`。 

### ステップ 1: 強制的な動きをモデル化する

 質問以外のセルごとに、出力方向が 1 つだけ存在します。 その方向がグリッドの外側に向かう場合、そのセルは直ちに脱出源になります。 

質問セルについては、それらが最適に選択されていると一時的に仮定します。これは、すべての選択肢が脱出につながる場合を除き、脱出源になることを回避できることを意味します。 

### ステップ 2: 逆エスケープ伝播を構築する

 初期エスケープ状態として、すべての境界から出る動きから開始します。 次に、逆方向に伝播します。 

セルからのすべての可能な移動がすでに不良セルにつながる場合、そのセルは「不良」としてマークされます。 固定方向の場合、これは簡単です。 のために`?`、どの近隣者も選択できると考えられるため、すべての近隣者がすでに悪い場合にのみ悪いものになります。 

### ステップ 3: BFS/DFS の閉鎖

 強制脱出が確認されたセルの列を維持します。 セルが強制エスケープになると、オプションのセット全体が安全でなくなった場合、そのセルの前のセルも強制エスケープになる可能性があります。 

新しいセルがマークされなくなるまで続行します。 

### ステップ 4: 残りのセルを数える

 強制エスケープとしてマークされていないすべてのセルは、次を使用してサイクルまたは閉じた構造の一部にすることができます。`?`課題。 これらは、回答でカウントされるセルです。 

### なぜ効果があるのか

 このアルゴリズムは、「どのような割り当てでも脱出を避けることができないセル」の最大の不動点を計算します。 すべての伝播ステップは単調です。細胞が脱出を回避できないことが証明されると、細胞の再割り当ては行われません。`?`考えられるすべての発信遷移がすでにエスケープ状態につながっているため、安全性を回復できます。 これにより、補完セットが、少なくとも 1 つの一貫した割り当てによってトークンが無期限にトラップされ続けるセルになることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

dirs = {
    'U': (-1, 0),
    'D': (1, 0),
    'L': (0, -1),
    'R': (0, 1)
}

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        g = [list(input().strip()) for _ in range(n)]

        N = n * m
        out = [[] for _ in range(N)]
        indeg = [0] * N

        def id(x, y):
            return x * m + y

        bad = [False] * N
        q = deque()

        # Build reverse edges and detect immediate escapes
        for i in range(n):
            for j in range(m):
                u = id(i, j)
                c = g[i][j]

                if c == '?':
                    continue

                di, dj = dirs[c]
                ni, nj = i + di, j + dj

                if ni < 0 or ni >= n or nj < 0 or nj >= m:
                    bad[u] = True
                    q.append(u)
                else:
                    v = id(ni, nj)
                    out[v].append(u)
                    indeg[u] += 1

        # We need full outgoing option count for '?'
        deg = [[0] * 4 for _ in range(N)]
        pos = lambda x, y: x * m + y

        # initialize counts
        for i in range(n):
            for j in range(m):
                u = id(i, j)
                c = g[i][j]
                if c == '?':
                    cnt = 0
                    for di, dj in dirs.values():
                        ni, nj = i + di, j + dj
                        if 0 <= ni < n and 0 <= nj < m:
                            cnt += 1
                    deg[u] = cnt

        # BFS propagate forced escape
        cnt_bad_out = [0] * N

        # recompute outgoing bad counts dynamically
        for u in range(N):
            cnt_bad_out[u] = 0

        while q:
            v = q.popleft()
            for u in out[v]:
                if bad[u]:
                    continue
                cnt_bad_out[u] += 1

                c = g[u // m][u % m]

                if c == '?':
                    total = deg[u]
                    if cnt_bad_out[u] == total:
                        bad[u] = True
                        q.append(u)
                else:
                    # fixed edge: only one option
                    bad[u] = True
                    q.append(u)

        ans = 0
        for i in range(N):
            if not bad[i]:
                ans += 1
        print(ans)

if __name__ == "__main__":
    solve()

 ## 特殊なケース

 特殊なケースは、すべてのセルが境界へのパスを形成する固定矢印であるグリッドです。 この場合、いくら理屈を並べても、`?`が適用され、エスケープ伝播があらゆる場所に到達するため、BFS はすぐにすべてのセルを不良としてマークします。 

もう 1 つのエッジ ケースは、グリッドがいっぱいになっている場合です。`?`。 ここでは、すべての遷移をサイクルにリダイレクトできるため、強制的にエスケープされるセルはありません。そのため、答えは合計セルに等しくなります。
