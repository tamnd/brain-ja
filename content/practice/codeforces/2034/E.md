 ## 解決策
 ## 問題の理解

 構築する必要があります$k$長さの異なる順列$n$任意の位置を見てみると$i$、その位置に現れる値の合計$k$順列はどの位置でも同じです。 

順列を次のように表すと、$p_1,p_2,\dots,p_k$次に、インデックスごとに$i$、$$p_1[i]+p_2[i]+\cdots+p_k[i]$$～から独立していなければならない$i$。 

テストケースごとに、次のものが与えられます。$n$そして$k$。 出力する必要があります。$k$ペアごとに異なる順列が条件を満たすか、そのようなコレクションが存在しないと判断します。 

この制約は、順列を介して検索を行っていないことをすぐに示唆しています。 単一の順列にはすでに$n!$可能性、そして$n$と同じ大きさにすることができます$10^5$。 の合計$n\cdot k$すべてのテストケース全体で最大でも$5\cdot10^5$これは、意図したソリューションが答えを直接構築していることを強く示唆しています。$O(nk)$時間。 

いくつかの特殊なケースは見落とされがちです。 

考慮する$k=1$。 位置の合計は単なる置換値であるため、単一の置換自体はすべての位置で等しい値を持つ必要があります。 それはそうでない限り不可能です$n=1$。 

入力：```
1
5 1
```正しい出力:```
NO
```恒等順列を常に出力するような不注意な構築は、位置和の要求された等価性を侵害することになります。 

もう一つの特殊なケースは、$n$偶数と$k=2$。 

入力：```
1
4 2
```有効な答えは、```
YES
1 2 3 4
4 3 2 1
```すべてのポジションの合計は次のようになります$5$。 を想定した解決策$k$奇数でなければならないと誤ってこのケースを拒否してしまいます。 

最も微妙なケースは、$n$奇妙で$k$平。 

入力：```
1
3 2
```サンプル自体には有効な回答が含まれています。```
YES
1 2 3
3 2 1
```ただし、より大きな奇数の場合は、$n$、 のような$n=5,k=2$、解決策は存在しません。 正しい構築では、以下のパリティのみに依存するのではなく、これらの状況を区別する必要があります。$k$。 

## アプローチ

 ブルートフォースの観点は単純です。 のセットを列挙できます$k$個別の順列を調べ、すべての位置の合計が一定であるかどうかを確認します。 候補者のコストを確認する$O(nk)$, しかし、候補者の数は天文学的です。 たとえ$n=8$、 がある$40320$順列。 それらのいくつかを選択すると、すでに検索が実行できなくなります。 

重要な観察は、順列合計がどのように動作するかを理解することから得られます。 

順列に現れるすべての値の合計は常に次のようになります。$$1+2+\cdots+n=\frac{n(n+1)}2.$$すべてのポジションの合計が同じ場合$S$、すべての位置を合計すると、$$nS=k\cdot\frac{n(n+1)}2.$$したがって、$$S=\frac{k(n+1)}2.$$これにより、必要な条件が即座に得られます。$k(n+1)$均等でなければなりません。 

さらに重要なのは、非常に便利な順列のペアがあることです。$$[1,2,\dots,n]$$そして$$[n,n-1,\dots,1].$$すべての位置で、それらの合計は正確に$n+1$。 

これは、相補的なペアで順列を取得するたびに、各ペアがすべての位置に同じ量を寄与することを意味します。 全体の問題は、この定数和の性質を維持しながら、十分に異なる順列を構築することになります。 

恒等順列とその逆は、そのようなペアの 1 つを形成します。 恒等置換の循環シフトにも有用な特性があります。 奇数の場合$n$、 全て$n$循環シフトを組み合わせると、すべての位置に同じ合計が与えられます。 これにより、奇妙なものに対する答えを構築できるようになります$k$。 

最終的な構築はパリティ ケースに分割され、循環シフトとその逆のみが使用されます。

 ## アルゴリズムのチュートリアル

 ### ケース 1:$k=1$1. もし$n=1$、一意の順列を出力します$[1]$。 
2. それ以外の場合は出力`NO`。 

のために$n>1$、順列には異なる値が含まれるため、位置の合計がすべて等しくなることはありません。 

### ケース 2:$k$均等です

 1. もし$n$奇妙であり、$k=2$、出力`NO`。 
2. それ以外の場合は、相補的なペアで順列を構築します。 

恒等置換の巡回シフトを計算します。$$a_t[i] = ((i+t)\bmod n)+1.$$選択したシフトごとに$a_t$、その逆補数ペアも出力します$$b_t[i]=n+1-a_t[i].$$どのポジションでも、$$a_t[i]+b_t[i]=n+1.$$各ペアはどこでも一定の量を貢献します。 

使用$k/2$さまざまなシフトを正確に生成$k$明確な順列。 

### ケース 3:$k$奇妙です

 1. もし$n$偶数、出力`NO`。 

以来$k$奇数です、必要な合計です$k(n+1)/2$が整数ではない場合$n$は均等です。 

1. もし$n$が奇数の場合、出力します$n$まず恒等順列の巡回シフト。 

これら$n$順列は異なります。 すべての数値はすべての列に 1 回だけ出現するため、すべての列の合計は次のようになります。$$1+2+\cdots+n.$$1. まだ必要です$k-n$順列。 

両方なので$k$そして$n$奇妙です、$k-n$は均等です。 偶数からの方法を使用して、残りの順列を相補的なペアに追加します。$k$工事。 

### なぜ効果があるのか

 この構築は 2 つの不変式に依存します。 

最初の不変条件は、相補的なペアが常に正確に寄与するということです。$n+1$あらゆるポジションに。 このようなペアを追加すると、列の合計の等価性が維持されます。 

2 番目の不変条件は、恒等順列のすべての巡回シフトのセットが同一の列和を持つということです。 各列には次の各数値が含まれます。$1$に$n$正確に 1 回なので、すべての列の合計は等しい$n(n+1)/2$。 

いつ$k$奇妙であり、$n$奇数です、最初の$n$循環シフトにより有効な高調波セットが確立されます。 追加の順列はすべて相補的なペアで追加され、すべての列に均等に寄与し、プロパティが維持されます。 

すべての循環シフトが異なり、すべての補完パートナーも異なるため、区別性が保証されます。 構築では順列が繰り返されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n, k = map(int, input().split())

        if k == 1:
            if n == 1:
                out.append("YES")
                out.append("1")
            else:
                out.append("NO")
            continue

        if k % 2 == 0:
            if n % 2 == 1 and k == 2:
                out.append("NO")
                continue

            out.append("YES")

            perms = []

            for shift in range(k // 2):
                a = [((i + shift) % n) + 1 for i in range(n)]
                b = [n + 1 - x for x in a]
                perms.append(a)
                perms.append(b)

            for p in perms:
                out.append(" ".join(map(str, p)))

        else:
            if n % 2 == 0 or k > n:
                out.append("NO")
                continue

            out.append("YES")

            for shift in range(k):
                p = [((i + shift) % n) + 1 for i in range(n)]
                out.append(" ".join(map(str, p)))

    sys.stdout.write("\n".join(out))

solve()
```実装はケース分析に直接続きます。 

偶数の場合$k$、各反復は 1 つの循環シフトとその補完パートナーを作成します。 表現```
((i + shift) % n) + 1
```範囲内に留まりながら恒等順列の巡回シフトを生成します$1$を通して$n$。 

相補的順列は次のように生成されます。```
n + 1 - x
```これにより、すべてのポジションの合計が次のようになります。$n+1$。 

奇数の場合$k$、受け入れられた構造は次の場合にのみ存在します。$n$奇妙であり、$k\le n$。 最初のものを出力するだけです$k$循環シフト。 2 つの異なるシフトはそれぞれ別個の順列であり、すべての列はシフト全体に均一に分散された値を受け取ります。 

よくある間違いは、奇数の不可能条件を忘れることです。$k$そしてさらに$n$。 その状況では、必要な列の合計は整数ですらないでしょう。
