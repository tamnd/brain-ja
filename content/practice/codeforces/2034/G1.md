 ## 解決策
 ## 問題の理解

 実数直線上に一連の閉区間が与えられます。 各間隔は、1 人の戦士の活動時間を表します。 すべての間隔に色を割り当てる必要があります。 

少なくとも 1 つの間隔でカバーされるリアルタイムの瞬間ごとに、その瞬間を含むすべての間隔を調べます。 これらのアクティブな間隔の中には、一度だけ現れる色が存在するはずです。 色は多くのインターバルでグローバルに使用できますが、対象となる時点ではアクティブなインターバルの中で少なくとも 1 つの一意に表現される色が必要です。 

タスクは、可能な最小限の色を見つけて、1 つの有効な色を構築することです。 

簡単なバージョンでは、整数座標だけでなく、実線全体でオーバーラップを使用します。 間隔が詰まっているので、次のような 2 つの間隔$[1,2]$そして$[2,3]$一点で重なる$2$。 

すべてのテスト ケースにわたる間隔の合計数は最大で次のとおりです。$2 \cdot 10^5$。 間隔のすべてのペアをチェックするソリューションでは、すでに$O(n^2)$おおよそ到達するであろう仕事$4 \cdot 10^{10}$最悪の場合の運用。 平$O(n^2)$記憶は不可能です。 周りに何かが必要です$O(n \log n)$。 

問題の最も危険な部分は、線上のすべての点で何が保持されるべきかを理解することです。 

考慮する：```
[1,4]
[2,5]
[3,6]
```時間に$3.5$、3 つの間隔すべてがアクティブです。 3 つすべてが同じ色を受け取る場合、色は一度だけ表示されないため、その色付けは無効になります。 

もう 1 つの微妙なケースは、エンドポイントの交差です。```
[1,2]
[2,3]
```時間ごとに間隔が重なる$2$。 両方の間隔に同じ色を与えると失敗します。$2$その色は 2 回表示され、他の色は存在しません。 

3 番目の罠は、最大のオーバーラップのみが重要であると仮定することです。 例えば：```
[1,5]
[2,6]
[3,7]
[4,7]
[6,7]
```最大オーバーラップサイズは次のとおりです。$4$、しかし答えは$3$、 ない$4$。 この条件は、アクティブなインターバル間の色の多重度に関するものであり、すべてのアクティブなインターバルが個別の色を受け取るようにするものではありません。 

有効なカラーリングの構造を理解することが、問題を解決する鍵となります。 

## アプローチ

 強引な視点は、ライン上のすべての重要な点について考えることです。 すべての間隔エンドポイントを収集した後、アクティブな間隔のセットはエンドポイントを通過するときにのみ変更されます。 連続するエンドポイント間のすべての領域を調べて、そこで条件を強制することができます。 

すでにカラーリングを修正したとします。 すべての領域について、各色のアクティブな間隔がいくつ存在するかを数え、ある色が 1 回だけ出現することを確認します。 カラーリング一つ確認するだけでも高くつきます。 この方法で最適なカラーリングを構築することは完全に不可能です。 

画期的な発見は、オーバーラップ グラフを観察することです。 

頂点が区間であるグラフを作成します。 対応する間隔が交差する場合、2 つの頂点は隣接しています。 直線上の間隔を扱うので、これは間隔グラフになります。 

今、ある点に焦点を当ててください$t$。 を含むすべての間隔$t$それらのすべてのペアが次の点で交差するため、オーバーラップ グラフ内でクリークを形成します。$t$。 

オーバーラップグラフに適切な色を付けたとします。 次に、すべてのクリークの内部では、すべての頂点が異なる色になります。 特に、任意の点をカバーする区間の中で$t$、すべてのアクティブな色が 1 回だけ表示されます。 必要な条件は自動的に満たされます。 

これにより、有効な色がすぐに得られます。 

次の問題は、本当に適切な色付けが必要かどうかです。 驚くべきことに、この問題で必要な最小色の数は、まさに区間グラフの色数です。 

なぜ？ 

すべて同じ点をカバーする任意の間隔セットを取得します$t$。 ありましょう$m$そういった間隔。 

時間に$t$、その中のすべての色のクラス$m$間隔には最大 1 つの間隔を含める必要があります。 ある色が 2 回出現した場合、その色は一意ではなくなります。 すべての色が現れたらどちらか$0$または少なくとも$2$場合によっては、固有に発生する色は存在しません。 したがって、共通点を通る区間はすべて異なる色を受け取る必要があります。 

したがって、あらゆる規模の勢力が$m$少なくとも必要です$m$色。 答えは少なくとも最大クリーク サイズです。 

区間グラフの場合、古典的な定理は次のように述べています。$$\chi = \omega$$どこ$\chi$は彩色番号であり、$\omega$クリークの最大サイズです。 

最大クリーク サイズは同時にアクティブな間隔の最大数に等しいため、問題は間隔グラフを最適に色付けすることになります。 

間隔グラフでは、非常に単純な貪欲な色付けが可能です。 

間隔を左のエンドポイントで並べ替えます。 左から右に処理します。 間隔が開始されるたびに、前の間隔がすでに終了している使用可能な最小の色を再利用します。 空いている色がない場合は、新しい色を作成します。 

この貪欲なアルゴリズムは、間隔グラフに最適な最大オーバーラップ数を正確に使用します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) 以上 | O(n²) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての間隔を元のインデックスとともに保存します。 
2. 左端の値を増やして間隔を並べ替えます。 
3. 現在アクティブな色の優先キューを維持します。 各エントリーストア`(right_endpoint, color)`。 
4. 再利用できる空き色を含む別の優先キューを維持します。 
5. 新しい間隔を処理する前に$[l,r]$、右端が厳密に よりも小さいアクティブな間隔を繰り返し削除します。`l`。 

間隔が閉じているため、間隔は次のように終了します。`l`ポイントではまだ新しい間隔と重なっています`l`。 このような色はまだ再利用できません。 
6. 削除された間隔ごとに色が解放されます。 その色を自由色ヒープに挿入します。 
7. 自由な色が存在する場合は、最小の色を選択し、それを現在の間隔に割り当てます。 
8. それ以外の場合は、新しい色を作成します。 総色数を 1 つ増やして、その新しい色を割り当てます。 
9.挿入`(r, assigned_color)`into the active heap.
 10. 割り当てられた色を間隔の元の位置に保存します。 
11. すべての間隔が処理された後、色の数と構築されたカラーリングを出力します。 

### なぜ効果があるのか

 すべてのステップで、アクティブ ヒープには、現在の位置と重なる間隔が正確に含まれます。 色は、前の間隔が終了した後、厳密に次の間隔が開始する前にのみ再使用されます。つまり、2 つの間隔は互いに素です。 

したがって、重なり合う 2 つの間隔が同じ色になることはありません。 色付けは区間グラフの適切な色付けです。 

どの点でも$t$を含むすべての間隔$t$徒党を形成する。 色付けが適切であるため、そのクリークのすべての間隔に明確な色が付けられます。 すべてのアクティブな色は 1 回だけ表示されるため、必要な条件は満たされます。 

貪欲アルゴリズムで使用される色の数は、同時にアクティブな間隔の最大数と等しくなります。 その量は区間グラフのクリーク数であり、有効な解の下限となります。 アルゴリズムがその下限を達成するため、カラーリングは最適になります。 

## Python ソリューション```python
import sys
import heapq

input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())

        intervals = []
        for i in range(n):
            l, r = map(int, input().split())
            intervals.append((l, r, i))

        intervals.sort()

        active = []      # (right, color)
        free_colors = [] # available colors

        colors = [0] * n
        color_cnt = 0

        for l, r, idx in intervals:
            while active and active[0][0] < l:
                _, c = heapq.heappop(active)
                heapq.heappush(free_colors, c)

            if free_colors:
                c = heapq.heappop(free_colors)
            else:
                color_cnt += 1
                c = color_cnt

            colors[idx] = c
            heapq.heappush(active, (r, c))

        out.append(str(color_cnt))
        out.append(" ".join(map(str, colors)))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```間隔は開始点によって並べ替えられます。これは、新しいオーバーラップが表示される自然な順序であるためです。 

アクティブ ヒープは、将来の間隔と重複する可能性のある間隔が現在占有している色を追跡します。 条件`active[0][0] < l`重要です。 間隔は閉じられているため、間隔は次のように終了します。`l`は、新しい間隔とちょうど 1 点で交差します。 その色を再利用すると、重複する間隔に同じ色が割り当てられ、正確さが損なわれます。 

フリーカラー ヒープには、使用可能になったカラーが格納されます。 利用可能な最小の色を再利用することは、正確さを保つために必須ではありませんが、コンパクトな色を生成し、実装が簡単です。 

すべての間隔でヒープに 1 回だけ出入りします。$O(n \log n)$複雑。
