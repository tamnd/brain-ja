 ## 解決策
 ## 問題の理解

 真っ直ぐなフェンスセグメントで形成された平面図が与えられています。 各セグメントは 2 つのグリッド ポイントを接続し、すべてのセグメントが一緒になって、交差や冗長なエッジのない単一の接続された平面グラフを形成します。 グラフは平面であり、ブリッジなしで完全に接続されているため、エッジは平面を作物畑に対応する一連の境界領域に分割します。 

各フィールドはポリゴンであり、その境界はこれらのフェンス セグメントのいくつかによって形成されます。 タスクは総面積を計算することではなく、これらすべての多角形面の二乗面積の合計を計算することです。 

入力サイズは十分に小さいため、平面埋め込みを明示的に再構築して面を列挙できます。 座標は最大 1000 までの 2D グリッド内にあり、最大 1000 個のセグメントがあるため、グラフベースの幾何学的再構成が可能です。 

微妙な難点は、顔が直接与えられていないことです。 各頂点の周囲のエッジの隣接性を周期的な順序で推測し、各面の周囲を 1 回だけ正確に歩き回る必要があります。 各多角形を抽出した後、その符号付き面積を計算し、その正方形を累積します。 

単純な試みでは、平面をグリッド上で満たそうとする可能性があります。 座標は単位グリッド セルではなく、連続した線分であるため、これは失敗します。 もう 1 つの素朴なアイデアは、セグメントを交差させて明示的に交差を構築することですが、この問題ではエンドポイント以外に交差がないことが保証されているため、これは不要ですが、誤って試行されることがよくあります。 

さらに重要な特殊なケースは、面が退化しているか、面積が非常に小さい可能性があることです。 サンプル入力では、1 つの面の面積は 0.5 です。これは、一般に対角線状のジオメトリにより部分的な領域が発生することを示しています。 整数のみの算術アプローチはここで機能しません。 

もう 1 つの微妙な落とし穴は、外側の面が誤って含まれるか除外されるべきであると仮定することです。 すべての境界領域を合計しているため、無限の外側の面を無視する必要があります。 

## アプローチ

 ブルートフォース解釈では、グラフ内の可能なすべてのサイクルを探索することにより、すべての面を明示的に再構築しようとします。 それぞれの有向エッジから開始し、一貫した回転ルールを維持しながら開始位置に戻るまで歩くことを試みることを想像することができます。 これは本質的に、構造を埋め込まない面の列挙です。 問題は、近傍を幾何学的にソートしないと、特に密な平面グラフでは、走査が分岐して、指数関数的に多くの循環ウォークを再訪問する可能性があることです。 グラフ サイズがわずか 1000 エッジであっても、ナイーブ サイクルの数が非常に大きくなる可能性があり、そのようなアプローチは非現実的になります。 

重要な構造的観察は、平面埋め込みグラフがすべての頂点の周囲のエッジの固定された循環順序を定義していることです。 各頂点の周囲のエッジを極角で並べ替えると、決定的な「次のエッジ」ルールを定義できます。つまり、エッジに沿って到着すると、面の次のエッジは頂点の周囲の次の時計回りのエッジになります。 これにより、問題は標準的な平面のトラバースに変換されます。 各有向エッジは各方向の 1 つの面トラバースに属するため、すべての面が 1 回だけ検出されます。 

顔を抽出したら、靴紐の公式を使用してその面積を簡単に計算します。 最終的な答えは、絶対面積の二乗和にすぎません。

 ## アルゴリズムのチュートリアル

 各無向セグメントを 2 つの有向ハーフエッジとして扱います。 中心となるアイデアは、すべての頂点に回転システムを構築して、頂点の周囲でエッジがどのように配置されるかを知ることです。

1. 各エンドポイントの有向エッジの隣接リストを構築します。 各セグメントは、各方向に 1 つずつ、2 つの有向エッジに寄与します。 面の移動は方向に依存するため、これが必要になります。 
2. 各頂点について、その頂点の周囲の極角によって出力近傍を並べ替えます。 を使用して角度を計算します`atan2(dy, dx)`。 この並べ替えにより、頂点周囲のエッジのローカルな時計回りまたは反時計回りの順序が定義されます。 
3. 各有向エッジからマッピングを構築する`(u -> v)`のソートされた隣接リスト内のインデックスに`u`。 これにより、一定時間の「次のエッジ」クエリが可能になります。 
4. 顔の遷移ルール​​を定義します。 頂点に到達したら`v`エッジ経由`(u -> v)`、その後、`v`入ってくるエッジとは反対の方向に注目します。`(v -> u)`。 で`v`の隣接順序に従って、次のエッジに移動します。`(v -> u)`周期的に。 これにより、常に面をトラバースの同じ側に保つことができます。 
5. すべての有向エッジに対して反復処理を行います。 有向エッジにアクセスしていない場合は、新しい面のウォークを開始します。 開始の有向エッジに戻るまで、遷移ルール​​に繰り返し従います。 訪問したすべての頂点を順番に記録します。 
6. 収集されたサイクルにわたって靴紐の式を使用してポリゴンの面積を計算します。 符号付き領域は向きに応じて正または負になるため、絶対値を採用します。 
7. 外側の面を除くすべての面の平方面積を合計します。 外側の面は最大の大きさの領域を生成するため、識別できます。 あるいは、追跡符号規則に従ってすべての面を含めて外側の面を減算することもできますが、より簡単な方法は、一貫した時計回りの埋め込みを使用する場合は、すべてを計算して負の向きの面を無視することです。 

### なぜ効果があるのか

 平面埋め込みと巡回順序付けにより、有向エッジを面境界に一意に分割する回転システムが定義されます。 重要な不変条件は、「次のエッジ」ルールが常に、隣接する領域に交差することなく 1 つの面の境界を通過し続けることです。 このシステムでは各有向エッジに 1 つの後続エッジがあるため、すべての面の境界が閉じたサイクルを形成し、すべての有向エッジがまさに 1 つのそのようなサイクルに属します。 これにより、重複のない完全なカバレッジが保証され、すべての境界領域が正確に 1 回カウントされることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def area(poly):
    s = 0
    n = len(poly)
    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]
        s += x1 * y2 - x2 * y1
    return abs(s) / 2

def solve():
    F = int(input())
    edges = []
    adj = {}

    for _ in range(F):
        x1, y1, x2, y2 = map(int, input().split())
        edges.append((x1, y1, x2, y2))
        adj.setdefault((x1, y1), []).append((x2, y2))
        adj.setdefault((x2, y2), []).append((x1, y1))

    # sort neighbors by angle
    import math
    pos = {}
    for u in adj:
        ux, uy = u
        nbrs = adj[u]
        nbrs.sort(key=lambda v: math.atan2(v[1] - uy, v[0] - ux))
        pos[u] = {v: i for i, v in enumerate(nbrs)}

    visited = set()
    res = 0.0

    for u in adj:
        for v in adj[u]:
            if (u, v) in visited:
                continue

            poly = []
            cu, cv = u, v

            while True:
                visited.add((cu, cv))
                poly.append(cu)

                ux, uy = cu
                vx, vy = cv

                # at v, we came from u, so consider reverse edge v->u
                nbrs = adj[(vx, vy)]
                idx = pos[(vx, vy)][(ux, uy)]
                nxt = nbrs[(idx + 1) % len(nbrs)]

                cu, cv = cv, nxt

                if (cu, cv) == (u, v):
                    break

            res += area(poly)

    print(f"{res * res:.10f}")

if __name__ == "__main__":
    solve()
```この実装では、幾何学的な隣接マップを構築し、極角を使用して各頂点にエッジの循環順序を割り当てます。 面の境界は横断方向に依存するため、重要な点は、有向エッジを一貫して使用することです。 

トラバーサル ループは、開始有向エッジに再び到達するまで、頂点を順番に記録します。 靴紐の式はサイクルごとに適用されます。 最後に、問題の要件に合わせて、最後に面積の合計が 2 乗されます。 

微妙な実装ポイントはマッピングです。`pos[v][u]`これは、すべての無向エッジが両方向に存在すると仮定します。 この対称性が崩れると、フェイスウォーク ルールは直ちに失敗します。

 ## 特殊なケース

 重要なケースの 1 つは、グラフが内部分割のない単一の単純なサイクルを形成する場合です。 この状況では、すべての頂点の次数が 2 であるため、角度の順序は自明です。 トラバースは常に他のエッジのみに移動し、アルゴリズムは正確に 1 つの面サイクルを正確に生成します。 

もう 1 つのケースは、複数のエッジが頂点で交わって扇形を形成する場合です。 ここでは、正しい角度ソートが不可欠です。 ソートを行わないと、トラバースはエッジ間を任意にジャンプし、無効なポリゴンが生成されます。 ソートを使用すると、次エッジ ルールによってローカルな面の境界が一貫して保存され、連続するエッジ間の各ウェッジが個別の面セグメントになります。 

最後の微妙なケースは、角度計算における浮動小数点の安定性です。 座標は小さな整数であるため、次のように使用します。`atan2`ここでは安全ですが、実稼働グレードのソリューションでは、浮動精度の問題を回避するために製品間の比較に置き換えることができます。
