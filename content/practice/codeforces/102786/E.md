## アプローチ

 直接的な解決策は、次のすべての数値を列挙することです。`1`に`N`、その桁の合計を計算し、ペアを保存します`(digit sum, number)`, and sort them. 並べ替えキーが必要な順序と正確に一致するため、これは正しいです。 However, when`N`到達する`10^18`、生成される要素の数は、プログラムが処理できる数をはるかに超えています。 最悪の場合は約`10^18`桁の合計の計算と、同様に大きなコレクションのソート。 

便利な構造は、桁の合計に小さな範囲があることです。 数値を生成する代わりに、各桁の合計グループに属する数値の数を数えることができます。 位置を含むグループがわかったら`M`、残りのタスクは、`M`- 1 つの固定桁の合計を持つ最小の数。 

計数は桁動的プログラミングで実行できます。 位置は 19 個しかないため、プレフィックスが固定された後、特定の残りの合計を持つ数字列が何個可能かを数えることができます。 これらのカウントを使用すると、膨大な範囲の数値を作成せずにスキップできます。 

必要な桁の合計を見つけたら、回答を桁ごとに作成します。 同じ桁の合計を持つ数値は昇順で表示されます。これは、すべての数値が同じ長さである場合の辞書順と同じです。 まず正しい長さを決定し、次に、そこに小さい桁を入力した場合に有効な補完がいくつ存在するかを数えて、各桁を選択します。

 ## アルゴリズムのチュートリアル

 1. 事前計算`ways(length, sum)`、すべての数字がどこから始まるかを示す、指定された長さの数字シーケンスの数`0`に`9`そして、桁の合計は以下に等しい`sum`。 このテーブルは、他の場所でも使用されるコア数カウント ツールです。 

これらのシーケンスには、数値の残りの接尾辞を表すため、先行ゼロが含まれる場合があります。 カウント中に全長が固定されるため、先行ゼロは問題を引き起こしません。 
2. 可能なすべての桁の合計について、`1`上向きに、何番目の数字を計算しますか`1`に`N`その桁の合計があります。 

カウントは桁DPで取得されます。 の数字をスキャンします`N`左から右に、現在のプレフィックスが既に以下より小さいかどうかを判断します。`N`またはまだそれと等しい。 先頭のゼロ表現を使用すると、短い長さのすべての正の数を自動的にカウントできます。 
3. から完全な桁の合計グループを減算します。`M`答えを含むグループが見つかるまで。 

このステップの後、`M`は 1 つの固定桁和グループ内の位置になります。 
4. 必要な数値の長さを見つけます。 

考えられる長さごとに、その長さの中で必要な桁の合計がいくつあるかを数えます。 桁数の少ない正の数値は数値的に小さいため、短い長さは常に長い長さよりも前に来ます。 
5. 左から右に答えを作成します。 

各位置で、可能な数字を昇順に試してください。 すべての候補数字について、残りの位置が残りの数字の合計で数字を完成できる方法が何通りあるかを数えます。 現在の場合`M`がその数より大きい場合は、それらの数値をすべてスキップします。 それ以外の場合、答えはその数字から始まります。 
6. 構築された数値を出力します。 

これが機能する理由は、スキップされたすべてのブロックが、必要な順序付けの連続した間隔に対応しているためです。 数字 DP は、各間隔内に有効な数値がいくつあるかを正確にカウントするため、`M`これらのカウントによって、目的の数値の相対位置が変更されることはありません。 構築中、選択されるプレフィックスは常に、そのブロックに残りの位置が含まれる最小のプレフィックスになります。これにより、答えがまだ残りの検索範囲内にあるという不変条件が保持されます。 

## Python ソリューション```python
import sys
from functools import lru_cache

input = sys.stdin.readline

@lru_cache(None)
def ways(length, total):
    if length == 0:
        return 1 if total == 0 else 0
    if total < 0:
        return 0
    res = 0
    for d in range(10):
        res += ways(length - 1, total - d)
    return res

def count_up_to(n, target_sum):
    digits = list(map(int, str(n)))
    m = len(digits)

    @lru_cache(None)
    def dp(pos, remaining, tight):
        if pos == m:
            return 1 if remaining == 0 else 0

        limit = digits[pos] if tight else 9
        ans = 0

        for d in range(limit + 1):
            if remaining >= d:
                ans += dp(pos + 1, remaining - d, tight and d == limit)

        return ans

    return dp(0, target_sum, True)

def count_exact_length(length, target_sum):
    ans = 0
    for first in range(1, 10):
        if target_sum >= first:
            ans += ways(length - 1, target_sum - first)
    return ans

def solve_case(n, m):
    digit_sum = 1

    while True:
        cnt = count_up_to(n, digit_sum)
        if m <= cnt:
            break
        m -= cnt
        digit_sum += 1

    length = 1
    while True:
        cnt = count_exact_length(length, digit_sum)
        if m <= cnt:
            break
        m -= cnt
        length += 1

    result = []
    remaining = digit_sum

    for pos in range(length):
        start = 1 if pos == 0 else 0

        for digit in range(start, 10):
            if remaining < digit:
                continue

            cnt = ways(length - pos - 1, remaining - digit)

            if m > cnt:
                m -= cnt
            else:
                result.append(str(digit))
                remaining -= digit
                break

    return ''.join(result)

def main():
    n, m = map(int, input().split())
    print(solve_case(n, m))

if __name__ == "__main__":
    main()

最後の構築ループは、`M`-番目の番号が回復されます。 長さがすでに固定されているため、数字を昇順で試行すると数値の順序と一致します。 スキップされた各桁は有効な数値の完全なブロックを表すため、そのサイズを減算することは、順序付けされたシーケンスを前に進めることと同じです。

## テストケース```python
import sys
import io
from functools import lru_cache

def build_solver():
    @lru_cache(None)
    def ways(length, total):
        if length == 0:
            return 1 if total == 0 else 0
        return sum(ways(length - 1, total - d) for d in range(10))

    def count_up_to(n, target_sum):
        digits = list(map(int, str(n)))
        m = len(digits)

        @lru_cache(None)
        def dp(pos, remaining, tight):
            if pos == m:
                return remaining == 0
            limit = digits[pos] if tight else 9
            ans = 0
            for d in range(limit + 1):
                if remaining >= d:
                    ans += dp(pos + 1, remaining - d, tight and d == limit)
            return ans

        return dp(0, target_sum, True)

    def count_exact_length(length, total):
        return sum(
            ways(length - 1, total - d)
            for d in range(1, 10)
            if total >= d
        )

    def solve_case(n, m):
        s = 1
        while True:
            c = count_up_to(n, s)
            if m <= c:
                break
            m -= c
            s += 1

        length = 1
        while True:
            c = count_exact_length(length, s)
            if m <= c:
                break
            m -= c
            length += 1

        ans = []
        remaining = s
        for pos in range(length):
            for d in range(1 if pos == 0 else 0, 10):
                if remaining >= d:
                    c = ways(length - pos - 1, remaining - d)
                    if m > c:
                        m -= c
                    else:
                        ans.append(str(d))
                        remaining -= d
                        break
        return ''.join(ans)

    return solve_case

solve = build_solver()

def run(inp: str) -> str:
    n, m = map(int, inp.split())
    return solve(n, m)

assert run("100 10") == "21"
assert run("1 1") == "1"
assert run("9 9") == "9"
assert run("20 5") == "20"
assert run("1000 3") == "100"
