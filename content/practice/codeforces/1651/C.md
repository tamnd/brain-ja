 ## 解決策
 ## 問題の理解

 2 列に配置されたコンピューターのネットワークがあり、それぞれに次のものが含まれています。`n`コンピューター。 各コンピューターには、整数で表される関連付けられたグレードがあります。 同じ行にあるコンピューターは、最初はすぐ隣のコンピューターに接続され、2 つの独立したチェーンを形成します。 私たちの目標は、2 つの列にわたってコンピューターを接続して、単一のフォールト トレラント ネットワークを形成することです。 ここでのフォールトトレラントとは、1 台のコンピュータに障害が発生した場合でも、ネットワークが完全に接続された状態を維持する必要があることを意味します。 

パソコンの接続にかかる費用`i`最初の行からコンピュータまで`j`2列目からは成績の絶対差、`|a_i - b_j|`。 ネットワークをフォールトトレラントにするための最小総コストを見つけたいと考えています。 

制約は大きくなります。`n`まで可能です`2 * 10^5`まであります`10^4`テストケース。 これにより、接続のすべてのペアを直接試行するソリューションは除外されます (`O(n^2)`)、それには必要な場合があるため、`10^9`操作。 ソリューションは、`n`テストケースごとに。 

エッジケースには、1 つの行がすべてであるなど、等級の極端な値が現れる状況が含まれます。`1`とその他のすべて`10^9`s. 複数の接続オプションを考慮せずに「最近傍」のみを接続する単純なアプローチは、このような場合に失敗する可能性があります。 さらに、小規模ネットワーク (`n = 3`) はフォールトトレラントな方法で接続する必要があるため、行間の接続について慎重に検討する必要があります。 

## アプローチ

 ブルート フォース アプローチでは、行間接続の可能なすべてのセットを試し、単一ノードで障害が発生した後も結果のグラフが接続されたままであるかどうかを確認します。 これは正しい答えを与えますが、計算上実行不可能です。`n`まで`2 * 10^5`。 

重要な点は、フォールト トレランス要件により、各列のすべての「エンド」コンピューターが反対側の列の少なくとも 1 台のコンピューターに接続される必要があるということです。 さらに、コンピュータを他の列の最も近いグレードに接続すると、コストが最小限に抑えられる傾向があります。 より正式には、必要な最小限の接続は次のとおりです。 

-`a[0]`一部の人に`b[j]`-`a[n-1]`一部の人に`b[k]`-`b[0]`一部の人に`a[p]`-`b[n-1]`一部の人に`a[q]`オプションで他のコンピューターも接続できますが、これら 4 つのエンドポイントを接続すると、1 台のコンピューターに障害が発生した場合でもネットワークは接続されたままになります。 したがって、問題は、絶対差の合計を最小化する方法でこれら 4 つの接続を選択することになります。 以来`n`サイズが大きくなる可能性があるため、すべての組み合わせを試すことはできません。 ただし、これら 4 つのケースのそれぞれについて、すべてのケースの最小絶対差を事前に計算することはできます。`n`反対側の列にはコンピューター。 次に、合計コストは、同じエンドポイントが複数の条件を最適に満たす場合に二重カウントを避けるためにいくつかの追加処理を加えた、これらの最小絶対差の合計になります。 

これにより、問題は次のように変換されます。`O(n^4)`に`O(n)`テストケースごとに、これは実現可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^4) | O(n^2) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最初の行の各エンドポイントについて (`a[0]`そして`a[n-1]`)、2 行目の任意のコンピューターとの最小絶対差を計算します。 これにより、接続コストが最小限に抑えられます`a[0]`そして`a[n-1]`。 
2. 同様に、2 行目の各エンドポイント (`b[0]`そして`b[n-1]`)、最初の行の任意のコンピューターとの最小絶対差を計算します。 これにより、接続コストが最小限に抑えられます`b[0]`そして`b[n-1]`。 
3. エンドポイントを他の行の対応するエンドポイントに直接接続する方が、最近傍に接続するよりも優れている可能性がある追加の組み合わせを計算します。 具体的には、直接接続について考えてみましょう。 

-`a[0]`に`b[0]`-`a[0]`に`b[n-1]`-`a[n-1]`に`b[0]`-`a[n-1]`に`b[n-1]`4. フォールト トレランスを保証するために、4 つのエンドポイントすべてをカバーする接続の合理的な組み合わせをすべて評価します。 それぞれの組み合わせについて、絶対差を合計します。 これらの組み合わせにおける最小の総コストを追跡してください。 
5. 最小総コストを出力します。 

機能する理由: 4 つのエンドポイントを最適に接続することで、1 台のコンピューターを削除してもネットワークが接続されたままになることが保証されます。 接続を追加するとコストが増加するだけです。 したがって、最小の総コストを見つけるには、これらのエンドポイント接続とその最適なペアリングのみを考慮するだけで十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def min_abs(a_val, arr):
    return min(abs(a_val - x) for x in arr)

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    # Minimal differences from endpoints to any opposite row computer
    a0_to_b = min_abs(a[0], b)
    an_to_b = min_abs(a[-1], b)
    b0_to_a = min_abs(b[0], a)
    bn_to_a = min_abs(b[-1], a)
    
    # Direct endpoint-to-endpoint connections
    a0_b0 = abs(a[0] - b[0])
    a0_bn = abs(a[0] - b[-1])
    an_b0 = abs(a[-1] - b[0])
    an_bn = abs(a[-1] - b[-1])
    
    # Compute candidate total costs
    candidates = [
        a0_to_b + an_to_b + b0_to_a + bn_to_a,
        a0_b0 + an_bn + b0_to_a + bn_to_a,
        a0_bn + an_b0 + b0_to_a + bn_to_a,
        a0_b0 + an_to_b + b0_bn + bn_to_a,
        a0_bn + an_to_b + b0_b0 + bn_to_a,
    ]
    
    print(min(candidates))
```機能`min_abs`指定されたエンドポイントの最小絶対差を見つけます。 次に、4 つすべてのエンドポイントの最小限の差を事前計算し、代替としてエンドポイント間の直接接続を考慮し、フォールト トレランスのためにすべてのエンドポイントをカバーする複数の合理的な組み合わせを評価します。 トータルコストを最小限に抑えて出力します。
