 ## 解決策
 ## 問題の理解

 断片化された辞書からページのコレクションが与えられます。 各ページには識別子があり、固定数の単語が含まれています。 重要な隠された構造は、これらの単語がもともと標準的な英語の順序ではなく、未知のアルファベット順に従ってソートされていたということです。 私たちのタスクは、すべてのページをソートされた辞書エントリとして生成する可能性がある、アルファベット文字の 1 つの有効な順序を復元することです。 

重要な点は、各ページが同じ未知の文字順序の下で辞書編集的な順序と内部的に一貫していることです。 すべてのページにわたって、この順序は一貫している必要があります。 並べ替えられた順序で隣接する単語間の比較から、個々の文字間の順序制約を推定できます。 最終的な目標は、表示されるすべての文字の完全な順序を再構築することです。 

これらの制約が矛盾している場合、つまり次のようなサイクルを意味します。`a < b < c < a`の場合、有効なアルファベットが存在しないため、不可能を出力する必要があります。 

入力サイズの制限は中程度です。 最大 1,000 ページ、1 ページあたり 1,000 単語の合計単語数は最大 100 万単語になります。 各単語の比較の長さは直線的で、最大 100 文字です。 単語のすべてのペアをグローバルに単純に比較するのは遅すぎますが、すべてのペアが必要なわけではありません。 辞書編集の再構築には、ソートされた順序で隣接する単語のみが重要となるため、有効なグラフ サイズが大幅に減少します。 

プレフィックス関係に違反すると、微妙な失敗が発生します。 たとえば、辞書編集上の想定された順序で長い単語がその接頭語の前に出現する場合、辞書は一貫性がありません。 たとえば、次のようになります。`abcd`前に`ab`、これは辞書編集上の順序では不可能であり、すぐに結果が得られるはずです。`IMPOSSIBLE`。 

もう 1 つの注意が必要なケースは、切断された文字です。 一部の文字は制約に決して表示されない場合があります。 これらは、他のものに対して任意の順序で出力に表示される必要があります。つまり、最終結果は必ずしも一意ではありません。 

## アプローチ

 ブルートフォースの試みでは、すべての個別の文字の完全な順序を推測し、すべてのページがその順序に従ってソートされているかどうかを確認しようとします。 あれば`C`独特のキャラクターがいます`C!`並べ替えの可能性があり、1 つの順序をチェックする場合でも、すべての単語をスキャンして比較する必要があるため、たとえ小さな入力であっても、まったく実行不可能な爆発が発生します。 

重要な点は、順序を直接推測する必要がないということです。 代わりに、辞書構造からペアごとの順序付け制約を抽出できます。 連続する 2 つの単語が異なる場合は常に、それらが異なる最初の位置によって 2 つの文字間の厳密な順序が決まります。 たとえば、次の場合`word1 = "abcx"`そして`word2 = "abdy"`、そして私たちは推測します`c < d`。 

これにより、問題は、ノードが文字でエッジが順序付け制約を表す有向グラフの構築に変換されます。 グラフが構築されると、トポロジカルな順序を見つけることが問題になります。 サイクルが存在する場合、有効なアルファベットは存在しません。 

追加の唯一の微妙な点は、プレフィックス違反の処理です。`word1`から始まる`word2`しかし、それよりも長く、`word1`前に現れます`word2`、グラフの構造に関係なく、順序付けは無効です。 

これにより、指数関数的な検索からグラフの構築およびトポロジカルなソートまでの問題が軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース順列 | O(C!・N・L) | O(C) | 遅すぎる |
 | グラフ + トポソート | O(合計文字数 + 制約) | O(C + E) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各ページのすべての単語を指定された順序で収集します。 各ページはすでに同じ未知のアルファベットでソートされているため、各ページを独立して扱います。 
2. ページごとに、連続する単語のすべてのペアを比較します。 各ペアについて、異なる最初の位置を見つけます。 異なる文字ペアの場合`(a, b)`が見つかったら、有向エッジを追加します`a → b`意味`a`前に来なければなりません`b`アルファベットで。 
3. 異なる位置は存在しないが、最初の単語が 2 番目の単語より長い場合、順序付けは無効です。 これは、長い単語が誤って接頭辞の前にあるという接頭辞違反に相当します。 
4. 単語に出現するすべての文字に対して有向グラフを構築し、各ノードの入次数を計算します。 
5. 次数が 0 のすべてのノードのキューを使用して、トポロジカル ソートを実行します。 繰り返しノードを削除し、出力エッジを緩和して結果に追加します。 
6. 結果の順序付けに入力に出現するすべての文字が含まれていない場合は、サイクルが存在し、出力します。`IMPOSSIBLE`。 

### なぜ効果があるのか

 各エッジは、辞書の順序と一致する有効なアルファベットで保持する必要がある必要な制約をエンコードします。 有効なアルファベットはすべてそのような制約を満たさなければならないため、グラフのトポロジカルな順序付けでなければなりません。 逆に、辞書編集的な比較は最初の異なる文字のみに依存し、それらの違いはエッジで正確に捕捉されるため、トポロジカルな順序付けはすべてのペアごとの制約を満たします。 したがって、問題は、有向グラフが非巡回であるかどうかを確認し、トポロジカルな順序付けを生成するかどうかを確認することに帰着します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from collections import defaultdict, deque

def solve():
    n, k = map(int, input().split())
    
    words = []
    present = set()
    
    pages = []
    
    for _ in range(n):
        p = int(input())
        page_words = [input().strip() for _ in range(k)]
        pages.append(page_words)
        for w in page_words:
            words.append(w)
            for c in w:
                present.add(c)
    
    adj = defaultdict(set)
    indeg = {c: 0 for c in present}
    
    def add_edge(a, b):
        if b not in adj[a]:
            adj[a].add(b)
            indeg[b] += 1
    
    for page in pages:
        for i in range(k - 1):
            w1, w2 = page[i], page[i + 1]
            m = min(len(w1), len(w2))
            found = False
            for j in range(m):
                if w1[j] != w2[j]:
                    add_edge(w1[j], w2[j])
                    found = True
                    break
            if not found:
                if len(w1) > len(w2):
                    print("IMPOSSIBLE")
                    return
    
    q = deque([c for c in indeg if indeg[c] == 0])
    order = []
    
    while q:
        c = q.popleft()
        order.append(c)
        for nxt in adj[c]:
            indeg[nxt] -= 1
            if indeg[nxt] == 0:
                q.append(nxt)
    
    if len(order) != len(indeg):
        print("IMPOSSIBLE")
        return
    
    print("".join(order))

if __name__ == "__main__":
    solve()
```実装は、入力に現れるすべての文字がグラフで表現されるように、すべての文字を収集することから始まります。 最終的なアルファベットには孤立した文字も含める必要があるため、これは重要です。 

エッジはノードごとのセットに保存され、重複した制約によって入次数が誤って増大するのを回避します。 これにより、同じ順序関係がページ間で複数回観察された場合の過剰カウントが防止されます。 

接頭辞チェックは、隣接する 2 つの単語が重複範囲内で異なっていない場合、ただちに処理されます。 これは最も一般的な微妙な間違いの 1 つです。これがないと、無効な辞書が誤ってグラフ ステージを通過する可能性があります。 

トポロジカルソートはカーンのアルゴリズムを使用します。 正確さは、一意のエッジごとに 1 回だけ度数を減分することに依存します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    from collections import defaultdict, deque

    def solve():
        n, k = map(int, input().split())
        pages = []
        present = set()

        for _ in range(n):
            p = int(input())
            page = [input().strip() for _ in range(k)]
            pages.append(page)
            for w in page:
                for c in w:
                    present.add(c)

        adj = defaultdict(set)
        indeg = {c: 0 for c in present}

        def add_edge(a, b):
            if b not in adj[a]:
                adj[a].add(b)
                indeg[b] += 1

        for page in pages:
            for i in range(k - 1):
                w1, w2 = page[i], page[i + 1]
                m = min(len(w1), len(w2))
                ok = False
                for j in range(m):
                    if w1[j] != w2[j]:
                        add_edge(w1[j], w2[j])
                        ok = True
                        break
                if not ok and len(w1) > len(w2):
                    return "IMPOSSIBLE"

        q = deque([c for c in indeg if indeg[c] == 0])
        res = []

        while q:
            c = q.popleft()
            res.append(c)
            for nxt in adj[c]:
                indeg[nxt] -= 1
                if indeg[nxt] == 0:
                    q.append(nxt)

        if len(res) != len(indeg):
            return "IMPOSSIBLE"
        return "".join(res)

    return solve()

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、複数のページで同じ順序制約が繰り返される場合です。 エッジはセットに保存され、重複した度数増分が防止されるため、アルゴリズムはこれを正しく処理します。 

もう 1 つの特殊なケースは、出現するものの制約にまったく関与しない文字です。 これらのノードは、角度ゼロでグラフ内に残り、最終的な順序付けの任意の位置に自然に表示されます。 これにより、アルファベットが部分的にのみ制限されている場合でも、正確さが保たれます。 

最後の微妙なケースは、ページ全体に隠されたサイクル検出です。 たとえば、次のような制約があります。`a < b`、`b < c`、 そして`c < a`別のページから来ている可能性があります。 トポロジカル ソートは、グラフ内に存在するノードよりも少ない順序で終了し、明示的なサイクル検出ロジックを必要とせずに、不可能性を正しくトリガーします。
