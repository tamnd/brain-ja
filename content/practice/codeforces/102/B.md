 ## 解決策
 ## 問題の理解

 この問題では、数値が 1 桁の数値になるまで、数値をその桁の合計で繰り返し置き換えることが求められます。 入力は数値です`n`これは非常に大きくなり、最大 1,000 万桁になる可能性があります。 出力は、1 桁の数値に到達するために必要な変換の数です。 

入力サイズにより直ちに保存が除外されます。`n`数百万桁の整数はネイティブ データ型を超えるため、ほとんどのプログラミング言語で標準の整数として使用されます。 どちらともうまくいくアプローチが必要です`n`文字列として、またはすべての中間数値を完全に実体化せずに数字の合計のプロパティを活用します。 

重要なエッジケースは次の場合に発生します。`n`すでに一桁の数字になっています。 たとえば、次の場合`n = 0`または`n = 7`、変換は必要ないため、出力は次のようになります。`0`。 合計演算を自動的に実行する単純な実装では、誤って次の値が返されます。`1`この場合。 もう 1 つの微妙な点は、次のような非常に大きな数値です。`n = "9999999999999999999999"`。 正しいアルゴリズムでは、これを直接整数に変換しようとするべきではありません。 

## アプローチ

 最も単純なアプローチは総当たり法です。数値が 1 桁になるまで繰り返し桁の合計を計算します。 これは正しいです。各変換では数値の大きさが厳密に減少し、最終的な終了が保証されます。 次の数字を反復処理できます。`n`そしてそれらを合計します。 このアプローチの問題は、数百万桁の数値の場合、単純に実装すると、特に型間で数値を前後に変換する場合、繰り返し桁の合計が遅くなる可能性があることです。 

最適なアプローチでは、変換の数が桁の合計によって複数桁の数値を減らす回数によって決定されることが観察されます。 巨大な整数について心配する代わりに、次のように扱うことができます。`n`文字列として。 最初の反復で次のことを確認します。`n`桁が 1 つ以上あります。 「はい」の場合、数字を合計します (文字を個別に解析します)。 その後、一桁の数字に達するまで続けます。 各反復では、次のことを表す文字列を走査するだけで済みます。`n`または最初のパス後の小さな整数。 

これが機能するのは、最初の変換の後、数値が通常の整数として管理できるほど十分に小さくなるためです。 整数のオーバーフローは発生せず、中間整数形式で一度に 1,000 万桁を超える桁を保持しようとすることはありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(L * log n) | O(L) | 正しいですが、L が大きい場合は非効率的です |
 | 最適 | O(L) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 番号を読み取ります`n`文字列として。 これにより、非常に大きな数値による整数のオーバーフローが回避されます。 
2. 次のことを確認します。`n`すでに一桁の数字になっています。 「はい」の場合はすぐに戻ります`0`。 これにより、変換が必要ないという特殊なケースが処理されます。 
3. カウンタを初期化する`count`ゼロに。 これにより、変換の数が追跡されます。 
4. ながら`n`複数の数字がある場合は、各文字を整数に変換し、すべての数字を合計します。 交換する`n`この金額で。 インクリメント`count`1つずつ。 
5. 1回`n`は 1 桁の数値の場合、出力`count`。 

それが機能する理由: 不変条件は、各反復後に次のことです。`n`桁数や数値が厳密に小さくなります。 プロセスは次の場合に終了します。`n`は正確に 1 桁なので、実行された変換の数がカウントに正確に反映されることが保証されます。 このアルゴリズムは、最初の合計が数字の文字列を管理可能な整数に削減し、その後の合計は標準の整数型に収まるのに十分小さい数値を演算するため、非常に大きな初期入力でも機能します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = input().strip()

if len(n) == 1:
    print(0)
else:
    count = 0
    current = n
    while len(current) > 1:
        total = sum(int(ch) for ch in current)
        current = str(total)
        count += 1
    print(count)
```このソリューションでは、非常に大きな数値を処理するために、まず入力を文字列として読み取ります。 些細なケースを処理するために、入力に 1 桁しかないかどうかをすぐに確認します。 ループ内では、`sum(int(ch) for ch in current)`文字列全体を整数に変換せずにすべての桁の合計を効率的に計算し、オーバーフローを回避します。 合計した後、結果は文字列に変換され、ループ条件で桁数を確認できるようになります。 カウンタは、変換の数が正しいことを保証します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(L) | 各桁は、最初の反復で最大 1 回アクセスされます。 後続の反復では小さな整数が演算されます。 |
 | スペース | お(1) | 入力サイズに関係なく、現在の合計とカウンターのみを保存します。 |

 このアルゴリズムは、最大入力サイズが 1,000 万桁の場合でも効率的です。 最初の反復は入力長が線形であり、数値がすぐに 1 桁または 2 桁に減少するため、後続の反復は無視できます。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = input().strip()
    if len(n) == 1:
        return "0"
    count = 0
    current = n
    while len(current) > 1:
        total = sum(int(ch) for ch in current)
        current = str(total)
        count += 1
    return str(count)

# provided samples
assert run("0\n") == "0", "sample 1"
assert run("10\n") == "1", "sample 2"
assert run("991\n") == "3", "sample 3"

# custom cases
assert run("9\n") == "0", "single-digit input"
assert run("1234567890\n") == "2", "large multi-digit input"
assert run("99999999999999999999\n") == "2", "all nines large number"
assert run("10000000000000000000\n") == "2", "boundary leading one"
assert run("5\n") == "0", "minimum non-zero single-digit"
```| テスト入力 | 期待される出力 | 検証内容 |

 | "99999999999999999999" | "2" | 大きな入力、すべて同じ数字 |

 ## 特殊なケース

 アルゴリズムは、次の値を返すことによって 1 桁の入力を正しく処理します。`0`すぐに。 非常に大きな数の場合、`"99999999999999999999"`を使用すると、合計を文字列として効率的に計算し、2 桁の数値に減算し、再度合計して 1 桁の結果に達します。 出力`2`変換の正確な数を反映します。 文字列と整数の間の変換はオーバーフローを防ぐために慎重に制御され、最大 1,000 万桁の入力の正確性が保証されます。
