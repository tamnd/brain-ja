 ## 解決策
 ## 問題の理解

 私たちは次の単一行のキューを扱っています。$N$人々には、前 (位置 1) から後ろ (位置 1) まで暗黙的に番号が付けられます。$N$）。 この行にはアリスとボブという 2 人の人物がいますが、彼らの正確な立場は直接的には示されていません。 代わりに、2 つの相対的な観察が伝えられます。 

アリスは自分の前に何人の人が立っているかを知っています。 彼女が見たら$A$前に人がいる、つまり列の中での彼女の位置は$A + 1$。 

ボブは自分の後ろに何人の人がいるかを知っています。 彼が見たら$B$後ろに人がいるなら、彼の位置は次のようになるはずです$N - B$、彼の後の人は全員その中に数えられるので、$B$人々。 

タスクは、この行のアリスとボブの間に厳密に何人の人がいるかを判断することです。 

制約は小さいです。$N \le 1000$。 これは十分に低いので、位置の直接的な算術または総当りの再構築でも瞬時に行うことができます。 ここでは二次時間まではまだ些細なことですが、問題の構造は、位置が特定されれば定数時間の計算が可能であることを示唆しています。 

状態に微妙なエッジケースが見られます$A + B \ne N - 1$。 もし平等が保たれるなら、アリスとボブは順序のあいまいさを解消する形で隣接することになるでしょう。 この問題により、その縮退境界は回避されますが、値に応じてアリスがボブの前または後のいずれかになる可能性があるため、実装では依然として可能な順序を両方処理する必要があります。 

よくある間違いは、アリスが常にボブより前にあると仮定することです。 それは保証されません。 たとえば、次の場合$N = 10$、$A = 7$、$B = 1$, アリスは 8 位、ボブは 9 位なので、アリスはボブの前になります。 しかし、もし$A = 1$、$B = 7$、アリスは位置 2 にあり、ボブは位置 3 にあり、順序は依然として一貫していますが、構成が異なると役割が反転する可能性があります。 式では両方向を考慮する必要があります。 

## アプローチ

 ブルートフォース解釈では、制約を満たすキュー内のすべての可能な配置を反復することによって、アリスとボブの有効な位置を再構築しようとします。 アリスをその位置に配置できます$i = A + 1$、ボブの位置$j = N - B$、そしてそれらの間のインデックスの数を明示的にカウントします。 両方の位置が入力から一意に決定されるため、これですでに十分です。そのため、制約を正しく解釈すると、実際には組み合わせのあいまいさがなくなります。 

遅い考え方では、代わりにキューをシミュレートし、アリスとボブをサイズの配列に配置する可能性があります。$N$そしてオフセットを数えます。 それはまだ実行されます$O(N)$、これは不要ですが、制約の下では許容されます。 ただし、このアプローチでは、インデックス作成と off-by-one の処理において回避可能な複雑さが生じます。 

重要な洞察は、両方の位置が直接計算可能であるということです。 アリスをマッピングすると、$A+1$そしてボブに$N-B$、答えは純粋にこれらのインデックス間の絶対距離から 1 を引いたものです。 これにより、シミュレーションが回避され、問題全体が定数時間の演算に簡素化されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | キューのシミュレーション |$O(N)$|$O(N)$| 受け入れられるが不要 |
 | 直接位置計算 |$O(1)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. アリスの位置を次のように計算します。$pos_A = A + 1$。 これは、「前に立つ人々」の定義に直接従うものです。 
2. ボブの位置を次のように計算します。$pos_B = N - B$。 これは、ボブの後ろの人数を数え、それを前からの位置に変換した結果になります。 
3. それらの間の絶対距離を次のように計算します。$d = |pos_A - pos_B|$。 これにより、ライン上の位置間のステップ数が得られます。 
4. この距離から 1 を引いて、アリスとボブ自身の両方を除外し、厳密に両者の間の人数を算出します。 

インデックス内の距離は間接的にエンドポイントをカウントし、内部要素のみが必要であるため、減算ステップは重要です。 

### なぜ効果があるのか

 キューは線形構造であり、各人が 1 つの整数座標を正確に占有します。 アリスとボブの座標が独立した制約によって固定されると、それらを配置する自由はなくなります。 直線上の 2 つの位置間の人数は、厳密にはそれらの間の整数インデックスの数です。これは常に次のようになります。$|i - j| - 1$。 どちらの位置も一意に決定されるため、計算された値はキューのどのような解釈でも不変です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

N, A, B = map(int, input().split())

posA = A + 1
posB = N - B

print(abs(posA - posB) - 1)
```解決策は、推論を直接算術に変換します。 重要な実装の詳細は、位置に対して 1 から始まるインデックスを一貫して使用することです。 アリスの位置はフロント カウントから +1 シフトされますが、ボブの位置はサフィックス カウントから導出されます。 

最後の1の減算は間違いやすいです。 これがないと、結果にはアリスまたはボブがカウントに含まれることになり、問題の要件に矛盾します。 

## 実用的な例

 ### 例 1

 入力:$N = 10, A = 2, B = 3$アリスは所定の位置にいます$2 + 1 = 3$、ボブは位置にいます$10 - 3 = 7$。 

| ステップ | posA | posB | 距離 | 結果 |
 | --- | --- | --- | --- | --- |
 | 位置を計算する | 3 | 7 | - | - |
 | 距離を計算する | 3 | 7 | 4 | - |
 | エンドポイントを減算する | - | - | - | 3 |

 これにより、位置 4、5、および 6 がそれらの間にあることが確認されます。 

### 例 2

 入力:$N = 7, A = 1, B = 4$アリスは位置 2 にあり、ボブは位置 3 にあります。 

| ステップ | posA | posB | 距離 | 結果 |
 | --- | --- | --- | --- | --- |
 | 位置を計算する | 2 | 3 | - | - |
 | 距離を計算する | 2 | 3 | 1 | - |
 | エンドポイントを減算する | - | - | - | 0 |

 これは、それらが隣接しており、それらの間に人が存在しないというエッジケースを示しています。 

これらのトレースは、カウントを位置に変換し、標準のギャップ公式を使用することが正確であることを確認します。

 ## 特殊なケース

 いつ$A = 0$, アリスはキューの最前列の位置 1 にいます。たとえば、$N = 5, A = 0, B = 1$。 すると、アリスは 1、ボブは です$5 - 1 = 4$。 計算されたギャップは、$|1 - 4| - 1 = 2$。 このアルゴリズムは、アリスがキューの途中にいることを決して想定していないため、これをきれいに処理します。 

いつ$B = 0$, ボブは最後の位置にいます$N$。 例えば、$N = 6, A = 2, B = 0$。 アリスは 3 歳、ボブは 6 歳、プロデュース$|3 - 6| - 1 = 2$。 同じ式が特別なケースなしで適用されます。 

アリスとボブが隣接している場合、たとえば$N = 7, A = 1, B = 4$、位置 2 と 3 にマップされます。距離は 1 で、1 を引くと 0 になります。アルゴリズムは明示的な隣接チェックを必要とせずに自然に 0 を生成するため、脆弱な分岐ロジックが回避されます。
