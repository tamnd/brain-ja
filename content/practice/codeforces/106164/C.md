 ## 問題の理解

 整数の表現を構築するように求められます$X$1 から始まる自然数の固定プレフィックスを使用します。選択された長さに対して$N$、シーケンスを取得します$1, 2, 3, \dots, N$各数値にプラス記号またはマイナス記号を割り当てます。 結果の符号付き合計は次と等しくなければなりません$X$。 すべての有効な構造の中で、可能な限り小さい構造が必要です。$N$また、有効な符号の割り当てを 1 つ出力する必要があります。 

式の構造は非常に厳密に重要です。 数値のサブセットを選択しているのではなく、要素を並べ替えたりスキップしたりすることはできません。 1 から 1 までのすべての整数$N$正確に 1 回出現する必要があり、符号のみが柔軟です。 

この制約により、合計で最大 1000 のテスト ケースが許可されます。$|X|$すべてのケースにわたって、$2 \cdot 10^5$。 この限界は、任意の解が次の大きさに比例することを意味するため、重要です。$X$テストケースごとは許容されますが、二次関数は何でも受け入れられます。$X$すでに不要ですが、慎重に実装すればまだ限界に達する可能性があります。 ざっくりと入った構造$O(\sqrt{|X|})$テストケースごとに簡単に十分です。 

微妙な点は、この問題が単純に対称的ではないということです。 符号を変更すると寄与が反転しますが、プレフィックス構造により、到達可能な合計が固定の連続範囲を形成します。$N$ただし、パリティ制約を理解した後でのみです。 

いくつかのエッジの状況を切り分ける価値があります。 

もし$X = 0$、有効な最小値$N$は 1 です。$1$単独ではゼロを形成することはできません。 最初の重要なキャンセルは次の時点で発生します。$1 - 2 = -1$、したがってゼロには少なくとも必要です$1 - 2 + 3$、これは 2 に等しいので、$N = 3$動作します。 

もし$X$の大きさは非常に小さいですが負であるため、常に最初に正の数を追加しようとする単純な貪欲なアプローチではオーバーシュートが発生して修正が必要になる可能性があり、修正はパッチではなく体系的に処理する必要があります。 

もし$X$大きさが大きいため、重要な点は最小値を決定することです。$N$、その後に標識を建設するわけではありません。 

## アプローチ

 ブルートフォースの観点は修正することから始まります$N$そして、達成するために記号を割り当てることができるかどうかを尋ねます$X$。 与えられた$N$、 がある$2^N$課題に署名します。 各代入は 1 つの合計を生成するため、直接列挙することはすぐには不可能です。$N = 30$。

重要な洞察は、$N$、達成可能なサブセット合計の範囲が十分に密になるため、最小のものを見つけるだけで済みます。$N$そのような$S \ge |X|$そしてパリティマッチ。 その条件が満たされれば、建設的な貪欲な調整はいつでも可能になります。

 ## アルゴリズムのチュートリアル

 すべての正の数から開始して合計を修正するという考えに基づいてソリューションを構築します。 

1. 絶対値を計算する$A = |X|$なぜなら、この構造は符号に関して対称であり、後で方向を調整できるからです。 
2. 最小のものを見つける$N$合計が$S = \frac{N(N+1)}{2}$少なくとも$A$。 これにより、次の大きさに到達するのに十分な「重み」が確保されます。$X$。 これが機能する理由は、各数値が最大でもその最大値に寄与するため、到達可能な調整の合計が次のように二次関数的に増加するためです。$N$。 
3. パリティのチェック$S$そして$X$。 反転するたびに合計が変化するため、$2i$、最終的な合計のパリティは次のように固定されます。$S$。 もし$S \bmod 2 \neq X \bmod 2$、増分$N$パリティが一致するまで。 これが必要なのは、そうしないと差を偶数増分の合計として表すことができないためです。 
4. すべての数値がプラスに寄与すると仮定して、符号の配列を初期化します。 
5. 必要な差を計算します$D = S - X$。 これは、符号を反転することで削減する必要がある合計量です。 
6. 反復処理$N$1 まで下がります。各ステップで、$2i \le D$の符号を反転します。$i$そして引きます$2i$から$D$。 この貪欲なステップは正しいです。なぜなら、数値が大きいほど差を減らすのに効果的であり、最初に数値を使用することで必要なフリップの数が最小限に抑えられるからです。 
7. すべての数値を処理した後、$D$ゼロになり、構築された符号パターンは正確に得られます。$X$。 

重要な不変条件は、次の値を超えるすべての整数を処理した後、$i$、残りの差額$D$常に数値のみを使用して表現できます$1 \dots i$これは、利用可能な反転に対応する有効な偶数増分のみを減算するためです。 私たちは常に実現可能な最大の貢献を最初に使用するため、より小さな数が残りを完了できないという窮地に追い込まれることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build(x):
    sign = {}
    x_abs = abs(x)

    n = 1
    s = 1
    while s < x_abs:
        n += 1
        s += n

    while s % 2 != x % 2:
        n += 1
        s += n

    # start all positive
    for i in range(1, n + 1):
        sign[i] = 1

    diff = s - x

    for i in range(n, 0, -1):
        if diff >= 2 * i:
            sign[i] = -1
            diff -= 2 * i

    expr = []
    for i in range(1, n + 1):
        if i == 1:
            expr.append("1")
        else:
            if sign[i] == 1:
                expr.append("+" + str(i))
            else:
                expr.append("-" + str(i))

    return n, "".join(expr)

def main():
    t = int(input())
    for _ in range(t):
        x = int(input())
        n, expr = build(x)
        print(n)
        print(expr)

if __name__ == "__main__":
    main()
```この実装は、建設的な推論を直接反映しています。 最初のループは十分に大きなプレフィックスの合計を見つけ、パリティは符号反転の下で不変であるため、2 番目のループでパリティを修正します。 貪欲な後方スイープは中核的な正確性ステップです。大きいものから小さいものへと反復することで、すべての削減ステップが最大限に効率的になることが保証され、将来の実現可能性が妨げられることはありません。 

重要な点の 1 つはコンピューティングです`diff = s - x`の符号付き値を使用して`x`、 ない`|x|`ターゲットの方向がどの反転が必要かに影響するためです。 もう 1 つの微妙な点は、1 から 2 までのすべての数値を常に出力するようにすることです。$N$たとえ一部が陽性のままだったとしても。

 ## 特殊なケース

 のために$X = 0$、アルゴリズムが増加します$N$合計条件とパリティ条件が一致するまで。 から始まる$N=1$、合計は 1 ですが、不十分です。 で$N=2$、合計は 3 ですが、0 との差が依然として奇数であるため、次の値に移動します。$N=3$、合計は 6 になり、$6 - 0 = 6$は均等です。 貪欲な反転により、次のような有効な構成が生成されます。$1 + 2 - 3 = 0$。 

次のような小さな負の値の場合、$X = -1$、この構造は、試みの素朴な失敗を回避します。$N=1$。 代わりに、それは次のように成長します$N=2$または$N=3$パリティに応じて、最終的な差分が有効な反転に分解可能であることを確認します。 

最大制約に近い大きな値の場合、アルゴリズムは安定したままになります。$N$くらいまでしか成長しない$\sqrt{2|X|}$、リニアスケールに近づくことはありません$X$、各フリップが残りの差を厳密に減らすため、貪欲パスは常に終了します。
