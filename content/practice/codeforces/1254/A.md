 ## 解決策
 ## 問題の理解

 各セルが空か米が入っている長方形のグリッドが与えられます。 私たちも持っています$k$鶏。 タスクは、グリッド全体を正確に分割することです。$k$接続された領域は、ニワトリごとに 1 つずつあり、すべてのセルが正確に 1 つの領域に属し、すべての領域が 4 方向に接続されます。 

ここでの工夫は、バランスをとるために重要なのはイネのセルだけであるということです。各ニワトリはその領域内のイネのセルを「収集」し、すべてのニワトリのイネのセルの最大数と最小数の差をできるだけ小さくしたいと考えています。 

したがって、本当の問題は、制約のあるグリッド分割の問題です。つまり、グリッドを次のように分割します。$k$コンポーネント間で可能な限り均等に米セルを分散しながら、それぞれが空ではない接続されたコンポーネントを配置します。 

グリッドのサイズは最大です$100 \times 100$、 そして$k \le 62$。 すべてのテスト ケースにわたって、セルの総数は、テスト ケースごとの線形スキャンに十分なほど少ないです。 

主要な構造上の制約は、すべてのリージョンに接続が必要であることです。 これにより、接続が決して「切断」されないことを保証しない限り、セルごとの任意の貪欲な割り当てが即座に排除されます。 

イネの細胞がまばらまたは密集している場合、微妙なエッジケースが現れます。 たとえば、すべてのイネのセルが単一のパス状の領域にある場合、最初にイネを数えてから割り当てるという単純なバランスでは、ジオメトリを注意深く考慮しないと、切断された領域が生成される可能性があります。 

もう 1 つのエッジケースは次のような場合です$k$特に大きいです$k = 62$これは、数字、大文字、小文字として使用できる個別の出力文字の正確な数です。 これは、各ニワトリが複雑な形状ではなく、単一の連続した横断セグメントによって表現できることを強く示唆しています。 

## アプローチ

 ブルートフォースアプローチでは、各セルを次のいずれかに割り当てようとします。$k$すべてのラベルに接続制約が適用されることを保証しながら、ラベルを作成します。 これは、グローバル接続制約を伴うグラフ分割問題となり、一般に指数関数的になります。 セルを順番に割り当てることに限定したとしても、依然として次のことを維持する必要があります。$k$接続されたコンポーネントを拡大し、コンポーネントごとの米の分布を追跡することで、状態空間がグリッド サイズとともに指数関数的に拡大します。 

重要な洞察は、実際にはグローバル パーティショニングの問題を「解決」する必要がないということです。 訪問したセルのすべてのプレフィックスが接続された領域を形成するように、グリッドを走査順序に線形化できます。 次に、この横断の連続するセグメントをニワトリに割り当てると、各ニワトリの領域は構築によって接続されたままになります。 

これを実現する標準的な方法は、グリッドの DFS または BFS トラバースで、接続されたウォーク内のすべてのセルをリストします。 この順序を取得すると、問題はシーケンスを次のように分割することになります。$k$米の数をできるだけ均等に分配しながら、連続したセグメントを配置します。 接続は自動的に確保されます。残る唯一の問題は、米の分布が可能な限り均一になるようにセグメント サイズのバランスを取ることです。 

なぜなら$k \le 62$、各セグメントの米数を追跡しながら、鶏ごとに少なくとも 1 つのセルを割り当て、残りのセルを貪欲に分配できます。

 | ブルートフォース | 指数 | 高 | 遅すぎる |

 ## アルゴリズムのチュートリアル

 グリッド内のすべてのセルの DFS オーダーを構築します。 次に、このシーケンスを次のように分割します。$k$連続した部分を配置し、各部分が空でないことを確認します。 走査順序を制御するため、各プレフィックスは接続されたままになり、各セグメントが接続されます。 

1. グリッド上で DFS を実行し、すべてのセルを訪問順に収集します。 

トラバーサルのプレフィックスが接続されたままになるように、順序は隣接性を尊重する必要があります。 
2. Let the resulting list be`order`長さのある$n = r \cdot c$。 
3. 最初のセルが確実に配置されるようにして、各ニワトリに少なくとも 1 つのセルを割り当てます。$k-1$segments each start with one cell from the order.
 4. 残りの細胞をラウンドロビン方式でニワトリ全体に 1 つずつ分配しますが、初期のニワトリが他のニワトリに比べて大きくなりすぎないようにバイアスをかけます。 
5. Assign a character label to each segment: digits, uppercase, then lowercase, up to 62 distinct symbols.
 6. Fill the answer grid according to the assignment.

 重要なバランスのステップは、セグメント サイズの差が最大 1 であることを確認することです。これにより、イネのセルが同じ走査順序に沿って分布するため、間接的にイネの数のバランスが保たれます。 

### なぜ効果があるのか

 DFS トラバーサルにより、順序付けのすべてのプレフィックスが接続されたグリッド セルのセットに対応することが保証されます。 したがって、トラバースの連続するセグメントも接続されます。 各ニワトリは連続するセグメントを 1 つだけ受け取るため、すべての接続制約が自動的に満たされます。 

The balance property comes from the fact that we distribute cells nearly evenly across$k$セグメント。 各セルは横断時の位置を除いて対称的に扱われるため、イネの細胞は最大でも 1 セル境界のシフトによって引き起こされる一定の因子の差を超えて 1 つのセグメントに不均衡に集中することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

dirs = [(1,0),(-1,0),(0,1),(0,-1)]

def solve():
    r, c, k = map(int, input().split())
    grid = [list(input().strip()) for _ in range(r)]
    
    visited = [[False]*c for _ in range(r)]
    order = []
    
    def dfs(x, y):
        visited[x][y] = True
        order.append((x, y))
        for dx, dy in dirs:
            nx, ny = x + dx, y + dy
            if 0 <= nx < r and 0 <= ny < c and not visited[nx][ny]:
                dfs(nx, ny)
    
    # run DFS from first cell
    dfs(0, 0)
    
    n = len(order)
    base = n // k
    extra = n % k
    
    ans = [[''] * c for _ in range(r)]
    
    idx = 0
    labels = "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ"
    
    for i in range(k):
        size = base + (1 if i < extra else 0)
        for _ in range(size):
            x, y = order[idx]
            ans[x][y] = labels[i]
            idx += 1
    
    for i in range(r):
        print("".join(ans[i]))

solve()
```DFS は、グリッドのグローバルに接続された順序を構築します。 セグメンテーションのステップにより、各ニワトリがその順序の連続したブロックを確実に取得できるようになり、接続された領域が直接保証されます。 

ラベル文字列は、制約に正確に一致して、最大 62 個のニワトリをサポートするように選択されます。 

実装の微妙な点は、DFS は、未訪問の走査開始点仮定の切断された領域が含まれている場合でも、グリッド全体をカバーする必要があることです。 このソリューションでは、グリッドが完全に到達可能であるか、単一の走査として効果的に処理されることを前提としています。 実際には、すべてのセルをループし、未訪問のセルが見つかるたびに DFS を開始し、順序を連結します。

 ## 特殊なケース

 例外的なケースは、グリッドが米で完全に満たされている場合です。$k = rc$。 この状況では、すべてのセルが独自の領域になる必要があります。 DFS の順序付けは引き続き機能し、各セグメントは単一のセルに縮退して、接続を簡単に維持します。 

もう 1 つの特殊なケースは、グリッドが非常にまばらな場合です。 イネのセルが分離されている場合でも、コネクティビティはイネだけでなくすべてのセルにわたって定義されるため、DFS は依然として有効なトラバーサルを生成します。 細分化は米の分布に依存しないため、脆弱で貪欲な決定が回避されます。 

最後のエッジ ケースは、DFS パスが長くて狭いようにグリッドが歪んでいる場合です。 その場合でも、隣接関係は走査順序に沿って維持されるため、隣接するセグメントは接続されたままになります。そのため、切断されたセルをまたいでセグメントが「ジャンプ」することはできません。
