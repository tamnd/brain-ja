 ## 問題の理解

 私たちは一連の箱を渡され、それぞれの箱にはいくつかのチョコレートが入っています。 1 回の移動で、ボックスから 1 つのピースを取り出し、隣接するボックスに移動することができます。そのため、ピースを移動するコストは、ピースがラインに沿って移動する距離とまったく同じになります。 

最終的な目標は、整数が存在するようにすべてのピースを再配置することです。$k > 1$すべてのボックスが最終的に次の数で割り切れる個数になるようにします。$k$。 合計ピース数が同じであり、移動コストが最小限に抑えられる限り、配分を完全に変更することは自由です。 

この条件を言い換えると、最終的な構成ではすべてのチョコレートをサイズのグループに分割する必要があるという便利な方法が得られます。$k$ここで、各ボックスはこれらのグループの整数を受け取ります。 制約「それぞれ」$a_i$で割り切れます$k$” はまさにその箱を意味します$i$取得します$c_i \cdot k$整数分のチョコレート$c_i$。 

入力サイズは最大で$10^6$ボックスと最大値$10^6$なので、チョコレートの総数は$S = \sum a_i$にも到達できます$10^{12}$。 これは、各移動ベースのシミュレーションが最大で$S$アイテム。 

2 番目の重要な意味は、答えは集合体としての箱ではなく、個々のチョコレートの位置のみに依存するということです。 各ボックスを単位チョコレートに拡張することは概念的には正しいですが、直接の拡張は大きすぎるため、推論を大幅に圧縮する必要があります。 

覚えておく価値のある微妙な失敗例が 2 つあります。 

もし$S = 1$、有効なものはありません$k > 1$合計を割るので、答えは次のようになります。$-1$。 盲目的に試みるあらゆる解決策$k = S$有効性をチェックしないと、誤ってゼロコストが返されてしまいます。 

もう 1 つの注意が必要なケースは、すべてのチョコレートがすでに何らかの数字で割り切れるような形で配置されているものの、その数字が合計を割り切れない場合です。 たとえば、次の場合$a = [1, 1]$、試してみてもいいかもしれません$k = 2$しかし、再分配は可算性を満たすことができません。$S = 2$グループ化制約は機能しますが、依然として構造を慎重に処理する必要があります。 

## アプローチ

 強引なアイデアは、可能な限りのことを試すことから始まります$k > 1$。 候補者ごとに$k$、すべてのボックスが次の倍数を持つ構成に配列を変換しようとします。$k$チョコレート。 概念的には、すべてのチョコレートを位置のリストに展開し、それらをサイズのグループに割り当てようとします。$k$、各グループ内の移動コストを最小限に抑えます。 

これは機能します。$k$が修正されると、問題は、線上の点を同じサイズのグループに最小コストでクラスタリングすることになります。 各グループの最適な構造はよく理解されています。位置の固定セットの場合、そのすべての質量を中央値に配置すると、絶対偏差コストが最小限に抑えられます。 

それぞれについて考えられるすべてのグループ化をチェックするため、ブルート フォースは失敗します。$k$チョコレートの数は指数関数的に増加します。 直したとしても$k$、サイズのグループに最適なパーティションを見つける$k$構造がなければ手に負えないでしょう。 

重要な観察は、すべてのチョコレートの位置を並べ替えると、固定のチョコレートの最適なグループ化が行われるということです。$k$任意ではありません。 最適なパーティションは、次のサイズの連続したブロックを取得することによって取得されます。$k$ソートされた順序で。 これは、グループをまたぐと距離が増えるだけであり、グループ間で要素を交換すると、いつでも再配置してコストを削減したりコストを変更しないことができるため発生します。 

したがって、問題はすべての約数を列挙することになります。$k$の$S$、すべてのポジションのソートされたリストを作成し、それぞれについて$k$、連続したサイズのチャンクに分割する$k$、中央値を介してコストを計算します。

 ## アルゴリズムのチュートリアル

 1. チョコレートの総数を計算する$S$。 もし$S = 1$、整数なし$k > 1$分割するのですぐに戻ります$-1$。 
2. 各ボックスのインデックスを展開してチョコレートのすべての位置を抽出します$i$その通り$a_i$リストに何度も`pos`。 このリストの各要素は、所定の位置にある 1 つの単位チョコレートを表します。$i$。 
3. 並べ替え`pos`。 これにより、移動コストが直線上の絶対距離となる 1 次元の構成が得られます。 
4. すべての約数を計算する$k$の$S$そのような$k > 1$。 各約数は、考えられるターゲット グループのサイズを表します。 
5. 各候補者について$k$、パーティション`pos`連続したサイズのブロックに分割する$k$。 各ブロックはチョコレートに対応しており、最終的には 1 つの「効果的なボックス グループ」に統合されます。 
6. ブロックごとに、そのブロック内の中央位置である最適なミーティング ポイントを計算します。 ブロックのコストは、この中央値までのすべての要素の距離の合計です。 
7. ブロックコストを累積して、このコストの合計を取得します。$k$。 有効なすべての最小値を維持する$k$。 

これが機能する主な理由は、1 次元空間ではグループ内の最適な輸送が中央値のみに依存し、最適なグループ化によりインターリーブが回避されるためです。 ソートが完了すると、最適なソリューションは、コストを増加させることなく、各グループが連続したセグメントで構成されるソリューションに変換できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    S = sum(a)
    if S == 1:
        print(-1)
        return
    
    pos = []
    for i, x in enumerate(a):
        if x:
            pos.extend([i] * x)
    
    pos.sort()
    
    prefix = [0] * (S + 1)
    for i in range(S):
        prefix[i + 1] = prefix[i] + pos[i]
    
    def cost(l, r):
        m = (l + r) // 2
        left = pos[m] * (m - l) - (prefix[m] - prefix[l])
        right = (prefix[r + 1] - prefix[m + 1]) - pos[m] * (r - m)
        return left + right
    
    def calc(k):
        total = 0
        for i in range(0, S, k):
            total += cost(i, i + k - 1)
        return total
    
    ans = 10**30
    
    x = S
    d = 1
    while d * d <= x:
        if x % d == 0:
            if d > 1:
                ans = min(ans, calc(d))
            if x // d > 1:
                ans = min(ans, calc(x // d))
        d += 1
    
    print(ans)

if __name__ == "__main__":
    solve()
```実装は、問題を位置の線形配列に変換することから始まります。これにより、すべての移動コストが単純な絶対距離になるようになります。 プレフィックス合計配列を使用すると、中央値までの距離をプレフィックスの差を使用して書き換えることができるため、セグメント コストの定数時間の計算が可能になります。 

の`cost(l, r)`関数はブロックを分離し、中央値の公式を使用してその最適な内部再配置コストを計算します。 の`calc(k)`関数はこれをサイズのすべてのブロックに適用します$k$、これは並べ替えられた構造引数により有効です。 

最後に、除数ループにより、意味のあるグループ サイズのみが評価されるようになり、大きな入力に対してもソリューションの効率が維持されます。

 ## 特殊なケース

 チョコレートの合計数が 1 の場合、1 より大きい有効な約数はないため、アルゴリズムはすぐに次の値を返します。$-1$。 これにより、実現可能性を誤って想定してしまうような単一グループのソリューションを構築しようとする試みが防止されます。 

すべてのチョコレートがすでに 1 つのボックスに集中している場合、位置配列には同じ値が繰り返されます。 有効な$k$、各ブロックの分散はゼロであるため、すべての要素が中央値と一致するため、すべてのコスト計算は正しくゼロを返します。 

分布の広がりが大きいが総和が素数の場合、候補は次のとおりです。$k = S$、単一のブロックを強制します。 アルゴリズムは、配列全体にわたって単一の中央値ベースのコストを計算することでこれを自然に処理し、避けられない移動コストを正確に反映します。
