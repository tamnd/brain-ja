 ## 解決策
 ## 問題の理解

 2D 平面上に最大 20 個の個別の点が与えられ、各点は風船を表します。 単一のダーツはセグメントや光線に限定されません。 無限の直線のように動作します。 ダーツが投げられると、その線上に正確にあるすべての風船が割れます。 

タスクは、すべての点が少なくとも 1 つの選択されたライン上に位置するように、できるだけ少ないラインを選択することです。 線はどこからでも開始できるため、重要なのはその方向とどの点が線と同一直線上にあるかだけです。 

n ≤ 20 という制約が重要な構造上のヒントです。 このように点の数が少ない場合、サブセットにわたる指数解は許容されます。 平面内のすべての幾何学的な線をグローバルに考慮しようとするものはすべて不必要です。 与えられた点によって引き起こされる線について推論するだけで済みます。 

正確さのためには、いくつかの特殊なケースが重要です。 ポイントが1つの場合、ダーツは必ず1本必要になります。 すべての点が 1 つの直線上にある場合、答えは 1 です。 3 つの点が同一直線上にない場合、すべてのペアが一意の線を定義しますが、複数の線が必要になる可能性が高く、最適な解決策を得るには、貪欲に線を選択するのではなく、ペアを慎重にグループ化することが必要になる場合があります。 

よくある落とし穴は、残りの最も多くのポイントをカバーするラインを常に選択するなど、貪欲な戦略を試みることです。 局所的に最適なラインを選択すると、後でより適切なグローバルな組み合わせがブロックされる可能性があるため、これは失敗します。 たとえば、正方形を形成する 4 つの点: 最初に 1 本の対角線を選択することは、局所的には適切ですが、最適な完全なカバーにはつながりません。 

## アプローチ

 強引なアイデアは、可能なすべての線のセットを試し、それらがすべての点をカバーしているかどうかを確認することです。 ただし、点の各ペアが線を定義し、そのような線が O(n²) あるため、可能な線の数はすでに多数です。 これらの行のサブセットは 2^(n²) になりますが、これはまったく実行不可能です。 

重要な観察は、実際には幾何学的な線を抽象オブジェクトとして列挙する必要がないということです。 最適な解決策は、2 つの点 (または縮退の場合は 1 つの点) によって定義される線を繰り返し選択するものとみなすことができ、その線は、それと同一線上にある点のサブセットを正確にカバーします。 n が小さいため、各ラインをポイント上のビットマスクとしてエンコードできます。 

これにより、問題は、サブセットにわたる DP をカバーする古典的なセットに変換されます。各状態は、どの点がすでにカバーされているかを表し、遷移によって、いくつかの追加の点をカバーする線が追加されます。 n ≤ 20 であるため、状態空間 2^n は管理可能であり、カバーされていない開始点を固定し、それをすべての可能なパートナーと組み合わせることで遷移を計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべての行サブセットに対するブルート フォース | O(2^(n²) · n²) | O(n²) | 遅すぎる |
 | サブセット上のビットマスク DP | O(n² · 2^n) | O(2^n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 点のペア (i, j) ごとに、i と j を通る無限線上にあるすべての点のセットを事前計算します。 このセットを n 点にわたるビットマスクとして表します。 i = j の場合、マスクは単なる {i} です。

このステップでは、ジオメトリをビット操作に変換して、後の遷移が単純な結合になるようにします。 
2. DP 配列を初期化します。ここで、dp[mask] は、マスク内の点のセットを正確にカバーするために必要なダーツの最小数を表します。 dp[0] = 0 に設定し、その他すべてを無限大に設定します。 
3. 0 から 2^n − 1 までのすべてのマスクを繰り返します。マスクごとに、到達できない場合はスキップします。 
4. 現在のマスクでまだカバーされていない最初の点 i を見つけます。 すべての有効な解決策は最終的にこの点をカバーする必要があるため、この点はこの状態の完了に含める必要があります。 
5. i と i から n − 1 までのすべての点 j を通るダーツ ラインを配置してみます。各 j について、ライン マスク L(i, j) を計算します。 次の状態はマスク ∪ L(i, j) となり、dp[next] = min(dp[next], dp[mask] + 1) と緩和します。 これは、i に固定されたラインの中からできるだけ多くの新しいポイントをカバーする 1 つのダーツを選択することを表します。 
6. すべてのマスクが処理されるまで続行します。 答えは dp[(1 << n) − 1] です。 

ステップ 4 を有効にする重要な制限は、どの解も何らかの線を使用して点 i をカバーしなければならず、その線は i と少なくとも 1 つの他の点 (または縮退した単一点線) を通過する必要があるということです。 すべての j を列挙すると、i までの可能なすべての有効な行がキャプチャされます。 

### なぜ効果があるのか

 DP の不変条件は、dp[mask] がマスク内の点のセットを正確にカバーするために必要な最小行数を格納することです。 すべての遷移では、少なくとも 1 つの未カバーのポイントをカバーする 1 つの有効なラインが追加され、最初の未カバーのポイントをカバーするラインを常に選択することで、すべての有効なソリューションをそのような選択肢のシーケンスに分解できます。 i を通るすべての幾何学的な線は何らかのペア (i, j) で表されるため、最適な解が見逃されることのない遷移セットが完成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def collinear_mask(i, j, pts):
    xi, yi = pts[i]
    xj, yj = pts[j]
    mask = 0
    for k, (xk, yk) in enumerate(pts):
        # check cross product (xj-xi, yj-yi) x (xk-xi, yk-yi)
        if (xj - xi) * (yk - yi) == (yj - yi) * (xk - xi):
            mask |= 1 << k
    return mask

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    if n <= 1:
        print(n)
        return

    # precompute line masks
    line = [[0] * n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            line[i][j] = collinear_mask(i, j, pts)

    INF = 10**9
    dp = [INF] * (1 << n)
    dp[0] = 0

    for mask in range(1 << n):
        if dp[mask] == INF:
            continue

        # find first uncovered point
        i = 0
        while i < n and (mask >> i) & 1:
            i += 1
        if i == n:
            continue

        for j in range(n):
            new_mask = mask | line[i][j]
            if dp[new_mask] > dp[mask] + 1:
                dp[new_mask] = dp[mask] + 1

    print(dp[(1 << n) - 1])

if __name__ == "__main__":
    solve()
```この実装は、ジオメトリをビットマスクとして表現することに大きく依存しています。 機能`collinear_mask`外積条件を使用して、2 つのアンカーによって定義されたラインに対してすべてのポイントをチェックします。これにより、浮動小数点の精度の問題が回避されます。 

DP ループは、冗長な分岐を減らすために、常に最初にカバーされていないポイントを選択します。 このルールがないと、同じセットが異なる順序で複数回生成され、実行時間が大幅に増加します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n² · 2^n) | 各サブセットに対してピボット ポイントを選択し、それを他のすべてとペアリングしてみます。各ライン マスクは事前に計算されるか、O(n) | で計算されます。

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    from math import inf

    def collinear_mask(i, j, pts):
        xi, yi = pts[i]
        xj, yj = pts[j]
        mask = 0
        for k, (xk, yk) in enumerate(pts):
            if (xj - xi) * (yk - yi) == (yj - yi) * (xk - xi):
                mask |= 1 << k
        return mask

    def solve():
        n = int(input())
        pts = [tuple(map(int, input().split())) for _ in range(n)]
        if n <= 1:
            print(n)
            return

        line = [[0]*n for _ in range(n)]
        for i in range(n):
            for j in range(n):
                line[i][j] = collinear_mask(i, j, pts)

        INF = 10**9
        dp = [INF] * (1 << n)
        dp[0] = 0

            i = 0
            while i < n and (mask >> i) & 1:
                i += 1
            if i == n:

            for j in range(n):
                dp[mask | line[i][j]] = min(dp[mask | line[i][j]], dp[mask] + 1)

        print(dp[(1 << n) - 1])

    solve()
    return ""

 ## 特殊なケース

 単一のポイントの場合、DP はすぐに 1 を返します。これは、カバーされていない最初のポイントが最終ポイントでもあり、そのポイントを通る選択された線がその状態を正確にカバーするためです。 

完全に共線的なセットの場合、すべてのペアがすべてのポイントに等しいマスクを生成するため、最初の遷移はすでに完全なビットマスクに達し、dp は 1 になります。DP は共線パートナーを含む任意の j を常に選択できるため、誤ってオーバーカウントすることはありません。 

3 つの共線点がない場合、各ライン マスクには最大 2 つの点が含まれます。 DP はペアリングの組み合わせを正しく探索します。これは、各遷移で最初に検出されたポイントに対して異なるパートナーを選択できるため、貪欲なマッチングではなくグローバルに最適なペアリングが保証されます。
