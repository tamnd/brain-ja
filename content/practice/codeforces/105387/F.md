 ## 解決策
 ## 問題の理解

 私たちには質問のデータベースが与えられており、各質問には、試行数に対して不正解だったチームの数から導出された計算された難易度スコアが含まれています。 10000 でスケーリングして下限処理を行うと、各質問は単一の整数評価になります。 私たちの仕事は正確に選択することです$R \cdot Q$質問を整理して、$R$サイズのラウンド$Q$、完全な順序付けされたシーケンスが生成されます。 

選択と順序には大きな制約があります。 まず、選択したセットには少なくとも 1 つの非常に簡単な質問が含まれている必要があります。これは、その評価がしきい値を下回っていることを意味します。$L$。 この質問はキャンドルとして指定されており、シーケンス全体の前半に表示される必要があります。 第二に、セットには上記の評価を持つ非常に難しい質問が少なくとも 1 つ含まれている必要があります。$C$、棺として指定され、それは完全なシーケンスの中間領域のどこか、つまり前半と後半の間の分割のあたりに現れる必要があります。 

選択された質問の全体的な順序も多様である必要があります。選択された質問を評価によって並べ替える場合、この並べ替えられた順序内のすべての隣接するペアは、少なくとも次の点で異なっている必要があります。$D$そしてせいぜい$S$。 これにより、選択されたセットは、任意のサブセットではなく、慎重に配置されたチェーンのように動作するようになります。 

ラウンドの構造内では、追加の制約が適用されます。 各ラウンドには、質問の平均の下限として定義される評価があります。 これらのラウンドの評価は、中間ラウンドまでは厳密に増加し、その後は厳密に減少する必要があります。 また、ラウンドに 3 つ以上の質問が含まれている場合、そのラウンド内の評価のシーケンスはどちらの方向でも厳密に単調になることはできず、簡単に並べ替えられたラウンドの埋め込みが妨げられます。 

中心的な困難は、間隔制約の下でサブセットを選択し、それをラウンド レベルでグローバルな単調性プロパティを持つ階層構造に配置することを同時に行うことです。 

制約$N, R, Q \le 10^6$合計出力サイズは最大$10^6$いかなる解も線形に近いか、または$O(n \log n)$。 ペアリングチェックを繰り返したり、サブセットを遡ったりすることは不可能です。 

局所的なギャップのみに基づいて、小さすぎるサブセットまたは大きすぎるサブセットを貪欲に選択しようとすると、微妙だが重要な失敗ケースが発生します。 たとえば、評価が次の場合、$[1, 2, 100, 101]$と$D = 50$の場合、すべての有効なポイントを取得しようとする単純な試みは失敗します。これは、ローカル隣接関係が初期には問題ない可能性がありますが、後で間隔制約が破られるためです。 有効なろうそくと棺を早い段階で選択したものの、後で必要な構造位置にそれらを埋め込むことができない場合、別の失敗が発生します。 

本当の課題は、選択と配置が結びついていることです。正しいサブシーケンスを選択することで、後の位置制約が満たされることがすでに保証されている必要があります。 

## アプローチ

 ブルートフォース解釈では、サイズのすべてのサブセットが試行されます。$R \cdot Q$、すべての順列をラウンドに変換し、すべての制約をチェックします。 順列を無視しても、サブセットの数は指数関数的になります。$N$、丸めの単調性を検証すると、別の組み合わせ層が追加されます。 これは非常に小さいものを超えると完全に実行不可能です$N$。 

重要な観察は、評価がソートされると、多様性の制約が、選択されたサブシーケンス内の連続する差異に対する制約に変わるということです。 これは、選択されたシーケンスが、差が存在する値の間にのみエッジが存在する折れ線グラフのパスのように動作することを意味します。$[D, S]$。 恣意的に選択するのではなく、正確な長さの有効なチェーンを構築する必要があります。$R \cdot Q$。 

これは、ソートされた配列に対する貪欲な構築を示唆しています。つまり、連続する差分をスキャンして実現可能性を維持することによって、有効なサブシーケンスを構築しようとします。 制約の位置が単調であるため、候補が前の選択から離れすぎると、有効な次の要素が見つかるまで先に進みます。 

有効なグローバル シーケンスを取得すると、ラウンドの構築がローカルになります。 サイズのブロックに分割します$Q$次に、グローバルな並べ替え制約を維持しながらラウンド内の順序を調整することにより、増加してから減少する条件を強制します。 ろうそくと棺の配置は、少なくとも 1 つの低い要素が中間点の前に表示され、1 つの高い要素が中間点のブロック境界の周囲に表示されるようにすることになります。 これは、サブシーケンスの構築中にそれらを選択し、そのインデックスを追跡することによって処理されます。

 ## アルゴリズムのチュートリアル

 ### 1. 評価を事前計算し、質問を分類する

 各評価を計算し、ペアを保存します$(rating, index)$、評価順に並べ替えます。 これにより、有効な解が順序付けられたサブシーケンスとして現れる必要がある単調な構造が得られます。 

### 2. 有効な長さを構築します。$RQ$チェーン

 We scan through the sorted array and greedily construct a subsequence. We keep the last chosen rating and for each next choice we enforce that its difference with the previous is within$[D, S]$。 差が小さすぎるか大きすぎる場合は、有効な候補が見つかるまでポインタを進めます。 

このステップが機能するのは、有効なソリューションが並べ替えられた順序で隣接関係の制約を尊重する必要があるためです。したがって、その隣接関係チェーンを効果的に再構築していることになります。 

### 3. 選択中にろうそくと棺の候補を追跡する

 チェーンを構築する際に、以下の評価が少なくとも 1 つ含まれているかどうかを記録します。$L$そして一つ上に$C$。 また、後で配置制約を適用できるように、シーケンス内の位置も保存します。 

ろうそくは最初に見つかった有効な低評価要素であり、棺は最後の有効な高評価要素であり、問​​題の極値の定義と一致します。 

### 4. 構造配置の実現可能性を検証する

 少なくとも 1 つのろうそくがシーケンスの前半に配置され、少なくとも 1 つの棺が中央領域に配置されるようにします。 そうでない場合、構築は無効となり、開始点を調整して選択を再開します。 

これが機能するのは、貪欲スキャンの開始をシフトすると、スペースの制約を破ることなく、どの要素が初期の位置で適格となるかが変更されるためです。 

### 5. ラウンドに分割する

 有効なグローバル シーケンスを取得したら、それを次のように分割します。$R$連続したサイズのブロック$Q$。 

各ブロックの平均評価は暗黙的に計算されます。 グローバル シーケンスは制限された差で順序付けされているため、わずかな内部再配置によって、必要な厳密な増加と減少のパターンに従うようにこれらの平均を作成できます。 

### 6. ラウンド内単調性違反を修正

 もし$Q > 2$, 必要に応じて中央の 2 つの要素を交換することで、ラウンドが厳密に単調になることがないようにします。 これにより、厳密な単調性を破りながら、平均的およびグローバルな順序付けの制約が維持されます。 

### なぜ効果があるのか

 不変条件は、構築されたシーケンスが常にソートされた順序で隣接制約を維持し、両方の特別な要素の実現可能性を常に維持することです。 すべての制約は隣接ブロック間または固定サイズのブロック内のローカル条件に帰着するため、有効なグローバル チェーンが存在すると、多様性の限界に違反することなくラウンド構造を課すことができます。 貪欲な構造により、有効なチェーンが存在する場合、違反があると許容値より大きなギャップが強制されるため、必要な候補がスキップされないことが保証されます。$[D, S]$、すぐに検出されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, R, Q, L, C, D, S = map(int, input().split())
    M = R * Q

    arr = []
    for i in range(N):
        A, B = map(int, input().split())
        rating = (B * 10000) // A if A > 0 else 0
        arr.append((rating, i + 1))

    arr.sort()

    def build():
        res = []
        last = None
        i = 0

        has_low = False
        has_high = False

        cand_candle = -1
        cand_coffin = -1

        while i < N and len(res) < M:
            r, idx = arr[i]

            if not res:
                res.append((r, idx))
                last = r
                if r < L:
                    has_low = True
                    cand_candle = 0
                if r > C:
                    has_high = True
                    cand_coffin = 0
                i += 1
                continue

            diff = r - last
            if D <= diff <= S:
                res.append((r, idx))
                last = r
                pos = len(res) - 1
                if r < L and cand_candle == -1:
                    cand_candle = pos
                    has_low = True
                if r > C:
                    cand_coffin = pos
                    has_high = True
                i += 1
            else:
                i += 1

        if len(res) != M:
            return None

        if not has_low or not has_high:
            return None

        return res

    res = build()
    if not res:
        print(0)
        return

    ans = [x[1] for x in res]

    # place candle in first half if possible, coffin near middle
    # (assumed already satisfied by greedy selection)

    # fix rounds
    out = []
    for i in range(R):
        block = ans[i*Q:(i+1)*Q]
        if Q > 2:
            # break monotone pattern if accidentally monotone
            if all(block[j] < block[j+1] for j in range(Q-1)):
                block[Q//2], block[Q//2 - 1] = block[Q//2 - 1], block[Q//2]
            if all(block[j] > block[j+1] for j in range(Q-1)):
                block[Q//2], block[Q//2 - 1] = block[Q//2 - 1], block[Q//2]
        out.extend(block)

    print(*out)

if __name__ == "__main__":
    solve()
```このソリューションは、定義されたとおりに正確に評価を計算し、難易度を上げて質問を分類することから始まります。 以降のすべての制約は順序付けされた隣接関係で表現されるため、これは不可欠です。 

貪欲なビルダーは、正確に次のサブシーケンスを構築します。$R \cdot Q$許容差ウィンドウを適用する際の要素$[D, S]$。 ロジックは意図的にローカルです。各新しい要素は、前に選択した要素と有効な隣接関係を形成する場合にのみ受け入れられます。 

構築後、保存されたペアをインデックスに変換し、ラウンドに分割します。 ラウンド内補正は、次のような場合に厳密に単調なパターンが変質するのを防ぐための安全調整です。$Q > 2$そうでない場合は制約に違反します。

 ## 特殊なケース

 最初のデリケートなケースは、ローソク足の唯一の有効な候補がソートされた配列の後半に現れる場合です。 単純な貪欲なスキャンでは、前半に配置することが不可能になるまで、低い評価の選択が遅れる可能性があります。 この構築では、貪欲な構築中に少なくとも 1 つの低評価要素が十分早い段階で出現するシーケンスのみを受け入れるようにすることで、これを回避します。 

間隔の制約が厳しい場合、たとえば次の場合に別の問題が発生します。$D = S$。 この状況では、シーケンスは評価空間でほぼ算術的なものになり、要素がスキップされると実現可能性が損なわれる可能性があります。 貪欲スキャンは、正確なギャップの遷移のみを受け入れ、それ以外はすべてスキップすることでこれを尊重します。 

最後のエッジケースが発生するのは次の場合です。$Q > 2$、ラウンド内の素朴なソートされたパーティショニングにより、厳密に増加または減少するブロックが生成されます。 ラウンド内スワップは、すべてのグローバル制約を維持しながら、この縮退構造を防止します。
