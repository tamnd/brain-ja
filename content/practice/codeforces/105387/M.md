 ## 解決策
 ## 問題の理解

 の行が与えられています$n$座席と$n$学生たち。 各学生には希望の座席番号があり、各学生には個人的な不満のコストパラメータもあります。 学生が希望する席に座らなかった場合、その学生に対する不満のコストが発生します。 彼らが自分の好きな席に座っていても、何も貢献しません。 

課題は、不満の合計ができるだけ小さくなるように、各生徒を固有の座席に割り当て、座席の順列を形成することです。 

したがって、入力は 2 つの長さの配列を定義します。$n$。 最初の配列は、各学生がどの座席に座りたいかを示します。 2 番目の配列は、その生徒を「置き忘れる」ことがどれだけの損失をもたらすかを示しています。 成果物では、学生に座席が割り当てられ、その結果として生じる総不満が最小限に抑えられる必要があります。 

制約$n \le 10^5$割り当ての試行ごとに超線形なものはすぐに除外されます。 3 次または 2 次のマッチング手法では限界を超えてしまいます。 ソートや貪欲な処理のようなものを期待する必要があります。$O(n \log n)$または$O(n)$。 

素朴ですがよくある間違いは、各生徒を個別に希望する座席に割り当て、競合を恣意的に解決できると想定することです。 これは失敗します。なぜなら、複数の学生が同じ席を希望する場合、誰がそれを獲得するかの選択が、彼らの不満の重みに応じて総費用に大きく影響するからです。 

もう 1 つの微妙なエッジ ケースは、複数の学生が同じ優先席を共有していて、不満の値が大きく異なる場合です。 たとえば、3 人の生徒全員が座席 1 を希望している場合、その費用は次のとおりです。$1, 1000, 1000$、その場合、学費の高い生徒を自分の好みから遠ざけるのは費用がかかるため、避けるべきです。 これらの競合に適切な優先順位を付けない貪欲な人は、次善の配置を簡単に選択してしまいます。 

最後に、すべての好みが異なる場合、答えは自明のことながらゼロになります。 正しいソリューションは、この構造を検出して保存する必要があります。 

## アプローチ

 強引な解釈では、生徒を座席に割り当てるすべての順列を試してみます。 順列ごとに、希望の座席に着いていない生徒の不満の合計を計算します。 これは、考えられるすべての割り当てをチェックするため、正しいです。 ただし、置換の数は、$n!$、そしてさらには$n = 10$、これはすでに大きすぎて計算できません。 

実際に何がコストを生み出すのかを理解する必要があります。 この費用は、生徒が希望する座席に割り当てられなかった場合にのみ発生します。 これは問題を再構成したものです。各座席は 1 回しか使用できないという制約の下で、希望する座席を無事に取得した生徒から得られる「節約されたコスト」の合計を最大化したいと考えています。 

これで構造がより明確になりました。 基本的に各学生は 1 つの座席に対するリクエストであり、各リクエストには重みがあります。 リクエストを満たすと、その学生の不満コストと同じだけの削減が得られるため、できるだけ多くの重要なリクエストに応えたいと考えています。 

これは、学生と座席の間の 2 部グラフにおける最大重み付けマッチング問題になりますが、非常に特殊な構造を持ちます。各学生には、希望する座席が 1 つだけあります。 これは、議席ごとの貪欲な競合解決の問題に帰着します。 

重要なアイデアは、各座席を個別に処理し、最大 1 人の生徒をその座席に割り当てることです。 複数の学生が同じ席を希望する場合は、不満のコストが最も大きい学生にその席を与えるべきです。そうすることで、そのリクエストを満たすことで最大の利益が得られるからです。 他の学生はすべて別の場所に割り当てられ、費用を支払う必要があります。 

これにより、問題は生徒を好みの座席に基づいてグループ化し、グループごとに 1 人の代表者を選択するという問題に変わります。

 | ブルートフォース |$O(n!)$|$O(n)$| 遅すぎる |
 | 最適 |$O(n \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 私たちは各座席を希望する生徒のバケツとして扱います。 

1. すべての生徒を希望の座席ごとにグループ化します。 席ごとに、それを希望する学生のリストとその不満の値を収集します。 
2. 各座席グループについて、最も高い不満値を持つ学生を選択します。 その生徒をこの席に割り当てます。 この選択により、座席ごとに 1 人しか満足させることができない場合でも、高額な費用の学生を満足させる利点を最大化することができます。 
3. 同じグループ内の他の生徒全員を「希望の座席に割り当てられていない」としてマークします。 これらの学生は、後で残りの空き席に配置されます。 
4. 選ばれた生徒を受け入れなかったすべての座席を回収します。 こちらは自由席です。 
5. 希望の座席に割り当てられなかった生徒を全員集めます。 これらは残った生徒たちです。 
6. 残った学生を自由席に任意に割り当てます。いずれにしても、これらの割り当てはいずれも彼らの希望に一致しないため、そのような学生は、どの間違った席を獲得したかに関係なく、不満のコストを全額負担します。 

重要なデザインの選択はステップ 2 です。各座席内で、最も置き場所を間違える可能性が高い生徒だけを配置します。 その理由は、その座席を「保存」するチャンスは 1 回だけであり、できるだけ高価な学生を節約したいからです。 

### なぜ効果があるのか

 このアルゴリズムは、座席ごとの局所的な最適性条件によって駆動されます。 各座席には最大 1 人の生徒を割り当てることができるため、その座席を争うすべての生徒のうち、費用を支払わずに済むのは 1 人だけです。 最大コストの学生を選択すると、そのグループからの合計ペナルティが最小限に抑えられます。これ以外の選択をすると、より高いコストの学生がマッチせず、完全なペナルティを受けることになるためです。 グループは座席間で独立しているため、これらのローカルで最適な決定が組み合わされて、グローバルに最適な割り当てになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pref = list(map(int, input().split()))
    cost = list(map(int, input().split()))
    
    buckets = [[] for _ in range(n + 1)]
    
    for i in range(n):
        buckets[pref[i]].append(i)
    
    ans = [-1] * n
    used_seats = [False] * (n + 1)
    
    # assign best candidate per seat
    free_seats = []
    unassigned = []
    
    for seat in range(1, n + 1):
        if not buckets[seat]:
            free_seats.append(seat)
        else:
            best = buckets[seat][0]
            for i in buckets[seat]:
                if cost[i] > cost[best]:
                    best = i
            ans[best] = seat
            used_seats[seat] = True
            
            for i in buckets[seat]:
                if i != best:
                    unassigned.append(i)
    
    # assign remaining seats
    ptr = 0
    for i in unassigned:
        while ptr < len(free_seats) and ans[i] == -1:
            s = free_seats[ptr]
            ptr += 1
            ans[i] = s
    
    print(sum(cost[i] for i in range(n) if ans[i] != pref[i]))
    print(*ans)

def main():
    solve()

if __name__ == "__main__":
    main()
```コードはまず、希望する座席に基づいて学生をグループ化します。 次に、座席ごとに、最大の不満コストを持つ学生を特定し、直接割り当てます。 他のすべての学生は再割り当てのために集められます。 

自由席はまさに「優秀な」生徒が選ばれていない席です。 これらは残りの生徒を埋めるために使用されます。 最終的な費用の計算では、希望する座席に配置されなかった生徒の費用を単純に合計します。 

微妙な点の 1 つは、残った学生がどの間違った席を受け取るかは気にしないということです。 費用は座席が好みと一致するかどうかによってのみ決まり、座席がどの程度間違っているかによって決まります。

 ## 特殊なケース

 主なエッジケースは、生徒全員が同じ座席を好む場合です。 次のような入力の場合:```
3
1 1 1
5 2 7
```アルゴリズムはコスト 7 の生徒を席 1 に配置します。これにより、コストの節約が最大化されます。 残りの 2 人の学生は別の席に座らされ、不満が募ります。 グループ化ステップにより、すべての候補が一緒に検討されるようになり、最大コストの選択により最適な節約が保証されます。 

もう 1 つの特殊なケースは、1 つの席に興味のある学生がいない場合です。 その席が空き枠となり、自然に余った生徒を吸収することになる。 不満は不一致のみに依存するため、これらの空きシート間の配置は同等であるため、割り当て順序は最適性に影響しません。
