 ## 解決策
 ## 問題の理解

 前の値に固定係数を繰り返し乗算し、剰余をとることによって生成された、決定論的な整数のシーケンスが与えられます。 シーケンスは指定された初期値から開始され、正確に結果を生成します。$n$数字。 次の各数値は前の数値にのみ依存するため、4 つのパラメーターが判明すると行全体が完全に決定されます。 

タスクは、シーケンス全体をそれ自体のために計算することではなく、生成された行のどこかに現れる 5 つの最大の値を特定し、昇順に出力することです。 

の制約$n$到達する$2 \cdot 10^7$これは、すべての値を保存しようとしたり、線形時間よりも悪いものを実行しようとするアプローチは失敗することを意味します。 二次関数または偶数$O(n \log n)$並べ替えベースのソリューションも実際には遅すぎます。シーケンスの生成には既に数千万回の操作が必要であり、追加のオーバーヘッドが時間制限を超えることになるからです。 また、各要素がオーバーヘッドのあるリストに保持されている場合、メモリ制限により、Python で完全な配列を安全に保存できなくなります。 

素朴な解釈では、すべての値を生成し、それらを並べ替えて、上位 5 つを選択します。 このアプローチは論理的には正しいですが、規模が大きくなるとすぐに壊れてしまいます。 のために$n = 20{,}000{,}000$、並べ替えには次の順序で必要になります$n \log n$、これは実現可能性をはるかに超えています。 

後でスキャンするためだけにすべての値を保存しようとすると、さらに微妙な問題が発生します。 たとえメモリが適合していても、キャッシュの動作が低下し、Python のオーバーヘッドが実行時間の大半を占めます。 

注目に値するまれなケースは、シーケンスがすぐに繰り返しまたはゼロに崩壊する場合です。 たとえば、次の場合$p = 1$の場合、次の条件に関係なく、すべての値がゼロになります。$a_1$そして$k$。 この場合の正しい出力は単に 5 つのゼロですが、変動性を前提とした不注意な実装では、依然として不必要な処理を試行したり、重複を誤って処理したりする可能性があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。すべてを生成します。$n$繰り返しを使用して値を取得し、それらを配列に格納し、配列を並べ替えて、最後の 5 つの要素を取得します。 これは、並べ替えによってすべての値が正しくランク付けされるため機能しますが、両方のメモリが必要になります。$n$整数と時間$O(n \log n)$。 と$n$最大 2,000 万の場合、アレイを構築するために必要なリニア スキャンですらすでに高価であり、ソートが完全に支配的です。 

重要な観察は、実際にはすべての値を完全に順序付ける必要はないということです。 シーケンスのストリーミング中にこれまでに確認された 5 つの最大値を知る必要があるだけです。 これにより、問題はグローバル順序付けタスクからストリーミング選択問題に変換されます。 

シーケンス自体は 1 パスで生成され、各ステップで、現在のベスト 5 候補を含む小さな構造を維持できます。 この構造がサイズ 5 を超えることはないため、すべての更新は定数時間です。 すべてをソートすることから固定サイズのトップセットを維持することへの移行により、対数係数が完全に削除されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (ストア + ソート) |$O(n \log n)$|$O(n)$| 遅すぎる |
 | ストリーミング トップ 5 メンテナンス |$O(n)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最初の値を計算します$a_1$そしてそれを答えの最初の候補として扱います。 シーケンスが開始される前は比較ができないため、これにより実行中の構造が初期化されます。 
2. これまでに確認された最大値を表す最大 5 つの数値からなる小さなリストを維持します。 最も小さいものに常にアクセスしやすいように、昇順に並べ替えてください。 
3. 2 番目の要素から次の要素までシーケンスを繰り返します。$n$-th 要素、次を使用して各値を生成します$a_i = (a_{i-1} \cdot k) \bmod p$。 このステップは純粋にストリーミングであるため、過去の値は保存されません。 
4. 新しく生成された値ごとに、現在の上位 5 つのリストの最小要素と比較します。 それより大きくない場合は、最終的な答えには影響しないため、すぐに破棄してください。 
5. 新しい値が上位 5 つのリストの最小値よりも大きい場合は、その値をリストに挿入し、サイズを固定するために最小の要素を削除し、並べ替え順序を復元します。 これにより、リストにはこれまでに確認された最良の候補が常に含まれるようになります。 
6.すべての処理が完了したら$n$値の場合、保存されている 5 つの値を昇順に出力します。 

重要な不変条件は、最初の処理後、$i$要素の場合、維持されるリストには、それらの中で最も大きい 5 つの値が正確に含まれます。$i$要素、ソート済み。 これは、リストが最初の要素から始まり、サイズ 5 まで増加するため最初は保持されます。また、すべての新しい値は上位 5 つに入ることができないか、より大きな要素を妨げることなく現在の上位 5 つの中の最小値を置き換えるために保持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, a1, k, p = map(int, input().split())

top = [a1]

cur = a1
for i in range(1, n):
    cur = (cur * k) % p

    if len(top) < 5:
        top.append(cur)
        top.sort()
    else:
        if cur > top[0]:
            top[0] = cur
            top.sort()

print(*top)
```このソリューションは、最大 5 つの要素のリストという最小限のデータ構造に依存します。 固定サイズの配列のソートは事実上一定時間であるため、各更新は一定の作業となります。 再計算や保存を避けるために、反復計算が行われます。 

微妙な点は、完全なシーケンスを決して保存しないことです。 変数`cur`は前の値のみを保持します。これは次の値を生成するのに十分です。 これにより、メモリ使用量が一定に保たれます。 

もう 1 つの詳細は、条件付き置換ロジックです。 新しい値が上位 5 つの現在の最小値を超えた場合にのみ、構造を変更します。 これにより、不必要な並べ替え操作が防止されます。これは、厳しい時間制約を考慮すると重要です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from sys import stdout
    import builtins

    input = sys.stdin.readline
    n, a1, k, p = map(int, input().split())

    top = [a1]
    cur = a1

    for i in range(1, n):
        cur = (cur * k) % p
        if len(top) < 5:
            top.append(cur)
            top.sort()
        else:
            if cur > top[0]:
                top[0] = cur
                top.sort()

    return " ".join(map(str, top))

# provided samples

# minimum-size edge
assert run("5 7 1 10") == "7 7 7 7 7"

assert run("5 1 10 1000") == "1 10 100 1000 0"

 ## 特殊なケース

 いつ$p = 1$、モジュロが続くすべての乗算はすぐにゼロを生成します。 シーケンス生成ステップでゼロのストリームが生成され、上位 5 つの構造が徐々にゼロで埋められて安定するため、アルゴリズムは引き続き正常に動作します。 最終出力は、特別な処理を行わなくても、正しく 5 つのゼロになります。 

いつ$k = 1$、シーケンスは一定になります。 最初の値はすべての位置で繰り返されるため、上位 5 つの構造は単純に同じ値で埋められます。 重複が許可されているため、置換ロジックによって最終結果が変更されることはなく、アルゴリズムは依然として同じ番号の 5 つのコピーを返します。 

いつ$n = 5$、構造が交換フェーズに入ることはありません。 すべての要素が直接挿入されるため、メンテナンス ロジックに依存せずに、初期化の正確さと最終出力の書式設定がテストされます。
