 ## 問題の理解

 元々は単純な式から得られたシーケンスの、部分的に破損した記述が与えられています。 不明な整数値があります$k$、およびインデックスごとに$i$、目的の値は除算によって得られます。$k$による$i$標準的な数学的な四捨五入を使用して最も近い整数に四捨五入し、半分が切り上げられます。 

ということで、それぞれのポジション$i$どちらかが正しい丸め値を含んでいます$c_i$、またはが欠落しており、疑問符としてマークされています。 目標は、可能な限り最小の正の整数を再構築することです。$k$すべての既知のエントリがこの丸め規則と一致するようにします。 

既知の各制約関係$k$狭い範囲の値に限定されます。 もし$c_i$知られているなら、$k/i$周囲の間隔になければなりません$c_i$幅 1 を中心に$c_i$。 それは問題を「推測」から変換します。$k$」を「多くの区間の交点にある整数を見つける」に変換します。 

制約が厳しいので、$n \le 1000$、可能な限りすべてをチェックするソリューション$k$大きな境界までは実行不可能です。 直接検索$k$潜在的に最大の値を考慮する必要があります$10^9$入力に応じてそれ以上ですが、総当たり反復には大きすぎます。 

丸めには微妙な点があります。条件は等価ではなく、間隔の制約です。 もう 1 つの重要な点は、欠落しているエントリには制限がないため、完全に無視できるということです。 

素朴な間違いはこう解釈することだろう$c_i = k/i$正確な分割またはフロア分割として。 たとえば、次の場合$k = 5$そして$i = 2$、 それから$k/i = 2.5$これを 2 または 3 として扱うと、どちらも間違っており、すべての制約が誤ってシフトされます。 

## アプローチ

 強引なアイデアは、次の値を増やしてみることです。$k$1 から順に実行し、すべてが既知であるかどうかを確認します$c_i$丸めルールと一致します。 候補者ごとに$k$、計算します$k/i$、四捨五入して、すべての既知の位置と比較します。 各小切手にかかる費用$O(n)$したがって、答えが大きい場合、これは法外に遅くなります。 

非効率性は、制約の構造を使用しないことに起因します。 それぞれ固定$c_i$単一の有効な値を与えるだけではありません$k$、有効な範囲を連続的に与えます。$k$価値観。 丸め条件は、次の形式の不等式に変換されます。$k/i$に近いです$c_i$」で直線区間になります。$k$。 

各制約が区間になると、問題はこれらすべての区間を交差させ、交差部分内の最小の整数を見つけることになります。 検索する代わりに$k$、グローバルな実行可能領域を維持し、既知のすべての観測を使用してそれを縮小します。 

残りの唯一の微妙な点は、丸めによって半整数の境界が作成されるため、すべてを 2 でスケールし、浮動小数点の問題を完全に回避する方がきれいです。

 ## アルゴリズムのチュートリアル

 すべてを 2 倍にすることで端数の境界を排除します。 と協力する代わりに、$k$、私たちは協力しています$T = 2k$。 各制約は単純な整数間隔になります。 

1. 既知のペアごとに$(i, c_i)$、丸めルールを境界に変換します。$T = 2k$。 

条件$c_i - 0.5 \le \frac{k}{i} < c_i + 0.5$になる$2i c_i - i \le 2k < 2i c_i + i$。 

それで$T$整数間隔内になければなりません$[2ic_i - i, 2ic_i + i - 1]$。 
2. グローバルな実行可能な間隔を維持する$[L, R]$のために$T$。 非常に幅の広いものとして初期化し、各制約間隔と交差させます。 

既知のそれぞれを処理した後、$c_i$、 アップデート$L = \max(L, 2ic_i - i)$そして$R = \min(R, 2ic_i + i - 1)$。 
3. すべての制約を処理した後、有効な$T$値はまさにその整数です$[L, R]$。 ここで必要となるのは最小の有効な$k$、これは最小偶数に相当します。$T$この範囲内で。 
4.調整する$T$最初の偶数以上まで$L$。 もし$L$均等です、それを保ちます。 それ以外の場合は 1 ずつ増加します。 
5. 出力$k = T / 2$。 

なぜそれが機能するかは、各制約が凸状であるという事実に関係しています。$k$。 丸めルールにより、各値の有効な値の連続した間隔が作成されます。$i$、そのような間隔をすべて交差すると、実行可能な解のセットが正確に保存されます。 すべての制約は必要十分条件であるため、$k$最終交差点の外側では、既知の少なくとも 1 つの交差点に違反する可能性があります。$c_i$、および任意の$k$inside はすべての制約を同時に満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    arr = input().split()

    L = -10**30
    R = 10**30

    for i, val in enumerate(arr, start=1):
        if val == '?':
            continue

        c = int(val)

        left = 2 * i * c - i
        right = 2 * i * c + i - 1

        L = max(L, left)
        R = min(R, right)

    if L % 2 != 0:
        L += 1

    T = L
    k = T // 2
    print(k)

if __name__ == "__main__":
    main()
```実装の核心は、丸め制約から線形不等式への変換です。$2k$。 既知の各値は実行可能な範囲を狭め、未知の位置は制約に寄与しないため、考慮する必要はありません。 最後のステップでは、有効な最小の整数を選択します。$k$、これは最小偶数に相当します。$T$。 

よくある間違いは、スケーリングの前に上限が排他的であることを忘れることです。 そのため、インターバルは次の時点で終了します。$2ic_i + i - 1$、 ない$2ic_i + i$。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、1 つを除くすべてのエントリが欠落している場合です。 このアルゴリズムは単一の間隔制約に帰着し、答えは完全にその制約から得られます。 交差ロジックは非常に広い範囲から開始され、正しく縮小されるため、引き続き機能します。 

もう 1 つの微妙なケースは、実行可能な間隔に奇数の値のみが含まれる場合です。$T$。 以来$T$偶数である必要があるため、明示的に上方調整します。 たとえば、次の場合$T \in [15, 15]$では、15 をスキップして 16 に進みます。元の定義では少なくとも 1 つの偶数解が存在することが保証されているため、このシフトにより有効性が保たれます。 

さらに特殊なケースは、制約が単一の境界値で重なる場合です。 スケーリング後の上限は包括的であるため、間隔のエンドポイントは安全であり、最終調整ステップで有効な最小解が誤って除外されることはありません。
