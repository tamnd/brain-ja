 ## 問題の理解

 私たちに与えられた木は、$n$ノードは接続された非巡回グラフであり、ノードを繰り返し消去してシーケンスを構築する必要があります。 ノードを消去するたびに、その時点で残っている隣接ノードの数をシーケンスに記録し、ノードとそれに接続されているすべてのエッジを削除します。 最終的な目標は、各整数をカウントすることです。$k$1から$n$、最大公約数が以下に等しいシーケンスの数$k$。 

入力は複数のテスト ケースで構成されます。 各テスト ケースが提供するのは、$n$とリスト$n-1$ツリーを定義するエッジ。 私たちは生産しなければなりません$n$カウントのモジュロに対応する、各テスト ケースの数値$998{,}244{,}353$。 

とすれば$n$と同じ大きさにすることができます$10^5$テストケースごととすべての合計$n$テストケース全体で最大$3 \cdot 10^5$、二次時間を使用する任意のアルゴリズム$n$遅すぎるでしょう。 これにより、ノード削除のあらゆる順列を試みるアプローチが即座に排除されます。 おおよそ線形または線形的な解を見つける必要があります。$n$、 理想的には$O(n \sqrt{n})$数論的手法が使用される場合。 

星や道のように、程度が最小限に変化するツリーでは、微妙なエッジ ケースが発生します。 たとえば、3 つのノード (ノード 1 が 2 と 3 に接続されている) を持つスターでは、次のようなシーケンスが可能になります。$[2,0,0]$そして$[1,1,0]$。 GCD が任意の葉の削除シーケンスから推測できると単純に仮定すると、失敗します。 削除の順序によって順序が根本的に変わるため、組み合わせの意味ですべての可能性を考慮する必要があります。 

## アプローチ

 ブルートフォースソリューションでは、すべてが列挙されます。$n!$ノード削除順序を計算し、それぞれの結果のシーケンスを計算して、GCD を計算します。 原理的には正しいですが、これは完全に実行不可能です。 たとえ$n = 10$、$10!$300万を超えており、$n = 10^5$それは天文学的な大きさです。 

重要な洞察は、約数を考慮することで得られます。 まず、すべての要素が次の数で割り切れるシーケンスに焦点を当てましょう。$k$。 これは問題を縮小することと同じです。次数が次数の倍数で表現できるノードのみを考慮するように、ツリーを「縮小」することを考えることができます。$k$。 次に、数論的な包含-排他 (メビウス反転原理) を使用して、潜在的な各 GCD のシーケンスを効率的にカウントできます。 

特定のツリー構造により、除数に対して動的プログラミングを使用できるようになります。 固定除数の場合$d$、ツリー上で DFS を実行し、各ノードで、そのスケールで次数が の倍数になるようにサブツリーを分割する方法を数えます。$d$。 リーフ ノードは基本ケースを示します。つまり、除数を満たすか満たさないかのいずれかです。 内部ノードは、その子からの結果を乗算的に結合します。 これにより、複雑さが大幅に軽減されます。すべての順列をチェックする代わりに、関連する除数ごとに各ノードを 1 回考慮するだけで済みます。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$そしてツリーを隣接リストとして構築します。 ツリー構造は DFS トラバーサルにとって重要です。 
2. 最大除数を計算します$d$検討する必要があります。 私たちに必要なのは$d \le n$GCD がより大きいため$n$一定の長さのシーケンスでは出現できません$n$。 
3. 各約数について$d$1から$n$、ツリー上で DFS を実行します。 各ノードで、結果として得られるすべての値が次の数で割り切れるように、有効なサブツリー シーケンスの数を計算します。$d$。 DP 関係は子に対して乗算的です。すべての子が除数条件を満たしている場合、親は 0 から次数で割った値までの値を取ることができます。$d$可分性を保つもの。 
4. ステップ 3 の結果を配列に格納します`count[d]`、すべての値が次の数で割り切れるシーケンスの数を表します。$d$。 
5. メビウス反転を使用して、倍数で割り切れる数列の数を、GCD が正確に一致する数列の数に変換します。$k$。 与えられた$k$、正確な GCD シーケンスは、すべての適切な倍数から寄与を差し引くことによって取得されます。$k$すでに計算されています。 
6. 結果の配列を剰余として出力します。$998244353$。 

機能する理由: DFS は、特定の除数と互換性のあるすべてのサブツリー構成が 1 回だけカウントされることを保証します。 メビウス反転は、ターゲット GCD の倍数で割り切れるシーケンスの過剰カウントを修正します。 子に対する乗算 DP はツリー構造を利用します。ノードを削除するとツリーが独立したサブツリーに分割されます。そのため、このアプローチはすべての順列を列挙しなくても機能します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        adj = [[] for _ in range(n)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            adj[u].append(v)
            adj[v].append(u)

        count = [0] * (n + 1)
        
        # DP to count number of sequences divisible by d
        for d in range(1, n + 1):
            dp = [1] * n  # ways for each node
            def dfs(u, p):
                for v in adj[u]:
                    if v == p:
                        continue
                    dfs(v, u)
                    dp[u] = dp[u] * dp[v] % MOD
                if len(adj[u]) % d != 0:
                    dp[u] = 0
            dfs(0, -1)
            count[d] = dp[0]

        # Möbius inversion to get exact GCD counts
        res = [0] * n
        for k in range(n, 0, -1):
            s = count[k]
            m = 2 * k
            while m <= n:
                s -= res[m - 1]
                s %= MOD
                m += k
            res[k - 1] = s

        print(" ".join(map(str, res)))

if __name__ == "__main__":
    solve()
```このソリューションでは、まずツリー構造を読み取り、DP 配列を初期化します。 DFS は、子サブツリーから乗算寄与を計算します。 除数チェックにより、現在の除数と互換性のあるシーケンスのみがカウントされることが保証されます。 メビウス反転は、複数の割り算による過大なカウントを修正します。 モジュロ演算を慎重に行うと、整数のオーバーフローが防止されます。
