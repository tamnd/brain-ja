 ## 解決策
 ## 問題の理解

 平面内のマークされた点の固定セットが与えられます。 各クエリでは、任意の点から開始します。$S$そして次の地点に到達できるかどうかを知りたい$T$。 

単一の移動は、2 つのマークされた点を選択することによって定義されます。$P$そして$Q$。 それらを選択した後、新しいポイントを計算します$T$からの有向セグメントが$P$に$T$からの有向セグメントとまったく同じです$S$に$Q$。 ベクトル形式ではこれは次のようになります$$T = P + (Q - S) = P + Q - S.$$この点を計算した後、現在位置と位置を結ぶ線分の任意の点に移動できます。$T$だけでなく、$T$自体。 

したがって、各ステップには 2 つの効果があります。 まず、2 つの固定点によって決定される反射のような変換を適用し、次にセグメントに沿った連続的な移動を可能にします。 タスクは、間の到達可能性を決定することです。$S$そして$T$これらの操作を無制限に繰り返します。 

制約は十分に大きいため、どのソリューションでもマークされたポイントを 1 回または 2 回処理し、一定時間または対数時間でクエリに応答する必要があります。 状態空間は連続的でサイズに制限がないため、動きをシミュレートしたり、明示的に到達可能な点のセットを維持したりするアプローチは、すぐに失敗します。 

微妙な難しさは、離散的な変換と連続的なセグメントの移動の組み合わせから生じます。 変換自体は線形であっても、セグメントに沿って移動する機能により、到達可能なセットが離散軌道からその軌道の凸閉包に変更されます。 これを無視した単純なシミュレーションでは、正確さに不可欠な中間点を見逃してしまいます。 

マークされたポイントのジオメトリが縮退すると、エッジ ケースが発生します。 すべての点が 1 つの線上にある場合、システムは基本的に 1 次元的に動作しますが、依然として自明ではない連続到達可能性を維持します。 マークされた構成によって暗黙的に誘導される少なくとも 2 つの非平行な方向がある場合、到達可能なセットは劇的に拡大します。 セグメントの閉包を考慮せずに反射だけを考慮する単純なアプローチでは、そのようなケースが誤って分類されてしまいます。 

## アプローチ

 強引なアイデアは、すべての操作を、ノードが平面内の点であるグラフの状態遷移として扱うことです。 ある点から$S$、すべてのペア$(P, Q)$新しい点を生成します$P + Q - S$、次に、間のセグメント全体も考慮します。$S$そして今回の新たなポイント。 

マークされた点だけを離散化したとしても、これはすでに爆発を引き起こします。すべてのステップはすべてのステップに依存します。$n^2$マークされた点のペアが作成され、各ステップで新しい状態の連続体が作成されます。 2 回または 3 回の操作の後、可能な状態の数は幾何学的な意味で無限になるため、BFS または DP スタイルの探索は不可能になります。 

重要な観察は、変換がアフィンであるということです。 操作$S \mapsto P + Q - S$は中点を中心とする中心対称です。$P$そして$Q$。 したがって、各移動は 2 つの固定点の中点を横切る現在の点を反映し、結果として得られるセグメントに沿った移動が可能になります。 

これは 2 つの構造的事実を意味します。 まず、マークされた点によって方向と制約の有限セットが定義され、すべての変換でアフィン ハル構造が維持されます。 第 2 に、セグメント緩和は、2 つの点が到達可能になると、その凸包内のすべての点も到達可能になることを意味します。 したがって、到達可能な集合は、繰り返される中心対称によって生成される凸領域になります。 

ジオメトリは、マークされた点が同一線上にあるかどうかに基づいて分類されます。 

すべてのマークされた点が 1 つの線上にある場合、すべての中間点もその線上にあり、すべての変換はその線上のある点を横切る現在の点を反映します。 これにより、ラインまでの距離が非常に制御された方法で維持され、システムが垂直方向に沿って 1 次元の自由度に減少します。 

マークされた点が同一線上にない場合、中点のセットは 2 つの独立した方向に平面に広がります。 反射と凸状閉鎖を繰り返すと、到達可能な領域が平面全体を満たすまで拡張されます。

 ## アルゴリズムのチュートリアル

 ### 1. マークされたすべての点が同一線上にあるかどうかを確認します。 

すべてのマークされた点が同じ線上にあるかどうかを計算します。 これは、2 つの異なる点を修正し、他のすべての点との外積がゼロであることを確認することで実行できます。 すべてのポイントがこのチェックに合格した場合、縮退のケースになります。 それ以外の場合は、フルプレーンの場合になります。 

### 2. 非共線性ケースを処理する

 同一線上にない 3 つのマークされた点が存在する場合、それらの中点はすでに 2 つの独立した方向を生成しています。 繰り返しの反射を使用すると、平面内の任意の点を近似でき、セグメントの閉包によって離散性が完全に除去されます。 この状況では、すべてのクエリにすぐにアクセスできるため、答えは常に「YES」になります。 

### 3. 共線性のケースに対処する

 すべてのマークされた点が直線上にあると仮定します$L$。 次のように座標を選択します。$L$は X 軸です。 出発点としましょう$S = (x_s, y_s)$。 

Each operation reflects$S$X 軸上の点を横切って点を生成し、その Y 座標は次のようになります。$-y_s$一方、x 座標は選択した中点に応じて任意にシフトできます。 セグメント操作により、y 座標による点間の補間が可能になります。$y_s$そして$-y_s$。 

これから、唯一の不変条件は、ラインまでの距離の絶対値です。 すべての操作で y 座標の大きさを維持または減少させることができますが、それを超えて増加させることはできません$|y_s|$。 したがって、到達可能な領域は無限の水平ストリップになります。$$|y| \le |y_s|.$$質問点$T = (x_t, y_t)$ラインまでの距離が次の条件を満たしている場合にのみ到達可能です。$|y_t| \le |y_s|$。 

### なぜ効果があるのか

 変革$T = P + Q - S$は、同一線上の点によって定義される線に対して平行構造を維持するアフィン対称です。 非共線性の場合、アフィン スパンは 2 次元になり、凸閉包によってすべての制限が取り除かれます。 共線性の場合、垂直成分は、その大きさが線からの初期距離を超えることができない有界可逆符号反転システムのように動作します。 これら 2 つのレジームは網羅的であり、操作が 2 つの独立した方向にまたがるか、単一の軸に集約されるため、中間構造は存在しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def collinear(points):
    x0, y0 = points[0]
    x1, y1 = points[1]
    for x, y in points[2:]:
        if (x1 - x0) * (y - y0) != (y1 - y0) * (x - x0):
            return False
    return True

def solve():
    n, q = map(int, input().split())
    pts = [tuple(map(int, input().split())) for _ in range(n)]
    
    all_collinear = n <= 2 or collinear(pts)

    if not all_collinear:
        for _ in range(q):
            input()
            print("YES")
        return

    # collinear case: use line through first two distinct points if possible
    x0, y0 = pts[0]
    dx, dy = 0, 0
    for x, y in pts:
        if x != x0 or y != y0:
            dx, dy = x - x0, y - y0
            break

    # if all identical points, line is arbitrary; everything reachable
    if dx == 0 and dy == 0:
        for _ in range(q):
            input()
            print("YES")
        return

    # perpendicular distance proportional via cross product
    # line direction is (dx, dy), perpendicular measure is cross product
    def dist(p):
        x, y = p
        return abs(dx * (y - y0) - dy * (x - x0))

    base = None  # starting point S is per query

    for _ in range(q):
        xs, ys, xt, yt = map(int, input().split())
        ds = dist((xs, ys))
        dt = dist((xt, yt))
        print("YES" if dt <= ds else "NO")

if __name__ == "__main__":
    solve()
```コードはまず、マークされたポイントのジオメトリが縮退しているかどうかを判断します。 そうでない場合は、すべてのクエリに即座に肯定的に応答します。 

点が同一線上にある場合、問題は線方向に対する符号付き面積 (外積) の測定に限定されます。 この量は、スケーリングまでは垂直距離とまったく同じように動作し、到達可能な領域は、ラインからの開始点の距離によって境界付けられるストリップになります。 

## 実用的な例

 ### 例 1

 直線上にマークされた 3 つの同一直線上にある点と、その直線の上にある開始点を考えます。 

| ステップ | アクション | 状態 |
 | --- | --- | --- |
 | 1 | 線の方向を計算する | 修正済み |
 | 2 | S | の距離を計算します。$d_s = 5$|
 | 3 | クエリ T には距離 |$d_t = 3$|

 以来$d_t \le d_s$、答えはYESです。 

これは、開始点よりも線に近い任意の点は、繰り返しの反射とセグメントの収縮によって到達可能であることを示しています。 

### 例 2

 同じ構成ですが、ターゲットはラインから遠くなります。 

| ステップ | アクション | 状態 |
 | --- | --- | --- |
 | 1 | S | の距離を計算します。$d_s = 2$|
 | 2 | T の距離を計算する |$d_t = 6$|

 以来$d_t > d_s$、答えはNOです。 

これは不変条件を示しています。つまり、操作では開始の大きさを超えて垂直距離を増やすことはできません。

 ## 特殊なケース

 すべてのマークされた点が一致すると、すべての変換は 1 つの点の周りの自明な反射になり、到達可能なセットは反復対称とセグメントの閉包に崩壊しますが、セグメントの緩和により依然として平面全体をカバーします。 

正確に 2 つの別個のマークされた点が存在する場合、それらは 1 つのライン方向を定義し、システムは同一線上の場合と同様に動作します。 すべての中間点が同じ線上にあるため、距離不変条件が引き続き適用されます。 

開始点がすでにマークされたライン上にある場合、到達可能なストリップはライン自体に縮退します。 その場合、直線上の点のみが到達可能となり、アルゴリズムはすべての操作を通じて垂直距離をゼロに正しく強制します。
