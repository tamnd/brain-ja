 ## 解決策
 ## 問題の理解

 いくつかのパケットが与えられ、各パケットには既知の数の風船が含まれています。 タスクは、これらのパケットを 2 人に分割して、各パケットが完全に 1 人に届くようにすることです。 パケットを壊すことはできず、両方の人が少なくとも 1 つのパケットを受け取る必要があります。 

分割後、各人が受け取る風船の合計数を計算します。 目標は、これら 2 つの合計が異なることを確認することです。 このような分割が存在する場合、最初の人にパケットの有効な割り当てを 1 つ出力する必要があります。 それ以外の場合は、有効な分割が存在しないと報告されます。 

入力サイズは非常に小さく、最大でも 10 パケットです。 これは、サブセットに対する指数関数的な検索が実行可能であることを直ちに示唆しています。 考えられるすべての割り当て (最大 2^10 = 1024 のケース) をチェックするソリューションは、単純な計算でも十分に制限内に収まります。 

主なエッジ ケースは、パケットが 1 つだけ存在する場合に発生します。 その場合、両方の人に同時に少なくとも1つのパケットを与えることは不可能なので、答えは不可能に違いありません。 もう 1 つの微妙な状況は、すべてのパーティションの合計が等しい場合ですが、すべてのパケット サイズが正であるため、これは単純な単一パケットの場合にのみ発生する可能性があります。 

## アプローチ

 最も直接的なアイデアは、パケットをグリゴリーまたはアンドリューに割り当てるあらゆる可能な方法を試すことです。 各パケットには 2 つの選択肢があるため、合計 2^n 個の割り当てがあります。 割り当てごとに、各グループのバルーンの合計を計算し、両方のグループが空でなく、その合計が異なるかどうかを確認します。 

この強引な方法は、漏れなく完全な解空間を探索するため、正しいです。 問題は、n が大きくなる可能性がある一般的な問題におけるパフォーマンスです。 n が 10 までの場合でも、このアプローチは依然として非常に高速です。なぜなら、最大 1024 個のサブセットがチェックされ、各合計計算のコストが O(n) となり、約 10,240 回の演算が必要になるからです。 

重要な点は、これ以上最適化する必要がないということです。 徹底的な検索が目的の解決策となるように、制約は意図的に小さくなっています。 必要なのは、1 つのグループが空であるか、合計が正確に一致する無効なパーティションを確実にスキップすることだけです。

 | サブセットに対するブルート フォース | O(n · 2^n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのパケットにわたるバルーンの合計数を計算します。 この値は、一方の側がわかればもう一方の側も決定されるため、各分割を迅速に評価するのに役立ちます。 
2. パケットが 1 つだけの場合は、すぐに -1 を出力します。 1 つのパケットを 2 つの空ではないグループに分割する方法はありません。 
3. パケットのすべてのサブセットを反復処理し、各パケットが Grigory に割り当てられているかどうかを表します。 
4. 各サブセットについて、それが空でも完全なセットでもないことを確認します。 これにより、両方の人が少なくとも 1 つのパケットを受信することが保証されます。 
5. 選択したサブセット内のバルーンの合計を計算します。 
6. この合計を残りの合計と比較します。 それらが異なる場合、これは有効な解決策であり、すぐに出力できます。 
7. 機能するサブセットがない場合は、-1 を出力します。 

### なぜ効果があるのか

 すべての有効な割り当ては、パケット インデックスの 1 つのサブセットに正確に対応します。 このアルゴリズムは、片側が空である無効なサブセットを除くすべてのサブセットをチェックします。 有効なサブセットごとに、残りの唯一の制約、つまり 2 つの合計が異なることを検証します。 考えられるすべてのパーティションが検査されるため、有効な解決策が見つかります。解決策が存在しない場合は、すべての可能性を検索します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    if n == 1:
        print(-1)
        return

    total = sum(a)
    m = 1 << n

    for mask in range(1, m - 1):
        s = 0
        for i in range(n):
            if mask & (1 << i):
                s += a[i]

        if s != 0 and s != total and 2 * s != total:
            print(bin(mask).count("1"))
            res = []
            for i in range(n):
                if mask & (1 << i):
                    res.append(i + 1)
            print(*res)
            return

    print(-1)

if __name__ == "__main__":
    solve()
```このソリューションでは、ビットマスクを使用してすべてのサブセットを列挙します。 各マスクは、どのパケットがグリゴリーに与えられるかをエンコードします。 条件`mask range 1 to (1<<n)-2`両側が空でないことを保証します。 

マスクごとに、サブセットの合計を計算し、それが相補的な合計と異なるかどうかを確認します。 小切手`2 * s != total`両方の合計が等しくないという要件を直接エンコードします。 

有効なサブセットが見つかると、そのサイズとインデックスが出力されます。

 ## 特殊なケース

 単一パケットのケースは、構造的に不可能な唯一のシナリオです。 のような入力で`1\n7`、各人に少なくとも 1 つのパケットを割り当てる方法がないため、アルゴリズムは列挙の前にすぐに -1 を返します。 

のような対称的な場合`2\n1 1`列挙でも失敗します。 可能な分割は次のとおりです。`{1}`そして`{2}`、両方とも等しい合計を生成します。 アルゴリズムは両方のマスクをチェックし、有効なサブセットを正しく検出し、最終的に -1 を出力します。 

サブセット チェックが明示的に比較するため、わずかに大きい対称のようなケースでも正しく動作します。`2 * sum != total`。 完全にバランスが取れているパーティションは拒否されますが、不均衡が見つかった場合は直ちに受け入れられます。
