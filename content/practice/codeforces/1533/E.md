 ## 解決策
 ## 問題の理解

 私たちは、ポリカープの既存の選手名簿に最後の 1 人を加えてチェス チームを結成する任務を負っています。$n$メンバー。 各プレイヤーの強さは整数であり、相手チームはすでに$n+1$メンバー。 目標は、次の候補者から 1 人を選択することです。$m$私たちのチームと相手のチームを組み合わせた後、プレーヤーの対戦相手と自分自身の間の最大の差、つまりゲームの難易度が最小限になるようにオプションを設定します。 

入力により、現在のチームのスキルが得られます$a_1 \dots a_n$、相手チーム$b_1 \dots b_{n+1}$、および候補オプション$c_1 \dots c_m$。 候補者ごとに、プレーヤーを最適に組み合わせることによって達成できる最小の難易度を計算する必要があります。 

制約は大きくなります。$n$そして$m$到達できる$2 \cdot 10^5$、任意の意味$O(n \cdot m)$または$O(n^2)$アプローチが遅すぎるでしょう。 2 秒の実行では、次のような解決策が必要です。$O(n \log n + m \log n)$またはそれ以上です。 

単純な実装では見逃す可能性のあるエッジ ケースには、候補者のスキルが既存のチーム メンバー全員よりもはるかに小さい、またははるかに大きい状況が含まれます。 たとえば、すべてが$a_i = 1$そして候補者は$c_k = 10^9$、ペアリングが不十分だと、大きな問題が発生する可能性があります。 並べ替えや最適なペアリング順序を考慮しない不注意なアルゴリズムでは、このような極端な状況では誤った結果が生じる可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、各候補者をチームに追加し、すべての候補者を生成することを検討します。$n+1$相手チームとの可能な組み合わせを階乗的に計算し、それぞれの最大難易度を計算します。 このアプローチは原理的には正しいですが、まったく実行不可能です。 のために$n = 2 \cdot 10^5$、順列の数は天文学的です。 

重要な観察は、ソート後に最大差を最小限に抑えることは、最小のスキルを最小の反対スキルと一致させ、最大のスキルを最大のスキルと一致させることと同じであるということです。 これは機能があるためです$f(x) = b_j - a_i$は順序に関して単調です。強いプレーヤーと強い対戦相手をマッチングさせると、最悪の場合のギャップが減少します。 したがって、既存のチームと対戦相手の両方をソートすることで、連続するメンバー間の差を事前に計算することができます。 2 つの差の配列を計算できます。1 つは最初の対戦相手をスキップすることを表し、もう 1 つは最後の対戦相手をスキップすることを表し、新しい候補のすべての挿入ポイントを効果的にカバーします。 次に、各候補について、二分探索によってソートされたチーム内の正しい位置が見つかり、事前に計算された配列によって最小限の難易度がすぐに得られます。 

ソート後に隣接するペアのみを考慮すればよいという観察により、問題は次のように軽減されます。$O((n+1)!)$に$O(n \log n + m \log n)$、入力サイズとしては許容範囲内です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((n+1)!) | O(n) | 遅すぎる |
 | ソート + 貪欲 + 二分探索 | O(n log n + m log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. Polycarp の現在のチームを並べ替える$a$そして相手チーム$b$。 これにより、順序によるペアリングが個々の問題を最小限に抑えることができます。 
2. 2 つのプレフィックス配列を計算します。`left_diffs`ペアリング用$a_i$と$b_{i-1}$（最初の対戦相手をスキップ）そして`right_diffs`ペアリング用$a_i$と$b_i$（最後の対戦相手はスキップします）。 それぞれに、そのシナリオの最大の差が保存されます。 これらの配列は、新しい候補者が埋めることができる 2 つの自然な「ギャップ」を表します。 
3. 各候補者について$c_k$、二分探索を使用して場所を特定します$c_k$分類されたチームに適合するだろう$a$。 これにより、どの相手のギャップを占めるかが特定されます。 
4. 左側の接頭辞の最大難易度、候補によってもたらされた差、および右側の接尾辞の最大難易度を組み合わせて難易度を計算します。 このステップでは、事前に計算された配列を使用します。$O(1)$アクセス。 
5. 各候補の最低難易度を出力します。 

機能する理由: ソートにより、順番にペアリングすると最大の差が最小限に抑えられます。 プレフィックスの最大値を事前に計算すると、候補の挿入に対する新しい最大難易度を効率的に計算できます。 二分探索により、候補者が既存のチームと比較して最適な場所に配置されることが保証されます。 構造上、アルゴリズムは常に各候補の最小達成可能な最大差を評価します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import bisect

n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))
m = int(input())
c = list(map(int, input().split()))

a.sort()
b.sort()

left = [0] * n
right = [0] * n

for i in range(n):
    left[i] = b[i] - a[i]
for i in range(n):
    right[i] = b[i+1] - a[i]

pref_left = [0] * (n+1)
pref_right = [0] * (n+1)

for i in range(n):
    pref_left[i+1] = max(pref_left[i], left[i])
for i in range(n-1, -1, -1):
    pref_right[i] = max(pref_right[i+1], right[i])

res = []
for val in c:
    idx = bisect.bisect_left(a, val)
    max_left = pref_left[idx]
    max_right = pref_right[idx]
    max_diff = max(max_left, max_right, b[idx] - val)
    res.append(str(max_diff))

print(' '.join(res))
```このソリューションでは、まずチームを並べ替えてから、対戦相手の配列のどちらかの端をスキップするときの差を事前計算します。 二分探索により候補の最適な挿入ポイントが特定され、最大難易度が候補ごとに一定時間で計算されます。 プレフィックス配列を慎重に処理することで、off-by-o を防止します。
