 ## 解決策
 ## 問題の理解

 正、負、またはゼロの整数の配列が与えられ、隣接する 2 つの要素を選択し、それらの符号を同時に反転するという 1 つの操作を何度でも実行できます。 目標は、これらの操作を最適に適用した後、すべての配列要素の合計を最大化することです。 

入力は複数のテスト ケースで構成され、それぞれの長さは$n$そして配列$n$整数。 出力は、テスト ケースごとに 1 つの整数、つまり、許可された任意の数の操作の後に達成可能な最大合計です。 

制約は重要です。$n$最大 200,000、および合計$n$すべてのテスト ケース全体で 200,000 を超えません。 このようなブルー​​トフォースアプローチは指数関数的に複雑になる可能性があるため、これにより、考えられるすべてのペアシーケンスを検査したり、操作を盲目的にシミュレートしたりするアルゴリズムは除外されます。 各要素の大きさは次のとおりです。$10^9$または同じくらい小さい$-10^9$したがって、中間合計は 64 ビット整数で処理する必要があります。 

見落としがちなエッジ ケースには、すべて負の数が奇数長である配列が含まれます。 例えば、$[-1, -1, -1]$各操作は 2 つの要素に影響するため、すべての要素を正に反転することはできません。 ここでの最適な合計は、最初の 2 つの要素を反転して取得することで得られます。$[1, 1, -1]$、合計すると$1$。 もう 1 つの微妙なシナリオは、ゼロを含む配列です。負とゼロを反転すると、ゼロを損なうことなく負を正に変換でき、合計が増加します。 

## アプローチ

 ブルートフォース手法は簡単です。すべての隣接するペアを反復処理し、符号を反転し、合計を計算し、改善が不可能になるまで繰り返します。 これは原理的には機能しますが、可能な操作シーケンスの数は指数関数的に増加します。 のために$n = 2 \cdot 10^5$、各ペアを一度考慮しても、すでに$O(n)$収束するまで反復すると、数百万または数十億の操作が発生する可能性があり、これは実現不可能です。 

より高速なソリューションを実現する重要な観察は、パリティと絶対値から得られます。 2 つの隣接する要素を反転すると、絶対値の合計は保持されますが、符号を変更できます。 すべての要素が負でない場合、合計は最大になります。 負の要素が偶数個ある場合は、それらをペアにして、すべてが正になるまで各ペアを反転します。 負の要素が奇数個ある場合は、1 つを除くすべてを正に反転して、絶対値の最も小さい要素を負のままにすることができます。 これは、この演算では符号をペアで反転することしかできないため、残った 1 つの負の値を削除することができないためです。 

最適なアプローチは、すべての要素の絶対値を合計し、負の数のカウントが奇数の場合は、最小の絶対値の 2 倍を減算することになります。 これにより、可能な限り最小限の影響でマイナス要素を 1 つだけ残すことが保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`total_sum`ゼロに、そして`min_abs`非常に大きな値にします。 追跡もする`neg_count`ゼロとして。 
2. 配列の各要素を反復処理します。 各要素について、その絶対値を次の値に加算します。`total_sum`。 アップデート`min_abs`絶対値が現在より小さい場合`min_abs`。 インクリメント`neg_count`要素が負の場合。 
3. すべての要素を処理した後、要素のパリティをチェックします。`neg_count`。 奇数の場合は2回引きます`min_abs`から`total_sum`避けられないマイナス要素を考慮して。 
4. 出力`total_sum`現在のテストケースの場合。 すべてのテスト ケースに対して繰り返します。 

これが機能する理由: 絶対値の合計は、すべての要素を正にできる場合に達成可能な最大値を表します。 演算ではペアで反転できるため、奇数の負の数のみがすべてを正にすることを防ぎます。 最小の絶対値を 2 回減算すると、影響が最小限の負の要素が 1 つ残ることになり、最大の合計が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_sum_after_flips():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total_sum = 0
        min_abs = float('inf')
        neg_count = 0

        for x in a:
            if x < 0:
                neg_count += 1
            abs_x = abs(x)
            total_sum += abs_x
            if abs_x < min_abs:
                min_abs = abs_x

        if neg_count % 2 == 1:
            total_sum -= 2 * min_abs

        print(total_sum)

if __name__ == "__main__":
    max_sum_after_flips()
```コードはアルゴリズムを直接反映しています。 私たちは計算します`total_sum`絶対値の合計として。`neg_count`負の要素の数を追跡し、`min_abs`最小の絶対値を見つけます。 小切手`neg_count % 2 == 1`1 つのマイナス要素を排除できない場合を確実に考慮します。 の使用`float('inf')`比較しても安全であり、`abs()`大きな整数を正しく処理します。

 ## 特殊なケース

 最初のエッジケースでは、$[-1, -1, -1]$、アルゴリズムは絶対値を 3 に合計し、3 つのマイナスを数え、2 × 1 → 1 を減算します。残りのマイナスは避けられません。 ゼロを含む 2 番目のエッジ ケースでは、アルゴリズムはゼロを非負として正しく処理し、最小の絶対値をゼロとして選択するため、合計の減少が回避されます。 どちらの場合も、アルゴリズムは正しい最大合計を生成します。
