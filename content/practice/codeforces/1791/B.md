 ## 解決策
 ## 問題の理解

 アルペレンは原点から始まる`(0,0)`2D グリッド上で。 彼には次のシーケンスが与えられます`n`移動するたびに、左、右、上、下の 4 つの基本的な方向のいずれかに 1 ユニット移動します。 キャンディーは固定位置にあります`(1,1)`、そして課題は、アルペレンが彼の動きを追跡している間にそのセルを通過するかどうかを判断することです。 入力は複数のテスト ケースで構成され、それぞれに移動数と移動シーケンスが含まれます。 少なくとも 1 回キャンディーに到達した場合、出力は「YES」、そうでない場合は「NO」です。 

制約は控えめです。`n`テストケースの数は最大50です`t`は最大 1000 です。これにより、すべてのテスト ケースのすべての動きをシミュレートするだけでも高速になるため、複雑な最適化の必要性が即座に排除されます。 エッジケースは、最初の動きでキャンディーにすぐに到達する場合、またはパスがループしているが接触しない場合に発生します。`(1,1)`。 たとえば、シーケンスが「LURD」の場合、Alperen は左に移動し、次に上に移動し、次に右に移動し、次に下に移動し、原点で終了します。 あらゆる方向に動いても、決して到達しない`(1,1)`、したがって、答えは「NO」です。 不用意に実装すると、最終位置のみをチェックしたり、方向シーケンスを誤解して間違った答えを返したりする可能性があります。 

## アプローチ

 Alperen のパスを段階的にシミュレートするという素朴なアプローチも最適です。 から開始`(0,0)`そして移動文字列を反復処理します。 移動するたびに、現在の座標を更新します。 更新のたびに、位置が一致しているかどうかを確認します`(1,1)`。 そうであれば、そのテスト ケースに対して直ちに「YES」と結論付けます。 到達せずにループが終了した場合`(1,1)`、「NO」を出力します。 

このアプローチが機能する理由は、`n`は非常に小さく、チェックは簡単です。 たとえば、到達可能なセルを事前計算したり、座標オフセットを使用したりしてさらに最適化しようとすると、不必要な複雑さが追加されます。 パスは固定されており決定的であるため、ソート、動的プログラミング、または BFS による利点はありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース / シミュレーション | テスト ケースあたり O(n) | お(1) | 承認済み |
 | 事前計算 / BFS | テスト ケースあたり O(n) | O(n) | 不要 |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、長さを読み取ります。`n`そして移動文字列`s`。 
3. Alperen の位置を初期化します。`(x, y) = (0, 0)`。 
4. 移動文字列内の各文字を繰り返します。 

1. キャラクターが`L`、デクリメント`x`1までに。 
2. キャラクターが`R`、増分`x`1までに。 
3. キャラクターが`U`、増分`y`1までに。 
4. キャラクターが`D`、デクリメント`y`1までに。 
5. 更新するたびに、次のことを確認します。`(x, y) == (1, 1)`。 true の場合、「YES」を出力し、このテスト ケースの処理を停止します。 
5. 訪問せずにループが終了した場合`(1,1)`、「いいえ」を出力します。 

なぜ機能するのか: アルゴリズムは次の不変条件を維持します。`(x, y)`グリッド上の Alperen の現在位置を常に反映します。 移動のたびにチェックすることで、最初の訪問が保証されます。`(1,1)`が検出されます。 移動は決定的であるため、セルがスキップされることはなく、誤検知は発生しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        x, y = 0, 0
        found = False
        for move in s:
            if move == 'L':
                x -= 1
            elif move == 'R':
                x += 1
            elif move == 'U':
                y += 1
            elif move == 'D':
                y -= 1
            if x == 1 and y == 1:
                found = True
                break
        print("YES" if found else "NO")

solve()
```このソリューションは入力を効率的に読み取り、Alperen の位置を追跡し、キャンディーに到達すると早期に終了します。 境界条件は正しく処理され、`strip()`末尾の改行が移動解析を妨げないようにします。 グリッドは正確な整数座標を使用するため、off-by-one エラーは不可能です。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

 ## 特殊なケース

 交差することなく 1 つの軸に沿って振動するパス`(1,1)`正しく処理されます。 例えば、`"LURD"`に戻り続けます`(0,0)`。 アルゴリズムは位置を順番に更新し、次の場合にのみ「YES」を出力します。`(1,1)`到達した場合、それ以外の場合は最後に「NO」を出力します。 単一移動パス、最初の移動でキャンディに到達するパス、および最大長パスはすべて正しくシミュレートされます。
