 ## 解決策
 ## 問題の理解

 配列があります`a[1..N]`感動のシーンを時系列に沿って解説。 この配列を正確に切り取る必要があります`K`空ではない連続部分。 パーツによって提供される値は、そのパーツ内の最大配列値であり、目的はそれらの合計を最大化することです。`K`最大値。 公式の制約は次のとおりです`1 <= K <= N <= 2000`そして`1 <= a[i] <= 1000`。 

最初のバウンド、`N <= 2000`、すべての DP 状態内のカット位置のすべてのペアを試すのはコストがかかりすぎるほど十分に大きいです。 標準パーティション DP には、`K * N`州、および各州には最大で`N`可能な以前のカット位置、`O(KN^2)`、約に達します`8 * 10^9`遷移するとき`N = K = 2000`。 これは 1 秒の制限がサポートできる範囲をはるかに超えています。 右端が移動するとセグメントの最大値が変化する特別な方法を利用する必要があります。 

不注意な実装を静かに破壊する可能性のある境界ケースがいくつかあります。 もし`K = 1`、セグメントは 1 つだけなので、答えは単純に配列全体の最大値になります。 例えば、`N = 2, K = 1, a = [3, 1]`与える`3`、 ない`4`、2 つのシーンは同じ幕に属しているためです。 

もし`K = N`、すべてのセグメントには要素が 1 つだけ含まれている必要があります。 例えば、`N = 3, K = 3, a = [2, 7, 4]`与える`13`。 DP が空のセグメントを誤って許可すると、無効な遷移とオーバーカウントが発生する可能性があります。 

等しい値にも注意が必要です。 のために`N = 4, K = 2, a = [5, 5, 1, 5]`、答えは`10`。 新しい値が現在のセグメントの最大値と等しい場合、最大値は変わらないため、対応する候補は 1 つの単調スタック グループとして扱うことができます。 スタック条件で間違った厳密性を使用すると、等しい最大値が不必要なグループに分割される可能性がありますが、最終的な値は、関連する候補状態が一貫して処理される場合にのみ正しいままになります。 

## アプローチ

 直接動的計画法による定式化は簡単です。 させて`dp[k][i]`最初の分割によって得られる最大の興奮であること`i`要素を正確に入力する`k`空ではない行為。 ポジションの直後に最後のアクトが始まる場合`j`、その場合、その貢献度は`max(a[j+1..i])`、 それで`dp[k][i] = max(dp[k-1][j] + max(a[j+1..i]))`全体的に有効`j`。 

すべての有効なパーティションには最後の動作の直前に一意の位置があるため、この繰り返しは正しいです。 その位置が決まったら、最初の`j`要素は最適なソリューションを形成します`k-1`最後の間隔が最大値に寄与する間、動作します。 

ブルートフォース実装により、移動中に最大値を維持できます`j`逆方向なので、各 DP 状態は`O(N)`すべての間隔の最大値を最初から再計算するのではなく、時間を計算します。 がある`O(KN)`状態、与える`O(KN^2)`総仕事量。 と`N = K = 2000`、これについてです`8 * 10^9`候補者の移行が遅すぎます。 

重要な観察点は、移行の高価な部分はそうではないということです。`dp[k-1][j]`。 それは変化する価値観です`max(a[j+1..i])`として`i`右に移動します。 

1 つの DP レイヤーを修正`k`そして、正しいエンドポイントを処理していると仮定します`i`。 あらゆる可能性のあるスタートのために`j`、候補を検討します`dp[k-1][j] + max(a[j+1..i])`。 

として`i`1 ずつ増加すると、これらの間隔の最大値はすべて変更されないか、新しい値になります。`a[i]`。 より具体的には、現在いくつかのスタートのセグメント最大値が以下の場合、`a[i]`、それらの開始値はすべて同じ新しい最大値を持つようになりました。`a[i]`。 それらは 1 つのグループに結合できます。 

単調なスタックはこれらのグループを自然に表します。 スタックには、減少するセグメントの最大値が格納されます。 それぞれの最大値とともに、最大の値も保存されます。`dp[k-1][j]`全員がそのグループに属し始めます。 グループが代表する最良の候補者は単純に次のようになります。`group_maximum + largest_previous_dp`。 

新しいとき`a[i]`到着、最大値が最大であるグループ`a[i]`ポップされてマージされます。 以来`a[i]`が以前の最大値と少なくとも同じくらい大きい場合、それらの候補値はマージ後に減少しません。 これにより、別の重要な簡略化が可能になります。つまり、グローバル最大値を維持するためにセグメント ツリーやヒープが必要ないということです。 古いグローバル最適値がポップされたグループに属していた場合、マージされたグループには同じ候補が含まれており、それが改善される可能性があります。 ポップされていないグループに属していた場合は、変更されないままになります。 したがって、現在の DP 状態の答えを単一のスカラーで維持できます。 

スタックは単調であり、すべてのグループは 1 つの DP レイヤー中に 1 回プッシュされ、多くても 1 回ポップされます。 したがって、1 つの DP 層には次の時間がかかります。`O(N)`を与える`O(KN)`アルゴリズム。

 ## アルゴリズムのチュートリアル

 1. 定義する`prev[i]`最初のパーティション分割の最良スコアとして`i`要素を前の行為の数に追加します。 最初は、アクションがゼロの場合のみ、`prev[0] = 0`有効です。 それ以外の状態はすべて不可能です。 
2. アクト数を処理します。`1`を通して`K`。 現在のレイヤーに対して、`cur`、 どこ`cur[i]`最終的には、最初のパーティション分割の最良のスコアを表します。`i`要素を現在のアクト数に追加します。 
3. 固定右端点の場合`i`、あらゆる可能な開始を検討してください`j`最終幕の。 その候補値は`prev[j] + max(a[j+1..i])`。 すべての候補を個別に保存する代わりに、現在の間隔の最大値が等しいグループが開始されます。 
4. 最大値が下から上に厳密に減少するスタックにグループを格納します。 各スタック エントリには最大値が含まれます`mx`そして最大の`prev[j]`そのグループが代表するすべてのスタートの中で。 そのグループの中で最も有力な候補者は`mx + best_prev`。 
5.加工時`a[i]`、新しい可能性のある最終幕の開始から始まります`j = i-1`。 その間隔は次のもののみで構成されます。`a[i]`、したがって、そのセグメントの最大値は`a[i]`そしてその基本値は`prev[i-1]`。 
6. 最大値が最大であるすべてのスタック グループをポップします。`a[i]`。 これらのグループのすべてのスタートは、`a[i]`新しい間隔の最大値として。 それらをマージします`best_prev`の値`prev[i-1]`、次に最大値を持つグループを 1 つ作成します。`a[i]`。 

条件は以下を使用します`<=`それよりも`<`なぜなら、等しい最大値はすべての候補に同じ効果をもたらすからです。 それらを組み合わせることで、可能な最適値を失うことなくスタックをコンパクトに保ちます。 
7. 新しく作成されたグループの最適な候補は次のとおりです。`a[i] + best_prev`。 ～のグローバルベストを更新`cur[i]`この値で。 ポップされなかったグループはまったく同じ候補値を保持するため、以前のグローバルベストが有効なままになります。 
8. 要求されたアクト数に対して十分な要素を持つエンドポイントのみが処理されます。 のために`k`動作する場合、最初に考えられるエンドポイントは`i = k`なぜなら、すべての行為には少なくとも 1 つの要素が含まれている必要があるからです。 レイヤーが完成したら置き換えます`prev`による`cur`。 
9. すべての処理が完了したら`K`レイヤー、`prev[N]`アレイ全体の可能な最大の興奮を正確に分割したものです。`K`行為する。 

不変条件は、計算の直前に`cur[i]`、あらゆる可能なスタート`j`最後の動作は、正確に 1 つのスタック グループによって表されます。 そのグループ内では、そのような開始はすべて同じ値を持ちます。`max(a[j+1..i])`したがって、最大のものだけを保持します`prev[j]`で十分です。 いつ`a[i]`正確に最大値を持つグループが追加されます`a[i]`変化し、それらはすべて同じ最大値に変化します`a[i]`これは、まさにポップアンドマージ操作が実行することです。 変更されていないグループはその候補を保存し、マージされたグループは吸収したすべての候補を保存または改善するため、維持されるグローバル最大値は正確に`cur[i]`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    neg = -10**18

    # prev[i] = best value for first i elements using the previous
    # number of acts.
    prev = [neg] * (n + 1)
    prev[0] = 0

    for acts in range(1, k + 1):
        cur = [neg] * (n + 1)

        # Each entry is [current maximum, best prev[j]]
        # for all starts j represented by this group.
        stack = []

        best = neg

        for i in range(acts, n + 1):
            x = a[i - 1]

            best_prev = prev[i - 1]

            while stack and stack[-1][0] <= x:
                _, group_best = stack.pop()
                if group_best > best_prev:
                    best_prev = group_best

            stack.append((x, best_prev))

            candidate = x + best_prev
            if candidate > best:
                best = candidate

            cur[i] = best

        prev = cur

    print(prev[n])

if __name__ == "__main__":
    solve()
```外側のループは、考えられるアクト数ごとに 1 つの DP レイヤーを構築します。`prev`に対する答えが含まれています`acts - 1`行動しながら、`cur`が満たされています`acts`行為する。 繰り返しは以前の行為数のみを参照するため、2 つのレイヤーのみを保持するだけで十分です。 

レイヤー内では、`stack`ペアを格納する`(maximum, best_previous_value)`。 2 番目の成分が最大値です`prev[j]`現在最初のコンポーネントをセグメント最大値として共有しているすべての開始位置にわたって。 これらのスタートに関するその他の情報はトランジションに影響を与えることはできません。 

ライン`while stack and stack[-1][0] <= x`最適化の中核です。 ポップされたすべてのグループの以前の最大値は以下です`x`したがって、右端点を現在の位置まで延長した後、その最大値は次のようになります。`x`。 最高です`prev[j]`したがって、新しいグループにマージできます。 

変数`best`現在のエンドポイントで確認されたすべてのグループの中で最大の候補を格納します。 グループをポップした後に再計算する必要はありません。 古い最適値がポップされていないグループにあった場合、それは変更されません。 ポップされたグループ内にあった場合、そのグループの候補は、マージされたグループ内の少なくとも同じ大きさの候補に置き換えられます。 

下限`i = acts`より少ない場合の不可能な状態を防止します`acts`要素は次のように分割されています`acts`空ではないセグメント。 Python の整数はオーバーフローせず、理論的な答えは最大でも`K * 1000 <= 2,000,000`。 

## 実用的な例

 サンプル 1 の場合、```
2 1
3 1
```アクトは 1 つだけであるため、DP 層はプレフィックス全体の最大値を見つける必要があります。 

|`i`|`a[i]`| 更新後のスタック |`best`|`cur[i]`|
 | --- | --- | --- | --- | --- |
 | 1 | 3 |`(3, 0)`| 3 | 3 |
 | 2 | 1 |`(3, 0), (1, -inf)`| 3 | 3 |

 で`i = 2`、新しい値`1`既存の最大値を置き換えません`3`、したがって最高の一幕物パーティションが残ります`3`。 出力は`3`。 

サンプル 2 の場合、```
2 2
3 100
```最初の DP 層は 1 つのアクトを表します。 その層の最後にある接頭辞の答えは次のとおりです。`3`そして`100`。 次に、2 番目の層では次のことのみが考慮されます。`i = 2`, なぜなら、2 つの行為には少なくとも 2 つの要素が必要だからです。 

|`i`|`a[i]`| 更新後のスタック |`best`|`cur[i]`|
 | --- | --- | --- | --- | --- |
 | 2 | 100 |`(100, 3)`| 103 | 103 |

 可能な唯一のパーティションは、`[3] | [100]`のスコアは`3 + 100 = 103`。 トレースはその理由も示しています`prev[i-1]`は、新しく開始された最終アクトの正しい基本値です。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 |`O(KN)`| 各 DP 層はすべてのエンドポイントを 1 回処理し、すべてのスタック エントリは最大 1 回プッシュおよびポップされます。 |
 | スペース |`O(N)`| 2 つの DP 配列と 1 つの単調スタックには、それぞれ最大で次のものが含まれます。`N + 1`エントリ。 |

 と`N <= 2000`そして`K <= 2000`、アルゴリズムは、約 400 万回のメイン DP 反復に加えて、レイヤーごとの線形数のスタック操作を実行します。 これは、意図した漸近要件内に問題なく適合しますが、以前のカット位置にわたる二次遷移は数十億回の操作に達します。

            stack.append((x, best_prev))

            candidate = x + best_prev
            if candidate > best:
                best = candidate

            cur[i] = best

        prev = cur

    return str(prev[n])

    return solution(inp).strip()

 ## 特殊なケース

 いつ`K = 1`の場合、アルゴリズムは 1 つの DP レイヤーのみを実行します。 入力用```
2 1
3 1
```最初の位置でグループが作成されます`(3, 0)`。 2番目の位置では、`1`よりも小さいです`3`したがって、別のグループが作成されますが、世界最高のグループは残ります。`3`。 最終的な答えは、`3`、配列全体の正確な最大値。 

いつ`K = N`、すべての行為には要素が 1 つだけ含まれている必要があります。 考慮する```
3 3
2 7 4
```最初の層は、最適な 1 幕のプレフィックス値を生成します。`2, 7, 7`。 2 番目の層は次から始まります`i = 2`、与える`2 + 7 = 9`、最終的には 2 つのアクトの正しいプレフィックス値に到達します。 3 番目のレイヤーは次の時点でのみ終了できます。`i = 3`、最後の単一要素の行為が貢献します。`4`、生産`2 + 7 + 4 = 13`。 

値が等しい場合は、スタック マージ ルールが適用されます。 のために```
4 2
5 5 1 5
```2番目のとき`5`到着すると、最大値を持つ既存のグループが到着します`5`最大値が新しい値と等しいため、ポップされます。 両方の開始点のセグメント最大値が同じになるため、それらをマージしても情報が失われることはありません。 この後、決勝戦`5`同様に、現在の最大値が最大であるすべてのグループをマージします。`5`。 最適なスコアは`10`。 

のようなケース```
4 2
1 10 2 9
```は、DP が複数の可能な開始位置を保持する必要がある理由を示しています。 最初の要素が与えられた後に切り取る`1 + 10 = 11`、3番目の要素が与えられた後にカットしながら`10 + 9 = 19`。 単調スタックは、正しいエンドポイントがどちらの方が優れているかを決定するまで、両方の可能性の候補を保持し、アルゴリズムが次の結果を返します。`19`。 

最大サイズの入力には次のものが含まれます`2000`要素と必要になる場合があります`2000`行為する。 すべての値が次と等しい場合`1000`、あらゆる行為が正確に貢献します`1000`、したがって、答えは次のとおりです`2,000,000`。 この反復性の高いケースでも、スタック操作は DP レイヤーごとに線形のままであり、必要な`O(KN)`走行時間。
