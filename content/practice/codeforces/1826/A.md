 ## 解決策
 ## 問題の理解

 私たちは人々のグループを与えられ、各人がグループ内の嘘つきの最小数について主張します。 人はそれぞれ、常に真実を言うか、常に嘘をつきます。 私たちの仕事は、これらの主張が一貫しているかどうかを判断し、一貫している場合は嘘つきの可能性がある人の数を特定することです。 クレームを調整できない場合は、-1 を返す必要があります。 

入力は複数のテスト ケースで構成されます。 テストケースごとに人数を受け取ります`n`そして配列`n`整数`l_i`、 どこ`l_i`人による嘘つきの最小数です`i`。 各テスト ケースの出力は、有効な嘘つきの数、または主張が矛盾している場合は -1 になります。 

制約は控えめです。`n`最大 100 まで可能で、すべてのテスト ケースの合計人数は最大 10,000 人です。 これにより、テスト ケースごとに O(n log n) または O(n²) のアルゴリズムが可能になります。 高度に最適化されたソリューションやサブリニアなソリューションを考慮する必要はありません。 

明らかではないエッジケースには、全員が嘘つきがゼロであると主張する状況、全員が嘘つきの最大数を主張する状況、または狭い範囲の嘘つき数のみを可能にする値の周囲に主張が集中している状況が含まれます。 たとえば、3人がこう言ったとします。`[2, 2, 2]`の場合、嘘つきは 1 人だけということはあり得ず、すべての主張を満たす構成は存在しません。 不用意に実装すると、すべての制約をチェックせずに数値を返し、間違った答えが生成される可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、0 から 0 までの可能な限りの数の嘘つきを試します。`n`そして、主張が満たされているかどうかを確認します。 嘘つき候補数について`k`、少なくともそれを確認します`k`人々は少なくとも主張する`k`嘘つきたち。 これが機能するのは、正直な人は実際の嘘つきの数と一致していなければならないが、嘘つきの主張は無関係であるためです。 検証ステップでは配列をスキャンする必要があるため、テスト ケースあたりの複雑さは O(n²) になります。 これは許容されます`n`最大 100 ですが非効率的です。 

重要な洞察は、すべての数値を恣意的にテストする必要はないということです。 主張の配列を並べ替えて、主張が嘘つき候補の数以下である人の数が予想される数と一致する最小のインデックスを見つけることができます。 もっと具体的に整理すると、`l_i`、次に、嘘つきの考えられる数ごとに、`x`、少なくとも主張している人の数`x`嘘つきは少なくともそうあるべきだ`x`。 これが当てはまれば、`x`は有効な答えです。 これにより、並べ替えにより問題が O(n log n) に軽減され、制約を考慮すると十分な速度になります。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そしてクレームの配列`l`。 
3. 配列をソートする`l`降順ではない順に。 並べ替えると、主張と潜在的な嘘つきの数が一致するため、チェックが簡素化されます。 
4. 結果を -1 として初期化します (矛盾を想定)。
 5. 嘘つきの可能性のある数をループする`x`0から`n`:

 1. 以上の請求をしている人が何人いるかを数えます。`x`。 並べ替えるとこうなります`n - i`、 どこ`i`は最初のインデックスです`l[i] >= x`。 
2. もし`x`このカウントと等しい場合、結果を次のように設定します`x`そして休憩する。 これは、一貫した構成を正確に表しています。`x`人々は嘘つきで、残りは真実を言います。 
6. このテスト ケースの結果を印刷します。 

正しさは、多くの嘘つきにとって不変条件から来ます。`x`、 その通り`x`嘘つきや真実を語る人は、その主張を納得させなければなりません。 並べ替えにより、候補者にとって真実であると考えられる主張の数を効率的に見つけることができます。`x`。 候補数がそれをサポートするクレームの数と等しい場合にのみ、一貫した構成が存在します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    l = list(map(int, input().split()))
    l.sort()
    result = -1
    for x in range(n + 1):
        # number of people claiming at least x liars
        count = sum(1 for val in l if val >= x)
        if count == x:
            result = x
            break
    print(result)
```このソリューションは高速 I/O を使用して入力を読み取り、最大 10,000 人を効率的に処理します。 配列をソートすると、カウントするクレームを整列させることができます。 このループは、考えられる嘘つきの数をそれぞれチェックし、それを裏付ける主張の数を計算します。 最初の有効なカウントが返されるか、存在しない場合は -1 が返されます。
