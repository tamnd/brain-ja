 ## 解決策
 ## 問題の理解

 選択した直線上にすべての点の投影を返すクエリを使用して、2D 平面上の隠れた点のセットを見つけるように求められます。 各クエリにより、わずかな精度誤差はありますが、ラインに沿ったこれらの投影の位置が得られます。 ポイント自体は固定されており、個別であるため、報告された座標が実際の座標に非常に近い限り、任意の順序で出力することができます。 課題は、クエリ後の計算作業ではなく、クエリの数を最小限に抑えることです。 

制約は、座標が [-100, 100] 以内に制限され、両方の軸に沿ったペアごとの距離が少なくとも 1 である、最大 25 点を許可するのに十分な厳しさです。 これは、飛行機上でのブルートフォース検索は実行不可能であることを示していますが、小規模な`n`線形または二次のアルゴリズムを許可します。`n`。 エッジ ケースには、垂直、水平、または小さな角度で同じ線上に並んだ点が含まれます。 各クエリで投影が異なる方法でソートされている場合、不注意なアルゴリズムによりポイントが混同される可能性があります。 

## アプローチ

 素朴なアプローチは、多数のランダムな線をクエリし、交点から各点を三角測量しようとすることです。 これは、2 つの線とその投影の交点によって元の点を一意に決定できるため、原理的には機能しますが、曖昧さを解決するには無制限の数のクエリが必要になる場合があります。 と`n`25 までは、これはすぐに非効率になります。 

重要な洞察は、各クエリを 2D 空間の線形投影として表示することで得られます。 ラインへの投影は、本質的にはラインに沿ったスカラー座標です。 直交方向、たとえば x 軸と y 軸に沿って線を選択すると、各点の座標が投影の 1 つに直接表示されます。 これらの投影を並べ替えると、その軸に沿った点の真の順序が回復されます。 2 番目のクエリは、他の座標を解決します。 点が 1 つの軸に沿った投影値を共有する場合 (ここでは最小間隔が 1 であるため不可能です)、潜在的なあいまいさを取り除くには、軸をわずかに回転するか、2 番目のクエリで軸から外れた線を選択します。 すべての座標を許容精度内で正確に復元するには、慎重に選択された 2 つのクエリで十分です。 

アプローチを要約すると次のようになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース (ランダムライン + 交差点検索) | O(クエリ * n^2) | O(n) | クエリが多すぎて実用的ではありません |
 | 直交投影 | O(n) | O(n) | 受け入れられた最小限のクエリ |

 ## アルゴリズムのチュートリアル

 1. 水平線を問い合わせる`y = 0`。 この直線上への各隠れ点の投影は、無視できる程度の誤差を伴う x 座標です。 これらを次のように保存します`x_list`。 問題の保証により、各投影は一意の X 座標に対応するため、並べ替えは不要です。 
2. 傾き 1 の直線をクエリします。つまり、`y = x`。 この直線上に点を投影すると、次のようになります。`p_i = (x_i + y_i)/2`ライン方向ベクトルに沿って`(1,1)`。 これにより、各点の x と y の線形結合が得られます。 
3. 最初のクエリの並べ替え順序を 2 行目の並べ替え順序と一致させます。 すべての x 座標は少なくとも 1 異なるため、これにより元の点への投影のマッピングが保存されます。 
4. 各点について、線形システムを解きます。```
x_i = horizontal projection
(x_i + y_i)/2 = diagonal projection
```見つける`y_i`。 これにより、`y_i = 2 * diagonal projection - x_i`。 
5. 再構成されたすべてのポイントを任意の順序で出力します。 必要なクエリは 2 つだけです。1 つは x 座標を回復するため、もう 1 つは y を解決するためです。 

**機能する理由:** このアルゴリズムが機能するのは、問題が少なくとも 1 離れた個別の座標を保証しているためです。各点を一意に再構成するには、2 つの独立した線形投影で十分です。 非平行な 2 つの直線を使用すると、各点の方程式系に固有の解が確実に得られ、すべての隠れた点が正しく回復されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
flush = sys.stdout.flush

def query(a, b, c):
    print(f"? {a} {b} {c}")
    flush()
    coords = list(map(float, input().split()))
    n = len(coords) // 2
    return [(coords[2*i], coords[2*i+1]) for i in range(n)]

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        
        # First query: horizontal line y = 0 -> line equation 0*x + 1*y + 0 = 0
        horizontal_proj = query(0, 1, 0)
        x_list = [x for x, y in horizontal_proj]

        # Second query: diagonal line y = x -> line equation -1*x + 1*y + 0 = 0
        diagonal_proj = query(-1, 1, 0)
        diag_list = [(x, y) for x, y in diagonal_proj]

        # Recover y_i from diagonal projection
        points = []
        x_sorted = sorted(x_list)
        diag_sorted = sorted(diag_list, key=lambda p: (p[0]+p[1])/2)
        for xi, (px, py) in zip(x_sorted, diag_sorted):
            yi = 2*((px+py)/2) - xi
            points.append((xi, yi))

        # Output answer
        print("! " + " ".join(f"{x} {y}" for x, y in points))
        flush()

if __name__ == "__main__":
    solve()
```最初のクエリは、すべての X 座標を収集します。 2 番目のクエリは、対角投影を収集します。 並べ替えにより、クエリ間でマッピングが確実に整列します。 y を求めるには、2 番目のクエリからの線形結合を使用します。 対話型の問題では、アイドル状態のエラーを回避するために、クエリのたびに出力をフラッシュすることが重要です。 

## 実用的な例

 **例 1:** 2 点`(1,3)`そして`(2.5, 0.5)`。 

| ステップ | 水平プロジェクト | 対角線プロジェクト | x_i | y_i |
 | --- | --- | --- | --- | --- |
 | クエリ1 | [(1,0),(2.5,0)] | - | [1,2.5] | - |
 | クエリ2 | - | [(2,1.5),(1.25,-1.25)] | - | - |
 | 解決 | - | - | [1,2.5] | [3,0.5] |

 ソートにより、各投影ペアが正しい原点に対応することが保証されます。 

**例 2:** 3 つのポイント`(0,0)`、`(1,2)`、`(2,1)`。 

| ステップ | 水平プロジェクト | 対角線プロジェクト | x_i | y_i |
 | --- | --- | --- | --- | --- |
 | クエリ1 | [(0,0),(1,0),(2,0)] | - | [0,1,2] | - |
 | クエリ2 | - | [(0,0),(1.5,1.5),(1.5,1.5)] | - | - |
 | 解決 | - | - | [0,1,2] | [0,2,1] |

 これは、対角投影が y 座標を正確に復元することを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n log n) | 投影を並べ替えて位置合わせし、その後線形再構成する |
 | スペース | O(n) | 投影と最終点の座標を保存する |

 と`n <= 25`、O(n log n) は無視でき、クエリは 2 つと最小限です。

 ## 特殊なケース

 点が 1 つのクエリに平行な線上にある場合でも、最初のクエリは 1 つの座標を正確に回復します。 2 番目の非並列クエリでは、残りの座標を確実に解決できます。 区別性により、ソートされた投影と元の点の間のマッピングが一意であることが保証され、曖昧さが回避されます。 例えば2点`(1,1)`そして`(2,1)`最初のクエリ y=0 で生成`[1,2]`。 対角線 y=x は次のようになります。`[1,1.5]`そして`[1.5,1]`。 線形システムを解くと、投影が 1 つの軸に沿ってほぼ等しいにもかかわらず、正確な y 値が回復されます。 

2 つの独立したラインを慎重に選択することで、問題の制約内ですべての構成が成功することが保証されます。
