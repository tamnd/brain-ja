 ## 問題の理解

重要な問題は、私たちには何も与えられないということです$x$直接、または完全な除数セットさえも。 内部除数のみが表示されます。これはペアリングで閉じる必要があります。$d \mid x$、 それから$\frac{x}{d} \mid x$1 または 2 でない限り、両方ともリストに表示されます。$x$。 

制約は小さいです。$n \le 300$クエリごとに、$t \le 25$。 これにより、高度な最適化や高度なデータ構造の必要性が排除されます。 ソート、ペアごとのチェック、さらには$O(n^2)$心配することなく候補者ごとに検証できます。 

対称性から微妙な問題が生じます。 単純な試みでは、最小値と最大値を乗算すると次のようになると仮定する可能性があります。$x$。 除数構造が矛盾しているか不完全である場合、これは失敗します。 もう 1 つの失敗ケースは、重複または相補的な除数の欠落により、予期されたペアが壊れる場合です。

## アプローチ

 強引なアイデアは、考えられるすべての候補を試してみることです。$x$。 与えられたすべての数値は除算する必要があるため、$x$、自然な上限$x$リスト内の最小要素と最大要素の積、またはそれらの LCM 構造の積です。 素朴な戦略は、次の条件まですべての候補者を列挙することです。$10^6$1 と 1 を削除した後、除数セットが入力と一致するかどうかを確認します。$x$。 各候補の約数を生成するにはコストがかかるため、これはすぐに実行不可能になります。$O(\sqrt{x})$、多くの候補にわたって繰り返されると、最悪の場合のコストが制限をはるかに超えてしまいます。 

重要な観察は、次の完全な約数セットが$x$ペアで構成する必要があります$(d, x/d)$。 端点を除くすべての約数が与えられているので、再構成できます。$x$最小要素と最大要素をペアにして一貫性をチェックします。 リストが正しい場合、最小の約数は最大の約数とペアになり、2 番目に小さい約数は 2 番目に大きい約数とペアになり、すべて同じ積が生成されます。$x$。 

これにより、問題は 1 つの候補値の並べ替えと検証に減ります。

 ## アルゴリズムのチュートリアル

 1. 指定された約数リストを並べ替えます。 最小値と最大値を確実に一致させるには、並べ替えが必要です。 
2. 候補値を計算する$x$最小要素と最大要素の積として。 
3. インデックスごとに$i$、それを確認してください$d[i] \cdot d[n-1-i] = x$。 
4. いずれかのペアがこの条件を満たさない場合、リストは有効な数値から取得できないため、-1 が出力されます。 
5. すべてのペアが一致する場合、出力$x$。 

ペアリング チェックが中心的な制約です。以下のすべての約数です。$\sqrt{x}$上記の一意の補数に対応する必要があります$\sqrt{x}$、その積は次と等しくなければなりません$x$。 

### なぜ効果があるのか

 任意の整数の約数セットは、乗算に関して対称です。$x$。 並べ替えると、この対称性が鏡映された位置として明らかになります。 入力が正しい場合、最小の要素はそれぞれ最大の要素と一意にペアになり、同じ積を生成する必要があります。$x$。 逸脱があると、除数閉包プロパティが壊れます。つまり、整数はリストを生成できません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        d = list(map(int, input().split()))
        d.sort()

        x = d[0] * d[-1]

        ok = True
        for i in range(n // 2):
            if d[i] * d[n - 1 - i] != x:
                ok = False
                break

        if ok:
            print(x)
        else:
            print(-1)

if __name__ == "__main__":
    solve()
```この解決策は、補数が対称的に揃うように除数リストをソートすることから始まります。 候補者$x$有効な約数セットは次の条件を満たす必要があるため、最も外側のペアから導出されます。$d_1 \cdot d_k = x$。 

次に、ループはすべてのミラーリングされたペアの不変式を検証します。 早期終了により、不一致が検出された後の不必要な計算が防止されます。 

よくある落とし穴は、最初と最後のペアだけでなく、すべてのペアが同じ製品を生成する必要があることを忘れていることです。 もう 1 つは、すべてのペアにわたる一貫性をチェックせずに、因数分解の一意性を仮定することです。

 ## 特殊なケース

 厄介なエッジ ケースは、すべての約数のペア構造が等しいにもかかわらず、グローバルな一貫性が失われる場合です。 例えば：```
3
2 3 4
```並べ替えると得られるもの`2, 3, 4`、プロデュース候補者$x = 8$。 ペアリング チェックはすぐに失敗します。$3 \cdot 3 \neq 8$。 アルゴリズムはそれを正しく拒否します。 

別のケースは最小限の入力です。```
1
k
```ここでアルゴリズムが扱うのは、$x = k^2$、唯一の除数がそれ自体とペアになる必要があるためです。 これは、リストから 1 と 1 を除外するという要件に一致します。$x$、縮退した場合には単一の内約数が残ります。
