 ## 問題の理解

 電子メール アドレスを表す文字列が与えられていますが、`.`記号は次のように綴られています`dot`そしてすべての`@`としての記号`at`。 私たちの目標は、元の有効な電子メール アドレスを最短の形式で再構築することです。 同じ長さの候補が複数ある場合は、辞書順に最小のものを選択します。 

入力文字列には小文字のみが含まれており、部分文字列の各インスタンスは`dot`または`at`実際のに対応します`.`または`@`メールで。 有効な電子メールには 1 つだけが含まれている必要があります`@`、複数を含めることができます`.`記号で始まり、で終わることはできません`.`または`@`。 

制約は寛大で、文字列の長さは最大 100 文字です。 これにより、パフォーマンスの限界に達することなく、文字列長の二次時間による解を検討できるようになります。 留意すべきエッジケースには、次のようなシーケンスが含まれます。`dot`そして`at`連続して出現するか、他の文字と重なる場所に出現します。例:`dota`次のように解析できます`d.o.a`または`do.ta`。 部分文字列を左から右に貪欲に置き換える単純なアプローチでは、無効な電子メールが生成される可能性があります。`dot`言葉の中に入れるべきでないところに。 たとえば、入力`dotdotatdot`結果は次のとおりになるはずです`. . @ .`正しく解析されていない`.d.o.t.a.t.`。 

## アプローチ

重要な観察は、位置がわかれば、それぞれの置換は局所的で決定的であるということです。`at`有効な電子メールには 1 つだけシンボルを含めることができるため、`@`。 これにより、問題は動的プログラミングの演習に変わります。文字列を左から右にスキャンし、考えられる数ごとに、その時点までの最短の有効な電子メール再構築を維持します。`@`使用される記号。 一つだけなので`@`が許可されている場合、状態空間は小さいです。 各位置で、単一の文字を使用することも、部分文字列を使用することもできます。`dot`として`.`、または部分文字列を消費します`at`として`@`まだ使用していない場合。 常に最も短い再構成​​文字列を選択し、複数の候補が同じ長さの場合は、辞書編集的に最も小さい文字列を選択します。

 ## アルゴリズムのチュートリアル

 1. 空の結果文字列を初期化します。 すでに配置されているかどうかを示すブール値フラグを追跡します`@`。 
2. インデックスを使用して入力文字列を反復処理します。`i`。 
3. 各インデックスで、まず部分文字列が`at`ここから始まり、`@`使用されていません。 その場合は追加してください`@`結果にマークを付ける`@`使用されているとおり、次の文字をスキップします`at`は2文字です。 
4. それ以外の場合は、部分文字列が`dot`ここから始まります。 その場合は追加します`.`結果に移動し、次の 2 文字をスキップします。 
5. どちらでもない場合`at`または`dot`適用される場合は、現在の文字をそのまま追加します。 
6. 文字列の終わりまで続けます。 
7. 再構築された文字列を返します。 

機能する理由: アルゴリズムにより、正確に 1 つの`@`2 回目の置換を許可しないため、配置されます。 いつも減ります`dot`シングルに`.`そして文字はそのまま残しておきます。 チェックすることで`at`前に`dot`の最初の文字が誤って置換されるのを防ぎます。`at`そうしないと、スタンドアロンのキャラクターまたはキャラクターの一部として誤解される可能性があります。`dot`。 各ステップで常に最長の有効な部分文字列を消費するため (`at`前にチェックされています`dot`)、出力は長さが最小であり、同じ長さの候補の中で辞書編集的に最小になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s = input().strip()
res = []
used_at = False
i = 0
while i < len(s):
    if not used_at and s[i:i+2] == 'at':
        res.append('@')
        used_at = True
        i += 2
    elif s[i:i+3] == 'dot':
        res.append('.')
        i += 3
    else:
        res.append(s[i])
        i += 1

print(''.join(res))
```コードはアルゴリズムを直接反映しています。 旗`used_at`正確に 1 つを配置することを保証します`@`。 チェックします`at`前に`dot`ケースを処理するために`at`の一部かもしれない`dot`部分文字列（のような`dotat`）。 インデックスの増分は消費された文字をスキップし、二重カウントを防ぎます。 文字列はリストを使用して効率的に再構築され、二次時間連結が回避されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    s = input().strip()
    res = []
    used_at = False
    i = 0
    while i < len(s):
        if not used_at and s[i:i+2] == 'at':
            res.append('@')
            used_at = True
            i += 2
        elif s[i:i+3] == 'dot':
            res.append('.')
            i += 3
        else:
            res.append(s[i])
            i += 1
    return ''.join(res)
