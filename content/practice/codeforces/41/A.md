 ## 解決策
 ## 問題の理解

 2 つの小文字の文字列が与えられます。 最初の文字列は、ある言語の単語であり、2 番目の文字列は、すべての単語が逆から書かれた別の言語への翻訳であると考えられます。 

タスクは、2 番目の文字列が最初の文字列の逆であるかどうかを確認するだけです。 その場合は印刷します`YES`。 それ以外の場合は印刷します`NO`。 

各文字列の最大長は 100 文字のみです。 このように制限が小さいと、非効率なアプローチでも制限時間内で問題なく実行できます。 文字列を 1 回スキャンするだけのソリューションで十分です。 高度なデータ構造や最適化のテクニックは必要ありません。 

この問題の主な危険はパフォーマンスではなく、正確さです。 不用意に実装すると、誤って無効なケースを受け入れる可能性があります。 

簡単な間違いの 1 つは、完全に反転した文字列を比較するのを忘れることです。 例えば：```
abc
ab
```正しい出力は次のとおりです。```
NO
```2 番目の文字列は短いため、最初の文字列を逆にすることはできません。 1 つの文字列が終了するまで一致する位置を比較するだけの実装では、このケースが誤って受け入れられます。 

もう 1 つのよくある間違いは、同じ方向の文字を比較して間違って反転してしまうことです。 考慮する：```
abc
cba
```正しい出力は次のとおりです。```
YES
```比較してみると`s[i]`と`t[i]`代わりに直接`t[n - 1 - i]`の場合、有効な翻訳は拒否されます。 

最後のエッジ ケースは単一文字の文字列です。```
a
a
```正しい出力は次のとおりです。```
YES
```1 文字の文字列はそれ自体を反転したものと等しいため、答えは依然として受け入れられる必要があります。 

## アプローチ

 この強引なアイデアは、最初の文字列の反転バージョンを手動で構築することです。 の最後の文字から反復できます。`s`最初の文字列に追加し、各文字を新しい文字列に追加します。 反転した文字列を構築した後、それを次と比較します。`t`。 

これが機能するのは、反転した単語が一意に定義されているためです。 すべての文字が逆の順序で表示される場合、翻訳は正しいです。 

このアプローチの欠点は、文字列が不変である言語では、文字列の連結を繰り返すと非効率になる可能性があることです。 追加するたびに新しい文字列が作成される可能性があり、最悪の場合、二次的な動作が発生する可能性があります。 最大長が 100 のみなので、これでも簡単に合格しますが、最もクリーンな実装ではありません。 

重要な観察は、問題がすでに組み込み操作に直接一致していることです。 逆を手動で再構築する代わりに、1 ステップで文字列を逆にして、結果をすぐに比較できます。 

Pythonでは、`s[::-1]`反転した文字列を作成します。 計算すると、問題は単一の等価性チェックに減ります。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 承認済み |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最初の文字列を読み取ります`s`。 
2. 2 番目の文字列を読み取ります`t`。 
3. リバース`s`スライスを使って。 
4. 反転した文字列を次と比較します。`t`。 
5. それらが等しい場合、出力します。`YES`。 それ以外の場合は、印刷します`NO`。 

逆順にするとすべての文字が保持され、順序のみが変更されるため、比較は機能します。 2 つの文字列は、翻訳が正しく実行された場合にのみ正確に一致します。 

### なぜ効果があるのか

 このアルゴリズムは、翻訳の定義プロパティを直接チェックします。 有効な翻訳された単語には、元の単語とまったく同じ文字が逆の順序で含まれている必要があります。 

もし`reverse(s) == t`、すべての位置が必要な反転文字と一致するため、翻訳は正しくなります。 

1 文字でも異なる場合、または長さが異なる場合、等価性チェックは自動的に失敗するため、翻訳は無効になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s = input().strip()
t = input().strip()

if s[::-1] == t:
    print("YES")
else:
    print("NO")
```プログラムは、標準入力から両方の文字列を読み取ることから始まります。 使用する`.strip()`入力の読み取りによって生成された末尾の改行文字を削除します。 

表現`s[::-1]`文字列の逆コピーを作成します。 Python のスライスは反転を内部で処理するため、手動ループは必要ありません。 

等価性チェックでは、長さと文字順序の両方が自動的に比較されます。 これにより、部分一致が誤って通過する可能性がある微妙なバグが回避されます。 

問題自体は基本的に単純であるため、実装は短くなります。 主な考え方は、文字列を反転することがまさに必要な操作であることを認識することです。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | 両方を反転して比較すると、文字列が 1 回スキャンされます。 
| スペース | O(n) | 反転された文字列は一時的に保存されます。 

文字列の最大長はわずか 100 であるため、このソリューションは時間とメモリの制限内に簡単に収まります。 

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    import sys
    input = sys.stdin.readline

    s = input().strip()
    t = input().strip()

    if s[::-1] == t:
        print("YES")
    else:
        print("NO")

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output.strip()

# provided sample
assert run("code\nedoc\n") == "YES", "sample 1"

# minimum-size input
assert run("a\na\n") == "YES", "single character"

# different lengths
assert run("abc\nab\n") == "NO", "length mismatch"

# same letters but wrong order
assert run("abcd\nabdc\n") == "NO", "incorrect reversal"

# maximum-size style case
s = "a" * 100
t = "a" * 100
assert run(f"{s}\n{t}\n") == "YES", "maximum equal strings"

# palindrome
assert run("level\nlevel\n") == "YES", "palindrome case"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`a / a`|`YES`| 最小サイズの入力 |
 |`abc / ab`|`NO`| 長さの不一致の処理 |
 |`abcd / abdc`|`NO`| 文字の順序が正しくありません |
 | 100`'a'`キャラクター |`YES`| 許可される最大長 |
 |`level / level`|`YES`| 回文は反転しても変化しません。 

## 特殊なケース

 文字列の長さが異なる場合を考えてみましょう。```
abc
ab
```アルゴリズムは以下を計算します。```
reverse("abc") = "cba"
```それから比較します`"cba"`と`"ab"`。 

文字列が異なるため、出力は次のようになります。```
NO
```これにより、アルゴリズムが誤って部分一致を受け入れないことが確認されます。 

ここで回文を考えてみましょう。```
level
level
```アルゴリズムは以下を計算します。```
reverse("level") = "level"
```反転された文字列は元の文字列と同一であるため、比較は成功し、出力は次のようになります。```
YES
```これにより、文字列自体の反転に等しい文字列が正しく処理されることが検証されます。 

最後に、文字は一致するが順序が一致しない場合を考えてみましょう。```
abcd
abdc
```アルゴリズムは以下を計算します。```
reverse("abcd") = "dcba"
```比較する`"dcba"`と`"abdc"`すぐに失敗し、以下が生成されます。```
NO
```これは、ソリューションが文字セットだけでなく、正確に逆の順序をチェックしていることを示しています。
