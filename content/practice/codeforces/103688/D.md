## Python ソリューション```python
import sys
input = sys.stdin.readline

def dot(ax, ay, bx, by):
    return ax * bx + ay * by

def solve():
    t = int(input())
    for _ in range(t):
        x1, y1, x2, y2, x3, y3 = map(int, input().split())

        # shift so O2 is origin
        a1x, a1y = x1 - x2, y1 - y2
        a3x, a3y = x3 - x2, y3 - y2

        # collinearity check between O1, O2, O3
        # if all three lie on a line through O2, configuration is degenerate
        cross = a1x * a3y - a1y * a3x

        if cross == 0:
            print("no")
        else:
            print("yes")

if __name__ == "__main__":
    solve()

唯一の実際の構造的欠陥のケースは次のような場合です。$O_1$、$O_2$、 そして$O_3$同一線上にあります。 その場合、最初の衝突を正常にトリガーする方向はすべて拘束されます。$O_2$到達するように調整できない線に沿って移動する$O_3$接線拘束に違反せず、利用可能な角度の自由度を崩壊させません。 外積はこの縮退を正確に検出します。
