 ## 問題の理解

 インデックスのペアごとに整数の配列が与えられます。$i < j$、非常に特殊な方法で素指数さえも取り除いた後、2 つの数値の積から派生値を計算します。 単一の数値の場合、それを素因数分解し、各素数の指数を調べます。 指数のパリティのみが重要です。素数が奇数回出現する場合、それはその素数の 1 つのコピーに寄与します。 偶数回出現すると完全に消えます。 機能$f(x)$は、指数が次のとおりであるすべての素数の積です。$x$は奇数なので、次の Squarefree カーネルです$x$。 

各ペアごとに$(b_i, b_j)$、計算します$f(b_i \cdot b_j)$、そしてこれをすべてのペアにわたって合計します。 

制約が十分に厳しいため、$O(n^2)$ペアごとの計算は不可能であるため、$n$まで可能です$2 \cdot 10^5$。 平$O(n \sqrt{A})$ペアごとでは遅すぎるでしょう。 問題を、配列の最大値における線形またはほぼ線形に近づける必要があります。$2 \cdot 10^5$。 

重要なエッジケースは、次のことを理解することから生まれます。$f(x)$元の多重度ではなく、指数のパリティのみに依存します。 例えば、$x = 12 = 2^2 \cdot 3$与える$f(x) = 3$、 その間$x = 18 = 2 \cdot 3^2$与える$f(x) = 2$。 パリティなしで素数セットのみを追跡する単純なアプローチでは、指数が偶数の場合に誤った結果が生成されます。 

もう一つの微妙なケースは、$f(b_i b_j)$単純ではありません$f(b_i) f(b_j)$共有素数は、結合された指数が偶数になると相殺されるためです。 たとえば、両方の数値が同じ素数に寄与する場合、その素数は結果から消えます。 

## アプローチ

 ブルートフォース手法は簡単です。すべての数値を因数分解して計算します。$f(b_i b_j)$すべてのペアについて計算し、結果を合計します。 これは定義に直接従うため、正しいです。 ただし、ペアごとに素因数分解をマージする必要があり、ペアごとに少なくとも対数または因数分解の時間がかかります。 と$O(n^2)$ペアの場合、これは実現可能な限界をはるかに超えます。 

重要な構造観察は次のとおりです。$f(x)$各素数指数が奇数か偶数かによってのみ決まります。 したがって、各数値は正方形のフリー カーネルに還元できます。$a_i$、各素数は最大 1 回出現します。 次に、2 つの数字について$a_i$そして$a_j$、 結果$f(a_i a_j)$素数ごとのパリティ XOR によって決定されます。 これにより相互作用が単純化されます。素数は独立して動作し、重複によってキャンセルが発生します。 

次に、式を代数的に再解釈します。 させて$a_i$～のスクエアフリーカーネルになる$b_i$。 それを示すことができます$$f(a_i a_j) = \frac{a_i \cdot a_j}{\gcd(a_i, a_j)^2}.$$これにより、問題はすべてのペアにわたる対称算術関数の合計に変換されます。 

残りの課題は、明示的に反復することなく、すべてのペアに対してこの関数を効率的に合計することです。 これは、gcd 構造上のメビウス反転を使用して処理されます。 gcd 制約を書き換えて、ペアごとの合計を約数に対する寄与に変換します。 これにより、各値の計算の問題が軽減されます。$k$、で割り切れる数値の寄与を集計したもの$k$、のみに依存する事前計算された算術係数と組み合わせます。$k$。 

問題が除数空間で表現されると、必要なすべての量は、除数に対する標準的なふるい形式の累積を使用して計算できます。

 ## アルゴリズムのチュートリアル

 ### ステップ 1: 各数値を平方フリー カーネルに換算します。 

すべての入力値に対して$b_i$、因数分解し、奇数の指数を持つ素数だけを保持します。 結果の値$a_i$正方形はなく、まだ境界があります$2 \cdot 10^5$。 このステップでは、各素数が最大 1 回出現する数値を扱うように問題を圧縮します。 

### ステップ 2: gcd を使用してペアの寄与を表現する

 2 つの値の場合$a_i$そして$a_j$、関数を次のように書き換えます$$f(a_i a_j) = \frac{a_i a_j}{\gcd(a_i, a_j)^2}.$$この再定式化により、2 つの数値間の相互作用が gcd 項内で完全に分離されます。 

### ステップ 3: 合計を gcd 分解に変換する

 私たちが欲しいのは$$\sum_{i<j} \frac{a_i a_j}{\gcd(a_i,a_j)^2}.$$まず、以下を含むすべてのペアにわたる完全な順序の合計を考慮します。$i=j$、後で調整します。 

gcd 値を修正する$d$。 書く：$$a_i = d x, \quad a_j = d y, \quad \gcd(x,y)=1.$$貢献度は、$x y$。 これにより gcd は完全に削除されますが、共素条件が導入されます。 

### ステップ 4: メビウス反転を使用して共素性を除去する

 条件を交換します$\gcd(x,y)=1$使用:$$[\gcd(x,y)=1] = \sum_{t \mid \gcd(x,y)} \mu(t).$$合計を交換すると、問題は割り算条件によってグループ化された寄与に変わります。 用語を再編成すると、すべては以下にのみ依存する式にまとめられます。 

-$S_k$: すべての合計$a_i$そのような$k \mid a_i$- に依存する純粋な算術要素$k$### ステップ 5: 除数の集計を計算する

 それぞれについて$k$、次を計算します。$$S_k = \sum_{i : k \mid a_i} a_i.$$これは、それぞれを反復することで実行できます。$a_i$そしてその値をすべての約数に分配します。 

### ステップ 6: 算術重みを事前計算する

 定義:$$g(k) = \sum_{t \mid k} \mu(t) \cdot t^2.$$これは、すべてを反復することで計算できます。$t$の倍数に貢献を追加します$t$。 

### ステップ 7: すべてを組み合わせる

 注文した合計は次のようになります。$$\sum_k \frac{S_k^2}{k^2} g(k).$$最後に、順序付きペアを順序なしペアに変換します。$$\text{answer} = \frac{\text{ordered sum} - n}{2}.$$減算により削除されるのは、$i=j$それぞれが貢献する場合 1.

 ### なぜ効果があるのか

 すべてのペアの寄与は、その gcd によって一意に分解されます。 メビウス反転により、すべてのペアが正しい重み付けで正確に 1 回カウントされることが保証され、除数集計により、すべての相互作用が独立した寄与を通じて捕捉されることが保証されます。$S_k$。 この構造では、各ペアがその gcd の除数チェーンで正確に表現されるため、二重カウントが回避されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAXA = 200000

# SPF for factorization
spf = list(range(MAXA + 1))
for i in range(2, int(MAXA**0.5) + 1):
    if spf[i] == i:
        for j in range(i * i, MAXA + 1, i):
            if spf[j] == j:
                spf[j] = i

def squarefree(x):
    res = 1
    while x > 1:
        p = spf[x]
        cnt = 0
        while x % p == 0:
            x //= p
            cnt ^= 1
        if cnt:
            res *= p
    return res

n = int(input())
b = list(map(int, input().split()))

a = [squarefree(x) for x in b]

S = [0] * (MAXA + 1)

for v in a:
    S[v] += v

# sum over divisors
for i in range(1, MAXA + 1):
    if S[i]:
        for j in range(2 * i, MAXA + 1, i):
            S[j] += S[i]

# Möbius
mu = [1] * (MAXA + 1)
is_comp = [False] * (MAXA + 1)
primes = []

for i in range(2, MAXA + 1):
    if not is_comp[i]:
        primes.append(i)
        mu[i] = -1
    for p in primes:
        if i * p > MAXA:
            break
        is_comp[i * p] = True
        if i % p == 0:
            mu[i * p] = 0
            break
        else:
            mu[i * p] = -mu[i]

g = [0] * (MAXA + 1)
for t in range(1, MAXA + 1):
    if mu[t] == 0:
        continue
    mt = mu[t] * (t * t)
    for k in range(t, MAXA + 1, t):
        g[k] += mt

inv = [1] * (MAXA + 1)
for i in range(1, MAXA + 1):
    inv[i] = pow(i, MOD - 2, MOD)

total = 0

for k in range(1, MAXA + 1):
    if S[k]:
        val = S[k] % MOD
        val = val * val % MOD
        val = val * g[k] % MOD
        val = val * inv[k] % MOD
        val = val * inv[k] % MOD
        total += val

total %= MOD
ans = (total - n) % MOD
ans = ans * ((MOD + 1) // 2) % MOD

print(ans)
```実装は、最小の素因数分解を使用して各数値をその平方フリー カーネルに圧縮することから始まります。 次のステージでは、すべての値に対して周波数加重和を構築し、それを除数全体に上方に伝播します。$S_k$複数からの寄付を蓄積します。 

メビウス値は線形ふるいを使用して生成され、算術重みの構築に使用されます。$g(k)$。 除算$k^2$浮動小数点の問題を回避するために、モジュールの逆変換を通じて処理されます。 

最後に、順序付きペアの合計が累積され、順序なしの結果が得られるように調整されます。

 ## 特殊なケース

 数値が完全な平方である場合、重大なエッジケースが発生します。 たとえば、すべての入力が 2 の累乗である場合、次のようになります。$2, 4, 8, 16$、それらの正方形フリーカーネルはすべて 2 または 1 に崩壊し、相互作用構造が劇的に変化します。 平方フリー削減は集計の前に実行され、パリティ動作が確実に保持されるため、アルゴリズムはこれを正しく処理します。 

もう 1 つのエッジ ケースは、多くの数値が共通の大きな自由平方コンポーネントを共有する場合です。 その場合、gcd 項は大きくなり、キャンセルが支配的になります。 すべての寄与が経由されるため、除数ベースの分解でもこれを捕捉できます。$S_k$、大きいところでは$k$影響を受けるすべての数値が累積され、それらの相互作用はペアごとではなく集合的に解決されます。
