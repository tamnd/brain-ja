 ## 問題の理解

 私たちは整数を書く方法を研究しています$n$増加しない正の整数のシーケンスとして。 言い換えれば、私たちは壊れます$n$右に移動しても決して増加しない部分に分割され、すべての部分が正でなければなりません。 これは、ソートされた形式で記述された標準の整数パーティションと同じです。 

このような各パーティションから、最初の要素と等しい初期要素の数を表す単一の数値を抽出します。 パーティションが値で始まる場合$x$、それから何回数えますか$x$シーケンスが下に落ちる前に最初から連続して表示されます$x$。 その数値は重みと呼ばれます。 

固定の場合$n$、多くの異なるパーティションが存在し、各パーティションが重みを生成します。 タスクはパーティションを数えることではなく、すべてのパーティションにわたって達成可能な個別の重みの数を数えるということです。$n$。 

入力は 1 つの整数だけです$n$、出力は、この重みが取り得るさまざまな値の数です。 

制約$n \le 10^9$パーティションの列挙や、すべての合計に対する部分的な DP さえも即座に除外します。 パーティションの数$n$超多項式に増加するため、パーティションを反復するアプローチは実行不可能です。 考えられるすべての最初の部分とその下の構造を反復することさえ、対数構造または平方根構造に崩れない限り避けなければなりません。 

微妙なエッジ ケースは、パーティションが極端に歪んでいる場合です。 例えば、$[n]$重み 1 を与えますが、$[1,1,\dots,1]$重みを与える$n$。 もう 1 つのあまり明白ではないケースは、中間の重みが連続していない可能性があることです。 1 と 2 の間のすべての整数ではありません$n$小規模であれば必ず達成可能である$n$、タスクは、完全な間隔を想定するのではなく、個別の達成可能な値をカウントすることです。 

## アプローチ

 強引なアイデアは、次のすべてのパーティションを生成することです。$n$、それぞれの重みを計算し、個別の結果を収集します。 これは概念的には単純です。合計が次の部分に達するまで、前の部分を超えないように次の部分を再帰的に選択します。$n$。 完全なパーティションごとに、最初の値に一致する初期要素の数を数えます。 

パーティションの数が少ないため、これはすぐに失敗します。$n$指数関数的です$\sqrt{n}$。 たとえ$n = 50$、これによりすでに数百万のパーティションが生成されます。$10^9$それはまったく不可能です。 

重要な観察は、重みが等しい値の最初のブロックにのみ依存するということです。 パーティションが value で始まるとします。$x$、繰り返しました$k$回。 次に、次のようになります。$$n = kx + (\text{remainder})$$ここで、剰余は、最大でも部分を使用して残りの合計を分割したものです。$x$、厳密に以下でなければなりません$x$(そうしないと、最初のブロックが長くなります)。 

重要な構造上の洞察は、固定重量の場合です。$k$、最初のブロックの後のすべてができるだけ小さいときに、可能な最小の合計が発生します。 つまり、次のようになります。$$[x, x, \dots, x, x-1, x-2, \dots, 1]$$と$k$のコピー$x$。 これにより、その重み構造の最小合計が生成されます。 

これにより、考えられる重みごとに問題が実現可能条件に変換されます。$k$が存在するかどうかを尋ねることができます。$x$最初のブロックサイズを持つパーティションのように$k$可能です。 最初のブロックの後の「最も緊密な」継続は最大の減少シーケンスであるため、存在条件は三角数を含む不等式に崩壊します。 

これにより、次のような単調な関係が得られます。$k$増加すると、必要最小限の$n$おおよそ次のように成長します$k^2$。 したがって、実現可能な最大値は、$k$の順序です$\sqrt{n}$、すべての有効な重みは、1 からその最大値までの連続した範囲を形成します。 

したがって、問題は最大のものを見つけることに帰着します$k$次のような:$$k(k+1)/2 \le n$$答えは単にその最大値です$k$。

 ## アルゴリズムのチュートリアル

 構造的境界を直接計算に変換します。 

1. 重みが$k$少なくとも必要です$k$最初の値のコピー、その後残りのシーケンスは厳密に減少するか、その値以下にとどまる必要があります。 これにより、最小の「形状コスト」が強制され、次のように二次関数的に増加します。$k$。 
2. 与えられた重量に対して可能な最小の構成を表現します。$k$。 最初の値が可能な限り小さく、それでも許容できる場合、最も厳密な構築が行われます。$k$これにより、シーケンスが階段構造に効果的にパックされます。 
3. 重量に必要な最小合計を計算します。$k$、これは三角数です$k(k+1)/2$。 これは、最初のブロックの下に減少する制約の行を積み重ねることに対応します。 
4. 最大のものを見つける$k$この最低額を超えないように$n$。 これは実現可能な最大重量です。 
5. これを出力します$k$なぜなら、すべてのより小さな重量は構造を緩和することによって達成できるからです。 

### なぜ効果があるのか

 重要な不変条件は、最初のブロックの重みを持つパーティションはすべて$k$少なくとも含まれている必要があります$k$最初の値が固定されると厳密に減少する剰余を強制する構造内の正の整数。 これにより、階段のパーティションの高さに相当する下限が課されます。$k$。 三角数は、そのような階段の最小合計と、追加の緩みを捕捉します。$n$柔軟性を高めるだけで、実現可能性を下げることは決してありません。 したがって、実現可能性は次のとおりであるかどうかによってのみ決まります。$n$その最小閾値を超えています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input().strip())

k = 0
# find maximum k such that k*(k+1)//2 <= n
# can do O(sqrt(n)) loop or binary search; sqrt is enough for 1e9
while (k + 1) * (k + 2) // 2 <= n:
    k += 1

print(k)
```実装では、以下を超えない最大の三角数を直接検索します。$n$。 ループが増える$k$状態を維持しながら$k(k+1)/2 \le n$。 使用する$(k+1)(k+2)/2$インクリメント後の再計算を回避し、クリーンな状態を保ちます。 

標準の整数解析以外のエッジ処理は必要ありません。$n \ge 1$少なくとも保証します$k = 1$は正しく考慮されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    input = _sys.stdin.readline

    n = int(input().strip())
    k = 0
    while (k + 1) * (k + 2) // 2 <= n:
        k += 1
    return str(k)

# provided sample

# small triangular boundary

 ## 特殊なケース

 のために$n = 1$、唯一のパーティションは$[1]$したがって、唯一の重みは 1 です。アルゴリズムは次から始まります。$k = 0$、小切手$1 \le 1$、1 に増加し、次の三角チェックに失敗するとすぐに停止します。 

のために$n = 6$、正確にヒットしました$3 \cdot 4 / 2 = 6$。 アルゴリズムは正しく許可します$k = 3$、正確な三角数が 1 つずつ除外されるのではなく、有効な最大値として含まれていることを示しています。 

のために$n = 7$の最小要件$k = 4$は 10 なので拒否されます。 アルゴリズムは正しく維持します$k = 3$、実現可能性は三角形のしきい値でのみ変化し、それらの間では変化しないことが確認されました。
