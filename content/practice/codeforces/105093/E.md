 ## 解決策
 ## 問題の理解

 いくつかの独立したシナリオが与えられています。 各シナリオには、$n$それぞれの国は、その技術レベルを表す単一の整数値を持っています。 

2 つの国は、技術レベルの絶対差が選択したしきい値を超えない場合に限り、通信ケーブルで直接接続できます。$a$。 このようなケーブルが存在する場合は、必ず構築されます。 2 つの国の間に経路を形成する一連のケーブルが存在する場合、2 つの国間の通​​信は可能です。 

目標は、可能な限り小さい値を選択することです。$a$つまり、許容されるすべてのケーブルが構築された後は、ある一連の接続を通じてすべての国が他のすべての国に到達できるようになります。 

入力サイズは最大を推奨します$10^5$すべてのテスト ケースにわたる合計値。これにより、すべてのペアを直接比較する二次アプローチが除外されます。 すべての国のペアをチェックするソリューションでは、最大で次のことが必要になります。$10^{10}$実現可能な限界をはるかに超えた最悪の場合の比較。 したがって、すべてのエッジにわたる推論を明示的に回避する構造が必要です。 

素朴な考え方による微妙な失敗例は、値が並べ替えられていない場合に現れます。 たとえば、値が次の場合:

 入力:```
1
4
1 100 2 3
```順序付けせずに任意のペア接続について誤って推論すると、接続を妨げる「ギャップ」が実際には 3 ～ 100 の間であり、任意の離れた要素間ではないことを見落としがちです。 正しい答えは、任意のペアの距離ではなく、順序付けの最も厳しいボトルネックにのみ依存します。 

もう 1 つのエッジ ケースは、次のようなすべての値が等しい場合です。```
1
5
7 7 7 7 7
```ここに任意の$a = 0$すべての差がゼロであるため、すでにすべてが接続されています。 

これらの観察は、最適な接続性の構造が、ソート順に並べたときに値がどのように並ぶかに依存することを示唆しています。 

## アプローチ

 この強引なアイデアは、国の各ペアを潜在的なエッジとして扱い、固定値の場合にどのエッジが存在するかをシミュレートすることです。$a$。 与えられた$a$、グラフを構築し、BFS または DSU を実行して接続を確認できます。 次に、二分探索を行うことができます$a$、毎回接続をチェックします。 

接続が単調であるため、これは正しく機能します。$a$ただし、各チェックではすべてを調べる必要があります。$O(n^2)$最悪の場合はペアになります。 最適化されていても、エッジの構築には依然として二次時間がかかり、次の条件では失敗します。$n = 10^5$。 

重要な観察は、テクノロジー値を並べ替えた後、接続性にとって重要なエッジのみが、並べ替えられた順序で隣接する要素間にあることです。 2 つの連続する並べ替え値の間に大きなギャップがある場合、そのギャップを「埋める」ために間にあるより小さい値は存在しません。 それをバイパスしようとするパスは、依然として同じ数値ジャンプを通過する必要がありますが、これは次の場合を除いて不可能です。$a$少なくともそのギャップはあります。 

したがって、問題全体は、ソートされた配列内の連続する要素間の最大の差を見つけることに帰着します。

 ## アルゴリズムのチュートリアル

 1. テクノロジ値の配列を降順でない順に並べ替えます。 並べ替えると、値間の最小限の「ジャンプ」の自然な構造が明らかになり、接続が失敗する可能性があります。 
2. ソートされた配列内の連続する要素のすべてのペアの間の差を計算します。 それぞれの違いは、その局所的なギャップを直接埋めるために必要な最小のしきい値を表します。 
3. これらの連続した差の最大値を追跡します。 この最大のギャップは、価値の連鎖における最も弱い部分です。 
4. この最大ギャップをテスト ケースの答えとして出力します。値が小さいと、接続に少なくとも 1 つの避けられない中断が残るためです。 

### なぜ効果があるのか

 値が並べ替えられると、最小要素から最大要素へのパスは中間値を昇順に移動する必要があります。 隣接しないノード間にエッジが存在する場合でも、そのような接続では、連続するソート値間の最大分離をバイパスすることはできません。これは、そのジャンプを軽減する中間値が存在しないためです。 隣接するすべてのギャップが「ブリッジ可能」になると、グラフは正確に接続され、最悪のギャップが必要な最小しきい値を決定します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    out = []
    for _ in range(T):
        n = int(input())
        arr = list(map(int, input().split()))
        arr.sort()
        
        ans = 0
        for i in range(1, n):
            ans = max(ans, arr[i] - arr[i - 1])
        
        out.append(str(ans))
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```このソリューションは、各テスト ケースを個別に処理します。 並べ替えは、密な接続性の問題を隣接する相違点の線形スキャンに変換するため、重要なステップです。 答えは、完全な接続に必要な最小しきい値に直接対応する最大ギャップを追跡することによって蓄積されます。 

よくある間違いは、すべてのペアごとの違いについて推論しようとすることです。 それは無関係な制約を過大評価します。 ソート順序の連続した違いのみが問題となります。これは、それらが値行の最小限の区切り文字を表すためです。

 ## 特殊なケース

 エッジケースの 1 つは次のような場合です$n = 2$。 このアルゴリズムでは、ソート後に直接減算が行われ、最大連続差は単純に 2 つの値の絶対差になります。 入力の場合:```
1
2
8 3
```ソートすると得られる$[3, 8]$、唯一のギャップは 5 であり、これが正しく返されます。 

もう 1 つの特殊なケースは、単一の外れ値と混合された値が繰り返されることです。 のために：```

```収量の選別$[4, 4, 4, 4, 100]$。 このアルゴリズムは、連続する差分をスキャンし、96 という単一の大きなギャップを見つけます。これにより、しきい値が少なくとも 96 でない限り、外れ値がクラスターから切り離されていることを正確に捕捉できます。
