 ## 解決策
 ## 問題の理解

 最大 20 個の潜在的な欠陥の固定セットが与えられています。 各申請者はこれらの欠陥の一部を選択し、満足度スコアを割り当てられます。 次に、求職者は「取引を妨げる」欠陥のリストを提供します。そして、これらの禁止された欠陥を含まない最も望ましい申請者を見つけなければなりません。 

よりアルゴリズム的な方法で言い換えると、各申請者は、値とペアになったサイズ f のユニバースのサブセットです。 各クエリは別のサブセットを与えるので、クエリ サブセットから素であるすべてのサブセットの中から最大値を見つける必要があります。 

制約があるからこそ面白いのです。 最大 200,000 人の応募者と 200,000 のクエリがあるため、すべての応募者をクエリごとにスキャンすることは直ちに不可能になります。 クエリごとに O(n) であっても、最悪の場合は 400 億のチェックが発生します。 主な制限は f ≤ 20 です。これは、すべてのサブセットが 0 から 2^f − 1 までのビットマスクとして表現できることを意味します。このビットマスクは事前計算に十分な大きさです。 

微妙な落とし穴は、クエリの表現にあります。 「取引違反者」リストは OR 条件です。これらの欠陥が 1 つでもある応募者は無効です。 したがって、正確なセットを照合するのではなく、クエリ マスクと交差するすべてのマスクを除外します。 

単純な間違いは、これを間違った方向のサブセット マッチングとして解釈することです (たとえば、申請者のマスクがクエリ マスクのサブセットであるかどうかを確認するなど)。 それは論理を逆転させ、完全に間違った答えを生み出すことになります。 

## アプローチ

 直接的なアプローチでは、各申請者をビットマスクとして保存し、クエリごとにすべての申請者をチェックして、そのマスクがクエリ マスクと交差するかどうかを確認します。 これは正しいですが、コストが O(nq) であり、実現不可能です。 

視点を反転すると、構造ははるかに単純になります。 「この申請者はクエリと競合するかどうか」という観点から考えるのではなく、「クエリによってどのマスクが完全に許可されるのか」という観点から考えます。 クエリ マスクが q の場合、有効な申請者は、m & q = 0 となるマスク m です。これは、m が f ビット内の q の補数のサブマスクであると言うのと同じです。 

これにより、各クエリが古典的なサブマスク集計問題に変換されます。つまり、各マスクの最適値の事前計算された配列が与えられた場合、指定されたマスクのすべてのサブマスクの最大値が必要になります。 これは、標準的なサブセット動的プログラミング手法 (サブマスク上の SOS DP) を使用して効率的に回答できます。 

まず、各申請者をビットマスクに圧縮し、正確なマスクごとに最大の望ましさを保存します。 次に、すべてのマスクがそのすべてのサブマスクの最大値を格納するように、これらの値を伝播します。 この前処理の後、各クエリは補数マスクの単一のルックアップになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(nq) | O(n) | 遅すぎる |
 | ビットマスク + サブマスク DP | O((n + 2^f)・f + q) | O(2^f) | 承認済み |

 ## アルゴリズムのチュートリアル

 すべての申請者とクエリを f ビットにわたるビットマスク形式に削減します。 

1. 各欠陥に 0 から f − 1 までのインデックスを割り当て、すべての申請者の欠陥リストをビットマスクに変換します。 正確な各マスクの最大の望ましさは配列に保存されます。 このステップでは、すべての構造化入力を固定サイズの状態空間に圧縮します。 
2. アレイを構築する`best[mask]`サイズは 2^f で、各エントリには、欠陥セットがまさにそのマスクである申請者間の最大の望ましさが格納されます。 
3. これを「サブマスク最大」DP に変換します。 すべてのマスクに対して、私たちが望んでいるのは、`dp[mask] = max(best[s]) for all s ⊆ mask`。 サブセットに対する標準ビット DP を使用してこれを計算します。ビットごとに、小さいサブマスクから大きいサブマスクに最大値を伝播します。 
4. クエリごとに、そのビットマスク q を構築します。 f ビット内の補数マスクを計算します。`comp = (~q) & ((1 << f) - 1)`。 
5. 質問に対する答えは単純です。`dp[comp]`comp には許容される欠陥が正確に含まれており、 dp[comp] はすべての有効な申請者マスクを集約するためです。 
6. dp[comp] が空の場合 (申請者が貢献していない場合)、失敗文字列を出力します。 

### なぜ効果があるのか

 核となる不変条件は、前処理後に、`dp[x]`は、欠陥セットが x のサブセットであるすべての応募者の間での最大の望ましさを格納します。 クエリ q に対して有効な申請者は、q と重複してはなりません。これは、そのマスクが q の補数のサブセットであることを意味します。 したがって、すべての有効な申請者は、正確に、`dp[comp]`、無効な応募者は、コンプの範囲外に少し含まれているため、そこに表示されることはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    f = int(input().strip())
    flaws = input().split()
    idx = {flaws[i]: i for i in range(f)}

    n = int(input().strip())

    size = 1 << f
    best = [-1] * size

    for _ in range(n):
        a = int(input().strip())
        tokens = input().split()

        mask = 0
        i = 0
        # tokens: im flaw (and/sry chaining)
        while i < len(tokens):
            if tokens[i] == "im":
                i += 1
                continue
            if tokens[i] == "sry":
                break
            flaw = tokens[i]
            i += 1
            if i < len(tokens) and tokens[i] in ("and", "sry"):
                mask |= (1 << idx[flaw])
                if tokens[i] == "sry":
                    break
                i += 1
            else:
                mask |= (1 << idx[flaw])

        best[mask] = max(best[mask], a)

    dp = best[:]

    for i in range(f):
        for mask in range(size):
            if mask & (1 << i):
                dp[mask] = max(dp[mask], dp[mask ^ (1 << i)])

    q = int(input().strip())
    full = (1 << f) - 1

    out = []
    for _ in range(q):
        tokens = input().split()

        qmask = 0
        i = 0
        while i < len(tokens):
            if tokens[i] == "no":
                i += 1
                continue
            if tokens[i] == "pls":
                break
            flaw = tokens[i]
            i += 1
            if i < len(tokens) and tokens[i] in ("or", "pls"):
                qmask |= (1 << idx[flaw])
                if tokens[i] == "pls":
                    break
                i += 1
            else:
                qmask |= (1 << idx[flaw])

        comp = full ^ qmask
        ans = dp[comp]
        if ans == -1:
            out.append("LOWER YOUR STANDARDS")
        else:
            out.append(str(ans))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```最初の段階では、各申請者をビットマスクに圧縮し、正確な構成ごとに最適な値のみを保存します。 複数の申請者が同一の欠陥セットを共有できるため、衝突は最大値を取ることによって処理されます。 

第 2 段階はサブマスク DP です。 ビットを反復するたびに、特定のビットを欠いているマスクの情報が、そのビットを含むマスクに伝播され、完全な「すべてのサブマスクの最大値」テーブルが構築されます。 

クエリ ロジックは、禁止されたセットを補完し、問題を純粋なサブセット クエリとして扱うことに依存しています。 

## 実用的な例

 小さなカスタム インスタンスを使って説明します。 

f = 3 に欠陥 a、b、c があると仮定します。 

申請者:

 マスク001→10

 マスク010→5

 マスク011→7

 前処理後:

 ベスト[001]=10、ベスト[010]=5、ベスト[011]=7

 サブマスク DP の後:

 dp[000]=0 (申請者なし)

 dp[001]=10

 dp[010]=5

 dp[011]=10

 dp[111]=10

 ここでクエリを実行します: 「a または c はありません」 → qmask = 101

 コンプ = 010

 答え = dp[010] = 5

 | ステージ | 値 |
 | --- | --- |
 | qマスク | 101 |
 | コンプ | 010 |
 | dp[comp] | 5 |

 これは、許可された機能を完全に含む申請者のみが考慮されることを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O((n + 2^f) · f + q) | マスクの構築、f ビット上の SOS DP、定数クエリ |
 | スペース | O(2^f) | すべてのサブセットにわたる配列 |

 f ≤ 20 なので 2^f は約 100 万となり、線形ビット DP ではメモリと時間の両方で管理できるため、指数係数は安全です。

 ## 特殊なケース

 重要なエッジケースは、クエリがすべての欠陥を禁止する場合です。 この場合、補数マスクはゼロとなり、欠陥のない申請者のみが有効となります。 存在しない場合、dp[0] は無効なままとなり、出力は失敗文字列でなければなりません。 dp[0] は正確な空のマスクのみを集約するため、DP はこれを正しく処理します。 

もう 1 つの特殊なケースは、同一の欠陥セットを共有する複数の申請者です。 前処理ステップではマスクごとの最大望ましさのみが保存されるため、重複によって結果が歪むことはなく、DP はサブマスク関係を通じて正しい最大値を上方に伝播します。
