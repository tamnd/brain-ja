 ## 問題の理解

 私たちにはいくつかの素数が与えられます。 各素数は、数字の正方行列の最初の行を表します。 素数に長さがある場合`n`の場合、行列は次のようになります。`n × n`。 

マトリックスは 2 つの条件を満たす必要があります。 

まず、10 進数として解釈されるすべての行はそれ自体が素数でなければなりません。 最初の行以外の行はゼロで始めることができます。 

第二に、行列は対称です。 位置の数字`(i, j)`の数字と等しくなければなりません`(j, i)`。 

タスクは、指定された最初の行ごとにそのような行列がいくつ存在するかをカウントすることです。 

行列について考えるのに役立つ方法は次のとおりです。最初の行が固定されると、対称性によりすぐに最初の列も固定されます。 次に、残りの選択肢はすべて、行の優先性と列の一貫性を同時に満たす必要があります。 

素数の最大長は`5`、入力数値は最大でも`99999`。 それは問題の性質を完全に変えます。 すべての桁行列の検索空間は膨大ですが、実際の次元は非常に小さいです。 これは、慎重に剪定されたブルート フォースまたは動的プログラミングのアプローチが機能する可能性があることを強く示唆しています。 

テストケースの数は最大で`30`, したがって、前処理は魅力的です。 よりも少ないです`100000`合計 5 桁の文字列ですが、`10^4`以下の素数`100000`。 素数を一度列挙し、すべてのテスト ケースで再利用する余裕があります。 

考えられるすべての行列を単純に検索するのは絶望的です。 のために`5 × 5`マトリックス、あります`10^25`数字の割り当て。 素数行だけを考慮したとしても、行ごとにまだ数千の候補があり、組み合わせは数兆通りになります。 

厄介な点は、行の制約と対称性が両方向に相互作用することです。 DFS を不注意にすると、無効な行列が簡単にカウントされてしまう可能性があります。

## アプローチ

 ブルートフォースのアイデアは単純です。 行列のサイズが`n`。 入力の最初の行を修正し、次に 2 行目で考えられるすべての素数を試し、3 行目で考えられるすべての素数を試します。 完全な行列を構築した後、それが対称かどうかを確認します。 

すべての候補行列が直接検査されるため、これは論理的に機能します。 問題は分岐要素です。 おおよそあります`10^4`以下の素数`100000`。 桁の長さによって制限しても、行ごとに数千の可能性が残ります。 のために`n = 5`、検索は大まかに次のようになります。```
3000^4 ≈ 8 × 10^13
```それはまったく不可能です。 

重要な観察は、対称性によってプレフィックス制約が作成されるということです。 

いくつかの行を選択すると、将来の行の部分が自動的に決定されます。 行の場合`0..k-1`すでに修正されている場合、最初の`k`行の桁数`k`対称性によって強制されます。 

たとえば、次を選択した後:```
239
307
```3 行目は次で始まる必要があります`"97"`なぜなら：```
a[2][0] = a[0][2] = 9
a[2][1] = a[1][2] = 7
```これにより問題は完全に変わります。 行を自由に選択するのではなく、各行は特定の接頭辞を持つ素数のセットに属している必要があります。 

以来`n ≤ 5`、長さとプレフィックスによってグループ化されたすべての素数を前処理できます。 その後、検索は積極的なプルーニングを伴う小さな DFS になります。 

DFS の深さで`k`、どのプレフィックス行がすでに正確にわかっています`k`持っている必要があります。 そのプレフィックスに一致する素数のみを反復処理します。 すべての有効な選択により、マトリックスが一貫して拡張されます。 

これにより、すべての素数タプルに対する指数関数的な検索がはるかに小さな状態空間に変わります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数関数的、おおよそ O(P^(n-1)) | O(n²) | 遅すぎる |
 | 最適 | O(有効な DFS 状態の数) | O(P) | 承認済み |

 ここ`P`最大 5 桁の素数の数です。 

## アルゴリズムのチュートリアル

 1. 以下のすべての素数を生成します`100000`ふるいを使って。 

すべての長さの素数が必要です`1`を通して`5`なぜなら、最初の行以降の行には先頭にゼロが含まれる可能性があるからです。 例えば、`"023"`素数に相当する`23`。 
2. すべての素数をゼロ埋めされた長さの文字列に変換します。`1`を通して`5`。 

たとえば、プライム`23`は次のようになります:```
"23"   for length 2
"023"  for length 3
"00023" for length 5
```これにより、先行ゼロを自然に処理できるようになります。 
3. 素数をグループ化する`(length, prefix)`。 

パディングされたすべてのプライム文字列を、そのプレフィックスをキーとする辞書に保存します。 

長さの例`3`:```
prefix "9"  -> ["907", "911", ...]
prefix "97" -> ["977", ...]
```後で、行が強制的に次で始まるようになったとき、`"97"`、互換性のあるすべての素数をすぐに取得できます。 
4. テスト ケースごとに、最初の行を行として保存します。`0`。 

行列は対称であるため、最初の列も自動的に固定されます。 
5. DFS を行ごとに実行します。 

行を選択しているとします。`k`。 

なぜなら行`0..k-1`はすでに固定されており、対称性が最初の要素を決定します。`k`行の桁数`k`。 

具体的には：```
row[k][j] = row[j][k]
```あらゆる人にとって`j < k`。 
6. 行に必要なプレフィックスを構築します`k`。 

現在の行が次の場合:```
239
307
```それから漕ぎます`2`次で始める必要があります:```
rows[0][2] + rows[1][2] = "97"
```7. そのプレフィックスに一致するすべてのプライム行を列挙します。 

長さの素数をすべて取得する`n`前処理辞書から必要なプレフィックスを付けます。 
8. 候補行を 1 つ追加し、再帰的に続行します。 

選択されたすべての行は、その強制プレフィックスがすでに一致しているため、以前のすべての行との対称性を自動的に保持します。 
9. 全てが終わったら`n`行が選択されている場合、有効な行列を 1 つ数えます。 

### なぜ効果があるのか

 DFS の深さで`k`、行`0..k-1`すでにそれらの間で対称性を満たしています。 最初`k`行の桁数`k`条件によって一意に決定されます。```
a[k][j] = a[j][k]
```まさにそのプレフィックスを持つ素数を選択すると、既存のすべての行との対称性が維持されます。 今後の行では、行に関係する残りの対称位置が後で強制されます。`k`。 

すべての対称制約は決定された瞬間に適用されるため、無効な行列はカウントされません。 必要なプレフィックスに一致するすべての正当な行が探索されるため、有効な行列が失われることはありません。 

## Python ソリューション```python
import sys
from collections import defaultdict

input = sys.stdin.readline

LIMIT = 100000

# sieve
is_prime = [True] * LIMIT
is_prime[0] = is_prime[1] = False

for i in range(2, int(LIMIT ** 0.5) + 1):
    if is_prime[i]:
        step = i
        start = i * i
        for j in range(start, LIMIT, step):
            is_prime[j] = False

# prefix[length][prefix] = list of prime strings
prefix = [defaultdict(list) for _ in range(6)]

for x in range(2, LIMIT):
    if not is_prime[x]:
        continue

    s = str(x)

    for length in range(len(s), 6):
        padded = s.zfill(length)

        for k in range(length + 1):
            pref = padded[:k]
            prefix[length][pref].append(padded)

t = int(input())

for _ in range(t):
    first = input().strip()
    n = len(first)

    rows = [first]
    ans = 0

    def dfs(k):
        nonlocal ans

        if k == n:
            ans += 1
            return

        need = []

        for j in range(k):
            need.append(rows[j][k])

        need = ''.join(need)

        for candidate in prefix[n][need]:
            rows.append(candidate)
            dfs(k + 1)
            rows.pop()

    dfs(1)

    print(ans)
```ふるいは以下のすべての素数を生成します`100000`一度。 行の最大長は`5`、この前処理は小さなものです。 

中央の前処理構造は次のとおりです。`prefix[length][pref]`。 固定長のすべてのプライム文字列をプレフィックスごとにグループ化して保存します。 これが DFS を高速にする理由です。 再帰中にすべての素数をテストする代わりに、互換性のある候補に直接ジャンプします。 

その行:```
padded = s.zfill(length)
```が不可欠です。 ゼロ埋め込みをしないと、次のような行になります。`"023"`たとえそれらが有効な素数を表していても、決して表示されません。`23`。 

DFS 状態には、すでに選択されている行のみが保存されます。 行選択時`k`、必要なプレフィックスは列から構築されます。`k`前の行:```
rows[j][k]
```これにより、対称性が厳密に強化されます。 

再帰の深さは最大でも`5`したがって、ここでは Python の再帰は完全に安全です。 

実装の微妙な点は、最後に対称性を明示的にチェックしないことです。 構築プロセスにより、それが段階的に保証されます。 すべての行は、適切な位置にある以前のすべての行と強制的に一致します。

import sys, io
from collections import defaultdict

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    LIMIT = 100000

    is_prime = [True] * LIMIT
    is_prime[0] = is_prime[1] = False

    for i in range(2, int(LIMIT ** 0.5) + 1):
        if is_prime[i]:
            for j in range(i * i, LIMIT, i):
                is_prime[j] = False

    prefix = [defaultdict(list) for _ in range(6)]

    for x in range(2, LIMIT):
        if not is_prime[x]:
            continue

        s = str(x)

        for length in range(len(s), 6):
            padded = s.zfill(length)

            for k in range(length + 1):
                prefix[length][padded[:k]].append(padded)

    t = int(input())
    out = []

    for _ in range(t):
        first = input().strip()
        n = len(first)

        rows = [first]
        ans = 0

        def dfs(k):
            nonlocal ans

            if k == n:
                ans += 1
                return

            need = ''.join(rows[j][k] for j in range(k))

            for cand in prefix[n][need]:
                rows.append(cand)
                dfs(k + 1)
                rows.pop()

        dfs(1)
        out.append(str(ans))

    return '\n'.join(out)
