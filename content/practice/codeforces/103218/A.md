 しましょう$A$の家族になる$t$-組み合わせてみましょう$\partial A$その影、すべての家族を意味します$(t-1)$- のメンバーに含まれる組み合わせ$A$。 可能な限り最小限のサイズを追求します$A$そのような$|\partial A| < |A|$。 

重要なツールはクラスカル・カトナ定理です。これは、すべての族の間で次のことが暗示されています。$A$の$t$- 固定カーディナリティ、シャドウとの組み合わせ$\partial A$を摂取することで最小化されます$A$蔵書目録の最初のセグメントになります。 したがって、特定のサイズのファミリが次の条件を満たす場合、$|\partial A| < |A|$の場合、同じ不等式がそのサイズの colex 初期セグメントにも当てはまります。 したがって、問題は、すべての要素からなるフォームの最初のセグメントを研究することに帰着します。$t$-のサブセット${1,2,\dots,n}$、閾値は二項層で発生するためです。 

そんなフルレイヤーファミリーのために$A = \binom{[n]}{t}$、影はすべてから構成されます$(t-1)$-のサブセット${1,2,\dots,n}$したがって、$$|A| = \binom{n}{t}, \quad |\partial A| = \binom{n}{t-1}.$$これらの量の比率は次のようになります。$$\frac{|\partial A|}{|A|} = \frac{\binom{n}{t-1}}{\binom{n}{t}} = \frac{t}{n-t+1}.$$不平等$|\partial A| < |A|$したがって、次と同等です$$\frac{t}{n-t+1} < 1,$$これを単純化すると$$t < n - t + 1,$$または同等の$$n > 2t - 1.$$最小の整数$n$この条件を満たすのは$n = 2t$。 この値については、$$|A| = \binom{2t}{t}, \quad |\partial A| = \binom{2t}{t-1}.$$比率は次のようになります。$$\frac{|\partial A|}{|A|} = \frac{t}{t+1} < 1,$$それで$|\partial A| < |A|$保持します$A = \binom{[2t]}{t}$。 

最小限度を示すことは残っています$|A|$。 どれについても$m < \binom{2t}{t}$、colex の初期セグメントを考慮します。$A_m$サイズの$m$。 クラスカル・カトナ定理は、その影が少なくとも他のサイズのファミリーの影と同じくらい大きいことを示唆しています。$m$。 レベルで$n = 2t - 1$、1つは持っています$$\binom{2t-1}{t-1} = \binom{2t-1}{t},$$したがって、レイヤー全体の影のサイズはレイヤー自体と同じになります。 これは平等が実現できる最後のポイントです。 このしきい値を超えてサイズを大きくすると、必然的にファミリには、colex 順序付けの次の層構造からのセットを含めることが強制され、上記の二項比は、最初の厳密な不等式が成り立つことを示しています。$|\partial A| < |A|$に渡すときに正確に発生します$n = 2t$。 

したがって、可能な限り最小の家族が発生するのは、$A$すべての完全なコレクションです$t$- のサブセット$2t$-要素セット。 

したがって、最小サイズは$$|A| = \binom{2t}{t}.$$

$$\boxed{\binom{2t}{t}}$$これで証明は完了です。 ∎
