 ## 解決策
 ## 問題の理解

 (n) 個の正弦波があります。 すべての波は同じ角周波数 (\omega) で振動しますが、それぞれ独自の振幅 (A_i) と位相 (\phi_i) を持ちます。 それらの合計は、同じ周波数を持つもう 1 つの正弦波として表現できることが保証されており、その振幅 (A) と位相 (\phi) を回復する必要があります。 

入力により、共通周波数 (n) が与えられ、次に (n) 個のペア ((A_i,\phi_i)) が与えられます。 出力は次のようなペア ((A,\phi)) です。 

A\sin(\オメガ t+\ファイ)
 】

 (A\ge 0) および (0\le\phi<2\pi) のすべての (t) に対して。 

周波数自体は計算に影響しません。 すべての項はまったく同じ (\omega) を持っているため、それらの振幅と位相を組み合わせるだけで済みます。 

値 (n) は (10^5) に達することがあります。 すべての波を他のすべての波と比較するソリューションでは、最悪の場合、2 秒の時間制限をはるかに超える、およそ (10^{10}) 個のペアごとの演算が実行されます。 線形または線形に近いアルゴリズムが必要です。 振幅は最大 (100) であるため、累積された係数は最大約 (10^7) であり、通常の浮動小数点の範囲内に十分収まります。 位相値はすでにラジアンで指定されており、1 回転内に収まります。 

一見合理的に見える実装が間違っている可能性がある、数値上のエッジケースがいくつかあります。 単一の波を考えてみましょう。```
1 1
5 0
```結果は正確に (5)、位相 (0) です。 位相を不必要に変更したり、1 つの三角関数成分による除算を含む式を使用したソリューションは、その成分がゼロの場合に失敗する可能性があります。 

2 番目のケースは、波が反対方向を向いている場合です。```
1 1
5 3.141592653589793
```結果は振幅 (5) と位相 (\pi) になります。 位相を計算する`atan(y / x)`(x) がゼロになる可能性があり、さらに重要なことに、(x) と (y) の符号によって象限が決まるため、これは安全ではありません。`atan2`はまさにこの状況向けに設計されています。 

最後に、完全なキャンセルも可能です。```
2 1
1 0
1 3.141592653589793
```2 つの波は互いに負であるため、結果はゼロ関数になります。 その振幅は (0) であり、すべての (\phi) に対して (0\sin(\omega t+\phi)=0) であるため、その位相は数学的に無関係です。 浮動小数点の実装では、正確なゼロではなく小さな残差が残ることがありますが、これは必要な誤差許容範囲内では無害です。 

(2\pi) の周囲にも境界ケースがあります。 例えば、```
2 1
1 0
1 6.283185307079586
```は、負の角度ではなく、(2\pi) に非常に近い合成位相を持ちます。 以来`atan2`([-\pi,\pi]) の角度を返します。負の結果は (2\pi) だけシフトする必要があります。 

## アプローチ

 直接的なアプローチでは、おそらくいくつかの点で合計を (t) の関数として評価し、それらの値から振幅と位相を回復しようとします。 それは不必要であり、すべてのウェーブに対して多くのポイントを評価することは作業が増えるだけです。 より代数的な総当りアプローチでは、三角恒等式を使用して 2 つの正弦波を繰り返し組み合わせることができます。 個々の組み合わせは正しいものの、式を繰り返し操作すると、不必要な作業や数値の複雑さが生じる可能性があります。 波のすべてのペアを考慮すると、最悪のケースは (n^2=10^{10}) 回の演算程度になります。 

有益な観察は、加算を行う前に位相シフトを拡張できることです。 1つの波に対して、

 A_i\sin(\omega t)\cos\phi_i
 +
 A_i\cos(\omega t)\sin\phi_i。 
】

 したがって、すべての波は、同じ 2 つの関数 (\sin(\omega t)) と (\cos(\omega t)) の線形結合にすぎません。 それらの係数を独立して追加できます。 

定義する

 [
 X=\sum_{i=1}^{n} A_i\cos\phi_i
 】

 そして

 [
 Y=\sum_{i=1}^{n} A_i\sin\phi_i。 
】

 すると、合計は次のようになります

 [
 f(t)=X\sin(\オメガt)+Y\cos(\オメガt)。 
】

 次に、目的の単一の波形を展開します。 

A\cos\phi\sin(\omega t)
 +
 A\sin\phi\cos(\omega t)。 
】

 係数を一致させると、

 [
 A\cos\phi=X、
 \qquad
 A\sin\phi=Y。 
】

 ペア ((X,Y)) は 2 次元ベクトルとして見ることができます。 その長さは結果として生じる振幅であり、

 [
 A=\sqrt{X^2+Y^2}、
 】

 そしてその方向は結果として生じる位相であり、

 [
 \phi=\オペレーター名{atan2}(Y,X)。 
】

 これにより、問題全体が入力を 1 回通過するだけで済みます。 正弦波は代数的に組み合わせることができるため、総当り攻撃は機能しますが、すべての波が同じ 2 つの基底関数を使用するという事実を利用できません。 すべての項が (\sin(\omega t)) と (\cos(\omega t)) の係数に帰着するという観察により、波の集合全体を 1 つの累積された 2 次元ベクトルで置き換えることができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(n^2)) | (O(1)) | 遅すぎる |
 | 最適 | (O(n)) | (O(1)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. (n) と (\omega) を読み取ります。 (\omega) の値はすべての波で同一であるため、その後は必要ありません。したがって、すべての作業は振幅と位相を使用して実行できます。 
2. 2 つのアキュムレータ (X=0) と (Y=0) を初期化します。 (\sin(\omega t)) と (\cos(\omega t)) の係数を完全な合計で保存します。 
3. すべての波 ((A_i,\phi_i)) について、(A_i\cos\phi_i) を (X) に加算し、(A_i\sin\phi_i) を (Y) に加算します。 これは、(\sin(\omega t+\phi_i)) の展開から直接続きます。 
4. 結果の振幅を次のように計算します。 

[
 A=\オペレーター名{ハイポット}(X,Y)。 
】

 これは係数ベクトルのユークリッド長であり、数値的には手動で (\sqrt{X^2+Y^2}) を記述するよりも適しています。 
5.次のように位相を計算します。 

[
 \phi=\オペレーター名{atan2}(Y,X)。 
】`atan2`は両方の座標を使用するため、正しい象限が選択されます。 パイソンの`math.atan2`(-\pi) から (\pi) までの範囲の角度を返します。 
6. 位相が負の場合、(2\pi) を加算します。 必要な出力間隔は ([0,2\pi)) であるため、これは`atan2`問題で必要な規則に準拠します。 
7. (A) と (\phi) を十分な 10 進数で出力します。 小数点以下 12 桁を出力すると、必要な精度 (10^{-6}) よりもはるかに高い精度が得られます。 

### なぜ効果があるのか

 波の接頭辞を処理した後、(X) はその接頭辞によって (\sin(\omega t)) に与えられた係数になります。また、(Y) は (\cos(\omega t)) の係数になります。 別の波を追加すると、これらの係数が正確に (A_i\cos\phi_i) と (A_i\sin\phi_i) によって更新されるため、不変式はすべての入力ラインに対して true のままになります。 

すべての波が処理された後の完全な関数は次のようになります。 

[
 X\sin(\オメガ t)+Y\cos(\オメガ t)。 
】

 (A=\sqrt{X^2+Y^2}) と (\phi=\operatorname{atan2}(Y,X)) を選択すると、(A\cos\phi=X) と (A\sin\phi=Y) が得られます。 これらの恒等式を (A\sin(\omega t+\phi)) に代入すると、浮動小数点の丸めを除いて、累積関数が正確に再現されます。 位相正規化は完全な回転を追加するだけであり、正弦波は変更されません。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    n, omega = input().split()
    n = int(n)

    x = 0.0
    y = 0.0

    for _ in range(n):
        a, phi = map(float, input().split())
        x += a * math.cos(phi)
        y += a * math.sin(phi)

    amplitude = math.hypot(x, y)
    phase = math.atan2(y, x)

    if phase < 0.0:
        phase += 2.0 * math.pi

    print(f"{amplitude:.12f} {phase:.12f}")

if __name__ == "__main__":
    solve()
```最初の行は次のようになります`omega`ですが、実装では意図的にそれを使用しません。 共通周波数はすべての項にすでに存在しており、係数のマッチング中に変更されることはありません。 

変数`x`そして`y`は、アルゴリズムで導出された 2 つの係数に直接対応します。 各入力波は角度 (\phi_i) で長さ (A_i) の 1 つのベクトルに寄与するため、これら 2 つの成分を累積することはベクトル加算と同等です。`math.hypot(x, y)`累積されたベクトルの長さを計算します。 Python ドキュメント`hypot`これは、まさにここで必要とされる振幅計算です。`math.atan2(y, x)`の代わりに使用されます`math.atan(y / x)`。 ゼロによる除算を回避するだけでなく、両方の座標の符号が保存されるため、正しい象限が選択されます。 

逆位相調整は、`atan2`。 結果が負の場合にのみ (2\pi) を追加すると、サインまたはコサインを変更せずに、返された角度が必要な間隔にマップされます。 

三角関数の計算には整数演算が含まれないため、整数のオーバーフローは問題になりません。 累積可能な最大の座標は (10^7) 程度であり、これは倍精度浮動小数点数で簡単に表現できます。
