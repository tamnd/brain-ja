 ## 解決策
 ## 問題の理解

 (n) 個の正弦波信号があります。 すべての信号は同じ角周波数 (\omega) で振動しますが、それぞれが独自の振幅 (A_i) と位相 (\phi_i) を持ちます。 それらの合計は依然として同じ周波数の正弦波であることが保証されているため、タスクは単一の等価信号の振幅 (A) と位相 (\phi) を回復することです。 

入力には、(n) 個の共通周波数と、(n) 個のペア ((A_i,\phi_i)) が含まれます。 周波数自体は信号を追加しても変化しないため、出力に表示される必要はありません。 出力には、結果の波の振幅と位相のみが必要です。位相は間隔 ([0,2\pi)) に正規化されています。 

キー制約は (n\le 10^5) です。 2 秒の制限があるため、(O(n)) 個の解が自然なターゲットになります。 (O(n^2)) メソッドは、最大入力サイズでおおよそ (5\cdot10^9) 個のペア演算を実行しますが、これは制限時間内に収まるサイズをはるかに超えています。 振幅と位相は実数であるため、浮動小数点演算が必要であり、要求された (10^{-6}) 許容誤差は、不必要に不安定な計算を避ける必要があることを意味します。 

不注意な実装が失敗する可能性のあるエッジケースがいくつかあります。 

1 つ目は位相ラッピングです。 考慮する```
2 1
1 6.2
1 0.1
```2 つの位相は (2\pi) と (0) に近いため、それらの合成位相は (2\pi) には近づきませんが、(0) に近づきます。 生の`atan2`結果は負の値になる可能性があり、それを直接印刷すると、必要な位相間隔に違反します。 位相はモジュロ (2\pi) で正規化する必要があります。 

2つ目はキャンセルです。 考慮する```
2 1
1 0
1 3.141592653589793
```2 つの波は正反対であるため、それらの和はゼロ関数になります。 正しい振幅は (0) です。 すべての (\phi) に対して (0\sin(x+\phi)=0) であるため、位相は数学的には無関係です。 堅牢な実装では、計算された振幅がゼロの場合に位相 (0) を返すことができます。 

3つ目は1つのコーディネートのみでのキャンセルです。 例えば、```
2 1
1 0
1 1.5707963267948966
```合計は (\sin x+\cos x=\sqrt2\sin(x+\pi/4)) なので、答えはおよそ```
1.4142135623730951 0.7853981633974483
```のみを使用する式`atan(y/x)`象限が失われ、間違った位相が生成される可能性があります。`atan2`両方の座標から角度を決定するため、 が必要になります。 

## アプローチ

 この問題を考える簡単な方法は、一度に 2 つの波を結合することです。 同じ周波数を持つ 2 つの波が 1 つの等価な波で表現できることがすでにわかっているとします。 最初の 2 つを結合し、その結果を 3 番目と結合し、次に 4 番目と結合する、というように行うことができます。 その逐次バージョンはすでに線形ですが、文字通りの総当たり実装では、次の組み合わせを選択する前に、残りの波のすべてのペアの結果を繰り返し再計算する可能性があります。 このような手順では、波のペアごとに 1 つのペアの組み合わせが実行され、次のようになります。 

[
 \frac{n(n-1)}2
 】

 組み合わせ。 (n=10^5) の場合、つまり (4,999,950,000) 個の組み合わせであるため、個々の組み合わせはすべて定数時間であるにもかかわらず、アプローチは非常に遅すぎます。 その正しさは加算の結合性によってもたらされますが、同じ部分和を繰り返し表現することで作業を無駄にします。 

この無駄な作業を取り除く観察は、中間の振幅と位相の保存を完全に停止することです。 角度加算恒等式を使用して 1 つの波を展開します。 

A_i\sin x\cos\phi_i
 +
 A_i\cos x\sin\phi_i,
 】

 ここで、(x=\オメガ t)。 

したがって、すべての波は、同じ 2 つの基底関数 (\sin x) と (\cos x) の線形結合にすぎません。 すべての係数を個別に追加できます。 

[
 S=\sum_i A_i\cos\phi_i,
 \qquad
 C=\sum_i A_i\sin\phi_i。 
】

 合計額は次のようになります

 [
 f(t)=S\sin(\オメガt)+C\cos(\オメガt)。 
】

 次に、目的の単一の波形を展開します。 

A\cos\phi\sin x+A\sin\phi\cos x。 
】

 係数を一致させると、

 [
 A\cos\phi=S、
 \qquad
 A\sin\phi=C.
 】

 したがって、振幅はベクトル ((S,C)) の長さになります。 

[
 A=\sqrt{S^2+C^2}。 
】

 位相はそのベクトルの方向です。 

[
 \phi=\オペレーター名{atan2}(C,S)。 
】

 これが中心的な考え方です。 すべての元の波は 1 つの 2 次元ベクトル ((A_i\cos\phi_i,A_i\sin\phi_i)) に寄与します。 波を追加することは、これらのベクトルを追加することとまったく同じです。 最終的な振幅はベクトルの長さであり、最終的な位相はベクトルの方向です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースペアの組み合わせの繰り返し | (O(n^2)) | (O(1)) | 遅すぎる |
 | 係数の累積 | (O(n)) | (O(1)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. (n) と共通周波数 (\omega) を読み取ります。 (\omega) の値は、すべての波がまったく同じ周波数を持ち、最終的な信号では変更されないため、その後は必要ありません。 
2. 2 つのアキュムレータ (S=0) と (C=0) を初期化します。 各波について、(A_i\cos\phi_i) を (S) に加算し、(A_i\sin\phi_i) を (C) に加算します。 

これら 2 つの値は、完全な合計における (\sin(\omega t)) と (\cos(\omega t)) の係数とまったく同じであるため、個々の波を保存する必要はありません。 
3. 最終振幅を次のように計算します。 

[
 A=\sqrt{S^2+C^2}。 
】

 これは、方程式 (S=A\cos\phi) と (C=A\sin\phi) から導き出されます。これらを二乗して加算すると (S^2+C^2=A^2) が得られるからです。 
4.次のように位相を計算します。 

[
 \phi=\オペレーター名{atan2}(C,S)。 
】

 引数は意図的にこの順序になっています。`atan2(y, x)`ベクトル ((x,y)) の方向を返します。ベクトルは ((S,C)) です。 
5. 位相が返された場合`atan2`負の場合は、(2\pi) を加算します。 これにより、角度が必要な間隔 ([0,2\pi)) に変換されます。 
6. 振幅と正規化された位相を十分な精度で出力します。 Python の倍精度浮動小数点演算は、必要な (10^{-6}) エラーに対して十分に対応できます。 

### なぜ効果があるのか

 すべての入力波を処理した後、アキュムレータは次の条件を満たします。 

[
 S=\sum_i A_i\cos\phi_i
 】

 そして

 [
 C=\sum_i A_i\sin\phi_i。 
】

 角度加算恒等式を使用すると、元の合計は正確に次のようになります。 

[
 S\sin(\オメガ t)+C\cos(\オメガ t)。 
】

 アルゴリズムは、(A\cos\phi=S) と (A\sin\phi=C) を満たす (A=\sqrt{S^2+C^2}) と (\phi=\operatorname{atan2}(C,S)) を選択します。 これら 2 つの等式を (A\sin(\omega t+\phi)) に代入すると、すべての入力波の合計とまったく同じ式が生成されます。 したがって、返された振幅と位相は、必要な等価信号を表します。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    n, omega = input().split()
    n = int(n)
    omega = float(omega)

    s = 0.0
    c = 0.0

    for _ in range(n):
        a, phi = map(float, input().split())
        s += a * math.cos(phi)
        c += a * math.sin(phi)

    amplitude = math.hypot(s, c)
    phase = math.atan2(c, s)

    if phase < 0.0:
        phase += 2.0 * math.pi

    print(f"{amplitude:.12f} {phase:.12f}")

if __name__ == "__main__":
    solve()
```最初の行は、波の数と共通の周波数を読み取ります。 それでも`omega`入力形式に属しているため解析されますが、計算には入りません。 これは、すべての波が同じ周波数を共有していることの直接的な結果です。 

このループは、アルゴリズムからの係数の累積を実装します。`math.cos(phi)`(\sin(\omega t)) の係数に寄与しますが、`math.sin(phi)`(\cos(\omega t)) の係数に寄与します。 変数には名前が付けられます`s`そして`c`これらの累積された係数に従って。`math.hypot(s, c)`数値的に堅牢な方法で (\sqrt{s^2+c^2}) を計算します。 また、平方根式を手動で記述する必要がなく、浮動小数点の大きさを扱う場合に適しています。 

位相計算には次のものを使用します。`atan2(c, s)`それよりも`atan(c / s)`。 後者は常に象限を失います`s`が負であり、次の場合にはゼロ除算の問題も発生します。`s`はゼロです。`atan2`両方のケースを直接処理します。 

正規化では、結果が負であるかどうかのみがチェックされます。`atan2`は ([-\pi,\pi]) の角度を返すため、(2\pi) を 1 回加算するだけで ([0,2\pi)) に代入できます。 浮動小数点の丸めにより、理論的には振幅ゼロが非常に小さくなる可能性がありますが、振幅ゼロの波の位相は任意であるため、正確性の問題は発生しません。 

整数の乗算や大きな整数配列は関係しないため、整数のオーバーフローは無関係です。 最大の合計は (10^7) 程度であり、Python の倍精度浮動小数点型で簡単に表現できます。

```振幅がゼロの場合、位相は物理的な意味を持たないため、許容される間隔内のどの位相も同じ波を表します。 ゼロを返すのは便利な正規の選択です。

2 1
1 3.141592653589793
1 1.5707963267948966
