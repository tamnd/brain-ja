 ## 解決策
 ## 問題の理解

 いくつかの正弦波があり、すべて同じ角周波数で振動しています。 波間で異なるのは、振幅と位相だけです。 それらの合計を同じ周波数を持つ 1 つの正弦波に置き換え、その振幅と位相を報告する必要があります。 

波 (i) の場合、

 [
 f_i(t)=A_i\sin(\omega t+\phi_i)。 
】

 完全な信号は次のとおりです

 [
 f(t)=\sum_{i=1}^{n} A_i\sin(\omega t+\phi_i),
 】

 そして、次のような値 (A\ge 0) と (0\le\phi<2\pi) が必要です。 

[
 f(t)=A\sin(\オメガ t+\ファイ)
 】

 (t) ごとに。 

すべての波が同じ周波数を持つことを認識すると、周波数 (\omega) は実際には計算とは無関係になります。 課題は、振幅と位相を効率的に結合することです。 

(n\le 10^5) を使用すると、(O(n)) アルゴリズムは 2 秒の制限の意図した範囲内に問題なく収まります。 (O(n^2)) メソッドでは、最大入力サイズで約 (10^{10}) 個の基本演算が必要になりますが、これは制限時間内に収まる量をはるかに超えています。 入力の振幅と位相は実数であるため、実装では浮動小数点演算を使用し、必要な (10^{-6}) 精度を尊重する必要もあります。 

通常、合理的な実装が失敗する原因となるエッジ ケースが 3 つあります。 一つ目はキャンセルです。 考慮する```
2 1
1 0
1 3.141592653589793
```2 つの波は反対なので、その和はちょうどゼロになります。 正しい結果は```
0 0
```(A=0) の場合、位相は効果がなく、(0) が有効な選択であるためです。 不用意に実装すると、`atan2(0, 0)`実装依存の解釈が得られるか、小さな数値振幅と任意の位相が生成される可能性があります。 

2 番目の問題は、フェーズの象限です。 のために```
1 1
1 4.71238898038469
```答えは、ほぼ同じ振幅と位相です。```
1 4.71238898038469
```以来`atan2`([-\pi,\pi]) の値を返しますが、(3\pi/2) の代わりに (-\pi/2) を返す場合があります。 数学的位相は同等ですが、必要な出力範囲は特に ([0,2\pi)) であるため、負の角度は正規化する必要があります。 

3 番目の問題は、蓄積された 2 つのコンポーネントのキャンセルです。 例えば、```
2 1
100 0
100 3.141592653589793
```再びゼロが生成されるはずです。 中間のサイン成分とコサイン成分は、大きな正と負の寄与が相殺されるため、非常に小さくなる可能性があります。 このソリューションでは、最終振幅が実質的にゼロになる場合を除き、浮動小数点値の正確な同等性に基づいて決定を行うべきではありません。 

## アプローチ

 この問題を考えるための直接的だが不必要にコストがかかる方法は、完全な信号をさまざまな時点で評価することです。 選択した時間 (t) ごとに、すべて (n) 個の波を計算し、それらを加算します。 (n) 個のサンプル時間を使用すると、(n) 波の (n) 回の評価が必要となり、(O(n^2)) 個の仕事が得られます。 (n=10^5) では、約 (10^{10}) 回の波評価に相当し、これでは非常に遅すぎます。 

すべての個々の波がその定義に従って正確に評価されるため、総当り的なアプローチは正しいため、計算されたサンプルは実際には必要な合計のサンプルになります。 問題は、共通の周波数により、任意のサンプルが必要とするよりもはるかに多くの構造が得られることです。 

重要な観察は角度加算恒等式です

 [
 \sin(x+\phi)=\sin x\cos\phi+\cos x\sin\phi.
 】

 それをあらゆる波に適用すると、

 A_i\cos\phi_i\sin(\omega t)
 +
 A_i\sin\phi_i\cos(\omega t)。 
】

 すべての波は、同じ 2 つの基底関数 (\sin(\omega t)) と (\cos(\omega t)) を使用して表現されるようになりました。 それらの係数を加算するだけで済みます。 

定義する

 [
 C=\sum_{i=1}^{n} A_i\cos\phi_i
 】

 そして

 [
 S=\sum_{i=1}^{n} A_i\sin\phi_i。 
】

 完全な信号は次のようになります。 

[
 f(t)=C\sin(\オメガt)+S\cos(\オメガt)。 
】

 次に、目的の単一の波形を展開します。 

A\cos\phi\sin(\omega t)
 +
 A\sin\phi\cos(\omega t)。 
】

 2 つの係数を一致させると、次のようになります。 

[
 A\cos\phi=C、
 \qquad
 A\sin\phi=S.
 】

 これら 2 つの方程式は、座標 ((C,S)) を持つベクトルを記述します。 その長さは結果として生じる振幅であり、

 [
 A=\sqrt{C^2+S^2}、
 】

 そしてその方向は結果として生じる位相であり、

 [
 \phi=\オペレータ名{atan2}(S,C)。 
】

 したがって、問題全体は、入力を 1 回通過して 2 つの実数を累積することになります。 

同じ洞察をベクトルの加算とみなすこともできます。 各正弦波 (A_i\sin(\omega t+\phi_i)) は、長さ (A_i) と角度 (\phi_i) のベクトルに対応します。 波を追加するということは、これらのベクトルを追加することを意味します。 結果として得られるベクトルの長さは (A)、方向は (\phi) です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(n^2)) | (O(1)) | 遅すぎる |
 | 最適 | (O(n)) | (O(1)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つのアキュムレータ (C=0) と (S=0) を初期化します。 それぞれ (\sin(\omega t)) と (\cos(\omega t)) の係数を保存します。 
2. すべての入力波について、(A_i\cos\phi_i) を計算し、(C) に追加します。 (A_i\sin\phi_i) を計算し、(S) に加算します。 

これが中心的な変革です。 波の共通周波数はすべての波が同じ 2 つの基底関数を使用することを意味するため、実際の時間 (t) で波を評価する必要はありません。 
3. すべての波が処理された後、次の計算を行います。 

[
 A=\sqrt{C^2+S^2}。 
】

 値 (C) と (S) は正確に (A\cos\phi) と (A\sin\phi) であるため、それらのユークリッド長が振幅でなければなりません。 

1. (A) が事実上ゼロの場合、出力 (0) および位相 (0)。 

振幅ゼロの正弦波は、その位相に関係なくまったくゼロであるため、位相 (0) が有効な標準的な選択となります。 これにより、ゼロ ベクトルの方向を尋ねる必要もなくなります。 
2. それ以外の場合は計算します

 [
 \phi=\オペレータ名{atan2}(S,C)。 
】`atan2`通常の代わりに必要です`atan(S/C)`なぜなら、それは両方の成分の符号を知っており、その結果として正しい象限を決定するからです。 

1. 位相が負の場合、それに (2\pi) を加算します。 次に、(10^{-6}) エラー要件を満たすのに十分な 10 進数の (A) と (\phi) を出力します。 

### なぜ効果があるのか

 すべての波形を処理した後、アキュムレータは次の条件を満たします。 

[
 C=\sum_i A_i\cos\phi_i
 】

 そして

 [
 S=\sum_i A_i\sin\phi_i。 
】

 角度加算恒等式により、元の合計は次のようになります。 

[
 f(t)=C\sin(\オメガt)+S\cos(\オメガt)。 
】

 計算された振幅と位相は次の条件を満たします。 

[
 A\cos\phi=C
 】

 そして

 [
 A\sin\phi=S.
 】

 これら 2 つの等式を次のように代入すると、

 [
 A\sin(\オメガ t+\ファイ)
 】

 は正確に (C\sin(\omega t)+S\cos(\omega t)) を生成します。これは元の合計です。 したがって、結果として得られる正弦波は、選択されたサンプル点だけでなく、(t) のすべての可能な値に対して等価になります。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

n, omega = input().split()
n = int(n)
omega = float(omega)

c = 0.0
s = 0.0

for _ in range(n):
    a, phi = map(float, input().split())
    c += a * math.cos(phi)
    s += a * math.sin(phi)

amplitude = math.hypot(c, s)

if amplitude < 1e-12:
    phase = 0.0
else:
    phase = math.atan2(s, c)
    if phase < 0.0:
        phase += 2.0 * math.pi

print(f"{amplitude:.12f} {phase:.12f}")
```最初の行は次のようになります`n`そして`omega`。 の値`omega`は入力形式の一部であるため解析されますが、後の計算では表示されません。 すべての波が同じ周波数を持つと、その振幅と位相のみが追加する必要がある係数ベクトルを決定します。 

変数`c`そして`s`は、アルゴリズムで導出された 2 つの係数に直接対応します。 各波について、コードはその水平成分 (A_i\cos\phi_i) と垂直成分 (A_i\sin\phi_i) を計算し、それらをそれぞれのアキュムレータに加算します。`math.hypot(c, s)`(\sqrt{c^2+s^2}) を計算します。 式を手動で記述することをお勧めします。`hypot`ベクトルの長さを確実に計算するように設計されています。 

ゼロチェックでは、チェックではなく非常に小さな許容値が使用されます。`amplitude == 0`。 浮動小数点キャンセルでは、小さな残差値で表される数学的にゼロの結果が残ることがあります。 振幅がゼロの場合はどの位相も有効であるため、位相 (0) を選択すると安定した有効な出力が得られます。 

ゼロ以外の結果の場合、`atan2(s, c)`ベクトルの角度 ((c,s)) を返します。 結果は ([-\pi,\pi]) にありますが、問題では ([0,2\pi)) が必要です。 負の結果に (2\pi) を加算すると、必要な範囲に変換されます。 正確に (2\pi) の結果は次からは発生しません。`atan2`、 (2\pi) の加算は負の値に対してのみ実行されるため、上限は有効なままです。 

式に周波数を乗算する必要はありません。 必要な出力位相は (A\sin(\omega t+\phi)) の定数 (\phi) であり、時間依存の角度 (\omega t+\phi) ではないため、これは実際には概念的な間違いになります。

import io
import math

def solve():
    input = sys.stdin.readline

    n, omega = input().split()
    n = int(n)
    omega = float(omega)

    c = 0.0
    s = 0.0

    for _ in range(n):
        a, phi = map(float, input().split())
        c += a * math.cos(phi)
        s += a * math.sin(phi)

    amplitude = math.hypot(c, s)

    if amplitude < 1e-12:
        phase = 0.0
    else:
        phase = math.atan2(s, c)
        if phase < 0.0:
            phase += 2.0 * math.pi

    print(f"{amplitude:.12f} {phase:.12f}")

    old_stdout = sys.stdout

    sys.stdout = io.StringIO()

        return sys.stdout.getvalue().strip()

 ## 特殊なケース

 完全なキャンセルは振幅ゼロ分岐によって処理されます。 のために```
2 1
1 0
1 3.141592653589793
```最初の波が寄与します ((C,S)=(1,0))。 2 番目のベクトルは ((-1,0)) に寄与するため、最終的なベクトルは ((0,0)) になります。 その振幅はゼロであり、アルゴリズムは位相ゼロを出力します。 両方の波が同じ周波数を持っているため、周波数によってこの結論は変わりません。 

第 4 象限のフェーズでは、よくある間違いが明らかになります。`atan2`。 のために```
1 1
1 4.71238898038469
```蓄積された成分はおよそ

 [
 C=0、\qquad S=-1。 
】`atan2(-1,0)`(-\pi/2) を返します。 必要な位相は非負でなければならないため、アルゴリズムは (2\pi) を加算して (3\pi/2) を取得します。これはまさに元の位相です。 

浮動小数点のキャンセルも安全に処理されます。 考慮する```
2 1
100 0
100 3.141592653589793
```数学的には、ベクトルの寄与は ((100,0)) と ((-100,0)) です。 浮動小数点演算では、2 番目の正弦は必ずしも正確にゼロとして表されるわけではないため、最終ベクトルには小さな残差が含まれる可能性があります。 の`1e-12`しきい値は、そのような残差をゼロ ベクトルとして扱います。 必要な数値許容誤差は (10^{-6}) であるため、意味のあるゼロ以外の結果は破棄されません。 

最後に、位相境界自体は、正規化ステップを超えて特別な処理を必要としません。 (2\pi) に近づく位相のベクトルは正 (C) 軸の真下を指しますが、ゼロのすぐ上の位相はその真上を指します。`atan2`これらの標識を正しく区別します。 正規化では、表現された正弦波は変更せずに、負の表現を ([0,2\pi)) の同等の値に変更するだけです。
