 ## 解決策
 ## 問題の理解

 を取り揃えております。`N`AQI 予測。連続した日ごとに 1 つの値。 また、最初の配列要素に対応する曜日としきい値もわかります。`X`。 授業日は、AQI が少なくとも以下の場合に停止されます。`X`。 土日は、AQI がしきい値に達した場合でもカウントされません。 

タスクは、AQI が少なくとも以下である配列の位置をカウントすることです。`X`対応する平日は月曜日から金曜日です。 

最初の行にはいくつでも含めることができます`10^6`日々。 これにより、配列を繰り返しスキャンしたり、位置ごとに初日からの距離に比例した作業を実行したりするアルゴリズムが即座に排除されます。 アン`O(N)`すべての AQI 値を少なくとも 1 回検査する必要があるため、scan が自然なターゲットになります。 と`N = 10^6`、`O(N log N)`この解決策は依然として数学的に合理的ですが、ここでは何のメリットもありません。`O(N^2)`大まかに必要とすることができます`5 * 10^11`繰り返しが行われ、1 秒の制限をはるかに超えています。 

AQI 値としきい値は次の範囲内にあります。`0`そして`500`したがって、答えには整数オーバーフローの懸念はありません。 せいぜい`10^6`日数を数えることができます。 

最初の明白ではないケースは、初日が週末である場合です。 例えば：```
1 Saturday 100
100
```正しい答えは、`0`。 チェックだけをするいい加減な実装`AQI >= X`戻るだろう`1`、土曜日に授業がないことを忘れています。 

2 番目のケースは、しきい値の比較が包括的な場合です。 例えば：```
1 Monday 100
100
```正しい答えは、`1`、AQI が次とまったく等しいため、`X`授業を中止します。 使用する`>`の代わりに`>=`間違って戻ってきます`0`。 

3 番目のケースは、スキャン中に日曜日をまたぐ場合です。 例えば：```
3 Friday 100
100 100 100
```曜日は金曜日、土曜日、日曜日なので、答えは次のようになります。`1`。 最初の曜日のみをチェックし、配列の位置ごとに曜日を進めるのを忘れた実装では、3 つの値すべてが誤ってカウントされる可能性があります。 

## アプローチ

 直接的な総当たりアプローチでは、各アレイ位置の曜日を個別に決定できます。 ポジションについて`i`、指定された最初の平日から開始し、位置に到達するまでカレンダーを 1 日ずつ進めます。`i`。 次に、その平日が平日であるかどうかを確認します。`a[i] >= X`。 

このアプローチは、すべての配列要素の正確な曜日を再構築するため、正しいです。 問題は、同じカレンダー作業を繰り返すことです。 ポジションについて`0`地位のために昇進は必要ありません`1`1つの昇進が必要であり、ポジションのためには`N - 1`、`N - 1`進歩が必要です。 平日の前売りの合計数は、`0 + 1 + 2 + ... + (N - 1) = N(N - 1)/2`。 

で`N = 10^6`、つまり`499,999,500,000`AQIチェックを考慮する前に、平日の前倒し。 それでは制限時間内に収まりません。 

重要な観察は、連続する配列位置が連続する暦日を表すということです。 ポジションの曜日がわかったら`i`、ポジションの平日`i + 1`は単に 7 日サイクルの次の平日です。 カレンダーを最初から再計算する必要はありません。 

月曜日から日曜日までを整数で表すことができます`0`を通して`6`。 すべての AQI 値について、2 つの条件をチェックします。AQI は少なくとも次の条件を満たす必要があります。`X`、現在の平日は次のいずれかである必要があります。`0, 1, 2, 3, 4`。 値を処理した後、次のようにして平日を進めます。`(weekday + 1) % 7`。 

ブルート フォース メソッドと最適なメソッドはどちらも AQI 値を検査しますが、最適なメソッドはカレンダーの同じプレフィックスを繰り返し再構築するのではなく、1 日あたり一定の作業のみを実行します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |

 | ブルートフォース | O(N²) | お(1) | 遅すぎる |
 | 最適 | O(N) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 月曜日を基準として、7 つの曜日名をカレンダー順に整数にマッピングします。`0`そして日曜日は`6`。 これにより、次の日に移動するのは単なる増分モジュロであるというコンパクトな表現が得られます。`7`。 
2.読む`N`、最初の曜日の名前、およびしきい値`X`。 開始曜日の名前を整数表現に変換します。 
3. を読んでください。`N`AQI 値を左から右に処理します。 位置で`i`、変数`weekday`実際の平日を表します`a[i]`。 
4. もし`weekday < 5`そして`a[i] >= X`、答えを増やします。 最初の条件では土曜日と日曜日が除外され、2 番目の条件では一時停止のしきい値が指定どおりに適用されます。 
5. 前進`weekday`使用して`(weekday + 1) % 7`。 これは月曜日から火曜日、火曜日から水曜日というように移動し、日曜日は月曜日に戻ります。 
6. 結局最終的なカウントを出力します`N`日数が処理されました。 

### なぜ効果があるのか

 不変条件は、処理の直前に`a[i]`、`weekday`はちょうど に対応する平日です`i`- 番目の配列要素。 それは最初は正しいので、`weekday`記載の初日より初期化されます。 それが位置に当てはまる場合`i`、一度進めると、次の暦日の平日が表示されます。これは、まさに位置に対応する平日です。`i + 1`。 したがって、不変式はすべての位置に当てはまります。 

各ポジションについて、アルゴリズムは、AQI が少なくとも以下の場合に正確に回答を増分します。`X`そしてその日は月曜日から金曜日までです。 これらはまさに授業が停止される条件であるため、カウントされたすべての日が有効であり、すべての有効な日がカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    day_to_num = {
        "Monday": 0,
        "Tuesday": 1,
        "Wednesday": 2,
        "Thursday": 3,
        "Friday": 4,
        "Saturday": 5,
        "Sunday": 6,
    }

    n, day_name, x = input().split()
    n = int(n)
    x = int(x)

    weekday = day_to_num[day_name]
    answer = 0

    remaining = n
    while remaining:
        values = map(int, input().split())
        for aqi in values:
            if weekday < 5 and aqi >= x:
                answer += 1

            weekday = (weekday + 1) % 7
            remaining -= 1

            if remaining == 0:
                break

    print(answer)

if __name__ == "__main__":
    solve()
```辞書は、テキストの開始曜日をアルゴリズムで使用される整数サイクルに変換します。 月曜日は`0`そして金曜日は`4`、ということで条件は`weekday < 5`5 つの授業日を正確に特定します。 

入力読み取りループには注意が必要です。 問題はすべてを置きますが、`N`2 行目の AQI 値。この行は次のように処理されます。`split()`公式入力には十分です。 また、ループは値を段階的に処理し、AQI 配列全体の保存を回避するため、アルゴリズムの追加スペースが維持されます。`O(1)`。 

カウンター`remaining`これにより、入力が複数行に分割された場合でも処理が堅牢になります。 AQI が消費されるたびに 1 ずつ減少し、処理はその直後に停止します。`N`価値観。 

比較には、`>=`、 ない`>`というのは、AQI がしきい値に等しいだけでクラスを一時停止するのに十分だからです。 現在の AQI がチェックされた後に曜日が繰り上げられるため、最初の AQI は翌日ではなく、指定された開始日に対して評価されます。 この順序により、最も一般的な off-by-one エラーが防止されます。 

この問題では Python の整数はオーバーフローしません。答えは最大でも`10^6`。

 週末の 1 日については、次のことを考慮してください。```

```最初の平日は、`5`、 それで`weekday < 5`は誤りです。 それでも`500 >= 0`、答えは残っています`0`。 その後、アルゴリズムは日曜日に進みますが、これ以上処理する値はありません。

```平日は月曜日で、`100 >= 100`は true なので、答えは次のようになります`1`。 これにより、誤って厳密なメソッドを使用する実装が捕捉されます。`>`比較。
