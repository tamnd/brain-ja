 ## 解決策
 ## 問題の理解

 電圧 (V) の DC 電源とそれに続く抵抗 (R) があります。 抵抗の後、電流は並列接続されたインダクタ (L) とコンデンサ (C) の間で分割されます。 最初は、インダクタ電流とコンデンサ電圧は両方ともゼロです。 

必要な量は抵抗電圧 (V_r(t)) です。 入力が保証されているため、回路はアンダーダンピングになります。 

[
 L < 4R^2C。 
】

 この状態は、時間の経過とともに振幅が減少しながら応答が振動することを意味します。 (V_r(t)) の全体的な最小値と最大値、およびそれらが発生する時刻が必要です。 

入力には 4 つの実数が含まれており、すべてのパラメーターは小さな正の値です。 反復する大きな入力サイズはありません。 関連する課題は、多くの値を処理することではなく、連続時間関数を正確に導出することです。 数値シミュレーションでは十分に小さいタイム ステップを選択する必要があり、(10^{-6}) の精度を確実に達成するには不必要な作業が必要となり、数値的な懸念が生じます。 回路方程式には閉形式の解があるため、極値を直接導出する必要があります。 

不用意に実装すると失敗するケースがいくつかあります。 まず、初期抵抗電圧は (V) ですが、これは発振応答の最小値または最大値ではありません。 たとえば、```
6 3.7 0.3 0.2
```最小値はその後約 (t=0.348848049) で発生し、値は (4.430980248) となるため、単純に (t=0) をチェックすると実際の最小値を見逃します。 

2 番目のトラップは、最初の振動が両方の極値を与えると仮定しています。 内部並列ブロック電圧のゼロ以外の最初の極値は正であり、これは最小抵抗電圧を与えることを意味します。 次の極値は負で、最大抵抗電圧を示します。 振動が減衰するため、後の極値はどれも大きさが小さくなり、最初の 2 つの極値がグローバルな極値となります。 

不足減衰条件の等価境界にも注意が必要です。 (L=4R^2C) の場合、発振周波数はゼロになり、その周波数で除算する式は崩れます。 この問題では厳密な不等式が明示的に保証されているため、実装では過小減衰の式を安全に使用できます。 

## アプローチ

 直接的な数値的アプローチでは、小さなタイム ステップで微分方程式をシミュレートします。 各ステップで、インダクタ電流、コンデンサ電圧、抵抗電圧を計算し、応答の方向の変化を探すことができます。 回路方程式は初期条件から状態を完全に決定するため、これは概念的には有効です。 

問題は、ステップをどの程度小さくする必要があるかを決定することです。 ステートメントにはシミュレーションを停止できる有限の時間制限はなく、必要な誤差は (10^{-6}) です。 シミュレーションでは、振動が減衰するのに十分長い間隔を推定し、同時に極値を正確に特定するために十分に小さなステップを使用する必要があります。 最悪の場合のパラメータ セットの場合、数百万回以上の状態更新が必要になる可能性がありますが、浮動小数点ステップ サイズと停止ヒューリスティックにより、依然として答えの信頼性が低くなる可能性があります。 時間計算量は事実上 (O(T/h)) です。ここで、(T) はシミュレートされた時間、(h) は時間ステップであり、どちらも問題によって修正されません。 

より良いアプローチは、回路方程式を直接記述することです。 (u(t)) を並列インダクタ コンデンサ ブロックの両端の電圧とします。 インダクタとコンデンサは並列であるため、両方とも電圧 (u(t)) を持ちます。 キルヒホッフの電圧則は次のようになります。 

[
 V=V_r(t)+u(t)、
 】

 それで

 [
 V_r(t)=V-u(t)。 
】

 抵抗器を流れる電流は、

 [
 I_r(t)=\frac{V-u(t)}{R}。 
】

 インダクタ電流は次の条件を満たします。 

[
 I_l'(t)=\frac{u(t)}{L},
 】

 コンデンサ電流は

 [
 I_c(t)=Cu'(t)。 
】

 (I_r=I_l+I_c) を使用して微分し、インダクタ方程式を代入すると、次のようになります。 

[
 -\frac{u'}{R}=\frac{u}{L}+Cu''。 
】

 並べ替えた後、

 [
 LCu''+\frac{L}{R}u'+u=0。 
】

 これは標準的な 2 次の不足減衰微分方程式です。 定義する

 [
 \alpha=\frac{1}{2RC}
 】

 そして

 [
 \omega=\sqrt{\frac{1}{LC}-\alpha^2}。 
】

 与えられた不等式は (\omega>0) を保証します。 コンデンサの初期電圧はゼロなので、

 [
 u(0)=0。 
】

 時間ゼロでは、インダクタ電流もゼロになります。 したがって、初期抵抗電流全体がコンデンサに入ります。 

[
 I_r(0)=\frac{V}{R}=Cu'(0)、
 】

 それは与える

 [
 u'(0)=\frac{V}{RC}=2\alpha V.
 】

 解決策は結果的に、

 [
 u(t)=\frac{2\alpha V}{\omega}e^{-\alpha t}\sin(\omega t)。 
】

 したがって、

 [
 V_r(t)=V-\frac{2\alpha V}{\omega}e^{-\alpha t}\sin(\omega t)。 
】

 現在、連続最適化問題は単純な微分計算になりました。 極値は満足する

 [
 V_r'(t)=0、
 】

 または等価です (u'(t)=0)。 差別化すると得られるもの

 [
 u'(t)=
 \frac{2\alpha V}{\omega}e^{-\alpha t}
 \left(\omega\cos(\omega t)-\alpha\sin(\omega t)\right)。 
】

 指数係数は決してゼロではないので、必要なのは

 [
 \omega\cos(\omega t)-\alpha\sin(\omega t)=0。 
】

 したがって、

 [
 \tan(\omega t)=\frac{\omega}{\alpha}。 
】

 しましょう

 [
 \theta=\arctan\left(\frac{\omega}{\alpha}\right)。 
】

 すべての極値は次の場所で発生します。 

[
 t_k=\frac{\theta+k\pi}{\omega}。 
】

 最初の (k=0) は (\sin(\omega t)) を正にするため、(u(t)) は正となり、(V_r(t)=V-u(t)) は最小になります。 次の (k=1) は (u(t)) を負にするため、最大の抵抗電圧が得られます。

後続のすべての極値は同じ交互の符号を持ちますが、係数 (e^{-\alpha t}) のため大きさは小さくなります。 したがって、最初の 2 つの極値はグローバル最小値と最大値です。 

結果として得られるソリューションでは、一定数の算術演算と三角関数演算が使用されます。

 | --- | --- | --- | --- |
 | 数値シミュレーション | (O(T/h)) | (O(1)) | 遅すぎて精度に敏感 |
 | クローズドフォームのソリューション | (O(1)) | (O(1)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. (V)、(R)、(L)、(C) を読み取ります。 入力と必要な出力は実数であるため、すべての計算では浮動小数点演算を使用する必要があります。 
2. 減衰係数を計算します。 

[
 \alpha=\frac{1}{2RC}。 
】

 これは振動の指数関数的な減衰率です。 

1. 減衰角周波数を計算します。 

[
 \omega=\sqrt{\frac{1}{LC}-\alpha^2}。 
】

 厳密な問題条件により、平方根の下の値が正であることが保証されます。 

1. コンピューティング

 [
 \theta=\arctan\left(\frac{\omega}{\alpha}\right)。 
】

 最初の極値は (\omega t=\theta) のときに発生します。これは、微分方程式の最小の正の解であるためです。 

1.セット

 [
 t_{\min}=\frac{\theta}{\omega}。 
】

 この時点で、並列ブロックの電圧は正であるため、抵抗電圧は (V) を下回り、グローバル最小値に達します。 

1.セット

 [
 t_{\max}=\frac{\theta+\pi}{\omega}。 
】

 次の静止点は 1/2 振動後です。 正弦項の符号が変わり、並列ブロックの電圧が負になり、抵抗の電圧が (V) より大きくなります。 

1. 評価する

 [
 V_r(t)=V-\frac{2\alpha V}{\omega}e^{-\alpha t}\sin(\omega t)
 】

 この２回の時に。 1 行目に最小時間と値を出力し、2 行目に最大時間と最大値を出力します。 

### なぜ効果があるのか

 抵抗電圧は (V-u(t)) です。ここで、(u(t)) は振幅が指数関数的に減少する減衰正弦波です。 その静止点は (\tan(\omega t)=\omega/\alpha) のときに正確に発生し、正と負の極値が交互に並びます。 指数係数は時間とともに厳密に減少するため、後のすべての極値の大きさは、前の極値よりも小さくなります。 したがって、(u) の最初の正の極値は (V_r) の全体的な最小値を生成し、最初の負の極値はその全体的な最大値を生成します。 このアルゴリズムは、閉形式の解からこれら 2 つの点を正確に計算します。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    V, R, L, C = map(float, input().split())

    alpha = 1.0 / (2.0 * R * C)
    omega = math.sqrt(1.0 / (L * C) - alpha * alpha)

    theta = math.atan(omega / alpha)

    t_min = theta / omega
    t_max = (theta + math.pi) / omega

    amplitude = 2.0 * alpha * V / omega

    def resistor_voltage(t):
        return V - amplitude * math.exp(-alpha * t) * math.sin(omega * t)

    v_min = resistor_voltage(t_min)
    v_max = resistor_voltage(t_max)

    print(f"{t_min:.12f} {v_min:.12f}")
    print(f"{t_max:.12f} {v_max:.12f}")

if __name__ == "__main__":
    solve()
```コードの最初の部分では、減衰振動を完全に特徴付ける (\alpha) と (\omega) を計算します。 入力は (L<4R^2C) を保証しているため、式は に渡されます。`sqrt`はポジティブです。 

値`theta`逆正接の主値です。 (\omega) と (\alpha) は両方とも正なので、`theta`厳密に (0) と (\pi/2) の間にあります。 それにより、`theta / omega`接線方程式の任意の解ではなく、最初の正の定常時間を使用します。 

最低限の使い方`theta`、最大使用量は`theta + math.pi`。 両方の極値に主逆正接のみを使用すると、2 つの値に対して誤って同じ振動位相が返されます。 

ヘルパー関数は、(V_r(t)) の派生式を直接評価します。 数値積分や時間の離散化がないため、シミュレーションのステップサイズやエンドポイントの問題はありません。 

出力では小数点以下 12 桁が使用されます。 これは、(10^{-6}) 許容誤差で必要とされる精度よりも大幅に高い精度であり、出力フォーマット中に有用な桁が失われることを回避します。

## 特殊なケース

 最初のエッジ ケースは最初の瞬間です。 考慮する```
1 1 1 1
```(t=0) では、コンデンサ電圧とインダクタ電流は両方ともゼロであるため、抵抗器は最初に完全な電源電圧を受け取り、(V_r(0)=1) になります。 アルゴリズムは、これをグローバル最小値または最大値として誤って扱うことはありません。 抵抗電圧が約 (0.582318) まで低下した (t_{\min}\ほぼ 1.209199577) が検出され、次に電圧が約 (1.090715) になった (t_{\max}\約 4.836798308) が検出されます。 初期値はこれらの極値の間にあります。 

2 番目の特殊なケースは、極値が交互に現れる性質です。 同じ入力の場合、最初の静止点は次のようになります。 

[
 \omega t=\frac{\pi}{3}、
 】

 したがって、正弦は正です。 したがって、(u(t)>0) かつ (V_r(t)<V) となります。 次の静止点には位相があります

 [
 \frac{4\pi}{3}、
 】

 ここで、サインは負であるため、(V_r(t)>V) となります。 主逆正接のみを使用する不注意な実装では、オーバーシュートは決して見つかりません。 

3 番目のエッジ ケースは、許容境界に近い強い減衰です。 考慮する```
20 20 0.1 20
```ここ

 [
 \alpha=\frac{1}{800}=0.00125、
 】

 while

 [
 \omega=\sqrt{\frac{1}{2}-0.00125^2}、
 】

 そのため、システムは依然として振動していますが、その減衰係数は固有振動数に比べて小さいです。 厳密な不等式により (\omega) が正のままであることが保証されるため、アルゴリズムは安全に平方根を評価し、(\omega) で除算できます。 

最後に、次のような大きなパラメータ値を考慮します。```
20 20 20 20
```Python の浮動小数点値は必要な中間量を簡単に表すため、整数オーバーフローを心配することなく同じ式が適用されます。 このアルゴリズムは、長い値のシーケンスを乗算したり、時間をかけて反復したりしないため、パラメーターの大きさによって累積誤差が発生することはありません。
