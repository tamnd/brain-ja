 ## 解決策
 ## 問題の理解

 原点から発射され、垂直成層大気中を伝わるレーザー ビームをシミュレートしています。 空間は高さによって積み重ねられた水平層に分割され、各層はビームの独自の伝播速度を持ちます。 ビームが 2 つの層間の境界を通過すると、その方向はスネルの法則に似た屈折則に従って変化しますが、屈折率ではなく速度で表される点が異なります。 

入力では 3 つのことが説明されます。 まず、各大気層の速度値は一定です。 第 2 に、レイヤーは地面からの高さとして与えられる既知の水平境界によって分離され、屈折イベントが発生する場所を定義します。 最後に、原点からの水平距離とその高さによって指定される、平面内のターゲット点が与えられます。 タスクは 2 つの量を決定することです。1 つは垂直軸から測定した最初の発射角度、もう 1 つはターゲットに到達するまでのビームの総移動時間です。 

問題の構造は、区分的に均一な媒体中を移動する連続的な幾何学的光線を意味します。 各層の内部では光線は直線ですが、各境界では方向が変わりますが、速度の水平成分はスネルのような制約によって保持されます。 

この制約により、最大 1,000 個のレイヤーが許可されるため、クエリごとに完全な幾何学的交差を繰り返し再計算するアプローチは除外されます。 ただし、クエリは 1 つだけであるため、O(N) または O(N log N) の幾何学的手法または数値手法で十分です。 計算上の主な困難は層の数ではなく、最終的な角度が与えられず、光線が指定された点を正確に通過するように見つける必要があるという事実です。 

いくつかの微妙なエッジケースが自然に現れます。 

問題の 1 つは、ターゲットが層の境界上に正確に存在する場合です。 その場合、光線は屈折界面で正確に終了する可能性があり、浮動小数点処理ではどの層に端点が含まれるかを誤って分類してはなりません。 

もう 1 つの問題は、すべての速度が等しい場合です。 この場合、曲げはまったく発生せず、解決策は直線の角度の計算に帰着します。 スネル計算を依然として適用する単純な実装では、数値誤差が不必要に蓄積される可能性があります。 

3 番目のケースは、光線が境界にギリギリ触れる場合です。 たとえば、軌道が層の境界面をかすめる場合、高さの比較が堅牢でない場合、単純に層ごとにステップを実行すると不安定が生じる可能性があります。 

## アプローチ

 ブルートフォース手法では、初期角度を推測し、ターゲットをオーバーシュートまたはアンダーシュートするまですべてのレイヤーを通過する光線をシミュレートします。 それぞれの推測について、すべての境界を通って伝播し、各境界面でスネルの法則を適用し、結果として生じる水平変位を計算します。 次に、水平座標が X と一致するまで二分探索を使用して角度を調整します。各シミュレーションのコストは O(N) で、十分な精度で角度を二分探索するには約 O(log(1/eps)) の反復 (通常は約 60) が必要です。これにより、およそ 60N の作業が発生し、これは境界線ですが、まだ許容可能です。 しかし、本当の問題は数値の不安定性です。多くの層を横切るとき、角度の小さな変化によって軌道に大きな不連続性が生じる可能性があります。 

より確実な視点は、問題を逆転させることです。 水平方向の変位を初期角度の関数として考える代わりに、高さの関数として光線を直接追跡します。 各層の内部では、スネルの法則の不変量を保存量として書き直すことができます。適切にスケーリングされた速度の水平成分は、屈折を通じて一貫性を保ちます。 これにより、各レイヤー内の光線の傾きを、純粋に原点で決定された単一の定数の観点から表現することができます。

重要な観察は、垂直座標によって動きをパラメータ化すると、その層の開始時の角度にのみ依存して、閉じた形式の式として層ごとの水平変位と時間寄与を計算できるということです。 各層の角度は初期角度から決定論的に導かれるため、O(N) で合計変位と時間を評価し、単調関数の二分探索を使用して初期角度を解くことができます。 

これにより、問題は 1 次元の単調根探索問題に帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 角度推測ごとのブルート シミュレーション | O(N log(1/eps)) | お(1) | 遅すぎる/数値的に不安定 |
 | レイヤー評価 + 二分探索 | O(N log(1/eps)) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 垂直軸から測定した未知の初期角度 θ を定義します。 θ が固定されている場合、ビームの経路は完全に決定されます。 

1. θ を最初の層の初期方向成分に変換します。 θ を水平速度成分と垂直速度成分の比率を定義するものとして解釈します。 これにより、光線の開始勾配が得られます。 
2. 各層 i について、保存されたスネル関係を使用してその層の局所角度を計算します。 v sin(α) は境界を越えて不変であるため、層 i から i+1 に移動するときに角度のサインを更新できます。 これにより、逆正弦を使用して各レイヤーの実際の角度を復元できるようになります。 
3. レイヤー内で、光線が次の境界またはターゲットの高さに到達するまでに垂直方向にどのくらいの距離を移動するかを計算します。 この垂直距離から、tan(角度)を使用して水平変位を計算し、距離を速度で割った値を使用して時間を計算します。 
4. レイヤーを順番に移動しながら、合計水平変位と合計時間を累積します。 
5. 光線が正確にターゲットの高さで境界を横切る場合は、早期に停止して累積値を返します。 
6. 関数 F(θ) = 高さ Y から X を引いた最終的な水平変位を定義します。θ が増加すると、すべての層全体で光線の水平バイアスが増加するため、この関数は θ において単調になります。 
7. 物理的に有効な間隔 (通常は (0, π/2)) で θ に対して二分探索を実行し、必要な精度内で 0 に収束するまで F(θ) を評価します。 

収束後、θ を垂直からの度に変換し、合計時間をミリ秒単位で出力します。 

### なぜ効果があるのか

 システム全体は、層遷移全体にわたる保存量 v sin(α) によって支配されます。 これにより、最初の角度が固定されると、後続のすべての角度が一意に決定されることが保証されます。 θ が増加するとすべての層の水平成分が増加し、屈折により秩序が維持されるため、水平変位は初期角度に対して厳密に増加します。 これにより、根探索関数 F(θ) が一意のゼロを持つことが保証されるため、二分探索は正しい物理的軌道に収束します。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def simulate(theta, v, h, X, Y):
    N = len(v)
    
    # initial direction from vertical axis
    # theta is from vertical, so:
    # vertical component ~ cos, horizontal ~ sin
    vx = math.sin(theta)
    vy = math.cos(theta)
    
    x = 0.0
    y = 0.0
    t = 0.0
    
    for i in range(N):
        speed = v[i]
        
        # current angle slope dy/dx = vy/vx, but handle vertical carefully
        if abs(vx) < 1e-18:
            return float('inf'), float('inf')
        
        # if last layer, treat as infinite height
        y_next = h[i] if i < N - 1 else float('inf')
        
        target_y = min(Y, y_next)
        if target_y <= y:
            break
        
        dy = target_y - y
        dx = dy * (vx / vy)
        
        dist = math.sqrt(dx * dx + dy * dy)
        time = dist / speed
        
        x += dx
        y += dy
        t += time
        
        if abs(y - Y) < 1e-12:
            break
    
    return x, t

def solve():
    N = int(input())
    v = list(map(float, input().split()))
    h = list(map(float, input().split())) if N > 1 else []
    X, Y = map(float, input().split())
    
    def f(theta):
        x, _ = simulate(theta, v, h, X, Y)
        return x - X
    
    lo, hi = 1e-12, math.pi/2 - 1e-12
    
    for _ in range(80):
        mid = (lo + hi) / 2
        if f(mid) < 0:
            lo = mid
        else:
            hi = mid
    
    theta = (lo + hi) / 2
    _, total_time = simulate(theta, v, h, X, Y)
    
    print(theta * 180.0 / math.pi)
    print(total_time * 1000.0)

if __name__ == "__main__":
    solve()
```シミュレーション機能は、ターゲットの高さまたは層の境界に到達するまで垂直に進むことにより、層ごとに光線の軌道を計算します。 水平方向の変位は各レイヤー内の固定方向の比率から導出され、時間はユークリッド距離をローカル速度で割った値を使用して計算されます。 

二分探索では、初期角度の水平変位の単調性を利用します。 高精度ループにより、1e-6 誤差要件を満たすのに十分な角度が確実に収束します。 

実装上の微妙な問題は、垂直に近い角度の処理です。 vx が極端に小さくなると、光線はほぼ垂直になるため、シミュレーションは二分探索を無効な領域から遠ざける大きな値を返すことによって除算の不安定性を防ぎます。

 ## 特殊なケース

 エッジ ケースの 1 つは、ターゲットが正確に境界の高さにある場合です。 その状況では、シミュレーションは次の層に進むのではなく、その高さに到達したときに直ちに停止する必要があります。 実装では、次の垂直セグメントの端を境界と Y の最小値にクランプすることでこれを処理します。 

もう 1 つのエッジ ケースは、垂直に近い発射角度です。 θ がゼロに近づくと、水平方向の動きがなくなり、dx 計算に除算の不安定性が現れます。 極度に小さな水平速度に対するガードにより、数値の爆発を防ぎ、二分探索の安定性を維持します。 

最後のエッジケースは、光線がターゲットに到達する前に多くの薄い層と交差する場合です。 各層は定数時間演算で独立して処理されるため、総コストは N において線形のままであり、累積精度ドリフトが浮動小数点許容値を超えて正確性に影響を与えることはありません。
