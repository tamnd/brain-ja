 ## 解決策
 ## 問題の理解

 空のセルと、次のように表される単一の接続されたポリオミノが占めるセルで構成されるグリッドが与えられます。`#`。 形状は固定されており、グリッドの端に沿って切断する以外は変更できません。 

プロセスは次のように機能します。形状から繰り返しピースを削除します。 各除去は、グリッドの端に沿って単一の直線カットによって行われ、接続された 1 つのチャンクが分離されます。 削除されたすべてのチャンクは、まったく同じ形状とサイズでなければなりません。 すべての削除後に最後に残ったチャンクも、同じ形状と一致する必要があります。 一方を回転して他方と一致させることができる場合、ピースは等しいとみなされますが、反転することは許可されません。 

形状を分割できる同一の部分の数を最大化したいと考えています。各部分は、残りの形状から 1 つの部分を切り取ることによって順番に取得されます。 

重要な制約は幾何学的なものです。ポリオミノを恣意的に分割しているのではなく、単一の直線カットの繰り返しと一貫した方法で分割しているため、分解は構造的に単純で再現可能でなければなりません。 

グリッド サイズは最大 300 x 300 であるため、すべてのセルのペアを比較したり、すべてのパーティションを直接試行したりするソリューションは遅すぎます。 すべての部分形状に対する 3 次または高度 2 次のアプローチでさえ、すでに大きすぎます。 

素朴な考えは、形状を k 個の同一の部分に分割し、それぞれの構成が有効かどうかを確認するあらゆる方法を試してみることです。 接続されたグリッド ポリオミノを分割する方法の数が指数関数的に増加するため、これはすぐに実行不可能になります。 

素朴な推論で何が問題となるかを明らかにする重要なエッジケースがいくつかあります。 

1 つの問題は、等しい面積で十分であると仮定することです。 たとえば、形状に 8 つのセルがあり、k = 2 または k = 4 を試した場合、同じサイズの領域が見つかる可能性がありますが、それらは合同ではない可能性があり、カット後に接続さえできない可能性があります。 もう 1 つの問題は、問題がカットを単一の直線分離に制限する場合に、任意のタイリングが許可されると仮定することです。これにより、非常に厳密な分解構造が強制されます。 

3 番目の微妙な点は回転です。 回転するまで同じである 2 つの部分は構造的に同一でなければならないため、慎重に正規化しないと、対称的ではあるが一致しない多くのパーティションが排除されます。 

## アプローチ

 強引な解釈では、考えられるすべての数の部分 k を試し、ポリオミノを等しい面積の k 個の接続された部分形状に分割し、すべてが回転まで合同であることを確認します。 これには、組み合わせ爆発的なグリッド グラフのパーティションを列挙する必要があります。 1 つの候補パーティションをチェックするだけでも、フラッド フィルと形状比較が必要となり、パーティションの数はセルの数で指数関数的に増加します。 

重要な点は、切断プロセスが非常に制限されていることです。 各ピースは、グリッドのエッジに沿って単一の直線カットによって除去されます。つまり、ピースは、層を剥離するように動作する一連の分離内に存在する必要があります。 これにより、任意のタイリングが排除され、最終的な構造が規則的に整列した単一の基本形状の繰り返しになります。 

これにより、ポリオミノが水平ストライプ構造または垂直ストライプ構造のいずれかに配置された繰り返し同一のブロックで構成されているかどうかを検出するという問題が軽減されます。 このような構造では、すべての部分は単一ブロックの変換された (場合によっては回転された) コピーであり、各削除は 1 つの完全なブロック層を切り取ることに対応します。 

したがって、任意のパーティションを検索する代わりに、形状を k 個の等しい連続した水平または垂直セグメントに分割する可能なすべての方法を試し、すべてのセグメントが回転まで同一であるかどうかを検証します。 有効な最大 k が答えを与えます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースパーティショニング | 指数 | O(NM) | 遅すぎる |
 | 正規化によるストリップ分解 | O(NM sqrt(A)) | O(NM) | 承認済み |

 ここで A は次の数です。`#`細胞。 

## アルゴリズムのチュートリアル

 形状をバイナリ行列として扱い、占有されたセルのセットを操作します。 

1. の合計数を数えます。`#`t 個の部分への有効な分解では、各部分に正確に A / t 個のセルが含まれている必要があるため、t は A を除算する必要があります。 
2. A の約数 t ごとに、形状を t 個の同一の部分に分割できるかどうかを判断します。 
3. 水平方向の分解と垂直方向の分解という 2 つの構造の可能性を個別に検討します。 
4. t 個の部分に水平に分解するには、各ブロックに正確に A / t 個のセルが含まれるように、グリッドを連続する t 個の水平ブロックに分割できる必要があります。 これにより、各ブロックの行数が強制的に同じになるため、各ブロックの高さは固定されます。 
5. 各ブロックを、その左上の占有セルを基準とした座標セットとして抽出します。 
6. 形状を比較するときに回転が許可されるため、座標セットの 4 つの回転すべてを生成し、辞書編集上の最小の表現を標準形式として選択することにより、各ブロックを正規化します。 
7. すべてのブロックの標準形式を比較します。 それらが一致する場合、この t は実行可能です。 
8. 垂直方向の分解でも同じ手順を繰り返し、行ではなく列ごとにスライスします。 
9. 問題の解釈では、t 個のピース​​が t シャーマンと最後に残ったピースに対応するため、答えは実現可能な最大の t から 1 を引いたものになります。 

正確さは、単一の直線カットの有効なシーケンスが、繰り返し行われる完全なストリップ除去と同等の構造を生成する必要があるという事実に依存します。 ワンカット削除の制限により、形状や市松模様のパーティションをインターリーブすることができなくなり、単一方向に沿って均一な繰り返しが強制されます。 正準回転比較により、方向の違いによって有効な等価性が妨げられないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def normalize(shape):
    coords = list(shape)

    def rot(c):
        return [(-y, x) for x, y in c]

    def norm(c):
        minx = min(x for x, y in c)
        miny = min(y for x, y in c)
        return sorted((x - minx, y - miny) for x, y in c)

    forms = []
    cur = coords
    for _ in range(4):
        forms.append(tuple(norm(cur)))
        cur = rot(cur)
    return min(forms)

def extract_blocks(grid, n, m, t, horizontal):
    cells = [(i, j) for i in range(n) for j in range(m) if grid[i][j] == '#']
    total = len(cells)
    per = total // t

    used = [[False]*m for _ in range(n)]
    blocks = []

    if horizontal:
        rows = [[] for _ in range(n)]
        for i, j in cells:
            rows[i].append(j)

        idx = 0
        cur_block = set()
        cnt = 0
        cur_cells = 0

        # greedy row grouping
        for i in range(n):
            for j in rows[i]:
                cur_block.add((i, j))
                cur_cells += 1
            if cur_cells == per:
                blocks.append(cur_block)
                cur_block = set()
                cur_cells = 0
        if cur_cells != 0:
            return None

    else:
        cols = [[] for _ in range(m)]
        for i, j in cells:
            cols[j].append(i)

        cur_block = set()
        cur_cells = 0

        for j in range(m):
            for i in cols[j]:
                cur_block.add((i, j))
                cur_cells += 1
            if cur_cells == per:
                blocks.append(cur_block)
                cur_block = set()
                cur_cells = 0
        if cur_cells != 0:
            return None

    if len(blocks) != t:
        return None

    return blocks

def check(grid, n, m, t):
    cells = sum(row.count('#') for row in grid)
    if cells % t != 0:
        return False

    per = cells // t

    # horizontal attempt
    blocks = []
    cur = set()
    cnt = 0
    row_cnt = 0

    # simple scan row by row
    for i in range(n):
        for j in range(m):
            if grid[i][j] == '#':
                cur.add((i, j))
                cnt += 1
        if cnt == per:
            blocks.append(cur)
            cur = set()
            cnt = 0

    if len(blocks) == t:
        canon = normalize(blocks[0])
        if all(normalize(b) == canon for b in blocks):
            return True

    # vertical attempt
    blocks = []
    cur = set()
    cnt = 0

    for j in range(m):
        for i in range(n):
            if grid[i][j] == '#':
                cur.add((i, j))
                cnt += 1
        if cnt == per:
            blocks.append(cur)
            cur = set()
            cnt = 0

    if len(blocks) == t:
        canon = normalize(blocks[0])
        if all(normalize(b) == canon for b in blocks):
            return True

    return False

def solve():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    cells = sum(row.count('#') for row in grid)

    best = 1
    for t in range(1, cells + 1):
        if cells % t == 0:
            if check(grid, n, m, t):
                best = max(best, t)

    print(best - 1)

if __name__ == "__main__":
    solve()

最終出力での 1 の減算は、t 個の同一の部分が、t 個のシャーマンの部分と、プロセスで説明された最後の残りの部分に対応するという事実を説明します。 

## 実用的な例

 ### サンプル 1

 の合計数を計算します。`#`セルを調べ、可能な因数分解をテストします。 最も有効な分解が t = 3 であると仮定します。 

| ステップ | 現在の t | 1 個あたりのサイズ | 有効なブロック | 正規一致 |
 | --- | --- | --- | --- | --- |
 | 1 | 1 | すべてのセル | 1ブロック | はい |
 | 2 | 2 | 無効な分割 | - | いいえ |
 | 3 | 3 | 等しい 3 分の 1 | 3ブロック | はい |

 これは、形状が 3 つの同一の回転ブロックに分解できることを示しており、答えは 2 人のシャーマンです。 

トレースは、t = 3 が形状の内部構造と一致する一方で、ブロックを合同にすることができないため、より小さいパーティションは失敗することを示しています。 

### サンプル 2

 占有セルの総数の約数を再度テストします。 

| ステップ | 現在の t | 1 個あたりのサイズ | 有効なブロック | 正規一致 |

 | 1 | 1 | フルシェイプ | 1 | はい |

これにより、特定の約数のみが構造的に一貫したストリップ分解に対応することが確認されます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(NM * A) | 各除数について、グリッドをスキャンしてブロックを構築します。各正規化コストはブロック サイズに比例します。 
| スペース | O(NM) | グリッドと座標セットの保存 |

 この制約により最大 300 x 300 のセルが許可されるため、スキャンごとに約 90,000 の操作が許容されます。 A が最大 90000 であり、ほとんどのグリッドには有効な分解が比較的少ないため、除数の列挙は引き続き管理可能です。

 ## 特殊なケース

 最小の単一セルの形状は、分割しようとすると切断後の接続に違反するため、自明なケースを超えて意味のある分解が存在しないことを示しています。 

長い水平線は、すべての部分が 1 つのセルである場合であり、連続した切断により一度に 1 つのセルを剥がすことができ、ストリップベースの分解が縮退した形状を正しく処理していることが確認できます。 

非常に不規則な接続形状により、正準回転比較によりジオメトリの不一致が拒否されるため、正規化ステップで不一致のフラグメントが誤って一致しないことが保証されます。
