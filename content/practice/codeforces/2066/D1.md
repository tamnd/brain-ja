 ## 解決策
 ## 問題の理解

 建物からの飛行機の有効な離陸シーケンスの数を数えるように求められます。`n`床。 各フロアには 1 人の居住者がおり、すべての居住者が少なくとも集合的に起動したいと考えています。`c`飛行機。 建物には、`m`総打ち上げ数。 各発射はどのフロアで発射したかによって記録されますが、このバージョンではすべての発射記録が欠落しているため、すべてのエントリが空白になります。 これらのギャップを次の整数で埋めることができる方法が何通りあるかを数える必要があります。`1`に`n`つまり、そのシーケンスは規則に従って発生した可能性があります。 

このルールでは 2 つの制約が課されます。 まず、住民の視点から、`i`- 階、すでに見た場合は発射を停止します`c`飛行機。 第二に、その日の終わりまでに、すべての住民が少なくとも次のことを目にする必要があります。`c`飛行機。 簡単バージョンでは、すべて`a_i`が欠落している場合、問題は長さのシーケンスを数えるということになります。`m`各フロアのどこに`i`少なくともその後起動しない`c`打ち上げはすでにフロアの下または階で行われており、最後までに少なくとも`c`各フロアから見える打ち上げ。 

制約を考慮すると (`1 <= n, c <= 100`そして合計`m`すべてのテスト ケースにわたって ≤ 10^4)、時間計算量がおおよそのアルゴリズム`O(n * m * c)`実現可能です。 明らかではないエッジケースは次のような場合です。`m`まさに`c`、またはいつ`m`に近いです`n * c`。 たとえば、次の場合`n = 3`、`c = 2`、 そして`m = 4`、単純なアプローチでは、低層階の打ち上げが遅すぎるシーケンスが発生し、最上階で十分な打ち上げを見ることが不可能になる可能性があります。 のようなシーケンス`[2, 3, 1, 3]`1階は決して見ないので無効です`c`が起動します。 

## アプローチ

 ブルートフォースアプローチは、長さのすべてのシーケンスを生成することです。`m`からの値を使用して`1`に`n`そして、可視性ルールに照らして各シーケンスをテストします。 シーケンスごとに、各フロアの視点をシミュレートし、見えている飛行機の数を数え、ルールが満たされているかどうかを確認します。 これは原理的には機能しますが、次のことが必要です`n^m`最悪の場合の運用は、たとえ控えめな者であっても完全に実行不可能です。`n`そして`m`以来`100^100`天文学的です。 

重要な観察は、シーケンスでは最上階が見終わるまでに、`c`飛行機、下の各階は少なくとも見たことがあるはずです`c`同じように。 これは本質的に単調です: 床の場合`i`見えます`c`起動すると、その下にあるすべてのフロアが少なくとも`c`。 これにより、この問題は動的プログラミングに適用しやすくなります。 

させて`dp[i][j]`配布方法の数を表す`j`最初のうちに起動します`i`フロアを超えないようにします。`c`-飛行機の制限。 星と棒の組み合わせ法と同様の漸化式を導出できますが、限界によって制限されます。`c`各フロアごとに。 具体的には、分布の組み合わせ公式を使用できます。`j`同一のオブジェクトを`i`ビン。各ビンには最大でも`c`オブジェクト。 包含-排他原理により、有効なシーケンスを効率的にカウントできます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^m) | O(m) | 遅すぎる |
 | DP / 組み合わせ論 | O(n * c) | O(n * c) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 階乗および逆階乗モジュロを事前計算する`10^9 + 7`まで`n * c`。 これにより、組み合わせをすばやく計算できるようになります`C(x, y)`モジュロ`MOD`使用して`fact[x] * inv_fact[y] * inv_fact[x-y] % MOD`。 
2. 各テスト ケースについて、次の場合`m < c`、総打ち上げ数が最下層でも確認できないため、すぐに 0 を返します。`c`。 
3.初期化`res = 0`。 この変数は、有効なシーケンスの総数を累積します。 
4. ループオーバー`k = 1`に`n`、実際に打ち上げに寄与するフロア数を表します。 それぞれについて`k`、正確にシーケンスの数を計算します。`k`フロアはゼロ以外の起動に寄与します。 包含-排他原則を使用して、少なくとも割り当て方法の数を数えます。`c`それぞれに起動します`k`打ち上げの合計が次と等しくなるようなフロア`m`。 
5. 整数解の数の公式を使用して、`x1 + x2 + ... + xk = m`と`0 <= xi <= c`これは、組み合わせ論と包含-除外の交互合計を使用して効率的に計算できます。 
6. 各貢献を`res`モジュロ`10^9 + 7`。 
7. 出力`res`。 

ここでの不変条件は、寄与するフロアの数を列挙し、有界の組み合わせ分布を使用することによって、各フロアが少なくとも見ているすべてのシーケンスをカウントするということです。`c`問題によって課せられた制限を超えずに飛行機を飛行させます。 包含-除外により、規則に違反するシーケンスの過剰カウントを確実に回避できます。`c`限界。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 10**9 + 7

def precompute_factorials(limit):
    fact = [1] * (limit + 1)
    inv_fact = [1] * (limit + 1)
    for i in range(1, limit + 1):
        fact[i] = fact[i - 1] * i % MOD
    inv_fact[limit] = pow(fact[limit], MOD - 2, MOD)
    for i in range(limit - 1, -1, -1):
        inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD
    return fact, inv_fact

def comb(n, k, fact, inv_fact):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n - k] % MOD

fact, inv_fact = precompute_factorials(10000)

t = int(input())
for _ in range(t):
    n, c, m = map(int, input().split())
    input()  # skip the line of zeros
    if m < c:
        print(0)
        continue
    res = 0
    for k in range(1, n + 1):
        # number of solutions to x1 + ... + xk = m with 0 <= xi <= c
        val = 0
        for i in range(k + 1):
            sign = -1 if i % 2 else 1
            val = (val + sign * comb(k, i, fact, inv_fact) * comb(m - i * (c + 1) + k - 1, k - 1, fact, inv_fact)) % MOD
        res = (res + val) % MOD
    print(res)
```このソリューションでは、まず、組み合わせ計算の階乗と逆階乗を事前計算します。 各テスト ケースは個別に処理されます。 ゼロには情報がないため、ゼロの入力はスキップします。 寄与する可能性のあるフロアをループします`k`包含-除外を使用して有効なシーケンスを計算します。 モジュロ演算により、結果が範囲内に収まることが保証されます。
