 ## 解決策
 ## 問題の理解

 総合的な強さを最大化するために、n 人のプールから正確に k 人のキャラクターを選択するように求められますが、その選択は、各キャラクターの属性から派生した 2 つの独立した分類ルールによって制限されます。 

各文字には、合計を最大化したい値 ci があります。 さらに、各キャラクターには ai という記号が付けられており、これによりキャラクターはポジティブ ai とネガティブ ai という相容れない 2 つの派閥に分けられます。 3 番目のカテゴリである ai = 0 は中立であり、どちらの派閥にも参加できます。 2 番目の属性 bi は、チーム構成に制限を導入します。選択できるのは、負の bi を持つキャラクターを最大 1 人だけです。 

主要な構造的制約は、最終チームが AI サインによって決定される 2 つのグローバルな「世界」のいずれかに完全に存在しなければならないということです。つまり、非ネガティブな AI キャラクターだけを選択し、おそらくネガティブで中立的な AI キャラクターを選択するか、非ポジティブな AI キャラクターだけを選択して中立的な AI キャラクターを選択するかのどちらかです。 ニュートラル ai イコール ゼロのキャラクターは柔軟で、どちらの世界でも使用できます。 各ワールド内では、bi が 0 未満の文字を最大 1 つ使用できます。 

ci の合計を最大化する正確に k 個のインデックスを選択する必要があります。 

入力サイズは最大 200000 に達するため、すべてのサブセット、さらにはすべての k 組み合わせを試行するような解決策は不可能です。 解は線形または n log n に近い必要があります。 ソートベースの貪欲またはプレフィックス最適化アプローチが必要です。 

ニュートラル ai がゼロに等しい文字が最適な選択を支配する場合、微妙なエッジ ケースが発生します。 もう 1 つは、許可されている 1 つのネガティブ BI 文字が非常に強力で、より強力なポジティブ BI 候補を置き換える場合でも、それを交換することが有益な場合です。 

単純な間違いは、制約を無視して ci によって上位 k を個別に選択することです。これは、選択されたセットに複数の負の bi 要素が含まれているか、両方の ai 符号が混在している場合に失敗します。 

## アプローチ

 ブルートフォース手法では、すべての k 要素サブセットを試し、制約を検証し、ci の合計を計算します。 これは実現可能性を直接チェックするので正しいですが、サブセットの数は二項 n 選択 k であり、これは n = 2000 の場合でも実現不可能で、200000 の場合は完全に不可能です。 

この構造を活用する必要があります。唯一のグローバルな決定は、どちらの AI 側を選択するかということです。これは、符号制約によってすべての要素が 2 つの素な候補ユニバースに分割され、中立要素が共有されるためです。 ユニバースが固定されると、問題は合計を最大化しながら、最大でも 1 つの「不良」項目 (bi < 0) を持つ k 要素を選択することになります。 

固定されたユニバース内では、制御された例外を使用して ci に貪欲な戦略が最適です。主に上位 k 個の要素を取得しますが、全体の上位 k の中に含まれていない場合でも、1 つの負の Bi アイテムを含める可能性を考慮する必要があります。これは、選択内のより弱い正の Bi アイテムを置き換えることができる可能性があるためです。 これにより、標準的な「最大 1 つの特別なアイテムを含む最適なサブセット」の最適化が実現され、単一のスワップを考慮したソートとプレフィックスの合計によって解決できます。 

両方のユニバースを独立して評価し、より良い結果を選択します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n は k を選択) | O(k) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 ai 記号に基づいて問題を 2 つの候補世界に分割しました。 

まず、ai > 0 のグループ、ai < 0 のグループ、ai = 0 のグループの 3 つのグループを用意します。ゼロ グループはワールドを評価するときにどちらの側にも追加できます。 

そして、「ポジティブな世界」と「ネガティブな世界」を対称的に評価します。 

固定ワールドの場合、対象となるすべてのキャラクターをリストに統合します。 このような要素を選択できるのは最大でも 1 つであるため、bi < 0 を持つ要素をマークします。 

このリストを ci の降順に並べ替えます。

ベースライン候補、つまり bi 制約を無視した上位 k 個の要素の合計を計算します。 

次に制約を調整します。 ベースラインにすでに bi < 0 の要素が 1 つだけ含まれている場合、それは有効です。 それ以外の場合は、少なくとも 2 つの悪い要素が含まれており、これは禁止されています。 これを修復するには、最終的に選択したセットに不良要素が 1 つ以下であることを確認する必要があります。 最適な修復は、選択した不良要素を 1 つだけ強制し、残りを最適な残りの要素で埋めるか、不良要素を完全にゼロにすることを検討することです。 

具体的には、高速評価のために、ソートされた ci のプレフィックス合計を事前計算します。 また、良好な要素 (bi >= 0) と不良要素 (bi < 0) のソートされたリストも維持します。 

次に、各世界で 2 つのシナリオを試します。 最初のシナリオでは、適切な要素のみを選択することを前提としているため、可能であれば適切なリストから上位 k 個を取得します。 2 番目のシナリオでは、不良要素を 1 つだけ選択することを前提としています。選択した特殊要素として各不良要素候補を反復処理し、概念的に削除して、残りのプールから最良の k - 1 を取得します。これは、プレフィックス構造または 2 リストの貪欲マージを使用して計算できます。 可能な限り最高の金額を追跡します。 

両方の世界で最良の結果を計算し、対応するインデックスを出力します。 

### なぜ効果があるのか

 重要な不変条件は、固定された ai 一貫性のあるユニバース内では、bi < 0 制約に関して、最適解は最大 1 つの要素でグローバルに ci でソートされた選択とは異なるものに変換できるということです。 制約に違反する最適なセットには、不良要素がまったくないか、変換後に不良要素が 1 つだけ含まれます。これは、余分な不良要素を利用可能な最良の良好な要素に置き換えても、合計が減少することはないためです。 これにより、問題は組み合わせ選択から、最大でも 1 つの例外項目を含む制御された貪欲な選択に軽減されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_world(items, k):
    # items: list of (ci, bi, idx)
    if len(items) < k:
        return None

    # split by badness
    good = [x for x in items if x[1] >= 0]
    bad = [x for x in items if x[1] < 0]

    good.sort(reverse=True)
    bad.sort(reverse=True)
    items.sort(reverse=True)

    def take_best(pool, t):
        return pool[:t]

    # prefix sums
    def prefix(arr):
        ps = [0]
        for x in arr:
            ps.append(ps[-1] + x[0])
        return ps

    good_ps = prefix(good)
    bad_ps = prefix(bad)
    all_ps = prefix(items)

    def sum_prefix(ps, t):
        if t < 0 or t >= len(ps):
            return None
        return ps[t]

    best_sum = -1
    best_choice = None

    # case 1: no bad items
    if len(good) >= k:
        cur = sum_prefix(good_ps, k)
        if cur > best_sum:
            best_sum = cur
            best_choice = [x[2] for x in good[:k]]

    # case 2: exactly one bad item
    # try each bad item as forced
    if k >= 1:
        for i, b in enumerate(bad):
            remaining = good + bad[:i] + bad[i+1:]
            remaining.sort(reverse=True)
            if len(remaining) < k - 1:
                continue
            cur = b[0]
            cur += sum(x[0] for x in remaining[:k-1])
            if cur > best_sum:
                best_sum = cur
                best_choice = [b[2]] + [x[2] for x in remaining[:k-1]]

    return best_sum, best_choice

def main():
    n, k = map(int, input().split())
    pos, neg, zero = [], [], []

    for i in range(n):
        a, b, c = map(int, input().split())
        if a > 0:
            pos.append((c, b, i + 1))
        elif a < 0:
            neg.append((c, b, i + 1))
        else:
            zero.append((c, b, i + 1))

    # evaluate positive world and negative world
    res = None

    for base in [pos, neg]:
        items = base + zero
        if len(items) < k:
            continue
        cur = solve_world(items, k)
        if cur is None:
            continue
        if res is None or cur[0] > res[0]:
            res = cur

    print(*res[1])

if __name__ == "__main__":
    main()
```このソリューションは、AI サインの世界を選択するという全体的な決定を内部選択の問題から分離します。 それぞれのワールドは、唯一の真に厳しい制約 (許可される単一の negative-bi 要素) をブルート フォースすることによって処理されます。 

各世界の内部では、交換引数が合計を改善または維持することを保証するために、ci によるソートに繰り返し依存しています。 残りの複雑さは、どの要素が固有の不良要素として選択されるかを列挙することから生じます。 

## 実用的な例

 ### 例 1

 入力:```
4 2
-1 1 5
0 1 4
2 1 6
0 -1 3
```私たちは 2 つの世界を評価します。 ポジティブ AI の世界では、ai >= 0 にゼロを加えたインデックスを取得し、値が 6、4、3 の項目を与えます。ci で並べ替えると 6、4、3 が得られます。k = 2、上位の選択肢には悪い bi < 0 がないため、最良の値は 6 + 4 です。 

| ステップ | 現在のプール | 選択されたセット | 合計 |
 | --- | --- | --- | --- |
 | ポジティブな世界 | 6、4、3 | 6、4 | 10 |

 ネガティブ AI の世界では、5、4、3 があります。最良のペアは 5 + 4 = 9 です。 

したがって、6 と 4 に対応するインデックスを選択します。 

これは、制約に違反することなく柔軟性を高めるため、ゼロ要素を正の世界に混合することが不可欠であることを裏付けています。

| ステップ | アクション | 選ばれた | 合計 |

 ## 特殊なケース

 すべての高 ci 要素が bi < 0 の禁止構成にある場合、重要なエッジ ケースが発生します。アルゴリズムは、明示的に 1 つの不良要素を強制し、その他を利用可能な最良の良好な要素で置き換えることによってこれを処理します。 これにより、最適性を犠牲にすることなく実現可能性が確保されます。 

すべての ai がゼロの場合、別のエッジ ケースが発生します。 この場合、両方の世界は同一であり、ゼロ要素が柔軟性を支配します。 アルゴリズムは自然に単一のプールに集約され、同じ単一不良制約を持つ ci のみに基づいて選択されます。 

3 番目のエッジ ケースは、k が 1 に等しい場合です。選択される要素が最大 1 つであるため、bi の制約は無関係になり、アルゴリズムはすべての有効な世界にわたって最大の ci を選択することになります。
