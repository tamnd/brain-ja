 ## 解決策

 ## 問題の理解

 数直線上に配置されたいくつかの異なる点が与えられます。 それらの位置は任意であり、分類されていません。 タスクは、元のポイントと挿入されたポイントをすべて並べ替えた後、連続するすべてのポイントのペアがまったく同じ距離になるように、最小限の追加ポイントを挿入することです。 

言い換えれば、既存の点を決して移動せずに、新しい点を追加するだけで、散在した座標セットを完全に等間隔な等差数列に変換したいと考えています。 最終セットは次のようなシーケンスを形成する必要があります$a, a + d, a + 2d, \dots$すべての元の点がこの進行のどこかに現れます。 

重要な制約は、$n \le 100{,}000$これにより、点のペアに対する二次戦略は即座に除外されます。 すべての点のペアを間隔の候補として試し、完全な構築をシミュレートするものはすべて、慎重に縮小する必要があります。単純な再構築では必要になる可能性があるためです。$O(n^2)$あるいは最悪の場合はさらに悪化します。 

微妙な難点は、元のポイントが順序付けされていないことです。 最初にそれらを並べ替えることを忘れると、「隣接する」距離についてまったく推論することができなくなります。 もう 1 つの故障モードは、グローバル間隔が入力順序の隣接する差によって決まると仮定することから生じますが、これは任意です。 

ポイントが既に等間隔に配置されている場合、小さいながらも重要なエッジ ケースが発生します。 たとえば、次のように入力します。```
3
0 2 4
```ここではポイントを追加する必要はありません。 最初に間隔の一貫性を確認せずに常に「ギャップを埋める」ことを試みるアプローチでは、ポイントが誤って挿入されます。 

別のケース:```
3
-5 10 5
```並べ替えると得られるもの$-5, 5, 10$。 自然なステップは 5 ですが、5 から 10 までのギャップは 5 ですが、-5 から 5 までの距離も 10 離れているため、0 を導入する必要があります。最小値と最大値のみを調べる単純な戦略では、ステップ 7.5 などを誤って想定し、失敗する可能性があります。 

## アプローチ

 ブルート フォース ビューポイントは、最終的な等差数列の潜在的な連続要素として 2 つの既存の点を選択することから始まります。 これら 2 つが最終的な配置で隣接していると仮定すると、それらの差によって候補ステップ サイズが定義されます。 このような候補ごとに、最小値から最大値までの区間をカバーする完全な等差数列を生成し、そこから失われた元の点の数を数えようとします。 

これが機能するのは、有効な最終構成はすべての元の点を含む等差数列である必要があり、そのステップがソートされた最終シーケンス内の連続する点間の差と一致している必要があるためです。 ただし、すべてのペアを試してみると、$O(n^2)$候補者ごとに、最大で 3 つまでスキャンできます。$O(n)$適用範囲を検証するためのポイント、$O(n^3)$最悪の解釈で、あるいは少なくとも$O(n^2)$ハッシュを使用すると遅すぎます$10^5$。 

重要な点は、すべてのペアが必要なわけではないということです。 配列を並べ替える場合、正しいステップ サイズで、最終的な進行における隣接する要素間のすべての差を分割する必要があります。 つまり、ステップは、ソートされた配列内のすべての隣接する差分の最大公約数でなければなりません。 このグローバル ステップを計算すると、$d$、最終的な構造は完全に決定されます。これは、最小値から最大値へのステップによる等差数列です。$d$。 

次に、並べ替えられた配列を反復処理し、連続する要素間でスキップされたステップの数を合計することで、既存のポイント間で欠落している整数の数をカウントできます。

 ## アルゴリズムのチュートリアル

 ### 最適な戦略

 1. すべての座標を昇順に並べ替えます。 これにより、最終的なターゲット構造において「隣接点」の概念が明確に定義されます。 分類しなければ、違いは構造的な意味を持ちません。 
2. ソートされた配列内のすべての連続するペアの間の差を計算します。 これらの違いは、現在の構成でのポイントの距離を表しており、有効な最終間隔はすべてのポイントを分割する必要があります。 
3. これらすべての違いの最大公約数を計算します。 この値は、すべての元の点がグリッド上に存在することを可能にする、可能な最大均一ステップ サイズになります。 より小さいステップでも機能しますが、より多くのポイントを挿入する必要があるため、gcd ステップが最適です。 
4. この gcd を次のようにします。$d$。 最終的なターゲットの進行は、ステップ サイズに従って最小値から最大値まで続きます。$d$。 
5. ソートされた配列を、隣接するペアごとにスキャンします。$x[i], x[i+1]$、計算する$(x[i+1] - x[i]) // d - 1$。 これは、完全な等差数列においてそれらの間に欠落している中間点がいくつあるかを数えます。 
6. これらすべてのカウントを合計し、結果を出力します。 

### なぜ効果があるのか

 ソートされた配列を修正したら、有効な最終構成はすべての点を均一な格子上に整列させる必要があります。 最終的なシーケンス内の 2 つの連続する元の点間の間隔は、並べ替えられた入力で観察されたすべてのギャップの公約数である必要があります。 最大公約数はそのようなステップの最大値であり、これを使用すると、より大きなステップに対応する中間位置が少なくなるため、必要な挿入点の数が最小限に抑えられます。 その後、すべてのギャップが同じサイズのセグメントに正確に分解されます。$d$したがって、欠落ポイントのカウントは決定的かつギャップローカルになり、ライン全体にわたる一貫性が確保されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import gcd

n = int(input())
a = list(map(int, input().split()))
a.sort()

d = 0
for i in range(1, n):
    d = gcd(d, a[i] - a[i - 1])

if d == 0:
    print(0)
    sys.exit()

ans = 0
for i in range(n - 1):
    ans += (a[i + 1] - a[i]) // d - 1

print(ans)
```解決策は、すべての構造的推論が一貫した順序で実行されるように座標を並べ替えることから始まります。 gcd 累積ステップは、すべてのローカルな差分を単一のグローバル ステップ サイズに徐々にマージします。 ゼロのチェックは、すべての点が一致する縮退ケースを処理しますが、この問題では個別の値が保証されるため、ほとんどが防御的です。 

最後のループでは、隣接する各ペアの間に等間隔の点がいくつ存在する必要があるかを再構築します。 表現$(a[i+1] - a[i]) // d - 1$step で定義された等差数列上の 2 つの既知の位置の間で欠落している格子点を直接カウントします。$d$。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math

    input = sys.stdin.readline
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()

    from math import gcd

    d = 0
    for i in range(1, n):
        d = gcd(d, a[i] - a[i - 1])

    ans = 0
    for i in range(n - 1):
        ans += (a[i + 1] - a[i]) // d - 1

    return str(ans)

# provided sample
assert run("3\n-5 10 5\n") == "1"

# already uniform spacing
assert run("3\n0 2 4\n") == "0"

# large gap with one insertion
assert run("4\n0 3 6 12\n") == "1"

# negative coordinates
assert run("3\n-10 -4 2\n") == "2"

# already arithmetic progression
assert run("5\n1 4 7 10 13\n") == "0"
```| テスト入力 | 期待される出力 | 検証内容 |

 ## 特殊なケース

 次のようなすでに等間隔の点の場合:```
5
1 4 7 10 13
```ソートされた差分はすべて 3 であるため、gcd は 3 のままです。各ギャップは次の条件を満たします。$(a[i+1] - a[i]) // 3 - 1 = 0$、正しい出力 0 が生成されます。 

初期順序が不均一な場合:```
3
10 0 5
```ソートすると得られる$[0, 5, 10]$。 gcd は 5 で、アルゴリズムは入力順序を完全に無視し、ソートされたジオメトリから構造を再構築するため、挿入は必要ありません。 

次のような大きなギャップがある場合:```
2
0 1000000000
```gcd は差そのものに等しいため、中間点は必要ありません。 すべての元の点が進行上になければならないという制約の下でステップ サイズが最大化されるため、アルゴリズムは完全な密なグリッドの挿入を正しく回避します。
