 ## 問題の理解

 手配をお願いしております$n^2$のアイテム$n \times n$グリッド。 各項目には次のタイプがあります。$1$に$n$、それぞれのタイプが正確に表示されます$n$したがって、マルチセットは完全に均一になります。 

それらを配置した後、すべての行とすべての列には、$n$その中の数字。 この値は、その行または列の「不安定性」と呼ばれます。 いずれかの行または列が選択したしきい値を超えた場合$m$の場合、その構成は安全でないと考えられます。 

タスクは、すべての数字の配置を設計し、選択することです。$m$すべての行と列にわたる最大 XOR が最小化されるようにします。 この最小限の可能な両方を出力する必要があります$m$そしてそれを実現する一つの仕組み。 

制約$n < 500$そして$n$奇数とは、グリッドが最大でも約$500 \times 500$、余裕があるので$O(n^2)$工事。 配列の数が天文学的であるため、行または列の順列を探索しようとする試みは直ちに実行不可能であるため、解決策は組み合わせ論ではなく XOR の代数構造を利用する必要があります。 

数値を任意またはランダムに分配すると XOR が「平均化される」と仮定すると、微妙な失敗例が発生します。 XOR は平均化されず、単一ビットの不均衡が決定論的に伝播します。 たとえば、$n = 3$の順列として行を配置します。$[1,2,3]$構造体がない場合は、次のような行 XOR が生成される可能性があります。$1 \oplus 2 \oplus 3 = 0$ただし、配置によっては列が不整合になる可能性があります。 各値が正確に表示されるという制約$n$回は、典型的にはラテン方陣のような、対称的な構造が必要であることを示唆しています。 

## アプローチ

 強引なアイデアは、各数値が正確に表示されるという制約の下で、各行のすべての順列を列挙することです。$n$全体で 3 倍にしてから、行と列の XOR を計算し、可能な最小値と最大値を取得します。 有効なラテン方乗順列に限定しても、候補の数はおよそ$(n!)^n$たとえ小さいものであっても、計算の限界をはるかに超えています。$n$。 ボトルネックは評価ではなく、有効な配置の組み合わせの爆発です。

標準的な循環ラテン方陣は機能します: セルを定義します。$(i, j)$として$(i + j) \bmod n + 1$。 これにより、すべての行と列が次の順列になることが保証されます。$1 \dots n$, したがって、各数値は行と列ごとに 1 回だけ表示されます。 各行にはすべての数字が含まれているため、$1 \dots n$、行 XOR はすべての行で同一であり、同じことが列にも当てはまります。 

したがって、問題は次の XOR を計算することに帰着します。$1 \oplus 2 \oplus \dots \oplus n$、これは可能な限り最小限になります$m$。 有効なラテン方陣はすでに均一性を強制しており、そのような構造の中で、この循環構造が最適かつ最も単純です。

 ## アルゴリズムのチュートリアル

 1. を構築します。$n \times n$各セルが配置されるグリッド$(i, j)$値が割り当てられます$(i + j) \bmod n + 1$。 これにより、各行がシフトされた順序ですべての値を循環し、すべての数値が行ごとに 1 回だけ表示されることが保証されます。 
2. 構造は行間で対称であるため、すべての列にも各値が 1 回だけ含まれます。 これにより、XOR の不均衡を引き起こす不均等な分散が回避されます。 
3. 数値の XOR を計算する$1$を通して$n$。 各行はすべての数値の順列であるため、この値は行または列の XOR です。 
4. この XOR を次のように出力します。$m$、続いて構築されたグリッド。 

### なぜ効果があるのか

 この構造では、すべての行とすべての列が同じマルチセットの順列であることが強制されます。$\{1, 2, \dots, n\}$。 XOR は置換下では不変であるため、すべての行の XOR は同じグローバル値と等しくなります。$S = 1 \oplus 2 \oplus \dots \oplus n$、列についても同じことが当てはまります。 すべての行と列の XOR 値が同一であるため、最大の不安定性は次のようになります。$S$すべての数字が表示されなければならないため、これ以上に優れた配置はありません。$n$これにより、XOR の意味での各行の平均には、有効なバランスのとれた構成において、行ごとに 1 回だけすべての寄与が含まれるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input().strip())

grid = [[0] * n for _ in range(n)]

for i in range(n):
    for j in range(n):
        grid[i][j] = (i + j) % n + 1

m = 0
for i in range(1, n + 1):
    m ^= i

print(m)
for row in grid:
    print(*row)
```この構築では直接式を使用するため、後戻りや条件付きロジックはありません。 唯一の微妙な点は、次のモジュロシフトを覚えておくことです。$+1$、値は 1 から始まるインデックスなので。 XOR 計算は単純な線形折り込みです。$1$に$n$。 

重要な設計上の選択は、$(i + j) \bmod n$これにより、完璧な循環シフト構造が保証されます。 行ごとに代替の置換を行うには、列全体での注意深い一貫性が必要ですが、この式は両方の制約を同時にエンコードします。
