 ## 解決策
 ## 問題の理解

 大統領選挙では、私たちに小さな候補者のリストが与えられます。そこには、各候補者の名前と、支持者の数を表す番号が付いています。 このタスクは、どの候補者に最も多くの支持者がいるのかを判断し、その候補者の名前を出力することです。 

入力は単一の整数で構成されます$n$、 に続く$n$線。 各行は、名前の文字列と支持者数の整数を使用して 1 人の候補者を説明します。 すべての名前とすべてのサポーター数が明確であることが保証されるため、同率に関する曖昧さがなくなり、常に 1 人の固有の勝者が存在します。 

計算的な観点から見ると、$n \le 10$、非常に小さいです。 ナイーブでも$O(n^2)$あるいはそれより悪いアプローチは自明のことながら高速ですが、問題の構造は直接リニア スキャンで十分であることを示唆しています。 唯一の意味のある制約は、入力の解析が正しくなければならず、最大値を正しく維持することです。 

名前と値の両方が一意であることが保証されているため、重複を伴う厄介な構造上のエッジケースはありません。 唯一の微妙な障害モードは、最大値トラッカーの誤った初期化または最初の要素の誤った処理です。これにより、すべての値が負または小さい場合 (ここでは値は正ですが)、真の最大値が失われる可能性があります。 

代表的なエッジケースは次のとおりです。 

入力:```
3
A 10
B 20
C 15
```正しい出力は次のとおりです`B`。 不注意なアプローチでは、最大サポーター数が誤って 0 に初期化され、バリアントの問題ですべての値が負の場合に失敗する可能性があります。ただし、ここでは値が少なくとも 1 であるため、その特定のバグは無害ですが、依然として同様の問題で一般的なパターンの問題です。 

## アプローチ

 最も直接的な戦略は、各候補を 1 つずつ読み取り、これまでに確認された最良の候補を追跡することです。 各エントリーについて、そのサポーター数を現在の最大数と比較します。 現在の最高値を超える場合は、最大値と保存されている名前の両方が更新されます。 

強引な解釈では、各候補者について、他のすべての候補者をスキャンして、より多くの支持者がいるかどうかを確認することになります。 それには$O(n^2)$比較しても、それでもまったく問題ありません$n \le 10$, しかし、不必要な繰り返し作業やより複雑なコードが導入されてしまい、何のメリットもありません。 

重要な観察は、問題は古典的なシングルパスの最大選択であるということです。 ペアの小さなコレクションのグローバル最大値のみが必要なため、並べ替えや比較の繰り返しは必要ありません。 プレフィックスの最大値は、より大きな値が出現したときに常に増分更新できるため、正確性を維持するには 1 回の走査で十分です。

 | ブルートフォース | O(n²) | お(1) | 受け入れられるが不要 |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 候補者を順次処理し、これまでに確認された最良の状態を維持します。 

1. 候補者数を読む$n$。 これにより、スキャンで実行する更新の数がわかります。 
2. 最初の候補を読み取り、現在の最高の名前と最高のサポーター数の両方をこの値で初期化します。 これにより、センチネル値を作成する必要がなくなり、すべての値が小さい場合でも正確さが保証されます。 
3. 残りの各候補者について、その名前と支持者の数を読み上げます。 
4. サポーター数を現在の最高値と比較します。 それが大きい場合は、保存されている最良の値と関連付けられた名前の両方を置き換えます。 これにより、最良の候補が常にこれまでに確認された最大値に対応することが保証されます。 
5. すべての候補を処理した後、保存されている最適な名前を​​出力します。 

### なぜ効果があるのか

 スキャン中のどの時点でも、アルゴリズムは、保存されているペアが、これまでに処理されたすべての候補の中で最大であるという不変条件を維持します。 新しい候補者はそれぞれ、この不変式を保存するか (それが大きくない場合)、保存されているペアを厳密に大きな支持者の数に置き換えることによってこの不変式を復元します。 すべての候補は 1 回だけ処理されるため、最後までに不変条件が入力全体に拡張され、保存された候補がグローバル最大値になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input().strip())

best_name = ""
best_count = -1

for i in range(n):
    name, cnt = input().split()
    cnt = int(cnt)
    
    if i == 0 or cnt > best_count:
        best_count = cnt
        best_name = name

print(best_name)
```この実装は単純な線形スキャンに依存しています。 最初の要素またはカウントが -1 に設定されたセンチネル ペアを使用して、最適なトラッカーを初期化します。 これにより、有効な入力値が必要に応じて即座に置き換えられることが保証されます。 

条件付き`i == 0`これにより、純粋にセンチネル ロジックに依存するのではなく、実際のデータから常に正しく初期化されることが保証されます。 比較`cnt > best_count`厳密な最大追跡を強制しますが、すべてのカウントが異なるため安全です。

 ## 特殊なケース

 制約により少なくとも 1 つの候補が保証されるため、唯一の構造的なエッジ ケースは処理です。$n = 1$。 その場合、最初の要素からの初期化により、その要素がすぐに最初の候補と最良の候補の両方になり、ループはそれを変更しません。 

例えば：```
1
Solo 42
```アルゴリズムセット`best_name = Solo`、`best_count = 42`、すべての更新をスキップします。 出力はそのまま残ります`Solo`, which is correct by definition.

 同点や欠損値がないため、他のエッジ ケースが正確さに影響を与えることはなく、すべての比較が厳密に決定的になります。
