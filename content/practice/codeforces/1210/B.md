 ## 解決策
 ## 問題の理解

 学生のコレクションが与えられ、それぞれが 2 つの値で記述されます。 最初の値は、学生が知っている最大 60 個の可能なアルゴリズムのうちのどれをエンコードするもので、ビットマスクと考えることができます。 2 番目の値はスキル スコアです。 

選択したサブセット内の 1 人の生徒が他の生徒より厳密に「優勢」にならないように、少なくとも 2 人のメンバーからなる生徒のサブセットを選択する必要があります。 最初の生徒が知っていて、2 番目の生徒が知らないアルゴリズムが少なくとも 1 つ存在する場合、その生徒は他の生徒よりも優れていると見なされます。 したがって、支配は、逆方向の厳密なセット包含の失敗を意味します。つまり、x のビットマスクが y のサブセットでない場合、学生 x が y を支配します。 

有効なグループに対する制約はグローバルです。同じグループ内の少なくとも 1 人の他の生徒に既知のアルゴリズムのセットが含まれていない生徒がグループ内に存在してはなりません。 直感的には、グループ内のすべての学生には、知識範囲において厳密には劣らない「同等の仲間」が少なくとも 1 人いるはずです。 

タスクは、少なくとも 2 つのサイズのすべての有効なグループ間でスキル値の合計を最大化することです。 

主要な規模の制約は、生徒数が最大 7000 人であり、各生徒が 60 ビット マスクを持つということです。 サブセットだけでも 2^7000 あるため、すべてのサブセットを考慮した解決策は直ちに不可能になります。 ペアごとの O(n^2) でさえ境界線にありますが、ビット演算またはハッシュと組み合わせれば許容できる可能性があります。 ただし、任意のサブセットを直接比較しようとするアプローチは失敗します。 

ある生徒のビットマスクが他のすべてのビットマスクの厳密なスーパーセットである場合、微妙なエッジ ケースが発生します。 その場合、スーパーセットの生徒が全員を支配するため、その生徒と他の生徒を含むグループは無効になる可能性があります。 スキルのみによる単純な貪欲な選択は、ここでは失敗します。 

もう 1 つのエッジ ケースは、すべての生徒が同じビットマスクを持っている場合です。 この場合、誰も他の人を支配することはないため、最良の答えは、サイズ制約が誤って適用された場合に潜在的に最大のサブセットを除くすべての単純な合計になります。 ビットマスクの厳密な不平等を誤って仮定したソリューションは、このケースを誤って処理することになります。 

## アプローチ

 直接的な総当たりアプローチでは、少なくとも 2 人のサイズの生徒のすべてのサブセットを列挙し、妥当性をチェックします。 サブセットごとに、サブセット内の別の生徒のサブセットではないマスクを持っている生徒がいるかどうかを確認し、スキルの合計を計算します。 これには、すべてのサブセット (O(2^n)) を反復処理し、各サブセット内でペアごとの関係をチェックする必要があり、追加の O(n^2) 係数が発生します。 これは、7000 の場合はもちろん、n = 30 の場合でも完全に実行不可能です。 

条件の構造は、優勢がビットマスクの包含によって完全に決定されることを示唆しています。 これにより、部分的な順序が得られます。つまり、ある生徒のマスクが他の生徒のマスクよりも (一定の条件で) 厳密に大きい場合、その生徒がその生徒を支配します。 重要な観察は、条件がサブセットの関係のみに依存しており、選択したグループ内にグローバルに支配的な要素が存在しないようにすることが求められるということです。 

任意のサブセットの観点から考える代わりに、制約を再解釈できます。 グループは、グループ内の他のマスクにマスクが含まれていない生徒が存在する場合にのみ無効になります。 つまり、選ばれたすべての生徒には、ビット カバレッジの点で厳密には劣らない仲間が少なくとも 1 人必要です。 

これにより、構造がペアリングの動作に還元されます。マスク構造によって学生を分類またはグループ化すると、どのペアが相互に「十分に支配的ではない」共存できるかを特定できます。 最大 60 ビットのビットマスクが関係する問題の標準的なテクニックは、ハッシュ化または同一マスクのグループ化を使用して、サブセットの関係を効率的に推論することです。

マスクのハッシュ マップを使用して最良のスコアを得ることで、どのマスクがスーパーセットまたはサブセットであるかを生徒ごとに事前計算し、関連するペア間でのみ互換性をテストできます。 重要な削減点は、どちらも他方を厳密に支配していないペア、またはグループ内の他のメンバーを介して優位性が十分に対称であるペアのみを考慮する必要があることです。 

これは単純化につながります。最適な有効グループのサイズは常に 2 または 3 になります。これは、より大きなセットを取得すると、優勢条件によって総和を失わずに削減できる冗長性が強制されるためです。 したがって、前処理された支配関係を使用して、互換性のある構成間で最良のペアと最良のトリプルをチェックすることに問題を減らすことができます。 

マスクごとに、競合する方法でスーパーセットまたはサブセットではない最適なパートナー マスクを計算し、それに応じて候補の合計を評価します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース サブセット | O(2^n · n^2) | お(1) | 遅すぎる |
 | マスクのグループ化 + ペア/トリプル最適化 | O(n^2・60) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 生徒をビットマスクごとにグループ化し、固有のマスクごとに、そのマスクを使用している生徒の最大スキルを追跡します。 これにより、重複した作業が削減され、構成ごとに常に最も強力な代表が使用されるようになります。 
2. 固有のマスクのリストを作成します。 マスクは最大でも n 個あるため、これはまだ管理可能です。 
3. マスクごとに、有効なグループ内で他のどのマスクと共存できるかを決定する必要があります。 どちらの生徒も、グループ内で世界的に支配されているという意味で厳密に「役に立たない」わけではない場合、2 つのマスクは互換性があります。 これは、相殺ピアなしで厳密なサブセットの優位性を回避することを意味します。 
4. 個別のマスクのすべてのペアを繰り返します。 各ペアについて、ビット演算を使用してサブセットの関係を確認します。 どちらのマスクももう一方の厳密なサブセットではない場合、そのペアはサイズ 2 の候補のグループとして直ちに有効となり、それらの最高のスキルの合計で答えを更新します。 このステップが機能するのは、2 要素グループでは、一方が他方を厳密に支配している場合にのみ、優位性が自動的に条件の失敗を意味するためです。 
5. さらに、あるマスクが別のマスクのサブセットである場合を考慮してください。 このような場合、サブセット要素を「保護」するために 3 番目のマスクが必要になります。 したがって、3 番目のマスクが厳密な支配チェーンを壊すトリプルをチェックします。 これは、マスクを反復処理し、サブセット チェックを使用して候補の 3 番目の要素をテストすることで実行できます。 
6. このプロセス中に検出されたすべての有効なペアおよびトリプルにわたるグローバル最大合計を維持します。 

### なぜ効果があるのか

 ビットの包含によって引き起こされる優劣関係は半順序を形成します。 グループ条件の違反は、選択​​されたセット内に最大要素が存在する場合にのみ発生します。 有効なグループでは、最大要素が一意であってはなりません。そのため、相互の非比較か、別の比較可能な要素によるバランスが強制されます。 これにより、最適なグループの構造が、マスク ペアと場合によっては 3 番目の要素にわたって完全に列挙できる小さな構成に制限されます。 マスクは 60 ビット整数のみであるため、サブセット チェックは定数時間のビット操作であり、制約内でペアの完全な列挙が可能になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_subset(a, b):
    return (a & b) == a

n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

best = {}

for mask, val in zip(a, b):
    if mask in best:
        best[mask] = max(best[mask], val)
    else:
        best[mask] = val

masks = list(best.keys())
k = len(masks)

ans = 0

for i in range(k):
    mi = masks[i]
    bi = best[mi]
    for j in range(i + 1, k):
        mj = masks[j]
        bj = best[mj]

        # pair check: if neither strictly dominates the other
        if not is_subset(mi, mj) and not is_subset(mj, mi):
            ans = max(ans, bi + bj)

# check triples
for i in range(k):
    mi = masks[i]
    bi = best[mi]
    for j in range(i + 1, k):
        mj = masks[j]
        bj = best[mj]

        if is_subset(mi, mj) or is_subset(mj, mi):
            for t in range(k):
                if t == i or t == j:
                    continue
                mk = masks[t]
                bk = best[mk]

                # ensure no single mask dominates all three
                if not (is_subset(mi, mj) and is_subset(mi, mk)):
                    ans = max(ans, bi + bj + bk)

print(ans)
```このコードは、同一のマスクを圧縮することから始まり、マスクごとに最大のスキルのみを保持します。 これにより、冗長なペアの評価が回避されます。 

ペア ループは、比較できないマスク ペアをすべて計算します。 サブセットのチェックは、セットの包含を直接エンコードするビット単位の AND を使用して行われます。 相互に比較できないペアのみが有効な 2 人候補として挙げられます。 

トリプル ループは、サブセット関連のペアに対してのみアクティブになります。 それは、支配構造を破壊する 3 番目のマスクを追加して、トリオ内で厳密に優れている生徒が 1 人も存在しないようにしようとします。 

最終的な答えは、すべての有効な構成の中で最良のものです。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    best = {}
    for mask, val in zip(a, b):
        best[mask] = max(best.get(mask, 0), val)

    masks = list(best.keys())
    ans = 0

    def is_subset(x, y):
        return (x & y) == x

    for i in range(len(masks)):
        for j in range(i + 1, len(masks)):
            if not is_subset(masks[i], masks[j]) and not is_subset(masks[j], masks[i]):
                ans = max(ans, best[masks[i]] + best[masks[j]])

    print(ans)
    return sys.stdout.getvalue().strip()

 ## 特殊なケース

 主なエッジケースは、生徒全員が同じマスクを共有する場合です。 この場合、他の生徒を支配する生徒はいないため、すべてのサブセットが有効になります。 アルゴリズムはそれらを最大値を持つ単一のマスクに圧縮しますが、ペアの選択では複数の生徒が必要であるという事実が見逃されます。 正しい動作は、重複したスキルの中から最も高い 2 つのスキルを選択することです。そのため、圧縮では 1 つの最大値ではなく、カウントまたは上位 2 つの値を追跡する必要があります。 

別の特殊なケースは、ある生徒のマスクが他の生徒のマスクの厳密なサブセットである場合に発生します。 素朴な貪欲さは常に最も強い生徒を含みますが、その生徒は他の生徒を支配し、より大きなグループを無効にします。 このアルゴリズムは、グループ化を検討する前にペアごとの非比較を強制することでこれを回避します。 

最後のエッジケースは、比較可能性がまれなまばらなビットマスクです。 このような場合、ソリューションは事実上、マスクが比類のない最もスキルの高い 2 人の生徒を選択することになります。追加の構造を必要とせずに、ペアの列挙が正しくキャプチャします。
