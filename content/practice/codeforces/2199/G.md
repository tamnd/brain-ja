 ## 問題の理解

 We are asked to find positions on a rectangular grid where we can place a jammer such that it always intercepts a robot moving from the bottom-left corner$(0,0)$右上隅に$(n,m)$、開始点と終了点では非表示のままです。 ロボットは右か上にしか移動できません。つまり、どのパスも一連の水平および垂直ステップで構成され、最終的には到達します。$(n,m)$。 ジャマーの範囲は半径のある円形です$r$そして、ロボットが**可能なすべてのパス**上でその半径内に確実に入る点が必要です。ただし、近すぎる点は除きます。$(0,0)$または$(n,m)$。 

入力により得られるのは、$n$、$m$、 そして$r$、 と$1 \le n,m$そして$n \cdot m \le 10^9$。 したがって、グリッド サイズが大きくなり、すべてのポイントを総当たりでチェックすることは不可能になります。$r$と同じ大きさにすることができます$n + m$これは、ジャマーが対角線全体をカバーする可能性があることを意味します。$(0,0)$に$(n,m)$。 出力は整数座標点の数です。$(x,y)$制約を満たすもの。 

ジャマーは**すべての経路**でロボットをカバーする必要があるため、微妙な点が生じます。 これは、「マンハッタン パス コリドー」のすべての点をカバーすることに相当します。$(0,0)$に$(n,m)$。 ロボットのパスはグリッドに整列した斜めの回廊を形成するため、この対角線から遠すぎる点は何らかのパスで回避できます。 この観察は、すぐに、海沿いの距離を考慮する必要があることを示唆しています。$x+y$sum は、ロボットの移動に沿って点がどのくらい離れているかを一意に決定します。 

エッジケースには、非常に狭いグリッドが含まれます (例:$1 \times 1$) または非常に長くて細いグリッド (例:$1 \times 10^9$)、非常に少数の、または非常に制約されたポジションのみが機能します。 もう一つの落とし穴は、$r$明示的に禁止されている開始または終了をカバーするのに十分な大きさです。 

## アプローチ

 ブルート フォース アプローチの説明は簡単です。すべての整数グリッド ポイントを反復処理します。$(x,y)$へのユークリッド距離を確認してください。$(0,0)$そして$(n,m)$を超える$r$そして、**すべての可能なパス**までの距離が最大でも次の距離であることを確認します。$r$。 すべてのパスを確認するには、すべてを列挙する必要があります$\binom{n+m}{n}$天文学的に大きいパス$n,m$まで$10^9$。 それを無視しても、すべてのグリッド点を反復することは少なくとも$O(n \cdot m)$、それは実現不可能です。 このアプローチは原理的には正しいですが、完全に非現実的です。 

重要な観察は幾何学的なものです: 任意の点$(x,y)$接続する線分からの**マンハッタン距離を満たさなければなりません$(0,0)$に$(n,m)$**は最大でも$r$両方向に。 ロボットは右または上にしか動かないため、ロボットの位置は次の条件を満たします。$0 \le x \le n$そして$0 \le y \le m$また、**すべてのパス**をインターセプトする点の場合、その点は次のように定義される「対角線」内に存在する必要があります。$x + y$距離。 具体的には、ユークリッド距離制約は 45 度回転した座標で単純化されます。$u = x + y$、$v = x - y$すべての道はそこにあるから$u$0から$n+m$。 ジャマーは、次の条件を満たす正方形のポイント内に位置する必要があります。$r < x^2+y^2$スタートを避けるためと、$r < (n-x)^2 + (m-y)^2$終わりを避けるために。 このような整数点の数は、次の範囲を使用して単純な算術で直接カウントできます。$x$そして$y$。

 ## アルゴリズムのチュートリアル

 1. 拘束が対称であることを確認して、ロボットの対角線に沿って回転した座標フレームに切り替えます。$x$そして$y$。 パスの合計$x+y$斜めの廊下にあるジャマーと交差する必要があります。 
2. 最小値と最大値を計算します。$x$開始点と終了点までのジャマーのユークリッド距離が厳密に次の値よりも大きくなるような座標$r$。 これにより定義されます$x$-境界として$x_{\min} = r$そして$x_{\max} = n - r$。 同様に、$y_{\min} = r$、$y_{\max} = m - r$。 
3. これらの境界外にあるジャマーは開始制約または終了制約に違反するため、これらの境界によって定義される長方形を超えるポイントは破棄されます。 
4. 残りの長方形内のすべての整数点を数えます。$\max(0, x_{\max} - x_{\min} + 1) \cdot \max(0, y_{\max} - y_{\min} + 1)$。 いずれかの次元が負の場合、条件を満たす点はありません。 
5. 各テストケースの積を出力します。 

このアルゴリズムが機能するのは、中央の対角ストリップ内のすべての点が距離内にあることが重要な不変条件であるためです。$r$すべてのロボット パスの始点または終点近くの長方形の外側の点は、禁止ゾーン ルールに違反します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, r = map(int, input().split())
        x_min = r + 1
        x_max = n - r - 1
        y_min = r + 1
        y_max = m - r - 1
        width = max(0, x_max - x_min + 1)
        height = max(0, y_max - y_min + 1)
        print(width * height)

if __name__ == "__main__":
    solve()
```コードは最初にテスト ケースの数を読み取ります。 テスト ケースごとに、開始点と終了点からの距離を考慮した最小座標と最大座標が計算されます。 の`+1`そして`-1`調整により、厳密な不平等が強制されます。 最終的な積は、許可された四角形内のすべての整数座標点をカウントし、四角形の寸法が縮退しているか負の場合は 0 を返します。
