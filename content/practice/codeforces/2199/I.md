この再形成ステップの後、オプションで 1 つの位置を割り当てることができます。`k`最初の配列から現​​在のステージまで (その位置の値が一致する場合)`c[i]`。 そうする場合、そのインデックスを次のように記録します。`b[i]`。 そうでなければ出発します`b[i] = 0`。

したがって、本当の制約は算術到達可能性に関するものではなく、シーケンスに一致させるために時間の経過とともにインデックスを割り当てる方法が何通りあるかということです。`c`、各ステージは 1 つの一致するインデックスを割り当てるか、スキップします。

どの段階でも任意の要素に任意の必要な値を自由に強制できるため、唯一の意味のある制約は組み合わせになります。つまり、特に複数の位置が再利用されたり、必要な値に一致するために新たに「アクティブ化」される場合、ステージ間で割り当てがどのように相互作用するかということです。

### なぜ効果があるのか

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, m = map(int, input().split())
    c = list(map(int, input().split()))

    from collections import Counter
    freq = Counter(c)

    # DP: dp[i] = number of ways using i distinct indices so far
    dp = [0] * (n + 1)
    dp[0] = 1

    # Precompute factorials up to max frequency
    max_k = max(freq.values(), default=0)
    fact = [1] * (max_k + 1)
    for i in range(1, max_k + 1):
        fact[i] = fact[i - 1] * i % MOD

    invfact = [1] * (max_k + 1)
    invfact[max_k] = modinv(fact[max_k])
    for i in range(max_k, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    def ways(k, t):
        # number of ways to assign k items onto t labeled non-empty groups
        if t > k:
            return 0
        # Stirling numbers of second kind via DP
        stir = [[0] * (t + 1) for _ in range(k + 1)]
        stir[0][0] = 1
        for i in range(1, k + 1):
            for j in range(1, min(i, t) + 1):
                stir[i][j] = (stir[i - 1][j - 1] + j * stir[i - 1][j]) % MOD
        return stir[k][t] * fact[t] % MOD

    for val, k in freq.items():
        ndp = [0] * (n + 1)
        for used in range(n + 1):
            if dp[used] == 0:
                continue
            for add in range(0, n - used + 1):
                t = used + add
                if t == 0:
                    continue
                w = ways(k, t)
                if w:
                    ndp[t] = (ndp[t] + dp[used] * w) % MOD
        dp = ndp

    print(sum(dp) % MOD)

if __name__ == "__main__":
    solve()
```DP は、各値を処理した後にアクティブになる個別のインデックスの数に基づいて編成されます。`c`。 各値の頻度について`k`、その出現がどのように割り当てられるかを計算します。`t`インデックス、ここで`t`すでに使用されているインデックスから`n`。 の`ways(k, t)`関数はからの射影をカウントします`k`上での出来事`t`ラベル付きインデックス。第 2 種スターリング数を乗算して実装されます。`t!`ラベル付けを考慮して。 

ネストされたループは、からの移行を反映しています。`used`へのインデックス`used + add`インデックス、ここで`add`現在の値グループに新しいインデックスを導入することに対応します。 

階乗事前計算は効率的なモジュラー組み合わせ論をサポートしますが、スターリング DP は引き続き実行可能です。`k ≤ 10^4`ただし、合計の再計算は値の頻度によって制限されます。

 ## 特殊なケース

 いつ`n = 1`、DP では 1 つのアクティブなインデックスのみが許可されます。 すべての値グループは、すべてのオカレンスをこの 1 つのインデックスにマップする必要があるため、Stirling 遷移は 1 つの構成に集約されます。 アルゴリズムはこれを自然に強制します。`t`1 を超えることはないため、追加のインデックスへの分岐は発生しません。
