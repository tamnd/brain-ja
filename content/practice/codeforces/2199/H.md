 ## 解決策
 ## 問題の理解

 長さの配列が与えられます$n$ここで、各要素は以下の整数です。$-1$に$n$。 特別な値$-1$はワイルドカードであり、以下の任意の整数に置き換えることができます。$0$そして$n$。 配列のプレフィックスごとに、ワイルドカードを置き換えることによって形成されたすべての配列の MEX (最小除外値) の合計を計算するように求められます。 シーケンスの MEX は、シーケンス内に存在しない最小の非負の整数です。 

問題のサイズはかなり大きいです:$n$到達できる$2 \cdot 10^5$、ただし、ワイルドカードの数は次の制限を受けます。$300$。 これは、すべてを列挙することはできないことを意味します$(n+1)^{k}$ワイルドカードの割り当てを明示的に行う場合$k$ワイルドカードの数です。 指数関数的な数の可能性を効率的に処理するには、動的プログラミングまたは組み合わせ論を使用するアプローチが必要です。 

エッジ ケースには、ゼロから始まる一連の連続した数値が既に含まれているシーケンスが含まれます。 たとえば、プレフィックスに次のものが含まれている場合、`[0, 1, 2]`そして1つ持っています`-1`、多くの割り当ての MEX は残る可能性があります`3`、ただし、人によってはこれを増やすことができます`4`ワイルドカードがどのように置き換えられるかに応じて異なります。 もう 1 つの微妙なケースは、プレフィックスにのみが含まれる場合です。`-1`s; その場合、MEX 合計は組み合わせカウントによって支配されます。 

## アプローチ

 素朴なアプローチは、それぞれを置き換えることによって可能なすべての配列を生成することです。`-1`数字付き`0`に`n`そして、結果の配列ごとに MEX を計算します。 これにより正確性が保証されますが、最大 300 個のワイルドカードを使用すると、次のような結果になります。$(n+1)^{300}$その可能性は天文学的に大きい。 数十のワイルドカードの場合でも、明示的に列挙することは不可能です。 

重要な観察は、MEX がゼロから始まる連続する整数の存在によって決定されるということです。 大きな数の正確な配置は気にせず、ただ次のことだけを気にします。`0, 1, 2, ..., m`一部の人には存在します`m`。 これにより、プレフィックス内の整数の数を現在の最大 MEX まで追跡できるようになります。 すべてのワイルドカードは、この連続シーケンスの欠落している数値を埋めるか、現在の MEX より大きい数値を選択することができます。 

これを、欠落要素と残りのワイルドカードの数に関する動的プログラミング問題としてモデル化できます。 させて`dp[i][j]`最初の値を割り当てる方法の数になります`i`まさにそのようなワイルドカード`j`欠落している要素 (0 から始まる番号) はカバーされます。 これにより、問題は指数関数的に減少します。$O(n \cdot k^2)$、これは実現可能です。`k ≤ 300`。 これをプレフィックス積の計算と組み合わせカウントと組み合わせて、合計 MEX 合計モジュロに対する各プレフィックスの寄与を計算します。$998244353$。

 ## アルゴリズムのチュートリアル

 1. 数値の周波数配列を初期化する`0`に`n`プレフィックスに存在します。 プレフィックス内のワイルドカードの位置を追跡します。 
2. 各プレフィックスについて、欠落している番号を決定します。`0`上向きに。 させて`m`ワイルドカードを無視して、現在のプレフィックスに欠落している最初の番号になります。 
3. しましょう`k`プレフィックス内のワイルドカードの数になります。 DP テーブルを定義する`dp[i][j]`最初の割り当て方法の数として`i`正確にカバーするワイルドカード`j`欠けている数字のうち`0..m-1`。 
4.初期化`dp[0][0] = 1`。 ワイルドカードごとに、テーブルを更新します。`j`すでにカバーされている場合、ワイルドカードは新しい不足している番号 (残っている場合) をカバーするか、番号 ≥ を選択することができます。`m`。 カウントモジュロを更新します`998244353`。 
5. DP テーブルに記入した後、このプレフィックスの MEX 合計への寄与を計算します。 各課題の場所`j`欠損番号がカバーされると、カバーされる番号を超えた最初の欠損番号に、からのウェイ数を乗じたものに等しい MEX が与えられます。`dp[k][j]`。 
6. 和のモジュロを保存する`998244353`このプレフィックスの答えとして。 すべてのプレフィックスに対してこの手順を繰り返します。 

機能する理由: DP テーブルは、欠落している数値にワイルドカードを割り当てるすべての組み合わせの可能性をエンコードします。 ワイルドカードと可能なカバレッジ状態を反復処理することにより、明示的に列挙することなく、すべての配列を系統的にカウントします。 各割り当ての MEX は、0 から始まる連続する数値がいくつ存在するかによってのみ決定され、DP テーブルはこれを正確に追跡します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    ans = []
    freq = [0] * (n + 2)
    wildcards = 0
    
    for i in range(n):
        if a[i] == -1:
            wildcards += 1
        else:
            freq[a[i]] += 1
        
        missing = []
        for x in range(n+1):
            if freq[x] == 0:
                missing.append(x)
        m = len(missing)
        
        # DP: dp[j] = number of ways to cover first j missing numbers
        dp = [0] * (m + 1)
        dp[0] = 1
        for _ in range(wildcards):
            new_dp = [0] * (m + 1)
            for covered in range(m + 1):
                # choose a wildcard to fill next missing
                if covered < m:
                    new_dp[covered + 1] += dp[covered]
                    new_dp[covered + 1] %= MOD
                # choose a wildcard to fill number >= m
                new_dp[covered] += dp[covered] * (n - m + 1)
                new_dp[covered] %= MOD
            dp = new_dp
        
        total = 0
        for covered in range(m + 1):
            mex_val = missing[covered] if covered < m else m
            total += dp[covered] * mex_val
            total %= MOD
        ans.append(total)
    
    print(" ".join(map(str, ans)))

if __name__ == "__main__":
    solve()
```コードの各部分は、上記のアルゴリズムのステップに対応します。 周波数配列はどの数値が存在するかを追跡します。`wildcards`カウント`-1`さん、`missing`現在のプレフィックスに存在しない番号を識別します。 DP テーブルは、欠落している数値をカバーするために、ワイルドカードの有効な割り当てをすべてカウントします。 モジュロを慎重に計算します`998244353`オーバーフローを避けるために各操作の後に。
