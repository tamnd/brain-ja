 ## 解決策
 ## 問題の理解

 2 人のプレイヤー、アリスとボブは、同じ長さの 2 本の文字列から開始します。 文字列には英小文字のみが含まれます。 彼らは正確にゲームを繰り返し実行します$P$ラウンドします。 各ラウンドで、アリスはボブの文字列の 1 文字を変更することを強制され、ボブはアリスの文字列の 1 文字を変更することを強制されます。 変更とは、位置を選択し、その文字を選択した他の小文字に置き換えることを意味します。 

結局$P$ラウンドでは、各プレイヤーは自分の文字列のみを評価します。 プレイヤーのスコアは、最終的な文字列内の最も一般的な文字の頻度として定義されます。 より高いスコアを獲得したプレイヤーが勝者となり、同点の場合は引き分けとなります。 どちらのプレイヤーも、初期弦についての十分な知識を持って最適に演奏します。 

重要な難点は、各操作が文字列全体では敵対的であるものの、プレイヤー自身の戦略内では協力的であることです。アリスは、自分の文字列ではなくボブの文字列にダメージを与えることによってのみ最終スコアを向上させます。逆も同様です。 最適化は純粋に、一定の編集回数の下で文字の頻度分布をどのように形成するかに関するものです。 

制約が大きいのは、$P$、 まで$10^9$、 その間$N$これにより、ラウンドにわたるシミュレーションが直ちに除外されます。 解決策は、初期の頻度分布の構造と、1 つの動きごとにどれだけの「効果的な変化」を達成できるかのみに依存する必要があります。 

微妙なエッジケースが現れるのは、$P = 0$。 変更は不可能であるため、答えは純粋に各文字列の最初の最大文字頻度によって決まります。 もう 1 つの特殊なケースは、文字列がすでに均一である場合です。 このような場合、キャラクターを変更すると、戦略に応じて集中力が低下したり高まったりする可能性がありますが、両方のプレイヤーが対称的に行動するため、最終的な効果は、どれだけの変更が強制されるか、および変更が文字全体にどのように分散されるかによってのみ決まります。 

## アプローチ

 単純なアプローチではゲームをシミュレートします。 各ラウンドで、アリスはボブの最終的な最大周波数を最小にするボブの文字列内の位置を選択しようとしますが、ボブはアリスに対して同じことを行います。 ただし、各変更後の最適な選択は、文字の現在の分布全体に依存し、最良の手を再計算するには時間がかかります。$O(N)$動きごとに。 と$P$まで$10^9$、これはまったく不可能です。 たとえシミュレーションの上限を$P \le 500$、各移動が最適なターゲット文字を動的に変更するため、状態空間は複雑なままです。 

重要な観察は、文字列の最終スコアにとって重要なのは、その最大の周波数クラスのサイズだけであるということです。 すべての操作で 1 つの文字が変更されるため、ある頻度カウントが減少し、別の頻度カウントが増加します。 高いレベルから見ると、各プレイヤーは、単一のドミナント文字に変換できる文字の数を最大化したいと考えています。 

文字列に周波数配列があるとします。$f_1, f_2, \dots, f_{26}$。 次の最も頻繁に使用される文字を最大化したい場合は、$x$変更があった場合、最善の戦略は常に、現在最適な文字をターゲットとして選択し、他のすべての文字をそれに変換することです。 各操作で最高の頻度を最大 1 増加させることができますが、これは他のすべてのキャラクターが使い果たされるまでに限られます。 

したがって、その後、$x$オペレーションの場合、可能な最大周波数は次のようになります。$$\min(N, \max(f_i) + x)$$なぜなら、移動するたびにドミナント文字の数が最大 1 つ増加する可能性があり、文字列の長さを超えることができないからです。 

これで、アリスとボブの間の相互作用は対称的になり、分離されます。各プレイヤーは自分の$P$相手の文字列上で移動しますが、問題となるのは自分自身の最後の文字列だけです。 したがって、アリスのスコアは、アリスの元の文字列とそれを減らすボブの能力に依存し、またその逆も同様です。 

ただし、ボブはアリスの文字列を変更するだけであるため、ボブは実質的にアリスの最大頻度を最小限に抑えようとします。 頻度クラスを減らす最善の方法は、最も頻度の高い文字を最初にターゲットにすることです。 各操作は、その文字にヒットした場合にのみ、現在の最大値を 1 減らします。 そうしないと、非ドミナント文字に無駄になります。 ボブは常に最適な選択ができるため、常にアリスの文字列の現在の多数派文字を攻撃します。 アリスとは対称的に。 

したがって、各プレイヤーの最適な結果は、対戦相手が多数派の集中を「破る」のに十分な操作を持っているかどうかによってのみ決まります。 

させて$mx_1$の最大周波数になります$S_1$、$mx_2$のために$S_2$。 後$P$ボブからアリスに移動すると、アリスの可能な限り最高の最終スコアは次のようになります。$$\max(1, mx_1 - P)$$なぜなら、各移動は 1 に達するまで支配的な周波数を最大 1 つずつ減らすことができるからです (少なくとも 1 つの出現が残っているため、1 を下回ることはできません)。 

同様に:$$\max(1, mx_2 - P)$$したがって、ゲームはこれら 2 つの値を比較することになります。

 | --- | --- | --- | --- |
 | ブルート フォース シミュレーション |$O(P \cdot N)$|$O(N)$| 遅すぎる |
 | 周波数低減モデル |$O(N)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 両方の文字列内の各文字の頻度をカウントします。 

これにより、各文字列の構造の完全な概要が得られます。操作は位置ではなくカウントにのみ影響するため、これで十分です。 
2. コンピューティング$mx_1$そして$mx_2$、アリスとボブの初期文字列の最大周波数。 

スコアは最も頻繁に使用される文字にのみ依存するため、他の頻度は無視できます。 
3. ボブがアリスに及ぼす影響を、アリスの最大頻度を最大で減少させるとしてモデル化します。$P$、生産$a = \max(1, mx_1 - P)$。 

各操作により、現在の支配的な文字が支配的でなくなるまで、その出現を 1 つ削除できます。 
4. 同様に計算します$b = \max(1, mx_2 - P)$ボブに対するアリスの影響について。 
5. 比較する$a$そして$b$。 もし$a > b$, アリスが勝ちます。 もし$a < b$、ボブが勝ちます。 それ以外の場合、結果は引き分けです。 

### なぜ効果があるのか

 重要な不変条件は、文字列内で最も頻繁に使用される文字の ID を再生中に明示的に追跡する必要がないことです。 重要なのはその数だけであり、あらゆる最適な動きは常に現在の多数派クラスをターゲットとします。 これにより、どの戦略も対戦相手のスコアから手ごとに 1 単位を超える減少単位を抽出できなくなり、どの戦略も自分のスコアを手ごとに 1 を超えて増やすことができなくなります。 その結果、初期最大周波数の線形調整によってプロセスが完全に捕捉されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, p = map(int, input().split())
        s1 = input().strip()
        s2 = input().strip()

        f1 = [0] * 26
        f2 = [0] * 26

        for c in s1:
            f1[ord(c) - 97] += 1
        for c in s2:
            f2[ord(c) - 97] += 1

        mx1 = max(f1)
        mx2 = max(f2)

        a = max(1, mx1 - p)
        b = max(1, mx2 - p)

        if a > b:
            print("Alice")
        elif a < b:
            print("Bob")
        else:
            print("Draw")

if __name__ == "__main__":
    solve()
```この実装では、各文字列が長さ 26 の周波数配列に圧縮されます。 これにより、位置を追跡したり、操作をシミュレートしたりする必要がなくなります。 

唯一の微妙なディテールはクランプです。`max(1, mx - p)`。 たとえ$P$が現在の最大頻度を超えるほど大きい場合、何らかの文字が少なくとも 1 回出現するため、スコアを 0 に下げることはできません。 実装では、この下限が直接強制されます。

 ## 特殊なケース

 いつ$P = 0$、アルゴリズムは初期最大周波数を直接比較します。 たとえば、`abcd`対`aabc`、両方の最大値がそれぞれ 1 と 2 であるため、ボブがすぐに勝ちます。 縮小は適用されず、数式は元の状態を正しく保存します。 

いつ$P$非常に大きいと言えます$10^9$、両方の文字列は、構造に関係なく最小スコア 1 に減らされます。 例えば、`aaaaa`対`bbbbb`1対1となり引き分けとなります。 クランプにより、負の周波数またはゼロの周波数が表示されなくなります。 

文字列が同一の場合、両方とも$mx_1$そして$mx_2$は等しく、同一の縮小後も両方は等しいままです。 1 つの文字列にさらに多様な文字が含まれている場合でも、最大頻度が優先され、他の場所の分布に関係なく一貫した比較が保証されます。
