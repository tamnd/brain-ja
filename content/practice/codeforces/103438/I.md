 ## 解決策
 ## 問題の理解

 同じサイズの 2 つのバイナリ グリッドが与えられます。 各セルは 0 または 1 で、白または黒を表します。 グリッド A から開始して、任意のセルを選択し、それを含む等しい値のセルの接続領域全体を取得し、その領域内のすべての値を反転する操作を適用できます。 

接続は 4 方向であり、接続領域は常に、初期構成ではなく、操作時のグリッドの現在の状態に基づいて定義されます。 

このような反転を任意の回数実行した後、最終的なグリッドが得られます。 目標は、グリッド B と異なるセルの数を最小限に抑えることです。 

重要な問題は、反転が単一のセルに対してローカルではなく、動的接続コンポーネント全体に対して行われ、それらのコンポーネントが操作のたびに変化することです。 このため、最初は最終的なグリッドを形成する際に実際にどの程度の自由があるのか​​が不明確になります。 

制約は小さく、N と M は最大 100 なので、O(N²M²) または O(N² log N) スタイルの解決策さえも妥当ですが、フリップのシーケンスに対する指数関数的な検索は完全に実行不可能です。 演算の構造は、解が個々のフリップ シーケンスではなく、グリッド グラフの接続されたコンポーネントの観点から表現される必要があることを強く示唆しています。 

いくつかの微妙な状況を強調する価値があります。 

グリッドがすでに均一である場合、たとえばすべてゼロの場合、すべての操作は一度にグリッド全体に影響を与えるため、グリッド全体を切り替えることしかできません。 その場合、答えは単純に、すべて 0 と一致するか、すべて 1 と一致するかの最小値になります。 

チェス盤のようにグリッドに色が交互に配置されている場合、最初はすべてのセルが独自のコンポーネントであるため、最初のいくつかの操作により柔軟性が高まりますが、マージが発生すると、コンポーネントが急速に大きくなり、到達可能な状態が非明確な方法で変更される可能性があります。 

より欺瞞的なケースは、大きな均一領域内の単一の孤立セルで A と B が異なる場合です。 単一の修正のように見えますが、最初にその周囲のコンポーネント構造を再形成しない限り、そのセルだけを反転することは不可能です。 

## アプローチ

 ブルートフォースアプローチでは、一連の塗りつぶし操作をシミュレートしようとします。 どの状態からでも、セルを選択し、その現在のコンポーネントを計算し、反転して再帰します。 分岐係数はおよそ O(NM) で、各フリップによって接続性が大きく変化する可能性があるため、最悪の場合シーケンスの深さも O(NM) になる可能性があります。 これにより、到達可能な状態が指数関数的に爆発し、病的な場合には 2^(NM) を軽く超えます。 状態空間はすべてのバイナリ グリッドのセットであるため、積極的なメモ化でも失敗します。 

重要な観察は、コンポーネントは変更されますが、操作には強力なマージ動作があるということです。 コンポーネントが反転すると、隣接する反対色のコンポーネントが吸収されるため、時間の経過とともに、任意の隣接領域をマージできるようになります。 実際には、最初の接続コンポーネントに制限されません。 ほとんど任意の方法で、グリッドを徐々に粗くして、より大きな接続されたブロックにすることができます。 

これは、最終的に重要なのは反転のシーケンスではなく、最終的に最終構成で内部的に一貫した領域にグリッドを分割することであることを意味します。 このような各領域はいずれかの色で均一にすることができ、異なる領域は B の不一致のコストによってのみ相互作用します。 

したがって、問題は、各領域に単一の最終色が割り当てられ、B との合計の不一致が最小限に抑えられるように、グリッドを接続された領域に分割する方法を決定することに帰着します。 パーティションが固定されると、各領域の最適な選択は独立します。B を一致させるか、B を基準に反転するかのいずれかで、その領域内で不一致が少なくなる方です。

これは、最適な決定が競合するセルを分離する方法でグリッドをコンポーネントに分割し、結果として得られる各コンポーネントが局所最小コストに寄与するという考えにつながります。

 ## アルゴリズムのチュートリアル

 1. 各セルがノードであり、エッジが 4 方向に隣接するセルを接続するグリッド上にグラフを構築します。 このグラフは、接続の変更を通じて地域が相互作用できる唯一の方法を表しています。 
2. この操作により、時間の経過とともに隣接する領域をマージできることがわかります。これは、このグラフ内の接続されたセルのセットを、最終的な構築において単一の制御可能なユニットとして扱うことを最終的に決定できることを意味します。 
3. 各セルについて、B と強制的に一致させるコストと B と強制的に一致させるコストを計算します。セルの場合、A がすでに B と等しい場合、B と一致させるコストは 0、それ以外の場合は 1 になります。 後で領域全体を反転すると、これらの役割が効果的に交換されます。 
4. 重要なステップは、グリッド グラフの接続された領域内で、その領域を B に合わせるか反転するかという、一貫したグローバルな決定を下す必要があることを認識することです。 これは、操作によってリージョンがマージされると、その内部構造によって均一な反転動作が強制されるためです。 
5. したがって、動作ダイナミクスによって引き起こされる制約の下で接続されたコンポーネントを特定し、コンポーネントごとに、A を変更せずに維持するか、完全に反転するかの最小値を計算します。 
6. すべてのコンポーネントにわたるこれらの最小コストを合計して、最終的な答えを求めます。 

### なぜ効果があるのか

 本質的な不変条件は、プロセスの進化を通じてセルのセットが接続されると、その後の操作ではそのセットがカラー反転に関して単一のユニットとして扱われるということです。 接続性は中間状態に依存しますが、隣接するコンポーネントをマージできるため、最終的な意思決定構造を、内部的に分離できない領域へのグリッドの分割として見ることができます。 

このような各領域内では、すべての有効な操作シーケンスが反転の均一なパリティを引き起こします。これは、領域が 2 つのグローバル状態 (A と整列または A に対して反転) のいずれかのみになることを意味します。領域ごとのこの 2 値の選択は、到達可能なすべての結果を説明するのに十分であり、B との不一致を最小限に抑えるには、領域ごとに独立して 2 つのオプションのうち良い方を選択することになります。 

領域は一度固定されると相互依存性を課さないため、グローバルな最適値はこれらのローカルな決定に分解され、合計の正確さを保証する必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from collections import deque

def solve():
    n, m = map(int, input().split())
    A = [input().strip() for _ in range(n)]
    B = [input().strip() for _ in range(n)]

    vis = [[False] * m for _ in range(n)]
    dirs = [(1,0), (-1,0), (0,1), (0,-1)]

    def bfs(i, j):
        q = deque([(i, j)])
        vis[i][j] = True
        cells = []

        while q:
            x, y = q.popleft()
            cells.append((x, y))
            for dx, dy in dirs:
                nx, ny = x + dx, y + dy
                if 0 <= nx < n and 0 <= ny < m and not vis[nx][ny]:
                    vis[nx][ny] = True
                    q.append((nx, ny))

        # compute cost inside this component
        cost_keep = 0
        cost_flip = 0

        for x, y in cells:
            if A[x][y] != B[x][y]:
                cost_keep += 1
            if A[x][y] == B[x][y]:
                cost_flip += 1

        return min(cost_keep, cost_flip)

    ans = 0
    for i in range(n):
        for j in range(m):
            if not vis[i][j]:
                ans += bfs(i, j)

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、グリッドをグラフとして扱い、フラッド フィルを実行して接続されたコンポーネントを抽出します。 各コンポーネントについて、コンポーネントを変更しないままにするか、A に対してすべてのセルを反転するかの 2 つの可能性が評価されます。B との不一致は両方のシナリオでカウントされ、より良い方が答えに追加されます。 

重要な実装の詳細は、BFS が色ではなくグリッドの隣接性のみに依存することです。 これは、接続性が操作を通じて進化する可能性があるという事実を反映しているため、依存する構造単位は初期の色コンポーネントではなく完全なグリッド グラフです。

 ## 特殊なケース

 A minimal 1×1 grid demonstrates the simplest behavior. The algorithm treats it as a single component, and correctly chooses whether to flip or not based on matching B.

A fully uniform grid shows the global flip behavior. Since all cells are connected, only two global states exist, and the algorithm correctly evaluates both.

 A checkerboard-style mismatch case stresses that even though many local differences exist, the component-based reasoning still aggregates correctly because decisions are evaluated over the entire connected structure rather than per cell greedily.
