 ## 解決策
 ## 問題の理解

 各テスト ケースでは、正確に完了するダウンロード プロセスについて説明します。`n`等しいステップ、から`0`に`n`。 ある中間点で`x`、 どこ`1 ≤ x ≤ n - 1`、ダウンロードは次の場所にあります。`x/n`完成と`(n - x)/n`残り。 完成した部分と残りの部分の比率を見るように求められます。`x : (n - x)`、それを減らし、整数になったときのこの比率の整数値のみを保持します。 

固定位置の場合`x`、比率は正確に整数になります。`x / (n - x)`は整数です。 それぞれ有効な`x`換算された比率値が合計に寄与します。 タスクは、この合計を計算することです。`n`。 

制約により、最大で次のことが許可されます。`10^5`テストケースとそれぞれの`n`と同じ大きさにすることができます`10^6`。 これにより、すべてのチェックが即座に除外されます。`x`から`1`に`n - 1`すべてのクエリに対して、約`10^11`最悪の場合の運用。 すべての位置に対するステップごとの対数アプローチであっても、事前処理を大幅に行わない限り、依然として遅すぎます。 

微妙なエッジケースが現れるのは、`n`プライムです。 その場合、自明な約数のみが存在するため、ロジックが誤って無効な位置をカウントしないようにする必要があります。 たとえば、次のようなとき`n = 5`、有効な位置は、多くの内分比が存在すると仮定するのではなく、慎重に導出する必要があります。 単純なシミュレーションではすべてが試される可能性があります`x`そして、特定の代数条件のみが重要であるという構造を見落としています。 

## アプローチ

 すべてのポジションに対してブルートフォースアプローチを繰り返す`x`から`1`に`n - 1`、比率を計算します`x / (n - x)`、整数かどうかをチェックし、整数であればそれを答えに追加します。 これは定義に直接従うため、正しいです。 ただし、必要なのは`O(n)`テストケースごとに作業するため、`O(nT)`全体として、これは両方の場合に実現可能な限界をはるかに超えています。`n`そして`T`大きいです。 

重要な簡素化は、完全性の条件を書き直すことで実現します。 比率`x / (n - x)`は整数です`k`もし、そしてその場合に限り`x = k(n - x)`。 並べ替えると`x(1 + k) = kn`、 それで`x = kn / (k + 1)`。 これが有効であるためには、`(k + 1)`分けなければなりません`kn`。 以来`k`そして`k + 1`は互いに素である、この力は`(k + 1)`分ける`n`。 

これにより、問題は位置を反復することから変わります。`x`の約数を反復する`n`。 各約数は 1 つの有効な比率値に直接対応し、解は次の数論関数のみに依存します。`n`、その線形範囲ではありません。 

これから、答えは除数の合計とカウントを含む単純な式に帰着します。これにより、次の値までのすべての値に対して完全な前処理が可能になります。`10^6`。

 ## アルゴリズムのチュートリアル

 問題を約数の算術に変換し、すべてを一度に事前計算します。`n`上限まで。 

1. 約数の合計を事前計算する`sigma(n)`あらゆる人にとって`n`まで`10^6`。 これは、各整数がその倍数すべてに寄与するふるいスタイルのアプローチを使用して行われます。 これが必要なのは、すべての有効な比率が個々の位置ではなく除数の構造に依存するためです。 
2. 約数の数を事前計算する`tau(n)`あらゆる人にとって`n`同じふるいの蓄積を使用します。 毎回、約数の出現ごとに 1 つの寄与を追加します。 
3. 各テスト ケースについて、次の内容を読んでください。`n`そして恒等式を使用して答えを計算します`answer = sigma(n) - tau(n)`。 
4. 各クエリの結果を即座に出力します。 

ステップ 3 が有効である理由は、有効な各比率を約数にマッピングすることにあります。`d`の`n`どこ`d ≥ 2`、そしてそのような各約数は正確に寄与します`(d - 1)`合計に。 

### なぜ効果があるのか

 すべての有効な比率は値に対応します`k`そのような`x / (n - x) = k`。 これにより、`x = kn / (k + 1)`、これは次の場合にのみ整数になります。`(k + 1)`分割する`n`。 書き込み`d = k + 1`、各約数`d ≥ 2`有効なポジションを 1 つだけ生成し、貢献します`d - 1`合計に。 このようなすべての約数を合計すると、次のようになります。`sum_{d|n, d≥2}(d - 1)`、代数的に単純化すると、`sigma(n) - tau(n)`。 

このアルゴリズムは、位置ベースの条件を、有効な比率と約数の間の正確な全単射に置き換えるので、正しいです。`n`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXN = 10**6

sigma = [0] * (MAXN + 1)
tau = [0] * (MAXN + 1)

for i in range(1, MAXN + 1):
    for j in range(i, MAXN + 1, i):
        sigma[j] += i
        tau[j] += 1

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        out.append(str(sigma[n] - tau[n]))
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```前処理ループは、古典的なふるいの方法で除数の合計とカウントを構築します。 あらゆる人にとって`i`、すべての倍数に貢献します`j`、その両方の値を に蓄積します`sigma[j]`そして1カウント`tau[j]`。 

クエリ ステップはテスト ケースごとに一定時間です。 引き算`sigma[n] - tau[n]`派生式を直接実装し、クエリ中の再計算を回避します。 

## 実用的な例

 ### 例 1

 検討してください`n = 6`。 

有効な比率は、1 より大きい 6 の約数 (2、3、および 6) から得られます。 

| 約数 d | 寄与率 (d - 1) |
 | --- | --- |
 | 2 | 1 |
 | 3 | 2 |
 | 6 | 5 |

 合計額は`1 + 2 + 5 = 8`。 

これは一致します`sigma(6) = 1 + 2 + 3 + 6 = 12`そして`tau(6) = 4`、 それで`12 - 4 = 8`。 

### 例 2

 検討してください`n = 10`。 

1 より大きい約数は 2、5、10 です。 

| 約数 d | 貢献 |
 | --- | --- |
 | 2 | 1 |
 | 5 | 4 |
 | 10 | 9 |

 合計は`14`。 

また、`sigma(10) = 18`、`tau(10) = 4`、 それで`18 - 4 = 14`。 

これらのトレースは、各約数が独立して寄与しており、変換が適用されると位置間に相互作用が存在しないことを示しています。

## テストケース```python
import sys, io

MAXN = 10**6
sigma = [0] * (MAXN + 1)
tau = [0] * (MAXN + 1)

for i in range(1, MAXN + 1):
    for j in range(i, MAXN + 1, i):
        sigma[j] += i
        tau[j] += 1

def solve_case(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline
    t = int(input())
    res = []
    for _ in range(t):
        n = int(input())
        res.append(str(sigma[n] - tau[n]))
    return "\n".join(res)

# custom small cases
assert solve_case("1\n1\n") == "0"
assert solve_case("1\n2\n") == "1"
assert solve_case("1\n6\n") == "8"
assert solve_case("1\n10\n") == "14"

# multiple tests
assert solve_case("3\n6\n10\n12\n") == "\n".join([
    str(sigma[6]-tau[6]),
    str(sigma[10]-tau[10]),
    str(sigma[12]-tau[12])
])

 ## 特殊なケース

 のために`n = 1`、中間位置がまったくないため、合計はゼロになる必要があります。 式は次のようになります`sigma(1) - tau(1) = 1 - 1 = 0`、特別な処理なしで定義に一致します。 

プライム用`n`、 のような`n = 5`、除数ベースの寄与のみが存在します。 約数は次のとおりです。`1`そして`5`、だからそれだけ`5`貢献する、与える`(5 - 1) = 4`。 式は次のようになります`sigma(5) - tau(5) = (1 + 5) - 2 = 4`、区間内に内部構造が存在しない場合でも、正確さを確認します。 

次のような高度に合成された数値の場合、`n = 12`、多くの約数が独立して貢献します。 各約数は前処理中に 1 回だけ寄与し、過大なカウントや寄与の欠落が発生しないため、アルゴリズムはこれを自然に処理します。
