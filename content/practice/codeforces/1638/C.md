 ## 解決策
 ## 問題の理解

 サイズの順列が与えられています$n$、1 から 1 までのすべての整数を含む配列です。$n$ある順序で 1 回だけ。 この順列から、無向グラフを構築します。$n$各頂点は順列内の位置に対応します。 2 つの頂点の間にエッジが存在します$i < j$前の位置の値が後の位置の値より大きい場合に限り、$p_i > p_j$。 基本的に、順列の各反転はグラフのエッジを定義します。 

タスクは、複数のテスト ケースについて、このグラフ内の接続コンポーネントの数を決定することです。 接続コンポーネントは、各ペアが直接またはエッジによって間接的に接続される頂点の最大のサブセットです。 

制約により許可されるのは、$n$まで$10^5$テストケースごとの合計と$n$すべてのテストケースにわたって、$2 \cdot 10^5$。 これは、線形または線形に近い複雑さを持つアルゴリズムは遅すぎることを意味します。 考えられるすべての頂点のペアをチェックする単純なアプローチでは、最大で次のようなパフォーマンスが得られます。$O(n^2)$テストケースごとに操作を行う必要がありますが、これは実行不可能です。 

微妙なエッジ ケースには、エッジが存在しないため各頂点が独自のコンポーネントを形成する厳密な順列の増加と、すべての頂点が 1 つのコンポーネントで接続される厳密な順列の減少が含まれます。 高い値と低い値を交互に並べると、複数の絡み合ったコンポーネントが作成される可能性があるため、慎重な取り扱いが必要です。 たとえば、$[2,1,4,3,5]$、最大値を追跡しない限り、成分はすぐにはわかりません。 

## アプローチ

 ブルートフォースアプローチは、すべてのペアを反復処理して完全なグラフを明示的に構築することです。$(i,j)$と$i<j$かどうかを確認します$p_i>p_j$。 次に、未訪問の各頂点から BFS または DFS を実行して、接続されているコンポーネントをカウントできます。 正しいのですが、これには次のことが必要です$O(n^2)$エッジプラスを構築するための操作$O(n + e)$グラフを移動するには、最大で$O(n^2)$として$e$もあるかもしれません$O(n^2)$。 これは失敗します$n=10^5$。 

重要な観察は、グラフ内の接続が反転によってのみ決定され、これらの接続には左から右の順序があるということです。 言い換えれば、任意の頂点は、より小さい値を持つその右側のすべての頂点に接続され、推移閉包は、重複する最大値を持つ連続したセグメントが単一のコンポーネントを形成することを意味します。 エッジを明示的に保存する必要はありません。 代わりに、これまでに確認された最大値を追跡しながら、左から右へ順列をスキャンできます。 現在のインデックスがこれまでに確認された最大値に等しいときはいつでも、コンポーネントを終了できます。これは、このセグメント内のすべての頂点が反転によって直接的または間接的に相互接続されているためです。 

この観察により、問題は、実行最大値を維持し、最大値が現在のインデックスに等しい点をカウントする順列の単一の線形スキャンに縮小されます。 これは$O(n)$これは、指定された制約に対して十分に効率的です。

 ## アルゴリズムのチュートリアル

 1. コンポーネントのカウンターを初期化します。`components = 0`、および現在の最大値を追跡する変数、`current_max = 0`。 
2. インデックスを使用して順列を反復処理します。`i`1から`n`(明確にするために 1 から始まり、コード内では調整を加えて 0 から始まります)。 
3. ポジションごとに、更新します`current_max`の最大値になる`current_max`そして`p[i]`。 これにより、現在のセグメントで見られる最大値が追跡されます。 
4. 現在のインデックスの場合`i`等しい`current_max`、接続コンポーネントの終わりに到達しました。 インクリメント`components`その理由は、このセグメント内のすべての前のインデックスが反転のチェーンを通じて接続されているため、現在の頂点がセグメントを閉じるということです。 
5. 順列全体をスキャンした後、`components`このテスト ケースの接続コンポーネントの数が含まれます。 
6. テスト ケースごとに上記の手順を繰り返し、結果を出力します。 

機能する理由: 定義上、エッジは、より大きな値がより小さな値に先行する場合に存在します。 最大値がまさにシーケンスの右端のインデックスであるインデックスのシーケンスは、すべての頂点が直接的または間接的に接続されているセグメントを形成します。 実行最大値により、重複する反転によって引き起こされるすべての間接的な接続が確実に捕捉されます。 現在の最大値が現在のインデックスと一致するたびに、後続の頂点はこのセグメントに接続し直すことができないため、別個のコンポーネントが形成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))
    components = 0
    current_max = 0
    for i, val in enumerate(p, start=1):
        current_max = max(current_max, val)
        if current_max == i:
            components += 1
    print(components)
```コードはテスト ケースの数を読み取り、それぞれのテスト ケースを反復処理します。 各順列について、現在の最大値を追跡します。 現在の位置が実行最大値と一致すると、コンポーネントが終了し、カウンターが増加します。 列挙は一緒に使用されます`start=1`配列インデックスを問題の 1 から始まる順列値に揃えます。 これにより、インデックスと値を比較する際の off-by-one エラーが防止されます。
