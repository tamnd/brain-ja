 ## 解決策
 ## 問題の理解

 グリッドとして表現されたペイントされたキャンバスが与えられます。`n`行と`m`列。 このグリッドの各セルには色が含まれており、ペイント プロセスは`2 × 2`ブラシ。 1 回のペイント操作で左上のセルが選択されます`(i, j)`そして色`k`、4つのセルをペイントします`(i, j)`、`(i+1, j)`、`(i, j+1)`、`(i+1, j+1)`カラーで`k`。 これは何度でも繰り返すことができます。 セルの最終的な色は、セルに影響を与えた最後の操作で適用された色です。 

タスクは、最終的な絵画を生成することができた有効なペイント操作のシーケンスを再構築するか、またはそれが不可能であると判断することです。 操作の数は以下を超えてはなりません`nm`。 

制約`2 ≤ n, m ≤ 1000`つまり、セルの総数は 10^6 に達する可能性があるため、`O(n m)`時間計算量は実現可能です。 これよりも悪いアルゴリズム`O(n m log n)`遅すぎると危険です。 

微妙なエッジケースが発生するのは、`2 × 2`ブロックを一貫して 1 色でペイントすることはできません。 たとえば、次のことを考えてみましょう。```
2 2
1 2
3 4
```シングルなし`2 × 2`ペイント操作では、4 色すべてを一度に生成できます。 ここでの出力は次のようにする必要があります。`-1`。 あらゆるものを貪欲に描こうとする素朴なアプローチ`2 × 2`均一性をチェックせずにブロックすると、何も通知せずに失敗する可能性があります。 

複数のオーバーラップによってのみセルをペイントできる場合、別のエッジ ケースが発生します。`2 × 2`ブロック。 たとえば、右下隅を左上隅にすることはできません。`2 × 2`, そのため、以前のブロックの一部としてペイントする必要があります。 これは、操作を再構築する必要がある順序に影響します。 

## アプローチ

 ブルートフォースアプローチは、可能な限り左上を試みることです。`(i, j)`そしてすべての色で、そこにブラシを適用することで最終的なキャンバスと一致するかどうかを確認します。 すべてのセルが描画されるまで繰り返し繰り返すことができます。 これは原理的には機能しますが、反復ごとに影響を受ける可能性があるため非効率的です。`O(n m)`ブロックが繰り返しブロックされ、`O((n m)^2)`複雑さは遅すぎるため、`n, m ≈ 1000`。 

重要な洞察は、最終的な絵から逆算して作業することです。 セルの最終的な色は、セルを描画した最後の操作から得られるため、以下を探すことができます。`2 × 2`少なくとも 1 つのセルがマークされておらず、空でないすべてのセルが同じ色であるブロック。 これらのブロックは、それらのセルに対する有効な「最後の操作」と見なすことができます。 このようなブロックを繰り返し識別し、処理済みとしてマークし、逆方向の操作を記録することで、順方向に適用されたときに絵画を生成するシーケンスを再構築できます。 

これにより、問題はオーバーラップに関するトポロジー処理の変形に帰着します。`2 × 2`ブロック。 各操作は 1 回だけ適用され、未処理のブロックがなくなるとアルゴリズムは終了します。 未処理のセルが有効なブロックに含まれない場合、描画は不可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((n m)^2) | O(nm) | 遅すぎる |
 | 逆貪欲 | O(nm) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. を初期化します。`done`サイズの行列`n × m`どのセルがすでに操作に含まれているかを追跡します。 
2. 空のリストを作成する`ops`操作を逆の順序で保存します。 
3. 全体を反復処理する`2 × 2`ブロック`(i, j)`のために`i = 0..n-2`、`j = 0..m-2`。 各ブロックについて、既に無視されている 4 つのセルの色をチェックします。`done`細胞。 すべての未完了セルが同じ色の場合`c`、4 つすべてを完了としてマークし、追加します`(i+1, j+1, c)`に`ops`。 
4. フルパスで新しいブロックが見つからなくなるまで、ステップ 3 を繰り返します。 
5. 繰り返しの後、すべてのセルがマークされているかどうかを確認します。`done`。 マークされていないセルがある場合は、印刷します`-1`。 それ以外の場合は逆にします`ops`順方向シーケンスを取得し、その後の操作の数を出力します。 

機能する理由: 不変条件は、マークされたすべてのブロックが、少なくとも 1 つのセルに対する有効な最後の操作に対応することです。 逆に処理することで、各セルの最終的な色はセルを覆う最後のブラシによって決定されるという制約が尊重されます。 各ブロックは最終的なペイントと一致する場合にのみ適用されるため、どの操作を行っても色が誤って上書きされることはありません。 一部のセルが一貫したブロックに属せない場合、絵画を生成することは不可能です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]
done = [[False]*m for _ in range(n)]
ops = []

while True:
    found = False
    for i in range(n-1):
        for j in range(m-1):
            cells = [(i,j),(i+1,j),(i,j+1),(i+1,j+1)]
            colors = set(a[x][y] for x,y in cells if not done[x][y])
            if len(colors) == 1 and colors:
                c = colors.pop()
                for x,y in cells:
                    done[x][y] = True
                ops.append((i+1,j+1,c))
                found = True
    if not found:
        break

if all(all(row) for row in done):
    print(len(ops))
    for op in reversed(ops):
        print(*op)
else:
    print(-1)
```このソリューションは、まずキャンバスを読み取り、追跡構造を初期化します。 ネストされたループは次のことをチェックします。`2 × 2`未完了のセル間の一貫性を保つためにブロックします。 の`found`フラグを使用すると、それ以上のブロックが適用できなくなるまでループが継続されます。 The final check ensures completeness. Reversing`ops`有効な順方向シーケンスが生成されます。 の使用`done`二重カウントを防ぎ、最終的な色を尊重します。
