 ## 解決策
 ## 問題の理解

 一連の垂直パネルが与えられ、各パネルは幅 1 と固定高さを持ちます。 視覚的には、各パネルは上部の水平バーに取り付けられており、上または下に移動できますが、常にそのバーに接続されたままにする必要があります。つまり、すべてのパネルは長さの垂直セグメントのままになります。$h_i$1 つのエンドポイントがバーに触れています。 

パネルを個別に再配置した後、2 つの長方形のポスターを配置します。1 つは完全にバーの上に、もう 1 つは完全にバーの下に配置する必要があります。 各ポスターはパネルの結合部分内に完全に収まる必要があり、バーを越えることはできません。 目標は、カバーされる領域の合計が最大になるように 2 枚のポスターの垂直方向のシフトと配置を選択することです。 

重要なインタラクションは、パネルを移動すると、バーの上または下にパネルがどれだけ位置するかが変化し、したがってそれが上部または下部のポスターにどれだけ役立つかが変化することです。 ただし、各パネルの合計の高さは固定されたままであるため、実際には各パネルの高さを再配分しています。$h_i$「貢献度が高い」と「貢献度が低い」に分けられます。 

制約により許可されるのは、$n \le 10^4$そして$h_i \le 10^{12}$。 これにより、サブ配列または分割構成に対する 3 次または 2 次の列挙が即座に除外されます。 平$O(n^2)$高価な内部スキャンが含まれる場合、このアプローチは遅すぎます。 期待すべきことは、$O(n \log n)$または$O(n)$おそらくプレフィックス/サフィックスの最適化または間隔にわたる貪欲な分解に基づいたソリューション。 

いくつかの特殊なケースについては、覚えておく価値があります。 すべての高さが小さくて均一である場合、単純な貪欲な人は、分割することが常に有益であると誤って仮定する可能性があります。$[1,1,1,1]$。 メソッドが連続性を考慮せずにパネルごとに部分的な高さを割り当てようとすると、多数の小さなセグメントにわたる寄与が誤って混合される可能性があります。これは、各ポスターが単一の連続した列ブロックを占有する必要があるため無効です。 

もう 1 つの微妙なケースは、単一の大きなセグメントが優勢である場合です。$[100,1,1,100]$。 間違った戦略では、両方のポスターを同じ高い領域内にインターリーブしようとする可能性がありますが、各パネルの高さを上部と下部で分割する必要があるため、オーバーラップすると使用可能な合計の高さが減少します。 

## アプローチ

 強引な解釈は、各パネルを上部のポスターと下部のポスターにどのように分割できるかを考えることから始まります。 パネルごとに$i$、値を割り当てることができます$u_i$バーの上で使用される部品として、$h_i - u_i$以下に使用する部分として。 次に、2 つの互いに素な間隔を選択するあらゆる可能な方法を試します。1 つは上部ポスターの合計です。$u_i$、および下のポスターの合計用に 1 つ$h_i - u_i$。 スプリットを割り当てて間隔を選択する方法は指数関数的に多く存在するため、これはすぐに実行不可能になります。 

たとえ分割構成を修正したとしても、素の部分配列の最適なペアを計算するには依然としてコストがかかります$O(n^2)$素朴にやれば。 これにより、全体の複雑さが限界をはるかに超えています。 

重要な観察は、パネルを「バランスの取れた」方法で部分的に分割しても利点がないということです。 内部分割は両方のポスターへの寄与を同時に減らすだけです。 代わりに、各パネルはどちらかの側に効果的にコミットする必要があります。つまり、上のポスターに完全に貢献するか、下のポスターに完全に貢献するかのいずれかになります。 

問題をこのように見ると、きれいな 1 次元の最適化になります。元の配列から 2 つの互いに素な部分配列を選択し、選択された各部分配列はその合計をポスターの 1 つに与えます。 最終的な答えは、2 つの重複しない部分配列の合計の最大可能合計です。 

これにより、問題は古典的な構造に要約されます。つまり、各位置またはその前で終了する最適なサブ配列と、各位置または各位置の後に開始する最適なサブ配列を計算し、それらを結合します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (スプリット + インターバル) | 指数関数 /$O(n^3)$|$O(n)$| 遅すぎる |
 | 最適 (接頭辞/接尾辞 カダネ) |$O(n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 この問題を、2 つの重複しない最大部分配列の合計を見つけることに変換します。 

1. 配列を計算する`left[i]`これは、プレフィックスに完全に含まれる最大サブ配列合計を表します。$[1, i]$。 これは、Kadane のアルゴリズムを使用して行われ、各位置までこれまでに見られた最良の結果を追跡します。 
2. 配列を計算する`right[i]`これは、サフィックスに完全に含まれるサブ配列の合計の最大値を表します。$[i, n]$。 これも、逆カダン スキャンを使用して計算されます。 
3. すべてのスプリットポイントを試してみる$i$、次のように解釈します。最初のポスターは完全に次のとおりです。$[1, i]$、2番目は完全に次のとおりです$[i+1, n]$。 分割ごとに計算します`left[i] + right[i+1]`。 
4. すべての分割点の最大値を取得します。 

これが機能する理由は、2 つの互いに素な部分配列の最適な構成は、何らかの境界によって分離できるためです。$i$。 1 つのサブアレイは完全にその境界の左側にあり、もう 1 つは完全に右側にあります。 プレフィックスとサフィックス DP により、両側で可能な限り最適なサブ配列がすでにわかっているため、正しい分割点を選択するだけで済みます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    left_best = [0] * n
    cur = a[0]
    best = a[0]
    left_best[0] = best

    for i in range(1, n):
        cur = max(a[i], cur + a[i])
        best = max(best, cur)
        left_best[i] = best

    right_best = [0] * n
    cur = a[-1]
    best = a[-1]
    right_best[-1] = best

    for i in range(n - 2, -1, -1):
        cur = max(a[i], cur + a[i])
        best = max(best, cur)
        right_best[i] = best

    ans = 0
    for i in range(n - 1):
        ans = max(ans, left_best[i] + right_best[i + 1])

    print(ans)

if __name__ == "__main__":
    solve()
```解決策は 2 つの Kadane パスに依存します。 前方パスは、すべてのインデックスで、プレフィックス内の任意の場所で終わる最適なサブ配列の合計を構築します。 逆方向パスはサフィックスに対しても同じことを行います。 最後のループでは、左側のソリューションと右側のソリューションを重複せずにステッチします。 

微妙な点は初期化です。 両方の Kadane トラッカーは、それぞれの方向の最初の要素から開始する必要があります。 ゼロで初期化すると、空のサブ配列が誤って許可されますが、これは明示的に許可されない限り無効です。 応答ループも次の時点で停止します。$n-2$これは、単一のポスター ソリューションが完全な配列のサブ配列をすでにキャプチャしているプレフィックスまたはサフィックスによって暗黙的に処理されている場合でも、インデックス パーティション化の観点から両側が空ではない必要があるためです。

 ## 特殊なケース

 単一パネルの場合、プレフィックス構造とサフィックス構造の両方が自明に一致するため、アルゴリズムは可能なサブ配列のみを取得することになります。 出力は単純に$h_1$、両方の Kadane パスがその値で正しく初期化されます。 

たとえば:

 入力:```
1
7
```プレフィックス配列とサフィックス配列には両方とも 7 のみが含まれており、答えは 7 であり、効果的に役立つポスターは 1 つだけであるという事実と一致します。 

次のような均一な配列で:```
4
2 2 2 2
```Kadane はプレフィックスの最適値を増加させて構築し、どの分割でも同じ合計を生成します。 アルゴリズムは正しく 8 を返します。これは、すべての要素を一緒にカバーする 2 つの互いに素な部分配列を選択することに対応します。 

完全に負の配列の場合:```
5
-1 -2 -3 -4 -5
```Kadane は、最適な各サブ配列が単一の要素であることを保証します。 次に分割すると、異なる側で最小の負の要素が 2 回選択されますが、重複が回避されるため、結果は正しくなります。$-1$これは、セグメントが長くなると合計が悪化するだけであることを反映しています。
