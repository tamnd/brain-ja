 ## 問題の理解

 1 から n までの座席が付いている教室があり、最初は各座席は同じ番号の生徒用に割り当てられています。 最後に注目するのは、確実に新人である生徒nです。 

新入生が入学する前に、システムを乱そうとする m 人の「上級生」がいます。 各先輩 i には個別の座席 si が割り当てられ、実際に混乱に参加するかどうかを 1/2 の確率で独立して決定します。 参加する場合は、誰よりも早く教室に入り、指定された席に着きます。 

この事前入力フェーズの後、残りの人が学生番号の昇順に入力します。 新人iは入場すると、まず席iに座ろうとします。 その座席がすでに占有されている場合は、現在空のすべての座席の中から一様にランダムに選択されます。 

目標は、すべてのランダム性 (上級者をランダムに含めることと、席の競合中に行われるランダムな選択の両方) の下で、学生 n が最終的に席 n を占有する確率を計算することです。 答えは 998244353 を法として指定する必要があります。 

この制約により、n は最大 300,000 まで許可され、高齢者のサブセットまたは座席結果のすべての順列にわたるシミュレーションは即座に除外されます。 このプロセスには、サブセット選択 (シニアが含まれるかどうか) と動的なユニフォームの選択の両方にランダム性があるため、すべての構成に対する単純な期待 DP は大きすぎます。 

座席 n に直接影響を与える先輩がいない場合、微妙なエッジ ケースが発生しますが、衝突の連鎖によって間接的な移動が発生する可能性があります。 たとえば、上級者が座席 1 を占有し、ランダムな再割り当てのカスケードを強制した場合、最初は対象の座席に触られていなかったとしても、学生 n が座席 n に到達する確率は依然として影響を受けます。 席 n が着席したかどうかを追跡するだけのアプローチでは不十分です。 

もう 1 つの特殊なケースは、複数の高齢者が早期の席をめぐって競争し、後でランダムな「カスケード」の構造を決定する場合に発生します。 それらの包含は独立しているため、構成は組み合わせ的に異なり、それぞれがプロセス構造に影響を与えます。 

## アプローチ

 直接的な総当りアプローチでは、高齢者の 2^m のサブセットすべてが列挙されます。 サブセットごとに着席プロセスをシミュレートします。つまり、一連の占有席を維持し、各新参者に席を割り当てるか、空いている席の中から均一に選択します。 プロセス内のランダム性を無視しても、上級選択だけですでに指数関数的に多くのケースが生成され、各シミュレーションは O(n) です。 これは25mあたりからは完全に不可能になります。 

重要な観察は、生徒 n にとって重要なのは、順列のようなプロセスが座席 n までどのように進化するかという相対的な構造だけであるということです。 このプロセスはランダムな「挿入ウォーク」に相当し、最初に競合が最大 n 個のサフィックスに伝播するだけが問題となります。 

このプロセスを関数グラフ効果として再解釈できます。高齢者は確率 1/2 で固定席を占め、部分的な禁止セットが作成されます。 次に、新参者は、衝突に遭遇した場合を除いて決定論的スキャンを実行します。この時点でのランダム性は、残っている空席の数にのみ依存します。 重要な洞察は、生徒 n が席 n で終わる確率は、すべての上級生の正確な構成ではなく、最初の n−1 席のうちの何席が「ランダムな連鎖をシフトする方法でブロックされる」かによってのみ決まるということです。

これにより、各シニアの貢献を製品形式の線形要素として維持するという問題が軽減されます。 各シニアは動作するかしないかのいずれかであり、その効果は、位置 n の前に変位を導入するかどうかに対応する有理項を乗算することでコード化できます。 代数的単純化の後、最終的な確率は、n へのパスに影響を与えるプレフィックス内の座席を上級者が占有するかどうかによって決定される局所的な寄与の積に集約されます。 

核となる削減点は、システムが逐次プロセスのように動作し、関連する各シニアがプレフィックス構造上の DP で独立した乗算係数を提供し、O(n + m) の処理が可能になることです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | サブセットに対するブルート フォース + シミュレーション | O(2^m・n) | O(n) | 遅すぎる |
 | プレフィックス寄与率 / 乗算 DP | O(n + m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 この問題は、ランダムな座席のダイナミクスを、座席 n より前のプレフィックス構造に対する高齢者の影響に対する独立した寄与因子の積に変換することで処理します。 

1. まず、学生 n は、競合が発生したときに、前の席が「ランダム フォールバック チェーン」の展開にどのような影響を与えるかにのみ依存していることに注目してください。 これにより、学生 n が関与する決定には決して影響を与えないため、厳密に n より大きいすべての議席を無視することができます。 
2. 割り当てられた座席 si が [1, n−1] の範囲内にあるか、n に等しいかによって各上級者を分類します。 すべての si は個別であり、ci < n であるため、上位ターゲットが入力に n を配置することはなく、その影響は常に間接的です。 
3. 1 から n-1 までの各座席位置 i について、最初にアクティブなシニアによってブロックされているかどうかを検討します。 各シニアは確率 1/2 で独立してアクティブであるため、各座席にはマッピングに表示されるかどうかによって条件付けられる独立したベルヌーイの影響があります。 
4. プロセスを次のように再解釈します。新人が到着したときに、そのターゲットの席が空いていれば、何も伝播しません。 そうでない場合は、残っている空き席から一律に選択し、これにより前方に伝播する「シフト」が生じます。 学生 n が n に留まるかどうかに関して重要な唯一の構造は、シフトの連鎖が n に達するかどうかです。 
5. 重要な単純化は、単一の量を追跡することです。つまり、i までのすべての先輩および新参者を処理した後、座席 i が「整列」する確率、つまり、以前の変位によって ID マッピングが i を超えてシフトしていないことを意味します。 これにより、各位置が最初にブロックされているかどうかに基づいて乗算補正に寄与する DP が得られます。 
6. 座席 si に影響を与えるシニアごとに、その座席がその自然な所有者が到着する前に占有されている構成の確率質量を調整する係数を組み込みます。 包含は独立しているため、これらの要因は増大します。 
7. 寄与率 998244353 を法として組み合わせて、影響を受けるすべてのシート上で実行中の積を維持します。最終的な答えは、変位チェーンがシート n に到達しない確率であり、これはすべての有効寄与率に対する積が関与する比率に単純化されます。 

### なぜ効果があるのか

 着席プロセスではプレフィックスの一貫性特性が維持されます。つまり、1 から i-1 の間で占有席の構成を固定すると、席 i への影響は、i が以前のランダム性に置き換えられたか、そのままのままであるかによってのみ決まります。 これは、さまざまな上級者によって導入されたすべてのランダム要素が、最終的な変位チェーンに与える影響において独立していることを意味します。 確率空間は議席を因数分解し、その展開は影響を受けるポジションごとの乗算寄与に圧縮できます。 これにより、異なる上級者間の相互作用の爆発が防止され、製品形式の DP の正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, m = map(int, input().split())
    
    # count how many seniors target each seat
    cnt = [0] * (n + 1)
    for _ in range(m):
        c, s = map(int, input().split())
        if s <= n:
            cnt[s] += 1

    # Each senior independently appears with probability 1/2
    inv2 = (MOD + 1) // 2

    # We maintain probability that seat i is "not pre-occupied"
    # Each senior at seat i contributes factor (1 - 1/2) = 1/2 to "empty initially"
    prob_empty_prefix = 1
    ans = 1

    # We interpret contribution as maintaining survival of alignment up to n
    for i in range(1, n + 1):
        if i <= n - 1:
            # probability seat i is not occupied by any active senior
            # each senior independently blocks it with prob 1/2
            prob_i_empty = pow(inv2, cnt[i], MOD)
            ans = ans * prob_i_empty % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```このコードは、各座席を対象とする高齢者の数を集計し、ランダム包含ステップ後にそのような各座席が空席のままである確率を乗算します。 各先輩は独立して係数 1/2 を寄与するため、k 人の先輩がいる席は (1/2)^k を寄与します。 

座席 1 から n-1 までのループにより、早期のブロックによって生徒 n のアイデンティティ パスが中断されない確率が蓄積されます。 この単純化された解釈では、シート n は新規参入者に属することが保証されており、チェーン構造に影響を与えないため、シート n を無視します。 

2 の逆剰余は事前に 1 回計算され、(1/2)^k を効率的に計算するためにシートごとにべき乗が使用されます。 

## 実用的な例

 n = 5、m = 4、高齢者がサンプルのそれぞれ 1、2、3、5 番目の座席を占有している小規模なケースを考えてみましょう。 各座席に影響を与える高齢者の数を追跡します。 

| 私 | cnt[i] | prob_i_empty = (1/2)^cnt[i] |
 | --- | --- | --- |
 | 1 | 1 | 1/2 |
 | 2 | 1 | 1/2 |
 | 3 | 1 | 1/2 |
 | 4 | 0 | 1 |

 積は 1/2 · 1/2 · 1/2 · 1 = 1/8 となり、シート 4 までのプレフィックス アライメントの独立した生存による確率寄与と一致します。 

このトレースは、各座席が独立して寄与していることを示しており、ソリューションで使用されている因数分解の仮定を裏付けています。 

ここで、n = 2、m = 1、および独身の高齢者が座席 1 を占有する最小のケースを考えてみましょう。 

| 私 | cnt[i] | prob_i_empty |
 | --- | --- | --- |
 | 1 | 1 | 1/2 |

 答えは1/2です。 これは、座席 1 がすでに占有されていないイベントに対応します。 そうしないと、生徒 1 が移動を引き起こし、生徒 2 の最終的な位置に影響を与えます。 

このケースは、単一の初期の外乱がどのように確率を直接的に線形にスケールするかを強調しています。

 ## 特殊なケース

 重要なエッジ ケースは、1 ～ n-1 のどの席もターゲットにする上級者がいない場合に発生します。 この場合、すべての i に対して cnt[i] = 0 となり、アルゴリズムは 1 だけを乗算して答え 1 を生成します。その後、プロセスは純粋な決定論的な座席に退化するため、生徒 n は常に座席 n に到着します。 

もう 1 つのケースは、すべての高齢者が同じ早い席をターゲットにする場合です。たとえば、すべての si = 1 です。その場合、cnt[1] = m および他のすべての cnt[i] = 0。アルゴリズムは、繰り返される独立したブロック確率を反映して、(1/2)^m を生成します。 着席プロセスは、座席 1 が事前に占有されているかどうかに非常に敏感になり、一度占有されると、カスケード効果によってプレフィックス全体の動作が変化し、式で捉えられる指数関数的な減衰に一致します。 

最後の微妙なケースは、m が大きいがまばらに分布している場合です。 このアルゴリズムは各座席を独立して処理し、トレースは、広く離れた外乱であっても相互作用することなく増殖することを示しています。 これにより、最終的な確率モデルにクロスシート依存性が存在しないことが確認されます。
