 ## 問題の理解

 ## アルゴリズムのチュートリアル

 中心的なアイデアは、プレフィックスの可用性の観点から実現可能性の条件を書き直すことです。 

1. 配列をソートする$a$降順ではない順に。 これにより、特定のしきい値に対して「十分小さい」敵の数を推論できます。 
2. 開始値を固定する$x$。 ポジションのために$i$、しきい値を定義します$T_i = x + i - 1$。 価値のある敵なら誰でも$\le T_i$最初の部分に表示される可能性があります$i$有効な順列の位置。 
3. 定義する$cnt_i(x)$最大でも価値のある敵の数として$T_i$。 これは時間ごとに利用可能な候補者の数です$i$。 
4. 有効な順列を選択する方法の数は、次の順序構造によって与えられます。$i$、新しく利用可能な要素から未使用の要素を選択する必要があります。 選択肢の数は、$$cnt_i(x) - (i - 1)$$以来$i-1$要素はすでに配置されています。 
5. したがって、$$f(x) = \prod_{i=1}^n (cnt_i(x) - i + 1)$$そして、因子が素数で割り切れるかどうかを気にします$p$。 
6.以来$p$は素数であり、積全体は非ゼロモジュロです$p$すべての因数が非ゼロモジュロである場合に限ります$p$。 したがって、すべてを避ける必要があります$x$一部の人にとっては$i$、$$cnt_i(x) \equiv i - 1 \pmod p$$7. 次に、どのようにするかを観察してください。$cnt_i(x)$と変化します$x$。 これは単に、値までのソートされた配列のプレフィックス数です。$x+i-1$。 したがって、$x$それぞれ増加します$cnt_i$フォームの予測可能なブレークポイントで段階的に増加します$a_j - i + 1$。 
8. すべてを追跡するのではなく$x$直接、空間を分解します。$x$すべての間隔に$cnt_i(x)$一定のままです。 このような間隔内では、積は定数モジュロになります。$p$したがって、すべての値が適切であるか、どれも適切でないかのどちらかです。 
9. 区間ごとに、いずれかの因数がゼロモジュロになるかどうかを確認します$p$。 その場合、間隔全体を不良としてマークします。 
10. 最後に、すべての整数を出力します。$x$不良間隔でカバーされていません。 

### なぜ効果があるのか

 重要な不変条件は、固定された$x$、実現可能性は複数の値セットにのみ依存します。$\{a_i\}$しきい値でフィルタリング$x+i-1$、そしてこのマルチセットは、いくつかの場合にのみ変更されます。$a_j$そのような閾値を超えます。 連続する交差の間では、すべてのプレフィックス数は変化しないため、次の乗算構造は次のようになります。$f(x)$安定しています。 これにより、グループ化が確実に行われます。$x$最大定常領域に入れると正確さが保たれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, p = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()

    # We will collect candidate bad intervals where f(x) ≡ 0 (mod p)
    intervals = []

    # For each position i, track how cnt_i(x) evolves.
    # Instead of explicitly maintaining cnt_i, we use the sorted structure:
    # cnt_i(x) = number of a_j <= x + i - 1

    # We sweep over i and possible k = cnt_i value transitions.
    # For a fixed i and k, cnt_i(x)=k holds when:
    # a[k-1] <= x + i - 1 < a[k]
    # => a[k-1] - i + 1 <= x < a[k] - i + 1

    # We treat a[0..n-1], with boundaries a[-1] = 0, a[n] = +inf
    INF = 10**18

    for i in range(1, n + 1):
        for k in range(0, n + 1):
            left_val = a[k-1] if k > 0 else 0
            right_val = a[k] if k < n else INF

            L = left_val - i + 1
            R = right_val - i

            if R < L:
                continue

            # cnt_i = k on [L, R]
            # factor = k - i + 1
            if (k - i + 1) % p == 0:
                intervals.append((L, R))

    # merge intervals
    intervals.sort()
    merged = []
    for l, r in intervals:
        if not merged or l > merged[-1][0]:
            merged.append([l, r])
        else:
            merged[-1][1] = max(merged[-1][1], r)

    # compute complement in positive x
    res = []
    cur = 1

    for l, r in merged:
        if cur < l:
            start = max(cur, 1)
            end = l - 1
            if start <= end:
                res.extend(range(start, end + 1))
        cur = max(cur, r + 1)

    # tail segment
    if cur <= 10**6:
        res.extend(range(max(cur, 1), 10**6 + 1))

    print(len(res))
    print(*res)

if __name__ == "__main__":
    solve()

微妙な点は、「さまざまなプレフィックス数」から固定セグメントへの変換です。$x$。 それが完了したら、残りは区間結合と補数の計算です。 特に各セグメントがいつ現れるかという点で半分開いているため、境界には注意する必要があります。$cnt_i$変化します。
