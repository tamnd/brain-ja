 ## 解決策
 ## セットアップ

 順序の真理値表$n$長さのバイナリ文字列です$2^n$。 ビーズは真理値表です$\beta$それは形ではありません$\alpha\alpha$。 変数の接頭辞を固定することによって得られるすべてのサブテーブルがビーズである場合、ブール関数は優れています。 

させて$S(n)$スイートブール関数の数を示します$n$変数。 目標は計算することです$S(n)$のために$n\le 7$。 

レベルのサブ関数$k$固定に相当する$x_1,\dots,x_k$、次数の真理値表を生成します。$n-k$。 甘さを実現するには、そのようなすべてのサブテーブルがビーズであることが必要です。 

## 解決策

 真理値表$\tau$秩序ある$m$順序の 2 つのサブテーブルがある場合にのみビーズです。$m-1$異なる。 したがって、順序の副次関数$m$LO および HI 制限が次の場合にのみビーズです。$x_1$は区別されます。 

ブール関数は、すべてのサブ関数について、次の場合にのみスイートです。$\tau$プレフィックス割り当てから生じる、誘導されたペア$(\tau_0,\tau_1)$満足する$\tau_0\ne \tau_1$。 

この条件は、関数の完全な 2 分決定木のすべてのノードに個別の LO および HI サブ関数があることを要求するのと同じです。 サブ関数はその真理値表によって完全に決定されるため、ノードの同等性はサブテーブルの同等性に正確に対応します。 

したがって、スイート関数によって誘導される構造は、深さの完全な二分決定木になります。$n$ここでは、すべてのノードが個別のサブ関数によってラベル付けされ、各ノードの順序が決まります。$m>0$順序の異なる部分関数の順序付きペアによって決定されます$m-1$。 

させて$T(m)$レベルに現れる一連の個別のサブ関数を示します$m$素敵な機能で$n$変数。 レベルで$0$関数は 1 つだけ、つまり元の関数です。 レベルからの各洗練ステップで$m-1$平らにする$m$、各サブ関数$\tau$秩序ある$n-m+1$順序付きペアに置き換えられます$(\tau_0,\tau_1)$順序の異なる部分関数の$n-m$。 

したがって、単一のサブ関数の許容される改良の数は次のようになります。$S(n-m) (S(n-m)-1)$、 以来$\tau_0$から任意に選択できます$S(n-m)$そして$\tau_1$残ったものから$S(n-m)-1$可能性。 

レベルで$m-1$がある$2^{m-1}$個別のノードは、最初の関数の異なる割り当てによって決定される個別の部分問題に対応するため、サブ関数とその洗練は独立しています。$m-1$変数。 したがって、スイート関数を深層から拡張する方法の総数は$m-1$深さまで$m$は$$\bigl(S(n-m)(S(n-m)-1)\bigr)^{2^{m-1}}.$$設定$m=n$の再発を与える$S(n)$に関しては$S(n-1)$:$$S(n) = \bigl(S(n-1)(S(n-1)-1)\bigr)^{2^{n-1}}.$$初期条件は$S(0)=2$、ゼロ変数の唯一のブール関数は定数であるため、$0$そして$1$、両方のビーズ。 

続いて計算してみましょう。 

のために$n=1$、$$S(1) = (S(0)(S(0)-1))^{1} = (2\cdot 1)^1 = 2.$$のために$n=2$、$$S(2) = (S(1)(S(1)-1))^{2} = (2\cdot 1)^2 = 4.$$のために$n=3$、$$S(3) = (4\cdot 3)^4 = 12^4 = 20736.$$のために$n=4$、$$S(4) = (20736\cdot 20735)^8.$$積を計算します。$$20736\cdot 20735 = 20736(20736-1) = 20736^2 - 20736.$$以来$20736^2 = 429981696$、減算すると、$$20736\cdot 20735 = 429981696 - 20736 = 429960960.$$したがって$$S(4) = (429960960)^8.$$のために$n=5$、$$S(5) = \bigl((429960960)^8((429960960)^8-1)\bigr)^{16}.$$のために$n=6$、$$S(6) = \Bigl(S(5)(S(5)-1)\Bigr)^{32}.$$のために$n=7$、$$S(7) = \Bigl(S(6)(S(6)-1)\Bigr)^{64}.$$したがって、値は完全に反復によって決定されます。 

したがって、$n\le 7$、$$\boxed{
\begin{aligned}
S(0)&=2,\\
S(1)&=2,\\
S(2)&=4,\\
S(3)&=20736,\\
S(4)&=(429960960)^8,\\
S(5)&=\bigl((429960960)^8((429960960)^8-1)\bigr)^{16},\\
S(6)&=\Bigl(S(5)(S(5)-1)\Bigr)^{32},\\
S(7)&=\Bigl(S(6)(S(6)-1)\Bigr)^{64}.
\end{aligned}}$$これで解決策は完了です。 ∎

 ## 検証

 反復はビード条件のみに依存し、すべてのノードで LO サブテーブルと HI サブテーブルが不等である必要があります。 これは、セクション 7.1.4 のビードの定義と一致します。 

各改良ステップで、すべてのノードは一意のプレフィックス割り当てによって決定される個別のサブ機能に対応するため、ノード間の独立性が保たれます。$2^{n-1}$ノードは、真理値表を互いに素な部分問題に分解することによって正当化されます。 

の計算$20736^2$として検証されます$$(20000+736)^2 = 400000000 + 2\cdot 20000\cdot 736 + 736^2
= 400000000 + 29440000 + 541696
= 429981696.$$引き算$20736$収量$429960960$、修正された製品を確認します。 

後続の式はすべて、この修正された基数のみに依存します。 

これで検証は完了です。 ∎
