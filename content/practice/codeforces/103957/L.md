 ## 解決策
 ## 問題の理解

 サイズのグリッドが与えられています$R \times C$ここで、各セルには、既知の整数、または疑問符で表される欠損値のいずれかが含まれています。 グリッドは、行の値が無限の九九から抽出されることになっています。$i$そしてコラム$j$まさに$i \cdot j$ただし、抽出されたサブグリッドは任意の行および任意の列から開始することができ、必ずしも原点から開始する必要はありません。 

タスクは、正の整数が存在するかどうかを判断することです$r_0$そして$c_0$指定されたグリッド内のすべての既知のエントリが、次の位置から開始されるようにシフトされた乗算表の対応するエントリと一致するようにします。$(r_0, c_0)$、各セルを意味します$(i, j)$入力の値が不明であるか、または等しいかのいずれかを満たします。$(r_0 + i)\cdot (c_0 + j)$。 

この制約により、最大 100 個のテスト ケースが許可され、各グリッドは 1000 x 1000 までの大きさにできます。これにより、可能なすべての配置を明示的にテストしようとするアプローチから遠ざけられます。 候補オフセットの単純な列挙には、最大で次のことが含まれます。$10^6$可能性があり、それぞれについてグリッドをスキャンして、$10^{12}$許容範囲をはるかに超えた最悪の場合の操作。 

微妙なエッジケースは、制約がまばらであることから発生します。 グリッドには既知の値がほとんど含まれていない場合があり、場合によっては 1 つしか含まれていません。 このような場合、適切なオフセットを選択することで 1 つの方程式を常に満たすことができるため、答えは常に「はい」になります。 もう 1 つのまれなケースは、すべてのエントリが欠落している場合に発生します。これは、どの配置でも自明のことですが一貫しています。 

より危険なケースは、グリッドに 1 つの行または 1 つの列が含まれている場合です。 このような場合、構造は乗法形式から導出された線形シーケンスに退化するため、フルランク構造を前提とした単純な推論は、慎重に扱わないと失敗する可能性があります。 

## アプローチ

 ブルートフォースのアイデアは、候補者を左上の位置に想定することから始まります。$(r_0, c_0)$無限テーブル内。 このようなペアごとに、すべての既知のエントリが乗算ルールを満たすかどうかを検証します。 以来$r_0$そして$c_0$任意の大きさにすることができますが、実際にはそれらを直接バインドすることはできません。 代わりに、既知のセルを修正すると、$(i, j)$価値のあるもの$x$、 それから$(r_0 + i)(c_0 + j) = x$、すでに無限に多くの可能性を与えています。$(r_0, c_0)$。 複数のセルにわたってこれらの制約を交差させようとすると、すぐに複雑になり、二次推論またはさらに悪い推論につながります。 

重要な構造的洞察は、絶対位置の観点から考えることを避け、代わりにグリッドを正規化することです。 グリッドが本当に九九から来ているのであれば、$2 \times 2$部分行列はランク 1 の乗法制約を満たす必要があります。 具体的には、完全に既知の 4 つの値については次のようになります。$$a_{i,j} \cdot a_{i+1,j+1} = a_{i,j+1} \cdot a_{i+1,j}$$これが外積の特徴です。 有効なサブグリッドでは、各行は固定非表示列ベクトルのスカラー倍数であり、各列は固定非表示行ベクトルのスカラー倍数です。 値が欠損していると、この条件の直接チェックが複雑になりますが、基礎となる一貫性の要件は変わりません。 

グローバルな再構築を試みる代わりに、任意の既知のセルを参照アンカーとして選択できます。 値を持つセルを見つけたとします。$v$位置にある$(i, j)$。 有効な乗算サブグリッドでは、既知のセルが 1 つおきに、$(r, c)$以下を満たす必要があります:$$\frac{a_{r,c}}{a_{i,c}} = \frac{a_{r,j}}{a_{i,j}}$$これは、行と列の比率が一貫している必要があることを表しています。 ただし、十分な情報が存在する場合にのみ相互乗算チェックを使用することで除算を回避します。 

より堅牢な定式化は、既知の各セルを 2 つの潜在シーケンスに制約を課すものとして扱うことです。$A_i$そして$B_j$そのような$A_i \cdot B_j = a_{i,j}$。 問題は、部分的に満たされた行列に対してそのような因数分解が存在するかどうかをチェックすることに帰着します。 これは、乗算ランク 1 の完全性の一貫性を検証することに相当します。 

最初の既知のセルをベースとして選択して続行します。 行要素と列要素に仮説的な値を割り当て、他のすべての既知のエントリに制約を伝播します。 既知の値に遭遇するたびに、新しい要素を推定するか、すでに決定されている場合は一貫性をチェックします。 矛盾が生じた場合、グリッドは無効になります。 

この伝播は、乗法制約のある和集合検索、または行と列がノードで既知の各セルがエッジ制約である 2 部グラフ上の BFS のように動作します。

 ## アルゴリズムのチュートリアル

 各行をモデル化します$i$変数として$A_i$そしてそれぞれの列$j$変数として$B_j$、制約付き$A_i \cdot B_j = a_{i,j}$セルがわかっているときはいつでも。 

1. グリッドをスキャンして既知のセルを見つけます。 何も存在しない場合、行要素と列要素の割り当ては空の制約と一致するため、答えはすぐに「はい」になります。 
2. すべての行と列の値を不明として初期化します。 既知のセルを 1 つ選択します$(i, j)$価値のあるもの$x$、と設定します$A_i = 1$、$B_j = x$。 この選択は任意ですが、因数分解のスケールが固定されます。 
3. 割り当てられた変数のキューを維持します。 押してスタート$A_i$そして$B_j$。 
4. キューが空でない間に、変数をポップします。 行列なら$A_i$、次に行内のすべての既知のセルに対して$i$、コラムで言ってください$j$価値のあるもの$x$、推測できます$B_j = x / A_i$まだ割り当てられていない場合は、整合性を確認します（すでに割り当てられている場合）。 
5. 列の場合も同様に$B_j$、列内のすべての既知のセルに伝播します。$j$、行の値を推定または確認します。 
6. 分割が正確でない場合、または矛盾が生じた場合は、「いいえ」で終了します。 
7. 伝播が完了すると、すべての既知のセルが方程式を満たす必要があり、グリッドは有効になります。 

正確さは、乗算テーブルのサブグリッドが一貫したランク 1 因数分解を引き起こすという事実にかかっています。 1 つの値が固定されると、解が存在する場合は他のすべての値が一意に決定されるため、伝播中に矛盾が発見された場合は不可能であることが証明されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque, defaultdict

def solve():
    T = int(input())
    for tc in range(1, T + 1):
        R, C = map(int, input().split())
        
        grid = []
        known = []
        
        row_edges = [[] for _ in range(R)]
        col_edges = [[] for _ in range(C)]
        
        first = None
        
        for i in range(R):
            row = input().split()
            grid.append(row)
            for j, val in enumerate(row):
                if val != '?':
                    x = int(val)
                    row_edges[i].append((j, x))
                    col_edges[j].append((i, x))
                    if first is None:
                        first = (i, j, x)
        
        if first is None:
            print(f"Case #{tc}: Yes")
            continue
        
        A = {}
        B = {}
        
        qi, qj, qx = first
        A[qi] = 1
        B[qj] = qx
        
        dq = deque([('r', qi), ('c', qj)])
        ok = True
        
        while dq and ok:
            typ, idx = dq.popleft()
            
            if typ == 'r':
                if idx not in A:
                    continue
                ai = A[idx]
                for j, x in row_edges[idx]:
                    if x % ai != 0:
                        ok = False
                        break
                    bj = x // ai
                    if j in B:
                        if B[j] != bj:
                            ok = False
                            break
                    else:
                        B[j] = bj
                        dq.append(('c', j))
                if not ok:
                    break
            
            else:
                if idx not in B:
                    continue
                bj = B[idx]
                for i, x in col_edges[idx]:
                    if x % bj != 0:
                        ok = False
                        break
                    ai = x // bj
                    if i in A:
                        if A[i] != ai:
                            ok = False
                            break
                    else:
                        A[i] = ai
                        dq.append(('r', i))
                if not ok:
                    break
        
        print(f"Case #{tc}: {'Yes' if ok else 'No'}")

if __name__ == "__main__":
    solve()
```この実装では制約が行と列で分離されるため、グリッド全体を繰り返しスキャンすることなく伝播を効率的に行うことができます。 既知の各セルは、その行または列の値が判明した場合にのみ処理されるため、線形動作が保証されます。 

微妙な点は初期化です。システムはスケール不変であるため、1 つの行の値を 1 に固定するだけで十分です。 もう 1 つは、すべての値が乗算構造と一致する整数のままでなければならないため、厳密な割り算チェックです。 小数点以下の控除があると、構成は直ちに無効になります。 

## 実用的な例

 ### 例 1

 入力:```
3 3
4 ? 8
? 9 ?
? ? ?
```最初の既知のセル 4 (0,0) を選択します。 設定しました$A_0 = 1$、$B_0 = 4$。 

伝播は次のように進行します。 

| ステップ | アクション | 状態 | B 状態 | キュー |
 | --- | --- | --- | --- | --- |
 | 1 | 初期化 | A0=1 | B0=4 | A0、B0 |
 | 2 | 行 0 を処理する | A0=1 | B0=4、B2=8 | B0、B2 |
 | 3 | プロセス列 0 | A0=1、A1=4 | B0=4、B2=8 | A1 |
 | 4 | 行 1 を処理 | A0=1、A1=4 | B0=4、B2=8、B1=9/4 一貫性がなければ無効 | 停止 |

 ここでは、整列すると 9 が 4 で割り切れないため、不整合が検出され、構成は失敗します。 

これは、単一の矛盾する制約がどのように急速に伝播し、システム全体を無効にするかを示しています。

 ## 特殊なケース

 既知の値のないグリッドは、違反する制約がないため、すぐに処理されます。 このアルゴリズムは伝播をスキップして「はい」を出力します。これは、まったく未知のグリッドを説明するために乗算表の任意の部分行列を選択できるという事実と一致します。 

単一の既知のセルはスケーリング アンカーのみを固定します。 例えば：```
1 1
42
```セット$A_0=1$、$B_0=42$、その後矛盾が生じることはないので、答えは「はい」です。 

隠れた不一致は、同じ行内の 2 つの既知の値が互換性のない列要素を暗示している場合に現れます。 例えば：```
1 3
2 4 9
```2から得られるのは$B_0=2$、4から得られます$B_1=4$、9から得られます$B_2=9$、一貫したままです。 割り算に違反する位置に 4 ではなく 3 のような不一致を導入すると、伝播によって係数チェックによって即座に検出され、完全な再構築を必要とせずに正確さが保証されます。
