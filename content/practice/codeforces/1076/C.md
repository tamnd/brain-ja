 ## 問題の理解

 私たちには番号が与えられています$d$そして、それを 2 つの非負の実数に分割できるかどうかを決定したいと考えています。$a$そして$b$2 つの条件が同時に成立する: それらの合計は等しい$d$、その積も次と等しい$d$。 

したがって、幾何学的には、和と積が固定目標値と一致する非負の実数直線上の 2 つの点を探します。 各テスト ケースでは、そのようなペアが存在するかどうかを尋ねます。存在する場合は、必ずしも一意のペアではなく、有効なペアを構築する必要があります。 

制約$d \le 10^3$そして$t \le 10^3$これは、テスト ケースごとに定数時間の計算のみが必要であることを意味します。 細かい粒度で候補値を反復するアプローチは依然として許容されますが、指数関数的または構造のない精度検索に依存するものは不要です。 方程式の構造は、数値の力ずくではなく、直接の代数的還元を示唆しています。 

主な微妙な点は、この問題では最大精度の実数が許容されることです。$10^{-6}$。 これにより、純粋な整数推論が除外され、条件を実数値の制約として解釈する必要が生じます。 もう 1 つの微妙な点は、浮動小数点ルートが境界ケース付近、特に境界ケース付近にあることです。$d = 0$そして$d = 1$、単純な数式では異なる動作をする可能性があるため、明示的な処理が必要です。 

故障モードは、二次方程式が常に非負の実数解を生成すると仮定しようとすると発生します。 例えば、$d = 1$代数操作が境界線の解を誤解を招く可能性があるにもかかわらず、必要な等式制約の下でシステムの一貫性を失わせる形でゼロに崩壊する判別式を導きます。 もう一つのエッジケースは、$d = 0$、両方の変数が同時にゼロに折りたたまれなければなりません。 

## アプローチ

 強引な見方では、候補者を選択しようとするでしょう$a$そして計算する$b = d - a$、次に、次のことを確認します。$a \cdot b \approx d$。 以来$a$が実数であれば、範囲を離散化します$[0, d]$多くの小さなステップに分かれています。 これは、すべての有効な解が合計制約を正確に満たさなければならないため、原理的には正しいですが、解空間は連続であり、精度要件を満たすために非常に細かいサンプリングが必要なため、計算的には無意味になります。 テスト ケースごとに 10^6 ステップがある場合でも、10^3 テストの最悪の入力はすでに遅すぎます。 

重要な構造的観察は、一度代入するとシステムが完全に決定されるということです。$b = d - a$。 これにより、製品の状態が次の単一の二次方程式に変換されます。$a$。 ただし、毎回直接解くのではなく、実現可能性は、結果として得られる二次方程式が非負領域の実根を持つかどうかのみに依存し、それらの根は明示的に構築できることがわかります。 制約構造により、問題はパラメーターを使用して二次方程式を解くことに帰着します。$d$、有効なルート ペアを選択します。 

代数は次のことを導きます。$$a(d - a) = d \Rightarrow a^2 - da + d = 0$$これにより、次のような判別条件が得られます。$$\Delta = d^2 - 4d = d(d - 4)$$したがって、本当の解決策は次の場合にのみ存在します。$d \ge 4$または$d = 0$。 特別な場合$d = 4$繰り返しルートが得られ、$d = 0$簡単に崩壊する$(0, 0)$。 のために$d \in (0, 4)$、判別式は負であるため、実際の解は存在しません。

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る$d$。 目標は、積和条件から導出される二次制約システムの実現可能性を判断することです。 
2. もし$d = 0$、すぐに出力$a = 0$、$b = 0$。 これが、矛盾を生じさせずに和と積の両方を同時にゼロにする唯一の方法です。 
3. もし$d < 4$、「N」を出力します。 これは判別式から導かれます$d(d - 4)$、これはネガティブになり、実際の解決策を排除します。 
4. それ以外の場合は判別式を計算します$\Delta = d^2 - 4d$。 この値は、制約から導出された二次方程式が実根を持つかどうかを決定します。 
5. の平方根を求めます。$\Delta$そして小さい方の根を計算します。$$a = \frac{d - \sqrt{\Delta}}{2}$$小さい方の根を選択すると、両方の値が負ではなくなり、数値的に安定します。 
6. コンピューティング$b = d - a$。 これにより合計制約が正確に適用され、浮動小数点ドリフトの違反が防止されます。$a + b = d$。 
7. 「Y」を出力し、続いて$a$そして$b$。 

### なぜ効果があるのか

 すべての有効なペアは両方の制約を同時に満たす必要があり、1 つの変数を代入するとシステムが単一の 2 次方程式に還元され、その根がすべての実行可能な解を正確に特徴づけます。 判別式は実解の存在を完全に決定し、構築された根は代数的等価性により和条件と積条件の両方を自動的に満たします。 変換は制約に対して全単射であるため、これらのルートの外側に他のペアは存在できません。$b = d - a$。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

t = int(input())
for _ in range(t):
    d = float(input().strip())

    if d == 0:
        print("Y 0.0 0.0")
        continue

    if d < 4:
        print("N")
        continue

    disc = d * d - 4 * d
    root = math.sqrt(disc)

    a = (d - root) / 2
    b = d - a

    print("Y", a, b)
```コードは二次リダクションを直接実装します。 早期の終了は、縮退した実行不可能な範囲を処理し、不必要な浮動小数点演算を回避します。 判別計算が安定しているのは、$d \le 10^3$、 それで$d^2$浮動小数点精度の制限内に十分収まります。 コンピューティング$b$として$d - a$合計制約を正確に保持し、丸め誤差の複合を回避します。

import sys, io
import math

def solve():
    input = sys.stdin.readline
    t = int(input())
    for _ in range(t):
        d = float(input().strip())

        if d == 0:
            print("Y 0.0 0.0")
            continue
        if d < 4:
            print("N")
            continue

        disc = d * d - 4 * d
        root = math.sqrt(disc)
        a = (d - root) / 2
        b = d - a
        print("Y", a, b)

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    from contextlib import redirect_stdout
    out = io.StringIO()
    with redirect_stdout(out):
        solve()
    sys.stdin = old
    return out.getvalue().strip()

 ## 特殊なケース

 のために$d = 0$、アルゴリズムはすぐに出力します$(0, 0)$。 代入すると合計 0 と積 0 が得られ、完全に一致します。 

のために$d = 3$、アルゴリズムはそのケースを拒否します。$d < 4$。 判別式$9 - 12 = -3$実際のルートがないことが確認されるため、有効なペアは存在しません。 

のために$d = 4$、判別式はゼロになり、単一の反復根が得られます。$a = b = 2$。 アルゴリズムは計算します$\sqrt{0} = 0$、その後、戻ります$a = 2$、$b = 2$、両方の制約を正確に満たします。
