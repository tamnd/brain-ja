 ## 解決策
 ## 問題の理解

 私たちは、上下左右の 4 方向への移動が許可される無限グリッドに取り組んでおり、各方向に 1 ステップのコストがかかります。 開始セル、ターゲット セル、および踏むことができない禁止セルの 3 つの特別なセルが与えられます。 このタスクは、禁止されたセルに到達することなく、スタート地点からターゲットまで移動するために必要な最短の移動回数を計算することです。 

禁止セルが存在しない場合、自由に移動できるグリッドでは、最短経路は常に水平方向と垂直方向の間隔の合計であるため、答えは単純にスタートとターゲットの間のマンハッタン距離になります。 

最大 10^4 のテスト ケースという制約により、クエリごとのグラフ検索を回避する必要があります。 座標が 1000 で制限されていても、グリッドには概念的には制限がなく、BFS の複雑さは入力サイズではなく探索された領域に依存するため、グリッド上の BFS は遅すぎます。 テスト ケースごとに O(1) 式が必要です。 

重要なエッジ ケースは、禁止セルが A と B の間の直線のマンハッタン パス上に正確に存在する場合に発生します。たとえば、A が (1,1)、B が (1,5)、F が (1,3) の場合、直接の垂直パスはブロックされます。 単純なマンハッタン距離の計算では 4 が返されますが、F の周りを迂回する必要があるため、本当の答えは 6 になります。もう 1 つの微妙なケースは、F が A と B の間の最短経路コリドー上にない場合です。 その場合、答えは変わりません。 

## アプローチ

 障害がなければ、問題は些細なものです。 2 つのグリッド点間の最短パスは、x 座標の絶対差と y 座標の絶対差として計算される単純なマンハッタン距離です。 これが機能するのは、すべての最適なパスが正確に同じ回数の水平方向および垂直方向の移動を行う必要があり、それらの移動の順列が有効であるためです。 

単一の禁止セルを導入すると、非常に限られた方法でのみ状況が変わります。 答えがマンハッタンの距離と異なるのは、A から B へのすべての最短経路が F を通過する必要がある場合だけです。これは、A、B、F が同じ行または列セグメント上にあり、F がそれらの間にある場合に正確に発生します。 この状況では、最短経路は F を踏んでしまうため、それを迂回して迂回する必要があり、ちょうど 2 つの余分なステップが追加されます。 

F がマンハッタンの意味で A と B によって形成される幾何学的セグメント上にない場合でも、F に着地しないように移動の順序をわずかに調整することでマンハッタンの距離を達成できます。これが可能となるのは、単一のパスから外れた点を回避する代替の最短ルートが常に少なくとも 1 つ存在するためです。 

したがって、解決策は、マンハッタン距離を計算し、F が直線セグメント上の A と B の直接の位置合わせをブロックするかどうかを確認することになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | グリッド上のブルートフォース BFS | クエリあたり O(N) (事実上無制限) | O(N) | 遅すぎる |
 | マンハッタン+ブロッキングチェック | テストごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 基本的な答えとして、A と B の間のマンハッタン距離を計算します。 これは、障害物を無視した可能な最短経路を表します。 
2. A と B が水平または垂直に揃っているかどうかを確認します。 このように位置合わせされていない場合、単一の点が F を通るすべての最短経路を強制することはできないため、基本的な答えは有効なままになります。 
3. A と B が同じ x 座標を共有する場合、最短パスは垂直方向にのみ移動します。 この場合、F も同じ垂直線上にあり、その y 座標が A と B の y 座標の間に厳密に存在するかどうかを確認します。 
4. A と B が同じ y 座標を共有する場合は、水平方向の位置合わせの対称チェックを実行します。 
5. いずれの場合でも、F が A と B の間のセグメント上に正確に存在する場合、ブロックされたセルの回りの迂回を考慮して、答えを 2 増やします。

迂回コストがちょうど 2 であるのは、直線上のブロックされた中間セルを回避する最小の方法は、1 つのユニットを脇に退かせ、その周りを通過して、元のラインに戻ることであるという事実から来ています。 

### なぜ効果があるのか

 グリッド内の最短パスは、水平方向と垂直方向の移動の順序を選択することによって完全に決定されます。 単一のブロックされたセルは、最適な長さを維持するすべての単調パス上にある場合にのみ、すべての最短パスを無効にできます。 これは、パスが単一の行または列セグメントに制限されている場合にのみ発生します。 この構成の外では、パスの合計長を増加させることなく、禁止されたセルがバイパスされるように、いつでも移動の順序を変更できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    xA, yA = map(int, input().split())
    xB, yB = map(int, input().split())
    xF, yF = map(int, input().split())

    ans = abs(xA - xB) + abs(yA - yB)

    if xA == xB == xF:
        if min(yA, yB) < yF < max(yA, yB):
            ans += 2

    if yA == yB == yF:
        if min(xA, xB) < xF < max(xA, xB):
            ans += 2

    return ans

t = int(input())
out = []
for _ in range(t):
    input()
    out.append(str(solve()))

print("\n".join(out))
```この実装では、マンハッタン距離を直接計算し、禁止セルが共有軸上の A と B の間に厳密に存在する場合、定数時間補正を適用します。 テスト ケース間の空白行は、入力形式に含まれるため、明示的に使用されます。 

よくある実装上の間違いは、厳密な不等式チェックを忘れることです。 F が A または B に等しい場合、問題によって個別のセルが保証されるため、迂回ロジックはトリガーされませんが、その仮定が緩和されたとしても、エンドポイントは同様に最短パスをブロックしません。

 | 初期化 | - | - | 0 | 4 |

ここで、A = (2,5)、B = (2,1)、F = (2,3) について考えてみましょう。 マンハッタンの距離は 4 です。すべての点が x = 2 を共有し、F が y = 5 と y = 1 の間にあるため、すべての直接垂直最短パスは F を通過します。

 ## 特殊なケース

 重要なケースの 1 つは、A と B が位置合わせされているが、F がセグメントの外側にある場合です。 たとえば、A = (1,1)、B = (1,5)、F = (1,10) となります。 アルゴリズムは厳密な不等式をチェックするため、補正は適用されず、答えは 4 のままです。F に触れずにパスを上向きにルーティングできるため、これは正しいです。 

別のケースは、位置合わせが x または y で維持されるが、F が 1 つの端点と一致する場合です。 この問題により明確なポイントが保証されますが、そうでない場合でも、パスがそこで開始または終了するため、エンドポイントは迂回を強制しません。 

最後のケースは、F がそのうちの 1 つと座標を共有していても、A と B が一直線に並んでいない場合です。 マンハッタン パスは、長さを維持しながら F を回避するようにいつでも再配置できるため、修正は必要ありません。
