 ## 解決策
 ## 問題の理解

 _n_ 行、_m_ 列のグラフ用紙を表す長方形のグリッドが与えられます。 いくつかの四角形は影付きでマークされています。`*`、残りは影なしで、 でマークされています。`.`。 ボブは、最小限のコストで送信できるように、影付きの正方形をすべて含む最小の長方形を切り出したいと考えています。 出力は単にこの四角形の内容であり、元のシェーディング パターンが維持されます。 

どちらの次元も 50 で区切られているため、グリッドは小さくなります。 つまり、すべてのセルに数回アクセスするアルゴリズムは十分に高速です。 本質的に問題は、すべての周囲の最小の境界ボックスを見つけることです。`*`文字。 

明らかではないエッジ ケースには、すべての影付きのセルが同じ行、同じ列上にある、または角に集まっている状況が含まれます。 たとえば、入力が次の場合:```
3 3
*..
...
...
```出力は次のようにする必要があります`*`行または列全体ではありません。 たとえば、常に完全な行または列を印刷するような不注意な実装では、空のセルが過剰に含まれる可能性があります。 同様に、1 行または 1 列のみの四角形は、インデックス エラーを生成せずに正しく処理される必要があります。 

## アプローチ

 ブルートフォースアプローチは、グリッド内のすべての可能な四角形を反復処理し、各四角形にすべての要素が含まれているかどうかをチェックすることです。`*`そして面積が最小のものを選択します。 これが機能するのは、正確さが保証されているためです。すべての星を含む四角形が候補となります。 ただし、操作回数はおおよそ`(n * m)^2 * (n * m)`各四角形をチェックするには、約 1,500 万回の反復が必要です。`n = m = 50`。 これも Python では 1 秒未満で実行できますが、非効率的であり、不必要です。 

最適なアプローチは問題の構造を利用します。必要なのは最上部、最下部、最左部、および最右部のみです。`*`細胞。 最小と最大の行インデックスと列インデックスを記録すると、`*`と表示されると、これらの 4 つの値が直ちに最小外接四角形を定義します。 これにより、各セルを 1 回だけスキャンし、これらの境界によって定義されたサブグリッドを出力するという作業が軽減されます。 重要な点は、最小の四角形は影付きのセルの端の座標と一致する必要があるため、他の四角形をテストする必要がないということです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((nm)^3) | O(nm) | 遅すぎる |
 | 最適 | O(nm) | O(1) おまけ | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最小行と最大行を追跡するために変数を初期化します (`top`、`bottom`) と列 (`left`、`right`)を含む`*`。 セット`top`そして`left`非常に多くの数に、そして`bottom`そして`right`-1まで。 
2. すべてのセルを反復処理します。`(i, j)`グリッド内で。 セルに次の内容が含まれている場合`*`、 アップデート`top`に`min(top, i)`、`bottom`に`max(bottom, i)`、`left`に`min(left, j)`、 そして`right`に`max(right, j)`。 このステップでは、影付きの領域の端を特定します。 
3. スキャン後、`top`に`bottom`行範囲を与え、`left`に`right`すべての星を含む最小の長方形の列範囲を示します。 
4. 行を反復処理する`top`に`bottom`各行について、列の部分文字列を出力します`left`に`right`。 これにより、元のシェーディング パターンがそのままの最小の長方形が出力されます。 

機能する理由: アルゴリズムは、次の不変条件を維持します。`top`、`bottom`、`left`、 そして`right`常にすべてを包含する`*`これまで見られた。 すべてのセルがスキャンされると、これらの境界によって定義される四角形が可能な限り最小になります。これより小さな四角形では、少なくとも 1 つの四角形が欠落してしまうためです。`*`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
grid = [input().strip() for _ in range(n)]

top, bottom = n, -1
left, right = m, -1

for i in range(n):
    for j in range(m):
        if grid[i][j] == '*':
            top = min(top, i)
            bottom = max(bottom, i)
            left = min(left, j)
            right = max(right, j)

for i in range(top, bottom + 1):
    print(grid[i][left:right + 1])
```コードはグリッドを読み取り、影付きのセルの極端な位置を追跡し、それに応じてグリッドをスライスします。 使用する`strip()`改行文字が干渉しないようにします。 Off-by-one エラーは、スライスに両方のエンドポイントを含めることによって回避されます。`right + 1`そして`bottom + 1`。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    top, bottom = n, -1
    left, right = m, -1

    for i in range(n):
        for j in range(m):
            if grid[i][j] == '*':
                top = min(top, i)
                bottom = max(bottom, i)
                left = min(left, j)
                right = max(right, j)

    for i in range(top, bottom + 1):
        print(grid[i][left:right + 1])

    return sys.stdout.getvalue().strip()

# Provided sample
assert run("6 7\n.......\n..***..\n..*....\n..***..\n..*....\n..***..") == "***\n*..\n***\n*..\n***", "sample 1"

# Single star
assert run("3 3\n...\n.*.\n...") == "*", "single star"

# Full rectangle
assert run("2 2\n**\n**") == "**\n**", "full 2x2 rectangle"

# Row-only rectangle
assert run("3 5\n.....\n*****\n.....") == "*****", "row only"

# Column-only rectangle
assert run("4 3\n.*.\n.*.\n.*.\n.*.") == "*\n*\n*\n*", "column only"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`3 3\n...\n.*.\n...`|`*`| 単一セルの長方形 |
 |`2 2\n**\n**`|`**\n**`| 完全な小さな長方形 |
 |`3 5\n.....\n*****\n.....`|`*****`| 単一行の長方形 |
 |`4 3\n.*.\n.*.\n.*.\n.*.`|`*\n*\n*\n*`| 単一列の長方形 |

 ## 特殊なケース

 すべての星が一列に並んでいたら、`top`そして`bottom`等しいです。 私たちのループはその行だけを正しく出力します。 同様に、すべての星が 1 つの列に並んでいる場合、`left`そして`right`は等しいため、単一列の長方形が生成されます。 星がグリッドの隅にある場合、次のようになります。`(0,0)`、`min`そして`max`ロジックは依然として正しい外接四角形を計算します。 このアルゴリズムは、最小入力と最大入力をシームレスに処理します。
