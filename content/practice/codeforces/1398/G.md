 ## 解決策
 ## 問題の理解

 ランニング スタジアムを垂直線で分割された長方形としてモデル化するように求められます。 水平方向の側面は、`(0,0)`に`(x,0)`そして`(0,y)`に`(x,y)`、そして、あります`n+1`座標における垂直セグメント`a_0, a_1, ..., a_n`、上端と下端を接続します。 各ラップはこれらのセグメントに沿った閉じた非交差パスであるため、長方形の辺と垂直パーティションに沿ってのみ移動します。 ラップの長さは、ラップが続くセグメントに沿った距離の合計です。 

コンテストには複数のステージがあり、それぞれに目標の長さが設定されています`l_i`。 各ステージには最長のラップ長が必要です`L`そのような`L`分割する`l_i`その通り。 ラップが分かれていない場合`l_i`、戻らなければなりません`-1`。 

制約は大きいです:`n`ステージの長さは最大 200,000、ステージの長さは最大 100 万です。`q`こちらも20万まで。 すべてのラップを明示的に列挙する単純なアプローチでは、考えられるラップ パスの数が垂直セグメントの数に応じて指数関数的に増加するため、遅すぎます。 スタジアムの構造と数理論の特性を活用する必要があります。 

微妙な点は、すべての長さが可能ではないということです。 たとえば、ラップは閉じたサイクルで垂直セグメントと水平セグメントを横断する必要があります。 セグメントのあるスタジアムで`[0,3,5,10]`そして高さ`5`、可能なラップの長さは、垂直セグメント間の距離の倍数に高さの 2 倍を加えたものになります。 ステージの長さが素数であるか、そのような組み合わせの倍数ではない場合、次のようになります。`-1`。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのラップを列挙しようとします。 すべての垂直セグメントから開始し、左または右に移動して、開始点に戻るすべてのサイクルを記録することができます。 各ラップの長さを計算するには、パスの長さの線形時間がかかり、割り算をチェックするためにすべての長さを保存すると、次のような組み合わせが爆発的に発生します。`2^(n+1)`可能なパス。 と`n`200,000 までは、これは明らかに不可能です。 

重要な観察は、すべてのラップの長さは、連続する垂直セグメント間の差異という観点から表現できるということです。`a_{i+1} - a_i`、高さ`y`。 周回ごとに縦移動と横移動が交互に行われるため、その長さは常に の倍数になります。`2y`水平方向の差の合計を加えたもの。 これにより、問題は数論的な問題に帰着します。つまり、すべての水平距離の最大公約数 (gcd) を見つけます。すると、すべてのラップの長さは次のようになります。`2*y + k*gcd`、 どこ`k`は水平方向の差の整数倍です。 

具体的に差分を計算してみると、`d_i = a_{i+1} - a_i`、これらの違いの gcd、`g`、ラップの水平部分を拘束します。 垂直方向の寄与は常に`2*y`。 この場合、すべての可能なラップ長のセットは、次の形式のすべての整数になります。`2*y + 2*k*g`ある整数に対して`k ≥ 0`。 特定のステージの長さに対して`l_i`、最大のものを見つけます`L`このような形の`l_i % L == 0`。 

これにより、問題は各ステージの単純な算術チェックに縮小されます。`l_i % gcd_set == 0`そして`l_i >= 2*x + 2*y`、 どこ`2*x + 2*y`最小周囲長です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(2^n) | 遅すぎる |
 | 最適 | O(n + q*sqrt(l_max)) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 連続する垂直セグメント位置の差を計算します。`d_i = a_{i+1} - a_i`。 これらは、どのラップでも発生する可能性のある最小の水平距離を表します。 
2. 最大公約数を計算する`g`あらゆる違いの中で`d_i`。 これは、ラップ内の水平距離は次の倍数でなければならないという事実を捉えています。`g`。 
3. 最小ラップ長は、水平距離をすべて取得したときに発生します。`x`そして両方の垂直エッジ`y`、与える`min_lap = 2*x + 2*y`。 
4.各段の長さについて`l_i`、初期化します`max_lap = -1`。 すべての約数を反復処理します`d`の`l_i`。 各約数について`d`、どうかを確認してください`d >= min_lap`そして`(d - 2*y) % (2*g) == 0`。 両方の条件が当てはまる場合は更新します`max_lap`に`d`。 
5. 出力`max_lap`ステージごとに。 

それが機能する理由: 不変条件は、ラップの長さが少なくとも次のとおりである必要があることです。`2*x + 2*y`とは異なります`2*y`水平方向の gcd の 2 倍の倍数です。 約数をチェックすると、`l_i`、ラップがステージの長さを分割すること、および算術条件により、指定されたスタジアム レイアウトでラップが構築可能であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import gcd, isqrt

n, x, y = map(int, input().split())
a = list(map(int, input().split()))
q = int(input())
l_list = list(map(int, input().split()))

# Compute horizontal differences and their gcd
diffs = [a[i+1] - a[i] for i in range(n)]
g = diffs[0]
for d in diffs[1:]:
    g = gcd(g, d)

min_lap = 2*x + 2*y

res = []
for l in l_list:
    max_lap = -1
    # iterate over divisors of l
    for i in range(1, isqrt(l)+1):
        if l % i == 0:
            for candidate in (i, l//i):
                if candidate >= min_lap and (candidate - 2*y) % (2*g) == 0:
                    if candidate > max_lap:
                        max_lap = candidate
    res.append(str(max_lap))

print(" ".join(res))
```コードは最初に水平方向の差とその gcd を計算します。 最小ラップ長はスタジアムの周囲によって決まります。 各ステージで、すべての約数がチェックされます。 長さと gcd 条件の両方を満たすものだけが考慮されます。 使用する`isqrt`以上のチェックを行わないことを保証します`O(sqrt(l_i))`ステージごとの約数。
