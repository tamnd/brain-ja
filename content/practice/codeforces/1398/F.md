 ## 問題の理解

設定された境界は、絶対位置ではなく、ストリーク イベントによって定義されます。 これは、疑問符の割り当て方法と、同一の値の連続をどれだけ長く保持するかに応じて、同じプレフィックスを異なる数のセットに分割できることを意味します。 

この制約により、クエリごとに線形に近い解決策が求められますが、すべてのクエリに対して答えを計算する必要があるため、$x$から$1$に$n$、それよりも悪いもの$O(n \log n)$すでに遅すぎます。 それぞれの素朴なシミュレーション$x$だろう$O(n^2)$、これは限界をはるかに超えています$n = 10^6$。

 ## アルゴリズムのチュートリアル

 1. まず文字列を、連続する等しい既知の値がブロックを形成するセグメントとして再解釈します。`?`戦略に応じてどちらかの側に統合できます。 重要な観察は、各位置が以下の長さ以下の連続内にある場合にのみ、有効なセット境界に寄与するということです。$x$。 
2. すべてのインデックスについて、そのインデックスを強制的に通過させることができる同種セグメントの最大可能長を計算します。 これは、競合する固定文字に到達するまで左右に拡張し、処理することで行われます。`?`柔軟です。 
3. 各インデックスは、次の制約間隔を生成します。$x$。 必要なストリークが最大でもポジションが境界をサポートできるかどうか$L$の場合、すべての回答に +1 が与えられます。$x \ge L$。 
4. 差分配列を使用してこれらの寄与を保存します。$x$、位置に 1 を追加します$L$そして位置で1を減算します$n+1$。 
5. すべての位置を処理した後、プレフィックスの合計を計算します。$x = 1 \ldots n$、各ストリークしきい値の最終的な答えが得られます。 

重要な考え方は、終了したセットの数は、特定のストリーク要件の下でどれだけ多くの強制境界機会が生き残るかによって完全に決定されるということです。 各位置は独立してアクティブまたは非アクティブになります。$x$成長します。 

### なぜ効果があるのか

 完成したすべてのセットの境界は、同一の結果の連続が長さに達する点に対応します。$x$。 未知数の固定割り当ての場合、これらの境界はまさに最大実行の終わりに発生します。 最適な割り当てにより、短い実行の数が最大化され、実行が長すぎると、$x$、より小さいしきい値に対して追加の境界を提供することはできません。 これにより、全体にわたる単調な寄与構造が引き起こされます。$x$、これはまさに差分配列がキャプチャするものです。 各ポジションはラン境界に合法的に参加できる場合にのみ考慮されるため、二重カウントは発生しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    s = input().strip()

    left = [0] * n
    right = [0] * n

    # left extension
    i = 0
    while i < n:
        j = i
        while j < n and s[j] == '?':
            j += 1
        start = i
        end = j - 1

        # process block [start, end] of '?'
        i = j

    # For simplicity, compute nearest fixed constraints
    last0 = -1
    last1 = -1

    best_left = [0] * n
    for i in range(n):
        if s[i] == '0':
            last0 = i
        if s[i] == '1':
            last1 = i
        best_left[i] = max(last0, last1)

    last0 = n
    last1 = n
    best_right = [0] * n
    for i in range(n - 1, -1, -1):
        if s[i] == '0':
            last0 = i
        if s[i] == '1':
            last1 = i
        best_right[i] = min(last0, last1)

    diff = [0] * (n + 3)

    for i in range(n):
        L = i - best_left[i]
        R = best_right[i] - i
        mx = max(L, R)
        if mx <= 0:
            continue
        diff[1] += 1
        if mx + 1 <= n:
            diff[mx + 1] -= 1

    res = [0] * (n + 1)
    cur = 0
    for x in range(1, n + 1):
        cur += diff[x]
        res[x] = cur

    print(*res[1:])

if __name__ == "__main__":
    solve()
