 ## 解決策
 ## 問題の理解

 このツリーは、すべてのノードが非負の「フロー値」を伝送するシステムを記述します。 葉は独立した水源を表し、任意の正の整数値を取ることができます。 すべての内部ノードは合流点を表し、その値はその子の値の正確な合計です。 ルートは、サブツリーから上向きに流れるすべてを集約するもう 1 つのノードにすぎません。 

一部のノードはフロー値がすでに固定されていますが、その他は不明です。 すべての合計関係がツリー全体で維持されるように、不明な値を選択する必要があります。 タスクは、制約と一致するすべてのノード値の有効な割り当てが 1 つだけ存在するかどうかを判断し、存在する場合はそれを出力することです。 有効な割り当てが複数ある場合、またはまったく割り当てがない場合、答えは「不可能」です。 

制約により、最大で$3 \cdot 10^5$これにより、線形または線形に近いソリューションが強制されます。 サブツリーに対するノードごとの再計算やフローの再分配の繰り返しを伴うものは遅すぎます。 この構造は親から子へのエッジを持つルート付きツリーであるため、有効なアプローチはすべて単一の DFS または BFS トラバーサルを利用する必要があります。 

重要な微妙な点は、指定されない限りリーフは固定されないが、内部ノードは追加的な制約を適用することです。 これは、たとえシステムが一貫していても、制約のないサブツリーは既知のノードに影響を与えることなく内部的に質量を再分配できるため、一意性が失われる可能性があることを意味します。 

よくある失敗例の 1 つは、完全に制約のないサブツリーです。 たとえば、ノードに 2 つの子があり、どちらも下位のどこにも制約されていない場合、親の合計が固定されている場合でも、その合計を 2 つのブランチ間で分割する方法は無限にあります。 合計の一貫性のみをチェックし、一意性を無視するソリューションでは、そのようなケースが誤って受け入れられます。 

もう 1 つの微妙なケースは、制約が存在するものの、制約がまばらである場合です。 値 10 を持つノードと 2 つの子、つまり 1 つのサブツリーには制約されたリーフが含まれ、もう 1 つは完全に制約されていないとします。 制約のないサブツリーは残りを吸収しますが、そのサブツリーに複数の葉が含まれている場合、その内部の分布はまだ固定されていないため、再び複数の解が得られます。 

最後に、固定値が他の制約によって暗示されるサブツリーの合計と一致しない場合、矛盾が発生します。 たとえば、ノードが 5 に固定されているが、その子が 3 に固定されており、別の子サブツリーが (少なくとも 1 つの葉を含むため) 少なくとも 3 を寄与する必要がある場合、最小可能な合計は 5 を超えるため、構成は不可能になります。 

## アプローチ

 直接的なアプローチは、リーフ値を変数として扱い、制約を上方に伝播することです。 各ノードの値はそのサブツリー内のすべてのリーフ値の合計であるため、すべての固定ノードはリーフ変数に対して線形方程式を適用します。 このシステムをグローバルに解こうとすることもできますが、方程式がツリー構造によってネストされており、解空間が高次元であるため、それはすぐに非現実的になります。 

もう 1 つの強引なアイデアは、リーフに任意の値を割り当て、各固定ノードを満たすように繰り返し調整することです。 これは基本的に依存制約のシステムを満たそうとしていますが、調整は祖先を通じて伝播し、競合が予期せず連鎖的に発生する可能性があります。 最悪の場合、調整ごとにサブツリー全体の再計算が必要となり、二次的な動作が発生する可能性があります。 

重要な観察は、すべてのノード値がそのサブツリー内の葉の合計によって完全に決定されるということです。 これにより、問題はサブツリー合計の制御に変わります。 各固定ノードはそのサブツリーの総質量を固定し、残された唯一の自由は、その質量を、それ自体が制約されていない子サブツリー間でどのように分配するかです。 

重要な構造は次のとおりです。あいまいさは、固定ノードによって完全に制約されていない複数の子サブツリーがノードにある場合にのみ現れます。 このような場合、制約に影響を与えることなく、これらのサブツリー間で質量を再分配できます。 逆に、すべての分岐点で最大 1 つの子サブツリーが制約されていない場合、すべての「自由質量」は葉に到達するまで固有の経路を強制的に流れ、曖昧さが排除されます。 

これにより、二相溶液が得られます。 まず、サブツリー集約を使用して制約の実現可能性を確認します。 次に、構造がどこでも複数の自由度を許容するかどうかを確認します。 そうであれば、答えは一意ではありません。 そうでない場合は、固定合計を下方に伝播することによって値を決定論的に再構築できます。

 ## アルゴリズムのチュートリアル

 ツリーを 1 にルートし、サブツリー情報を操作します。

### ステップ 1: 制約されたノードを特定する

 固定値を持つすべてのノードにマークを付けます。 これらのノードは、サブツリーの合計を完全に決定するアンカーとして機能します。 

### ステップ 2: サブツリー「制約カバレッジ」を計算する

 リーフから上に向かって DFS を実行します。 各ノードについて、そのサブツリーに少なくとも 1 つの制約されたノードが含まれているかどうかを判断します。 システムは少なくとも 1 つの制約を持つサブツリーのみを一意に固定できるため、これは不可欠です。 

サブツリーに制約が含まれていない場合、その内部配布は完全に自由になり、すでに一意性が脅かされます。 

### ステップ 3: 分岐の曖昧さをチェックする

 すべてのノードについて、その子を検査します。 制約されたノードを含まない子サブツリーの数を数えます。 この数が少なくとも 2 の場合、これら 2 つのサブツリーはすべての制約を満たしたまま任意の量のフローを交換できるため、構成は直ちに非固有になります。 

この条件は、システム内のすべての自由度を捕捉します。 

### ステップ 4: サブツリーの合計をボトムアップに伝播する

 可能な場合は実際のノード値を計算します。 ノードに固定値がある場合は、それを採用します。 それ以外の場合、1 つを除くすべての子サブツリーの合計が決定されている場合、それが判明すると、残りの 1 つは親の合計から減算されます。 

この伝播は、一意性チェックに合格したツリーでのみ可能です。そうでないと、複数の不明なブランチが存在することになります。 

### ステップ 5: 肯定的であることを検証する

 すべてのリーフは正の値で終わる必要があります。 葉はソースを表すため、ゼロまたは負の計算値は矛盾を意味します。 

### なぜ効果があるのか

 すべてのノード値はそのサブツリー内のリーフ変数の合計に等しいため、システムは基本的にツリー構造の制約行列を持つリーフ上で線形です。 一意性条件は、制約によって引き起こされる商グラフにおいて、制約されていないリーフのすべての接続領域のサイズが 1 であることを要求することと同等です。 DFS 条件は、どのノードも 2 つの独立した制約のないサブツリーが一定の合計の下で共存することを許可しないことを保証します。これはまさに質量の一意の分解の条件です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n = int(input())
p = [0] * (n + 1)
parents = list(map(int, input().split()))
for i in range(2, n + 1):
    p[i] = parents[i - 2]

a = [0] + list(map(int, input().split()))

children = [[] for _ in range(n + 1)]
for i in range(2, n + 1):
    children[p[i]].append(i)

fixed = [False] * (n + 1)
for i in range(1, n + 1):
    if a[i] != 0:
        fixed[i] = True

has_fixed = [False] * (n + 1)
bad = [False]

def dfs(u):
    hf = fixed[u]
    zero_free_children = 0

    for v in children[u]:
        cf = dfs(v)
        hf = hf or cf
        if not cf:
            zero_free_children += 1

    if zero_free_children >= 2:
        bad[0] = True

    has_fixed[u] = hf
    return hf

dfs(1)

if bad[0]:
    print("impossible")
    sys.exit()

ans = a[:]

def assign(u, forced_sum=None):
    # forced_sum is the sum required by ancestors if known
    cur = a[u] if a[u] != 0 else None

    child_unknown = []
    known_sum = 0

    for v in children[u]:
        if a[v] != 0:
            known_sum += a[v]
        else:
            child_unknown.append(v)

    if cur is not None:
        remaining = cur - known_sum
        if remaining < len(child_unknown):
            print("impossible")
            sys.exit()

        if len(child_unknown) == 1:
            a[child_unknown[0]] = remaining

        elif len(child_unknown) > 1:
            # split minimally, but uniqueness guarantees this won't happen
            for v in child_unknown[:-1]:
                a[v] = 1
            a[child_unknown[-1]] = remaining - (len(child_unknown) - 1)

    for v in children[u]:
        assign(v)

assign(1)

if any(a[i] == 0 for i in range(1, n + 1)):
    print("impossible")
else:
    print(*a[1:])
```最初の DFS は、各サブツリーに固定ノードが含まれているかどうかを計算し、制約のない 2 つのサブツリーが共存する分岐点を検出します。これにより、一意性が直ちに失われます。 

第 2 フェーズでは、既知の合計を下方に伝播しようとします。 ノードに固定値がある場合、その子にバジェットが適用されます。 1 つの子のみが制約されていない場合、その子は残りの質量全体を強制的に取得することになります。これが唯一の一意性が維持される状況です。 

最終チェックでは、未設定のままのノードがないことを確認します。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、ノードにちょうど 2 つの子があり、そのうちの 1 つだけに固定ノードが含まれる場合です。 この場合、空きサブツリーが 1 つしかないため、アルゴリズムは構成を拒否しません。 残りのサブツリーは、固定された親からの減算によって完全に決定され、その中のすべてのリーフは下方伝播によって一意に決定されます。 

もう 1 つのケースは、ノードがまったく固定されていない場合です。 すべてのサブツリーには制約がなく、すべての内部ノードで複数の独立した分割が可能です。 DFS は、ルートで複数の制約されていないブランチを即座に検出し、インスタンスを拒否します。 

最後の微妙なケースは、制約が下部にのみ表示される深いチェーンです。 中間ノードは制約されていませんが、各ノードは各ステップで最大でも 1 つの制約されていない子サブツリーを持つため、リーフ制約が上方に伝播した後も構造は一意に決定されたままになります。
