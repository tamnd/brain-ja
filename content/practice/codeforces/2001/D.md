 ## 解決策
 ## 問題の理解

 整数のシーケンスを処理し、重複する要素を含まずに長さを最大化するサブシーケンスを見つけるように求められます。 最大長のすべての部分列の中で、変更された辞書編集順序を最小にするものを選択する必要があります。部分列内の奇数の位置にある各要素は次のように乗算されます。$-1$。 基本的に、私たちは 2 つの目標のバランスを取ります。1 つ目は、できるだけ多くの個別の数値を取得する必要があり、2 つ目は、符号付き辞書編集値を最小化するためにそれらの順序を決定する必要があります。 

入力は複数のテスト ケースで構成されます。 それぞれの場合に、シーケンスの長さが与えられます。$n$そしてシーケンスそのもの。 制約により許可されるのは、$n$までに$3 \cdot 10^5$、合計は$n$すべてのテストケースで以下を超えない$3 \cdot 10^5$。 これにより、線形より悪いアルゴリズムは禁止されます。$n$テストケースごとに。 すべてのサブシーケンスを調べる単純なアプローチでは、指数関数的な時間が必要となり、まったく実行不可能です。 エッジ ケースには、すべての要素が同一であるシーケンス、長さ 1 のシーケンス、および辞書編集基準を満たすために最適なサブシーケンスを慎重にインターリーブする必要があるシーケンスが含まれます。 

## アプローチ

 ブルートフォース手法では、入力のすべてのサブシーケンスを列挙し、要素が繰り返されているサブシーケンスを破棄し、辞書編集順序の修正を最小限に抑えた最長のものを選択します。 これには必要です$O(2^n)$テストケースごとの操作であり、明らかに実行不可能です。$n$まで$3 \cdot 10^5$。 

最適なアプローチは 2 つの観察に基づいています。 まず、重複を含まない最長のサブシーケンスの長さは、シーケンス内の個別の要素の数と正確に一致します。 これにより、修正された辞書編集順序を最小化する順序でこれらの個別の要素を選択するという問題が軽減されます。 2 番目に、入力をトラバースする際に、各個別の要素が最後に出現したものを取得して、左から右に貪欲にサブシーケンスを構築できます。 これにより、奇数位置の負の辞書編集基準を満たすためにサブシーケンスを反転するときに、最小限の順序付けが保証されます。 重要な洞察は、重複のないシーケンスの場合、唯一の自由度は個別の要素の相対的な順序であり、最後の出現に従ってそれらを反転すると、符号付き辞書編集値が自然に最小化されるということです。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 空の辞書を初期化して、各要素の最後の出現インデックスを保存します。 これにより、シーケンス内で各要素が出現する最終位置を知ることができます。 
2. 入力シーケンスを左から右にたどります。 各要素について、辞書内の最後の出現インデックスを更新します。 このステップの後、ディクショナリはそれぞれの個別の値を配列内の最後のインデックスにマップします。 
3. 個別の要素を抽出し、最後に出現したインデックスによって並べ替えます。 これにより、奇数の位置の符号を調整するときに辞書編集基準が最小化される順序で個別の値のシーケンスが生成されます。 
4. このシーケンスの長さ、つまり個別の要素の数を出力します。 
5. シーケンス自体を、最後の出現順にソートして決定された順序で出力します。 

不変条件は、要素を最後に出現した順に選択することにより、各要素を最大 1 回使用する元の配列から取得されたサブシーケンスは、より小さい符号付き辞書編集シーケンスを生成できないことです。 最終出現のソートにより、出力内の以前の要素が入力内で最後に出現した後に出現することが保証され、奇数位置の負の値の最小値が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        last_occurrence = {}
        for i, val in enumerate(a):
            last_occurrence[val] = i
        # Sort elements by last occurrence index
        result = sorted(last_occurrence.keys(), key=lambda x: last_occurrence[x])
        print(len(result))
        print(' '.join(map(str, result)))

solve()
```このソリューションでは、辞書を使用して、各個別要素の最後の出現を効率的に追跡します。 保存されたインデックスによって並べ替えることにより、奇数の位置にある記号を考慮するときに辞書編集上の順序付け規則が確実に尊重されます。 すべての演算は、個別の要素の数において線形演算的であり、次の範囲内で制限されます。$n$、問題の制約の下で効率を確保します。 すべて同じ番号を持つシーケンスや単一要素シーケンスなどのエッジ ケースは、最後の出現マップが唯一の一意の要素を依然として正確に識別するため、自然に処理されます。 

## 実用的な例

 入力用`[3, 2, 1, 3]`、最後の出現は次のとおりです。`{3: 3, 2: 1, 1: 2}`。 インデックス利回りによる並べ替え`[2, 1, 3]`。 出力の長さは`3`、出力シーケンス`[2, 1, 3]`。 奇数の位置を負の符号で反転すると、`[-2, 1, -3]`これは、長さが 3 の他のサブシーケンスよりも小さいです。 

入力用`[1, 1, 1, 1]`、最後の出現辞書は次のとおりです。`{1: 3}`。 出力シーケンスの長さは次のとおりです。`1`そしてシーケンス`[1]`。 

| インデックス | 要素 | 最後に発生したこと | 出力シーケンス |
 | --- | --- | --- | --- |
 | 0 | 3 | 3 | 2 |
 | 1 | 2 | 1 | 1 |
 | 2 | 1 | 2 | 3 |
 | 3 | 3 | 3 | |

 このトレースは、アルゴリズムが個別の要素を目的の順序で正しくキャプチャしていることを示しており、不変式が成り立つことが確認されています。

 ## 特殊なケース

 長さ 1 のシーケンスの場合、たとえば、`[1]`、辞書マップ`1`インデックスを付ける`0`、出力は`[1]`。 アルゴリズムは、この最小限の入力を正しく処理します。 すべてが同一の要素を持つシーケンスの場合、辞書は単一のキーに縮小されるため、アルゴリズムは単一要素のシーケンスを出力します。`[value]`。 最長のサブシーケンスが左端以外の順序で要素を選択する必要があるシーケンスの場合、次のようになります。`[3, 2, 1, 3]`、最後の出現順に並べ替えると、正しい順序が保証されます。`[2, 1, 3]`。 これにより、奇数位置の負の辞書編集基準が満たされることが保証されます。
