 ## 解決策
 ## 問題の理解

 長さの文字列として 2 進数が与えられます。$n$、先行ゼロが含まれる場合があります。 タスクは、各整数について決定することです。$i$1から$n$、数を割り切れるようにするために必要な隣接するスワップの最小数。$2^i$、または不可能な場合はその旨を示します。 各テスト ケースは独立しており、合計は$n$すべてのテストケースで次を超えない$2 \cdot 10^5$。 

入力制約は、各文字列を効率的に処理する必要があることを意味します。 可能なスワップの数は階乗であるため、隣接するスワップのすべての順列をチェックする単純な方法は問題外です。$n$、これは不可能です$n$まで$10^5$。 代わりに、2 進数の特性を利用して、0 と 1 の位置を直接操作するアプローチが必要です。 

明らかではないエッジケースは、文字列にゼロがほとんど含まれていない場合、または最下位ビットがすでにゼロである場合に発生します。 たとえば、文字列`1001`もっている`n = 4`、そしてそれを割り切れるようにするには、`4`最後の 2 ビットがゼロである必要があります。 ゼロが足りない場合、答えは次のようになります。`-1`。 位置をチェックせずに単にゼロを数える不注意な実装では、不可能な解を誤って報告する可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、最後のスワップが完了するまで、隣接するスワップのあらゆる組み合わせが試行されます。$i$ビットがゼロの場合は、スワップ数を記録します。 原理的には正しいですが、これには指数関数的な数のスワップのシーケンスを探索する必要があります。 たとえ$n = 20$、これは手に負えなくなります。 

重要な観察は、2 進数を次で割り切れるようにするということです。$2^i$、最後です$i$ビットはすべてゼロでなければなりません。 隣接するビット間でのスワップが許可されているため、ゼロをターゲット位置に移動するために必要なスワップの最小回数は、その現在位置とターゲットの間の距離と同じになります。 ゼロの位置を特定し、右端のゼロを最後のゼロに移動することで、各テスト ケースを処理できます。$i$ポジション。 

これにより、テスト ケースあたりの問題が指数関数的な時間から線形時間に短縮されます。 ゼロの位置を追跡し、最後のゼロを移動するのに必要な距離の合計を計算するだけで済みます。$i$右端にゼロ$i$ポジション。 以下の場合は、$i$文字列にゼロがある場合、答えは次のとおりです。`-1`このアプローチは問題の構造を利用しており、与えられた制約に対して十分に効率的です。

 | ゼロポジションによる貪欲 | テスト ケースあたり O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、バイナリ文字列を読み取ります。`s`長さの`n`。 
2. 文字列内のすべてのゼロの位置をリストに記録します。`zeros`。 
3. それぞれについて`i`1から`n`、ゼロの数が以下かどうかを確認します。`i`。 ある場合は出力します`-1`最後にするのは不可能だから`i`ビットはすべてゼロです。 
4. それ以外の場合は、`i`最後までゼロ`i`文字列の位置。 一番右を選択してください`i`からのゼロポジション`zeros`。 
5. 選択した各ゼロを最終的にターゲット位置に移動するのに必要なスワップ数を計算します。 ゼロが位置にある場合`pos`そしてその目標は`n - (i - k)`のために`k`0から`i-1`、このゼロのスワップ数は次のようになります。`target - pos`。 
6. 選択したすべてのゼロのスワップを合計します。 この合計は、数を割り切れる隣接するスワップの最小数です。`2^i`。 
7. すべてに対して繰り返します`i`そして結果を出力します。 

機能する理由: スワップごとに 0 から 1 の位置を右に移動できるため、位置から 0 を移動します。`pos`目標位置まで`t`正確に必要です`t - pos`交換します。 使用可能な右端のゼロを選択すると、移動が最小限に抑えられます。 これにより、正確性と最小限性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    
    zeros = [i for i, ch in enumerate(s) if ch == '0']
    num_zeros = len(zeros)
    res = []

    for i in range(1, n+1):
        if num_zeros < i:
            res.append(-1)
        else:
            swaps = 0
            # select rightmost i zeros
            for k in range(i):
                pos = zeros[-(k+1)]
                target = n - (k+1)
                swaps += target - pos
            res.append(swaps)
    print(' '.join(map(str, res)))
```割り算条件を満たすことができるのはゼロだけであるため、解ではまずゼロの位置を収集します。 右端のゼロはすでに終わりに近づいているため、右端のゼロを貪欲に選択すると、スワップが最小限に抑えられます。 計算`target - pos`必要な動きを直接測定します。 ゼロの数が以下の場合の処理`i`正確さを保証し、範囲外のエラーを防ぎます。
