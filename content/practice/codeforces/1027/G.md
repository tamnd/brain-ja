 ## 問題の理解

重要な問題は、開始位置がわからないため、変換の可能なすべての軌道で迎撃を保証する必要があることです。$f(i) = i \cdot x \bmod m$。 モーションの構造は完全に決定的であるため、すべての開始点で、場合によっては一時的なプレフィックスの後にサイクルが生成されます。 ただし、乗算剰余なので、$m$一般に、必ずしも可逆である必要はありません。グローバル構造は、サイクルにフィードするツリーを含むサイクルで構成される有向グラフです。

 ## アルゴリズムのチュートリアル

 1. すべての約数を列挙します$d$の$m$。 各約数は状態の gcd 層を表します$i$どこ$\gcd(i,m)=d$。 これは、次の乗算により機能します。$x$gcd クラスを以下に保存します$\gcd(x,m)=1$。 
2. 各約数について$d$、 定義する$n = m/d$。 フォームの数値を分析します$i = d \cdot k$どこ$\gcd(k,n)=1$。 これらはまさにモジュロ単位です$n$、つまり、そのカウントは$\varphi(n)$。 
3. を掛けるので、$x$可逆モジュロです$n$、これらの順列として機能します。$\varphi(n)$要素。 すべての順列は互いに素なサイクルに分解され、確実にキャプチャするには各サイクルに 1 つのトラップが必要です。 
4. の乗算によって引き起こされるサイクル数$x$有限群上の軌道数は、繰り返し乗算したものと等しくなります。$x$。 サイクルを明示的に見つける代わりに、マップを繰り返し適用すると、各軌道が別個の同値クラスに対応することが観察されます。 
5. この特定の構造では、各 gcd 層が正確に寄与します。$\gcd(x-1, n)$乗算中の固定構造は、次の解に従って崩壊するため、サイクルします。$x^t \equiv 1 \pmod{n}$、軌道分解は、によって引き起こされる安定剤に依存します。$x-1$。 
6. すべての約数にわたるサイクル数を合計します。$d\mid m$最終的な答えを得るために。 

### なぜ効果があるのか

 変換により、状態空間が互いに素な gcd 不変層に分割され、各層内で関数は全単射になります。 すべての全単射はサイクルに分解され、すべての開始点は最終的に正確に 1 つのサイクルに入るため、最小トラッピング セットには各サイクルから少なくとも 1 つの要素が含まれている必要があります。 サイクルがレイヤー間で交差することはないため、すべてのレイヤーのサイクル数を合計すると、グローバルに最小のヒット セットが生成されます。 異なるコンポーネントからの 2 つのサイクルは関数グラフ構造の下で互いに素であるため、トラップはそれらをカバーできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def divisors(n):
    small = []
    large = []
    i = 1
    while i * i <= n:
        if n % i == 0:
            small.append(i)
            if i * i != n:
                large.append(n // i)
        i += 1
    return small + large

def solve():
    m, x = map(int, input().split())
    
    divs = divisors(m)
    ans = 0
    
    for d in divs:
        n = m // d
        
        # compute contribution of this layer
        # cycles induced by multiplication by x on units mod n
        g = math.gcd(x - 1, n)
        ans += g
    
    print(ans)

if __name__ == "__main__":
    solve()
```コードは、次のすべての約数を列挙することから始まります。$m$、各約数は状態の個別の gcd クラスに対応するためです。 各約数について$d$を考慮して状態空間を圧縮します。$n = m/d$、これは共素残基の還元系を表します。 

重要な計算は貢献です$\gcd(x-1, n)$、次の乗算方法をキャプチャします。$x$その層の軌道が崩壊します。 この値は、すべての除数クラスにわたって加算されます。 実装では、すべての状態の反復処理を慎重に回避し、算術プロパティに完全に依存します。 

除数の列挙が実行されます$O(\sqrt{m})$、これは制約の下で実現可能です。
