 ## 解決策
 ## 問題の理解

 スティックの長さの独立したセットがいくつか与えられています。 各セットでは、長方形を形成するように正確に 4 本のスティックを選択する必要があります。つまり、同じ長さのペアが 2 つ必要です。高さ用に 1 ペア、幅用に 1 ペアです。 各スティックは 1 回のみ使用でき、スティックを分割することはできません。 

形成できるすべての有効な長方形の中から、単に長方形を見つけようとするわけではありません。 各候補の長方形を、その​​ジオメトリに応じた特定の式で評価しています。$a$そして$b$、周囲は$2(a+b)$そしてそのエリアは$ab$, したがって、値は次のようになります$$\frac{P^2}{S} = \frac{4(a+b)^2}{ab}.$$この式は、一方の辺が他方よりもはるかに大きくなると、二乗和に比べて分母が小さくなるため、辺間の不均衡に大きなペナルティを与えます。 長方形が正方形に最も近い場合、式は最小化されます。 

各テスト ケースには合計で最大 100 万個のスティックを含めることができるため、テスト ケースごとにどのようなソリューションも本質的に線形またはほぼ線形である必要があります。 すべての 4 回転、さらにはすべてのペアを考慮しようとすると、遅すぎます。 

単純な考えは、少なくとも 2 回出現するすべての長さのペアを試してスコアを計算することです。 失敗するケースは、長さが何度も出現する場合です。並べ替えられた順序で隣接性を考慮せずに頻度から貪欲にペアを選択すると、数値的に近いわずかに異なる辺の長さによって形成されるより適切な長方形を見逃す可能性があるためです。 

たとえば、次のような長さがあるとします。$1,1,100,100,2,2,99,99$、周波数ベースの貪欲な選択は、次のような極端なペアにジャンプする可能性があります。$1 \times 100$ですが、最適な長方形は次のようになります。$2 \times 99$または、完全な構造に応じて、別のより近いペアリングが行われます。 重要な問題は、最適性は豊富さだけではなく、価値の近さに依存するということです。 

## アプローチ

 長方形は、それぞれ少なくとも 2 回現れる 2 つの異なる長さを選択することによって完全に決定されます。 利用可能な等しいスティックの候補ペアをすべて知っている場合、問題は、式を最小化するそのようなペアを 2 つ選択することになります。 

ブルート フォース ソリューションでは、最初に少なくとも 2 の頻度ですべての長さを収集し、次にそのような長さのすべてのペアを試します。 あれば$k$このような独特の長さ、これは$O(k^2)$。 すべての値が何度も出現する最悪の場合、$k$が大きくなる可能性があるため、この二次関数のアプローチは遅くなりすぎます。 

重要な観察は、コスト関数がペアに滑らかに依存することです。$(a,b)$そして最小化されるのは$a$そして$b$近いです。 これは、すべてのペアが必要ではなく、長さの順にソートされた隣接する候補だけが必要であることを示唆しています。 候補の長さ (利用可能なペアとしてそれぞれ 2 回繰り返される) を並べ替えると、最適なペアのペアは小さな近傍から得られる必要があります。同じ長さが 4 回繰り返される (正方形) か、または 2 つの隣接する別個の長さのいずれかです。 

したがって、すべての組み合わせをテストする代わりに、周波数を使用可能なペアに圧縮し、ローカルでスキャンします。

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

### 1. すべてのスティックの長さの周波数をカウントします。 

最大 10000 の値に対して周波数配列を構築します。制約はスティックの長さに制限されるため、これで十分です。 

長方形には等しい長さのペアが必要なので、周波数が必要です。 

### 2. 使用可能なペアを抽出する

 それぞれの長さごとに$x$、それが寄与する素のペアの数を計算します。`freq[x] // 2`。 このような各ペアは、長方形の一辺を表します。 

利用可能な各ペアを候補サイドとして保存します。 

ここでの理由は、長方形は辺ごとにちょうど 2 つのスティックを使用するため、各長さが寄与できる完全なペアの数だけを考慮するということです。 

### 3. 候補陣営の分類されたリストを作成する

 それぞれの長さを展開します$x$しかし、最適化のために必要なのは、候補値のソートされた順序で各辺の長さのコピーを最大 2 つだけ必要とすることです。 これは、最適な四角形がソートされた空間内の隣接する値のみに依存するためです。 

そこで、寄与するペアの数に応じて、それぞれの有効な長さが複数回出現するリストを作成します。 

### 4. 隣接するペアをスキャンして長方形を形成します

 ソートされた候補リストを繰り返し処理し、連続するすべてのペアを取得します。$(a, b)$。 このような各ペアは、可能な長方形を表します。 

スコアを計算します。$$(a + b)^2 / (a \cdot b)$$(スケーリング定数まで、比較は同等です)。 

これまでに確認された最高のペアを追跡します。 

隣接性が機能する理由は、親密さから離れると不均衡が増大し、厳密には目的が悪化するためです。 

### 5. 正方形の特別な処理

 任意の長さに少なくとも 4 つの出現がある場合、直接正方形を形成できます。 正方形は、周囲から領域への動作が固定されているすべての長方形の中で式を最小化するため、このケースを明示的にチェックします。 

### なぜ効果があるのか

 目的関数は辺間の比率のみに依存します。 固定積の場合、辺が等しい場合に合計が最小になります。 したがって、すべての有効な四角形の中で、同じ値が繰り返される (四角形) か、並べ替えられた順序で最も近い 2 つの利用可能な値から最適なものが得られる必要があります。 隣接しない選択は、一方の側をもう一方の側に移動し、不均衡を減らし、目的を減らすことによって改善できます。 

これにより、局所的な最適性条件が作成されます。つまり、実現可能な辺の長さのソート順に隣接する候補内で大域的な最適性が見つかります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        arr = list(map(int, input().split()))

        freq = [0] * 10001
        for x in arr:
            freq[x] += 1

        sides = []
        square_candidate = None

        for x in range(1, 10001):
            c = freq[x]
            if c >= 2:
                pairs = c // 2
                if pairs >= 2:
                    if square_candidate is None:
                        square_candidate = (x, x)
                if pairs >= 1:
                    # each pair contributes one side
                    sides.append(x)

        sides.sort()

        best_val = float('inf')
        best = None

        def value(a, b):
            return (a + b) * (a + b) / (a * b)

        for i in range(len(sides) - 1):
            a, b = sides[i], sides[i + 1]
            v = value(a, b)
            if v < best_val:
                best_val = v
                best = (a, b)

        if square_candidate is not None:
            print(square_candidate[0], square_candidate[0], square_candidate[1], square_candidate[1])
        else:
            a, b = best
            print(a, a, b, b)

if __name__ == "__main__":
    solve()
```周波数配列は、入力を使用可能な幾何学的構成要素に圧縮します。 の`sides`リストは、スティックのペアによって形成されるすべての可能な長方形の辺を表します。 

隣接する要素のスキャンは最適化の中核です。すべてのペアをテストするのではなく、並べ替えに依存して、隣接する要素間で最適なバランスが存在することを確認します。 

四角形チェックは、隣接するペアの比較として表示されない可能性がある、縮退しているものの、多くの場合最適な構成を表すため、分離されています。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、単一の値が少なくとも 4 回出現する場合です。 この状況では、最適な長方形は常に正方形です。 アルゴリズムは、周波数を構築する際にこれを明示的に検出します。 たとえば、入力`5 5 5 5`すぐに 5 のペアが 2 つ生成され、正方形が形成され、他の値と比較する必要がなくなります。 

複数の値がそれぞれ 1 つのペアを正確に形成する場合、別の特殊なケースが発生します。 例えば`1 1 100 100 2 2 99 99`。 アルゴリズムはこれを候補の側に圧縮します`[1,2,99,100]`。 並べ替えにより隣接性比較テストが確実に行われる`(1,2)`、`(2,99)`、`(99,100)`、最も近いペアから最良の長方形が現れます。 これにより、アルゴリズムが次のような離れた値を誤ってペアリングすることを防ぎます。`(1,100)`そうなると、さらにひどい不均衡が生じることになります。 

3 番目のエッジ ケースは、有効な四角形構成が 1 つしかない場合です。 長方形が存在することが保証されているため、辺のリストには少なくとも 2 つの要素が含まれている必要があるため、隣接スキャンでは少なくとも 1 つの候補ペアが生成されます。 これにより、アルゴリズムが無効なインデックスにアクセスしたり、空の出力を生成したりすることがなくなります。
