 ## アルゴリズムのチュートリアル

 セットの現在の要素のハッシュ セットを維持します。 また、数値に関する情報を約数ごとにグループ化したキャッシュも維持しているので、それぞれの答えに答えることができます。$k$-効率的にクエリを実行します。

### なぜ効果があるのか

 固定ごとに$k$、数直線上に整数の動的なセットを効果的に維持し、最初に欠落している非負の整数を繰り返しクエリします。 それぞれの挿入または削除は、更新される値の約数にのみ影響するため、そのような構造体の制限された数にのみ影響します。 ポインタの前進により、すべてのインデックスが構造ごとに最大 1 回スキップされることが保証されます。 これにより、すべてのクエリにわたる償却された線形移動数が得られ、正確さと効率が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def divisors(x):
    d = 1
    res = []
    while d * d <= x:
        if x % d == 0:
            res.append(d)
            if d * d != x:
                res.append(x // d)
        d += 1
    return res

def solve():
    q = int(input())
    present = set()

    # for each k, store occupied indices i such that i*k is present
    occ = {}

    # pointer for each k: smallest candidate index
    ptr = {}

    def add_val(x):
        if x in present:
            return
        present.add(x)
        for d in divisors(x):
            if d not in occ:
                occ[d] = set()
                ptr[d] = 0
            occ[d].add(x // d)

    def remove_val(x):
        if x not in present:
            return
        present.remove(x)
        for d in divisors(x):
            if d in occ:
                occ[d].discard(x // d)

    def query(k):
        if k not in occ:
            return 0
        s = occ[k]
        p = ptr[k]
        while p in s:
            p += 1
        ptr[k] = p
        return p * k

    out = []
    for _ in range(q):
        parts = input().split()
        if parts[0] == '+':
            add_val(int(parts[1]))
        elif parts[0] == '-':
            remove_val(int(parts[1]))
        else:
            out.append(str(query(int(parts[1]))))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
