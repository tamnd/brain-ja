 ## 解決策
 ## 問題の理解

 正確に配置するように求められます$n$内のポイント$n \times n$整数グリッド。 各点は個別のセルを占有し、選択した点間のすべてのペアごとのマンハッタン距離を調べます。 これらすべての距離から個別の値のみを収集し、このセットをできるだけ大きくしたいと考えています。 

重要な対象は点そのものではなく、点が引き起こす距離の多様性です。 すべてのペアが値に貢献します$|x_i-x_j| + |y_i-y_j|$、多くのペアが同じ距離を繰り返す場合があります。 タスクは、これらの値ができるだけ分散するように点を配置することです。 

グリッド サイズは次のように直線的に増加します。$n$、そして私たちも選択します$n$ポイントがあるため、構成はかなり緻密です。 以来$n$まで上がります$1000$最大 50 のテスト ケースがあり、すべてのペアを明示的に検査しようとするソリューションは遅すぎます。これは、1 つのテスト ケースにすでに次のものが含まれているためです。$\Theta(n^2)$ペア。 

単純な試みでは、ポイントをランダムに分散したり、利用可能な最も遠いセルを貪欲に選択したりして、距離を最大化しようとする可能性があります。 マンハッタンの距離構造は非常に規則的であり、局所的な貪欲な選択により距離の多様性が簡単に崩れてしまう可能性があるため、これは失敗します。 たとえば、単一の線上に点を配置すると、距離のみが生成されます。$0 \ldots (n-1)$、より広がりのある 2D 構造では、より豊富なセットが得られます。 

Another subtle issue is symmetry. 多くの異なる構成は「広がっている」ように見えますが、平行移動または共線縮退により同一の距離セットが生成されます。 したがって、構築では、単なる幾何学的分散ではなく、多様性を明示的に強制する必要があります。 

## アプローチ

 強引なアイデアとしては、あらゆる方法を試して選択することです。$n$細胞が外に出た$n^2$、すべてのペアごとの距離を計算し、出現する個別の値の数を測定します。 これは組み合わせ的に不可能です。構成の数は$\binom{n^2}{n}$1 つの構成を評価する場合でもコストがかかります$O(n^2)$。 これは、実現可能な限界をはるかに超えて爆発します。$n=20$。 

重要な構造的観察は、マンハッタンの距離が 2 つの独立した 1 次元の差に依存するということです。 行と列の座標がどのように変化するかを制御できれば、距離の多様性を間接的に制御できます。 多様性を最大化する特に強力な方法は、極端な座標の違いをクラスター化するのではなく、制御されたシーケンス内で段階的に探索するポイントを構築することです。 

意図した構造では、「ジグザグの極端なペアリング」パターンでポイントを構築します。つまり、距離が広範囲の合計をカバーするようにグリッドの反対側の端をペアにします。 考え方は、行の差と列の差の両方が多くのスケールにわたって変化し、これらの差の組み合わせが冗長にならないようにすることです。 

効果的な構築の 1 つは、その座標がグリッドの端の間を交互に進み、構造化された方法で内側に移動するパス上に位置するように点を配置することです。 これにより、多くの明確なマンハッタン距離が作成されます。これは、各ステップで水平方向または垂直方向の分離の大きさが新たに導入され、前後の点の組み合わせによって他の場所では繰り返されない合計が生成されるためです。 

より深い洞察は、マンハッタンの明確な距離を最大化することは、世界の多様性を最大化することと同等であるということです。$(|x_i-x_j|, |y_i-y_j|)$ペア。 座標シーケンスに大きな広がりと非反復ギャップ構造を持たせることにより、間接的に個別の合計を最大化します。

 ## アルゴリズムのチュートリアル

 私たちが使用する構造は決定論的であり、次のセットを構築します。$n$制御された交互の方法でグリッドの対称の極値をペアにすることにより、ポイントを生成します。 

1. グリッドの 4 隅から開始して、概念的に内側に向かってレイヤーを検討します。 各層は、中心からの「距離サイン」が増加するセルを提供します。 
2. グリッドの反対側を交互に配置する一連の座標を生成します。 具体的には、行を昇順に取得しますが、列は小さい値と大きい値の間で交互に取得します。 これにより、連続するポイント間の水平方向の差が、大きい値と小さい値の間で変動することが保証されます。 
3. 初期のポイントが 1 つの境界 (たとえば、上または左) の近くに位置し、後のポイントが反対側の境界 (下または右) の近くに位置するようにポイントを配置します。 これにより、初期ポイントと後期ポイントの間のペアごとの差異が、考えられる行と列のギャップの全範囲に及ぶことが保証されます。 
4. 新しく追加されたすべての点が、以前の点と組み合わせたときに、以前に見られなかったマンハッタン距離を少なくとも 1 つ導入するという不変条件を維持します。 これは、各新しい点が少なくとも 1 つの座標を以前に使用されていなかった極端なレベルに変更し、新しい絶対差の大きさを生成するために達成されます。 
5. 構築されたすべての点を出力します。 

### なぜ効果があるのか

 この構造により、座標の違いが小さな値のセットに限定されないことが保証されます。 代わりに、シーケンスに沿って移動するにつれて、行の差と列の差の両方が新しい大きさを繰り返し導入します。 マンハッタン距離はこれら 2 つの独立した成分の合計であるため、いずれかの次元の新しい大きさごとに、以前の点との新しい合計が作成される可能性があります。 これにより、繰り返される距離の小さなセットへの崩壊が防止され、最大限の多様性が保証されます。$|x_i-x_j| + |y_i-y_j|$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve(n):
    pts = []
    
    # We split points into two interacting chains:
    # one along the top boundary and one along the bottom boundary.
    # We alternate columns to maximize horizontal variation.
    
    left, right = 1, n
    
    toggle = True
    for i in range(1, n + 1):
        if toggle:
            pts.append((1, left))
            left += 1
        else:
            pts.append((n, right))
            right -= 1
        toggle = not toggle
    
    # If n is odd, this already gives n points.
    # If even, we still have n points; structure remains balanced.
    
    return pts

t = int(input())
for _ in range(t):
    n = int(input())
    res = solve(n)
    for x, y in res:
        print(x, y)
```コードは、上部と下部の行に 2 つの相互作用する「フロント」を構築します。 1 つのフロントは左から右に、もう 1 つは右から左に交互に移動します。 これにより、グリッド全体を探索する必要がなく、行と列の両方の差に大きな広がりが生じます。 

交互の切り替えは、連続する点が少なくとも 1 つの座標で最大限に異なることを保証し、クラスタリングを防ぎ、広範囲のマンハッタン距離を促進するため、非常に重要です。 

左ポインタと右ポインタは、列が同じ順序で再利用されないことを保証するため、初期ポイントと後期ポイントの間の水平距離には多くの個別の値が蓄積されます。

 ## 特殊なケース

 のために$n = 2$、この構築ではちょうど 2 つの点が生成されます。$(1,1)$そして$(2,2)$。 アルゴリズムは 1 回交互に行われ、1 つのポイントを上の行に配置し、もう 1 つのポイントを下の行に配置します。 左右のポインタは両方とも境界内で開始され、正確に 1 回だけ移動するため、重複や無効なインデックス付けのリスクはありません。 

偶数の場合$n$、2 つのポインタは直後に一致します。$n/2$繰り返し。 各ステップは列範囲の両側から 1 つの値を消費するため、衝突は発生せず、すべての列が交互の行で 1 回だけ使用されます。 

奇数の場合$n$の場合でも、最後の反復では、左ポインタから有効な未使用列が依然として生成されます。これは、変更により、左が常に残りの未割り当て領域内に残ることが保証されるためです。 この構築では列を再利用する必要がないため、グリッド制約は全体にわたって保持されます。
