 ## 問題の理解

 各テストケースについて、バイナリ文字列の最長のプレフィックスを見つけるように求められます。`a`別のバイナリ文字列のサブシーケンスとして現れる可能性があります`b`。 プレフィックスは単に最初の文字です`k`の登場人物`a`、およびその続き`b`からゼロ個以上の文字を削除することによって形成されます。`b`残りの文字の順序は変更しません。 

入力はテスト ケースの数を示し、各テスト ケースの長さは`a`そして`b`, followed by the strings themselves. 出力は、各テスト ケースの単一の整数です。つまり、テスト ケースの最長プレフィックスの長さです。`a`それはの続きです`b`。 

制約は寛大ですが、簡単ではありません。 各文字列の長さは最大 200,000 文字で、すべてのテスト ケースの合計も 200,000 文字に制限されます。 最悪のケースではおよそ 4 * 10^10 の演算に達する可能性があるため、テスト ケースごとに O(n*m) 時間かかるアルゴリズムは除外されます。 テスト ケースごとに O(n + m) に近い値が必要です。 

注意すべきエッジケースは以下のような場合です。`b`よりも短いです`a`、またはいつ`b`に必要な文字が含まれていません`a`。 たとえば、次の場合`a = "111"`そして`b = "000"`、答えは 0 です。もう 1 つのエッジケースは次のような場合です。`a`文字が 1 つだけ含まれています。 その文字が存在する場合、コードは正しく 1 を返す必要があります。`b`そうでない場合は 0。 途中で終わる接頭辞`b`または、複数の文字をスキップする必要があります`b`これは、素朴な実装が失敗する可能性がある微妙なケースでもあります。 

## アプローチ

 ブルートフォースアプローチでは、次のすべてのプレフィックスに対して反復処理が行われます。`a`、それぞれについて、それが次の部分シーケンスであるかどうかを確認します。`b`。 これを行うには、スキャンすることができます`b`プレフィックスの各文字を調べて、すべての文字が順番に表示されるかどうかを確認します。 これは正しいですが、サブシーケンスの各チェックには O(m) 時間がかかり、チェックするプレフィックスが n 個あります。 最悪の場合、これは O(n*m) となり、指定された制約に対して遅すぎます。 

最適化のための重要な洞察は、検索を再開する必要がないことを認識することで得られます。`b`プレフィックスごとに。 最後に一致した位置を追跡できます`b`文字が連続して一致する限り、プレフィックスを拡張します。 別のアプローチは、検索を逆にすることです。つまり、検索の最後から開始します。`b`の末尾から文字を一致させようとします`a`後ろ向きに。 この問題では、次の接頭辞を考慮するため、`a`、より単純な貪欲なアプローチは、次の文字を一致させることです。`a`最初に見つかった「1」から始まります`b`右端から。 2 つのポインターを使用できます。1 つは末尾にあります。`a`そして最後に1つ`b`。 ポインタを中に移動します`b`後方にポインタをデクリメントします`a`文字が一致するたびに。 ポインタが入ったら`a`先頭を超えて移動すると、サブシーケンスである最長のプレフィックスが見つかりました。

 ## アルゴリズムのチュートリアル

 1. テストケースごとに文字列を読み取ります。`a`そして`b`。 
2. 2 つのインデックスを初期化します。`i`最後の文字で`a`(n-1) と`j`最後の文字で`b`(m-1)。 
3. 両方のインデックスが範囲内にあるときに、比較します。`a[i]`と`b[j]`。 
4. 一致する場合はデクリメントします。`i`で文字を照合することに成功したため、`i`接頭辞で。 
5. 常にデクリメントする`j`後方に進むからです`b`次に一致する文字を検索します。 
6. ループ後の最長プレフィックス長`k`は`i+1`、 以来`i`最後の一致しない文字のインデックスです。`a`。 

機能する理由: 2 ポインター アプローチにより、一致する末尾からの最長のプレフィックスが確実に見つかります。`b`。 後方に移動すると、常に文字を順番に照合し、次の時点で停止することが保証されます。`b`保証が枯渇すると、プレフィックスが一致しなくなります。 これは貪欲な選択です。どの文字もスキップするため、常に最初に最後の文字と一致しようとします。`b`以前は、達成可能なプレフィックス長を短縮することしかできませんでした。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = input().strip()
        b = input().strip()
        
        i = n - 1
        j = m - 1
        
        while i >= 0 and j >= 0:
            if a[i] == b[j]:
                i -= 1
            j -= 1
        
        print(i + 1)

if __name__ == "__main__":
    solve()
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`そして文字列から改行を取り除きます。 2 つのインデックスを使用して、エンドポイントからの進行状況を追跡します。`a`そして`b`。 デクリメントします`i`一致した場合のみ、常にデクリメントされます`j`。 印刷`i+1`最後に、一致する最長のプレフィックス長を示します。 微妙な点には、トラバースの方向、空の文字列の処理、および正しく解釈することが含まれます。`i+1`プレフィックスがゼロ文字と一致する場合。
