 ## 解決策
 ## 問題の理解

 正の整数と数値の配列が与えられます。$c$負、ゼロ、または正の値を指定できます。 タスクは、配列を並べ替えて、連続する要素間の絶対差の合計を最小化する順列に並べ替えることです。$c$。 具体的には、順列の場合$b$の$a$を最小限に抑えたい$$\sum_{i=1}^{n-1} |b_{i+1} - b_i - c|.$$この最小和を達成するすべての順列の中で、辞書編集的に最小のものを出力する必要があります。 辞書順とは、2 つのシーケンスが異なる最初の要素によってどちらが小さいかを決定することを意味します。 

入力制限は中程度です。 各配列には最大 5000 個の要素を含めることができ、最大 1000 個のテスト ケースを含めることができますが、すべてのテスト ケースにわたる要素の合計数が 5000 を超えることはありません。これは、全体的に複雑なソリューションはおおよそあることがわかります。$O(n \log n)$または$O(n^2)$実現可能です。 

明らかではないエッジケースは次のとおりです。$c$配列要素に対して非常に負であるか、または非常に正です。 たとえば、次の場合$a = [1,2,3]$そして$c = 10$、連続する差ができるだけ 10 に近い場合、合計は最小になります。 単純に配列を並べ替えると、次のような配置を見逃してしまう可能性があります。$|b_{i+1} - b_i - c|$最小。 もう 1 つのエッジ ケースは、次のようにすべての要素が等しい場合です。$a = [5,5,5]$そして$c$は任意です。 どの順列でも同じ合計が得られるため、辞書編集的に最小のシーケンスは単にソートされた配列になります。 

## アプローチ

 ブルートフォースアプローチは、すべてを生成することです。$n!$順列を計算し、それぞれの合計を計算し、最小値を選択します。 これは明らかに非現実的です$n=10$、 なぜなら$10! = 3,628,800$操作。 したがって、より構造化された方法が必要です。 

重要な洞察は、引数の符号が固定されている場合、絶対値関数は線形に動作するということです。 連続する2つの数字の場合$b_i$そして$b_{i+1}$、 用語$|b_{i+1} - b_i - c|$が最も小さいとき$b_{i+1} - b_i$にできるだけ近いです$c$。 これは、連続する差分が近似されるように配列要素を配置することを意味します。$c$。 

これを次のように定式化できます。 まず配列をソートしましょう。 次に、貪欲な配置を検討します。すでに配置されている要素の両端キューを維持し、現在の差異をほぼ維持する残りの最大の要素または最小の残りの要素を選択します。$c$。 いつ$c$が負の場合、差は負である必要があるため、大きな数値は小さな数値よりも前に置く必要があります。 いつ$c$が正の場合、小さい数値は大きい数値よりも前に置く必要があります。 これは、ソートされた配列の端から繰り返し選択することと同等で、「傾斜した」配置をシミュレートします。 

大まかな方向がわかったら（場合は昇順）、$c\ge 0$、場合は降順$c<0$)、両方の選択が合計に同じ寄与をもたらす場合は、小さい要素を最初に選択することで、いつでも辞書編集的に関係を解消できます。 これにより、最小合計と辞書編集上の最小順序が同時に保証されます。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$、$c$、および配列$a$。 仕分け$a$これは、辞書編集上の順序を管理するための最初の自然なステップです。 
2. 配列を昇順に並べ替えます。 これにより、最小限の寄与で配列の端から貪欲な決定を行うことができます。 
3. ソートされた配列の先頭と末尾に 1 つずつ、2 つのポインターを初期化します。 また、空の結果配列も初期化します。 
4. 要素が残っている間に、残っている最小の要素または残っている最大の要素を現在のシーケンスに追加する場合の絶対差を評価します ($c$を考慮に入れてください）。 合計が最小になるものを選択してください。 両方の選択で同じ寄与が得られる場合は、辞書編集上の順序を維持するために小さい方の要素を選択します。 
5. すべての要素が配置されるまで繰り返します。 
6. 結果の順列を出力します。 

これが機能する理由: 各ステップで、合計への増分寄与を最小限に抑える要素を貪欲に選択します。 連続した差分のみを考慮すればよく、常に 2 つの極端な値の中から最良の選択を選択するため、これによりグローバルな最小性が保証されます。 最初に並べ替えることにより、同点の状況で辞書順に最小のオプションが選択されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, c = map(int, input().split())
        a = list(map(int, input().split()))
        a.sort()
        if n == 1:
            print(a[0])
            continue
        res = []
        i, j = 0, n-1
        while i <= j:
            if not res:
                # first element, pick smallest
                res.append(a[i])
                i += 1
            else:
                # decide to pick from left or right
                left = abs(a[i] - res[-1] - c)
                right = abs(a[j] - res[-1] - c)
                if left <= right:
                    res.append(a[i])
                    i += 1
                else:
                    res.append(a[j])
                    j -= 1
        print(" ".join(map(str, res)))

if __name__ == "__main__":
    solve()
```このソリューションでは、まず配列を並べ替えて辞書順を管理します。 メイン ループは、ソートされた配列の両端を考慮し、その要素が追加された場合の合計への増分寄与を計算します。 最小値を選択すると、合計が段階的に最小化されます。 並べ替えにより、辞書編集上の順序のタイブレークが正しいことも保証されます。
