 ## 解決策
 ## 問題の理解

 それぞれが整数の電荷を持つ、一列に配置された一連の粒子が与えられます。 私たちは任意の粒子を除去できる装置を持っています。その後、2 つの隣接する粒子が 1 つの粒子に融合され、その電荷は隣接する 2 つの粒子の合計になります。 目標は、粒子が 1 つだけ残るまで一連の操作を適用し、最後の粒子の電荷を最大化することです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースについて、粒子の数とそれぞれの電荷がわかります。 出力は、操作を最適に実行した後の残りの粒子の可能な最大電荷です。 

制約は重要です。$2 \cdot 10^5$すべてのテスト ケースにわたる粒子の合計があり、個々の電荷が非常に大きいか負になる可能性があります。 これらの制約があるため、パーティクルの削除と配列の再計算を繰り返し行う単純なシミュレーションは遅すぎます。 各操作のシミュレーションには時間がかかる場合があります$O(n^2)$大きな入力の場合は 1 秒以内に終了しません。 

すべてのパーティクルが負の場合、微妙なエッジ ケースが発生します。 パーティクルを無差別に結合する不用意なアプローチは、最大残留電荷を不必要に減少させる可能性があります。 たとえば、次のような行がある場合、`[-1, -2, -3]`の場合、最適な戦略は、最終粒子として最小の負の合計を維持する方法で負の数値をマージすることです。 

## アプローチ

 ブルートフォース手法は簡単です。パーティクルの除去の可能性ごとに、パーティクルが 1 つ残るまで残りの可能なすべてのシーケンスを再帰的にシミュレートし、最大値を取得します。 これにより、考えられるすべての操作シーケンスが調査されるため、正しい答えが得られることが保証されます。 ただし、このアプローチは時間計算量の階乗になります。$n$粒子、おおよそあります$n!$探索するシーケンス、これは実行不可能です$n \sim 10^5$。 

重要な観察は、マージの順序は、連続する正または負のシーケンスをグループ化すること以外には重要ではないということです。 この操作は基本的に隣接する数値をマージするので、おそらく負の和のゼロ長マージをスキップした後、最終的に最終的な粒子の電荷は元の配列の連続した部分列の合計になります。 これにより、問題は最大部分配列合計問題の変形に縮小されます。 

具体的には、残りの粒子の可能な最大電荷は、非負の合計の最大の連続サブシーケンスの合計に等しい。 これは、配列を反復処理し、連続する粒子を貪欲にマージすることで線形時間で計算できます。常にすべての正の寄与を合計し、負の接頭辞を含めることで合計が小さくなったときに合計をリセットします。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、粒子の数を読み取ります。`n`そして料金表`c`。 
2. 2 つの変数を初期化します。`current_sum`連続したサブシーケンスの進行中の合計を追跡するため、および`max_sum`見つかった最大合計を追跡します。 
3. 料金を順番に繰り返します。 各粒子について、その電荷を次のように加算します。`current_sum`。 もし`current_sum`現在のパーティクル単独よりも小さくなる、リセット`current_sum`粒子の電荷に応じて。 これは、部分配列の合計を最大にするための Kadane のアルゴリズムの標準的な修正です。 
4.アップデート`max_sum`もし`current_sum`それを超えています。 
5. すべてのパーティクルを処理した後、`max_sum`最終粒子の達成可能な最大電荷が含まれます。 
6. 各テスト ケースの結果を印刷または保存します。 

機能する理由: マージ操作により、シーケンスが連続セグメントの合計に減らされます。 マージの最適なシーケンスでは、潜在的な合計を失わずにプラスの寄与をスキップすることはできません。 したがって、すべての連続セグメントの最大合計を見つけることは、マージを最適に実行することと同じです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        c = list(map(int, input().split()))
        current_sum = max_sum = c[0]
        for charge in c[1:]:
            current_sum = max(charge, current_sum + charge)
            max_sum = max(max_sum, current_sum)
        print(max_sum)

if __name__ == "__main__":
    solve()
```このソリューションでは、複数のテスト ケースに高速 I/O を使用します。 各パーティクルを 1 回だけ処理し、実行中の合計を効率的に維持し、Python の整数は任意精度であるため、整数のオーバーフローが発生しないようにします。

 ## 特殊なケース

 配列に負の数値のみが含まれている場合、アルゴリズムは最小の負の粒子を正しく選択します。これは、値を減らすマージを実行しないことに相当します。 例えば、`[-1, -2, -3]`返品`-1`。 

パーティクルが 1 つだけの場合、操作は必要なく、アルゴリズムはそのパーティクルを直接返します。 

Python は任意精度の整数をサポートしているため、このソリューションはオーバーフローすることなく大きな正の整数も処理します。
