 ## 問題の理解

 長さの文字列を構築する必要があります`n`可能な限り異なる小文字を使用しないでください。 

問題は、行優先のトラバーサルによってその文字列が生成される **すべての可能なグリッド形状**に対して文字列が有効なままでなければならないということです。 もし`n = r × c`の場合、文字列は次のように解釈できます。`r × c`グリッド。 因数分解ごとに、`n`、結果として得られるグリッドには、同じ文字を含む隣接するセルのペアがあってはなりません。 

行優先の順序で、水平方向に隣接するものは、次のように異なる位置に対応します。`1`行内では、垂直方向に隣接するものは異なる位置に対応します。`c`。 

文字列を構築するとします`s`。 あらゆる約数について`c`の`n`、次のことを保証する必要があります。

難しいのは、有効な文字列を構築できないことです。 難しいのは、使用する個別の文字の数が最小限であることを証明することです。

 ## アルゴリズムのチュートリアル

 1. 最小の整数を見つける`k ≥ 2`そのような`n % k != 0`。 
2. 最初のものを使用します`k`小文字:```

ステップ 1 で最小文字数が指定されているのはなぜですか?

### なぜ効果があるのか

 構築された文字列にはピリオドが付いています`k`。 2 つの位置に同じ文字が含まれるのは、それらの距離が の倍数である場合のみです。`k`。 

任意のグリッド幅に対応`c`分割する`n`、垂直方向の衝突には必要になります`c`の倍数になる`k`。 そんなことはあり得ない、なぜなら`k`分けない`n`, 一方、すべての約数`c`の`n`そうです。 

水平方向の衝突は距離に対応します`1`。 以来`k ≥ 2`、隣接する位置は常に異なる文字を受け取ります。

最適化のために、以下のすべての整数`k`分割する`n`。 より少ない数を使用するソリューション`k`個別の文字は、これらの約数の 1 つに関連付けられた制約を満たす必要がありますが、これは不可能です。 したがって、`k`達成可能な個別の文字の最小数です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())

        k = 2
        while n % k == 0:
            k += 1

        s = []
        for i in range(n):
            s.append(chr(ord('a') + (i % k)))

        ans.append(''.join(s))

    sys.stdout.write('\n'.join(ans))

if __name__ == "__main__":
    solve()
```最初のループは、割り切れない 1 より大きい最小の整数を検索します。`n`。 この値は常に最大で約`log₂(n) + 1`、なぜなら、`2,3,4,...,k-1`全部分割された`n`、 それから`n`すでに巨大なものになるだろう。 実際には、ループは数回しか実行されません。 

取得後`k`、文字列は周期的に生成されます。 位置`i`～に相当する手紙を受け取る`i mod k`、まさに次の期間を作成します`k`。 

実装の詳細の 1 つは注目に値します。 グリッド形状を明示的にテストする必要はありません。 数論的引数は、次のすべての約数の正しさを保証します。`n`したがって、周期文字列を構築するだけで十分です。
