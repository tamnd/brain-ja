 ## 解決策
 ## 問題の理解

 同じ長さの配列がいくつか与えられています。 それらはすべて同じ隠れ塩基配列から生じています。 そのベースから複数のコピーが作成され、次に 2 つの変換ルールのいずれかを使用して各コピーが変更されました。 これらのコピーのうちの 1 つだけが特別で、残りのコピーとは異なる変換ルールを使用します。 

変換によって配列の合計は変更されませんが、構造化された方向性を持った方法で値が再分配されます。 特殊でない配列では、対応する質量を右端に押しながら、単位質量を 2 つの位置で 1 ステップ左に移動する特定の「2 点シフト」のみが許可されます。 特別な配列は、わずかに長い範囲で質量をシフトする別のルールを使用し、インデックス全体で異なる不均衡パターンを効果的に作成します。 

これらの未知の操作の後には、最終的な配列のみが与えられます。 タスクは、どの配列が特別な配列であるかを特定し、特別な変換がその配列に何回適用されたかを判断することです。 

制約により、テスト ケースごとにほぼ線形の解決策が求められます。 すべてのテスト ケースにわたる要素の合計数は 100 万で制限されているため、配列のすべてのペアを単純に比較したり、操作をシミュレートしようとするソリューションは、テスト ケースごとに O(m) または O(m log m) で動作する場合にのみ受け入れられます。 テスト ケースごとに n または m の二次関数を実行することは不可能です。 

単純な解釈では、各候補インデックスの基本配列の再構築を試み、一貫性を検証することになります。 各再構成の試行には O(nm) のコストがかかり、全体では O(n²m) になるため、これはすぐに失敗します。 

さらに微妙な落とし穴は、配列をペアごとに直接比較し、「差分パターン」によって特別な配列を識別できると仮定していることです。 演算はローカル ノイズではなく、グローバルな線形制約を保​​持するため、配列間の単純な差分では特殊な配列がきれいに分離されません。 

## アプローチ

 重要な問題は、すべての配列が同じ未知の塩基を共有しており、その上に適用されたさまざまな構造化摂動の効果しか確認できないことです。 強引なアイデアは、どの配列が特別であるかを推測し、それが特別であると仮定し、その後、特別な操作モデルを使用して基本配列を再構築しようとすることです。 ベースが回復されたら、他のすべての配列が特別ではない操作を使用して生成できるかどうかを確認できます。 

これは論理的には正しいですが、計算的には実行不可能です。 1 つの候補から基底を再構成するには、m 個の位置にわたる制約付きシステムをシミュレートまたは解決する必要があり、これを n 個の候補すべてに対して実行すると、n 倍の演算が多すぎます。 

重要な観察は、どちらの操作も配列内の強力な線形構造を保持していることです。 慎重に選択した配列の重み付き合計を定義すると、特別ではない演算ではその合計が意味のある形で変更されませんが、特殊な演算では予測可能な二次関数で合計が変更されます。 これにより、各配列を、未知の基本配列ではなく、適用された特殊操作の数のみに依存する単一のスカラー署名に変換できます。 

すべての配列に対してこの不変式のような値を計算すると、特殊でない配列はすべて同じベースラインに収まりますが、特殊な配列は逸脱します。 偏差は、インデックスを特定し、特殊操作の正確な数を回復するのに十分な大きさです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 候補ごとのブルート フォース再構築 | O(nm²) | O(m) | 遅すぎる |
 | 重み付けされた不変式の計算 | O(nm) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 配列を両方の操作で予測どおりに動作する単一のスカラーに変換する位置重み付けを構築します。 アイデアは、質量がインデックス間でどのように押し出されるかを追跡する方法で不均衡を測定することです。

1. インデックスに対する固定多項式の重みを使用して、各配列の変換された値を計算します。 標準的な選択は、隣接する差分または 2 次のプレフィックス構造から得られる寄与を使用することです。これにより、基本配列の効果がキャンセルされます。 
2. 配列ごとに、どの程度の「構造化シフト」が発生したかを表す単一の整数値を累積します。 この構造は、タイプ 1 の操作がこの値に正味の変化を与えないように選択されます。 
3. 各配列について、同じスカラーを再度計算します。ただし、操作 2 がアプリケーションごとに一定の加算量に寄与することに注目してください。 これは、各配列のスカラー値がベースラインに固定係数の k 倍を加えたものに等しいことを意味します。ここで、k は適用される特別な演算の数です。 
4. すべての非特殊配列は、演算 1 を少なくとも 1 回のみ使用し、演算 2 は決して使用しないため、同じスカラー ベースラインを共有します。 特殊な配列だけがずれています。 
5. 個別のスカラー値を持つ配列を識別します。 そのスカラーとベースラインの差により、特殊操作の数が決まります。 

この実装では、配列ごとに O(m) の重み付き合計を計算します。 

正確さは線形不変条件に基づいています。両方の演算は、演算 2 による制御された寄与を除き、選択された重み付けの下でその効果がキャンセルされる再分布に対応します。変換は配列値に対して線形であるため、すべての効果が重なり、最終的なスカラーは隠れた基本配列とは無関係に、演算の数によって一意に決定されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    arrs = []
    
    for _ in range(n):
        arrs.append(list(map(int, input().split())))
    
    # We compute two auxiliary arrays:
    # pref1: weighted sum with i
    # pref2: weighted sum with i*i (via linear combination trick)
    
    def signature(a):
        s1 = 0
        s2 = 0
        for i, x in enumerate(a, start=1):
            s1 += x * i
            s2 += x * i * i
        return s1, s2
    
    sigs = [signature(a) for a in arrs]
    
    # Use first array as reference baseline candidate group
    # Since only one differs, majority share same transformed structure
    base = sigs[0]
    
    # find the special one by deviation in second component after normalization
    diff = None
    idx = -1
    
    for i in range(n):
        if sigs[i] != base:
            idx = i
            diff = sigs[i][0] - base[0]
            break
    
    # compute k from linear scaling constant (derived from operation effect)
    # for this problem structure, each special op contributes fixed +1 shift in derived metric
    k = abs(diff)
    
    print(idx + 1, k)

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()
```実装では、各配列の位置署名を計算します。 最初のモーメントと 2 番目のモーメントは、値がインデックス間でどのように分布しているかをキャプチャします。 どちらの操作も合計の合計は保持しますが、質量を非対称にシフトするため、これらのモーメントを比較することで操作 2 の影響を分離します。 

次に、特殊でないベースライン配列の中から一貫したベースライン配列を選択し、シグネチャが逸脱している配列を見つけます。 最初の瞬間の差は、特別な操作の数に直接対応します。これは、特別な操作を適用するたびに、集合的な重み付けされた位置に固定単位のシフトが導入されるためです。 

重要な点は、基本配列を再構築する必要がないことです。 不変条件はそれを完全に削除します。 

## 実用的な例

 長さ 5 の配列が 3 つあり、演算 1 で 2 つ、演算 2 で 1 つが生成される、概念的な小さなケースを考えてみましょう。各配列の最初のモーメントを計算します。 

| 配列 | モーメント値 |
 | --- | --- |
 | c1 | 42 |
 | c2 | 42 |
 | c3 | 47 |

 ここで、c1 と c2 は完全に一致するため、それらは特別なものではないことがわかります。 c3 の偏差は 5 で、これは適用された特殊操作の数に対応します。 

これは、不変式が特殊な演算に対する線形感度を維持しながら、すべての有効な非特殊な変換を単一の同値クラスに折りたたむことを確認します。 

2 番目のトレースは、基本配列が均一な場所に構築できます。 生の配列が大きく異なっていても、計算されたシグネチャは特殊なケース以外では依然として一致しており、メソッドが初期構成から独立していることがわかります。

 ## 特殊なケース

 基本配列が定数の場合、厄介な状況が発生します。 その場合、特殊でないすべての操作は同一の配列を生成し、目に見える唯一の差異は特殊な操作から生じます。 操作 2 では、操作 1 では複製できない別の 2 次変位パターンが導入されるため、不変条件でもそれが区別されます。 

もう 1 つの微妙なケースは、シフトの部分的なキャンセルにより、複数の配列が同様に見える場合です。 生の値がわずかに異なる場合でも、変換が線形であり、2 つの演算タイプ間で偶発的な衝突が発生しないため、重み付けされたシグネチャは一貫して発散します。
