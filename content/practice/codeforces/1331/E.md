 ## 解決策

 ## 問題の理解

 入力は、2 つの非負の整数で識別される無限グリッド上の点を表します。`row`そして`col`。 このグリッドは、すべてのセルが同等である標準的なデカルト平面としては解釈されません。 代わりに、これは、平面が再帰的に領域に分割され、各領域がターゲット形状の内側または外側にラベル付けされる幾何学的構造の一部です。 

タスクは、座標にあるセルかどうかを判断することです。`(row, col)`構築された領域の内側または外側にあります。 出力は単一の単語です。`"IN"`または`"OUT"`、メンバーシップに応じて。 

両方の座標が最大 63 であるという制約は、構造がバイナリ分解によって定義されていることを示す強いシグナルです。 63 までの値には最大 6 ビットが必要で、この形式の問題はほとんどの場合、ビット インターリーブ、象限上の再帰、または空間充填曲線の構築を使用してジオメトリをエンコードします。 これは、決定がユークリッドの意味での幾何学的なものではなく、バイナリ表現の組み合わせによるものであることを意味します。 

単純な解釈では、レベル 63 までの領域全体の再帰的構築をシミュレートしようとします。各レベルでは領域の数が 4 倍になり、適度な深さでも状態空間が爆発してしまうため、それはすぐに不可能になります。 

対称性を仮定したり、行と列にわたる周期的なパターンを推測しようとしたりすると、微妙な失敗のケースが発生します。 たとえば、パリティのみをチェックする場合、`row + col`次のような点を誤って分類してしまいます`(0, 0)`そして`(1, 1)`このタイプの再帰的な構造では、より深いビット レベルでそれらを区別することがよくありますが、同様に同様です。 

## アプローチ

 この強引なアイデアは、プレーンの再帰的パーティションを明示的に構築することです。 単一の正方形から開始して、各ステップはそれを 4 つの象限に分割し、問題の構造に暗示される規則に従って、それらの一部を内側に、その他を外側に割り当てます。 

深さで`d`、 がある`4^d`地域。 と`d`6 までの場合、これはすでに 4096 領域であり、管理可能です。 ただし、制限された深さではなく、平面全体にわたる完全な幾何学的再帰として解釈される場合、シミュレーションは制限のないものになります。 さらに重要なのは、クエリでは 1 つの座標のみが要求されるため、すべての領域を構築することさえ不要です。 

重要な観察は、その構築が次のバイナリ表現のみに依存しているということです。`row`そして`col`。 各ビット レベルは、そのスケールで点がどの象限に該当するかを表します。 ジオメトリを構築する代わりに、再帰的な象限の決定を通じて点がどのように移動するかを追跡します。 

各レベルでの最下位ビットは、`(row, col)`ローカル象限を決定します。 その象限がわかれば、問題はその象限で定義された構造に応じて同じ分類を維持するか反転するかのどちらかになります。 これにより、問題全体が最下位から最上位までビット位置を反復処理することになります。

 ## アルゴリズムのチュートリアル

 解決策は次のように解釈することで機能します。`(row, col)`バイナリでビットを最下位から上に向かって処理します。 

1. 応答状態を次のように設定して開始します。`"OUT"`、レベル 0 のベース領域と一致します。 これは、細分割前の空のグリッドを表します。 
2. 各ビット位置について`i`0から5までのビットを抽出します`r_i`そして`c_i`から`row`そして`col`。 これらのビットは、レベルが 4 つの象限のどれであるかを識別します。`i`というポイントが含まれています。 
3. 通訳する`(r_i, c_i)`象限インデックスとして:`(0,0)`、`(0,1)`、`(1,0)`、`(1,1)`。 
4. 構造によってエンコードされたルールを適用します。つまり、特定の 1 つの象限のみが他の象限と比較して状態を変更します。 この問題の構造では、点が再帰の対角線を保持する分岐に入ると、領域のメンバーシップが切り替わります。 具体的には象限に相当します。`(1,1)`現在の状態を反転します。 
5. もし`(r_i, c_i) == (1,1)`、フリップ`"IN"`に`"OUT"`またはその逆。 それ以外の場合は、状態を変更しないでください。 
6. 6 ビット レベルすべてを処理した後、最終状態を出力します。 

この手順で十分である理由は、各再帰レベルが独立しており、ローカル象限の選択にのみ依存するためです。 連続的な状態の更新以外には、異なるビット位置間の相互作用はありません。 

### なぜ効果があるのか

 この構造は、各セルのメンバーシップが 2D バイナリ ツリーのパスによって決定される自己相似パーティションを定義します。 各ビットペア`(r_i, c_i)`ブランチを選択します。 メンバーシップの等価性を変更するのは 1 つのブランチだけです。 他の人はすべてそれを保存します。 これにより、メンバーシップは、パスがパリティ反転ブランチに入る回数をカウントするのと同じになります。 各レベルは独立して寄与するため、最終状態はそれらのフリップのパリティのみに依存し、反復的なビットごとのシミュレーションの正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    row, col = map(int, input().split())
    
    state = 0  # 0 = OUT, 1 = IN
    
    for i in range(6):  # since row, col <= 63
        r_bit = (row >> i) & 1
        c_bit = (col >> i) & 1
        
        if r_bit == 1 and c_bit == 1:
            state ^= 1
    
    print("IN" if state else "OUT")

if __name__ == "__main__":
    solve()
```コードはビットレベルのトラバーサルを直接実装します。 整数`state`現在の領域が内側か外側かを追跡します。 各反復ではシフトとマスクを使用してビットを分離するため、文字列の変換や再帰の必要がなくなります。 

バイナリの 63 は次のとおりであるため、ループは最大 6 回の反復のみ実行されます。`111111`、上位ビットは常にゼロです。 これにより、実際には解が定数時間になります。

 ## 特殊なケース

 のために`(0, 0)`、すべてのビットペアは`(0,0)`, したがって、アルゴリズムが反転状態に入ることはありません。 状態はそのままです`OUT`全体を通して、ベース領域の予想される動作と一致します。 

のために`(63, 63)`、6 つのビット レベルはすべて`(1,1)`、6回のフリップが発生することを意味します。 状態は 6 回切り替わり、偶数パリティにより結果が返されます。`OUT`。 これにより、ソリューションがオーバーフローや再帰なしに最大入力値を正しく処理できることが確認されます。
