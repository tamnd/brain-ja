 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、根を張った木です。`n`各頂点は 0 個以上の子を持つことができます。 2つのリンゴを任意の頂点に配置します`x`そして`y`。 木が揺さぶられると、それぞれのリンゴが葉に到達するまで一歩ごとに子供のところに移動し、そこで落ちます。 ティモフェイは複数の仮定について知りたがっている`(x, y)`、**順序付けられた葉のペア**の数`(a, b)`リンゴはどこから始まるのか`x`に落ちる`a`そしてリンゴはから始まります`y`に落ちる`b`。 

ツリーは静的です。 その構造はクエリ間で変わりません。 問題は、**各頂点から到達可能なリーフのセット**を決定することに帰着します。 どの葉から到達できるかがわかったら`x`そして`y`、ペアの数は、それらのセットのサイズのデカルト積です。 いくつかの葉が重なっている場合、それはカウントの積としてペアを数えることによって自然に処理されます。重複は許可されています。`(a, b)`は順序付きペアです。 

制約は重要です。 の合計`n`すべてのテスト ケースの数は最大 200,000 であり、同様に`q`。 各クエリのリーフを個別に計算する単純なアプローチでは、`O(n)`クエリごとに動作するため、`O(nq)`最悪の場合、最大 4 × 10¹⁰ の操作が可能ですが、これは完全に不可能です。 したがって、クエリに答えるためにツリー上で前処理ステップが必要です。`O(1)`または`O(log n)`時間。 

明白でないエッジ ケースには、それ自体が葉である頂点が含まれます。 たとえば、次の場合`x`は葉です。到達できる唯一の葉はそれ自体です。 もし`x`そして`y`が同じ頂点である場合、ペアの数はその頂点から到達可能なリーフの数の 2 乗になります。 不注意な実装では、葉を正しく処理することを忘れたり、両方のリンゴが同じ葉から始まるときに失敗したりする可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、クエリごとにリンゴが落ちることをシミュレートします。 クエリごとに`(x, y)`から DFS を実行できます。`x`到達可能なリーフを列挙してから、別の DFS を列挙します。`y`。 これは、可能なエンドポイントを直接カウントするため、正しいです。 ただし、このアプローチのパフォーマンスは、`O(n)`クエリごとに動作し、`q`最大 2 × 10⁵ および`n`最大 2 × 10⁵ の操作数は法外です。 

重要な洞察は、任意の頂点から到達可能なリーフのセットは静的であり、ツリー構造にのみ依存するということです。 したがって、単一の DFS を使用して **すべての頂点についてそのサブツリー内の葉の数を事前計算**できます。 頂点を根元とするサブツリーの葉`v`まさに頂点です`u`そのサブツリーには子がありません。 すべての頂点の下にある葉の数がわかったら、クエリを実行します。`(x, y)`事前に計算されたカウントを乗算することになります。`leaves[x] * leaves[y]`。 これにより、クエリ時間が短縮されます。`O(1)`後`O(n)`前処理中。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(nq) | O(n) | 遅すぎる |
 | 葉を事前計算する | O(n + q) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして木の端。 隣接リスト表現を構築します。 
3. 各頂点のすべての子を識別し、子のない頂点を葉としてマークします。 
4. ルートから開始して DFS を実行します。 

- 頂点ごとに`v`、子がない場合は、設定します`leaves[v] = 1`。 
- それ以外の場合は合計`leaves[u]`すべての子供たちにとって`u`の`v`。 
- これにより、`leaves[v]`をルートとするサブツリー内のリーフの総数を格納します。`v`。 
5.読む`q`クエリ`(x, y)`。 クエリごとに計算します`leaves[x] * leaves[y]`そして結果を印刷します。 
6. すべてのテスト ケースに対して繰り返します。 

機能する理由: 各頂点のサブツリーには、固定されたリーフのセットが含まれています。 リーフ数を事前に計算することで、各クエリを単純な乗算に削減します。 DFS は、すべての頂点のサブツリーの葉の数が 1 回だけ計算されることを保証するため、正確さが維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        adj = [[] for _ in range(n + 1)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            adj[u].append(v)
            adj[v].append(u)
        # compute children
        children = [[] for _ in range(n + 1)]
        for v in range(1, n + 1):
            for u in adj[v]:
                if u != 1 and u not in children[v] and v != 1:
                    children[v].append(u)
        # DFS to count leaves
        leaves = [0] * (n + 1)
        visited = [False] * (n + 1)
        def dfs(v):
            visited[v] = True
            if len(adj[v]) == 1 and v != 1:  # leaf
                leaves[v] = 1
                return 1
            total = 0
            for u in adj[v]:
                if not visited[u]:
                    total += dfs(u)
            leaves[v] = total
            return total
        dfs(1)
        q = int(input())
        for _ in range(q):
            x, y = map(int, input().split())
            print(leaves[x] * leaves[y])

if __name__ == "__main__":
    solve()
```説明: ツリーを表すために隣接リストを使用します。 DFS は訪問したノードを追跡し、リーフ数を計算します。 基本ケースは、子が 1 つしかない場合はルートも含めて、葉を適切に処理します。 クエリは一定時間内に解決されます。 葉の検出を正しく処理するために特別な注意が払われます (`len(adj[v]) == 1 and v != 1`) ルートには子が 1 つだけ存在する可能性がありますが、それ自体は葉ではないためです。
