 ## 解決策
 ## 問題の理解

 私たちには通りがあります`n`ポジションを構築します。 すべての位置に、高さが次の範囲の整数である家を含めることができます。`0`そして`h`。 

高さのある家から得られる利益`a`は`a²`, したがって、高い家は常に優れています。 市が課すのは`m`ゾーニングルール。 各ルールはポジションのセグメントをカバーします`[l, r]`そして、そのセグメント内で最も高い家はある値を超えることはできないと言います`x`。 

課題は、すべての制限が満たされ、総利益 (すべての高さの二乗和) ができるだけ大きくなるように、すべてのポジションの高さを選択することです。 

制約は非常に小さいです。 両方`n`そして`m`せいぜい`50`。 すべての制限とすべての位置の積に比例した作業を実行するアルゴリズムであっても、完全に安全です。 アン`O(nm)`または`O(n²m)`ソリューションは即座に実行されます。 

主な課題は、範囲制限が個々の住宅にどのような影響を与えるかを理解することです。 制限により、範囲内の最大の高さは超えることはできません。`x`。 つまり、その範囲内のすべての家も最大でも`x`。 もし一軒でもこれより高い家があれば`x`、範囲の最大値を超えます`x`そして制限に違反することになります。 

よくある間違いは、制限を 1 つのポジションにのみ適用されるものとして扱うことです。 

考慮する：```
3 10 1
1 3 5
```すべての家は制限範囲内にあるため、すべての高さは最大でも以下でなければなりません`5`。 

最適な高さは次のとおりです。```
[5, 5, 5]
```利益：```
25 + 25 + 25 = 75
```不用意に解釈すると、次のような高さが許容される可能性があります。`[10, 10, 10]`、明らかに制限に違反しています。 

もう 1 つの簡単な間違いは、複数の制限が重複する可能性があることを忘れていることです。 

例：```
3 10 2
1 2 7
2 3 4
```位置`2`両方の範囲に属します。 その高さは両方の制限を満たす必要があるため、実質的な最大値は次のようになります。```
min(7, 4) = 4
```最適な高さは次のようになります。```
[7, 4, 4]
```制限の 1 つを無視すると、無効な回答が生成されます。 

最後の微妙な点は、一部のポジションはいかなる制限にも決して現れない可能性があるということです。 

例：```
3 10 1
2 2 3
```位置`1`そして位置`3`グローバル制限を除いて制限はありません`h = 10`、したがって、それらは高さにとどまる必要があります`10`。 

最適な高さは次のとおりです。```
[10, 3, 10]
```利益：```
100 + 9 + 100 = 209
```## アプローチ

 強引なアイデアは、考えられるすべての高さの割り当てを試して、最も有効な高さを維持することです。 各ポジションには最大で`h + 1`選択肢があるので、`(h + 1)^n`可能な構成。 

と`n = 50`そして`h = 50`、これはおおよそ次のとおりです。```
51^50
```これは天文学的規模であり、まったく不可能です。 

重要な観察は、すべての制限が個々のポジションの上限に直接変換されるということです。 

制限に次のような内容があるとします。```
l = 2, r = 5, x = 7
```その区間の最大高さは超えてはいけないので、`7`、からのすべての位置`2`を通して`5`個別に最大でも`7`。 

これは、それぞれの立場を独立して考えることができることを意味します。 どの位置でも高さに到達できると想定することから始めます`h`。 次に、各制限を処理して、カバーされたすべての位置の許容高さを次のように減らします。```
current_limit = min(current_limit, x)
```すべての制限が処理された後、各位置には有効な最大高さが設定されます。 

次に目的関数を考えてみましょう。 1 つのポジションによって寄与される利益は次のとおりです。```
a²
```これは厳密には次のように増加します`a`非負の高さの場合は増加します。 

位置が相互作用しなくなるため、各位置の最良の選択は単にその最大許容高さになります。 

全体の問題は、すべての位置で許容される最終的な最大高さを計算し、それらの二乗を合計することに帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((h+1)^n) | O(n) | 遅すぎる |
 | 最適 | O(nm) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を作成する`height`長さの`n`すべてのエントリを次のように初期化します`h`。 
2. 各制限の処理`(l, r, x)`。 
3. 区間内のすべての位置について`[l, r]`、現在の制限を次のように置き換えます。```
min(current_limit, x)
```これにより、そのポジションに影響を与えるすべての制限が累積されます。 
4. すべての制限が処理された後、`height`その位置の最大の法的高さを保存します。 
5. 以下を計算します。```
answer = Σ height[i]²
```6. 結果の合計を出力します。 

### なぜ効果があるのか

 範囲の制限により、その範囲内の家はこの範囲を超えてはなりません。`x`。 申請中`min(current_limit, x)`対象となるすべての位置にこの要件を正確に記録します。 

すべての制限が処理された後、ポジションに保存される値は、そのポジションをカバーする制限によって課される最小の上限になります。`h`何もカバーしない場合。 

すべての高さは負ではなく、利益は等しいため、利益関数は高さとともに増加します。`a²`。 家を高くしても利益は決して減りません。 したがって、どの位置でも、法定の最大高さが最適な選択となります。 これより小さいものを選択すると、利益が減少するだけであり、すべての制約がポジションごとの制限にすでにエンコードされているため、追加の制約を満たすことはできません。 

したがって、アルゴリズムは、利益を最大化する独自の構成を構築します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, h, m = map(int, input().split())

height = [h] * n

for _ in range(m):
    l, r, x = map(int, input().split())
    for i in range(l - 1, r):
        height[i] = min(height[i], x)

answer = sum(v * v for v in height)
print(answer)
```配列`height`すべての位置の現在の最大許容高さを保存します。 

最初はどの位置でも高さに到達できます`h`、したがって配列は次のように埋められます`h`。 

各制限はすぐに処理されます。 入力では 1 から始まるインデックスが使用されるのに対し、Python リストでは 0 から始まるインデックスが使用されるため、間隔`[l, r]`は次のようになります:```
range(l - 1, r)
```すべてのカバーされたポジションについて、これまでに確認された最小制限を維持します。 

すべての制限が適用されると、各位置にはすでに最適な高さが含まれています。 最後のループでは二乗和を計算します。 

繰り返し行われるため、重複する間隔については特別な処理は必要ありません。`min`操作ではすべての制限が自然に組み合わされます。 可能な最大の答えは次のとおりであるため、整数オーバーフローも無関係です。```
50 × 50² = 125000
```これは Python の整数に簡単に適合します。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    n, h, m = map(int, input().split())

    height = [h] * n

    for _ in range(m):
        l, r, x = map(int, input().split())
        for i in range(l - 1, r):
            height[i] = min(height[i], x)

    return str(sum(v * v for v in height))

# provided samples
assert run(
"""3 3 3
1 1 1
2 2 3
3 3 2
"""
) == "14", "sample 1"

assert run(
"""4 10 2
2 3 8
3 4 7
"""
) == "262", "sample 2"

# minimum size
assert run(
"""1 5 0
"""
) == "25", "single position"

# full-range restriction
assert run(
"""3 10 1
1 3 5
"""
) == "75", "all positions limited"

# overlapping restrictions
assert run(
"""3 10 2
1 2 7
2 3 4
"""
) == "81", "minimum of overlapping limits"

# unrestricted positions remain at h
assert run(
"""3 10 1
2 2 3
"""
) == "209", "positions outside intervals"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1 5 0`|`25`| 最小サイズのインスタンス |
 | フルレンジ制限 |`75`| 範囲制限はすべての位置に適用されます |
 | 重複する制限 |`81`| 該当するすべての制限の最小値が使用されます。 
| 単一の制限位置 |`209`| 覆われていない位置は高所に残ります`h`|

 ## 特殊なケース

 ### 重複する制限

 入力:```
3 10 2
1 2 7
2 3 4
```処理すると以下が得られます。```
[10,10,10]
→ [7,7,10]
→ [7,4,4]
```位置`2`両方の制限を受けて小さい値を維持します`4`。 最終的な利益は次のとおりです。```
49 + 16 + 16 = 81
```アルゴリズムはこれを繰り返すことで自動的に処理します。`min`操作。 

### 道路全体にわたる規制

 入力:```
3 10 1
1 3 5
```処理すると以下が得られます。```
[10,10,10]
→ [5,5,5]
```利益：```
25 + 25 + 25 = 75
```すべてのポジションは制限された間隔に属しているため、すべてのポジションには同じキャップが適用されます。 

### 無制限のポジション

 入力:```
3 10 1
2 2 3
```処理すると以下が得られます。```
[10,10,10]
→ [10,3,10]
```ポジション`1`そして`3`どの間隔にも出現しないため、元の制限が保持されます。`h = 10`。 

利益：```
100 + 9 + 100 = 209
```による初期化`h`制限の影響を受けていないポジションが自動的に可能な限り最大の法的高さを取得することを保証します。
