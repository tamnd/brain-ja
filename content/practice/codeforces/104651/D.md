 ## 解決策
 ## 問題の理解

 長さ n の整数シーケンスが与えられます。 そこから離散フーリエ変換を計算し、n 個の複素数値を生成します。 各周波数 t は、すべての配列要素の複素数和に対応し、各要素にそのインデックスと t に応じた単位複素回転が乗算されます。 

インデックス k という 1 つの位置を変更して、選択した任意の整数に置き換えることができます。 各係数はすべての配列要素の線形結合であるため、この 1 つの変更はすべてのフーリエ係数に同時に影響します。 

目標は、変換を再計算した後、すべてのフーリエ係数の最大の大きさができるだけ小さくなるように、位置 k で新しい値を選択することです。 

制約は十分小さいため、O(n²) 前処理アプローチが許容されます。 n は最大 2000 であるため、すべてのフーリエ係数を直接計算することが可能です。 より難しいのは、1 つの自由変数を最適化することです。 

最適な変更が元の値からかけ離れている場合、微妙なエッジ ケースが発生します。 単純なアプローチでは、小さな調整のみを試行するか、最適な値が元の f_k の近くにあると想定する可能性がありますが、最適な選択は、局所的な構造ではなく、すべての周波数にわたるグローバルなバランスに依存します。 

たとえば、元のシーケンスにすでに 1 つの支配的なフーリエ ピークがある場合、f_k を変更するとそのピークを「引き下げる」ことができますが、他のピークはわずかに上昇する可能性があります。 x を f_k の周囲の小さな近傍に制限すると、真の最適値を完全に逃す可能性があります。 

## アプローチ

 直接の解釈は簡単です。f_k の可能なすべての置換値を試し、フーリエ変換を再計算し、最良の答えを追跡します。 ただし、候補値には制限がないため、これは直ちに不可能です。 妥当な数値範囲に制限したとしても、依然として無限に多くの可能性が残されています。 

重要な観察は、フーリエ変換が入力シーケンス内で線形であるということです。 元の変換を F⁰_t で表す場合、f_k を x に置き換えると、t に応じて単位複素根を乗算した (x − f_k) を加算することによって各係数が変更されます。 これは、すべてのフーリエ係数が単一の実変数 x のアフィン関数になることを意味します。 

書き換えると、各係数は原点からの距離が x の凸関数となる平面上の点になります。 目的は、すべての t にわたるこれらの凸関数の最大値です。 凸関数の最大値は凸のままであるため、問題は、最終的な答えが整数で評価される、実数 x に対する 1 次元の凸関数を最小化することに帰着します。 

この構造により、実数の x に対する三項検索が可能になります。 各評価では、n 個の距離すべてを計算する必要があり、チェックあたりのコストは O(n) になります。 全体的な複雑さは O(n² 対数精度) となり、n が 2000 までであれば十分に高速です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | x に対するブルート フォース | 無限 / O(範囲 · n²) | O(n) | 不可能 |
 | 最適な三項探索 | O(n² log R) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 まず、元の配列の離散フーリエ変換を計算します。 これにより、すべての周波数 t のベースライン係数 F⁰_t が得られます。 

次に、インデックス k の変更が各係数にどのような影響を与えるかを分離します。 単位複素乗数 ω_t = e^{-2π i k t / n} を事前計算します。 f_k を値 x に置き換えると、新しい係数は F⁰_t + (x − f_k) · ω_t になります。 

ここで、方向 ω_t が実軸になるように各係数を回転することにより、この式を幾何学的に再解釈します。 これにより、各周波数が複素平面内の固定点に変換され、変数 x が実数軸に沿ってシフトします。 大きさは移動点xから平面内の固定点までの距離になります。

各 t に対して、関数 g_t(x) = |x + b_t| を定義します。ここで、b_t は、F⁰_t と ω_t から導出される事前計算された複素定数です。 目的は、max_t g_t(x) を最小化することです。 

次に、この最大値を最小にする実数値 x を検索します。 凸関数の最大値は凸であるため、実数 x に対して三分探索を適用します。 

各候補 x ですべての周波数を評価し、最大距離を計算します。 収束後、最終的な答えは整数の置換である必要があるため、見つかった実際の最適値の周囲で最適な整数値をチェックします。 

### なぜ効果があるのか

 各 g_t(x) は、平面内の固定点から線に沿って移動する点までのユークリッド距離であるため、x の凸関数です。 凸関数の最大値も凸であり、単一のグローバル最小値が保証されます。 これにより、三分探索が極小値にとらわれず、間隔を狭めても常に真の最適値が維持されることが保証されます。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def dft(f):
    n = len(f)
    res = [0j] * n
    for t in range(n):
        acc = 0j
        for s in range(n):
            angle = -2.0 * math.pi * s * t / n
            acc += f[s] * complex(math.cos(angle), math.sin(angle))
        res[t] = acc
    return res

def solve():
    n, k = map(int, input().split())
    f = list(map(int, input().split()))

    F = dft(f)

    base = f[k]

    # precompute w_t = exp(-i 2π k t / n)
    w = []
    for t in range(n):
        angle = -2.0 * math.pi * k * t / n
        w.append(complex(math.cos(angle), math.sin(angle)))

    # b_t = F_t - f_k * w_t
    b = [F[t] - base * w[t] for t in range(n)]

    def cost(x):
        x = float(x)
        best = 0.0
        for t in range(n):
            val = b[t] + x * w[t]
            best = max(best, abs(val))
        return best

    # ternary search on real x
    lo, hi = -1e5, 1e5
    for _ in range(80):
        m1 = (2 * lo + hi) / 3
        m2 = (lo + 2 * hi) / 3
        if cost(m1) < cost(m2):
            hi = m2
        else:
            lo = m1

    x0 = (lo + hi) / 2

    # check nearby integers
    best_ans = float('inf')
    for xi in range(int(x0) - 3, int(x0) + 4):
        best_ans = min(best_ans, cost(xi))

    print(best_ans)

if __name__ == "__main__":
    solve()
```解決策は、完全なフーリエ変換を直接計算することから始まりますが、これは制約の下で許容されます。 次に、事前に計算された回転係数を使用して、インデックス k の寄与を分離します。 

コスト関数は、特定の置換値のすべての周波数にわたる最大の大きさを評価します。 三分探索は、凸関数が最小値に達する区間を繰り返し縮小します。 浮動小数点演算では小さなドリフトが生じるため、最終ステップでは連続最適値付近の整数値をチェックして、整数制約が満たされていることを確認します。 

## 実用的な例

 単一の要素を変更するとスペクトル バランスが大きく変化する小さなシーケンスを考えてみましょう。 n = 3、k = 2、f = [1, 1, 0] と仮定します。 

まずフーリエ係数を計算します。 次に、f₂ の変更がすべての係数に同時にどのように影響するかを調べます。 

| ステップ | ×推測 | 影響を受ける F_t 構造 | 最大 |F_t| |

 |------|--------|---------------|----------|

 | 開始 | 0 | オリジナルのスペクトル | 大 |

 | ミッド1 | -2 | 減少した主周波数 | 小さい |

 | ミッド2 | 2 | 不均衡は他の場所に移動します。 大きい |

 三分探索では最大値が減少する方向が優先され、最終的には最良のトレードオフ付近に収束します。 

この例は、最適な変更が必ずしも元の値 0 に近いわけではないことを示しています。 1 つの周波数をローカルに調整するのではなく、すべての周波数のバランスをグローバルに調整するように選択されます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n² + n log R) | DFT のコストは O(n²)、各評価のコストは O(n)、三項検索では O(log R) の評価が使用されます。 
| スペース | O(n) | フーリエ係数と事前計算された回転係数を保存します。 

n ≤ 2000 の場合、DFT は約 400 万の演算に寄与し、三分探索ではさらに数十万の演算が追加され、制限内に問題なく収まります。

 ## 特殊なケース

 重要なエッジ ケースは、最適な変更が f_k の元の値から遠く離れている場合です。 実装が f_k に近い値のみを試行する場合、最適なキャンセルには支配的なフーリエ ピークを低減するために一方向への大きなシフトが必要な場合に、解決策を逃すことになります。 凸定式化では、これは探索間隔の原点から遠く離れたところにある最小値に対応します。 

もう 1 つのエッジ ケースは、複数の周波数が同等に支配的な場合です。 このような場合、コスト関数は鋭い最小値ではなく、平坦な底部領域を持ちます。 凸性により局所的なプラトーが全体的に最適であることが保証されるため、三分探索は引き続き正しく収束しますが、平坦な領域からのドリフトを避けるためには整数の丸めが不可欠になります。
