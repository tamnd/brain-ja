 ## 解決策
 ## 問題の理解

 正の整数のリストで T 素数を識別するように求められます。 T 素数は、正確に 3 つの異なる正の約数を持つ数値として定義されます。 約数について考えると、数値がちょうど 3 になる唯一の方法は、それが素数の 2 乗である場合です。 たとえば、4 は、約数が 1、2、4 であり、2 が素数であるため、T 素数です。 6 のような数には 4 つの約数 (1、2、3、6) があるため、T 素数ではありません。 

入力では、最大 100,000 の整数が指定され、その後に整数自体が続きます (最大 10^12 まで)。 入力サイズが大きいため、数値ごとに約数を 1 つずつ検査するソリューションは非常に遅くなります。 たとえば、√10^12 までのすべての数値を割り切れるかどうかをチェックするには、数値ごとにおよそ 100 万ステップが必要ですが、これは単一の数値については実行可能ですが、100,000 個の数値については実行できません。 したがって、クエリごとの作業を減らす、よりスマートなアプローチが必要です。 

エッジケースにも慎重に対処する必要があります。 数字 1 は約数が 1 つしかないため、T 素数になることはありません。 10^12 のような大きな平方は、平方根を求めるときに整数のオーバーフローや精度の低下を起こさずに処理する必要があります。 16 (4^2) など、完全平方であっても平方根が素数ではない数値も拒否する必要があります。 

## アプローチ

 ブルートフォース手法は簡単です。各数値について、その約数を数えます。 カウントがちょうど 3 の場合は、YES を出力します。 それ以外の場合は、NO を出力します。 約数を単純に数えるには、√x まで反復する必要があり、最悪の場合の複雑さは O(n√x) となり、最悪の場合、およそ 10^11 回の演算になります。 これでは問題の制約に対して遅すぎます。 

重要な観察は、数値が素数の完全二乗である場合にのみ、その数値にはちょうど 3 つの約数があるということです。 これにより、問題は 2 つのステップに短縮されます。数値が完全な平方であるかどうかと、その平方根が素数であるかどうかを判断します。 大量の入力を効率的に処理するには、エラトステネスのふるいを使用して 10^6 までのすべての素数を生成し (√10^12 = 10^6 であるため)、それらの平方をセットに保存します。 各入力数値について、それが T 素数のセットに含まれているかどうかを単純にチェックします。 これにより、クエリごとの作業が単純なセット検索に減り、平均で O(1) になります。

 ## アルゴリズムのチュートリアル

 1. エラトステネスのふるいを使用して、10^6 までのすべての素数を計算します。 T 素数は 10^6 より大きい平方根を持つことができないため、この範囲は十分です。 
2. T 素数を格納するために空のセットを初期化します。 ふるいによって生成された素数 p ごとに、p の 2 乗を計算し、セットに追加します。 これにより、最大 10^12 までのすべての可能な T 素数が事前計算されます。 
3. 数値の配列を読み取ります。 各数値 x について、事前に計算された T 素数のセットに x が含まれているかどうかを確認します。 
4. セット内に x が見つかった場合は、YES と出力します。 それ以外の場合は、NO を出力します。 

これが機能する理由は、セットには素数の 2 乗であるすべての数値が正確に含まれているためです。 すべての T 素数は、その平方根が素数であるため含まれており、セットに含まれていない数値は完全な平方根でないか、非素数平方根を持っています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def sieve(limit):
    is_prime = [True] * (limit + 1)
    is_prime[0] = is_prime[1] = False
    for i in range(2, int(limit ** 0.5) + 1):
        if is_prime[i]:
            for j in range(i*i, limit + 1, i):
                is_prime[j] = False
    primes = [i for i, val in enumerate(is_prime) if val]
    return primes

def main():
    n = int(input())
    numbers = list(map(int, input().split()))
    
    max_root = int(10**6) + 1
    primes = sieve(max_root)
    
    t_primes = set(p * p for p in primes)
    
    for x in numbers:
        if x in t_primes:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    main()
```sieve 関数は素数を効率的に生成し、割り算を繰り返しチェックする必要がなくなります。 T プライムをセットに保存すると、メンバーシップ チェックを一定時間行うことができます。これは 100,000 クエリにとって重要です。 コードは次を使用して入力を読み取ります。`sys.stdin.readline`Python での入力処理の遅さを回避するため。 整数乗算を使用すると、浮動小数点の不正確さを回避できます。

## 特殊なケース

 1 は素数ではないため、T 素数ではないため、アルゴリズムは 1 を正しく処理します。 浮動小数点の平方根を避け、整数の乗算に依存しているため、10^12 のような大きな数値が正確に処理されます。 16、36、100 など、完全平方であっても根が合成である数値は、平方根が事前に計算された素数セットに対してチェックされるため、拒否されます。 セット ルックアップでは、数値の上限が 100,000 個であっても、一定時間の検証が保証されます。
