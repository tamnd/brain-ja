 ## 解決策
 ## 問題の理解

 この問題では、ディマが 2 つのスコアを覚えているサッカーの試合のシナリオが与えられています。1 つは気が散る直前、もう 1 つは戻ったときです。 各スコアは 2 つのチームのゴールで構成されます。 ゲームは両チームとも 1 ゴールずつ進みます。 我々は、ディマの不在中に両チームのスコアが決して同じではなかった可能性があるかどうかを判断するよう求められている。 これが可能であれば出力は「YES」、それ以外の場合は「NO」になります。 

スコアは最大の整数です。$10^9$、テスト ケースの数は最大です。$10^4$。 これにより、得点されたすべてのゴールをシミュレートするようなアプローチは除外されます。これは、何十億ものステップを反復する必要がある可能性があるためです。 代わりに、スコアの可能なシーケンスについて、明示的に生成せずに数学的に推論する必要があります。 

明らかではないエッジケースには、一方のチームがはるかに先を行っていて得点を続けているのに、もう一方のチームがまったく得点していない状況が含まれます。 たとえば、初期スコアが$0:2$そして最終スコアは$5:2$, 最初のチームは、スコアが等しくなくても 5 回連続でゴールを決める可能性があります。 すべてのゴール シーケンスをシミュレートする不用意なアプローチは、等価性が発生する必要があると誤って仮定する可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、最初のスコアから 2 番目のスコアまで、考えられるすべてのスコアシーケンスをシミュレートしようとします。 これは理論的には正しいです。なぜなら、どちらかのチームの 1 ゴール増加のシーケンスにはすべての可能性が含まれるからです。 ただし、得点数が非常に多くなる可能性があるため、これは完全に非現実的です。$10^9$、操作カウントが受け入れられなくなります。 

問題を単純化する重要な観察は、スコアが等しくなる唯一の方法は、最初のチーム間の差を少しずつ越える場合であるということです。 定義する$d_1 = x_1 - y_1$そして$d_2 = x_2 - y_2$。 もし$d_1$そして$d_2$同じ符号 (両方が正または両方が負) であるか、それらのいずれかが 0 である場合、スコアが等しくなくても 2 番目のスコアに到達する可能性があります。 符号が異なる場合、ある時点で平等を避けることはできません。 これにより、問題は最初と最後の違いの単純なチェックに減ります。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、Dima が気を散らした前後のスコアを読み取ります。$(x_1, y_1)$そして$(x_2, y_2)$。 
3. 差を計算する$d_1 = x_1 - y_1$そして$d_2 = x_2 - y_2$。 
4. 次のことを確認します。$d_1 \cdot d_2 > 0$または$d_1 = d_2 = 0$。 これにより、スコアが決してゼロを超えないことが保証され、平等は決して起こらないことを意味します。 
5. 条件が真の場合、「YES」を出力します。 それ以外の場合は、「NO」を出力します。 

効果がある理由: 製品$d_1 \cdot d_2$正であることは、両方の差が同じ符号を持つことを保証します。 ゴールは一方のチームのスコアのみを増加させるため、差は単調に変化し、ゼロを超えることはありません。 これにより、インターバル中にチームが同じスコアになることがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x1, y1 = map(int, input().split())
        x2, y2 = map(int, input().split())
        d1 = x1 - y1
        d2 = x2 - y2
        if d1 * d2 > 0:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```このソリューションは、高速 I/O を使用して各テスト ケースを効率的に読み取ります。 差の計算と符号の確認は一定時間内に行われます。 このロジックにより、実行不可能である得点シーケンスのシミュレーションが回避されます。

 ## 特殊なケース

 一方のチームが多くのゴールを決めているのに、もう一方のチームはゴールを決めていない場合を考えてみましょう。 たとえば、から始めて、$0:1$そして終わる$0:5$、その差は常にマイナスであり、同点は発生しません。 アルゴリズムが計算するのは、$d_1 = -1$、$d_2 = -5$、積は正であり、正しく「YES」を出力します。 

差がゼロを超えた場合、次のようになります。$1:2$に$3:2$、アルゴリズムは次のように計算します$d_1 = -1$、$d_2 = 1$、積は負であり、正しく「NO」を出力します。 これにより、すべてのスコアをシミュレートすることなく、微妙な境界条件の正確性が確認されます。
