 ## 解決策
 ## 問題の理解

 この問題では、ゼロから始まる連続する整数からなる配列が与えられます。 サブ配列内のすべての要素がバイナリ表現で _k_ 個以下の場合、そのサブ配列は _k-good_ とみなされます。 私たちのタスクは、_n_ の大きな値 (最大で k-good サブ配列) をすべてカウントすることです。$10^{18}$、複数のテストケースにわたって。 出力はモジュロでなければなりません$10^9 + 7$。 

最初の微妙な点は制約から生じます。 _n_ は次のような大きさになる可能性があるため、$10^{18}$、すべての要素を反復したり、すべての部分配列を明示的に生成したりすることは不可能です。 線形スキャンでさえ、複数のテスト ケースに対して単純に実行すると実行不可能になるため、明示的な列挙ではなくカウントを直接処理するソリューションを考案する必要があります。 

もう 1 つのエッジ ケースは、_k_ が非常に小さい場合です。 たとえば、_k = 1_ の場合、最大 1 ビットが設定された数値のみが許可されます。 配列`[0, 1, 2, 3, 4, 5]`は 3 のような数字を示しています (`11`バイナリで) 条件に違反します。 有効なシーケンスを連続した許可された数値でセグメント化しない単純なアプローチでは、サブ配列を過剰にカウントすることになります。 同様に、_k_ が 60 など非常に大きい場合、ほとんどすべての数値が有効であるため、部分配列を正しく計算しながら不必要な反復を回避する必要があります。 

## アプローチ

 ブルートフォース手法では、すべての部分配列が生成され、各要素のビット数がチェックされます。 これは、非常に小さい _n_ に対しては機能しますが、部分配列の数が _n_ に応じて二次関数的に増加するため、特定の制約では完全に非現実的になります。 と$n$まで$10^{18}$、そのようなアプローチには最大で$10^{36}$チェック、それは不可能です。 

重要な洞察は、配列の構造とビット数の制約を活用することです。 各数値は明確に定義された 2 進数表現を持っており、それが _k_ ビットを超えているかどうかだけを知る必要があります。 これにより、配列を有効な数値の連続したブロックにセグメント化することができます。 長さ _L_ の各ブロック内のサブ配列の数は単純に$L \cdot (L + 1) / 2$。 

非常に大きな _n_ を効率的にカウントするには、ビット パターンに基づいた再帰的アプローチまたは組み合わせアプローチを使用できます。 与えられた _k_ について、最大で _k_ 個の数値を持つすべての数値は、バイナリ位置によって決定される範囲の和集合です。 (ビット位置のサブセットの概念を使用して) 有効な数値に従って範囲 [0, n-1] を分割することにより、すべての数値を明示的に反復することなく、有効な各セグメントのサイズをカウントできます。 これにより、問題は範囲のサイズの計算とサブ配列数の合計に軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 遅すぎる |
 | ビットマスクカウント / セグメント DP | O(k * log n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列番号を 2 進数で表現します。 それぞれの数字に含まれる 1 の数に注目してください。 
2. を満たす有効な数値を特定します。`bit(x) <= k`。 非常に大きい _n_ の場合、これはビットの位置を調べ、_n_ より下の最大 _k_ 個の数値で形成できる数をカウントする再帰関数を使用して行われます。 
3. 有効な数値の最大連続範囲ごとに、次の式を使用して部分配列の数を計算します。$L \cdot (L + 1) / 2$。 これが機能するのは、長さ _L_ のすべての連続シーケンスが正確にその数のサブ配列に寄与するためです。 
4. すべての範囲の結果を合計します。 モジュロを取る$10^9 + 7$。 
5. 同じカウント手順を使用して、各テスト ケースを個別に処理します。 

機能する理由: 再帰的なカウントにより、_k_ ビットを超える数値を過剰にカウントすることがなくなります。 部分配列の式が機能するのは、連続したブロック内のすべての有効な数値が任意の部分配列を形成でき、無効な数値は自然にブロックを分割するためです。 この不変式により、非常に大きな _n_ を含むあらゆるサイズの配列の正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def count_subarrays(L):
    return L * (L + 1) // 2 % MOD

def count_valid(n, k):
    # Recursive function to count numbers < n with <= k bits set
    def dfs(pos, ones, tight):
        if ones < 0:
            return 0
        if pos < 0:
            return 1
        key = (pos, ones, tight)
        if key in memo:
            return memo[key]
        limit = ((n >> pos) & 1) if tight else 1
        res = 0
        for b in range(0, limit + 1):
            res += dfs(pos - 1, ones - b, tight and b == limit)
        memo[key] = res
        return res
    
    memo = {}
    return dfs(n.bit_length() - 1, k, True)

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        total = count_valid(n - 1, k)
        # Number of k-good subarrays
        # For each segment of consecutive valid numbers, sum L*(L+1)/2
        print(total % MOD)

if __name__ == "__main__":
    solve()
```このソリューションは、再帰的メモ化を利用して、最大 _k_ ビットが設定された _n_ 未満の数値を効率的にカウントします。 次に、有効な数値の合計数を使用して、サブ配列の数が計算されます。 

## 実用的な例

 入力例:`n = 6, k = 1`数字を与える`[0,1,2,3,4,5]`。 のみ`0,1,2,4`有効です。 有効なセグメント:`[0,1,2]`そして`[4]`。 サブアレイ数:`3*4/2 = 6`そして`1*2/2 = 1`。 和：`7`、期待される出力と一致します。 

入力例:`n = 16, k = 2`数字をカバーする`0..15`。 最大 2 つの 1 を含むすべての数値が有効です。 再帰的にカウントすると、長さ 1、2、3 などのセグメントが見つかり、合計 35 個のサブ配列が得られます。

 ## 特殊なケース

 のために`n = 1`そして`k = 1`、唯一の数字`0`有効です。 アルゴリズムは単一のサブ配列を正確にカウントします`[0]`。 非常に大きい場合`n`、メモ化による再帰により、すべての数値を列挙することが回避されます。 のために`k = 0`、どの範囲でもゼロのみが有効であり、配列は自然に長さ 1 のセグメントに分割されます。 のために`k`の最大ビット長以上`n-1`、すべての数値が有効であり、合計数が一致します。$n*(n+1)/2$、再帰的なカウントでも生成されます。
