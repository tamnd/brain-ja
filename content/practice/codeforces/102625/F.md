 ## アプローチ

 直接的な解決策は、各ショップ間隔のすべての数値を反復処理し、すべての桁が許可されたセットに属しているかどうかを確認し、桁の合計を計算し、一部の桁が平均条件を満たすかどうかをテストします。 これは定義に正確に従っているため、正しいです。 ただし、1 つの間隔には最大 10 億の数値を含めることができます。`100000`最悪の場合に周辺に必要となる店`10^14`制限をはるかに超えています。 

便利な構造は、すべての数値が最大 10 桁まで十分に小さいということです。 数値を列挙する代わりに、桁ごとに数えます。 Digit DP を使用すると、最終条件に影響する情報 (現在の桁の合計と有効な平均桁がすでに出現しているかどうか) のみを保持しながら、すべての数値を制限まで構築できます。 

固定長の場合、条件は最終的な合計のみに依存します。 数値を構築した後、その数値の 1 つが次の条件を満たすかどうかを確認します。`length * digit == sum`。 長さが最大でも 10 であるため、可能な和は小さく、状態空間は小さくなります。 

あらゆる長さの有効な数値の数を事前計算し、クエリ境界と等しい長さに対してのみ数字 DP を使用します。 各ショップの答えは次のようになります。`countPerfect(R) - countPerfect(L - 1)`これにより、すべてのショップが効率的に処理できるようになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(合計範囲サイズ × 桁数) | お(1) | 遅すぎる |
 | 最適 | O(q × 桁数 × 合計 × 状態) | O(桁 × 合計 × 状態) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 許可されている 3 つの数字から重複した値を削除し、それらを数値に含めることができる唯一の数字として保存します。 このような数字は決してパーフェクト ローズにはなり得ないため、DP は他の数字を決して生成すべきではありません。 
2. 以下からすべての長さに対する有効な数値の数を事前計算します。`2`に`10`。 長さを生成する際、表示された桁の合計と桁のセットを保持します。 出現する数字を保存する理由は、完全な数字が構築された後、それらの数字のいずれかが満たされるかどうかを知る必要があるためです。`length * digit == sum`。 
3.実装する`count(x)`を超えないパーフェクトローズの数を返します。`x`。 の長さよりも短い長さについて、事前に計算されたすべてのカウントを加算します。`x`。 
4. 同じ長さの場合`x`、最上位桁から桁 DP を実行します。 状態には、現在位置、累積合計、使用されている数字のマスク、およびプレフィックスが既に以下より小さいかどうかが含まれます。`x`。 
5. 最後の数字を選択した後、その数字の長さが少なくとも 2 であり、マスクに数字が含まれている場合にのみ、数字を受け入れます。`d`と`length * d == sum`。 
6. 店舗間隔ごと`[L, R]`、計算する`count(R) - count(L - 1)`最大値のインデックスを保持します。 

機能する理由: DP は通常の 10 進表現と同じ桁順序に従うため、すべての数値は DP という数字によって 1 回だけ表現されます。 今後の選択は現在の合計、すでに表示されている桁数、および上限制限にのみ依存するため、保存された情報で十分です。 最終的に、受け入れテストはまさにパーフェクト ローズ条件を数学的に再定式化したものであるため、カウントされたすべての数値は有効であり、すべての有効な数値がカウントされます。 

## Python ソリューション```python
import sys
from functools import lru_cache

input = sys.stdin.readline

a, b, c, q = map(int, input().split())
digits = sorted(set([a, b, c]))

pre = [0] * 11

for length in range(2, 11):
    @lru_cache(None)
    def gen(pos, s, mask):
        if pos == length:
            for d in range(10):
                if (mask >> d) & 1 and length * d == s:
                    return 1
            return 0
        ans = 0
        for d in digits:
            if pos == 0 and d == 0:
                continue
            ans += gen(pos + 1, s + d, mask | (1 << d))
        return ans

    pre[length] = gen(0, 0, 0)

def count_le(x):
    if x <= 0:
        return 0

    s = str(x)
    n = len(s)
    ans = sum(pre[2:n])

    @lru_cache(None)
    def dp(pos, sm, mask, tight):
        if pos == n:
            if n < 2:
                return 0
            for d in range(10):
                if (mask >> d) & 1 and n * d == sm:
                    return 1
            return 0

        limit = int(s[pos]) if tight else 9
        res = 0

        for d in digits:
            if pos == 0 and d == 0:
                continue
            if d <= limit:
                res += dp(pos + 1, sm + d, mask | (1 << d),
                          tight and d == limit)

        return res

    ans += dp(0, 0, 0, True)
    return ans

best_shop = 1
best_value = -1

for i in range(1, q + 1):
    l, r = map(int, input().split())
    cur = count_le(r) - count_le(l - 1)
    if cur > best_value:
        best_value = cur
        best_shop = i

print(best_shop)
```前処理部分は正確な長さの回答を構築します。 先頭のゼロが禁止されているため、最初の桁から開始され、再帰では桁の合計と出現した桁のセットの両方が記録されます。 

の`count_le`関数はまず、事前計算されたテーブルを使用して短い長さを処理します。 残りの DP は、境界と同じ桁数の数値のみを処理します。 の`tight`フラグは、制限を超えるプレフィックスの構築を防ぎます。 

最終状態は方程式をチェックします`length * digit == sum`。 これにより、浮動小数点演算が回避され、平均条件から丸めの問題が除去されます。 

Python の整数はオーバーフローしませんが、最大長はわずか 10 で、最大合計は 90 であるため、実装では状態が小さく保たれます。 バインドされた数字は呼び出しごとに変わるため、キャッシュはバインドごとに再作成されます。

 ## 特殊なケース

 1 桁の場合、DP は長さ 1 の最終状態に到達し、すぐにそれを拒否します。 許可される数字の場合`1 2 3`と間隔`[1,9]`、1 桁もパーフェクト ローズではないため、返されるカウントはゼロです。 

先行ゼロの場合、最初の遷移ではゼロの選択が禁止されます。 許可された数字を使用して`0 1 2`、番号`12`生成されますが、`012`10 進表現規則に一致するため、考慮されることはありません。 

繰り返される数字の場合、マスクは、出現回数ではなく、どの数字値が出現したかを保存します。 数字付き`5 5 5`、次のような数字`55`そして`555`出現する数字が式を満たすため受け入れられますが、1 桁の場合は`5`長さが足りないため拒否されます。
