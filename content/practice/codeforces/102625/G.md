 ## 解決策
 # 問題の理解

 この問題は、通路でつながった秘密オフィスのツリーを記述しています。 各通路にはセキュリティレベルがあります。 考えられるすべての会議場所に対して、他のすべてのオフィスがそのオフィスまでの固有の経路に沿って担当者を派遣します。 復路では、担当者はそのパス上で最大のセキュリティ レベルを持つすべての通路に情報を隠します。 

タスクは、任意のパッセージに配置された隠された情報コピーの最大数を見つけて、その最大数に達するすべてのパッセージをリストすることです。 入力には、オフィスの数、その後に通路、そのエンドポイント、およびセキュリティ レベルが含まれます。 出力には、コピーの最大数と、そのカウントを持つすべてのパッセージのインデックスが含まれます。 元の問題の制約には次のものがあります。$2 \cdot 10^5$したがって、オフィスのすべてのペアのパスを検査するアプローチは不可能です。 

直接シミュレーションでは、順序付けされたすべてのオフィスのペアが考慮され、おおよその結果が得られます。$n^2$パス。 と$n=200000$、このあたりです$4 \cdot 10^{10}$1 秒のソリューションで処理できる範囲をはるかに超えています。 個々のパスを調べるのではなく、ツリー構造をグローバルに処理する必要があります。 

主なエッジ ケースは、同じ最大セキュリティ レベルや、パス上の唯一の最大セキュリティ レベルではない通路から発生します。 たとえば、次のことを考えてみましょう。```
3
1 2 5
2 3 5
```正しい出力は次のとおりです。```
4 2
1 2
```不注意な解決策では、オフィス 1 からオフィス 3 へのパス上の最大通過を 1 つだけカウントする可能性がありますが、両方の通過は同じ最大レベルを持ち、両方ともコピーを受け取ります。 

もう 1 つの注意が必要なケースは、セキュリティの高い通路が、セキュリティの低い通路が情報を受信できないようにブロックする場合です。 例えば：```
3
1 2 10
2 3 1
```最初のパッセージは 4 コピーを受け取り、2 番目のパッセージは 2 コピーを受け取ります。 エッジがそれらのパス上で最大であるかどうかを確認せずに、エッジを含むパスの数だけをカウントする解決策では、間違った答えが得られます。 

# アプローチ

 ブルートフォースの解決策は簡単です。 すべての会議室に対して、トラバースを実行して他のすべてのオフィスからのパスを検索し、各パスの最大セキュリティ値を見つけて、その値を持つすべての通路の数を増やします。 定義に直接従っているため、これは正しいです。 ただし、オフィスペア数は$n(n-1)$、各パスの処理には時間がかかります$O(n)$、 その結果$O(n^3)$最悪の場合は動作します。 すべてのペアの距離を保存するだけでも、すでにコストがかかりすぎます。 

重要な観察は、セキュリティ レベルの通路が存在することです。$w$すべてのエッジが最大でもセキュリティ レベルを持つパスでのみ問題となります$w$。 セキュリティ レベルが 2 を超えるすべての通路を削除すると、$w$次に、残りの各コンポーネント内で、すべてのパスは最大レベルのエッジのみを使用します。$w$。 レベルの経過$w$は、このコンポーネント内の通路によって区切られたオフィスの順序付けられたペアに対して正確に選択されます。 

これは、セキュリティ レベルを上げてパッセージを処理することを示唆しています。 同じレベルのパッセージのグループを処理する前に、素セット結合構造は、より小さなレベルを使用して接続されたコンポーネントを表します。 現在のレベルでは、これらの通路によって接続された小さなコンポーネントが一時的なツリーを形成します。 仮設ツリーをサイズごとに分割した通路用$a$そして$b$、それを横切る順序ペアの数は$2ab$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^3)$|$O(n)$| 遅すぎる |
 | 最適 |$O(n \log n)$|$O(n)$| 承認済み |

 # アルゴリズムのチュートリアル

 1. すべてのパッセージをセキュリティ レベルに従って並べ替えます。 同じレベルの通路はすべて同じパス上の最大エッジになる可能性があるため、同じセキュリティ レベルをまとめて処理します。 
2. セキュリティ レベルが低いパッセージのみを含む DSU を維持します。 各 DSU コンポーネントは、現在のレベルで最大のエッジとなる可能性のある通路を使用せずに接続されたオフィスのグループを表します。 
3. 同じセキュリティ レベルを持つパッセージのグループごとに、各 DSU コンポーネントを単一のノードにまとめます。 電流通路は、これらの収縮したノードの間にフォレストを形成します。 
4. 各一時ツリーを横断します。 現在の通路ごとに、その通路の両側にある元のオフィスの合計数を計算します。 両側に次の内容が含まれている場合$a$そして$b$オフィス、追加$2ab$そのパッセージのカウントに。 
5. このセキュリティ レベルのすべてのカウントが計算されたら、このレベルのすべてのパッセージを DSU にマージします。 これらは、より大きなセキュリティ レベルを処理するときに使用可能になります。 

機能する理由: レベルのあるパッセージの場合$w$、オフィスのペアは、それらの間のパス全体に より大きなエッジが含まれていないときに正確にそれに寄与します。$w$そして通路はその道沿いにあります。 レベル処理中$w$、DSU コンポーネントと一時フォレストは、まさにそれらのパスを表します。 通路を切断すると、有効なパスがサイズの 2 つのグループに分割されます。$a$そして$b$、そして各側からの 1 つのエンドポイントの順序付けられた選択は 1 回ずつ寄与します。 したがって$2ab$そのパッセージのすべての情報コピーを正確にカウントします。 

# Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    edges = []
    for i in range(1, n):
        u, v, w = map(int, input().split())
        edges.append((w, u - 1, v - 1, i))

    parent = list(range(n))
    size = [1] * n

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(a, b):
        a = find(a)
        b = find(b)
        if a == b:
            return
        if size[a] < size[b]:
            a, b = b, a
        parent[b] = a
        size[a] += size[b]

    edges.sort()
    ans = [0] * n
    i = 0

    while i < n - 1:
        j = i
        while j < n - 1 and edges[j][0] == edges[i][0]:
            j += 1

        graph = {}
        nodes = set()

        for _, u, v, idx in edges[i:j]:
            ru = find(u)
            rv = find(v)
            graph.setdefault(ru, []).append((rv, idx))
            graph.setdefault(rv, []).append((ru, idx))
            nodes.add(ru)
            nodes.add(rv)

        visited = set()

        for start in nodes:
            if start in visited:
                continue

            order = []
            par = {start: -1}
            pedge = {}

            stack = [start]
            visited.add(start)

            while stack:
                x = stack.pop()
                order.append(x)
                for y, eid in graph.get(x, []):
                    if y != par[x]:
                        par[y] = x
                        pedge[y] = eid
                        visited.add(y)
                        stack.append(y)

            total = 0
            for x in order:
                total += size[find(x)]

            sub = {}
            for x in reversed(order):
                cur = size[find(x)]
                for y, eid in graph.get(x, []):
                    if par.get(y) == x:
                        cur += sub[y]
                sub[x] = cur
                if par[x] != -1:
                    other = total - cur
                    ans[pedge[x]] += 2 * cur * other

        for _, u, v, _ in edges[i:j]:
            union(u, v)

        i = j

    best = max(ans[1:])
    res = [str(i) for i in range(1, n) if ans[i] == best]

    print(best, len(res))
    print(" ".join(res))

if __name__ == "__main__":
    solve()
```DSU 部分は、セキュリティ レベルを高めるという考え方に従っています。 の`find`この操作により、現在のレベルがマージされる前に、現在の縮小されたコンポーネントが得られます。 

一時グラフは、一度に 1 つのセキュリティ レベルに対してのみ再構築されます。 その頂点は DSU コンポーネントであり、個々のオフィスではありません。 走査により、この一時フォレスト内のサブツリーのサイズが計算されます。 一時的なエッジが次のサイズのサブツリーを分離する場合`cur`残ったものから`total - cur`、有効な順序ペアの数は正確に`2 * cur * (total - cur)`。 

マージステップはカウント後に行われます。 この順序付けは不可欠です。 現在のレベルのパッセージがカウント前にマージされた場合、それらはすでに使用可能な下位レベルの接続として誤って表示されます。 

# 実用的な例

 最初のサンプルの場合:```
3
2 1 3
3 1 1
```処理は次のとおりです。 

| 通路 | 現在のコンポーネント | サイドサイズ | 貢献 |
 | --- | --- | --- | --- |
 | 1 | {1}、{2}、{3} | 2 と 1 | 4 |
 | 2 | {1,2}、{3} | 1 と 2 | 2 |

 最大寄与度は 4 であるため、パッセージ 1 が選択されます。 

2 番目のサンプルの場合:```
5
2 1 3
4 3 1
5 4 1
2 3 1
```セキュリティ レベル 1 のパッセージ用に作成された一時ツリーは次のものを生成します。 

| 通路 | サイドサイズ | 貢献 |
 | --- | --- | --- |
 | 2 | 2 と 3 | 12 |
 | 3 | 1 と 4 | 8 |
 | 4 | 2 と 3 | 12 |

 より高いレベルのパッセージは個別に処理され、別のパッセージと同じ最大値に達し、複数の回答が生成されます。

 # エッジケース

 最大レベルが等しい場合、アルゴリズムは現在のレベルのすべてのパッセージをまとめて処理します。 入力で```
3
1 2 5
2 3 5
```両方の通路は同じ一時ツリー内にあります。 各カットにはサイド サイズ 1 と 2 があり、それぞれ 4 つのコピーが与えられるため、両方が返されます。 

非常に大きなセキュリティ値を持つ通路の場合、その下の小さな通路は、大きな通路を横切るパスから情報を受け取ることができません。 で```
3
1 2 10
2 3 1
```最初のレベルは単独で処理されます。 一時コンポーネントにはサイズ 1 と 2 の 2 つの側面があり、4 が与えられます。2 番目のパッセージは後で処理され、レベル 10 のパッセージを最大として含まないペアのみを受け取り、2 が与えられます。DSU マージの順序では、この区別が保持されます。
