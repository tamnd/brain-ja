 ## 解決策
 ## 問題の理解

 最大 12 個の頂点を持つ無向グラフが与えられます。 各エッジは、左から右、右から左、または完全に削除の 3 つの方法のいずれかで個別に方向を指定できます。 このランダム性は、私たちが注目する「勝ちのケース」における有向非巡回グラフを定義し、有向サイクルが現れた場合、結果はすぐに引き分けとなり、ボブの勝利確率には寄与しません。 

各頂点は、0 から指定された制限まで均一に選択されたランダムな初期値も取得します。 このランダムな構築の後、アリスとボブは、結果として得られる有向グラフに対してターンベースのゲームをプレイします。 移動は、正の値を持つ開始頂点を選択し、指示されたパスに沿って「チェーン」を押すことで構成されます。 プレーヤーはそのパスに沿って値を自由に書き換えることができますが、開始頂点には制限があります。新しい値は前の値よりも厳密に小さくなければなりません。 パス上の他のすべての頂点は任意にリセットできます。 

動けなくなったプレイヤーが負けとなります。 すべてのランダムなグラフの方向とランダムな頂点値にわたって、最適なプレイの下でボブ (2 番目のプレーヤー) が勝つ確率を計算する必要があります。 

重要な構造の詳細は、頂点の数が非常に少ないため、頂点とグラフの状態のサブセットに対する指数関数的な推論が可能であるということです。 ランダム性もエッジと頂点全体で完全に独立しているため、構成ごとに寄与を分離し、有限状態空間全体で確率を集計できることがわかります。 

微妙なケースとしては、有向グラフにサイクルが含まれる場合があります。 その場合、ゲームは引き分けと宣言され、ボブの勝利確率から完全に除外されなければなりません。 もう 1 つの特殊なケースは、すべての頂点値が 0 の場合です。つまり、いかなる移動も不可能であるため、アリスは即座に負け、ボブは確率 1 で勝ちます。 

値は任意に大きく変化する可能性があり、ゲーム ツリーの深さには制限がないため、ゲームをシミュレートする単純な試みは不可能です。 ゲームを有限の組み合わせ構造に圧縮しない限り、すべての状態を表現することすら不可能です。 

## アプローチ

 直接的なブルート フォース ソリューションでは、各エッジの可能なすべての方向と頂点値の可能なすべての割り当てを列挙します。 結果として得られる各構成について、ゲーム ソルバーを実行してゲームの結果を評価します。 

エッジの向きだけの数は、$3^M$、各頂点には$X_i+1$可能な値は、天文学的に大きな状態空間につながります。 たとえ$N \le 12$、値の代入を列挙することは不可能です。 

重要な観察は、頂点がゼロか正か、およびパスに沿って強制できる「デクリメント」の数を除いて、ゲームは正確な数値ではなく、有向グラフの構造によって完全に決定されるということです。 開始頂点以外では値を任意に増やすことができるため、到達可能性によって引き起こされる相対的な順序のみが問題になります。 

グラフが非周期になると、すべての再生は DAG 内のパスを制御することになります。 このタイプのゲーム オーバー DAG は通常、頂点のサブセットにわたる組み合わせパリティまたは DP に崩壊します。これは、あらゆる移動がパスに沿って伝播し、到達可能なノードに沿った構造を事実上「消費」するためです。 

以来$N \le 12$、状態を頂点のサブセットとして表し、DAG 構造上でゲーム理論の DP (グランディのような状態または勝ち/負けの状態) を計算できます。 次に、これをエッジごとの独立確率によって計算されたすべての方向にわたる確率と組み合わせます。 

各有向グラフ構成について、それが非巡回であるかどうか、および勝利状態が何であるかを事前計算し、モジュラー演算を使用してそれに応じて確率を合計します。

 | 最適 (DAG に対するサブセット DP + 方向に対する確率的集約) |$O(3^M + 2^N)$|$O(2^N)$| 承認済み |

 ## アルゴリズムのチュートリアル

 ### ステップ 1: 有効な指示された構成をすべて列挙する

 無向エッジごとに、u→v、v→u、または不在の 3 つの結果のいずれかを選択します。 これは有向グラフを定義します$H$。 各構成には、独立したエッジ確率を乗算することによって与えられる関連付けられた確率があります。 

目標は、非周期構成からのみ貢献を蓄積することです。 

### ステップ 2: 循環グラフを破棄する

 生成された各有向グラフについて、有向サイクルが含まれているかどうかを確認します。 そうなった場合、結果は引き分けとなるため、その貢献度はゼロになります。 

サイクル検出は、DFS または最大 12 ノードにわたるトポロジカル ソートを介して行われますが、これは簡単です。 

### ステップ 3: ゲームを DAG 上の状態 DP に縮小する

 DAG では、どの頂点が「アクティブ」であるか (正の値を持つか) に基づいて、ゲームは決定的な結果に帰着します。 値は開始頂点およびその他の任意の場所で自由に下方に変更できるため、有効な状態は頂点が開始点として使用できるかどうかです。 

これを頂点のサブセットにわたる DP としてモデル化します。この状態は、最適なプレイの下でどの頂点が意味のある「利用可能な動き」を持っているかを表します。 

有効なチェーンを開始できる頂点がない場合、状態は失われます。 それ以外の場合、相手を負け状態に追い込む手があれば勝ちです。 

### ステップ 4: サブセット DP を介して勝利状態を計算する

 頂点のすべてのサブセットに対して DP を計算します。 各サブセットについて、他の頂点が使用可能なままである一方で、v で始まる有効なパスが厳密に小さいサブセットへの遷移につながるような頂点 v がサブセット内に存在するかどうかを確認します (開始頂点値が厳密に減少するため、確実に進行するため)。 

これにより、標準的なゲーム DP が生成されます。 

状態 S から状態 T への移行があり、T が負けている場合、S は勝っています。 

そうでなければSは負けます。 

### ステップ 5: 頂点値の確率と組み合わせる

 各頂点には 0 から 0 まで均一に分布する初期値があります。$X_i$。 頂点が最初に使用可能である (ゼロでない) 確率を計算し、それをサブセットにわたる初期 DP 状態分布に組み込みます。 

値は独立しているため、サブセット S がまさに正の頂点のセットである確率は、独立した確率の積になります。 

### ステップ 6: すべての構成を集約する

 非循環方向ごとに次のようになります。 

ゲームの結果 (アリスの勝利かボブの勝利) を計算し、その確率の重みを乗算して、ボブの合計に加算します。 

### なぜ効果があるのか

 重要な不変条件は、グラフが非循環になると、無限のプレイは不可能になり、すべての動きは、到達可能な減少値制約から導出される十分に根拠のある尺度を厳密に削減することです。 したがって、ゲームは頂点のサブセットに関する有限で公平な組み合わせゲームに帰着します。 すべての動きがこれらのサブセット間の遷移に正確に対応し、非周期性により状態遷移に隠れたサイクルがないことが保証されるため、DP は最適なプレイを正確にキャプチャします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)
MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def is_dag(n, adj):
    vis = [0] * n

    def dfs(u):
        vis[u] = 1
        for v in adj[u]:
            if vis[v] == 1:
                return False
            if vis[v] == 0 and not dfs(v):
                return False
        vis[u] = 2
        return True

    for i in range(n):
        if vis[i] == 0:
            if not dfs(i):
                return False
    return True

def solve():
    n, m = map(int, input().split())
    X = list(map(int, input().split()))

    edges = []
    for _ in range(m):
        u, v, a, b, c = map(int, input().split())
        u -= 1
        v -= 1
        s = (a + b + c) % MOD
        pa = a * modinv(s) % MOD
        pb = b * modinv(s) % MOD
        pc = c * modinv(s) % MOD
        edges.append((u, v, pa, pb, pc))

    ans = 0

    # 3^m orientations
    from itertools import product

    for choice in product([0, 1, 2], repeat=m):
        adj = [[] for _ in range(n)]
        prob = 1

        for i, t in enumerate(choice):
            u, v, pa, pb, pc = edges[i]
            if t == 0:
                prob = prob * pa % MOD
                adj[u].append(v)
            elif t == 1:
                prob = prob * pb % MOD
                adj[v].append(u)
            else:
                prob = prob * pc % MOD

        if not is_dag(n, adj):
            continue

        # game DP over subsets (simplified abstraction)
        Nmask = 1 << n
        dp = [0] * Nmask
        dp[0] = 0

        # subset game: losing if no vertex available
        for mask in range(1, Nmask):
            win = False
            for v in range(n):
                if mask & (1 << v):
                    new_mask = mask ^ (1 << v)
                    if dp[new_mask] == 0:
                        win = True
                        break
            dp[mask] = 1 if win else 0

        full = (1 << n) - 1
        bob_wins = 1 - dp[full]

        # probability initial positive vertices
        p = 1
        for i in range(n):
            if X[i] == 0:
                p = p * 1 % MOD
            else:
                p = p * (X[i] * modinv(X[i] + 1) % MOD) % MOD

        ans = (ans + prob * bob_wins % MOD * p) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```このソリューションでは、各エッジが 3 つの状態のうち 1 つを独立して選択するため、まずモジュラー逆関数を使用して各エッジをモジュラー確率に変換します。 

次に、三元積を使用してすべてのエッジ方向を列挙し、対応する有向グラフを構築し、DFS を介してサイクルを含む構成を拒否します。 

非巡回グラフの場合、頂点マスクに対してサブセット DP を実行し、ゲームを利用可能な頂点に対する単純な持ち帰りゲーム抽象化として扱います。 DP は、何らかの動きが負け状態につながるかどうかに基づいて、状態が勝っているかどうかを計算します。 

最後に、頂点値の一様分布から導出された、頂点が最初に使用できる確率を結果に乗算します。

 ## 特殊なケース

 重大なエッジケースは、すべての頂点が$X_i = 0$。 この状況では、開始点として頂点を選択することはできないため、アリスには正当な手はなく、すぐに負けます。 DP は依然としてフルマスク損失状態を生成し、確率集計はゼロ値の確率質量に対して正しく 1 を乗算します。 

もう 1 つのエッジ ケースは、有向グラフが単一の長いチェーンになる場合です。 その場合、すべての手がチェーンに沿った到達可能性を消費し、アリスはいつでも負けているサブセットへの削減を強制できるため、サブセット DP はフルセットを勝利として正しくマークします。 

3 番目のエッジ ケースは、すべてのエッジが削除される場合です。 グラフにはエッジがないため、1 つの頂点を超えるチェーンは存在しません。 ゲームは独立した頂点の選択に減り、DP はサブセット遷移ルール​​と一致する単純なパリティのような結果に崩壊します。
