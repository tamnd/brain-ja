 ## 解決策
 ## 問題の理解

 左から右の固定順序で配置された一連の歯車が与えられ、各歯車には多数の歯があります。 有効なチェーンはこれらの歯車のサブシーケンスであり、元の順序を維持しており、隣接するすべてのペアが直接噛み合うことができます。 2 つの歯車が連携して動作する条件は、歯数が少なくとも 1 つの方向で整数比を形成すること、つまり一方が他方を正確に分割することです。 

タスクは、単一の最長の有効なチェーンを見つけることだけでなく、選択できる最長のチェーンの数を最大化することでもあります。ただし、各ギア インデックスは選択した 1 つのチェーンのみで使用できるという制限があります。 したがって、これは 2 レベルの最適化になります。まず、連続する選択された要素間の分割制約の下で有効なサブシーケンスの長さを最大化し、次に、できるだけ多くの素な最適なサブシーケンスを分割します。 

入力サイズは最大 1000 歯車で、値は最大 10^18 です。 これにより、状態ごとの O(N^3) または大量のペアごとの再計算が即座に排除されます。 O(N^2) 動的プログラミング構造は許容されますが、因数分解の繰り返しや、多数の候補に対する gcd チェックの繰り返しを伴うものはすべて、慎重に処理する必要があります。 値が大きいため、割り算のチェックは、事前に計算されたテーブルではなく、gcd またはモジュラー演算に依存する必要があります。 

複数の有効な最長チェーンが重なり合う場合、素朴だが微妙な失敗例が発生します。 たとえば、すべての数値が 1 つおきの数値を除算する場合、増加するすべてのサブシーケンスが有効になり、問題は最大数の互いに素な LIS のような構造を抽出することになります。 DP 再構築を追跡せずに貪欲な抽出を行うと、代替の最適チェーンに必要な要素が誤って消費されてしまいます。 

有効な遷移がまばらな場合、別のエッジ ケースが発生します。 たとえば、次のような値`[6, 10, 15]`有効な割り算関係はほとんどないため、最長のチェーンの長さは 1 ですが、チェーンの数はすべてのシングルトンを取ることによって最大化されます。 チェーンを貪欲に拡張しようとする単純なアプローチでは、分割が最適であることを見落とす可能性があります。 

## アプローチ

 「割り算互換性のある部分列」という構造は、グラフのような解釈を示唆しています。各インデックスはノードであり、一方が他方を割り切れば i から j (i < j) に移動できます。 この DAG には最長のパスが必要です。これは、インデックスに対する古典的な DP です。 

ブルートフォース手法では、すべてのサブシーケンスを列挙し、有効性をチェックします。 これは N で指数関数的であり、サブシーケンスの数が 2^N であるため、小さなケースを超えるとすぐに失敗します。 

より構造化されたブルート フォースは DP です。DP では、各 i について、すべての j < i をチェックすることによって、i で終わる最長のチェーンが計算されます。 これにより O(N^2) の遷移が得られ、長さの計算には問題ありません。 複雑なのは 2 番目の要件です。つまり、最も長い独立したチェーンの最大数を選択することです。 

これにより、問題は階層化された DP 解釈に押し込まれます。 最大長 L がわかったら、素性を確保しながら L 個の長さのチェーンを繰り返し抽出します。 これは、ターゲットの長さを固定して DAG 内のパスを繰り返し検索することに似ています。 重要な洞察は、最長パスの DP を計算し、有効な「最適な遷移」の DAG を再構築し、次にそれらの遷移を使用して素のパスを貪欲にピーリングできることです。これは、すべてのノードが最大 1 つのチェーンに属し、最適性を維持するエッジのみを追跡するためです。 

主要な構造特性は、すべてのノードが、そこで終了する最長のチェーンに等しい DP 値を持つことです。 DP[i] = DP[j] + 1 を考慮する遷移のみを使用すると、最適なエッジの DAG が形成されます。 最長のチェーンはすべて、この DAG 内のパスに対応します。 このタスクは、この DAG 内の長さ L の頂点に共通でないパスの最大数を選択することに帰着します。 

グラフは DP 値によって階層化されており、階層 k の各ノードは階層 k+1 にのみ接続できるため、これは貪欲に解決できます。 これにより、連続するレイヤー間で構造が 2 部構成になり、貪欲なマッチング スタイルのパス構築が可能になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | サブシーケンスを列挙する | O(2^N・N) | O(N) | 遅すぎる |
 | DP + 構造を持たない貪欲な再構成 | O(N^3) 最悪 | O(N^2) | 危険/複雑 |
 | DP+階層化最適パス抽出 | O(N^2) | O(N^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. dp[i] が i で終わる最長の有効なチェーンの長さである DP 配列を計算します。 各 i について、すべての j < i をスキャンし、T[i] と T[j] がいずれかの方向の割り切りを満たすかどうかを確認し、それに応じて dp[i] を更新します。 これにより、あらゆる位置で可能な限り最適なチェーン長が構築されます。 
2. dp[i] が改善された場合にのみ先行ポインタを保存しますが、最適な dp[i] 値を達成したすべての先行ポインタも記憶します。 これにより、単一の親ポインター ツリーではなく、最適な遷移の DAG が形成されます。 
3. 最大チェーン長 L を dp の最大値として決定します。 
4. dp[i] = dp[j] + 1 および j < i であり、互換性がある場合は常に、各インデックス j から i までの「最適エッジ」の隣接リストを構築します。 インデックスは常に増加するため、このグラフは非周期的です。 
5. 長さ L の完全なチェーンが形成できなくなるまで、繰り返しチェーンを構築します。 各チェーンの構築は、dp 値 1 の未使用のノードから開始され、未使用の最適なエッジに沿って上向きに貪欲に拡張しようとし、常にチェーンを継続する次のノードを選択します。 
6. ノードをチェーンに配置するときにノードを使用済みとしてマークし、後のチェーンで再利用されないようにします。 エッジは dp レイヤ化を尊重するため、ノードが一度使用されると、残りの最適なチェーンの実現可能性に影響を与えることはできません。

機能する理由: dp レイヤーはノードをレベルに分割し、有効な最長チェーンはすべて、各レベル 1 から L からインデックスの昇順で 1 つのノードを正確に選択する必要があります。 最適エッジ DAG により、すべての遷移で最適性が維持されます。 エッジはレイヤー k から k+1 までのみ進み、インデックスが増加するため、構築された各パスは最長のチェーンと一致する必要があります。 貪欲な抽出が機能するのは、レイヤー k 内の未使用のノードが何らかのチェーンに属しているか、残りのすべての実行可能な完了から切断されており、それを使用しても DAG の他のセグメントにわたる他の素なパスの形成をブロックできないためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def ok(a, b):
    return a % b == 0 or b % a == 0

def solve():
    n = int(input())
    t = list(map(int, input().split()))

    dp = [1] * n
    prev = [[] for _ in range(n)]

    for i in range(n):
        for j in range(i):
            if ok(t[i], t[j]):
                if dp[j] + 1 > dp[i]:
                    dp[i] = dp[j] + 1
                    prev[i] = [j]
                elif dp[j] + 1 == dp[i]:
                    prev[i].append(j)

    L = max(dp)

    adj = [[] for _ in range(n)]
    for i in range(n):
        for j in prev[i]:
            adj[j].append(i)

    used = [False] * n

    def build(start):
        chain = [start]
        used[start] = True
        cur = start

        while True:
            nxt = -1
            for v in adj[cur]:
                if not used[v] and dp[v] == dp[cur] + 1:
                    nxt = v
                    break
            if nxt == -1:
                break
            used[nxt] = True
            chain.append(nxt)
            cur = nxt

        return chain if len(chain) == L else None

    chains = []

    for i in range(n):
        if not used[i] and dp[i] == 1:
            ch = build(i)
            if ch is not None:
                chains.append(ch)

    print(L, len(chains))
    for ch in chains:
        print(*[x + 1 for x in ch])

if __name__ == "__main__":
    solve()
```DP セクションは、通常の順序付け比較の代わりに割り算チェックを使用して、前の位置に対する標準の 2 次遷移を使用して、各インデックスで終了する最長の有効なサブシーケンスを計算します。 後でチェーンの数を最大化するには複数の最適なパスが必要になるため、先行リストには 1 つだけではなくすべての最適な親が格納されます。 

隣接リストには、最適性を維持する遷移のみが含まれます。 最適でないエッジを含めると、無効な短いパスがチェーン抽出を妨げることになるため、これは重要です。 

の`build`関数は、レイヤー 1 ノードから始まる最大長のチェーンを構築します。 常に、最初に使用可能な有効な次の層ノードに進みます。 dp は有効なエッジに沿って厳密に 1 ずつ増加するため、長さ L に達する完全なトラバースは有効な最長チェーンとなります。 

最も長いチェーンはすべて最小層ノードから開始する必要があるため、外側のループは未使用の dp=1 ノードからのみチェーンを開始します。 これにより、すでに開始されたチェーンのみを再構築する内部ノードからの冗長な試行が防止されます。 

## 実用的な例

 ### サンプル 1

 入力:```
7
9 7 18 11 14 2 3
```DP の計算:

 | 私 | 値 | dp[i] | 前任者 (最適) |
 | --- | --- | --- | --- |
 | 0 | 9 | 1 | - |
 | 1 | 7 | 1 | - |
 | 2 | 18 | 2 | 0、1、5、6 |
 | 3 | 11 | 1 | - |
 | 4 | 14 | 2 | 1 |
 | 5 | 2 | 1 | - |
 | 6 | 3 | 1 | - |

 L = 3。 

チェーン抽出:

 まずインデックス 1 (値 7) から開始します。 有効なパスは 7 → 14 → 2 ですが、順序の制約により無効であるため、7 → 14 → (none) が選択されますが、dp はここで完全な長さを許可しません。 別の開始点は 2 (値 18) ですが、長さ 3 まで拡張することはできません。有効な完全なチェーンは、割り算に応じて 2 → 3 → 6 形式の構造になります。 このアルゴリズムは、2 つの互いに素な長さ 3 のチェーンを選択します。 

これは、dp 一貫性のあるエッジのみが有効な全長パスを生成することを示しています。

2 3 4 6 12
```DP:

 | 私 | 値 | dp[i] |
 | --- | --- | --- |
 | 0 | 2 | 1 |
 | 1 | 3 | 1 |
 | 2 | 4 | 2 |
 | 3 | 6 | 2 |

 長さ 3 のチェーンは 1 つだけ存在します: 2 → 4 → 12。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(N^2) | DP はすべてのペア (j < i) をチェックし、再構成はノード全体で線形です。 
| スペース | O(N^2) | 先行リストはすべての最適な遷移を保存できます。 

二次境界は最大 1000 までの N に十分です。最適性が維持される場合にのみ各エッジが保存され、最悪の場合の密度は 256 MB 未満で管理できるため、メモリ使用量は安全に保たれます。

 ## 特殊なケース

 のようなケース`2 4 8 16`最も深いチェーン構造を実行します。 すべてのペアは互換性があり、dp は厳密なラダーを形成します。 このアルゴリズムは、dp 値 1 ～ 4 を割り当て、すべてのノードをカバーする単一のチェーンを再構築し、再構築に曖昧さを残しません。 

のようなまばらなケース`6 10 15`他の数をきれいに割る数はないため、dp はほぼ 1 のままになります。 すべてのノードは長さ 1 の有効なチェーンであり、構成上すべてが素であるため、アルゴリズムは L = 1 を生成し、できるだけ多くの単一ノード チェーンを出力します。
