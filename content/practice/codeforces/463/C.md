 ## 解決策
 ## 問題の理解

 私たちは、$n \times n$各セルにはお金を表す非負の整数があります。 目標は、どのセルも両方のビショップによって攻撃されないように正確に 2 つのビショップを配置し、少なくとも 1 人のビショップによって攻撃されたすべてのセルから収集される合計金額を最大化することです。 ビショップは、ビショップが占有するセルを含む、その位置を通過する対角線に沿ったすべてのセルを攻撃します。 

入力により得られるのは、$n$そしてボードは整数の 2D 配列として表されます。 出力は、収集できる最大金額と 2 人の司教の座標です。 行と列には 1 から始まるインデックスが付けられます。 

制約が意味するのは、$n$最大 2000 まで可能です。$4 \times 10^6$細胞。 2 人のビショップのポジションのすべてのペアを試す単純なアプローチでは、次のことが必要になります。$O(n^4)$明らかに実行不可能な操作です。 したがって、ビショップ攻撃の構造を利用して実行するソリューションが必要です。$O(n^2)$または$O(n^2 \log n)$時間。 

対角線を共有するセルに最大の資金が存在する場合、微妙なエッジ ケースが発生します。 「重複なし」ルールを考慮せずにビショップを配置する不注意な実装では、誤ってお金が 2 回含まれる可能性があります。 たとえば、2×2 ボードの場合:```
1 2
3 4
```1 人のビショップが (1,2) にいて、もう 1 人のビショップが (2,1) にいる場合、両方ともセル (1,1) を攻撃します。 対角線の単純な合計では 1 が 2 倍にカウントされますが、正しい出力では一意のセルのみが合計されるはずです。 

## アプローチ

 強引なアプローチは、2 人のビショップのポジションのすべてのペアを試すことです。 各ペアについて、攻撃されたすべての一意のセルの合計を計算します。 これには、各ビショップペアのすべての対角線を反復処理することが含まれます。その結果、次のようになります。$O(n^4)$複雑。 これが機能するのは、正確性が保証されているためです。つまり、考えられるすべての配置が考慮されています。 しかし、$2000^4 \approx 1.6 \times 10^{13}$操作により使用できなくなります。 

重要な洞察は、ビショップの攻撃パターンを観察することで得られます。 各セルは正確に 2 つの対角線に属します。1 つは定数です。$i + j$(「メイン」対角線) と定数を持つもの$i - j$（「反」対角線）。 ビショップが攻撃する価値の合計は、ビショップが位置する 2 つの対角線の合計にすぎません。 2 人のビショップが同じセルを攻撃しないようにするには、チェス盤の異なる「カラー クラス」に属している必要があります。$i + j \mod 2$パリティは少なくとも 1 つの対角線の交差点を共有します。 したがって、ボードを黒と白のセルに分割し (市松模様の色付け)、各セルの対角線の合計を計算し、黒で最良のセルと白で最良のセルを選択します。 

これにより、問題は 2 つの配列の計算に減ります。1 つはすべての主対角線の合計、もう 1 つはすべての対角線の合計です。 各セルの寄与の合計は、その対角線の合計からそのセル自体の値を引いたものになります (二重カウントを避けるため)。 最後に、2 つのカラー クラスを反復して、独立して合計を最大化するセルを見つけます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^4) | O(n^2) | 遅すぎる |
 | 最適 | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つの配列を初期化する`diag1`そして`diag2`すべての主対角線 (i + j) と反対角線 (i - j) の合計を保持します。 各配列のサイズは次のとおりです。$2n-1$対角線には 0 から 0 までのインデックスが付けられるため、$2n-2$。 
2. 各セルを反復処理します。`(i, j)`ボードに追加`a[i][j]`に`diag1[i+j]`そして`diag2[i-j+n-1]`。 このステップでは、各対角線に沿って合計金額を集計します。 
3. 黒と白のセルで最良のビショップを追跡するための 2 つの変数を初期化します。 細胞ごとに`(i, j)`、その寄与を次のように計算します。`diag1[i+j] + diag2[i-j+n-1] - a[i][j]`。 パリティをチェックする`(i+j) % 2`。 黒の場合、貢献度が高ければ最高の黒セルを更新します。 白の場合、貢献度が高ければ最高の白セルを更新します。 
4. すべてのセルを繰り返した後、最良の黒と白のセルの寄与を合計します。 これらの位置は、黒と白のセルが対角線を共有しないため、重ならないことが保証されます。 
5. 合計の合計と 2 つのビショップの座標を、インデックスを 1 ベースに変換して出力します。 

機能する理由: 各セルは黒と白の 1 色に属します。 各色から最大値を選択することで、対角線に沿った合計を最大化しながら、2 人のビショップが同じセルを攻撃しないようにします。 対角線の合計からセル自体を差し引いた値は、ビショップのカバレッジを二重にカウントすることなく正しくカウントします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = [list(map(int, input().split())) for _ in range(n)]

diag1 = [0] * (2*n)
diag2 = [0] * (2*n)

for i in range(n):
    for j in range(n):
        diag1[i+j] += a[i][j]
        diag2[i-j+n] += a[i][j]

max_black = -1
max_white = -1
pos_black = (0,0)
pos_white = (0,0)

for i in range(n):
    for j in range(n):
        total = diag1[i+j] + diag2[i-j+n] - a[i][j]
        if (i+j) % 2 == 0:
            if total > max_black:
                max_black = total
                pos_black = (i+1, j+1)
        else:
            if total > max_white:
                max_white = total
                pos_white = (i+1, j+1)

print(max_black + max_white)
print(pos_black[0], pos_black[1], pos_white[0], pos_white[1])
```コードはまず、O(n^2) の対角線に沿って合計を計算します。 の引き算`a[i][j]`ビショップ自身のセルを二重にカウントすることを防ぎます。 パリティを使用して黒と白を区別することで、ビショップが攻撃されたセルを共有しないようにします。 最終出力にはインデックスを 1 ベースに変換する必要があります。
