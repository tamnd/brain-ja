 ## 問題の理解

 あります$m$それぞれに同じ内容が含まれる完全なデッキ$n$カードの価値。 すべてのデッキを混ぜ合わせた後、$mn$合計物理カード、すべての値が正確に表示されます$m$回。 

アレックスがランダムに取る$n$この大きな山からカードを取り出し、トリックの作業用デッキとして使用します。 

次に、観客はその作業用デッキからランダムにカードを 1 枚選び、その値を覚えて元に戻します。 アレックスはシャッフルしてランダムなカードを引きます。 Alex が魔法を何も行わず、単に一様にランダムに引いていると仮定すると、引かれたカードが記憶されているカードと同じ値を持つ確率を計算する必要があります。 

入力は次のもので構成されます$n$そして$m$。 出力は単一の浮動小数点数、つまりトリックが成功する確率です。 

制約は小さく、次までです。$1000$, しかし、興味深いのは確率を分析的に求めることです。 可能なすべてを列挙しようとするアプローチ$n$- カードの選択は不可能です。そのような選択の数は次のとおりです。$$\binom{mn}{n},$$これは、中程度の値であっても天文学的に大きくなります。 

いくつかの特殊なケースは注目に値します。 

いつ$n=1$、作業用デッキには常に 1 枚のカードが含まれます。 観客がそのカードを選び、アレックスは同じカードを引かなければならないので、答えは常に次のようになります。$1$。 例えば：```
1 5
```正しい出力は次のとおりです。```
1
```因数を含む式$mn-1$次の場合、分母はゼロで除算されます。$n=m=1$、その場合は個別に処理する必要があります。 

もう 1 つの簡単な間違いは、すべての値が作業デッキに最大 1 回しか出現しないと想定することです。 例えば：```
2 2
```選択したデッキは、$\{A,A\}$、成功を確実にします。 重複を無視すると、誤った確率が生成されます。 

## アプローチ

 強引な視点は、実際に必要な量を明らかにするので便利です。 

選択した特定のデッキにカウントが含まれていると仮定します。$$c_1,c_2,\dots,c_n,$$どこ$c_i$値のコピーの数です$i$、 そして$$c_1+c_2+\cdots+c_n=n.$$観客が価値を選ぶ$i$確率的に$c_i/n$。 交代後、アレックスは価値を引き出します$i$確率的に$c_i/n$。 この固定デッキの場合、成功確率は次のようになります。$$\sum_{i=1}^{n}\frac{c_i}{n}\cdot\frac{c_i}{n} = \frac{1}{n^2}\sum_{i=1}^{n} c_i^2.$$ブルートフォースソリューションでは、選択されたすべての可能なデッキを列挙し、この数量を計算し、すべての選択の平均を計算します。 選択数は$\binom{mn}{n}$、それはまったく実行不可能です。 

重要な観察は、次の期待値のみが必要であるということです。$$\sum c_i^2.$$すべてのカードの値は対称です。 させて$X$選択したデッキ内の 1 つの特定の値のコピーの数になります。 

それから$$E\!\left[\sum_{i=1}^{n} c_i^2\right] = nE[X^2].$$したがって、答えは次のようになります$$\frac{E[X^2]}{n}.$$今$X$超幾何分布に従います。 

がある$mn$カードの合計。 

その通り$m$そのうちの値が選択されています。 

私たちは絵を描きます$n$カード。 

したがって$$X \sim \text{Hypergeometric}(N=mn,\ K=m,\ n).$$超幾何確率変数の場合、$$E[X] = \frac{nK}{N},$$そして$$\mathrm{Var}(X) = n\frac{K}{N} \left(1-\frac{K}{N}\right) \frac{N-n}{N-1}.$$置き換える$N=mn$そして$K=m$、$$E[X]=1,$$そして$$\mathrm{Var}(X) = \frac{(n-1)(m-1)}{mn-1}.$$以来$$E[X^2] = \mathrm{Var}(X)+E[X]^2,$$私たちは得る$$E[X^2] = 1+\frac{(n-1)(m-1)}{mn-1}.$$したがって、$$P = \frac{1}{n} \left( 1+\frac{(n-1)(m-1)}{mn-1} \right).$$これは実装にはすでに十分です。

 ## アルゴリズムのチュートリアル

 1.読む$n$そして$m$。 
2. 特殊なケースに対処する$n=m=1$。 

この状況ではカードが 1 枚しか存在しないため、成功確率は正確に$1$。 
3. コンピューティング$$\mathrm{Var}(X) = \frac{(n-1)(m-1)}{mn-1}.$$これは、選択したデッキに出現する固定値のコピー数の分散です。 

1. コンピューティング$$E[X^2] = 1+\mathrm{Var}(X).$$の平均$X$等しい$1$、 それで$E[X]^2=1$。 

1. コンピューティング$$P=\frac{E[X^2]}{n}.$$対称性により、次の期待値は$\sum c_i^2$等しい$nE[X^2]$。 

1. 結果を浮動小数点数として出力します。 

### なぜ効果があるのか

 選択されたデッキが固定されている場合、成功確率は次のとおりです。$$\frac{1}{n^2}\sum c_i^2.$$全体的な答えは、すべてのランダムなデッキ選択に対するこの数量の期待値です。 期待値の線形性により、次の合計を置き換えることができます。$n$対称項による$nE[X^2]$、 どこ$X$単一の値のコピーをカウントします。 以来$X$は超幾何的であるため、その平均と分散は正確にわかっています。 これらの式を代入すると、期待される正確な成功確率が得られます。 すべてのステップは等しいため、アルゴリズムは真の確率を計算します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    if n == 1 and m == 1:
        print(1.0)
        return

    var = (n - 1) * (m - 1) / (n * m - 1)
    ans = (1.0 + var) / n

    print(ans)

solve()
```実装は導出に直接続きます。 

唯一の特別な扱いは、$(n,m)=(1,1)$。 閉形式分散には次の因子が含まれます。$mn-1$分母ではゼロになります。 確率的に言えば、答えは自明です$1$カードは1枚しか存在しないからです。 

すべての演算は浮動小数点で実行されます。 必要な精度はただ$10^{-6}$、つまり標準的な Python`float`算数は十分すぎるほどです。 

ソリューション全体が定数サイズの数式を評価することになるため、ループは必要ありません。

 ## 特殊なケース

 可能な最小の入力を考えてみましょう。```
1 1
```存在するカードは 1 枚だけです。 観客がそのカードを選び、アレックスが同じカードを引きます。 アルゴリズムはすぐに戻ります`1.0`分散の公式を評価する前に、ゼロによる除算を回避して正しい答えを導き出します。 

考慮する：```
3 1
```すべての値は 1 回だけ存在します。 選択されたデッキは常に 3 枚の異なるカードの完全なセットです。 アルゴリズムは計算します$$\mathrm{Var}(X)=0,$$なぜなら、固定値は確実に 1 回だけ現れるからです。 それから$$P=\frac{1}{3}.$$これは、3 つの異なるカードから記憶されているカードを引く直感的な確率と一致します。 

考慮する：```
1 5
```大きな山にはその値のコピーが 5 枚存在しますが、作業デッキにはちょうど 1 枚のカードが含まれています。 アルゴリズムは計算します$$\mathrm{Var}(X)=0, \qquad P=1.$$観客とアレックスは同じ 1 枚のカードを操作することを強いられるため、成功は保証されます。 

最後に、重複が重要な場合を考えてみましょう。```
2 2
```不注意な解決策は、2 つの異なる値が常に選択されて応答すると仮定する可能性があります。$1/2$。 超幾何計算では、次のような選択が正しく考慮されます。$\{A,A\}$、確率が高まります。 結果として得られる答えは、$$\frac{2}{3},$$これはサンプル出力と一致します。
