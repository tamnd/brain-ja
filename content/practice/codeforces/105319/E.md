 ## アルゴリズムのチュートリアル

 導出された合計を効率的に評価することにより、各テスト ケースの答えを計算します。

2. 各テスト ケースについて、次の内容を読んでください。$N, M, K$。 私たちは解釈します$t$生き残る要素の数として$B$、カラーブロックの代表者の数を意味します。 
3. 反復する$t$から$1$に$N$。 それぞれについて$t$、どの位置を選択する方法の数を計算します。$A$これらの始まりに対応します$t$ブロック。 これは$\binom{N-1}{t-1}$、最初のブロックは位置 1 に固定され、残りのブロックは$t-1$ブロックの開始は残りの中から選択されます$N-1$ポジション。

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAX = 200000 + 5

fact = [1] * MAX
invfact = [1] * MAX

for i in range(1, MAX):
    fact[i] = fact[i-1] * i % MOD

invfact[MAX-1] = pow(fact[MAX-1], MOD-2, MOD)
for i in range(MAX-2, -1, -1):
    invfact[i] = invfact[i+1] * (i+1) % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n-r] % MOD

def solve():
    T = int(input())
    for _ in range(T):
        N, M, K = map(int, input().split())
        
        ans = 0
        
        for t in range(1, N + 1):
            ways_pos = C(N - 1, t - 1)
            ways_color = K * pow(K - 1, t - 1, MOD) % MOD
            ways_num = C(M + t - 1, t)
            
            ans += ways_pos * ways_color % MOD * ways_num % MOD
            ans %= MOD
        
        print(ans)

if __name__ == "__main__":
    solve()
```階乗事前計算は、ブロック位置の選択と非減少数シーケンスの形成の両方に必要なすべての二項係数をサポートします。 べき乗剰余演算は、各ブロック シーケンス内の色の遷移を処理します。 

ループオーバー$t$縮小されたスタックの可能なすべてのサイズに対する貢献を蓄積します。$B$、各項は、事前に計算された組み合わせ論を使用して一定時間で計算されます。 

よくある実装の落とし穴は、二項引数が異なることを忘れていることです。$N-1$選ぶ$t-1$、他のものは使用します$M+t-1$選ぶ$t$。 これらを混同すると、組み合わせ解釈が崩れます。

 ## 特殊なケース

 主なエッジケースは次のような場合です$K = 1$。 次に、すべてのカードが同じ色を共有するため、すべてのシーケンスが 1 つのブロックに折りたたまれます。$t=1$いつも。 式は次のようになります。$\binom{M}{1} = M$、最初のカードのみが重要であるという事実と一致します。 

もう一つのケースは、$M = 1$、数値が意味のある増加をすることができない場合。 非減少条件は自明となるため、答えは色の構造のみに依存します。 この式は、カラー ブロック構成をカウントするために正しく折りたたまれます。 

最後に、いつ$N = 1$、ブロックは 1 つだけあり、トランジションはありません。 式は次のようになります。$K \cdot M$これは、直接の解釈と一致します。つまり、比較するものがないため、どの 1 枚のカードも有効です。
