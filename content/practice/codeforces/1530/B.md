 ## 解決策
 ## 問題の理解

 として表される長方形のテーブル上の皿の数を最大にするように求められます。$h \times w$グリッド。 プレートは、最初の行、最後の行、最初の列、最後の列を含む周囲に沿ってのみ配置できます。 さらに、2 つのプレートを直角または斜めに隣接させることはできません。 つまり、どのプレートでも$(i, j)$、周囲の 8 つのセルは空のままにしておく必要があります。 目標は、可能な最大のプレート数を達成する、各テーブルの有効なプレート構成を出力することです。 

入力は複数のテスト ケースを提供し、それぞれにテーブルのディメンションが含まれます。$h$そして$w$。 生産する必要があります$h$長さの線$w$テスト ケースごとに、プレートには「1」、空のセルには「0」をマークします。 以来$3 \le h, w \le 20$そして$t \le 100$、アルゴリズムは小さなグリッドを処理するだけで済みます。つまり、すべての周囲のセルを順番に検査するソリューションも実現可能です。 

明らかではないエッジケースは、テーブルが非常に狭いか短い場合に発生します。$3 \times 3$テーブル。 ここで、コーナーをチェックせずに単純に配置すると、エッジに沿って隣接するセルにプレートを配置しようとし、隣接制限に違反する可能性があります。 同様に、均等な寸法のテーブルでは、複数の同等の最大配置が可能であるため、特にコーナーでの競合を回避するパターンを適用する際に、ソリューションが一貫している必要があります。 

## アプローチ

 ブルート フォース アプローチでは、境界セルのすべての可能なサブセットを試行し、隣接関係の競合がないか各組み合わせをチェックします。 おおよそあります$2 \cdot h + 2 \cdot (w - 2)$周囲のセルなので、サブセットの数は周囲の長さで指数関数的になります。 のために$h = w = 20$、この結果は$2^{76}$combinations, which is infeasible.

 重要な観察は、隣接制約が境界に沿って局所的に伝播するということです。 エッジに沿って交互の位置に配置されたプレートは、コーナーを慎重に処理する限り衝突することはありません。 これを利用するには、上の行、右の列、下の行、左の列の順にエッジを移動し、セルとその隣接セルが空いているときにプレートを貪欲に配置します。 これが機能するのは、隣接関係の制約が純粋にローカルであるためです。そのため、境界に沿った貪欲なアプローチにより常に最大の構成が生成されます。 唯一の微妙な点は、コーナーでの対角線の隣接性をチェックすることです。これは、コーナーの隣に既にプレートが含まれている場合、配置をスキップすることで処理できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(2h + 2w)) | O(h*w) | 遅すぎる |
 | 貪欲なエッジ配置 | O(h*w) | O(h*w) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. を初期化します。$h \times w$grid filled with zeros. これは空のテーブルを表します。 
2. 上の行に沿って左から右に繰り返します。 各セルについて、セル自体とその 8 つの隣接セルが空かどうかを確認します。 そうであれば、このセルにプレート (「1」) を配置します。 
3. 右端の列に沿って上から下に繰り返します。 上のセルは既に処理されている右上隅と重なるため、スキップします。 プレートを配置する前に、同じ隣接チェックを適用します。 
4. 一番下の行に沿って右から左に繰り返します。 右下隅は右の列で埋まってしまっている可能性があるため、スキップしてください。 もう一度、配置する前に近隣を確認してください。 
5. 左端の列に沿って下から上に繰り返します。 すでに処理されている場合は、左下隅と左上隅をスキップします。 隣の人が空の場合にのみプレートを置きます。 
6. すべてのエッジが処理されたら、グリッドを行ごとに印刷します。 

機能する理由: プレートは、隣接するすべてのセルが空いている場合にのみ配置され、隣接性違反がないことが保証されます。 エッジを順番に処理することで、コーナーの競合が走査の順序に従って確実に解決されます。 各エッジセルはすぐ隣のセルからのみ影響を受けるため、プレートの数を最大化するためにグローバルなバックトラッキングは必要ないため、ローカルの貪欲な配置で十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def place_plates(h, w):
    grid = [['0'] * w for _ in range(h)]

    def safe(i, j):
        for di in [-1, 0, 1]:
            for dj in [-1, 0, 1]:
                ni, nj = i + di, j + dj
                if 0 <= ni < h and 0 <= nj < w:
                    if grid[ni][nj] == '1':
                        return False
        return True

    # top row
    for j in range(w):
        if safe(0, j):
            grid[0][j] = '1'

    # right column
    for i in range(1, h):
        if safe(i, w - 1):
            grid[i][w - 1] = '1'

    # bottom row
    for j in range(w - 2, -1, -1):
        if safe(h - 1, j):
            grid[h - 1][j] = '1'

    # left column
    for i in range(h - 2, 0, -1):
        if safe(i, 0):
            grid[i][0] = '1'

    return [''.join(row) for row in grid]

t = int(input())
for _ in range(t):
    h, w = map(int, input().split())
    result = place_plates(h, w)
    print('\n'.join(result))
    print()
```このソリューションでは、`safe`隣にプレートが含まれていないことを保証する関数。 上の行は左から右に、右の列は上から下に、下の行は右から左に、左の列は下から上に処理されます。 隣接チェックにより二重配置が防止されるため、コーナーは自然に処理されます。 塗りつぶし後、グリッドが印刷されます。
