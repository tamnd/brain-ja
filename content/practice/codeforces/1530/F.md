 ## 解決策
 ## 問題の理解

 正方形のイベント表が「勝つ」確率を計算するように求められます。 の各セル$n \times n$テーブルには、指定された確率で発生する可能性のあるイベントが含まれています。 行、列、主対角線、および対対角線は線とみなされます。 少なくとも 1 つのラインですべてのイベントが同時に発生する場合、テーブルは勝利しています。 入力は確率を整数として与えます$a_{i,j}$代表する$a_{i,j} \cdot 10^{-4}$、出力では、モジュラー逆関数を使用して確率をモジュロ 31,607 で計算する必要があります。 

制約は次のとおりです。$2 \le n \le 21$これは、列または行のサブセットに対する指数アルゴリズムを許可するには十分小さいですが、すべてを総当たりで列挙するには大きすぎます。$2^{n^2}$可能なイベントの組み合わせ。 イベントの独立性により、線に沿って確率を乗算することができます。これは最適化にとって重要です。 重要な点は、確率が 10,000 スケールの整数として与えられるため、精度を維持し、モジュラー演算を正しく使用するように注意する必要があることです。 もう 1 つのエッジ ケースは、一部の確率が 0 または 10,000 であり、不可能なイベントまたは特定のイベントに対応する場合です。 ここでは単純な浮動小数点アプローチでは精度が失われる可能性があるため、モジュラー演算または正確な分数を使用する方が安全です。 

## アプローチ

 素朴なアプローチではすべてを試してしまうだろう$2^{n^2}$イベントの構成を確認し、それぞれに勝ちラインが存在するかどうかを確認し、確率を合計します。 これは正しいですが、たとえ$n=21$を合計する必要があるため、$2^{400}$州。 

より良いアイデアは、包含と排除の原則を活用することです。 どのラインも完全に占有されていない確率を計算し、1 から減算できます。各ラインを定義します。$L$(行、列、主対角線、対対角線)$E_L$すべてのイベントが含まれるイベントになります$L$起こる。 包含-除外を使用して、線のすべてのサブセットを合計して、少なくとも 1 つの線が発生する確率を求めます。 これでも行数は指数関数的に増加します。 あるので$2n+2$行の場合、サブセット数は$2^{2n+2}$、これは実現可能です$n \le 21$確率を注意深く計算すると。 

どの行と列が「使用」されているかをビットマスクで表し、動的プログラミングによって寄与を効率的に計算することで、さらに最適化できます。 各行は、アクティブ化される列のサブセットに独立して寄与できます。 対角線は、特定の列ビットのみが設定された特別な行として処理できます。 これにより、重複するイベントの冗長な計算が削減され、複雑さが管理可能に保たれます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(n^2)) | お(1) | 遅すぎる |
 | ビットマスク DP による包含-除外 | O(n * 2^n) | O(2^n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての確率を変換する$a_{i,j}$31,607 を法とするモジュラー分数に変換します。 それぞれについて$a_{i,j}$、 店$p_{i,j} = a_{i,j} \cdot 10^{-4} \mod 31,607$10,000 のモジュラー逆数を使用します。 これにより、モジュロでの正確な演算が保証されます。 
2. 各行について、その行の列のサブセットがすべてゼロである (イベントが発生しない) 確率を計算します。 これらを列上のマスクとして保存します。 これにより、ビットマスクを使用して行を結合するときに高速な計算が可能になります。 
3. 主対角線と反対角線を、特定の列ビットのみを持つ追加行として扱います。 これにより、すべてのライン計算を単一のビットマスク フレームワークに統合できます。 
4. 列マスク上で動的プログラミングを使用します。 させて`dp[mask]`に対応する列が存在する確率を表します。`mask`処理された行ではすべてのイベントがゼロになります。 初期化する`dp[0] = 1`。 
5. 各行を更新します。`dp`すべての列マスクを反復処理します。 それぞれについて`dp[mask]`、現在の行が追加の列をアクティブにしない確率を乗算します。 これは、行マスクを次のように畳み込むことと同等です。`dp`不変性を維持するため。 
6. すべての行を処理した後、`dp[full_mask]`すべてのイベントを含む列がない、つまりテーブルが勝っていない確率を示します。 これを 1 モジュロ 31,607 から減算して、当選確率を取得します。 
7. 出力には次の要求があるため、必要に応じてモジュラー反転を処理して結果を返します。$p \cdot q^{-1} \mod 31,607$。 

機能する理由: 列の状態をビットマスクとして表すことで、重複する行を効率的に考慮し、二重カウントを回避できます。 畳み込みステップにより、独立したイベントの確率が正しく組み合わされることが保証されます。 特別な行として対角線を含めることで、同じ DP ですべての勝ちラ​​イン タイプをカバーできるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 31607

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n = int(input())
    a = [list(map(int, input().split())) for _ in range(n)]
    # Convert to modular probability fractions
    prob = [[(a[i][j] * modinv(10000)) % MOD for j in range(n)] for i in range(n)]
    
    # Precompute row products
    row_prod = []
    for i in range(n):
        prod = [1] * (1 << n)
        for mask in range(1 << n):
            val = 1
            for j in range(n):
                if mask & (1 << j):
                    val = val * prob[i][j] % MOD
                else:
                    val = val * (1 - prob[i][j]) % MOD
            prod[mask] = val
        row_prod.append(prod)
    
    dp = [0] * (1 << n)
    dp[0] = 1
    for i in range(n):
        ndp = [0] * (1 << n)
        for mask in range(1 << n):
            for row_mask in range(1 << n):
                ndp[mask | row_mask] = (ndp[mask | row_mask] + dp[mask] * row_prod[i][row_mask]) % MOD
        dp = ndp
    
    full_mask = (1 << n) - 1
    result = (1 - dp[full_mask]) % MOD
    print(result)

if __name__ == "__main__":
    solve()
```各セクションでは、入力確率をモジュラー分数に変換し、すべての列サブセットにわたる各行の確率を事前計算し、ビットマスク DP を使用して完全にアクティブなラインがない確率を効率的に計算します。 畳み込みステップ`dp[mask | row_mask]`新しい行を既存の列カバレッジに追加した場合の効果をマージします。 モジュラー演算を使用すると、精度が確保され、必要なモジュロ出力が処理されます。
