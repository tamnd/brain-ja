 ## 問題の理解

 番号を取るように求められます$n$2050 の倍数を 10 のべき乗でスケールした数値の合計として表します。 具体的には、2050、20500、205000、2050000 などの数値を使用できます。 このシーケンス内の各数値は、正確に 2050 に 10 の累乗を乗算したものです。 タスクは、合計が次になるような数値の最小数を見つけることです。$n$、またはそれは不可能であると報告します。 

入力は複数のテスト ケースで構成され、それぞれに 1 つの数値が含まれます。$n$。$n$と同じ大きさにすることができます$10^{18}$これにより、考えられるすべての組み合わせを強引に列挙することが排除されます。 この限界は、大きな整数を効率的に、理想的には桁数に対して対数時間または線形時間で処理するメソッドが必要であることを示しています。$n$。 

微妙なエッジケースが発生する場合$n$2050年までに全く割り切れない。 例えば、$n = 205$2050 の数値の合計として記述することはできません。 常に除算または減算を試行する不注意な実装では、非整数の結果が得られるか、存在しない合計を誤って構築しようとします。 もう 1 つのエッジケースは次のような場合です$n$は、次のような 10 の累乗を伴う単一の 2050 数です。$2050 \cdot 10^{15}$。 私たちのソリューションは、より小さな倍数をすべて反復することなく、これらを処理する必要があります。 

## アプローチ

 素朴なアプローチは、2050 年の数値をすべて生成することです。$n$そしてすべての組み合わせを試してください。 2050 の数字ごとに、次から繰り返し減算できます。$n$ゼロになるまで。 これは本質的に、総当たりの貪欲なアプローチです。 小規模でも機能します$n$ただし、可能な 2050 桁の数値の数は桁数に応じて変化するため、大きな入力の場合は失敗します。$n$減算ループは次の値に達する可能性があります$10^{18}/2050 \approx 5 \cdot 10^{14}$最悪の場合の運用。 

重要な洞察は、有効なすべての$n$許可される数値はすべて 2050 の倍数であるため、2050 で割り切れる必要があります。$n$2050 年までに、問題は結果の数値を表すことになります。$m = n / 2050$10 のべき乗の合計として。10 のべき乗にはゼロ以外の桁が 1 つだけあるため、項の最小数は単純に次の桁の合計になります。$m$。 これにより、考えられるすべての組み合わせを繰り返す必要がなくなり、問題が単純な桁の合計の計算に減ります。 このアプローチは、どのような数値でも機能します。$m$10 進数の は、10 のべき乗の合計と 1 桁の係数の積として一意に表すことができ、各係数は、特定の 10 のべき乗を持つ 2050 個の数のカウントに対応します。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$T$。 
2. 各テスト ケースの番号を読み取ります。$n$。 
3. 次のことを確認します。$n$2050 で割り切れない場合は、-1 を出力して次のテスト ケースに進みます。 このステップでは、不可能なケースを即座にフィルタリングします。 
4. 分割$n$2050年までに取得するには$m$。 これにより、問題は桁を数える問題に変換されます。 
5. 必要な 2050 番号の数に応じてカウンターを初期化します。 
6. ながら$m > 0$の最後の桁を抽出します。$m$モジュロ 10 を使用してカウンタに加算し、整数で除算します。$m$10 で割ります。これは実質的に次の桁を合計します。$m$。 
7. カウンタを印刷します。 これは、必要な 2050 番号の最小数です。 

の各桁が一致するため、正確性が保証されます。$m$は、2050 の数に 10 の特定の累乗を乗じた数に対応します。各桁は対応する 2050 の数で直接実現できるため、桁を合計すると最小の項数が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

T = int(input())
for _ in range(T):
    n = int(input())
    if n % 2050 != 0:
        print(-1)
        continue
    m = n // 2050
    count = 0
    while m > 0:
        count += m % 10
        m //= 10
    print(count)
```まずテスト ケースの数を読み取り、次に各テスト ケースを反復処理します。$n$。 可分性チェックにより、不可能な場合の不必要な計算が防止されます。 2050 で割ると、問題は桁和の問題に変換されます。 次に、次の数字をループします。$m$、それらを合計して最終的なカウントを取得します。 整数除算を使用すると、浮動小数点精度の問題は発生しません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    T = int(input())
    for _ in range(T):
        n = int(input())
        if n % 2050 != 0:
            output.append("-1")
            continue
        m = n // 2050
        count = 0
        while m > 0:
            count += m % 10
            m //= 10
        output.append(str(count))
    return "\n".join(output)
