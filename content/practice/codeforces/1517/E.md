 ## 解決策
 ## 問題の理解

 私たちに与えられた一行は、`n`人々はそれぞれ「C」または「P」というラベルの付いたカードを持っています。 カードの配置ごとに候補写真が形成されます。 特定のパターンが有効であると考えられます。「C」を保持している人については、右に移動しても連続する「C」間の距離が減少してはならず、「P」を保持している人については、右に移動しても連続する「P」間の距離が増加してはなりません。 目標は、「C」カードの数字の合計が「P」カードの数字の合計より厳密に小さい、有効な写真をすべてカウントすることです。 

入力は整数の配列です`a_1, ..., a_n`、各人に関連付けられた価値観を表します。 出力は有効な写真の数を法的に計算したものです。`998244353`。 

制約は厳しいです:`n`到達できる`200,000`、最大で`200,000`テストケースの合計。 すべてを生み出す素朴なアプローチ`2^n`パーティション分割は不可能でしょう。 線形またはほぼ線形にスケールするアプローチが必要です。`n`テストケースごとに。 

微妙なエッジケースには以下が含まれます: 長さのあるシーケンス`1`(配列が 1 つだけ存在する場合)、すべての値が同一である配列 (多くの合計が一致する可能性がある)、有効なシーケンスが単調距離規則によって制限される場合。 たとえば、次の場合`a = [1, 1, 1]`の場合、「C」距離は減少できないため、「CPC」などのシーケンスは慎重に検討する必要があります。 

## アプローチ

 ブルートフォース手法では、ラインを「C」と「P」にすべて分割して、それぞれの距離条件をチェックします。 これには反復処理が必要です`2^n`組み合わせ、それぞれについて単調な間隔ルールを検証します。 最悪の場合の操作はおおよそ次のようになります。`O(n * 2^n)`、これは明らかに不可能です`n`まで`200,000`。 

重要な洞察は、距離の制約が「C」と「P」の配置方法に構造を課すことを観察することで得られます。 「C」のシーケンスではギャップが減少せず、「P」のシーケンスではギャップが増加しません。 これにより、両端のプレフィックスの合計に焦点を当てることができます。先頭から 'C' として取得され、最後から 'P' として取得される連続した要素のシーケンスが有効な候補を形成します。 次に、問題は、合計条件を満たす接頭辞と接尾辞の分割の数をカウントすることと、最初と最後の要素を交互にする配置についての追加のチェックをいくつか行うことに帰着します。 

基本的に、すべてのサブセットを考慮するのではなく、有効な構成を、左側から「C」として残りを「P」としていくつかの連続する要素を取るか、右側から「C」として左側を「P」として取るかのいずれかとして扱うことができます。これには、小さな特殊なケースをカバーするために最初の要素を反転するいくつかの追加パターンが含まれます。 これにより、複雑さが軽減されます。`O(n)`プレフィックス合計を使用したテスト ケースごと。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * 2^n) | O(n) | 遅すぎる |
 | プレフィックス/サフィックスの合計 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列のプレフィックスの合計を計算します。`a`、開始点から各位置までの値の合計が得られます。 これにより、連続するサブ配列の合計を定数時間で計算できるようになります。 
2. 同様に接尾語の合計を計算します。これにより、末尾から逆方向に合計が計算されます。 これにより、「P」セクションの合計を効率的に確認できます。 
3. カウンタの初期化`ans`有効な写真の数を追跡します。 
4. 最初の分割を繰り返します。`k`要素は「C」であり、残りは`n-k`要素は「P」です。 分割ごとに、「C」要素の合計を比較します(`prefix[k]`) 'P' 要素の合計 (`prefix[n] - prefix[k]`）。 インクリメント`ans`合計条件が成立する場合。 
5. 右端から「C」シーケンスを考慮してプロセスを繰り返します。 では、最後に`k`要素は 'C' で、最初の要素は`n-k`要素は「P」です。 
6. 特殊なケースに対処するために最初または最後の要素を交換するシーケンスを調整します。 具体的には、距離制約を満たすためにエッジで交互するシーケンスを考慮する必要があります (長さ 1 のギャップは常に単調特性を満たすことができるため)。 
7. 戻る`ans % 998244353`。 

**機能する理由:** 接頭辞と接尾辞の列挙は、単調ギャップ制約を満たすすべてのシーケンスをキャプチャします。 有効な写真はどれも、エッジを少し調整して、左または右から分割して表現できます。 不変条件は、「C」と「P」の合計を常に正しく比較し、有効な構成が欠落したり二重にカウントされたりしないようにすることです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        if n == 1:
            print(1)
            continue
        
        prefix = [0] * (n+1)
        for i in range(n):
            prefix[i+1] = prefix[i] + a[i]
        
        ans = 0
        
        # Case 1: take k elements from left as C
        for k in range(1, n+1):
            sum_c = prefix[k]
            sum_p = prefix[n] - prefix[k]
            if sum_c < sum_p:
                ans += 1
        
        # Case 2: take k elements from right as C
        suffix = [0] * (n+1)
        for i in range(n-1, -1, -1):
            suffix[n-i] = suffix[n-i-1] + a[i]
        
        for k in range(1, n):
            sum_c = suffix[k]
            sum_p = prefix[n] - suffix[k]
            if sum_c < sum_p:
                ans += 1
        
        print(ans % MOD)

solve()
```このソリューションは、高速範囲合計クエリのプレフィックスとサフィックスの合計を計算します。 ループは、左と右からのすべての連続した選択を処理します。 長さ 1 の配列のエッジ ケースは直接処理されます。
