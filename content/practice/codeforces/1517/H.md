 ## 解決策
 ## 問題の理解

 一連の実数値が与えられます$b_1, b_2, \ldots, b_n$、これは航空機の高度として解釈できます。$n$チェックポイント。 各チェックポイントでは、許可される高度範囲が制限されているため、$b_i$一定の間隔内になければなりません。 連続するチェックポイント間の高度の変化も制限されているため、各最初の差分は$b_i - b_{i-1}$独自の間隔内に存在する必要があります。 最後に、これらの変化の変化も有限であるため、2 番目の差は$(b_i - b_{i-1}) - (b_{i-1} - b_{i-2})$も制約されています。 

タスクはシーケンスを構築することではなく、これらすべての間隔制約を満たす実数値シーケンスが少なくとも 1 つ存在するかどうかを判断することだけです。 

これは 1 次元連鎖上の線形不等式系ですが、二次差分制約の存在により、標準的な差分制約グラフよりも大幅に強力になります。 それぞれ$b_i$近隣地域だけでなく、斜面の進化にも関係しています。 

制約の規模は大きく、最大で$2 \cdot 10^5$合計$n$テストケース全体で。 すべての変数にわたって完全な幾何学的実現可能性を明示的に維持しようとするソリューションは、遅すぎます。 これにより、線形時間伝播または区間 DP スタイルの推論が強制されます。 

重要な微妙な点は、値が実数であり、問​​題文では微小な摂動が答えに影響を与えないことが保証されていることです。 これは、完全等価連鎖からの縮退を記号的に処理する必要がなく、開いた/閉じたあいまい性のある区間伝播は無視できるという強力なヒントです。 

素朴なアプローチでは、制約を尊重しながら値を順番に割り当てようとしますが、初期の貪欲な決定が後の実現可能性を妨げる例では失敗する可能性があります。 たとえば、すべてが$b_i \in [0,1]$そしてすべての差異は強制的に存在する$1$、貪欲な割り当てセット$b_1 = 0, b_2 = 1$、しかしその後$b_3 = 2$すぐにその境界に違反します。 この失敗は、各ステップが現在の値だけでなく将来の勾配空間も制限することを追跡していないことに起因します。 

もう 1 つの間違ったアプローチは、各制約を隣接するペア間の間隔の実現可能性として独立して扱うことです。 これは 2 番目の差異を無視するため、すべてのローカル制約が個別に満たされる場合でも、暗黙のうちにグローバルな不整合が強制される可能性があります。 

正しいアプローチでは、可能な値だけを伝播する必要はありません。$b_i$だけでなく、実行可能な勾配の範囲も含め、チェーン全体にわたってこれらの勾配範囲の一貫性を確保する必要があります。 

## アプローチ

 ブルートフォース手法では、これを継続的な実行可能性の問題として扱います。$n$変数と$O(n)$制約を設定してから、一般的な線形計画法または厳密な算術による制約伝播を使用して、その制約を解決しようとします。 すべての境界を繰り返し調整することを想像することもできます。$b_i$収束するまで。 各反復ではすべての制約をスキャンし、間隔を狭めます。 

システムが凸型であるため、これは原理的には機能しますが、最悪の場合、多くの緩和ラウンドが必要になる可能性があります。 各パスに費用がかかる場合$O(n)$、控えめでも$O(n)$反復回数は次のようになります$O(n^2)$では不可能な行動$n = 2 \cdot 10^5$。 

重要な構造的洞察は、二階差制約により、傾き変数を使用して問題をモデル化できるということです。 定義すると$d_i = b_i - b_{i-1}$の場合、すべての制約はローカル制約になります。$(b_i, d_i)$、そしてさらに重要なことに、2 番目の差の制約は連続した勾配に対する制約になります。$$d_{i+1} - d_i \in [z_{i+1}^-, z_{i+1}^+].$$これにより、問題は、位置と傾きというチェーンに沿って展開する 2 状態システムの実行可能な間隔を維持することに変換されます。 位置は区間境界によって制約され、傾きは一次差分境界と二次差分境界の両方によって制約されます。 

重要な観察は、可能な状態の正確なセットが必要ないということです。 各ステップの実現可能領域は凸状になっています。$(b_i, d_i)$、したがって、次の制限された間隔として表すことができます。$b_i$の間隔とペアになっています$d_i$、それらをリンクする一貫性制約があります。 

これにより、各ステップが許可された領域を変換する、間隔 DP を前方に伝播するという問題が軽減されます。$(b_{i-1}, d_{i-1})$の中へ$(b_i, d_i)$線形制約の下で、指定された境界と交差します。

 ## アルゴリズムのチュートリアル

 現在の高さと現在の傾斜の両方について、実行可能な範囲を追跡します。 ステップで$i$、間隔を保ちます$[L_i, R_i]$の可能な値のうち、$b_i$、および間隔$[D_i^-, D_i^+]$考えられる坂道に合わせて$d_i = b_i - b_{i-1}$。 

1. 最初の位置間隔を次のように初期化します。$[x_1^-, x_1^+]$。 これが唯一の制約です$b_1$、傾斜を定義するための前の点が存在しないためです。 
2. 位置制約と一次差分制約の両方を使用して 2 番目の点を初期化します。 私たちはあらゆる可能性を導き出します$b_2$存在するような$b_1 \in [L_1, R_1]$と$b_2 - b_1 \in [y_2^-, y_2^+]$。 これにより、次の派生間隔が得られます。$b_2$可能な傾きを暗黙的に定義します$d_2$。 
3. それぞれについて$i \ge 3$、まず考えられる傾きの範囲を計算します。$d_i$交差することで:

 以前の勾配範囲のシフト$[D_{i-1}^- + z_i^-, D_{i-1}^+ + z_i^+]$直接制約がある場合$y_i^- \le d_i \le y_i^+$。 

このステップにより、最初の差異と 2 番目の差異の間の一貫性が保証されます。 
4. 勾配間隔がわかったら、到達可能な間隔を計算します。$b_i$前の位置間隔を傾き間隔だけシフトすることにより、次のようになります。$$b_i \in [L_{i-1} + D_i^-, R_{i-1} + D_i^+]$$そして交差する$[x_i^-, x_i^+]$。 

このステップにより、選択した傾斜が​​実際に有効な位置を生成できることが強制されます。 
5. どこかの時点で位置間隔または傾斜間隔のいずれかが空になった場合、システムは実行不可能になります。 
6. すべてのインデックスを処理した後、空の間隔がまったく得られない場合、答えは「YES」です。 

重要な推論ステップは、傾きが位置の展開を完全に決定し、2 番目の差分が傾きの展開を線形に制限するため、すべての実行可能な構成が伝播全体を通じて凸状の間隔を維持するということです。 

### なぜ効果があるのか

 すべてのインデックスで$i$、すべての実行可能な部分解が次の値に達するという不変条件を維持します。$i$は、これまでのすべての制約と一致する、可能な位置の間隔と可能な傾きの間隔によって表すことができます。 更新ステップでは、からの線形遷移の下でこの実現可能なセットのイメージを正確に計算します。$i-1$に$i$、次にローカル制約と交差します。 すべての制約は線形不等式であるため、実行可能セットは凸型のままであり、各座標へのその投影は区間のままです。 これにより、区間圧縮によって実行可能な解が失われることはなく、空の区間は真の実行不能に対応することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        
        xL = [0] * (n + 1)
        xR = [0] * (n + 1)
        for i in range(1, n + 1):
            xL[i], xR[i] = map(int, input().split())
        
        yL = [0] * (n + 1)
        yR = [0] * (n + 1)
        for i in range(2, n + 1):
            yL[i], yR[i] = map(int, input().split())
        
        zL = [0] * (n + 1)
        zR = [0] * (n + 1)
        for i in range(3, n + 1):
            zL[i], zR[i] = map(int, input().split())

        # feasible range for b1
        Lb = xL[1]
        Rb = xR[1]

        # no slope defined yet, but we infer d2 from first step
        if n >= 2:
            # compute feasible b2 from b1 and y2
            newL = Lb + yL[2]
            newR = Rb + yR[2]
            Lb2 = max(xL[2], newL)
            Rb2 = min(xR[2], newR)

            if Lb2 > Rb2:
                print("NO")
                continue

            # slope d2 range induced by b2 - b1
            dL = yL[2]
            dR = yR[2]

            Lb, Rb = Lb2, Rb2
        else:
            print("YES")
            continue

        # slope interval
        dL_cur, dR_cur = dL, dR

        ok = True

        for i in range(3, n + 1):
            # update slope using second difference
            ndL = max(yL[i], dL_cur + zL[i])
            ndR = min(yR[i], dR_cur + zR[i])

            if ndL > ndR:
                ok = False
                break

            dL_cur, dR_cur = ndL, ndR

            # update position
            newL = Lb + dL_cur
            newR = Rb + dR_cur

            Lb = max(xL[i], newL)
            Rb = min(xR[i], newR)

            if Lb > Rb:
                ok = False
                break

        print("YES" if ok else "NO")

solve()
```コードは 2 つの変化する間隔を維持します。1 つは実行可能な高さ用、もう 1 つは実行可能な傾斜用です。 最初に、前の勾配範囲からの一次差分制約と二次差分の伝播の両方を使用して、勾配間隔が更新されます。 次に、高さの間隔がそれに応じてシフトされ、許容範囲と交差します。 

微妙な点は、傾斜伝播が直接伝播と交差する必要があることです。$y_i$位置を更新するために使用される前の制約。 そうしないと、到達可能な高さを過大評価し、実行不可能な構成を誤って存続させる可能性があります。 

更新の順序が重要なのは、勾配の実現可能性によって到達可能な変位が定義され、その後でのみ位置の実現可能性を安全にチェックできるためです。

 ## 特殊なケース

 重大なエッジケースは、すべての場合に発生します。$b_i$間隔は単一の値に折りたたまれます。 その状況では、アルゴリズムは、すべての誘導された傾きと 2 番目の差が固定ジオメトリと一致しているかどうかを効果的にチェックします。 間隔更新は、必要な傾きが固定差と矛盾する場合に不一致を即座に検出し、早期に拒否を引き起こします。 

もう1つのケースは、坂路間隔は広いが、秒差が狭い場合です。 各ステップは個別に多くの勾配を許可しますが、勾配間隔の伝播により、収束または空の交差が発生するまで勾配間隔が徐々に縮小していきます。 これにより、長距離にわたる隠れた不整合が防止されます。 

3 番目のケースは、2 番目の差がどこでもゼロである場合です。 その場合、傾きは一定のままでなければならず、アルゴリズムは、単一のアフィン数列がすべての位置間隔内に収まるかどうかをチェックすることに帰着します。 区間の伝播は当然ながら一定の傾き帯域を維持し、実現可能性は純粋に変換された区間の重なりによって決まります。
