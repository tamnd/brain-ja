 ## 問題の理解

 番号を見つけるように求められます$x \ge 2$指定された配列内のすべての数値が$a$から生成できます$x$特別な加算ルールを使用します。 このルールにより、繰り返し追加することができます。$x$目標数に達するまで、その約数の 1 つが 2 以上である必要があります。 たとえば、3 から始めて、3 自体を加算して 6 を取得し、次に 2 (6 の約数) を加算して 8 を取得できます。つまり、3 は 8 の生成関数です。$x$これは配列のすべての要素に対して同時に機能します。そうでない場合は -1 を報告します。$x$存在します。 

入力は最大です$10^4$すべてのテスト ケースの配列サイズの合計は最大で$10^5$。 各配列要素は最大でも$4 \cdot 10^5$。 これにより、配列の合計サイズがほぼ線形または線形的なアルゴリズムに制約されるため、すべての候補を試す単純な総当たりアプローチが必要になります。$x$すべての目標は実行不可能です。 

配列内の数値が [2, 3, 4, 5] のような連続した小さな整数である場合、微妙なエッジ ケースが発生します。 このようなシナリオでは、どんな小さなことでも、$x$いくつかの数値を生成しても、他の数値では失敗する可能性があります。 単純に最小値または最大値を候補として選択すると誤った結果が生じることが多いため、最小の候補を特定する原則に基づいた方法が必要です。 

もう 1 つの特殊なケースは、すべての数値が共通の因数を共有する場合です。 たとえば、[6, 12, 18] は 6 から生成できますが、不用意に実装すると、より小さい値を試行する可能性があります。$x$2 と同様に、除数の制約により 18 を効率的に生成できません。 

## アプローチ

 ブルートフォースソリューションでは、考えられるすべてのことを繰り返すことになります。$x \ge 2$配列内の最小要素まで。 それぞれについて$x$、すべての生成プロセスをシミュレートします。$a_i$配列内で。 これには、次のいずれかに達するまで約数を繰り返し加算することが含まれます。$a_i$またはオーバーシュートします。 この方法は原理的には正しいですが、遅すぎます。 最悪の場合、加算の数は次の値に比例する可能性があります。$a_i$、そして最大で$10^5$操作数は超過する可能性があります$10^{10}$、これは受け入れられません。 

最適化するための重要な観察は、生成を逆に推論できることです。 もし$x$生成する$y$、 それから$y - x$から始まる何らかの約数のシーケンスで割り切れる必要があります。$x$。 これは、すべての数値から最小の候補を引いた最大公約数 (GCD) が、可能性のあるものに対して強力なフィルターを提供することに注意するのと同じです。$x$。 具体的に挙げると、$x$配列内の最小の数値、またはソートされた配列内の連続する数値の差の GCD である場合、これが次の値であるかどうかを確認できます。$x$確かに、すべての数値のジェネレーターです。 洞察としては、数値間の違いによって追加できる約数に制約が課せられ、GCD はそれらの制約を 1 つの候補に凝縮するということです。$x$。 

配列をソートし、最小要素と他の各要素の差を計算し、これらの差の GCD を計算して、GCD を引いた最小要素が少なくとも 2 であり、ジェネレータとして機能できるかどうかを検証できます。 これにより、検索スペースが減少します。$O(a_i)$要素ごとに少数の候補を絞り込み、ソリューションを実現可能にします。

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、配列を読み取ります。$a$そしてそれを昇順に並べ替えます。 並べ替えにより、数値間の差異を推論できるようになり、GCD 計算が簡素化されます。 
2. ソートされた配列の連続する要素間の差分を計算します。 させて$d_i = a_{i+1} - a_1$みんなのために$i \ge 2$。 これらの違いは、それぞれのレベルに達するまでに必要な追加のステップの合計を表します。$a_i$小さい数字から。 
3. すべての差の GCD を計算する$d_i$。 この GCD は、すべての差を均等に分割する最大のステップ サイズを表し、候補が確実に得られるようにします。$x$それはすべてを生み出す可能性があります$a_i$。 
4. 検討する$x = a_1 - \text{GCD}$。 もし$x \ge 2$、すべて生成できるかどうかを確認します$a_i$それぞれの違いを検証することで、$a_i - x$から始まる何らかの約数列で割り切れます。$x$。 実際には、私たちが選択したため、$x$差分の GCD に基づいて、このチェックは次の場合に自動的に合格します。$x \ge 2$。 
5. もし$x < 2$または無効です$x$存在する場合は -1 を返します。 それ以外の場合は戻ります$x$。 

機能する理由: GCD は、許可された加算演算を使用して、配列内のすべての数値に到達するために必要な最小限のステップをカプセル化します。 選択する$x$として$a_1 - \text{GCD}$GCD の倍数を使用してすべてのターゲットに到達できる番号から開始するようにします。 不変条件は、配列内のすべての数値からマイナスされることです。$x$は GCD で割り切れるので、各数値に達するまで除数の加算を順序付けできることが保証されます。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        if n == 1:
            print(a[0])
            continue
        a.sort()
        diff_gcd = 0
        for i in range(1, n):
            diff_gcd = math.gcd(diff_gcd, a[i] - a[0])
        x = a[0] - diff_gcd
        print(x if x >= 2 else -1)

solve()
```最初の部分では、複数のテスト ケースを処理し、配列を読み取ります。 最小限の要素を特定するにはソートが必要です。 このループは差分の GCD を計算し、すべての制約を 1 つの候補に凝縮します。 最後に、最小の数値からこの GCD を減算して、$x$そして、それが最小許容値の 2 を満たしていることを確認してください。
