 ## 問題の理解

 すべてゼロから始まる整数の配列の重み付き合計を最大化するように求められます。 配列には長さがあります$n$そして受け取ります$m$これらの操作の後、Kevin は任意の数の追加のプレフィックスまたはサフィックスの追加を実行できます。 与えられた目標値に対して$v$、要素は対応する重みに寄与します。$c_i$その価値が等しい場合にのみ、完全な美しさへ$v$。 タスクは、それぞれについて計算することです。$v$1から$V$、ケビンが最適な状態を続ければ、達成可能な最大の美しさ。 

制約が示すのは、$n$そして$m$と同じ大きさにすることができます$2\cdot 10^5$したがって、考えられるすべての操作シーケンスを反復する解決策は不可能です。 さらに、$V$最大 2000 まで可能です。$V^2$すべてのテスト ケースにわたって、次のことに限定されます$4 \cdot 10^6$、アルゴリズムが複雑であることを示唆しています。$O(n V)$許容されます。 

エッジ ケースには、長さが 1 の配列、すべての重みが等しい配列、または初期操作によって一部の要素が既にそれを超えているシナリオが含まれます。$V$。 単純な実装では、すでに目標を超えている要素を適切に考慮していない場合、美しさを誤ってカウントする可能性があります。$v$そして減らすことはできません。 

## アプローチ

 ブルート フォース アプローチは概念的には単純です。アレイを構築するための初期操作をシミュレートします。$a$、それぞれについて$v$1から$V$、正確に到達するまで、プレフィックスとサフィックスの追加シーケンスをすべて試してください。$v$各インデックスで。 このアプローチは正しいですが、加算シーケンスの数が指数関数的に増加するため、まったく実行不可能です。$n$そして追加の数。 インデックスごとに 1 つの操作を試行することに限定したとしても、最悪の場合の複雑さは次のとおりです。$O(n^2 V)$、これは大きすぎます$n \sim 2 \cdot 10^5$。 

重要な点は、任意の数のプレフィックスとサフィックスの追加を、連続した範囲に追加する非負の整数として表現できることです。 具体的に定義しましょう$a_i$初期操作後。 作るには$a_i$その通り$v$, Kevin は追加の加算を実行する必要があります。$a_i + \text{additional}_i = v$。 プレフィックスとサフィックスの追加は範囲に影響を与えるため、操作を選択すると、増加する連続範囲を選択することになります。 これにより、問題は重みの最大合計に縮小されます。$c_i$そのような範囲にわたって$a_i \le v$まで増分できます$v$。 

形式的には、$d_i = v - a_i$。 要素$i$美しさに貢献できるなら$d_i \ge 0$。 したがって、達成可能な最大の美しさは、次の最大の合計です。$c_i$ある範囲の要素にわたって、対応する$d_i$は非負です。 接頭辞と接尾辞の追加を使用して、連続した範囲を増分できるため、インデックスの連続した部分列を選択できます。$d_i \ge 0$そして、それらを正確に実現するために必要な数の操作を追加します。$v$。 これにより、次のように答えを計算できるようになります。$O(n)$値ごと$v$Kadane のアルゴリズムのバリアントを使用します。

 ## アルゴリズムのチュートリアル

 1. 配列を初期化する$a$長さのあるゼロの$n$。 を繰り返します$m$初期操作。 インデックスでのタイプ L の各操作について$x$、インデックス 0 の差分配列を 1 ずつインクリメントし、インデックスでデクリメントします。$x$by 1. インデックスでのタイプ R の各演算について$x$、インデックスで増分$x-1$インデックスでのデクリメント$n$。 差分配列を実際の配列に変換します$a$プレフィックスの合計を取得します。 このステップでは、すべての初期操作を O(n + m) で効率的にシミュレートします。 
2. 各目標値について$v$1から$V$、計算する$d_i = v - a_i$。 もし$d_i < 0$、 要素$i$到達できない$v$美しさへの貢献はゼロです。 それ以外の場合は、その重量$c_i$合算が可能です。 
3. 最大部分配列合計アルゴリズムを適用します。$c_i$インデックスに限定されます。$d_i \ge 0$。 累積合計ゼロから開始し、配列を反復処理します。$d_i < 0$、累計をゼロにリセットします。 それ以外の場合は追加します$c_i$現在の合計を計算し、発生した最大合計を追跡します。 
4. ステップ 3 で求めた最大合計が、この問題の答えになります。$v$。 全員に繰り返します$v$1から$V$。 

これが機能するのは、連続するインデックスの範囲を調整して、$v$プレフィックスとサフィックスの追加を使用します。 ステップ 1 の差分配列により、初期操作が確実に尊重されます。 サブ配列の合計を最大化することで、インデックスのサブセットを最適に選択し、範囲を超えずに美しさを最大限に高めることができます。$v$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, V = map(int, input().split())
        c = list(map(int, input().split()))
        diff = [0]*(n+1)
        for _ in range(m):
            op, x = input().split()
            x = int(x)
            if op == 'L':
                diff[0] += 1
                diff[x] -= 1
            else:
                diff[x-1] += 1
                diff[n] -= 1
        a = [0]*n
        curr = 0
        for i in range(n):
            curr += diff[i]
            a[i] = curr

        result = []
        for v in range(1, V+1):
            max_beauty = 0
            curr_sum = 0
            for i in range(n):
                if a[i] > v:
                    curr_sum = 0
                else:
                    curr_sum += c[i]
                    if curr_sum > max_beauty:
                        max_beauty = curr_sum
            result.append(str(max_beauty))
        print(' '.join(result))

if __name__ == "__main__":
    solve()
```このソリューションでは、最初の操作後に差分配列を使用して配列を構築し、プレフィックスとサフィックスの増分を効率的に処理します。 次に、それぞれの値について$v$要素を反復処理し、すでに超えている要素をスキップすることで最大の美しさを計算します。$v$、そして累計を使用して最良の連続サブシーケンスを追跡します。 これにより、追加の操作を明示的にシミュレートすることが回避され、それぞれの操作に最適な美しさが保証されます。$v$。
