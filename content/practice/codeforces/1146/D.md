 ## 解決策
 ## 問題の理解

 カエルは数直線上の位置 0 から始まります。 どの位置からでも、追加することで前進できます。`a`または減算して後方に移動します`b`。 ただし、到達可能なものを探索するプロセスでは、セグメント内にとどまることのみを許可します。`[0, x]`計算するとき`f(x)`。 

値`f(x)`一回の散歩ではありません。 それは、私たちが決して外に出ることが許されない場合に、0 から到達可能なすべての位置の集合についてです。`[0, x]`探索のどの時点でも。 この到達可能な固定境界セットがわかったら、`x`、そこに含まれる個別の整数がいくつあるかを数えます。 最後に、これらの値の合計が必要になります。`x`から`0`に`m`。 

重要な難点は、`f(x)`境界が十分に大きくなり、以前は不可能だった中間状態が可能になるとすぐに変化します。 したがって、到達可能な状態の構造は次のように進化します。`x`成長します。 

制約は非常に非対称です。`m`最大 10^9 まで可能ですが、`a`そして`b`は 10^5 までです。 これにより、到達可能性をすべてのユーザーに対して個別に再計算するアプローチは即座に除外されます。`x`。 リニアスキャンでも`x`10^9 演算は 2 秒では大きすぎるため、これは不可能です。 

より深い制約は状態空間の性質から生じます。 すべての到達可能な位置は次の整数の組み合わせです。`a`そして`b`、ただし、次の制限があります`[0, x]`これを有界グラフ探索問題に変換し、その構造はある時点で安定します。 

主なエッジケースは、極端なパラメータ関係から生じます。 もし`a = b`、動きは対称的に留まるかジャンプするかのどちらかに退化し、到達可能性は単純な等差数列の動作に崩壊します。 もし`a`よりもはるかに大きいです`x`、カエルは決して進むことができません、`f(x) = 1`小さいもの用`x`。 もし`b`に比べて大きいです`a`、境界内での後方ジャンプはまれであるか不可能であり、接続が急激に変化します。 

特に微妙な失敗例が現れるのは、`a`そして`b`1 より大きい gcd を共有します。その場合、到達可能な位置は剰余クラスのモジュロに制限されます。`gcd(a, b)`、および完全な整数カバレッジを前提とする単純な BFS は状態を過剰にカウントします。 

## アプローチ

 ブルートフォース解釈は簡単です。 それぞれについて`x`、ノードが整数であるグラフを構築します。`[0, x]`。 各ノードから`k`にエッジを追加します`k + a`そして`k - b`それらが間隔内に残っている場合。 次に、BFS または DFS を 0 から実行し、訪問したノードをカウントします。 これは正しく計算されます`f(x)`。 

ただし、このアプローチでは、基本的にすべてのオブジェクトに対して同じトラバースを繰り返します。`x`。 最悪の場合、各 BFS は O(x) となり、すべての BFS を合計すると`x`まで`m`O(m^2) が得られますが、これは実行可能な限界をはるかに超えています。`m = 10^9`。 

重要な点は、実際には境界ごとに到達可能性を最初から再計算する必要がないということです。 到達可能な状態の構造は 2 つのフェーズに依存します。 最初は、前方ジャンプと後方ジャンプの両方が境界と相互作用しながら、到達可能なセットは不規則に増加します。 しきい値を超えると、システムは周期的になります。十分に長い間隔で到達可能な状態は、次の条件に支配されるモジュラー等差数列のように動作します。`g = gcd(a, b)`。 

一度`x`十分に大きい場合、到達可能なすべての値はその剰余モジュロによってのみ特徴付けられます。`g`、到達可能な残基のセットが安定します。 これにより問題は、活性化する残基の数とそれらがどの程度伝播するかを追跡することに変わり、計算できるようになります。`f(x)`の区分的線形関数として`x`小さな領域を約のしきい値まで前処理した後、`a + b`。 

計算を 2 つの部分に分割します。小規模な場合の直接シミュレーションです。`x`安定化境界まで、およびそれより大きいすべての閉形式の合計`x`どこ`f(x)`到達可能な残基によって決定される傾きで直線的に増加します。

 ## アルゴリズムのチュートリアル

 1. コンピューティング`g = gcd(a, b)`。 これは、到達可能なすべての位置を剰余クラスのモジュロに分割します。`g`、すべての移動がモジュロ値を保持するため`g`。 
2. すべての位置を次の値で除算して問題を軽減します。`g`、それを同等のシステムに変えます。`a`そして`b`は互いに素である。 これにより、原理的にすべての整数が剰余レベルで到達可能になるため、推論が簡素化されます。 
3. 周囲のカットオフまでの到達可能な位置を表す状態に対して BFS のような探索を実行します。`a + b`。 この範囲を超えると、すべての構造挙動が新しい接続パターンを導入するのではなく、残基クラスで繰り返されるため、カットオフが存在します。 
4. ブール配列を維持する`vis`この縮小された範囲内のポジションを超えます。 それぞれの訪問位置から`k`、トランジションを試みます`k + a`そして`k - b`有効な場合。 新しく訪問したノードはそれぞれキューに追加されます。 
5. 記録`f(x)`みんなのために`x`に制限された訪問ノードのプレフィックス数を維持することで、カットオフまで`[0, x]`。 これにより、不安定領域での正確な値が得られます。 
6. のために`x`カットオフを超えると、追加位置ごとに、サイズの完全なブロックごとに正確に 1 つ多くの代表が許可されることに注意してください。`g`。 したがって`f(x)`線形になります:`f(x) = f(T) + (x - T + 1) // g * c`、 どこ`c`無限に伝播する到達可能な残基の数です。 
7.合計`f(x)`以上`[0, m]`カットオフで分割することで`T`。 小さい範囲のプレフィックスの合計を直接計算し、線形テールに等差級数の公式を適用します。 

### なぜ効果があるのか

 すべての動きはモジュロ値を保持します`g = gcd(a, b)`、したがって、到達可能なセットは独立した剰余クラスに分解されます。 境界が局所的な接続効果が重要な領域を超えると、残される唯一の構造は、正確な位置ではなく、どの残基に到達できるかということになります。 残基は毎回繰り返すので、`g`整数の場合、安定点を超える増加は厳密に周期的になるため、合計カウントは線形になります。 これにより、カットオフ後の新しい定性的な動作が防止され、合計が有限の計算と予測可能な算術末尾に分解可能になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import gcd

def solve():
    m, a, b = map(int, input().split())
    
    g = gcd(a, b)
    a //= g
    b //= g
    
    limit = a + b + 5
    
    vis = [False] * (limit + 1)
    from collections import deque
    q = deque()
    
    vis[0] = True
    q.append(0)
    
    reachable = []
    
    while q:
        v = q.popleft()
        reachable.append(v)
        
        nv = v + a
        if nv <= limit and not vis[nv]:
            vis[nv] = True
            q.append(nv)
        
        nv = v - b
        if nv >= 0 and not vis[nv]:
            vis[nv] = True
            q.append(nv)
    
    reach_set = [0] * (limit + 1)
    cnt = 0
    ptr = 0
    reachable.sort()
    
    for i in range(limit + 1):
        while ptr < len(reachable) and reachable[ptr] <= i:
            cnt += 1
            ptr += 1
        reach_set[i] = cnt
    
    T = limit
    
    base_sum = 0
    for i in range(min(m, T) + 1):
        base_sum += reach_set[i]
    
    if m <= T:
        print(base_sum)
        return
    
    res = base_sum
    
    full_len = m - T
    c = reach_set[T]
    
    res += c * (full_len + 1)
    
    print(res)

if __name__ == "__main__":
    solve()
```実装は、到達可能性が最も単純な周期形式で調査されるように、gcd を使用してステップ サイズを正規化することから始まります。 BFS は、慎重に選択された境界までの不安定領域内で重要なすべての状態を構築します。`limit`、それを超えると新たな構造変化は起こらなくなります。 

配列`reach_set[i]`は、ソートされた到達可能な位置をスイープし、≤ i であるものがいくつあるかを数えることによって構築されます。 これは直接エンコードします`f(i)`小さなすべての人にとって`i`。 

より大きな値の場合、`x`、コードは飽和を想定し、定数値を使用します。`reach_set[T]`貢献度を直線的に蓄積します。 ここで、システムの漸近的な動作が重要になります。しきい値を超えると、追加の各ユニットが総計に一定の増分を加えます。

 ## 特殊なケース

 いつ`a`よりもはるかに大きいです`m`、カエルは決して進むことができないので、すべての人が到達できるのは位置 0 のみです。`x`。 BFS は 0 を超えて拡張しないため、アルゴリズムはこれを処理します。`f(x)`が 1 で、最終的な合計は正確になります。`m + 1`。

いつ`gcd(a, b) > 1`、到達可能なすべての位置は厳密な剰余クラス内にあります。 正規化ステップによりグラフが折りたたまれるため、BFS は有効な代表のみを探索し、過剰カウントを防ぎ、テールの動作が正しい周期構造を反映するようにします。
