 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、$n$3 つの点が同一線上にないことが保証されます。 これらの点から、点が特定の非凸順序で接続されている星形の構成である五芒星を形成できる 5 点のサブセットの数を数えたいと思います。 セグメントの正確な長さは重要ではありません。 重要なのは、線の交差パターンが星形と一致することです。 

入力は次のもので構成されます$n$それぞれの点の間で区切られた整数の座標を持つ点$-10^6$そして$10^6$。 出力は単一の整数、つまり存在する五芒星の数です。 

まず最初に気づくことは、$n$すべての 5 点サブセットをチェックする単純なアプローチでは、次のことが必要になります。$\binom{300}{5} \approx 2.4 \times 10^9$繰り返し。 これは 4 秒の制限時間をはるかに超えているため、すべての 5 つ組を直接検査するアルゴリズムは直ちに実行不可能になります。 すべての組み合わせを明示的に列挙することを避けるために、幾何学的特性を活用するアプローチが必要です。 

明らかではないエッジ ケースには、部分凸性または共線性を満たす可能性のある、縮退したように見えるサブセットが含まれます。 たとえば、4 つの点が凸四角形を形成し、1 つの点が内側にある場合、どのサブセットが実際に星型を作成するために交差する対角線を生成するかをアルゴリズムが区別することが重要です。 不用意に組み合わせて使用​​すると、これらの構成が過剰にカウントされる可能性があります。 

## アプローチ

 ブルート フォース アプローチの説明は簡単です。5 つの点のすべての組み合わせを生成し、それが五芒星を形成するかどうかを確認します。 指定された 5 タプルの五芒星を正しく検出するには、凸包に沿った点の順序をチェックし、セグメントの交差を確認する必要があります。 高速な幾何学的述語を使用した場合でも、このアプローチはおおよそのパフォーマンスを発揮します。$O(n^5)$不可能な操作$n = 300$。 

より高速な解決策を明らかにする重要な観察は、五芒星がその凸包によって完全に決定されるということです。 任意の 5 点の場合、凸包は五角形 (包面上の 5 点すべて) または厳密に内側に 1 点がある四角形のいずれかになります。 星型パターンは、凸包が五角形の場合にのみ発生します。 1 つの点が内側にある場合、五芒星に必要な正しい交差パターンを生成できません。 これにより、考慮すべき候補サブセットの数が大幅に減少します。 

この観察により、凸包がちょうど 5 つの点を持つ 5 つの点のすべてのサブセットを数えることができます。 これを効率的に行う 1 つの方法は、すべての点を反復処理し、任意の 2 点を結ぶ線の左側または右側にある点の数を計算することです。 組み合わせ幾何学を使用すると、エッジごとに、内部点のない五角形を生成するために点を組み合わせる方法の数を数えることができます。 このアプローチにより、実質的な複雑さはおよそ次のように軽減されます。$O(n^3)$、これは実現可能です$n = 300$。

 ## アルゴリズムのチュートリアル

 1. 順序付けされた点のペアごとに$(i,j)$、厳密に有向線の左側にある点の数を計算します。$i \to j$。 これをテーブルに格納します`left[i][j]`。 これにより、任意のペアについて、線の片側の五角形に参加できる点の数を決定できます。 
2. 点のすべてのトリプルを反復処理します。$(i,j,k)$。 事前計算されたものを使用する`left`テーブル、三角形の片側にいくつの点があるかを決定します。$(i,j,k)$。 これらのトリプルは、潜在的な五芒星の部分的な凸包エッジとして機能します。 
3. 5 点の凸包を完成させるために 2 つの追加点を選択できる方法の数を数えます。 これには基本的な組み合わせ論が含まれます。$m$側面に点があります$\binom{m}{2}$2つのポイントを選択する方法。 
4. すべてのトリプルのカウントを累積します。 有効な各五芒星は対称性により複数回カウントされるため、最後に適切なオーバーカウント係数 (この場合は 5) で除算します。 
5. 合計数を出力します。 

機能する理由: 凸包のプロパティにより、包上に 5 つの点を持つサブセットのみが五芒星を形成できることが保証されます。 エッジの各側の点の数を数え、それらを組み合わせて組み合わせることで、正規化後にすべての有効な 5 点の五角形が正確に 1 回カウントされるようになります。 左側/右側のカウントにより、内部点が誤って含まれないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from itertools import combinations

def cross(a, b, c):
    # cross product of AB x AC
    return (b[0]-a[0])*(c[1]-a[1]) - (b[1]-a[1])*(c[0]-a[0])

def solve():
    n = int(input())
    points = [tuple(map(int, input().split())) for _ in range(n)]
    
    left = [[0]*n for _ in range(n)]
    
    for i in range(n):
        for j in range(n):
            if i == j:
                continue
            cnt = 0
            for k in range(n):
                if k != i and k != j:
                    if cross(points[i], points[j], points[k]) > 0:
                        cnt += 1
            left[i][j] = cnt
    
    total = 0
    for i in range(n):
        for j in range(n):
            if i == j:
                continue
            for k in range(j+1, n):
                if k == i:
                    continue
                # use combinatorics based on left counts
                a = left[i][j]
                b = left[j][k]
                c = left[k][i]
                # number of pentagons with this triangle as part
                total += a * b * c
    
    # divide by overcount factor
    print(total // 5)

solve()
```コードは最初にすべてのエッジの左側のカウントを計算します。 これらのカウントにより、結合ステップで五角形に追加できる点の数を知ることができます。 トリプルループはすべての三角形を構築し、`a * b * c`counts the number of ways to select two additional points to form a 5-point hull. Dividing by 5 accounts for symmetric overcounting across rotations of the pentagon.
