 ## 解決策
 ## 問題の理解

 問題の難易度のリストが与えられ、そのサブセットを破棄して、残りを任意に並べ替えることができます。 並べ替えた後は、隣接するすべてのペアの違いが最大でも異なるという意味で、シーケンスが「滑らか」であることが必要です。$k$。 

目標はシーケンス自体を構築することではなく、そのような順序が存在するようにできるだけ多くの問題を保持することです。 同様に、有効なシーケンスに配置できる、保持できる要素の最大数を見つけて、それを次の式から減算します。$n$。 

並べ替えの自由に隠された重要な観察は、隣接性の制約は、最大でもサイズのステップで値を接続できるかどうかにのみ依存するということです。$k$、元の位置ではありません。 

制約から、$n$まで可能です$2 \cdot 10^5$したがって、単一のテスト ケース内の二次関数はすでに遅すぎます。 ソートベースまたはリニアスキャンソリューションが期待されています。 値が上がるので、$10^9$、頻度配列や直接インデックス付けに依存することはできません。 

微妙な失敗例は、値が「ほぼ接続されている」にもかかわらず、中間要素をスキップする必要がある場合に発生します。 

たとえば、次の場合$k = 2$そして値は$[1, 10, 11, 12]$、単純な考えでは、1 から貪欲に拡張しようとするかもしれませんが、10、11、12 が長い有効なブロックを形成している場合でも、1 は 10 に接続できません。 正しい答えは、連続した値が一定の距離内に収まる最大の構造を特定するかどうかによって異なります。$k$、任意の点から開始するのではありません。 

もう 1 つの落とし穴は、グローバルな順序を保持するか、遷移をシミュレートする必要があると想定していることです。 再配置は自由であるため、問題は、制限されたギャップを持つチェーンに配置できるマルチセットを選択することになります。 

## アプローチ

 ブルートフォースビューでは、問題のすべてのサブセットを試し、サブセットごとにそれらをある順序で並べて、隣接するすべての差異が範囲内にあるかどうかを確認します。$k$。 固定サブセットのチェックが重要であると仮定しても、$O(n \log n)$ソート後のサブセットの数は次のようになります。$2^n$、でもそれは不可能です$n = 40$。 これにより、列挙ではなく構造的な削減が必要であることが明らかになります。 

重要な洞察は、配列を並べ替えることから得られます。 ソート後は、ソートされた順序で連鎖できる要素を選択することで有効な配置を作成する必要があります。 選択した 2 つの要素が以上異なる場合$k$、中間値を挿入するとギャップが悪化するだけであるため、他の場所で単調性を壊さずに有効な順序でそれらを隣接させることはできません。 

したがって、問題は、ソート後に、選択された連続する要素の差異が最大で最大となるような最大のサブセットを見つけることになります。$k$。 これは、ギャップ ≤ を維持しながら横断できる最長のセグメントを見つけることと同じです。$k$ただし、工夫が必要です。要素をスキップすることができるので、実際には「隣接するチェーン間の差 ≤ k」という関係に基づいて最大の連結成分を探します。 

ソートされた順序で、エッジがインデックスを接続するグラフを構築することを考えることができます。$i, j$もし$a_j - a_i \le k$。 構造は単調なので、スライディング ウィンドウを使用できます。右ポインタを移動すると、接続が維持される範囲内に左ポインタが確実に留まります。 私たちができる最善のことは、連続して保持される要素間の最大ギャップが ≤ である最大のウィンドウを維持することです。$k$。 

これは、ソートされた配列を、隣接する差分が ≤ である連続セグメントにグループ化することになります。$k$。 各セグメント内にすべての要素を保持できます。 セグメント間ではギャップを埋める要素がないため、セグメントは独立しています。 

したがって、答えは次のとおりです$n - \max(\text{size of a segment where consecutive differences} \le k)$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^n \cdot n \log n)$|$O(n)$| 遅すぎる |
 | 最適 |$O(n \log n)$テストごと |$O(1)$番外編 | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 難易度の配列を降順でない順に並べ替えます。 

最適な配置における隣接関係は常に昇順を尊重するため、ソートが必要です。 遠く離れた値を混在させる並べ替えはギャップを埋めるのに役立ちません。 
2. ソートされた配列をスキャンし、連続する各差分が最大である最長の連続ブロックを追跡します。$k$。 

このブロックは、制約を破ることなくすべての要素を順番に配置できるグループを表します。 
3. 現在のセグメント長を維持し、ギャップが より大きくなるたびにリセットします。$k$が表示されます。 

大きなギャップは硬い障壁として機能し、有効な隣接関係はそれを越えることができません。 
4. スキャン中に確認された最大セグメント長を維持します。 
5. 答えは次のとおりです。$n - \text{maximum segment length}$、達成可能な最良のブロックの外側にあるものはすべて削除されるためです。 

### なぜ効果があるのか

 ソート後の有効な取り決めでは、中間値がソート順で中間値の間に存在しない限り、大きなギャップを中間値で埋めることはできないという事実を考慮する必要があります。 これにより、有効な選択はすべて、連続する要素の差異が最大で異なる領域内に完全に収まるようになります。$k$。 ギャップを超えるたびに$k$、シーケンスは、どの順序でもマージできない独立したコンポーネントに分割されます。 したがって、最適解では、その中ですべての要素を制約に違反することなく連続して配置できるため、そのような最大のコンポーネントが維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        a.sort()
        
        best = 1
        cur = 1
        
        for i in range(1, n):
            if a[i] - a[i - 1] <= k:
                cur += 1
            else:
                best = max(best, cur)
                cur = 1
        
        best = max(best, cur)
        
        print(n - best)

if __name__ == "__main__":
    solve()
```このソリューションでは、最初に配列を並べ替えて、すべての潜在的な隣接関係がローカルになるようにします。 次に、単一の線形スキャンを実行し、隣接する各差分が許容しきい値内にある最大のセグメントに要素をグループ化します。$k$。 変数`cur`現在のセグメントの長さを追跡し、`best`遭遇したそのような最大のセグメントを追跡します。 

唯一の微妙な詳細は、ループ終了後の最後の更新です。これは、最後のセグメントが最大である可能性があり、そうでない場合は見逃されてしまうためです。

 入力:```

a = [1, 2, 4, 5, 6]
```ソート後 (すでにソート済み)、以下をスキャンします。 

| 私 | a[i] | 差分 | カー | 最高 |
 | --- | --- | --- | --- | --- |
 | 0 | 1 | - | 1 | 1 |
 | 1 | 2 | 1 | 2 | 1 |

 | 4 | 6 | 1 | 3 | 2 |

 最終的な最良のセグメントは 3 で、以下に対応します。$[4,5,6]$。 

答えは$5 - 3 = 2$。 

これは、1 や 2 のような孤立した小さな値が、禁止されたギャップによって分離されている場合には役に立たないことを示しています。

 ## 特殊なケース

 すべての要素が同一の場合、並べ替えではどこでも差分がゼロになるため、スキャンによって長さの単一セグメントが形成されます。$n$。 アルゴリズムは維持します`best = n`これは、出力 0 につながります。これは、すべての順序がすでにバランスされているという事実と一致します。 

いつ$n = 1$、ループは決して実行されません、そして`best`答えは 0 になり、自明な有効なラウンドと一致します。 

配列が大きなギャップによって分離された 2 つのクラスターに分割される場合、たとえば、$[1,2,3,100,101,102]$小さいもので$k$、スキャンにより 2 つのセグメントが生成されます。 ギャップを越えて隣接することはできないため、アルゴリズムは大きい方のみを正しく保持します。 

値が常により大きいギャップで交互に配置される場合$k$、すべての要素が独自のセグメントになります。 最大セグメント サイズは 1 であるため、答えは次のようになります。$n-1$、問題は 1 つだけ保持できることを反映しています。
