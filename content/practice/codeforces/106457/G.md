 ## 問題の理解

 この問題は輸送船団について説明しています。 船`i`積載能力がある`A_i`。 単一のクレート サイズを選択する必要があります`x`。 船は、その容量を正確なサイズの木箱に分割できる場合にのみ使用できます。`x`、したがって、船は次の場合にのみ貢献します。`A_i`の倍数です`x`。 

選択したクレート サイズに対して、エンパイアの支払いは、クレート サイズにそれを使用できる船の数を乗じたものになります。 数学的に言えば、次の値は`x`は：`x * (number of A_i values divisible by x)`タスクは、最大の支払いが得られるクレートのサイズを見つけることです。 複数のクレート サイズで同じ支払いが発生する場合は、最小のクレート サイズを選択する必要があります。 

入力には船舶の数とその能力が含まれます。 出力は最適なクレート サイズです。 

重要な制約は、最大で`10^6`船、およびすべての容量は最大です`10^6`。 すべての船舶に対して可能なすべてのクレート サイズをチェックするソリューションは、次のようなパフォーマンスを発揮します。`10^12`最悪の場合、通常の 1 秒の制限をはるかに超えた操作が可能になります。 船舶の数ではなく、収容力の小さな最大値を活用する必要があります。 

主なエッジ ケースは、ネクタイと、約数として表示されるものの、最も頻度が高いわけではないクレート サイズに由来します。 

たとえば、入力が次の場合:```
3
2 4 6
```正しい出力は次のとおりです。```
3
```クレートのサイズ`2`3 隻すべてで機能し、`2 * 3 = 6`。 クレートのサイズ`3`容量のある船のみで動作します`6`、与える`3 * 1 = 3`, したがって、この例では同点は生成されません。 最大値の約数のみを調べる不注意な実装では、より小さい約数の中からより適切な候補を見逃してしまう可能性があります。 

ネクタイケースは次のとおりです。```
4
2 4 6 8
```正しい出力は次のとおりです。```
4
```木箱のサイズ`2`与える`2 * 4 = 8`、およびクレートのサイズ`4`与える`4 * 2 = 8`。 どちらも同じ配当なので、小さい方のクレート サイズを選択する必要があり、答えは次のようになります。`2`。 スコアが等しい場合に常に回答を更新する不用意な実装では、現在の回答を後の候補に置き換えると、間違った値が返されます。 

最小サイズのケースは次のとおりです。```
1
1000000
```答えは次のとおりです。```
1000000
```唯一の船を数える必要があり、その全容量を木枠サイズとして使用できます。 

## アプローチ

 直接的な解決策としては、考えられるすべてのクレート サイズを試すことになります。`x`。 それぞれについて`x`、すべての船をスキャンし、容量が何個で割り切れるかを数えます。`x`。 この方法は、考えられるすべての選択肢の正確な支払いを評価するため、正しいです。 ただし、`N = 10^6`、これには次までのチェックが必要になります。`10^6`最大値に対して可能な値`10^6`船、結果として約`10^12`可分性テスト。 

有益な観察は、容量も制限されているということです。`10^6`。 すべての船舶にクレート サイズを受け入れるかどうかを尋ねる代わりに、プロセスを逆にして、各クレート サイズの容量がその倍数であるかを尋ねることができます。 

させて`freq[v]`収容能力のある船舶の数とする`v`。 固定クレートサイズの場合`x`、使用可能な船の容量は次のとおりです。`x, 2x, 3x, ...`最大容量まで。 ふるいのようなループを使用して、これらの値の頻度を合計できます。 考えられる各クレート サイズは、その倍数にアクセスすることで処理されます。これは、すべての船を個別にチェックするよりもはるかに高速です。 

すべてのカウントを計算した後、`x`、ペイアウトを比較します`x * count`。 2 つのペイアウトが等しい場合、小さい方を維持します。`x`。

 ## アルゴリズムのチュートリアル

 1. 各容量を持つ船舶の数を数えます。 これを保管してください`freq`、 どこ`freq[v]`容量の何倍かを教えてください`v`が表示されます。 これにより、個々の船ではなく値を処理できるようになります。 
2. 可能なすべてのクレート サイズを反復処理します。`x`から`1`最大容量まで。 それぞれについて`x`、のすべての倍数の周波数を加算します。`x`。 これらはまさにクレートサイズで展開できる船です`x`。 
3. 支払いを次のように計算します。`x * count`。 これまでに確認された最高の配当よりも大きい場合は、答えを置き換えます。 同じ場合は、小さい方のクレート サイズを維持します。 
4. すべての候補をチェックした後、保存されているクレート サイズを出力します。 

なぜ効果があるのか:

 あらゆる可能なクレートサイズに対応`x`、アルゴリズムは、次の値で割り切れるすべての容量を訪問します。`x`したがって、計算された数は、その木箱サイズを使用できる船の数と正確に一致します。 したがって、支払いの計算は問題の定義と同じです。 可能な限り`x`が考慮され、最小値を維持することによって同点が処理されるため、最終的な答えは最適であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    mx = max(a)
    freq = [0] * (mx + 1)

    for value in a:
        freq[value] += 1

    best_x = 1
    best_value = 0

    for x in range(1, mx + 1):
        count = 0
        for multiple in range(x, mx + 1, x):
            count += freq[multiple]

        value = x * count

        if value > best_value:
            best_value = value
            best_x = x
        elif value == best_value and x < best_x:
            best_x = x

    print(best_x)

if __name__ == "__main__":
    solve()
```周波数配列には、入力範囲内に実際に存在する容量のみが格納されます。 その規模は船舶の数ではなく、最大の収容能力によって決まります。 

外側のループは、考えられるすべてのクレート サイズを試します。 内側のループはその倍数をたどって、その周波数を加算します。 これにより、船舶のリスト全体を繰り返しスキャンする必要がなくなります。 

同点条件は明示的に処理されます。 2 つのクレート サイズの配当が同じ場合、新しいクレート サイズの方が小さい場合にのみ、現在の回答が置き換えられます。 これにより、結果が反復順序に依存することがなくなります。 

Python の整数はオーバーフローしないため、乗算は`x * count`最大値でも安全です。 処理すべき唯一の境界ケースは最大容量そのものであり、これは周波数配列およびすべての複数ループに含まれます。
