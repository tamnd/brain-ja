 ## 解決策
 ## 問題の理解

 このタスクは基本的に、各船が異なる、空ではない船のサブセットを選択し、それらのサブセットのうち奇数のサイズを持つものがいくつあるかを数えるというものです。 

単一の整数が与えられます$n$、利用可能な個別の船の数を表します。 船舶のすべてのサブセットは、考えられる艦隊に対応します。 ただし、サイズが奇数のサブセットのみが有効とみなされます。 フリートには少なくとも 1 隻の船が含まれている必要があるため、空のサブセットは自動的に除外されます。 

したがって、問題は、サイズのセットのサブセットがいくつあるかを数えるということになります。$n$奇妙なカーディナリティーを持っています。 

生の列挙の観点から考えると、各船舶は含めることも除外することもできます。$2^n$サブセットの合計。 これらの中で、選択した要素の数が奇数であるものが正確に必要です。 

小さな例で構造を明確にします。 もし$n = 3$、サブセットは次のとおりです。$\{\}, \{1\}, \{2\}, \{3\}, \{1,2\}, \{1,3\}, \{2,3\}, \{1,2,3\}$。 

奇数サイズのサブセットはシングルトンとフルセットであり、次のようになります。$3 + 1 = 4$。 

制約により許可されるのは、$n \le 60$これにより、サブセットを明示的に列挙するアプローチは即座に除外されます。 平$2^{60}$計算の範囲をはるかに超えています。 指数関数的なものは何でも$n$定数時間式にしないと遅すぎます。 

微妙なエッジケースが現れるのは、$n = 1$。 唯一のサブセットは$\{1\}$サイズが 1 であるため、これは有効です。正解は 1 です。空のセットを誤って含めたり、パリティのカウントを誤ったりする単純な実装は、ここで失敗します。 

もう一つのケースは、$n = 2$。 サブセットは次のとおりです。$\{1\}, \{2\}$、どちらも有効であるため、答えは 2 です。これは、奇数と偶数のサブセット数の間の対称性をすでに示唆しており、これが重要な構造的洞察になります。 

## アプローチ

 ブルートフォースアプローチでは、すべてが生成されます。$2^n$サブセットを抽出し、サイズが奇数のものをカウントします。 概念的にはこれは簡単です。0 から 0 までのすべてのビットマスクを反復処理します。$2^n - 1$、セットされたビットをカウントし、パリティが奇数の場合は答えをインクリメントします。 これは正しいです。各サブセットが 1 回だけ表され、パリティが明確に定義されているからです。 

問題はランタイムです。 たとえ$n = 40$、$2^{40}$すでに約$10^{12}$実行可能な限界をはるかに超えた操作。 問題のサイズが 60 までなので、これはまったく使用できません。 

重要な観察は、有限集合のサブセットがパリティ クラス全体に均等に分布していることです。 各サブセットは、固定要素を切り替えることによってのみ異なる別のサブセットと組み合わせることができます。 このペアリングによりパリティが反転され、偶数サイズのサブセットと奇数サイズのサブセットの間に 1 対 1 の対応関係が作成されます。 

より具体的には、次のすべてのサブセットを考慮します。$n$要素。 サブセットを取ると$S$、最初の要素の存在を切り替えると、それが個別のサブセットにマップされます$S'$。 これらの 1 つは偶数サイズで、もう 1 つは奇数サイズです。 これにより、パワーセット全体がペアに分割されます。つまり、すべてのサブセットのちょうど半分が奇数サイズになります。 

あるので$2^n$サブセットの合計、正確には$2^{n-1}$それらのカーディナリティは奇数です。 

空のセットは、選択された要素を含むシングルトン セットとペアになっているため、この引数には影響しません。そのため、ペア構造ですでに考慮されています。

 | --- | --- | --- | --- |
 | ブルートフォース |$O(n 2^n)$|$O(1)$| 遅すぎる |
 | 最適 |$O(1)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る$n$、これは個別の船の数を表します。 
2. すべてのサブセットが船ごとの二者択一に対応していることを認識し、次のようにします。$2^n$サブセットの合計。 目的は、それらを列挙することではなく、奇数のサイズを持つものがいくつあるかを計算することです。 
3. 固定要素のメンバーシップを反転することでサブセットをペアにすることができるという構造的事実を利用します。これにより、偶数サイズと奇数サイズの均等な分割が保証されます。 
4. 有効なフリートの数は次のとおりであると結論付けます。$2^{n-1}$。 
5. 高速累乗またはビット シフトを使用して、この値を直接計算します。 

唯一の計算作業は 2 の累乗の評価であり、実装に応じて定数時間または対数時間で実行できます。 

### なぜ効果があるのか

 不変条件は、固定要素を切り替えると、偶数サイズのサブセットと奇数サイズのサブセット間の全単射が定義されるということです。 すべてのサブセットには、選択した要素が含まれるか含まれないかのどちらかがあり、そのメンバーシップを反転すると、衝突を引き起こすことなくパリティが変更されます。 このマッピングは可逆的であり、パワー セット全体をカバーするため、2 つのパリティ クラスは同じサイズでなければならず、それぞれにすべてのサブセットのちょうど半分が含まれるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input().strip())
print(1 << (n - 1))
```解決策は、代わりにビットシフトに依存します。`pow(2, n-1)`Python の整数は浮動小数点変換の問題を安全に処理できますが、その方が単純であり、浮動小数点変換の問題も回避できるからです。 シフトは直接構築します$2^{n-1}$。 

唯一の微妙な点は、$n = 1$、シフトは次のようになります$1 << 0 = 1$、正解と一致します。 

## 実用的な例

 ### 例 1: n = 3

 サイズパリティによってサブセットがどのように分割されるかを追跡します。 

| サブセットのサイズ | カウント |
 | --- | --- |
 | 0 | 1 |
 | 1 | 3 |
 | 2 | 3 |
 | 3 | 1 |

 奇数サイズのサブセットは、サイズ 1 と 3 のサブセットです。 

これは、ペアリングの直感を裏付けます。すべての偶数サブセットには、固定要素を切り替えることによって得られる、対応する奇数サブセットがあります。 

出力は$2^{2} = 4$。 

### 例 2: n = 4

 | サブセットのサイズ | カウント |
 | --- | --- |
 | 0 | 1 |
 | 1 | 4 |
 | 2 | 6 |
 | 3 | 4 |
 | 4 | 1 |

 奇数サブセットの合計$4 + 4 = 8$、一致します$2^{3}$。 

この例は、分布が次の条件に関係なく対称であることを裏付けています。$n$、小さなケースには依存しません。

 ## 特殊なケース

 のために$n = 1$、サブセットは 1 つだけ、つまり単一の船だけです。 アルゴリズムは計算します$2^{0} = 1$、サイズが奇数であるため、正しく有効としてカウントされます。 

より大きな値の場合、$n = 60$の場合、結果は非常に大きな整数になりますが、Python は任意精度の整数を処理するため、オーバーフローや精度の問題は発生しません。 計算は単一ビット シフトのままであるため、実行は定数時間であり、境界でも安定しています。
