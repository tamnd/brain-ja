 ## 問題の理解

 肉の量は均等ですが、`N`、そして2匹のワニ。 Vasya は 2 つの正の整数のピース サイズを選択します`A`そして`B`。 肉の合計は、各サイズの同じ数の部分で構成されている必要があります。`m`サイズの部分`A`そして`m`サイズの部分`B`、 それから`N = m(A + B)`。 

駒は毎回投げられます`K`秒順に`A, B, A, B, ...`。 ワニは、前の獲物を食べ終えた場合にのみ、新しい獲物を捕まえることができます。 両方のワニが同時にフリーになった場合、より強いワニがピースを獲得します。 1キログラムを食べるのにちょうど1秒かかります。 

正の整数を出力する必要があります`A`そして`B`2 匹のワニが食べた総量の差ができるだけ小さくなるようにする。 

バウンド`N <= 10^9`可能なピース サイズのすべてのペアを列挙することは直ちに除外されます。 の順序で存在する可能性があります`N^2`これは、1 秒のソリューションで検査できる範囲をはるかに超えています。 重要なのは、答えは方法によってのみ決まるということです`K`と比較する`N/2`そして`N-1`したがって、最終的なアルゴリズムには定数時間と定数メモリのみが必要です。 

不注意な解決策が誤って対処する可能性がある境界状況が 3 つあります。 のために`N = 4, K = 1`、選択する`A = B = 2`が最適です。 最初の部分は時間 0 で強いワニに捕らえられますが、時間 1 で 2 番目の部分が到着するとき、そのワニはまだ食べているため、弱いワニがそれを取得します。 同時フィニッシュを利用可能としてカウントするのではなく、ワニが次のスローの前に厳密にフィニッシュしたかどうかをチェックするシミュレーションは、このケースを誤る可能性があります。 

のために`N = 4, K = 2`、選択する`A = B = 2`食事のバランスが取れていない。 強いワニは 2 番目の駒を投げたときにちょうど終わるので、すぐに対象となり、その駒もキャッチします。 最適な施工は、`A = 3, B = 1`、強いワニには3キログラム、弱いワニには1キログラムを与えます。 境界での等価性が、一般的なオフバイワンエラーの原因となります。 

のために`N = 4, K = 3`、可能な限り大きな最初のピースでさえサイズが最大 3 であるため、どのピースも強いワニを 2 投目まで忙しくさせることはできません。`A = 1, B = 3`は有効ですが、強いワニは両方の部分をキャッチし、4キログラムすべてを食べます。 弱いワニが肉を与えなければならないと仮定した解決策は、不可能なバランスを誤って探求することになります。 

## アプローチ

 直接的なブルートフォース ソリューションでは、すべての正のペアを列挙できます。`(A, B)`、次のペアを拒否します。`A + B`分けない`N`、残りのペアごとにすべてのスローをシミュレートします。 各ワニの状態は、最後にピースを捕まえた時間とそのサイズによって完全に決定されるため、シミュレーションは正確です。 

問題は候補者の数だ。 ポジティブなものを単純に列挙すると`A`そして`B`と`A + B <= N`、 がある`1 + 2 + ... + (N - 1) = N(N - 1)/2`順序ペア、つまり約`5 * 10^17`いつ`N = 10^9`。 シミュレーション前に無効なペアを拒否しても、そのアプローチを実行可能にすることはできません。 

数字で見ると構造はもっと簡単になります`m`ペアのピース。 以来`N = m(A+B)`、 もし`m >= 2`、 それから`A + B <= N/2`。 

このたった 1 つの不平等が決定的です。 いつ`K >= N/2`、そのような構造の各ピースには最大でもサイズがあります`K`, そのため、駒をキャッチした後、強いワニは次のスローまでにフリーになります。 強いワニは自由なときに勝つので、すべての駒を捕まえます。 

したがって、いつ`K >= N/2`、弱いワニに肉を与えようとするあらゆる有益な試みは、次の方法を使用する必要があります。`m = 1`。 正確に 2 つのサイズのピースが存在します。`A`そして`B`、 と`A+B=N`。 最初のピースは強いワニに行きます。 2番目の部分は、最初の部分がまだ食べられている場合にのみ、弱いワニに行くことができます`K`、つまり`A > K`。 

これにより、最適化全体が可能な限り最小のものを選択することになります。`A`満足のいく`A > K`。 つまり`A = K+1`、与える`B = N-K-1`、 いつでも`K <= N-2`。 

いつ`K < N/2`、さらに良い可能性があります。 各サイズ1枚ずつお持ち帰り可能です`A = B = N/2`。 以来`A > K`、2枚目が到着しても強いワニはまだ忙しいです。 弱いワニがそれをキャッチするので、両方のワニが正確に受け取ります`N/2`キログラムであり、最適な差はゼロです。 

いつ`K >= N-1`、2ピース構造の可能な限り大きな最初のピースでも満足することはできません。`A > K`、 なぜなら`A <= N-1`。 弱いワニは何も受け取れないので、避けられない差は`N`。 使用できます`A = 1, B = N-1`、強いワニがすべてを食べるようにします。

 ## アルゴリズムのチュートリアル

 1. 比較する`K`と`N/2`。 もし`K < N/2`、 選ぶ`A = B = N/2`。 最初の部分は、強いワニを何時間も忙しくし続けます`K`秒なので、2番目の部分は弱いワニに行きます。 両方とも同じ金額を受け取ります。これは、絶対最小の差異であるゼロです。 
2. もし`K >= N/2`、どうかを検討してください。`K < N-1`。 この範囲内で選択してください`A = K+1`そして`B = N-K-1`。 最初の部分はより長く続きます`K`秒なので、2番目の部分が到着すると、強いワニは忙しいです。 弱いワニが 2 番目の部分を受け取ります。 以来`A`次のスロー以降も続く可能な限り最小の最初のピースです。これにより、結果として生じる差が最小限に抑えられます。`A-B`。 
3. もし`K >= N-1`、 選ぶ`A = 1`そして`B = N-1`。 強いワニは二投目前に一投目を終え、二投目もキャッチします。 それはすべてを食べる`N`キログラム、そして弱いワニに肉を与えることができない構造なので、これが最適です。 

### なぜ効果があるのか

 中心的な不変条件は、いつでも`A+B <= N/2`そして`K >= N/2`、可能なピースのサイズはどちらも最大です`K`, したがって、強いワニは次のスローで常にフリーになります。 その結果、各サイズの少なくとも 2 つのコピーを含むすべての構造は、すべてを強力なワニに供給します。 

いつ`K < N/2`、建設`A=B=N/2`差はゼロですが、これは改善できません。 いつ`K >= N/2`、少なくとも 2 つのペアを持つすべての構造はすべてを強いワニに供給するため、弱いワニに餌を与えることができる構造は各サイズのピースを 1 つずつ持たなければなりません。 2 つのピースがあると、弱いワニはちょうどそのときに 2 つ目のピースを受け取ります。`A>K`、したがって、可能な限り最小の有効な`A`は`K+1`。 これにより最小限に抑えられます`A-B`、各ブランチが最適な構造を返すことを証明しています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, K = map(int, input().split())

    if 2 * K < N:
        A = N // 2
        B = N // 2
    elif K < N - 1:
        A = K + 1
        B = N - K - 1
    else:
        A = 1
        B = N - 1

    print(A, B)

solve()
```最初のブランチは使用します`2 * K < N`の代わりに`K < N / 2`、浮動小数点演算を回避します。 以来`N`均等です、`N/2`は整数であり、厳密な不等式はまさにそのサイズの部分が満たされる条件です。`N/2`次の作品が到着してもまだ食べられています。 

2番目の支店では、`A = K+1`意図的に 1 つ大きいです`K`。 もし私たちが使っていたら`A = K`、強いワニは 2 投目で正確に最初のピースを終了し、それをキャッチする資格があります。 この問題は、フィニッシュとスローを同時に行うことでワニが新しいピースを試行できることを明確に示しています。 

表現`B = N-K-1`が正である一方で、`K < N-1`。 そのため、2 番目の支店は次の場所に止まります。`K = N-1`。 最後の分岐では、`A = 1`そして`B = N-1`両方とも正であり、合計は`N`、つまり、各サイズが 1 つずつ存在します。 

すべての値は最大でも`10^9`, そのため、Python の整数はあらゆる計算を簡単に処理できます。 シミュレーションは必要ありません。
