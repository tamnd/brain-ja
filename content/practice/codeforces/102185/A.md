 ## 問題の理解

 (N) 個のセルからなる円形の道路があります。 アリ番号 (i) は、ヘリコプターが現在待機しているセルから開始するため、すべてのアリが死ぬと、開始セルはちょうど 1 位置だけ進みます。 アリは最初、(K) 個の細胞を歩くのに十分な寿命を持っています。 キノコは、以前のアリが死んだ細胞に現れます。 アリがキノコに到達すると、それを食べてさらに寿命を延ばします。 (P)キノコを食べると、合計歩行距離は

 [
 S(P)=K+\left\lfloor\frac K2\right\rfloor+
 \左\lフロア\frac K3\右\rフロア+\ドット+
 \左\lf床\frac K{P+1}\右\r床。 
】

 アリが自分の開始セルに正確に戻るとすぐに、ミッションは成功します。 道路には (N) 個のセルがあるため、この問題は、道路の合計距離が (N) で割り切れる場合に正確に発生します。 そのアリの数が必要です。アリが成功しなかった場合は (-1) が必要です。 

境界は、セルまたは多数のアリに関するシミュレーションを除外するのに十分な大きさです。 (N) と (K) はどちらも (10^9) に達する可能性があるため、(O(N))、(O(K))、または (O(NK)) アルゴリズムでも使用できません。 ソリューションでは、プロセスを一定数の状態に減らす必要があります。 

1 つずつ間違いを犯しやすい場所がいくつかあります。 たとえば、入力の場合`7 4`、最初のアリは 4 回移動するため、セル 4 ではなくセル 5 で死にます。 2 番目のアリはセル 2 から開始し、3 移動後にセル 5 に到達し、そこでキノコを食べ、さらに (\lfloor4/2\rfloor=2) 移動します。 その合計距離は 6 なので、セル 1 で死にます。アリが基本 (K) 移動を終えた後にのみキノコを利用できるものとして扱うシミュレーションでは、誤ってこの相互作用を見逃してしまいます。 

もう一つの境界ケースは、`2 1`。 最初のアリは 1 つのセルを歩いて死ぬので、最初には戻りません。 2 番目のアリはキノコの上から正確に開始し、すぐにキノコを食べますが、(\lfloor1/2\rfloor=0) ため、まだ 1 つのセルだけを歩きます。 このプロセスは永遠に繰り返され、答えは`-1`。 キノコに到達するために正の距離が必要なソリューションでは、開始セルでキノコを誤って処理することになります。 

ケース`6 4`答えます`2`。 最初のアリは 4 マス歩いて死にます。 2 番目のアリはそのキノコを食べて 2 つの余分なセルを取得し、合計距離 (4+2=6)、つまりちょうど 1 周が得られます。 (K) が (N) で割り切れるかどうかだけをチェックすると、この有効なヒーローを見逃してしまいます。 

## アプローチ

 直接シミュレーションでは、すべてのキノコの位置を保持し、各アリを円に沿って移動させ、キノコに到達するか死ぬたびに停止します。 これは概念的に単純であり、プロセスに正確に従っているため、正しいです。 問題は、(N) が (10^9) になる可能性があり、ヘリコプターは永久にアリを放出し続けることができるということです。 最悪の場合、シミュレーションには (\Theta(N)) 個以上のアリの動きが必要になる可能性があり、それぞれの動きでキノコの情報が調べられる可能性があります。 これは 1 秒の制限をはるかに超えています。 

有益な観察は、キノコの数が決して多くなる必要がないということです。 最初のアリの後にキノコが 1 つあります。 アリがそのキノコを食べると、現在存在するすべてのキノコを食べたことになるので、アリが死ぬと新しいキノコが 1 つだけ残ります。 アリが既存のキノコを食べなかった場合、2 番目のキノコを作成します。 次のアリは両方を食べます。 

最後のステートメントが重要な部分です。 既存のキノコを 1 つ持っているアリが、最初の (K) 細胞の間にそのキノコに到達しなかったと仮定します。 そのキノコは 1 つのキノコを食べたアリによって作られたので、その距離は次のように導き出されます。 

[
 A=K+\左\l階 K/2\右\r階。 
】

 現在のアリが別のキノコを作成した後、新しいキノコは次のアリより (K-1) 個先にあります。 次のアリがそれを食べて、さらに (\lfloor K/2\rfloor) 個の細胞を獲得し、合計 (A) 個の細胞を与えます。 古いキノコもこれらの (A) セル内にあるため、両方のキノコが消費されます。 したがって、キノコは 2 つが最大です。 

これは、最初のアリ以降のすべてのアリは、食べたキノコの数 (P\in{0,1,2}) によってのみ分類できることを意味します。 したがって、その歩行距離は次の 3 つの値のいずれかになります。 

[
 S(0)=K、
 】

 [
 S(1)=A=K+\左\l階 K/2\右\r階、
 】

 [
 S(2)=B=K+\左\l床 K/2\右\r床+
 \左\lフロアK/3\右\rフロア。 
】

 アリの (P) がわかると、(P) の次の値も決まります。 (P=0) の場合、その後にキノコが 2 つあるので、次のアリは両方を食べます。 (P=1) または (P=2) の場合、新しいキノコが 1 つだけ残ります。 次の開始セルからの距離は次のとおりです。 

[
 (S(P)-1)\bmod N.
 】

 この距離が最大 (K) の場合、次のアリは最初の生存期間中にその距離に到達し、(P=1) になります。 それ以外の場合は (P=0) になります。 

可能な状態は 3 つだけであるため、多くても数回の遷移の後、状態が繰り返されます。 その時点からプロセスは定期的に行われます。 州に関連付けられた歩行距離は決して変化しないため、その州への最初の訪問時に距離が (N) で割り切れなかった場合、後で割り切れるようになることはありません。

 ## アルゴリズムのチュートリアル

 1. 最初のアリを別々に扱います。 キノコは食べないので距離は(K)です。 (K=N) の場合、開始セルに戻り、答えは次のようになります。`1`。 
2. コンピューティング

 [
 A=K+\左\l階 K/2\右\r階。 
】

 2 番目のアリは必ず最初のアリが作ったキノコに到達します。 (A) が (N) で割り切れる場合、2 番目のアリが主人公なので、 return`2`。 

1. 2 番目のアリの後、キノコが 1 つだけ残ります。 3 番目のアリの開始セルからの距離は、

 [
 d=(A-1)\bmod N.
 】

 1 の減算は、ヘリコプターが次のアリを放出する前に時計回りに 1 つのセルを移動することから得られます。 

1. (d\le K) の場合、3 番目のアリはこのキノコを食べるため、2 番目のアリとまったく同じ状態になります。 (A) はすでにチェックされており、(N) で割り切れないため、この状態が永遠に繰り返され、答えは次のようになります。`-1`。 
2. (d>K) の場合、3 番目のアリはキノコを食べません。 それは（K）個の細胞を歩き回り、2番目のキノコを作成します。 したがって、4 番目のアリは両方のキノコを食べます。 
3. コンピューティング

 [
 B=K+\左\l階 K/2\右\r階+
 \左\lフロアK/3\右\rフロア。 
】

 (B) が (N) で割り切れる場合、4 番目のアリは開始セルに戻ります。したがって、答えは次のようになります。`4`。 

1. それ以外の場合、4 番目のアリはちょうど 1 つのキノコを残します。 次のアリはそのキノコを食べてすでに考慮された (P=1) 状態になるか、それを食べずに (P=0) 状態に戻ります。 どちらの場合でも、同じ有限の状態シーケンスが繰り返されるため、後のアリは英雄になることはできません。 戻る`-1`。 

アルゴリズムの背後にある不変条件は、最初のアリが行動を開始するまでに、前のアリが何も食べず、その結果次のアリのためにキノコが 2 つ残ったという特殊な状況を除いて、キノコは常に最大 1 つしか存在しないということです。 これら 2 つのキノコは常に一緒に消費されます。 したがって、将来は、現在のアリがキノコを 0 個食べるか、1 個食べるか、2 個食べるかによって完全に決まります。 このような各状態の歩行距離は固定されているため、最初に発生したときに (N) で割り切れるかどうかを確認するだけで十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, K = map(int, input().split())

    # Ant 1 eats no mushrooms.
    if K % N == 0:
        print(1)
        return

    # An ant eating exactly one mushroom.
    one = K + K // 2

    if one % N == 0:
        print(2)
        return

    # After ant 2, there is one mushroom.
    # Its distance from ant 3's starting cell is (one - 1) mod N.
    d = (one - 1) % N

    # Ant 3 eats the same single mushroom.
    # The state then repeats forever.
    if d <= K:
        print(-1)
        return

    # Ant 3 eats no mushroom, so ant 4 gets two mushrooms.
    two = one + K // 3

    if two % N == 0:
        print(4)
        return

    print(-1)

if __name__ == "__main__":
    solve()
```最初の条件は、マッシュルームが存在しない唯一の可能な (P=0) 状態を処理します。 (K\le N) なので、最初のアリがヒーローになれる唯一の方法は (K=N) ですが、`K % N`条件を数学的定義に直接一致させます。 

変数`one`は (S(1)) です。 2 番目のアリは常に最初のキノコを消費するため、これがアリの正確な歩行距離になります。 チェック中`one % N`ant 2 が成功したかどうかを即座に判断します。 

表現`(one - 1) % N`は、次の開始セルに対する新しいキノコの位置を表します。 アリは一周以上歩いた可能性があるため、モジュロが必要です。 この距離を比べてみると、`K`次のアリが追加の寿命なしでキノコに到達するかどうかを決定します。 

距離が(K)を超えると、3番目のアリは何も食べません。 これにより、2 つのキノコが共存する唯一の状況が作成されます。 4 番目のアリは両方を消費するため、その距離は次のようになります。`one + K // 3`。 どのアリもキノコを 3 個食べることはできないため、これ以上の額は必要ありません。 

Python の整数には任意の精度があるため、次のような値が得られます。`one`そして`two`値が (10^9) を超えても安全です。 コードでも使用されています`% N`明示的なセル番号の算術演算ではなく、すべての循環インデックス付けとそれに関連するオフバイワンエラーを回避します。 

## 実用的な例

 最初のサンプルの場合、(N=7) および (K=4)。 

| アリ | 食べたキノコ(P) | 徒歩圏内 | 次のキノコまでの距離 | 結果 |
 | --- | --- | --- | --- | --- |
 | 1 | 0 | (4) | (5) | ヒーローではありません |
 | 2 | 1 | (4+2=6) | (5) | ヒーローではありません |
 | 3 | 0 | (4) | (6) | 2 番目のキノコを作成します |
 | 4 | 2 | (4+2+1=7) | (6) | ヒーロー |

 2 番目のアリはセル 5 でキノコを食べ、セル 1 で死にます。3 番目のアリはセル 3 から始まりますが、セル 1 に残っているキノコは 5 セル離れており、最初の 4 セルの寿命を超えています。 セル 7 で別のキノコを作成します。4 番目のアリは両方のキノコに遭遇し、合計距離 7 セル、つまり完全に 1 つの円を取得します。 答えは`4`。 

2 番目のサンプルの場合、(N=5) および (K=3)。 

| アリ | 食べたキノコ(P) | 徒歩圏内 | 次のキノコの距離 | 結果 |
 | --- | --- | --- | --- | --- |
 | 1 | 0 | (3) | (4) | ヒーローではありません |
 | 2 | 1 | (3+1=4) | (3) | ヒーローではありません |
 | 3 | 1 | (4) | (3) | 同じ状態が繰り返される |

 ここで (S(1)=4) ですが、これは 5 で割り切れません。アリ 2 の後、キノコはアリ 3 の開始セルから 3 セル離れているため、アリ 3 もそれを食べます。 同じ状況が、その後のすべてのアリに発生します。 関連する距離は 3 と 4 だけであるため、どちらも完全な 5 セルのラップを生成することはできません。 答えは`-1`。

 ## 特殊なケース

 のために`2 1`、最初のアリはセル 1 からセル 2 まで歩き、キノコを作成します。 2 番目のアリはセル 2 から開始するため、すぐにそのキノコを食べます。 追加の距離は (\lfloor1/2\rfloor=0) で、アリは 1 つのセルを歩いてセル 1 に到達します。次のアリは新しいキノコから始めて、同じように行動します。 歩行距離は 2 で割り切れないため、アルゴリズムは繰り返し (P=1) 状態に到達し、出力します。`-1`。 

のために`7 4`、キノコ 1 個の値は (A=6) です。 3 番目のアリは、(K=4) よりも大きい距離 ((6-1)\bmod7=5) で残りのキノコを認識するため、何も食べません。 これにより、4 番目のアリに対して 2 つのキノコが作成されます。 その距離は (B=6+\lfloor4/3\rfloor=7)、および (7\bmod7=0) であるため、アルゴリズムは次のように出力します。`4`。 

のために`6 4`、最初のアリは (4\not\equiv0\pmod6) のためヒーローではありません。 2 番目のアリはキノコを 1 つ食べ、(4+\lfloor4/2\rfloor=6) マスを歩きます。 (6\bmod6=0) なので、最初に戻り、アルゴリズムは次のように出力します。`2`。 

のために`5 3`、1 つのキノコの距離は (4) で、5 で割り切れません。次のキノコは距離 (3) にあり、(K) に正確に等しいため、3 番目のアリはそれを食べます。 キノコが1つある状態が永遠に繰り返されます。 The comparison uses`<= K`、 ない`< K`なぜなら、現在の寿命が終わるまさにそのときにキノコに到達したアリは、死ぬ前にキノコを食べるからです。 したがって、正しい結果は次のようになります`-1`。 

のために`1000000000 1000000000`、最初のアリは正確に (10^9) 個のセル、つまり 1 周分を歩きます。 答えはすぐに`1`。 これは、制約値が最大であってもセルの配列、シミュレーション カウンター、またはセルごとの状態が必要ない理由も示しています。
