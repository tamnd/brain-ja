 ## 問題の理解

 正確に曲を構築する必要があります`T`秒。 コーラスには長さがある`A`任意に何度でも繰り返すことができます。 既存の間奏はすべて最大 1 回使用できますが、すべての詩には長さがあります`B`新しく書かれたコピーを表すため、次のように使用すると`k`詩、グループは少なくとも次のことを書くことができなければなりません`k`詩。 

の一部のサブセットを選択するとします。`N`間奏。 その合計期間を次のようにします`x`そしてそのサイズは`m`。 次に、いくつかの数字が必要になります`c`そのようなコーラスの`x + kB + cA = T`。 

順序制限は数値で表すこともできます。 がある`k`節なので、連続する節の間には少なくとも次のものが必要です`k - 1`他の部分。 選ばれた間奏とサビはまさにAメロを区切るパートです。 したがって、必要なのは`m + c >= k - 1`。 

入力には以下が含まれます`T`、`A`、 そして`B`、その後に最大 500 のインタールードが続き、その長さは最大 500 です。`T`と同じ大きさにすることができます`10^18`, そのため、曲の合計時間によってインデックスを付けた動的なプログラムは不可能です。 便利な小さなパラメータは次のとおりです。`A`、`B`、間奏カウント。 以来`A <= 500`、剰余モジュロを含む状態空間`A`十分小さいです。 

答えには有用な構造的限界もあります。 有効な曲が少なくとも`A`詩を正確に削除します`A`詩と追加`B`コーラス。 それらの合計期間は等しいため、`A * B`秒は削除され、`B * A`秒が追加されます。 節の数は減少しますが、利用可能なセパレータの数は増加します。 したがって、結果として得られた曲は依然として有効です。 したがって、最小解は常に次の値よりも少なくなります。`A`詩。 

これにより、詩の数に対する一見無制限の検索が、最大 500 の可能性に変更されます。

3 番目のエッジ ケースは、分離条件そのものです。 最初のサンプルでは、​​選択された間奏とコーラスが一緒になって十分な区切り文字を提供しているため、3 つの詩が可能です。 合計期間の方程式をチェックするだけでは不十分です。数値解を導き出すことがまだ不可能な場合があるからです。

## アプローチ

 直接的な総当たりの解決策では、間奏のすべてのサブセットが列挙されます。 各サブセットについて、その期間がわかっています`x`とその要素の数`m`。 次に、可能な限りの数の詩を試すことができます。`0`を通して`A - 1`、必要なコーラス数を計算し、長さとセパレータの条件を確認します。 

すべての合法的な曲は、どの間奏が使用されるか、使用される詩の数、使用されるコーラスの数が正確に決定されるため、強引な方法は正しいです。 問題はサブセットの列挙です。 と`N = 500`、 がある`2^500`サブセットごとに一定量の作業を 1 つだけ実行するだけでも、すでに限界をはるかに超えています。 まで試してみます`A`詩数は単純なバージョンを大まかにします`O(A * 2^N)`。 

重要な観察は、コーラスの数に制限がないということです。 選択した間奏の合計長さがわかったら、法を適用します。`A`、方程式`x + kB + cA = T`の可能な値を決定します`k`モジュロ`A`。 最小の答えは常に より小さいため、`A`、すべての残基に対して、最大で 1 つの最小候補が存在します。`k`。 

残りの問題は、選択した間奏の数です。選択した各間奏は区切り文字でもあるためです。 これを、有界サブセット合計 DP で解決します。 選択された間奏の可能なすべての数と剰余モジュロごとに`A`、その状態を実現する最小の総間奏時間を保存します。 

以上のカウントを区別する必要はありません`A - 1`。 すべての候補者`k`以下です`A`したがって、区切り条件は、間奏の数が以下のしきい値に達したかどうかのみを尋ねます。`A`。 少なくともすべてのカウントに対して 1 つの上限付き DP 状態を使用します`A - 1`。 これによりDPが維持されます`O(N A^2)`状態と遷移。

 ## アルゴリズムのチュートリアル

 1. しましょう`m`選択された間奏の数になり、`x`合計期間。 一定の詩数の場合`k`、曲は満足する必要があります`x + kB + cA = T`。 

まさにその時にアレンジが可能です`m + c >= k - 1`。 
2. 考慮するだけで十分であることを証明する`0 <= k < A`。 有効な曲があった場合`k >= A`、 取り除く`A`詩と追加`B`コーラス。 どちらの操作も持続時間を次のように変更します。`AB`, したがって、期間は変わりません。 区切り文字の数は減らず、節数は減ります。 この変換を繰り返すと、最終的には以下の数を含む有効な曲が得られます。`A`詩。 
3. あらゆる可能な残留物について`r`モジュロ`A`、最小のものを見つけます`k`で`[0, A - 1]`満足のいく`kB ≡ T - r (mod A)`。 

これは、最大でも列挙するだけで実行できます。`A`可能な値`k`そしてそれぞれがどの残基に対応するかを記録します。 一部の残留物は解決策がない場合があります。`gcd(A, B)`分けない`T - r`。 
4. サブセット DP を構築します。 させて`dp[m][r]`正確に含むサブセットの最小合計期間であること`m`間奏とそれに一致する長さを持つ`r`モジュロ`A`。 

以下に正確な数のみを保存します`A - 1`。 最後の状態、`m = A - 1`、少なくとも意味します`A - 1`選ばれた間奏曲。 

デュレーションの間奏を処理する場合`s`、からの移行`m`に`m + 1`そして残留物から`r`に`(r + s) % A`。 カウント次元は逆方向に処理されるため、各間奏は最大 1 回使用されます。 
5. 各残基について`r`、その候補を取得します`k`。 候補がない場合、この残余では最小限の詩数の曲を作成できません。 
6. を表すすべての DP 状態について`m`選択した間奏について、間奏とセパレーター条件によって強制されるコーラスが占める最小秒数を計算します。 

もし`m >= k - 1`、余分なコーラスは強制されないため、必要な詩以外の長さは単純に`x`。 

もし`m < k - 1`、 少なくとも`k - m - 1`コーラスが必要なので、ヴァース以外の長さは`x + A * (k - m - 1)`。 
7. この最低限必要な詩以外の時間を次のようにします。`need`。 詩の後の残りの長さは`T - kB`。 候補が実現可能になるのは、次のとおりです。`need <= T - kB`。 

残りの差は、次の非負の倍数になります。`A`、追加のコーラスを追加することができます。 
8. 実現可能な最小のものを採用する`k`すべての残留物にわたって。 

機能する理由: DP には、間奏の可能なすべてのサブセットが含まれており、そのカウントと長さの法によってグループ化されています。`A`、そのような各状態の最小期間を保存します。 固定剰余の場合、合同式によって可能な最小の節数が決定されます。 最小限の解決策を得るには、これ以上の数の節は必要ありません。 次に、DP チェックにより、詩を分離するために必要な最小限の数のコーラスが正確に追加されます。 結果のデュレーションが範囲内に収まる場合`T`、未使用期間は次で割り切れます。`A`任意の追加コーラスを入れることができます。 逆に、すべての有効な曲は 1 つの DP 状態と 1 つの候補残基に対応するため、有効な最小解を見逃すことはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = 10**30

def solve_case(T, A, B, S):
    n = len(S)

    # A minimum answer is always < A.
    # We only need exact counts below A - 1.
    # The last state represents all counts >= A - 1.
    K = min(n, A - 1)

    dp = [[INF] * A for _ in range(K + 1)]
    dp[0][0] = 0

    for s in S:
        # We only transition from exact states m < K.
        # The state K is already "at least K", and adding the
        # current item cannot improve its minimum sum.
        for m in range(K - 1, -1, -1):
            cur = dp[m]
            nxt = dp[m + 1]

            for r in range(A):
                x = cur[r]
                if x == INF:
                    continue

                nr = (r + s) % A
                nx = x + s
                if nx < nxt[nr]:
                    nxt[nr] = nx

    # candidate[r] = smallest k in [0, A - 1] satisfying
    # k * B == T - r (mod A).
    candidate = [-1] * A

    for k in range(A):
        r = (T - k * B) % A
        if candidate[r] == -1:
            candidate[r] = k

    answer = A

    for r in range(A):
        k = candidate[r]
        if k == -1:
            continue

        verse_time = k * B
        if verse_time > T:
            continue

        budget = T - verse_time

        for m in range(K + 1):
            x = dp[m][r]
            if x == INF:
                continue

            if m < k - 1:
                x += A * (k - m - 1)

            if x <= budget:
                answer = min(answer, k)
                break

    return -1 if answer == A else answer

def solve():
    T, A, B = map(int, input().split())
    N = int(input())

    if N:
        S = list(map(int, input().split()))
    else:
        S = []

    print(solve_case(T, A, B, S))

if __name__ == "__main__":
    solve()
```実装セットの最初の部分`K = min(N, A - 1)`。 DP には、これより大きいカウントは必要ありません。`A - 1`、すべての候補詩の数が以下より小さいためです。`A`。 最後の状態は、少なくとも次の条件を備えたすべてのサブセットを表します。`A - 1`要素。 

遷移が繰り返される`m`後ろ向きに。 これは、ゼロまたは 1 つのサブセット遷移を適切に実装する標準的な方法です。 州`K`遷移のソースとしては意図的に使用されません。 これはすでに十分に大きなカウントをすべて表しているため、別のインタールードを追加しても、状態を同じ適格クラスに維持しながら継続時間を長くすることしかできません。 そこに保存されている最小期間を改善することはできません。 

の`candidate`array は、剰余ごとにモジュラー方程式を個別に解くことを回避します。 考えられるものはすべて列挙します`k`一度残差を計算します`r = (T - kB) mod A`。 

次の 2 つの値がある場合、`k`同じ残差が生成された場合、タスクでは最小限の詩数が求められるため、小さい方が唯一関連する残差となります。 

最後のループでは、すべての残基とすべての DP カウントがチェックされます。 いつ`m < k - 1`、不足しているセパレータはコーラスによって提供される必要があり、これが原因となります。`A * (k - m - 1)`秒。 いつ`m >= k - 1`、順序付け条件によって強制されるコーラスはありません。 

すべての期間の計算では Python 整数が使用されるため、`10^18`縛られている`T`オーバーフローを引き起こしません。 DP 自体には、最大でも間奏時間の合計までの値のみが含まれます。`250000`、さらに小さな区切り文字の修正。

    INF = 10**30
    n = len(S)

    K = min(n, A - 1)

    dp = [[INF] * A for _ in range(K + 1)]
    dp[0][0] = 0

    for s in S:
        for m in range(K - 1, -1, -1):
            cur = dp[m]
            nxt = dp[m + 1]

            for r in range(A):
                x = cur[r]
                if x == INF:
                    continue

                nx = x + s
                if nx < nxt[nr]:
                    nxt[nr] = nx

    candidate = [-1] * A

    for k in range(A):
        r = (T - k * B) % A
        if candidate[r] == -1:
            candidate[r] = k

    answer = A

    for r in range(A):
        k = candidate[r]
        if k == -1:
            continue

        budget = T - k * B
        if budget < 0:
            continue

の巨大な価値`T`DP サイズには影響しません。 たとえば、`T = 10^18`、すべての間奏の合計は依然として次のように制限されます。`250000`。 DP はこれらの少額のみを処理しますが、`T`最終的な算術チェックで使用されます。
