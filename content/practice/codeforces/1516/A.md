 ## 解決策
 ## 問題の理解

 負ではない整数の配列が与えられるので、さまざまな「転送」操作を実行できます。 1 回の操作で、2 つの異なる要素を選択し、最初の要素から 1 を減算し、2 番目の要素に 1 を加算します (最初の要素がゼロを下回らない場合)。 目標は、最大でも使用することです$k$配列を辞書編集的にできるだけ小さくするための操作。 

辞書順に小さいということは、配列を左から右に比較するときに、最初に異なる位置の結果の値が小さくなるということを意味します。 基本的に、左端の要素をできるだけ小さく保ちながら、できるだけ多くの値を右に押し込みたいと考えています。 

制約は小さいです。$n \le 100$そして$k \le 10000$。 以来$k$より大幅に大きくなる可能性があります$n$文字通りにしようとすると、すべての操作で一度に 1 つのユニットを移動する単純なシミュレーションを行う余裕はありません。 各要素は最大でも 100 であるため、配列の値は小さく、貪欲なアプローチがうまく機能していることを示唆しています。 

明らかではないエッジケースには、一部の要素が最初からゼロである配列が含まれます。 それらから減算しようとすると、スキップする必要があります。 別の微妙なケースが発生する場合$k$すべての譲渡可能な単位の合計より大きい。 この場合、最小の配列は、すべての余分なユニットをできるだけ右に移動することによって取得されます。 たとえば、入力の場合`2 10`と配列`1 0`、2 番目の要素を減らすことはできず、最初の要素から 2 番目の要素に 1 をプッシュすることによってすべての操作が消費され、次の結果が得られます。`[0 1]`。 

## アプローチ

 ブルートフォース手法では、各操作を 1 つずつシミュレートします。 すべてのステップで、配列を左から右にスキャンして 0 より大きい最初の要素を見つけ、そこから 1 を減算し、その右側の最初の要素に 1 を加えます。 これは正しいですが、非効率的です。$k \cdot n$ステップ。 もし$k$は 10000 であり、$n$は 100、つまり 1,000,000 回の操作であり、この問題では許容されますが、不要です。 

重要な洞察は、各操作が影響するのは 2 つの要素のみであり、目標は辞書編集的な最小化であるということです。 左側の配列を小さくするには、常に左端の要素をできるだけ減らし、削除されたユニットを右側に押し出す必要があります。 一度に 1 つずつ減算する代わりに、各要素から最大値を超えない範囲で一度に移動できます。$k$。 要素が$a_i$そして$k$操作は残っています、移動できます`min(a_i, k)`最後の要素までの単位。 この貪欲な選択により、左側の位置に残ったユニットはその位置の配列を大きくするだけであるため、辞書編集上の最小性が保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * k) | O(n) | 受け入れられるが遅い |
 | 貪欲な転送 | O(n) | O(n) | 最適かつ高速 |

 ## アルゴリズムのチュートリアル

 1.読む$t$、テストケースの数。 
2. 各テスト ケースについて、次の内容を読んでください。$n$、$k$、および配列$a$。 
3. 最後の要素を除き、配列を左から右に繰り返します。 

1.各要素について$a[i]$、計算します`move = min(a[i], k)`。 これは、マイナスになって残りの操作を超えることなく、この要素から転送できる最大値です。 
2. 減算`move`から$a[i]$そしてそれを追加します$a[n-1]$。 
3.減らす$k$による`move`。 もし$k$ゼロに達すると、ループを早期に中断します。 
4. 結果の配列を印刷します。 

これが機能する理由: 不変条件は、要素を常に左から右に処理し、ユニットを右に転送できる場合にのみ左の要素を削減することです。 処理が完了すると、左側の要素をそれ以上削減することはできなくなり、左端の位置が確実に最小化されます。 可能な限りすべてを最後の要素にプッシュすることで、辞書編集上の順序が最小化されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    for i in range(n - 1):
        if k == 0:
            break
        move = min(a[i], k)
        a[i] -= move
        a[-1] += move
        k -= move
    
    print(' '.join(map(str, a)))
```説明: どの転送にも個別のターゲットが必要なため、最後から 2 番目の要素まで反復します。`move = min(a[i], k)`ゼロを下回ったり、残りの演算を超えたりすることがないようにします。 更新中`a[-1]`すべてのユニットが可能な限り右に移動されることを保証します。 いつ休憩するか`k == 0`不必要な繰り返しを避けます。

 ## 特殊なケース

 最初の要素がゼロの場合、それから減算する演算はできません。 入力`[0 5]`と`k=10`配列は変更されないままになります。`move = min(a[0], k) = 0`。 アルゴリズムは、ゼロ要素からの転送を正しくスキップします。 

もし`k`最後の要素を除くすべての要素の合計を超えると、すべての値が最後の要素にプッシュされ、最も左端の配列が最小になります。 入力`[3 2 1]`と`k=100`になる`[0 2 4]`、アルゴリズムが非負性を維持しながら残りの操作を尊重していることを確認します。
