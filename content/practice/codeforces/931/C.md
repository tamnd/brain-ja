 ## 問題の理解

 キリルの測定値を表す複数の整数セットが与えられます。 すべての値は非常に緊密にクラスター化されています。すべての値は最大 2 の長さの間隔内にあるため、シフト後のデータには最大で 3 つの可能な整数のみが含まれます。 

Anya は同じサイズの別のマルチセットを構築する必要があります。 彼女の値はキリルの値と同じ数値範囲内に収まる必要があり、合計はキリルの合計と一致する必要があります。これは、サイズが固定されているため、平均を維持することと同じです。 

すべての有効な構造の中で、多重度マッチングの下で​​キリルのマルチセットと一致する値の数を最小限に抑えるように求められます。 つまり、値が両方のマルチセットに複数回出現する場合、各ペアリングで 1 回の出現が消費されるため、そのようなペアリングの合計数を最小限に抑えたいと考えます。 

範囲幅が最大 2 であるという制約が、重要な構造上の制限です。 これは、正規化後、すべての値が {0, 1, 2} のようなセットに属することを意味します。 これにより、問題は、固定和制約の下で小さなアルファベット上で周波数を選択するという問題に分解されます。 

最大 100,000 の入力サイズでは、二次構造や、ネストされた方法ですべての割り当てを明示的に反復するアプローチは除外されます。 このソリューションでは、決定空間を単一の線形スキャンまたは小さな状態空間にわたる定数因子最適化に縮小する必要があります。 

単純な試みでは、Anya の配列のすべての順列を列挙するか、合計条件をチェックしながら値を再分配するすべての方法を列挙しようとします。 これはすぐに失敗します。なぜなら、構造なしで組み合わせ的に扱われると、3 つの値にカウントを分散しても、構成が指数関数的に多くなるからです。 

ローカルでの一致を避けるために値を貪欲に割り当てようとすると、より微妙な失敗ケースが発生します。 ローカル回避により、グローバル合計制約が破られる可能性があります。 たとえば、キリルの配列がほとんど 0 と 1 である場合、アーニャの配列でゼロをやみくもに避けると、1 または 2 が多すぎて、必要な合計が割れてしまう可能性があります。 

したがって、正しい解決策は、問題を 1 つの線形方程式に基づくグローバルな周波数選択として扱う必要があります。 

## アプローチ

 ブルートフォースの観点は、Anya の配列が、範囲内の 3 つの可能な値のそれぞれを使用する回数によって完全に決定されることに注目することから始まります。 最小値を L とすると、すべての有効な配列は、合計が n になり線形和制約を満たす L、L+1、および L+2 のカウントを選択することに対応します。 

単純な解決策では、合計が n になるカウントのトリプルをすべて列挙し、どれが合計条件を満たすかをチェックします。 これは概念的にはすでに遅すぎますが、そのようなトリプルは O(n^2) しかないため、まだ管理可能です。 ただし、各構成を評価し、Kirill の配列との重複を計算すると、再構築またはマッチング シミュレーションを介して直接実装された場合、O(n^3) の動作が発生します。 

重要な観察は、最小値が 0 になるように値をシフトした後、問題は単一の線形方程式 n1 + 2*n2 = S' (S' はシフトされた合計) に従って、Anya が使用する 0、1、2 の数を選択することになります。 n2 が固定されると、他のすべてが決まります。 これにより、探索空間が 2 自由度から 1 自由度に縮小されます。 

2 番目の洞察は、値ドメインのサイズが一定であるため、頻度カウントを使用して任意の候補のコストを一定時間で計算できるということです。 これにより、可能なすべての n2 値を線形時間で反復し、最適な構成を選択することができます。

 ## アルゴリズムのチュートリアル

まずキリルのデータの構造を特定することから始めます。 

1. 配列内の最小値 L を計算し、L を減算してすべての値をシフトします。この変換後、すべての値は {0, 1, 2} になります。 この正規化により、絶対的な位置決めが削除され、合計制約が純粋に代数的になります。 
2. シフトされたアレイの周波数 f0、f1、f2 をカウントします。 総和S'も計算します。 
3. 次に、カウント y0、y1、y2 を使用して Anya の配列を構築します。 これらは、y0 + y1 + y2 = n および y1 + 2*y2 = S' を満たさなければなりません。 
4. y2 のすべての実行可能な値を 0 から n まで反復します。 各 y2 について、y1 = S' - 2*y2 を計算します。 y1 が負であるか、n - y2 を超える場合、この設定は無効となりスキップされます。 
5. 有効なペア (y1、y2) ごとに、y0 = n - y1 - y2 を計算します。 これにより、候補マルチセットが完全に決定されます。 
6. 各候補について、キリル配列との一致数を min(f0, y0) + min(f1, y1) + min(f2, y2) として計算します。 この値を最小化する構成を追跡します。 
7. すべての可能性をスキャンした後、最良のトリプルを出力し、任意の順序で配列を再構成します。 

y2 のみを変更する理由は、合計制約が線形であり、y2 が選択されると y1 を一意に固定するためです。 

### なぜ効果があるのか

 本質的な不変条件は、すべての有効な解が、単体 y0 + y1 + y2 = n 内の直線 y1 + 2*y2 = S' 上の 1 つの整数点に正確に対応するということです。 これにより、実行可能領域が 1 次元の候補セットに縮小されます。 目的関数はカウントのみに依存し、この離散領域にわたって区分的に線形であるため、すべての有効な整数点を評価することで、グローバルな最適値を見つけることが保証されます。 

実現可能性は取り決めではなくグローバルな数にのみ依存するため、ローカルな決定が独立して実現可能性に影響することはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    mn = min(a)
    a = [x - mn for x in a]

    f0 = f1 = f2 = 0
    for x in a:
        if x == 0:
            f0 += 1
        elif x == 1:
            f1 += 1
        else:
            f2 += 1

    S = f1 + 2 * f2

    best = float('inf')
    best_y0 = best_y1 = best_y2 = 0

    for y2 in range(n + 1):
        y1 = S - 2 * y2
        if y1 < 0 or y1 > n:
            continue
        y0 = n - y1 - y2
        if y0 < 0:
            continue

        cost = min(f0, y0) + min(f1, y1) + min(f2, y2)

        if cost < best:
            best = cost
            best_y0, best_y1, best_y2 = y0, y1, y2

    print(best)

    res = ([mn] * best_y0 +
           [mn + 1] * best_y1 +
           [mn + 2] * best_y2)

    print(*res)

if __name__ == "__main__":
    solve()

y1 は方程式から直接導出され、負になったり n を超えたりする可能性があるため、y1 の計算には注意が必要です。 候補を評価する前に、両方の条件をチェックする必要があります。 最終的な再構成は順序とは無関係であるため、値は単純にブロックで出力されます。

 ## 特殊なケース

 Kirill の配列内のすべての値が同一の場合、範囲は 1 つの値に集約され、有効な構成は同じマルチセットのみになります。 正規化後、f1 と f2 はゼロであり、実行可能な y 構成が 1 つだけ存在するため、アルゴリズムはこれを処理します。そのため、スキャンはゼロコストの解を返します。
