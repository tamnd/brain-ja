 ## 解決策
 ## 問題の理解

 無向グラフが与えられました。 各エッジは 2 点間に描かれたセグメントを表します。 エッジを 1 つだけ削除し、それを削除した後、残りのグラフを 2 部構成にすることができます。 

すべてのエッジが異なる色の頂点を接続するように、すべての頂点を 2 色で色付けできる場合、グラフは 2 部構成になります。 同じことを別の言い方で言えば、グラフには奇数のサイクルが含まれてはなりません。 

タスクは、削除するとグラフ全体が 2 部になるすべてのエッジを出力することです。 

グラフには最大で次のものを含めることができます$10^4$頂点と$10^4$エッジ。 定数係数が大きい場合、そのサイズは頂点とエッジの両方で二次関数を即座に除外します。 すべてのエッジを削除し、二部性を最初からチェックする単純なソリューションでは、完全な DFS または BFS が実行されます。$m$回。 各小切手にかかる費用$O(n+m)$したがって、全体の複雑さは次のようになります。$O(m(n+m))$。 両方の値が近い場合$10^4$、おおよそに達する$2 \cdot 10^8$Python ではリスクが高すぎます。 

厄介な点は、グラフが切断される可能性があることです。 頂点 1 からの DFS のみが他のコンポーネントの奇数サイクルをミスする不注意な実装。 

もう 1 つの微妙なケースは、グラフがすでに 2 部構成になっている場合に発生します。 その後、エッジを削除しても 2 部グラフが残るため、すべてのエッジを印刷する必要があります。 

例えば：```
3 2
1 2
2 3
```グラフはすでに 2 部構成になっています。 正しい出力:```
2
1 2
```奇数サイクルに関与する「不良」エッジのみを検索する間違ったアプローチでは、誤って何も印刷されない可能性があります。 

逆に、複数の奇数サイクルが独立して存在する場合もあります。 1 つのエッジを削除してもすべての奇数サイクルを破壊できない場合、答えは空です。 

例：```
6 6
1 2
2 3
3 1
4 5
5 6
6 4
```切り離された三角形が 2 つあります。 1 つのエッジを削除すると、1 つの三角形だけが破壊され、他の奇数サイクルは残ります。 正しい出力:```
0
```すべてのエッジは奇数サイクル上にありますが、単一のエッジがグラフ全体を固定することはないため、単純な「エッジが奇数サイクルに属している」という基準はここでは当てはまりません。 

最も困難なエッジケースは、奇数サイクルが重複することです。 場合によっては、いくつかの奇数サイクルがエッジを共有し、共有されたエッジのみが機能することがあります。 

例：```
5 6
1 2
2 3
3 1
3 4
4 5
5 3
```2 つの三角形は頂点 3 を共有しますが、エッジは共有しません。 単一のエッジ除去では両方の奇数サイクルが破壊されないため、答えは依然として空です。 

## アプローチ

 ブルートフォースのアイデアは単純です。 すべてのエッジについて、それを一時的に削除し、BFS または DFS カラーリングを使用して残りのグラフが 2 部であるかどうかをテストします。 

二者チェック自体は標準です。 走査中に交互の色を割り当てます。 同じ色の頂点を接続するエッジに遭遇した場合、グラフには奇数のサイクルが含まれており、二部構成ではありません。 

これは、エッジの削除が着色プロセスから独立しているため機能します。 すべての候補エッジを直接テストできます。 

問題は総費用です。 を繰り返します$O(n+m)$すべてのエッジのグラフ走査、生成$O(m(n+m))$全体的な時間。 と$m = 10^4$、これは大きくなりすぎます。 

重要な観察は、奇数サイクルが二部性を妨げる唯一の障害であるということです。 1 つのエッジを削除すると、そのエッジがグラフ内のすべての奇数サイクルに属している場合にのみ役立ちます。 

それは問題を完全に変えます。 削除するたびに二部性を再計算する代わりに、単一の DFS ツリー内の奇数サイクルの構造を研究します。 

グラフを DFS し、深度パリティによって頂点に色を付けるとします。 木の端は常に反対の色を接続します。 非ツリー エッジの動作は異なります。 

異なるパリティの頂点を接続すると、偶数サイクルが形成されます。 

同じパリティの頂点を接続すると、奇数サイクルが形成されます。 

これらの「悪い」バックエッジは、グラフ内の奇数サイクルを完全に特徴づけます。 

ここで、1 つのエッジを削除すると、すべての奇数サイクルがどのように削除されるかを考えてみましょう。 すべての奇数サイクルは、1 つの不良バック エッジとそのエンドポイント間のツリー パスに対応します。 エッジは、そのようなすべての奇数サイクルに属する場合にのみ有効になります。 

これは、DFS ツリーでのカウントの問題になります。 

各不良バック エッジに、そのエンドポイント間のパスに沿った寄与を割り当てます。 貢献をボトムアップで蓄積した後、各ツリー エッジは奇数サイクルが何回通過したかを認識します。 

グラフに正確に含まれている場合$k$不良バックエッジによって奇数サイクルが発生した場合、次のようになります。 

もし$k = 0$、あらゆるエッジが機能します。 

もし$k > 0$、エッジはすべてに属している場合に機能します。$k$奇数のサイクル。 

非ツリー不良エッジ自体も、それらが 1 つの奇数サイクルの寄与に関与する唯一のエッジである場合には機能します。 

これにより、問題全体が 1 つの DFS と 1 つの蓄積パスに軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(m(n+m))$|$O(n+m)$| 遅すぎる |
 | 最適 |$O(n+m)$|$O(n+m)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 無向グラフを構築し、すべてのエッジのインデックスを保存します。 
2. すべての接続されたコンポーネント上で DFS を実行します。 

DFS 中に、以下を保存します。 

- 各頂点の深さ
 - DFS ツリー内の親エッジ
 - 深度モジュロ 2 を使用したパリティ カラー
 3. DFS 中にエッジを分類します。 

すでに訪問した近傍が親ではない場合、バック エッジが見つかりました。 

2 つのエンドポイントが同じパリティを持つ場合、このバック エッジにより奇数サイクルが作成されます。 
4. すべての奇数バックエッジをグローバルにカウントします。 

この値を`odd_cnt`。 

もし`odd_cnt == 0`、グラフはすでに 2 部になっているため、すべてのエッジが有効です。 
5. 奇数のバックエッジごとに$(u,v)$、パスの貢献を追加します。 

仮定する`depth[u] > depth[v]`。 

インクリメント`mark[u] += 1`デクリメント`mark[v] -= 1`後で、DFS ツリーを介して上方向に値を集計すると、パス上のすべてのツリー エッジが`u`に`v`1 回の寄付を受け取ります。 
6. 再度 DFS を実行して、サブツリーの合計を蓄積します。 

各頂点について、子から親への寄与を合計します。 

させて`sub[x]`最終累積値を示します。 

親から子への木の端に`sub[child] == odd_cnt`の場合、すべての奇数サイクルがこのエッジを通過するため、これを削除するとグラフが修正されます。 
7. 非ツリー奇数エッジを個別に処理します。 

すべての奇数バックエッジは個別に、正確に 1 つの奇数サイクル記述子に属します。 このようなエッジは、次の場合に機能します。`odd_cnt == 1`。 
8. 有効なエッジ インデックスをすべて収集し、並べ替えて出力します。 

### なぜ効果があるのか

 無向 DFS 内のすべての奇数サイクルは、1 つの奇数バック エッジとそのエンドポイントを接続するツリー パスによって表すことができます。 

寄与の伝播は、各奇数サイクルに属するツリーのエッジを正確にマークします。 積み上げた後は、`sub[x]`接続するツリーのエッジを通過する奇数サイクルの数に等しい`x`その親に。 

エッジがすべての奇数サイクルに属している場合、エッジを削除するとすべての奇数サイクルが同時に破壊され、グラフが 2 部構成になります。 

エッジが 1 つの奇数サイクルでもミスした場合、そのサイクルは削除後も存続するため、グラフは非 2 部のままになります。 

アルゴリズムはこの状態を正確にチェックします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(1 << 25)

n, m = map(int, input().split())

g = [[] for _ in range(n + 1)]
edges = [None]

for i in range(1, m + 1):
    u, v = map(int, input().split())
    edges.append((u, v))
    g[u].append((v, i))
    g[v].append((u, i))

depth = [0] * (n + 1)
visited = [False] * (n + 1)
parent = [0] * (n + 1)
parent_edge = [0] * (n + 1)

mark = [0] * (n + 1)

odd_edges = []
odd_cnt = 0

def dfs(u, pe):
    global odd_cnt

    visited[u] = True

    for v, idx in g[u]:
        if idx == pe:
            continue

        if not visited[v]:
            depth[v] = depth[u] + 1
            parent[v] = u
            parent_edge[v] = idx
            dfs(v, idx)
        elif depth[v] < depth[u]:
            if (depth[u] - depth[v]) % 2 == 0:
                odd_cnt += 1
                odd_edges.append(idx)

                mark[u] += 1
                mark[v] -= 1

for i in range(1, n + 1):
    if not visited[i]:
        dfs(i, -1)

if odd_cnt == 0:
    print(m)
    print(*range(1, m + 1))
    sys.exit()

ans = []

def collect(u, pe):
    subtotal = mark[u]

    for v, idx in g[u]:
        if idx == pe:
            continue

        if parent[v] == u:
            child_sum = collect(v, idx)

            if child_sum == odd_cnt:
                ans.append(idx)

            subtotal += child_sum

    return subtotal

for i in range(1, n + 1):
    if parent[i] == 0:
        collect(i, -1)

if odd_cnt == 1:
    ans.extend(odd_edges)

ans.sort()

print(len(ans))
print(*ans)
```最初の DFS は DFS ツリーを構築し、奇数のバック エッジを検出します。 パリティ テストは DFS の深さから行われます。 2 つのエンドポイント間の深さの差が偶数の場合、サイクル長は奇数になります。 

の`mark`配列はパスの累積を実装します。 奇数バックエッジの場合$(u,v)$、より深いエンドポイントで増加し、祖先で減少すると、サブツリー集約中にそのパス上のすべてのツリー エッジが 1 つの寄与を受け取ります。 

2 番目の DFS はサブツリーの合計をボトムアップで計算します。 木の端が正確に運ぶ場合`odd_cnt`貢献があれば、すべての奇数サイクルがそれを通過します。 

条件`depth[v] < depth[u]`同じバックエッジを 2 回処理することを回避します。 これがないと、無向エッジは両方向からカウントされます。 

非ツリー奇数エッジの個別の処理は微妙です。 このようなエッジ自体が 1 つの奇数サイクルを閉じます。 これを削除すると、それがグラフ全体で唯一の奇数サイクル記述子である場合にのみグラフが修正されます。 

DFS ツリーは長さの長いチェーンになる可能性があるため、再帰制限を増やす必要があります。$10^4$。

import sys, io

def solve():
    input = sys.stdin.readline

    sys.setrecursionlimit(1 << 25)

    n, m = map(int, input().split())

    g = [[] for _ in range(n + 1)]
    edges = [None]

        u, v = map(int, input().split())
        edges.append((u, v))
        g[u].append((v, i))
        g[v].append((u, i))

    depth = [0] * (n + 1)
    visited = [False] * (n + 1)
    parent = [0] * (n + 1)

    mark = [0] * (n + 1)

    odd_edges = []
    odd_cnt = 0

    def dfs(u, pe):
        nonlocal odd_cnt

        visited[u] = True

        for v, idx in g[u]:
            if idx == pe:
                continue

            if not visited[v]:

                parent[v] = u
                dfs(v, idx)
            elif depth[v] < depth[u]:
                if (depth[u] - depth[v]) % 2 == 0:
                    odd_cnt += 1
                    odd_edges.append(idx)

                    mark[u] += 1
                    mark[v] -= 1

    for i in range(1, n + 1):
        if not visited[i]:
            dfs(i, -1)

    if odd_cnt == 0:
        print(m)
        print(*range(1, m + 1))
        return

    ans = []

    def collect(u, pe):
        subtotal = mark[u]

        for v, idx in g[u]:
            if idx == pe:
                continue

            if parent[v] == u:
                child = collect(v, idx)

                if child == odd_cnt:
                    ans.append(idx)

                subtotal += child

        return subtotal

    for i in range(1, n + 1):
        if parent[i] == 0:
            collect(i, -1)

    if odd_cnt == 1:
        ans.extend(odd_edges)

    ans.sort()

    print(len(ans))
    if ans:
        print(*ans)
    else:
        print()

    backup_stdout = sys.stdout

    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out
