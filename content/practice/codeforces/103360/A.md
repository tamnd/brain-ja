 ## 解決策

 しましょう$n = s + t$(1)と同様に、$t$-組み合わせ$c_t \cdots c_1$と$n > c_t > \cdots > c_1 \ge 0$追加の隣接制限と合わせて$c_{j+1} > c_j + 1 \qquad (t > j \ge 1).$新しい整数を定義する$c'_j = c_j - (j-1), \qquad 1 \le j \le t.$から$c_{j+1} \ge c_j + 2$それは次のとおりです$c'_{j+1} = c_{j+1} - j \ge c_j + 2 - j = (c_j - (j-1)) + 1 = c'_j + 1,$したがって$c'_t > c'_{t-1} > \cdots > c'_1 \ge 0.$したがって$c'_t \cdots c'_1$普通の厳密なものです$t$- (3) の意味での組み合わせ。一連の連続する整数から形成されます。 

から$c_t \le n-1$人は得る$c'_t = c_t - (t-1) \le n-1-(t-1) = n-t,$そして$c'_1 \ge 0$～から直接保持する$c_1 \ge 0$。 したがってそれぞれの$c'_j$にある${0,1,\ldots,n-t}$。 

逆に、通常の組み合わせを考えると、$n-t \ge c'_t > \cdots > c'_1 \ge 0,$定義する$c_j = c'_j + (j-1).$$c_{j+1} \ge c'_{j+1} + j \ge (c'_j + 1) + j = (c'_j + (j-1)) + 2 = c_j + 2,$$

 したがって、隣接条件は$c_{j+1} > c_j + 1$が成立し、また$c_t \le n-1$から続く$c'_t \le n-t$。 この再構成は変換を反転するため、有効なピアノとコードの組み合わせと通常のコードの間で全単射になります。$t$-組み合わせオン${0,1,\ldots,n-t}$。 

したがって、隣接制限のあるピアノ演奏者の問題は、すべての要素を生成することと同じです。$t$-の組み合わせ$(n-t+1)$-要素セット。 (1.2.6-2) により、その数は次のようになります。$\binom{n-t+1}{t},$基礎となるグラウンドセットには要素があるため、$0,1,\ldots,n-t$。 

このようなコードをすべて辞書順に生成するには、アルゴリズムを適用します。$L$セクション 7.2.1.3 の変換後の変数への適用$c'_t \cdots c'_1$、そして出力します$c_j = c'_j + (j-1) \qquad (1 \le j \le t).$これにより、アフィン シフトの下で辞書編集上の順序が維持され、許容されるすべてのコードが 1 回だけ生成されます。
