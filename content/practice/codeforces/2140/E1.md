 ## 解決策
 ## 問題の理解

 並んでいます`n`山。 各パイルには次のいずれかが含まれます`1`または`2`これは簡単なバージョンなので、`m ≤ 2`。 

ゲームはパイル値を変更しません。 プレイヤーは山を取り除くだけです。 いつでも、現在のパイルは左から右に再インデックス付けされ、移動には、現在のインデックスが良好なインデックスの固定セットに属しているパイルを削除することが含まれます。 

アリスが最初に動き、最後に残った山の値をできるだけ大きくしたいと考えています。 ボブはできるだけ小さいものを望んでいます。 

可能なパイル値のすべての割り当てについて、ゲームを最適にプレイし、最後に残ったパイルの値を取得します。 タスクは、すべての構成にわたってその値を合計することです。 

最初に注目すべきことは、ゲームの仕組みは位置のみに依存し、山に書かれた実際の数字には決して依存しないということです。 値は、最終的に生き残る位置を評価する場合にのみ重要です。 

制約`n ≤ 20`が鍵です。 ゲームの状態は、生き残ったポジションのセットによって表現できます。`2^20`およそ100万です。 この声明では、次の合計が保証されることさえ保証されています。`2^n`すべてのテストケース全体で最大でも`2^20`これは、ビットマスク動的プログラミング ソリューションを強く示唆しています。 

よくある間違いは、どの元の位置が生き残るかを直接計算しようとすることです。 その位置は最適なプレイに依存し、インデックスを再作成するたびに変わります。 このゲームは、単純な消去法ではなく、動的に変化するシーケンスをめぐるミニマックス ゲームです。 

インプットを考慮する```
3 2
2
1 2
```杭があれば`[2,1,2]`、アリスは 2 番目の山を削除して、残すことができます。`[2,2]`。 次に、ボブは最初の山を削除する必要があり、最終的な値は次のようになります。`2`。 ゲーム状態に固定の「生存位置」を割り当てようとするアプローチでは、この相互作用が失われます。 

もう一つの微妙なケースは次のような場合です。`n = 1`。```
1 2
1
1
```まったく動きは再生されません。 唯一の山がすぐに生き残ります。 少なくとも 1 つの削除を想定した DP では、誤った結果が生成されます。 

## アプローチ

 最も直接的な強引な方法は、すべてを列挙することです。`m^n`構成。 各構成について、ゲーム ツリーに対してミニマックス検索を実行し、最終的な値を決定できます。 

のために`n = 20`、構成の数さえすでに`2^20 ≈ 10^6`、各構成にはゲームを解決する必要があります。 これはあまりにも高価です。 

重要な観察は、ゲームが山の値を比較するだけであるということです。 以来`m ≤ 2`、すべての山は次のいずれかです`1`または`2`。 

設定をバイナリ シーケンスとしてエンコードするとします。```
1 stone -> 0
2 stones -> 1
```この構成の最終的な答えは次のいずれかです。`0`または`1`このバイナリの世界では。 私たちが知る必要があるのは、アリスが最後に残った山を強制的にできるかどうかだけです。`1`。 

これにより、問題はバイナリ シーケンスに関する純粋なゲームに変換されます。 

状態は単に現在のバイナリ シーケンスです。 山を取り除くとビットが 1 つ消えます。 以来`n ≤ 20`、長さのすべてのシーケンス`ℓ`のビットマスクで表すことができます`ℓ`ビット。 

状態の最小値もバイナリです。```
0 = Bob can force the final bit to be 0
1 = Alice can force the final bit to be 1
```これにより、あらゆる長さのすべてのマスクにわたる DP が得られます。 

どの長さがわかったら-`n`マスクは次のように評価されます`1`、構成のカウントが簡単になります。 すべてのバイナリ マスクは、値が 1 つのみであるため、正確に 1 つの構成に対応します。`1`そして`2`。 

最終的な杭の値は次のようになります。```
1 + (game result bit)
```それで```
sum(final values)
=
(number of configurations)
+
(number of masks whose game result is 1)
```のために`m = 2`、構成の数は`2^n`。 

のために`m = 1`、すべての構成は完全に 1 で構成されているため、答えは単純です。`1`。 

DP はすべてのマスクを 1 回だけ処理し、次の合計が保証されるという保証を使用します。`2^n`有界である。 これにより、受け入れられる解決策が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 構成とゲーム状態の両方で指数関数的 | 指数 | 遅すぎる |
 | 最適なビットマスク DP | O(n · 2^n) | O(2^n) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### ステップ 1

 特殊なケースを処理する`m = 1`。 

すべての山には正確に 1 つの石が含まれているため、すべての構成は同一であり、最終的な答えは常に次のようになります。`1`。 

### ステップ 2

 のために`m = 2`、各構成をバイナリ マスクとして表します。 

少し`i = 0`パイルに含まれていることを意味します`1`。 

少し`i = 1`パイルに含まれていることを意味します`2`。 

### ステップ 3

 すべてのシーケンス マスクの DP 値を定義します。`dp[mask]`アリスが最後の生き残ったビットを強制的にできるかどうかを表します。`1`その状態から。 

シーケンスの長さは、現在マスク層に格納されているビット数によって決まります。 

### ステップ 4

 長さの初期化`1`。 

唯一残っているビットが`0`、結果は`0`。 

唯一残っているビットが`1`、結果は`1`。 

### ステップ 5

 からのプロセス長さ`2`まで`n`。 

長さのあるマスクの場合`ℓ`、誰の番かを決定します。 

その通り`n - ℓ`削除はすでに発生しています。 

もし`n - ℓ`互角ならアリスの番です。 

もし`n - ℓ`おかしい、今度はボブの番だ。 

### ステップ 6

 すべての法的な子状態を生成します。 

あらゆる優れたインデックスに対して`c`と`c ≤ ℓ`を削除します。`c`現在のマスクの - 番目のビット。 

これにより、長さのマスクが生成されます`ℓ - 1`。 

### ステップ 7

 ミニマックスを適用します。 

アリスの番の場合、状態値はすべての子の値の OR になります。 

アリスは 1 つの手だけを必要として、子供を勝ちに導きます。 

ボブの番の場合、状態値はすべての子の値の AND になります。 

ボブはアリスにとって最悪の手を選択します。 

### ステップ 8

 長さのすべてのマスクを計算した後`n`、DP値を持つものが何個あるか数えます`1`。 

このカウントを次のようにします`win`。 

答えは```
2^n + win
```剰余を取得`10^9 + 7`。 

### なぜ効果があるのか

 状態の DP 値は、まさにそのゲーム ポジションの最小値です。 

パイルが 1 つだけ残っているときは、最後のビットがすでにわかっているため、基本ケースは正しいです。 

より大きな国家にとって、あらゆる法的措置はより小さな国家を生み出す。 アリスが動いた場合、結果を最大化する子を選択します。これは正確には二値の結果に対する OR です。 ボブが移動する場合、彼は結果を最小化する子を選択します。これは正確には 2 値の結果に対する AND です。 

シーケンスの長さに関する帰納法により、すべての DP 値はその状態の真のゲーム理論上の値と等しくなります。 

長さ-`n`マスクは次のように評価されます`1`対応する構成が value で終わるとき正確に`2`最適なプレイのもとで。 このようなマスクの数をベースライン寄与度に追加すると、`1`すべての構成から必要な合計が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def solve():
    t = int(input())

    for _ in range(t):
        n, m = map(int, input().split())
        k = int(input())
        good = list(map(int, input().split()))

        if m == 1:
            print(1)
            continue

        dp = [None] * (n + 1)

        dp[1] = [0, 1]

        for length in range(2, n + 1):
            size = 1 << length
            cur = [0] * size

            alice_turn = ((n - length) & 1) == 0
            valid_good = [x for x in good if x <= length]

            for mask in range(size):
                if alice_turn:
                    val = 0
                    for pos in valid_good:
                        idx = pos - 1

                        low = mask & ((1 << idx) - 1)
                        high = mask >> (idx + 1)
                        child = low | (high << idx)

                        val |= dp[length - 1][child]
                        if val:
                            break
                    cur[mask] = val
                else:
                    val = 1
                    for pos in valid_good:
                        idx = pos - 1

                        low = mask & ((1 << idx) - 1)
                        high = mask >> (idx + 1)
                        child = low | (high << idx)

                        val &= dp[length - 1][child]
                        if not val:
                            break
                    cur[mask] = val

            dp[length] = cur

        win = sum(dp[n])
        ans = ((1 << n) + win) % MOD
        print(ans)

solve()
```DP はシーケンスの長さによって編成されます。`dp[length][mask]`その正確なシーケンスのミニマックス結果を保存します。 

ビットを削除するために使用される式は、実装の中で最もデリケートな部分です。 マスクを、削除された位置の前のビットとその後のビットに分割します。 上の部分は右に 1 位置ずらして結合されます。 

もう 1 つの詳細は方向転換の検出です。 長さの状態`length`ちょうど後に表示されます`n - length`削除。 アリスが最初に移動するため、この数値のパリティによって誰の順番になるかが一意に決まります。 

保存される状態の合計数が少ないため、メモリ使用量は少なく抑えられます。```
2 + 4 + 8 + ... + 2^n
=
2^(n+1) - 2
```これが 200 万を下回ったとき`n = 20`。

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n · 2^n) | すべてのマスクは 1 回処理され、それぞれ最大で`n`法的削除 |
 | スペース | O(2^n) | 合計 DP ストレージはマスクの数に比例します。

def run(inp: str) -> str:

    def input():
        return input_data.readline()

        n, m = map(int, input().split())
        k = int(input())
        good = list(map(int, input().split()))

        if m == 1:
            out.write("1\n")
            continue

        dp[1] = [0, 1]

        for length in range(2, n + 1):
            cur = [0] * (1 << length)

            alice_turn = ((n - length) & 1) == 0
            valid_good = [x for x in good if x <= length]

            for mask in range(1 << length):
                if alice_turn:
                    val = 0
                    for pos in valid_good:
                        idx = pos - 1
                        low = mask & ((1 << idx) - 1)
                        high = mask >> (idx + 1)
                        child = low | (high << idx)
                        val |= dp[length - 1][child]
                        if val:
                            break
                    cur[mask] = val
                else:
                    val = 1

                        idx = pos - 1

                        child = low | (high << idx)
                        val &= dp[length - 1][child]
                        if not val:
                            break
                    cur[mask] = val

            dp[length] = cur

        out.write(str(((1 << n) + sum(dp[n])) % MOD) + "\n")

    return out.getvalue()

 ## 特殊なケース

 ### 山は 1 つだけ

 入力:```
1 2
1
1
```DP は長さから始まります`1`, したがって、トランジションは実行されません。 

マスクは次の 2 つです。```
0 -> value 1
1 -> value 2
```答えは次のとおりです。```
1 + 2 = 3
```基本レイヤーはすでに完成したゲームを表しているため、アルゴリズムはこれを自然に処理します。 

### すべての山は 1 に等しい

 入力:```
3 1
2
1 3
```構成は 1 つだけです。```
[1,1,1]
```ゲームがどのように進行しても、最終的なパイル値は次のとおりです。`1`。 

アルゴリズムはすぐに戻ります`1`いつ`m = 1`、不必要な DP 作業を回避します。 

### シーケンスが縮小すると、良好なインデックスが失われる

 入力:```
3 2
2
1 3
```現在の長さになると、`2`、 索引`3`はもう無効です。 

実装では、以下を満たす適切なインデックスのみを明示的に保持します。```
good_index <= current_length
```したがって、生成されたすべての移動は現在の状態では合法です。 これにより、存在しないポジションへのアクセスが回避され、ゲームのルールに正確に一致します。
