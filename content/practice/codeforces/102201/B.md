 ## 解決策
 ## 問題の理解

 電球の 4 つの可能な操作はすべて、境界がその電球を通過する半平面を生成します。 選択したすべての半平面を交差させると、常に軸に平行な長方形が得られますが、場合によっては縮退または空になります。 

同じ選択肢をもっとわかりやすく表示する方法があります。 最終的に照らされた領域が長方形 (R) であると仮定します。 ((X,Y)) にある電球は、電球が厳密に (R) の内側にない場合でも、(R) の 4 つの辺のうちの 1 つを正確に位置合わせできます。 電球が外側または境界上にある場合は、(R) を含む対応する半平面を選択します。 逆に、電球が厳密に内側 (R) にある場合、その 4 つの半平面のどれも長方形全体を含むことができません。 したがって、元の問題はまさに、内部に電球が含まれていない (H\times W) ステージ内で最大面積の軸に平行な長方形を見つける問題です。 

これは、すべての (x) 座標とすべての (y) 座標が異なる場合に特化した、点に関する古典的な最大の空の四角形の問題です。 個別の座標条件により、以下の区間表現が特にきれいになります。 同じ削減は、この問題の既知の治療法で使用される重要な観察でもあります。 

(N\le 100000) では、(O(N^2)) スキャンは実行できません。 最悪のケースは、各間隔の最大垂直ギャップを維持するために必要な作業を考慮する前の、おおよそ (5\times10^9) 間隔の状態です。 座標境界は (10^8) に達するため、座標圧縮は便利ですが、グリッドベースの方法はまったく問題外です。 

誤って処理されやすい境界ケースがいくつかあります。 たとえば角に電球が 1 つあるとします。```
100 100 1
0 0
```ステージ全体は有効です。電球がその境界上にあるため、答えは (10000) になります。 境界点を禁止されたものとして扱うテストでは、誤ってゼロが返されます。 

電球が下降対角線を形成している場合、```
4 4 5
0 4
1 3
2 2
3 1
4 0
```答えは(6)です。 (4\times4) ステージ全体は不可能ですが、最適とは単に連続する (x) 座標または連続する (y) 座標間の最大ギャップではありません。 両方の側面を同時に考慮する必要があります。 

最後に、長方形はその境界で複数の電球に接触する可能性があります。 それらの電球は許可されています。 このため、定式化では、点をまったく含まない長方形ではなく、空の内部が使用されます。 

## アプローチ

 直接的なアプローチは、電球を (x) で並べ替え、候補の長方形内に水平方向に位置する連続する電球のグループを選択し、それらの (y) 座標間の最大の垂直方向のギャップを計算することです。 候補となる四角形の水平投影にちょうど電球 (l,\ldots,r) が含まれているとします。 その水平側面は、前後のバルブ、またはステージの境界に達するまで外側に押すことができます。 したがって、その最大可能幅は次のようになります。 

[
 x_{r+1}-x_{l-1}、
 ]

 ここで、(x_0=0) および (x_{N+1}=H) です。 

この水平に含まれる電球の固定セットでは、垂直間隔の内部に選択された (y) 座標が含まれていてはなりません。 ステージ境界 (0,W) と値 (y_l,\ldots,y_r) を追加し、並べ替えて、連続する最大のギャップを取得します。 その値を (h(l,r)) と呼びます。 この間隔で表される最適な長方形の面積は次のとおりです。 

[
 (x_{r+1}-x_{l-1})h(l,r)。 
]

 これにより、正確な (O(N^2)) アルゴリズムが得られます。 一度に 1 つの位置を拡張 (r) し、選択した (y) 座標を順序付けされたセットに維持できるため、各間隔を効率的に処理できます。 問題は間隔の数です。 (N=100000) の場合、(N(N+1)/2) 個、つまり約 (5\times10^9) 個あります。 

最適化は、関連する間隔が強力な入れ子構造を持っていることを観察することから始まります。 区間 ([l,r]) の場合、(h(l,r)) は、その区間に属する (y) 座標を挿入した後の最大ギャップです。 間隔を拡大しても既存のギャップを分割することしかできないため、(h) が増加することはありません。 この単調性により、重要な最大状態のみを保持することができます。 

分割統治ソリューションでは、まさにこれらの状態が使用されます。 (x) で順序付けされた点の再帰セグメントごとに、コンパクトなトリプルのセットを構築します。 

[
 (l、r、h)、
 ]

 ここで、([l,r]) は (x) 間隔、(h) は利用可能な最大垂直ギャップです。 保持された間隔は層状ファミリーを形成します。一方が他方を含まない限り、そのうちの 2 つは部分的に重なり合うことはできません。 ある間隔に別の間隔が含まれる場合、そのギャップ値はそれより大きくなりません。 これら 2 つのプロパティは、潜在的に 2 次のコレクションが分割統治レベルごとに線形サイズのコレクションに崩壊する理由です。 

次に、2 つの再帰的な部分を結合する必要があります。 それらのトリプルが ((l_i,r_i,h_i)) および ((l_j,r_j,h_j)) の場合、互換性のある四角形は水平方向に重なり合います。 

[
 \min(r_i,r_j)-\max(l_i,l_j)
 ]

 そして縦の隙間

 [
 h_i+h_j。 
]

 したがって、彼らの貢献は

 [
 (h_i+h_j)
 \left(\min(r_i,r_j)-\max(l_i,l_j)\right)。 
]

 残りの問題は、2 つの層状三重族にわたる構造化された最大値です。 入れ子になった区間は 2 次元の支配問題として処理されます。 部分的に重複する間隔は、2 番目の分割統治によって処理できます。 交差部分問題内では、(h) で順序付けするとトリプルが単調になります。(h) が増加すると、左の端点は右に移動し、右の端点は左に移動します。 結果として得られる実現可能なパートナー セットはスライディング ウィンドウであり、最終的な最大計算に必要な単調性を与えます。 

これは、最大の空の長方形定式化の既知の (O(N\log^3N)) 解で使用されるものと同じ構造最適化です。 文献では、一般的な最大の空の長方形の問題について、より洗練された境界も示していますが、ここでの個別の座標構造は、コンテストの解決策としては十分です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(N^2\log N)) | (O(N)) | 遅すぎる |
 | 最適な分割統治 | (O(N\log^3N)) | (O(N\log N)) | 承認済み |

 ## アルゴリズムのチュートリアル

1. すべての電球を (x) で並べ替えます。 結果の座標を (x_0=0) および (x_{N+1}=H) として (x_1,\ldots,x_N) として書き込みます。 すべての (y) 座標は個別であるため、対応する (y) 座標は順列を形成します。 
2. 実行可能なすべての照明を軸に平行な空の長方形として解釈します。 これにより、すべての電球における 4 方向の選択が削除され、それが 1 つの幾何学的条件に置き換えられます。つまり、電球が厳密に長方形の内側に存在することはできません。 
3. (x) 間隔 ([l,r]) の場合、(0,y_l,\ldots,y_r,W) 間の最大ギャップとして (h(l,r)) を定義します。 長方形の水平投影にこれらの電球が正確に含まれている場合、その最大幅は (x_{r+1}-x_{l-1}) となるため、候補領域は ((x_{r+1}-x_{l-1})h(l,r)) になります。 
4. (x) インデックスの間隔で再帰的に解きます。 1 つの再帰セグメント内では、最大状態 ((l,r,h)) のみを維持します。 新しいポイントが間隔に追加される場合、既存の垂直方向のギャップのみを分割できるため、その最適なギャップが大きくなることはありません。 これにより、支配的な状態を破棄するために必要な層状性と単調性が得られます。 
5. 左半分と右半分を再帰的に解きます。 水平セットが完全に半分に含まれるすべての最適な長方形は、その再帰呼び出しによってすでに考慮されています。 
6. 関連する水平間隔が分割点を横切って交わる長方形を結合します。 2 つの状態の場合、それらの結合された水平方向のスパンは 2 つの間隔の交差によって決まりますが、それらの 2 つの垂直方向のギャップは追加的に寄与します。 最大化する値は

 [
 (h_i+h_j)
 \left(\min(r_i,r_j)-\max(l_i,l_j)\right)。 
]
 7. 間隔のペアをネストされたペアと交差するペアに分割します。 ネストされた間隔は座標に関する支配条件を満たしており、標準の 2 次元順序付けで処理できます。 交差ペアの形式は次のとおりです。 

[
 l_i<l_j<r_i<r_j。 
]

 これは本当に難しい唯一のケースです。 
8. 交差するペアに 2 番目の分割統治を適用します。 各ノードでは、条件を満たすペアのみが存在します。 

[
 l_i<l_j\lemid<r_i<r_j
 ]

 処理されます。 2 次中点を横切らないペアは再帰的に渡されます。 
9. 左側のファミリーを増加 (h) してソートし、右側のファミリーを減少 (h) してソートします。 保持される間隔は層状であるため、(h) を増やすと、左の端点が右に移動し、右の端点が左に移動します。 固定された右状態の場合、その有効な左状態は連続したスライディング ウィンドウを形成します。 これらのウィンドウの端点は単調に移動するため、すべてのペアを列挙することなく、すべてのペアの最大値を見つけることができます。 
10. すべての再帰レベルでこの組み合わせを繰り返します。 最初の分割統治は 1 つの対数係数に寄与し、構造化交差計算はさらに 2 つの対数係数に寄与し、(O(N\log^3N)) が得られます。 

不変条件は、すべての最大の空の四角形が、保持された間隔状態の 1 つでの表現、または異なる再帰的な半分からの 2 つの状態の互換性のある組み合わせとしての表現を持つということです。 間隔を拡大しても垂直方向のギャップを破壊することしかできないため、支配された状態は後でより良い長方形の一部になることはできません。 ネストされたケースと交差するケースでは、すべての相対間隔順序が使い果たされるため、最適な長方形は破棄されません。 

## Python ソリューション

 (O(N\log^3N)) アルゴリズムのフル コンテスト実装は、従来のセグメント ツリー ソリューションよりも大幅に複雑になります。 特に、交差ペア ルーチンでは、層状トリプル ファミリとその単調スライディング ウィンドウを維持する必要があります。 短い Python 実装は、受け入れられたアルゴリズムの忠実な翻訳ではなく、ここで (O(N^2)) 実装を提示しながら、受け入れられたというラベルを付けることは、(N=100000) に対して誤解を招く可能性があります。 

参考までに、幾何学的縮小と (O(N^2)) ベースラインは簡単です。```python
import sys
input = sys.stdin.readline

def largest_empty_rectangle(H, W, points):
    points.sort()

    n = len(points)
    x = [0] + [p[0] for p in points] + [H]
    y = [0] + [p[1] for p in points] + [W]

    ans = 0

    for l in range(1, n + 1):
        vals = [0, W]

        for r in range(l, n + 1):
            vals.append(y[r])
            vals.sort()

            height = 0
            for i in range(1, len(vals)):
                height = max(height, vals[i] - vals[i - 1])

            width = x[r + 1] - x[l - 1]
            ans = max(ans, width * height)

    return ans

def solve():
    H, W, N = map(int, input().split())
    points = [tuple(map(int, input().split())) for _ in range(N)]
    print(largest_empty_rectangle(H, W, points))

if __name__ == "__main__":
    solve()
```このコードは、小規模なインスタンスの正しさの神託として役立ちますが、指定された制約に対する送信アルゴリズムではありません。 ネストされたループは (x) 間隔ごとに列挙し、選択された (y) 座標をソートすると実装がさらに遅くなります。 受け入れられているアプローチは、この列挙を上で説明した層状の分割統治構造に置き換えます。 

最大面積は (10^{16}) であるため、Python では乗算には任意精度の整数を使用する必要があります。 Python はこれを自動的に処理しますが、C++ 実装には 64 ビット整数が必要です。 

ステージ境界は、水平方向に (0) と (H)、垂直方向に (0) と (W) として含まれます。 これは、ステージ境界にある電球に特別な処理が必要ない理由でもあります。 

## 実用的な例

 サンプル 1 では、点はすでに (x) によって並べ替えられています。 

| (l) | (r) | 水平スパン | 選択された (y) 値 | 最大の垂直ギャップ | エリア |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 1 | (1-0=1) | (0,4,4) | 4 | 4 |
 | 1 | 2 | (2-0=2) | (0,4,3,4) | 3 | 6 |
 | 1 | 3 | (3-0=3) | (0,4,3,2,4) | 2 | 6 |

 | 3 | 5 | (4-2=2) | (0,2,1,0,4) | 1 | 2 |

サンプル 2 では、左下隅に電球が 1 つだけあります。 

| (l) | (r) | 水平スパン | 垂直ギャップ | エリア |

これらの痕跡は、「厳密に」という言葉がなぜ重要なのかを示しています。 長方形の境界上の点によって長方形が無効になることはありません。これにより、サンプル 2 のコーナー バルブがステージ全体と共存できるようになります。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | (O(N\log^3N)) | 層状区間の構築と 2 レベルの分割統治の組み合わせは、それぞれ対数係数に寄与します。 |
 | スペース | (O(N\log N)) | 再帰的なトリプルファミリーと補助構造は、対数的に多くのレベルにわたって保存されます。 |

 (N=100000) の場合、二次列挙は基本的に大きすぎます。 分割統治構造により、関連する区間相互作用の数がポイントごとに多対数的に減少します。 これは、元の (10) 秒、(1) GB コンテストの制限によって必要とされるスケールです。 一般的な最大の空の長方形に関する文献でも、これが単純なスキャンではなく、自明ではない計算幾何学問題であることが確認されています。 

## テストケース

# helper: run solution on input string, return output string

    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdout = io.StringIO()

    try:
        solve()
        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

"""
) == "6\n"

 ## 特殊なケース

 コーナーケースの場合```
1 1 1
0 0
```唯一の電球が隅にあります。 フルステージの内部は空ですので、答えは(1)です。 間隔表現には境界点として電球が含まれていますが、それでも垂直方向のギャップ (1) と水平方向の幅 (1) が得られます。 

のために```
4 4 1
2 2
```唯一の点は厳密にステージ全体の内側にあるため、(16) エリアの長方形は禁止されています。 最適な長方形は、左半分、右半分、上半分、下半分のいずれかを占めることができ、面積は (8) になります。 これは、点が厳密に候補四角形の内側にあるかどうかではなく、候補四角形の境界上にあるかどうかだけをチェックする実装をキャッチします。 

のために```
4 4 2
0 0
