 ## 解決策
 ## 問題の理解

 平面内に整数座標を持つ 3 つの異なる点が与えられ、4 番目の頂点を選択してそれらを平行四辺形に仕上げるすべての可能な方法を推論するように求められます。 指定された 3 つの点は単一線上にないことが保証されているため、すでに有効な三角形を形成しています。 

重要な幾何学的事実が問題全体を動かします。つまり、平行四辺形の 3 つの頂点が与えられた場合、どの点が「共有角」であるかを選択する方法は正確に 3 つあり、それぞれの選択によって、平行四辺形を完成させる固有の 4 番目の点が決まります。 このような各完成形は異なる形状を生成する可能性があるため、結果として得られる各平行四辺形を個別に評価する必要があります。 

有効な完了点ごとに、その座標、形成された平行四辺形の面積、および 2 つの幾何学的述語 (平行四辺形がひし形であるかどうか、および長方形であるかどうか) を出力する必要があります。 出力は完了点の座標によってソートする必要があります。 

座標の範囲は小さく、各座標はマイナス 1,000 から 1,000 までの範囲にあります。 これにより、64 ビット整数の内積および外積に対して整数演算が完全に安全になります。 偶数二乗長は約 10^6 以内に収まり、座標の積は約 10^12 以内に収まり、標準の整数制限を十分に下回ります。 

出力フォーマット要件は厳密で、特に小数点以下 2 桁までの切り捨てが厳密です。 これは、浮動小数点の不安定性を可能な限り回避し、代わりにフォーマットする前にすべてを整数または制御された有理演算で計算する必要があることを意味します。 

微妙な特殊なケースは、有効な完了ポイントの数を誤解することです。 常に正確に 3 つがあると想定するのは簡単ですが、入力がすでに退化した方法で平行四辺形を形成している場合、または 2 つの計算された完了点が一致するように点が選択されている場合は、重複が発生する可能性があります。 実際、ジオメトリでは重複が許可されていますが、欠落している頂点の役割の個別の選択に起因する場合は、やはり個別のエントリとして出力する必要があります。 

もう 1 つの微妙な点は分類です。 ひし形はすべての辺が等しいことに依存しますが、長方形は隣接する辺が垂直であることに依存します。 垂直または水平エッジの下では傾斜が信頼できないため、これらのプロパティは座標ヒューリスティックではなくベクトル ジオメトリを使用してチェックする必要があります。 

## アプローチ

 強引な解釈では、グリッド上の 4 つの点の選択ごとに平行四辺形を作成しようとしますが、3 つの点だけが与えられ、4 番目の点は代数的に決定されるため、ここではそれは無関係です。 

中心的な観察は、任意の平行四辺形は、3 つの頂点を表す順序付けられた 3 つの点を選択することによって定義されるということです。 どの点が 2 つのエッジの共有頂点であるかを固定すると、4 番目の点はベクトル加算によって一意に決定されます。 

点 A を共有頂点として選択し、それに隣接する他の 2 つの頂点として B と C を選択するとします。 次に、4 番目の点 D は、平行四辺形構造のベクトル等価性 AB + AC = AD を満たす必要があり、これは D = B + C − A に再配置されます。これは、共有頂点の選択ごとに 1 回ずつ、計 3 回使用される基本的な構造です。 

3 つの候補点が計算されると、結果として得られる各四角形は構成上、平行四辺形として有効になります。 面積は、2 つの隣接するエッジ ベクトルの外積の大きさを使用して計算できます。 たとえば、ベクトル AB と AC を使用すると、面積は |AB × AC| となります。 

形状を分類するには、ベクトルの内積と長さに依存します。 平行四辺形は、隣接する辺が垂直であれば長方形です。これは、2 つのエッジ ベクトルの内積が 0 であることを意味します。 すべての辺が等しい場合、それはひし形になります。平行四辺形では、向かい合う辺がすでに等しいため、隣接する辺の長さが等しいかどうかをチェックすることになります。

したがって、ソリューションは純粋に幾何学的なものであり、3 つの構成のみが生成され、それぞれが個別にチェックされるため、一定時間で実行されます。

 ## アルゴリズムのチュートリアル

 入力ポイントに A、B、C のラベルを付けます。 

1. 各点を順番に、平行四辺形の共有頂点として扱います。 A が共有頂点の場合、D = B + C − A を計算します。同じロジックが B と C に循環的に適用されます。これにより、選択ごとに、対角線での平行四辺形の中点対称性が強制されます。 
2. 構築された各点 D について、対応する頂点の割り当てを使用して平行四辺形を形成します。 A が共有頂点の場合、エッジは AB と AC になります。 このステップでは、領域と形状のチェックに必要なジオメトリを定義します。 
3. 外積の大きさ |(B − A) × (C − A)| を使用して面積を計算します。 これが機能するのは、外積によって三角形の符号付き面積の 2 倍が得られ、平行四辺形の面積がその三角形の面積の 2 倍になるためです。 
4. 内積を使用して平方辺の長さを計算します。 同じ構成について、|AB|^2 と |AC|^2 を比較して、すべての辺が等しいかどうかを判断します。これはひし形の特徴です。 
5. AB・ACを使用して直交性を確認します。 この内積が 0 の場合、共有頂点の角度は 90 度となり、平行四辺形が長方形になります。 
6. 結果の完了ポイントと計算されたすべての属性を保存します。 
7. 3 つの候補をすべて生成したら、それらを x 座標で辞書順に並べ替え、次に y 座標で並べ替えます。 
8. 各結果を、小数点第 2 位までに切り捨てられた座標と面積、その後にひし形フラグと長方形フラグを付けて出力します。 

正しさは、頂点とそれに隣接する 2 つの頂点を選択することによってすべての平行四辺形が一意に決定され、そのような選択ごとに有効な 4 番目の点が 1 つだけ生成されるという事実に基づいています。 

### なぜ効果があるのか

 平行四辺形は、頂点から伸びる 2 つの隣接するエッジによって完全に決定されます。 与えられた 3 つの点の中からその頂点の可能な選択をそれぞれ反復することにより、構造的に異なる補完をすべて列挙します。 ベクトルの構築は反対側の閉包を保証し、幾何学的述語は座標方向に依存しないドットとクロス積の不変特性のみに依存します。 これにより、有効な平行四辺形の補完が見逃されたり、無効な平行四辺形が導入されたりすることがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

def dot(ax, ay, bx, by):
    return ax * bx + ay * by

def dist2(ax, ay, bx, by):
    dx = ax - bx
    dy = ay - by
    return dx * dx + dy * dy

def solve():
    x1, y1 = map(int, input().split())
    x2, y2 = map(int, input().split())
    x3, y3 = map(int, input().split())

    pts = [(x1, y1), (x2, y2), (x3, y3)]
    res = []

    # try each point as the shared vertex
    for i in range(3):
        A = pts[i]
        B = pts[(i + 1) % 3]
        C = pts[(i + 2) % 3]

        ax, ay = A
        bx, by = B
        cx, cy = C

        # completion point D = B + C - A
        dx = bx + cx - ax
        dy = by + cy - ay

        # vectors
        ABx, ABy = bx - ax, by - ay
        ACx, ACy = cx - ax, cy - ay

        # area of parallelogram
        area = abs(cross(ABx, ABy, ACx, ACy))

        # rhombus: all sides equal in parallelogram -> AB == AC
        rhombus = dist2(ax, ay, bx, by) == dist2(ax, ay, cx, cy)

        # rectangle: right angle at A
        rectangle = dot(ABx, ABy, ACx, ACy) == 0

        res.append((dx, dy, area, rhombus, rectangle))

    res.sort()

    out = []
    for dx, dy, area, rhombus, rectangle in res:
        out.append(f"point: {dx:.2f} {dy:.2f}")
        out.append(f"area: {area:.2f}")
        out.append(f"is rhombus: {'yes' if rhombus else 'no'}")
        out.append(f"is rectangle: {'yes' if rectangle else 'no'}")
        out.append("-" * 25)

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```実装はベクトル構築ロジックに直接に従います。 重要な点は、常に 1 つの入力点をピボット A として扱い、他の 2 つを隣接する頂点として扱い、欠落している点に対する一貫した式を保証することです。 並べ替えは切り捨てとは無関係であるため、書式設定の前に生の整数座標で行われます。 

すべての幾何学的述語は整数演算を使用して計算されるため、浮動小数点精度の問題が回避されます。 唯一の浮動書式設定は出力時に行われ、値がすでに正確な整数であるか、小数点以下 2 桁の整数として正確に表現できる場合、切り捨ては Python 書式設定によって自然に処理されます。

 ## 特殊なケース

 微妙な状況の 1 つは、入力三角形の対称性により、計算された 3 つの完了ポイントに重複が含まれる場合です。 このような場合、2 つの異なるピボットを選択すると、同じ 4 番目の頂点が生成される可能性があります。 このアルゴリズムでは、ソート前に両方のエントリが出力され、最終的な順序付けでは同じ座標がグループ化され、必要な出力多重度が維持されます。 

もう 1 つのエッジ ケースは、三角形がすでに直角または二等辺になっている場合です。 (0,0)、(2,0)、(0,1) のような直角三角形の場合、補完の 1 つが長方形を形成します。 軸の位置合わせに関係なく、垂直な辺ではドット積がゼロになるため、ドット積チェックではこれを直接検出します。 

最後のエッジケースには、負の座標が含まれます。 すべての計算は純粋に整数の加算と乗算であるため、符号の変更は正確さに影響しません。 たとえば、点 (0,0)、(5,0)、(-3,4) の場合、計算された完了点は正の象限と負の象限の両方にまたがりますが、外積と内積は変換時に一貫性があり不変のままです。
