 ## 解決策
 ## 問題の理解

 DNA 鎖を表すアルファベット {A、C、G、T} 上の文字列が与えられています。 各文字には固定の補数があり、A は T とペアになり、C は G とペアになります。DNA 文字列を取得し、それを逆にして、すべての文字をその補数で置き換えると、ステートメントで逆補文字列と呼ばれるものが得られます。 

タスクは、元の文字列がその逆補数と同一かどうかを確認することです。 つまり、左から i 番目のすべての位置について、i の文字は位置 n − 1 − i の文字の補数と一致する必要があります。 

入力サイズは最大 10^6 文字で、二次関数は直ちに除外されます。 すべての位置のペアを直接比較するソリューションが線形であれば問題ありませんが、ループ内で文字列の構築を繰り返したり、反転を繰り返したりするものは時間制限を超えます。 

よくある失敗例は、補数ルールを適用せずに、誤って通常の意味での回文性のみをチェックしてしまうことです。 たとえば、文字列「ATAT」は、A ↔ T と反転するとマッピング後にパターンが保持されるため有効ですが、「AAAA」は通常の回文であっても失敗します。 もう 1 つの微妙な間違いは、逆補文字列を明示的に構築していることです。 これはまだ O(n) ですが、タイトなループ内で不用意に実行すると、不要なオーバーヘッドやメモリの重複が発生する可能性があります。 

## アプローチ

 直接的なアプローチは、逆補完文字列を明示的に作成し、それを元の文字列と比較することです。 文字列を反転し、補数関数を使用して各文字をマップしてから、等価性をチェックします。 これは正しく、線形時間で実行されますが、変換された文字列に対して追加のメモリ割り当てが実行され、不一致が早期に検出された場合には不必要な完全な構築が行われます。 

実際には完全に変換された文字列が必要ないことを観察することで、これを改善できます。 条件は純粋にペアごとです。一方の側を補完した後、位置 i は位置 n − 1 − i と一致する必要があります。 これは、両端から内側にスキャンして、その場で状態を確認できることを意味します。 

重要な構造的洞察は、問題がインデックスのペアに対する対称制約に帰着するため、O(1) 個の追加スペースと文字列の半分に対する 1 回のパスのみが必要であるということです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 逆補完文字列を作成する | O(n) | O(n) | 承認済み |
 | 2 点比較 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 2 つのポインターを使用して文字列を処理します。1 つは左端から始まり、もう 1 つは右端から始まります。 各ステップで、左側の文字が右側の文字の補数と等しいかどうかを確認します。 

1. 2 つのインデックス l = 0 と r = n − 1 を初期化します。これらは、逆補数条件を満たす必要がある文字列内の対称位置を表します。 
2. l ≤ r の場合、s[l] を s[r] の補数と比較します。 それらが異なる場合は、このミラーリングされたペアで定義条件が違反されているため、その文字列は DNA 回文ではないとすぐに結論付けることができます。 
3. 一致する場合、l += 1 および r -= 1 を設定して、両方のポインターを内側に移動します。これにより、以前にチェックされたすべての対称ペアが条件を満たすという不変条件が保持されます。 
4. ポインターが交差するまですべてのペアが有効な場合、文字列は逆補対称性を満たしているため、YES が出力されます。 

重要な考え方は、各キャラクタがミラーリングされた位置を持つ 1 つの制約にのみ参加するため、バックトラッキングやグローバル構造が必要ないということです。 

### なぜ効果があるのか

アルゴリズムは常に、処理されたすべてのペア (i, n − 1 − i) が s[i] = 補数(s[n − 1 − i]) を満たすことを強制します。 すべてのインデックスはそのようなペアに 1 つだけ参加するため、すべてのペアをカバーすることで正確さが保証されます。 単一の制約違反により条件全体が無効になるため、不一致の場合の早期終了は有効です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

comp = {
    'A': 'T',
    'T': 'A',
    'C': 'G',
    'G': 'C'
}

n = int(input())
s = input().strip()

l, r = 0, n - 1

while l <= r:
    if comp[s[r]] != s[l]:
        print("NO")
        sys.exit(0)
    l += 1
    r -= 1

print("YES")
```補数マッピングは、O(1) ルックアップ用の辞書内で事前に計算されます。 2 ポインター ループは、追加の文字列を構築せずに対称位置をチェックします。 経由の終了`sys.exit(0)`これは、不一致が早期に発生する最悪の場合に最適です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    comp = {'A':'T','T':'A','C':'G','G':'C'}

    n = int(input())
    s = input().strip()

    l, r = 0, n - 1
    while l <= r:
        if comp[s[r]] != s[l]:
            return "NO"
        l += 1
        r -= 1
    return "YES"

# provided samples
assert run("4\nATAT\n") == "YES"
assert run("3\nAAA\n") == "NO"

# custom cases
assert run("1\nA\n") == "NO", "single char must mismatch unless self-complementary (none here)"
assert run("2\nAT\n") == "YES", "perfect complement pair"
assert run("6\nACGTAC\n") == "NO", "mixed structure breaks symmetry"
assert run("6\nACGTAC\n") == "NO"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1A | いいえ | 単一文字のエッジケース |
 | 2AT | はい | 最小有効ペア |
 | 6 ACGTAC | いいえ | 非回文構造 |

 ## 特殊なケース

 「A」のような単一文字の場合、アルゴリズムは s[0] と補数 (s[0]) を比較します。 補数(A) が T であるため、チェックはすぐに失敗し、正しく NO が返されます。 これは、この定義では長さ 1 の文字列が決して有効ではないことを示しています。 

「ATAT」のような偶数長の文字列の場合、すべてのペアが 1 回だけチェックされ、すべての制約が満たされるため、アルゴリズムは早期終了せずに続行し、YES を返します。 

「AAA」など、文字列の前半に現れる不一致の対称ペアの場合、アルゴリズムは最初の比較ですぐに終了します。 これにより、制約違反が 1 つあれば文字列を失格にするのに十分であるため、早期終了が正確さに影響を与えないことが確認されます。
