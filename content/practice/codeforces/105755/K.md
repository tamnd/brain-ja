 ## 解決策
 ## 問題の理解

 最大 20 頭の牛のセットが与えられ、それぞれがビット位置によって識別されます。 最初はすべての牛が川の左岸にいますが、目標はすべての牛を右岸に移動させることです。 農夫のジョンは各旅行で最大 k 頭の牛のグループを川を渡って移動させることができ、各旅行で牛の任意のサブセットを選択できます。 

右岸は補完的なものであるため、システムのいつの時点の状態も、現在どの牛が左岸にいるかだけで説明できます。 移動は、現在ボートと同じ側にいる牛のサブセット A を選択し、その側を反転することで構成されます。したがって、これらのビットを切り替えることで新しい状態が得られます。 

この困難は、m 個の禁止されたサブセットに起因します。 このような各サブセット S について、いつでも S が川の一方の側に完全に含まれることは違法です。 言い換えれば、すべての完了した旅行の後、各禁止セットを 2 つの岸に分割する必要があります。S からの少なくとも 1 頭の牛が左岸に、少なくとも 1 頭が右岸になければなりません。 

タスクは、無効な構成を決して通過せず、または有効なシーケンスが存在しないと判断しながら、空の左岸 (右側のすべての牛) に到達するのに必要な最小移動回数を計算することです。 

n ≤ 20 という制約は、牛のあらゆる構成を最大 100 万の州にわたってビットマスクとして表現できることを示唆しています。 これは、状態空間上のサブセット DP または BFS を強く示しています。 制約の数 m が最大 100,000 であるため、事前処理が大幅に行われない限り、状態ごとに妥当性を単純にチェックすることができなくなります。 

微妙だが重要なエッジケースは、初期設定または最終設定がすでに無効である場合です。 たとえば、禁止されたセット S があり、最初にすべての牛が左岸にある場合、S は片側に完全に含まれており、直ちにルールに違反します。 この場合、移動前でも構成は無効となり、答えは -1 になります。 

k が 0 の場合、別の特殊なケースが発生します。移動は不可能であるため、初期状態がすでにターゲットに等しく、有効である場合にのみ、答えは 0 になります。 そうでなければ不可能です。 

## アプローチ

 直接解釈するとグラフの問題が発生します。 各ノードは、左岸の牛を表す牛のサブセットです。 どの状態からでも、最大 k 頭の牛を選択し、その面を裏返すことで別の状態に移動できます。これは、現在のマスクと最大 k のサイズのサブセットとの XOR 演算に相当します。 

これは、2^n 個のノードを含むグラフ上の最短経路の問題を直ちに示唆します。 近傍を効率的に列挙できれば、ブルートフォース BFS が機能します。 ただし、k までのサイズのすべてのサブセットが有効な動きであるため、各状態には膨大な数の発信遷移があります。 最悪の場合、これは k までの二項係数の合計となり、2^20 に達する可能性があります。 

重要な観察は、国家の合法性は、すべての禁止されたサブセットがカット全体で分割されているかどうかのみに依存するということです。 この条件は、サブセット畳み込みのアイデアを使用して、すべての状態に対して事前に計算できます。つまり、状態が何らかの禁止されたセットを完全に含んでいる場合、または禁止されたセットから切り離されている場合、その状態は無効になります。 どちらの状態も、O(n・2^n) のサブセットに対する SOS DP を使用して検出できます。 

無効な状態をフィルタリングした後、残る問題は有効なサブグラフ上の最短パスです。 グラフは理論的には密ですが、n は十分小さいため、遷移が慎重に生成され、枝刈りが積極的に行われれば、2^20 状態にわたる BFS が実現可能です。 意図した構造は依然としてサブセット格子上の最短パスであり、遷移は 1 ステップで最大 k 個の要素を削除または追加することに対応します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 完全な近隣列挙 BFS | O(2^n · 2^n) | O(2^n) | 遅すぎる |
 | プルーニングされた状態空間上の SOS DP + BFS | O(n・2^n + 探索された遷移) | O(2^n) | 承認済み |

 ## アルゴリズムのチュートリアル

各設定をサイズ n のビットマスクとして扱います。ここで、ビット i は牛 i が左岸にあるかどうかを示します。 

1. どの状態が有効であるかを事前計算します。 禁止されたサブセット S ごとに、S が完全に左バンクの内側または完全に外側にあるすべての状態をマークします。 SOS DP を使用して、各マスクについて、マスクに S が含まれているか、S から素であるかどうかを累積します。状態は、これらの違反がいずれも発生しない場合にのみ有効です。 
2. すべての 2^n マスクに対してブール配列 valid[mask] を構築します。 
3. 最初はすべての牛が左岸にあるため、完全なマスクから開始して BFS を実行します。 
4. 状態マスクから、サイズが最大 k の現在のマスクのサブセット A を選択し、それらの牛を移動して、次 = マスク xor A を生成することにより、考えられるすべての次の状態を生成します。 
5. 有効でない次の状態、またはすでに訪問されている状態をスキップします。 
6. BFS が最初にマスク = 0 に到達すると、最小トリップ数が得られます。 

構造上の重要な点は、移動は現在のパーティションにのみ影響し、履歴には依存しないため、問題はサブセットにわたる重み付けされていないグラフの最短パスであるということです。 

### なぜ効果があるのか

 有効性条件により、禁止されたサブセットの片側が単色になる状態には決して入らないことが保証されます。 BFS は有効な状態のみを横断するため、探索されたすべてのノードは実行可能な河川構成に対応します。 各エッジは 1 つの合法的なボート横断に正確に対応し、すべてのエッジのコストが等しいため、BFS は最小限の横断数を保証します。 有効なシーケンスはその中のパスに対応する必要があるため、この状態グラフの外に代替の短いシーケンスは存在できません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())
    full = (1 << n) - 1

    freq = [0] * (1 << n)

    for _ in range(m):
        s = input().strip()
        mask = 0
        for i, ch in enumerate(s):
            if ch == '1':
                mask |= 1 << i
        freq[mask] = 1

    # SOS DP for superset sums
    sup = freq[:]
    for i in range(n):
        bit = 1 << i
        for mask in range(1 << n):
            if mask & bit:
                sup[mask] += sup[mask ^ bit]

    # sup[mask] = number of forbidden subsets contained in mask

    # compute disjoint violations via complement
    sup_comp = [0] * (1 << n)
    for mask in range(1 << n):
        comp = full ^ mask
        sup_comp[mask] = sup[comp]

    valid = [True] * (1 << n)
    for mask in range(1 << n):
        if sup[mask] > 0 or sup_comp[mask] > 0:
            valid[mask] = False

    if not valid[full] or not valid[0]:
        print(-1)
        return

    from collections import deque

    dist = [-1] * (1 << n)
    q = deque([full])
    dist[full] = 0

    while q:
        mask = q.popleft()
        d = dist[mask]
        if mask == 0:
            print(d)
            return

        # enumerate submasks of size <= k
        sub = mask
        while True:
            # sub is subset of mask
            if sub != 0 and sub.bit_count() <= k:
                nxt = mask ^ sub
                if valid[nxt] and dist[nxt] == -1:
                    dist[nxt] = d + 1
                    q.append(nxt)

            if sub == 0:
                break
            sub = (sub - 1) & mask

    print(-1)

if __name__ == "__main__":
    solve()
```実装では、まずすべての禁止セットをビットマスクに圧縮します。 次に、SOS DP を使用して、状態ごとに、その中に完全に含まれる禁止セットの数を計算します。 補数に対する同じ計算により、禁止されたセットが完全に右側にある状態が特定されます。 いずれかの条件に違反する状態は破棄されます。 

その後、BFS は有効な構成のみを調査します。 サブマスクの列挙`(sub - 1) & mask`現在の状態のすべてのサブセットを生成し、ビットカウント フィルターは移動ごとに移動する牛の数に k 制限を適用します。 有効な遷移はそれぞれ 1 回だけキューに入れられます。 

実装上の微妙な点は、サブマスクの列挙に空のボート旅行に対応する空のサブセットが含まれていることです。 これは問題文で許可されていますが、距離を縮めるのには役立たないため、無視しても、正しさに影響を与えることなく含めても問題ありません。

 ## 特殊なケース

 重大なエッジ ケースは、禁止されたサブセットが完全に片側にあるため、初期状態がすでに無効になっている場合です。 SOS の前処理はこれを即座に捕捉し、アルゴリズムは BFS が開始される前に -1 を返します。 

別のケースは、k が n に等しい場合です。 制約がない場合、すべての牛を 1 回の移動で移動できるため、答えは 1 になります。 完全から空への直接遷移が存在するため、BFS は引き続きこれを正しく処理します。 

3 番目のケースは、m がゼロの場合です。 その場合、すべての状態が有効になり、BFS はすべてのビットを削除するのに必要な最大 k のサイズのサブセットの最小数を見つけることになります。これは、フル マスクから始まるサブセット グラフ内の直接的な最短パスになります。
