 ## 問題の理解

 整数のペアを数えています$(a, b)$単純な線形制約を満たすもの: それらの合計は指定された値に固定されます$n$、両方の数値はゼロを中心とする対称区間内になければなりません。 間隔は次のように定義されます。$p$： 両方$a$そして$b$の間にある必要があります$-10^p$そして$10^p$、包括的。 

したがって、タスクは 2 次元でペアを個別に検索することではありません。 一度$a$選ばれて、$b$強制される$n - a$。 唯一の問題は、次の整数値がいくつあるかです。$a$両方を維持してください$a$そして$n-a$許容範囲内です。 

入力は 2 つの整数だけで、1 つは目標合計を定義し、もう 1 つは許容値の大きさを定義します。 出力は、次の有効な整数の選択肢の数です。$a$、これは有効なペアに直接対応します。 

構造の複雑さという点では、制約は非常に小さいです。$p \le 9$、したがって、境界は最大で$10^9$。 つまり、有効範囲は常に最大でもサイズの連続した間隔です。$2 \cdot 10^9 + 1$、つまり、すべての可能な値を列挙するソリューションは、$a$すでに境界線に達していますが、最悪の場合でも実行可能ですが、不要です。 

主体的に選択しようとすると素朴な間違いが現れる$a$そして$b$次に合計でフィルタリングすることで、実際には 1 次元である構造を効果的に二重にカウントします。 もう 1 つのよくある間違いは、両方の境界を両方の変数に同時に適用する必要があることを忘れていることです。 

具体的なエッジ状況は、間隔が非常に狭く、解決策が存在しない場合に発生します。 たとえば、次の場合$n = 25$そして$p = 1$、範囲は$[-10, 10]$。 その範囲内の 2 つの数値の合計が 25 になることはないため、答えは 0 でなければなりません。制約の片側のみをチェックするアプローチでは、誤って正の数が報告されます。

 ## アルゴリズムのチュートリアル

 1. 境界を計算する$M = 10^p$。 これにより、両方の変数の許容範囲が定義されます。 問題全体はこの 1 つの値によって制約されます。 
2. 条件を変換する$a \in [-M, M]$最初の間隔に直接入る$I_1 = [-M, M]$。 
3. 条件を書き換える$b = n - a \in [-M, M]$の制約に$a$。 

これは次のようになります。$$-M \le n - a \le M$$これは以下と同等です:$$n - M \le a \le n + M$$2番目の間隔を与える$I_2 = [n - M, n + M]$。 
4. これら 2 つの区間の交差部分を計算します。 左側の境界は次のとおりです。$$L = \max(-M, n - M)$$そして、正しい境界は次のとおりです。$$R = \min(M, n + M)$$5. もし$L > R$、間隔は重複せず、有効な値はありません$a$存在するので、答えは0です。 
6. それ以外の場合、交差部分の整数値の数は次のようになります。$R - L + 1$、これが最終的な答えです。 

### なぜ効果があるのか

 すべての有効なペア$(a, b)$によって一意に決定されます$a$、および制約$a$まさに両方の要件です$a$そして$n-a$一定の間隔内にあります。 これは、次の 2 つの独立した間隔制約に変換されます。$a$。 それらの交差は、過剰カウントや省略なしに、実行可能なセットを正確に捕捉します。 この計算により、元の 2 変数制約システムが 1 つの区間計数問題に縮小され、すべての有効な解が保持され、すべての無効な解が構築によって除外されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, p = map(int, input().split())
    M = 10 ** p

    L = max(-M, n - M)
    R = min(M, n + M)

    if L > R:
        print(0)
    else:
        print(R - L + 1)

if __name__ == "__main__":
    solve()
```ソリューションは、最大許容範囲を計算します。$a$両方の制約の下で、その重複部分にある整数の数を直接カウントします。 実装の重要な詳細は、両方の境界を対称的に計算し、単純な最大値と最小値の交差を適用することです。 オフバイワンのリスクは最終的なカウントに現れます。 整数間隔には包括的な性質があるため、に 1 を加算する必要があります。$R - L$。
