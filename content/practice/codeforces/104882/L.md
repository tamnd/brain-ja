 ## 解決策
 ## 問題の理解

 私たちは、次のような形状を持つことが知られている、平面上の未知の直線を復元しようとしています。$y = kx + b$、両方のパラメータは次の範囲の実数です。$-100$そして$100$。 線について何かを学ぶ唯一の方法は、「この点からの最短距離は何ですか」という形式の質問をすることです。$(x, y)$ラインまで？」と尋ねると、ジャッジはその距離を返します。 

インタラクションには制約があります。そのような質問は最大 5 つまで行うことができ、その後は次の近似値を出力する必要があります。$k$そして$b$最大でも相対誤差または絶対誤差あり$10^{-3}$。 

各クエリは幾何学的制約を与えます。つまり、線から一定の距離にあるすべての点が 2 本の平行線を形成します。 したがって、それぞれの答えは単一の線を特定するのではなく、クエリ点を中心とした対称的な可能性のペアに制限します。 難しいのは、これらの非線形制約の少数を組み合わせて一意の線にすることです。 

境界は微妙な意味で重要です。 以来$k$そして$b$小さいので、次のような座標を使用してクエリを安全に構築できます。$-100, 0, 100$数値の不安定性がありません。 問題は数値精度ではなく、距離式の絶対値から曖昧さを解決することです。 

単純な戦略では、2 つまたは 3 つの点からラインを推測しようとしますが、ライン上の点は得られず、距離だけが得られます。 つまり、私たちは標識情報を直接観察することはありません。 

よくある失敗例は、距離式内の符号が固定されていると想定している場合です。 たとえば、からの距離を解釈する$(0,0)$として$b / \sqrt{k^2+1}$それが実際にあることを無視する$|b| / \sqrt{k^2+1}$の符号を失います。$b$。 この対称性を無視したアプローチでは、複数の有効な候補線が生成されます。 

## アプローチ

 強引なアイデアは、いくつかの点をサンプリングし、各クエリを平行な境界線のペアを定義するものとして扱い、すべての可能性を幾何学的に交差させようとすることです。 各クエリはバイナリの曖昧さを導入するため、$m$までのクエリ$2^m$候補行。 5 つのクエリを使用すると、すでに最大 32 の可能性があり、まだ管理可能ですが、勾配切片形式で直接実行すると、交差点のジオメトリが乱雑になり、数値的に不安定になります。 

重要な観察は、表現を切り替えることです。 と協力する代わりに、$y = kx + b$、行を正規化された形式で扱います。$$Ax + By + C = 0$$私たちの回線はどこですか$A = k$、$B = -1$、$C = b$、スケーリングまで。 距離の式は次のようになります。$$\frac{|Ax + By + C|}{\sqrt{A^2 + B^2}}$$各クエリは次の二次方程式を与えます。$A, B, C$しかし、より重要なのは、符号までの線形制約と共有正規化係数を与えることです。 

厳選した3つのポイントでお悩みを軽減します。 各クエリでは次の結果が得られます。$$|kx - y + b| = d \cdot \sqrt{k^2 + 1}$$させて$t = \sqrt{k^2 + 1}$。 その場合、すべてのクエリは次のようになります。$$kx - y + b = \pm d \cdot t$$これにより、問題は未知の要素を含む小規模なシステムの解決に変換されます。$k, b, t$方程式ごとの未知の符号。 3 つのクエリでは、3 つの方程式と、総当たりで実行できる 8 つの可能な符号割り当てのみが得られます。 各割り当てにより、一貫性をチェックできる候補ソリューションが生成されます。 

これにより、幾何学的な再構成が、ケースごとに閉形式の解をもつ有限列挙問題に変わります。

 ## アルゴリズムのチュートリアル

 3 つの固定クエリ ポイントを選択します。$(0,0)$、$(100,0)$、 そして$(0,100)$。 

1. クエリ$(0,0)$、 受け取る$d_1$。 これは以下に対応します$|b| = d_1 \cdot t$、 どこ$t = \sqrt{k^2 + 1}$。 
2. クエリ$(100,0)$、 受け取る$d_2$。 これにより、$|100k + b| = d_2 \cdot t$。 
3. クエリ$(0,100)$、 受け取る$d_3$。 これにより、$|b - 100| = d_3 \cdot t$。 

この時点で、すべての情報は共有スケール係数を持つ 3 つの絶対値方程式にエンコードされます。$t$。 

1. すべての符号トリプルを列挙する$(e_1, e_2, e_3) \in \{\pm 1\}^3$。 各絶対値を符号付き形式に置き換えます。$$b = e_1 d_1 t,\quad 100k + b = e_2 d_2 t,\quad b - 100 = e_3 d_3 t$$2. 最初の 2 つの式から、$b$そして解決します$k$に関しては$t$:$$100k = t(e_2 d_2 - e_1 d_1)$$それで$$k = \frac{t(e_2 d_2 - e_1 d_1)}{100}$$3. に代入します$t^2 = k^2 + 1$で単一の方程式が生成されます。$t$。 明示的に解決してください。 
4.回復する$k$そして$b$次に、3 番目の方程式との整合性を確認します。$$|b - 100| \approx d_3 t$$許容範囲内で一致する場合、この割り当ては正しいです。 
5. 出力$k, b$。 

重要なメカニズムは、各符号の選択により、非線形絶対制約が残り 1 つの未知のスカラーを持つ線形システムに変換され、正規化条件がそのスカラーを一意に解決することです。 

### なぜ効果があるのか

 直線は、この表現における 3 つの実際の自由度 (暗黙的な形式の傾き、切片、スケール) によって完全に決定されます。 各クエリは 1 つの二次制約に影響しますが、共有スケールの導入後は$t$、それぞれは符号まで線形になります。 符号の曖昧さは離散的で小さいため、徹底的な列挙により正しい構成がテストされることが保証されます。 正しい符号が選択されると、システムには一貫した独自のソリューションが得られ、他のすべての構成は少なくとも 1 つの制約に違反します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def ask(x, y):
    print(f"? {x} {y}")
    sys.stdout.flush()
    d = float(input().strip())
    if d < 0:
        sys.exit(0)
    return d

def solve():
    d1 = ask(0, 0)
    d2 = ask(100, 0)
    d3 = ask(0, 100)

    for e1 in (-1, 1):
        for e2 in (-1, 1):
            for e3 in (-1, 1):

                # We derive t from k^2 + 1 = t^2
                # k = t * C / 100, where C = e2*d2 - e1*d1
                C = e2 * d2 - e1 * d1

                denom = 1 - (C * C) / 10000.0
                if abs(denom) < 1e-12:
                    continue

                t2 = 1.0 / denom
                if t2 <= 0:
                    continue

                t = math.sqrt(t2)

                k = t * C / 100.0
                b = e1 * d1 * t

                # verify third equation
                if abs(abs(b - 100) - d3 * t) < 1e-3:
                    print(f"! {k:.10f} {b:.10f}")
                    sys.stdout.flush()
                    return

solve()
```この実装は代数を直接反映しています。 唯一の微妙な点は、分母が次の場合に数値が不安定になるのを防ぐことです。$1 - C^2 / 10000$記号のほぼ縮退した構成により、 は非常に小さくなります。 

浮動小数点の丸め処理が平方根の抽出と相互作用する場合、複数の代数分岐により数値的には妥当でも不正確な解が生成される可能性があるため、検証ステップは不可欠です。

 ## 特殊なケース

 微妙な状況の 1 つは次のような場合です。$1 - C^2 / 10000$極端に小さくなります。 これは、導出された線形関係がほぼ強制的な、縮退に近い構成に対応します。$k^2 \approx -1$、これは不可能であり、無効な符号の割り当てを示します。 このような場合、アルゴリズムは分母チェックにより分岐を安全にスキップします。 

もう 1 つのエッジケースは次のような場合です$b = 0$、最初のクエリは距離ゼロを返します。 アルゴリズムはこれを自然に処理します。$e_1 d_1 t = 0$力$b = 0$かかわらず$t$、そして残りの方程式は依然として次のことを決定します$k$ユニークに。 

3 番目のケースは、傾き切片表現で線が垂直に近い場合ですが、$k$は有界で有限であるため、表現は安定しており、正規化は$t$爆発を防ぎます。
