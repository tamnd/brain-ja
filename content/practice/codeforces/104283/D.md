 ## 解決策
 ## 問題の理解

 単一の正の整数が与えられます$N$。 すべての整数に対して$k$から$1$に$N$との関係に基づいて「美しさ」という価値を定義します。$k$そして$N$。 

もし$k$～と共通の素因数を共有しない$N$、 それから$k$は有効であるとみなされ、その寄与は次の最大公約数に依存します。$k-1$そして$N$。 それ以外の場合は、$k$そして$N$が互いに素でない場合、寄与はゼロです。 

タスクは、全体にわたるこれらの寄与の合計を計算することです。$k$範囲内で$[1, N]$。 

したがって、概念的には、すべての還元された残基を法として反復処理します。$N$、そしてそのようなそれぞれについて$k$、追加します$\gcd(k-1, N)$答えに。 

制約が意味するのは、$N$すべてを繰り返すのに十分な大きさにすることができます$k$毎回 gcd を計算することは受け入れられません。 直接ループの場合はコストがかかります$O(N \log N)$、次の場合はすぐに壊れます。$N$周りにいる$10^9$あるいは$10^7$。 

主な問題点は、次の条件です。$\gcd(k, N) = 1$」はドメインをオイラーのトーティエント構造に制限しますが、寄与はシフトされた値に依存します。$k-1$、直接周期性が破壊されます。 

微妙なエッジケースが現れる$k = 1$。 ここ$k$は常に以下と素である$N$、 しかし$k-1 = 0$、 それで$\gcd(0, N) = N$。 残基全体にわたって一様な挙動を仮定する多くの単純な導出は、この特別な寄与を黙って見逃しており、最終的な答えが正確にシフトする可能性があります。$N$。 

たとえば、次の場合$N = 5$、 有効$k$は$1,2,3,4$。 貢献内容は、$5,1,1,1$、合計すると$8$。 を無視する式は、$k=1$ケースは誤って与えます$4$。 

## アプローチ

 ブルートフォースの解決策は簡単です。 すべてを繰り返します$k$から$1$に$N$、どうかを確認してください$\gcd(k, N) = 1$、そうであれば追加します$\gcd(k-1, N)$答えに。 これは正しいですがコストがかかります$O(N \log N)$、これは大規模なものには遅すぎます$N$。 

重要な観察点は、次の条件です。$\gcd(k, N) = 1$手段$k$換算残差系のモジュロにわたる範囲$N$。 すべての値を繰り返す代わりに、貢献度を値ごとにグループ化できます。$\gcd(k-1, N)$。 

させて$d = \gcd(k-1, N)$。 それから$d \mid N$、そして私たちは共素がいくつあるか数えています$k$満足する$k \equiv 1 \pmod d$。 この構造は、約数によるグループ化を示唆しています。$N$、個人ではなく$k$。 

重要な単純化は、約数とオイラーの合計関数の観点から合計を再解釈することです。 各剰余クラスの寄与は、モジュラー システム内の互いに素な剰余を数えることに集約されます。これはまさに$\varphi(\cdot)$エンコードします。 

これにより、問題がすべてにわたって繰り返されることが軽減されます。$k$の約数を反復する$N$、通常は$O(\sqrt{N})$。

 ## アルゴリズムのチュートリアル

 計算する最終的な式は、すべての有効な式をグループ化することによって導出されます。$k$の値に従って$\gcd(k-1, N)$。 これにより、除数ベースの合計が得られます。 

### ステップ

 1. すべての約数を計算します。$N$。 

考えられるすべての値$\gcd(k-1, N)$の約数でなければなりません$N$したがって、他の値は寄与できません。 
2. 各約数について$d$のセットを考えてみましょう。$k$そのような$k \equiv 1 \pmod d$。 

書き込み$k = 1 + d \cdot t$、制約は内部で線形数列になります。$[1, N]$。 
3. これらの候補者の中で、次の条件を備えた候補者のみを保持します。$\gcd(k, N) = 1$。 

この制限は、オイラーのトーティエント関数が係数に換算したときにカウントされるものとまったく同じです。$N/d$、条件は方法によって異なりますので、$k$の残りの要素と相互作用します$N$。 
4. 除数に関連付けられた有効な寄与の数$d$になる$\varphi(N/d)$、そしてそのような各貢献は追加します$d$答えに。 

これは、すべての有効な残基クラスがその gcd 値に正確に寄与するためです。$d$。 
5. すべての約数の合計$d$、最後に特殊なケースを修正します$k = 1$これにより、きれいな除数の定式化に余分なオーバーカウントが導入されます。 

この調整により、次のような事実から生じる不一致が解消されます。$\gcd(0, N) = N$、これは除数のグループ化で均一に表されません。 

### なぜ効果があるのか

 すべての有効な$k$値によって一意に分類されます$d = \gcd(k-1, N)$、そしてこれ$d$分けなければなりません$N$。 変革$k \mapsto k-1$は、サイズを変更せずに縮小剰余系をシフトし、オイラーのトーティエント関数は、モジュラー スケーリングの下で​​互いに素のままの剰余の数を正確にカウントします。 これにより、すべての有効な$k$は 1 つの除数バケット内で 1 回だけカウントされ、すべてのバケットが正しい gcd 値に寄与します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def divisors(n):
    small, large = [], []
    i = 1
    while i * i <= n:
        if n % i == 0:
            small.append(i)
            if i * i != n:
                large.append(n // i)
        i += 1
    return small + large[::-1]

def phi(n):
    res = n
    i = 2
    x = n
    while i * i <= x:
        if x % i == 0:
            while x % i == 0:
                x //= i
            res -= res // i
        i += 1
    if x > 1:
        res -= res // x
    return res

def solve():
    n = int(input())
    
    divs = divisors(n)
    ans = 0
    
    for d in divs:
        ans += d * phi(n // d)
    
    ans -= 1
    print(ans)

if __name__ == "__main__":
    solve()
```実装ではまず、次のすべての約数を列挙します。$N$有効な gcd 貢献はすべて、それらのいずれかから提供されている必要があるためです。 各約数について$d$、それは計算します$\varphi(N/d)$、この gcd 層に寄与する共素剰余クラスの数をカウントします。 このような各クラスは正確に貢献します$d$, だから私たちは蓄積します$d \cdot \varphi(N/d)$。 

最終的な減算は、$1$シフトされた剰余系を均一に扱うことによって導入されたオーバーカウントを修正し、特に次の境界動作を調整します。$k = 1$。

 ## 特殊なケース

 デリケートなケースの 1 つは、$N = 1$。 唯一の値は$k = 1$、これは互いに素ですが、$\gcd(0,1) = 1$。 式は次のようになります。$1 - 1 = 0$、これは直接評価と正しく一致します。 

もう 1 つのエッジケースは次のような場合です$N$プライムです。 それからほぼ毎回$k$貢献する$1$、 を除外する$k = 1$貢献するもの$N$。 最終的な答えは次のようになります$2N - 2$、除数の式に補正を加えたものは、これに正確に一致します。 

3 番目のケースは次の場合です。$N$には、2 の累乗など、多くの約数があります。 この状況では、複数の gcd 層のサイズが重複していますが、除数のグループ化により、各層が 1 回だけカウントされることが保証されます。$\varphi(N/d)$、剰余構造が非常に規則的である場合でも、二重カウントを回避します。
