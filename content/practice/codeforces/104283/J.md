 ## 解決策
 ## 問題の理解

 ボールのコレクションが与えられます。各ボールには最初に色があり、各色には関連する値があります。 これに加えて、ボールの色をある特定の色から別の色に変更できる変換ルールがあります。 これらの変換は、最終的に販売するボールを正確に k 個選択する前に、任意の数のボールに任意の順序で繰り返し適用できます。 

重要な考え方は、ボールは 1 つの変形に限定されないということです。 色 A を B に変えることができ、B を C に変えることができる場合、A も事実上 C になることができます。 したがって、各元の色には最終的に到達できる色のセット全体があり、各ボールについて、開始色から到達可能なすべての色の中で可能な限り最高の値に興味があります。 すべてのボールに達成可能な最高の値が割り当てられると、タスクは最大の合計値を持つ k 個のボールを選択することになります。 

この制約は、色の数と変換ルールの数の両方が大きくなり、この問題の一般的なバージョンでは最大約 100,000 になる可能性があることを意味します。 これにより、各ノードから到達可能なすべての色を個別に明示的に調査しようとするアプローチは即座に除外されます。 色ごとの単純な BFS または DFS は、同じ構造を繰り返し走査し、最悪の場合は 2 次の動作に低下します。 

単純な推論による微妙な失敗のケースは、変換が 1 ステップのみであると想定していることに起因します。 たとえば、変換 1 → 2 および 2 → 3 があり、値 p1 = 1、p2 = 5、p3 = 10 がある場合、単純なワンステップ更新では色 1 に値 5 を割り当て、そこで停止します。 正解すれば、1 が最終的に 3 になり、値 10 が得られるはずです。サイクルが存在する場合、別の失敗ケースが発生します。 1 → 2 → 3 → 1 の場合、3 色すべてが相互に到達可能であり、すべての色が最大値を共有する必要があります。 サイクルを崩壊させないアプローチは、到達可能な値を過小評価することになります。 

## アプローチ

 ブルートフォースアプローチは、各色について、操作を繰り返し適用して到達可能なすべての色を計算し、それらの中で最大価格を取得することです。 これは、各ノードから開始して DFS や BFS などのグラフ トラバーサルを実行することで実行できます。 これは正しいですが、同じトラバースを何度も繰り返します。 密なグラフでは、各走査がほぼすべてのノードを訪問する可能性があり、およそ O(n · (n + m)) の動作が発生します。これは、n と m の両方が大きい場合には非常に遅くなります。 

重要な構造的観察は、変換グラフが到達可能性を定義し、到達可能性は推移的であるということです。 これは、グラフを強く接続されたコンポーネントに圧縮することを直ちに示唆します。 強く接続されたコンポーネント内では、すべての色が他の色に到達できるため、すべての色が同じ達成可能な最高の値、つまりコンポーネント内の最大価格を共有する必要があります。 

強く接続された各コンポーネントを 1 つのノードに圧縮すると、結果として得られるグラフは有向非巡回グラフになります。 この DAG では、コンポーネントの最適値は、そのコンポーネント自体の内部の最適値と、到達可能なすべてのコンポーネントの最適値の間の最大値です。 これは、DAG 上の単純な伝播問題となり、トポロジーの逆順序で解決できます。 

元の色ごとに達成可能な最良の値を計算した後、各ボールは開始色の値を独立して継承します。 最後のステップは、単純に k 個の最大値を選択することです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ノードごとのブルート フォース トラバーサル | O(n(n + m)) | O(n + m) | 遅すぎる |
 | SCC + DAG 伝播 | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 各色がノード、各操作 xi → yi が有向エッジである有向グラフを構築します。 このグラフは、1 ステップでどの変換が許可されるかを正確にエンコードします。 
2. このグラフの強連結成分を計算します。 このステップの目的は、相互に到達できるすべての色をグループ化することです。 このようなグループ内では、どの色も他の色に変換できるため、それらの区別はもはや問題になりません。 
3. 各コンポーネントについて、その内部の基本値を、その内部のすべての元の色の中での最大価格として計算します。 これは、コンポーネントを離れることなく達成可能な最高の値です。 
4. 各コンポーネントがノードであり、コンポーネントを構成する元のノード間にエッジがある場合はコンポーネント間にエッジが存在する凝縮グラフを構築します。 SCC 圧縮によりサイクルが削除されるため、このグラフは非循環であることが保証されます。 
5. この凝縮された DAG を逆のトポロジー順序で走査します。 各コンポーネント u について、value[u] = max(value[u], value[v]) を設定することにより、すべての出力エッジ u → v を使用してその値を緩和しようとします。 これにより、最終的により良いコンポーネントに到達できた場合、その最良の値が確実に継承されます。 
6. 伝播後、各ボールに対応する開始色のコンポーネントの値を割り当てます。 
7. すべてのボールの値を降順に並べ替え、上位 k 個の値を合計します。 

正確さは、SCC がすべての周期的な相互到達可能性を捕捉し、凝縮グラフが循環なしで残りのすべての到達可能性関係を保存するという事実に依存します。 逆のトポロジー順序で処理するため、コンポーネントを処理すると、到達可能なすべてのコンポーネントにはすでに最終的な正しい値が設定されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

def solve():
    n, m, k = map(int, input().split())
    c = list(map(int, input().split()))
    p = list(map(int, input().split()))

    g = [[] for _ in range(n)]
    rg = [[] for _ in range(n)]

    for _ in range(m):
        x, y = map(int, input().split())
        x -= 1
        y -= 1
        g[x].append(y)
        rg[y].append(x)

    # Kosaraju: first pass order
    vis = [False] * n
    order = []

    def dfs1(v):
        vis[v] = True
        for to in g[v]:
            if not vis[to]:
                dfs1(to)
        order.append(v)

    for i in range(n):
        if not vis[i]:
            dfs1(i)

    comp = [-1] * n

    def dfs2(v, cid):
        comp[v] = cid
        for to in rg[v]:
            if comp[to] == -1:
                dfs2(to, cid)

    cid = 0
    for v in reversed(order):
        if comp[v] == -1:
            dfs2(v, cid)
            cid += 1

    comp_val = [0] * cid

    for i in range(n):
        comp_val[comp[i]] = max(comp_val[comp[i]], p[i])

    cg = [[] for _ in range(cid)]
    indeg = [0] * cid

    for v in range(n):
        for to in g[v]:
            if comp[v] != comp[to]:
                cg[comp[v]].append(comp[to])
                indeg[comp[to]] += 1

    # topological DP (Kahn)
    from collections import deque
    q = deque()

    for i in range(cid):
        if indeg[i] == 0:
            q.append(i)

    while q:
        u = q.popleft()
        for v in cg[u]:
            if comp_val[u] > comp_val[v]:
                comp_val[v] = comp_val[u]
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)

    vals = [0] * n
    for i in range(n):
        vals[i] = comp_val[comp[i]]

    vals.sort(reverse=True)
    print(sum(vals[:k]))

if __name__ == "__main__":
    solve()
```実装は、グラフを読み取り、Kosaraju の SCC アルゴリズムに必要な前方隣接リストと逆隣接リストの両方を構築することから始まります。 最初の DFS は終了順序を構築し、反転グラフ上の 2 番目の DFS はコンポーネント ID を割り当てます。 

圧縮後、各コンポーネントの初期値がノード間の最大価格として計算されます。 次に、冗長な作業を避けるためにセルフエッジを慎重にスキップして、凝縮されたグラフが構築されます。 

DAG 上の伝播では、キューベースのトポロジ トラバーサルが使用されます。 コンポーネントを処理するたびに、その最適な値を隣接コンポーネントにプッシュし、値の情報が到達可能パスに沿って流れるようにします。 

最後に、すべてのボールはそのコンポーネントの計算された最良の値を継承し、上位 k 個を選択します。 

## 実用的な例

 5 つの色と変換 1 → 2、2 → 3、4 → 5 を持つ小さなインスタンスを考えます。価格を p = [1、5、2、10、7] とし、初期色 [1、4、5、2、3] を持つ k = 2 個のボールが必要だとします。 

SCC 分解後、コンポーネント {1,2,3}、{4,5} が接続されていないことがわかります。そのため、実際には 4 → 5 はチェーンを形成しますが、元には戻らないため、SCC は {1}、{2}、{3}、{4}、{5} になります。 コンポーネントの値は最初は p と同じです。 

ここで伝播: 1 が 2 に到達し、3 に到達すると、コンポーネント 1 は 1,5,2 の最大値を取得して 5 になり、その後 3 に伝播して 3 も 5 になります。 同様に、4 が 5 に達すると、4 は max(10,7)=10 になり、5 に伝播して 10 になります。 

最終的なボールの値は [5, 10, 10, 5, 5] になります。 k = 2 を選択すると、10 + 10 = 20 となります。 

このトレースは、到達可能性によって有向チェーンに沿って値がどのように増加するか、またワンステップ更新だけでなくクロージャまで伝播がどのように継続する必要があるかを示しています。

 ## 特殊なケース

 重要なエッジ ケースは、完全に周期的なグラフです。 すべての色が 1 つのサイクルを形成する場合、すべての色が最終的にグローバル最大価格になる必要があります。 SCC ステップではすべてが 1 つのコンポーネントにマージされ、伝播ではそれ以上何も行われないため、結果は即時に正確になります。 

もう 1 つのエッジ ケースは、最大値が最後のノードにある長いチェーンです。 DAG 伝播がなければ、中間ノードで最適な値が得られることはありません。 逆トポロジ処理により、最適な値がすべての先行者に到達するまでチェーンを逆方向に流れることが保証されます。 

最後のエッジケースは、操作がまったくない場合です。 この状況では、各ボールは孤立したままとなり、答えは単に k 個の最大の元の価格の合計になります。 各ノードが独自の SCC を形成し、伝播エッジが存在しないため、アルゴリズムはこれを自然に処理します。
