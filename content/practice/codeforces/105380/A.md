 ## 解決策
 ## 問題の理解

 特別な種類のサイズの順列を構築するように求められます`n`。 ここでの順列とは、次の数値を並べ替えることを意味します。`1`に`n`それぞれ 1 回ずつ。 

ねじれは、順列が固定点のないインボリューションのように動作しなければならないことです。 つまり、位置の値を見ると、`j`、呼んでください`a[j]`、同じマッピングを再度適用すると、次のように戻ります。`a[a[j]] = j`。 同時に、どの位置もそれ自体にマッピングすることはできません。`a[j] != j`あらゆる人にとって`j`。 

この構造により、すべてのインデックスが他の 1 つのインデックスと強制的にペアになります。 もし`a[x] = y`、その後自動的に`a[y] = x`、そしてどちらでもない`x`または`y`等しいことができる。 したがって、順列は完全に素の 2 サイクルで構成されます。 

入力サイズ`n`と同じ大きさにすることができます`100000`したがって、どのソリューションも線形時間で実行する必要があります。 二次関数または偶数$O(n \log n)$構築自体は問題ありませんが、繰り返しの検索や照合を伴うものは不必要であり、危険です。 

重要なエッジケースが現れるのは、`n`奇数です。 すべての要素がペアに属さなければならない場合、要素の数が奇数であると、1 つのインデックスがペアにならないままになります。 そのため、条件を満たすことができなくなります。 

たとえば、次のようなとき`n = 3`、次のようなペアが必要になります`(1, 2)`そして`(3, ?)`、しかしパートナーは残っていない`3`。 いかなる試みも固定点を強制するか、全単射要件を破ることになります。 

したがって、本当の困難は、可能な場合に順列を構築することではなく、構造が不可能な場合を認識することです。 

## アプローチ

 素朴な試みは、どの位置がすでに使用されているかを追跡することによって順列を構築しようとすることです。 以下のインデックスを反復処理できます。`1`に`n`、および未使用のインデックスごとに`i`、別の未使用のインデックスを検索します`j`そしてセット`a[i] = j`、`a[j] = i`。 条件を明示的に強制するため、これにより正確さが保証されます。 

問題はパフォーマンスです。 インデックスごとに、残りの未使用のインデックスをスキャンしてパートナーを見つける場合があります。 最悪の場合、これはおよそ次のようになります。$n + (n-1) + (n-2) + \cdots$、つまり$O(n^2)$。 と`n = 100000`、これは実現可能な限界をはるかに超えています。 

重要な観察点は、次の条件です。`a[a[j]] = j`そして`a[j] != j`順列がインデックス上で完全に一致するように強制します。 パートナーを動的に検索する必要はありません。 すべての要素が他の 1 つの要素と正確にペアになっていることを確認するだけで済みます。 

その解釈を受け入れると、構築はすぐに始まります。数値を順番にリストし、隣接するペアを交換すると、有効な 2 サイクルが自動的に作成されます。 各ペア`(1,2)`、`(3,4)`、`(5,6)`、など両方の条件を満たします。 マッピングは対称的であり、それ自体にマッピングされる要素はありません。 

もし`n`が奇数の場合、1 つの要素がペアになっていないため、有効な構造が存在しません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースマッチング | O(n²) | O(n) | 遅すぎる |
 | 隣接スワッピング | O(n) | O(1) おまけ | 承認済み |

 ## アルゴリズムのチュートリアル

 1. かどうかを確認します。`n`奇数です。 そうであれば、すぐに出力します`-1`。 これは、ペアリングにはサイズがちょうど 2 のグループが必要であり、奇数の数では完全なペアリングが不可能になるためです。 
2. 配列を初期化する`a`サイズの`n + 1`(便宜上、1 から始まるインデックスを使用します)。 
3. インデックスを反復処理する`i`から`1`に`n`の段階で`2`。 
4. 各ペアについて`(i, i+1)`、割り当てます`a[i] = i+1`そして`a[i+1] = i`。 これにより、隣接する要素間に相互マッピングが作成されます。 
5. すべてのインデックスを処理した後、配列を出力します。`1`に`n`。 

2 ずつ進める理由は、各操作がちょうど 2 つの未使用のインデックスを消費し、ペア間で重複がないことが保証されるためです。 

### なぜ効果があるのか

 構築された順列は、2 つのサイクルの素結合です。 各インデックス`i`パートナーは 1 人だけ割り当てられます`i+1`または`i-1`、したがって、マッピングは全単射です。 置換を 2 回適用すると、元のインデックスに戻ります。これは、2 回交換すると元の位置が復元されるためです。`a[a[i]] = i`。 どの要素もそれ自体にマップされることはないため、固定小数点条件も満たされます。 異なるペア間には相互作用がないため、このプロパティはグローバルに保持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    if n % 2 == 1:
        print(-1)
        return
    
    a = list(range(n + 1))
    
    for i in range(1, n + 1, 2):
        a[i], a[i + 1] = i + 1, i
    
    print(*a[1:])

if __name__ == "__main__":
    solve()
```このソリューションでは、まずパリティをチェックすることで不可能条件を処理します。 これは失敗する可能性がある唯一のケースです。 

配列はダミーの 0 インデックスで初期化され、1 から始まるインデックスが問題定義と一致するようになります。 これにより、指数調整の繰り返しが回避され、オフバイワンのリスクが軽減されます。 

このループは、隣接するインデックスをペアごとに一定時間で交換します。 各反復で 2 つのポジションが永続的に確定されるため、追加の簿記は必要ありません。 

最後に印刷`a[1:]`ダミースロットを削除し、順列を出力します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

 | 時間 | O(n) | 各インデックスは 1 回アクセスされ、1 回スワップされます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque

    # embedded solution
    def solve():
        n = int(sys.stdin.readline().strip())
        if n % 2 == 1:
            print(-1)
            return
        a = list(range(n + 1))
        for i in range(1, n + 1, 2):
            a[i], a[i + 1] = i + 1, i
        print(*a[1:])

    old_stdout = sys.stdout
    sys.stdout = io.StringIO()
    solve()
    out = sys.stdout.getvalue().strip()
    sys.stdout = old_stdout
    return out

# provided samples

assert run("4\n") == "2 1 4 3", "sample 2"

# custom cases

assert run("2\n") == "2 1", "minimum even case"
assert run("3\n") == "-1", "small odd impossibility"
assert run("10\n") == "2 1 4 3 6 5 8 7 10 9", "larger even case"

 ## 特殊なケース

 いつ`n = 1`、単一の要素に対して可能なパートナーはありません。 アルゴリズムはすぐに戻ります`-1`、固定点が許可されないという要件に一致します。 

いつ`n = 2`、ループは 1 回実行され、位置が入れ替わります。`1`そして`2`、生産`[2, 1]`。 手動で確認すると、`a[a[1]] = a[2] = 1`インデックスについても同様に`2`、正しさを確認します。 

いつ`n`次のような奇数はありますか`5`、アルゴリズムは構築が開始される前にパリティを検出します。 のために`n = 5`、戻る`-1`次のような部分的なペアリングの試行を回避します`(1,2)`、`(3,4)`これはインデックスを残します`5`ペアが解除され、固定小数点または無効なマッピングが強制されます。
