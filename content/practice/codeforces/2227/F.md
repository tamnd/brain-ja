 ## 解決策
 ## 問題の理解

 各列には高さから積み上げられた立方体が含まれます$1$高さまで$a_i$。 重力が右に曲がった後は、立方体の高さは変わりません。 同じ高さの立方体は独立してスライドし、その水平レベルで右端の利用可能な位置を占めます。 

高さごとに考えると便利です。 固定高さの場合$h$、 定義する$$C_h=\#\{i : a_i\ge h\}.$$がある$C_h$そのレベルのキューブ。 重力が作用した後、それらは$C_h$立方体は右端を占めます$C_h$列、$$n-C_h+1,\dots,n.$$この問題は、すべての立方体の移動距離の合計を求めます。 重力の前では、最大で 1 つの立方体を削除できます。これは、1 つの列を選択することを意味します。$i$そして減少$a_i$による$1$。 

制約は大きいです。 すべてのテストケースにわたって、$$\sum n \le 2\cdot 10^5.$$二次関数はすぐに不可能になります。 平$O(n\sqrt n)$不快だろう。 ターゲットは$O(n)$または$O(n\log n)$テストケースごとに。 

最も危険なエッジ ケースは、1 つのキューブを削除すると他の多くのキューブの動作が変化する場合です。 

考慮する$$[1,2,3,2,1].$$最初の答えは$5$。 最後の列の唯一の立方体を削除すると、次のようになります。$$[1,2,3,2,0],$$そして答えは次のようになります$9$。 削除された立方体の動きを差し引くだけのソリューションでは、全体的な効果が失われます。 

もう 1 つの重要なケースは、次のような非減少配列です。$$[1,2,3,4,5].$$すべての立方体はすでにそのレベルの右端の位置を占めています。 答えは$0$、立方体を削除しても改善できません。 

3 番目のケースは、複数のポジションが同等に改善に貢献している場合です。 例えば、$$[5,4,1,1,1].$$正しい選択は、最大の列ではなく、グローバル構造に依存します。 

## アプローチ

 ブルートフォース ソリューションでは、あらゆる可能な削除が試行されます。 候補インデックスごとに、最終構成全体を再構築し、総移動距離を再計算します。 1 つの構成の結果を計算するには、すべての高さまたはすべての立方体を処理する必要があるため、全体の複雑さは少なくとも$O(n^2)$、さらに悪化することもよくあります。 と$n=2\cdot 10^5$、これは限界をはるかに超えています。 

重要な観察は、最終的な構成はカウントのみに依存するということです。$C_h$。 

高さの場合$h$、立方体が列を占有します$$n-C_h+1,\dots,n.$$柱の立方体$i$と高さ$h$動く$$(n-C_h+k)-i,$$どこ$k$高さを含む列の中でのランクです$h$。 

移動したキューブを数える代わりに、**移動しない**キューブを数えます。 

列を修正する$i$。 高さのある立方体$h\le a_i$カラムの際に正確に所定の位置に留まります$i$レベルの最後の右端のブロックに属します$h$。 これはつまり$$i \ge n-C_h+1.$$同様に、$$C_h \ge n-i+1.$$この条件を満たす最大の高さは正確に$$s_i=\min(a_i,a_{i+1},\dots,a_n),$$接尾辞の最小値。 

したがって、コラム$i$正確に含まれています$s_i$動かない立方体。 以来のコラム$i$含まれています$a_i$合計キューブの数、その列によって寄与される移動キューブの数は$$a_i-s_i.$$すべての列を合計すると最初の答えが得られます$$\text{base}=\sum_{i=1}^{n}(a_i-s_i).$$ここで、立方体を 1 つ削除することを考えてみましょう。 

減れば$a_i$による$1$、suffix-minimum 配列内で変更できる値は 1 つだけです: 列で表される最小値$i$。 合計の答えは次のように増加します$1$まさに、高さがその位置のサフィックスの最小値に等しい位置から立方体を削除したときです。 

させて$$f(x)=\#\{i:s_i=x\}.$$値を選択すると$x$suffix-minimum 配列に出現する場合、次の出現を 1 つ減らすことができます。$x$。 これにより、答えは次のように増加します$$f(x)-1.$$したがって、最善の改善は、$$\max_x (f(x)-1).$$すべてのサフィックスの最小値が 1 回だけ出現する場合は、何もしないのが最適です。 

したがって、最終的な答えは、$$\boxed{ \sum_{i=1}^{n}(a_i-s_i) + \max\!\left(0,\max_x f(x)-1\right) }.$$この観察は線形の解決策に直接つながります。

 ## アルゴリズムのチュートリアル

 1. サフィックスの最小配列を計算します。$$s_n=a_n,\qquad s_i=\min(a_i,s_{i+1}).$$2. コンピューティング$$\text{base}=\sum_{i=1}^{n}(a_i-s_i).$$これは、削除前の合計移動距離に等しくなります。 
3. suffix-minimum 配列に現れるすべての値の頻度を数えます。 
4. しましょう$$m=\max_x f(x).$$5. 可能な限り最善の改善は、$$\max(0,m-1).$$6. 出力$$\text{base}+\max(0,m-1).$$### なぜ効果があるのか

 列ごとに$i$、サフィックスの最小値$s_i$は、重力後に固定されたままになるその列内の立方体の正確な数です。 1 つおきの立方体は少なくとも 1 つの位置を移動します。 したがって$a_i-s_i$列ごとに移動するキューブをカウントします$i$、合計すると総移動距離が得られます。 

1 つのキューブを削除すると、現在サフィックスの最小値として機能している値にのみ影響します。 サフィックスの最小値の場合$x$表示されます$f(x)$1 つの出現を減らすと、1 つを除くすべてのポジションの最小値が破壊され、$f(x)-1$答えの中で。 除去しても大きなゲインは得られません。 したがって、最適な改善は次の最大値となります。$f(x)-1$。 

## Python ソリューション```python
import sys
from collections import defaultdict

input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        s = [0] * n
        s[-1] = a[-1]

        for i in range(n - 2, -1, -1):
            s[i] = min(a[i], s[i + 1])

        base = 0
        freq = defaultdict(int)

        for ai, si in zip(a, s):
            base += ai - si
            freq[si] += 1

        best = 0
        for cnt in freq.values():
            best = max(best, cnt)

        ans.append(str(base + max(0, best - 1)))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()

import sys
import io
from collections import defaultdict

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        s = [0] * n
        s[-1] = a[-1]

        for i in range(n - 2, -1, -1):
            s[i] = min(a[i], s[i + 1])

        base = 0
        freq = defaultdict(int)

        for ai, si in zip(a, s):
            base += ai - si
            freq[si] += 1

        best = max(freq.values())
        out.append(str(base + max(0, best - 1)))

    return "\n".join(out)

# minimum size
assert run("1\n1\n1\n") == "0"

# strictly increasing
assert run("1\n5\n1 2 3 4 5\n") == "0"

# all equal
assert run("1\n4\n3 3 3 3\n") == "3"

# suffix minimum repeated many times
assert run("1\n5\n1 2 3 2 1\n") == "8"

# decreasing array
assert run("1\n5\n5 4 3 2 1\n") == "10"

 ## 特殊なケース

 検討してください$$[1,2,3,4,5].$$サフィックスの最小配列は元の配列と等しくなります。 あらゆる周波数は$1$、したがって、改善項は次のようになります。$0$。 アルゴリズムの出力$0$、立方体が動かないという事実と一致します。 

考慮する$$[3,3,3,3].$$サフィックスの最小配列は次のとおりです。$$[3,3,3,3].$$基本的な答えは$0$、しかし値$3$4回登場します。 改善点は、$$4-1=3.$$このアルゴリズムは、共有最小プラトーから 1 つの立方体を削除する利点を正しく捉えています。 

考慮する$$[5,4,3,2,1].$$サフィックスの最小配列は次のとおりです。$$[1,1,1,1,1].$$基本的な答えは$$(5-1)+(4-1)+(3-1)+(2-1)+(1-1)=10.$$最大周波数は、$5$を改善し、$4$。 このアルゴリズムは、重力をシミュレートせずに、サフィックス最小周波数を通じてこれを完全に処理します。
