 ## 問題の理解

 部分配列積は次のように割り切れます。$6$製品に少なくとも 1 つの要素が含まれている場合に限り、$2$そして少なくとも 1 つの要因$3$。 

各数値について、その割り算のみ$2$そして$3$重要です。 正確な値は関係ありません。 すべての要素は、次の 4 つのグループのいずれかに属します。 

-$A$: で割り切れる$6$-$B$: で割り切れる$2$しかし、それによってではありません$3$-$C$: で割り切れる$3$しかし、それによってではありません$2$-$D$: どちらでも割り切れない$2$または$3$配列の順序を任意に変更できます。 目標は、積が次で割り切れるサブ配列の数を最小限に抑えることです。$6$。 

すべてのテスト ケースの合計の長さは最大でも$2 \cdot 10^5$、したがって、周りの解決策$O(n)$または$O(n \log n)$簡単に十分に高速です。 単一のテスト ケースにはすでに約$2 \cdot 10^{10}$サブアレイ。 

よくある間違いは、正確な製品に焦点を当てることです。 たとえば、$$[2,9]$$製品は$18$で割り切れます。$6$たとえどちらの要素も割り切れないとしても、$6$個別に。 要因の存在のみ$2$そして$3$重要です。 

もう 1 つの簡単な罠は、すべての要素にすでに両方の要素が含まれている場合です。$$[6,12,18].$$空でないすべての部分配列は次のように割り切れます。$6$、順序に関係なく。 任意の順列が最適です。 

3 番目のエッジ ケースは、配列にのみが含まれる場合です。$B$そして$D$要素。 その場合、部分配列には因子を含めることはできません$3$したがって、すべての順列が最適になります。 

## アプローチ

 強引なアイデアは、すべての順列を試し、有効な部分配列の数を計算し、最適な配置を維持することです。 

すべての可能性を直接チェックするため、これは正しいです。 残念ながら、さえ$n=10$すでに与えています$$10! = 3{,}628{,}800$$したがって、このアプローチはすぐに役に立たなくなります。 

重要な観察は、要因のみが$2$そして$3$案件。

要素の数が固定されている場合、含まれるサブ配列の数は、すべての要素が 1 つの連続したブロックを形成するときに最大になります。 したがって、因子が欠落しているサブ配列の数を最大化するには$2$、のすべての要素$C$そして$D$連続している必要があります。

 ## アルゴリズムのチュートリアル

 1. 数値を 4 つのグループに分割します。 

グループ$A$で割り切れる数値が含まれています$6$。 

グループ$B$で割り切れる数値が含まれています$2$しかし、それによってではありません$3$。 

グループ$C$で割り切れる数値が含まれています$3$しかし、それによってではありません$2$。 

グループ$D$残りのすべての番号が含まれます。 
2. のすべての要素を出力します。$A$。 
3. のすべての要素を出力します。$B$。 
4. のすべての要素を出力します。$D$。 
5. のすべての要素を出力します。$C$。 

各グループ内の順序は重要ではありません。 

### なぜ効果があるのか

 部分配列は次で割り切れません$6$要素が欠けている場合$2$、 要素$3$、またはその両方。 

因子を含まないすべての要素$2$まさに$C \cup D$。 それらを 1 つの連続したセグメントに配置すると、要素が欠落しているサブ配列の数が最大になります。$2$。 

因子を含まないすべての要素$3$まさに$B \cup D$。 それらを 1 つの連続したセグメントに配置すると、要素が欠落しているサブ配列の数が最大になります。$3$。 

アレンジメント$$A \;|\; B \;|\; D \;|\; C$$両方の目標を同時に達成できるため、$B \cup D$そして$C \cup D$それぞれが連続しています。 

不良サブアレイの数が最大化されるため、良好なサブアレイの数、つまり$f(a)$、最小化されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        arr = list(map(int, input().split()))

        A = []
        B = []
        C = []
        D = []

        for x in arr:
            by2 = (x % 2 == 0)
            by3 = (x % 3 == 0)

            if by2 and by3:
                A.append(x)
            elif by2:
                B.append(x)
            elif by3:
                C.append(x)
            else:
                D.append(x)

        ans = A + B + D + C
        print(*ans)

solve()
