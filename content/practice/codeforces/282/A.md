 ## 解決策
 ## 問題の理解

 この問題は、最初にゼロに設定された変数 _x_ が 1 つだけあるおもちゃのプログラミング言語で発生します。 プログラムの各行は、この変数をインクリメントまたはデクリメントするステートメントです。 演算は変数の前または後に指定できるため、ステートメントは次のようになります。`++X`、`X++`、`--X`、 または`X--`。 私たちのタスクは、すべてのステートメントを順番に実行した後、_x_ の最終値を決定することです。 

入力はステートメントの数から始まります`n`、 に続く`n`行、それぞれが有効なステートメントです。 出力は、_x_ の最終値を表す単一の整数です。 

制約を考慮すると、`n`は最大でも 150 ですが、これは現代のコンピューターにとっては非常に小さい値です。 これは、すべてのステートメントを個別に検査する単純なアプローチでも即座に実行されることを意味します。 大きな入力サイズ、整数のオーバーフロー、またはパフォーマンスの最適化に関する懸念はありません。 

明白ではないエッジケースは、シンボルの順序から発生します。 操作は前後に現れる可能性があるため、`X`、素朴なチェック`statement == "++X"`または`statement == "X++"`次のようなデクリメント操作を見逃す可能性があります`X--`。 の存在をチェックして増加と減少を検出する必要があります。`++`または`--`位置だけでなく、ステートメント内のどこでも。 たとえば、入力は次のとおりです。```
3
++X
X--
--X
```最終的な値は次のようになります。`0`、最初の値が増加し、2 番目の値が減少し、3 番目の値が再び減少するためです。 

## アプローチ

 ブルートフォースアプローチは簡単です。 カウンタを初期化する`x`ゼロに。 各ステートメントについて、文字列を調べます。 含まれている場合`++`、増分`x`; 含まれている場合`--`、デクリメント`x`。 これが機能するのは、すべてのステートメントに 1 つの操作と 1 つの変数が含まれているためです。 各ステートメントは個別に検査され、ステートメントごとに定数時間の文字列検索のみが実行されるため、合計操作数は次のように比例します。`n`。 のために`n = 150`、これは些細なことです。 

ブルートフォース手法はすでにステートメントの数に対して線形時間で実行されているため、ここには意味のある「高速」アルゴリズムはありません。 重要な洞察は、ステートメントを位置的に解析したりトークン化したりする必要がないということです。 2 文字の演算子の存在`++`または`--`で十分です。 この観察により、実装が簡素化され、文字の順序に関連する特殊なケースが排除されます。

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`x`ゼロに。 これは、プログラム内の唯一の変数の現在の値を表します。 
2. ステートメントの数を読み取り、`n`。 
3. プログラム内の各ステートメントについて、部分文字列が含まれているかどうかを確認します。`++`。 そうなった場合はインクリメントします`x`。 
4. ステートメントに次の内容が含まれている場合`--`、デクリメント`x`。 
5. すべてのステートメントを処理した後、次の値を出力します。`x`。 

機能する理由: アルゴリズムは、次の不変条件を維持します。`x`これまでに処理されたすべてのステートメントの最終的な効果が常に反映されます。 各ステートメントは変更します`x`上または下に 1 つだけ実行すると、すべてのステートメントに 1 つの操作が必ず含まれることが保証されます。 したがって、順次スキャンして更新することで、`x`検出された操作に従って、最終値が正しいことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
x = 0

for _ in range(n):
    statement = input().strip()
    if "++" in statement:
        x += 1
    elif "--" in statement:
        x -= 1

print(x)
```このソリューションは、まずステートメントの数を読み取り、初期化します。`x`。 各ステートメントについて、末尾の改行またはスペースが削除され、インクリメント演算子またはデクリメント演算子の存在がチェックされます。 私たちが使用するのは`in`演算子は前後に現れる可能性があるため、位置チェックではありません。`X`。 これにより、次のようなすべての順列の正確さが保証されます。`++X`または`X++`。 最後に、結果が出力されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    x = 0
    for _ in range(n):
        statement = input().strip()
        if "++" in statement:
            x += 1
        elif "--" in statement:
            x -= 1
    return str(x)

# provided samples
assert run("1\n++X\n") == "1", "sample 1"

# custom cases
assert run("3\n++X\nX--\n--X\n") == "-1", "mixed increments and decrements"
assert run("5\n++X\nX++\n++X\nX++\n++X\n") == "5", "all increments"
assert run("4\n--X\nX--\n--X\nX--\n") == "-4", "all decrements"
assert run("1\nX--\n") == "-1", "single decrement"
assert run("2\nX++\n--X\n") == "0", "increment followed by decrement"
```| テスト入力 | 期待される出力 | 検証内容 |

| すべて 5 増分 | 5 | すべての増分を正しく処理します。 
| すべてを 4 つデクリメントします | -4 | すべてのデクリメントを正しく処理します。
