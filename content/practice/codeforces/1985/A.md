 ## 解決策
 ## 問題の理解

 それぞれちょうど 3 文字の長さの 2 つの文字列が与えられており、私たちのタスクはそれらの最初の文字を交換することです。 各テスト ケースについて、入力は 2 つの文字列を提供し、出力は交換後に形成された 2 つの新しい文字列を反映する必要があります。 各文字列の 2 番目と 3 番目の文字は変更されません。 概念的には、各文字列を 3 つのタイルの単語として考えることができ、最初のタイルのみが対応する単語と交換されます。 目標は、最後の 2 文字をそのままにして、テスト ケースごとに新しい単語のペアを生成することです。 

制約は非常に小さく、文字列の長さは 3 で、テスト ケースの数は最大 100 です。これは、時間や空間を最適化する必要がないことを意味します。 文字を明示的に交換する単純な実装は、無視できるほどの時間で実行されます。 明らかではない特殊なケースは、主に同一の最初の文字に関するものです。 最初の文字が同じ場合、それらを交換しても文字列は変更されません。 たとえば、与えられた`"cat cat"`、スワップの結果は次のようになります。`"cat cat"`again, which is still valid. もう 1 つの潜在的なエッジ ケースは、すべての文字が同じである同一の文字列間の交換です。`"zzz zzz"`、これも変更されません。 

## アプローチ

 ブルートフォースアプローチは、この問題に対する最適なアプローチでもあります。 各テスト ケースでは、各文字列の最初の文字を抽出し、それらを交換して、文字列を再構築できます。 文字列の長さは常に 3 であるため、このアプローチは即時的であり、テスト ケースごとに一定時間で動作します。 問題を単純化する観察は、交換が最初の文字にのみ影響するということです。 他のすべての文字は変更されないため、複雑なループや条件は必要ありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(t) | お(1) | 承認済み |
 | 最適 | O(t) | お(1) | 承認済み |

 ここ`t`テストケースの数です。 

## アルゴリズムのチュートリアル

 1. テストケースの数を読み取り、`t`。 
2. テスト ケースごとに、2 つの文字列を読み取ります。`a`そして`b`。 
3. の最初の文字を抽出します`a`そして最初の文字は`b`。 
4. これらの最初の文字を交換して新しい文字列を作成します`a_new`そして`b_new`。 
5. 交換した文字を元の文字列の残りの 2 文字と連結します。 
6. 印刷`a_new`そして`b_new`スペースで区切ります。 

機能する理由: 最初の文字を交換することは、まさに問題が要求していることです。 文字列の長さは 3 であることが保証されているため、インデックス付けは安全であり、残りの 2 文字と連結すると、変更されていない部分が保持されます。 このアルゴリズムでは、他の文字が変更されず、交換が 1 回だけ実行されるため、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a, b = input().split()
        # Swap first characters
        a_new = b[0] + a[1:]
        b_new = a[0] + b[1:]
        print(a_new, b_new)

if __name__ == "__main__":
    solve()
```このソリューションは、高速 I/O を使用して入力を読み取り、各行を 2 つの文字列に分割し、交換を実行して、結果を出力します。 新しい文字列を直接構築するため、追加のストレージは必要ありません。

## 特殊なケース

 両方の文字列が同一の場合、次のようになります。`"cat cat"`、最初の文字を入れ替えても何も変わりません。 アルゴリズムは、常に交換された最初の文字と変更されていない残りの文字から新しい文字列を構築するため、これを適切に処理します。 最初の文字がすでに同じ場合、次のように`"zzz zzz"`、スワップでは文字列も変更されませんが、これは正しいことです。 このソリューションは、残りの文字を前提とせずに最初の文字のみを処理するため、制約内のすべてのバリエーションを正しく処理します。
