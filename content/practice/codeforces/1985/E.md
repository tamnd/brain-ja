 ## 問題の理解

 整数の辺の長さをもつ小さなボックスを 3D 空間の大きなボックスの中に配置するように求められます。 小さな箱には一定の体積が必要です$k$すべての角が整数座標にあるように、軸に沿って整列する必要があります。 課題は、大きなボックス内の有効な配置の数が最大化されるように、この小さなボックスの辺の長さを選択することです。 有効な配置は、ボックスがその境界を超えることなく、より大きなボックス内に完全に収まる場合に発生します。 

入力は次元で構成されます$x, y, z$大きな箱と希望の量$k$秘密箱の。 各テスト ケースでは、秘密ボックスの整数次元の任意の選択に対する個別の整数配置の最大数を出力する必要があります。 整数次元のセットが体積を生成しない場合$k$大きな箱の中に収まる量であれば、答えはゼロです。 

この制約により、大きなボックスの各辺は最大 2000 までとなります。$k$まで$x \cdot y \cdot z$。 最大 2000 のテスト ケースがありますが、すべてのテスト ケースの合計は$x$、$y$、 そして$z$すべてのテストで 2000 を超えません。これは、合計で、辺の長さまたは因数にわたる入れ子になったループが存在することを意味します。$k$おおよそを超えない$2000^3$すべてのテストケースにわたって。$k$非常に大きくなる可能性があるため、32 ビットのオーバーフローを避けるように注意する必要があります。 

単純なアプローチでは、1 つ以上の辺の長さがボックスの対応する寸法より大きいケースを見逃して、配置がゼロになる可能性があります。 たとえば、大きなサイズの箱$2 \times 2 \times 2$と$k = 7$制限内に 7 になる整数の 3 つ乗算がないため、整数次元のボックスに適合できません。 

## アプローチ

 ブルートフォースアプローチは、考えられるすべての整数のトリプレットを列挙することです。$(a, b, c)$そのような$a \cdot b \cdot c = k$。 各トリプレットについて、次を使用して、大きなボックス内に収まる配置の数を計算します。$(x-a+1) \cdot (y-b+1) \cdot (z-c+1)$、3 つの要素がすべて正の場合にのみカウントされます。 これが機能するのは、各軸に沿った有効な配置の数が、単に境界を超えずにボックスを開始できる位置の数であるためです。 この総当たりの難しさは因数分解です$k$そしてすべてのトリプルを生成します。 単純な立方体ループオーバー$a, b, c$まで$\sqrt[3]{k}$が遅すぎるとき$k$非常に大きく、最大で$2000^3$理論的には。 

重要な洞察は、約数を考慮するだけでよいということです。$k$。 まず、すべての約数を生成します。$k$まで$\sqrt{k}$。 各約数について$a$、すべての約数を考慮します$b$の$k // a$そしてセット$c = k // (a \cdot b)$。 これにより保証されます$a \cdot b \cdot c = k$。 次に、次のことを確認します$a \le x$、$b \le y$、 そして$c \le z$。 そうであれば、配置数を計算します$(x-a+1) \cdot (y-b+1) \cdot (z-c+1)$そして最大値を追跡します。 これにより、約数の数がゆっくりと増加するため、反復回数が大幅に減少します。$O(k^{1/3})$トリプルを生成するためのものです。 

問題には対称性があります。つまり、次の順序です。$a, b, c$～に関連した問題$x, y, z$箱は回転できないので。 正しい適合を取得するには、有効なトリプルごとに 6 つの順列すべてを考慮する必要があります。 すべての順列を考慮しないと、いくつかの最適な配置が失われる可能性があります。

## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取り、各ケースをループします。 抽出する$x, y, z, k$。 
2. このテスト ケースの最大配置数を追跡する変数を初期化します。 
3. Enumerate all divisors$a$の$k$。 各約数について$a$、$a$は、x 軸に沿った可能な長さを表します。 
4. それぞれについて$a$、すべての約数を列挙します$b$の$k // a$。 コンピューティング$c = k // (a \cdot b)$確実にする$a \cdot b \cdot c = k$。 
5. トリプルのすべての順列を生成する$(a, b, c)$。 各順列について、次のことを確認します。$a \le x$、$b \le y$、 そして$c \le z$。 その場合、各軸に沿った配置数を次のように計算します。$(x-a+1) \cdot (y-b+1) \cdot (z-c+1)$。 
6. すべての順列の最大配置数を追跡します。 
7. すべての約数と順列がチェックされた後、最大数を出力するか、配置が不可能な場合はゼロを出力します。 

なぜ効果があるのか​​: 因数分解によって$k$そしてすべての順列を考慮すると、体積を生み出すすべての整数の辺の長さの組み合わせを検査することが保証されます。$k$。 フィット感を確認する$x, y, z$有効性を保証します。 順列を考慮すると、ボックスが軸に沿って整列するすべての方法が把握されます。 実行可能なすべての候補を評価するため、計算された最大配置数は正確です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from itertools import permutations
from math import isqrt

def divisors(n):
    small, large = [], []
    for i in range(1, isqrt(n) + 1):
        if n % i == 0:
            small.append(i)
            if i != n // i:
                large.append(n // i)
    return small + large[::-1]

t = int(input())
for _ in range(t):
    x, y, z, k = map(int, input().split())
    max_places = 0
    divs_a = divisors(k)
    for a in divs_a:
        if a > x:
            continue
        remaining = k // a
        divs_b = divisors(remaining)
        for b in divs_b:
            c = remaining // b
            for (aa, bb, cc) in permutations([a, b, c]):
                if aa <= x and bb <= y and cc <= z:
                    places = (x - aa + 1) * (y - bb + 1) * (z - cc + 1)
                    if places > max_places:
                        max_places = places
    print(max_places)
```このソリューションでは、まず効率的に約数を生成し、次に有効なトリプルを構築します。 順列により、すべての軸の位置合わせが確実にチェックされます。 Python は大きな整数を処理するため、オーバーフローを回避し、ボックスの次元を超える約数を早期にスキップします。 位置の乗算には次の式を使用します$(dimension - side + 1)$それぞれの軸に沿って。
