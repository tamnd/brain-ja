 ## 解決策
 ## 問題の理解

 この問題では、整数配列のプレフィックスを分析し、特定のルールに従ってどのプレフィックスが「適切」であるかを判断するように求められます。 長さの接頭辞$i$他のすべての要素の合計に等しい要素がプレフィックス内に存在する場合、それは良好であるとみなされます。 たとえば、配列では`[1, 3, 2, 6]`、完全な配列が良い理由は、`6`等しい`1 + 3 + 2`。 単一要素の配列は、要素がゼロの場合にのみ有効です。 入力は複数のテスト ケースで構成され、それぞれが配列長とそれに続く配列要素を指定し、出力は各ケースの適切なプレフィックスの数です。 

この制約は、単一の配列が最大で$2 \cdot 10^5$すべてのテスト ケースの合計が同じ数を超えないこと。 これは次のような解決策を意味します$O(n^2)$最悪の場合、大まかな時間がかかるため、テスト ケースあたりの時間が遅すぎます。$4 \cdot 10^{10}$操作。 効率的なソリューションは、理想的にはテスト ケースごとに線形またはほぼ線形の時間で動作する必要があります。$O(n)$配列ごとに。 エッジ ケースには、単一要素の配列、ゼロのみを含む配列、複数の要素が「残りの合計」である可能性がある配列、初期には良好に見えても要素が追加されると失敗するプレフィックスが含まれます。 例えば、`[0, 1]`良くないから`0 ≠ 1`そして`1 ≠ 0`、 それでも`[0]`一人でいいです。 

## アプローチ

 単純なアプローチでは、各プレフィックスを個別に、および長さのプレフィックスごとに考慮します。$i$、すべての要素をチェックして、他のすべての要素の合計と等しいかどうかを確認します。 これは原理的には正しいです。プレフィックスの合計を計算し、要素ごとに合計の合計からそれを減算して、それが要素と等しいかどうかを確認します。 複雑さは$O(n^2)$すべてのプレフィックスの長さのため、テストケースごとに$i$あなたは実行します$i$問題の制約を考慮すると、これは実行不可能です。 

重要な洞察は、プレフィックスが適切かどうかを判断するには、これまでのすべての要素の合計と、そのプレフィックス内の個々の要素の数を知るだけで十分であるという観察から得られます。 合計額が`S`プレフィックスは長さです`i`、要素が存在する場合はプレフィックスが適しています`x`そのような`x = S - x`、つまり、`2 * x = S`。 これは、プレフィックス要素の頻度マップと現在のプレフィックス合計が必要なだけであることを意味します。 新しい要素をプレフィックスに追加するたびに、合計を更新し、`(sum - element)`周波数マップを使用してプレフィックスに存在します。 実行中の合計と頻度の辞書を維持することにより、各プレフィックスを一定時間でチェックでき、その結果、$O(n)$アルゴリズム。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 良好なプレフィックスのカウンターをゼロに初期化し、現在のプレフィックスの累計を初期化し、これまでに検出された各要素の頻度を追跡する辞書を初期化します。 
2. 配列内の各要素を反復処理して、それを累計に加算し、辞書内のそのカウントをインクリメントします。 
3. 合計と頻度を更新した後、ターゲット値を次のように計算します。`sum - element`プレフィックス内の各要素に対して。 もし`2 * element = sum`、現在のプレフィックスは適切です。 
4. 条件が満たされるたびに、good-prefix カウンタをインクリメントします。 
5. 配列の終わりまで次の要素に進みます。 
6. テスト ケースのすべての要素を処理した後、そのテスト ケースのカウンターを出力します。 

正確さを保証する不変条件は、各ステップでの累計が現在のプレフィックスの合計を正確に反映し、周波数マップにプレフィックス内のすべての要素が含まれていることです。 チェック中`2 * x == sum`1 つの要素が残りの要素の合計と等しいという条件を正確に捕捉します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def count_good_prefixes(a):
    freq = {}
    total = 0
    good_count = 0
    for x in a:
        total += x
        freq[x] = freq.get(x, 0) + 1
        if total % 2 == 0:
            target = total // 2
            if freq.get(target, 0) > 0:
                good_count += 1
    return good_count

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(count_good_prefixes(a))
```の`count_good_prefixes`関数は、配列を反復処理するときに頻度辞書と累計を維持します。 新しい要素ごとに合計合計が更新され、プレフィックスの合計が偶数であるかどうかがチェックされます。 存在する場合、合計の半分がプレフィックスに存在するかどうかがチェックされます。 これにより、正確に 1 つの要素が残りの要素の合計と等しくなることが保証されます。 辞書を使用すると、すべての要素を繰り返し処理する必要がなくなり、複雑さが線形に保たれます。 この関数は、合計が 0 で要素が 0 であるため、単一要素のプレフィックス 0 が適切であるというエッジ ケースを正しく処理します。
