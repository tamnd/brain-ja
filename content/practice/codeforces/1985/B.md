 ## 問題の理解

 番号を選択するように求められます$x$2との間$n$すべての倍数の合計となるような包括的$x$を超えないもの$n$最大化されます。 たとえば、次の場合$n = 15$そして私たちは選ぶ$x = 2$、倍数は 2、4、6、8、10、12、14 で、それらの合計は 56 です。一意の最適値が存在することが保証されています。$x$それぞれに$n$。 入力は複数のテスト ケースで構成され、それぞれが次の値を指定します。$n$、出力は単一の整数です$x$テストケースごとに。 

制約$2 \le n \le 100$が小さいということは、おおよそ二次関数である解を意味します。$n$それは受け入れられますが、それでもより単純な観察ベースのアプローチを目指す必要があります。 一意性が保証されているため、私たちの方法では常に 1 つの正解が得られるという確信が得られます。 

微妙なエッジケースが発生する場合$n$プライムまたはスモールです。 たとえば、次の場合$n = 3$、候補者は$x = 2$そして$x = 3$。 2 の倍数は 2、3 の倍数は 3 となるため、正解は 3 になります。常に最小のものを選択する単純なアプローチ$x$または、割り算パターンに依存すると、ここで失敗する可能性があります。 

もう 1 つのエッジケースは次のような場合です$n$は均等です。 頻繁、$x = 2$多くの倍数が生成され、値が大きいほど項の数が急速に減少するため、合計が支配的になります。 最適なアプローチを実現するには、このパターンを認識することが重要です。 

## アプローチ

 ブルートフォースアプローチは簡単です: 各候補者に対して$x$2から$n$の倍数の合計を計算します。$x$を超えないもの$n$。 倍数の合計は次のように直接計算できます。$x + 2x + 3x + \dots + kx$どこ$k = \lfloor n / x \rfloor$。 これは等差級数の公式を使用して効率的に計算できます。$x \cdot k \cdot (k+1) / 2$。 それぞれについて$n$、すべてをテストします$x$そして最大の金額を記録したものを追跡します。 と$n \le 100$、これにはテスト ケースごとに最大 100 人の候補者が含まれており、100 個のテスト ケースには十分な速度ですが、より単純な洞察を探すことにも価値があります。 

重要な観察は、与えられた値の合計が$x$次のように書き換えることができます$x \cdot k \cdot (k+1) / 2$、 どこ$k = n // x$。 この関数は、次の 2 つの競合する要因によって成長します。$x$数値が大きいほどそれ自体も大きくなり、$k$、倍数の数。次のように減少します。$x$が増加します。 いつ$x$小さいです、$k$大きいので多くの項が生成されますが、$x$小さいです。 いつ$x$大きいです、$k$数量が少ないため、商品に限りがございます。 小規模なテスト$n$それを示しています$x = 2$または$x = n$多くの場合、チェックすべき唯一の候補です。 体系的な分析により、最大合計は次のいずれかで発生することが確認されています。$x = 2$またはで$x = n$。 したがって、最適なアプローチは、これら 2 つの候補のみの合計を計算し、大きい方を選択することです。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 各テスト ケースは独立しているため、ループ内で処理できます。 
2. 各テスト ケースについて、整数を読み取ります。$n$。 
3. の倍数の合計を計算します。$x = 2$。 させて$k_2 = n // 2$、その場合、合計は$2 \cdot k_2 \cdot (k_2 + 1) // 2$。 
4. の倍数の合計を計算します。$x = n$。 ここ、$k_n = n // n = 1$、つまり合計は$n$。 
5. 2 つの合計を比較します。 の合計の場合、$x = 2$大きい場合、出力 2。 それ以外の場合は出力$n$。 
6. すべてのテスト ケースに対して繰り返します。 

なぜ機能するのか: 倍数の合計関数は次の形式になります。$x \cdot k \cdot (k+1)/2$と競合する効果$x$そして$k$両極端を作る、2、そして$n$、検討すべき唯一の候補です。 テストでは他に何も示されません$x$範囲内にあると、より大きな合計を生成できるため、正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    sum2 = 2 * (n // 2) * ((n // 2) + 1) // 2
    sumn = n
    if sum2 > sumn:
        print(2)
    else:
        print(n)
```コードはテスト ケースの数を読み取り、それぞれをループします。$n$。 の倍数の合計を計算します。$x = 2$そして$x = n$、整数の除算と等差級数の公式を使用してループを回避します。 比較により最適なものが選択されます。$x$。 実装上の微妙な選択は、整数の除算が確実に使用されるようにすることです。$k = n // x$そうでない場合、等差級数は不正確になります。
