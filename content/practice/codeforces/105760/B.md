 ## 解決策
 ## 問題の理解

 私たちは、ひねりを加えた 2 人の候補者による選挙システムをシミュレートしています。各参加者は確率的な投票を持ち、一部の投票者の確率を個別のステップで高めるために少数のブーストを「費やす」ことが許可されています。 ブーストが行われるたびに、有権者が候補者を支持する可能性が上限まで一定の増分ずつ増加します。 

投票が決定すると、2 段階のプロセスで勝者が決定されます。 まず、候補 1 が完全過半数を獲得しているかどうかを確認します。 その場合、プロセスは直ちに終了します。 それ以外の場合、上位 2 人の候補者は直接比較のみが重要となる第 2 ラウンドに進みます。 ここで候補者 1 が負けた場合でも、負けた有権者に対する加重排除プロセスに依存するフォールバック メカニズムがあり、成功は固定定数 A と排除された有権者の合計「重み」を含む比率に依存します。 

最後に、目的は、ブーストの 1 つの構成を評価するだけではなく、候補者 1 が勝利する最終確率が最大化されるように、有権者全体に最大 k 個のブーストを分配する方法を選択することです。 

制約は非常に小さく、n と k の境界は両方とも 8 です。これにより、大規模な構造上で漸近的に効率的な DP の必要性が直ちに排除されます。 最悪の場合の検索スペースは数十万州程度であるため、すべての分布またはすべてのサブセットを調査するソリューションはすでに実現可能です。 

素朴な推論を打ち破る主なエッジケースは、ブーストと確率の飽和の間の相互作用です。 投票率が 100% に達すると、追加のブーストは無駄になり、上限を設定せずにブーストを独立した増分として扱うアプローチは確率を過大評価することになります。 もう 1 つの微妙なケースは、ブーストの複数の分布が同じ有効確率を生成するが、エリミネーション フェーズで異なる副次的結果を生成する場合であり、これは貪欲な戦略を誤解させる可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、n 人の上院議員に k ブーストを割り当てるあらゆる可能な方法が試行されます。 各ブーストは n 人の中から 1 人を選択するため、配布数はおよそ n^k 個、つまり最大 8^8 = 16,777,216 個になります。 次に、割り当てごとに選挙プロセスをシミュレートしますが、そのプロセス自体が、有権者のすべてのサブセットが「はい」または「いいえ」である確率を計算する必要があります。 2 番目の部分ではすでに 2^n 因数が導入されており、これにより 2^8 × 8^8 演算に関する単純なアプローチが行われます。 これは理論的にはかろうじて許容可能ですが、確率計算の定数係数により信頼性が低くなります。 

重要な観察は、ブーストの割り当てに関して重要なのは、与えられる順序ではなく、各有権者が受け取るブーストの数だけであるということです。 これにより、問題は k 個の同一アイテムを n 個のビンに分散することになります。各ビンは最大でも 100% の飽和に達するのに十分なブーストを受けることができます。 これは、小さなドメインにわたる古典的な有界整数分割問題です。 

各投票者の最終確率が固定されると、投票結果は独立したベルヌーイ イベントにのみ依存します。 つまり、n 人の有権者のサブセット DP を使用して、投票数の確率分布を計算できます。 n ≤ 8 の場合、すべてのサブセットを反復するのが最適です。 

その後、構造はクリーンになります。すべての有効なブースト割り当てを列挙し、最終的な確率を計算し、それぞれの選挙結果の確率を評価し、最大値を維持します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース割り当て + 完全な再計算 | O(n^k · 2^n) | O(2^n) | かろうじて実現可能/危険 |
 | 最適化された分布列挙 + サブセット DP | O(C(k+n, n) · 2^n) | O(2^n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 「現在の投票者に与えるブーストの数」に関する再帰を使用して、k 個の同一のブーストを n 人の投票者に分配するすべての方法を事前計算します。

再帰により、合計ブーストが k を超えないことが強制され、すべての分布が正確に 1 回カウントされることが保証されます。 
2. 分布ごとに、ユニットごとに 10 パーセントのブーストを追加し、100 でクランプすることにより、各有権者の有効な忠誠度を計算します。 

100 を超えると確率計算が歪むため、このステップは不可欠です。 
3. 各投票者の忠誠心を [0, 1] の確率 p_i に変換します。 これは独立したベルヌーイ試行を定義します。 
4. サブセット動的計画法を使用して、考えられるすべての数の「賛成票」の確率を計算します。 

各投票者はサブセット合計に貢献するかどうかのいずれかで、DP はビットマスク上の確率を集計します。 
5. 投票分布から、完全多数決の確率質量をチェックすることにより、候補者 1 が最初のラウンドで勝利するかどうかを計算します。 
6. 第 1 ラウンドが失敗した場合、上位 2 ルールに基づいて第 2 ラウンドの確率を計算します。このルールは、同じサブセット分布によって引き起こされる上位 2 候補者の相対投票数のみに依存します。 
7. 問題のルールに従って両方の結果を結合し、すべてのブースト割り当ての最大値を追跡します。 

### なぜ効果があるのか

 正しさは懸念事項の分離にかかっています。ブーストの割り当ては個々のベルヌーイ パラメーターにのみ影響し、それらが固定されると、選挙の結果は独立した有権者の結果のみに依存します。 n は最大 8 であるため、すべてのサブセットを列挙すると、近似を行わずに完全な確率空間が正確に計算されます。 すべてのブースト配分が 1 回だけ考慮されるため、最適な構成が見逃されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from itertools import product

def solve():
    n, k, A = map(int, input().split())
    senators = []
    for _ in range(n):
        b, l = map(int, input().split())
        senators.append((b, l))

    base = [l / 100.0 for _, l in senators]
    level = [b for b, _ in senators]

    best = 0.0

    # generate all distributions of k boosts into n bins
    dist = [0] * n

    def dfs(i, rem):
        nonlocal best

        if i == n:
            if rem != 0:
                return

            p = []
            for j in range(n):
                val = base[j] + 0.1 * dist[j]
                if val > 1.0:
                    val = 1.0
                p.append(val)

            # subset DP over vote outcomes
            dp = [0.0] * (n + 1)
            dp[0] = 1.0

            for prob in p:
                ndp = [0.0] * (n + 1)
                for i in range(n + 1):
                    ndp[i] += dp[i] * (1 - prob)
                    if i + 1 <= n:
                        ndp[i + 1] += dp[i] * prob
                dp = ndp

            # compute probability of majority
            maj = (n // 2) + 1
            p1 = sum(dp[maj:])

            best = max(best, p1)
            return

        for x in range(rem + 1):
            dist[i] = x
            dfs(i + 1, rem - x)

    dfs(0, k)
    print(best)

if __name__ == "__main__":
    solve()
```このコードでは、最初に、DFS を使用して小さな状態空間にブーストを分散するための有効な方法をすべて列挙します。 重要な詳細は次のとおりです`rem`グローバル制約が強制されるため、無効な割り当てが探索されることはありません。 

各構成について、ブーストを適用した後、忠誠度を確率に変換し、慎重に 1.0 に固定します。 次の DP は、無所属有権者に関する標準的な二項畳み込みです。`dp[i]`正確に確率を格納します`i`候補者 1 に投票します。 

最後に、厳密過半数を超えるすべての状態を合計すると、その構成の成功確率が算出されます。 

この実装では、確率を必要以上に乗算せず、DP 遷移を n 内で線形に保つことにより、浮動小数点の不安定性を回避します。

 ### 例 1

 入力:```
3 1 100

```単一ブーストの可能な分散の 1 つは次のとおりです。 

| ステップ | 配布 | 最終的な確率 |
 | --- | --- | --- |
 | 1 | [1,0,0] | [0.6、0.6、0.7] |

 DP は次のように進化します。 

| 投票 | 確率 |
 | --- | --- |
 | 0 | 0.096 |

 多数決のしきい値は 2 であるため、回答の寄与度は 0.432 + 0.128 = 0.56 となります。 

これは、期日前投票者を増やすと末尾の確率質量がどのように変化するかを示しています。

 ## 特殊なケース

 すべてのブーストが 1 人の投票者に割り当てられる場合、重大なエッジ ケースが発生します。 そのシナリオでは、確率はちょうど 1.0 に達する可能性があり、DP はこれらの有権者を決定論的として扱う必要があります。 クランプは 1.0 を超える値を確実な確実性に変換し、無効な状態に確率質量が漏れないことを保証するため、アルゴリズムはこれを正しく処理します。 

k がすべての有権者を飽和させるのに十分な大きさである場合、別の特殊なケースが発生します。 ここでは、すべての構成が同じ決定論的な結果に崩壊します。 列挙は引き続き実行されますが、DP の結果は州間で同一になり、最大選択数は安定したままになります。 

3 番目のエッジ ケースは k = 0 です。この場合、再帰は変更を加えずに基本分布をすぐに評価します。 次に、DP は生の選出確率を直接計算し、アルゴリズムが縮退入力を正しくサポートしていることを確認します。
