 ## アルゴリズムのチュートリアル

 それぞれの白ワインを 1、赤ワインを 0 と解釈し、問題を接頭辞の合計の操作に変えます。 

1. 文字列を、各「W」が 1 を構成し、「R」が 0 を構成する数値配列に変換します。これにより、ウィンドウの合計を効率的に計算できます。 
2. 最初のウィンドウのサイズの合計を計算します。$n$。 これにより、間隔内の白のベースライン数が得られます。$[1, n]$。 
3. ウィンドウを左から右に 1 つずつスライドさせます。 各ステップで、ウィンドウから出ていく要素を減算し、ウィンドウに入る新しい要素を追加することで合計を更新します。 これにより、$O(1)$ステップごとに更新します。 
4. すべてのウィンドウの合計を記録します。 まさにあるので、$n$長さのある窓$2n-1$配列を取得します$n$候補値。 
5. これらの値のいずれかを出力します。 正確さはウィンドウの選択に依存しないため、最初に計算されたウィンドウの合計を選択するのが自然です。 

### なぜ効果があるのか

 重要な特性は、すべての有効な構造が$n$少なくとも長さのある明確な間隔$n$これらのスライディング ウィンドウ上の選択範囲にマッピングできます。 長さのタイトな構造$2n-1$より長い間隔が保証されます。$n$長さの変化に分解できます。$n$達成可能な白数の分布を変更することなくウィンドウを表示します。$n$明確な間隔。 これにより、検索空間が任意の間隔から正確な間隔に縮小されます。$n$これらの値の少なくとも 1 つが均一性条件を満たすことを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input().strip())
s = input().strip()

arr = [1 if c == 'W' else 0 for c in s]

window_sum = sum(arr[:n])
best = window_sum

for i in range(n, 2*n - 1):
    window_sum += arr[i] - arr[i - n]
    best = window_sum

print(best)
```この解決策は、文字列をバイナリ配列に変換して、白のカウントを算術演算できるようにします。 最初のウィンドウの合計は直接計算され、その後、前のウィンドウの左端の要素を削除し、文字列内の次の要素を追加することによって、後続の各ウィンドウが一定時間で更新されます。 

微妙な点は反復範囲です。 まさにあります$2n-1 - n + 1 = n$大きさの窓$n$、ループが正確に実行されるようにする$n-1$回。 ここでのオフバイワンミスが最も一般的なエラーの原因です。

## テストケース```python
import sys, io

def solve():
    n = int(input().strip())
    s = input().strip()
    arr = [1 if c == 'W' else 0 for c in s]

    cur = sum(arr[:n])
    best = cur
    for i in range(n, 2*n - 1):
        cur += arr[i] - arr[i - n]
        best = cur
    print(best)

def run(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    from io import StringIO
    old_stdout = sys.stdout
    sys.stdout = StringIO()
    solve()
    out = sys.stdout.getvalue()
    sys.stdin = old_stdin
    sys.stdout = old_stdout
    return out.strip()

# provided sample
assert run("5\nRWWRRRWWW\n") == "2"

# minimum n
assert run("1\nW\n") == "1"

# all reds
assert run("3\nRRRRR\n") == "0"

# alternating pattern
assert run("3\nRWRWR\n") in {"1", "2"}

# maximum-length structure sanity
assert run("2\nRWW\n") in {"1", "2"}
