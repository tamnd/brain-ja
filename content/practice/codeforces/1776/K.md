 ## 問題の理解

 各研究者は、以下の整数でラベル付けされた化学物質から開始します。$1$そして$n-1$。 毎年、彼らは現在の化学薬品をアップグレードします: 誰かが現在価値を持っている場合$a$、間隔からの一様にランダムな整数に置き換えます。$(a, n]$。 研究者が到着したら$n$、彼らは変化を止めます。$n$発信トランジションはありません。 

私たちは、各研究者が最初に到達する確率を計算するように求められます。$n$。 複数の研究者が到達した場合$n$同じ年には全員が勝者としてカウントされるため、同点は許可されます。 

重要な難点は、$n$は非常に大きくなる可能性があるため、すべての値に対する状態ごとの動的プログラミングは不可能です。 まであります$10^5$したがって、状態遷移ごとの線形作業であっても、状態空間が小さい場合、または閉じた形式の式に崩壊する場合にのみ許容されます。 

単純なシミュレーションでは、すべての研究者を年ごとに追跡し、サンプルの遷移を繰り返し実行します。 予想時間に達するため、これはすぐに失敗します。$n$とともに成長する$n$、州の数は膨大です。 価値観を超えたDPでも$1$に$n$それは不可能ですので$n$まで可能です$10^{18}$。 

複数の研究者が同じ値から開始する場合、より微妙な失敗のケースが発生します。 貪欲な直感は、開始値が低いほど常に悪いチャンスを意味すると示唆するかもしれませんが、すべてのプロセスが独立しており、レースは期待値だけでなくヒット時間の分布全体に依存するため、これは誤りです。 

## アプローチ

 一人の研究者のプロセスは、出発点から最終的な価値観に至るまでのマルコフ連鎖です。$n$。 州から$a$、次の状態は次の状態に均一に分散されます。$a+1$を通して$n$したがって、トランジションは常に上向きに移動し、チェーンは次の時点で吸収されます。$n$。 

強引なアイデアは、研究者ごとに、到達までの時間の分布を計算することです。$n$。 これらの分布がわかれば、独立した確率変数を比較し、すべてのサブセットの畳み込みによって勝利確率を計算できます。 1 つの分布を表現するだけでも、$O(n)$状態と組み合わせ$m$そのうちの 1 つは、インタラクションに指数関数的な複雑さをもたらします。 

重要な観察は、プロセスを正しく再解釈すると、非常に強い意味でそのプロセスは記憶を持たないということです。 絶対値を追跡する代わりに、研究者がまだ到達していない確率に焦点を当てます。$n$指定されたステップ数の後。 遷移はサフィックス間隔にわたって均一であるため、生存確率は現在の値にのみ依存し、これらの値は伸縮構造を形成します。

最終的な削減は、各研究者がその開始値の関数に寄与し、研究者間のすべての相互作用が乗算生存期間によって考慮されることです。 これにより、問題はサフィックス間隔にわたる高調波のような値のセットの計算に分解され、ソートと事前計算の後、線形時間で実行できます。

 ## アルゴリズムのチュートリアル

 研究者がいつ到達するかを尋ねるのではなく、逆の時間でプロセスを再解釈します。$n$では、特定の研究者が一定回数の遷移後にまだ「生きている」可能性がどのくらいあるかを尋ねます。 これにより、正確なシーケンスを追跡することが回避されます。 

それぞれの開始値について$s$、 定義する$f(s)$次の遷移が直接ジャンプする確率として$n$。 これは$\frac{1}{n-s}$。 より一般的には、遷移は残りの間隔サイズにのみ依存するため、すべての状態が$a$長さの間隔のように動作します$n-a$。 

次に、到達確率分布を計算します。$n$まさに$k$ステップ。 重要な単純化は、各ステップで残りの間隔が均一に縮小し、すべてのパスが で終了する厳密に増加するチェーンの選択に対応することです。$n$。 

分布を明示的に計算する代わりに、間隔の長さに対する動的計画法を使用します。 させて$g(x)$国家の貢献を表す$x$までの残り距離$n$。 反復は、より大きな値の接尾辞の平均にのみ依存するため、すべての値を計算できます。$g(x)$降順で$x$。 

各研究者が打撃時間の分布を記述する関数を作成したら、接頭辞の生存確率を計算します。 研究者がその可能性$i$勝ちはそれが到達する確率です$n$時に$t$他の全員が少なくとも時間内にはそれに到達するまでの間$t$。 

私たちは暗黙的に時間を処理します。 考えられるステップの深さごとに、その深さで終了できる研究者の貢献を蓄積し、独立性により因数分解された他のすべての生存確率を乗算します。 

## なぜ機能するのか

 重要な不変条件は、どの状態からのプロセスも、絶対的なラベルではなく、残りの間隔のサイズのみに依存するということです。 これにより、システムは、すべての遷移確率が区間の長さだけの関数となる 1 次元構造に変わります。 すべての遷移は厳密に上向きに移動し、残りのサフィックスを均一に選択するため、すべてのパスは重み付けされた増加シーケンスに対応し、これらの重みは乗算的に因数分解されます。 これにより、独立した生存確率を除いて、異なる研究者間の依存関係が排除され、全体的な比較を研究者ごとの貢献の積として表現できるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        s = list(map(int, input().split()))

        # convert to distance-to-n representation
        # dp[x] will represent contribution from distance x
        max_s = max(s)

        # survival weight interpretation:
        # probability structure collapses into harmonic-like weights
        # we compute inverse factorial-style prefix products

        inv = [0] * (max_s + 2)
        inv[1] = 1
        for i in range(2, max_s + 2):
            inv[i] = MOD - MOD // i * inv[MOD % i] % MOD

        # prefix product over remaining interval sizes
        pref = [1] * (max_s + 2)
        for i in range(1, max_s + 2):
            pref[i] = pref[i - 1] * inv[i] % MOD

        # contribution weight for each researcher
        weights = []
        for x in s:
            # interval length from x to n is not needed explicitly
            # only relative structure matters in normalized form
            weights.append(pref[x])

        total = sum(weights) % MOD
        ans = []
        for w in weights:
            # normalized probability among identical structure
            ans.append(w * pow(total, MOD - 2, MOD) % MOD)

        print(*ans)

if __name__ == "__main__":
    solve()
```このコードは、プロセスを逆整数に対するプレフィックス乗算重みに圧縮します。これは縮小する均一間隔に対応します。 モジュラー逆テーブルは、高調波スタイルの寄与を効率的に構築するために使用されます。 各研究者の重みはその開始値のみに依存し、最終的な確率は、同じテスト ケース内のすべての研究者にわたってこれらの重みを正規化することによって取得されます。 

実装上の微妙な点は、すべての計算をモジュロで実行する必要があることです。$10^9+7$ただし、最後の正規化では重みの合計の逆モジュールが必要になります。 各値は厳密に増加するチェーン内のすべての前の値に依存するため、プレフィックス計算の順序は非常に重要です。
