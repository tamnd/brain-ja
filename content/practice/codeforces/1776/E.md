 ## 解決策
 ## 問題の理解

 私たちは、電車を避けながら、平行する線路をあるプラットホームから別のプラットホームに横断する人、イソナをシミュレートするように求められました。 交差点は直線で線路に対して直角です。 各鉄道は正確に 1 メートルのスペースを占め、連続する鉄道の間、およびプラットフォームと最も近い鉄道の間の距離は 1 メートルです。 Isona はいつでも速度を選択できますが、速度の各変更は「速度の変更」としてカウントされるため、これらを最小限に抑えたいと考えています。 彼女は待ったり、じっとしたりすることもでき、休憩から走り始めることは速度の変更としてカウントされません。 

入力は列車の数を表します`n`、鉄道の数`m`、合計許容時間`s`、および秒数`v`イソナは最高速度で1メートルを超えるのにかかります。 各列車は開始時刻と終了時刻によって与えられます`(a_i, b_i)`そして鉄道`r_i`それが占有します。 出力は、Isona が時間内に他のプラットフォームに到達するために行う必要がある速度変更の最小数です。`s`、 または`-1`それが不可能な場合。 

制約は次のことを教えてくれます`m`小さい (最大 10)、`n`500 に達する可能性があり、時間値が非常に大きくなる可能性があります (`10^9`）。 これは、複雑さが指数関数的に依存するアルゴリズムに焦点を当てるべきであることを示唆しています。`m`でもオンではない`s`または実際の時間値。1 秒ごとに繰り返すと遅すぎるためです。 エッジケースには、電車があらゆるタイミングを妨げる状況、同じ線路上で電車が隣同士にある場合、またはイソナが速度変化を避けるために完璧なタイミングで走行できる状況などが含まれます。 

すべてのメーターにわたって開始時間と速度変更のあらゆる組み合わせを試す単純な実装は、考えられるタイミングの数が膨大で時間範囲が広いため、実行不可能です。 

## アプローチ

 ブルートフォース ソリューションでは、可能な開始時間ごとに、各メートルにわたる Isona の動きをシミュレートしようとします。 速度の変化を追跡しながら、待機または最高速度での実行のあらゆる組み合わせを試すことができます。 このアプローチは原理的には正しいですが、`m`10回まで、そしてその倍まで`10^9`、毎秒繰り返すことは不可能です。 「各タイムステップでの最小速度変化」を記録する動的計画法でも、範囲が広いため失敗します。`s`。 

重要な観察は、列車が各鉄道の狭い間隔のみを遮断していることです。 列車の数は最大で 500、鉄道の数は最大で 10 であるため、これらの間隔を前処理して、各鉄道の「安全なウィンドウ」を識別できます。 安全な窓内であれば、イソナは電車にぶつからずに渡ることができます。 窓の間では、待つか速度を調整する必要があるかもしれません。 これにより、この問題は層 (鉄道)​​ 上の動的計画法の問題に変わり、各州が次の鉄道の安全な区間ごとの最早到着時刻と最小速度変化を追跡します。 

具体的には、各鉄道の状態を一連の間隔で表すことができます。`[start_time, end_time]`イソナは衝突することなく到着できます。 鉄道からの移動`i`鉄道へ`i+1`、鉄道からの間隔のすべてのペアを考慮します`i`に`i+1`。 各ペアについて、彼女が次の鉄道に到着できる最も早い時間を計算し、おそらく電車を避けるために待っています。 彼女がこれらの間隔の間に速度を調整した場合、速度変更は 1 回としてカウントされます。 最後に、その前に到着する最後の鉄道のすべての有効な区間の間で最小速度が変化します。`s`答えを出します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^m * s) | O(s * m) | 遅すぎる |
 | 安全な間隔での最適な DP | O(n * m^2) | O(n * m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 列車を前処理して、各鉄道の通行止め区間のリストを作成します。 各鉄道はその間隔を次のように保存します。`(a_i, b_i)`開始時間順に並べ替えます。 追加します`0`そして`s`DP 計算を簡素化するための人工境界として使用します。 
2. 鉄道ごとに、遮断区間を安全区間に変換します。 安全な間隔とは、イソナが列車に遭遇せずにこの鉄道を横断できる最大時間区間です。 鉄道用`r_i`、ブロックされた間隔が`[1,2], [3,4]`、安全区間は次のようになります。`[0,1], [2,3], [4,s]`。 
3. DP 配列を初期化する`dp[i][j]`鉄道用`i`そして安全な間隔`j`。 各エントリには、その間隔の終わりに到達するために必要な最小限の速度変化が保存されます。 最初の鉄道では、その後に始まるすべての安全区間`0`で到達できます`0`そのタイミングでイソナが走り始めると速度が変わります。 
4. 後続の各鉄道について`i`、前の鉄道のすべての安全な区間を反復します。`i-1`。 以前の間隔と現在の間隔の組み合わせごとに、最も早い時間を計算します`t`イソナは、最大速度を考慮し、必要に応じて待機することで、前回の間隔から現在の間隔に到達できます。 これに速度の変更が必要な場合 (つまり、所要時間が最高速度の移動とは異なる場合)、速度変更カウントを 1 つ増やします。 
5. すべての鉄道を処理した後、最後の鉄道の安全区間を調べます。 事前にホームに到着できる間隔ごとに`s`, その中で最小の変速回数をとります。 存在しない場合は出力`-1`。 
6. 結果を出力します。 

機能する理由: 各鉄道で、DP 状態は安全な区間に到達するための最小限の速度変化を記録します。 移行では安全な間隔と最小限の速度調整のみが考慮されるため、必要な変更の数を過小評価することはありません。 最初の鉄道から最後の鉄道までを伝播することで、待機と速度変更のあらゆる組み合わせが考慮されるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, s, v = map(int, input().split())
    trains = [[] for _ in range(m)]
    for _ in range(n):
        a, b, r = map(int, input().split())
        trains[r-1].append((a, b))
    
    safe = []
    for tlist in trains:
        tlist.sort()
        intervals = []
        prev = 0
        for a, b in tlist:
            if prev < a:
                intervals.append((prev, a))
            prev = b
        if prev < s:
            intervals.append((prev, s))
        safe.append(intervals)
    
    dp = [{} for _ in range(m)]
    for st, en in safe[0]:
        dp[0][(st, en)] = 0
    
    for i in range(1, m):
        for c_st, c_en in safe[i]:
            dp[i][(c_st, c_en)] = float('inf')
            for p_st, p_en in dp[i-1]:
                prev_changes = dp[i-1][(p_st, p_en)]
                t_needed = v
                earliest_arrival = max(c_st, p_st + t_needed)
                if earliest_arrival <= c_en:
                    changes = prev_changes
                    if earliest_arrival != p_st + t_needed:
                        changes += 1
                    dp[i][(c_st, c_en)] = min(dp[i][(c_st, c_en)], changes)
    
    ans = float('inf')
    for (st, en), changes in dp[-1].items():
        if st <= s:
            ans = min(ans, changes)
    
    print(-1 if ans == float('inf') else ans)

solve()
```このソリューションは、列車を安全な間隔に前処理します。 DP は、ある鉄道から次の鉄道へ最小限の速度変化を伝達します。 安全な間隔ごとに、追加の速度変更なしでその間隔に到達できるかどうかを計算し、到達できない場合はカウントを増やします。 から始まる間隔などの境界条件`0`またはで終わる`s`プラットフォームのエッジを安全な間隔で含めているため、自然に処理されます。

 | 1 | [0,1]、[2,3]、[4,5] | すべての場合は 0 |

| 3 | [0,3],[4,5] | 2 からの遷移、最小変更は 0 のまま |

 出力は`0`、イソナが速度を調整せずに最高速度でまっすぐに走り、安全に到達できることを示しています。

```| 鉄道 | 安全な間隔 | DP 状態 (最小変更) |
