 ## 解決策
 ## 問題の理解

 接続された無向グラフが与えられます。 すべてのエッジを会社に割り当てる必要があります。 

会社だとします`c`すべてのエッジに色が付いています`c`。 カラーリングには2つの条件を満たす必要があります。 

最初の条件は、単一の企業が接続されたスパニング ネットワークを所有できないことを示しています。 すべての色について、その色のエッジのみで形成されるグラフを切断する必要があります。 

2 番目の条件はさらに強力です。 任意の 2 社を取り上げます。 これら 2 つの会社のいずれかに属するすべてのエッジを保持すると、結果のグラフは接続される必要があります。 

会社数は自由に選べます`k`、 に限って`k ≥ 2`。 

グラフには最大 50 個の頂点があり、すべての頂点の合計は`n`テスト ケース全体で最大 5000 です。これらの制限はごくわずかです。 課題はアルゴリズムの複雑さではなく、常に機能する構造を見つけることです。 

最も危険な間違いは、各色を切り離すことだけに集中することです。 その部分は簡単です。 難しいのは、すべての色のペアが接続されたグラフを形成することを保証することです。 

パスを検討する`1-2-3`。 

エッジに色を付けたら`(1,2)`カラー1とエッジ付き`(2,3)`色 2 を使用すると、それぞれの色が切り離されます。 ただし、有用なものを何も持たない 3 番目の色を導入すると、一部の色のペアがグラフを接続できない可能性があります。 ペアごとの接続要件はグローバルであり、色のすべてのペアに適用される必要があります。 

完全なグラフには別の簡単な罠が現れます。 

仮定する`n = 3`そして 3 つのエッジがすべて存在します。 頂点 1 に属するすべてのエッジをカラー 1 で着色し、残りのエッジをカラー 2 で着色すると、カラー 1 だけが接続され、最初の条件に違反します。 

完全なグラフは、主要な構築に特別な調整が必要な唯一の状況です。 

## アプローチ

 強引な考え方では、色を割り当ててから条件を検証しようとします。 

最大 1225 のエッジを持つグラフの場合、2 つの色から選択するだけで、すでに`2^m`可能性。 各割り当ての後に接続を確認するのは簡単ですが、検索スペースは天文学的に大きくなります。 

重要な点は、多くの色は必要ないということです。 

頂点を選択することを想像してください`u`。 すべてのエッジに 1 つの色を与えます`u`、そして 1 つおきのエッジに 2 番目の色を与えます。 

2 色だけを使用する場合、2 番目の要件は簡単になります。 色のペアは 1 つだけあります。`{1,2}`、そしてそれらは一緒に元のグラフのすべてのエッジを含みます。 元のグラフが接続されているため、ペアは接続されます。 

ここで必要なのは、それぞれの色が切り離されていることを確認することだけです。 

カラー 2 にはエッジ接触が含まれていません`u`、つまり頂点`u`孤立している。 カラー 2 は自動的に切断されます。 

色 1 は中心にある星です。`u`。 隣接しない頂点が存在する場合、この色は切断されます。`u`、その頂点のカラー 1 の次数が 0 であるためです。 

これにより、すべての不完全なグラフが即座に解決されます。 次数が次より小さい頂点を選択します`n-1`。 

残る唯一のケースは完全なグラフです。 

完全なグラフでは、すべての頂点が他のすべての頂点に隣接しているため、前の引数は失敗します。 追加の色が 1 つ必要です。 

頂点を選択してください`u`。 

1 つのインシデント エッジを与える`u`カラー1。 

他のすべてのエッジに付随するものを与えます`u`カラー2。 

残りのすべてのエッジに色 3 を付けます。 

これで、すべての色が接続されなくなりました。 

カラー 1 にはエッジが 1 つだけ含まれています。 

色 2 は、葉が 1 枚欠けている星です。 

カラー 3 にはエッジが含まれていません`u`。 

色のペアはすべて接続されます。 

カラー 1 と 2 には、次のすべてのエッジが含まれます。`u`、スパニングスターを形成します。 

色 1 と 3 が接続されます`u`固有のカラー 1 エッジを介して、カラー 3 には残りの頂点上の完全なグラフが含まれます。 

色 2 と 3 は対称です。 

これで問題は完全に解決します。

 ## アルゴリズムのチュートリアル

 1. グラフを読み取り、すべての頂点の次数を計算します。 
2. 頂点があるかどうかを確認します`u`厳密に次数が小さい`n-1`。 
3. そのような頂点が存在する場合は、次を使用します。`k = 2`。 

に付随するすべてのエッジに色 1 を割り当てます。`u`。 

1 つおきのエッジに色 2 を割り当てます。 

カラー 2 が切断されているため、`u`カラー 2 エッジがありません。 

カラー 1 は、少なくとも 1 つの頂点が隣接していないため、切断されています。`u`、その頂点にはカラー 1 のエッジがありません。 
4. それ以外の場合、グラフは完成します。 
5. 使用する`k = 3`。 
6. 任意の頂点、たとえば頂点 1 を選択します。 
7. 頂点 1 に属するエッジのうち 1 つのエッジを選択し、それに色 1 を付けます。 
8. 頂点 1 に属するエッジを 1 つおきにカラー 2 で色付けします。 
9. 残りのエッジをすべてカラー 3 で色付けします。 
10. 元の入力順序で色を出力します。 

### なぜ効果があるのか

 不完全なグラフの場合、選択した頂点`u`少なくとも 1 つの非隣接国があります。 カラー 1 のグラフは、接触するエッジのみで構成されます。`u`、そのため、非隣人は孤立します。 カラー 2 のグラフにはエッジ接触が含まれていません`u`、 それで`u`それ自体が孤立している。 両方の色が切断されています。 

色は 2 つしかないため、任意の 2 つの色の和集合は、単純に接続された元のグラフになります。 

完全なグラフでは、色 1 には単一のエッジが含まれており、切断されています。 カラー 2 は部分的なスターであり、カラー 1 エッジの 1 つの端点がカラー 2 エッジを受け取らないため、切断されています。 カラー 3 には頂点 1 に付随するエッジが含まれていないため、頂点 1 は分離されます。 

カラーペアの接続性については、次のとおりです。`1 ∪ 2`頂点 1 に属するすべてのエッジが含まれており、星形を形成します。`1 ∪ 3`頂点に関する完全なグラフが含まれています`{2,3,...,n}`また、頂点 1 をその完全なグラフに接続する 1 つのエッジもあります。`2 ∪ 3`類似しています。 

したがって、必要な条件はすべて当てはまります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n, m = map(int, input().split())

        edges = []
        deg = [0] * (n + 1)

        for _ in range(m):
            u, v = map(int, input().split())
            edges.append((u, v))
            deg[u] += 1
            deg[v] += 1

        u = -1
        for v in range(1, n + 1):
            if deg[v] < n - 1:
                u = v
                break

        if u != -1:
            print(2)

            ans = [2] * m
            for i, (a, b) in enumerate(edges):
                if a == u or b == u:
                    ans[i] = 1

            print(*ans)

        else:
            print(3)

            ans = [3] * m
            first_edge = -1

            for i, (a, b) in enumerate(edges):
                if a == 1 or b == 1:
                    first_edge = i
                    break

            ans[first_edge] = 1

            for i, (a, b) in enumerate(edges):
                if i == first_edge:
                    continue
                if a == 1 or b == 1:
                    ans[i] = 2

            print(*ans)

solve()
```最初の部分では次数を計算します。 より小さい次数を持つ頂点`n-1`グラフが不完全であることを即座に証明します。 

不完全な場合、選択した頂点に接触するすべてのエッジはカラー 1 を受け取ります。他のすべてのエッジはカラー 2 のままです。応答配列全体を 2 で初期化し、次にインシデントエッジを上書きするのが最も簡単な実装です。 

完全なグラフの場合、3 色を使用します。 頂点 1 に属する 1 つのエッジを見つけて、それをカラー 1 用に予約します。頂点 1 に接触する他のエッジはすべてカラー 2 になります。残りのエッジはカラー 3 を維持します。 

微妙な点は、色を元の入力順序に維持する必要があることです。 出力は、`i`- 番目の入力エッジなので、すべてのエッジをリストに保存し、エッジ インデックスによって色を割り当てます。

# These tests validate the construction properties rather than
# a specific coloring, since many valid outputs exist.

from collections import deque

def check(n, edges, k, colors):
    assert 2 <= k

    def connected(allowed):
        g = [[] for _ in range(n)]
        for (u, v), c in zip(edges, colors):
            if c in allowed:
                u -= 1
                v -= 1
                g[u].append(v)
                g[v].append(u)

        q = deque([0])
        vis = [False] * n
        vis[0] = True

        while q:
            x = q.popleft()
            for y in g[x]:
                if not vis[y]:
                    vis[y] = True
                    q.append(y)

        return all(vis)

    for c in range(1, k + 1):
        assert not connected({c})

    for a in range(1, k + 1):
        for b in range(a + 1, k + 1):
            assert connected({a, b})

 ## 特殊なケース

 3 つの頂点に関する完全なグラフを考えてみましょう。```
1
3 3
1 2
1 3
2 3
```すべての頂点には次数があります`n-1 = 2`, これでグラフが完成しました。 アルゴリズムは 3 色の分岐に入ります。 

頂点 1 に属する 1 つのエッジにはカラー 1 が与えられ、もう一方のエッジにはカラー 2 が与えられ、残りのエッジにはカラー 3 が与えられます。 

ここで 2 色の構成を誤って使用すると、色 1 が接続されたスパニング スターを形成し、要件に違反することになります。 特殊な完全グラフ分岐により、この問題が回避されます。 

ここで次のことを考えてみましょう。```
1
4 5
1 2
1 3
2 3
2 4
3 4
```頂点 1 の次数は 2 であり、次数よりも小さいです。`n-1 = 3`。 

頂点 1 に属するすべてのエッジはカラー 1 になります。残りのエッジはカラー 2 になります。 

頂点 4 は頂点 1 に隣接していないため、色 1 で分離されます。頂点 1 は色 2 で分離されます。両方の色は切断されていますが、それらの結合は元の接続されたグラフです。 

これはまさに建設が活用する特性です。
