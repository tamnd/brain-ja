 ## 解決策
 ## 問題の理解

 原点にある大砲が、同じ初速で、それぞれが指定された角度で多数のボールを発射するシナリオがあります。 目標は、各ボールが垂直の壁に当たった後、または地面に到達した後、どこに着地するかを決定することです。 各壁は、X 軸から始まり、ある高さで終わる垂直セグメントです。`y_i`。 物理学は均一重力下での標準的な発射体の動きです。水平速度は一定、垂直速度は重力に応じて線形に減少し、垂直変位は時間で二次になります。 

入力はショット数です`n`、初速度`V`、角度`alpha_i`ラジアン単位の壁の数`m`、 その後`m`彼らが与えた壁`x`座標と高さ`y`。 出力は最終的な座標です`(x, y)`各砲弾の、どこで`y`ゼロ (ボールが地面に当たる) またはボールを止める壁の高さのいずれかになります。 

制約は次のことを教えてくれます`n`最大 10^4 にすることができ、`m`最大 10^5。 すべてのショットとすべての壁を反復する単純なアルゴリズムでは、最悪の場合、10^9 の演算が行われ、これでは遅すぎます。 これは、ソリューションがショットごとにすべての壁をテストするのではなく、何らかの幾何学的特性または並べ替え特性を利用する必要があることを強く示唆しています。 

エッジケースには同時に複数の壁が含まれます`x`座標、ボールの軌道よりも完全に高い壁、または壁の先端にボールが正確に着地する場合。 たとえば、壁がある場合、`x=5`高さがある`y=0`そしてボールは正確に通過します`(5, 0)`、詰まっていると考えるべきです。 浮動小数点の精度を無視したり、壁の最上部での等価性のチェックに失敗したりすると、間違った出力が得られます。 

## アプローチ

 ブルートフォースアプローチでは、ショットごとに、すべての壁との交差が計算されます。 ボールの垂直位置を次のように評価します。`x = x_i`公式を使って`y = x*tan(alpha) - (g*x^2)/(2*V^2*cos^2(alpha))`壁の高さより下にあるかどうかを確認してください。 これは理論的には正しく機能しますが、`n=10^4`そして`m=10^5`それは結果として`10^9`操作 - 3 秒で処理できる時間をはるかに超えています。 

重要な洞察は、壁が垂直であり、大砲が常に右側に発射されるということです。 これは、ボールが衝突できる最初の壁は、ボールの軌道が壁の頂点よりも下にある左端の壁であることを意味します。 壁を増加順に並べ替えると`x`、壁を順番にチェックするだけです。 壁での発射体の高さが壁の上部を下回ると、発射体は引っかかり、停止することができます。 これにより、比較の数が大幅に減少します。 さらに、各 x 座標で最も高い壁のみを保持するように壁を前処理することで、重複する壁の重複チェックを回避します。 軌道の式は、小さな時間増分で動きをシミュレートすることなく直接計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * m) | O(m) | 遅すぎる |
 | ソート + リニア スイープ | O(n log n + m log m) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力値：撮影枚数を読み取ります。`n`、初速`V`、および角度のリスト`alpha`。 次に壁の数を読み取ります`m`とその座標`(x_i, y_i)`。 
2. 壁を並べ替える`x`。 複数の壁が同じものを共有している場合`x`、最大の壁だけを残します。`y`なぜなら、この x に当たるボールは最初に最も高い壁を横切るからです。 
3. ショットごとに、次の観点から発射体関数を計算します。`x`:`y(x) = x * tan(alpha) - (g * x^2) / (2 * V^2 * cos(alpha)^2)`。 これは、水平方向の動きの標準的な運動学方程式から導出されます (`x = V * cos(alpha) * t`) と垂直方向の動き (`y = V * sin(alpha) * t - 0.5 * g * t^2`）。 を解決する`t = x / (V * cos(alpha))`与える`y(x)`。 
4. 壁全体で線形スキャンを実行します。`x`。 壁ごとに計算します`y(x_i)`軌跡機能を使って。 もし`y(x_i) <= y_i`、ボールが引っかかる`(x_i, y(x_i))`そしてスキャンを中断します。 ボールを止める壁がない場合は、地面への衝撃を計算します。 地面は次のとおりです`y=0`。 解決する`0 = x * tan(alpha) - (g * x^2)/(2 * V^2 * cos^2(alpha))`のために`x`水平方向の着地点を取得するには:`x_ground = 2 * V^2 * sin(alpha) * cos(alpha) / g`。 
5. 十分な精度で最終座標を出力します (条件を満たすには少なくとも 9 桁の 10 進数)。`10^-4`許容範囲）。 

それが機能する理由: 不変条件は、ボールが右に単調に移動し、垂直方向の位置が増加することです。`x`ピークを過ぎると減少します。 壁を並べ替えると、`x`そして順番にチェックすることで、ボールがぶつかる可能性のある最初の壁を確実に見つけることができます。 運動学の公式を直接使用することで、壁の交差点を見逃すことがなくなり、ごとに最大高さを処理できるようになります。`x`重なり合う壁を正しく処理します。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

g = 9.8

n, V = map(int, input().split())
angles = list(map(float, input().split()))
m = int(input())
walls = {}

for _ in range(m):
    x, y = map(float, input().split())
    if x not in walls or walls[x] < y:
        walls[x] = y

# Convert walls to sorted list of tuples
walls_list = sorted(walls.items())

results = []

for alpha in angles:
    tan_alpha = math.tan(alpha)
    cos_alpha = math.cos(alpha)
    cos2 = cos_alpha ** 2
    x_final = None
    y_final = None
    
    for x, y_wall in walls_list:
        y_proj = x * tan_alpha - (g * x * x) / (2 * V * V * cos2)
        if y_proj <= y_wall + 1e-10:  # small epsilon for floating point
            x_final = x
            y_final = y_proj
            break
    
    if x_final is None:
        x_final = (2 * V * V * math.sin(alpha) * cos_alpha) / g
        y_final = 0.0
    
    results.append((x_final, y_final))

for x, y in results:
    print(f"{x:.9f} {y:.9f}")
```コードはまず、重なっている壁をそれぞれの位置で最も高い壁に統合します。`x`。 次に、最初に衝突する壁が見つかるまで、壁の位置での各発射体の位置を計算します。 壁に衝突しない場合は、地面衝撃の公式が使用されます。 イプシロンにより、数値精度により壁が誤ってスキップされないことが保証されます。
