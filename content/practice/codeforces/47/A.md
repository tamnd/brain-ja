 ## 解決策
 ## 問題の理解

 与えられた正の整数が三角数として表現できるかどうかを判断するように求められます。 三角数は正三角形にドットを配置することによって形成されるため、_n_ 番目の三角数は最初の _n_ 個の正の整数の合計になります。 たとえば、最初のいくつかの三角数は 1、3、6、10、15 などです。 入力は単一の整数です`n`1 ～ 500 の範囲で、出力は次のようになります。`YES`もし`n`任意の三角数に一致します。それ以外の場合は、`NO`。 

以来`n`が最大 500 であれば、計算上の限界について推論できます。 32 番目の三角数はすでに 528 であり、上限をわずかに上回っているため、各三角数を順番に計算することは可能です。 これは、問題が単純な反復に十分小さいことを示しています。 不注意なアプローチでは、浮動小数点除算を使用して三角数の式を逆にしようとする可能性があり、1、3、6 などの小さな整数に対して 1 ずつずれたエラーが発生する可能性があります。たとえば、2 次式の判別式の計算を誤ると、1 は三角ではないと誤って結論付ける可能性があります。 

エッジケースには以下が含まれます`n = 1`、`n = 500`、および 5 (3 と 6 の間) などの三角形の数字のすぐ下または上の数字。 

## アプローチ

 素朴なアプローチは、三角数を順番に生成し、それぞれを次のように比較することです。`n`。 1 から始めて、次に 1 + 2 = 3、次に 1 + 2 + 3 = 6 というように、一致するまで続けます。`n`またはそれを超えます。 これが機能するのは、三角数が単調増加するためです。`n`一致するものを見つける可能性はありません。 

ここでは、この単純な方法で実際には十分です。`n`は 500 です。三角数はほぼ二次関数的に増加するため、最悪の場合の反復回数は約 32 になります (`k(k+1)/2 ≤ 500`）。 これは、2 秒という時間制限の妥当な制限をはるかに下回っています。 

別の方法は、閉じた形式の式を使用することです。`k(k+1)/2 = n`そして解決します`k`二次公式を使って。 これには、解が正の整数であるかどうかを確認する必要があります。 数学的には洗練されていますが、浮動小数点演算や慎重な整数チェックが必要になり、丸めの問題が発生する危険があるため、この問題に対しては反復アプローチがより簡単で安全で、完全に適切です。

 | ブルートフォース | O(√n) | お(1) | 承認済み |
 | 二次公式 | お(1) | お(1) | 受け入れられるが、やりすぎ |

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`current`現在の三角数を表す 1 と変数`increment`2. 変数`increment`次の三角数を形成するために追加する次の数を追跡します。 
2. ループしながら`current`以下である`n`。 反復ごとに、次のことを確認します。`current`等しい`n`。 存在する場合は、印刷してください`YES`そしてプログラムを終了します。 
3. もし`current`等しくない`n`、 追加`increment`に`current`次の三角数を取得し、インクリメントします`increment`これは、最初から合計を計算することなく、シーケンス 1、3、6、10 などの形成をシミュレートします。 
4. 一致するものが見つからずにループが終了した場合は、次のように出力します。`NO`。 

これが機能する理由は、三角数が厳密に単調増加するためです。 それらを反復的に構築することで、次のことが保証されます。`n`三角形であれば正確にヒットします。 オーバーシュートすると、それに等しい三角数は存在しません`n`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

current = 1
increment = 2

while current <= n:
    if current == n:
        print("YES")
        break
    current += increment
    increment += 1
else:
    print("NO")
```コードはアルゴリズムに直接に従います。`current`最初の三角数である 1 から始まり、`increment`2 から始まります。ループは追加します`increment`に`current`毎回、連続する三角数を生成します。 の`else`に関する条項`while`ループは、ループが何もせずに自然に終了した場合にのみトリガーされます。`break`を保証します。`NO`一致するものが見つからない場合は、 が出力されます。 これにより、off-by-one エラーや不必要なチェックが回避されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from contextlib import redirect_stdout
    out = io.StringIO()
    with redirect_stdout(out):
        n = int(input())
        current = 1
        increment = 2
        while current <= n:
            if current == n:
                print("YES")
                break
            current += increment
            increment += 1
        else:
            print("NO")
    return out.getvalue().strip()
