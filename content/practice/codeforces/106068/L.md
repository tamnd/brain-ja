 ## 解決策
 ## 問題の理解

 まず、サイズが高さで表される 1 つの正三角形から始めます。$H$。 このプロセスは反復的です。 各操作で、三角形は 4 つの合同な正三角形に再分割され、中央の 1 つだけが保持され、他の 3 つは破棄されます。 この動作を繰り返す$K$回、常に残りの三角形に適用されます。 

タスクは、最後に残った三角形の面積を決定することです。$K$そのような操作。 

幾何学的観点から見ると、各操作は固定線形係数で三角形を縮小します。 三角形は 4 つの等しい面積の部分三角形に分割され、1 つだけが保持されるため、面積はちょうど 1 分の 1 に減ります。$4$操作ごとに。 これにより、問題は基本的に、幾何学的再構成ではなく、細分化が繰り返された場合の面積の指数関数的減衰に関するものになります。 

入力境界は操作の数に対して大きく、$K$まで$10^5$。 これにより、ジオメトリをシミュレートしたり、浮動小数点ジオメトリ構造を使用して段階的に反復的な領域の再計算を実行したりするアプローチは即座に除外されます。 ただし、変換の構造は乗法的でステップごとに一定であるため、プロセス全体を閉じた形式の式に減らすことができます。 

微妙なエッジケースが現れるのは、$K = 0$、ここでは変換は起こらず、答えは単に元の三角形の面積になります。 少なくとも 1 つの操作を前提としたソリューションでは、ステップが適用されない場合でも、領域が誤って縮小されます。 

浮動小数点の安定性から別の問題が発生します。 答えには 4 の累乗による繰り返し除算が含まれるため、単純な乗算または除算の反復では、大きな精度誤差が蓄積される可能性があります。$K$、特に近くの$10^{-4}$許容範囲。 これにより、段階的な更新ではなく、最終的なべき乗をワンショットで計算することが奨励されます。 

## アプローチ

 直接シミュレーションでは、三角形を明示的に維持し、各細分割後にその面積を再計算します。 各ステップでは 4 つの等しい部分のうちの 1 つだけが保持されるため、面積は「現在の面積を 4 で割ったもの」として繰り返し再計算できます。 これは正しいです。各操作では領域を均一に縮小しながら類似性が維持されます。 

ただし、これにより、線形時間プロセスが発生します。$K$。 と$K$まで$10^5$、これはまだ計算上は実行可能ですが、不必要な浮動小数点の繰り返し除算が導入され、累積エラーのリスクが増大し、オーバーヘッドが追加されます。 

重要な観察は、変換が純粋に乗算的であり、ステップ全体で独立しているということです。 後$K$演算の場合、面積はまさに初期面積に次の値を乗算したものになります。$(1/4)^K$。 これにより、べき乗を使用して最終結果を定数時間で計算できるようになります。 

唯一残っている成分は、高さを与えられた正三角形の最初の面積です。$H$。 正三角形の場合、高さが$H$、辺の長さは$s = \frac{2H}{\sqrt{3}}$、面積は次のとおりです。$$A = \frac{\sqrt{3}}{4}s^2 = \frac{\sqrt{3}}{4} \cdot \frac{4H^2}{3} = \frac{\sqrt{3}}{3}H^2$$したがって、最終的な答えは次のようになります。$$A_K = \frac{\sqrt{3}}{3}H^2 \cdot 4^{-K}$$| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |

 ## アルゴリズムのチュートリアル

 1. 整数の読み取り$H$そして$K$。 これらは、元のジオメトリと、縮小操作が適用される回数を定義します。 
2. 高さに基づく公式を使用して、正三角形の初期面積を計算します。$A_0 = \frac{\sqrt{3}}{3}H^2$。 このステップでは、幾何学的入力をスカラー量に変換します。 
3. によって引き起こされるスケーリング係数を計算します。$K$操作、つまり$4^{-K}$。 各操作では 4 つの等面積部分のうちの 1 つが正確​​に保存されるため、面積は毎回 4 で除算されます。 
4. 初期面積に倍率を乗算して、最終面積を取得します。 
5. 結果を浮動小数点数として出力します。 

### なぜ効果があるのか

 各操作の変換により、正三角形が 4 分の 1 の面積を持つ類似の三角形にマッピングされます。 類似性により、スケールを超えて形状が問題にならないことが保証されるため、領域の進化のみが関係します。 各ステップは同じ一定の比率を独立して適用するため、後の領域は$K$ステップは、まさに初期面積に次の積を乗算したものです。$K$同一の因子$1/4$。 この乗法的不変性により、中間の幾何学的な推論は必要なく、シーケンスに依存する動作も存在しません。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

H, K = map(int, input().split())

# initial area of equilateral triangle from height
area0 = (math.sqrt(3) / 3.0) * H * H

# each operation keeps 1/4 of the area
area = area0 * (0.25 ** K)

print(area)
```コードはまず、標準の正三角形の恒等式を使用して、幾何学的高さを面積に変換します。 次に、変換は単一のべき乗演算として適用され、反復ループが回避されます。 使用する`0.25 ** K`繰り返し分割する場合と比較して、明瞭さと数値の安定性の両方が保証されます。 

よくある落とし穴は、最初に辺の長さを計算してから面積を再計算することです。これにより、精度は向上せずに余分な浮動小数点演算が発生します。 もう 1 つは K 回のループですが、これは不必要であり、丸め誤差が蓄積する可能性があります。

## テストケース```python
import sys, io
import math

def solve():
    input = sys.stdin.readline
    H, K = map(int, input().split())
    area0 = (math.sqrt(3) / 3.0) * H * H
    print(area0 * (0.25 ** K))

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from contextlib import redirect_stdout
    import io as sio
    out = sio.StringIO()
    with redirect_stdout(out):
        solve()
    return out.getvalue().strip()

# provided samples
assert run("10 2")[:5] == "3.608"
assert run("5 0")[:6] == "14.433"

# custom cases
assert run("1 0")[:5] == "0.577", "minimum height no operations"
assert run("1 1") != "0", "single reduction should shrink area"
assert run("1000000000 0") != "", "maximum H no operations"
assert run("2 5") != "", "small height large K stability check"

 ## 特殊なケース

 のために$K = 0$の場合、アルゴリズムはスケーリングを適用せずに元の三角形領域を返す必要があります。 この式を機械的にたどると、べき乗は$4^0 = 1$, したがって、結果は変わりません。 入力用$H = 10, K = 0$、計算は次のようになります。$$A = \frac{\sqrt{3}}{3} \cdot 100 \cdot 1$$アルゴリズムは特別な分岐を行わずにこれを自然に処理します。 

大型用$K$、 言う$K = 100000$、要因$0.25^K$浮動小数点演算ではゼロに向かってアンダーフローします。 面積は指数関数的にゼロになる傾向があるため、これは数学的限界と一致します。 印刷された許容差ではこの動作が許可されているため、数値的にゼロになっても結果は有効のままです。 

大型用$H$、 のような$H = 10^9$、初期領域は大きくなりますが、指数関数的減衰と組み合わせると、倍精度の範囲内に十分収まります。$4^{-K}$中程度の場合はすぐにマグニチュードが減少します$K$。
