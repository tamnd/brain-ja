 ## 解決策
 ## 問題の理解

 私たちには石の山が与えられました。 2 人のプレイヤーが交互にターンを行い、各ターンでプレイヤーが正の数の石を取り除きます。 制限は、削除される石の数が現在のパイル サイズの最上位ビット値よりも厳密に小さくなければならないことです。 

最上位ビットの値は、現在の数値を超えない最大の 2 の累乗です。 現在のパイルサイズが$x$、そのバイナリ表現で設定された最上位ビットは次のとおりです。$2^k$、その後、プレーヤーは任意の数字を削除することができます$1$まで$2^k - 1$。 石を取り除くと山が減り、他のプレイヤーにターンが移ります。 有効な手を打てなかったプレイヤーは負けます。これは山がゼロの場合に起こります。 

タスクは、多くの独立した開始値を決定することです。$N$、最初のプレイヤーが最適なプレイの下で強制的に勝利するかどうか。 

制約は次のとおりです$N \le 10^{18}$、ゲームのシミュレーションは即座に除外されます。 一つのゲームでも長く続く$O(N)$最悪の場合、移動する可能性があります。$10^5$テストケース。 したがって、どのソリューションも、おそらくバイナリ表現のプロパティを使用して、テスト ケースごとに最大でも対数時間または定数時間で答えを計算する必要があります。 

単純なアプローチでは、すべての可能な動きをシミュレートしたり、ゲームの状態を動的に計算したりしようとします。 これは時間の問題だけでなく、状態空間が巨大であり、遷移が現在の値の MSB に非線形に依存するため、失敗します。 

次の場合、微妙なエッジケースが発生します。$N$は 2 のべき乗のわずかに小さいか、わずかに大きい値です。 たとえば、$N = 7$、MSBは$4$、しかし、$N = 8$、MSBは$8$。 これにより移動範囲が大幅に変化し、単調性についての素朴な直感が不正確になります。 隣接する整数に関して同様の動作を想定する解決策は、ここで破綻します。 

## アプローチ

 ゲームを直接解決しようとすると、負けている状態への移行が存在する場合、その状態を勝ちと定義できます。 ある立場から$x$、プレイヤーは任意の状態に移動できます$x - k$どこ$1 \le k < \text{MSB}(x)$。 ブルートフォース再帰では、次のすべての数値の勝ちステータスが計算されます。$1$に$N$、すべての有効な動きをチェックします。 

これはゲームのルールに正確に従っているため、原則的には正しいです。 ただし、各州ごとに$x$、最大で$O(x)$最悪の場合（MSB が相対的に大きい場合）の遷移$x$)、これをすべてについて計算します$x$まで$10^{18}$不可能です。 に限定したとしても$N$、単一のテスト ケースはすでに実行可能な計算を超えています。 

重要な観察は、ゲームに影響を与える唯一の構造は、現在の最高の 2 のべき乗であるということです。 任意の間隔で$[2^k, 2^{k+1}-1]$、MSB は次のように固定されます。$2^k$, したがって、この範囲内のすべての位置には同じ移動制約が適用されます。 これにより、ゲームが独立したブロックに分割され、各ブロック内での動作が正確に分析できる方法で周期的になります。 

MSB が等しいブロック内$2^k$、許可される動きは、から何かを減算します。$1$に$2^k - 1$。 これは立場から言うと$x$、間隔内のすべての値に到達できます$[x-(2^k-1), x-1]$。 これは古典的な到達可能性の構造です。つまり、到達可能なすべての状態が勝っている場合にのみ、ポジションが負けます。 

重要な単純化は、そのような各ブロック内で、負けたポジションが単純なパターンを形成することです。つまり、すべてのポジションの剰余がモジュロになるということです。$2^k$ゼロの場合は、他のものとは異なる動作をします。 これは、ゲームの結果が次の条件にのみ依存するという事実につながります。$N$MSB の倍数であるかどうか。 

具体的に言うと、$N = 2^k$の場合、最初のプレイヤーは負けの立場になります。どのような動きをしてもゲームは前のブロックに送られ、対戦相手が完全に有利になるからです。 それ以外の場合は、$N > 2^k$、最初のプレイヤーはいつでも山を正確に減らすことができます$2^k$、相手に不利な立場を強います。 

これにより、問題全体が次のバイナリ構造の単純なチェックに集約されます。$N$。

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

1. 2 の最大累乗を計算します。$p$そのような$p \le N$。 これは、$N$。 ビット演算を使用して計算できます。 
2. かどうかを確認します。$N$と全く同じです$p$。 これにより、数値自体が 2 の累乗であるかどうかが決まります。 
3. もし$N = p$、最初のプレイヤーの負けポジションを宣言します。 
4. それ以外の場合は、最初のプレイヤーの勝ちと宣言します。 

ステップ 2 で十分である理由は、MSB が移動範囲全体を定義するためです。 一度$N$2 の累乗を超えると、相手を境界状態に強制するのに十分な柔軟性が常にあります。$p$、負けています。 

### なぜ効果があるのか

 ゲームは MSB 間隔によって自然に分割されます。 各インターバル内で$[2^k, 2^{k+1}-1]$、左端点を除くすべての位置は直接移動できます。$2^k$。 このエンドポイントは特別です。$2^k$、すべての動きは間隔を厳密に下回っており、対戦相手は効果的により有利な位置を与えられます。 これにより、間隔ごとに 1 つの負け状態が作成され、正確に 2 の累乗になります。 

2 のべき乗以外のすべてのポジションはその負け状態に直接移行できるため、勝ちとなります。 2 のべき乗のポジションは同じ間隔内にとどまることができないため、負けています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = 1 << (n.bit_length() - 1)
        if n == p:
            print("Second")
        else:
            print("First")

if __name__ == "__main__":
    solve()
```このソリューションは、以下を超えない最大の 2 のべき乗を計算します。$n$を使用して`bit_length`、これは最高位の設定ビットの位置を直接示します。 シフトすると 2 のべき乗が再構築されます。 

重要な決定は平等性チェックです。 もし$n$はちょうど 2 のべき乗であり、ポジションは負けています。 それ以外の場合は、プレーヤーはいつでも 1 回の移動で 2 のべき乗状態に移動できるため、勝ちです。 

この実装ではシミュレーションを一切回避し、純粋にバイナリ構造に依存します。これは、上限を考慮すると不可欠です。$10^{18}$。

 ## 特殊なケース

 のために$N = 1$、MSB は 1 であるため、1 未満の正の整数は存在せず、最初のプレイヤーは移動できなくなります。 アルゴリズムは計算します$p = 1$そして正しく負けを出力します。 

のために$N = 2^k$、 のような$N = 16$、MSB は以下に等しい$N$自体。 条件$N == p$トリガーし、負けとしてマークします。 どのような動きも前のインターバルに落ち、そこで対戦相手は即座に反応して構造的優位性を回復することができます。 

のために$N = 2^k + 1$、 のような$N = 9$, MSB は 8 です。プレーヤーは石を 1 つ削除して 8 になることができ、これは相手にとって負けのポジションです。 アルゴリズムはこれを勝ちとして分類します。$9 \ne 8$、建設的な戦略に一致します。
