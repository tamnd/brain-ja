## アプローチ

 ## アルゴリズムのチュートリアル

 私たちは問題を、与えられたシーケンス長の実現可能性をチェックすることに落とし込みます。$n$。

2. もし$S(n) \le s$、 それから$n$実現可能です。 そうでなければそうではありません。 
3. 二分探索を使用します。$n$、1 から始まり安全な上限まで。 自然な境界は、$2 \cdot 10^9$、しかし実際には$\sqrt{2s/k}$十分です。 安全にクランプできます$10^{9}$。 
4. 二分探索では、公式を使用して中点を繰り返しテストします。 可能であれば、右に移動して大きくしてみてください$n$、それ以外の場合は左に移動します。

### なぜ効果があるのか

 有効な長さのシーケンスに対して$n$、それぞれを置き換えます$a_i$制約と一致する最小の値を使用すると、同じ長さのシーケンスが生成され、合計がそれ以上大きくなりません。 この変換は厳密に合計を減少させるか維持するため、実現可能性は最小限の構成によって完全に決まります。 その最小和は単調であるため、$n$、二分探索では、実行可能な最大長が正しく特定されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def feasible(n, s, k):
    return n + k * n * (n - 1) // 2 <= s

def solve():
    t = int(input())
    for _ in range(t):
        s, k = map(int, input().split())

        lo, hi = 1, 10**9
        ans = 1

        while lo <= hi:
            mid = (lo + hi) // 2
            if feasible(mid, s, k):
                ans = mid
                lo = mid + 1
            else:
                hi = mid - 1

        print(ans)

if __name__ == "__main__":
    solve()
```機能`feasible`導出された最小和の式をエンコードします。 除算は全体で整数演算を使用するため安全です。 二分探索では、すべての値が次の値に達するという不変条件が維持されます。`ans`実現可能、そしてそれを超えるもの`hi`そうではありません。 

の上限$10^9$付いていても安全です$k = 1$、合計は次のように増加します$n^2/2$を超える$10^{18}$かなり前に$10^9$。

 ## 特殊なケース

 のために$s = 1$、 かかわらず$k$、長さ 2 の最小のシーケンスでも少なくとも合計が必要であるため、要素は 1 つだけ存在できます。$1 + (1 + k) > 1$。 アルゴリズムはこれを処理します。$S(2) = 2 + k > 1$, したがって、二分探索は 1 を超えて拡張されることはありません。 

非常に大きい場合$k$、 のような$k \ge s$、第2期だけですでに予算を超えています。 例えば、$s = 10, k = 20$。 それから$S(2) = 2 + 20 = 22$、だからそれだけ$n = 1$実現可能です。 実現可能性チェックは即座に拒否されます$n = 2$、答えは 1 のままです。 

のために$k = 1$、成長は最も遅く、可能な限り最大の長さが得られます。 このアルゴリズムは三角数に還元され、二分探索で最大の値が正しく見つかるため、引き続き機能します。$n$満足のいく$n(n+1)/2 \le s$。
