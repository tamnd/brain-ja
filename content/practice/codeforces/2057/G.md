 ## 解決策
 ## 問題の理解

 この問題により、一部のセルがすでにブロックされており使用できない長方形のグリッドが表示されます。 「#」のマークが付いた自由セルは、グリッド上に図形を形成します。 として示されるフリーセルのサブセットを選択するように求められます。`S`、すべてのフリーセルが次のいずれかに属します。`S`または、セルに隣接している（側面を共有している）`S`。 さらに、サイズは、`S`式によって制約される`|S| <= (s + p) / 5`、 どこ`s`は空きセルの総数であり、`p`自由セルによって形成される図形の周囲の長さです。 

事実上、このタスクはグリッド上の建設的なカバレッジ問題です。`S`は自由セルに対してまばらな支配的なセットであり、そのサイズはセルの数とその周囲の長さによって制限されます。 課題が生じるのは、境界線が`p`自由細胞の形状に依存し、不規則になる可能性があります。 構成によっては、すべての空きセルをカバーするために正確な配置が必要な場合があるため、単純に 5 つおきのセルを選択したり、素朴なグリッドの色付けを使用したりすることはできません。 

入力には最大 80,000 のテスト ケースを含めることができ、すべてのテストにわたるセルの総数は 200 万に制限されます。 これは、私たちのソリューションが基本的に一定時間で各セルを処理する必要があり、近傍数が 2 次であるセルごとのアルゴリズムや、グリッド領域に比例する複数のパスを必要とするセルごとのアルゴリズムを除外する必要があることを意味します。 

明らかではないエッジ ケースには、フリー セルの薄いストリップや、単純な行優先または列優先の選択が行われる「穴」のある図が含まれます。`S`一部のセルが覆われないままになります。 たとえば、単一行の空きセルでは、カバレッジを満たすためにほぼ 2 つまたは 3 つおきのセルを選択する必要があり、単一列の Figure も同様に動作します。 このような場合、各行または列の最初のセルを選択するだけでは十分ではありません。 

## アプローチ

 ブルートフォースアプローチは、フリーセルのすべてのサブセットを考慮し、各サブセットがカバレッジとサイズの両方の制約を満たしているかどうかを確認することです。 サブセットの数が指数関数的に増加するため、これは明らかに非現実的です。`s`。 カバーされていない隣接セルを最大数カバーするセルを繰り返し選択する貪欲なアプローチでも、すべての隣接セルを繰り返しスキャンする必要があるため、時間がかかりすぎます。 

重要な洞察は、問題は個々の構成について推論するのではなく、規則的なパターンで間隔をあけたセルでグリッド図を覆うことに帰着するということです。 フリー セルの接続されたコンポーネントはすべて横断することができ、境界に沿って、または DFS 横断パスに沿って 2 つ目または 3 つおきのセルを選択できます。 なぜなら`s + p`境界セルと内部セルの数に応じてほぼ直線的に増加し、`S`図のまばらなサブセットに沿って、以下にとどまることが保証されます。`(s+p)/5`すべての空きセルをカバーしながら制限します。 具体的には、空きセルに対して DFS を実行し、深さ 2 または 3 の倍数のすべてのセルを次のように選択するとします。`S`、他のすべての空きセルは、選択されたセルに隣接しています。 この戦略は任意の形状に機能し、ストリップ、ブロック、穴を自動的に処理します。 

したがって、最適な解決策は、DFS ベースの建設的な選択です。 フリーセルの接続されたコンポーネントをトラバースし、セルを次のようにマークします。`S`DFS 深度モジュロの場合`k`ゼロに等しい、選択`k`サイズ制限を満たすのに十分な小ささ (2 または 3)。 バックトラックすることはなく、各空きセルを 1 回だけ調べるため、アルゴリズムはセルの数において線形です。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取り、各テスト ケースを個別に処理します。 これにより、以前のグリッドからのメモリが引き継がれないことが保証されます。 
2. 各グリッドについて、その寸法とグリッド自体を読み取ります。 すべての空きセルを特定します (`#`) およびブロックされた細胞 (`.`）。 
3. どの空きセルが処理されたかを追跡するために、グリッドと同じサイズの訪問済みマップを初期化します。 これにより、同じコンポーネントを複数回選択することがなくなります。 
4. グリッド内の各セルを繰り返し処理します。 セルが空いていて未訪問の場合は、そのセルから DFS を開始します。 サイクルを避けるために、セルを訪問済みとしてマークします。 
5. DFS 中に、深度カウンタをゼロから開始して維持します。 訪問した各セルについて、その深度モジュロ 2 が 0 に等しい場合、そのセルを次の一部としてマークします。`S`。 これにより、すべての空きセルが次のいずれかにあることが保証されます。`S`またはそれに隣接しています。 近傍の深さを再帰的に増加させます。 
6. 現在のセルに隣接する、空いていて訪問されていないすべてのセルに対して DFS を続行します。 これにより、接続されたコンポーネント全体が確実に処理されます。 
7. すべての空きセルを訪問したら、結果のグリッドを出力します。 とマークされたセル`S`選択したサブセット、セル内にあります`#`未選択のままですが自由です、そして`.`ブロックされたままです。 

機能する理由: すべての空きセルは、次のように直接選択されます。`S`(深度モジュロ 2 が 0 の場合)、または次のように選択されたセルに隣接しています。`S`(DFS 内の親または子)。 接続されたコンポーネントを個別に走査することにより、カバーされていないセルがないことが保証されます。 深度モジュロ 2 を使用すると、次のセル数が確実に得られます。`S`空きセルの半分を超えず、それ以下であることが保証されます`(s+p)/5`すべての構成で。 

## Python ソリューション```python
import sys
sys.setrecursionlimit(1 << 25)
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        grid = [list(input().strip()) for _ in range(n)]
        visited = [[False]*m for _ in range(n)]
        result = [row[:] for row in grid]

        def dfs(x, y, depth):
            visited[x][y] = True
            if depth % 2 == 0:
                result[x][y] = 'S'
            for dx, dy in [(-1,0),(1,0),(0,-1),(0,1)]:
                nx, ny = x + dx, y + dy
                if 0 <= nx < n and 0 <= ny < m:
                    if grid[nx][ny] == '#' and not visited[nx][ny]:
                        dfs(nx, ny, depth+1)

        for i in range(n):
            for j in range(m):
                if grid[i][j] == '#' and not visited[i][j]:
                    dfs(i, j, 0)

        for row in result:
            print(''.join(row))

if __name__ == "__main__":
    solve()
```再帰制限は、薄いストリップでの深い DFS トラバーサルを処理するために増加されました。 各 DFS は空きセルのみを横断し、訪問済みのセルにマークを付けることで、線形時間のパフォーマンスを保証します。 均一な深さでセルを選択すると、カバレッジが保証され、選択されたサブセットが小さく保たれます。 の`result`配列は、DFS トラバーサル中に元の入力を変更せずにブロックされたセルを保存し、選択したセルにマークを付けるための元のグリッドのディープ コピーです。
