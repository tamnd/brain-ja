 ## 問題の理解

 長さの文字列が与えられます$N$固定開き括弧、固定閉じ括弧、および次のように記述されるワイルドカード位置の 3 種類の文字で構成されます。`?`。 各ワイルドカードは独立して次のいずれかに置き換えることができます。`(`または`)`。 

すべてのワイルドカードを置き換えると、標準のかっこ文字列が得られます。 このような文字列は、一致する括弧の正しいシーケンスとして解釈できる場合に有効です。つまり、接頭辞の閉じ括弧の数が開き括弧の数より多くなることはなく、開き括弧と閉じ括弧の合計数が等しいことを意味します。 

タスクは、有効なバランスの取れたシーケンスを生成する疑問符の割り当ての数をカウントし、このカウントのモジュロを出力することです。$10^9 + 7$。 

制約$N \le 3000$すべてのブルートフォースを即座に排除します$2^{\#?}$課題。 最悪の場合、文字列はすべて疑問符になるため、$2^{3000}$可能性はありますが、それは数え切れないほどです。 一つの課題を確認するだけでも時間がかかります$O(N)$, したがって、強引な攻撃は完全に不可能です。 

これにより、有効なプレフィックスを段階的に構築する動的プログラミング ソリューションが推進されます。 

素朴な推論による微妙な失敗例は、`(`そして`)`重要です。 たとえば、次のような文字列`"())("`カウントは等しいですが、プレフィックスの不均衡により無効です。 もう 1 つの落とし穴は、将来の選択を考慮せずに左から右にペアを貪欲に一致させることです。 ワイルドカードは後でバランスを修復したり崩したりする可能性があるため、ローカルでの決定は安全ではありません。 

## アプローチ

 ブルートフォースアプローチはすべてを反復することになる$2^k$疑問符を置き換えて結果の文字列を構築し、スタックまたはカウンター スキャンを使用してバランスが取れているかどうかを確認します。 これは、妥当性の定義を直接テストするため、正しいです。 ただし、$k = N$、これはすでに必要です$2^{3000}$構成と各妥当性チェックのコスト$O(N)$、実行できなくなる指数関数的な時間が発生します。 

重要な観察は、括弧の接頭辞の有効性は、現在存在する一致しない開き括弧の数にのみ依存するということです。 左から右にスキャンすると、次のように定義される現在の残高を追跡するだけで済みます。$$\text{balance} = \#(\text{open}) - \#(\text{close})$$この残高が決してマイナスにならず、ゼロで終了する場合、シーケンスは有効です。 

これは、位置とバランスを重視した動的プログラミングを示唆しています。 各インデックスでは、文字が固定であるかワイルドカードであるかに応じて遷移を考慮します。 州から$(i, b)$に移動します$i+1$そして更新します$b$選択した文字に応じて +1 または -1 します。 

これにより、問題はサイズの層状グラフ内のパスを数えるという問題に軽減されます。$O(N^2)$、残高の範囲は次のとおりです。$0$に$N$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^k \cdot N)$|$O(N)$| 遅すぎる |
 | DP オーバーポジションとバランス |$O(N^2)$|$O(N)$| 承認済み |

 ## アルゴリズムのチュートリアル

 DP 配列を定義します。`dp[b]`現在のバランスが正確になるように、現在の位置までプレフィックスを処理する方法の数を表します。$b$、プレフィックスは有効です (残高がマイナスになることはありません)。 

文字を左から右に処理します。 

1.初期化`dp[0] = 1`。 これは、正確に 1 つの方法で残高がゼロの空のプレフィックスを表します。 
2. 文字列内の文字ごとに、新しい DP 配列を構築します。`ndp`最初はすべてゼロです。 
3. 現在のキャラクターが`(`、バランスのあるすべての状態$b$に移行します$b+1$。 これは次の場合にのみ許可されます$b+1 \le N$。 これは、キャラクターのバランスを高める必要があるという選択の余地がないことを反映しています。 
4. 現在のキャラクターが`)`、バランスのあるすべての状態$b > 0$に移行します$b-1$。 ある州$b = 0$一致しないプレフィックスを閉じることができないため、この移行では無効です。 
5. 現在のキャラクターが`?`、両方の遷移を考慮します。次のように扱います。`(`そしてとして`)`。 1 つ目は残高を増やし、2 つ目は可能であれば残高を減らします。 
6.各文字を処理した後、置き換えます`dp`と`ndp`。 
7. すべての文字を処理すると、答えは次のようになります。`dp[0]`有効な完全なシーケンスは残高ゼロで終了する必要があるためです。 

これが機能する主な理由は、バランスによってプレフィックスが有効かどうかが完全に特徴づけられるためです。 他の履歴情報は必要ありません。 

### なぜ効果があるのか

 どのプレフィックスでも、すべての有効な部分割り当ては、その位置と現在の残高によって一意に記述されます。 同じ位置とバランスを持つ 2 つの部分シーケンスは、将来の有効性が負にならないこととゼロで終了することのみに依存するため、将来の拡張可能性は同一になります。 したがって、DP はすべての有効な構造を、バランスによってインデックス付けされた素の同値クラスに分割し、遷移によって正確性と完全性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

n = int(input().strip())
s = input().strip()

dp = [0] * (n + 2)
dp[0] = 1

for ch in s:
    ndp = [0] * (n + 2)
    if ch == '(':
        for b in range(n):
            if dp[b]:
                ndp[b + 1] = (ndp[b + 1] + dp[b]) % MOD
    elif ch == ')':
        for b in range(1, n + 1):
            if dp[b]:
                ndp[b - 1] = (ndp[b - 1] + dp[b]) % MOD
    else:
        for b in range(n + 1):
            if dp[b]:
                ndp[b + 1] = (ndp[b + 1] + dp[b]) % MOD
                if b > 0:
                    ndp[b - 1] = (ndp[b - 1] + dp[b]) % MOD
    dp = ndp

print(dp[0])
```DP 配列のサイズが設定されている$n+2$すべてのステップで境界チェックを行わずに遷移に安全に対応します。 文字が更新されるたびに新しい配列が構築され、同じ反復でまだ必要な状態が上書きされるのを防ぎます。 

実装の重要な詳細は、負の残高移行を決して許可しないことを保証することです。これは、`)`天びん 1 からループし、チェックすることで`b > 0`ワイルドカードの場合。
