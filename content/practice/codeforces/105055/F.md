 ## 解決策
 ## 問題の理解

 正確に次のシーケンスを構築するように求められます。$N$シーケンスが厳密に増加するような正の整数であり、そのようなすべてのシーケンスの中で総コストが最小のものを必要とします。 

コスト構造が重要な部分です。 各整数はバイナリ表現を通じて評価されます。 あらゆるビット位置$i$固定費がある$C_i$。 数字にビットがある場合$i$セット、貢献します$C_i$その数値のコストに。 したがって、数値のコストは、その数値に含まれるビット位置のコストの合計にすぎません。 ビット間に相互作用はなく、コストにおける桁上げ効果もありません。また、ビットが存在する範囲を超える数値への依存もありません。 

「正の整数を厳密に増加させる」順序制約は、選択されたすべての整数が個別であり、値によって順序付けできることを強制するだけです。 異なる正の整数の任意のセットを並べ替えることができるため、順序付けの制約によって選択できる数値のセットが制限されることはありません。数値を繰り返すことができず、ゼロを避ける必要があるということだけです。 

したがって、タスクは選択することになります。$N$明確なゼロ以外のバイナリマスク以上$M$ビットを増やして、ビットコストの合計を最小限に抑えます。 

制約があるため、これは興味深いものになります。$M$最大 1000 になる可能性があるため、可能な数の世界は膨大です。$2^M - 1$。 しかし、$N \le 100$したがって、指数関数的なサイズの空間にある最も安価な 100 個のオブジェクトだけが必要です。$M$。 すべてのサブセットを列挙しようとする方法は不可能です。 すべてのビットマスクに対する動的プログラミングさえも、次の理由により実行不可能です。$2^M$状態空間。 

素朴な試みは、すべてのサブセットコストを生成し、最小のものを選択するという観点から考えることです。$N$。 サブセットの数が指数関数的に増加するため、これはすぐに失敗します。$M$、そしてそれらを保存することさえ不可能です。 

2 番目の単純なアイデアは、最小のコスト パターンを持つビットまたは数値を貪欲に選択することですが、サブセットが組み合わせで相互作用するため、これは失敗します。少し高価なビットを早期に組み合わせると、後で安価なマルチビット サブセットが生成される可能性があるため、ローカルな決定ではグローバルな最適性が維持されません。 

微妙なエッジ ケースは、空のサブセットです。 そのコストはゼロであり、常に最良の候補となりますが、数値ゼロに対応します。すべての整数は正でなければならないため、これは許可されません。 正しい解決策がある場合は、それを考慮から明示的に除外する必要があります。 

## アプローチ

 問題の構造は次のとおりです。各数値は最大 1000 個の独立したアイテム (ビット) のサブセットであり、サブセットのコストはアイテムの重みの合計です。 私たちが望んでいるのは、$N$空のサブセットを除いた最小のサブセットの合計。 

これは古典的な「独立した重みの最小サブセットの k 個の合計」問題です。 ブルートフォースアプローチでは、次のすべてのサブセットが列挙されます。$M$ビットを取得し、そのコストを計算し、並べ替えて、最初のビットを選択します。$N$。 各サブセットが独立しており、コストの計算が簡単であるため、これは概念的に機能します。 失敗点は指数関数的な爆発です。$2^{1000}$サブセットは制限をはるかに超えています。 

重要な点は、すべてのサブセットが必要なわけではないということです。 最初のものだけが必要です$N$、 どこ$N \le 100$。 これにより、ビットを 1 つずつスキャンしながら、最良の候補の小さなフロンティアのみを維持することができます。 各ビットはサブセットに現れるか現れないかのどちらかであり、ビットを追加するとコストが次のように増加します。$C_i$。 これは、2 つの並べ替えられたリスト (既存のサブセットの合計と、それらの合計に新しい重みを加えたもの) を繰り返しマージすることと同じです。 

すべてのサブセットを明示的に保存する代わりに、現在最適なサブセットのリストを維持します。$N$サブセットの合計。 コストをかけて新しいビットを加工する場合$w$、既存のすべてのサブセットの合計$x$新しい候補者を生成できる$x + w$。 古いリストとシフトされたリストをマージし、最小のものだけを保持します。$N$結果。 すべてのビットに対してこれを繰り返すと、最良のものが構築されます$N$サブセット全体の合計。 

すべてのコストが負ではないため、サブセットの合計は可能性を拡大するにつれて単調増加し、枝刈りが行われます。$N$要素は、後で小さな結果の一部になる可能性のあるものを決して破棄しません。 

最後に、空のサブセットを破棄し、次のサブセットを取得します。$N$価値観。

 ## アルゴリズムのチュートリアル

 各ビット位置を重み付きの独立したアイテムとして扱います$C_i$。 各サブセットはこれらのアイテムのいくつかの選択に対応し、そのコストは選択された重みの合計です。 

## アルゴリズムのチュートリアル

 1. コスト 0 で、「何も選択しない」を表す単一のサブセットから開始します。これは、ビットを考慮する前のアイデンティティ状態として機能します。 
2. リストを管理する`dp`最小のものだけを保存する$N+1$これまでに見られたサブセットコスト。 保管しております$N+1$の代わりに$N$後で空のサブセットを破棄する必要があるためです。 
3. 各ビット位置について$i$、そのコストを読む$C_i$。 これを、すでに構築したサブセットに含めたり除外したりできるアイテムとして扱います。 
4. すべての値を取得して、候補の新しいリストを作成します。`dp`そしてまた追加$C_i$それに。 これは、このビットを使用しないか、または使用するすべてのサブセットを表します。 
5. オリジナルを結合する`dp`とシフトされたリストを並べ替えて、最小のものだけを保持します$N+1$価値観。 これにより、最も有望なサブセットコストのみが保持されることが保証されます。 
6. すべてのビット位置に対してこのプロセスを繰り返します。 
7. すべてのビットを処理した後、値 0 (空のサブセットに対応) を削除し、最小値を合計します。$N$残りの値。 

マージが機能する理由は、最初のマージを処理した後であるためです。$i$ビット、`dp`には、それらのビットのみを使用して達成可能な最小のサブセット合計が含まれます。 新しいビットを導入すると、有効な新しいサブセットはすべて古いサブセット、または古いサブセットにこのビットを加えたものになるため、明示的なサブセット列挙を必要とせずにマージによってすべての可能性が網羅されます。 

すべてのコストは負ではないため、枝刈りステップは安全です。 現在の最小値に含まれないサブセット$N+1$将来の操作では負でない値のみが追加されるため、後で小さくすることはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, M = map(int, input().split())
    C = list(map(int, input().split()))

    dp = [0]

    for w in C:
        new = dp + [x + w for x in dp]
        new.sort()
        if len(new) > N + 1:
            new = new[:N + 1]
        dp = new

    # remove empty subset
    dp = [x for x in dp if x != 0]

    print(sum(dp[:N]))

if __name__ == "__main__":
    solve()
```このコードは、最適なサブセット合計の動的なリストを維持します。 このリストは常に、処理されたビットを使用して達成可能な最小コストを表します。 各反復では、重みを追加して現在の状態を複製し、両方の可能性をマージし、切り捨てて最も関連性の高い候補のみを保持します。 

最後にゼロをフィルタリングすることで、無効な空のサブセットが誤って含まれることがなくなります。 最初は常にゼロが最小の要素であるため、当然、合計の前に削除されます。

 ## 特殊なケース

 空のサブセットは、主要な構造上のエッジ ケースです。 常にコスト 0 の初期状態として表示され、構築中は常に最小値になります。 このアルゴリズムは、正しいスーパーセットの組み合わせを生成する必要があるため、意図的に中間状態を通過しますが、最終的な答えを生成する前にそれを削除します。 たとえば、次の場合$M = 1$そして$C = [7]$、中間状態になります。$[0, 7]$。 ゼロを削除すると、有効なシーケンス要素は 7 だけになり、これは可能な唯一の正の整数と一致します。 

もう 1 つの微妙なケースは、複数の異なるサブセットが同じコストを生成する場合です。 これは、複数のビットが同一である場合に頻繁に発生します。$C_i$。 アルゴリズムは重複を保持します`dp`、それぞれが異なるサブセットを表し、到達するには複数の同一のコストが必要になる可能性があるため、これが必要です。$N$有効な個別の数値。
