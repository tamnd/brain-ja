 ## 解決策
 ## 問題の理解

 位置 0 から位置 N までの 1 次元の街路セグメントと、このセグメントに沿った固定整数座標に配置された街灯のセットが与えられます。 すべての街灯は同一の電球を使用し、各電球は固定距離 R だけ左右に対称に点灯します。これを電力と呼びます。 道路上の点は、少なくとも 1 つの街灯から距離 R 以内にある場合、点灯しているとみなされます。 

タスクは、0 から N までの区間上のすべての点が少なくとも 1 つの街灯によって照らされるように、R の最小値を選択することです。 

入力サイズでは最大 200,000 の街灯が許可されるため、どのソリューションでもすべてのペア間の二次比較を回避する必要があります。 すべての街灯柱のペアを比較したり、細かいグリッド上の点ごとにカバレッジをチェックしたりするソリューションでは、あまりにも時間がかかりすぎます。 ソート後に街灯柱の位置を線形時間または線形算術時間で処理するソリューションを期待する必要がありますが、それらはすでにソートされているため、線形時間は達成可能です。 

単純なアプローチでは、候補半径 R を試し、すべてのポイントをチェックするか、ラインを少しずつスイープすることによって、カバレッジが完全かどうかを検証します。 線形スキャンと組み合わせた R の二分探索でも機能しますが、限界ギャップを直接計算することでより良い結果を得ることができます。 

重要なエッジケースは境界から生じます。 街灯が 1 つしかない場合、答えは道路の両端をカバーするのに十分な大きさでなければならないため、max(P[0], N - P[0]) になります。 もう 1 つの微妙なケースは、街灯柱が集まっているが、中央に 1 つの大きな隙間が存在する場合に発生します。 他の距離に関係なく、そのギャップが答えを支配します。 

## アプローチ

 強引なアイデアは、半径 R を固定し、間隔 [P_i - R, P_i + R] の和集合がセグメント [0, N] 全体をカバーするかどうかをチェックすることです。 この検証は、街灯柱を通過し、最も遠くにある覆われた点を維持することによって行うことができます。 万一ギャップが生じた場合、R が不足します。 

ただし、R の可能な値をすべて試すことは現実的ではありません。R の範囲は N までであり、各チェックですべての街灯をスキャンする場合、すべての値を直接検索すると O(N^2) になるからです。 二分探索でもこれは O(M log N) まで改善されますが、探索を完全に回避することもできます。 

重要な観察は、適用範囲が完全に連続する街灯柱と境界線の間の距離によって決定されるということです。 位置 P[i] と P[i+1] にある 2 つの隣接する街灯の間では、それぞれがそれらの間の距離の少なくとも半分に広がっている場合にのみ、それらの受信可能範囲間のギャップは閉じられます。 したがって、セグメント内の制限要因は最大隣接ギャップの半分です。 最後に、0 から最初のランプまでの距離、および最後のランプから N までの距離もカバーする必要があります。 

したがって、答えは 3 つの量のうちの最大値です。0 から P[0] までの距離、P[M-1] から N までの距離、および連続する街灯間の最大差の半分です。 これにより、必要な最小半径が直接得られます。

 ## アルゴリズムのチュートリアル

1. 道路の始点から最初の街灯までの距離を計算します。街灯はその左側のすべてを独立してカバーする必要があるためです。 この値が P[0] です。 
2. 最後の街灯から道路の終点までの距離を計算します。これは、他の街灯がそれを超えてカバレッジを拡大するのに役立ちません。 この値は N - P[M-1] です。 
3. 連続する街灯柱のペアをすべてスキャンし、それらの間のギャップ P[i+1] - P[i] を計算します。 両側からのカバレッジは中央で交わる必要があるため、各街灯はそのギャップの最大でも半分に寄与します。 すべてのペアにわたるそのようなギャップの最大値を追跡します。 
4. ステップ 3 で求めた最大ギャップの半分を取ります。これは、隣接する 2 つの街灯柱の間に覆われていない領域が現れないようにするために必要な最小半径を表します。 
5. 最終的な答えは、計算された 3 つの値 (左境界距離、右境界距離、および最大内部ギャップの半分) の最大値です。 

### なぜ効果があるのか

 道路上のすべての点は、街灯から距離 R 以内になければなりません。 カバレッジが失敗する可能性がある唯一の場所は、2 つの連続する街灯柱の間の境界または中間のいずれかです。これは、1 つの街灯からのカバレージの連続間隔内には内部ギャップがないためです。 境界では、1 つの街灯のみが寄与するため、半径は少なくともエッジに達する必要があります。 2 つの街灯柱の間では、両方が中間点のギャップを埋めるのに十分な距離にある場合にのみ、それらのカバレッジ間隔が一致します。その場合、R はそれらの間の距離の少なくとも半分になります。 これらの必要な条件を最大限に活用すると、実行可能な最小の半径が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, M = map(int, input().split())
    P = list(map(int, input().split()))

    # distance to left boundary
    ans = P[0]

    # distance to right boundary
    ans = max(ans, N - P[-1])

    # maximum gap between consecutive lampposts
    max_gap = 0
    for i in range(M - 1):
        max_gap = max(max_gap, P[i + 1] - P[i])

    ans = max(ans, max_gap / 2)

    # output as integer (problem guarantees integer result)
    print(int(ans))

if __name__ == "__main__":
    solve()
```このコードは、実現可能性を定義する 3 つの制約を直接実装します。 入力を読み取った後の最初の 2 行は、境界カバレッジを処理します。 このループは、隣接する街灯間の最大間隔を計算します。これは、2 つの照明範囲が交わる必要がある唯一の場所です。 2 で割ると、ギャップが両側からの必要な対称拡張に変換されます。 最終的な最大値は、すべての制約を組み合わせて、最小の十分な半径になります。 

微妙な点は、2.0 による除算を使用し、その後 int にキャストすると、答えが整数であるか、丸めの問題なしで正確に表現できると想定されることです。 この問題の典型的な定式化では、すべての位置は整数であり、最適な半径は整数または半整数のいずれかであり、問​​題固有の保証の後でも整数出力が得られます。 厳密な整数演算が優先される場合は、上限のある整数除算を次のように使用できます。`(gap + 1) // 2`整数のみの形式で作業する場合。

 ## 特殊なケース

 長い通りの位置 0 にある 1 つの街灯柱は、半径を N に設定することでカバーされます。アルゴリズムは左側の境界距離を 0、右側の境界距離を N として計算するため、答えは N となり、1 つのランプでセグメント全体をカバーする必要があるという要件と一致します。 

N = 10 の P = [2, 8] など、2 つの街灯が遠く離れているケースでは、ギャップ状態が明らかになります。 ギャップは 6 であるため、ハーフギャップは 3 です。境界距離は 2 と 2 であるため、答えは 3 です。アルゴリズムは、最大のカバーされていない領域の中点を制限因子として正しく選択します。 

P = [0, 1, 2, 100] など、遠くの端点を持つ密にクラスター化されたセットでは、右側の境界が優勢になります。 100 の最後の街灯は半径 0 から 100 を強制するため、答えは 0 になり、アルゴリズムは max(N - P[-1], ...) を介してこれを取得します。
