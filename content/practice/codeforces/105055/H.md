 ## 解決策
 ## 問題の理解

 整数パラメータが与えられています$N$そして有理関数$$f(x) = \frac{5xN^2}{x^2 + 3xN - 5N^2}.$$タスクはすべての実数値を見つけることです$a$そのようなプラグ$a$関数に入力すると同じ値が返されます。つまり、$f(a) = a$。 このような値がいくつ存在するかを出力し、それらを明示的にリストする必要があります。 

入力サイズは小さいです:$N$にある$[-300, 300]$そしてゼロ以外です。 これにより、漸近的に重いメソッドの必要性が即座に排除されます。 テスト ケースごとに定数サイズの代数問題を最終的に解くことができれば、どのような解決策でも十分です。 

主な微妙な点は、領域制限のある有理方程式を解いていることです。 一部の値では分母がゼロになる可能性があり、それらの値は、単純化後に代数根として表示される場合でも除外する必要があります。 この制限を追跡せずに両辺に分母を掛ける単純な代数操作を行うと、誤って無効な点が含まれてしまいます。 

2 番目の微妙な点は、$x$分子に次のものが含まれるため、これは魅力的です。$x$、 しかし$x = 0$別々に扱う必要があります。 このルートは、分母がゼロ以外の場合には有効ですが、簡略化中に簡単に失われます。 

エッジケースには次のようなものがあります。 

のために$N = 1$、分母は次のようになります$x^2 + 3x - 5$、これには実根があるため、いくつかの候補解が関数の極と一致する可能性があります。 不注意なソルバーにはそのような点が含まれる可能性があります。 

のために$x = 0$、私たちはいつも得ます$f(0) = 0$分母がゼロ以外である限り、分母は次のように評価されるため、$-5N^2 \neq 0$、ゼロは常に有効な解です。$N \neq 0$。 

最後に、方程式は二次方程式、つまりゼロを超える追加根が最大 2 つになる可能性がありますが、禁止された分母のゼロと一致するものがないことを確認する必要があります。 

## アプローチ

 強引な解釈では、次の方程式を扱うことになります。$f(x) = x$連続等式として計算し、候補となる実数値を列挙しようとします。 実際の解は数え切れないので、それは不可能です。 

代わりに、代数方程式を記号的に直接解きます。 関数の等価性$$\frac{5xN^2}{x^2 + 3xN - 5N^2} = x$$は、両辺に分母を乗算することによって変換できますが、分母がゼロである値を明示的に除外した後にのみ変換できます。 これにより、根が正確に見つかる多項式が生成されます。 

代数を実行すると:$$5xN^2 = x(x^2 + 3xN - 5N^2)$$右側を展開すると次のようになります。$$5xN^2 = x^3 + 3x^2N - 5xN^2.$$すべてを脇に置く:$$0 = x^3 + 3x^2N - 10xN^2.$$因数分解$x$:$$x(x^2 + 3Nx - 10N^2) = 0.$$したがって、解決策は常に 1 つあります$x = 0$。 残りの解は二次方程式から得られます。$$x^2 + 3Nx - 10N^2 = 0.$$その判別式は次のとおりです。$$\Delta = 9N^2 + 40N^2 = 49N^2.$$それで：$$x = \frac{-3N \pm 7|N|}{2}.$$以来$N^2$が常に正である場合、直接単純化します。$$x = \frac{-3N \pm 7N}{2}.$$したがって、2 つの根は次のようになります。$$x_1 = 2N, \quad x_2 = -5N.$$これらが分母をゼロにしないことをまだ確認する必要があります。 絶対にやらない番組の代わりをする$N \neq 0$したがって、3 つのルートはすべて有効です。 

この強引なアイデアは、有理方程式をあたかも実数の探索が必要であるかのように扱うため、失敗しますが、構造は明白な因数分解によって 3 次方程式にきれいに崩壊します。 重要な観察は、有理関数と恒等関数が等しい場合、常に分母をクリアした後に多項式が生成され、ここでは完全に因数分解されているということです。

 ## アルゴリズムのチュートリアル

 1. 方程式から始める$f(x) = x$両辺に分母を掛けますが、有効な解では分母が非ゼロであるという仮定の下でのみです。 これにより、禁止されたポイントから無効なルートが導入されることがなくなります。 
2. 結果の式を次の多項式に展開します。$x$。 元の分母は 2 次であり、これを乗算するため、構造は 3 次になります。$x$。 
3. すべての項を片側に移動して、3 次多項式を取得します。 このステップでは、関数方程式を標準的な根探索問題に変換します。 
4. 因数分解$x$, すべての用語に含まれているためです。 これによりすぐに次のことがわかります$x = 0$元の関数がそこで定義されていれば、これは解決策です。 
5. 残りの二次方程式を解く$x^2 + 3Nx - 10N^2 = 0$判別法を使って。 判別式は完全二乗に単純化され、きれいな整数根が保証されます。 
6. 2 つの根を次のように計算します。$2N$そして$-5N$。 
7. 3 つの値を出力します$0$、$2N$、 そして$-5N$。 

### なぜ効果があるのか

 この変換により、元の有理方程式と、分母がゼロ以外の領域で導出された多項式との間の等価性が維持されます。 元の方程式の有効な解はすべて多項式を満たす必要があり、分母を打ち消さない多項式の根が有効な解に対応します。 根の構造を明示的にチェックし、分母のゼロと一致するものはないため、$N \neq 0$、ソリューションセットは正確です。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    N = int(sys.stdin.readline().strip())
    res = [0, 2 * N, -5 * N]
    res = list(set(res))
    return str(len(res)) + "\n" + " ".join(map(str, res)) + "\n"

# provided sample

assert run("2\n") != "", "basic sanity"

 ## 特殊なケース

 のために$N = 1$を使用すると、方程式が特にきれいになり、導出された式が大きな値での偶発的なキャンセルに依存していないことを検証するのに役立ちます。 置き換える$N = 1$根を与える$0, 2, -5$。 分母は$x^2 + 3x - 5$、これは 3 つの点すべてでゼロではないため、ルートは無効になりません。 

のために$N = -1$、根が出ます$0, -2, 5$。 よくある間違いは、両方のことを忘れることです。$2N$そして$-5N$符号を一貫して反転しますが、構造は対称のままです。 どちらの値を代入してもゼロ以外の値がゼロになることはないため、分母のチェックは安全です。$N$。 

どれについても$N$、ルート$x = 0$は特に重要です。 元の有理式の分子が次の値に比例するという理由だけで存続します。$x$、分母は次のように評価されます。$-5N^2$、これは常にゼロ以外です。 これにより、$x$単純化中の因数分解は、因数分解後に明示的に再導入する限り、有効な解を破棄しません。
