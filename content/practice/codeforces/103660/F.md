 ## 解決策
 ## 問題の理解

 2 つの整数が与えられます。$n$そして$k$、および一連の$n$構造が一定のパターンに従う分数。 分母はすべて同じ値ですが、分子は 1 から始まり 2 までの単純な等差数列を形成します。$n$。 具体的には、分数は、$$\frac{1}{k}, \frac{2}{k}, \frac{3}{k}, \dots, \frac{n}{k}.$$各分数について、最初にそれを最小項に換算する必要があります。 これは、分子と分母を最大公約数で割ることを意味します。 すべての分数を個別に単純化した後、各換算された分数から分子を取り出し、それらを合計します。 

各テスト ケースの出力は、単純化された分子の合計です。 

制約は私たちを$O(n)$テストケースごとにそれ以上の解決策を見つけることは不可能です。$n$まで可能です$10^9$、最大で$10^5$テストケース。 すべての分数を反復するアプローチは直ちに実行不可能です。単一の最悪のケースでも問題が発生するためです。$10^9$gcd の計算。 

主なエッジケースは次のような場合です$k = 0$。 この場合、通常の意味では割り算は定義されません。 サンプルからの意図された解釈は、分母がゼロの場合は gcd の動作が意味を持たないため、分数は実質的に縮退し、特別な処理が必要になるということです。 直接計算する単純な実装$\gcd(i, 0)$除算を試みると、慎重に扱わないと誤ったロジックが生成されます。 

もう一つの微妙なケースは次のような場合です。$k = 1$。 すべての分数はすでにその分子に等しいため、答えは最初の分数の合計になります。$n$整数。 このケースは、一般的な式の健全性チェックとして機能します。 

## アプローチ

 直接的なアプローチは説明が簡単です。 テストケースごとに、すべてのテストを繰り返します$i$1から$n$、計算する$g = \gcd(i, k)$、端数を減らします$\frac{i}{k}$の中へ$\frac{i/g}{k/g}$、と追加します$i/g$答えに。 各分数は独立して約定されるため、これは定義上正しいです。 問題は、これには次のことが必要であるということです$O(n)$テストケースごとの gcd 計算。 と$n$まで$10^9$、単一のテスト ケースでさえ、実行可能な限界をはるかに超えています。 

重要な観察は、リダクション後の分子は次のもののみに依存するということです。$\gcd(i, k)$。 それぞれを処理するのではなく、$i$個別に、インデックスを gcd でグループ化します。$k$。 固定除数の場合$d$の$k$、すべての数字$i$そのような$\gcd(i, k) = d$分子に貢献する$i/d$。 書き込み$i = d \cdot x$、この状態になります$\gcd(x, k/d) = 1$。 それで合計します$x$すべての倍数にわたって$d$まで$n$と互いに素である$k/d$。 

これにより、問題は、共素性制約を伴う等差数列での数のカウントと合計に変換されます。 これを処理する標準的な方法は、次の素因数に対する包含と排他です。$k$、または同等にブロックをカウントするオイラーのトーティエントスタイルを使用します。 有効なものすべての合計が必要なので、$x$、それらの数だけでなく、互いに素な整数の合計が以下になるという事実を使用します。$m$の約数にわたる乗算接頭辞の合計を使用して表現できます。$k$。 約数を事前計算し、素因数分解に包含排除を適用する$k$各テスト ケースを次のように縮小します。$O(\sqrt{k})$または$O(\text{number of primes in }k)$。 

したがって、繰り返す代わりに、$n$の構造を反復処理します。$k$これは、一般的な制約ではテスト ケースごとに十分小さいです。

 ## アルゴリズムのチュートリアル

 中心的なアイデアは、各インデックスの寄与を書き直すことです$i$gcd 構造に関して言えば、$k$、次に、約数によって集計します。$k$。 

1. もし$k = 0$、分数リストを縮退として扱い、次のように分子の合計を直接計算します。$1 + 2 + \dots + n$分母がゼロの場合は意味のあるキャンセルが存在しないためです。 これは次のようになります。$\frac{n(n+1)}{2}$。 
2. もし$k \neq 0$、因数分解$k$その主な要因に。 多重度によって共素性の条件が変化することはないため、個別の素数のみが必要になります。 
3. すべての約数を生成します。$k$素因数分解から。 各約数$d$は、次の間で共有される可能性のある gcd 値を表します。$i$そして$k$。 
4. 各約数について$d$、 定義する$k' = k/d$。 全てを考慮したい$i$そのような$\gcd(i, k) = d$、これは以下と同等です$i = d \cdot x$どこ$\gcd(x, k') = 1$。 
5. そのようなものが何個あるか数えてください$x$範囲内に存在する$1 \le d \cdot x \le n$、つまり$x \le \lfloor n/d \rfloor$。 
6. 有効なすべての合計を計算します。$x \le \lfloor n/d \rfloor$と互いに素である$k'$の素因数に対して包含排他を使用する$k'$。 素数の各サブセットは、その積の倍数の算術和を交互に加算または減算します。 
7. 結果の合計を乗算します。$x$1 だけ (分子の寄与が正確に等しいため)$x = i/d$）を答えに蓄積します。 

### なぜ効果があるのか

 すべての整数$i$1との間$n$によって決定される 1 つのクラスにのみ属します$d = \gcd(i, k)$。 このパーティションにより、二重カウントや漏れがなくなります。 各クラス内での書き換え$i = d \cdot x$共素性条件を完全に分離します。$x$に対して$k/d$。 共主性制約は素数をきれいに考慮するため、包含-排他はこれらの制限されたセットの合計を正しく計算します。$k/d$。 分解により、元のすべての分子が変換された形式で 1 ​​回だけ寄与することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def factorize(x):
    primes = []
    i = 2
    while i * i <= x:
        if x % i == 0:
            primes.append(i)
            while x % i == 0:
                x //= i
        i += 1
    if x > 1:
        primes.append(x)
    return primes

def sum_upto(m):
    return m * (m + 1) // 2

def coprime_sum(m, primes):
    # sum of numbers in [1..m] not divisible by any prime in primes
    res = 0
    p = len(primes)
    for mask in range(1 << p):
        mult = 1
        bits = 0
        for i in range(p):
            if mask & (1 << i):
                mult *= primes[i]
                bits += 1
        if mult > m:
            continue
        cnt = m // mult
        s = mult * sum_upto(cnt)
        if bits % 2 == 0:
            res += s
        else:
            res -= s
    return res

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())

        if k == 0:
            print(n * (n + 1) // 2)
            continue

        primes = factorize(k)

        # naive grouping over divisors of k via inclusion-exclusion
        # contribution from each gcd class d
        ans = 0
        for mask in range(1 << len(primes)):
            d = 1
            bits = 0
            for i in range(len(primes)):
                if mask & (1 << i):
                    d *= primes[i]
                    bits += 1

            k_div_d = k // d
            m = n // d

            # inclusion-exclusion sum of x coprime to k_div_d
            res = coprime_sum(m, factorize(k_div_d))

            if bits % 2 == 0:
                ans += res
            else:
                ans -= res

        print(ans)

if __name__ == "__main__":
    solve()
```このソリューションは、包含と排除の 2 つの層を中心に構造化されています。 外側の層は、分子インデックスと分子インデックス間の可能な gcd 値によって分割されます。$k$一方、内側の層は、指定された換算係数と互いに素な整数の合計を計算します。 機能`coprime_sum`割り算制約によって生成される等差数列の合計を処理します。`factorize`同じ小さな整数なので再利用されます$k/d$包含排他のために繰り返し素数に分解されます。 

一般的な実装上の落とし穴は、包含/除外が約数に適用されるかどうかを混同することです。$d$または共素性制約への$x$。 正しい分離とは、$d$インデックスのスケーリングを制御します。$k/d$各クラス内で許可される値のフィルタリングを制御します。

 ## 特殊なケース

 のために$k = 0$の場合、アルゴリズムはすべての gcd ロジックをバイパスし、三角和を直接計算します。 入力用$n = 10$、実行が返されます$55$これは、すべての分数が単純な分子のみの寄与として動作するという事実と一致します。 

いつ$k = 1$、外側の包含-排他ループは引き続き実行されますが、すべての数値が 1 と互いに素であるため、内側の共原理フィルターは空になります。$i$まさに貢献する$i$、累積により最初の合計が再構築されます。$n$整数。 

いつ$n < k$、以下に大きな約数の倍数が存在しないため、ほとんどの gcd クラスは空です。$n$。 すべてのクラスが使用するため、アルゴリズムはこれを自然に処理します。$n // d$、ゼロになり何も寄与しないため、無効な寄与が防止されます。
