 ## 問題の理解

 2 つの有向グラフが与えられ、それぞれ次のようになります。$n$頂点。 両方のグラフは強く結びついており、どちらかのグラフ内のすべての有向サイクルの長さは で割り切れます。$k$。 

各頂点には、発信または着信のいずれかのラベルが付けられます。 正確に追加することができます$n$新しい有向エッジ、および追加されたすべてのエッジは 2 つのグラフの間に入る必要があります。 これらの追加エッジは完全な構造を形成する必要があります。すべての出力頂点には 1 つの出力追加エッジがあり、すべての入力頂点には 1 つの入力追加エッジがあります。 

これらのエッジを追加した後、元のグラフと追加されたエッジの両方によって形成される最終的な有向グラフを確認します。 要件は、この結合グラフ内のすべての有向サイクルも、次の値で割り切れる長さを持たなければならないことです。$k$。 課題は、そのような構築が可能かどうかを判断することです。 

この制約は、最終的なグラフでは何も直接シミュレートできないことを意味します。 各グラフには最大で次のものを含めることができます$2 \cdot 10^5$テスト全体にわたる頂点全体、および最大エッジの合計$5 \cdot 10^5$。 どのようなソリューションでも、テスト ケースごとに構造を線形または線形に近いものに削減する必要があるため、通常は$O(n + m)$または$O(n \log n)$。 

2 つのグラフ間の相互作用から、微妙な困難が生じます。 それぞれのグラフはすでに個別に「$k$-cycle-consistent」を使用すると、クロス エッジを追加すると、両方のグラフを混合する新しいサイクルが作成される可能性がありますが、それらの混合サイクルは依然として同じモジュラー制約を尊重する必要があります。 

よくある落とし穴は、グローバルに入力頂点と出力頂点のバランスをとることだけを考えることです。 これでは十分ではありません。たとえカウントが一致したとしても、剰余モジュロ全体で内部構造が一致しません。$k$悪いサイクルを強制する可能性があります。 

出力頂点を任意に貪欲に一致させようとすると、別の失敗ケースが発生します。 ローカルに有効なマッチングであっても、長さが次の値で割り切れないサイクルが作成される可能性があります。$k$2 つのグラフには、位置合わせする必要がある隠れたモジュール構造が課されるためです。 

## アプローチ

 各グラフ内では、すべてのサイクル長が次の条件で割り切れます。$k$非常に強いです。 これは、頂点の一貫したモジュール化されたラベル付けを意味します。 任意の頂点を選択して値を割り当てます$0$。 任意の有向エッジの場合$u \to v$、値の差を定義します$+1$その端に沿って。 すべてのサイクルは次の値で割り切れる長さがあるため、$k$、この割り当ては一貫しています。同じ頂点間の任意の 2 つのパスは、長さが次のサイクルだけ異なります。$0 \bmod k$、つまり値の剰余$k$は明確に定義されています。 

これは、各グラフのすべての頂点に剰余を割り当てることができることを意味します。$\mathbb{Z}_k$そして、すべての有向エッジはこの剰余を正確に増加させます$1 \bmod k$。 

したがって、各グラフは次のように分解されます。$k$レイヤー、すべてのエッジはレイヤーから始まります$i$レイヤー化する$i+1 \bmod k$。 

次に、交差エッジを追加すると何が起こるかを考えてみましょう。 すべてのクロスエッジも貢献します$+1$したがって、サイクルが有効であり続けるためには、同じモジュール構造も尊重する必要があります。 This forces compatibility between the residue systems of the two graphs, but the second graph’s labeling can be cyclically shifted without changing internal validity.

 つまり、核となる自由は単一の世界的な変化である$s \in [0, k-1]$2 番目のグラフのすべての剰余に適用されます。 

シフトを修正した後、すべての頂点には、共通のモジュロ システムで明確に定義された剰余が含まれます。 

次に、追加されたエッジを見てください。 各頂点には、適切な方向にインシデント追加エッジが 1 つだけ存在する必要があります (出力する頂点は 1 つを放射し、入力する頂点は 1 つを受信します)。 これにより、方向制約の下で 2 つのグラフの頂点セット間の完全な一致が強制されます。 

重要な観察は、エッジはグラフ間で両方向に進むことができるため、重要な構造はシフト下での剰余の互換性だけであるということです。 残基が整列したら、基本的に、残基クラスごとに必要な「送信者」と「受信者」を一貫して照合できるかどうかをチェックします。 これにより、問題は、残差クラスごとに、利用可能なエンドポイントの数が一致するようなシフトが存在するかどうかをチェックすることに集約されます。 

強引なアプローチでは、次数制約と周期制約の両方を考慮して頂点間のすべてのマッチングを試行しますが、これは本質的に階乗的であり、完全に実行不可能です。 

モジュール構造により、すべての複雑さが解消されます。$k$残差クラスと単一のシフトパラメータにより、問題がチェックに変わります$k$可能な調整。

 ## アルゴリズムのチュートリアル

 ### ステップ 1: 各グラフ内のモジュールラベルを計算する

 各グラフに対して、任意のノードから DFS または BFS を実行し、剰余値を割り当てます。$k$すべてのエッジで値が増加するように、$1$。 強力な接続により、この割り当ての一貫性が保証されます。 

### ステップ 2: 残基ごとの頂点タイプを数える

 各グラフについて、発信ラベルと着信ラベルに分けて、各剰余クラスの頂点の数を維持します。 

したがって、グラフ A については次のように計算します。 

-$outA[r]$-$inA[r]$グラフBについても同様です。 

### ステップ 3: 2 番目のグラフのすべての循環シフトを試す

 シフトを選択します$s$グラフ B のすべての剰余に適用されます。シフト後の剰余の頂点$r$になる$r + s \bmod k$。 

### ステップ 4: 各シフトでの実現可能性を確認する

 固定シフトの場合、残差クラスごとに結合需要を計算します。 追加されたエッジは、すべての出力頂点がグラフ全体で何らかの入力頂点と一致することを満たさなければなりません。 エッジは常にグラフ間を移動するため、実現可能性は、シフトの下で剰余クラスごとに利用可能なエンドポイントが等しくなるまで下がります。 

何らかのシフトですべての残基クラスが完全にバランスがとれていれば、構築は可能です。 

### ステップ 5: 結果を出力する

 少なくとも 1 つのシフトが機能する場合は、「はい」と答えてください。 それ以外の場合は「NO」と答えてください。 

### なぜ効果があるのか

 不変条件は、各グラフが一貫性を認めることです。$\mathbb{Z}_k$潜在関数の増加$1$エッジに沿って。 結合グラフ内の有向サイクルの全長は、これらの増分の合計に等しくなります。 したがって、サイクルは、残留ポテンシャルがすべてのクロスエッジにわたって一貫している場合にのみ有効です。 

唯一の自由度は、2 つのグラフの剰余系間のグローバル オフセットです。 このオフセットが固定されると、すべての頂点は剛体残基クラスを持ち、有効な構築はこれらのクラスを尊重する必要があります。 どのオフセットの下でも剰余カウントが一致しない場合、エッジを一致させなくても、不正確なモジュラー和を含むサイクルが生成されることを回避できません。 逆に、一貫したオフセットが存在する場合、サイクル制約に違反することなく剰余クラス内でエッジをペアにすることができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_residue(n, edges, k):
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)

    # strongly connected + cycle condition => consistent mod-k labeling
    # we propagate arbitrary DFS labeling
    comp = [-1] * n
    val = [0] * n

    sys.setrecursionlimit(10**7)

    def dfs(u):
        for v in adj[u]:
            if comp[v] == -1:
                comp[v] = 0
                val[v] = (val[u] + 1) % k
                dfs(v)
            else:
                # consistency check (optional; guaranteed by statement)
                pass

    comp[0] = 0
    dfs(0)

    # fallback BFS to ensure all visited (graph strongly connected)
    from collections import deque
    q = deque([0])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if comp[v] == -1:
                comp[v] = 0
                val[v] = (val[u] + 1) % k
                q.append(v)

    return val

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a_cls = list(map(int, input().split()))
    m1 = int(input())
    edges1 = [tuple(map(lambda x: int(x) - 1, input().split())) for _ in range(m1)]

    b_cls = list(map(int, input().split()))
    m2 = int(input())
    edges2 = [tuple(map(lambda x: int(x) - 1, input().split())) for _ in range(m2)]

    ra = build_residue(n, edges1, k)
    rb = build_residue(n, edges2, k)

    outA = [0] * k
    inA = [0] * k
    outB = [0] * k
    inB = [0] * k

    for i in range(n):
        if a_cls[i] == 1:
            outA[ra[i]] += 1
        else:
            inA[ra[i]] += 1

        if b_cls[i] == 1:
            outB[rb[i]] += 1
        else:
            inB[rb[i]] += 1

    ok = False

    for shift in range(k):
        good = True
        for r in range(k):
            a_out = outA[r] + outB[r]
            a_in = inA[r] + inB[r]

            # apply shift to B: residue r in B becomes (r+shift)%k
            b_out = outB[(r - shift) % k]
            b_in = inB[(r - shift) % k]

            if a_out != a_in:
                good = False
                break

        if good:
            ok = True
            break

    print("YES" if ok else "NO")
```実装では、まず各グラフのモジュール構造が再構築されます。 次に、すべての頂点を剰余クラスに圧縮します。$k$、役割 (受信または送信) によって分けられます。 最後に、2 つの残基システム間のすべての巡回アラインメントを試行し、次数制約が一貫して満たされるかどうかをチェックします。 

よくある微妙な点は、シフトが頂点ごとではなくグローバルであることです。 頂点ごとのアライメントを混合すると、サイクル不変式が即座に破壊されます。

 ## 特殊なケース

 1 つのグラフが単一の剰余クラスの頂点をすべて持ち、もう 1 つのグラフが均等に分散している場合、デリケートなケースが発生します。 その状況では、シフトによって不均衡を修正することはできず、単純なマッチングによって頂点を任意にペアにしようとしても、アルゴリズムは正しく拒否します。 

もう一つのコーナーケースは、$k = n$ここで、各頂点は事実上、一意の剰余クラス内に存在する可能性があります。 ここでは、カウントの不一致が 1 つでもあると、有効なシフトが即座に妨げられ、剰余カウントによって問題全体が崩壊し、置換全体にわたる厳密な等価性チェックが行われます。 

3 番目のケースは、両方のグラフが個別に対称的に見えるが、それらの剰余分布が相互に循環回転している場合です。 シフト ループはまさにこの状況を捉えており、唯一の自由はグローバルな位置合わせであり、頂点ごとの再配置ではないことを確認しています。
