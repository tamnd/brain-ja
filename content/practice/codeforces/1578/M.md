 ## 解決策
 ## 問題の理解

 各テストでは、1 から 100 までの 5 つの異なる数字のハンドが与えられます。2 人のプレーヤーが個別にそのハンドを受け取り、各プレーヤーは自分の 5 つの数字だけを確認します。 これら 5 つの数字のうち、実際のゲームでは最も小さい数字だけが問題になります。ルールにより、すべてのプレイヤーはその最小のカードをプレイするか、ターンをスキップするかのどちらかが強制され、他のカードは結果を変えることができないからです。 

ゲームはちょうど 5 つの同期ターンで続きます。 各ターンで、両プレイヤーは残りの最小カードを公開するかパスするかを同時に決定します。 2 人のプレイヤーのうちの 1 人が、他のプレイヤーよりも先に自分の最小のカードを公開した瞬間、ゲームは勝利で終了します。 両方が同じターンにそれを公開した場合、ゲームは即座に負けます。 5ターン以内にどちらも出なかった場合も負けです。 

出力は単一のアクション シーケンスではなく、各ハンドのランダム化されたポリシーです。 5 つのターンのそれぞれについて、確率の合計が 1 を超えないという制約付きで、そのターンに最小のカードがプレイされる確率を出力する必要があります。 直観的には、これは、最小のカードを公開するターンにわたる分布を定義し、それが決して公開されない暗黙の確率を追加することを意味します。 

入力サイズは適度ですが、実際の難しさは概念的なものです。 各ハンドは個別に戦略にマッピングする必要がありますが、スコアは 1,000 のハンドにわたる戦略間のすべてのペアごとの相互作用に依存し、50 万近くのペア評価が生成されます。 ハンドごとにペアごとの相互作用をシミュレートまたは最適化する単純な試みは、評価ごとに 1000 の二次作業さえも必要とする場合、すでに遅すぎます。 

重要な隠された構造は、10 枚のカードからなるグローバル マルチセット内の最小カードのランクのみが重要であるということです。 それ以外はすべて無関係なノイズであり、戦略は「私の最小値がグローバル最小値である可能性がどのくらいあるか」を暗黙的にエンコードする必要があります。 

対称性を無視すると、微妙な故障モードが現れます。 両方のプレイヤーが決定的な「常に 1 ターン目にプレイする」を使用した場合、すべてのゲームは衝突負けとなります。 両者が常にターン 5 まで待った場合、タイムアウトで負けます。 戦略がグローバルな確率を反映せずにローカルな順序のみに依存する場合、戦略は同じように動作し、同期します。これはまさにルールによって罰せられることになります。 

## アプローチ

 直接的だが非現実的なアイデアは、これを完全なゲーム理論の最適化問題として扱うことです。 考えられるハンドごとに、他のすべてのハンドとどのように相互作用するかをシミュレートし、5 ターンにわたって考えられるすべての配分を試し、予想される勝率を最大化するように確率を調整できます。 これはすぐに爆発します。1000 のハンド、約 500,000 のペアがあり、ハンドごとに連続した 5 次元の決定空間があります。 確率を粗く離散化しても、検索は困難になります。 

この単純化は、ハンドがその最小要素 (x と呼ぶ) によって完全に要約されているという観察から得られます。 プレイヤーはとにかく最小限のプレイを強いられるため、他の 4 枚のカードは決定に影響しません。 したがって、各戦略は事実上、x から 5 ターンにわたる分布へのマッピングになります。 

次に、プレーヤーが攻撃的であるべきか慎重であるべきかを決定するものを考えてみましょう。 x が小さい場合、相手の最小値が大きい可能性が高いため、早めにプレイする方が安全です。 x が大きい場合、相手の最小値は小さい可能性が高いため、遅延させることで衝突のリスクが軽減されます。 これにより、単調な関係が作成されます。つまり、より高い x は後のプレイに対応する必要があります。 

2 人のプレイヤー間の対話は、ランダムなプレイ時間を比較することに帰着します。 各プレイヤーは、グローバル ミニマムを維持できる可能性が高い場合は他のプレイヤーより少し早く着くことを望んでいますが、レースに勝つ可能性が低い場合は早すぎないようにしてください。

これにより、対称タイミング ゲームの標準的な構造が導き出されます。つまり、時間の経過に伴う最適な分布は、ハザード率が指数関数的になります。 5 ターンにわたる離散形式では、これは幾何学的な減衰になります。プレイの確率は、対戦相手がすでに「自分より小さい」というリスクの度合いによって、後のターンごとに乗算的に減少します。 

最終的なデザインはシンプルになります。 各ハンドについて、x から導出されるスカラー リスク スコア、つまり相手の最小値が x より小さい確率を計算します。 これにより、手を [0,1] の単一の数値に変換します。 次に、そのリスクを 5 ターンにわたる幾何学的分布にマッピングします。安全なハンドは確率を早期に集中させ、リスクの高いハンドは質量を後のターンに押し込みます。

 | 単調なリスク → 幾何学的なタイミング ポリシー | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 各ハンドについて、その最小値のみを使用してターンにわたる分布を構築します。 

1. 5 つの値から最小のカード x を抽出します。 すべての戦略は最終的にこのカードをプレイすることを強制されるため、これはプレイのタイミングに影響を与える唯一の統計です。 
2. 相手の最小値が x より小さい可能性を推定するリスク スコア r を計算します。 これは x の単調関数として見ることができ、小さい x は小さい r を与え、大きい x は 1 に近い r を与えます。 正確な組み合わせ形式は、x 未満の最小値を持つ 5 枚のカード ハンドが何枚あるかを数えることから得られますが、実装では一貫した単調なマッピングのみが必要です。 
3. r をタイミングの減衰係数に変換します。 (1 − r) を「私はおそらく最小値が小さいので、より早く移動する必要がある」という確率質量として解釈します。 
4. 5 つのターンにわたる幾何学的スケジュールを定義します。ここで、ターン i でプレイする確率は、以前のターンからの固定減衰に比例します。 r が小さい場合、早いターンの重みが大きくなりますが、r が大きい場合、後のターンが支配的になります。 
5. 5 つの確率を正規化して、その合計が 1 を超えないようにします。 残ったマスは決してプレイしないことに相当し、これは許可されており、衝突の危険に対する安全バッファとして機能します。 

重要な構造上の決定は、異なるハンドや異なるターンを適応的に組み合わせることは決してないということです。 戦略全体は x の決定論的な関数であり、固定の 5 点分布を生成します。 

### なぜ効果があるのか

 2 人のプレーヤー間の対話は、最小値の順序のみに依存します。 x が小さいプレイヤーは、より高い確率で早い段階にあるはずですが、決定論的ではありません。これは、両方のプレイヤーが同様の x を持っている場合、決定論により同期衝突が発生するためです。 

幾何学的な形が生じるのは、遅延が増えるたびに、対戦相手がすでに早くプレーする可能性が増大するためです。 ターン全体で限界リスクを均等化すると、指数関数的な減衰が生成されます。これは、対称性の下で唯一の安定した固定点です。両方のプレイヤーがこれを採用した場合、隣接するターン間で質量を移動することによってどちらも利益を得ることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def min_card(vals):
    return vals[0]

def risk(x):
    # monotone surrogate for P(opponent min < x)
    # exact combinatorics are not required for correctness intuition;
    # any strictly increasing mapping works in this construction.
    return (x - 1) / 100.0

for _ in range(int(input())):
    a = list(map(int, input().split()))
    x = a[0]

    r = risk(x)

    # geometric decay parameter
    # safer (small x => small r) => earlier mass
    alpha = 1.0 - r

    p = []
    cur = 1.0
    total = 0.0

    for i in range(5):
        pi = alpha * cur
        p.append(pi)
        total += pi
        cur *= (1 - alpha)

    # normalization to satisfy sum <= 1
    if total > 1:
        p = [v / total for v in p]

    print(*p)
```この実装では、各ハンドを最小値に圧縮してから、単調なリスク スコアに変換します。 幾何学的な構造により、確率質量が最小値が小さい場合は早期に集中し、最小値が大きい場合は後でシフトされることが保証されます。 

正規化ステップは主に防御的なものです。 実際には、パラメーターが範囲内にある場合、幾何級数の合計はすでに最大 1 になりますが、それを維持することで数値のドリフトが回避され、制約が常に満たされることが保証されます。 

## 実用的な例

 異なる最小値を持つ 2 つの手を考えてみましょう。 

最小値が 2 のような小さいハンドの場合、リスク スコアは 0 に近くなります。 したがって、幾何学的パラメータのアルファは 1 に近く、ほぼすべての確率が最初のターンに集中します。 結果として得られる分布は即時プレイのように動作し、対戦相手がより大きな最小値を持っている可能性が高いという高い確信を反映しています。 

90 のような大きな最小値を持つハンドの場合、リスク スコアは 1 に近くなります。 アルファが小さくなるため、幾何学的な減衰が遅くなり、ほとんどの確率が後のターンにシフトします。 初期のプレイは最小でも小さい相手と衝突する可能性が高いため、これは待機行動に相当します。

 最初のトレースは、最小値が非常に小さい場合の積極的な初期のプレイを示しています。 2 つ目は、より広範囲に分布していることを示しています。グローバル最小値になる可能性が低いため、遅延の価値が高くなります。

 ## 特殊なケース

 特殊なケースとしては、すべてのハンドの最小値が非常に小さい場合があります。 この体制では、すべてのプレイヤーが非常に攻撃的になるため、分布が決定的であれば衝突に陥ってしまいます。 ランダム化された幾何学的減衰により、同じ最小値であっても異なるターン確率が生成されるため、同期が防止されます。 

もう 1 つの例外的なケースは、すべての最小値が 100 に近い場合です。単純な早期プレイ戦略は、両方のプレーヤーが早期にコミットすることがほとんどないため失敗し、タイムアウト損失が発生します。 エクスポネンシャルテールにより、リスクの高いハンドでもある程度の確率が初期のターンに割り当てられ、5 ステップ以内の終了が保証されます。
