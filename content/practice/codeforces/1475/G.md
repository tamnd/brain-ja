 ## 解決策
 ## 問題の理解

 整数の配列が与えられ、Polycarp は、個別の要素のすべてのペアについて、一方が他方を分割する場合に配列が美しいと定義します。 言い換えれば、すべての人にとって、$i \ne j$、 どちらか$a_i$分割する$a_j$または$a_j$分割する$a_i$。 タスクは、配列を美しくするためにできるだけ少ない要素を削除することです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースでは、配列の長さと配列要素自体が提供されます。 各テスト ケースの出力は単一の整数、つまり削除する必要がある要素の最小数です。 

制約により許可されるのは、$n$まで$2 \cdot 10^5$および最大の要素値$2 \cdot 10^5$。 すべてのペアの割り算をチェックする単純なアプローチでは、次のことが必要になります。$O(n^2)$テスト ケースごとの操作。上限では実行不可能です。$n^2$そうかもしれない$4 \cdot 10^{10}$。 したがって、大まかにアルゴリズムが必要です$O(n \log n)$または$O(n \sqrt{m})$どこ$m$最大の入力を効率的に処理するための最大値です。 

微妙な特殊なケースは、同じ番号のコピーが複数存在する場合です。 例えば、$[2,2,8]$すべてのペアがすでに美しいので、$2$お互いに分割し、$2$分割する$8$。 重複を正しく処理しないアルゴリズムでは、要素が誤って削除される可能性があります。 もう 1 つのケースは、すべての要素が公倍数のない素数である場合です。たとえば、$[3,5,7]$; 最適な解決策は、1 つの要素を除いてすべての要素を削除することです。 

## アプローチ

 ブルートフォース手法では、すべてのペアをチェックし、可分性に違反する要素を貪欲に削除しようとします。 それは正しいですが、遅すぎます。 各要素について、他のすべての要素に対して割り切れる可能性を検証する必要があります。$n-1$要素、生成$O(n^2)$テストケースごとに。 これが受け入れられなくなるのは、$n$アプローチ$2 \cdot 10^5$。 

重要な観察は、配列が何らかの基数の倍数で構成されている場合に美しくなるということです。 すべてのペアをチェックする代わりに、数値ごとにカウントすることができます$x$配列内で割り切れる数値はいくつありますか$x$またはの倍数$x$。 潜在的な基数ごとに、その倍数で終わる美しいサブセットの最大サイズを計算すると、削除する最小要素は次のようになります。$n$minus this maximum subset size.

 これにより、問題は一種のふるいアプローチに変換されます。数値を最小値から最大値まで反復し、各数値で割り切れる数値のカウントを累積します。 次に、割り算の連鎖を形成できる数値の最大数を追跡します。 洞察としては、数値はその倍数で美しい配列を形成するのに役立つだけであるため、すべてのペアをチェックする必要はなく、各数値の倍数だけをチェックする必要があるということです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n + m log m) | O(m) | 承認済み |

 ここ、$m$配列要素の最大値 ($2 \cdot 10^5$）。 ふるいは、各数値とその倍数を効率的に処理することを保証します。 

## アルゴリズムのチュートリアル

 1. 頻度配列を使用して、配列内の各数値の出現をカウントします。`freq`最大要素までのサイズ$2 \cdot 10^5$。 これにより、各数字が何回出現するかを知ることができます。 
2. を初期化します。`dp`同じサイズの配列、ここで`dp[x]`数字で終わる美しいサブセットの最大サイズを表します`x`。 当初は、`dp[x] = freq[x]`なぜなら、`x`繰り返された`freq[x]`時代は些細なことに美しい。 
3. すべての数値を反復処理する`x`1から`max_val`。 数値ごとに、その倍数を繰り返します`k*x`。 アップデート`dp[k*x] = max(dp[k*x], dp[x] + freq[k*x])`。 これにより、最大チェーン サイズが倍数に沿って伝播されます。 
4. すべての数値を処理した後、次の最大値が得られます。`dp`最大の美しいサブセットに対応します。 削除する要素の最小数は次のとおりです。`n - max(dp)`。 

これが機能する理由は、小さい数から大きい数まで反復し、倍数に沿ってカウントを伝播することにより、可能な限り最大の分割可能なチェーンを効果的に構築しているためです。 各数値は、割り算の要件に違反することなく、その倍数の連鎖に寄与します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    MAX_A = 2 * 10**5
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        freq = [0] * (MAX_A + 1)
        for num in a:
            freq[num] += 1

        dp = freq[:]
        for x in range(1, MAX_A + 1):
            if dp[x] == 0:
                continue
            for k in range(2, (MAX_A // x) + 1):
                dp[k * x] = max(dp[k * x], dp[x] + freq[k * x])
        print(n - max(dp))

if __name__ == "__main__":
    solve()
```最初のセクションでは入力を効率的に読み取ります。`freq`各数値の出現をカウントします。`dp`は各数値のカウントから始まり、その数値のみの些細な美しいサブセットを表します。 ネストされたループは、チェーン サイズを倍数に沿って伝播します。 ついに、`n - max(dp)`必要な除去の数を示します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + m log m) | 周波数のカウントは O(n)、倍数に沿った伝播は高調波系列によりおよそ O(m log m) です。 
| スペース | O(m) | 配列`freq`そして`dp`サイズの最大要素 |

 ## 特殊なケース

 アレイの場合`[3,5,7]`、`freq`それぞれを 1 としてカウントします。`dp[3]=1`、`dp[5]=1`、`dp[7]=1`。 倍数がそれ以上伝播することはありません。 最大の美しいサブセットはサイズ 1、削除 =`3-1=2`。 これは、個別の数値間で割り切れない配列の処理を示しています。 

のために`[2,2,8]`、`dp[2]=2`、`dp[4]=0`、`dp[8]=1`。 伝播元`2`、`dp[4]=2`、`dp[8]=3`。 最大チェーンサイズは3です
