 ## 問題の理解

 私たちには番号が与えられています$n$そして、いくつかの 2020 といくつかの 2021 を合計することで構築できるかどうかを知りたいと考えています。 

私たちが選ぶなら$a$2020年のコピーと$b$2021 のコピーの場合、結果の値は次のようになります。$$2020a + 2021b$$タスクは単に、負でない整数が存在するかどうかを判断することです。$a$そして$b$与えられたものを生み出す$n$。 

入力には最大で次のものが含まれます$10^4$テストケース。 の各値$n$せいぜい$10^6$。 多くのテスト ケースが存在する可能性があるため、クエリごとに本質的に一定時間のアルゴリズムが必要です。 各テスト ケースに対して少数の算術演算のみを実行するアプローチが理想的です。 

いくつかの特殊なケースは見落とされがちです。

## アプローチ

 最も直接的なアプローチはブルートフォースです。 2021 は可能な限りすべての数を試すことができます。 選択するとします$b$2021 年のコピー。残りの値は$$n - 2021b$$その余りが負でなく、2020 年までに割り切れる場合、有効な表現が見つかりました。 

この方法は正しいです。考えられるすべての表現が、次の 1 つの値に正確に対応するからです。$b$, そしてそれらすべてをチェックします。 

問題は効率です。 のために$n = 10^6$、の可能な値の数$b$おおよそです$$\frac{10^6}{2021} \approx 495.$$実際にはこれでもこの問題には十分小さいため、強引な解決策でも問題はありません。 しかし、質問全体をいくつかの算術演算に集約する、より明確な観察があります。 

式を書き換えます。$$n = 2020a + 2021b$$以来$2021 = 2020 + 1$、$$n = 2020a + (2020+1)b$$

$$n = 2020(a+b) + b$$させて$$k = a+b.$$それから$$n = 2020k + b.$$分割するとき$n$2020年までに：$$n = 2020 \left\lfloor \frac{n}{2020} \right\rfloor + (n \bmod 2020).$$以前の形式と比較すると、次のことがわかります。$b$剰余と等しくなければなりません。 

残りは固定です:$$b = n \bmod 2020.$$商は次のとおりです。$$k = \left\lfloor \frac{n}{2020} \right\rfloor.$$以来$a = k-b$、必要です$$k \ge b.$$商と余りを代入すると、非常に単純な条件が得られます。$$\left\lfloor \frac{n}{2020} \right\rfloor \ge n \bmod 2020.$$この不等式が成り立つ場合、答えはYESです。 それ以外の場合、答えは「NO」です。

 ## アルゴリズムのチュートリアル

 1. 値を読み取る$n$。 
2. 商を計算します。$$q = n // 2020$$これは、可能な最大値を表します。$a+b$。 
3. 剰余を計算します。$$r = n \% 2020$$有効な表現はすべて正確に使用する必要があります$r$2021年のコピー。 
4. かどうかを確認します。$$q \ge r.$$それが本当なら、私たちは選択できます$b=r$そして$a=q-r$、両方とも非負です。 
5. 出力`"YES"`不等式が成立する場合、そうでない場合は出力`"NO"`。 

### なぜ効果があるのか

 すべての表現は次のように書くことができます$$n = 2020(a+b) + b.$$2020 年で除算した余りは一意に決定されるため、有効な表現には次の条件が必要です。$$b = n \bmod 2020.$$商は与える$$a+b = n // 2020.$$有効な解決策としては、$a$負でない値でなければなりません:$$a = (n // 2020) - (n \bmod 2020) \ge 0.$$この条件は必要かつ十分です。 それが成り立つ場合、明示的に構築できます。$a$そして$b$。 失敗した場合、否定的でない選択はできません。$a$存在します。 したがって、アルゴリズムは正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        q = n // 2020
        r = n % 2020

        if q >= r:
            ans.append("YES")
        else:
            ans.append("NO")

    sys.stdout.write("\n".join(ans))

solve()
```実装は数学的導出に直接従います。 

商`q`は、2021 年ごとに 2020 年に 1 を加えたものとみなした場合の用語の合計数を表します。`r`は、追加の 1 が何個必要かを表します。これは、まさに 2021 の数です。 

検証する唯一の条件は、それらを考慮するのに十分な合計期間が存在するかどうかです。`r`2021 年のコピー。まさに小切手です。`q >= r`。 

の最大値であるため、オーバーフローの懸念はありません。`n`だけです$10^6$、Python の整数制限をはるかに下回っています。 この実装では、各テスト ケースに対して、整数の除算、モジュロ、および比較のみが実行されます。
