 ## 解決策
 ## 問題の理解

 と呼ばれる、同じサイズの 2 つの正方バイナリ行列が与えられます。`a`そして`b`。 各要素は 0 または 1 です。許可される操作は、行全体を反転するか、列全体を反転することです。反転とは、各要素と 1 の XOR 演算を意味します。私たちのタスクは、変換が可能かどうかを判断することです。`a`の中へ`b`これらの行と列の反転のシーケンスを使用します。 

入力では複数のテスト ケースを指定し、それぞれが行列のサイズと 2 つの行列自体を指定します。 行列を等しくする一連の反転が存在する場合、出力は「YES」、それ以外の場合は「NO」になります。 

アルゴリズム設計を推進する主な制約は次のとおりです。`n`最大 1000 まで指定でき、合計は`n`すべてのテスト ケースで 1000 を超えません。これは、1000^3 = 10^9 の演算であるため、O(n^3) のブルート フォース ソリューションでは遅すぎることを意味します。 O(n^2) アプローチは、合計サイズがおよそ 10^6 要素までの行列を数秒で処理できるため、実現可能です。 

微妙なエッジ ケースは、行列のサイズが 1x1 または 2x2 の場合です。 たとえば、単一要素行列はその行で 1 回、列で 1 回しか反転できないため、ソリューションがパリティを正しく考慮していることを確認する必要があります。 もう 1 つの注意が必要なケースは、行と列を交互に反転する必要がある場合です。 すべてを貪欲に反転する単純なアプローチでは、不可能な中間状態が生成され、誤って「NO」と結論付けられる可能性があります。 

## アプローチ

 最も簡単な方法は、行と列の反転の可能なシーケンスをすべて試すことですが、行については 2^n 通り、列については 2^n 通りの反転が可能です。 すべての組み合わせを試すと、O(2^(2n) * n^2) の演算が行われ、n ≥ 20 の場合は指数関数的に遅くなります。理論的には、各フリップでセルが変更されるか変更されないため、このブルートフォースは機能し、すべての構成に到達可能ですが、実際には大きな行列では失敗します。 

重要な洞察は、行と列の反転の違いを考慮することで、行と列の反転の効果を捉えることができることに気づくことです。`a`そして`b`。 特定のセル (i, j) について、いくつかの反転の後、その最終値は次のようになります。`a[i][j] XOR row_flip[i] XOR col_flip[j]`。 この方程式は次と等しくなければなりません`b[i][j]`。 同様に、各セルについては次のようになります。```
row_flip[i] XOR col_flip[j] = a[i][j] XOR b[i][j]
```最初の行の反転を任意に選択すると、列の反転は一意に決定されます。 次に、残りの行の反転は同じ XOR 式を満たす必要があります。 そうすれば、変換は可能です。 これにより、問題は O(n^2) で実行できる XOR 方程式系の整合性チェックに集約されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(2n) * n^2) | O(n^2) | 遅すぎる |
 | XOR パリティ / 建設的 | O(n^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 新しい行列を計算する`d`どこ`d[i][j] = a[i][j] XOR b[i][j]`。 各エントリは次のことを表します。`a[i][j]`一致させるには奇数回反転する必要があります`b[i][j]`。 これにより、問題が行列演算から XOR 制約のシステムに変換されます。 
2. 最初の行の反転を任意に決定します。たとえば、次のようにします。`row_flip[0] = 0`。 次に、各列ごとに、`j`、必要な列反転は次のように計算できます。`col_flip[j] = d[0][j] XOR row_flip[0]`。 
3. For each remaining row`i > 0`、最初の列を比較して、必要な行反転を計算します。`row_flip[i] = d[i][0] XOR col_flip[0]`。 これにより、各行の最初の列がターゲットと一致することが保証されます。 
4. 他のすべてのエントリが XOR 条件を満たしていることを確認します。`row_flip[i] XOR col_flip[j] == d[i][j]`。 この方程式に違反するセルがある場合、システムは矛盾しており、答えは「NO」です。 
5. すべてのセルが方程式を満たす場合、一連の反転が存在し、答えは「YES」になります。 

機能する理由: 最初の行と最初の列の反転が選択されると、残りの反転が決定されます。 XOR システムは、すべてのセルが一貫しているかどうかを保証します。 このアプローチでは、フリップのすべてのシーケンスを明示的に試行する必要がなく、すべての一貫性制約がチェックされます。 の恣意的な選択`row_flip[0]`最初の行の反転は常に列の反転と組み合わせることができるため、機能します。 解決策が存在する場合、それは次のいずれかの選択で発見されます。`row_flip[0]`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = [list(map(int, list(input().strip()))) for _ in range(n)]
        input()  # skip empty line
        b = [list(map(int, list(input().strip()))) for _ in range(n)]
        
        # compute difference matrix
        d = [[a[i][j] ^ b[i][j] for j in range(n)] for i in range(n)]
        
        # assume first row flip = 0
        row_flip = [0] * n
        col_flip = [d[0][j] for j in range(n)]
        
        possible = True
        for i in range(1, n):
            row_flip[i] = d[i][0] ^ col_flip[0]
            for j in range(1, n):
                if row_flip[i] ^ col_flip[j] != d[i][j]:
                    possible = False
                    break
            if not possible:
                break
        print("YES" if possible else "NO")

if __name__ == "__main__":
    solve()
```コードはまず行列を読み取り、その XOR 差を計算し、行と列の反転配列を初期化します。 最初の行をゼロに設定し、列反転を直接導出します。 次に、残りの行が XOR 制約に対してチェックされます。 矛盾が見つかった場合、答えは「いいえ」です。 それ以外の場合は「YES」です。 行列間の空行をスキップすると、入力読み取りのずれが回避されます。 リスト内包表記を使用すると、行列の差が効率的に計算されます。
