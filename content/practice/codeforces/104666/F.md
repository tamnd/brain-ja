 ## 解決策
 ## 問題の理解

 以下の範囲のすべての整数を調べます。$N$に$M$。 各整数について$x$この範囲では、その「変動性」を分割方法の数として定義します。$x$すべてのトラックが同じ数のアイテムを運び、すべてのアイテムが使用されるように、同一のアイテムを同一のトラックの隊列に輸送します。 

有効な輸送隊は、使用されるトラックの数によってのみ決まります。 私たちが選ぶなら$k$トラックの場合、各トラックは正確に荷物を運ぶ必要があります$x/k$アイテムなので、これは次の場合にのみ可能です$k$分割する$x$。 したがって、の変動性は、$x$はまさに次の正の約数の数です$x$、一般的には次のように表されます$d(x)$。 

タスクは合計を計算することです$$\sum_{x=N}^{M} d(x)$$どこ$N, M$と同じ大きさにすることができます$10^{12}$したがって、すべての数値を反復処理することは不可能です。 

この制約は、間隔内の整数ごとの処理に依存するアルゴリズムは、間隔の長さ自体が長さに達する可能性があるため、最悪の場合には直ちに遅すぎることを意味します。$10^{12}$。 平$O(\sqrt{x})$数字ごとには不可能です。 

主なエッジケースは次のような場合です$N = M$ここで、潜在的に大きな単一の数の約数を計算する必要があります。 もう一つは、いつ$N = 1$、すべての整数が少なくとも 1 つの約数に寄与し、累積が急速に増加するためです。 

すべてをループする素朴なアプローチ$x$約数を数えます$\sqrt{x}$について演奏するだろう$$O((M-N+1)\sqrt{M})$$限界をはるかに超えた操作。 

## アプローチ

 ブルートフォースのアイデアは簡単です: 各数値に対して$x$範囲内で、次の値までのすべての候補をチェックして、それを整数で割る数を計算します。$\sqrt{x}$。 すべての約数のペアがその範囲内にあるため、これは正しいです。 ただし、範囲サイズに制限がなく、範囲サイズに達する可能性があるため、これは機能しません。$10^{12}$、数値を反復処理することさえ不可能になります。 

別の視点が必要です。 直す代わりに$x$そしてその約数を数えると、視点が逆転します。潜在的な約数を修正します。$d$、 にある数字がいくつあるか数えます。$[N, M]$で割り切れます$d$。 毎回$d$数値を割る$x$、それはちょうど 1 に貢献します$d(x)$。 したがって、各ペア$(x, d)$と$d \mid x$最終回答に 1 回貢献します。 

これにより合計が交換されます。$$\sum_{x=N}^{M} d(x) = \sum_{d \ge 1} \#\{x \in [N,M] : d \mid x\}$$これで、内部項はフロア除算を使用して簡単に計算できます。$$\# = \left\lfloor \frac{M}{d} \right\rfloor - \left\lfloor \frac{N-1}{d} \right\rfloor$$残っている唯一の問題は、すべてを合計すると、$d$まで$M$まだ大きすぎます。 重要な観察は、商関数が$\lfloor M/d \rfloor$の区間にわたって区分的に一定です$d$。 1 つずつ繰り返すのではなく、商が固定される範囲を飛び越えます。 これにより、異なる値の数が減少します。$\lfloor M/d \rfloor$くらいまで$O(\sqrt{M})$、同様に$\lfloor (N-1)/d \rfloor$。 

これらの範囲を処理し、ブロックに寄与を蓄積します。

 ## アルゴリズムのチュートリアル

 フロア分割の結果が一定になるグループ化された間隔で除数の値をスキャンすることにより、合計を計算します。 

1. 答えを 0 として初期化します。考えられるすべての約数からの寄与を累積します。 
2. ポインタを設定する$d = 1$。 これは、評価している現在の約数を表します。 
3. その間$d \le M$、値を計算します$$a = \left\lfloor \frac{M}{d} \right\rfloor, \quad b = \left\lfloor \frac{N-1}{d} \right\rfloor$$これらは何倍かを表します$d$寝そべる$[1,M]$そして$[1,N-1]$。 
4. この正確な貢献$d$は$a - b$。 答えに追加してください。 これは、範囲内で割り切れる数値がいくつあるかを数えます。$d$。 
5. の最大範囲を決定します。$d$どちらも$a$そして$b$変わらないまま。 これは、次のブレークポイントを計算することによって行われます。$$d' = \min\left(\frac{M}{a}, \frac{N-1}{b} \text{ (if } b > 0)\right)$$私たちはそこから安全に飛び降りることができます$d$に$d'$すべての中間約数が寄与構造において同一に動作するためです。 
6.セット$d = d' + 1$そして繰り返します。 

各ジャンプは、同じように寄与する除数値の完全な間隔をスキップし、線形反復を回避します。 

### なぜ効果があるのか

 約数関係が発生するたびに$(d \mid x)$除数の処理時に 1 回だけカウントされます$d$。 定数の下限値によるグループ化により、範囲全体で同一の乗法構造を生成するすべての約数が、省略や重複なくまとめられることが保証されます。 分解により、2 次元の計数問題が、除数の寄与に対する 1 次元のスイープに変換されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, M = map(int, input().split())
    
    def count_leq(x, d):
        return x // d

    ans = 0
    d = 1

    while d <= M:
        q1 = M // d
        q2 = (N - 1) // d

        # find next d where M//d or (N-1)//d changes
        if q1 == 0:
            r1 = M
        else:
            r1 = M // q1

        if q2 == 0:
            r2 = M
        else:
            r2 = (N - 1) // q2 if N > 1 else M

        nd = min(r1, r2)

        ans += (q1 - q2) * (nd - d + 1)

        d = nd + 1

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、実行中の除数インデックスが維持され、商の値が一定である範囲が圧縮されます。 重要な詳細は、両方の次のブレークポイントを計算することです。$M // d$そして$(N-1) // d$、貢献行動の変化を見逃さないようにします。 

注意が必要です$N = 1$、 どこ$N-1 = 0$、フロア分割の動作が異なるためです。 コードは 2 番目のブレークポイントを保護することでこれを暗黙的に処理します。

def run(inp: str) -> str:

def solve_capture(inp: str) -> str:
    import sys
    from io import StringIO
    backup = sys.stdin
    sys.stdin = StringIO(inp)

    N, M = map(int, sys.stdin.readline().split())

    ans = 0
    d = 1

    while d <= M:
        q1 = M // d
        q2 = (N - 1) // d

        r1 = M // q1 if q1 else M
        if N > 1:
            q2v = (N - 1) // d

        ans += (q1 - q2) * (nd - d + 1)
        d = nd + 1

    sys.stdin = backup
    return str(ans)

 ## 特殊なケース

 いつ$N = 1$、 用語$(N-1)$がゼロになるため、すべての約数が寄与します$\lfloor M/d \rfloor$。 アルゴリズムはこれを処理します。整数除算は任意の値で行われるためです。$d$は第 2 項に 0 を与えるため、寄与は の倍数を数えることに正しく還元されます。$[1, M]$。 

いつ$N = M$、ループは単一の数値の除数関数を効果的に計算します。 このアルゴリズムは範囲の長さに依存せず、依然として約$\sqrt{N}$divisor ブロック、すべての寄与を正しく合計します。 

いつ$M$は非常に大きいですが、約数がほとんどありません。このアルゴリズムは、数値ではなく除数ブロックを反復処理するため、効率的に実行されます。また、フロア除算の構造により、寄与が見逃されることはありません。
