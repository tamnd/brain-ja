 ## 解決策
 ## 問題の理解

 ゲームは、チョコレート バーのように動作する大きな長方形のグリッド上でプレイされます。 一部の細胞が汚染されています。 2 人のプレーヤーは、現在残っている長方形をグリッド線に沿って繰り返し切り取り、切り取りの一方の側を破棄し、もう一方の側を新しいアクティブ領域として保持します。 重要なルールは、プレイヤーが汚染された細胞を少なくとも 1 つ含むピースを食べた場合、そのプレイヤーは即座に負けになるということです。 

移動は、現在の長方形の辺を選択し、その辺からカット ラインを数えることによって指定されます。 たとえば、「上部 X」のような移動は、現在の長方形の上部境界から X 番目の行の後で水平にカットし、下部を残して上部を破棄することを意味します。 同様に、「左 X」は、垂直にカットして左側の部分を破棄することを意味します。 

ゲームの観点から見ると、各移動は現在の長方形を軸に沿った小さな長方形に縮小します。唯一の禁止された結果は、解釈に応じて破棄または保持されたピースに汚染されたセルが含まれることです。 この問題では、プレイヤーが汚染されたマスを食べると負けになることが明示されているため、すべての動きで、食べた部分に汚染された細胞が含まれていないことを確認する必要があります。 

入力により、最大 100,000 x 100,000 の完全な初期グリッド サイズが得られますが、汚染されたセルは最大 100 個のみです。 それぞれの動きの後に、私たちは相手の動きや端末の「ヤッ！」をインタラクティブに受け取ります。 彼らが負けたことを示しています。 

この制約は、完全なグリッドをシミュレートできないことを直ちに意味します。 どのような解決策も、汚染された細胞の位置のみに依存する必要があります。 K は最大でも 100 であるため、カットまたはバウンドの合法性について推論するには、これらの点のみを考慮する必要があります。 

単純なアプローチでは、現在の四角形を維持し、すべての可能なカットに対してすべての汚染されたセルをスキャンして、破棄された領域に汚染されたセルが含まれているかどうかを確認します。 移動方向ごとに最大 10^5 の可能なカット位置と最大 100 個の汚染セルがあるため、これは移動ごとに 10^7 チェックとなり、これはすでに厳しいものであり、インタラクティブ シーケンス全体で簡単に制限を超える可能性があります。 

保持された領域内の汚染されたセルを即座に分離しない限り、どの切断も安全であると仮定すると、より微妙な故障モードが表示されます。 これは誤りです。なぜなら、重要なのは食べられた領域であり、方向に応じて、どちら側が食べられたかの解釈を一貫して処理する必要があるからです。 これを誤解すると、たとえ保持された四角形が安全であっても、無効な移動が発生します。 

もう 1 つのエッジ ケースは、すべての汚染されたセルが境界線上にある場合です。 不注意な戦略ではその線上で正確にカットしようとする可能性がありますが、ルールではグリッド線ではなく正方形をカウントするため、インデックスの位置がずれていると安全領域が 1 単位ずつ誤ってシフトし、汚染されたセルが誤って含まれてしまう可能性があります。 

## アプローチ

 重要な観察は、ゲームの状態が、残っているすべての汚染されたセルを含む軸に沿った最小の長方形によって完全に決定されるということです。 現在の四角形がわかったら、有効な移動では、破棄された部分に汚染されたセルが含まれていないことを確認しながら、その四角形を縮小する必要があります。 

これは、唯一の意味のある制約が、長方形内で現在まだ「生きている」汚染されたセルの極端な位置から来ていることを直ちに示唆しています。 具体的には、汚染されたセルの行インデックスと列インデックスの最小値と最大値のみを考慮します。 現在の安全な四角形は常にこれらの極端な境界線に囲まれています。これは、より大きな拡張には、ゲームがより早く終了するはずだった領域に汚染されたセルがすでに含まれていることになるためです。 

したがって、ゲームは汚染されたセットの周囲に縮小する境界ボックスを維持することになります。 各移動は、食べられる部分に汚染された細胞がまだ含まれている領域を切断することを避けながら、この境界ボックスを縮小する必要があります。

重要な考え方は、対戦相手も有効な動きを強制されるため、境界ボックスは常に制御された方法で縮小するということです。 勝利の戦略は、汚染されたセルの境界ボックスの片側に常に隣接してカットし、相手が強制的に負けるまで安全なストリップを効果的に剥がすことです。 

ブルートフォースアプローチでは、各方向の考えられるすべてのカットラインについて、すべての K 点をスキャンすることによって、除去される側に汚染されたセルが含まれているかどうかをテストします。 これは正しいですが、インタラクション下では遅すぎます。 

代わりに、汚染されたセルの 4 つの極値座標 (最小行、最大行、最小列、最大列) を事前計算します。 すべての有効な動きは、これらの極端な領域の 1 つのすぐ外側をカットすることで選択でき、安全な領域のみを確実に削除します。 

これにより、各移動が O(1) 推論に削減されます。つまり、最も近い危険な境界がどこにあるかが常にわかります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | カット チェックごとに O(K)、潜在的に O(K * 移動) | O(K) | 遅すぎる |
 | 最適 | O(K) 前処理、移動ごとに O(1) | O(K) | 承認済み |

 ## アルゴリズムのチュートリアル

 上、下、左、右の 4 つの値を使用して、すべての汚染されたセルの境界四角形を維持します。 

1. すべての汚染されたセル座標を読み取り、最小行、最大行、最小列、および最大列を計算します。 これらは、合法性にとって重要な唯一の地域を定義します。 
2. 現在アクティブな四角形を完全なグリッドとして初期化します。 
3. 先攻か後攻かを決めます。 2番目を選択した場合は、すぐに「パス」を出力し、相手の最初の動きを待ちます。 
4. 各ターンで、現在アクティブな四角形を確認し、汚染された境界ボックスと比較します。 
5. 最も上の汚染された行の上に安全なスペースがある場合は、移動「top X」を発行します。ここで、X は現在の上部境界から汚染された領域が始まる直前までの距離です。 これにより、安全な行のみが削除されます。 
6. それ以外の場合、最も下の汚染された行の下に安全なスペースがある場合は、対称的に「bottom X」を発行します。 
7. それ以外の場合は、「left」と「right」を使用して列に対して同じロジックを実行します。 
8. 各移動の後、それに応じてアクティブな四角形を更新し、対戦相手が負けるまで続けます。 

重要な理由は、汚染された細胞が含まれていないことが保証されている領域を常にカットするということです。 汚染された領域は固定されているため、カットするたびに、触れることなく周囲の安全なパッドが減少します。 

### なぜ効果があるのか

 不変条件は、アクティブな四角形が常にすべての汚染されたセルの境界ボックスを完全に含み、移動するたびにこの境界ボックスの外側にあるストリップを完全に削除することです。 どのような操作を行っても汚染されたセルを含む領域が削除されることはないため、合法性は保たれます。 最終的に、アクティブな長方形は境界ボックス上に正確に崩壊します。その時点で、対戦相手がさらに強制的に移動すると、必然的に汚染されたセルが食べられることになり、ゲームはこちらに有利に終了します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def flush():
    sys.stdout.flush()

def move(cmd):
    print(cmd)
    flush()

R, C, K = map(int, input().split())

top = R
bottom = 1
left = C
right = 1

for _ in range(K):
    a, b = map(int, input().split())
    top = min(top, a)
    bottom = max(bottom, a)
    left = min(left, b)
    right = max(right, b)

started = False

def shrink():
    global top, bottom, left, right

    # try top
    if top > 1:
        x = top - 1
        move(f"top {x}")
        top = 1
        return True

    # try bottom
    if bottom < R:
        x = R - bottom
        move(f"bottom {x}")
        bottom = R
        return True

    # try left
    if left > 1:
        x = left - 1
        move(f"left {x}")
        left = 1
        return True

    # try right
    if right < C:
        x = C - right
        move(f"right {x}")
        right = C
        return True

    return False

# we can just play first; if we want second, print pass
# here we choose first for simplicity
# (interactive strategy does not depend on opponent)
# If required, one could read first opponent move instead.

# main loop
while True:
    if not shrink():
        break
    line = input().strip()
    if line == "yuck!":
        break
```このコードは、汚染されたセルの境界ボックスを維持し、外側から安全なストリップを繰り返し削除します。 それぞれの動きは、どちらの側に取り外し可能な安全なスペースが残っているかを確認することによって決定的に選択されます。 インタラクティブな問題では、ジャッジがコマンドをすぐに受け取ることができるように、各手の後のフラッシングが不可欠です。 

微妙な実装の詳細は、長方形の更新では、汚染された領域の境界まで安全なストリップ全体が常に切り取られることを前提としていることです。 これにより、不変条件が単純に保たれます。移動するたびに、アクティブな四角形の少なくとも 1 つの境界が汚染された境界ボックスと揃います。 

## 実用的な例

 ### サンプル 1

 4 × 6 のグリッドと (2,3) と (4,4) の汚染されたセルから始めます。 境界ボックスは上=2、下=4、左=3、右=4です。 

| ステップ | アクション | トップ | 下 | 左 | 右 |
 | --- | --- | --- | --- | --- | --- |
 | 0 | イニシャル | 2 | 4 | 3 | 4 |
 | 1 | カットトップ1 | 1 | 4 | 3 | 4 |
 | 2 | 相手の動き | 1 | 4 | 3 | 4 |
 | 3 | 左をカット 2 | 1 | 4 | 1 | 4 |

 このトレースは、最初に安全な上部のストリップを削除し、次に安全な左側のストリップを削除して対戦相手に応答し、汚染された領域に向かって長方形を徐々に折りたたむことを示しています。 

### サンプル 2

 初期グリッドは 3 x 5 で、(2,3) に汚染されたセルが 1 つあるため、境界は上 = 2、下 = 2、左 = 3、右 = 3 になります。 

| ステップ | アクション | トップ | 下 | 左 | 右 |
 | --- | --- | --- | --- | --- | --- |
 | 0 | イニシャル | 2 | 2 | 3 | 3 |
 | 1 | 相手の動き | 2 | 2 | 3 | 3 |
 | 2 | 右にカット 2 | 2 | 2 | 3 | 5 |
 | 3 | 底部をカット 1 | 2 | 3 | 3 | 5 |

 このケースは、境界ボックスがすでにタイトな場合、境界に合わせたカットのみが可能であり、安全領域に拡張しようとすると即時に崩壊することを示しています。

 ## 特殊なケース

 (1,1) などのコーナーに位置する汚染されたセルでは、すべての安全なカットが反対側のみで発生するように強制されます。 境界ボックスが角まですぐに折りたたまれ、両側に安全なストリップが残らないため、アルゴリズムはこれを処理します。 

すべての汚染されたセルが単一の行、たとえば行 50 にある場合、上部と下部の境界は同一になります。 その後、アルゴリズムは左右のカットのみを実行し、汚染された行に触れる危険がある水平方向の移動を正しく回避します。 

汚染された細胞が垂直線を形成する場合、同じ対称性が適用され、動きは水平方向の縮小のみに制限されます。 すべてのカットが安全なストリップのみを削除するという不変条件により、これらの縮退構成でも無効な動きが決して生成されないことが保証されます。
