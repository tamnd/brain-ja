 ## 解決策
 ## 問題の理解

 2 人のキャラクターが一定数の同一のハニー ポットを共有するシステムが与えられています。 最初は、ポットは両者の間でランダムに分割されますが、両側が少なくとも 1 つのポットを受け取る分割のみが許可されます。 ポットは区別できないため、重要なのはプーさんが持っているポットの数だけです。これは 1 から 1 までの任意の値です。$n-1$、それぞれ同じ確率です。 

最初の分割の後、システムは個別のラウンドで進化します。 各ラウンドでは、3 つのうちの 1 つが起こる可能性があります。 確率で$p$、ポットが 1 つプーさんからヘファランプに移動し、プーさんのカウントが 1 つ減ります。 確率で$q$、ポットが 1 つヘファランプからプーさんに移動し、プーさんのカウントが 1 つ増えます。 確率で$r$、何も変わりません。 プーさんがポット 0 に達した場合、または$n$ポットの場合、プロセスは永久に停止します。 

タスクは固定ラウンド数を考慮することです$i$、そして 2 つの条件が同時に成立する確率を計算します。 まず、プロセスはまだ吸収されておらず、どちらの側もポットがゼロに達していないことを意味します。 次に、後の構成$i$ラウンドは初期設定とまったく同じです。 

制約は十分に小さいため、状態空間は本質的に線形になります。$n$、 以来$n \le 26$ただし、ステップ数は 1600 に達する可能性があります。これは、テスト ケースごとの 2 次または 3 次動的計画法のソリューションは許容できるが、時間の経過や状態の経過に伴う指数関数的なものは許容できないことをすぐに示唆しています。 

微妙な点は、答えが最初のランダムな分割に依存することです。 私たちは単一の開始状態を追跡するのではなく、プーさんのポット カウントのすべての可能な開始値の平均を追跡します。 もう 1 つの重要な制約は吸収規則です。 0 または$n$たとえ後で概念的に同じ構成に戻ったとしても、完全に除外する必要があります。 

単純な間違いは、吸収を無視し、これを整数上の無制限のランダム ウォークとして扱うことです。 これにより、境界を越えるパスが誤ってカウントされてしまいます。 もう 1 つの間違いは、異なる開始位置からの遷移を混合することで状態を誤って平均化してしまうことです。これは、一致する構成だけでなく、同じ初期構成に戻るという要件を破っています。 

## アプローチ

 直接的な総当たりアプローチでは、考えられるすべてのシーケンスをシミュレートします。$i$可能な各初期分割から始まるラウンド。 各ラウンドは 3 つの結果に分岐します。$i$ステップがあります$3^i$開始状態ごとに考えられる履歴。 中程度の場合でも$i$、これは実行不可能になります。$3^{1600}$天文学的に大きいです。 吸収による無効な状態を枝刈りしても、これを実行可能にするほど分岐係数は減少しません。 

重要な観察は、システムが次の整数値から構成される小さな状態空間にわたるマルコフ連鎖であるということです。$1$に$n-1$、吸収境界は次のとおりです。$0$そして$n$。 次の状態になる確率$t$ステップは、完全な履歴ではなく、前のステップのみに依存します。 これにより、時間の経過とともに指数列挙を動的プログラミングに置き換えることができます。 

ただし、2 番目の構造層も必要です。 この条件では元の状態に戻る必要があるため、元の状態に戻ると単純に分布を計算することはできません。$i$混合初期分布からのステップ。 考えられる開始状態ごとに遷移を個別に追跡し、均一な初期分布に従って結果を結合する必要があります。 

これにより、各開始値に対してクリーンな定式化が得られます。$s$で始まる制約付きランダム ウォークが実行される確率を計算します。$s$またまたです$s$後$i$限界にぶつからずにステップを進めます。 これは州と時間に関する標準的な DP です。$n$が小さいため、起動ごとに独立して実行すると効率が維持されます。

 ## アルゴリズムのチュートリアル

 このプロセスを状態のランダム ウォークとして解釈します$1$を通して$n-1$、ここでの状態$x$プーさんが持っているという意味$x$鍋。 

1. 考えられる各開始状態について$s$、DP 配列を初期化します。$dp[s] = 1$。 これは、プロセスが構成で開始されることが確実であることを表します。$s$、遷移が発生する前に。 
2. 時間の経過とともにステップを繰り返します。$1$に$k$、各ステップで新しい DP 配列を更新します。 各遷移は、ラウンドの 3 つの可能な結果に従って確率質量を分配します。 
3. 状態から$x$、システムは次の場所に移動できます。$x-1$確率的に$p$、 に$x+1$確率的に$q$、またはに滞在$x$確率的に$r$。 これらの更新は、結果の状態が以下の範囲内に留まる場合にのみ適用されます。$[1, n-1]$。 
4. 次へ移行するあらゆる移行$0$または$n$は廃棄されます。 これは吸収に相当し、これらのパスは将来の状態には寄与しません。 
5.完了後$i$ステップ、記録$dp[s]$、これは次の確率を表します。$s$に戻ると、システムは次の状態に戻ります。$s$吸収なしで。 
6. すべての開始状態に対してこれを繰り返します。$s \in [1, n-1]$、初期構成はこれらの状態にわたって一様にランダムであるため、結果を平均します。 

### なぜ効果があるのか

 DP 状態は、位置と生存の両方を暗黙的にエンコードします。 テーブル内のすべての確率質量は、吸収されていない有効なパスに対応します。 遷移は段階的に適用され、吸収された状態が再導入されることはないため、無効な軌道がシステムに再入力されることはありません。 確率の線形性により、独立した開始状態を合計して平均することで、元のランダムな初期化と正確に一致することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())
        p, q, r = map(float, input().split())
        k = int(input())

        m = n - 1
        inv_m = 1.0 / m

        answers = [0.0] * k

        for s in range(1, n):
            dp = [0.0] * n
            dp[s] = 1.0

            for t in range(k):
                ndp = [0.0] * n

                for x in range(1, n):
                    val = dp[x]
                    if val == 0:
                        continue

                    ndp[x] += val * r

                    if x - 1 >= 1:
                        ndp[x - 1] += val * p

                    if x + 1 <= n - 1:
                        ndp[x + 1] += val * q

                dp = ndp
                answers[t] += dp[s] * inv_m

        for v in answers:
            print(f"{v:.6e}")

if __name__ == "__main__":
    solve()
```このソリューションでは、考えられる初期分割ごとに個別の確率展開を構築します。 DP 配列は、吸収境界に達していないことを条件とした、各ラウンド後のプーさんのポット カウントの分布を表します。 

内部移行ステップでは、考えられる 3 つの結果が直接適用されます。 境界チェックにより、状態への遷移が保証されます。$0$または$n$は完全に無視され、これらの状態に到達するとゲームが直ちに終了するというルールに一致します。 

各時間ステップは、その特定の初期値の開始状態に戻る確率に寄与します。 これらの貢献を累積し、次で割ります。$n-1$最後に平均化によって暗黙的に行われます。 

出力の書式設定では、必要な精度の制約に一致するように科学表記法が使用されます。

開始状態ごとに、時間の経過とともに確率質量がどのように進化するかを追跡します。 以下の表は、平均化する前に、各ステップ数後に同じ状態に戻る確率を示しています。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、移動確率によって質量が直接吸収状態に移行する場合です。 たとえば、$n = 3$、状態から開始$1$、状態を減少させる遷移は直ちにゲームを終了します。 DP は、トランジションを追加する前に境界をチェックすることで、このマスを正しく破棄します。 

もう 1 つのエッジケースは次のような場合です$r$は 1 に非常に近いです。この状況では、ほとんどの確率質量は所定の位置に留まり、数値の安定性は組み合わせ構造よりも重要です。 確率は減算せずに段階的に累積されるため、DP は安定しています。 

最後のケースは次のような場合です。$k = 1$。 ここで、答えは単純に、すべての開始を平均した、1 ステップ後に同じ状態に留まる確率です。 DP は単一の遷移層に縮小され、より深い履歴は関与しません。
