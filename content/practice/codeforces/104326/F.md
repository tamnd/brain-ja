 ## アルゴリズムのチュートリアル

 1. すべての素因数を削除します$x$それも分ける$b$。 これは繰り返し計算することで行われます$\gcd(x, b)$そして分割$x$共通因数がなくなるまでそれを計算します。 このステップでは、繰り返しサイクルに寄与する可能性のある分母の部分を分離します。 
2. しましょう$x'$このようなすべての削減後の残りの値になります。 削除された要素の数によって、非周期プレフィックスの長さが決まります。 それぞれの削除は、基数の 1 桁のステップに対応します。$b$繰り返しの前にキャンセルが発生する分割プロセスが安定する可能性があります。 
3. もし$x' = 1$、分数は底で有限になります$b$、したがって、繰り返しサイクルはありません。 周期の長さはゼロです。

### なぜ効果があるのか

 ベースの各ステップで、$b$展開すると、余りが乗算されます。$b$そして、現在の実効分母を法として減少させます。 間の共有要素$b$そして分母はすぐに崩壊し、実効弾性率が低下します。 このような要素がすべて削除されると、残りのシステムは乗法群モジュロで動作します。$x'$ここで、すべての状態は反転可能であり、剰余のシーケンスは最終的に次数の乗法に等しい周期で繰り返される必要があります。$b$。 これにより、プロセスが、因子のキャンセルによって生じる有限のプレフィックスと純粋な循環剰余プロセスにきれいに分割されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from math import gcd

def factorize(n):
    f = {}
    d = 2
    while d * d <= n:
        while n % d == 0:
            f[d] = f.get(d, 0) + 1
            n //= d
        d += 1
    if n > 1:
        f[n] = f.get(n, 0) + 1
    return f

def remove_common_factors(x, b):
    g = gcd(x, b)
    prefix = 0
    while g != 1:
        while x % g == 0:
            x //= g
            prefix += 1
        g = gcd(x, b)
    return x, prefix

def mod_pow(a, e, mod):
    r = 1
    a %= mod
    while e:
        if e & 1:
            r = (r * a) % mod
        a = (a * a) % mod
        e >>= 1
    return r

def multiplicative_order(b, mod):
    phi = mod
    factors = factorize(phi)
    for p in factors:
        phi -= phi // p

    order = phi
    for p in factorize(order):
        while order % p == 0 and mod_pow(b, order // p, mod) == 1:
            order //= p
    return order

def solve():
    x, b = map(int, input().split())
    x, prefix = remove_common_factors(x, b)

    if x == 1:
        print(prefix, 0)
        return

    # ensure gcd(b, x) = 1
    g = gcd(b, x)
    if g != 1:
        x //= g

    period = multiplicative_order(b, x)
    print(prefix, period)

if __name__ == "__main__":
    solve()
```機能`remove_common_factors`分母が底と素数を共有する長い除算の部分をシミュレートします。 共通の gcd が見つかるたびに、それらの要素が分母から取り除かれ、プレフィックスが繰り返されないことになります。 

削減された分母が得られたら、`multiplicative_order`サイクル長を計算します。 まず、素因数分解を使用して係数のオイラー和を計算し、次に候補次数の約数をテストしてそれを削減します。 高速累乗は次の累乗かどうかをチェックします。$b$減らされた分母を 1 を法として折りたたまれます。 

微妙な点は、プレフィックスが gcd 呼び出しだけでなく、因子の削除に関してもカウントされることです。 共有素因​​数による各除算は、基数展開における 1 桁のシフトに対応します。

 ## 特殊なケース

 基底との共有因子を除去した後に分母が 1 になる場合、微妙なエッジ ケースが発生します。 のような入力の場合`12 10`、gcd の削除を繰り返すと、2 と 3 の両方が 10 を割るため、12 が 1 に減ります。アルゴリズムは、終了前にプレフィックスの 1 ステップを正確にカウントし、次の結果を生成します。`1 0`。 

もう 1 つのケースは、基底が最初から分母とすでに互いに素である場合です。 のために`7 10`、プレフィックスの削除は行われず、全体の動作は 10 を法とする 7 の乗算次数によって決定されます。アルゴリズムは、不必要な削減を行わずに、ただちにサイクル計算に入ります。 

分子がすでに基本表現と完全に互換性がある場合、次のようになります。`1 2`、gcd は 1 であり、1 を法とする 2 の位数は自明のことながらゼロです。 このアルゴリズムは、無効なモジュラー計算を回避するためにこのケースを短絡します。
