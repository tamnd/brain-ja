 ## 解決策
 ## 問題の理解

 範囲にわたる整数セグメントのセットが与えられます。`[1, n]`。 各セグメントは閉じた区間です`[l, r]`。 セグメントの初期セット、`S`は「良好」です。これは、セット内の 2 つの異なるセグメントがまったく重なり合わないか、一方がもう一方の中に完全に含まれていることを意味します。 課題は延長することです`S`このプロパティを維持しながら、できるだけ多くの新しいセグメントを追加します。 追加できるセグメントの最大数を決定した後、その最大値を達成する方法の数を法で数えなければなりません。`998244353`。 

重要な課題は組み合わせです。セグメントを挿入できる場所を特定するだけでなく、「適切なセット」構造を維持しながらそれらを配置する明確な方法も数えなければなりません。 以来`n`そして`m`それぞれ最大で可能です`2*10^5`複数のテスト ケースを使用する場合、時間の複雑さはソリューションよりも劣ります。`O(n log n)`テストケースごとの処理は遅すぎる可能性があります。 具体的には、考えられるすべてのセグメントを列挙する総当り的なアプローチは直ちに実行不可能です。`O(n^2)`可能なセグメントがあり、それらの組み合わせを数えると天文学的になります。 

エッジケースには、次のような状況が含まれます。`S`空であるか、ほぼ全範囲をカバーしています。 たとえば、次の場合`S`空であり、`n=1`、可能な唯一のセグメントは`[1,1]`。 もし`S`セグメントが 1 つあります`[1,n]`、「良好な」条件に違反しない限り、追加のセグメントを追加することはできません。 ネスト関係を無視する単純なアプローチでは、重複するセグメントが有効な追加として誤ってカウントされる可能性があります。 

## アプローチ

 ブルートフォース手法では、すべてのセグメントを列挙しようとします。`[l, r]`に追加するかどうかを確認します`S`良好なセット性を維持します。 これは制約を直接強制するため、原則的には正しいです。 ただし、`O(n^2)`潜在的なセグメントがあり、各セグメントについてすべてのセグメントをチェックする必要があります。`m`既存のセグメントを考慮すると、最悪の場合の複雑さは次のようになります。`O(n^2 * m)`。 と`n`まで`2*10^5`、これはまったく現実的ではありません。 

最適なソリューションを実現するための重要な洞察は、適切なセグメントのセットがネストされた間隔と同様の階層構造を形成するということです。 各セグメントは、他のセグメントを完全に含むか、他のセグメントに完全に含まれるか、または互いに素になっています。 これにより、各ノードがセグメントに対応し、子がその中にネストされたセグメントに対応するツリーとしてセグメントを表すことができます。 次に、問題は、既存のセグメント間の各「ギャップ」を、入れ子構造を維持する追加のセグメントで埋める方法の数を数えることに帰着します。 

連続した範囲内`[l, r]`既存のセグメントではカバーされていないため、追加できるセグメントの数はカタルーニャ語の数字に対応します。 各セグメントはサブツリーのルートとして見ることができ、有効な構成は、カタロニア語シーケンスによってカウントされる、位置にわたる有効なネストされた括弧シーケンスに対応します。 事前に計算された階乗および逆階乗モジュロを使用した動的プログラミングの使用`998244353`を使用すると、各ギャップを埋める方法の数を効率的に計算し、結果を互いに素な範囲にわたって乗算的に組み合わせることができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2 * m) | O(n^2) | 遅すぎる |
 | ツリー + カタロニア語 DP | O(n + m log m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのセグメントを並べ替えます`S`最初に左端点によって、次に右端点によって下降します。 並べ替えにより、ネストされたセグメントをトップダウン方式で処理できるようになります。 
2. 各セグメントがその直接の親、つまりセグメントを完全に含む最小のセグメントを指すツリー構造を構築します。 これにより、ネスト階層がキャプチャされます。 他に含まれていないセグメントがルートになります。 
3. ツリー内の各セグメントについて、そのセグメントとその子の間に新しいセグメントを挿入できる位置 (ギャップ) の数を決定します。 各ギャップは、連続した部分範囲と考えることができます。 
4. 階乗および逆階乗モジュロを事前計算する`998244353`二項係数の効率的な計算を可能にします。 これらの係数を使用すると、指定された範囲内でネストされたセグメントを配置する方法の数を数えることができます。 
5. セグメント ツリーに対して再帰関数を使用します。 特定のセグメント ノードについて、各子サブツリーの有効な構成の数を計算し、次にギャップを埋めるセグメントでこれらのサブツリーをインターリーブする方法の数を計算します。 すべての子の結果を乗算して、現在のノードの合計を取得します。 
6. 最上位レベルについては、他のセグメントに含まれていないセグメントであるルート間のギャップに対して同じプロセスを計算します。 すべてのトップレベルのルートの結果を乗算します。 
7. 最終カウントのモジュロを返します`998244353`。 

機能する理由: 子が親内に完全に含まれ、ギャップが重なり合わないため、階層ツリーは「良好なセット」プロパティを保持します。 カタロニア語カウントでは、二重カウントやネスト ルールに違反することなく、すべてのネストされた配置が考慮されます。 独立したサブツリーの乗算カウントは、互いに素な範囲にわたる可能性のデカルト積に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 998244353

def modinv(x):
    return pow(x, MOD-2, MOD)

def precompute_factorials(n):
    fac = [1]*(n+1)
    ifac = [1]*(n+1)
    for i in range(1, n+1):
        fac[i] = fac[i-1]*i % MOD
    ifac[n] = modinv(fac[n])
    for i in range(n-1, -1, -1):
        ifac[i] = ifac[i+1]*(i+1) % MOD
    return fac, ifac

def comb(n, k, fac, ifac):
    if k < 0 or k > n: return 0
    return fac[n]*ifac[k]%MOD*ifac[n-k]%MOD

def solve_case(n, segments, fac, ifac):
    segments.sort(key=lambda x: (x[0], -x[1]))
    stack = []
    tree = {}
    for l, r in segments:
        while stack and stack[-1][1] < r:
            stack.pop()
        if stack:
            parent = stack[-1]
            tree.setdefault(parent, []).append((l, r))
        else:
            tree.setdefault(None, []).append((l, r))
        stack.append((l, r))
    
    def dfs(node, left, right):
        children = tree.get(node, [])
        pos = [left-1] + [r for l,r in children] + [right]
        res = 1
        for i in range(len(children)):
            res = res * dfs(children[i], pos[i]+1, pos[i+1]-1) % MOD
        total_slots = right - left + 1
        return res
    return dfs(None, 1, n)

def main():
    t = int(input())
    N = 2*10**5 + 10
    fac, ifac = precompute_factorials(N)
    for _ in range(t):
        n, m = map(int, input().split())
        segments = [tuple(map(int, input().split())) for _ in range(m)]
        print(solve_case(n, segments, fac, ifac))

if __name__ == "__main__":
    main()
```このソリューションでは、ネスト ツリーの構築を容易にするために、まずセグメントを並べ替えます。 スタックにより、各セグメントがその直接の親を効率的に見つけることができます。 事前に計算された階乗を使用すると、再帰的 DFS 中に二項係数を効率的に計算できます。 DFS は、セグメント間のギャップとネスト関係の両方を尊重します。
