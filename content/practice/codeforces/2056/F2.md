## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        k, m = map(int, input().split())
        n_bin = input().strip()
        n = int(n_bin, 2)
        if m == 1:
            print(0)
            continue
        res = 0
        med_idx = (n + 1) // 2
        bit = 1
        while bit < m:
            # If median >= bit, then that bit contributes
            # For large n, parity is determined by whether med_idx mod (2*bit) >= bit
            if (med_idx // bit) % 2 == 1:
                res ^= bit
            bit <<= 1
        print(res)

solve()
```コードはまず、次のバイナリ文字列を変換します。$n$整数に変換します。 もし$m=1$、可能なシーケンスはすべてゼロのみであるため、XOR はゼロになります。 その他の場合$m$、最大 2 の累乗を繰り返します。$m$。 ビットごとに、中央値インデックスにそのビットが XOR に寄与しているかどうかを判断します。 これは、良好なシーケンス全体にわたる中央値のパリティ特性に依存します。 最後に、寄与するすべてのビットの XOR を計算します。
