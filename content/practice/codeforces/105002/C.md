 ## 解決策
 ## 問題の理解

 すでに順番に配置された、有効なドミノ タイルのチェーンが与えられています。 各タイルには 0 から 6 までの 2 つの数字があります。チェーン内の隣接するタイルは、接触する端ですでに一致しているため、チェーンは一貫しています。 

完全なドミノ セットには、0 から 6 までの順序のない値のペアごとに 1 つのタイルが含まれているため、合計 28 のタイルが含まれます。 それらの一部はすでにチェーンで使用されており、残りのタイルは利用可能です。 

このタスクは、接触する端には同じ番号がなければならないというルールに従って、未使用のタイルをチェーンの左端または右端に追加できるかどうかを確認することです。 可能であれば、そのようなタイルの有効な配置と方向を 1 つ出力する必要があります。 そうでない場合は、手は存在しないと出力します。 

重要な点は、チェーンの 2 つのエンドポイントのみが重要であるということです。 候補タイルは、その端の 1 つが左端の露出された番号と一致する場合、左側で有効であり、右端についても同様です。 

制約は小さく、チェーン内のタイルは最大 28 個であり、可能なタイルの範囲もちょうど 28 です。これにより、大量の検索は即座に除外されます。 合計状態空間のサイズは一定であるため、すべての可能なタイルを直接スキャンするだけでも十分です。 

微妙なケースは方向性です。 (2, 5) のようなタイルは、どちらの側がチェーンの端に接続されているかに応じて、(2, 5) または (5, 2) として配置できます。 タイルを裏返すのを忘れた不注意な解決策は、有効な手を誤って拒否することになります。 

もう 1 つのエッジ ケースは、複数のタイルが有効な場合です。 この問題では任意の有効な答えが許可されるため、最初の一致で停止できます。 

## アプローチ

 ブルートフォース解釈では、残りのすべてのタイルをシミュレートし、それをチェーンの両端に両方の方向で接続しようとします。 各タイルについて、最大 2 つの配置をチェックします。 タイルは合計で最大 28 個あるため、各一定時間で最大 56 回のチェックが行われます。 未使用のタイルのセットを明示的に再構築したとしても、総作業量は無視できます。 

チェーンはすでに固定されており分岐しないため、より深い組み合わせ論やグラフ構造は必要ありません。 唯一の決定は、1 つのエンドポイントを拡張できるかどうかです。 

重要な点は、未使用のセットを複雑な方法で明示的に再構築する必要がないということです。 チェーン内に表示されるすべてのタイルをマークし、28 タイル スペース全体をスキャンして、エンドポイントに対して妥当性をテストできます。 

これにより、問題は一定の宇宙にわたる直接的な存在チェックに帰着します。

 ## アルゴリズムのチュートリアル

1. ドミノの連鎖を読み取り、順番に保管します。 読み取り中に、どのタイル ペアがすでに使用されているかを記録します。 ドミノには順序がありませんので、(a, b) と (b, a) を同じタイルとして扱います。 
2. チェーンの露出したエンドポイントを特定します。 左のエンドポイントは最初のタイルの左の値、右のエンドポイントは最後のタイルの右の値です。 これら 2 つの数値によって、可能なすべての拡張子が決まります。 
3. 0 ≤ a ≤ b ≤ 6 で、考えられるすべてのドミノ タイル (a、b) を繰り返します。この列挙は、ドミノ セット内の使用可能なタイルの完全なセットを表します。 
4. チェーン内ですでに使用されているタイルをスキップします。 これにより、残りの部分のみが考慮されるようになります。 
5. 未使用の各タイルについて、左端に配置できるかどうかを確認します。 これは、a または b のいずれかが左端点と一致する場合に当てはまります。 その場合は、一致する番号がチェーンに接続されるようにタイルの向きを変え、すぐに方向「L」で出力します。 
6. 左側が使用できない場合は、右端に設置できるか確認してください。 これは、a または b のいずれかが正しいエンドポイントと一致する場合に当てはまります。 その場合は、一致する番号が右側につながるように向きを変えて、「R」方向で出力します。 
7. いずれかの条件を満たすタイルが存在しない場合は、「FISH」を出力します。 

### なぜ効果があるのか

 このアルゴリズムは、有効な移動にはチェーンの 1 つのエンドポイントが関与する必要があるという事実に基づいています。 ドミノ セットは有限で完全に列挙されているため、考えられるすべての候補がテストされます。 使用済みタイルのフィルタリングにより、既存のドミノが再利用されることがなくなり、エンドポイントの一致により隣接関係の有効性が保証されます。 有効な配置が見つかるとすぐに出力されるため、完全性が保たれます。解決策が存在する場合、それは列挙中に表示されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
used = set()

tiles = []
for _ in range(n):
    a, b = map(int, input().split())
    tiles.append((a, b))
    used.add((a, b))

left_end = tiles[0][0]
right_end = tiles[-1][1]

for a in range(7):
    for b in range(a, 7):
        if (a, b) in used:
            continue

        if a == left_end or b == left_end:
            if b == left_end:
                a, b = b, a
            print("L")
            print(a, b)
            sys.exit(0)

        if a == right_end or b == right_end:
            if a == right_end:
                a, b = b, a
            print("R")
            print(a, b)
            sys.exit(0)

print("FISH")
```実装は、O(1) メンバーシップ チェックのために、使用されているすべてのドミノをセットに保存することから始まります。 列挙中に使用されたセットに対して候補を繰り返しテストするため、これは重要です。 

エンドポイントは、最初と最後のタイルから直接取得されます。 入力によって有効なチェーンが保証されるため、これらの値は明確に定義されます。 

ネストされたループは、28 個の可能なドミノ タイルをすべて正規形式 (a ≤ b) で列挙します。 各タイルについて、まず未使用であることを確認し、次に左右の互換性をテストします。 方向は、一致する番号が正しい側に配置されるようにエンドポイントを交換することによって処理されます。 

を使用した早期終了`sys.exit(0)`これは、有効な答えが受け入れられるという要件と一致して、有効な手を見つけたらすぐに停止することを保証します。

 ## 特殊なケース

 エッジ ケースの 1 つは、チェーンが単一のタイルで構成されている場合です。 この場合、両方のエンドポイントが同じタイルから取得されるため、左側と右側の両方が有効な接続ポイントになります。 このアルゴリズムは常に両方のエンドポイントを個別にチェックし、一致する未使用のタイルが受け入れられるため、引き続き機能します。 

もう 1 つのケースは、タイルが両方のエンドポイントに同時に一致する場合です。 たとえば、左の端点が 3 で、右の端点も 3 の場合、3 を含むタイルはどちらの方向にも接続できます。 アルゴリズムは、最初に見つかった一致を選択する可能性がありますが、有効な回答はすべて許可されるため、これは許容されます。 

最後のケースは、残りのすべてのタイルが両方のエンドポイントから事実上切断される場合です。 28 タイルすべての列挙により、この状況が正しく検出されることが保証されます。これは、どちらのエンドポイント テストにも合格する候補がなく、最終的な「FISH」出力につながるためです。
