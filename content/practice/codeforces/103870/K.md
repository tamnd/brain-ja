 ## 解決策
 ## 問題の理解

 私たちは、各参加者が 3 つの選択肢から 1 つを独立して選択する、3 択ゲームの繰り返しラウンドを中心に構築された確率的消去プロセスに注目しています。 同一のエンティティのグループは単一の状態で開始され、各ラウンドの後、選択肢の配分に応じて、それらの一部のサブセットが次のラウンドまで生き残ります。 このプロセスは、エンティティが 1 つだけ残るまで続行されます。 タスクは、初期グループ サイズごとに計算することです。$x$、生存者が 1 人になるまでに必要な予想ラウンド数。 

したがって、入力は同一プレイヤーの初期数を表し、出力は上記のランダム排除ダイナミクスの下で 1 人のプレイヤーだけが生き残るまでの予想されるゲーム数になります。 

反復によって暗示される制約構造は次のとおりです。$x$選択肢のすべての構成にわたる単純な状態の拡張が実行不可能になるほど大きくなる可能性があります。 1ラウンドでもすでに$3^x$各参加者が 3 つのアクションから独立して選択するため、考えられる結果が異なります。 結果を直接列挙しようとするソリューションは、すぐに指数関数的になります。 唯一実行可能な方向性は、対称性によって結果を圧縮し、正確な構成ではなく、ラウンド後に何人のプレイヤーが残るかに焦点を当てることです。 

イベント空間を適切に条件付けせずに、「少なくとも 1 つの消去が発生する」ことだけを推論しようとすると、微妙な失敗モードが発生します。 無条件確率と条件付き確率を誤って混合すると、再発に偏りが生じます。 たとえば、すべての構成を均一に扱いながら、同時に構成の削除に制限すると、正規化が崩れ、たとえ小規模な構成であっても誤った期待が生じることになります。$x$、 のような$x=2$、ここでは手作業による計算がまだ扱いやすいです。 

もう一つのエッジケースは、$x=1$。 その場合、ゲームはまったく必要ないため、期待はまったくゼロでなければなりません。 消去確率で割る反復では、この基本ケースを明示的に処理する必要があります。 

## アプローチ

 直接的な総当りのアプローチでは、じゃんけんで考えられるすべての割り当てを列挙することになります。$x$各ラウンドのクローンを作成し、生き残る数を計算し、すべての結果を再帰的に平均します。 これは、すべての確率的遷移にわたる期待の文字通りの定義に従っているため、原理的には正しいです。 ただし、各州は次のように分岐します。$3^x$結果をグループ化しても、これは多項カウントに減少するだけであり、依然として指数関数的に増加します。$x$。 再帰ツリーはあらゆる深さで拡張するため、このアプローチは非常に小さいレベルを超えると完全に実行不可能になります。$x$、 その周り$x \le 10$。 

重要な観察は、このプロセスは、どの特定のプレイヤーが選択するかではなく、何人のプレイヤーが各アクションを選択するかによってのみ依存するということです。 この対称性により、ラベル付き構成からの状態空間が、残りのプレーヤーの数を表す単一の整数状態に折りたたまれます。 この圧縮を受け入れると、問題はマルコフ過程になります。$x$、各ステップはより小さなステップに移行します。$k$ある程度の計算可能な確率で。 

2 番目に重要な考え方は、ラウンドを 2 つのフェーズに分けることです。 まず、少なくとも 1 つの消去が発生する可能性があります。 第 2 に、排除が発生することを条件として、生き残った人の数に分布が生じます。 この分離により、最初の「有用な」ラウンドの予想待機時間を計算し、標準の期待線形性を使用して、それをより小さな状態への遷移と組み合わせることができます。 

これが確立されると、期待値は$dp[x]$これは、考えられる各生存者数への遷移確率によって重み付けされた、すべての小さな状態にわたる繰り返しとして書くことができます。 これらの確率の計算は、二項タイプの計数に帰着します。つまり、選択肢が 2 つだけ表示されるすべての代入の中で (3 番目の選択肢は消去を意味しないため)、正確に結果が得られる方法が何通りあるかを数えます。$k$生存者。 

これは、動的プログラミング ソリューションにつながります。$x$ここで、各状態はすべてのより小さな状態に依存します。 遷移確率は組み合わせ的に事前に計算することができ、予想される待ち時間の項はラウンドが実際に敗退を引き起こす確率から導出されます。

 ## アルゴリズムのチュートリアル

 私たちは定義します$dp[x]$に必要な予想ラウンド数として$x$同一のクローンを 1 つの生存者に減らします。 

1.ベースケースを固定する$dp[1] = 0$。 クローンが 1 つだけの場合は相互作用が不可能なため、ラウンドは必要ありません。 
2. 次の構成を検討します。$x$クローン。 1 回のラウンドでは除去が行われないか、クローンの数が減少する可能性があります。 まず、ラウンドが実際に少なくとも 1 回の敗退を引き起こす確率に焦点を当てます。 消去は、3 つの選択肢すべてがクローン内に出現しない場合にのみ発生します。 
3. ラウンドで 2 つの選択肢のみが使用される確率を数えます。 固定の選択肢のペア、たとえばジャンケンの場合、各クローンは確率でこれら 2 つの中から独立して選択します。$(2/3)^x$。 ただし、すべてのクローンがそれらのうちの 1 つだけを選択するケースを除外する必要があります。これは、確率でそれぞれ 2 つのサブケースに対応します。$(1/3)^x$。 したがって、固定ペアの場合、有効な確率は次のようになります。$(2/3)^x - 2(1/3)^x$。 
4. ジャンケンには 3 つの可能な選択肢があるため、3 を掛けます。これにより、ラウンドが「アクティブ」である確率の合計が求められます。つまり、少なくとも 1 つの除外が発生することを意味します。$$p_x = 3\left(\left(\frac{2}{3}\right)^x - 2\left(\frac{1}{3}\right)^x\right).$$1. このようなアクティブなラウンドが発生するまでの予想待機時間は次のとおりです。$1/p_x$。 これは、プロセスが実際に縮小するまでに予想される合計ラウンド数を取得します。 
2. ここで、ラウンドがアクティブであるというイベントを条件とします。 このようなラウンドでは、ちょうど 2 つの選択肢が表示され、そのうちの 1 つがもう 1 つを排除します。 生存者はまさに、非支配的な選択肢を選択したクローンです。 確率を正確に計算すると、$k$クローンは生き残る。 
3. 固定の選択肢のペアの場合、どちらを選択しますか$k$クローンは生き残る選択肢を選び、$\binom{x}{k}$。 残り$x-k$全員が負ける選択肢を選ばなければなりません。 すべてが等しくないすべての構成を正規化すると、次の条件付き確率が得られます。$\binom{x}{k}$、生存者全体の二項分布のような分布につながります。 
4. これらの遷移を組み合わせて、以下を取得します。$$dp[x] = \frac{\sum_{k=1}^{x-1} dp[k]\cdot P(x \to k)}{p_x} + \frac{1}{p_x}.$$最初の項は、より小さい状態に移行した後に予想される将来のコストを説明し、第 2 項はそのような移行が発生するまでの待ち時間を示します。 

1. この DP を昇順で評価します。$x$、各状態はより小さい値にのみ依存するためです。 
2. 階乗および逆階乗を事前計算して、二項係数を効率的に計算します。$O(1)$、全体的に複雑になります$O(n^2)$。 

### なぜ効果があるのか

 このプロセスは、状態が生き残ったクローンの数によって完全に特徴づけられるマルコフ連鎖を形成します。 各ラウンドでは、システムを変更しないままにするか、厳密に下方に移動します。 下向きの動きが発生するというイベントを条件付けすることで、待機に費やされる時間を状態遷移から分離します。 期待値の線形性により、可能性のあるすべての次の状態の寄与を確率で重み付けして合計することができます。 確率は割り当ての組み合わせ数にのみ依存し、恒等式には依存しないため、二項構造は正確であり、正規化が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(a):
    return pow(a, MOD - 2, MOD)

def solve():
    n = int(input().strip())
    
    if n == 1:
        print(0)
        return

    # factorials for binomial coefficients
    fact = [1] * (n + 1)
    invfact = [1] * (n + 1)

    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD

    invfact[n] = modinv(fact[n])
    for i in range(n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    def C(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

    # probability-related constants in modular form
    inv3 = modinv(3)
    inv3x = [1] * (n + 1)
    inv2pow = [1] * (n + 1)

    for i in range(1, n + 1):
        inv3x[i] = inv3x[i - 1] * inv3 % MOD

    dp = [0] * (n + 1)

    for x in range(2, n + 1):
        px = (3 * (pow(2 * inv3, x, MOD) - 2 * inv3x[x])) % MOD
        if px < 0:
            px += MOD

        inv_px = modinv(px)

        total = 1  # waiting time contribution

        for k in range(1, x):
            ways = C(x, k)
            total += ways * dp[k] % MOD

        dp[x] = total % MOD * inv_px % MOD

    print(dp[n] % MOD)

if __name__ == "__main__":
    solve()
```コードはまず階乗テーブルを構築して、組み合わせを効率的に計算します。 DP 配列には、すべての小さいサイズの期待値が格納されます。 

用語$p_x$は、ラウンドによってシステム サイズが削減される確率に対応するモジュラー演算を使用して実装されます。 その逆数は、削減が発生するまでの予想待ち時間を表します。 

それぞれについて$x$、考えられるすべての生存者数からの貢献を蓄積します。$k$、二項係数によって重み付けされます。 これは、任意のサブセットが対称性を反映していることを反映しています。$k$生き残る可能性も同様です。 

最後に、で割ると、$p_x$エリミネーションラウンドを条件付けして期待値を正規化し、導出された再発と一致させます。 

## 実用的な例

 ### 例 1: x = 1

 | 状態 x | 有効確率 p_x | トランジション | dp[x] |
 | --- | --- | --- | --- |
 | 1 | 0 | なし | 0 |

 単一のクローンでは対話は不可能なため、プロセスはすぐに終了します。 再帰により、基本ケースによるゼロ除算が正しく回避されます。 

これは、マルコフ過程に出力遷移がない境界条件を確認します。 

### 例 2: x = 2

 | 状態 x | k=1 の寄与 | p_x | dp[x] |
 | --- | --- | --- | --- |
 | 2 | dp[1] = 0 | ポジティブ | 1/p_x |

 2 つのクローンがある場合、アクティブなラウンドはそのうちの 1 つを除去する必要があります。 可能な次の状態は 1 だけであり、これは将来のコストがゼロです。 期待は完全に引き分けのない最初のラウンドを待つことになります。 

これにより、遷移状態が 1 つだけ存在する場合に、DP が幾何学的待ち時間に正しく折りたたまれることが検証されます。

 のために$x=1$の場合、アルゴリズムは確率の計算を試行せずにすぐにゼロを返します。 これにより、消去確率におけるゼロ除算が回避されます。$p_x$、それ以外の場合、ゲームは必要ないため未定義になります。
