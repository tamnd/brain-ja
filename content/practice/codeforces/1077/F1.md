 ## 解決策
 ## 問題の理解

 一連の写真が与えられ、それぞれの写真の美しさを表す値が与えられます。 課題は、正確に一定数の写真を選択することであり、そのような選択すべての中で、最大限の総合的な美しさを求めます。 ただし、これらの選択された画像がラインに沿ってどのように分配されるかについては、構造上の制約があります。 

この制約は、少なくとも一定の長さの連続したブロックを見ると、`k`、そのブロックには選択した画像が少なくとも 1 つ含まれている必要があります。 言い換えれば、ストレッチをすることは決して許可されません。`k`連続して選ばれなかったポジション。 これにより、選択した位置が適切に分散されますが、残りの選択をどのように分散するかについては柔軟性が残ります。 

出力は、選択された美しさの達成可能な最良の合計、または有効な選択が存在しないという宣言のいずれかです。 

制約`n ≤ 200`すぐに、3 次または高度 2 次の動的計画法ソリューションが受け入れられると提案します。 サブセットに対する指数関数的なアプローチは不可能です。`x`要素はすでに与えています$\binom{200}{100}$-スケールの組み合わせ。 これは、問題がプレフィックスまたは位置を介して構造化された DP であることを示す典型的なシグナルです。 

「カバレッジ」の制約から微妙な問題が発生します。 常に最良のものを選ぶという素朴な貪欲な考え`x`値の高い要素がクラスター化され、選択された位置のない長いギャップが残る可能性があるため、要素は失敗します。 たとえば、大きな値が先頭と末尾ではなく、長さの中間のセグメントに集中している場合`k`が空の場合、たとえ合計が高くても、解は無効になります。 

もう 1 つの失敗例は、正確なカウントを尊重しないことに起因します。`x`。 たとえ構成が間隔制約を満たしていても、正確に一致しない限り無効です。`x`要素が選ばれます。 これにより、問題は数と構造の両方に対する制約付きの最適化に変わります。 

## アプローチ

 ブルートフォースアプローチでは、正確に選択するためにあらゆる方法が試行されます。`x`インデックスを作成し、間隔制約を確認します。 各サブセット チェックでは、アレイがスキャンされていないことを確認する必要があります。`k`連続した選択されていない位置が存在し、有効な場合は合計値。 サブセットの数は$\binom{n}{x}$、中程度の場合でも巨大になります`n`、各検証コスト`O(n)`、これは完全に不可能になります。 

重要な構造的観察は、制約が局所的であり、選択された位置がどれだけ離れているかによってのみ依存するということです。 配列を左から右に処理する場合、どの時点でも重要なのは、既に選択した要素の数と、強制的に選択せずにどこまで処理できるかということだけです。 

これにより、位置、選択の数、最後に選択された要素からの経過時間を追跡する動的プログラミングの定式化が自然に生まれます。 サイズのギャップがないという制約`k`が許可されている場合は、それ以上進むたびに、次のことを保証することでエンコードできます。`k-1`選択せずにステップを実行すると、すでに選択が含まれている状態になります。 

プレフィックスに対する DP 状態を定義します。位置ごと、選択された要素の数ごと、および許容されるギャップ長ごとに、可能な限り最適な合計を計算します。 トランジションは、現在の要素を選択するか、スキップできる範囲を超えないことを考慮してスキップします。`k-1`選択を強制せずに連続した位置を選択します。 

これにより、グローバルな間隔制約が制限されたローカル ステート マシンに変換され、これが解決策が扱いやすくなる理由です。

 ## アルゴリズムのチュートリアル

 すでに選択した要素の数と、最後に選択した要素からどれだけ離れているかを追跡する DP を構築します。 目標は、セグメントの長さというルールに決して違反しないようにすることです。`k`完全に選択を解除することはできません。 

1. DP テーブルを初期化します。`dp[i][j]`選択されたプレフィックスを処理した後の最大の美しさの合計を表します。`j`要素、および状態遷移によって暗黙的に強制される現在のサフィックス制約を伴います。 

重要なアイデアは、最後に選択されたインデックスを明示的に追跡するのではなく、連続スキップがまだ許可されている回数を追跡するということです。 
2. 各ポジションで`i`の場合、2 つの選択肢を検討します。どちらかを選択します。`a[i]`あるいはスキップします。 

選択すると、最後に選択した位置が更新されるため、スキップ制約がリセットされます。 
3. 選択した場合`a[i]`の状態から移行します。`j-1`選択した要素を次の状態にします`j`選択された要素とゲイン`a[i]`価値において。 
4. スキップしたら`a[i]`、まだ蓄積していない場合にのみこれを許可します。`k-1`連続スキップ。 これにより、禁止された長さのブロックが作成されることがなくなります。`k`選択なしで。 
5. 最良の値を維持しながら遷移を前方に伝播し、制約に違反する状態が決して作成されないように注意します。 
6. 最終的な答えは、正確に一致する州の中で最良の値です。`x`すべての位置を処理した後に要素が選択されました。 

### なぜ効果があるのか

 すべての状態は、禁止されたギャップが作成されていない有効な部分構造をエンコードします。 スキップ制約は、選択した 2 つの位置間の距離が最大でも次の距離であることを保証します。`k-1`したがって、長さのすべてのセグメント`k`選択したインデックスを少なくとも 1 つ含める必要があります。 DP は有効な状態のみを拡張し、不正なギャップを決して導入しないため、無効な構成は生成されません。 同時に、すべての有効な構成はこれらの状態を通過する 1 つのパスに正確に対応し、完全性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k, x = map(int, input().split())
    a = list(map(int, input().split()))

    INF = -10**18

    # dp[i][j][t]:
    # i - position
    # j - number chosen
    # t - how many consecutive skips since last pick (0..k-1)
    dp = [[[INF] * k for _ in range(x + 1)] for _ in range(n + 1)]

    dp[0][0][0] = 0

    for i in range(n):
        for j in range(x + 1):
            for t in range(k):
                if dp[i][j][t] == INF:
                    continue

                cur = dp[i][j][t]

                # skip
                if t + 1 < k:
                    dp[i + 1][j][t + 1] = max(dp[i + 1][j][t + 1], cur)

                # take
                if j < x:
                    dp[i + 1][j + 1][0] = max(dp[i + 1][j + 1][0], cur + a[i])

    ans = max(dp[n][x])

    print(-1 if ans < 0 else ans)

if __name__ == "__main__":
    solve()
```制約は本質的にカウントと間隔の両方に関するものであるため、DP では 3 次元が使用されます。 連続したスキップを追跡しないと、「k 個の長さのすべてのセグメントにピックが含まれる」ルールに違反する無効なシーケンスが許可されてしまうため、3 番目の次元は不可欠です。 

初期化では、空のプレフィックスのみが有効として設定されます。 すべての遷移は値を消費するかギャップを拡張します。無効なギャップ拡張は明示的にブロックされます。`t + 1 < k`状態。 

最終的な回答では、考えられるすべてのターミナル ギャップ状態がチェックされます。これは、制約は、最後の選択後に何が起こるかではなく、不正なギャップが形成されないことを保証することのみが重要であるためです。

 ## 特殊なケース

 重要なエッジケースが発生するのは次の場合です。`k = 1`。 この状況では、すべての位置を選択する必要があり、スキップしようとする DP 状態は直ちに無効化する必要があります。 移行ルールは当然すべてのスキップをブロックします。`t + 1 < 1`は決して真ではないため、継続的な選択が強制されます。 

別の微妙なケースが現れるのは、`x`に比べて大きい`n`。 DP は、間隔の制約により要素の選択が少なすぎる状況を正しく処理する必要があります。 アルゴリズムは当然、次のような状態で終了します。`j < x`有効な完了がありません。`-1`。 

3 番目のケースは、価値の高い要素がより近くにクラスター化されている場合です。`k`、DP は各ウィンドウで最大 1 つを選択する必要があります。 スキップ状態ディメンションにより、要素が選択されると、次の要素が選択されることが保証されます。`k-1`位置を安全にナビゲートすることはできますが、間隔を侵害しようとする試みは状態空間が破損する前に拒否されます。
