 ## 解決策
 ## 問題の理解

 ドミノ タイルのセットが与えられ、それぞれの半分に 2 つの数字が書かれています。 課題は、隣接するドミノの接している半分が同じ番号になるように、すべてのドミノを順番に配置することです。 ドミノをひっくり返すと、2 つの数字が入れ替わります。 出力は、どのドミノが各位置に配置されるか、およびそれが裏返されるかどうかを説明するシーケンス、またはそのような配置が不可能な場合は「解決策なし」のいずれかです。 

この問題はグラフの問題として解釈できます。 0 から 6 までの各数字は頂点を表し、各ドミノは両端の 2 つの数字を接続するエッジです。 隣接する半分が一致するようにドミノを一列に配置することは、すべてのエッジを 1 回だけ使用するパス、つまりオイラー パスを見つけることに相当します。 パスが同じ頂点で始まり同じ頂点で終わる場合、それはオイラー回路です。 

制約により、最大 100 個のドミノが許可されます。 これは小さいため、時間計算量がエッジの二乗数に比例するアプローチでも実現可能です。 ただし、課題は、すべての順列を強引に列挙することよりも、グラフの構造とエッジの向きを正しく処理することにあります。これはドミノの数の階乗となり非現実的です。 

明らかではないエッジ ケースには、すべてのドミノが同じ番号を持つ場合、ドミノが切断されたコンポーネントを形成する場合、または必要なオイラー パスが奇数次数の頂点で開始または終了する必要がある状況が含まれます。 たとえば、次の入力を使用します。```
3
1 2
2 3
4 5
```ドミノのセットは 2 つの切り離されたコンポーネントを形成するため、解決策はありません。 接続性をチェックせずに貪欲にドミノを連鎖させようとする単純なアルゴリズムは、何も言わずに失敗します。 

## アプローチ

 ブルートフォースアプローチでは、ドミノのすべての順列を生成し、それぞれが有効なチェーンであるかどうかをテストしようとします。 ドミノが 100 個ある場合、これには 100 個が関係することになります。 順列は天文学的に大きい。 枝刈りを伴うバックトラッキングを使用したとしても、最悪のケースは依然として非現実的です。 

重要な洞察は、ドミノの配置が頂点 0 ～ 6 とドミノに対応するエッジを含むマルチグラフ問題を形成するということです。 有効なシーケンスを見つけることは、オイラー パスを見つけることと同じです。 オイラー パスは、グラフが接続されており、すべての頂点が偶数次数を持つ場合 (オイラー回路)、または正確に 2 つの頂点が奇数次数を持つ場合 (オイラー パス) に存在します。 これにより、グラフの走査と次数のチェックの問題が軽減され、頂点とエッジの数が少ないため対処可能です。 

隣接リストを構築し、各ドミノをエッジとして保存することで、Hierholzer のアルゴリズムを適用してオイラー パスを見つけることができます。 このメソッドはグラフをウォークスルーし、進行に応じてエッジを削除し、各エッジが 1 回だけ使用されるようにします。 ドミノを反転するのは簡単です。パスがドミノの元の方向とは反対の方向にエッジを横切る場合、反転したとマークします。

 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | オイラーパス / Hierholzer | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グラフの隣接リストを作成します。頂点は 0 ～ 6 の番号、エッジはドミノのインデックスです。 各エッジは、使用されたかどうかを示すフラグとともに保存されます。 
2. 各頂点の次数を数えます。 奇数次数の頂点は、オイラー パスの開始と終了を決定します。 奇数次数の頂点が 2 つ以上ある場合は、オイラー パスは不可能であるため、「解なし」と出力されます。 
3. 開始頂点を選択します。 奇数次数の頂点がある場合は、そのうちの 1 つから開始します。 それ以外の場合は、少なくとも 1 つのエッジを持つ任意の頂点から開始します。 
4. Hierholzer のアルゴリズムを実行します。 開始頂点でスタックを初期化します。 スタックが空ではないときに、一番上の頂点を見てください。 未使用のエッジがある場合は、そのエッジをたどり、使用中であることをマークし、新しい頂点をスタックにプッシュします。 未使用のエッジがない場合は、スタックから頂点をポップし、パスに追加します。 
5. 得られたパスは逆順なので、最後に逆にします。 このシーケンスは頂点を表します。 連続する頂点の各ペアはドミノに対応します。 どのドミノエッジが使用されているか、またそれを裏返す必要があるかどうかを追跡します。 
6. 再構築されたパスの順序に従ってドミノのインデックスと方向を出力します。 

機能する理由: Hierholzer のアルゴリズムは、各エッジが 1 回だけ使用されることを保証し、有効なオイラー パスまたは回路が存在する場合はそれを生成します。 次数チェックにより、トラバース前に解決が可能であることが確認されます。 不変条件は、各エッジが通過時に 1 回だけ削除されること、およびスタックによってパスが接続され有効であることが保証されることです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import defaultdict, deque

n = int(input())
dominoes = []
adj = defaultdict(list)
used = [False] * n

for i in range(n):
    a, b = map(int, input().split())
    dominoes.append((a, b))
    adj[a].append((b, i))
    adj[b].append((a, i))

deg = [0] * 7
for i in range(7):
    deg[i] = len(adj[i])

odd = [i for i in range(7) if deg[i] % 2 == 1]
if len(odd) not in [0, 2]:
    print("No solution")
    sys.exit()

start = odd[0] if odd else next((i for i in range(7) if deg[i] > 0), 0)
stack = [start]
res = []

while stack:
    v = stack[-1]
    while adj[v] and used[adj[v][-1][1]]:
        adj[v].pop()
    if adj[v]:
        u, idx = adj[v].pop()
        used[idx] = True
        stack.append(u)
    else:
        stack.pop()
        if stack:
            u = stack[-1]
            # find the domino connecting u and v
            for idx, (a, b) in enumerate(dominoes):
                if used[idx]:
                    continue
                if (a, b) == (u, v):
                    used[idx] = True
                    res.append((idx + 1, '+'))
                    break
                if (a, b) == (v, u):
                    used[idx] = True
                    res.append((idx + 1, '-'))
                    break

for idx, sign in res[::-1]:
    print(f"{idx} {sign}")
```コードは最初に隣接リストを構築し、頂点の次数を計算します。 奇数次の頂点によって、オイラー パスが可能かどうかが決まります。 Hierholzer のアルゴリズムはスタックで実装されており、エッジを使用済みとして注意深くマークします。 最終的なパスは逆に再構築され、連続する頂点がドミノのインデックスと方向にマッピングされます。 ドミノをひっくり返す必要がある場合には、特別な注意が必要です。
