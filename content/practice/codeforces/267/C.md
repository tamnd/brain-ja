 ## 解決策
 ## 問題の理解

 私たちには、少数の交差点を接続する有向道路システムが与えられています。 各道路には容量があり、方向に関係なく、合計で割り当てられる最大交通量があります。 重要な自由度は、道路上の交通をどちらの方向にも分割できることです。これは、符号付きの値で表されます。入力方向に従う場合は正、それ以外の場合は負です。 

システムは恣意的なものではありません。 これは保守的な流れ場のように動作します。つまり、すべての中間ジャンクションで流れが維持されるため、入口ノード 1 と出口ノード n を除いて、総流入量は総流出量と等しくなります。 それに加えて、より強力な構造上の制約があります。つまり、任意の 2 つのノード間では、任意のパスに沿ったトラフィックの「統合」はパスに依存しません。 これは、トラフィックがノード上のポテンシャル関数の差として表現できると言っているのと同じであり、これは、すべての実現可能なソリューションが、エッジごとの独立したフローではなく、ノードのポテンシャルによって完全に決定されることを直ちに意味します。 

タスクは、容量制約と潜在的な一貫性構造の両方を考慮して、有効な署名付きフローをすべてのエッジに割り当てながら、ノード 1 から出るトラフィックの合計 (ノード n に入るトラフィックと等しくなります) を最大化することです。 

制約は十分に厳しいので、エッジの数における二次または三次は許容されますが、グラフ構造上の指数関数は許容されません。 最大 100 個のノードと 5000 個のエッジがあるため、組み合わせ列挙ではなく、線形代数または最短経路スタイルの推論を余儀なくされます。 

貪欲または局所的なフロー調整を使用してエッジを独立して処理しようとすると、微妙な失敗のケースが発生します。 たとえば、2 つのノード間に複数の平行な道路が存在する場合、各エッジがその容量を尊重していたとしても、それらを個別に割り当てると、グローバルな潜在的整合性条件に違反する可能性があります。 もう 1 つの故障モードは、任意の実行可能流量を仮定することです。つまり、ポテンシャルのサイクルは、純差がゼロに対応しない限り許可されません。単純な最大流量定式化では強制されません。 

## アプローチ

 ブルート フォース ビューでは、すべてのエッジにフロー変数を割り当て、すべての制約（ノードでのフローの節約、エッジの容量制約、パス合計の一貫性）を直接強制しようとします。 これにより、不等式を含む線形方程式系、つまり最大 5000 個の変数を含む大規模な線形プログラムが生成されます。 一般的な LP 法を介して直接解くことは理論的には正しいですが、構造を考えると遅すぎて不必要です。 

重要な観察は、パス独立条件により、各エッジ フローがそのエンドポイント間のポテンシャルの差となるようにノード ポテンシャルの存在を強制することです。 つまり、有効な構成はすべて、グラフ上の勾配フィールドとして書き込むことができます。 これにより、問題全体が、各エッジ容量から導出される間隔制約の下でノード値を見つけることに帰着します。 

u と v の間の各エッジは、差 |pot[u] − Pot[v]| を制限します。 ≤ c. 目的は、ソースからシンクまでの正味フローを最大化することになります。これは、スケーリングまでの Pot[1] − Pot[n] を最大化することに対応します。 制約は均一かつ対称であるため、pot[1] = 0 を固定し、差分制約に従って最大の実現可能な Pot[n] を計算できます。 これは、実行可能な最長の潜在的なギャップを見つけることと同等であり、各エッジが両方向の不平等を課す、変換されたグラフでの最短経路の計算に帰着します。 

したがって、問題は差分制約のシステムとなり、最大 100 ノードのグラフ内の最短パスを使用して解決できます。

 ## アルゴリズムのチュートリアル

各エッジをノード電位に対する 2 つの制約として再解釈します。 エッジ (u, v, c) については、v − u ≤ c および u − v ≤ c があり、制約グラフでは 2 つの有向エッジになります。 

1. すべてのノード v に潜在値 dist[v] を導入し、一貫したポテンシャル フィールド内の位置を表します。 変換の曖昧さを取り除くために dist[1] = 0 を修正します。 
2. すべての道路 (u、v、c) に対して、2 つの有向制約を追加します: dist[v] ≤ dist[u] + c および dist[u] ≤ dist[v] + c。 これらにより、両方向に容量制限が適用されます。 
3. 実現可能な最大の構成を計算するために、この制約グラフのノード 1 からの最短パスを求めます。 各緩和ステップにより、潜在的な差異のすべての上限が確実に尊重されます。 
4. グラフには任意の重みが含まれる可能性がありますが、有効なインスタンスには負のサイクルが存在するはずがないため、ノード 1 から Bellman-Ford を実行します。 
5. 収束後、dist[n] は、すべての制約の下でノード 1 からの可能な最大の一貫した潜在的な差を表し、これは最大トラフィック値に等しくなります。 
6. 流量は潜在的な降下に等しいため、各エッジについて、実際の流量は dist[u] − dist[v] (または方向によってはその負) として再構成できます。 

これが機能する理由: すべてのエッジ制約によって定義される実現可能領域は、まさにメトリックのような空間を形成するノード ポテンシャルのセットです。 Bellman-Ford は、これらの制約の最も厳しい上限エンベロープを計算します。 すべての有効な解は、エッジによって引き起こされるすべてのペアごとの境界を満たさなければならないため、計算されたポテンシャルは、ソースとシンク間の分離を最大化する極限の一貫した割り当てになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    m = int(input().strip())

    edges = []
    adj = [[] for _ in range(n + 1)]

    for _ in range(m):
        u, v, c = map(int, input().split())
        edges.append((u, v, c))
        adj[u].append((v, c))
        adj[v].append((u, c))

    INF = 10**18

    dist = [0] * (n + 1)

    # Bellman-Ford-like relaxation (difference constraints)
    # We want the maximum feasible distances, so we relax using min constraints on negated system.
    for _ in range(n):
        updated = False
        for u, v, c in edges:
            if dist[v] > dist[u] + c:
                dist[v] = dist[u] + c
                updated = True
            if dist[u] > dist[v] + c:
                dist[u] = dist[v] + c
                updated = True
        if not updated:
            break

    # Now compute answer as maximum possible separation
    ans = 0
    for i in range(1, n + 1):
        ans = max(ans, dist[i] - dist[1])

    # reconstruct flows
    flows = []
    for u, v, c in edges:
        flows.append(dist[u] - dist[v])

    print(f"{ans:.5f}")
    print("\n".join(f"{x:.5f}" for x in flows))

if __name__ == "__main__":
    solve()
```この実装では、ノード ポテンシャルの単一配列が維持され、エッジの一貫性が繰り返し強制されます。 それぞれの緩和により、いずれの方向においてもエッジがその容量に起因する境界に違反しないことが保証されます。 流れの再構築はポテンシャルの差を使用し、これにより自動的に反対称性が満たされます。つまり、エッジを反転すると流れの符号が反転します。 

よくある微妙な点は、方向に依存するフロー変数を明示的に保存しないことです。 そうすると、システムのパラメータが過剰になり、構造が壊れてしまいます。 すべてはノードの電位から得られます。

 ## 特殊なケース

 エッジ ケースの 1 つは、複数の並列エッジが異なる容量を持つ同じノードに接続する場合です。 この場合、最も厳しい制約が優先されますが、緩和を繰り返すことで、入力順序に関係なく確実に最小境界に到達します。 すべての更新では距離が減少するだけなので、アルゴリズムは自然に収束します。 

もう 1 つのエッジ ケースは、一貫した容量を持つノードのサイクルです。 すべての制約は対称範囲であるため、負のサイクルは発生せず、ベルマン フォードは最大でも n 回の反復後に安定します。 結果として生じるポテンシャルはすべてのサイクル パスにわたって一貫したままであり、パスの独立性が自動的に維持されます。
