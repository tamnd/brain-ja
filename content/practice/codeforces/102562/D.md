 ## 解決策
 ## 問題の理解

 各候補者は縦軸の位置に立っています`(0, a_i)`着弾点に向かって直進する矢を発射します。`(x_i, y_i)`。 タスクは、選択した 2 つの矢印の軌道が交わらないように、できるだけ多くの候補を維持することです。 

軌道を確認する便利な方法は、開始高さと傾斜を含む線として見ることです。 開始時の高さは、`a_i`、傾きは`(y_i - a_i) / x_i`。 入力は開始高さと着陸点を与え、出力は交差せずに共存できる軌道の最大数です。 

すべてのテスト ケースにわたる候補者の数は次のとおりです。`500000`したがって、すべてのペアを比較するアルゴリズムは不可能です。 二次アプローチは次のように実行されます。`250000000000`これは、通常の競技プログラミングの時間制限をはるかに超えています。 解決策が必要です`O(N log N)`総投入量あたり。 

座標は非常に大きく、約`2^52`したがって、浮動小数点演算は安全ではありません。 2 つの傾きを比較する際の小さな精度誤差により、答えが変わる可能性があります。 すべての傾き比較は、整数相互乗算を使用して実行する必要があります。 

実装がサイレントに失敗する場合がいくつかあります。 等勾配もその 1 つです。 例えば：```
1
3
0 5 5
10 5 15
20 5 25
```坂道はすべて`1`、したがって、答えは次のとおりです`3`。 厳密に増加するサブシーケンスの実装では、誤って返される可能性があります。`1`等しい勾配が許可されるためです。 

別のケースは負の傾きです。```
1
2
0 2 -2
10 2 8
```斜面は、`-1`そして`-1`、したがって、両方の軌道は平行であり、答えは次のようになります。`2`。 分母の符号を考慮せずに分子を通常の整数として扱うと、誤った順序が発生しやすくなります。 

3 番目の危険なケースは、値が大きい場合です。```
1
2
0 4503599627370496 4503599627370496
1 4503599627370496 0
```斜面は、`1`そしておよそ`-1`、そして答えは`1`。 これらの値を次のように変換すると、`float`傾きを不正確に比較するのに十分な精度が失われる可能性があります。 

## アプローチ

 直接的な解決策は、すべての軌跡のペアを調べて、それらが交差するかどうかを判断することです。 2 つの軌道は、開始高さに対して傾斜が誤って順序付けされている場合に交差するため、開始高さで並べ替えて、傾斜のすべてのペアを比較できます。 これは正しいです。なぜなら、並べ替えた後だからです。`a_i`、低い軌道は、その傾きが大きくない場合にのみ、高い軌道の下に留まることができます。 問題は比較の回数です。 と`N = 100000`、ブルートフォースメソッドには約`N * (N - 1) / 2`、またはおよそ 50 億回の比較ですが、これでは遅すぎます。 

重要な観察は、垂直軸上の位置に基づいて候補を並べ替えた後、減少することのない最長の一連の傾きのみが必要になるということです。 候補者を仮定します`i`候補の下から始まります`j`。 の傾きがある場合、`i`が大きいほど、最終的には下の線が上の線を捉え、軌道が交差します。 傾きが小さいか等しい場合、2 つの線の間の距離がゼロになることはないため、両方を選択できます。 

幾何学的な問題は、有理数に対する最長の非減少部分列問題になります。 標準的な忍耐力の分類テクニックでは、これを次のように解決します。`O(N log N)`。 唯一の追加の課題は分数を正確に比較することであり、これは相互乗算によって処理されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(N²) | お(1) | 遅すぎる |
 | 最適 | O(N log N) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての候補者を開始時の身長で並べ替えます`a_i`昇順で。 これにより、軌跡が垂直軸から離れる順序が固定されます。 選択された有効なセットは、この順序を尊重する必要があります。 
2. すべての軌道を勾配値に変換します。$$s_i = \frac{y_i-a_i}{x_i}$$分母は常に正であるため、傾きを比較するには分子と分母の外積を比較するだけで済みます。 

1. ソートされた順序でスロープを処理し、忍耐強いソート配列を維持します。 位置の値`k`長さが減少しないサブシーケンスの可能な最小の終了勾配を表します`k + 1`。 
2. 現在の傾きについて、それよりも厳密に大きい、最初に保存されている傾きを見つけます。 その値を現在の傾きに置き換えます。 保存されている傾きより大きい傾きがない場合は、その傾きを追加します。 

等しい傾きが答えに同時に現れる可能性があるため、検索では、最初の以上の値ではなく、最初の大きい値が使用されます。 厳密に増加する最長のサブシーケンスではなく、最長の非減少サブシーケンスが必要です。 

1. 忍耐力ソート配列の長さは、交差しない軌道の最大数です。 

なぜ効果があるのか:

 開始高さで並べ替えると、選択したすべての軌道が下から上に表示されます。 2 つの連続して選択された軌道の場合、下の軌道は上の軌道よりも大きくない傾斜を持たなければなりません。 そうしないと、低い位置から始まりますが、上昇速度が速くなるため、最終的には上の軌道に到達する必要があります。 傾斜が非減少順に順序付けされている場合、連続する軌跡間の垂直方向の差は正から始まり、ゼロ未満に減少することはありません。 したがって、すべての有効な答えは、減少しない勾配の部分列に正確に対応します。 忍耐力ソート アルゴリズムはそのような最長のサブシーケンスを検出するため、その長さが必要な最大値となります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def greater_frac(a, b):
    return a[0] * b[1] > b[0] * a[1]

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        arr = []

        for _ in range(n):
            a, x, y = map(int, input().split())
            arr.append((a, y - a, x))

        arr.sort()

        tails = []

        for _, num, den in arr:
            cur = (num, den)

            left = 0
            right = len(tails)

            while left < right:
                mid = (left + right) // 2
                if greater_frac(tails[mid], cur):
                    right = mid
                else:
                    left = mid + 1

            if left == len(tails):
                tails.append(cur)
            else:
                tails[left] = cur

        ans.append(str(len(tails)))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```入力はまず次のように変換されます。`(starting height, slope numerator, slope denominator)`。 傾きを次のように保存する`(y_i - a_i, x_i)`浮動小数点演算を回避します。 

軸からの出発順序によって軌道を考慮する必要がある順序が決まるため、並べ替えステップは開始座標のみに基づきます。 

の`tails`array は、最長の非減少サブシーケンスの通常の忍耐ソート構造です。 二分探索では、現在の分数よりも厳密に大きい最初の分数が検索されます。 分数の比較では除算ではなく乗算が使用されるため、最大の座標であってもすべての計算が正確に保たれます。 

Python 整数は、大きな中間積を自動的に処理します。 固定幅の整数を使用する言語では、乗算が 64 ビットの制限を超える可能性があるため、より幅の広い型が必要になります。

## 特殊なケース

 等しい傾きは二分探索の選択によって処理されます。 入力の場合:```
1
3
0 5 5
10 5 15
20 5 25
```すべての軌道には傾斜がある`1`。 二分探索では、現在の値より厳密に大きい値のみを検索するため、等しい傾きをより短いサブシーケンス位置に置き換えることはありません。 配列は長さに応じて増加します`3`、それは正しいです。 

負の勾配には特別な処理は必要ありません。 考慮する：```
1
2
0 2 -2
10 2 8
```坂道はどちらも`-1`、として表されます`(-2, 2)`そして`(-2, 2)`。 相互乗算によりそれらが正確に比較されるため、両方に互換性があるとみなされ、答えは次のようになります。`2`。 

非常に大きな座標も安全です。 のために：```
1
2
0 4503599627370496 4503599627370496
1 4503599627370496 0
```最初の坂は`1`、一方、2番目は`-1`。 忍耐配列は、最初の値をより小さい傾きに置き換え、長さを残します。`1`。 アルゴリズムはこれらの値を浮動小数点に変換しないため、精度の低下は発生しません。
