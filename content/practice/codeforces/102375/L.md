 ## 問題の理解

 角のある長方形の中に整数グリッドがあります`(0, 0)`そして`(X, Y)`。 すべてのマークされたポイントの中で、`p1`は特別です。 ユークリッド距離が存在するすべてのグリッド点をカウントする必要があります。`p1`他のすべてのマークされた点までの距離よりも大きくありません。 

直接解釈すると、すべてのグリッド ポイントをすべてのマークされた点と照合することになります。 それはあまりにも高価です。 二乗距離を比較すると、有用な構造が表示されます。 固定された競争相手の場合`pi`、少なくとも次の値に近い点のセット`p1`について`pi`2 点の垂直二等分線によって境界付けられる 1 つの半平面です。 望ましいセットは、これらすべての半平面と長方形の交差部分です。 

元のコンテストの声明では次のようになります。`X, Y, K <= 2 * 10^5`、2 秒の時間制限と 512 MiB のメモリ制限があります。 これにより、グリッド点とマークされた点のすべてのペアに対する反復処理が即座に除外されます。 長方形自体には約`(2 * 10^5 + 1)^2 = 4 * 10^10`整数ポイントなので、`O(XY)`アルゴリズムは不可能です。 マークされたポイントを大まかに処理する必要があります`O(K log K)`時間を置いてから 1 つの座標範囲のみをスキャンします。 

実装を静かに破壊する可能性のある境界ケースがいくつかあります。 

もし`K = 1`、競争相手がまったくいないので、どのグリッド点も良好です。 例えば、```
1 1 1
0 0
```出力があります`4`, なぜなら、長方形の 4 つの整数点は`(0,0)`、`(0,1)`、`(1,0)`、 そして`(1,1)`。 よくある間違いは数えることです`X * Y`代わりに細胞`(X + 1) * (Y + 1)`グリッド点。 

競合他社も同じものを持てる`x`としてコーディネートする`p1`。 その場合、それらの垂直二等分線は水平であるため、`x`全然束縛されてる。 例えば、```
2 4 3
1 2
1 0
1 4
```最初の競争相手が要求するのは、`y >= 1`、2番目の要件は`y <= 3`、そしてすべての`x`から`0`を通して`2`許可されています。 答えは`3 * 3 = 9`。 すべての競争相手を自分自身として扱う`x`-line は、ゼロで除算するか、この制限を黙って失うかのいずれかになります。 

二等分線は 2 つの整数座標の間の中間を通過できます。 例えば、```
2 2 2
1 1
0 1
```に対する条件`(0,1)`は`x >= 1/2`、したがって、整数点には次の値が必要です`x >= 1`。 考えられるのは 2 つあります`x`値と 3 つの可能な値`y`値、出力の提供`6`。 数学的な下限または上限の代わりに切り捨て整数除算を使用すると、間違った境界が生成される可能性があります。 

ネクタイも受け入れなければなりません。 条件は距離が競合他社の距離以下であるため、二等分線上に正確にある点は良好な領域に属します。 このため、ソリューション内のすべてのエンベロープ比較では、アクティブなラインを選択するときに非厳密な比較が使用されます。

これは正しいです。なぜなら、厳密にどの競技者もより近い場合にポイントが認められるからです。 ただし、最悪の場合は約`4 * 10^10`グリッドポイントと`2 * 10^5`競合他社、大まかに言うと`8 * 10^15`距離の比較。 これは制限時間内に収まる量を何桁も超えています。 

重要な観察は、2 つの 2 乗ユークリッド距離を比較すると、次の 2 次項が除去されるということです。`x`そして`y`。 させて`p1 = (x1, y1)`そして競争相手を`q = (xi, yi)`。 不平等`(x - x1)^2 + (y - y1)^2 <= (x - xi)^2 + (y - yi)^2`単純化すると`2(xi - x1)x + 2(yi - y1)y <= xi^2 + yi^2 - x1^2 - y1^2`。

その半平面は、`2 dx x + 2 dy y <= C`。 

この方程式は整数演算で維持されるため、浮動小数点エラーが境界点に影響を与えることはありません。 
3. もし`dx = 0`、不等式には何も含まれていません`x`。 いつ`dy > 0`、になります。`y <= (yi + y1) / 2`。

4. もし`dx > 0`の不等式を解きます。`x`:`x <= (C - 2dy * y) / (2dx)`。

5. もし`dx < 0`、割り算は不等式を逆転します。`x >= (2dy * y - C) / (2(-dx))`。 

これは下限ラインです。 これらすべての機能を最大限に活用する必要があります。 2 番目の種類のハルを実装する代わりに、下位のすべての線の否定を保存します。 元の線の最大値は、その否定の最小値の負になります。 
6. すべての有理線を次のように表します。`f(y) = (m*y + b) / d`と`d > 0`。 傾きを小さくして線を並べ替える`m/d`。 傾きが等しい場合、最小の切片を持つ線だけが最小エンベロープとして重要になります。

9. 上部エンベロープを次のように評価します。`y`そしてその数学的床を取得します。 否定された下限エンベロープを評価し、その下限の負の値を取得します。これにより、元の下限の数学的上限が得られます。

## Python ソリューション```python
import sys
input = sys.stdin.readline
from functools import cmp_to_key

def slope_cmp(a, b):
    # Compare a.m / a.d and b.m / b.d, in decreasing order.
    left = a[0] * b[2]
    right = b[0] * a[2]

    if left > right:
        return -1
    if left < right:
        return 1

    # Equal slopes. Smaller intercept first.
    left = a[1] * b[2]
    right = b[1] * a[2]

    if left < right:
        return -1
    if left > right:
        return 1
    return 0

def value_leq(a, b, x):
    # a(x) <= b(x), with both denominators positive.
    left = (a[0] * x + a[1]) * b[2]
    right = (b[0] * x + b[1]) * a[2]
    return left <= right

def redundant(a, b, c):
    # Slopes are strictly decreasing.
    # b is redundant iff intersection(a,b) >= intersection(b,c).

    n1 = b[1] * a[2] - a[1] * b[2]
    d1 = a[0] * b[2] - b[0] * a[2]

    n2 = c[1] * b[2] - b[1] * c[2]
    d2 = b[0] * c[2] - c[0] * b[2]

    return n1 * d2 >= n2 * d1

def build_hull(lines):
    if not lines:
        return []

    lines.sort(key=cmp_to_key(slope_cmp))

    hull = []

    for line in lines:
        if hull:
            last = hull[-1]

            # Same slope. Keep the smaller intercept.
            if line[0] * last[2] == last[0] * line[2]:
                if line[1] * last[2] < last[1] * line[2]:
                    hull[-1] = line
                continue

        while len(hull) >= 2 and redundant(hull[-2], hull[-1], line):
            hull.pop()

        hull.append(line)

    return hull

def solve():
    X, Y, K = map(int, input().split())

    points = [tuple(map(int, input().split())) for _ in range(K)]
    x1, y1 = points[0]

    ymin = 0
    ymax = Y

    upper_lines = []
    lower_lines = []

    base_sq = x1 * x1 + y1 * y1

    for xi, yi in points[1:]:
        dx = xi - x1
        dy = yi - y1
        C = xi * xi + yi * yi - base_sq

        if dx == 0:
            s = xi + x1

            if dy > 0:
                # y <= (yi + y1) / 2
                ymax = min(ymax, s // 2)
            else:
                # y >= (yi + y1) / 2
                ymin = max(ymin, (s + 1) // 2)

        elif dx > 0:
            # x <= (C - 2*dy*y) / (2*dx)
            upper_lines.append((-2 * dy, C, 2 * dx))

        else:
            # x >= (2*dy*y - C) / (2*(-dx))
            #
            # Store the negation:
            # -x_bound = (-2*dy*y + C) / (2*(-dx))
            lower_lines.append((2 * dy, -C, -2 * dx))

    if ymin > ymax:
        print(0)
        return

    upper_hull = build_hull(upper_lines)
    lower_hull = build_hull(lower_lines)

    upper_ptr = 0
    lower_ptr = 0

    answer = 0

    for y in range(ymin, ymax + 1):
        if upper_hull:
            while (
                upper_ptr + 1 < len(upper_hull)
                and value_leq(
                    upper_hull[upper_ptr + 1],
                    upper_hull[upper_ptr],
                    y
                )
            ):
                upper_ptr += 1

            m, b, d = upper_hull[upper_ptr]
            upper_num = m * y + b
            right = upper_num // d
        else:
            right = X

        if lower_hull:
            while (
                lower_ptr + 1 < len(lower_hull)
                and value_leq(
                    lower_hull[lower_ptr + 1],
                    lower_hull[lower_ptr],
                    y
                )
            ):
                lower_ptr += 1

            m, b, d = lower_hull[lower_ptr]
            lower_neg_num = m * y + b

            # Original lower bound is -lower_neg_line.
            # ceil(-z) = -floor(z).
            left = -(lower_neg_num // d)
        else:
            left = 0

        if left < 0:
            left = 0
        if right > X:
            right = X

        if left <= right:
            answer += right - left + 1

    print(answer)

if __name__ == "__main__":
    solve()

3つの支店は、`dx`アルゴリズムからの 3 つの幾何学的ケースに直接対応します。 のために`dx = 0`の場合、制限は純粋に垂直であるため、線は作成されません。 のために`dx > 0`の場合、上限線の分母は正になります。 のために`dx < 0`、乗算`-1`線が否定される前に分母を正にします。 

船体格納庫`(m, b, d)`浮動小数点の傾きと切片の代わりに。 すべての比較では、2 つの分数が相互乗算されます。 座標は次のように大きくできます。`2 * 10^5`、二乗座標はおおよそ到達できます`4 * 10^10`, ただし、Python の整数には任意の精度があるため、オーバーフローの問題はありません。 

の`redundant`テストでは、連続する線の正確な交差座標が使用されます。 船体は厳密に減少する勾配によって並べ替えられるため、これらの交差式の分母は正になります。 これにより、交差座標が負の場合でも交差乗算が有効になります。 

クエリ ポインタは前方にのみ移動します。 行は増加して処理されるため、`y`、最適なラインも、傾斜が一貫して順序付けられた船体内を単調に移動します。 これにより、構築後のすべてのエンベロープ クエリが線形時間に短縮されます。 

床の操作も微妙なポイントだ。 パイソンの`//`は、負の分子を含む数学的な床の除算であり、まさに有理境界が必要とするものです。 否定された下側エンベロープの場合、その値が`z = -g`、必要な整数の下限は次のとおりです。`ceil(g) = -floor(z)`コード内で使用される式について説明します。 

## 実用的な例

 サンプル 1 の場合、`p1 = (2,2)`。 他の 4 つの点は、次の関連する境界を生成します。`(1,1)`与える`x >= 3 - y`。`(1,3)`与える`x >= y - 1`。`(3,3)`与える`x <= 5 - y`。`(3,1)`与える`x <= y + 1`。 

したがって、封筒は`L(y) = max(3-y, y-1)`そして`R(y) = min(5-y, y+1)`。

サンプル 2 の場合、`p1 = (0,0)`そしてあらゆる競争相手は`(i,0)`のために`1 <= i <= 5`。 各競技者が与えるもの`2ix <= i^2`、

または`x <= i/2`。

 と`K, Y <= 2 * 10^5`、ソートは漸近コストを支配します。 アルゴリズムは決して列挙しません`O(XY)`これがブルート フォースとの決定的な違いです。 Python の任意精度の整数は、固定幅の整数を使用する言語で 64 ビット演算を必要とするオーバーフローの問題も解決します。 

## テストケース

 次のテストでは、送信されたソリューションが次のように保存されていることを前提としています。`solution.py`。 ヘルパーは一時的にヘルパーを置き換えます。`input`機能してその出力をキャプチャするため、各アサーションは同じことを実行します`solve()`提出物によって使用されます。```python
import sys
import io
import solution

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout
    old_input = solution.input

    sys.stdin = io.StringIO(inp)
    solution.input = sys.stdin.readline
    sys.stdout = io.StringIO()

    try:
        solution.solve()
        return sys.stdout.getvalue().strip()
    finally:
        solution.input = old_input
        sys.stdin = old_stdin
        sys.stdout = old_stdout

# Provided sample 1
assert run("""\
4 4 5
2 2
1 1
1 3
3 3
3 1
""") == "5", "sample 1"

# Provided sample 2

1 0

4 0
5 0
""") == "7", "sample 2"

# Minimum-size rectangle, only p1.
assert run("""\

0 0
""") == "4", "minimum case"

 ## 特殊なケース

 いつ`K = 1`、行配列は空です。 ハル クエリはスキップされるため、コードでは次を使用します。`left = 0`そして`right = X`行ごとに。 入力用```
1 1 1
0 0
```行間隔は`[0,1]`両方にとって`y = 0`そして`y = 1`、行ごとに 2 ポイントを提供し、生成します`4`。 

競合他社が共有する場合`x`と`p1`、コードは`dx == 0`支店。 のために```
2 4 3
1 2
1 0
1 4
```要点`(1,0)`もっている`dy = -2`, したがって、条件は次のようになります`y >= 1`。 ポイント`(1,4)`もっている`dy = 2`, したがって、条件は次のようになります`y <= 3`。 結果の行間隔は次のようになります。`[1,3]`、各行には 3 つの可能なすべてが含まれます`x`コーディネート。 答えは`9`。 

半整数境界の場合```
2 2 2
1 1
0 1
```競合他社が持っている`dx = -1`、`dy = 0`、下限関数は次のようになります。`1/2`。 下のエンベロープは正確に次のように評価されます。`1/2`、そして Python のフロア分割は次のようになります。`0`変換された値に対して`-1/2`符号変換が正しく処理された後にのみ。 コードは、元の整数の下限を次のように計算します。`1`、有効な行を与える`x = 1,2`3 つそれぞれについて`y`価値観と答え`6`。 

同点が許可されるため、二等分線上に正確に位置する点は良好なままでなければなりません。 サンプル 1 では、`(2,2)`は`p1`それ自体、一方で`(2,1)`そして`(2,3)`関連する二等分線上にあります。 エンベロープの比較では、`<=`, したがって、現在の最良のラインを結ぶラインは、結ばれた座標を除外することなくアクティブになることができます。 

長方形の境界も検索空間の一部です。 計算された下限が負の場合、次のようにクランプされます。`0`、上限を超えた場合`X`に固定されています。`X`。 したがって、長方形を超えて広がるボロノイ セルは、許可されたグリッドの外側にカウントされるのではなく、正しくクリップされます。 

最後に、有効な入力に対して答えがゼロになることはありません。`p1`それ自体は長方形内の整数点であり、それ自体までの距離はゼロです。 実装では一時的に行に空の間隔を取得する場合がありますが、行は`y = y1`常に少なくとも含まれます`x = x1`したがって、合計の答えは少なくとも 1 つです。
