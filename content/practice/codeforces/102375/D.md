 ## 問題の理解

 各候補について、身長、ウイングスパン、1試合あたりの得点、1試合あたりのリバウンド、1試合あたりのアシストという5つの整数統計がわかっています。 各統計には独自の期待間隔があり、候補はその間隔に対してすべての値がどこに位置するかによって判断されます。 

予想される間隔内の値の場合、中間点は上半分に属します。 したがって、上半身になるための 5 つのしきい値は、身長が 205、ウイングスパンが 225、得点が 15、リバウンドが 4、アシストが 5 です。 上限エンドポイントより厳密に大きい値は、予想範囲を超えているとみなされます。 たとえば、高さ 205 はすでに上半分にありますが、高さ 221 は予想範囲を超えています。 

タスクは、すべての候補をカテゴリ 0、1、2、または 3 に分類することです。カテゴリ 0 は最も強い条件を持っているため、最初にチェックする必要があります。 それには、予想される範囲を超える少なくとも 3 つの統計値が必要で、その 3 つのうち身長または翼幅が含まれます。 次にカテゴリ 1、カテゴリ 2 が続きます。どの条件も当てはまらない場合、答えはカテゴリ 3 です。 

入力には最大 32 個の候補が含まれており、各候補には常に 5 つの値が含まれます。 候補ごとに数百の演算を実行するアルゴリズムであっても、快適に高速になります。 並べ替え、動的プログラミング、グラフ アルゴリズム、またはデータ構造は必要ありません。 有用な目標は、候補者ごとに一定の作業を行い、合計時間を O(N) とすることです。

## アプローチ

 文字通りの総当りソリューションでは、5 つの統計のそれぞれを 4 つの状態 (予想間隔未満、下半分、上半分、予想間隔以上) のいずれかに分類できます。 1 つの候補に対して可能な状態の組み合わせは (4^5=1024) 個だけです。 それらをすべて列挙し、各組み合わせがどのカテゴリを受けるかを判断し、候補をそれらのケースと比較することができます。 32 個の候補の最大入力の場合、これは (32\cdot1024=32768) 個の状態チェックだけであるため、この意図的に単純な方法でも、実際の制約に対して十分に高速になります。 

候補者の数が増えると、統計の数が指数関数的に増加するため、魅力的ではなくなります。 5 つの固定統計量の場合、この区別はほとんど理論上のものですが、同じ考えを 20 個の統計量に一般化すると、列挙には (4^{20}) が必要になり、これは約 (1.1\cdot10^{12}) 個の組み合わせになります。 現在の 5 統計量の問題でも、カテゴリ ルールが少数のカウントにのみ依存する場合、状態を列挙する理由はありません。 

重要な観察は、各統計の 2 つのプロパティを決定した後は、正確な値は重要ではないということです。 私たちが知る必要があるのは、それが少なくとも上半分にあるかどうか、そしてそれが予想範囲を厳密に上回っているかどうかだけです。 これらのプロパティを直接数えることができます。 

各候補者について、`high`少なくとも上半分にある統計の数とし、`above`予想範囲を厳密に上回る数値である必要があります。 また、身長や翼幅が予想範囲を超えているかどうかも個別に記憶します。 すべてのカテゴリ条件は、これらのカウントを使用して表現できます。 

第 1 ラウンドのルールには、「すべてのパラメーターが少なくとも予想される範囲内にある」というフレーズが追加されています。 これは、5 つの統計のいずれも下限エンドポイントを下回っていないと言っているのと同じです。 ブール変数を使用してそれを追跡できます。 これらのいくつかのカウンターが利用可能になると、すべてのカテゴリーを直接テストできます。 

状態空間が小さいため、総当たりアプローチは機能しますが、実際の候補が決して到達しない状態に対して作業を実行します。 すべてのルールが少数の集合プロパティにのみ依存するという観察により、問題は候補ごとの比較の数が一定に減少します。

 ## アルゴリズムのチュートリアル

 1. 1 人の候補者の 5 つの統計を読み取ります。 ある候補のカテゴリが別の候補に依存することがないため、候補を独立して処理します。 
2. 各統計について、それが少なくとも上半分のしきい値であるかどうか、および予想される上限のエンドポイントを厳密に上回っているかどうかを判断します。 しきい値はそれぞれ 205、225、15、4、および 5 です。 間の区別`>=`そして`>`中間点は上半分に属しますが、上側の終点はまだ予想される間隔内にあるため、これは不可欠です。 
3. 上半分以上に統計がいくつあるかを数えます。 これに電話してください`high`。 また、予想範囲を厳密に超えている統計がいくつあるかも数えます。 これに電話してください`above`。 
4. 身長または翼幅が予想範囲を超えているかどうかを記録します。 カテゴリ 0 では、これら 2 つの物理測定値のいずれかが上記範囲の統計値に含まれる必要があるため、これが必要になります。 
5. 最初にカテゴリ 0 を確認します。`above >= 3`身長または翼幅のいずれかが予想される範囲を超えています。 ユニコーンはより弱い品質条件も満たすため、最初にテストしますが、カテゴリー 0 が優先されます。 
6. カテゴリ 0 が適用されない場合は、カテゴリ 1 を確認します。その最初の条件は次のとおりです。`above >= 2`と共に`high >= 3`。 2 番目の条件では、すべての統計が少なくとも予想範囲内にあり、少なくとも 3 つの統計が上半分にあることが必要です。 最初の条件は、「2 つ上ともう 1 つが少なくとも上半分」を表現するのに十分です。これは、範囲を超えるすべての値自体が上半分以上のグループに含まれるためです。 
7. カテゴリ 1 が適用されない場合は、カテゴリ 2 を確認します。その最初の条件は次のとおりです。`above >= 1`そして`high >= 2`。 2 番目の条件は単純です。`high >= 3`。 ここでも、予想範囲を超える値は自動的にカウントされます。`high`。 
8. 前述の条件がいずれも満たされない場合、カテゴリ 3 が出力されます。カテゴリは必要な優先順位でチェックされるため、これはまさに残りのケースになります。 

### なぜ効果があるのか

 どの候補者にとっても、`above`は、予想される上限エンドポイントを厳密に上回る統計の数です。`high`は、少なくとも上半分の統計の数と正確に一致します。 別個の物理フラグは、カテゴリ 0 の追加の身長または翼幅要件を正確に捕捉します。その結果、記述された各条件は、分類システム内の対応するルールと同等になります。 カテゴリ 0 はカテゴリ 1 の前にチェックされ、カテゴリ 1 はカテゴリ 2 の前にチェックされ、カテゴリ 3 はいずれも当てはまらない場合にのみ使用されるため、生成されたカテゴリは、すべての候補に対して最も強力に適用可能なカテゴリになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def classify(values):
    lower = [190, 200, 10, 2, 3]
    upper = [220, 250, 20, 6, 7]
    middle = [205, 225, 15, 4, 5]

    high = 0
    above = 0
    all_expected = True

    for i, x in enumerate(values):
        if x < lower[i]:
            all_expected = False

        if x >= middle[i]:
            high += 1

        if x > upper[i]:
            above += 1

    physical_above = values[0] > upper[0] or values[1] > upper[1]

    if above >= 3 and physical_above:
        return 0

    if (above >= 2 and high >= 3) or (all_expected and high >= 3):
        return 1

    if (above >= 1 and high >= 2) or high >= 3:
        return 2

    return 3

def solve():
    n = int(input())
    answer = []

    for _ in range(n):
        values = [int(input()) for _ in range(5)]
        answer.append(str(classify(values)))

    sys.stdout.write("\n".join(answer))

if __name__ == "__main__":
    solve()
```配列`lower`、`upper`、 そして`middle`5 つの境界を入力値と同じ順序で保存します。 しきい値を 5 つの統計量と明示的に一致させることで、5 つの個別の比較コードを必要とするのではなく、分類ロジックが均一になります。`all_expected`true として開始され、値が予想される間隔を下回るとすぐに false になります。 これは 2 番目のカテゴリー 1 の条件を直接表しており、すべての統計が少なくともその予想範囲の下限値であることが必要です。 

表現`x >= middle[i]`中間点を含む上半分をカウントします。 表現`x > upper[i]`それを超える予想範囲外の値のみをカウントします。 これらの比較を交換したり、間違った方向に厳密にしたりしてはなりません。 

の`physical_above`ユニコーン ルールでは、これら 2 つの統計値のうちの 1 つがその範囲を超えていることが特に要求されるため、条件では身長と翼幅のみが検査されます。 少なくとも 1 つが条件を満たす場合、どれがどれであるかを知る必要はありません。 

Python では整数オーバーフローの懸念はなく、固定幅の整数を使用する言語であっても、ここでのすべてのカウンターは最大 5 です。 入力には候補ごとにちょうど 5 行が含まれるため、リスト内包表記では現在の候補に属する値が正確に読み取られます。
