## アプローチ

重要な点は、要素の削除は 2 つの可能な方法でのみ個別の値の数に影響を与えるということです。 削除された値に周波数がある場合$1$の場合、個別の値の数は 1 つ減少します。 それ以外の場合は、同じままです。 つまり、それぞれのポジションが$i$かどうかを効果的にエンコードする$b_i$ユニークな出来事であるかどうか、したがって$a_i$かどうかだけを伝えます$b_i$シングルトン、または繰り返される値グループの一部です。

 ## アルゴリズムのチュートリアル

 解決策は配列の解釈に依存します$a$ポジションを 2 つの行動タイプに分類します。 

1. 要素を削除すると、その要素がその値の一意の出現である場合にのみ、個別の値の数が変化することがわかります。 これはあらゆるポジションを意味します$i$値が一意であるか反復されているかどうかのみに基づいてエンコードします。$a_i$の個別の値のグローバル数とは異なります$b$。 
2. すべてのポジションは次のとおりであると推測します。$b$少なくとも頻度のある値に属する$2$要素を削除しても個別のカウントが変更されないインデックスに対応する必要があります。 すべてのシングルトン値は、削除するとカウントが 1 つ減るインデックスに対応します。 
3. これにより、$a_i$すべてのインデックスにわたって最大 2 つの異なる値を取ること。 3 つ以上の異なる値が表示される場合、$a$、マルチセットは制約を満たすことができません。 
4. 最大値を入力します$a$完全な配列内の個別の要素の数に対応します$b$。 これは、シングルトンを削除すると個別のカウントが減少するため、可能な限り最大の$a_i$削除しても固有の要素が除去されない位置に対応します。 
5. 個別の値のグローバル数が決まると$k$が修正されているため、分割します$n$シングルトン除去と非シングルトン除去に対応する位置に配置します。 シングルトン位置の数を次のようにします。$s$。 
6. 残りの部分$k$個別の値は、正確に次のような位置に割り当てる必要があります。$s$そのうちのはシングルトンであり、残りは少なくとも周波数に寄与します$2$。 どの値がシングルトンであるかを選択する方法の数は組み合わせであり、各選択肢について、星とバーを使用して残りの値に追加の出現を分配します。 
7. 二項係数を効率的に計算するために階乗と逆階乗を事前計算し、すべての有効な分割を合計します。 

### なぜ効果があるのか

 不変条件は、次の各値が$b$のすべてのポジションに一定の貢献をするか、$a$、または、一意である場合にのみ削除されると貢献度が減ります。 これにより、構造が 2 つの安定した領域、つまりシングルトンによる変更と安定した繰り返し値の削除に分割されます。 すべての有効な構成は、すべての位置にわたってこの二分法を一貫して保持する必要があるため、問題全体は、シングルトン値クラスと非シングルトン値クラスの固定分割の下で一貫した周波数割り当てをカウントすることに帰着します。 これにより、頻度数を超えた位置間の隠れた依存関係が防止され、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAXN = 300000 + 5

fact = [1] * MAXN
invfact = [1] * MAXN

for i in range(1, MAXN):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAXN - 1] = pow(fact[MAXN - 1], MOD - 2, MOD)
for i in range(MAXN - 2, -1, -1):
    invfact[i] = invfact[i + 1] * (i + 1) % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    mx = max(a)
    mn = min(a)

    if mx == mn:
        print(1)
        continue

    cnt = {}
    for x in a:
        cnt[x] = cnt.get(x, 0) + 1

    # number of positions with max value (non-changing removals)
    k = cnt[mx]
    s = n - k

    ans = 0
    for singles in range(0, k + 1):
        ways_choose_singles = C(k, singles)
        ways_assign = C(n - singles - 1, k - 1) if k - 1 <= n - singles - 1 else 0
        ans = (ans + ways_choose_singles * ways_assign) % MOD

    print(ans)
```階乗事前計算は、クエリごとに一定時間で二項係数を返すために使用されます。 メインループは、シングルトン動作に対応する位置の数と、安定した削除に対応する位置の数を計算します。 

主要な実装の詳細は、最大値の頻度を分離することです。$a$、変化しない除去の数のアンカーとして機能します。 そこから、そのうちのいくつが実際のシングルトン値の位置に対応するかを列挙します。$b$、組み合わせの配置を計算します。 

負のパラメータまたは範囲外のパラメータはゼロを寄与する必要があるため、残りの出現を分散するときに無効な二項引数を避けるように注意する必要があります。
