 ## 解決策
 ## 問題の理解

 無向接続グラフ上で進化するプロセスが与えられています。$n$頂点。 プロセスは一連の整数に依存します$a_1, a_2, \dots, a_m$、これは「時間の経過とともに距離がジャンプする」と考えることができます。 

開始頂点が選択され、0 日目にペイントされたものとしてマークされます。その後、毎日、$i$、すでにペイントされている頂点までの最短パス距離が正確に一致するすべての頂点$a_i$塗装になります。 頂点は一度ペイントされると永久にペイントされたままになるため、ペイントされた頂点のセットは増加するだけです。 

質問は特定のグラフに関するものではありません。 代わりに、グラフに最適な開始頂点を選択できる場合に、この一連の距離ルールが、接続されているすべてのグラフを完全にカバーすることを保証するのに十分強力であるかどうかを尋ねられます。 答えが「はい」の場合は、「SI」を出力します。 それ以外の場合は、接続されたグラフを構築する必要があります。$n$どの開始頂点が選択されても、プロセスがすべての頂点をペイントすることができないような頂点です。 

制約は小さいです。$n \le 100$、$m \le 100$、すべてのテスト ケースの合計は最大 1000 です。これは、構造グラフのプロパティと単純な構造の観点から考えることができることを意味します。 何でも$O(n^2)$または$O(nm)$テストケースごとの処理は快適に高速です。 

微妙な点は、プロセスが距離によってのみ駆動されるということです。 グラフの構造は最短経路距離によってのみ重要となるため、攻撃者はグラフ メトリックの制約内で任意の距離メトリックのように動作するグラフを自由に構築できます。 

主な困難は、距離レイヤーのシーケンスがすべての可能なグラフで完全な BFS のような拡張を「シミュレート」できるかどうか、またはそれを永続的にブロックする何らかのグラフ ジオメトリが存在するかどうかを理解することにあります。 

いくつかの特殊なケースは、プロセスの性質を明確にするのに役立ちます。 

もし$a = [1]$次に、任意の頂点から開始して、すぐに隣接するすべての頂点をペイントし、次のステップで、ペイントされたフロンティア全体から 1 つのエッジを外側に拡張し続けます。 これはまさに BFS 拡張であり、接続されたグラフ上では最終的にはすべてに到達します。 

代わりに$a = [2]$、グラフは単純なパスであり、1 つの端点から開始して、開始点から等距離にある頂点のみを描画します。 The opposite parity layer never appears, so half the graph remains unpainted.

 These examples suggest that the value$1$は、エッジに沿って直接伝播し、完全な到達可能性を保証する唯一の距離であるため、特別な役割を果たします。 

## アプローチ

 ブルートフォース解釈では、固定グラフに対して考えられるすべての開始頂点を試し、描画プロセスを段階的にシミュレートします。 各シミュレーションでは、現在ペイントされているセットからすべての頂点までの距離を計算する必要があります。これは、BFS のような更新または 1 日あたりのマルチソース BFS を使用して実行できます。 これにはすでに約$O(mn^2)$単純な実装では開始頂点ごとに計算され、グローバルに推論しようとするとすべてのグラフで乗算されます。 これは概念的に必要なものをはるかに超えています。 

本当の変化は、接続されているすべてのグラフにわたって条件が普遍的であることを観察することから生まれます。 つまり、単一のグラフを分析しているわけではありません。 代わりに、敵対的な距離ジオメトリの下でもシーケンスが最終的なカバレッジを強制するかどうかを尋ねています。 

重要な観察点は、値が$1$他のすべての距離とは根本的に異なります。 頂点がペイントされると、次の操作が行われます。$a_i = 1$ペイントされたすべての頂点の隣接するすべての頂点にペイントが即座に広がります。 その時点から、プロセスは初期シード セットからの標準的な BFS 拡張になります。 グラフは接続されているため、空ではないセットからの BFS は最終的にコンポーネント全体に到達します。 

これは、シーケンスに少なくとも 1 つが含まれる場合、$1$、グラフに関係なく、プロセスは常に成功します。 最初のステップでは複雑なサブセットが描かれるかもしれませんが、最初に発生するのは$1$プロセスを完全なグラフ フラッディングに変換します。 

いいえの場合$1$存在する場合、すべてのステップで少なくとも$2$。 この体制では、プロセスがグラフの一部と永続的に「位相がずれている」グラフを構築できます。 シンプルで堅牢な構造はパス グラフです。 パス上では、距離はラインに沿った絶対的な差のように動作します。 距離がなければ$1$の場合、プロセスは、すべての開始点のカバレッジを保証する方法で、部分的に満たされたセットから隣接するレイヤーに確実に伝播することができません。 あるレイヤーが最初からアクティブにならないように、いつでも頂点を配置できます。 

したがって、決定は単純な条件に帰着します。$1$シーケンスに登場します。

 ## アルゴリズムのチュートリアル

 ### 最適な戦略

 1.読む$n$そしてそのシーケンス$a_1, \dots, a_m$。 の値$n$必要に応じて反例を構築する場合にのみ関係し、答えを決定する場合には関係しません。 
2. シーケンスをスキャンし、値が等しいかどうかを確認します。$1$。 これがプロセスにとって重要な唯一の構造特性です。 
3. もし、$1$存在する場合は「SI」を出力します。 単位距離の伝播ステップが現れると、接続されたすべてのグラフが完全に描画されるため、構築する必要はありません。 
4. いいえの場合$1$存在する場合は、プロセスを中断する単純な接続グラフを構築します。 上のパス$n$頂点だけで十分です。 そのエッジを出力します$(0,1), (1,2), \dots, (n-2,n-1)$。 

### なぜ効果があるのか

 不変条件は、距離のないすべての伝播ステップです。$1$少なくとも次の「距離粒度」を維持する$2$。 これにより、どのグラフでも、部分的にペイントされた領域からの隣接レベルの拡散が保証されなくなります。 瞬間$1$が表示されると、ペイントされたすべての頂点がそのすぐ隣の頂点のソースとなり、接続によって最終的に完全なカバレッジが強制されるため、この不変条件は消えます。 

したがって、シーケンスは、単位ステップが含まれている場合にのみ、一般的に成功します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        
        if 1 in a:
            print("SI")
        else:
            print("NO")
            # construct a simple path graph
            print(n - 1)
            for i in range(n - 1):
                print(i, i + 1)

if __name__ == "__main__":
    solve()
```この実装では、テスト ケースごとにリニア スキャンのみが実行されます。 とき$1$見つかった場合は、すぐにプランを承諾します。 それ以外の場合は、接続されて最小であることが保証されるパス グラフを出力します。 

ここでよくある間違いは、ペイント プロセスをシミュレートしようとすることです。 答えは、他の距離の詳細な相互作用ではなく、単位距離の伝播が存在するかどうかのみに依存するため、これは不要です。 

## 実用的な例

 次の場合を考えてみましょう$n = 6$、$a = [4, 1, 2, 3, 5]$。 

| ステップ | シーケンスチェック | 決定 |
 | --- | --- | --- |
 | スキャン | 1を参照 | 受け入れる |

 以来$1$存在する場合は「SI」を出力します。 その理由は、最終的にプロセスには、ペイントされたすべての頂点のすべての隣接点に広がるステップが含まれ、接続が完全にカバーされるようにするためです。 

ここで考えてみましょう$n = 5$、$a = [2, 4, 3]$。 

| ステップ | シーケンスチェック | 決定 |

 | スキャン | 1 が見つかりません | パスを構築する |

 パスグラフを出力します$0-1-2-3-4$。 どの開始頂点からでも、単位距離の伝播が存在しないため、プロセスがすべての構成にわたってすべての頂点を確実に埋めることができなくなります。

 ## 特殊なケース

 シーケンスに 1 より大きい値のみが含まれている場合、アルゴリズムは常にパスを出力します。 たとえば、$n = 4$そして$a = [2,2]$、出力はチェーンです$0-1-2-3$。 任意の頂点から開始すると、ユニットの伝播がないため、プロセスがすべてのグラフにわたる完全なカバレッジを保証できないため、固定された単純な接続構造を返すだけで十分です。 

もし$n = 2$、パスの構築は引き続き正しく機能し、単一のエッジが生成されます。 これは最小の接続グラフであり、接続されていない場合は必ず反例として正しく機能します。$1$が存在します。 

もし$1$などの長いシーケンスのどこにでも現れます。$[3, 7, 1, 5]$、アルゴリズムは引き続きすぐに受け入れます。 単位距離の伝播が利用可能になると、接続により、空ではないペイントされたセットから最終的に完全にカバーされることが保証されるため、後の値は重要ではありません。
