 ## 問題の理解

 あります$n$オリンピックに参加する参加者。 各参加者$i$等差数列を形成する一定の時刻に開始します: 最初の時刻が開始します$0$、2番目の時間$x$、3番目の$2x$、など、参加者$i$から始まります$(i-1)x$。 

すべての参加者が正確に支出します$t$コンテストの執筆分なので、参加者は$i$時間通りに終わる$(i-1)x + t$。 

参加者が終了すると、その時点でまだコンテストに参加している他の参加者が何人いるかを確認します。 参加者は、すでに開始しているがまだ終了していない場合、アクティブであるとみなされます。 参加者の「不満」$i$間隔が時間と重なる他の参加者の数です$(i-1)x + t$。 

タスクは、参加者全員の不満の合計を計算することです。 

制約は非常に大きく、$n$まで$2 \cdot 10^9$。 これにより、参加者を個別にシミュレートしたり、ペアごとに重複をチェックしたりするソリューションは即座に除外されます。 たとえ$O(n)$解決策は何十億もの操作が必要となるため、非常に遅すぎます。 

時間構造も均一です。すべての参加者は同じ間隔の長さを持ちます。$t$、開始点は次のように等間隔に配置されます。$x$。 この強い規則性は、オーバーラップ数が個々のシミュレーションではなく、相対的な位置にのみ依存することを示唆しています。 

間隔の間隔が継続時間の大半を占める場合、微妙なエッジ ケースが発生します。 もし$t < x$の場合、終了時刻に将来の参加者と重複する参加者は存在しません。 

たとえば、次の場合$x = 10$、$t = 3$、 そして$n = 5$、各参加者は次の参加者が開始する前に終了するため、答えは次のようになります。$0$。 単純なシミュレーションでは、オーバーラップをカウントしようとしても、コストのかかる作業の後には何も検出されない可能性があります。 

もう 1 つのエッジケースは次のような場合です$t$に比べて非常に大きいです$x$。 次に、各参加者は、後続の多くの参加者 (潜在的にはほぼすべての参加者) と重複し、定数時間で計算する必要があるにもかかわらず、合計は構造的に二次関数的に増加します。 

## アプローチ

 直接シミュレーションでは、参加者ごとに計算が行われます。$i$、時間と重なる間隔の数$(i-1)x + t$。 これには、他のすべての参加者をスキャンし、開始がその時間より前であり、終了がそれ以降であるかどうかを確認する必要があります。 これにより、$O(n^2)$それぞれの場合、最悪の場合の動作$n$スキャンできる参加者$n$その他。 と$n$まで$2 \cdot 10^9$、これは不可能です。 

重要な観察は、構造が完全に均一であるということです。 すべての参加者のインターバルの長さは同じです$t$、開始点は等間隔です。 したがって、個々の間隔について推論する代わりに、条件をインデックスの不等式に変換できます。 

参加者の終了時$i$、私たちは参加者のみを考慮します$j > i$、同じ期間と厳密に早い開始時間により、早い参加者はその時点までにすでに終了しているためです。 後の参加者のうち、終了時刻以前または終了時刻に開始した参加者のみ$i$貢献する。 

これにより、開始ステップの数によって決まる固定サイズのスライディング ウィンドウ内にインデックスがいくつあるかを数えるという問題が軽減されます。$t$、つまり$\lfloor t / x \rfloor$。 

この削減が行われると、答えは単純な区分線形関数の閉形式の合計になります。

 ## アルゴリズムのチュートリアル

 しましょう$k = \left\lfloor \frac{t}{x} \right\rfloor$。 この値は、サイズの完全な開始間隔の数を表します。$x$期間内に収まる$t$。 

1. 終了時刻における参加者の重複条件を書き換える$i$。 参加者$j$間隔がカバーされていれば貢献します$(i-1)x + t$。 これにより、次の 2 つの不等式が得られます。$j > i$そして$(j-1)x \le (i-1)x + t$。 
2. 2 番目の不等式を減算して単純化します。$(i-1)x$、降伏$(j-i)x \le t$。 Since all values are integers, this becomes$j - i \le k$。 
3. 両方の制約を結合します。 参加者の有効な貢献者$i$まさに、$$i < j \le i + k$$有効範囲と交差しています$1 \le j \le n$。 

1. これをカウントに変換します。$$\text{discontent}_i = \min(k, n - i)$$せいぜいあるから$k$将来の参加者は範囲内にいますが、最大でも$n - i$実際の残りの参加者。 

1.全体を合計する$i$:$$\sum_{i=1}^{n} \min(k, n-i)$$1. 合計を 2 つの領域に分割します。 のために$i \le n-k$、値は常に$k$。 のために$i > n-k$から直線的に減少します。$k-1$まで$0$。 
2. 以下を計算します。 

もし$k \ge n$とすると、すべての項は次のようになります。$n-i$、与える$\frac{n(n-1)}{2}$。 

さもないと：$$(n-k)\cdot k + \frac{k(k-1)}{2}$$### なぜ効果があるのか

 このアルゴリズムは、終了時のオーバーラップが絶対時間ではなく相対インデックス距離のみに依存するという事実に基づいています。 すべての参加者には最大でも次の「ウィンドウ」が表示されます。$k$その後の参加者はまだアクティブです。 開始時間は等間隔であるため、このウィンドウの形状はすべての時間で同じになります。$i$、ずらしただけです。 この不変性により、動的な重複問題が決定論的な算術和に変わります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    x = int(input().strip())
    t = int(input().strip())

    k = t // x

    if k == 0:
        print(0)
        return

    if k >= n:
        print(n * (n - 1) // 2)
        return

    ans = (n - k) * k + k * (k - 1) // 2
    print(ans)

if __name__ == "__main__":
    solve()
```実装の核心は単一パラメータへの削減です。$k$。 一度$k$が計算されると、すべての動作がシミュレーションなしで決定されます。 2 つの分岐は、「オーバーラップ ウィンドウ」が参加者の範囲全体よりも大きいかどうかを処理します。 算術公式は、定数の接頭辞とそれに続く減少する尾部の合計から直接得られます。 

整数の除算には注意が必要です。$k = t // x$すべてのパラメータが整数であり、内部に収まる最大の整数のフル シフトのみが必要なため、これは有効です。$t$。

 ## 特殊なケース

 いつ$k = 0$の場合、アルゴリズムはすぐにゼロを返します。 これは以下に対応します$t < x$つまり、各参加者は、後の参加者が開始する前に終了します。 入力用$n=5, x=10, t=3$、私たちは得ます$k=0$、終了時刻に重複する間隔がないため、すべての不満値はゼロになります。 

いつ$k \ge n$、すべての参加者には、終了時刻になってもまだアクティブな後続の参加者がすべて表示されます。 のために$n=4, x=1, t=100$、私たちは得ます$k=100 \ge n$、したがって、答えは次のようになります$4 \cdot 3 / 2 = 6$。 これは、参加者 1 には他の 3 人が表示され、参加者 2 には 2 人が表示され、参加者 3 には 1 人が表示され、参加者 4 には何も表示されないという事実と一致します。 

いつ$k = n-1$、構造は一定の動作から三角形の動作にスムーズに移行します。 のために$n=4, x=1, t=3$、私たちは得ます$k=3$、そして貢献は$3,2,1,0$、正しく合計すると、$6$。 これは、定数の接頭辞と減少する接尾辞の間の分割の正確さをチェックします。
