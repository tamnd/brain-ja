 ## 解決策
 ## 問題の理解

 整数の配列が与えられ、位置ごとに値を置き換える変換を繰り返し適用できます。$x$と$-x-1$。 これを 2 回適用すると元の値が返されるため、各要素は事実上、それ自体またはその変換されたバージョンの 2 つの最終状態のみを持ちます。 

タスクは、すべての最終的な配列値の積ができるだけ大きくなるように、到達可能な 2 つの値のどちらになるかを位置ごとに独立して選択することです。 次に、その最大積を達成する配列を出力します。 

制約$n \le 10^5$線形または線形に近い解決策を強制します。 組み合わせのチェックや選択肢のグローバルなシミュレーションなど、要素間のペアごとの相互作用を伴うものはすべて、すぐに遅くなりすぎます。$O(n^2)$すでに$10^{10}$操作。 

ここではいくつかの微妙なケースが重要です。 すべての数値が正の場合、変換により負の値が生成される可能性があり、製品に悪影響を与える可能性があるため、変換を回避することが期待されます。 数値が負の場合、変換することで数値を正にすることができ、製品が大幅に改善されます。 ゼロは変身するため特別な振る舞いをします。$-1$これは乗算には悪影響を与えるため、通常は変更しないでください。 主な問題は、製品の最適化ではグローバルにバランス サインが必要になることが多く、これは決定間の結合を示唆する可能性がありますが、ここでは各要素が 2 つの独立した状態しか持たないため、構造が単純化されます。 

## アプローチ

 ブルートフォースアプローチでは、選択肢のあらゆる組み合わせを試行し、各要素を二者択一の決定として扱います。$a_i$そして$-a_i-1$。 これは次のことにつながります$2^n$可能な配列。 たとえ$n = 30$、これは実行不可能になり、$n = 10^5$それはまったく不可能です。 すべての可能性を列挙しているため、正しさは明らかですが、指数関数的に増加するため使用できなくなります。 

重要な観察は、有害なグローバルな相互作用を引き起こすことなく、各要素をローカルで最適化できることです。 変換はインボリューティブです。つまり、各値には 2 つのオプションがあり、それ以上の構造はありません。 各インデックスの 2 つの候補を比較します: 元の値$a_i$、および変換された値$-a_i - 1$。 驚くべきことに、すべてのインデックスに対してこれら 2 つの値のうち大きい方を個別に選択するだけで十分であるということです。 

これが機能する理由は、選択された値が常に負ではない、または最悪の場合でもゼロであり、符号の競合が完全に排除されるためです。 すべての数値が負でなくなると、単一の因子を増加しても積を減らすことはできないため、積を最大化することは各因子を個別に最大化することになります。

 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^n \cdot n)$|$O(n)$| 遅すぎる |
 | 最適 |$O(n)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1.各要素について$a_i$、その変換された値を計算します$b_i = -a_i - 1$。 これは、から到達可能な唯一の代替状態をキャプチャします。$a_i$したがって、要素ごとの決定空間を完全に列挙します。 
2. 比較する$a_i$そして$b_i$をクリックして、大きい方を選択します。 これにより、選択された値が常に最終製品に対する最良の局所的寄与となることが保証されます。 
3. 選択した値を結果配列に保存します。 各ポジションは独立して決定されるため、以前の選択を再度検討する必要はありません。 
4. すべての要素を処理した後、結果の配列を出力します。 

### なぜ効果があるのか

 各要素には到達可能な値が 2 つだけあり、2 つの最大値を選択すると、選択されたすべての値が可能な限り大きくなることが保証されます。 変換ではインデックス間の独立性が維持されるため、ある位置の選択を別の位置とリンクする制約はありません。 選択された各値がそのペアの大きい方であることを確認すると、最終的な配列はコンポーネントごとに最大になります。この選択ルールの後は、選択されたすべての値が負ではないため、単一の要素を増加しても積が増加または維持されるだけです。 これにより、符号やパリティに対するグローバルな最適化の必要がなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    res = []
    for x in a:
        y = -x - 1
        if x >= y:
            res.append(x)
        else:
            res.append(y)
    
    print(*res)

if __name__ == "__main__":
    solve()
```この実装は、各インデックスが独立しているという観察に直接基づいています。 すべての要素について、考えられる 2 つの状態を計算し、大きい方を選択します。 比較では、負の値、ゼロ、正の数値を含むすべてのエッジ ケースが暗黙的に処理されます。 グローバルな制約がないため、追加の簿記は必要ありません。

 ## 特殊なケース

 主なエッジケースは、値が次のような場合です。$-1$。 この場合、変換により次の結果が得られます。$0$、ゼロは符号の問題を引き起こさず、より大きいため、製品にとっては厳密に優れています。$-1$。 アルゴリズムはすべてのデータを正しく変換します。$-1$の中へ$0$、これは製品を最大化することに一致します。 

もう 1 つの微妙なケースは、ゼロそのものです。 ゼロが変身する$-1$、これは価値と製品への貢献の両方で悪いため、アルゴリズムはそれを変更しないようにします。 これにより、全体の結果を低下させる負の要素を導入するのではなく、ゼロが最終製品において中立的な要素として機能することが保証されます。
