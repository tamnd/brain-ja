 ## 問題の理解

制約により許可されるのは、`n`すべてのテスト ケースで最大 200,000 件なので、これより悪いソリューションはありません`O(n log n)`テストケースごとにタイムアウトになる可能性があります。 これにより、あらゆる可能性を試すことができなくなります`b`配列を使用したり、すべての値の距離を単純に繰り返しチェックしたりすることもできます。 エッジ ケースには、すべての要素が等しいか、厳密に増加している配列が含まれます。 このような場合、アルゴリズムが不連続な位置に値を出現させることを許可しない場合、単純な選択により最大の美しさが過小評価される可能性があります。

 ## アルゴリズムのチュートリアル

 1. 2 つの配列を初期化する`first_pos`そして`last_pos`サイズの`n+1`各数値が表示される左端と右端のインデックスを保存します。 それらを埋める`-1`初期化されていないことを示します。 
2. 配列を反復処理する`a`。 それぞれについて`i`そして`a_i`、あらゆる数字を考慮してください`x`1から`a_i`。 それぞれについて`x`、 もし`first_pos[x]`は`-1`に設定します。`i`。 常に設定する`last_pos[x]`に`i`。 これにより、すべての有効な`x`、配置できる最も古い位置と最も新しい位置を追跡します。 
3. 変数を初期化する`beauty = 0`。 すべての数値を反復処理する`x`1から`n`。 もし`first_pos[x] != -1`、 追加`last_pos[x] - first_pos[x]`に`beauty`。 この合計は、全体の美しさに対する各数値の可能な最大の貢献です。 
4. 結果を印刷または保存します。`beauty`テストケースごとに。 

機能する理由: 各値が配置される左端と右端の位置を記録することによって`x`合法的に配置される可能性がある場合、その番号に対して可能な最大距離を捕捉することを保証します。 すべての数値の合計はすべての寄与を正確に考慮しており、他の数値の配置によってこれらのエンドポイントを超えて距離を増やすことはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        first_pos = [-1] * (n + 1)
        last_pos = [-1] * (n + 1)
        
        for i, val in enumerate(a):
            for x in range(1, val + 1):
                if first_pos[x] == -1:
                    first_pos[x] = i
                last_pos[x] = i
        
        beauty = 0
        for x in range(1, n + 1):
            if first_pos[x] != -1:
                beauty += last_pos[x] - first_pos[x]
        print(beauty)
```外側のループは複数のテスト ケースを効率的に処理します。 ネストされたループオーバー`x`1から`a_i`によって課された制限まで、すべての番号の潜在的なポジションを確実に記録します。`a_i`。 引き算`last_pos[x] - first_pos[x]`は正確に次の距離です`x`。 への初期化`-1`存在しない数字を数えるのを防ぎます。
