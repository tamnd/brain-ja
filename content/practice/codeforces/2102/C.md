 ## 解決策
 ## 問題の理解

 以下のすべての整数を配置するように求められます。$0$に$n^2 - 1$に$n \times n$グリッド。各数値は 1 回だけ使用されます。 グリッドを構築した後、考えられるすべてのサブ長方形を考慮し、そのサブ長方形内に現れない最小の非負の整数である MEX を計算します。 目的は、すべての部分長方形の MEX 値の合計ができるだけ大きくなるように数値を配置することです。 

これについて考える重要な方法は、小さな値が不釣り合いな影響を与えるということです。 部分長方形は少なくとも貢献します$k$すべての値が含まれる場合にのみ合計に変換します。$0$に$k-1$。 したがって、小さな数値の配置によってほぼすべてが決まりますが、大きな数値は多くのサブグリッドの MEX 値にほとんど影響しません。 

入力は複数の独立したテスト ケースで構成され、それぞれにグリッド サイズが与えられます。$n$。 すべての合計$n$テスト ケース全体の数は最大 1000 なので、$O(n^2)$テストケースごとに構築します。 サブグリッドを明示的に評価したり、サブグリッドごとに MEX 値を計算したりするソリューションは不可能です。$O(n^4)$サブ長方形。 

単純な考え方による微妙な失敗例は、ランダム性または単純な行単位の充填で十分であると仮定することです。 たとえば、行ごとに次のように入力します。$0,1,2,\dots$小さな数値を水平方向に近接して配置しますが、垂直方向のコンパクトさは無視します。 部分四角形は両方の次元に依存するため、線形順序付けよりも両方の軸の小さな値をクラスタリングすることが重要です。 

## アプローチ

 強引なアイデアは、次のすべての順列を試してみることです。$n^2$数値を計算し、各取り決めの合計 MEX 寄与を計算します。 たとえ 1 つのアレンジメントのスコアを計算できたとしても、$O(n^4)$、順列の数は$(n^2)!$、それは完全に不可能です。 

何が MEX 合計を増加させるのかを再解釈すると、この問題は扱いやすくなります。 各整数$x$すべての数値を含むサブ四角形内でのみプラスに寄与します。$0$を通して$x$。 したがって、小さな値の寄与を最大化するには、できるだけ多くのサブ四角形でカバーされる位置にそれらの値を表示する必要があります。 

位置のセル$(i,j)$まさに含まれています$i(n-i+1) \cdot j(n-j+1)$サブ長方形。 これはグリッドの中心で最大化されます。 したがって、最適な戦略は、小さい数値を中心近くに配置し、大きい数値を境界近くに配置することです。 すべてのグリッドの中で重要なのは、中心から外側に拡張する順序であり、「カバレッジ寄与度」の大きい順に番号を割り当てます。 

これにより、中心からの距離に基づいてセルを順序付けし、それらを貪欲に埋めることに基づいた構造が得られます。$0$最も「中央」のセルでは、$1$、 それから$2$、 等々。 これにより、数値のすべての接頭辞が可能な限り最も価値のある領域を占めるようになり、小さな値が一緒に含まれる部分四角形の数が最大化されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 順列に対するブルートフォース |$O((n^2)! \cdot n^4)$|$O(n^2)$| 遅すぎる |
 | センターアウトの貪欲な配置 |$O(n^2 \log n)$または$O(n^2)$|$O(n^2)$| 承認済み |

 ## アルゴリズムのチュートリアル

 以下から番号を割り当ててグリッドを構築します。$0$「重要度」の降順でセルに上向きに移動します。ここで、重要度はセルを含むサブ四角形の数です。 

1. すべてのセルについて$(i, j)$、その寄与を計算します$c(i,j) = i(n-i+1)\cdot j(n-j+1)$。 これは、そのセルが含まれるサブ四角形の数を測定するため、小さい数値がどれほど価値があるかを反映します。 
2. すべてのセルを降順に並べ替えます。$c(i,j)$。 2 つのセルの値が等しい場合、それらは対称的に寄与するため、それらの間の順序は問題ありません。 
3. 並べ替えられたリストを繰り返し、次から始まる値を割り当てます。$0$、次の各整数を次に最も価値のあるセルに配置します。 
4. 結果のグリッドを出力します。 

カバレッジを明示的に計算する理由は、MEX がすべての小さな数値を同時に含むサブ四角形の数に依存するためです。 カバレッジの高いセルに小さな数値を配置すると、必要な値がすべて一緒に表示されるサブ四角形の数が最大になります。 

### なぜ効果があるのか

 重要な不変条件は、最初のオブジェクトを配置した後、$k$数字、それらは$k$サブ長方形のカバレッジが最も高いセル。 これらすべてを含むサブ四角形$k$値はこれらの高カバレッジ位置のすべてと交差する必要があるため、個々のカバレッジを最大化すると、少なくとも寄与するサブ四角形の数が最大化されます。$k+1$MEX合計に換算します。 MEX 合計はプレフィックスを含む部分長方形の数に分解できるため、$[0..x]$、この方法で各プレフィックスを貪欲に最適化すると、全体的に最適な配置が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        
        cells = []
        for i in range(n):
            for j in range(n):
                # 1-indexed formula for subrectangle coverage
                x = (i + 1) * (n - i) * (j + 1) * (n - j)
                cells.append((x, i, j))
        
        cells.sort(reverse=True)
        
        grid = [[0] * n for _ in range(n)]
        
        val = 0
        for _, i, j in cells:
            grid[i][j] = val
            val += 1
        
        for row in grid:
            print(*row)

if __name__ == "__main__":
    solve()
```この構築では、セルごとに、そのセルが含まれる部分四角形の数を計算します。 これは、小さな値を配置する頻度がサブグリッドの MEX に影響を与える頻度を直接測定するため、重要なスコアリング関数です。 このスコアで並べ替えると、中央のセルが最初に入力されるようになります。 

この数式では、1 ずつインデックスが付けられた座標を使用して、1 つずつずれたエラーを回避します。行内のセル$i$(0 から始まる) は次の一部です$(i+1)(n-i)$垂直セグメントの端点の選択、および列の場合も同様です。 

よくある間違いは、行と列の寄与が独立して乗算されることを忘れていることです。 もう 1 つは、0 インデックス付き数式と 1 インデックス付き数式を混合することです。これにより、重み付けがシフトされ、最適な順序付けが崩れます。

def run(inp: str) -> str:

    import sys
    input = sys.stdin.readline

    out = []

        n = int(input())
        cells = []
        for i in range(n):

            out.append(" ".join(map(str, r)))

 ## 特殊なケース

 のために$n=1$、セルと値は 1 つだけです。 アルゴリズムはカバレッジを次のように計算します。$1$、値を代入します$0$、そして正しい自明なグリッドを出力します。 

偶数の場合$n$、単一の中心セルがないため、複数のセルが同じ最大カバレッジを共有します。 並べ替えは同順位で安定しており、等しい値間の順序付けは正確さに影響を与えないため、アルゴリズムはこれを自然に処理します。 

大型用$n$、カバレッジ値は大きくなる可能性がありますが、常に Python 整数に収まります。 順序は一貫しており、建設は引き続き実行されます$O(n^2 \log n)$、制約を変更せずに一致させます。
