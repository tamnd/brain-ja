 ## 解決策
 ## 問題の理解

 一連のチョコレート バーの購入があり、それぞれが特定の数のポイントを獲得します。 Vasya は 0 ポイントからスタートし、バーごとに賞品センターに行くことができます。 賞品には固定ポイントのコストがあり、マグカップ、タオル、バッグ、自転車、車の順に厳密に増加しています。 Vasya は貪欲な戦略を適用します。賞品を買うのに十分なポイントがあるときはいつでも、買える範囲で最も高価なものを選び、ポイントを減らし、賞品を買えなくなるまでこれを繰り返します。 

私たちの仕事は、Vasya の賞品コレクションを再構築し、すべてのチョコレート バーを処理した後に残ったポイントを決定することです。 

入力により得られるのは、`n`(最大 50)、各バーのポイント (`p_i`最大 10^9)、および 5 つの賞品のコスト (厳密に増加、最大 10^9)。 小さいもの`n`パフォーマンスを気にせずにプロセスを直接シミュレートできます。 大きなポイント値は、小さな整数を前提とした単純な配列ベースの DP またはカウント手法を避けなければならないことを意味します。 

エッジケースには、Vasya のポイントが賞品の価格と正確に一致する状況、または一度に複数の賞品を買う余裕があり、貪欲な選択を繰り返し適用する必要がある状況が含まれます。 たとえば、Vasya が 10 ポイントを獲得し、賞金がかかる場合`[2,4,10,15,20]`、彼は複数の小さなアイテムを購入するのではなく、すぐにバッグを選択する必要があり、購入のたびに残ったポイントを正しく計算する必要があります。 

## アプローチ

 ブルートフォースアプローチは単純なシミュレーションです。 ゼロポイントから始めて、チョコレートバーごとにポイントを追加します。 次に、現在のポイントが少なくとも最も安い賞品のコストである間に、Vasya が購入できる最も高価な賞品を繰り返し見つけ、そのカウントを増やし、そのコストをポイントから差し引きます。 すべての小節に対してこれを続けます。 

このアプローチは、Vasya の貪欲な戦略に直接従っているため、正しいです。 以来`n`最大 50 で賞品が 5 つしかない場合、ポイント交換を繰り返す内部ループは最大で実行されます。`n * max_points / min_cost`回。 ポイント値が大きい場合でも、反復の最大数は貪欲な減算シーケンスによって制限され、実際には小節ごとにせいぜい数回の反復です。 

制約が小さいため、より高速な漸近解は必要ありませんが、重要な洞察は、貪欲な戦略により、小さな賞品の順序を考慮せずに、常に最大の手頃な賞品を選択できるということです。この問題は、このアプローチが最適であることを保証します。

## アルゴリズムのチュートリアル

 1. リストを初期化する`count`サイズは 5 ～ 0 で、Vasya が集めた各賞品の数を表します。 初期化する`points`ゼロに。 
2. 各チョコレート バーを時系列順に繰り返します。 そのポイントを追加する`points`。 
3. その間`points`少なくとも最も安い賞品の価格です。 

ａ． 最も高価な賞品から最も安価な賞品まで繰り返します。 

b. 価格が以下の最も高価な賞品を見つけます。`points`。 

c. 対応するカウントをインクリメントします。 

d. から賞品の費用を差し引きます`points`。 
4. すべてのチョコレート バーを処理した後、各賞品の個数を印刷し、続いて残りの個数を印刷します。`points`。 

これが機能するのは、各内側ループの後、おそらく次のチョコレート バーからさらにポイントを追加した後を除いて、Vasya は賞品を獲得できないという不変条件があるためです。 各決定点で、最も高価で手頃な賞品を選択することで、貪欲な戦略が問題の説明と一致することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
points_list = list(map(int, input().split()))
prizes = list(map(int, input().split()))  # a, b, c, d, e
count = [0] * 5
points = 0

for p in points_list:
    points += p
    while points >= prizes[0]:
        for i in range(4, -1, -1):
            if points >= prizes[i]:
                count[i] += 1
                points -= prizes[i]
                break

print(' '.join(map(str, count)))
print(points)
```外側のループは各バーにポイントを追加します。 内側のループは、Vasya が賞品を購入できなくなるまで、貪欲な戦略を繰り返し適用します。 最も高価なものから最も安価なものまで繰り返すことで、常に最高額の賞品が最初に選択されます。 使用する`break`内側のループ内では、反復ごとに 1 つの賞品のみが購入されることが保証され、Vasya の継続的な交換が正しくシミュレートされます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    points_list = list(map(int, input().split()))
    prizes = list(map(int, input().split()))
    count = [0]*5
    points = 0
    for p in points_list:
        points += p
        while points >= prizes[0]:
            for i in range(4, -1, -1):
                if points >= prizes[i]:
                    count[i] += 1
                    points -= prizes[i]
                    break
    return f"{' '.join(map(str,count))}\n{points}"

# Provided sample
assert run("3\n3 10 4\n2 4 10 15 20\n") == "1 1 1 0 0\n1", "sample 1"

# Minimum input
assert run("1\n1\n1 2 3 4 5\n") == "1 0 0 0 0\n0", "min input"

# All points smaller than cheapest prize
assert run("3\n1 1 1\n5 6 7 8 9\n") == "0 0 0 0 0\n3", "all points small"

# Exact sums
assert run("2\n7 4\n2 3 5 7 10\n") == "0 1 1 0 0\n3", "exact sums"

# Multiple exchanges per bar
assert run("1\n20\n2 4 10 15 20\n") == "0 0 1 0 0\n10", "single large bar"
