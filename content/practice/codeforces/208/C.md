 ## 解決策
 ## 問題の理解

 都市と道路を表す方向のない接続されたグラフが与えられます。すべての道路の所要時間は同じです。 すべての都市の中で、都市 1 と都市 n は特別です。私たちはこれら 2 つのエンドポイント間の移動を重視します。 1 から n に進むとき、人は常に最短経路を選択します。複数の最短経路が存在する場合、それらはすべて同等の可能性があるとみなされます。 

警察署は 1 つの都市にのみ設置することができます。 終点の 1 つに警察署がある道路は安全であるとみなされます。 他の道路はすべて危険です。 都市 1 から都市 n までのすべての最短パスについて、そのパスが使用する安全なエッジの数を数えます。 複数の最短パスが存在する可能性があるため、すべての最短パスにわたる安全なエッジの平均数を取得し、この期待値を最大化する警察署の配置を選択します。 

頂点の数に関する制約は小さく、最大でも 100 都市ですが、道路の数は多くなる可能性があります。 これは、n で 3 次の動作を行うアルゴリズムは依然として許容可能ですが、すべての最短パスを列挙することを含むアルゴリズムは許容できないことをすぐに示唆しています。 

主な困難は、答えが 1 つのパスだけではなく、すべての最短パスの構造に同時に依存することです。 単純なアプローチでは、1 から n までのすべての最短パスを列挙し、各候補ステーションの位置を評価しようとします。 ただし、密なグラフでは最短パスの数が指数関数的に増加する可能性があります。 

グラフに 1 と n の間にエッジが重なった最短ルートが多数ある場合、微妙なエッジ ケースが発生します。 たとえば、BFS 距離によって階層化された完全な 2 部構造では、すべての最短パスは中間選択肢の異なる組み合わせになります。 総当たり列挙は、n が 30 程度であってもすぐに失敗します。 

もう 1 つの特殊なケースは、最短パスが一意である場合です。 その場合、問題は選択したノードに接触する単一パスのエッジの数を最大化することに帰着します。これにより大幅に簡略化され、正確性の適切な健全性チェックになります。 

## アプローチ

 ブルートフォースのアイデアは概念的に単純です。最初に 1 から n までのすべての最短パスを計算し、次に候補都市 c ごとにすべての最短パスを評価し、そのパス上のエッジが c に含まれる数を数えます。 最後に、すべてのパスの平均をとり、最大値を取得します。 

定義に直接従っているため、正しさは明らかです。 障害は最短パスの数によって発生し、一般的なグラフでは最短パスが指数関数的に増加する可能性があります。 各パスの長さは O(n) であり、そのようなパスは指数関数的に多く存在する可能性があるため、それらを保存することすら不可能です。 

重要な観察は、実際にはパスを列挙する必要がないということです。 各最短経路の各エッジについて、それが特定のステーションの選択に寄与するかどうかを知る必要があるだけです。 パスごとに推論するのではなく、視点を切り替えてエッジを越えて集約します。 

まず、BFS を使用して 1 からの最短距離と n からの最短距離を計算します。 これにより、エッジが最短パス上に存在するエッジに分割されます。エッジ (u, v) は、最短パス DAG 内の連続するレイヤー間を通過する場合に関連します。これは、dist1[u] + 1 + distN[v] が dist1[n] に等しい、または対称条件を意味します。 

ここで、小さい方の dist1 から大きい方の dist1 に向けて、1 から n までの最短パスに現れる可能性のあるエッジのみで構成される DAG を構築します。 すべての最短パスは、この DAG 内のパスに対応します。 

P をすべての最短経路の集合とする。 各候補ノード c について、パス内の c に含まれるエッジの数の P にわたる平均が必要です。 これをエッジの合計として書き直します。エッジ e ごとに、e を通過する最短パスの数を数え、e が c に接触する場合は 1 を加えます。

これにより、問題は、最短パス DAG のエッジごとに、そのエッジを使用する最短パスの数をカウントするようになります。 これは DAG 上の標準的な DP です。最短パスのエッジに限定して、1 からすべてのノードまで、およびすべてのノードから n までの経路を計算します。 各エッジ寄与は、前方カウントと後方カウントの積になります。 

エッジの使用数がわかったら、候補ノード c を評価することは、すべての発生する最短パス エッジにわたって、それらのエッジを使用する最短パスの数を合計し、最短パスの総数で正規化することになります。 

これにより、問題は、すべてのペアの最短パス DAG カウントを計算し、それぞれ O(deg(c)) で n 回の評価を実行することになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべての最短パスを列挙する | 指数 | 指数 | 遅すぎる |
 | 最短パス DAG + DP カウント | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. BFS を使用してノード 1 からの最短距離を計算します。 これは、最短パス構造の前方階層化を定義します。 
2. BFS を使用してノード n からの最短距離を計算します。 これにより、エッジが 1 と n の間の最短パス上にあるかどうかを検証できます。 
3. dist1[u] + 1 + distN[v] = dist1[n] または対称条件を満たす「有用なエッジ」のセットを構築します。 これにより、選択されたすべてのエッジが少なくとも 1 つの最短パスに属することが保証されます。 
4. 有用なエッジに限定された隣接リストを構築し、それらを小さい方の dist1 から大きい方の dist1 に向けます。 距離はエッジに沿って厳密に増加するため、これにより DAG が生成されます。 
5. この DAG 上でノード 1 から DP を実行して、ways1[v] (1 から v までの最短パスの数) を計算します。反復により、すべての入力 DAG エッジにわたるways1 が合計されます。 
6. 同様に、ways2[v]、つまり反転 DAG 内の v から n への最短パスの数を計算します。 
7. 最短パスの総数は、ways1[n] です。 有用なエッジ (u, v) ごとに、それを使用する最短パスの数をウェイ 1[u] * ウェイ 2[v] として計算します。 
8. 各候補ステーション都市 c について、すべてのインシデント有効エッジにわたる寄与を計算します。 エッジが (c, v) の場合、ways1[c] *ways2[v] に寄与します。 (u, c) の場合、ways1[u] *ways2[c] が寄与します。 このような寄与をすべて合計し、最短パスの合計で割って、安全なエッジの予想数を取得します。 

この集計が機能する理由は、すべての最短パスがエッジに一意に分解され、パスを二重にカウントせずにエンドポイントに到達する方法の数を使用して各エッジの寄与を個別にカウントできるためです。 

### なぜ効果があるのか

 1 から n までのすべての最短パスは、最短パス DAG 内の 1 つのパスに正確に対応します。 任意のエッジ e = (u, v) の場合、e を含む最短パスの数は、1 から u に到達する方法の数と v から n に到達する方法の数を掛けたものになります。この分解では各パスが正確に 1 回カウントされるため、エッジ上の寄与を合計すると、期待値の正しい線形分解が得られます。 したがって、パスに対する期待値は、すべての最短パスにわたる周波数によって各エッジを重み付けすることと同じです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

n, m = map(int, input().split())
g = [[] for _ in range(n + 1)]
edges = []

for _ in range(m):
    u, v = map(int, input().split())
    g[u].append(v)
    g[v].append(u)
    edges.append((u, v))

def bfs(src):
    dist = [10**9] * (n + 1)
    dist[src] = 0
    q = deque([src])
    while q:
        u = q.popleft()
        for v in g[u]:
            if dist[v] > dist[u] + 1:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

dist1 = bfs(1)
distn = bfs(n)
D = dist1[n]

sg = [[] for _ in range(n + 1)]
rg = [[] for _ in range(n + 1)]

valid_edges = []

for u, v in edges:
    if dist1[u] + 1 + distn[v] == D:
        sg[u].append(v)
        rg[v].append(u)
        valid_edges.append((u, v))
    elif dist1[v] + 1 + distn[u] == D:
        sg[v].append(u)
        rg[u].append(v)
        valid_edges.append((v, u))

ways1 = [0] * (n + 1)
ways1[1] = 1
order = sorted(range(1, n + 1), key=lambda x: dist1[x])
for u in order:
    for v in sg[u]:
        ways1[v] += ways1[u]

waysn = [0] * (n + 1)
waysn[n] = 1
order = sorted(range(1, n + 1), key=lambda x: -dist1[x])
for u in order:
    for v in rg[u]:
        waysn[v] += waysn[u]

total_paths = ways1[n]

edge_cnt = 0
node_ans = [0] * (n + 1)

for u, v in valid_edges:
    cnt = ways1[u] * waysn[v]
    node_ans[u] += cnt
    node_ans[v] += cnt
    edge_cnt += cnt

best = 0.0
for i in range(1, n + 1):
    if total_paths:
        best = max(best, node_ans[i] / total_paths)

print(f"{best:.10f}")
```実装は、BFS を使用して両方のエンドポイントからの最短距離を計算することから始まります。BFS は、どのエッジが最短パスに参加できるかを識別するバックボーンです。 次に、前方距離と後方距離の間の一貫性を強制することにより、グラフがフィルタリングされて最短パス DAG になります。 

順方向 DP は 1 から各ノードに到達する最短パスの数をカウントし、逆方向 DP は各ノードから n までの最短パスの数をカウントします。 これら 2 つの値を組み合わせると、各有向エッジを通過する最短パスの数が求められます。 

最後に、各ノードはその入射エッジからの寄与を集約します。 最短パスの総数で除算すると、生のカウントが最短パスの一様分布における期待値に変換されます。 

元のグラフは無向ですが、DP は距離によって引き起こされる有向非循環構造で動作するため、エッジが正しい方向で 1 回だけカウントされるように注意する必要があります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    from collections import deque

    n, m = map(int, sys.stdin.readline().split())
    g = [[] for _ in range(n + 1)]
    edges = []

    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        g[u].append(v)
        g[v].append(u)
        edges.append((u, v))

    def bfs(src):
        dist = [10**9] * (n + 1)
        dist[src] = 0
        q = deque([src])
        while q:
            u = q.popleft()
            for v in g[u]:
                if dist[v] > dist[u] + 1:
                    dist[v] = dist[u] + 1
                    q.append(v)
        return dist

    dist1 = bfs(1)
    distn = bfs(n)
    D = dist1[n]

    sg = [[] for _ in range(n + 1)]
    rg = [[] for _ in range(n + 1)]

    valid_edges = []

    for u, v in edges:
        if dist1[u] + 1 + distn[v] == D:
            sg[u].append(v)
            rg[v].append(u)
            valid_edges.append((u, v))
        elif dist1[v] + 1 + distn[u] == D:
            sg[v].append(u)
            rg[u].append(v)
            valid_edges.append((v, u))

    ways1 = [0] * (n + 1)
    ways1[1] = 1
    order = sorted(range(1, n + 1), key=lambda x: dist1[x])
    for u in order:
        for v in sg[u]:
            ways1[v] += ways1[u]

    waysn = [0] * (n + 1)
    waysn[n] = 1
    order = sorted(range(1, n + 1), key=lambda x: -dist1[x])
    for u in order:
        for v in rg[u]:
            waysn[v] += waysn[u]

    total_paths = ways1[n]

    node_ans = [0] * (n + 1)
    for u, v in valid_edges:
        cnt = ways1[u] * waysn[v]
        node_ans[u] += cnt
        node_ans[v] += cnt

    best = 0.0
    for i in range(1, n + 1):
        if total_paths:
            best = max(best, node_ans[i] / total_paths)

    return f"{best:.10f}"

 ## 特殊なケース

 重要なケースの 1 つは、1 と n の間に最短パスが 1 つだけ存在する場合です。 その状況では、DP は 1 つのパスをカウントすることになり、各ノードの寄与は、そのパスの 1 つまたは 2 つのエッジに接触するかどうかにのみ依存します。 アルゴリズムはこれを正しく処理します。ウェイズ 1 とウェイズ n がパスに沿って 1 になり、その他の場所では 0 になるため、エッジの寄与は単純なインジケーター値に崩壊します。 

もう 1 つのケースは、すべての層で選択肢の数が 2 倍になる層状グリッドなど、完全な対称性を持って多数の最短パスが存在する場合です。 ここで、単純に考えると二重カウントの問題が示唆されるかもしれませんが、DAG 内の一連の遷移を選択することによって各最短パスが一意に決定されるため、前方後方因数分解により各パスがエッジごとに 1 回正確にカウントされることが保証されます。
