 ## 問題の理解

 正の整数が与えられます$n$。 2 つの正の整数を選択するすべての方法を検討します$p$そして$q$彼らの積が分割されるように$n$、そしてさらに$p \le q$。 有効なペアごとに値を計算します。$r = \frac{p}{q}$。 タスクは、個別の有理値がいくつあるかを決定することです。$r$このようなすべてのペアに現れる可能性があります。 

したがって、この構造は約数を直接列挙するものではなく、因数をペアにするものです。$n$あらゆる可能な方法で、異なる因数分解間で繰り返しを許可し、各因数分解の 2 つの部分間の比率を観察します。 

この制約により、最大 2000 のテスト ケースが許可され、それぞれのテスト ケースは$n$と同じ大きさにすることができます$10^{10}$。 これにより、追加の構造を持たずにテスト ケースごとに単純なネストされた方法ですべての約数を列挙するアプローチは即座に除外されます。 典型的な$O(\sqrt{n})$テストごとの因数分解は許容されますが、それに近いものは何でも可能です。$O(n^{1/2} \cdot q)$慎重に制限し、効率的に実装する必要があります。 

微妙な点としては、$p$そして$q$は独立して選択された任意の約数ではありません。 彼らは満足しなければなりません$pq \mid n$、つまり、それらの素指数は共に指数バジェット内に収まらなければなりません。$n$。 単純な間違いは、これを次の任意の 2 つの約数を選択するものとして扱うことです。$n$、積が超過する無効なペアを上乗せカウントします。$n$。 

もう 1 つのよくある落とし穴は、比率を仮定することです。$p/q$選択した除数ごとに独立した約数の比のように動作します。 素数指数間の依存関係が問題の核心です。 

## アプローチ

 ブルートフォースアプローチでは、すべての約数を列挙します。$n$、すべてのペアを試してください$(p, q)$かどうかを確認してください$pq \mid n$。 有効なペアごとに、次のように計算します。$p/q$それをセットに挿入します。 もし$d$は約数の数です$n$、これには必要です$O(d^2)$テスト ケースごとにペアを作成し、割り算をチェックすると、少なくとも一定のオーバーヘッドが追加されます。 以来$n$最大約まで持つことができます$10^5$最悪の場合、これは複数のテスト ケースにわたってすぐに実行不可能になります。 

重要な観察点は、次の条件です。$pq \mid n$素因数の乗算です。 書いてみると$$n = \prod p_i^{a_i},$$それから選択する$p$そして$q$指数分割の選択に対応します$x_i$そして$y_i$そのような$$x_i \ge 0, \quad y_i \ge 0, \quad x_i + y_i \le a_i.$$比率は次のようになります。$$\frac{p}{q} = \prod p_i^{x_i - y_i}.$$これにより、問題は異なる指数ベクトルの数を数えるという問題に変わります。$(x_i - y_i)$素数ごとに独立して形成できます。 重要な単純化は、各素因数が最終積に独立して寄与するため、異なる比率の総数は、素数ごとに考えられる指数差の数の積となることです。 

指数を持つ単一の素数の場合$a$、の達成可能な値のセット$x - y$下$x + y \le a$区間内のすべての整数であることが判明$[-a, a]$。 つまり、まさに存在します$2a + 1$プライムごとの選択肢。 

これらの寄与をすべての素数に乗算すると、答えが得られます。

 ## アルゴリズムのチュートリアル

 問題を素因数分解と指数計算に還元します。 

1.因数分解$n$その主力に。 まで小さな整数で繰り返し除算します。$\sqrt{n}$。 素数を見つけるたびに$p$、その指数を数えます$a$。 有効なペアのすべての構造はこれらの指数のみに依存するため、このステップが必要です。 
2. 各素数指数について$a$、この素数によって寄与される可能な値の数を計算します。 制約を分析します$x + y \le a$すべての整数の差を考慮します$x - y$。 到達可能なセットは正確に以下のすべての整数です。$-a$に$a$、これは貢献します$2a + 1$選択肢。 
3. すべての貢献度を掛け合わせます。 各素数は独立して動作するため、素数間の組み合わせは選択のデカルト積を形成します。 
4. 各テスト ケースの最終結果を出力します。 

### なぜ効果があるのか

 正しさは 2 つの構造的事実に基づいています。 まず条件ですが、$pq \mid n$は素数指数にわたってきれいに分解します。つまり、ペアの実現可能性は素数指数ごとの予算にのみ依存します。 第二に、比率$p/q$は素数の乗算であるため、最終値を形成するときに異なる素数が相互作用することはありません。 この独立性により、すべての有効なグローバル構造が独立した素数ごとの指数の選択に一意に対応し、素数ごとの有効な差のすべての組み合わせが有効なグローバル比を生成することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def factorize(n):
    factors = {}
    d = 2
    while d * d <= n:
        if n % d == 0:
            cnt = 0
            while n % d == 0:
                n //= d
                cnt += 1
            factors[d] = cnt
        d += 1
    if n > 1:
        factors[n] = factors.get(n, 0) + 1
    return factors

q = int(input())
for _ in range(q):
    n = int(input())
    f = factorize(n)
    ans = 1
    for a in f.values():
        ans *= (2 * a + 1)
    print(ans)
```因数分解ステップでは、すべての素指数が抽出されます。これが、残りの計算に必要な唯一の情報です。 最大の約数にわたるループ$\sqrt{n}$安全なので$n \le 10^{10}$。 

乗算ステップでは、導出された式を直接実装します。 対処できる以上の境界問題はありません$n = 1$、因数リストは空であり、答えは正しく 1 のままです。

 ## 特殊なケース
