## アプローチ

 出発点は表現することです$a$そして$b$基地内で$p$。 書く$a = a_0 + a_1 p + \dots + a_{k-1} p^{k-1}$そして同様に$b$。 どちらも厳密には以下であるため、$p^k$、どちらも正確に$k$ゼロが埋め込まれた場合の数字。 

素数のルーカス型構造は次のことを示しています。$$\binom{a}{b} \bmod p = \prod_{i=0}^{k-1} \binom{a_i}{b_i} \bmod p,$$いずれかの桁が違反している場合、値はゼロになります$b_i \le a_i$。 

これにより、問題はデジタル処理に変換されます。 各位置は独立して乗算係数に寄与します。$\mathbb{F}_p^\times$。 固定桁位置の場合、すべての有効なペアを列挙できます。$(a_i,b_i)$と$0 \le b_i \le a_i < p$結果の剰余を計算します$\binom{a_i}{b_i} \bmod p$。 

これにより、問題全体の長さが短くなります。$k$シーケンス構築問題: 各位置で、乗算係数に寄与する 1 つの「桁遷移」を選択します。${1,2,\dots,p-1}$、そしてすべての貢献を掛け合わせます。 

したがって、数値を扱う代わりに、許可された乗法重みの複数セットを操作し、繰り返します。$k$回。 目標は、長さのシーケンスをカウントすることになります$k$その積が等しい$x$モジュロ$p$。 

ブルート フォース バージョンでは、各ポジションを独立して処理し、状態を超えて DP を維持します。$p$そのDPは、$p-1$すべての数字ペアの寄与に依存する状態と遷移。 一歩を踏み出すためには、$O(p^2)$数字のペアを列挙するため、および$k$ステップごとに合計の複雑さは次のようになります$O(k p^2)$、それは不可能です$k$天文学的に大きくなる可能性があります。 

重要な構造的洞察は、素数を法とする乗算が非ゼロ残基にわたって環状群を形成するということです。 各残基をマッピングすると$v$指数に$e$そのような$v = g^e \bmod p$原始根の場合$g$、その場合、乗算は指数の剰余加算になります。$p-1$。

 ## アルゴリズムのチュートリアル

 問題を巡回群の多項式累乗に変換します。 

1. 1 桁の二項値のテーブルを作成します。 すべてのペアを列挙します$(a,b)$と$0 \le b \le a < p$そして計算する$c = \binom{a}{b} \bmod p$。 このような各ペアは、残基にわたる頻度配列に 1 つの出現に寄与します。$1$に$p-1$。 これにより、各桁位置が乗算的にどのような影響を与えるかを説明する重み分布が得られます。 
2. プリミティブルートを選択します$g$モジュロ$p$離散対数テーブルを計算して、すべての非ゼロ剰余が$v$指数にマッピングできる$e$と$v = g^e \bmod p$。 これにより、乗算が指数空間での加算に変換されます。 
3. 初期多項式を構築する$F$、ここでインデックス$e$寄与が指数を持つ数字ペアの総数を格納します$e$。 この多項式はサイズのリング内に存在します$p-1$ここで、乗算は巡回畳み込みです。 
4. 通訳する$k$バイナリ指数として。 恒等多項式 (桁の寄与がないことを表す) から開始して、二乗を繰り返します。$F$の対応するビットが存在するたびに結果に乗算します。$k$が設定されています。 各乗算は巡回畳み込みを介して行われ、その後にリダクションモジュロが続きます。$x^{p-1}-1$。 
5. べき乗後、次の指数に対応する係数を読み取ります。$x$。 この係数は有効なペアの数です$(a,b)$。 

この手順が機能する理由は、各桁の位置が独立して同一に寄与するためです。 の$k$に対応する位置$k$独立した乗算寄与の同じマルチセットからの引き出し。 多項式累乗は、独立した乗法選択にわたる積の分布を正確にモデル化します。 巡回畳み込みにより、指数を法として正しい組み合わせが強制されます。$p-1$の構造と一致します。$\mathbb{F}_p^\times$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

# ---------- NTT helpers ----------
def ntt(a, invert):
    n = len(a)
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            a[i], a[j] = a[j], a[i]

    length = 2
    while length <= n:
        wlen = pow(3, (MOD - 1) // length, MOD)
        if invert:
            wlen = pow(wlen, MOD - 2, MOD)
        for i in range(0, n, length):
            w = 1
            half = length >> 1
            for j in range(i, i + half):
                u = a[j]
                v = a[j + half] * w % MOD
                a[j] = (u + v) % MOD
                a[j + half] = (u - v) % MOD
                w = w * wlen % MOD
        length <<= 1

    if invert:
        inv_n = pow(n, MOD - 2, MOD)
        for i in range(n):
            a[i] = a[i] * inv_n % MOD

def convolution(a, b):
    n = 1
    while n < len(a) + len(b):
        n <<= 1
    fa = a[:] + [0] * (n - len(a))
    fb = b[:] + [0] * (n - len(b))

    ntt(fa, False)
    ntt(fb, False)
    for i in range(n):
        fa[i] = fa[i] * fb[i] % MOD
    ntt(fa, True)
    return fa

def cyclic_convolution(a, b, n):
    c = convolution(a, b)
    res = [0] * n
    for i, v in enumerate(c):
        res[i % n] = (res[i % n] + v) % MOD
    return res

# ---------- main ----------
p = 0
x = 0

def solve():
    global p, x
    k_str, p, x = input().split()
    p = int(p)
    x = int(x)

    # find primitive root (simple brute, p small enough)
    def is_primitive(g):
        seen = set()
        cur = 1
        for _ in range(p - 1):
            cur = cur * g % p
            if cur in seen:
                return False
            seen.add(cur)
        return len(seen) == p - 1

    g = 2
    while not is_primitive(g):
        g += 1

    log = [-1] * p
    cur = 1
    for i in range(p - 1):
        log[cur] = i
        cur = cur * g % p

    # build one-digit contribution polynomial
    freq = [0] * (p - 1)

    fact = [1] * p
    for i in range(1, p):
        fact[i] = fact[i - 1] * i % p

    invfact = [1] * p
    invfact[p - 1] = pow(fact[p - 1], p - 2, p)
    for i in range(p - 2, -1, -1):
        invfact[i] = invfact[i + 1] * (i + 1) % p

    def C(n, r):
        if r < 0 or r > n:
            return 0
        return fact[n] * invfact[r] % p * invfact[n - r] % p

    for a in range(p):
        for b in range(a + 1):
            v = C(a, b)
            if v != 0:
                freq[log[v]] += 1

    # exponentiation base polynomial
    def poly_pow(poly, k_bits):
        res = [0] * (p - 1)
        res[0] = 1

        base = poly[:]

        for bit in k_bits:
            if bit == '1':
                res = cyclic_convolution(res, base, p - 1)
            base = cyclic_convolution(base, base, p - 1)

        return res

    ans_poly = poly_pow(freq, k_str)
    target = log[x]
    print(ans_poly[target] % MOD)

if __name__ == "__main__":
    solve()
```実装では、まず二項係数のモジュロの完全なルックアップを構築します。$p$1 桁の場合は、ゼロ以外の各値をその離散対数クラスにマップします。 これにより、指数空間では乗算が加算に変換されます。 次に、多項式累乗ルーチンは、次の 2 進表現に対して 2 進累乗を使用します。$k$、循環畳み込みを繰り返し適用して寄与を結合します。 

循環畳み込みステップでは、指数合計がモジュロでラップアラウンドするように強制されます。$p-1$、体の乗法群の構造と一致します。

 ## 特殊なケース

 主なエッジケースは次の場合に発生します。$x$ジェネレータ残余です。 この状況では、離散対数に正確に合計される指数の組み合わせのみが寄与し、循環ラップアラウンドで間違いがあれば、すぐに答えが変わります。 畳み込みはモジュロで実行されるため、アルゴリズムはこれを正しく処理します。$x^{p-1}-1$、正確な周期的な動作を強制します。 

もう 1 つの特殊なケースは、多くの数字のペアが同じ二項剰余を生成する場合です。 これにより、頻度分布が大きく歪められ、単純な一様な仮定が不正確になります。 このアルゴリズムはすべてのペアを明示的にカウントするため、多重度は近似されるのではなく正確に保存されます。 

最後の微妙なケースは次のような場合です。$k=1$。 べき乗機構全体が単一の多項式検索に集約されます。 バイナリ累乗ループは、次のビットに基づいて 1 層の乗算を正確に実行するため、コードはこれを自然に処理します。$k$。
