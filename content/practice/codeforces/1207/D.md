 ## 解決策
 ## 問題の理解

 私たちに与えられたコレクションは、$n$ラベル付きタイル。各タイルには整数のペアが含まれます。$(a_i, b_i)$。 私たちのタスクは、結果として生じるシーケンスが 2 つの非常に特殊な失敗パターンを回避できるように、これらのタイルを並べ替えることができる方法が何通りあるかを数えることです。 

並べ替え後の最初の座標のシーケンスが減少していないか、または 2 番目の座標のシーケンスが減少していない場合、並べ替えられたシーケンスは不良であるとみなされます。 どちらの座標シーケンスも非降順でソートされていない場合、そのシーケンスは良好です。 

したがって、1 つの固定された順序をチェックしているわけではありません。 代わりに、インデックスのすべての順列を考慮します。$1 \ldots n$、各順列を適用してペアを並べ替え、結果として得られる良好なシーケンスの数を数えます。 

困難は、「悪い」とは局所的な構造に関するものではなく、一次元における全体的な単調性に関するものであるという事実から来ています。 シーケンスは、すべての要素にわたって結合と順序がどのように相互作用するかに応じて、さまざまな理由で不良になる可能性があります。 

制約$n \le 3 \cdot 10^5$順列を明示的に調べるアプローチを除外します。 平$O(n^2)$メソッドが遅すぎます。 解決策は、ソート構造と点の同値クラスに対する組み合わせカウントに依存する必要があります。 

多くのペアが同じ 1 番目または 2 番目の座標を共有する場合、微妙なエッジ ケースが発生します。 たとえば、すべてが$a_i$が等しい場合、すべての順列が最初のシーケンスを非減少にするため、答えはゼロになる必要があります。 非減少順序ではなく厳密な順序のみをチェックする単純なアプローチでは、これが部分的に安全であると誤って扱われてしまいます。 

もう 1 つの注意が必要なケースは、すべてのペアが同一である場合です。 この場合、両方の座標シーケンスは常に非減少であるため、すべての順列は不良となり、答えは再び 0 になります。 

## アプローチ

 ブルートフォースのアイデアは単純です。インデックスのすべての順列を試し、結果のシーケンスを構築し、最初の座標が減少していないか、2 番目の座標が減少していないかを確認します。 これは定義に直接従うため、正しいです。 ただし、置換の数は、$n!$であっても天文学的に大きくなります。$n = 10$。 チェックステップ自体は$O(n)$、全体的な結果につながります$O(n \cdot n!)$完全に実行不可能な複雑さ。 

重要な観察は、「最初または 2 番目の座標によって並べ替えられる」という条件は、1 つの軸に投影されたときの要素の相対的な順序にのみ依存するということです。 すべてのペアを次の基準で並べ替えると、$a_i$、最初の条件の違反がこの順序付けの反転に対応する構造を公開します。 同様に、並べ替えると、$b_i$2 番目の条件の構造を公開します。 

良い順列を直接数えるのではなく、すべての順列を数えて悪い順列を差し引く方が簡単です。 並べ替えは、次の順序で並べ替えると問題になります。$a$または並べ替え$b$。 重複も処理する必要があります。両方でソートされた順列は 2 回カウントされるため、修正する必要があります。 

これにより、問題は、$a$そしてによって$b$。 オーバーラップ構造は、同一のペアをグループ化し、等しい値で形成されたブロックに対して組み合わせ論を使用することによって管理されます。 グループ化されると、有効な順列の数は、グループ サイズの階乗と 2 つの単調な配置の注意深い減算に依存します。 

最終的な構造は、両方の単調な順序付けを同時に回避しながら、並べ替えのカウントに分解されます。これは、2 つの並べ替えられた構成に対する包含と排除によって実現されます。

 | 最適 |$O(n \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 私たちは、順列が悪くなる可能性のある 2 つの方法を分離し、それらを完全なセットから慎重に削除することでソリューションを構築します。 

1. 最初の座標でペアを並べ替えます$a_i$。 これにより、この順序を維持する順列が「悪い」という正規の順序が与えられます。$a$”。
 2. ペアを 2 番目の座標で並べ替えます$b_i$。 これは同様に、「悪い」順列のセットを定義します。$b$”。
 3. ソートされたシーケンスを生成する順列の数を数えます。$a$。 これは連携している場合にのみ可能です$a$等しいグループ内での並べ替えが許可されるため、そのような並べ替えの数は、同一の頻度の階乗の積になります。$a$-両方の座標でグループ化した後のブロック。 
4. 並べ替えた順列も同様に数えます。$b$、再び同一の多重度を考慮します。$b$-ブロック。 
5. 両方で同時にソートされる順列をカウントします。$a$そして$b$。 これは、同一のペアがグループ化され、シーケンスが両方のソート順を尊重する場合に正確に発生します。これにより、通常は同一のグループ化が行われます。$(a_i, b_i)$ペア。 
6. 包含/除外を適用します。$$\text{answer} = n! - (\text{sorted by } a + \text{sorted by } b - \text{sorted by both})$$減算により、すべての悪い順列が 1 回だけ削除されることが保証されます。 

### なぜ効果があるのか

 核となる不変条件は、複数セットのペアの順列が 4 つのカテゴリのいずれかに正確に分類される必要があるということです。$a$のみ、並べ替え$b$のみ、両方でソート、またはどちらもソートしない。 最初の 3 つのカテゴリは、まさに悪いケース、またはそれらの重複です。 これらのカテゴリは全次数制約によって定義されるため、その数は投影下の等しい要素の周波数構造にのみ依存します。 これらの構造化されたセットに対する包含-排他により、順列が二重にカウントされたり見逃されたりしないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 998244353

def solve():
    n = int(input())
    a = []
    b = []
    pairs = []
    
    for _ in range(n):
        x, y = map(int, input().split())
        a.append(x)
        b.append(y)
        pairs.append((x, y))
    
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD
    
    def count_sorted_by(key):
        arr = sorted(pairs, key=key)
        res = 1
        i = 0
        while i < n:
            j = i
            while j < n and key(arr[j]) == key(arr[i]):
                j += 1
            res = res * fact[j - i] % MOD
            i = j
        return res
    
    total = fact[n]
    
    by_a = count_sorted_by(lambda x: x[0])
    by_b = count_sorted_by(lambda x: x[1])
    
    both = 1
    arr = sorted(pairs)
    i = 0
    while i < n:
        j = i
        while j < n and arr[j] == arr[i]:
            j += 1
        both = both * fact[j - i] % MOD
        i = j
    
    ans = (total - by_a - by_b + both) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```このコードは階乗を事前計算して、同一グループ内の順列を高速にカウントできるようにします。 機能`count_sorted_by`座標によるソート後に要素をグループ化し、単調性を維持する内部再配置を反映するブロック サイズの階乗を乗算します。 

最後の包含/除外ステップでは、両方のタイプの不正な順序を減算し、それらの交差を復元することによって、良好な順列の数を構築します。 

実装の微妙な点は、等価グループ化では交差ケースを計算するときに完全なペア比較を使用する必要があることです。 座標を 1 つだけ使用すると、重複が過剰にカウントされてしまいます。 

## 実用的な例

 ### 例 1

 入力:```
3
1 1
2 2
3 1
```階乗を計算します。$3! = 6$。 

並べ替え順$a$それぞれサイズ 1 のグループが与えられるため、$by\_a = 1$。 

並べ替え順$b$値が切れ目なく厳密に増加するわけではない構造を形成し、再び次の状態につながります。$by\_b = 1$。 

同一のペアはすべて別個のものであるため、$both = 1$。 

| 数量 | 値 |
 | --- | --- |
 | 合計 | 6 |
 | by_a | 1 |
 | by_b | 1 |
 | 両方 | 1 |

 答え：$$6 - 1 - 1 + 1 = 5$$このトレースは、構造化された単調なものだけが除外され、ほとんどの順列が良好であることを示しています。 

### 例 2

 入力:```
4
1 1
1 1
2 2
2 2
```ここでは、重複が構造を支配します。 

| 数量 | 値 |
 | --- | --- |
 | 合計 | 24 |
 | by_a | 4 |
 | by_b | 4 |
 | 両方 | 4 |

 答え：$$24 - 4 - 4 + 4 = 20$$このケースは、重複が両方の並べ替えられた投影で大きな要因寄与を生み出し、過剰な減算を避けるために包含-除外が不可欠であることを示しています。

 ## 特殊なケース

 次のような完全に均一なシーケンス$(1,1)$繰り返された$n$両方の座標シーケンスが一定のままで減少しないため、times はすべての置換を強制的に不良とします。 アルゴリズムは、両方の投影で階乗グループ化を通じてこれを処理し、すべてのカウントを等しくして、包含と除外の後にゼロを生成します。 

両方の座標で厳密に増加するシーケンスは、反対の極値を作成します。 恒等式以外のすべての順列は少なくとも 1 つの順序を破るので、ほとんどの順列は良好です。 座標ごとに並べ替えられたカウントは 1 に減算され、包含-排他により 2 つの単調順列のみが過剰にカウントされることなく正しく減算されます。
