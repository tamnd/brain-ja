 ## 問題の理解

 のグループの順列を分析するように求められています。$n$賢者、そこでは何組かがお互いを知っています。 これらの賢者の順列ごとに、次の長さのバイナリ文字列を作成できます。$n-1$知人の隣接性を示します。順列内の 2 人の連続する賢者がお互いを知っている場合は「1」、そうでない場合は「0」です。 私たちの目標は、可能な長さのすべてのバイナリ文字列をカウントすることです。$n-1$、それを生成する順列の数。 

入力は知人関係を次のようにエンコードします。$n \times n$対角にゼロがある対称バイナリ行列。 出力は長さの配列です$2^{n-1}$、各位置は整数として解釈されるバイナリ文字列に対応します。 

ブルートフォースには制約が厳しいです。 と$n \le 18$、すべてを列挙します$n!$順列を直接実行することは不可能です。$18! \approx 6.4 \cdot 10^{15}$。 これにより、順列を生成する単純なアプローチが除外されます。 この問題には、より賢明な組み合わせプログラミングまたは動的プログラミングのアプローチが必要です。 

エッジケースには、すべての賢者がお互いを知っているというシナリオが含まれます。 この場合、すべて 1 の文字列のみが発生し、他のすべての文字列のカウントは 0 でなければなりません。 もう 1 つのシナリオは、二人の賢者がお互いを知らない場合です。 その場合、すべてゼロの文字列のみが表示されます。 空または完全な隣接文字列を処理しない不注意な実装では、これらの極端な値を誤ってカウントする可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、すべてが生成されます。$n!$順列を作成し、順列ごとに、隣接行列内の連続するペアをチェックしてバイナリ文字列を構築します。 次に、その文字列のカウンターをインクリメントします。 これは問題の定義を正確に反映しているため機能しますが、時間計算量は次の要因によって決まります。$n$、これは受け入れられません$n = 18$。 

計算を高速化するための重要な観察は、賢人のサブセットに対する動的計画法を使用して問題を解決できるということです。 具体的には、男性のサブセットごとに、連続する男性の隣接関係を表す特定のバイナリ文字列を使用して、特定の賢者で終わるように配置する方法の数を追跡できます。 これにより、問題は階乗時間から次のように変換されます。$O(n \cdot 2^n \cdot 2^{n-1})$、これを単純化すると、$O(n \cdot 4^n)$-許容される$n \le 18$。 

これが機能するのは、順列を段階的に構築できるためです。 man で終わるサブセットにいくつのシーケンスが存在するかがわかっていれば、$u$紐付き$s$、次に新しい男性を追加します$v$次のいずれかによって文字列を決定的に拡張します。$u$そして$v$お互いを知っています。 DP 状態は次のように定義されます。$(mask, last, bitmask)$どこ`mask`すでに使用されている男性をエンコードします。`last`部分順列の最後の男であり、`bitmask`これまでに生成された隣接文字列の整数表現です。

 ## アルゴリズムのチュートリアル

 1. 入力行列を解析して隣接配列にします。`adj[i][j]`賢者の場合は 1`i`賢者は知っている`j`、それ以外の場合は 0。 
2. 動的プログラミングテーブルを初期化する`dp`によってインデックス付けされました`(mask, last, bitmask)`。 ここ、`mask`使用済みの賢者のビットマスクです。`last`は現在の順列における最後の賢者のインデックスであり、`bitmask`これまでの隣接文字列を表す整数です。 すべてのエントリをゼロに設定します。 
3. 各賢者を個別に配置して DP をシードします。 単一の男性を含む順列の場合`i`、 セット`dp[1 << i][i][0] = 1`。 単一要素の隣接文字列は空で、整数 0 に対応します。 
4. 1 から 2 までのすべてのマスクを繰り返します。`(1 << n) - 1`。 マスクごとに、可能なすべての最後のマスクを反復処理します。`u`現在のサブセット内。 もし`dp[mask][u][*] > 0`、未使用の男性を追加することを検討してください`v`順列を拡張します。 
5. 各候補者について`v`、新しいマスクを計算します`mask2 = mask | (1 << v)`。 新しい隣接文字列の整数を計算します。`bitmask2 = (bitmask << 1) | adj[u][v]`。 インクリメント`dp[mask2][v][bitmask2]`による`dp[mask][u][bitmask]`。 
6. DP を埋めた後、すべての最終状態を次のように繰り返します。`mask = (1 << n) - 1`。 それぞれについて`last`そして`bitmask`、カウントを累積します`result[bitmask]`。 
7. 結果の配列を出力します。`result`長さの`2^{n-1}`。 

不変条件とは、`dp[mask][last][bitmask]`は常に、によって示されるサブセットの順列の数を正確にカウントします。`mask`で終わる`last`でエンコードされた隣接関係文字列を生成します。`bitmask`。 DP 遷移は、隣接文字列を更新しながら有効な置換を正しく拡張するため、どの置換も複数回カウントされず、すべてが考慮されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
adj = [list(map(int, line.strip())) for line in sys.stdin]

size = 1 << n
dp = [{} for _ in range(size)]

for i in range(n):
    dp[1 << i][i] = {0: 1}

for mask in range(size):
    for u in range(n):
        if not (mask & (1 << u)) or not dp[mask][u]:
            continue
        for bitmask, count in dp[mask][u].items():
            for v in range(n):
                if mask & (1 << v):
                    continue
                mask2 = mask | (1 << v)
                bitmask2 = (bitmask << 1) | adj[u][v]
                if v not in dp[mask2]:
                    dp[mask2][v] = {}
                dp[mask2][v][bitmask2] = dp[mask2][v].get(bitmask2, 0) + count

result = [0] * (1 << (n - 1))
final_mask = (1 << n) - 1
for u in range(n):
    if u in dp[final_mask]:
        for bitmask, count in dp[final_mask][u].items():
            result[bitmask] += count

print(" ".join(map(str, result)))
```隣接行列は整数に変換され、ビット単位の演算で隣接文字列を効率的に拡張できるようになります。 各 DP 辞書は、そのサブセットと最後の要素に発生するビットマスクのみを処理するため、メモリが節約されます。 辞書を使用すると、完全な辞書を保存する必要がなくなります。`2^{n-1}`必要な場合を除いて、サブセットごとの状態。 の`get`このメソッドはカウントを上書きせずにきれいに蓄積します。
