 ## 解決策

 ## 問題の理解

 1 から n までの数値の順列が与えられており、それをちょうど k 個の連続するセグメントに分割する必要があります。 各セグメントは、そのセグメント内の最大要素に等しい値を与えます。目標は、これらのセグメントの最大値の合計ができるだけ大きくなるように分割点を選択することです。 この最大可能合計を見つけた後、k セグメントを配置するさまざまな方法が何通りあるかを数えることも必要です。 

重要な詳細は、セグメントが連続しているため、隣接するインデックス間の k−1 個のカット位置のみを選択していることです。 カットが修正されると、すべての位置は正確に 1 つのセグメントに属し、各セグメントは正確に 1 つの最大値に寄与します。 

n が 200,000 までの制約により、O(n log n) または O(n) の解が強制されます。 パーティションの数が k と組み合わせて増加するため、パーティションを明示的に評価したり、セグメントの最大値を繰り返し再計算しようとすると、すぐに失敗します。 

グローバル戦略を持たずに大きな値を貪欲に削減すべきだと考えると、単純な間違いが生じます。 たとえば、k = 2 の [1, 3, 2, 4] のような順列では、4 の直前をカットするのが適切に見えますが、最適な分割は、以前の大きな要素がすでにセグメントに「割り当てられている」かどうかによって異なります。 もう 1 つの微妙な失敗モードは、複数の等しい最適なカット構成が存在する場合にパーティションを誤ってカウントすることです。これは、複数の隣接するカットの選択から同じ最大寄与構造が生じる可能性があるためです。 

## アプローチ

 ブルートフォースアプローチでは、あらゆる方法を試して、n-1 個のギャップの中から k-1 個のカット位置を選択します。 選択ごとに、各セグメントを個別にスキャンしてセグメントの最大値を計算します。 プレフィックス前処理を使用しても、1 つのパーティションの評価には依然として O(n) のコストがかかり、O(n 選択 k−1) 個のパーティションが存在します。 これは、n = 30 の場合でも天文学的に大きくなり、ブルート フォースが使用できなくなります。 

重要な観察は、各セグメントの寄与は、どの要素がセグメントの「責任」を最大にするかによって決まるということです。 すべての要素は一意であるため、各値は 1 つのセグメントの最大値になる可能性があります。 したがって、各セグメントの最大値は何らかの要素から得られる必要があり、より大きなアンカーを選択すると常に合計が増加するため、k 個の最大要素を「アンカー」として割り当てることが戦略となります。 

特定の要素がセグメント最大値として機能することを決定したら、残りのタスクは、順序を維持しながら、選択された各最大値が独自のセグメントに分離されるようにカットを分散することになります。 これにより、問題は、k 個の要素を選択し、選択された各要素が左から最初にセグメント最大値が出現するようにカットを配置する方法を数えることに変換されます。 

要素を値の降順に処理し、各「上位 k 」要素がセグメントを開始できる場所を決定します。 連続して選択したアンカー間で、自由な位置の数によってカットを配置できる方法の数が決まり、これは乗法的なカウント プロセスになります。

 ## アルゴリズムのチュートリアル

 まず、順列内のすべての値の位置を特定します。 これは順列であるため、1 から n までの各値は 1 回だけ出現するため、位置配列 pos[value] を構築できます。 

次に、値が含まれている場合は、より大きな値がセグメント最大値を支配する必要があるため、値を降順で処理します。

1. n から 1 まで値を繰り返し、k 個の最大値の位置を収集します。 これらのポジションは、最大合計に貢献できる唯一の候補者です。 これは、選択した最大値をより小さい値に置き換えると、合計が厳密に減少するためです。 
2. 選択した位置を昇順に並べ替えます。 これらの位置は、左から右へのセグメントの構造を定義します。 
3. 選択された各アンカーがセグメントの最大値として 1 回だけ寄与するため、最大可能合計は単に k 個の最大値の合計です。 
4. 構成をカウントするために、連続する選択された位置間のギャップを調べます。 選択された位置が x1 < x2 < ... < xk であるとします。 連続する各ペアについて、利用可能なカット位置の数は xi+1 − xi です。 このような各ギャップは、有効なパーティションの数に独立して寄与します。 
5. 最終的な答えは、これらすべてのギャップ サイズの積、モジュロ 998244353 です。 

どの要素がセグメント最大値であるかを決定すると、連続して選択された最大値の間の各ギャップで 1 つのカットを選択することによってすべての有効なパーティションが決定されるため、カウントは機能します。 カットはセグメントの境界を越えることができないため、各ギャップは独立して動作します。 

### なぜ効果があるのか

 このアルゴリズムは、最適解では、k 個の最大値がそれぞれ別個のセグメントの最大値として現れる必要があるという事実に基づいています。 他の構成は、より小さなセグメントの最大値をより大きな未使用の値と交換することで変換でき、目的を厳密に高めます。 これらの最大値が固定されると、分割の自由度は、まさに連続する最大値間のセグメントをどこで区切るかの選択となり、これらの選択はギャップ全体で独立します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, k = map(int, input().split())
    p = list(map(int, input().split()))

    pos = [0] * (n + 1)
    for i, v in enumerate(p):
        pos[v] = i

    # take k largest values
    chosen_vals = list(range(n, n - k, -1))
    chosen_pos = [pos[v] for v in chosen_vals]
    chosen_pos.sort()

    # maximum sum
    max_sum = sum(chosen_vals)

    # count ways
    ways = 1
    for i in range(k - 1):
        gap = chosen_pos[i + 1] - chosen_pos[i]
        ways = (ways * gap) % MOD

    print(max_sum, ways)

if __name__ == "__main__":
    solve()
```位置配列を使用すると、各値が順列内のどこに位置するかを定数時間で検索できるため、スキャンの繰り返しが回避されます。 置換順序が値の順序と一致していないため、選択した位置を並べ替える必要があります。 

カウント ループは、連続して選択された最大値間のギャップを増やします。 各ギャップは、セグメントの最大値を固定に保つ有効なカット配置の数を表します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import prod

    MOD = 998244353

    n, k = map(int, input().split())
    p = list(map(int, input().split()))

    pos = [0] * (n + 1)
    for i, v in enumerate(p):
        pos[v] = i

    chosen = list(range(n, n - k, -1))
    chosen_pos = sorted(pos[v] for v in chosen)

    ans_sum = sum(chosen)
    ways = 1
    for i in range(k - 1):
        ways = (ways * (chosen_pos[i + 1] - chosen_pos[i])) % MOD

    return f"{ans_sum} {ways}"

# sample
assert run("3 2\n2 1 3\n") == "5 2"

# minimum k = 1
assert run("4 1\n4 1 2 3\n") == "4 1"

# maximum k = n
assert run("3 3\n1 2 3\n") == "6 1"

# reversed permutation
assert run("5 2\n5 4 3 2 1\n") == "9 4"

# random structure
assert run("5 3\n2 5 1 4 3\n") == "12 2"

 ## 特殊なケース

 k = 1 の場合、配列全体が 1 つのセグメントになります。 このアルゴリズムでは最大の要素のみが選択され、ギャップがないため積ループは空になり、単一の有効なパーティションに一致する 1 を返します。 

k = n の場合、すべての要素が独自のセグメントを形成します。 選択された値はすべての要素であり、連続する位置が 1 だけ異なるため、ギャップはすべて 1 になります。積は 1 のままで、パーティションが 1 つだけ存在するという事実と一致します。
