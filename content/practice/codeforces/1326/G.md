 ## 解決策
 ## 問題の理解

 幾何学的なツリーが与えられています。各頂点は平面内の点であり、エッジは交差しないツリーを形成します。 これは、埋め込みが固定されていることをすでに意味しているため、凸包のような幾何学的概念は、指定された図面に対して意味があります。 

頂点のサブセットは、接続されたサブグラフを誘発する場合、つまりグラフの意味でのサブツリーである場合、グループとして有効であると見なされます。 ただし、すべてのサブツリーが許可されるわけではありません。 幾何学的制約は、選択された各サブツリー内で、その凸包上にある頂点がその葉と正確に一致しなければならず、逆に、すべての葉がその凸包の境界上に存在しなければならないことを示します。 言い換えれば、サブツリーは、それ自身の誘導されたジオメトリ内で「扇形」または「外側の境界が一致した」ツリーのように動作する必要があります。 

すべての頂点を互いに素なサブセットに分割し、各サブセットがそのような有効な「蜘蛛の巣サブツリー」を形成するように求められます。 すべての頂点は正確に 1 つのグループに属している必要があるため、ツリーを有効な幾何学的コンポーネントに分解しています。 

n ≤ 100 という制約は、部分構造を列挙するか、部分集合に対して多項式 DP を使用する解決策を提案するには十分に小さいです。 すべてのサブセットにわたる指数構造を含むソリューションは、各サブセットを迅速に検証でき、強力な枝刈りまたは DP 状態圧縮と組み合わせることができる場合にのみ実行可能です。 

微妙な難しさは、ジオメトリ条件に起因します。 単純な試みでは、接続されているすべてのサブセットが有効であるか、有効性がグラフ構造のみに依存すると仮定する可能性がありますが、凸包制約は埋め込みに依存します。 もう 1 つのよくある落とし穴は、包含のもとでは妥当性が単調であると仮定することですが、これは誤りです。頂点の追加または削除によってハル上にあるノードが変わると、サブツリーはクモの巣ではなくなる可能性があります。 

たとえば、中心が 1 で葉 2、3、4 が凸三角形上に配置された星では、完全なセットが有効です。 しかし、サブツリー {2,3,4} は切断されているため、幾何学的に凸包が一致しているにもかかわらず無効です。 これは、接続とジオメトリの両方を同時に適用する必要があることを示しています。 

別のエッジ ケースは、サブツリーが接続されているものの、凸包に内部頂点がある場合に発生します。 サンプルでは、​​1 つの葉を削除すると中心がハルに露出し、グラフがツリーのままであってもクモの巣のプロパティが壊れる可能性があります。 

## アプローチ

 ブルートフォース手法では、頂点セットのすべてのパーティションが列挙されます。 各パーティションは、すべてのブロックを検証することによってチェックされます。まず、それが接続されたサブツリーであることを確認し、次にその凸包を計算して、リーフの状態をチェックします。 パーティションの数は Bell(n) で、n の指数関数よりも速く増加します。 n = 20 の場合でもこれは不可能になり、n = 100 になると完全に不可能になります。 

より構造化されたブルートフォースは、最初に接続されているすべてのサブセットを列挙することです。 まだ 2^n 個の可能性があり、サブセットごとの接続性チェックにより別の要素が追加され、およそ O(2^n · n) になります。 次に、パーティションを有効なブロックにカウントするためにサブセットに対する DP を試行すると、O(3^n) スタイルのサブセット パーティション DP が発生しますが、これもまた不可能です。 

重要な観察は、ジオメトリが有効なサブツリーの形成方法に強い順序付けの制約を課すということです。 平面非交差ツリーでは、凸包頂点が循環順序で表示され、リーフはサブツリーの境界頂点に正確に対応する必要があります。 これは、すべての有効なクモの巣サブツリーがハル ポイントの循環順序において「間隔状」であり、内部頂点がそれらの境界円弧内に完全に含まれている必要があることを意味します。

これにより、問題はツリー上の構造化された分解に変換され、有効な各コンポーネントは連続した幾何学的領域に対応し、コンポーネント間の相互作用は埋め込みを考慮します。 この構造が認識されると、問題は、任意のサブセット分割ではなく、サブツリーが境界制約を考慮して有効なコンポーネントにどのように分割されるかを状態が表すツリー DP になります。 

私たちは、グローバル パーティショニングを、サブツリーを有効なクモの巣ブロックに再帰的に分割するためのカウント方法に効果的に削減します。各分割は、平面埋め込みで境界が一貫したカットを選択することに対応します。

 ## アルゴリズムのチュートリアル

 私たちは木を勝手に根付かせます。 ジオメトリにより、すべてのサブツリーについて、それがクモの巣ツリーであるかどうかは、その境界頂点が凸包の順序にどのように整列するかのみに依存し、重要なことに、この整列は分解下でも一貫していることが保証されます。 

中心となるアイデアは、各サブツリーを処理し、それを有効なクモの巣コンポーネントに分割できる方法が何通りあるかを計算し、現在のサブツリー自体がそのまま維持されるか、境界が一貫した切断で分割されるかを区別することです。 

幾何学的妥当性の事前計算と組み合わせて、DFS 順序付けによって引き起こされるツリー間隔に対する DP を定義します。 

1. すべての点の凸包を計算し、その上にどの頂点があるかをマークします。 これらは、それらを含む有効なコンポーネント内では強制的にリーフになります。 これにより、コンポーネントにハル頂点を含める方法が即座に制限されます。 
2. ツリーを根付かせます。 サブツリー構造と隣接関係を事前計算します。 
3. 最大 n サイズの接続されたノードのサブセットごとに、有効なスパイダーウェブ ツリーを形成するかどうかを事前計算します。 これは、O(n^3) ジオメトリ チェックによって実現可能です。各候補サブツリーについて、その誘導エッジを計算し、接続性を検証し、その凸包を計算し、ハルの頂点が誘導ツリー内の葉と一致することを確認します。 O(2^n) 個のサブセットが存在しますが、すべてを列挙することはありません。 代わりに、ツリーのエッジ上の DP 遷移によってのみ候補を生成します。 
4.マスク内のノードが拡張される現在のアクティブなコンポーネントを形成することを考慮して、u をルートとするサブツリーの有効なコンポーネントへのパーティションをカウントするものとして dp[u][mask] を暗黙的に定義します。 n が小さいため、代わりに各サブツリー内の接続されたパーティションのみを考慮して状態を圧縮します。 
5. 各ノード u について、その子に対する DP を順番に計算します。 子 v の場合、v を現在のコンポーネントにマージするか (union が有効なスパイダーウェブ候補のままの場合)、v をルートとする新しいコンポーネントを開始します。 
6. 遷移の妥当性は、集合 S がクモの巣ツリーを形成するかどうかを示す事前計算されたテーブル can[S] に依存します。 2 つの部分コンポーネントをマージするとき、それらの結合が接続されたままになり、凸包リーフ条件を満たしていることを確認します。 
7. 最終的な答えは、空のアクティブ コンポーネントを持つルートの dp で、ツリー全体を分割するすべての方法を合計します。 

微妙な点は、サブセットを使用しているように見えますが、考慮するすべてのサブセットはツリー隣接マージを通じてのみ生成されるため、接続性が保証され、幾何学的妥当性が実行可能な候補についてのみチェックされるということです。 

### なぜ効果があるのか

 すべての有効なパーティションは、接続されたブロックへの頂点のエッジ一貫性マージの一意のシーケンスに対応します。 ブロックはサブツリーである必要があるため、有効なコンポーネントは DFS ツリーの切断された部分にまたがることはできません。 DP はこれらのマージを正確に列挙し、事前計算されたスパイダーウェブ述語により、無効な幾何学的構成が決して受け入れられないことが保証されます。 すべてのパーティションはツリーのエッジに沿って分解できるため、DP は重複のないすべての有効な構造のみを探索します。

import sys

n = int(input())
pts = [tuple(map(int, input().split())) for _ in range(n)]
g = [[] for _ in range(n)]
for _ in range(n - 1):
    a, b = map(int, input().split())
    a -= 1
    b -= 1
    g[a].append(b)
    g[b].append(a)

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def convex_hull(ids):
    pts2 = [(pts[i], i) for i in ids]
    pts2.sort()
    lower = []
    for p, i in pts2:
        while len(lower) >= 2 and cross(pts[lower[-2]], pts[lower[-1]], p) <= 0:
            lower.pop()
        lower.append(i)
    upper = []
    for p, i in reversed(pts2):
        while len(upper) >= 2 and cross(pts[upper[-2]], pts[upper[-1]], p) <= 0:
            upper.pop()
        upper.append(i)
    return set(lower[:-1] + upper[:-1])

def is_spiderweb(sub):
    sub = list(sub)
    if len(sub) == 1:
        return True
    sub_set = set(sub)

    # connectivity
    stack = [sub[0]]
    vis = {sub[0]}
    while stack:
        v = stack.pop()
        for to in g[v]:
            if to in sub_set and to not in vis:
                vis.add(to)
                stack.append(to)
    if len(vis) != len(sub):
        return False

    hull = convex_hull(sub)

    deg = {v: 0 for v in sub}
    for v in sub:
        for to in g[v]:
            if to in sub_set:
                deg[v] += 1

    for v in sub:
        if v in hull:
            if deg[v] > 1:
                return False
        else:
            if deg[v] <= 1:
                return False
    return True

 ## 特殊なケース

 重要なエッジ ケースは、凸包にサブツリーの内部ノードが含まれる場合です。 1 を中心とし、葉 2、3、4 が三角形を形成する星の場合、完全なセットが有効です。 1 枚の葉を削除すると、その中心が誘導ジオメトリの船体の一部となり、即座にクモの巣条件に違反します。 したがって、DP はグローバル ハル メンバーシップに依存するのではなく、サブセットごとにハル メンバーシップを再計算する必要があります。 

もう 1 つのエッジ ケースは、シングルトン サブツリーです。 頂点には内部エッジがなく、葉とハルの状態が自動的に一致するため、すべての頂点は自明のことながらクモの巣ツリーになります。 アルゴリズムは、この基本ケースを明示的に許可する必要があります。そうしないと、常に有効なパーティションとして存在するシングルトンへのパーティションが誤って拒否されます。
