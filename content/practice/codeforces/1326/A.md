 ## 問題の理解

 正の 10 進数を正確に構築する必要があります。`n`数字。 すべての数字はゼロ以外でなければならず、整数はその中に現れる各数字で割り切れない必要があります。 

各テスト ケースでは、入力により必要な長さのみが得られます。`n`。 その長さの有効な数値を出力できます。 そのような番号が存在しない場合は、印刷します`-1`。 

この制約は、候補番号を検索することが期待されていないことをすぐに示唆しています。 1 つのテスト ケースでは、最大で次の数を生成する必要がある場合があります。`10^5`桁数、すべての長さの合計も最大です`10^5`。 多くの候補を調べたり、巨大な整数に対して高価な演算を実行したりするアルゴリズムは不要になります。 意図したソリューションでは、出力サイズに直接比例する時間で答えを構築する必要があります。 

最初の明白ではないエッジケースは次のとおりです。`n = 1`。 

入力：```
1
1
```出力：```
-1
```1 桁の正の数は常にそれ自身で割り切れます。 数値内の唯一の桁が数値と等しいため、有効な答えは存在しません。 

もう 1 つの簡単な間違いは、次のものだけからなる数値を作成することです。`9`s.

 入力：```
1
3
```候補者：```
999
```これは失敗します。`999`で割り切れます`9`。 ゼロ桁がないだけでは十分ではありません。 

3 番目の間違いは、存在するすべての桁で割り算が失敗する必要があることを忘れていることです。 例えば：```
444
```で割り切れます`4`, したがって、すべての数字がゼロ以外であっても無効です。 

課題は、可算性を効率的にチェックすることではありません。 課題は、1 を超えるすべての長さに対して確実に機能するパターンを見つけることです。 

## アプローチ

 ブルートフォース戦略では、`n`-桁の数字を入力し、各候補が条件を満たすかどうかをテストします。 1 つの候補をテストするのは簡単です。その桁を検査し、各桁で割り切れるかどうかを確認します。 問題は検索スペースです。 がある`9^n`との数字`n`ゼロ以外の数字。 たとえ`n = 20`、これはすでに天文学的な規模です。 のために`n = 100000`、網羅的な検索はまったく不可能です。 

重要な点は、有効な回答は 1 つだけ必要であり、すべてではないということです。 

数字だけを含む数値を作成するとします。`2`そして`3`。 数値が奇数の場合は、次の数で割り切れません。`2`。 桁の合計が倍数でない場合`3`の場合、次の値で割り切れません。`3`。 これらは数値に現れる唯一の数字であるため、両方の要件が満たされます。 

非常に単純なパターンでまさにこれを実現できます。```
2333...333
```最初の桁は`2`、そして残りの`n - 1`数字は`3`。 

検証してみましょう。 

最後の桁は`3`したがって、この数は奇数であり、次の数で割り切れません。`2`。 

桁の合計は以下に等しい$$2 + 3(n-1)=3n-1.$$以来`3n - 1`残りを残す`2`で割ると`3`、その数は次の値で割り切れません。`3`。 

存在する唯一の数字は、`2`そして`3`, したがって、数値はどの桁でも割り切れません。 

この構造はあらゆる用途に適しています。`n > 1`。

 ## アルゴリズムのチュートリアル

 1.読む`n`。 
2. もし`n = 1`、印刷`-1`。 

1 桁の正の数は常にその唯一の桁で割り切れるため、解は存在しません。 
3. それ以外の場合は、次の 1 つの文字列で構成される文字列を出力します。`'2'`に続く`n - 1`のコピー`'3'`。 

これにより、`n`- 数字のみを含む数字`2`そして`3`。 

### なぜ効果があるのか

 あらゆる人にとって`n > 1`、構築された数値は数字で終わります`3`、だから不思議です。 で割り切れる任意の数`2`偶数である必要があるため、この数は次の数で割り切れません。`2`。 

桁の合計は$$2 + 3(n-1)=3n-1.$$この値は次では割り切れません`3`したがって、数値自体は次の値で割り切れません。`3`。 

数字に表示される唯一の数字は、`2`そして`3`。 この数はどちらでも割り切れないことを示しました。 したがって、10 進表現に現れるどの数字でも割り切れません。 

のために`n = 1`、有効な番号が存在しないため、印刷します`-1`は正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())

        if n == 1:
            ans.append("-1")
        else:
            ans.append("2" + "3" * (n - 1))

    sys.stdout.write("\n".join(ans))

solve()
```プログラムは各テスト ケースを独立して処理します。 

特別な場合`n == 1`最初に処理する必要があります。 このケースを忘れると、`"2"`、これは無効です。`2`で割り切れます`2`。 

それよりも長いすべての場合、式は次のようになります。`"2" + "3" * (n - 1)`必要な文字列を直接構築します。 巨大な整数を構築するよりも、文字列を操作する方が望ましいためです。`n`到達できる`100000`。 この問題は数値を出力することだけを要求しており、数値の計算は実行しません。 

出力はリストに蓄積され、最後に一度出力されます。 これにより、出力操作の繰り返しが回避され、標準的な競技プログラミングの実践に適合します。
