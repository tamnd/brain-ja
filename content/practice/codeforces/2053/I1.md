 ## 問題の理解

 整数配列が与えられます`a`新しい配列を作成するように求められました`b`含まれている`a`部分列として、合計は次と同じになります。`a`、最大部分配列合計、いわゆる退屈を最小限に抑えます。 最小の退屈を達成する配列の中で、要素が最も少ない配列が必要であり、その長さを報告する必要があります。`m`。 事実上、要素間に負でない数値またはゼロを挿入できます。`a`合計を変更せずに、連続するセグメントのピーク合計を削減します。 

入力は複数のテスト ケースを提供し、それぞれに配列の長さが含まれます。`n`配列要素が続きます。 重要な制約は次のとおりです。`n`すべてのテスト ケース全体で最大 300 万件になる可能性があり、個々の要素の規模が大きくなる可能性があります。 これらの限界のため、すべての可能な部分配列を反復する解法は遅すぎます。 テスト ケースごとに線形または線形に近いソリューションが必要です。 明らかではないエッジ ケースには、大きな負の数を含む配列 (自然な最大サブ配列合計が個々の正の数より小さい場合)、または既に非増加パターンがあり、最小退屈値がすべての正の要素の正確な合計である配列が含まれます。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての配列を生成しようとします。`b`を含む`a`サブシーケンスとして、それぞれの最大部分配列合計を計算し、退屈を最小限に抑えるものを選択します。 の要素間に数値を挿入する方法は指数関数的に多く存在するため、これは明らかに非現実的です。`a`、最大部分配列の合計を繰り返し計算すると、配列あたり O(n²) になります。 

重要な洞察は、最大サブ配列合計に対する数値の挿入の影響を観察することで得られます。 The maximum subarray sum of`b`の要素の累積合計の影響を受けます。`a`。 これを最小限に抑えるには、追加要素全体に合計を分散することで、プレフィックス合計の大幅な上昇を抑える必要があります。 正式には、累計が何らかのしきい値を超えた場合、ゼロまたは負の数値を挿入して、合計を変更せずに中間ピークを減らすことができます。 これにより、元の配列の最大プレフィックス合計を計算する問題が軽減されます。`a`そして、サブアレイがそのピークを超えないようにするために必要な「ギャップ」の数を決定します。 

この簡単なバージョンでは、合計がゼロを超える頻度を数え、それに応じて長さを調整しながら累積合計をシミュレートするだけで十分です。 結果は最小の長さになります`m`それは最小限の退屈を実現します。

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`current_sum`反復処理中に実行中のプレフィックス合計を追跡するには、ゼロに設定します。`a`。 初期化もする`max_boredom`発生した最大の累積合計を記録するには、ゼロにします。 
2. 各要素について`x`で`a`に追加します`current_sum`。 アップデート`max_boredom`それ自体の最大値になることと、`current_sum`。 これにより、追加の要素を挿入することなく、連続する最大の正の累積が取得されます。 
3. 合計を計算します`total_sum`配列の`a`。 問題によると、可能な最小限の退屈はこの合計を超えることはできず、私たちの構造では、挿入される要素の最小限の数でそれが達成可能であることが保証されます。 
4. 大きな正の実行を分割するために必要な追加要素の数を決定します。 概念的には、累積合計が増加するたびに、最小限の退屈を超えないように新しい要素を挿入する必要がある場合があります。 この簡単なバージョンでは、配列の最小長は`m`単純に、プラスの寄与の数と元の長さを足した合計です。`n`。 
5. 計算結果を出力します。`m`テストケース用。 

機能する理由: プレフィックス合計アプローチでは、退屈の定義を反映して、連続合計の最大値が直接追跡されることが保証されます。 累積和がどのように増加するかを考慮し、ピークを回避する要素を挿入することで、最小の最大部分配列和を達成できます。 合計金額が保存されるため、`a`サブシーケンスのままであれば、すべての制約が満たされます。 挿入の最小数は直接最小長を与えます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total_sum = sum(a)
        current_sum = 0
        max_boredom = 0
        for x in a:
            current_sum += x
            max_boredom = max(max_boredom, current_sum)
        # minimal length is total_sum + extra elements to spread peaks
        print(total_sum + (max_boredom - total_sum if max_boredom > total_sum else 0))

if __name__ == "__main__":
    solve()
```このコードは、高速 I/O を使用して入力を読み取り、大規模なデータセットを処理します。 現在の累積合計を計算し、発生した最大合計を更新します。 print ステートメントは、配列の合計を使用して最小長を計算し、それを超えるピークを調整します。 負の数は累積和を減らすため、境界条件が処理され、最大値関数によって増加のみが保証されます。`m`必要なときに。
