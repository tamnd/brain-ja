 ## 解決策
 ## 問題の理解

 値が次の範囲にある配列が与えられます。`1`そして`n`。 要素は何度でも再利用できるため、重要なのは、値が何回出現するかではなく、配列内にどの値が存在するかだけです。 

すべての整数に対して`i`から`1`に`n`、その積が正確に一致する、選択された配列値の最小数を見つけなければなりません。`i`。 そのような積が形成できない場合は、出力します。`-1`。 

問題を乗算グラフとして表示するのは便利な方法です。 値の場合`k`配列内に表示され、次に製品から表示されます`x`に移動するかもしれません`x * k`を超えない限り、`n`。 すべての乗算では、選択された要素がもう 1 つ使用されます。 

の合計`n`すべてのテストケース全体で最大でも`3 · 10^5`。 近い解決策`O(n^2)`すぐに除外されます。 周りに何かが必要です`O(n log n)`テストケース全体にわたって。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

考慮する：```
n = 3
a = [1, 1, 1]
```製品`1`は選択した 1 つの要素で取得できるため、`1`は`1`、 ない`0`。 このステートメントでは、少なくとも 1 つの要素を選択する必要があります。 

考慮する：```
n = 4
a = [2]
```製品`4`として入手可能です`2 · 2`配列に含まれるのが 1 つだけであるにもかかわらず、`2`。 再利用は許可されています。 

考慮する：```
n = 5
a = [2, 4]
```製品`3`不可能です。 すべての数値がより小さい数値から構築できると仮定する不注意な DP は、その数値が到達可能であると誤ってマークすることになります。 

## アプローチ

 この強引なアイデアは、すべての製品を状態として扱い、最短パスの検索を実行することです。 製品から`x`、利用可能なすべての配列値を乗算してみてください。 すべての乗算はもう 1 つの要素を選択することに相当するため、これは正しいです。 

問題はトランジションの回数です。 あれば`Θ(n)`利用可能な個別の値をすべての状態からすべて調べると、複雑さは次のようになります。`Θ(n^2)`、これは大きすぎます`n = 3 · 10^5`。 

重要な観察事項は、すべての製品が最大でも`n`、すべての遷移は次の形式をとります。```
x -> x * k
```どこ`k`配列内に存在する値です。 

以来`k ≥ 2`あらゆる有用な乗算では、宛先はソースよりも厳密に大きくなります。 グラフは DAG であり、その位相順序は単に数値の増加順です。 

させて`dp[x]`積を取得するために必要な選択された要素の最小数になります。`x`、ニュートラルな製品から始めると仮定します。`1`費用がかかる`0`。 

加工するとき`x`、利用可能なすべての乗数`k`リラクゼーションを生み出します:```
dp[x * k] = min(dp[x * k], dp[x] + 1)
```すべての状態で利用可能なすべての値を反復する代わりに、すべての可能な乗数を反復します。`k`まで`n / x`そして単に次のことを確認してください`k`が配列内に存在します。 

検査されるペアの総数は次のとおりです。```
Σ floor(n / x)
```それは`O(n log n)`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ブール配列を構築する`present`、 どこ`present[v]`値の場合は true`v`配列に表示されます。 
2. 無限大で初期化された DP 配列を作成します。 
3.セット`dp[1] = 0`。 これは、要素を選択する前の空の製品を表します。 
4. プロセス番号`x`から`1`に`n`昇順で。 
5. もし`dp[x]`はまだ無限大です。積なのでスキップしてください`x`形成できません。 
6. すべての乗数について`k`から`2`に`⌊n / x⌋`：

もし`present[k]`それは本当です、リラックスしてください```
dp[x * k] = min(dp[x * k], dp[x] + 1)
```の乗算`k`追加の配列要素を 1 つ選択することに相当します。 
7. 答えを組み立てます。 

のために`i > 1`、答えは`dp[i]`有限の場合、そうでない場合`-1`。 

のために`i = 1`、答えは次のとおりです。```
1  if present[1]
-1 otherwise
```出力できません`0`少なくとも 1 つの要素を選択する必要があるためです。 

### なぜ効果があるのか

 グラフには次のエッジが含まれています`x`に`x * k`いつでも値`k`配列内に存在します。 すべてのエッジにはコストがかかります`1`、そしてすべてのエッジは厳密に大きなノードに行きます。 したがって、数値順序の増加は有効なトポロジー順序となります。 

加工時`x`、`dp[x]`すでに製品からの最短経路長と等しくなります`1`に`x`。 すべての出力エッジを緩和すると、最適な値がより大きな製品に伝播されます。 すべてのパスは選択された配列要素のシーケンスに正確に対応するため、`dp[i]`積が以下になる選択された要素の最小数になります。`i`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        present = [False] * (n + 1)
        for x in a:
            present[x] = True

        INF = 10 ** 9
        dp = [INF] * (n + 1)
        dp[1] = 0

        for x in range(1, n + 1):
            if dp[x] == INF:
                continue

            limit = n // x
            for k in range(2, limit + 1):
                if present[k]:
                    nx = x * k
                    if dp[nx] > dp[x] + 1:
                        dp[nx] = dp[x] + 1

        ans = []

        if present[1]:
            ans.append("1")
        else:
            ans.append("-1")

        for i in range(2, n + 1):
            if dp[i] == INF:
                ans.append("-1")
            else:
                ans.append(str(dp[i]))

        print(" ".join(ans))

solve()
```の`present`配列は重複する値をすべて削除します。 要素は無限に何度も再利用できるため、重要なのは存在だけです。 

DP は製品から始まります`1`費用がかかる`0`。 これは仮想的な開始状態であり、それ自体は有効な答えではありません。 だからこそ、製品に対する答えは`1`は別扱いとなります。 

ループの順序は重要です。 処理`x`すべての遷移がより大きな番号に進むため、昇順で機能します。 優先キューや繰り返しの緩和は必要ありません。 

もう 1 つの微妙な点は、乗数が次から始まることです。`2`。 乗算`1`製品を変更することはなく、自己ループが作成されます。 このような遷移は最短パスには役に立たないため、無視できます。

 ## 特殊なケース

 次のことを考慮してください。```
1
3
1 1 1
```DPは維持します`dp[1] = 0`、しかし製品の最終的な答えは`1`DP からは取得されません。 アルゴリズムチェック`present[1]`そして出力`1`、少なくとも 1 つの要素を選択する必要があるという要件を満たしています。 

考慮する：```
1
4
2 2 2 2
```処理`x = 1`作成します`dp[2] = 1`。 後は加工`x = 2`作成します`dp[4] = 2`。 このアルゴリズムでは、配列内に 1 つしか存在しない場合でも、同じ値を繰り返し使用することが正しく許可されます。 

考慮する：```
1
5
2 4 4 2 2
```いかなる移行も到達できない`3`または`5`。 DP 値は無限大のままであるため、アルゴリズムは次のように出力します。`-1`両方のターゲットに対して。 これにより、到達できない製品が有効としてマークされるのを防ぎます。
