 ## 解決策
 ## 問題の理解

 ゲームは木の上で行われます。 Spyrosaliv がノード上で開始される`s`ノードに到達したい`d`。 すべてのターンで、彼は現在ブロックされていないエッジを越えて移動する必要があります。 到達`d`すぐに勝ちます。 正当な手を打てなかった場合は負けとなります。 

Spyrosaliv が行動するたびに、Cow the Cow にターンが与えられます。 牛はブロックされたエッジを 1 つ制御します。 前のブロックを削除して、別のエッジに新しいブロックを配置できます。 牛はスピロサリブが到達するのを阻止しようとしている`d`。 

重要な問題は、前の手を見て常に反応できる相手に対して、開始位置にチャンスがあるかどうかです。 

ノードの数は次のように大きくできます。`200000`, そのため、考えられる多くのゲーム状態を調査するような解決策は不可能です。 このサイズのツリーでは、線形時間に近いアルゴリズムのみが可能です。 動きをシミュレートするのではなく、木の構造特性を見つける必要があります。 

明らかではないエッジケースは、Spyrosaliv が最初に動くという事実によって引き起こされます。 目的地が直接隣接している場合、牛は決して干渉する機会がありません。 

例えば：```
2 1 2
1 2
```正しい出力は次のとおりです。```
YES
```Spyrosaliv はノードからすぐに移動します`1`ノードへ`2`。 

牛がルートをブロックできるかどうかのみを考慮する不注意なアプローチは、先手の利点を無視するため、牛が常に勝つという誤った言い方をすることになります。 

もう 1 つの重要なケースは、より長いパスです。```
3 1 3
1 2
2 3
```正しい出力は次のとおりです。```
NO
```Spyrosaliv がノードに移動`2`。 牛はノードにつながる唯一のエッジをブロックします`3`、そのため、スパイロサリブはターゲットに向かって続行できません。 後退することは、牛に後ろの端をブロックする機会を与えるだけです。 

大きなツリーでも同じ問題が発生します。 Spyrosaliv が現在のノードを離れた後、牛は目的地に向かうエッジを常にブロックできるため、余分な分岐は勝利戦略を作成しません。 

## アプローチ

 自然な総当たりアプローチは、ゲームをグラフ検索として扱うことです。 状態には、Spyrosaliv の現在のノードと現在ブロックされているエッジが含まれます。 あらゆる州から、あらゆる合法的な措置を試し、牛から起こり得るあらゆる反応をシミュレートすることができました。 これは最適なプレイを正確にモデル化しているため正しいですが、状態の数が多すぎます。 

まであります`n`可能なポジションと`n - 1`エッジがブロックされている可能性があり、大まかに示します`O(n^2)`州。 のために`n = 200000`、これは時間や記憶に収まる範囲をはるかに超えています。 

重要な観察は、宛先ノードでツリーをルート化することから得られます。`d`。 を除くすべてのノード`d`には、宛先に近づく親エッジが 1 つだけあります。 Spyrosaliv が隣接していない場合`d`、彼の最初の動きは、誰かの子供に移動すると考えることができます。`d`の根を張った木、または上向きに向かって進んでいる`d`。 ～に向かって成功するたびに、`d`、牛はスパイロサリブが次に必要とする正確なエッジをブロックすることができます。 

Spyrosaliv が現在ノードにあると仮定します`u`、およびからのエッジ`u`親への方向だけが有効です。 Spyrosaliv がどこかに移動すると、牛が新しいノードの親エッジをブロックする可能性があります。 その後、スピロサリブは目的地から強制退去させられます。 この戦略を繰り返すことで、スパイロサリブはさらに遠ざかります。`d`彼が行き止まりに達するまで。 

牛がこの機会を得ることができないのは、最初の動きだけです。 もし`s`に隣接しています`d`, スピロサリブはすぐに目的地に到着します。

 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ツリーを読み取り、すべてのノードの近隣ノードを保存します。 必要な情報は次のとおりです。`d`に直接接続されています`s`したがって、完全なトラバースは必要ありません。 
2. 隣接するものをすべてチェックします`s`。 それらのうちの 1 つが`d`, スピロサリブは最初のターンでそこに移動でき、牛が行動する前に勝ちます。 
3. もし`d`隣接していない`s`、出力`NO`。 牛は最初の移動後、目的地に向かう端をブロックすることで、いつでもスパイロサリブの進行をブロックできます。 

なぜ効果があるのか:

 ツリーをルート化する`d`。 すべてのノードには、距離を縮めるエッジが 1 つだけあります。`d`。 Spyrosaliv は、ターゲットに近づくためにこのようなエッジを繰り返し使用する必要があります。 移動するたびに、牛はスパイロサリブの新しい位置を認識し、次の減少エッジをブロックすることができます。 牛はスピロサリブの後に行動するため、この戦略から逃れられる唯一の方法は到達することです。`d`最初の動きで。 それはまさにそのときに起こります`s`そして`d`隣接している。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, s, d = map(int, input().split())
    adj = [[] for _ in range(n + 1)]

    for _ in range(n - 1):
        u, v = map(int, input().split())
        adj[u].append(v)
        adj[v].append(u)

    for v in adj[s]:
        if v == d:
            print("YES")
            return

    print("NO")

if __name__ == "__main__":
    solve()
```答えは最初の動きに依存するため、実装には隣接リストのみが必要です。 親関係を保存したり、ゲームをシミュレートしたりする必要はありません。 

ループオーバー`adj[s]`考えられるすべての初動をチェックします。 そこに目的地が現れた場合、ゲームはすぐに Spyrosaliv に有利に終了します。 それ以外の場合、牛のブロック戦略はツリーの残りの部分に関係なく機能します。 

ノードには次の番号が付けられているため、インデックス作成のトリックは必要ありません。`1`隣接リストはサイズを指定して作成されます`n + 1`。
