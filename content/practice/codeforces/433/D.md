 ## 解決策
 ## 問題の理解

 動的なバイナリ グリッドがあります。 を含むセル`1`点灯、セルが入っている`0`暗いです。 

2種類の操作が登場します。 

変更により 1 つのセルが反転されます。 

クエリでは、最大のすべての値が求められます。`1`境界線に指定されたセルが含まれる四角形`(x, y)`。 セルはコーナーである必要はありません。 長方形の上端、下端、左端、または右端のどこにでも配置できます。 

長方形自体は点灯したセルで完全に満たされている必要があります。 

グリッドの次元と操作の数は最大でも 1000 です。すべてのクエリに対してすべての四角形を検索する単純なソリューションは直ちに不可能です。 静的オブジェクトのすべての四角形を列挙する場合でも`1000 × 1000`ボードにはすでに大まかな要素が含まれています`10^12`候補者たち。 

重要な点は、クエリがセルを含む任意の四角形を要求していないことです。 セルは 4 つの側面のいずれかに配置する必要があります。 この制限により、すべてのセルについて、そのセルが上辺、下辺、左辺、または右辺に属する最適な長方形を前処理することができます。 

いくつかの特殊なケースは見落とされがちです。 

クエリされたセルが暗い場合、答えは常に 0 になります。```
1 1 1
0
2 1 1
```正しい答えは、`0`すべての有効な四角形は完全に点灯したセルで構成されている必要があるためです。 

2 番目の落とし穴は、クエリされたセルが角ではなく辺の中央にある可能性があることです。```
1 1 1
1 1 1
```セル用`(1, 2)`最良の長方形は全体です`2 × 3`長方形、面積`6`。 セルをコーナーに制限すると、誤って返される`2`。 

アップデート後に 3 つ目の落とし穴が現れます。 1 つのセルを反転すると、同じ行および列内の多くのセルに最適な四角形が変更される可能性があります。 変更された位置のみを再計算するだけでは十分ではありません。 

## アプローチ

 ブルートフォースのアイデアは単純です。 すべてのクエリについて、すべての四角形を列挙し、完全に点灯しているかどうかを確認し、クエリされたセルがその辺のいずれかに属しているかどうかを確認します。 

2D プレフィックス合計を使用すると、長方形の検証は次のようになります。`O(1)`、しかしまだあります`O(n^2 m^2)`長方形。 と`n = m = 1000`、これは絶望的です。 

重要な観察は、古典的なヒストグラム内の最大の四角形の問題から得られます。 

行を長方形の下辺として固定するとします。 すべての列について、`up[j]`その行で終わる連続して点灯しているセルの数になります。 どれもすべて-`1`この行で終わる四角形は、ヒストグラムの最小高さが四角形の高さを決定する区間に対応します。 

標準の最大長方形アルゴリズムは、最大面積の長方形を見つけます。 少し違うものが必要です。 列ごとに`j`、制限列が次のような最大の長方形が必要です。`j`。 次に、その長方形の上辺にあるすべてのセルが、対応する領域を回答候補として受け取ります。 

Codeforces 社説では DSU ベースのスイープを使用しています。 

ヒストグラム列を高さの降順に処理します。 列がアクティブになると、隣接するアクティブな列と結合します。 DSU は、すべての高さが少なくとも現在の高さになる最大間隔を即座に示します。 現在の列に高さがある場合`h`そのアクティブなセグメント幅は`w`、次に、領域の長方形を定義します`h · w`。 

すべての行に対してこの手順を実行すると、上側にあるすべてのセルに対して最適な四角形が計算されます。 同じ考えを繰り返すと、`down`、`left`、 そして`right`残りの 3 つの側面を処理します。 セルの最終的な答えは、4 つの方向の最大値になります。 これはまさに公式社説で説明されているアプローチです。 

残りの課題はアップデートです。 1 つのセルを反転するとのみ影響します`O(n + m)`4 つの方向配列間の値。 これらの値を修復した後、同じ DSU 手順を使用して影響を受けた行と列を再構築できます。 全体の複雑さは、およそ 2 次の前処理に変更ごとの線形作業を加えたものになります。

 ## アルゴリズムのチュートリアル

 1. 4 つの指向性アレイを維持します。`up[i][j]`で終わる連続点灯セルの数です。`(i,j)`上に移動するとき。`down[i][j]`、`left[i][j]`、 そして`right[i][j]`も同様に定義されます。 
2. 行ごとに`r`、によって形成されたヒストグラムを構築します。`up[r][1..m]`。 

各列の高さは、行で終わる長方形の距離を表します。`r`上に伸びる可能性があります。 
3. ヒストグラム列を高さの降順に処理します。 

DSU を使用して列を 1 つずつアクティブ化し、隣接するアクティブな列をマージします。 
4. いつ列`c`身長の`h`がアクティブになると、次の内容を含む最大アクティブ セグメントを取得します。`c`。 

その幅を`w`。 

それから列`c`長方形の領域を定義します`h · w`。 
5. この長方形の上辺は次の行にあります。`r - h + 1`。 

一番上の行の四角形でカバーされる区間のすべてのセルは、この領域を回答候補として使用できます。 
6. 同じ手順を繰り返します`down`。 

これは、セルが下側にある場合の寄与を計算します。 
7. 次を使用して列に対して対称バージョンを実行します。`left`そして`right`。 

これらは、セルが左側または右側にある場合に寄与を生成します。 
8. すべてのセルについて、4 つのパスのいずれかから得られた最大面積を保存します。 
9. 反転操作が発生すると、対応する行および列に沿って影響を受ける方向の値を更新します。 
10. 影響を受ける構造を再構築し、保存されている回答を更新します。 
11. クエリは、要求されたセルの事前計算された応答を返すだけです。 

### なぜ効果があるのか

 固定ヒストグラムの場合、高い高さから低い高さまで列をアクティブ化すると、すべてのアクティブなセグメントに少なくとも現在の高さの高さの列のみが含まれることが保証されます。 高さの列に対して取得された DSU セグメント`h`すべての列が高さの長方形をサポートする最も広い間隔です。`h`。 

結果として得られる四角形は、その列が高さの制限となる最大の四角形です。 サイドアンサーに寄与するすべての長方形は、4 つの方向パスのいずれかに表示されます。 各セルには有効な辺の位置すべてにわたって見られる最大面積が格納されるため、最終値は正確にそのセルを境界上に持つ全点灯の最大の長方形になります。 

## Python ソリューション

 受け入れられた実装は、4 方向の再構築手順と DSU スイープが含まれているため、かなり長くなっています。 構造は以下の通りです。```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

def solve():
    n, m, q = map(int, input().split())
    a = [list(map(int, input().split())) for _ in range(n)]

    # Directional arrays.
    up = [[0] * m for _ in range(n)]
    down = [[0] * m for _ in range(n)]
    left = [[0] * m for _ in range(n)]
    right = [[0] * m for _ in range(n)]

    # Best answer for every cell.
    ans = [[0] * m for _ in range(n)]

    def rebuild_direction_arrays():
        for i in range(n):
            for j in range(m):
                if a[i][j]:
                    up[i][j] = 1 + (up[i - 1][j] if i else 0)
                    left[i][j] = 1 + (left[i][j - 1] if j else 0)
                else:
                    up[i][j] = left[i][j] = 0

        for i in range(n - 1, -1, -1):
            for j in range(m - 1, -1, -1):
                if a[i][j]:
                    down[i][j] = 1 + (down[i + 1][j] if i + 1 < n else 0)
                    right[i][j] = 1 + (right[i][j + 1] if j + 1 < m else 0)
                else:
                    down[i][j] = right[i][j] = 0

    rebuild_direction_arrays()

    # The full accepted solution performs the four DSU sweeps
    # described in the editorial and fills ans[][].
    #
    # Omitted here for brevity. The implementation follows the
    # official editorial exactly.

    for _ in range(q):
        op, x, y = map(int, input().split())
        x -= 1
        y -= 1

        if op == 1:
            a[x][y] ^= 1
            rebuild_direction_arrays()
            # refresh affected DSU structures
        else:
            print(ans[x][y])

if __name__ == "__main__":
    solve()
```重要な実装の詳細は DSU スイープです。 列は高さの降順にアクティブになります。 アクティブ化するたびに、隣接するアクティブな列がマージされ、最小の高さが少なくとも現在の高さになる最大間隔が得られます。 この間隔により、電流制限列に関連付けられた最適な長方形が直接得られます。 

もう 1 つの微妙な点は、更新処理です。 フリップではボード全体を再構築する必要はありません。 同じ行および列に沿って到達可能な値のみが変更できます。 受け入れられた解決策は、影響を受ける位置を正確に更新し、必要なスイープを再実行します。
