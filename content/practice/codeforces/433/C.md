 ## 解決策
 ## 問題の理解

 ノートブックのページには次の番号が付けられています。`1`に`n`。 シーケンス`a`涼子が情報を読み取る順序を説明します。 ページ内に 2 つの連続した情報がある場合`a[i]`そして`a[i+1]`、彼女は向きを変えなければなりません`|a[i] - a[i+1]|`ページ。 

合計の労力は、連続するすべてのペアにわたるこれらの距離の合計です。 

読書の前に、彼女は多くても 1 回の操作を行うことができます。 彼女はページ番号を選択します`x`そしてページ番号`y`、からすべてをコピーします`x`に`y`、およびすべての発生`x`シーケンス内は次のようになります`y`。 タスクは、この操作を 1 回適用した後、または何も変更しなかった後のページめくりの合計コストの最小値を見つけることです。 

入力サイズが大きいです。 両方`n`そして`m`到達できる`100000`。 シーケンス自体には以下を含めることができます`100000`要素、つまりすべてのペアを試すアルゴリズム`(x, y)`すぐには無理です。 まであります`10^10`そんなペアたち。 すべてのページ値について、考えられるすべてのターゲット ページをチェックするだけでも、制限時間をはるかに超えてしまいます。 

答えは 32 ビットの範囲を超えることもあります。 長さのシーケンス`100000`おおよそ貢献できる`100000 × 100000`したがって、64 ビット演算が必要です。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

考慮する：```
3 4
2 2 2 2
```コストはすでにゼロです。 異なるページ間の遷移はありません。 すべての値が少なくとも 1 つのエッジに関与していると想定するソリューションでは、誤って空の構造にアクセスする可能性があります。 

考慮する：```
5 2
1 5
```初期費用は、`4`。 ページの結合`5`ページに`1`シーケンスを生成します`[1,1]`そしてコスト`0`。 隣接するページではなく、ページの頻度のみを調べるソリューションでは、この改善は見逃されます。 

考慮する：```
5 5
1 2 1 2 1
```ページ`1`ページと対話する`2`4回。 そういった繰り返しが重要なのです。 隣接するものをマルチセットではなくセットとして扱うと、繰り返される遷移の寄与が過小評価され、誤ったゲインが生成されます。 

## アプローチ

 最も直接的なアイデアから始めましょう。 

ページを選択するとします`x`そして、それが出現するたびに何らかのページに置き換えます`y`。 シーケンスを再構築して総コストを再計算できます。 これをすべてのペアに対して行う`(x, y)`必要`O(n^2 m)`仕事。 

と`n = m = 100000`、これはおおよそです`10^15`操作、完全に実行不可能。 

重要な観察点は、ページを置き換えていることです。`x`接触しているトランジションのみに影響します`x`。 

ページ間の遷移を取る`u`そして`v`。 

どちらのエンドポイントも等しくない場合`x`、マージ後もトランジションは変更されず、まったく同じ量に寄与します。 に付随するエッジのみ`x`案件。 

固定ページ値の場合`x`の隣に表示されるすべてのページを収集します。`x`シーケンスで。 遷移が複数回発生する場合は、複数のコピーを保管してください。 この近傍のマルチセットを次のようにします。```
v1, v2, ..., vk
```変更前の総コストに含まれる部分は、`x`は```
|x-v1| + |x-v2| + ... + |x-vk|
```置き換えると`x`による`y`、になります。```
|y-v1| + |y-v2| + ... + |y-vk|
```ここで問題は次のようになります。 

各ページの値について`x`、値を見つけます`y`最小化する```
Σ |y-vi|
```これは絶対値の典型的な特性です。 最小値はマルチセットの中央値で達成されます。 

したがって、すべてのページ値に対して`x`:

 1. 隣接するページの値をすべて収集します。 
2. 現在の寄与を計算します。 
3. 近隣リストを並べ替えます。 
4. 中央値を取得します。 
5. 次の場合に寄与度を計算します。`x`その中央値に置き換えられました。 
6. 違いはページを最適に結合することで得られる改善です`x`。 

最良のマージとは、単にすべてのページ値の中で最大の改善を意味します。 

すべての近隣リストの合計サイズは、`2(m-1)`隣接するすべてのペアが各エンドポイントに 1 回ずつ寄与するためです。 すべてのリストをまとめて並べ替えるコスト`O(m log m)`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²m) | O(m) | 遅すぎる |
 | 最適 | O(m log m) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 合計して元の総コストを計算します。`|a[i] - a[i+1]|`すべての隣接するペアにわたって。 
2. 隣接するペアごとに`(a[i], a[i+1])`、値が異なる場合は、各エンドポイントを他のエンドポイントの近隣リストに追加します。 

これは、1 つのエンドポイントが変更された場合にどの遷移が影響を受けるかを正確に記録します。 
3. すべてのページの値について`x`から`1`に`n`、その近隣リストを処理します。 
4. コンピューティング```
old = Σ |x - v|
```すべての隣人の上に`v`の`x`。 

これは、接触しているすべてのトランジションの現在の寄与です。`x`。 
5. 近隣リストをソートし、その中央値を取得します。 

中央値は、絶対偏差の合計を最小化します。 
6. コンピューティング```
new = Σ |median - v|
```同じ近隣リスト上で。 
7. ページを最適に置き換えることによる利益`x`は```
gain = old - new
```8. すべてのページ値にわたって最大ゲインを維持します。 
9. 答えは次のとおりです。```
original_cost - maximum_gain
```### なぜ効果があるのか

 すべての移行は独立して総コストに影響します。 ページを差し替えます`x`に伴う遷移のみを変更します`x`; 他のすべての遷移は同一のままです。 

固定ページの場合`x`、目的の影響を受ける部分は正確に```
Σ |y - v|
```どこ`v`隣接するすべての範囲に及ぶ`x`、多重度でカウントされます。 古典的な中央値の性質は、この式が以下を選択することによって最小化されることを示しています。`y`マルチセットの中央値に等しい。 

各ページ値は個別に最適化でき、マージ操作は 1 回だけ許可されるため、全体的に最適な移動は、可能な限り最大の削減を実現するページです。 元のコストからその削減を差し引くと、達成可能な最小合計が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    neigh = [[] for _ in range(n + 1)]
    total = 0

    for i in range(m - 1):
        u = a[i]
        v = a[i + 1]

        total += abs(u - v)

        if u != v:
            neigh[u].append(v)
            neigh[v].append(u)

    best_gain = 0

    for x in range(1, n + 1):
        if not neigh[x]:
            continue

        vec = neigh[x]

        old = 0
        for v in vec:
            old += abs(x - v)

        vec.sort()
        med = vec[len(vec) // 2]

        new = 0
        for v in vec:
            new += abs(med - v)

        best_gain = max(best_gain, old - new)

    print(total - best_gain)

solve()
```最初のループでは、元のコストを計算し、同時に隣接リストを構築します。 すべての隣接するペアは、各エンドポイントに 1 つずつ、合計 2 つのリストに寄与します。 

両方のエンドポイントが等しい遷移は、近隣リストを作成するときに無視されます。 このような遷移はすでにゼロに寄与しており、マージに関係なくゼロのままであるため、ゲインの計算に影響を与えることはできません。 

各ページの値について、`old`すべてのインシデントの移行によって寄与される現在のコストを測定します。 近傍リストをソートした後、中央の要素が中央値になります。 ページをこの中央値で置き換えると、影響を受けるコストの可能な最小値が得られます。これは次のように計算されます。`new`。 

改善点は、`old - new`。 最大の改善は、最適なマージ操作に対応します。 

Python の整数は 32 ビットを超える値を自動的に処理するため、特別なオーバーフロー処理は必要ありません。

import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    def input():
        return sys.stdin.readline()

    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    neigh = [[] for _ in range(n + 1)]
    total = 0

    for i in range(m - 1):
        u = a[i]
        v = a[i + 1]

        total += abs(u - v)

        if u != v:
            neigh[u].append(v)
            neigh[v].append(u)

    best = 0

    for x in range(1, n + 1):
        if not neigh[x]:

        vec = neigh[x]

        old = sum(abs(x - v) for v in vec)

        vec.sort()
        med = vec[len(vec) // 2]

        new = sum(abs(med - v) for v in vec)

        best = max(best, old - new)

    return str(total - best)

## 特殊なケース

 次のことを考慮してください。```
1 1
1
```隣接するペアがないため、元のコストは`0`。 すべての近隣リストは空です。 アルゴリズムはすべてのページをスキップし、`best_gain = 0`、および出力`0`。 

考慮する：```
3 4
2 2 2 2
```隣接するすべての差はゼロです。 隣接する値はすべて等しいため、隣接する値は記録されません。 このアルゴリズムは空のリストの中央値を計算しようとすることはなく、正しく返されます。`0`。 

考慮する：```
5 2
1 5
```本来の費用は`4`。 ページ`1`近隣リストがある`[5]`、与える`old = 4`、`median = 5`、`new = 0`、 得`4`。 同じゲインがページに表示されます`5`。 最終的な答えは、`4 - 4 = 0`。 

考慮する：```
5 5
1 2 1 2 1
```ページの近隣リスト`1`は`[2,2,2,2]`、だけではありません`{2}`。 アルゴリズムは 4 つのコピーすべてを保存します。 その貢献は、`4`、と置き換えます`1`による`2`コストの 4 つの単位をすべて削除します。 近傍をセットとして扱うと、誤って 1 つの出現のみがカウントされ、ゲインが過小評価されます。
