 ## 解決策
 ## 問題の理解

 うちには水道の蛇口が２つあります。 最初のものはある温度で水を生成します`t1`、2番目の温度`t2`、 どこ`t1 ≤ t0 ≤ t2`。 

コールドタップは、以下の任意の整数の流量を供給できます。`0`に`x1`、ホットタップは以下の任意の整数の流量を供給できます。`0`に`x2`。 流量を選ぶ場合`y1`そして`y2`、結果として生じる混合温度は次のようになります。$$\frac{t_1y_1+t_2y_2}{y_1+y_2}.$$私たちの目標は、許容範囲内で整数の流量を選択し、結果として得られる温度が少なくとも`t0`。 すべての有効な選択肢の中で、最も近い温度が必要です。`t0`。 Since the temperature may not be exactly attainable, we minimize the excess above`t0`。 

いくつかの選択肢が同じ温度を生成する場合、ボブは浴槽がより早く満たされることを好むため、総流量を最大化します。`y1 + y2`。 

制限は次のとおりです`10^6`したがって、すべての可能なペアに対する総当たり攻撃`(y1, y2)`まで必要になります`10^12`2秒以内にチェックすることは完全に不可能です。 受け入れられた解決策は、温度公式の数学的構造を利用する必要があります。 

微妙な点は、目的が辞書編集的であることです。 まず上記の温度差を最小限に抑えます`t0`、次に総流量を最大化します。 溶液をより速く充填しても、温度の品質を犠牲にすることは許されません。 

もう 1 つの簡単な間違いは、温度が少なくとも`t0`。 例えば：```
t1 = 10, t2 = 70, t0 = 25
```ある温度の混合物`24.9`に近いです`25`混合物よりも`25.1`, ですが、温度が目標値を下回っているため無効です。 

冷水のみの使用が最適な場合もあります。```
10 70 100 100 10
```冷水だけでも、どの量でもすでに正確な温度が得られます`10`、ターゲットと一致します。 最良の選択は`(100, 0)`なぜなら、すべての完全一致の中で最も早くバスを満たすからです。 

最後に、いつ`t1 = t2 = t0`、すべての有効な混合物には正確な目標温度があります。 答えは単純に最大総流量です。`(x1, x2)`。 

## アプローチ

 直接総当たりですべてのペアを試すことになる$$0 \le y_1 \le x_1,\quad 0 \le y_2 \le x_2.$$各ペアについて結果の温度を計算し、以下の温度を破棄します。`t0`、必要な順序に従って最適な候補を保持します。 

推論は単純で完全に正しいですが、複雑です。$$O(x_1x_2).$$どちらの限界にも達する可能性があるので、`10^6`、これはおおよそになります`10^{12}`反復が多く、実行可能な範囲をはるかに超えています。 

重要な観察は、1 つの流量を固定すると、もう 1 つの流量は基本的に温度制約によって決定されるということです。 

お湯の量を固定するとします`y2`。 必要です$$\frac{t_1y_1+t_2y_2}{y_1+y_2}\ge t_0.$$乗算して並べ替えると、$$(t_0-t_1)y_1 \le (t_2-t_0)y_2.$$固定の場合`y2`、有効な最大値`y1`は$$y_1= \left\lfloor \frac{(t_2-t_0)y_2}{t_0-t_1} \right\rfloor.$$有効な最大値が必要な理由`y1`? 増えるから`y1`温度を下げます。 最も近い温度を探しているので、`t0`上記から、有効性を維持しながらできるだけ多くの冷水が必要です。 

今だけ`y2`まだ列挙する必要があります。 以来`x2 ≤ 10^6`可能なすべての熱水流量を反復することは完全に実現可能です。 

それぞれについて`y2`、許容最大値を計算します。`y1`、上限を次のとおりにします`x1`、得られた混合物を評価します。 これにより、検索が 2 次元から 1 次元に減ります。

 ## アルゴリズムのチュートリアル

 1. 答えを次のように初期化します。`(1, 0)`。 問題は保証します`x1 ≥ 1`したがって、少なくとも 1 つの有効な選択肢が常に存在します。 
2. 反復する`y2`から`0`に`x2`。 
3. もし`t0 = t1`、冷水のあらゆる量だけですでに目標を正確に満たしています。 この特殊な場合、最適な冷水の量は単純に次のとおりです。`x1`。 
4. それ以外の場合は計算します$$y_1= \left\lfloor \frac{(t_2-t_0)y_2}{t_0-t_1} \right\rfloor.$$これは、混合物の温度を少なくとも維持できる最大の冷水流量です。`t0`。 

1. タップ容量には限りがありますので交換してください。`y1`による`min(y1, x1)`。 
2. 大文字と小文字を区別しない`y1 = 0`そして`y2 = 0`温度が不定になるからです。 
3. 混合候補を現在の最良の回答と比較します。 

浮動小数点演算を使用する代わりに、相互乗算によって温度を比較します。$$\frac{t_1y_1+t_2y_2}{y_1+y_2}.$$候補者は、それが超過している場合に優れています`t0`より小さいです。 超過量が等しい場合は、大きい方を優先します。`y1+y2`。 

1. 最適な候補を保存して続行します。 
2. 選択したペアを出力します。 

### なぜ効果があるのか

 固定の場合`y2`、増加しています`y1`より多くの冷水が加えられるため、結果として得られる温度が下がります。 すべての有効な値の中で、`y1`、有効な最大のものは、次の値に最も近い温度を生成します。`t0`上から。 値が小さいと、温度がさらに暑くなり、厳密には悪化するだけです。 

アルゴリズムはあらゆる可能性を調べますので、`y2`、それぞれに独自の最良のものを選択します`y1`、潜在的に最適なソリューションがすべて考慮されます。 最終的な比較は、問題の順序に正確に従います。まず、上記の超過温度を最小限に抑えます。`t0`、次に総フローを最大化します。 したがって、選択されたペアは全体的に最適です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t1, t2, x1, x2, t0 = map(int, input().split())

    best_y1 = 1
    best_y2 = 0

    best_num = t1
    best_den = 1

    for y2 in range(x2 + 1):
        if t0 == t1:
            y1 = x1
        else:
            y1 = ((t2 - t0) * y2) // (t0 - t1)
            if y1 > x1:
                y1 = x1

        if y1 == 0 and y2 == 0:
            continue

        num = t1 * y1 + t2 * y2
        den = y1 + y2

        if num < t0 * den:
            continue

        cur_diff_num = num - t0 * den
        best_diff_num = best_num - t0 * best_den

        left = cur_diff_num * best_den
        right = best_diff_num * den

        better = False

        if left < right:
            better = True
        elif left == right and den > best_den:
            better = True

        if better:
            best_y1 = y1
            best_y2 = y2
            best_num = num
            best_den = den

    print(best_y1, best_y2)

solve()
```ループは、考えられるすべての温水流量を列挙します。 それぞれについて、温度制約から導出された式により、温度を少なくとも維持できる最大の冷水流量が得られます。`t0`。 

この実装では浮動小数点数は決して使用されません。 最小化される量は、$$\frac{\text{temperature}-t_0}{1},$$次のように書くことができます$$\frac{\text{num}-t_0\cdot\text{den}}{\text{den}}.$$このような 2 つの分数は、交差乗算を使用して比較されます。 Python の整数には任意の精度があるため、これにより精度の問題が回避され、安全性が保たれます。 

特別な場合`t0 == t1`注目に値する。 派生した数式はゼロで除算されるため、個別に処理する必要があります。 この状況では、あらゆる量の冷水を使用することが有効であり、可能な限り最大量を使用すると、最低温度と最速の充填速度が得られます。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    t1, t2, x1, x2, t0 = map(int, input().split())

    best_y1 = 1
    best_y2 = 0
    best_num = t1
    best_den = 1

    for y2 in range(x2 + 1):
        if t0 == t1:
            y1 = x1
        else:
            y1 = ((t2 - t0) * y2) // (t0 - t1)
            y1 = min(y1, x1)

        if y1 == 0 and y2 == 0:
            continue

        num = t1 * y1 + t2 * y2
        den = y1 + y2

        if num < t0 * den:
            continue

        cur = (num - t0 * den) * best_den
        prv = (best_num - t0 * best_den) * den

        if cur < prv or (cur == prv and den > best_den):
            best_y1 = y1
            best_y2 = y2
            best_num = num
            best_den = den

    return f"{best_y1} {best_y2}"
