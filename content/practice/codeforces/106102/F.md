 ## 解決策
 ## 問題の理解

 乗客は一人ずつ飛行機に乗り込んでいきます。 すべての乗客には固定列とその列内の固定座席があります。 

列内の座席`1`窓と座席の隣にあります`m`通路の隣にあります。 乗客は必ず通路側から入場し、指定された席に向かって歩きます。 

乗客が座席を希望しているとします`s`。 通路からその席に向かって歩いているとき、彼らはすべての番号の席を通過します。`s`。 それらの座席の一部がすでに占有されている場合、着席している乗客は立ち上がって新参者を通さなければなりません。 それぞれのスタンディングアクションが貢献します`1`答えに。 

このタスクは、搭乗プロセス全体で乗客が立ち上がった合計回数を計算することです。 

列と座席の数は最大でも可能です`10^9`、しかし、ただ`k ≤ 10^5`乗客は実際に存在します。 これは、すべての列またはすべての座席番号に依存する解決策が不可能であることをすぐに示します。 関連するデータは、入力に表示される占有座席のみです。 

微妙な点は、異なる行間では相互作用が決して起こらないことです。 列の座席に向かって歩く乗客`r`すでに同じ列に座っている人にのみ影響します。 

乗客が次の順序で到着する列を考えてみましょう。```
seat 5
seat 2
```2人目の乗客が到着したら、着席します`5`すでに満席で通路と座席の間に座っています`2`なので、座席の乗客は`5`一度立つ。 貢献度は、`1`。 

次に、次のことを考えてみましょう。```
seat 2
seat 5
```2番目の乗客は座席までのみ歩きます`5`、通路の隣にあります。 誰も道を遮るものはありません。 貢献度は、`0`。 

不注意に実装すると、大きな座席番号ではなく、より小さな座席番号で占有座席をカウントし、逆の結果が得られる可能性があります。 

もう 1 つの簡単な間違いは、異なる列の乗客を混ぜることです。 

例：```
row 1 seat 5
row 2 seat 4
row 1 seat 2
```列の乗客のみ`1`、座席`5`最終到着が重要です。 列に並んでいる乗客`2`行は独立しているため、関係ありません。 

正しい答えは、`1`、 ない`2`。 

## アプローチ

 直接シミュレーションは簡単です。 

到着する乗客ごとに、同じ列に以前に着席していた乗客をすべてスキャンし、座席番号の大きい座席に何人が座っているかを数えます。 このような乗客はそれぞれ 1 回立ち上がらなければなりません。 

これは正解です。なぜなら、座席が通路と目的地の座席の間にあるとき、着席した乗客はまさに進路を妨げるからです。 

問題は走行時間です。 と`k = 100000`到着ごとに以前の乗客全員をチェックする必要があるのは大まかです```
1 + 2 + ... + 99999 ≈ 5 × 10^9
```限界をはるかに超えた最悪の場合の比較。 

重要な観察は、固定行内で反転を数えているということです。 

列の座席の到着順が```
a1, a2, a3, ...
```乗客の場合`ai`到着すると、以前に占有されていた座席はすべて、`ai`スタンドアップ イベントが 1 回発生します。 

したがって、この行の寄与はまさにペアの数です。```
i < j and ai > aj
```これは古典的な反転数です。 

問題が反転カウントに帰着すると、フェンウィック ツリーを使用して各行を個別に処理できます。 座席番号は最大でも大きくできるため、`10^9`, 実際に行に表示される座席番号を圧縮します。 

全列の乗客数の合計は最大でも`100000`したがって、全体的な複雑さは次のようになります。`O(k log k)`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k²) | O(k) | 遅すぎる |
 | 最適 | O(k log k) | O(k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての乗客を搭乗順に読み上げます。 
2. 各列内の到着順を維持しながら、座席番号を列ごとにグループ化します。 
3. 各行について、その行に表示されるすべての座席番号を収集し、それらを並べ替えて座標圧縮マッピングを構築します。 
4. その行の個別の座席の数と同じサイズのフェンウィック ツリーを作成します。 
5. その列の乗客を到着順に処理します。 
6. 現在の座席について`s`、圧縮された位置を見つけます`p`。 
7. しましょう`seen`この行ですでに処理されている乗客の数になります。 
8. 圧縮されたインデックスを持つ処理済みシートの数をフェンウィック ツリーにクエリします。`≤ p`。 
9. 初期の座席の数は厳密に次の値よりも大きい`s`は```
seen - count(≤ s)
```この値を答えに追加します。 
10. シートを挿入する`s`フェンウィックの木に入り、さらに進みます。 
11. すべての行からの寄与を合計し、結果を出力します。 

### なぜ効果があるのか

 座席が指定されている乗客の場合`s`, 立たなければならないのは、同じ列の大きい番号の座席に既に着席している乗客だけです。 まさに通路と通路の間にある席です。`s`。 

到着順に行を処理する場合、すべての立席イベントは 1 組の乗客に対応し、前の乗客が後の乗客よりも大きい座席番号に座ります。 このようなペアは、その列の座席番号の順序を正確に反転したものになります。 

フェンウィック ツリーは、以前に処理されたすべてのシートを維持します。 各ステップで、前の座席が現在の座席よりも大きい座席がいくつあるかがカウントされます。これは、まさにこの乗客によって引き起こされた立ち席イベントの数です。 すべての行でこれらの値を合計すると、必要な合計が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class Fenwick:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 1)

    def add(self, idx, val):
        while idx <= self.n:
            self.bit[idx] += val
            idx += idx & -idx

    def sum(self, idx):
        res = 0
        while idx > 0:
            res += self.bit[idx]
            idx -= idx & -idx
        return res

def solve():
    n, m, k = map(int, input().split())

    rows = {}

    for _ in range(k):
        r, s = map(int, input().split())
        rows.setdefault(r, []).append(s)

    answer = 0

    for seats in rows.values():
        vals = sorted(set(seats))
        comp = {v: i + 1 for i, v in enumerate(vals)}

        fw = Fenwick(len(vals))
        seen = 0

        for seat in seats:
            pos = comp[seat]

            not_greater = fw.sum(pos)
            greater = seen - not_greater

            answer += greater

            fw.add(pos, 1)
            seen += 1

    print(answer)

solve()
```辞書`rows`列ごとに、搭乗順の座席番号のシーケンスを保存します。 反転は到着順に依存するため、順序を維持することが不可欠です。 

列ごとに、座席番号が座標圧縮されます。 元の座席番号は次のように大きくなる可能性があります`10^9`ただし、反転カウントでは相対的な順序のみが重要です。 

フェンウィック ツリーには、以前に処理されたシートの頻度が保存されます。 シートを加工する際には、`fw.sum(pos)`現在の座席番号以下の以前の座席の数を返します。 これを引くと`seen`より大きい数の以前の座席をそのまま残します。 

答えは大まかに到達できます```
100000 × 99999 / 2
```したがって、64 ビット対応の整数で格納する必要があります。 Python の整数はこれを自動的に処理します。

import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    class Fenwick:
        def __init__(self, n):
            self.n = n
            self.bit = [0] * (n + 1)

        def add(self, idx, val):
            while idx <= self.n:
                self.bit[idx] += val
                idx += idx & -idx

        def sum(self, idx):
            res = 0
            while idx:
                res += self.bit[idx]
                idx -= idx & -idx
            return res

    n, m, k = map(int, input().split())

    rows = {}
    for _ in range(k):
        r, s = map(int, input().split())
        rows.setdefault(r, []).append(s)

            ans += seen - fw.sum(p)
