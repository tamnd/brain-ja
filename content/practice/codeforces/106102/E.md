 ## 解決策
 ## 問題の理解

 ボックスは、`M × N`グリッド。 行のセル`i`そしてコラム`j`長さは次の鉛筆が入っています`i · N + j`。 行と列にはゼロからインデックスが付けられるため、左上のセルには長さが含まれます`0`。 

テストケースごとに与えられるのは、`M`、`N`、およびターゲットの長さ`L`。 軸に沿ったグリッドのサブ長方形を選択し、その中のすべての鉛筆を結合することができます。 結果として得られる鉛筆の全長は、その部分四角形内のすべての値の合計です。 

タスクは、合計が正確に次の部分長方形を見つけることです。`L`。 このような長方形が複数存在する場合は、可能な限り小さい領域を出力する必要があります。 合計を持たない四角形がない場合`L`、出力します`-1`。 

寸法は次のように大きくできます。`10^6`、 その間`L`到達できる`10^12`。 位置や四角形のサイズをブルートフォーススキャンすることは完全に不可能です。 すべての行またはすべての列を反復処理するだけでも、すでに大きすぎます。 

重要な観察は、グリッド値が非常に規則的な算術構造を形成していることです。 位置を検索する代わりに、任意の長方形の合計に対する閉じた式を導出し、問題を次の約数に対する数論的検索に変換できます。`2L`。 

よくある間違いは、長方形の寸法のみが重要であると想定することです。 高さと幅が同じ 2 つの長方形は、開始位置が異なるため、合計が異なる場合があります。 

考慮する：```
M = 3, N = 3

0 1 2
3 4 5
6 7 8
```あ`1 × 2`長方形には合計を含めることができます`1`、`3`、`5`、`7`、`9`、`11`。 

寸法だけでは合計は決まりません。 

計算された開始位置がグリッドの外側に着地する場合、別の微妙なケースが発生します。```
M = 2, N = 3, L = 8
```面積のある長方形`4`は存在し、機能しますが、代数的に有効な解の中には、許容範囲を超えた左上隅に対応するものもあります。 幾何学的境界も引き続きチェックする必要があります。 

## アプローチ

 ブルート フォース ソリューションでは、すべてのサブ四角形を列挙し、その合計を計算します。 

がある`O(M²N²)`サブ長方形。 までの寸法`10^6`、それは絶望的です。 グリッドを格納することさえ不可能です。 

グリッドの構造が私たちを救ってくれるのです。 あらゆる価値観は```
value(i, j) = iN + j
```長方形が次から始まるとします。`(r, c)`そして高さがある`h`と幅`w`。 

そのエリアは```
A = h · w
```等差数列を合計すると、```
sum = A · ( N(2r + h - 1) + (2c + w - 1) ) / 2
```定義する```
B = N(h - 1) + (w - 1)
x = Nr + c
```それから```
sum = A(2x + B)/2
```目標値に向けて`L`:```
2L = A(2x + B)
```これは直ちに、その領域が`A`分けなければなりません`2L`。 

それは問題を完全に変えます。 巨大なグリッド内の位置を検索する代わりに、約数を列挙します。`2L`。 数の約数の数は次のとおりです。`2 · 10^12`わずか数千です。 

候補地としては`A`、あらゆる因数分解を試します```
A = h · w
```と`h ≤ M`そして`w ≤ N`。 

方程式を整理すると、```
x = (2L/A - B)/2
```もし`x`が負でない整数の場合、回復します```
r = x // N
c = x % N
```そしてそれを単純に検証してください```
r ≤ M - h
c ≤ N - w
```何らかの因数分解が機能する場合、面積は`A`達成可能です。 領域を昇順にテストするため、最初の有効な領域が答えになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(M²N²) | お(1) | 遅すぎる |
 | 最適 | およそ O(d²) ここで、d は 2L | の約数の数です。 O(d) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. コンピューティング`S = 2L`。 
2.因数分解`S`。 
3. すべての約数を生成します。`S`そして昇順に並べ替えます。 
4. 各約数について`A`の`S`、それを長方形の候補領域として扱います。 
5. すべての因数分解を列挙する`A = h · w`。 
6. 次の場合はペアをスキップします。`h > M`または`w > N`。 
7. コンピューティング```
Q = S / A
B = N(h - 1) + (w - 1)
```8.次のことを確認します。```
Q - B
```は負ではなく偶数です。 

それ以外の場合、対応する開始位置を整数にすることはできません。 
9. 回復する```
x = (Q - B)/2
r = x // N
c = x % N
```10. 長方形が適合することを確認します。```
r ≤ M - h
c ≤ N - w
```11. 有効な四角形が 1 つ見つかるとすぐに出力します。`A`。 
12. 動作する領域がない場合は出力`-1`。 

### なぜ効果があるのか

 合計の公式```
L = A(2x + B)/2
```は、すべての長方形の正確な特徴付けです。 

高さと幅が固定されている場合、数量は`B`固定されています。 残された唯一の自由は開始位置であり、次のように表されます。`x = Nr + c`。 

方程式を並べ替えると、次の一意の候補値が得られます。`x`。 その値が有効なグリッド位置ではない場合、その寸法の四角形はターゲットの合計を生成できません。 有効な場合、対応する四角形は正確に生成します。`L`。 

アルゴリズムは可能なすべての領域分割をチェックします`2L`そしてその領域のあらゆる可能な因数分解。 すべての有効な四角形はこれらの条件を満たさなければならないため、解を逃すことはできません。 領域を昇順でテストすると、最初の有効な領域の領域が最小であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def factorize(x):
    fac = []
    d = 2

    while d * d <= x:
        if x % d == 0:
            cnt = 0
            while x % d == 0:
                x //= d
                cnt += 1
            fac.append((d, cnt))
        d += 1 if d == 2 else 2

    if x > 1:
        fac.append((x, 1))

    return fac

def gen_divisors(factors, idx=0, cur=1, out=None):
    if out is None:
        out = []

    if idx == len(factors):
        out.append(cur)
        return out

    p, e = factors[idx]
    val = 1

    for _ in range(e + 1):
        gen_divisors(factors, idx + 1, cur * val, out)
        val *= p

    return out

t = int(input())

for _ in range(t):
    M, N, L = map(int, input().split())

    S = 2 * L

    factors = factorize(S)
    divisors = gen_divisors(factors)
    divisors.sort()

    answer = -1

    for A in divisors:
        found = False

        for h in divisors:
            if h * h > A:
                break

            if A % h:
                continue

            w = A // h

            for hh, ww in ((h, w), (w, h) if h != w else ()):
                if hh > M or ww > N:
                    continue

                Q = S // A
                B = N * (hh - 1) + (ww - 1)

                diff = Q - B

                if diff < 0 or diff & 1:
                    continue

                x = diff // 2

                r = x // N
                c = x % N

                if r <= M - hh and c <= N - ww:
                    answer = A
                    found = True
                    break

            if found:
                break

        if found:
            break

    print(answer)
```最初の部分は因数分解します`2L`。 その因数分解からすべての約数を生成します。 

外側のループでは、候補領域を昇順にテストします。 実行可能な最小の領域のみを考慮するため、有効な四角形が見つかると検索はすぐに停止できます。 

領域ごとに、すべての因子ペアを列挙します。`(h, w)`。 代数は一意の可能な開始インデックスを与えます`x`。 変換中```
x = Nr + c
```に戻る`(r, c)`整数の除算と剰余を使用するのは簡単です。 

最も一般的な実装上の間違いは、幾何学的チェックを忘れることです。```
r ≤ M - h
c ≤ N - w
```の値`x`は方程式を満たしていても、ボックスの外側に広がる長方形に対応する場合があります。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    def factorize(x):
        fac = []
        d = 2
        while d * d <= x:
            if x % d == 0:
                c = 0
                while x % d == 0:
                    x //= d
                    c += 1
                fac.append((d, c))
            d += 1 if d == 2 else 2
        if x > 1:
            fac.append((x, 1))
        return fac

    def gen(fac, i=0, cur=1, out=None):
        if out is None:
            out = []
        if i == len(fac):
            out.append(cur)
            return out
        p, e = fac[i]
        v = 1
        for _ in range(e + 1):
            gen(fac, i + 1, cur * v, out)
            v *= p
        return out

    t = int(input())
    ans = []

    for _ in range(t):
        M, N, L = map(int, input().split())
        S = 2 * L

        divs = gen(factorize(S))
        divs.sort()

        res = -1

        for A in divs:
            ok = False

            for h in divs:
                if h * h > A:
                    break
                if A % h:
                    continue

                w = A // h

                pairs = [(h, w)]
                if h != w:
                    pairs.append((w, h))

                for hh, ww in pairs:
                    if hh > M or ww > N:
                        continue

                    Q = S // A
                    B = N * (hh - 1) + (ww - 1)

                    diff = Q - B

                    if diff < 0 or diff % 2:
                        continue

                    x = diff // 2
                    r = x // N
                    c = x % N

                    if r <= M - hh and c <= N - ww:
                        res = A
                        ok = True
                        break

                if ok:
                    break

            if ok:
                break

        ans.append(str(res))

    return "\n".join(ans)

# sample-style cases
assert solve("1\n2 3 8\n") == "4"

# minimum grid
assert solve("1\n1 1 1\n") == "-1"

# whole grid
assert solve("1\n3 3 36\n") == "9"

# single cell exists
assert solve("1\n2 2 3\n") == "1"

# impossible target
assert solve("1\n3 3 10\n") == "-1"

 | --- | --- | --- |
 |`1 1 1`|`-1`| セル値 1 は存在しません |
 |`3 3 36`|`9`| グリッド全体のソリューション |

 ## 特殊なケース

 次のことを考慮してください。```
1
1 1 1
```グリッドには値が 1 つだけ含まれます。```
0
```アルゴリズムテストエリア`1`、対応する位置を計算し、合計が次の長方形にならないことがわかります。`1`。 出力します`-1`。 

考慮する：```
1
2 2 3
```細胞`(1,0)`値が含まれています`2`、 そして`(1,1)`値が含まれています`3`。 

エリア用`1`、式は値に正確に対応する有効な開始位置を与えます。`3`。 アルゴリズムはすぐに戻ります`1`、これが最適です。 

考慮する：```
1
2 3 8
```不用意に実装すると、左上隅がグリッドの外側にある代数解が見つかる可能性があります。 再構築のステップ```
r = x // N
c = x % N
```に続く```
r ≤ M - h
c ≤ N - w
```それらの誤検知を排除し、幾何学的に有効な長方形のみを保持します。
