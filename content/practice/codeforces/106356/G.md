 ## 解決策
 ## 問題の理解

 整数のシーケンスを生成するシステムが与えられており、各整数はビットマスクとしてエンコードされたゲノムを表します。 各ビットは、特定の遺伝マーカーが存在するかどうかを示します。 

進化の法則は決定的です。 最初の 2 つのゲノムは次のように固定されます$a$そして$b$。 その後、両方に出現する遺伝マーカーのみを保持することによって、前の 2 つのゲノムからすべての新しいゲノムが構築されます。これはまさにビットごとの AND 演算です。 

したがって、シーケンスは次のようになります。$g_1 = a$、$g_2 = b$、そしてのために$t \ge 3$、$g_t = g_{t-1} \,\&\, g_{t-2}$。 

クエリごとに、次のように計算する必要があります。$g_t$潜在的に非常に大きいため$t$、 まで$10^8$、最大で$10^5$独立した実験。 

制約の主な意味は、シーケンスを段階的にシミュレートできないことです。 クエリごとの単純な再帰シミュレーションは次のように線形になります。$t$、これは直ちに実行不可能です。 テスト ケースごとでも、最大で保存または反復$10^8$時間的にも記憶力的にも不可能なステップです。 

微妙なエッジケースが現れるのは、$t = 1$または$t = 2$、再発は適用されません。 もう 1 つの重要なケースは、次のいずれかの場合です。$a$または$b$は 0 です。これは、AND 演算によりビットが急速に崩壊し、すぐに 0 になり、その後 0 のままになるシーケンスが生成される可能性があるためです。 

## アプローチ

 総当りの解釈は簡単です。時間に達するまでの繰り返しをシミュレートします。$t$。 各ステップでは、前の 2 つの値のビット単位の AND が計算されます。$O(1)$32 ビット整数の演算。 ただし、以来、$t$と同じ大きさにすることができます$10^8$、これは次のことにつながります$O(t)$クエリごとに、最悪の場合には$10^5$クエリには最大で$10^{13}$これは実行可能な限界をはるかに超えています。 

重要な観察は、ビットごとの AND が非常に強い意味で単調であるということです。つまり、最後の 2 つの状態のいずれかでビットが 0 になると、そのビットは再び現れることはありません。 各ビットは独立して進化し、ビット位置ごとに 2 つの初期ビットに対して同じ繰り返しを効果的に実行します。$a_i, b_i \in \{0,1\}$。 

したがって、整数について考える代わりに、単一のビット位置を分析します。 各ビットについて、前の 2 ビットの AND によって定義されたバイナリ シーケンスを取得します。 可能な初期構成は 4 つだけです$(a_i, b_i)$であり、それぞれ非常に短い過渡現象が発生します。 

両方が 1 の場合、将来のすべての項は 1 のままです。どちらかが 0 の場合、シーケンスは最初の AND ステップ以降ですぐに 0 に崩壊し、永久に 0 のままになります。 より正確には、時間 3 で次のように計算します。$a_i \& b_i$、同じ値の繰り返しの AND は安定しているため、その後はすべて同じままになります。 

これは、各ビットごとにシーケンスが次の値で安定することを意味します。$g_3 = a \& b$、そして全員にとって$t \ge 3$、値は定数です。 したがって、問題全体は 1 つの観測値に帰着します。つまり、第 3 項の後、シーケンスはもはや変化しません。

 ## アルゴリズムのチュートリアル

 1.読む$a$、$b$、 そして$t$クエリごとに。 これらは、最初の 2 つの状態と評価する必要がある時間インデックスを定義します。 
2. もし$t = 1$、 戻る$a$シーケンス定義が計算なしで最初の項を修正するため、直接的にこれが起こります。 
3. もし$t = 2$、 戻る$b$直接的には同じ理由で。 
4. あらゆる場合$t \ge 3$、計算する$a \& b$。 これは、定義のタイムステップ 3 で形成されたゲノムに対応します。 
5. すべてに対してこの値を返します$t \ge 3$, それ以上進化しても結果は変わらないためです。 

なぜ効果があるのか:

 反復では、冪等で結合するビット単位の AND のみを使用します。 計算したら$g_3 = a \& b$、次のステップは次のようになります$g_4 = g_3 \& g_2$。 しかし$g_2 = b$、 そして$g_3 = a \& b$、 それで$g_4 = (a \& b) \& b = a \& b$。 同様に、$g_5 = g_4 \& g_3 = (a \& b) \& (a \& b) = a \& b$。 したがって、シーケンスはすぐに次の固定点にロックされます。$t = 3$、その後は一定のままです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    out = []
    for _ in range(T):
        a, b, t = map(int, input().split())
        if t == 1:
            out.append(str(a))
        elif t == 2:
            out.append(str(b))
        else:
            out.append(str(a & b))
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```このソリューションは、安定化プロパティを直接エンコードします。 唯一の分岐はオンです$t$、2つの基本ケースを安定体制から分離します。 の計算$a \& b$は定数時間であり、Python のネイティブな整数のビット単位の演算に依存します。

 ## 特殊なケース

 両方のとき$a$そして$b$がゼロの場合、すべてのステップはゼロのままです。 アルゴリズムは戻ります$a$のために$t=1$、$b$のために$t=2$、 そして$a \& b = 0$みんなのために$t \ge 3$、定数ゼロの進化と正確に一致します。 

いつ$a = b$、シーケンスはその値で一定のままである必要があります。 のために$t \ge 3$、計算します$a \& a = a$したがって、出力はすべてのステップにわたって一貫しています。 

いつ$t = 1$または$t = 2$、計算が再発を妨げるべきではありません。 このアルゴリズムは初期値を明示的に返し、AND ルールの不適切な時期尚早の適用を回避します。 

ビットが完全に異なる場合、例えば$a = 8$そして$b = 4$、第 3 項はゼロになり、ゼロのままになります。 アルゴリズムは正しく出力します$a \& b = 0$みんなのために$t \ge 3$、すべての共有遺伝マーカーの即時損失と一致します。
