 ## 問題の理解

 私たちにはいくつかの素数が与えられます。 素数ごとに$p$、10 進数表現の前に 1 つ以上の 10 進数を置くことができます。 結果の数値は、選択したプレフィックスと$p$。 

私たちの目標は、先頭に付加される数字をできるだけ少なくしながら、結果の数値を合成するプレフィックスを生成することです。 最小長の複数のプレフィックスが機能する場合は、それらのどれも受け入れられます。 

重要な観察は、次の制約から得られます。$p$。 すべての入力数値は 10 から 10 までの素数です。$10^8$、 それで$p$が 2、3、または 5 に等しくなることはありません。特に、$p \bmod 3$は常に 1 または 2 のいずれかです。 

不注意なアプローチでは、多くのプレフィックスを試し、結果の数値の素数性をテストする可能性があります。 これは小さな入力には機能しますが、問題の構造を完全に無視します。 

考慮する$p = 11$。 

数字の 1 を先頭に追加すると、111 が得られます。$111 = 3 \times 37$、結果は複合です。 

答えは先頭に付加された数字を 1 つだけ使用しているため、すでに最適です。 

別の例は$p = 13$。 

2 を先頭に付けると 213 が得られ、$213 = 3 \times 71$。 

繰り返しますが、1 桁で十分です。 

最も重要なエッジケースは、先頭にゼロを付加した数字が許可されていないことを理解することです。 元の数値が素数であっても、先頭に少なくとも 1 桁を追加する必要があります。 したがって、可能な最小の回答の長さは 0 ではなく 1 になります。 

## アプローチ

 ブルート フォース ソリューションでは、1 桁のプレフィックスをすべて試行し、次に 2 桁のプレフィックスをすべて試行し、合成数が見つかるまでそれを繰り返します。 候補ごとに、連結された数値を構築し、素数性テストを実行します。 

これが機能するのは、最終的には何らかの接頭辞が合成数を生成する必要があるためです。 問題は、素数性テストが最大で何度も繰り返されることです。$10^5$テストケース。 結果の数値が極端に大きくない場合でも、素数チェックを繰り返し行う必要はありません。 

重要な点は、実際には検索する必要がないということです。 

させて$k$の桁数になります$p$。 先頭に 1 桁を付ける場合$d$、新しい番号は$$N = d \cdot 10^k + p.$$以来$10 \equiv 1 \pmod 3$、$$10^k \equiv 1 \pmod 3.$$したがって$$N \equiv d + p \pmod 3.$$なぜなら$p$は 3 より大きい素数、$p \bmod 3$は 1 または 2 のいずれかです。 

もし$p \bmod 3 = 1$、 選ぶ$d = 2$。 

それから$$N \equiv 2 + 1 \equiv 0 \pmod 3.$$もし$p \bmod 3 = 2$、 選ぶ$d = 1$。 

それから$$N \equiv 1 + 2 \equiv 0 \pmod 3.$$結果の数値は 3 で割り切れ、3 より大きいため、合成する必要があります。 

常に 1 桁の数字が機能するため、先頭に付加される数字の最小数は常に 1 です。

 ## アルゴリズムのチュートリアル

 1. 素数を読み取る$p$。 
2. コンピューティング$p \bmod 3$。 
3. もし$p \bmod 3 = 1$、数字を出力します`2`。 

連結された数値は 3 で割り切れます。$2 + 1 \equiv 0 \pmod 3$。 
4. それ以外の場合は、$p \bmod 3 = 2$ので、数字を出力します`1`。 

連結された数値は 3 で割り切れます。$1 + 2 \equiv 0 \pmod 3$。 

### なぜ効果があるのか

 しましょう$k$の桁数になります$p$。 先頭に数字を追加した後$d$、新しい番号は$$N = d \cdot 10^k + p.$$以来$10^k \equiv 1 \pmod 3$、$$N \equiv d + p \pmod 3.$$私たちの選択$d$保証する$d + p \equiv 0 \pmod 3$。 したがって、$N$は 3 で割り切れます。 

なぜなら$N$少なくとも 2 桁の数字が含まれており、3 より大きい場合、3 で割り切れるということは、$N$複合です。 

1 桁のプレフィックスが常に存在し、先頭にゼロの数字を付けることは許可されていないため、ソリューションでは 1 桁未満を使用することはできません。 したがって、生成される答えは常に最適です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    p = int(input())

    if p % 3 == 1:
        print(2)
    else:
        print(1)
```このソリューションでは、次の残留物のみが使用されます。$p$モジュロ 3。 

いつ$p \equiv 1 \pmod 3$、数字`2`連結された数値が 3 で割り切れるようになります。 

いつ$p \equiv 2 \pmod 3$、数字`1`同じことをします。 

最終的な数値を計算する必要はありません。 の桁数$p$合同なので計算する必要はありません$$10^k \equiv 1 \pmod 3$$あらゆるものに当てはまります$k$。 

実装はテスト ケースごとに一定時間で実行され、すべての素数テストが回避されます。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline
    t = int(input())
    ans = []

    for _ in range(t):
        p = int(input())
        ans.append("2" if p % 3 == 1 else "1")

    return "\n".join(ans) + "\n"

# basic examples
assert run("1\n11\n") == "1\n"
