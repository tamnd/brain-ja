 ## アルゴリズムのチュートリアル

 遷移表を作成します`nxt[i][c]`、 どこ`i`の位置です`s`そして`c`は文字であり、以降に次のインデックスを格納します。`i`どこ`c`が表示される、または`-1`存在しない場合。 

次に、各クエリを次のように処理します。 

1.初期化`pos = 0`、つまり、最初の文字の前から開始します。`s`。 
2. の各文字について`t`、 アップデート`pos = nxt[pos][c] + 1`。 いつでも`nxt[pos][c] = -1`、 それから`t`は部分列ではないので、答えは次のようになります。`0`。 このステップでは、線形時間でサブシーケンス マッチングを直接シミュレートします。`|t|`。 
3. もし`t`はサブシーケンスであるため、文字を繰り返し追加しようとします。 現在のポインタを維持します`pos`で`s`。 
4. 追加された文字ごとに、許可されている文字を選択します`c`で試合を有利に進めることができる`s`、 意味`nxt[pos][c] != -1`。 
5. 現在の文字列にそのような文字が存在しない場合`pos`、これ以上延長することはできないので、終了します。 
6. 追加が成功するたびに移動します`pos`前方に進む`s`、そして、実行できたステップの数を数えます。 

答えは、有効な次の出現につながる文字がない位置に到達するまでに成功した拡張の数です。 

### なぜ効果があるのか

 いつでも、文字列がまだサブシーケンスであるかどうかを判断するために必要な情報は、ファイル内の現在の一致位置だけです。`s`。 の`nxt`テーブルは、任意の位置からのすべての将来の可能性をエンコードします。 追加された各文字は厳密に位置を進めます。`s`したがって、プロセスは単調なウォークスルーを形成します`s`。 すべての文字がつながったら、`-1`、拡張子はサブシーケンスのプロパティを保持できないため、プロセスを停止する必要があります。 これにより、追加された文字の代替シーケンスでも同じ状態からの有効な遷移が必要となるため、最適性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, k = map(int, input().split())
    s = input().strip()

    # build next occurrence table
    nxt = [[-1] * k for _ in range(n + 1)]

    last = [-1] * k
    for i in range(n - 1, -1, -1):
        last[ord(s[i]) - 97] = i
        for c in range(k):
            nxt[i][c] = last[c]
    for c in range(k):
        nxt[n][c] = -1

    q = int(input())
    out = []

    for _ in range(q):
        t = input().strip()

        pos = 0
        ok = True

        for ch in t:
            c = ord(ch) - 97
            if pos > n:
                ok = False
                break
            nxt_pos = nxt[pos][c]
            if nxt_pos == -1:
                ok = False
                break
            pos = nxt_pos + 1

        if not ok:
            out.append("0")
            continue

        # try to extend
        ans = 0
        while True:
            found = False
            for c in range(k):
                nxt_pos = nxt[pos][c]
                if nxt_pos != -1:
                    pos = nxt_pos + 1
                    ans += 1
                    found = True
                    break
            if not found:
                break

        out.append(str(ans))

    print("\n".join(out))

if __name__ == "__main__":
    main()

後続のチェックでは、このテーブルを使用して更新します。`pos`効率的に。 文字が一致しない場合、クエリは次のように直ちに解決されます。`0`。 

拡張フェーズでは、ポインタをまだ進めることができる文字を繰り返し見つけます。 有効な文字の選択は正確さに影響しません。これは、正確にどの文字列が形成されるかではなく、継続可能時間をカウントするだけであるためです。
