 ## 解決策
 ## 問題の理解

 ゼロ以外の整数の配列が与えられます。 各ステップで、任意の要素を選択し、その絶対値に等しいコインを獲得し、負の場合はその右側にあるすべてを削除し、正の場合は左側にあるすべてを削除します。 目標は、アレイが空になるまでに収集されるコインの合計を最大化することです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースの配列の長さは最大です。$2 \cdot 10^5$、すべてのテスト ケースにわたるすべての配列の長さの合計は次を超えません。$2 \cdot 10^5$。 各要素は次のように大きくできます。$10^9$絶対値で言うと。 これは、あらゆるソリューションがテスト ケースごとに線形または線形に近い時間で動作する必要があることを意味します。 考えられるすべての選択をシミュレートする単純な総当りアプローチでは、配列の長さが指数関数的に増大し、明らかに実行不可能です。 

エッジ ケースには、長さ 1 の配列、すべて正またはすべて負の数値を含む配列、大きな絶対値が先頭または末尾に現れる配列が含まれます。 たとえば、配列が次の場合、$[-10, -5, -1]$、最良の選択は最後の負の数を選択することです。$-1$、接頭辞は残ります$[-10, -5]$、最初の要素を繰り返し取得してコインを最大化します。 最初か最後かを考慮せずに常に最大の絶対値を取得する不用意な貪欲なアプローチは失敗する可能性があります。 

## アプローチ

 ブルートフォース ソリューションでは、各ステップで考えられるすべての要素が考慮されます。 長さの配列の場合$n$、最初のステップは$n$選択肢、そして最大$n-1$次のステップなどで、大まかに説明します。$n!$シーケンス。 各シーケンスでは、収集されたコインの合計を計算する必要があります。 明らかに、$n!$は禁止されています$n \sim 10^5$。 

重要な観察は、各ステップでの選択により、配列がプレフィックスまたはサフィックスに自然に分割されるということです。 ピックの後は常に片側を完全に削除するため、**同じ符号の連続するセグメント**を調べることで、最適な動きのシーケンスを見つけることができます。 正の数値のセグメント内では、そのセグメント内の最大数値以外は決して選択しません。これは、より小さな正の数値を選択すると、その右側にある潜在的により大きな数値が削除されるためです。 同様に、負のセグメントでは、そのセグメントの最後 (右端) の数値 (絶対値の最大値) を選択する必要があります。これは、前の負の数値を選択するとセグメントの残りの部分が破棄されるためです。 

これにより、配列を 1 回スキャンし、同じ符号の連続する数字をグループ化し、各グループの最大値を取得するという問題が軽減されます。 これらの最大値の合計により、最適なコインの合計が得られます。 この貪欲な戦略が機能するのは、セグメント内の数値をコミットすると、その前後のすべてを削除する必要があるからです。 連続する各セグメントの極大値を常に取得することで、次のセグメントに移動する前にそのセグメントから収集できる量を最大化します。

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`total_coins`0に、そして`i`0にします。`i`配列内の現在のインデックスを追跡します。 
2. その間`i`未満です`n`、新しいセグメントを開始します。 現在の数値の符号 (正または負) を記録します。 変数を初期化する`segment_max`現在の要素に。 
3. 同じ符号の連続する数字を更新しながら移動します。`segment_max`セグメント内の最大絶対値まで。 符号が変わるか、配列が終了するまで続けます。 
4.追加`segment_max`に`total_coins`。 これは、この連続セグメント内のコインを最大化する数字を最適に選択することに対応します。 
5.セット`i`次のセグメントの先頭まで移動し、配列が完全に処理されるまでステップ 2 ～ 4 を繰り返します。 
6. 出力`total_coins`。 

これが機能するのは、同じ符号の各セグメントが選択に関して独立しているためです。 正のセグメントで最大値を選択すると、左側のプレフィックスが最適に破棄され、負のセグメントで最大値を選択すると、右側のサフィックスが最適に破棄されます。 それ以外の選択をすると、収集されるコインの合計が厳密に減少します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total_coins = 0
        i = 0
        while i < n:
            current_sign = a[i] > 0
            segment_max = a[i]
            j = i
            while j < n and (a[j] > 0) == current_sign:
                segment_max = max(segment_max, a[j])
                j += 1
            total_coins += segment_max
            i = j
        print(total_coins)

if __name__ == "__main__":
    solve()
```コードは各テスト ケースを読み取り、配列を反復処理して、同じ符号のセグメントを識別します。 各セグメントについて、最大要素が検索され、それが累計に追加されます。 変数`j`次の符号が変わるまでスキャンします。 単一要素セグメントや負のセグメントで終わる配列などの境界条件は、自然に処理されます。`while`ループは配列の終端で停止します。 このソリューションでは配列自体は変更されないため、コストのかかるスライス操作が回避されます。
