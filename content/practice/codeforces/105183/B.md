 ## 解決策
 ## 問題の理解

 私たちは次のことに取り組んでいます$n \times m$このグリッドでは、各セルにウェルを含めることも、空のままにすることもできます。 井戸は 2 つの点で特別です。 まず、対角線を含む隣接するすべてのセルに「サービス」を提供します。つまり、井戸からチェビシェフ距離 1 以内のセルには水が供給されていると見なされます。 第 2 に、すべての空のセルは少なくとも 1 つのウェルから供給される必要があります。 

このカバレッジ要件に加えて、ウェルの配置はグリッドの垂直軸と水平軸の両方に関して対称である必要があります。 言い換えれば、グリッドを左から右または上から下に反映する場合、ウェルのパターンは変更されない必要があります。 

出力は単なる文字のグリッドです。`'O'`井戸をマークし、`'+'`空のセルにマークを付けます。 完全なカバレッジを保証するすべての有効な対称構成の中で、ウェルの数を最小限に抑える必要があります。 

制約$1 \le n, m \le 100$指数関数的に多くの配置をチェックすることに依存する解決策は不可能であることを明確にしてください。 セルのすべてのサブセットを試すソリューションでも、最大で次のことが必要になります。$2^{10000}$実行可能な計算をはるかに超えた最悪の場合の状態。 

さらに微妙な問題は対称性から生じます。 対称性を無視した貪欲なカバー戦略は設計が簡単ですが、両方向に反射制約を強制すると、それ以外の場合は最適なタイリングの多くが無効になります。 

この緊張を明らかにするエッジ ケースの 1 つは、次のような非常に小さなグリッドです。```
1 2
```対称性のない単純な最適支配では、両方のセルをカバーする単一のウェルが配置される可能性があります。 ただし、対称性により、反射下では両方のセルが同一になることが強制されるため、両方がウェルであるか、両方が空になります。 後者は、空のセルにはカバレッジがないため無効であり、両方ともウェルである必要があります。 

これは、カバレッジだけでは必要ない場合でも、対称性によって配置の重複が強制される可能性があることを示しています。 

## アプローチ

 対称性を少し無視すると、問題は、すべてのセルが少なくとも 1 つの選択された中心の 3×3 近傍内に収まるように、最小数のセルを選択することになります。 各ウェルはそれ自体のセルと周囲の 8 つのセルをカバーするため、グリッドは 3×3 の正方形が重なってカバーされると考えることができます。 

簡単な構成は、ステップ 3 で通常のグリッド上でウェルを選択することです。たとえば、すべてのセルにウェルを配置します。$(i, j)$ここで、両方の座標は 3 を法とする固定合同クラスに分類されます。これにより、各セルが選択した中心から最大 1 ステップ以内に位置することが保証され、約$\lceil n/3 \rceil \cdot \lceil m/3 \rceil$井戸。 

この構造は、各ウェルが最大 9 個のセルをカバーするため、キング ムーブによる支配に最適です。そのため、3×3 ブロックあたり 1 ウェルの漸近密度を超える構成はありません。 

残る問題は対称性です。 固定モジュラー パターンは、水平反射と垂直反射の両方で対称であることが保証されません。 リフレクションにより剰余クラスが 3 を法として変更される可能性があり、これにより構造が破壊されます。 

完全に対称なタイリングを直接設計する代わりに、最適な制約のないソリューションは 3×3 の周期構造のみに依存するという、より単純な観察を利用します。 この周期的なグリッドで可能なシフトは 9 つだけです。 シフトごとに、候補解を構築し、それが両方の対称制約を満たすかどうかを明示的にチェックできます。 以来$n, m \le 100$、9パターンにわたるこの野蛮なチェックは簡単です。 

すべての有効な対称パターンの中から、ウェルの数が最小限のものを選択します。 この方法で生成されたすべてのパターンは同じ漸近密度を持つため、有効なパターンが最適です。

 ## アルゴリズムのチュートリアル

 3×3 の繰り返し構造に基づいてソリューションを構築し、対称性を満たすバージョンを選択します。 

1. シフトを修正する$(sx, sy)$どこ$sx, sy \in \{0,1,2\}$。 このシフトにより、パターンの最初の「アクティブ」セルがどこから始まるかが決まります。 グリッドの残りの部分は、両方向に 3 セルごとに周期的に繰り返されます。 
2. すべてのセルにウェルを配置して候補グリッドを構築します。$(i, j)$そのような$(i - sx) \bmod 3 = 0$そして$(j - sy) \bmod 3 = 0$。 これにより、正確に 3 セルの間隔で配置された均一なウェルの格子が作成されます。 
3. このグリッドが左右対称であるかどうかを確認します。 あらゆる細胞に$(i, j)$、その値が一致することを確認します$(i, m - 1 - j)$。 不一致があった場合、候補は無効となります。 
4. 同様に垂直対称性を検証して確認します。$(i, j)$マッチ$(n - 1 - i, j)$すべての細胞に。 
5. 両方の対称条件が満たされる場合、このグリッドを受け入れます。 すべての有効な候補は同じ密度を持っているため、最初の有効な候補で停止できます。 

これが機能する理由は、対称性はカバレッジには影響せず、繰り返しパターンの配置のみに影響するためです。 周期構造に限定することで、問題を一定数の構成に縮小し、それぞれを独立して検証できます。 

### なぜ効果があるのか

 重要な不変条件は、選択されたすべてのパターンが完全な 3x3 周期支配セットであることです。これは、すべてのセルが、選択された中心からチェビシェフ距離 1 以内にあることを意味します。 周期的な構造により、シフトに関係なくカバレッジが保証されます。 

対称性は、直接構築するのではなく、候補をフィルタリングすることによって強制されます。 リフレクションは剰余 3 を法的に並べ替えるだけであるため、対称的な最適解が存在する場合は常に、9 つのシフトのうちの少なくとも 1 つは両方の対称軸と一貫して一致します。 すべての最適解はこの同じ周期構造の変換であるため、最適な構成を見逃さないことが保証されています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build(n, m, sx, sy):
    grid = [['+' for _ in range(m)] for _ in range(n)]
    for i in range(n):
        for j in range(m):
            if (i - sx) % 3 == 0 and (j - sy) % 3 == 0:
                grid[i][j] = 'O'
    return grid

def ok_sym(grid):
    n = len(grid)
    m = len(grid[0])

    for i in range(n):
        for j in range(m):
            if grid[i][j] != grid[i][m - 1 - j]:
                return False
    for i in range(n):
        for j in range(m):
            if grid[i][j] != grid[n - 1 - i][j]:
                return False
    return True

def solve():
    n, m = map(int, input().split())

    best = None
    best_cnt = float('inf')

    for sx in range(3):
        for sy in range(3):
            g = build(n, m, sx, sy)

            if not ok_sym(g):
                continue

            cnt = sum(row.count('O') for row in g)
            if cnt < best_cnt:
                best_cnt = cnt
                best = g

    for row in best:
        print("".join(row))

if __name__ == "__main__":
    solve()
```このソリューションは、9 つ​​すべての周期的なタイリングを構築し、対称性によってそれらをフィルター処理します。 グリッドの構築は直接的であり、各候補はチェックインされます。$O(nm)$。 以来$n, m \le 100$、これは快適な速度を維持します。 

唯一の微妙な部分は対称性チェックです。両方の反射を明示的に検証する必要があります。 誤って 1 つの軸だけをチェックしてしまうことはよくありますが、この問題では垂直方向と水平方向の不変性が同時に必要になります。

```これは、正しい解決策が最も「明白な」周期的調整ではない可能性があることを示しています。 対称フィルタリングにより、正しいオフセットが選択されます。

 ## 特殊なケース

 空のセルはすぐにカバレッジ要件に違反するため、1×1 グリッドでは唯一のセルが強制的にウェルになります。 アルゴリズムはすべてのシフトを試行し、構築されたすべてのパターンはシフトに応じて原点またはその近くにウェルを配置します。 少なくとも 1 つのシフトで単一のシフトが生成されます。`'O'`これは対称的かつ最適です。 

1×m グリッドでは、対称により中心に沿った位置が強制的にミラーリングされます。 単純な周期的な配置では対称性が崩れる可能性がありますが、9 つのシフトのうち、少なくとも 1 つはパターンを揃えて、すべての配置がそれ自体に反映されるようにします。 フィルタリングのステップにより、そのような構成のみが確実に存続します。 

2×2 や 4×4 のような偶数×偶数のグリッドの場合、すべての位置に個別のミラー パートナーがあるため、反射対称性は特に制限されます。 定期的な構築では依然として有効な候補が生成されますが、多くのシフトは拒否されます。 このアルゴリズムは、対称性の構築に直接依存せず、すでに対称性を満たしている有効なシフトの検出のみに依存しており、ケースバイケースの推論を回避します。
