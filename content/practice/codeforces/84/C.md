 ## 解決策
 ## 問題の理解

 円形のターゲットのセットが与えられ、すべてが Ox 軸上にあり、それぞれがその中心座標と半径によって定義されます。 ヴァレラは複数回射撃し、各射撃には (x, y) 座標があります。 目標は、ターゲットごとに、最初に命中したショットを特定すること、またはショットが命中しなかった場合は -1 を特定することです。 中心までのユークリッド距離が半径以下の場合、ショットはターゲットに当たります。 最終出力には、少なくとも 1 回ヒットしたターゲットの合計数も必要です。 

ターゲットの数$n$まで可能です$10^4$、ショット数$m$まで可能です$2 \cdot 10^5$。 単純な二重ループですべてのターゲットに対して各ショットをチェックするには、$n \times m$操作、おおよそまで$2 \cdot 10^9$最悪の場合、1 秒の制限時間には遅すぎます。 ショットごとの距離計算の回数を減らす方法が必要です。 

ターゲットが非常に接近しているか、互いに接触している場合、微妙なエッジ ケースが発生します。 重なり合うターゲットがない場合でも、1 つのターゲットの境界にあるショットが次のターゲット内に存在する可能性があります。 アルゴリズムは、任意のターゲットだけでなく、入力順序で最初にヒットしたターゲットを正確に識別する必要があります。 

もう 1 つのエッジ ケースは、ターゲットの境界上でのショットです。 境界を含めるには、ユークリッド距離の式を「≤」で実装する必要があります。 すべての座標は制限されているため、整数のオーバーフローは問題になりませんが、座標の 2 乗は標準の整数制限内にとどまる必要があります。 

## アプローチ

 ブルート フォース アプローチでは、各ターゲットと各ショットを単純に反復し、ショットからターゲットの中心までの二乗距離を計算し、それを二乗半径と比較します。 正しいのですが、実行されます$n \times m$距離の計算、おおよそ$2 \cdot 10^9$最悪の場合、遅すぎる場合もあります。 

最適化するための重要な観察は、すべてのターゲットの中心が X 軸上にあり、重なり合っていないことです。 各ターゲットは、X 軸上の間隔によって定義されます。$x-r$に$x+r$。 ショットは、x 座標がこの間隔内にある場合にのみターゲットに命中できます。 さらに、垂直距離は、$y$満たさなければなりません$y^2 \le r^2 - (x_{\text{shot}} - x_{\text{target}})^2$。 ターゲットを X 座標で並べ替えることで、二分探索を使用して各ショットの候補ターゲットを効率的に特定できるようになります。 

ショットごとにすべてのターゲットをチェックする代わりに、X 軸上の各ターゲットの間隔を事前に計算できます。 ポジションでのショットの場合$(sx, sy)$、x 間隔に以下が含まれるすべてのターゲットが見つかります。$sx$。 間隔がばらばらであるか、接触しているだけであるため、二分探索ではショットごとに最大 1 つの候補ターゲットが特定されます。 次に垂直距離をチェックして、ショットが円の中にあるかどうかを確認します。 これにより、複雑さが軽減されます。$O(m \log n)$ショットのチェックに加えて、$O(n \log n)$仕分け用に。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * m) | O(n) | 遅すぎる |
 | ソートされた間隔 + 二分探索 | O(n log n + m log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのターゲットを (center_x、radius、index) のタプルとしてリストに読み取ります。 各ターゲットの X 軸上の間隔を計算します: [center_x - radius, center_x + radius]。 入力順序にマップし直すためのインデックスを保存します。 
2. ターゲットを左側の間隔境界で並べ替えます。 並べ替えにより、バイナリ検索が効率的に機能するようになります。 
3. 各ターゲットに命中した最初のショットを追跡するために、長さ n の結果配列を -1 で初期化します。 
4. すべてのショットを繰り返します。 (sx, sy) での各ショットについて:

 ａ． ターゲットの左境界で二分探索を実行して、左境界が ≤ sx である最後のターゲットを見つけます。 

b. 候補ターゲットについて、ショットの x 座標が間隔内にあるかどうか、および中心までのユークリッドの二乗距離が二乗半径以下であるかどうかを確認します。 

c. 命中し、ターゲットに最初のショットが記録されていない場合は、結果配列を 1 から始まるショット インデックスで更新します。 
5. すべてのショットを処理した後、最初のヒットがあったターゲットの数を数えます (結果は -1 ではありません)。 
6. 合計ヒット数を出力し、続いて入力順に結果配列を出力します。 

機能する理由: ターゲットを並べ替えて X 座標で検索すると、ショットが当たる可能性のあるターゲットを見逃すことがなくなります。 間隔は重複していないため、二分探索ではショットごとに 1 つの候補ターゲットが特定されます。 二乗距離を使用すると浮動小数点エラーが回避され、インデックス マッピングにより入力順に結果がレポートされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from bisect import bisect_right

n = int(input())
targets = []
for i in range(n):
    x, r = map(int, input().split())
    targets.append((x - r, x + r, x, r, i))  # left, right, center, radius, original index

targets.sort()  # sort by left boundary

m = int(input())
shots = [tuple(map(int, input().split())) + (idx + 1,) for idx in range(m)]  # x, y, 1-based index

res = [-1] * n
lefts = [t[0] for t in targets]  # for binary search

for sx, sy, shot_idx in shots:
    pos = bisect_right(lefts, sx) - 1
    if 0 <= pos < n:
        l, r, cx, cr, idx = targets[pos]
        if l <= sx <= r and (sx - cx)**2 + sy**2 <= cr**2:
            if res[idx] == -1:
                res[idx] = shot_idx

hit_count = sum(1 for x in res if x != -1)
print(hit_count)
print(' '.join(map(str, res)))
```このソリューションはターゲットを読み取り、それを x 間隔に変換します。 左境界でソートすると、候補ターゲットの効率的な二分探索が可能になります。 各ショットについて、 bisect_right は、左がショットの x 座標以下である最後の間隔を見つけます。 x 間隔と二乗距離をチェックすることで、正確さを確認できます。 「最初のショット」要件を維持し、ターゲットごとの最初のヒットのみを更新します。
