 ## アルゴリズムのチュートリアル

 1. コンピューティング$d = n - k$。 この量は、サイクル全体にわたって効果的に均等に分配されるキャンディーの数を表します。 
2. もし$d \le 0$、剰余を維持しながら正の完全なサイクル数を形成する有効な方法はありません。$k$, したがって、答えは不可能です。 この問題では$n > k$、 それで$d$常にポジティブです。 
3. すべての整数を反復処理します。$i$1から$\lfloor \sqrt{d} \rfloor$。 それぞれ$i$潜在的な除数候補です。 
4.いつでも$i$分割する$d$、両方を考慮してください$i$そして$d / i$の候補値として$m$。 これにより、1 回のチェックで除数ペアの両方のメンバーが取得されます。

6. 有効な最小値を追跡します。$m$列挙中に発生しました。 有効な約数はどれでも受け入れられるため、最小値を採用しますが、決定的な出力が必要です。

### なぜ効果があるのか

 プロセスは常に次の方程式に帰着します。$n = q \cdot m + k$、強制的に$m$分ける$n-k$。 すべての有効な回答は、次の約数として表示される必要があります。$n-k$したがって、すべての約数を反復すると検索空間が完成します。 制約$m > k$剰余条件がモジュラー算術限界と一致していることを保証します。 すべての有効な候補がチェックされ、最小値が選択されるため、有効な解決策が見逃されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    d = n - k

    ans = None

    i = 1
    while i * i <= d:
        if d % i == 0:
            j = d // i

            if i > k:
                if ans is None or i < ans:
                    ans = i

            if j > k:
                if ans is None or j < ans:
                    ans = j

        i += 1

    print(ans if ans is not None else -1)

if __name__ == "__main__":
    solve()
```この解決策は、問題を次の除数の列挙に縮小します。$d = n - k$。 ループオーバー$i \cdot i \le d$各除数のペアが 1 回だけ処理されるようにするため、値が次の値に近い場合でもランタイムの効率が維持されます。$10^{18}$。 

注意すべき点は両方をチェックすることです$i$そして$d / i$、ペアの片側が欠けていると有効な答えが省略されてしまうためです。 2 番目の重要な詳細は、$m > k$これは、モジュロ演算の剰余が除数より小さくなければならないという制約を直接エンコードします。
