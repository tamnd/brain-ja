 ## 解決策
 ## 問題の理解

 私たちには基準が与えられている$n \times n$チェス盤では、左上の四角形が黒で色が水平方向と垂直方向に完全に交互になります。 これにより、通常の市松模様が作成されます。 タスクは、サイズの正方形が何個あるかを決定することです$1 \times 1$白いです。 

ボードのサイズは単一の整数によって制御されます$n$。 出力は、この交互パターン内の白セルの数だけです。 

制約は重要です。$n$と同じ大きさにすることができます$10^9$。 グリッドを構築したり、すべてのセルを反復しようとしたりするソリューションは、直ちに不可能になります。 完全なシミュレーションには次のことが必要です$n^2$に達する操作$10^{18}$最悪の場合、実現可能な限界をはるかに超えます。$n \le 10^3$。 

明示的に行に色を付けて白セルを行ごとに数えようとすると、単純な落とし穴が発生します。 たとえば、$n = 4$、グリッドを構築しようとするかもしれません:

 入力:```
4
```強引なシミュレーションでは、16 個のセルを塗りつぶし、色を交互に変更し、白を数えます。 それは小規模でも機能します$n$、しかし、同じロジックは実行不可能になります。$n = 10^9$、明示的な構造はメモリまたは時間内に存在できません。 

もう 1 つの微妙なエッジ ケースは、奇数サイズのボードです。 たとえば:

 入力:```
3
```出力：```
4
```セルの半分が常に白であるという単純な仮定では、次のようになります。$4.5$、意味がありません。 パリティ構造が重要です。 

## アプローチ

 ブルートフォース手法では、すべてのセルを反復処理します。$(i, j)$、パリティに基づいて白かどうかを判断し、カウンターをインクリメントします。 セルの座標の合計が左上の黒いセルと逆のパリティを持つ場合、そのセルは白になります。 黒はから始まるので、$(1,1)$、和を持つ$2$の場合、セルは白になります。$(i + j)$奇数です。 

この方法は、カラーリング ルールを直接エンコードするため、正しいです。 ただし、必要なのは$n^2$小切手。 いつ$n = 10^9$、これは次のようになります$10^{18}$まったく実行不可能な操作です。 

重要な観察は、ボードが完全に周期的であるということです。 各 2 x 2 ブロックには、ちょうど 2 つの白のセルと 2 つの黒のセルが含まれます。 これにより、反復の必要がなくなります。 セルを個別に数える代わりに、行と列の完全なペアがいくつ存在するか、および残りがどのように動作するかを数えるだけで済みます。$n$奇数です。 

もし$n$が偶数の場合、ボードは次のように分割されます。$2 \times 2$ブロックであり、それぞれがちょうど 2 つの白セルに寄与します。 もし$n$が奇数の場合は、交互構造を維持する部分的な行と列が追加され、偶数の場合と比較して合計で 1 つの余分な白いセルが追加されます。 

これは、整数の除算に基づく閉じた形式の式に直接つながります。

 ## アルゴリズムのチュートリアル

 1. 各セルの色はその座標のパリティのみに依存することに注目してください。 白いセルは、指定された開始設定で座標合計が奇数の場合に発生します。 これにより、シミュレーションが不要になります。 
2. ボードを完全に分割します$2 \times 2$ブロック。 このような各ブロックには、ちょうど 2 つの白いセルが含まれています。 完成したブロックの数は$(n // 2)^2$。 これにより、完全にペアになった構造がすべてキャプチャされます。 
3. 次の場合に、残った行と列を処理します。$n$奇数です。 最後の行または最後の列がある場合、それらは交互のパターンに従って追加のセルを提供し、結果は正確に$\lfloor n^2 / 2 \rfloor$全体的に白い細胞。 
4. 最終的な答えを整数の除算として計算します。$n \cdot n // 2$、偶数と奇数の両方のケースを分岐せずに自然に処理します。 

### なぜ効果があるのか

 カラーリングにより、グリッドの厳密なパリティ分割が行われます。すべてのセルは、次の基準に基づいて 2 つのクラスのいずれかに正確に属します。$(i + j) \bmod 2$。 グリッドは黒のセルから始まるため、$(1,1)$、白いセルは、グリッド全体に均一に分布するパリティ クラスの 1 つに対応します。 どの長方形の領域でもパリティは完全に交互になり、不均衡は面積が奇数の場合に最大 1 つのセルによってのみ発生します。 これにより、切り捨てられたちょうど半分のセルが白になることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input().strip())
print((n * n) // 2)
```この解決策は完全にチェス盤のパリティ構造に依存しています。 表現$n * n$セルの総数を計算します。 整数除算を使用して 2 で除算すると、白セルの正確な数と一致する切り捨てによって偶数と奇数の両方のケースが自動的に処理されます。 

微妙な点は、Python の整数は大きな値を安全に処理できるため、$n = 10^9$、コンピューティング$n^2$有効のままです。 固定幅の整数を使用する言語では、オーバーフローを避けるために 64 ビットの演算を保証する必要があります。
