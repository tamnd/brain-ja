 ## 解決策
 ## 問題の理解

 この問題では、Petya は最小限の時間で誕生日の料理をすべて揃えたいと考えています。 それぞれの料理について、レストランから自分で取りに行くか、`b_i`数分で到着するか、配達を注文してください。`a_i`分。 すべての宅配業者は、Petya が家を出ると同時に配達を開始しますが、Petya は受け取りを選択したすべてのレストランを順番に訪問し、移動時間を合計する必要があります。 目標は、どの料理を個人的に受け取るか、どの料理を配達するかを選択して、すべての料理が自宅に届くまでの合計時間を最小限に抑えることです。 

各テスト ケースは料理の数を示します`n`および 2 つのリスト: 配達時間`a`個人的なお迎え時間`b`。 出力は、すべての料理が Petya の家に届くまでの最小合計時間です。 なぜなら`n`最大 2·10^5 になる可能性があり、すべてのテスト ケースの合計も 2·10^5 になるため、料理のすべてのサブセットを試行するアルゴリズムは実行不可能です。 線形または線形のアプローチが必要です`n`。 

主要なエッジケースは、最速の集荷時間がどの宅配業者よりも優れている場合、またはすべての配達時間が個人旅行よりも速い場合に発生します。 たとえば、次の場合`a = [1,1,1]`そして`b = [10,10,10]`の場合、最適な戦略はすべてを配達して合計時間を 1 とすることですが、配達と集荷を合計する不注意なアプローチでは時間を過大評価する可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、料理のすべてのサブセットを個人的にピックアップし、残りを配達することを検討します。 各サブセットについて、そのサブセットの受け取り時間を合計し、その合計と残りの料理の最大配達時間の間の最大値を取得します。 このアプローチは原理的には正しいですが、2^n 個のサブセットがあるため実行不可能です。 

最適なアプローチは、並べ替えと貪欲な推論に依存します。 Petya が選択した場合を考慮してください。`k`皿は自分で取りに行き、残りは`n-k`食器が届けられます。 そのときの合計時間は、`sum of the k largest b_i`（彼は最大のものを拾うことができるので、`b_i`配達時間の無駄を避けるために最初に）、他の料理との最大配達時間を考慮します。 すべてのクーリエが並行して開始するため、合計時間は次の間の最大時間になります。`sum of pickup times for chosen dishes`そして最大宅配時間。 したがって、合計時間を最小限に抑えるには、次のように分類する必要があります。`b_i`降順で、それぞれについて`k = 0..n`を選択することを検討してください。`k`最大`b_i`そして残りを配達してもらいます。 これらの候補の中の最小値が答えになります。 並べ替えにより、最大値の合計を効率的に計算できます。`b_i`、全体として O(n log n) の解が得られます。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`そしてリスト`a`（配送）と`b`（選び出す）。 
2. 並べ替え`b`降順で。 これにより、部分和を計算するときに、最初に最大のピックアップ時間を選択することができます。 
3. ソートされたプレフィックスの合計を計算します。`b`リスト。`prefix[k]`最初の合計を表します`k`最大`b_i`。 
4. 変数を初期化する`ans`無限大で。 反復処理`k`0から`n`。 それぞれについて`k`:

 - 最初のものを選択することを検討してください`k`最大`b_i`個人的には。 
- 残り`n-k`料理の配達が行われますので、そのうちの最長配達時間は`max(a)`すべてが考慮される場合、または関連するサブセットが考慮される場合。 納期は変動する可能性があるため、検討するのが安全です`max(a)`みんなのために`n`個人的に拾ったものを除いた料理。 
- この選択にかかる合計時間は`max(prefix[k], max(a))`。 
- アップデート`ans`最小限まで`ans`そしてこの合計時間。 
5. すべてを考慮した上で`k`、`ans`には、テスト ケースの最小合計時間が含まれます。 
6. 印刷`ans`。 

機能する理由: アルゴリズムは、個人的に選んだ料理の数ごとに、`k`、最初に最大のピックアップ時間を選択することで、可能な限り最適な構成を検討します。 並べ替えにより、プレフィックスの合計により、すべての配送/集荷の選択肢にわたって最小最大時間が確実に得られます。 の`max`2 つの並列プロセスのうち遅い方がボトルネックであることを確認し、現実世界のシナリオを正しくモデル化します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        b_sorted = sorted(b, reverse=True)
        prefix = [0]*(n+1)
        for i in range(n):
            prefix[i+1] = prefix[i] + b_sorted[i]

        max_a = max(a)
        ans = float('inf')
        for k in range(n+1):
            time = max(prefix[k], max_a)
            ans = min(ans, time)
        print(ans)

if __name__ == "__main__":
    main()
```コードは最初にテスト ケースの数を読み取ります。 各テスト ケースについて、次のようになります。`a`そして`b`。 仕分け`b`降順でプレフィックスの合計を効率的に計算でき、Petya が最初のプレフィックスを取得した場合の累積時間を表します。`k`最大`b_i`。 それぞれについて`k`、合計時間を集荷合計と最大配達時間の最大値として計算します。 全体を通しての最小値`k`と印刷されています。 このアプローチでは、サブセットの列挙が回避され、テスト ケースごとに O(n log n) で実行されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    res = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        b_sorted = sorted(b, reverse=True)
        prefix = [0]*(n+1)
        for i in range(n):
            prefix[i+1] = prefix[i] + b_sorted[i]
        max_a = max(a)
        ans = float('inf')
        for k in range(n+1):
            ans = min(ans, max(prefix[k], max_a))
        res.append(str(ans))
    return '\n'.join(res)
