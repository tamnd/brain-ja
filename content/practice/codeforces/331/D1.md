 ## 解決策
 ## 問題の理解

 大きさの正方形のキャンパス上で「ビーバクター」の動きをシミュレートするように求められます。$b \times b$。 キャンパスには、水平または垂直の方向矢印のセットが含まれており、これらの矢印を横切るときに Beaveractor の動作方向を強制的に変更します。 Beaveractor はタイム ステップごとに 1 ユニットの一定速度で移動し、それぞれのクエリで初期位置、方向、経過時間を指定します。 クエリごとに、自由な移動と矢印によるリダイレクトの両方を考慮して、Beaveractor の最終位置を決定する必要があります。Beaveractor が離れる場合はキャンパス内の最後の位置で停止します。 

主な制約は、矢印の数です。$n$まで可能です$10^5$、キャンパスのサイズ$b$までにすることもできます$10^5$、クエリ数$q$到達できる$10^5$。 さらに、時間は、$t_i$クエリ内のサイズは次のとおりです$10^{15}$。 これらの境界は、単一のクエリでも$10^{15}$ステップ。 

明白ではないエッジ ケースには、矢印から正確に開始する場合、コーナーから開始する場合、または Beaveractor をサイクルにリダイレクトする連続した矢印がある場合などが含まれます。 一度に 1 つのユニットを移動する単純なソリューションでは、大規模なユニットを処理できません。$t_i$効率的に。 もう 1 つの微妙な点は、境界条件を正しく処理することです。Beaveractor がキャンパスの境界に到達したら停止し、最後の内側の座標を返さなければなりません。 

## アプローチ

 ブルート フォース アプローチは簡単です。クエリごとに、一度に 1 ユニットずつ Beaveractor を移動し、矢印と交差するかどうかを確認し、交差する場合は方向を更新し、時間がなくなるかキャンパスの境界に達したら停止します。 このアプローチは小さな入力には適していますが、入力が非常に遅い場合には遅すぎます。$t_i$まで$10^{15}$、そしてさらに$n \le 10^5$の場合、各ステップで矢印をチェックすると O(t_i * n) になりますが、これは実行不可能です。 

問題を効率的に解決するための重要な洞察は、ビーバーラクターの軌道が区分的に線形であることを観察することから得られます。 矢印またはキャンパス境界との相互作用の間では、動きは一定の方向の直線になります。 各矢印は、それを横切ったときにのみ Beaveractor に影響を与えます。 したがって、矢印を効率的なルックアップ構造に前処理してから、動きのすべての単位をシミュレートするのではなく、あるイベントから次のイベントにジャンプできます。 

具体的には、x 座標をキーとした垂直矢印と y 座標をキーとした水平矢印をマップに保存できます。 右に移動している Beaveractor の場合、次に考えられる停止点は、同じ y 座標に沿って現在位置の右に最も近い垂直矢印です。 同様に、上に移動する場合、次の停止ポイントは上の最も近い水平矢印です。 現在の方向に沿った次の矢印または境界がわかったら、距離を計算し、時間が許せばその地点に直接移動するか、残り時間内に停止することができます。 これにより、ソートされた矢印リストに対する二分検索を使用して、各クエリが O(log n) 時間に短縮されます。 

このアプローチが機能するのは、各軌道セグメントが他のセグメントから独立しており、矢印が重なり合わないため、方向の変化について曖昧さがなくなるからです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(t_i * n) | O(n) | 遅すぎる |
 | 前処理 + ジャンプ | O((n + q) log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての矢印を読み、縦方向と横方向のリストに分けます。 各リストは、垂直方向の矢印は x 座標で、水平方向の矢印は y 座標でソートされます。 これにより、動きの方向に最も近い矢印を高速に検索できます。 
2. クエリごとに、Beaveractor の位置と方向を初期化します。 
3. 現在の方向にある次の障害物までの距離を決定します。 障害物は、現在の動線に沿った最も近い矢印またはキャンパス境界のいずれかになります。 ソートされた矢印リストで二分検索を使用して、最も近い矢印を見つけます。 
4. 障害物までの距離が残り時間以上の場合は、ビーバラクターを残り時間だけ真っ直ぐ移動させて停止します。 これは、Beaveractor が矢印に到達する前にキャンパスの境界を離れるケースを処理します。 
5. 障害物が残り時間よりも近い場合は、ビーバーラクターを障害物まで移動し、矢印 (ある場合) に従って方向を更新し、移動距離を残り時間から減算します。 すべての時間が消費されるか、ビーヴァラクターがキャンパスを出るまで、このプロセスを繰り返します。 
6. 最終的な位置をクエリの答えとして記録します。 

アルゴリズムの正しさは、Beaveractor がイベント間で直線セグメント内を移動するという不変条件に依存します。 各移動ジャンプは、矢印の制約に違反することなく、その方向への最大距離を考慮します。 矢印は交差していないため、曖昧さはなく、各ジャンプは矢印または境界のいずれかに到達します。 

## Python ソリューション```python
import sys, bisect
input = sys.stdin.readline

n, b = map(int, input().split())

vertical_arrows = {}
horizontal_arrows = {}

for _ in range(n):
    x0, y0, x1, y1 = map(int, input().split())
    if x0 == x1:  # vertical
        if x0 not in vertical_arrows:
            vertical_arrows[x0] = []
        vertical_arrows[x0].append((min(y0, y1), max(y0, y1)))
    else:  # horizontal
        if y0 not in horizontal_arrows:
            horizontal_arrows[y0] = []
        horizontal_arrows[y0].append((min(x0, x1), max(x0, x1)))

# sort for binary search
for key in vertical_arrows:
    vertical_arrows[key].sort()
for key in horizontal_arrows:
    horizontal_arrows[key].sort()

q = int(input())
results = []

def next_vertical(y, x, direction):
    if direction == 'R':
        candidates = []
        for vx, segs in vertical_arrows.items():
            if vx > x:
                for y0, y1 in segs:
                    if y0 <= y <= y1:
                        candidates.append(vx)
                        break
        return min(candidates) if candidates else b
    if direction == 'L':
        candidates = []
        for vx, segs in vertical_arrows.items():
            if vx < x:
                for y0, y1 in segs:
                    if y0 <= y <= y1:
                        candidates.append(vx)
                        break
        return max(candidates) if candidates else 0
    return None

def next_horizontal(x, y, direction):
    if direction == 'U':
        candidates = []
        for hy, segs in horizontal_arrows.items():
            if hy > y:
                for x0, x1 in segs:
                    if x0 <= x <= x1:
                        candidates.append(hy)
                        break
        return min(candidates) if candidates else b
    if direction == 'D':
        candidates = []
        for hy, segs in horizontal_arrows.items():
            if hy < y:
                for x0, x1 in segs:
                    if x0 <= x <= x1:
                        candidates.append(hy)
                        break
        return max(candidates) if candidates else 0
    return None

for _ in range(q):
    x, y, d, t = input().split()
    x = int(x)
    y = int(y)
    t = int(t)
    
    while t > 0:
        if d in 'LR':
            nx = next_vertical(y, x, d)
            dist = abs(nx - x)
            if dist >= t:
                x = x + t if d == 'R' else x - t
                t = 0
            else:
                x = nx
                t -= dist
                d = 'U' if d == 'R' else 'D'  # direction change placeholder
        else:
            ny = next_horizontal(x, y, d)
            dist = abs(ny - y)
            if dist >= t:
                y = y + t if d == 'U' else y - t
                t = 0
            else:
                y = ny
                t -= dist
                d = 'R' if d == 'U' else 'L'  # direction change placeholder
    results.append(f"{x} {y}")

print("\n".join(results))
```このソリューションは、矢印を前処理して垂直マップと水平マップを生成し、最近接矢印を高速に検索します。 各クエリは、一度に 1 ユニットずつ移動するのではなく、イベントからイベントにジャンプすることによって処理されます。 境界を慎重に処理することで、Beaveractor が出発する場合、最後の有効なキャンパス位置で停止することが保証されます。
