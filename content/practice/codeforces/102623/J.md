 ## 解決策
 私は社説を書くことはできますが、あなたが提供した問題ステートメントは**インタラクティブな問題**に関するものですが、要求された形式では通常の stdin/stdout ソリューション、サンプルベースのテスト、およびオフライン Python 実装が必要です。 

これら 2 つの形式はここでは互換性がありません。 

- 元の問題では、プログラムはグリッドを受信しません。 受信のみ`n`そして`m`、その後、次のようなクエリを出力する必要があります。`? x1 y1 x2 y2`そして裁判官の返答を読んでください。 
- 「入力」セクションには非表示のグリッド値が含まれていないため、オフラインの Python ソリューションは標準入力から応答を再構築できません。 
- サンプルはインタラクション トランスクリプトであり、通常のサンプル入力/出力ペアではありません。 
- 要求されたアサートベースのテストは、模擬対話型ジャッジなしでは正しく作成できません。 

要求された構造で完全な社説を作成するには、次のいずれかの説明が必要です。 

1. クエリ戦略と対話型 Python 実装を含む、独自の対話型ソリューションが必要です。 
2. 問題はオフライン バージョンに変換されており、入力には実際の内容が含まれています。`n × m`バイナリ グリッドであり、タスクは何か他のものを出力することです。 その場合は、変換されたステートメントを提供してください。 

オプション 1 をご希望の場合は、アルゴリズム、証明、複雑さの分析、Python インタラクション コードを使用した完全なインタラクティブな編集を作成できます。
