 ## 解決策
 ## 問題の理解

 頂点上のラベル付きツリーをカウントする必要があります`1..n`という 2 種類の制約を満たします。 いくつかの頂点のペアはエッジによって強制的に接続されます。 他の制限により、特定の頂点の上または下からの最終次数が制限されます。 

答えは、1 本のツリーを構築することを求めているわけではありません。 有効なツリーを表す可能な隣接行列をすべてカウントする必要があります (モジュロ)`998244353`。 

小さい値`n <= 60`木やエッジを列挙するアプローチは除外されます。 ラベルが付けられた木の数は`n^(n-2)`ケイリーの公式によると、これはすでに巨大なものです`n = 60`。 多項式の解が必要です。 

重要な観察は、すべての有効なケースで強制エッジがフォレストを形成するということです。 サイクルが含まれている場合、ツリーにすべてのサイクルを含めることはできません。 このフォレストのすべての接続コンポーネントを縮小した後、残りの選択肢は、これらのコンポーネントをツリーに接続することだけです。 

微妙な点は、次数制限は、縮小されたコンポーネントではなく、元の頂点に適用されることです。 頂点にはすでに強制エッジによってある程度の次数が与えられており、コンポーネント間のエッジによって提供できるのは残りの次数のみです。 

## アプローチ

 ブルート フォース ソリューションでは、Prüfer シーケンスを使用してすべてのラベル付きツリーを生成できます。 ツリーは長さのシーケンスに対応します`n-2`したがって、すべてのシーケンスを列挙し、ツリーを再構築し、すべての制約をチェックできます。 すべてのラベル付きツリーは 1 回だけ出現するため、これは正しいです。 ただし、`n^(n-2)`シーケンス、これは中程度の人でも不可能です`n`。 

有用な構造は、必須のエッジを縮小することで得られます。 必須フォレストに次のものがあるとします。`c`接続されたコンポーネント。 有効な最終ツリーは、正確に追加することによって取得されます。`c-1`これらのコンポーネント間のエッジ。 収縮後は、コンポーネントのすべてのペアを接続でき、コンポーネント内のエンドポイントの選択がそのエンドポイントの次数に影響します。 

コンポーネントの場合`C`、 させて```
S_C = sum(x_v)
```すべての頂点にわたって`v`その中に。 重み付き Cayley の公式によれば、収縮されたコンポーネント上の木の生成関数は次のようになります。```
(S_1 + S_2 + ... + S_c)^(c-2) * S_1 * S_2 * ... * S_c
```ここで、の指数は`x_v`頂点から離れる新しいエッジの数を表します`v`。 

残りのタスクは、制約によって許可される次数のみを抽出することです。 なぜなら`n`がわずか 60 である場合、可能な外部次数の合計に対する動的計画法で十分です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース Prüfer 列挙 | O(n^(n-2) * n) | O(n) | 遅すぎる |
 | 契約林 + 生成関数 DP | O(n^3) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. DSU を使用して、必須エッジがフォレストを形成しているかどうかを確認します。 エッジがすでに接続されている 2 つの頂点を結合する場合、すべてのツリーは非循環であるため、答えはゼロになります。 
2. すべての頂点について、必須フォレスト内の次数を計算します。 これは、すでに確定している最終学位の部分です。 
3. すべての次数制約を、頂点に付随する追加エッジの数の範囲に変換します。 頂点にすでに必須の次数がある場合`d`の場合、その追加次数は次を満たさなければなりません。```
lower - d <= extra_degree <= upper - d
```4. 必須フォレストをコンポーネントに圧縮します。 コンポーネントが 1 つだけの場合、最終ツリーのすべてのエッジはすでに固定されているため、すべての次数制約が一致すれば答えは 1 になります。 
5. すべてのコンポーネントについて、その頂点が与えられた外部エッジの総数を何通り受け取ることができるかを記述する多項式を計算します。 受信できる頂点の場合`t`外部エッジの寄与は次のとおりです。```
x^t / t!
```コンポーネント内でこれらの多項式を乗算すると、コンポーネント多項式が得られます。 
6. すべてのコンポーネントを組み合わせます。 コンポーネントには、縮小ツリー内に少なくとも 1 つの外向きエッジが必要なので、その合計外部次数は次のようになります。`g >= 1`。 Cayley の公式は次のことに貢献します。```
(c-2)! * g
```コンポーネントの貢献を選択するため。 
7. コンポーネント上でナップザックを実行して、合計外部次数を次と等しくします。`2(c-1)`、木が立っているので、`c`契約したノードには`c-1`エッジとそのようなすべてのエッジは 2 度に寄与します。 

### なぜ効果があるのか

 必須のエッジは固定フォレストを定義します。 すべての有効なツリーは、縮小されたコンポーネント間のツリーに一意に対応し、元の頂点が新しいエッジの端点になるかの選択肢を加えたものに対応します。 

生成関数は、これらのエンドポイントの選択を正確にエンコードします。 単項式の係数は、頂点間で外部次数を分配する方法の数を示します。 Cayley の公式は、コンポーネントをそれらのコンポーネント次数で接続する方法の数を示します。 DP は考えられるすべての有効な次数割り当てを合計するため、有効なツリーはすべて 1 回カウントされ、無効なツリーは除外されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, m, k = map(int, input().split())

    parent = list(range(n))
    size = [1] * n

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(a, b):
        a = find(a)
        b = find(b)
        if a == b:
            return False
        if size[a] < size[b]:
            a, b = b, a
        parent[b] = a
        size[a] += size[b]
        return True

    forced_deg = [0] * n

    ok = True
    for _ in range(m):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        forced_deg[a] += 1
        forced_deg[b] += 1
        if not union(a, b):
            ok = False

    low = [1] * n
    high = [n - 1] * n

    for _ in range(k):
        op, x, d = map(int, input().split())
        x -= 1
        if op == 0:
            low[x] = max(low[x], d)
        else:
            high[x] = min(high[x], d)

    if not ok:
        print(0)
        return

    for i in range(n):
        low[i] -= forced_deg[i]
        high[i] -= forced_deg[i]
        if high[i] < 0:
            print(0)
            return
        low[i] = max(low[i], 0)

    roots = {}
    comp_id = []
    for i in range(n):
        r = find(i)
        if r not in roots:
            roots[r] = len(roots)
        comp_id.append(roots[r])

    c = len(roots)

    if c == 1:
        ans = 1
        for i in range(n):
            if not (low[i] <= 0 <= high[i]):
                ans = 0
        print(ans)
        return

    fact = [1] * (n + 5)
    invfact = [1] * (n + 5)
    for i in range(1, n + 5):
        fact[i] = fact[i-1] * i % MOD
    invfact[-1] = pow(fact[-1], MOD - 2, MOD)
    for i in range(n + 4, 0, -1):
        invfact[i-1] = invfact[i] * i % MOD

    comps = [[] for _ in range(c)]
    for i in range(n):
        comps[comp_id[i]].append(i)

    polys = []

    for comp in comps:
        poly = [1]
        for v in comp:
            nxt = [0] * (len(poly) + n)
            for i, a in enumerate(poly):
                if a:
                    for d in range(low[v], high[v] + 1):
                        nxt[i + d] = (nxt[i + d] + a * invfact[d]) % MOD
            poly = nxt

        val = [0] * len(poly)
        for i in range(1, len(poly)):
            val[i] = poly[i] * i % MOD
        polys.append(val)

    dp = [0] * (2 * c)
    dp[0] = 1

    for poly in polys:
        ndp = [0] * (2 * c)
        for i in range(len(dp)):
            if dp[i]:
                for j in range(1, len(poly)):
                    if i + j < len(ndp):
                        ndp[i + j] = (ndp[i + j] + dp[i] * poly[j]) % MOD
        dp = ndp

    ans = dp[2 * c - 2] * fact[c - 2] % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```DSU 部分は必須のフォレストを処理します。 ツリーにはサイクルを含めることができないため、同じコンポーネント内で接続を繰り返すと、それが不可能であることがすぐにわかります。 

次数変換は最も間違いやすい部分です。 制限は最終次数を記述しますが、生成関数は新しく追加されたエッジのみをカウントします。 すでに固定されている森林次数を減算すると、問題は多項式で表される正確な量に変換されます。 

階乗逆関数が表示されるのは、多項展開の係数に、選択した指数の階乗による除算が含まれるためです。 後でコンポーネント次数を乗算すると、収縮されたツリーの Cayley 寄与が復元されます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n^3) | 多項式のマージが優勢で、頂点数は最大 60、次数範囲は 60 |
 | スペース | O(n^2) | DP 配列は次数分布のみを格納します。 

すべての木には次数しかないため、最大次数の範囲は小さくなります。`n-1`エッジ。 と`n = 60`、立方体境界は簡単に制限内に収まります。
