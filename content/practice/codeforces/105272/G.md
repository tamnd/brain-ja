 ## 問題の理解

 私たちは、完全に固定された世代で進化する集団を見ています。 第一世代は、ある程度の数の個体から始まります。$a$。 あらゆる生殖世代のすべての人が正確に生産します$r$したがって、各世代は前の世代に同じ係数を乗算することによって取得されます。$r$。 このプロセスは次の期間継続します$m$再生産の世代、しかし世代では$m$、生殖が停止し、その世代はまだ存在しますが、それ以上の子孫は生成されません。 

したがって、人口規模は等比級数を形成します。$$a, ar, ar^2, \dots, ar^m$$そして、記録された総人口は、これらすべての世代の合計です。$$n = a(1 + r + r^2 + \dots + r^m)$$私たちに与えられたのはただ$n$トリプルが何個あるか数えなければなりません$(a, r, m)$と$a \ge 1$、$r > 1$、$m \ge 0$正確にこの合計を生成できます。 

重要な問題は、異なる幾何学的分解が同じ合計を生成する可能性があることです。そのため、一意の因数分解を解決するのではなく、有効なパラメーター化をすべてカウントすることになります。 

制約$n \le 10^9$構造の少なくとも 1 つまたは 2 つの次元を列挙することはできるが、すべてのトリプルを個別に総当りで実行することはできないことを強く示唆しています。 すべてを試すソリューション$a, r, m$だって爆発するだろうから$r^m$急速に成長しますが、それでも多くの組み合わせが残ります。 

微妙なエッジケースが現れるのは、$m = 0$。 この場合、世代は 1 つだけなので、合計は単純に次のようになります。$n = a$。 This means every$n$常に少なくとも 1 つの有効な構成、つまり単一の非再生世代を提供します。 

もう 1 つのエッジケースは次のような場合です$r$は十分大きいため、幾何学和は 2 項または 3 項をわずかに超えません。 多くの素朴なアプローチは、異なるものを扱うことによって過大評価されます$(a, r)$残りの合計が整数制約によって完全に説明できるかどうかを確認せずに、ペアを独立したものとして扱います。 

## アプローチ

 強引なアイデアは、可能な限りすべてを反復することです$r$そして$m$、幾何学的な合計係数を計算します。$$S(r, m) = 1 + r + r^2 + \dots + r^m$$そして、次のことを確認します$a = n / S(r, m)$は整数です。 そうであれば、それをカウントします。 

これは正しいですが、すぐに実行不可能になります。 それでも$m$という事実によって暗黙的に制限されています$r^m \le n$、ペアの数$(r, m)$まだ大きいです。 それぞれについて$r$、最大$m$おおよそです$O(\log_r n)$、そしてすべてを合計すると$r$に近い複雑さを与えます$O(n)$最悪の場合の約数構造と指数関数的成長。 
重要な観察は、構造が 2 つの制約によって完全に決定されるということです。つまり、合計は幾何学的であり、$a$は単なる倍率です。 したがって、列挙する代わりに$a$、幾何和を修正します$S$、そしてそれを要求します$S$分割する$n$。 修正したら$r$そして$m$、$S$は一意に決定され、すべての有効な構成は、次の有効な幾何学的合計係数を選択することに対応します。$n$。 

したがって、問題はすべてのペアを列挙することになります。$(r, m)$次のような:$$S(r, m) \mid n
\quad \text{and} \quad r > 1$$それぞれの有効な$S$、正確に 1 つ得られます$a = n / S$。 

計算構造が管理しやすくなる理由は、$r^m$指数関数的に増加するため、それぞれ$r$を超えるまで幾何和をシミュレートするだけで済みます。$n$。

 ## アルゴリズムのチュートリアル

 考えられるすべての幾何学和を列挙し、それらが割り切れるかどうかを確認することに重点を置きます。$n$。 

1. 可能なすべての値を反復処理します。$r$2から始まります。 まで行くだけでいいのです$r \le n$しかし実際には、成長により各チェーンの停止がはるかに早くなります。 
2. 固定の場合$r$、等比数列の合計を増分的に計算します。 から始める$sum = 1$に対応します。$m = 0$。 
3. ランニングパワー項に繰り返し乗算します。$r$、各ステップで合計を更新します。 加算するたびに、合計が次を超えるかどうかを確認します$n$。 そうなった場合は、停止してください。これ以上条件を追加すると増加するだけです。 
4. 計算されたそれぞれの合計について$S$、どうかを確認してください$n \bmod S = 0$。 そうであれば、それは有効な分解を表し、1 つの構成に寄与します。 
5. 些細なケースを常に含める$m = 0$、 どこ$S = 1$に対応します。$a = n$。 
6. すべての有効なケースをすべて累積します。$r$。 

重要な考え方は、各有効な構造が固有の幾何学的なプレフィックスの合計に対応するということです。$S(r, m)$、その合計が固定されると、初期人口が強制されます。 

### なぜ効果があるのか

 有効な人口履歴はすべて、再生産係数の選択によって完全に決定されます。$r$、深さ$m$、次にスケーリング$a$。 総人口は常に$a \cdot S(r, m)$。 逆に言えば、どのペアでも$(r, m)$固定額を定義します$S$、そしてもし$S$分割する$n$、有効な$a$。 列挙が終わりました$r$累乗累乗により、固定された部分和のシーケンスが計算されるため、すべての可能な幾何学和を正確に 1 回生成できます。$r$は厳密に増加しており、一意に決定されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    # m = 0 case: sum = 1 always
    # contributes exactly one configuration for any n
    ans = 1
    
    # try all r > 1
    # geometric sum S = 1 + r + r^2 + ...
    for r in range(2, n + 1):
        s = 1
        term = 1
        
        while True:
            term *= r
            s += term
            if s > n:
                break
            if n % s == 0:
                ans += 1
    
    print(ans)

if __name__ == "__main__":
    solve()
```このコードは、答えを 1 で初期化することによって、単純な単一世代のケースを直ちに分離します。これは、以下に対応します。$m = 0$、そこでは再生産は起こらず、人口はただ残ります。$a = n$。 

各候補者の再生産率$r$、私たちは力を構築します$r$段階的に。 変数`term`トラック$r^k$、 そして`s`幾何和を累積します。 一度`s`を超える$n$, これ以上条件を付けてもさらに増加するだけなのでやめます。 

毎回`s`分割する$n$、有効な整数を意味するため、有効な構成をカウントします。$a = n / s$。 

微妙な点は、明示的に追跡していないことです。$m$更新回数によって暗黙的にエンコードされるため`term`。

 ## 特殊なケース

 ### ケース n = 1

 唯一可能な構成は、単一の非再生世代です。 アルゴリズムが初期化されます`ans = 1`したがって、意味のあるループ反復を入力しなくても、正しく 1 が返されます。 

### n に近い大きな r

 いつ$r = n$、幾何和は次のようになります。$1 + n$をすぐに超えます$n$。 ループは 1 回の反復後に停止するため、無効なディープ チェーンの探索に時間を無駄にすることがなくなります。 

### 素数 n

 プライム用$n$、幾何学和が 1 または正確に等しい構成のみ$n$可能です。 自明レベルまたは全和レベルでは除数チェックのみが成功し、中間因数分解が存在しないという数学的制限に一致するため、アルゴリズムはこれを検出します。
