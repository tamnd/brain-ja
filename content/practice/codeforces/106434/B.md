 ## 解決策
 ## 問題の理解

 私たちには歪んだ形でしか見えない配列が与えられています。 観測された配列内の各要素は、元々は観測された値の周囲の固定間隔内の任意の整数であった可能性があります。 具体的には、値が表示された場合、`a[i]`の場合、暗号化前の真の値は次のいずれかの整数である可能性があります。`a[i] - l`まで`a[i] + r`, しかし、決してマイナスではありません。 

問題は、結果として得られる隠し配列が減少しないように、各位置に対して 1 つの有効な元の値を選択できるかどうかです。 

したがって、配列を一意に再構築する必要はありません。 シーケンスがソートされるように、すべての位置に対して有効な値を選択する方法が少なくとも 1 つ存在するかどうかを判断するだけで済みます。 

制約は次のとおりです`n = 2 * 10^5`したがって、どのような解も線形に近いものでなければなりません。 範囲内のすべての選択肢を試すことを伴うものは、各要素に最大で`O(10^9)`可能な値。 範囲にわたる要素ごとの検索でも爆発的になります。 

素朴な考えでは、各位置を独立して扱うことになりますが、順序制約によりすべての位置が緊密に結合されます。 重要な問題は、それぞれの選択が将来の選択を制限することです。 

いくつかの失敗例から、何が問題になるのかが明らかになります。 

各ステップで可能な限り最小の値を貪欲に選択すると、初期の値が小さいと、後の要素が小さくなりすぎて非減少のままになるため、後で行き詰まってしまう可能性があります。 

代わりに、各ステップで可能な最大の値を選択すると、より小さい初期の選択を必要とする有効なソリューションが不必要にブロックされる可能性があります。 

本当の問題は、各位置が間隔であり、値のチェーンを各間隔から 1 つずつ選択して、非減少シーケンスを形成できるかどうかを確認する必要があることです。 

## アプローチ

 ブルート フォースの解釈は簡単です。各位置について、その区間内で考えられるすべての元の値を考慮します。`[a[i] - l, a[i] + r]`、すべての組み合わせに対してバックトラッキングまたは動的計画法を使用して、非減少シーケンスを構築してみます。 これは、妥当性の定義を直接検討しているため、正しいです。 ただし、各ポジションには最大`O(r + l)`可能性、そしてそれ以上`n`これにより、おおよその組み合わせが指数関数的に増加します。`(range size)^n`、それはまったく実行不可能です。 

重要な観察は、ある位置で考えられるすべての値を記憶する必要は決してないということです。 左から右に処理する場合、重要なのはプレフィックスとして終了できる値の実行可能な範囲だけです。 すべての選択肢を追跡するのではなく、プレフィックスを有効に保つために最後に選択された要素のすべての可能な値の間隔を追跡します。 

位置で`i`、最後に選択された値が一定の間隔内にある必要があることがすでにわかっているとします。`[L, R]`。 次の要素では、値を選択する必要があります`x`そのような`x >= L`そして`x`にある`[a[i] - l, a[i] + r]`。 したがって、選択できる最小値は次のとおりです。`max(L, a[i] - l)`、最大値は`a[i] + r`。 この間隔が無効になる（下限が上限を超える）場合、構築は不可能になります。 

これにより、問題は単純な区間伝播プロセスに変わります。

 ## アルゴリズムのチュートリアル

 有効なプレフィックスの最後の要素に対して可能なすべての値のセットを維持します。 セットではなく、実現可能な範囲のみを保持します`[L, R]`。 

1. 最初の要素の範囲を次のように初期化します。`[a[0] - l, a[0] + r]`。 元の値は負ではない必要があるため、下限は少なくともゼロになるように固定します。 
2. この範囲を現在の実行可能な間隔として設定します。 
3. 次のポジションごとに`i`、その許容間隔を計算します`[low_i, high_i] = [a[i] - l, a[i] + r]`、再びクランプ`low_i`ゼロに。 
4. 非減少順序を維持するには、新しい値は少なくとも次の値でなければなりません。`L`。 したがって、区間を交差します`[low_i, high_i]`と`[L, +infinity)`、新しい下限を与える`L' = max(L, low_i)`そして上限`R' = high_i`。 
5. いつでも`L' > R'`、位置で有効な値を選択できません`i`単調性を崩さない限り、それは不可能であるとすぐに結論付けられます。 
6. それ以外の場合は更新します`[L, R] = [L', R']`そして続けます。 
7. すべての要素が正常に処理されると、有効な非減少の隠し配列が存在します。 

### なぜ効果があるのか

 アルゴリズムは、位置を処理した後も不変条件を維持します。`i`、間隔`[L, R]`プレフィックスの有効な非減少シーケンスの最後の要素として機能するすべての値が含まれます。`1..i`。 各ステップでは、このセットと次の要素の有効な範囲の交差部分が計算されます。 どちらの制約も凸間隔であり、単調性は下限を課すだけであるため、到達可能なセットは全体を通して間隔のままです。 間隔が空になると、シーケンスは値の制約と順序の制約の両方を満たすことができなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, l, r = map(int, input().split())
a = list(map(int, input().split()))

L = max(0, a[0] - l)
R = a[0] + r

for i in range(1, n):
    low = max(0, a[i] - l)
    high = a[i] + r

    L = max(L, low)
    R = high

    if L > R:
        print("NO")
        sys.exit()

print("YES")
```実装は間隔メンテナンス ロジックに直接続きます。 唯一の微妙な点は、元の値を負にすることはできないため、下限をゼロにクランプすることです。 もう 1 つの重要な点は、実現可能性を除いて、以前の状態に基づいて上限を決して縮小しないことです。これは、将来の柔軟性のためには、より大きな値が常に望ましいためです。

 ## 特殊なケース

 微妙なエッジケースは次のような場合です`l = r = 0`。 この状況では、配列は固定されており、問題は、指定された配列が既に非減少であるかどうかを確認することになります。 各間隔は 1 つの値に集約され、減少するとすぐにエラーが発生するため、アルゴリズムはこれを自然に処理します。`L > R`。 

もう 1 つのケースは、初期の要素では広い範囲が許容されるが、後の要素では急激な下限が強制される場合です。 たとえば、次のようなシーケンス`10, 0, 0`十分な大きさの`l`そして`r`最初の間隔によって最小値がゼロよりも大きくなる場合、2 番目の位置でも無効になる可能性があります。 間隔伝播は、範囲を交差させて実現可能性を崩壊させることにより、これを即座に検出します。 

最後のケースは、最初の要素がすでに高い値で始まっているが、実行可能な唯一の再構築にはより小さい値が必要な場合です。 このアルゴリズムでは、最初の間隔を可能な限り広くすることが正しく許可されており、単一の値に早まってコミットすることがないため、後の制約が適切に考慮されます。
