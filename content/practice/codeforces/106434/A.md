 ## 解決策
 ## 問題の理解

 ロボットは、0 から L までの整数点のセグメントとして考えることができる 1 次元のコリドー内を移動します。左の壁は位置 0 にあり、右の壁は位置 L にあります。ロボットは位置 X から開始し、最初は左または右のいずれかを向いています。 毎秒、現在向いている方向に正確に 1 ユニット移動します。 壁を越えて移動しようとすると、最初に境界にぶつかり、すぐに方向を反転し、その後、反対方向に移動し続けます。 

タスクは、T 秒後のロボットの位置を決定することです。 

この制約により、L と T は最大 10^9 まで許容され、ステップバイステップのシミュレーションが即座に除外されます。 線形シミュレーションでは、テストごとに最大 10^9 の操作が必要になりますが、これでは遅すぎます。 ソリューションでは、モーションを直接式に圧縮するか、テストごとに O(1) の計算を行う必要があります。 

素朴な推論による一般的な失敗例は、境界での「バウンス」動作を無視し、動きを単純な直線運動として扱うことです。 たとえば、L = 10、X = 3 の場合、T = 4 に対して右に移動すると、単純な計算では 7 が得られますが、これはここではたまたま正しいことになります。 しかし、ロボットが壁に衝突して反射した場合、その動きは単調ではなくなり、一般に線形外挿は失敗します。 

複数の反射が発生すると、別の微妙な障害が発生します。 たとえば、L = 5、X = 2、T = 10 の間右に移動すると、ロボットは繰り返しバウンドします。 最初の衝突だけを考慮したアプローチはすぐに破綻します。 

## アプローチ

 このモーションは基本的に、境界での反射を伴う直線歩行です。 直接シミュレーションでは、各ステップで位置と方向を追跡し、壁での位置と反転方向を更新します。 これは正しいですが、O(T) 時間がかかり、T が大きい場合には実行不可能です。 

重要な観察は、回廊を展開することで反射を除去できるということです。 ロボットが跳ねるのではなく、壁に到達した後、廊下の鏡面コピーに進み続けると想像してください。 これにより、運動が無限線上の単純な直線運動に変換されます。 

より具体的には、[0, L] の位置を長さ 2L の周期構造にマッピングします。 ロボットは壁のない線上にあるかのように移動し、X から開始して方向に応じてステップごとに ±1 移動します。 T ステップ後、その「展開位置」は X + d・T になります。ここで、d は右の場合は +1、左の場合は -1 です。 次に、周期 2L の対称性を使用して、この位置を [0, L] にマッピングし直します。 

p = (X + d・T) mod (2L) の場合、次のようになります。 

p ≤ L の場合、答えは p です。 

p > L の場合、答えは 2L − p です。 

これが機能するのは、一方の壁からもう一方の壁までのすべての完全な横断が長さ L のセグメントに対応し、反射が方向の反転に相当し、これがまさに折りたたみマップがエンコードしているものであるためです。

 | モジュール式反射マッピング | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 方向を速度 d の数値に変換します。右が +1、左が -1 になります。 これにより、ロジックの分岐ではなく、動作が算術演算に変換されます。 
2. T ステップ後の生の位置を p = X + d・T として計算します。 これは、あたかも廊下が無限に伸びているかのような、壁のない動きを表現しています。 
3. モジュロ演算を使用して p を範囲 [0, 2L] に正規化します: p = p mod (2L)。 これにより、反射によって作成された繰り返し構造がキャプチャされます。 
4. モジュロ調整後に p が負の場合、2L を加算してシフトします。 これにより、周期表現の一貫性が保証されます。 
5. 展開された位置を実際の廊下にマッピングします。 p が [0, L] 内にある場合、それはすでに有効な位置に対応しています。 p が (L, 2L] にある場合は、p = 2L − p として反映します。

反射ステップは、ロボットが「仮想ミラー回廊」の中点を通過し、元のセグメントに向かって戻ってくることに正確に対応します。 

### なぜ効果があるのか

 不変条件は、展開線上でのロボットの動作が、同じ長さ L の前方セグメントと鏡像セグメントの間で交互に行われることです。ロボットが境界を横切るたびに、その方向反転は、セグメントの反射コピーへの動作を継続することと同等です。 モジュロ演算により、この無限の展開が長さ 2L の単一周期間隔に圧縮され、最後の反映ステップで元のセグメント内のロボットの正しい画像が選択されます。 すべての壁の相互作用は周期の対称的な半分の間の遷移に正確に対応するため、マッピングで情報が失われることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    L = int(input().strip())
    X = int(input().strip())
    S = input().strip()
    T = int(input().strip())

    d = 1 if S == 'R' else -1

    p = X + d * T

    mod = 2 * L
    p %= mod
    if p < 0:
        p += mod

    if p <= L:
        print(p)
    else:
        print(2 * L - p)

if __name__ == "__main__":
    solve()
```この実装では、展開線モデルを直接適用します。 方向は±1としてエンコードされており、移動が単一の算術式となります。 2L によるモジュロは、無限の反射を有界の周期領域に圧縮する重要なステップです。 

最後の条件は、元のコリドーへの折り返しを処理します。 L のしきい値は重要です。このしきい値は、順方向トラバーサルとミラーされたトラバーサルを区別します。 

微妙な点の 1 つは、モジュロ後の負の値の処理です。 Python のモジュロはすでに正のモジュラスに対して非負の結果を返していますが、調整を維持することで、他の言語への翻訳時にロジックが堅牢になります。

| ステップ | 式 | 値 |

 これは境界を越えていることを示しています。 10 で右の壁に到達した後、ロボットは効果的に反射して左に移動します。これは、13 を 7 に折り返すことで捕捉されます。

 ## 特殊なケース

 1 つのエッジ ケースは、まさに壁から始まり、外側に向かって移動しています。 たとえば、L = 5、X = 5、S = R、T = 1 です。ロボットは展開空間内で 5 から 6 に移動しますが、6 > 5 は 10 − 6 = 4 を意味するため、反射後に 4 にマッピングされます。アルゴリズムはこれを折り畳みルールを通じて自然に処理します。 

別のケースでは、全サイクルが繰り返されます。 L = 4、X = 1、S = R、T = 6 の場合、展開された位置は 7、モジュロ 8 は 7、反射は 1 を与えます。これは、ロボットが 2 回完全に移動した後に元の位置に戻るという事実と一致します。 

3 番目のケースは、T が非常に大きい場合です。計算は 2L を法とする T のみに依存するため、T = 10^9 のような値は、その換算された剰余と同じように動作します。 このアルゴリズムは T の絶対サイズには依存せず、反射によって引き起こされるサイクル内の位置のみに依存します。
