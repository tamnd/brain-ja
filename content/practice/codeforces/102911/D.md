 ## 解決策
 ## 問題の理解

 1 から N までの整数が与えられており、それらを 2 つのグループに分割し、それらをアリスとボブと呼びます。 各整数によって提供される値は正確にその数値であるため、アリスが一連の数値を受け取った場合、彼女の合計スコアはそれらの数値の合計となり、ボブのスコアも同様に定義されます。 目標は、2 つの合計間の絶対差ができるだけ小さくなるように、すべての数値を 1 回だけ分配することです。 また、この最小の差を達成する有効な割り当てを 1 つ出力する必要があります。 

この構造は任意のデータではなく、非常に厳密なセットです。固定の重みが線形に増加する連続した整数です。 この柔軟性により、動的計画法やサブセットサム機構を使用せずに問題を線形時間で解決できるようになります。 

すべての数値の合計は S = N(N+1)/2 です。 これにより、最終的な違いがどのようなものになるかが即座に制限されます。 S が偶数の場合、原理的にはセットを 2 つの等しい半分に分割することが可能であり、答えはゼロになります。 S が奇数の場合、どのパーティションも合計を等しくすることができないため、最良の答えは少なくとも 1 つです。 

素朴な解釈では、これは部分集合和の問題であると思われるかもしれませんが、それは誤解を招きます。 最大 2e5 要素の値に対する古典的なサブセット合計 DP は、合計が約 2×10^10 に増大し、時間とメモリの両方で DP が実行不可能になるため、最大 2×10^5 の制約の下では不可能です。 

ここで重要となるエッジ ケースは、貪欲な直感を手動でテストできる N の小さな値です。 N = 1 の場合、{1} を片側に完全に割り当てて、差分 1 を生成する必要があります。N = 2 の場合、{1} と {2} を別々に割り当てて、差分 1 を生成することもできます。 N = 3 の場合、{3} をアリスに、{1,2} をボブに割り当てると、等しい合計 3 と 3 が生成され、差は 0 になります。プレフィックス分割を交互に実行したり試みたりする不注意な戦略は、バランスが位置ではなく大きさに依存するため、このような小さなケースでは失敗する可能性があります。 

## アプローチ

 ブルートフォースアプローチは、{1, 2, ..., N} のすべてのサブセットを考慮し、その合計を計算し、その合計と S からその合計を引いたものとの差を最小化しようとすることです。 これは正しいですが、すぐに爆発します。2^N 個のサブセットがあるため、N = 30 ですら実行不可能になり、問題の制約はそれをはるかに超えます。 

重要な観察は、任意の重みを自由に選択できるわけではなく、各ステップで常に最大の残りの要素にアクセスできることです。 これは、貪欲な戦略を示唆しています。常に、現在最大の未使用番号を、より小さい現在の合計を持つグループに割り当てます。 直感的には、大きな数値が差を支配するため、不均衡を修正できる可能性があるうちに、まずそれらの数値を使用して不均衡を修正する必要があります。 

これが機能するのは、どの段階でも 2 つの部分和の差が残りの要素の合計によって制限され、残りの最大要素が常に、より小さな要素の組み合わせよりもその差に十分な影響を与えるためです。 これにより、安定したバランス調整プロセスが作成されます。大きな修正は早期に行われ、小さな修正は結果を改善します。

 ## アルゴリズムのチュートリアル

 アリスとボブの現在の合計を常に維持しながら、割り当てを増分的に構築します。 

1. 2 つの合計 SA = 0 と SB = 0、および長さ N の空の代入文字列を初期化します。 
2. N から 1 まで k を繰り返します。 
3. SA と SB を比較します。 SA が SB 以下の場合、k をアリスに割り当て、k を SA に加算します。 それ以外の場合は、k を Bob に割り当て、k を SB に追加します。 
4. 応答文字列の位置 k に割り当てを記録します。 
5. すべての数値を処理した後、|SA − SB| を計算します。 最終的な答えとして。

各ステップは、利用可能な最大値を使用して可能な限り積極的に電流の不均衡を低減するように設計されています。 N から下への順序付けにより、すべての決定がその時点で可能な最大の影響を与えて行われることが保証されます。 

### なぜ効果があるのか

 貪欲な戦略では、k より大きいすべての数値を処理した後、差 |SA − SB| が得られるという特性が維持されます。 残りのセット {1, 2, ..., k} が与えられた場合、 は可能な限り小さくなります。 kを置くときは常に和が小さい方を選択するので、不均衡が必要以上に大きくなることはありません。 残りの数値はすべて厳密に k より小さいため、将来の割り当てによって k に関する間違った決定を元に戻すことはできないため、その時点で k を最適に配置することは常に安全です。 これにより、ステップ k での正確さがステップ k+1 から N までの最適性にのみ依存する帰納的構造が作成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    sa = 0
    sb = 0
    res = [''] * (n + 1)
    
    for k in range(n, 0, -1):
        if sa <= sb:
            sa += k
            res[k] = 'A'
        else:
            sb += k
            res[k] = 'B'
    
    diff = abs(sa - sb)
    print(diff)
    print(''.join(res[1:]))

if __name__ == "__main__":
    solve()
```実装は貪欲な構造を直接反映しています。 配列`res`割り当てをインデックスごとに保存するので、最後に順番に出力できます。 決定条件は`sa <= sb`正確性を維持しながら決定的なタイブレークを保証します。 

微妙な実装のポイントは、プロセスが N から 1 まで純粋に増分であるため、合計を再計算したり、残りの要素を明示的に追跡したりする必要がないことです。もう 1 つの重要な点は、インデックス付けです。サイズ N+1 の配列を使用すると、値 k を位置 k にマッピングする際の off-by-1 エラーが回避されます。 

## 実用的な例

 ### 例 1: N = 3

 SA = 0、SB = 0 から始めます。 

| k | SA | SB | 選ばれた |
 |---|---|---|---|
 | 3 | 0 | 0 | あ |
 | 2 | 3 | 0 | B |
 | 1 | 3 | 2 | B |

 アリスは {3} を取得し、ボブは {2,1} を取得します。 最終的な合計は SA = 3 および SB = 3 であるため、差は 0 です。 

これは、最大の要素を最初に割り当てるとすぐにバランスが固定され、小さな要素のみがバランスを微調整することを示しています。 

### 例 2: N = 5

 | k | SA | SB | 選ばれた |
 |---|---|---|---|
 | 5 | 0 | 0 | あ |
 | 4 | 5 | 0 | B |
 | 3 | 5 | 4 | B |
 | 2 | 5 | 7 | あ |
 | 1 | 7 | 7 | B |

 最終セットはアリス {5,2}、ボブ {4,3,1} です。 両方の和は 7 なので、差は 0 になります。 

このトレースは、利用可能な最大の補正が常に即座に適用されるため、アルゴリズムがどのようにして不均衡を繰り返し補正し、一方の側が大きく前方にドリフトすることを許さないかを示しています。

 ## 特殊なケース

 N = 1 の場合、両方の合計が等しく始まり、最初の分岐がアリス側をトリガーするため、アルゴリズムは単一の値をアリスに割り当てます。 結果は SA = 1、SB = 0 となり、出力 1 が生成されます。これはどのパーティションでも改善できないため最適です。 

N = 2 の場合、プロセスは最初に 2 をアリスに割り当て、次に 1 をボブに割り当てます。 最初のステップの後は SA = 2、SB = 0、2 番目のステップの後は SA = 2、SB = 1 です。最終的な差は 1 であり、代替割り当てを行ってもこれ以上の結果は得られません。 

N = 3 の場合、トレースは、貪欲な割り当てによって正確な等価性が生成されることを示しています。 A、B、A などの単純な交互アプローチでは SA = 4 および SB = 2 が得られますが、これは厳密にはさらに悪く、位置の割り当てではなく現在の合計に基づく貪欲な方法が必要である理由を示しています。
