 ## 解決策
 ## 問題の理解

 私たちには哲学者のリストが与えられ、それぞれの哲学者の「支配力の強さ」を表す正の整数値が関連付けられています。 哲学者は、自分の価値が相手の価値で割り切れる場合、相手を支配すると言われます。つまり、大きい値が小さい値の正確な倍数でなければなりません。 

タスクは、リスト内の他のすべての哲学者を支配する単一の哲学者が存在するかどうかを判断することです。 複数の候補がこの条件を満たす場合、インデックスが最も小さい候補が選択されます。 

入力は、単純に哲学者の数とその値が続くものです。 出力は、有効な「王」の 1 から始まるインデックス、またはそのような哲学者が存在しない場合は -1 です。 

この制約では、最大 10^9 の値と最大 2・10^5 の哲学者が許可されます。 これにより、哲学者のすべてのペアを直接チェックするアプローチは即座に除外されます。これは O(n^2) となり、最悪の場合 4・10^10 の演算に達し、明らかに時間制限を超える可能性があるからです。 

複数の哲学者が同じ価値観を共有する場合、微妙な特殊なケースが現れます。 任意の数はそれ自身を分割するため、同一の値が相互支配を形成し、その値が他のすべての値も支配する場合、それらの中で最も古いインデックスが答えになります。 たとえば、すべての値が 224 の場合、すべての哲学者が他の哲学者を支配するため、答えは 1 になります。 

もう 1 つの特殊なケースは、たとえそれが非常に大きい場合でも、単一の値が他の値を分割しない場合です。 たとえば、配列 [6, 10, 15] では、他の数値を分割する数値がないため、複数の「大きな」値が存在するにもかかわらず、正しい出力は -1 になります。 

## アプローチ

 ブルートフォース手法では、各哲学者を王候補として試し、その値が他のすべての値で割り切れるかどうかを確認します。 各候補 i について、すべての j をスキャンし、Ai % Aj == 0 を検証します。これには、合計で O(n^2) 個の割り算チェックがかかります。 各チェックは定数時間ですが、n が 2・10^5 までの場合、これは実行不可能になります。 

重要な観察は、有効なキングは配列内の最大値でなければならないということです。これは、Ai が他のすべてを支配する場合、Ai はすべての Aj で割り切れる必要があり、すべての j について Ai ≥ Aj を意味するためです。 したがって、候補は最大値のセットから得られる必要があります。 

これにより、検索スペースが大幅に減少します。 すべてのインデックスをチェックするのではなく、最大値を保持するインデックスのみをチェックします。 すべての等しい最大値は優勢性に関して同じように動作するため、テストする必要があるのはそのうちの 1 つだけ、理想的には最初に出現した値だけです。 

次に、この最大値が配列内のすべての要素を分割するかどうかを検証します。 そうであれば、それは正当な王です。 それ以外の場合は候補が存在しません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | お(1) | 遅すぎる |
 | 最大候補チェック | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 私たちは問題を、単一の値が他の値をすべて除算できるかどうかをテストすることに縮小します。 

1. 配列を 1 回スキャンして、最大値とその最初のインデックスを見つけます。 その理由は、有効なキングは少なくとも他のキングと同じ大きさでなければならないため、最大値のみが適格であるためです。 
2. 配列を再度スキャンし、すべての要素が最大値で割り切れるかどうかを確認します。 割り切れない要素が見つかった場合、優勢にはすべての哲学者をカバーする必要があるため、この候補をすぐに拒否できます。 
3. すべてのチェックに合格した場合、最初の最大要素の格納されたインデックスを返します。 
4. いずれかのチェックが失敗した場合は、-1 を返します。 

重要な決定は、注目を最大要素に制限することです。これにより、ペアごとの比較が不要になります。 

### なぜ効果があるのか

値 A_k が他のすべての値を支配する場合、すべての i について、ある整数 m について A_k = m · A_i でなければなりません。これは、すべての i について A_k ≥ A_i を意味します。 これにより、A_k がグローバル最大値になります。 等しい最大値の間では、割り算は同一であるため、最小のインデックスを選択することで、タイブレーク ルールの下での正確性が保証されます。 したがって、アルゴリズムは、可能な唯一の構造候補を直接テストし、必要な分割条件を検証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    mx = max(a)
    idx = -1
    
    for i in range(n):
        if a[i] == mx:
            idx = i + 1
            break
    
    for x in a:
        if mx % x != 0:
            print(-1)
            return
    
    print(idx)

if __name__ == "__main__":
    solve()
```最初のパスでは最大値が計算され、その最初の位置が記録されます。 出力は値だけではなくインデックスに依存するため、これが必要です。 

2 番目のパスでは、候補最大値からすべての要素までの割り切り可能性をチェックすることで、優勢条件を強制します。 条件 mx % x == 0 は、mx がすべての x の倍数であるという要件を直接変換したものです。 

障害時の早期終了により、不必要なチェックが防止され、ソリューションが線形に保たれます。

 ## 特殊なケース

 すべての値が同じ場合、最大値が複数回表示されます。 アルゴリズムは最初に出現したものを選択しますが、すべての数値が割り算されるため、割り算チェックに合格します。 たとえば、[224, 224, 224] は mx = 224 を生成し、2 番目のパスでは失敗しないため、インデックス 1 が返されます。 

最大値が複数回出現しても、他の値が割り切れない場合でも、結果は -1 になります。 たとえば、[10, 10, 3] は mx = 10 ですが、10 % 3 は失敗するため、生き残る候補はありません。 

配列に 1 が含まれている場合、すべての値が 1 でない限り、1 はそれ自体を支配するだけであるため、自動的に答えにはなりません。 たとえば、[1, 2, 3] は、優勢の逆方向では 1 % 2 が有効ではないため失敗します。
