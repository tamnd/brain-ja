 ## 解決策
 ## 問題の理解

 各ノードが小文字でラベル付けされたルート付きツリーが与えられます。 各ノードについて$i$のサブツリー内の任意のノードから開始して形成できるすべての文字列を分析するように求められます。$i$そして適切な子孫に繰り返しジャンプし、パスに沿って文字を連結します。 ノードの最終出力$i$この方法で生成できるすべての個別の文字列のカウントの二乗和です。$998244353$。 

ツリーにはテスト ケースごとに最大 5000 個のノードを含めることができ、すべてのテスト ケースのノードの合計も 5000 に制限されます。これにより、すべての可能なパスを明示的に生成するブルート フォース アプローチが即座に排除されます。$2^{\text{size of subtree}}-1$指数関数的に増加するパス。 エッジ ケースには、すべてのノードが同じ文字を持つツリー、単一の長いチェーンを持つツリー、サイズ 1 のサブツリーが含まれます。 すべての文字列を列挙しようとする不用意なソリューションは、時間とメモリの両方で失敗します。 

## アプローチ

 素朴なアプローチは、サブツリー内のすべての開始ノードを列挙し、すべての適切な子孫を訪問することによってすべてのパスを再帰的に生成することです。 各パスは文字列に変換され、辞書内でカウントされ、二乗カウントが合計されます。 これは非常に小さなツリーには機能しますが、スターまたはチェーンの最悪の場合には、$n \approx 5000$、パスの数は指数関数的です$n$、これは明らかに実行不可能です。 

重要な洞察は、問題がサブツリーからの文字列のカウントを結合することに帰着できるという観察から得られます。 具体的には、どのノードでも$u$、で始まる文字列$u$は単なる文字です$u$または、その文字が子で始まる文字列と連結されたもの。 これは自然に、ツリー上での動的プログラミング アプローチにつながります。 をルートとするサブツリー内のすべての文字列を表すことができます。$u$文字列の頻度マップとして。実際の文字列連結のオーバーヘッドを回避するために、各文字列は文字のタプルまたはハッシュとして表されます。 次に、子マップを親マップにマージし、カウントを適切に更新します。 周波数マップのマージはすべてのパスを列挙することなく段階的に実行できるため、このアプローチは次のように二次関数的に拡張されます。$n$を考慮すると許容範囲です$n \le 5000$。

 ## アルゴリズムのチュートリアル

 1. ツリーを解析し、エッジを隣接リストに保存します。 ルートをノード 1 としてマークします。 
2. 各ノードに対して、周波数マップを初期化します。`dp[u]`そのノードのカウント 1 の 1 文字の文字列が含まれます。これは、で開始および終了するすべてのパスを表します。`u`。 
3. ポストオーダー DFS を使用してツリーを処理します。 各ノードについて`u`、それぞれの子供たちを考慮します`v`。 
4. の各文字列について`dp[v]`の文字を先頭に追加して新しい文字列を作成します。`u`。 この文字列を追加します`dp[u]`そしてそのカウントを次からのカウントだけインクリメントします`dp[v]`。 これにより、次から始まるすべてのパスが結合されます。`v`から始まるパスに`u`。 
5. すべての子を結合した後、`dp[u]`で始まるすべての文字列のカウントが含まれます。`u`。 同じマップを次のサブツリーに使用できます。`u`なぜなら、サブツリーで始まるパスはいずれかで始まるからです。`u`または子であり、マージ ステップによりすべての組み合わせが確実にカウントされます。 
6. 各ノードについて`i`、カウントの二乗を合計します。`dp[i]`答えを得るために。 モジュロを適用する$998244353$。 

機能する理由: DP の不変条件は、ノードの処理後に`u`、`dp[u]`で始まるすべての個別の文字列を正しくカウントします。`u`または子孫にあります。 現在のノードの文字を先頭に追加して子をマージすると、ノードから適切な子孫に移動するという要件が考慮されます。 カウントの二乗和により、要求されたメトリックが正しく計算されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10000)

MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        tree = [[] for _ in range(n)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            tree[u - 1].append(v - 1)
            tree[v - 1].append(u - 1)
        
        ans = [0] * n
        
        def dfs(u, parent):
            # dp[u] maps strings to counts
            dp = {}
            # the single letter at u
            dp[s[u]] = 1
            for v in tree[u]:
                if v == parent:
                    continue
                child_dp = dfs(v, u)
                # merge child strings
                for key, count in child_dp.items():
                    new_key = s[u] + key
                    dp[new_key] = dp.get(new_key, 0) + count
            ans[u] = sum(count * count for count in dp.values()) % MOD
            return dp
        
        dfs(0, -1)
        print(' '.join(str(a) for a in ans))
```DFS は、各ノードのマップを 1 文字の文字列で初期化します。 子どもたちを訪問するとき、私たちは親の文字を先頭に追加して新しい文字列を作成します。 平方和は、すべての子をマージした後に計算されます。 再帰の深さは次の値よりも高く設定されています$n$深い木を扱うため。 キーは一意の文字列のみであるため、辞書を使用すると、メモリ内に指数関数的な数の文字列が作成されることを回避できます。
