 ## 解決策
 ## 問題の理解

 負でない整数の配列と数値が与えられます。$k$。 タスクは、配列から要素を繰り返し削除し、常に長さのウィンドウを選択することです。$k$その MEX が最大であり、そのウィンドウ内の要素を削除します。 正確に実行した後$n-k+1$このような削除を行うと、配列の長さは次のようになります。$k-1$。 私たちの目標は、最終的なアレイの MEX を最大化することです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースには最大で次のものを含めることができます$2 \cdot 10^5$要素とすべての合計$n$テストケース全体の境界は次のとおりです$2 \cdot 10^5$。 各テスト ケースはこれほど大きくなる可能性があるため、どのようなアルゴリズムでも$O(n^2)$複雑さが遅すぎるでしょう。 解決策が必要です$O(n)$テストケースごとに。 

エッジ ケースには、すべての要素がゼロである配列、範囲の中央に欠落している要素がある配列、および次のような配列が含まれます。$k = n$。 たとえば、配列の場合`[0,0,0]`と`k=3`、要素を 1 つ削除すると、残りの配列は次のようになります。`[0,0]`、したがって、MEX は 1 です。単純なスライディング ウィンドウ MEX 計算では、繰り返される削除を効率的に処理できない可能性があります。 

## アプローチ

 ブルートフォースアプローチは文字通りプロセスをシミュレートすることです。 削除ごとに次のようにします。 

1. 長さのウィンドウごとに MEX を計算します。$k$。 
2. 最大 MEX のウィンドウを選択します。 
3. そのウィンドウから 1 つの要素を削除します。 

ウィンドウの MEX を計算する$O(k)$小さな配列では実現可能ですが、$n$は$2 \cdot 10^5$そして$k$に匹敵する$n$、このアプローチには最大で時間がかかります$O(n^2)$が遅すぎます。 

重要な観察は、削除の正確な順序を気にしていないということです。 最終的な MEX は、すべての削除後の配列内の要素のマルチセットによって決定されます。 出演するので$n-k+1$削除された場合、残りの要素は$k-1$削除されても生き残る最小の要素、または戦略的に選択された要素。 この問題を、配列内の各整数の頻度を数えるという問題に変換できます。 任意の整数$x$それ以上に起こること$n-k+1$削除によって時間を完全に削除することはできません。 したがって、達成可能な最大 MEX は最小の非負の整数です。$x$その頻度が以下の場合$n-k+1$。 

これにより、問題は欠失のシミュレーションから単純な計数問題に変換され、次の結果が得られます。$O(n)$テストケースごとのソリューション。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O(n^2) | O(n) | 遅すぎる |
 | 周波数カウント / MEX ロジック | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 周波数配列を初期化する`count`サイズの`n+2`(最大の値をカバーするには`n`）をゼロにします。 この配列には、配列内で各整数が出現する回数が格納されます。 
2. 入力配列を反復処理して増分します。`count[a[i]]`要素ごとに`a[i]`。 このステップにより、各数字が何回出現するかを知る準備が整います。 
3. コンピューティング`deletions = n - k + 1`、削除される要素の数。 
4.初期化`mex = 0`。 0 から上に向かって繰り返します。 各整数について`mex_candidate`、配列内の頻度が次より大きいかどうかを確認します。`deletions`。 残っている場合、完全に削除することはできませんので、増加させてください。`mex`そして続けます。 その頻度が以下の場合`deletions`、この番号は完全に削除できるため、現在の`mex`が答えです。 
5. 最終出力`mex`。 

効果がある理由: 後$n-k+1$削除のみ$k-1$要素は残ります。 以上の数値が出現する場合、$n-k+1$回は、少なくとも 1 回の削除が生き残ることが保証されています。 存続することが保証できない最小の非負の整数は、残りの配列の正確な MEX です。 この洞察により、シミュレーションの必要がなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        count = [0] * (n + 2)
        for x in a:
            count[x] += 1
        deletions = n - k + 1
        mex = 0
        while count[mex] > deletions:
            mex += 1
        print(mex)

if __name__ == "__main__":
    solve()
```このソリューションは、まずすべての入力を読み取り、出現回数をカウントし、次に頻度を比較することによって MEX を決定します。`deletions`。 使用する`n+2`で`count`いつでも確認できるようにします`mex`まで`n+1`インデックスエラーなし。 Off-by-one エラーはインクリメントすることで回避されます。`mex`カウントが削除数を超えた場合のみ。
