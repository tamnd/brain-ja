 ## 解決策
 ## 問題の理解

 各テスト ケースでは、最低ピッチから最高ピッチまですでに順序付けられている 3 つの音符が記述されています。 音符は異なるオクターブに属している可能性がありますが、入力により、最初の音符から 2 番目の音符まで、および 2 番目の音符から 3 番目の音符までの距離が最大 11 半音であることが保証されます。 私たちの仕事は、これら 3 つの音がメジャー トライアドを形成するのか、マイナー トライアドを形成するのか、あるいはどちらでもないのかを判断することです。 

重要な情報は、連続する音符間の半音の数だけです。 メジャー トライアドには 4 半音の間隔があり、その後に 3 半音が続きます。 マイナー トライアドには 3 半音の間隔があり、その後に 4 半音が続きます。 他の間隔のペアは次のように報告する必要があります。`Dissonance`。 

テストケースの数は最大でも 2000 件と非常に少ないです。 各テスト ケースには 3 つのノートしか含まれていないため、ケースごとの定数処理でも十分です。 この解決策に必要なのは、音名からオクターブ内の位置へのマッピングと、いくつかの算術演算だけです。 

最初の微妙なケースは、ノートがオクターブ境界を越える場合です。 例えば、```
A C E
```正しい出力は次のとおりです```
Minor triad
```メモ`C`よりもインデックスが小さい`A`1 オクターブ内ですが、実際には次のオクターブにあります。 単純にオクターブ インデックスを減算すると、負の値が生成されます。 次の音符のインデックスが小さい場合、間隔の計算では常に 12 を加算する必要があります。 

もう 1 つの簡単な間違いは、音の増加シーケンスがすべてコードとして分類できると仮定することです。 例えば、```
C F A
```音程は 5 半音と 4 半音で、どちらのコード定義にも一致しません。 正しい出力は次のとおりです```
Dissonance
```最後のエッジケースは、入力が音名に関して音楽的に下降しているにもかかわらず、オクターブのためにピッチが上昇している場合です。```
E D C
```正しい出力は次のとおりです```
Dissonance
```それでも`D`そして`C`半音階の早いほうに現れるほど、より高いオクターブに属します。 オクターブ ラッピングを無視するソリューションでは、不正確な負の距離が計算されます。 

## アプローチ

 簡単なアプローチは、音楽の定義を直接シミュレートすることです。 すべての音符をオクターブ内の位置に変換し、連続する音符間の半音の距離を計算し、必要に応じてオクターブの折り返しを調整して、2 つの距離を 2 つの有効なパターンと比較します。 

また、考えられるすべてのメジャー トライアドとマイナー トライアドを生成し、入力がそれらのいずれかに一致するかどうかをチェックすることも考えられます。 考えられるルートは 12 個、コード タイプは 2 つだけなので、それでも必要なパターンは 24 個だけで、十分に高速です。 それは正しいのですが、不必要な前処理と比較が発生します。 

問題の定義がすでに連続する半音の距離で表現されているため、直接間隔の計算はより簡単です。 各音符が 0 ～ 11 の整数にマッピングされると、各テスト ケースは 2 つの間隔計算と 2 つの比較に減ります。

 | --- | --- | --- | --- |
 | ブルートフォース | テスト ケースごとに O(24) | お(24) | 受け入れられますが、不要です |

 ## アルゴリズムのチュートリアル

 1. 各音名から半音スケール内の位置へのマッピングを作成します。 
2. 3 つのメモを読み、数値の位置に変換します。 
3. 最初の音から 2 番目の音までの間隔を計算します。 2 番目の位置が小さい場合は、減算する前に 12 を加算して、間隔が次のオクターブに上向きに移動することを表します。 
4. まったく同じ方法で 2 番目の間隔を計算します。 
5. 2 つの間隔が次の場合`(4, 3)`、印刷`Major triad`。 
6. それ以外の場合、間隔が`(3, 4)`、印刷`Minor triad`。 
7. それ以外の場合は、印刷します`Dissonance`。 

### なぜ効果があるのか

 入力により、ノートが低いピッチから高いピッチの順にすでに順序付けられていることが保証されます。 唯一の問題は、上に移動するとオクターブ境界を越える可能性があることです。 数値の音価が減少するたびに 12 を加算すると、実際の上向きの半音の距離が再構築されます。 これら 2 つの距離が計算された後、コードのタイプは問題の定義によって完全に決定されます。 考えられるすべての入力が連続する音程のペアを正確に 1 つ生成するため、アルゴリズムは常にコードを正しく分類します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

pos = {
    "C": 0,
    "C#": 1,
    "D": 2,
    "D#": 3,
    "E": 4,
    "F": 5,
    "F#": 6,
    "G": 7,
    "G#": 8,
    "A": 9,
    "A#": 10,
    "B": 11,
}

def interval(a, b):
    if b < a:
        b += 12
    return b - a

t = int(input())

for _ in range(t):
    n1, n2, n3 = input().split()

    x = pos[n1]
    y = pos[n2]
    z = pos[n3]

    d1 = interval(x, y)
    d2 = interval(y, z)

    if d1 == 4 and d2 == 3:
        print("Major triad")
    elif d1 == 3 and d2 == 4:
        print("Minor triad")
    else:
        print("Dissonance")
```辞書には、半音スケールが 0 ～ 11 の整数として保存されます。これにより、間隔の計算が文字列処理ではなく単純な整数の減算になります。 

ヘルパー関数は、実装の唯一の難しい部分を処理します。 2 番目の音符の数値が小さい場合、その音は次のオクターブに属するため、12 を加算すると正しい上方への距離が再構築されます。 このステートメントでは各間隔が最大 11 半音であることが保証されているため、この調整で常に十分です。 

各テスト ケースは 2 つの間隔を計算し、それらを 2 つのみの有効なパターンと比較します。 半音スケールは連続した整数で表され、すべての間隔はオクターブ調整後の位置間の差として直接測定されるため、1 つずつずれることはありません。

## テストケース```python
import sys
import io

def solve():
    import sys
    input = sys.stdin.readline

    pos = {
        "C": 0,
        "C#": 1,
        "D": 2,
        "D#": 3,
        "E": 4,
        "F": 5,
        "F#": 6,
        "G": 7,
        "G#": 8,
        "A": 9,
        "A#": 10,
        "B": 11,
    }

    def interval(a, b):
        if b < a:
            b += 12
        return b - a

    t = int(input())
    out = []

    for _ in range(t):
        a, b, c = input().split()
        d1 = interval(pos[a], pos[b])
        d2 = interval(pos[b], pos[c])

        if d1 == 4 and d2 == 3:
            out.append("Major triad")
        elif d1 == 3 and d2 == 4:
            out.append("Minor triad")
        else:
            out.append("Dissonance")

    print("\n".join(out))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()
    solve()
    ans = sys.stdout.getvalue()
    sys.stdin = backup_stdin
    sys.stdout = backup_stdout
    return ans

assert run(

C E G
A C E
B D F#
C F A
E D C
"""
) == (
"""Major triad
Minor triad
Minor triad
Dissonance
Dissonance
"""
)

assert run(
"""1
C E G
"""
) == (
"""Major triad
"""
)

assert run(
"""1
A C E
"""
) == (
"""Minor triad
"""
)

assert run(

C F A
"""
) == (

"""
)

assert run(

"""
) == (

"""
