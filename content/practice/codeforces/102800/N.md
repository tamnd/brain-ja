 ## 解決策
 # 問題の理解

 無向加重都市グラフがあります。 ボブはいつも構築から始める`1`そして建物に到達したいと思っています`n`。 各クエリでは 1 つの道路が一時的に削除され、その道路が使用できなくなった後は、可能な限り最短のルートを見つける必要があります。 

入力はグラフのエッジを記述し、多くの独立した「このエッジを削除する」クエリを要求します。 各クエリの出力は、`1`に`n`選択したエッジを使用せずに、または`-1`目的地に到達できなくなった場合。 

限界が主な課題です。 まで`10^5`建物、`2 * 10^5`街路と`2 * 10^5`クエリの場合、すべてのクエリに対して最短パス アルゴリズムを実行するには、大まかに次のものが必要になります。`q * (m log n)`オペレーション、それは周りにあります`2 * 10^5 * 2 * 10^5`、可能性をはるかに超えています。 グラフを 1 回前処理して、各クエリにほぼ即座に答える必要があります。 

いくつかの詳細が単純な解決策を壊す可能性があります。 グラフには平行な道路が含まれる場合があるため、1 つのエッジを削除しても 2 つの建物間の接続がすべて削除されるとは限りません。 

例えば：```
3 3 1
1 2 5
1 2 1
2 3 1
1
```答えは次のとおりです。```
2
```最初のストリートを削除しても、間にある 2 番目のストリートが削除されるため、重要な意味はありません。`1`そして`2`まだ利用可能です。 エンドポイントのペアのみを保存するソリューションでは、両方が誤って削除されてしまいます。 

もう 1 つの注意が必要なケースは、複数の最短パスが存在する場合です。```
4 4 1
1 2 1
2 4 1
1 3 1
3 4 1
2
```答えは次のとおりです。```
2
```削除されたエッジは 1 つの最短パスに属しますが、もう 1 つの最短パスは残ります。 選択された 1 つの最短パス上のすべてのエッジが重要であると仮定する方法は失敗します。 

最後に、エッジを削除するとグラフが切断される場合があります。```
2 1 1
1 2 7
1
```答えは次のとおりです。```
-1
```アルゴリズムは、到達不可能な状態を明示的に処理する必要があります。 

## アプローチ

 直接的な解決策は、各クエリを個別に処理することです。 削除されたエッジについては、一時的に削除し、構築からダイクストラを実行します。`1`建物へ`n`。 ダイクストラは残りのグラフで最短経路を与えるので、これは正しいです。 ただし、最悪の場合、これは実行されます`q`ディクストラは実行され、コストは約`O(q * m log n)`。 所定の制限を考慮すると、これは数桁遅すぎます。 

重要な点は、エッジごとにまったく異なる最短経路問題を解く必要がないということです。 考慮する必要があるのは、選択された 1 つの最短パスに実際に影響を与える可能性があるエッジだけです。`1`に`n`。 

First, run Dijkstra from`1`and build a shortest path tree. からのパス`1`に`n`このツリー内が参照パスとして選択されます。 参照パスは削除後もまだ存在するため、このパス上にないエッジは答えに影響を与えることはできません。 

参照パス上のすべてのエッジに対して、それを迂回する最適な迂回が必要です。 ツリーの 1 つのエッジを削除すると、ツリーが 2 つの部分に分割されます。 有効な置換パスは、別のエッジを使用してこの分離を横切る必要があります。 非ツリー エッジは 2 つのツリー領域を接続するため、すべての非ツリー エッジで連続する範囲のパス エッジを置き換えることができます。 その範囲の最適な候補を計算し、範囲最小更新を使用してそれを適用できます。 

2回目のダイクストラのラン`n`置換エッジの反対側に入った後に必要な距離を示します。 ツリー構造により、非ツリー エッジがバイパスできるパス エッジを決定できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |`O(q * m log n)`|`O(n + m)`| 遅すぎる |
 | 最適 |`O((n + m) log n)`|`O(n + m)`| 承認済み |

 ## アルゴリズムのチュートリアル

 1. ノードからダイクストラを実行します。`1`。 最短距離とすべてのノードの親を最短パス ツリーに保存します。 

親ポインタを使用すると、次のルートから 1 つの最短ルートを回復できます。`1`に`n`。 
2. ツリーパスを復元します。`1`に`n`。 これらは、削除することで答えが変わる唯一のエッジです。 

道路がこのパス上にない場合でも、元の最短パスを使用できます。 
3. ノードからダイクストラを実行する`n`すべてのノードから目的地までの距離を計算します。 

これらの値を使用すると、削除されたエッジの目的地側に入る迂回路を評価できます。 
4. 最短パス ツリーをたどって、すべてのノードをそのパス ツリーの最も深いノードに割り当てます。`1 -> n`その祖先であるパス。 

これにより、メイン パスのどのセクションに各サブツリーが含まれているかがわかります。 
5. 選択したパスの一部ではないすべてのエッジについて、どのパス エッジをバイパスできるかを決定します。 

2 つのエンドポイントがパス位置に属している場合`a`そして`b`の場合、このエッジはそれらの位置間のすべてのパス エッジを置き換えることができます。 候補コストは、1 つのエンドポイントまでの距離、エッジの重み、およびもう 1 つのエンドポイントからエッジまでの距離です。`n`。 
6. すべての非パス エッジに範囲最小更新を適用します。 

遅延セグメント ツリーは、すべてのパス エッジに最適な置換値を保存します。 
7. 削除されたエッジが選択したパス上にある場合、クエリごとに、保存されている置換値を返します。 それ以外の場合は、元の最短距離を返します。 

なぜ効果があるのか:

 選択した最短パス上の木の端を削除することを検討してください。 削除されたエッジは、最短パス ツリー内の開始点から目的地を分離します。 残りのルートは、別のエッジを通ってこの分離を通過する必要があります。 このようなすべての交差エッジは範囲の更新中に考慮され、保存される値はすべての交差の中で可能な最小コストとなります。 エッジが選択したパス上にない場合、そのパスは変更されず、最適なままになります。 

## Python ソリューション```python
import sys
import heapq

input = sys.stdin.readline

INF = 10**30

class SegTree:
    def __init__(self, n):
        self.n = n
        self.lazy = [INF] * (4 * n)

    def update(self, node, l, r, ql, qr, val):
        if qr < l or r < ql:
            return
        if ql <= l and r <= qr:
            if val < self.lazy[node]:
                self.lazy[node] = val
            return
        mid = (l + r) // 2
        self.update(node * 2, l, mid, ql, qr, val)
        self.update(node * 2 + 1, mid + 1, r, ql, qr, val)

    def query(self, node, l, r, idx, carry=INF):
        carry = min(carry, self.lazy[node])
        if l == r:
            return carry
        mid = (l + r) // 2
        if idx <= mid:
            return self.query(node * 2, l, mid, idx, carry)
        return self.query(node * 2 + 1, mid + 1, r, idx, carry)

def dijkstra(start, g):
    n = len(g) - 1
    dist = [INF] * (n + 1)
    parent = [-1] * (n + 1)
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d != dist[u]:
            continue
        for v, w, idx in g[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                parent[v] = (u, idx)
                heapq.heappush(pq, (nd, v))
    return dist, parent

def solve():
    n, m, q = map(int, input().split())
    g = [[] for _ in range(n + 1)]
    edges = []
    for i in range(1, m + 1):
        u, v, w = map(int, input().split())
        edges.append((u, v, w))
        g[u].append((v, w, i))
        g[v].append((u, w, i))

    dist1, parent = dijkstra(1, g)
    distn, _ = dijkstra(n, g)

    on_path = [False] * (m + 1)
    path_edge_pos = [-1] * (m + 1)
    path_nodes = []

    cur = n
    while cur != -1:
        path_nodes.append(cur)
        if cur == 1:
            break
        p, e = parent[cur]
        on_path[e] = True
        cur = p

    path_nodes.reverse()
    k = len(path_nodes) - 1

    pos_node = [-1] * (n + 1)
    for i, x in enumerate(path_nodes):
        pos_node[x] = i

    for i in range(k):
        p, e = parent[path_nodes[i + 1]]
        path_edge_pos[e] = i

    children = [[] for _ in range(n + 1)]
    for v in range(2, n + 1):
        if parent[v][0] != -1:
            children[parent[v][0]].append(v)

    belong = [-1] * (n + 1)

    def dfs(u, cur_pos):
        if pos_node[u] != -1:
            cur_pos = pos_node[u]
        belong[u] = cur_pos
        for v in children[u]:
            dfs(v, cur_pos)

    dfs(1, 0)

    seg = SegTree(max(1, k))

    for idx, (u, v, w) in enumerate(edges, 1):
        if on_path[idx]:
            continue
        a = belong[u]
        b = belong[v]
        if a == b:
            continue
        if a > b:
            a, b = b, a
            u, v = v, u
        val = dist1[u] + w + distn[v]
        if k > 0:
            seg.update(1, 0, k - 1, a, b - 1, val)

    ans = []
    for _ in range(q):
        e = int(input())
        if not on_path[e]:
            ans.append(str(dist1[n]))
        else:
            p = path_edge_pos[e]
            res = seg.query(1, 0, k - 1, p)
            ans.append(str(res if res < INF else -1))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```最初のダイクストラ実行により、元の最短距離と最短パス ツリーの両方が得られます。 親配列は、への 1 つの特定の最短パスを識別するために使用されます。`n`; このため、それらのエッジのみに置換値が必要になります。 

置換エッジはルートの中央のみを記述するため、2 回目のダイクストラ実行が必要です。 迂回路が入る側からゴールする最も安価な方法がまだ必要です。 

セグメント ツリーは最小値を遅延的に保存します。 非パス エッジは多くのパス エッジをカバーする可能性があるため、それらを 1 つずつ更新すると時間がかかりすぎます。 範囲更新により、この作業が対数時間に短縮されます。 

パスエッジのインデックス付けはゼロから始まり、正確に`k`エントリ、ここで`k`は、選択したパス上のエッジの数です。 非パス エッジに対するクエリは、元の最短距離を即座に返し、無効なセグメント ツリー アクセスを回避します。 

Python の整数はオーバーフローしないため、可能な最大パス長が 32 ビット制限を超える可能性があるため、これは便利です。
