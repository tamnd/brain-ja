 ## 解決策
 ## 問題の理解

 移動が 4 方向に制限されているグリッドで作業しているため、2 点間の距離はマンハッタン距離を使用して測定されます。 学校は 1 つの座標に固定されており、各生徒は同じ無限グリッド上の別の座標に住んでいます。 各生徒はマンハッタンの最短の道に沿って学校から自宅まで歩きます。つまり、軸に沿ったステップでのみ移動し、決して迂回することはありません。 

学校を除く任意の整数グリッド点に単一のキオスクを配置することができます。 学校からその生徒の家までの少なくとも 1 つの最短経路がキオスクの場所を通過する場合、その生徒は購入者とみなされます。 マンハッタンの幾何学形状では複数の最短経路が存在する可能性があるため、1 人の生徒が複数の有効な経路を持つ可能性がありますが、そのうちの 1 つだけがキオスクと交差する必要があります。 

タスクは、できるだけ多くの生徒の最短経路上にあるようにキオスクの場所を選択し、その最大数と ​​1 つの有効な最適な位置の両方を報告することです。 

制約は大きく、学生数は最大 200,000 人、座標は最大 10^9 です。 これにより、すべてのグリッド ポイントにわたる候補者ごとのシミュレーションや生徒ごとのパス列挙が直ちに除外されます。 二次関数や「生徒のすべてのペアを試して何かを計算する」ことさえも失敗します。 

重要な微妙な点は、マンハッタンの最短経路は一意ではないということです。 (x, y) の生徒の場合、最初に x 座標を調整してから y 座標を調整するパス、またはその逆のパス、または単調な進行を維持しながらそれらを混合するパスは有効です。 この柔軟性により、複数の最適なキオスクの配置が可能になります。 

素朴な直感を打ち破るようなエッジケースは、通常、パスの多重性を無視することから発生します。 たとえば、学校、キオスク、および学生がマンハッタンの意味で同一線上にある場合、単純な実装ではパスが 1 つだけ存在すると想定し、有効な包含を見逃してしまう可能性があります。 

もう 1 つの特殊なケースは、多くの学生が同じ家のコーディネートを共有している場合です。 これによって寄与ロジックは変わりませんが、カウントが増加するため、同一のポイントをグループ化することが重要になります。 

## アプローチ

 強引なアイデアは、各グリッド ポイントを候補キオスクの場所とみなして、各生徒について、この点を通過する学校からその生徒までの最短経路が存在するかどうかを確認することです。 固定スチューデントの場合、点が最短経路上にあるかどうかは、マンハッタン距離が加法的に分解するかどうかを確認することで確認できます。経路は次の場合にのみ P を通過します。 

dist(s, P) + dist(P, 学生) = dist(s, 学生)。 

このチェックは学生ごとに一定時間行われるため、1 人の候補者の評価には O(n) かかります。 ただし、グリッドは巨大で、最大 10^9 × 10^9 の位置が可能です。 自然な単純化である候補者を学生の所在地に制限しても、依然として最大 200,000 人の候補者が残り、最悪のケースでは O(n^2) の動作が生成され、これでは遅すぎます。 

構造的な洞察は、上記の条件が任意の幾何学には依存せず、学校との相対的な座標の比較にのみ依存するということです。 等式を拡張すると、単調な意味で x 方向と y 方向の両方でキオスクが学校と生徒の間にある場合、生徒が貢献していることがわかります。 より正確には、キオスクは学校と生徒によって形成される軸に沿った長方形の内側に配置され、一貫した進行方向に沿って配置されなければなりません。 

これにより、問題は方向性の計数の問題に帰着します。 各生徒は学校に固定された長方形を誘導します。そして、できるだけ多くのそのような長方形で覆われた点が必要です。 平面をスキャンする代わりに、最適な点は 4 つの基本方向のいずれかで学校に隣接している必要があることがわかります。これは、象限内で候補者を移動してもカバー範囲が減少することはなく、満足した生徒を失うことなく常に学校の隣の境界線に向かって押し進めることができるためです。

したがって、4 つの候補位置 (学校から右、左、上、または下に 1 歩ずつ) をテストするだけで済み、x または y 座標が学校に対して正しい側にある生徒の数が最大になる方向を選択するだけです。 

これにより、問題はすべての生徒に渡される単純な数え方に変わります。

 ## アルゴリズムのチュートリアル

 私たちは、決定を学校の周りの 4 つの正規の候補点に減らします。つまり、各基本方向に 1 つのユニットを移動します。 方向ごとに、その隣接するセルを最短経路で通過できる学生の数を数えます。 

1. 学校から 4 つの方向を考えます: 右 (x の増加)、左 (x の減少)、上 (y の増加)、下 (y の減少)。 各方向は、学校に隣接する候補セルの選択に対応します。 この制限が機能するのは、最適なソリューションがこれらの境界に隣接する位置のいずれかに達するまで、すでにサービスを提供している生徒に対する有効性を失うことなく学校に向けて移動できるためです。 
2. 生徒ごとに、学校から生徒までの最短経路が最初のステップを通過できる方向を決定します。 これは純粋に座標の比較によって決定されます。 生徒が学校の右側にいる場合 (x_i > s_x)、学校から右に移動することが、その生徒への最短経路の第一歩となる可能性があります。 同様に、x_i < s_x の場合、左が有効です。 同じロジックが y に対して独立して適用されます。 
3. 学校から各方向に到達できる生徒の数に応じて 4 つのカウンターを維持します。 各生徒について、生徒が異なる相対象限に位置するかどうかに応じて、正確に 1 つまたは 2 つのカウンターを増分します。 
4. カウンタが最大になる方向を選択します。 複数の方向が結合する場合は、どれでも受け入れられます。 
5. 選択したカウントと、対応する隣接座標を出力します。 

重要な考え方は、マンハッタンの最短パスは x と y で独立して単調であるため、学校からの最初の移動によって、どの生徒のセットがそのセルを最短パスに含めることができるかが決まるということです。 

### なぜ効果があるのか

 どの生徒にとっても、学校から生徒までの最短経路は、最初に各軸に沿って向かうか離れるかのいずれかに移動し、後で方向を反転する必要はありません。 したがって、キオスクが生徒の相対的な位置と一致する方向に学校のすぐ隣に配置されていれば、その最初のステップを通過する最短経路をいつでも構築できます。 同じ方向に離れた点があったとしても、より近い点に到達できたはずの一部の生徒が除外されるため、カバレッジは向上しません。 これにより、最適なソリューションを境界に隣接する 4 つの位置のテストに簡略化できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, sx, sy = map(int, input().split())

right = left = up = down = 0

for _ in range(n):
    x, y = map(int, input().split())
    
    if x > sx:
        right += 1
    if x < sx:
        left += 1
    if y > sy:
        up += 1
    if y < sy:
        down += 1

best = max(right, left, up, down)

if best == right:
    print(best)
    print(sx + 1, sy)
elif best == left:
    print(best)
    print(sx - 1, sy)
elif best == up:
    print(best)
    print(sx, sy + 1)
else:
    print(best)
    print(sx, sy - 1)
```このソリューションは各生徒を 1 回スキャンし、x 軸と y 軸に沿って学校に関連して生徒を分類します。 各分類は方向カウントに直接寄与します。 最後の選択では、最適な方向が選択され、有効な隣接座標が出力されます。 マンハッタンの最適パスは軸に沿って独立して分解されるため、パスの幾何学的再構成は必要ありません。 

微妙な実装の詳細は、学生が水平カウンターと垂直カウンターの両方に独立して貢献することです。 これは意図的なもので、最短パスは軸優先移動または Y 軸優先移動のいずれかを通過するように構成できるため、両方の次元で有効なパスの選択肢が提供されます。 

学校が座標 0 または 10^9 にある場合、境界処理が重要になります。 この問題では、選択したポイントが境界内に留まることを保証しており、少なくとも 1 つの方向が常に有効であるため (境界ではない限り、境界では反対方向が有効です)、隣接ロジックは安全なままです。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n, sx, sy = map(int, input().split())

    right = left = up = down = 0

    for _ in range(n):
        x, y = map(int, input().split())
        if x > sx:
            right += 1
        if x < sx:
            left += 1
        if y > sy:
            up += 1
        if y < sy:
            down += 1

    best = max(right, left, up, down)

    if best == right:
        return f"{best}\n{sx+1} {sy}\n"
    if best == left:
        return f"{best}\n{sx-1} {sy}\n"
    if best == up:
        return f"{best}\n{sx} {sy+1}\n"
    return f"{best}\n{sx} {sy-1}\n"

# provided sample
assert run("""4 3 2
1 3
4 2
5 1
4 1
""") == "3\n4 2\n"

# all same direction
assert run("""3 0 0
1 1
2 2
3 3
""") == "3\n1 0\n"

# symmetric case
assert run("""4 0 0
1 0
-1 0
0 1
0 -1
""".replace("-", "0"))  # placeholder adjustment

# minimal
assert run("""1 5 5
6 5
""") == "1\n6 5\n"

# vertical only
assert run("""2 10 10
10 11
10 12
""") == "2\n10 11\n"

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべての生徒が学校の片側にちょうど横たわっている場合です。 たとえば、すべての生徒が x > s_x を満たす場合、アルゴリズムは常に正しい方向を選択し、キオスクを (s_x + 1, s_y) に配置します。 すべての最適なパスは右に移動することから始まるため、どの生徒もこのセルを通過する最短パスを持っています。 

もう 1 つの特殊なケースは、生徒が 4 方向すべてに均等に分散されている場合です。 その場合、複数の方向が結びつきます。 この問題では任意のタイブレークが許可されるため、アルゴリズムは任意の最大値を選択しますが、これは有効です。 

最後の微妙なケースは、多くの生徒が一方の軸では等しい座標を共有しているが、もう一方の軸では座標を共有していない場合です。 たとえば、すべて x = s_x ですが、y は異なります。 水平方向のカウンターはゼロのままであり、解決策は完全に垂直方向の分布に依存します。 アルゴリズムは軸の比較を明確に分離し、両方の軸が同時に寄与する必要があると想定していないため、これを自然に処理します。
