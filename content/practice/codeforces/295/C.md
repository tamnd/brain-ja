 ## 解決策
 ## 問題の理解

 すべての人の体重は 50 kg か 100 kg です。 ボートは左岸からスタートし、総重量がボート制限を超えない空でないグループを運ぶことができます。 ボート内の誰かが操縦する必要があるため、すべての横断には少なくとも 1 人の乗客が含まれます。 

全員を左岸から右岸まで輸送しなければなりません。 すべての有効な輸送計画の中で、2 つの値が必要です。 

最初の値はボートの最小乗車回数です。 

2 番目の値は、その最小値を達成する個別の輸送計画の数です。 少なくとも 1 つの乗り物に異なる人々が含まれている場合、2 つのプランは異なります。 

重要な観察は、人間には可能な体重が 2 つしかないということです。 最小乗車数を検索する際に、各人の身元を個別に記憶する必要はありません。 左岸に50kgの人が何人、100kgの人が何人残っているかを知るだけで十分です。 

人の数は最大 50 人です。正確なサブセットを保存する状態には、最大 50 人が必要です。$2^{50}$可能性はありますが、それは完全に不可能です。 一方、残りの体重 50 kg と 100 kg の人の数はそれぞれ 0 ～ 50 の範囲にあり、約$51 \times 51$可能性。 ボートの位置を追加しても、残る州はまだ 6000 未満です。 

微妙な点は、最短経路検索ではアイデンティティを完全に無視できないことです。 体重が異なる 50 kg の人が 3 人いて、そのうちの 1 人を移動させるとします。 人 A を選択した場合と人 B を選択した場合は同じカウント状態になりますが、異なる輸送計画を表します。 各遷移を生成する具体的な選択肢の数を数えながら、カウント状態を検索する必要があります。 

いくつかの特殊なケースは、誤って処理されやすいものです。

## アプローチ

 ブルートフォースソリューションでは、すべての人を別個のものとして扱い、考えられるすべてのボートの積み荷を検索します。 たった 50 人でも、乗客のサブセットの数は$2^{50}$そして、すべての州がさらに多くの州に分岐することになります。 探索空間はすぐに爆発します。 

ブルートフォースが魅力的に見える理由は、個別の計画の定義が個人のアイデンティティに依存しているためです。 残念ながら、州内でアイデンティティを維持するにはコストがかかりすぎます。 

ウェイトの構造がすべてを変えます。 すべての重みは 50 または 100 であるため、状態は 3 つの値によって完全に決定されます。 

- 左岸には体重50kgの人が何人残っているか、
 - 左岸には100kgの人が何人残っているか、
 - 現在ボートが入っているバンク。 

状態空間は小さくなります。$$51 \times 51 \times 2 \approx 5200.$$残りの課題は、個別の計画をカウントすることです。 同じカウント状態のペア間の 2 つの遷移は、実際の人々のさまざまな選択に対応する可能性があります。 

仮定する$x$現在、左岸には体重50キロの人々がいます。$p$彼らの向こう側。 その人たちを選ぶ方法は無数にあります$$\binom{x}{p}.$$同様に選択すると、$q$体重100キロの人が貢献する$$\binom{y}{q}.$$その遷移の多重度の合計は、2 つの二項係数の積です。 

ボートに乗るたびにちょうど 1 回の横断費用がかかるため、州グラフは重み付けされていません。 このグラフを作成すると、最小乗車回数が最短経路の問題になります。 すべてのエッジのコストが等しいため、BFS によって最短距離が得られます。 BFS の実行中、各エッジに関連付けられた組み合わせ数を乗算して、最短パスの数も維持します。 

これにより、両方の答えが同時に得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^n)$州かそれより悪い | 指数 | 遅すぎる |
 | 最適 |$O(S \cdot T)$|$O(S)$| 承認済み |

 ここ$S \approx 5200$は状態の数であり、$T$は実現可能なボート積載パターンの数です。 

## アルゴリズムのチュートリアル

 1. 体重50kgの人の数を数え、それを呼び出します$A$、そして100kgの人の数、それを呼び出します$B$。 
2. すべての体重を 50 で割ります。50 kg の人は体重 1、100 kg の人は体重 2 になり、ボートの定員は$M = k / 50$。 
3. すべてのペアを事前計算する$(p,q)$そのような$p+2q \le M$そして$p+q > 0$。 各ペアは、1 つの交差点で考えられる乗客の構成を表します。 
4. すべての二項係数を事前計算する$\binom{n}{r}$のために$0 \le n,r \le 50$モジュロ$10^9+7$。 
5. 状態を利用する$(x,y,s)$、 どこ：

-$x$左岸にまだいる体重50kgの人の数、
 -$y$左岸にまだいる体重100kgの人の数、
 -$s=0$ボートが左岸にあることを意味します。 
-$s=1$船が右岸にあることを意味します。 
6.BFSを開始します$(A,B,0)$。 この状態の距離は 0、最短経路の数は 1 です。 
7. ボートが左岸にある場合は、可能なすべてのペアを試してください。$(p,q)$と$p \le x$そして$q \le y$。 それらの乗客を右岸に移動させて州に到達してください$(x-p,y-q,1)$。 
8. その遷移の多重度は次のとおりです。$$\binom{x}{p}\binom{y}{q}.$$1. ボートが右岸にある場合、右岸には現在$A-x$体重５０キロの人たちと$B-y$体重百キロの人。 可能なすべての戻り荷重を試してください$(p,q)$満足のいく$$p \le A-x,\qquad q \le B-y.$$新しい状態は$(x+p,y+q,0)$。 

1. この戻り遷移の多重度は次のとおりです。$$\binom{A-x}{p}\binom{B-y}{q}.$$1. 通常の BFS 緩和を実行します。 状態が初めて検出された場合は、その距離を記録し、最短パスのカウントを初期化します。 別の最短パスが同じ状態に到達する場合、その寄与モジュロを加算します。$10^9+7$。 
2. 目標の状態は次のとおりです。$(0,0,1)$、つまり全員が右岸にいて、最後の横断はすでに行われているということです。 

### なぜ効果があるのか

 州には、将来のすべての法的措置を決定するために必要な情報が正確に含まれています。 残りの 50 kg と 100 kg の人の数が同じで、ボートの位置が同じ 2 つの構成では、将来の可能性が同じになります。 

状態グラフの各エッジは 1 回のボート乗りに正確に対応するため、乗り物の最小回数は正確にこのグラフの最短経路距離になります。 BFS は、重み付けされていないすべてのグラフで最短距離を見つけます。 

固定遷移の場合、それを実現する具体的な方法の数は、関連する二項係数によって与えられる実際の乗客の選択肢の数に等しくなります。 パスに沿ってこれらの係数を乗算すると、そのパスによって表される輸送計画の数がカウントされます。 BFS の最短パスの反復計算では、すべての最短パスのみでこれらの寄与が合計され、最適な輸送計画の数が正確に得られます。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

MOD = 1000000007

def main():
    n, k = map(int, input().split())
    w = list(map(int, input().split()))

    A = sum(x == 50 for x in w)
    B = sum(x == 100 for x in w)

    M = k // 50

    C = [[0] * 51 for _ in range(51)]
    for i in range(51):
        C[i][0] = C[i][i] = 1
        for j in range(1, i):
            C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % MOD

    moves = []
    for p in range(51):
        for q in range(51):
            if p + q > 0 and p + 2 * q <= M:
                moves.append((p, q))

    dist = [[[-1] * 2 for _ in range(B + 1)] for _ in range(A + 1)]
    ways = [[[0] * 2 for _ in range(B + 1)] for _ in range(A + 1)]

    q = deque()
    dist[A][B][0] = 0
    ways[A][B][0] = 1
    q.append((A, B, 0))

    while q:
        x, y, side = q.popleft()

        cur_dist = dist[x][y][side]
        cur_ways = ways[x][y][side]

        if side == 0:
            for p, r in moves:
                if p > x or r > y:
                    continue

                nx = x - p
                ny = y - r
                ns = 1

                mult = C[x][p] * C[y][r]
                mult %= MOD

                if dist[nx][ny][ns] == -1:
                    dist[nx][ny][ns] = cur_dist + 1
                    ways[nx][ny][ns] = cur_ways * mult % MOD
                    q.append((nx, ny, ns))
                elif dist[nx][ny][ns] == cur_dist + 1:
                    ways[nx][ny][ns] = (
                        ways[nx][ny][ns] + cur_ways * mult
                    ) % MOD
        else:
            right50 = A - x
            right100 = B - y

            for p, r in moves:
                if p > right50 or r > right100:
                    continue

                nx = x + p
                ny = y + r
                ns = 0

                mult = C[right50][p] * C[right100][r]
                mult %= MOD

                if dist[nx][ny][ns] == -1:
                    dist[nx][ny][ns] = cur_dist + 1
                    ways[nx][ny][ns] = cur_ways * mult % MOD
                    q.append((nx, ny, ns))
                elif dist[nx][ny][ns] == cur_dist + 1:
                    ways[nx][ny][ns] = (
                        ways[nx][ny][ns] + cur_ways * mult
                    ) % MOD

    answer_dist = dist[0][0][1]

    if answer_dist == -1:
        print(-1)
        print(0)
    else:
        print(answer_dist)
        print(ways[0][0][1] % MOD)

if __name__ == "__main__":
    main()
```すべてのカウントが最大 50 であるため、組み合わせテーブルは 1 回計算されます。各遷移には定数時間のルックアップのみが必要です。 

BFS には、最短距離と最短経路の数の両方が保存されます。 ある状態が初めて発見されると、その最小距離がわかります。 別のパスがまったく同じ距離で同じ状態に到達する場合、その寄与もカウントする必要があります。 

よくある間違いは、ボートが右岸から戻るときに、現在左岸にいる番号を使用することです。 復路では右岸から乗客を選択するため、正しいカウントは次のようになります。$A-x$そして$B-y$。 

もう 1 つの微妙な点は、グラフが人々のアイデンティティによって方向付けられていないことです。 恒等式は、二項係数による遷移多重度内でのみ現れます。
