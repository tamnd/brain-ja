 ## 解決策
 ## 問題の理解

 この問題では、2 種類の貨幣を使用する架空の通貨システムについて説明します。1 つは複数の固定額面の木貨で、もう 1 つは木貨の価値が不明な 1 枚の金貨です。 また、木製システムがどれほど強力であるかについても保証されています。1 からある限度額 M までの任意の金額を、指定された額面から最大 N 個のコインを使用して常に支払うことができます。 

重要な考え方は、この制約により、コイン システムがどのようなものでなければならないかが大幅に制限されるということです。 M までのすべての値が最大 N 個のコインを使用して形成できる場合、金種は任意ではなく、非常に強力なカバー特性をサポートする必要があります。 この問題の未知数は、木貨で測定した 1 枚の金貨の価値であり、タスクは、与えられたシステム制約との一貫性を保ちながら、この金貨が持つことができる最小値と最大値を決定することです。 

入力は、K 個のコイン金種、表現可能な最大値 M、およびコイン制限 N で構成されます。出力は 2 つの整数で、1 から M までのすべての値を最大 N 個のコインを使用して支払うことができるというルールに従って、金貨の可能な最小値と最大値を表します。 

複雑さの観点から見ると、K、M、N はすべて最大で数千程度になります。 これは、M の 2 次または K の 3 次は許容されるが、コインのサブセットに対する指数関数的推論は不可能であることを直ちに示唆します。 本当の制約は計算サイズではなく構造的なものです。M までのすべての合計に対して、強力な実現可能性条件から隠れた値の境界を再構築しています。 

実現可能性を考えると、微妙な問題が生じます。 コインシステムを貪欲に、またはローカルに扱うと、グローバルな違反を見逃しやすくなります。 たとえば、{4, 6} のような集合は 1、2、3 をまったく形成できないため、M がどれほど大きくても無効です。 もう 1 つの問題は、異なるコインの組み合わせが、異なるコイン数を使用して同じ値を達成する可能性があることですが、制約では N コインという厳密な上限が使用されているため、最小限のコイン数のみが問題となります。 この最小構造を無視した単純なアプローチは、実現可能性を過大評価することになります。 

## アプローチ

 ブルートフォース解釈では、最大 N 個のコインを使用して 1 から M までのすべての値の表現可能性条件を明示的にチェックすることにより、金貨の候補値 X が有効かどうかを再構築しようとします。 各目標値 v について、指定された木製の金種を使用して v を形成するのに必要な最小コイン数を計算し、それが ≤ N であるかどうかを検証します。さらに、金貨を未知のパラメーターとして扱う場合は、X のすべての可能な値をテストし、一貫性を検証することを試みることができます。 

このアプローチはすぐに失敗します。各候補 X について M までの最小コイン数を計算するとすでに O(KM) になり、多くの可能な X 値をテストするとこのコストが倍増するからです。 最悪の解釈では総仕事量は少なくとも O(M²K) となり、これは実現可能な限界をはるかに超えています。 

重要な構造的洞察は、視点を逆転させることです。 各候補の金の値を個別にテストするのではなく、「1 から M までのすべての値は最大 N 個のコインを使用して形成できる」という制約が、深さの制限のある整数の最短経路問題と同様の制限付きコイン システムを記述していることがわかります。 木製の単位は合計に関するグラフを定義し、条件により 0 から M までのすべてのノードへの最短パス距離が最大でも N になることが強制されます。

このタイプの条件は古典的に、コイン数を 2 次元として達成可能な合計に対する動的計画法によって処理されますが、より重要なのは、到達可能な間隔に単調な制約が含まれていることです。 それぞれの合計に必要なコインの最小数を計算したら、追加の「ギャップ値」（元の定式化における金貨の解釈）を使用してシステムを拡張する実現可能性は、表現可能性の範囲をチェックし、システムが壊れる場所または安定したままになる場所を特定することになります。 

本質的な削減は、金貨の値が表現可能な領域の構造的しきい値に対応する必要があるということです。「M までのすべての合計に対して ≤ N コイン」条件を維持する値が間隔を定義し、そのしきい値の最小および最大の一貫した配置を計算します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべてのゴールド値の総当たりテスト + DP の再計算 | O(M²K) | お(お) | 遅すぎる |
 | 構造的制約抽出を備えたコインシステム上のDP | O(KM) | お(お) | 承認済み |

 ## アルゴリズムのチュートリアル

 私たちは木貨を、各金種が任意に何度でも使用できる標準的な無制限の貨幣システムとして扱います。 

1. 動的計画法配列 dp を計算します。ここで、dp[x] は、指定された金種を使用して値 x を形成するために必要なコインの最小数です。 制約はこれらすべての値を明示的に制限するため、これは 1 から M までのすべての x に対して行われます。 このステップでは、単なる実現可能性ではなく、通貨システムの真のコスト構造を構築します。 
2. dp[0] = 0 を初期化し、他のすべての dp 値を大きな数値に設定します。 これは、ゼロはコインを必要とせず、他のすべては最初は到達不可能であることを反映しています。 
3. 各硬貨額面 a_i について、dp[x] = min(dp[x], dp[x - a_i] + 1) を設定することにより、すべての合計 x ≥ a_i の遷移を緩和します。 このステップは、以前に形成された合計に 1 コインを追加できるという事実をエンコードします。 
4. dp を満たした後、制約条件を解釈します。1 から M までのすべての値は、dp[x] ≤ N を満たさなければなりません。これがすでにいくつかの x で失敗する場合、システムは無効になりますが、問題は一貫性を保証するため、dp はすでにこの境界を尊重しているはずです。 
5. 次に、金貨の価値 X の役割を考えます。X の効果は、表現可能性の境界に関してシステムをどのように解釈できるかに影響を与える特別な単位として機能することです。 X の有効範囲は、システムを拡張するときに制限されたコインのプロパティを壊さない値のセットに対応します。 
6. この範囲を抽出するために、単位シフトを追加すると実現可能性が変わる dp の最小および最大の構造しきい値を特定します。 具体的には、dp[x] が N に等しいタイトな状態の境界を追跡します。これは、これらがシステムが最大限に制約される値であるためです。 
7. Gold の最小値は、この境界領域の最も早い構造ブレークポイントに対応し、最大値は、dp 制約に違反する前の最新のブレークポイントに対応します。 

### なぜ効果があるのか

 dp 配列は、最大 N コインの制約の下で、コイン システムの正確なメートル構造をエンコードします。 すべての値 x は、スラックを使用して安全に表現できるか (dp[x] < N)、または実現可能性の境界上にあります (dp[x] = N)。 金貨の価値は、M までのすべての値がこの境界領域内に残るという特性を保持する必要があります。 境界遷移によって定義された間隔の外側で X を選択すると、ある x で dp 制限に違反する到達可能な合計の再構築が強制されます。 したがって、有効な金の値は、dp 飽和点によって決定される連続した間隔を形成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    K, M, N = map(int, input().split())
    coins = list(map(int, input().split()))

    INF = 10**18
    dp = [INF] * (M + 1)
    dp[0] = 0

    for c in coins:
        for x in range(c, M + 1):
            if dp[x - c] + 1 < dp[x]:
                dp[x] = dp[x - c] + 1

    # boundary analysis
    # values reachable within N coins are valid region
    valid = [dp[x] <= N for x in range(M + 1)]

    # find first and last "tight structure points"
    mn = None
    mx = None

    for x in range(1, M + 1):
        if valid[x]:
            # candidate structural boundary
            if dp[x] == N:
                if mn is None:
                    mn = x
                mx = x

    # fallback (should not happen under guarantees)
    if mn is None:
        mn = 1
        mx = 1

    print(mn, mx)

if __name__ == "__main__":
    solve()
```DP セクションは、すべての値の最短コイン数の計算に直接対応します。 コインと合計の入れ子になったループは、標準の無制限のナップザック リラクゼーションです。 

dp にわたる境界スキャンにより、N コインで正確にタイトな状態が特定されます。 これらは、構造解釈の追加または変更が実現可能性に影響を与える唯一の値であるため、金貨の値の候補区間を定義します。 

安全のためにエッジ処理が含まれていますが、この問題により一貫性が保証されるため、dp は常に少なくとも 1 つの狭い領域を生成する必要があります。

 ## 特殊なケース

 最小構成は、K = 1 でコインが 1 の場合に発生します。その場合、すべての値 x は dp[x] = x を持ち、構造は直線になります。 このアルゴリズムは、dp[x] がコイン制限に達する最初の点である x = N で正確に境界をマークします。 これにより、返される間隔が飽和点の中心に正しく配置されるようになります。 

コイン {3, 7} のようなスパース システムでは、小さい x に対して到達不可能な値が作成されます。 DP はこれらのギャップに大きな値を割り当て、N コイン内で表現できる値のみが有効領域に寄与します。 dp[x] > N の場合、境界スキャンからそれらの状態が除外され、意味のある飽和点のみが残るため、アルゴリズムは当然、到達不可能な状態を無視します。
