 ## 解決策
 ## 問題の理解

 モジュラー算術規則によって生成された一連のプラットフォームの高さが与えられます。 x 番目のプラットフォームは高い位置にあります`(a · x) mod p`、 どこ`a`そして`p`は互いに素であり、最初のもののみを考慮します`n`そういったポジション。 キャラクターは高さ 0 から始まり、1 回のジャンプが固定制限を超えない限り、任意の 2 つの位置の間を上に移動できます。`h`。 課題は、これらのプラットフォームの中で最も高いプラットフォームに到達できるかどうかを判断することです。`n`ポイントは、キャラクターが到達可能なプラットフォームを訪問する順序を任意に選択できると仮定します。 

これは単純な「最大値に直接到達できるか」という質問ではありません。 すでに到達している 2 つのプラットフォーム間をジャンプできるということは、高さの差が最大であれば、プラットフォームがノードのすべてのペアが接続されたグラフを形成することを意味します。`h`。 問題は、この規則に従って、最大の高さを持つノードが 0 を含む連結成分にあるかどうかを尋ねます。 

テスト ケースの数に対する制約は最大 10⁴ と非常に厳しく、`n`そして`p`最大 10⁹ まで大きくすることができます。 これにより、すべてのプラットフォームの高さを明示的に構築したり、テスト ケースごとに接続を素朴にシミュレートしたりするアプローチは直ちに除外されます。 テスト ケースごとに O(n) であっても、合計すると大きすぎます。 

重要な点は、シーケンスが`(a · x mod p)`残基上で順列のようなウォークのように動作します。`a`そして`p`は互いに素である。 ただし、サイクル全体をたどるのではなく、最初のサイクルだけをたどります。`n`ポイントを順番に。 これにより、ほとんどの直接的な構造が破壊され、単調性や単純なギャップについての単純な推論は失敗します。 

典型的な間違いは、高さがモジュロで分散しているため、次のように仮定することです。`p`の場合、到達可能な領域はインデックス順のローカル近傍のみに依存します。 たとえば、高さが次の場合、`7, 2, 9, 4`と`h = 2`、インデックス順にアクセスすると到達可能性情報が得られると誤って仮定する可能性があります。 ただし、正しいトランジションは、インデックスの順序ではなく、ソートされた高さのみに依存します。 

別の障害モードは、エッジが絶対的な高さの差のみに依存するグラフの到達可能性が接続性と同等であることを無視しています。 インデックスに対する単純な BFS では、たまたま高さが近い、隣接していないインデックス間の有効なジャンプを見逃してしまいます。 

## アプローチ

 ブルートフォース解釈により、完全なグラフが構築されます。`n`各ノードがプラットフォームの高さであるノード。 2 つのノードは、絶対高さの差が最大以下の場合に接続されます。`h`。 次に、地上 (0​​) から BFS または DFS を実行し、最大高さのノードに到達できるかどうかを確認します。 これは正しいですが、すべてのペアごとのエッジを構築するには O(n²) のコストがかかり、これは中程度のレベルでも不可能です。`n`。 

絶対差のしきい値によって定義されたグラフでは、並べ替えられた順序で近い点間のエッジのみが重要であることを観察することで、これを軽減できます。 高さがソートされたら、各ノードは距離内にある直近のノードに接続するだけで済みます。`h`これは、長距離接続がしきい値内にある場合、中間の並べ替えポイントを通じて分解できるためです。 

これにより、並べ替え後の折れ線グラフの接続の問題が軽減され、到達可能な間隔を貪欲に拡張できます。 残りの困難は、依然として生成しなければならないことです。`n`効率的に価値を高めます。 重要な観察は次のとおりです。`n`はテスト ケース全体で大きく、各テストでは生成された残差の線形スキャンのみが必要で、それぞれの残差を生成します。`a·x mod p`はO(1)です。 本当のボトルネックはテストごとのソートですが、すべてのテストにわたる合計入力サイズが 10⁴ 以内に制限されているため、これは許容範囲内です。 

したがって、解決策は次のようになります。すべての高さを生成し、それらを並べ替えて、次に、`h`。

 ## アルゴリズムのチュートリアル

 1. 次を使用してすべてのプラットフォームの高さを生成します。`h[i] = (a · i) mod p`のために`1 ≤ i ≤ n`。 これにより、到達可能なノードの状態空間が明示的に構築されます。 
2. 高さの配列を並べ替えます。 到達可能性はインデックスの順序ではなく数値の近さのみに依存するため、並べ替えは不可欠です。 
3. 変数を初期化する`reachable_max`地面が 0 にあり、上向きの接続性を考慮するため、最小の高さとなります。 
4. ソートされた高さを最小から最大までスイープします。 連続する高さの間のギャップが最大でも`h`を拡張して、それらを同じ到達可能なクラスターにマージします。`reachable_max`。 
5. いずれかの時点でギャップが超過した場合`h`では、ターゲットの最大高さが現在のクラスターに既に含まれているかどうかを確認します。 そうでない場合、ギャップを埋めることができず、残りのより大きな値は 0 から到達できなくなります。 
6. 処理後、最大の高さが 0 と同じ接続されたセグメント内にあるかどうかを確認します (同等に、0 を含む最初のクラスターが、より大きな切れ目なしで最大値に達するかどうか)。`h`）。 

重要な考え方は、並べ替え順序によって問題が、禁止されたギャップに遭遇することなく、到達可能な最小値から最大値まで範囲を連続的に拡張できるかどうかをチェックすることに変換されるということです。 

### なぜ効果があるのか

 並べ替え後、2 つの高さの間でジャンプできるのは、それらが距離内にある場合のみです。`h`。 2 つの連続する並べ替え値の差が 2 を超える場合`h`の場合、中間値のチェーンはそれらの間に存在しません。これは、中間値が数値的にそれらの間に存在する必要があり、したがってその間でソートされるためです。 したがって、これより大きいギャップは、`h`グラフを切り離されたコンポーネントに分離する硬い障壁を形成します。 0 から到達可能なコンポーネントは、すべての隣接する差が最大でも最小の高さから始まる最初のセグメントです。`h`。 最大値がこのセグメント内にある場合は、到達可能です。 それ以外の場合は、禁止されたギャップによって分離されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    
    for _ in range(t):
        a, n, p, h = map(int, input().split())
        
        vals = [(a * i) % p for i in range(1, n + 1)]
        vals.sort()
        
        # start from the smallest height cluster
        ok = True
        for i in range(1, n):
            if vals[i] - vals[i - 1] > h:
                # if max is beyond this point, it is unreachable
                if vals[n - 1] > vals[i - 1]:
                    ok = False
                break
        
        out.append("YES" if ok else "NO")
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```生成ステップでは、プラットフォームの高さの完全なセットが直接構築されます。 ソートにより、値空間における隣接性について純粋に推論できることが保証されます。 スイープにより、次の値より大きい最初の「ブロッキング ギャップ」が検出されます。`h`。 このようなギャップが見つかると、右側のすべてが左側のすべてから切り離されてしまいます。 

最大値がギャップを超えているかどうかをチェックする条件は、重要な正確性ゲートです。最大値がすでに到達可能なプレフィックス内にある場合は成功します。 そうしないと、グラフに到達する前にグラフが分割されてしまいます。 

微妙な点は、0 は概念的にすべてのプラットフォームの下にあるため、0 からの到達可能性を明示的にシミュレートしていないことです。 最小のプラットフォームは常に最初の到達可能な領域に属し、拡張は上に向かって進みます。

 ## 特殊なケース

 微妙なケースの 1 つが次のような場合です。`h = 0`。 この場合、接続できるのは同じ高さのもののみです。 ソートされた順序で厳密に増加するシーケンスはすぐにゼロより大きなギャップを生成し、コンポーネントを分割するため、アルゴリズムはこれを正しく処理します。 最大値が最小値と等しくない場合、到達不能になります。 

もう一つのケースは次のような場合です。`n = 1`。 ソートされた配列には単一の要素が含まれるため、ギャップは存在せず、アルゴリズムはただちに到達可能であると結論付け、唯一のプラットフォームが自明に到達可能であるという事実と一致します。 

値がモジュロでラップアラウンドする場合、さらにエッジケースが発生します。`p`。 シーケンスは循環的に生成されますが、ソートによりラップ構造への依存が除去されます。 接続性の基準は並べ替え後の直線距離のみに依存するため、ラップアラウンドは正確さに影響しません。
