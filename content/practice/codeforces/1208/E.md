 ## 解決策
 ## 問題の理解

 テーブルが与えられました`n`行と`w`列。 各行には、行内で左右にスライドできる配列が含まれていますが、完全にテーブル内に留まり、連続する列を占有する必要があります。 配列は異なる長さを持つことができ、一部の要素は負の値になる可能性があります。 私たちの目標は、各列について、その列をカバーする配列によってもたらされる数値の最大合計を計算することです。 配列が特定の列を最適な配置でカバーしていない場合、その寄与はゼロになります。 

主要な課題はサイズの制約にあります。 配列の数`n`そして列の数`w`どちらも最大です`10^6`、配列要素の合計数も最大で になります。`10^6`。 各配列の可能な配置をすべて試し、列ごとに寄与を合計する単純なアプローチでは、次の結果が得られます。`O(n * w)`最悪の場合の運用`10^{12}`そして実行不可能です。 このため、配列要素の総数とテーブル幅を加算した値が線形となる方法を使用する必要があります。 

エッジ ケースは、配列がテーブルに比べて非常に短い場合、または負の数が含まれている場合に発生します。 たとえば、配列の長さが 1、値が -5 の場合、`w = 5`の場合、最適な戦略は、関心のある列の外側に配置して、その寄与がゼロになるようにすることです。 常に配列値を加算する単純なアプローチでは、負の寄与が誤って生成されます。 もう 1 つの厄介なシナリオは、配列の長さがテーブルの幅と等しい場合に発生します。 次に、すべての列をカバーし、選択なしにすべての合計に寄与する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、すべての配列を考慮し、その行内のすべての有効な開始位置に配列を配置しようとします。 各ポジションについて、対象となる各列の寄与度を更新し、すべてのポジションをチェックした後、各列の最大値を取得します。 これは原理的には正しいですが、反復処理が必要です`w - l_i + 1`長さの各配列の位置`l_i`そして、そのような位置ごとに更新する必要があります`l_i`列。 すべての配列を合計すると、次のようになります。`O(total_elements * w)`動作が遅すぎます。 

重要な洞察は、列の合計に対する各行の寄与が「スライディング ウィンドウの最大値」問題であるという事実を利用することです。 各配列について、列に寄与する値は、どのサブ配列がその列をカバーするかによってのみ決まります。 デキューまたは 2 パス手法を使用して、各列について、この行が寄与できる最適な値を事前計算できます。 具体的には、各配列を幅のテーブル内のウィンドウとして扱います。`w`、必要に応じて配列の両端にゼロを埋め込み、潜在的な各列の最大値を計算します。`O(l_i)`time per array. すべての配列を処理した後、列ごとに寄与を合計します。 このアプローチは、配列要素の合計数にテーブル幅を加えた値が線形であり、制約内に快適に収まります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * w) | O(w) | 遅すぎる |
 | スライディング ウィンドウ / Prefix-Max | O(total_elements + w) | O(w) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. Initialize an array`ans`長さの`w`ゼロ付き。 これにより、各列の最大合計が保持されます。 
2. 各行について、配列の長さを決定します。`l`とその要素。 この行のウィンドウ内の各列について、この配列の最大寄与度を計算します。 
3. もし`l`等しい`w`の場合、配列は行全体を占めます。 その要素を直接追加するだけです`ans`。 
4. もし`l`よりも小さいです`w`、スライドをシミュレートするために配列にゼロを埋め込みます。 長さの新しい配列を作成します`w`元の配列は左から右にスライドできます。 この配列の先頭と末尾にはゼロがあり、マイナスの影響を与えずに「部分的なカバレッジ」を可能にします。 
5. パディングされた配列全体で左から右のプレフィックスの最大値と右から左へのサフィックスの最大値を計算します。 コラム用`i`、配列の寄与は、列をカバーできる配列内の要素の最大値です。`i`。 これにより、負の数値を効果的にウィンドウの外側に配置することで、負の数値を無視できるようになります。 
6.アップデート`ans`この配列からの寄与を追加することにより、各列に対して。 
7. すべての行を処理した後、印刷します。`ans`。 の各値`ans`は、その列で達成可能な最大合計を表します。 

正確さは、各列について、その行内で配列をスライドさせることで達成可能な最大の寄与を常に追跡するという不変条件を維持することに依存します。 配列をスキップする方が良い場合でも、ゼロでパディングすると、列に負の寄与が強制されることがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, w = map(int, input().split())
ans = [0] * w

for _ in range(n):
    data = list(map(int, input().split()))
    l = data[0]
    a = data[1:]
    
    if l == w:
        for i in range(w):
            ans[i] += a[i]
        continue
    
    padded = [0] * w
    for i in range(l):
        padded[i] = a[i]
    
    left_max = [0] * w
    current = float('-inf')
    for i in range(l):
        current = max(current, a[i])
        left_max[i] = current
    for i in range(l, w):
        left_max[i] = left_max[i-1]
    
    right_max = [0] * w
    current = float('-inf')
    for i in range(l-1, -1, -1):
        current = max(current, a[i])
        right_max[i] = current
    for i in range(l, w):
        right_max[i] = float('-inf')
    
    for i in range(w):
        ans[i] += max(0, max(left_max[i] if i < l else float('-inf'), right_max[i] if i >= w-l else float('-inf')))
        
print(' '.join(map(str, ans)))
```このソリューションでは、まず配列が行全体をカバーしているかどうかをチェックし、その場合は値が直接追加されます。 小さい配列の場合、プレフィックスとサフィックスの最大値を使用して各列への最大寄与を効率的に計算します。 パディングにより、列をカバーしない方がよい場合に、配列がゼロに寄与できることが保証されます。 最後のループでは、コントリビューションを行ごとにマージします。`ans`。
