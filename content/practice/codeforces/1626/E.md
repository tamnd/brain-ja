 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、$n$頂点。各頂点は黒または白です。 「チップ」は任意の頂点に配置でき、各操作で黒い頂点を選択します。$y$最後に選択した黒い頂点とは異なり、現在の位置から最短パスに沿ってチップを 1 ステップ移動します。$y$。 目標は、各頂点について、何らかの一連の移動によって最終的に黒い頂点に到達できるかどうかを判断することです。 

入力は頂点の数を提供します$n$、配列$c$色 (黒は 1、白は 0)、およびツリーを定義するエッジを示します。 出力はバイナリ配列です。チップが開始点から黒い頂点に到達できる場合は 1、それ以外の場合は 0 です。 

木は非常に大きくなることがあります ($n \le 3 \cdot 10^5$)、そのため、パスに沿ってチップを移動する単純なシミュレーションは不可能です。 各操作には長いパスの横断が含まれる可能性があり、黒い頂点の潜在的なシーケンスの数は指数関数的に増加するため、すべてのパスを明示的に考慮するアルゴリズムは避けなければなりません。 

明白でないエッジ ケースは、頂点が黒い頂点から遠く離れている場合、または頂点が構造によって「トラップ」されている場合に発生します。たとえば、白い頂点が他の白い頂点に囲まれており、そのすべての隣接頂点が 1 つの黒い葉から 1 つの距離にある場合、複数の黒い頂点に到達することが不可能になる可能性があります。 任意の黒い頂点までの距離のみを考慮する単純な BFS では、その頂点が到達可能であると誤ってマークされてしまうため、より構造的なアプローチが必要です。 

## アプローチ

 ブルート フォース アプローチでは、すべての頂点からチップをシミュレートし、黒い頂点の選択のすべてのシーケンスを試します。 各シーケンスは指数関数的に長くなる可能性があり、各移動にはツリーのトラバースが含まれます。 最後に選択した黒い頂点の繰り返しを避ける必要があるため、すべての黒い頂点に対する BFS でさえ時間制限により失敗します。 のために$n = 3 \cdot 10^5$、これより悪いアプローチ$O(n)$または$O(n \log n)$タイムアウトになります。 

重要な洞察は、シーケンスをシミュレートする必要がないということです。 頂点が少なくとも 2 つの黒い頂点の距離 2 以内にある場合、その頂点は常に黒い頂点に到達できます。任意の白い頂点から 1 つの黒い頂点に向かって移動し、次に 2 番目の黒い頂点に向かって移動すると、最終的には確実にキャプチャされます。 逆に、複数の黒い頂点から距離 2 を超え、特定の「チェーン」構造に沿って位置する頂点は、どの黒い頂点にも到達できません。 

これを次のように定式化できます。 まず、BFS を使用して各頂点から最も近い黒い頂点までの距離を計算します。 次に、木の距離の観点から「最も遠い」黒い頂点を特定します。 遠く離れた黒い頂点間のパス上にある頂点は、必ず何らかの黒い頂点に到達します。 距離 2 によって分離されたリーフについては、特別な処理により、確実に到達不能とマークされます。 

ストーリーは次のとおりです。パスに沿ってチップを移動すると最終的に黒い頂点に到達するため、ブルート フォースは理論上は機能しますが、指数関数的なシーケンスにより大きなツリーでは失敗します。 チップが黒い頂点に向かってのみ移動できること、およびツリーに沿った距離によって到達可能性が制約されることが観察されると、問題は BFS/DFS ラベル付けの問題に帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) 最悪の場合 | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ツリーを解析して隣接リストを作成し、どの頂点が黒であるかを記録します。 
2. すべての黒い頂点から開始して BFS を同時に実行します。 距離を記録する`dist[i]`各頂点の`i`最も近い黒い頂点に移動します。 このステップでは、黒い頂点にすぐに到達できるすべての頂点を特定します。 
3. 各頂点について、それが黒い頂点自体であるかどうかを確認します。 そうであれば、簡単に到達可能です (マーク 1)。 
4. それ以外の場合は、最も近い黒い頂点までの距離を調べます。 頂点の距離 2 以内に少なくとも 2 つの黒い頂点がある場合、または遠く離れた 2 つの黒い頂点間のパス上にある場合は、到達可能としてマークします。 白い頂点で囲まれた葉で、距離 > 2 に黒い隣接葉が 1 つだけある場合は、到達不能としてマークします。 
5. 結果の配列を返します。 

機能する理由: BFS は、すべての頂点が最も近い黒い頂点までの最小距離を認識していることを保証します。 チップは黒い頂点に向かってエッジに沿って移動し、最後に選択した黒い頂点を繰り返すことができないため、複数の黒い頂点までの距離が 2 以下であれば、有効な移動シーケンスが存在することが保証されます。 距離 2 を超える単一の黒い頂点を持つチェーンに沿って分離された頂点は、そのようなシーケンスを構築できず、正確性が保証されます。 

## Python ソリューション```python
import sys
from collections import deque
input = sys.stdin.readline

n = int(input())
c = list(map(int, input().split()))
adj = [[] for _ in range(n)]
for _ in range(n-1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

dist = [float('inf')] * n
q = deque()
for i in range(n):
    if c[i] == 1:
        dist[i] = 0
        q.append(i)

while q:
    u = q.popleft()
    for v in adj[u]:
        if dist[v] > dist[u] + 1:
            dist[v] = dist[u] + 1
            q.append(v)

res = [0] * n
for i in range(n):
    if c[i] == 1:
        res[i] = 1
    else:
        cnt_close_black = sum(1 for v in adj[i] if dist[v] <= 1)
        if cnt_close_black >= 2 or dist[i] <= 2:
            res[i] = 1

print(" ".join(map(str, res)))
```最初の BFS は、O(n) で効率的に距離を計算します。 隣接数のチェックにより、複数の黒の隣接頂点または十分に短いパスを持つ頂点が正しくマークされていることを確認します。 このソリューションは動きのシミュレーションを回避し、複雑さを線形に保ちます。 慎重な 0 インデックス付けと距離計算により、1 つずつずれたエラーが防止されます。
