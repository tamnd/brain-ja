 ## 問題の理解

 0 から 0 を含まない範囲にある整数の数を数えています。$10^n$、選択された各数値が次の形式の固定整数で割り切れるという追加の要件があります。$3 \cdot 2^a$。 すべてのテスト ケースでこのセットのサイズが必要なので、998244353 を法として出力します。 

問題を理解するのに役立つ方法は、非常に大きな数直線上に等間隔の点を配置していることです。 間隔は次によって決まります。$3 \cdot 2^a$そして、私たちが興味があるのは、これらのポイントのうち何個が より前に当てはまるかだけです。$10^n$。 

制約$n \le 10^{18}$すぐに私たちに決して建設できないと告げます$10^n$明示的に、または標準の数値形式で表すこともできます。 範囲または計算能力を整数形式で直接シミュレートしようとするソリューションは失敗します。 唯一の実行可能な道は、累乗と割り算について代数的に推論することです。 

微妙な特殊ケースの 1 つは、ゼロが含まれていることです。 間隔は 0 から始まり、0 はすべての正の整数で割り切れるため、常に答えの一部になります。 正の倍数のみをカウントする単純なアプローチでは、この寄与を見逃してしまいます。 たとえば、次の場合$n = 1$そして$a = 1$、有効な範囲は次のとおりです。$[0, 10)$、そして除数は$6$。 有効な値は次のとおりです。$0, 6$したがって、正しい答えは 2 です。最初の正の倍数からカウントを開始する不注意な実装では、誤って 1 が返されます。 

もう 1 つの失敗モードは、構造を単純化せずに大きな累乗を独立して計算しようとすることから発生します。 両方$10^n$そして$2^a$は指数関数的な量ですが、因数分解を通じてきれいに相互作用するため、問題は扱いやすくなります。 

## アプローチ

 ブルートフォース手法では、0 から 0 までのすべての整数が列挙されます。$10^n - 1$そして、次のように割り算をテストします$3 \cdot 2^a$。 これは定義を直接適用するため、概念的には単純で正しいものです。 ただし、候補者数は、$10^n$、小さいものでも天文学的に大きくなります。$n$。 入力サイズが大きくなると複雑さが指数関数的に増大するため、最小ではない場合でもこのアプローチは不可能になります。 

重要な観察は、有効な数値は等間隔に配置された次の倍数であるということです。$m = 3 \cdot 2^a$。 したがって、各数値を確認するのではなく、次の値の倍数を数えるだけで済みます。$m$下に横たわる$10^n$。 これにより、問題は、固定区間に等差数列の項がいくつ収まるかという単純な割り算の問題に変換されます。 

唯一残っている問題は、分子が両方とも$10^n$そして除数構造には巨大な指数が含まれます。 直接計算は不可能ですが、$10^n = 2^n \cdot 5^n$除数と完全に一致します$3 \cdot 2^a$これにより、2 進成分と非 2 成分を分離し、モジュラー演算とフロア分解を使用して商を評価できるようになります。

 ## アルゴリズムのチュートリアル

 しましょう$m = 3 \cdot 2^a$そして$N = 10^n$。 の倍数が必要です$m$で$[0, N)$に等しい$\left\lfloor \frac{N-1}{m} \right\rfloor + 1$。 以来$N$は常に正であるため、これを単純化すると、$\left\lfloor \frac{N}{m} \right\rfloor + 1$なぜなら$N$は決して割り切れません$m$因数 3 によるものです。 

1.書き換える$N$として$10^n = 2^n \cdot 5^n$。 これにより、式内の 2 の累乗が分離され、次の関数と直接相互作用します。$2^a$除数で。 
2. 2 のべき乗をきれいに割り算します。 書き換えます$$\frac{10^n}{3 \cdot 2^a} = 2^{n-a} \cdot \frac{5^n}{3}.$$このステップでは、2 のべき乗の相互作用のみが分離され、3 による除算を含むよりクリーンな分数項が残ります。 
3. スプリット$5^n$商と剰余をモジュロ 3 に変換します。$5 \equiv 2 \pmod{3}$、 我々は持っています$5^n \bmod 3 = 2^n \bmod 3$、パリティに応じて交互に切り替わります。$n$。 これにより、次のようになります。$$5^n = 3q + r$$どこ$r \in \{1,2\}$。 
4. この分解を次のように置き換えます。$$\frac{10^n}{3 \cdot 2^a} = 2^{n-a} q + 2^{n-a} \cdot \frac{r}{3}.$$最初の項はすでに整数です。 第 2 項はフロアを通じてのみ貢献します。 
5. 最終的な答えを次のように計算します。$$\left(2^{n-a} \cdot \left\lfloor \frac{5^n}{3} \right\rfloor + \left\lfloor \frac{2^{n-a} \cdot r}{3} \right\rfloor \right) + 1.$$+1 は常に存在するゼロを表します。 

### なぜ効果があるのか

 すべての有効な数値は、次の倍数に正確に対応します。$m$、したがって、解を数えることは整数の除算に帰着します。 分解により、すべての大きな指数が個別に処理されることが保証されます。2 の累乗はきれいに吸収され、残りの 3 による除算は小さなモジュラー剰余問題に還元されます。 すべてのステップではフロアを取得する前に正確な整数演算が保持されるため、近似誤差は発生しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def mod_pow(a, e):
    res = 1
    a %= MOD
    while e > 0:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve():
    t = int(input())
    for _ in range(t):
        n, a = map(int, input().split())

        # handle 2^{n-a} as power in modular arithmetic
        if n < a:
            # 2^{n-a} = 2^{-k}, but in integer formula this term becomes 0
            # since 10^n < 2^a * 3 for large a, only zero contributes
            print(1)
            continue

        pow2 = mod_pow(2, n - a)
        pow5 = mod_pow(5, n)

        # floor(5^n / 3)
        q5 = pow5 // 3
        r5 = pow5 % 3

        term1 = pow2 * (q5 % MOD) % MOD
        term2 = (pow2 * r5) // 3 % MOD

        ans = (term1 + term2 + 1) % MOD
        print(ans)

if __name__ == "__main__":
    solve()
```コードは、上記で導出された正確な分解に従います。 まず、次の 2 のべき乗を分離します。$10^n$そして、除数から対応する因数を削除します。 それから計算します$5^n$3 を法とする商と剰余の両方を決定します。これらがフロア分割に影響を与える唯一の部分です。 結果は、2 つのクリーンな貢献と必須のゼロ項から組み立てられます。 

実装の微妙な詳細は、次の処理です。$n < a$。 この場合、除数には 2 の因数が 2 よりも多く含まれます。$10^n$、主要な期間の構造が崩壊し、ゼロからの些細な貢献だけが残ります。

 ## 特殊なケース

 いつ$a = n$、除数の 2 の累乗は、次の 2 の累乗を正確に打ち消します。$10^n$。 式は 3 の倍数を数えるまでに折りたたまれます。$5^n$、の構造のみ$5^n \bmod 3$重要です。 このアルゴリズムは、負の指数を回避し、正しい基数寄与を直接返す条件付き分岐を通じてこれを処理します。 

いつ$a$よりもはるかに小さいです$n$、 用語$2^{n-a}$スケーリングを支配しますが、オーバーフローや精度の低下を防ぐため、常に 3 による除算コンポーネントとは切り離されています。 分解により、大きさの違いに関係なく正確さが保証されます。 

ケース$n = 1, a = 1$等差数列にはまだ最初の項がゼロに含まれているため、正の倍数が存在しない場合でも、ゼロ要素が常に含まれることが確認されます。
