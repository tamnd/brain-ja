 ## 解決策
 ## 問題の理解

 長さのシーケンスが何個あるかを数えるように求められます`n`以下の整数を使用して構築できます`1`に`m`、隣接する要素のすべてのペアが互いに素でなければならないという制限があります。 2 つの数は、その最大公約数が次の場合に互いに素になります。`1`したがって、連続する要素は、素因数を共有しない場合にのみ許可されます。 

出力は、そのようなシーケンスの数を法にしたものです。`998244353`したがって、タスクは純粋に組み合わせです。シーケンスを構築するのではなく、ローカル隣接制約の下でシーケンスをカウントするだけです。 

制約`n ≤ 1000`そして`m ≤ 1000`十分に小さいため、二次または二次に近い動的計画法のアプローチが妥当です。 ただし、すべてのペア間の遷移を明示的に列挙しようとするソリューションはすべて`(i, j)`共原理性を完全にチェックするのは難しいため、単純な方法ではまだ注意が必要です。`O(log m)`ペアごとに、単純な移行を押し進めることになります。`O(n m^2 log m)`。 

最も危険なエッジケースは次のような場合です`m = 1`。 この場合、可能な唯一のシーケンスは 1 の定数シーケンスであり、これは有効です。`gcd(1, 1) = 1`。 区別性を誤って仮定したり、自己遷移を除外したりするアプローチは、ここでは失敗します。 

もう一つの微妙なケースは次のような場合です。`m`は大きいですが、高度に合成された数値が遷移を支配します。 共素性は高度に構造化されており、密度ではなく共有素数に依存するため、「ペアの半分が互いに素である」などの素朴な仮定は誤ったカウントにつながります。 

## アプローチ

 ブルートフォース戦略では、シーケンスを段階的に構築します。 各位置で、次のすべての可能な値が試行されます。`1`に`m`、前の要素と互いに素であるかどうかを確認します。 これにより、単純な再帰が行われます。つまり、位置ごとに、すべての有効な次の値に分岐します。 条件を直接強制するため、正しさは即座にわかります。 

失敗のポイントは繰り返しです。 各州`(position, previous_value)`につながる`m`移行があり、`n * m`そのような状態なので、総当たり攻撃は当然、部分問題が繰り返される動的計画法の問題になります。 メモ化しない場合、再帰は次のように指数関数的に分岐します。`m^n`、でもそれは不可能です`n = 20`。 

唯一の依存関係が前の要素にあることを認識すると、その構造は頂点上の完全な有向グラフ上の古典的な隣接 DP になります。`1..m`ここで、エッジは 2 つの数値が互いに素である場合にのみ存在します。 タスクは長さを数えるようになります。`n`このグラフの中を歩きます。 

重要な観察は、どのペアが互いに素であるかを事前に計算しておけば、遷移を繰り返し再計算する必要がないということです。 次に、DP は固定遷移グラフに沿った伝播カウントに減少します。 

さらなる改良点は、`m ≤ 1000`、すべての共素ペアを事前計算できます。`O(m^2)`次にDPを実行します`O(n m^2)`。 これは、一般的な Codeforce 制約の下では十分です。`n, m ≤ 1000`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース再帰 | O(m^n) | O(n) | 遅すぎる |
 | ペア事前計算を使用した DP | O(n m^2) | O(m^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 ノードが次の整数である有向グラフ内のパスを数えることとして問題をモデル化します。`1`に`m`、からのエッジがあります`i`に`j`もし`gcd(i, j) = 1`。 

1. 互いに素な隣接関係テーブルを事前計算する`ok[i][j]`みんなのために`1 ≤ i, j ≤ m`。 このステップでは、後の DP 遷移が定数時間ルックアップになるように、すべての有効な遷移を明示的に定義します。 
2. DP 配列を初期化する`dp[x]`value で終わる現在の長さの有効なシーケンスの数を意味します`x`。 長さのシーケンスの場合`1`、からのすべての値`1`に`m`有効なので、`dp[x] = 1`。 
3. 次の位置ごとに繰り返します。`2`に`n`。 それぞれの値について`j`、新しい値を計算します`ndp[j]`以前のすべての値を合計することによって`i`そのような`ok[i][j]`保持、蓄積`dp[i]`。 
4. 各レイヤーを処理した後、置き換えます`dp`と`ndp`。 これにより、ステップの後、`k`、`dp`すべての有効な長さのシーケンスを表します`k`。 
5. すべての位置を処理した後、次のすべての値を合計します。`dp`有効な長さのシーケンスの総数を取得するには`n`。 

この遷移の背後にある重要な考え方は、各シーケンスは最後の要素によって一意に決定され、すべての有効な拡張は最後の 2 つの要素が互いに素であるかどうかのみに依存するということです。 

### なぜ効果があるのか

 あらゆる段階で`k`、配列`dp`有効な長さのシーケンスの数を正確に格納します`k`それぞれの可能な値で終わります。 すべての長さのシーケンスのため、トランジションは正確さを維持します。`k`で終わる`j`有効な長さのシーケンスから取得する必要があります`k-1`いくつかで終わる`i`どこ`gcd(i, j) = 1`。 各シーケンスには一意の最後の要素があり、すべての有効な先行要素が合計に 1 回だけ含まれるため、シーケンスが二重にカウントされることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

n, m = map(int, input().split())

# precompute coprimality
ok = [[False] * (m + 1) for _ in range(m + 1)]
for i in range(1, m + 1):
    for j in range(1, m + 1):
        if gcd(i, j) == 1:
            ok[i][j] = True

dp = [0] * (m + 1)
for i in range(1, m + 1):
    dp[i] = 1

for _ in range(n - 1):
    ndp = [0] * (m + 1)
    for i in range(1, m + 1):
        if dp[i] == 0:
            continue
        for j in range(1, m + 1):
            if ok[i][j]:
                ndp[j] = (ndp[j] + dp[i]) % MOD
    dp = ndp

print(sum(dp[1:]) % MOD)
```この実装は DP 定義を直接ミラーリングします。 の`ok`遷移が繰り返し計算されないように、テーブルには共素性が格納されます。`gcd`。 DP 配列は、値を自然な範囲に揃えるために 1 からインデックスが付けられます。`1..m`、オフバイワンの混乱を避けます。 

主な微妙な点は、シーケンスの数が指数関数的に増加するため、すべての累積ステップでモジュロが適用されるようにすることです。`n`。 もう 1 つの重要な詳細は、すべての値を初期化することです。`dp`に`1`これは、すべての単一の数値が有効な長さ 1 のシーケンスを形成するという事実に対応します。 

## 実用的な例

 ### 例 1

 入力:```

```ペアを数えます`(a1, a2)`の値を持つ`1..5`そしてgcdは次と等しい`1`。 

初期化します:

 | ステップ | dp[1] | dp[2] | dp[3] | dp[4] | dp[5] |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 1 | 1 | 1 | 1 | 1 |

 長さ 2 への移行:

 それぞれについて`j`、すべてを合計します`i`そのような`gcd(i, j) = 1`。 

たとえば、`j = 2`、有効な先行者は次のとおりです。`1, 3, 5`。 

| j | 有効な i | ndp[j] |
 | --- | --- | --- |
 | 1 | 1、2、3、4、5 | 5 |
 | 2 | 1,3,5 | 3 |
 | 3 | 1、2、4、5 | 4 |
 | 4 | 1,3,5 | 3 |
 | 5 | 1、2、3、4 | 4 |

 最終的な答えは、`5 + 3 + 4 + 3 + 4 = 19`。 

このトレースは、カウントが値の一様な分布ではなく、完全に互いに素な隣接関係によって駆動されていることを示しています。

def run(inp: str) -> str:

    MOD = 998244353

    def gcd(a, b):

            a, b = b, a % b
        return a

    n, m = map(int, input().split())

    for i in range(1, m + 1):
        for j in range(1, m + 1):
            if gcd(i, j) == 1:

    dp = [0] * (m + 1)

        dp[i] = 1

    for _ in range(n - 1):

    return str(sum(dp[1:]) % MOD)

 ## 特殊なケース

 いつ`m = 1`、DP には州が 1 つだけあります。 アルゴリズムが初期化されます`dp[1] = 1`トランジションを繰り返し適用します。 以来`gcd(1,1) = 1`、すべての遷移がカウントを保持するため、その後`n`ステップ、答えは残っています`1`、唯一可能なシーケンスと一致します`[1,1,...,1]`。 

いつ`n = 1`の場合、遷移ループは実行されません。 このアルゴリズムは、初期 DP 配列の合計を直接返します。`m`。 これは、すべての値が長さ 1 の有効なシーケンスを形成するという事実と一致します。 

すべての値を考慮すると、次のような高度に合成された数値であっても、隠れた制限は表示されません。`12`または`60`共素性はヒューリスティックや近似によってではなく、ペアごとに適用されるため、正しく処理されます。
