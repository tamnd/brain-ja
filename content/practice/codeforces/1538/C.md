 ## 解決策
 ## 問題の理解

 整数の配列と 2 つの値で定義された範囲が与えられます。`l`そして`r`。 タスクは、個別のインデックスのすべてのペアをカウントすることです。`(i, j)`これらのインデックスの要素の合計が、境界を含む指定された範囲内に収まるようにします。 言い換えれば、ペアの数が必要です`(i, j)`どこ`i < j`そして`l ≤ a[i] + a[j] ≤ r`。 

入力は複数のテスト ケースで構成されます。 テストケースごとに、配列のサイズを取得します。`n`、下限と上限`l`そして`r`、および配列自体。 出力は、各テスト ケースの条件を満たすペアの数です。 

制約は非常に重要です。 と`n`テスト ケースごとに最大 2 · 10^5 と合計`n`最大 2・10^5 のテスト ケースでも、O(n²) アルゴリズムでは、最悪の場合、10^10 のオーダーの演算が必要になります。これは、2 秒で実行できる演算をはるかに超えています。 安全のためには、O(n log n) に近いアルゴリズムが必要です。 配列内の値と境界は 10^9 まで大きくなる可能性があるため、値による配列のインデックス付けや、数値の大きさに応じてスケーリングする頻度配列に依存する手法は避けなければなりません。 

エッジ ケースには、すべての値が等しい配列、範囲を満たすペアがない配列、境界の周囲に多数のペアが集まっている配列が含まれます。`l`そして`r`。 たとえば、`a = [1, 1, 1]`そして`l = 5, r = 6`、条件を満たすペアがないため、正しい出力は 0 です。単純な実装ではチェックを忘れる可能性があります。`i < j`ペアを二重にカウントするか、無効な合計を含めます。 

## アプローチ

 ブルートフォースアプローチは簡単です。すべてのペアを反復処理します。`(i, j)`と`i < j`合計が次の範囲内にあるかどうかを確認します`l`そして`r`。 これは、考えられるすべてのペアを明示的に検査するため、正しいことが保証されていますが、テスト ケースごとに O(n²) 時間が必要です。 のために`n`2・10^5 に近い場合、最悪の場合、およそ 2・10^10 回の反復となり、これは実行不可能です。 

最適なソリューションを見つけるための重要な洞察は、すべてのペアを個別に調べる必要がないということです。 配列をソートすると、固定要素の場合`a[i]`、問題は要素の数を数えるということになります。`a[j]`と`j > i`満足する`l - a[i] ≤ a[j] ≤ r - a[i]`。 配列はソートされているため、有効な`a[j]`は連続したセグメントを形成します。 これにより、二分探索を使用して、有効な左端と右端を効率的に見つけることができます。`a[j]`s、要素あたりの有効なペアの数を O(log n) で示します。 合計の複雑さは O(n log n) になり、制約の下では許容されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 遅すぎる |
 | ソート + 二分探索 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を昇順に並べ替えます。 ペアカウントに二分探索を効率的に適用するには、ソートが必要です。 
2. 変数を初期化する`count`ゼロに。 これにより、有効なペアの数が累積されます。 
3. インデックスごとに`i`0 から n - 2 まで、考慮してください`a[i]`ペアの最初の要素として。 2 番目の要素は次の条件を満たす必要があります`l - a[i] ≤ a[j] ≤ r - a[i]`と`j > i`。 
4. 使用する`bisect_left`インデックスを見つけるには`left`最初の要素の`a[j]`以上のソートされた配列内`l - a[i]`、から始まる部分配列内を検索します。`i + 1`。 
5. 使用する`bisect_right`インデックスを見つけるには`right`最初の要素が厳密に次より大きい`r - a[i]`、で始まる部分配列にもあります`i + 1`。 
6. この有効なペアの数`i`は`right - left`。 これを追加`count`。 
7. すべての処理が完了したら`i`、`count`有効なペアの総数が含まれます。 出力してください。 

機能する理由: 並べ替えにより、それぞれの`i`、候補者全員`a[j]`と`j > i`は昇順です。 有効な連続プロパティ`a[j]`内にある`[l - a[i], r - a[i]]`二分検索により、要素が欠落したり二重にカウントされたりすることなく、正確な範囲が検索されます。 全体をまとめると`i`すべてのペアをカバーします`i < j`。 

## Python ソリューション```python
import sys
import bisect
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, l, r = map(int, input().split())
        a = list(map(int, input().split()))
        a.sort()
        count = 0
        for i in range(n - 1):
            left = bisect.bisect_left(a, l - a[i], i + 1)
            right = bisect.bisect_right(a, r - a[i], i + 1)
            count += right - left
        print(count)

if __name__ == "__main__":
    solve()
```並べ替えステップでは、効率的なバイナリ検索のために配列を準備します。 ループにより、次のペアのみがカウントされることが保証されます。`i < j`。`bisect_left`そして`bisect_right`と正確に等しい合計を含む境界条件を正しく処理します。`l`または`r`。 から探す`i + 1`ペアを数えることを防ぎます。`j ≤ i`。
