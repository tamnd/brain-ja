 ## 問題の理解

 最小の整数を見つけるように求められます$m \ge n$以下のすべての数値のビット単位の AND が得られます。$n$に$m$指定された数値に等しい$x$。 正式には、私たちが望んでいるのは、$n \& (n+1) \& \dots \& m = x$。 各テスト ケースでは 2 つの数値が得られます。$n$そして$x$そして、最小値を計算する必要があります。$m$または報告する$-1$そうでない場合$m$存在します。 

入力境界は非常に大きいです。$n$そして$x$まで行くことができます$10^{18}$。 これにより、次のすべての数値を反復するアプローチが可能になります。$n$反復回数が最大になる可能性があるため、それ以上は実行不可能です。$10^{18}$。 したがって、各数値を順番にチェックするのではなく、ビット レベルまたは AND の数学的特性で問題を推論する必要があります。 

エッジケースは微妙です。 たとえば、次の場合$x > n$、で始まるシーケンスの AND であるため、それに到達できません。$n$1 を 0 に変えることはできますが、0 を 1 に変えることはできません。 もう 1 つのエッジケースは次のような場合です$x = n$、この場合、最小限の$m$は$n$自体。 最後に、上位ビットを変更せずに特定のビットをゼロにする必要があるシーケンスは、追加する数値が小さすぎると保持したいビットが破壊される可能性があるため、注意が必要です。 

## アプローチ

 ブルートフォースアプローチは単純にすべてを試します$m \ge n$そして計算します$n \& (n+1) \& \dots \& m$等しくなるまで$x$。 これは原理的には正しいですが、入力が大きい場合は実行できません。 10^6 の数値の狭い範囲であっても、単純な解決策ではすでに遅すぎます。$t = 2000$テストケース。 

重要な洞察は、ビットごとの AND がどのように動作するかを理解することから得られます。 から始まる連続する数字を AND すると、$n$の場合、AND 結果には、範囲内のすべての数値が 1 を共有する位置にのみ 1 が含まれます。$x$位置に 1 があります。$n$0があるので取得する方法はありません$x$なぜなら、AND では新しいビットを 1 に設定できないからです。$n$の位置に 1 があります$x$が 0 であるため、最小値を見つける必要があります$m$これらの 1 は、その位置にゼロが含まれる数値に達すると「オフ」になります。 これにより、ビットを慎重に操作して目的を達成するという問題が軽減されます。$x$。 

この問題は、各ビットを最低位から最高位まで処理し、最小値を構築しようとすることで解決できます。$m$それはビットをゼロにします。$x$は 0 ですが、上位ビットには影響しません。 これには、ビットマスク操作に基づく貪欲なアプローチが含まれます。

 ## アルゴリズムのチュートリアル

 1.次のことを確認します$n = x$。 もしそうなら、$m = n$単一の数値の AND はそれ自体に等しいため、これは最小の解です。 
2. 次のことを確認します。$x > n$。 もし$x$位置に 1 があります。$n$が 0 の場合、AND シーケンスは決して到達できません$x$、だから戻ってください$-1$。 
3. のビットを計算します。$n$それは 1 です$x$これらは、選択して「オフにする」必要があるビットです。$m$それは、それらのビットがクリアされる次の番号に達します。 変数を初期化する`candidate_m`に`n`。 
4. 最下位ビットから開始して、各ビットに対して上に移動します。`n`1 と`x`0 があり、増分します`candidate_m`下位ビットをゼロに保ちながら、このビットをゼロに反転する最小の数に設定します。 これは次を使用して実行できます`candidate_m |= (1 << bit)`最初の違反ビットを検出し、下位ビットをすべてクリアします。 
5.施工後`candidate_m`、全範囲の AND が成り立つことを確認します。`n`に`candidate_m`等しい`x`。 そうなった場合、これが最小限の解決策です。 それ以外の場合は出力$-1$。 
6. 計算された値を返します`candidate_m`。 

機能する理由: このアルゴリズムは、連続する整数にわたる AND の単調特性を利用します。 結果内の 0 のビットは、最終的にシーケンス内の何らかの数値で 0 に設定される必要があります。 必要なビットをゼロにする最初の数値を貪欲に設定することで、最小性を確保します。 この検証により、予期せぬキャリーオーバーが上位ビットに影響を与えないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x = map(int, input().split())
        if n == x:
            print(n)
            continue
        if x > n:
            print(-1)
            continue
        
        m = n
        valid = True
        for i in range(60):
            n_bit = (n >> i) & 1
            x_bit = (x >> i) & 1
            if n_bit == 1 and x_bit == 0:
                # we need to flip this bit to zero
                m |= (1 << i)
                m &= ~((1 << i) - 1)  # clear lower bits
        # Verify
        cur = n
        result = n
        while cur < m:
            result &= cur
            cur += 1
        result &= m
        if result == x:
            print(m)
        else:
            print(-1)

if __name__ == "__main__":
    solve()
```コードはまず、次のような簡単なケースを処理します。`n = x`または`x > n`。 次に、最小限のものを構築します`m`下位ビットをできるだけ小さく保ちながら、ゼロになる必要がある各ビットを強制的に反転させることによって。 最後に、AND シーケンスを検証して正確さを保証します。
