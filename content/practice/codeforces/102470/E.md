 ## 解決策
 ## 問題の理解

 DNA は環状配列であり、すべてのヌクレオチド タイプが正確に 2 回出現しますが、その 2 つの出現は次のように同じ面を持つ場合があります。`a ... a`、または反対の面、など`a ... A`。 

ペアを削除する前にシーケンスを再配置できるため、手術は複雑に見えます。 重要なのは、これらの手術を実際に再現する必要がないということです。 円形の単語全体は、閉じた曲面の記述として見ることができます。 各ヌクレオチドのペアは、多角形の 2 つのエッジがどのように接着されているかを示し、必要な腕または脚の数はまさにその表面のトポロジカル タイプになります。 

境界が入力文字列である多角形を取得します。 すべての文字は多角形の 1 つの端を表し、同じヌクレオチドが 2 つ出現する場合は結合されます。 2 つの出現が同じ面を持っている場合、ポリゴン境界に沿った方向が一致するため、それらの端点は同じ順序で識別されます。 面が異なる場合、方向が一致しないため、端点は逆の順序で識別されます。 

すべてのエッジのペアが接着された後は、1 つの面があり、正確に`n / 2`エッジ、どこ`n`文字列の長さです。 オイラー特性に必要な残りの数量は、すべての端点を識別した後の個別の頂点の数だけです。 

素集合共用体構造を使用してその数値を見つけることができます。 連続する文字のペアごとに頂点を 1 つ作成し、次のようにします。`n`初期頂点。 すべてのヌクレオチド ペアについて、2 つの面が等しいか異なるかに従って、適切なエンドポイントを結合します。 DSU コンポーネントの数が最終的な頂点の数になります。`V`。 

オイラー特性は次のようになります。 

[
 \chi = V - E + F
 ]

 と

 [
 E = \frac n2,\qquad F=1。 
]

 閉じた接続サーフェスには、方向付け可能なサーフェスと方向付け不可能なサーフェスの 2 つのタイプが考えられます。 方向付け可能なサーフェス`g`ハンドルは持っています

 [
 \chi = 2 - 2g、
 ]

 それで

 [
 g = 1-\frac{\chi}{2}。 
]

 方向付け不可能なサーフェス`k`クロスキャップは

 [
 \chi = 2-k、
 ]

 それで

 [
 k = 2-\chi。 
]

 これらはまさに、それぞれ脚と腕で表される 2 つの量です。 これは、オイラー特性と配向性による閉曲面の標準的な分類です。 

入力の長さは最大 52 であるため、`O(n^2)`または`O(n^3)`絶対的には解は小さくなります。 ここでの有用な観察はより強力です。問題を頂点の識別に変換した後、`O(n)`労働組合が必要です。 潜在的に膨大な数のカットアンドペーストシーケンスをシミュレートする理由はありません。 

直接シミュレーションや不正確なポリゴン解釈が失敗する可能性があるいくつかのエッジ ケースがあります。 のために`aA`、2 つの反対側の面はすぐにキャンセルされるため、答えは次のようになります。`none`。 すべてのペアを端に寄与するものとして扱う方法では、1 つが誤って報告されてしまいます。 

のために`aa`、手術 2 によって 2 つの等しい面を除去でき、1 つの腕に貢献します。 正しい結果は`1 arm`。 これは、オイラー特性 1 を持つ方向付け不可能な曲面の最も単純な例でもあります。 

のために`abAB`、手術 3 では、円形シーケンス全体が削除され、1 本の脚が提供されるため、答えは次のようになります。`1 leg`。 重要な詳細は、`a`そして`A`同じヌクレオチドペアに属しますが、`b`そして`B`もう一方のペアを形成します。 大文字と小文字を異なるヌクレオチドタイプとして扱うと、この減少は完全に見逃されてしまいます。 

循環的な隣接性も重要です。 のために`aBAb`、配列は 2 つのヌクレオチド タイプを交互にし、両方のペアが反対の面を持ちます。 手術 3 は円形の境界の周囲に適用され、`1 leg`。 内部部分文字列のみをチェックする線形のみの実装では、このケースは見逃されます。 

## アプローチ

 直接的なアプローチは、手術をシミュレーションすることです。 手術 1、2、または 3 が利用可能な場合は常に、対応する文字を削除し、適切なカウンターを更新します。 利用可能なものがない場合は、考えられるすべてのカット アンド ペースト操作を試し、別の縮小手術が可能になる構成を再帰的に検索します。 

このアプローチは正しいです。許可されたすべての手術で最終的な生物学的結果が保存され、最終結果が選択された一連の手術から独立していることが保証されているからです。 問題は検索スペースです。 ヌクレオチドごとにカット アンド ペースト操作を試みることができ、さまざまな選択により、長さを減らすことなく多くの異なる環状文字列を作成できます。 中間構成の繰り返しを考慮する前であっても、可能な文字列の数は階乗的に増加します。 26 種類のヌクレオチドが 2 回現れるため、固定ペアによる直線状配列の数は

 [
 \frac{52!}{(2!)^{26}},
 ]

 循環シーケンスの回転を考慮する前に。 それは 1 秒以内に数えられるものをはるかに超えています。 公式ソリューションの議論では、カットアンドペースト状態に対する浅い幅優先検索でもタイムアウトになる可能性があることも指摘しています。 

より高速な解決策を明らかにする観察は、操作が実際には文字列のテキスト表現に関するものではないということです。 これらは、ペアのエッジによってエンコードされたトポロジカル サーフェスを保存します。 手術 1、手術 2、手術 3、およびカット アンド ペーストは、同じサーフェスを単純化するための異なる方法です。 したがって、最終的な腕または脚の数は、オイラー特性と配向性によって決まります。 

文字列がペアのエッジを持つ多角形として解釈されると、オイラー特性の計算は簡単になります。 常に 1 つの面があり、ヌクレオチドのペアごとに 1 つのエッジがあり、頂点の数はポリゴンの境界頂点間の等価クラスの数と正確に一致します。 これらの等価クラスは、まさに DSU が維持するように設計されているものです。 

方向性はさらに簡単です。 すべてのヌクレオチドが各面に 1 回出現する場合、表面は正確に配向可能です。 一部のペアが同じ面を 2 回使用する場合、対応するエッジの接着によってサーフェスの方向が反転され、方向付けできなくなります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 階乗スケール、最大 (O(52! / 2^{26})) 状態 | 探索空間における指数 | 遅すぎる |
 | 最適 | (O(n \alpha(n))) | (O(n)) | 承認済み |

 この数学的解決策は、公式の SWERC ソリューション アウトラインで強調されているアプローチでもあり、文字列を閉曲面をエンコードしているものとして説明し、そのオイラー特性を次から計算することを推奨しています。`V - E + F`。 

## アルゴリズムのチュートリアル

 1. しましょう`n`DNA 文字列の長さになります。 作成する`n`番号付きの頂点`0`を通して`n-1`。 頂点`i`文字の直前の点です`i`、だから性格`i`頂点からのエッジです`i`頂点へ`(i + 1) mod n`。 
2. すべてのヌクレオチド タイプの 2 つの位置を特定します。 元のキャラクターを比較すると、2 つの顔が等しいかどうかがわかります。 各ヌクレオチドを一度処理するだけで済みます。 
3. ヌクレオチドが次の位置にあると仮定します。`p`そして`q`同じ顔で。 2 つの対応するエッジはポリゴンの周囲を同じ方向に横断するため、それらの端点は同じ順序で識別されます。 実行する`union(p, q)`そして`union(p + 1, q + 1)`、両方のインデックスを法として取得します`n`。 

これは、等しい面のペアに対応するエンドポイントの識別です。 
4. 2 つの出現が反対の面を持っていると仮定します。 ポリゴンの境界に沿ったそれらの方向は反対であるため、一方のエッジの最初の端点は、もう一方のエッジの 2 番目の端点と識別されます。 実行する`union(p, q + 1)`そして`union(p + 1, q)`、再びモジュロ`n`。 

この反転は、この構造の微妙な部分です。 それを忘れると表面が変わり、答えが変わる可能性があります。 
5. すべてのペアの処理が完了したら、DSU コンポーネントをカウントします。 この番号に電話してください`V`。 ポリゴンが接着された後の各コンポーネントは 1 つの頂点を表します。 
6.セット

 [
 E = n/2
 ]

 すべてのヌクレオチド タイプが 1 つの接着エッジに寄与するため、`F = 1`元のポリゴンは単一の面であるためです。 コンピューティング

 [
 \chi = V-E+1。 
]
 7. すべてのヌクレオチドペアが反対の面を持っているかどうかを確認することにより、配向性を決定します。 1 つのペアでも同じ面を持つ場合、そのサーフェスは方向付けできません。 すべてのペアが反対の面を持っている場合、向きを変えることができます。 
8. 方向付け可能な表面の場合、次のように計算します。 

[
 g=1-\chi/2。 
]

もし`g`がゼロ、表面は球、答えは`none`。 それ以外の場合は出力`g legs`、次の場合に単数形を使用します。`g = 1`。 
9. 方向付け不可能な表面の場合、次のように計算します。 

[
 k=2-\chi。 
]

もし`k`がゼロの場合、四肢はありません。 それ以外の場合は出力`k arms`、ここでも単数形を使用します。 

### なぜ効果があるのか

 不変量は、対になった環状 DNA によってコード化された閉曲面です。 ポリゴン境界は 1 つの面を提供し、各ヌクレオチド ペアは 1 つのエッジを提供し、DSU 識別はどの境界頂点が同じ表面頂点になるかを正確に記述します。 その結果、`V`、`E`、 そして`F`アルゴリズムによって計算され、表面のオイラー特性が得られます。 

手術では、このサーフェスの表現のみが変更されます。 手術 1、2、および 3 は基本部分の削除に対応しますが、カット アンド ペーストでは、下にあるサーフェスを変更せずに多角形の表示を変更します。 最終結果はそのサーフェスによって一意に決定されるため、そのオイラー特性と方向性によって、腕や脚の有無、およびその数を決定するのに十分です。 閉じた曲面の分類式により、必要な数が正確に得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]

def solve_case(s):
    n = len(s)
    dsu = DSU(n)

    positions = [[] for _ in range(26)]

    for i, ch in enumerate(s):
        positions[ord(ch.lower()) - ord('a')].append(i)

    orientable = True

    for pos in positions:
        if not pos:
            continue

        p, q = pos

        if s[p].islower() == s[q].islower():
            orientable = False

            dsu.union(p, q)
            dsu.union((p + 1) % n, (q + 1) % n)
        else:
            dsu.union(p, (q + 1) % n)
            dsu.union((p + 1) % n, q)

    vertices = sum(
        1 for i in range(n)
        if dsu.find(i) == i
    )

    edges = n // 2
    faces = 1
    chi = vertices - edges + faces

    if orientable:
        value = 1 - chi // 2

        if value == 0:
            return "none"
        if value == 1:
            return "1 leg"
        return f"{value} legs"

    value = 2 - chi

    if value == 0:
        return "none"
    if value == 1:
        return "1 arm"
    return f"{value} arms"

def main():
    out = []

    while True:
        s = input().strip()
        if s == "END":
            break
        if s:
            out.append(solve_case(s))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```の`DSU`classはポリゴンの頂点間の同値関係を表します。 パス圧縮により繰り返しが行われる`find`操作は事実上一定時間ですが、サイズによる結合はツリーを浅く保ちます。 

の`positions`配列には、各ヌクレオチド タイプの 2 つの位置が格納されます。 この問題では、使用されるすべてのヌクレオチドが正確に 2 回出現することが保証されるため、空でない各エントリには正確に 2 つの位置が含まれます。 

等しい面のペアの場合、コードは結合します。`p`と`q`そして`(p + 1) mod n`と`(q + 1) mod n`。 これらは、両方のエッジが同じ方向を持つ場合に対応する端点です。 

反対面のペアの場合、端点は交差します。 1 つのオカレンスの最初のエンドポイントがもう 1 つのオカレンスの 2 番目のエンドポイントと結合され、その逆も同様です。 最後の文字の出ていくエッジは頂点で終わるため、モジュロ演算は必須です。`0`。 これがないと、循環ケースで off-by-one エラーが発生します。 

の`orientable`flag は true として開始され、ヌクレオチドが同じ面で 2 回出現するとすぐに false になります。 配置の他のプロパティは配向性に影響しません。 

すべての結合の後、DSU ルートをカウントすると、最終的な頂点の数が得られます。 エッジの数は`n // 2`、 ない`n`1 つのヌクレオチドが 2 回出現すると、1 つの接着エッジが形成されるためです。 開始オブジェクトは単一のポリゴンであるため、面は 1 つだけ存在します。 

式では整数演算が使用されます。 方向付け可能なサーフェスの場合、`chi`必ず偶数なので、`1 - chi // 2`が正しい属です。 Python の整数を使用すると、オーバーフローの心配もなくなりますが、ここでの最大値は非常に小さいです。 

コードは、次の時点まですべてのテスト ケースを処理します。`END`、入力形式の要求に応じて。 

## 実用的な例

 ### サンプル 1:`rkrk`ヌクレオチドには2種類あり、`r`そして`k`、両方のペアが同じ顔を使用します。 

| ペア | ポジション | 顔関係 | DSU組合 | コンポーネント |
 | --- | --- | --- | --- | --- |
 |`r`| 0、2 | 同じ |`0~2`、`1~3`| 2 |
 |`k`| 1、3 | 同じ |`1~3`、`2~0`| 2 |

 両方のペアを処理した後、4 つのポリゴン頂点が 2 つの同値クラスを形成します。 したがって、

 [
 V=2、\qquad E=2、\qquad F=1
 ]

 そして

 [
 \chi=2-2+1=1。 
]

 少なくとも 1 つのペアは等しい面を持っているため、サーフェスは方向付けできません。 クロスキャップの数は

 [
 2-\カイ=1。 
]

 出力は`1 arm`。 

この例は、等しい面のペアの 2 つの端点を同じ順序で結合する必要がある理由を示しています。 また、方向付け不可能な表面が奇数のオイラー特性を持つ可能性があることも示しています。 

### サンプル 2:`abcdeABCDE`すべてのヌクレオチドは小文字で 1 回、大文字で 1 回出現するため、表面は方向付け可能です。 

| ペア | ポジション | 顔関係 | 主要な DSU 組合 |
 | --- | --- | --- | --- |
 |`a`| 0、5 | 反対 |`0~6`、`1~5`|
 |`b`| 1、6 | 反対 |`1~7`、`2~6`|
 |`c`| 2、7 | 反対 |`2~8`、`3~7`|
 |`d`| 3、8 | 反対 |`3~9`、`4~8`|
 |`e`| 4、9 | 反対 |`4~0`、`5~9`|

 結合により 2 つの頂点コンポーネントが生成されます。 したがって、

 [
 V=2、\qquad E=5、\qquad F=1、
 ]

 与える

 [
 \chi=2-5+1=-2。 
]

 サーフェスは方向を変えることができるため、

 [
 g=1-\frac{-2}{2}=2。 
]

 結果は`2 legs`。 

このトレースは、ペアの順序が頂点の識別、したがってオイラー特性に影響を与えることを示しています。 存在するヌクレオチドの種類を数えるだけでは十分ではありません。 

### サンプル 3:`shcoOCfFHS`すべてのヌクレオチドのペアは反対の面を持っているため、表面は配向可能です。 同じ DSU 構造を適用すると、6 つの頂点コンポーネントが生成されます。 5つのエッジがあり、

 [
 \chi=6-5+1=2。 
]

 オイラー特性 2 の配向可能な曲面は属数 0 を持ち、これは球です。 したがって、端はなく、出力は次のようになります。`none`。

import sys
import io

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]

def solve_case(s):
    n = len(s)
    dsu = DSU(n)

    positions = [[] for _ in range(26)]

    for i, ch in enumerate(s):
        positions[ord(ch.lower()) - ord('a')].append(i)

    orientable = True

    for pos in positions:
        if not pos:
            continue

        p, q = pos

        if s[p].islower() == s[q].islower():
            orientable = False
            dsu.union(p, q)
            dsu.union((p + 1) % n, (q + 1) % n)
        else:
            dsu.union(p, (q + 1) % n)
            dsu.union((p + 1) % n, q)

    vertices = sum(
        1 for i in range(n)
        if dsu.find(i) == i
    )

    edges = n // 2
    chi = vertices - edges + 1

    if orientable:
        value = 1 - chi // 2
        if value == 0:
            return "none"
        if value == 1:
            return "1 leg"
        return f"{value} legs"

    value = 2 - chi
    if value == 0:
        return "none"
    if value == 1:
        return "1 arm"
    return f"{value} arms"

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = []

    while True:
        s = sys.stdin.readline().strip()
        if not s or s == "END":
            if s == "END":
                break
            continue
        out.append(solve_case(s))

    return "\n".join(out)

 ## 特殊なケース

 のために`aA`、ポリゴンの頂点が 2 つあります。 2 つのオカレンスは反対の面を持っているため、端点は逆の順序で接着されます。 両方の頂点は区別されたままとなり、`V=2`。 以来`E=1`そして`F=1`、私たちは得ます`χ=2`。 サーフェスは方向付け可能であり、その属数はゼロです。 出力は`none`を除去する直接手術に一致します。`aA`。 

のために`aa`、どちらの出現も同じ面を持ちます。 最初のエッジは頂点 0 から頂点 1 に進み、2 番目のエッジは頂点 1 から頂点 0 に戻ります。同次エンドポイント識別では 2 つの頂点がマージされます。`V=1`。 と`E=1`そして`F=1`、オイラー特性は次のとおりです。`1`。 サーフェスは向きを変えることができないため、`2-1=1`アーム。 これは手術 2 と完全に一致します。 

のために`aBbA`、二人`a/A`二つの現象は反対の面を持ちます。`b/B`出来事。 文字列は円の周囲で 2 つのヌクレオチド タイプを交互に配置するため、手術 3 が適用され、1 つの脚に寄与します。 DSU 表現では、4 つのポリゴン頂点が 1 つのコンポーネントに折りたたまれます。 したがって、`V=1`、`E=2`、 そして`F=1`、与える`χ=0`。 すべてのペアは反対の面を持っているため、表面は方向付け可能で属数 1 を持ち、結果は次のようになります。`1 leg`。 

最大サイズの文字列の場合`aabbccddeeffgghhiijjkkllmmnnooppqqrrssttuuvvwwxxyyzz`、すべてのヌクレオチドのペアは同じ顔を持っています。 各ヌクレオチドの隣接するペアは連続するポリゴン頂点を識別し、一連の識別により最終的に 52 個の頂点すべてが 1 つのコンポーネントにマージされます。 したがって`V=1`そして`E=26`、与える

 [
 \chi=1-26+1=-24。 
]

 サーフェスは向きを変えることができないため、アームの数は次のようになります。 

[
 2-(-24)=26。 
]

 これは手術の解釈とも一致します。なぜなら、すべての隣接する等しいペアは手術 2 で直接除去でき、26 種類のヌクレオチドのそれぞれに 1 つのアームが寄与するからです。
