 ## 解決策
 ## 問題の理解

 墓地は長方形の格子状になっており、`W * H`細胞。 ジョンはから始めます`(0, 0)`そして到達したい`(W - 1, H - 1)`。 1 つのセルから隣接するセルまでの通常の歩行には、ちょうど 1 秒かかります。 一部の房は墓石で塞がれており、中に入ることができません。 

お化けの穴は、特定の 1 つのセルのルールを変更します。 ジョンが穴に入っても、隣接する独房には進みません。 代わりに、彼は指定された目的地のセルに即座に転送され、経過時間がホールに指定された値になります。`T`。 以来`T`ネガティブかもしれないが、穴があればジョンは過去に飛ばされる可能性がある。 

これは、有向重み付きグラフとして自然に表すことができます。 使用可能なすべてのセルが頂点です。 通常の動きは、重量の方向性のあるエッジを作成します`1`一方、ホーンテッド ホールは、重みを付けて原点から目的地まで 1 つの有向エッジを作成します。`T`。 John は出口に到達するとすぐに停止するため、出口には出力エッジがありません。 

入力にはいくつかの墓地が含まれています。 それぞれについて、グリッドの寸法、墓石の位置、幽霊の出る穴を受け取ります。 穴の起源は独特で、入り口も出口も墓石でも穴でもありません。 

考えられる結果は 3 つあります。 出口にたどり着けない場合の答えは、`Impossible`。 ジョンが入り口から負の時間サイクルに到達できれば、そのサイクルを繰り返し横断して到達時間を際限なく短縮できるため、答えは次のようになります。`Never`。 それ以外の場合、答えは入口から出口までの最短移動時間になります。 

グリッドは最大でも`30 * 30`, したがって、最大でも`900`細胞。 これはアルゴリズムとしては十分小さい`O(VE)`、 どこ`V`はセルの数であり、`E`可能な動きと穴の数です。 ここでは、グリッド サイズに関する 2 次または 3 次アルゴリズムも実行可能ですが、可能なパスに対する指数関数的な検索は実行できません。 時間値は次のように小さくすることができます。`-10000`したがって、通常のダイクストラなど、非負のエッジ重みを必要とする最短パス アルゴリズムは適用できません。 

いくつかの詳細により、本来の実装が失敗する可能性があります。 

1 セルの墓地を考えてみましょう。```
1 1
0
0
0 0
```入口と出口は同じ独房なので、ジョンはすでに出口に到着しています。 正しい答えは、`0`。 少なくとも 1 つの動きが必要であると想定する実装では、誤って報告される可能性があります。`Impossible`。 

ホールは負の時間を持ち、すでに訪問したセルを指すことができます。 例えば：```
2 2
0
1
1 0 0 0 -3
0 0
```穴自体は、この特定のグリッドで負のサイクルを作成するのに十分ではありません。その原点に到達するのにすでに 1 秒のコストがかかっているためです。ただし、到達可能なルートが合計の負のコストで穴の原点に繰り返し戻ることができる場合、答えは次のようになります。`Never`。 負のサイクルを認識せずに単に距離を緩和し続ける最短パス アルゴリズムでは、値を永久に減少させ続ける可能性があります。 

負のサイクルも出口につながる必要はありません。 たとえば、入口が総コストのループに到達できると仮定します。`-1`一方、出口は別の場所にあり、そのループからは到達できません。 答えはまだです`Never`なぜなら、問題はジョンが無限に時間を遡ることができるかどうかを問うものであり、そのようなサイクルが出口への成功したルート上にあるかどうかを問うものではないからである。 出口にも到達できる負のサイクルのみを検索する実装では、間違った結果が得られます。 

最後に、ホール セルは通常の歩行セルとして扱うこともできません。 セルに穴がある場合、そこに入ると、ジョンはすぐに別の場所に転送されます。 そのセルから通常の 4 方向の移動を許可すると、実際の墓地には存在しないエッジが作成されます。 

## アプローチ

 直接的な総当りアプローチでは、入り口から考えられるパスを列挙し、その累積時間を追跡します。 通常のセルごとに最大 4 つの選択肢があるため、パスの長さは`L`いくつでも生成できます`4^L`可能性。 人工的に停止した場合、これはすでに膨大なものになります`900`動きます:`4^900`おおよそです`10^541`可能な散歩。 より基本的には、グラフにはサイクルが含まれる可能性があるため、列挙できる有限の最大パス長はありません。 負のサイクルでは、John が同じセルを任意に何度も再訪問する必要がある場合があります。これは、単純なパスだけを考慮しても、網羅的なパスの列挙を完了することさえできないことを意味します。 

すべての法的ジャーニーは単なるグラフ エッジのシーケンスであり、答えはそれらのシーケンスの中で最小のエッジの重みの合計であるため、ブルート フォースのアイデアは概念的に機能します。 問題は、シーケンスが指数関数的に多くなり、サイクルによって可能なウォークのセットが無限になる可能性があることです。 

有益な観察は、重み付き有向グラフに変換すると、グリッド自体は特別なものではないということです。 通常技には重みがある`1`、一方、穴は負の重みを持つことができます。 したがって、負のエッジをサポートし、到達可能な負のサイクルも検出できる最短パス アルゴリズムが必要です。 

ベルマンフォードがぴったりフィットします。 1 回の完全なリラクゼーション パスの後、もう 1 つのエッジを持つパスを使用して距離を改善できます。 後`V - 1`負のサイクルのない最短パスは頂点を繰り返す必要がないため、すべての最短の単純なパスが考慮されます。 もう 1 回緩和しても到達可能な頂点を改善できる場合は、到達可能な負のサイクルが存在します。 

同じ表現で 3 つの出力すべてを処理します。 出口距離が無限のままの場合は、到達できません。 さらなる緩和が可能であれば、その入り口は負のサイクルに達する可能性があり、その答えは次のとおりです。`Never`。 それ以外の場合は、出口で計算された距離が最小移動時間となります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数関数的、最大`O(4^L)`長さの`L`、サイクルに制限なし |`O(L)`DFS パスの場合 | 遅すぎてサイクルを完全に処理できません。 
| 最適 |`O(VE)`|`O(V + E)`| 承認済み |

 ここ`V <= 900`、 その間`E`せいぜい大まかです`4V + V`したがって、ベルマンフォードは最悪の場合でも数百万回のエッジ緩和のみを実行します。 

## アルゴリズムのチュートリアル

 1. グリッドを読み、すべての墓石にブロックされているマークを付けます。 また、すべての心霊ホールを出発地、目的地、時差ごとに保存します。 入口と出口は使用可能であることが保証されているため、特別な回復は必要ありません。 
2. すべてのグリッド セルに整数の頂点を割り当てます。たとえば次のようにします。`id = y * W + x`。 これにより、エッジを構築するための元の座標を保持しながら、2 次元グリッドを通常のグラフとして処理できます。 
3. すべてのセルについて、それが墓石の場合はスキップします。 また、ジョンは墓地に到達するとすぐに墓地を離れるため、出口もスキップします。そのため、出口からの出口が彼の旅の一部になることはありません。 
4. 現在のセルにホーンテッド ホールが含まれている場合は、そのセルからの有向エッジを 1 つだけウェイト付きでホールの宛先に追加します。`T`。 穴に入るとすぐにジョンが転送されるため、通常の 4 つのウォーキング エッジは追加しません。 
5. それ以外の場合、セルは通常の草です。 4 つの隣接するセルのそれぞれに、重み付きの有向エッジを追加します。`1`隣人がグリッド内にあり、墓石ではない場合。 両方のセルが使用可能な場合は常に両方向に移動できるため、これらの通常のエッジは自然にペアを形成します。 
6. すべての距離を無限大に初期化し、入口距離を次のように設定します。`0`。 この距離は、ジョンが入口からその頂点に到達できる既知の最も早い時間を表します。 
7. までを実行します。`V - 1`ベルマン～フォード間のリラクゼーションパスを完了する。 あらゆるエッジに`(u, v, w)`、 もし`u`到達可能であり、`dist[u] + w < dist[v]`、 アップデート`dist[v]`。 
8. 完全なパスによって更新が行われない場合は、早めに停止します。 この時点では、別のエッジによって到達可能な距離を改善することはできないため、到達可能な負のサイクルが存在しない限り、現在の距離はすでに最終的な距離になります。 パスには何も変更が加えられなかったので、そのようなサイクルは存在しません。 
9. 通常の Bellman-Ford が通過した後、もう一度すべてのエッジをスキャンします。 エッジがその目的地をさらに改善でき、そのソースが到達可能であれば、入口から到達可能な負のサイクルが存在します。 出力`Never`。 
10. 到達可能な負のサイクルが存在しない場合は、出口距離を検査します。 距離が無限である場合は、出口に到達できないことを意味するため、出力`Impossible`。 それ以外の場合は、有限距離を最小移動時間として出力します。 

なぜ機能するのか: Bellman-Ford は、その後の不変条件を維持します。`k`完全なリラクゼーションパス、到達可能なすべてのパスは最大でも`k`エッジが考慮されています。 到達可能な負のサイクルがない場合は、頂点を繰り返さずに最短パスを選択できるため、最大で`V - 1`エッジとそのコストは、それらのパスの後に取得されます。 その後も改善が可能である場合は、対応するパスに繰り返し頂点が含まれている必要があり、繰り返し部分の合計重みが負になり、到達可能な負のサイクルが得られます。 緩和条件では有限距離の頂点のみが考慮されるため、入口から到達できないサイクルは必要に応じて無視されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    out = []

    while True:
        W, H = map(int, input().split())
        if W == 0 and H == 0:
            break

        V = W * H

        grave = [False] * V
        G = int(input())

        for _ in range(G):
            x, y = map(int, input().split())
            grave[y * W + x] = True

        holes = {}
        E = int(input())

        for _ in range(E):
            x1, y1, x2, y2, t = map(int, input().split())
            origin = y1 * W + x1
            destination = y2 * W + x2
            holes[origin] = (destination, t)

        edges = []

        for y in range(H):
            for x in range(W):
                u = y * W + x

                if grave[u]:
                    continue

                # John leaves immediately after reaching the exit.
                if x == W - 1 and y == H - 1:
                    continue

                # A hole replaces normal movement from this cell.
                if u in holes:
                    v, t = holes[u]
                    edges.append((u, v, t))
                    continue

                for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    nx = x + dx
                    ny = y + dy

                    if 0 <= nx < W and 0 <= ny < H:
                        v = ny * W + nx

                        if not grave[v]:
                            edges.append((u, v, 1))

        INF = 10**30
        dist = [INF] * V
        start = 0
        finish = V - 1
        dist[start] = 0

        for _ in range(V - 1):
            changed = False

            for u, v, w in edges:
                if dist[u] != INF and dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w
                    changed = True

            if not changed:
                break

        # A further improvement means a reachable negative cycle.
        never = False

        for u, v, w in edges:
            if dist[u] != INF and dist[u] + w < dist[v]:
                never = True
                break

        if never:
            out.append("Never")
        elif dist[finish] == INF:
            out.append("Impossible")
        else:
            out.append(str(dist[finish]))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```の`grave`配列は、グラフと同じ平坦化された頂点番号を使用して、ブロックされたセルを記録します。 平坦化`(x, y)`の中へ`y * W + x`距離配列とエッジの端点を単純な整数にします。 

エッジの構造は最もデリケートな部分です。 通常のセルには最大 4 つのエッジの重みがかかります`1`。 ホールは、指定された時間差により、正確に 1 つのエッジを獲得します。 出口にはまったくエッジがありません。 最後のルールにより、ジョンがすでに墓地を去った後に続く旅をグラフで記述することができなくなります。 

境界チェックでは以下を使用します。`0 <= nx < W`そして`0 <= ny < H`、そのため、動きがグリッドの端を越えることはありません。 ホールの宛先は、別のホールの起点を含む任意の非墓セルである可能性があり、構造はそれを自然に処理します。 

Bellman-Ford 距離配列は、浮動小数点無限大ではなく、大きな有限センチネルを使用します。 Python の整数には任意の精度があるため、負の値がオーバーフローすることはありません。 到達可能性チェック`dist[u] != INF`も不可欠です。 これがないと、到達不可能な負のサイクルが人為的な無限値を改善しているように見え、誤って生成される可能性があります。`Never`。 

最後の緩和パスは、出口に向かうエッジだけでなく、すべてのエッジにわたって実行されます。 これは意図的なものです。 答えは到達可能な負のサイクルで十分です。`Never`たとえジョンがそのサイクルから出口まで移動できなかったとしても。 

## 実用的な例

 ### サンプル 1

 最初の墓地は、`3 x 3`墓石のあるグリッド`(2, 1)`そして`(1, 2)`。 穴はありません。 

関連するベルマン-フォード状態は次のように発展します。 正確な緩和順序は、パス内で距離がいつ現れるかに影響を与える可能性がありますが、最終的な距離はその順序とは無関係です。 

| パス | 有限距離の到達可能なセル | 出口`(2,2)`|

 ## 特殊なケース

 の`1 x 1`この場合は、入口の距離をゼロに設定し、出ていくエッジを構築するときに出口をスキップすることで処理されます。 出口は入口と同じ頂点なので、`dist[finish]`すぐにです`0`。 アルゴリズムの出力`0`リラックスを必要とせずに。 

到達可能な負のサイクルについては、次のことを考慮してください。```

0 0
