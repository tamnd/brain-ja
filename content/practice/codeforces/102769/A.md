 ## 解決策
 # 問題の理解

 この問題では、赤と青のボールの集合について説明します。 がある`r`赤いボールと`b`青いボール、および 2 つのボールが置き換えられることなく均一にランダムに選択されます。 選択した両方のボールが赤である確率を計算し、その確率を小数として出力する必要があります。 出力形式では、各回答の前にケース番号も必要です。 

利用可能なすべてのボールから 2 つのボールを選択する方法の総数は、次のペアの数になります。`r + b`オブジェクト、つまり`C(r+b, 2)`。 好ましい選択肢は、赤いボールのみを含むペアです。`C(r, 2)`。 必要な確率は、これら 2 つの量の比です。 

制約は小さく、各色数は最大 100 で、テスト ケースは最大 10 です。 これは、直接の組み合わせ計算であっても十分に高速であることを意味します。 高度な確率手法や大規模な事前計算は必要ありません。 主な課題はパフォーマンスではなく、分数を切り捨てたり、特殊な値を正しく処理したりする際の間違いを避けることです。 

いくつかのケースでは、誤って対処されやすいものがあります。 赤玉が1個しかない場合、赤玉を2個選ぶことは不可能です。 入力の場合:```
1
1 5
```答えは`Case #1: 0/1`。 不用意に実装すると計算される可能性があります`1 * 0 / 2 = 0`正しくは正しいですが、削減された分母は依然として正で非ゼロでなければならないことを忘れてください。 

もう 1 つのケースは、すべてのボールが赤である場合です。 入力の場合:```
1
5 0
```考えられるすべてのペアが赤であるため、確率は正確に 1 です。 縮小された答えは次のようになります。`1/1`のようなものではありません`10/10`。 

最後のよくある間違いは、順序のないペアの代わりに順序付きの選択を使用することです。 例えば：```
1
2 1
```有利なペアが 1 つ、赤いボールが 2 つ、合計 3 つのペアがあります。 答えは`1/3`。 順序付けられたドローをカウントすると、`2 / 6`これは数学的には等しいですが、出力前に適切な縮小が必要です。 

## アプローチ

 直接的なアプローチは、可能なペアの数と成功したペアの数を数えることです。 2 つのオブジェクトを選択すると順序は無視されるため、選択の合計数は次のようになります。$$\binom{r+b}{2}=\frac{(r+b)(r+b-1)}{2}$$成功した選択は次のとおりです。$$\binom{r}{2}=\frac{r(r-1)}{2}$$確率は、最初の値を 2 番目の値で割ったものです。 入力値が小さいため、この方法はすでに最適です。 総当たりシミュレーションでは、すべてのボールのペアを試し、両方が赤であるかどうかを確認し、結果をカウントすることができます。 それはまだ正しいですが、不必要な作業が発生します。 200 個のボールの場合、すべてのペアをチェックすることは、テスト ケースごとに約 20,000 回の操作を意味します。これはここでは許容されますが、数学的構造は無視されます。 

すべてのペアの可能性が等しいという観察により、シミュレーションをカウントに置き換えることができます。 有利なペアの数と合計ペアがわかれば、確率はほんの一部になります。 分子と分母を最大公約数で割るだけで、必要な既約形式を生成できます。 

ブルート フォースは、すべての可能な選択を直接モデル化するため機能しますが、カウント公式は、すべてのペアの確率が同一であり、可能なペアの数が閉じた形式であるため機能します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((r+b)^2) | お(1) | Accepted for these limits, but unnecessary |
 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取り、ボール カウントの各ペアを個別に処理します。 
2. Compute the number of successful selections. Two red balls can be chosen in`r * (r - 1) / 2`選択したボールの順序は重要ではないためです。 
3. 可能な選択の総数を計算します。 Any two balls among all`r + b`ボールを選択でき、`(r + b) * (r + b - 1) / 2`可能性。 
4. 有利な数と合計数の最大公約数を求めます。 両方の値をこの gcd で割って、端数を減らします。 
5. 必要なケース番号付け形式を使用して、換算された分数を出力します。 

この問題では既約分数が求められるため、gcd による除算が必要です。 分子と分母を同じ値で割った場合、確率自体は変わりません。 

これが機能する理由: 考えられるすべてのボールのペアが選択される確率は同じです。 分子は 2 つの赤いボールを含むペアを正確に数えますが、分母は考えられるすべてのペアを数えます。 それらの比率はまさに必要な確率です。 最大公約数による削減では、分数の表現が変更されるだけであり、その値は変更されないため、最終的な出力は数学的に等価であり、既約となります。 

## Python ソリューション```python
import sys
from math import gcd

input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for case in range(1, t + 1):
        r, b = map(int, input().split())

        numerator = r * (r - 1) // 2
        denominator = (r + b) * (r + b - 1) // 2

        g = gcd(numerator, denominator)
        numerator //= g
        denominator //= g

        ans.append(f"Case #{case}: {numerator}/{denominator}")

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```このソリューションは、計数アプローチに直接従います。`numerator`成功した選択肢の数を保存し、`denominator`考えられるすべての選択肢を保存します。 

結合式には 2 つの連続する値の積が必要であるため、乗算は除算の前に行われます。 値が十分小さいため、Python では整数のオーバーフローは問題になりません。 

gcd 操作は特殊なケースも自然に処理します。 分子がゼロの場合、ゼロの gcd と分母が分母そのものになるため、結果は次のようになります。`0/1`。 分子と分母が等しい場合、gcd は分数を次のように減算します。`1/1`。

## テストケース```python
import sys
import io
from math import gcd

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    result = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return result

def solve():
    input = sys.stdin.readline
    t = int(input())
    out = []

    for case in range(1, t + 1):
        r, b = map(int, input().split())

        num = r * (r - 1) // 2
        den = (r + b) * (r + b - 1) // 2

        g = gcd(num, den)
        out.append(f"Case #{case}: {num // g}/{den // g}")

    print("\n".join(out))

""") == """Case #1: 0/1

""", "samples"

""") == """Case #1: 0/1
""", "one red ball"

""") == """Case #1: 1/1
""", "all red balls"

3 3
""") == """Case #1: 1/5
""", "balanced small case"

""") == """Case #1: 99/398
""", "maximum values"

 ## 特殊なケース

 赤いボールが 1 つだけある場合:```
1
1 5
```アルゴリズムが計算します`1 * 0 / 2 = 0`成功したペア。 ペアの合計数は正なので、分数は次のようになります。`0/6`、そして gcd 削減はそれを次のように変更します`0/1`。 

すべてのボールが赤の場合:```
1
5 0
```有利カウントと合計カウントは両方とも`10`。 gcd は`10`、生産`1/1`。 This avoids printing an unreduced probability.

 For the case where order is incorrectly counted:```
1
2 1
```正しいモデルは順序のないペアをカウントします。 成功したペアが 1 つと合計 3 つのペアがあります。 このアルゴリズムは、最初の赤を描いてから 2 番目の赤を描くことと、2 番目の赤を描いてから最初の赤を描くことを区別しないため、問題で説明されている選択プロセスと一致します。
