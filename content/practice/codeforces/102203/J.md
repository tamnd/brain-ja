 ## 問題の理解

 最大 300 個の交差を持つ有向重み付きグラフがあります。 各誘導道路には正の通過時間があります。 2人のパトロール隊員が交差点で出発`s1`そして`s2`。 

彼らは順序を検査しなければならない`p1, p2, ..., pk`まさにこの順番で。 必要な検査はすべて、いずれかの職員が行うことができます。 警察官が必要な交差点に到着すると、次の検査を開始できます。 警察官は同じ交差点に立つことが許可されており、検査が必要な交差点に警察官がすでにいる場合、検査に移動時間はかかりません。 

タスクは、到達するまでの可能な最小の合計時間を見つけることです。`pk`検査されています。 必要な移行が不可能な場合の答えは次のとおりです。`-1`。 

ステートメント内に隠されている最初のグラフの問題は、最短パスです。 警察官が交差点から移動する必要があるとき`u`交差点まで`v`からの最短の移動時間のみ`u`に`v`重要です。 グラフは方向があるので、からの距離は`u`に`v`必ずしもからの距離ではありません`v`に`u`。 

境界は十分に小さいです`n`すべてのペアの最短経路計算を可能にする`O(n^3)`。 と`n <= 300`、つまり最大 2,700 万回のリラクゼーション操作に相当します。 一方で、`k`は 1000 に達する可能性があるため、必要な交差点ごとに 2 次遷移を含む DP はすでに約 9,000 万の状態遷移に達し、すべてのチェックポイントを 2 人の警察官のうちの 1 人にブルートフォースで割り当てるには、`2^1000`可能性はありますが、それは完全に不可能です。 

不注意なソリューションによって誤って処理される可能性のあるエッジケースがいくつかあります。 1 つ目は、道路がまったくないにもかかわらず、必要な交差点がすでに占有されている場合です。 例えば：```
2 0 31 1 21 2
```最初の航海士は 1 から開始し、2 番目の航海士は 2 から開始します。必要な順序は次のとおりです。`1, 1, 2`したがって、すべての検査は、正しい交差点にすでに立っている警察官によって実行されます。 答えは`0`。 連続するチェックポイントのすべてのペアに実際の道路が必要であると想定するソリューションでは、誤った結果が返されます。`-1`。 

もう 1 つの微妙なケースは、チェックポイントが繰り返されることです。 のために```
1 0 41 1 1 11 1
```答えは`0`。 警察官がすでに現場にいる場合、繰り返し検査を行う場合は移動する必要はありません。 同じ連続頂点を不可能な遷移として扱うのは間違いです。 

両役員が会談する可能性もある。 例えば：```
2 1 21 2 51 21 1
```最初の検査は頂点 1 ですでに満たされており、その後 1 人の警察官が時間 5 で頂点 2 に移動するため、答えは次のようになります。`5`。 2 人の将校が異なる頂点を占有する必要があると主張する DP は、完全に有効な状態を拒否することになります。 

最後に、方向性が重要です。 考慮する：```
2 1 21 2 72 11 1
```2での最初の検査は7コストですが、2から1に戻すことは不可能です。 答えは`-1`。 有向グラフを無向グラフに置き換えると、不正確な有限の答えが生成されます。 

## アプローチ

 直接的な総当たりソリューションでは、必要なチェックポイントごとに、2 人の担当者のどちらがチェックポイントを実行するかを決定できます。 がある`2^k`そのような課題。 割り当てが決定されると、各士官のルートはその士官に割り当てられたチェックポイントによって完全に決定され、すべての移動は最短経路の距離に置き換えることができます。 したがって、列挙は正しいですが、最悪の場合には、`2^1000`それぞれの割り当てには最大で`O(k)`仕事。 これはおおよそです`O(k * 2^k)`、それは可能性をはるかに超えています。 

より有望なアプローチは動的プログラミングです。 チェックポイント後`pi`検査が行われており、警察官が必ず1人立っています。`pi`、つまり、その検査を行ったばかりの警察官です。 他の警察官に関するどのような情報が必要ですか? 現在の交差点のみ。 以前のすべて`pi`はすでにそのコストを DP 値に貢献しています。 

これにより、インデックスで構成される状態が得られます。`i`そして他の役員の頂点`x`。 最初はこれで生成されるようです`O(k n)`しかし、不用意に移行すると、考えられるすべての古い状態と比較される可能性があります。`x`考えられるあらゆる新しい状態で、`O(k n^2)`仕事。 重要な観察は、州からの次のことです。`(i, x)`次の検査で意味のある選択肢は 2 つだけです。 

現在いる役員は、`pi`検査できる`p(i+1)`。 その場合、他の役員はそのまま残ります`x`。 

あるいは、他の警察官が検査することもできます`p(i+1)`。 その場合、現在いる役員は、`pi`は非アクティブな役員になるため、新しい他のポジションは正確に`pi`。 

2 番目の遷移は、その遷移先の状態がすべての古い遷移で常に同じであるため、特に便利です。`x`。 古いポジションと新しいポジションの任意のペアを考慮する必要はありません。 

したがって、すべてのペアの最短パスが計算された後、DP は`O(k n)`時間。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |`O(k * 2^k)`最短パスの後 |`O(n^2)`| 遅すぎる |
 | DP + フロイド・ウォーシャル |`O(n^3 + k n)`|`O(n^2)`| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最短経路距離を計算する`dist[u][v]`フロイド・ウォーシャルを使用して、交差点のすべてのペアの間を測定します。 当初は、`dist[u][u] = 0`、すべての指示された道路はその移動時間に寄与し、到達できないペアの距離は無限大になります。 すべての道路には正の重みがあるため、最短パスは標準緩和によって直接処理できます。 
2. 定義する`dp[x]`チェックポイント処理後`pi`1 人の警察官が勤務している場合の最小経過時間として`pi`そしてもう一人の警官は交差点にいる`x`。 どの物理担当者がどれであるかを覚える必要はありません。 の役員`pi`単に現役役員と呼ばれます。 
3. DP を初期化します。`p1`。 から始まる役員のいずれか`s1`到達する`p1`、他の役員を残して`s2`、またはから始まる役員`s2`到達する`p1`、他の役員を残して`s1`。 したがって、考えられる 2 つの状態は次のとおりです。`dp[s2] = dist[s1][p1]`そして`dp[s1] = dist[s2][p1]`。 

2 つの可能性が同じ状態につながる場合は、より小さいコストを維持します。 
4. 連続するペアごとに`pi`、`p(i+1)`、 させて`next = p(i+1)`。 州から`dp[x]`、まず現役の武将を から移動させることを検討してください。`pi`に`next`。 新しい状態はまだ`x`、追加料金がかかります`dist[pi][next]`。 
5. 非アクティブな役員を移動させることも検討してください。`x`に`next`。 新しいアクティブな役員は、以前に非アクティブだった役員になりますが、古いアクティブな役員はそのまま残ります。`pi`。 したがって、新しい状態は次のようになります。`pi`、追加料金がかかります`dist[x][next]`。 
6. 現在の DP 配列を新しく計算されたもので置き換えます。 無限の最短経路距離を伴う遷移は、対応する担当者がその検査を実行できないため、無視されます。 
7.加工後`pk`、すべての有限`dp[x]`は、検査シーケンス全体を終了する有効な方法を表します。 全体的に最低限のものを取る`x`。 すべての状態が無限の場合、出力`-1`。 

### なぜ効果があるのか

 不変条件は、処理後のものです。`pi`、`dp[x]`検査されたプレフィックスが 1 人の担当者で終わるすべての有効なスケジュールの中で可能な最小時間を格納します。`pi`そしてもう一つは`x`。 

次の検問所では、2 人の警察官のうち 1 人が検査を行います。 もしその役員が`pi`それを実行すると、最初の遷移はそのスケジュールを考慮して終了します`x`変わらない。 もしその役員が`x`それを実行すると、2 番目の移行ではそのスケジュールが考慮され、他の役員はそのまま残ります。`pi`。 可能な選択肢はこれら 2 つだけであるため、すべての有効なスケジュールには対応する DP 遷移があります。 

逆に、すべての DP 遷移はグラフ内の実際の最短パスに従い、次の検査後に有効な構成が生成されます。 DP は可能なすべての構成に対して最も安価なコストを維持するため、チェックポイント シーケンスにわたる帰納法により、最終的な最小値が正確に最適なパトロール期間であることが証明されます。 

## Python ソリューション```python
Pythonimport sysinput = sys.stdin.readline

def solve():    n, m, k = map(int, input().split())
    INF = 10**30    dist = [[INF] * n for _ in range(n)]
    for i in range(n):        dist[i][i] = 0
    for _ in range(m):        v, u, t = map(int, input().split())        v -= 1        u -= 1        if t < dist[v][u]:            dist[v][u] = t
    p = [x - 1 for x in map(int, input().split())]    s1, s2 = map(lambda x: x - 1, map(int, input().split()))
    # Floyd-Warshall.    for mid in range(n):        dmid = dist[mid]        for u in range(n):            du = dist[u]            if du[mid] == INF:                continue            base = du[mid]            for v in range(n):                nd = base + dmid[v]                if nd < du[v]:                    du[v] = nd
    # dp[x]:    # one patrol is at p[i], the other is at x.    dp = [INF] * n
    first = p[0]
    if dist[s1][first] < INF:        dp[s2] = min(dp[s2], dist[s1][first])
    if dist[s2][first] < INF:        dp[s1] = min(dp[s1], dist[s2][first])
    for i in range(k - 1):        cur = p[i]        nxt = p[i + 1]
        move_active = dist[cur][nxt]        ndp = [INF] * n
        for other in range(n):            cur_cost = dp[other]            if cur_cost == INF:                continue
            # The patrol currently at cur handles nxt.            if move_active < INF:                value = cur_cost + move_active                if value < ndp[other]:                    ndp[other] = value
            # The other patrol handles nxt.            move_other = dist[other][nxt]            if move_other < INF:                value = cur_cost + move_other                if value < ndp[cur]:                    ndp[cur] = value
        dp = ndp
    answer = min(dp)    print(-1 if answer == INF else answer)

if __name__ == "__main__":    solve()

フロイド-ウォーシャル ループでは、`mid`中間頂点として。 小切手`du[mid] == INF`不必要な作業を回避できる`u`到達できない`mid`。 値`10**30`単純な最短経路では最大でも`n - 1`エッジと各エッジのコストは最大でも`10^6`。 

DP には、現在最新の検問所に立っていない警察官の考えられるすべての場所に対して 1 つの州が含まれています。 アクティブな武将が移動しても、非アクティブな位置は変化しません。 非アクティブな役員が移動すると、古いアクティブな場所が新しい非アクティブな場所になります。これが、宛先インデックスが`cur`それよりも`nxt`。 

初期化では両方の先発役員を考慮する必要があります。 選ぶだけ`s1`二等航海士が到着する予定に間に合わない可能性がある`p1`初め。 同じ理由がその後のすべてのチェックポイントにも当てはまり、両方の警察官が実行犯の可能性があるとみなされる必要があります。

### サンプル 2

| チェックポイント | アクティブな位置 | その他のポジション | 最小コスト |

 |`1 0 5`、すべてのチェックポイントが 1 に等しい |`0`| グラフの最小サイズとコストゼロの繰り返し検査 |
 |`2 1 2`、 のみ`1 -> 2`存在します |`-1`| 指定された到達可能性と到達不能な遷移 |
 |`3 3 4`、循環グラフ |`8`| 役員は面会して、次回の検査を行う役員を変更することができます。 
|`3 4 3`、 平行`1 -> 2`エッジ |`10`| 最小の平行エッジを選択し、中間の最短パスを使用する |

 ## 特殊なケース

 必要なチェックポイントがすべてすでに占有されている場合、道路は必要ありません。 最小サイズの例では```
1 0 51 1 1 1 11 1
```初期化によりコストがゼロの状態が作成されるため、`dist[1][1] = 0`。 その後の移行もコストはゼロです。 答えは`0`これは、警察官がすでにその交差点にいる場合、検査では移動する必要がないという事実から直接得られます。 

繰り返されるチェックポイントは、距離行列の同じゼロ対角線によって処理されます。 現役の役員がすでにいる場合`pi`そして`p(i+1) = pi`、 それから`dist[pi][p(i+1)] = 0`。 現職役員への移行では、他の役員の地位は変更されず、コストは何も追加されません。 

到達不能な遷移の場合、無限大は無効なスケジュールが DP に入るのを防ぎます。 で```
2 1 21 2 72 11 1
```最初の検査は頂点 2 に到達した後にいずれかの役員によって実行できますが、アクティブな位置が 2 になると 1 に戻るパスはありません。他の役員がすでに 1 にある場合、DP は代わりにその役員に 2 番目の検査を実行させることができますが、これは考慮する必要があります。 どちらの構成も必要な順序を許可しない場合、すべての最終状態は無限のままとなり、答えは次のようになります。`-1`。 

同じ交差点の占有を許可されている警察官が自然に表現されているのは、次のような理由からです。`dp[x]`～に制限を設けない`x`アクティブな位置に等しい。 状態は位置を表すものであり、個別の頂点を表すものではありません。 これは、一方の警察官がもう一方の警察官に追いつき、後で検査の責任を負うような状況にも対処します。 

平行な有向エッジでは、最小エッジの重みを取る必要があります。 たとえば、両方の場合、`1 -> 2`コスト 100 と 4 が存在する場合、行列エントリとして 100 を使用すると、後続のすべての最短パスが不必要に高価になります。 初期化には次のものを使用します`min(dist[v][u], t)`したがって、フロイド-ウォーシャルは正しいグラフから開始します。 

最後に、パス コストが大きい場合は、十分に大きな整数センチネルが必要です。 Python の整数はオーバーフローしませんが、次のようなセンチネルを使用します。`10**30`到達不能状態のチェックを明示的に行い、追加を有限の答えから安全に分離します。
