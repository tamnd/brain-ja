## アプローチ

 直接的な解決策は、すべてのクエリを個別に処理することです。 特定の`k`、現在の連続数を維持しながら文字列をスキャンします。`1`s. もしその数字に達したら`k`、答えはすぐにわかります`NO`; スキャンが終了すると、答えは次のようになります。`YES`。 これは正しいです。クエリを無効にできるのは、十分に長い連続した干渉ブロックだけであるためです。 

問題はスキャンの繰り返しです。 最悪の場合、文字列は`10^6`キャラクターがいます`3 \cdot 10^5`クエリ。 すべてのクエリで文字列全体を検査する必要がある場合、最悪のケースは約`3 \cdot 10^11`操作。 一つ一つのスキャンは単純なものですが、これを何度も繰り返すのは制限時間内では不可能です。 

重要な点は、すべてのクエリが同じ文字列について同じ質問をしていることです。 すべての実行の長さをクエリごとに個別に知る必要はありません。 させて`mx`の最長の連続ブロックの長さになります。`1`s in the entire string. 1 つおきのブロックは次の値を超えない`mx`したがって、クエリは正確に次の場合に成功します。`mx < k`。

### なぜ効果があるのか

 値`mx`連続するブロックの最大長です。`1`s. 値を含むクエリ`k`干渉ブロックが長さを持たない場合にのみ有効です`k`またはそれ以上。 以来`mx`はそのようなブロックの中で最大のものであり、すべてのブロックの長さは`k`まさにいつ`mx < k`。 前処理では真の最大値が計算されるため、比較によりすべてのクエリに対して独立して正しい答えが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    s = input().strip()

    mx = 0
    cur = 0

    for ch in s:
        if ch == '1':
            cur += 1
            if cur > mx:
                mx = cur
        else:
            cur = 0

    ans = []

    for _ in range(m):
        k = int(input())
        if mx < k:
            ans.append("YES")
        else:
            ans.append("NO")

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```スキャンで使用されるのは、`cur`現在の干渉の進行を表します。 のみ増加します`1`そしてそれをリセットする`0`連続するすべての実行を他の実行から独立させます。 いつでも`cur`より大きくなる`mx`、グローバル最大値を更新します。 

比較は意図的に行われています`mx < k`、 ない`mx <= k`。 このステートメントでは厳密に次の数よりも少ない値が許可されます`k`ノイズの多いナノ秒が連続して発生します。 最大長さのランの場合`3`、`k = 3`生産しなければならない`NO`、 その間`k = 4`生成する`YES`。 

保証される最初と最後の文字は次のとおりです。`0`ですが、アルゴリズムは正確性をこれに依存しません。 また、次の一連の文字列を含む文字列も正しく処理されます。`1`どちらかの境界にあります。 

最大のカウンターは 1 つだけであるため、整数オーバーフローの問題はありません。`n`、せいぜい`10^6`とにかく Python が直接処理します。 文字列自体は一度保存され、回答リストには最大でも`3 \cdot 10^5`短い文字列。

## テストケース```python
import sys
import io

def solve():
    input = sys.stdin.readline

    n, m = map(int, input().split())
    s = input().strip()

    mx = 0
    cur = 0

    for ch in s:
        if ch == '1':
            cur += 1
            mx = max(mx, cur)
        else:
            cur = 0

    ans = []
    for _ in range(m):
        k = int(input())
        ans.append("YES" if mx < k else "NO")

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        solve()
        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

    "4\n"

    "1\n"
    "2\n"

    "5\n"
