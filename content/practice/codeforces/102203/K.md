 ## 問題の理解

 (n) 個の異なるエージェントと (m) 個の異なる宇宙港が存在します。 各エージェントは正確に 1 つの宇宙ポートに割り当てられる必要があり、すべての宇宙ポートは少なくとも 1 つのエージェントを受け入れる必要があります。 同じ宇宙ポートに割り当てられたエージェントは許可されるため、タスクはエージェントのセットから宇宙ポートのセットまでのすべての全射関数をカウントすることです。 

エージェントは異なります。 たとえば、(n=2) と (m=2) の場合、2 つの有効な割り当ては、エージェント 1 からポート 1、エージェント 2 からポート 2、またはその逆です。 したがって、答えは 2 になります。 

答えのモジュロ (998244353) が必要です。 (n) と (m) は両方とも 250000 に達する可能性があるため、(O(nm)) 動的計画法ソリューションには約 (6.25\cdot10^{10}) の演算が必要となり、完全に実行不可能です。 (O(m^2))でも大きすぎます。 1 秒の制限がある場合、目的のソリューションは、小さな対数係数を除いて本質的に線形である必要があります。 

不注意な実装によって誤って処理される可能性のある境界ケースがいくつかあります。 たとえば (n=2,m=3) エージェントよりも多くのスペースポートがある場合、どの割り当ても 3 つのポートすべてをカバーできないため、答えは 0 になります。階乗または包含除外を含む式は、除算を行う前にこれを処理する必要があります。 

宇宙港が 1 つだけある場合、各エージェントの目的地は 1 つだけです。 したがって、(n=5,m=1) の答えは 1 になります。誤ったエンドポイントから包含/排他ループを誤って開始する実装では、ここで 0 が生成される可能性があります。 

(n=m) の場合、すべての宇宙港にはエージェントが 1 人だけ含まれている必要があるため、答えは (n!) になります。 (n=2,m=2) の場合は 2 が得られます。(n=1,m=1) の場合は 1 が得られます。このケースは、最終的な包含除外符号と二項係数が正しく処理されているかどうかを確認するのにも役立ちます。

ブルート フォースが機能するのは、カウントしたいオブジェクトを明示的に列挙するためです。 問題は、それらのオブジェクトのほとんどが無効であり、それらを個別に検査する理由がないことです。 

重要な観察は、「すべての宇宙港が使用されている」という条件が包含-排他によって処理できるということです。 ポートを占有する必要なく、すべての (m^n) 個の割り当てから開始します。 次に、少なくとも 1 つの特定のポートが空である割り当てを減算します。 2 つの特定のポートを強制的に空にすると、各エージェントの可能な宛先は (m-2) 個だけになり、((m-2)^n) 個の割り当てが与えられます。 このプロセスを継続すると、交互の合計が得られます。 

正確に (k) 個の宇宙港を禁止するように選択した場合、それらを選択する (\binom{m}{k}) 通りの方法と、それらを回避する ((m-k)^n) 個の割り当てがあります。 包含排他は結果として次のようになります。

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, m = map(int, input().split())

    if m > n:
        print(0)
        return

    # Modular inverses of 1..m.
    inv = [0] * (m + 1)
    if m >= 1:
        inv[1] = 1

    for i in range(2, m + 1):
        inv[i] = MOD - (MOD // i) * inv[MOD % i] % MOD

    # C(m, 0)
    comb = 1
    ans = 0

    for k in range(m):
        ways = pow(m - k, n, MOD)
        term = comb * ways % MOD

        if k & 1:
            ans -= term
        else:
            ans += term

        if ans >= MOD:
            ans -= MOD
        elif ans < 0:
            ans += MOD

        # C(m, k + 1) from C(m, k)
        comb = comb * (m - k) % MOD
        comb = comb * inv[k + 1] % MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()

逆配列では、標準的な素数係数の再帰が使用されます。 表現`MOD % i`は常により小さいです`i`、そのため、その逆数は処理時にすでに計算されています。`i`。 

変数`comb`(\binom{m}{k}) の現在の値を保存します。 これは (k=0) に対応する 1 から始まり、現在の用語を処理した後にのみ更新されます。 現在の用語では (\binom{m}{k+1}) ではなく (\binom{m}{k}) を使用する必要があるため、順序は重要です。 

ループは次で停止します`range(m)`、 (k=0,\ldots,m-1) を処理します。 (n\ge1) であるため、省略された (k=m) 項は (0^n=0) となり、省略しても何も変わりません。 これにより、パワー実装が特殊な式 (0^n) を処理する方法に依存することも避けられます。 

パイソンの`pow(base, exponent, MOD)`はべき乗剰余演算を直接実行するため、中間値が通常の整数 (base^n) ほど大きくなることはありません。 答えとすべての二項係数は剰余で換算されます。`MOD`すべての乗算の後。
