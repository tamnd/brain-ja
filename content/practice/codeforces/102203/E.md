## アプローチ

 最も直接的な総当たりの方法は、位置のすべてのサブセットを列挙することです。`s`、対応するサブシーケンスを構築し、それが特殊な文字列のいずれかに等しいかどうかを確認します。 すべてのサブシーケンスは、次から選択されたインデックスによって一意に識別されるため、これは正しいです。`s`。 ただし、(2^n) 個のサブセットがあるため、`n = 5000`このメソッドには (2^{5000}) 個の候補があります。 候補の構築または比較に (O(n)) かかる場合、最悪の場合の作業は (O(n2^n)) となり、制限をはるかに超えます。 

より合理的な最初の試みは、関連するすべてのものを構築することです。`f_i`そして、標準サブシーケンス DP を使用してそのサブシーケンスをカウントします。 パターンの場合`p`長さの`m`、 維持する`dp[j]`、最初の値を取得する方法の数`j`の登場人物`p`の処理されたプレフィックスから`s`。 1 つの入力文字を処理すると、その文字を含むすべてのパターン位置が更新されます。 これはすでに多項式ですが、単純な実装ではすべてをスキャンします。`m`すべての文字のパターンの位置。 

有益な観察は、パターンが指数関数的に増加するということです。 なぜなら`f_i`の長さは (2^i-1) で、考慮する必要があるのは約 (\log_2 n) 個のパターンだけであり、それらの長さの合計はそれ自体 (O(n)) のみです。 現在のパターン内の各文字の位置を事前計算することもできます。 キャラクターのとき`x`から`s`到着したら、そのキャラクターが含まれるパターン位置のみを更新します。`x`、無関係な位置をスキャンするのではなく。 

標準のサブシーケンス DP には、微妙な要件が 1 つあります。 パターンの状態は右から左に更新する必要があります。 それらを左から右に処理した場合、新しく読み取られた文字は同じ反復中に数回使用され、実質的に 1 つの位置を許可することができます。`s`パターンの複数の文字を表します。 順序を逆にするとそれを防ぐことができます。

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def count_subsequences(s, pattern):
    m = len(pattern)

    positions = [[] for _ in range(26)]
    for j, ch in enumerate(pattern, 1):
        positions[ord(ch) - 97].append(j)

    dp = [0] * (m + 1)
    dp[0] = 1

    for ch in s:
        pos = positions[ord(ch) - 97]

        for j in reversed(pos):
            value = dp[j] + dp[j - 1]
            if value >= MOD:
                value -= MOD
            dp[j] = value

    return dp[m]

def solve(s):
    n = len(s)

    freq = [0] * 26
    for ch in s:
        freq[ord(ch) - 97] += 1

    answer = 0
    pattern = "a"

    for i in range(1, 27):
        length = len(pattern)
        if length > n:
            break

        feasible = True
        for j in range(i):
            # In f_i, character j appears 2^(i-j-1) times.
            need = 1 << (i - j - 1)
            if freq[j] < need:
                feasible = False
                break

        if not feasible:
            break

        answer += count_subsequences(s, pattern)
        if answer >= MOD:
            answer -= MOD

        if i == 26:
            break

        pattern = pattern + chr(97 + i) + pattern

    return answer

def main():
    s = input().strip()
    print(solve(s))

if __name__ == "__main__":
    main()
```の`count_subsequences`関数は、1 つの固定ターゲット パターンの標準サブシーケンス DP を実装します。`dp[0]`空のサブシーケンスを選択する方法は 1 つだけであるため、 は 1 に初期化されます。 すべての入力文字について、一致するパターンの位置のみが更新されます。 

位置は 1 から始まるインデックスとして保存されます。`dp[j]`当然最初のものを表します`j`パターンの文字。 逆の反復は、実装の重要な詳細です。 のために`pattern = "aa"`そして文字を入力`a`たとえば、アップデートは最初に変更する必要があります`dp[2]`古いものを使って`dp[1]`、その後変更します`dp[1]`。 それ以外は同じ`a`誤って 2 回貢献する可能性があります。 

モジュラー加算では、代わりに単一の条件付き減算が使用されます。`% MOD`あらゆる移行に。 両方のオペランドがすでにモジュラスを下回っているため、それらの合計は以下になります`2 * MOD`1 つの減算で十分です。 

実現可能性チェックでは、再帰構造を直接使用します。 から移動するとき`f_i`に`f_{i+1}`、既存のすべてのキャラクター数が 2 倍になり、新しいキャラクターが 1 回出現します。 式`1 << (i - j - 1)`まさにその多様性を表現しています。 一部の文字が欠落しているためにパターンを埋め込むことができなくなると、それ以降のパターンもすべて埋め込むことができなくなるため、外側のループが終了する可能性があります。 

パターン自体は、入力された長さを超えて構築されることはありません。 サイズは反復ごとに 2 倍になるため、最大 12 個のパターンが関連します。`n <= 5000`。
