 ## 解決策
 ## 問題の理解

 タスクは正の整数の配列を再構築することです。`a`、2 つの配列が与えられた場合`b'`そして`c'`。 これらの配列はから生成されました`a`2 つの段階を経ます: 最初に、すべての連続するペアを取得します。`a`形成する`b`そして`c`、ここでそれぞれ`b_i`は最小値であり、それぞれ`c_i`ペアの最大値です`(a_i, a_{i+1})`; 2番目に、並べ替えることによって`b`そして`c`いくつかの未知の順列を伴う`p`生産する`b'`そして`c'`。 課題は、このプロセスを逆にして、有効な元の配列を生成することです。`a`、またはそのような配列が存在しないと判断します。 

入力は整数で構成されます`n`と 2 つの配列`b'`そして`c'`、それぞれの長さ`n-1`。 出力は有効です。`a`長さの`n`または`-1`再建が不可能な場合。 制約`2 ≤ n ≤ 10^5`そして`1 ≤ b'_i, c'_i ≤ 10^9`上記のような複雑なアルゴリズムを提案する`O(n log n)`線形または線形に近い解決策は実行可能ですが、遅すぎる可能性があります。 

明らかではないエッジ ケースには、複数のペアが同じ最小値または最大値を持つシーケンスが含まれます。`b' = [1,1,1]`そして`c' = [2,2,2]`。 競合を考慮せずに値を順番に割り当てる単純な貪欲なアプローチでは、否定的な結果や一貫性のないシーケンスが発生する可能性があります。 連続する要素が、矛盾する最小値と最大値の制約を満たさなければならない場合、別の注意が必要なシナリオが発生します。`b'`そして`c'`、 例えば`b' = [2,3]`そして`c' = [3,2]`。 アルゴリズムは、すべてのペアに互換性があること、および最終的な配列が`a`最小値と最大値の関係に違反しません。 

## アプローチ

 ブルートフォースアプローチでは、すべての順列を試みます。`b'`そして`c'`、再構築を試みる`a`、最小値と最大値の定義との一貫性を検証します。 のために`n-1`要素、あります`(n-1)!`順列。 それぞれの順列を再構成する必要があります`a`そして妥当性をチェックします。これは順列ごとに O(n) です。 このアプローチは理論的には正しいですが、`n`まで`10^5`なぜなら`(n-1)!`は天文学的に大きく、計算限界をはるかに超えています。 

重要な観察は、それぞれの要素が`a`正確に 2 つの連続する最小値と最大値のペアで出現します: 要素の場合`a_i`(最初と最後を除く)、`a_i`の一部です`b_{i-1}`、`c_{i-1}`、`b_i`、 そして`c_i`。 したがって、これをグラフ問題としてモデル化できます。各ペア`(b'_i, c'_i)`の 2 つの連続する要素間のエッジを定義します。`a`、一方の要素は最小値、もう一方の要素は最大値です。 各ペアを無向エッジとして扱い、一貫してエンドポイントを割り当てることを試みることにより、問題は、共有ノードで値が一致するチェーンとしてこれらのペアを配置することになります。 最初のペアについて 2 つの可能性を考慮し、選択を順番に伝播するだけで済みます。 いずれかのステップで最小-最大制約が満たされない場合、再構築は不可能です。 

最初のペアの 2 つの可能な割り当てに基づいて最大 2 つのシーケンスのみを探索するだけなので、この洞察により複雑さが階乗から線形に軽減されます。 伝播により、後続のすべての要素が一致するか、矛盾が生じることが保証されます。

 ## アルゴリズムのチュートリアル

 1. リストを初期化する`a`長さの`n`プレースホルダー付き。 最初のペアを考えてみましょう`(b'_0, c'_0)`。 割り当てる`a[0] = b'_0`そして`a[1] = c'_0`そして逆転の可能性も残しておく`a[0] = c'_0`、`a[1] = b'_0`。 これら 2 つの初期シーケンスは、2 つの唯一の開始オプションを表します。 
2. 残りのペアを反復処理します。`i = 1`に`n-2`。 検討中の各シーケンスについて、現在のシーケンスの互換性を確認してください。`b'_i`そして`c'_i`最後に割り当てられた要素を使用して`a[i]`。 有効な割り当ては 2 つあります。`a[i+1] = b'_i`そして`a[i] = max(a[i], c'_i)`一貫性がある場合、または`a[i+1] = c'_i`そして`a[i] = min(a[i], b'_i)`一貫していれば。 競合を引き起こすシーケンスをすべて破棄します。 
3. すべてのペアを処理した後、一方または両方のシーケンスが有効なままである場合は、有効なシーケンスを出力します。 両方のシーケンスが失敗した場合、出力`-1`。 
4. 伝播は、それぞれが次の条件を満たす不変式に依存します。`a[i]`隣接するペアの最小制約と最大制約の両方を満たさなければなりません。 両方の可能性をチェックし、矛盾したシーケンスを即座に破棄することで、実行可能な配列のみが確実に生き残るようになります。
