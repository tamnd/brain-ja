 ## 解決策
 ## 問題の理解

 潜在的な三角形の辺を表す整数の配列が与えられ、許可される操作は、ある要素を別の要素にコピーすることです。 最終的な目標は、要素のすべての個別のトリプレットが非縮退三角形を形成するようにすることです。 幾何学的用語で言えば、これは、任意の 3 つの異なる要素について、$x$、$y$、 そして$z$、三角形不等式が成り立つ必要があります。つまり、任意の 2 つの要素の合計が 3 番目の要素を超えなければなりません。 

入力は複数のテスト ケースで構成されます。 各テスト ケースはサイズの配列を与えます$n$、各要素は 1 ～$10^9$。 出力はテスト ケースごとに 1 つの整数、つまり必要なコピー操作の最小限の数です。 制約は、$n$まで$2 \cdot 10^5$同様に境界が定められたすべてのテストの合計は、$O(n^2)$したがって、線形または線形に近い解決策が必要です。 

配列がすでに昇順でソートされているが、値が大きく異なる場合、微妙なエッジ ケースが発生します。 たとえば、最大の要素が最小の 2 つの要素の合計より大きい場合、何も変更しなければ、一部のトリプレットについては三角形条件が失敗します。 不注意なアプローチでは、単純に個別の値をカウントしたり、任意の要素をコピーしたりする可能性があり、必要な操作を過大評価または過小評価することになります。 

## アプローチ

 ブルートフォースアプローチでは、可能なすべての代入を試し、各トリプレットについて三角不等式が成り立つかどうかをチェックします。 これは原理的には正しいですが、完全に実行不可能です。$O(n^3)$三つ子。 明らかに、このようなシミュレーションは遅すぎます。 

最適なアプローチでは、数学的観測が使用されます。 三角不等式を満たす 3 つの数値の場合、最大の数値が他の 2 つの数値の合計を超えることはできません。 配列をソートする場合、最大の要素は、最終的な配列内の 2 つの最小の要素の合計を超えてはなりません。 これは、問題が、ある値 (理想的には最も頻度の高い要素) の頻度を最大化し、それを他の値にコピーして、上位 2 つの異なる値のみを残すことにあることを示唆しています。 

解決策は、最も頻度の高い要素を見つけることになります。$f$、維持$f$をベースとして使用し、必要に応じて要素をコピーします。 配列に$n$要素と$f$発生する$c$回の最小操作数は$n - c$、他のすべての要素はからコピーできるため、$f$。 ただし、注意深く分析すると、サイズ 3 の配列の場合、3 つの辺がすでに三角形を形成している場合には演算は必要ありません。また、より大きな配列では、三角形不等式が常に成り立つためには 2 つの異なる値のみを残す必要があることがわかります。 

これにより、問題は周波数のカウントと計算に軽減されます。$n - \text{max frequency}$線形時間で。 この方法では、トリプレットの明示的なチェックが回避され、最小限の操作が保証されます。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$そして配列$a$。 
2. それぞれの異なる数値の頻度を数えます。$a$。 
3. 最大周波数を決定する$c$すべての要素の中で。 
4. 操作の最小数は次のとおりです。$n - c$なぜなら、最も頻繁に使用される要素を他のすべての要素にコピーできるからです。 
5. テスト ケースに対してこの値を出力します。 

これが機能する理由: 不変条件は、各辺が同一であるため、すべての要素を最も頻繁に出現する要素と等しくすることで、どの三重項も自明に三角不等式を満たすということです。 この操作では任意の要素からのコピーが許可されるため、これより少ない数の操作でこれを達成でき、最小性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import Counter

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        freq = Counter(a)
        max_freq = max(freq.values())
        print(n - max_freq)

if __name__ == "__main__":
    main()
```このソリューションは高速 I/O を使用し、複数のテスト ケースを効率的に処理します。 の`Counter`発生を効率的に追跡し、`max(freq.values())`線形時間で最大の周波数を与えます。 実装の微妙な選択には、`input()`と一緒に使用されます`readline()`大規模な入力での TLE を回避するため、`map(int, input().split())`スペースで区切られた整数を正しく解析します。
