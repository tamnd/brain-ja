 ## 解決策
 ## 問題の理解

 数値の配列が与えられ、その要素の分散を最大化する部分列を選択するように求められます。 この文脈における分散は、選択された値がその平均の周囲にどれだけ広がっているかを測定するため、値ができるだけ離れている部分列が必要です。 

この問題の重要な観察点は、すべての要素を保持したり、サブシーケンスの順序を超えて構造を保持したりする必要はないということです。 インデックスのサブセットを自由に選択できます。 この自由により、問題はサブシーケンスに対する組み合わせの問題から、値の選択のみに依存する問題に軽減されます。 

配列のサイズが 2⋅10^5 などの一般的な Codeforce スケールまでの場合、サブシーケンスの数が指数関数的に増加するため、すべてのサブシーケンスを試行するアプローチは直ちに不可能になります。 すべてのペアまたはトリプルを反復処理するだけでも、すでに遅すぎます。 これにより、ソリューションは列挙ではなく配列からの集約情報のみに依存するようになります。 

分散が極端な値以上のものに依存すると仮定すると、微妙な失敗例が現れます。 たとえば、配列が次の場合、`[1, 2, 3]`、素朴な直感は、値を混合すると、単に極端な値をとるよりも高い分散が得られると示唆するかもしれません。 ただし、値が最も分散しているときに分散が最大化されるため、最適なサブシーケンスは常に最小値と最大値に集中します。 中間値を含めようとしても、平均が中心に近づくだけであり、分散が減少します。 

もう 1 つの特殊なケースは、すべての値が等しい場合です。 のために`[5, 5, 5]`、どの部分列も分散がゼロになります。 最小値と最大値の差を含む単純な式ではゼロが正しく生成されますが、浮動小数点の実装は慎重に扱わないとノイズが発生する可能性があります。 

最後の重要な問題は数値の安定性です。 この問題では、自然に分数である値を計算する必要があります。 浮動小数点を直接計算すると精度誤差が生じる可能性があるため、合理的または高精度の表現が必要です。 

## アプローチ

 分散の定義から始めます。 選択した値の部分列に対して$x_1, x_2, \dots, x_k$、分散は$$\mathrm{Var} = \frac{1}{k}\sum x_i^2 - \left(\frac{1}{k}\sum x_i\right)^2.$$ブルートフォースは、すべてのサブシーケンスを列挙し、その平均と分散を計算し、最大値を追跡します。 これは正しいですが、まったく実行不可能です。 と$n$要素、あります$2^n$サブシーケンス、さらには$n=40$すでに大きすぎるでしょう。 

重要な構造的洞察は、分散を最大化することによって分散が最大化されるということです。 分散は平均からの二乗偏差に依存するため、最小値と最大値の間の中間値を含めると、広がりを増やすことなく二乗距離の寄与が減少します。 これは、最適なサブシーケンスでは配列の極値のみが使用されることを意味します。 

より正確には、最良の部分列が最小要素と最大要素のみで構成されることがわかれば、問題はこれら 2 つの値のみを含むマルチセットの分散を計算することになります。 それらの間に個別の値を追加しても分散が減少するだけなので、最適な解には現れません。 

したがって、次の発生から形成される部分列のみを考慮する必要があります。`mn`そして`mx`。 最適な構成は、それぞれが何回出現するかによってのみ決まりますが、閉じた形式は、次の点で直接的な表現にさらに単純化されます。`mn`そして`mx`、提供されたソリューションで導出されたもの。 

この削減により、問題はサブシーケンスの最適化から配列をスキャンした後の定数時間の計算に分解されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n · n) | O(n) | 遅すぎる |
 | 最適 (最小/最大削減) | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

1. 配列を読み取り、その最小値と最大値を計算します。 

広がりを決定するのは極値のみであるため、このステップでは分散の最大化に関連するすべての情報が取得されます。 
2. スキャン後、2 つのスカラーが得られます。`mn`そして`mx`。 

これらは、最適なサブシーケンスを構築するために重要な唯一の候補を定義します。 
3. 派生式を計算します。$$ans = 2(mn^2 + mx^2) - (mn + mx)^2.$$この式は、2 値分布の分散式を拡張し、問題の実装で使用される整数スケーラブルな形式に単純化したものです。 
4. 4 による除算を使用して整数部分と小数部分に分割し、結果を固定小数形式で出力します。 

代数展開により分母が 4 になるため、この割り算が発生します。 

### なぜ効果があるのか

 核となる不変条件は、最大分散を達成するサブシーケンスは、分散を減少させることなく、グローバル最小値とグローバル最大値の出現のみを含むサブシーケンスに変換できるということです。 中間値は平均からの二乗偏差を厳密に減少させますが、範囲は増加しないため、目的を改善することはできません。 問題空間が 2 つの値に折りたたまれると、分散はそれらのカウントと値にのみ依存し、最適なカウントはステートメントの導出で提供される閉形式の簡略化によって暗黙的に処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    mn = 10**30
    mx = -10**30

    for _ in range(n):
        x = int(input())
        if x < mn:
            mn = x
        if x > mx:
            mx = x

    ans = (mx * mx + mn * mn) * 2 - (mx + mn) * (mx + mn)

    print(ans // 4, end=".")
    frac = (ans % 4) * 25
    print(f"{frac:02d}")

t = int(input())
for _ in range(t):
    solve()
```この実装では、まず単一の線形スキャンを実行して最小値と最大値を抽出します。 2 つの変数を超える追加のストレージは必要ありません。 

の表現`ans`は編集上の導出とまったく同じように計算されます。 精度の問題を回避するために、全体で整数演算が使用されます。 

最終的な出力フォーマットは、分母が 4 に固定されているという事実に依存しているため、剰余は常に 0、1、2、または 3 になります。25 を乗算すると、これらのケースは正しい 10 分の 1 に変換されます。

 ## 特殊なケース

 すべての値が同一の場合、アルゴリズムは次のように設定します。`mn = mx`、計算された式はゼロに崩壊します。 たとえば、入力`[7, 7, 7]`収量`ans = 0`したがって、出力は正確に次のようになります`0.00`浮動小数点計算は必要ありません。 

値に負の値が含まれる場合、次のようになります。`[-5, 10]`しても、アルゴリズムは依然として極値を正確に識別し、純粋にその代数的関係から分散を計算します。 この式は算術演算のみに依存するため、有効なままです。`mn`そして`mx`、符号の仮定ではありません。 

配列の要素が 1 つだけの場合、`mn`等しい`mx`、式は再びゼロに評価されます。 min と max は両方とも同じ初期化から開始され、一貫して更新されるため、スキャンは特別な分岐を必要とせずにこれを自然に処理します。
