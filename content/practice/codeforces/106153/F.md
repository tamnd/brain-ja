 ## 解決策
 ## 問題の理解

 各テスト ケースに対して整数の配列が与えられ、2 つの異なる要素を選択して、それらから形成された式を評価するように求められます。 式は固定されていません。異なるインデックスの順序付きペアについて、可能な 3 つの値、つまり合計、差、積を計算できます。 タスクは、2 つの異なる要素のすべての選択と 3 つの操作すべてから取得可能な最大値を決定することです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは、正の数、負の数、およびゼロを含むことができる配列を提供します。 各テスト ケースの出力は 1 つの整数であり、2 つの異なる位置を選択し、許可された操作の 1 つを適用することで達成できる最大値です。 

素朴な解釈では、すべてのペアの O(n²) 列挙が示唆されます。これは、テスト ケース全体で n が大きい場合、すでに境界線に達しています。 ただし、操作の構造により、重要な内容が大幅に制限されます。 

重要な点は、配列内のすべての要素が同等に関連しているわけではないということです。 極値は 3 つの操作すべてを支配します。 乗算の場合、通常、最も大きな正の数または最も負の数が最適な候補となります。 引き算の場合、最大の数値と最小の数値を組み合わせることで最良の結果が得られます。 さらに、やはり最大値が優先されます。 このように「興味深い」候補が極端なところに集中していることが、問題を圧縮しやすくしています。 

不注意な解決策は、次のような場合に失敗することがよくあります。 

入力:```
3
-100 1 2
```大きな正の数のみに単純に注目すると、2 * 1 または 2 + 1 を試行し、2 - (-100) = 102 が最適であることを見逃してしまいます。 

もう 1 つの落とし穴は、2 つの負の数の積が正の組み合わせを超える可能性があることを無視していることです。 

入力:```
3
-10 -9 1
```最良の答えは (-10) * (-9) = 90 で、これがすべての合計と差を支配します。 

これらの例は、正と負の両極値を対称的に考慮する必要がある理由を示しています。 

## アプローチ

 ブルート フォース手法では、順序付けられたインデックスのペアごとに反復処理が行われ、3 つの式すべてが計算されます。 これは定義を直接評価するため、単純かつ正確です。 ただし、テスト ケースごとに O(n²) ペアを実行します。n が大きい場合、これは実行できなくなります。 

重要な観察は、一定数の要素のみが最適なソリューションの一部になり得るということです。 乗算と減算では、極値のみが問題になります。配列内の最大 2 つの値と最小の 2 つの値は、最適な組み合わせのすべてのケースをすでにカバーしています。 正の値と負の値は対称的に動作するため、負の値と相互作用する可能性があるゼロについても考慮する必要があります。 

すべてのペアを評価する代わりに、配列を 2 つの最大値、2 つの最小値、および存在する場合は 0 で構成される小さな候補セットに縮小します。 すべての最適解には、これらの候補の少なくとも 1 つが含まれている必要があります。これは、3 つの操作すべての結果を改善または保存するために、極端でない要素をより極端な要素に置き換えることができるためです。 

ブルートフォースはすべてを探索するため機能しますが、n が大きくなると失敗します。 極値のみが重要であるという観察により、問題を最大でも一定数の候補に圧縮し、この縮小されたセット内のすべてのペアをチェックすることができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 遅すぎる |
 | 最適 (極端な場合のみ) | O(n log n) または O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

1. 配列を 3 つの概念グループ (正の数、負の数、ゼロ) に分割します。 乗算の動作が符号によって異なるため、この分離は便利です。 
2. 正の数の場合は、最小 2 つの値と最大 2 つの値のみを保持します。 減算では最小のプラスが問題になる可能性がありますが、成長を伴うすべての操作では最大のプラスが問題になります。 
3. 負の数値の場合は、2 つの最小値 (最も負の値) と 2 つの最大値 (0 に最も近い値) のみを保持します。 乗算では最も負の値が重要ですが、ゼロに最も近い値は減算で正の値と相互作用する可能性があります。 
4. 少なくとも 1 つのゼロがある場合は、候補セットに単一のゼロを含めます。 ゼロは、乗算と減算のエッジ動作にのみ関係し、値を支配したり無効にしたりする可能性があります。 
5. 選択したすべての候補を 1 つの小さなリストに結合します。通常、サイズは最大 8 または 9 です。 
6. 個別の候補の順序付きペアをすべて列挙します。 各ペア (i, j) について、a[i] + a[j]、a[i] - a[j]、および a[i] * a[j] を計算し、最大値を追跡します。 
7. 見つかった最良の値を出力します。 

正確さは、要素を適切な方向のより極端な要素に置き換えるという点で、すべての操作が単調であるという事実にかかっています。 候補が極値の中にない場合、それをより極値に置き換えても 3 つの式のいずれも悪化することはなく、厳密には少なくとも 1 つは改善される可能性があります。 

## なぜ機能するのか

 最適なペアには、それぞれの符号領域で極端な要素が含まれている必要があります。 加算の場合、どちらかのオペランドをより大きな値に置き換えても、結果が増加するだけです。 減算の場合、最初の項を最大化し、2 番目の項を最小化すると最良の値が得られるため、大域的な最大値と最小値のみが問題となります。 乗算の場合、符号構​​造は候補を 2 つの最大の正数または 2 つの最小の負数のいずれかに絞り込みます。 したがって、最適な解は、その値を減らすことなく、縮小された候補セット内のペアにマッピングできます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    pos = []
    neg = []
    zero = False
    
    for x in a:
        if x == 0:
            zero = True
        elif x > 0:
            pos.append(x)
        else:
            neg.append(x)
    
    def add_candidates(arr, cand):
        arr.sort()
        m = len(arr)
        for i in range(min(2, m)):
            cand.append(arr[i])
        for i in range(max(0, m - 2), m):
            cand.append(arr[i])
    
    cand = []
    add_candidates(pos, cand)
    add_candidates(neg, cand)
    
    if zero:
        cand.append(0)
    
    ans = -10**18
    m = len(cand)
    
    for i in range(m):
        for j in range(m):
            if i == j:
                continue
            x, y = cand[i], cand[j]
            ans = max(ans, x + y, x - y, x * y)
    
    print(ans)

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()
```実装は削減のアイデアに直接準拠しています。 境界要素のみを安全に抽出できるように、値を符号で明示的に区切ります。 ヘルパー関数は、並べ替え後に各グループから 2 つの最小要素と 2 つの最大要素を選択します。 これにより、価値の範囲の両端を確実に捉えることができます。 

候補セットは十分に小さいため、完全なペアごとのチェックは安全です。 二重ループはテスト ケースごとに一定の作業を行います。 Python 整数を介して暗黙的に 64 ビット整数の動作を使用するよう注意が払われており、これにより、元の C++ コンテキストに存在するオーバーフローの問題が回避されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import isclose
    import sys as _sys

    input = _sys.stdin.readline

    def solve():
        n = int(input())
        a = list(map(int, input().split()))
        
        pos, neg = [], []
        zero = False
        
        for x in a:
            if x == 0:
                zero = True
            elif x > 0:
                pos.append(x)
            else:
                neg.append(x)
        
        def add(arr, cand):
            arr.sort()
            m = len(arr)
            for i in range(min(2, m)):
                cand.append(arr[i])
            for i in range(max(0, m-2), m):
                cand.append(arr[i])
        
        cand = []
        add(pos, cand)
        add(neg, cand)
        if zero:
            cand.append(0)
        
        ans = -10**18
        for i in range(len(cand)):
            for j in range(len(cand)):
                if i != j:
                    x, y = cand[i], cand[j]
                    ans = max(ans, x+y, x-y, x*y)
        
        return str(ans)

    def main():
        t = int(input())
        out = []
        for _ in range(t):
            out.append(solve())
        return "\n".join(out)

    return main()

 ## 特殊なケース

 重要なエッジケースは、大きな正と大きな負の混合から最適値が得られる場合に発生します。 たとえば、入力`[-100, 1, 2]`から 202 が得られます`2 - (-100)`または、存在する値に応じて乗算から 200 になります。 アルゴリズムは両極端を維持するため、両方の候補が最終的な列挙で直接評価されます。 

もう 1 つのエッジ ケースは、ゼロが負の値と並んで存在する場合です。 明示的にゼロを含めない場合、次のような場合`[-5, 0, 1]`正解を見逃してしまいます`5`から`0 - (-5)`。 このアルゴリズムは候補セットにゼロを明示的に挿入し、ゼロを含む減算と乗算が確実に考慮されるようにします。 

最後に、次のようにすべての値が同一の場合、`[7, 7, 7]`の場合でも、最大値と最小値の両方が同じであり、ペアの評価により正しい反復積、和、および差が自明に得られるため、候補の削減は依然として正確さを維持します。
