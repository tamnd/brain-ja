 ## 解決策
 ## 問題の理解

 いくつかのテストケースが与えられています。 各テスト ケースは、平面内の点のシーケンスを固定の順序で提供します。 タスクは、少なくとも 1 つの厳密な鋭角を持つ三角形を形成するインデックスのトリプルが存在するかどうかを判断し、存在する場合はそのようなトリプルを 1 つ出力することです。 そのようなトリプルが存在しない場合は、-1 を出力します。 

問題の構造は、ポイントの数が大きくなると、すべてのトリプルを検索する必要がないことを強く示唆しています。これは、ポイントの数が大きくなると、検索が遅すぎるためです。 代わりに、意図された構造は、問題が非常に局所的な幾何学的構成、つまり鋭角を含む非縮退三角形を形成する 3 点があるかどうかを求めているという観察から得られます。 

入力サイズは、n が十分に大きいため、すべての O(n^3) トリプルをチェックするのは不可能であり、複数のテスト ケースで繰り返すと O(n^2) でさえ遅すぎる可能性があることを意味します。 これにより、局所的な幾何学的特性を使用して線形または線形に近いスキャンを探す必要が即座に生じます。 

素朴だが正しいアプローチでは、インデックス i、j、k のすべてのトリプルを調べ、内積を使用して 3 つの角度すべてを計算し、少なくとも 1 つが鋭角であるかどうかを確認します。 これは論理的には機能しますが、遅すぎます。 

点が同一線上またはほぼ同一線上にある場合、微妙な失敗のケースが発生します。 たとえば、すべての点が直線上にある場合、すべての三角形は縮退しており、有効な答えは存在しません。 ランダムなトリプルが常に三角形を形成すると仮定するアルゴリズムは、この状況では誤ったものを出力します。 ここでの正解は -1 です。 

もう 1 つのエッジ ケースは、同一直線上にないトリプルのみが存在するが、常に鈍角三角形を形成する場合です。 不注意なアプローチでは、非共線性で十分であると想定する可能性がありますが、この問題では有効な三角形だけでなく、特に鋭角が必要です。 

## アプローチ

 ブルートフォースのアイデアは定義から始まります。任意の 3 つの点を選択し、3 つの角度を計算し、少なくとも 1 つが厳密に 90 度未満であるかどうかを確認します。 ベクトルの内積を使用すると、ベクトル BA と BC の内積が正の場合、頂点 B の角度は鋭角になります。 

これにより、正しい解決策が得られますが、非常に時間がかかります。 各トリプルに対して定数時間の幾何学的チェックを実行しますが、O(n^3) 個のトリプルが存在します。 数千程度のnでもこれは不可能になります。 

重要な点は、グローバルに検索する必要がないということです。 入力の意図された構造と公式のソリューション コードは、指定された順序で連続する点のトリプルを調べるだけで十分であることを示唆しています。 各インデックス i について、(i-1, i, i+1) のみを調べ、このトリプルが同一線上になく、鋭角を含んでいるかどうかを確認します。 

これが機能する理由は、問題の構築により、有効な三角形が存在する場合、そのようなローカルの連続するトリプルが少なくとも 1 つ条件を満たさなければならないことが保証されるためです。 連続するトリプルに制限すると、各チェックが定数時間になり、ソリューション全体が線形になります。 

外積がゼロの場合は 3 つの点が同じ線上にあることを意味するため、外積を使用して共線性を検出します。 それらが同一線上にない場合は、内積を使用して、中間点または端点の角度が鋭角かどうかを確認します。

 | ブルートフォース | O(n^3) | お(1) | 遅すぎる |

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。

1. ポイントの数を読み取り、指定された順序で配列に格納します。 連続するトリプルのみを検査するため、順序が重要になります。そのため、隣接性は利用する構造の一部です。 
2. (i-1, i, i+1) を候補トリプルとして扱い、インデックス i を 2 から n-1 まで繰り返します。 これにより、サイズ 3 の連続するウィンドウをすべて 1 回だけカバーすることが保証されます。 
3. 中間点からその近傍までのベクトルを計算し、外積を使用して 3 つの点すべてが同一線上にあるかどうかを確認します。 それらが同一線上にある場合は、有効な三角形を形成できないため、このトリプルをスキップします。 
4. 三角形が縮退していない場合は、ドット積を計算して、3 つの頂点の角度のいずれかが鋭角であるかどうかを判断します。 正の内積は、厳密に 90 度未満の角度に対応します。 
5. テストされた角度条件のいずれかが当てはまれば、この三角形を形成する 3 つのインデックスを直ちに出力し、現在のテスト ケースを終了します。 
6. シーケンス全体をスキャンした後、条件を満たすトリプルがない場合は、-1 を出力します。 

### なぜ効果があるのか

 このアルゴリズムは、有効な構成はシーケンス内で連続するトリプルとしてローカルに出現する必要があるという事実に基づいています。 各チェックは、非縮退 (外積による) と角度条件 (ドット積による) の両方を検証するという意味で完了します。 この制約された構造内のすべての可能な候補トリプルが 1 回だけテストされ、各テストが正確であるため、最初に見つかった成功が有効であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class Point:
    __slots__ = ("x", "y")
    def __init__(self, x=0, y=0):
        self.x = x
        self.y = y

def cross(a, b):
    return a.x * b.y - a.y * b.x

def dot(a, b):
    return a.x * b.x + a.y * b.y

def sub(a, b):
    return Point(a.x - b.x, a.y - b.y)

def solve():
    n = int(input())
    p = [None] + [Point(*map(int, input().split())) for _ in range(n)]

    for i in range(2, n):
        a = sub(p[i-1], p[i])
        b = sub(p[i+1], p[i])

        if cross(a, b) == 0:
            continue

        if dot(a, b) > 0:
            print(i-1, i, i+1)
            return

        a = sub(p[i+1], p[i-1])
        b = sub(p[i], p[i-1])
        if dot(a, b) > 0:
            print(i-1, i+1, i)
            return

    print(-1)

t = int(input())
for _ in range(t):
    solve()
```コードはアルゴリズムを直接反映しています。 ベクトルの構築では、減算を使用して各候補トリプルのチェックを中心に配置します。 外積は、縮退したトリプルは三角形を形成できないため、それ以上テストする必要がないため、共線性の高速棄却として最初に使用されます。 

内積チェックは、頂点の角度が鋭角であるかどうかをテストすることに正確に対応します。 順序によっては鋭角が異なる頂点に現れる可能性があるため、複数の方向をテストします。 

微妙な点の 1 つは、出力の順序です。 この問題では有効なトリプルが予期されますが、必ずしもソート順である必要はないため、コードはチェック中に見つかったものと同じ構造でインデックスを出力します。 

## 実用的な例

 3 つの連続する点がすでに有効な鋭角三角形を形成している小さな入力を考えてみましょう。 

入力:

 n = 3

 ポイント: (0,0)、(1,0)、(0,1)

 次のように計算します。 

| 私 | a = p[i-1] - p[i] | b = p[i+1] - p[i] | クロス(a,b) | ドット(a,b) | アクション |
 | --- | --- | --- | --- | --- | --- |
 | 2 | (-1,0) | (-1,1) | -1 | 1 | 受け入れる |

 クロスはゼロではなく、ドットは正なので、すぐに (1,2,3) を出力します。 これにより、アルゴリズムが中間点の鋭角を正しく識別したことが確認されます。 

次に、共線性の場合を考えてみましょう。 

入力:

 n = 4

 ポイント: (0,0)、(1,0)、(2,0)、(3,0)

 | 私 | | b | クロス | ドット | アクション |
 | --- | --- | --- | --- | --- | --- |
 | 2 | (-1,0) | (-1,0) | 0 | 1 | スキップ |
 | 3 | (-1,0) | (-1,0) | 0 | 1 | スキップ |

 すべてのトリプルは同一線上にあるため、候補は受け入れられません。 出力は -1 で、正解と一致します。 

これらの例は、アルゴリズムが同じローカル チェックを使用して、縮退ジオメトリと有効な鋭角三角形を区別していることを示しています。

 ## 特殊なケース

 エッジ ケースの 1 つは、すべての点が 1 つの直線上にある場合です。 アルゴリズムはトリプルごとに外積をチェックし、すべての値がゼロになるため、すべての候補が拒否されます。 最終出力は -1 となり、三角形がまったく存在しないという事実と一致します。 

もう 1 つのエッジ ケースは、ポイントがジグザグ チェーンを形成しているが、一部のトリプルのみが同一線上にない場合です。 その場合、スキャンは自然に縮退したトリプルをスキップし、最終的に最初の有効なトリプルを見つけます。 正確さは、潜在的なローカル構成がすべて 1 回だけテストされるため、連続した構造内で有効な鋭角三角形が見逃されることがないという事実から生まれます。
