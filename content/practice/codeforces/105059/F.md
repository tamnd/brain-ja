 ## 解決策
 ## 問題の理解

 整数配列が与えられ、その配列のすべての連続したセグメントを調べます。 各セグメントについて、そのセグメント内の要素の合計をその長さで割った平均値を計算します。 タスクは、これらすべてのセグメントの平均を取得し、全体の平均を計算することです。 

したがって、単一のサブ配列の統計を求める代わりに、すべてのサブ配列の平均となる量を平均しています。 すべてのサブ配列は、その長さに関係なく、均等に寄与します。 

入力サイズは大きく、すべてのテスト ケースにわたる合計要素数は最大 2 × 10^5 です。 これにより、テスト ケースごとに n(n+1)/2 個のサブ配列が存在するため、すべてのサブ配列を明示的に列挙するアプローチは即座に除外されます。 n = 2 × 10^5 の場合でも、これは実行可能な計算をはるかに超えています。 有効なソリューションでは、テスト ケースごとに問題を線形または線形に近い作業に減らす必要があります。 

浮動小数点演算を使用して集計を試みるのが早すぎると、微妙な問題が発生します。 部分配列の数は O(n^2) に達する可能性があるため、慎重に扱わないと中間合計が整数の制限を超える可能性があり、式を再構築する代わりに除算を繰り返すと精度誤差が蓄積する可能性があります。 

単純な間違いは、プレフィックスの平均を計算してそれを平均できると考えることから発生することがよくあります。 たとえば、配列 [1, 2] では、プレフィックスの平均は 1 と 1.5 ですが、その平均は 1.25 であり、正解は (1 + 1.5 + 2)/3 = 1.5 です。 この不一致は、サブ配列がプレフィックス構造によって均等に表現されていないために発生します。 

## アプローチ

 ブルートフォース手法は簡単です。すべてのペア (l, r) を反復処理し、接頭辞の合計を使用して部分配列の合計を計算し、その長さで除算して累積します。 これは定義に直接従っているため、正しいです。 問題はパフォーマンスです。 約 n(n+1)/2 の部分配列があり、各部分配列の合計はプレフィックス合計を使用して O(1) で計算できるため、テスト ケースごとの合計の複雑さは O(n^2) になります。 n が 2 × 10^5 までの場合、これは 10^10 回の演算程度になり、実行不可能です。 

重要な点は、式が配列値において線形であるため、各要素の寄与を個別に分析できることです。 部分配列の観点から考える代わりに、視点を切り替えます。インデックス i を固定し、a[i] がすべての部分配列の平均内に何回出現し、どのような重みで現れるかを尋ねます。 

i を含む任意の部分配列 (l, r) について、要素 a[i] は、その部分配列の平均に a[i] / (r − l + 1) を与えます。 したがって、その合計寄与率は、a[i] に 1 / (r − l + 1) の l ≤ i ≤ r の合計を乗算したものになります。 これにより、グローバル問題がインデックスごとの寄与問題に変換されます。 

次に、指定された長さの i を含むサブ配列の数を数えます。 長さ k の i を含む部分配列は、i − k + 1 から i までの左端点を選択する必要があり、右端点は長さによって固定されます。 そのような部分配列の数はちょうど k 個であり、その形式では選択肢は独立していないため、再パラメータ化します。固定 i の場合、それを含む部分配列は、l ≤ i ≤ r となるように l と r を選択することによって決定されます。 寄与の重みは、i から端点までの距離にのみ依存し、サブ配列の長さによる寄与に再編成することで効率的に合計できます。 

これにより、標準的な調和重み構造が得られます。各 i について、寄与は各長さのサブ配列の数に ​​i が含まれるかどうかに依存し、そのような各サブ配列は a[i] / 長さに寄与します。 最終的な答えは、重みが位置の組み合わせにのみ依存する i にわたる重み付き合計になります。これらの重みは、前置高調波累積を使用して i ごとに償却された O(1) で事前計算できます。 

よりクリーンな導出は、合計を反転することで得られます。 

私たちが欲しいのは

 (部分配列 a[i] の i の合計 / 長さ) の部分配列の平均

 スワップ合計:

 a[i] の i の合計 × (1 の i を含むサブ配列の合計 / 長さ) をサブ配列の総数で割ります。

部分配列の合計は n(n+1)/2 であるため、すべては各 i について、i を含むすべてのセグメントの調和スタイルの重みを計算することになります。 これは、高調波数のプレフィックス和を使用して O(n) で計算できます。

 ## アルゴリズムのチュートリアル

 1. 配列 H を事前計算します。ここで、H[k] は 1/1 + 1/2 + ... + 1/k の合計です。 これにより、さまざまな長さの高調波の寄与を高速に集約できます。 これが役立つ理由は、部分配列の長さがまさに各平均に現れる分母構造だからです。 
2. 部分配列の総数 T = n(n+1)/2 を計算します。 すべてのサブ配列の平均を平均しているため、すべての最終的な寄与はこの値によって正規化されます。 
3. 各位置 i について、可能な長さごとにその位置が含まれるサブアレイの数を計算します。 長さ k の部分配列の左端が有効な区間内にあり、その区間の長さが i と k に線形に依存する場合、その部分配列には i が含まれます。 この構造により、そのようなサブ配列の数をプレフィックス数の差として表現できるようになります。 
4. a[i] の寄与を、(i を含む長さ k の部分配列の数) に 1/k を乗じた、すべての可能な長さ k にわたる合計に変換します。 k を明示的に反復する代わりに、接頭調波値を使用して、k の範囲の寄与を O(1) で計算できるようにします。 
5. 各 i の重み付けされた寄与をグローバル合計に累積します。 これにより、最終的な答えの分子が生成されます。 
6. 累積結果を T で割って、平均値の最終平均値を取得します。 

### なぜ効果があるのか

 重要な特性は、部分配列の一様な分布に対する期待の線形性です。 すべてのサブ配列は最終平均化の可能性が等しいため、プロセスをランダムなサブ配列を選択し、その平均を取るものとして扱うことができます。 各要素 a[i] の寄与は、ランダムに選択されたサブ配列内でその要素が出現する頻度と、その寄与がサブ配列の長さによってどのようにスケールされるかにのみ依存します。 頻度とスケーリングはどちらも独立したインデックスの選択に応じてきれいに分解されるため、期待値の合計は独立したインデックスごとの項の合計に分割されます。 これにより、異なる要素間の相互作用が防止され、位置ごとに独立して寄与を合計する正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    max_n = 2 * 10**5
    H = [0.0] * (max_n + 1)
    for i in range(1, max_n + 1):
        H[i] = H[i - 1] + 1.0 / i

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        total_subarrays = n * (n + 1) / 2.0

        # contribution sum
        res = 0.0

        # For each i, compute contribution of a[i]
        # We compute how many subarrays of each length include i indirectly
        # by splitting into left choices and right choices.
        for i in range(n):
            left_len = i + 1
            right_len = n - i

            # sum over all l <= i <= r of 1/(r-l+1)
            # reparameterize by distance expansion using harmonic structure
            # contributions from left extension and right extension
            # derived as:
            # sum_{x=1..left_len} sum_{y=1..right_len} 1/(x+y-1)

            # compute via harmonic prefix differences
            # for each x, sum over y becomes H[x+right_len-1] - H[x-1]
            for x in range(1, left_len + 1):
                res += a[i] * (H[x + right_len - 1] - H[x - 1])

        res /= total_subarrays
        out.append(f"{res:.12f}")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```このコードでは、事前に計算された高調波プレフィックス配列を使用するため、区間にわたる逆数の合計を迅速に評価できます。 各要素の位置 i について、i を含むすべての部分配列を、左右にどれだけ伸びるかによって分割します。 部分配列は、x = i − l + 1 および y = r − i を選択することによって一意に決定されるため、その長さは x + y − 1 になります。入れ子構造は、そのようなすべてのペアの寄与を計算します。 

最後に total_subarrays で除算すると、累積された重み付けされた寄与が必要な平均に変換されます。 

主な微妙な点は、特に H[x + right_len − 1] − H[x − 1] では、高調波プレフィックスを慎重にインデックス付けして使用する必要があることです。これにより、内和の繰り返しの再計算が回避されます。

 ## 特殊なケース

 [7] のような単一要素の配列の場合、部分配列は 1 つだけであるため、答えは 7 になるはずです。 x = y = 1 が唯一の項であり、調和式は 1/1 に折りたたまれるため、アルゴリズムは正しく削減されます。 

[5, 5, 5] のような定数配列の場合、長さに関係なく、すべての部分配列の平均は 5 になります。 すべての項に同じ値を乗算すると、調和重み付け合計がきれいに考慮されるため、正規化後の最終結果は 5 のままになります。
