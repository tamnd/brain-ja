 ## 解決策
 ## 問題の理解

 各頂点が核を表すツリーが与えられます。 すべてのノードには 2 つの独立した属性があり、1 つは中性子数として、もう 1 つは陽子数として考えることができます。 木のエッジは考えられる相互作用を表しており、電荷がエッジを横切って移動するたびに、方向と、中性子ベースの差分を使用するか陽子ベースの差分を使用するかの選択に応じて、電荷の値が変化します。 

より正確には、ノード i からノード j に移動するときに、現在の電荷を aj − ai または bj − bi だけ増加させることができます。 このプロセスは、初期電荷が 1 に等しい特別なノード s で開始され、電荷はツリーを通じて伝播され、すべてのノードが s からの一意のパスに沿って行われた選択に応じて何らかの値を受け取ります。 

タスクは、この伝播プロセスの後に任意のノードに現れる可能性のある最大電荷値を決定することです。 

この制約では最大 10^5 のノードが許可され、ノードごとに値を個別に再計算したり、エッジ遷移の可能な選択肢をすべて列挙しようとしたりするソリューションは即座に除外されます。 パス上の指数関数的分岐やノードごとの二次走査を伴うアプローチは遅すぎます。 ツリー構造は、各ノードが最初から一意のパスによって到達されることを示唆しているため、課題は接続性ではなく、これらの固定パスに沿って選択肢を最適化することです。 

素朴な推論による微妙な失敗例は、パスに沿った一貫性を考慮せずに、各エッジが独立して可能な限り最良のデルタに寄与すると仮定することです。 たとえば、エッジごとに max(bj − bi, aj − ai) を貪欲に選択すると、共有ノード値を通じて選択が相互作用するため、失敗する可能性があります。 

もう 1 つの落とし穴は、問題がすべての a 値またはすべての b 値をグローバルに選択することと同等であると想定していることです。 これも失敗します。最適な選択はエッジごとに両方を組み合わせることができますが、制御された方法で伸縮する構造を伴うためです。 

## アプローチ

 強引な解釈では、すべてのエッジ トラバーサルに対する a または b の可能なすべての割り当てを調査しようとします。 s から任意のノードまでの各パスの長さは最大 O(n) であるため、最悪の場合は 2^(n) 通りの組み合わせが考えられます。 パス上の動的プログラミングに限定しても役に立ちません。構造を持たずにノードごとに最適な値を再計算すると、合計作業量が依然として O(n^2) になるからです。 

重要な観察は、各エッジでは 2 つの選択肢が可能ですが、各ノードの効果がパス履歴から独立するようにパスに沿った寄与を再編成できることです。 これが機能する理由は、すべての動きがノード値の違いのみに依存するためです。そのため、パスに沿って合計を拡張すると、意図的に対称性を破らない限り、内部ノードの寄与が構造化された方法でキャンセルされます。 

ノードがパスに出現するときにどのように寄与するかを検査すると、そのノードは差分のソースまたは宛先として機能します。 発生ごとに、a を使用するか b を使用するかを独自に選択します。 これにより、パス全体がノードの出現ごとの独立したローカル寄与の合計に変換されます。 これにより、問題はパス依存の組み合わせ論から単純なツリーの累積に軽減されます。 

この形式で書き換えられると、各ノードは固定の最適な内部値を提供し、パスのエンドポイントのみに特別な処理が必要になります。 これにより、 からの単一の DFS が可能になります。

 ## アルゴリズムのチュートリアル

 ツリーを s にルートし、s から外側へのパスに沿って値を計算します。 

### ステップ

1. s でツリーを根付けします。 これにより、すべてのノードの一意の親が固定され、ルートからノードへのチェーンとしてパスを推論できるようになります。 エッジの寄与は方向に依存するため、方向が重要です。 
2. 各ノード i について、2 つのローカル量 (ai と bi の最大値、および ai と bi の最小値) を計算します。 これらは、ノードがプラスまたはマイナスに寄与する場合の最良の選択と最悪の選択を表します。 
3. v 自体の最終的な正の寄与を除いて、ルート s からノード v までの累積寄与を表す実行値 dp[v] を定義します。 s は最初のエッジに沿った出力差分のソースとしてのみ機能するため、dp[s] を −min(as, bs) として初期化します。 
4. から DFS または BFS を使用してツリーを走査します。 親 u から子 v に移動するときは、dp[v] を dp[u] + (max(av, bv) − min(av, bv)) として更新します。 これは、内部ノードがパスに沿って 1 つの正の発生と 1 つの負の発生の両方に寄与しているという事実を捉えています。 
5. 各ノード v について、その最終的な達成可能な値を dp[v] + max(av, bv) として計算します。 これにより、端末ノードとして v に可能な限り最高の受信寄与が追加されます。 
6. すべてのノードの最大値を追跡します。 

### なぜ効果があるのか

 s から v までのすべてのパスは、パスに沿った各ノードからの寄与に分解できます。 各内部ノードは、エッジ トラバーサル内でちょうど 2 回、つまり送信元として 1 回、宛先として 1 回表示されます。 各エッジトラバーサルで a または b を個別に選択できるため、最適な戦略は、正の出現に大きい値を割り当て、負の出現に小さい値を割り当てることです。 これにより、各内部ノードは、パス構造に関係なく、正確に max(ai, bi) − min(ai, bi) に寄与するようになります。 エンドポイントはこの対称性を破るため、s と v は別々に処理されます。 これにより、dp[v] が v までの最良の累積をエンコードすることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    n, s = map(int, input().split())
    a = [0] + list(map(int, input().split()))
    b = [0] + list(map(int, input().split()))
    
    g = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        g[u].append(v)
        g[v].append(u)

    hi = [0] * (n + 1)
    lo = [0] * (n + 1)
    for i in range(1, n + 1):
        hi[i] = max(a[i], b[i])
        lo[i] = min(a[i], b[i])

    dp = [0] * (n + 1)
    visited = [False] * (n + 1)

    dp[s] = -lo[s]
    visited[s] = True

    ans = -10**30

    stack = [s]

    while stack:
        u = stack.pop()
        ans = max(ans, dp[u] + hi[u])

        for v in g[u]:
            if not visited[v]:
                visited[v] = True
                dp[v] = dp[u] + (hi[v] - lo[v])
                stack.append(v)

    print(ans)

if __name__ == "__main__":
    solve()
```実装では、各遷移が一定時間になるように、最初にすべてのノードの hi と lo を事前計算します。 DFS スタックにより、線形の複雑さを維持しながら、各エッジを 1 回だけトラバースすることが保証されます。 dp 配列にはルートからの累積された内部寄与が格納され、最終的な答えは各ノードで受信される最良の寄与を加算することによって計算されます。 

初期化 dp[s] = −lo[s] は、ルートに入力エッジがないという事実をエンコードするため、最初の遷移で 1 回だけマイナスに寄与します。 他のすべてのノードは、dp 遷移式を通じてプラスとマイナスの両方に寄与します。

 ## 特殊なケース

 最小限の単一ノード ツリーにより、初期化動作が分離されます。 その場合、 dp[s] は -min(as, bs) で、最終値は max(as, bs) になります。これは、遷移は発生せず、最適な固有ノード値のみが重要であるという考えと正確に一致します。 

2 ノード ツリーでは、最初のエッジの符号処理が強調されます。 s から開始する遷移では、どちらのエンドポイントも二重にカウントすることなく、単一の hi 〜 lo 寄与を正しく適用する必要があります。 

星型ツリーは、複数の子がルートから同じ dp ベースを独立して継承するかどうかをテストします。 各子は s からの同じ累積値を使用するため、正確さはブランチ間の相互汚染がないことを保証することに依存します。これはツリー トラバーサルと独立した dp 更新によって保証されます。
