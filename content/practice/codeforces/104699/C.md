 ## 解決策
 ## 問題の理解

 一連の棚が与えられ、各棚には固定数の人形が入っています。 最初に子供のグループがこれらの棚に分散され、各棚に立っている子供が毎秒その棚から人形を 1 つずつ取り出します。 一瞬の間に棚の人形がなくなった場合、その瞬間に棚から人形をうまく取り出すことができるのは一部の子供たちだけであり、残りの子供たちは次の瞬間に自分たちを支えるのに十分な人形がまだある他の棚にすぐに転送されます。 一部の子供たちは、最終的に続行するための有効な棚を見つけることができず、すでに集めたものをすべて持って去ってしまうかもしれません。 

この問題における重要な自由度は、棚全体のすべての子の初期配置を選択できることです。 問題は、最終的にすべての子供がまったく同じ数の人形を受け取るような、何らかの初期割り当てが存在するかどうかです。 

入力により、棚と子の数が与えられ、その後に各棚にある人形の数が続きます。 出力は、そのような公平な割り当てが存在するかどうかという二者択一の決定です。 

制約$n \le 10^5$そして$m \le 10^9$個々の子供や数秒のレベルでのシミュレーションは不可能であることがすぐにわかります。 すべての子を反復処理するだけでもすでに大きすぎるため、棚間の移動をシミュレートすると明らかに制限を超えてしまいます。 ソリューションでは、プロセス全体を配列から導出される少数の集合量に分解する必要があります。 

人形の総数が子供の数よりも少ない場合、微妙なエッジケースが現れます。 そうなると、たとえ完璧に分配したとしても、少なくとも一人の子供は人形を一個も受け取ることができず、平等な分配は不可能となる。 人形の総数が子供の数で割り切れない場合、別の特殊なケースが発生します。 すべての人形は最終的には誰かの子供に取られ、最終的な数が等しい必要があるため、割り算が必要です。 

単純なアプローチでは、子を棚に貪欲に割り当ててフローをシミュレートしようとする可能性がありますが、子は棚間を動的に移動でき、その相互作用は静的な割り当てではなく時間の発展に依存するため、すぐに曖昧さに陥ります。 このため、個々のパスに関する直接的な推論は誤解を招きます。 

## アプローチ

 強引な戦略は、プロセス全体を明示的にシミュレートすることです。子供たちを棚に割り当て、秒ごとの消費プロセスを実行し、オーバーフローの動きを処理し、各子供が集めた人形の数を追跡します。 これはステートメントに文字通り従うため、概念的には簡単です。 ただし、各秒ごとに棚にいるすべての子供が関与する可能性があり、子供は棚間を繰り返し移動する可能性があります。 最悪の場合、次のような問題が発生します。$O(m \cdot \text{time})$操作は、次のことを考えると実行不可能です$m$それ自体は最大です$10^9$。 

重要な観察は、複雑な動作ルールにもかかわらず、人形は作成または破壊されず、プロセスが終了するまで最終的にはすべての人形がちょうど 1 人の子供によって取られるということです。 動きのダイナミクスは、_誰がどの人形を撮るかにのみ影響し、_合計で何人の人形が撮影されるか_には影響しません。 したがって、意味のある唯一の数量は、入手可能な人形の総数です。 

人形の総数が$S = \sum a_i$、成功したシナリオでは、すべての人形が均等に分割される必要があります。$m$すべての子は同じ番号で終わるためです。 これは、各子供が受け取る必要があることを直ちに意味します。$S / m$人形、整数でなければなりません。 

この条件が成立すると、移動ルールによって追加の構造的制約が課されることはなくなります。 どのような配置も同一のユニットの流れとして解釈でき、すべての人形は同等であるため、常に均等な分割を実現する方法で子を割り当てることができます。 

したがって、問題は完全に、合計が子供の数で割り切れるかどうかを確認することに帰着します。

 ## アルゴリズムのチュートリアル

 1. すべての棚の人形の合計数を計算します。 これは、すべての子に分配する必要があるリソースの全量を表します。 
2. この合計が子供の数以上であるかどうかを確認します。 それが小さい場合、必然的に人形を受け取らない子供もいれば、より多くの人形を受け取る子供もいて、平等は不可能になります。 
3. 人形の総数が子供の数で割り切れるかどうかを確認します。 割り切れない場合は、子の配置に関係なく、均等な分割は存在しません。 
4. 両方の条件が満たされる場合、有効な取り決めが存在すると結論付けます。 

この手順の背後にある理由は、プロセスが純粋に再分配であるためです。 子どもたちの移動は、地域全体の消費順序にのみ影響を及ぼし、世界全体には影響しません。 すべての人形は一度だけ消費されるため、最終的な配布では地球環境保護を尊重する必要があります。 

### なぜ効果があるのか

 システムは常に、消費されたすべての人形が正確に 1 人の子供に割り当てられると終了します。子供は、総配布が許可する以上の人形を持って終了することはできません。 最終的な要件ではすべての子供が区別できないため、唯一可能な安定した構成は、消費される人形の総数が均等に分割される構成です。 不均衡は、部分的または残りの割り当てを意味し、消費の離散的な性質に矛盾します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    
    total = sum(a)
    
    if total < m:
        print("NO")
        return
    
    if total % m != 0:
        print("NO")
        return
    
    print("YES")

if __name__ == "__main__":
    solve()
```このソリューションは配列を読み取り、人形の総数を集計し、地球規模の保全から導き出された 2 つの必要な条件を適用します。 このプロセスは全体的な実現可能性に影響を与えず、配布順序のみに影響を与えるため、位置を追跡したり、動きをシミュレートしたりする必要はありません。 

よくある間違いは、棚間の子供の動きをモデル化しようとすることです。 これにより、結果の基準は変更されずに不必要な複雑さが生じます。

 ## 特殊なケース

 子供が 1 人しかいない場合、最小限のケースが発生します。 その状況では、すべての人形が自然にその子の元に行き、割り算が常に成り立つため、ゼロ以外の合計はすぐに機能します。 

人形の総数が子の数より少ない場合、プロセスは子ごとに 1 つの人形も割り当てることができないため、平等は不可能です。 アルゴリズムはこれを正しく拒否します。`total < m`チェック。 

合計が子の数で正確に割り切れる場合、棚間での分布が非常に不均一であっても問題になりません。 このシステムは常に同一のユニットを再配布していると解釈できるため、実現可能性はアルゴリズムが直接捕捉する算術一貫性のみに依存します。
