 ## 解決策
 ## 問題の理解

 私たちは、石積みの円形で行われる 2 人用ゲームを分析するように求められました。 各山には特定の数の石があります。 プレイヤーは順番に、現在の山から正の数の石を取り除きます。 ターンは時計回りに進むため、プレイヤーが山から石を削除した後、`i`、次のプレイヤーは山から石を取り除かなければなりません`i+1`、最後の山の後に最初の山に回り込みます。 自分の番に空の山に遭遇したプレイヤーは負けます。 マイクはいつも最初に行きます。 

入力は複数のテスト ケースを記述し、それぞれが杭の数とそのサイズを指定します。 出力には、両方が最適にプレイした場合にどちらが勝つかを示す必要があります。 重要な観察は、杭の数が比較的少ないことです (`n ≤ 50`) ただし、石の数は多くなる可能性があります (`a_i ≤ 10^9`）。 これにより、可能な動きを順番にシミュレートするようなアルゴリズムは除外されます。これには数十億回の操作が必要となる可能性があります。 

すべての杭が同じサイズである場合、重要なエッジケースが発生します。 たとえば、次の場合`n = 2`そして両方の山は`100`石を取り除くと、マイクは最初の山からいくつかの石を取り除きます。 その後、ジョーは次の山で自分の動きを一致させることができますが、ゲームは対称的であるため、マイクは最初に空の山に遭遇することを余儀なくされます。 最初の山だけを見る単純な解決策では、誤ってマイクが勝者であると宣言する可能性があります。 もう 1 つのエッジケースは単一の山です。マイクはすべての石を取り除くだけですぐに勝ちます。 

## アプローチ

 ブルートフォース ソリューションでは、考えられるすべての動きをシミュレートしようとします。 各ターンで、最大 1 つ削除してみることができます。`a_i`現在の山から石を取り出し、勝者を再帰的に計算します。 このアプローチはゲームのルールに直接従うため正しいですが、その複雑さは法外です。各山には最大で`10^9`石が多く、徹底的なシミュレーションが不可能になります。 

重要な洞察は、各プレイヤーが時計回りの順序で次の山に移動する必要があることを観察することで得られます。 サイクルが通過した回数よりも石の数が少ない山に最初に遭遇したプレイヤーが負けます。 別の言い方をすると、開始シーケンス内のすべての前の山よりも厳密に小さい最初の山が勝者を決定します。前のプレーヤーは、その時点を超えて相手に勝利を強制することはできないためです。 この問題については、単純なチェックに帰着します。つまり、最初から杭を繰り返し、マイクがジョーの潜在的なミラーリングの動きに匹敵できない最初の山を見つけます。 マイクが最初に厳密に小さい山を持っていた場合、ジョーが勝ちます。 そうでなければ、マイクは即座に勝ちます。 

この観察により、潜在的に指数関数的な問題が、杭の数に関する線形問題に変換されます。 各テスト ケースを O(n) 時間で解決できます。これは、上限の場合でも効率的です。`t = 1000`テストケース。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 これにより、すべてのゲーム シナリオをループすることができます。 
2. 各テストケースについて、杭の数を読み取ります。`n`そしてパイルサイズの配列`a`。 
3. 変数を初期化する`winner`に`"Mike"`デフォルトとして。 
4. 最初の山から繰り返します。 以前の最小値よりも厳密に小さい山に遭遇した場合、それは、マイクがジョーのミラーリング戦略を危険にさらさずに安全に続行できないことを意味します。 アップデート`winner`に`"Joe"`そしてループを断ち切ります。 実際には、マイクが先に進む最初の山が決定的な山であるため、反復ではジョーが利用できる最も早い山を特定するだけで済みます。 
5. 各テスト ケースの勝者を出力します。 

機能する理由: ゲームは逐次的に行われ、それぞれの手が次の山に強制的に移されます。 相手のアドバンテージに匹敵するために必要な石の数よりも少ない石の山に最初に到達したプレイヤーが負けます。 パイルを 1 回スキャンすることで、誰が最初にこの負け条件に到達するかを決定します。 一方のプレーヤーが最適なプレーから逸脱しても、もう一方のプレーヤーの勝ちの差がより明確になるだけであるため、これにより正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    winner = "Mike"
    for i in range(n):
        if a[i] < min(a[:i], default=a[i]):
            winner = "Joe"
            break
    print(winner)
