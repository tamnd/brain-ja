 ## 解決策
 ## 問題の理解

 私たちには根のない木が与えられていますが、$n$頂点。 隠れた頂点がある$x$私たちが識別する必要があること。 実行できる唯一の操作は、いくつかの頂点を選択し、それぞれについて非表示の頂点までの距離を受け取るクエリです。 目標は、**必要なクエリの最小数**を決定して、一意に決定できることを保証することです。$x$、どの頂点であっても。 

より簡単に言うと、ツリーは道路で結ばれた都市のネットワークとして想像できます。$x$秘密の宝物がある都市です。 クエリは、「宝物は都市からどのくらい離れていますか」という質問に相当します。$v_i$？」 必要な最小限の質問数が私たちが求めているものです。 

制約により、最大で$2\cdot 10^5$すべてのテスト ケースにわたるノード。これは、アルゴリズムが線形よりも劣ることを意味します。$n$テストケースごとに実行すると遅すぎます。 各頂点に対して考えられるすべてのクエリのセットを試行する単純なアプローチでは、指数関数的な処理が必要になり、まったく実行不可能になります。 また、クエリが必要ない単一ノードのツリーや、エンドポイント近くのクエリが中心近くのクエリとは異なる動作をする可能性がある直線のツリーなどのエッジ ケースも考慮する必要があります。 

いくつかの非明白なエッジケースには、1 つの中心ノードが他のすべてのノードに接続する星型ツリーや、1 つの頂点での 1 つのクエリで十分な 2 ノード ツリーが含まれます。 不注意なアプローチでは、答えが常にツリーの深さに依存すると仮定する可能性がありますが、これは小さいツリーや対称ツリーの場合は当てはまりません。 

## アプローチ

 ブルートフォースアプローチは、考えられるすべてのクエリセットを考慮し、考えられるすべての隠れた頂点の距離をシミュレートすることです。 各セットについて、距離のセットがすべての頂点を一意に識別するかどうかを確認します。 これは論理的には正しいですが、まったく現実的ではありません。 のために$n = 10^5$、クエリサブセットの数は$2^n$これは天文学的な数字です。 

重要な観察は、問題が **木の直径特性**に帰着するということです。 木の直径が 1 (単一エッジ) であるか、単一ノードである場合、0 または 1 つのクエリが必要です。 チェーンが長い場合は、最も遠い点を考慮してください。直径の一端または中心でのクエリは、すべての頂点を一意に識別できます。これは、これらの点からの距離がツリー全体で一意のパターンを形成するためです。 より一般的には、ツリーはその直径に応じて 0、1、または 2 つのクエリで常に解決できます。 ツリーが単一の頂点である場合、クエリは必要ありません。 ツリーが「分岐」構造を持つ場合、多くの場合、直径の中心にある適切に選択された 1 つの頂点で十分です。 木が線であるか、複数の長い枝がある場合、直径の端にある 2 つのクエリは常に隠れた頂点を一意に識別します。 

したがって、最適なアプローチは、ツリーの直径を計算し、その長さに基づいてクエリの数を決定することです。 直径は 2 回の BFS トラバースで線形時間で計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * 2^n) | O(n) | 遅すぎる |
 | 直径ベースの最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、ツリー構造を読み取り、各頂点の隣接リストを作成します。 
2. もし$n = 1$、単一の頂点が自明に識別されるため、0 が出力されます。 
3. 任意のノード (通常はノード 1) から開始して BFS を実行し、最も遠いノードを見つけます。$u$。 これにより、$u$は木の直径の 1 つの端点です。 
4. 以下から始まる BFS を実行します。$u$最も遠いノードを見つけるには$v$から$u$。 間の距離$u$そして$v$木の直径です。 
5. 直径が 0 (単一の頂点) または 1 (接続された 2 つの頂点) の場合、クエリの最小数はそれぞれ 0 または 1 です。 
6. 直径が 1 より大きい場合、クエリの最小数は常に 2 です。これは、直径の端点をクエリすると、隠れた頂点を一意に識別する 2 つの距離値が生成されるためです。 他のすべての頂点には、これらの端点までの一意の距離のペアがあります。 
7. テスト ケースの計算されたクエリ数を出力します。 

これが機能する理由: 不変条件は、どの木でも、直径の端点をクエリすると、各頂点を一意に識別する距離が得られるということです。 端点は可能な限り離れているため、直径の端点までの距離のペアが同じ 2 つの頂点はありません。 これにより一意性が保証されます。 

## Python ソリューション```python
import sys
from collections import deque
input = sys.stdin.readline

def bfs_farthest(n, adj, start):
    dist = [-1] * (n + 1)
    dist[start] = 0
    q = deque([start])
    farthest_node = start
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
                if dist[v] > dist[farthest_node]:
                    farthest_node = v
    return farthest_node, dist

t = int(input())
for _ in range(t):
    n = int(input())
    adj = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        adj[u].append(v)
        adj[v].append(u)
    
    if n == 1:
        print(0)
        continue
    
    u, _ = bfs_farthest(n, adj, 1)
    v, dist = bfs_farthest(n, adj, u)
    diameter = max(dist)
    
    if diameter == 1:
        print(1)
    else:
        print(2)
```このコードは、隣接リストを使用してツリーを構築します。 の`bfs_farthest`関数は、開始ノードから最も遠いノードと距離配列を見つけます。 2 つの BFS 呼び出しにより、直径のエンドポイントと実際の直径の長さが決定されます。 直径に基づいて、正しいクエリ数が出力されます。 単一ノードツリーのエッジケースの処理には注意が必要です。 

## 実用的な例

 最初のサンプル入力の場合:

 | ステップ | BFS 開始 | 最遠ノード | 距離配列 | 直径 | クエリ |

 ## 特殊なケース

 単一ノードツリーの場合:

 入力:```
1
1
```アルゴリズムは BFS なしですぐに 0 を出力します。 これにより、些細なケースが正しく処理されます。 

星型ツリーの場合:

 入力:```
1
5
1 2
1 3
1 4
1 5
```ノード 1 からの BFS は最も遠いノード 2 に到達します。 ノード 2 からの BFS は、最も遠いノード 4 に到達します。 直径は 2 なので、アルゴリズムは 2 を出力します。2 つの直径の端点からの距離により、すべての頂点が一意に識別されます。 

3 つのノードのラインの場合:

 入力:```
1
3
1 2
2 3
```1 からの BFS は 3 を最も遠いものとして見つけます。 3 からの BFS は 1 を最も遠いものとして見つけます。 直径は 2 なので、2 つのクエリが必要です。 各頂点には、1 と 3 までの一意の距離のペアがあります。 

これらのトレースは正確さを裏付けます
