 ## 解決策
 ## 問題の理解

 個別の整数を含むグリッドが与えられます。 マイケルは寸法を選択します`h × w`、次に、ジョーは正確にそのサイズのサブ長方形を密かに選択します。 Michael は、どの四角形が選択されたかを確認する前に、Joe が選択した四角形内の最大値に名前を付ける必要があります。 

すべての値は個別であるため、ボード全体には固有のグローバル最大値があります。 マイケルは可能な限り勝利を保証できる`h × w`subrectangle には同じセルが含まれます。 その場合、ジョーの選択に関係なく、選択した長方形内の最大値は常にボード全体のグローバル最大値になります。 

タスクは可能な限り小さい領域を見つけることです`h · w`この保証が可能なもの。 

寸法は満たしています`n, m ≤ 40`、小さいです。 考えられるすべての長方形サイズを試すアルゴリズムも、簡単に入手できます。 あるのは`40 × 40 = 1600`可能`(h, w)`テスト ケースごとにペアがあるため、直接の数学的解決策で十分です。 

微妙な点は、マイケルがジョーがどのサブ長方形を選択したかを知る必要がないことです。 彼に必要なのは、考えられるすべての選択肢において最大であることが保証される数値だけです。 すべての値は異なるため、唯一の候補はボード全体のグローバル最大値です。 

次のグリッドについて考えてみましょう。```
1 2
3 4
```最大値`4`右下隅にあります。 選択する`h = 1, w = 1`Joe は次の内容を含むセルを選択できるため、失敗します。`1`、その最大値は`4`。 

正しい答えは、`4`、ボード全体を選択することで得られます。 四角形に最大値が含まれているかどうかだけをチェックする不注意なアプローチでは、誤った値が返されます。`1`。 

もう 1 つの簡単な間違いは、最大値が端にある可能性があることを忘れていることです。```
5 1 2
3 4 0
```最大値は位置です`(1,1)`。 答えは中心までの距離で決まりません。 長方形の寸法は、あらゆる配置に左上隅が含まれるように十分な大きさにする必要があります。 

## アプローチ

 ブルート フォースの観点は、グローバル最大値を含むセルを特定することから始まります。 セルが行にあるとします。`r`そしてコラム`c`1 から始まるインデックスを使用します。 

すべてのペアについて`(h, w)`考えられるものはすべて列挙できます`h × w`サブ長方形を作成し、それぞれに次のものが含まれているかどうかを確認します。`(r, c)`。 「はい」の場合、マイケルはその選択で勝ちます。 次に、最小面積を維持します。 

これは正しいです。なぜなら、すべての有効な四角形にグローバル最大セルが含まれている場合に、マイケルは正確に勝利するからです。 問題は、すべてのサイズについて、多くの長方形の位置を調べることになることです。 制約が十分小さいため、これでも問題は解決しますが、問題の実際の構造が隠蔽されています。 

重要な点は、長方形を列挙する必要がまったくないということです。 

固定高さの場合`h`、長方形の開始行は次のいずれかの値になります。`1`に`n - h + 1`。 

このようなすべての四角形に行が含まれるようにするには`r`、次の 2 つの条件が同時に成立する必要があります。```
start_row ≤ r
start_row + h - 1 ≥ r
```最も制限的な開始行は、可能な限り最小の開始行と最大の開始行です。 

最小のスタートは、`1`、これには以下が必要です。```
1 + h - 1 ≥ r
h ≥ r
```最大のスタートは、`n - h + 1`、これには以下が必要です。```
n - h + 1 ≤ r
h ≥ n - r + 1
```それらを組み合わせると次のようになります。```
h ≥ max(r, n - r + 1)
```列についてもまったく同じ理由で次のようになります。```
w ≥ max(c, m - c + 1)
```面積を最小限に抑えるために、有効な最小の高さと幅を選択します。```
h = max(r, n - r + 1)
w = max(c, m - c + 1)
```答えは単純です`h · w`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²m²) | お(1) | 概念的に遅すぎる、不要 |
 | 最適 | O(nm) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グリッドをスキャンして、グローバル最大値を含むセルを見つけます。 
2. その位置を次のようにします`(r, c)`1 から始まるインデックス付け。 
3. すべての有効な四角形に行を含める最小の高さを計算します。`r`:```
h = max(r, n - r + 1)
```これは、最上部または最下部の配置が行を回避できない最小の高さです。`r`。 
4. すべての有効な四角形に列を含めるための最小幅を計算します。`c`:```
w = max(c, m - c + 1)
```5. 出力:```
h × w
```### なぜ効果があるのか

 毎`h × w`有効な長さの行間隔ごとにその場合に限り、四角形には最大のセルが含まれます。`h`行が含まれています`r`および長さのすべての有効な列間隔`w`列が含まれています`c`。 

この性質を満たす最小の高さは次のとおりです。`max(r, n-r+1)`。 高さが小さい場合は、行をスキップして上部に配置するか、下部に配置することができます。`r`。 同じ議論が幅にも当てはまります。 

高さと幅は独立しているため、各寸法の有効な最小値を選択すると面積が最小化されます。 結果として得られるすべての四角形にはグローバル最大セルが含まれるため、その最大値は常に同じになります。 マイケルはいつでも正しく答えることができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, m = map(int, input().split())

    mx = -10**18
    r = c = 0

    for i in range(1, n + 1):
        row = list(map(int, input().split()))
        for j in range(1, m + 1):
            if row[j - 1] > mx:
                mx = row[j - 1]
                r, c = i, j

    h = max(r, n - r + 1)
    w = max(c, m - c + 1)

    print(h * w)
```最初のループはグリッドを読み取り、同時にグローバル最大値を見つけます。 すべての値は異なるため、最大セルも一意になります。 

その位置を見つけた後`(r, c)`、必要な高さと幅の公式は、上で展開した幾何学的な議論から直接導き出されます。 

1 から始まるインデックスを使用すると、式が簡素化されます。 数量`n - r + 1`そして`m - c + 1`包括的に測定された反対側の境界線までの距離を表します。 最大値を取ると遠い側が選択され、それによって長方形が避けられなくなるまでの大きさが決まります。 

各行を読み取る以外に追加の配列は必要ありません。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n, m = map(int, input().split())

        mx = -10**18
        r = c = 0

        for i in range(1, n + 1):
            row = list(map(int, input().split()))
            for j in range(1, m + 1):
                if row[j - 1] > mx:
                    mx = row[j - 1]
                    r, c = i, j

        ans.append(str(max(r, n - r + 1) *
                       max(c, m - c + 1)))

    print("\n".join(ans))

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    old_stdout = sys.stdout
    sys.stdout = out
    solve()
    sys.stdout = old_stdout
    return out.getvalue()

 ## 特殊なケース

 コーナーに最大値があるボードを考えてみましょう。```
1
2 2
10 1
2 3
```最大値は次のとおりです`(1,1)`。 

アルゴリズムは以下を計算します。```
h = max(1, 2) = 2
w = max(1, 2) = 2
answer = 4
```寸法を小さくすると、角を完全に避ける長方形が可能になります。 ボード全体が必要です。 

ここで、中心にある最大値を考えてみましょう。```
1
3 3
1 2 3
4 9 5
6 7 8
```最大値は次のとおりです`(2,2)`。 

アルゴリズムは以下を計算します。```
h = max(2, 2) = 2
w = max(2, 2) = 2
answer = 4
```毎`2 × 2`の長方形`3 × 3`ボードにはセンターセルが含まれています。 よくある間違いは、答えは次のとおりであると仮定することです。`3 × 3 = 9`、しかし、中心はすでにエリアで避けられなくなりました`4`。 

最後に、単一の行について考えてみましょう。```
1
1 5
1 2 10 3 4
```最大値は列です`3`。 

アルゴリズムは次のようになります。```
h = 1
w = max(3, 3) = 3
answer = 3
```長さ 5 の行にある長さ 3 のすべての連続セグメントには、中間位置が含まれます。 この式は、特別な場合を必要とせずに、1 次元のボードを自然に処理します。
