 ## 解決策
 ## 問題の理解

 整数のペアが何組あるかを数えるように求められます$(a, b)$一定の間隔内に存在する$[l, r]$そのような$l \le a \le b \le r$との間の特定の関係$a$そして$b$が成り立ちます: それらの最小公倍数と最大公約数の比は正確に次のようになります。$k$。 

表現$\frac{\mathrm{lcm}(a,b)}{\gcd(a,b)}$は古典的な数論的オブジェクトです。 書いてみると$a = g x$そして$b = g y$、 どこ$g = \gcd(a,b)$そして$\gcd(x,y)=1$、 それから$\mathrm{lcm}(a,b)=gxy$, したがって、比率は次のようになります$xy$。 この条件により、大きな数値の処理の問題が軽減されます。$10^9$積が正確に一致する互いに素のペアについて推論する$k$。 

各テスト ケースは独立しており、範囲境界は十分に大きいため、テスト ケース内のすべてのペアを直接列挙できます。$[l,r]$実現不可能です。 範囲サイズは最大です$10^9$, それでさえ$O((r-l)^2)$または$O(n^2)$インターバルの長さを超えることは不可能です。 テスト ケースの数は少ないですが、間隔の規模を補うことはできません。 

主な微妙な点は、条件が範囲内の 2 つの変数に依存しているように見えますが、実際には次の約数構造に因数分解されることです。$k$。 これは通常、有効なペアが次の因子ペアに対応することを示します。$k$共素性制約は構築によって自動的に削除されます。 

単純な間違いは、すべてを直接反復処理することです。$a, b$範囲内で gcd と lcm を計算します。 それは最大で可能です$10^{18}$最悪の場合の運用。 

もう 1 つのよくある間違ったアプローチは、ペアのみを考慮することです$(x, k/x)$gcd によるスケーリングを考慮せず、次の制約を無視します。$a$そして$b$中に横たわっていなければならない$[l,r]$。 たとえば、次の場合$k = 12$、のようなペア$(2,6)$基本レベルでは有効ですが、両方を乗算します。$g$妥当性を範囲依存の計数問題に移します。 

## アプローチ

 アイデンティティから始めます:$$\frac{\mathrm{lcm}(a,b)}{\gcd(a,b)} = xy$$書いた後$a = g x, b = g y$と$\gcd(x,y)=1$。 条件は次のようになります。$$xy = k, \quad \gcd(x,y)=1$$これはつまり$x$そして$y$～の互いに素因数のペアを形成する$k$。 一度$(x,y)$すべての有効なペアが固定されています$(a,b)$gcd 値を選択することで生成されます$g$、与える：$$a = g x,\quad b = g y$$範囲制約は次のようになります。$$l \le gx \le r,\quad l \le gy \le r$$これは次のように単純化されます。$$g \in \left[\left\lceil \frac{l}{x} \right\rceil, \left\lfloor \frac{r}{x} \right\rfloor\right]
\cap
\left[\left\lceil \frac{l}{y} \right\rceil, \left\lfloor \frac{r}{y} \right\rfloor\right]$$したがって、有効な互いに素な因数のペアはそれぞれ整数のカウントに寄与します。$g$2 つの区間の交差点にあります。 

ブルートフォースメソッドはすべてを試します$a$そして$b$で$[l,r]$、gcdとlcmを計算し、条件を確認します。 これは正しいですが、間隔には最大で次のものを含めることができるため、遅すぎます。$10^9$数字。 

重要な観察は、条件が次の因子ペアのみに依存するということです。$k$, したがって、候補の数は次の約数になります。$k$、これはせいぜい約$10^3$一般的な制約については、$10^9$。 これにより、二次範囲の問題が約数の列挙問題に分解されます。

 ## アルゴリズムのチュートリアル

 この問題を、有効な gcd スケールの共素因数ペアをカウントすることに変換します。 

1. すべての約数を列挙します$x$の$k$。 各約数について$x$、 定義する$y = k/x$。 これにより、次のすべての因子ペアが生成されます。$k$。 私たちに必要なのは$x \le y$順序を明示的に処理しない限り、対称ケースの二重カウントを避けるためです。 
2. ペアごとに$(x, y)$という意味で有効かどうかを確認してください。$\gcd(x,y)=1$。 共素でない場合はスキップしてください。 これにより分解が確実に行われます$a=gx, b=gy$gcd 構造と一致しています。 
3. 有効なペアごとに、次の許容範囲を計算します。$g$。 制約$l \le gx \le r$そして$l \le gy \le r$2 つの区間に変換します$g$。 以下を使用してそれらの交差を計算します。$$L = \max\left(\left\lceil \frac{l}{x} \right\rceil, \left\lceil \frac{l}{y} \right\rceil\right), \quad
R = \min\left(\left\lfloor \frac{r}{x} \right\rfloor, \left\lfloor \frac{r}{y} \right\rfloor\right)$$4. もし$L \le R$、それから、$R - L + 1$の有効な値$g$、それぞれが有効なペアを生成します$(a,b)$。 
5. すべての有効な因子ペアにわたる寄与を合計します。 

対称性を強制するため、対称性を個別に処理しません。$a \le b$自然に確保することで$x \le y$。 

### なぜ効果があるのか

 すべての有効なペア$(a,b)$次のように一意に書くことができます$a=gx, b=gy$どこ$g=\gcd(a,b)$そして$(x,y)$は互いに素のペアであり、その積は$k$。 gcd で割ると共有素因数がすべて削除され、縮小ペアが残るため、この表現は独特です。 このアルゴリズムは、考えられるすべての縮小ペアを 1 回だけ列挙し、それぞれについて、区間内に残るすべての考えられる gcd スケーリングをカウントします。 すべてのペアが見逃されることはありません。$(a,b)$独特の現象を引き起こす$(g,x,y)$、因子のペアが異なると異なる縮約形式が生成されるため、どのペアも二重にカウントされません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def solve():
    t = int(input())
    for _ in range(t):
        l, r, k = map(int, input().split())

        ans = 0

        x = 1
        while x * x <= k:
            if k % x == 0:
                y = k // x

                if math.gcd(x, y) == 1:
                    # compute valid g range
                    L1 = (l + x - 1) // x
                    R1 = r // x

                    L2 = (l + y - 1) // y
                    R2 = r // y

                    L = max(L1, L2)
                    R = min(R1, R2)

                    if L <= R:
                        ans += (R - L + 1)

                if x * x != k:
                    x2 = k // x
                    y2 = k // x2

                    if math.gcd(x2, y2) == 1:
                        L1 = (l + x2 - 1) // x2
                        R1 = r // x2

                        L2 = (l + y2 - 1) // y2
                        R2 = r // y2

                        L = max(L1, L2)
                        R = min(R1, R2)

                        if L <= R:
                            ans += (R - L + 1)

            x += 1

        print(ans)

if __name__ == "__main__":
    solve()
```実装は、最大まで除数を反復します。$\sqrt{k}$、ペアで相補的な約数を生成します。 各ペアについて、共素性をチェックし、有効な範囲を計算します。$g$。 上限と下限の演算は整数演算によって処理されます。$(l + x - 1) // x$与える$\lceil l/x \rceil$、 そして$r // x$与える$\lfloor r/x \rfloor$。 

実装の微妙な点は、対称性を慎重に扱うことです。 各約数のペアは 1 回処理されますが、コードは次の場合に二重カウントを避ける必要があります。$x = y$、つまり、いつ$k$は完全な正方形です。 条件$x * x != k$同じペアを 2 回再処理することを防ぎます。

 ## 特殊なケース

 主なエッジケースは次のような場合です$k=1$。 唯一の因子ペアは$(1,1)$、すべての有効なペアが必要です$a=b=g$。 アルゴリズムは計算します$g \in [l,r]$、正確に生産$r-l+1$すべての対角ペアが条件を満たすという事実と一致します。 

別のエッジケースが発生するのは次の場合です。$k$プライムです。 唯一の互いに素な因数のペアは、$(1,k)$。 有効なペアはすべてに対応します$g$両方とも$g$そして$gk$間に横たわる。 もし$k > 1$、これは厳しく制限します$g$、次の場合には貢献度がゼロになることがよくあります。$gk > r$。 

いつ$l=r$、同じ数字のペアのみが貢献できます。 アルゴリズムは、範囲の交差によってこれを自然に強制しますが、これは最大でも 1 つの有効な範囲に集約されます。$g$、選択した因子ペアがその時点で正確に適合するかどうかに応じて異なります。
