 ## 解決策
 ## 問題の理解

 可能な正の整数の長さのリストが与えられます。 このリストから、繰り返しを許可して 3 つの値を選択し、それらを中空の長方形のボックスの 3 つの寸法として解釈する必要があります。 選択した寸法が$a$、$b$、 そして$c$、ボックスの販売価格は次のように定義されます。$a^2 + b^2 + c^2$、製造コストは$ab + bc + ca$。 1 つのボックスからの利益はこれら 2 つの式の差であり、目標はどちらを選択するかです。$a$、$b$、 そして$c$この利益を最大化するにはリストから選択してください。 

したがって、タスクは最大化に帰着します$$(a^2 + b^2 + c^2) - (ab + bc + ca)$$すべてのトリプルにわたって$a, b, c$指定されたセットから取得されます。 

制約$N \le 5000$までの値$10^6$ナイーブな人をすぐに除外する$O(N^3)$すべてのトリプルの列挙。これには次のオーダーが含まれます。$125$上限は10億通りの組み合わせ。 平$O(N^2)$アプローチには、時間内に快適にフィットするように注意深い構造が必要です。 

微妙な点は、繰り返しが許可されていることです。 最適なソリューションには同じ値を複数回使用することが含まれる可能性があるため、これは重要です。たとえば、$a = b = c$、これにより式が簡素化され、混合選択肢を支配できるようになります。 

2 番目の明白ではないエッジ ケースは、最適なソリューションが非常にアンバランスな値から得られる場合です。 この式には二乗項と交差項が混在しているため、大きなスプレッドを好むのか均一な値を好むのかはすぐにはわかりません。 「最大の 3 つの値を選択する」または「極端な値を選択する」などの素朴で貪欲な直感は、次の値の間のトレードオフによっては失敗する可能性があります。$a^2$成長と$ab$罰則。 

## アプローチ

 ブルートフォースソリューションはすべてのトリプルを試行します$(a, b, c)$リストから利益を直接計算します。 これは正しいです。制約では、セット内のメンバーシップを超える追加の構造が定義されていないからです。 ただし、必要なのは$O(N^3)$評価、つまり$1.25 \times 10^{11}$操作時の操作$N = 5000$、合理的な制限時間をはるかに超えています。 

次に、目的関数を書き換えて構造を公開します。$$a^2 + b^2 + c^2 - ab - bc - ca$$この式はすべての変数で対称的であり、配列を並べ替えて極端な構成について推論することを示唆しています。 重要な観察は、どの固定ペアでも$(b, c)$、式は 2 次です。$a$:$$a^2 - a(b + c) + (b^2 + c^2 - bc)$$の係数$a^2$は正なので固定$b, c$の関数$a$凸です。 これは最適を意味します$a$次の場合に、許可されたセットの極端な値で発生する必要があります。$b$そして$c$固定されています。 

これにより、すべてを試す代わりに、有効な検索スペースが減少します。$a$、境界付近の候補のみを考慮する必要があります。 ソートされた配列を使用すると、固定の場合$b, c$、 最高の$a$は最小要素または最大要素のいずれかです。凸性により、両端に勝る内部値が存在しないことが保証されるためです。 

したがって、問題をすべてのペアの反復に帰着させます。$(b, c)$、各ペアについて、一定数の候補をチェックします。$a$、通常は最小値と最大値だけです。 これにより、複雑さが軽減されます$O(N^2)$。 

対称性を観察することで、評価をさらに調整することができます。式は完全に対称です。$a, b, c$なので、役割をあまり慎重に区別する必要はありません。 代わりに、2 つのインデックスを修正し、極値を使用して最良の完了を評価できます。

 ## アルゴリズムのチュートリアル

 配列を並べ替えて、最小値と最大値をすばやく参照し、極端な動作について推論できるようにします。 

1. 配列をソートする$V$降順ではない順に。 ソートにより、凸完成ステップに必要な唯一の候補である大域的な極値に直接アクセスできるようになります。 
2. 変数を初期化する`ans`非常に小さな値にします。 これにより、すべての構成にわたって見つかった最大利益が追跡されます。 
3. インデックスのすべてのペアを反復処理します。$(i, j)$、治療$V[i]$そして$V[j]$ボックスの 2 つの寸法として。 このステップでは、すべての構造ペアの相互作用を調査します。これが、式の変動性のほとんどが生じる場所です。 
4. 各ペアについて$(i, j)$、3 番目の次元の 2 つの候補補完を計算します。$V[0]$そして$V[N-1]$。 これらは、利用可能な最小値と最大値を表します。各変数の凸性により、これで十分です。 
5. 各候補者について$k \in \{0, N-1\}$、利益を計算します。$$V[i]^2 + V[j]^2 + V[k]^2 - V[i]V[j] - V[j]V[k] - V[k]V[i]$$そして更新します`ans`この値が大きい場合。 

1. すべてのペアが処理された後、出力`ans`。 

### なぜ効果があるのか

 他の変数が固定されている場合、式は各変数で対称かつ凸になります。 凸性は、変数が順序付けされると、任意の固定ペアについて、式を最大化する 3 番目の変数が許可されたセットの境界の 1 つに位置することを保証します。 並べ替えにより境界にグローバルにアクセスできるようになるため、3 番目の座標の最小値と最大値のみをチェックするだけで十分です。 対称性により、任意のペアを修正しても一般性が失われないことが保証されるため、すべてのペアを反復することですべての最適な構成がカバーされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    v = list(map(int, input().split()))
    v.sort()

    INF = -10**30
    ans = INF

    # precompute extremes
    mn = v[0]
    mx = v[-1]

    for i in range(n):
        a = v[i]
        a2 = a * a
        for j in range(n):
            b = v[j]
            b2 = b * b

            # try c = mn
            c = mn
            val = a2 + b2 + c * c - a * b - b * c - c * a
            if val > ans:
                ans = val

            # try c = mx
            c = mx
            val = a2 + b2 + c * c - a * b - b * c - c * a
            if val > ans:
                ans = val

    print(ans)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず入力を並べ替えて境界アクセスを簡単にします。 二重ループはすべての順序付きペアを列挙します。これは、式が対称であるため安全であり、順列によって正確性の保証が変更されることはありません。 

ループ内では、3 次元の最小値と最大値のみをテストします。 これらは次のように事前計算されます。`mn`そして`mx`、インデックス作成の繰り返しを回避します。 式は整数演算を使用して直接計算され、最大約$10^{18}$Python ではオーバーフローなし。 

微妙な実装の詳細は、強制しないことです。$i < j$。 これは意図的なもので、寸法の繰り返しが許可され、対称性によって正確さが損なわれないためです。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import prod  # dummy import to ensure environment stability

    n = int(input())
    v = list(map(int, input().split()))
    v.sort()

    mn, mx = v[0], v[-1]
    ans = -10**30

    for i in range(n):
        a = v[i]
        for j in range(n):
            b = v[j]

            for c in (mn, mx):
                val = a*a + b*b + c*c - a*b - b*c - c*a
                ans = max(ans, val)

    return str(ans)

 ## 特殊なケース

 次のような単一要素入力$N = 1$すべての寸法が等しい箱が生成されるため、利益は次のようになります。$3a^2 - 3a^2 = 0$。 両方のループが 1 回実行され、それ自体と同じ境界値で同じ値のみを評価するため、アルゴリズムはこれを処理します。 

2 番目のエッジ ケースは、最適解が 3 つの次元すべてに同じ値を使用する場合です。 たとえば、最適な構造が繰り返されても、アルゴリズムは引き続き次のことを評価します。$a = b = c = mn$そして$mx$均一なソリューションを見逃さないようにします。 

3 番目のケースは、最適なソリューションに極端な値が混在している場合です。 このアルゴリズムは常に、ペアごとに 3 次元のグローバルな最小値と最大値を含む組み合わせをテストするため、極値に依存する構成は少なくとも 1 回は直接評価され、最適値が大きく歪んでいる場合でも正確さが維持されます。
