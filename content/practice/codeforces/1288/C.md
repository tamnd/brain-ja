 ## 解決策
 ## 問題の理解

 配列のペアを数える必要があります$(a,b)$、両方の長さ$m$、その値は間にあります$1$そして$n$。 

配列$a$非減少の配列である必要があります$b$必要なすべての位置で増加しないようにする必要があります$a_i \le b_i$。 

答えは非常に大きくなる可能性があるため、モジュロで出力します。$10^9+7$。 

まず最初に気づくことは、$m$せいぜい小さいです$10$、 その間$n$到達できる$1000$。 複雑さが多項式である任意の解$n$そして$m$大丈夫です。 可能な配列の数は指数関数的であるため、配列を列挙しようとする解決策は絶望的です。 たとえ$n=1000$そして$m=10$、 がある$1000^{10}$可能な配列。 

興味深い部分は、単調性制約と条件の間の相互作用です。$a_i \le b_i$。 配列は独立していません。 

小さな例を考えてみましょう。```
n = 2, m = 2
```有効なペアは、ステートメントにリストされている 5 つのペアです。 

よくある間違いは、減少しない配列を数えることです。$a$および非増加配列$b$別々にしてからそれらを組み合わせてみてください。 これは位置に関する制約を無視します$a_i \le b_i$。 例えば、$$a=[1,2],\qquad b=[1,1]$$単調性の要件は満たしていますが、違反しています$a_2 \le b_2$。 

もう一つの微妙なケースは次のような場合です。$n=1$。```
1 10
```すべての要素は次のようにする必要があります$1$したがって、有効なペアは 1 つだけです。$$a=[1,1,\ldots,1],\quad b=[1,1,\ldots,1].$$複数の値が使用可能であると誤って想定した数式はオーバーカウントされます。 

3 番目のエッジ ケースは、等価性が頻繁に発生する場合に発生します。 例えば：```
2 1
```有効なペアは次のとおりです。$$(1,1),\ (1,2),\ (2,2).$$答えは$3$、 ない$2$。 治療するソリューション$a_i<b_i$の代わりに$a_i\le b_i$すべての等しいペアを失います。 

## アプローチ

 ブルートフォースアプローチは簡単です。 すべての非減少配列を生成する$a$、すべての非増加配列を生成します$b$、どうかを確認してください。$a_i\le b_i$すべてのポジションに。 

長さが減少しない配列の数$m$値を超える$1\ldots n$は$$\binom{n+m-1}{m}.$$のために$n=1000$そして$m=10$、これはもうあります$2.8\times10^{23}$。 それらを列挙することは完全に不可能です。 

重要な観察は、2 つの配列を単一のモノトーン シーケンスにマージできることです。 

の値を書きます$a$左から右へ:$$a_1 \le a_2 \le \cdots \le a_m.$$次に、次の値を書きます。$b$逆の順序で:$$b_m \le b_{m-1} \le \cdots \le b_1.$$なぜなら$a_i \le b_i$、中間の接続も次の順序を尊重します。$$a_m \le b_m.$$すべてを組み合わせると得られるもの$$a_1 \le a_2 \le \cdots \le a_m \le b_m \le b_{m-1} \le \cdots \le b_1.$$これは単純に長さが減少しないシーケンスです$2m$誰の価値観がそこにあるのか$1\ldots n$。 

逆に、長さが減少しないすべてのシーケンス$2m$有効なペアを一意に決定する$(a,b)$:$$a_i = s_i, \qquad b_i = s_{2m-i+1}.$$したがって、元の問題は、長さが減少しないシーケンスをカウントすることとまったく同じです。$2m$以上$n$価値観。 

これは典型的な星と棒の数です。$$\binom{n+2m-1}{2m}.$$係数は素数なので、$n+2m-1 \le 1019$、この二項係数を効率的に計算できます。

 ## アルゴリズムのチュートリアル

 1. しましょう$$N = n + 2m - 1, \qquad K = 2m.$$2. すべての有効なペアが$(a,b)$非減少シーケンスに対応します$$a_1,\ldots,a_m,b_m,\ldots,b_1$$長さの$2m$。 
3. 長さが減少しないすべてのシーケンスが、$2m$値を超える$1\ldots n$有効なペアを 1 つだけ再構築します。 

対応は全単射であるため、ペアを数えるのは、そのようなシーケンスを数えるのと同じです。 
4. 長さが減少しないシーケンスをカウントする$2m$星とバーを使用します。 

サイズのマルチセットの数$2m$から選ばれた$n$値が等しい$$\binom{n+2m-1}{2m}.$$5. 二項係数モジュロを計算します。$10^9+7$。 

係数は素数なので、階乗と逆剰余を使用します。$$\binom{N}{K} = \frac{N!}{K!(N-K)!}.$$6. 結果を出力します。 

### なぜ効果があるのか

 ソリューション全体は全単射に基づいています。 

有効なペアが与えられた場合$(a,b)$、シーケンス$$a_1,\ldots,a_m,b_m,\ldots,b_1$$は減少していないため、$a$減少していない、$b$増加していない、および状態$a_m\le b_m$2つの半分を接続します。 

長さが減少しない任意のシーケンスを指定すると、$2m$、その前半を次のように割り当てます。$a$そしてその逆の後半は$b$非減少を自動的に生成します$a$、増加しない$b$、 そして$a_i\le b_i$あらゆるポジションに。 2 つの構造は互いに逆であるため、マッピングは 1 対 1 および 1 対 1 になります。 

したがって、答えは正確に、長さが減少しないシーケンスの数です。$2m$以上$n$可能な値、つまり$\binom{n+2m-1}{2m}$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

n, m = map(int, input().split())

N = n + 2 * m - 1
K = 2 * m

fact = [1] * (N + 1)
for i in range(1, N + 1):
    fact[i] = fact[i - 1] * i % MOD

inv_fact = [1] * (N + 1)
inv_fact[N] = pow(fact[N], MOD - 2, MOD)

for i in range(N, 0, -1):
    inv_fact[i - 1] = inv_fact[i] * i % MOD

ans = fact[N]
ans = ans * inv_fact[K] % MOD
ans = ans * inv_fact[N - K] % MOD

print(ans)
```コードは組み合わせ公式を直接実装します。 

値$N=n+2m-1$は二項係数の頂点であり、$K=2m$が一番下です。 

階乗は事前に計算されたモジュロです$10^9+7$。 係数は素数であるため、フェルマーの定理は次のようになります。$$x^{-1} \equiv x^{MOD-2} \pmod{MOD}.$$の逆階乗を計算する$N$最初に残りの逆階乗を逆方向に埋めるのが、標準的な線形時間手法です。 

可能な限り最大の$N$は$$1000 + 20 - 1 = 1019,$$そのため、配列は小さく、制限内に快適に収まります。

## テストケース```python
# helper: run solution on input string, return output string
import io
import sys

def solve():
    MOD = 10**9 + 7

    n, m = map(int, input().split())

    N = n + 2 * m - 1
    K = 2 * m

    fact = [1] * (N + 1)
    for i in range(1, N + 1):
        fact[i] = fact[i - 1] * i % MOD

    inv_fact = [1] * (N + 1)
    inv_fact[N] = pow(fact[N], MOD - 2, MOD)

    for i in range(N, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % MOD

    ans = fact[N]
    ans = ans * inv_fact[K] % MOD
    ans = ans * inv_fact[N - K] % MOD

    print(ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided sample

# minimum size

# only one value available
assert run("1 10\n") == "1\n", "forced arrays"

# another small hand-checkable case

 ## 特殊なケース

 次のことを考慮してください。```
1 10
```アルゴリズムは計算します$$\binom{1+20-1}{20} = \binom{20}{20} = 1.$$長さが減少しないシーケンスが 1 つだけ$20$存在します、つまりすべてのものです。 これは、配列の一意の有効なペアにマップされます。 

考慮する：```
2 1
```アルゴリズムは計算します$$\binom{2+2-1}{2} = \binom{3}{2} = 3.$$その３組は、$(1,1)$、$(1,2)$、 そして$(2,2)$。 スターとバーは厳密にシーケンスを増加させるのではなくマルチセットをカウントするため、等しいケースは自然にカウントされます。 

考慮する：```
2 2
```マージされたシーケンスには長さがあります$4$。 値を超えて減少しないシーケンスの数$\{1,2\}$は$$\binom{5}{4}=5.$$再構築中$a$最初の 2 つの位置から、$b$最後の 2 つの位置を反転すると、正確に 5 つの有効なペアが得られます。 全単射により、有効なペアが欠落せず、いずれも 2 回カウントされないことが保証されます。
