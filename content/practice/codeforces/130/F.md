 ## 解決策
 ## 問題の理解

 このタスクは、指定された整数 _n_ を素因数に分解し、それらを非降順で出力します。各素数はその多重度に従って繰り返されます。 基本的に、数値が次のような素数の積である場合、$n = 2^2 \cdot 3^1 \cdot 5^2$、出力は次のようになります。`2 2 3 5 5`。 入力は 2 ～ 250 の単一の整数であり、これは十分に小さいため、Pollard の rho や非常に大きな数に最適化された sieves などの高度な因数分解アルゴリズムは必要ありません。 

上限は 250 のみであるため、次の値に比例した演算を実行できます。$n$または$\sqrt{n}$制限時間2秒以内に楽々クリア。 主なエッジケースは、_n_ 自体が素数 (例: 2、3、197) の場合に発生します。この場合、因数分解は次のようになります。`n`または、_n_ が素数の完全二乗 (例: 49 = 7*7) の場合、アルゴリズムが繰り返し因数を正しく処理するかどうかをテストします。 ここでは、_n_ までのすべての数値で割る素朴なアプローチが機能します。$n \le 250$ですが、潜在的な約数だけを考慮することで、もう少し良い結果を得ることができます。$\sqrt{n}$。 

もう 1 つの微妙な点は順序付けです。因数は減少しない順序で出力する必要があり、多重度はべき乗として要約するのではなく完全に展開する必要があります。 たとえば、8 = 2^3 は次のように出力する必要があります。`2 2 2`、 ない`2^3`。 

## アプローチ

 ブルートフォース手法では、2 から _n_ までのすべての整数を反復して、割り切れるかどうかをテストします。 除数 _d_ が _n_ を除算するたびに、それが出力され、除算できなくなるまで _n_ が _d_ で除算されます。 これが機能するのは、1 より大きい整数は素数であるか、素因数分解できるためです。 _n_ が小さい場合、除算の試行回数はおよそ$n$、これは許容されます$n \le 250$。 

最適化を可能にする観察結果は、これより大きな要素は存在しないということです。$\sqrt{n}$(おそらく _n_ 自体を除く) は、繰り返しの試行で考慮する必要があります。 小さな因数をすべて削除すると、残った数値はすべて素数になるはずです。 これにより、以下までのみループすることができます$\sqrt{n}$最後に残った数値を個別に処理します。 これにより、アルゴリズムをシンプルで読みやすく保ちながら、不必要なチェックの数がわずかに減ります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n) | お(1) | n ≤ 250 の場合は受け入れられます |
 | 最適 | O(√n) | お(1) | 受け入れられ、きれいになった |

 ## アルゴリズムのチュートリアル

 1. 入力から整数 _n_ を読み取ります。 変数を初期化する`num`因子を抽出するときに残りの数値を保存します。 
2. すべての整数を反復処理します。`i`2から始まり$\sqrt{n}$。 それぞれについて`i`、分割するかどうかをテストします`num`。 
3. その間`i`分割する`num`、印刷`i`そして分ける`num`による`i`。 までこのループを続けます。`i`もう分断しない`num`。 これにより、繰り返される素因数が正しい回数出力されるようになります。 
4. までのループを終えたら$\sqrt{n}$、 もし`num`はまだ 1 より大きいですが、それ自体が素因数である必要があるため、出力します`num`。 
5. 印刷されたすべての数字をスペースで区切ります。 

機能する理由: 1 より大きいすべての整数は一意に素因数分解できます。 まで繰り返すことで$\sqrt{n}$すべての因数を削除すると、残った数字はすべて素数でなければならないため、アルゴリズムは各素因数を正確に正しい回数だけ出力します。 不変条件は、各反復において、`num`残りのすべての素因数分解されていない素数成分の積に等しい。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
num = n
i = 2
factors = []

while i * i <= num:
    while num % i == 0:
        factors.append(i)
        num //= i
    i += 1

if num > 1:
    factors.append(num)

print(' '.join(map(str, factors)))
```ソリューションはまず整数を読み取り、初期化します。`num`残りの部分を追跡して因数分解します。 外側のループは、潜在的な約数を最大で実行します。$\sqrt{num}$、内側のループは現在の除数のすべての出現を削除します。 順序を維持するために、見つかったすべての要素をリストに追加します。 最終チェックは、`num > 1`残りの数値が素数で、次の数値より大きい場合を処理します。$\sqrt{n}$。 因子を 1 つの文字列に結合すると、正しい出力形式が保証されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    num = n
    i = 2
    factors = []
    while i * i <= num:
        while num % i == 0:
            factors.append(i)
            num //= i
        i += 1
    if num > 1:
        factors.append(num)
    return ' '.join(map(str, factors))

# provided samples
assert run("245\n") == "5 7 7", "sample 1"

# custom cases
assert run("2\n") == "2", "minimum prime"
assert run("4\n") == "2 2", "perfect square of smallest prime"
assert run("250\n") == "2 5 5 5", "composite with multiple factors"
assert run("13\n") == "13", "prime greater than √n"
assert run("81\n") == "3 3 3 3", "power of a prime"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 2 | 2 | 最小素数 |
 | 4 | 2 2 | 小さな素数の繰り返し |
 | 250 | 2 5 5 5 | 複数の異なる素因数 |
 | 13 | 13 | √n より大きい素数 |
 | 81 | 3 3 3 3 | 素数のべき乗が正しく処理される |

 ## 特殊なケース

 最小の入力でも、`n = 2`、単一の因子を生成します`2`。 アルゴリズムが初期化されます`num = 2`、ループに入り、2*2 > 2 を確認するため、内側のループをスキップし、チェックします`num > 1`そしてプリント`2`。 のために`n = 49`、ループは 7 を 2 回正しく削除し、√n を超えて繰り返された因数が完全に展開されていることを示しています。 √n より大きい素数の場合、次のように`n = 13`、最後のチェックにより、唯一の素因数が出力されることが確認されます。 このアプローチは、特別な分岐を行わずに、すべての非自明なシナリオを処理します。
