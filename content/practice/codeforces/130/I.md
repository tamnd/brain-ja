 ## 解決策
 ## 問題の理解

 最大 100 個の整数の配列が与えられます。 すべての値は 1 ～ 60 の範囲にあります。タスクは単に配列を非降順で出力することです。 

一見すると、これは標準的な並べ替え問題のように見えますが、値の範囲が異常に小さいため、問題の構造が完全に変わります。 任意の数値を並べ替えることを考える代わりに、各値が何回出現するかを数えることを考えることができます。 

配列の長さは非常に小さいです。 たとえ$O(n^2)$バブル ソートや挿入ソートなどのソート アルゴリズムは制限内に問題なく収まります。$100^2 = 10{,}000$操作は無視できます。 値の範囲は配列サイズよりもさらに小さく、可能な値は 60 個のみです。 これにより、入力サイズに対して線形時間で実行されるカウントベースのソリューションへの扉が開きます。 

主なエッジ ケースは、重複した値や、許容範囲の境界に現れる値から発生します。 

次の入力を考えてみましょう。```
5
7
7
7
7
7
```正しい出力は次のとおりです。```
7 7 7 7 7
```セットに値を格納する不注意な実装では、重複が削除され、1 つだけが出力されます。`7`。 

もう 1 つの簡単な間違いは、最小値または最大値を正しく処理することを忘れることです。```
4
1
60
1
60
```正しい出力は次のとおりです。```
1 1 60 60
```カウント配列がサイズ 61 ではなく 60 で作成された場合、インデックスにアクセスします`60`言語によっては失敗するか、間違った出力が自動的に生成されます。 

最小入力サイズも重要です。```
1
42
```出力は次のようになります。```
42
```実装によっては、要素が 1 つしか存在しない場合に、誤って余分なスペースを印刷したり、何も印刷し忘れたりすることがあります。 

## アプローチ

 ブルートフォースアプローチは、標準の比較ソートを使用することです。 要素を繰り返し比較し、小さい値を前に移動します。 比較による並べ替えによって最終的な配列の順序が正しいことが保証されるため、バブル ソート、挿入ソート、または選択ソートはすべて機能します。 

のために$n = 100$、 平$O(n^2)$複雑さは大丈夫です。 バブルソートのパフォーマンスは最大でも約$100 \times 100 = 10{,}000$比較は 2 秒の制限では簡単です。 

この問題の興味深い点は、値の範囲が制限されていることです。 すべての数値は 1 ～ 60 の範囲にあります。これは、入力サイズに関係なく、取り得る個別の値が 60 個のみであることを意味します。 要素を直接並べ替える代わりに、各値が出現する回数をカウントできます。 

観察によると、価値がわかっている場合、`x`表示されます`k`回の場合、ソートされた配列には正確に含まれている必要があります。`k`のコピー`x`、それらはすべて、より大きな値の前に出現する必要があります。 

これにより、問題は頻度をカウントし、ソートされたシーケンスを昇順に再構築することに変換されます。 アルゴリズムは次のようになります。 

1. 各数値の出現回数を数えます。 
2. 1 から 60 まで繰り返します。 
3. 各数字を出現した回数だけ出力します。 

非常に狭い範囲に特化したカウントソートです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 承認済み |
 | 最適 | O(n + 60) | お(60) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`、配列内の要素の数。 
2. 周波数配列を作成する`cnt`サイズは 61 で、ゼロで初期化されます。 

索引`i`何倍の値を保存します`i`が表示されます。 サイズ61を使用しているのでインデックス`1`を通して`60`直接使用可能です。 
3. 配列の各要素を読み取ります`x`。 
4. インクリメント`cnt[x]`。 

すべての数値を処理した後、`cnt[v]`値の頻度に等しい`v`入力配列内。 
5. 空の回答リストを作成します。 
6. 以下の値を反復処理します。`1`に`60`。 
7. 各値について`v`、回答リストに正確に追加します`cnt[v]`回。 

値を昇順に処理するため、再構築されたシーケンスは自動的にソートされます。 
8. 回答リストをスペースで区切られた整数として出力します。 

### なぜ効果があるのか

 アルゴリズムは、値を処理した後も不変条件を維持します。`v`、回答リストには以下のすべての入力要素が含まれます。`v`、正確に正しい多重度でソートされた順序で。 

値の出現はすべて 1 回だけカウントされ、後で 1 回だけ再現されるため、要素が失われたり重複したりすることはありません。 値は昇順に追加されるため、より大きな数値がより小さな数値の前に現れることはできません。 これにより、最終的なシーケンスがソートされた配列になることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

cnt = [0] * 61

for _ in range(n):
    x = int(input())
    cnt[x] += 1

ans = []

for value in range(1, 61):
    ans.extend([value] * cnt[value])

print(*ans)
```最初の部分は入力を読み取り、周波数配列を構築します。 値の範囲は 1 ～ 60 であるため、サイズ 61 のリストで十分です。 インデックス 0 は使用されないため、インデックス付けが単純になり、すべての値から 1 を減算することがなくなります。 

再構築フェーズでは、値が昇順に繰り返されます。 各値について、入力に出現した回数だけ追加します。 表現:```
[value] * cnt[value]
```現在の値の繰り返しコピーを含むリストを作成します。 

使用する`extend`繰り返す代わりに`append`呼び出しにより実装が簡潔になります。 

決勝戦`print(*ans)`必要な出力形式に一致する要素をスペースで区切って自動的に出力します。 これにより、末尾のスペースの問題も回避されます。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    n = int(input())
    cnt = [0] * 61

    for _ in range(n):
        x = int(input())
        cnt[x] += 1

    ans = []

    for value in range(1, 61):
        ans.extend([value] * cnt[value])

    print(*ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue().strip()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output

# provided sample
assert run(

9

3
"""

 ## 特殊なケース

 すべての要素が同一である場合を考えてみましょう。```
5
7
7
7
7
7
```周波数配列は次で終わります。`cnt[7] = 5`。 再構築中に、アルゴリズムは値を追加します`7`ちょうど5回。 他にゼロ以外の周波数はないため、最終出力は次のようになります。```
7 7 7 7 7
```これにより、重複が折りたたまれずに保持されることが確認されます。 

ここで境界値を考えてみましょう。```
4
1
60
1
60
```入力を読み取ると、次のようになります。```
cnt[1] = 2
cnt[60] = 2
```再構成ループは 1 ～ 60 までスキャンします。 届いたら`1`、コピーを 2 つ追加します。 届いたら`60`、さらに 2 つのコピーを追加します。 最終結果は次のとおりです。```
1 1 60 60
```サイズ 61 の周波数配列を使用すると、インデックスが作成されます。`60`有効。 

最後に、可能な最小の入力を検討します。```
1
42
```アルゴリズムが増加します`cnt[42]`一度。 再構築では、次のコピーが 1 つ追加されます。`42`。 出力は次のとおりです。```
42
```カウント手法はすべての有効な入力サイズに対して自然に機能するため、単一要素の配列には特別な処理は必要ありません。
