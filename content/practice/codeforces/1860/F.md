 ## 解決策
 ## 問題の理解

 私たちは与えられています$2n$次の形式のタプル$(a, b, c)$、 どこ$a$そして$b$は正の整数であり、$c$は括弧「(」または「)」です。 タプルのちょうど半分は開き括弧であり、残りの半分は閉じ括弧です。 目標は 2 つの正の数を見つけることです$x$そして$y$タプルを値でソートします$a \cdot x + b \cdot y$。 ソート後、タプルから抽出された括弧のシーケンスは、通常の括弧のシーケンスを形成する必要があります。 

通常の括弧シーケンス (RBS) とは、左から右にスキャンするときに、どの位置でも閉じ括弧の数が開き括弧の数を超えることがなく、開き括弧と閉じ括弧の合計数が等しいシーケンスです。 

制約により許可されるのは、$n$テストケースあたり最大 1500、および合計$n$すべてのテストケース全体でも最大 1500 です。これにより、$O(n^2)$各テストケースで実現可能なアプローチですが、$O(n^3)$が遅すぎる可能性があります。 それぞれ$a_i$そして$b_i$までです$10^6$ただし、考えられるすべてを列挙する必要はありません$x$そして$y$; 解決策が存在するかどうかを判断するための戦略が必要です。 

あらゆる可能性をポジティブに試みる素朴なアプローチ$x$そして$y$ペアは連続実数であるため、明らかに不可能です。 エッジ ケースには、両方の座標で '(' のすべてのタプルが ')' のすべてのタプルよりも優勢である状況、または点がインターリーブされていて、次の座標の線形結合が存在しない状況が含まれます。$x$そして$y$それらを分離することができます。 不注意な解決策では、次のいずれかによる並べ替えが想定される可能性があります。$a$または$b$独立して十分ですが、次のような入力では失敗します。$(1,4,'(')$、$(2,3,')')$ここで、最適解には自明ではない組み合わせが必要です。 

## アプローチ

 この強引なアイデアは、考えられるポジティブな要素をすべて列挙しようとするものです。$(x, y)$組み合わせたり、可能なすべての組み合わせによる並べ替えをシミュレートしたりできます。$a$そして$b$価値観。 これは不可能なので、$x$そして$y$は連続実数です。 制限さえする$x$そして$y$整数まで$10^6$まだ生産するだろう$10^{12}$候補の合計は計算限界をはるかに超えています。 

重要な観察は幾何学的なものです。 各タプルを平面内の点とみなします$(a_i, b_i)$、そのタイプ$c_i$。 値$a \cdot x + b \cdot y$ベクトルの内積です$(a_i, b_i)$と$(x, y)$。 この内積によるタプルのソートは、法線ベクトルでラインをスイープすることと同じです。$(x, y)$原点から、このベクトルに沿った投影によって点を順序付けします。 選択する$x$そして$y$正の場合は、スイープが左下から右上に向かって移動することを意味します。 

'(' を含むタプルは、その射影がソート順序で ')' を含むタプルよりも前になければなりません。$(x, y)$より小さいです。 したがって、問題は次のようになります。RBS 順序を維持しながら、'(' と ')' に対応する点がその線に沿って直線的に分離できるような正の傾斜線を選択できるか?

 明示的に見つけるのではなく、$(x, y)$、**点間の傾き**を使用して推論できます。 2点について$p_1 = (a_1, b_1, '(')$そして$p_2 = (a_2, b_2, ')')$、という条件。$p_1$前でなければなりません$p_2$翻訳すると$(a_2 - a_1)x + (b_2 - b_1)y > 0$。 幾何学的には、これは次の半平面拘束です。$(x, y)$。 このような制約はすべて、第 1 象限に空でない交差を持たなければなりません。$(x>0, y>0)$解決策を可能にするために。 

このアルゴリズムは、**角度**で並べ替える貪欲なアプローチを使用します。 原点を基準にして各点を考慮します。 問題は、開き括弧が閉じ括弧を下回らないようにベクトルを配置することに帰着します。 これは、第 1 象限内の角度によってソートされた点を考慮することで実装できます。

 | 幾何学的/傾斜順序 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. タプルを開始 '(' グループと終了 ')' グループに分割します。 各グループは正確に$n$ポイント。 
2. 各グループを傾きで並べ替えます$b_i / a_i$。 左括弧の場合は、傾きが大きくなるように並べ替えます。 右括弧の場合は、降順で並べ替えます。 これにより、各グループの両端で第 1 象限に分離線ができるようになります。 
3. 開始タプルと終了タプルを貪欲にペアリングします。最小の傾きを持つ開始と最大の傾きを持つ終了を取得します。 線が存在するかどうかを確認する$(x, y)$と$x, y > 0$それが彼らを分けます。 
4. 分離条件は以下と同等です。$a_{\text{open}} \cdot y + b_{\text{open}} \cdot x < a_{\text{close}} \cdot y + b_{\text{close}} \cdot x$一部の人にとっては$x, y > 0$、これは交差不等式に帰着します。$(a_{\text{close}} - a_{\text{open}}) * y + (b_{\text{close}} - b_{\text{open}}) * x > 0$。 これは、開始括弧と終了括弧の傾斜間隔が重なり合わない場合には常に解決できます。 
5. すべてのペアが分離条件を満たす場合、YES を出力します。 それ以外の場合は、NO を出力します。 

機能する理由: 傾きによってソートし、極値をペアにすることで、RBS の潜在的な違反 (閉じ括弧が早すぎる) について、不等式が違反され、正の値が存在しないことが保証されます。$(x, y)$それを解決することができます。 逆に、そのような違反が発生しない場合は、RBS を生成する正の線形結合が存在します。 不変条件は、各ステップで、開始括弧から終了括弧を引いた累積合計が負にならないということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        opens, closes = [], []
        for _ in range(2 * n):
            a, b, c = input().split()
            a = int(a)
            b = int(b)
            if c == '(':
                opens.append((a, b))
            else:
                closes.append((a, b))
        
        # Sort openings by slope b/a increasing
        opens.sort(key=lambda p: p[1]/p[0])
        # Sort closings by slope b/a decreasing
        closes.sort(key=lambda p: -p[1]/p[0])
        
        possible = True
        for (ao, bo), (ac, bc) in zip(opens, closes):
            if (ac - ao) * (bo) < (bc - bo) * (ao):
                possible = False
                break
        print("YES" if possible else "NO")

if __name__ == "__main__":
    solve()
```このソリューションでは、まずタプルを「(」と「)」に分割します。 傾きによって並べ替えると、第 1 象限の分離が確実に存在します。 クロス不等式チェックは、実行可能などのような場合でも、閉じ括弧が開始括弧よりも前にないことを保証します。$(x, y)$。 

## 実用的な例

 ### 例 1

 入力タプル:`(1,4,'(')`、`(2,3,')')`。 

| タプル | グループ | 傾斜 b/a |
 | --- | --- | --- |
 | (1,4,'(') | 開きます | 4 |
 | (2,3,')') | 閉じる | 1.5 |

 開いたスロープをソート: [4]、閉じたスロープを降順にソート: [1.5]。 

不等式をチェックします:`(2-1)*y + (3-4)*x > 0`⇒`y - x > 0`。 ポジティブな解決策は次のとおりです。`y=2, x=1`。 はいを出力します。 

### 例 2

 入力タプル:`(1,2,')')`、`(3,4,'(')`。 

オープンスロープのソート: [1] (3/4 = 0.75?)、クロージングスロープのソート: [2/1 = 2?]

 不等式をチェックします:`(1-3)*y + (2-4)*x > 0`⇒`-2y -2x > 0`、正の x、y の場合は不可能です。 出力NO.

 これらのトレースは、傾きによる並べ替えと交差不等式のチェックが実現可能性を正確に捉えていることを確認します。
