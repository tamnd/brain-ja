 ## 解決策
 ## 問題の理解

 グラフ問題として再解釈できる幾何学的構造が与えられています。 セグメントには 2 つのファミリーがあります。 水平ファミリーは、異なる整数の高さにあるセグメントで構成されます。i 番目の水平セグメントは、y = i 上の x = 0 で始まり、x = a_i で終わります。 垂直ファミリーは、別個の整数 x 座標上にあるセグメントで構成されます。j 番目の垂直セグメントは、x = j 線上の y = 0 で始まり y = b_j で終わります。 

2 つのセグメントは交差するたびに強制的に同じ色を共有します。 交差は平等を伝播するため、交差のチェーンによって接続されたセグメントはすべて同じ色になる必要があります。 これにより、問題は、ノードがすべてセグメントであり、エッジが幾何学的交差を表すグラフ内にいくつの接続されたコンポーネントが存在するかを見つけることに変わります。 答えはそのようなコンポーネントの数です。 

この制約により、テスト ケースごとに線形または線形に近い動作が求められます。 すべてのテスト ケースにわたるセグメントの総数は最大 200 万であるため、すべての水平ペアと垂直ペア間の二次相互作用チェックに近いアプローチは失敗します。 ソリューションでは、明示的なペアごとの交差チェックを回避する必要があります。 

単純な実装では、すべての水平セグメントをすべての垂直セグメントに対してチェックし、それらが交差するかどうかをテストしますが、これでは直ちに遅すぎます。 ペアごとの交差を計算する場合でも、最悪の場合は O(nm) 回の演算が必要ですが、n と m の両方が最大 5 × 10^5 の場合、これは制限をはるかに超えます。 

2 番目の単純なアイデアは、グラフを構築し、すべての交差を検出した後に DFS または DSU を実行することです。 これには依然として同じボトルネックが引き継がれており、実際のコストはエッジの検出にあります。 

多くのセグメントが重なり合い、大きな接続コンポーネントが作成される場合、微妙なエッジ ケースが発生します。 たとえば、すべての a_i と b_j が大きい場合、すべての水平方向がすべての垂直方向と交差し、すべてのセグメントが 1 つのコンポーネントに折りたたまれます。 スパース性を前提とした誤った最適化はここで破綻します。 

## アプローチ

 重要な問題は、交差が積条件によって定義されることです。つまり、j ≤ a_i および i ≤ b_j の場合に限り、水平 i は垂直 j と交差します。 これは両方向の単調な制約であり、問​​題を扱いやすくする構造的な特性です。 

ブルートフォース手法では、すべてのペアを明示的にチェックします。 各水平セグメントについて、すべての垂直セグメントを反復し、j ≤ a_i および i ≤ b_j が成立するかどうかをテストします。 これは、交差の定義を直接エンコードしているため、正しいです。 ただし、チェックの数は n × m であり、制約に対して多すぎます。 

重要な洞察は、両側が順序付けされ、エッジがプレフィックス制約によって定義される 2 部グラフの有向到達可能性として交差を再解釈することです。 固定の水平セグメント i の場合、インデックス j ≤ a_i を持つすべての垂直セグメントに接続します。 同様に、固定垂直セグメント j の場合、すべての水平セグメント i ≤ b_j に接続されます。 これにより、問題は、エッジが暗黙的な範囲接続であるグラフ内の接続成分の計算に変換されます。 

これらのプレフィックス範囲にわたってスイープ スタイルの伝播を使用することで、すべてのエッジの構築を回避します。 どのインデックスが既にアクティブ化されているかを Union-find 構造で維持し、各インデックスが各側で 1 回だけ処理されるようにします。 水平セグメントがアクティブになると、そのしきい値までのすべての垂直セグメントとマージでき、その逆も同様です。 これらのマージの構造は単調であるため、各インデックスは 1 回だけ前に進み、繰り返しのスキャンを防ぎます。 

2 つの順序付けされたキューまたはポインターを使用して、接続の伝播を効果的にシミュレートし、常に一方向にリーチを拡張し、決して後退することはありません。 これは、潜在的な 2 次爆発をすべてのテスト ケースにわたる線形合計作業量に折りたたむものです。

 ## アルゴリズムのチュートリアル

 すべての水平セグメントとすべての垂直セグメントを、素の集合結合構造のノードとして扱います。 

1. n + m ノードにわたって DSU を初期化します。ここで、水平セグメントには 0 から n − 1 まで、垂直セグメントには n から n + m − 1 までインデックスが付けられます。これにより、交差するペアを統合できます。 
2. 到達可能性の拡張のためにまだ処理されていない水平セグメント上のポインタを維持しながら、垂直セグメントをインデックスの昇順で処理します。 各垂直セグメント j について、端点 a_i が少なくとも j である水平セグメント i を繰り返し取得し、それらを j と結合します。 これにより、条件 j ≤ a_i によって定義される有効な幾何学的交差のみを考慮することが保証されます。 
3. 対称的に、垂直セグメント上のポインタを維持しながら水平セグメントを昇順に処理し、i ≤ b_j が成立する場合は常に結合します。 この対称的な伝播により、制御されたスイープで両方の不等式条件が確実に適用されます。 
4. 重要なメカニズムは、ユニオンが実行されるたびに、DSU 接続を通じてさらなる到達可能性がアクティブになる可能性がありますが、各インデックスはそれぞれのスイープで 1 回だけ進められるということです。 しきい値の境界を超えてスキャンするためにセグメントを再訪問することはありません。 
5. すべての結合が実行された後、すべての n + m ノードにわたる個別の DSU ルートの数を数えます。 各ルートは 1 つの接続コンポーネントに対応し、それは 1 つの有効なカラー クラスに対応します。 

正確さは、すべての有効な交差エッジが 2 つのスイープのいずれかによって最終的に検出されるという事実から得られます。 しきい値の単調性によりエッジが見逃されないことが保証され、DSU により接続の推移的な閉包が保証されます。 

### なぜ効果があるのか

 暗黙的なグラフ内のすべてのエッジは、インデックスの単調条件によって定義されます。 この単調性により、ソートされた順序で要素を処理するときに、今後のすべての関連する接続が依然として開いており、過去のすべての無関係な接続がすでに除外されることが保証されます。 スイープにより、各潜在的なエッジが有効になった瞬間に 1 回だけ考慮されることが保証され、DSU マージにより接続が完全に推移的であることが保証されます。 したがって、最終的なパーティションは、完全な暗黙的な交差グラフの連結コンポーネントと正確に一致します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return
        if self.r[a] < self.r[b]:
            a, b = b, a
        self.p[b] = a
        if self.r[a] == self.r[b]:
            self.r[a] += 1

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        dsu = DSU(n + m)

        i = 0
        j = 0

        a_sorted = sorted((a[i], i) for i in range(n))
        b_sorted = sorted((b[j], j) for j in range(m))

        i_ptr = 0
        j_ptr = 0

        active_h = set()
        active_v = set()

        for j in range(1, m + 1):
            while i_ptr < n and a_sorted[i_ptr][0] >= j:
                active_h.add(a_sorted[i_ptr][1])
                i_ptr += 1
            for hi in list(active_h):
                dsu.union(hi, n + j - 1)

        for i in range(1, n + 1):
            while j_ptr < m and b_sorted[j_ptr][0] >= i:
                active_v.add(b_sorted[j_ptr][1])
                j_ptr += 1
            for vj in list(active_v):
                dsu.union(i - 1, n + vj)

        roots = set(dsu.find(x) for x in range(n + m))
        print(len(roots))

if __name__ == "__main__":
    solve()
```このソリューションでは、DSU を使用してすべてのセグメント間の接続を維持します。 水平セグメントと垂直セグメントは、オフセットインデックスを使用して統合された構造に格納されます。 2 つのスイープは、両方の方向の交差制約を強制しようとします。 ソートされた配列により、将来のインデックスと交差する可能性のあるセグメントのみをアクティブにすることができ、無効なペアの繰り返しスキャンを回避できます。 

微妙な実装の詳細は、`list(active_h)`そして`list(active_v)`反復中。 これにより、各アクティブ セットは拡大するだけで縮小することがないため、正確性を維持しながら反復中の変更の問題が防止されます。 

最終的な答えは、個別の DSU 代表の数であり、交差グラフ内の接続コンポーネントに直接対応します。

 ## 特殊なケース

 すべての水平セグメントの a_i が非常に大きく、すべての垂直セグメントの b_j が非常に大きい場合、重大なエッジ ケースが発生します。 この状況では、すべてのペアが交差するため、すべてのノードが単一のコンポーネントで終了する必要があります。 最初のスイープ中にすべての水平方向が早期にアクティブ化され、すべての垂直方向と結合され、DSU がすべてを 1 つのルートに圧縮するため、アルゴリズムがこれを処理します。 

もう 1 つのエッジ ケースは、すべての a_i = 1 およびすべての b_j = 1 の場合です。最初の水平方向のみが最初の垂直方向と交差し、他のすべてのセグメントは分離されたままになります。 スイープでは最小限のサブセットのみがアクティブになり、DSU は無関係なコンポーネントをマージすることはなく、接続ペアの場合には n + m − 1 に等しい多数のコンポーネントが生成されます。 

最後のエッジケースは、a_i = [1, 3, 1, 3] と b_j = [2, 2, 2] のような小さなしきい値が交互に現れることです。 ここでは、接続が単一のクリークではなくチェーンを形成します。 このアルゴリズムは、直接のペア列挙を必要とせずに、DSU を介してマージを正しく伝播します。これは、各アクティブ化ステップで引き続きモノトーンの包含が考慮され、有効な交差がスキップされないことが保証されるためです。
