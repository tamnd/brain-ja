 ## 解決策
 ## 問題の理解

 いくつかの独立したテスト ケースが与えられています。 各テスト ケースは個別の整数の有限セットを提供し、このセットが要素間の違いを含む非常に特殊な構造特性を満たすかどうかを判断する必要があります。 

この条件は、セットから 2 つの異なる要素を選択するたびに、少なくとも 1 つの方向に一方を他方から減算すると、同じセットに既に含まれている値が生成されなければならないことを示しています。 言い換えれば、各ペアに対して少なくとも 1 つの符号付き差分を取得してセットを閉じる必要があります。 

したがって、任意のペアを取ると、$a, b$、計算します$a-b$そして$b-a$、これら 2 つの結果のうち少なくとも 1 つは元の要素内にすでに存在している必要があります。 

各テスト ケースの出力は、この条件がセット全体に当てはまるかどうかに応じて、単純に「はい」または「いいえ」を決定します。 

制約が十分に大きいため、すべてのペアを明示的にチェックするメソッドは即座に疑われます。 まで$5 \cdot 10^5$単一のテスト ケース内の数値と合計$2 \cdot 10^6$、すべてのペアにわたる二次スキャンには、最大で$10^{12}$最悪の場合の運用が困難になる可能性があり、実際の限界をはるかに超えています。 平$O(n \log n)$合計の入力サイズが大きいため、テスト ケースごとのソリューションは慎重に設計する必要があります。 

素朴なアプローチは、計算された差分の再利用を処理する方法でも微妙に失敗します。 たとえば、次のようなセットでは、$\{1, 2, 3\}$連続した差分をチェックすれば十分だと誤解する人もいるかもしれませんが、この条件は、並べ替えられた順序で隣接していないペアを含む、順序付けされていないすべてのペアに適用されます。 

負の数が関係する場合、別の失敗ケースが発生します。 たとえば、$\{-1, 0, 1\}$、すべての差はセットに戻りますが、正の差または絶対差のみをチェックすると、セットが無効であると誤って結論付ける可能性があります。 2 つのうちの 1 つだけが存在する必要があるため、減算の方向性が重要になります。 

さらに微妙な問題は、クロージャが推移的に動作すると仮定していることです。 たとえ$a-b$そして$b-c$セットに含まれていますが、保証はありません$a-c$したがって、隣接する要素間のローカルチェックは不十分です。 

## アプローチ

 ブルートフォース戦略は単純です。 すべてのペアについて$(a_i, a_j)$、両方の差を計算し、入力から構築されたハッシュ セットに少なくとも 1 つが存在するかどうかを確認します。 これは、定義を直接適用するため、正しいです。 問題はコストです。 各テストケースに必要なものは、$O(n^2)$ペアチェックであり、各チェックはハッシュによる定数時間です。 と$n$まで$5 \cdot 10^5$、これは天文学的に大きくなり、さらに小さなサブタスクの制限でもすでに実現可能性を超えています。 

重要な構造的洞察は、どのような種類の集合がそのような強力な閉包条件を満たす可能性があるかを観察することから得られます。 配列をソートする場合は、最小の要素を選択します$m$、その他の要素を考慮します$x$、次にペア$(x, m)$どちらかを強制する$x - m$または$m - x$セットの中にいること。 以来$m$最小限であり、$m - x$は負であり、構造が対称でない限り存在しないことがよくあります。 これは、有効なセットが 1 つの算術構造の周りに厳しく制限されなければならないことを直ちに示唆しています。 

小さな例をテストすると、パターンが現れます。有効なセットは、順序付けされていない差分によって暗黙的に処理される負のステップ対称性を含む、固定ステップを持つまさに等差数列です。 セットを並べ替える場合、隣接する差分はすべて等しい必要があります。そうでない場合は、セットに存在しない差分を生み出すギャップが存在します。 

より正確には、ソートされた配列を次のようにします。$a_1 < a_2 < \dots < a_n$。 与えられた意味での減算で集合が閉じている場合、すべての差は集合自体の中で表現可能でなければなりません。 最小のプラスの差$d = a_2 - a_1$クリティカルになります。 他のすべての要素は、によって生成された格子上に存在する必要があります。$d$そうでない場合、一部のペアがセットにない差を生み出します。 これにより、連続するすべての差が強制的に次と等しくなります。$d$、セットを等差数列に変換します。 

これを認識すると、検証は線形になります。つまり、隣接する差分がすべて等しいかどうかを確認します。

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

1. 配列を並べ替えて、隣接するギャップを通して相違点の構造が見えるようにします。 プロパティは入力順序ではなく値に依存し、ソートされた形式で違いを推論するのが最も簡単であるため、並べ替えは不可欠です。 
2. 最初の差を計算します$d = a_1 - a_0$。 この値は、有効な構成内の他のすべての要素の候補ジェネレーターとして機能します。 
3. 配列を反復処理し、連続するすべての差が等しいかどうかを確認します。$d$。 ギャップが異なる場合、その構造は減算による閉包を満たすことができないとすぐに結論付けます。 
4. すべての差異が一致する場合、セットが有効であることを出力します。 

重要な考え方は、単一のステップ サイズが確立されると、すべての要素が最小間隔で定義された等差数列上に正確に配置される必要があるということです。 何らかの偏差があると、その差が同じセット内で表現できないペアが生成されます。 

### なぜ効果があるのか

 ソート後、減算でセットが閉じられたとします。 最小のギャップを考慮する$d = a_1 - a_0$。 任意の要素$a_k$からアクセスできます$a_0$有効な差異を繰り返し使用し、そのようなすべての差異自体がセットに属している必要があります。 ギャップがこれより大きいか小さい場合$d$、既存の構造と一致しない新しい差分値が導入され、隣接する境界要素を含む一部のペアの閉包が壊れます。 これにより、均一な間隔が強制されます。これは、セットがまさに等差数列であることを意味し、すべてのペアごとの差が次の倍数であることを保証します。$d$したがって、セット内に残ります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()

        if n == 2:
            print("SI")
            continue

        d = a[1] - a[0]
        ok = True

        for i in range(2, n):
            if a[i] - a[i - 1] != d:
                ok = False
                break

        print("SI" if ok else "NO")

if __name__ == "__main__":
    solve()
```この解決策は、各テスト ケース配列を並べ替えることから始まり、すべての構造比較が連続する要素に沿って配置されます。 ソートが完了すると、最初の差が候補ステップ サイズとして採用されます。 次にループは、このステップ サイズが配列全体にわたって一貫していることを検証します。 

特別な場合$n = 2$は常に有効です。これは、ペアが 1 つだけの場合、問題条件下で解釈されたときに 2 つの相違点のうちの 1 つが元の要素の 1 つと一致することが保証されるためです。 

正確性は、均一な間隔からの逸脱をできるだけ早く検出することにかかっており、これにより、違反が見つかった場合にアレイ全体を不必要にスキャンすることが防止されます。

 ## 特殊なケース

 次のような 2 要素セットの場合`{x, y}`の場合、ペアは 1 つしかなく、構造は均一性チェックに違反できないため、アルゴリズムはすぐに「SI」を返します。 例えば、`{10, 100}`に並べ替えます`[10, 100]`そしてスキップして$n=2$支店。 

次のようなほぼ等差数列の場合`{0, 2, 4, 5}`、収量の選別`[0, 2, 4, 5]`。 最初のギャップセット$d = 2$ただし、最後のステップでは不一致が生じます。$5 - 4 = 1$。 ループはこれを直接検出し、セットを拒否します。 

次のような完全に対称的な進行の場合`{-8, -4, 0, 4, 8}`、ソートでは常に 4 という一定の差が得られるため、すべてのペアごとの減算は格子内に留まり、アルゴリズムは明示的なペア チェックを必要とせずにそれを受け入れます。
