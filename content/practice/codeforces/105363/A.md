 ## 解決策
 ## 問題の理解

 いくつかの短い文字列が与えられ、それぞれについて、再配置して「hola」という単語を形成できるかどうかを判断する必要があります。 再配置とは、文字を自由に並べ替えることはできますが、文字を追加したり削除したりすることはできないことを意味します。 したがって、タスクは、入力単語内の複数の文字セットが「hola」の複数の文字セットと正確に一致するかどうかをチェックすることになります。 

各クエリは独立しており、文字列は非常に小さいため、各ケースの決定は純粋にその文字列にローカルに行われます。 各ケースの出力は、この比較に基づく単純な承認または拒否です。 

各文字列の長さが最大 ​​5 であるという制約により、見方が大きく変わります。 文字ごとに一定またはほぼ一定の作業を行うアルゴリズムは、自明のことながら十分に高速です。 各文字列の並べ替えなど、多少冗長なことがあっても無視できます。 これにより、ソリューションは複雑さへの懸念から遠ざかり、正確さと単純さへと向かいます。 

いくつかの特殊なケースが自然に現れます。 「holaa」などの文字が繰り返される文字列は、必要な文字がすべて含まれている場合でも、余分な文字が含まれるため、拒否する必要があります。 「ola」などの短い文字列も、文字が欠落しているため拒否する必要があります。 もう 1 つのケースは、「ohal」のような正しい順列で、文字は完全に一致しますが、シャッフルされます。 

すべての必須文字が少なくとも 1 回出現するかどうかだけをチェックする単純なアプローチは失敗します。 たとえば、「holi」には h、o、l、i が含まれるため、正確な周波数一致が考慮されていない場合、単純な存在チェックでは誤って受け入れられる可能性があります。 

## アプローチ

 この問題を考える強引な方法は、入力文字列のすべての順列を生成し、それらのいずれかが「hola」に等しいかどうかを確認することです。 文字列の長さは最大 5 であるため、順列の最大数は 120 であり、これはテスト ケースごとに技術的に実現可能です。 ただし、順列を繰り返し生成するのは不必要な作業であり、概念的には、問題のより単純な構造がわかりにくくなります。 正確さは、明示的に再配置を検討するのではなく、文字数の一致から得られます。 

重要な観察は、2 つの文字列が各文字の同じ頻度を含む場合に限り、互いの順列であるということです。 再配置を生成する代わりに、文字数を直接比較できます。 ターゲットの単語は固定されており非常に小さいため、両方の文字列を並べ替えるか、頻度を数えて比較することができます。 

ここでは特に仕分けがきれいです。 入力文字列をソートし、ソートされたバージョンの「hola」、つまり「ahlo」と比較すると、即座に等価性テストが得られます。 あるいは、26 個の小文字にわたる頻度配列も同様に機能しますが、このような小さな制約ではソートで十分であり、おそらくより簡単です。 

ブルートフォースアプローチでは不必要な構造の探索に時間がかかりますが、最適なビューでは問題が各文字列の直接の正規表現に分解されます。

 ## アルゴリズムのチュートリアル

 最も直接的なので、ソートベースのアプローチを使用します。

1. 「hola」のソートされた参照文字列を事前計算します。これは「ahlo」になります。 これにより、すべての入力と比較するための正規形式が得られます。 
2. 各ケースは独立しており、個別に処理する必要があるため、テスト ケースの数 T を読み取ります。 
3. 各入力文字列 s について、そのソートされたバージョンを計算します。 並べ替えにより、同じ文字の順列が同じ表現にまとめられることが保証されます。 
4. ソートされた文字列を「ahlo」と比較します。 それらが同一であれば、入力は正確に「hola」の順列であるため、「SI」を出力します。 それ以外の場合は「NO」を出力します。 
5. すべてのテスト ケースに対してこのプロセスを繰り返し、1 行に 1 つの回答を生成します。 

### なぜ効果があるのか

 並べ替えは、文字の複数セットに対して決定的な標準形式を定義します。 2 つの文字列は、並べ替えられた表現が同一である場合にのみ、互いの順列になります。 これにより、置換下の文字列の同値クラスとそれらのソートされた形式との間に 1 対 1 のマッピングが作成されるため、ソートされた文字列が等しいことが正確さのために必要かつ十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    target = sorted("hola")
    target = "".join(target)

    t = int(input().strip())
    for _ in range(t):
        s = input().strip()
        if "".join(sorted(s)) == target:
            print("SI")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```このソリューションでは、まずターゲット単語「hola」のソートされた形式、つまり「ahlo」を構築します。 これにより、文字比較を手動で再計算したりハードコーディングしたりする必要がなくなります。 

各テスト ケースでは、入力文字列は Python の組み込みソートを使用してソートされます。これは効率的で、最大長が 5 であるため十分です。その後、比較は単純な文字列の等価性チェックであり、両方の文字列が同一の文字マルチセットを持つかどうかを直接エンコードします。 

の使用`sys.stdin.readline`高速な入力処理が保証されますが、制約が小さいため、ここではパフォーマンスは重要ではありません。 ロジック自体は完全にソートによる正規表現を中心としています。

 ## 特殊なケース

 「hola」より短い文字列。例:`h`、単一文字列にソートすることで処理されます。 これは 4 文字の参照と一致しないため、比較はすぐに失敗し、「NO」が生成されます。 

次のような文字が繰り返される文字列`holaa`に並べ替えます`aa hlo`(概念的には`aahlo`)、とは異なります`ahlo`, したがって拒否されます。 これにより、文字を明示的にカウントしなくても、頻度の不一致が正しく検出されることが確認されます。 

次のような完全に有効な置換`loah`に並べ替えます`ahlo`、ターゲットに正確に一致します。 これにより、順序の差が並べ替えステップによって完全に正規化されることが確認されます。
