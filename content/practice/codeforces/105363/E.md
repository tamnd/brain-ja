 ## 解決策
 ## 問題の理解

 次の長方形グリッドが与えられます。$n \times m$各セルに 2 つの色のいずれかを割り当てる必要があります。 カラーリングは 2 つのグローバル条件を同時に満たさなければなりません。 

まず、セルのちょうど半分が黒、残りの半分が白でなければなりません。 これにより直ちに強制的に$n \cdot m$均等である必要があります。そうでない場合、分割は不可能です。 

次に、横に隣接するセルのすべてのペアを調べます。 各隣接関係は、2 つのエンドポイントが同じ色であれば「良好」、異なる色であれば「不良」になります。 要件は、良好な隣接関係の数が不良隣接関係の数と等しい必要があることです。 すべてのエッジはこれら 2 つのタイプのいずれかに正確に分類されるため、これは、すべてのグリッド エッジのちょうど半分が同じ色のセルを接続することを強制することと同じです。 

入力は複数のテスト ケースで構成され、それぞれが指定されたグリッド サイズに対してそのようなカラーリングが存在するかどうかを尋ね、存在する場合は 1 つの有効な構造を出力します。 

制約の構造は、解が総グリッド サイズにおいて本質的に線形である必要があることを意味します。 合計から$n \cdot m$到達できる$2 \cdot 10^6$、セルごとに一定以上の作業を行うソリューションは許容されますが、テスト ケース内の二次関数はすでに遅すぎます。 

いくつかの特殊なケースは、早期に切り分ける価値があります。 

もし$n=1$または$m=1$、グリッドは単純なパスになります。 パスでは、すべての内部エッジは常に反対側のパリティ頂点の間にあり、エッジの総数が次のとおりであるため、両方の条件を同時にバランスさせることは不可能になります。$n m - 1$これにより、等しいエッジと等しい色の必要な分割と奇数/偶数の不一致が生じます。 たとえば、$1 \times 2$グリッドには 1 つのエッジがあり、それを 2 つの等しい半分に分割することはできません。 

もう 1 つの重要な観察結果はパリティです。 いつでも$n \cdot m$が偶数であっても、エッジの構造によって正確に半分が同じで半分が異なる隣接に分割できない場合、エッジ条件は依然として失敗する可能性があります。 これは、両方の次元が同時に均等であることに依存することがわかります。 

## アプローチ

 ブルートフォース手法では、グリッドの可能なすべての色付けが試行されます。 各セルには 2 つの選択肢があるため、$2^{nm}$構成。 構成ごとに、黒と白のセルを数え、すべてのエッジをスキャンして、等しいか異なるセルの数を数えます。 これは正しいですが、たとえ$n=m=6$、それはすでに与えられているので、$2^{36}$可能性。 

重要な観察は、2 番目の条件は純粋にエッジに関するものであり、構造が線形であるということです。 値を最適化しているわけではありません。 私たちは正確なバランスをとろうとしています。 これは、異なるエッジ タイプの均等な寄与を強制する強い対称性を持つ構造を探す必要があることを示唆しています。 

決定的な構造的洞察は、両方の次元が均等な場合、グリッドを次のように分割できるということです。$2 \times 2$ブロック。 各ブロック内では、常に 2 つの黒セルと 2 つの白セルを正確に含む 2 つのバランスの取れたパターンの 1 つを使用できます。 これらのパターンをブロック上でチェッカー盤状に注意深く交互に配置することで、1 つのブロック内で生じた局所的な不均衡がすべて、隣接するブロックによって確実に補償されるようになります。 これにより、グローバルなカウントが完全に回避され、構築により両方の制約が強制されます。 

これにより、グローバル制約システムの問題が軽減されます。$nm$変数を独立したローカル決定に反映$2 \times 2$タイル。

 ## アルゴリズムのチュートリアル

 まず、解決策が可能かどうかを判断します。 構築は両方の場合にのみ機能します。$n$そして$m$均等です。 どちらかの次元が奇数の場合は、すぐに「NO」を出力します。 

両方が偶数の場合、次を使用してグリッドの構築に進みます。$2 \times 2$ブロック。 

1. グリッドをブロックに分割します。各ブロックはインデックスに対応します。$(2i,2j)$に$(2i+1,2j+1)$。 両方の次元が均等であるため、部分的なブロックが表示されないため、この縮小は自然です。 
2. 各ブロックには 2 つのパターンのいずれかが割り当てられます。 パターン A では、2 つの黒いセルと 2 つの白いセルが横縞に配置されます。$$\begin{matrix}
. & . \\
\# & \#
\end{matrix}$$パターン B はチェッカー パターンです。$$\begin{matrix}
. & \# \\
\# & .
\end{matrix}$$3. ブロックグリッド上で市松模様のパターンを選択します: ブロック$(i,j)$次の場合にパターン A を使用します$(i+j)$は偶数、それ以外の場合はパターン B。 

この交互の選択により、ブロックが一方向に過剰な同色隣接に寄与するたびに、その隣接するブロックが反対の構造に寄与し、グリッド全体にわたる不均衡の蓄積を防ぐことができます。 
4. すべてのブロックを埋めた後、結果のグリッドを出力します。 

### なぜ効果があるのか

 それぞれ$2 \times 2$ブロックは黒と白のセルに関して個別にバランスが取られるため、色のグローバルな均等性が自動的に保持されます。 

エッジの場合、重要な特性は、2 つのブロック パターンが、ブロック境界に沿って等しい隣接と異なる隣接をどのように分散するかが異なるということです。 パターン A ではブロック内の水平方向の同一性が最大化され、パターン B では同一性が斜めに分散されます。 ブロック上に市松模様に配置すると、2 つのブロック間のすべての内部境界に相補的なパターンが表示され、エッジの寄与が対称的にペアになります。 これにより、全体的に、すべてのエッジの正確に半分が同じ色で、半分が異なる色になることが保証されます。 

構築は決定的であり、すべてのセルを一度だけカバーするため、矛盾や重複は発生しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, m = map(int, input().split())

        if n % 2 == 1 or m % 2 == 1:
            print("NO")
            continue

        print("SI")

        grid = [[''] * m for _ in range(n)]

        for i in range(0, n, 2):
            for j in range(0, m, 2):
                if (i // 2 + j // 2) % 2 == 0:
                    grid[i][j] = '.'
                    grid[i][j + 1] = '.'
                    grid[i + 1][j] = '#'
                    grid[i + 1][j + 1] = '#'
                else:
                    grid[i][j] = '.'
                    grid[i][j + 1] = '#'
                    grid[i + 1][j] = '#'
                    grid[i + 1][j + 1] = '.'

        for row in grid:
            print(''.join(row))

if __name__ == "__main__":
    solve()
```解決策は、構築が完全性に依存しているため、どちらかの次元が奇数であるすべてのケースを拒否することから始まります。$2 \times 2$タイリング。 次に、グリッドがブロックごとに塗りつぶされます。 各ブロックは圧縮座標系でインデックス付けされます。$(i//2, j//2)$、このインデックスのパリティによって、2 つのパターンのどちらが使用されるかが決まります。 

微妙な点は、どちらのパターンも黒と白のカウントが内部的にバランスが取られているため、グローバル カウントを明示的に追跡する必要がないことです。 実際の設計上の唯一の選択は、ブロック境界間のバランスを強制する交互ルールです。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    T = int(sys.stdin.readline())
    out = []

    for _ in range(T):
        n, m = map(int, sys.stdin.readline().split())

        if n % 2 == 1 or m % 2 == 1:
            out.append("NO")
            continue

        out.append("SI")
        grid = [[''] * m for _ in range(n)]

        for i in range(0, n, 2):
            for j in range(0, m, 2):
                if (i // 2 + j // 2) % 2 == 0:
                    grid[i][j] = '.'
                    grid[i][j + 1] = '.'
                    grid[i + 1][j] = '#'
                    grid[i + 1][j + 1] = '#'
                else:
                    grid[i][j] = '.'
                    grid[i][j + 1] = '#'
                    grid[i + 1][j] = '#'
                    grid[i + 1][j + 1] = '.'

        out.extend(''.join(row) for row in grid)

    return '\n'.join(out)

 ## 特殊なケース

 For a$1 \times m$または$n \times 1$グリッドの場合、ブロック ペアリングの失敗という意味では 1 つの次元が奇数であるため、アルゴリズムは即座に拒否します。 例えば、$1 \times 2$を形成できません$2 \times 2$ブロックなので、構築ステップには入らず、出力は正しく「NO」になります。 

両方の寸法が偶数だが最小の場合、次のように$2 \times 2$、グリッドはちょうど 1 つのブロックを形成します。 アルゴリズムはパリティに基づいてパターン A または B を選択し、バランスの取れた 2 行 2 列の配置を生成し、両方のグローバル制約がその単一ブロック内で直接満たされます。 

次のような大きな均等なグリッドの場合$4 \times 6$、チェッカーボードの交互配置により、すべてのブロック インターフェイスが相補的な隣接インターフェイスとペアになることが保証されます。 これにより、行または列にわたるエッジの不均衡のドリフトが防止され、最終的なグリッドは両方のグローバル制約を正確に満たします。
