 ## 問題の理解

 2 つの 2 進数が与えられます`a`そして`b`長さの`n`、そして私たちは変身したいのです`a`の中へ`b`一連の XOR シフト操作を使用します。 各操作で正の整数を選択できます`k`そして左シフトのいずれか`a`による`k`ビットまたは右シフト`a`による`k`ビットを計算し、シフトされた数値と元の数値の XOR`a`。 範囲外にシフトしたビットは破棄され、空の位置にはゼロが埋め込まれます。 せいぜい以下に限られます`n`操作。 

問題は、この変換を達成する一連の操作を作成するか、それが不可能であると報告するかを私たちに求めています。 シーケンスは最小である必要はなく、複数の有効なシーケンスが存在する可能性があります。 

制約は小さいです。`n`最大 2000 まで可能で、すべての合計`n`これは、テスト ケースごとに線形時間で各ビットを個別に検査または変更するソリューションが実現可能であることを意味します。 ただし、XOR シフト操作の考えられるすべてのシーケンスを列挙すると指数関数的になるため、すべてのシーケンスにわたる単純な総当り攻撃は現実的ではありません。 

明らかではないエッジケースとしては、次のような場合があります。`a`すでに等しい`b`この場合、操作は必要ありません。 もう 1 つの注意が必要なケースは次のような場合です。`a`シングルを持っています`1`そして`b`持っています`1`シフト操作では到達できない位置にある場合など`a = 1`、`b = 0`1 ビットの数値では不可能です。 同様に、`b`もっとある`1`よりも`a`XOR シフトを通じて生成することはできますが、変換は不可能です。 

## アプローチ

 ブルートフォースアプローチでは、長さまでのすべての可能なシフトシーケンスが試行されます。`n`、XOR を適用し、到達できるかどうかを確認します。`b`。 XOR とシフトは決定論的であるため、これは正しいですが、可能なシーケンスの数は次のように指数関数的に増加します。`n`、これを実行不可能にします`n`2000年まで。 

重要な洞察は、次のような立場で考えることです。`1`シーケンスではなくビット。 各 XOR シフト操作は、`1`ビットを別の位置に移動し、途中でビットを反転します。 私たちが代表するとしたら`a`そして`b`ビット文字列の場合、問題は左端と右端を揃えることに帰着します。`1`ビットを分割し、ビット間の距離に等しいサイズのシフトを使用してギャップを埋めます。 これは、貪欲にソリューションを構築できることを意味します。まず、一番左の要素を確認します。`1`の`a`一番左に揃えます`1`の`b`左シフトを使用してから、右シフトを使用して伝播します`1`必要な位置に移動します。 もし`b`はありません`1`でも`a`そうすれば排除できる`1`エッジへのシフトの組み合わせによって行われます。そうでない場合、変換は不可能です。 

この構造により、相対的に線形時間で解を生成できます。`n`、最大 3 つの操作を使用します。1 つは左端を揃える操作です。`1`、広めるためのもの`1`s、およびオプションでもう 1 つ追加して構成を完了します。 この問題はそれを保証します`n`可能であれば操作だけで十分です。

 ## アルゴリズムのチュートリアル

 1. バイナリ文字列を変換する`a`そして`b`整数値に変換します。 これにより、文字列インデックスを気にせずに直接ビット単位の操作が可能になります。 
2. もし`a`すでに等しい`b`、出力`0`そして戻ります。 この場合、操作は必要ありません。 
3. もし`a`ゼロであり、`b`ゼロ以外の場合、出力`-1`。 新しいものを生み出せない`1`ゼロ値から。 
4. もし`b`ゼロですが、`a`がゼロ以外の場合は、すべてのビットをキャンセルする単一の操作を出力します。 これは XOR 演算によって実行できます`a`それ自体を左にシフトして`n-1`(またはすべてのビットに触れるシフト)。 これにより、結果が確実にゼロになります。 
5. それ以外の場合は、一番左の位置を見つけます。`1`で`a`そして`b`。 シフト`a`左端になるように左に置いた`1`一番左に揃えます`1`で`b`。 この操作を記録します。 
6. 必要に応じて、右シフトを実行して伝播します。`1`の位置へ`b`それらはありますが、`a`まだありません。 右シフトによる XOR 演算`a`これらのビットを切り替えて一致させることができます`b`。 
7. まで伝播を繰り返します。`a`マッチ`b`。 以来`n`は小さいため、実際には最大 3 回の操作が必要です。 
8. 一連の操作を出力します。 

機能する理由: 各 XOR シフト操作はビットを決定的に移動および切り替えます。 左端を揃えると`1`まず、残りのビットがそのアンカーを基準にして制御できることを確認します。 不変条件は、各操作の後、左端の`1`の`a`左端を越えて右に移動することはありません`1`の`b`, したがって、変革は常に目標に向かって進んでいます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = int(input().strip(), 2)
        b = int(input().strip(), 2)

        if a == b:
            print(0)
            continue
        if a == 0:
            print(-1)
            continue
        if b == 0:
            # Eliminate all bits
            shift = n - 1
            print(1)
            print(shift)
            continue

        ops = []
        # Align leftmost 1
        a_l = a.bit_length() - 1
        b_l = b.bit_length() - 1
        if a_l < b_l:
            ops.append(b_l - a_l)
            a ^= a << (b_l - a_l)
        elif a_l > b_l:
            ops.append(-(a_l - b_l))
            a ^= a >> (a_l - b_l)

        # If still not equal, align rightmost 1
        if a != b:
            a_r = (a & -a).bit_length() - 1
            b_r = (b & -b).bit_length() - 1
            ops.append(b_r - a_r)
            if b_r - a_r > 0:
                a ^= a << (b_r - a_r)
            else:
                a ^= a >> (a_r - b_r)

        print(len(ops))
        if ops:
            print(' '.join(map(str, ops)))

if __name__ == "__main__":
    solve()
```このソリューションは入力を効率的に読み取り、文字列を整数に変換してビット単位で直接操作します。 の使用`bit_length()`一番左のものを見つけます`1`、 その間`(a & -a).bit_length()`一番右のものを見つけます`1`。 シフトは、左シフトの場合は正の整数として適用され、右シフトの場合は負の整数として適用されます。 XOR の更新`a`変換を追跡するためにその場で。
