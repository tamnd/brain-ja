 ## 問題の理解

 指定された文字列の最も長い「強力な」サブシーケンスの長さを見つけるように求められます。 強力な文字列とは、短い文字列を少なくとも 2 回繰り返すことで得られる文字列です。 正式には、何らかの文字列の場合、$T'$繰り返すことができます$k \ge 2$形成にかかる時間$T$、 それから$T$強力です。 文字列の部分シーケンスは、残りの文字の順序を変更せずに 0 個以上の文字を削除することによって取得されます。 

入力は単一の文字列です$S$最大長は 80 で、出力は単一の整数、強力なサブシーケンスの最大長、または存在しない場合は 0 です。 最大長が 80 という小さいため、個別の文字数やサブシーケンスの組み合わせの数が指数関数に近づくヒントが実現可能である可能性があります。 

エッジケースは、すべての文字が異なる場合、または最小限の繰り返しの場合に発生します。 たとえば、「abcdef」には繰り返しのサブシーケンスがないため、答えは 0 になります。「aaa」のような文字列には複数の強力なサブシーケンスがあります。「aa」は強力ですが、「a」が 3 回繰り返されて「aaa」になるため、「aaa」も強力です。 不注意な解決策では、長さが 2 を超えるサブシーケンスを考慮できなかったり、連続する文字のみが重要であると仮定したりする可能性がありますが、サブシーケンスでは文字がスキップされる可能性があります。

 ## アルゴリズムのチュートリアル

 1. の各文字の出現を数えます。$S$。 これにより、繰り返されるシーケンスに対して特定の文字を複数回選択できるかどうかを迅速にチェックできます。 
2. 可能なすべての長さにわたって反復します$d$基本文字列の$T'$。$d$1 から までの範囲で指定できます$|S|/2$繰り返し回数があるので、$k$少なくとも 2 でなければなりません。 
3.長さごとに$d$、一定の長さの文字のすべてのシーケンスを生成します$d$バックトラッキングまたは再帰的アプローチを使用します。 各ステップで、十分な回数出現する文字のみを選択してください。$S$全体で少なくとも 2 回の繰り返しを許可します。 
4. 各候補者について$T'$、スキャンして繰り返しコピーを作成しようとします。$S$貪欲に文字を取り合ってマッチさせる$T'$。 到達した全長を数えます。 
5. すべての候補とすべての約数にわたる最大長を追跡します。 

なぜ機能するのか: 強力なサブシーケンスは次のように表すことができます。$T' \cdot k$と$k \ge 2$。 考えられるものをすべて列挙すると$T'$最大の長さのシーケンス$|S|/2$そして貪欲にそれらを一致させようとします$S$、可能な選択肢をすべて見逃すことがないため、最も長いサブシーケンスが見つかることが保証されています。$T'$サブシーケンスは、順序に違反することなく常に文字をスキップできます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from collections import Counter
from itertools import product

def main():
    S = input().strip()
    n = len(S)
    count = Counter(S)
    letters = list(count.keys())
    max_len = 0

    # Try all lengths of base string T' from 1 to n//2
    for d in range(1, n//2 + 1):
        # Generate all sequences of letters of length d
        for seq in product(letters, repeat=d):
            # Count frequency needed for 2 repeats
            needed = Counter(seq)
            possible = True
            for ch in needed:
                if count[ch] < needed[ch] * 2:
                    possible = False
                    break
            if not possible:
                continue
            # Compute max repetitions
            min_reps = min(count[ch] // needed[ch] for ch in needed)
            max_len = max(max_len, min_reps * d)
    
    print(max_len)

if __name__ == "__main__":
    main()
```解決策は、文字の頻度を数えることから始まります。$S$。 次に、考えられるすべての基本文字列長を反復し、次を使用してすべての候補シーケンスを生成します。`itertools.product`。 の`needed`カウンターは、各レターの何部のコピーが必要かを追跡します。$S$繰り返す$T'$少なくとも2回。 各シーケンスが達成できる最大繰り返し回数を計算し、グローバル最大値を更新します。 使用する`Counter`これにより、繰り返される文字の数え間違いを回避し、境界ケースを自然に処理できます。
