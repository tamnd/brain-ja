 ## 解決策
 ## 問題の理解

 私たちには演劇クラブがあります`n`男の子たちと`m`girls. パフォーマンス グループには正確に次の内容が含まれている必要があります`t`追加の制限が 2 つあります。少なくとも 4 人は男の子、少なくとも 1 人は女の子でなければなりません。 

タスクは、形成できる異なる有効なグループの数を数えることです。 選択した人物の少なくとも 1 人が異なる場合、2 つのグループは異なるものとみなされます。 

制約は非常に小さいです。 両方`n`そして`m`は最大 30 であるため、かなり高価な組み合わせ計算でも安全です。 答えも 64 ビット整数内に収まります。つまり、モジュラー演算を行わずに組み合わせを直接計算できます。 

制約から分かる重要な点は、高度な最適化テクニックは必要ないということです。 選択されたグループにはサイズがあるため、可能な少年の数はわずかです`t`、男子は少なくとも 4 人のメンバーを貢献する必要があります。 男の子と女の子の間で可能な限りの分割を試してみることができます。 

反復限界が不注意な場合、誤った答えが簡単に生成される可能性のある特殊なケースがいくつかあります。 

次の入力を考えてみましょう。```
4 10 5
```有効な構成は、男子 4 名と女子 1 名のみです。 正しい答えは次のとおりです。```
40
```男子チームを 4 ではなく 0 から開始するバグの多いループでは、多くの無効なチームがカウントされます。 

もう 1 つの注意が必要なケースは、特定のスプリットに参加できる十分な女の子がいない場合です。```
10 1 8
```有効な構成は男子 7 名、女子 1 名のみです。 女の子は1人しか存在しないため、6人の男の子と2人の女の子を選ぶことは不可能です。 すべての分割の組み合わせを盲目的に計算する不注意な実装では、次のような無効な値が試行される可能性があります。`C(1, 2)`。 

もう 1 つの微妙なケースが次の場合に現れます。`t`に近いです`n + m`。```
4 1 5
```有効なグループは 1 つだけです。全員を選択する必要があります。 

上限が間違っているループでは、すべての男子が選択されるケースが誤ってスキップされる可能性があります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 人々のすべてのサブセットを列挙し、そのサイズが正確であるかどうかを確認できます。`t`、少なくとも 4 人の男の子が含まれているかどうか、少なくとも 1 人の女の子が含まれているかどうか。 

これが機能するのは、すべての有効なグループが 1 つのサブセットに正確に対応するためです。 問題はサブセットの数です。 最悪の場合、合計60人になるということは、`2^60`サブセット。 これは天文学的な規模であり、2 秒で実行できる速度をはるかに超えています。 

問題の構造により、より良い方向性が得られます。 実際には、数え上げの際に身元は気にせず、選ばれる男女の数だけを気にします。 

グループに正確に含まれると判断したとします。`b`男の子たち。 すると女の子の数は強制的に`t - b`。 

この固定分割の場合:```
ways = C(n, b) * C(m, t - b)
```私たちが自主的に選択するからです`b`からの男の子`n`そして`t - b`からの女の子`m`。 

残っている唯一のタスクは、すべての有効な値を反復処理することです。`b`。 

ブルートフォース手法は、すべてのサブセットを個別に処理するため失敗します。 組み合わせアプローチは、構成ごとに膨大な数のサブセットをグループ化します。 個々のグループを調べる代わりに、1 つの構造のすべてのグループを一度に数えます。 

試行できる値は最大 30 個であるため、この解決策は十分に高速です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(n+m)) | お(1) | 遅すぎる |
 | 最適 | O(t) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`n`、`m`、 そして`t`。 
2. 選択した男の子の数を繰り返し、それを呼び出します`boys`。 
3. ステートメントでは少なくとも 4 人の少年が必要であるため、有効な少年の最小数は 4 です。 
4. 男の子の有効な最大数は次のとおりです。`min(n, t - 1)`。 

以上を選択することはできません`n`男の子、そして少なくとも一人の女の子のための余地を残さなければなりません。 
5. 有効なそれぞれについて`boys`値、計算:```
girls = t - boys
```6. これらの人々を選択する方法の数を数えてください。```
C(n, boys) * C(m, girls)
```7. この値を答えに追加します。 
8. 最終的な答えを印刷します。 

### なぜ効果があるのか

 有効な各劇団には、選ばれた少年たちの固有の数がいます。 実行可能なすべての少年の数を反復処理すると、すべての有効な一団が 1 回の反復で正確に表示されます。 

固定分割の場合`(boys, girls)`、選択肢は独立しています。 最初にどの男子が参加するかを選択し、次にどの女子が参加するかを選択します。 2 つの組み合わせ数を乗算すると、その構成を持つ劇団の正確な数が得られます。 

ループはすべての有効な構成をカバーし、他の構成と重複する構成がないため、最終合計ではすべての有効なグループが 1 回だけカウントされます。 

## Python ソリューション```python
import sys
from math import comb

input = sys.stdin.readline

n, m, t = map(int, input().split())

answer = 0

for boys in range(4, min(n, t - 1) + 1):
    girls = t - boys
    
    if 1 <= girls <= m:
        answer += comb(n, boys) * comb(m, girls)

print(answer)
```解決策は、組み合わせ推論に直接従うものです。 

ルールに違反する男子生徒が少ないため、ループは 4 から始まります。 上限は`min(n, t - 1)`なぜなら、存在する以上の男の子を選択することはできず、すべてを選択することになるからです。`t`男の子の場合、女の子はゼロになります。 

小切手:```
if 1 <= girls <= m:
```無効な女の子数から保護します。 この条件がなければ、女の子が 2 人しかいないのに 5 人を選ぶなど、不可能な選択が試みられる可能性があります。 

パイソンの`math.comb`正確な二項係数を効率的に計算し、必要な範囲を安全に処理します。 答えは 64 ビット整数の範囲に収まるため、オーバーフローは問題になりません。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io
from math import comb

def solve():
    input = sys.stdin.readline
    
    n, m, t = map(int, input().split())
    
    ans = 0
    
    for boys in range(4, min(n, t - 1) + 1):
        girls = t - boys
        
        if 1 <= girls <= m:
            ans += comb(n, boys) * comb(m, girls)
    
    print(ans)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    backup = sys.stdout
    sys.stdout = out
    
    solve()
    
    sys.stdout = backup
    return out.getvalue().strip()

# provided sample
assert run("5 2 5\n") == "10", "sample 1"

# minimum valid configuration
assert run("4 1 5\n") == "1", "minimum sizes"

# only one possible girl count
assert run("10 1 8\n") == str(comb(10, 7)), "single girl available"

# multiple valid splits
assert run("6 3 7\n") == "36", "multiple compositions"

# larger boundary-style case
assert run("30 30 30\n") == str(
    sum(comb(30, b) * comb(30, 30 - b)
        for b in range(4, 30))
), "large values"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`4 1 5`|`1`| 全員が選ばれなければならない正確な境界線 |
 |`10 1 8`|`120`| 考えられる女の子の数が 1 人だけの場合 |
 |`6 3 7`|`36`| 複数の有効な構成 |
 |`30 30 30`| 計算値 | 限界に近い大きな組み合わせ値 |

 ## 特殊なケース

```アルゴリズムは、4 から始まる男の子の数を繰り返します。唯一の有効な分割は次のとおりです。```

girls = 1
```計算は次のようになります。```
C(4,4) * C(10,1) = 1 * 10 = 10
```少年が 4 人未満の無効なケースは考慮されません。 

次に、次のことを調べます。```
10 1 8
```ループは以下をチェックします。 

| 男の子 | 女の子 | 有効？ |
 | --- | --- | --- |
 | 4 | 4 | いいえ |
 | 5 | 3 | いいえ |
 | 6 | 2 | いいえ |
 | 7 | 1 | はい |

 最後の行のみが満たされます`girls <= m`。 答えは次のようになります。```
C(10,7) * C(1,1) = 120
```これにより、組み合わせを追加する前に女の子の数を検証することの重要性が確認されます。
