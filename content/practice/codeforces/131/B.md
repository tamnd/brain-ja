 ## 解決策
 ## 問題の理解

 割り当てられた番号が正反対であるクライアントのペアをすべて数えるように求められます。 各クライアントは -10 から 10 までの番号を持ち、一方のクライアントが番号を持つ場合、ペアは有効です。$x$もう一方には番号が付いています$-x$。 ゼロはそれ自体の反対とみなされ、番号 0 を持つ 2 つのクライアントが有効なペアを形成します。 クライアントの順序は重要ではないため、各ペアは 1 回だけカウントされる必要があり、クライアントは自分自身とペアにすることはできません。 

入力はクライアントの数で構成されます$n$割り当てられた番号のリスト$t_1, t_2, \dots, t_n$。 出力は、有効な反対のペアの合計数です。 

以来$n$と同じ大きさにすることができます$10^5$、すべてのペアを明示的にチェックするブルートフォースアプローチには、おおよそ次のものが必要です$n^2/2$操作、つまり$5 \cdot 10^9$最悪の場合。 これは 2 秒の制限には遅すぎるため、線形または線形に近い解決策が必要です。 すべての数値は狭い固定範囲内にあり、これはカウントベースのアプローチを示唆しています。 エッジケースには、すべてゼロ、繰り返しの数字、および負と正の対称性が含まれます。 たとえば、入力が次の場合`0 0 0`、次の 3 つのペアがあります。`(1,2)`、`(1,3)`、`(2,3)`。 2 つのループでペアをチェックする単純なアプローチでは、ペアを 2 重にカウントするか、ゼロの自己ペアリングを見逃す可能性があります。 

## アプローチ

 ブルートフォース手法は単純です。クライアントのすべてのペアを反復処理し、それらの数値が反対かどうかを確認し、カウンターをインクリメントします。 これは正確に機能しますが、実行されます$O(n^2)$、これは不可能です$n=10^5$周りでパフォーマンスするから$5 \cdot 10^9$比較。 メモリは無視できますが、ランタイムの都合上、このアプローチは受け入れられません。 

最適なアプローチでは、カウント戦略を使用します。 まず、リスト内のすべての数値の頻度マップを作成します。 それぞれの番号について$x$、反対側と形成された有効なペアの数$-x$の数の積です$x$そしてその数$-x$。 ゼロには特別な処理が必要です。ゼロ間のペアの数は次のとおりです。$\binom{count_0}{2} = count_0 \cdot (count_0-1)/2$。 二重カウントを避けるために、カウントをその反対の数で乗算するときは、正の数 (ゼロを含む) のみを考慮してください。 

数値が小さく、制限されているという観察により、長さ 21 (-10 から 10 に相当) の固定サイズの配列または辞書を使用してカウントを追跡することが可能になります。 これにより、実行時間が短縮されます$O(n)$数えるためと$O(1)$固定数の可能な値を使用してペアを計算します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | お(1) | 遅すぎる |
 | 最適 | O(n) | O(1) (固定配列) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. カウンタ配列を初期化する`freq`-10 から 10 までの数値の頻度を格納するサイズ 21。数値のインデックス$x$は`x + 10`。 
2. 入力リストを反復処理し、対応するインデックスをインクリメントします。`freq`番号ごとに。 これにより、線形時間で周波数マップが構築されます。 
3. 変数を初期化する`pairs`反対のペアの総数を保存するには 0 に設定します。 
4. 1 から 10 までの数値を繰り返します。各数値について`x`、乗算する`freq[x + 10]`による`freq[-x + 10]`そして結果を追加します`pairs`。 これにより、反対の数字を持つすべてのペアが二重にカウントされることなく 1 回カウントされます。 
5. ゼロを個別に扱います。 もし`freq[10]`はゼロの数です、加算します`freq[10] * (freq[10] - 1) // 2`に`pairs`すべてのゼロとゼロのペアを考慮します。 
6. の値を出力します。`pairs`。 

機能する理由: アルゴリズムは、すべての数値に対する不変式を使用して、すべてのペアを正しくカウントします。$x > 0$、その負の組み合わせをすべて 1 回だけ含めます。 ゼロはそれ自体と対になるため、組み合わせ式で扱われます。 これにより、どのペアも 2 回カウントされることがなくなり、無効なセルフペアリングが発生することはなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
nums = list(map(int, input().split()))

# frequency array for numbers -10 to 10
freq = [0] * 21
for num in nums:
    freq[num + 10] += 1

pairs = 0
# count positive-negative pairs
for i in range(1, 11):
    pairs += freq[i + 10] * freq[-i + 10]

# count zero pairs
pairs += freq[10] * (freq[10] - 1) // 2

print(pairs)
```最初の部分は入力を読み取り、周波数配列を構築します。 正の数に対するループは、二重にカウントせずに負の数とのペアを計算します。 ゼロの場合は、次から 2 つの要素を選択するための組み合わせ式を使用します。`freq[10]`ゼロ。 正確な整数を取得するには、整数の除算を使用します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    nums = list(map(int, input().split()))
    freq = [0]*21
    for num in nums:
        freq[num+10] += 1
    pairs = 0
    for i in range(1, 11):
        pairs += freq[i+10]*freq[-i+10]
    pairs += freq[10]*(freq[10]-1)//2
    return str(pairs)

# provided samples
assert run("5\n-3 3 0 0 3\n") == "3", "sample 1"
assert run("4\n1 -1 1 -1\n") == "4", "sample 2"

# custom cases
assert run("1\n0\n") == "0", "single zero"
assert run("3\n0 0 0\n") == "3", "three zeros"
assert run("6\n-10 10 -10 10 -10 10\n") == "9", "max absolute value"
assert run("5\n1 1 1 1 1\n") == "0", "all equal positive"
assert run("5\n-1 -1 -1 -1 -1\n") == "0", "all equal negative"
```| テスト入力 | 期待される出力 | 検証内容 |

 ## 特殊なケース

 ゼロの場合は、次のように入力します。`0 0 0`結果として周波数が発生する`freq[10] = 3`。 ペア数の式は次のように計算します。`3*2/2 = 3`ペア、正しく列挙する`(1,2)`、`(1,3)`、`(2,3)`。 すべての同一の正の数について、例えば、`1 1 1`、 count 配列には`freq[11] = 3`、 しかし`freq[-1+10] = freq[9] = 0`, したがって、ペアは追加されません。
