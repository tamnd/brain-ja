 ## 解決策
 ## 問題の理解

 サイズのグリッドとして表現された白黒写真が与えられます。`n × m`ここで、各セルは、白ピクセルの場合は「1」、黒ピクセルの場合は「0」です。 Polycarpus は、「星」を十字のような形をした白いピクセルの構成、つまり上下左右に白いピクセルが隣接するものとして定義します。 私たちの目標は、写真に含まれる少なくとも長方形の部分行列がいくつあるかを数えるということです。`k`星。 長方形の辺はグリッドに合わせて配置する必要があります。 

制約を考慮すると、`n`そして`m`それぞれ最大 500 まで増やすことができます。これは、グリッドに最大 250,000 個のセルを含めることができることを意味します。 考えられるすべての長方形を列挙し、それぞれの中に星の数がいくつあるかを確認するという素朴なアプローチを試みた場合、長方形の数は O(n^2 × m^2) となり、最悪の場合は 10^10 を超える可能性があり、大きすぎて直接処理できません。 これは、四角形内の星の数を迅速にクエリする前処理ステップが必要であることを示しています。 

エッジ ケースには、星の数が非常に少ないグリッド、すべてのピクセルが白で星が重なっているグリッド、星が境界上にあるものの十字パターンに完全に適合していない小さな長方形が含まれます。 十字パターンを確認せずに星をカウントする不用意な実装はオーバーカウントを引き起こします。 たとえば、3×3 のすべて白のグリッドの場合は次のようになります。```
111
111
111
```中心には有効な星が 1 つだけあります。 「1」を星として数えると、誤って 9 つ星と報告されてしまいます。 

## アプローチ

 ブルートフォース手法では、まず考えられるすべての長方形を識別し、その中にある星を数えます。 これを正しく行うには、まず有効な星をすべて検出する必要があります。 各セルについて、隣接する 4 つのセルも白であるかどうかを確認します。 次に、各長方形について、その領域内の星を合計します。 星の位置を事前に計算した場合、各長方形を個別にチェックすると星の数を数えるのに O(n^2 × m^2 × 1) がかかりますが、長方形の列挙は依然として O(n^2 × m^2) であり、遅すぎます。 

重要な洞察は、星の検出を四角形の列挙から分離することです。 グリッド上に星をマークすると、2D プレフィックス合計配列を構築できます。`prefix[i][j]`は、(1,1) から (i,j) までの部分行列内の星の数です。 次に、(x1, y1) から (x2, y2) までで定義される長方形内の星の合計は、標準の包含/除外公式を使​​用して O(1) で計算できます。```
stars = prefix[x2][y2] - prefix[x1-1][y2] - prefix[x2][y1-1] + prefix[x1-1][y1-1]
```ここで問題は、少なくとも次の要素を含むすべての長方形を数えるということになります。`k`効率的な戦略を使用してスターを獲得します。 上部と下部の行のすべてのペアを反復処理し、列ごとに 2D 問題をこれらの行間の星の数として 1D に圧縮し、2 つのポインターを持つスライディング ウィンドウを使用して、星の合計が以上である部分配列をカウントします。`k`。 これは、列が累積的であり、合計が負ではないという事実を利用しており、2 ポインター手法が効率的に機能します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2 × m^2) | O(n × m) | 遅すぎる |
 | 最適 | O(n^2 × m) | O(n × m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グリッドを初期化する`stars[n][m]`有効な星の位置をマークします。 各セルを反復処理する`(i,j)`ここで、1 ≤ i ≤ n-2 および 1 ≤ j ≤ m-2 です。 セルとその 4 つの隣接セルが白の場合、マークを付けます。`stars[i][j] = 1`。 それ以外の場合は、0 とマークします。これにより、十字の中心位置のみがカウントされるようになります。 
2. 2D プレフィックス合計配列を構築する`prefix[n+1][m+1]`。 細胞ごとに`(i,j)`、 セット`prefix[i][j] = stars[i][j] + prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1]`。 これにより、任意の四角形内の星の数の O(1) クエリが可能になります。 
3. 上部と下部の行のすべてのペアを反復処理します。`top`そして`bottom`。 列ごとに計算します`col_stars[c]`間の星の数として`top`そして`bottom`プレフィックス合計配列を使用してその列に入力します。 
4. 治療する`col_stars`1D配列として。 2 ポインター手法を使用します。列のスライディング ウィンドウを維持します。`left`に`right`このウィンドウ内の星の合計が少なくとも`k`。 インクリメント`right`合計が ≥ k になるまで増加します。`left`合計を維持しながら。 各ウィンドウは次の長方形を定義します。`top`に`bottom`そしてから`left`に`right`少なくとも`k`星。 追加`(m - right + 1)`答えに対して、次から始まるすべての有効な長方形を表します。`left`。 
5. すべての上下の行ペアを合計して、有効な四角形の合計数を取得します。 

機能する理由: どの段階でも、アルゴリズムはプレフィックスの合計を使用して、現在の四角形内の星の正確な数を維持します。 2 ポインター法により、すべての連続するサブ配列 (列) が欠落することなくカウントされることが保証され、スライディング ウィンドウにより、冗長な再計算を行わずに四角形が効率的にカウントされることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, m, k = map(int, input().split())
    grid = [input().strip() for _ in range(n)]
    
    # Step 1: mark valid stars
    stars = [[0]*m for _ in range(n)]
    for i in range(1, n-1):
        for j in range(1, m-1):
            if grid[i][j] == '1' and grid[i-1][j] == '1' and grid[i+1][j] == '1' \
               and grid[i][j-1] == '1' and grid[i][j+1] == '1':
                stars[i][j] = 1
    
    # Step 2: 2D prefix sum
    prefix = [[0]*(m+1) for _ in range(n+1)]
    for i in range(n):
        for j in range(m):
            prefix[i+1][j+1] = stars[i][j] + prefix[i][j+1] + prefix[i+1][j] - prefix[i][j]
    
    ans = 0
    # Step 3: iterate over all row pairs
    for top in range(1, n+1):
        for bottom in range(top, n+1):
            col_stars = [0]*m
            for col in range(1, m+1):
                col_stars[col-1] = prefix[bottom][col] - prefix[top-1][col] - prefix[bottom][col-1] + prefix[top-1][col-1]
            
            # Step 4: two pointers to count valid column windows
            left = 0
            curr_sum = 0
            for right in range(m):
                curr_sum += col_stars[right]
                while curr_sum - col_stars[left] >= k:
                    curr_sum -= col_stars[left]
                    left += 1
                if curr_sum >= k:
                    ans += m - right
    
    print(ans)

if __name__ == "__main__":
    main()
```の`stars`配列はクロスの検出ロジックを分離します。 プレフィックス合計を使用すると、O(1) 内の任意の四角形をクエリできます。 上下ペアにわたるネストされたループは管理可能です。`n`≤ 500。列に対する 2 ポインター スキャンは、少なくとも次の値を持つ四角形を効率的にカウントします。`k`の非負和を活用して星を獲得します。`col_stars`。
