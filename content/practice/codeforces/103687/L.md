 ## 解決策
 ## 問題の理解

 キャンディー値の複数セットが与えられています。 JB はこれらのキャンディーのサブセットを選択する必要があります。 彼がサブセットを選択した後、その選択したサブセットの平均値を計算します。$X$。 次に、マシンは JB に、値が厳密に次の値よりも大きいすべてのキャンディーを与えます。$X$、選ばれたかどうかは関係ありません。 

JB は、このプロセスの最後に最終的に受け取るキャンディーの数を最大化するサブセットを選択したいと考えています。 

したがって、決定は間接的です。サブセットの選択は最終的な利益を直接決定するものではなく、平均しきい値を決定し、そのしきい値によってどのキャンディーが授与されるかが決まります。 

重要な相互作用は循環的です。 選択したサブセットが平均を定義します$X$、 しかし$X$どのキャンディーが「勝ち」としてカウントされるかを決定します。 サブセットにキャンディーを含めるとしきい値が上下し、それによって報酬となるキャンディーの最終セットが変わる可能性があるため、単純な推論は難しくなります。 

入力サイズは最大です$10^6$したがって、多くのサブセットを評価しようとする解決策は不可能です。 平$O(n^2)$または$O(n \log n)$複数のパスの上に重い定数がある場合は、パスごとに線形または線形に近い場合にのみ許容されます。 一度ソートしてから 1 回または 2 回のスイープで処理するソリューションを期待する必要があります。 

いくつかの微妙な特殊なケースがすぐに現れます。 

すべてのキャンディーが同じ価値を持つ場合、次のようにします。$a_i = 5$の場合、どのサブセットも平均 5 であり、厳密に 5 より大きいキャンディーはないため、答えは常に 0 になります。 

非常に大きなキャンディーが 1 つある場合、それをサブセットに含めると平均が増加し、構成によっては厳密に平均より大きくならない可能性があります。 たとえば、価値観$[1, 100]$。 両方を選択した場合、平均は 50.5 であるため、100 のみが取得され、1 が得られます。100 のみを選択した場合、平均は 100 であるため、厳密にはこれより大きいものはなく、0 が得られます。最良は 1 です。 

単純な試みでは、大きな要素を貪欲に含めようとする可能性がありますが、包含によってしきい値が非ローカルな方法で変更されるため、構造を持たない貪欲な選択は失敗します。 

## アプローチ

 この強引なアイデアは、すべてのサブセットを列挙し、その平均を計算し、その平均を超える要素の数を数えるというものです。 これは定義上は正しいですが、すぐには実行できません。 がある$2^n$各サブセットについて、その合計と平均を計算し、すべての要素をスキャンしてそれを超える要素の数をカウントする必要があります。その結果、おおよその結果は次のようになります。$O(n \cdot 2^n)$限界をはるかに超えた操作。 

この指数関数的な爆発を回避するには、サブセットの観点から考えることを避け、代わりにキャンディーが授与されるかどうかを決定する最終条件について推論する必要があります。$a_i > X$。 最終的に重要なのは閾値だけです$X$、サブセット自体ではありません。 

候補のしきい値を修正するとします$X$。 そうすれば、JB は、次の値を超えるキャンディーを正確に受け取ります。$X$。 そのセットをそうしましょう$S$。 そのサイズは純粋に次の要素によって決まります。$X$。 ここで問題は、平均が正確に一致するサブセットを選択できるかということです。$X$、すべての要素がより大きいことを保証しながら、$X$まさにそれらです$S$?

 重要な観察は、最適な戦略では、JB が選択するサブセットを常にソートされた値の接尾辞で揃えることです。 配列を非昇順に並べ替えると、任意のしきい値に対して$X$、より大きなキャンディー$X$このソートされた配列のプレフィックスを形成します。 ちょうど一番上を取ることを検討していると仮定しましょう$k$最大のキャンディーが確実な勝者となります。 次に、選択したサブセットがこれらのサブセットの最小値よりも厳密に小さい平均を生成することを確認する必要があります。$k$そうしないと、一部の要素が条件に失敗します。 

これは問題を再構成することを示唆しています。たとえば、JB が最終的に取得するキャンディーの数を推測します。$k$、トップが可能かどうかを確認してください。$k$値は、構築された平均よりも正確に大きい値です。 

配列を降順に並べ替えます。$a_1 \ge a_2 \ge \dots \ge a_n$。 JBが少なくともトップを獲得できた場合$k$キャンディー、次にしきい値$X$以下を満たす必要があります:$$a_k > X \ge a_{k+1}$$（と$a_{n+1} = -\infty$）。 

実現可能性をチェックする必要があります: 平均が以下のサブセットを選択できるか$a_k$しかし、まさにそれらにつながる構造と一貫しています。$k$勝者？ 最適な構築は、プレフィックスのみを考慮する必要があり、固定プレフィックスの達成可能な最良の平均がプレフィックスの合計によって制御されることであることがわかります。 

最後の単純化は、最適な答えは最大値であるということです。$k$次のような:$$\frac{\text{sum of some subset}}{|S|} < a_k$$そして、固定の候補しきい値と比較して平均を最小化または制御するための最適なサブセットは、常に最大側から要素を貪欲に取得することに対応し、これにより条件がプレフィックス平均のチェックに減ります。 

したがって、問題は、ソートされた配列をスキャンし、選択したグループの拡張が勝者を定義する不等式条件と一致しているかどうかを検証しながら、プレフィックスの合計を維持することに集約されます。

### なぜ効果があるのか

 重要な不変条件は、結果を改善する方法で結果の平均を変更することなく、選択したサブセットがソート順序を尊重するような最適な構成に変換できることです。 選択したサブセットに小さい要素が含まれ、大きい要素が除外されている場合、それらを交換しても、厳密にそれを超える要素の数を最大化するための有益な方法で平均しきい値を増やすことはできません。 この交換引数は、ソートされた配列の接頭辞に対して最適な構造を強制し、その決定を接頭辞の合計と境界要素のみに依存させます。$a_k$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    a.sort(reverse=True)
    
    pref = [0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + a[i]
    
    ans = 0
    
    for k in range(1, n + 1):
        # candidate: top k elements are the winners
        # need to ensure we can choose a subset with average < a[k-1]
        # best subset to control average is within top k
        # so check if prefix average condition holds in a stable way
        if pref[k] / k < a[k - 1]:
            ans = k
    
    print(ans)

if __name__ == "__main__":
    solve()
```ソートのステップにより、常に唯一の意味のある順序 (最強のキャンディーから下位) で勝利セットの候補を評価することが保証されます。 プレフィックス合計配列を使用すると、各プレフィックスの平均値を定数時間で計算できます。これが実現可能性チェックの原動力となります。 

状態は上位の平均と比較します$k$のキャンディー$k$- 番目の値。 平均がすでに厳密に以下の場合$a_k$の場合、以下のしきい値を生成することと一致するサブセット構成が存在します。$a_k$、それらを意味します$k$キャンディーは厳密にしきい値を超えているため、収集可能です。 

ループは最大有効値を蓄積します。$k$、これが最終的な答えです。
