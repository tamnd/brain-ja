 ## 解決策
 ## 問題の理解

 整数のコレクションが与えられます。それぞれの整数は、約数の数が 3 ～ 5 と非常に少ないという意味で「ほぼ素数構造」であることが知られています。これらすべての数値を掛け合わせて 1 つの巨大な数にし、最終的な積の約数の数 (法 998244353) を計算するように求められます。 

重要なオブジェクトは値そのものではなく、その素因数分解です。 数値の約数の数は、素因数分解の指数にのみ依存します。 数字が次のように書かれている場合$x = p_1^{e_1} p_2^{e_2} \cdots$の場合、除数の数は次のようになります。$(e_1 + 1)(e_2 + 1)\cdots$。 したがって、このタスクは、すべての入力数値に現れるすべての素数の結合指数構造を再構築し、この公式を適用することと同じです。 

制約$n \le 500$は小さいですが、各数値は次のように大きくなります。$2 \cdot 10^{18}$、これにより直接因数分解は自明ではなくなります。 ただし、約数の制限は非常に強力です。 約数が 3 ～ 5 の数は、非常に限られた形式のみを持つことができます。素数平方のいずれかです。$p^2$(3 つの約数)、2 つの異なる素数の積$pq$(約数 4)、または素数立方体$p^3$または$p^4$(指数構造に応じて 4 または 5 の約数)、または 4 乗の素数$p^4$(約数は 5)。 この構造により、あらゆることが保証されます。$a_i$最大でも 2 つの異なる素因数を持ちます。 

試算除算などの汎用手法を使用して各数値を因数分解しようとする素朴なアプローチ$\sqrt{a_i}$最悪の場合は遅すぎるため、$\sqrt{10^{18}} = 10^9$。 これを500回行っても不可能です。 

2 番目の微妙な問題は、一部の数値が異なる間で素数を共有する可能性があることです。$a_i$したがって、指数をグローバルに正しく集計しない限り、数値ごとのローカル推論では不十分です。 

数値が単一の素数のべき乗である場合、エッジケースが発生します。 たとえば、次の場合$a_i = p^4$の場合、指数 4 が 1 つの素数に寄与し、これが欠けていると約数のカウントが不正確になります。 もう一つの問題は誤分類です$p^2$対$pq$、どちらもサイズは似ていますが、指数構造が異なります。 

## アプローチ

 強引なアイデアは、それぞれを因数分解することです$a_i$試行除算または Pollard-Rho を個別に使用して、すべての素数指数を収集し、グローバル ディクショナリへの指数寄与を乗算します。 除数の数は指数にのみ依存するため、これは原理的には正しいですが、ここでは一般的な整数因数分解は過剰です。 

構造上の制約により状況は一変します。 各数値の約数は最大 5 つであるため、その素因数分解は非常に小さくなければなりません。 これはそれぞれを意味します$a_i$は 1 つの素数の累乗か、最大 2 つの素数の積です。 つまり、1 つの数値につき最大 2 つの素数を検出するだけで済みます。 

完全な因数分解の代わりに、数値間の gcd 関係を利用できます。 2 つの数値が素因数を共有する場合、それらの gcd はそれを直接公開します。 素因数を検出したら、それを完全に分割します。 個別の素数という点では各数値が小さいため、gcd 抽出を繰り返すとすべての数値が完全に分解されます。 

これにより、問題が重い整数因数分解から制御された gcd ベースのピーリング プロセスに軽減され、各ステップで決定論的に素因数が抽出されます。

 ## アルゴリズムのチュートリアル

 残りの値のマルチセットと素数指数の辞書を維持します。 

1. 数字ごとに$a_i$, gcd を使って他の数値と比較することで素数構造を抽出しようとします。 この考え方は、共有素因数が自明ではない gcd として現れるということです。 
2. それぞれについて$a_i$、別のものを選択してください$a_j$。 コンピューティング$g = gcd(a_i, a_j)$。 もし$g > 1$、 それから$g$少なくとも 1 つの完全な素因数が含まれている必要があります$a_i$。 
3. もし$g$1でも等しくない$a_i$、適切な要因を発見しました。 治療します$g$主要な電力コンポーネントとして、それを分割します$a_i$、更新中$a_i \leftarrow a_i / g$。 除数構造により、素数の単一層を超えた隠れた複合干渉がないことが保証されるため、このステップは安全です。 
4. それぞれの値が得られるまで gcd 抽出を繰り返します。$a_i$は 1 または素数累乗に減らされます。 1 より大きい残りの値はそれ自体が素数べき乗です。 
5. すべての数値が素数累乗に分解されたら、素数ごとの指数カウントを集計します。 素因数が出現するたびに、その指数の合計が増加します。 
6. 最後に、次の素数の積として除数の数を計算します。$(e_p + 1)$、モジュロ 998244353。 

### なぜ効果があるのか

 各数値には最大 2 つの異なる素因数があります。 これにより、gcd 相互作用の動作が大幅に制限されます。自明でない gcd は、数値間で共有される素数力率全体に対応する必要があります。 これにより、一般的な整数に存在するであろう曖昧な部分的な重複が防止されます。 その結果、gcd ピーリングを繰り返すと、明示的な因数分解を必要とせずに、すべての主要な寄与がきれいに分離されます。 不変条件は、各抽出ステップの後、除去されたすべての成分が完全なプライムパワー寄与であり、混合複合物ではないことが保証されるということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import gcd

MOD = 998244353

def solve():
    n = int(input())
    a = [int(input()) for _ in range(n)]

    primes = {}

    for i in range(n):
        x = a[i]
        if x == 1:
            continue

        for j in range(n):
            if i == j:
                continue
            if x == 1:
                break
            g = gcd(x, a[j])
            if g != 1 and g != x:
                # extract factor
                while x % g == 0:
                    x //= g
                # record factor g contribution
                y = g
                primes[y] = primes.get(y, 0) + 1

        if x > 1:
            primes[x] = primes.get(x, 0) + 1

    ans = 1
    for e in primes.values():
        ans = ans * (e + 1) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```コードは各数値を反復処理し、他の数値で gcd を使用して共有因子を剥がそうとします。 自明でない gcd が見つかると、それは完全な素数べき成分として扱われ、現在の値から完全に削除されます。 すべての相互作用後に残った値は、残りの素数パワーとみなされ、直接記録されます。 

最後の除数の計算は、素数指数に対する乗法除数の公式を直接適用します。 

微妙な点の 1 つは、現在の数値から gcd 因子のすべての出現を完全に除算し、部分的な剰余が残らないようにすることです。 これにより、同じ主要な寄与を二重にカウントすることが回避されます。

 ## 特殊なケース

 重要なエッジケースは、すべての数値が個別の素数のべき乗である場合です。 その状況では、すべての gcd チェックは 1 を返し、アルゴリズムは各数値を完全な素数累乗として扱うようにフォールバックする必要があります。 最終的な乗算は、$(e+1)$指数 1 以上を正しく計算します。 

もう 1 つのエッジケースは、次のような反復パワーです。$p^4$。 素数が 1 つしかない場合でも、他の数値を含む gcd は決してトリガーされない可能性があるため、アルゴリズムはリダクション後に完全な数値を正しく保持する必要があります。 最後のステップでは、残っているものがすべて確実に取り除かれます。$x > 1$失われていません。 

最後の微妙なケースは、2 つの数値が素数を共有しているものの、指数が異なる場合です。 どの gcd にも最小指数累乗が含まれており、完全除算では両方の数値からそれがきれいに削除されるため、gcd 抽出では依然として共有基底素数構造が分離されます。
