 ## 解決策
 ## 問題の理解

 配列が与えられ、それを 2 つの操作を使用して繰り返し変換することができます。つまり、配列を反転するか、配列をその差分配列で置き換えます。これにより、配列が 1 要素ずつ縮小され、新しい値が連続する要素間の差分になります。 

これらの操作は任意の順序で何度でも適用できますが、配列の長さが 1 になった時点で停止する必要があります。 私たちの目標は、最終的な単一値 (その時点での配列の合計でもある) を最大化することです。 

したがって、このプロセスは基本的に、有限差分変換を繰り返し適用する制御された方法であり、いつでも配列を反転できる追加の自由があり、将来の差分の符号パターンが変更されます。 

制約は小さく、`n ≤ 50`したがって、多項式または 3 次の動作を伴う解決策も許容されます。 ただし、すべての操作シーケンスを指数関数的に探索することはできません。各ステップが 2 つの選択肢に分岐し、その深さは最大で 2 つになるためです。`n`、爆発するでしょう。 

すべての数値が負の場合、または交互の符号が存在する場合、微妙なエッジ ケースが発生します。 貪欲な「常に差分を取る」アプローチは、反転によって減算の方向が変わり、後続の層の主要な要素の寄与が反転する可能性があるため、失敗します。 

## アプローチ

 強引なアイデアは、考えられるすべての操作シーケンスをシミュレートすることです。 長さの状態から`k`、逆転することも差分を取ることもできるので、状態の数はおおよそ次の深さの二分木のように増加します。`n`。 メモ化を行ったとしても、反転のさまざまな順列がマルチセットだけでなく中間配列にも影響を与えるため、状態空間は大きくなります。 

重要な観察は、逆転が根本的に新しい代数力を生み出すわけではないということです。 元の要素の最終的な線形結合の符号パターンを変更するだけです。 

繰り返される差分演算を拡張すると、最終的な単一の値は常に、符号が交互になる二項係数に等しい係数を持つ元の配列の線形結合になります。 配列を反転すると、これらの係数が対称的に交換されます。 

したがって、操作の観点から考えるのではなく、最終結果について考えることに切り替えます。`k`差分演算の結果は、元の配列と次の符号付き畳み込みです。`k`パスカルの三角形の - 番目の行。 唯一の自由は、各段階でシーケンスを順方向に適用するか逆順に適用するかです。 

これにより、問題は差異の各レベルで最適な方向を選択することになり、考えられるすべての停止深さと反転のパリティを評価することで最適な答えを導き出すことができます。

 ## アルゴリズムのチュートリアル

 1. 差分演算を適用した後、次のことを観察します。`k`回、結果として得られる単一の値は、係数が次の値に等しい元の配列の線形結合です。`C(k, i)`位置と方向に応じて記号が交互に表示されます。 
2. 最大の二項係数を事前計算します。`n`パスカルの三角形を使って。 これにより、あらゆるものを評価できるようになります。`k`効率的に次数の差を計算します。 
3. 差分演算の可能な数ごとに`k`から`0`に`n-1`、正確に計算した後に達成可能な最良の値を計算します。`k`削減。 
4. 固定の場合`k`では、配列の両方の方向 (元と逆) を考慮します。 各方向は、二項組み合わせにおける異なる符号パターンを定義します。 
5. 結果の値を、配列とその配列に対応する係数ベクトルの間のドット積として計算します。`k`そしてオリエンテーション。 
6. 全体の最大値を取る`k`そして両方の方向。 
7. Output this maximum as the answer.

 重要な考え方は、反転は係数の順序を反転するだけであるため、すべての深さで両方向をテストすれば十分であるということです。 

**機能する理由:** 有効な演算シーケンスはすべて、配列を元の配列または反転した配列の k 次の有限差分に換算します。 そのような結果はすべて列挙することでカバーされるため、`k`どちらの方向でも、考えられるすべての最終状態を網羅します。 したがって、この有限セットの最大値は最適である必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        if n == 1:
            print(a[0])
            continue

        # binomial coefficients
        C = [[0] * n for _ in range(n)]
        C[0][0] = 1
        for i in range(1, n):
            C[i][0] = C[i][i] = 1
            for j in range(1, i):
                C[i][j] = C[i-1][j-1] + C[i-1][j]

        ans = -10**18

        for k in range(n):
            # compute k-th difference contribution
            for rev in [False, True]:
                arr = a[::-1] if rev else a

                val = 0
                for i in range(n - k):
                    sign = -1 if i % 2 else 1
                    val += sign * C[k][i] * arr[i]

                ans = max(ans, val)

        print(ans)

if __name__ == "__main__":
    solve()
