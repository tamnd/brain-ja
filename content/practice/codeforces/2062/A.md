 ## 解決策
 ## 問題の理解

 文字で構成されるバイナリ文字列が与えられます`0`そして`1`。 目標は、文字列内のすべての文字を次のように変換することです。`0`。 サブシーケンス内の連続する 2 つの文字が同じにならないように文字列のサブシーケンスを選択し、そのサブシーケンス内のすべての文字を反転する操作を実行できます (`0`になる`1`そして`1`になる`0`）。 各操作では複数の文字を同時に反転できますが、選択したサブシーケンス内の隣接する要素が交互になるという制約の下でのみ可能です。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは最大 50 個の長さの文字列です。テスト ケースの数は最大 10,000 です。 各文字列は最大 50 文字と短いため、少なくとも次の時間で実行されるアルゴリズムを検討できます。$O(n^2)$制限時間を超えずにテストケースごとにテストします。 ただし、テストケースの数が多いため、不必要な入れ子ループは避ける必要があります。 

明らかでないエッジ ケースには、すでにすべて 0 である文字列、すべて 1 である文字列、および 1 が交互の位置でのみ現れる文字列が含まれます。 不注意なアプローチは、それぞれをひっくり返そうとする可能性があります`1`重複を考慮せずに、最大の交互セグメントを個別にまたは貪欲に反転すると、必要以上に多数の操作が発生する可能性があります。 たとえば、`10101`、各シングルの素朴なフリップ`1`5 つの操作が発生しますが、交互のサブシーケンスを慎重に選択することで、同じことを 3 つで達成できます。 

## アプローチ

 ブルートフォース手法では、文字列の有効なサブシーケンスをすべて試して反転し、残りの文字列を再帰的に解決します。 これは正しいですが、非常に遅いです。 たとえ$n = 50$、サブシーケンスの数が指数関数的に増加するため、このアプローチは実行不可能になります。 

重要な観察は、すべての操作で文字が交互に切り替わるサブシーケンスを反転するということです。 したがって、最小の操作数は、連続する同一文字のブロックの数によって決まります。`1`s は、少なくともその長さと同じ数のフリップを必要とするか、隣接する位置のフリップと組み合わせて合計数を減らすことができます。 それぞれを具体的に言うと、`1`隣接するものと一緒に反転する可能性があります`0`は交互のパターンですが、最小の操作数は、次の位置の数を数えることに相当します。`1`が連続して出現するか、または実行される回数`1`s.

 この問題を単純な計数タスクに帰着させる洞察は、演算の数はすべての 1 の合計に等しいということですが、交互のフリップを考慮すると、これはさらに減少します。 実際、演算の最小数は、連続する同一文字のセグメントの数に等しくなります。`1`。 それぞれの実行`1`を慎重に選択した単一の交互フリップ シーケンスで削除でき、隣接しないものを同じ操作で同時に処理できます。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. 文字列ごとにカウンターを初期化します。`ops`ゼロに。 
3. 文字列を左から右にトラバースします。 
4. いつでも`1`が発生した場合は、`ops`カウンターを設定し、この実行が終了するまで右に移動し続けます。`1`に達します。 
5.スキップ`0`次まで`1`が見つかったら、前の手順を繰り返します。 
6. 文字列全体を走査した後、`ops`は必要な最小限の操作数を表します。 
7. 各テストケースの結果を出力します。 

機能する理由: 連続して実行されるたびに、`1`s は少なくとも 1 回反転する必要があります。 で始まる最大の交互サブシーケンスを反転することにより、`1`できるだけ多くの文字を含めて、すべてを削除します`1`不要な追加操作なしで実行できます。 フリップは隣接しない実行を接続できないため、個別の実行にまたがるフリップを結合しようとしても、操作の数を減らすことはできません。`1`交互サブシーケンス規則に違反することはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def min_operations(s: str) -> int:
    ops = 0
    i = 0
    n = len(s)
    while i < n:
        if s[i] == '1':
            ops += 1
            while i < n and s[i] == '1':
                i += 1
        else:
            i += 1
    return ops

t = int(input())
for _ in range(t):
    s = input().strip()
    print(min_operations(s))
```機能`min_operations`文字列を反復処理し、連続する各実行をカウントします。`1`単一の操作として。 内側のループでは、二重カウントを避けるために現在の実行をスキップします。 使用する`input().strip()`末尾の改行によるエラーを回避します。 各文字が 1 回だけ処理されるため、このソリューションは効率的に機能します。

 ## 特殊なケース

 完全にゼロで構成される文字列の場合、次のようになります。`00000`、アルゴリズムは、次の実行がないことを正しく識別します。`1`とリターン`0`操作。 完全に 1 で構成される文字列の場合、次のようになります。`11111`、アルゴリズムは単一の連続した実行を識別し、次の値を返します。`1`動作は最小限です。 次のような交互パターン`10101`それぞれを正しく数えます`1`独自の実行で、最小限の操作を行います。 内側のループは連続するループをスキップし、オフバイワンエラーを防ぐため、アルゴリズムが二重にカウントを実行することはありません。
