 ## アルゴリズムのチュートリアル

 この問題を再定式化して、ノードごとに、考えられる各深さレベルをサポートする子の数を計算し、それを全体にわたる寄与に変換します。$k$。 

### ステップ

 1. ツリーを 1 でルートし、DFS 順序でツリーを計算します。 

これにより、すべてのサブツリーがその親より前に処理されるようになり、必要なときにいつでも子の情報を利用できるようになります。 
2. 各ノードについて$u$、マルチセットを定義します$S_u$各子が提供する最大ヒープ深さを表す値が含まれます。 

この抽象化により、構造を無視してサブツリーの「強度」のみに焦点を当てることができます。 
3. ノードをポストオーダーで処理します。 葉の場合は、$S_u = \{1\}$。 

リーフは、次の条件に関係なく、深さ 1 のヒープのみを形成できます。$k$。 
4. 内部ノードの場合$u$、すべての子マルチセットをマージします$S_v$一つの構造にまとめます。 

マージ ステップでは、考えられるすべてのサブツリーの深さを集約します。$u$信頼できる。 
5.変換$S_u$ソートされた配列に$a_u$。 

ヒープの状態は「少なくとも$k$子供たち」。 
6. 各深さのしきい値について$m$、要素の数を計算します。$a_u$少なくとも$m-1$。 

この数は、実現可能な最大値を直接示します。$k$どの深さまで$m$達成可能です。 
7. ノードへの貢献を蓄積する$u$すべてを合計すると$m$：各深さ$m$貢献する$m$みんなに$k \le c_u(m)$。 

これにより、2 次元の依存関係が間隔のカウントに変換されます。 
8. 親ノードが既に集約された情報を再利用できるように、結果を上方にマージします。 

これにより、各エッジがマージ操作ごとに 1 回だけ処理されることが保証されます。 

### なぜ効果があるのか

 すべてのノードで$u$、可能なヒープ深さの構造は、特定の深さのしきい値をサポートできる子サブツリーの数によって完全に決定されます。 重要な不変条件は、処理後の$u$、マルチセット$S_u$で達成可能なすべてのサブツリーの深さを正しくエンコードします。$u$。 ヒープの状態はしきい値を超えた子の数のみに依存するため、ソートによって必要な情報がすべて保持され、構造の詳細が失われることはありません。 

各ペアであるため、すべての貢献は 1 回だけカウントされます。$(u, m)$有効な一意の間隔にマッピングされます。$k$、これらの間隔は集計において互いに素です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

n = int(input())
g = [[] for _ in range(n)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append(v)
    g[v].append(u)

ans = 0

def dfs(u, p):
    global ans
    depths = []

    for v in g[u]:
        if v == p:
            continue
        child_depths = dfs(v, u)
        depths.extend(child_depths)

    if not depths:
        ans += 1
        return [1]

    depths.sort(reverse=True)

    cnt = 0
    freq = {}

    # compute contribution of u
    for i, d in enumerate(depths, 1):
        if d >= i:
            cnt = i
        else:
            break

    ans += cnt + 1

    new_depth = cnt + 1
    return depths[:cnt] + [new_depth]

dfs(0, -1)
print(ans)
```DFS は、ノードごとに、その子からの達成可能な深さのリストを計算します。 リストはソートされているため、最大の深さと必要な最小の位置を貪欲に一致させることができ、ヒープの深さの増加をサポートできる子の数をチェックすることをシミュレートします。 

変数`cnt`増加する深さの制約の連鎖を維持できる子の最大数を表します。 これが計算されると、ノードはそのノードをルートとするすべての有効なヒープ構成を提供します。`cnt + 1`。 

戻り値はサブツリーを簡略化された表現に圧縮し、最も強力な寄与者とノード自体で新しく形成された深さのみを保持します。 これにより、保存された状態の指数関数的な増加が防止されます。 

再帰制限が増加するのは、ツリーが長いチェーンになる可能性があり、そうしないと Python のデフォルト制限がオーバーフローしてしまうためです。

def run(inp: str) -> str:

    import sys
    input = sys.stdin.readline

    g = [[] for _ in range(n)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    sys.setrecursionlimit(10**7)

        nonlocal ans
        depths = []

            if v == p:

            child = dfs(v, u)
            depths.extend(child)

            if d >= i:
                cnt = i
            else:
                break

        ans += cnt + 1
        return depths[:cnt] + [cnt + 1]

 ## 特殊なケース

 パス状のツリーは、再帰にとって最もクリーンなストレス ケースです。 各ノードには子が 1 つだけあるため、ソートされた深さリストのサイズは常に 1 になります。 アルゴリズムは次のように割り当てます。`cnt = 1`すべての内部ノードで、組み合わせ爆発を起こすことなく、一貫した深さの上方への伝播を生成します。 

星型のツリーは、しきい値の動作を最も明確に示します。 ルートでは、子の深さのリストは大きくなりますが、すべて 1 に等しいため、$k=1$深さの増加に貢献します。 アルゴリズムは正しく計算します`cnt = 1`これにより、より多くの子がより高い深さを自動的に意味すると誤って仮定した場合に発生する過大評価を防ぐことができます。 

完全にバランスの取れた二分木は、マージによって対称性が維持されるかどうかをテストします。 各レベルで、子の深さリストが均等に結合され、貪欲なマッチングにより、十分に深いサブツリーのペアのみが上位レベルに寄与することが保証され、集約された寄与の正確性が維持されます。
