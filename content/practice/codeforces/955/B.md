 ## 解決策
 ## 問題の理解

 単一の小文字文字列が与えられます。 課題は、その位置を 2 つの互いに素なサブシーケンスに分割して、各サブシーケンスが等しい文字の 2 つの連続するブロックに再配置できる文字列を形成できるかどうかを判断することです。また、これら 2 つのブロックは異なる文字を使用する必要があります。 

要件を理解するもう 1 つの方法は、2 つのサブシーケンスのそれぞれが「2 ブロック ソート可能」でなければならないということです。つまり、その文字を並べ替えた後、ある文字の後にいくつかの別の文字が続くように見える必要があります。 2 つの文字は異なるものである必要があり、両方のブロックが空であってはなりません。 

2 つのサブシーケンスのインデックスを自由に選択できるため、これは部分文字列のパーティションではなく、位置のパーティションです。 

文字列の長さは最大 100000 にすることができ、インデックスのすべてのパーティションをテストしようとするソリューションは即座に除外されます。 文字列を 2 つのサブシーケンスに分割するだけでも、すでに 2^n 通りの可能性があり、両側を個別に検証しようとするとさらに可能性が高くなります。 実行可能な解決策は、頻度パターンと文字の再利用から導き出される構造的制約に依存する必要があります。 

いくつかの特殊なケースは見落とされがちです。 

「aaaaa」など、異なる文字が 1 つだけ含まれる文字列は、明らかに正常に分割できません。これは、サブシーケンスも 1 つの文字で構成され、2 つの異なるブロックを形成できないためです。 

「ababab」のような文字列は柔軟に見えるかもしれませんが、文字が均等に分散されすぎると、それぞれに必要な構造を持つ少なくとも 2 つの異なる文字を含む 2 つのサブシーケンスを構築することが制限されます。 

もう 1 つの微妙なケースは、文字列に正確に 2 つの異なる文字が含まれているが、1 つの文字が出現するのがまれすぎて、2 ブロック構造を持つ両方のサブシーケンスを同時にサポートできない場合です。 

## アプローチ

 ブルートフォースのアイデアは、インデックスを 2 つのサブシーケンスに分割する方法を選択することから始まります。 各パーティションについて、両方のサブシーケンスを個別にチェックします。各サブシーケンスについて、文字のマルチセットを正確に 2 つの異なるシンボルに再配置できるかどうかを確認します。 このチェック自体は頻度カウントを使用することで簡単に行えますが、パーティションの数がすべてを支配します。 

サブシーケンス内の順序を無視したとしても、各文字の位置をグループ A または B に割り当てる方法は 2^n 通りあり、n = 100000 の場合はこれは不可能です。 

重要な観察は、各サブシーケンスの内部順序制約が非常に弱いということです。サブシーケンスを修正すると、それはそれに含まれる異なる文字の数と、再配置後に異なる文字の空でない 2 つのグループに分割できるかどうかにのみ依存します。 この条件は次のように単純化されます。サブシーケンスには少なくとも 2 つの異なる文字が含まれている必要があり、選択した 1 つの文字のすべての出現を最初のブロックに割り当て、その他のすべてを 2 番目のブロックに常に割り当てることができます。 

したがって、有効な各サブシーケンスには少なくとも 2 つの異なる文字のみが必要です。 問題は、元の文字列の複数の文字セットを、それぞれ少なくとも 2 つの異なる文字を含む 2 つのグループに分割できるかということです。 

これにより、問題は周波数分布の実現可能性チェックに変換されます。 シーケンスを調整することはなくなり、双方が少なくとも 2 つの異なる文字タイプを受け取るようにするだけです。 

世界中にいくつの異なる文字が存在するかを追跡すれば、実現可能性について推論することができます。 個別の文字の合計数が少なすぎる場合、分割は不可能です。 異なる文字が多数ある場合は、いつでも双方が満足できるようにそれらを配布できます。 

唯一の自明ではない境界は、アルファベットの多様性がちょうど 2 または 3 の場合であり、この場合、両方の部分列が依然として 2 つの異なる文字を取得できることを確認する必要があります。

最終的な解決策は、文字の頻度をカウントし、供給を使い果たさずに 2 つのグループのそれぞれに少なくとも 2 つの異なる文字を割り当てることができるかどうかを確認することになります。

 ## アルゴリズムのチュートリアル

 小文字のラテン文字のみが表示されるため、文字列を 26 文字にわたる頻度配列に圧縮します。 

1. 文字列内の各文字の出現回数を数えます。 これにより、使用可能なシンボルのマルチセット ビューが得られます。 どの文字が割り当てられているかがわかれば、サブシーケンス内の順序は無関係になるため、これで十分です。 
2. 存在する個別の文字の数を計算します。 存在する個別の文字が 4 つ未満の場合、各サブシーケンスに 2 つの異なる文字を与え、それらを互いに素な状態に保つことは期待できません。 これは、各サブシーケンスには少なくとも 2 つの異なる文字が必要であるため、きれいな分割を試みるにも全体で少なくとも 4 つの異なる文字が必要であるという事実から来ています。 
3. 4 つ以上の異なる文字がある場合は、2 つの異なる文字をサブシーケンス A に割り当て、2 つの異なる文字をサブシーケンス B に割り当てることで、常に有効なパーティションを構築できます。各サブシーケンスには正確な数ではなく、少なくとも 2 つの異なるシンボルのみが必要であるため、残りの文字は任意に分配できます。 
4. 異なる文字がちょうど 3 つある場合、それらのうちの 1 つが両方のサブシーケンスに分割できるほど頻繁に出現する一方で、各グループに少なくとも 2 つの異なる文字が残っているかどうかを確認する必要があります。 この場合、実現可能性は、少なくとも 1 つの文字の頻度が 1 より大きく、両方のグループを完成させるために再利用できるかどうかによって決まります。 
5. 異なる文字が 2 つだけ存在する場合、解決策は存在しません。 1 つのサブシーケンスでは必ず 2 番目の個別の文字が欠落し、要件に違反します。 

### なぜ効果があるのか

 各サブシーケンスの唯一の構造要件は、再配置後に 2 つの異なるシンボルが存在することです。 つまり、パーティションの問題は文字に対するセットカバー スタイルの制約に集約されます。各サブセットに少なくとも 2 つの異なるシンボルを割り当てる必要があります。 文字は独立しており、その数のみが重要であるため、実現可能性は、使用可能な個別の文字の数と、数が少ない場合に分割できるかどうかのみに依存します。 これにより、一度個別の文字条件が満たされると、サブシーケンス内の順序を常に「2 つの連続するグループ」プロパティを満たすように配置できることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    freq = [0] * 26

    for ch in s:
        freq[ord(ch) - 97] += 1

    distinct = sum(1 for x in freq if x > 0)

    # If fewer than 3 distinct letters, impossible
    if distinct < 3:
        print("No")
        return

    # If 3 or more distinct letters, we can always arrange a valid split
    # because we can assign at least two letters per subsequence by distribution.
    print("Yes")

if __name__ == "__main__":
    solve()
```このソリューションでは、個別の文字をカウントするだけで済みます。 必要な状態は周波数配列だけです。 文字の利用可能性が十分であれば、サブシーケンスの内部構造は常に満たされるため、サブシーケンスをシミュレートすることはありません。 

少なくとも 2 つの異なるシンボルを持つマルチセットは常に 2 つの連続するブロックに順序付けできるため、実装上の重要な選択は配置を完全に無視することです。

 文字列には 2 つの異なる文字のみが含まれています。 1 つのサブシーケンスは必ず 2 つの異なるシンボルを持つ能力を失うため、2 つのブロックを形成することはできません。 

出力は「いいえ」です。 

### 例 2: 「abcabc」

 | ステップ | 周波数 | 独特の | 決定 |
 | --- | --- | --- | --- |
 | すべて読む | a:2 b:2 c:2 | 3 | はい |

 3 つの異なる文字があります。 (a,b) を一方のサブシーケンスに割り当て、(b,c) をもう一方のサブシーケンスに割り当て、必要に応じて b を共有することができます。 どちらのサブシーケンスも 2 つのブロックに再配置できます。 

出力は「はい」です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    s = input().strip()
    freq = [0] * 26
    for ch in s:
        freq[ord(ch) - 97] += 1
    distinct = sum(1 for x in freq if x > 0)
    return "Yes\n" if distinct >= 3 else "No\n"

# provided samples

 ## 特殊なケース

 「aaaaaa」のような単一の繰り返し文字列は、distinct = 1 を生成することによって処理され、すぐに No を返します。2 つのブロックのサブシーケンスを形成するための 2 番目のシンボルが存在しないため、アルゴリズムは分割を試行しません。 

「ababab」のような 2 文字の文字列は、distinct = 2 となるため、拒否されます。 これは、グローバルに 2 つだけが存在する場合、両方のサブシーケンスに 2 つの異なる文字を与えることが不可能であることを正確に捉えています。 

「aaabbbccc」のような境界線にある 3 文字の場合は、distinct = 3 となり、アルゴリズムは Yes を返します。 ここで、各サブシーケンスには少なくとも 2 つのシンボルを割り当てることができます。これは、3 つの文字にわたる分散によって重複またはペアリングの柔軟性が保証され、有効な 2 ブロックの配置を構築するのに十分であるためです。
