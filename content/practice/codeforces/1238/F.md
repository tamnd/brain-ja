 ## 解決策
 ## 問題の理解

 ツリーが与えられ、線上の線分の交差グラフとして表現できる最大の接続された部分グラフを見つける必要があります。 

グラフは、セグメントごとに 1 つの頂点を作成し、対応するセグメントが交差するたびに 2 つの頂点を接続することによって、セグメントから構築されます。 この方法で表現できる木もあれば、そうでない木もあります。 指定されたツリーのすべての接続されたサブグラフの中で、表現可能な頂点の最大数を持つサブグラフを見つけなければなりません。 

入力には最大で次のものが含まれます$1.5 \cdot 10^5$テスト ケースですが、すべてのツリーの頂点の合計数は最大でも$3 \cdot 10^5$。 この集約バウンドが重要です。 ツリーごとの線形よりも大幅に悪い解決策は失敗します。 アン$O(n^2)$アルゴリズムには次のようなものが必要です$9 \cdot 10^{10}$最悪の場合の操作は完全に不可能です。 平$O(n \log n)$それは問題ありませんが、意図した解決策は実際には線形です。 

難しいのはツリーの処理自体ではありません。 課題は、どのツリーが区間交差グラフとして表現できるかを理解することです。 

古典的な結果によれば、区間グラフはまさに直線上の区間の交点グラフです。 区間グラフであるツリーの構造は非常に制限されています。 区間グラフは弦状であり、木の中で唯一の区間グラフは毛虫であるため、いかなるサイクルも不可能です。 

毛虫は葉をすべて取り除くと簡単な道になる木です。 

この観察によって問題は完全に変わります。 私たちはもはや、任意の適切なサブツリーを探す必要はありません。 私たちは、接続された最大のサブツリーであるイモムシを探しています。 

いくつかの特殊なケースは見落とされがちです。 

星を考えてみましょう。```
1
5
1 2
1 3
1 4
1 5
```木全体が毛虫です。 葉を削除すると、頂点が 1 つだけ残ります。 答えは5です。 

単純な直径ベースのアプローチでは、誤って 2 のみが返されます。 

高さ 2 のバランスの取れた二分木を考えてみましょう。```
      1
    / | \
   2  3  4
  / \ / \
 5 6 7 8
```答えは 7 ではなく 8 です。最適なイモムシは 1 つの中央パスを使用し、そのパスの頂点に葉を付けたままにすることができます。 

もう 1 つの微妙なケースは、単純なパスです。```
1-2-3-4-5
```すでに木全体が毛虫になっています。 答えは5です。 

分岐頂点のみをカウントし、パスの終点を忘れる DP は、このケースを過小評価します。 

## アプローチ

 ブルートフォースの観点は単純です。 接続されているすべてのサブツリーを列挙し、それが毛虫であるかどうかをテストします。 

木が毛虫かどうかをテストするのは簡単です。 すべての葉を削除し、残ったグラフがパスであるかどうかを確認します。 問題は接続されたサブツリーの数です。 数百の頂点を持つツリーでさえ、すでに膨大な数の接続されたサブグラフを持っています。 このアプローチは絶望的です。 

重要な観察は構造的です。 

木は、それが毛虫である場合に限り、区間グラフとして表現できます。 キャタピラは、しばしば脊椎と呼ばれる背骨のパスと、そのパスの頂点に取り付けられた任意の葉で構成されます。 

区間表現について考える代わりに、パスの選択について考えることができます。 そのパス上のすべての頂点は、その隣接するすべてのリーフに寄与する可能性があります。 パスから 1 つの端を超えて伸びる枝は、キャタピラの特性に違反します。 

頂点が脊椎に属していると仮定します。 1 つの入射エッジはスパイン上の親に接続するために使用され、別の入射エッジはスパインを下方向に継続することができ、残りのすべての入射エッジは 1 つのリーフ頂点にのみ寄与できます。 

これは当然、ツリー DP を示唆します。 

根を張った木を直しましょう。 背骨が現在の頂点から始まり、下に向かう最良のキャタピラを表す状態が必要です。 スパインが頂点を通過するとき、未使用のすべての子が 1 つのリーフを提供します。 脊椎を継続するために 1 人の子供が選ばれる場合があります。 

これにより、問題は各頂点が寄与する最長パス スタイルの DP に変わります。```
(number of available leaves) + 1
```そして一人の子供がその連鎖を続けるかもしれません。 

最終的な答えは、直径 DP とまったく同じように、各頂点を通る 2 つの最適な下向きの脊椎の拡張を組み合わせることによって得られます。

 ## アルゴリズムのチュートリアル

 ツリーが任意の頂点、たとえば頂点 1 にルートするとします。 

定義:`dp[v]`= 背骨が次から始まる芋虫サブツリーの最大サイズ`v`そして子孫にのみ続きます。 

頂点の場合`v`、 させて```
base(v) = 1 + (deg(v) - 1)
```非ルート頂点の場合。 

の`1`頂点自体をカウントします。 

入射エッジのうち、1 つのエッジは親に向かうため、リーフになることはできません。 他のすべての未使用の入射エッジはリーフに寄与する可能性があります。 

ルートの場合:```
base(root) = 1 + deg(root)
```親エッジがないためです。 

次に、頂点をボトムアップで処理します。 

### 1. スパインを拡張せずにすべての頂点の寄与を計算します。 

脊椎が次の位置で終わる場合`v`、すべての子エッジが葉になります。 

価値は単純に`base(v)`。 

### 2. 一人の子供を通して背骨を伸ばしてみてください

 脊椎が子供まで続いていると仮定します`u`。 

へのエッジ`u`はリーフとして利用できなくなったので、1 つのリーフの貢献を失います。 

結果の値は次のとおりです。```
base(v) - 1 + dp[u]
```すべての子の最大値を取得します。 

これにより、`dp[v]`。 

### 3. 各頂点を通過する最良のキャタピラを計算します。 

大域最適は、そのスパインが通過する可能性があります。`v`そして 2 つの異なる子方向に進みます。 

させて```
gain(u) = dp[u]
```すべての子供たちに。 

子の最大の 2 つのゲインを取得します。 

キャタピラの中心は`v`サイズがあります```
base(v) + best1 + best2 - 2
```2 による減算は、2 つの子エッジをリーフ エッジの代わりにスパイン エッジとして使用することによって行われます。 

ルートの場合、すでに除外されている親エッジがないため、式は少し異なります。 

以下の統合実装を使用する方が簡単で、特殊な場合の推論を回避できます。 

### 4. グローバル回答を更新する

 すべての頂点について、その頂点を背骨が通過する最良のイモムシで答えを更新します。 

### 5. すべてのテスト ケースを処理する

 頂点の総数は最大でも$3 \cdot 10^5$の場合、ツリーごとに 1 つの DFS で十分です。 

### なぜ効果があるのか

 毛虫は背骨の経路によって完全に決まります。 スパイン上のすべての頂点は、スパイン上に残すために最大 2 つの入射エッジを使用できます。 他のすべての入射エッジはリーフのみを提供できます。 

DP 状態は、背骨が上から頂点に入り、最大で 1 つの子を通って下向きに続く最適なイモムシを表します。 頂点で 2 つの最適な子エクステンションを組み合わせると、その頂点が最上位の頂点となる、考えられるすべてのスパイン パスが構築されます。 すべてのイモムシには、根が生えているツリー内でそのような最も高い脊椎の頂点が 1 つだけあるため、すべての有効なイモムシが考慮されます。 DP は常に、合法的にリーフになることができるすべての頂点を考慮し、スパインから 1 を超える距離が生じるすべての頂点を除外します。 したがって、計算された最大値はまさに最大のイモムシのサブツリーになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    anss = []

    for _ in range(t):
        n = int(input())

        g = [[] for _ in range(n)]

        for _ in range(n - 1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            g[u].append(v)
            g[v].append(u)

        parent = [-1] * n
        order = [0]
        parent[0] = 0

        for v in order:
            for to in g[v]:
                if parent[to] == -1:
                    parent[to] = v
                    order.append(to)

        dp = [0] * n
        answer = 0

        for v in reversed(order):
            deg = len(g[v])

            if v == 0:
                base = deg + 1
            else:
                base = deg

            best1 = 0
            best2 = 0

            dp[v] = base

            for to in g[v]:
                if to == parent[v]:
                    continue

                cand = base - 1 + dp[to]
                if cand > dp[v]:
                    dp[v] = cand

                val = dp[to]
                if val > best1:
                    best2 = best1
                    best1 = val
                    best1_child = to
                elif val > best2:
                    best2 = val

            answer = max(answer, dp[v])

            cur = base

            if best1:
                cur += best1 - 1
            if best2:
                cur += best2 - 1

            answer = max(answer, cur)

        anss.append(str(answer))

    sys.stdout.write("\n".join(anss))

if __name__ == "__main__":
    solve()
```再帰の深さの問題を回避するために、ツリーは繰り返しルート化されます。 まで$3 \cdot 10^5$頂点、再帰的 DFS は Python では危険です。`base`スパインを継続する子がない場合の現在の頂点の寄与を表します。 非ルート頂点の場合、1 つのエッジが親方向用にすでに予約されているため、残りの入射エッジのみがリーフになることができます。`dp[v]`背骨が入る最高の毛虫を保管します`v`上から始まり、1 人の子供を通して継続する場合があります。 子を介して拡張すると、潜在的なリーフ エッジが 1 つ消費されるため、遷移では`base - 1 + dp[child]`。 

全体的な答えは、背骨が頂点を通過して 2 つの子方向に続く毛虫も考慮する必要があります。 これは標準的な木の直径を組み合わせるステップに似ているため、2 つの最大の子の DP 値を保持します。

    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())

        g = [[] for _ in range(n)]

        for _ in range(n - 1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            g[u].append(v)
            g[v].append(u)

        parent = [-1] * n
        order = [0]
        parent[0] = 0

        for v in order:
            for to in g[v]:
                if parent[to] == -1:
                    parent[to] = v
                    order.append(to)

        dp = [0] * n
        ans = 0

        for v in reversed(order):
            deg = len(g[v])

            base = deg + 1 if v == 0 else deg

            best1 = best2 = 0
            dp[v] = base

            if best1:
                cur += best1 - 1
            if best2:
                cur += best2 - 1

            ans = max(ans, cur)

        out.append(str(ans))

    return "\n".join(out)
