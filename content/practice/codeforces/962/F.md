 ## 解決策
 ## 問題の理解

 無向の単純なグラフが与えられ、どのエッジが単一の単純なサイクルに「排他的」であるかを特定するように求められます。 言い換えれば、各エッジについて、このエッジを含むグラフ全体にちょうど 1 つのサイクルが存在するかどうかを知りたいのです。サイクルは単純であり、頂点を繰り返しません。 

このタスクを言い換えると、グラフ内のすべてのエッジが 0、1、または多数の単純なサイクルに参加しており、そのようなサイクルに正確に 1 つ属するエッジを正確に選択する必要があるということです。 

この制約では、最大 100,000 個の頂点とエッジが許可されるため、サイクルを明示的に列挙するアプローチは即座に除外されます。 グラフ内の単純なサイクルの数は、最悪の場合指数関数的に増加する可能性があるため、「すべてのサイクルを見つけてエッジの参加をカウントする」ことを試みる方法は、中程度の入力にさえ到達するずっと前に失敗します。 サイクルの列挙を完全に回避するエッジの構造特性評価が必要です。 

グラフが単一の単純なサイクルである場合、微妙なエッジ ケースが発生します。 その状況では、すべてのエッジが答えに含まれる必要があります。 単純な DFS サイクル検出では、エッジを何らかのサイクルの一部としてマークする可能性がありますが、エッジを共有する複数の別個のサイクルがあるのか​​、それとも 1 つのみのサイクルがあるのか​​は区別されません。 もう 1 つの注意が必要な状況は、サイクルが重なっている場合です。 たとえば、パスを共有する 2 つのサイクルは複数のサイクルに属するエッジを作成します。これらのエッジは、DFS の意味ではサイクルの一部であっても除外する必要があります。 

重要な問題は、「正確に 1 つの単純なサイクルに属する」ということが、単一サイクル検出実行の純粋にローカルな特性ではないことです。 それは同じエッジを横断する独立したサイクルの数に依存します。これは、横断履歴ではなくグラフ構造の観点から推論することを示唆しています。 

## アプローチ

 強引なアイデアは、すべての単純なサイクルを列挙し、エッジごとに、そのエッジに含まれる個別のサイクルの数を数えるというものです。 これは、すべての頂点から DFS を開始し、訪問したセットを追跡し、頂点を再訪問したときにサイクルを記録すると想像できます。 枝刈りを行っても、密なグラフ内の単純サイクルの数は指数関数的に増加し、100,000 のエッジを持つ疎なグラフでもこれは実行不可能になります。 各サイクル検出パスが大きく分岐し、多くの部分的な状態を再訪するため、操作数は爆発的に増加します。 

重要な洞察は、サイクル自体から移行し、代わりにサイクルが明示的に列挙されず暗黙的に表現される分解を使用することです。 関連する構造は、グラフの二重連結分解です。 すべてのエッジは、正確に 1 つの二重接続コンポーネント (エッジ二重接続コンポーネントとも呼ばれます) に属し、そのような各コンポーネント内にサイクルが「含まれています」。 

古典的な事実として、エッジは少なくとも 1 つのサイクルを含む二重接続コンポーネント、つまり DFS に少なくとも 1 つのバックエッジを持つコンポーネント、またはサイズが 1 より大きく、ツリー エッジ ブリッジ構造ではないコンポーネントに属する場合に限り、エッジは少なくとも 1 つの単純なサイクル上に存在します。 ただし、条件はより厳密です。正確に 1 つの単純なサイクルに属するエッジが必要です。 これは、構造が「多循環」ではなく「循環状」である二重接続コンポーネント内のサイクルの一部であるエッジに正確に対応していることがわかります。 

二重接続コンポーネントでは、エッジの数が頂点の数と等しい場合、そのコンポーネントには、アーティキュレーション ポイントのみを介して接続されている可能性のある木を含む単純なサイクルが 1 つだけ含まれますが、二重接続コンポーネントにはアーティキュレーション ポイントがないため、そのようなコンポーネントはまさに単純なサイクル グラフになります。 したがって、そのようなコンポーネント内のすべてのエッジは、正確に 1 つの単純なサイクル、つまりコンポーネントにまたがる固有のサイクルに属します。

コンポーネントに頂点よりも多くのエッジがある場合、少なくとも 2 つの独立したサイクルがあり、サイクルに参加するすべてのエッジは、これらのサイクルの組み合わせによって形成される複数の単純なサイクル内にあるため、そのようなコンポーネント内のエッジは適格ではありません。 コンポーネントがツリー (エッジ = 頂点 - 1) の場合、サイクルはまったく含まれません。 

したがって、問題は、二重接続コンポーネントを見つけて、エッジ数が頂点数と等しいコンポーネントを選択することに帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースサイクル列挙 | 指数 | 指数 | 遅すぎる |
 | 二重接続コンポーネント (Tarjan) | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 DFS ベースの Tarjan アルゴリズムを使用して、二重接続コンポーネントを計算します。 

1. すべての頂点に対して DFS を実行し、検出時間と低リンク値を維持します。 ローリンク値は、DFS ツリー内で最も早く到達可能な祖先をキャプチャし、これによりバックエッジの検出が可能になります。 
2. 現在 DFS 再帰スタック内にあるエッジのスタックを維持します。 サブツリーが完全な二重接続コンポーネント境界を形成していることを識別するたびに (low[v] >= disc[u] の場合)、スタックからエッジをポップして 1 つのコンポーネントを形成します。 
3. ポップされたエッジの各グループは、1 つの二重接続コンポーネントを定義します。 頂点とそれに属するエッジの両方を収集します。 
4. 各コンポーネントについて、そのコンポーネントに含まれる個別の頂点とエッジの数を数えます。 
5. コンポーネントがedge_count == vertex_countを満たす場合、それは単一の単純なサイクルでなければなりません。 このコンポーネント内のすべてのエッジを有効な回答としてマークします。 
6. すべてのコンポーネントを処理した後、すべてのマークされたエッジをインデックスの昇順で出力します。 

重要な推論ステップは、Tarjan 分解によってすべてのエッジが 1 つの二重接続コンポーネントに確実に属するため、サイクルを二重にカウントしたり、間違って分割したりすることがないことです。 

### なぜ効果があるのか

 無向グラフでは、すべての単純なサイクルが単一の二重接続コンポーネント内に完全に含まれています。 このようなコンポーネント内では、サイクルが制御された方法でオーバーラップします。 条件edge_count == vertex_countは、コンポーネントに独立したサイクルが1つだけあるという特殊なケースを特徴付けます。 その場合、すべてのエッジはその単一サイクル上にあり、複数の独立したサイクルを導入する方法でエッジを再利用することなく、2 番目の個別の単純なサイクルを形成する方法はありません。 したがって、そのようなコンポーネント内のすべてのエッジは、正確に 1 つの単純なサイクルに属します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n, m = map(int, input().split())
g = [[] for _ in range(n)]
edges = []

for i in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append((v, i))
    g[v].append((u, i))
    edges.append((u, v))

tin = [-1] * n
low = [-1] * n
timer = 0

stack = []
used_edge = [False] * m
in_comp_edge = []
ans = set()

def dfs(u, peid):
    global timer
    tin[u] = low[u] = timer
    timer += 1

    for v, eid in g[u]:
        if eid == peid:
            continue
        if tin[v] == -1:
            stack.append(eid)
            dfs(v, eid)
            low[u] = min(low[u], low[v])

            if low[v] >= tin[u]:
                comp_edges = []
                comp_vertices = set()
                while True:
                    e = stack.pop()
                    comp_edges.append(e)
                    a, b = edges[e]
                    comp_vertices.add(a)
                    comp_vertices.add(b)
                    if e == eid:
                        break
                if len(comp_edges) > 0:
                    if len(comp_edges) == len(comp_vertices):
                        for x in comp_edges:
                            ans.add(x)
        else:
            if tin[v] < tin[u]:
                stack.append(eid)
            low[u] = min(low[u], tin[v])

for i in range(n):
    if tin[i] == -1:
        dfs(i, -1)

print(len(ans))
print(*sorted(x + 1 for x in ans))
```DFS は、各頂点に検出時間を割り当て、ローリンク値を計算して、サブツリーが閉じたコンポーネントを形成するタイミングを検出します。 エッジ スタックにより、二重接続コンポーネントが識別されると、そのすべてのエッジが正確に 1 回収集されることが保証されます。 

実装の重要な点は、バックエッジが正しくプッシュされ、コンポーネントが関節境界で正確にポップされるようにすることです。 エッジ数と頂点数の間の同等性チェックは、純粋なサイクル コンポーネントを分離するフィルターです。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n, m = map(int, sys.stdin.readline().split())
    g = [[] for _ in range(n)]
    edges = []

    for i in range(m):
        u, v = map(int, sys.stdin.readline().split())
        u -= 1
        v -= 1
        g[u].append((v, i))
        g[v].append((u, i))
        edges.append((u, v))

    tin = [-1] * n
    low = [-1] * n
    timer = 0
    stack = []
    ans = set()

    def dfs(u, pe):
        nonlocal timer
        tin[u] = low[u] = timer
        timer += 1
        for v, eid in g[u]:
            if eid == pe:
                continue
            if tin[v] == -1:
                stack.append(eid)
                dfs(v, eid)
                low[u] = min(low[u], low[v])
                if low[v] >= tin[u]:
                    comp_edges = []
                    comp_vertices = set()
                    while True:
                        e = stack.pop()
                        comp_edges.append(e)
                        a, b = edges[e]
                        comp_vertices.add(a)
                        comp_vertices.add(b)
                        if e == eid:
                            break
                    if len(comp_edges) == len(comp_vertices):
                        for x in comp_edges:
                            ans.add(x)
            elif tin[v] < tin[u]:
                stack.append(eid)
                low[u] = min(low[u], tin[v])

    for i in range(n):
        if tin[i] == -1:
            dfs(i, -1)

    out = sorted(x + 1 for x in ans)
    return str(len(out)) + "\n" + " ".join(map(str, out)) if out else "0\n"

 ## 特殊なケース

 単一サイクルのグラフは、意図したポジティブなケースを示しています。 三角形に対してアルゴリズムを実行すると、同じ数の頂点とエッジを持つ二重接続コンポーネントが 1 つだけ生成されるため、すべてのエッジが正しく選択されます。 

単一のエッジ入力は、1 つの頂点セット サイズ 2、エッジ数 1 を持つ自明な二重連結コンポーネントを形成するため、等価条件が満たされず、エッジは選択されません。 DFS はサイクル コンポーネントを構築しないため、答えは空です。 

2 つの互いに素なサイクルで構成されるグラフは、2 つの独立した二重連結成分を生成し、それぞれが別々に等式条件を満たします。 このアルゴリズムは両方のコンポーネントのすべてのエッジをマークし、コンポーネント間の独立性を確認します。 

ぶら下がりエッジのあるサイクルは、フィルタリング動作を示します。 三角形の部分は有効なコンポーネントを形成しますが、ぶら下がりエッジはエッジと頂点の比率が一致しないツリー状のコンポーネントを形成するため、正しく除外されます。
