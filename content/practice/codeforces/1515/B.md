 ## 解決策
 ## 問題の理解

 同じ直角二等辺三角形のパズルのピースのセットが与えられました。 各三角形には 2 つの等しい辺と直角があります。 フェニックスはまさに使いたい$n$これらの三角形を組み合わせて、重なりや穴のない完全な正方形を形成します。 彼はピースを自由に回転したり動かしたりすることができます。 タスクは、テスト ケースごとに、そのような正方形の形成が可能かどうかを判断することです。 

入力は複数のテスト ケースを提供し、それぞれが 1 つの整数で構成されます。$n$、次のように大きくすることができます$10^9$。 出力は単純に、正方形を形成できる場合は「YES」、そうでない場合は「NO」です。 

制約$n \le 10^9$すべての部分を反復したり、すべての幾何学的配置を試したりするソリューションは非現実的であることがすぐにわかります。 数式または算術チェックを使用して、テスト ケースごとに一定時間で答えを計算するアプローチが必要です。 

重要な点は、すべての整数が使えるわけではないということです。$n$正方形を形成することができます。 例えば、$n = 2$2 つの三角形が斜辺を結ぶと正方形を形成できるため、この関数は機能します。$n = 4$4 つの三角形でより大きな正方形を形成できるため、これも機能します。 しかし、$n = 6$失敗します。6 つの同一の直角二等辺三角形をどのように配置しても、完全に正方形を形成することはできません。 不注意な解決策では、任意の偶数が機能すると仮定する可能性がありますが、ピースの配置には、辺 1 の正方形を形成する 2 の倍数か、より大きなサイズの正方形を形成する 4 の倍数のいずれかが必要です。 

## アプローチ

 ブルートフォース手法では、三角形を 1 つずつ配置し、正方形が形成されるかどうかを確認しようとします。 概念的には、すべての回転と位置をシミュレートしてみることができます。 これは原理的には正しいですが、計算上不可能です。$n \sim 10^9$、アレンジメントの数は階乗的に増加するためです。 

重要な洞察は、三角形の合計面積の観点から推論することです。 それぞれの三角形の面積は、$0.5$(ユニット脚を想定)。 もし$n$三角形が正方形を形成する場合、正方形の面積は$n \times 0.5 = n/2$。 したがって、正方形の辺は次のようになります。$\sqrt{n/2}$。 整数座標の正方形の場合、$\sqrt{n/2}$は、三角形から構成される整数長の辺の合計として表現できる有理数でなければなりません。 

幾何学的な推論から、次の場合にのみ正方形を構築できることがわかります。$n$次のように表現できます$2k^2$または$4k^2$、 どこ$k$は整数です。 最初の形式は斜辺に沿った 2 つの三角形で作られた正方形に対応し、2 番目の形式は 4 つの三角形で作られた正方形に対応します。$k \times k$正方形のグリッド。 

この観察により、問題は整数演算を使用して 2 つの条件をチェックすることになります。$n$は 2 で割り切れ、$n/2$は完全な正方形であるか、$n$は 4 で割り切れ、$n/4$は完全な正方形です。 どちらのチェックも$O(1)$テストケースごとに。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | 最適 | テスト ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、整数を読み取ります。$n$三角形の数を表します。 
2. もし$n$2で割り切れる場合は計算してください$n/2$。 どうかを確認してください$n/2$は、整数の平方根を取得して二乗し直すと完全平方になります。 
3. もし$n/2$が完全な正方形である場合は、「YES」と出力して次のテスト ケースに進みます。 これは、斜辺に沿った正確に 2 つの三角形から形成される正方形に対応します。 
4. それ以外の場合は、次のことを確認してください。$n$は 4 で割り切れます。$n/4$そしてそれが完全な正方形であるかどうかを確認します。 
5. もし$n/4$完全な正方形の場合は、「YES」と出力します。 これは、正方形のグリッドに配置された 4 つの三角形から構成される正方形に対応します。 
6. どちらのチェックにも合格しない場合は、「NO」と出力します。 

機能する理由: 不変条件は、直角二等辺三角形から形成される正方形が基本単位正方形を形成するために 2 つまたは 4 つの三角形を必要とし、より大きな正方形はこれらの基本単位の整数倍であるということです。 したがって、面積引数は正確さを保証し、整数平方チェックはピースがギャップや重なりなく完全に整列することを保証します。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    ans = "NO"
    if n % 2 == 0:
        half = n // 2
        if int(math.isqrt(half)) ** 2 == half:
            ans = "YES"
    if ans == "NO" and n % 4 == 0:
        quarter = n // 4
        if int(math.isqrt(quarter)) ** 2 == quarter:
            ans = "YES"
    print(ans)
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`まで処理する$10^4$テストケース。 の`math.isqrt`この関数は、浮動小数点エラーなしで整数の平方根を正確に計算し、それを二乗し直すことで正確な完全二乗検出が保証されます。 両方にチェックを入れる`n/2`そして`n/4`両方の幾何学的配置をカバーします。 チェックの順序により、4 三角形のケースを試行する前に 2 三角形のケースが確実に検出されます。 

## 実用的な例

 **例 1: n = 2**

 | n | n%2 | n/2 | sqrt(n/2)^2 | 結果 |
 | --- | --- | --- | --- | --- |
 | 2 | 0 | 1 | 1 | はい |

 このアルゴリズムは、2 つの三角形が正方形を形成できることを正確に識別します。 

**例 2: n = 6**

 | n | n%2 | n/2 | sqrt(n/2)^2 | n%4 | n/4 | sqrt(n/4)^2 | 結果 |
 | --- | --- | --- | --- | --- | --- | --- | --- |
 | 6 | 0 | 3 | 1 | 2 | - | - | いいえ |

 どちらでもない`n/2`または`n/4`は完全な正方形なので、答えは NO です。 

これらのトレースは、アルゴリズムが n = 6 のような不可能なケースを区別し、可能な最小の平方を検出していることを確認します。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | テスト ケースごとに O(1) | 各テスト ケースは、一定数の算術演算と整数の平方根計算を実行します。 
| スペース | お(1) | テスト ケースごとに少数の整変数のみが使用されます。 

と$t \le 10^4$、合計操作は 2 秒の制限時間内に十分収まります。

import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    
    t = int(input())
    for _ in range(t):
        n = int(input())
        ans = "NO"
        if n % 2 == 0:
            half = n // 2

                ans = "YES"
        if ans == "NO" and n % 4 == 0:
            quarter = n // 4
            if int(math.isqrt(quarter)) ** 2 == quarter:
                ans = "YES"
        print(ans)
    return out.getvalue().strip()

 ## 特殊なケース

 n = 1 の場合、アルゴリズムは 2 と 4 で割り切れるかどうかをチェックします。どちらも失敗するため、NO が出力されます。 これは直観と一致します。単一の三角形では正方形を形成することはできません。 n = 8 の場合、アルゴリズムは最初に n/2 = 4 (完全な正方形) をチェックするため、YES が出力されます。 これは、2 三角形と 4 三角形の両方の配置を確認することが重要であることを示しています。 2 × 10^9 のような大きな n の場合、Python の整数には制限がなく、アルゴリズムはオーバーフローすることなくテスト ケースごとに O(1) で動作します。`math.isqrt`大きな整数を効率的に処理します。
