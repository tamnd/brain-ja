 ## 解決策
 ## 問題の理解

 私たちはプレイヤーの循環システムを与えられており、各プレイヤーは実際の価値のある金額を保持しています。 プレイヤーは固定サイクルで配置され、1 ラウンド中に各プレイヤーが現在の資金の半分を時計回りの隣のプレイヤーに同時に転送し、最後のプレイヤーが最初のプレイヤーに資金の半分を送り返します。 これは、各ラウンドがバランスのベクトルの決定論的な線形変換であることを意味します。 

タスクは、整数残高の初期配列から開始して、非常に多数の同一ラウンド、具体的には 20,221,204 回の反復後のこのシステムの状態を計算することです。 各プレイヤーの最終的なバランスが高精度の実数値として出力されます。 

n が 100,000 までという制約は、ラウンドにわたるシミュレーションやラウンドごとの O(n) プロセスを R 回繰り返すことは完全に不可能であることを意味します。 単一ラウンドでも O(n) であるため、直接シミュレーションにはおよそ 2×10^13 の演算が必要になりますが、これは実行可能な限界をはるかに超えています。 

微妙な問題は、演算に実数と繰り返しの半分が含まれるため、数値の安定性が重要になることです。 ただし、本当の問題は浮動小数点精度ではなく、何度も適用される変換の構造です。 

一般的な失敗モードは、数ラウンドだけをシミュレートしようとしたり、正当化せずに周期性などの単純なパターンを探したりすることです。 たとえば、n = 2 の場合、システムはすぐに安定しますが、n が大きくなると、その背後にある線形演算子を理解しない限り、動作は短いサイクルで自明に周期的ではなくなります。 

もう 1 つのエッジ ケースは n = 2 です。この場合、転送は対称になり、1 ラウンド後にすぐに固定点に落ち着く可能性があります。これは、「常に大きく変化する」と仮定したアプローチを誤解させる可能性があります。 

## アプローチ

 各ラウンドでは、同じ線形変換が残高のベクトルに適用されます。 現在の状態を配列 a として表すと、1 ラウンドの後、各ポジションは自分から半分を受け取り、(循環的な意味で) 左隣から半分を受け取ります。これは、各プレーヤーが半分を保持し、半分を与える一方、前のプレーヤーから半分を受け取るためです。 

より正確には、1 ラウンドの後、各位置は 2 つの寄与の合計になります。つまり、その位置自体の前の値の半分と、反時計回りの隣の位置の前の値の半分になります。 これはサイクル上の線形反復であり、プロセス全体が同じ線形演算子を繰り返し適用していることを意味します。 

ブルート フォースのアプローチは簡単です。プロセスをラウンドごとにシミュレートします。 各ラウンドで配列を 1 回スキャンし、次の状態を計算します。 これにはラウンドあたり O(n) のコストがかかり、R = 20,221,204 ラウンドの場合、合計の複雑さは O(nR) となり、最悪の場合でも 10^12 回の演算のオーダーとなり、限界をはるかに超えています。 

重要な観察は、これが次元 n のベクトル空間上の線形変換であるということです。 繰り返し適用することは、線形演算子の累乗に相当します。 直接べき乗は行列のべき乗を示唆しますが、行列は循環バンド行列であり、より構造化された形式になります。 より深い洞察は、すべてのラウンドがサーキュラントのような演算子による乗算と同等であるということです。これは、システムがフーリエ空間で独立して進化することを意味します。 各フーリエ モードは、固定されたスカラー係数によって独立して発展します。 

つまり、R ステップをシミュレートする代わりに、R アプリケーション後に各周波数成分がどのようにスケールされるかを分析します。 分解されると、各成分はそのモードの固有値によって決定される比を持つ等比数列になります。 R の丸めの後、各モードは単純に固有値 ^R で乗算されます。

これにより、問題は離散フーリエ変換の計算、指数関数的スケーリングの適用、配列の再構築に軽減されます。 実数に対する完全な FFT は理論的には O(n log n) ですが、この問題では、変換が既知の固有値を持つ単純なシフトと平均の演算子であることがわかれば、完全な複雑な機構は必要ありません。 

実際、演算子は new[i] = (a[i] + a[i-1]) / 2 です。この畳み込みカーネルの固有値は λ_k = (1 + ω^k) / 2 です。ここで、ω は 1 の原始 n 乗根です。 したがって、R ステップの後、各周波数成分は λ_k^R で乗算されます。 最終的な配列は逆変換によって取得されます。 

これは、n 要素にわたる R 回の繰り返しパスを 1 つの変換と 1 つの逆変換で置き換えるので、最適です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(nR) | O(n) | 遅すぎる |
 | 周波数 / FFT ベースのべき乗 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 更新ルールを、各位置がサイクル内のそれ自体の半分と前の要素の半分を受け取る畳み込みとして解釈します。 この再定式化は線形構造を明らかにするため、非常に重要です。 
2. 同じ線形畳み込みを繰り返し適用することは、周波数領域での乗算の繰り返しに相当することを認識します。 このステップでは、問題を時間発展からスペクトル発展に移します。 
3. 初期配列の離散フーリエ変換を計算します。 各インデックスは、プレーヤーの位置ではなく、周波数モードの振幅を表すようになりました。 
4. 各周波数成分 k について、その固有値 λ_k = (1 + ω^k) / 2 を計算します。ここで、ω は 1 の原始 n 乗根です。 この値は、1 ラウンド後にそのモードがどのように変化するかをキャプチャします。 
5. 各 λ_k を R = 20,221,204 乗し、対応するフーリエ係数にこの値を乗算します。 これにより、R 回の繰り返し変換がモードごとに 1 つのべき乗に置き換えられます。 
6. 逆フーリエ変換を適用して、元の座標系で最終的な配列を再構成します。 

ここでべき乗がきれいに機能する理由は、各フーリエ モードが独立して進化するためです。 オペレーターを繰り返し適用する際にモードが他のモードと混合することはありません。そのため、変換の力はこの基準で斜めに作用します。 

### なぜ効果があるのか

 変換は、循環畳み込みカーネルによって定義されるℝⁿ 上の線形演算子 T です。 巡回演算子はフーリエ基底によって対角化されます。これは、T が各基底ベクトル上で単純なスカラー倍算として機能する基底が存在することを意味します。 その基底で表現されると、T を繰り返し適用することは、各スカラー固有値をべき乗することと同じになります。 フーリエ変換は座標をまさにこの固有基底に変更するため、システムの発展は周波数ごとに独立したスカラーべき乗になります。 逆変換を介して元の基底を再構築すると正確さが維持されるため、最終ベクトルは初期状態に正確に T^R が適用されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import cmath

def fft(a, invert):
    n = len(a)
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            a[i], a[j] = a[j], a[i]

    length = 2
    while length <= n:
        ang = 2 * cmath.pi / length * (-1 if invert else 1)
        wlen = complex(cmath.cos(ang), cmath.sin(ang))
        i = 0
        while i < n:
            w = 1
            for j in range(length // 2):
                u = a[i + j]
                v = a[i + j + length // 2] * w
                a[i + j] = u + v
                a[i + j + length // 2] = u - v
                w *= wlen
            i += length
        length <<= 1

    if invert:
        for i in range(n):
            a[i] /= n

def solve():
    n = int(input())
    a = list(map(float, input().split()))
    R = 20221204

    fa = list(map(complex, a))
    fft(fa, False)

    nroot = cmath.exp(2j * cmath.pi / n)

    for k in range(n):
        omega_k = nroot ** k
        lam = (1 + omega_k) / 2
        fa[k] *= lam ** R

    fft(fa, True)

    print(*[fa[i].real for i in range(n)])

if __name__ == "__main__":
    solve()
```コードは、配列を周波数空間に変換するための標準的な反復 FFT を実装することから始まります。 更新ルールはサイクルにわたる畳み込みであり、FFT は循環畳み込みを対角化するため、変換が必要です。 

変換後、各周波数成分は、R 乗された対応する固有値で乗算されます。`(1 + omega_k) / 2`各プレイヤーが自分の値の半分を保持し、サイクル内の前のプレイヤーから半分を受け取るという事実をエンコードします。 

最後に、逆 FFT によって最終構成が再構築されます。 数値誤差により無視すべき小さな虚数成分が生じるため、実数部が抽出されます。 

実装の微妙な詳細は、1 の根に複素指数を使用することです。 もう 1 つは、複素数のべき乗では浮動誤差が蓄積される可能性がありますが、必要な精度により安全に許容されます。

 ## 特殊なケース

 n = 2 の場合、システムはスワップ下で対称になり、変換は 2 つの値の平均化に陥ります。 この場合にアルゴリズムを実行すると、固有値 1 の定数モードと固有値 0 の交互モードの 2 つのフーリエ モードが生成されます。交互モードは最初のべき乗の直後に消滅し、予想される安定化に一致する定数ベクトルを残します。 

一様な配列の場合、すべての値は同一であるため、畳み込みによって状態はまったく変化しません。 フーリエ用語では、ゼロ周波数モードのみがアクティブであり、その固有値は正確に 1 であるため、累乗を繰り返すとベクトルが正確に保存されます。 

[x, 0, 0, ..., 0] のような疎な初期ベクトルの場合、アルゴリズムはゼロ以外の周波数成分を通じてすべての位置に質量を分散します。 各成分は独立して進化し、多くの反復の後、高周波成分は |(1+ω^k)/2| に応じて低周波成分に比べて縮小し、繰り返しの局所平均化と一致する滑らかな分布を生成します。
