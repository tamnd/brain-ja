 ## 問題の理解

 からの数値の順列が与えられます。$1$に$N$ただし、順列自体の代わりに、固定配列を含む非常に特殊な構造特性を持つそのような順列がいくつあるかを数えるように求められます。$X$長さの$M$。 

重要なオブジェクトは、「辞書編集上の最小の長さの部分列」です。$M$順列の「」。部分列は、順序を変えずに要素を削除することによって形成されます。長さのすべての部分列の中で$M$、辞書編集的に最小のものを考慮します。つまり、シーケンスを左から右に比較し、異なる最初の位置がより小さい値を持つことを優先します。 

条件は、この辞書編集上の最小のサブシーケンスが指定されたシーケンスと正確に等しい必要があることです。$X$。 の順列が何回あるかを数えるように求められます。$1 \ldots N$この条件をモジュロで満たす$998244353$。 

制約は次のとおりです$N = 250000$、二次関数や偶数関数は即座に除外されます。$O(N \log^2 N)$重い定数を使用します。 解決策は線形または線形演算に近いものでなければなりません。 

明らかではない問題は、「辞書編集上の最小の部分列」が局所的な条件ではないことです。 素朴な解釈では、次のことだけを保証する必要があると思われます。$X$がサブシーケンスとして表示されますが、それはあまりにも弱すぎます。 前後の要素の構造は、より小さなサブシーケンスを形成できるかどうかに影響します。 

いくつかの特殊なケースがこれを強調しています。

重要な点は、貪欲な部分列選択によって引き起こされるグローバルな順序付けによって順列が制限されていることです。 

## アプローチ

重要な変化は、辞書編集上の最小の部分列がどのように形成されるかを再解釈することです。 このようなサブシーケンスを貪欲に構築する場合、各ステップで、長さのサブシーケンスを完成できる最小の値を選択します。$M$。 これは、実現可能性の制約の下で利用可能な最小の要素を選択するのと同様に動作します。

重要な構造的洞察は、要素の相対的な順序が各接頭辞よりも小さいことです。$X$実現可能性を決定します。 以下の要素$X_i$辞書編集的に小さい部分列がそれらを利用できるような位置に出現しないように制御する必要があります。

 ## アルゴリズムのチュートリアル

 このプロセスを、最小値から順に順列を構築するものとして再解釈し、貪欲なサブシーケンス選択により要素を正確に選択するように強制します。$X$。 

### ステップ

 1. すべての数値を次から並べ替えます。$1$に$N$自然に、昇順に処理します。 値ごとに、それが以下の一部であるかどうかを決定します。$X$かどうか、また強制条件と比較してどこに配置できるか。 
2. どの値が属するかを示すマーカー配列を構築します。$X$。 これにより、数直線が次のように分割されます。$M$強制チェックポイント。 
3. からの値を処理します。$1$に$N$昇順で、非の数のカウンターを維持します。$X$これまでのところ、要素は「自由な位置」に配置されてきました。 これらの自由な位置は、辞書編集上の最小サブシーケンスに直接影響を与えない要素を表します。 
4. ある値に達したとき$v = X_i$、貪欲なサブシーケンス構築で選択されることを確認する必要があります。$X_i$で$i$- 番目のステップ。 これにより、未使用のすべての値が次の値より小さいという制約が課されます。$X_i$よりも優れたサブシーケンス接頭辞を形成できてはなりません$X_1 \ldots X_i$。 
5. 連続する要素間$X$、非の数を数えてください。$X$値はその値の範囲内にあります。 これらは残りのスロット間で自由に配置でき、階乗的な選択に貢献します。 
6. 各独立区間内の順列は自由であるため、モジュール階乗を使用してすべての区間の寄与を乗算します。 

### なぜ効果があるのか

 辞書編集上最小のサブシーケンスは、完了を妨げない最小値を常に選択する貪欲な選択によって決定されます。 つまり、各段階で$i$、接頭辞$X_1 \ldots X_i$すべてのサブシーケンスの中で可能な限り最良のプレフィックスのままでなければなりません。 あまりにも早い段階で、より小さい未使用の値が出現すると、このプレフィックスの一部が置き換えられます。 

これにより、値の間隔に対して厳密な順序制約が作成されます。要素は次の値よりも小さいです。$X_i$前のセグメントで使い果たされる必要があります。そうしないと、貪欲な選択が妨げられてしまいます。 これらの制約が適用されると、残りの要素は区間内で独立して動作し、階乗の積が生成されます。 この独立性により、カウントがきれいに因数分解されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    N, M = map(int, input().split())
    X = list(map(int, input().split()))

    in_x = [False] * (N + 1)
    for v in X:
        in_x[v] = True

    fact = [1] * (N + 1)
    for i in range(1, N + 1):
        fact[i] = fact[i - 1] * i % MOD

    # count free elements between consecutive X values in value space
    X_sorted = sorted(X)

    total = 1
    prev = 0
    used = 0

    for v in X_sorted:
        gap = 0
        for i in range(prev + 1, v):
            if not in_x[i]:
                gap += 1

        total = total * fact[gap] % MOD
        prev = v

    # elements larger than last X
    gap = 0
    for i in range(prev + 1, N + 1):
        if not in_x[i]:
            gap += 1

    total = total * fact[gap] % MOD

    print(total)

if __name__ == "__main__":
    solve()
```実装ではまず、どの値がコンポーネントの一部として固定されているかを特定します。$X$。 階乗を事前計算して、独立した値の間隔内の順列をカウントします。 次に、値の範囲をスキャンし、非すべての値をグループ化します。$X$連続する要素間の要素$X$それらのグループサイズの階乗を乗算した値。 

微妙な点は、インデックス空間ではなく値空間で動作することです。 制約は、位置ではなく値の順序に依存する辞書編集上の最小のサブシーケンスを通じて定義されるため、これは不可欠です。

 ## 特殊なケース

 重要なエッジケースの 1 つは次のような場合です。$X$すでにソートされたシーケンスです$1,2,\dots,M$。 この場合、プレフィックスより小さい値は強制位置の外側に存在できないため、残りの要素はすべて単一の制約のない領域に存在する必要があります。 アルゴリズムは、すべての非$X$値を 1 つの間隔にまとめ、制約が崩れた場合でも階乗カウントにより正しい単一の構成が生成されます。 

もう 1 つのケースは、すべての小さな値が後から現れる場合です。$X$、 例えば$X = [N-M+1, \dots, N]$。 ここでは、ほとんどすべての数値が早い間隔にあります。 このアルゴリズムは、大きな階乗ブロックを正しく乗算します。これは、これらの初期の自由値が、大きな強制要素の貪欲な選択に影響を与えることなく任意に並べ替えられることを反映しています。 

退化ケースは次の場合に発生します。$M = N$。 次に、すべての値が強制され、すべての間隔のサイズが 0 になり、積は 1 のままとなり、以下と一致する単一の順列と一致します。$X$。
