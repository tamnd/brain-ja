 乱雑な状態${0,1,\dots,n}$はまさにブール格子内のアンチチェーンです: ファミリー$\mathcal C$2 つの異なるメンバーが満たさないようなサブセットの$\alpha \subset \beta$。 サイズベクトル$(M_0,M_1,\dots,M_n)$のメンバーの数を記録します$\mathcal C$各レベルにあります$\binom{[n]}{t}$。 

### パート (a): 特性評価

 しましょう$\mathcal C_t \subseteq \binom{[n]}{t}$～のサブファミリーになる$t$-散らかった場所に設置し、$|\mathcal C_t| = M_t$。 散らかった状態の決定的な条件は、すべての人にとって次のようなものです。$s<t$、セットされていません$\mathcal C_s$のいずれかのセットに含まれます$\mathcal C_t$。 

同様に、各ペアについて$s<t$、家族は満足します$$\mathcal C_s \cap \nabla(\mathcal C_t) = \varnothing,$$どこ$\nabla(\mathcal C_t)$は上向きの閉鎖を意味します$\mathcal C_t$。 

したがって、サイズ ベクトルは、互いに素なファミリが存在する場合にのみ実行可能です。$$\mathcal C_t \subseteq \binom{[n]}{t}, \quad |\mathcal C_t| = M_t,$$のメンバーがいないように$\mathcal C_s$のいずれかのメンバーのサブセットです$\mathcal C_t$のために$s<t$。 

この条件は正確です。そのような選択はいずれも乱雑さを生成し、すべての乱雑さはそのような分解をもたらします。 

これで特性評価は完了です。 

∎

 ### パート (b): の列挙$n=4$のレベルを書きます$\binom{[4]}{t}$として$$|\binom{[4]}{0}|=1,\quad |\binom{[4]}{1}|=4,\quad |\binom{[4]}{2}|=6,\quad |\binom{[4]}{3}|=4,\quad |\binom{[4]}{4}|=1.$$実行可能なサイズのベクトルはアンチチェーンに対応するため、選択されたセットに別の選択されたセットが含まれることはありません。 

＃＃＃＃ レベル$0$空のセットはすべての空でないセットに含まれるため、$M_0=1$それから他のすべて$M_t=0$。 これによりベクトルが得られます$$(1,0,0,0,0).$$これから仮定します$M_0=0$。 

#### 純粋レベルのアンチチェーン

 単一レベルはそれ自体がアンチチェーンであるため、次のことが可能です。$$(0,1,0,0,0),\ (0,2,0,0,0),\ (0,3,0,0,0),\ (0,4,0,0,0),$$

$$(0,0,1,0,0),\dots,(0,0,6,0,0),$$

$$(0,0,0,1,0),\dots,(0,0,0,4,0),$$

$$(0,0,0,0,1).$$固定カーディナリティ内では包含が発生しないため、これらは単一レベル内の任意のサブセットに対応します。 

#### ミキシングレベル$1$そして$2$あ$2$-set には 2 つだけが含まれます$1$-セット。 家族に含まれている場合$M_2$明確な$2$-sets、それらの共用体には少なくともサイズがあります$M_2+1$(スター構成によって実現)、最大でも$2M_2$(サイズ制限までに連続していない場合)$4$）。 

この共用体の各要素は、対応するシングルトンを含めることを禁止します。 

したがって、可能なシングルトンの最大数は最大でも$$M_1 \le 4 - (M_2+1) = 3 - M_2.$$この限界はすべての実現可能なものに対して達成可能です$M_2$の星を取ることで$2$-セット。 したがって、レベル間の混合レベル制約は$1$そして$2$まさに$$0 \le M_2 \le 3,\quad 0 \le M_1 \le 3 - M_2.$$#### ミキシングレベル$2$そして$3$補完の下での対称性によって$[4]$、$3$-set には補完要素が 1 つだけ含まれます$1$-set は前のケースと二重に対応します。 あ$3$-セットには3つが含まれます$2$-subsets なので、対称引数は次のようになります。$$0 \le M_3 \le 3,\quad 0 \le M_2 \le 3 - M_3.$$#### ミキシングレベル$1$そして$3$もし$3$-set が選択されており、これには 3 つのシングルトンが含まれています。 もし$M_3>0$、少なくとも 3 つの頂点が占有されているため、最大でも 1 つのシングルトンが素のままにできます。 これは前述の不等式によってすでに暗示されています。 

＃＃＃＃ レベル$4$もし$M_4=1$の場合、1 つおきのレベルはゼロでなければなりません。$[4]$すべてのサブセットが含まれます。 

もし$M_4=0$、それ以上の制限は発生しません。 

#### 最終的な列挙

 すべての実現可能なサイズのベクトルは、まさに次の条件を満たすものです。$$M_0 \in \{0,1\}, \quad \text{and if } M_0=1 \text{ then } M_1=M_2=M_3=M_4=0,$$それ以外の場合$M_0=0$と$$0 \le M_2 \le 3,\quad 0 \le M_3 \le 3,$$

$$0 \le M_1 \le 3 - M_2,\quad 0 \le M_3 \le 3 - M_2,$$上記で既に含まれている対称制約と合わせて、$M_4 \in {0,1}$。 

具体的には、自明ではない実現可能ベクトル ($M_0=0$) は、許容される任意のペアを選択することによって得られるすべての整数解です。$(M_2,M_3)$と$0\le M_2,M_3\le 3$そして$M_2+M_3\le 3$、そして選択します$$0 \le M_1 \le 3 - M_2,\quad 0 \le M_3 \le 3 - M_2,$$サイズのセットがないという一貫性を持って$3$サポート内でシングルトンと共存できます。 

純粋レベルのケースとシングルトンを合わせて$(0,0,0,0,1)$、これらはあらゆるサイズの乱雑なベクトルを排出します。$4$要素。 

これで解決策は完了です。 ∎
