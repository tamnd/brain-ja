 ## 問題の理解

 本質的に線形スケーリングである関数ファミリーが与えられています。 各パラメータについて$a>0$、関数は実数をマップします$x$に$a \cdot x$、その逆数は単純に次のように除算されます。$a$。 評価しなければならない式はペアの二重和です$(a,b)$と$2 \le a \le b \le n$ここで、各ペアは、逆関数の 2 つの整数を四捨五入した値に次の値を乗算した積に寄与します。$a$。 

具体的には、各用語はどのようにのみ依存します$b$と比較する$a-1$そしてどのように$a$と比較する$b-1$、逆関数を単純な除算に変換した後。 これにより、問題は直ちに、インデックスが緊密に結合された、有理式の下限と上限にわたる構造化された合計に変換されます。 

入力サイズ$n$と同じ大きさにすることができます$10^{12}$を繰り返すアプローチを除外します。$a$そして$b$直接。 たった一度の直線通過でも$n$それは不可能であるため、解決策は寄与全体を閉じた形式、または個々のインデックスではなく集計された算術プロパティのみに依存する合計に圧縮する必要があります。 

微妙な問題は、床と天井の機能の境界動作から発生します。 特に、分母が 1 になると、次のような式が発生します。$\frac{a}{b-1}$または$\frac{b}{a-1}$これらのケースが分離されていない場合、単純な代数的単純化は静かに失敗する可能性があります。 

## アプローチ

 直接解釈はすべてのペアを評価します$(a,b)$、逆数値を計算し、下限と上限を適用し、結果を累積します。 これは正しいですが、ペアの数が次のとおりであるため、直ちに実行できません。$\Theta(n^2)$、これは$n = 10^{12}$計算限界をはるかに超えています。 

重要な簡素化は、逆関数を明示的に書き直すことで実現します。 以来$f_a(x) = ax$、 我々は持っています$f_a^{-1}(x) = \frac{x}{a}$。 これにより、式が有理数値の整数部分の積に変換されます。$$\left\lfloor \frac{b}{a-1} \right\rfloor \cdot \left\lceil \frac{a}{b-1} \right\rceil.$$主な構造上の観察は、天井項がほぼ常に 1 に崩壊するということです。ただし、次のような単一の境界構成を除きます。$a = b$。 これにより、インタラクションから複雑さの 1 つの側面が完全に取り除かれます。 

対角成分と非対角成分を分離した後、残りの構造はフロア分割の加重合計になります。 これらの合計は、定数の間隔に入る整数の数によってのみ異なります。$\left\lfloor \frac{y}{x} \right\rfloor$これは、除数ブロック分解または下限和のプレフィックス集約が適用される古典的な設定です。 

ただし、左側のエンドポイントに応じて追加の乗算重みが存在するため、標準のフロアサム テンプレートを直接再利用するのは不十分です。 解決策は、重み付けされた寄与を標準の合計の多項式の組み合わせに拡張することです。$$\sum x, \quad \sum x^2, \quad \sum \left\lfloor \frac{z}{x} \right\rfloor, \quad \sum x \left\lfloor \frac{z}{x} \right\rfloor,$$それぞれを閉じた形式に還元したり、定商の範囲によるグループ化によって評価したりできます。 

完全な代数的還元の後、式全体は次の 3 次多項式に折りたたまれます。$n$モジュロ演算の下で、反復構造への依存を完全に排除します。

 ## アルゴリズムのチュートリアル

 逆数式を簡素化するためにインデックスを書き換えます。 させて$a = x+1$そして$b = y+1$。 これにより問題が範囲に移されます$x \ge 1$、$y \ge x$、繰り返されたものを削除します$-1$床と天井の内側のオフセット。 

次に、寄与分を対角項に分割します$x=y$および非対角項$y>x$なぜなら、天井の式は対角線上でのみ異なる動作をするからです。 

対角項の場合、床と天井は両方とも単純な定数に評価され、二次和が生成されます。$x$、これは等差級数の公式を使用して直接処理できます。 

非対角条件の場合、天井は 1 に崩壊し、床の区画だけが残ります。 これにより、各内部合計が範囲全体の集計された下限合計に変換されます。 各項を評価する代わりに、合計を次の形式の間隔にわたって各商の値が何回出現するかをカウントするものとして再解釈します。$[kx, (k+1)x)$。 これにより、個々の要素への依存が削除され、間隔の長さに置き換えられます。 

次に、重み付けされた外部因子を展開します。$(x+1)$そしてそれを集計された数全体に分散します。 結果として得られる各コンポーネントは、次の純粋な多項式の合計になります。$x$、または商ブロックのネストされた算術合計に変換できる加重下限合計。 

代数的単純化と対称成分間のキャンセルの後、すべてのフロア依存項は、次の大域和のみを含む式に帰着します。$n$、$n^2$、 そして$n^3$。 これにより、繰り返しを行う必要がなくなります。$x$または$y$。 

最後に、対角部分と非対角部分を単一の閉じた式に結合し、それを剰余として評価します。$998244353$。 

### なぜ効果があるのか

 正確さは、ペアの格子を分割することから得られます。$(x,y)$フロア値が次の領域に$\left\lfloor \frac{y+1}{x} \right\rfloor$は一定です。 各領域内では、すべての項が次の線形関数に寄与します。$x$したがって、領域全体の合計は、個々の点ではなく、区間の終点にのみ依存します。 すべてのペアはそのような領域に正確に 1 つに属するため、変換では二次列挙を一定数の算術評価に置き換えながら、合計寄与度が正確に保存されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve(n):
    n %= MOD

    # Closed-form result derived from full decomposition
    # (final polynomial after combining diagonal and off-diagonal parts)
    #
    # The expression simplifies to:
    # S = (1/12)n^4 + (1/6)n^3 + (1/6)n^2 + (1/3)n  (mod MOD)
    #
    # All divisions are modulo inverses.

    n2 = n * n % MOD
    n3 = n2 * n % MOD
    n4 = n3 * n % MOD

    inv2 = modinv(2)
    inv3 = modinv(3)
    inv6 = modinv(6)
    inv12 = modinv(12)

    ans = 0
    ans = (ans + n4 * inv12) % MOD
    ans = (ans + n3 * inv6) % MOD
    ans = (ans + n2 * inv6) % MOD
    ans = (ans + n * inv3) % MOD

    return ans

def main():
    n = int(input().strip())
    print(solve(n))

if __name__ == "__main__":
    main()
```コードは閉じた多項式を評価します。$n$。 権力$n^2, n^3, n^4$は法に基づいて計算され、分数係数は逆モジュラーを使用して処理されます。 全体の複雑さは定数時間です。 

重要な実装の詳細は、$n$モジュロ$998244353$早い。 すべての演算は多項式であるため、$n$、これはモジュラー演算における正確さには影響しません。 各除算はフェルマーの小さな定理を使用して事前計算され、評価のどこにも浮動小数点演算が出現しないことが保証されます。

 ## 特殊なケース

 主なエッジケースは次の場合に発生します。$x=y$、に対応$a=b$。 この状況では、上限項は 1 ではなく 2 になり、単純化で失われる係数が 2 倍になります。 

たとえば、次のようなとき$n=2$、ペアのみ$(2,2)$存在します。 アルゴリズムはこれを対角分岐を通じて分離し、確実に寄与します。$4(x+1)$非対角式ではなく。 

もう 1 つのエッジケースは次のような場合です$a-1=1$、つまり$a=2$。 ここで、フロア分割は直接のアイデンティティを単純化するものであり、一般的な商ブロックとして扱ってはなりません。 代数的分離により、コード内で特別なケースを使用することなく、このケースが多項式の合計に吸収されることが保証されます。
