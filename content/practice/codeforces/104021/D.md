 ## 問題の理解

 多くのシーケンスにわたる重みを合計するように求められます。 各シーケンスは固定長です`n`、そしてすべての要素はその間にあります`1`そして`m`。 最大公約数が正確に一致するシーケンスのみを考慮します。`d`。 有効なシーケンスごとに`(a1, a2, ..., an)`、すべての要素の積の k 乗に等しい値を計算し、この値をすべての有効なシーケンスで合計します。 

つまり、概念的には、私たちは全長にわたっています。`n`境界付きアルファベットの配列をグローバル gcd 制約でフィルタリングし、シーケンス全体に依存する乗算スコアを集計します。 

すべてを支配する最初の制約は、`n`、これは 10^100000 まで大きくなる可能性があります。 これにより、次のようなアルゴリズムが即座に排除されます。`n`通常の整数ループカウンターとして。 ～への依存`n`代数累乗に還元する必要があります。`n mod something`が必要です。 

2 番目の制約は、`m ≤ 100000`、これは、以下の値に対する事前計算を強く示唆しています。`m`許可されています。 これは、接頭辞合計、メビウス反転配列、およびべき乗表がすべて実行可能な領域です。 

3 番目の重要な制約は gcd 条件です。 問題で gcd を使用したシーケンスが正確に要求されるときはいつでも`d`、標準的な構造の単純化では、因数分解します。`d`あらゆる要素から。 これにより、制約が以下に等しい gcd に変換されます。`1`縮小されたドメインでの問題。 

gcd フィルタリングが積指数と相互作用する場合、微妙なエッジ ケースが発生します。 単純なアプローチでは、乗法構造を適切に分離せずに、シーケンスを生成したり、除数を反復しようとしたりする可能性があります。 これは、二重にカウントしたり、スケーリング下で gcd と product の両方が適切に相互作用するという事実を見逃したりすることにつながります。 

もう 1 つの一般的な障害モードは、巨大な指数の処理です。`n`べき乗剰余演算で直接使用可能です。 以来`n`は通常の整数として与えられないため、べき乗が含まれる場合は適切なサイクル長を法として減算する必要があります。 

## アプローチ

 ブルートフォース戦略では、有効な長さのシーケンスをすべて明示的に列挙します。`n`、その積を計算し、累乗します`k`、gcdの状態を確認します。 gcd 制約を無視しても、シーケンスの数は`m^n`、小さいものでも天文学的な大きさです。`n`。 ブルートフォースは原理的には正しいですが、状態空間が指数関数的に拡大するため、すぐに崩壊します。`n`。 

重要な観察は、gcd 条件と積構造の両方が乗算的であるということです。 これにより、2 つの大きな変換が可能になります。 

まず、gcd 条件を正規化します。 すべての要素の場合`ai`で割り切れます`d`、書くことができます`ai = d * bi`。 次に、gcd 制約は次のようになります。`gcd(b1, ..., bn) = 1`、ドメインは次のように縮小します。`1 ≤ bi ≤ m/d`。 

第二に、重りはきれいに分解されます。 製品は、`d^n * (b1 * b2 * ... * bn)`、それで累乗した後`k`、グローバル要素を取得します`d^{n*k}`乗算`(b1 * ... * bn)^k`。 

ここで問題は、完全に乗算的な重みをもつ古典的な「gcd 1 によるシーケンスの合計」になります。 

次のステップは、メビウス反転を使用して gcd 制約を削除することです。 gcd が 1 に等しいことを直接強制する代わりに、すべてのシーケンスをカウントし、すべての要素が公約数を共有するシーケンスを減算します。 

固定除数の場合`g`、シーケンスはすべて`bi`で割り切れます`g`次のように書き換えることができます`bi = g * ci`。 これにより、寄与度が次の要素に応じて明確に分離されます。`g`そして、より小さな制約のないシーケンス`ci`。 

残りの制約されていない合計は、ポジション全体で因数分解されます。 長さのすべてのシーケンスの合計`n`の`(product bi^k)`になる`(sum i^k)^n`これにより、組み合わせ爆発全体が単一のプレフィックス電力和に縮小されます。 

すべてをまとめると、各項にプレフィックスの累乗和とべき乗剰余が含まれる、約数に対するメビウス加重和を評価します。

 ## アルゴリズムのチュートリアル

 ### ステップ 1: gcd 条件を正規化する

 それぞれの値を置き換えます`ai`と`bi = ai / d`。 シーケンス制約は次のようになります。`1 ≤ bi ≤ m/d`そして`gcd(b1, ..., bn) = 1`。 と表します。`x = m/d`。 

これにより、gcd 制約がスケーリング係数から分離されます。`d`。 

### ステップ 2: グローバル乗算係数を分離する

 オリジナル商品は、`∏ ai = d^n ∏ bi`。 パワーアップ後`k`、からの合計貢献度`d`になる`d^{n*k}`。 これをメインの組み合わせ計算の外に置きます。 

### ステップ 3: 基本べき乗和関数を定義する

 あらゆる制限に対して`t`、 定義する`S(t) = sum_{i=1..t} i^k`。 

シーケンスは位置全体で考慮されるため、この関数はすべてのシーケンスの合計の構成要素となります。 

### ステップ 4: 制約のないシーケンスの合計を表現する

 gcd の制限がない場合、長さのすべてのシーケンスの合計`n`は：`(S(t))^n`それぞれの立場が独立して貢献するからです。 

### ステップ 5: gcd = 1 に対してメビウス反転を適用する

 以下を使用して、gcd が 1 であるシーケンスをカウントします。`sum_{g=1..x} μ(g) * F(x/g, g)`どこ`F(x/g, g)`すべての要素が次の数で割り切れるシーケンスをカウントします。`g`。 

### ステップ 6: 可分性条件を変換する

 それぞれの場合`bi`で割り切れます`g`、 書く`bi = g * ci`。 それから：`bi^k = g^k * ci^k`したがって、完全なシーケンスは次のことに貢献します。`g^{n*k} * (∏ ci^k)`したがって：`F(x/g, g) = g^{n*k} * (S(x/g))^n`### ステップ 7: すべてのコンポーネントを組み合わせる

 gcd-1 の合計は次のようになります。`sum μ(g) * g^{n*k} * (S(x/g))^n`スケーリング係数を乗算して戻すと、次のようになります。`answer = d^{n*k} * sum μ(g) * g^{n*k} * (S(x/g))^n`### ステップ 8: 大きな指数 n を処理する

 以来`n`は非常に大きいため、直接使用することはありません。 累乗を含むもの`n`モジュラー指数ルール (通常はモジュロ) を使用して削減されます。`MOD-1`係数が素数の場合)、および`n`大きな整数文字列として読み取られます。 

### なぜ効果があるのか

 すべての変換では、スケーリングまたは除数グループ化の前後でシーケンス クラス間の全単射を保証することにより、正確なカウントが維持されます。 メビウス反転では、gcd が 1 より大きいシーケンスからの寄与が正確に相殺されることが保証されます。 シーケンス位置間の独立性により、積の合計が単一のプレフィックス合計の累乗に因数分解されます。 したがって、最終的な構造は除数クラスの合計であり、各クラスは正しい重みを持つ素なシーケンスのセットに寄与します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 59964251

# Precompute Möbius up to max m
MAXM = 100000
mu = [1] * (MAXM + 1)
vis = [False] * (MAXM + 1)
primes = []

for i in range(2, MAXM + 1):
    if not vis[i]:
        primes.append(i)
        mu[i] = -1
    for p in primes:
        if i * p > MAXM:
            break
        vis[i * p] = True
        if i % p == 0:
            mu[i * p] = 0
            break
        else:
            mu[i * p] = -mu[i]

def mod_pow(a, e):
    r = 1
    a %= MOD
    while e > 0:
        if e & 1:
            r = r * a % MOD
        a = a * a % MOD
        e >>= 1
    return r

def sum_k_powers(x, k):
    # direct computation since x <= 1e5
    s = 0
    for i in range(1, x + 1):
        s = (s + mod_pow(i, k)) % MOD
    return s

def solve():
    T = int(input())
    for _ in range(T):
        n_str, m, d, k = input().split()
        m = int(m)
        d = int(d)
        k = int(k)

        # reduce n modulo MOD-1 (assume MOD prime-like behavior)
        n = 0
        for c in n_str:
            n = (n * 10 + int(c)) % (MOD - 1)

        x = m // d
        if x == 0:
            print(0)
            continue

        # precompute S(t)
        S = [0] * (x + 1)
        for i in range(1, x + 1):
            S[i] = (S[i - 1] + mod_pow(i, k)) % MOD

        ans = 0

        for g in range(1, x + 1):
            if mu[g] == 0:
                continue
            t = x // g
            base = S[t]
            term = mod_pow(base, n)
            term = term * mod_pow(g, n * k % (MOD - 1)) % MOD
            if mu[g] == 1:
                ans = (ans + term) % MOD
            else:
                ans = (ans - term) % MOD

        d_factor = mod_pow(d, n * k % (MOD - 1))
        ans = ans * d_factor % MOD

        print(ans % MOD)

if __name__ == "__main__":
    solve()

機能`sum_k_powers`概念的にはプレフィックスの合計です`S(t)`、しかしそれ以来`t`が十分小さい場合は、各項のべき乗剰余を使用して直接計算されます。 これが主な計算コストですが、制限があるため制限内に残ります。`m`。 

メインループはメビウス反転公式を評価します。 各約数について`g`、縮小された範囲を計算します`t = x/g`、基本合計を評価します`S(t)`、それを力に上げます`n`、そして除数の寄与を乗算します`g^{n*k}`。 メビウス値によって、この項が加算されるか減算されるかが決まります。 

最後に、グローバル スケーリング係数を掛けます。`d^{n*k}`。 

指数の取り扱いには注意が必要です。 あらゆる出来事が起こる`n`内部べき乗は剰余で減算されます`MOD-1`10^100000 桁の指数による直接累乗は不可能であるため、オイラー形式のサイクル短縮の仮定の下で行われます。

 ## 特殊なケース

 重大なエッジケースは次のような場合です。`m < d`、これにより、`x = m/d = 0`。 この場合、有効なシーケンスはありません。 このアルゴリズムは、メビウスの計算を入力せずに、直ちに 0 を正しく返します。 

もう 1 つのエッジケースは次のような場合です`x = 1`。 それからのみ`g = 1`が寄与し、メビウス和は単一のべき乗項に崩壊します。 これにより、アルゴリズムが不必要な除数構造に依存していないことがチェックされます。 

最後のエッジケースは、次のような理由ですべての数値が強制的に等しくなる場合です。`x = 1`または`m = d`。 アルゴリズムは引き続き計算します`S(1) = 1^k = 1`したがって、すべてのシーケンスの重みは同じになり、べき乗は正しく 1 になります。
