 ## 解決策
 ## 問題の理解

 最初はサイズがゼロの行列が与えられます。$n \times n$。 一連の操作が適用され、各操作で行全体または列全体が選択され、その行または列のすべてのセルに正の整数が追加されます。 すべての操作が完了すると、ちょうど 1 つのセルが非表示になり、その値が次の値に置き換えられます。$-1$。 最終的な行列が表示されます。タスクは、非表示のセルが置換される前の元の値を回復することです。 

最終的な行列の各セル値は、その行に影響を与えるすべての行操作と、その列に影響を与えるすべての列操作からの寄与の合計です。 非表示のセルも概念的には同じ加法構造を持っていますが、最終的な値は与えられません。$-1$。 

制約$n \le 1000$ということを意味します$O(n^2)$スキャンは許容されますが、セルごとに再構築を繰り返したり、動作をシミュレートしようとしたりすることは不要であり、やりすぎです。 この構造は、操作の完全なシーケンスを再構築する必要があるのではなく、行と列にわたるグローバルな一貫性条件を強く示唆しています。 

微妙な点は、1 つの欠損値を除いて行列が完全に一貫していることです。 欠落しているセルを無視した場合でも、他のすべてのエントリは、行と列の寄与への同じ加法分解を考慮する必要があります。 この一貫性が重要な鍵となります。 

単純な間違いは、行と列の増分を明示的に推測しようとしたり、未知数が多すぎるシステムを解こうとしたりすることです。 もう 1 つのよくある誤った考え方は、答えが単に行または列の最大値または最小値であると想定することですが、行と列の寄与が重複するため、これは失敗します。 

素朴な考えによる具体的な失敗例は、次のようなマトリックスです。$$\begin{matrix}
5 & 7 \\
6 & -1
\end{matrix}$$隠れた値が行または列の極値間の差に等しいという誤った仮定がある可能性がありますが、加法分解を理解していないと、行/列の寄与が非対称である場合、そのようなヒューリスティックはすぐに機能しません。 

## アプローチ

 各セルの値は次のように表現できます。$$a_{i,j} = R_i + C_j$$どこ$R_i$行に対する行操作からの合計寄与度です。$i$、 そして$C_j$列に対する列操作からの合計寄与度です。$j$。 この分解は、各操作が正確に 1 つの行または 1 つの列に均一に影響を与えるため成り立ちます。 

完全な行列があれば、任意に修正できます。$R_1 = 0$そしてすべてを導き出す$C_j$行 1 からすべてを回復します$R_i$、またはその逆。 システムはまさにランク 1 の加算構造であるため、一貫性があります。 

問題は、その位置にあるセルが欠落していることです$(x, y)$。 方程式で直接使用することはできませんが、他のすべてのセルを使用して一貫した式を再構築することができます。$R$そして$C$。 これらを取得したら、隠された値は次のようになります。$R_x + C_y$。 

ブルートフォースアプローチでは、次のシステムを解決しようとします。$2n$変数と$n^2 - 1$おそらくガウス消去法または反復推測を使用した方程式。 これは不必要であり、あまりにも重すぎるので、$n = 1000$、完全な線形ソルバでは、時間がかかりすぎて複雑になります。 

重要な洞察は、すべての方程式が必要なわけではないということです。 欠落しているセルを含まない行を選択すると、参照を修正し、線形時間で行列全体に値を伝播することができます。 

クリーンな参照行を選択したら$r$、任意の列に対して$j$、設定できます$$C_j = a_{r,j} - a_{r,1}$$次に、任意の行に対して$i$そしてコラム$1$、$$R_i = a_{i,1} - C_1$$これにより、すべての行および列の電位が再構築されます。 最後に、行と列のポテンシャルから欠落しているエントリを計算します。 

必要なのは、$-1$細胞。

 ## アルゴリズムのチュートリアル

 1. 位置を特定します$(x, y)$マークされた欠落セルの$-1$。 これは、クリーンな参照として使用できない行または列を定義するために必要です。 
2. 参照行を選択します$r$それは等しくありません$x$。 これにより、行内のすべての値が保証されます。$r$有効であり、相加的モデルと一致しています。 
3. 配列を定義する$C$サイズの$n$、と設定します$C_j = a_{r,j} - a_{r,0}$。 これにより、列 0 を基準としたすべての列の寄与が修正され、効果的に選択されます。$R_r = 0$。 
4. 列 0 をアンカーとして使用して、各行のポテンシャルを計算します。$R_i = a_{i,0} - C_0$。 このステップでは、参照行と一貫して行寄与を再構築します。 
5. 欠損値を次のように計算します。$R_x + C_y$加法的分解はすべての有効なセルに適用され、非表示のセルにも拡張されるためです。 

### なぜ効果があるのか

 すべての有効なセルは、行項と列項への一貫した分解を満たします。 任意の 1 つの参照行を固定することにより、システムの自由度がなくなります。 他の値はすべて、その行を基準にして決定されます。 システムは 1 つの欠落エントリを除いてグローバルに一貫しているため、有効な行から再構築すると正確さが保たれます。 次に、欠損値は同じ分解によって強制されます。これは、欠損値がその行と列のポテンシャルのみに依存し、その両方がすでに一意に決定されているためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = []
    mx = 0
    x = y = -1

    for i in range(n):
        row = list(map(int, input().split()))
        for j in range(n):
            if row[j] == -1:
                x, y = i, j
        a.append(row)

    # pick reference row not containing -1
    r = 0 if x != 0 else 1

    # compute column potentials using reference row
    C = [0] * n
    base = a[r][0]
    for j in range(n):
        C[j] = a[r][j] - base

    # compute row potentials
    R = [0] * n
    for i in range(n):
        R[i] = a[i][0] - C[0]

    # answer is reconstruction of missing cell
    print(R[x] + C[y])

if __name__ == "__main__":
    solve()
```コードは、行列を読み取り、欠落しているセルを特定することから始まります。 次に、$-1$すべての計算で有効なデータが使用されるようにします。 列ポテンシャルは、参照行をその最初の要素に対して正規化することによって導出されます。 次に、導出された列ベースラインを使用して行電位が計算されます。 最後に、欠損値は加法モデルを使用して再構築されます。 

微妙な実装の詳細は、$-1$あらゆる算術におけるセル。 これにより、再構築された電位の汚染が回避されます。

 ## 特殊なケース

 エッジ ケースの 1 つは、欠落しているセルが最初の行または最初の列にある場合です。 アルゴリズムは、含まれないことが保証されている参照行を選択することでこれを処理します。$-1$したがって、無効な演算は発生しません。 

例えば：$$\begin{matrix}
-1 & 2 \\
3 & 5
\end{matrix}$$ここで、参照行は行 1 になります。 

次のように計算します。$$C_0 = 3 - 3 = 0,\quad C_1 = 5 - 3 = 2$$次に再構築します。$$R_0 = 2 - 0 = 2$$したがって、欠損値は次のようになります。$$R_0 + C_0 = 2$$これは、欠落しているエントリによって自然なアンカリングがブロックされた場合でも、有効な行が依然として追加構造を完全に決定するため、システムは解決可能なままであることを示しています。
