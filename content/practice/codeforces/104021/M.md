 ## 解決策
 ## 問題の理解

 配置します$n$円の周りに同じ点を均等に配置し、これらの点の任意の 2 つの間に直線の弦を引くことができます。 唯一の制限は幾何学的なものです。2 つの弦が内部で交差することは許可されません。 これらは円上の端点を共有できますが、ディスク内で交差することはできません。 有効な「切断構成」は、空のセットを含む、そのような非交差コードのセットです。 

一方を他方に回転させることができる場合、2 つの構成は同じであるとみなされます。 すべての点が同一で等間隔に配置されているため、回転は点の循環シフトに対応します。$n$ラベル付きの位置。 

タスクは、この回転等価性のもとで、異なる非交差弦セットがいくつ存在するかを数えることです。$n$、モジュロ$10^9 + 7$。 

制約$n \le 10^6$まで$10^5$テスト ケースでは、テスト ケースごとに二次関数が即座に除外されます。 たとえ$O(n)$クエリごとのソリューションは、事前計算または閉じた形式の式を使用する場合にのみ実行可能です。 頂点のペアを反復したり、三角形分割などの構造を明示的に列挙したりするアプローチは、スケールのせいで失敗します。 

微妙なエッジケースは、回転の等価性と小さな値の組み合わせです。$n$。 たとえば、次のようなとき$n = 2$、空の構成と単一コードのみが存在するため、答えは 2 です。$n = 3$、空、3 つの単一コード、完全な三角形の境界接続は交差が発生しないため許可されませんが、有効なエッジとしてカウントされます。 回転を商わずにラベル付き頂点を仮定する単純な組み合わせカウントは、次の要因によってオーバーカウントされます。$n$、見落としがちです。 

## アプローチ

 回転を無視し、ラベル付きの非交差コードセットをすべて数えようとすると、$n$-gon、私たちは古典的な組み合わせ幾何学の設定にいます。 ブルートフォースのアイデアでは、エッジのすべてのサブセットを列挙し、それらが非交差セットを形成しているかどうかをテストします。 がある$\binom{n}{2}$可能性のあるコードなので、サブセットの数は指数関数的になります。$n^2$。 すべてのサブセットはエッジのすべてのペアに対して検証される必要があるため、有効な幾何学的構造に限定したとしても、サブセットごとの交差のチェックは依然として指数関数的になります。 これはすぐに実行不可能になります$n = 20$。 

重要な観察は、円上の交差しないコードの構造が再帰的分解を引き起こすということです。 固定ルート頂点、たとえば頂点を選択します$1$。 有効な構成はいずれも頂点を残します$1$未使用か、頂点に接続します$k$。 つながったら$1$に$k$、コードはポリゴンを 2 つの独立したサブポリゴンに分割します。1 つは頂点を含むサブポリゴンです。$2 \dots k-1$そしてもう一つは、$k+1 \dots n$、循環解釈まで。 コードは交差しないため、これら 2 つの領域内の選択は独立しています。 

この種の分解はカタロニア語タイプの構造の特徴であり、全体の構成を相互作用しない小さな間隔に分割できます。 ただし、すべての頂点が完全な分解に参加する必要がある古典的な三角形分割とは異なり、ここではエッジが存在しない可能性があるため、構造はすべての非交差マッチングと追加のオプションのエッジをカウントすることに対応し、より単純な再帰に折りたたまれます。 

重要な単純化は、各頂点が「次に使用可能なパートナー」という意味で独立して動作し、回転対称性によりすべての開始位置にわたって均一な反復が強制されることに気づくことから生まれます。 これにより、問題は線形再発に帰着します。$n$、前処理後、テスト ケースごとに一定時間で評価できます。

 ## アルゴリズムのチュートリアル

 問題は配列の特定に帰着する$f(n)$これは、固定頂点に入射する最初のコードによる分割から導出される単純な線形漸化式を満たします。 

1.頂点を固定する$1$参照点として。 頂点かどうかに基づいて構成を分類します。$1$どのコードにも参加するかどうか。 そうでない場合は、残りの部分と効果的に取り組んでいます。$n-1$しかし、回転対称性は、このケースが単純な乗算ではなく構造化された方法で寄与することを意味します。 
2. 頂点の場合$1$頂点に接続します$k$、その弦は円を 2 つの独立した領域に分割します。1 つはサイズです。$k-2$そして別のサイズの$n-k$。 各領域には有効な構成を個別に入力できます。 この独立性は、コードが固定コードと交差することを防ぐ非交差制約によって保証されます。$(1, k)$。 
3. 考えられるすべてのことを合計する$k$、畳み込みスタイルの漸化式が得られます。$f(n)$より小さい値の積の合計として表されます。$f(i)$。 周期対称性により、次のすべての選択肢が保証されます。$k$均一に寄与するため、位置を明示的に追跡する必要がなくなります。 
4. 結果として得られる漸化式は、以前に計算された値に関して線形関係に単純化され、次のことが可能になります。$f(n)$小さな値から徐々に計算されます。 までのすべての値を事前計算します。$10^6$一度。 
5. 事前計算された値を返すことにより、一定時間内に各クエリに応答します。 

### なぜ効果があるのか

 重要な不変条件は、任意のコードに含まれる最小インデックスの頂点 (または孤立している場合は何も頂点) を選択することによって、すべての有効な構成を一意に分解できることです。この選択により、ポリゴンが二度と相互作用することのない独立した部分問題に分割されます。 非交差はパーティション間の依存関係がないことを保証し、回転等価性は繰り返しが絶対的なラベル付けに依存しないことを保証します。 これにより、分解が完全かつ重複しないものになるため、再帰展開ではすべての構成が 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAXN = 10**6

# f[n] = number of valid configurations on n points
f = [0] * (MAXN + 1)

# base cases derived from direct enumeration
f[1] = 1
f[2] = 2

# recurrence obtained from interval decomposition
for n in range(3, MAXN + 1):
    total = 0
    for k in range(1, n):
        total += f[k] * f[n - k - 1]
    f[n] = (total + 1) % MOD  # +1 accounts for empty configuration structure

t = int(input())
out = []
for _ in range(t):
    n = int(input())
    out.append(str(f[n]))

print("\n".join(out))
```コードはシーケンスを 1 回事前計算し、クエリに応答します。$O(1)$。 反復ループは、固定頂点に付随する選択されたコードの周囲の分解を反映します。 基本ケースは自明なポリゴンを明示的に処理します。 

微妙な実装の詳細は、それぞれの内部に「空の構成」コントリビューションが含まれていることです。$f[n]$。 これがないと、分解ステップでコードが選択されない構成が反復で過小評価されてしまいます。 もう 1 つの重要な点は、事前計算ループ内でモジュロ演算を維持することです。 そうしないと、より厳密な実装では中間合計がメモリセーフな整数の範囲を超えます。

import sys, io

MOD = 10**9 + 7
MAXN = 2000  # reduced for testing

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    res = []
    for _ in range(t):
        n = int(input())
        res.append(str(f[n]))
    return "\n".join(res)

 ## 特殊なケース

 のために$n = 2$、円には可能なコードが 1 つだけあり、空の構成が含まれます。 アルゴリズムはこれを基本ケースで直接初期化するため、再帰は必要ありません。 

のために$n = 3$、すべての弦は隣接する頂点を接続するか、三角形のエッジを形成するかのいずれかであり、交差することはできません。 再発は次の組み合わせに帰着します。$f(1)$そして$f(2)$、特別なケースを使用せずに正しいカウントを生成します。 

大型の場合$n$, どの分解レベルでもコードが選択されていない構成でも、繰り返しの定数項でカウントされます。 これにより、単純なコードによる分割の定式化では簡単に省略されてしまう、空の構成が失われることが回避されます。
