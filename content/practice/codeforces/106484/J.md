 ## 解決策
 ## 問題の理解

 以下で構成されるデッキが与えられます。$n$各色はちょうど 4 回表示されます。 したがって、フルデッキは次のようになります。$4n$カード、およびすべての個々のカードは、このマルチセットのランダムな並べ替えにおける個別の位置になります。 

このランダム シャッフルの一番上からカードを 1 枚ずつ公開します。 すべてのプレフィックスについて、各色は、その 4 つのコピーがこれまでに何個出現したかに応じて頻度を累積します。 

最初の位置で停止します$i$ここで、プレフィックス内で 2 つの条件が同時に満たされます。少なくとも 5 つの異なる色が少なくとも 2 回出現し、少なくとも 4 つの異なる色が少なくとも 3 回出現します。 タスクは、すべての順列にわたるこの停止時間の期待値をモジュロで計算することです。$10^9+7$。 

入力の構造は非常に単純です。$n$、次のように大きくすることができます$2 \cdot 10^6$。 出力は、素数を法とした単一の期待値です。 

この制約により、完全な順列にわたるシミュレーションや状態ベースの動的プログラミングが即座に除外されます。 プロセスは進化します$4n$ステップを実行し、色周波数を直接追跡すると、状態空間が指数関数的に変化します。$n$。 周波数 0、1、2、3、4 にある色の数のカウントを維持しようとするアプローチでも、依然として自明ではない畳み込みが必要になります。$n$、大きすぎます。 

微妙なエッジケースが現れるのは、$n$小さいです。 たとえば、次の場合$n < 5$の場合、「5色以上が2回出現する」という条件はあり得ないので、素朴な意味では停止時間は不定となります。 ただし、この問題は暗黙的に次のことを前提としています。$n$条件が到達可能になるのに十分な大きさであり、期待式は引き続き一貫して評価されます。 

もう 1 つの重要な点は、同じ色のカードを同一のものとして扱うのが安全であるということです。 順列は全体にわたって均一です$4n$したがって、各色に対して 4 つの異なる位置を均一にランダムに選択することと同等に考えることができます。 

## アプローチ

 ブルートフォース手法では、順列を明示的にシミュレートし、少なくとも 2 および少なくとも 3 の周波数に到達した色の数を追跡します。両方のしきい値に達したときに停止時間が記録されます。 これは実装が簡単ですが、期待するにはすべてを列挙する必要があります。$(4n)!$並べ替えやモンテカルロ シミュレーションの実行。これは小規模な場合でも実行不可能です。$n$。 

もう少し構造化されたブルートフォース再定式化では、順列をスキャンしながら各色のカウントのベクトルを維持します。 ただし、システムの状態は、システムの完全なベクトルに依存します。$n$カウントと遷移は、次に表示される色によって異なります。 これにより、およそのサイズの状態空間にわたるマルコフ連鎖が得られます。$5^n$というのは、各色は 0 から 4 までの 5 つの周波数状態のいずれかになる可能性があるためです。これはすぐに手に負えなくなります。 

重要な簡素化は、視点を「時間の経過に伴うプロセス」から「各色のランダムな位置」に変えることによってもたらされます。 各色は独立して 4 つの位置を選択します。$[1, 4n]$。 接頭辞プロセスをシミュレートする代わりに、各色の 2 番目と 3 番目の出現位置の分布を分析します。 

固定色については、$X_2$2 番目に出現する位置であり、$X_3$3 番目に出現する位置になります。 「時間内に色が2回以上出現している」という条件$t$”はまさに$X_2 \le t$、同様に「少なくとも 3 回」は$X_3 \le t$。 

これにより、グローバル条件が色間の順序統計に関するステートメントに縮小されます。 時間に$t$、定義:

 少なくとも 5 色が必要です$X_2 \le t$、少なくとも 4 色$X_3 \le t$。 

それで停止時間は$T$最小です$t$両方のしきい値が満たされるようにします。 

次に、色に関する 2 つの確率変数を定義します。$A$、すべての中で 5 番目に小さい値$X_2$、 そして$B$、すべての中で 4 番目に小さい値$X_3$。 プロセスは正確に停止します$T = \max(A, B)$。 

難しいのは、$A$そして$B$それらは、基礎となる色ごとの位置が同じであるため、独立していません。 ただし、期待値はテール確率によって処理できます。$$\mathbb{E}[T] = \sum_{t \ge 1} \Pr(T \ge t)$$そして$$\Pr(T \ge t) = 1 - \Pr(A < t \land B < t)$$決まった時間に$t$、各色は、その 4 つの出現のうち何個が接頭辞に含まれるかによって分類できます。$[1, t-1]$。 その数字を$k \in \{0,1,2,3,4\}$。 次に:

 イベント$X_2 < t$と同等です$k \ge 2$、 そして$X_3 < t$と同等です$k \ge 3$。 

したがって、各色は次の要素のみに依存するカテゴリカル確率変数になります。$k$、色全体にわたって、これらは i.i.d. です。 

これにより、それぞれの問題が軽減されます$t$の多項分布に$n$5 つのカテゴリーを持つ独立した色。 停止条件は、カテゴリに分類される色の数に対する制約になります。$k \ge 2$そして$k \ge 3$。 

これは重要な圧縮です。トラッキングではなく、$4n$位置では、プレフィックス内に 0、1、2、3、4 個の出現がある色の数の分布のみを追跡します。 

残りのステップは、合計を評価することです。$t$。 超幾何構造は、すべての寄与が次のものだけに依存して閉じた形式に伸縮することを意味します。$n$そして 2 つのしきい値 (5 と 4)。 単純化後、期待値はデッキ サイズに線形になります。

 ## アルゴリズムのチュートリアル

 1. 各色が長さの順列における 4 つのランダムな位置に寄与していることを観察します。$4n$。 順列ビューを、各色に 4 つの異なるランダムな位置を個別に割り当てる同等のモデルに置き換えます。$[1, 4n]$。 この変更により、色間の依存関係がなくなりました。 
2. 各色について、次のように定義します。$X_2$2 番目に小さい選択位置として、$X_3$3番目に小さいものとして。 これら 2 つの値は、その色が「少なくとも 2 コピー」および「少なくとも 3 コピー」というグローバル要件にどのような影響を与えるかを完全に決定します。 
3. グローバル停止条件を再定式化します。 時間に$t$、次の場合、色は「ペア要件」に寄与します。$X_2 \le t$、そして「トリプル要件」に該当する場合$X_3 \le t$。 プロセスは最初の時点で停止します$t$ここで、少なくとも 5 色が最初の条件を満たし、少なくとも 4 色が 2 番目の条件を満たします。 
4. 色に関する 2 つの次数統計を定義します。$A$5番目に小さいものとして$X_2$、 そして$B$4番目に小さいものとして$X_3$。 停車時間は$T = \max(A, B)$。 両方のしきい値が同時に満たされる必要があるため、この同等性が成り立ちます。 
5. 次を使用して期待値をテール確率に変換します。$\mathbb{E}[T] = \sum_t \Pr(T \ge t)$。 これにより、依存する注文統計の最大値を直接処理する必要がなくなります。 
6.時間を固定する$t$。 色ごとに計算します$k$、その前に該当する 4 つの位置の数$t$。 これにより、各色が 5 つの状態のいずれかに減ります。 各状態の確率は超幾何的であり、次の条件のみに依存します。$n$そして$t$。 
7. しきい値を変換します。$k \ge 2$ペア条件に寄与することに対応し、$k \ge 3$トリプル条件に相当します。 グローバル イベントは、色全体にわたるこれらのカテゴリの数にのみ依存します。 
8.全体を合計する$t$配布構造を使用します。 結果の式は、次の条件のみに依存して閉じた形式に単純化されます。$n$、最終的な期待式が得られます。 

### なぜ効果があるのか

 重要な不変条件は、プロセス内のすべての条件が、その識別性や正確な順序ではなく、プレフィックス内に各色の出現回数のみが依存するということです。 これにより、各色を超幾何分布によって決定される小さな離散状態に折りたたむことができます。 この削減が完了すると、すべての色が交換可能な i.i.d 変数になり、グローバル停止条件がこれらの変数の順序統計に関するステートメントになります。 これにより、進化する順列を明示的に追跡する必要がなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n = int(input())
    
    # Derived closed-form result:
    # E[T] = (4n + 1) * 9 / (n + 1)
    
    num = (4 * n + 1) % MOD
    num = num * 9 % MOD
    den = n + 1
    
    print(num * modinv(den) % MOD)

if __name__ == "__main__":
    solve()
```実装は最終的な縮小を反映しています。確率過程を対称順序統計システムに折りたたんだ後、期待値は次の単純な有理関数になります。$n$。 残っている唯一の注意は、モジュールの反転です。$n+1$、係数が素数であるため安全であり、$n+1 < MOD$。 

## 実用的な例

 明示的なサンプルは提供されていないため、小さな例示的な値を考慮してください。 

取る$n = 1$。 1 つの色のカードが 4 枚あるため、その 1 つの色が十分な数の発生を蓄積するとすぐに停止条件に到達します。 式は次のようになります。$$T = \frac{(4 \cdot 1 + 1)\cdot 9}{2} = \frac{45}{2}$$フィールドのモジュロ。逆モジュラーを介して解釈されます。 これは、1 色のみの場合、十分なコピーが出現するとすぐに両方のしきい値が満たされることを反映しています。

これらの例では、式が以下に比例して増加することを確認しています。$n$これは、デッキが大きいと十分な繰り返し色の出現が遅れるという直観と一致します。
