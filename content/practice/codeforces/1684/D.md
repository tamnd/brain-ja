 ## 解決策
 ## 問題の理解

 一連のトラップが与えられ、それぞれに基本ダメージ値が設定されています。 トラップを順番に通過し、各トラップでダメージを受けるか、ジャンプしてトラップをスキップします。 トラップを飛び越えるたびに、そのダメージは防止されますが、その後のすべてのトラップのダメージは、すでに行われたジャンプごとに 1 ずつ増加します。 We are allowed to make at most$k$ジャンプします。 目標は、受けるダメージの合計を最小限に抑えることです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースが提供するのは、$n$、トラップの数、$k$、許可される最大ジャンプ数、およびリスト$n$各トラップの基本ダメージを表す整数。 出力はテスト ケースごとに 1 つの整数、つまり達成可能な最小の合計ダメージです。 

制約により許可されるのは、$n$到達する$2 \cdot 10^5$と合計$n$テストケース全体では最大でも$2 \cdot 10^5$。 これは、どの解もほぼ線形である必要があることを示しています。$n$テストケースごとに。 トラップのサブセットの数が膨大であるため、ジャンプのあらゆる組み合わせを試す単純なアプローチは不可能です。$2^n$、妥当な計算時間をはるかに超えています。 最大の基本ダメージ値が大きい$10^9$非効率的にダメージを蓄積するような解決策は避けなければならないことを示唆しています。 

明らかではないエッジケースには、次のような状況が含まれます。$k \ge n$、すべてのトラップをジャンプしてダメージをゼロにすることができる場合、およびボーナスダメージのカスケード効果により、最適なジャンプが最大の基本ダメージトラップではない場合。 たとえば、`[5,10,11,5]`と$k=1$, 3 番目のトラップを飛び越える方が、後続のトラップへの +1 ボーナスを考慮した合計が最小化されるため、最大のトラップを飛び越えるよりも優れています。 

## アプローチ

 ブルートフォースソリューションでは、飛び越えるトラップのすべてのサブセットを列挙し、各サブセットの合計ダメージを計算し、最小値を選択します。 これはあらゆる可能性を試すので正しいですが、次のことが必要です。$O(2^n)$テストケースごとの操作は実行不可能です$n$まで$2 \cdot 10^5$。 

重要な洞察は、逆の順序で罠を飛び越えた場合の影響を考慮することです。 すべてのトラップの有効コストは、基本ダメージから、後のトラップをジャンプすることで得られる潜在的な「回避ボーナス」を差し引いたものです。 最後を飛び越えたら$k$トラップの場合、それらのジャンプは以前のトラップには影響しません。 ダメージリストを逆にして、最大の実効ダメージを最初に考慮することで、貪欲に選択することができます。$k$総ダメージを最大限に軽減するために飛び越える罠。 基本ダメージを減らしてトラップを並べ替えると、ボーナス効果がジャンプの回数に比例して増加するため、可能な限り最新の位置で最大の基本ダメージを持つトラップをスキップするのが最適になります。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$そして$k$、そしてトラップダメージの配列$a$。 
2. 基本ダメージの降順にトラップを並べ替えます。 これにより、ダメージが合計に最も大きく寄与するトラップが特定されます。 
3. 最初の項目を選択します$k$ソートされたリストからトラップを飛び越えます。 ジャンプするたびにトラップの基本ダメージを回避し、合計ダメージを減らします。 これまでに適用されたジャンプの数を追跡します。 
4. 配列を順番に走査します。 各トラップについて、ジャンプ用にマークされている場合は、ダメージの追加をスキップします。 それ以外の場合は、そのダメージとその前にすでに適用されているジャンプの数を加算します。 
5. ステップ 4 で累積した合計が最小総ダメージとなります。 

このアルゴリズムが機能するのは、基本ダメージが最大のトラップに対してジャンプが最も効果的であるためです。 並べ替えて上位を選択すると$k$トラップでは、各ジャンプが総ダメージの軽減に最大限に貢献することを保証します。 ボーナスダメージは、トラップを順番に通過しながらジャンプ回数を蓄積することで自然に処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        # sort traps by base damage in descending order
        sorted_indices = sorted(range(n), key=lambda i: a[i], reverse=True)
        jump_set = set(sorted_indices[:k])
        damage = 0
        jumps_done = 0
        for i in range(n):
            if i in jump_set:
                jumps_done += 1
            else:
                damage += a[i] + jumps_done
        print(damage)

if __name__ == "__main__":
    solve()
```まず、トラップ インデックスをダメージの降順に並べ替え、上位を選択します。$k$ジャンプするインデックス。 移動中、スキップされたトラップごとにジャンプ カウンターが増加し、後続のトラップの効果的なダメージが増加します。 の合計`a[i] + jumps_done`ジャンプしていないトラップの場合、合計ダメージは最小限になります。

## 特殊なケース

 いつ$k \ge n$、 のような`n=4, k=4, a=[8,7,1,4]`、アルゴリズムはすべてのトラップを正しくジャンプします。 ジャンプカウンターはトラップごとに増加しますが、すべてスキップされるため、ダメージに寄与するトラップはありません。 ダメージはゼロのままで、予想される最小ダメージと一致します。 

複数のトラップのダメージが等しい場合、`a=[5,5,5,5]`そして`k=2`の場合、アルゴリズムはソート後の最初の 2 つのインデックス (インデックス 0 と 1) を選択してジャンプします。 残りのトラップは、5 + 2 ジャンプ = 7 および 5 + 2 = 7 のダメージを受け、合計は 14 になります。これは、他の組み合わせを考慮すると最小限です。 このアプローチでは、並べ替えられた順序で最も古いものを選択することで、等しい値を適切に処理します。
