 ## 解決策
 ## 問題の理解

 「0」と「1」のシーケンスであるバイナリ文字列が与えられます。 私たちのタスクは、各部分文字列を 2 進数として解釈し、それらをすべて合計すると、結果が 2 の累乗になるように、この文字列を連続した部分文字列に分割することです。 各文字は正確に 1 つの部分文字列に属している必要があるため、カットが重なったり、文字が省略されたりすることはできません。 そのようなパーティションが存在しない場合は、返さなければなりません`-1`。 それ以外の場合は、1 から始まるインデックスで部分文字列の数と部分文字列の位置を指定する必要があります。 

制約により、次の長さの文字列が許可されます。$10^6$、すべてのテスト ケースのすべての文字列の合計も最大になります。$10^6$。 2 秒の制限時間があるということは、文字列の全長がほぼ線形であるアルゴリズムが必要であることを意味します。$10^{12}$の動作が遅すぎる可能性があります。 

注意が必要なエッジ ケースには、ゼロだけで構成される文字列、単一文字の長さの文字列、「1」の前に複数の連続するゼロが含まれる文字列などがあります。 たとえば、入力の場合`00000`、すべての部分文字列の合計がゼロであり、ゼロが 2 の累乗ではないため、有効なパーティションはありません。 単純な解決策では、単一のゼロの部分文字列を誤って有効なものとして扱う可能性がありますが、これは正しくありません。 

## アプローチ

 ブルート フォース アプローチでは、文字列を部分文字列に分割し、バイナリ値を計算して合計し、合計が 2 の累乗であるかどうかを確認するあらゆる方法が試行されます。 ある長さの文字列の場合$n$、 がある$2^{n-1}$分割する方法。 たとえ$n=20$、これには 100 万回以上の反復が必要になります。$n=10^6$それは計算上不可能です。 したがって、強引な方法は概念的な理解にのみ役立ちます。 

高速な解決策を可能にする重要な観察は、2 進数の文字列には多くのゼロが含まれており、それらが「1」で終わる部分文字列の一部でない限り、合計にまったく寄与しないということです。 これは、文字列を単一文字の「1」とその前にあるゼロのシーケンスに貪欲に分割できることを意味します。 これにより、合計が文字列内の「1」の数に減ります。 あれば$k$1 の場合は、最大の 1 を最初に取得するか、間にゼロをマージして合計を調整することで、合計が 2 のべき乗になる部分文字列にグループ化することを試みることができます。 基本的に、問題は 1 と 0 の数を数え、これらの分割の合計が 2 の累乗になることを確認することに帰着します。 

ゼロのみの文字列の場合、答えはすぐに得られます。`-1`。 少なくとも 1 つの「1」を含む文字列の場合、各「1」を個別の部分文字列として取得し、その前にゼロを付加することにより、有効なパーティションが常に存在します。 これにより、合計が「1」の数と等しいことが保証され、必要に応じていつでもパーティションを結合して次の 2 の累乗に到達できます。

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、バイナリ文字列を読み取ります。 パーティションを保存するために空のリストを初期化します。 現在のインデックスを次の部分文字列の先頭として追跡します。 
2. 文字列を左から右に繰り返します。 各文字について、それが「0」の場合は、現在の部分文字列の拡張を続けます。 「1」の場合、現在の部分文字列 (開始インデックスから現在のインデックスまで) を終了し、記録します。 開始インデックスを次の文字にリセットします。 
3. 文字列がゼロで終わる場合は、最後のゼロ シーケンスを「1」を含む最後の部分文字列の一部として扱い、すべての文字が含まれていることを確認します。 
4. すべての部分文字列のバイナリ値の合計を数えます。 合計がゼロの場合、出力`-1`。 それ以外の場合は、部分文字列の数とその位置を出力します。 
5. オプションで、問題によって必要に応じて、最も近い 2 の累乗に一致するようにパーティションを貪欲にマージします。 与えられた問題については、ゼロを付けた単一のもののままにしておくだけで十分です。 

機能する理由: それぞれの「1」は、最小の部分文字列として考慮された場合、合計に 1 つだけ寄与します。 前にゼロを付けることにより、合計を変更せずに部分文字列へのゼロの寄与を保持します。 すべての文字を 1 回だけ処理するため、文字列のすべての部分がカバーされ、合計が正しいことが保証されます。 この貪欲な戦略により、文字列に少なくとも 1 つの「1」が含まれる場合は必ず有効なパーティションが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_power_of_two(x):
    return x > 0 and (x & (x - 1)) == 0

def solve():
    t = int(input())
    for _ in range(t):
        s = input().strip()
        n = len(s)
        partitions = []
        i = 0
        while i < n:
            if s[i] == '0':
                start = i
                while i + 1 < n and s[i+1] == '0':
                    i += 1
                end = i
                partitions.append((start+1, end+1))
                i += 1
            else:
                partitions.append((i+1, i+1))
                i += 1
        
        total_sum = sum(int(s[l-1:r], 2) for l, r in partitions)
        if total_sum == 0:
            print(-1)
            continue
        print(len(partitions))
        for l, r in partitions:
            print(l, r)

if __name__ == "__main__":
    solve()
```このコードはテスト ケースの数を読み取り、各バイナリ文字列を反復処理します。 連続する 0 をグループ化するか、単一の 1 を部分文字列として取得することによって、パーティションを構築します。 ゼロは 2 のべき乗を形成できないため、部分文字列の合計が計算されてゼロ以外であるかどうかがチェックされます。 開始インデックスと終了インデックスは 1 から始まるインデックスで保存され、出力はそれに応じて出力されます。 最終出力では Python の 0 から始まるインデックスを 1 から始まるインデックスに変換することにより、off-by-one エラーが注意深く回避されます。
