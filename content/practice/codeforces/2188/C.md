 ## 解決策
 ## 問題の理解

 整数の配列が与えられ、最大の整数を見つけるように求められます。$k$少なくとも差が 2 つ以上ある任意の 2 つの要素を繰り返し交換することで、配列を非降順にソートできるようにする$k$。 そうでない場合$k$存在するので戻ります$-1$。 本質的には、$k$スワップが許可される制限を表します。大きいほど$k$つまり、実行できるスワップの数が少なくなるため、実現可能な最大のスワップを見つけることになります。$k$配列のソート可能な構造の限界をテストします。 

入力は複数のテスト ケースを提供し、それぞれに最大長の配列が含まれます。$2 \cdot 10^5$、すべてのテスト ケースにわたるすべての配列の長さの合計が次を超えません。$2 \cdot 10^5$。 これは、時間計算量がほぼ線形または線形であるアルゴリズムはすべて、$n$テストケースごとに許容されます。 可能なすべてのスワップを試すなどの 2 次解は、$O(n^2) = 4 \cdot 10^{10}$最悪の場合、遅すぎる場合もあります。 

明らかではない特殊なケースもあります。 配列がすでにソートされている場合は、$k > 0$技術的にはスワップが必要ないため、「貯金箱」のように見えます。 このような場合、最大の子豚は、$k$事実上未定義であるため、問題を返す必要があります$-1$。 すべて同一の要素を持つ配列がこのカテゴリに分類されます。 もう 1 つの微妙なケースは、配列に要素が 1 つだけあり、交換が不可能な場合です。 繰り返しますが、答えは次のようになります。$-1$。 不注意なアプローチでは、実際にスワップが必要かどうかを確認せずに、配列の差分に基づいて常に正の整数を返す可能性があり、不正確な答えが得られる可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのことを繰り返すことになります。$k$1 から配列内の最大要素の差までの値。 それぞれについて$k$、少なくとも差があるペア間のスワップをシミュレートできます。$k$配列がソートされるかどうかを確認します。 これは原理的には機能しますが、各シミュレーションに時間がかかる可能性があるため、法外に遅くなります。$O(n^2)$時間があるかもしれないし、$O(n)$候補者$k$価値観。 合計すると、これを超えることになります$O(n^3)$、これは不可能です$n$まで$2 \cdot 10^5$。 

重要な洞察は、重要な交換は要素をグローバル最小値と最大値に接続するものだけであることを理解することです。 配列がすでにソートされている場合、スワップは必要なく、答えは次のようになります。$-1$。 それ以外の場合、順序が狂っている要素は、正しい位置に到達するために最小または最大の要素と交換できなければなりません。 したがって、最大の子豚は、$k$は、最大値と各場違い要素の間の差、および最小値と各場違い要素の間の差の最小値です。 ソートされた配列は、どの要素が適切でないかを検出するための参照を提供します。 

これにより、問題は線形スキャンに変換されます。配列の最小値と最大値を計算し、各要素をソートされた配列内の位置と比較し、両端までの最小距離を追跡します。 この観察により、解決策は次のように簡略化されます。$O(n \log n)$仕分け用と$O(n)$スキャンの場合は、指定された制約に対して十分に効率的です。

 | ブルートフォース | O(n^3) | O(n) | 遅すぎる |

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、配列を読み取り、その長さを決定します。$n$。 
2. 配列の要素が 1 つだけの場合、出力$-1$そして続けます。 交換はできません。 
3. 配列のソートされたバージョンを計算します。 ソートされた配列が入力と同一の場合、出力$-1$交換の必要がないからです。 
4. 配列のグローバル最小値と最大値を決定します。 
5. 実現可能な最大値を追跡するために変数を初期化します。$k$、0から始まります。 
6. 配列を反復処理します。 ソートされた配列内の位置と一致しない各要素について、その最小値と最大値との差を計算します。 最大のものを更新します$k$これらの差の最大値として。 
7. すべての要素をスキャンした後、計算された最大値を出力します。$k$。 

重要な不変条件は、順序が狂っている要素は、正しい位置に到達するために最小または最大の要素と交換できなければならないということです。 したがって、最大の貯金箱$k$は、配列の端と間違って配置された要素の位置によって完全に決まります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    if n == 1:
        print(-1)
        continue
    
    sorted_a = sorted(a)
    if a == sorted_a:
        print(-1)
        continue
    
    mn, mx = min(a), max(a)
    k = 0
    for i in range(n):
        if a[i] != sorted_a[i]:
            k = max(k, abs(a[i] - mn), abs(a[i] - mx))
    print(k)
```コードは最初に、長さ 1 の配列と既にソートされた配列という単純なケースを処理します。 配列のソートされたバージョンは、間違って配置された要素を識別するために使用されます。 各要素を最小値と最大値と比較することで、最大値を決定します。$k$これにより、必要なすべてのスワップが可能になります。 よくある落とし穴は、最小値と最大値の両方の差を比較することを忘れることで、過小評価につながる可能性があります。$k$。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        if n == 1:
            output.append("-1")
            continue
        sorted_a = sorted(a)
        if a == sorted_a:
            output.append("-1")
            continue
        mn, mx = min(a), max(a)
        k = 0
        for i in range(n):
            if a[i] != sorted_a[i]:
                k = max(k, abs(a[i]-mn), abs(a[i]-mx))
        output.append(str(k))
    return "\n".join(output)
