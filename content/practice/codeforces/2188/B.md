 ## 解決策
 ## 問題の理解

 バイナリ文字列として表される座席の行が与えられます。`1`学生がそこに座っていることを示し、`0`は空席を示します。 最初は 2 人の生徒が隣接することはありません。 目標は、着席できる生徒がなくなるまで生徒を追加することですが、追加する生徒の数をできる限り少なくする必要があります。 出力は、元の生徒と新しく追加された生徒の両方を含む、着席した生徒の最終的な数です。 

重要な制約は、2 人の生徒が隣り合った席に座ることができないことです。 これは、新しい学生を配置する場合、両方の隣接学生が空であることを確認する必要があることを意味します。 入力サイズは、すべてのテスト ケースで合計 2 × 10^5 シートに達する可能性があります。これにより、最悪の場合 10^10 の操作に達する可能性があるため、ネストされたループで各シートを繰り返しチェックするソリューションは除外されます。 

エッジ ケースには、長さ 1 の行、完全に空の行、生徒が交互に配置されている行、または境界近くに生徒がいる行が含まれます。 単純なアプローチでは、新入生の間隔を最適に配置するときに端を処理しなかったり、座席を二重に数えたりすることにより、数え間違える可能性があります。 

たとえば、次のように考えてみましょう`s = "00000"`。 1 人の生徒を最初の席に配置するだけでは、その列にそれ以上の生徒を座らせることができなくなるわけではありません。 最適な配置は座席 1 と座席 4 で、生徒は合計 2 名になります。 不用意に間隔をあけずに左から右に貪欲にすると、生徒は 1 番、2 番、4 番の席に配置され、数えすぎてしまいます。 

## アプローチ

 ブルートフォース手法では、文字列を繰り返しスキャンし、隣が空いている最初の空席を見つけ、そこに生徒を配置し、配置できる席がなくなるまで繰り返します。 これが機能するのは、各配置が有効であり、最終的にはすべての可能な位置が埋まるためです。 ただし、長い空の行を繰り返しスキャンすると、最悪の場合、これは O(n^2) になる可能性があり、2 × 10^5 までの n には遅すぎます。 

重要な観察は、問題が、空席の連続するブロックに収まる、隣接していない学生の最大数を数えることに帰着するということです。 すでに占有されている座席 (または列の境界) の間、長さ 0 が連続するセグメント`k`ホストできる`ceil(k / 2)`追加の生徒たち。 これは、学生を 1 つおきの席に配置することで、追加は最小限に抑えられ、カバー範囲は最大限に確保されるという貪欲な選択から来ています。 行をこれらのゼロブロックに分割し、結果を合計することで、入力制限に合わせてスケールする O(n) ソリューションが得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、行の長さを読み取ります。`n`そしてバイナリ文字列`s`。 
3. カウンタを初期化する`students`着席している生徒の総数を追跡するには、ゼロに設定します。 
4. 文字列を左から右にトラバースします。 インデックスを使用する`i`座席をスキャンします。 
5. 現在の座席の場合`s[i]`は`1`、増分`students`設定により1つずつ隣の席をスキップ`i += 2`。 これにより、隣接性制約に違反しないことが保証されます。 
6. 現在の座席の場合`s[i]`は`0`、隣の人を確認します: 前の (または境界) 座席と次の座席の両方が`0`(または境界線)、ここに生徒を配置し、増分します`students`で次の席にスキップします。`i += 2`。 
7. それ以外の場合は、次の座席に移動します。`i += 1`。 
8. 行全体を処理した後、出力します。`students`そのテストケースに対して。 

機能する理由: 各位置で、すでに着席している生徒を考慮するか、隣接関係を侵害することなく新しい生徒を貪欲にゼロ セグメントに配置します。 生徒を配置した後に次の座席をスキップすると、2 人の生徒が隣接することがなくなります。 空いている各セグメントは最大限に活用され、このプロセスでは学生を席に着かせる機会を決して逃しません。 すべての合計`students`カウントは、それ以上着席できない最小の合計を示します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def min_total_students():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        students = 0
        i = 0
        while i < n:
            if s[i] == '1':
                students += 1
                i += 2
            elif s[i] == '0':
                left_empty = (i == 0) or (s[i-1] == '0')
                right_empty = (i == n-1) or (s[i+1] == '0')
                if left_empty and right_empty:
                    students += 1
                    i += 2
                else:
                    i += 1
            else:
                i += 1
        print(students)

if __name__ == "__main__":
    min_total_students()
```コードは最初に入力を読み取り、各テスト ケースを反復処理します。 while ループを使用して座席を効率的にスキャンし、生徒がすでに出席しているか、座席を配置できるときにカウンターをインクリメントします。 左右のチェックは境界条件を正しく処理し、範囲外のエラーがないことを保証します。 配置後に次のシートをスキップすると、隣接関係違反が防止されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

## 特殊なケース

 1人掛け列の場合`s = "0"`、アルゴリズムは生徒を 1 人配置して終了します。 のような行の場合`"10001"`、アルゴリズムは既存の生徒を正確にカウントし、それぞれに 1 人の生徒を配置できる 2 つのゼロのセグメントを特定し、合計 3 つになります。 処理されるすべてのシートが直接寄与するかスキップされるという不変条件により、隣接関係違反がないことが保証されます。 境界チェック`i == 0`または`i == n-1`インデックスエラーを防ぎ、生徒が端に最適に着席できるようにします。
