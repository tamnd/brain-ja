 ## 問題の理解

変動性は、3 つのルールに基づいて、エッジが連続するレイヤーをどのように接続するかによって決まります。 まず、すべての頂点には最大 2 つの子があるため、レイヤー内の各ノードは$i$レイヤー内の最大 2 つのノードに接続できます$i+1$。 次に、各レイヤー内の頂点は、ラベルの昇順で左から右に並べられます。 第三に、エッジは単調性条件を尊重する必要があります: 頂点の場合$u$の左側にあります$v$同じレイヤーにあるすべての子$u$のすべての子よりも小さなラベルを持つ必要があります$v$。 これにより、連続するレイヤー間で見たときに非交差構造が強制されます。 

出力は、指定された高さにおけるそのような木の数です。$n$、モジュロ$10^9+7$。 

制約$n \le 5000$ツリーを列挙しようとしたり、サブセットに対して指数関数状態 DP を実行しようとしたりするアプローチは直ちに除外されます。 答えは急速に大きくなるため、組み合わせ再帰または多項式遷移を伴うカタロニア語のような構造が期待されます。 

素朴なアプローチでは、すべての有効な割り当てをチェックしながら、子をレイヤーごとに割り当てようとします。 1層遷移でも分散させようとすると$i$レイヤー内のノード$i+1$の間で$i$レイヤー内のノード$i$、可能性の数は組み合わせ的に増加します。 これを繰り返していきます$n$レイヤーがあるとそれが不可能になります。

## アプローチ

 連続する 2 つのレイヤー間の構造が全体の難しさです。 レイヤーがあります$i$と$i$順序付けされたノードとレイヤー$i+1$と$i+1$順序付けられたノード。 レイヤー内の各ノード$i$0、1、または 2 つの子を持つことができ、前のノードの子は後のノードの子の完全に左側になければなりません。 これは、レイヤー内の各ノードを意味します$i$レイヤー内の連続したブロック (空の可能性がありますが、サイズは最大 2) が割り当てられます$i+1$、これらのブロックは次の層を分割します。 

したがって、各レイヤーの遷移は分割に相当します。$i+1$ポジションをオーダーした$i$順序付けされたグループ。各グループのサイズは 0、1、または 2 で、グループは左から右に順番に表示されます。 問題は、そのような「層間の分布」がいくつ存在するかを数えることと、層間で増殖することになります。 

させて$dp[i]$高さまでの有効な木の数になります$i$。 どのように層を形成するかをカウントする繰り返しが必要です$i$レイヤーを生成できる$i+1$。 各ノードは 0、1、または 2 つの子を提供するため、子の合計は正確に一致する必要があります。$i+1$、の組成を数えています。$i+1$の中へ$i$それぞれのパーツ$\{0,1,2\}$ただし、順序制約はすでに適用されています。 

これはより明確に再解釈できます。 レイヤー内の各ノード$i$層内の 0、1、または 2 つの連続したノードに接続します$i+1$。 左から右にスキャンすると、長さのシーケンスが割り当てられます。$i+1$ここで、各位置は、サイズ 1 または 2 のブロックを開始するか、前の割り当てでカバーされるかを選択します。 これにより、層内のノードの数を決定する DP が得られます。$i$お子様を 2 名使用するか、子供 1 名を何名で使用するか、合計補償範囲が確実に満たされるようにしてください。$i+1$。 

標準的な圧縮では、次のような反復が得られます。$$dp[i+1] = \sum_{k=0}^{\lfloor i/2 \rfloor} \binom{i-k}{k}$$しかし、これを直接計算するのはまだ遅すぎます。$n=5000$。 

より直接的に観察すると、組み合わせ合計を完全に回避できます。 上からレイヤーごとに構築することを検討してください。 各ステップでの構造は、連続するレイヤー間の各エッジに対して、それがシングルリンクであるかダブルリンク拡張の一部であるかを選択することと同じです。 これにより、システムは線形 DP に縮小され、新しいリーフ構造をアタッチするか、前のノードの 2 番目の子を拡張するという 2 つの可能性によって、新しい各レイヤーが前のレイヤーにのみ依存します。 

これにより、単純な繰り返しが得られます。$$dp[i] = dp[i-1] \cdot i + dp[i-2] \cdot (i-1)$$ベースケース付き$dp[1]=1$、$dp[2]=1$。 2 つの用語は、最後の層拡張が単一の子を新しいスロットに挿入することによって形成されるか、または 2 つの連続する位置にまたがるペア構造を形成することによって形成されるかに対応します。

 ## アルゴリズムのチュートリアル

 最後に構築されたレイヤーが次のレイヤーにどのように拡張されるかをキャプチャする再帰を使用して、レイヤーごとに有効な木の数を計算します。 

1.初期化$dp[1] = 1$。 頂点が 1 つでエッジが存在しないツリーが 1 つだけ存在します。 これにより構造が固定されます。 
2.初期化$dp[2] = 1$。 2 つの層の場合、2 番目の層には 1 つのノードがあり、順序制約の下でルートをそれに接続する方法は 1 つだけです。 
3. それぞれについて$i$3から$n$、計算する$dp[i]$以前の構成からの貢献を使用します。 最初の貢献は、有効な高さのツリーをすべて拡張することです$i-1$新しいシングルトン アタッチメントを挿入すると、$dp[i-1] \cdot (i-1)$新しいレイヤーが導入されるため、可能性があります$i-1$注文と一致する可能な取り付け位置。 
4. 2 番目の寄与は、新しい層が 2 つの連続する位置にまたがるペアのアタッチメントを導入し、高さから構造を効果的にマージする構成を説明します。$i-2$。 これは貢献します$dp[i-2] \cdot (i-2)$。 この要因は、使用可能なスロット間でペアの拡張の位置を選択することから発生します。 
5. 両方の寄与を合計し、剰余を取る$10^9+7$。 再帰のオーバーヘッドを避けるために、結果を繰り返し保存します。 

### なぜ効果があるのか

 すべてのステップで、ツリー構造は最後の 2 つのレイヤーがどのように接続されているかによって完全に決定されます。 制約により、レイヤー内の各ノードが次のレイヤーの連続した間隔を占めるように強制されるため、唯一の自由は、拡張機能が 1 つの子を使用するか、2 つの隣接する位置をペア構造にマージするかどうかです。 これら 2 つの可能性は、からの移行に正確に対応します。$i-1$そして$i-2$そして、すべての有効な構成は、最後のそのような選択肢を識別することによって一意に分解されます。 この一意性により、繰り返しによって各有効なツリーが 1 回だけカウントされることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input().strip())
    if n == 1:
        print(1)
        return
    if n == 2:
        print(1)
        return

    dp = [0] * (n + 1)
    dp[1] = 1
    dp[2] = 1

    for i in range(3, n + 1):
        dp[i] = (dp[i - 1] * (i - 1) + dp[i - 2] * (i - 2)) % MOD

    print(dp[n])

if __name__ == "__main__":
    solve()
```コードは繰り返しを直接実装します。 基本ケースは、構造が強制される最小の層を処理します。 ループは小さい高さから上に向かって構築され、各値がすでに計算された状態のみに依存することが保証されます。 乗算$i-1$そして$i-2$最後のレイヤーを拡張するときに導入された有効な接続位置の数を反映します。 

オーバーフローを防ぐために、モジュロはすべてのステップに適用されます。 サイズリストの使用$n+1$メモリ制限内では安全であり、計算は線形です。
