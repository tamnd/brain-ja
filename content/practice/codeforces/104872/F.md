 ## 問題の理解

 私たちに与えられているのは、$n \times n$最初は次の数値の完全な順列を含むグリッド$1$に$n^2$。 元のグリッドの特徴的な特性は、すべての行の合計が同じ値に等しく、すべての列の合計も同じ値に等しいということです。 この構造は 1 回の操作だけで破壊されます。2 つのセルの値が交換されています。 

タスクは、交換された 2 つのセルの座標を特定することです。 これら 2 つの値を元に戻すと、グリッドは再び有効な「マジック」グリッドになり、すべての行の合計と列の合計が等しくなります。 

重要な制約は、$n$最大 1000 まで大きくできるため、グリッドには最大 100 万個のセルが含まれます。 多くのスワップ候補の行または列のプロパティを再計算するソリューションは、グリッド全体で線形時間で効果的に動作する必要があります。 二次関数または偶数$O(n^3)$スワップのシミュレーションは実行できませんが、グリッド上の単一パスに基づくものであれば何でも許容されます。 

微妙な点は、すべての値が個別であるため、各値がその位置を一意に識別することです。 これによりあいまいさがなくなり、行合計の値が間違っている場合でも、一意の場所まで追跡できます。 

もう 1 つの重要な観察は、グリッドが有効な魔方陣とちょうど 2 つのセルだけ異なっていることです。 つまり、すべての構造違反は局所的であり、位置の入れ替えによる影響を除いて、すべての行と列は正しいということです。 

行のみまたは列のみをチェックする必要があると想定すると、単純な失敗ケースが発生します。 行の合計は保持するが列の合計は破棄する、またはその逆のスワップを考えてみましょう。 このような場合、私たちは両方の側面について同時に推論することを余儀なくされます。 

## アプローチ

 直接的な総当たり的なアイデアは、すべてのセルのペアを考慮し、それらを交換し、結果として得られるグリッドが魔法になるかどうかを確認することです。 各ペアについて、すべての行と列の合計コストを再計算します。$O(n^2)$、そして、あります$O(n^4)$ペア。 これにより、天文学的に大きな複雑さが生じます。$O(n^6)$、たとえ小規模であっても完全に実行不可能です。$n$。

 ## アルゴリズムのチュートリアル

 ## アルゴリズムのチュートリアル

 1. 予想されるマジックサムを計算する$S = \frac{n(n^2+1)}{2}$。 グリッドは次の順列であるため、これは正しいグリッドの各行と列が持つべき合計です。$1 \ldots n^2$。 
2. グリッド上の 1 回のパスですべての行の合計を計算します。 合計が異なる行を特定します。$S$。 これらは、交換された要素の 1 つを含む候補行です。 
3. すべての列の合計を同様に計算し、合計が異なる列を特定します。$S$。 これらは、交換された要素を含む候補列です。 
4. 単一のスワップの性質上、ちょうど 2 行とちょうど 2 列が正しくなくなります。 電話してください$r_1, r_2$そして$c_1, c_2$。 これは、交換された各セルが 1 つの行と 1 つの列にのみ影響を与えるためです。 
5. 4 つの交差セルについて考えてみましょう。$(r_1,c_1), (r_1,c_2), (r_2,c_1), (r_2,c_2)$。 これらは、交換された値を含む可能性がある唯一の位置です。 
6. これら 4 つの候補のいずれかのペアの値を交換して、行と列の合計がすべて次と等しくなるかどうかを確認します。$S$。 ちょうど 1 つのスワップがこの条件を満たします。 
7. 有効なペアの座標を出力します。 

### なぜ効果があるのか

 スワップされた各セルは、正確に 1 つの行の合計と 1 つの列の合計に加算誤差をもたらします。 スワップされたセルがちょうど 2 つあるため、影響を受ける行と列の数はそれぞれ 2 つを超えることはできません。また、スワップされた両方のセルが同じ行または列にない限り、2 つ未満にすることはできません。この場合でも、同じ交差ロジックと一致するちょうど 1 つの行または列の不均衡パターンが生成されます。 この制限により、不正な構造はすべて最大 4 つの座標に集中することになり、他のセルは独立して合計に影響を与えることができなくなります。 したがって、元のスワップを一意に回復するには、異常な行と列の交差部分に注意を限定するだけで十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = [list(map(int, input().split())) for _ in range(n)]

    S = n * (n * n + 1) // 2

    row_sum = [0] * n
    col_sum = [0] * n

    for i in range(n):
        for j in range(n):
            v = a[i][j]
            row_sum[i] += v
            col_sum[j] += v

    bad_rows = [i for i in range(n) if row_sum[i] != S]
    bad_cols = [j for j in range(n) if col_sum[j] != S]

    if len(bad_rows) == 1:
        bad_rows.append(bad_rows[0])
    if len(bad_cols) == 1:
        bad_cols.append(bad_cols[0])

    r1, r2 = bad_rows[0], bad_rows[1]
    c1, c2 = bad_cols[0], bad_cols[1]

    def check_swap(x1, y1, x2, y2):
        # simulate swap effect locally by computing affected rows/cols
        rs = row_sum[:]
        cs = col_sum[:]

        v1 = a[x1][y1]
        v2 = a[x2][y2]

        rs[x1] += v2 - v1
        rs[x2] += v1 - v2
        cs[y1] += v2 - v1
        cs[y2] += v1 - v2

        return all(rs[i] == S for i in range(n)) and all(cs[j] == S for j in range(n))

    candidates = [
        (r1, c1, r2, c2),
        (r1, c2, r2, c1)
    ]

    for x1, y1, x2, y2 in candidates:
        if check_swap(x1, y1, x2, y2):
            print(x1 + 1, y1 + 1)
            print(x2 + 1, y2 + 1)
            return

solve()
