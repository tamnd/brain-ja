 ## 解決策
 ## 問題の理解

 2 次元グリッドを通過するレーザー ビームをシミュレートするように求められます。 グリッド内の各セルは空かブロックされています。 ビームは特定の空のセルから開始し、北東、北西、南東、南西の 4 つの方向のいずれかに斜めに移動します。 ビームがブロックされたセルまたはグリッドの端に当たると、単純な反射ルールに従って反射します。垂直の壁に当たると方向の水平成分が反転し、水平の壁に当たると垂直成分が反転し、コーナーに当たると両方が反転します。 私たちの目標は、ビームがサイクルに入る前に通過する空のセルの数を数えることです。 

入力は、グリッドの寸法、ブロックされたセルのリスト、ビームの初期位置と方向で構成されます。 制約はかなり大きく、グリッドは 10^5 × 10^5 までの大きさが可能で、最大 10^5 個のブロックされたセルが存在する可能性があります。 2 秒の制限時間がある場合、ビームを段階的に移動させるブルート フォース シミュレーションでは、最悪の場合、最大 10^10 の操作が実行されますが、これは明らかに実行不可能です。 

微妙なエッジ ケースには、端または角の隣から開始する場合、開始位置のすぐ隣にブロックされたセルがある場合、またはすぐに複数の反射が発生する方向に移動する場合などが含まれます。 たとえば、ビームが (1,1) から開始して北西に移動すると、すぐに上壁と左壁の両方に当たります。 単純なシミュレーションでは、セルが二重にカウントされたり、反射が誤って処理されたりする可能性があります。 もう 1 つの注意が必要なシナリオは、ブロックされたセルによって狭い通路が形成される場合です。ビームがセルに沿って繰り返し反射し、アクセス可能なすべての空のセルに到達する前にサイクルが発生する可能性があります。 サイクルを正しく識別し、無限ループを防ぐことが不可欠です。 

## アプローチ

 単純なアプローチでは、一度に 1 セルずつビームをシミュレートします。 各ステップで、次の対角セルが境界内にあり、ブロックされていないかを確認します。 そうであれば、ビームを移動し、訪問したセルをマークします。 それ以外の場合は、ビームを反射して続行します。 これは小さなグリッドでは機能しますが、ビームが新しいセルに到達せずに O(n*m) ステップを移動する可能性があり、反射ごとに追加のチェックが必要になるため、大きな次元では機能しません。 最大の制約がある場合、このアプローチでは制限時間を超えてしまいます。 

重要な観察は、ビームが常に座標の和または差が一定の線に沿って移動するということです。 北東方向と南西方向の動きは、反射されるまで x + y または x - y の同じ値を維持します。 セルごとに移動する代わりに、境界線またはその対角線に沿った次のブロックされたセルに到達するまでに、ビームが現在の方向に進むことができる最大ステップ数を計算できます。 各対角線に沿ってブロックされたセルのソートされたリストを維持することにより、二分探索を使用して次の障害物を見つけることができます。 各反射は 1 つのイベントとして処理され、イベントの総数はセルの総数ではなく、遭遇した一意の対角線または角の数に比例します。 これにより、実際には複雑さが O(n*m) から O(k log k) に軽減され、実現可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n*m) | O(n*m) | 遅すぎる |
 | 最適 | O(k log k) | O(k) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 入力を解析し、ブロックされたセルを保存します。 ブロックされたセルに対角線でインデックスを付ける 4 つのマップを維持します。1 つは x + y の合計用、もう 1 つは x - y の差用です。 これにより、対角線に沿った次の障害物を素早く調べることができます。 
2. 方向文字列をベクトル (dx, dy) に変換します。 北東は (-1,1)、北西は (-1,-1)、南東は (1,1)、南西は (1,-1) です。 
3. 訪問したセルを保存するセットと状態を保存するセットを初期化します。 状態は (current_x, current_y, dx, dy) によって定義されます。 状態セットは、ビームが以前の構成に戻ったことを認識することで無限ループを防ぎます。 
4. ループ内で、境界線またはその対角線に沿った次のブロックされたセルに到達する前に、現在の方向に沿って実行できる最大ステップ数を確認します。 これは、壁までの距離を計算し、現在のパスで最も近いブロックされたセルの対角マップをクエリすることによって行われます。 
5. ビームをそのステップ数だけ移動し、すべての中間セルを訪問済みとしてマークし、現在の位置を更新します。 
6. ビームが障害物または境界に到達すると、衝突の種類に応じて dx および/または dy を反転してビームを反射します。 
7. 次の反復の前に、現在の状態が以前に確認されたことがあるかどうかを確認します。 その場合は、ビームがサイクルに入ったときにループを解除します。 
8. ループが終了したら、訪問したセルの数をカウントし、結果を出力します。 

機能する理由: 各対角線は、その線に沿って可能な最大の移動を計算するため、セルを見逃すことなく移動されます。 状態追跡を使用すると、サイクルによって無限ループが発生することがなくなります。 セルは最初にアクセスしたときにのみマークされるため、このアルゴリズムでは、到達可能なすべての空のセルが 1 回カウントされることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from bisect import bisect_left, bisect_right
from collections import defaultdict

n, m, k = map(int, input().split())
blocked = set()
diag_sum = defaultdict(list)
diag_diff = defaultdict(list)

for _ in range(k):
    x, y = map(int, input().split())
    blocked.add((x, y))
    diag_sum[x + y].append(x)
    diag_diff[x - y].append(x)

for key in diag_sum:
    diag_sum[key].sort()
for key in diag_diff:
    diag_diff[key].sort()

x, y, dir_str = input().split()
x = int(x)
y = int(y)

dir_map = {'NE': (-1, 1), 'NW': (-1, -1), 'SE': (1, 1), 'SW': (1, -1)}
dx, dy = dir_map[dir_str]

visited = set()
states = set()

while True:
    state = (x, y, dx, dy)
    if state in states:
        break
    states.add(state)
    
    visited.add((x, y))
    
    if dx == -1:
        steps_x = x - 1
    else:
        steps_x = n - x
    if dy == -1:
        steps_y = y - 1
    else:
        steps_y = m - y
    steps = min(steps_x, steps_y)
    
    if dx * dy == 1:
        d = x - y
        lst = diag_diff.get(d, [])
        if dx == 1:
            idx = bisect_right(lst, x)
            if idx < len(lst):
                steps = min(steps, lst[idx] - x - 1)
        else:
            idx = bisect_left(lst, x) - 1
            if idx >= 0:
                steps = min(steps, x - lst[idx] - 1)
    else:
        s = x + y
        lst = diag_sum.get(s, [])
        if dx == 1:
            idx = bisect_right(lst, x)
            if idx < len(lst):
                steps = min(steps, lst[idx] - x - 1)
        else:
            idx = bisect_left(lst, x) - 1
            if idx >= 0:
                steps = min(steps, x - lst[idx] - 1)
    
    x += dx * steps
    y += dy * steps
    
    if x + dx > n or x + dx < 1:
        dx *= -1
    if y + dy > m or y + dy < 1:
        dy *= -1

print(len(visited))
```コードはまず、O(log k) アクセスの対角線に沿ってブロックされたセルを事前計算します。 動きは遮るもののない対角線に沿ったジャンプで計算され、プロセス中に訪問したセルにマークが付けられます。 反射は、次のステップが境界を越えるときに適用されます。 サイクル検出により無限ループを防止します。
