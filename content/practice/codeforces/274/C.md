 ## 解決策
 ## 問題の理解

 平面上にいくつかの点が与えられ、それぞれが円の中心を表します。 これらの円は同時に成長し始め、その半径は時間の経過とともに直線的に増加します。 穴とは、黒い円で完全に囲まれた、接続された白い領域です。 タスクは、平面上に穴が残らない最も早い時間を決定することです。これは、以前に囲まれていたすべての領域が完全に満たされるか、拡大する円に統合されることを意味します。 穴が存在しない場合は、-1 を出力する必要があります。 

入力は円の数を与えます$n$(最大 100) とその座標。 出力は、最後の穴が消える時間を高精度で表す浮動小数点数です。 以来$n$小さい場合、3 次または 2 次の演算$n$許容されます。 課題は、平面をピクセルごとにシミュレートせずに、穴がいつ消えるかを理解し、円の交差点を正確にモデル化することにあります。 

エッジ ケースには、直線上にある点など、円が閉じた領域を決して作成しない構成が含まれます。 たとえば、次の 3 つの点$(0,0)$、$(1,1)$、 そして$(2,2)$閉じた穴が形成されることはないため、出力は -1 になるはずです。 もう 1 つの微妙なケースは、3 つの点が三角形を形成する場合です。3 つの円が外接円の半径で交わるとき、ちょうど三角形の内側の穴が消えます。 

## アプローチ

 ブルートフォースアプローチは、時間の経過に伴う円の成長をシミュレートし、各ステップで穴がないかチェックすることです。 時間値を少しずつサンプリングし、幾何学的な結合演算を使用して黒い領域を追跡し、囲まれたすべての白い領域をマークすることができます。 概念的には正しいものの、この方法は非現実的です。なぜなら、平面上の穴を高精度で検出するには複雑な幾何学的操作が必要であり、何百万回もの反復が必要になる可能性があるためです。$n=100$。 

最適なアプローチは幾何学的洞察に依存します。 穴は、3 つの円の中心によって形成される三角形の内部にのみ存在できます。 重要な観察は、すべての三角形の外接円が成長する円で覆われると穴が消えるということです。 成長する各円の半径は時間に等しいため、最後の穴はすべての三角形の中で最大の外周半径で消えます。 座標幾何学から標準的な公式を使用して、三角形の頂点から外周半径を計算できます。 三角形を形成する 3 つの点がない場合 (すべての点が同一線上にあるか、3 点未満である場合)、穴は存在せず、答えは -1 になります。 

ブルートフォースアプローチは原理的には正しいですが、実行不可能です。 外周半径アプローチが機能するのは、穴が円で囲まれた領域に対応し、穴を含む最小の三角形の外接円が消失時間を決定するためです。

 | ブルートフォースシミュレーション | O(T * n^2) | O(n^2) | 遅すぎる |

 ## アルゴリズムのチュートリアル

 1.すべて読む$n$円の中心を点のリストに追加します。 これは単純なデータ ストレージであり、距離と外周半径を計算するために使用されます。 
2. もし$n < 3$、3 つ未満の点では穴を囲むことができないため、すぐに -1 を出力します。 三角形がないので、囲まれた領域は存在しません。 
3. 変数を初期化する`max_radius`これは、円の中心によって形成されるすべての三角形の中で最大の外周半径を保存します。 
4. 3 つの異なる点のすべての組み合わせを繰り返します。 各トリプレットについて、それらが形成する三角形の面積を計算して、点が同一線上にあるかどうかを確認します。 面積がゼロの場合は、同一線上の点が穴を囲むことができないため、このトリプレットをスキップします。 
5. 同一線上にないトリプレットの場合、外周半径を計算します。$R$公式を使用して: 三角形の辺が次の場合$a, b, c$とエリア$S$、 それから$R = \frac{a b c}{4 S}$。 辺は点間のユークリッド距離を使用して計算されます。 
6.アップデート`max_radius`現在の外周半径が現在の値より大きい場合。 すべてのトリプレットを処理した後、`max_radius`最後の穴が消える正確な時間が含まれています。 
7. もし`max_radius`すべてのトリプレットを処理した後でも 0 が続く場合は、-1 を出力します。 それ以外の場合は、印刷します`max_radius`十分な精度で。 

これが機能する理由: 不変条件は、どの穴も 3 つ以上の円で囲まれ、三角形を形成する必要があるということです。 最後の穴は、円の半径がそれを囲む三角形の外周半径に達すると消えます。 すべての三角形の最大外周半径を計算することで、考えられるすべての穴にわたる最新の消失時間を取得します。 

## Python ソリューション```python
import sys, math
from itertools import combinations
input = sys.stdin.readline

def distance(p1, p2):
    dx = p1[0] - p2[0]
    dy = p1[1] - p2[1]
    return math.hypot(dx, dy)

def triangle_area(a, b, c):
    # Using shoelace formula
    x1, y1 = a
    x2, y2 = b
    x3, y3 = c
    return abs((x1*(y2 - y3) + x2*(y3 - y1) + x3*(y1 - y2)) / 2.0)

def circumradius(a, b, c):
    side_a = distance(b, c)
    side_b = distance(a, c)
    side_c = distance(a, b)
    S = triangle_area(a, b, c)
    if S == 0:
        return 0
    return (side_a * side_b * side_c) / (4 * S)

def main():
    n = int(input())
    points = [tuple(map(int, input().split())) for _ in range(n)]
    
    if n < 3:
        print(-1)
        return
    
    max_radius = 0.0
    for a, b, c in combinations(points, 3):
        R = circumradius(a, b, c)
        max_radius = max(max_radius, R)
    
    if max_radius == 0:
        print(-1)
    else:
        print("{:.10f}".format(max_radius))

if __name__ == "__main__":
    main()
```この解決策は、距離、三角形の面積、外周半径を計算するヘルパー関数を定義することから始まります。 これらは重要な幾何学的プリミティブです。 main 関数は点を読み取り、3 点未満の自明なケースを処理し、すべての点の 3 つ組を反復処理して外周半径を計算します。 小数点以下 10 桁を印刷することで精度が維持されます。 

境界の考慮事項には、面積がゼロになる共線点が含まれるため、その場合、外周半径は無視されます。 組み合わせを使用すると、トリプレットが繰り返されなくなります。 使用距離`math.hypot`数値の安定のために。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

 | スペース | O(n) | ポイントをリストに保存し、中間計算用にいくつかの変数を保存するため、スペースの使用量はポイント数に比例します。 |

 n に対する制約が小さいため、3 次時間計算量は実現可能です。 メモリ使用量は、256 MB の制限に比べればわずかです。
