 ## 解決策
 ## 問題の理解

 次の行列が与えられます。`n`行と`m`列。 各行は元々は降順ではない順序で並べ替えられていましたが、現在は一部のエントリが消去されています（マークが付けられています）。`-1`)、列がシャッフルされている可能性があります。 私たちのタスクは、列の順序を復元して、消去されたエントリを整数で埋め、すべての行を再度ソートできるようにすることです。 出力は、有効な並べ替えを表す列インデックスの順列です。または、`-1`そのような順序が存在しない場合。 

入力制約`1 ≤ n·m ≤ 10^5`これは、せいぜい線形または線形に近い時間アルゴリズムを許容できることを意味します。 二次関数の何か`n·m`遅すぎる可能性があります。 各数値は 32 ビット整数の範囲に収まるため、算術オーバーフローを心配する必要はありません。 

エッジケースは微妙です。 たとえば、列全体が消去された場合、その列はどこにでも収まる可能性があるため、既存の数値のみを比較する単純なアプローチでは、不可能であると誤って宣言される可能性があります。 同様に、一部の行に複数の列に等しい値が含まれている場合、最終的な順序付けで、埋められた数値が行のソートされたプロパティを維持できるようにする必要があります。 

具体的な例は次のとおりです。```
2 2
-1 2
1 -1
```単純な比較では、最初の列が値を取得できることを認識する前に拒否される可能性があります。`0`行 1 ではソートが維持されます。 正しい出力は次のとおりです`2 1`、正確な値ではなく、制約に基づいた慎重な相対順序付けが必要であることを示しています。 

## アプローチ

 ブルートフォースメソッドはすべてを試します`m!`列の順列を確認し、行をソートするために消去されたエントリを埋めることが可能かどうかを順列ごとにチェックします。 これは原理的には正しいですが、実行不可能です。`m!`たとえ`m = 10`。 各順列をチェックするには、すべての行と列を反復処理する必要があります。`O(n·m·m!)`これは私たちの限界をはるかに超えています。 

重要な観察は、問題がトポロジカルな順序付けに帰着するということです。 各行は列間の制約を意味します: 列に数値がある場合`c1`列の数値より大きいです`c2`同じ行にあります(無視します)`-1`)、そして最後の素敵なマトリックスでは、`c1`後に現れる必要があります`c2`。 消去されたエントリの場合は、任意の値を取ることができるため、無視できます。 すべての行を結合して、列の依存関係の有向グラフを構築します。 このグラフに周期がある場合、順序付けはできません。 非巡回の場合、トポロジカル ソートにより有効な列の置換が得られます。 

最適な解決策が機能するのは、塗りつぶされた数値によって課される相対的な順序のみを考慮するためです。 正確な値は必要ないので、問題を階乗時間の順列チェックから線形時間のトポロジカルソートに減らすことができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n・m・m!) | O(n・m) | 遅すぎる |
 | トポロジカルソート | O(n・m) | O(n・m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 隣接リストを初期化する`graph`列と配列の場合`in_degree`入ってくるエッジを追跡します。 これらには、行から派生した列の依存関係が保存されます。 
2. 各行を繰り返し処理します。 入力されたエントリのペアごとに`(c1, c2)`の値が`c1`> の値`c2`、からエッジを追加します`c2`に`c1`グラフで。 これはそれをエンコードします`c2`前に現れる必要があります`c1`。 無視する`-1`エントリ。 
3. すべての行を処理した後、カーンのトポロジカル ソートのアルゴリズムを使用してサイクルをチェックします。 すべての列の入次数が 0 であるキューを初期化します。 
4. キューから列を繰り返し削除し、結果の順列に追加し、その近傍の入次数を減らします。 入力次数が 0 に低下するネイバーをキューに追加します。 
5. すべての列が処理された場合は、結果の順列を出力します。 サイクルによりすべての列を追加できない場合は、出力`-1`。 

機能する理由: すべての有向エッジは、非減少シーケンスを実現するために保持する必要がある行によって暗示される制約を表します。 トポロジカルソートを実行することにより、これらすべての制約を尊重した列の順序が生成されます。 なぜなら`-1`エントリには何の制約も課されず、エントリを無視しても無効にはなりません。 サイクルは、解決できない矛盾した順序を示します。`-1`。 

## Python ソリューション```python
import sys
from collections import deque, defaultdict
input = sys.stdin.readline

n, m = map(int, input().split())
matrix = [list(map(int, input().split())) for _ in range(n)]

graph = [[] for _ in range(m)]
in_degree = [0] * m

for row in matrix:
    filled = [(val, idx) for idx, val in enumerate(row) if val != -1]
    filled.sort()
    for i in range(len(filled) - 1):
        u = filled[i][1]
        v = filled[i + 1][1]
        if filled[i][0] < filled[i + 1][0]:
            graph[u].append(v)
            in_degree[v] += 1

queue = deque([i for i in range(m) if in_degree[i] == 0])
order = []

while queue:
    u = queue.popleft()
    order.append(u + 1)
    for v in graph[u]:
        in_degree[v] -= 1
        if in_degree[v] == 0:
            queue.append(v)

if len(order) < m:
    print(-1)
else:
    print(*order)
```このソリューションでは、まず行ごとに消去されていない数値を収集し、それらを並べ替えて順序付けの制約を特定します。 グラフと次数配列を使用すると、カーンのアルゴリズムが効率的に実装されます。 追加`1`インデックスを使用すると、出力が 1 から始まる要件に一致することが保証されます。 

## 実用的な例

 ### サンプル 1

 入力:```
3 3
1 -1 -1
1 2 1
2 -1 1
```| 行 | 入力済みのエントリ | 並べ替え済み | エッジが追加されました |
 | --- | --- | --- | --- |
 | 1 | [(1,0)] | [(1,0)] | なし |
 | 2 | [(1,0),(2,1),(1,2)] | [(1,0),(1,2),(2,1)] | 0→1、2→1 |
 | 3 | [(2,0),(1,2)] | [(1,2),(2,0)] | 2->0 |

 トポロジカルソートグラフにより列順序が生成される`[3,1,2]`。 

このトレースは、無視していることを示しています`-1`また、厳密に小さい値からエッジを追加するだけで、すべての制約が保持され、有効な置換が可能になります。 

### カスタム入力```
2 2
-1 2
1 -1
```行ごとに入力されたエントリ:`[(1,1)]`、`[(1,0)]`。 厳密な不等式がないため、グラフにはエッジがありません。 任意の順列`[1,2]`または`[2,1]`有効です。 トポロジカルソートの戻り値`[1,2]`。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n・m) | 各行は 1 回スキャンされます。 埋められたエントリの並べ替えは行ごとに最大でも O(m log m) ですが、m ≤ 10^5/n であるため、全体としては線形のままです。 グラフ構築と位相ソートは O(m + n・m) です。 |
 | スペース | O(n・m) | マトリックスと隣接リストを保存します。 次数配列は O(m) です。 |

 この解は、n・m ≤ 10^5 の場合、2 秒の制限内に問題なく収まります。 

## テストケース```python
import sys, io
def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    from collections import deque
    input = sys.stdin.readline
    n, m = map(int, input().split())
    matrix = [list(map(int, input().split())) for _ in range(n)]
    graph = [[] for _ in range(m)]
    in_degree = [0]*m
    for row in matrix:
        filled = [(val, idx) for idx, val in enumerate(row) if val != -1]
        filled.sort()
        for i in range(len(filled)-1):
            u = filled[i][1]
            v = filled[i+1][1]
            if filled[i][0] < filled[i+1][0]:
                graph[u].append(v)
                in_degree[v] += 1
    queue = deque([i for i in range(m) if in_degree[i]==0])
    order=[]
    while queue:
        u=queue.popleft()
        order.append(u+1)
        for v in graph[u]:
            in_degree[v]-=1
            if in_degree[v]==0:
                queue.append(v)
    if len(order)<m:
        return "-1"
    return " ".join(map(str, order))
