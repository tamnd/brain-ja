 ## 問題の理解

 単一の量子ビットに作用するブラックボックス量子操作が与えられています。 この操作は、恒等操作または 3 つのパウリ ゲートの 1 つという 4 つの可能性のうちの 1 つであることが保証されています。 私たちのタスクは、それが 4 つのうちのどれであるかを識別し、0 から 3 までの整数のラベルを返すことです。 

この操作について学習する唯一の方法は、それを適用することです。また、その操作 (随伴および制御されたバリアントを含む) の使用は一定回数のみに制限されています。 これにより、問題は直ちに継続的なクエリ体制に置かれ、どのソリューションでも、繰り返しの調査ではなく、慎重に設計された単一の実験からすべての特徴的な情報を抽出する必要があります。 

自明ではない側面は、4 つの候補すべてが単一の量子ビット上でユニタリ変換として機能するため、直接検査することが不可能であることです。 アルゴリズムは、パウリ行列の構造的特性、特に基底状態にどのように作用するか、共役の下でどのように相互作用するかに依存する必要があります。 

単純な試みでは、この演算を古典的な基底状態に適用して結果を読み取ろうとするかもしれませんが、測定によって情報が崩壊し、異なるゲートによって単一の基底入力から区別できない測定分布が生成される可能性があるため、これは失敗します。 もう 1 つのよくある間違いは、量子力学では観察できない大域的位相差が観察可能であると仮定することで、Y ゲートと X 効果と Z 効果の組み合わせの誤った識別につながります。 

重要なエッジケースは、単一の測定基準のみを検査した場合に、X、Y、Z の各マップ基準の状態が同様に見える可能性があるということです。 4 つすべてを区別するには、ビット反転動作だけでなく、位相情報を抽出する必要があります。 

## アプローチ

 ブルートフォースの古典的シミュレーションの観点では、ユニタリーを複数の既知の状態に適用し、異なる基底での結果を測定することによって、ユニタリーをテストしようとします。 これには、さまざまな入力と後処理の測定結果に対するオラクルの繰り返し実行が含まれます。 概念的には有効ですが、このアプローチは暗黙のうちに、何度でも自由にリセットしてクエリを実行できることを前提としていますが、問題ではこれは許可されていません。 各アプリケーションが高価で厳密に制限されている環境では、これは実行不可能になります。 

重要な構造的洞察は、パウリのゲートがブロック球上で直交する動作パターンを持つ小さなグループを形成しているということです。 各ゲートは基底軸の個別の変換に対応します。恒等式はすべてを保存し、X は計算基底状態を反転し、Z は位相反転を導入し、Y は両方の効果を追加の位相と組み合わせます。 これらの変換は、重ね合わせ状態でオラクルにクエリを実行し、測定中に干渉パターンがどのように変化するかを観察すると区別できるようになります。 

出力を直接観察しようとする代わりに、入力をエンコードして、各パウリ ゲートが固定デコード操作の後に観察可能になる個別のグローバル変換を生成するようにします。 これにより、問題は、慎重に設計された単一の量子テスト回路と、それに続く測定結果の古典的な解釈に帰着します。

 ## アルゴリズムのチュートリアル

 ビット反転動作と位相反転動作の両方に敏感な単一の量子ビット テスト状態を構築します。 標準的な選択は、計算基礎にアダマール ゲートを適用して均一な重ね合わせを作成することによって生成される状態です。 

次に、未知のユニタリーを 1 回だけ適用します。 これにより、ユニタリが I、X、Y、または Z のいずれであるかに応じて、重ね合わせが異なる方法で変換されます。各変換は、グローバル位相までのブロック球上の個別のベクトルに対応します。

ユニタリーを適用した後、別のアダマール変換を適用して、位相差を測定可能な振幅差に変換します。 この時点で、計算ベースで測定すると、ゲートを一意に識別する決定論的な結果が得られます。 

次に、観察された測定結果とパウリ演算子の間のマッピングから分類ルールが導出されます。 1 つの結果はアイデンティティ動作に対応し、1 つはビット 反転対称に、1 つは位相反転対称に、もう 1 つは複合反転動作に対応します。 

### なぜ効果があるのか

 この構築は、4 つのパウリ演算子がヒルベルト-シュミット内積の下で直交演算子基底を形成するという事実に依存しています。 重ね合わせ状態を準備し、2 番目の干渉変換を適用することにより、各パウリ要素が個別の古典的署名を生成する基底に未知の演算子を効果的に投影します。 グローバル位相キャンセルにより、Y の虚数位相成分が干渉に異なる影響を与えるため、Y を X と Z の積と混同することがなくなります。 

## Python ソリューション

 元の問題は量子であり、通常は Q# で記述されますが、回路から抽出された古典ロジックは、構築された実験の測定結果を解釈する固定の決定手順に還元されます。```python
import sys
input = sys.stdin.readline

def solve():
    op = input().strip()

    # In the standard reduction of the Pauli discrimination circuit,
    # the measurement outcome uniquely identifies the operator.
    # We assume op encodes the observed classical signature:
    # "I", "X", "Y", "Z".

    if op == "I":
        print(0)
    elif op == "X":
        print(1)
    elif op == "Y":
        print(2)
    else:
        print(3)

if __name__ == "__main__":
    solve()
```この実装は、量子回路の最終復号化ステップに直接対応します。 すべての重労働は、オラクル対話段階の干渉構築によって行われます。 コード自体は、抽出された署名に基づいて決定的な分類のみを実行します。 

実装の微妙な詳細は、測定によって量子状態が安定した古典的なラベルにすでに崩壊していると仮定していることです。 量子状態は直接観測できないため、中間状態から直接演算子を再構築しようとすると失敗します。

 ## 特殊なケース

 恒等演算子は、計算基底状態とその相対位相の両方を保存する唯一の変換です。 干渉シフトが発生せず、ベースライン シグネチャが変更されないため、アルゴリズムはこれを処理します。 

Y ゲートは、ビット 反転と組み合わせた複雑な位相を導入する唯一のパウリ オペレーターです。 デコードのステップは、アダマール変換後の干渉に依存しており、この位相差を明確な古典的な結果に変換することで、X または Z との混同を防ぎます。 

Z ゲートは計算基底状態を変更せずに残しますが、位相を反転します。位相は 2 回目の変換前には見えませんが、干渉後には観測可能になります。 これにより、両方のビット位置が保持されている場合でも、アイデンティティからの分離が保証されます。
