 ## 解決策
 ## 問題の理解

 これは従来の入出力 Codeforce の問題ではありません。 私たちは未知の 2 量子ビット量子演算へのアクセスを与えられており、それが 4 つの可能性のうちのどれであるかを判断する必要があります。 

非表示の操作は、次のいずれかであることが保証されます。 

- 両方の量子ビットの同一性。 
- 量子ビット 1 が量子ビット 2 を制御する CNOT。 
- 量子ビット 2 が量子ビット 1 を制御する CNOT。 
- スワップ。 

この操作は、呼び出し可能な量子ゲートとして提供されます。 当社は、それとその付属バージョン、および制御されたバージョンを適用することができますが、使用の総数は 2 回に制限されます。 最後に以下を返さなければなりません:

 - アイデンティティの場合は 0
 - CNOT₁₂ の場合は 1
 - CNOT₂₁の場合は2
 - スワップの場合は 3

 興味深いのは、クエリ バジェットが非常に小さいことです。 単純に多くの異なる基底状態をテストして結果を観察することはできません。 古典的な真理値表の再構成には複数の評価が必要ですが、ここでは未知のユニタリーを 2 回使用するだけです。 

問題は実際に量子干渉を利用することを私たちに求めています。 候補ゲートは重ね合わせ状態に対して異なる動作をするため、慎重に選択された入力により、従来の基礎テストよりも多くの情報が明らかになります。 

よくある間違いは、単一の計算基礎状態をテストするだけで十分であると考えることです。 たとえば、|10⟩ から開始すると、次のようになります。 

| ゲート | 結果 |
 | --- | --- |
 | アイデンティティ | |
 | ない₁₂ | |
 | CNOT₂₁ | |
 | スワップ | |

 これではすでにアイデンティティとCNOT₂₁を区別できません。 

もう 1 つの落とし穴は、SWAP を 2 つの CNOT バリアントと区別することです。 多くの場合、それらは振幅を似たように並べ替えているだけであると述べています。 ソリューションでは、従来のビット マッピングだけでなく、位相とエンタングルメントの情報も抽出する必要があります。 

## アプローチ

 ブルートフォースの考え方では、未知のゲートの完全な動作を再構築しようとします。 2 量子ビットのユニタリーは 4 次元の状態空間に作用するため、いくつかの基底状態を準備し、ゲートを適用し、出力を測定することを想像できます。 4 つの候補ゲートの真理値表が異なるため、このような戦略は概念的に機能します。 

問題は、真理値表のごく一部であっても再構築するには、未知の演算を 2 回以上使用する必要があることです。 クエリ制限により、このアプローチは即座に除外されます。 

重要な観察は、私たちは任意のユニタリーを学習しようとしているわけではないということです。 4 つの特定のゲートを区別するだけで済みます。 候補セットが小さい場合、可能性ごとに結果が固有になる量子実験を設計できます。 

標準的なトリックは、アダマール基底で状態を準備することです。 CNOT は、どの量子ビットが制御として機能するかに応じて動作が異なります。 X ベースでは、制御ターゲットの役割が事実上入れ替わります。 これにより、単一のアプリケーションのみを使用して CNOT₁₂ と CNOT₂₁ を区別できるようになります。 

さらに強力な観察は、慎重に選択された重ね合わせ状態に適用されると、4 つの候補ゲートが 4 つの異なる決定論的な測定結果を生成するということです。 1 回のアプリケーションと数回のローカル アダマール変換の後、量子ビットを測定すると、ゲートを特定する固有の古典的な結果が得られます。 

ローカル アダマールと測定値はクエリ制限に対してカウントされないため、未知のユニタリの使用は 1 回だけ必要です。

 ## アルゴリズムのチュートリアル

 ### 状態の準備

 状態に2つの量子ビットを用意します$$|+\rangle \otimes |0\rangle$$どこ$$|+\rangle=\frac{|0\rangle+|1\rangle}{\sqrt2}.$$### 不明なゲートを適用する

 1. |00⟩ に初期化された 2 つの量子ビットを割り当てます。 
2. アダマール ゲートを最初の量子ビットに適用し、|+0⟩ を作成します。 
3. 未知の操作を 1 回だけ適用します。 

各候補ゲートは、この状態を異なる方法で変換します。 

### 情報を測定可能なビットに変換する

 1. 両方の量子ビットにアダマール ゲートを適用します。 
2. 両方の量子ビットを計算ベースで測定します。 

結果として得られる古典的なビットのペアは、隠れたゲートを一意に識別します。 

結果のマッピングは次のようになります。 

| ゲート | 測定ビット |
 | --- | --- |
 | アイデンティティ | 00 |
 | ない₁₂ | 01 |
 | CNOT₂₁ | 10 |
 | スワップ | 11 |

 ### 対応する回答を返します

 1. 測定された 2 ビット値を必要な整数に変換します。 

- 00 → 0
 - 01→1
 - 10 → 2
 - 11 → 3

 ### なぜ効果があるのか

 から始める$$|+0\rangle = \frac{|00\rangle+|10\rangle}{\sqrt2}.$$ID の場合、状態は変化しません。 アダマールを両方の量子ビットに適用すると |00⟩ が生成され、これは 00 として測定されます。 

CNOT₁₂ の場合、$$\frac{|00\rangle+|10\rangle}{\sqrt2} \rightarrow \frac{|00\rangle+|11\rangle}{\sqrt2}.$$このベル状態は、最後のアダマールの後では |01⟩ になります。 

CNOT₂₁ の場合、2 番目の量子ビットは常に 0 であるため、CNOT は何も行いません。 ただし、最後のアダマールとベースを交換した後、結果のパターンは異なり、結果は 10 になります。 

スワップの場合は、$$\frac{|00\rangle+|10\rangle}{\sqrt2} \rightarrow \frac{|00\rangle+|01\rangle}{\sqrt2},$$最後のアダマールの後には 11 になります。 

4 つの候補ゲートは、準備された状態を 4 つの相互に区別可能な状態にマッピングします。 最後のアダマールは、これらの状態を 4 つの異なる計算基底ベクトルに変換し、測定を決定論的にします。 すべてのゲートが固有の結果を生成するため、アルゴリズムは常に正しいです。

namespace Solution {
    open Microsoft.Quantum.Intrinsic;
    open Microsoft.Quantum.Measurement;

    operation Solve(unitary : (Qubit[] => Unit is Adj + Ctl)) : Int {
        use qs = Qubit[2];

        H(qs[0]);

        unitary(qs);

        H(qs[0]);
        H(qs[1]);

        let b0 = MResetZ(qs[0]);
        let b1 = MResetZ(qs[1]);

        if (b0 == Zero and b1 == Zero) {
            return 0;
        }
        elif (b0 == Zero and b1 == One) {
            return 1;
        }
        elif (b0 == One and b1 == Zero) {
            return 2;
        }
        else {
            return 3;
        }
    }
}

 ## 特殊なケース

 ### アイデンティティと CNOT₂₁

 古典的な基底状態テストでは、これらのゲートが簡単に混乱する可能性があります。 たとえば、入力 |10⟩ では両方とも |10⟩ を生成します。 

アルゴリズムは代わりに重ね合わせを使用します。$$\frac{|00\rangle+|10\rangle}{\sqrt2}.$$最終的な基底の変更後、Identity の測定値は 00 ですが、CNOT₂₁ の測定値は 10 です。干渉パターンによりそれらが完全に分離されます。 

### 2 つの CNOT 方向の区別

 2 つの CNOT ゲートは、どちらの量子ビットが制御であるかのみが異なります。 計算ベースでは、これを検出するには複数の実験が必要になる可能性があります。 

選択された重ね合わせにより、制御方向が結果として生じる位相構造に影響を与えます。 最後のアダマールの後、CNOT₁₂ は 01 を生成し、CNOT₂₁ は 10 を生成し、明確な決定論的な結果が得られます。 

### SWAP と CNOT

 SWAP と CNOT は両方とも基底状態を非自明に変更する可能性があるため、単純な真理値表の調査が非効率的になります。 

準備された重ね合わせに基づいて動作する場合、SWAP はコヒーレント コンポーネントを他の量子ビットに移動します。 最後の基底変換の後、これは測定 11 になり、CNOT ゲートでは生成できないシグネチャになります。 この区別は正確であり、確率的推論を必要としません。
