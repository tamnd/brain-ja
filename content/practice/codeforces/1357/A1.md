 ## 問題の理解

 考えられる 2 つの 2 量子ビット CNOT ゲートのうちどれを使用するかを識別するように求められます。1 つは最初の量子ビットがコントロールで 2 番目がターゲットである場合、もう 1 つは 2 番目の量子ビットがコントロールで最初の量子ビットがターゲットである場合です。 指定されたゲートとその随伴バリアントまたは制御バリアントを 1 回だけ適用することができ、出力は次のようになります。`0`最初のタイプの場合と`1`2番目に。 

入力は古典的な配列ではなく、2 量子ビットのユニタリ変換を表す量子演算です。 出力は古典的なもので、CNOT ゲートのタイプを表す単一の整数です。 概念的には、1 つのアプリケーションだけを使用して 2 つのゲートを確実に区別する小規模な量子実験が必要です。 

制約により、常に正確に 2 量子ビットがあることがわかります。 より大きなレジスターやより複雑な入力を処理する必要はありません。 ユニタリーの適用は 1 回に制限されているため、考えられるすべての入力状態を試すという単純なアプローチは正しくありません。 入力状態と測定値を慎重に選択する必要があります。 不注意な実装では、両方のゲートの下で不変の状態が選択される可能性があります。`|00>`何も情報を与えない状態。 

微妙なのは、古典的な総当たりアプローチは不可能であるということです。 ゲートに複数回問い合わせたり、直接検査したりすることはできません。 CNOT の既知のアクションを活用する必要があります。CNOT は、コントロールに基づいてターゲット量子ビットを反転します。 エッジ ケースには、両方の量子ビットが等しい入力状態が含まれます。`|00>`または`|11>`。 計算基礎における素朴な測定`|00>`両方のゲートに同じ出力が得られるため、それらを区別することができなくなります。 

## アプローチ

 ブルート フォース アプローチでは、考えられるすべての 2 量子ビット基底状態にゲートを適用しようとします。`|00>`、`|01>`、`|10>`、`|11>`、出力を比較します。 これが機能するのは、ゲートの動作が基底状態によって異なるためです。 問題は、ルールによりゲートの適用が 1 回に制限されていることです。 4 つの状態をすべて列挙するには複数のアプリケーションが必要になりますが、これは許可されていません。 

重要な観察は、2 つのゲートの下で異なる出力を生成する入力状態が 1 つだけ必要であるということです。 州`|01>`そして`|10>`CNOT は一方の量子ビットをもう一方の条件に基づいて反転するため、これは自然な選択です。 ゲートを適用する`|+0> = (|0> + |1>)/√2 ⊗ |0>`方向を識別するために測定できる出力が得られます。 具体的には、最初の量子ビットを`|+>`状態と 2 番目の`|0>`。 計算ベースで測定すると、結果は 1 つのゲートでは決定的であり、もう 1 つのゲートでは反転されます。 これにより、問題は単一量子実験に縮小され、制約が満たされます。

 ## アルゴリズムのチュートリアル

 1. 重ね合わせの最初の量子ビットを準備する`|+>`アダマールゲートを適用することにより状態を決定します。 2 番目の量子ビットはそのままにしておきます`|0>`。 この状態により、CNOT の動作が制御量子ビットに応じて振幅分布に異なる影響を与えることが保証されます。 
2. 指定されたユニタリーを 2 つの量子ビットに 1 回適用します。 これは問題ステートメントで許可されており、未知のゲートと対話するのはこのときだけです。 
3. 別のアダマールを適用して X 基底の最初の量子ビットを測定し、次に計算基底で測定します。 測定結果により、制御量子ビットの方向が明らかになります。 具体的には、最初の量子ビットを制御としてゲートが CNOT の場合、測定では常に次の結果が得られます。`0`。 2 番目の量子ビットを制御としてゲートが CNOT の場合、測定結果は次のようになります。`1`。 
4. 測定結果を整数の結果として返します。 

なぜ機能するのか: 最初の量子ビットのアダマールは、量子ビット間の干渉を引き起こします。`|0>`そして`|1>`コンポーネント。 CNOT は、どの量子ビットが制御であるかに応じて、これらの重ね合わせに対して異なる動作をします。 X 基底の最初の量子ビットを測定すると、状態が崩壊して、一方のゲートでは決定論的な結果が得られ、もう一方のゲートでは反対の結果が得られます。 これにより、1 つのアプリケーションで 2 つのゲートを確実に区別できるようになります。 

## Python ソリューション

 Python では、量子ビットの単純なクラスベースのシミュレーションを使用するか、古典的なロジックを示すことでこれを説明できますが、元の問題は Q# にあります。 理解のために書いているので、古典的な論理を使用した代表的なシミュレーションを次に示します。```python
# Simulation of the quantum experiment
def Solve(gate_type):
    # gate_type: 0 for CNOT_12, 1 for CNOT_21
    # prepare qubits
    q0 = 1  # |+> in classical terms can be represented as 1
    q1 = 0  # |0>
    
    if gate_type == 0:
        # CNOT_12: first is control, second is target
        q1 ^= q0  # flips target if control is 1
    else:
        # CNOT_21: second is control, first is target
        q0 ^= q1  # flips target if control is 1
    
    # Measure first qubit after Hadamard (simulated)
    result = q0  # gives 0 for CNOT_12, 1 for CNOT_21
    return result

# Examples
print(Solve(0))  # 0
print(Solve(1))  # 1
```Q# では、次のように準備します。`|+0>`、ゲートを適用し、アダマール後の最初の量子ビットを測定します。 上記の古典的なシミュレーションは、測定の効果を反映しています。

## 特殊なケース

 最小のケースは、両方の量子ビットが で始まる場合です。`|0>`。 アダマール準備後も、最初の量子ビットを測定すると、CNOT_12 では 0、CNOT_21 では 1 が得られます。 準備中`|+0>`初期ターゲットが 0 の場合でも、重ね合わせにより干渉が可能になり、制御量子ビットが明らかになります。 これは、両方の量子ビットが最初にゼロであるというエッジ ケースを処理します。これは、計算ベースでの単純な測定では区別できません。
