 ## 問題の理解

 タスクは、適用されると次のような量子操作を実装することです。$P$の倍数で、量子ビットの小さなレジスタに対する完全な量子フーリエ変換 (QFT) の効果を再現します。 入力は整数です$P$2 から 8 までの値と、リトル エンディアン形式の量子レジスタ。各量子ビットは、最下位ビットが先頭となる符号なし整数のビットを表します。 出力は、QFT の根演算を適用した後の量子ビットの変換された状態です。 

制約は量子ビット サイズの点では厳しいですが、計算上は緩やかです。レジスタには最大 7 量子ビットが含まれるため、ヒルベルト空間次元は最大 128 です。これは、実際のシミュレーションでの指数関数的な爆発を心配することなく、演算を QFT に関して明示的に定義できること、および位相回転を介したフラクショナル QFT 演算の構築が実現可能であることを意味します。 以来$P \le 8$完全な QFT を取得するために繰り返し適用する場合、位相角の最大 8 回の乗算が必要となるため、精度の考慮は管理可能です。 

レジスタに量子ビットが 1 つしかない場合、微妙なエッジ ケースが発生します。 単一量子ビットの QFT は単なるアダマール変換であり、その小数乗をとることは、位相回転とブロッホ球上の回転を適用することに対応します。 複数の量子ビットを想定し、条件付き回転を適用する単純なアプローチは、ここでは失敗します。 

もう 1 つの潜在的な落とし穴は、量子ビットの順序です。 リトルエンディアンの順序付けは通常のインデックス付けを反転するため、制御された位相回転はすべて、量子ビットのインデックスからフーリエ基底での重要度への正しいマッピングを適用して適用する必要があります。 エンディアンを混乱させると、間違ったグローバル状態が生成されます。 

## アプローチ

 ブルート フォース アプローチでは、指定された数の量子ビットで QFT の完全なユニタリ行列を計算し、行列を取得しようとします。$P$-th root を計算し、結果として得られるユニタリーを基本ゲートに分解します。 これは理論的には正しいですが、実際には面倒です。たとえ 7 量子ビットであっても、QFT は$128 \times 128$行列と計算$P$-th root は記号的には面倒で、複雑な線形代数が必要になります。 さらに、結果の行列をハードウェアでサポートされるゲートに分解することは簡単ではありません。 

重要な洞察は、QFT がアダマール ゲートと制御された位相回転を使用する単純な再帰的な方法ですでに構造化されていることです。 制御された各回転は次の形式になります。$R_k = \text{diag}(1, e^{2\pi i / 2^k})$。 実装するには$1/P$QFT のパワーを利用すれば、完全なユニタリを対角化する必要はありません。 代わりに、同じ分解を適用しますが、すべての回転角度を次のようにスケールします。$1/P$。 これにより構造が保存されます。このスケーリングされた回転を適用します。$P$回は元の QFT を正確に再構築します。 次のようなライブラリ関数`QFTLE`Q# では完全な QFT を実行でき、角度を適切に調整するか、分数回転で各量子ビットに対して呼び出して変更できます。

 ## アルゴリズムのチュートリアル

 1. 包装を解きます`LittleEndian`基礎となる量子ビットの配列を取得するために登録します。 これにより、各量子ビットを個別にアドレス指定し、正しい順序で回転を適用できるようになります。 
2. 量子ビットの数を決定する$n$レジスターにあります。 これは、QFT のサイズと適用する制御された回転のセットを定義します。 
3. 配列内の各量子ビットに対して、最下位ビットから開始してアダマール ゲートを適用します。 これにより、その量子ビットのフーリエ変換が始まります。 
4. インデックスが増加する (より重要な) 後続の量子ビットごとに、現在の量子ビットとすべてのそれほど重要ではない量子ビットの間で制御された回転を適用します。ただし、回転角度を次の値で割ります。$P$。 具体的には、量子ビットペア (制御$c$、ターゲット$t$）、 適用する$R_k^{1/P}$どこ$k = t - c + 1$。 
5. すべての量子ビットを処理した後、必要に応じてビット反転を実行します。 標準 QFT は量子ビットを交換して順序を修正します。 フラクショナル QFT を実装しているため、同じスワップ パターンで構造が維持されます。 
6. 操作を次のようにマークします。`Adj+Ctl`Q# では、随伴バリアントと制御バリアントが自動的にサポートされます。 

正確性の不変条件は、各回転ゲートがエンコードすることです。$P$元の位相の - 乗根。 このルート操作を適用する$P$は、位相を QFT の完全な回転角度まで乗算して戻し、グローバル位相までの完全な QFT 変換を再現します。 

## Python ソリューション

 問題は Q# にあるため、Python の直接ソリューションでは量子ビットを操作できませんが、古典的な類似物である分数 QFT ユニタリ行列を計算することはできます。 競技プログラミングの目的で、回転角度を生成できます。```python
import sys
import math
input = sys.stdin.readline
import cmath

def fractional_qft(state, p):
    n = len(state)
    N = 1 << n
    new_state = [0]*N
    for k in range(N):
        acc = 0
        for j in range(N):
            angle = 2*math.pi*k*j/(N*p)
            acc += state[j] * cmath.exp(1j*angle)
        new_state[k] = acc / math.sqrt(N)
    return new_state

# example usage
n = 3
state = [1,0,0,0,0,0,0,0]
p = 2
res = fractional_qft(state, p)
for v in res:
    print(abs(v))
```このコードは、古典的なベクトルに QFT を適用する効果を模倣し、位相を次のようにスケールします。`1/p`フラクショナル QFT をモデル化します。 による除算`p`指数にこの演算を適用することで、`p`標準の QFT 行列を再現します。 

## 実用的な例

 入力:`n=2`量子ビット、`p=2`、初期状態`[1,0,0,0]`。 

| ステップ | 操作 | 状態 (大きさ) |
 | --- | --- | --- |
 | 0 | イニシャル | [1,0,0,0] |
 | 1 | 量子ビット 0 上の H | [1/sqrt(2), 1/sqrt(2), 0,0] |
 | 2 | 量子ビット 1 と 0 の間の R_2^(1/2) | [1/sqrt(2), 1/sqrt(2), 0,0] (位相調整済み) |
 | 3 | 量子ビット 1 上の H | 最終状態 |

 これは、回転を次のようにスケーリングすることを示しています。`1/p`正しいフラクショナル QFT が生成されます。 

入力：`n=3`量子ビット、`p=3`、初期状態`[1,0,0,0,0,0,0,0]`完全な QFT を再構築する 3 つのアプリケーションで同様の動作を示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n^2) | 各量子ビットは、制御された回転を介して重要度の低いすべての量子ビットと相互作用し、n*(n-1)/2 の演算を実行します。 |
 | スペース | O(n) | 量子ビット配列のみが保存され、追加の古典的な構造は含まれません。 |

 複雑さは制約内に収まります: n ≤ 7 であるため、操作ごとに制御される回転は最大 21 回であり、量子シミュレーターまたはハードウェアにとっては些細なことです。

 ## 特殊なケース

 単一量子ビットレジスタの場合、`p=2`の場合、アルゴリズムはアダマールを適用し、続いて恒等回転を適用します (制御された回転が存在しないため)。 出力は、予想されるフラクショナル QFT を再現します。 最大レジスタ サイズの場合、制御されるすべての回転は次のようにスケールされます。`1/p`、そして操作を適用する`p`回は完全な QFT 位相を正確に累積し、重要度の低い量子ビットに対する各量子ビットの相対位相が正しいという不変条件を維持します。 アルゴリズムの構造は、当然ながらリトル エンディアンの順序を尊重します。
