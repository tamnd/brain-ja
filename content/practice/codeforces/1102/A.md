 ## 解決策
 ## 問題の理解

 1 から 1 までの整数のシーケンスが与えられます。$n$。 タスクは、このシーケンスを 2 つの素なセットに分割することです。$A$そして$B$したがって、それらの合計間の絶対差は、$|sum(A) - sum(B)|$、できるだけ小さいです。 入力は単一の整数です$n$出力は、この最小の差を表す単一の整数です。 

以来$n$と同じ大きさにすることができます$2 \cdot 10^9$、シーケンスを明示的に構築したり、すべてのパーティションを試したりすることは不可能です。 この制約は、すべてのソリューションが次の点に関して一定時間で実行されなければならないことを意味します。$n$。 反復処理することはできません$n$要素またはサブセットでも$O(n)$時間がかかりすぎて、解決策が必要になる$O(n^2)$それ以上は全く不可能です。 

非自明なエッジケースは、1 から 2 までの数値の合計のパリティから発生します。$n$。 最初の合計$n$自然数は$S = n(n+1)/2$。 もし$S$が偶数である場合、理論的には、シーケンスを等しい合計を持つ 2 つのセットに分割し、最小差が 0 になることが可能です。$S$が奇数の場合、2 つのセットの合計が奇数の合計になる整数になることはできないため、最小の差は 1 でなければなりません。 パリティを無視する単純なソリューションでは、セットを手動で構築しようとする可能性がありますが、大規模なアプリケーションでは遅すぎる可能性があります。$n$。 

## アプローチ

 ブルートフォース手法では、シーケンスのすべてのサブセットを生成し、素セットの各ペアの合計の差を計算しようとします。 すべてのパーティションをチェックすると最小の差が見つかることが保証されるため、このアプローチは原理的に機能します。 ただし、サイズのセットのサブセットの数は$n$は$2^n$。 たとえ控えめでも$n$、 言う$n = 30$、これはすでに10億を超える可能性があります。 のために$n$まで$2 \cdot 10^9$、これはまったく不可能です。 

重要な洞察は、シーケンスが 1 から始まる連続した整数であるということです。$n$数値は次のような単純な式です。$S = n(n+1)/2$。 2 つのパーティション間の絶対差は、次の場合にのみ 0 になります。$S$偶数、または 1 の場合$S$奇数です。 この観察により、セットの構築や反復の必要性がなくなり、問題が計算に軽減されます。$S$そしてそのパリティをチェックします。 ブルートフォース推論により、このショートカットの正しさが検証されます。最小の差は、合計が偶数であるか奇数であるかによってのみ決定されます。

 ## アルゴリズムのチュートリアル

 1. 1 から 1 までのシーケンスの合計を計算します。$n$公式を使って$S = n(n+1)/2$。 この式は等差級数の公式から導出されており、反復を必要としないため、大規模な場合でも実行可能です。$n$。 
2. パリティをチェックします。$S$。 もし$S$は 2 で割り切れるので、和は偶数になります。 それ以外の場合、合計は奇数になります。 
3. 次の場合は 0 を返します。$S$偶数、または 1 の場合$S$奇数です。 これは、可能な最小の絶対差です。 その理由は、偶数の合計はちょうど半分に分割できるのに対し、奇数の合計は整数の合計に分割したときに常に 1 の余りが残るからです。 

これが機能する理由: 合計の公式により合計を正確に取得できることが保証され、パリティ チェックにより正しい最小差が選択されることが保証されます。 シーケンスは連続する整数を厳密に増加させるため、他の分割構成では合計のパリティによって暗示される差よりも小さな差を生成することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
total_sum = n * (n + 1) // 2
if total_sum % 2 == 0:
    print(0)
else:
    print(1)
```コードは単一の整数を読み取ります$n$、浮動小数点エラーを避けるために整数の除算を使用して合計を計算し、モジュロ演算子を使用してパリティをチェックします。 整数除算を使用すると、非常に大きな値の正確性が保証されます。$n$丸め誤差のリスクなし。 条件式は最小の差を直接出力します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    total_sum = n * (n + 1) // 2
    return str(0 if total_sum % 2 == 0 else 1)

# Provided samples
assert run("3\n") == "0", "sample 1"
assert run("4\n") == "0", "sample 2"

# Custom cases

assert run("2\n") == "1", "small even n"
