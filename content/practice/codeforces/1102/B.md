 ## 解決策
 ## 問題の理解

 一連の整数が与えられ、各位置に k 個のラベル (色と呼ぶ) の 1 つを割り当てるように求められます。 すべての位置は正確に 1 つの色を受け取る必要があります。 同時に、1 から k までのすべての色がすべての位置で少なくとも 1 回出現する必要があります。 

さらに構造上の制限が 1 つあります。 固定色に割り当てられた位置だけを見ると、それらの位置のすべての値はペアごとに異なる必要があります。 言い換えれば、各カラー クラス内で同じ値を繰り返すことはできません。 

したがって、タスクは、すべてのグループが空ではなく、各グループに配列値の重複が含まれないように、インデックスを k 個のグループに分散することです。 

n ≤ 5000 および k ≤ n という制約は、O(n²) 個の解がまだ実行可能であることを示唆しています。 三次関数や、サブセットにわたる繰り返しの高価な再計算を伴うものは境界線に達しますが、それでも合格することがあります。 これは建設的な貪欲な問題であるため、目標は数値目標を最適化することではなく、安定した割り当てを見つけることです。 

最初の微妙な失敗例は、ある値が非常に頻繁に出現する場合に発生します。 値が k 回を超えて出現する場合、色内の重複は禁止されているため、有効な解決策ではそれらの出現を別の色に配置する必要があります。 これはすぐに下限を意味します。つまり、値の最大頻度は最大でも k でなければならず、それ以外の場合は色付けが存在しません。 

たとえば、k = 2 で配列が [1, 1, 1] の場合、値 1 が 3 回出現し、それらの位置に 3 つの異なる色が強制されますが、これは不可能です。 周波数を無視する単純な割り当てでは、誤った色付けが生成されます。 

もう 1 つのエッジ ケースは、k が個別の値の数に比べて大きい場合です。 たとえ周波数に問題がないとしても、k 個の空でないグループが必要です。 これにより、競合を回避できたとしても、慎重に色の配分を行う必要があります。 

## アプローチ

 強引な視点は、色を順番に割り当てて、あらゆる可能性を試すことを考えることです。 各位置で、同じ値が含まれていない 1 から k までの任意の色を選択できます。 これにより、各ステップで最大 k の分岐係数が発生し、妥当性を維持するには以前の割り当てをチェックする必要があります。 最悪の場合、これは kⁿ 個の可能性を探索しますが、n = 30 の場合でも完全に実行不可能です。 

重要な構造的観察は、対立は等しい価値観にのみ依存するということです。 異なる価値観は決して相互作用しません。 したがって、各値について、その出現が異なる色に分散されていることを確認するだけで済みます。 これは、同一の値をグループとして処理することを示唆しています。 

次に、インデックスを値で並べ替えることを考えます。 グループ化したら、各値の出現をラウンドロビン方式で色 1 ～ k に分散します。 これにより、同じ色に同じ値が 2 回割り当てられることがないため、単一の色内で値が繰り返されないことが保証されます。 同時に、k 色が使用されていることを確認する場合、最初の k 個の個別の値を慎重に割り当てることで、各色が空でないことを保証できます。 

残る唯一の懸念は実現可能性だ。 値が k 回を超えて出現すると、直ちに失敗します。 それ以外の場合は、すべての値を内部競合なしで配布できます。 

k 色すべてが確実に使用されるようにするには、並べ替えられた要素を反復処理しながら循環的に色を割り当てることができますが、すべての色が少なくとも 1 つの割り当てを受け取るようにする必要があります。 n ≥ k であり、すべての要素に色を割り当てているため、最初の k 個の割り当てで個別の色を強制的に使用するようにするだけで済みます。

 ## アルゴリズムのチュートリアル

 インデックスをその値でソートすることに基づいて貪欲な構築を進めます。

1. インデックスを配列値でグループ化します。 これにより、同じ値を一緒に処理できるようになります。競合は同じ値内でのみ発生するため、これが必要です。 
2. 各値グループについて、そのサイズを確認します。 いずれかのグループのサイズが k より大きい場合は、有効なカラーリングが存在しないと直ちに結論付けます。 これは、同じ値の色を再利用する必要があるためです。 
3. 1 から k までの使用可能な色のリストを準備します。 これらは、循環する色を表します。 
4. グループを反復して要素に色を割り当てます。 各グループ内で、パレットから順番に色を割り当て、必要に応じて折り返します。 ただし、グループ サイズ ≤ k であるため、グループ内で色を繰り返すことはありません。 
5. すべてのグループを割り当てた後、各色が少なくとも 1 回表示されることを確認します。 n ≥ k である限り、色ごとに少なくとも 1 つの要素を配列全体に分散し、割り当てプロセスで色をスキップしないため、これは自然に満たされます。 

重要な考え方は、同じ色に同じ値を 2 回割り当てないこと、および割り当てがパレット全体に広がるため、どの色も未使用のままにしないことです。 

### なぜ効果があるのか

 重要な不変条件は、各値グループを処理した後、どの色にもその値の重複した出現が含まれないということです。 グループは値ごとに互いに素であるため、後のステップで以前に処理された値の競合が再び発生する可能性はありません。 さらに、バランスの取れた周期的な方法で色を割り当てるため、可能な限りすべての色が割り当てを受け取り、k ≤ n の場合に未使用の色が発生するのを防ぎます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    pos = {}
    for i, x in enumerate(a):
        pos.setdefault(x, []).append(i)
    
    # feasibility check
    for x in pos:
        if len(pos[x]) > k:
            print("NO")
            return
    
    res = [0] * n
    
    # assign colors
    color = 1
    for x in pos:
        for idx in pos[x]:
            res[idx] = color
            color += 1
            if color > k:
                color = 1
    
    print("YES")
    print(*res)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず各値をその位置にマッピングする辞書を構築します。 これは、同じ値の重複を一緒にチェックする必要があるという制約を強制するために必要です。 

実現可能性のチェックは重要です。リストがサイズ k を超えた場合、そのグループ内の色の繰り返しを避けることができない割り当ては存在しないため、直ちに停止します。 

色付けステップでは、単一のグローバル循環ポインターを使用します。 これにより、すべての要素にわたって色ができるだけ均等に分配されます。 k でのラップアラウンドにより、色は再利用されますが、サイズが最大 k の単一値グループ内では決して再利用されません。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    pos = {}
    for i, x in enumerate(a):
        pos.setdefault(x, []).append(i)
    
    for x in pos:
        if len(pos[x]) > k:
            return "NO\n"
    
    res = [0] * n
    color = 1
    for x in pos:
        for idx in pos[x]:
            res[idx] = color
            color += 1
            if color > k:
                color = 1
    
    return "YES\n" + " ".join(map(str, res)) + "\n"

 ## 特殊なケース

 すべての要素が同一で、n > k の場合、アルゴリズムは周波数チェックで直ちに失敗します。 たとえば、k = 2 で [5, 5, 5] を入力すると、値 5 が 3 回出現するため、条件がトリガーされます。 チェックでは、割り当てが開始される前にこれを検出するため、無効な循環カラーリングの構築が防止されます。 

すべての要素が異なる場合、グループ化によりシングルトン リストが生成されます。 循環割り当てでは、色を繰り返し処理するだけですが、各値は一意であるため、制約に違反することはありません。 管理する重複がないため、不変式は自明に成立します。
