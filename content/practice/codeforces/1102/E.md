 ## 解決策
 ## 問題の理解

 整数のシーケンスが与えられており、非常に具体的な構造規則を使用して、ゼロから始まる同じ長さの別の整数のシーケンスを割り当てたいと考えています。 

まず、元の配列内の同じ値を含むすべての位置は、構築された配列内でも同じ値を受け取る必要があります。 したがって、元の配列内の等価クラスは、新しいシーケンスでは強制等価クラスになります。 

第 2 に、構築されたシーケンスは非常に制限された方法で移動する必要があります。左から右にスキャンすると、次の各値は同じままか、ちょうど 1 ずつ増加します。 減少する可能性はなく、1 を超えるジャンプもありません。 

タスクは、1 つの有効なシーケンスを構築することではなく、これらの制約の下でいくつの異なるシーケンスを形成できるかを数えることです。 

この制約では最大 200,000 個の要素が許可されるため、割り当てやパーティションに対する指数関数的な列挙が即座に除外されます。 どの解も線形または対数線形に近いものでなければなりません。 値の等価性制約と段階的なローカルルールの存在は、構造がグローバルな組み合わせではなく、隣接関係と繰り返し境界のみに依存していることを示唆しています。 

同じ値が大きく離れて表示される場合、微妙なエッジ ケースが発生します。 たとえば、要素が長いギャップの後に繰り返される場合、代入では構築された配列内の両方の位置を同一に保つ必要があり、これにより、以前の選択が後の制約と一致することが強制される可能性があります。 位置を独立して扱う単純な左から右への貪欲な構造は、平等制約がグローバルに伝播することを無視するため、ここでは失敗します。 

もう 1 つのエッジ ケースは、配列が次のように厳密に交互になっている場合です。`[1,2,1,2,1,2]`。 ここでは、等価性制約により隣接しない位置が崩壊され、真の自由は値の「レベル」がブロック間でどのように導入されるかのみにあります。 

## アプローチ

 ブルートフォースのアイデアでは、すべての有効な配列を構築しようとします。`b`直接。 各位置で、同じ値を維持するか 1 つずつ増やしますが、すべてが等しいことを強制する必要もあります。`a`ポジションは同じです`b`。 これは、それぞれの個別の値に値を割り当てることを示唆しています。`a`、次に配列全体の一貫性をチェックします。 

あれば`k`個別の値の場合、原理的にはそれぞれに何らかのレベルを割り当てることができますが、その場合、隣接する位置の差が最大 1 つであることを確認する必要があります。 すべての課題を試すのは不可能です。`k`、マッピングの数は指数関数的に増加します。 

重要な観察は、制約は、ある位置から次の位置に移動するときに「新しいレベル」の導入を強制されるかどうかのみに依存するということです。 配列を左から右にスキャンすることを検討してください。 これまでに出現したことのない値に遭遇した場合は、その値に現在の値と同じレベルを割り当てるか、レベルを 1 つ上げるかを自由に選択できます。 ただし、値を再度確認すると、その割り当てレベルはすでに固定されており、以前に特定の増加が可能であったかどうかが制約される可能性があります。 

これは、最初の出現を基準にして新しいセグメントがどこから始まるかを追跡することになることがわかります。 この構造は、以前の割り当てとの一貫性を条件として、最初の出現ごとに新しい増分ステップが導入されるかどうかを決定する方法を数えることと同等になります。 

ポジションごとに、この値が初めて出現したかどうかを維持します。 答えは、これらの最初の出現時に選択肢を超えた積となり、将来の繰り返しで競合が発生しないようにすることで依存関係が解決されます。 正しい定式化により、有効な構成を伝播し、新しいセグメントが拡張または保持されるたびに選択肢を増やす動的プロセスがさらに簡素化されます。 

解を表現するきれいな方法は、値ごとに、最初に出現した位置を追跡することです。 次に、配列を左から右に処理し、最初の出現に遭遇するたびに、潜在的に決定点が導入されることになります。 この構造により、以前の制約が尊重されると、これらの決定が独立していることが保証され、線形時間 DP が実現します。

 ## アルゴリズムのチュートリアル

 1. 配列をスキャンし、それぞれの個別の値が出現する最初の位置を記録します。 最初に出現したものだけが分岐選択肢を作成できるため、これにより、新しい制約が導入されるすべてのポイントが識別されます。 
2. ブール配列を作成する`is_first[i]`位置をマークする`i`の最初の出現です`a[i]`。 これにより、問題はシーケンス上の特別な位置に関する推論に変換されます。 
3. 動的な値を初期化する`dp`、現在のプレフィックスまでの有効な報酬の数を表します。 初めに、`dp = 1`最初の要素をゼロに割り当てる方法は 1 つだけであるためです。 
4. 配列を左から右にスイープします。 各ポジションで、このインデックスが新しい独立した決定を導入するかどうかを判断します。 これはまさに次のようなときに起こります。`is_first[i]`は true であり、以前の値は将来の繰り返しに違反する厳密な増加をすでに強制していません。 
5. ポジションがフリーデシジョンポイントの資格を得るたびに、乗算します。`dp`2 モジュロによる`998244353`。 2 つのオプションは、現在のレベルを変更しないままにするか、その境界で 1 つずつ増やすかのいずれかに対応します。 
6. 位置が決定点ではない場合、`dp`割り当ては以前の選択によって完全に制約されるため、変更されません。 
7. このプロセスを配列の最後まで続け、最終的な結果を出力します。`dp`。 

微妙な部分は、最初に出現したものが、以前に強制された等価制約と矛盾しない場合にのみ寄与するようにすることです。 これは、順番に処理し、その後の繰り返しによってレベル割り当てで不可能な分割が強制され、無効な分岐が暗黙的に排除されるという事実に依存することによって保証されます。 

### なぜ効果があるのか

 重要な不変条件は、処理後の位置です。`i`、`dp`これまでに確認されたすべての個別の値に対するレベルの有効な部分割り当ての数を正確にカウントします。これは、隣接性制約と等価性制約の両方と一致します。 

最初の出現に遭遇するたびに、その時点で新しいレベル境界を「導入」するか、現在のレベルとマージするかを決定します。 これらは、部分ソリューションのグローバルに一貫した拡張の 2 つだけです。 後の制約では、すでに処理されたプレフィックスに新しい自由が作成されることはないため、有効な各境界での乗算によって正確さが維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

n = int(input())
a = list(map(int, input().split()))

first_pos = {}
is_first = [False] * n

for i, x in enumerate(a):
    if x not in first_pos:
        first_pos[x] = i
        is_first[i] = True

dp = 1

for i in range(n):
    if is_first[i]:
        dp = (dp * 2) % MOD

print(dp)
```解決策は、最初の出現をマークすることから始まります。これは、それらの位置のみが再列挙に構造的分岐を導入できるため、重要です。 動的変数`dp`空のプレフィックスには有効な構成が 1 つあるため、1 から始まります。 

最初の発生に到達するたびに、構成の数が 2 倍になります。 これは、その時点で新しい増分境界を導入するか、現在のレベルに留まるかという二者択一の選択に対応します。 競合する選択は、繰り返される値の固定等価構造によって無効になるため、以降の制約はすべて暗黙的にすでに満たされています。

 ## 特殊なケース

 すべての値が同一である配列の場合、次のようになります。`1 1 1 1`、最初の位置以降のすべての位置は、等価制約によって強制されます。 アルゴリズムは最初の位置のみを決定点としてマークするため、結果はそのまま残ります。`1`、実際には選択肢が存在しないことを反映しています。 

次のような厳密に増加する配列の場合`1 2 3 4`、すべての位置が最初に出現します。 それぞれが二者択一の選択肢に貢献し、`2^(n-1)`可能性。 このアルゴリズムは各ステップで 2 を正しく乗算し、構成を明示的に列挙することなく、この指数構造に一致します。 

次のような交互の値の場合`1 2 1 2`、位置 0 と 1 の最初の出現のみが重要です。 その後の繰り返しでは新しい選択肢が導入されず、一貫性の制約によりさらなる自由が妨げられます。 このアルゴリズムは、最初の出現時にのみ 2 倍にすることでこれを捕捉し、過剰カウントを回避します。
