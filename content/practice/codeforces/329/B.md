 ## 解決策
 ## 問題の理解

 森を表す長方形のグリッドが与えられます。 一部のセルは木によってブロックされており、1 つのセルには開始位置が含まれています`S`、1 つのセルには出口が含まれます`E`、一部のセルには数字が含まれています。 数字のセルは、最初にそこに立っている他の多くのブリーダーを表します。 

すべてのブリーダーは、私たちが移動を開始する前に、私たちの将来のルート全体を知っています。 彼らはターンごとに 1 歩ずつ移動し、その場で待機し、可能な限り戦闘を強制するために完璧に連携することができます。 ブリーダーが私たちと同じセルに到達すると、戦闘が発生し、そのブリーダーは永久に消滅します。 

私たちの目的は、通過するまでの合計戦闘数を最小限に抑えるルートを選択することです。`E`。 

最初の観察は、移動距離を最小限に抑えようとしていないということです。 それで戦闘が少しでも減るなら、勝手に歩き回ってもいいかもしれない。 課題は、私たちが選んだ道に関係なく、どのブリーダーが面会を強制できるのかを理解することです。 

グリッドには最大でも次のものが含まれます$1000 \times 1000 = 10^6$細胞。 すべてのブリーダーまたはすべての桁セルから独立してグラフ検索を実行するアルゴリズムは、コストが高すぎます。 平$O((rc)^2)$操作は全く不可能です。 セルの数が線形に近いものが必要です。 

最大の難点は、ブリーダーが私たちのルートを事前に知っていることです。 素朴な解釈では、複雑な追跡ゲームを示唆するかもしれませんが、最短経路の構造により、問題は単純なグラフ距離の問題に完全に崩壊します。

```出口前のセルのみを厳密に考慮する不用意な解決策では、このブリーダーを見逃してしまいます。

## アプローチ

 強引な視点は、問題をゲームとして扱うことです。 私たちは完全なルートを選択し、すべてのブリーダーが応答を選択し、衝突が何回発生したかを数えます。 からのパスを列挙することを想像できます。`S`に`E`、ブリーダーの動きをシミュレートし、最適なルートを選択します。 

これはすぐに不可能になります。 小規模なオープン グリッドであっても、有効なルートの数は指数関数的に増加します。 最大 100 万個のセルでは、パス列挙アプローチは絶望的です。 

突破口は、森を最初から見るのではなく、出口から見ることから生まれます。 

すべてのセルからセルまでの最短経路距離を計算するとします。`E`。 させて`dS`からの距離になる`S`に`E`。 

飼育員が監房までの距離にいる場合を考えてみましょう。`E`せいぜい`dS`。 

この後旅の途中でどこかの細胞に着いたら`t`移動すると、そのセルには最大の距離が存在します`dS - t`から`E`。 までの距離のあるブリーダー`E`せいぜい`dS`そのセルに向かって最短経路に沿って移動し、私たちより遅くまでに到着することができます。 ブリーダーは事前に私たちのルートを知っており、いつでも好きなときに待機できるため、そのようなブリーダーは私たちの道のどこかで戦闘を強制する可能性があります。 

ここで、次の距離にあるブリーダーを考えてみましょう。`E`より大きい`dS`。 

私たちがすぐに最短経路をたどり、できるだけ早く去ったとしても、そのブリーダーは到達できません。`E`出発する前に。 最短ルート上のすべてのセルが`E`せいぜい距離がある`dS`、ブリーダーも時間内にそれらのセルのいずれにも到達できません。 そのようなブリーダーは決して面会を強制することはできません。 

つまり、答えはからの距離のみに依存します。`E`。 

からの距離があるすべての桁セル`E`の距離以下である`S`その数字の値が答えに寄与します。 他の人は何も貢献しません。 

次から始まる 1 つの BFS だけが必要です。`E`。

 ## アルゴリズムのチュートリアル

 1. グリッドを読み取り、次の位置を特定します。`S`そして`E`。 
2. 以下から開始して BFS を実行します。`E`。 

非ツリー セルはすべて、出口までの最短距離を受け取ります。 すべての移動のコストは等しいため、BFS は最短パスを正しく計算します。 
3. 開始セルの距離を記録します。`dS`。 

これは、出口に到達するために必要な最小移動数です。 
4. グリッドのすべてのセルをスキャンします。 

セルに数字が含まれている場合は、必ずその BFS 距離を確認してください。 
5. 数字のセルにアクセスできる場合`E`そしてその距離は最大でも`dS`、その数値を答えに追加します。 

そのようなブリーダーは、私たちよりも早く、私たちの最短距離のどこかの地点に到達することができるでしょう。 
6. 累計を出力します。 

### なぜ効果があるのか

 しましょう`d(v)`セルからの最短距離を示します`v`に`E`。 

私たちの最適な戦略は、`S`に`E`、正確に取る`dS = d(S)`動く。 より長いルートはブリーダーに追加の時間を与えるだけです。 

細胞内にいるあらゆるブリーダーにとって`b`と`d(b) ≤ dS`、ブリーダーは最短経路に沿って出口に向かって移動できます。 最短ルートに沿って、`t`私たちが移動するセルの上に立つと、その距離は`E`等しい`dS - t`。 以来`d(b) ≤ dS`、そのルート上には、遅くとも私たちよりも早くブリーダーが到達できる地点が存在します。 ブリーダーさんは事前にこちらのルートを知っていて待ってくれることもあるので、戦闘は避けられません。 

どのブリーダーにとっても、`d(b) > dS`、出口に到達するだけでも、脱出全体よりも時間がかかるでしょう。 最短ルート上のすべてのセルには最大でも距離があるため、`dS`、ブリーダーは時間内にそのようなセルに到達することができません。 戦闘は不可能だ。 

したがって、正確にブリーダーは最大の距離で指のセルに位置します`dS`答えに貢献します。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    r, c = map(int, input().split())
    grid = [list(input().strip()) for _ in range(r)]

    sx = sy = ex = ey = -1

    for i in range(r):
        for j in range(c):
            if grid[i][j] == 'S':
                sx, sy = i, j
            elif grid[i][j] == 'E':
                ex, ey = i, j

    dist = [[-1] * c for _ in range(r)]
    q = deque([(ex, ey)])
    dist[ex][ey] = 0

    dirs = ((1, 0), (-1, 0), (0, 1), (0, -1))

    while q:
        x, y = q.popleft()

        for dx, dy in dirs:
            nx, ny = x + dx, y + dy

            if not (0 <= nx < r and 0 <= ny < c):
                continue
            if grid[nx][ny] == 'T':
                continue
            if dist[nx][ny] != -1:
                continue

            dist[nx][ny] = dist[x][y] + 1
            q.append((nx, ny))

    limit = dist[sx][sy]
    ans = 0

    for i in range(r):
        for j in range(c):
            ch = grid[i][j]

            if ch.isdigit() and dist[i][j] != -1 and dist[i][j] <= limit:
                ans += int(ch)

    print(ans)

solve()
```BFS は、出口から到達可能なすべてのセルまでの最短距離を計算します。 から検索を実行します`E`すべての桁のセルからではなく、最適化が重要です。 

値`limit = dist[sx][sy]`まさに最短の脱出時間です。 この制限よりも出口から遠いブリーダーは、私たちが出発する前に私たちを妨害することはできません。 

条件`dist[i][j] != -1`一部のセルが木によって出口から切り離されている可能性があるため、これが必要です。 そのようなブリーダーは私たちに決して連絡することができず、数えてはなりません。 

グリッドには数字が含まれており、`S`、`E`、 そして`T`。 使用する`ch.isdigit()`ブリーダー セルを明確に識別し、他のシンボルに対する特別な処理を回避します。

import sys
import io
from collections import deque

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    r, c = map(int, input().split())
    grid = [list(input().strip()) for _ in range(r)]

    for i in range(r):
        for j in range(c):
            if grid[i][j] == 'S':
                sx, sy = i, j
            elif grid[i][j] == 'E':
                ex, ey = i, j

    dist = [[-1] * c for _ in range(r)]
    q = deque([(ex, ey)])
    dist[ex][ey] = 0

    while q:
        x, y = q.popleft()

        for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nx, ny = x + dx, y + dy

            if 0 <= nx < r and 0 <= ny < c:
                if grid[nx][ny] != 'T' and dist[nx][ny] == -1:
                    dist[nx][ny] = dist[x][y] + 1
                    q.append((nx, ny))

    limit = dist[sx][sy]
    ans = 0

    for i in range(r):
        for j in range(c):
            if grid[i][j].isdigit():
                if dist[i][j] != -1 and dist[i][j] <= limit:
                    ans += int(grid[i][j])

    return str(ans)
