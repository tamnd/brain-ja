 ## 解決策
 ## 問題の理解

 整数の配列が与えられているので、モジュロ演算を左から右に連続して適用したときに最終結果がゼロにならないように配列の順序を変更できるかどうかを判断する必要があります。 形式的には、順列が必要です$b_1, b_2, \dots, b_n$入力配列の$a_1, a_2, \dots, a_n$そのような$$b_1 \bmod b_2 \bmod \dots \bmod b_n \neq 0$$モジュロ演算は左結合なので、最初に計算します。$b_1 \bmod b_2$、その結果を剰余として取得します$b_3$、 等々。 たとえば、次の場合$b = [2024, 1000, 8]$、評価は$(2024 \bmod 1000) \bmod 8 = 24 \bmod 8 = 0$。 

入力には複数のテスト ケースが含まれています。 各テスト ケースは要素の数を指定します$n$そして配列自体。 制約により、最大で次のことが許可されます。$10^4$テストケースと合計$2 \cdot 10^5$すべてのテスト ケースにわたる要素。 これにより、おおよその解決策よりも悪い解決策は排除されます。$O(n \log n)$テストケースごとに、$O(n^2)$解決策は制限時間を超えてしまう可能性があります。 

配列にすべて同じ数値が含まれている場合、微妙な問題が発生します。 例えば、$[3, 3, 3]$は、順列に関係なく、常に 0 に評価されます。これは、数値のモジュロ自体は 0 であり、0 をモジュロにしたものはすべて 0 のままであるためです。 もう 1 つの注意が必要なシナリオは、配列内の最小の数値が次のような場合です。$1$。 もし$1$が最初に表示される場合、結果は$1 \bmod x$いつもです$1$、後続のモジュロ演算でゼロに減らすことはできません。 したがって、$1$正しく配置されていれば、ゼロ以外の結果が保証される可能性があります。 

## アプローチ

 ブルートフォースアプローチは、すべてを試すことです$n!$配列の順列を計算し、それぞれの連鎖モジュロを評価します。 これは明らかに実行不可能であるため、$n$まで可能です$10^5$。 先頭に最小要素を持つ順列のみを考慮しようとしても、より大きな配列では依然として組み合わせ爆発が起こります。 

重要な洞察は、左結合モジュロ演算が大きい数値と小さい数値の順序に影響されるということです。 具体的には、最初の要素は最大開始剰余を決定します。 最大の要素を最初に配置し、最小の要素を最後に配置すると、中間の剰余が早期にゼロに達しない可能性が最大になります。 あるステップで現在の剰余が次の数値の倍数である場合、この演算ではゼロしか得られないことがわかります。 したがって、配列を非降順で並べ替えると、最初のモジュロ演算は次のようになります。$a_1 \bmod a_2$。 もし$a_1 < a_2$、残りは$a_1$、これは非ゼロです。 数値を減らさないようにすることで、すべての数値が同一でない限り、剰余がすぐにゼロになることはありません。 

したがって、解決策は、配列に複数の個別の値が含まれているかどうかを確認することになります。 すべての要素が等しい場合、答えは「NO」です。 それ以外の場合、配列を非降順でソートすると、連鎖モジュロがゼロ以外の値に評価されることが保証されます。

 | 並べ替え + 個別のチェック | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、要素の数を読み取ります。$n$そして配列$a$。 
2. すべての要素が$a$等しいです。 「はい」の場合、どの順列もゼロになるため、「NO」を出力します。 
3. それ以外の場合は、配列を非降順で並べ替えます。 これにより、最初のモジュロ演算が安全であり、残りが途中でゼロに崩壊することがなくなります。 
4. 有効な順列が存在することを示す場合は、「YES」を出力します。 この問題に対して実際に順列を構築する必要はなく、その存在を確認するだけで済みます。 

機能する理由: 不変条件は、配列に少なくとも 2 つの異なる数値が含まれている場合、それらを非減少順に配置することで、各モジュロ演算後の剰余が確実に保持または削減されますが、すべてが等しい場合を除き、すぐにゼロになることはありません。 最小の数値はシーケンスの先頭または先頭にあるため、すべての数値が等しくない限り、左結合モジュロ チェーンはその数値をゼロに減らすことができません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    if len(set(a)) == 1:
        print("NO")
    else:
        print("YES")
```コードは最初にテスト ケースの数を読み取ります。 テスト ケースごとに、配列を読み取り、個別の要素をカウントするためのセットに変換します。 異なる要素が 1 つだけある場合は、「NO」が出力されます。 それ以外の場合は、「YES」が出力されます。 使用する`set(a)`要素が繰り返される配列を効率的に処理するため、これは非常に重要です。 存在のみを考慮する場合、並べ替えは実​​際には不要です。

## 特殊なケース

 すべて同じ番号を持つ配列は、`set(a)`チェック。 少なくとも 1 つのモジュロ演算で非ゼロの剰余が生成されるため、2 つの異なる数値のみを含む配列が処理されます。 最小の数値が含まれる配列`1`これを最初に配置すると、モジュロチェーンがゼロ以外のままであることが保証されるため、自然に処理されます。 Python は大きな整数をネイティブに処理するため、大きな数値を含む配列は安全です。 このアルゴリズムは、実際の順列の構築には依存せず、少なくとも 2 つの異なる数値を持つという特性のみに依存します。
