 ## 問題の理解

 個別の値の数を数えるように求められます$k$与えられた数値を表現できるように$l$として$l = k \cdot a^x \cdot b^y$負でない整数の場合$x$そして$y$。 言い換えると、$k$の残りの要素です$l$のべき乗を因数分解した後$a$そして$b$あらゆる組み合わせで。 各テスト ケースは 3 つの整数を与えます$a$、$b$、 そして$l$、そして異なる数のカウントを出力する必要があります$k$この分解を満たす値。 

制約が示すのは、$a$そして$b$比較的小さい（$\le 100$） その間$l$まで可能です$10^6$到達できるテストケースの数は$10^4$。 これは、すべての数値を反復する解は次のとおりであることを意味します。$l$遅すぎるでしょう。 の乗法構造のみを調査するアプローチが必要です。$l$効率的に。 

重要な微妙な点が生じるのは、$a$そして$b$同じ素数のべき乗であるか、共通の素因数を共有します。 たとえば、次の場合$a = 4$そして$b = 8$、次に乗算します$a^x \cdot b^y$素因数分解を無視する単純なアプローチでは、二重に数えたり、可能性を見逃したりする可能性があります。 もう 1 つのエッジケースは次のような場合です$l$どちらでも割り切れない$a$または$b$、すぐに得られます$k = l$。 

## アプローチ

 ブルートフォースアプローチでは、すべての非負の累乗を試します。$x$そして$y$そのような$a^x \le l$そして$b^y \le l$、次に計算します$k = l / (a^x \cdot b^y)$分割が正確であれば。 正しいのですが、これには最大で$(\log_a l) \cdot (\log_b l)$テスト ケースごとの反復。小規模な場合には実現可能$l$、ただしコストがかかる可能性があります$t = 10^4$テストケース。 

重要な洞察は、私たちは次の異なる値のみを考慮しているということです。$k$、の約数に対応します。$l$すべての権限を取り除いた後、$a$そして$b$。 これは、次の乗算構造を使用できることを示唆しています。$l$べき乗を効率的に反復するには:

 1. 次のすべての累乗を事前計算します。$a$そして$b$を超えないもの$l$。 
2. すべての組み合わせを乗算します$a^x \cdot b^y$そして分割されるかどうかを確認してください$l$。 もしそうなら、$k = l / (a^x \cdot b^y)$有効です。 
3.ストア$k$自動的に重複排除するセットに含めます。 

これにより、問題は有効なべき乗のみを反復することになり、次の値までのすべての整数を反復するよりもはるかに小さくなります。$l$。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$a$、$b$、 そして$l$。 
2. 空のセットを初期化する`k_values`個別の結果を保存します。 
3. 権限のリストを生成します。$a$を超えないもの$l$。 1 から始めて繰り返し乗算します$a$超えるまで$l$。 保管場所`powers_a`。 
4. 同様に、次のべき乗のリストを生成します。$b$を超えないもの$l$。 保管場所`powers_b`。 
5. それぞれについて$p\_a$で`powers_a`そして$p\_b$で`powers_b`、計算する`product = p_a * p_b`。 もし`l % product == 0`、計算する`k = l // product`そしてそれを追加します`k_values`。 
6. すべての組み合わせがチェックされた後、`k_values`がこのテストケースの答えです。 出力してください。 
7. すべてのテスト ケースに対して繰り返します。 

なぜ機能するのか: 実行可能なすべての累乗を反復することによって、$a$そして$b$を超えずに$l$、あらゆる可能性を保証します$k$と考えられます。 整数除算を使用すると、正確な因数分解のみが寄与し、セットによって重複が削除されます。 このアプローチにより、不可能な組み合わせに対する不必要な反復が回避されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a, b, l = map(int, input().split())
        k_values = set()
        
        powers_a = []
        x = 1
        while x <= l:
            powers_a.append(x)
            if l // x < a:
                break
            x *= a
            
        powers_b = []
        y = 1
        while y <= l:
            powers_b.append(y)
            if l // y < b:
                break
            y *= b
        
        for p_a in powers_a:
            for p_b in powers_b:
                product = p_a * p_b
                if product > l:
                    continue
                if l % product == 0:
                    k_values.add(l // product)
        
        print(len(k_values))

if __name__ == "__main__":
    solve()
```コードはチェックすることで整数のオーバーフローを注意深く防ぎます。`l // x < a`そして`l // y < b`乗算する前に、累乗が次を超えないことを確認します`l`。 セットを使用すると、それぞれをカウントすることが保証されます`k`一度だけ。
