 ## 解決策
 ## 問題の理解

 無向グラフが与えられ、各頂点に集合 {1, 2, 3} から 1 つの値を割り当てるように求められます。 この割り当ては、すべてのエッジが値の合計が奇数となる 2 つの頂点を接続する場合にのみ有効です。 タスクは、998244353 を法として、そのような割り当てがいくつ存在するかを数えることです。 

「合計が奇数」という条件により、どのペアがエッジに現れることができるかが即座に制限されます。 一方の端点が奇数で、もう一方の端点が偶数の場合、合計は奇数になります。 許可されるラベルのうち、1 と 3 は奇数、2 は偶数です。 これにより、問題は 3 つの任意のラベルを扱うことから二分割制約を扱うことに変わります。つまり、すべてのエッジが奇数のラベルが付いた頂点を偶数のラベルが付いた頂点に接続する必要があります。 

したがって、グラフのすべての接続されたコンポーネントは 2 部構成でなければなりません。そうしないと、エッジに沿ってパリティを一貫して割り当てる方法がありません。 

制約は大きく、すべてのテスト ケースにわたって最大 3×10^5 の頂点とエッジが合計されます。 これにより、サイズ n の単一コンポーネントでも 3^n 個の可能性が生じるため、バックトラッキングや割り当ての総当たり列挙を使用して頂点ごとに独立して値を割り当てようとするアプローチは除外されます。 目的のソリューションは、グラフ トラバーサルを使用して、テスト ケースごとに線形またはほぼ線形である必要があります。 

いくつかの特殊なケースが重要です。 

長さ 3 のサイクルなどの三角グラフでは、答えはゼロになります。 たとえば、n=3 のエッジ (1-2、2-3、3-1) です。 パリティを代替しようとする試みは、サイクルに沿って矛盾を強制するため失敗します。 

孤立した頂点は常に有効であり、独立してカウントに影響します。 たとえば、n=1 および m=0 の単一ノード グラフには、有効な割り当てが 3 つあります: {1,2,3}。 

接続されていないグラフでは、異なるコンポーネントへの割り当てが相互作用しないため、コンポーネント間で答えを乗算的に組み合わせる必要があります。 

## アプローチ

 ブルート フォース アプローチでは、各頂点への値 1、2、または 3 の割り当てをすべて試行し、すべてのエッジがパリティ制約を満たすかどうかを確認します。 これには、3^n の代入をチェックし、それぞれを O(m) で検証して O(3^n · m) を与える必要がありますが、これは n が約 20 の場合でも実行不可能です。 

重要な簡素化は、値をパリティ クラスとして解釈することで実現します。 各頂点は奇数 (1 または 3) または偶数 (2) のいずれかです。 エッジ制約はパリティのみに依存し、選択された正確な奇数値には依存しません。 最初にグラフを 2 つのパリティ クラスに分割することを決定すると、各クラス内の割り当てを絞り込むことができます。 

接続された 2 部コンポーネントの場合、パリティを割り当てる有効な方法は 2 つあります。開始ノードを偶数または奇数として選択し、伝播するというものです。 コンポーネントが 2 部構成でない場合、伝播によって矛盾が生じ、答えがゼロになることを意味します。 

パリティが固定されると、奇数に割り当てられた各頂点は独立して 1 または 3 のいずれかになり、奇数側の頂点ごとに 2 つの選択肢が与えられます。 割り当てられたすべての頂点は 2 でなければならず、自由は与えられません。 ただし、各コンポーネントのグローバル パリティの方向を自由に交換でき、どちらの側が奇数であるとみなされるかが反転します。 これは、サイズ a と b の 2 部コンポーネントの場合、有効な割り当ての数は 2^a + 2^b であることを意味します。 

コンポーネントは独立しているため、これらの寄与をすべてのコンポーネントにわたって乗算します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(3^n・m) | O(n + m) | 遅すぎる |
 | DFS + 二部カウンティング | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。

1. グラフの隣接リストを作成します。 この表現が必要なのは、コンポーネントを繰り返し走査することになり、隣接リストによって線形時間走査が可能になるためです。 
2. 各ノードが訪問されない、または 2 つのパリティ カラーのいずれかが割り当てられるカラー配列を維持します。 DFS または BFS を使用して、エッジに沿って交互の色を割り当てます。 
3. 未訪問のノードごとに、トラバーサルを開始し、接続されているコンポーネントを 2 色で色付けしようとします。 走査中に、各カラー クラスに到達するノードの数を数えます。 これにより、コンポーネントの 2 つのパーティションのサイズが得られます。 
4. 走査中に同じ色の 2 つのノードを接続するエッジが見つかった場合、グラフは 2 部ではありません。 その場合、パリティ制約により矛盾が生じるため、有効な代入が存在しないため、すぐに 0 を返します。 
5. 有効なコンポーネントの場合、その寄与を 2^a + 2^b として計算します。ここで、a と b は 2 つのカラー クラスのサイズです。 この値をグローバルな答えに乗算します。 
6. すべてのコンポーネントに対してこの手順を繰り返し、最終積のモジュロ 998244353 を出力します。 

これが機能する理由は、パリティがどのように伝播するかに関係しています。 ノードにパリティが割り当てられると、すべての隣接ノードは反対のパリティを取ることを強制され、この制約はコンポーネント全体に広がります。 これは、各接続コンポーネントが、グローバル方向の選択肢が 2 つだけある 2 部グラフ問題のように動作することを意味します。 向きを固定した後、奇数側の各ノードは 2 つの奇数ラベルから独立して選択しますが、偶数ノードは 2 に固定されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, m = map(int, input().split())
    g = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    color = [-1] * n
    ans = 1

    for i in range(n):
        if color[i] != -1:
            continue

        stack = [i]
        color[i] = 0
        cnt = [0, 0]

        ok = True

        while stack:
            u = stack.pop()
            cnt[color[u]] += 1

            for v in g[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    stack.append(v)
                elif color[v] == color[u]:
                    ok = False

        if not ok:
            return 0

        a, b = cnt[0], cnt[1]

        pow2_a = pow(2, a, MOD)
        pow2_b = pow(2, b, MOD)

        ans = ans * (pow2_a + pow2_b) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```隣接リストの構築により、DFS 中に各エッジを 1 回横断できることが保証されます。 カラー配列は 2 分割の試行をエンコードします。 -1 は未訪問を意味し、0/1 は両側を表します。 

スタックベースの DFS では、n が大きくなる可能性があるため、再帰の深さの問題が回避されます。 各ノードは 1 回処理され、各エッジは 2 回検査されるため、複雑さは線形に保たれます。 

重要な実装の詳細は、走査中に色ごとにノードをカウントすることです。 これにより、どちらの側が「奇妙」であるかについて 2 つの可能な解釈が直接得られます。 奇数とラベル付けされた各頂点には 1 または 3 の 2 つの選択肢があるため、両側の 2 の累乗を別々に計算します。 

競合が見つかった場合は、すぐに 0 を返すことで、不必要な計算が回避されます。 

## 実用的な例

 ### 例 1: シングルエッジ

 入力:

 n=2、エッジ(1-2)

 | ステップ | ノード | 色の割り当て | カウント (0,1) | 紛争 |
 | --- | --- | --- | --- | --- |
 | 開始 | 1 | 0 | (1,0) | いいえ |
 | 訪問 | 2 | 1 | (1,1) | いいえ |

 コンポーネントのサイズは a=1、b=1 です。 

寄与度は 2^1 + 2^1 = 2 + 2 = 4 です。 

最終的な答え: 4.

 これにより、パリティの役割を交換すると、個別の有効な割り当てが生成されることが確認されます。 

### 例 2: 三角形

 入力: 1-2-3-1

 | ステップ | ノード | 色の割り当て | カウント | 紛争 |
 | --- | --- | --- | --- | --- |
 | 開始 | 1 | 0 | (1,0) | いいえ |
 | 訪問 | 2 | 1 | (1,1) | いいえ |
 | 訪問 | 3 | 1 (2 から) ですが、エッジは 3-1 | (2,1) | 衝突 |

 エッジ (3,1) を処理するとき、両方のエンドポイントですでにカラー 0/1 不一致要件が違反されているため、競合が発生します。 

答えは0です。 

これは、非 2 部コンポーネントがグラフ全体を即座に無効にすることを示しています。

 ## 特殊なケース

 孤立した頂点は 1 つのノードのコンポーネントとして扱われます。 DFS はそれに色 0 を割り当て、カウント (1,0) を生成します。 寄与率は 2^1 + 2^0 = 2 + 1 = 3 となり、可能な 3 つのラベルと一致します。 

切断されたグラフはコンポーネントごとに処理され、乗算ステップによりコンポーネント間での割り当ての独立性が確保されます。 

非 2 部サイクルは、DFS 中にすでにカラー化された隣接サイクルがパリティの一貫性に違反する場合に検出されます。 その時点でアルゴリズムは中止され、ゼロが返されるため、不正確な部分的なカウントが防止されます。
