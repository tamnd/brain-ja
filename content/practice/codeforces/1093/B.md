 ## 解決策
 ## 問題の理解

 英語の小文字のみで構成されるいくつかの独立した文字列が与えられます。 各文字列について、その文字を任意の順序に並べ替えることができます。 並べ替えた後、回文ではない文字列を取得できるかどうかを判断するか、文字をどのように並べ替えても、結果として得られる配置はすべて回文であることを報告する必要があります。 

回文は、前から読んでも後ろから読んでも同じ文字列です。 タスクは、すべての順列を構築することではなく、少なくとも 1 つの非回文順列が存在するかどうかを判断することです。 存在する場合は、そのような再配置を出力します。 

制約は小さく、各文字列の長さは最大 1000 で、クエリの数は最大 100 です。 これにより、順列を列挙する試みは即座に排除されます。長さが 10 であっても、順列の数はすでに 360 万であり、1000 の場合は実行不可能だからです。 文字列ごとの線形または線形算術ソリューションで十分です。 

重要な微妙なケースは、文字列にすべて同じ文字が含まれている場合、または文字列の構造が非常に対称的である場合に発生します。 たとえば、文字列が次の場合、`"aaa"`、すべての順列はそのままです`"aaa"`、これは回文です。 同様に、`"aa"`回文以外のものに変更することはできません。 

それほど単純ではないケースは、文字列に複数の異なる文字が含まれているにもかかわらず、すべての置換の下で強制的に回文に変換される場合です。 配置にばらつきがあると非対称が生じるため、これはすべての文字が同一の場合にのみ発生します。 

単純な間違いは、次のような文字列を仮定することです。`"ab"`または`"aba"`同様に行動します。 実際には、`"aba"`に並べ替えることができます`"aab"`または`"baa"`、どちらも回文ではないため、文字列が完全に均一でない限り、常に可能です。 

## アプローチ

 ブルートフォース戦略では、文字列のすべての異なる順列を生成し、それぞれが回文であるかどうかをチェックします。 これは、考えられるすべての再配置の検索空間を徹底的に探索するため、正しいです。 ただし、置換の数は文字列の長さに応じて階乗的に増加するため、繰り返される文字を重複排除しても、長さが 1000 までの場合はこれを実現できません。 

重要な観察は、順列で特別な構造を見つけることは求められておらず、回文を完全に回避することだけを求められているということです。 文字列を非回文にすることが不可能になるのは、すべての再配置が同一である場合、つまりすべての文字が同じ場合にのみ発生します。 その場合、スワップを行っても何も変わりません。 

少なくとも 2 つの異なる文字があれば、いつでも非回文を生成できます。 これを保証する簡単な方法は、文字列を並べ替えることです。 ソートされた文字列がすでに回文ではない場合、作業は完了です。 回文の場合、最後の文字を別の位置に交換すると、少なくとも 2 つの異なる文字が存在するため、対称性が崩れ、常に不一致が発生します。 

したがって、問題は、すべての文字が同一であるかどうかをチェックし、そうでない場合は、すべて同じ文字の場合を除く並べ替えを出力することに帰着します。

 ## アルゴリズムのチュートリアル

 各文字列に対して独立して有効な答えを構築します。 

1. 文字列を読み取り、各文字を最初の文字と比較して、すべての文字が同一かどうかを計算します。 このステップでは、唯一不可能なケースを特定します。 
2. すべての文字が同一の場合、出力`-1`すべての順列は同じ文字列であり、その文字列は回文であるためです。 
3. それ以外の場合は、文字列を辞書編集上の昇順に並べ替えます。 ソートにより、文字の確定的な配置が保証されます。 
4. ミラー位置を比較して、ソートされた文字列が回文であるかどうかを確認します。 
5. 回文でない場合は要件を満たしているのでそのまま出力します。 
6. 回文の場合は、最初の文字をそれとは異なる文字と交換します。 すべての文字が同一であるわけではないため、そのような位置が存在する必要があります。 この交換により非対称性が保証され、非回文文字列が生成されます。 

### なぜ効果があるのか

 すべての順列が回文となる唯一の状況は、すべての文字が等しい場合です。これは、再配置によって均一性が維持されるためです。 少なくとも 2 つの異なる文字が存在する場合、文字が別の位置と異なる位置が少なくとも 1 つ存在する必要があります。 ソートされた配置では同一の文字が集中しており、異なる文字が関与する交換では必然的にある位置でミラー対称性が崩れます。 したがって、その場合には、いつでも非回文順列を構築できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_one(s: str) -> str:
    n = len(s)
    if all(c == s[0] for c in s):
        return "-1"

    s = sorted(s)
    if s != s[::-1]:
        return "".join(s)

    s[0], s[-1] = s[-1], s[0]
    return "".join(s)

def main():
    t = int(input())
    out = []
    for _ in range(t):
        s = input().strip()
        out.append(solve_one(s))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```このソリューションでは、まず、すべての文字が一致するというあり得ない些細なケースを検出します。 並べ替えると、ベースラインの配置が作成されます。 回文チェックにより、次のようなエッジケースで対称文字列を誤って出力することがなくなります。`"aabbaa"`。 対称性が発生した場合、エンドポイントを交換すると、ミラーリングされた位置間で少なくとも 1 つの不一致が保証されます。 

スワップ戦略は安全です。少なくとも 2 つの異なる文字が存在することで、最初と最後の位置がすべての場合に同じになることが保証されるため、両端で対称性を破れば常に十分です。

 ## 特殊なケース

 均一文字の場合は、唯一の真のブロック構成です。 入力用`"zzzz"`、小切手はすぐに返されます`-1`再配置しても文字列が変更されないためです。 

のために`"aabbaa"`、ソートすると回文が得られます。 次に、アルゴリズムはエンドポイントを交換しますが、両方のエンドが同一である可能性があるため、単純な交換は失敗する可能性があります。 正しく実行すると、別の文字の位置がスキャンされ、それと交換され、次のような文字列が生成されます。`"baaaba"`、対称ではありません。 

これにより、ソートによって誤って回文が生成された場合でも、少なくとも 2 つの異なる文字が存在することで、有効な分割操作が常に存在することが保証されます。
