 ## 解決策
 ## 問題の理解

 配列を表す数値のリストが与えられ、要素を 1 つだけ削除できます。 それを削除した後、残りの数値がどのように「広がっているか」を調べます。これは、残っている最大値と最小値の差として定義されます。 

タスクは、この広がりができるだけ小さくなるように削除する単一要素を選択し、達成可能な最小の広がりを出力することです。 

重要な制約は、配列が最大 100,000 要素まで大きくてもよいということです。 これにより、各要素を削除し、削除ごとに線形時間で最小値と最大値を最初から再計算しようとするアプローチは即座に除外されます。$O(n^2)$最悪の場合は動作します。 代わりに、グローバル構造について何かを一度計算して、それを再利用する必要があります。 

極値が複数回発生する場合、微妙なエッジケースが発生します。 たとえば、最小値が複数回出現する場合、出現した 1 つだけを削除しても最小値は変わりません。 最大値についても同様です。 これは、最適な除去が極端な値の 1 つをターゲットとする場合が多いため重要ですが、常にそうとは限りません。 

配列を考慮してください`[1, 100, 100, 100]`。 削除中`1`広がりを与える`100 - 100 = 0`。 削除中`100`広がりを与える`100 - 1 = 99`。 ソートされた順序で最初または最後の要素を削除することのみを考慮する単純なアプローチは、極値の重複を正しく考慮していないと失敗します。 

すべての値が等しい場合、別の特殊なケースが発生します。 この場合、削除してもすべて同じ値が残り、答えはゼロになります。 

## アプローチ

 ブルートフォースのアイデアは単純です。すべてのインデックスについて、その要素の削除をシミュレートし、残りの配列の最小値と最大値を計算し、結果として生じる最小の差を追跡します。 各除去コスト後の最小値と最大値を計算する$O(n)$、そしてすべての人のためにそれを行う$n$ポジション利回り$O(n^2)$。 と$n = 10^5$、これは実現可能な限界をはるかに超えています。 

問題の構造により、より効率的な戦略が可能になります。 不安定性は、残りの要素の最小値と最大値にのみ依存します。 1 つの要素を削除する場合、答えを変えることができるのは 2 つだけです。極値ではないものを削除して最小値と最大値は同じままにするか、極値の 1 つを削除して最小値または最大値を 2 番目に小さい要素または 2 番目に大きい要素にシフトする可能性があります。 

これは、最小値と 2 番目に小さい値、および最大値と 2 番目に大きい値を知る必要があるだけであることを示唆しています。 中間の要素を削除しても、最小値と最大値は変更されないため、結果は変わりません。 現在の最小値を削除すると、新しい最小値は 2 番目の最小値になります。 現在の最大値を削除すると、新しい最大値が 2 番目の最大値になります。 

したがって、最適な答えは、最小値を削除するか、最大値を削除するという 2 つの候補のみから導き出される必要があります。 他の削除では両方の極値がそのまま残るため、範囲を改善することはできません。

 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を 1 回スキャンして、最小値、2 番目に小さい値、最大値、および 2 番目に大きい値を決定します。 これら 4 つの数値は、極端な要素を除去した後に範囲がどのように変化するかを完全に表しています。 
2. 元の範囲を次のように計算します。`max_value - min_value`。 これは、極端ではない要素を削除するか、事実上何も改善しない場合を表します。 
3. 最小限の要素を削除することを検討します。 削除後、残っている最小値が 2 番目に小さい値になるため、結果の範囲は次のようになります。`max_value - second_min`。 
4. 最大要素を削除することを検討します。 削除後、残っている最大値が 2 番目に大きい値になるため、結果の範囲は次のようになります。`second_max - min_value`。 
5. 元の範囲、最小値の削除、および最大値の削除の 3 つの値の最小値を取得します。 これは、要素を 1 つだけ削除した後に達成できる最良の不安定性です。 

### なぜ効果があるのか

 配列の不安定性はその極値のみに依存します。 極端でない要素を削除しても範囲のどちらの端点も変更できないため、結果は改善されません。 極値を削除すると範囲の片側のみが変更され、その側の次の候補値は 2 番目に小さい要素または 2 番目に大きい要素によって一意に決定されます。 有効な削除はすべてこれらのカテゴリのいずれかに分類されるため、これらのケースを徹底的にチェックすることですべての可能性がカバーされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

INF = 10**18

min1 = min2 = INF
max1 = max2 = -INF

for x in a:
    # update smallest and second smallest
    if x < min1:
        min2 = min1
        min1 = x
    elif x < min2:
        min2 = x

    # update largest and second largest
    if x > max1:
        max2 = max1
        max1 = x
    elif x > max2:
        max2 = x

original = max1 - min1
remove_min = max1 - min2
remove_max = max2 - min1

print(min(original, remove_min, remove_max))
```この実装は配列に対して 1 回のパスを実行し、4 つの実行値を維持します。 更新ロジックは、各極値の最適な候補と次善の候補の両方を慎重に保存し、極値が仮説的に削除されたときに、正しい置換値がすでにわかっていることを保証します。 

最後のステップでは、3 つの意味のある構成を評価します。 範囲のどちらの境界も変更できないため、他の削除は明示的に考慮されません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    INF = 10**18

    min1 = min2 = INF
    max1 = max2 = -INF

    for x in a:
        if x < min1:
            min2 = min1
            min1 = x
        elif x < min2:
            min2 = x

        if x > max1:
            max2 = max1
            max1 = x
        elif x > max2:
            max2 = x

    return str(min(max1 - min1, max1 - min2, max2 - min1))

# provided sample
assert run("4\n1 3 3 7\n") == "2"

# all equal
assert run("5\n5 5 5 5 5\n") == "0"

# remove min best case
assert run("4\n1 100 100 100\n") == "0"

# remove max best case
assert run("4\n1 2 3 4\n") == "2"

# minimal size
assert run("2\n1 10\n") == "0"

 ## 特殊なケース

 重要なケースの 1 つは、最小値または最大値が複数回出現する場合です。 入力用`[1, 1, 5, 10]`、1つを削除します`1`最小値は変わらないので、2 番目の最小値はそのままです`1`。 アルゴリズムはこれを処理します。`min2`もなります`1`、 それで`max - min2`範囲の変化がないことを正しく反映します。 

もう 1 つのケースは、最適な手が位置からではなく、値の繰り返しから明らかになる場合です。 で`[1, 2, 3, 4]`、削除`2`または`3`範囲を改善するために何もしませんが、`1`または`4`より小さな範囲が得られます。 このアルゴリズムは、極端な除去のみを評価することでこれを捕捉し、極端でない除去を明示的にテストする必要がないことを保証します。 

最後に、サイズ 2 の配列の場合、1 つの要素を削除すると 1 つの値が残り、不安定性がゼロになります。 どちらの極端な削除も同一の残りのエンドポイントを比較することになるため、式は正しく減少します。
