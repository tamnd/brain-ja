 ## 解決策
 ## 問題の理解

 私たちは与えられています`n`それぞれの頂点に番号が付いている`a_i`書かれていて、最初はエッジがありません。 数値の合計を支払うことで、任意の 2 つの頂点を接続できます。`a_x + a_y`。 さらに、`m`特別オファーでは、特定のエッジを割引価格で追加できます`w`。 目標は、最小の総コストでグラフを接続することです。 

以来`n`最大値が 200,000 である場合、考えられるすべての頂点ペアを直接調べるソリューションは遅すぎます。O(n^2) 操作が必要になるためです。これは、およそ 4 * 10^10 であり、2 秒では実行不可能です。 したがって、問題の構造を活用して、考慮するエッジの数を減らすアプローチが必要です。 頂点の数値は 10^12 に達する可能性があるため、不用意に合計にコストがかかると整数のオーバーフローが懸念されますが、Python は大きな整数をネイティブに処理します。 

明らかではないエッジ ケースには、特別オファーが頂点合計を介して接続するよりも厳密に安価である場合や、複数のコンポーネントを接続するために最も安価な頂点を使用する必要がある状況が含まれます。 たとえば、頂点の場合`[1, 3, 3]`そして特別オファー`(2,3,5)`そして`(1,2,1)`、常に特別オファーを貪欲に使用する単純なアプローチでは、最下位の頂点と他の頂点の組み合わせを無視すると、不正確な合計が生成される可能性があります。 

## アプローチ

 ブルートフォース手法では、すべてが考慮されます。`n*(n-1)/2`頂点間の可能なエッジには、次のいずれかのコストを割り当てます。`a_x + a_y`または、より安価な特別オファーが存在する場合は、クラスカルのアルゴリズムを実行して最小のスパニング ツリーを見つけます。 これは理論的には正しいですが、n=2*10^5 の場合、O(n^2) エッジの生成とソートは、数百億回の演算が必要となるため、遅すぎます。 

これを扱いやすくするための重要な観察は、グラフで 2 つの頂点を接続することです。`x`そして`y`費用`a_x + a_y`コンポーネントを接続する最も安価な方法の 1 つは、常に最小の頂点を関与させることです。`a_i`。 最小値で頂点を考える`a_i`; これを使用するエッジは、より大きな頂点間のエッジよりも潜在的に安価になります。 したがって、n^2 個の可能なエッジをすべて追加する代わりに、すべての頂点をこの最小限の頂点に接続することをシミュレートできます。これには、O(n) 個のエッジのみが必要です。 特別オファーに加えて、O(n + m) 個のエッジを考慮する必要がありますが、これは実現可能です。 

これを最小スパニング ツリー問題として扱い、Disjoint Set Union (DSU) 構造を使用してクラスカルのアルゴリズムを効率的に実装することにより、すべての頂点を接続するための最小コストを計算できます。 O(n + m) 個のエッジとユニオン演算のソートには O((n + m) log(n + m)) 時間がかかりますが、これは許容範囲内です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2 log n) | O(n^2) | 遅すぎる |
 | 最適 | O((n + m) log(n + m)) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最小の頂点を特定します。`a_i`。 この頂点を呼び出します`min_vertex`価値のあるもの`min_value`。 このステップを行う理由は、任意の頂点を`min_vertex`特別オファーで低コストが提供されない限り、最小ではない 2 つの頂点を接続するよりも安くなることが保証されています。 
2. 空のリストを初期化する`edges`。 頂点ごとに`v`等しくない`min_vertex`、エッジを追加します`(min_vertex, v, min_value + a_v)`。 これにより、すべての頂点が最小コストの頂点への安価な潜在的な接続を持つことが保証されます。 
3. 特別オファーを読んでください。 オファーごとに`(x, y, w)`に追加します`edges`。 各特別オファーは数値の合計よりも安くなる可能性があるため、MST で考慮する必要があります。 
4. すべてのエッジをコスト順に並べ替えます。 クラスカルのアルゴリズムでは、サイクルを形成しない利用可能な最も安価なエッジを常に選択できるようにするために、ソートが必要です。 
5. DSU を初期化します。`n`頂点。 コストの高い順にエッジを処理します。 各エッジについて`(u, v, cost)`、 もし`u`そして`v`DSU 内の異なるコンポーネントに属している場合は、それらを結合して追加します`cost`現在の合計に。 すでに接続されているコンポーネントを接続するエッジをスキップします。 
6. すべてのエッジを処理した後の累計は、グラフを接続するための最小コストを表します。 印刷してください。 

機能する理由: すべての MST には、最小限のコストですべてのコンポーネントを接続するエッジが含まれている必要があります。 最小の頂点から他のすべての頂点までのエッジを含めることで、コンポーネント間で潜在的に必要となる接続を最小限のコストで利用できるようにします。 特別オファーは明示的に追加および検討されるため、より安価な接続の機会を逃すことはありません。 DSU は、MST の不変条件を維持し、サイクルを形成しないことを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0]*n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        xroot = self.find(x)
        yroot = self.find(y)
        if xroot == yroot:
            return False
        if self.rank[xroot] < self.rank[yroot]:
            self.parent[xroot] = yroot
        else:
            self.parent[yroot] = xroot
            if self.rank[xroot] == self.rank[yroot]:
                self.rank[xroot] += 1
        return True

def main():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    min_value = min(a)
    min_index = a.index(min_value)

    edges = []
    for i in range(n):
        if i != min_index:
            edges.append((min_value + a[i], min_index, i))

    for _ in range(m):
        x, y, w = map(int, input().split())
        edges.append((w, x-1, y-1))

    edges.sort()
    dsu = DSU(n)
    total_cost = 0
    for cost, u, v in edges:
        if dsu.union(u, v):
            total_cost += cost

    print(total_cost)

if __name__ == "__main__":
    main()
```DSU の実装により、結合操作と検索操作がほぼ一定時間維持されることが保証されます。これは、2*10^5 頂点でのパフォーマンスにとって重要です。 エッジをソートすると、常に最も安価なエッジが次に考慮されることが保証されます。 使用する`min_index`私たちが生成することだけを保証します`n-1`最小頂点からエッジを抽出し、O(n^2) の生成を回避します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O((n + m) log(n + m)) | エッジのソートと結合演算の実行が優先されます。 各結合/検索はほぼ O(1) です。 |
 | スペース | O(n + m) | エッジと DSU の親/ランク配列を保存します。 |

 これは、n, m ≤ 2*10^5 の 2 秒の時間制限内に問題なく収まります。
