 ## 問題の理解

 正の整数が与えられます$n$。 自然数の順序付けされた 4 倍の個数を数えたい$(a, b, c, d)$両方のペアが同じ合計制約を満たすように存在します。$a + b = n$そして$c + d = n$、4 つの数値はすべて次のように厳密に順序付けされます。$a < c < d < b$。 

したがって、次のように考えることができます: の 2 つの異なる分解を選択しています。$n$2つのポジティブな部分に分けられます。 各分解は、1 と 2 の間の分割点の選択に対応します。$n-1$。 1 つの分解から、より小さい要素を次のように取得します。$a$そしてより大きいものは$b$、そして 2 番目の分解から、$c$そして$d$そして、2 番目のペアが数直線上の最初のペアの内側に厳密に存在することが必要です。 

入力サイズの制約は次のとおりです。$n \le 10^9$これにより、すべてのペアの反復が即座に除外されます。$(a, b)$、あるので$O(n)$彼らのうち。 平$O(\sqrt{n})$または$O(n \log n)$有効なペアの構造は単純で純粋に組み合わせであるため、ここではアプローチは不必要に複雑になります。 

微妙なエッジケースは次のような場合です$n$とても小さいです。 のために$n \le 3$、厳密に増加する 4 つの自然数を固定和構造内に当てはめることはできないため、有効な 4 倍数はまったく存在しません。 たとえば、次のようなとき$n = 3$、唯一の分解は$(1, 2)$, したがって、2 つの異なるペアを選択することは不可能です。 

もう一つのエッジケースは、治療を試みる場合です。$a, b, c, d$独立して。 合計制約によりすべての選択肢が補完的な値に緊密に結合されるため、これは無効な構成を過剰にカウントすることにつながります。 

## アプローチ

 すべての有効なペア$(a, b)$と$a + b = n$そして$a < b$を選択することによって一意に決定されます$a$範囲内で$1 \le a < \frac{n}{2}$、 以来$b = n - a$より大きくなければなりません$a$。 これですでに線形構造が得られます。すべての有効なペアが点に対応します。$a$整数行で。 

ここで、4 倍条件にはそのようなペアが 2 つ必要です$(a, b)$そして$(c, d)$、厳密な順序で$a < c < d < b$。 置き換える$b = n - a$そして$d = n - c$、順序は次のようになります。$$a < c < n - c < n - a$$左半分と右半分は対称であり、不等式は純粋に制約に単純化されます。$a$そして$c$：

から$c < n - c$、私たちは得ます$2c < n$、 それで$c < \frac{n}{2}$。 

から$n - c < n - a$、私たちは得ます$a < c$、これはすでに条件の一部です。 

残りの重要な制約は、両方のペアが有効な分解であるため、次のようになります。$$1 \le a < c < \frac{n}{2}, \quad \text{and} \quad b = n - a > c$$条件$c < n - a$と同等です$a + c < n$。 

したがって、問題は整数のペアを数えるということになります。$(a, c)$次のような:$$1 \le a < c, \quad a + c < n, \quad c < \frac{n}{2}$$固定ごとに$c$、有効な$a$値は以下を満たします:$$1 \le a < c \quad \text{and} \quad a < n - c$$それで：$$a \in [1, \min(c-1, n-c-1)]$$したがって、それぞれについて$c$、その範囲に入る整数の数を数え、有効なすべての整数を合計します。$c$。 これにより、問題は次の分割点における単純な算術加算に変換されます。$c = \frac{n}{2}$。 

ブルートフォースアプローチでは、すべてを繰り返すことになります。$a, c$、与える$O(n^2)$、それは不可能です$n = 10^9$。 制約が区分的線形境界に崩壊するという観察により、次の時点で分割することで定数時間で答えを計算できます。$c = \frac{n}{2}$。

 ## アルゴリズムのチュートリアル

 各ペアの小さい要素の観点から問題を書き直します。 有効な各分解は、次の選択に対応します。$a$、 その後$b = n - a$、 と$a < b$。 2 番目のペアも同様に定義されます。$c$そして$d = n - c$。 次に、順序付けを強制し、すべてを制約に変換します。$a$そして$c$。 

### ステップ

 1. コンピューティング$m = \lfloor \frac{n}{2} \rfloor$。 これは、有効なペアの小さい方の要素の最大値です。 どれでも$a$または$c$に横たわらなければなりません$[1, m]$。 
2. 大きい要素のしきい値を修正する$n - c$そしてそれぞれについてそれを観察してください$c$、 有効$a$値は両方よりも厳密に小さい値です$c$そして$n - c$。 これにより、順序付けと合計の実現可能性の両方が保証されます。 
3. それぞれについて$c \in [1, m]$、有効な数を計算します。$a$として$\min(c - 1, n - c - 1)$。 1 を引くと、厳密な不等式が保証されます。 
4.範囲を分割する$c$かどうかに応じて$c \le n - c$か否か。 切り替えは次の時点で発生します。$c = \frac{n}{2}$。 
5. 最初のセグメントでは、$c \le \frac{n}{2}$、制限要因は$c - 1$、したがって、貢献は直線的に増加します。 
6. 2 番目のセグメントでは、$c > \frac{n}{2}$、制限要因は次のようになります。$n - c - 1$、対称的な減少シーケンスを生成します。 
7. 反復の代わりに閉じた形式の式を使用して、両方の算術シーケンスを合計します。 

### なぜ効果があるのか

 すべての有効な 4 つ組は 1 つのペアに正確に対応します$(a, c)$導出された不等式を満たし、そのようなすべてのペアが一意に決定されます。$b$そして$d$。 変換では、重複を導入することなくすべての制約が保持されます。 区分的分割により、ボトルネックが発生する正確なポイントが捕捉されます。$\min(c-1, n-c-1)$したがって、2 つの等差数列を合計すると、すべての有効な構成が 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

m = n // 2

ans = 0

for c in range(1, m + 1):
    ans += min(c - 1, n - c - 1)

print(ans)
```実装は、有効な 2 番目のペアの下位要素ごとに直接削減に従います。$c$の選択肢が何個あるか数えます。$a$有効のままです。 ループは、導出された制約を直接反映する簡単な方法で記述されています。 

重要な繊細さは表現です`min(c - 1, n - c - 1)`。 用語`c - 1`強制する$a < c$、 その間`n - c - 1`強制する$a < n - c$、それを保証します$a + c < n$。 どちらかの境界が欠けていると、2 番目のペアが最初のペアの内側に厳密に収まらない、無効な 4 倍数が過剰にカウントされることになります。

 ## 特殊なケース

 のために$n = 1$、有効なペアがありません$(a, b)$, したがって、4回転は存在しません。 アルゴリズムセット$m = 0$の場合、ループは実行されず、正しく 0 を返します。 

のために$n = 4$、唯一のペアは$(1,3)$したがって、2 つの異なるネストされたペアを選択することは不可能です。 ループオーバー$c$有効な寄与はゼロです。$c - 1$有効な範囲では常に 0 または負の値になります。 

のために$n = 5$、2つのペアがあります$(1,4), (2,3)$、ちょうど 1 つのネストが可能です。 ループは、次の場合に 1 つの有効な選択肢を正しくカウントします。$c = 2$、両方の制約が$a < c$そして$a + c < n$同時にきつくなります。
