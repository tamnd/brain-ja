 ## 解決策
 ## 問題の理解

 N 個の位置に配置される 1 から N までの数字の順序が与えられます。 配列 a をラリーの「理想的なレイアウト」と考えてください。理想的には、位置 i には値 a[i] が必要です。 

ハリーは、同じ値のセット 1 から N を別の順列に並べ替えることができます。 b. 再配置のコストは少し変わった方法で定義されます。つまり、すべてのポジション i について、絶対差 |a[i] − b[i]| を使用して、ハリーの選択がラリーの予想からどれだけ逸脱しているかを測定し、すべてのポジションにわたってこれらの値の最小値を採用します。 ハリーは、この最小値をできるだけ大きくしたいと考えています。 

したがって、タスクは、最悪の場合の近さを最大化しながら、すべての位置を a の優先値から遠ざける順列 b を構築することです。 

制約は N = 10^5 まであり、すべての置換を試行するソリューションや、すべてのスワップをチェックするなどの二次関数さえも直ちに除外されます。 O(N log N) も問題ありませんが不要なので、線形時間で実行される構造が必要です。 

N = 1 の場合、微妙なエッジケースが発生します。可能な順列は 1 つだけであるため、|a1 − b1| であるため、答えは強制的に 0 になります。 は常に 0 です。 

N ≥ 2 の場合、興味深い部分が始まります。 素朴な考えとしては、距離が 0 になるため、a[i] との正確な一致を避けようとすることになります。しかし、正確な一致を避けたとしても、a[i] ± 1 のような近似一致も避けたいと考えます。これは、これらの一致によっても最小値が減少するためです。 

## アプローチ

 構造を無視すると、総当たりアプローチではすべての順列 b が試行され、O(N) でスコアが計算されます。 Nもいるから！ 制約がすべての位置をグローバルに結合するため、バックトラッキングなどのよりスマートな検索に制限しても失敗します。 

重要な観察は、各位置 i が厳密に 1 つの値を禁止していることです。つまり、b[i] = a[i] は絶対最小の寄与 0 を与えるため望ましくないです。そこで、a で定義される対角線上の禁止位置を使用した順列を構築しようとしています。 これは、各インデックスが 1 つの値だけを除外する、古典的な「混乱のような」代入問題になります。 

このように見ると、構造は単純になります。各位置で 1 つの値のみが禁止され、使用可能な値が N 個あるため、割り当てを常に循環的にシフトできます。 すべての要素が異なるインデックスに移動し、すべての値が異なるため、配列 a の循環シフトにより、どの位置も元の値を受け取らないことが保証されます。 

これは、N ≥ 2 の場合、距離 0 を取得する唯一の方法は等価性であり、これを排除したため、常に少なくとも 1 の最小距離を達成できることを意味します。 

また、一般的に 1 よりも優れたものを作ることはできません。 少なくとも 2 の最小距離を強制しようとするとします。そのためには、すべての位置 i が a[i] だけでなく、a[i] − 1 および a[i] + 1 (存在する場合) も避ける必要があります。 境界付近では、1 や N などの値には有効な選択肢がほとんどなく、N が大きく、任意の順列が考慮される場合、全体的には避けられない競合が発生します。 ≥2 で常に成功するきれいな構造は存在せず、最悪の場合、構造により 1 にまで引き下げられます。 

したがって、最適な答えは、N = 1 の場合は 0、それ以外の場合は 1 であり、a に対する固定点を持たない順列を構築するだけで済みます。 

a の単純な巡回シフトにより、これが直接達成されます。

 ## アルゴリズムのチュートリアル

1. 値の元の配置を表す配列 a を読み取ります。 
2. N が 1 に等しい場合、直ちに 0 を出力し、可能な唯一の置換を返します。 再配置によって単一の位置の値が変更されないため、これは強制されます。 
3. a を左に 1 位置シフトして、新しい配列 b を構築します。つまり、各要素は a の次の位置の値を受け取り、最後の位置は最初の要素を受け取ります。 
4. 達成された最小距離として 1 を出力します。 
5. 構築された配列を出力します。 

このシフトが選択される理由は、すべての位置 i が、元々は異なる位置に属していた値を受け取ることが保証されるためです。また、 a のすべての値は別個であるため、等価性は不可能です。 

### なぜ効果があるのか

 この構造では、すべての i < N について、b[i] = a[i+1] であることが保証されます。これは、a のすべての要素が個別であるため、a[i] とは異なります。 同様に、b[N] = a[1]ですが、これも a[N] とは異なります。 したがって、 b[i] = a[i] を満たす位置はないため、すべての絶対差は少なくとも 1 になります。個別の整数間の絶対差は整数であるため、取り得る最小値は正確に 1 になります。これは、N = 1 の場合にのみ 0 が避けられないため、これが最適です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    if n == 1:
        print(0)
        print(a[0])
        return

    b = a[1:] + a[:1]

    print(1)
    print(*b)

if __name__ == "__main__":
    solve()
```この実装は、循環シフトの考え方に直接従っています。 スライス操作 a[1:] + a[:1] は、順列の 1 回転を実行します。 これにより、すべての値が 1 から N の範囲内に 1 回だけ収まることが保証されるため、b は有効になります。 

出力値 1 が固定されるのは、この構造では a[i] と b[i] の間の完全な一致が保証されないためであり、そのため、最小絶対差が 0 に低下することはありません。

 ## 特殊なケース

 N = 1 の場合、アルゴリズムは 0 と単一の値を直接返します。 異なる順列を構築する自由はないため、これが唯一の有効な結果です。 

N ≥ 2 の場合、巡回シフトにより、すべての位置 i の値が元の位置から移動します。 入力がすでにサイクルであるか、高度に構造化されている場合でも、シフトによってすべての i について b[i] ≠ a[i] が保証され、最適な最小距離 1 が強制されます。
