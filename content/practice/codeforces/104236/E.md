 ## 解決策
 ## 問題の理解

 2D 平面上に一連の点が与えられ、それぞれが国立公園内の観測点を表します。 すべてのステーションには、均一な電力レベルを持つ無線デバイスが装備されています。$P$。 この電力によって通信半径が決まります。ユークリッド距離が最大でも 2 つのステーションであれば直接通信できます。$\sqrt{P}$。 メッセージは中間ステーションを介して中継できるため、通信は直接リンクに限定されず、接続性はグラフ理論の意味で定義されます。 

タスクは、可能な限り小さい値を選択することです。$P$すべてのステーションがこの通信ネットワークを介して接続されるようになります。 

再フレーム化すると、ポイント上に完全な重み付きグラフが構築されます。2 つのノード間の重みはユークリッド距離の 2 乗です。 最小のしきい値が必要です$P$最大でも重みのあるエッジのみを保持すると、$P$、結果のグラフが接続されます。 

制約$N \le 500$これは、エッジの完全なペアごとの考慮が実行可能であることを意味します。 せいぜい約$125{,}000$エッジ、つまりアルゴリズム$O(N^2 \log N)$または$O(N^2)$行動は許容されます。 3 次またはそれ以下のものも、最適化された形式でのみ渡されますが、ここでは不要です。 

いくつかの特殊なケースが重要です。 すべての点が同一の場合、接続は必要ないため、答えはゼロになります。 点が 1 つの非常に遠い外れ値を含む線を形成している場合、答えは、絶対的に最も遠い点のペアではなく、可能な限り最適なスパニング構造に沿った必要な単一の最長接続によって決まります。 

単純な間違いは、答えが任意の 2 点間の最大距離であると仮定することです。 たとえば、3 つの点が三角形を形成し、2 つの点は遠く離れているが、両方とも中心点に近い場合、接続は中心を介して達成されるため、最大エッジは直接必要ありません。 

## アプローチ

 問題は基本的に、距離のしきい値以下での接続に関するものです。 の候補値を固定すると、$P$、二乗距離が最大以下の点のペアをすべて接続するグラフを構築できます。$P$をクリックし、グラフが BFS または DSU を使用して接続されているかどうかを確認します。 可能性のあるものを検索すると、正しいですが高価な解決策が得られます。$P$価値観。 

強引なアイデアは次のようになります。すべてのペアごとの二乗距離を計算し、それらを並べ替えて、しきい値を昇順に試し、毎回接続性をチェックします。 最悪の場合、接続性を再計算する可能性があります$O(N)$回、それぞれの費用$O(N^2)$、につながる$O(N^3)$不必要ではありますが、それでも許容できる範囲の行動です。$N=500$高度に最適化されたコードのみで使用されます。 

重要な観察は、グラフが接続されるような最小しきい値を効果的に探しているということです。これはまさに最小スパニング ツリー (MST) の定義です。 二乗距離を重みとして使用して完全なグラフの MST を構築すると、答えは MST の最大エッジ重みになります。 これが機能するのは、MST がすべてのノードを接続する最も安価な方法であり、接続しきい値では少なくともすべての MST エッジが許可されている必要があるためです。 

したがって、しきい値を試す代わりに、Prim のアルゴリズムを使用して MST を直接計算します。$O(N^2)$明示的なエッジストレージを使用せずに密なグラフで距離を維持できるためです。 最終的な答えは、MST で使用される最大のエッジです。

 | --- | --- | --- | --- |

 ## アルゴリズムのチュートリアル

 各点を、エッジの重みがユークリッド距離の二乗である完全接続グラフのノードとして扱います。 

1. 任意のノード（便宜上ノード 0）から開始し、MST に含まれるとしてマークを付けます。 これは、ひとつの駅からつながる構造を構築していくということを表しています。 
2. 配列を維持する`min_dist[i]`ノードからの最小二乗距離を保存する`i`MST 内にすでに存在する任意のノードに送信します。 最初は、これはノード 0 のみから計算されます。 
3. MST にまだ存在しない最小のノードを繰り返し選択します。`min_dist`。 この選択により、利用可能な可能な限り安価な接続を使用して、現在接続されているコンポーネントを常に拡張できるようになります。 
4. このノードを MST に追加し、答えを次の最大値として更新します。`min_dist`選択されたすべてのエッジの間で。 この最大値はスパニング構造内のボトルネック エッジを表すため、追跡されます。 
5. ノードを追加した後、更新します`min_dist`残りのすべてのノードについて、現在の値と新しく追加されたノードまでの距離を比較します。 これにより、`min_dist`現在の部分的な MST と一致します。 
6. すべてのノードが含まれるまで続行します。 最終的な答えは、このプロセス中に選択された最大のエッジの重みです。 

### なぜ効果があるのか

 すべてのステップで、Prim のアルゴリズムは、選択されたノードの現在のセットが、そのセットの可能な総コストが最小のエッジを使用して接続されるという不変条件を維持します。 このコンポーネントをグラフの残りの部分に接続するエッジには、少なくとも現在の重みがなければなりません。`min_dist`選択したノードの。 常にそのような利用可能な最小のエッジを選択するため、最小限のボトルネック スパニング ツリーを効率的に構築できます。 この構造の最大のエッジは、グラフ全体の接続を可能にする最小のしきい値です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    if n == 1:
        print(0)
        return

    in_mst = [False] * n
    min_dist = [10**30] * n

    in_mst[0] = True
    for i in range(1, n):
        dx = pts[i][0] - pts[0][0]
        dy = pts[i][1] - pts[0][1]
        min_dist[i] = dx * dx + dy * dy

    ans = 0

    for _ in range(n - 1):
        v = -1
        best = 10**30
        for i in range(n):
            if not in_mst[i] and min_dist[i] < best:
                best = min_dist[i]
                v = i

        in_mst[v] = True
        ans = max(ans, best)

        for i in range(n):
            if not in_mst[i]:
                dx = pts[i][0] - pts[v][0]
                dy = pts[i][1] - pts[v][1]
                dist = dx * dx + dy * dy
                if dist < min_dist[i]:
                    min_dist[i] = dist

    print(ans)

if __name__ == "__main__":
    solve()
```実装は直接密プリムのアルゴリズムです。 の`min_dist`配列は常に、各外部ノードを現在の MST に接続する最も安価な方法を反映します。 浮動小数点演算を避けるために二乗距離を使用します。$\sqrt{P}$distance は、2 乗値を比較することと同じです。 

微妙な点は、ノード 0 からの距離を正しく初期化することです。 そうしないと、不正確な無限値が生成され、選択ステップが中断されます。 もう 1 つの重要な点は、問題では総コストではなくしきい値が求められるため、選択したエッジの重みを合計するのではなく、その最大値を追跡することです。

 ## 特殊なケース

 単一ステーションの場合、MST にはエッジがないため、アルゴリズムは初期化されます。`ans`ゼロとして返され、すぐに返されます。 選択ループに入ることはありません。これは、接続要件が存在しないという事実と一致します。 

すべての点が一致する場合、計算されたすべての二乗距離はゼロになるため、すべての点が一致します。`min_dist`更新はゼロのままです。 選択された各エッジの重みは 0 であるため、最終的な最大値も 0 となり、予想される出力と一致します。 

遠くにある外れ値が 1 つある場合、アルゴリズムは最初に小さなエッジを持つ近い点の間でクラスターを構築し、最終的には可能な限り最小のリンクを使用して外れ値をそのクラスターに接続します。 すべての中間オプションがすでに使い果たされているため、最終エッジは大きくなければならず、MST はこれをボトルネックとして正確に捕捉します。
