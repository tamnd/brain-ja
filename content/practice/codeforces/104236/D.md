 ## 解決策
 ## 問題の理解

 長方形のグリッドが与えられ、2 人のプレイヤーが 2 つの異なるセルに配置されます。 グリッドには障害物がないため、常に 4 つの基本方向への移動が可能です。 プレイヤーは順番に一度に 1 歩ずつ移動し、移動するたびに隣接するセルに移動する必要があります。 プレイヤーが他のプレイヤーが現在占有しているセルに移動すると、ゲームは直ちに終了し、移動したプレイヤーが勝ちとなります。 

重要な点は、両方のプレイヤーが最適にプレイすることであり、唯一の目的は、誰のターンに応じて勝利を強制するか、負けを回避することです。 初期位置とどのプレイヤーが最初に動くかを考慮して、勝者を決定するように求められます。 

この制約により、グリッドは 2000 x 2000 までの大きさになることができます。これは、ゲーム グラフの考えられるすべての状態をシミュレートしようとするソリューションは遅すぎることを意味します。 単純な状態検索では、位置の各ペアを状態として扱い、最悪の場合、最大約 40 億の状態が得られますが、これは時間とメモリの両方で実行可能な限界をはるかに超えています。 これは、解が状態空間を、おそらく距離に基づいて、より単純な不変量に折りたたむ必要があることを直ちに示唆しています。 

プレイヤー同士が非常に接近している場合、微妙なエッジケースが発生します。 たとえば、それらが隣接している場合、最初のプレイヤーがすぐに勝つことができます。 もう 1 つのエッジ ケースは、両者が長さ 2 のパスで隔てられている場合です。この場合、最初のプレイヤーが対戦相手に到達するか、最初にインターセプトされるかはターン順序によって決まります。 これらのケースは、正確な経路構造よりも、距離と方向転換順序の同等性の方が重要であることを示唆しています。 

## アプローチ

 ブルート フォース アプローチでは、ゲームを状態グラフとしてモデル化します。各状態は両方のプレイヤーの位置とそのターンで構成されます。 各状態から、アクティブなプレーヤーの 4 つの動きすべてを試し、それが勝利につながるかどうかを再帰的に評価します。 これは、巨大な暗黙的なグラフ上の典型的なミニマックス ゲームです。 概念的には正しいですが、状態の数は次のとおりです。$R^2 C^2$, 各プレイヤーは独立してセルを占有し、各遷移は最大 4 つの方向に分岐するためです。 メモ化しても、到達可能な構成の数は依然として 1 秒の制限には多すぎます。 

重要な観察は、両方のプレーヤーが移動力において対称的であり、それらの間のマンハッタンの距離を最小限に抑えようとしているということです。 空のグリッドでは、2 つのセル間の最短経路は正確にマンハッタン距離です。 両方のプレイヤーが最適にプレーする場合、逸脱は会議を遅らせ、立場を悪化させるだけであるため、常にお互いに向かって最短経路に沿って移動します。 

これにより、ゲームは単一の量、つまりプレーヤー間のマンハッタンの距離に縮小されます。 移動するプレイヤーはいつでも相手に近づくことができるため、移動するたびにこの距離は 1 だけ減少します。 プレーヤーのターンで距離が 0 に達すると、ゲームは終了します。これは、プレーヤーがちょうど相手のセルに足を踏み入れたことを意味します。 

そのため、位置を追跡するのではなく、距離を縮めるのに必要な手数と、どのプレイヤーが最終的な手を取るかを追跡するだけです。 これにより、複雑なゲーム状態の問題がパリティ問題に変換されます。

 ## アルゴリズムのチュートリアル

 1. 次の式を使用して 2 人のプレーヤー間のマンハッタン距離を計算します。$D = |r_s - r_c| + |c_s - c_c|$。 これは、一方のプレイヤーが空のグリッドでもう一方のプレイヤーに到達するために必要な最小移動数を表します。 
2. 最適なプレイでは、どちらかのプレーヤーが動くたびに、この距離がちょうど 1 だけ減少することを観察します。 それは、各プレイヤーが常に相手に近づくため、迂回を強いられる障害物がないからである。 
3. ゲームはその手番で正確に終了すると結論付ける$D$、その後から$D$合計移動距離がゼロになり、最後の移動者が相手のセルに足を踏み入れます。 
4. どのプレイヤーが手番をするかを決定します$D$。 最初のプレイヤーがサムの場合、サムは 1、3、5 ターン目と順番に移動します。 クライドが先に動いた場合、代わりにクライドが奇数ターンを占めます。 
5. のパリティを比較します。$D$最初の動きの人のアイデンティティとともに。 もし$D$奇数の場合、最初の動きが最後の動きをします。 もし$D$が偶数の場合、後手が勝ちます。 

### なぜ効果があるのか

 不変条件は、最適なプレイでは両プレイヤーが常にマンハッタンの距離を 1 回の移動につき 1 つずつ減らすことを強制するということです。 対戦相手は最適な動きを反映できるため、遅れたり、より長いパスを選択したりすることにはメリットがありません。 これにより、ゲームは開始からの決定的なカウントダウンに変わります。$D$この場合、残っている唯一の自由度は、どのプレイヤーが最後のデクリメントを取得するかです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    R, C = map(int, input().split())
    rs, cs, rc, cc = map(int, input().split())
    first = input().strip()

    dist = abs(rs - rc) + abs(cs - cc)

    if first == 'S':
        # Sam moves on odd turns
        if dist % 2 == 1:
            print("S")
        else:
            print("C")
    else:
        # Clyde moves on odd turns
        if dist % 2 == 1:
            print("C")
        else:
            print("S")

if __name__ == "__main__":
    solve()
```この実装により、グリッド ゲーム全体が単一のマンハッタン距離の計算とパリティのチェックに短縮されます。 唯一の微妙な部分は、先行者の ID と同等性を正しく調整することです。 よくある間違いは、最初のプレーヤーがサムかクライドかどうかを調整せずに、常に同じパリティに対応すると仮定することです。 コードは、その配置を維持するために開始文字で明示的に分岐します。

 ## 特殊なケース

 プレイヤーが隣接して開始する場合、マンハッタンの距離は 1 です。最初のプレイヤーは相手のセルに直接移動できるため、常にすぐに勝ちます。 アルゴリズムは計算します$D = 1$、1 は奇数であるため、実際のゲームプレイと一致して、先手者に勝ちが割り当てられます。 

2歩離れなど、距離が均等の場合、後手が実質的に最終手を獲得します。 たとえば、サムがスタートして距離が 2 の場合、サムが最初に移動して距離を 1 に減らし、次にクライドが距離を 0 に減らして勝ちます。 パリティ ルールは、ターンをシミュレートすることなく、これを正しく捉えます。 

代わりにクライドが開始すると、パリティ解釈により役割が反転しますが、同じ不変式が保持されます。 計算はグリッドのサイズや形状には依存せず、マンハッタンの距離とターン順序の配置のみに依存します。
