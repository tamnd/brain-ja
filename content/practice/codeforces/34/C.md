 ## 解決策
 ## 問題の理解

 ユーザーが入力した一連のページ番号を印刷用に処理するように求められます。 入力は、次のような、カンマで区切られた正の整数の単一文字列です。`1,2,3,1,1,2,6,6,2`。 一部の番号は、場合によっては非連続で繰り返される場合があります。 私たちの目標は、圧縮された正規表現を生成することです。つまり、連続する番号が範囲にマージされ、重複が削除され、単一のページがダッシュなしで表現されます。 

たとえば、から`1,2,3,1,1,2,6,6,2`重複を削除すると、次のようになります。`1,2,3,6`、その後に連続する数字`1,2,3`に統合されています`1-3`、最終出力を与える`1-3,6`。 

入力には最大 100 個の数値が含まれ、それぞれの数値が 1000 を超えることはありません。これらの制約は、高度に最適化されたデータ構造が必要ないことを意味します。 O(n log n) 個のソリューションであっても、2 秒の制限内で快適に実行されます。 配列を複数回スキャンする単純なアルゴリズムも機能しますが、重複や連続した範囲には注意する必要があります。 

微妙なエッジ ケースには、すべての数値が同じであるシーケンス、ギャップのあるシーケンス、他の数値がインターリーブされた重複したシーケンスが含まれるシーケンスが含まれます。 例えば、`5,5,5`出力する必要があります`5`、 そして`1,3,2`重複排除と並べ替えの後は次のようになります`1-3`出力は昇順である必要があるためです。 実装を不用意に行うと、重複排除を見逃したり、単一の数値の形式が間違ったりする可能性があります。 

## アプローチ

 ブルートフォースアプローチは、入力を反復処理し、各数値を以前のすべての数値と比較して重複を削除し、結果のリストを並べ替えてから、再度反復して連続する数値をマージすることです。 これは指定された制約に対して機能しますが、スキャンと並べ替えを繰り返す必要があります。 最悪の場合の操作数はおよそ`O(n^2)`重複削除プラスの場合`O(n log n)`並べ替えの場合、n ≤ 100 の場合は許容されますが、洗練されていません。 

重要な洞察は、セットを使用して表示された番号を追跡し、リストを使用して挿入順序を保持することで、順序を保持しながら一意性を維持できるということです。 重複排除されたリストを取得したら、連続する番号を結合するのは簡単です。 これにより、冗長な作業が削減され、実装が簡単になり、重複の削除と範囲の書式設定という 2 つの問題が明確に分離されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | n ≤ 100 の場合は受け入れられますが、非効率的です。 
| 最適 | O(n log n) | O(n) | 受け入れられ、清潔でメンテナンス可能 |

 ## アルゴリズムのチュートリアル

 1. カンマで分割し、各部分を整数に変換することにより、入力文字列を解析します。 これにより、入力された順序で整数のリストが得られます。 
2. を維持しながら、このリストを繰り返し処理します。`seen`セット。 各番号について、それが入っていない場合は、`seen`、新しいリストに追加します`unique_pages`そしてそれを追加します`seen`。 これにより、最初の出現順序が保持され、重複が削除されます。 
3. 並べ替え`unique_pages`昇順で。 範囲は順序付けられたシーケンスでのみ意味をなすため、並べ替えが必要です。 
4. 空のリストを初期化する`ranges`そしてポインタ`start`最初の要素で。 2 番目の要素以降、並べ替えられたリストを繰り返し処理します。 各要素について、前の要素と連続している場合は続行します。 連続していない場合は、次のいずれかを追加して現在の範囲を閉じます。`start`または`start-end`に`ranges`をクリックし、現在の要素から新しい範囲を開始します。 
5. ループの後に、同じ方法で最終範囲を追加します。 
6. 参加する`ranges`カンマでリストして印刷します。 これにより、要求された正規形式が生成されます。 

なぜ効果があるのか​​: あらゆる段階で、`unique_pages`各数値が 1 回だけ含まれており、リストはソートされています。 連続するすべてのシーケンスは 1 つの範囲にマージされますが、連続しない数値は自然に個別の範囲を形成します。 不変条件とは、`ranges`常に、これまでに確認されたすべての数値をカバーする適切にフォーマットされた範囲が含まれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

pages = list(map(int, input().strip().split(',')))

seen = set()
unique_pages = []
for p in pages:
    if p not in seen:
        unique_pages.append(p)
        seen.add(p)

unique_pages.sort()

ranges = []
start = unique_pages[0]
end = unique_pages[0]

for p in unique_pages[1:]:
    if p == end + 1:
        end = p
    else:
        if start == end:
            ranges.append(str(start))
        else:
            ranges.append(f"{start}-{end}")
        start = end = p

if start == end:
    ranges.append(str(start))
else:
    ranges.append(f"{start}-{end}")

print(','.join(ranges))
```このコードは、まず入力を整数に解析し、順序を維持しながら重複を削除してから、リストを並べ替えます。 次に、連続する番号を追跡して範囲を構築します。`start`そして`end`。 最後の print ステートメントはリストを正しくフォーマットします。 微妙な点は、ループ後の最終範囲の処理です。これは忘れられやすく、最後のページを見逃す可能性があります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    pages = list(map(int, input().strip().split(',')))
    seen = set()
    unique_pages = []
    for p in pages:
        if p not in seen:
            unique_pages.append(p)
            seen.add(p)
    unique_pages.sort()
    ranges = []
    start = unique_pages[0]
    end = unique_pages[0]
    for p in unique_pages[1:]:
        if p == end + 1:
            end = p
        else:
            if start == end:
                ranges.append(str(start))
            else:
                ranges.append(f"{start}-{end}")
            start = end = p
    if start == end:
        ranges.append(str(start))
    else:
        ranges.append(f"{start}-{end}")
    return ','.join(ranges)

# provided sample
assert run("1,2,3,1,1,2,6,6,2") == "1-3,6", "sample 1"
# all equal
assert run("5,5,5,5") == "5", "all equal"
# single element
assert run("42") == "42", "single element"
# max value
assert run(",".join(map(str, range(1,101)))) == "1-100", "consecutive max"
# gaps
assert run("1,3,2,5,6") == "1-3,5-6", "gaps"
# unordered input
assert run("10,1,3,2,7,6,8") == "1-3,6-8,10", "unordered input"
