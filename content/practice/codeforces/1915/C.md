 ## 解決策
 ## 問題の理解

 いくつかのバケツが与えられ、各バケツにはいくつかの単位正方形が含まれています。 すべての正方形は同一であり、辺の長さは 1 です。 

質問は簡単です。すべてのバケツからすべての正方形を取り出した場合、それらを配置して、正方形を残さずに 1 つの大きな正方形を形成できるでしょうか?

 単位正方形の総数が$S$、その場合、その面積が次のとおりであるときに、より大きな正方形を正確に構築できます。$S$。 正方形の面積は完全平方数でなければならないため、タスクはすべてのバケットの内容の合計が完全平方であるかどうかをチェックすることになります。 

制約は十分に小さいため、すべての要素を 1 回だけ処理できます。 すべてのテスト ケースにわたって、値の合計数は最大で$2 \cdot 10^5$、だから、$O(n)$テスト ケースごとのソリューションは簡単に十分に高速です。 同じ値を繰り返し検索または反復するアプローチは不要です。 

微妙な点の 1 つは、個々の値が次のように大きくなる可能性があることです。$10^9$。 まであり得るので、$2 \cdot 10^5$全体的に数値が大きいため、合計が非常に大きくなる可能性があります。 固定サイズの整数型を使用する言語では、小さすぎる型を使用するとオーバーフローが発生します。 Python の整数は自動的に増加するため、ここでは問題になりません。 

もう 1 つの簡単な間違いは、浮動小数点演算を使用して平方根が整数であるかどうかのみをチェックすることです。 数値が大きいと、精度の問題が発生する可能性があります。 例えば：```
1
2
1000000000 1000000000
```合計は$2000000000$、完全な正方形ではありません。 浮動小数点の丸めにより、大きな値の比較が正しく行われないことがあります。 整数の平方根を使用すると、そのリスクが回避されます。 

バケットが 1 つしかない場合は、別のエッジ ケースが発生します。```
1
1
9
```正方形の総数は 9 です。$3^2$したがって、正しい答えは次のとおりです。```
YES
```領域をチェックするのではなく、明示的に寸法を構築しようとする不用意な実装は、このケースを過度に複雑にする可能性があります。 

## アプローチ

 最も直接的なアイデアは、単位正方形の総数を計算し、その数が次のように書けるかどうかを判断することです。$k^2$ある整数に対して$k$。 

ブルートフォースバージョンでは、次の値を繰り返し試行します。$k$それまで$k^2$合計額に達するかそれを超えます。 合計が$S$、これには最大で$\sqrt{S}$繰り返し。 合計が非常に大きくなる可能性があるため、これは非現実的になります。 たとえば、次のような合計$2 \cdot 10^{14}$前後が必要になります$1.4 \cdot 10^7$小切手。 

重要な点は、正方形の配置は重要ではないということです。 合計数のみが重要です。 総面積がわかれば、問題は完全平方検定になります。 

平方根を手動で検索する代わりに、合計の整数平方根を計算できます。 させて$$r = \lfloor \sqrt{S} \rfloor.$$もし$r^2 = S$、 それから$S$は完全な正方形であり、答えは「YES」です。 それ以外の場合、答えは「NO」です。 

これにより、問題は、入力値を通過する 1 回のパスと 1 回の平方根計算に軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n + \sqrt{S})$|$O(1)$| 遅すぎる |
 | 最適 |$O(n)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. 各テスト ケースについて、次の内容を読んでください。$n$バケットの内容の配列。 
3. 単位正方形の総数を計算します。$$S = \sum a_i$$すべての正方形を使用する必要があるため、この合計は正確に最終的な図形の面積になります。 
4. 整数の平方根を計算します。$r$の$S$。 

整数の平方根は、その二乗が次の値を超えない最大の整数です。$S$。 
5. かどうかを確認します。$r^2 = S$。 

平等が成り立つなら、$S$は完全な正方形であり、正方形を形成することができます。 
6. 出力`"YES"`いつ$r^2 = S$、それ以外の場合は出力`"NO"`。 

### なぜ効果があるのか

 一辺の長さのある正方形$k$面積がある$k^2$。 利用可能な単位正方形の総数は次のとおりです。$S$したがって、すべてのピースから作られた正方形は正確な面積を持たなければなりません$S$。 

もし$S$完全な正方形です。辺の長さを選択してください$k = \sqrt{S}$そして施工が可能です。 

もし$S$は完全な正方形ではないため、整数の辺の長さは面積を生成できません$S$, したがって、正方形を構築することは不可能です。 

アルゴリズムはこの必要十分条件を正確にチェックし、正確性を保証します。 

## Python ソリューション```python
import sys
from math import isqrt

input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    total = sum(a)
    root = isqrt(total)

    print("YES" if root * root == total else "NO")
```最初のステップでは、すべてのバケットの内容を合計して合計面積を計算します。 

機能`isqrt()`浮動小数点演算を使用せずに整数の平方根を返します。 これにより、数値が大きくなったときに発生する可能性のある精度の問題が回避されます。 

取得後`root`、コードは次のことをチェックします。`root * root`元の合計と等しくなります。 等しいとは、和が完全二乗であることを意味します。 そうでなければそうではありません。 

この実装では、入力配列以外の一定の追加メモリのみを使用し、各要素を 1 回だけ処理します。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io
from math import isqrt

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        s = sum(a)
        r = isqrt(s)

        ans.append("YES" if r * r == s else "NO")

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return out
