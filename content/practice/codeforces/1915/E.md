 ## 解決策
 ## 問題の理解

 私たちには、一定量のジュースが入ったグラスが数列与えられます。 ユリアは奇数のグラスで飲み、デートの相手は偶数のグラスで飲みます。 タスクは、ユリアと彼女のデート相手がそのサブ配列内でまったく同じ合計量のジュースを消費するような、これらのグラスの連続したサブ配列が存在するかどうかを判断することです。 

入力は複数のテスト ケースで構成され、各テスト ケースはジュースの量とともに一連のグラスを記述します。 出力は、そのようなサブ配列が存在するかどうかを示す単純な「YES」または「NO」です。 主な課題は、テスト ケースあたりのガラスの数が最大 200,000 に達する可能性があり、すべてのテスト ケースの合計も 200,000 に制限されることです。 これにより、すべての O(n²) 個の連続する部分配列をチェックする単純なアプローチは除外されます。これは、最悪の場合、演算の総数が 10¹⁰ を超えることになり、これは 1 秒の制限時間には多すぎるためです。 

すべてのグラスに同じ量のジュースが入っている場合、微妙なエッジケースが発生します。 その場合、偶数長のサブ配列はすぐに条件を満たします。 もう 1 つの注意が必要なシナリオは、すべての奇数位置のガラスの合計が偶数位置のガラスの合計と異なる場合です。 単純に配列全体の合計のみをチェックすると、合計のバランスをとる小さなサブ配列が見逃されてしまいます。 たとえば、入力では`[1, 3, 2]`、配列全体の合計は均衡しませんが、部分配列は`[1, 3, 2]`インデックス 1 から開始すると機能します。`1+2 = 3`。 

## アプローチ

 ブルートフォースソリューションでは、考えられるすべての連続するサブ配列を調べ、奇数と偶数の位置を別々に合計します。 これにより、有効なサブ配列の定義が文字通りチェックされるため、正確さが保証されます。 ただし、テスト ケースごとに O(n²) の操作が必要であり、n が 2·10⁵ までの場合は遅すぎます。 

最適なアプローチは、接頭辞の合計と、Iulia の合計ジュースと部分配列内の彼女の日付の差だけを気にするという観察に依存しています。 させて`diff[i]`は、開始位置から位置 i までの奇数位置のガラスと偶数位置のガラスの合計の差になります。 次に、任意の部分配列に対して`[l, r]`、サブ配列は次の場合にのみバランスします。`diff[r] - diff[l-1] = 0`。 これにより、問題はプレフィックス差分配列内で 2 つの等しい値を見つけるという問題に軽減されます。 また、パリティも処理する必要があります。開始位置が奇数と偶数では異なる diff シーケンスが生成されるため、偶数インデックス用と奇数インデックス用の 2 セットのプレフィックス差分を維持します。 

この戦略により、配列を 1 回スキャンし、セットまたはハッシュ マップを使用して検出されたプレフィックスの違いを追跡することで、各テスト ケースを線形時間で解決できます。

 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テストケースについて、グラスの数を読み取ります。`n`そして配列`a`果汁の量。 
2. 2 つの変数を初期化します。`prefix_diff_odd`そして`prefix_diff_even`、それぞれ奇数位置と偶数位置で終わる部分配列のイウリアと彼女の日付の合計間の累積差を表します。 また、奇数位置と偶数位置で確認されたプレフィックスの違いを保存するために 2 つのセットを初期化します。 
3. 累積差分変数を初期化する`cum_diff`を 0 に設定し、空のプレフィックスを考慮してパリティ 0 (偶数) に対応するセットに 0 を追加します。 
4. 各ガラスを反復処理します。`i`0からn-1まで。 ポジションごとに更新します`cum_diff`追加することで`a[i]`それがイウリアの位置（奇数インデックス）の場合は減算します`a[i]`それが彼女の日付の位置（インデックスでも）の場合。 
5. 現在位置のパリティを決定します。 どうかを確認してください`cum_diff`は、このパリティに対応するセットで以前に見られました。 そうであれば、ユリアと彼女のデートのジュースのバランスを取る部分配列が存在します。 すぐに「YES」を出力します。 
6. もし`cum_diff`以前に見られなかった場合は、現在のパリティに対応するセットに追加して続行します。 
7. 一致するものが見つからずに配列の末尾に到達した場合は、「NO」を出力します。 

このアプローチにより、連続するサブ配列について、イウリアとその日付のジュース合計の差が同じパリティで繰り返される場合、それらの位置間のサブ配列のバランスが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        seen = [set(), set()]  # seen[0] for even indices, seen[1] for odd indices
        cum_diff = 0
        seen[0].add(0)
        found = False
        for i in range(n):
            if i % 2 == 0:
                cum_diff += a[i]
            else:
                cum_diff -= a[i]
            parity = (i + 1) % 2
            if cum_diff in seen[parity]:
                print("YES")
                found = True
                break
            seen[parity].add(cum_diff)
        if not found:
            print("NO")

if __name__ == "__main__":
    solve()
```このソリューションでは、2 つのセットを使用して偶数位置と奇数位置のプレフィックスの違いを追跡し、パリティを正しく処理できるようにします。 累積差額`cum_diff`ユリアと彼女のデートのジュースを交互に摂取します。 偶数パリティ インデックスのセットに 0 を追加すると、最初の位置から始まるサブ配列が正しく検出されます。
