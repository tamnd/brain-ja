 ## 問題の理解

 平面内に一連の点が与えられますが、単一線上に 3 つの点が存在しないという制限があります。 あらゆる点について\(p\)、他の 4 つの点のサブセットが何個あると、厳密に以下を含む単純な四角形を形成できるかを数えたいとします。\(p\)。 このような各サブセットは、4 つの点を使用して四角形を描画する方法が複数ある場合でも、それが囲むことができる点ごとに 1 回カウントされます。 

出力はすべてのポイントの合計です\(p\)したがって、すべてのペアの「ポイント」\(p\)、有効な 4 点サブセット\(Q\)” の場合は 1 を貢献します\(Q\)を含む凸四角形に配置できます。\(p\)。 

制約\(n \le 2500\)立方体的なものはすでに示唆されています\(n\)\(O(n^2 \log n)\) または \(O(n^2)\) がターゲットである一方で、遅すぎます。 すべての単純な列挙\(\binom{n}{5}\)サブセットは実現不可能です。\(\binom{2500}{5}\)天文学的に大きいです。 

微妙な点は、この条件が「囲む単純な四角形を形成できる」ということです。\(p\)” は、選択した 5 つの点の凸包にのみ依存します。「3 つの共線性がない」保証により、どの 5 点セットにも明確に定義された凸包があり、可能な包殻タイプは三角形または四角形だけです。四角形には、包が四角形であり、かつその場合に限り、5 点セットの内部点が含まれます。\(p\)その中にあります。 

これにより、問題は純粋に組み合わせ幾何学の問題に帰着します。つまり、5 点のサブセットごとに、その点が厳密に凸包の内側にいくつあるかを数え、それをすべてのサブセットにわたって累積します。 

エッジケースの主なリスクは、点が船体の境界上にある構成を誤って分類することですが、これは一般的な位置の仮定によって除外されます。 もう 1 つのよくある間違いは、すべての 5 点サブセットが 1 つの「内側点」に寄与すると仮定することです。これは、船体が五角形の場合は誤りです。その場合、内側点は存在しないからです。 

## アプローチ

 直接的な総当たりアプローチでは、すべての 5 点サブセットを列挙し、その凸包を計算し、厳密に内部に存在する点の数を数えます。 これは正しいですが、それぞれ \(O(1)\) または \(O(\log n)\) のジオメトリを持つ \(O(n^5)\) のサブセットが必要です。\(n = 2500\)。 

重要な点は、カウント方向を逆にすることです。 サブセットを反復処理して、サブセット内にポイントがいくつ含まれているかを尋ねる代わりに、ポイントを修正します。\(p\)そして、以下を含む凸四角形を形成する 4 点の部分集合がいくつあるかを尋ねます。\(p\)。 これにより、問題は周囲の局所的な角度計数問題に変換されます。\(p\)。 

点を修正する\(p\)。 他のすべての点を極角で並べ替えます\(p\)。 標準的な幾何学的洞察は、4 つの点のセットが次の要素を含む四角形を形成するというものです。\(p\)もし、そしてその場合に限り、周囲から見たときに\(p\)、それらは通過する半平面にすべて含まれるわけではありません。\(p\)。 同様に、4 つの点の中に、次の点を中心とする開いた半円はありません。\(p\)それらすべてが含まれています。 

したがって、固定の場合\(p\)、どの角度間隔にも含まれない点の 4 タプルの数を数えます。\(\pi\)。 これは古典的な円形の 2 点の計数問題になります。4 つの点すべてが半円内にある相補的な構成を数え、合計から減算します。\(\binom{n-1}{4}\)。 

この構造は、凸多角形を数えたり、角度スイープ問題で標準的な「半平面に含まれない」サブセットを数えたりするのと同じです。 

それぞれについて\(p\)では、ラップアラウンドを処理するために角度配列を複製し、2 ポインター ウィンドウを使用して、半円内で 3 倍を 4 倍に拡張できる数を数えます。 これらの「悪い」構成に対する包含と除外により、最終的なカウントが得られます。 

最後に、この値を全体にわたって合計します。\(p\)。

 ## アルゴリズムのチュートリアル

 答えをポイントごとに計算します。 

固定点の場合\(p\)、他のすべての点を考慮して、その周囲の極角を計算します。\(p\)。 この配列を次のようにします\(a\)、サイズの\(n-1\)、角度が増加する方向に並べ替えられます。 次に、追加して \(2(n-1)\) に拡張します。\(a_i + 2\pi\)循環ハンドリング用。 

どの半円にも含まれない 4 点サブセットの数を数えたいとします。 有効なものを直接カウントする代わりに、不良なものを減算します。 

悪い 4 回転とは、4 つの点すべてが半円内にあるものです。 このような半円の開始点を修正し、次の半円内にトリプルがいくつあるかを数えます。\(\pi\)範囲。 2 ポインター ウィンドウは、各円弧内のポイントの数を示します。 

それぞれの立場から\(i\)、最も遠いインデックスを見つけます\(j\)角度差が以下になるように\(\pi\)。 あれば\(k = j - i\)このウィンドウでポイントを選択し、そのうちの 3 つを一緒に選択します\(i\)に固定された不良クワドルプルを形成する\(i\)、貢献\(\binom{k}{3}\)。 

以上をまとめると\(i\)、左の端点として機能する各ポイントに対して 1 回ずつ、各不良 4 倍数を正確に 4 回オーバーカウントします。 この過剰数を修正するために適切に分割します。 

最後に、不良クワドルプルの数をから引きます。\(\binom{n-1}{4}\)\(f(p)\) を取得し、すべてを合計します\(p\)。 

### なぜ効果があるのか

 4 点セットは囲む四角形を形成できません\(p\)ちょうど半円の中に収まるとき\(p\)。 この等価性により、幾何学的包含条件が 1 次元の循環順序付け条件に変換されます。 スライディング ウィンドウは、制御された過剰カウントを超えて構成を欠落したり重複したりすることなく、半円で制約されたすべての最大サブセットをカウントします。これは組み合わせ正規化によって補正されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from math import atan2

def comb4(x):
    if x < 4:
        return 0
    return x * (x - 1) * (x - 2) * (x - 3) // 24

def comb3(x):
    if x < 3:
        return 0
    return x * (x - 1) * (x - 2) // 6

n = int(input())
pts = [tuple(map(int, input().split())) for _ in range(n)]

ans = 0

for i in range(n):
    x0, y0 = pts[i]
    ang = []
    for j in range(n):
        if i == j:
            continue
        x, y = pts[j]
        ang.append(atan2(y - y0, x - x0))
    ang.sort()
    m = len(ang)

    ang += [a + 2 * 3.141592653589793 for a in ang]

    j = 0
    bad = 0

    for k in range(m):
        if j < k:
            j = k
        while j < k + m and ang[j] - ang[k] < 3.141592653589793:
            j += 1
        cnt = j - k - 1
        bad += comb3(cnt)

    total = comb4(m)
    ans += total - bad

print(ans)
```コードは各ポイントを独立して処理します。 角度の計算により、選択した点の周囲の極順序が固定されます。 配列を 2 倍にすることで、モジュール式の算術演算を複雑にすることなく、半円クエリをラップアラウンドできるようになります。 

2 ポインター スイープにより、各ウィンドウが前方にのみ拡張され、ソート後のポイントごとの複雑さが線形に保たれます。 

減算ステップでは、「不正な半円の四辺形」が、その点を含む有効な四辺形の最終的な数に変換されます。
