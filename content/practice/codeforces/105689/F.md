 ## 解決策
 ## 問題の理解

 祭りにはランタンが並び、それぞれのランタンには現在の高さが示されています。 ドラゴンは、選ばれた 1 つのランタンからスタートし、最終的にはすべてのランタンの上に立ちたいと考えています。 隣接するランタンの間でのホップは、その時点で高さが一致している場合にのみ可能です。 

ドラゴンは、現在立っているランタンで高さをエネルギーと交換できます。 ランタンを 1 つ下げると 1 エネルギーが得られ、ランタンを 1 つ増やすと 1 エネルギーを消費します。 タスクは、多くの質問に答えることです。開始位置について、必要な初期エネルギーの最小量はいくらか、いくつかの質問の後、ランタンの高さは変化する可能性があります。 

入力では、ランタンの数と操作が説明され、その後に初期の高さが続きます。 アップデートにより 1 つのランタンの高さが変更されます。 質問では、特定のランタン インデックスからの最小開始エネルギーが求められます。 

制限は大きく、最大で$2 \cdot 10^5$提灯と$2 \cdot 10^5$操作。 これにより、すべての質問に対してすべてのランタンをスキャンする必要がなくなるため、除外されます。$4 \cdot 10^{10}$最悪の場合の運用。 更新とクエリの両方に対数または定数の時間がかかる構造が必要です。 

難しいのは、ドラゴンが同じランタンを繰り返し下げたり上げたりしても自由エネルギーを生み出すことができないことに気づくことです。 ランタンを下げるとエネルギーが発生しますが、そのランタンを次のホップに必要な高さに戻すと、まったく同じ量が消費されます。 重要なのは、訪問するランタンの相対的な高さだけです。 

よくある間違いは、次のランタンを一方向にのみ考慮することです。 ドラゴンは反対側の非常に高いランタンを訪問する必要がある場合があるため、すべての開始位置で列全体の中で最も高いランタンを考慮する必要があります。 

たとえば、次の入力を使用します。```
3 1
5 1 2
1 2
```答えは次のとおりです。```
0
```最初のランタンから始めると、すでに最大の高さが設定されているため、初期エネルギーは必要ありません。 

もう 1 つのエッジ ケースは、開始ランタンが最も高くない場合です。```
3 1
5 1 2
1 2
```クエリがランタン 2 に関するものである場合、答えは次のようになります。```
4
```隣接するランタンのみをチェックするソリューションでは、もう一方の端の高さ 5 が見逃され、より小さい値が返される可能性があります。 

## アプローチ

 直接的なアプローチはドラゴンの動きをシミュレートします。 選択したランタンから出発して、左右に移動して、ホップごとに必要なエネルギーを追跡します。 これが機能するのは、動作ルールを正確にシミュレートできるためです。 ただし、1 つのクエリについては、すべてのクエリを調べる必要がある場合があります。$n$提灯。 と$q$クエリの場合、最悪のケースは$O(nq)$、これは許容範囲をはるかに超えています。 

重要な観察は、ホップ中のエネルギー変化を観察することから得られます。 ドラゴンが高いランタンから移動すると仮定します。$x$隣の高さのあるランタンに$y$。 もし$y$より高い、ドラゴンは費やす$y-x$エネルギー。 もし$y$低いとドラゴンが得する$x-y$エネルギー。 どちらの場合も、エネルギーは正確に次のように変化します。$$x-y$$一連のホップの後、中間の高さはすべてキャンセルされます。 ランタンからスタート$p$そして高さのあるランタンに到達$h$、エネルギーは次のようになります。$$E + a_p - h$$エネルギーが最も低くなるのは、ドラゴンがこれまで訪れた中で最も高いランタンに到達したときです。 目標はすべてのランタンを訪問することなので、最も高いランタンは単純に配列全体の最大の高さになります。 

したがって、位置からの必要な初期エネルギーは$p$は：$$\max(0, \text{maximum height} - a_p)$$必要な動的情報は現在の最大高さだけです。 更新によりその最大値が変更される可能性があるため、複数の高さのセットを維持し、操作のたびに最大値を取得します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | クエリあたり O(n)、合計 O(nq) | お(1) | 遅すぎる |
 | 最適 | 更新ごとに O(log n)、クエリごとに O(1) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのランタンの高さを、最大値を挿入、削除、取得できるデータ構造に保存します。 この問題には、遅延削除を伴う最大ヒープで十分です。 
2. 更新操作の場合は、古い高さを新しい高さに置き換えます。 古い値をヒープから直接削除することはできないため、各ランタンの現在の高さを個別に保存し、最大値をチェックするときに古いヒープ エントリを無視します。 
3. ランタンへの質問$p$、最初に古いヒープ エントリを削除してから、現在の最大高さを取得します。 答えは、この最大値と開始時のランタンの高さの差が正の場合はその差であり、それ以外の場合はゼロになります。 
4. 計算値を出力します。 

機能する理由: ホップ中に、現在のランタンの高さと次のランタンの高さの差によってドラゴンのエネルギーが変化します。 完全なルートでは、訪問したすべての中間高地が相殺されます。 唯一の危険な点は、最も高いランタンを訪れることです。そこは、ドラゴンが最初の高さと比較して最も多くのエネルギーを費やした場所だからです。 その高さに到達するのに十分なエネルギーがあるということは、他のすべてのランタンも訪問できることを意味します。 この公式は、最初のランタンを最も高いランタンと同じ高さにするために必要な不足エネルギーを正確に測定します。 

## Python ソリューション```python
import sys
import heapq

input = sys.stdin.readline

def solve():
    n, q = map(int, input().split())
    a = list(map(int, input().split()))

    heap = []
    for i, x in enumerate(a):
        heapq.heappush(heap, (-x, i))

    out = []

    for _ in range(q):
        query = input().split()
        if query[0] == '1':
            p = int(query[1]) - 1
            while -heap[0][0] != a[heap[0][1]]:
                heapq.heappop(heap)
            out.append(str(max(0, -heap[0][0] - a[p])))
        else:
            p = int(query[1]) - 1
            x = int(query[2])
            a[p] = x
            heapq.heappush(heap, (-x, p))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```配列`a`各ランタンの現在の高さを保存します。 更新後にヒープ エントリが古くなっている可能性があるため、これが必要です。 

Python のヒープは最小ヒープであるため、ヒープには負の高さが格納されます。 したがって、最大の高さが最小の負の数として先頭になります。 

クエリに答える前に、コードは現在の高さと一致しなくなったヒープ エントリを削除します。`a`。 この遅延削除により、すべての操作を高速に保ちながら、より複雑なデータ構造の必要性が回避されます。 

クエリの回答では、派生した式が直接使用されます。 の`max`この呼び出しは、ドラゴンが初期エネルギーを必要としないため、開始ランタンが既にグローバル最大高さを持っている場合を処理します。

    input = sys.stdin.readline

    n, q = map(int, input().split())
    a = list(map(int, input().split()))

    heap = []
    for i, x in enumerate(a):
        heapq.heappush(heap, (-x, i))

    ans = []

        else:
            p = int(query[1]) - 1
            x = int(query[2])
            a[p] = x
            heapq.heappush(heap, (-x, p))

    return "\n".join(ans)

 ## 特殊なケース

 ランタンが 1 つしかないとき、龍はすでにすべてのランタンを訪れています。 入力の場合:```
1 1
7
1 1
```最大高さと開始高さは両方とも 7 なので、答えは次のようになります。```
0
```必要なエネルギーは最大高さと開始高さの間の正の差であるため、アルゴリズムはこれを処理します。 

スタートランタンがすでに最も高いときは、初期エネルギーは必要ありません。 のために：```
3 1
5 2 4
1 1
```最大の高さは 5 で、開始の高さも 5 です。答えは次のとおりです。```
0
```ドラゴンは他のランタンを調整しながらエネルギーを獲得したり消費したりできます。 

高さの更新により以前の最大値が削除された場合、古いヒープ値が回答に影響を与えてはなりません。 のために：```
2 3
100 0
2 1 10
1 2
1 1
```アップデート後の高さは`[10, 0]`。 古い価値観`100`一時的にヒープ内に残りますが、応答する前に遅延削除ステップによって削除されます。 答えは次のとおりです。```
10
0
```現在の最大値は 10 であり、古い値 100 ではないためです。
