 ## 解決策
 ## 問題の理解

 一連のセルが与えられます。各セルは最初にウサギが含まれているか、空になっています。 各演算で、正の整数シフトを選択できます。$K$、その後、すべてのセルが並行して動作します。 

占有されているすべてのセルはウサギの一部をその場に保持し、同時に別の部分を正確に送信します$K$右側に位置します。 その宛先が最後のセルを超える場合は、何も送信されません。 空でない細胞はウサギを維持することができ、繁殖には事実上制限がないため、重要なのは細胞に何匹のウサギが含まれているかではなく、少なくとも一度は細胞に到達できるかどうかだけです。 

したがって、各操作はグローバルな「到達可能性の拡張」のように動作します。現在到達可能なすべてのセルは、それ自体を再び到達可能としてマークし、そのセルにもマークを付けます。$i+K$そのインデックスが存在するときはいつでも到達可能です。 

目標は、そのようなシフトのシーケンスを選択することです$K_1, K_2, \dots$順番に適用すると、すべてのセルに到達できるようになります。 必要な操作の数を最小限に抑えるか、それが不可能であると判断します。 

文字列の長さは最大 40 であり、状態または到達可能な構成のセットの探索に依存するソリューションが実行可能であることがすぐにわかります。 ただし、演​​算数が指数関数的に増加するものは、演算数が非常に少ない場合にのみ有効です。 これにより、すべての配列にわたるシミュレーションではなく、構造の特性評価が行われるようになります。 

重要なエッジ ケースは、空のセルの左側に最初に占有されているセルがない場合に発生します。 移動は右方向のみであるため、どのようにシフトを選択しても、そのようなセルに到達することはできません。 たとえば、文字列が次の場合、`0100`、2 番目のセルが最初のセルに影響を与えることはできないため、最初のセルが到達可能になることはありません。 正しい出力は次のとおりです`-1`。 

もう 1 つの微妙なケースは、すべてのセルが最初からすでに占有されている場合です。 この場合、何も展開する必要がないため、操作は必要ありません。 常に少なくとも 1 つの操作を実行する単純な実装では、ここで誤って過大評価されてしまいます。 

## アプローチ

 直接的なアプローチは、考えられるすべての操作シーケンスをシミュレートすることです。 各操作では、任意の正の値を選択できます$K$、各操作の後、到達可能な位置のセットは決定論的に変化します。 原理的には、到達可能なセルのサブセットに対して BFS を実行できます。この場合、各状態は可能な限りすべてのことを試みます。$K$。 ただし、状態空間は$2^{40}$、分岐係数が大きいため、$K$最大 40 までの範囲があり、一連の操作が長くなる可能性があります。 これにより、実行可能な操作シーケンスが爆発的に増加し、すぐに実行不可能になります。 

重要な観察は、中間状態の正確な値は無関係であるということです。 重要なのは、「シフトと分岐」操作を繰り返すことによって、到達可能性が最初の到達可能性からどこまで伝播できるかということです。 

シフトを伴う各動作$K$あらゆる到達可能な位置を効果的に許可$i$新しい到達可能な位置を作成するには$i+K$。 複数の操作の後、初期の占有位置からの距離が選択されたシフトの合計として表現できる場合、位置に到達できます。各シフトは伝播経路に沿って最大 1 回使用できます。 これにより、問題は古典的な表現可能性の問題に変わります。必要なすべての距離がサブセットの合計として表現できるように、正の整数のマルチセットが必要になります。 

建設的な観点からシフトを選択すると、$K_1, K_2, \dots, K_t$の場合、到達可能な変位はこれらの値のサブセットの合計になります。 慎重に選択したシフトを使用すると、以下のすべての整数を表すことができます。$0$最大値まで。 少ない数値でこのカバレッジを最大化する最適な方法は、連続した間隔ですべてのサブセットの合計を生成する 2 のべき乗を使用することです。 

したがって、問題は、任意のセルがその左側にある最も近い最初に占有されているセルから移動するために必要な最大距離を見つけることに帰着します。 この最大距離がわかったら$D$、最小のものが必要です$t$からのすべての整数を表すことができるように、$0$に$D$の部分集合和を使用する$t$この数値は次の場合に達成されます。$2^t - 1 \ge D$。

 ## アルゴリズムのチュートリアル

 1. 左に最も近い占有セルを追跡しながら、文字列を左から右にスキャンします。 ポジションごとに$i$、最も近いインデックスを記録します$j \le i$その細胞のように$j$占領されています。 
2. 任意の時点で、セルの左側 (セル自身を含む) に占有セルがない場合、問題は発生しません。 これは、最初に占有されているセルが位置 1 にない場合、または最初のセルの前にギャップがある場合に発生します。 その場合は返却してください$-1$。 
3. ポジションごとに$i$、距離を計算します$i - j$、 どこ$j$はその左側に最も近い占有位置です。 
4. しましょう$D$すべての位置にわたるそのような最大距離になります。 
5. もし$D = 0$、すべてのセルがすでに到達可能であるため、0 を返します。 
6. それ以外の場合は最小値を見つけます$t$そのような$2^t - 1 \ge D$、そして戻ります$t$。 

このステップが機能する理由は、各操作で、伝播中にオプションで取得またはスキップできる新しいシフト値が追加されるためです。$t$すべての初期位置の演算は、次のサブセット和として表現可能なすべてのオフセットに到達できます。$t$数字。 2 のべき乗を選択すると、指定された操作数でカバーされる整数の接頭辞が最大化されるため、最適です。 

### なぜ効果があるのか

 一連の操作により一連のシフト値が定義されます。$K_1, \dots, K_t$。 到達可能な位置は、各ステップでシフトを使用するかどうかを選択することによって決定され、これによりこれらの値のサブセット合計構造が形成されます。 したがって、到達可能な変位は、選択されたシフトのサブセット和閉包を正確に形成します。 

必要な変位をすべてカバーするには、必要な最大変位を確保するだけで済みます。$D$表現可能な範囲内にあります。 達成可能な最大の連続範囲は$t$正の整数は 2 の累乗の場合に発生し、カバレッジが得られます。$[0, 2^t - 1]$の場合、最小限の操作が直接続きます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    n = len(s)

    prev = -1
    max_dist = 0

    for i in range(n):
        if s[i] == '1':
            prev = i
        else:
            if prev == -1:
                print(-1)
                return
            max_dist = max(max_dist, i - prev)

    if max_dist == 0:
        print(0)
        return

    t = 0
    cap = 0
    while cap < max_dist:
        t += 1
        cap = (1 << t) - 1

    print(t)

if __name__ == "__main__":
    solve()
```この実装では、左側の最も近い占有セルを追跡します。 これにより、操作をシミュレートする必要がなく、到達可能性の制約が直接適用されます。 

重要な微妙な点は、初期の不可能性チェックです。ゼロが現れる前にゼロが見つかった場合、すべての動きは厳密に右方向であるため、その位置に到達することは決してできません。 

2 番目に重要な部分は、必要な最大距離を計算することです。 それがわかれば、残りはその範囲をカバーするために必要な 2 進数の数を見つけることになります。 

## 実用的な例

 次のような入力を考えてみましょう`10011`。 

左から右にスキャンします。 

| 私 | s[i] | 前へ | 距離 i-前 | 最大距離 |

 | 0 | 1 | 0 | 0 | 0 |
 | 1 | 0 | 0 | 1 | 1 |
 | 2 | 0 | 0 | 2 | 2 |
 | 3 | 1 | 3 | 0 | 2 |
 | 4 | 1 | 4 | 0 | 2 |

 最大距離は 2 なので、最小の距離が必要です$t$そのような$2^t - 1 \ge 2$。 それは与える$t = 2$。 

ここで考えてみましょう`01110`。

 インデックス 0 では、左側に占有されているセルがないため、すぐに失敗します。そのため、答えは次のようになります。`-1`。 これは、到達可能性が逆方向に伝播することができず、初期のギャップが致命的であることを示しています。

 ## 特殊なケース

 最初の文字が`0`の場合、左側への伝播源がないため、アルゴリズムは直ちに不可能を検出します。 スキャンを実行すると次のことがわかります`prev = -1`インデックス 0 にあるため、関数は次の値を返します。`-1`距離計算の前に。 

すべてのキャラクターが揃ったとき、`1`、すべてのセル自体に初期ソースがあるため、最大距離がゼロを超えることはありません。 計算された`max_dist`0のままで、出力に直接つながります`0`、不要な操作を正しく回避します。 

ちょうど 1 つだけある場合`1`の位置 0 にあるとします。`100000`、後のすべての位置には、そのインデックスに等しい距離があります。 最大距離は、$n-1$、アルゴリズムはこれを、ライン全体にまたがるのに必要なシフト操作の数を反映して、その範囲を表すのに必要なビット数に正しく変換します。
