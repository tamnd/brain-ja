 ## 解決策
 ## 問題の理解

 垂直制約のある 1D 追跡をシミュレートしています。 

フリスビーは最初に少し遅れて投げられます。 その瞬間から、一定の高さから水平方向に一定の速度で移動し、同時に重力を受けて落下します。 フリスビーがキャッチできるようになるのは、フリスビーがまだ空中にあるとき、そして犬がジャンプして届くほど高さが低いときだけです。 

犬は後で原点からスタートし、固定最大水平速度で瞬時に左または右に移動でき、固定高さのしきい値まで垂直ジャンプも実行できます。 フリスビーをキャッチした後、犬はすぐに同じ水平速度で原点に戻ります。 時間ゼロから犬が原点に戻るまでの合計時間を計測します。 

重要な決定は、犬がフリスビーに出会う正確な時間を選択することです。 この選択によって、集合場所と最終的な帰還コストの両方が決定されるため、目標は、合計完了時間を最小限に抑える実現可能な集合時刻を選択することです。 

入力は 2 つの軌道を定義します。 フリスビーの軌道は、発射時間、初期高さ、水平速度、重力によって決まります。 犬の軌道は開始時間と水平速度に依存しますが、垂直方向の制約は迎撃が可能な場合にのみ制限されます。 

制約により最大 100 万の値が許可されるため、時間を段階的にサンプリングするアプローチは不可能です。 関連する時間範囲が約 100 万に及ぶ可能性があり、最大 1e-4 までの連続精度が必要なため、ミリ秒を超える緻密なシミュレーションであっても遅すぎます。 

最も微妙な失敗のケースは、実現可能性のウィンドウを無視したことに起因します。 

最初のエッジケースは、フリスビーが十分に低くなる前にキャッチしようとしています。 フリスビーが高さ 160 からスタートし、犬が高さ 40 までしかジャンプできない場合、水平位置が一致していても早期インターセプトは不可能です。 

フリスビーがすでに地面に着いた後、2 番目のエッジケースがキャッチしようとしています。 着陸後、フリスビーは意図した「エアキャッチ」条件を満たさなくなり、その点を超えるとモデルが壊れます。 

3 番目のエッジ ケースは、同期を無視することです。 フリスビーが犬よりも水平方向にはるかに速い場合、両方の速度と開始の遅れを結合する不等号を考慮しない限り、犬は決してフリスビーを捕まえることができない可能性があります。 

## アプローチ

 強引なアプローチでは、多くの集合時間の候補を考慮し、各時間におけるフリスビーの位置と高さを計算し、犬がその位置に到達できるかどうかを確認し、合計の戻り時間を計算します。 時間は連続であるため、必要な精度を満たすために非常に細かい分解能で時間を離散化する必要があります。 1e-4 精度で最大 10^6 ミリ秒の範囲では、約 10^10 の評価が行われますが、これは実行不可能です。 

集合場所が物理的に固定されると、最終コストは集合時間の一次関数であることが観察されると、構造はより単純になります。 フリスビーの位置は時間的に決定されるため、犬が戻る距離も同時に決定されます。 これにより、問題はすべての制約を満たす実行可能な最小時間を選択することになります。 

実現可能性は 3 つの独立した条件によって決まります。 まず、犬は始める前に捕まえることはできませんし、フリスビーも投げる前に捕まえることはできません。 第二に、フリスビーは犬の垂直方向の届く範囲内になければなりません。これは、フリスビーの高さが最大 ​​Hd になる時間枠に変換されます。 第三に、水平到達可能性では、犬の開始遅延と速度を考慮して、犬が時間 t までにフリスビーの x 座標に到着できる必要があります。 

これらの制約が表現されると、最適解は単にそれらをすべて満たす最も早い時間になります。

 ## アルゴリズムのチュートリアル

 1. 犬が行動できる最も早い時間 (Td) とフリスビーが存在する最も早い時間 (Tf) を計算します。 有効な会議は両方の後に行われる必要があります。 
2. フリスビーが垂直にキャッチできるようになる時間を計算します。 その高さは Hf から始まる下向きの放物線です。 Hf - (t - Tf)^2 / 2 ≤ Hd を解くと、t ≥ Tf + sqrt(2(Hf - Hd)) が得られます。 これは、フリスビーがジャンプできるほど低い位置にある最も早い時期です。 
3. フリスビーがまだ空中にあるときを計算します。 Hf - (t - Tf)^2 / 2 = 0 のときに地面に衝突し、t = Tf + sqrt(2Hf) となります。 有効なキャッチ時間は厳密にこの時点より前に留まっている必要があります。 
4. 水平方向のリーチ制約を計算します。 時間 t で、フリスビーは x_f = Vf (t - Tf) にあります。 犬は Td で動き始め、最大でも Vd (t - Td) をカバーできます。 したがって、Vf (t - Tf) ≤ Vd (t - Td) が必要です。 並べ替えると、t の一次不等式が得られ、Vf が Vd 以下か、Vd と等しいか、Vd より大きいかに応じてしきい値時間が生成されます。 
5. すべての下限値の最大値を取得します。Tf、Td、垂直方向のキャッチしきい値、および水平方向の実現可能性しきい値です。 これは物理的に捕獲が可能な最も早い時期です。 
6. 集合位置 x = Vf (t - Tf) を計算します。 
7. 犬はキャッチ直後に一定の速度で戻るので、合計時間を t + x / Vd として計算します。 

### なぜ効果があるのか

 すべての実現可能な解は単一の会議時間 t に対応し、t が固定されると、すべての空間量は一意に決定されます。 制約は、有効時間の閉じた間隔を定義します。 キャッチまでの待機時間と帰還距離の両方が時間とともに増加するため、合計完了時間は t に比例して増加します。 したがって、実行可能な最も早い時間を超える遅延は結果を厳密に悪化させ、後で構成しても結果を改善することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def solve():
    Tf, Vf, Hf, Td, Vd, Hd = map(float, input().split())

    # time bounds from start conditions
    t = max(Tf, Td)

    # vertical constraint: frisbee must be low enough to reach
    if Hf > Hd:
        t = max(t, Tf + math.sqrt(2.0 * (Hf - Hd)))

    # frisbee must still be in air
    t = min(t, Tf + math.sqrt(2.0 * Hf))

    # horizontal feasibility: Vf*(t-Tf) <= Vd*(t-Td)
    # solve for t
    if abs(Vf - Vd) < 1e-12:
        if Vf > Vd:
            return print("inf")  # unreachable case in theory
    else:
        rhs = Vf * Tf - Vd * Td
        denom = Vf - Vd
        if denom > 0:
            t = max(t, rhs / denom)
        else:
            t = max(t, rhs / denom)

    x = Vf * (t - Tf)
    ans = t + x / Vd

    print("%.10f" % ans)

if __name__ == "__main__":
    solve()
```この実装では、まず時間制約を結合することにより、実現可能な最も早い会議時間を構築します。 垂直方向の制約には、発射体の高さ方程式の逆数が使用されます。 水平方向の制約は、t における線形不等式に変換されます。 t を選択すると、フリスビーの位置が直接計算され、最終的な答えに戻りの移動時間が追加されます。 

符号は Vf が Vd より大きいかどうかによって異なるため、不等式を並べ替える際には注意が必要です。 最終的な答えには 1e-4 以内の絶対誤差のみが必要なので、浮動小数点精度で十分です。

import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import sqrt

    Tf, Vf, Hf, Td, Vd, Hd = map(float, inp.split())

    t = max(Tf, Td)

    if Hf > Hd:
        t = max(t, Tf + math.sqrt(2.0 * (Hf - Hd)))

    t = min(t, Tf + math.sqrt(2.0 * Hf))

    if abs(Vf - Vd) > 1e-12:

        t = max(t, rhs / (Vf - Vd))

    return f"{t + x / Vd:.10f}"

 ## 特殊なケース

 重要なエッジケースは、犬が利用可能になった後に垂直方向の拘束がアクティブになる場合です。 このような場合、高さのしきい値を無視すると、フリスビーがまだ高すぎる、実行不可能な早い集合時間を選択することになります。 

もう 1 つのエッジケースは、フリスビーが犬よりも水平方向に速い場合です。 不等式は方向を反転させ、符号の変更に対応できないと、犬が迎撃地点に決して到達できない時間を選択することになります。 

3 番目のエッジケースは、フリスビーが地面にぶつかろうとしているときです。 計算された実行可能時間が着陸時間を超える場合、ソリューションは有効な間隔に固定するか、その領域を完全に拒否する必要があります。そうでない場合、モデルは物理的に不可能なキャッチ イベントを生成します。
