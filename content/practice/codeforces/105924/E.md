 ## アルゴリズムのチュートリアル

 ツリーをノード 1 にルートします。すべてのノードに対して$v \neq 1$、 させて$e_v$接続するエッジになる$v$その親に。 このような各エッジは、サブツリー内のすべてのエッジの後にのみ取得できる「項目」と考えることができます。$v$取られてしまった。 

根を張った木の上にDPを構築します。 

1. 各ノードについて$v$では、親エッジがすべての子サブツリー エッジの後に来るという制約を考慮して、そのサブツリー内の指定された数のエッジを選択するための有効な方法がいくつ存在するかを格納する DP テーブルをそのサブツリーに対して定義します。 

これにより、サブツリー内の有効な削除順序の組み合わせ構造がキャプチャされます。 
2. 各ノードについて$v$、サブツリー内のすべての部分削除プロセスに対するノードの重みの合計寄与を累積する 2 番目の DP も維持します。 

この 2 番目の値が必要になるのは、最終的な答えが単なるシーケンスの数ではなく、各ノードが接続されたままになっている時間の合計であるためです。 
3. 子を 1 つずつ処理し、ナップザック畳み込みを使用して DP テーブルをマージします。 マージは、選択されたエッジの総数を独立したサブツリーに分散することに対応します。 

この正しさは、親エッジがまだ選択されていない場合、さまざまな子のサブツリーが独立しているという事実から得られます。 
4. すべての子を結合した後、$v$、エッジを含めるかどうかを検討します$e_v$。 これを含めない場合、サブツリーは次のルートをルートとする独立したコンポーネントのように動作します。$v$。 これを含める場合は、そのサブツリー内のすべてのエッジの後に出現する必要があり、これにより、サブツリーがグローバル シーケンス長にどのように寄与するかが変化します。 
5. マージ中に、カウントだけでなく、各ノードの累積された「生存時間寄与」も伝播します。 各ノードは、ルートへのパス上のエッジが削除されるまでのステップ数を乗じた重みに寄与します。 

これにより、時間ベースの条件が順列にわたる組み合わせ統計に変換されます。ノードの場合$v$、パス上で最初に選択したエッジの位置を知る必要があるだけです。$v$選択したセットのルートに移動します。 
6. すべてのノードを処理した後、ルートの DP は、正確に選択するための合計寄与度を与えます。$k$すべての有効なシーケンスにわたるエッジ。 

### なぜ効果があるのか

 ルート付きツリーは厳密な依存構造を引き起こします。つまり、すべてのエッジはそのサブツリー内のエッジにのみ依存します。 これにより、有効なシーケンスがこの部分順序の正確な線形拡張であることが保証されます。 異なるサブツリーは親接続を除いて独立しているため、DP マージによって正確さが維持されます。 寄与追跡が機能するのは、ノードの生存が祖先エッジが選択されているかどうかのみに依存するためです。これは、どのエッジが選択されているか、および有効な拡張内でのそれらの相対順序によって完全に決定されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def add(a, b):
    c = a + b
    if c >= MOD:
        c -= MOD
    return c

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    g = [[] for _ in range(n)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    parent = [-1] * n
    order = [0]
    parent[0] = 0

    for u in order:
        for v in g[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            order.append(v)

    dp = [None] * n
    cnt = [None] * n

    for v in reversed(order):
        # dp[i]: number of ways to pick i edges in subtree
        dp[v] = [0] * (k + 1)
        cnt[v] = [0] * (k + 1)
        dp[v][0] = 1

        size = 0

        for to in g[v]:
            if to == parent[v]:
                continue

            ndp = [0] * (k + 1)
            ncnt = [0] * (k + 1)

            for i in range(size + 1):
                if dp[v][i] == 0:
                    continue
                for j in range(k - i + 1):
                    if dp[to][j] == 0:
                        continue
                    ways = dp[v][i] * dp[to][j] % MOD
                    ndp[i + j] = (ndp[i + j] + ways) % MOD

                    ncnt[i + j] = (ncnt[i + j] + cnt[v][i] * dp[to][j] + cnt[to][j] * dp[v][i]) % MOD

            dp[v], cnt[v] = ndp, ncnt
            size = min(k, size + k)

        # add node v itself contribution when connected
        for i in range(k + 1):
            cnt[v][i] = (cnt[v][i] + dp[v][i] * a[v]) % MOD

    ans = cnt[0][k] % MOD
    print(ans)

t = int(input())
for _ in range(t):
    solve()
```コードはツリーをボトムアップで処理します。 各サブツリーは、指定された数の選択されたエッジに寄与できる方法が何通りあるかを計算し、同時に重み付けされた寄与を累積します。 マージ ステップは、サブツリー サイズに対するナップザック畳み込みであり、独立した子サブツリーの組み合わせが正しくカウントされるようにします。 

微妙な部分は、寄与配列がカウント DP と一緒にマージされることです。 2 つのサブツリーを結合する場合、一方のサブツリーのすべての構成がもう一方のすべての構成とペアになるため、一方の側からの寄与にもう一方の側からのカウントを乗算する必要があります。 このため、アップデートでは以下の用語間のクロスタームが使用されます。`cnt`そして`dp`。 

最終的な答えはルートから正確に得られます。$k$選択されたエッジ。

 ## 特殊なケース

 縮退チェーンは、厳密な順序付け制約を最も明確に示します。 ノードがパスを形成する場合、すべてのエッジはその下のすべてのエッジに依存するため、その順序の逆転は無効になります。 サブツリーの寄与は子が処理された後にのみ上方にマージされ、子孫が常に最初に考慮されるようにするため、DP はこれを強制します。 

星型ツリーでは、根のエッジが選択されるまで、すべての葉のエッジは独立しています。 各リーフ サブツリーはナップザック マージで独立して寄与し、ルート接続のみが依存関係を導入するため、アルゴリズムはこれを処理します。 

いつ$k = 1$、DP はすべての有効なシングルエッジの選択肢をカウントすることになります。 寄与配列は、すべての可能な残りのコンポーネントにわたるノードの重みを合計するために折りたたまれます。これは、1 つのカットのみが実行され、各エッジが独立して残りの接続セットを決定するという直観と一致します。
