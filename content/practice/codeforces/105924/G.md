 ## 解決策
 ## 問題の理解

 n 個の頂点と m 個のエッジを持つ無向グラフが与えられます。 グラフには、同じ頂点ペアの間に自己ループと複数のエッジがすでに含まれている場合があります。 各エッジは通常の方法で端点の次数に寄与します。目標は、すべての頂点が最終的​​に均等な次数になるように、追加のエッジをできるだけ少なくしてグラフを変更することです。 

重要な自由度は、自己ループの追加を含め、頂点の任意のペアの間にエッジを追加できることです。また、同じ頂点のペアの間に複数のエッジを追加することもできます。 追加された各エッジは、標準の無向グラフと同じ方法で次数を変更します。つまり、自己ループはその頂点の次数に 2 を与えますが、u と v の間のエッジは両方の次数を 1 ずつ増加させます。 

出力には、追加されるエッジの最小数と、エッジを追加する 1 つの有効な方法の両方が記述されている必要があります。 

制約 n、m ≤ 10^5 は、グラフを線形時間で処理する必要があることを意味します。 頂点のペアを明示的に考慮しようとしたり、補助的な密な構造を構築したりするアプローチは、遅すぎます。 唯一の実行可能なアプローチは、問題を頂点パリティに対する単純な構造不変式に還元することです。 

重要な微妙な点は、自己ループの存在です。 自己ループは 2 を加算するため、頂点次数のパリティを変更しません。これは、自己ループはパリティを直接修正するのには役に立たないことを意味しますが、構築では依然として許可されており、単一の奇数頂点などの一部のエッジ ケースでは必要になる場合があります。 

2 番目の微妙な点は、グラフにすでに複数のエッジが含まれている可能性があるため、次数の計算は単純なグラフ構造を想定せず、純粋に出現数のカウントに依存する必要があることです。 

単純なアプローチでは、グローバル構造を使用せずに、任意の方法で奇数次の頂点を貪欲に接続しようとします。 これは、ローカル ペアリングの決定により最後に奇数の頂点がペアになっていない場合、たとえば奇数の頂点の数が一貫して追跡されていない場合に失敗する可能性があります。 

## アプローチ

 最初の自然な試みは、各頂点のパリティのみが重要であることを観察することです。 すべての頂点を奇数次数で計算し、それらを貪欲に修正しようとすることもできます。つまり、2 つの奇数の頂点を繰り返し選択してそれらを接続します。 追加された各エッジが両方のエンドポイントのパリティを反転するため、これは正しいように見えます。 

この貪欲なペアリングはすでに最適に近づいていますが、本当の問題は、頂点を恣意的にペアリングするよりもさらに複雑なことを行う必要があるかどうかです。 ブルートフォースの考え方は、エッジを追加するすべての可能な方法を検索して条件を検証することですが、エッジの選択ごとに 2 つのパリティが変更され、検索スペースが奇数の頂点の数と組み合わせて増加するため、それはすぐに指数関数的になります。 

重要な観察は、パリティが重要な唯一の制約であるということです。 エッジを追加するたびに 2 つの端点のパリティが反転されるため、奇数の頂点の総数は常に偶数になります。 したがって、問題は、奇数の頂点を任意にペアにし、各ペアをそれらの間にエッジを追加することによって固定することに帰着します。 このような各エッジは 2 つの奇数の頂点を同時に解決するため、ペア間の相互作用は必要ありません。 

微妙なケースが 1 つ残っています。奇数の頂点が 1 つだけ存在する場合、それを別の異なる頂点とペアにすることはできません。 この場合、唯一の有効な操作は、自己ループを使用してそれをそれ自体に接続することです。これにより、次数に 2 が加算され、パリティが固定されます。 

したがって、カウントが奇数の場合は自己ループを使用して、すべての奇数次の頂点を収集し、それらを任意の順序でペアにすることによって、解は完全に決定されます。

 ## アルゴリズムのチュートリアル

 グラフを処理し、次数同等性のみを使用します。

1. すべてのエッジを反復処理し、両方のエンドポイントを増分することにより、各頂点の次数を計算します。 自己ループは同じ頂点に 2 を寄与します。これはパリティには影響しませんが、次数の計算では引き続きカウントされます。 
2. 次数が奇数であるすべての頂点をリストに収集します。 このリストは、グラフの不均衡を正確に表しています。 
3. リストが空の場合、グラフはすでに条件を満たしているため、エッジを追加する必要はありません。 
4. リストの長さが奇数の場合は、そこから 1 つの頂点を取り出し、自己ループを使用してそれ自体に接続します。 これにより、概念的にはその頂点が奇数リストから削除されます。これは、そのパリティが 2 を加算した後の次数カウントで 0 mod 2 だけ反転するためです。 
5. これで、リストに残っているすべての頂点の数が偶数になります。 それらを順番にペアにします。頂点を一度に 2 つずつ順番に取得し、各ペアを新しいエッジに接続します。 
6. 構築されたすべてのエッジを出力します。 

順番にペアリングすることの背後にある理由は、各エッジが独立して正確に 2 つの奇数の頂点を固定し、他のエッジには影響を与えないため、どのペアリングも有効であるということです。 

### なぜ効果があるのか

 不変条件は、どの段階でも、奇数の次数を持つ頂点のセットが、リスト内で追跡しているセットとまったく同じであるということです。 各操作は、2 つの頂点 (u と v をペアにする場合) を削除するか、自己ループを介して最後のシングルトンを効果的に解決します。 各操作はパリティをローカルでのみ反転し、選択したエンドポイントの外側に新しい奇数頂点を決して導入しないため、このプロセスは、奇数頂点がなくなるまで厳密に奇数頂点の数を減らします。 奇数頂点の総数は、おそらく自己ループを介した単一頂点の一時的な処理を除いて常に偶数です。自己ループはパリティを変更しないため、正確性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    deg = [0] * (n + 1)

    for _ in range(m):
        u, v = map(int, input().split())
        deg[u] += 1
        deg[v] += 1

    odd = []
    for i in range(1, n + 1):
        if deg[i] % 2 == 1:
            odd.append(i)

    res = []

    # If odd count is odd, fix one vertex with a self-loop
    if len(odd) % 2 == 1:
        x = odd.pop()
        res.append((x, x))

    # Pair remaining vertices
    for i in range(0, len(odd), 2):
        u = odd[i]
        v = odd[i + 1]
        res.append((u, v))

    print(len(res))
    for u, v in res:
        print(u, v)

if __name__ == "__main__":
    solve()
```この解決策は、度数配列を構築することから始まります。これは、パリティ情報を取得するために必要な唯一の構造です。 エッジを自由に追加できるため、隣接構造自体は無関係であり、接続性の制約は存在しません。 

奇数リストには、修正が必要な頂点が正確に保存されます。 自己ループを介した単一の残りの頂点の処理は、唯一の明らかではない実装の詳細です。 この手順を行わないと、奇数の頂点が存在すると 1 つの頂点が未解決のままになります。 

簡単にするために、ペアリングは直線的な順序で行われます。 どのペアリングも有効であるため、アルゴリズムのマッチングや最適化は必要ありません。

 ## 特殊なケース

 頂点が 1 つだけでエッジがないグラフでは、自己ループの必要性が明らかになります。 次数は 0 であり、すでに偶数であるため、アクションは必要ありません。 奇数リストは空であるため、アルゴリズムは空のリストを正しく生成します。 

処理後にちょうど 1 つの頂点が奇数次数を持つグラフには特別な処理が必要です。 たとえば、度が [1, 0, 0] の場合、奇数リストは [1] になります。 自己ループ ステップがないと、パートナー頂点がないため、アルゴリズムは失敗します。 自己ループは、(1, 1) を追加することでこれを解決します。これにより次数が 2 増加し、シングルトンを排除しながらパリティの正確性が維持されます。 

多くの奇数頂点を含む大きなグラフは、線形ペアリングを確認します。 すべてのエッジはちょうど 2 つの頂点でパリティを反転するため、奇数セットの任意のパーティションのペアリングは有効です。 このアルゴリズムは構造には依存せず、パリティ数のみに依存するため、奇数の頂点がグラフ全体に任意に分散されている場合でも正しいままです。
