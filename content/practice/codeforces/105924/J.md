 ## 解決策
 ## 問題の理解

 有向グラフが与えられます$n$都市にはラベルが付けられていますが、その端はわかりません。 代わりに、各ペアについて、到達可能性を記述する行列が示されます。$(i, j)$からの旅行が可能かどうかはわかります。$i$に$j$1 つ以上の指示された道路を使用する。 

私たちのタスクは、これらの異なる有向グラフの数を数えることです。$n$ノードは、これとまったく同じ到達可能性関係を生成します。 一方のグラフには現れてもう一方のグラフには現れない有向エッジが少なくとも 1 つ存在する場合、2 つのグラフは異なるものとみなされます。 

重要な問題は、到達可能性がグローバルな特性であることです。 単一のエッジを追加または削除すると、推移的なパスが原因で、多くの場所で到達可能性が変化する可能性があります。 したがって、単にエッジのサブセットをカウントしているのではなく、指定された推移閉包を正確に生成するエッジのサブセットのみをカウントしています。 

制約$n \le 2000$これは、いかなる組み合わせの方法でもエッジを直接反復できないことを意味します。 エッジのサブセット、さらにはパスのサブセットを考慮するアプローチは、すぐに指数関数的になります。 したがって、到達可能性マトリックスの構造は、有効なグラフを大きく制約する必要があります。 

微妙なエッジ ケースは、マトリックスが 2 つのノードが相互に到達できると示している場合です。 たとえば、次の場合$1$そして$2$相互に到達できる場合、それらはすべての有効なグラフ内で強く接続されたコンポーネントに属している必要があります。 これを無視して各ペアを個別に扱うと、誤って相互到達可能性を壊してしまうグラフを誤ってカウントしすぎてしまいます。 

到達可能性が 1 より大きいサイズのサイクルを形成する場合、別の障害モードが発生します。 たとえば、すべてのノードが他のすべてのノードに到達する三角形では、完全な双方向エッジ セットが強制されません。 多くの異なるエッジ セットが同じ強力な接続を生成するため、それらすべてをカウントする必要があります。 

## アプローチ

 ブルートフォースのアイデアは簡単です。すべての可能な有向グラフを反復処理します。$n$ノードの到達可能性を計算し (たとえば、各ノードから Floyd-Warshall または BFS を使用して)、それを指定された行列と比較します。 これは概念的には正しいですが、グラフの数は$2^{n(n-1)}$、これは実行可能な計算をはるかに超えています。$n = 20$。 

重要な観察は、到達可能性によってグラフが強く接続されたコンポーネントに分割されるということです。 各コンポーネント内では、すべてのノードが他のすべてのノードに到達する必要がありますが、コンポーネント間では、構造は到達可能性が半順序である有向非巡回グラフになります。 

この分解は 2 つの独立した計数問題を分離するため、非常に重要です。 まず、強く接続された各コンポーネントを有向グラフとして実現できる方法が何通りあるかを数えなければなりません。 第 2 に、コンポーネント間で、エッジの選択によって凝縮 DAG によって暗示される到達可能性構造が変更されないことを保証する必要があります。 

サイズのコンポーネント内$k$、到達可能性が完全であるグラフは、強接続の有向グラフに正確に対応します。 したがって、強く接続された有向グラフを数える必要があります。$k$ラベル付きノード。 これは、サブセットに対する包含-排他を使用して実行できます。すべての有向グラフから開始し、到達可能な閉じたサブセットを考慮して、強く接続されていないグラフを差し引きます。 

コンポーネント間では、到達可能性 DAG によって、コンポーネントのどのペアを方向的に接続する必要があるかが決まります。 この構造が修正されると、SCC の内部エッジを個別に選択し、到達可能性の制約を破壊しないコンポーネント間のエッジを選択することによって、すべての有効なグラフが取得されます。

 ## アルゴリズムのチュートリアル

 ### 1. 相互到達可能性に基づいてノードをグループ化する

 まず 2 つのノードを扱います$i$そして$j$与えられた行列に従ってそれぞれが他方に到達できる場合、同じグループに属しているものとみなされます。 これにより、グラフが等価クラスに分割されます。 

有効なグラフでは、相互到達可能性がまさに同じ強く接続されたコンポーネント内にあることの定義であるため、このステップは正当化されます。 

### 2. コンポーネント間の凝縮構造を構築する

 任意の 2 つのコンポーネントの場合$A$そして$B$、あるノードの場合、$A$のいくつかのノードに到達できます$B$、次に、内のすべてのノード$A$のすべてのノードに到達する必要があります$B$。 これにより、コンポーネント上に有向非環状構造が誘導されます。 

マトリックスによって暗示される到達可能性関係を使用して、これらのコンポーネントをトポロジー的に順序付けることができます。 

### 3. コンポーネントを考慮して問題を考慮する

 コンポーネントが特定されると、全体的な答えは、各コンポーネントからの独立した寄与と、許容されるコンポーネント間構造の積になります。 

この因数分解が機能する理由は、凝縮構造が固定されると、コンポーネント内のエッジが異なるコンポーネント間の到達可能性に影響を与えないためです。 

### 4. 各コンポーネント内の強く接続されたグラフを数える

 サイズのコンポーネントの場合$k$、有向グラフの数を数えます。$k$ラベル付きノードは強く接続されています。 

あるという事実から始めます。$2^{k(k-1)}$自己ループのない有向グラフ。 ここから、強く結びついていないグラフを差し引きます。 空ではない適切なサブセットが存在する場合、グラフは強く接続されていません$S$エッジが入らないように$S$すべてのノードが内部にある間、外部から$S$到達可能性の下で内部的に閉じられています。 

これにより、サブセットに対する標準的な包含-除外 DP が得られ、固定ノードから到達可能なセットが選択されたサブセット内にあるグラフの数が計算されます。 

### 5. 結果を結合する

 各コンポーネントの強接続カウントを乗算し、クロスコンポーネント エッジからの寄与を乗算します。これは、凝縮 DAG によって決定され、すでに指定されているものを超えて到達可能性を変更しません。 

### なぜ効果があるのか

 正確性は、到達可能性がグラフを強く接続されたコンポーネントに分割し、各コンポーネント内で唯一の制約が強い接続性自体であるという事実に依存します。 コンポーネントが固定されると、異なるコンポーネント間のエッジはコンポーネントの内部到達可能性構造を変更できなくなり、無効なコンポーネント間のエッジは直ちに指定された到達可能性マトリックスと矛盾します。 この分離により、重複や二重カウントを発生させることなく、コンポーネントごとに独立してカウントを実行できることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

# Precompute powers up to n^2
def modpow(base, exp):
    res = 1
    while exp:
        if exp & 1:
            res = res * base % MOD
        base = base * base % MOD
        exp >>= 1
    return res

def solve():
    n = int(input())
    a = [list(map(int, input().split())) for _ in range(n)]

    # Step 1: build SCCs using mutual reachability
    comp = [-1] * n
    comps = []

    for i in range(n):
        if comp[i] != -1:
            continue
        stack = [i]
        comp[i] = len(comps)
        cur = [i]

        while stack:
            u = stack.pop()
            for v in range(n):
                if a[u][v] == 1 and a[v][u] == 1 and comp[v] == -1:
                    comp[v] = comp[u]
                    stack.append(v)
                    cur.append(v)

        comps.append(cur)

    # Step 2: precompute powers for SCC counting
    max_k = max(len(c) for c in comps)
    pw = [1] * (max_k * max_k + 1)
    for i in range(1, len(pw)):
        pw[i] = pw[i - 1] * 2 % MOD

    # Step 3: DP for strongly connected graphs
    # f[k] = number of strongly connected digraphs on k nodes
    f = [0] * (max_k + 1)
    f[0] = 1

    for k in range(1, max_k + 1):
        total = pw[k * (k - 1)]
        bad = 0
        # inclusion-exclusion over first node's reachable set
        for mask in range(1, 1 << k):
            size = bin(mask).count("1")
            ways = pw[size * (size - 1)]
            if size < k:
                bad = (bad + ways * f[k - size]) % MOD

        f[k] = (total - bad) % MOD

    # Step 4: multiply component contributions
    ans = 1
    for c in comps:
        ans = ans * f[len(c)] % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```実装は、指定された相互到達可能性関係を使用して、ノードを強く接続されたコンポーネントにグループ化することから始まります。 コンポーネントが識別されると、各コンポーネントは独立して処理されます。 

2 のべき乗の事前計算は、固定数のノード上のすべての有向グラフを迅速にカウントするために使用されます。$k$-ノード有向グラフには$k(k-1)$可能なエッジ。 

動的プログラミング部分は、サブセットに対する包含排他を使用して、強く接続された有向グラフの数を計算します。 用語`total`すべてのグラフをカウントしますが、`bad`より小さな閉じた構造に分割することで、強力な接続に失敗したものを差し引きます。 

最後に、各 SCC が有効なグラフの総数に独立して寄与するため、すべてのコンポーネントの結果を乗算します。

 ## 特殊なケース

 単一ノード SCC の場合、アルゴリズムは次のように割り当てます。$f[1] = 1$というのは、グラフが 1 つだけ存在し、それが自明に強く結びついているからです。 

完全に接続された到達可能性マトリックスの場合、すべてのノードが 1 つの SCC 内にあります。 このアルゴリズムは、問題を、強く接続されたすべての有向グラフを数えるというものに縮小します。$n$包含-排他により、マトリックス内ですべてのペアが相互に到達可能であっても、誤って接続を切断したグラフが確実に除外されます。 

完全に順序付けされた到達可能性 (上三角行列) を実現するために、各ノードは独自の SCC を形成します。 到達可能性の制約に違反せずにエッジを追加する自由がないため、結果は 1 になります。
