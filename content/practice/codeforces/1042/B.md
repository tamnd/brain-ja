 ## 解決策

 ## 問題の理解

 ジュースのオプションのコレクションが与えられます。各オプションにはコストと、それが提供する一連のビタミンが含まれています。 ビタミンは合計で 3 つだけで、A、B、C とラベルが付けられています。Petya がジュースのセットを購入すると、それらのジュースに含まれるすべてのビタミンを効果的に摂取することになります。 目標は、総コストを最小限に抑えながら、3 つのビタミンすべてがカバーされるようなジュースのサブセットを選択することです。 

これは順序付けや順序付けの問題ではなく、最大 1000 項目にわたる純粋なサブセット選択の問題です。 各アイテムは次のいずれか 1 つだけを提供します$2^3 - 1 = 7$ビタミンの組み合わせが考えられるため、問題の構造は大幅に圧縮されています。 タスクは、和集合が完全な集合 {A, B, C} に等しい最も安価な組み合わせを見つけることです。 

制約$n \le 1000$これは、項目に関する二次解であっても境界線にあるものの、最適化された形式ではまだ実現可能であることを意味します。 ただし、すべてのジュースの完全なサブセットの列挙を試みるアプローチはすべて、$2^{1000}$、無理です。 すべてのサブセットにわたる単純な DP さえも除外されます。 重要な制限は、状態空間がジュースの数ではなく、ビタミンの組み合わせの数によって定義されることです。 

複数のジュースが同じビタミンマスクを共有していてもコストが異なる場合、微妙な問題が発生します。 たとえば、2 つのジュースが両方ともビタミン A のみを提供する場合、最適なソリューションではより高価なジュースは決して使用されないため、最も安価なジュースのみを気にすることになります。 もう 1 つのエッジ ケースは、ジュースに必要なビタミンがまったく含まれていない場合です。たとえば、C を含むジュースがない場合です。この場合、A と B が完全にカバーされている場合でも、答えは -1 でなければなりません。 

さらに例外的なケースは、単一のジュースにすべてのビタミン A、B、および C が含まれる場合です。そのジュース単独は、安価な部分ジュースを組み合わせた場合と比較して最適である場合とそうでない場合があります。 常に最も「完全な」ジュースを好む貪欲なアプローチは、A+B+C のコストが 100 であるのに、A、B、C のコストがそれぞれ 1 であるような場合には失敗します。 

## アプローチ

 直接的な強引なアイデアは、ジュースのすべてのサブセットを考慮し、ビタミンの結合と総コストを計算することです。 これはすべての可能性を検討するため正しいですが、反復処理が必要です。$2^n$サブセット。 と$n = 1000$、これは天文学的に大きく、計算限界をはるかに超えています。 

重要な観察は、ビタミンのスペースが小さいことです。 すべてのジュースは 1 ～ 7 の範囲のマスクに対応し、各ビットは A、B、または C が存在するかどうかを表します。 ジュースのサブセットを選択することを考える代わりに、マスクの組み合わせを選択することを考えることができます。 

マスクによってジュースを圧縮すると、ビットごとの OR が 7 に等しい最大 3 ビットのマスクのマルチセットを選択して、コストを最小限に抑えるという問題が生じます。 これは、ビットマスクに対する動的プログラミング、または単純に各マスクの最小コストを維持して、1、2、または 3 つのマスクのすべての組み合わせを試すことを示唆しています。 

マスクは 7 つしかないため、マスクのすべてのペアとトリプルを安全に列挙して、最適な組み合わせを計算できます。 これにより、問題が指数関数的に減少します。$n$マスク上の定数時間へ。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | サブセットに対するブルート フォース |$O(2^n \cdot n)$|$O(n)$| 遅すぎる |
 | ビットマスク圧縮 + 列挙 |$O(n + 7^3)$|$O(7)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各ジュースのビタミン文字列を 3 ビット マスクに変換します (A = 1、B = 2、C = 4)。これにより、各項目が 1 ～ 7 の数値に減ります。このステップにより、問題が固定状態の最適化問題に変わります。 
2. 配列を維持する`best[8]`、無限大で初期化されます。`best[m]`マスクに正確に一致するジュースの最小コストを保存します`m`。 ここでは、各タイプの最も安価な代表のみを考慮します。 
3. 各ジュースについて、そのマスクを計算して更新します。`best[mask] = min(best[mask], cost)`。 これにより、支配的な選択を維持することがなくなります。 
4. もし`best`組み合わせても必要なビットをすべてカバーする方法はありません。後で実現可能性をチェックすることで検出します。 
5. マスクのすべてのペアを列挙します`(i, j)`そして計算する`best[i] + best[j]`、OR が 7 に等しいものを追跡します。これは、1 つまたは 2 つのジュースを使用するソリューションをカバーします。 
6. すべてのトリプルを列挙する`(i, j, k)`同様に、チェック`i | j | k == 7`、回答を更新します。 これにより、3 つの部分ジュースが必要な場合にも確実に対応できます。 
7. 有効な最小合計を返します。完全なカバレッジを達成できる組み合わせがない場合は -1 を返します。 

### なぜ効果があるのか

 すべてのジュースは、ビタミン マスクによって定義された 7 つの同等クラスの 1 つに属します。 最適なソリューションは、選択したマスクごとに最大でも 1 つの代表を使用するソリューションに変換でき、選択したジュースを同じマスクの安価なものに置き換えても、結果が悪化することはありません。 ターゲット空間は 7 つの州のみであるため、ビタミンの実行可能な結合を表すには、最大 3 つのマスクのすべての組み合わせを列挙するだけで十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = 10**18

n = int(input())
best = [INF] * 8

for _ in range(n):
    parts = input().split()
    c = int(parts[0])
    s = parts[1]

    mask = 0
    for ch in s:
        if ch == 'A':
            mask |= 1
        elif ch == 'B':
            mask |= 2
        else:
            mask |= 4

    best[mask] = min(best[mask], c)

ans = INF

for i in range(1, 8):
    if best[i] == INF:
        continue
    if i == 7:
        ans = min(ans, best[i])

for i in range(1, 8):
    for j in range(1, 8):
        if best[i] == INF or best[j] == INF:
            continue
        if (i | j) == 7:
            ans = min(ans, best[i] + best[j])

for i in range(1, 8):
    for j in range(1, 8):
        for k in range(1, 8):
            if best[i] == INF or best[j] == INF or best[k] == INF:
                continue
            if (i | j | k) == 7:
                ans = min(ans, best[i] + best[j] + best[k])

print(-1 if ans == INF else ans)
```このソリューションでは、まず各ジュースをビットマスクに圧縮し、次にマスクあたりの最も安価なコストのみを維持することで重複を削減します。 最終的な答えは、最大 3 つのマスクを総当たり的に組み合わせて計算されます。 状態空間が 7 に固定されているため、トリプル ループは安全であり、全体の演算は一定のままです。 

微妙な点は、マスクを組み合わせて繰り返し使用できることです。これは正しいことです。1 つの安価なマスクでは他のマスクと合わせて完全にカバーできない場合、同じマスクで 2 つの異なるジュースを購入する必要がある場合があるからです。 

## 実用的な例

 ### 例 1

 入力:```
4
5 C
6 B
16 BAC
4 A
```ジュースをマスクにマッピングします。 

| ジュース | マスク | コスト |
 | --- | --- | --- |
 | C | 4 | 5 |
 | B | 2 | 6 |
 | BAC | 7 | 16 |
 | あ | 1 | 4 |

 圧縮後、`best`は:

 A=4、B=6、C=5、ABC=16。 

次に、組み合わせを評価します。 

| ステップ | 選ばれたマスク | または | コスト |
 | --- | --- | --- | --- |
 | シングル | (7) | 7 | 16 |
 | ペア | (1,2,4) | 7 | 4+6+5=15 |

 最小値は 15 です。 

これは、1 つのジュースですべてのビタミンをカバーできるとしても、安価な部分的なものを組み合わせた方が優れていることを裏付けています。

| ステップ | 組み合わせ | または | 有効 |

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    INF = 10**18
    n = int(input())
    best = [INF] * 8

    for _ in range(n):
        parts = input().split()
        c = int(parts[0])
        s = parts[1]

        mask = 0
        for ch in s:
            if ch == 'A':
                mask |= 1
            elif ch == 'B':
                mask |= 2
            else:
                mask |= 4

        best[mask] = min(best[mask], c)

    ans = INF

    for i in range(1, 8):
        if best[i] < INF and i == 7:
            ans = min(ans, best[i])

    for i in range(1, 8):
        for j in range(1, 8):
            if best[i] < INF and best[j] < INF and (i | j) == 7:
                ans = min(ans, best[i] + best[j])

    for i in range(1, 8):
        for j in range(1, 8):
            for k in range(1, 8):
                if best[i] < INF and best[j] < INF and best[k] < INF and (i | j | k) == 7:
                    ans = min(ans, best[i] + best[j] + best[k])

    return "-1" if ans == INF else str(ans)

 ## 特殊なケース

 主なエッジケースは、複数のジュースが同じマスクを共有する場合です。 アルゴリズムは、次のようにしてそれらを正しく折りたたみます。`best[mask]`、最安のみを確保することが考慮されます。 たとえば、A のコストが 5 で、別の A のコストが 2 の場合、2 だけが保持され、A を含む最適なソリューションではそれが使用されます。 

もう 1 つのケースは、最適なソリューションで使用されるジュースが 3 つ未満の場合です。 列挙には単一とペアの組み合わせが明示的に含まれるため、(A+B+C in one Juice) や (A+B, C) などのソリューションがすべてカバーされます。 

最後に、マスクのどの組み合わせも欠落ビットを生成できないため、不可能なケースはきれいに処理されます。 どのマスクにもビタミン C が含まれていない場合、すべての OR が 3 以下のままとなり、アルゴリズムは更新されません。`ans`、結果は -1 になります。
