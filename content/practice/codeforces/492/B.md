 ## 解決策
 ## 問題の理解

 通り全体が照らされるように、長さ _l_ の直線道路に沿って配置されたランタンの最小光半径を決定するように求められます。 各ランタンは通り沿いの固定位置にあり、左右の距離 _d_ 以内の点を照らすことができます。 目標は、道路上の 0 から _l_ までのすべての点が少なくとも 1 つのランタンの光半径内に収まるように、最小の _d_ を見つけることです。 

入力は、提灯の数 _n_、街路の長さ _l_、および提灯の位置で構成されます。 ランタンは通りの端に配置することも、複数のランタンが同じ位置を共有することもできます。 

制約は中程度です。 _n_ ≤ 1000 および _l_ が 10^9 までの場合、O(n log n) を超える複雑さの解はおそらく不要です。 ランタンの位置を O(n log n) でソートすることは可能です。 通りの長さが長いため、通りに沿ったすべてのポイントを総当りチェックすることは不可能です。 

単純なアプローチを破る可能性のあるエッジ ケースとしては、位置 0 または _l_ にランタンが配置されている場合、ランタンが端に隙間を残してクラスター化されている場合、またはランタンが 1 つだけである場合などがあります。 たとえば、位置 [0] にランタンがある長さ 10 の道路には半径 10 が必要ですが、[0,10] には 5 しか必要ありません。道路の端を無視する不用意なアルゴリズムでは、必要な半径が過小評価されます。 

## アプローチ

 強引なアプローチでは、通りに沿ったすべての点が考慮され、最も近いランタンまでの距離がチェックされます。 任意の点からランタンまでの最大距離によって必要な半径が定義されるため、これは正しいですが、街路の長さが 10^9 までの場合、これでは遅すぎます。 

重要な観察は、問題がソートされたランタンの位置間の距離に帰着できるということです。 ランタンを分類した後、連続するランタン間の最大の間隔によって、通りの中央部分をカバーするために必要な最小半径が決まります。 道路は最初のランタンより前から始まり、最後のランタンより後に終わる場合があるため、道路の最初と最後の地点までの距離も個別に考慮する必要があります。 

最小半径 _d_ は、連続するランタン間の最大距離の半分、最初のランタンから通りの始まりまでの距離、最後のランタンから通りの終わりまでの距離の 3 つの値の最大値であることがわかります。 これにより、問題は単純な並べ替えといくつかの比較に減ります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(l * n) | お(1) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ランタンの数 _n_ と街路の長さ _l_ を読み取り、ランタンの位置をリストに読み込みます。 ランタンの位置を並べ替えることで、連続するギャップを効率的に分析できるようになります。 
2. ランタンの位置を昇順に並べ替えます。 ソートにより、連続するランタン間の最大ギャップを 1 回のパスで計算できます。 
3. 連続するランタン間の最大距離を計算します。 連続する各ペアについて、距離の半分を計算します。 これは、中央のセグメントがランタンで完全にカバーされるために必要な半径を表します。 このような最大の半距離を保存します。 
4. 最初のランタンから通りの始まりまでの距離と、最後のランタンから通りの終わりまでの距離を計算します。 これらの距離により、道路の終点が確実に点灯します。 
5. 答えは、半値ギャップの最大値と道路の端点までの距離です。 この値を十分な精度で出力します。

このアルゴリズムが機能するのは、ランタン間の最大ギャップによって中間セグメントのカバレッジが制御され、エンドポイントが個別に処理されるためです。 光は左右に均等に広がる性質があるため、ランタン間の隙間を半分にすれば、ランタン間のすべての点をカバーするのに十分であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, l = map(int, input().split())
lanterns = list(map(int, input().split()))

lanterns.sort()

# largest half-gap between consecutive lanterns
max_gap = max((lanterns[i+1] - lanterns[i]) / 2 for i in range(n-1))

# distance from street ends
left_edge = lanterns[0] - 0
right_edge = l - lanterns[-1]

# the required radius
d = max(max_gap, left_edge, right_edge)

print(f"{d:.10f}")
```コードは最初にランタンを並べ替えてギャップを評価します。 この内包では、内部カバレッジを処理するために、連続する各ギャップの半分が計算されます。 端までの距離は明示的に計算されます。 最大値を取ると、すべてのセグメントが確実にカバーされます。 小数点以下 10 桁で印刷すると、精度要件を満たします。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n log n) | ソートが優先され、他のすべてのステップは O(n) |
 | スペース | O(n) | ランタンの位置を保存する |

 n ≤ 1000 の場合、O(n log n) の操作は簡単です。 メモリ使用量は 256 MB 制限を大幅に下回っています。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, l = map(int, input().split())
    lanterns = list(map(int, input().split()))
    lanterns.sort()
    max_gap = max((lanterns[i+1] - lanterns[i])/2 for i in range(n-1)) if n > 1 else 0
    left_edge = lanterns[0] - 0
    right_edge = l - lanterns[-1]
    d = max(max_gap, left_edge, right_edge)
    return f"{d:.10f}"

# Provided sample
assert run("7 15\n15 5 3 7 9 14 0\n") == "2.5000000000", "sample 1"
# Single lantern at start
assert run("1 10\n0\n") == "10.0000000000", "single lantern at start"
# Single lantern at end
assert run("1 10\n10\n") == "10.0000000000", "single lantern at end"
# Two lanterns at ends
assert run("2 10\n0 10\n") == "5.0000000000", "two lanterns at ends"
# Lanterns clustered in middle
assert run("3 10\n4 5 6\n") == "4.0000000000", "clustered middle lanterns"
# Lanterns at 0, 1, 2, ..., 1000 on length 1000
assert run("1001 1000\n" + " ".join(str(i) for i in range(1001)) + "\n") == "0.5000000000", "dense lanterns"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 10\n0 | 10.0000000000 | スタート時に 1 つのランタンが通り全体をカバー |
 | 1 10\n10 | 10.0000000000 | 端に 1 つのランタン | 写真
 | 2 10\n0 10 | 5.0000000000 | 端に 2 つのランタン、中央のカバレッジ |
 | 3 10\n4 5 6 | 4.0000000000 | ランタンが集まって端が露出 | 写真
 | 1001 1000\n0..1000 | 0.5000000000 | 密集したランタン、最小限の半径 |

 ## 特殊なケース

 すべてのランタンが同じ位置、たとえば長さ 10 の道路上の [5] にある場合、連続するランタン間の最大ハーフギャップは定義されていないため、n=1 を個別に処理する必要があります。 開始点と終了点までの距離によって半径が決まります。0 に到達するには 5、10 に到達するには 5 なので、半径は max(5,5)=5 となります。 

ランタンが端にある場合、アルゴリズムは最も近い端までの距離がゼロであると正しく計算し、内部のギャップのみを考慮します。 街路の長さが 10 でランタン [0,10] の場合、最大ギャップは 10 なので、半分は 5 になります。
