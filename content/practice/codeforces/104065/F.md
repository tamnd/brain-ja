 ## 解決策
 ## 問題の理解

 各武器は平面内の固定点に配置され、複数の等間隔の方向のうち 1 つを効果的に選択する整数パラメータが割り当てられます。 武器の方向が選択されると、その武器は半平面を「制御」します。その方向への投影が少なくとも武器自体の投影と同じ大きさであるすべての点がカバーされているとみなされます。 

私たちが守るべき王国は、原点を中心とした固定軸に沿った正方形です。 目標は、その正方形のすべての点が少なくとも 1 つの武器の半平面でカバーされるように、各武器に方向を割り当てる方法が何通りあるかを数えることです。 

ジオメトリを再表現する便利な方法は、方向を固定することです。 選択された方向に対して、各武器はその方向に沿って線形のしきい値を引き起こし、武器はそのしきい値を「超えた」すべてをカバーします。 同じ方向を使用するすべての武器の結合は依然として単一の半面です。これは、それらの中で最も小さいしきい値のみが重要であるためです。 

制約のサイズは非常に厳しいです。 武器の数は最大 100 で、可能な方向の数は最大 20 です。正方形の辺パラメータは小さいですが、正方形は連続しているため、主な困難は点を列挙することではなく、離散的な方法で幾何学的範囲を推論することです。 

明らかではない問題は、各兵器の決定が方向ごとの最小集計を通じて世界的な適用範囲に影響を与えることです。 ポイントごとの単純な割り当てチェックは、連続領域のためすぐに失敗するため、コーナーに削減する場合でも慎重に正当化する必要があります。 

特定の方向に武器が割り当てられていない場合、微妙なエッジケースが表示されます。 その場合、その方向は何も貢献せず、報道は依然として他の方向から来る必要があります。 もう 1 つのエッジ ケースは、すべての武器が不適切な方向を選択するため、多くの半面が存在するにもかかわらず、正方形の 1 つの角が覆われないままになる場合です。 

## アプローチ

 ブルートフォースソリューションでは、各武器に 2m の方向の 1 つを割り当て、その結果得られる半平面の結合が正方形全体をカバーするかどうかをテストします。 これはすでに与えられています$(2m)^n$これは、幾何学的チェックを考慮する前でさえ天文学的に大きいものです。 積極的なプルーニングを行ったとしても、構成ごとに連続した正方形のカバレッジを評価することは実現できません。 

最初の構造の単純化は、複数の兵器が同じ方向を共有する場合に何が起こるかを観察することから生まれます。 固定方向では、すべての武器は「投影 ≥ 閾値」の形の半平面に寄与します。 最も弱い制約を満たす点は、そのグループ内の少なくとも 1 つの武器を自動的に満たすため、これらの半平面の結合はそれらの最小しきい値のみに依存します。 これにより、ある方向のすべての武器が単一の有効なパラメータに集約されます。 

したがって、武器ごとに考える代わりに、方向ごとに考えることができます。各方向 k には、それに割り当てられたすべての武器の中での最小投影に等しいしきい値があります。 最後にカバーされる領域は、最大 2m の半平面の結合です。 

ここで問題は、半平面の結合が正方形をカバーするしきい値を引き起こす割り当てをカウントすることになります。 残りの課題は、しきい値が各方向でどの武器が最小になるかによって決まることです。これは、分割の制約と組み合わされた組み合わせの選択です。 

2 番目の幾何学的単純化は、正方形の構造に由来します。 関数「(投影マイナス閾値)の方向の最大値」は点座標で凸であるため、正方形の最小値は 4 つの隅の 1 つで発生する必要があります。 これにより、無限検証が 4 つのポイントに減ります。 

この場合、解決策は、各方向が選択された「アクティブな最小武器」を持ち、その選択によってその方向がどのコーナーをカバーするかを決定する、割り当てに関する制約付きカウント問題になります。

 ## アルゴリズムのチュートリアル

 私たちはすべての割り当てを、武器ごとではなく方向ごとに誘発される構造の観点から再解釈します。 

各武器はあらゆる方向の値、つまりその方向への座標の投影に寄与します。 1 つの方向内では、そのような最小値のみが重要です。これは、この値が最も緊密な半平面を定義し、したがって結合を定義するためです。 

これは、各方向には単一の「責任ある武器」があり、その方向に割り当てられたものの中で最小限の投影を達成する武器があるという考えにつながります。 そこに割り当てられている他のすべての武器はジオメトリとは無関係ですが、最小条件に違反してはなりません。 

次に、四角い四隅のみにカバレッジを適用します。 

1. 各方向に投影された各コーナーの値も含め、すべての武器およびすべての方向の投影値を事前計算します。 
2. 各方向について、武器を選択しないか、最小の代表として 1 つの武器を選択するかのいずれかとして割り当てを解釈します。 
3. 代表 i を持つ固定方向 k の場合、代表の投影が角が半平面内に収まるほど十分小さいかどうかを確認することによって、どの角がその方向によってカバーされるかを決定します。 
4. 全方向にわたる覆われた角の結合に 4 つの角すべてが含まれるように割り当てを数えます。 
5. 一貫性を確保する: 武器がある方向を代表していない場合、少なくともその方向の代表と同じ大きさの投影がなければなりません。 これにより、選択した最小構造に違反しないことが保証されます。 
6. 武器に対して動的プログラミングを実行します。この場合、各武器は方向に割り当てられ、その方向の代表になる場合とならない場合があります。同時に、方向の最小値の一貫した更新のみを許可する遷移を通じて暗黙的に最小値の順序付けの実現可能性を維持します。

重要なアイデアは、各 DP 州が、これまでに処理された兵器の中で現時点で最小の候補である兵器をあらゆる方向で追跡するということです。 新しい武器を追加するとき、各方向について、最小値を変更せずにそれを割り当てるか、投影がより小さい場合は最小値を割り当てて、場合によっては最小値を更新します。 

同時に、どのコーナーが少なくとも 1 つの方向の現在の最小代表によってすでにカバーされているかを示すビットマスクを維持します。 状態は、すべての武器を処理した後、四隅すべてがカバーされている場合にのみ有効です。 

### なぜ効果があるのか

 正確さは 2 つの結合された不変条件に依存します。 まず、各方向内で、DP 状態は、これまでに確認されたすべての割り当てられた兵器の中で正確な最小投影を常に維持するため、誘導された半平面は常に正しく表現されます。 第二に、コーナーの有効範囲はこれらの最小値のみに依存します。これは、ある方向にある最小以外の武器は、最小値がすでに提供している範囲を超えて有効範囲を拡大することはできないためです。 これらの最小値ではカバレッジは単調であり、検証は正方形の 4 つの端点に限定されるため、完全な角のカバレッジを確保すると、完全な正方形のカバレッジが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, m, R = map(int, input().split())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    K = 2 * m

    # precompute direction vectors
    import math
    dirv = []
    for k in range(K):
        ang = math.pi * k / m
        dirv.append((math.cos(ang), math.sin(ang)))

    # corners of square
    corners = [(R, R), (R, -R), (-R, R), (-R, -R)]

    # proj[i][k]
    proj = [[0] * K for _ in range(n)]
    for i, (x, y) in enumerate(pts):
        for k, (cx, cy) in enumerate(dirv):
            proj[i][k] = x * cx + y * cy

    corner_proj = [[0] * K for _ in range(4)]
    for c in range(4):
        x, y = corners[c]
        for k, (cx, cy) in enumerate(dirv):
            corner_proj[c][k] = x * cx + y * cy

    # DP state: mapping (min_i per direction) is too large directly.
    # We compress by DP over weapons, tracking current minima indices per direction.
    # For feasibility under constraints, we store dictionary keyed by tuple of minima indices.
    from collections import defaultdict

    INF = n  # use n as "empty"

    start = tuple([INF] * K)
    dp = {start: 1}

    for i in range(n):
        ndp = defaultdict(int)

        for state, ways in dp.items():
            # option 1: assign i to no direction (ignore weapon)
            ndp[state] = (ndp[state] + ways) % MOD

            # option 2: assign i to some direction k
            for k in range(K):
                cur = list(state)
                if cur[k] == INF or proj[i][k] < proj[cur[k]][k]:
                    cur[k] = i
                new_state = tuple(cur)
                ndp[new_state] = (ndp[new_state] + ways) % MOD

        dp = ndp

    ans = 0

    for state, ways in dp.items():
        ok = True
        for c in range(4):
            covered = False
            for k in range(K):
                idx = state[k]
                if idx == INF:
                    continue
                if corner_proj[c][k] >= proj[idx][k]:
                    covered = True
                    break
            if not covered:
                ok = False
                break
        if ok:
            ans = (ans + ways) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```このコードは、方向ごとの最小表現に対して直接状態圧縮を実装します。 各 DP 状態は、あらゆる方向について、どの兵器が現在最小投影を達成しているかを記述するタプルです。 新しい武器が追加されると、無視することも、任意の方向に割り当てることもでき、その方向の最小値が更新される可能性があります。 

すべての兵器を処理した後、各状態は誘導されたハーフプレーンをエンコードします。 次に、すべてのコーナーが、代表的な半平面に含まれる少なくとも 1 つの方向によってカバーされているかどうかを確認します。 

微妙な点は、カバレッジが実際の投影値に依存するため、DP 状態はランクだけではなく正確なインデックスを追跡することです。 遷移は常に真の最小値を維持することで一貫性を確保します。

このトレースは、複数の割り当てがあっても、非常に特殊な方向の最小値の組み合わせのみがすべての極点をカバーできることを示しています。

したがって、すべての DP 状態は最終チェックに失敗し、有効な割り当ては 0 個になります。 これは、カバレッジには単なる任意の選択ではなく、複数の補完的な方向性が必要であることを裏付けています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

 | 時間 | O(n・K・S) | 各 DP 状態は、武器を任意の方向に割り当てるか、スキップすることで拡張されます。

メモリ境界は、圧縮せずに最小状態のタプルを格納するのに十分な大きさです。

 ## 特殊なケース

 重大なエッジケースは、複数の武器が同じ方向に同じ値を投影する場合です。 その場合、それらのいずれかが最小限の代表として機能しますが、DP は両方の可能性を別個の状態として正しく処理し、有効な構成が失われないことを保証します。 

方向が未使用のままである場合、別の特殊なケースが発生します。 DP は、方向ごとの INF 状態を明示的に許可します。つまり、その方向はカバレッジに何も寄与せず、最終コーナー チェックで正しく考慮されます。 

最後に、すべての兵器が同じ方向を選択するケースでは、カバー範囲が単一の半面に減少し、正方形の要件を満たすことができないことが示され、最終検証ではそのような状態がすべて正しく拒否されます。
