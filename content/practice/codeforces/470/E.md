 ## 解決策
 ## 問題の理解

 を印刷する必要があります`n × n`文字を使用したチェス盤。 白い四角は次のように表されます。`.`と黒い四角形`#`。 左上隅の四角形は白で、実際のチェス盤と同じように色が水平方向と垂直方向に交互に表示されます。 

入力には単一の整数が含まれています`n`、ボードのサイズがわかります。 出力には次のものが含まれている必要があります`n`それぞれの行に`n`ボードの 1 つの行を説明する文字。 

制約は非常に小さいです。 以来`1 ≤ n ≤ 9`、すべてのセルを個別に生成する場合でも、最大で`81`操作。 合理的な解決策であればどれでも十分高速です。 このタスクは最適化ではなく、交互のカラー パターンを正しく再現することです。 

よくある間違いは、開始色を間違えることです。 たとえば:

 入力:```
1
```正しい出力:```
.
```左上の四角は白なので、最初の文字は`.`。 から始まる`#`ボード全体が反転してしまいます。 

もう 1 つの簡単な間違いは、各行内でのみ交互に配置しているのに、連続する行は反対の色で開始する必要があることを忘れていることです。

```正しい出力:```

エラーの 3 番目の原因は、off-by-one インデックス付けです。 色は、行と列の位置の合計が偶数か奇数かによって異なります。 パリティ ロジックを調整せずに 1 ベースのインデックスを使用すると、ボード全体が反転する可能性があります。 

## アプローチ

 最も直接的なアプローチは、すべての正方形を調べてその色を決定することです。 ポジションごとに`(row, col)`を含めるべきかどうかを決定します。`.`または`#`、その文字を現在の行に追加し、完成した行を出力します。 

しかないため、この強引なアプローチはすでに十分です。`n²`細胞。 と`n = 9`、最悪のケースには次のものが含まれます。`81`ポジション。 

重要な観察は、チェス盤の色が交互に切り替わることです。 行と列にゼロからインデックスを付けると、偶数で位置決めされます。`row + col`左上の四角形と同じ色を持ち、奇数の位置には`row + col`反対の色を持っています。 

左上の四角は白いので、次のように表されます。`.`、単純に出力します:```
.
```いつ`(row + col)`は偶数であり、```
#
```いつ`(row + col)`奇数です。 

これにより、簡単なパリティ チェックで各セルを個別に判断できるようになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(1) 出力を除く | 承認済み |

 この問題では、すべてのセルが出力に現れる必要があるため、総当たりアプローチと最適アプローチは事実上同じです。 

## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`。 
2. すべての行インデックスを反復処理します。`i`から`0`に`n - 1`。 
3. 現在の行を 1 文字ずつ構築します。 
4. 各列インデックスについて`j`から`0`に`n - 1`、計算する`(i + j) % 2`。 
5. 結果が次の場合`0`、追加`.`この四角形は左上の四角形と同じ色であるためです。 
6. それ以外の場合は追加します`#`色を交互にする必要があるためです。 
7. 行を作成したら、それを印刷します。 

### なぜ効果があるのか

 チェス盤は、隣接するマスの色を交互に切り替えます。 水平方向または垂直方向に 1 ステップ移動すると、パリティが変更されます。`row + col`したがって、パリティは色が本来あるべきものとまったく同じように交互になります。 左上の四角`(0,0)`偶数パリティを持ち、白です。 偶数パリティを持つすべての平方は受信します`.`、奇数パリティを持つすべての平方は受信します。`#`、必要なチェス盤のパターンを正確に生成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

for i in range(n):
    row = []
    for j in range(n):
        if (i + j) % 2 == 0:
            row.append('.')
        else:
            row.append('#')
    print(''.join(row))
```プログラムは基板サイズを読み取ることから始まります。 

外側のループは行を処理し、内側のループは列を処理します。 ポジションごとに`(i, j)`、のパリティ`i + j`色を決定します。 偶数パリティは同じ色に対応します。`(0, 0)`、白であり、次のように表されます。`.`。 奇数パリティは以下に対応します`#`。 

各行はリストに蓄積され、次を使用して文字列に変換されます。`''.join(row)`。 これにより、文字列の繰り返しの連結が回避され、実装がクリーンな状態に保たれます。 

最も一般的な実装上の間違いは、パリティ ルールを逆にしてしまうことです。 以来`(0,0)`白である必要があり、偶数パリティにマッピングする必要があります`.`それよりも`#`。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    n = int(input())
    out = []

    for i in range(n):
        row = []
        for j in range(n):
            row.append('.' if (i + j) % 2 == 0 else '#')
        out.append(''.join(row))

    return '\n'.join(out)
