 ## 解決策
 ## 問題の理解

 私たちは壁にそれぞれ高さの異なる一組の釘を与えられ、それぞれの釘には一定の長さのロープが結ばれています。 すべてのロープのもう一方の端はキャンディーに接続され、空中に浮いた一点を形成します。 目標はキャンディーを地面に降ろすことであり、これを行うにはロープを 1 つずつ切断します。 切断するたびにキャンディーを保持しているロープのセットが減り、残りのロープの長さが足りなくてキャンディーを地上に保持できない場合は、キャンディーが低くなる可能性があります。 

数学的には、各爪の高さは同じです$a_i$長いロープを持っています$b_i$。 キャンディーの高さは次の最小値によって決まります。$a_i + b_i$すべてのロープがまだ取り付けられています。 キャンディーを地面に着地させるには、高さとロープの長さの合計がゼロ以下になる最小値が必要です。 この質問では、これを達成するために切断するロープの最小数を尋ねます。 以来$n \le 50$すべての操作は単純な比較であり、問​​題は主に並べ替えとカウントに関するものであり、複雑なデータ構造や最適化に関するものではありません。 

一部のロープが単独で地面に到達するのに十分な長さの場合、明らかではないエッジケースが発生します。 たとえば、釘の高さよりも長いロープが存在する場合、キャンディーは切断されずにすでに地面または地面の下にあります。 もう 1 つの微妙な点は、キャンディーの高さは有効な最短のロープによって決まるため、最適な解決策には、最長のロープではなく、より高い釘に取り付けられたロープを最初に切断することが含まれる可能性があることです。 

## アプローチ

 ブルートフォース手法では、ロープのすべてのサブセットを考慮し、それらを 1 つずつ切断し、キャンディーが地面に到達するかどうかを確認します。 これが機能する理由は、$n \le 50$、 それで$2^{50}$部分集合は理論的には可能ですが、すべてを列挙することは不可能です。 ただし、重要な観察によりこれが単純化されます。キャンディーの現在の高さに比べて「短すぎる」ロープの数を知る必要があるだけです。 

釘を高さによって分類し、キャンディーの位置を超えた余分なロープの長さに焦点を当てることができます。 一番高い釘から始めて、ロープの高さと長さを合わせても地面に届かない場合は、切断する必要があります。 釘の高さの降順にロープを検討し、各ロープがこれまでに切断されたロープの数を超えて伸びているかどうかを確認することで、最小切断量を貪欲に計算できます。 これにより、問題が分類され、ロープを 1 回通過するだけで済みます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 (貪欲) | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 爪の本数を読み取る$n$。 各爪の高さを保存します$a_i$そしてロープの長さ$b_i$タプルとして。 
2. 爪を高さの高い順に並べ替えます$a_i$。 これにより、キャンディーの高さに最も影響を与えるロープを最初に考慮することが保証されます。 
3. カウンタの初期化`cuts = 0`これまでに切断されたロープの数を追跡します。 
4. ソートされたネイルを繰り返します。 各釘について、ロープの長さを確認してください$b_i$すでに切断されたロープの数以下です。 その場合は、カットしてもキャンディーをさらに下げることはできないため、スキップしてください。 それ以外の場合は増分します`cuts`キャンディーを降ろすにはこのロープを切る必要があるからです。 
5. すべての釘が考慮されるまで続けます。 カウンター`cuts`最後に、切断する必要があるロープの最小数が表示されます。 

効果がある理由: 最も高い釘を最初に考慮することで、キャンディーの落下を妨げる可能性のあるすべてのロープが確実に考慮されるようになります。 カットごとにキャンディーの有効最小高さが減少し、貪欲な基準により不必要なカットがカウントされないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        ropes = [tuple(map(int, input().split())) for _ in range(n)]
        # Sort by nail height descending
        ropes.sort(reverse=True)
        cuts = 0
        for i in range(n):
            height, length = ropes[i]
            # If current rope cannot be the limiting factor, skip
            if length <= cuts:
                continue
            cuts += 1
        print(cuts)

if __name__ == "__main__":
    main()
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`、各ロープをタプルとして保存し、降順で並べ替えて、最も高い釘を最初に処理します。 小切手`if length <= cuts`すでに短すぎてキャンディーの下降に影響を与えないロープの不必要な切断を避けるため、これは非常に重要です。 インクリメント`cuts`地面に届くまでに切らなければならないロープを貪欲に数えます。

 ## 特殊なケース

 すべてのロープが個別に地面に到達するのに十分な長さであれば、切断する必要はありません。 ロープがすべて短くても、最も高い釘のロープが最も短い場合は、複数回の切断が必要になる場合があります。 高さ順に並べ替えることで、最も高い釘が最初に処理され、必要なカットが過少にカウントされることを防ぎます。 たとえば、非常に高い釘と非常に短い長さに結び付けられた 1 本のロープは、最初に切断する必要がありますが、これはアルゴリズムが分類を通じて自然に処理します。
