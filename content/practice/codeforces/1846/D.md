 ## 解決策
 ## 問題の理解

 私たちには、垂直線に沿って配置されたいくつかの同一の三角形の「枝」で構成される様式化された図面が与えられます。 各枝は、固定基底長を持つ二等辺三角形です。`d`そして高さ`h`。 すべての三角形は同じ方向を向いています。底辺は水平で、頂点は上を向いていますが、垂直の幹は各底辺の中点を通過しています。 

各枝は特定の垂直位置に配置されます`y_i`、ベースの高さを表します。 三角形はすべて同じ形なので、変わるのは縦に積み上げたときにどれだけ重なるかだけです。 

タスクは、個々の三角形の面積の合計を個別に計算することではなく、それらの結合の面積を計算することです。 インクの重なりには追加のペイントが必要ないため、ペイントされた領域の重なりは 1 回だけカウントされます。 

それぞれの三角形には面積があります$$S = \frac{d \cdot h}{2}$$困難は重なりから生じます。2 つの三角形が垂直方向に十分に近い場合、それらはより小さい類似の三角形領域で重なり合い、この重なりは交差チェーンごとに 1 回減算する必要があります。 

この制約により、これは興味深いものになります。すべてのテスト ケースにわたる分岐の合計数は、最大 です。`2 · 10^5`、座標は最大で大きくなる可能性があります`10^9`。 すべての三角形のペアを比較するソリューションは遅すぎます。 

重要な微妙なケースは、複数の三角形が推移的にオーバーラップしているが、ペアごとのオーバーラップがすべて明らかではない場合です。 たとえば、三角形 A は B に重なり、B は C に重なりますが、A と C は直接重なる場合もあれば、そうでない場合もあります。 単純なペアワイズ ユニオン アプローチでは、二重にカウントしたり、連鎖した重複を見逃したりする危険があります。 

素朴な推論を打ち破るエッジケースには、次のようなものがあります。 

もし`d`とても大きくて、`h`小さくても適度な間隔がある`y_i`値は完全な重複を引き起こします。例:```
n = 3, d = 10, h = 1
y = [1, 2, 3]
```すべての三角形は完全に重なっているため、答えは 3 つの三角形領域ではなく 1 つの三角形領域だけです。 

もし`h`が大きく、ギャップが小さい場合、部分的な重なりが連続的に積み重なり、単一のマージされた形状が生成されます。 

これらの挙動は、この構造が基本的に、重複領域が高さの差に応じて線形に縮小する間隔の垂直方向の結合に関するものであることを示しています。 

## アプローチ

 直接的なアプローチは、各三角形を幾何学的形状として扱い、ペアごとの交差を使用して結合領域を計算することです。 三角形のすべてのペアについて、それらの重なり合う垂直スパンを計算し、それに応じて重なり合う領域を差し引くことができます。 

これはすぐに高価になります。`O(n^2)`ペアであり、各オーバーラップの計算は自明ではありません。 と`n`まで`2 · 10^5`、これは不可能です。 

重要な観察は、各三角形の形状が両方向に直線的であることです。底辺から上に移動するにつれて、水平方向の幅が直線的に減少します。 つまり、2 つの三角形間の重なりは、それらの底辺間の垂直距離のみに依存します。 

で並べ替えると`y_i`、三角形を昇順に処理し、ユニオンの現在の「アクティブなマージされたエンベロープ」を維持できます。 新しい三角形はそれぞれ次のいずれかを行います。 

1. 現在のマージされた上部の上で重なり合わずに開始し、その領域全体を提供します、または
 2. 部分的に重なるため、有効付加面積が減少します。 

オーバーラップ条件は純粋に 1 次元になります。隣接する 2 つの三角形の場合、垂直方向のギャップが以下の場合、オーバーラップが存在します。`h`。 オーバーラップが存在する場合、交差領域自体は、高さが次のより小さな三角形になります。`h - gap`、そのベースは比例して拡大縮小します。 

これにより、実行中のマージされた寄与を維持し、スキャン中に重複寄与を段階的に差し引くことができます。

 ## アルゴリズムのチュートリアル

 1. 三角形を底辺の高さで並べ替えます`y_i`。 これにより、重複はソートされた順序で近くの三角形とのみ発生する可能性があるため、各三角形を以前にマージされた構造とのみ比較することが保証されます。 
2. 総面積を 0 として初期化し、将来のオーバーラップに影響を与える最後の三角形を表す現在の「アクティブ セグメント」を維持します。 
3. 各三角形について、順番に次の操作を行います。 

前のアクティブな三角形と重ならない場合 (ギャップ ≥ h)、三角形領域全体を追加します。 

それ以外の場合は、オーバーラップ高さを次のように計算します。`h - gap`そして、単純合計から重複する三角形の領域を減算します。 
4. オーバーラップが発生した場合は、三角形をより高く拡張したままにして、実質的にマージされた「上部エンベロープ」を更新します。 
5. すべての三角形が処理されるまで続行します。 

重要な計算は、垂直にシフトされた 2 つの同一の二等辺三角形の間の重複領域です。 幅は高さに比例して増加するため、交点は高さの小さい相似三角形になります。`h - gap`, したがって、その面積は残りの高さの割合の二乗に比例します。 

### なぜ効果があるのか

 各三角形は、幅が均一に縮小する垂直方向の線形境界を定義します。 このような形状を線に沿って結合すると、あらゆる高さで最も高いアクティブ エンベロープが維持されます。 幅プロファイルは凸状で線形であるため、隣接しない三角形間の重なりは、並べ替えられた順序で中間のものによって完全に支配されます。 これにより、順番に処理することで交差を見逃したり、カバーされていない領域を二重にカウントしたりすることがないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, d, h = map(int, input().split())
        y = list(map(int, input().split()))

        base_area = d * h / 2.0
        ans = base_area

        for i in range(1, n):
            gap = y[i] - y[i - 1]
            if gap >= h:
                ans += base_area
            else:
                # overlapping part is a smaller similar triangle
                overlap_h = h - gap
                ratio = overlap_h / h
                overlap_area = base_area * ratio * ratio
                ans += base_area - overlap_area

        print(f"{ans:.10f}")

if __name__ == "__main__":
    solve()
```このコードは、次のように指定された暗黙的な構造をソートした後、左から右に段階的に面積を計算します。`y_i`。 基本三角形の面積は 1 回計算されます。 連続するペアごとに、垂直ギャップを介して重複が存在するかどうかを判断します。 

重なりがない場合は、三角形の領域全体が追加されます。 オーバーラップが存在する場合、類似度を使用してオーバーラップする三角形を計算します。オーバーラップの高さは線形に縮小するため、面積は二次的にスケールされます。 だからこそ、次のように掛けます。`(overlap_h / h)^2`。 

微妙な点は、完全なジオメトリを明示的に追跡する必要がないということです。 すべての三角形が同一で整列しているため、形状は高さの違いによって完全に決まります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n, d, h = map(int, input().split())
        y = list(map(int, input().split()))

        base_area = d * h / 2.0
        ans = base_area

        for i in range(1, n):
            gap = y[i] - y[i - 1]
            if gap >= h:
                ans += base_area
            else:
                overlap_h = h - gap
                ratio = overlap_h / h
                ans += base_area - base_area * ratio * ratio

        out.append(str(ans))

    return "\n".join(out)

 ## 特殊なケース

 最初のエッジケースは、すべてが`y_i`非常に近いです。 例えば：```
n = 3, d = 4, h = 2
y = [1, 2, 3]
```ここで、連続するすべてのギャップは次のようになります。`1`, そのため、新しい三角形はそれぞれ、前の三角形と大きく重なり合います。 アルゴリズムはオーバーラップ式を繰り返し適用し、増分寄与のみを縮小します。 最終結果は、三角形の面積の 3 倍ではなく、連続した縮小によって構築された 1 つの結合された形状になります。 

2 番目のエッジケースは、ギャップが正確に等しい場合です。`h`。 で：```
y = [1, 3], h = 2
```三角形は点で接しているだけです。 条件`gap >= h`オーバーラップ減算が発生しないようにするため、両方の完全な領域が加算されます。 これにより、浮動小数点ノイズが発生する可能性があるゼロ領域交差の誤った削除が防止されます。 

3 番目のケースは次の場合です。`d`または`h`浮動小数点精度が関係するほど十分に大きいです。 オーバーラップには二乗比が使用されるため、中間値は浮動小数点で保持する必要がありますが、すべての演算には最大でも次の有界積が含まれるため、安定したままになります。`1e10`スケール数値、十分に倍精度の精度の範囲内です。
