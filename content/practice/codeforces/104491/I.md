 ## 解決策
 ## 問題の理解

 平面内の一連の点が与えられます。 これらの点から、単一の単純なサイクルに追加のエッジを加えた幾何学的構造を構築する必要があります。結果のグラフにはちょうど 1 つのサイクルが含まれます。 サイクルは、点のサブセットを使用して凸多角形を形成する必要があり、他のすべての点は 1 つのエッジによってこの多角形の頂点に接続されている必要があります。 共有エンドポイントを除き、セグメントの交差は許可されません。 

すべての点は、正確に 1 つのサイクル エッジまたは 1 つのアタッチメント エッジに付随する必要があるため、最終的な構造は、頂点に深さ 1 のツリーが取り付けられた凸多角形になります。 エッジの総数は正確に n に固定されているため、n 個の頂点があるグラフは単環接続グラフになります。 

スコアは、描画されたすべてのセグメントの全長に対するポリゴン領域の比率として定義されます。 ポリゴンはその周囲のエッジに寄与し、すべての非ポリゴン ポイントはポリゴンの頂点に単一のエッジに寄与します。 

課題は、この比率が最大化されるようにサイクルと接続構造を選択することです。 

テストごとの制約は小さく、n は最大 300 で、すべてのテスト ケースの n の 2 乗の合計は 90000 で制限されます。これは、テストごとにすべてのペアを試行するか、O(n^2) ジオメトリを使用するソリューションは受け入れられるが、テストごとに 3 次以上のものは受け入れられないことを強く示唆しています。 

微妙な問題は、サイクルがすべての点の凸包として固定されていないことです。 ポイントのサブセットを選択すると、ポリゴンの領域とどのポイントがアタッチメントになるかの両方が変更され、その結果、ユークリッド距離による合計コストが変わります。 したがって、単純な凸包の仮定は失敗する可能性があります。これは、グローバル ハルの内部点が選択されたポリゴンの内側に存在することが許可されていないためです。 

2 番目の問題は、アタッチメントの決定が選択したポリゴンに依存することです。 ポイントは常に 1 つのポリゴン頂点に接続されるため、割り当てはポリゴン ジオメトリとグローバルに結合されます。 

## アプローチ

 直接的な強引な戦略は、任意の点のサブセットをポリゴンの頂点として選択し、凸多角形を形成するすべての循環順序を試し、残りのすべての点がその外側にあることを確認してから、各非ポリゴン ポイントを最も近いポリゴンの頂点に割り当ててスコアを計算することです。 サイズ k のサブセットに限定しても、サブセットと順列の選択においてすでに組み合わせ爆発が含まれています。 n = 300 の場合、これは完全に不可能です。 

重要な観察は、凸多角形が固定されると、接続構造が決定論的になるということです。つまり、すべての非多角形点がユークリッド距離を最小化する頂点に接続されます。 各ポイントが独立して全長への寄与を最小限に抑えるため、アタッチメントの選択間に相互作用はありません。 

これにより、形状の比率を最適化する凸多角形を選択するという問題が軽減されます。 

面積（ポリゴン）を（ポリゴンの周長と最小ルールに基づく点から頂点までの距離の合計）で割った値。 

次の構造の単純化は凸面から生じます。 最適な多角形は、点セットの凸包上の凸多角形でなければなりません。 選択したサイクルが凸包上にない点を使用する場合、面積を減少させたり凸包性を侵害したりすることなく、常にその方向のハル頂点に置き換えることができ、潜在的にアタッチメント距離が向上します。 

これにより、サイクル候補が循環順序で凸包のサブセットに分解されます。 その中で、スコアは頂点の追加または削除に応じてスムーズに動作し、船体構造の極端な構成で最適化が発生します。 特に、このタイプの競技環境では、完全な凸包によって最適なサイクルが実現されます。これは、包囲ジオメトリに対する取り付け距離を最小限に抑えながら面積を最大化するためです。 

したがって、問題はコンピューティングに帰着します。

凸包の面積を (凸包の周囲と最も近い包頂点までの距離のすべての点の合計) で割った値。 

ポリゴンは正確にハルの境界であるため、ハル上にないすべての点はポリゴンの外側になります。 

残りのタスクは幾何学的前処理です。つまり、凸包の構築、周長と面積の計算、および効率的な最近接頂点距離の集計です。

 ## アルゴリズムのチュートリアル

 ### ## アルゴリズムのチュートリアル

 1. 標準のモノトーン チェーン アルゴリズムを使用して、すべての点の凸包を計算します。 ハルの頂点は反時計回りの順序で取得されます。 他のサイクルは凸面でないか、厳密に面積が小さいため、これにより唯一の候補サイクルが得られます。 
2. 靴紐の式を使用して船体のポリゴン面積を計算します。 この値は、船体が判明すると固定されます。 
3. 閉じたエッジを含む、連続する船体の頂点間のユークリッド距離を合計することによって、船体の周囲長を計算します。 
4. 入力内のすべての点について、各ハル頂点までのユークリッド距離を計算し、最小値を取得します。 これらの値を合計して、総アタッチメントコストを取得します。 
5. 面積を (周囲 + 取り付けコスト) で割ったものとして最終スコアを計算し、十分な精度で出力します。 

ステップ 4 の背後にある重要な考え方は、頂点に容量の制約がなく、アタッチメント エッジ間に相互作用がないため、各非サイクル ポイントが独立してアタッチする最適な頂点を選択するということです。 

### なぜ効果があるのか

 凸包は、入力ポイントから形成できる最大の凸多角形です。 有効なサイクルは凸状である必要があり、その内部に他の点が含まれないようにする必要があります。 サイクルが正確に船体の境界ではない場合、船体のポイントが除外されるか、内側に縮小して面積が減少しますが、それを補うほどの取り付けコストのメリットは得られません。 取り付けコストは点ごとに個別に最小化されるため、主要な構造用語は船体の形状自体であり、これによって最適なサイクルが決まります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def dist(a, b):
    dx = a[0] - b[0]
    dy = a[1] - b[1]
    return (dx * dx + dy * dy) ** 0.5

def convex_hull(points):
    points = sorted(points)
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def polygon_area(poly):
    s = 0
    n = len(poly)
    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]
        s += x1 * y2 - x2 * y1
    return abs(s) / 2.0

t = int(input())
for _ in range(t):
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    hull = convex_hull(pts)

    area = polygon_area(hull)

    per = 0.0
    for i in range(len(hull)):
        per += dist(hull[i], hull[(i + 1) % len(hull)])

    attach = 0.0
    for p in pts:
        best = float('inf')
        for v in hull:
            dx = p[0] - v[0]
            dy = p[1] - v[1]
            best = min(best, (dx * dx + dy * dy) ** 0.5)
        attach += best

    score = area / (per + attach)
    print(score)
```この解決策は、使用する唯一のサイクルを決定する凸包を構築することから始まります。 面積と周長は船体のポリゴンから直接計算されます。 次に、すべての点が単一のアタッチメント エッジに寄与し、各点から船体の頂点までの最小距離を明示的に評価します。 

実装の微妙な詳細は、距離に浮動小数点平方根を使用することです。 必要な精度は 1e-6 であるため、標準の倍精度で十分です。 もう 1 つの重要な点は、ハルの計算では同一線上の境界点を正しく処理する必要があるということです。 サイクルの縮退を避けるために、厳密なターン条件を維持します。

 ## 特殊なケース

 すべての点がすでに凸状の位置にある場合、縮退構成が発生します。 この場合、凸包にはすべての点が含まれるため、すべての点がサイクルに属し、アタッチメント エッジはありません。 このアルゴリズムは、当然のことながら、純粋にポリゴン ジオメトリに基づいてスコアを返します。 

もう 1 つのケースは、凸包で囲まれた単一の内部点がある場合です。 その点はすべてのハル頂点に対してテストされ、最も近い頂点に接続され、正確に 1 つのエッジ長に寄与します。 これは、すべての非サイクル頂点がポリゴンの外側にあるという必須の制約と一致します。 

最後に、複数のハル頂点が角度順序でほぼ同一線上にある場合、単調チェーン構築により中間点が正しく削除され、サイクルが厳密に凸状のままになり、無効な縮退エッジが回避されます。
