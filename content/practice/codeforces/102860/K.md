 ## 解決策
 ## 問題の理解

 チェッカーには白駒と黒駒の2種類があります。 これらすべてを 1 つの垂直な塔に配置する必要があります。 黒のストライプは、黒のピースの最大連続ブロックであり、ブロック内のすべての黒のピースが上下の別の黒のピースと接触し、ブロックが白いピースまたはタワーの端によって他の黒いブロックから分離されていることを意味します。 

タスクは、すべてのピースの最適な順序を選択した後、可能な限り多くの個別の黒いストライプを見つけることです。 

入力には、白い部分の数と黒い部分の数が含まれます。 出力は、作成できる黒のグループの最大数です。 

この制約により、カウントを最大約 10^18 まで非常に大きくすることができます。 これにより、シミュレーション、タワーの建設、またはピースの数を超える動的プログラミングが即座に除外されます。 解決策は 2 つの量の間の数学的関係のみに依存し、一定時間で実行する必要があります。 

重要なエッジケースは、白い​​部分がセパレーターであるという事実から来ています。 たとえば、黒い部分が存在しない場合、黒い縞は存在しません。 

入力例:```
5 0
```正しい出力は次のとおりです。```
0
```常に少なくとも 1 つのストライプを返す解決策は間違っています。 

もう 1 つの重要なケースは、黒いピースはあるが白いセパレーターがない場合です。 

入力例:```
0 3
```可能なタワーは 3 つの黒いピースが一緒になったものだけです。したがって、答えは次のようになります。```
1
```黒のピースの数を返す不注意なアプローチでは、誤って 3 が出力されてしまいます。 

最後の境界ケースは、すべての黒い部分を分離するのに十分な白い部分がある場合です。 

入力例:```
10 3
```3 つの黒い部分は次のように配置できます。`BWBWB`、他の場所には白い部分が残っています。 答えは次のとおりです。```
3
```白い部分の数のみを答えとして考慮する解決策は、ストライプの数が黒い部分の数を超えることができないため、失敗します。 

## アプローチ

 強引な方法は、ピースの順序を変えて試し、その結果生じるストライプを数えることです。 考えられるあらゆる配置が考慮されているため、これは正しいですが、考えられる塔の数は膨大です。 10^18 個のピース​​では、塔を表現することすら不可能であるため、列挙やシミュレーションに基づくアプローチは機能しません。 

有益な観察は、白い部分が黒い部分の 2 つのグループの間に最大 1 つの分離を作成できるということです。 もし持っていれば`a`白い部分、彼らが作成できるのはせいぜい`a + 1`黒い縞模様が現れる場所: 最初の白い部分の前、白い部分の間、最後の白い部分の後。 

同時に、すべてのストライプに少なくとも 1 つの黒い部分が含まれている必要があります。 と`b`黒い部分、それ以上は作成できません`b`ストライプ。 

ストライプの最大数は、次の 2 つの制限のうち小さい方です。`min(number of black pieces, number of possible gaps created by whites)`最適な配置は、白をセパレーターとして使用して、可能な限り多くの利用可能なギャップに黒のピースを配置するだけです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(配置数) | O(個数) | 遅すぎる |
 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.白のピースと黒のピースの数を読み取ります。 
2.黒い部分がない場合は出力`0`ストライプには少なくとも 1 つの黒い部分が含まれている必要があるためです。 
3. 黒のストライプに使用できる位置の数を計算します。 と`a`白い部分があります`a + 1`タワー内の分離された領域の可能性があります。 
4. 答えは、黒のピースの数と利用可能な領域の数の小さい方の値です。 

これが機能する理由は、すべてのストライプが少なくとも 1 つの黒い部分を消費し、ストライプ間のすべての分離に白い部分が必要であるためです。 構築では、選択した各領域に 1 つの黒い部分を配置することで、常にこの境界を達成できます。 

なぜ効果があるのか:

 ある取り決めがあるとします。`x`黒い縞模様。 すべてのストライプには少なくとも 1 つの黒い部分が含まれているため、`x`黒のピースの合計数を超えることはできません。 また、連続するストライプの各ペアの間には、少なくとも 1 つの白い部分がなければなりません。`x`ストライプは少なくとも必要です`x - 1`白い区切り文字。 これは、ストライプの数が以下を超えることができないことを意味します`a + 1`。 両方の制限が必要であるため、答えはこれを超えることはできません`min(b, a + 1)`。 黒の部分または領域のいずれかがなくなるまで、利用可能な各領域に 1 つの黒の部分を配置することで、常に正確にその数のストライプを実現できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a, b = map(int, input().split())

    if b == 0:
        print(0)
    else:
        print(min(b, a + 1))

if __name__ == "__main__":
    solve()
```このソリューションは 2 つのカウントを直接読み取り、タワーを構築しようとしません。 値が反復するには大きすぎる可能性があるため、これが必要です。 

特別な取り扱いは、`b == 0`Python では厳密には必須ではありません。`min(0, a + 1)`もゼロを生成しますが、条件を維持すると推論が明確になります。 表現`a + 1`Python の整数には任意の精度があるため、安全です。

import sys
import io

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout
    return out

def solve():
    a, b = map(int, sys.stdin.readline().split())
    if b == 0:
        print(0)
    else:
        print(min(b, a + 1))

## 特殊なケース

 黒い部分がない場合:```
0 0
```アルゴリズムが見ているのは、`b == 0`そしてすぐにゼロを返します。 タワーには黒い部分が含まれていないため、黒い縞模様は存在しません。 

白い部分がない場合：```
0 3
```利用可能なリージョンの数は、`0 + 1 = 1`。 式は次のようになります`min(3, 1)`、与える`1`。 白いセパレーターがないため、黒い部分はすべて接続されたままでなければなりません。 

白い部分が多い場合：```
10 3
```がある`10 + 1 = 11`可能性のある領域ですが、黒い部分は 3 つだけです。 答えは`min(3, 11) = 3`。 それぞれの黒い部分は異なる領域を占めることができ、3 つの別々のストライプを作成できます。 

黒い部分が多いがセパレータが限られている場合:```
2 10
```あるのは`2 + 1 = 3`可能な地域。 黒い部分が 10 個存在する場合でも、形成できる縞は最大 3 つであるため、出力は次のようになります。```
3
```アルゴリズムは、一方の側だけを考慮するのではなく、両方の制限を適用することでこれを処理します。
