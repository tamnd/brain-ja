 ## 解決策
 ## 問題の理解

 色の循環シーケンスを構築する必要があります。`n`卵。 利用可能な色は正確に 7 色あります。`R, O, Y, G, B, I, V`2 つの条件が同時に成立する必要があります。 

まず、すべての色が少なくとも 1 回は出現する必要があります。 

次に、円上にある 4 つの連続した卵の各ブロックには、4 つの異なる色が含まれている必要があります。 卵は円を形成するため、シーケンスは回り込みます。 最後の卵と最初の卵も隣接しています。 

入力は 1 つの整数だけです`n`、卵の数。 出力は、任意の長さの有効なカラー文字列です。`n`。 

制約は非常に小さいです。`n`せいぜい`100`, そのため、かなり非効率なアプローチでも制限時間内に快適に実行できます。 このような小さな制限では、すべての色の割り当てに対する総当りのバックトラッキング ソリューションが理論的には可能ですが、分岐係数が依然として十分に大きいため、煩雑で不必要になります。 この問題は実際には建設的であり、常に機能する単純なパターンがあります。 

難しいのは円形の条件です。 直線的に動作するシーケンスは、ラップアラウンド後に失敗する可能性があります。 例えば：```
ROYGBIVR
```左から右にのみチェックすると問題ないように見えますが、最後の 3 文字と最初の 1 文字の形式は次のようになります。```
IVRR
```繰り返すこと`R`。 

もう 1 つのよくある間違いは、7 色すべてを一度使用し、最初から繰り返すことです。```
ROYGBIVROY...
```これは、4 つのウィンドウの一部に結合点付近で繰り返される色が含まれるため、失敗します。 

たとえば、`n = 8`:```
ROYGBIVR
```境界を越えて連続する 4 つの卵は次のとおりです。```
V R R O
```二`R`が表示されます。 

重要な点は、実際にはすべてのローカル ウィンドウで 7 色すべてが必要なわけではないということです。 必要なのは、連続する 4 つの卵の各グループがペアごとに区別されることだけです。 慎重に選択された繰り返しサフィックスは、その条件を無期限に満たすことができます。 

## アプローチ

 強引な解決策では、現在の部分シーケンスが「4 つの連続した個別」ルールに違反しているかどうかを確認しながら、各卵に 7 つの色のうち 1 つを割り当てようとします。 最後に、7 色すべてが使用されていることと、円形のラップアラウンド ウィンドウが有効であることも検証します。 

これは制約が小さいため機能しますが、検索空間は依然として指数関数的です。 最悪の場合は大まかに調査します`7^n`可能性は中等度であっても天文学的に大きい`n`。 枝刈りは役に立ちますが、建設的な問題を意図した場合、このアプローチは依然として不必要に複雑です。 

本当の洞察は、4 つの連続した卵の状態を研究することで得られます。 隣接する 4 つのブロックごとに異なる文字が含まれる有効な繰り返しパターンがすでにある場合、そのパターンを永久に繰り返すことは有効なままです。 

標準的な虹のシーケンス:```
ROYGBIV
```すでに条件を満たしています。 円形の重なりによって重複が生じるため、最初から繰り返し続けると問題が発生します。 

7 文字のパターン全体を繰り返すのではなく、4 つの異なる特性を維持する接尾辞のみを繰り返します。 シーケンス:```
GBIV
```その繰り返し内の連続する 4 つのブロックはすべて、別個の文字の回転であるため、永遠に繰り返すことができます。 

したがって、構造は次のようになります。 

1. から始める`"ROYGBIV"`7 色すべてが表示されることを保証します。 
2. 余分な位置ごとに、次から循環的に文字を追加します。`"GBIV"`。 

例`n = 10`:```
ROYGBIVGBI
```円形の境界を越える場合も含め、連続する 4 文字はすべて区別されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(7^n) | O(n) | 概念的には遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 基本文字列を作成します。```
ROYGBIV
```これにより、すべての色が少なくとも 1 回表示されることが直ちに保証されます。 

1. 追加で必要な文字の数を計算します。```
extra = n - 7
```1. 繰り返しパターンを使用します。```
GBIV
```このパターンが選択されるのは、繰り返されるコピー内の 4 文字の連続するブロックがそれぞれ異なるままであるためです。 

1. から文字を追加します。`"GBIV"`全長が長くなるまで周期的に`n`。 

もし`extra = 5`、次を追加します。```
GBIVG
```1. 最後の文字列を出力します。 

### なぜ効果があるのか

 最初の 7 文字には 7 色すべてが 1 回だけ含まれているため、最初の条件はすぐに満たされます。 

繰り返しの接尾辞`"GBIV"`長さは 4 で、4 つの文字はすべて別個です。 このパターンの繰り返されるコピー内の 4 つの連続したブロックは、同じ 4 文字の循環シフトにすぎないため、繰り返しは表示されません。 

間の境界`"ROYGBIV"`また、ベースの最後の数文字がすでに自然に整列しているため、追加されたサフィックスも機能します。`"GBIV"`。 

その結果、連続する 4 つの卵のすべての円形ウィンドウには 4 つの異なる色が含まれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    base = "ROYGBIV"
    extra_pattern = "GBIV"
    
    ans = base
    
    for i in range(n - 7):
        ans += extra_pattern[i % 4]
    
    print(ans)

solve()
```解決策は、必須の 7 色のシーケンスから始まります。 この問題ではすべての色が少なくとも 1 回表示される必要があるため、この部分は修正されました。 

残りのポジションは以下を使用して埋められます。`"GBIV"`周期的に。 モジュロ演算は、その 4 文字パターン内の折り返しを処理します。 

微妙な点は、最初の 7 文字の後にのみ追加することです。 7 文字の虹全体を繰り返すと、境界付近の円形の状態が崩れてしまいます。 

もう 1 つの重要な詳細は、回答の長さが正確に一致する必要があることです。`n`。 ループが回るから`n - 7`何度も、追加のチェックを行わなくても、最終的な長さは正確になります。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    n = int(input())
    
    base = "ROYGBIV"
    extra_pattern = "GBIV"
    
    ans = base
    
    for i in range(n - 7):
        ans += extra_pattern[i % 4]
    
    print(ans)

def run(inp: str) -> str:
    global input
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline
    
    out = io.StringIO()
    backup = sys.stdout
    sys.stdout = out
    
    solve()
    
    sys.stdout = backup
    return out.getvalue().strip()

# provided sample
assert run("8\n") == "ROYGBIVG", "sample 1"

# minimum size
assert run("7\n") == "ROYGBIV", "minimum n"

# one full extra cycle
assert run("11\n") == "ROYGBIVGBIV", "full GBIV repetition"

# off-by-one after cycle restart
assert run("12\n") == "ROYGBIVGBIVG", "cycle restart"

# maximum size length check
res = run("100\n")
assert len(res) == 100, "maximum size"

# all colors appear
for c in "ROYGBIV":
    assert c in res, "missing color"
