 ## 解決策
 ## 問題の理解

 詩の 3 つのフレーズを表す 3 行が与えられています。 有効な俳句には、最初の句にちょうど 5 つの母音文字、2 番目の句に 7 つ、3 番目の句に 5 つの母音文字が含まれている必要があります。 

この問題では、音節が母音の数に単純化されます。 小文字のみ`a`、`e`、`i`、`o`、 そして`u`母音とみなされます。 スペースは重要ではなく、単語は複数のスペースで区切ることができます。 先頭と末尾のスペースも使用できます。 

タスクは、3 行のそれぞれの母音を数え、その数が必要な母音と一致するかどうかを確認するだけです。`5-7-5`パターン。 

制約はわずかです。 各行の長さは最大 100 文字であるため、合計入力サイズは最大 300 文字になります。 非効率な解決策であっても、制限時間内に簡単に収まります。 各文字列を 1 回通過するだけで十分です。 

主な問題はパフォーマンスではなく、フォーマットを正しく処理することです。 単語の間に複数のスペースを入れることができます。また、行の先頭または末尾にスペースを入れることもできます。 単語を不用意に分割しようとするソリューションでは、誤って有効な文字を無視したり、空のトークンを誤って処理したりする可能性があります。 

次の入力を考えてみましょう。```
on  codeforces  
beta round is running
   a rustling of keys
```最初の行には複数のスペースと末尾のスペースが含まれています。 正しい出力は次のとおりです`YES`スペースは母音のカウントに影響しないためです。 

もう 1 つの簡単な間違いは、小文字の母音のみがカウントされることを忘れることです。 例えば：```
bcdfg
aeiouuu
hello
```母音の数は、`0`、`7`、 そして`2`、したがって、答えは次のとおりです`NO`。 

不注意に実装すると、母音の出現総数ではなく個別の母音をカウントする可能性があります。 例えば：```
aaaaa
aeiouae
eeeee
```カウントは次のとおりです`5`、`7`、 そして`5`。 一意の文字だけでなく、すべての母音の出現が重要です。 

## アプローチ

 最も直接的なアプローチは、各行を 1 文字ずつ処理し、母音セットに属する文字の数をカウントすることです。`{a, e, i, o, u}`。 3 行すべてのカウントを計算した後、次のように比較します。`[5, 7, 5]`。 

ここでは、入力が非常に小さいため、総当たり解釈でも快適に機能します。 各文字列をすべての母音に対して個別に繰り返しスキャンするとします。 各行の長さは最大でも 100 なので、それでも数百回の操作しかありません。 

もっと明確な観察は、単語の境界がまったく必要ないということです。 スペースは無関係で、すべての子音は単純に無視できます。 全体の問題は、各行で一致する文字を数えるということになります。 

この洞察により、非常にコンパクトな線形ソリューションが得られます。 各行を 1 回スキャンして母音を数え、その結果を必要なパターンと比較します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(5 × n) | お(1) | 承認済み |
 | 最適 | O(n) | お(1) | 承認済み |

 ここ、`n`3 行にわたる文字の合計数です。 

## アルゴリズムのチュートリアル

 1. 3 つの入力行を表示どおりに読み取ります。 
2. 必要な母音数を次のように保存します。`[5, 7, 5]`。 
3. 各行について、すべての文字をスキャンし、母音セットに属する文字の数を数えます。`{a, e, i, o, u}``。 
4. 現在の行のカウントをその位置の期待値と比較します。 

最初の行には 5 つの母音、2 行目には 7 個、3 行目には 5 個の母音が含まれている必要があります。 
5. 比較に失敗した行がある場合は、出力します。`NO`すぐに。 
6. 3 行すべてが必要な数と一致する場合、次のように出力します。`YES`。 

### なぜ効果があるのか

 この問題における有効な俳句の定義は、各句の母音文字の数のみに依存します。 アルゴリズムはそれらの文字を正確にカウントし、他の文字はすべて無視します。 すべての文字が 1 回チェックされ、すべての母音の出現がカウントに 1 つだけ寄与するため、計算された合計は正確です。 これらの合計を比較すると、`5-7-5`問題定義と直接一致するため、アルゴリズムは無効な詩を受け入れたり、有効な詩を拒否したりすることはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# solution

vowels = set("aeiou")
target = [5, 7, 5]

lines = [input().rstrip('\n') for _ in range(3)]

for i in range(3):
    count = 0

    for ch in lines[i]:
        if ch in vowels:
            count += 1

    if count != target[i]:
        print("NO")
        sys.exit()

print("YES")
```この解決策は、すべての母音をセット内に保存することから始まります。 セット内のメンバーシップ チェックは一定時間行われるため、実装がクリーンで効率的に保たれます。 

3 行は指定されたとおりに正確に読み取られます。 末尾の改行文字のみを削除します。`rstrip('\n')`。 プレーンを使用する`strip()`また、先頭と末尾のスペースも削除されますが、これは不要です。 ここでスペースは正確さに影響しませんが、元の入力形式を保持する方が安全です。 

各行について、すべての文字を反復処理し、文字が母音であるたびにカウンターをインクリメントします。 

行の母音を数えた後、すぐに結果を必要な値と比較します。 カウントが異なる場合は、残りの行を確認し続ける必要はないので、次のように出力します。`NO`そして早期終了。 

3 行すべてが必要な数を満たしている場合、詩は俳句の構造と一致し、印刷されます。`YES`。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    vowels = set("aeiou")
    target = [5, 7, 5]

    lines = [input().rstrip('\n') for _ in range(3)]

    for i in range(3):
        count = 0

        for ch in lines[i]:
            if ch in vowels:
                count += 1

        if count != target[i]:
            print("NO")
            return

    print("YES")

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output

# provided sample
assert run(
    "on  codeforces  \n"
    "beta round is running\n"
    "   a rustling of keys\n"
) == "YES\n", "sample 1"

# minimum-size invalid case
assert run(
    "a\n"
    "a\n"
    "a\n"
) == "NO\n", "minimum-size case"

# exact 5-7-5 using repeated vowels
assert run(
    "aaaaa\n"
    "aeiouae\n"
    "eeeee\n"
) == "YES\n", "exact vowel counts"

# spaces everywhere
assert run(
    "   aeiou   \n"
    " aeiouae \n"
    "  eeeee\n"
) == "YES\n", "leading and trailing spaces"

# consonants only
assert run(
    "bcdfg\n"
    "hjklmnp\n"
    "qrst\n"
) == "NO\n", "zero vowels"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`a / a / a`|`NO`| 最小サイズの無効な入力 |
 | 正確な数で繰り返される母音 |`YES`| 総発生数が重要 |
 | 多くのスペースを含む入力 |`YES`| スペースは無視する必要があります |
 | 子音のみ |`NO`| ゼロ母音の処理 |

```アルゴリズムはすべての文字をスキャンします。 スペースは母音ではないため無視されます。 カウントは次のようになります`5`、`7`、 そして`5`したがって、出力は次のようになります。```
YES
```もう 1 つの特殊なケースは、母音がまったく含まれていない行です。 

入力：```

```微妙な間違いは、すべての母音を数えるのではなく、個別の母音を数えるということです。 

入力：```

```最初の行には、同じ母音のコピーが 5 つ含まれています。 アルゴリズムはすべての出現を個別に正確にカウントし、カウントを生成します。`5`、`7`、 そして`5`。 出力は次のとおりです。```
YES
```
