[CF 144E - コンテスト](https://codeforces.com/problemset/problem/144/E)

 **タグ:** データ構造、貪欲
 **解決時間:** 1 分 25 秒
 **確認済み:** はい

 ## 解決策
 ## 問題の理解

 _n_ 度の階段と呼ばれる正方行列の三角形領域が与えられます。 この階段では、右上から左下に伸びる二次対角線上の領域を除いて、各セルにアクセスできます。 この階段には、_m_ 人のスポーツマンが別々の位置に配置されています。 各スポーツマンは最短経路に沿って移動して二次対角線に到達しなければなりません。 それらは横に隣接するセルにのみ移動でき、対角線までの距離はそのような移動の最小数として測定されます。 

課題は、スポーツ選手の最大数を選択して、各選手が別のスポーツ選手と同時に同じセルを占有することなく、二次対角線への最短経路を選択できるようにすることです。 2 人のスポーツマンが同じセルを順番に移動することはできますが、2 人が同時にそのセルを占有することはできません。 

入力は、すべて有効な階段領域内にあるスポーツ選手の座標のリストです。 出力は、参加できるスポーツ選手の最大数と、それに対応する一連の指数です。 

制約により、_n_ と _m_ は最大 100,000 まで許可されます。これは、効率的なソリューションがほぼ線形またはほぼ線形の時間で実行される必要があることを意味します。 パスのすべての順列を試行する単純なアプローチは、_m_ で階乗的になるため、完全に実行不可能です。 エッジケースは、複数のスポーツ選手が第 2 対角線に対して等距離にいる場合、または第 2 対角線に対して同じ線上にある場合に発生します。これは、経路を慎重に選択しない限り、回避できない衝突につながる可能性があります。 たとえば、2 人のスポーツ選手が同じ列で異なる列からスタートした場合、彼らが目指す斜めのステップが一致する可能性があり、正しく順序付けされていないと衝突が発生します。 不用意にアプローチすると、これを見逃して、実行可能なセットを過剰にカウントしてしまう可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、すべての最短経路に沿って移動するスポーツ選手のあらゆる順列をシミュレートしようとします。 構成ごとに、2 つが同じ正方形を同時に占有しているかどうかがチェックされます。 原理的には正しいですが、このアプローチは完全に非現実的です。_m!_ 個の順列があり、各パスのシミュレーションに _O(n)_ 時間がかかる可能性があります。 _m_ が 100,000 までの場合、これは現実的ではありません。 

重要な洞察は、階段内の最短経路の構造を観察することで得られます。 位置 _(r, c)_ にいる各スポーツマンは、二次対角線までの最小距離が _(r + c - n - 1)_ で与えられます。 すべての最短パスは同じ長さを持ち、対角線のセルにはその列によってインデックスを付けることができます。 最短経路は事実上、対角線に向かって左下斜めに移動することを含み、スポーツマンは同じ対角線上で他のスポーツ選手を追い越すことはできません。 したがって、問題はスケジューリングの問題に帰着します。つまり、各スポーツマンに、衝突することなく目標の対角セルに到達するための「タイムスロット」を割り当てます。 これは貪欲に解決できます。 

スポーツ選手を対角線までの距離で分類し、優先キューまたはカウント戦略を使用して対角線のセルに割り当てることができます。 特定の対角セルについて、スポーツ選手は距離の短い順に割り当てられ、最も早く到着したスポーツ選手が最初にスロットを獲得し、衝突が回避されます。 各スポーツ選手を二次対角線上の潜在的なターゲットにマッピングし、最も早い到着をシミュレートすることで、衝突のない割り当てを保証します。 ソートが使用されている場合、この解決策は _O(m log m)_ 時間で機能しますが、これは指定された制約で許容可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(m! * n) | O(m * n) | 遅すぎる |
 | 距離による貪欲な割り当て | O(m log m) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 次の式を使用して、各スポーツ選手の二次対角線までの最短経路距離を計算します。`distance = r + c - n - 1`。 これにより、必要な最小限の移動数が得られます。 
2. スポーツ選手を、到達可能なターゲット対角セルごとにグループ化します。 位置にある各二次対角セル`(i, j)`は最大でも 1 人のスポーツマンを収容できるため、割り当てられるリソースは限られています。 
3. スポーツ選手を対角線までの距離で並べ替えます。 並べ替えにより、より近いスポーツ選手が最初に割り当てられるようになり、後から到着するスポーツ選手との衝突が防止されます。 
4. ソートされたスポーツマンを反復処理し、それぞれのスポーツ選手のパスに対応する利用可能な対角セルに貪欲に割り当てます。 占有された対角セルを追跡して、2 人のスポーツ選手に同じターゲットが割り当てられないようにします。 すでにセルが取られている場合は、とりあえずスポーツマンをスキップしてください。 
5. 割り当てられたすべてのスポーツ選手を収集し、その数と指数を出力します。 

機能する理由: 距離順に並べ替えると、2 人のスポーツ選手が進路上で衝突することがなくなります。 対角セルへの各割り当ては、可能な限り早く到着した順に行われ、スポーツマンが別のスポーツマンが同時に占有しているセルに移動することはありません。 この不変条件により、衝突しないスポーツ選手の最大数が選択されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
sportsmen = []

for i in range(m):
    r, c = map(int, input().split())
    # distance to secondary diagonal
    dist = r + c - n - 1
    sportsmen.append((dist, r, c, i + 1))  # store index 1-based

# sort by distance
sportsmen.sort()

occupied_diagonal = set()
selected = []

for dist, r, c, idx in sportsmen:
    target_diag = c  # each diagonal cell can be indexed by its column
    if target_diag not in occupied_diagonal:
        occupied_diagonal.add(target_diag)
        selected.append(idx)

print(len(selected))
print(" ".join(map(str, selected)))
```このソリューションでは、まず各スポーツ選手の距離を計算し、次にそれらを並べ替えて、最も早く到着できる選手が最初に考慮されるようにします。 それぞれの二次対角列は、2 人のスポーツ選手が同じセルをターゲットにしないようにするためのキーとして使用され、衝突を防ぎます。

 | 測定 | 複雑さ | 説明 |

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    sportsmen = []
    for i in range(m):
        r, c = map(int, input().split())
        dist = r + c - n - 1
        sportsmen.append((dist, r, c, i + 1))
    sportsmen.sort()
    occupied_diagonal = set()
    selected = []
    for dist, r, c, idx in sportsmen:
        target_diag = c
        if target_diag not in occupied_diagonal:
            occupied_diagonal.add(target_diag)
            selected.append(idx)
    return f"{len(selected)}\n{' '.join(map(str, selected))}"

# provided sample
assert run("3 3\n2 3\n3 2\n3 3\n") == "3\n1 2 3"

# custom cases
assert run("4 4\n2 3\n3 2\n4 1\n1 4\n") == "4\n3 1 2 4"
assert run("1 1\n1 1\n") == "1\n1"
assert run("5 5\n5 1\n4 2\n3 3\n2 4\n1 5\n") == "5\n1 2 3 4 5"
assert run("3 2\n2 3\n3 3\n") == "2\n1 2"

 | 1 1 / 1 1 | 1 / 1 | 最小入力サイズ |
