 ## 解決策
 ## 問題の理解

 2 つの括弧のシーケンスが与えられています。`s`そして`t`、これは個別に括弧シーケンスとして無効になる可能性があります。 タスクは、有効で (バランスが取れており、適切にネストされている)、両方の括弧を含む最も短い括弧の文字列を生成することです。`s`そして`t`サブシーケンスとして。 サブシーケンスでは文字をスキップできるため、`s`そして`t`順番に現れる必要がありますが、必ずしも連続している必要はありません。 

入力サイズは小さく、各文字列は最大 200 文字です。 これは、3 次または 2 次の時間計算量を持つアルゴリズムは許容できるが、それより大幅に劣るアルゴリズムを使用できることを意味します。$O(n^3)$遅すぎるでしょう。 シーケンスの可能なすべての挿入またはすべてのインターリーブを列挙するような解決策を避けるように注意する必要があります。 

エッジ ケースは、一方または両方のシーケンスがすでに単独で有効である場合、一方のシーケンスが他方のシーケンス内に完全にネストされている場合、またはシーケンスのプレフィックスが非常にアンバランスである場合に発生します。 たとえば、次の場合`s = "((("`そして`t = ")))"`、出力は次のようにする必要があります`"((()))"`; 単純に文字列を連結する単純なアプローチでは、次のようになります。`"((()))))"`それは無効です。 同様に、`s`または`t`が空の場合、出力は空ではない文字列の通常のブラケット補完である必要があります。 

## アプローチ

 ブルートフォースアプローチでは、あらゆる可能なインターリーブ方法が試行されます。`s`そして`t`追加のブラケットを挿入してバランスをとります。 概念的には、マージされたシーケンスを有効にするために、すべての位置に開き括弧と閉じ括弧を挿入してみることができます。 これは原理的には正しいですが、可能性の数は長さが増すにつれて指数関数的に増加します。`s`そして`t`-実現可能な計算をはるかに超えています$n = 200$。 

より高速な解決策の重要な観察は、この問題を最短の共通スーパーシーケンス問題としてモデル化できることですが、追加の制約があります。シーケンスは括弧シーケンスとして有効なままでなければなりません。 括弧シーケンスの状態は、閉じられていない括弧 '(' の現在の数によって取得できます。これにより、各プレフィックスの有効なスーパーシーケンスの最小長を追跡する動的プログラミング アプローチが動機付けられます。`s`そして`t`および開き括弧のそれぞれの可能な現在のバランス。 

正式に定義すると、`dp[i][j][b]`を含む最短のシーケンスとして`s[:i]`そして`t[:j]`現在の残高を持つサブシーケンスとして`b`開き括弧。 を行わない限り、「(」または「)」を段階的に追加できます。`b`負の場合は、シーケンスが有効なままであることが保証されます。 これにより、問題は指数関数的な時間から三次時間に軽減されます。これは、状態の数が最大でも 200×200×200 = 8,000,000 であり、2 秒の制限に十分収まるためです。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(n+m)) | O(2^(n+m)) | 遅すぎる |
 | 最適 (プレフィックスの DP + バランス) | O(n * m * (n+m)) | O(n * m * (n+m)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. DP テーブルの初期化`dp[i][j][b]`最初の最短の文字列を格納します`i`の登場人物`s`そして最初の`j`の登場人物`t`バランスをとって`b`。 から始める`dp[0][0][0]`空の文字列として。 
2. 州ごとに`(i, j, b)`表で、次の 2 つの可能なステップを検討してください。`'('`または追加します`')'`。 追加`'('`残高を 1 つ増やしながら追加します`')'`1つ減ります。 追加のみ`')'`もし`b > 0`有効な順序を維持するため。 
3. 括弧を追加するときは、括弧内の次の文字と一致するかどうかを確認します。`s`および/または`t`。 一致する場合`s[i]`、増分`i`新しい状態で。 同様に、一致する場合は、`t[j]`、増分`j`。 これにより、現在の文字がスーパーシーケンス内で消費された場合にのみ文字列内を進むことが保証されます。 
4. その州に対して以前に記録された文字列よりも短い場合は、新しい文字列で DP テーブルを更新します。 これにより、常に可能な限り最短のシーケンスを構築することが保証されます。 
5. DP テーブルに入力した後の答えは、`dp[len(s)][len(t)][0]`、両方のシーケンスが完全に含まれており、残高がゼロであるため、有効な括弧シーケンスが保証されます。 

機能する理由: 各ステップで、DP はこれまでの決定から生じる可能性のあるすべてのシーケンスをキャプチャし、現在の文字列が有効であり、消費されたすべての文字が含まれているという不変条件を維持します。 状態には残高が明示的に含まれるため、無効なシーケンスを構築することはできません。 複数のパスが同じ状態に至る場合は、常に短い文字列を選択することで、結果のシーケンスが最小限になるようにします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

s = input().strip()
t = input().strip()

n, m = len(s), len(t)

# BFS with states (i, j, balance)
queue = deque()
queue.append((0, 0, 0))
visited = {}
visited[(0, 0, 0)] = ""

while queue:
    i, j, b = queue.popleft()
    cur = visited[(i, j, b)]
    
    if i == n and j == m and b == 0:
        print(cur)
        break

    for c in "()", :
        nb = b + 1 if c == '(' else b - 1
        if nb < 0:
            continue
        ni = i + (i < n and s[i] == c)
        nj = j + (j < m and t[j] == c)
        key = (ni, nj, nb)
        new_str = cur + c
        if key not in visited or len(new_str) < len(visited[key]):
            visited[key] = new_str
            queue.append(key)
```BFS により、常に最短のシーケンスが最初に探索されるようになります。 バランス`b`開き括弧の数を追跡します。 私たちが許可するのは`b >= 0`有効性を維持するために、シーケンス ポインタをインクリメントします。`s`そして`t`現在の括弧が一致する場合のみ。 これにより、出力に両方が含まれることが保証されます。`s`そして`t`サブシーケンスとして最小限に抑えられます。
