 ## 解決策
 ## 問題の理解

 1 つの大きなテキスト文字列が与えられます`s`、これは入力全体に対して固定されます。 次に、多くのクエリ文字列を受け取ります`x`。 

お問い合わせの場合`x`、私たちはそれだけに興味があるのではありません`x`自体。 任意の循環回転`x`is considered equivalent. たとえば、`x = "abcd"`、文字列`"abcd"`、`"bcda"`、`"cdab"`、 そして`"dabc"`すべてが同じ周期クラスに属します。 

クエリごとに、次の部分文字列の数を数えなければなりません。`s`の任意の回転に等しい`x`。 

長さ`s`到達できる`10^6`、すべてのクエリの合計の長さも最大です。`10^6`。 クエリごとにテキスト全体を個別にスキャンするソリューションは、直ちに不可能です。 たとえ`O(|s|)`クエリごとの手順は約`10^12`最悪の場合の運用。 

この制約は、大規模な前処理ステップが必要であることを強く示唆しています。`s`、その後、クエリ全体の長さでほぼ直線的な処理が続きます。 

単純なソリューションでは誤って処理される可能性がある微妙な状況がいくつかあります。 

考慮する：```
s = "aaaaa"
x = "aa"
```の回転`"aa"`まだです`"aa"`。 すべてのローテーションを生成し、その出現数を合計すると、同じ文字列が 2 回カウントされることになります。 正しい答えは、`4`、 ない`8`。 

別の例:```
s = "ababab"
x = "abab"
```回転は次のとおりです。```
abab
baba
abab
baba
```異なる文字列は 2 つだけ存在します。 4 つの回転をすべて個別にカウントすると、重複が生成されます。 

回転が発生しない場合は、別の落とし穴が発生します。`s`全然。 例えば：```
s = "abc"
x = "de"
```すべての回転はゼロに寄与する必要があり、アルゴリズムはテキスト全体を検索せずにこれを効率的に検出する必要があります。 

主な困難は、すべての発生を同時に処理することです。`s`、クエリのすべての循環ローテーション、および重複したローテーション。 

## アプローチ

 強引なアイデアは単純明快です。 

長さのクエリの場合`m`、すべてを生成します`m`回転。 ローテーションごとに、それが何回出現するかを数えます。`s`。 接尾辞配列、接尾辞オートマトン、またはハッシュ構造は、1 つの出現クエリにすぐに答えることができます。 

問題は、長さのクエリであることです。`m`もっている`m`回転。 クエリの合計長は長さに達する可能性があるため、`10^6`、生成される回転の総数はおよそに達する可能性があります`10^12`。 たとえ各回転が一定時間で処理されたとしても、これは限界をはるかに超えています。 

重要な観察は、文字列のすべての回転が長さとして現れることです。`m`内部の部分文字列`x + x`。 

例えば：```
x      = abcd
x + x  = abcdabcd
```回転は正確に、開始位置が前半にある長さ 4 の部分文字列です。 

これにより、問題は次のように変換されます。 

> すべての異なる長さの中で-`m`の部分文字列`x + x`回転に対応し、内部での出現数を合計します。`s`。 

これで、接尾辞オートマトンが非常に自然になりました。 

サフィックスオートマトンを構築した後`s`、すべての状態は終了位置の同値クラスを表します。 サフィックス リンクを介して出現数を伝播すると、各状態には、その状態によって表されるすべての文字列の出現数が格納されます。 

スキャン中`x + x`、オートマトン内で現在一致している最長のサフィックスを維持できます。 一致する長さが少なくとも`m`、長さの回転がわかっています。`m`ここで終わります。 

残りの課題は、その正確な長さに対応する状態を特定することです。`m`弦。 

接尾辞オートマトンでは、状態`v`は区間内のすべての長さを表します。```
(len(link(v)) + 1) ... len(v)
```したがって、正確な長さの文字列の場合`m`、親の長さが次の値よりも小さくなるまで、サフィックス リンクを登っていきます。`m`。 結果として得られる状態は、その長さを一意に表します。`m`部分文字列。 

スキャン中に同じ回転の異なる発生が何度も表示される場合があります`x + x`。 個別のローテーションはそれぞれ 1 回だけ必要なので、状態にタイムスタンプを付け、各状態をクエリごとに最大 1 回カウントします。 

これにより、クエリの合計長において線形な解が得られます。

 ## アルゴリズムのチュートリアル

 1. テキスト文字列の接尾辞オートマトンを構築する`s`。 
2. 新しく作成されたすべての非クローン状態について、その出現回数を次のように初期化します。`1`。 
3. 状態を長さによって並べ替え、カウントを長い状態からそのサフィックス リンクの親に伝播します。 このステップの後、すべての状態は、その表現された部分文字列の出現回数を内部に保存します。`s`。 
4. お問い合わせの場合`x`長さの`m`、構築する`t = x + x`。 
5. 最初の部分のみをスキャンします`2m - 1`の登場人物`t`。 これらの位置は正確に`m`周期的な回転。 
6. 以下を維持します。 

-`p`、現在のオートマトンの状態。 
-`cur_len`、一致する最長のサフィックスの長さ。 
7. 文字ごとに、標準の接尾辞オートマトンの一致遷移を実行します。 トランジションが存在しない場合は、トランジションが存在するまでサフィックス リンクをたどるか、ルートに戻ります。 
8.いつでも`cur_len >= m`、サフィックスリンクを登りながら`len(link(p)) >= m`。 

この調整後の状態は、`p`間隔に長さが含まれる一意の状態です`m`。 その状態は現在の回転を表します。 
9. 現在のクエリ中にこの状態がカウントされていない場合は、その出現回数を回答に追加し、現在のクエリのタイムスタンプでマークします。 
10. 蓄積された回答を出力します。 

### なぜ効果があるのか

 すべての周期回転`x`長さとして 1 回だけ表示されます -`m`最初の内部のある位置で終わる部分文字列`2m - 1`の登場人物`x + x`。 

スキャン中、サフィックス オートマトンは、処理されたプレフィックスの中で発生する最長のサフィックスを維持します。`s`。 一致したサフィックスが少なくとも長さがある場合`m`、長さ-`m`現在の位置で終わるサフィックスは、`x`。 

接尾辞オートマトンの状態は、連続した区間内のすべての部分文字列の長さを表します。 親の長さが以下になるまでサフィックス リンクを登ります。`m`間隔に長さが含まれる一意の状態を選択します`m`。 その状態は現在の回転に正確に対応します。 

その状態に保存される出現回数は、表現された文字列が出現する回数と等しくなります。`s`。 重複したローテーションは同じ状態にマップされ、タイムスタンプによって重複したローテーションが複数回カウントされるのを防ぎます。 したがって、すべての個別の回転は 1 回だけ寄与し、答えは正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s = input().strip()

max_states = 2 * len(s) + 5

link = [-1] * max_states
length = [0] * max_states
occ = [0] * max_states
nxt = [[0] * 26 for _ in range(max_states)]

size = 1
last = 0
link[0] = -1

for ch in s:
    c = ord(ch) - 97

    cur = size
    size += 1

    length[cur] = length[last] + 1
    occ[cur] = 1

    p = last
    while p != -1 and nxt[p][c] == 0:
        nxt[p][c] = cur
        p = link[p]

    if p == -1:
        link[cur] = 0
    else:
        q = nxt[p][c]
        if length[p] + 1 == length[q]:
            link[cur] = q
        else:
            clone = size
            size += 1

            length[clone] = length[p] + 1
            link[clone] = link[q]
            nxt[clone] = nxt[q][:]

            while p != -1 and nxt[p][c] == q:
                nxt[p][c] = clone
                p = link[p]

            link[q] = clone
            link[cur] = clone

    last = cur

max_len = len(s)

cnt = [0] * (max_len + 1)
for v in range(size):
    cnt[length[v]] += 1

for i in range(1, max_len + 1):
    cnt[i] += cnt[i - 1]

order = [0] * size
for v in range(size - 1, -1, -1):
    cnt[length[v]] -= 1
    order[cnt[length[v]]] = v

for i in range(size - 1, 0, -1):
    v = order[i]
    parent = link[v]
    if parent >= 0:
        occ[parent] += occ[v]

vis = [0] * size
timer = 0

q = int(input())

out = []

for _ in range(q):
    x = input().strip()
    m = len(x)

    t = x + x

    timer += 1
    ans = 0

    p = 0
    cur_len = 0

    for i in range(2 * m - 1):
        c = ord(t[i]) - 97

        while p != -1 and nxt[p][c] == 0:
            p = link[p]

        if p == -1:
            p = 0
            cur_len = 0
            continue

        cur_len = min(cur_len, length[p]) + 1
        p = nxt[p][c]

        while link[p] != -1 and length[link[p]] >= m:
            p = link[p]

        if cur_len >= m and vis[p] != timer:
            vis[p] = timer
            ans += occ[p]

    out.append(str(ans))

sys.stdout.write("\n".join(out))
```最初のセクションでは、テキスト文字列のサフィックス オートマトンを構築します。 すべての非クローン状態は発生回数から始まります`1`、1 つのサフィックス終了位置に対応します。 

カウンティング ソート パスでは、長さを増やすことによって状態を並べ替えます。 この順序を逆方向に処理すると、サフィックス リンクを通じて出現数が伝播され、標準の SAM 出現統計が生成されます。 

クエリごとにスキャンします。`x + x`オートマトンに現在表示されている最長のサフィックスを維持しながら。 アップデート```
cur_len = min(cur_len, length[p]) + 1
```は標準の SAM マッチング式です。 サフィックスリンクジャンプ後に、現在一致している長さを正しく調整します。 

ループ```
while link[p] != -1 and length[link[p]] >= m:
    p = link[p]
```重要なステップです。 終わったら状態を言う`p`表現された間隔に長さが含まれる一意の状態です`m`。 

タイムスタンプ配列により、クエリごとに最大 200 万のサイズのブール配列がクリアされることがなくなります。 各クエリは一意の識別子を受け取り、状態はその識別子に対して 1 回だけカウントされます。
