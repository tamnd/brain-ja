 ## 解決策
 ## 問題の理解

 私たちは 2 種類の生き物が住む世界を与えられています。 最初のタイプの各クリーチャーには正確に 1 つの頭と 19 本の脚がありますが、2 番目のタイプの各クリーチャーには正確に 7 つの頭と 4 つの脚があります。 私たちは、この世界で観察された頭の総数と足の総数を知らされます。 タスクは、頭の数と足の数の両方が正確に一致するように、各タイプの生き物が何匹存在できるかを決定することです。 有効な分解が複数存在する場合は、そのうちのいずれか 1 つを使用できます。 分解が不可能な場合は、不可能であることを報告する必要があります。 

入力は 2 つの整数で構成されます。 1 つ目は頭の総数で、2 つのクリーチャー タイプの線形結合を制限します。 2 番目は脚の総数で、2 番目の線形制約を提供します。 出力は、各タイプのクリーチャーが何匹存在したかを示す非負の整数のペア、または解が存在しない場合は -1 です。 

境界では最大 10^8 の値が許容されますが、構造は本質的に組み合わせ的ではありません。 2 つの変数で 2 つの線形方程式からなる系を解いていますが、非負の制約と解が整数であるという要件があります。 これにより、問題は検索ではなく定数時間の代数解法に即座に配置されます。 

単純なアプローチでは、1 つのクリーチャーの可能な数をすべて試し、頭の方程式からもう一方のクリーチャーを推定し、脚の方程式が一致するかどうかを確認しようとします。 これは機能しますが、不要であり、最悪の場合、概念的には最大 10^8 の反復がループする可能性があり、これでは遅すぎます。 

エッジケースは、可分性の制約と、頭と脚の間のパリティのような構造の不一致から発生します。 一般的な失敗モードは、ヘッド方程式がレッグの一貫性を検証せずに常にカウントを一意に決定すると仮定することです。 もう1つは、一方の種が他方の種と比べて脚よりも頭の方が不均衡に多く寄与しており、表面的には解決可能に見えるシステムを実行不可能なものにしてしまうということを見落としている。 

たとえば、頭が 2 つで脚が 19 本ある場合、単頭の生き物が 2 つ存在すると誤って仮定する可能性がありますが、脚の数はすぐに矛盾します。 矛盾は、両方の方程式が同時に適用される場合にのみ現れます。 

## アプローチ

 問題は、連立一次方程式を解くことに帰着します。 1頭19本足の生き物の数をx、7頭4本足の生き物の数をyとします。 次に:

 x + 7y = A

 19x + 4y = B

 ブルートフォース手法では、0 から A // 7 までの y のすべての可能な値を反復処理します。各 y について、x = A - 7y を計算し、それが負でなく、レッグ方程式を満たすかどうかを確認します。 これは正しいです。すべての有効な解決策は両方の制約を同時に満たさなければならないからです。 ただし、最悪の場合、A は 10^8 になり、最大約 1.4 × 10^7 の反復が行われる可能性があります。これは境界線であり、単一テストの問題には不要です。 

重要な観察は、これが存在する場合には一意の代数解をもつ 2×2 線形システムであるということです。 変数を直接削除できます。 x = A - 7y から、2 番目の方程式に代入します。 

19(A - 7y) + 4y = B

 19A - 133y + 4y = B

 19A - 129y = B

 129y = 19A - B

 したがって、y は右辺によって一意に決定されます。 y が分かると、x が直接続きます。 残っている唯一のタスクは、y が整数であり、x と y の両方が負ではないことを検証することです。 

これにより、問題は少数のチェックによる定数時間の演算に変わります。

 ## アルゴリズムのチュートリアル

 消去法を用いて系を解き、実現可能性を検証します。

1. 頭の制約を使用して、1 頭の生き物の数 x を y で表します: x = A - 7y。 これにより、システムの変数が 2 つから 1 つに減ります。 
2. この式をレッグ方程式に代入します: 19(A - 7y) + 4y = B。このステップにより、両方の制約が独立してではなく同時に適用されます。 
3. y を分離する方程式を単純化します。19A - 129y = B となり、y = (19A - B) / 129 が得られます。これは、両方の方程式を満たすことができる y の唯一の値です。 
4. (19A - B) が 129 で割り切れるかどうかを確認します。割り切れない場合は、整数解が存在しないため、-1 を出力します。 これにより、クリーチャーの数は整数でなければならないため、整数性が強制されます。 
5. y を計算してから、x = A - 7y を計算します。 これにより、y が検証されると完全な解が再構築されます。 
6. x と y が両方とも負でないことを確認します。 どちらかが負の場合、その解はクリーチャーを数えるという物理的な意味で無効であるため、-1 を出力します。 

### なぜ効果があるのか

 このシステムは、整数に対する 2 つの独立した線形制約で構成されます。 有効な解は両方を同時に満たす必要があり、消去法により、y は A と B の 1 つの線形式によって一意に決定されることがわかります。変換では等価性が維持されるため、派生方程式の整数解は元のシステムの有効なペア (x, y) に正確に対応します。 したがって、可除性と非負性をチェックするだけで存在を判断し、解を求めることができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    A, B = map(int, input().split())

    numerator = 19 * A - B
    denom = 129

    if numerator % denom != 0:
        print(-1)
        return

    y = numerator // denom
    x = A - 7 * y

    if x < 0 or y < 0:
        print(-1)
        return

    print(x, y)

if __name__ == "__main__":
    solve()
```この解決策は、まず、代数的消去ステップを y の単一の式に直接エンコードします。 除算チェックにより、クリーチャーの数が端数であると想定されることがなくなります。 y を計算した後、x はレッグから再計算するのではなくヘッド制約から導出されます。これにより、冗長な演算が回避され、整数にとどまることで浮動小数点のリスクが完全に軽減されます。 

代数操作だけでは非負性が強制されないため、最後の検証ステップが必要です。 方程式の一貫性を保証するだけです。

 ## 特殊なケース

 A と B が両方とも有効な整数であるにもかかわらず、システムが y に対して小数値を生成する場合、微妙なエッジ ケースが発生します。 たとえば、A = 2、B = 19 の場合、分子 19・2 - 19 = 19 が生成されますが、これは 129 では割り切れません。アルゴリズムは、割り算チェックを通じてこれを即座に検出し、小数のクリーチャー数を解釈しようとする試みを防ぎます。 

もう 1 つの特殊なケースは、代数が負の y を生成する場合です。 これは、有効な混合物のヘッドに比べてレッグ数が大きすぎる状況に対応します。 このような場合、計算された y は非負性制約に違反し、明示的に拒否されるため、線形システムの数学的解が実行可能領域外にある場合でも正確さが保証されます。
