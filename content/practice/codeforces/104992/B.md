 ## 解決策
 ## 問題の理解

 私たちは、各動物が食事ごとに一定の整数のニンジンを消費する、同一の動物のシステムに注目しています。 その食事当たりの量は、特定の動物のすべての食事で同じであり、またすべての動物で同じです。 唯一のばらつきは、動物ごとに異なる整数が選択される可能性があることですが、そのような各整数は一定の範囲内になければなりません$[a, b]$。 

すべての動物が合わせて、正確に 2 回の食事で摂取したニンジンの総数は次のようになります。$n$。 各動物は両方の食事で同じ量を食べるので、食べる動物は$x$1食あたりのニンジンの摂取量が正確に貢献します$2x$合計にニンジン。 あれば$k$動物の食事ごとの消費量の値$x_1, x_2, \dots, x_k$、合計は$$2(x_1 + x_2 + \dots + x_k) = n.$$したがって、問題は、私たちが表現できるかどうかを尋ねることになります。$n/2$合計として$k$それぞれの範囲内の整数$[a, b]$を最大化したいと考えています$k$。 

制約は次のとおりです$10^{15}$したがって、候補を列挙したりパーティションをシミュレートしようとするソリューションは直ちに実行不可能になります。 すべての可能な値を反復しても、$k$そうしないと、考えられるすべての構成が遅すぎることになります。$k$それ自体は次のように大きくなる可能性があります$10^{15}$。 

最初の重要な観察は、次のような場合です。$n$おかしい、すぐには無理な状況。 それぞれの貢献度は$2x$、合計は偶数でなければなりません。 

別の微妙な失敗例が発生するのは、$n/2$値の合計として表現するには小さすぎるか大きすぎます。$[a, b]$。 たとえば、次の場合$n = 10$、$a = 6$、$b = 7$、その後、各動物は 2 回の食事で合計 12 ～ 14 個のニンジンを提供します。 1匹でもすでに10匹を超えているので正解は$-1$。 2 で割り切れるかどうかだけをチェックする単純なアプローチでは、誤って 1 以上が出力されてしまいます。 

同様に、$n/2$サイズは大きいですが、拘束が厳しすぎるため、次のようになります。$n = 9$、$a = 2$、$b = 5$、 それから$n/2 = 4.5$は整数ではないため、たとえローカル境界に互換性があるように見えても、答えは直ちに無効になります。 

主な困難は、値を各食事に個別に割り当てているのではなく、全体的な実現可能性によって制約された動物ごとの固定整数に割り当てていることです。 

## アプローチ

 総当たり的な観点からは、動物の数を決定しようとします。$k$かどうかをテストすることで得られます$n/2$に分解できます$k$間の整数$a$そして$b$。 固定の場合$k$の合計かどうかを確認する必要があります。$k$の値$[a, b]$等しいことができます$S = n/2$。 これは、$$k \cdot a \le S \le k \cdot b.$$これが当てはまる場合、そのような分解は、からの剰余を分配することによって存在します。$a$いくつかの要素にわたって均等に、境界内で調整します。 

したがって、それぞれについて$k$、実現可能性のチェックは一定時間です。 ブルートフォースアプローチでは、すべてが試行されます$k$から$1$に$S/a$。 最悪の場合、そのときは、$a = 1$、これは最大まで繰り返すことを意味します$10^{15}$という価値観はまったく実現不可能です。 

重要な観察は、実現可能性は次のような不平等にのみ依存するということです。$k$パーティションの内部構造ではありません。 条件を書き換えると$$k \cdot a \le S \le k \cdot b,$$私たちは隔離できる$k$:$$\frac{S}{b} \le k \le \frac{S}{a}.$$したがって、問題は最大の整数を見つけることになります。$k$これらの境界を満たす、つまり:$$k_{\max} = \left\lfloor \frac{S}{a} \right\rfloor,$$これを条件として$k$も満たす$k \cdot b \ge S$。 そうでない場合は無効です$k$存在します。 

これにより、組み合わせ構造全体が単一の間隔チェックに折りたたまれます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースオーバー$k$|$O(S/a)$|$O(1)$| 遅すぎる |
 | 不平等の削減 |$O(1)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. コンピューティング$S = n / 2$。 もし$n$おかしい、すぐに返す$-1$。 すべての貢献は建設によって 2 倍になるため、これが必要です。 
2. 動物の最大可能数を次のように計算します。$k = \left\lfloor S / a \right\rfloor$。 これは、動物あたりの最小許容消費量を使用してカウントを最大化することに対応します。 
3. この候補があるかどうかを確認します$k$可能な最大の合計を検証することで有効です。$k$動物、つまり$k \cdot b$、少なくとも$S$。 そうしないと、どんなに寛大な割り当てであっても、必要な合計に達することはできません。 
4. チェックに合格した場合は、出力します。$k$。 それ以外の場合は出力$-1$。 

### なぜ効果があるのか

 各動物は独立した整数を与えます。$[a, b]$、つまり、達成可能な合計のセットは、$k$動物はまさに間隔です$[k a, k b]$。 範囲内に留まりながら 1 匹の動物の値を 1 ずつ増やすことができるため、ギャップはありません。 したがって、実現可能性は、次のことを確認することに帰着します。$S$一部の人にとってはこの間隔内にあります$k$。 実現可能な最大のものを選択する$k$押すのと同じです$k$下限制約まで$k a \le S$上限がまだカバーされていることを確認しながら、タイトです$S$。 これにより、正確性と最大性の両方が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input().strip())
a = int(input().strip())
b = int(input().strip())

if n % 2 == 1:
    print(-1)
    sys.exit()

S = n // 2

k = S // a

if k == 0:
    print(-1)
    sys.exit()

if k * b < S:
    print(-1)
else:
    print(k)
```有効な合計はすべて偶数であるため、コードは最初にパリティ制約を適用します。 次に、問題を作業に落とし込みます。$S = n/2$、1食あたりの消費量の合計。 

表現`S // a`動物あたりの許容最小摂取量の下で、可能な限り最大の動物数を選択します。 その後の条件`k * b < S`各動物の消費量を最大化しても必要な合計に到達できないかどうかを検証します。これは、有効な構成が存在しないことを意味します。 

明示的な`k == 0`check は次のようなケースを処理します。$S < a$つまり、1 匹の動物にも有効な値を割り当てることができません。

 ## 特殊なケース

 いつ$n$奇数です、例えば$n = 1$、アルゴリズムはそれを即座に拒否します。$S = n/2$は整数ではないため、動物ごとに整数を割り当てても有効な合計を算出できません。 

いつ$S < a$、 例えば$n = 5$、$a = 3$、$b = 10$、私たちは得ます$S = 2$。 計算により得られるのは、$k = 0$、アルゴリズムは戻ります$-1$これは、たとえ 1 匹の動物であっても有効な摂取量を割り当てることができないことを正しく反映しています。 

1頭あたりの最小摂取量が多い場合など$n = 100$、$a = 60$、$b = 70$、私たちは得ます$S = 50$、1匹でもすでに合計を超えています。 条件$k = S // a = 0$拒否をトリガーし、この境界を正しく処理します。 

いつ$a = b$、 のような$a = b = 5$、唯一可能な合計構造は剛体です。 アルゴリズムは、次のことをチェックすることに要約されます。$S$で割り切れます$5$、そして戻ります$k = S/5$有効な場合、そうでない場合$-1$。
