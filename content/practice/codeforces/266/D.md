 ## 解決策
 ## 問題の理解

 バータウンの道路を表す接続された無向グラフが与えられます。 ジャンクションはノードであり、道路は正の長さの重み付けされたエッジです。 タスクは、新しい BerDonalds レストランの場所を選択して、そこからジャンクションまでの最大距離が最小限になるようにすることです。 重要なのは、レストランは交差点だけでなく、道路沿いのどこにでも設置できることです。 出力は、可能な限り最短の「最も遠いジャンクションまでの最大距離」です。 

入力の場合、最初の行は次のようになります。`n`そして`m`、ジャンクションと道路の数。 次は`m`線は道路を表し、それぞれに 2 つのジャンクションと長さが含まれます。 出力は、交差点や道路沿いのどこかで発生する可能性のある最小の「最遠距離」を表す実数です。 

制約により許可される`n`そして`m`それぞれ最大数千、エッジの重みは最大 10^5 です。 制限時間は5秒なので複雑なアルゴリズム`O(n^3)`最悪の場合は遅すぎるかもしれませんが、`O(n^2 log n)`実現可能です。 グラフは接続されているため、切断されたコンポーネントを処理する必要はありません。 

明らかではないエッジ ケースには、最適な点が 1 本の道路の中点にある、ノードが 2 つだけあるグラフが含まれます。 もう 1 つの微妙なケースは、複数の最長最短パスが道路と交差する場合に発生します。 最適なレストランは、ノードではなく道路自体にある可能性があります。 

たとえば、長さ 1 の 1 本の道路で接続された 2 つのノードのグラフの最適距離は 0.5 です。 ノードのみを考慮する単純なアプローチでは、誤って 1 が返されます。 

## アプローチ

 強引なアプローチでは、すべての道路に沿ったすべての可能な点を考慮し、その点からすべてのノードまでの最短距離を計算し、最大値を取得します。 これは、考えられるすべての配置をテストするため機能しますが、実行不可能です。各道路は多数の候補点に分割される可能性があり、それぞれの距離の計算は次のとおりです。`O(n + m)`ダイクストラを使用すると、`O(m * (w_max) * (n + m))`動作が遅すぎます。 

重要な洞察は、道路上の最適な位置は、グラフ内の「最も遠いノード」までの距離のバランスが取れている点にあるということです。 具体的には、ダイクストラのアルゴリズムを使用してすべての交差点からの最短距離を計算すると、各道路について次のことを考慮できます。`u - v`長さの`w`。 させて`d[u][x]`そして`d[v][x]`他のすべてのノードまでの距離になります。 道路上で最大値を最小化する点を見つけるだけで済みます。`d[u][i] + t`そして`d[v][i] + (w - t)`、 どこ`t`からの距離です`u`道路沿いにあります。 この最大値は区分的に線形です`t`, したがって、最小値は 2 つの距離が交差する点で発生します。 したがって、エッジに沿った最小最大距離を見つけるには、エッジごとに 1 回の計算だけが必要です。 

「道路に沿った最遠距離関数は区分的に線形である」という観察により、すべてのペアの最短パスまたは各ノードからの単一ソース距離を計算した後、潜在的に連続的な検索をエッジごとの単一の評価に減らすことができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(m * w_max * (n + m)) | O(n + m) | 遅すぎる |
 | 最適 | O(n * (n log n + m)) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ダイクストラのアルゴリズムを使用して、すべてのジャンクションから他のすべてのジャンクションまでの最短距離を計算します。 これを次のように保存します`dist[i][j]`みんなのために`i, j`。 これにより、任意の点からの最大距離を評価するために必要な基本距離が得られます。 
2. 変数を初期化する`best`無限大で。 これにより、これまでに見つかった最小最大距離が保存されます。 
3. 各道路を反復処理します。`(u, v, w)`。 他のすべてのノードについて`i`、計算する`d_u = dist[u][i]`そして`d_v = dist[v][i]`。 点からの距離`t`ノードへの道沿い`i`は`min(d_u + t, d_v + (w - t))`。 
4. 現在の道路の点を見つけます`t`これにより、すべてのノードまでの最大距離が最小化されます。 機能以来`max(min(d_u + t, d_v + (w - t)))`が区分的に線形で凸である場合、最適値は 2 つの線形関数が交差する場所で発生します。 計算する`t = (d_v - d_u + w) / 2`そしてそれをクランプします`[0, w]`。 
5. エッジに沿ったこの最適な点からすべてのノードまでの最大距離を計算します。 アップデート`best`この最大値が小さい場合。 
6. すべてのエッジに対して繰り返して戻ります`best`最小最大距離として。 

機能する理由: 道路上の任意の点から最も遠いノードまでの距離は、常に、ノードごとに 1 つずつ、複数の線形関数の最大値になります。 線形最大値は 2 つの線が交差する場所で最小化されるため、エッジごとの交差を評価することで最適な点が見つかることが保証されます。 あらゆるエッジを考慮することで、ノード間で発生する解決策を見逃すことがなくなります。 

## Python ソリューション```python
import sys
import heapq
input = sys.stdin.readline

def dijkstra(n, adj, start):
    dist = [float('inf')] * n
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in adj[u]:
            if dist[v] > d + w:
                dist[v] = d + w
                heapq.heappush(pq, (dist[v], v))
    return dist

def main():
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1; v -= 1
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    dist = [dijkstra(n, adj, i) for i in range(n)]
    
    best = float('inf')
    for u, v, w in edges:
        t_values = []
        for i in range(n):
            t_i = (dist[v][i] - dist[u][i] + w) / 2
            t_i = max(0, min(w, t_i))
            t_values.append(max(dist[u][i] + t_i, dist[v][i] + w - t_i))
        best = min(best, max(t_values))
    
    print(f"{best:.10f}")

if __name__ == "__main__":
    main()
```このソリューションでは、まず隣接リストを構築し、次にすべてのノードからダイクストラを実行します。 重要なステップは、直線距離関数の交差を使用して各エッジに沿った最適な点を評価することです。 クランピング`t`レストランが道路上にあることを確認します。 最終結果は高精度に印刷されます。
