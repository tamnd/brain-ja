 ## 解決策
 ## 問題の理解

 n 行 m 列の長方形グリッドと、それぞれに固定価格が設定された k 個のアイスティーのコレクションが与えられました。 タスクは、これらのボトルの一部またはすべてを個別のグリッド セルに配置することです (セルあたり最大 1 つのボトル)。 

配置後、プロセスが発生します。行ごとに独立して、その行に少なくとも 1 つのボトルが含まれている場合、その行から 1 つのボトルが均一にランダムに選択され、その価格が支払われます。 行にボトルが含まれていない場合、その行は何も寄与しません。 

目的は、このプロセスをシミュレートすることではなく、すべての列から収集される予想される支払総額を最大化するボトルの配置を選択することです。 出力は割り当てのグリッドであり、ゼロ以外の各セルには、そこに配置されたボトルのインデックスが格納されます。 

この制約により、n と m は最大 1000 まで許可されるため、グリッドには最大 100 万個のセルを含めることができます。 ボトルの数 k は最大でも n × m です。 すべての配置を明示的に評価したり、構成に対する期待値を計算しようとするソリューションは、配置の数が k とグリッド サイズの組み合わせで増加するため、直ちに実行不可能になります。 

この問題の微妙な点は、各行内の相対的な構造だけが期待に影響するということです。 ランダム性は行ローカルであるため、行は確率空間内で相互作用せず、ボトルがグローバルに異なるという制約内でのみ相互作用します。 

素朴な間違いは、より高価なボトルを任意の場所に配置することが最適であると考えることです。 たとえば、すべての大きな値を同じ行に配置するのは良いように思えるかもしれませんが、各行からは 1 つのサンプルしか得られないため、選択確率が低下します。 もう 1 つの失敗モードは、価値の低いボトルを行に追加すると、その行の期待値が減少することを無視することです。 

## アプローチ

 まずは総当たり的な観点から検討してみましょう。 各ボトルをセルに割り当てるか未使用のままにし、行ごとに反復して期待値を計算するとします。 固定行の場合、値 v1 ～ vt を持つボトルが t 個含まれている場合、期待される寄与は (v1 + ... + vt) / t です。 これは、すべての行が割り当てられた値の平均に寄与することを意味します。 

ブルートフォース戦略では、k 個のボトルを最大 n 行に分割し、m 列に分散するすべての方法を列挙します。 列を無視した場合でも、ボトルのどのサブセットが各行に配置されるかを決定するだけで、最悪の解釈ではすでに n^k 個の可能性が生じます。 これは実現可能な限界をはるかに超えています。 

重要な点は、各行が割り当てられた値の平均のみに寄与するため、平均の合計が最大になるように行を構成する必要があるということです。 セットに可能な限り最大の要素が含まれている場合、セットの平均は最大になります。 ただし、緊張もあります。行内の要素の数を増やすと平均が薄れる可能性がありますが、慎重に分散すればより多くの行を空にしないことも可能になります。 

より有用な再定式化は、各ボトルを正確に 1 つの行に割り当てる (または未使用のままにする) という観点から考えることです。各行の寄与は、それに割り当てられているマルチセットのみに依存します。 平均の合計を最大化したいので、必要な場合を除き、同じ行に小さい値と大きい値を混在させないようにします。 

すべてのボトルの値を降順に並べ替え、各行が並べ替えられたリストの連続したセグメントを取得するように配置し、平均のバランスが保たれるように行サイズを選択すると、最適な構造が現れます。 重要な簡素化は、容量の制約を超えて列は重要ではないため、各行にボトルを何本入れるかを決定するだけでよいことです。

貪欲な構造は次のようになります。初期の行で高い平均を維持し、小さな値で高値の行が不必要に混入するのを避ける方法で最大値を割り当てます。 各行がその平均に寄与するため、行が飽和するまでは、高い値を積み重ねるのではなく、行全体に分散する方が有益です。 

これにより、問題はソートに加えて、容量制約の下での貪欲な割り当てに集約されます。

 | 最適 | O(k log k) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 各セルが最大 1 つのボトルを保持するという制約の下で、行平均の合計を最大化する方法に焦点を当てて、ソリューションを構築します。 

1. 元のインデックスを維持したまま、すべてのボトルを価格の安い順に並べ替えます。 その理由は、値を大きくすると行平均にできるだけ早く、そして強く影響を与える必要があるためです。 
2. 空のグリッドを初期化し、各行に最大 m 個のボトルを保持できる行のリストを準備します。 
3. 並べ替えたボトルを反復処理し、各ボトルをまだ容量が残っている行に割り当てます。 指針となる原則は、他の行が空の場合に、早い段階で行を過剰に埋めないようにすることです。これは、より低い値が追加されると行の平均が減少するためです。 
4. バランスの取れた方法で行を埋め、どの行にも不釣り合いに多くの小さな値が蓄積され、他の行は空のままになることがないようにします。 これにより、値が集中するのではなく、複数の行にわたって平均が高く保たれます。 
5. すべてのボトルを配置したら、残りのセルにゼロを入力します。 

この構造がなぜ機能するかは、平均値がどのように動作するかに関係しています。 各行は独立して寄与しており、寄与度は合計をカウントで割ると線形になります。 行ごとのボトルの数が固定されている場合、各行の前半に大きな値を配置すると、その行の平均が最大化されます。 大きな値を行全体に分散すると、小さな値によって薄められるのを防ぐことができます。これは、値を分離するよりも混合する方が限界寄与が減少するためです。 

維持される不変条件は、各ステップで、部分的に構築された割り当てによって行プレフィックスが可能な限り高値優先に維持され、行間の交換が容量制約に違反することなく平均の合計を増加させることができないということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())
    p = list(map(int, input().split()))
    
    # sort by value descending with original indices (1-based)
    items = sorted([(p[i], i + 1) for i in range(k)], reverse=True)
    
    grid = [[0] * m for _ in range(n)]
    
    # distribute in row-major order, but always place high values first
    idx = 0
    
    for i in range(n):
        for j in range(m):
            if idx < k:
                grid[i][j] = items[idx][1]
                idx += 1
            else:
                break
    
    for row in grid:
        print(*row)

if __name__ == "__main__":
    solve()
```この実装では、最初にすべてのボトルが並べ替えられ、価値の高いアイテムがグリッドの前の方に配置されます。 次に、グリッドを行ごとに埋めていき、決定的な順序でセルにインデックスを割り当てます。 

重要な点は、期待をシミュレートしたり、行ごとに明示的に最適化したりしようとしていないことです。 代わりに、より高い値をより早く配置すると、それらが初期の行にグループ化される可能性が高くなり、それが予想される合計を支配するという構造に依存します。 

行優先のフィルは、各行がソートされた配列の連続ブロックを受け取ることを保証します。これは、行が大きく異なる値でインターリーブされない最適な構造と一致します。 

## 実用的な例

 次のサンプル入力を考えてみましょう。 

入力:

 n = 2、m = 3、k = 3

 値 = [1、4、6]

 ソート後：[6, 4, 1]

 行ごとに埋めていきます。 

| ステップ | セル (i,j) | 価値を置く | 残りのアイテム |
 | --- | --- | --- | --- |
 | 1 | (0,0) | 6 | [4,1] |
 | 2 | (0,1) | 4 | [1] |
 | 3 | (0,2) | 1 | [] |

 グリッドは次のようになります。 

行 1: 6 4 1

 行 2: 0 0 0

 これは、単一行の値の最適な集中に対応し、その行の平均寄与を最大化します。 

次に 2 番目の例を考えてみましょう。 

入力:

 n = 3、m = 2、k = 4

 値 = [10, 9, 1, 1]

 並べ替え: [10、9、1、1]

 | ステップ | セル | 値 |
 | --- | --- | --- |
 | 1 | (0,0) | 10 |
 | 2 | (0,1) | 9 |
 | 3 | (1,0) | 1 |
 | 4 | (1,1) | 1 |

 行 1 の平均は (10+9)/2 = 9.5、行 2 の平均は (1+1)/2 = 1、行 3 は空です。 

トレースは、高い値をフロントローディングすると、支配的な最初の行が生成され、それが対物レンズを駆動することを示しています。

 ## 特殊なケース

 クリティカルなエッジ ケースは、k が n × m に等しい場合であり、グリッドが完全に埋まっていることを意味します。 この状況では、配置を最適化する自由はなく、アルゴリズムは単にグリッド全体にソートされた値を割り当てるだけです。 各行には正確に m 個の要素があるため、各行の平均は割り当てられたブロックによって固定され、並べ替えられた配置により、より高い値が以前の行に集中することが保証されます。 

もう 1 つのエッジ ケースは、k が n に比べて小さい場合です。 多くの行は空になります。つまり、期待値に寄与する行は数行だけです。 貪欲なフィルでは、最初の数行のみが値を受け取るようにします。空の行は平均を薄めないため、寄与の最大化と一致します。 

最後に、すべての価格が同じである場合、すべての取り決めは同じ期待値を生成します。 このアルゴリズムは引き続き、順次に入力することによって有効な割り当てを生成し、すべての置換が目的の下で同等であるため、正当性条件に違反することはありません。
