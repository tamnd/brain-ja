 ## 解決策
 ## 問題の理解

 列車は、特定の点から始まり右に無限に続く固定された水平線に沿って移動します。 すべての危険ゾーンは平面上の円であり、列車の進路が円を通過するときは常に、列車の進路のうちその円の内側にある部分のみをカウントします。 複数の円がパスに沿って重なっている場合、円ごとの寄与ではなく、ライン上でカバーされる全長を測定しているため、重なっている部分は 1 回だけカウントされます。 

幾何学的には、列車の経路を修正すると、すべてが 1 つの 1D 問題に集約されます。 列車は常に水平線 y = y0 上に留まるため、各円はこの線にまったく接触しないか、x 軸に沿ってセグメントを切り取っています。 タスクは、x ≥ x0 に制限された、そのようなすべてのセグメントの和集合の全長を計算することになります。 

制約では最大 100,000 個の円が許可されるため、すべての円のペアを比較したり、ラインを繰り返しスキャンしたりするアプローチは遅すぎます。 単純な O(k²) オーバーラップ解像度では、限界をはるかに超えます。 O(k²) 区間のマージさえも不可能です。 

微妙なエッジケースは、水平移動線とまったく交差しない円から発生します。 たとえば、(0, 10) を中心とし半径 1 の円は y = 0 に触れないため、何も寄与しません。 もう 1 つの特殊なケースは接線です。円が線にちょうど接触している場合、長さ 0 の単一の点セグメントに寄与し、答えに影響を与えることはできません。 

もう 1 つの重要な状況は、円の交点が開始位置 x0 の完全に左側にある場合です。 円と線が交差しても、x ≧ x0 の部分だけが問題となるため、間隔は正しく切り取られなければなりません。 

## アプローチ

 直接的なアプローチは、各円を個別に処理し、水平線 y = y0 と交差する位置を計算し、各点をカバーする円の数を維持しながら x 軸に沿って歩くことをシミュレートすることです。 これは自然に、X 座標上のスイープラインのアイデアにつながります。 ただし、必要なのはカバレッジ数ではなく結合の長さだけであるため、イベント構造として実装されたスイープ ラインも不要です。 

重要な観察は、各円が直線 y = y0 上の最大 1 つの区間に寄与するということです。 (xc, yc) を中心とする半径 r の円の場合、パスからの垂直距離は dy = y0 − yc として固定されます。 |死ぬ|なら > r、円はパスと交差しません。 それ以外の場合、交差部分の水平方向の半幅は sqrt(r² − dy²) となり、区間 [xc − d, xc + d] が得られます。 

すべての円を区間に変換した後、問題は重複する区間をマージし、x0 から開始してカバーされる全長を計算することになります。 

k が大きい場合、ブルート フォースは失敗します。これは、ペアごとのマージまたはスキャンの繰り返しによって 2 次の動作が生成されるためです。 左のエンドポイントで間隔を並べ替えると、問題は O(k log k) でのシングル パス マージに軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース オーバーラップ シミュレーション | O(k²) | O(k) | 遅すぎる |
 | 並べ替え + マージ間隔 | O(k log k) | O(k) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 1. 円を X 軸上の間隔に変換します。 

各円について、dy = y0 − yc を計算します。 dy² > r² の場合、列車は円に入らないのでスキップします。 それ以外の場合は、d = sqrt(r² − dy²) を計算します。 円は、直線 y = y0 上の区間 [xc − d, xc + d] に寄与します。 このステップでは、2D の幾何学的な問題を 1D の間隔の問題に還元します。 

### 2. 開始点までの間隔をクリップします。 

トレインは x = x0 で開始するため、x0 の残りの間隔の部分は無関係です。 各間隔 [l, r] を [max(l, x0), r] に置き換えます。 クリッピング後 l ≥ r の場合は破棄します。 これにより、到達可能なカバーされたセグメントのみを測定することが保証されます。 

### 3. すべての間隔を左のエンドポイントで並べ替えます

並べ替えにより決定的な順序が与えられ、線形結合が可能になります。 間隔を順序付けすると、重複構造が 1 回のスイープで簡単に解決されます。 

### 4. 間隔を結合し、カバーされた長さを蓄積する

 現在のアクティブな間隔 [cur_l、cur_r] を維持します。 ソートされた間隔を横断します。 次の間隔が cur_r の後に始まる場合は、cur_r − cur_l を答えに追加してリセットします。 それ以外の場合は、必要に応じて cur_r を拡張します。 最後に、最後のアクティブな間隔の長さを追加します。 

### なぜ効果があるのか

 各円は直線上の凸セグメントに正確にマップされ、直線上の結合の長さは元のジオメトリではなく間隔の端点のみに依存します。 並べ替えにより、間隔を処理するときに、以前の間隔との潜在的な重複がすべて単一のマージされたセグメントに解決されていることが保証されます。 不変条件は、すべてのステップで、現在のセグメントがすべての処理された間隔の和集合を表すため、結合されていないセグメントを追加しても領域を見逃したり二重にカウントしたりすることがないということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def solve():
    x0, y0, k = map(int, input().split())
    intervals = []

    for _ in range(k):
        xc, yc, r = map(int, input().split())
        dy = y0 - yc
        if dy * dy > r * r:
            continue
        dx = math.sqrt(r * r - dy * dy)
        l = xc - dx
        rgt = xc + dx

        if rgt <= x0:
            continue
        l = max(l, x0)
        intervals.append((l, rgt))

    if not intervals:
        print("0.0000000000")
        return

    intervals.sort()

    total = 0.0
    cur_l, cur_r = intervals[0]

    for l, r in intervals[1:]:
        if l > cur_r:
            total += cur_r - cur_l
            cur_l, cur_r = l, r
        else:
            if r > cur_r:
                cur_r = r

    total += cur_r - cur_l
    print(f"{total:.10f}")

if __name__ == "__main__":
    solve()
```コードはまずすべての円を列車の路線上の候補セグメントに変換し、次に x0 の左側にある無関係な部分を削除します。 ソートにより、1 回のパスでマージできることが保証されます。 円の交差により自然に実数値の端点が生成されるため、浮動小数点 sqrt が必要です。 最後の蓄積ステップは、最後のセグメントが失われないように、ループの後に慎重に実行する必要があります。 

よくある実装上の間違いは、マージ前に x0 に対してクリップするのを忘れることです。 もう 1 つは接線交点の扱いが間違っていることです。 r² == dy² の場合、dx はゼロになり、有効な長さゼロの間隔が生成されます。これは無害であり、当然、共用体ロジックでは無視されます。

 ## 特殊なケース

 直線 y = y0 にちょうど 1 点でのみ接触する円は、dy² = r² となり、dx = 0 となります。アルゴリズムはこれを [xc, xc] に変換し、マージ後の長さが 0 となるため、結果には影響しません。 

すべての円がパスの上または下にある場合、dy² > r² チェック中にすべての間隔が破棄され、空のリストが残り、出力 0 が生成されます。 

大きな円が左端に無限に伸びているが、開始点 x0 がその内側にある場合、クリッピングにより x0 以降の部分のみがカウントされます。 左側のエンドポイントは x0 になるため、寄与は到達可能なセグメントに正しく制限されます。
