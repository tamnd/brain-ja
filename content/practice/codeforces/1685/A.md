 ## 解決策
 ## 問題の理解

 各数値が隣接する数値よりも厳密に大きくなるか、厳密に小さくなるように、一連の整数を円上に配置するように求められます。 入力は複数のテスト ケースで構成されます。 各テスト ケースでは、整数の数が示され、その後に整数自体が続きます。 出力では、そのような循環配置が 1 つの有効な配置とともに可能であることを確認するか、不可能であることを示す必要があります。 

重要なのは、各数値が循環順序で「極大値」または「極小値」を形成する必要があるということです。 配置が円形であるため、最初と最後の要素は隣接するため、境界に注意する必要があります。 単純なアプローチでは、有効性をチェックするためにすべての順列を試行する可能性がありますが、テスト ケースに最大 100,000 個の数値が含まれ、テスト ケースが 30,000 個ある場合、これは計算上不可能です。 これは、解決策が本質的に建設的で線形または線形演算的でなければならないことを示唆しています。 

エッジ ケースには、すべての要素が等しい配列が含まれますが、隣接する要素よりも厳密に大きいまたは小さい要素はないため、これは不可能です。 小さな配列、特にサイズ 3 の場合、要素が明確でないか、適切にバランスが取れていない場合、扱いが難しくなる可能性があります。 

## アプローチ

 ブルートフォース手法では、配列のすべての順列を生成し、それが局所的な最小-最大条件を満たすかどうかをチェックします。 これは原理的には正しいですが、階乗時間計算量 O(n!) があり、10^5 までの n では現実的ではありません。 

最適な解決策の重要な洞察は、最小-最大パターンを満たすために、並べ替えられた配列を 2 つの半分 (小さい方の半分と大きい方の半分) に分割できることです。 それらをインターリーブし、小さい方の要素から 1 つの要素を取得し、次に大きい方の要素から 1 つの要素を取得し、このパターンを継続することで、各数値が隣接する数値よりも小さいか大きいかを交互に繰り返すことができます。 最大の半分の要素が小さい半分の要素よりも多くても 1 つ多い場合、このインターリーブにより常に有効な円を生成できます。 同一の値が多すぎる場合、これは失敗します。 

ソートされたインターリーブは、最大の数値の間に最小の数値を配置することで厳密な不平等が確実に満たされるため機能します。 並べ替えにより、どの要素が隣接する要素より小さいか大きいかを制御できます。

 | --- | --- | --- | --- |
 | ブルート フォース (順列チェック) | お(ん!) | O(n) | 遅すぎる |
 | 建設的なインターリーブ | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を昇順に並べ替えます。 これにより、小さい数値と大きい数値を明確に区別できるようになり、インターリーブ戦略が厳密な不平等を維持することが保証されます。 
2. アレイを 2 つの半分に分割します。 前半に小さい数字を入れ、後半に大きい数字を入れます。 n が奇数の場合、後半にはもう 1 つの要素が含まれます。 
3. 小さい方の半分の要素を偶数のインデックスに配置し、大きい方の半分の要素を奇数のインデックスに配置して、2 つの半分をインターリーブします (またはその逆)。 これにより、すべての要素が反対側の半分に隣接する要素を持つようになり、最小-最大条件が強制されます。 
4. どこかの時点で、小さい方の半分の最大数が大きい方の半分の最小数以上である場合、構築は不可能です。 それ以外の場合は、「YES」とインターリーブ配列を出力します。 

機能する理由: 利用可能な最小の数値を 2 つの大きな数値の間に配置し、最大の数値を 2 つの小さな数値の間に配置することで、各要素が隣接する要素よりも厳密に大きいか小さいことが保証されます。 ソートとインターリーブではこの特性が維持され、配列は循環的であるため、最後の要素と最初の要素も条件を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()
        half = n // 2
        if a[half-1] == a[half]:
            print("NO")
            continue
        res = []
        left = a[:half]
        right = a[half:]
        for i in range(half):
            res.append(left[i])
            res.append(right[i])
        if n % 2 == 1:
            res.append(right[-1])
        print("YES")
        print(" ".join(map(str, res)))

if __name__ == "__main__":
    solve()
```コードは、テスト ケースの数を読み取ることから始まります。 テスト ケースごとに、配列を読み取り、並べ替えます。 小切手`a[half-1] == a[half]`これにより、厳密な不等式を満たすために同じ数が多すぎないことが保証されます。 左半分と右半分をインターリーブすると、有効な循環最小-最大シーケンスが生成されます。 n が奇数の場合、右半分の最後の要素が追加されて円が完成します。

 ## 特殊なケース

 のために`n=3`そして入力`[1,1,2]`、左半分`[1]`そして右半分`[1,2]`境界等価性を持ちます。 アルゴリズムが検出するのは、`a[half-1] == a[half]`そして正しく出力される`NO`。 のために`n=6`と`[1,1,1,11,111,1111]`、ソートされた配列`[1,1,1,11,111,1111]`左に分かれます`[1,1,1]`そして正しい`[11,111,1111]`。 インターリーブにより生成される`[1,11,1,111,1,1111]`、これは循環最小-最大特性を満たします。 アルゴリズムは両方のケースを適切に処理します。
