 ## 解決策
 ## 問題の理解

 順列が与えられています`p`からの数字のうち`1`に`n`そして私たちのタスクは別の順列を構築することです`q`特定の重み関数を最小化する同じ数値。 の重さ`q`それぞれの絶対差の合計として計算されます。`q_i`そして`p`-次の位置の値`q`、順列を循環として扱います。 具体的な重さは、$$|q_1 - p_{q_2}| + |q_2 - p_{q_3}| + \dots + |q_n - p_{q_1}|$$入力は複数のテスト ケースで構成され、それぞれに順列長が指定されます。`n`そして順列`p`自体。 出力は順列である必要があります`q`長さの`n`可能な限り最小限の重量を実現します。 以来`n`最大 200 まで可能で、合計は`n`すべてのテスト ケースが 400 を超えない、すべてのテスト ケースを総当たりで列挙する`n!`順列は不可能です。 ただし、次のアルゴリズムを使用する余裕があります。`O(n^2)`各テストケースの複雑さ。 

エッジケースが発生するのは次の場合です`n`特に小さいです`2`または`3`。 たとえば、次の場合`p = [2, 1]`、 両方`[1, 2]`そして`[2, 1]`同じ重みを与えます。 1 つの固定された順序を前提とする不注意なアプローチでは、有効な出力が失われる可能性があります。 もう 1 つの微妙なシナリオは次のような場合です。`p`すでにソートまたは反転されています。 the algorithm should not assume that the smallest weight is always achieved by the identity permutation.

 ## アプローチ

 The brute-force solution would generate all permutations of`q`そしてそれらの重みを明示的に計算し、合計が最小のものを選択します。 これは正しいですが、非現実的です。`n!`の順列`n = 200`計算上不可能です。 

重要な観察点は、各要素が`q`と比較されます`p`の別の要素で`q`。 したがって、問題は順列の次のサイクルに変換できます。`p`。 各サイクルはシーケンスを表します。`q_i`にマッピングされます`p[q_i]`最初に戻るまで繰り返します。 選択することで`q`単一サイクルの要素を順番に並べると、各項がそのサイクルの連続する要素間の差となり、大きなジャンプが回避されるため、重みが最小限に抑えられます。 これにより、問題は次のサイクルを特定することになります。`p`そしてそのうちの 1 つを循環順序で出力します。 簡単なバージョンでは、次のサイクルに従って形成される順列です。`p`有効です。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして順列`p`。 
3. 配列を初期化する`visited`サイズの`n+1`どの要素がサイクルで使用されたかを追跡します。 
4. 以下の数値を反復処理します。`1`に`n`。 数字の場合`i`が訪問されていない場合は、から始まるサイクルに従い始めます。`i`:

 1.セット`cur = i`。 
2. その間`cur`訪問されていません:

 1. マーク`cur`訪問したとおり。 
2.追加`cur`出力順列へ`q`。 
3. に移動します`cur = p[cur-1]`。 
5. 結果の順列を出力します。`q`。 

不変条件は、各数値が 1 回だけ出現し、サイクルに従うことで要素が連続することを保証することです。`q`あるサイクルで連続している`p`。 この構造により、間のジャンプが最小限に抑えられます。`q_i`そして`p[q_{i+1}]`、最小限の重みを与えます。 全ての数字が入っているので、`q`有効な順列のままです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))
    
    visited = [False] * (n + 1)
    q = []
    
    for i in range(1, n + 1):
        if not visited[i]:
            cur = i
            while not visited[cur]:
                visited[cur] = True
                q.append(cur)
                cur = p[cur - 1]
    print(*q)
```コードは最初にテスト ケースの数を読み取ります。 各テスト ケースについて、次のようになります。`n`そして`p`。 の`visited`配列により、各サイクルを 1 回だけ実行することが保証されます。 のサイクル構造に従って、`p`各数値が 1 回だけ出現することを保証します。`q`そして重量も最小限に抑えられています。 インデックス作成は慎重に処理されます。`p`Python では 0 から始まりますが、値の範囲は次のとおりです。`1`に`n`。

 ## 特殊なケース

 いつ`n=2`そして`p=[2,1]`、次の 2 つのサイクルがあります。`1->2->1`。 アルゴリズムは次から始まります`1`を生み出すサイクルに従います`q=[1,2]`。 から開始`2`生み出すだろう`q=[2,1]`。 この場合、重み計算は対称であるため、両方の出力が有効です。 これは、アルゴリズムが長さ 2 のサイクルを正しく処理していることを示しています。 同様に、`n`複数のサイクルで 2 より大きい場合、アルゴリズムはすべてのサイクルを順番に連結し、最小の重みを維持する有効な順列を生成します。
