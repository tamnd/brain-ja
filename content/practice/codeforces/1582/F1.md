 ## 解決策
 ## 問題の理解

 整数の配列が与えられます。タスクは、次のすべての可能な値を決定することです。`x`これは、配列の増加するサブシーケンスの XOR として取得できます。 増加するサブシーケンスとは、各要素が前の要素よりも厳密に大きいものであり、サブシーケンスは元の配列の要素をスキップできます。 空のサブシーケンスは許可されます。これにより、次の XOR が生成されます。`0`。 出力には、考えられるすべての XOR 値が昇順でリストされている必要があります。 

配列サイズは最大 100,000 まで可能ですが、各要素は最大 500 です。`n`これは、サブシーケンスの数が指数関数的に増加するため、すべてのサブシーケンスを個別に検査するアルゴリズムを用意できないことを意味します。 小さな限界`a_i`(500) は、考えられる XOR 結果に対してビットマスキングや動的プログラミングなどの技術を使用して、限られた値の範囲を活用できる可能性があることを示唆しています。 

明らかではないエッジ ケースには、数値が繰り返される配列や、厳密に降順で並べられた配列が含まれます。 たとえば、配列`[2, 2, 2]`次のようなサブシーケンスは引き続き許可されます`[2]`XORを生成する`2`、 しかし`[2,2]`増加していないため無効です。 「厳密に増加する」要件を無視した不用意なアプローチでは、重複がカウントされ、無効な XOR 値が生成されます。 もう一つのエッジケースは、`[0, 0, 0]`、空のサブシーケンスが生成されます。`0`唯一の有効なサブシーケンスも生成します`0`。 

## アプローチ

 ブルート フォース アプローチでは、配列のすべてのサブシーケンスを考慮し、それらの XOR を計算し、結果を収集します。 これは、考えられるすべての増加サブシーケンスを列挙するため、正しいです。 ただし、部分列の数は`2^n`、それは周りにあります`10^30`のために`n = 100,000`、このアプローチは完全に実行不可能になります。 

より構造化されたアプローチでは、動的プログラミングを使用します。 それぞれの値について`v`配列内で、より小さい番号で終わる以前のサブシーケンスを拡張することを検討できます。 取得可能なすべての XOR 結果を、可能な最後の要素で終わるまで追跡します。 それぞれの XOR のセットを保存する単純な DP`n`要素は次のことを観察することで単純化できます。`a_i <= 500`。 これにより、可能な最後の要素と可能な XOR 値によってインデックス付けされた DP テーブルが可能になります。 重要な洞察は、それぞれについて維持することです。`a_i`、より小さい数値を使用して達成可能な XOR のセット`a_i`。 処理するたびに`a_i`、それを、より小さい値について以前に達成可能なすべての XOR と XOR し、テーブルを更新します。 これにより、サブシーケンスの明示的な反復処理が回避されます。 

もう 1 つのさらに効率的なアプローチでは、「XOR 基底」または「線形基底」と呼ばれる線形代数のような手法を使用します。 考え方は、厳密に増加するサブシーケンスに対して達成可能なすべての XOR 値を生成できる XOR の最小セットを表す一連の数値を維持することです。 配列内の各数値について、それより小さい数値を使用して基底を更新します。 基礎が構築されると、すべての XOR 値が基礎要素の組み合わせとして取得可能になります。 これにより、基底要素の数が最大 9 個になるため、複雑さが大幅に軽減されます (最大値であるため)。`a_i = 500`fits in 9 bits), and the update operations are linear in the basis size.

 | アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n) | O(2^n) | 遅すぎる |
 | セット付きDP | O(n * max_a * max_xor) | O(max_a * max_xor) | 承認済み |
 | XOR ベース | O(n * max_bits) | O(最大ビット) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を初期化する`dp`長さは 501、ここで`dp[v]`数値で終わる厳密に増加するサブシーケンスを使用して達成可能なすべての XOR 値のセットです`v`。 初期化する`dp`と`dp[0] = {0}`空のサブシーケンスの場合。 
2. 各数値を反復処理します。`a_i`入力配列内。 それぞれについて`a_i`、一時的なセットを作成します`new_xors`含む`a_i`それ自体、単一要素のサブシーケンスであるため、`[a_i]`有効です。 
3. 小さい値ごとに`v`未満`a_i`、 組み​​合わせる`a_i`すべての XOR 値を使用して`dp[v]`。 具体的には、それぞれについて、`x`で`dp[v]`、計算する`x ^ a_i`そしてそれを追加します`new_xors`。 このステップでは、次で終わるすべての有効なサブシーケンスを拡張します。`v`追加することで`a_i`。 
4.アップデート`dp[a_i]`すべての値を加算することで、`new_xors`。 これにより、`dp[a_i]`で終わる増加するサブシーケンスから取得できるすべての XOR が含まれます。`a_i`。 
5. すべての要素を処理した後、すべての要素の和集合を取得します。`dp[v]`を設定して、達成可能な XOR 値の最終セットを形成します。 
6. XOR 値のセットを昇順に並べ替え、カウントと値を出力します。 

なぜ効果があるのか​​: 各ステップで、`dp[v]`で終わるサブシーケンスを増やすことで達成可能なすべての XOR 値を正確に表します。`v`。 小さい数値を拡張すると増加するプロパティが維持され、XOR 演算が正しく伝播されます。 すべての要素を反復処理して結果をマージすることにより、有効な XOR が失われることはなく、無効なサブシーケンスが含まれることもありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

max_val = 500
dp = [set() for _ in range(max_val + 1)]
dp[0].add(0)  # handle empty subsequence producing XOR 0

for num in a:
    new_xors = {num}
    for smaller in range(num):
        for x in dp[smaller]:
            new_xors.add(x ^ num)
    dp[num].update(new_xors)

result = set()
for s in dp:
    result.update(s)

res_list = sorted(result)
print(len(res_list))
print(*res_list)
```の`dp`配列はそれぞれの`dp[v]`で終わるサブシーケンスの XOR のみを保存します`v`、増加するサブシーケンスのプロパティを維持します。 ネストされたループは安全です。`num <= 500`したがって、要素ごとに最大 500 回の反復が発生しますが、これは許容範囲内です。`n <= 10^5`。 すべてのセットを結合すると、達成可能なすべての XOR が生成されます。 最後に並べ替えると、出力が確実に昇順になります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from contextlib import redirect_stdout
    out = io.StringIO()
    with redirect_stdout(out):
        n = int(input())
        a = list(map(int, input().split()))

        max_val = 500
        dp = [set() for _ in range(max_val + 1)]
        dp[0].add(0)

        for num in a:
            new_xors = {num}
            for smaller in range(num):
                for x in dp[smaller]:
                    new_xors.add(x ^ num)
            dp[num].update(new_xors)

        result = set()
        for s in dp:
            result.update(s)

        res_list = sorted(result)
        print(len(res_list))
        print(*res_list)
    return out.getvalue().strip()
