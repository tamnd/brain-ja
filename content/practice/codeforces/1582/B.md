 ## 解決策
 ## 問題の理解

 いくつかの配列が与えられます。 各配列について、すべての要素の合計を次のようにします。$s$。 合計が正確に一致する部分列がいくつあるかを数える必要があります$s-1$。 

サブシーケンスは、任意の数の要素を削除することによって形成されます (要素をまったく削除しないか、すべてを削除することもできます)。 残りの要素の順序は変わりません。 

配列の長さは最大 60 で、配列を直接スキャンするには十分な長さですが、サブシーケンスの数は$2^{60}$、それは巨大です。 すべてのサブシーケンスを列挙することは完全に不可能です。 平$2^{40}$操作はすでに 1 秒の制限には多すぎます。 

値自体は次のように大きくできます。$10^9$、しかし、合計に対する動的計画法は決して必要ないので、それはあまり問題ではありません。 問題の構造は、0 と 1 がいくつ出現するかによってのみ決まることがわかります。 

いくつかの特殊なケースは見落とされがちです。 

考慮する```
1
2
1 0
```合計は 1 です。合計が 0 である部分列が必要です。空の部分列と 0 のみを含む部分列の両方がこれを満たしているため、答えは 2 です。空の部分列を忘れた解は 1 を返します。 

検討してください```
1
2
1000 1000
```合計は 2000 です。1999 を取得するには、合計が 1 になる要素を削除する必要がありますが、そのような要素や組み合わせは存在しません。 答えは 0 です。不注意なアプローチでは、すべての配列に少なくとも 1 つの有効なサブシーケンスがあると誤って想定される可能性があります。 

もう一つの興味深い事例は、```
1
4
1 1 0 0
```合計の合計は 2 です。ほぼ完全なサブシーケンスの合計は 1 でなければなりません。1 のうちの 1 つだけを削除でき、残りのゼロのセットはそれぞれ独立して選択できます。 ゼロが 2 つあるので、それが貢献します$2^2=4$選択肢。 どちらを削除するかを選択するには 2 つの方法があります。その答えは次のとおりです。$2 \times 4 = 8$。 

## アプローチ

 ブルートフォースソリューションは、すべてのサブシーケンスをチェックし、その合計を計算し、等しいものがいくつあるかを数えます。$s-1$。 これが機能するのは、定義がサブシーケンスについて直接尋ねているためです。 問題は部分列の数です。 と$n=60$、 がある$$2^{60}\approx 1.15\times 10^{18}$$実用的なものをはるかに超えた可能性があります。 

重要な観察は、補語に注目することから得られます。 合計を含む部分列$s-1$は、削除された要素の合計が 1 であることを意味します。 

すべての数値は負ではないため、削除された要素の合計が 1 になる唯一の方法は、1 に等しい要素を 1 つだけ削除し、1 より大きい正の数を削除しないことです。 

ゼロは合計に影響を与えないため、各ゼロは独立して残るか削除される可能性があります。 あれば$z$ゼロと$o$一つ、私たちは持っています$o$どちらかが削除される選択肢と、$2^z$どのゼロが残るかを決定する方法。 

答えは単純です$$o \times 2^z$$配列を 1 回スキャンすると、両方のカウントが得られます。

 | 最適 |$O(n)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 1 つのテスト ケースを読みます。 
2. 0 に等しい要素の数を数えます。この数を次のようにします。$z$。 

ゼロは、含めても除外しても合計が変わることがないため、特別です。 
3. 1 に等しい要素の数を数えます。この数を次のようにします。$o$。 

有効なサブシーケンスでは、値が 1 である要素を 1 つだけ除外する必要があります。 
4. 答えを次のように計算します。$$o \times 2^z$$がある$o$削除されたゼロには選択肢があり、すべてのゼロには独立して 2 つの可能性があります。 
5. 結果を出力します。 

### なぜ効果があるのか

 部分列に合計があるとします。$s-1$。 同様に、削除された要素の合計は 1 になります。 

すべての配列要素は負ではないため、1 より大きい要素は削除できません。 2 つ以上の要素を削除すると、すでに少なくとも 2 が寄与することになります。したがって、1 に等しい要素を 1 つだけ削除する必要があります。 

ゼロは削除された合計には何も寄与しないため、有効性に影響を与えることなく削除または保持できます。 

すべての有効なサブシーケンスは、削除された 1 の 1 つの選択肢と、各ゼロの 1 つの独立した選択肢に対応します。 逆に、そのような組み合わせはすべて有効なサブシーケンスを生成します。 この対応は 1 対 1 であるため、カウントは正確に$o \times 2^z$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    zeros = 0
    ones = 0

    for x in a:
        if x == 0:
            zeros += 1
        elif x == 1:
            ones += 1

    print(ones * (1 << zeros))
```プログラムは各テスト ケースを独立して処理します。 

配列に対するループでは、0 と 1 がカウントされます。 1 より大きい値は、合計が 1 に等しくなる必要がある削除されたセットに属することはできないため、無視されます。 

表現`1 << zeros`計算する$2^{\text{zeros}}$。 最大 60 個の要素の場合、最大値は次のとおりです。$2^{60}$、これは Python の任意精度の整数内に簡単に収まります。 

乗算の順序は関係ありません。 何もない場合、答えは自動的にゼロになります。

    sys.stdin = io.StringIO(inp)

 ## 特殊なケース

 検討してください```
1
2
1 0
```我々は持っています`ones = 1`そして`zeros = 1`。 アルゴリズムは戻ります$$1 \times 2^1 = 2$$2 つの有効なサブシーケンスは次のとおりです。`(0)`そして空のサブシーケンス。 ゼロは自由に削除できるため、アルゴリズムは当然両方をカウントします。 

考慮する```
1
2
1000 1000
```1 もゼロもありません。 アルゴリズムは計算します$$0 \times 2^0 = 0$$削除された要素のコレクションの合計が 1 になることはあり得ないため、答えは正確には 0 になります。 

考慮する```
1
4
1 1 0 0
```カウンターは、`ones = 2`そして`zeros = 2`。 答えは$$2 \times 2^2 = 8$$2 つのうち 1 つだけを削除する必要があります。 それぞれのゼロは独立して残ることも消えることもあります。 このアルゴリズムは、サブシーケンスを列挙することなく、8 つの可能性すべてをカウントします。
