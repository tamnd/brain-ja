 ## 解決策
 ## 問題の理解

 整数の配列が与えられます`a`長さの`n`。 タスクは、負でない整数をすべて見つけることです。`x`これは、厳密に増加する部分列の XOR として表現できます。`a`。 各要素が前の要素より厳密に大きい場合、サブシーケンスは厳密に増加しており、XOR が標準のビット単位の演算です。 

入力制約は重要です。`n`最大 1,000,000 に達する可能性があり、要素`a[i]`これは、すべてのサブシーケンスを列挙する素朴なアプローチを即座に除外します。`2^n`可能なサブシーケンス。 二次関数のアルゴリズムでも`n`内部操作が重い場合は遅すぎる可能性があります。 線形または線形算術の複雑さに近いものが必要です。`n`に応じて管理可能な要素を含む`a[i]`。 

Edge cases are non-obvious. 1 つは空のサブシーケンスで、常に XOR 0 が得られます。もう 1 つは、すべての要素が等しい場合で、長さ 1 のサブシーケンスのみが新しい XOR 値に寄与します。 また、サブシーケンスを形成するときに重複を厳密に増加するものとして扱うことができないため、繰り返される要素は慎重に扱う必要があります。 

## アプローチ

 ブルートフォース手法では、増加するすべてのサブシーケンスを列挙し、その XOR を計算します。 長さの配列の場合`n`、部分列の数は`2^n`、これは不可能です`n = 10^6`。 各位置で可能なすべての XOR を追跡する動的プログラミング アプローチでも、最適化しないと大きくなりすぎます。これは、XOR 値自体が最大に達する可能性があるためです。`2^13`最大 5000 の数値の場合、可能な XOR の数は爆発的に増加する可能性があります。 

重要な洞察は、GF(2) 上の線形代数 (XOR は加算法 2 のように動作します) と貪欲なシーケンス構築からのアイデアを組み合わせることによって得られます。 サブシーケンスを明示的に考慮する代わりに、各値で終わるシーケンスを厳密に増加させることで達成できる XOR 値の「基礎」を維持します。 考えられるそれぞれの数字について`v`最小から最大まで、以下の数字で終わるシーケンスで到達可能な XOR のセットを維持します。`v`。 私たちが見るとき`v`、セット内の各 XOR を次の XOR 演算によって拡張します。`v`。 これらのセットを結合すると、達成可能なすべての XOR が得られ、それらを次の関数を使用して効率的に表すことができます。`set`または`boolean`5000 までの数値の XOR は 8192 によって制限されるため、配列になります。 

これにより、サブシーケンスを列挙する必要がなくなるため、複雑さが軽減されます。 値を順番に処理することにより、厳密に増加する条件を尊重しながら、達成可能な XOR を前方に伝播します。

 ## アルゴリズムのチュートリアル

 1. **データ構造の初期化**: ブール値セットの配列を準備します。`reachable`サイズの`max_value+1`(5001) 各値で終わるシーケンスによって達成可能な XOR を追跡します。 また、グローバルセットを初期化します`all_xor`含む`0`空のサブシーケンスの場合。 
2. **値を順番に処理**: 反復します`v`0 から 5000 まで。それぞれ`v`入力配列に存在する場合は、各 XOR を取得して新しい XOR を計算します`x`で`all_xor`そして形成`x ^ v`。 これらを一時的なセットに集めます`new_xor`。 
3. **到達可能な XOR を更新**: マージ`new_xor`の中へ`all_xor`。 これにより、すべてのサブシーケンスが数値 ≤ で終わることが保証されます。`v`前の要素よりも大きい数のシーケンスのみを拡張するため、厳密に増加する要件が考慮され、尊重されます。 
4. **結果のコンパイル**: すべての値を処理した後、`all_xor`厳密に増加するサブシーケンスによって達成可能なすべての XOR が含まれます。 並べ替えて出力します。 

**機能する理由**: このアルゴリズムは、次の不変条件を維持します。`all_xor`数値 ≤ current で終わる厳密に増加するサブシーケンスのすべての XOR が含まれます`v`。 昇順に処理することで、結合することはありません`v`数字付き ≥`v`したがって、厳密に増加する特性が保存されます。 新しい数値はそれぞれ、最後の要素よりも厳密に大きい場合にのみシーケンスを拡張します。 これにより、完全性と正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

max_val = 5000
present = [0] * (max_val + 1)
for num in a:
    present[num] = 1

all_xor = {0}

for v in range(max_val + 1):
    if present[v]:
        new_xor = set()
        for x in all_xor:
            new_xor.add(x ^ v)
        all_xor |= new_xor

result = sorted(all_xor)
print(len(result))
print(' '.join(map(str, result)))
```このコードは、不必要な繰り返しを避けるために、まず配列内に出現する数値を記録します。 次に、数値を昇順に使用して、達成可能な XOR のセットを繰り返し拡張します。 セットユニオン`|=`重複がないことを保証します。 最後に、カウントとソートされた XOR 値を出力します。 

微妙な点には初期化が含まれます`all_xor`と`0`空のサブシーケンスと処理の場合`v`厳密に増加する条件を尊重するために増加します。 どちらかを忘れると、誤った結果が生じます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    max_val = 5000
    present = [0] * (max_val + 1)
    for num in a:
        present[num] = 1
    all_xor = {0}
    for v in range(max_val + 1):
        if present[v]:
            new_xor = set()
            for x in all_xor:
                new_xor.add(x ^ v)
            all_xor |= new_xor
    result = sorted(all_xor)
    return f"{len(result)}\n{' '.join(map(str,result))}"
