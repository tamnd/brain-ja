 ## 解決策
 ## 問題の理解

 次のサイズの長方形グリッドが与えられます。$N \times M$。 このグリッドの内側に、同心の長方形の「リング」で構成される構造を構築します。 各リングは、前のリングの内側にある小さな長方形の周囲を占め、連続するリングの間には、幅がちょうど 1 セルの必須の空の境界線があります。 各リングは、境界に沿ってほぼ完全に茂みで埋められていますが、境界上のちょうど 1 つのセルが入口として機能するために空のままになっています。 

最初のリングはグリッド全体の外側の境界です。 2 番目のリングはそこから 1 セル内側に配置され、3 番目のリングはさらに内側のセルに配置されます。 新しいリングはすべて、周囲に空の廊下があるため、前のリングと比較して 2 行 2 列の収縮を消費します。 

最大でビルドする場合に使用されるブッシュの数を計算するように求められます。$K$リングをすべて配置できない場合があります$K$グリッドが小さくなりすぎる場合。 その場合、各リング内に少なくとも 1 つの内部セルを残す有効なリングの最大数のみを構築します。 

有効な各リングは、周囲の長さから 1 を引いた値になります (1 つのセルが茂みのない入口であるため)。 

制約により許可されるのは、$N, M, K$まで$3 \cdot 10^9$したがって、どのソリューションも一定時間で実行する必要があります。 リングの数は数十億にも達する可能性があるため、リングを反復するシミュレーションは不可能です。 解決策は、各リングの直接的な算術特性評価に依存する必要があります。 

グリッドが小さすぎて、内部にフリー セルを含む別の完全な長方形が収まらない場合、微妙なエッジ状態が発生します。 たとえば、1 つのリングを構築した後、残りの内側の長方形が次のようになったとします。$1 \times M$または$2 \times 2$の場合、次の場合でもそれ以上のリングは無効になります。$K$の方が大きいです。 

## アプローチ

 直接的なアプローチでは、リングごとにシミュレートされます。 各リングについて、長方形を両次元で 2 縮小し、その周長を計算し、入口の 1 を減算して累積します。 どちらかの場合は停止します$K$リングが構築されていないか、残りの四角形に有効な内部領域を含めることができません。 

これは正しいですが、コストはリングの数に比例します。 最悪の場合、各リングの寸法はわずかに減少するだけなので、最大約$1.5 \cdot 10^9$繰り返し。 反復ごとに定数時間の演算を行ったとしても、これは時間制限をはるかに超えています。 

重要な観察は、各リングがそのインデックスによって完全に決定されるということです。 の$i$- 番目のリング (0 から始まるインデックス) は、次のサイズの長方形の周囲長です。$$(N - 2i) \times (M - 2i)$$リングは、両方の次元が少なくとも 1 である場合にのみ有効であり、さらに重要なことに、内部要件はリング内に少なくとも 1 つの空きセルを意味するため、以下が必要です。$$N - 2i \ge 3,\quad M - 2i \ge 3$$これにより、リングの数に厳密な上限が決まります。$$i < \frac{N-1}{2}, \quad i < \frac{M-1}{2}$$したがって、リングの数は次のようになります。$$R = \min\left(K, \left\lfloor \frac{N-1}{2} \right\rfloor, \left\lfloor \frac{M-1}{2} \right\rfloor\right)$$一度$R$がわかっている場合、各リングの寄与を合計します。 の$i$-th リングの周囲の長さ:$$2(N - 2i) + 2(M - 2i) - 4$$そして、入口の 1 を減算します。つまり、次のようになります。$$4(N + M - 4i) - 4 - 1 = 4(N + M - 4i) - 5$$したがって、単純な等差級数を計算します。$i = 0 \ldots R-1$。

 ## アルゴリズムのチュートリアル

 グリッドが崩壊する前に、完全なリングが何個存在できるかを計算します。 

1. ジオメトリで許可されるレイヤーの最大数を次のように計算します。$\left\lfloor\frac{N-1}{2}\right\rfloor$そして$\left\lfloor\frac{M-1}{2}\right\rfloor$。 これにより、選択されたすべてのリングが内部空間の少なくとも 1 つのセルを残すことが保証されます。 
2.セット$R$最小限まで$K$そしてこれら 2 つの幾何学的限界です。 これにより、要求されたリング数が物理的に適合する数に固定されます。 
3. すべてのリングの合計寄与度を計算します。 各リングは、周囲から 1 つの入口セルを引いたものに寄与し、これはリング インデックスに線形に依存します。$i$。 
4. 合計を次のように書き換えます。$$\sum_{i=0}^{R-1} (4N + 4M - 16i - 5)$$定数と次の合計の合計として$i$。 
5. 等差級数の公式を使用して評価します。$$R(4N + 4M - 5) - 16 \cdot \frac{R(R-1)}{2}$$### なぜ効果があるのか

 各リングは、リング インデックスで線形であるサイズの縮小を除いて独立しています。 ジオメトリでは、リングが無効になると、それより深いリングもすべて無効になることが保証されます。これは、両方の寸法がレイヤーごとに厳密に 2 ずつ減少するためです。 この単調収縮により、問題は有効なリングの単一の連続したプレフィックスに変わります。 各リングはそのインデックスの一次関数に寄与するため、合計は閉形式の算術合計となり、シミュレーションの必要がなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N = int(input())
    M = int(input())
    K = int(input())

    R = min(K, (N - 1) // 2, (M - 1) // 2)

    if R <= 0:
        print(0)
        return

    # sum of (4N + 4M - 16i - 5)
    total = R * (4 * N + 4 * M - 5)
    total -= 16 * (R * (R - 1) // 2)

    print(total)

if __name__ == "__main__":
    solve()
```コードはまず、実現可能なレイヤーの数を決定します。 表現`(N - 1) // 2`そして`(M - 1) // 2`リングが少なくとも 1 セルの内部を持つように、内側へのオフセットの最大数をキャプチャします。 1 を引くことで、次のような縮退ケースが保証されます。$3 \times 3$グリッドではリングを 1 つだけ許可します。 

合計には、リング寄与の定数部分と線形部分の分割から導出された閉じた形式の式が使用されます。 用語`R * (R - 1) // 2`インデックスの合計に相当します$0 + 1 + \dots + (R-1)$、これが唯一の非定数部分です。 

値が前後に達する可能性があるため、整数演算には注意が必要です。$10^{19}$ですが、Python はこれを安全に処理します。

 ## 特殊なケース

 主なエッジケースは、グリッドが 1 つのリングには十分な大きさだが、2 つには十分ではない場合です。 取る$N = 4$、$M = 4$、$K = 10$。 式は次のようになります。$$R = \min(10, 1, 1) = 1$$外輪のみ有効です。 内側の$2 \times 2$この領域は、別のリングに対して少なくとも 1 つの内部空きセルを持つという要件を満たさないため、除外する必要があります。 計算では、これが自然に強制されます。$(N-1)//2$そして$(M-1)//2$限界。 

もう 1 つの微妙なケースは、1 つの次元が最小である場合です。$N = 3$、$M$大きい。 たとえ$M$多くの縮小ステップが許可されると、垂直方向の制約が優先され、複数のリングが妨げられます。 アルゴリズムは、より狭い次元を正確に優先します。 

最後に、いつ$K = 0$または非常に大きな式、$R$正しくクランプされ、ネガティブ リングと幾何学的実現可能性を超えるオーバーフローの両方が発生しないことが保証されます。
