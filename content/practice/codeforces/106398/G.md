 ## 問題の理解

 私たちは一連の計画されたトレーニングセッションを与えられています。 理想的には、$n$ただし、Vasya はセッションの一部をスキップする場合があります。 スキップされたセッションはすべて失われるわけではありません。後で訪問するセッションで補償する必要があります。 セッションを欠席した場合$i$セッション時に補償されます$j$、努力コストは$j - i + 1$これには、当日に行われたトレーニングがすでに含まれています$j$自体。 

Vasya は任意の数のセッションをスキップすることができ、1 回の訪問で複数の欠席したセッションを補うことができます。 ただし、すべての報酬の合計累積労力が超過することはできません。$k$。 目標は、すべてのセッションを確実に確保しながら、Vasya が実際に参加するセッションの数を最小限に抑えることです。$n$セッションは最終的に総労力予算の範囲内で補償されます。 

重要なのは正確なスケジュールではなく、スキップされたセッションがどのようにグループ化され、最終的にどこで返済されるかです。 連続するセッションの長いブロックがスキップされ、後で 1 回だけ参加した場合、以前に欠席したセッションによってペナルティが累積されるため、コストが大きくなります。 

入力は 2 つの整数を与えます$n$そして$k$、出力は、合計労力を超過することなく、逃したすべてのセッションを補うことができる訪問セッションの最小数です。$k$。 

制約は以下に達します$10^{18}$、したがって、線形または二次反復に依存するすべての解$n$不可能です。 問題を閉形式条件または対数探索に還元する、純粋に数学的または貪欲な構造が必要です。 

重要なエッジケースは、Vasya がほぼすべてのセッションに出席する場合です。 素朴な想定では、出席するのは$n-1$セッションは常に機能しますが、コストが依然として超過する可能性があります$k$スキップされたセッションがどのように配置されるかによって異なります。 もう 1 つの微妙なケースは、スキップされたすべてのセッションが最初または最後にグループ化される場合です。これは、コストをまったく異なる方法で最小化または最大化するためです。

 ## アルゴリズムのチュートリアル

 スキップされたセッションの数という観点から問題を再解釈します。 させて$x$Vasya がスキップしたセッションの数になります。$n - x$セッション。 目標は最大値を決定することです$x$スキップされたすべてのセッションをコスト内で補うことができるようにする$k$。 

1. まず、コストは、スキップされたセッションとその後の参加セッションとの組み合わせにのみ依存することがわかります。 コストは遅延とともに直線的に増加するため、コストを最小限に抑えるには、スキップされたすべてのセッションをできるだけ早く補償する必要があります。 
2. 参加セッションがスキップされたセッションを吸収する「アンカーポイント」として均等に分散されるようにスケジュールを調整します。 各アンカーはスキップされたセッションのブロックを補償でき、各ブロック内のコストは距離に基づく算術構造に従います。 
3. 一定数のスキップされたセッションの場合$x$、これらのスキップされたセッションが単一の連続プレフィックスを形成すると、最初に利用可能な参加セッションまでの平均距離が最小限に抑えられるため、最小限のコストが達成されます。 断片化しても距離は伸びるだけです。 
4. この最適な配置の下では、コストは三角構造になります。スキップされたセッションが寄与します。$1 + 2 + \dots + x$に等しい$x(x+1)/2$なぜなら、スキップされた各セッションは、最終的には可能な限り最良の方法で次に利用可能な参加セッションと一致するからです。 
5. 今度は不等式を解きます$x(x+1)/2 \le k$。 これにより、許可されるスキップの最大数が決まります。 次に、答えを次のように計算します。$n - x$。 

### なぜ効果があるのか

 重要な不変条件は、コスト関数が絶対的なラベルではなく、スキップされたセッションと出席したセッションの間の相対的な順序のみに依存するということです。 コストを増加させることなく、スキップの任意の構成を連続ブロックに変換できます。 この正規形式に縮小されると、コストは純粋なプレフィックス合計構造になり、スキップをグループ化することによって独自に最小化されます。 これにより、三角数の境界が必要かつ十分になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())

    lo, hi = 0, n

    def cost(x):
        return x * (x + 1) // 2

    while lo < hi:
        mid = (lo + hi + 1) // 2
        if cost(mid) <= k:
            lo = mid
        else:
            hi = mid - 1

    skipped = lo
    print(n - skipped)

if __name__ == "__main__":
    solve()
```このソリューションは、スキップされたセッションの数に対して二分検索を実行します。 ヘルパー関数は、指定されたスキップ数の三角コストを計算します。 コストが以下を超えない実現可能な最大のスキップ数を検索します。$k$、からそれを引きます$n$参加セッションの最小数を取得します。 

二分探索はコスト関数なので安全です$x(x+1)/2$厳密に増加しています$x$、実現可能性の単調性を確保します。
