 ## 問題の理解

 課題は幾何学的なものです。 各テスト ケースでは、平面内に一連の個別の点が与えられ、4 つの異なる点のグループを大文字として配置できる数を数えなければなりません。`T`。 

4点の場合`A`、`M`、`B`、 そして`C`、の水平部分`T`セグメントです`AB`、 と`M`まさにその中間点。 残りのポイント`C`幹の終点です。 ステムは次と同じ長さでなければなりません`AB`、そしてそれは垂直でなければなりません`AB`で`M`。 同様に、もし`A`そして`B`知られているなら、`M`は強制されており、可能な場所は 2 つだけです`C`。 

入力には最大 100 個のテスト ケースが含まれます。 各セットには 4 ～ 50 個の異なる点が含まれており、すべての座標はそれらの間にあります。`-1000`そして`1000`。 公式の制限時間は 1 秒、メモリ制限は 256 MB です。 

50 ポイントという小さな限界は、テスト ケースが 100 個ある場合、単純な 4 ポイントの列挙を除外するのに十分な大きさです。 4 つの異なる点の順序付き選択肢をすべて列挙するには、`50 * 49 * 48 * 47 = 5,527,200`1 つの最大サイズのテスト ケースの選択肢、または 100 のそのようなケース全体で最大 5 億 5,272 万の選択肢。 3次時間に近い解は快適ですが、2次時間の解はさらに優れています。 

浮動小数点の比較が数値上の主な問題です。 このステートメントは、2 つの値の差が最大である場合に、それらの値が等しいと定義します。`10^-6`。 との座標を比較すると、`==`次のような算術演算が行われるため、結果として有効な点が拒否される可能性があります。`(x1 + x2) / 2`正確に表現できない場合があります。 

例えば4つのポイント```
(0, 0)
(2, 0)
(1, 0)
(1, 2)
```を形成します`T`、したがって、答えは次のとおりです`1`。 中点を計算し、浮動小数点座標を完全に等しいかどうか比較する実装は、問題が保証していない特性に依存しています。 

2 番目のエッジケースは、同じです`T`で説明できます`A`そして`B`交換した。 のために```
(0, 0)
(2, 0)
(1, 0)
(1, 2)
```ペア`(A,B)`そして`(B,A)`同じクロスバーについて説明します。 順序付きペアをカウントすると、次のようになります。`2`正しい答えの代わりに`1`。 

3 番目のエッジ ケースは、候補クロスバーに 2 つの考えられるステム エンドポイントのうち 1 つしか存在しない場合に発生します。 のために```
(0, 0)
(2, 0)
(1, 0)
(1, 2)
(5, 5)
```まだちょうど1つあります`T`。 両方の垂直方向をチェックする必要がありますが、実際に存在する点のみを数えます。 

公式の UCF ステートメントでは、同じ幾何学的定義が示されており、`10^-6`平等寛容。 

## アプローチ

 直接的なアプローチは、4 つの異なる点を選択し、それらの点の可能なすべての割り当てをテストすることです。`A`、`M`、`B`、 そして`C`。 テストは定義から直接続きます。次のことを確認します。`M`の中間点です`AB`、 それ`CM`と同じ長さです`AB`、そして 2 つのセグメントが`M`垂直です。 

有効なすべてのものが存在するため、そのアプローチは正しいです。`T`は 4 つのポイントで構成されているため、考えられるすべての割り当てを調べることで、最終的にその正しい役割が検査されます。 問題は選択肢の多さです。 50 ポイントの場合、順序付き 4 倍数を列挙する場合でも、テスト ケースごとに 5,527,200 の選択肢が必要で、最大サイズの 100 のケースでは、幾何学的チェックが実行される前に 552,720,000 の選択肢に達する可能性があります。 

ジオメトリの構造により、検索を整理するためのはるかに優れた方法が得られます。 4 つのポイントを選択する代わりに、2 つのエンドポイントを選択します`A`そして`B`クロスバーの。 これら 2 つの点が固定されると、他の 2 つの位置には自由が残されません。 

中間点は`M = ((Ax + Bx) / 2, (Ay + By) / 2)`。 

ベクトルを次のようにします`A`に`B`なれ`(dx, dy)`。 同じ長さの垂直ベクトルは次のいずれかです。`(-dy, dx)`または`(dy, -dx)`。 したがって、考えられるステムエンドポイントは以下のみです。`C1 = M + (-dy, dx)`そして`C2 = M + (dy, -dx)`。 

したがって、順序のない点のペアごとに、最大で 2 つの候補となる 4 番目の点が生成されます。 これらの候補座標が入力内に出現するかどうかを確認するだけで済みます。 

最大 50 ポイントの場合、すべてのポイントをスキャンして各候補を見つける単純な実装でも、`O(p^3)`時間。 がある`O(p^2)`の選択肢`A,B`、2 つの候補地、および`O(p)`各候補者をスキャンします。 これは、指定された境界に対して十分に小さいことが容易にわかります。 

このブルートフォース手法は、考えられるすべての役割の割り当てが検査されるため機能しますが、ジオメトリがすぐに決定される可能性のある組み合わせを探索するため失敗します。 クロスバーのエンドポイントが中点と考えられる両方のステムを一意に決定するという観察により、検索の次元全体が削除されます。

 | ブルートフォース | O(p^4) | お(1) | 最悪の場合は遅すぎる |
 | 最適 | O(p^3) | O(p) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. を読んでください。`p`現在のテスト ケースのポイントを取得し、その座標を保存します。 
2. 順序付けされていない点のペアをすべて列挙します`A`そして`B`。 とのペアのみを使用する`i < j`クロスバーのエンドポイントを交換しても別のコンポーネントが作成されないため、これは不可欠です。`T`。 
3. 中点を計算する`M`の`A`そして`B`。 中点は定義の最初の条件によって強制されるため、他の入力点を選択する必要はありません。`M`独立して。 
4. コンピューティング`dx = Bx - Ax`そして`dy = By - Ay`。 ベクトル`(dx, dy)`クロスバーについて説明します。 
5. 考えられる 2 つのステムエンドポイントを構築します。 に垂直なベクトル`(dx, dy)`全く同じ長さのものは`(-dy, dx)`、その反対は`(dy, -dx)`。 どちらかのベクトルを追加すると、`M`についての可能な位置を 1 つ与える`C`。 
6. 各候補者について`C`、入力ポイントをスキャンし、両方の座標が範囲内にあるかどうかを確認します。`10^-6`候補座標の。 点が一致する場合、答えをインクリメントします。 
7. すべてのペアと両方の垂直方向を処理し、結果のカウントを必要な形式で出力します。`Set #k: answer`フォーマットの後に空行が続きます。 

数値比較は 2 つの座標に独立して適用されます。 両方の座標の差が最大でも以下の場合、点は存在するとみなされます。`10^-6`、ステートメントの等価ルールと一致します。 

### なぜ効果があるのか

 有効なすべての`T`、その 2 つのクロスバー エンドポイントは順序のないペアです`A,B`入力で。 アルゴリズムがそのペアに到達すると、中点計算によって必要な点が正確に生成されます。`M`。 ベクトル`AB`同じ長さを持つ 2 つの垂直ベクトルを正確に決定します。`AB`したがって、生成された 2 つの候補は正確に、`C`。 

したがって、有効な`C`の`T`スキャンで見つけなければなりません。 逆に、生成された候補が入力点と一致する場合は常に、中点条件、等しい長さ条件、および垂直性条件がすべて構築上成立するため、これら 4 つの点は有効な条件を形成します。`T`。 

使用する`i < j`各クロスバーが 1 回考慮されることを意味します。 固定クロスバーの場合、考えられるステム エンドポイントはそれぞれ 1 回考慮されるため、有効なグループは複数回カウントされません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

EPS = 1e-6

def same_point(x1, y1, x2, y2):
    return abs(x1 - x2) <= EPS and abs(y1 - y2) <= EPS

def solve_case(points):
    n = len(points)
    ans = 0

    for i in range(n):
        ax, ay = points[i]

        for j in range(i + 1, n):
            bx, by = points[j]

            dx = bx - ax
            dy = by - ay

            mx = (ax + bx) / 2.0
            my = (ay + by) / 2.0

            # Two perpendicular vectors having the same length as AB.
            candidates = (
                (mx - dy, my + dx),
                (mx + dy, my - dx),
            )

            for cx, cy in candidates:
                for px, py in points:
                    if same_point(cx, cy, px, py):
                        ans += 1
                        break

    return ans

def main():
    t = int(input())

    out = []

    for case_no in range(1, t + 1):
        p = int(input())
        points = [tuple(map(float, input().split())) for _ in range(p)]

        ans = solve_case(points)

        out.append(f"Set #{case_no}: {ans}")
        out.append("")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()

中点は除算を使用します。`2.0`座標は実数だからです。 次に、2 つの候補点が垂直変換から直接取得されます。 もし`(dx, dy)`はクロスバーベクトル、`(-dy, dx)`長さを変えずに 90 度回転させます。 

内部スキャンでは、生の浮動小数点座標をキーとする辞書の代わりに、イプシロン比較を意図的に使用します。 正確な浮動小数点値に基づく辞書では、結果が表現の詳細に依存することになります。 わずか 50 ポイントなので、スキャンはより簡単かつ十分に高速です。 

の`break`一致点を見つけた後も必要です。 入力ポイントは明確であることが保証されているため、1 つの候補は最大 1 つの入力ポイントに対応できます。 なしで`break`、ステートメントによって重複が除外されているにもかかわらず、将来の重複座標によってカウントが誤って増加します。
