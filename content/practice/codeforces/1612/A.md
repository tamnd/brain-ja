 ## 解決策
 ## 問題の理解

 私たちは、マンハッタン距離を使用して動きが測定されるグリッドに取り組んでいます。これは、2 点間のコストが水平方向と垂直方向の距離の合計であることを意味します。 1 つの点は原点に固定され、2 番目の点は座標に位置します。$(x, y)$。 タスクは、中間格子点が存在するかどうかを判断することです。$C$、非負の整数座標で、原点とマンハッタン間の距離のちょうど中間に位置します。$B$。 そのようなポイントが存在する場合は、有効なポイントを出力する必要があります。 それ以外の場合は不可能であると報告します。 

要件の構造は対称的です。つまり、原点から距離までの距離が異なります。$C$原点からの距離の半分に等しくなければなりません$B$、そして同じことがこれからも成り立つはずです$B$に$C$。 これはすぐに次のことを意味します$C$はユークリッド用語の中点ではなく、L1 メトリックの下の中点です。距離が直線を形成するのではなく、軸間で分割されるため、動作が大きく異なります。 

制約は小さく、座標は 50 で制限され、テスト ケースは最大 3000 個です。 これは、$O(1)$最悪の場合、テスト ケースごとに定数係数の構築が必要になります。 理論的にはグリッドの総当りスキャンも可能ですが、その必要はありません。 ただし、正確さはパフォーマンスではなく、マンハッタンの中間点がいつ存在するかを理解することによって左右されます。 

次の場合、微妙なエッジケースが発生します。$x + y$奇数です。 その場合、マンハッタンからの距離は、$A$に$B$は奇数であり、それを半分にすると非整数になります。 整数点間のマンハッタン距離は常に整数であるため、有効な中点は存在できません。 別の失敗ケースは、両方の座標が小さいがパリティが混在している場合に発生します。たとえば、$(2, 1)$ここで、座標を個別に分割するような単純な試みは、両方の距離制約を同時に満たすことができません。 

## アプローチ

 単純なアプローチでは、すべての候補点を試してしまうでしょう$C = (i, j)$と$0 \le i, j \le x + y$、両方の距離を計算し、両方が等しいかどうかを確認します。$(x + y)/2$。 グリッドが小さいため概念的には機能しますが、最悪の場合、大まかな検査が行われてしまいます。$O((x+y)^2)$テストケースごとの候補者。 3000 のテスト ケースにわたって、これは理論的にはまだ管理可能ですが、不必要にコストがかかり、基礎となる構造がわかりにくくなります。 

重要な観察は、マンハッタン距離が軸に沿って分解されることです。 私たちが望んでいるのは:$$|x| + |y| = d$$そしてポイントが必要です$C = (c_x, c_y)$次のような:$$c_x + c_y = d/2$$そしてまた:$$|x - c_x| + |y - c_y| = d/2$$必要な合計距離を水平方向と垂直方向の寄与に分割すると解釈すると、ジオメトリは単純になります。 すべての点が第 1 象限にあるため、絶対値はなくなり、問題は分布に帰着します。$d/2$両方の終点に到達するのと一致する方法で、x 軸と y 軸の間の距離の単位を指定します。 

させて$d = x + y$。 もし$d$は奇数です。整数の中点は存在しません。 偶数の場合、次のように構築する必要があります。$c_x, c_y \ge 0$次のような:$$c_x + c_y = d/2$$そして$c_x$を超えない$x$～との距離との一貫性を壊す方法で$B$。 

明確で建設的なトリックは、すべての水平方向の進行状況を最初に配置してみることです。距離の半分を消費するか、到達するまで、X 軸に沿って移動しようとします。$x$、残りを y 方向に使用します。 対称的な代替案も同様に機能します。 有効な構造の 1 つは次のとおりです。$$c_x = \min(x, d/2), \quad c_y = d/2 - c_x$$これにより、負でないことが保証され、必要な合計が保持され、移動のすべての単位がマンハッタン メトリックで正確に考慮されるため、両方の距離が自動的に調整されます。

 ## アルゴリズムのチュートリアル

 各テスト ケースを個別に処理し、中間点を直接構築します。 

1. コンピューティング$d = x + y$。 これは、原点からマンハッタンまでの合計距離です。$B$、そしてそれは中間点が数値的に可能であるかどうかを決定します。 
2. もし$d$奇数です、出力$-1 -1$。 その理由は、どの中間点もこの距離のちょうど半分の位置になければならないためです。これは整数では不可能です。$d$奇数です。 
3. しましょう$half = d / 2$。 
4.セット$c_x = \min(x, half)$。 これは、利用可能な水平距離内にとどまることを優先します。$B$、パスの軸に沿った構造をオーバーシュートしないようにします。 
5.セット$c_y = half - c_x$。 これにより、残りの必要な距離が垂直方向に割り当てられます。 
6. 出力$(c_x, c_y)$。 

明らかではない部分ですが、この貪欲な割り当てがなぜ有効なのかがわかります。 マンハッタン メトリックでは、軸に沿った独立した移動が許可されるため、合計距離を水平成分と垂直成分に分解すると、有効なパスに対応します。 この構造により、合計距離の両方の半分のバランスが保たれます。 

### なぜ効果があるのか

 重要な不変条件は、各ステップで、原点からの L1 距離がちょうど 1/2 である点を構築していることです。$x + y$までの残り距離を確保しながら、$B$同じ値と一致します。 マンハッタン距離は軸間で加算されるため、$c_x$水平移動の単位と$c_y$垂直移動の単位は、相互作用項なしで両方の距離を完全に決定します。 最小ベースの分割は、非負性を侵害したり、座標を超えたりすることなく、実現可能性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x, y = map(int, input().split())
        d = x + y

        if d % 2:
            print(-1, -1)
            continue

        half = d // 2
        cx = min(x, half)
        cy = half - cx

        print(cx, cy)

if __name__ == "__main__":
    solve()
```このソリューションは、検索を完全に回避することを中心に構築されています。 パリティ チェックは、存在を無効にできる唯一の条件です。 それが過ぎると、次を使用して分割されます。`min(x, half)`負の座標を決して割り当てず、必要な合計距離を超えないことを保証します。 

実装の微妙な詳細は、コンピューティング`cy`残りは一貫性を保証するためです。 もし`cx`すでにすべてを消費しています`half`、 それから`cy`ゼロになる。 それ以外の場合は、ギャップを正確に埋めます。 これにより、条件分岐が回避され、構築が安定します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import isclose

    input = sys.stdin.readline
    t = int(input())
    out = []
    for _ in range(t):
        x, y = map(int, input().split())
        d = x + y
        if d % 2:
            out.append("-1 -1")
        else:
            half = d // 2
            cx = min(x, half)
            cy = half - cx
            out.append(f"{cx} {cy}")
    return "\n".join(out)

 ## 特殊なケース

 いつ$x + y = 0$、アルゴリズムはすぐに戻ります$(0, 0)$両方の距離がゼロであり、中点条件が正しく縮退しているためです。 この構造ではパリティ チェックを超えた除算は試行されないため、特別な処理は必要ありません。 

たとえば、1 つの座標がゼロの場合$(42, 0)$、アルゴリズムセット$half = 21$、次に割り当てます$cx = 21$、$cy = 0$、両方の距離制約を正確に維持します。 これにより、すべての距離が 1 つの軸から得られる必要があることを考慮せずに、座標を独立して分割しようとするよくある間違いを回避できます。 

いつ$x + y$奇数です、例えば$(13, 37)$、関数はすぐに拒否します。 中間点を構築しようとすると、分数のマンハッタン距離が必要になりますが、整数グリッドでは不可能であるため、出力は$-1 -1$強制されます。 

この構築では、ユークリッド対称性を決して仮定せず、マンハッタン距離の加法分解のみを仮定するため、これらのケースを一貫して処理します。
