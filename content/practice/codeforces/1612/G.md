 ## 解決策
 ## 問題の理解

 ラベルのマルチセットが与えられます。ここで、label`i`正確に表示されます`c_i`回。 これらすべての出現を単一の配列に配置する必要があります。 配列が固定されたら、同一の値のすべてのペアを調べ、それらの位置間の距離を加算します。 課題は、この合計距離を最大化する配置を見つけ、その最大値に達する異なるアレイの数を数えることです。 

最大化している式は、等しい要素の相対位置にのみ依存します。 同じ値の 2 つの出現が遠く離れている場合、それらの寄与は大きくなります。 それらが一緒にクラスター化されている場合、その寄与は小さくなります。 したがって、問題の構造は、グローバルなパッキング制約の下で、配列全体に同一の項目を可能な限り効果的に分散させることです。 

配列の全長は、すべての値の合計です。`c_i`、最大約100万になる可能性があります。 これにより、ポジションに関する二次推論は即座に排除されます。 どのソリューションも、ほぼ直線的またはほぼ直線的な時間で動作する必要があります。`O(n log n)`仕分けのせいで。 

単純な考えとしては、マルチセットのすべての順列を試してスコアを計算することですが、順列の数が階乗的に増加するため、中程度のサイズであってもこれは実行不可能です。 

各値を独立して処理し、その出現を連続的に配置しようとすると、より微妙な失敗のケースが発生します。 たとえば、値のコピーをすべて隣り合って配置すると、たとえ値を拡散する完全な自由があったとしても、その影響は最小限になります。 これは、ローカル グループ化が大きな周波数に対して最適ではないことを示しています。 

主な問題は、1 つの値の選択が他のすべての値で利用可能な「スペース構造」に影響を与えるため、ソリューションでは独立した配置ではなく、グローバルな順序付けの原則を決定する必要があることです。 

## アプローチ

 ブルートフォースアプローチでは、マルチセットのすべての順列を列挙し、各配置のスコアを計算します。 1 つの順列のスコアの計算は配列サイズに線形であるため、合計の複雑さは次のようになります。`O(n! · n)`、これは実現可能な限界をはるかに超えています。 

単一の値が目的にどのように寄与するかを推論する方法が必要です。 値が位置に現れるとします。`p1 < p2 < ... < pk`。 その寄与は、他の値とは無関係に、これらの位置の関数としてのみ書き換えることができます。 重要な観察は、固定された一連のポジションの場合、それらのポジションが可能な限り分散しているときに寄与が大きくなるということです。 

これにより、問題はグローバル割り当て問題に変わります。ポジションを割り当てなければなりません。`1..n`さまざまなサイズのグループに`c_i`、各グループの貢献は、選択した位置が利用可能なスペース内に最大限に広がるときに最大化されます。 

構造上の洞察は、最も「価値のある」位置は配列の両端であるということです。 常に外側の位置を最初に割り当てると、早い段階で大きなギャップが作成され、後の配置がまだ分散したままになるのに役立ちます。 これは、値を降順で処理するという貪欲な戦略につながります。`c_i`、各値について、その出現箇所を左端と右端の残りの位置に交互に割り当てます。 

この貪欲なプロセスによって配置が固定されると、各グループに割り当てられた位置から最大値を直接計算できます。 

カウントする場合は、同じ周波数を持つ値が構造内で対称的に動作することを観察してください。 2 つのラベルを同じものと交換する`c_i`構造やスコアは変わりませんが、異なる周波数のラベルを交換すると、ラベルが受け取る「拡散パワー」の量が変化し、一般に最適性が損なわれます。 これにより、周波数クラスごとの階乗係数が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! · n) | O(n) | 遅すぎる |
 | 最適な貪欲 + カウント | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 次に、最適な配置を構築し、最大スコアと最適な配列の数の両方を計算します。 

1. 値のインデックスを降順に並べ替えます`c_i`。 その理由は、大規模なグループは位置の広がりの影響を最も受けやすいため、グローバル構造がまだ最も柔軟なときに最初に割り当てる必要があるためです。 
2. 2 つのポインターを維持する`L = 1`そして`R = n`、残りの未使用のポジションを表します。 
3. ソートされた順序で各値について、左端から 1 つの位置、次に右端から 1 つの位置を繰り返し、すべての出現が配置されるまで交互に配置します。 これにより、連続して選択された位置間の分離が最大化されるため、グループ内のペアごとの距離が最大化されます。 
4. この値に割り当てられた正確な位置を昇順に並べ替えて記録します。 
5. ID を使用してその寄与を計算する$$\sum_{1 \le i < j \le k} (p_j - p_i)$$これは、ソートされた位置に対する線形式として評価できます。 
6. この投稿をグローバル回答に追加します。 
7. カウントするには、頻度ごとに値をグループ化します。`c_i`。 特定の周波数値が発生した場合`x`インデックス間での倍数、答えに次の値を掛けます。`x!`。 これは、同一の頻度でラベルを交換しても構造や結果のスコアが変わらないことを反映しています。 

### なぜ効果があるのか

 すべてのステップで、貪欲な構造により、残りの空きセグメントが可能な限りコンパクトになる一方で、すでに配置されている要素は極端な位置を占めます。 内側の位置では失われた外側の距離を決して補うことができないため、極端な位置を使用して遅延が発生すると、少なくとも 1 つのグループの達成可能なスパンが減少します。 これにより、各グループが処理された時点で利用可能な最も分離された構成を受け取る単調な構造が作成されます。 ラベルの周波数ベースの対称性により、同一ラベル内の順列全体で最適性が維持されます。`c_i`一方、クラス間の交換は、ポジション範囲全体のグループサイズの分布を変更し、厳密に貢献を削減または変更することになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def main():
    m = int(input())
    c = list(map(int, input().split()))
    
    n = sum(c)
    
    # group indices by decreasing c
    idx = list(range(m))
    idx.sort(key=lambda i: -c[i])
    
    L, R = 1, n
    
    # store positions for each value
    pos = [[] for _ in range(m)]
    
    # build arrangement implicitly via position assignment
    for i in idx:
        k = c[i]
        tmp = []
        
        for j in range(k):
            if j % 2 == 0:
                tmp.append(L)
                L += 1
            else:
                tmp.append(R)
                R -= 1
        
        tmp.sort()
        pos[i] = tmp
    
    # compute f(a)
    ans = 0
    
    for i in range(m):
        p = pos[i]
        k = len(p)
        for t, val in enumerate(p):
            # contribution formula component
            ans += val * (2 * t - k + 1)
    
    # counting optimal arrays: factorial over equal c_i groups
    freq = {}
    for x in c:
        freq[x] = freq.get(x, 0) + 1
    
    ways = 1
    for v in freq.values():
        ways = ways * math_factorial(v, MOD) % MOD
    
    print(ans, ways)

def math_factorial(n, mod):
    res = 1
    for i in range(2, n + 1):
        res = res * i % mod
    return res

if __name__ == "__main__":
    main()
```コードはまず、現在の間隔の両端から位置を繰り返し割り当てることによって、最適な配置を構築します。 これにより、貪欲な処理順序を考慮して、各グループ内の最大限の分離が保証されます。 

寄与の計算では、ソートされた位置に対して直接線形公式を使用し、ペアの列挙を回避します。 各位置は、同じグループ内でその前後にある要素の数に応じて、プラスまたはマイナスに寄与します。 

最後に、カウント ステップでは、同じ頻度を共有するラベルの数を集計し、これらのカウントの階乗を乗算します。 

微妙な点は、割り当てプロセスがラベルの識別には依存せず、その頻度のみに依存することです。 これにより、カウント部分のきれいな階乗分解が可能になります。

import sys, io

MOD = 10**9 + 7

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math

    def solve():
        m = int(input())
        c = list(map(int, input().split()))
        n = sum(c)

        idx = list(range(m))
        idx.sort(key=lambda i: -c[i])

        L, R = 1, n
        pos = [[] for _ in range(m)]

        for i in idx:
            k = c[i]
            tmp = []
            for j in range(k):
                if j % 2 == 0:
                    tmp.append(L)
                    L += 1
                else:
                    tmp.append(R)
                    R -= 1
            tmp.sort()
            pos[i] = tmp

        ans = 0
        for i in range(m):
            p = pos[i]
            k = len(p)
            for t, v in enumerate(p):
                ans += v * (2*t - k + 1)

        from collections import Counter
        freq = Counter(c)
        ways = 1
        for v in freq.values():
            ways = ways * math.factorial(v) % MOD

        print(ans, ways)

    solve()
    return ""

 ## 特殊なケース

 いつすべて`c_i = 1`、すべての順列は同じスコアを生成します`0`、カウントが正しく返される必要があります`n!`。 周波数グループ化は単一のサイズ クラスに分割されるため、アルゴリズムはこれを処理します。`n`。 

値が 1 つしか存在しない場合、配置に自由はありません。 貪欲な割り当てでも有効な完全な間隔の割り当てが生成され、スコア計算は位置の固定セットにわたって正しく集計されます。 

複数の値が同じ周波数を共有する場合、それらの ID を交換しても、割り当てられた位置セットは変更されません。 これはまさに、周波数ごとの階乗補正によって捕捉された状況であり、過大カウントまたは過少カウントがないことが保証されます。
