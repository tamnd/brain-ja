 ## 問題の理解

 ユーザーがエモートの数が増減するメッセージで構成される「エモート トライアングル」を送信したいというチャット シナリオをシミュレートするように求められました。 指定されたサイズの場合$k$、最初のメッセージには 1 つのエモートが含まれ、2 番目には 2 つのエモートが含まれます。$k$- 番目のメッセージ$k$エモートを追加すると、次のメッセージが 1 つに戻ります。 これにより、次のシーケンスが形成されます。$2k-1$メッセージ内のエモートの数$i$は$\min(i, 2k-i)$。 

チャット プラットフォームには、送信されたエモートの総数が所定のしきい値に達するかそれを超えるとユーザーを禁止するモデレーション システムがあります。$x$。 タスクは、ユーザーが禁止される前に送信できるメッセージの数を決定することです。 ユーザーが超過せずに三角形を完成した場合$x$、答えは$2k-1$。 

制約は大きいです:$k$まで可能です$10^9$そして$x$まで$10^{18}$。 メッセージごとにエモートを合計する単純なシミュレーションでは、最大で$2 \cdot 10^9$テストケースごとの追加。 これにより、テスト ケースごとに対数時間または定数時間で機能するソリューションが強制されます。 

明らかではないエッジケースには、小規模なものが含まれます$k$そしてとても小さい$x$、 例えば$k=1, x=1$。 三角形にはメッセージが 1 つしかないため、ユーザーはすぐに禁止される可能性があります。 もう 1 つのエッジケースは次のような場合です$x$三角形全体の合計よりも大きくなります。 のために$k=4$そして$x=20$、三角形の合計は 16 です。この場合、ユーザーは禁止されることなくすべてのメッセージを終了します。 

## アプローチ

 ブルート フォースのアプローチは簡単です。一連のメッセージを生成し、現在の合計を保持し、合計がその値に達するかそれを超えるまでメッセージをカウントします。$x$。 これは小規模な場合に機能します$k$しかし、次の場合に失敗します$k$数十億のメッセージを合計するのは遅すぎるため、このサイズは大きくなります。 最悪の場合の操作数は次のとおりです。$O(k)$テストケースごとに、これは受け入れられません$k$まで$10^9$そして$t$まで$10^4$。 

重要な観察は、三角形の各半分にあるエモートの数が単純な等差級数を形成しているということです。 前半は1から$k$そして合計すると$k(k+1)/2$。 後半は～から減少します$k-1$を 1 にすると、合計が$(k-1)k/2$。 三角形の総和は、$k^2$。 これにより、次のことをすぐに判断できます。$x$三角和を超える場合、ユーザーはすべてを書き込みます$2k-1$メッセージ。 

もし$x$よりも小さいです$k(k+1)/2$、増加部分でユーザーが禁止されます。 最初の合計の公式を使用できます。$m$自然数と二次不等式を解く$m(m+1)/2 \ge x$最小のものを見つける$m$。 もし$x$を超える$k(k+1)/2$しかし、未満です$k^2$、禁止は減少部分で発生します。 問題を変えることができます。前半の合計をから引きます。$x$残りのエモートを計算し、同様の式を降順シーケンスに適用します。 メッセージ数に対する二分検索の使用は、両方の部分で効率的に機能します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k) | お(1) | k が大きいと遅すぎる |
 | 最適 (三角形の半分の二分探索) | O(log k) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テストケースについて、前半の合計エモートを計算します$S_1 = k(k+1)/2$。 比較する$x$に$S_1$。 
2. もし$x \le S_1$、増加部分で禁止が発生します。 1 ～ の範囲で二分検索を使用します。$k$メッセージの最小数を見つけるには$m$そのような$m(m+1)/2 \ge x$。 戻る$m$。 
3. もし$x > S_1$そして$x \le k^2$、減少部分で禁止が発生します。 残りのエモートを計算する$x' = x - S_1$。 減少する部分は次のようになります。$k-1$エモート付きメッセージ$k-1, k-2, ..., 1$。 Use binary search on$1..k-1$メッセージの最小数を見つけるには$m$そのような$(k-1 + k-2 + ... + (k-m)) \ge x'$。 同様に、最後の合計$m$からの数字$k-1$下: 合計 =$m(2k-m-1)/2$。 戻る$k + m$。 
4. もし$x > k^2$、ユーザーは禁止されることなくすべてのメッセージを完了します。 戻る$2k-1$。 

機能する理由: 三角形は厳密に増加し、その後厳密に減少します。 等差級数の公式を使用すると、累積合計が到達する正確な点を見つけることが保証されます。$x$各メッセージを繰り返す必要はありません。 二分探索により、最小数のメッセージが正しく計算されることが保証されます。 不変条件は、正確な累積和限界と等差数列和です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def messages_before_ban(k, x):
    total = k * k
    if x >= total:
        return 2 * k - 1
    first_half = k * (k + 1) // 2
    if x <= first_half:
        # binary search in increasing part
        l, r = 1, k
        while l < r:
            m = (l + r) // 2
            if m * (m + 1) // 2 >= x:
                r = m
            else:
                l = m + 1
        return l
    else:
        # banned in decreasing part
        x_rem = x - first_half
        l, r = 1, k - 1
        while l < r:
            m = (l + r) // 2
            if m * (2 * k - m - 1) // 2 >= x_rem:
                r = m
            else:
                l = m + 1
        return k + l

t = int(input())
for _ in range(t):
    k, x = map(int, input().split())
    print(messages_before_ban(k, x))
```このソリューションでは、まずユーザーが禁止しきい値を超えずにトライアングルを完了したかどうかをチェックします。 算術合計の公式を使用して、増加部分と減少部分を個別に処理します。 二分探索を使用して、しきい値を超える最小メッセージ数を効率的に見つけ、慎重なループ不変条件によるオフバイワンの間違いを回避します。
