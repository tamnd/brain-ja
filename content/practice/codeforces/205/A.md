 ## 解決策
 ## 問題の理解

 ロズディルの町から他の _n_ つの町までの移動時間のリストが与えられました。 各町には正の整数の時間があり、町には 1 から _n_ までの番号が付けられます。 目的は、移動時間が最も短い町を見つけることです。 この最小時間を持つユニークな町がある場合は、その番号を出力します。 複数の町が最小値で結ばれている場合、小さな象はロズディルに留まり、「まだロズディル」と印刷されます。 

この制約により、最大 100,000 の町が許可され、移動時間は 10^9 に達する可能性があります。 これは、どのソリューションも線形時間で動作する必要があることを示しています。 時間の配列のソートは O(n log n) で機能しますが、線形スキャンの方が簡単で十分です。 二次複雑さの演算は非常に遅くなります。 

複数の町が同じ最小移動時間を共有する場合、微妙な特殊なケースが発生します。 たとえば、入力が次の場合`5\n4 2 2 5 6`、最小時間は 2 ですが、2 つの町 (2 と 3) で発生します。 不用意に実装すると、最初に見つかった最小値を返すだけになる可能性がありますが、これは誤りです。 別の特殊なケースは、町が 1 つしかない場合に発生します。この場合、一意性が保証されているため、答えはその町でなければなりません。 

## アプローチ

 ブルートフォース手法はすべての町を反復して、最小時間とそれに対応する町のインデックスを追跡します。 これが機能するのは、問題の要件を直接実装しているためです。つまり、最小値を特定し、同点かどうかをチェックします。 演算に関して言えば、各比較は定数時間であるため、全体の時間は O(n) です。 メモリ使用量は入力を超えて O(1) です。 このアプローチはすでに最適ですが、タイ検出には注意する必要があります。一意性をチェックする必要がある場合、最小のインデックスを 1 つ保存するだけでは不十分です。 

重要な洞察は、配列のスキャン中に 3 つの情報を維持できるということです。つまり、現在の最小移動時間、最初にその時間を達成した町のインデックス、およびこの最小値が何回発生したかを示すカウンターです。 これより短い時間に遭遇するたびに、最小値を更新し、インデックスを現在の町に設定し、カウンタを 1 にリセットします。同じ最小値に遭遇した場合は、カウンタをインクリメントします。 最後に、カウンターが 1 より大きい場合は、「Still Rozdil」を出力します。 それ以外の場合は、保存されているインデックスを出力します。 このアプローチは線形であり、一定の追加スペースを使用し、重複や単一要素の配列を含むすべてのエッジ ケースを正しく処理します。

 ## アルゴリズムのチュートリアル

 1. 3 つの変数を初期化します。`min_time`非常に多くの数に、`min_index`-1に、そして`count`0にします。`min_time`これまでに見つかった最小の移動時間を保存します。`min_index`最初にこの最小値を達成した町の 1 から始まるインデックスを格納します。`count`この最小値が何回発生したかを保存します。 
2. インデックス付きのループを使用して、移動時間を反復処理します。`i`0からn-1まで。 各町の所要時間を読み取ってください。 
3. 現在の移動時間が以下の場合`min_time`、これは新しい最小値です。 セット`min_time`この値に、`min_index`に`i + 1`(0 ベースのインデックス付けから 1 ベースのインデックス付けに変換するため)、リセット`count`1に。 
4. 現在の移動時間が等しい場合`min_time`、増分`count`同じ最小値を持つ別の町が見つかったため、1 倍になります。 
5. すべての町をスキャンした後、次の値を確認します。`count`。 もし`count`は 1、印刷します`min_index`。 もし`count`1 より大きい場合は、「Still Rozdil」と出力します。 

機能する理由: このアルゴリズムは、最小移動時間を常に追跡し、それを達成した町の数をカウントします。 厳密に短い時間が見つかった場合にのみ更新することで、`min_index`常に最小値を持つ最初の町を指します。 重複をカウントすることで、一意の最小値が実際に存在する場合にのみ宣言することが保証されます。 すべてを 1 回繰り返すため、見逃される町はありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
times = list(map(int, input().split()))

min_time = 10**9 + 1
min_index = -1
count = 0

for i in range(n):
    t = times[i]
    if t < min_time:
        min_time = t
        min_index = i + 1
        count = 1
    elif t == min_time:
        count += 1

if count == 1:
    print(min_index)
else:
    print("Still Rozdil")
```最初のセクションでは、高速 I/O を使用して入力を読み取ります。`min_time`最初の町が正しく更新できるように、可能な移動時間よりも大きな値に初期化されます。 ループ中、現在の最小値のインデックスとカウントを維持します。 この問題では 1 から始まるインデックス付けが想定されているため、インデックスに 1 を追加します。 最後に、同点を処理するためにカウントを確認します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    times = list(map(int, input().split()))
    min_time = 10**9 + 1
    min_index = -1
    count = 0
    for i in range(n):
        t = times[i]
        if t < min_time:
            min_time = t
            min_index = i + 1
            count = 1
        elif t == min_time:
            count += 1
    return str(min_index) if count == 1 else "Still Rozdil"

# Provided samples
assert run("2\n7 4\n") == "2", "sample 1"
assert run("5\n7 4 2 2 5\n") == "Still Rozdil", "sample 2"

# Custom cases
assert run("1\n10\n") == "1", "single town"
assert run("3\n5 5 5\n") == "Still Rozdil", "all equal values"
assert run("4\n3 2 4 2\n") == "Still Rozdil", "multiple minimums"
assert run("4\n7 1 3 4\n") == "2", "unique minimum in the middle"
assert run("5\n10 9 8 7 6\n") == "5", "minimum at the end"

 ## 特殊なケース

 アルゴリズムは初期化することで単一の町の入力を処理します。`min_time`最初の町で高く、正しく更新されています。 重複する最小値は増分することで処理されます。`count`最小値が発生するたびに、同点になると「Still Rozdil」が確実にトリガーされます。 このアルゴリズムは、最後のインデックスに現れる最小値も正確に識別し、最初に見つかった不変式と適切なインデックス付けを維持します。
