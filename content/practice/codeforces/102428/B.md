 ## 解決策
 ## 問題の理解

 平面内の点で表される一連の野菜植物があります。 目的の家は中心が原点に固定された正方形ですが、その方向は完全に自由です。 植物は広場の境界上にあるかもしれませんが、厳密にその内側にあることはできません。 

半辺の長さが(a)の正方形の場合、実際の辺の長さは(2a)なので、周囲長は(8a)となります。 したがって、タスクは、可能な最大の半辺 (a) を見つけて、それに (8) を乗算することです。 

入力には最大で (10^4) 個の点が含まれますが、各座標は最大 (10^9) までの絶対値を持つことができます。 アーカイブされた Codeforces ステートメントには 6 秒の時間制限があるため、目的のソリューションでは (O(N^2)) または (O(N^3)) の幾何学的検索を回避する必要があります。 座標境界が大きいということは、二乗距離を含む計算では可能な限り整数演算を使用する必要がある一方、最終的な角度計算では必ず浮動小数点を使用する必要があることも意味します。 

最初の自明ではないケースは、植物がまさに境界線上にある場合です。 例えば、```
1
0 1
```答えがあります`8.0000`。 原点を中心とした半辺 (1) の正方形では、一方の辺に植物を置くことができます。 境界点を禁止されたものとして扱うと、この正方形が誤って拒否され、(8) より小さい答えが生成されます。 

2 番目のエッジケースは、起源に非常に近い植物です。 のために```
1
1 0
```答えはまたです`8.0000`。 正方形を回転させて、植物を正確に一面に置くことができます。 点が半分の辺以下の距離にあるかどうかをチェックする不注意な実装では、この境界位置が誤って無効であると見なされます。 

3 番目の問題はローテーションにあります。 のために```
2
1 0
0 1
```答えは`8.0000`。 両方の植物は、軸に沿った半辺の正方形の境界上に同時に横たわることができます (1)。 辺が任意の固定方向にある正方形のみをテストすると、方向自体が最適化の一部であるという事実が見落とされてしまいます。 

最後の微妙な点は、向きが周期的であることです。 正方形を (90^\circ) 回転させるとまったく同じ正方形が得られるため、考慮する必要があるのは長さ (\pi/2) の間隔だけです。 

## アプローチ

 直接的な幾何学的検索では、方向を修正し、すべての植物を検査し、その方向と互換性のある最大の半辺を決定します。 問題は、方向性が無限に存在することです。 2 つの制約が相互作用するすべての臨界方向を生成してからそれらをテストすることもできますが、そのような候補は (O(N^2)) 個あり、すべての (N) 個のプラントに対して各候補をテストすると (O(N^3)) 個の作業が必要になります。 (N=10^4) の場合、制限時間の許容範囲をはるかに超えて、約 (10^{12}) 点のチェックに達する可能性があります。 

有益な観察は、方向と正方形のサイズを同時に最適化する必要がないということです。 代わりに、候補の半分の辺 (a) を修正し、「はい」か「いいえ」で答える質問をします。厳密に正方形の中に植物が存在しない回転はありますか? この物件はモノトーンです。 半辺(a)の正方形を配置できれば、それより小さな正方形もすべて同じ向きで配置できます。 その結果、二分探索が可能になります (a)。 この二分探索の削減は、問題の独立した解決策によって説明されているアプローチでもあります。 

残る問題は 1 つの候補 (a) をチェックすることです。 

1 つの植物 (P=(x,y)) を取り上げ、その極座標を ((r,\phi)) とします。 (\theta) が正方形の外向き法線の 1 つの方向を示すものとします。 正方形によって決定される座標系では、植物は投影されます。 

[
 r\cos(\ファイ-\シータ)
 ]

 そして

 [
 r\sin(\phi-\theta)。 
]

 両方の絶対投影が (a) より小さい場合、植物は厳密に正方形の内側にあります。 

[
 |r\cos(\phi-\theta)|<a
 ]

 そして

 [
 |r\sin(\phi-\theta)|<a.
 ]

 (r<a) の場合、植物は考えられるすべての正方形の方向の内側にあるため、候補は直ちに不可能になります。 (r\geq\sqrt2a) の場合、2 つの射影のうち少なくとも 1 つは常に (a) 以上であるため、植物は決して正方形に入らず、制限を課しません。 

興味深いケースは、

 [
 a\leq r<\sqrt2a.
 ]

 (q=a/r) と置きます。 (1/\sqrt2<q\leq1) であるため、両方の不等式を満たす角度は 1 つの開区間モジュロ (90^\circ) を形成します。 その中心は (\phi-\pi/4)、半角は

 [
 h=\arcsin(q)-\frac{\pi}{4}。 
]

 したがって、すべての植物は、方向の 1 つの禁止された開いた間隔を与えます。 これらすべての禁止された間隔の和集合が、長さ (\pi/2) の方向の円全体をカバーするかどうかを判断するだけで済みます。 

このチェックは、間隔のエンドポイントを並べ替えた後の標準的なスイープです。 リファレンス ソリューションの説明では、角度間隔とスイープを使用して、考えられるすべての回転がブロックされているかどうかを判断します。 

ここには小さな数値の詳細があります。 ちょうど正方形の辺にある植物が許可されているため、禁止された間隔は開いています。 二分探索中に、実現可能性テストで閉区間を安全に使用できます。 唯一の有効な方向が端点で正確に発生する場合、閉区間検定は正確な最適値を拒否する可能性がありますが、その最適値よりも無限に小さい値はすべて受け入れられます。 したがって、二分探索は同じ上限に近づきますが、これは小数点以下 4 桁で十分です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(N^3)) | (O(N)) | 遅すぎる |
 | 最適 | (O(KN\log N)) | (O(N)) | 承認済み |

 ここで (K) は二分探索反復の固定回数で、実装では 70 として選択されます。 

## アルゴリズムのチュートリアル

1. すべての植物を読み取り、原点からの距離を計算します。 最初は二乗距離を整数として保持します。これにより、植物が確実に内部にあるか、確実に無関係であるかを判断する際の不要な浮動小数点エラーが回避されます。 
2. (0) と原点から任意の植物までの最小距離との間の半辺 (a) を二分探索します。 正方形には半径 (a) の円盤全体が含まれるため、より大きな半辺は不可能であり、距離が (a) よりも小さい植物は必然的に内側になります。 
3. 候補 (a) については、すべての植物を検査します。 (r<a) の場合、回転によってそのプラントを保存できないため、直ちに false を返します。 
4. (a\leq r/\sqrt2) の場合、プラントを無視します。 2 つの垂直投影のうち少なくとも 1 つは少なくとも (r/\sqrt2) の大きさを持ち、これは少なくとも (a) であるため、植物が厳密に内部に存在することはありません。 
5. 残りのすべての植物について、その極角 (\phi=\operatorname{atan2}(y,x)) を計算します。 正方形は (\pi/2) ごとに繰り返されるため、禁止区間の中心 (\phi-\pi/4) を ([0,\pi/2)) に正規化します。 
6. コンピューティング

 [
 h=\arcsin(a/r)-\pi/4。 
]

 禁止された方向は、中心から (h) 以内の角度、モジュロ (\pi/2) です。 

1. 区間が ([0,\pi/2)) のどちらかの端と交差する場合、それを 2 つの区間に分割します。 これにより、循環区間問題が通常の区間和集合問題に変換されます。 
2. すべての間隔エンドポイントを並べ替え、間隔を結合します。 それらの和集合が完全な範囲 ([0,\pi/2]) をカバーする場合、どの方向でも少なくとも 1 つの植物が厳密に正方形の内側に配置されるため、候補 (a) は不可能です。 それ以外の場合は、すべての禁止区間の外側に方向性が存在するため、(a) が実行可能です。 
3. 二分探索を 70 回繰り返し実行します。 座標が (10^9) ほど大きい場合でも、間隔は 4 桁の 10 進数に必要な精度よりも大幅に小さくなります。 
4. (8a) は正方形の周囲長であるため、(8a) を小数点以下 4 桁で出力します。 

### なぜ効果があるのか

 固定された半辺 (a) の場合、各プラントは、正方形の法線方向への両方の垂直射影の大きさが (a) より小さい方向を正確に禁止します。 これらの禁止された方向は、植物が常に内側にある、または決して内側にないという 2 つの自明なケースを除いて、1 つの開区間モジュロ (\pi/2) を形成します。 

したがって、実現可能な方向は、すべての禁止区間の和集合が方向円全体をカバーしないときに正確に存在します。 スイープはその状態を正確にチェックします。 (a) では、正方形を拡大しても無効な配置を有効な配置に変えることができないため、実現可能性述語は単調です。 したがって、二分探索は実現可能な最大の半辺に収束し、それに (8) を掛けると最大周長が得られます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

PI = math.pi
PERIOD = PI / 2.0
EPS = 1e-12

def solve():
    n = int(input())
    points = []

    min_r2 = None

    for _ in range(n):
        x, y = map(int, input().split())
        r2 = x * x + y * y
        points.append((x, y, r2))
        if min_r2 is None or r2 < min_r2:
            min_r2 = r2

    min_r = math.sqrt(min_r2)

    def feasible(a):
        intervals = []

        for x, y, r2 in points:
            r = math.sqrt(r2)

            if r < a:
                return False

            # If r / sqrt(2) >= a, the point is never strictly inside.
            if r * r >= 2.0 * a * a:
                continue

            phi = math.atan2(y, x)

            # The forbidden interval is centered at phi - pi/4
            # modulo pi/2.
            center = (phi - PI / 4.0) % PERIOD

            q = a / r
            if q > 1.0:
                q = 1.0

            half = math.asin(q) - PI / 4.0

            left = center - half
            right = center + half

            if left < 0.0:
                intervals.append((0.0, right))
                intervals.append((left + PERIOD, PERIOD))
            elif right >= PERIOD:
                intervals.append((left, PERIOD))
                intervals.append((0.0, right - PERIOD))
            else:
                intervals.append((left, right))

        if not intervals:
            return True

        intervals.sort()

        covered = 0.0

        for left, right in intervals:
            if left > covered + EPS:
                return True

            if right > covered:
                covered = right

            if covered >= PERIOD - EPS:
                return False

        return True

    lo = 0.0
    hi = min_r

    for _ in range(70):
        mid = (lo + hi) / 2.0
        if feasible(mid):
            lo = mid
        else:
            hi = mid

    print(f"{8.0 * lo:.4f}")

if __name__ == "__main__":
    solve()
```入力ループは、各点を (x^2+y^2) とともに保存します。 Python の整数には任意の精度があるため、座標の最大二乗和も正確に表現されます。 

の`feasible`関数は 3 つの幾何学的ケースを直接実装します。 比較`r * r >= 2 * a * a`(r/\sqrt2) の計算を回避し、追加の平方根を導入せずに両側を比較できるため、推奨されます。 

自明ではないケースの場合、`atan2`全範囲 ((-\pi,\pi]) のプラント方向を示します。減算 (\pi/4) により、禁制区間がプラント方向から正方形の対角線の方向に移動し、モジュロ (\pi/2) を取得すると、正方形の (90^\circ) 回転対称性が削除されます。

 表現`asin(a / r) - pi / 4`処理中のケースでは正確に負ではありません。 クランピング`q`(1) は、(a) が (r) に非常に近い場合の小さな浮動小数点オーバーシュートを防ぎます。 

円形の間隔はゼロと交差する可能性があるため、コードは円形の間隔を 2 つの通常の間隔に分割します。 並べ替えた後、`covered`ゼロから連続してカバーされる右端の点を格納します。 次の間隔が厳密に後に始まる場合`covered`、方向性が明らかにされておらず、候補者は実現可能です。 小さいもの`EPS`エンドポイントに接触する際の数値ノイズによって決定が変更されるのを防ぎます。 

二分探索では、イプシロンベースの終了条件に依存するのではなく、70 回の反復が使用されます。 これにより、決定的な精度の制限が与えられ、off-by-one スタイルの終了の問題が回避されます。 70 回の半分では、(10^{-4}) 出力要件を何桁も下回る誤差が残ります。 

## 実用的な例

 ### サンプル 1

これはまさに二分探索が設計されている状況です。実行可能性は最適な半辺で true から false に変化し、区間和集合チェックがその遷移を検出します。

import sys
import io
import math

PI = math.pi
PERIOD = PI / 2.0
EPS = 1e-12

def main():
    input = sys.stdin.readline

    n = int(input())
    points = []
    min_r2 = None

    for _ in range(n):
        x, y = map(int, input().split())
        r2 = x * x + y * y
        points.append((x, y, r2))
        if min_r2 is None or r2 < min_r2:
            min_r2 = r2

    min_r = math.sqrt(min_r2)

    def feasible(a):
        intervals = []

        for x, y, r2 in points:
            r = math.sqrt(r2)

            if r < a:
                return False

            if r * r >= 2.0 * a * a:
                continue

            phi = math.atan2(y, x)
            center = (phi - PI / 4.0) % PERIOD

            q = min(1.0, a / r)
            half = math.asin(q) - PI / 4.0

            left = center - half
            right = center + half

            if left < 0.0:
                intervals.append((0.0, right))
                intervals.append((left + PERIOD, PERIOD))
            elif right >= PERIOD:
                intervals.append((left, PERIOD))
                intervals.append((0.0, right - PERIOD))
            else:
                intervals.append((left, right))

        if not intervals:
            return True

        intervals.sort()

        covered = 0.0

        for left, right in intervals:
            if left > covered + EPS:
                return True

            if right > covered:
                covered = right

            if covered >= PERIOD - EPS:
                return False

        return True

    lo = 0.0
    hi = min_r

    for _ in range(70):
        mid = (lo + hi) / 2.0
        if feasible(mid):
            lo = mid
        else:
            hi = mid

    print(f"{8.0 * lo:.4f}")

    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        main()
        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

 ## 特殊なケース

 最終的な境界上にある点の場合、禁止された方位間隔が開きます。 考慮する```
1
0 1
```半分の辺 (a=1) では、点は距離 (r=1) を持ちます。 安全な方向は、点が正方形の辺上にある方向のみであり、植物は境界上で許可されているため、これらの方向は禁止されているとは見なされません。 二分探索は、安全な方向の空ではないセットが存在する下から (a=1) に近づき、正しい周囲長を生成します。`8.0000`。 

原点の対角方向の点については、次のように考えます。```
1
1 1
```植物には距離 (\sqrt2) があります。 法線の 1 つが ((1,1)) を向くように正方形を回転すると、植物は半辺 (\sqrt2) の側面に配置されます。 結果として得られる周囲長は、

 [
 8\sqrt2\約11.313708、
 ]

 したがって、出力は`11.3137`。 点は一般的な射影不等式によって処理されるため、実装では特別な角度のケースを使用せずにこれを処理します。 

対称点の場合、```
4
1 0
0 1
-1 0
0 -1
```すべての向きは同じ幾何学法 (90^\circ) によって拘束されます。 最良の選択は、4 つの植物すべてがその境界上にある、半分の辺を持つ軸に沿った正方形 (1) です。 区間スイープでは、(1) のすぐ上の候補に有効な向きがないことが認識されますが、(a=1) は二分探索で近づく限界値です。 印刷された周囲の長さは、`8.0000`。 

等半径のプラントの場合、12 点```
12
5 0
4 3
3 4
0 5
-3 4
-4 3
-5 0
-4 -3
-3 -4
0 -5
3 -4
4 -3
```すべての距離は正確に一致します (5)。 それらの方向は、法 (90^\circ) を削減した後、(\arctan(3/4)) の最大角度ギャップを残します。 最適な正方形は、そのギャップの中間に対角線方向を配置し、半辺を与えます。 

[
 5\cos\left(\frac{\arctan(3/4)}2\right)
 =\frac{3\sqrt{10}}2.
 ]

 外周はおよそ`18.9737`。 このケースでは、いくつかの禁止区間が重なり合い、最も近いプラントだけではなく、その正確な角度配置によって答えが決定されるアルゴリズムの部分を実行します。
