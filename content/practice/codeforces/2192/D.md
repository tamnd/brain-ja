 ## 解決策
 ## 問題の理解

 ノード 1 をルートとするツリーが与えられ、各ノードは正の整数の重みを持ちます。 選択したルートに対するツリーのコストは、ノードの重みとそのルートからの距離の積の全ノードにわたる合計です。 新しいサブツリー ルートとみなされるノードごとに、必要に応じて 1 つの操作 (サブツリー内の 1 つのノード (ルート自体ではない) を同じサブツリー内の新しい親に移動する) を実行した後に達成可能な最大コストを計算する必要があります。 

これは、各ノードについて、サブツリーをわずかに再配置することで、そのノードからサブツリー内のすべてのノードまでの距離の加重合計を最大化したいことを意味します。 入力は複数のテスト ケースを提供し、それぞれにツリーとノードの重みのリストが含まれます。 出力は、ツリー内の各ノードの最大コストのリスト (テスト ケースごとに 1 つのリスト) である必要があります。 

制約により、すべてのテスト ケースにわたるノードの合計数が最大 200,000 であることがわかります。 これにより、ブルートフォース手法には攻撃が含まれる可能性があるため、考えられるすべてのノードまたはすべての移動操作について最初から距離を再計算する単純なソリューションが不要になります。$O(n^2)$テストケースごとの操作と最大$10^9$全体的な計算。 エッジ ケースには、サブツリー内に自分自身のみが含まれるノード (移動が不可能な場合)、または複数の子と大きな重み差を持つノード (最適な移動がすぐには分からない可能性がある) が含まれます。 たとえば、ノード 3 のサブツリーに重み 1、2、および 10 のノードがある場合、アルゴリズムは、可能であれば深さを最大化するために最も重いノードを移動することを選択する必要があります。 不注意な実装では、距離との積を考慮せずに常に最も深いノードまたは最も重いノードが選択される可能性があり、次善のコストが発生します。 

## アプローチ

 ブルート フォース アプローチでは、各ノードをルートとして取得し、そのサブツリーの初期コストを計算し、次にそのサブツリー内のすべてのノードのサブツリー内の他の考えられるすべての親への有効な移動をすべて試行し、そのたびにサブツリー コストを再計算します。 これは論理的には正しいですが、次のようなサブツリーの場合です。$k$ノード、これには以下が関係する可能性があります$O(k^3)$ノードの移動ごとにすべての子孫までの距離を再計算する必要があるためです。 ツリー内のすべてのノードを合計すると、これは許可される操作を簡単に超えます。 

最適化するための重要な観察は、可能な最善の策は、常に最大の重みを持つノードを現在のサブツリー ルートから可能な限り遠くに持ってきて、その距離への寄与を増やすことであるということです。 サブツリーがルート化されると、$r$、ノードの達成可能な最大距離増加はサブツリーの高さによって制限されます。 したがって、最初に、標準の深さ優先検索を使用して、移動せずに各サブツリーの合計コストを計算できます。 次に、各サブツリーで最大の重みを持つノードを見つけて、それをルートから最も遠いリーフに仮想的に「接続」し、そのノードに可能な最大の深さを与えることができます。 これにより、問題がツリー DP に還元され、各ノードがその子孫の重みの合計とそのサブツリー内の最大重み付きノードが格納され、ツリーごとに線形時間で最適なコストを計算できるようになります。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力エッジからツリーを構築し、ノードの重みを読み取ります。 これにより、標準的な隣接リスト表現が得られます。 
2. 各ノードに対して、深さ優先検索を実行して 2 つの量を計算します。そのノードをルートとする場合のサブツリーの初期コストと、そのサブツリー内の重みの合計です。 ノードの場合$u$、サブツリーの初期コストは次のとおりです。$\sum_{v \in \text{subtree}(u)} a_v \cdot d(u,v)$。 これは、子からのコストとその重みの合計を合計することによって再帰的に行われます (各重みは親までの追加距離 1 に寄与するため)。 
3. DFS 中に、各サブツリー内の最大重みノードも追跡します。 各ノードについて$u$、最大重量を保管します$m_u$そのサブツリー内で見つかり、それを達成するノードの深さは相対的に$u$。 
4. をルートとするサブツリーについて、最大 1 回の移動後の最大コストを計算するには$u$、最大重みノードを最も遠いリーフに移動することを検討してください。$u$。 潜在的な利益は、$m_u \cdot (\text{height} - d_{\text{current}})$。 このゲインをサブツリーの初期コストに追加して、サブツリーの達成可能な最大コストを取得します。$u$。 
5. DFS が完了したら、ステップ 4 で計算された各ノードの最大コストを出力します。$n$各 DFS 呼び出しが各ノードを 1 回だけ処理すると、ツリーあたりの全体的な複雑さは次のようになります。$O(n)$。 

正確さを保証する不変条件は、他のノードまたは移動の組み合わせを移動すると、最も重いノードをそのサブツリーの最も深い位置に移動するよりも大きな利得が得られないということです。 これは、コストが重量と距離の積で線形であるため、最大重量に対する距離を最大化すると、1 回の許容移動のグローバル最大値が得られるためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        adj = [[] for _ in range(n)]
        for _ in range(n-1):
            u, v = map(int, input().split())
            adj[u-1].append(v-1)
            adj[v-1].append(u-1)
        
        # initialize arrays
        subtree_sum = [0]*n
        initial_cost = [0]*n
        max_weight = [0]*n
        max_depth = [0]*n

        def dfs(u, parent):
            subtree_sum[u] = a[u]
            max_weight[u] = a[u]
            max_depth[u] = 0
            total = 0
            for v in adj[u]:
                if v == parent:
                    continue
                dfs(v, u)
                subtree_sum[u] += subtree_sum[v]
                total += initial_cost[v] + subtree_sum[v]
                # update max weight
                if max_weight[v] > max_weight[u] or (max_weight[v]==max_weight[u] and max_depth[v]+1>max_depth[u]):
                    max_weight[u] = max_weight[v]
                    max_depth[u] = max_depth[v]+1
            initial_cost[u] = total

        dfs(0, -1)

        ans = [0]*n

        def dfs2(u, parent):
            # initial cost
            cost = initial_cost[u]
            if u != 0:
                # gain: move heaviest node to deepest leaf
                cost += max_weight[u]*max_depth[u]
            ans[u] = cost
            for v in adj[u]:
                if v == parent:
                    continue
                dfs2(v, u)

        dfs2(0, -1)
        print(' '.join(map(str, ans)))

if __name__ == "__main__":
    solve()
```最初の DFS は、各サブツリーの初期コストを計算し、最大重みノードとその深さを追跡します。 2 番目の DFS は、最大重みノードを最も深いポイントに移動した後、ノードごとに達成可能な最大コストを計算します。 サブツリー プロパティの計算と手の評価を明確に区別するために、DFS を 2 つのパスに分割します。 

微妙な点としては、ルート ノード自体が決して移動されないようにすること、最大重みノードを比較するときに深さの更新を正しく処理すること、初期コストを計算するために重みの合計を正確に伝播することなどが挙げられます。 大規模なチェーンでのスタック オーバーフローを防ぐために、再帰の深さが増加しました。
