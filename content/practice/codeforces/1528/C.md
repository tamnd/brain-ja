 ## 解決策
 ## 問題の理解

 同じ頂点セット上に 2 つのルートを持つツリーが与えられています。`1..n`。 両方のツリーが頂点にルートしています`1`。 

これら 2 つのツリーからグラフを定義します。 2 つの頂点が 2 つの条件を同時に満たす場合、2 つの頂点は接続されます。 

最初の条件は、最初のツリーで 1 つの頂点がルートから他のパス上にあることを示します。 言い換えれば、2 つの頂点は最初のツリーの祖先に関連しています。 

2 番目の条件は、2 番目のツリーではどちらの頂点も他の頂点の祖先ではないことを示しています。 2 番目のツリーにおけるそれらの祖先の間隔は、比較できないものでなければなりません。 

タスクは、このグラフ内で最大のクリークのサイズを見つけることです。 

直接グラフが明示的に構築されることはありません。 まで`3 * 10^5`すべてのテスト ケースにわたって頂点を保存することは、考えられるすべてのエッジを保存することさえ不可能です。 上のグラフ`3 * 10^5`頂点には大まかに含めることができます`4.5 * 10^10`エッジ。 

この制約により、頂点のペアをチェックするアプローチは即座に除外されます。 アン`O(n²)`アルゴリズムには約`9 * 10^10`最悪の場合の運用。 線形に近いものが必要です。`O(n log n)`。 

問題の最も微妙な部分は、クリークがどのようなものかを理解することです。 

最初のツリーがチェーンであると仮定します。```
1
|
2
|
3
|
4
```選択された頂点のすべてのペアは、最初のツリーの祖先に関連しています。 残りの唯一の要件は、2 番目のツリーに祖先関連のペアがないことです。 

不用意な解決策は、2 番目のツリー内の間隔がペアごとに素である頂点の数を最大化しようとする可能性があります。 それだけでは十分ではありません。 もっと強力なプロパティが必要です。つまり、すべてのペアについて、どちらの区間にももう一方の区間が含まれていてはなりません。 ネストは 2 番目のツリーにおける祖先関係を意味するため、ネストされた間隔は禁止されています。 

もう 1 つの簡単な間違いは、選択した 1 つの頂点の間隔に他のいくつかの頂点が含まれる場合に発生します。 

例：```
Second tree:
1
├─2
│ └─3
└─4
```頂点の間隔`2`そして`3`入れ子になっています。 両方が最初のツリーの同じパス上にある場合でも、両方がクリークに属することはできません。 

根元にも注目です。 2 番目のツリーでは、ルートがすべての頂点の祖先になります。 その間隔には、1 つおきの間隔が含まれます。 したがって、ルートは有効なクリーク内の別の頂点と共存することはできません。 

## アプローチ

 ブルートフォースの観点は、記念グラフを構築し、その最大クリークを計算することです。 

両方のツリーの祖先関係をチェックすることで、頂点のペアごとにエッジを形成しているかどうかを判断できます。 それはすでにコストがかかります`O(n²)`。 グラフを構築した後、最大クリークを見つけることは一般的なグラフでは NP 困難であるため、この方向は完全に絶望的になります。 

重要な観察は、ここで生成されたグラフが非常に特殊な構造をしているということです。 

派閥について考えてみましょう。 最初のツリーでは頂点のすべてのペアが祖先に関連している必要があるため、すべてのクリーク頂点が最初のツリーの単一のルートからノードへのパス上に存在する必要があります。 

なぜ？ 

クリーク内の任意の 2 つの頂点を取得します。 それらは最初のツリーで比較できる必要があります。 ルート付きツリー内でペアごとに比較可能な頂点のセットはチェーンを形成します。これはまさにルートから下へのパスです。 

次に 2 番目の木を見てください。 

任意の 2 つのクリーク頂点については、どちらも 2 番目のツリー内のもう一方の祖先であってはなりません。 オイラー ツアー間隔を使用すると、各頂点はサブツリー間隔に対応します`[tin, tout]`。 祖先関係は区間包含になります。 

したがって、クリークは、2 番目のツリー内の間隔がペアごとに含まれていない最初のツリーの 1 つのパス上の頂点のセットに対応します。 

もっと強い言い方が真実です。 

どの間隔にも別の間隔が含まれないように 2 番目のツリー間隔のコレクションを維持する場合、2 番目のツリー内の対応する 2 つの頂点は祖先関連ではありません。 維持されているすべての頂点は最初のツリー DFS 内の 1 つの現在のパスから取得されるため、それらは自動的にクリークを形成します。 

これにより、問題は次のように変換されます。 

最初のツリー内のパスをトラバースしている間、2 番目のツリー内の間隔がペアごとに含まれない頂点の可能な最大のセットを維持します。 

間隔構造は、順序付けられた集合の解決策を示唆します。 最初のツリーでの DFS 中に、入るときに頂点が追加され、出るときに頂点が削除されます。 現在の最適な間隔のコレクションを現在のパス上に維持します。 

有名なソリューションは、2 番目のツリーでオイラーのエントリ時間によって順序付けされた間隔を維持します。 新しい間隔が挿入されるたびに、最大 1 つの既存の間隔を削除する必要があります。 これにより、`O(n log n)`アルゴリズム。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) 以上 | O(n²) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 2 番目のツリーの前処理

 まず、2 番目のツリーでオイラー ツアーを実行します。 

頂点ごとに`v`、次を計算します。`tin[v]`= 入場時間`tout[v]`= 退場時間

 頂点`u`の先祖です`v`2 番目のツリーでは、まさに次のような場合に実行されます。`tin[u] ≤ tin[v]`そして`tout[v] ≤ tout[u]`。 

### アクティブなクリークを維持する

 最初のツリーの DFS 中に、再帰スタックはルートから現在のパスへの 1 つのパスを表します。 

このパスから選択した頂点のセットを維持します。 頂点を直接保存する代わりに、バランスの取れた構造で順序付けされた頂点のオイラーエントリ時間を保存します。 

不変条件は、選択された頂点が 2 番目のツリーの間隔に対応し、他の頂点が含まれないことです。 

### DFS 移行

 1. 頂点を入力します`v`最初の木で。 
2. 直前と直後の間隔を求める`tin[v]`順序付けられたセット内。 
3. 現在選択されている間隔の 1 つにすでに次の間隔が含まれているかどうかを確認します。`v`。 

このような間隔が存在する場合は、次のように追加します。`v`クリークのサイズが大きくなるでしょう。 インターバルを含むものを削除して挿入します`v`。 
4. それ以外の場合は、`v`選択した間隔の 1 つが含まれます。 

「はい」の場合、追加`v`コレクションがさらに悪化してしまうので、`v`含まれる間隔ほど具体的ではありません。 挿入しません`v`。 
5. それ以外の場合`v`選択されたすべての間隔と比較できません。 挿入してください。 
6. セットの現在のサイズでグローバル応答を更新します。 
7. の子への DFS`v`最初の木で。 
8. すべての子が処理された後、入力時に実行された変更を正確にロールバックします。`v`。 

これにより、データ構造が親パスに対応する状態に復元されます。 

### なぜ効果があるのか

 いつでも、DFS スタックは最初のツリー内のパスになります。 選択されたすべての頂点はそのパスに属するため、選択された頂点のすべてのペアは最初のツリー内の祖先に関連します。 

維持されるセットには、2 番目のツリーに含まれていないペアごとの間隔が常に含まれます。 ルート ツリー内の 2 つの区間がクリーク条件に違反する可能性があるのは、一方にもう一方が含まれている場合のみです。 更新ルールにより、封じ込めがない状態が維持されます。 

新しい間隔が既存の選択された間隔内に含まれている場合、大きい間隔を小さい間隔に置き換えても、将来の可能性を減らすことはできません。 間隔が小さいほど厳密には制限が厳しくなり、他の素な間隔に対して少なくとも同程度の余地が残ります。 これが重要な貪欲なステップです。 

したがって、維持されるセットは、現在のルートからノードへのパス上の頂点間で可能な最大のクリークです。 すべての DFS 状態にわたって最大サイズを取得すると、グローバル最大クリークが得られます。 

## Python ソリューション```python
import sys
from bisect import bisect_left

input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

def solve():
    t = int(input())
    ans_out = []

    for _ in range(t):
        n = int(input())

        g1 = [[] for _ in range(n + 1)]
        p1 = list(map(int, input().split()))
        for i, p in enumerate(p1, start=2):
            g1[p].append(i)

        g2 = [[] for _ in range(n + 1)]
        p2 = list(map(int, input().split()))
        for i, p in enumerate(p2, start=2):
            g2[p].append(i)

        tin = [0] * (n + 1)
        tout = [0] * (n + 1)

        timer = 0

        def dfs2(v):
            nonlocal timer
            timer += 1
            tin[v] = timer
            for to in g2[v]:
                dfs2(to)
            tout[v] = timer

        dfs2(1)

        active = []
        best = 0

        def is_ancestor(u, v):
            return tin[u] <= tin[v] and tout[v] <= tout[u]

        def dfs1(v):
            nonlocal best

            pos = bisect_left(active, tin[v])

            inserted = False
            removed_vertex = -1

            if pos > 0:
                pred_tin = active[pos - 1]
                pred = tin_to_vertex[pred_tin]

                if is_ancestor(pred, v):
                    active.pop(pos - 1)
                    active.insert(pos - 1, tin[v])

                    inserted = True
                    removed_vertex = pred

                    best = max(best, len(active))

                    for to in g1[v]:
                        dfs1(to)

                    active.pop(pos - 1)
                    active.insert(pos - 1, tin[pred])
                    return

            if pos < len(active):
                succ_tin = active[pos]
                succ = tin_to_vertex[succ_tin]

                if is_ancestor(v, succ):
                    best = max(best, len(active))

                    for to in g1[v]:
                        dfs1(to)

                    return

            active.insert(pos, tin[v])
            inserted = True

            best = max(best, len(active))

            for to in g1[v]:
                dfs1(to)

            active.pop(bisect_left(active, tin[v]))

        tin_to_vertex = [0] * (n + 1)
        for v in range(1, n + 1):
            tin_to_vertex[tin[v]] = v

        dfs1(1)

        ans_out.append(str(best))

    sys.stdout.write("\n".join(ans_out))

if __name__ == "__main__":
    solve()
```最初の DFS は、2 番目のツリーのオイラー区間を計算します。 サブツリー間隔は連続セグメントになるため、祖先クエリは間隔包含テストに減ります。 

2 番目の DFS は最初のツリー上で実行されます。 再帰スタックは、まさに私たちが検討しているクリーク候補のパスです。 

秩序ある構造`active`現在選択されている頂点のオイラー入力時間を保存します。 重要な事実は、包含のない間隔の間では、次の順序で並べ替えることができるということです。`tin`で十分です。 新しい間隔を含めることができる間隔は、この順序でその前の間隔である必要があります。 新しい間隔に含めることができる間隔は、その後続間隔である必要があります。 そのため、隣接する 2 つのみを検査する必要があります。 

ロールバックは、再帰呼び出しから戻った直後に処理されます。 すべての DFS 状態では、独自のルートからノードへのパスに対応するコレクションが正確に認識されます。

import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()

    def solve():
        from bisect import bisect_left

        input = sys.stdin.readline
        t = int(input())
        ans = []

        for _ in range(t):
            n = int(input())

            g1 = [[] for _ in range(n + 1)]
            p1 = list(map(int, input().split()))
            for i, p in enumerate(p1, start=2):
                g1[p].append(i)

            g2 = [[] for _ in range(n + 1)]
            p2 = list(map(int, input().split()))
            for i, p in enumerate(p2, start=2):
                g2[p].append(i)

            tin = [0] * (n + 1)
            tout = [0] * (n + 1)

            timer = 0

            def dfs2(v):
                nonlocal timer
                timer += 1
                tin[v] = timer
                for to in g2[v]:
                    dfs2(to)
                tout[v] = timer

            dfs2(1)

            tin_to_vertex = [0] * (n + 1)
            for v in range(1, n + 1):
                tin_to_vertex[tin[v]] = v

            active = []
            best = 0

            def anc(u, v):
                return tin[u] <= tin[v] and tout[v] <= tout[u]

            def dfs1(v):
                nonlocal best

                pos = bisect_left(active, tin[v])

                if pos > 0:
                    p = tin_to_vertex[active[pos - 1]]
                    if anc(p, v):
                        old = active[pos - 1]
                        active[pos - 1] = tin[v]

                        best = max(best, len(active))
                        for to in g1[v]:
                            dfs1(to)

                        active[pos - 1] = old
                        return

                if pos < len(active):
                    s = tin_to_vertex[active[pos]]
                    if anc(v, s):
                        best = max(best, len(active))
                        for to in g1[v]:
                            dfs1(to)
                        return

                active.insert(pos, tin[v])

                best = max(best, len(active))
                for to in g1[v]:
                    dfs1(to)

                active.pop(bisect_left(active, tin[v]))

            dfs1(1)
            ans.append(str(best))

        return "\n".join(ans)

    return solve()
