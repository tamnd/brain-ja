 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、`n`頂点。 各頂点には範囲があります`[l_v, r_v]`代入できる整数。 番号を割り当てる必要があります`a_v`すべてのエッジに沿った絶対差の合計が最大化されるように、範囲内の各頂点に適用されます。 つまり、すべてのエッジに対して`(u, v)`、追加します`|a_u - a_v|`私たちの目標は、トータルな美しさの最大化です。 

入力はテスト ケースの数を提供します`t`。 各テスト ケースには、`n`、 に続く`n`範囲、その後に続く`n-1`エッジ。 各テスト ケースの出力は単一の整数、つまり達成可能な最大の美しさです。 

制約は次のことを教えてくれます`n`まで到達できます`10^5`テスト ケースごとに、すべてのテスト ケースの合計が次を超えない`2*10^5`。 これにより、以下よりも悪い解決策は排除されます。`O(n)`または`O(n log n)`テストケースごとに。 可能性の数は指数関数的であるため、頂点への可能な番号の割り当てをすべて試すことはできません。各頂点には 2 つ以上のオプションがあり、`2^100000`対処するのは不可能です。 

考慮すべきエッジケースは、ツリーが直線 (チェーン) である場合です。その場合、1 つの頂点の選択はその隣接頂点にのみ影響しますが、最適な選択はチェーンに沿って伝播する必要があるためです。 たとえば、範囲を持つ 2 つの頂点のチェーン`[1,1]`そして`[100,100]`自明に違いが生じます`99`。 範囲のエンドポイントを考慮しない単純な実装では、これを見逃す可能性があります。 

もう 1 つの微妙なケースは、頂点に次のような範囲がある場合です。`l_v = r_v`。 その場合、値は固定されるため、アルゴリズムは縮退間隔を適切に処理する必要があります。 

## アプローチ

 ブルートフォースアプローチは、許容範囲内で各頂点の可能なすべての数値を試し、その割り当ての合計の美しさを計算し、最大値を取ることです。 割り当ての数は指数関数的に増加するため、これは明らかに実行不可能です。`n`。 

重要な観察は、各頂点について、その範囲の端点のみを考慮すればよいということです。`l_v`そして`r_v`。 これは、絶対差が区分的線形関数であるためです。親子エッジの場合`(u, v)`、子のいずれかのエンドポイントと親のいずれかのエンドポイントを取得したときに、美しさへの最大の貢献が得られます。 いずれかのエンドポイントを超えて差を改善することはできないため、内部値を選択する必要はありません。 

この観察により、問題はツリー上の動的プログラミングに帰着します。 各頂点で、2 つの値を追跡します。この頂点が左端点を取る場合のサブツリーの最大の美しさ、および右端点を取る場合の最大の美しさです。 次に、各子供について、4 つの組み合わせすべてを考慮して可能性を組み合わせます (`l_u`と`l_v`、`l_u`と`r_v`、`r_u`と`l_v`、`r_u`と`r_v`) 絶対的な差を子の DP 値に加算します。 

ツリー構造により、これを単一の DFS で実行できます。 ルートから開始して DP 値を再帰的に計算し、ルートで 2 つのオプションの最大値を取得します。 このアプローチは次のように実行されます。`O(n)`各エッジが 1 回ずつ訪問されるため、テスト ケースごとに異なります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | DP オン ツリー | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 隣接リストを使用してツリーを表します。 各頂点には近隣の頂点が格納されます。 これにより、効率的な DFS トラバーサルが可能になります。 
2. 各頂点について`v`、2 つの DP 値を維持します。`dp[v][0]`最高の美しさなら`a_v = l_v`、 そして`dp[v][1]`最高の美しさなら`a_v = r_v`。 
3. 任意の頂点 (頂点 1 など) から開始して DFS を実行します。 現在の頂点の場合`v`とその子`u`、再帰的に計算します`dp[u][0]`そして`dp[u][1]`。 
4. 頂点に戻る場合`v`、 アップデート`dp[v][0]`そして`dp[v][1]`次のように：`dp[v][0] += max(abs(l_v - l_u) + dp[u][0], abs(l_v - r_u) + dp[u][1])`

`dp[v][1] += max(abs(r_v - l_u) + dp[u][0], abs(r_v - r_u) + dp[u][1])`これは、親エンドポイントと子エンドポイントの 4 つの可能な組み合わせすべてを考慮し、最大値を選択します。 
5. DFS が完了すると、ツリーの最大の美しさは次のとおりです。`max(dp[root][0], dp[root][1])`。 

これが機能する理由は、ルートとなるサブツリーの割り当てが最適であるためです。`v`の割り当てのみに依存します`v`それ自体とその子に対する最適な割り当て。 差の絶対値はエンドポイントで最大化されるため、頂点ごとに 2 つのケースのみを追跡します。 この DP 不変式により正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**6)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        lr = [tuple(map(int, input().split())) for _ in range(n)]
        tree = [[] for _ in range(n)]
        for _ in range(n-1):
            u, v = map(int, input().split())
            tree[u-1].append(v-1)
            tree[v-1].append(u-1)

        dp = [[0, 0] for _ in range(n)]
        
        def dfs(v, parent):
            for u in tree[v]:
                if u == parent:
                    continue
                dfs(u, v)
                dp[v][0] += max(abs(lr[v][0]-lr[u][0]) + dp[u][0],
                                abs(lr[v][0]-lr[u][1]) + dp[u][1])
                dp[v][1] += max(abs(lr[v][1]-lr[u][0]) + dp[u][0],
                                abs(lr[v][1]-lr[u][1]) + dp[u][1])
        
        dfs(0, -1)
        print(max(dp[0][0], dp[0][1]))

solve()
```隣接リストにより、二次メモリの使用が回避されます。 の`sys.setrecursionlimit`DFS が Python の再帰制限に達しないようにします。 DP の更新により、最大限の美しさが子から親へと正しく伝播されます。 使用する`abs(l_v - l_u)`追加のロジックなしで負の差異を処理します。
