 ## アルゴリズムのチュートリアル

 まずコード文字列を変換します$S$正味変位に換算$(s_x, s_y)$R、L、U、D の寄与を合計することによって計算されます。これにより、特別な演算の決定論的な部分の効果が得られます。 

次に、関心のある状態は常にターゲットに対する現在のオフセットであることがわかり、これを次のように初期化します。$(x, y)$原点に対して。 

次に、特別な操作がこのオフセットを 2 段階でどのように変更するかを計算します。 最初のステージではオフセットを次のように移動します。$(x - s_x, y - s_y)$。 第 2 段階では、バーストを適用します。$d$4 つの方向のいずれかに移動します。 方向ごとに、ターゲットまでのマンハッタン距離を計算します。 この問題では、この選択が常に最適に行われることが保証されているため、結果として最小の距離が得られる方向を選択します。 

これにより、既知のコストとともに、1 つの特別な操作の後に現在のオフセットを新しいオフセットにマップする関数が得られます。$|S| + 1$を押します。 

この時点では、この操作を 1 つの移動に挟んで何回適用するかを決定する問題として扱います。 単一の移動は常にマンハッタンの距離をコスト 1 ごとにちょうど 1 だけ減らすため、ベースラインとして機能します。 それぞれの特別な操作により、現在のオフセットのみに応じてマンハッタン距離の決定的な最良の場合の短縮が行われます。 

これ以上の改善が不可能になるまで、コストあたりの即時削減が最大になる操作を繰り返し適用し、残りの距離を単一の移動で終了します。 

### なぜ効果があるのか

 プロセスはターゲットに対する現在のオフセットを常に維持し、すべての操作はそのオフセットをどのように変更するかのみに基づいて評価されます。 単一の移動ではマンハッタンの距離がちょうど 1 だけ減少し、特別な操作では次の式で決定される計算可能な固定量だけ減少します。$(s_x, s_y)$そして$d$現在のオフセットを基準にして。 各アクションのコストは固定されており、状態空間にはこのオフセットを超える隠れた構造がないため、局所的に最適な削減からの逸脱は、将来のより良い構成を可能にすることなく、厳密に総コストを増加させることになります。 これにより、プロセス全体で一貫した削減に対する貪欲な選択が可能になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def best_after_combo(dx, dy, sx, sy, d):
    dx -= sx
    dy -= sy

    best = 10**30

    ndx = dx + d
    best = min(best, abs(ndx) + abs(dy))

    ndx = dx - d
    best = min(best, abs(ndx) + abs(dy))

    ndy = dy + d
    best = min(best, abs(dx) + abs(ndy))

    ndy = dy - d
    best = min(best, abs(dx) + abs(ndy))

    return best

def solve():
    x, y, d = map(int, input().split())
    s = input().strip()

    sx = sy = 0
    for c in s:
        if c == 'R':
            sx += 1
        elif c == 'L':
            sx -= 1
        elif c == 'U':
            sy += 1
        else:
            sy -= 1

    cur = abs(x) + abs(y)

    nxt = best_after_combo(x, y, sx, sy, d)

    # treat as one-shot improvement model
    gain = cur - nxt

    cost_single = 1
    cost_combo = len(s) + 1

    if gain <= 0:
        print(cur)
        return

    # how many useful full improvements we can apply
    k = cur // gain

    remaining = cur - k * gain
    ans = k * cost_combo + remaining
    print(ans)

if __name__ == "__main__":
    solve()

機能`best_after_combo`コードを適用し、最適に選択した後、マンハッタン距離を評価します。$d$-移動方向。 4 つの選択肢はそれぞれ、1 つの軸方向に完全に沿って押すことに対応し、すべての結果を明示的に計算します。 

次に、最初のマンハッタン距離と、コンボを 1 回適用した後に達成可能な最良の距離を比較し、その差を単一単位の「ゲイン」として扱います。 これにより、コストのかかる操作と、単位コストの移動に対する変動報酬のバランスの問題が軽減されます。
