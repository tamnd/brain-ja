 ## 問題の理解

 私たちは、`n × m`グリッド。 すべてのセルには、4 つの角の形をしたパイプ部分の 1 つが含まれている必要があります。 各ピースは、セルの隣接する 2 つの側面を正確に接続します。 

パイプの種類は次の 4 つです。 

- タイプ 1 は上と左を接続します
 - タイプ 2 は上部と右側を接続します
 - タイプ 3 は下と右を接続します
 - タイプ 4 は下と左を接続します

 一部のセルはすでに固定されていますが、一部は空でマークされています。`.`。 配管システム全体が漏れないようにするために、空のセルを何通り埋めることができるかを数えなければなりません。 

パイプ終端は、次のいずれかの場合に有効です。 

- 隣接するセルの別のパイプ端に接続する、または
 - グリッドの外側の境界線に触れます。 

内部端が一致しないと漏れが発生し、構成が無効になります。 

グリッドには最大で次のものを含めることができます`5 · 10^5`セルを使用すると、代入に対する検索が即座に除外されます。 すべての空のセルには 4 つの可能性があるため、総当たりで調べます。`4^k`どこにあるのかを述べます`k`空のセルの数です。 平`k = 30`すでに不可能です。 

境界にあるセルの総数`5 · 10^5`意図したソリューションのグリッド サイズが線形またはほぼ線形であることを強く示唆しています。 セル数が 2 次になるとタイムアウトになります。 

難しいのは、「漏れがない」ということが世界全体で実際に何を意味するのかを理解することです。 不用意に実装すると、隣接するセルを独立して検証しようとし、境界によって課せられる構造上の制約を見逃す可能性があります。 

次の入力を考えてみましょう。```
1 1
.
```答えは次のとおりです。```
0
```すべてのパイプ タイプには正確に 2 つの端があります。 で`1 × 1`グリッド、4 辺すべてが境界線です。 4 つのピースのいずれも両端が必要な方向に同時に外側を向いていないため、配置は機能しません。 

もう一つの微妙なケース:```
1 2
13
```答えは次のとおりです。```
1
```タイプ`1`最初のセルでは上と左が公開されており、どちらも境界線に触れているため有効です。 タイプ`3`2 番目のセルでは下と右が公開されます。これも境界線に触れているため有効です。 内側の2つの側面は接続されていないため、この配置では実際に漏れが発生します。 ローカルの学位のみを検証する単純なチェッカーは、誤ってそれを受け入れてしまうでしょう。 

もう 1 つ重要なエッジ ケース:```
2 2
11
11
```答えは次のとおりです。```
0
```最初の行の 2 つのセルは、上辺を境界線に露出させようとしていますが、これは問題ありませんが、下辺は完全に接続されていません。 すべての内部エッジは両側から接続されているか、両側から使用されていない必要があります。 

重要な点は、すべての内部隣接が 2 つの隣接セル間に同等条件を課すということです。 

## アプローチ

 ブルートフォースの解決策は簡単です。 空のセルごとに、4 つのパイプ タイプすべてを試します。 完全なグリッドを構築した後、すべての隣接するペアをスキャンし、すべてのパイプの端が正しく一致していることを確認します。 これは、有効性条件が純粋にローカルであるため機能します。 

問題は課題の数です。 グリッドに`k`空のセル、テストする必要があります`4^k`構成。 最悪の場合、`k = 5 · 10^5`、それは天文学的な大きさです。 

パイプピースの構造により、より強力な特性が得られます。 

それぞれの作品は、縦方向につながっているか、横方向につながっているかで説明できます。 

たとえば:

 - タイプ 1 は上と左を使用します
 - タイプ 2 は上部と右側を使用します
 - タイプ 3 は下と右を使用します
 - タイプ 4 は下と左を使用します

 内側のエッジ全体で何が起こるかを観察してください。 

水平方向に隣接する 2 つのセルがエッジを共有しているとします。 両方のピースがそのエッジを介して接続されるか、どちらも接続されません。 4 つのピース タイプを見ると、この条件はセルが 2 つのパリティ クラスのいずれかに属するかどうかによってのみ決まります。 

これをより明確に表現する方法は次のとおりです。 

各セルにバイナリ値を定義します。 

- 種類`1`そして`3`クラスに所属している`0`- 種類`2`そして`4`クラスに所属している`1`この場合、有効な水平隣接には、2 つの隣接セルが反対のクラスを持つ必要があります。 

同様に、すべての有効な垂直隣接にも反対のクラスが必要です。 

これは、グリッド全体が強制的に市松模様になることを意味します。 

すべてのセルのチェッカーボード クラスが固定されると、各セルに許可されるパイプ タイプは次の 2 つだけになります。 

- 境界線の方向ごとに 1 つの選択肢。 

次に、境界制約によって 2 つの選択肢のうちどちらが有効であるかが決まります。 

実際、チェッカーボード パリティを修正した後は、すべてのセルが一意に決定されるようになります。 可能なチェッカーボードの色は 2 つだけであるため、最終的な答えは最大でも次のとおりです。`2`。 

したがって、指数関数的に多くの割り当てを検索する代わりに、2 つのグローバル パターンのみをテストします。

 ## アルゴリズムのチュートリアル

 1. すべてのパイプ タイプにパリティ値を割り当てます。 

させて：$$p(1)=0,\quad p(2)=1,\quad p(3)=0,\quad p(4)=1$$有効なシステム内の隣接するセルは、常に反対のパリティを持っている必要があります。 
2. 最初の市松模様のパターンを試してください。 

あらゆる細胞に対して`(i, j)`:$$p(i,j) = (i+j)\bmod 2$$これにより、セルがどのパリティを持つ必要があるかが決まります。 
3. すべての固定セルについて、互換性を確認します。 

パリティが必要なチェッカーボード パリティと一致しないパイプ タイプがグリッドに既に含まれている場合、このパターンは不可能です。 
4. すべてのセルについて、コンクリート パイプの方向が存在するかどうかを確認します。 

パリティが修正されると、各セルには 2 つの候補パイプ タイプが正確に存在します。 

- パリティ`0`型を与える`1`または`3`- パリティ`1`型を与える`2`または`4`国境によってどちらが合法であるかが決まります。 

たとえば、一番上の行のセルでは、下向きのみのパイプを使用することはできません。 上部の露出面は境界線の動作と一致する必要があります。 
5. 必要な境界線の方向が一意に有効なタイプを決定するかどうかを確認します。 

隣接するパリティが交互になるため、内部エッジの一致はすでに保証されています。 

残る唯一の問題は、ピースの方向が外側の境界線と互換性があるかどうかです。 
6. 反対側の市松模様の色についてもこのプロセスを繰り返します。 

2 番目のパターンは次のとおりです。$$p(i,j) = 1 - ((i+j)\bmod 2)$$7. 2 つのパターンのうち、有効なものがいくつあるかを数えます。 

### なぜ効果があるのか

 不変条件は、すべての内部エッジが反対のパリティの 2 つのセルを接続することです。 

どのタイプのパイプでも、エッジを越えて移動すると、そのエッジが使用されているかどうかが反転します。 すべての有効な内部エッジは両方のセルで使用されるか、両方のセルで使用されない必要があるため、隣接するセルは反対のパリティ クラスに属している必要があります。 

パリティ交互を強制するすべての隣接関係を持つ接続されたグリッドには、有効なグローバル割り当てが 2 つだけあり、2 つのチェッカーボードの色が付けられます。 セルのパリティが固定されると、境界制約により一意のパイプ方向が強制されます。 これ以上の自由は残されていません。 

このアルゴリズムは、可能なグローバル パリティ構造を 2 つだけ正確にテストするため、有効な設定を見逃すことはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000003

def solve():
    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    # parity:
    # 1,3 -> 0
    # 2,4 -> 1
    parity = {
        '1': 0,
        '2': 1,
        '3': 0,
        '4': 1
    }

    ans = 0

    for start in range(2):
        ok = True

        for i in range(n):
            for j in range(m):
                need = (i + j + start) & 1

                c = g[i][j]

                if c != '.':
                    if parity[c] != need:
                        ok = False
                        break

            if not ok:
                break

        if ok:
            ans += 1

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```数学的構造によりローカル シミュレーションがすべて削除されるため、実装は驚くほど短くなります。 

辞書`parity`パイプ部分の 2 つの等価クラスをエンコードします。 重要な事実は、隣接するセルが常に反対のパリティを持たなければならないということです。 

2 つの可能なチェッカーボード割り当てのそれぞれについて、位置で必要なパリティを計算します。`(i, j)`として：```
(i + j + start) & 1
```変数`start`左上隅に表示されるパリティを選択します。 

固定パイプがグリッド内にすでに存在する場合は、そのパリティが必要なパリティと一致することを確認するだけです。 不一致があると、パターン全体が直ちに無効になります。 

明示的なエッジチェックは必要ありません。 パリティ特性評価により、すべての内部互換性がすでに保証されています。 

よくある間違いは、実際のパイプの向きを再構築しようとすることです。 それは不必要です。 パリティ条件は必要かつ十分です。 

もう 1 つの簡単な間違いは、答えが次の値を超える可能性があると仮定することです。`2`。 1 つのセル パリティが選択されると、他のすべてのセル パリティは隣接制約によって強制されます。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    parity = {
        '1': 0,
        '2': 1,
        '3': 0,
        '4': 1
    }

    ans = 0

    for start in range(2):
        ok = True

        for i in range(n):
            for j in range(m):
                need = (i + j + start) & 1

                c = g[i][j]

                if c != '.':
                    if parity[c] != need:
                        ok = False
                        break

            if not ok:
                break

        if ok:
            ans += 1

    print(ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.strip()

# minimum grid
assert run("1 1\n.\n") == "2", "single empty cell"

# fixed valid parity
assert run("1 2\n12\n") == "1", "one checkerboard works"

# conflicting fixed cells
assert run("2 2\n11\n..\n") == "0", "same parity neighbors impossible"

# all empty
assert run("3 3\n...\n...\n...\n") == "2", "both checkerboards valid"
