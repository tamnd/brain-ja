 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、根を張った木です。`n`頂点、ラベル付き`1`を通して`n`、頂点`1`根です。 ルート以外の各頂点`i`親がいる`p_i`、ツリーのエッジを定義します。 番号を割り当てるように求められます`1`を通して`n`特定のカウント関数を最大化するために、頂点をある順序 (順列) で変換します。 

この関数は頂点のペアをカウントします`(u, v)`ここでの値は`u`の最小共通祖先の値より小さい`u`そして`v`での値よりも小さくなります。`v`。 正式には、`a[u] < a[lca(u, v)] < a[v]`。 順列を選択したい`a`できるだけ多くのペアがこの不等式を満たすようにします。 

問題は次のように限定されています`n ≤ 5000`。 すべてのペアを考慮した素朴なアプローチ`(u, v)`それぞれの順列は直ちに実行不可能です。`O(n^2)`ペア、そして`n!`順列。 たとえ単一の順列を修正したとしても、ペアごとにすべての LCA 値を単純に計算すると、`O(n^3)`。 したがって、強引なアプローチは絶望的です。 課題は、LCA のツリー構造とプロパティを活用して、最適な値を効率的に計算することです。 

エッジ ケースには、直線であるツリー (縮退ツリー) またはスター型 (すべてのノードがルートに直接接続されている) が含まれます。 直線では、離れた頂点の LCA はルートに近いため、有効なペアを最大化するには、極値がルートに近くなければならない場合があります。 スターでは、ルートはほとんどのペアの LCA であるため、その値が重要になります。 

## アプローチ

 ブルートフォースソリューションでは、すべての順列を試みます。`1..n`、すべての LCA を計算し、有効なペアをカウントします。 正確さは保証されていますが、複雑さが爆発的に増加します。`O(n! * n^2)`操作 - たとえ`n = 10`。 これにより、正しいが非現実的なベースラインが確立されます。 

最適化するための重要な洞察は、関数が`f(a)`サブツリーに沿って再帰的に分解できます。 各サブツリーで取得可能な最大値がわかっている場合は、ルートと比較してどのサブツリーのノードがより小さい数値を取得し、どのノードがより大きな数値を取得するかを選択することでそれらを結合できることに注目してください。 より具体的には、すべての有効なペア`(u, v)`どこ`lca(u, v) = x`関与しなければならない`x`厳密にその間にある`a[u]`そして`a[v]`。 これは自然に満たされます`x`は中間の値を持ち、その子のサブツリーは上下の範囲に分割されます`a[x]`。 

ルート化されたサブツリーに対する動的プログラミングは自然なアプローチです。 させて`dp[u][k]`のサブツリー内のペアの最大数になります。`u`割り当てれば`k`合計の数値。 各頂点について、各子に割り当てられたノードの数を考慮して、その子の DP をマージできます。 これにより、順列の列挙が回避され、管理可能なサブツリーの組み合わせのみが計算されるため、複雑さが大幅に軽減されます。`n = 5000`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * n^2) | O(n) | 遅すぎる |
 | サブツリー DP | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ツリー構造を解析します。 DFS トラバーサルを容易にするために、親配列から隣接リストを構築します。 
2. DP 配列を定義する`dp[u][k]`のサブツリーに有効なペアの最大数を格納するには`u`使用して`k`数字。 
3. DFS を使用して、ポストオーダーのツリーを走査します。 葉っぱに関しては、`dp[u][1] = 0`単一のノードはペアを形成しないためです。 
4. 内部ノードの場合`u`、から始めます`dp[u][1] = 0`。 それぞれの子どもたちを考慮する`v`その DP テーブルを`u`の現在の DP は一時配列を使用します。 させて`s1`に割り当てられた番号の数になります`u`これまでと`s2`に割り当てられた番号`v`。 すると、結合された DP 値は次のようになります。`dp[u][s1 + s2] = max(dp[u][s1 + s2], dp[u][s1] + dp[v][s2] + s1 * s2)`。 の`s1 * s2`term は、次から 1 つの数値を選択して形成された新しいペアをカウントします。`u`の既存の割り当てと子からの割り当て、`u`その間。 
5. すべての子を処理した後、`dp[1][n]`答えは、すべてを使用した有効なペアの最大数です。`n`ツリー内の数字。 
6. 戻る`dp[1][n]`。 

不変条件とは、`dp[u][k]`をルートとするサブツリー内で達成可能な最大ペアを正確にカウントします。`u`正確にいつ`k`番号が割り当てられています。 組み合わせカウントを使用して子とマージすると、異なるサブツリーにまたがるすべてのペアが次のようになります。`u`LCA としてカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10000)

def solve():
    n = int(input())
    parents = list(map(int, input().split()))
    
    tree = [[] for _ in range(n)]
    for i, p in enumerate(parents):
        tree[p-1].append(i+1)
    
    # dp[u][k] = max pairs in subtree of u using k nodes
    dp = [None] * n
    size = [0] * n
    
    def dfs(u):
        dp[u] = [0]  # 0 nodes initially
        size[u] = 1
        for v in tree[u]:
            dfs(v)
            new_dp = [0]*(size[u] + size[v] + 1)
            for s1 in range(size[u]):
                for s2 in range(1, size[v]+1):
                    new_dp[s1+s2] = max(new_dp[s1+s2], dp[u][s1] + dp[v][s2] + s1*s2)
            size[u] += size[v]
            dp[u] = new_dp[:size[u]+1]
    
    dfs(0)
    print(dp[0][n])

solve()
```DFS はツリーをボトムアップで構築します。 二重ループは子 DP を親にマージし、すべての新しいペアを正確にカウントします。 設定`s2`から`1`に`size[v]`空の割り当てを二重にカウントすることを回避します。

 ## 特殊なケース

 ルートが LCA であるため、2 つのノードを持つツリーは常に 1 つの有効なペアを生成します。 DP はこれを自然に処理します。ルートはそのリーフの子 DP をマージします。`[0,1]`。 線ツリーは、割り当て順序が重要であることを示しています。 マージでは、ペア間の LCA を持つ有効な組み合わせのみがカウントされます。`2`のペア`n=4`。 スター ツリーは、複数の子の結合を示します。 DP は `s までのすべてのペアを正しくカウントします
