 ## 解決策
 ## 問題の理解

 ロボット掃除機の上面図は凸多角形として与えられます。 部屋のコーナーは、2 つの垂直な壁によって形成される通常の 90 度のコーナーです。 掃除機を任意の角度に回転させて、隅にできるだけ押し込みます。 

掃除機は壁を貫通できないため、隅に押し込まれた後も、掃除機の形状により、隅近くの一部の領域が依然として到達できない可能性があります。 タスクは、すべての回転にわたって可能な最小のカバーされていない領域を計算することです。 

幾何学的には、回転を選択した後、両方の座標軸に同時に触れるまで多角形を平行移動します。 覆われていない領域は、多角形の左下にある第 1 象限内のエリアになります。 このような最小の領域が必要です。 

ポリゴンには最大$4 \cdot 10^4$頂点。 これにより、二次関数は即座に除外されます。 平$O(n^2)$安価な操作では約$1.6 \cdot 10^9$限界をはるかに超えたペアチェック。 解決策$O(n \log n)$または線形が必要です。 

座標の大きさは次のとおりです$10^6$、中間生成物が到達する可能性があります$10^{12}$。 Python では整数オーバーフローは無害ですが、精度の低下を避けるために幾何学式は慎重に記述する必要があります。 

最初の微妙なエッジ ケースは、多角形にすでに部屋の角と一致する直角の角がある場合に現れます。 例えば：```
4
0 0
1 0
1 1
0 1
```正方形は隅にぴったり収まるので、答えはゼロです。 頂点の距離またはエッジの傾きのみをチェックする単純なアプローチでは、浮動小数点ノイズにより誤って正の面積が返される可能性があります。 

もう 1 つの注意が必要なケースは、最適な位置が 1 つの頂点ではなく 2 つのエッジによって決定される場合です。 円に近似する正多角形を考えてみましょう。 2 つの壁との接触は異なる点で発生し、覆われていない領域は単に最下位の頂点だけではなく支持線に依存します。 同じ頂点が両方の壁に接触していると想定する実装は、ここで失敗します。 

3 番目の落とし穴は、ポリゴンの方向に起因します。 頂点は時計回りまたは反時計回りの場合があります。 外積と回転キャリパーのロジックは、両方で同じように機能する必要があります。 例えば：```
3
0 0
2 0
0 1
```そして```
3
0 1
2 0
0 0
```同じ三角形を説明します。 答えは同じでなければなりません。 

## アプローチ

 ブルーフォースのアイデアは単純明快です。 回転角度を固定する$\theta$、すべての頂点を回転し、ポリゴンが両方の座標軸に接触する位置の移動位置を計算し、覆われていない領域を評価します。 多くの角度を十分に密にサンプリングすれば、答えを近似することができます。 

覆われていない領域は回転とともに連続的に変化するため、これは概念的に機能します。 問題は精度です。 正確さを保証するには、2 つの壁に接触する支持エッジが変化するすべての重要な回転を検査する必要があります。 がある$O(n^2)$可能なエッジのペアがあり、各ペアのジオメトリを再計算すると、二次の複雑さが生じます。 

重要な観察は、覆われていない領域が非常にきれいな幾何学的解釈を持っているということです。 

回転後に多角形が隅に押し込まれたとします。 垂直壁に接する支持線の外向き法線を持たせる$u$、水平壁に接する支持線の外向き法線を持たせます。$v$。 壁が垂直なので、$u$そして$v$に垂直です。 
覆われていない領域は、まさに多角形によって切り取られた長方形の角です。 その面積は以下に等しい$$A(\theta) = h(\theta) \cdot h(\theta + \pi/2)$$どこ$h(\alpha)$方向におけるポリゴンのサポート関数です$\alpha$。 

ここで決定的な簡素化が行われます。 凸多角形の場合、サポート関数は、連続するエッジ法線間のサインおよびコサインにおいて区分的に線形です。 重大な変更は、サポートする頂点の 1 つが変更された場合にのみ発生します。 回転キャリパーを使用すると、このようなすべてのイベントを線形時間で処理できます。 

幾何学的な再定式化により、実装がさらにすっきりします。 角が原点に来るようにポリゴンを配置すると、覆われていない領域は、すべての回転にわたってポリゴンを含む軸に整列した最小の長方形領域になります。 

固定方向の場合は、次のように定義します。$$W = \max x - \min x$$

$$H = \max y - \min y$$最小の覆われていない領域は、次の最小値に等しくなります。$W \cdot H$、これはまさに凸多角形の最小面積包囲四角形問題です。 

この問題には、凸包を前処理した後、線形時間で回転キャリパーを使用する古典的な解決策があります。

 ## アルゴリズムのチュートリアル

 1. ポリゴンの頂点を読み取り、反時計回りに順序付けされていることを確認します。 

回転キャリパーの式は、一貫した方向を想定しています。 符号付き領域を計算し、必要に応じて配列を反転します。 
2. あらゆるエッジに対して$i \to i+1$、その方向ベクトルと正規化された方向を計算します。 

最小面積長方形定理は、最適な長方形の少なくとも 1 つの辺が多角形のエッジに平行であることを示します。 これにより、無限に多くの回転が減少します。$n$候補者の方向性。 
3. 回転キャリパーで 4 つの指針を維持します。 

現在のエッジの方向については、以下を追跡します。 

- 法線方向の最も遠い頂点、
 - エッジ方向の最も遠い、
 - 反対側のエッジ方向の最も遠いところ。 

これらは、囲む長方形の上、右、左の支持線に対応します。 
4. 対応する投影が増加する間に各ポインタを進めます。 

凸性は単調性を保証します。 各ポインターは、アルゴリズム全体でポリゴンの周囲を 1 回だけ前進します。 
5. 現在の方向の長方形の寸法を計算します。 

させて$e$をユニットエッジ方向とし、$n$その垂直単位ベクトル。 

長方形の幅は$$\max(p \cdot e) - \min(p \cdot e)$$そして高さは$$\max(p \cdot n) - \min(p \cdot n)$$6. 幅と高さを掛けて答えを更新します。 

この長方形は、現在のエッジに平行な 1 つの辺を持つ最小の外接長方形です。 これらの候補の中から大域最適が現れます。 
7. すべてのエッジが処理されるまで続行します。 

すべてのポインターは最大でも 1 回ラップアラウンドするため、合計実行時間は線形です。 

### なぜ効果があるのか

 正しさは 2 つの幾何学的事実に依存します。 

まず、多角形を隅に押し込んだ後の覆われていない領域は、回転された多角形の軸に沿った外接する長方形の領域と等しくなります。 多角形の左端と最下端の支持線が壁と一致するように多角形を移動すると、まさにその長方形の欠損が作成されます。 

第 2 に、凸多角形の場合、最小面積を囲む長方形の片面は常に多角形のエッジと面一になります。 これが当てはまらない場合は、多角形を含んだまま、長方形をわずかに回転して面積を減らすことができます。 

回転キャリパーは凸面を利用します。 支持エッジが多角形の周りを連続的に回転すると、すべての末端支持点も単調に移動します。 これにより、すべての最適な候補が 1 回だけチェックされることが保証されます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def cross(a, b):
    return a[0] * b[1] - a[1] * b[0]

def sub(a, b):
    return (a[0] - b[0], a[1] - b[1])

def dot(a, b):
    return a[0] * b[0] + a[1] * b[1]

def polygon_area2(poly):
    n = len(poly)
    s = 0
    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]
        s += x1 * y2 - y1 * x2
    return s

def solve():
    n = int(input())
    p = [tuple(map(float, input().split())) for _ in range(n)]

    if polygon_area2(p) < 0:
        p.reverse()

    nxt = lambda i: (i + 1) % n

    j = 1
    k = 1
    l = 1

    ans = float("inf")

    for i in range(n):
        ni = nxt(i)

        ex = p[ni][0] - p[i][0]
        ey = p[ni][1] - p[i][1]

        length = math.hypot(ex, ey)

        ux = ex / length
        uy = ey / length

        vx = -uy
        vy = ux

        def proj_u(idx):
            return p[idx][0] * ux + p[idx][1] * uy

        def proj_v(idx):
            return p[idx][0] * vx + p[idx][1] * vy

        while proj_v(nxt(j)) > proj_v(j):
            j = nxt(j)

        while proj_u(nxt(k)) > proj_u(k):
            k = nxt(k)

        while proj_u(nxt(l)) < proj_u(l):
            l = nxt(l)

        height = proj_v(j) - proj_v(i)
        width = proj_u(k) - proj_u(l)

        ans = min(ans, width * height)

    print("{:.20f}".format(ans))

solve()
```最初の部分では、2 倍の符号付き面積の式を使用してポリゴンの方向を計算します。 頂点が時計回りの場合は、頂点を反転して、すべての幾何学的比較が一貫して動作するようにします。 

ソリューションの中核は、回転キャリパー ループです。 各エッジに対して、2 つの直交単位ベクトルを構築します。 1 つはエッジの方向に従い、もう 1 つはその垂直法線に従います。 

3 つのポインタは極端な投影を追跡します。 ポインタ`j`法線方向への最大投影を与え、これによって長方形の高さが決まります。 ポインタ`k`そして`l`エッジ方向に沿った最大および最小の投影を決定し、幅を与えます。 

射影関数は、ドット積を使用して明示的に記述されます。 正規化されたベクトルを使用すると、投影が実際のユークリッド距離になるため、式が単純になります。 

最もデリケートな部分は、ポインターの進行条件です。 彼らは厳密な不平等を利用します。 凸多角形と同一線上のトリプルがない場合、これにより無限ループが回避され、単調性が維持されます。 

もう 1 つの簡単な間違いは、モジュロ ラップアラウンドを忘れることです。 すべてのポインターはポリゴンの周囲を周期的に移動するため、ヘルパー`nxt(i)`コードをコンパクトかつ安全に保ちます。
