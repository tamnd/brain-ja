 ## 解決策
 ## 問題の理解

 長さの文字列を構築するように求められます`N`最初のものだけを使用して`K`アルファベットの文字。指定された「名前」文字列が`P`特定の開始位置で正確に発生し、他の場所では発生しません。 位置はバイナリ文字列として指定されます。`1`ことを示します`P`そこから始めなければなりません、そして`0`してはならないことを示します。 の位置`P`重複することもできますが、これは許可されており、場合によっては必要です。 

たとえば、次の場合`P = "aba"`そしてバイナリ文字列は`"101"`、それは次のことを示します`P`結果の文字列の位置 1 と 3 から開始する必要があります。 正しい出力は次のようになります`"ababa"`。 

制約は小さいですが、自明ではありません。`N`最大 100 まで可能で、`K`最大 26。これは、おおよその値を含む任意のソリューションを意味します。`N^2`操作は許容されますが、潜在的な文字列の数は指数関数的に増加するため、すべての可能な文字列をブルート フォース チェックすることは現実的ではありません。`N`。 

明らかではないエッジケースには、以下の重複発生が含まれます。`P`それは衝突する可能性があります。 たとえば、次の場合`P = "aa"`そしてポジションは`"11"`、 最初`P`は位置 1 から始まり、2 番目は位置 2 から始まります。単純なアプローチでは、`P`開始するたびに盲目的に生産します`"aaa"`ここでは機能しますが、`P = "ab"`の 2 番目の出現を配置するため、それは不可能です`"ab"`最初の文字は次のようにする必要があります`'b'`そして`'a'`同じ位置にあり、競合しています。 

もう 1 つの微妙な点は、`0`開始できません`P`、ただし、 の位置外の文字`P`最初から任意の有効な文字を指定できます`K`文字。 これにより、文字列の残りの部分を柔軟に埋めることができます。 

## アプローチ

 ブルートフォースソリューションでは、すべての長さの文字列が生成されます。`N`最初のものを使用して`K`文字を入力し、必要な文字がすべて一致するかどうかを確認します。 これは原理的には正しいですが、その複雑さは次のとおりです。`O(K^N)`、これは天文学的に大きい`N = 100`。 

実用的な解決策を可能にする重要な観察は、最終的な文字列内の各位置は、次の要素が重複することによってのみ制約されるということです。`P`。 開始位置を順番に繰り返して「ペイント」しようとすると、`P`文字列上で競合（重複する 2 つの異なる文字）が発生すると、直ちに解決が不可能になります。 すべての必須のオカレンスが矛盾なく配置されると、残りのすべての位置にアルファベットの任意の文字を入力できます。 

これにより、問題は、制約を適用する文字列の 1 回のパスと、制約のない位置のフィルインに軽減されます。 これは、各文字が最大 2 回処理されるため効率的です (制約の配置中に 1 回、充填中に 1 回)。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(K^N) | O(N) | 遅すぎる |
 | 制約の伝播 + 塗りつぶし | O(N * | P | ) |

 ## アルゴリズムのチュートリアル

 1. 配列を初期化する`S`長さの`N`と`None`空の位置を表す値。 
2. バイナリ文字列内の位置を反復処理します。`P`始めなければなりません。 それぞれについて`i`と`1`、コピーしてみます`P`の中へ`S`位置から開始`i`。 の各キャラクターごとに、`P`、どうかを確認してください`S`はその位置にすでに値を持っています。 一致する場合は、次の文字と一致する必要があります。`P`; そうでなければ解決は不可能です。 
3. すべての必須オカレンスを配置した後、`P`、繰り返します`S`また。 あるところならどこでも`None`、最初の有効な文字に置き換えます。`K`手紙。 簡単にするために、最初の文字を選択します`'a'`。 
4.変換`S`文字列に変換して出力します。 

効果がある理由: すべて`1`バイナリマスクでは強制されるため、`P`必要な位置に正確に発生します。 重複するオカレンス間の競合はステップ 2 で検出され、正確さが保証されます。 未指定の位置はアルファベットから自由に任​​意に入力できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

N, K = map(int, input().split())
P = input().strip()
mask = input().strip()

S = [None] * N
lenP = len(P)

for i, c in enumerate(mask):
    if c == '1':
        start = i
        for j in range(lenP):
            pos = start + j
            if pos >= N:
                print("No solution")
                sys.exit()
            if S[pos] is not None and S[pos] != P[j]:
                print("No solution")
                sys.exit()
            S[pos] = P[j]

alphabet = [chr(ord('a') + i) for i in range(K)]
for i in range(N):
    if S[i] is None:
        S[i] = alphabet[0]

print("".join(S))
```コードはアルゴリズムに直接に従います。 境界外エラーが発生した場合は、慎重に処理します。`1`強制するだろう`P`超える`N`。 競合は文字ごとにチェックされます。 残りの空きポジションは次のように埋められます。`'a'`、許可されるアルファベットの最初の文字。問題の「どの答えも受け入れられる」という条件を満たします。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    N, K = map(int, input().split())
    P = input().strip()
    mask = input().strip()
    S = [None] * N
    lenP = len(P)
    for i, c in enumerate(mask):
        if c == '1':
            start = i
            for j in range(lenP):
                pos = start + j
                if pos >= N:
                    return "No solution"
                if S[pos] is not None and S[pos] != P[j]:
                    return "No solution"
                S[pos] = P[j]
    alphabet = [chr(ord('a') + i) for i in range(K)]
    for i in range(N):
        if S[i] is None:
            S[i] = alphabet[0]
    return "".join(S)

# Provided sample
assert run("5 2\naba\n101\n") == "ababa", "sample 1"

# Custom tests
assert run("4 2\nab\n11\n") == "abba", "overlap allowed"
assert run("3 2\naa\n11\n") == "aaa", "simple overlap"
assert run("5 3\nabc\n1001\n") == "abcaa", "non-overlapping, fill with 'a'"
assert run("2 2\nab\n11\n") == "No solution", "too short to place both occurrences"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 4 2、ab、11 | アバ | 重複する発生 |
 | 3 2、aa、11 | ああ | 同じ文字、重複 |
 | 5 3、abc、1001 | あばか | 空きポジションが正しく埋まりました |
 | 2 2、ab、11 | 解決策はありません | 不可能な配置 |
