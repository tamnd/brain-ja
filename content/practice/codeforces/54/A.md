 ## 解決策
 ## 問題の理解

 私たちはハリネズミが次回受け取るであろうプレゼントの最小数を見積もるよう求められています。`N`日々。 彼にはプレゼントの受け取りに関して 2 つのルールがあります。それは、休日ごとにプレゼントを受け取ること、そしてそれ以上の贈り物をしてはいけないということです。`K`何も受け取らない日々。 今日の現在はすでに計算されているため、1 日目から 1 日目までのみを考慮します。`N`。 

入力すると`N`そして`K`初め。 次に、どの日が休日であるかを通知されます。 目標は、両方の制約を満たすために必要なプレゼントの最小数をカウントすることです。 出力は単一の整数、つまりこの最小値です。 

制約を見てみると、`N`最大 365 ですが、十分小さいです。 これは、おおよそのアルゴリズムであっても、`N^2`操作は 2 秒以内に正常に実行されます。`K`せいぜい`N`、したがって、潜在的に大きなギャップを伴うプレゼントを計画する必要がありますが、それを超えることはありません`K`日々。 祝日は一意でソートされているため、スキャンが簡単になります。 

明らかではないエッジケースとしては、休日が、既にプレゼントを受け取る予定の日と重なっている状況が挙げられます。`K`-日ルール。 たとえば、次の場合`N=5`、`K=2`、休日は`[2,4]`、単純に重要な素朴なアプローチ`ceil(N/K)`休日を追加すると、重複が二重にカウントされます。 もう 1 つの注意が必要なケースは次のような場合です。`K`よりも大きいです`N`; その場合、休日以外のプレゼントはせいぜい 1 つだけ必要になる可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、1 日から 2 日まで毎日シミュレートされます。`N`、プレゼントを最後に受け取った日を追跡します。 毎日、休日かどうかを確認します。`K`最後のプレゼントから数日が経過しました。 いずれかが true の場合、現在のカウントをインクリメントし、最終現在の日付を更新します。 これは両方の制約を直接強制するため機能しますが、`N`小さく、冗長なので、毎日繰り返す必要はありません。 

重要な洞察は、プレゼントは最大でも間隔を開けなければならないことを認識することです`K`日は異なりますが、休日によって特定の日が固定されます。 したがって、最初に休日に貪欲にプレゼントを置き、その後、プレゼントの間の隙間を埋めて、延長がないようにすることができます。`K`日々には現在がありません。 プレゼント間の間隔 (または 0 日目から最初の休日まで、休日の間、および最後の休日から翌日まで) を処理することによって`N`)、単純な整数除算を使用して、追加で必要なプレゼントの数を計算できます。 

これにより、問題は日ごとのシミュレーションから間隔分析に変換されます。 任意の長さの間隔に対して`L`、必要なプレゼントの数は`(L-1)//K + 1`もし`L > 0`。 これは、各プレゼントが対象となるため、機能します。`K`それから数日後。 この式は、間隔全体をカバーするための最小のプレゼント数をカウントします。

 ## アルゴリズムのチュートリアル

 1.読む`N`、`K`、休日のリスト。 すでにプレゼントがある「今日」を表すために、休日リストの先頭に 0 を追加します。 追加`N+1`最後の間隔の処理を簡素化するセンチネルとして。 
2. カウンタの初期化`presents`0にします。 
3. 連続する休日のペアを繰り返します。`start`そして`end`。 インターバルごとに`(start, end)`、プレゼント間の日数を次のように計算します。`end - start - 1`。 この長さが正の場合、次を使用してプレゼントの最小数を計算します。`(length - 1) // K + 1`そしてそれを追加します`presents`。 
4. 出力`presents`。 

それが機能する理由: 不変条件は、すべての休日がすでにプレゼントを受け取り、プレゼント間のすべての間隔が、プレゼントを尊重する公式によってカバーされるということです。`K`-日の最大値。 各インターバルは独立しており、この貪欲な方法でインターバル内にプレゼントを追加することで、ギャップが生じないようにすることができます。`K`日が経ちます。 祝日にはすでにプレゼントがあるため、二重カウントはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

N, K = map(int, input().split())
line = list(map(int, input().split()))
C = line[0]
holidays = line[1:]

# Add today (day 0) and a sentinel after the last day
days = [0] + holidays + [N+1]
presents = 0

for i in range(1, len(days)):
    interval = days[i] - days[i-1] - 1
    if interval > 0:
        presents += (interval + K - 1) // K

print(presents)
```まず入力を読み取り、休日を日数のリストに変換します。 0日目の先頭と末尾`N+1`エッジケースを簡素化します。 連続する「現在」の間隔ごとに、天井分割を使用して必要な最小限の現在を計算します。`(interval + K - 1) // K`。 最後に、合計数が出力されます。 慎重な選択`interval = days[i] - days[i-1] - 1`包含/排他的な日数カウントでよく発生する 1 つずつずれたエラーを回避します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    N, K = map(int, input().split())
    line = list(map(int, input().split()))
    C = line[0]
    holidays = line[1:]
    days = [0] + holidays + [N+1]
    presents = 0
    for i in range(1, len(days)):
        interval = days[i] - days[i-1] - 1
        if interval > 0:
            presents += (interval + K - 1) // K
    return str(presents)

# provided sample
assert run("5 2\n1 3\n") == "3", "sample 1"

# minimum input
assert run("1 1\n0\n") == "1", "single day, no holiday"

# maximum K
assert run("10 10\n2 3 7\n") == "2", "K covers most days"

# all days holidays
assert run("5 1\n5 1 2 3 4 5\n") == "5", "every day a holiday"

# no holidays, K=2
assert run("6 2\n0\n") == "3", "even spacing with K=2"
```| テスト入力 | 期待される出力 | 検証内容 |

 | 10 10 2 3 7 | 2 | 最大 K 値、まばらな休日 |
 | 5 1 5 1 2 3 4 5 | 5 | すべての休日は二重カウントを保証しません |
 | 6 2 0 | 3 | 休日以外の間隔は正しく処理されます。
