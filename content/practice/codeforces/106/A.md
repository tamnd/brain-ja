 ## 解決策
 ## 問題の理解

 私たちには、デュラックのゲームの切り札スーツと 2 枚のカードが与えられます。 課題は、ゲームのルールに従って最初のカードが 2 番目のカードに勝つことができるかどうかを判断することです。 

各カードにはランクとスーツがあります。 ランクは次のように並べられます。```
6 < 7 < 8 < 9 < T < J < Q < K < A
```カードが別のカードに勝つ可能性があるのは、正確に 2 つの状況です。 

両方のカードのスーツが同じ場合は、ランクの高いカードが勝ちます。 

スートが異なる場合、最初のカードは切り札のスートに属している場合にのみ勝ち、2 番目のカードはそうではありません。 

入力サイズは小さく、カード 2 枚と切り札 1 枚だけです。 ここではパフォーマンス上の課題はありません。 定数時間の実装は、制限内で十分に高速です。 

難しいのは、ルールを正しい順序で処理することです。 いくつかのケースは似ていますが、動作が異なります。 

簡単な間違いの 1 つは、ランクに関係なく、切り札は切り札以外のカードに勝つということを忘れることです。 

例えば：```
Trump = H
6H  AS
```正しい答えは次のとおりです。```
YES
```エースは通常のランク順では 6 よりもはるかに強力ですが、ハートのカードは切り札です。 

もう 1 つのよくある間違いは、切り札ではない別のスートの上位カードに勝利を許してしまうことです。 

例えば：```
Trump = D
AS  KC
```正しい答えは次のとおりです。```
NO
```スートは異なり、どちらのカードも切り札ではないため、最初のカードが 2 番目のカードに勝つことはできません。 

3 番目のエッジケースは、両方のカードが切り札である場合です。 そのような状況では、ランク比較が再び重要になります。 

例えば：```
Trump = S
7S  9S
```正しい答えは次のとおりです。```
NO
```どちらのカードも切り札なので、普通にランクを比較すると、7 は 9 よりも弱いです。 

## アプローチ

 この問題を考える強引な方法は、カード間の考えられる勝ちの関係をすべて手動でエンコードすることです。 カードが 36 枚しかないため、理論的にはどのカードが他のどのカードに勝つかを事前に計算してから検索を実行できます。 

カードの数が非常に少ないため、このアプローチは機能します。 完全な比較表には、最大でも次のものが含まれます。```
36 × 36 = 1296
```関係。 

それでも、これは不要です。 ゲームのルールには、直接比較のプロセスがすでに記載されています。 考えられるすべてのペアを保存する代わりに、2 枚のカード間の関係を即座に評価できます。 

重要な観察は、重要な事実は 3 つだけであるということです。 

まず、スーツが等しいかどうか。 

第二に、最初のカードが切り札かどうか。 

第三に、ランクの相対的な順序。 

これらの条件に基づいてルールを整理すると、実装が簡単になります。 

スートが等しい場合は、ランク値を比較します。 

スートが異なる場合、最初のカードが切り札の場合にのみ勝ち、2 番目のカードは切り札ではありません。 

それ以外はすべて負けます。

 | ブルートフォース | O(36²) 前処理 | O(36²) | 受け入れられるが不要 |
 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. トランプ訴訟を読む。 
2. 2 枚のカードを読み取ります。 
3. 各カードをランク​​とスートのコンポーネントに分けます。 
4. 順位を文字列またはマッピングに保存します。```
"6789TJQKA"
```この文字列内のインデックスはカードの強さを表します。 

1. 両方のカードのスーツが同じかどうかを確認します。 

もしそうなら、彼らの順位を比較してください。 最初のカードが 2 番目のカードに勝つのは、そのランク インデックスが大きい場合のみです。 

1. スートが異なる場合は、最初のカードが切り札で、2 番目のカードが切り札でないかどうかを確認します。 

その条件が当てはまる場合は、印刷します`"YES"`。 

1. 残りのすべてのケースでは、印刷します。`"NO"`。 

### なぜ効果があるのか

 アルゴリズムはゲームのルールを直接反映しています。 

スートが一致する場合、ランクのみが重要となるため、ランク インデックスを比較することで正しい勝者が得られます。 

スートが異なる場合、別のカードに勝つ唯一の方法は、切り札以外のカードに対して切り札を使用することです。 アルゴリズムはその状態を正確にチェックします。 

ルールには他に勝利する状況は存在しないため、考えられるすべての入力が正しく処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    trump = input().strip()
    first, second = input().split()

    rank_order = "6789TJQKA"

    r1, s1 = first[0], first[1]
    r2, s2 = second[0], second[1]

    if s1 == s2:
        if rank_order.index(r1) > rank_order.index(r2):
            print("YES")
        else:
            print("NO")
    else:
        if s1 == trump and s2 != trump:
            print("YES")
        else:
            print("NO")

solve()
```解決策は、切り札のスートと 2 枚のカードを読み取ることから始まります。 各カードは正確に 2 文字で表されるため、ランクとスートの抽出は単に文字列にインデックスを付けるだけです。 

文字列`"6789TJQKA"`ランク階層を定義します。 インデックスが大きいほど、カードが強力であることを意味します。 これにより、条件分岐の長いチェーンが回避され、比較ロジックがコンパクトに保たれます。 

最初の主要なブランチでは、スーツが一致するかどうかをチェックします。 その場合、ゲーム ルールではランクのみが重要であるため、インデックスを比較します。 

スートが異なる場合、トランプが関与しない限り、ランクは重要ではなくなります。 このコードは、最初のカードが切り札で、2 番目のカードがそうでないかどうかをチェックします。 それがクロススーツの唯一の勝利条件です。 

微妙な点の 1 つは、より弱い切り札がより強力な非切り札に勝つということです。 スーツが異なる場合にはランク比較がスキップされるため、実装はこれを自動的に処理します。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    trump = input().strip()
    first, second = input().split()

    rank_order = "6789TJQKA"

    r1, s1 = first[0], first[1]
    r2, s2 = second[0], second[1]

    if s1 == s2:
        if rank_order.index(r1) > rank_order.index(r2):
            print("YES")
        else:
            print("NO")
    else:
        if s1 == trump and s2 != trump:
            print("YES")
        else:
            print("NO")

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    backup = sys.stdout
    sys.stdout = out

    solve()

    sys.stdout = backup
    return out.getvalue()

# provided sample
assert run("H\nQH 9S\n") == "YES\n", "sample 1"

# same suit, higher rank wins
assert run("D\nAH KH\n") == "YES\n", "same suit higher rank"

# same suit, lower rank loses
assert run("C\n7S TS\n") == "NO\n", "same suit lower rank"

# trump beats stronger non-trump
assert run("H\n6H AS\n") == "YES\n", "trump overrides rank"

# different suits, no trump involved
assert run("D\nAS KC\n") == "NO\n", "different non-trump suits"

# both trump cards, compare rank normally
assert run("S\nJS QS\n") == "NO\n", "both trump cards"

```スートが異なるため、アルゴリズムは最初のカードが切り札かどうかをチェックします。 そうではない。 勝利ルールが適用されないため、出力は次のようになります。`"NO"`。 

最後に、2つの切り札を考えてみましょう。
