 ## 解決策
 ## 問題の理解

 各ラップトップには、プロセッサ速度、RAM サイズ、HDD サイズ、価格の 4 つの値があります。 3 つの技術的特性すべてにおいて厳密に優れている別のラップトップが同時に存在する場合、そのラップトップは時代遅れとみなされます。 ラップトップが古いかどうかを判断するのに、価格は関係ありません。 

古いラップトップをすべて削除した後、最小コストで残っているラップトップを選択し、その元のインデックスを印刷する必要があります。 

制約はわずかです。 ラップトップの数は最大でも 100 台なので、すべてのラップトップのペアを比較するアルゴリズムであっても完全に安全です。 完全なペアごとの比較は、最大でも$100^2 = 10{,}000$制限時間 2 秒以内であれば簡単なチェックです。 

主な困難はパフォーマンスではなく、支配条件を正しく解釈することです。 ラップトップが時代遅れになるのは、別のラップトップの速度が厳密に大きく、RAM が厳密に大きく、同時に HDD が厳密に大きい場合のみです。 

簡単な間違いの 1 つは、「以上」を十分なものとして扱うことです。 次の入力を考えてみましょう。```
2
2000 1024 100 300
2000 2048 200 250
```2 台目のラップトップは RAM と HDD の点で優れていますが、プロセッサの速度は同等であり、厳密には高速ではありません。 どちらのラップトップも時代遅れではありません。 正しい答えは次のとおりです。```
2
```を使用した不用意な実装`>=`最初のラップトップを誤って取り外してしまう可能性があります。 

もう 1 つのよくあるバグは、古いラップトップをチェックしているときに、価格が無関係であることを忘れることです。 考慮する：```
2
3000 2048 300 900
2500 1024 200 100
```2 台目のラップトップは、はるかに安価ですが、時代遅れです。 正しい答えは次のとおりです。```
1
```一部の実装では、仕様に関係なく、誤って安価なラップトップを保持します。 

いくつかのラップトップが比較にならないという微妙なケースもあります。 例えば：```
3
3000 1024 500 400
2500 4096 300 350
3200 2048 200 300
```それぞれが少なくとも 1 つの属性で負けるため、どちらも他を支配しません。 3 つすべてが候補のままなので、単純に最も安価なラップトップ 3 を選択します。 

## アプローチ

 最も直接的なアプローチは、すべてのラップトップを調べて、他のラップトップがそのラップトップを支配していないかどうかを尋ねることです。 ラップトップ用`i`、すべてのラップトップに対して反復処理を行います`j`。 ラップトップの場合`j`速度、RAM、HDD がラップトップよりもはるかに優れています`i`時代遅れなので破棄できます。 

古くないラップトップをすべて特定した後、それらをスキャンし、価格が最小のものを選択します。 

この強引な方法はすでに十分に高速です。 ラップトップが最大 100 台の場合、比較の総数はわずか 10,000 件です。 各比較では 3 つの整数がチェックされるため、実行時間は実質的に瞬時になります。 

制約が意図的に小さいため、並べ替え、高度なデータ構造、または最適化のトリックは必要ありません。 重要な観察は、問題がちょうど 3 つの属性にわたるペアごとの優越性を問うているということです。 すべてのラップトップが他のすべてのラップトップと相互作用する可能性があるため、完全な比較が最も単純かつ明確な解決策です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 承認済み |
 | 最適 | O(n²) | お(1) | 承認済み |

 この問題に関しては、総当たりの解決策も最適な実用的な解決策です。 

## アルゴリズムのチュートリアル

 1. すべてのラップトップを読み取り、その属性を元の 1 から始まるインデックスとともに保存します。 
2. すべてのラップトップに`i`、最初はそれが古くなっていないことを前提としています。 
3. ノートパソコンの比較`i`他のすべてのラップトップに対して`j`。 
4.ラップトップの場合`j`より優れた速度、より優れた RAM、より優れた HDD を備えている、マーク ラップトップ`i`時代遅れのように。 

これは、問題文の定義と正確に一致します。 等しい値はカウントされません。 
5. すべての比較の後、古いとマークされなかったラップトップのみを保持します。 
6. 残りのラップトップの中から、コストが最小のものを選択します。 
7. 元のインデックスを印刷します。 

### なぜ効果があるのか

 ラップトップは、3 つの技術仕様すべてにおいて他のラップトップが優勢でない場合にのみ有効です。 アルゴリズムは、すべてのラップトップについてこの状態を徹底的にチェックします。 考えられるすべての支配ペアがテストされるため、古いラップトップはフィルタリング ステップを通過できません。 

フィルタリング後、問題はすべての有効な候補の中から最小コストのラップトップを選択することになります。 このアルゴリズムは、残っているすべてのラップトップを 1 回だけスキャンするため、常に正しい最小値が見つかります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    laptops = []

    for i in range(n):
        speed, ram, hdd, cost = map(int, input().split())
        laptops.append((speed, ram, hdd, cost, i + 1))

    best_cost = float('inf')
    best_index = -1

    for i in range(n):
        s1, r1, h1, c1, idx1 = laptops[i]

        outdated = False

        for j in range(n):
            if i == j:
                continue

            s2, r2, h2, c2, idx2 = laptops[j]

            if s2 > s1 and r2 > r1 and h2 > h1:
                outdated = True
                break

        if not outdated and c1 < best_cost:
            best_cost = c1
            best_index = idx1

    print(best_index)

if __name__ == "__main__":
    solve()
```このソリューションでは、出力にはラップトップ データ自体ではなく入力内の位置が必要であるため、すべてのラップトップを元のインデックスとともに保存します。 

ネストされたループは、優位性チェックを直接実装します。 各ラップトップについて、3 つの特性すべてにおいて厳密に優れている別のラップトップを検索します。 の`break`ラップトップが古いことが判明すると、それ以上の比較は不要になるため、これは重要です。 

厳密な比較演算子は、最も重要な実装の詳細です。 交換中`>`と`>=`問題の意味が変わり、属性が等しい場合に誤った結果が生成されます。 

最終的な選択ステップでは、古いテストに合格したラップトップのみが考慮されます。 すべての価格が異なるため、最小コストのラップトップも独自のものになります。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

 | 時間 | O(n²) | すべてのラップトップを他のすべてのラップトップと比較します。

と$n \le 100$、二次解では最大 10,000 回の比較が実行されますが、これは最新のハードウェアとしては非常に小さいです。 メモリ使用量も無視できます。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())
    laptops = []

    for i in range(n):
        speed, ram, hdd, cost = map(int, input().split())
        laptops.append((speed, ram, hdd, cost, i + 1))

    best_cost = float('inf')
    best_index = -1

    for i in range(n):
        s1, r1, h1, c1, idx1 = laptops[i]

        outdated = False

        for j in range(n):
            if i == j:
                continue

            s2, r2, h2, c2, idx2 = laptops[j]

            if s2 > s1 and r2 > r1 and h2 > h1:
                outdated = True
                break

        if not outdated and c1 < best_cost:
            best_cost = c1
            best_index = idx1

    print(best_index)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output.strip()

# provided sample
assert run(
    "5\n"
    "2100 512 150 200\n"
    "2000 2048 240 350\n"
    "2300 1024 200 320\n"
    "2500 2048 80 300\n"
    "2000 512 180 150\n"
) == "4", "sample 1"

# minimum size
assert run(
    "1\n"
    "3000 2048 500 700\n"
) == "1", "single laptop"

# equal attribute edge case
assert run(
    "2\n"
    "2000 1024 100 300\n"
    "2000 2048 200 250\n"
) == "2", "equal speed should not dominate"

# cheaper outdated laptop
assert run(
    "2\n"
    "3000 2048 300 900\n"
    "2500 1024 200 100\n"
) == "1", "price does not affect dominance"

# incomparable laptops
assert run(
    "3\n"
    "3000 1024 500 400\n"
    "2500 4096 300 350\n"
    "3200 2048 200 300\n"
) == "3", "choose cheapest among non-dominated"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 単一のラップトップ | 1 | 最小サイズの入力 |
 | 等速ケース | 2 | 厳密な不等式の処理 |
 | 安い時代遅れのラップトップ | 1 | 優位性チェック中に価格は無視される |
 | 比類のないラップトップ | 3 | 部分的な優位性の正しい処理 |

2

2
