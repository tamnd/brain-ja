 ## 問題の理解

 Doe グラフと呼ばれる再帰的に定義されたグラフのファミリー内の最短経路を計算するように求められます。 各グラフは次数 _n_ によって定義されます。 基本ケースは自明です。_D_(0) は単一の頂点であり、_D_(1) は 1 つのエッジで接続された 2 つの頂点です。 _n_ ≥ 2 の場合、グラフ _D_(n) は、_D_(n-1) と _D_(n-2) を特定の方法で結合することによって形成されます。_D_(n-2) の頂点番号は _D_(n-1) のサイズだけシフトされ、_D_(n-1) と _D_(n-2) の境界頂点を接続する 2 つの新しいエッジが追加されます。 この再帰的な構造はフィボナッチ数列に似ています。_D_(n) の頂点の数は |_D_(n-1)| です。 + |_D_(n-2)|。 

入力により、グラフの次数 _n_ (最大 1000) とクエリの数 _t_ (最大 10^5) が与えられます。 各クエリは、グラフ内のグローバル番号で識別される 2 つの頂点間の最短距離を求めます。 |_D_(1000)| であるため、頂点は 10^16 まで大きくすることができます。 天文学的に大きいです。 各クエリの最短パスの長さを出力するように求められます。 

主な課題は、グラフを明示的に構築することが不可能であることです。 単純な BFS では、すべての |_D_(n)| を保存する必要があります。 頂点の数は、n=1000 の場合、メモリを桁違いに超えます。 さらに、クエリの数が多いため、それぞれに効率的に回答する必要があります。 グラフをシミュレートする不用意なアプローチは、再帰構造の奥深くにある頂点、または最大のインデックスに近い頂点を含むクエリでは失敗します。 

留意すべきエッジ ケースには、左側のサブグラフ _D_(n-1) の両方、右側のサブグラフ _D_(n-2) の両方、およびそれぞれ 1 つの頂点をクエリすることが含まれます。 たとえば、_D_(5) では、最初の頂点 (_D_(4) の最初) と 6 番目の頂点 (_D_(3) の最初の頂点) をクエリするには、再帰ステップで追加された 2 つの「ブリッジ エッジ」を使用する必要があります。 

## アプローチ

 ブルート フォース アプローチは簡単です。隣接リストとして _D_(n) を構築し、クエリごとに BFS またはダイクストラを実行します。 これが機能するのは、BFS が重み付けされていないグラフで最短パスを見つけるためです。 ただし、頂点の数はフィボナッチ数のように指数関数的に増加します: |_D_(n)| ~ φ^n、φ ≈ 1.618。 n=1000 の場合、 |_D_(n)| はおよそ 10^208 であるため、隣接関係に基づくアプローチは不可能になります。 BFS の時間計算量も法外に高く、1 つのクエリでも O(|_D_(n)|) かかります。 

重要な洞察は、Doe グラフが自己相似の再帰的構造を持っているということです。 各 _D_(n) は、正確に 2 つのエッジで結合された _D_(n-1) と _D_(n-2) で構成されます。 これにより、グラフを構築せずに最短パスを再帰的に計算できます。 _D_(n) の頂点 _u_ と _v_ の間のクエリの場合、各頂点がどのサブグラフに属しているかを判断できます。 両方が同じサブグラフ内にある場合、再帰します。 それらが異なるサブグラフにある場合、最短パスは 2 つの接続エッジのいずれかを通過する必要があります。 n までのすべての _D_(k) のサイズを事前計算して境界を効率的に決定し、この再帰的計算を適用します。

 ## アルゴリズムのチュートリアル

 1. k = 0 ～ n のすべてのグラフ _D_(k) のサイズを事前計算します。 しましょう`size[k] = |D(k)|`。 これは、フィボナッチ漸化式を使用すると、n で線形になります。`size[k] = size[k-1] + size[k-2]`。 これにより、頂点がどのサブグラフに属しているかを迅速に判断できます。 
2. 再帰関数を定義する`dist(n, u, v)`頂点間の最短距離を返します`u`そして`v`グラフ_D_(n)内。 
3. 基本ケース: n = 0 の場合、グラフには単一の頂点があるため、クエリは実行できません。 n = 1 の場合、u と v が異なる場合、距離は 1 になります。 
4. u と v がどこにあるかを決定します。 

- 両方が ≤ size[n-1] の場合、_D_(n-1) にあります。 で再帰する`dist(n-1, u, v)`。 
- 両方とも > size[n-1] の場合、それらは _D_(n-2) にあります。 シフトインデックス:`u' = u - size[n-1]`、`v' = v - size[n-1]`、そして再帰的に`dist(n-2, u', v')`。 
5. u が _D_(n-1) にあり、v が _D_(n-2) にある場合 (またはその逆)、最短パスは 2 つの接続エッジのいずれかを使用する必要があります。`(size[n-1], size[n-1]+1)`そして`(size[n-1]+1, 1)`。 両方のオプションのパスの長さを計算します。 

- 最初のエッジを通るパス:`dist(n-1, u, size[n-1]) + 1 + dist(n-2, 1, v')`- 2 番目のエッジを通るパス:`dist(n-1, u, 1) + 1 + dist(n-2, 1, v')`(インデックス作成に応じて調整します)

 2 つのうちの最小値を取ります。 
6. 計算された最小距離を返します。 基本ケースに到達するまで、これを再帰的に適用します。 

これが機能する理由: 再帰はグラフの構造を反映しています。 各頂点は、2 つのサブグラフの 1 つに完全に収まるか、2 つの接続エッジの 1 つを通過する必要があります。 これら 2 つのエッジ オプションではすべての可能な最小パスが考慮されるため、これによりアルゴリズムが最短パスを見つけることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(3000)

# Precompute sizes of D(k)
n_max = 1000
size = [0] * (n_max + 1)
size[0] = 1
size[1] = 2
for k in range(2, n_max + 1):
    size[k] = size[k-1] + size[k-2]

def dist(n, u, v):
    if n == 0:
        return 0  # only one vertex, no path possible
    if n == 1:
        return 1  # two vertices connected
    if u > v:
        u, v = v, u

    if v <= size[n-1]:
        return dist(n-1, u, v)
    elif u > size[n-1]:
        return dist(n-2, u - size[n-1], v - size[n-1])
    else:
        # u in D(n-1), v in D(n-2)
        d1 = dist(n-1, u, size[n-1]) + 1 + dist(n-2, 1, v - size[n-1])
        d2 = dist(n-1, u, 1) + 1 + dist(n-2, 1, v - size[n-1])
        return min(d1, d2)

t, n = map(int, input().split())
for _ in range(t):
    a, b = map(int, input().split())
    print(dist(n, a, b))
```このソリューションでは、トップダウンの再帰的アプローチが使用されます。 の`size`配列を使用すると、頂点が _D_(n-1) に属するか _D_(n-2) に属するかをすぐに判断できます。 再帰では、2 つの接続エッジを考慮して、2 つのサブグラフ間の境界を越える処理が慎重に処理されます。 n = 1000 までの安全な再帰を保証するために、Python の再帰制限を 3000 に増やします。
