 ## 解決策
 ## 問題の理解

 その木は毎年新しい葉を出します。 年に$i$、成長します$i^i$葉。 葉は永遠に残るわけではありません。 年に作られた葉っぱ$i$正確に木の上に残ります$k$年、つまり何年にもわたって存在することを意味します$i, i+1, \dots, i+k-1$。 

特定の年について$n$、現在木にある葉の総数が偶数か奇数かを判断する必要があります。 

その年に成長した葉$i$年にはまだ存在します$n$もし、そしてその場合に限り$$i \le n \le i+k-1.$$並べ替えると$$n-k+1 \le i \le n.$$年はから始まりますので、$1$、その年に見られる紅葉$n$間から来る$$\max(1, n-k+1), \dots, n.$$制約は、直接シミュレーションが不可能であることを示す最初の手がかりです。 両方$n$そして$k$と同じ大きさにすることができます$10^9$、最大まであります$10^4$テストケース。 何年にもわたって反復されるソリューションでは、最悪の場合、数十億回の操作が必要になります。 

答えは、葉の総数が偶数かどうかだけを尋ねます。 つまり、実際のリーフ数ではなく、パリティのみを考慮します。 この観察により、膨大な数の算術問題が単純な計数問題に変わります。 

よくある間違いは、10^9^{10^9} などの値を計算しようとすることです。 パリティは値が奇数か偶数かによってのみ決まるため、これらの数値は想像を絶するほど大きく、まったく不要です。 

もう 1 つの簡単な間違いは、最後のものだけを忘れることです。$k$年が貢献します。 例えば：```
n = 5, k = 2
```たった数年$4$そして$5$案件。 からすべての年を使用$1$を通して$5$間違った答えが生まれてしまいます。 

3 番目の微妙なケースは次の場合に発生します。$k=1$。 それから一年だけ$n$貢献します。 例えば：```
n = 1, k = 1
```木にはまさに$1^1=1$葉は奇数なので、答えは次のようになります。`NO`。 

## アプローチ

 ブルートフォース ソリューションでは、毎年誰の葉がまだ生きているかを特定し、$i^i$、それらを合計し、最終的な合計の等価性を確認します。 

活動年数は、$$n-k+1,\dots,n.$$巨大なサイズを無視しても、$i^i$、このアプローチでは、次までの繰り返しが必要です。$10^9$年。 と$10^4$テストケースでは、操作数が完全に不可能になります。 

重要な点は、パリティが実際の値よりもはるかに単純であるということです。 

考慮する$i^i$。 

もし$i$偶数であれば、$i^i$は均等です。 

もし$i$それは奇妙です、それでは$i^i$奇数です。 

したがって、次のパリティは$i^i$はまさに次のパリティです$i$。 

葉の数の合計の同等性は、奇数年の貢献度にのみ依存します。 偶数年ごとに偶数が与えられ、パリティには影響しません。 

アクティブな間隔には以下が含まれます$$[n-k+1,\, n].$$この区間内の奇数の整数の数が奇数であれば、リーフの総数は奇数になります。 この区間内の奇数の整数の数が偶数であれば偶数です。 

ここで必要なのは、連続した間隔内の奇数の数のパリティだけです。 

連続する 2 つの整数のうち、ちょうど 1 つが奇数になります。 つまり、奇数カウントのパリティは間隔の長さだけに依存します。$k$。 

もし$k$が偶数の場合、間隔には正確に次の値が含まれます$k/2$奇数と$k/2$丁数。 答えは次のいずれかによって決まります。$k/2$偶数または奇数です。 

さらに単純な観察もあります。 させて$$S = \sum_{i=n-k+1}^{n} i^i.$$モジュロ$2$、$$S \equiv \sum_{i=n-k+1}^{n} i.$$和のパリティは、奇数項の数のパリティと等しくなります。 任意の長さの間隔で$k$、奇数の数が奇数になるのは次のとおりです。$k \bmod 4$は$1$または$2$、そして正確にいつでも$k \bmod 4$は$0$または$3$。 

終了年を調べると、さらに明確な導出が得られます。$n$。 パリティのみが重要であるため、受け入れられた解決策は、間隔内の奇数を数えるというものになります。 結果のパリティは次のもののみに依存します。$k$。

 | 最適 |$O(1)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、葉がまだ存在する年の間隔を決定します。$$[n-k+1,\; n].$$2. 観察してください$i^i$と同じパリティを持っています$i$。 用語ごとに置き換える$i^i$そのパリティ寄与によって。 
3. 区間内に奇数の整数がいくつあるかを数えます。 
4. 奇数の個数が偶数の場合、出力`YES`葉の総数が偶数だからです。 
5. それ以外の場合は出力`NO`。 

奇数の整数の数を求める便利な公式$1$を通して$x$は$$\left\lfloor \frac{x+1}{2} \right\rfloor.$$したがって、次の奇数整数の数は$[L,R]$は$$\left\lfloor \frac{R+1}{2} \right\rfloor - \left\lfloor \frac{L}{2} \right\rfloor.$$このカウントのパリティのみが重要です。 

### なぜ効果があるのか

 すべての偶数塩基は偶数乗を生成し、すべての奇数塩基は奇数乗を生成します。 モジュロ$2$、各学期$i^i$まったく同じように動作します$i$。 

したがって、総葉数のパリティは、奇数年の貢献葉数のパリティとなります。 アルゴリズムは、アクティブな間隔の量を正確に計算します。 奇数の寄与者の数が偶数であれば、葉の総数は偶数になります。 数が奇数の場合、葉の総数は奇数になります。 すべてのステップでパリティが維持されるため、アルゴリズムは常に正しい答えを生成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
ans = []

for _ in range(t):
    n, k = map(int, input().split())

    l = n - k + 1

    odd_count = (n + 1) // 2 - (l // 2)

    if odd_count % 2 == 0:
        ans.append("YES")
    else:
        ans.append("NO")

print("\n".join(ans))
```最初のステップでは、アクティブな間隔を計算します。$[n-k+1,n]$。 これらはまさに葉が生きている年です
