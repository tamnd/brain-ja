 ## 解決策
 ## 問題の理解

 テスト ケースごとに 3 つの整数を受け取ります。 タスクは、これら 3 つの数値のいずれか 1 つが他の 2 つの数値の合計として表現できるかどうかを判断することです。 

値が 3 つしかないため、条件が true になる可能性は正確に 3 つあります。 

もし`a + b = c`、 または`a + c = b`、 または`b + c = a`。 

制約は非常に小さいです。 テスト ケースの最大数でも 9261 にすぎず、各テスト ケースには 0 から 20 までの整数が 3 つだけ含まれています。これは、考えられるすべての関係を直接チェックする余裕があることを意味します。 総作業量は少なく、テスト ケースごとに数回の算術演算のみです。 

ゼロが含まれる場合、微妙なエッジケースが発生します。 

考慮する：```
0 0 0
```正しい答えは、`YES`なぜなら`0 + 0 = 0`。 合計が加数よりも厳密に大きくなければならないと仮定する不注意な解決策は、誤った結果を返します。`NO`。 

別の特殊なケースは、すべての数値が等しいがゼロではない場合に発生します。```
20 20 20
```正しい答えは、`NO`。 どの数値も他の 2 つの合計と等しくありません。`20 + 20 = 40`。 2 つの値が等しいかどうかだけをチェックする不注意なソリューションでは、誤って結果が返される可能性があります。`YES`。 

もう 1 つのケースは、特定の位置に最大の数が与えられていない場合です。```
15 7 8
```正しい答えは、`YES`なぜなら`7 + 8 = 15`。 チェックのみを行うソリューション`a + b == c`この有効な構成が失われます。 

## アプローチ

 最も直接的な総当り攻撃のアイデアは、ターゲット番号のあらゆる選択肢をテストすることです。 数値は 3 つだけなので、最初の数値が他の 2 つの合計に等しいかどうか、2 番目の数値が他の 2 つの合計に等しいかどうか、3 番目の数値が他の 2 つの合計に等しいかどうかを確認できます。 

この 3 つのチェックは、1 つの数値が残り 2 つの数値の合計になるすべての方法を正確にカバーするため、このアプローチは正しいです。 

各テスト ケースについて、3 つの加算と 3 つの比較を実行します。 最大 9261 のテスト ケースでも、これは数万回の操作にすぎず、取るに足らないものです。 

重要な観察は、問題自体にはすでに考えられるケースが 3 つしかないということです。 並べ替えや検索などの複雑なテクニックは必要ありません。 タスク全体は、3 つの有効な方程式を直接評価することに帰着します。 

ここでは、探索空間が一定であるため、総当たり解と最適解は事実上同じです。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. 各テスト ケースについて、次の内容を読んでください。`a`、`b`、 そして`c`。 
3. かどうかを確認します。`a + b == c`。 

これが真であれば、1 つの数値は他の 2 つの数値の合計となるため、答えは次のようになります。`YES`。 
4. かどうかを確認します。`a + c == b`。 

これは、2 番目の数値が合計である場合をカバーします。 
5. かどうかを確認します。`b + c == a`。 

これは、最初の数値が合計である残りの可能性をカバーします。 
6. 3 つのチェックのうち少なくとも 1 つが true の場合、出力します。`YES`。 それ以外の場合は印刷します`NO`。 

### なぜ効果があるのか

 3 つの数値のうち 1 つだけが、次の 3 つの方程式の 1 つにおける他の 2 つの合計になる可能性があります。`a + b = c`、`a + c = b`、 または`b + c = a`。 

アルゴリズムは 3 つの可能性をすべてチェックします。 有効な関係が存在する場合、これらの比較のいずれかが成功し、アルゴリズムは次のように出力します。`YES`。 3 つの比較がすべて失敗した場合、他の 2 つの合計に等しい数値はないため、正しい答えは次のようになります。`NO`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    a, b, c = map(int, input().split())

    if a + b == c or a + c == b or b + c == a:
        print("YES")
    else:
        print("NO")
```最初の行はテスト ケースの数を読み取ります。 各反復で 3 つの整数を読み取ります。 

内部の状態は、`if`ステートメントは、アルゴリズムで説明した 3 つの方程式を直接実装します。 論理和を使用すると、答えは次のようになります。`YES`有効な合計関係が見つかるとすぐに。 

3 つの可能性をすべてチェックすること以外に、境界条件に関する懸念はありません。 数値は非常に小さいため、Python では整数のオーバーフローは不可能です。 すべての有効な構成がテストされるため、チェックの順序は重要ではありません。
