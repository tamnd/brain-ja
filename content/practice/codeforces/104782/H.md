 ## 解決策
 ## 問題の理解

 無限グリッド上の一連の点が与えられます。各点はニューロンを表し、色でタグ付けされています。 各クエリには、色のシーケンスも与えられます。 実際のニューロンのシーケンスを、カラー シーケンスの各位置に 1 つずつ構築する必要があり、同じニューロンを複数回再利用できます。 

構築されたシーケンスのコストは、連続して選択されたニューロン間のマンハッタン距離の合計として定義されます。 クエリ内の各位置について、その位置で必要な色と一致する色を持つニューロンを選択し、総パス コストを最大化したいと考えています。 

したがって、実際のタスクは次のとおりです。カラー シーケンスが与えられたクエリごとに、連続して選択されたポイント間のマンハッタン距離の合計が最大になるように、位置ごとに 1 つのポイントを (許可されたカラー クラスから) 選択します。 

制約が十分に大きいため、ニューロンに対するクエリごとの二次推論は不可能です。 最大 2×10^5 のニューロンと最大 2×10^5 のクエリを使用でき、クエリの合計の長さは最大 5×10^5 になります。 これは、連続する色間の各遷移は一定時間または対数時間で処理する必要があり、2 つの色クラス間のすべての点を直接ペアリングすることを伴うものは遅すぎることをすでに示唆しています。 

素朴な解釈では、クエリ内の隣接する色のペアごとに、2 つのセットから最適なニューロンのペアを計算しようとします。 この考えは構造的には正しいですが、すべてのペアをチェックして再計算するのはコストがかかりすぎます。 

クエリ内で色が複数回出現する場合、微妙なエッジ ケースが発生します。 ニューロンの再利用が許可されているため、各位置の選択は隣接性を除いて独立しています。 間違った貪欲な解釈では、色ごとに単一の最適な代表をグローバルに選択して再利用しようとしますが、最適な選択はグローバルな代表ではなく、シーケンス内の隣接する両方の色に依存するため失敗します。 

たとえば、ある色には (0,0) と (100,0) に点があり、別の色には (0,100) と (100,100) に点があるとします。 方向に応じて、異なるコーナーが最適となるため、色ごとに単一の固定代表では情報が失われます。 

## アプローチ

 ブルートフォースアプローチのアイデアは単純です。 各クエリおよび隣接する色のペアごとに、最初のカラー セットと 2 番目のカラー セットからのニューロンのすべてのペアを試し、それらのマンハッタン距離を計算し、最大値を取得します。 各ステップは 2 つの連続する位置のみに依存するため、これは正しいです。 ただし、カラー クラスに k 個のポイントがある場合、各遷移のコストは O(k²) となり、最悪の場合、クエリごとに O(n²) にまで縮退し、これは許容範囲をはるかに超えています。 

重要な観察は、マンハッタン距離にはペアの列挙を回避できる構造があるということです。 式 |x1 − x2| + |y1 − y2| 線形形式を使用して書き換えることができます。 任意の 2 点の距離は、(±x ± y) の差の 4 つの符号構成にわたる最大値です。 これにより、2 つのセット間のマンハッタン距離を最大化する問題が、単純な投影の極値の比較に変換されます。 

各色について、すべての点を保持する代わりに、変換された 2 つの座標 x + y と x − y の極値のみを保存する必要があります。 これらがわかったら、色 A の任意の点と色 B の任意の点の間の最大マンハッタン距離の計算は、これらの投影全体の最大値と最小値を比較することで一定時間に短縮されます。 

これにより、クエリ内の各遷移が O(1) に削減され、ソリューション全体がクエリの合計サイズにおいて線形になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(クエリの合計の長さ × カラーごとのポイント²) | O(n) | 遅すぎる |
 | 最適 | O(n + クエリの合計長) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 まずニューロンを前処理します。

1. 各色について、x + y の最小値と最大値、および x − y の最小値と最大値の 4 つの値を維持します。 これらをすべてのニューロンに対して 1 回のパスで計算します。 これにより、各カラー クラスが一定サイズの情報に圧縮され、極端な場合に関連するすべてのマンハッタン距離の動作が保存されます。 
2. クエリごとに、指定されたカラー シーケンスを繰り返します。 
3. 色 c と d の隣接するすべてのペアについて、事前に計算された値を使用して、色 c のニューロンと色 d のニューロンの間の可能な限り最適なマンハッタン距離を計算します。 
4. この遷移値を計算するために、2 つの投影を個別に評価します。 射影 x + y の場合、最適なクロスペアは max(c) − min(d) または max(d) − min(c) から得られます。 これら 2 つの最大値を採用します。 x − y についても同じことを行います。 
5. その推移の答えは、2 つの予測の最大値です。 クエリの回答に追加します。 
6. クエリの長​​さが 1 の場合、遷移が存在しないため、答えは 0 になります。 

微妙な点は、投影ごとに両方の方向を考慮する必要があるということです。 どちらのセットがより大きな極端値を提供するかに応じて、どちらの側からも最適な組み合わせが得られる可能性があります。 

### なぜ効果があるのか

 2 点間のマンハッタン距離は、それらの座標の 4 つの一次関数の最大値として表現できます。 これは、2 組の点の間で、これらの直線方向の少なくとも 1 つで極端なペアによって最大可能な距離が実現されなければならないことを意味します。 色ごとに x + y および x − y の最小値と最大値のみを保存することで、これらの極端な候補を正確に保存します。 すべての最適なペアはこれらの境界値のいずれかで表される必要があるため、内部点によって答えが改善されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = 10**30

n = int(input())
mn_sum = {}
mx_sum = {}
mn_diff = {}
mx_diff = {}

for _ in range(n):
    x, y, c = map(int, input().split())
    s = x + y
    d = x - y

    if c not in mn_sum:
        mn_sum[c] = INF
        mx_sum[c] = -INF
        mn_diff[c] = INF
        mx_diff[c] = -INF

    mn_sum[c] = min(mn_sum[c], s)
    mx_sum[c] = max(mx_sum[c], s)
    mn_diff[c] = min(mn_diff[c], d)
    mx_diff[c] = max(mx_diff[c], d)

def best(c, d):
    if c == d:
        return 0

    ans = 0

    ans = max(ans, mx_sum[c] - mn_sum[d])
    ans = max(ans, mx_sum[d] - mn_sum[c])

    ans = max(ans, mx_diff[c] - mn_diff[d])
    ans = max(ans, mx_diff[d] - mn_diff[c])

    return ans

t = int(input())
out = []

for _ in range(t):
    tmp = list(map(int, input().split()))
    m = tmp[0]
    arr = tmp[1:]

    res = 0
    for i in range(m - 1):
        res += best(arr[i], arr[i + 1])

    out.append(str(res))

print("\n".join(out))
```前処理ステップでは、色ごとに 4 つの極値を構築します。 各更新は一定時間であるため、完全な前処理はニューロンの数において線形です。 

の`best`関数はマンハッタン削減をエンコードします。 最適なペアリングはどちらの側からも得られる可能性があるため、明示的に両方向をチェックします。 同じニューロンを再利用する場合、2 つの同じ色を選択しても距離は強制されないため、自己遷移の場合はゼロを返します。 

各クエリは、パス コストの分解と一致する、隣接する色のペアにわたる遷移コストを合計することによって処理されます。 

よくある実装上の間違いは、4 方向のチェックの 1 つを忘れたり、対称性を誤って仮定したりすることです。 もう 1 つは、x と y の最小/最大を個別に扱うことですが、マンハッタン距離は座標を結合するため、これでは不十分です。 

## 実用的な例

 2 色を使用した小さなセットアップを考えてみましょう。 

色 1 には点 (0, 0) と (10, 0) があります。 色 2 には点 (0, 5) と (10, 5) があります。 クエリは [1, 2, 1] です。 

色ごとに次を計算します。 

カラー 1: x+y は {0, 10}、x−y は {0, 10}

 色 2: x+y は {5, 15}、x−y は {-5, 5}

 次に、遷移を評価します。 

| 移行 | 最良の x+y の差 | 最良の xy 差 | 結果 |
 | --- | --- | --- | --- |
 | 1→2 | max(10−5, 15−0) = 15 | max(10−(-5), 5−0) = 15 | 15 |
 | 2→1 | max(15−0, 10−5) = 15 | max(5−0, 10−(-5)) = 15 | 15 |

 合計は30です。 

このトレースは、同じ色にはクエリ全体で一貫したポイントの選択が必要ないことを示しています。 各遷移は独立して極端な組み合わせを選択します。 

ここで、単色のクエリ [1, 1, 1] を考えてみましょう。 すべての位置は同じニューロンを再利用できるため、すべての遷移の寄与はゼロになります。 その色に存在するポイントの数に関係なく、出力は 0 です。 これにより、自己遷移が正しく折りたたまれることが確認されます。

 ## 特殊なケース

 主なエッジケースは、色が連続した位置に現れる場合です。 この状況では、両方の位置で同じニューロンを再利用できるため、遷移は常にゼロに寄与するはずです。 このアルゴリズムは、両方の色が等しい場合に明示的にゼロを返すため、誤って距離が導入されることはありません。 

別の特殊なケースには、単一のニューロンのみを含む色が含まれます。 それでも、最小値と最大値が同じ値に崩壊し、その色に関係するすべての遷移が決定的になるため、極値構造は依然として機能します。 アルゴリズムは、初期化以降の特別なケースを使用せずに、これを自然に処理します。 

最後の微妙なケースは、最適な遷移が異なる方向の異なる投影から得られる場合です。 このアルゴリズムは、x + y および x − y の極値を独立して評価し、最大値をもたらす投影が遷移ごとに選択されるようにするため、これを処理します。
