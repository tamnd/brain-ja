 ## 解決策
 ## 問題の理解

 長さの整数シーケンスを数えています$K$、すべてのエントリは厳密に正であり、その合計は次のように固定されます。$S$。 追加の制約は構造的なものです。ある長さの連続したブロックを取得する場合、$T$、そのようなすべてのブロックにはまったく同じ積が含まれます。 したがって、位置の積$1$を通して$T$、$2$を通して$T+1$、などまで$K-T+1$を通して$K$、すべて等しい必要があります。 

和の制約はグローバルですが、積の制約はローカルですが、すべてのスライディング ウィンドウにわたって繰り返されます。 重要な問題は、積の状態が隣接する位置を非加算的な方法で結合することです。これは、剛構造に崩壊しない限り、通常は指数関数的な挙動を示唆します。 

制約により許可されるのは、$K, S, T$まで$5 \cdot 10^6$。 これにより、二次関数は即座に除外されます。$K$または$S$。 平$O(S \log S)$重い定数を使用する場合は境界線に達するため、最終的な解決策は問題を 1 つの合計または少数の組み合わせ式に減らす必要があります。 

製品の制約を「独立した窓」として扱おうとすると、微妙な故障モードが現れます。 たとえば、各ウィンドウが個別の条件を課していると考える人もいるかもしれませんが、それらはかなり重なり合っています。 もう 1 つのよくある落とし穴は、隣接する制約のみが重要であると仮定することです。 しかし、条件は局所的な不平等ではなく、大域的な周期構造です。 

小さな例ですでに構造が示されています。$T = 3$、製品の品質$(a_1 a_2 a_3) = (a_2 a_3 a_4)$力$a_1 = a_4$。 すべてのウィンドウにわたってこれを繰り返すと、ピリオド付きの定期的な繰り返しが強制されます。$T$、これが本当の構造崩壊です。 

## アプローチ

 ブルートフォースアプローチでは、すべての正のシーケンスを合計して生成しようとします。$S$窓ごとに製品の状態を確認します。 の作曲数$S$の中へ$K$ポジティブな部分は$\binom{S-1}{K-1}$すでに膨大であり、各シーケンスのコストを確認する$O(K)$。 これは、中程度の値であっても、すぐに実現可能性を超えて爆発します。 

重要な観察は、等積制約が重なると強い再発が強制されるということです。 連続するウィンドウを比較すると、$$a_1 a_2 \cdots a_T = a_2 a_3 \cdots a_{T+1}$$これにより、共通因数が即座にキャンセルされ、次の結果が得られます。$a_1 = a_{T+1}$。 この引数を配列全体でシフトすると、次のようになります。$$a_i = a_{i+T}$$すべての有効なインデックスに対して。 したがって、シーケンスは最初のシーケンスによって完全に決定されます。$T$要素とピリオド付きの繰り返し$T$ただし、切り詰められた接尾辞の場合は除きます。 

したがって、問題は選択に帰着します$T$正の整数$x_1, \dots, x_T$ただし、シーケンスの長さが異なるため、最終的な合計の多重度は等しくありません。$K$で割り切れないかもしれない$T$。 

させて$K = qT + r$、 と$0 \le r < T$。 それから最初の$r$期間内のポジションが表示されます$q+1$回、残りは$T-r$ポジションが表示されます$q$全長の倍$K$。 これにより、合計制約が加重線形方程式に変換されます。 

ここで、単一の重み付き方程式に対する正の整数の解をカウントする必要があります。 これは古典的な母関数係数の問題になりますが、異なる重みが 2 つだけあるため、きれいな組み合わせ分解が可能になります。

 ## アルゴリズムのチュートリアル

 ### ステップ 1: 積の制約を周期性に還元する

 連続したウィンドウ商品を比較し、共通条件を解除します。 これにより、すべての者間の平等が強制されます。$a_i$そして$a_{i+T}$。 配列は最初の配列によって完全に決定されます。$T$価値観。 

### ステップ 2: 各位置の出現を数える

 書く$K = qT + r$。 次に位置$1$に$r$現れる$q+1$完全なシーケンス内の時間と位置$r+1$に$T$現れる$q$回。 これにより、合計制約が最初の重み付き合計に変換されます。$T$変数。 

### ステップ 3: 非負の変数にシフトする

 しましょう$x_i \ge 1$。 代わりの$x_i = y_i + 1$、 それで$y_i \ge 0$。 方程式は、ターゲットがシフトされた線形ディオファントス制約になります。$$\sum w_i y_i = S - \sum w_i$$### ステップ 4: 重みのタイプごとに変数を分割する

 重みは 2 つだけです。$a = q$そして$b = q+1$。 ありましょう$T-r$重みの変数$a$、 そして$r$重みの変数$b$。 それに応じて変数をグループ化します。 

### ステップ 5: 2 つの独立した合計変数に変換する

 しましょう$A$1 ウェイト ステップ単位での最初のグループの合計寄与度であり、$B$2番目のグループの場合。 方程式は次のようになります。$$aA + bB = S'$$実現可能な範囲で繰り返します$A$、決定します$B$有効な場合は一意に。 

### ステップ 6: 各グループ内の分布を数える

 固定用$A$、全体に分散する方法の数$T-r$変数は次のとおりです。$$\binom{A + (T-r) - 1}{T-r - 1}$$同様に、$B$以上$r$変数:$$\binom{B + r - 1}{r - 1}$$### ステップ 7: すべての有効な分割を合計する

 すべてを繰り返します$A$そのような$S' - aA$で割り切れます$b$、計算する$B$、組み合わせカウントの積を累積します。 

### なぜ効果があるのか

 変換全体は、積制約がシーケンスを厳密な周期構造に崩壊させるという事実に依存しています。 周期性が強制されると、元の非線形状態は完全に消えます。 残るのは、独立変数に対する重み付き整数分割問題です。 各グループ内の独立性は、固定整数の合計を同一のビンに分散するという標準的な「星と棒」の解釈から得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    K, S, T = map(int, input().split())
    
    q, r = divmod(K, T)
    
    a = q
    b = q + 1
    
    # number of variables of each type
    cnt_b = r
    cnt_a = T - r
    
    # minimal sum (all x_i = 1)
    min_sum = a * cnt_a + b * cnt_b
    S -= min_sum
    
    if S < 0:
        print(0)
        return
    
    # precompute factorials up to S
    n = S + max(cnt_a, cnt_b) + 5
    fact = [1] * (n + 1)
    invfact = [1] * (n + 1)
    
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD
    
    invfact[n] = pow(fact[n], MOD - 2, MOD)
    for i in range(n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD
    
    def C(n, k):
        if n < 0 or k < 0 or n < k:
            return 0
        return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD
    
    ans = 0
    
    if cnt_a > 0:
        for A in range(0, S // a + 1):
            rem = S - a * A
            if rem % b != 0:
                continue
            B = rem // b
            if B < 0:
                continue
            waysA = C(A + cnt_a - 1, cnt_a - 1) if cnt_a > 0 else (1 if A == 0 else 0)
            waysB = C(B + cnt_b - 1, cnt_b - 1) if cnt_b > 0 else (1 if B == 0 else 0)
            ans = (ans + waysA * waysB) % MOD
    else:
        # only one weight type
        if S % b == 0:
            B = S // b
            ans = C(B + cnt_b - 1, cnt_b - 1)
    
    print(ans % MOD)

if __name__ == "__main__":
    solve()
```実装は、積制約を周期性から導出された 2 つの重み構造に変換することから始まります。 最小合計の減算により、すべての変数が負でないことが保証されます。これは、組み合わせ解釈に必要です。 

階乗および逆階乗は、高速な二項係数クエリをサポートするために事前計算されています。 メイン ループは最初のグループの合計寄与度を反復し、有効な各分割は 2 つの独立した組み合わせカウントの積に寄与します。 

実装でよくある落とし穴は、各グループが順列問題ではなく合成問題であることを忘れていることです。 このため、単純な累乗ではなく星と棒の公式が使用されます。

 ## 特殊なケース

 重要なエッジケースの 1 つは次のような場合です。$K < T$。 この状況では、スライディング ウィンドウがないため、製品の制約によって制限がまったく課されません。 アルゴリズムは引き続き正しく動作します。$q=0$、すべての重みが 1 になり、問題は標準的な構成数に減ります。 

もう一つのエッジケースは、$r=0$ここで、配列は完全に周期的であり、剰余はありません。 この場合、すべての変数の重みは同じになります$q$、アルゴリズムは単一グループの星と棒の計算に崩壊します。 ループオーバー$A$まだ機能しますが、有効な位置合わせが 1 つだけ存在します。 

最後のエッジケースは、最小構成を減算した後に調整後の合計がマイナスになる場合です。 これは、正のシーケンスがすべて 1 のベースラインよりも小さい合計を達成できないため、正しくゼロ構成を生成します。
