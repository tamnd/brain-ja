 ## 解決策
 ## 問題の理解

 いくつかのテストケースが与えられています。 各テスト ケースにはスティックの長さのコレクションがあります。 このコレクションから、平面内で自由に回転して再配置した後、4 本の棒すべてを辺として使用して平行四辺形を形成できるような 4 本の異なる棒を選択できるかどうかを知りたいと考えています。 

平行四辺形には、2 組の等しい対辺があります。 したがって、選択した 4 つのスティックの長さのうち、2 つの等しいペアにできる必要があります。 言い換えると、選択した 4 つの値を並べ替えると、次のようになります。$x, x, y, y$いくつかの正の長さの場合$x$そして$y$。 入力での選択の順序は、個別のインデックスを超えて重要ではありません。 

入力サイズが大きい: すべてのテスト ケースにわたるスティックの合計数が達する可能性があります。$2 \cdot 10^5$、まであります$10^4$テストケース。 これにより、すべてのクアドルプルを明示的にチェックしようとするソリューションは即座に除外されます。$n = 2 \cdot 10^5$作るだろう$O(n^4)$または$O(n^3)$不可能。 

重要な制約は、スティックの長さが次の制限を受けることです。$n$これは、周波数ベースの推論がテスト ケースごとに線形または線形に近い時間で可能であることを示唆しています。 

多くの値が同一である場合、微妙なエッジケースが発生します。 たとえば、すべてのスティックが次のように等しい場合、$[1, 1, 1, 1]$の場合、すべての辺が等しい平行四辺形を形成できるため、答えは明らかに YES です。これは特殊な場合です。 もう 1 つのエッジ ケースは、次のように、正確に 2 つの異なる値があるが、十分な繰り返しがない場合です。$[1, 1, 2, 3]$、ペアはあるかもしれないが、2 つの完全なペアを形成することはできません。 

単純な間違いは、個別のインデックスを確保せずに、「配列内の任意の 2 つのペアで十分である」と考えることです。 たとえば、値が次の場合、$[1, 1, 2]$、1 のペアがあるため 2 つのペアを形成できると誤って考えるかもしれませんが、それでも別のペアが必要ですが、それは存在しません。 

## アプローチ

 強引なアプローチでは、すべての 4 回転を試すことになります。$i < j < k < p$、4 つの値を確認し、それらが 2 つの等しいペアに分割できるかどうかをテストします。 これは正しいです。4 つのスティックの可能な選択をすべて徹底的に試しているからです。 ただし、4倍の数は、$\binom{n}{4}$として成長します。$O(n^4)$。 たとえ$n = 2000$、これはすでに遅すぎます、そしてここで$n$までです$2 \cdot 10^5$、完全に実行不可能になります。 

条件の構造によって問題が単純化されます。 区別性を確保すること以外には、どのインデックスがペアを形成するかは気にしません。 重要なのは、それぞれ少なくとも 2 回出現する少なくとも 2 つの異なる値が存在するかどうかだけです。 値が 4 回出現する場合、同じ長さの 2 つのペアを形成できるため、これも機能します。 2 つの異なる値がそれぞれ少なくとも 2 回出現する場合、各値に 1 つのペアを割り当てることができます。 

したがって、問題は頻度の問題に帰着します。多重度を慎重に数えながら、等しい値のペアが少なくとも 2 つ存在するかどうかを確認する必要があります。 頻度が少なくとも 4 の 1 つの値はすでに 2 つのペアに寄与しており、頻度が少なくとも 2 の 2 つの値でも十分です。 

これにより、問題は、スキャン頻度と、抽出できる素のペアの数をカウントすることになります。

 ## アルゴリズムのチュートリアル

 この問題を、スティックの長さの複数セットの中に等しい値のペアが何組存在するかを数えるという問題に変換します。 

1. ハッシュ マップまたは配列を使用して、各スティックの長さの頻度をカウントします。 

この手順が必要なのは、ペアリングの条件は、各値の位置ではなく、存在する各値のコピーの数にのみ依存するためです。 
2. 頻度のある個別の値ごとに$f$、それが寄与する素のペアの数を計算します。$f // 2$。 

これにより、要素を再利用せずにその値から形成できるペアの最大数が取得されます。 
3. すべての値にわたるこれらのペアのカウントを合計します。 

合計は、全体で形成できる同じ長さのペアの数を表します。 
4. ペアの合計数が 2 以上の場合は、YES と出力します。 それ以外の場合は、NO を出力します。 

平行四辺形には、ある長さの対向する 2 つの辺と、別の長さの対向する 2 つの辺が必要であるため、少なくとも 2 つのペアが必要です。 

### なぜ効果があるのか

 平行四辺形を形成する 4 本のスティックの有効な選択は、2 つの等しいペアに分割する必要があります。 各ペアは同一の値から得られる必要があるため、すべての有効な解は周波数マルチセットから 2 つの互いに素なペアを選択することに対応します。 逆に、マルチセットから 2 つの互いに素なペアを抽出できれば、それらを平行四辺形の対辺として割り当てることができます。 回転と再配置が許可されているため、反対側の等しいことを超える幾何学的制約は実現可能性に影響しません。 

したがって、この問題は、利用可能な等しいペアの合計数が少なくとも 2 つであるかどうかを確認することとまったく同じです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        freq = {}
        for x in a:
            freq[x] = freq.get(x, 0) + 1

        pairs = 0
        for v in freq.values():
            pairs += v // 2

        if pairs >= 2:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```このソリューションは、直接周波数アグリゲーションを中心に構築されています。 辞書は線形時間でカウントを蓄積します。 2 番目のパスでは、整数除算によって各周波数が使用可能なペアの数に変換されます。 これにより、実際のインデックスや組み合わせを明示的に追跡する必要がなくなります。 

よくある実装の落とし穴は、頻度 4 の 1 つの値が 2 つのペアに寄与することを忘れることです。`v // 2`かどうかだけを確認するのではなく、重要です。`v >= 2`。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        freq = {}
        for x in a:
            freq[x] = freq.get(x, 0) + 1
        pairs = sum(v // 2 for v in freq.values())
        out.append("YES" if pairs >= 2 else "NO")
    return "\n".join(out)

# provided samples

assert run("1\n4\n1 1 1 1\n") == "YES"

# custom cases
assert run("1\n3\n1 1 2\n") == "NO", "only one pair exists"
assert run("1\n4\n1 2 3 4\n") == "NO", "no pairs at all"
assert run("1\n6\n1 1 1 1 2 2\n") == "YES", "one value gives two pairs"
assert run("1\n6\n1 1 2 2 3 3\n") == "YES", "three pairs available"

 ## 特殊なケース

 エッジ ケースの 1 つは、単一の値が配列の大半を占める場合です。 のような入力の場合`1 1 1 1`、頻度は 4 で、同じ値から 2 つのペアが生成されます。 アルゴリズムは計算します`4 // 2 = 2`、正しくYESを返します。 

もう 1 つのケースは、ペアは存在するが数が不十分な場合です。`1 1 2 3`。 ここで、周波数は次から 1 つのペアを生成します。`1`他からはゼロ、合計 1。 アルゴリズムはそれを正しく拒否します。 

さらに欺瞞的なケースは、`1 1 1 2 2`。 周波数は`1:3`そして`2:2`。 これにより、`1 + 1 = 2`したがって、4 本のスティックを適切に配置できるかどうかは視覚的には明らかではないかもしれませんが、答えは「YES」です。 ペアリングの抽象化により、幾何学的に推論する必要がなく正確さが保証されます。
