 ## 解決策
 ## 問題の理解

 頂点を原点として、指定されたすべてのマネキンを平面上で囲むことができる最小の角度を決定するように求められます。 各マネキンには座標があります$(x_i, y_i)$、原点自体にはマネキンはありません。 出力は、この角度を度単位で高精度に測定したものである必要があります。 

具体的には、原点に立って頭を回転させてすべてのマネキンを見ることを想像してください。 この質問では、頭を原点から動かさずにすべてのマネキンを見るために必要な最小限の「視野」を尋ねます。 すべてのマネキンが半平面内にある場合、角度は 180 度未満になる可能性がありますが、マネキンが原点をほぼ完全に囲んでいる場合、角度は 360 度に近づく可能性があります。 

制約によって与えられるのは、$n$まで$10^5$、および間の座標$-1000$そして$1000$。 2 秒の時間制限により、おおよそのアルゴリズムが可能になります。$O(n \log n)$範囲。 二次関数 ($O(n^2)$) までのパフォーマンスを発揮します$10^{10}$動作が遅すぎます。 

注意すべきエッジケースには、マネキンが同じラインに沿って配置されている構成や、すべての象限にまたがって配置されている構成が含まれます。 たとえば、2 つのマネキンが$(1, 0)$そして$(-1, 0)$180度の角度が必要です。 単純なアプローチでは、ペアごとの角度を非効率的に計算したり、角度をラップするのを忘れたりする可能性があります。$360^\circ$境界。 

## アプローチ

 ブルートフォースアプローチでは、マネキンのすべてのペアを考慮し、原点でのマネキン間の角度を計算します。 次に、ペアごとに、他のすべてのマネキンがこれら 2 点で定義されたくさび内にあるかどうかを確認できます。 これが機能するのは、最小の囲い角のエッジが 2 つのマネキンを通過する必要があるためです。 ただし、すべてをチェックすると、$O(n^2)$ペアリングしてすべてを検証する$n$それぞれに付与されるポイント$O(n^3)$操作は完全に非現実的です$n = 10^5$。 

重要な観察は、各マネキンが原点からの方向ベクトルに対応しているということです。 逆正接関数を使用して、このベクトルの角度を計算できます。 すべての角度を昇順に並べ替えると、単位円に沿って連続するマネキンを見ることができます。 最小の囲み角度は、連続する角度間の最大ギャップの補数になります。 これにより、次の問題が軽減されます。$O(n^3)$に$O(n \log n)$並べ替えが複雑さを支配するからです。 

これは、円の最大の空の「スライス」がマネキンを見る必要がない方向に対応しているため、機能します。 このギャップを差し引くと、$360^\circ$、すべての点をカバーするために必要な最小角度を取得します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n) | 遅すぎる |
 | 並べ替えとギャップ | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのマネキンの座標を読み取ります。 各点は次のように表されます。$(x_i, y_i)$。 
2. 2 引数の逆正接関数を使用して、原点に対する各点の角度を計算します。$\text{atan2}(y, x)$。 これにより、間の角度がラジアンで与えられます。$-\pi$そして$\pi$。 
3. 角度を範囲に正規化する$[0, 2\pi)$。 これにより、負の値が回避され、ギャップの計算が簡素化されます。 
4. すべての角度を昇順に並べ替えます。 連続する角度は、原点の周りで時計回りの順序で点に対応します。 
5. 連続する角度間のギャップを計算します。最後の角度と最初の角度の間のギャップも考慮することを忘れないでください。$2\pi$。 
6. 最大のギャップを特定します。 最小の囲い角は、この最大のギャップの補数になります。つまり、$2\pi - \text{largest gap}$。 
7. 係数を使用して、結果をラジアンから度に変換します。$180 / \pi$。 
8. 十分な精度で答えを出力します。 

ここでの不変条件は、ソートされた点間の最大角度ギャップによって、カバーする必要のない円の部分が決まるということです。 このギャップを除外することで、すべてのマネキンを含む最小の角度が得られます。 最大のギャップにはマネキンを含めることはできないため、これにより正確さが保証されます。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

n = int(input())
angles = []

for _ in range(n):
    x, y = map(int, input().split())
    angle = math.atan2(y, x)
    if angle < 0:
        angle += 2 * math.pi
    angles.append(angle)

angles.sort()
max_gap = 0

for i in range(n):
    next_i = (i + 1) % n
    gap = angles[next_i] - angles[i]
    if gap < 0:
        gap += 2 * math.pi
    max_gap = max(max_gap, gap)

min_angle = 2 * math.pi - max_gap
print("{:.10f}".format(min_angle * 180 / math.pi))
```まずすべての点を読み取り、次を使用して角度を計算します。`atan2`、すべての象限の点を正しく処理します。 角度を正規化すると、$[0, 2\pi)$負の値を避けます。 ソートにより、連続するギャップを循環順序で計算できるようになります。 ラップアラウンド ギャップはモジュロ演算を使用して処理されます。 度への変換により、最終出力が必要な精度と一致することが保証されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    angles = []
    for _ in range(n):
        x, y = map(int, input().split())
        angle = math.atan2(y, x)
        if angle < 0:
            angle += 2 * math.pi
        angles.append(angle)
    angles.sort()
    max_gap = 0
    for i in range(n):
        next_i = (i + 1) % n
        gap = angles[next_i] - angles[i]
        if gap < 0:
            gap += 2 * math.pi
        max_gap = max(max_gap, gap)
    min_angle = 2 * math.pi - max_gap
    return "{:.10f}".format(min_angle * 180 / math.pi)
