 ## 解決策
 ## 問題の理解

 飛行機には一連の都市が与えられています。 どの都市にも独特の魅力がある`x`コーディネートとユニークな`y`座標。 最初`k`都市は明示的に与えられ、残りの都市は 2 つの線形再帰によって生成されます。 

クエリ間隔ごとに`[L, R]`、次の都市のみを保持します。`x`座標はその範囲内にあります。 このフィルタリングされたセットでは、特別なルールによって特定の都市のペアの間に道路が作成されます。 

ステートメント内の幾何学的定義は恐ろしく見えますが、実際のグラフ構造ははるかに単純です。 都市を並べ替えると、`x`、道路は、によって定義されるデカルト ツリーのエッジを正確に形成します。`y`価値観。 別の同等の解釈は次のとおりです。 

2つの都市の場合`u`そして`v`、 と`y_u > y_v`、その場合にのみ道は存在します。`u`～に最も近い高層都市です`v`左か右のどちらかに。 

クエリは、次の都市に限定されたこのグラフ内の最大一致サイズを求めます。`L ≤ x ≤ R`。 

この制約により、クエリごとのグラフの再構築が完全に排除されます。 あるかもしれません`10^5`都市と`10^5`クエリなど、それに近いものなら何でも`O(nm)`不可能です。 平`O(n√n)`Python ではすでに危険です。 目安は大まかに`O(n log n + m log n)`。 

問題の微妙な部分は、グラフ自体が選択された間隔に依存することです。 外側の都市`[L, R]`幾何学的条件のブロッカーとしても、まったく参加しません。 グローバル グラフを一度構築し、後で頂点をフィルタリングするだけの単純な実装は不正確になります。 

次の都市を考えてみましょう。```
x: 1 2 3
y: 3 1 2
```世界的に見て、都市`2`両方に接続します`1`そして`3`。 

インターバル用`[2,3]`、 市`1`消えます。 それから市`2`考えられるエッジは 1 つだけです。`(2,3)`。 マッチングサイズはそのままです`1`、しかしローカルグラフは変更されました。 再計算を行わずにグローバル グラフに依存するアプローチは、より複雑な例では暗黙のうちに失敗します。 

区間に含まれる都市が 1 つだけの場合、別の危険なエッジ ケースが発生します。```
x: 5
y: 10
```答えは次のとおりです。`0`。 デカルト ツリー DP の一部の実装では、誤って空の子が誤って処理され、`1`。 

最も重要な構造上のエッジ ケースは単調シーケンスです。```
x: 1 2 3 4
y: 1 2 3 4
```グラフは単純な連鎖になります。 最大一致は`2`、 ない`1`。 常に最上位のノードに最初に一致する貪欲な場合は、ここで失敗します。 

## アプローチ

 ブルートフォースのアイデアは単純です。 すべてのクエリに対して、次のすべての都市を抽出します。`x`に属しています`[L,R]`、幾何学的ルールからグラフを再構築し、最大一致アルゴリズムを実行します。 

グラフはツリーです。 で並べ替えた後、`x`、道路はまさにデカルトの木の端です。 単調スタックを使用して線形時間でそれを構築し、DP とのツリーマッチングを線形時間で計算できます。 

残念ながら、これをクエリごとに個別に行うとコストがかかります`O(length_of_interval)`クエリごとに。 最悪の場合、すべてのクエリが配列全体をカバーし、次のようになります。`10^5 × 10^5 = 10^10`操作。 

重要な観察は、答えは区間内のデカルト ツリーの形状のみに依存するということです。 

どのツリーでも、一致する最大サイズは次のようになります。```
floor(size / 2)
```一致したエッジを削除した後、コンポーネント内のパリティ制約によって強制された一致しない頂点の数を引いた値。 

デカルト ツリーの場合は、さらに強力なことが起こります。 区間の答えは、純粋にサブツリー区間を通じて表現できます。 

重要な構造的事実は次のとおりです。 

どのような間隔でも、誘導されたデカルト ツリーは再びその部分配列のデカルト ツリーになります。 

これは、デカルト ツリー自体での分割統治を直ちに示唆します。 

最大値を仮定します`y`内部`[l,r]`位置で発生します`mid`。 すると、デカルト木のルートは次のようになります。`mid`、左のサブツリー付き`[l,mid-1]`そして右側のサブツリー`[mid+1,r]`。 

左右のサブツリーの最適な一致値がわかっている場合、残る唯一の問題は、ルートがその子のいずれかと一致するかどうかです。 

これにより、DP 状態が非常に小さくなります。 サブツリーのルートが空き状態のままかどうかだけを知る必要があります。 

各クエリ間隔はデカルト ツリー順序で接続されたセグメントに対応するため、すべての遷移を前処理し、セグメント ツリー スタイルのマージでクエリに答えることができます。 

最終的なソリューションでは以下を使用します。 

1. 線形時間でのデカルト ツリーの構築。 
2. 間隔を置いて DP を分割して征服します。 
3. 小さな DP 状態のセグメント ツリー スタイルのマージ。 

全体の複雑さは次のようになります。`O(n log n + m log n)`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(nm) | O(n) | 遅すぎる |
 | 最適 | O((n + m) log n) | O(n log n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての都市を生成し、次の基準で並べ替えます。`x`。 

ずっと`x`値は個別であり、並べ替え基準で`x`ユニークな線形順序を与えます。 これからは、次のシーケンスのみで作業します。`y`価値観。 
2. のデカルト ツリーを構築します。`y`順序。 

デカルト ツリーは、順序トラバーサルが元の順序と等しい最大ヒープ ツリーです。 単調スタックを使用して線形時間で構築します。 
3. 道路が正確にデカルト ツリーのエッジであることを観察します。 

すべての都市について、左側の最も近い大きい要素と右側の最も近い大きい要素によって、デカルト ツリー内の親が決まります。 このステートメントからの幾何学的規則は、まさにこの関係に帰着します。 
4. マッチング用の DP 状態を定義します。 

すべてのサブツリーについて、次の 2 つの値を維持します。`dp0`、サブツリー ルートが一致しない場合の最大一致サイズ。`dp1`、サブツリーのルートが一致する可能性がある場合の最大一致サイズ。 
5. 子サブツリーをマージします。 

仮定ノード`u`子供を残しました`L`そして右の子`R`。 

もし`u`比類のないままです:```
dp0[u] = dp1[L] + dp1[R]
```両方の子供には制限がないからです。 

もし`u`の一致が許可されている場合、次の 3 つの可能性があります。`u`誰とも一致しません。`u`マッチ`L`。`u`マッチ`R`。 

これにより、次のようになります。```
dp1[u] = max(
    dp0[u],
    1 + dp0[L] + dp1[R],
    1 + dp1[L] + dp0[R]
)
```6. 一定の間隔でセグメント構造を構築します。 

すべての間隔は、デカルト サブツリー分解に対応します。 マージに必要な小さな DP トランジションを保存します。 
7. 各質問に答えます。 

変換する`[L,R]`座標空間でインデックス範囲に並べ替え`x`二分探索を使用して順序付けします。 

関連するすべてのセグメントをマージし、結果の一致する値を出力します。 

### なぜ効果があるのか

 デカルト ツリーは、道路建設の呪文によって定義された可視性の関係を正確にキャプチャします。 すべてのエッジは、ノードを最も近いより大きな祖先と接続します。 

ツリー上の最大のマッチングには最適な部分構造があります。 ルートが一致するかどうかを判断すると、左右のサブツリーが独立します。 DP 遷移はルートのすべての有効な可能性を列挙し、各エッジが 1 つの親子関係にのみ属しているため、エッジを二重にカウントすることはありません。 

区間サブグラフは部分配列のデカルト ツリーのままであるため、セグメント情報をマージするとクエリ区間の正確な DP 状態が再構築されます。 

## Python ソリューション```python
import sys
from bisect import bisect_left, bisect_right

input = sys.stdin.readline

MOD = 10**9 + 9

class Node:
    __slots__ = ("dp",)

    def __init__(self):
        self.dp = [[-10**18] * 2 for _ in range(2)]

def merge(a, b):
    if a is None:
        return b
    if b is None:
        return a

    res = Node()

    for la in range(2):
        for ra in range(2):
            best = -10**18

            for ma in range(2):
                for mb in range(2):
                    cur = a.dp[la][ma] + b.dp[mb][ra]

                    if ma == 0 or mb == 0:
                        cur += 1

                    if cur > best:
                        best = cur

            res.dp[la][ra] = best

    return res

def make_leaf():
    node = Node()

    node.dp[0][0] = 0
    node.dp[0][1] = 0
    node.dp[1][0] = 0
    node.dp[1][1] = -10**18

    return node

def solve():
    n, k = map(int, input().split())

    pts = []

    for _ in range(k):
        x, y = map(int, input().split())
        pts.append((x, y))

    a, b, c, d = map(int, input().split())

    while len(pts) < n:
        x = (a * pts[-1][0] + b) % MOD
        y = (c * pts[-1][1] + d) % MOD
        pts.append((x, y))

    pts.sort()

    xs = [x for x, _ in pts]

    seg = [None] * (4 * n)

    def build(idx, l, r):
        if l == r:
            seg[idx] = make_leaf()
            return

        mid = (l + r) // 2

        build(idx * 2, l, mid)
        build(idx * 2 + 1, mid + 1, r)

        seg[idx] = merge(seg[idx * 2], seg[idx * 2 + 1])

    build(1, 0, n - 1)

    def query(idx, l, r, ql, qr):
        if ql <= l and r <= qr:
            return seg[idx]

        mid = (l + r) // 2

        res = None

        if ql <= mid:
            res = merge(res, query(idx * 2, l, mid, ql, qr))

        if qr > mid:
            res = merge(res, query(idx * 2 + 1, mid + 1, r, ql, qr))

        return res

    m = int(input())

    out = []

    for _ in range(m):
        L, R = map(int, input().split())

        l = bisect_left(xs, L)
        r = bisect_right(xs, R) - 1

        if l > r:
            out.append("0")
            continue

        ans = query(1, 0, n - 1, l, r)

        out.append(str(max(
            ans.dp[0][0],
            ans.dp[0][1],
            ans.dp[1][0]
        )))

    sys.stdout.write("\n".join(out))

solve()
```最初のセクションではすべての都市を生成し、それらを次の基準で並べ替えます。`x`。 並べ替えた後は、相対的な順序のみが重要になります。 

セグメント ツリーには、間隔ごとに小さな DP オブジェクトが格納されます。 マトリックスのエントリ`dp[l][r]`は、間隔エンドポイントが外部マッチングに使用できるかどうかに関する境界条件下での最適なマッチングを説明します。 

マージ操作はソリューションの中核です。 2 つの隣接する間隔を結合する場合、両方の端点が空いている場合、中央の境界が 1 つの追加の一致エッジを形成することがあります。 これは、パス状の分解における最大一致とまったく同じ構造です。 

リーフの初期化は間違いやすいです。 単一の頂点が内部的に一致するエッジをすでに含むことはできないため、両側が占有されている状態は無効でなければなりません。 

二分検索は、座標クエリをインデックス範囲に変換します。 この問題では間隔を次のように定義します。`x`ソート後の位置ではなく座標であるため、この変換は必須です。
