 ## 解決策
 ## 問題の理解

 私たちは、正確に含まれるポーションを作成する任務を負っています。$k\%$魔法のエッセンスと$(100-k)\%$水。 大釜は空から始まり、どちらの材料も一度に 1 リットルしか追加できません。 目標は、正確な比率を達成するために注ぐ必要がある最小リットル数を決定することです。 入力により多数のテスト ケースが提供されます$t$、それぞれ希望するパーセンテージを指定します$k$、出力はそれぞれの合計リットルの最小数を示す必要があります。 

重要な観察は、ポーションの比率は絶対量ではなく、エッセンスと水の相対的な数にのみ依存するということです。 したがって、問題は最小の整数を見つけることになります。$e$そして$w$そのような$$\frac{e}{e + w} = \frac{k}{100}.$$これを次のように書き換えることができます$100 \cdot e = k \cdot (e + w)$、それは次のことにつながります$100e - k(e + w) = 0$、または同等の$e \cdot (100 - k) = w \cdot k$。 これは整数の線形ディオファントス方程式です$e$そして$w$。 

制約は小さいですが、$1 \le k \le 100$そして$t \le 100$、だから、$O(1)$テスト ケースごとの算術解で十分です。 エッジケースが発生するのは次の場合です$k$100 を均等に割ります (例:$k = 25, 50, 100$）そしていつ$k$は 100 と互いに素です (例:$k = 3, 7$）。 100 までのすべてのボリュームをテストする素朴な解決策は機能しますが、単純な数理論的公式が存在することを考えると、その必要はありません。 

## アプローチ

 ブルートフォースアプローチでは、可能なすべてのボリュームを反復処理します。$e + w$1 から開始して、分数かどうかを確認します$e/(e+w)$等しい$k/100$。 のために$k = 1$または$k = 99$、これには最大 100 のステップが必要になる可能性があり、これは許容できますが、エレガントではありません。 

最適なアプローチでは、最大公約数推論が使用されます。 もし$g = \gcd(k, 100)$、 それから$k = g \cdot k'$そして$100 = g \cdot 100'$。 比率を満たす最小の合計リットルは正確に次のとおりです。$100/g$、 以来$$\frac{e}{e+w} = \frac{k}{100} = \frac{k'}{100'}$$その比率の最小の整数は次のとおりです。$e = k'$そして$w = 100' - k'$、与える$e + w = k' + (100' - k') = 100' = 100/g$。 これにより、反復なしで即座に式が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 |---|---|---|---|
 | ブルートフォース | テスト ケースごとに O(100) | お(1) | 受け入れられるが不要 |
 | 最適 | テスト ケースごとに O(log 100) | お(1) | 受け入れられ、エレガント |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、パーセンテージを読み取ります。$k$。 
3. 最大公約数を計算する$g = \gcd(k, 100)$。 これにより、分子と分母の両方を削減できる最大の要因が特定されます。 
4. 合計リットルの最小数を次のように計算します。$100/g$。 これは最小の整数に相当します$e$そして$w$比率を満たすもの。 
5. テスト ケースの結果を印刷します。 

なぜ効果があるのか​​: 分数を減らすことによって$k/100$最も低い項まで、正確なパーセンテージを維持する最小の整数比を見つけます。 この換算された分数の分子と分母の合計により、最小の総体積が得られます。 これより小さな整数の組み合わせは正確な比率を満たすことができません。これより小さな合計は分数の縮約特性に違反するためです。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    k = int(input())
    g = math.gcd(k, 100)
    print(100 // g)
```このソリューションは、各テスト ケースを読み取り、最大公約数を計算し、最小総量を出力します。 整数の除算を選択すると、正確なリットル数が得られます。 Pythonの組み込み`math.gcd`以下を含むすべてのエッジケースを自動的に処理します。$k = 100$そして$k = 1$。

## テストケース```python
import sys, io
def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        k = int(input())
        g = math.gcd(k, 100)
        output.append(str(100 // g))
    return "\n".join(output)
