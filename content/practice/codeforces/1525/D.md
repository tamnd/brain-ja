 ## 解決策
 ## 問題の理解

 並んでいます`n`肘掛け椅子、その一部には最初は人が座っています。 私たちの目標は、最初に占有されていたすべての座席が空になるように、すべての人を現在空いている肘掛け椅子に移動することです。 問題は、人を一度に 1 人ずつ移動させ、人を席から移動させるのに時間がかかることです。`i`席に着く`j`まさに`|i - j|`。 全員の移動にかかる合計時間を最小限に抑えたいと考えています。 

入力配列`a`長さの`n`初期状態をエンコードします。`1`占有座席を示し、`0`自由席。 出力は単一の整数、つまり最小の合計移動時間です。 

制約は次のことを教えてくれます`n`最大 5000 まで可能ですが、これは動的プログラミングやフローのようなアルゴリズムを使用できる程度に十分小さいです。`O(n^2)`操作。 また、占有座席数は最大でも`n/2`したがって、常に少なくとも占有席と同数の空席が存在し、有効な解決策が存在することが保証されます。 

エッジ ケースには、すべての座席が空である場合 (すぐに 0 が返されるはずです)、および占有座席がクラスター化されている構成が含まれます。これにより、全体的な考慮なしに最も近い空席と最も近い人を組み合わせようとする単純な貪欲なアプローチがつまずく可能性があります。 

## アプローチ

 強引なアプローチでは、空席への人々の割り当てをあらゆる方法で試し、総移動時間を計算します。 これは、人々の空席のすべての順列を列挙することに相当します。 あれば`k`占有された座席と`m`空席の場合、課題の数は`m! / (m - k)!`、これは難治性です`k`または`m`このアプローチは正しいですが、遅すぎます。`n`5000まで。 

重要な洞察は、問題が重み付けされた 2 部マッチングのインスタンスに還元できるということです。 占有席を 1 つの頂点セットとして扱い、空席をもう 1 つの頂点セットとして扱います。 人を座席に割り当てるコストは、その人の間の距離です。 ただし、完全なハンガリー語アルゴリズムは次のように実行されます。`O(n^3)`または`O(k^3)`この時間は境界線にありますが、動的プログラミングによって最適化できます。 

座席の一次元の順序を利用できます。 させて`occupied`人々の役職をソートしたリストであり、`empty`ソートされた自由席のリスト。 定義する`dp[i][j]`最初の値を割り当てるための最小総コストとして`i`人々を最初のサブセットに`j`空席。 繰り返しは単純です。現在の空席をスキップする (割り当てなし) か、現在の人をそれに割り当てて移動コストを追加します。 これにより、解決策は次のようになります。`O(k * m)`動的計画法の問題は実行可能です。`k`そして`m`それぞれ最大 2500 です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(m! / (m-k)!) | O(m) | 遅すぎる |
 | ソートされたリストを使用した DP | O(k * m) | O(k * m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力を解析し、占有された (`occupied`) と空の (`empty`）椅子。 
2. DP 配列を初期化する`dp`寸法付き`(k + 1) x (m + 1)`どこ`k`は人の数であり、`m`空席の数。 を除くすべてのエントリを無限大に設定します。`dp[0][0] = 0`。 
3. 各人物に対して反復処理を行う`i`0から`k`。 各人について、空席ごとに繰り返します`j`0から`m`。 各ステップで、2 つのオプションを伝播します。 

- 空席をスキップする`j`:`dp[i][j+1] = min(dp[i][j+1], dp[i][j])`。 
- 人を割り当てる`i`空席へ`j`:`dp[i+1][j+1] = min(dp[i+1][j+1], dp[i][j] + abs(occupied[i] - empty[j]))`。 
4. DP テーブルに記入すると、答えは次のようになります。`dp[k][m]`、すべての人を割り当てるための最小の合計コスト。 

なぜ機能するのか: DP の不変条件は次のとおりです。`dp[i][j]`最初の割り当ての最小コストを常に保存します。`i`人々を最初のグループの一部に`j`空席。 各ステップでスキップと代入の両方を考慮することで、考えられるすべてのシーケンスが考慮され、テーブルを順番に埋めることで、使用前にすべての依存関係が満たされることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

occupied = [i for i, val in enumerate(a) if val == 1]
empty = [i for i, val in enumerate(a) if val == 0]

k = len(occupied)
m = len(empty)

INF = 10**18
dp = [ [INF] * (m + 1) for _ in range(k + 1) ]
dp[0][0] = 0

for i in range(k + 1):
    for j in range(m):
        if dp[i][j] == INF:
            continue
        # Option 1: skip current empty chair
        dp[i][j+1] = min(dp[i][j+1], dp[i][j])
        # Option 2: assign current person if possible
        if i < k:
            dp[i+1][j+1] = min(dp[i+1][j+1], dp[i][j] + abs(occupied[i] - empty[j]))

print(dp[k][m])
```このソリューションでは、まず、占有されている椅子と空の椅子のリストを分離します。 DP テーブルは、到達不可能な状態を表すために、慎重に無限大で初期化されます。 スキップ オプションを使用して、割り当てられる空席を柔軟に選択できるように、考えられるすべての割り当てを繰り返します。 最小総コストは次のとおりです。`dp[k][m]`。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    occupied = [i for i, val in enumerate(a) if val == 1]
    empty = [i for i, val in enumerate(a) if val == 0]
    k = len(occupied)
    m = len(empty)
    INF = 10**18
    dp = [ [INF] * (m + 1) for _ in range(k + 1) ]
    dp[0][0] = 0
    for i in range(k + 1):
        for j in range(m):
            if dp[i][j] == INF:
                continue
            dp[i][j+1] = min(dp[i][j+1], dp[i][j])
            if i < k:
                dp[i+1][j+1] = min(dp[i+1][j+1], dp[i][j] + abs(occupied[i] - empty[j]))
    return str(dp[k][m])
