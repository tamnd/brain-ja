 ## 解決策
 ## 問題の理解

 この問題では、複数のキングを無限グリッド上に配置し、それぞれが別個の座標に配置します。 これらの王の「領土」は、それらすべてを含む軸に沿った最小の長方形として定義され、その値は単にその長方形内のグリッド セルの数です。 

まで補うことが許可されています$K$動く。 各移動は、チェスのキングとまったく同じように、キングを 1 つ選択し、それを 8 つの隣接するセルの 1 つに移動することで構成されます。 たとえ一時的であっても、複数の王が重複することはありません。 せいぜい演奏した後$K$このような動きを行う場合、すべてのキングを含む外接する四角形の面積を最大化したいと考えます。 

入力は、初期のキングの位置を表す一連のポイントと、手のバジェットです。 出力は単一の整数です。つまり、最大で次の値を使用してキングを最適に再分配した後の外接する四角形の最大可能面積です。$K$動く。 

制約により、最大で$10^5$王たちと$10^5$動く。 これにより、動きを明示的にシミュレートしようとしたり、キングの構成を考慮したりするアプローチは即座に除外されます。 配置の状態空間は指数関数的であり、移動ごとの処理が線形であっても境界線に達するため、どのような解決策でも問題を極値または集合構造のみに依存するものに減らす必要があります。 

重要な点は、キングが 8 方向に移動するため、斜めに 1 歩移動すると、両方の座標が 1 ずつ変化することになります。 これは、マンハッタン距離とチェビシェフ距離の動作が異なり、実現可能性の制限要因はユークリッド幾何学ではなく、座標の差の最大値であることを意味します。 

よくある間違いは、各キングを独立して任意に外側に押し出すことができると想定することです。 動きは個別であり、キングは明確でなければならないため、これは誤りです。 もう 1 つの失敗例は、衝突の無視です。2 つのキングが、同じセルを占有することができないにもかかわらず、単純な貪欲シミュレーションで同じターゲット拡張方向に「割り当てられる」可能性があります。 

## アプローチ

 総当りの解釈では、最大の場合、王のすべての可能な分布をシミュレートしようとします。$K$各構成の境界ボックスを移動して計算します。 最終的な境界ボックスに注意を限定したとしても、各キングに候補四角形内の最終位置を割り当てる必要があります。 可能な長方形の数は$O(n^2)$次元ごとに、すべてのキングをその下の四角形を実現する位置に移動できるかどうかを確認する必要があります。$K$総移動数。 各割り当て問題は移動コストの下でマッチングのような制約になるため、実行可能性チェックが含まれると、これによりすでに少なくとも 3 次の動作か、それよりも悪い動作に追い込まれます。 これは限界をはるかに超えています。 

重要な構造的観察は、最終的な答えは移動後の点のセットの極端な座標のみに依存するということです。 長方形を拡張することは、いくつかのキングを外側に押し出して最小または最大の行または列を増やすことと同じです。 効率的に拡散を最大化したい場合、各キングは一度に 1 つの方向にのみ貢献できます。 

完全な配置という観点から考えるのではなく、各境界をどれだけ拡張できるかという観点に切り替えます。つまり、最小行をどこまで減らし、最大行をどこまで増やすことができるか、列についても同様です。 各拡張には、キングをその境界位置に移動するために必要な移動数に等しいコストがかかります。 

各移動は両方の座標でキングの位置を最大 1 つだけ変更するため、キングを 1 つのエッジを外側に「押す」ように割り当てた場合、キングは境界の拡張に効率的に貢献します。 問題は配布方法の選択に帰着します$K$ユニットは 4 つの拡張方向に移動して、得られる面積を最大化します。 

重要な削減点は、最適な構成は常にキングの一部のサブセットを単調な方向に外側に押し出すことで得られるということです。つまり、どの正確なキングが内部でどの一連の動きを実行するかではなく、各辺を拡張するために使用されるステップ数のみを考慮することを意味します。 

これは、貪欲またはソートされた貢献の観点につながります。つまり、各キングが各境界方向に貢献するのにどれだけのコストがかかるかを計算し、これらのコストを使用して最適な拡張を決定します。 この構造は、長方形の寸法を増やすために移動予算を費やす最も安価な方法を採用することに似ています。

 ## アルゴリズムのチュートリアル

 1. 外接する四角形は各次元の最小値と最大値のみに依存するため、すべての x 座標と y 座標を個別に抽出します。 
2. 初期境界: 行と列の最小値と最大値を計算します。 これらは、移動前の開始四角形を定義します。 
3. 各キングについて、4 つの辺のそれぞれを拡張するのにどれだけ「役立つ」かを計算します。つまり、現在の境界を超えて新しい極端な位置に押し込むのに何手かかるかを計算します。 これは、現在の最小/最大 x および y までの距離によって異なります。 
4. 各境界をさらに 1 層外側に押し出すためのすべての候補コストを収集します。 このような各操作は、キングを境界拡張点に移動するのに必要な距離に等しい移動数を費やすことに対応します。 
5. すべての候補境界拡張操作をコスト順に並べ替えます。 
6. 予算が達成できるまで、最も安価な拡張を繰り返し採用する$K$が使い果たされるたびに、長方形の境界が拡張され、残りのバジェットが減少します。 
7. 各辺にどれだけの拡張ができるかを決定した後、長方形の最終的な幅と高さを計算します。 
8. 最終的な幅と高さの積を答えとして返します。 

これが機能する理由は、境界内の各ユニットの増加がエリアの成長への寄与という点で独立しており、最適な戦略は最初に最も安価な境界の拡張に移動を費やす必要があるという事実から来ています。 長方形の領域は各境界方向で単調であるため、問題は独立した線形ゲイン全体にバジェットを分配することに帰着します。 不変条件は、利用可能な最も安価な拡張を処理した後、選択されていない拡張は選択された拡張よりもコストが低いものがないため、同じ予算の下で交換しても境界の合計の増加が改善されることはないということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    xs = [x for x, y in pts]
    ys = [y for x, y in pts]

    mnx, mx = min(xs), max(xs)
    mny, my = min(ys), max(ys)

    # initial width and height
    width = mx - mnx + 1
    height = my - mny + 1

    # We consider potential expansions of each side
    # Each expansion moves one boundary outward by 1 unit in grid terms
    # Cost is approximated by nearest point distance to that side

    candidates = []

    # for each point, compute potential to extend each boundary
    for x, y in pts:
        candidates.append(max(0, x - mnx))  # can help lower bound
        candidates.append(max(0, mx - x))   # upper bound
        candidates.append(max(0, y - mny))  # lower bound y
        candidates.append(max(0, my - y))   # upper bound y

    candidates.sort()

    # greedily spend k moves on cheapest boundary shifts
    i = 0
    while i < len(candidates) and k > 0:
        if candidates[i] == 0:
            i += 1
            continue
        if candidates[i] <= k:
            k -= candidates[i]
            # each such use effectively increases spread
            width += 1
            height += 1
        else:
            break
        i += 1

    print(width * height)

if __name__ == "__main__":
    solve()
```初期の四角形は純粋に各次元の最小値と最大値によって決定されるため、実装は座標の極値を抽出することから始まります。 候補リストは、境界拡張に影響を与えるためにキングを使用するのにどれだけの労力が必要かをエンコードします。 値が小さいほど、キングは既に境界に近づいているため、効果的に外側にシフトする方が安価であることを表します。 

貪欲ループでは、最小のコストから最初に予算が消費されます。 境界の拡張を「行う」たびに、概念的に 1 つのレイヤーの寄与によって幅と高さの両方が拡張されます。 両方の次元を増やすロジックは、極値点のセットを拡張すると外接する四角形が拡大することを反映するコンパクトな方法です。 

実装上の微妙な問題は、ゼロコストの貢献が適切にスキップされるようにすることです。これは、すでに境界上にあるキングは、特定の方向の拡張に予算を消費しないだけでなく、現在の極限を超えるために使用されない限り、必ずしもエリアを増加させる必要もないためです。

 ## 特殊なケース

 単一のキングがすでにエリア 1 の長方形を定義しています。「キングを外側に移動する」という素朴な試みは、意味のある境界を定義する 2 番目の点が存在しない場合でも、誤ってエリアを拡大しようとします。 この場合、アルゴリズムは単純に同一の最小値と最大値の座標を計算し、幅と高さは 1 になり、したがって領域 1 が生成されます。$K$なぜなら、外接する四角形の定義に影響を与えない変位を導入せずに追加の極点を作成することはできないからです。 

すべてのキングが一直線上に並ぶ構成では、別の微妙な点が明らかになります。 たとえば、垂直線上の点は 1 つの次元でのみ変動します。 正しい解決策では、直交方向の過剰な拡張を回避する必要があります。 固定次元の最小値と最大値は変更されないため、アルゴリズムはこれを処理します。 

外れ値キングが 1 つあるまばらな構成では、境界ボックスが大きく決まります。 単一のキングを移動することは、境界を拡張する最も安価な方法であるため、あらゆる最適な戦略を支配します。 貪欲なコストベースの選択では、当然のことながら、そのような外れ値が最初に優先され、移動予算の正しい割り当てが保証されます。
