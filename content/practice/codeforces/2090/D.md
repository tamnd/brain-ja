 ## 解決策
 ## 問題の理解

 最初の順列を構築するように求められます。$n$正の整数から派生したシーケンスには多くの素数が含まれます。 具体的には、順列の場合$p_1, p_2, \dots, p_n$と定義します。$c_i = \lceil \frac{p_1 + p_2 + \dots + p_i}{i} \rceil$。 目標は、少なくとも次のことを保証することです。$\lfloor n/3 \rfloor - 1$の$c_i$値は素数です。 

入力はテスト ケースの数を示します$t$その後$t$順列のサイズを表す整数。 それぞれ$n$と同じ大きさにすることができます$10^5$、そしてサイズの順列を生成する必要があります$n$テストケースごとに。 なぜなら$n$が大きく、複数のテスト ケースが存在する可能性があるため、順列ごとの線形時間よりも悪いアプローチは遅すぎる可能性があります。 並べ替え、累積和、またはシーケンスの構築$O(n)$算術演算は実行可能ですが、ネストされた反復は実行されません。$n^2$要素は法外なものになります。 

エッジケースが発生するのは次の場合です$n$非常に小さいです、例えば$n = 2$または$n = 3$。 最低限の要件$\lfloor n/3 \rfloor - 1$はゼロになる可能性があるため、順列は依然として次の式を満たしている必要があります。$c_i$, しかし、多くの素数は必要ありません。 不注意な実装では、実際に必要な数よりも多くの素数を適用しようとすると失敗する可能性があります。 もう一つの微妙な点は、$c_i$プレフィックスの合計に依存するため、数値の順序が重要になります。 非常に大きな数値を早くまたは遅く配置すると、早いかどうかに影響します。$c_i$値は素数です。 

## アプローチ

 ブルートフォースアプローチは、長さのすべての順列を生成することです。$n$を計算します。$c_i$それぞれについて素数を数えます。 すべての順列をチェックすると、必要な素数の数を満たすものが確実に見つかるため、これは正しいです。 ただし、置換の数は、$n!$でさえ天文学的な大きさです。$n = 10$そのため、指定された制約ではこのアプローチは実行不可能になります。 

重要な洞察は、問題は、正確な「数学的」順列を見つけるというよりは、最初はゆっくりと、その後より速く増加するプレフィックス合計を持つシーケンスを構築することにあるということです。 特に、シーケンスは、$2,1,3,4,5,\dots$初期のプレフィックス合計は素数である小さな整数 (多くの場合 2 または 3) を生成するため、機能します。 最初のいくつかの要素の後、平均の上限は安定し、頻繁に素数に達し続けます。 基本的に、シーケンスは 2 から始まり、次に 1、そして残りの数字が昇順に続きます。 これにより、初期の素数の中から十分な小さな素数が保証されます。$c_i$順列を正しく入力しながら値を調整します。 この構造はすべての人に有効です$n$、時間的に線形であり、実装が簡単です。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、整数を読み取ります。$n$。 
3. 次のように順列リストを初期化します。$2$最初の要素として。 これにより、最初の$c_1$プライムです。 
4.追加$1$2番目の要素として。 最初の 2 つの要素の接頭辞の合計により、別の素数が得られます。$c_2$。 
5. 残りの数字を追加します。$3$まで$n$昇順で。 これにより、初期の順列を維持しながら、残りの順列が埋められます。$c_i$値を素数として扱います。 
6. 現在のテスト ケースの順列を出力します。 

効果がある理由: 配置することで$2$そして$1$開始時に、最初のいくつかのプレフィックス平均は小さな素数であることが保証されます (2 と 2$n \ge 2$）。 残りの数は、必要な初期シーケンス内の素数の数を減らしません。 この問題に必要なのはおよそ 3 分の 1 だけなので、$c_i$プライムになること、そして$2$そして$1$開始時に早めにいくつかを確保してください$c_i$が素数である場合、このパターンはすべての条件を満たします。$n$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        if n == 2:
            print("2 1")
            continue
        perm = [2, 1] + list(range(3, n+1))
        print(" ".join(map(str, perm)))

if __name__ == "__main__":
    solve()
```このソリューションは、テスト ケースの数を読み取り、それぞれを個別に処理します。 のために$n = 2$、固定順列を出力します。`2 1`最小の入力を正しく処理します。 大型の場合$n$、パターンを使用して順列を構築します。`2,1,3,4,...,n`。 リストの内包理解`list(range(3, n+1))`残りのシーケンスを効率的に構築します。 の`print`ステートメントは、整数を文字列に変換し、スペースで結合して、必要な形式を生成します。

 ## 特殊なケース

 のために`n = 2`、アルゴリズムの出力`2 1`。 最初のプレフィックスの合計は 2、2 番目のプレフィックスの合計は 3、ceil(avg) 値は 2 と 2 で、どちらも素数です。 これは、必要な 0 素数を満たします。$\lfloor n/3 \rfloor - 1$。
