 ## 問題の理解

 2 つのグローバル演算を繰り返し適用できる整数の配列が与えられます。 1 つの操作では奇数位置のすべての要素がインクリメントされ、もう 1 つの操作では偶数位置のすべての要素がインクリメントされます。 各演算ではインデックスの固定サブセットに 1 が加算され、どちらの演算も何度でも適用できます。 

ここでのタスクは、すべての要素が同じパリティになるように配列を変換できるかどうかを判断することです。つまり、一連の操作の後にすべての値が偶数または奇数になることを意味します。 

主要な構造上の制約は、テスト ケースあたりの入力サイズが小さく、要素数が最大 50 であることです。 これにより、テスト ケースごとの線形または一定の作業を超える最適化の必要性が即座に除外されます。 すべての状態の二次または三次シミュレーションでも許容されますが、その必要はありません。 

素朴な落とし穴は、各要素を独立して自由に制御していると考えることです。 各操作は配列の半分に同時に影響を与えるため、これは不正確です。 たとえば、単一の不一致要素を修正しようとすると、必然的に、同じインデックス パリティ クラスの他のすべての要素も変更することになります。 

もう 1 つの微妙な失敗例は、十分な操作を選択することで各要素のパリティを独立して制御できると想定している場合です。 たとえば、1 つの位置だけを見て、それに必要な増分数を決定する場合、同じ増分が同じパリティ クラスのすべての位置に適用されることを無視する可能性があります。 

混乱を招く小さな例として、次のような配列があります。`[1, 2]`。 両方を独立して修正しようとすることもできますが、どの操作でも 1 つのパリティ クラスの両方の位置が一度に変更されるため、決定は結合されます。 

## アプローチ

 強引なアイデアは、奇数のインデックスと偶数のインデックスに対するすべての可能な数の操作をシミュレートすることです。 奇数インデックス演算の x 演算と偶数インデックス演算の y 演算を適用すると、各要素の最終値が完全に決定されます。 すべてのペアを試すことができます`(x, y)`すべての最終値が同じパリティを共有しているかどうかを確認します。 

ただし、n が小さい場合でも、x と y には制限がありません。 検索範囲を限定しない限り、あらゆる可能性を試すことは無限です。 パリティ動作を観察すると、この問題はすぐに解決されます。 

各操作では、ターゲット インデックス クラス内のすべての要素のパリティが反転されます。 つまり、重要なのは、奇数インデックス演算を偶数回適用するか奇数回適用するかだけであり、偶数インデックス演算についても同様です。 2回適用するとパリティ効果が解除されます。 

したがって、各インデックス クラスは、パリティを反転するかどうかに関係なく、ちょうど 1 つのバイナリ自由度に寄与します。 これにより、問題は 2 つのバイナリ フリップ (奇数クラス フリップと偶数クラス フリップ) を割り当てて、結果として得られるすべてのパリティが一致するかどうかを確認できるかどうかを確認することに集約されます。 

これで構造がシンプルになりました。 これら 2 つのグローバル トグルを使用して、すべての値を偶数にすることができるか、すべての値を奇数にすることが可能かどうかをテストするだけで済みます。 それは、インデックス全体の初期パリティ パターンが、位置合わせが可能な方法で一貫しているかどうかによってのみ決まります。 

直接的に単純化すると、各インデックス パリティ グループ内で、それらのすべてを反転することも、反転しないこともできるということです。 したがって、フリップを選択した後、両方のグループを単一のターゲット パリティに合わせる必要があります。 

これは、両方のグループを同時にすべて偶数またはすべて奇数に一致させることができるかどうかをチェックすることになります。これは、これらのグローバル ターゲットの少なくとも 1 つが一致する場合に正確に可能です。

 ## アルゴリズムのチュートリアル

 配列を 2 つの暗黙的なグループ (奇数インデックスの要素と偶数インデックスの要素) に分割します。 

1. すべての要素がすでに同じパリティであるかどうかを計算します。 「はい」の場合、操作は必要ないため、答えはすぐに「はい」になります。 これは、自明な固定小数点の場合を処理します。 
2. 奇数インデックスと偶数インデックスの要素のパリティを別々に記録します。 重要なのは、彼らの価値観ではなく、各グループが内部的に均一であるか、混合されているかです。 
3. 奇数インデックス演算を適用すると奇数グループのすべての要素が反転し、偶数インデックス演算を適用すると偶数グループのすべての要素が反転することに注目してください。 したがって、各グループには、反転するか反転しないかの独立した二者択一の選択肢があります。 
4. 変換後にすべての要素が偶数になるように反転を選択できるかどうか、およびすべてが奇数になるように反転を選択できるかどうかを個別に確認します。 どちらかが達成可能であれば、答えは「はい」です。 
5. 2 つのグループ間のパリティ構造が一貫していないため、両方のグローバル ターゲットが不可能な場合にのみ、「いいえ」と結論付けます。 

### なぜ効果があるのか

 各操作は、1 つのインデックス クラスに対するグローバルな XOR のような切り替えに貢献します。 パリティは 2 を法とする値にのみ依存するため、反復操作はクラスごとの 2 値の選択に集約されます。 これは、変換空間全体には、反転なし、奇数のみ反転、偶数のみ反転、または両方反転の 4 つの状態しかないことを意味します。 これらの状態のいずれも配列全体で均一なパリティを生成しない場合、長いシーケンスは 2 を法としてこれら 4 つのケースのいずれかに還元されるため、一連の操作は生成できません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # check parity groups
        odd = [a[i] % 2 for i in range(0, n, 2)]
        even = [a[i] % 2 for i in range(1, n, 2)]
        
        # if already uniform
        if len(set(a[i] % 2 for i in range(n))) == 1:
            out.append("YES")
            continue
        
        # try target all-even or all-odd
        def can(target):
            # we choose flip_x, flip_y in {0,1}
            # odd group becomes (odd_parity XOR flip_x)
            # even group becomes (even_parity XOR flip_y)
            # all must equal target
            
            # odd group consistency
            ok1 = all((p ^ 0) == target or (p ^ 1) == target for p in odd)
            # even group consistency
            ok2 = all((p ^ 0) == target or (p ^ 1) == target for p in even)
            return ok1 and ok2
        
        if can(0) or can(1):
            out.append("YES")
        else:
            out.append("NO")
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```The implementation directly encodes the idea that each index class can independently be flipped or not. ヘルパーさん`can(target)`各グループを選択したパリティに統一できるかどうかをチェックします。 1 ずつインクリメントするとパリティが反転するため、XOR 推論が使用されます。 

微妙な点は、パリティを超えて実際の値をシミュレートしていないことです。 偶数性のみが重要であるため、完全な整数を追跡する試みは不要です。

 ## 特殊なケース

 重要なエッジケースは、配列のパリティがすでに均一である場合です。 例えば`[2, 4, 6]`。 アルゴリズムはただちに単一のパリティ クラスを検出し、変換を調査せずに YES を返します。 

もう 1 つのエッジ ケースは、次のような 1 つのインデックス グループが内部的に矛盾している場合です。`[1, 2, 1, 3]`。 偶数インデックス グループではパリティが混合されます。つまり、反転を組み合わせても均一にすることはできません。 この場合、アルゴリズムは両方のターゲット パリティを正しく拒否し、NO となります。 

最終的なエッジケースは最小サイズです`n = 2`、両方の要素が異なるグループに属します。 ここでも、各グループは独立して制御可能であるため、実現可能性は、アルゴリズムが同じパリティ ロジックを通じて正しく評価する一貫したターゲットが存在するかどうかにのみ依存します。
