 ## 問題の理解

 バスケットボールのシュートが成功するまでの一連の距離が与えられています。 各ショットはしきい値に応じてポイントを与えます`d`私たちが選ぶということ。 ショット距離が厳密に以下の場合`d`、そのショットは2点の価値があります。 それ以外の場合、距離が以上の場合`d`、そのショットは3ポイントの価値があります。 

私たちのタスクは、負でない整数を選択することです`d`すべてのショットの合計スコアが正確になるように`k`。 すべての有効な選択肢の中から、`d`、最小のものが必要です。 

ここで重要な構造は、変化するということです。`d`各距離がしきい値のどちら側に該当するかのみに影響します。 増加中`d`いくつかのショットを 3 点グループから 2 点グループに移動し、減少させます。`d`逆のことをします。 

制約は、候補しきい値ごとの直接シミュレーションには十分小さいです。 と`n ≤ 1000`、O(n^2) または O(n log n) のアプローチでも、1 秒の制限内では十分に高速です。 これは、次の複数の候補値をテストする余裕があることをすぐに示唆しています。`d`特に、並べ替えや個別のブレークポイントを利用する場合はそうです。 

重要な観察は、次の値のみが含まれるということです。`d`あるものと等しい`ai`または、ソートされた 2 つの連続する距離の間にあると、ショットの割り当てが変更される可能性があります。 これにより、すべての整数にわたる無限の検索スペースが最大で 1 つに縮小されます。`n + 1`意味のある事例。 

微妙なエッジケースが現れるのは、`d = 0`。 ずっと`ai ≥ 1`、すべてのショットは次のようになります`ai ≥ d`, したがって、すべてのショットが 3 ポイントに貢献します。 多くの場合、これが可能な最大スコアになります`3n`これは有効な候補であり、明示的に含める必要があります。 

もう 1 つのエッジ ケースは、希望のスコアが得られない場合です。`k`等しい`2n`つまり、すべてのショットは 2 ポイント グループ内になければなりません。 これは次の場合にのみ発生します`d`は厳密にすべての距離よりも大きいです。 

## アプローチ

 素朴なアプローチは、次のすべての整数値を試してみることです。`d`0 から大きな上限まで、それぞれのスコアを計算し、最小の有効なスコアを選択します。 それぞれについて`d`、すべてスキャンします`n`距離を計算し、それぞれが 2 ポイントまたは 3 ポイントに貢献するかどうかを決定します。 これには小切手ごとに O(n) のコストがかかります。 距離は最大 10^9 になる可能性があるため、安全な上限は`d`また、約 10^9 になる可能性もあり、このアプローチでは最悪の場合非常に遅くなり、10^12 程度の演算が必要になります。 

重要な洞察は、スコア関数は次の場合にのみ変化するということです。`d`配列内の距離の 1 つと交差します。 2 つの連続する並べ替えられた値の間の要素のセット`< d`そして`≥ d`変化しないため、スコアは一定です。 つまり、考慮する必要があるのは、`d`入力値から導出された有限セット内で、通常はすべての個別の距離に 0 を加えたものです。 

配列をソートしたら、いくつの要素が下回るかを維持することで、各候補しきい値のスコアをシミュレートできます。`d`。 として`d`が増加すると、このカウントは単調に増加し、スコアは予測どおりに変化します。

 ## アルゴリズムのチュートリアル

 1. 距離の配列を降順でない順に並べ替えます。 並べ替えは、しきい値を下回る要素の数を推論できるため便利です。`d`O(1) で位置を固定します。 
2. 「3 点グループ」に割り当てられる要素の数を反復処理することで、暗黙的にプレフィックス情報を事前計算します (`ai ≥ d`）。 プレフィックスの合計を直接計算する代わりに、分割点を追跡します。`i`、ここでの要素は`i`に`n-1`3 ポイントを貢献し、残りは 2 ポイントを貢献します。 
3. 可能な分割インデックスごとに`i`0から`n`を選択していると解釈します。`d`間`a[i-1]`そして`a[i]`(境界処理あり)。 サフィックス内のすべての要素`[i, n)`≥ d であり、3 ポイントに貢献しますが、接頭辞は`[0, i)`2得点に貢献。 
4. この分割のスコアを次のように計算します。`2 * i + 3 * (n - i)`。 この式は、各ショットを個別にシミュレートすることなく、スコアリング ルールを直接エンコードします。 
5. このスコアが等しいかどうかを確認します`k`。 存在する場合は、最小値を計算します`d`それがこの分割を達成します。 有効な最小値`d`は 0 (の場合) のいずれかです`i = 0`） または`a[i-1] + 1`いつ`i > 0`。 
6. 最低限の事項を記録しておきます。`d`すべての有効な分割にわたって。 

正確さは、すべての有効なしきい値が、ソートされた配列の 1 つのパーティションに正確に対応するという事実にかかっています。`< d`そして`≥ d`、そのようなすべてのパーティションは、次の間隔で表すことができます。`d`価値観。 

### なぜ効果があるのか

 このアルゴリズムは、可能なしきい値の無限のセットを最大で 1 つに圧縮します。`n + 1`距離のソート順によって定義される同値クラス。 各クラス内での要素の順序は、`d`は変化しないので、スコア関数は一定のままです。 したがって、すべてのスプリット ポジションを列挙すると、考えられるすべての個別の結果が網羅的にカバーされ、最小限の結果が選択されます。`d`有効な結果ごとに、スコアを達成する世界最小のしきい値を確実に見つけることができます。`k`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
a = list(map(int, input().split()))
a.sort()

best = None

for i in range(n + 1):
    score = 2 * i + 3 * (n - i)
    if score == k:
        if i == 0:
            d = 0
        else:
            d = a[i - 1] + 1
        if best is None or d < best:
            best = d

print(best)
```この解決策は、すべてのしきい値が連続するプレフィックスとサフィックスの分割に対応するように距離を並べ替えることから始まります。 ループオーバー`i`以下に該当する要素の数を選択することを表します`d`。 スコア式は、要素ごとのチェックを行わずに、両方のグループの貢献度を直接評価します。 

施工時`d`、境界線の選択が重要です。 正確に望むなら`i`要素は厳密に以下である必要があります`d`、 それから`d`より大きくなければなりません`i-1`-番目の要素以下`a[i]`。 選択する`a[i-1] + 1`は、この分離を強制する最小の整数です。

 ## 特殊なケース

 すべてのショットが 3 ポイントに貢献する必要がある場合、スコアは次のようになります。`3n`に対応します。`i = 0`。 この状況では、アルゴリズムは正しく割り当てます`d = 0`。 たとえば、入力の場合`n = 3`、`a = [5, 10, 20]`、`k = 9`、ループは次のことを見つけます`i = 0`有効かつ返品`0`、すべての`ai ≥ 0`。 

すべてのショットが 2 ポイントに貢献する必要がある場合、スコアは次のようになります。`2n`に対応します。`i = n`。 のために`a = [2, 4, 6]`、`k = 6`、有効な分割は次のとおりです。`i = 3`。 アルゴリズムは次のように割り当てます。`d = a[2] + 1 = 7`これは、すべての要素が厳密に下回っていることを保証する最小のしきい値です。`d`。 

答えが 2 つの隣接する値の間にある場合、次のようにします。`a = [3, 8, 10]`そして、以下の 2 つの要素が必要です`d`、アルゴリズムが選択します`i = 2`とセット`d = a[1] + 1 = 9`。 これにより保証されます`3, 8 < 9`そして`10 ≥ 9`、曖昧さなく意図した分割を維持します。
