 ## 問題の理解

 この問題では、有効な配列の部分列の数を数えるよう求められます。 サブシーケンスは、いくつかのインデックスを選択し、元の順序を維持することによって作成されます。 選択された長さのシーケンス`k`最初に選択した値が次の値で割り切れる場合に有効です。`1`、2 番目に選択された値は次の数で割り切れます。`2`、3番目によって`3`、 等々。 どのインデックスが選択されたかのみを考慮するため、値は同じだが位置が異なる 2 つのサブシーケンスは別々にカウントされます。 答えはモジュロで出力する必要があります`1e9 + 7`。 

入力は長さの配列です`n`、 どこ`n`到達できる`100000`値は次のように大きくできます。`10^6`。 二次動的計画法ソリューションには、すでに次のものが必要になります。`10^10`最悪の場合、動作が遅すぎます。 値の制限は、値の約数の数は最大で次のとおりであるため、数値の割り算の構造がキーであることを示唆しています。`10^6`効率的に処理できるほど小さい。 

よくある間違いは、サブシーケンスをインデックスではなく値で追跡することです。 たとえば、入力の場合`3`と配列`1 1 1`、すべての単一要素が異なるサブシーケンスを形成するため、答えは次のようになります。`3`、 ない`1`。 もう 1 つの注意が必要なケースは、必要な位置のために値がサブシーケンスを拡張できない場合です。 入力用`2`と配列`2 1`、その続き`[2,1]`2 番目の要素は次の要素で割り切れる必要があるため、無効です。`2`、 そして`1`そうではありません。 正しい答えは、`2`、から来ています`[2]`そして`[1]`。 現在の長さを考慮せずに値だけをチェックする不注意な解決策は、オーバーカウントを引き起こす可能性があります。 

別の境界ケースは次の値です。`1`。 以来`1`はすべての正の整数で割り切れるため、有効なサブシーケンス内の任意の位置に配置できます。 入力あり`3`と配列`1 1 1`、答えは空ではないすべてのサブシーケンスです。`7`。 

## アプローチ

 直接的なアプローチは、すべてのサブシーケンスを構築することです。 各サブシーケンスについて、最初に選択した要素が次の数で割り切れるかどうかを確認できます。`1`、その 2 番目の時刻`2`、 等々。 これは定義に正確に従っているため、正しいです。 ただし、長さの配列`100000`もっている`2^100000 - 1`空ではないサブシーケンスが存在する可能性があるため、列挙することは不可能です。 

より良い方向は、配列を左から右に処理し、現在の長さごとに有効なサブシーケンスがいくつ存在するかを維持することです。 配列のいくつかのプレフィックスをすでに処理していると仮定します。 新しい価値観が見えたら`x`、次に必要な位置が分割される既存の有効なサブシーケンスの次の要素になる可能性があります。`x`。 

重要な観察は、以下の全長分布は決して必要ないということです。`n`。 値`x`新しいサブシーケンスの長さを作成するのに役立つだけです`i`いつ`i`分割する`x`。 以来`x <= 10^6`、約数の数が少ない。 これらの長さのみを更新できます。 

させて`dp[i]`有効な長さの部分列の数を表します`i`これまでに処理された要素から形成されます。 値を処理するとき`x`、すべての約数`d`の`x`長さの部分列を意味します`d - 1`長さまで伸ばすことができます`d`追加することで`x`。 更新します`dp[d] += dp[d-1]`。 長さ`1`すべての数値は次で割り切れるため、このケースは常に可能です。`1`、 それで`dp[1]`要素ごとに 1 ずつ増加します。 

更新順序は重要です。 現在の値が同じサブシーケンス内で複数回再利用されないように、除数を降順で処理する必要があります。 短い長さから長い長さに更新すると、新しく作成されたサブシーケンスが同じ配列要素を使用してすぐに再度拡張される可能性があり、これは無効になります。

 ## アルゴリズムのチュートリアル

 1. 動的プログラミング配列を作成します。`dp[i]`有効な長さのサブシーケンスの数を格納します`i`配列の現在のプレフィックスを処理した後。 最初は要素が使用されていないため、すべての値はゼロです。 
2. すべての配列値を反復処理します。`x`左から右へ。 現在の値で長さの新しいサブシーケンスを開始できます。`1`、だから増やす`dp[1]`1つずつ。 
3. すべての約数を求めます`x`。 各約数について`d`より大きい`1`、 アップデート`dp[d]`追加することで`dp[d-1]`。 その理由は、長さのすべての有効な部分列が`d-1`追加できる`x`有効な長さになる`d`。 
4. 除数を降順に処理します。 これにより、以前の配列要素のサブシーケンスのみに基づいて遷移が維持され、現在の要素が複数回カウントされることがなくなります。 
5. 配列全体が処理された後、すべてを合計します。`dp[i]`価値観。 空ではない有効なサブシーケンスはすべてある程度の長さを持っているため、この合計が答えになります。 

なぜ効果があるのか:

 不変条件は、最初の処理後の`j`要素、`dp[i]`長さの有効なサブシーケンスの数と正確に等しい`i`それらだけを使用して`j`要素。 新しい要素のとき`x`を考慮した場合、考えられる新しいサブシーケンスは、で終わるものだけです。`x`。 前の部分はすでに有効な長さのサブシーケンスである必要があります`d-1`、 どこ`d`分割する`x`、新しい要素が位置を占めるため`d`。 このアップデートでは、これらの拡張機能のみがカウントされ、それ以外はカウントされません。 降順更新では、前の部分に現在の要素が含まれないことが保証されるため、カウントされたすべてのサブシーケンスは一意のインデックス セットに対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10 ** 9 + 7

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    dp = [0] * (n + 2)

    for x in a:
        divs = []
        i = 1
        while i * i <= x:
            if x % i == 0:
                divs.append(i)
                if i * i != x:
                    divs.append(x // i)
            i += 1

        divs.sort(reverse=True)

        for d in divs:
            if d == 1:
                dp[1] = (dp[1] + 1) % MOD
            elif d <= n:
                dp[d] = (dp[d] + dp[d - 1]) % MOD

    print(sum(dp) % MOD)

if __name__ == "__main__":
    solve()
```配列`dp`サイズは次のとおりです`n`サブシーケンスは要素の数を超える長さを持つことができないためです。 トランジションには、実際に表示される位置のみが必要です。 

各値について、コードはまず平方根までのすべての数値をチェックして約数を収集します。 最大の値は`10^6`, これでも十分速いです。 除数を降順に並べ替えることは、現在の要素の無効な再利用を防ぐための詳細です。 

いつ`d == 1`の場合、値はそれ自体で新しいサブシーケンスを作成します。 より大きな約数の場合、`dp[d-1]`は、現在のインデックスより前で終了するサブシーケンスをすでに表しているため、現在の値を追加すると、長さの新しい有効なサブシーケンスが作成されます。`d`。 

Python の整数はオーバーフローしませんが、更新中にモジュロ演算が適用され、格納された値の境界が維持されます。

## テストケース```python
import sys
import io

MOD = 10 ** 9 + 7

def solution(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    dp = [0] * (n + 2)

    for x in a:
        divs = []
        i = 1
        while i * i <= x:
            if x % i == 0:
                divs.append(i)
                if i * i != x:
                    divs.append(x // i)
            i += 1

        divs.sort(reverse=True)

        for d in divs:
            if d == 1:
                dp[1] += 1
            elif d <= n:
                dp[d] = (dp[d] + dp[d - 1]) % MOD

    return str(sum(dp) % MOD)

assert solution("2\n1 2\n") == "3"
assert solution("5\n2 2 1 22 14\n") == "13"

assert solution("1\n1000000\n") == "1"
assert solution("3\n1 1 1\n") == "7"
assert solution("4\n2 3 4 6\n") == "7"
