 ## 解決策
 ## 問題の理解

 一連のビーコンをライン上に配置しています。 各ビーコンには位置と現在の電力があります。 パワーのあるビーコン`p`包含区間をカバーする`[x - p, x + p]`。 すべてのラウンド中、異なる電力を持つ重複する間隔のペアごとに、弱いビーコンが 1 つの電力を獲得します。 すべての利益は同時に起こります。 タスクは、プロセスが安定状態に達した後にカバーされる整数位置の合計数を決定することです。 

到達可能なビーコンの数`2 * 10^5`, したがって、ラウンドをシミュレートすることは不可能です。 1 ラウンドで多くのパワーが変更される可能性があり、パワーは一度に 1 つずつ増加するため、ラウンド数も多くなる可能性があります。 この入力サイズでは、次のような解決策が必要です。`O(n log n)`これにより、多くのビーコンのペア間での繰り返しの比較を伴うものはすべて除外されます。 

主なトラップは、間隔だけでなく、パワーが変化するという事実によって引き起こされます。 最初は別のビーコンから分離されていたビーコンは、ある程度の増加後に接続されるようになります。 最初に重複する間隔のみをマージする解決策は正しくありません。 

例えば：```
2
0 1
5 3
```間隔は`[-1,1]`そして`[2,8]`、最初のものが終了した直後に 2 つ目が開始されるため、それらはすでに重なっています。 力が均等になるのは、`3`、そして最後の結合は`[-3,8]`、長さあり`12`。 最初の共用体のみを保持する不注意な実装では、次の出力が出力されます。`10`。 

別の例は次のとおりです。```
3
0 1
4 1
8 5
```最初の 2 つのビーコンは重なりませんが、3 番目のビーコンが 2 番目のビーコンに到達します。 2 番目のビーコンが増加し、最終的には最初の 2 つを同じ最終コンポーネントに接続できます。 新たに作成されたオーバーラップを無視すると、この連鎖反応を見逃すことになります。 

最後のエッジ ケースは、コンポーネント内で最大電力を持つビーコンです。 それは決して成長することはありませんが、弱いビーコンは最終的に同じパワーに達します。 すべてのビーコンを対称的に成長するかのように扱うと、誤った最終出力が与えられます。 

## アプローチ

 直接的なアプローチは、プロセスをシミュレートすることです。 ラウンドごとに、ビーコンのすべてのペアをチェックし、重複するペアをすべて見つけて、弱いパワーを増やすことができます。 これはルールに正確に従っているため、これは正しいです。 ただし、すべてのペアを確認するとコストがかかります`O(n^2)`ラウンドごとに。 と`n = 2 * 10^5`、1 回のフル スキャンでさえすでにコストが高すぎ、ラウンド数は小さな定数によって制限されません。 

重要な観察は、プロセスが接続されたグループにのみ依存しているということです。 重複する間隔の接続されたグループ内では、最大電力を増加させるためのより強力なビーコンがないため、最大電力は変わりません。 他のすべてのビーコンには、最大電力ビーコンに至る重複するパスがあるため、すべてのビーコンが同じ最大電力に達するまで、増加はこのパスに沿って伝播します。 

これは、動的プロセスを静的マージ プロセスに置き換えることができることを意味します。 ビーコンを左から右に処理します。 処理されたすべてのグループは、その左端の位置、右端の位置、およびその中の最大パワーによって表されます。 両方が最終累乗まで拡張された後、新しいグループが前のグループと重なる場合、それらは実際には同じ最終コンポーネントに属している必要があります。 それらを統合し、より大きな最大出力を維持します。 

新しいビーコンの影響を受けるのは最後に処理されたコンポーネントのみであるため、スタックで十分です。 2 つのコンポーネントをマージした後、新しいコンポーネントはその前のコンポーネントにも到達できるため、最後の 2 つのスタック エントリが重複している間、マージを繰り返します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |`O(r * n^2)`|`O(n)`| 遅すぎる |
 | 最適 |`O(n log n)`|`O(n)`| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのビーコンを位置に基づいて並べ替えます。 この順序で処理するのは、将来発生する可能性のあるすべてのインタラクションは、既に表示されているコンポーネントまたは右側のコンポーネントに対してのみ発生する可能性があるためです。 
2. 現在のビーコンから新しいコンポーネントを作成します。 左右の境界線は両方ともビーコンの位置であり、そのパワーはビーコン本来のパワーです。 
3. 新しいコンポーネントをスタック内の以前のコンポーネントと比較します。 最後の間隔が重なった場合、それらを分離したままにすることはできません。 左側のコンポーネントから左側の境界を取得し、右側のコンポーネントから右側の境界を取得して、両方の最大パワーを取得して、これらをマージします。 
4. 新しいマージされたコンポーネントがまだ前のスタック要素と重なっている間、後方へマージを続けます。 これは、いくつかの古いコンポーネントを吸収するのに十分なほど拡張する強力なコンポーネントを処理します。 
5. すべてのビーコンが処理された後、すべてのスタック エントリが 1 つの最終的な安定したコンポーネントになります。 それらの間隔の長さを合計します。 

なぜ機能するのか: 不変条件は、最初の処理後の`i`ビーコンのみを使用して形成できる最終コンポーネントがスタックに含まれています。 コンポーネント内のすべての弱いビーコンが最終的にその値に達するため、コンポーネントは最終的な最大電力を保存します。 2 つの隣接する格納されたコンポーネントが重なると、それらのビーコンは安定化後に相互に影響を与えるため、それらを分離しておくと最終コンポーネントの定義に違反します。 マージを繰り返すと、挿入のたびに不変式が復元されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = []
    for _ in range(n):
        x, p = map(int, input().split())
        a.append((x, p))

    a.sort()

    stack = []

    for x, p in a:
        stack.append([x, x, p])

        while len(stack) >= 2:
            l1, r1, p1 = stack[-2]
            l2, r2, p2 = stack[-1]

            if l2 - p2 <= r1 + p1:
                nl = l1
                nr = max(r1, r2)
                np = max(p1, p2)

                stack.pop()
                stack.pop()
                stack.append([nl, nr, np])
            else:
                break

    ans = 0
    for l, r, p in stack:
        ans += r - l + 1

    print(ans)

if __name__ == "__main__":
    solve()
```stack メソッドは左から右の処理に依存しているため、入力は最初にソートされます。 各スタック エントリには、安定化後に重要な情報、つまり極端な位置と最大電力のみが保存されます。 

重複チェックでは、最終的に拡張された間隔が使用されます。 2 つのコンポーネント`[l1, r1]`そして`[l2, r2]`力を持って`p1`そして`p2`対話する場合`l2 - p2 <= r1 + p1`。 マージ操作では最大の電力が維持されます。これは、接続されたコンポーネント全体が共有する最終的な電力だからです。 

最後のループは包括的な長さを計算するため、`[l, r]`は`r - l + 1`。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    data = sys.stdin.read().split()
    sys.stdin = old

    if not data:
        return ""

    it = iter(data)
    n = int(next(it))
    a = []

    for _ in range(n):
        x = int(next(it))
        p = int(next(it))
        a.append((x, p))

    a.sort()
    stack = []

    for x, p in a:
        stack.append([x, x, p])
        while len(stack) >= 2:
            l1, r1, p1 = stack[-2]
            l2, r2, p2 = stack[-1]
            if l2 - p2 <= r1 + p1:
                stack.pop()
                stack.pop()
                stack.append([l1, max(r1, r2), max(p1, p2)])
            else:
                break

    ans = sum(r - l + 1 for l, r, p in stack)
    return str(ans) + "\n"

```スタックは最初に 2 つのコンポーネントを作成します。 2 番目のコンポーネントは次のように展開されます。`[2,8]`、重なっている`[ -1,1 ]`, したがって、それらはマージします。 最後のコンポーネントにはパワーがあります`3`と間隔`[-3,8]`、長さを与える`12`。 

のために```
3

```最初の 2 つのビーコンは、電源を備えたコンポーネントにマージされます`1`。 3 番目のビーコンが挿入されると、その間隔は`[3,13]`はそのコンポーネントの最後の間隔と重なるため、構造全体が 1 つのコンポーネントになります。 蓄積される最大電力は、`5`、生産`[-5,13]`長さのある`19`。
