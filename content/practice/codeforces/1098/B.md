 ## 解決策
 ## 問題の理解

 サイズのグリッドが与えられています$n \times m$ここで、各セルには、A、G、C、または T の 4 つの文字のいずれかが含まれます。厳格なローカル ルールを満たす同じ次元の新しいグリッドを構築する必要があります。つまり、2 x 2 のサブグリッドごとに 4 つの異なる文字をすべて 1 回だけ含める必要があります。 

この状態は非常に強いです。 これは、隣接する行のペアと隣接する列のペアを取得するたびに、結果として得られる 4 つのセルが A、G、C、T の順列を形成する必要があることを意味します。目的は、有効なグリッドを構築することだけではなく、元のグリッドにできるだけ近いグリッドを選択して、変更されたセルの数を最小限に抑えることです。 

制約により、最大で$3 \cdot 10^5$セルの合計。 これにより、考えられるすべてのグリッドを明示的に考慮しようとしたり、複数の候補に対してコストのかかるローカル チェックを使用してセルごとの最適化を試みたりするアプローチは即座に除外されます。 どのソリューションも、セル数が線形に近くなければなりません。 

単純ですが当然の間違いは、ローカルで制約を適用しながら行ごとにグリッドを構築しようとすることです。 問題は、制約が行または列単独にローカルではなく、すべてのセルを 3 つの近傍セルと結合し、初期の貪欲な選択が後でコストのかかる修正を強制する可能性があることです。 

たとえば、2 × 3 グリッドの場合は次のようになります。```
A G C
T A G
```貪欲なフィルでは、最初の 2 列が有効な 2x2 ブロックを形成することを保証できますが、その後の列 3 の調整により以前の一貫性が損なわれ、カスケード変更が強制される可能性があります。 これは、制約によってローカルに最適化可能な構造ではなく周期構造が作成されるために発生します。 

もう 1 つの落とし穴は、グリッドを任意に埋めた後、2 x 2 の正方形すべてを個別にチェックすることで妥当性を強制しようとすることです。 このアプローチでは有効なチェックは生成されますが、構築のガイドにはなりません。また、1 つのセルを変更すると最大 4 つの 2 x 2 ブロックに影響するため、違反をローカルで修正することは独立していません。 

## アプローチ

 重要な観察点は、有効なテーブルは高度に構造化されており、周期的であるということです。 すべての 2 x 2 ブロックには 4 文字すべてが 1 回だけ含まれている必要があるため、有効な構成はグリッド全体で一貫したパターンを繰り返す必要があります。 

単一の有効な 2 x 2 ブロックを見ると、それは 4 つの文字の順列です。 このようなブロックを選択すると、グリッドの残りの部分は基本的にパリティ制約によって決まります。1 ステップ右または下に移動すると、隣接するすべての 2 x 2 ブロックが有効なままになるように、一貫した方法で文字を変換する必要があります。 

これは、固定の 2 x 2 テンプレートと 2 つのバイナリ次元から有効なグリッドを生成できることを意味します。 具体的には、 に基づいて文字を割り当てることが考えられます。$(i \bmod 2, j \bmod 2)$ただし、工夫が必要です。A、G、C、T を 4 つのパリティ位置に割り当てる方法は複数あります。 がある$4!$4 つの文字を並べ替えますが、特定の構造化された配置のみがグリッド全体で一貫したタイリングを生成します。 実際、2 つの独立した置換 (偶数行と奇数行に 1 つ) を選択し、それらを列全体で一貫して組み合わせると、有効な構築ファミリーが得られることがわかります。 

これについてより堅牢な考え方は次のとおりです。有効なグリッドは両方向に 2 周期でなければなりません。つまり、グリッド全体が 2 × 2 のタイルの繰り返しで構成されます。 したがって、問題は、考えられる少数の定数の 2 × 2 基のパターンの中から最良のものを選択し、それをグリッド全体に拡張することに帰着します。 

本質的に異なる有効な 2 x 2 パターン (行と列の交換まで) は 12 個しかありませんが、それらを注意深く列挙する必要さえありません。 代わりに、文字の基本的な順序を修正し、パリティ クラス間で割り当てを交換および回転することによって生成される少数の順列セットを考慮することができます。 

候補パターンごとに、O(nm) 時間で完全なグリッドを構築し、元のグリッドに一致するセルの数をカウントできます。 最良の候補者が最適な答えを出します。 

強引なアイデアは、行と列ごとに独立してパリティ クラスへの文字の割り当てをすべて試行することですが、選択がグローバルに相互作用するため、これは指数関数的に爆発的に増加します。 妥当性によってグローバルな周期性が強制されるという観察により、検索空間が一定数のテンプレートに縮小されます。

 ## アルゴリズムのチュートリアル

 1. 文字セット S = {A, G, C, T} を修正します。 それらを 2 x 2 の繰り返しパターンに配置する候補の方法を列挙します。 これで十分な理由は、有効なグリッドはすべての 2 x 2 ブロックにわたって一貫性を強制する必要があり、これはグローバルな周期構造を意味するためです。 
2. 4 つの文字のすべての順列を生成します。 各順列は、2 x 2 テンプレート内の位置に文字を割り当てる方法を定義します。 

左上、右上、左下、右下。 
3. 順列ごとに、この 2 x 2 ブロックをすべての行と列にわたって繰り返すことによって、候補グリッドを構築します。 具体的には、セル (i, j) は、順列内の 4 つの位置のうち 1 つを選択する (i % 2, j % 2) によって決定されます。 
4. この構築されたグリッドを元のグリッドと比較し、一致するセルの数を数えます。 不一致の数は、必要な変更の数です。 
5. 不一致を最小限に抑える順列を追跡します。 これにより、最も近い有効な周期構造が選択されることが保証されます。 
6. すべての順列を評価した後、最適に構築されたグリッドを出力します。 

機能する理由: すべての有効なグリッドは行と列のパリティ クラスに一貫した割り当てを誘導する必要があり、これにより 2 x 2 の繰り返し構造が強制されます。 固定テンプレートからの逸脱は、少なくとも 1 つの 2 x 2 サブグリッド制約を破ることになります。 したがって、最適な解決策はこの有限の周期的タイリング群の中にあり、それらを徹底的にチェックすることで、最適な解決策が見つかることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    chars = ['A', 'G', 'C', 'T']

    best_grid = None
    best_score = -1

    # try all permutations of 4 characters
    from itertools import permutations

    for perm in permutations(chars):
        # build candidate grid
        cand = []
        score = 0

        for i in range(n):
            row = []
            for j in range(m):
                val = perm[(i % 2) * 2 + (j % 2)]
                row.append(val)
                if val == grid[i][j]:
                    score += 1
            cand.append("".join(row))

        if score > best_score:
            best_score = score
            best_grid = cand

    print("\n".join(best_grid))

if __name__ == "__main__":
    solve()
```この実装では、4 つの文字の 24 個の順列すべてが反復されます。 順列ごとに、固定の 2 x 2 パターンを割り当て、行インデックスと列インデックスのパリティを使用してグリッド全体にパターンを拡張します。 

インデックスマッピング`(i % 2) * 2 + (j % 2)`2 x 2 のブロック位置を行優先の順序でエンコードします。 これが簡略化の核心です。制約について明示的に推論するのではなく、構造的に制約を強制します。 

スコアは一致するセルの数として計算されます。これは編集を最小限に抑えることと同じです。

 ## 特殊なケース

 重要なエッジ ケースは、入力グリッドがすでに完全に有効である場合です。 この場合、1 つの順列が正確に一致するため、アルゴリズムはそれを変更せずに保存する必要があります。 一致する順列が次の値に等しい最大スコアを達成するため、スコアリング メカニズムによってこれが保証されます。$n \times m$。 

もう 1 つの特殊なケースは、すべての文字が同一である場合です。 入力の場合:```
2 2
AA
AA
```有効な出力では、4 文字すべてを固定パターンで交互に配置する必要があります。 アルゴリズムはすべての順列を評価し、任意に 1 つを選択し、完全に有効なタイリングを生成します。 正確さは、出力内のすべての 2 x 2 ブロックに、入力構造とは関係なく、構造上 4 つの異なる文字がすべて含まれているという事実から得られます。 

最後の微妙なケースは、ローカル パッチは一貫しているように見えても、グローバル パリティの競合が存在する大きなグリッドです。 すべての順列の列挙により、一貫したグローバル パリティの割り当てが確実にテストされるため、部分的な構成によってアルゴリズムが一貫性のない状態に陥ることはありません。
