 ## 解決策
 ## 問題の理解

 1 から 1 までの番号が付けられた一連のボールが与えられます。$n$、それぞれに正の整数のラベルが付いています。 長さのプレフィックスごとに$i$($1 \le i \le n$）、ポジションの数を決定したいと考えています$j$小さい数が大きい（または等しい場合はいずれか）に吸収され、吸収されたボールが削除されるというルールに従って、隣接するボールのペアを繰り返しマージすると、最後に残ったボールとして生き残ることができます。 ハードバージョンの修正$x=1$, そのため、常に最初のボールから計算を開始します。 

主な課題は、すべての操作を単純にシミュレートしようとすると、マージ シーケンスが指数関数的に増加する可能性があることにあります。 と$n$まで$2 \cdot 10^5$と合計$n$同じ次数で区切られたすべてのテスト ケースにわたって、テスト ケースごとに線形または線形に近いアプローチより悪いアプローチは制限時間を超過します。 これにより、考えられるすべてのマージのブルートフォース シミュレーションが即座に除外されます。$i$ボールを 1 つにすると、組み合わせて成長します。 

エッジ ケースには、すべての数値が等しい、厳密に増加する、または厳密に減少するシーケンスが含まれます。 たとえば、すべてのボールにラベルが付けられている場合、$1,1,1,1$そうすると、各マージでどのボールを削除するかを選択できるため、すべてのポジションが潜在的に生き残ることができます。 If the sequence is strictly increasing$1,2,3,4$、生き残るために十分な「強さ」を持っているのは最後のいくつかのポジションだけであり、不用意に貪欲な実装を行うと、決して勝つことができないポジションを誤ってカウントする可能性があります。 もう 1 つの微妙なケースは、大きな数字が早い段階で出現する場合です。左端のボールが巨大な場合、その右側にあるすべてのものを吸収することができ、均等な配分と比較して生き残るポジションの数が変化する可能性があります。 

これらのパターンを理解することは、強引なアプローチから効率的なアプローチに移行するための鍵となります。 

## アプローチ

 ブルートフォース手法では、各プレフィックスに対して反復処理が行われます。$1 \dots i$、次に、考えられるすべてのマージ操作をシミュレートし、どのボールが最後に残る可能性があるかを追跡します。 これは理論的には正しいですが、状態の数は$i$ボールは指数関数的です ($O(2^{i})$）なので、小さなものでも$i$30などはすでに不可能です。 

重要な観察は、ボールが最後まで生き残ることができるのは、先行するすべてのボールの合計が少なくともそれと同じくらい大きい場合のみであるということです。 より正式には、右から左に処理する場合、ボールはその位置にあります。$j$その右側にあるすべての小さなボールの合計が以下の場合に生き残ることができます。$a_j$。 プレフィックスの合計が超過すると、$a_j$、どのような順序でマージしても、それが最後に生き残ったボールになることはできません。 

これにより、アレイの終端から始端に向かって線形スキャンが行われ、現在の「吸収可能な」合計の累計が維持されます。 この合計以上の値を持つボールは、生存可能な位置のセットに追加されます。 生存可能なボールを追加するにつれてプレフィックスの合計は増加し、大きな数が右側の小さな数を吸収できるという事実を捉えています。 この観察を使用して、次のように計算できます。$f(i)$みんなのために$i$1 つの逆方向パスで、カウントを対応する各プレフィックス長に割り当てます。 これにより、複雑さが指数関数的なものから線形なものに軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$そしてそのシーケンス$a$。 以来$x=1$、計算してみます$f(i)$みんなのために$i$1から$n$。 
2. 変数を初期化する`current_sum`ゼロに。 これにより、以前のボールを吸収する可能性のあるボールの累積合計が追跡されます。 
3. 配列を初期化する`survivable`長さの$n$ゼロ付き。 これにより、ボールがその位置にあるかどうかが記録されます$j$プレフィックスとして存続できます。 
4. 配列の末尾 (位置) から繰り返します。$n-1$) 開始方向 (位置 0) に向かって移動します。 各ボールについて: その値の場合$a[j]$以上です`current_sum`、生存可能としてマークします (`survivable[j] = 1`) を追加します$a[j]$に`current_sum`。 そうしないと生き残れません。 
5.充填後`survivable`、プレフィックス配列を初期化します`f`長さの$n$ゼロ付き。 配列を左から右に移動し、これまでに確認された生存可能なボールの累積数を維持します。 このカウントを次のものに割り当てます`f[i]`プレフィックスごとに$i+1$。 
6. の値を出力します。`f`で始まるすべてのプレフィックスに対して$x=1$。 

機能する理由: 右から左に反復することにより、各ボールは、マージされた可能性のある右側のすべてを吸収できる場合にのみ生存可能とみなされます。 累積合計の不変条件により、マージ シーケンスで最後に生き残る可能性のあるボールのみをカウントすることが保証されます。 ボールがこのチェックに失敗すると、それより前のボールはその恩恵を受けることができないため、後方パスで十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, x = map(int, input().split())
    a = list(map(int, input().split()))
    
    survivable = [0] * n
    current_sum = 0
    for i in range(n-1, -1, -1):
        if a[i] >= current_sum:
            survivable[i] = 1
            current_sum += a[i]
    
    f = []
    count = 0
    for i in range(n):
        count += survivable[i]
        f.append(count)
    
    print(' '.join(map(str, f[x-1:])))
```このソリューションでは、まず生存可能なボールを右から左にマークし、次に各プレフィックスの累積カウントを計算します。 使用する`current_sum`シーケンスの初期の大きな数値が複数の小さな数値を吸収する可能性がある場合を正しく処理できるようにします。 ループは最後から始まるため、最後のボールなどの境界条件は自然に処理されます。 使用する`f[x-1:]`必要なプレフィックスのみを出力します。
