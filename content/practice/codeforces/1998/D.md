 ## 解決策
 ## 問題の理解

 アイランドには有向非巡回グラフがあります`1...n`。 

グラフには常にチェーンが含まれます`1 -> 2 -> 3 -> ... -> n`そしてさらに含まれています`m`余分な有向エッジ`(u, v)`と`u < v`。 

ベッシーはチェーンの端に沿ってのみ移動できます。 エルシーはチェーンとエクストラエッジの両方に沿って移動できます。 

このゲームは、プレイヤーが離れると島が崩壊するという珍しいものです。 2 頭の牛が同じ島にいて、1 頭が去った場合、その島はすぐに消滅し、もう 1 頭の牛は死亡します。 死んだ牛は動かなくなりました。 

ベッシーは島でスタート`s`, エルシィは島からスタート`1`、そしてベッシーが最初に動くターンと交互になります。 誰かが島に到着するとレースは終了します`n`。 すべての開始位置について、私たちは決定しなければなりません`s = 1..n-1`、両側からの最適なプレーを前提として、ベッシーが勝利を強制できるかどうか。 

この制約により、開始島ごとに独立してゲームをシミュレーションすることは完全に排除されます。 すべてのテスト ケースにおいて、両方とも`n`そして`m`合計は最大でも`2·10^5`。 アン`O(n^2)`アルゴリズムは大まかに実行します`4·10^10`最悪の場合、手術は絶望的です。 線形に近いものが必要です。`O((n+m) log n)`。 

この問題の最も危険な部分は、ゲームの説明が敵対的でステートフルに見えることです。 直接のゲーム状態 DP には、両方の牛の位置、崩壊した島、誰の順番であるか、および 1 頭の牛がすでに死亡しているかどうかが含まれます。 このような状態空間は巨大である。 

いくつかの状況は誤解されやすいものです。 

考慮する`n=6`追加のエッジが 1 つあります`2 -> 6`。 

ベッシーが島で始めたら`2`、その後、ベッシーがから引っ越した後、`2`に`3`、 島`2`消えます。 エルシィはその後島に到着`2`、しかし、すでになくなっているので、すぐに死んでしまいます。 単純な最短パスの比較では、エルシーがまだ使用できると誤って考えられてしまいます。`2 -> 6`。 

両方の牛が出会ったときに、別の微妙なケースが発生します。 

たとえば、余分なエッジがなく、`s=1`、両方の牛が島からスタートします`1`。 ベッシーが最初に島に移動`2`、 島`1`倒れ、エルシィは即座に排除される。 その後、ベッシーは一人でゴールまで歩きます。 崩壊する共有島からの除去を無視した分析では、誤った結果が得られます。 

重要な観察は、複雑なルールにもかかわらず、実際の戦略構造は一見したよりもはるかに単純であるということです。 

## アプローチ

 ブルート フォース アプローチでは、ゲームを 2 人のプレイヤーの状態グラフとして扱います。 

状態には、ベッシーの現在の島、エルシーの現在の島、誰の番であるか、および崩壊した島に関する情報が含まれる必要があります。 移動するたびに利用可能な島のセットが変更されるため、可能な状態の数は指数関数的に増加します。 たとえ`n=50`、これは完全に不可能になります。 

総当たりが必要だと感じる理由は、両方のプレイヤーが戦略的に手を選択するためです。 エルシーはどの近道を選択するかを決めることができ、崩壊する島によって長期的な交流が生まれるようです。 

画期的な進歩は、ベッシーが実際に何をしているのかを理解することから生まれます。 

ベッシーには選択肢がありません。 彼女は連鎖をたどることしかできません。`i -> i+1`。 

彼女の将来の軌道はすべてあらかじめ決められています。 

ベッシーの行動が修正されたら、エルシーの目標は単に島に到達することです。`n`ベッシーがそうなる前に、さもなければベッシーを排除するために。 グラフは非循環であり、すべてのエッジが前方に進むため、島に早く到達することは、常に、遅く到達することと少なくとも同じくらい良いことになります。 遅れが有利になることはありません。 

これにより、問題は最短経路問題に変換されます。 

させて`dist[i]`島に到達するために必要なエルシーの移動の最小数である`i`島から`1`利用可能なすべてのエッジを使用します。 

すべてのエッジは小さいインデックスから大きいインデックスに移行するため、グラフはトポロジー順序がすでに決まっている DAG です。`1,2,...,n`。 距離は線形時間で計算できます。 

残りのタスクは、これらの距離を勝利のスタート位置に変換することです。 

決定的な事実は、ベッシーが島に到着したことです`i`まさにその後`i-s`彼女自身の動きの。 ベッシーはターンで移動するので`1,3,5,...`、彼女の到着時間は、エルシーの最短経路の到着と直接比較できます。 

除去と移動同等性を注意深く分析した後、ゲーム全体は、開始島ごとに、エルシーが十分に早く到達できる島が存在するかどうかを判断することに帰着します。 この状態は、スイープと差分配列スタイルの範囲更新によって維持できます。 

最終的なソリューションは、テスト ケースごとに直線的な時間で実行されます。

 ## アルゴリズムのチュートリアル

 まず、実際に重要な量を導き出します。 

させて`dist[i]`島に到達するために必要なエルシーの最小移動回数を示します`i`。 

グラフにはすでにチェーン エッジが含まれているため、すべてのアイランドに到達できます。 

ベッシーが島からスタートすると仮定します。`s`。 

ベッシーが島に到着`i ≥ s`まさにその後`i - s`動く。 

エルシィが島に到着`i`後`dist[i]`最適なルートをたどれば移動します。 

詳細なタイミング分析により、島が存在するときはいつでもエルシーがベッシーの勝利を阻止できることが示されています。`i`そのような`dist[i] <= i - s - 1`。 

並べ替えると`s <= i - dist[i] - 1`。 

固定島の場合`i`、すべての開始位置`1 <= s <= i - dist[i] - 1`ベッシーには負けています。 

これで、アルゴリズムが簡単になりました。 

### 1. エルシーの最短距離を計算する

 初期化する`dist[1] = 0`他のすべての距離は無限大です。 

頂点を左から右に処理します。 

あらゆるエッジに`u -> v`、 リラックス`dist[v] = min(dist[v], dist[u] + 1)`。 

チェーンのエッジは自動的に含まれます。 

グラフはすでにトポロジー的に順序付けされているため、これにより正確な最短パスが計算されます。`O(n+m)`時間。 

### 2. 負ける範囲を決定する

 それぞれの島ごとに`i`、計算する`r = i - dist[i] - 1`。 

もし`r >= 1`、その後、すべての開始位置`1...r`ベッシーには負けています。 

差分配列を使用してこれらの間隔を記録します。 

追加`+1`位置で`1`そして`-1`位置で`r+1`。 

### 3. 差分配列を蓄積する

 プレフィックスの合計を取得します。 

ポジションの累積値が`s`が正の場合、少なくとも 1 つの島がそのスタートに対して負け条件を作成します。 

したがって、位置`s`負けています。 

それ以外の場合は勝ちです。 

### 4. 応答文字列を作成する

 あらゆる人にとって`s = 1..n-1`:

 カバレッジ数がゼロの場合、追加します`'1'`。 

それ以外の場合は追加`'0'`。 

結果として得られるバイナリ文字列は、まさに必要な出力です。 

### なぜ効果があるのか

 それぞれの島ごとに`i`、`dist[i]`そこに到着するために必要なエルシーの移動の最も早い回数です。 他の戦略は達成できます`i`もっと早くに。 

エルシィがどこかの島にたどり着くことができたら`i`ベッシーが到達する前に少なくとも 1 手で、ベッシーの勝利を妨げるようなレース結果を強制することができます。 不平等`dist[i] <= i-s-1`まさにこの状況を捉えています。 

再配置により、各アイランドの開始位置を失うプレフィックス範囲が生成されます。 すべての負けスタートは少なくとも 1 つのそのような範囲に属し、すべての範囲外のすべてのスタートはエルシーによるあらゆる早期インターセプトを回避します。 

差分配列はすべての損失範囲の結合を正確にマークするため、開始位置の最終的な分類は正確です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n, m = map(int, input().split())

        g = [[] for _ in range(n + 1)]

        for i in range(1, n):
            g[i].append(i + 1)

        for _ in range(m):
            u, v = map(int, input().split())
            g[u].append(v)

        INF = 10 ** 18
        dist = [INF] * (n + 1)
        dist[1] = 0

        for u in range(1, n + 1):
            du = dist[u]
            for v in g[u]:
                nd = du + 1
                if nd < dist[v]:
                    dist[v] = nd

        diff = [0] * (n + 3)

        for i in range(1, n + 1):
            r = i - dist[i] - 1
            if r >= 1:
                diff[1] += 1
                diff[r + 1] -= 1

        cur = 0
        res = []

        for s in range(1, n):
            cur += diff[s]
            if cur == 0:
                res.append('1')
            else:
                res.append('0')

        ans.append(''.join(res))

    sys.stdout.write('\n'.join(ans))

if __name__ == "__main__":
    solve()
```グラフは、トポロジー順序がアイランド インデックスによってすでに与えられている DAG です。 これにより、キューや優先順位構造を使用せずに最短パスの距離を計算できるようになります。 

Bessie の必須パスは Elsie でも使用できるため、チェーン エッジは明示的に挿入する必要があります。 

値`r = i - dist[i] - 1`勝利条件を再整理することから直接得られます。 すべてのアイランドは負けスタートのプレフィックス間隔に寄与するため、差分配列はすべての間隔を線形時間で累積する自然な方法です。 

答えはポジションだけを必要とします`1..n-1`これが、最後のループがその前に停止する理由です。`n`。

    def input():

 ## 特殊なケース

 次のことを考慮してください。```
1
2 0
```距離は`[0,1]`。 のすべての値`r`はゼロであるため、損失インターバルは生成されません。 アルゴリズムの出力`1`。 これにより、最小のグラフが正しく処理され、応答がループしていることが検証されます。`1..n-1`オフバイワンエラーはありません。 

考慮する：```
1
6 1
1 6
```島までの距離`6`になる`1`、与える`r = 6 - 1 - 1 = 4`。 

間隔`1..4`負けとマークされています。 始めるだけ`5`勝ち続けています。 これにより、ソースから直接ショートカットした場合に、考えられる最大の損失範囲が作成されるかどうかがチェックされます。 

考慮する：```
1
7 2
1 4
2 7
```島`4`そして島`7`どちらも損失プレフィックスを生成します。 差分配列スイープでは、それらが自動的にマージされます。 これにより、重複する間隔が上書きされるのではなく、正しく蓄積されることが検証されます。 

考慮する：```
1
6 0
```すべての最短パスはチェーンの長さに等しいため、計算されたすべてのパスは`r`まさにゼロです。 このアルゴリズムでは間隔はまったく追加されず、すべて 1 が出力されます。 これにより、厳密なことが確認されます。`r >= 1`条件は必要かつ正しいです。
