 ## 解決策
 ## 問題の理解

 この問題では、整数 _m_ を次の値で割ったときの余りを計算するように求められます。$2^n$ここで、_n_ と _m_ は正の整数です。 言い換えれば、2 のべき乗の係数と被除数のサイズが与えられ、被除数をその係数で割った後に残るものを見つけなければなりません。 入力 _n_ は、除数を求めるために 2 を掛ける回数を指定します。一方、_m_ は、その除数を法として減算される数値です。 出力は 0 から 0 までの単一の整数です。$2^n - 1$、剰余を表します。 

制約は中程度ですが、微妙な影響を及ぼします。 _n_ と _m_ は両方とも 10^8 までの大きさにすることができます。 直接コンピューティング$2^n$おおよその数で保存または操作するため、実用的ではありません。$10^{30,000,000}$数字はメモリ上では不可能です。 これにより、文字通り構築するアプローチは除外されます。$2^n$。 したがって、アルゴリズムは、明示的に計算するのではなく、2 の累乗の特性に依存する必要があります。 

_m_ が以下の場合にエッジ ケースが発生します。$2^n$この場合、剰余は単純に _m_ になるか、_m_ が正確に割り切れる場合です。$2^n$、剰余はゼロになります。 たとえば、_n_ = 5 および _m_ = 32 の場合、$2^5 = 32$余りは ​​0 です。計算しようとする不用意な実装$2^n$このような場合、文字通り失敗するかオーバーフローします。 

## アプローチ

 ブルートフォースアプローチでは、次の計算を試みます。$2^n$そして _m_ モジュロを実行します$2^n$。 これは原理的には正しいですが、_n_ が 10^8 までの場合、数値は$2^n$は天文学的に大きいため、標準の整数型では表現できません。 これを直接構築しようとすると、問題の限界をはるかに超えて、膨大な時間とメモリが必要になります。 

重要な洞察は次のとおりです$2^n$は非常に単純なバイナリ表現です。バイナリでは 1 の後に _n_ 個のゼロが続きます。 _m_ モジュロの計算$2^n$_m_ の最後の _n_ ビットを取得することと同じです。 実際には、これはまさにビット単位の AND 演算と同じです。$2^n - 1$達成する、なぜなら$2^n - 1$バイナリでは _n_ 個です。 この観察により、問題は最大の制約でも機能する単一の高速操作に集約され、膨大な数の構築が回避されます。

 ## アルゴリズムのチュートリアル

 1. 整数 _n_ と _m_ を読み取ります。 これらはそれぞれ 2 の指数と減らす数値を指定します。 
2. コンピューティング$mask = 2^n - 1$。 これにより、2 進数で _n_ 個の 1 を含む数値が作成されます。 その理由は、2 の累乗を法とする任意の数値が、このマスクによって分離される最後の _n_ ビットと同等であるためです。 
3. 剰余を次のように計算します。$result = m \& mask$。 ビット単位の AND 演算では、_m_ の最後の _n_ ビットが正確に保持され、上位ビットは破棄されます。 この操作により直接生成されるのは、$m \bmod 2^n$大きな数の演算は必要ありません。 
4. 結果を印刷します。 これにより効率的に計算が完了します。 

これが機能する理由: 不変条件は、任意の整数 _m_ について、除算の余りです。$2^n$_m_ の最下位 _n_ ビットのみに依存します。 との AND 演算$2^n - 1$上位ビットをゼロに設定しながら、それらのビットを保持します。これは残りには影響しません。 これにより、_m_ または _n_ の大きさに関係なく、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
m = int(input())

# 2^n - 1 is a mask with n ones in binary
mask = (1 << n) - 1

# remainder of m divided by 2^n
result = m & mask

print(result)
```このコードは、高速 I/O を使用して入力を読み取り、大きなべき乗を明示的に計算することを避けるために左シフトを使用してマスクを計算し、ビットごとの AND を適用して最後の _n_ ビットを抽出します。 使用する`1 << n`Python の整数には制限がないため、Python では高速かつ安全です。 最終的な出力では、必要に応じて残りが出力されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    m = int(input())
    mask = (1 << n) - 1
    return str(m & mask)

# provided samples
assert run("4\n42\n") == "10", "sample 1"
assert run("1\n58\n") == "0", "sample 2"

 ## 特殊なケース

 _m_ が以下の場合$2^n$の場合、アルゴリズムは _m_ 自体を正しく返します。 たとえば、n = 5、m = 3 の場合、マスク = 31、3 & 31 = 3 となります。_m_ が等しい場合$2^n$、n = 5、m = 32 など、マスクは 31、32 & 31 = 0 です。30 や m = 1073741825 などの大きな _n_ も引き続き機能します。これは、Python が任意精度の整数をサポートしており、ビット単位の AND によって正しい最後の 30 ビットが分離されるためです。 これらのケースでは、アルゴリズムがすべての境界を正しく処理していることが確認されます。
