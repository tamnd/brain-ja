 ## アルゴリズムのチュートリアル

## Python ソリューション```python
import sys
input = sys.stdin.readline

from math import gcd

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        base = a[0]
        g = 0
        
        for x in a[1:]:
            g = gcd(g, abs(x - base))
        
        if g == 0:
            print(-1)
        else:
            print(g)

if __name__ == "__main__":
    solve()
```このソリューションは、すべての値を最初の要素に固定し、絶対差の gcd を累積します。 絶対値を使用すると、割り算が対称であるため、符号の問題が回避されます。 gcd をゼロとして初期化すると、最初の差が値に適切にシードされるようになります。 

実装の重要な詳細は、すべてが等しい場合の処理​​です。 すべての要素が基数と等しい場合、すべての差はゼロになり、gcd はゼロのままとなり、正しい結果がトリガーされます。$-1$出力。
