 ## 解決策
 ## 問題の理解

 各立方体には 2 桁の数字が含まれています。 分割しなければなりません`2n`立方体を正確に 2 つの山に分割`n`それぞれ立方体。 

分割後、Valera は最初のヒープから任意のキューブを選択し、2 番目のヒープから任意のキューブを選択できます。 最初のキューブに次のものが含まれている場合`ab`2番目には次の内容が含まれます`cd`、彼は4桁の数字を取得します`abcd`。 

ヒープ内の順序は関係ありません。 重要なのは、各ヒープにどの「値」が現れるかです。 値の場合`13`最初のヒープに 5 回出現しても、考えられるプレフィックスは 1 つだけです。 同様に、次の場合も`45`2 番目のヒープに 3 回出現しても、可能なサフィックスは 1 つだけです。 

最初のヒープに次のものが含まれているとします。`x`個別の値と 2 番目のヒープに含まれる値`y`明確な価値観。 最初のヒープ内のすべての個別の値は、2 番目のヒープ内のすべての個別の値と組み合わせることができるため、個別の 4 桁の数値の数は正確に次のようになります。`x · y`。 

タスクは、この積を最大化し、ヒープへのキューブの 1 つの最適な割り当てを出力することです。 

制約はキューブ数の点では小さいですが、`2n ≤ 200`ですが、すべてのキューブ値が間にあるため、値はさらに制限されます。`10`そして`99`。 可能な異なる値は 90 個のみです。 これは、ソリューションでは個々の立方体ではなく値の頻度について推論する必要があることを強く示唆しています。 

よくある間違いは、ヒープ内のキューブの数のバランスをとることに重点を置くことです。 目的は、それらの値を保持するキューブの数ではなく、各ヒープ内の**個別の値**の数によって決まります。 

考慮する：```
n = 2
13 13 13 45
```2つ置く`13`を異なるヒープに分割すると、各ヒープに 1 つの異なる値が作成されます。 3番目`13`何も新しいことに貢献しません。 個別カウントをさらに増やすことができる唯一の値は、`45`。 

もう 1 つの微妙なケースは、すべての値が一意である場合です。```
n = 2
10 20 30 40
```両方のヒープに値が存在することはできません。 最善の戦略は、4 つの個別の値をできるだけ均等に分割し、個別のカウントを与えることです。`(2,2)`そして製品`4`。 不用意に貪欲な割り当てを行うと、次のような問題が発生する可能性があります。`(3,1)`そして製品`3`。 

もう一方の極端な場合:```
n = 2
55 55 55 55
```両方のヒープに値を含めることができます`55`ただし、どちらのヒープにも他の値を含めることはできません。 答えは`1`、 ない`4`重複によって新しい個別の値が作成されないためです。 

## アプローチ

 ブルートフォースソリューションでは、あらゆる方法で選択を試みます。`n`最初のヒープのキューブ。 がある$$\binom{2n}{n}$$そういった選択。 最大入力サイズとしては、これは天文学的な大きさです。 たとえ`n = 20`、その数はすでに1000億を超えています。 網羅的な検索は不可能です。 

重要な観察は、実際のキューブのアイデンティティは値の頻度によってのみ重要であるということです。 

値が 1 回だけ出現するとします。 この値は、最大 1 つのヒープに個別の値を提供できます。 

値が少なくとも 2 回出現するとします。 次に、各ヒープに 1 つのコピーを配置し、その値を両方のヒープの個別のカウントに同時に寄与させることができます。 

させて：

-`d`頻度が少なくとも 2 である値の数になります。 
-`s`頻度がちょうど 1 である値の数になります。 

繰り返されるすべての値は、各ヒープに 1 つの異なる値を提供します。 最大数の個別の値が必要な場合は、この寄与が強制されます。 

すべてのシングルトン値は、1 つの個別の値を 1 つのヒープに提供します。 残っている唯一の決定は、どのヒープがそれを受け取るかです。 

ヒープが次のようになった場合`x`そして`y`個別の値の場合:$$x+y = 2d+s$$なぜなら、繰り返されるすべての値は 2 回寄与し、すべてのシングルトンは 1 回寄与するからです。 

製品`x·y`最大化されるのは`x`そして`y`できるだけ近くにいる。 繰り返される値はすでに両方のヒープに均等に寄与しているため、シングルトン値をヒープ間で可能な限り均等に分散するだけです。 

どのヒープが各値の「個別の寄与」を受け取るかを決定した後、残りの重複キューブはすべて目的とは無関係になります。 これらは、各ヒープに正確に含まれるという要件を満たすためにのみ使用できます。`n`立方体。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(\binom{2n}{n})$|$O(1)$| 遅すぎる |
 | 最適 |$O(n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての値の頻度を数え、すべての立方体の位置を記憶します。 
2. 頻度が少なくとも 2 である値ごとに、1 つのオカレンスをヒープ 1 に割り当て、もう 1 つのオカレンスをヒープ 2 に割り当てます。 

これにより、その値が各ヒープに 1 つの異なる値を提供することが保証されます。 
3. 頻度がちょうど 1 である値ごとに、ヒープを交互に配置します。 

最初のシングルトンはヒープ 1 に、2 番目はヒープ 2 に、3 番目はヒープ 1 に、というように続きます。 

交互では、個別の値の数のバランスが可能な限り維持され、積が最大化されます。 
4. コンピューティング$$x = d + \left\lceil \frac{s}{2} \right\rceil, \qquad y = d + \left\lfloor \frac{s}{2} \right\rfloor$$そして出力`x · y`。 
5. いくつかのキューブはまだ割り当てられていません。 これらは、少なくとも 2 回出現した値の追加のコピーです。 
6. しましょう`need1`ヒープ 1 がサイズに達するために必要な追加キューブの数になります。`n`。 
7. 最初の値を割り当てます`need1`未割り当てのキューブをヒープ 1 に、残りのすべての未割り当てキューブをヒープ 2 に配置します。 

これらのキューブの値は対応するヒープにすでに存在しているため、個別の値の数は変更されません。 

### なぜ効果があるのか

 少なくとも 2 つの頻度を持つすべての値は、両方のヒープに同時に寄与できます。 各ヒープに 1 つのコピーを配置することを拒否すると、少なくとも 1 つのヒープ内の個別の値の数が減少し、製品を改善することはできません。 

頻度が 1 のすべての値は、全体で 1 つの異なる値に寄与します。 繰り返されるすべての値が分割されると、個別の値の寄与の合計数が固定されます。$$x+y=2d+s.$$固定合計の場合、2 つの数値が可能な限り等しいときに積が最大になります。 シングルトン値を交互に配置すると、まさにそのバランスの取れた分布が生成されます。 

残りのコピーはヒープ内ですでに表現されている値に属しているため、移動しても変更できません`x`または`y`。 ヒープ サイズのみに影響します。 残りのスロットを任意に埋めると、最適性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    pos = {}
    for i, v in enumerate(a):
        pos.setdefault(v, []).append(i)

    ans = [0] * (2 * n)

    d = 0
    s = 0

    single_heap = 1

    for v, idxs in pos.items():
        if len(idxs) >= 2:
            d += 1
            ans[idxs[0]] = 1
            ans[idxs[1]] = 2
        else:
            s += 1
            ans[idxs[0]] = single_heap
            single_heap = 3 - single_heap

    x = d + (s + 1) // 2
    y = d + s // 2
    best = x * y

    cnt1 = sum(1 for xh in ans if xh == 1)
    need1 = n - cnt1

    for v, idxs in pos.items():
        start = 2 if len(idxs) >= 2 else 1
        for idx in idxs[start:]:
            if need1 > 0:
                ans[idx] = 1
                need1 -= 1
            else:
                ans[idx] = 2

    print(best)
    print(*ans)

if __name__ == "__main__":
    solve()
```辞書`pos`各値のすべての位置を保存します。 これにより、最初の出現、2 番目の出現、および残りのコピーを区別できるようになります。 

最初のパスでは、個別値の数を決定するオカレンスを割り当てます。 繰り返される値の場合、1 つのコピーが各ヒープに配置されます。 シングルトン値の場合、ヒープを交互に使用します。 

この時点では、いくつかのキューブが未割り当てのままになります。 これらのキューブはすべて、すでにどこかに表示されている値の冗長コピーです。 どちらのヒープでも個別の値の数を増やすことはできません。 

変数`need1`ヒープ 1 のサイズに達するまでにあと何個のキューブが必要かを示します`n`。 ちょうどその数の未割り当てのキューブをヒープ 1 に割り当て、残りをヒープ 2 に割り当てます。`2n`、ヒープ 2 は自動的にサイズが決まります。`n`同じように。 

よくある実装上の間違いは、追加の重複を割り当てた後で個別の値をカウントしてしまうことです。 個別のカウントは、最初の割り当てフェーズによって完全に決定されます。 余分な重複は、ヒープ サイズの制約を満たすためにのみ存在します。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    n = int(input())
    a = list(map(int, input().split()))

    pos = {}
    for i, v in enumerate(a):
        pos.setdefault(v, []).append(i)

    ans = [0] * (2 * n)

    d = 0
    s = 0
    cur = 1

    for v, idxs in pos.items():
        if len(idxs) >= 2:
            d += 1
            ans[idxs[0]] = 1
            ans[idxs[1]] = 2
        else:
            s += 1
            ans[idxs[0]] = cur
            cur = 3 - cur

    best = (d + (s + 1) // 2) * (d + s // 2)

    cnt1 = sum(x == 1 for x in ans)
    need1 = n - cnt1

    for v, idxs in pos.items():
        start = 2 if len(idxs) >= 2 else 1
        for idx in idxs[start:]:
            if need1 > 0:
                ans[idx] = 1
                need1 -= 1
            else:
                ans[idx] = 2

    return str(best)

assert run("2\n13 24 13 45\n") == "4"

## 特殊なケース

 次のことを考慮してください。```
2
55 55 55 55
```の頻度`55`は4つです。 アルゴリズムは、各ヒープに 1 つのコピーをただちに配置します。 残りの 2 つのコピーは個別のカウントとは無関係で、ヒープ サイズを埋めるためにのみ使用されます。 両方のヒープに単一の個別の値が含まれています`55`、したがって、答えは次のとおりです`1`。 

考慮する：```
2
10 20 30 40
```すべての値はシングルトンです。 このアルゴリズムは代入を交互に行い、各ヒープに 2 つのシングルトン値を生成します。 個別のカウントは次のようになります。`(2,2)`そして答えは`4`。 あらゆる課題を生み出す`(3,1)`だけを与えるだろう`3`。 

考慮する：```
3
10 10 20 20 30 40
```価値観`10`そして`20`少なくとも 2 回出現するため、それぞれが両方のヒープに寄与します。 価値観`30`そして`40`シングルトンであり、均等に分割されます。 個別のカウントは次のようになります`(3,3)`そして答えは`9`、これは、個別値の寄与の固定合計数の可能な最大積です。
