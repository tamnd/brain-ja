 ## 解決策
 ## 問題の理解

 文字列を入力するように求められます`s`長さの`n`テキスト エディタを使用すると、単一の文字を追加するか、すでに入力されている連続した部分文字列をコピーして最後に貼り付けるという 2 つの操作が可能になります。 目標は、文字列全体を厳密に少ない時間で生成できるかどうかを判断することです。`n`操作。 

各テスト ケースでは、文字列と文字列自体の長さが示されます。 より少ない数で入力できた場合、出力は「YES」になるはずです。`n`それ以外の場合は「いいえ」。 テスト ケース全体のすべての文字列の長さの合計は最大 200,000 であるため、各文字列を線形時間で処理するソリューションはどれも実現可能です。 二次関数となる解`n`遅すぎるだろうから`n`200,000 に達する可能性があります。 

この問題には微妙なケースがいくつかあります。 たとえば、文字列にすべて個別の文字が含まれている場合、コピーする部分文字列がないため、唯一のオプションは各文字を個別に入力することです。 文字列が早い段階でシーケンスの繰り返しを開始する場合、コピーすることで全体の操作を減らすことができます。 長く繰り返される部分文字列のみを検索する不用意なソリューションでは、次のように、最初に 1 つの繰り返し文字がある文字列に対して誤って「NO」を出力する可能性があります。`aa`1 回の追加と 1 回のコピーで入力できます。 

エッジ ケースには、コピーが不可能な長さ 1 の文字列が含まれるため、出力は「NO」になる必要があります。また、最初の 2 文字が同一である文字列は、最初の文字を入力した後にコピーが可能になり、以下の操作が即座に減少します。`n`。 

## アプローチ

 ブルートフォースアプローチでは、各ステップですでに入力された部分のすべての部分文字列を考慮して、それが次のセグメントに一致するかどうかを確認して、文字列の入力をシミュレートしようとします。 この方法は正しいですが、ある長さの文字列を対象としています。`n`、確認が必要になる可能性があります`O(n^2)`最悪の場合、部分文字列が一致します。 と`n`2·10^5 までは管理できなくなります。 

重要な洞察は、単一の操作を保存できるかどうかを確認するだけでよいということです。 以下の文字列を入力するには`n`操作を行うには、最初に繰り返される文字が必要です。 最初の文字を入力すると、後でその文字が再び表示された場合、その最初の文字から始まる少なくとも 1 つ以上の長さの部分文字列をコピーできます。 この観察により、問題は大幅に軽減されます。入力プロセス全体をシミュレートする必要はありません。 必要なのは、文字列の前半または最初の文字の後のどこかに、文字が少なくとも 2 回出現するかどうかを確認することだけです。 そうであれば、少なくとも 1 回のコピー操作を保証でき、各文字を個別に入力する場合と比較して操作を節約できます。 

これにより、解決策は、繰り返される文字に対する単純な線形スキャンに縮小されます。

 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして文字列`s`。 
3. もし`n`が 1 の場合、単一の文字はコピー操作の恩恵を受けられないため、「NO」が出力されます。 
4. それ以外の場合は、最初の文字から最後から 2 番目の文字まで文字列を反復処理します。 
5. 文字がその前の文字と一致するかどうかを確認します (または同等の場合、`s[i]`に登場する`s[0:i]`）。 一致するものが見つかった場合は、最初の部分を入力してコピーを実行できるため、すぐに「YES」を出力し、以下の合計操作を削減します。`n`。 
6. 重複文字がない場合は「NO」を出力します。 

機能する理由: このアルゴリズムでは、部分文字列をコピーすることで少なくとも 1 つの操作を保存できる可能性がある場合にのみ「YES」を出力します。 コピーは以前に入力されたセグメントからのものである必要があるため、文字が繰り返されると、そのようなコピーが存在することが保証されます。 逆に、すべての文字が一意である場合、コピーは不可能であり、最小操作数は正確に`n`ですので、「NO」が正解です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    if n == 1:
        print("NO")
        continue
    found = False
    seen = set()
    for c in s:
        if c in seen:
            found = True
            break
        seen.add(c)
    print("YES" if found else "NO")
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 些細な案件でも即対応いたします`n == 1`。 他のケースでは、文字列を反復処理して、見たことのある文字のセットを維持します。 以前に登場したキャラクターに初めて遭遇したとき、「YES」を出力します。 セットを使用すると、一定時間のルックアップが保証され、複雑さが線形に保たれます。 微妙な点としては、不必要な繰り返しを避けるために、入力行をトリミングしたり、繰り返される文字が見つかったときに早めに中断したりすることが含まれます。

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        if n == 1:
            print("NO")
            continue
        found = False
        seen = set()
        for c in s:
            if c in seen:
                found = True
                break
            seen.add(c)
        print("YES" if found else "NO")
    return output.getvalue().strip()

 ## 特殊なケース

 最小の入力`n = 1`コピーできないため「NO」を返します。 のために`n = 2`2 つの同一の文字がある場合、アルゴリズムは正しく「YES」を出力します。最初の文字を入力した後、その文字をコピーして演算を 2 から 1+1=2 (等しい) に減らすことができるためです。そのため、2 番目の文字が後の長い文字列で出現する場合は、厳密にそれより少ない値しか実行できません。 このアルゴリズムは、すべての一意の文字を含む長い文字列を正しく処理し、操作の節約が存在しないため「NO」を出力します。 また、シーケンスの早い段階で繰り返し文字を含む文字列を処理します。繰り返しを即座に検出し、「YES」を出力します。これにより、繰り返しの存在によってコピー操作が許可されるという不変条件が確認されます。
