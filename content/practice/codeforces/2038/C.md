 ## 解決策
 ## 問題の理解

 整数のリストが与えられ、各整数は x 座標または y 座標のいずれかを表すことができます。 タスクは、このリストから 8 つの整数を選択し、2D 平面上に 4 つの点を形成し、これらの 4 つの点が辺が軸に平行な長方形の角になるようにすることです。 目標は、長方形の面積を最大化することです。 そのような長方形を形成することが不可能な場合は、「NO」と出力する必要があります。 それ以外の場合は、「YES」と、長方形の座標を表す 8 つの選択された数値を出力します。 

考慮すべき最初の制約は、軸に沿って整列された長方形には 2 つの異なる x 座標と 2 つの異なる y 座標が必要であり、各角が有効な (x, y) ペアを持つように、それぞれ 2 回繰り返されることです。 これは、数値が少なくとも 2 回出現しない場合、その数値を使用して長方形を形成できないことを意味します。 同様に、それぞれ少なくとも 2 回出現する個別の値が 2 つ未満の場合は、四角形を形成できません。 最大面積は、各値が少なくとも 2 回出現することを前提として、x 値間の最大距離と y 値間の最大距離を乗算することによって決定されます。 

の境界`n`重要です。 以来`n`2・10^5 とすべての合計に達する可能性があります`n`複数のテスト ケースにわたるテスト ケースも 2·10^5 によって制限されるため、8 つの数値のすべての組み合わせを明示的にチェックするアルゴリズムを用意することはできません。 すべての総当たりチェック`C(n, 8)`サブセットは天文学的に遅いです。 テスト ケースごとに O(n log n) または O(n) を目指す必要があります。 数値の範囲 (-10^9 ～ 10^9) では、頻度カウントに単純な配列インデックスを使用することはできません。 辞書またはソートベースのアプローチが適切です。 

素朴なアプローチを打ち破る可能性のあるエッジケースには、単一の値にクラスター化された繰り返し番号を含むリストが含まれます。 例えば、`[0, 0, 0, 0, 5, 5, 5, 5]`最大面積 25 の長方形を形成できますが、カウントをチェックせずに最小値と最大値のみを選択する不注意な実装では、選択される可能性があります。`[0, 0, 0, 0, 0, 0, 0, 5]`2 つの異なる x と y をそれぞれ 2 回繰り返す必要があるため、これは無効です。 

## アプローチ

 ブルート フォース アプローチでは、4 つの点の考えられるすべての組み合わせが考慮され、それらが有効な長方形を形成しているかどうかがチェックされます。 組み合わせごとに、x 座標に 2 つの異なる値が含まれるかどうか、および y 座標に 2 つの異なる値が含まれるかどうかが検証されます。 面積は次のように計算されます。`(max_x - min_x) * (max_y - min_y)`。 複雑さはおよそ O(n^4) ですが、これはまったく実行不可能です。`n`2・10^5まで。 

この問題を扱いやすくするための重要な洞察は、面積を最大化するには、長方形の辺を定義する最小 2 つの数値と最大 2 つの数値が必要であることを認識することです。 各数値の頻度を数えると、少なくとも 2 回出現する最大 2 つの数値と最小 2 つの数値を選択して、x 座標として機能し、同様に y 座標として機能することができます。 これにより、問題は組み合わせ探索ではなく、並べ替えと頻度カウントの問題に縮小されます。 中央にある他の数値はより広い領域に寄与しないため、少なくとも 2 回出現する最大 4 つと最小 4 つの一意の数値のみが必要です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^4) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして整数のリスト。 
3. 辞書内の各整数の頻度を数えます。 
4. 2 回未満出現する整数をフィルターで除外します。 少なくとも 2 回出現する値のみが長方形の辺として適格です。 
5. 残りの対象となる番号を並べ替えます。 
6. 残っている適格な数値が 2 つ未満の場合は、四角形を形成できないため、「いいえ」を出力して次のテスト ケースに進みます。 
7. それ以外の場合は、x 軸と y 軸に適格な最小値と最大値を選択します。 それらをペアで割り当てます。`(x1, x2)`そして`(y1, y2)`。 
8. 各 x と各 y をペアにして、長方形の 4 つの角を形成します。`(x1, y1)`、`(x1, y2)`、`(x2, y1)`、`(x2, y2)`。 
9. 「YES」と、これらの四隅を表す 8 つの数字を印刷します。 
10. すべてのテスト ケースについて繰り返します。 

なぜ機能するのか: 長方形の領域は`(max_x - min_x) * (max_y - min_y)`。 少なくとも 2 回出現する最小値と最大値を選択することで、両方の軸が最適にカバーされることが保証され、上位 2 つの適格な数値を使用することで、周波数制約を尊重しながら可能な限り最大の領域が確保されます。 他の選択肢を選択すると辺の長さが短くなったり、最小繰り返し要件に違反したりするため、この方法で最大面積を生成できないことはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import Counter

t = int(input())
for _ in range(t):
    n = int(input())
    arr = list(map(int, input().split()))
    
    freq = Counter(arr)
    eligible = [x for x in freq if freq[x] >= 2]
    if len(eligible) < 2:
        print("NO")
        continue
    
    eligible.sort()
    x1, x2 = eligible[0], eligible[-1]
    y1, y2 = eligible[0], eligible[-1]
    
    # Adjust in case the list has duplicates in both ends
    x_candidates = [x for x in eligible if freq[x] >= 2]
    y_candidates = [x for x in eligible if freq[x] >= 2]
    
    x1, x2 = x_candidates[0], x_candidates[-1]
    y1, y2 = y_candidates[0], y_candidates[-1]
    
    print("YES")
    print(f"{x1} {y1} {x1} {y2} {x2} {y1} {x2} {y2}")
```このソリューションでは、カウンターを使用して、少なくとも 2 回発生する値を効率的にフィルターします。 並べ替えにより、最大面積の極端な値を選択できるようになります。 最小と最大の x 座標と y 座標を組み合わせると、長方形の辺が軸に平行になることが保証され、面積が最大化されます。 8 つの数字は、長方形を形成する限り任意の順序で印刷されます。
