 ## 解決策
 ## 問題の理解

 裁判官が隠しバイナリ文字列を持っているというインタラクティブな問題が与えられます。`s`長さの`n`。 私たちの目標は、少なくとも 1 人のキャラクターを特定することです。`s`テスト ケースごとに最大 3 つのクエリを実行します。 各クエリは、バイナリの部分文字列を何回繰り返すかを尋ねます。`t`連続して発生する`s`。 最大 3 つのクエリの後、既知の位置にある単一の文字を推測する必要があります。`s`。 プログラムは、クエリを出力し、その部分文字列の出現回数を示す整数応答を読み取ることによって、審査員と対話します。 

重要な制約はクエリ制限です。テスト ケースごとに実行できるクエリは 3 つだけです。 と`n`最大でも 50 であるため、すべての位置を個別に試すような強引なアプローチはできませんが、長い文字列に対する高度なアルゴリズムも必要ありません。 課題は、応答から明確な文字を確実に推測できるように、部分文字列を戦略的に選択することにあります。 

エッジケースは、文字列が一様である場合、またはパターンが繰り返される場合に発生します。 例えば、`s = "00"`または`s = "11"`長さ 2 の部分文字列だけを尋ねると、素朴なアプローチが誤解を招く可能性があります。`"01"`位置に関係なくゼロのオカレンスを返します。 クエリ戦略が位置を確実に区別できるようにする必要があります。 

## アプローチ

 ブルートフォースアプローチは、長さ 1 のすべての部分文字列を要求することですが、次の場合、すべてのクエリをすぐに使い果たす可能性があります。`n > 3`、クエリ制限に違反しています。 理由を説明せずに 1 より大きい長さの任意の部分文字列を尋ねると、たとえばクエリなど、あいまいな情報が得られる可能性があります。`"11"`で`"10101"`は複数回出現する可能性があり、単一ビットの位置はわかりません。 

重要な観察は、次のことです。`"0"`、`"1"`、`"00"`、 または`"11"`多くの場合、位置を特定するのに十分な情報が提供されます。 各応答は連続した出現をカウントするため、次のように求めると、`"0"`そして`"00"`、最初の文字が次であるかどうかを推測できます。`0`または`1`カウントを比較することによって。 同様に、`"1"`そして`"11"`人に対しても同じことができます。 これは、連続する部分文字列の重複する性質を利用します。つまり、単一ビットと倍精度ビットの合計数がわかれば、少なくとも 1 つの明確な文字を見つけることができます。 

これにより、問題は、考えられるすべての文字列の中の 1 文字の識別を保証する 3 つのクエリ戦略に集約されます。 アルゴリズムが機能するのは、`"0"`、`"1"`、`"00"`、`"11"`は文字の数と位置と直接的な関係があり、カウントに関する単純な算術演算から少なくとも 1 つの文字を導き出すことができます。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、最初に次の数をクエリします。`"0"`。 これにより、文字列内のゼロの合計数が得られます。 少なくとも 1 つのゼロが存在するかどうかはすぐにわかります。 カウントがゼロの場合、すべての文字は`1`。 
2. 次に、次の数をクエリします。`"1"`。 これは最初のクエリを補完します。`"1"`count が 0 の場合、文字列全体が 0 になります。 これで、各タイプに少なくとも 1 つの文字が存在することがわかりました。 
3. 明確な位置を見つけるには、長さ 2 の部分文字列をクエリします。`"00"`もし`"0"`count がゼロ以外、または`"11"`もし`"1"`count がゼロ以外です。 重複する出現回数によって、文字列の最初の文字が繰り返しペアの一部であるかどうかがわかります。 の数が`"00"`ゼロの合計数から 1 を引いた値に等しく、最初の文字はゼロです。 それ以外の場合、最初の文字は 1 です。 対称推論が適用されるのは、`"11"`。 
4. 推測をフォーマットで出力する`0 i c`、 どこ`i`は位置 (1 から始まるインデックス)、および`c`前のステップで決定された文字です。 これにより、最大 3 つのクエリを使用して正確性が保証されます。 

機能する理由: 不変条件は、1 文字のカウントと 2 文字の部分文字列をクエリした後、少なくとも 1 ビットを解決するのに十分な情報が常に存在することです。 すべての位置が長さ 1 または 2 の少なくとも 1 つの部分文字列に関与しており、必要な文字は 1 つだけであるため、クエリは 3 つで十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
print_flush = lambda s: (print(s, flush=True))

t = int(input())
for _ in range(t):
    n = int(input())
    
    print_flush("1 0")
    zeros = int(input())
    
    print_flush("1 1")
    ones = int(input())
    
    if zeros == 0:
        # all ones, pick first position
        print_flush("0 1 1")
        verdict = int(input())
        continue
    if ones == 0:
        # all zeros, pick first position
        print_flush("0 1 0")
        verdict = int(input())
        continue
    
    # query double substring to locate a definite character
    if zeros > 0:
        print_flush("1 00")
        count00 = int(input())
        if count00 > 0:
            print_flush("0 1 0")
        else:
            print_flush("0 1 1")
    else:
        print_flush("1 11")
        count11 = int(input())
        if count11 > 0:
            print_flush("0 1 1")
        else:
            print_flush("0 1 0")
    
    verdict = int(input())
```このソリューションでは、まず文字列が一様であるかどうかをチェックするため、推測が簡素化されます。 次に、2 文字の部分文字列をクエリして、あいまいさを解決します。 印刷後は毎回フラッシングに注意する必要があります。 最初の位置を選択することでシンプルさが確保され、クエリが容易になります。`"00"`または`"11"`正しいビット識別を保証します。
