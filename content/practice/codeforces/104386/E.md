 ## 解決策
 ## 問題の理解

 長方形のグリッドが与えられ、各セルにはすでに固定のいずれかが含まれています。`0`、固定`1`、または未知の`?`。 すべての未知のセルは、後で独立して次のいずれかに置き換えられます。`0`または`1`、各選択肢は等しい確率を持ちます。 すべての置換が行われた後、最終的なバイナリ グリッドを検査し、直交して隣接するペアが含まれているかどうかを確認します。`1`細胞。 

タスクはランダム性をシミュレートすることではなく、最終的なグリッドに隣接する 2 つのグリッドが存在しない確率を計算することです。`1`細胞。 答えは 998244353 を法として指定する必要があります。 

これを確率的制約充足問題として見ると便利です。`?`は自由なバイナリ変数であり、独立したセットを生成する代入の一部が必要です。`1`グリッド グラフのセル。 

グリッド サイズは最大 15 x 15 なので、セルの数は最大 225 です。 これにより、すべての割り当てを列挙するアプローチは即座に除外されます。`?`なぜなら、最悪の場合には 2^225 の可能性があり、これは計算上の実現可能性をはるかに超えているからです。 2^40 でさえ 2 秒以内にすでに境界線に達しているため、セルに対する強引な攻撃は実行できません。 

もう 1 つの素朴なアイデアは、すべての有効な割り当てを直接生成してそれらを数え、2^{疑問符の数} で割ることです。 これには依然として有効な構成をすべて列挙する必要があり、セルの数は指数関数的に増加します。 

2 番目の単純な間違いは、セルを独立して処理したり、貪欲に局所的な決定を試みたりすることです。 隣接性制約によりグリッド全体の選択肢が結合されるため、ローカルの独立性は失われます。 

素朴な推論が破綻する具体的なエッジケースは、まったく未知の 2x2 グリッドです。 割り当ては合計 16 個ありますが、隣接しない割り当てのみです。`1`は有効です。 単純な「セルごとの確率を乗算する」アプローチでは、独立性を誤って仮定し、有効な状態を過剰にカウントしてしまいます。 

主な問題はグローバル隣接性であり、これは幅と高さが小さいグリッド グラフに対するグラフ制約の問題を示唆しています。 これは、行のサブセットに対するプロファイル動的プログラミングの古典的なセットアップです。 

## アプローチ

 ブルートフォースの解決策は、すべての割り当てを反復処理することです。`?`セルを入力し、グリッドを埋めて、隣接するセルのペアがあるかどうかを確認します。`1`が存在します。 各チェックのコストは O(nm) で、2^k 個の割り当てがあります (k は疑問符の数)。 最悪の場合、k = 225 となるため、これは完全に不可能です。 

有効な状態のみに制限したとしても、グリッド内の独立したセットの数は nm 単位で指数関数的に増加します。 問題の構造は、完全なグリッドを列挙することを避け、代わりにソリューションを段階的に構築する必要があることを示唆しています。 

重要な点は、隣接関係の制約がローカルであるということです。つまり、セルはその左、右、上、下に隣接するセルとのみ相互作用します。 グリッドを行ごとに処理する場合、行を埋めるときに未解決の依存関係は前の行との関係だけになります。 これは、各行構成がどのセルに設定されるかをエンコードする、行に対するビットマスク動的プログラミングを示唆しています。`1`。 

各行について、固定制約を尊重する有効なビットマスクをすべて列挙します。`0`、`1`、 そして`?`。 次に、連続する行間を遷移して、垂直方向の競合が発生しないようにし、行内で隣接する 2 つのビットが両方とも存在しないようにします。`1`。 

これにより、問題が nm での指数関数から最大 15 である m での指数関数に減少し、実行可能になります。

 ## アルゴリズムのチュートリアル

 グリッドを行ごとに処理し、各行を長さ m のビットマスクとして扱います。セル (i, j) に 1 が割り当てられている場合、ビット j は 1 になります。 

1. 水平方向に隣接する 1 を含まないすべての有効な行マスクを事前計算します。 これにより、行内に違反がないことが保証されます。 どのマスクでも`mask & (mask << 1) != 0`は無効です。 
2. 各行 i について、固定グリッド制約に基づいて有効なマスクをさらにフィルタリングします。 セルが強制的に 0 に設定されている場合、そのビットは 0 でなければなりません。強制的に 1 に設定されている場合、そのビットは 1 でなければなりません。そうでない場合は、どちらでも構いません。 
3. 2 つの行マスク間の遷移を定義します。`a`(前の行) と`b`(現在の行)。 制約は、1 の垂直方向の隣接が許可されていないことです。`a & b == 0`。 
4. 以下の場合に動的プログラミングを使用します。`dp[i][mask]`は、i までの行の有効な構成の数です。行 i は次の値に等しくなります。`mask`。 
5. 行 0 の制約と一致するすべての有効なマスクを割り当てて、行 0 の dp を初期化します。 
6. 次の行ごとに、垂直互換性を満たすすべての有効な以前のマスクと現在のマスクを反復処理し、カウントを累積することによって dp 遷移を計算します。 
7. すべての行を処理した後、最後の行のすべての有効なマスクの dp[n-1][mask] を合計します。 
8. 結果を 2^{数で割って確率に変換します。`?`モジュラーインバースを使用します。 

これが機能する理由は、すべての完全なグリッド割り当てが行マスクの 1 つのシーケンスに正確に対応するためです。 DP は、すべての水平および垂直隣接制約を満たすシーケンスを正確に列挙し、フィルタリング ステップによって固定セルとの一貫性が保証されます。 それぞれなので`?`は、正確に 2 つの等確率の選択肢を提供し、2^k による正規化により、一様ランダム割り当ての下でカウントが確率に変換されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def main():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    # count question marks
    q = sum(row.count('?') for row in grid)

    # precompute powers of 2
    pow2 = [1] * (n * m + 1)
    for i in range(1, n * m + 1):
        pow2[i] = pow2[i - 1] * 2 % MOD

    inv_pow2 = pow(pow2[q], MOD - 2, MOD)

    # generate valid row masks (no adjacent 1s)
    valid_masks = []
    for mask in range(1 << m):
        if mask & (mask << 1):
            continue
        valid_masks.append(mask)

    # precompute compatibility with each row
    row_allowed = []
    for i in range(n):
        allowed = []
        for mask in valid_masks:
            ok = True
            for j in range(m):
                if grid[i][j] == '1' and not (mask >> j & 1):
                    ok = False
                    break
                if grid[i][j] == '0' and (mask >> j & 1):
                    ok = False
                    break
            if ok:
                allowed.append(mask)
        row_allowed.append(allowed)

    dp = {mask: 1 for mask in row_allowed[0]}

    for i in range(1, n):
        ndp = {mask: 0 for mask in row_allowed[i]}
        for pmask, val in dp.items():
            for cmask in row_allowed[i]:
                if pmask & cmask:
                    continue
                ndp[cmask] = (ndp[cmask] + val) % MOD
        dp = ndp

    total = sum(dp.values()) % MOD
    print(total * inv_pow2 % MOD)

if __name__ == "__main__":
    main()
```コードはまず、水平方向の隣接性を回避し、固定制約を尊重するすべての行の状態を列挙します。 次に、行に対して標準プロファイル DP を実行します。この場合、隣接する行の両方に 1 が含まれる列がないようにすることで、遷移によって垂直互換性が強制されます。 最終結果では、すべての有効な割り当てがカウントされ、次に、によって導入されたランダムな選択肢の数によって正規化されます。`?`。 

実装の微妙な点は、DP が固定配列の代わりに辞書を使用することです。 これにより、無効なマスクの反復処理が回避され、状態空間が各行の制約と一致するマスクのみに制限されます。 もう 1 つの重要な詳細は、2^q のモジュラー逆関数です。これは、未知のセルの均一な独立サンプリングの下で​​生のカウントを確率に正しく変換します。

 ## 特殊なケース

 単一セルグリッド`?`は、確率の正規化ステップを示しています。 DP は有効な構成を 1 つカウントしますが、確率は 2 で割って 1/2 モジュロ 998244353 を生成する必要があります。アルゴリズムは 2^q の逆モジュラを正しく適用します。 

次のような完全に制約された行`11`水平フィルタリングを示します。 マスク生成ステップでは DP の前の無効な状態がすべて除去されるため、遷移は考慮されません。 

強制されたものが交互の位置に表示されるグリッドにより、垂直方向の競合チェックが確実に実行されます。 条件`pmask & cmask == 0`各行が個別に有効に見える場合でも、行全体で重複するものを正確に削除します。
