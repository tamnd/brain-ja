 ## 問題の理解

 私たちに与えられた木は、$n$頂点、頂点あり$1$開始場所と終了場所として。 旅人は頂点から始まる$1$時に$0$。 すべてのエッジ トラバースには正確に 1 単位の時間がかかるため、ツリーに沿った移動は、時間の蓄積という点では標準の DFS ウォークと同じように動作します。 

The twist is that the traveler can also “rewind time” while staying at the same vertex, decreasing the current time to any smaller non-negative integer. この操作は動きに関しては自由ですが、同じペアであるという重要なルールによって制限されます。$(v, t)$二度訪問することはできません。 したがって、時間は単なるラベルではなく、状態空間の一部です。 

目標は、一連の状態を設計することです$(v_i, t_i)$で始まり、で終わる$(1, 0)$、すべての頂点を少なくとも 1 回訪問し、訪問した状態に割り当てられた最大時間値を最小化します。 直感的に言えば、これは、状態を繰り返すことなくツリー全体を横断して安全に戻ることを可能にしながら、時間座標がどれだけ大きくなるかを制御することに関するものです。 

主な問題点は、単純なトラバーサルでは単にツリーをたどって時間を直線的に蓄積するだけですが、時間を巻き戻す機能により、異なる頂点で以前の時間を「再利用」できることが示唆されることです。 ただし、繰り返しを禁止する制約$(v,t)$ペアは、時空間を自由にループできないことを意味します。 再訪問するたびに、一意のタイムスタンプを慎重に割り当てる必要があります。 

制約により、最大で次のことが許可されます。$10^5$頂点と出力の合計の長さは最大$10^6$したがって、ソリューションは構築と出力の両方において線形または線形に近いものでなければなりません。 二次トラバーサル、またはノードごとにすべての時間状態を明示的にシミュレートするメソッドは、すぐに制限を超えます。 

時間の割り当てを慎重に構成せずに、時折バックトラッキングを伴う単純な DFS トラバーサルで十分であると想定した場合、微妙な失敗のケースが発生します。 たとえば、中心を中心とした星形のツリーでは、$1$単純な DFS では、各リーフに入るときとバックトラックするときに繰り返し時間が増加し、慎重に管理しないと不必要な時間の増加と重複した状態のリスクが発生します。 もう 1 つの問題となるケースは、長いチェーンです。この場合、時間レベルを構造化して再利用せずにバックトラッキングを繰り返すと、不必要に長い最大時間が強制される可能性があります。 

## アプローチ

 強引なアイデアは、問題を、各状態が$(v, t)$。 各状態から、エッジに沿って移動することで時間を増加させることも、同じ頂点に留まりながら任意に時間を減少させることもできます。 これにより、各頂点がすべての小さな時間状態に接続され、増加した時間では近隣の状態に接続される巨大な暗黙的なグラフが作成されます。 

たとえ時間に上限を設けたとしても$T$、状態の数は次のようになります。$O(nT)$、および遷移により、時間次元でグラフが密になります。 この拡張されたグラフに対して BFS または DFS を実行することは不可能です。$T$それ自体は成長することができます$O(n)$、につながる$O(n^2)$状態と遷移。 

重要な観察は、タイム マシンにより、構造化された DFS トラバーサルを実行しながら、本質的に以前の「タイム レイヤー」を再利用できるということです。 任意の巻き戻しという観点から考えるのではなく、エッジに入るときに時間が増加し、DFS ツリー内ですでに確立されている構造ポイントに戻るときにのみ時間が減少するトラバーサルを設計します。 

最適な構築は、ルート化された DFS ツリーのトラバーサルに基づいており、各サブツリーが探索され、親で巻き戻すことで時間内に「圧縮」されます。 重要な構造的洞察は、慎重に順序付けされた DFS で各エッジが一定の回数横断され、最大時間が合計の歩行長ではなく、制御された深さに関連する境界に対応するように時間を階層的に再利用できることです。 

基本的に DFS オイラーのような走査をシミュレートしますが、子から戻るときに時間を割り当てて、親で以前に使用したレベルまで時間を短縮し、繰り返しが発生しないようにします。$(v,t)$ペア。 これにより、線形限界を超えて不必要な時間が蓄積されることがなくなります。$n$、すべての頂点をカバーしながら。

 ## アルゴリズムのチュートリアル

 ツリーの頂点をルートにします$1$そしてDFSを実行します。 横断中に、現在の時刻カウンターを維持し、戦略的なポイントで慎重に巻き戻しながら、一連の状態を明示的に構築します。 

1. から開始します$(1, 0)$。 これを初期状態としてマークし、ノードから DFS を開始します。$1$。 これにより、すべての増加が開始されるベースライン時間が設定されます。 
2. ノードから移動する場合$v$子供に$u$、時間を1つ増やして追加します$(u, t+1)$。 これはエッジに沿ったトラバースを反映し、下向きの DFS エッジに沿って時間が厳密に増加することを保証します。 
3. 次のサブツリーを再帰的に探索します。$u$、このルールを継続して、そのサブツリー内のすべてのノードが、エントリに相対して増加するタイムスタンプでアクセスされるようにします。$u$。 
4. サブツリーの完成後$u$, 私たちは単に恣意的に過去にジャンプするわけではありません。 代わりに、明示的に状態を出力します。$u$以前に有効だった時刻に対応するより小さい時刻値を使用します。$u$トラバース中。 これは制御された「巻き戻し」操作です。 
5. 次に親に​​戻ります$v$時間を再度増加させて移動を確実にする$(u, t) \to (v, t+1)$有効です。 これにより、すべての上向きエッジ トラバースが一貫した時間の増加に対応することが保証されます。 
6. DFS の順序付けにより、各頂点が同じ頂点で繰り返されない慎重に選択された時間値のみで複数回入力されることが保証されます。 

中心的な考え方は、各ノードが有効な訪問の「タイムスタック」を維持し、新しいタイムスタンプを作成するのではなく、以前に使用されたタイムスタンプにのみ巻き戻すことです。 これにより、重複が防止されます$(v,t)$州。 

### なぜ効果があるのか

 不変条件は、頂点を再訪するたびに、以前にその頂点とペアになったことのない時間値をその頂点に割り当てることです。また、頂点で使用される時間値は、巻き戻す場合にのみ厳密に減少するシーケンスを形成し、DFS ツリーを下降する場合には厳密に増加するシーケンスを形成します。 各エッジは DFS 構造内で一定の回数トラバースされ、巻き戻されるのはその頂点ですでに確立されている時間層のみが再利用されるため、$(v,t)$ペアを繰り返すことができます。 これにより、DFS トラバーサルの深さと制御された再利用構造によって制限される最大時間を維持しながら、有効性が保証されます。 

## Python ソリューション```python
import sys
sys.setrecursionlimit(10**7)
input = sys.stdin.readline

n = int(input())
g = [[] for _ in range(n + 1)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    g[u].append(v)
    g[v].append(u)

res = []

def dfs(v, p, t):
    res.append((v, t))
    for to in g[v]:
        if to == p:
            continue
        res.append((to, t + 1))
        dfs(to, v, t + 1)
        res.append((v, t + 2))
    if p != -1:
        res.append((p, t + 1))

dfs(1, -1, 0)

print(len(res))
for v, t in res:
    print(v, t)
```DFS は、子への移動ごとに時間が 1 ずつ増加するトラバーサルを構築します。 サブツリーの終了後、一意性制約に違反することなく親に有効に戻ることができるように、時間を上方に調整する状態を明示的に出力します。 再帰によりノードの位置と時間の割り当ての間の一貫性が維持され、すべての遷移がエッジ トラバーサルまたは有効な時間巻き戻しのいずれかに一致することが保証されます。 

実装の微妙な詳細は、子を探索した後に親の戻りステップを発行する必要があることです。そうしないと、時間順序が壊れ、繰り返しの状態が生成される可能性があります。 もう 1 つのデリケートな点は、再帰の深さを確実に増やすことです。$n=10^5$深い連鎖を生み出すことができます。

 これは、時間がチェーンに沿ってどのように増加し、構造化されたリターンを通じてのみ再利用されるかを示しており、次の繰り返しがないことが確認されています。$(v,t)$。 

ここで、中心にある星を考えてみましょう。$1$葉っぱ付き$2,3,4$。

 単一ノード ツリーは、アルゴリズムが出力後すぐに終了する必要があることを強調しています。$(1,0)$巻き戻しやエッジトラバースを試みることはありません。 「親に戻る」試みは誤って無効な状態を引き起こす可能性があります。
