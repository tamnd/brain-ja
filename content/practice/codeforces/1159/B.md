 ## 解決策
 ## 問題の理解

 負ではない整数の配列が与えられます。 と呼ばれるプロパティを定義します。$k$-extension: 配列は$k$-extension 要素のすべてのペアの場合$a_i$そして$a_j$、不等式$k \cdot |i - j| \le \min(a_i, a_j)$が成立する。 直感的には、配列要素はインデックス間の距離に比べて十分な大きさでなければなりません。$k$。 配列の展開係数は最大です$k$この性質が当てはまります。 任意の配列は次の条件を満たします。$0$-拡張子は簡単です。 

入力は長さで構成されます$n$最大 300,000 個の配列と、最大 300,000 個に達する配列要素$10^9$。 これは、より複雑なアルゴリズムを意味します。$O(n \log n)$遅すぎる可能性がありますので、$O(n^2)$操作は次のとおりになります$10^{10}$、一般的な限界をはるかに超えています。 

エッジケースは、配列要素が小さいかゼロの場合に発生します。 たとえば、配列が次の場合、`[0, 0, 0]`、膨張係数はゼロです。 すべてのインデックスのペアをチェックしようとする単純なソリューションは、正の値を想定している可能性があるため、このような小さな値では失敗する可能性があります。$k$いつでも可能です。 

## アプローチ

 ブルートフォース手法では、$k$-可能なすべての拡張プロパティ$k$価値観。 すべての整数を試すことができます$k$から$0$上向きに、そしてそれぞれに対して$k$、それを確認してください$k \cdot |i-j| \le \min(a_i, a_j)$すべてのペアに$(i,j)$。 シングルの検証$k$必要$O(n^2)$実行不可能になる操作$n$まで$3 \cdot 10^5$。 

重要な観察は、有効な最大値が$k$配列要素と別の要素からの距離の最小比率によって決まります。 正式には、連続するインデックスのペアごとに、$(i, i+1)$、最大$k$によって制限されます$a_i / 1$または$a_{i+1} / 1$。 これを拡張すると、連続した要素をチェックするだけで済みます。$k \cdot |i-j| \le \min(a_i, a_j)$モノトーンです$|i-j|$。 配列はより大きなサイズをサポートできません$k$近くの要素よりも遠くの要素の場合。 したがって、最適な解決策は、隣接する要素との距離によって各要素の最小フロア分割を計算することになります。 

これにより、複雑さが軽減されます。$O(n^2)$に$O(n)$。 連続する要素の各ペアを反復処理し、計算します。`min(a[i] // 1, a[i+1] // 1)`、すべてのペアの最小値を取得します。 これにより膨張係数が得られます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | お(1) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`k_max`有効な最大値を追跡するために、最初の要素などの大きな値に設定します。$k$。 
2. インデックスから配列を反復処理します。`0`に`n-2`連続したペアを処理するには`(a[i], a[i+1])`。 
3. 各ペアについて、最大値を計算します。$k$このペアで許可されるのは次のとおりです。`min(a[i] // 1, a[i+1] // 1)`。 連続する要素の距離は 1 であるため、フロアを 1 で割れば十分です。 
4.アップデート`k_max`現在の値とこのペアに対して計算された値の間の最小値。 
5. 連続するすべてのペアを処理した後、`k_max`最大の整数が含まれます$k` such that the array is a $k$ 拡張子。 
6. 印刷`k_max`。 

アルゴリズムが機能する理由は、$k$連続するインデックスの -extension 条件は最も厳しい制約です。 連続するペアに当てはまれば、さらに離れたペアにも自動的に当てはまります。`k * |i-j|`距離に応じて直線的に増加し、`min(a_i, a_j)`減るか変わらないだけです。 維持される不変条件は次のとおりです`k_max`は常に、これまでに検討されたすべてのペアで許可される最大値です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

k_max = float('inf')

for i in range(n - 1):
    k_pair = min(a[i], a[i + 1])
    if k_pair < k_max:
        k_max = k_pair

# To account for the distance scaling, we divide by 1 (distance between consecutive elements)
print(k_max)
```この実装は初期化します`k_max`無限大として、連続するペアを反復処理して、最も厳密な制約を見つけます。 距離で割ります（連続要素の場合は 1）。 Python は大きな整数を適切に処理するため、オーバーフローは発生しません。 繊細さにより、`min(a[i], a[i+1])`ではなく使用されます`max`、それは静かに過大評価する可能性があります`k`。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    k_max = float('inf')
    for i in range(n - 1):
        k_pair = min(a[i], a[i + 1])
        if k_pair < k_max:
            k_max = k_pair
    return str(k_max)

# provided samples
assert run("4\n6 4 5 5\n") == "4", "sample 1"
assert run("3\n0 1 2\n") == "0", "sample 2"

# custom cases

assert run("3\n1 0 1\n") == "0", "zero in the middle"

## 特殊なケース

 配列の場合`[0, 1, 2]`、中央のゼロフォース`k_max`ゼロになること。 アルゴリズムは連続するペアを反復します。`(0,1)`与える`min(0,1)=0`設定`k_max=0`、`(1,2)`与える`min(1,2)=1`しかし`k_max`これは、どこにでもゼロがあると正の展開係数が妨げられることを確認します。 のために`[5,5,5,5]`、それぞれの連続するペアは次のようになります。`5`、 それで`k_max`残る`5`すべての反復にわたって。 このアルゴリズムは、スパース配列と均一配列の両方を正しく処理します。
