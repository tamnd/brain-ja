 ## 解決策
 ## 問題の理解

 直線上の一連の点が与えられますが、最初は完全に接続されていません。 各演算は開始位置、固定ステップ サイズ、長さを指定して、その等差数列セグメント内にあるすべての点を接続します。 すべての操作を処理した後の目標は、ポイント間にどれだけの接続コンポーネントが残っているかを判断することです。 

ここでの接続コンポーネントは標準的なグラフ接続です。操作のいずれかによって作成されたエッジのチェーンを介して 2 点間を移動できる場合、それらは同じグループに属します。 

すべてのテスト ケースにわたるポイントと操作の数という点で制約は大きく、合計で最大数十万に達します。 単一の演算で最大 O(n) 個のエッジを生成できるため、各等差数列ですべてのエッジを明示的に構築するアプローチは即座に除外されます。 したがって、単純な拡張では、最悪の場合、O(n²) にまで劣化します。 

微妙な落とし穴は、各操作が進行中の隣接する要素のみを接続すると仮定し、推移性を考慮せずにそこで停止することです。 たとえば、1-3-5-7 を接続すると、エッジ (1,7) を明示的に追加しなくても、すべてが 1 つのコンポーネントになることを意味します。 

もう 1 つの障害モードは、グローバル構造を使用せずに各操作を独立して扱い、その中でマージすることです。これは、異なる操作が共有ノードを介して相互作用するときに中断されます。 

## アプローチ

 ブルート フォース アプローチでは、各等差数列と和集合のエンドポイントのすべてのエッジが明示的に生成されます。 各操作で k 要素に触れると、O(k²) 個のエッジが作成されます。 k は大きくなる可能性があるため、これでは遅すぎます。 

重要な観察は、エッジは、特定の演算に対して同じ剰余モジュロ d を共有する数値のみを接続するということです。 ステップ d の各操作は、インデックスを独立した算術チェーンに分割します。 すべてのエッジを追加する代わりに、剰余クラスごとにグループ化した後、そのような各チェーン内の連続する要素を結合するだけで十分です。 

さらに良いことに、各操作の進行を反復処理し、各要素を前の要素と結合することで各操作を処理できるため、操作ごとに 2 次ではなく線形の作業が得られます。 

d は最大 10 であるため、d のステップで位置を反復することにより、効率的に共用体を構築することもできます。 

これにより、DSU を使用して等差数列のセグメントを効率的にマージするという問題が軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (各進行のすべてのペア) | O(n²) 最悪の場合 | O(n) | 遅すぎる |
 | ステップワイズユニオンを使用した最適化された DSU | O(n log* n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 点 1 から n までの素集合和集合構造を維持します。 

1. すべてのポイントが独自のコンポーネントになるように DSU を初期化します。 これは、点が接続されていない開始状態を表します。 
2. 各演算 (a、d、k) に対して、シーケンス a、a + d、a + 2d、...、a + k・d を生成します。 
3. このシーケンスを順番にたどって、連続する各ペアを結合します。 つまり、union(a, a + d)、union(a + d, a + 2d) などです。 
4. すべての操作に対して繰り返します。 
5. すべてのユニオンを処理した後、すべてのノードにいくつの個別の DSU ルートが残っているかを数えます。 この数は接続されたコンポーネントの数です。 

連続する要素のみを結合する理由は、チェーン内の接続が推移的であるためです。 等差数列で隣接する要素を接続すると、明示的なペアワイズ エッジを必要とせずに、その数列内のすべての点が接続されます。 

### なぜ効果があるのか

 各操作により、選択された点上にパス グラフが形成されます。 パスは、連続するノードをリンクすることによって完全に接続されます。 最終的なグラフはこれらのパス グラフの結合であるため、連続するすべてのエッジにわたる DSU は、完全なエッジ セットとまったく同じ接続性を保持します。

元のエッジはすべて、操作によって誘導されたパス内の 2 つの連続するノードの間にあるため、接続が失われることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n + 1))
        self.size = [1] * (n + 1)

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        dsu = DSU(n)

        for _ in range(m):
            a, d, k = map(int, input().split())
            x = a
            for _ in range(k):
                y = x + d
                dsu.union(x, y)
                x = y

        roots = set()
        for i in range(1, n + 1):
            roots.add(dsu.find(i))

        print(len(roots))

if __name__ == "__main__":
    solve()
```DSU 構造により、多くの操作が重複する場合でもコンポーネントを効率的にマージできます。 各操作内のループは k 個のエッジのみを処理します。これは、誘導されたパス内のリンクの数に正確に対応します。 

微妙な実装の詳細は、find でパス圧縮を使用することです。これにより、操作ごとに償却された複雑さがほぼ一定に保たれます。 

もう 1 つのポイントは、DSU が接続を直接キャプチャするため、隣接関係リストを明示的に構築しないことです。 

## 実用的な例

 ### 例 1

 入力:```
n = 10, m = 2
(1,2,4)
(2,2,4)
```10 個の分離されたノードから始めます。 

最初の演算では、(1,3)、(3,5)、(5,7)、(7,9) を結合します。 これにより、9 までのすべての奇数を含む 1 つのコンポーネントが形成されます。 

2 番目の演算では、(2,4)、(4,6)、(6,8)、(8,10) を結合します。 これにより、すべての偶数を含む別のコンポーネントが形成されます。 

相互接続は存在しないため、最終的な数は 2 コンポーネントになります。 

### 例 2

 入力:```
n = 100, m = 1
(19,2,4)
```(19,21)、(21,23)、(23,25)、(25,27) を結合します。 これら 5 つのノードが 1 つのコンポーネントになります。 

他の 95 ノードはすべて分離されたままであるため、コンポーネントの合計は 96 になります。 

これは、操作がローカル算術チェーンにのみ影響し、到達可能なインデックスを超えて伝播しないことを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n α(n)) | 各結合/検索はほぼ一定に償却され、すべての操作にわたる合計エッジは線形です。 
| スペース | O(n) | DSU 配列は親とサイズを格納します。 

この制約により、最大 2×10^5 の合計点と演算が許可されるため、線形に近い DSU ソリューションは制限内に簡単に収まります。

    input = sys.stdin.readline

            self.size = [1] * (n + 1)

            b = self.find(b)

                if self.size[a] < self.size[b]:
                    a, b = b, a
                self.parent[b] = a
                self.size[a] += self.size[b]

 ## 特殊なケース

 重要なエッジ ケースは、k = 0 の場合です。これは、各操作で 1 つの点のみが選択されることを意味します。 この場合、結合は実行されず、すべてのノードは分離されたままになるため、答えは n になります。 内部ループは結合を実行しないため、アルゴリズムはこれを自然に処理します。 

もう 1 つのエッジ ケースは、d = 1 で k が大きい場合に発生します。これは、完全な連続セグメントを 1 つのコンポーネントに事実上接続します。 DSU は隣接するペアを正しくマージし、単一のチェーン コンポーネントを生成します。 

最後の重要なケースは、異なる演算による算術シーケンスの重複です。 DSU はこれを自動的に処理します。これは、操作間でユニオンを繰り返すと、コンポーネントが重複や順序付けの問題なく推移的にマージされるためです。
