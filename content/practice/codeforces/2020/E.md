 ## 解決策
 ## 問題の理解

 整数の配列が与えられ、それぞれがランダムなマルチセットに含まれる独立した確率を持ちます。 タスクは、選択したすべての要素の XOR の 2 乗の期待値を計算することです。 入力では、10,000 のうちの整数として確率と配列要素自体が提供されます。 すべての配列の長さの合計が 200,000 を超えず、すべての数値が最大 1023 になるように、複数のテスト ケースを効率的に処理する必要があります。出力は、期待される二乗 XOR モジュロです。$10^9+7$。 

考えられるすべてのサブセットを列挙する単純なアプローチは実行不可能です。$2^n$サブセットは天文学的に大きい$n$200,000まで。 エッジ ケースには、単一要素の配列、異なる確率で繰り返される数値、確率が 0 または 100% の状況が含まれます。これにより、期待値が簡単に単純化される可能性がありますが、モジュロを正しく計算する必要があります。$10^9+7$。 たとえば、配列が次の場合、`[1,1]`確率的に`[10000,0]`、最初の要素のみが寄与し、$(f(S))^2$単純に$1^2$。 不用意に実装すると、確率に必要なモジュラー逆数または整数スケーリングを忘れる可能性があります。 

## アプローチ

 ブルート フォース ソリューションは、各サブセットの XOR を計算し、その確率を乗算し、二乗し、全体の合計を計算します。$2^n$サブセット。 これは正しいですが、次の場合は明らかに不可能です$n > 20$。 

より高速なソリューションに対する重要な洞察は、期待値の線形性と、XOR 演算をビットごとに分解する機能です。 XOR はビットごとの加算モジュロ 2 であるため、各ビットは独立して動作します。 させて$X_i$ビットのインジケーター確率変数を示します$i$選択したマルチセットの XOR で。 それから$\Pr(X_i=1)$奇数の配列要素がビットを持つ確率です。$i$含まれています。 

コンピューティング$\Pr(X_i=1)$これは、数値のサブセットに対して確率生成関数を維持することによって直接行うことができます。 させて$q_i = 1 - p_i / 10^4$。 与えられたビットに対して$b$、 定義する$s_b = \sum$そのビットを持つ数値の確率。 動的計画法または 2 つの状態 (ビットが設定されているかどうか) にわたる反復畳み込みを使用すると、そのビットが設定されている確率を計算できます。$b$最終的な XOR では 1 になります。 

取得したら$\Pr(X_i=1)$10 ビットすべてに対して ($a_i \le 1023$)、の期待値$(f(S))^2$次のように表現できます$$\mathbb{E}[(f(S))^2] = \sum_{i} 2^{2i} \Pr(X_i=1) + \sum_{i\neq j} 2^{i+j} \Pr(X_i=1 \text{ XOR } X_j=1)$$ここで、交差項はビットの独立性を使用して簡略化され、次のようになります。$$\Pr(X_i \oplus X_j = 1) = \Pr(X_i=1)\cdot(1-\Pr(X_j=1)) + (1-\Pr(X_i=1))\cdot\Pr(X_j=1)$$この分解により、指数関数的な問題がビット数と配列サイズにおいて線形の問題に縮小されます。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$、 配列$a$、および配列$p$。 確率を剰余分数に変換する$p_i/10000 \bmod 10^9+7$。 
2. 配列を初期化する`prob_bit[10]`各ビットがランダムなサブセットの XOR に設定される確率を格納します。 
3. 各ビットについて$b$0から9まで、計算します`prob_bit[b]`配列を反復処理し、選択された奇数の数値にそのビットが設定されている確率を更新します。 これは反復的に行うことができます。ビットが設定された数値ごとに、偶数パリティと奇数パリティの現在の確率にその包含確率を乗算します。 
4. 次の式を使用して期待二乗を計算します。$$\mathbb{E}[(f(S))^2] = \sum_{b=0}^{9} 2^{2b} \text{prob\_bit}[b] + \sum_{0 \le b_1 < b_2 < 10} 2^{b_1+b_2} ( \text{prob\_bit}[b_1] + \text{prob\_bit}[b_2] - 2 \text{prob\_bit}[b_1]\text{prob\_bit}[b_2] )$$確率を計算するときは、10000 の逆数を使用したモジュラー演算を使用します。 

1. 結果のモジュロを出力します。$10^9+7$。 

機能する理由: XOR 演算はビットごとに分解され、選択が独立しているため、各ビットの確率を乗算的に組み合わせることができます。 クロスビット項は、期待値の線形性と XOR 式によって処理されます。 このアルゴリズムはサブセットを列挙することはありませんが、考えられるそれぞれの寄与を正確に考慮します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
INV10000 = pow(10000, MOD-2, MOD)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        p = list(map(int, input().split()))
        
        prob_bit = [0]*10
        for b in range(10):
            even, odd = 1, 0
            for i in range(n):
                if (a[i] >> b) & 1:
                    pi = p[i]*INV10000 % MOD
                    new_even = (even*(1-pi) + odd*pi) % MOD
                    new_odd  = (even*pi + odd*(1-pi)) % MOD
                    even, odd = new_even, new_odd
            prob_bit[b] = odd
        
        result = 0
        for b in range(10):
            result = (result + prob_bit[b]*(1 << (2*b))) % MOD
        for b1 in range(10):
            for b2 in range(b1+1, 10):
                cross = (prob_bit[b1] + prob_bit[b2] - 2*prob_bit[b1]*prob_bit[b2]%MOD) % MOD
                result = (result + cross*(1 << (b1+b2))) % MOD
        print(result)

if __name__ == "__main__":
    solve()
```このソリューションでは、確率を剰余分数に変換し、各ビットが最終的な XOR に設定される確率を繰り返し計算します。 次に、単一ビットの寄与とペアごとのクロスビットの寄与の両方を使用して、期待される平方が組み立てられます。 剰余乗算を使用するとオーバーフローが防止され、演算の順序は Python の演算子の優先順位に従います。
