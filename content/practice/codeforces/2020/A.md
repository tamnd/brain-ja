 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、整数を読み取ります。`n`そして`k`。 
3. もし`k`1に等しい、返す`n`すべての演算でちょうど 1 が減算されるため、答えとなります。 
4. それ以外の場合は、操作のカウンタをゼロに初期化します。 
5. ながら`n`ゼロより大きい：

 - コンピューティング`n % k`、現在の累乗の減算数を与えます。`k`必要です。 
- この余りを操作カウンタに加算します。 
- アップデート`n`に`n // k`次に高いべき乗を処理するには`k`。 
6. ループの後、カウンターには最小限の操作が含まれます。 出力してください。 

なぜ効果があるのか​​: 表現する`n`基地内で`k`の各べき乗の回​​数を正確に捕捉します。`k`が必要です。 各ステップの剰余は、現在の電力を何回減算するかを示し、次の値で割ります。`k`moves to the next power. The process terminates when all powers are exhausted, guaranteeing the minimal number of operations.

 ## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        if k == 1:
            print(n)
            continue
        ans = 0
        while n > 0:
            ans += n % k
            n //= k
        print(ans)

if __name__ == "__main__":
    solve()
```このコードは、高速 I/O を使用して複数のテスト ケースを効率的に処理します。 専用ケースを分離します`k = 1`無限ループを回避し、整数の除算と剰余を使用して基底を走査します。`k`表現。 各ループ反復は、基数の 1 桁の処理に対応します。`k`、対数的な複雑さを確保します。
