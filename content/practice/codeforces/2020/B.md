 ## 問題の理解

 からインデックス付けされた電球の行にプロセスが与えられます。$1$に$n$。 最初はすべての電球が点灯しています。 次に、構造化された方法で電球を繰り返し反転します。$i$、の倍数ごとに$i$状態が一度切り替わります。 

すべての操作が終了した後、各電球はインデックスを整数で割った数に等しい回数だけ反転されます。 この観察が重要な単純化です: 電球$j$まさに反転している$d(j)$回、どこで$d(j)$は約数の数です$j$。 フリップするたびに状態が切り替わるため、最終状態は次のパリティのみに依存します。$d(j)$。 

出力では最小値が求められます。$n$このプロセスを実行した後、$n$まさに電球$k$電球は点灯したままです。 

制約は次のとおりです$10^{18}$のために$k$したがって、どのような解決策でも、問題を閉じた形式の算術特性に還元する必要があります。 あらゆるシミュレーションが終わった$n$または、すべての数値を約数として数えることは不可能です。 

よくある落とし穴は、「電球は完全な正方形に対応する」と誤って仮定することです。 この設定では、すべての電球をオンにしてからスイッチを入れるので、これは真実とは逆です。$d(j)$回。 このフリップ パリティが欠けていると、完全に間違ったカウント関数が発生し、その結果、誤った反転が発生します。$n$。 

## アプローチ

 単純なアプローチでは、候補者ごとにプロセスをシミュレートします。$n$、すべての除数の数を計算します。$1 \le j \le n$、反転をシミュレートし、点灯している電球の数を数えます。 これには少なくとも費用がかかります$O(n \sqrt{n})$または$O(n \log n)$実装に応じてチェックごとに、そしてそれ以来$n$それ自体が非常に大きくなる可能性がありますが、これは完全に実行不可能です。 

重要な観察は、個々の電球の状態は決して必要ないということです。 最終的に点灯する電球の数だけが必要です。 

電球はオンの状態から始まるため、偶数回反転するとオンになります。 したがって、電球$j$オンになっている場合$d(j)$は均等です。 約数が奇数の数値は完全二乗だけなので、正確には$\lfloor \sqrt{n} \rfloor$電球は奇数回反転されるため、終了します。 残りの電球はすべて点灯したままになります。 
この中で、$1..n$、点灯している電球の数は次のとおりです。$$\text{on}(n) = n - \lfloor \sqrt{n} \rfloor.$$ここで問題は、最小値を見つけることです。$n$そのような$$n - \lfloor \sqrt{n} \rfloor = k.$$この機能は単調です$n$, したがって、有効な最小値を検索できます。

 ## アルゴリズムのチュートリアル

 書き換えます$n$に関しては$s = \lfloor \sqrt{n} \rfloor$。 それから$s^2 \le n \le (s+1)^2 - 1$となり、方程式は次のようになります。$$k = n - s.$$それで：$$n = k + s.$$境界への代入$n$与える:$$s^2 \le k + s \le (s+1)^2 - 1 = s^2 + 2s.$$これは次のように単純化されます。$$s^2 - s \le k \le s^2 + s.$$したがって、固定の場合$s$、すべて有効です$k$隙間に横たわる$[s(s-1), s(s+1)]$。 

今必要なのは最小のものです$n = k + s$、これは有効な最小値に相当します。$s$満足のいく：$$s(s+1) \ge k \quad \text{and} \quad s(s-1) \le k.$$かつてそのような$s$が見つかったら出力します$n = k + s$。 

2 番目の条件は、次のような最小限の条件によって自動的に満たされます。$s$、インターバルがあるため、$[s(s-1), s(s+1)]$ギャップのないすべての非負の整数をカバーします。 

### なぜ効果があるのか

 各整数$n$正確に 1 つの値を生成します$s = \lfloor \sqrt{n} \rfloor$、それぞれの固定内で$s$ブロック、の値$k$と直線的に増加します$n$として$k = n - s$。 それぞれの実現可能範囲$s$は連続しているので、最小のものを選択します$s$それは届く$k$可能な限り最小の値が得られます$n$。 それよりも小さくない$s$生成できる$k$、およびそれ以上の$s$増加する$n$直接。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        k = int(input().strip())

        # find smallest s such that k <= s(s+1)
        # quadratic: s^2 + s - k >= 0
        # s = ceil((sqrt(1+4k) - 1)/2)

        s = (math.isqrt(4 * k + 1) - 1) // 2
        while s * (s + 1) < k:
            s += 1

        n = k + s
        print(n)

if __name__ == "__main__":
    solve()
```## 実用的な例

 のために$k=1$、テストします$s=0$:$0 \cdot 1 = 0 < 1$、とても無効です。 次$s=1$:$1 \cdot 2 = 2 \ge 1$、 それで$s=1$。 それから$n = 1 + 1 = 2$。 

のために$k=3$、チェックします$s=1$:$1 \cdot 2 = 2 < 3$、 無効。 次$s=2$:$2 \cdot 3 = 6 \ge 3$、 有効。 それで$n = 3 + 2 = 5$。 

これらはサンプルと一致し、間隔条件がどのように答えを直接決定するかを示しています。
