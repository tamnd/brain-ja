 ## 問題の理解

 小文字の文字列があり、選択した文字がすべて異なるサブシーケンスを数えたいと考えています。 サブシーケンスは選択した位置によって決定されるため、最初の位置を選択すると、`a`から`aab`そして2番目を選択する`a`どちらも 1 文字の文字列を生成しますが、異なるサブシーケンスです。`a`。 空のサブシーケンスも有効です。 

重要な質問は実際には文字の順序ではありません。 どのポジションを選択するかを決定すると、元の順序によってサブシーケンスが自動的に与えられます。 虹のサブシーケンスの場合、各文字は、選択位置が 0 つであるか、選択位置が 1 つだけ存在する可能性があります。 その観察により、問題は独立した選択の結果に変わります。 

文字列の長さは最大でも`100000`したがって、すべてのサブシーケンスを検査するアルゴリズムはまったく実行不可能です。 がある`2^n`サブシーケンスはすでに天文学的な規模に達しています`n = 100000`。 二次時間のアルゴリズムでも、`10^10`最大サイズでの操作は 1 秒の制限をはるかに超えます。 線形または線形に近い解決策が必要です。 

不注意な実装が失敗する可能性のあるエッジケースがいくつかあります。 のために`a`、正解は`2`を選択する可能性があるため、`a`あるいは何も選択しません。 空のサブシーケンスを忘れた実装は次を返します。`1`。 

のために`aaa`、答えは`4`。 3 つの位置のいずれも選択しないことも、3 つの位置のうち 1 つだけを選択することもできます。 結果のサブシーケンスには同じ文字が 2 回含まれるため、2 つの位置を選択することは無効です。 よくある間違いは、さまざまな位置の選択肢ではなく、結果として得られるさまざまな文字列を数えることです。`2`、つまり空の文字列と`a`。 

のために`aab`、答えは`6`。 有効なサブシーケンスは、空のサブシーケンス、3 つの 1 文字のサブシーケンス、および 1 つの文字を含む 2 つの有効な長さ 2 のサブシーケンスです。`a`そして`b`。 の2つの選択肢は、`a`使用する位置が異なるため、異なります。 

## アプローチ

 直接的な解決策では、位置のすべてのサブセットを列挙します。 サブセットごとに、選択した文字を調べて、文字が 2 回出現するかどうかを確認できます。 位置のすべてのサブセットが 1 つのサブシーケンスを正確に表すため、これは正しいです。 ただし、`2^n`各サブセットのチェック自体に最大で時間がかかる場合があります`O(n)`時間。 結果として生じる最悪の場合の複雑さは次のようになります。`O(n 2^n)`、 と`2^100000`最大入力サイズでの候補サブシーケンス。 それらの候補を生成することさえ不可能です。 

有益な観察は、虹の部分列が各文字に独立して非常に単純な制限を課しているということです。 手紙だと仮定して、`c`発生する`cnt[c]`元の文字列の倍数。 虹のサブシーケンスには、まさに`cnt[c] + 1`この文字の可能性: 出現する文字をまったく選択しないか、または出現する文字の 1 つだけを選択する`cnt[c]`出来事。 

これらの選択肢は、異なる文字間で独立しています。 次の出来事を 1 つ選択すると、`a`そして1回の発生`b`、それらの位置によってサブシーケンス内の順序がすでに決定されています。 追加の注文を選択する必要はありません。 したがって、文字ごとの選択肢のすべての組み合わせは、正確に 1 つの有効な虹のサブシーケンスを生成し、すべての有効な虹のサブシーケンスは、まさに 1 つのそのような組み合わせに対応します。 

26 個の小文字を使用すると、合計数は次のようになります。 

[
 \prod_{c='a'}^{'z'} (cnt[c] + 1)。 
】

 空のサブシーケンスは、すべての文字に対してゼロの出現を選択することによって自然に含まれます。 

サブシーケンスは選択された位置によって完全に決定されるため、ブルート フォースは機能しますが、位置サブセットが指数関数的に多いため失敗します。 すべての文字が独立して 0 回または 1 回選択できるという観察により、問題は 26 個の周波数を数え、26 個の小さな係数を乗算するという問題に縮小されます。

 ## アルゴリズムのチュートリアル

 1. 小文字ごとに 1 つのエントリを含む周波数配列を作成します。 文字列を 1 回スキャンし、すべての文字に対応する頻度を増やします。 これにより、各文字を選択できる位置の数がわかります。 
2. に対する答えを初期化します。`1`。 これは、文字が選択されていない単一の選択肢、つまり空のサブシーケンスを表します。 
3. 小文字ごとに、答えに次の値を掛けます。`cnt[c] + 1`そしてそれを剰余的に減らします`11092019`。 この係数は、その文字のすべての可能性をカウントします。つまり、出現しないものを選択するか、出現する文字の 1 つを正確に選択します。 
4. 結果として得られた製品を印刷します。 各文字の選択は独立しているため、この積はすべての虹のサブシーケンスを 1 回だけ正確にカウントします。 

### なぜ効果があるのか

 虹の部分列を考えてみましょう。 すべての文字について、その文字が存在しないかどうか、または存在する場合にはその文字のどの出現が選択されたかを記録します。 部分列には繰り返しの文字が含まれていないため、この記述にはすべての文字に対して 1 つの選択肢があります。存在しない場合は選択肢が 0 つ、存在する場合はその出現の 1 つです。 逆に、これらの文字ごとの選択肢のコレクションでは、各文字に対して最大 1 つの位置が選択されるため、元の順序で読まれた場合、選択された位置は常に虹のサブシーケンスを形成します。 したがって、虹の部分列と、によってカウントされる組み合わせとの間には 1 対 1 の対応関係があります。 

[
 \prod_c (cnt[c]+1)。 
】

 乗算では、空のサブシーケンスを含む、目的のオブジェクトが正確にカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 11092019

def solve():
    s = input().strip()

    cnt = [0] * 26
    for ch in s:
        cnt[ord(ch) - ord('a')] += 1

    ans = 1
    for x in cnt:
        ans = ans * (x + 1) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```最初のループは周波数配列を構築します。 入力には英小文字のみが含まれているため、`ord(ch) - ord('a')`すべての文字を範囲に直接マッピングします`0`を通して`25`。 

2 番目のループでは積の式が適用されます。 から始まる`ans = 1`is necessary because the empty subsequence must be counted. 登場する文字については`x`倍、乗算`x + 1`accounts for all ways to either omit that letter or select one of its occurrences.

 The modulo is applied after every multiplication. Python の整数はオーバーフローしませんが、計算全体を通じて値を減らし続けることは、必要な答えにとって自然であり、中間値を小さく保つことの両方です。 There is no off-by-one issue in the frequency factor: if a letter appears once, its factor is`2`、「選択しない」および「その唯一の出現を選択する」を表します。 出現回数が 0 回の場合、その係数は`1`そしてそれは効果がありません。
