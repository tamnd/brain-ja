 ## 解決策
 ## 問題の理解

 入力は、45 度回転した直交迷路の長方形の図面です。 ドット以外の各文字は、入力セル内の 1 つの斜めの壁セグメントを表します。 スラッシュは右上隅から左下隅までの対角線を占め、バックスラッシュは反対側の対角線を占めます。 ドットには壁がありません。 

タスクは特定のパスを見つけることではありません。 自由空間のすべての領域が境界のない外側の領域へのパスを持つように、削除する壁セグメントをできるだけ少なくする必要があります。 迷路には複数の切り離された囲まれた領域が含まれる場合があるため、答えは、すべての自由空間コンポーネントを外側のコンポーネントにマージするために必要な壁の除去の数になります。 

スラッシュ方向のチェッカーボード条件により、図面が意図した迷路ジオメトリを持つことが保証されます。 このアルゴリズムにとってさらに重要なことは、画像を 2 倍に拡大縮小した後、すべての斜めの壁を正確に 2 つのブロックされたグリッド位置で表現できることです。 その後、連続迷路を通常のグリッド接続問題として扱うことができます。 

R,C≤1000 の場合、入力には最大 10 6 個のセルが含まれます。 O((RC) 2 ) などの 2 次数の入力セルを検査するソリューションは、10 12 回の演算に達する可能性があり、非常に遅すぎます。 入力の定数係数展開にわたる線形または線形に近いスキャンが適切です。 スケーリングされたグリッドには最大で約 4×10 6 個の位置があるため、実装ではセルごとの過度のオーバーヘッドを持つ Python オブジェクトも回避する必要があります。 

元の文字のみについて推論する実装を騙す可能性のあるエッジケースがいくつかあります。 一枚の壁が必ずしも何かを囲んでいるわけではありません。 例えば、```
1 1
/
```出力があります`0`これは、対角線セグメントが境界に到達し、境界領域を分離しないためです。 すべての壁を障害物としてカウントすると、誤って返されてしまう`1`。 

完全に空の迷路は、別の境界ケースです。```
1 1
.
```空間全体がすでに外とつながっている、答えは`0`。 実装では、迷路セルを数えるのではなく、接続された自由空間コンポーネントを数える必要があります。 

対角線の方向も重要です。 サンプル 3 について考えてみましょう。```
2 2
\/
/\
```4 つの壁は領域を囲んでいないため、正しい出力は次のようになります。`0`。 4 つのスラッシュを 2×2 に配置すると閉じた正方形が作成されると仮定した解決策は、これを誤ります。 

最後に、いくつかの囲まれた領域を複数回削除する必要があります。 サンプル 2 には 2 つの囲まれた領域があるため、その答えは次のようになります。`2`。 1 回の壁の削除では、現在別個の 2 つの自由空間コンポーネントのみをマージできるため、各領域から 1 つの壁を削除することが必要です。 

## アプローチ

 ブルートフォースソリューションは、幾何学的定義から始めることができます。 削除する可能性のあるすべての壁のセットについて、それらの壁を削除し、結果として得られる迷路を塗りつぶし、すべての空きスペース コンポーネントが外側に達しているかどうかを確認します。 これは、満たすように求められている条件を明示的にテストしているため、正しいですが、最大 10 6 の壁が存在する可能性があります。 サブセットを列挙するには 2 10 6 通りの可能性が必要ですが、これは直ちに不可能です。 

それほど極端ではない総当たり戦略は、壁を特定し、その除去を繰り返しシミュレートすることです。 候補の壁ごとに、それを削除し、スケールされたグリッド全体に塗りつぶしを実行して、残っているコンポーネントの数を判断できます。 W=O(RC) の壁と塗りつぶしあたりの作業量が O(RC) の場合、これにはすでに O((RC) 2 ) のコストがかかります。 最大入力サイズでは、繰り返しの反復を考慮する前に、これは 10 12 セル訪問のオーダーになります。 

有益な観察は、どの壁を除去するかを実際に決定する必要がないということです。 削除する前に、空き領域コンポーネントがいくつ存在するかを知る必要があるだけです。 

自由空間の K 個の接続されたコンポーネントがあり、そのうちの 1 つが外部コンポーネントであると仮定します。 他のすべてのコンポーネントは最終的にそれに接続する必要があります。 1 つの壁を削除すると最大 2 つのコンポーネントがマージされるため、少なくとも K-1 回の削除が必要です。 

その下限も達成可能です。 コンポーネントは壁で区切られており、頂点が自由空間コンポーネントでエッジが取り外し可能な壁である隣接グラフは、平面迷路全体を通して接続されます。 この隣接グラフのスパニング ツリーを選択し、その K-1 エッジを削除できます。 したがって、答えは正確に K−1 です。 

残りの問題は、K をカウントすることです。最もきれいな表現は、すべての入力セルを 2×2 ブロックにスケーリングすることです。 スラッシュは右上から左下の対角線で 2 つのブロック位置になり、バックスラッシュはもう一方の対角線で 2 つのブロック位置になります。 ドットは 4 つの位置すべてを空けたままにします。 この変換後、通常の 4 方向の接続性は、迷路の領域の接続性を正確に表します。 

次に、未訪問の空きポジションをすべてフラッドフィルします。 各フラッド フィルで 1 つの領域が検出されるため、フラッドの数は K となり、答えは K−1 になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 繰り返しの塗りつぶしの場合は O((RC) 2 ) | O(RC) | 遅すぎる |
 | 最適 | O(RC) | O(RC) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. R×C 文字グリッドを読み取り、約 2R×2C のサイズのスケールされたグリッドを作成します。 外側の領域が明示的に表現されるように、その周囲に 1 つの追加の行と列の空きスペースを使用します。 
2. を含むすべての入力セルに対して、`/`、スケーリングされた 2×2 ブロックの右上と左下の点に対応する 2 つの位置をブロック済みとしてマークします。 あ`/`したがって、2 セルの斜めの壁になります。 
3. を含むすべての入力セルに対して、`\`、反対側の 2 つのポジションをブロック済みとしてマークします。 ドットにより、スケールされたブロック全体が解放されます。 
4. スケールされたグリッドのすべての位置をスキャンします。 未訪問の空き位置が見つかるたびに、コンポーネント数をインクリメントし、その位置からフラッドフィルして、到達可能なすべての空き位置を訪問済みとしてマークします。 
5. 出力`components - 1`。 コンポーネントの 1 つは、境界のない外側領域です。 他のすべてのコンポーネントはそれに接続する必要があり、壁を削除するたびにコンポーネントの数が最大 1 つずつ減ります。 

### なぜ効果があるのか

 各対角壁は、同じ対角セグメントを形成する 2 つの隣接するブロックされたセルで表されるため、スケール変更されたグリッドは元の迷路のトポロジーを保存します。 したがって、元の自由空間の 2 つの点は、それらの対応するスケーリング位置が同じ 4 方向に接続されたコンポーネントに属する場合に正確に接続されます。 

スケーリングされたグリッドに K 個の自由空間コンポーネントが含まれるとします。 1 つは外側の領域ですが、残りの K-1 成分は囲まれた領域であり、現時点では脱出できません。 1 つの壁を削除しても最大 2 つのコンポーネントをマージできるため、K-1 未満の削除ではすべての領域を外部に接続できない可能性があります。 

逆に、2 つの自由空間コンポーネントが壁を共有している場合は常に、その壁を削除するとそれらがマージされます。 壁が無視されると平面全体が接続されるため、コンポーネントの隣接構造が接続されます。 その構造のスパニング ツリーには K-1 個のエッジがあり、それらの壁を削除すると、すべてのコンポーネントが外側のコンポーネントにマージされます。 したがって、最小値は正確に K−1 です。 

## Python ソリューション```python
import sys
from array import array

input = sys.stdin.readline

def solve():
    R, C = map(int, input().split())
    maze = [input().rstrip('\n') for _ in range(R)]

    H = 2 * R + 2
    W = 2 * C + 2
    total = H * W

    # 0 = free and unvisited
    # 1 = wall or already visited
    grid = bytearray(total)

    # Keep one-cell padding around the drawing. The padding represents
    # the unbounded outside region.
    for i in range(R):
        row = maze[i]
        base = (2 * i + 1) * W
        for j, ch in enumerate(row):
            if ch == '/':
                grid[base + 2 * j + 2] = 1
                grid[base + W + 2 * j + 1] = 1
            elif ch == '\\':
                grid[base + 2 * j + 1] = 1
                grid[base + W + 2 * j + 2] = 1

    components = 0
    stack = array('i')

    for start in range(total):
        if grid[start]:
            continue

        components += 1
        grid[start] = 1
        stack.append(start)

        while stack:
            v = stack.pop()
            r = v // W
            c = v - r * W

            if r > 0:
                u = v - W
                if not grid[u]:
                    grid[u] = 1
                    stack.append(u)

            if r + 1 < H:
                u = v + W
                if not grid[u]:
                    grid[u] = 1
                    stack.append(u)

            if c > 0:
                u = v - 1
                if not grid[u]:
                    grid[u] = 1
                    stack.append(u)

            if c + 1 < W:
                u = v + 1
                if not grid[u]:
                    grid[u] = 1
                    stack.append(u)

    print(components - 1)

if __name__ == "__main__":
    solve()
```実装の最初の部分では、スケーリングされた表現を構築します。 配列は次のように保存されます。`bytearray`これは、整数の Python リストではなく、最大のスケーリングされたグリッドには約 400 万の位置が含まれており、各位置には 1 ビットの論理情報 (ここでは 1 バイトで表されます) のみが必要なためです。 

入力位置のスラッシュの場合`(i, j)`、ブロックされた位置は次のとおりです。`(2i+1, 2j+2)`そして`(2i+2, 2j+1)`。 バックスラッシュの場合は、`(2i+1, 2j+1)`そして`(2i+2, 2j+2)`。 の`+1`オフセットにより、図面全体の周囲に自由な境界線が残ります。 

フラッド フィルでは、セル インデックスを格納するのではなく、整数セル インデックスのスタックを使用します。`(row, column)`タプル。 位置を次のようにエンコードする`row * W + column`各スタックエントリを単一の整数にします。`array('i')`このスタックは、数百万の Python 整数オブジェクトを含む Python リストよりも大幅に小さく保たれます。 

行と列を回復するために使用される除算と剰余は、グリッドの寸法が約 2000 程度であるため安全です。また、Python の整数を使用すると、オーバーフローの心配もなくなります。 

境界チェックは、隣接するインデックスにアクセスする前に意図的に実行されます。 外側のパディングは同じスケールのグリッドの一部であるため、外側に対する特別な塗りつぶしロジックはありません。 それは単にパディングセルを含むコンポーネントです。

import sys
import io
from array import array

def solve_io(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    R, C = map(int, sys.stdin.readline().split())
    maze = [sys.stdin.readline().rstrip('\n') for _ in range(R)]

    H = 2 * R + 2
    W = 2 * C + 2
    total = H * W

    grid = bytearray(total)

    for i in range(R):
        row = maze[i]
        base = (2 * i + 1) * W

        for j, ch in enumerate(row):
            if ch == '/':
                grid[base + 2 * j + 2] = 1
                grid[base + W + 2 * j + 1] = 1
            elif ch == '\\':
                grid[base + 2 * j + 1] = 1
                grid[base + W + 2 * j + 2] = 1

    components = 0
    stack = array('i')

    for start in range(total):
        if grid[start]:
            continue

        components += 1
        grid[start] = 1
        stack.append(start)

        while stack:
            v = stack.pop()
            r = v // W
            c = v - r * W

            if r > 0:
                u = v - W
                if not grid[u]:
                    grid[u] = 1
                    stack.append(u)

            if r + 1 < H:
                u = v + W
                if not grid[u]:
                    grid[u] = 1
                    stack.append(u)

            if c > 0:
                u = v - 1
                if not grid[u]:
                    grid[u] = 1
                    stack.append(u)

            if c + 1 < W:
                u = v + 1
                if not grid[u]:
                    grid[u] = 1
                    stack.append(u)

    sys.stdout.write(str(components - 1) + '\n')
    result = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout
    return result
