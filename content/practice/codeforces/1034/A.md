 ## 解決策
 ## 問題の理解

 正の整数のリストが与えられ、その一部を削除することができます。 削除後、残った数値の最大公約数を調べます。 目標は、削除する要素をできるだけ少なくしながら、この新しい gcd を元の完全な配列の gcd よりも厳密に大きくすることです。 

入力は単一の配列だけです。 出力は、残りのセットの gcd が厳密に大きくなるように必要な除去の最小数です。または、`-1`そのような改善が不可能な場合。 

主な制限は、値を変更することはできず、要素を削除することのみができることです。 したがって、gcd を増やす唯一の方法は、元のグローバル gcd よりも強い公約数を共有する数値のサブセットに制限することです。 

の制約`n`は 300,000 まで増加し、値は約 1.5e7 まで増加します。 これにより、すべてのサブセットを試行したり、削除を繰り返して gcd を再計算したりするソリューションは除外されます。 サイズ n-1 または n-2 のすべての候補サブセットを個別にチェックしても、各 gcd 計算は O(n) であり、O(n^2) になるため、遅すぎます。 

すべての数値が同一である場合、微妙な特殊なケースが発生します。 gcd はすでにその数値に等しいため、要素を削除してもそれを増やすことはできません。 もう 1 つの重要なケースは、グローバル gcd を因数分解した後にすべての数値が 1 になる場合です。これは、1 には 1 より大きい適切な約数がないため、改善が不可能になるためです。 

たとえば、配列が次の場合、`[6, 10, 15]`、gcd は 1 です。要素を 1 つ削除して要素を増やすこともできますが、サイズ 2 のサブセットには gcd が 1 より大きいものはないため、答えは次のようになります。`-1`。 

別の例は`[4, 6, 9]`ここで、グローバル gcd は再び 1 ですが、削除されます。`6`葉`[4, 9]`gcd 1 のままで、どのペアも同様に動作します。 したがって、やはり改善はありません。 

## アプローチ

 この強引なアイデアは、考えられるすべてのサブセットを試し、その gcd を計算し、元のサブセットよりも厳密に大きい gcd が得られる最小数の欠失を追跡することです。 これは問題の定義と直接一致するため、正しいです。 ただし、サブセットの数は指数関数的であるため、サイズのすべてのサブセットのチェックに制限さえあります。`n-1`または`n-2`O(n^2) 個の gcd 計算が必要になり、それぞれのコストが O(log A) になります。これは、`3e5`要素。 

重要な観察は、元の gcd が正規化する必要がある唯一のベースラインであるということです。 すべての数値をグローバル gcd で割ると、`g`の場合、問題は、残りの数値の gcd を厳密に 1 より大きくすることになります。有効な改善された gcd は、変換された数値の 1 より大きい約数でなければなりません。 

したがって、タスクは次のようになります。残りのサブセットの gcd が少なくとも 2 になるように、できるだけ少ない要素を削除します。サブセットを検索する代わりに、視点を反転します。 どの整数について尋ねます`d > 1`は割り切れる要素の数です`d`最大化された？ 

gcd が次で割り切れるサブセットを選択すると、`d`の場合、そのサブセット内のすべての要素は次の数で割り切れる必要があります。`d`。 したがって、固定の可能な最良のサブセットは、`d`は、正確に、次の要素で割り切れるすべての要素の集合です。`d`。 中でも`d > 1`、最も多くの要素を分割するものが必要です。 

素約数のみを考慮するだけで十分です。 合成数の場合`d`いくつかの要素を除算すると、それらすべての要素も少なくとも 1 つの素因数で割り切れるため、素数のパフォーマンスが悪化することはありません。 

したがって、問題は素因数ごとに数えることになります。`p`、割り切れる配列要素の数`p`、そして最大値を選択します。

 ## アルゴリズムのチュートリアル

 まず、すべてをグローバル gcd で除算して配列を正規化します。 これにより、共通のベースラインが削除され、1 を超える改善のみを検索することが保証されます。 

1. 配列全体の gcd を計算します。 これは、サブセットの可能な最小の gcd です。 
2. すべての要素をこの gcd で除算します。 このステップの後、フルアレイの gcd は 1 になります。 
3. 結果の数値がすべて 1 の場合は、停止して戻ります。`-1`。 どの数値にも素因数が含まれていないため、サブセットは 1 より大きい gcd を持つことはできません。 
4. 各数値について、その固有の素因数を抽出します。 
5. 素数の頻度カウンタを維持し、各素数を数値ごとに最大 1 回インクリメントします。 
6. 最良の候補は、最も多くの要素に現れる素数です。 
7. 答えは、合計要素からこの最大周波数を引いたものです。 

ステップ 5 の背後にある推論は重要です。 素因数分解で素数が何回出現するかではなく、素数が数値を除算するかどうかのみを考慮します。 1 つの数値内の重複をカウントすると、貢献度が誤って水増しされてしまいます。 

### なぜ効果があるのか

 有効なサブセットはすべて、gcd が 1 より大きい必要があります。これは、そのすべての要素が少なくとも 1 つの素因数を共有することを意味します。 素数の修正`p`、gcd が次の値で割り切れる最良のサブセット`p`は正確に、以下で割り切れるすべての数値の集合です。`p`。 すべての有効なサブセットは少なくとも 1 つのそのような素数に対応し、すべてのそのようなサブセットはこのカウントによって完全に捕捉されるため、素数を最大化することで最適なソリューションが得られます。 最適なグループ以外のすべてを削除すると、最小限の削除が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    from math import gcd

    g = 0
    for x in a:
        g = gcd(g, x)

    b = [x // g for x in a]

    mx = max(b)
    if mx == 1:
        print(-1)
        return

    spf = list(range(mx + 1))
    i = 2
    while i * i <= mx:
        if spf[i] == i:
            for j in range(i * i, mx + 1, i):
                if spf[j] == j:
                    spf[j] = i
        i += 1

    def get_primes(x):
        res = []
        while x > 1:
            p = spf[x]
            res.append(p)
            while x % p == 0:
                x //= p
        return set(res)

    freq = {}
    best = 0

    for x in b:
        if x == 1:
            continue
        for p in get_primes(x):
            freq[p] = freq.get(p, 0) + 1
            if freq[p] > best:
                best = freq[p]

    print(n - best)

if __name__ == "__main__":
    solve()

最終的な答えは、最良の素数で割り切れないすべての要素を削除して計算されます。 どの数値にも素因数が現れない場合、最良の頻度はゼロのままで、答えは次のようになります。`n`、しかし、以前のチェックにより、確実に戻ります`-1`改善が不可能な場合。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    return sys.stdout.getvalue() if False else solve_capture(inp)

def solve_capture(inp: str) -> str:
    import sys
    from math import gcd
    input = sys.stdin.readline

    data = inp.strip().split()
    n = int(data[0])
    a = list(map(int, data[1:]))

    g = 0
    for x in a:
        g = gcd(g, x)

    b = [x // g for x in a]
    mx = max(b)
    if mx == 1:
        return "-1\n"

    spf = list(range(mx + 1))
    i = 2
    while i * i <= mx:
        if spf[i] == i:
            for j in range(i * i, mx + 1, i):
                if spf[j] == j:
                    spf[j] = i
        i += 1

    def get_primes(x):
        s = set()
        while x > 1:
            p = spf[x]
            s.add(p)
            while x % p == 0:
                x //= p
        return s

    freq = {}
    best = 0

    for x in b:
        if x == 1:
            continue
        for p in get_primes(x):
            freq[p] = freq.get(p, 0) + 1
            best = max(best, freq[p])

    return str(n - best) + "\n"

 ## 特殊なケース

 グローバル gcd で除算してすべての数値が 1 になると、すべての要素はすべての素数構造を失います。 アルゴリズムは最大値チェックを通じてこれを直接検出し、返します。`-1`1 より大きい約数はどのサブセットにも存在できないため、因数分解を試行する前に実行してください。 

のような入力の場合`[6, 10, 15]`、正規化により配列は変更されません。 各数値は異なる素数に寄与しますが、複数の要素に素数が現れることはありません。 最大周波数は 1 になります。これは、最適なサブセットのサイズが 1 であることを意味し、`n - 1`要素は可能な限り最良の結果であり、アルゴリズムはそれを正しく返します。
