 ## 解決策
 ## 問題の理解

 整数の配列が与えられ、非常に制限されたタイプの順列を使用してそのインデックスを並べ替えることができます。つまり、最初に戻る前にすべての位置を 1 回だけ訪問する単一サイクルです。 言い換えれば、任意の順列を選択することはできず、すべてのインデックスにわたって完全なサイクルを形成する順列のみを選択することができます。 

この巡回順序付けを適用した後、その新しい順序で配列を読み取り、新しいシーケンスを取得します。 目標は、結果として得られるシーケンスを対称にすることです。つまり、左から右、右から左に同​​じように読めるようにすることです。 

したがって、タスクは値を回文に並べ替えるだけではなく、サイクル内の反対の位置が等しい値を持つように、単一サイクルに沿って位置を割り当てることができるかどうかを判断することです。 

順列は 1 サイクルでなければならないという制限が重要な制約です。 これがなければ、一致する値を持つ位置を自由にペアにして、標準のマルチセット マッチングで解決できます。 サイクル制約により、グローバル順序構造が強制され、単一ループ内ですべての位置に後続および先行が 1 つだけ存在します。 

入力サイズはテスト ケース全体で合計 200,000 要素に達するため、ソリューションはテストごとに線形またはほぼ線形である必要があります。 二次構成や順列の繰り返しシミュレーションは実行できません。 

いくつかの特殊なケースが実現可能性を決定します。 すべての値が同一の場合、どのサイクルでも機能するため、答えは自明に「はい」になります。 頻度分布が非常に不均衡な場合、たとえば 1 つの値が大きく支配しすぎる場合、サイクルに沿って等しいペアを対称的に分布させることはできません。 もう 1 つの微妙なケースは、n が偶数または奇数の場合です。これは、対称の中心がパリティに応じて異なる動作をするためです。ただし、ここではシーケンスが循環的に置換されているため、固定された中央のインデックスではなく、サイクル内の反対の位置の周囲で対称が強制されます。 

隠れた主な困難は、サイクル構造により、値のペアの制約を尊重する位置にわたってハミルトニアン サイクルを構築する必要があることです。 

## アプローチ

 サイクルの制限を無視する場合、自然な考え方は、等しい値をペアにして、各ペアを回文内で対称的に配置することです。 これにより、問題は値ごとにインデックスをグループ化し、それらを外側から内側に照合することになります。これは、標準的な回文構築問題に機能します。 

ただし、サイクル制約はこの自由を壊します。 位置 i が σ(i) にマッピングされると決定すると、構造全体が単一の有向サイクルになります。 つまり、値を個別に配置するのではなく、インデックス セット全体を 1 つの循環注文に埋め込んでいます。 単純な試みでは、すべての順列を試し、それが循環であるかどうかを確認し、回文の妥当性をテストします。 これは複雑さの要因であり、すぐには実行不可能です。 

より構造化されたビューは、最終的なサイクル順序で対称になる必要がある位置のペアの観点から考えることです。 円上にインデックスを配置することを想像すると、円上の反対側の点は同じ値を持つ必要があります。 したがって、同じ値を持つインデックスは、円全体でペアになるように配置する必要があります。 

これが建設的なアイデアにつながります。 インデックスを値ごとにグループ化します。 各グループ内で、サイクル全体の対称制約を満たすためにインデックスを使用する必要があります。 重要な観察は、各値クラスが、サイクル全体でミラーリングされたペアに分割する必要がある位置に寄与していることです。 いずれかのグループに、他のグループと一貫してペアリングできない奇数の残りがある場合、構築は失敗します。 

ペアリングが決定したら、ペアのエンドポイントを交互に切り替えてサイクルを構築し、すべてのインデックスに後続が 1 つだけ存在するように慎重につなぎ合わせ、サイクルが終了します。 

問題は、すべてのインデックスを一貫して対称ペアにできるかどうかを判断し、それらのペアを有効な巡回置換に順序付けることができるかどうかということになります。

 ## アルゴリズムのチュートリアル

 1. すべてのインデックスを値ごとにグループ化します。 各値 v は、それが出現する位置のリストを示します。 回文では等しい値のみをミラーリングできるため、これが必要です。 
2. 各グループについて、グループ内で任意にインデックスをペアにします。 グループのサイズが奇数の場合は、1 つのインデックスを一時的にペア解除したままにしておきます。 これらのペアになっていないインデックスは、可能であれば、後で異なる値間で照合されます。 
3. すべてのグループから残りの不対インデックスをすべて収集します。 これらは、独自の値クラス内で一致しなかった要素を表します。 
4. 残ったインデックスの数が 2 より多い場合、構築は不可能です。 これは、サイクル回文では、一致しない位置が最大 1 つの交差値ペアしか形成できないためです。 
5. 残りのインデックスがちょうど 2 つある場合、それらはサイクル構造内で互いに反対側に配置する必要があります。 ちょうど 1 つだけ残っている場合、それは構造的にそれ自身と対になっている必要がありますが、固定点のない厳密なサイクルではそれは不可能なので、その場合は答えは不可能です。 
6. 次に、対称制約を表すペアのリストを作成します。 各ペア (u、v) は、これら 2 つの位置がサイクル順序で反対に表示される必要があることを意味します。 
7. 任意のペアから開始して未使用のペアを繰り返しリンクすることによってサイクルを構築し、各位置に 1 つの後続と 1 つの先行に正確に割り当てられるようにします。 
8. すべてのペアが 1 つのループに接続されたら、後続ポインターによって定義された順列を出力します。 

### なぜ効果があるのか

 この構造では、すべてのインデックスが 1 つの対称ペアに参加することが強制され、サイクル内の反対の位置にエンドポイントを配置することですべてのペアが尊重されます。 順列は単一サイクルであるため、すべてのインデックスには出力エッジが 1 つだけあり、ペアリングが完了しているため、等しい値によって引き起こされるすべての制約が満たされます。 グローバル サイクルにより接続が確保され、ローカル ペアリングにより回文対称性が確保されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        pos = {}
        for i, v in enumerate(a):
            pos.setdefault(v, []).append(i + 1)

        pairs = []
        leftover = []

        for v, lst in pos.items():
            for i in range(0, len(lst) - 1, 2):
                pairs.append((lst[i], lst[i + 1]))
            if len(lst) % 2 == 1:
                leftover.append(lst[-1])

        if len(leftover) > 2:
            print("NO")
            continue

        # we now try to build cycle structure using pairs
        nodes = []
        for u, v in pairs:
            nodes.append(u)
            nodes.append(v)

        if len(leftover) == 2:
            nodes.extend(leftover)
        elif len(leftover) == 1:
            print("NO")
            continue

        # build adjacency in cycle
        m = len(nodes)
        if m != n:
            print("NO")
            continue

        # arrange nodes alternately
        left = nodes[:m // 2]
        right = nodes[m // 2:][::-1]

        perm = [0] * n
        for i in range(m // 2):
            perm[left[i] - 1] = right[i]
            perm[right[i] - 1] = left[(i + 1) % (m // 2)]

        # verify cycle property (safety)
        vis = set()
        cur = 1
        ok = True
        for _ in range(n):
            if cur in vis:
                ok = False
                break
            vis.add(cur)
            cur = perm[cur - 1]

        if not ok or len(vis) != n:
            print("NO")
        else:
            print("YES")
            print(*perm)

if __name__ == "__main__":
    solve()
```このソリューションでは、まずインデックスを値ごとにグループ化し、内部ペアを貪欲に形成します。 残った要素は構造的な不均衡を表すため、追跡されます。 3 つ以上が残っている場合、単一サイクル制約の下では循環回文は存在できません。 

構築ステップでは、ペアになっているすべてのエンドポイントをシーケンスに平坦化し、それを 2 つの半分に分割します。 半分は反転され、置換マッピングのターゲットとして使用され、ミラー構造が保証されます。 各インデックスは、循環一貫性を強制する方法で、対応するペアを指します。 

最後に、検証ステップでサイクルをシミュレートし、順列が実際に 1 サイクルであることを確認します。 これにより、微妙な施工上の欠陥を防ぐことができます。

 ## 特殊なケース

 重大なエッジケースは、ちょうど 1 つの値が奇数回発生する場合です。 たとえば、配列が次の場合、`[1, 1, 1]`、ペアリング後にインデックスが 1 つ残ります。 シングルサイクル置換では全単射制約を破らずにペアになっていない要素を対称位置に配置できないため、アルゴリズムはこれを拒否します。 

もう 1 つのエッジ ケースは、複数の値のそれぞれが奇数の残り物に寄与し、2 つ以上の不対インデックスを生成する場合に発生します。 例えば`[1,1,2,2,3]`合計3つが残ります。 回文対称性を破ることなくこれらを単一のサイクルに一貫してペアにすることができないため、構築は早期に失敗します。 

最後の構造的なエッジケースは、ローカルではペアリングが成功するが、グローバルでは単一サイクルの形成に失敗する場合です。 検証ステップでは、トラバーサルを明示的にシミュレートすることでこの状況を捉え、構築された順列が複数の互いに素なサイクルではなく、1 つの接続されたサイクルであることを確認します。
