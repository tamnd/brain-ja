## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_power_of_two(x):
    return x > 0 and (x & (x - 1)) == 0

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        
        if is_power_of_two(n):
            print(-1)
            continue
        
        k = 2
        while k * (k + 1) // 2 > n:
            k += 1
        
        print(k)

if __name__ == "__main__":
    solve()

条件$k(k+1)/2 \le n$実現可能性フィルターとして使用されます。 これは、各剰余クラスの最小代表を合計することから直接得られます。 ループは安全であるため、$k$ゆっくりと成長し、大まかに境界が定められています$O(\sqrt{n})$, しかし実際には、すべての有効な入力に対して非常に早く停止します。
