 ## 問題の理解

 正の整数の配列からインデックスの「適切なペア」を見つけるように求められます。 適切なペアは 2 つのインデックスで構成されます$i$そして$j$何らかの要素を考慮すると、$a_k$配列内の、からの距離の合計$a_i$に$a_k$そしてから$a_k$に$a_j$からの距離に等しい$a_i$に$a_j$。 幾何学的に言えば、$a_k$を結ぶ直線上になければなりません$a_i$そして$a_j$, 実数直線上の数字を考えるとき。 

入力は複数のテスト ケースで構成され、それぞれのテスト ケースは配列サイズを持ちます$n$そして配列要素。 出力は適切なペアを識別する必要があり、問題は解決策が常に存在することを保証します。 重要な詳細は次のとおりです$i$等しいかもしれない$j$これにより、サイズ 1 の配列に対する自明な解決策がすぐに得られます。 

制約により、最大で$10^5$単一の配列内の要素、およびすべてのテスト ケースの合計が以下を超えないこと$2 \cdot 10^5$。 これは、アレイごとに線形以上の作業を実行するソリューションは遅すぎる可能性があることを意味します。 また、絶対値プ​​ロパティを無視すると、最初の 2 つのインデックスの単純な選択が失敗する可能性があるため、すべての要素が等しい配列、2 つの要素を含む配列、または重複を含む配列には一般的に注意する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、インデックスのすべてのペアを試します。$(i, j)$すべての定義プロパティを確認します$k$。 これには必要です$O(n^3)$最悪の場合の動作は次のとおりです。$O(n^2)$私たちが検討するペア$n$要素。 これは明らかに不可能です$n$まで$10^5$。 

平等を守る$$|a_i - a_k| + |a_k - a_j| = |a_i - a_j|$$単純化を明らかにします。 左辺はからの距離に等しい$a_i$に$a_j$もし、そしてその場合に限り$a_k$間にあります$a_i$そして$a_j$包括的な。 つまり、どちらかです$a_i \le a_k \le a_j$または$a_j \le a_k \le a_i$。 この洞察により、問題は配列内の最小値と最大値である 2 つの数値を見つけることに帰着します。 どれでも$k$他のすべての要素は最小値と最大値の間にあるため、このプロパティは自動的に満たされます。 したがって、問題は、最小要素と最大要素を特定することに帰着します。$O(n)$時間。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$そして配列$a$。 
2. 配列の最小値と最大値、およびそれぞれのインデックスを格納する 2 つの変数を初期化します。 
3. 配列を反復処理します。 現在の要素が現在の最小値より小さい場合は、最小値とそのインデックスを更新します。 現在の最大値より大きい場合は、最大値とそのインデックスを更新します。 
4. 反復が終了すると、最小要素と最大要素のインデックスが得られます。 これらのインデックスを適切なペアとして出力します。 
5. 配列に要素が 1 つだけ含まれている場合は、そのインデックスを 2 回出力します。 これにより、追加のチェックを行わずに特殊なケースがカバーされます。 

これが機能する理由: 最小値と最大値を選択すると、他のすべての配列要素がそれらの間に位置します。 これにより、あらゆる場合に次のことが保証されます。$k$、$|a_i - a_k| + |a_k - a_j| = |a_i - a_j|$、良好なペア特性を満たします。 どの要素も平等性を侵害することはできず、リニア スキャンによって正確さと効率が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        min_val = float('inf')
        max_val = float('-inf')
        min_idx = max_idx = 0

        for idx, val in enumerate(a):
            if val < min_val:
                min_val = val
                min_idx = idx
            if val > max_val:
                max_val = val
                max_idx = idx

        # output 1-based indices
        print(min_idx + 1, max_idx + 1)

if __name__ == "__main__":
    solve()
```このソリューションは、高速 I/O を使用して各配列を効率的に読み取ります。 インデックスを注意深く追跡して、1 から始まる結果を返します。 使用する`float('inf')`そして`float('-inf')`大きな整数であっても正しい初期化が保証されます。 配列を 1 回繰り返すと保証されます$O(n)$テストケースあたりの時間。
