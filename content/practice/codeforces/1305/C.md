 ## アルゴリズムのチュートリアル

 1. すべてのペアごとの差が次のようになるように配列をソートします。$a_j - a_i$と$j > i$。 これにより、絶対値を回避し、差異に対する一貫した方向性を維持できるようになります。 
2. 配列を初期化する`cnt`サイズの$m$以前に見た数値が各剰余クラスのモジュロに該当する数を保存します。$m$。 これにより、処理されたすべての要素の履歴が圧縮されます。 
3. 1 に初期化された実行中の回答を維持します。 
4. ソートされた配列を反復処理します。 現在の各要素について$x$、残差クラスを反復処理することにより、以前のすべての要素に対する寄与を計算します。$r \in [0, m-1]$。 各剰余クラスは、値が一致するモジュロである数値のグループを表します。$m$、そのクラス内のすべての要素は、モジュラー算術における同じ剰余構造に寄与します。 
5. 各残基クラスについて、差の積の寄与を計算します。$(x - y) \mod m$みんなのために$y$そのクラスで乗算することで$(x - r) \mod m$に従って繰り返し`cnt[r]`。 これにより、個々の要素の反復処理がグループ化された累乗に置き換えられます。 
6. 現在の要素のコントリビューションを処理した後、更新します`cnt[x % m] += 1`。 
7. すべての要素が処理されるまで続行します。 

重要な不変条件は、ステップで$i$、`cnt[r]`最初の要素のうちのいくつの要素が正しく保存されますか$i$残基クラスに属する$r$、これまでに計算された部分積は、それらの処理された要素間のすべてのペアごとの差のモジュロの積に等しくなります。$m$。 新しい各要素は、前の要素との差異を正確に使用して積を拡張します。剰余によるグループ化は、モジュラー乗算が繰り返される同一の因数に分散するため、正確さを維持します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    
    a.sort()
    
    cnt = [0] * m
    ans = 1

    for x in a:
        rx = x % m
        # multiply contributions with previous elements
        for r in range(m):
            if cnt[r]:
                diff = (rx - r) % m
                # multiply diff repeated cnt[r] times
                for _ in range(cnt[r]):
                    ans = (ans * diff) % m

        cnt[rx] += 1

    print(ans)

if __name__ == "__main__":
    solve()

微妙な点は、概念的には寄与を多くの同一の要素の積として扱っているにもかかわらず、明示的にループしていることです。`cnt[r]`回。 残基上の外側のループは次のように制限されているため、これでも効率的です。$m$、合計更新が残っています$O(nm)$。
