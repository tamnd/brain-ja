 ## アルゴリズムのチュートリアル

 ### 1. 候補番号を集める

 私たちはすべての価値観を受け入れます$a_i - 1$、$a_i$、 そして$a_i + 1$、必要に応じて無効な正の制約を無視します。 これらは、最小限の編集で新しい gcd 構造を現実的に作成できる唯一の場所です。 

要素をわずかにシフトすることで、システムに新しい素因数を導入できることが直感的にわかります。 

### 2. 各候補数を因数分解する

 収集されたすべての値について、試行除算を使用して素数に因数分解します。$\sqrt{x}$。 発見された各素数は候補 gcd として保存されます。 

繰り返し出現しても評価は変わらないため、セットを使用して素数の重複を排除します。 

### 3. 各候補素数を評価する

 素数ごとに$p$、すべての要素のコストを計算します。$$\text{cost}(p) = \sum_i \min(a_i \bmod p,\, p - (a_i \bmod p))$$これは、それぞれを移動するために必要な±1 回の操作の最小数を表します。$a_i$の倍数に$p$。 

すべての素数の最小値を取得します。 

### 4. 最良の結果を返す

 答えは、テストされたすべての素数の最小コストです。 

### なぜ効果があるのか

 重要な構造特性は、最適な最終 gcd が$g$すべての最終要素を分割する必要があります。つまり、少なくとも 1 つの変更された値は正確に次の倍数でなければなりません。$g$。 各要素は安価にしか変更できないため、少なくとも 1 つは$a_i - 1, a_i, a_i + 1$と素因数を共有する必要があります$g$。 これにより、最適解のすべての素因数が因数分解ステップで確実に発見されます。 

したがって、gcd 値を直接列挙する必要はなく、それを生成する素数のみを列挙する必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def factor(x, primes):
    res = set()
    tmp = x
    for p in primes:
        if p * p > tmp:
            break
        if tmp % p == 0:
            res.add(p)
            while tmp % p == 0:
                tmp //= p
    if tmp > 1:
        res.add(tmp)
    return res

def sieve(limit=2000):
    is_p = [True] * (limit + 1)
    is_p[0] = is_p[1] = False
    ps = []
    for i in range(2, limit + 1):
        if is_p[i]:
            ps.append(i)
            for j in range(i * i, limit + 1, i):
                is_p[j] = False
    return ps

def cost(a, p):
    r = a % p
    return min(r, p - r)

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    small_primes = sieve(2000)

    candidates = set()
    for x in a:
        for v in (x - 1, x, x + 1):
            if v > 1:
                candidates.add(v)

    primes = set()
    for v in candidates:
        primes |= factor(v, small_primes)

    ans = float('inf')

    for p in primes:
        s = 0
        for x in a:
            r = x % p
            s += min(r, p - r)
        ans = min(ans, s)

    print(ans)

if __name__ == "__main__":
    solve()

各素数のコスト計算は、モジュラー距離を使用した配列上の単一の線形パスです。 最終的な答えは、これらの値の最小値です。 

微妙な点は扱い方$a_i - 1$、ゼロになる可能性があります。 これらの値は有効な素数構造に寄与しないため、安全にスキップされます。
