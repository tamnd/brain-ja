 ## 解決策
 ## 問題の理解

 私たちは単位正方形の無限のグリッド上を移動します。 どのマスからでも、上下左右に 1 歩ずつ移動できます。 一部のマスには悪いマークが付けられており、そのようなマスに入るには 1 コストかかります。 開始マスと終了マスは良好であることが保証されているため、答えはその間に訪れた不良マスのみをカウントします。 

正方形`(x, y)`対角線の 2 つの系列のいずれかにある場合は不良です。$|x+y|\equiv 0 \pmod{2a}$または$|x-y|\equiv 0 \pmod{2b}$座標とパラメータは次のように大きくなります。`10^9`したがって、グリッドを直接探索するアルゴリズムは不可能です。 マンハッタンの最短の道を歩くだけでも、約`2 * 10^9`動きます。 解は定数時間または対数時間で機能する必要があります。 

主な困難は、これらの不良セルが実際に幾何学的にどのように見えるかを理解することです。 単純に読むと危険な細胞が散在していることが示唆されますが、一致条件は斜めの縞全体を表します。 答えはグリッド上の経路探索に関するものではなく、2 つの領域を区切る障壁線の数を数えることにあります。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

たとえば、両方の点が同じ安全領域内にあると仮定します。```
2 2 1 0 1 1
```答えは`0`。 点間の長方形と交差する悪い対角線の数を数える不注意な解決策では、誤って肯定的な答えが生成されてしまいます。 

座標が負の場合、別の微妙なケースが発生します。```
3 4 -10 -1 7 20
```不良条件は絶対値を使用します。 整数の除算が負の場合にどのように動作するかを忘れると、式は 1 つ間違ってしまいます。 ソリューションではフロア分割を慎重に使用する必要があります。 

点が不良ラインのすぐ隣にある場合にも、境界の問題が発生します。 考慮する：```
2 2 1 0 0 1
```答えは`1`。 2 つの点は、1 つの不良対角線だけで区切られた隣接領域にあります。 フロアロジックの代わりに通常の除算を使用して境界を誤って数えると、次の結果が得られる可能性があります。`0`または`2`。 

最後の重要な観察は、悪い対角線の交差によって答えが 2 倍増加するわけではないということです。 接続された不良コンポーネントを 1 つ通過するには、そこに接触する不良セルの数に関係なく、1 回の訪問が必要になります。 対角線を独立して処理すると、過大なカウントが発生します。 

## アプローチ

 ブルート フォース解釈では、すべてのグリッド正方形をグラフの頂点としてモデル化し、BFS またはダイクストラを実行します。 良い広場に移動するには費用がかかります`0`、悪いマスに移動するとコストがかかります`1`。 グリッドは無限であるため、少なくとも点の周囲の境界ボックスに制限する必要があります。 

これは、最短パス アルゴリズムがすべての可能なルートにわたる総コストを正しく最小化するため、概念的には機能します。 問題は規模だ。 座標は数十億単位異なる可能性があるため、到達可能な長方形を保存するだけでも約`10^18`最悪の場合は細胞も。 グラフの走査はリモートでは実行できません。 

不良セルの構造は、より強力な視点を与えます。 方程式には次のことが含まれます`x + y`そして`x - y`、これは対角座標です。 各条件は、無限に多くの平行な対角線を記述します。 これらの線は、平面を接続された安全な領域に分割します。 

重要な幾何学的事実は、ある安全な領域から別の安全な領域に移動するには、危険な対角線を 1 回だけ横切る必要があるということです。 不良セル自体が領域間の境界を形成するため、訪問される不良セルの最小数は、単純に分離する対角線のバリアの最小数になります。 

理屈で考えるのではなく、`(x, y)`座標を直接指定するには、次のように定義します。$u=x+y$そして$v=x-y$悪い線は縦線と横線になります。`(u, v)`飛行機：$u\equiv 0 \pmod{2a}$そして$v\equiv 0 \pmod{2b}$安全領域は、これらの線の間にある長方形のセルです。 2 つの点が、連続する倍数間の同じ間隔に属している場合、それらは同じ領域内にあります。`2a`そして`2b`。 

したがって、答えは、変換された座標を区切る領域境界の数を数えることに帰着します。 それは単純な算術計算になります。

 ## アルゴリズムのチュートリアル

 1. 両方の点を対角座標に変換します。$u=x+y,\quad v=x-y$これらの座標では、不良対角線が軸に沿ったグリッド線になります。 
2. 各点について、それがどの水平ストリップに属するかを決定します。`u`方向。 

これをフロア分割で行います。`2a`:$U=\left\lfloor \frac{u}{2a} \right\rfloor$悪い一線を越えるたびに`u = k * 2a`、このインデックスは 1 ずつ変化します。 
3. に対しても同じことを行います。`v`使用する方向`2b`:$V=\left\lfloor \frac{v}{2b} \right\rfloor$4. 交差する不良領域の最小数は次のようになります。$\max\left(|U_1-U_2|, |V_1-V_2|\right)$1 つの不良コンポーネントを横切ると、両方の座標が同時に 1 つ進む可能性があります。 そのため、答えは合計ではなく、最大の差になります。 
5. 結果を印刷します。 

### なぜ効果があるのか

 不適切な対角線により、飛行機が接続された安全ゾーンに分割されます。 変換された座標で`(u, v)`、これらのゾーンは、垂直方向と水平方向の不良線で区切られた長方形です。 

ある長方形から別の長方形に移動すると、次のいずれかが変化します。`u`ストリップインデックスまたは`v`交差点ごとに最大 1 つずつインデックスを削除します。 不良接続コンポーネントに 1 回アクセスすると、交差点を通過するときに両方の座標を同時に調整できます。 

つまり、どのパスでも少なくとも`max(|ΔU|, |ΔV|)`交差点ごとに各座標が最大 1 つずつ変化するためです。 逆に、両方の座標の調整が必要な場合には、戦略的に交差点を横断することで、正確に同じ数の交差点を達成するパスをいつでも構築できます。 

したがって、下限と上限は一致し、最適性が証明されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a, b, x1, y1, x2, y2 = map(int, input().split())

    u1 = x1 + y1
    v1 = x1 - y1

    u2 = x2 + y2
    v2 = x2 - y2

    du = abs(u1 // (2 * a) - u2 // (2 * a))
    dv = abs(v1 // (2 * b) - v2 // (2 * b))

    print(max(du, dv))

solve()
```最初のセクションでは、通常の座標を対角座標に変換します。 これが中心となる幾何学的変換です。 この変形の後、複雑な斜めの障壁は、等間隔に配置された普通の垂直線と水平線になります。 

次の部分では、各ポイントがどのストリップに属するかを計算します。 座標が負になる可能性があるため、フロア分割を使用することが不可欠です。 パイソンの`//`演算子はすでに数学的な床の除算を実行しています。これはまさに私たちが必要としているものです。 

答えはそうではありません`du + dv`。 これは、すべての交差点で 1 つの座標のみが変更されると仮定します。 不良対角線の交差点では、1 つの交差点で両方のストリップ インデックスが同時に進む可能性があります。 これが、正しい公式が使用する理由です。`max`。 

この実装では整数演算のみを使用するため、次の値に近い場合でも精度の問題はありません。`10^9`limits.

import io

def solve_io(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

 ## 特殊なケース

 両方の点が同じ安全領域内にある場合を考えてみましょう。```
2 2 1 0 1 1
```次のように計算します。 

-`u1 = 1`、`u2 = 2`-`v1 = 1`、`v2 = 0`それから：

-`1 // 4 = 0`-`2 // 4 = 0`-`1 // 4 = 0`-`0 // 4 = 0`したがって、変換された両方のストリップ インデックスが一致し、答えが得られます。`0`。 ポイントを区切る不適切な対角線はありません。 

次に、負の座標の場合を調べます。```
3 4 -10 -1 7 20
```変換された座標は次のとおりです。 

-`u1 = -11`-`u2 = 27`フロア分割の使用:

 -`-11 // 6 = -2`-`27 // 6 = 4`違いは`6`。 

誤ってゼロに向かって切り捨てた場合、次のようになります。`-1`の代わりに`-2`、答えを生み出す`5`、それは間違いです。 Python のフロア分割が幾何学的分割と一致するため、アルゴリズムは成功します。 

最後に、境界隣接の場合を考えてみましょう。```
2 2 1 0 0 1
```変身した`u`座標は同じストリップ内に残りますが、`v`座標がストリップから移動します`0`剥ぐ`-1`。 ちょうど 1 つの悪い対角線がそれらの間にあるため、答えは次のようになります。`1`。 

これにより、ストリップインデックスの解釈がグリッドのジオメトリと正確に一致することが確認されます。
