 ## 問題の理解

 3 つの辺すべてが最大で 1 になるような整数辺の直角三角形がいくつ存在するかを数える必要があります。`n`。 

辺のある直角三角形`(a, b, c)`はピタゴラス方程式を満たします。$a^2+b^2=c^2⟦PROTECT_24⟧b⟦PROTECT_25⟧a^2 + b^2 = c^2 \approx 225.00 + 225.00 = 450.00$a と b を調整すると、三角形と c.abc の派生値が更新されます。 

この問題により、辺の順序が制限されます。```
1 ≤ a ≤ b ≤ c ≤ n
```三角形は次のようなものであるため、順序が重要です。`(3,4,5)`そして`(4,3,5)`同じ三角形として扱う必要があります。 条件`a ≤ b`重複を自動的に削除します。 

入力には単一の整数が含まれています`n`。 出力は有効なトリプルの数です。`(a, b, c)`方程式と順序制約を満たしていること。 

上限はあくまで`10^4`。 そうすれば問題の性質はすぐに変わります。 たとえ`O(n^2)`アルゴリズムは以下のことを実行します`10^8`Python で慎重に実装すれば、最悪の場合でも単純な演算が可能になります。これはまだ境界線にありますが、軽量の算術演算では許容できることがよくあります。 アン`O(n^3)`解決策は完全に不可能です。`10^12`繰り返し。 

主な課題は、トリプルの不必要な列挙を避けることです。 

重複した三角形が誤ってカウントされた場合、微妙なエッジケースが発生します。 

たとえば:

 入力:```
5
```唯一有効な三角形は`(3,4,5)`。 

正しい答えは次のとおりです。```
1
```すべての順序付けられたペアをループする不用意な総当たり攻撃`(a,b)`強制せずに`a ≤ b`両方を数えます`(3,4,5)`そして`(4,3,5)`そして間違って印刷してしまう`2`。 

もう一つの簡単な間違いは、それを忘れることです`c`最大でも`n`。 

たとえば:

 入力:```
10
```ペア`(6,8)`生成する`c = 10`、これは有効です。 

しかし`(8,15)`生成する`c = 17`、方程式を満たしていてもカウントしてはなりません。 

3 番目の落とし穴は、浮動小数点の精度にあります。 一部の実装では以下を計算します。```
c = int(math.sqrt(a*a + b*b))
```そして、方程式が成り立つかどうかを確認します。 浮動小数点の丸めにより、大きな数値に対して不正確な値が生成される場合があります。 安全なアプローチは、次のことを明示的に確認することです。```
c * c == a * a + b * b
```三角形を数える前に。

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`。 
2.初期化`answer = 0`。 
3. 反復する`a`から`1`に`n`。 

これにより、三角形の最初の脚が選択されます。 
4. 反復する`b`から`a`に`n`。 

から始まる`a`保証する`a ≤ b`したがって、すべての三角形は正確に 1 回カウントされます。 
5. 以下を計算します。```
s = a*a + b*b
```これは斜辺の二乗です。 
6. 以下を計算します。```
c = int(s ** 0.5)
```かどうかを確認するだけで済みます。`s`は完全な正方形です。 
7. 両方の条件を確認します。```
c * c == s
c <= n
```最初の条件は次のことを確認します。`c`は整数です。 

2 つ目は、三角形が問題の境界を尊重するようにします。 
8. 両方の条件が当てはまる場合、答えをインクリメントします。 
9. 最終的な答えを印刷します。 

### なぜ効果があるのか

 アルゴリズムは、考えられるすべての順序ペアを検査します。`(a,b)`満足のいく`1 ≤ a ≤ b ≤ n`。 

各ペアについて、可能な値は 1 つだけです。`c`それはピタゴラス方程式を満たす可能性があります。 アルゴリズムはその候補を計算し、それが範囲内の有効な整数であるかどうかをチェックします。 

ループによって強制されるため、有効な三角形はすべて 1 回だけ表示されます。`a ≤ b`。 次の等式があるため、無効な三角形は数えられません。$a^2+b^2=c^2⟦PROTECT_30⟧b⟦PROTECT_31⟧a^2 + b^2 = c^2 \approx 225.00 + 225.00 = 450.00$a と b を調整すると、三角形と c.abc の派生値が更新されます。 

直接チェックされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

answer = 0

for a in range(1, n + 1):
    for b in range(a, n + 1):
        s = a * a + b * b
        c = int(s ** 0.5)

        if c <= n and c * c == s:
            answer += 1

print(answer)
```外側のループは最初のレグを選択します`a`。 内部ループは次から始まります`a`の代わりに`1`、重複した注文が自動的に削除されます。 

変数`s`店舗:$a^2+b^2$コードは整数の平方根候補を計算します。`c`浮動小数点平方根と整数変換を使用します。 重要な詳細は検証ステップです。```
c * c == s
```このチェックを行わないと、丸めエラーにより非正方形が正方形として誤って分類される可能性があります。 

条件:```
c <= n
```斜辺が制限を超える三角形をカウントしないようにします。 

追加の配列やデータ構造は必要ないため、メモリ使用量は一定に保たれます。

import io

def solve():
