 ## 解決策
 ## 問題の理解

 次のサイズの長方形グリッドが与えられます。$n \times m$、各セルは塗りつぶされるか空になります。 「都市」は、塗りつぶされたセルの接続されたコンポーネントとして定義され、接続は側面を通して行われます (対角線はありません)。 最初は、グリッド上にちょうど 2 つの都市があります。 私たちの仕事は、いくつかの空のセルを埋めて、単一の接続された都市を実現することですが、より厳しい条件があります。つまり、塗りつぶされた 2 つのセル間の最短経路が、それらの間のマンハッタンの距離と正確に等しくなければなりません。 この条件は、すべての塗りつぶされたパスがマンハッタン距離を超える最短パスを増加させる迂回路や分岐がなく「直線的」である必要があることを意味します。 また、追加で塗りつぶされるセルの数も最小限に抑える必要があります。 

入力では、最大グリッドを含む複数のテスト ケースが可能です。$50 \times 50$テスト全体のすべてのセルの合計が 25,000 を超えないこと。 これは、私たちには余裕があることを意味します$O(nm)$あるいは$O((nm)^2)$テスト ケースごとにアプローチしますが、3 次以降のものは遅すぎる可能性があります。 エッジケースには狭いグリッドが含まれます (例:$1 \times 3$) 行または列が 1 つだけ存在するグリッド、2 つの都市が対角の対角にあるグリッド、および都市がすでに行または列に沿って整列しているグリッド。 

DFS を使用して任意の 2 つの都市間のすべてのパスを恣意的に埋めるような単純な接続方法は、マンハッタンの条件に違反する可能性があります。 たとえば、ギザギザのパスに沿って塗りつぶした場合、塗りつぶされたセルに沿った最短距離はマンハッタンの距離を超える可能性があり、これは禁止されています。 

## アプローチ

 この強引なアプローチでは、2 つの都市を接続するために空のセルを埋めるあらゆる可能な方法をテストし、マンハッタンの状況を検証しようとします。 のために$50 \times 50$グリッド、それは組み合わせ的に実行不可能です。 重要な洞察は、マンハッタン メトリックの幾何学的構造を使用することです。 両方の都市のすべての塗りつぶされたセルのセットを考慮すると、マンハッタンの距離条件は、塗りつぶされたセルが 2 つの都市の端を接続する「直線の長方形」を占有する必要があることを意味します。 より具体的には、最初の都市から 1 つのセルを選択し、2 番目の都市から 1 つのセルを選択した場合、行と列のインデックスがまたがる四角形内のすべてのセルを埋めると、マンハッタン距離が維持されることが保証されます。これは、この四角形に沿って塗りつぶされた 2 つのセルは、厳密に行と列に沿ったパスを介して相互に到達できるためです。 

したがって、問題は、最小限の追加の塗りつぶされたセルで 2 つの都市を接続する効率的な長方形を特定することに帰着します。 最適な四角形は、2 つの都市の行インデックスと列インデックスの最小値と最大値を接続することによって取得されます。つまり、都市 A のセルを都市 B のセルに「L 字型」パスに沿って接続することによって得られます。最初は行に沿って、次に列に沿って (またはその逆)。 これには、最大でも 1 つの直線の垂直セグメントと 1 つの水平セグメントが必要であり、新しい塗りつぶしが最小限に抑えられます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(nm)) | O(nm) | 遅すぎる |
 | 最適な直線接続 | O(nm) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グリッドを解析し、塗りつぶされたすべてのセルを見つけます。 BFS または DFS を使用して、2 つの異なる都市を識別し、それらの座標を別々に保存します。 これにより、どのセルが各都市に属しているかを正確に知ることができます。 
2. 各都市から代表的なセルを 1 つ選択します。 どの細胞も機能します。 マンハッタンの不動産は、2 人の代表者の間の補充で十分であることを保証します。 
3. 代表間の L 字型パスを計算します。 まず、2 人の代表者の行と列にまたがる長方形に沿ってすべてのセルを入力します。 実際的な方法の 1 つは、最初のセルから 2 番目のセルの行まで、次にそこから 2 番目のセルの列までセルを埋めることです。 順序は関係ありません。 それは常にマンハッタンの距離特性を満たします。 
4. グリッドにフィリングを適用します。 すでに入力されているセルは変更されません。 これにより、L 字型接続に沿ってのみセルを充填するため、充填されるセルの総数が最小限に抑えられます。 
5. 最終的なグリッドを出力します。 

機能する理由: 不変条件は、2 つの塗りつぶされたセルは、2 つの代表がまたがる長方形内の行と列に限定されたパスを介して相互に到達できるということです。 他のすべてのパスはこの長方形のサブセット、または元の都市内にあるため、塗りつぶされたセルに沿った最短パスはマンハッタン距離に等しくなります。 この長方形の外側にセルを追加する必要はないため、塗りつぶし数は最小限で済みます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        grid = [list(input().strip()) for _ in range(n)]
        city_coords = []
        visited = [[False]*m for _ in range(n)]

        def dfs(r, c, city):
            stack = [(r,c)]
            while stack:
                x, y = stack.pop()
                if visited[x][y]:
                    continue
                visited[x][y] = True
                city.append((x,y))
                for dx, dy in [(-1,0),(1,0),(0,-1),(0,1)]:
                    nx, ny = x+dx, y+dy
                    if 0<=nx<n and 0<=ny<m and grid[nx][ny]=='#' and not visited[nx][ny]:
                        stack.append((nx,ny))

        # find the two cities
        cities = []
        for i in range(n):
            for j in range(m):
                if grid[i][j]=='#' and not visited[i][j]:
                    city = []
                    dfs(i,j,city)
                    cities.append(city)
        
        a_r, a_c = cities[0][0]
        b_r, b_c = cities[1][0]

        # fill L-shaped path
        for r in range(min(a_r, b_r), max(a_r, b_r)+1):
            grid[r][a_c] = '#'
        for c in range(min(a_c, b_c), max(a_c, b_c)+1):
            grid[b_r][c] = '#'

        # output
        for row in grid:
            print(''.join(row))

if __name__ == "__main__":
    solve()
```DFS により、セルの形状が不規則であっても、各都市が正しく識別されることが保証されます。 各都市の最初のセルを選択すると、有効な接続が保証されます。 それらの間の L 字型のパスを埋めると、マンハッタンの距離特性が保持されます。
