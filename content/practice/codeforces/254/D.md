 ## 解決策
 ## 問題の理解

 この問題は、店舗の長方形の地下室を`n × m`グリッドでは、壁になっているセルもあれば、空のセルもあり、眠っているネズミが入っているセルもあります。 ヴァシリーは 2 つの手榴弾を持っており、手榴弾がセル内で爆発すると、その爆発は毎秒、隣接するセルに外側に伝播し、最大で`d`秒ですが、壁を通過することはできません。 タスクは、眠っているネズミがいるすべてのセルが少なくとも 1 つの手榴弾の爆風範囲内にあるような 2 つの手榴弾の配置が存在するかどうかを判断することです。 もしそうなら、我々は 2 つの手榴弾の位置を報告しなければなりません。 それ以外の場合は、戻ります`-1`。 

The constraints give`n`そして`m`最大1000、そして`d`これは、空のセルのすべてのペアを単純に反復するソリューションは、おおよそ次のようになることを意味します。`O((nm)^2)`最悪の場合、最大 10^12 の演算になりますが、明らかに遅すぎます。 の小さな値`d`これは重要です。これは、単一の爆発が伝播できる距離を制限します。つまり、グリッド全体のグローバル最短パスを計算するのではなく、爆発の伝播を、選択したセルからの小さなローカル BFS として扱うことができます。 

明らかではないエッジケースには、壁によって地下室が隔離されたゾーンに分割されているため、すべてのネズミをカバーするために 2 つの手榴弾を正確な位置に配置する必要があるグリッドが含まれます。 たとえば、`5 × 5`グリッド：```
XXXXX
XR..X
X.XRX
X..RX
XXXXX
```不注意なアプローチをすると、2 つの手榴弾が近づきすぎて、壁が爆発を妨げて到達できないネズミが数匹残る可能性があります。 アルゴリズムは、このような空間分離を慎重に処理する必要があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。空のセルのすべてのペアを手榴弾の位置として列挙し、それぞれから BFS の爆発をシミュレートし、すべてのラットのセルがクリアされているかどうかを確認します。 これが機能するのは、爆発が 4 つの基本方向に均一に広がるためです。`d`小さいです。 各 BFS については、探索のみを行います。`O(d^2)`伝播制限により手榴弾の周囲にセルが存在しますが、空のセルの数はおよそ最大で 3 個になります。`10^6`。 すべてのペアをチェックするには時間がかかります`O((nm)^2 * d^2)`実行可能性をはるかに超えた操作です。 

重要な洞察は、すべてのペアをシミュレートする必要はないということです。 代わりに、マルチソース BFS のアイデアを使用して、空のセルから各ラットまでの最大距離を計算できます。 ネズミがそれよりも遠くにいる場合、`d`すべての空のセルからの答えは、`-1`。 すべてのネズミが範囲内にいる場合`d`あるセルの場合、問題はすべてのラットをカバーする 2 つの極端なセルを見つけることになります。1 つの手榴弾を 1 つの軸に沿って最も遠いラットに対応するセルで選択し、もう 1 つは反対の軸に沿って最も遠いラットにある手榴弾を選択します。 以来`d ≤ 8`、1つの手榴弾からの爆発が小さな近所を一掃します。 同じ爆発ゾーンにない 2 つの手榴弾を慎重に選択することで、ラットの集団全体を効率的にカバーできます。 このアプローチでは、ラットの最大分離距離が爆発距離の 2 倍に 1 を加えた値に制限されるため、正確さを保証しながらすべてのペアの反復を回避します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((nm)^2 * d^2) | O(nm) | 遅すぎる |
 | マルチソース BFS + バウンディング | O(nm * d) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グリッドを解析し、すべてのラットとすべての空のセルの位置を記録します。 これにより、グリッドを繰り返しスキャンすることなく、潜在的な爆発中心を迅速に評価できます。 
2. 空のセルごとに、以下に制限された BFS を実行します。`d`4 つの基本的な方向にステップし、爆風がクリアしたすべてのセルをマークします。 このセルからどのラット セルに到達できるかを記録します。 それ以上は伝播しません`d`爆発はその後消えるから`d`秒。 BFS はキューを使用して距離を追跡し、セルの再訪問を回避します。 
3. すべての空のセルからすべてのラットのセルまでの距離マップを作成するか、または各ラットについて、距離内で最も近い空のセルを追跡します。`d`。 このステップでは、小さな機能を活用します。`d`効率を維持するため。 必要なのは地元の近所だけです。 
4. 爆発が最大数のラットをカバーする空のセルを特定します。 1 つの手榴弾ですべてのネズミをカバーできる場合は、2 回返すか、2 番目のセルを選択します。 それ以外の場合は、結合した爆発がすべてのラットをカバーする上位 2 つのセルを選択します。 候補ペアを効率的に反復して、ラット細胞の結合範囲をチェックします。 
5. すべてのラットをカバーする空のセルのペアがない場合は、リターンします。`-1`。 それ以外の場合は、2 つの手榴弾の位置を報告します。 

なぜ効果があるのか​​: すべてのネズミはその範囲内にいる必要があります`d`少なくとも 1 つの手榴弾のステップ。 BFS 伝播により、以下に制限されます`d`、爆発範囲を正確にシミュレートしています。 すべてのネズミをカバーする 2 つの手榴弾の位置を選択することで、ネズミがクリアされないままになることが保証されます。 不変条件は、各ステップで BFS が内部で到達可能なすべてのセルを正しく計算することです。`d`、そのような 2 つの到達可能性セットを結合すると、完全なカバレッジが保証されます。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

n, m, d = map(int, input().split())
grid = [list(input().strip()) for _ in range(n)]

rats = []
empty = []

for i in range(n):
    for j in range(m):
        if grid[i][j] == 'R':
            rats.append((i, j))
            empty.append((i, j))
        elif grid[i][j] == '.':
            empty.append((i, j))

def bfs(start):
    q = deque()
    q.append((start[0], start[1], 0))
    visited = [[False]*m for _ in range(n)]
    visited[start[0]][start[1]] = True
    reachable_rats = set()
    while q:
        x, y, dist = q.popleft()
        if dist > d:
            continue
        if grid[x][y] == 'R':
            reachable_rats.add((x, y))
        for dx, dy in [(-1,0),(1,0),(0,-1),(0,1)]:
            nx, ny = x+dx, y+dy
            if 0 <= nx < n and 0 <= ny < m and not visited[nx][ny] and grid[nx][ny] != 'X':
                visited[nx][ny] = True
                q.append((nx, ny, dist+1))
    return reachable_rats

# Precompute reachability from each empty cell
coverage = {}
for e in empty:
    coverage[e] = bfs(e)

all_rats = set(rats)
found = False
for i in range(len(empty)):
    for j in range(i+1, len(empty)):
        if coverage[empty[i]] | coverage[empty[j]] == all_rats:
            print(empty[i][0]+1, empty[i][1]+1, empty[j][0]+1, empty[j][1]+1)
            found = True
            break
    if found:
        break

if not found:
    print(-1)
```このコードはまず、すべてのラットと空のセルを識別します。 各空のセルから BFS を実行して、そこにある手榴弾でどのネズミを一掃できるかを決定し、ペアを反復してすべてのネズミを一掃するセルを見つけます。 微妙なポイントとしては、`dist > d`BFS カットオフと結合セットとして、結合されたカバレッジを確認します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
