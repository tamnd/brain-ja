 ## 解決策
 ## 問題の理解

 値のカウントが与えられます`1..k`。 価値`i`正確に表示されなければなりません`a_i`回。 空のセルは許可されており、次のように表されます。`0`。 

すべてのコピーを`n × n`行列化して最小化する`n`。 毎`2 × 2`部分行列は 2 つの条件を満たさなければなりません。 

最初の条件は、その 4 つのセルのうち、最大 3 つが占有される可能性があることを示しています。 毎`2 × 2`ブロックには少なくとも 1 つのゼロが含まれている必要があります。 

2 番目の条件は、各対角線上の 2 つのセルに同じ数値を含めることはできないことを示します。 

入力は複数の数値セットを記述します。 出力は、正確にそれらの数値と任意の数の空のセルを含む正方行列です。 

総データ量は膨大です。 1 つのテストには最大で次のテストを含めることができます。`2 · 10^5`数値と合計`m + k`テストの範囲も次によって制限されます`2 · 10^5`。 すべての値に対して行列全体を繰り返しスキャンするソリューションは、非常に遅すぎます。 総作業量が実際に充填するセルの数に基本的に比例する構造が必要です。 

声明からは危険なケースは明らかではない。 

何度も出現する値について考えてみましょう。```
m = 8
a = [8]
```単純な考えは、十分な数の非ゼロ セルを含む行列を見つけることです。 それだけでは十分ではありません。 数値が等しい場合は、対角線上の競合も回避する必要があります。 最大の周波数により、追加の下限が作成されます。`n`。 

もう 1 つの微妙なケースは、マトリックスがほぼ満杯の場合です。```
m = 15
```あ`4 × 4`マトリックスには 16 個のセルがありますが、`2 × 2`ブロックにはゼロが必要です。 16 個のセルすべてを使用することは不可能です。 建設では十分な空き位置を確保する必要があります。 

3 番目のトラップは、1 つの値を行列の異なる領域に分割することです。 不注意に行うと、同じ値のコピーがいくつかのオブジェクトの両方の対角線上に現れる可能性があります。`2 × 2`ブロック。 最終的な構造は、最大 1 つの値が 2 つの領域間の境界を越え、その値であっても安全なままになるように設計されています。 

## アプローチ

 ブルートフォースの視点は、最小のものを探すことです。`n`、すべてを確認しながら数字を配置してみてください。`2 × 2`ブロック。 何とか直したとしても`n`、最大を割り当てます`2 · 10^5`ローカル制約を常に検証しながら、項目を行列の位置に配置すると、すぐに組み合わせになります。 配置を探索する現実的な方法はありません。 

重要な観察は、局所的な制約が固定された幾何学的パターンを示唆しているということです。 

行インデックスが奇数であるすべてのセルを取得します。 このセットを呼び出します`A`。 

行インデックスが偶数であるすべてのセルを取得します。 このセットを呼び出します`B`。 

任意の対角線`2 × 2`ブロックは常に 1 つのセルを接続します`A`そして1つのセルから`B`。 

数値が完全に内側にある場合`A`、その番号のコピーが対角線上で出会うことはありません。 完全に内側に配置された数値にも同じことが当てはまります`B`。 

これにより、問題は能力の問題に変わります。 1 つのリージョンに保持できるコピー数は何ですか?

 地域`A`含まれています`n * ceil(n / 2)`細胞。 

地域`B`含まれています`n * floor(n / 2)`細胞。 

すべての値が 1 つの領域に限定されている場合、斜めの競合は自動的に解消されます。 

最大の周波数は 1 つの領域内に収まる必要があるため、`max(a_i) ≤ n * ceil(n / 2)`。 

最初の条件では、すべての項目にゼロが必要です。`2 × 2`ブロックは、1 つのチェッカーのようなサブパターンのすべてのセルを空のままにすることで満たされます。 使用可能なセルの最大数は、`n² - floor(n / 2)²`。 

したがって、次のことも必要です`m ≤ n² - floor(n / 2)²`。 

これら 2 つの不等式は、まさに有効な最小サイズを決定するために使用される条件です。 一度そのような`n`が見つかった場合は、値を頻度で並べ替え、最初に大きい領域を埋めます。 両方の領域のセルに強制的に占有される値は最大 1 つです。 この特別な値は慎重に処理されますが、他のすべての値は完全に 1 つの領域内に留まります。 これにより、斜め方向の競合がすべて排除されます。

 ## アルゴリズムのチュートリアル

 1. すべての値を頻度の降順に並べ替えます。 
2. 最小のものを見つける`n`そのような`max(a_i) ≤ n * ceil(n / 2)`そして`m ≤ n² - floor(n / 2)²`。 

最初の不等式は、最も頻度の高い値がより大きな領域内に収まることを保証します。 2 番目の方法では、全体的に十分な使用可能なセルが保証されます。 
3. 領域のすべてのセルを列挙します`A`行優先の順序で。 これらは行です`1, 3, 5, ...`。 
4. しましょう`cap = |A| = n * ceil(n / 2)`。 
5. 値を周波数の降順にたどって、プレフィックスの合計が次を超える最初の値を見つけます。`cap`。 

以前の値はすべて内部に完全に収まります`A`。 

この値が存在する場合、分割する必要があるのはこの値だけです。 
6. 残りの空き位置を埋めます。`A`その分割値のできるだけ多くのコピーを使用します。 
7. 残りの部分を埋め続けます。`A`以前のすべての値を使用します。 
8. 領域のすべてのセルを列挙します`B`同じ順序で。 
9. 分割値の残りのコピーを`B`。 
10. 残りの値をすべて内部に完全に配置します`B`。 
11. マトリックスを出力します。 

### なぜ効果があるのか

 おそらく 1 つを除くすべての値は、単一の領域内に完全に含まれます。 の任意の対角線`2 × 2`ブロックは常に 1 つのセルを接続します`A`そして1つのセルから`B`。 値は 1 つの領域にのみ表示されるため、同じ対角線上に 2 回表示することはできません。 

両方の領域に表示される唯一の値は、分割値です。 そのコピーは、次の 1 つの連続した接尾辞を形成します。`A`および 1 つの連続したプレフィックス`B`。 セルの順序によりコピーが防止されます。`A`そしてコピーを`B`の対角になることから`2 × 2`ブロック。 これはまさに、受け入れられているソリューションで使用されている構造です。 

容量の不平等により、十分な使用可能なセルと、最も頻繁に使用される値を格納するための十分なスペースの両方が保証されます。 すべての数字が配置され、すべてのローカル制限が尊重されるため、マトリックスは美しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        m, k = map(int, input().split())
        arr = list(map(int, input().split()))

        vals = [(arr[i], i + 1) for i in range(k)]
        vals.sort(reverse=True)

        mx = vals[0][0]

        n = 1
        while True:
            if mx <= n * ((n + 1) // 2) and \
               m <= n * n - (n // 2) * (n // 2):
                break
            n += 1

        ans = [[0] * n for _ in range(n)]

        cap = n * ((n + 1) // 2)

        pref = 0
        split = len(vals)

        for i, (cnt, _) in enumerate(vals):
            if pref + cnt > cap:
                split = i
                break
            pref += cnt

        posA = []
        for r in range(0, n, 2):
            for c in range(n):
                posA.append((r, c))

        posB = []
        for r in range(1, n, 2):
            for c in range(n):
                posB.append((r, c))

        ptrA = 0
        ptrB = 0

        remain = 0
        split_id = -1

        if split < len(vals):
            need = cap - pref
            split_cnt, split_id = vals[split]

            for _ in range(need):
                r, c = posA[ptrA]
                ptrA += 1
                ans[r][c] = split_id

            remain = split_cnt - need

        ptrA = 0

        for i in range(split):
            cnt, val = vals[i]
            while cnt:
                if ans[posA[ptrA][0]][posA[ptrA][1]] == 0:
                    r, c = posA[ptrA]
                    ans[r][c] = val
                    cnt -= 1
                ptrA += 1

        if split < len(vals):
            while remain:
                r, c = posB[ptrB]
                ptrB += 1
                ans[r][c] = split_id
                remain -= 1

            for i in range(split + 1, len(vals)):
                cnt, val = vals[i]
                while cnt:
                    r, c = posB[ptrB]
                    ptrB += 1
                    ans[r][c] = val
                    cnt -= 1

        print(n)
        for row in ans:
            print(*row)

solve()
```最初の部分では、最小有効サイズを計算します。 ループは安いので、`n`決して大きくなりません。 マトリックスの辺の長さはおよそ`√m`。 

ソートされた配列が構築の中心です。 大きな周波数が最初に処理されるため、より大きな領域内では最大値が優先されます。 

変数`split`領域を越える可能性のある唯一の値を識別します`A`地域へ`B`。 以前の値はすべて内部に完全に収まります`A`、以降の値はすべて内部に完全に収まります`B`。 

実装の微妙な詳細は、一部のセルが`A`すでに分割値が含まれている可能性があります。 他の値を入力している間、コードは占有位置をスキップします。 このチェックを怠ると、コピーが上書きされ、頻度カウントが壊れてしまいます。 

もう 1 つの簡単な間違いは、行のインデックス付けです。 地域`A`行で構成されます`0, 2, 4, ...`ゼロベースのインデックス付けで、編集上の説明の奇数行に対応します。
