 ## 解決策
 ## 問題の理解

 正の整数の配列が与えられているので、それを Nastia が適切な配列と呼ぶものに変換する必要があります。 良好な配列とは、連続する要素のすべてのペアが互いに素である配列として定義されます。 つまり、すべてのインデックスに対して$i$から$2$に$n$、の最大公約数$a_{i-1}$そして$a_i$等しい必要があります$1$。 許可される操作は、インデックスを選択する 2 つの要素の置換です。$i$そして$j$新しい値を割り当てます$x$そして$y$に$a_i$そして$a_j$、古い値の小さいほうが新しい値の小さいほうと等しいという制限があります。 各操作は 2 つの要素を同時に変更します。実行できるのは最大でも$n$そのような操作。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは、配列と配列自体の長さを提供します。 出力は、実行された操作の数と、その後に各操作の詳細が続きます。 問題によって解決策が存在することが保証されるため、不可能なケースに対処する必要はありません。 

制約は、すべての合計が$n$すべてのテストケースにわたって、$2 \cdot 10^5$。 これは、どのソリューションも大まかに実行する必要があることを意味します。$O(n)$テスト ケースごとに 2 秒の制限内に収まるようにします。 到達可能な配列要素に対する入れ子ループを含むアルゴリズム$O(n^2)$テストケースごとの速度が遅すぎます。 エッジケースには、既に良好な配列、繰り返し番号を含む配列、一定の長さの配列が含まれます。$1$(これは自明のことですが)、すべての数値が偶数であるか、すべての数値が共通の因数を共有する配列です。 グローバル プランを持たずに隣接する要素をチェックして調整するだけの単純なソリューションでは、共素性の条件が注意深く維持されていない場合、多くの操作が必要になったり、無効な置換が生成されたりする可能性があります。 

## アプローチ

 ブルートフォース手法では、配列を左から右にスキャンして、連続する各ペアをチェックしようとします。 ペアが互いに素でない場合は、一方または両方の数値をもう一方の数値と互いに素であるものに置き換えることができます。 これは概念的には機能しますが、操作ルールを尊重しながらどの数値を選択するかを決定するのは複雑になる可能性があります。 操作の数は次のようになります。$n$、各操作では gcd を繰り返し計算する必要がある場合があります。 これは非効率的ですが、小さな配列ではそれでも機能します。 

重要な洞察は、1 つの要素を参照として固定し、その固定要素に関連して配列内の他のすべての要素を 1 つずつ変更することです。 簡単な選択は、配列内の最小の要素をピボットとして選択するか、最初の要素だけを選択することです。 大きな素数と固定要素を交互に使用することで、連続するペアが互いに素であることを保証できます。 置換操作では、小さい方の値を維持する任意の値を割り当てることができるため、連続する各ペアが 1 回のパスで互いに素になるように体系的に番号を割り当てることができます。 これにより、問題は次のような建設的なアルゴリズムに帰着します。$O(n)$動作を保証し、正確性を保証します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | お(1) | n が大きいと遅すぎます |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、配列の長さを特定します。$n$そして配列$a$。 
2. 共部性を固定するための参照インデックスを選択します。 便利な選択は、次の最小要素の位置です。$a$、ただし、固定位置はどれでも機能します。 この要素を次のようにします$m$。 
3. 操作の空のリストを初期化します。 
4. 配列を左から右に繰り返します。 インデックスごとに$i$参照インデックスと等しくない:

 - 新しい値を決定する$x$参照要素の場合と$y$のために$a_i$そのような$gcd(x, y) = 1$そして、古い値の小さい方は、新しい値の小さい方と等しくなります。 単純で建設的な選択は、参照要素を交互に配置することです。$m$大きな素数の場合、$10^9 + 7$、割り当て$m$一方にプライムを、もう一方にプライムを設定します。 
- 操作をタプルとして記録する$(ref_index, i, x, y)$。 
5. すべての要素を処理した後、操作の数と操作の詳細を出力します。 

機能する理由: 維持される不変条件は、各操作の後、参照要素と現在処理されている要素が互いに素であるということです。 各要素は参照に関連して調整されるため、参照または変更された要素を含む連続するペアは共素性条件を満たします。 各要素を 1 回だけ処理するため、合計の操作数は最大で$n - 1$。 必要に応じて常に参照要素または大きな素数を割り当てることができるため、小さい値を保存するという操作規則が満たされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import gcd

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # Find the minimal element and its index
        min_val = min(a)
        min_idx = a.index(min_val)
        
        operations = []
        # Use a large prime to pair with min_val
        large_prime = 10**9 + 7
        
        for i in range(n):
            if i == min_idx:
                continue
            if (i - min_idx) % 2 == 0:
                operations.append((min_idx + 1, i + 1, min_val, large_prime))
            else:
                operations.append((min_idx + 1, i + 1, min_val, min_val + 1))
        
        print(len(operations))
        for op in operations:
            print(*op)

if __name__ == "__main__":
    solve()
```コードは最初にテスト ケースの数を読み取ります。 各配列について、共素性のピボットとして機能する最小の要素を見つけます。 他の要素を反復処理し、置換ルールを満たしながら gcd が 1 に等しいことを保証する値を使用した操作を生成します。 の使用`min_val`古い値と新しい値の最小値が一致することを保証し、大きな数値を交互に使用することで gcd の競合を回避します。
