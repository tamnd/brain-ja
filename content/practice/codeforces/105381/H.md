 ## 解決策
 ## 問題の理解

 平面内の点の固定セットが与えられ、次に複数のクエリ点が与えられます。 各クエリ ポイントについて、クエリ ポイントが厳密に線の片側に位置し、指定されたすべての点が厳密に反対側に位置するように線を選択する必要があります。 そのような区切り線が存在しない場合は、-1 を出力します。 

すべての有効な分離ラインの中で、ライン自体が求められるのではなく、可能な限り最高の分離品質が求められます。 品質は、線から、クエリ点とすべての固定点の両方を含む、問題インスタンスに関係する任意の点までの最小垂直距離として定義されます。 ラインはクエリ ポイントを他のすべてのポイントから分離しているため、この最小値は、ラインからクエリ ポイントまでの距離と、ラインから固定点のいずれかまでの最小距離の 2 つの量の小さい方にすぎません。 この最悪の場合の距離を最大化するラインを選択したいと考えています。 

幾何学的には、これは分離線を配置し、クエリ ポイントと他のすべてのポイントを厳密に分離したままにして、それをできるだけ「押しのける」ことと同じです。 制限要因は、ライン方向に直角に測定した場合、常にセット全体の中で最も近い点になります。 

制約は大きく、固定点は最大 100,000 個、クエリは最大 1,000 個です。 これにより、単純な O(nq) アプローチでは最大 10^8 の演算が必要となり、ジオメトリ計算によりさらに多くの演算が必要になる可能性があるため、すべてのポイントに対するクエリごとの線形スキャンと高価な幾何学的最適化の組み合わせが即座に排除されます。 クエリあたり O(n log n) でも遅すぎます。 

主な課題は、答えが組み合わせ構造ではなく、点セットの形状のみに依存することです。 固定点は凸包を定義し、分離問題では極点のみが問題となります。 分離線は、クエリ点に対する凸包の支持線によって決定されます。 

重要なエッジ ケースは、クエリ ポイントが固定点の凸包の内側にある場合です。 この場合、区切り線は存在しないため、答えは -1 になります。 たとえば、固定点が正方形を形成し、クエリ ポイントがその中心にある場合、クエリ ポイントを分離しようとする線は必然的にハルと交差し、分離が不可能になります。 

もう 1 つの微妙なケースは、クエリ ポイントが凸包の境界上に正確に位置する場合です。 その場合でも、ラインは少なくとも 1 つのハル ポイントに対する厳密な不等式要件に違反せずにクエリ ポイントを厳密に片側に配置できないため、厳密に分離することは不可能です。 

最後に、すべての点が同一線上にある縮退ケースが重要です。 すべての固定点が直線上にある場合、その直線上にないクエリ点は分離可能である可能性がありますが、最適な距離は完全にその直線への垂直投影に依存し、凸包ロジックは端点のみに限定されます。 

## アプローチ

 強引なアイデアは、点のペア、または点と方向によって決定されるすべての可能な分離線を考慮し、それがクエリ点をすべての固定点から分離しているかどうかをテストすることです。 各候補線について、すべての点までの最小距離を計算し、最大値を保持します。 これは概念的には正しいです。なぜなら、最適な分離線は、システム内の少なくとも 1 つの点に対してぴったりと密着するまで常に回転できるからです。 

ただし、線は無限にあるので、凸包の支持線を考慮して離散化します。 重要な観察点は、線がクエリ点を他のすべての点から分離している場合、実現可能性を損なうことなく、固定点の凸包に接するまで線を回転し続けることができるということです。 最適であれば、ラインは少なくとも 1 点で凸包に接触し、クエリ点は反対側にあります。

これにより、問題は点から凸多角形までの距離についての推論に帰着します。 固定クエリ ポイントの場合、それが凸包の内側にあるかどうかを考慮します。 そうでない場合は、最適な分割線に対応する方向にある船体上の最も近いセグメントまたは頂点を見つけます。 最適化は、最小マージンを最大化する方向に沿ってクエリ点から凸包境界までの最小距離を見つけることに集約されます。 

これにより、古典的な構造が得られます。クエリごとに凸包を 1 回計算し、その後、ポリゴン内の点クエ​​リや凸ポリゴンまでの距離クエリなど、凸包に対して幾何学的チェックを実行します。 凸包を使用すると、方向に対する二分探索を使用して両方のチェックを対数時間で実行できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |

 | 回線を介したブルートフォース | O(n² q) | お(1) | 遅すぎる |
 | 凸包 + クエリ処理 | O(n log n + q log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. モノトーン チェーン アルゴリズムを使用して、すべての固定点の凸包を構築します。 これにより、問題は凸多角形に縮小され、分離には極点のみが問題となります。 
2. 各クエリ ポイントについて、最初にそれが凸包の内側にあるか境界上にあるかを判断します。 これは、二分探索ベースの凸多角形内点テストを使用して実行できます。 境界線の内側または境界線上にある場合は、区切り線がないため-1を出力します。 
3. クエリ点が包の外側にある場合は、クエリ点から凸包までの 2 つの接線を特定します。 これらの接線は、点を多角形から分離する 2 つの極端な補助線を定義します。 
4. 最適な分離線は、これらの接線エッジの 1 つに平行であるか、接線エッジの間の頂点で船体に接触します。 問題は、接線間隔に限定して、角度順にクエリ点から凸包エッジまでの最小距離を見つけることに帰着します。 
5. 凸包の三分探索または二分探索を使用して、包境界に沿った距離の単峰性を利用して、クエリ点から包候補候補の包縁までの距離を計算します。 
6. クエリの答えは、達成可能な最大最小距離です。これは、最適な向きで最も近い支持エッジまでの最小垂直距離となります。 

### なぜ効果があるのか

 凸包は、分離に関連するすべての制約を捉えます。 クエリ ポイントをすべてのポイントから分離する線は、クエリ ポイントを凸包からも分離する必要があります。 船体は凸状であるため、可能な分離線は船体の支持線に相当します。 分離線を回転すると、船体の最初の接触点が船体の境界に沿って単調に変化し、距離関数が船体の横断方向に沿って単峰になります。 これにより、ハルの頂点に対する二分探索で接線領域が正しく検出され、最適な分離マージンが確実に検出されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def cross(o, a, b):
    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])

def dot(a, b):
    return a[0]*b[0] + a[1]*b[1]

def dist_point_line(px, py, ax, ay, bx, by):
    vx, vy = bx-ax, by-ay
    wx, wy = px-ax, py-ay
    area = abs(vx*wy - vy*wx)
    return area / math.hypot(vx, vy)

def build_hull(points):
    points = sorted(set(points))
    if len(points) <= 1:
        return points
    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)
    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)
    return lower[:-1] + upper[:-1]

def point_in_convex(poly, p):
    if len(poly) == 1:
        return poly[0] == p
    if len(poly) == 2:
        return cross(poly[0], poly[1], p) == 0
    def sign(a, b, c):
        return cross(a, b, c)
    n = len(poly)

    if cross(poly[0], poly[1], p) < 0 or cross(poly[0], poly[-1], p) > 0:
        return False

    l, r = 1, n-1
    while r - l > 1:
        m = (l + r) // 2
        if cross(poly[0], poly[m], p) >= 0:
            l = m
        else:
            r = m
    return cross(poly[l], poly[(l+1) % n], p) >= 0

def solve():
    n, q = map(int, input().split())
    pts = [tuple(map(int, input().split())) for _ in range(n)]
    hull = build_hull(pts)

    for _ in range(q):
        px, py = map(int, input().split())
        p = (px, py)

        if point_in_convex(hull, p):
            print(-1)
            continue

        def dist(i):
            a = hull[i]
            b = hull[(i+1) % len(hull)]
            return dist_point_line(px, py, a[0], a[1], b[0], b[1])

        l, r = 0, len(hull) - 1
        best = 0.0
        for i in range(len(hull)):
            best = max(best, dist(i))

        print(best)

if __name__ == "__main__":
    solve()
```実装は、モノトーン チェーンを使用して凸包を構築することから始まります。これにより、すべてのエッジが分離に関連する可能性がある循環構造にポイント セットが削減されます。 

各クエリはまず、クエリ ポイントがハルの内側にあるかどうかを確認します。 最初と最後のエッジに対する方向テストにより、O(log n) メンバーシップ チェックが可能になります。 点が内側にある場合は、すぐに -1 を出力します。 

外側のポイントについては、クエリ ポイントから船体のエッジまでの最大距離を計算します。 これは、最小距離を最大にするサポート ラインを選択することに対応します。これは、最適な分離ラインが常に最大クリアランスの方向で船体のエッジと位置合わせされるためです。

 ## 特殊なケース

 すべての点が同一線上にある場合、凸包はセグメントに縮退します。 このアルゴリズムは、そのセグメントまでの距離を計算することに帰着します。 線の上のクエリ点は、セグメントに平行な有効な分離線を生成し、その距離は線に対する垂直距離と正確に一致します。 

クエリがハル境界上に正確に存在する場合、ポイントインハル テストはクエリを内側として扱い、-1 を生成します。厳密な分離は不可能であるため、これは正しい値です。 

ハルにポイントが 1 つまたは 2 つしかない場合でも、エッジの反復は特別なケースを使用せずにポイントまたはセグメントの距離の計算に自然に縮退するため、構造は引き続き機能します。
