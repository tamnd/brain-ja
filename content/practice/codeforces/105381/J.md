 ## 解決策
 ## 問題の理解

 2 つの文字列、つまり長いテキストが与えられます。`s`そしてパターン`t`。 すべての開始位置をスキャンします`s`どこ`t`フィットする可能性があります。 トニーのアルゴリズムは、そのような位置ごとに、部分文字列が以下に等しいかどうかを判断しようとします。`t`ただし、すべての文字をチェックする代わりに、`k`ランダムなプローブ。 各プローブは内部のランダムなインデックスを選択します`t`内の対応する文字を比較します。`s`そして`t`。 すべてのプローブがたまたま一致する位置にのみ到達した場合、アルゴリズムはその部分文字列を一致として受け入れます。 

出力は、どの位置が一致したかに関するものではありません。 代わりに、このランダム化された手順が文字列内のどこにも誤検知を生成しない、つまり一致しない部分文字列を誤って一致として報告しない確率を計算する必要があります。 

文字列には最初の 8 文字のみが使用され、合計の長さは最大 200,000 文字になります。 これにより、位置ごとの二次比較が即座に排除されます。 定数が大きい位置ごとの線形であっても危険です。 ほぼ線形の前処理とシフトごとの一定時間の評価が必要です。 

微妙なエッジ ケースは、パターンと 1 つの位置だけが異なる部分文字列から発生します。 このような場合、アルゴリズムは、異なるインデックスをサンプリングする頻度に応じて確率の不一致を見逃す可能性があるため、特に脆弱です。 

2 番目のエッジ ケースは、部分文字列がパターンと完全に異なる場合です。 その場合、すべてのランダム プローブは直ちに不一致を検出するため、これらの位置は実際には安全であり、確率 1 に寄与します。 

## アプローチ

 直接シミュレーションでは、すべての位置を反復処理します。`s`、それぞれについてシミュレートします`k`ランダムチェック。 それだけではすでに遅すぎるので、`k`最大10億にもなる可能性があります。 シミュレーションに上限を設けたとしても、ランダム性により、正確な確率を推論することは不可能になります。 

重要な観察点は、それぞれの位置が`i`正しさに関して独立して動作します。 このアルゴリズムは、少なくとも 1 つの一致しない部分文字列が誤って受け入れられた場合にのみ失敗します。 したがって、シフトごとに計算します`i`、このシフトが偽陽性ではない確率を計算し、これらの確率を掛け合わせます。 

固定シフトの場合、次のように定義します。`d_i`位置の数として`s[i + j] != t[j]`。 1 回のランダム プローブ中に、アルゴリズムがインデックスを選択します`r`パターンの長さから均一に。 これらのいずれかを選択すると、エラーが正確に検出されます。`d_i`位置が合わない。 したがって、単一のプローブでは確率の不一致を検出できません`(m - d_i) / m`、 どこ`m = |t|`。 後`k`独立したプローブであっても、アルゴリズムが依然として不一致の検出に失敗する確率は、`((m - d_i) / m)^k`。 これはまさに、次の場合のシフトの偽陽性確率です。`d_i > 0`。 

したがって、残りのタスクはすべてを計算することです`d_i`効率的に。 これは古典的なパターン マッチングの再定式化です。シフトごとに、シフト間で一致するポジションの数を計算します。`s`そして`t`。 アルファベットのサイズは 8 しかないため、8 つのバイナリ インジケーター配列を構築し、畳み込みを使用して相関を計算します。 シフト時の試合数`i`は整列された一致の文字の合計であり、不一致が直接続きます。 

全部揃ったら`d_i`、貢献度を掛け合わせます。 

のために`d_i = 0`の場合、部分文字列は真に等しいため、係数 1 に寄与します。 

のために`d_i > 0`、掛け算します`(1 - ((m - d_i)/m)^k)`。 

これにより、問題は畳み込みと位置ごとのべき乗剰余計算に変わります。

 ## アルゴリズムのチュートリアル

 1. コンピューティング`m = |t|`そして`n = |s|`。 すべてのシフトを評価します`i`から`0`に`n - m`。 
2. キャラクターごとに`c`から`'a'`に`'h'`、出現箇所をマークするバイナリ配列を構築します。`s`そして`t`。 片側を反転して、畳み込みによりシフト比較の位置を揃えます。 
3. 各文字に対して畳み込みを実行します。 これにより、シフトごとに`i`、その文字に一致する位置の数。 すべての文字を合計すると、`match[i]`。 
4. コンピューティング`d_i = m - match[i]`。 これは、次の間で一致しない位置の数です。`t`で始まる部分文字列`i`。 
5. 事前計算`inv_m = m^{-1} mod MOD`。 計算もする`inv_m_k = inv_m^k mod MOD`、すべてのシフトで共有されるためです。 
6. 各シフトについて、`d_i > 0`、次を計算します。`base = m - d_i`

`p_i = (base^k mod MOD) * inv_m_k mod MOD`これは、アルゴリズムが不一致の検出に失敗する確率です。 
7. 答えを乗算します`(1 - p_i)`このようなすべてのシフトに対する modulo MOD。 

### なぜ効果があるのか

 アルゴリズムのランダム性は各位置にローカルであり、異なる開始インデックス間で相互作用しないため、各シフトは独立して動作します。 固定シフトの場合、間違った出力を生成する唯一の方法は、すべての不一致インデックスをすべてサンプリングしないようにすることです。`k`試練。 その出来事の確率は以下にのみ依存します`d_i`、他のポジションではありません。 正確性を確保するには、一致しないすべてのシフトで失敗を回避する必要があるため、最終的な確率は、独立したシフトごとの成功確率の積になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def ntt_convolution(a, b):
    # iterative NTT for 998244353
    def bitrev(a):
        n = len(a)
        j = 0
        for i in range(1, n):
            bit = n >> 1
            while j & bit:
                j ^= bit
                bit >>= 1
            j ^= bit
            if i < j:
                a[i], a[j] = a[j], a[i]

    def ntt(a, invert):
        n = len(a)
        bitrev(a)
        length = 2
        while length <= n:
            wlen = pow(3, (MOD - 1) // length, MOD)
            if invert:
                wlen = pow(wlen, MOD - 2, MOD)
            i = 0
            while i < n:
                w = 1
                for j in range(i, i + length // 2):
                    u = a[j]
                    v = a[j + length // 2] * w % MOD
                    a[j] = (u + v) % MOD
                    a[j + length // 2] = (u - v) % MOD
                    w = w * wlen % MOD
                i += length
            length <<= 1
        if invert:
            inv_n = pow(n, MOD - 2, MOD)
            for i in range(n):
                a[i] = a[i] * inv_n % MOD

    n = 1
    while n < len(a) + len(b):
        n <<= 1
    fa = a + [0] * (n - len(a))
    fb = b + [0] * (n - len(b))

    ntt(fa, False)
    ntt(fb, False)
    for i in range(n):
        fa[i] = fa[i] * fb[i] % MOD
    ntt(fa, True)
    return fa

s = input().strip()
t = input().strip()
k = int(input())

n, m = len(s), len(t)

if m > n:
    print(1)
    sys.exit()

match = [0] * (n - m + 1)

for c in range(8):
    ch = chr(ord('a') + c)
    A = [0] * n
    B = [0] * m
    for i in range(n):
        if s[i] == ch:
            A[i] = 1
    for i in range(m):
        if t[i] == ch:
            B[m - 1 - i] = 1

    conv = ntt_convolution(A, B)
    for i in range(n - m + 1):
        match[i] += conv[i + m - 1]

inv_m = pow(m, MOD - 2, MOD)
inv_m_k = pow(inv_m, k, MOD)

ans = 1

for i in range(n - m + 1):
    d = m - match[i]
    if d == 0:
        continue
    base = m - d
    p = pow(base, k, MOD) * inv_m_k % MOD
    ans = ans * (1 - p) % MOD

print(ans % MOD)
```畳み込みステップでは、シフトごとのオーバーラップ カウントが構築されます。 パターン配列を反転すると、畳み込みインデックスが確実に整列し、各出力位置がパターン配列間の特定の整列に対応するようになります。`s`そして`t`。 確率の計算は不一致数から直接行われます。 

べき乗モジュラー`pow(base, k, MOD)`シフトごとに確率が の乗になるため、 が必要です。`k`独立した試験。 

## 実用的な例

 元のサンプルは完全に指定されていないため、2 つの例を考えてみましょう。 

まず、`s = "abca"`そして`t = "bc"`、 と`k = 1`。 

シフト 0 では、部分文字列は次のようになります。`"ab"`、不一致数は 2 です。不一致の検出に失敗する確率は、`(0/2)^1 = 0`なので貢献度は1です。 

シフト 1 では、部分文字列は次のようになります。`"bc"`、不一致数は 0 なので、1 が寄与します。 

シフト 2 では、部分文字列は次のようになります。`"ca"`、不一致数は 2 で、再び 1 に寄与します。 

| シフト | 部分文字列 | 不一致 d | p_i | 係数 |
 | --- | --- | --- | --- | --- |
 | 0 | アブ | 2 | 0 | 1 |
 | 1 | 紀元前 | 0 | - | 1 |
 | 2 | ca | 2 | 0 | 1 |

 最終的な答えは 1 です。 

2番目に、取る`s = "aaa"`そして`t = "aa"`、`k = 2`。 

シフト 0 と 1 はどちらも完全一致であるため、どちらからも寄与されません。 すべての位置合わせは確率 1 で正しく、同一の重複によってランダム性が導入されないことが確認されます。 

これらの例は、ランダム性が問題となるのは不一致が存在する場合のみであり、その場合でも位置ではなく数によってのみ問題になることがわかります。

 ## 特殊なケース

 いつ`s`そして`t`は同一であり、すべてのシフトは`d_i = 0`なので、確率的な失敗項は導入されません。 すべての部分文字列が真に一致し、拒否または誤分類できないため、アルゴリズムは確率 1 を正しく出力します。 

いつ`t`が 1 文字の場合、すべての不一致は試行ごとに確率 1 で即座に検出されます。 これにより、すべての不等シフトが係数 1 に寄与します。`(0/1)^k = 0`そしてやはり最終製品は安定したままになります。 

部分文字列がすべての位置で異なる場合、`t`、 我々は持っています`d_i = m`、 それで`base = 0`係数は 1 になります。これは、完全に無関係な部分文字列がエラーを引き起こす可能性がないことを意味し、すべてのプローブが常に不一致を即座に検出するという直観と一致します。
