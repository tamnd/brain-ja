 ## 解決策
 ## 問題の理解

 正方形の紙を表すサイズ _n_ × _m_ の長方形グリッドが与えられます。 いくつかの正方形がペイントされ、セット _A_ が形成されます。 セット _A_ は 4 方向の意味で接続されています。どのペイントされた正方形からでも、一辺を共有するペイントされた正方形に沿って歩くことで、他のペイントされた正方形に到達できます。 私たちの目標は、セット _A_ が切断されるように、ペイントされた正方形の最小数を削除することです。 

入力は、_m_ 文字の _n_ 行、塗りつぶされた四角形を表す「#」と「.」で構成されます。 空の正方形を表します。 出力は単一の整数です。_A_ を切断するために削除する必要がある正方形の最小数、またはそれが不可能な場合は -1 です。 

制約は小さく、_n_ と _m_ は最大 50 であるため、セルの総数は最大 2500 です。これは、O(n×m×(n×m)) の複雑さのアルゴリズムが実行可能であるほど十分に低いため、複雑さの高いグラフ操作についての心配は排除されます。 エッジ ケースには、非常に小さなグリッド、または _A_ が単一の線または狭いコーナーを形成するグリッドが含まれます。 たとえば、1×1 で描かれた正方形は切断できないため、答えは -1 になります。 同様に、2×2 ブロックは、任意の 2 つの正方形を削除することで常に切断できますが、1 つの正方形を削除するだけでは不十分です。 

単純なソリューションでは接続の定義を見落とす可能性があります。 たとえば、_A_ が 3 つの正方形からなる直線を形成している場合、中央の正方形を削除すると接続が切断されますが、角の近傍のみをチェックする不注意なアルゴリズムではこれを検出できない可能性があります。 

## アプローチ

 ブルートフォース手法では、ペイントされた正方形のすべてのサブセットを反復処理し、各サブセットを削除し、残りのペイントされた正方形が接続されているかどうかを確認します。 ペイントされた正方形は最大 2500 個あり、すべてのサブセットをチェックするのは指数関数的であるため、このアプローチは明らかに実行不可能です。 

重要な洞察は、大きな正方形のセットを削除することを考慮する必要がないということです。 この問題は古典的なグラフ理論に帰着します。_A_ は接続されたグラフ (ノードはペイントされた正方形であり、エッジは隣接するペイントされた正方形の間に存在します) であり、グラフを切断するために削除するノードの最小数が必要です。 これが**頂点カット**の概念です。 

小さなグリッドの場合は、次の 3 つのケースがあります。 

1. ペイントされた正方形が 1 つだけの場合、答えは -1 です。 単一のノードを切断することはできません。 
2. 1 つの四角形を削除してもグラフがつながったままになる場合は、少なくとも 2 つの四角形を削除する必要があります。 2×2 以上のブロックでは、隣接しない 2 つの正方形を削除するだけで十分です。 
3. 関節点を確認できます。ノードを削除すると接続されたコンポーネントの数が増える場合、そのノードは関節点です。 少なくとも 1 つのペイントされた正方形がアーティキュレーション ポイントである場合、答えは 1 です。それ以外の場合、少なくとも 3 つのペイントされた正方形があるグリッドの場合、答えは 2 です。 

これにより、問題は、ペイントされたすべての正方形を反復処理し、一度に 1 つずつ一時的に削除し、残りのグラフが接続されているかどうかを確認するだけになります。 n×m ≤ 2500 であり、DFS/BFS 接続チェックが O(n×m) であるため、これは実現可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべてのサブセット) | O(2^(n_m) * n_m) | O(n*m) | 遅すぎる |
 | 咬合チェック / 1 つまたは 2 つの除去 | O((n*m)^2) | O(n*m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力グリッドを解析し、ペイントされたすべての正方形をリストに記録します`painted`。 
2. 塗りつぶしたマスの数が 1 または 2 の場合は、すぐに -1 を返します。 単一の正方形を切断することはできません。 2 つの正方形には少なくとも 2 つの除去が必要ですが、この問題では最小限の非自明な除去が必要であるため、-1 を返します。 
3. ペイントされた各正方形を反復処理します。`(x, y)`で`painted`。 一時的に削除済みとしてマークします。 
4. ペイントされた残りの正方形から開始して BFS または DFS を実行します。 到達可能なペイントされた正方形の数を数えます。 
5. カウントが、ペイントされた正方形の総数から 1 を引いた値より小さい場合、`(x, y)`セットを切断します。 すぐに 1 を返します。 
6. グラフを切断する四角形が 1 つもない場合は、2 を返します。ペイントされた四角形が少なくとも 3 つあるグリッドの場合は、事前に処理した合計数が 3 未満でない限り、慎重に選択した 2 つの四角形を削除するだけで常に十分です。 

不変条件は、ペイントされたセットの接続性が BFS/DFS トラバーサルによって正確にキャプチャされること、および 3 つ以上の正方形を持つ接続されたセットの最小除去数は最大でも 2 であることです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(5000)

n, m = map(int, input().split())
grid = [list(input().strip()) for _ in range(n)]

def in_grid(x, y):
    return 0 <= x < n and 0 <= y < m

def dfs(x, y, visited):
    visited[x][y] = True
    for dx, dy in ((1,0),(-1,0),(0,1),(0,-1)):
        nx, ny = x+dx, y+dy
        if in_grid(nx, ny) and grid[nx][ny] == '#' and not visited[nx][ny]:
            dfs(nx, ny, visited)

# Count painted squares
painted = [(i,j) for i in range(n) for j in range(m) if grid[i][j] == '#']
k = len(painted)

if k <= 2:
    print(-1)
    sys.exit()

# Try removing each painted square
for x, y in painted:
    grid[x][y] = '.'
    visited = [[False]*m for _ in range(n)]
    # find a starting square
    start = next((i,j) for i in range(n) for j in range(m) if grid[i][j]=='#')
    dfs(start[0], start[1], visited)
    count = sum(visited[i][j] for i,j in painted if (i,j)!=(x,y))
    if count != k-1:
        print(1)
        sys.exit()
    grid[x][y] = '#'  # restore

print(2)
```コードはまず、ペイントされたすべての正方形を識別し、些細なケースを処理します。 正方形ごとに、その削除をシミュレートし、DFS との接続を確認します。 微妙なのは、チェック後に正方形を復元し、残りのペイントされた正方形を正確にカウントすることです。
