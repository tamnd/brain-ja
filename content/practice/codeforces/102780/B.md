 ## 解決策
 ## 問題の理解

 この回路は、いくつかの同一の未知の抵抗から構築されています。 各ステージには並列接続された 1 つの既知の抵抗と 1 つの謎の抵抗が含まれており、すべてのステージが直列に接続されます。 入力により、段数、回路全体の合計抵抗、および各段の既知の抵抗値が得られます。 任務は、謎の抵抗器の抵抗を回復することです。 

未知の抵抗がある場合`x`、既知の抵抗を持つ単一ステージの寄与`ri`は$$\frac{ri \cdot x}{ri + x}$$2つの抵抗が並列に接続されているためです。 合計回路抵抗は、すべてのステージにわたるこれらの値の合計であるため、次の値を見つける必要があります。`x`そのような$$\sum_{i=1}^{k}\frac{r_i x}{r_i+x}=R$$ステージの数は 1000 に達する可能性があり、既知の各抵抗は大きくなる可能性があります。 これにより、多くの可能な抵抗値を試したり、多くの項を使用してシンボリック方程式を解く方法が除外されます。 便利な特性は、必要な精度が次のとおりであることです。`10^-6`したがって、約 60 ～ 100 回の反復を伴う反復数値法は、十分に高速です。 解決策`O(k log precision)`この操作は、反復ごとに最大 1000 個の値の単純な合計のみを実行するため、快適にフィットします。 

いくつかのケースでは、不注意な実装が壊れる可能性があります。 よくある間違いは、答えが常に既知の最大の抵抗に近いと仮定することです。 たとえば、入力の場合```
1 5
10
```正しい出力は`10.000000`、唯一のステージに抵抗があるため$$\frac{10x}{10+x}=5$$それは与える`x=10`。 次のような固定された上限`100000`考えられるより大きな答えでは失敗します。 

もう 1 つの問題は、二分探索の停止が早すぎることです。 と```
3 11
3 12 30
```答えは`6.000000`。 数回反復すると、近似値に見えるものの、必要な精度を満たさない近似値が見つかる可能性があります。 関数はスムーズに変更されるため、多くの反復処理が安価になり、この問題が回避されます。 

3 番目のエッジ ケースは、ターゲットが既知の抵抗の合計のちょうど半分である場合です。 例えば、```
2 10
10 10
```答えがあります`10`、各並列ペアが寄与するため、`5`。 アルゴリズムは、検索間隔が単に小さくなったときに停止するのではなく、上限がこの値に到達できるようにする必要があります。 

## アプローチ

 直接的なアプローチは、謎の抵抗器の可能な値を試し、その結果の合計抵抗を計算することです。 抵抗は連続値であるため、すべての候補を正確に列挙することはできず、細かいグリッドを単純にスキャンすると膨大な数のチェックが必要になります。 たとえ範囲が 100 万の可能な値に制限され、すべてのチェックにかかる時間はわずかであったとしても、`k`最悪の場合、すでに約 10 億回の操作が必要になります。`k=1000`。 

有益な観察は、合計抵抗が未知の抵抗の単調関数であるということです。 いつ`x`個々の並列抵抗が増加します$$\frac{r_i x}{r_i+x}$$も増えます。 これは、答えが 1 つだけ存在し、次の値に対して二分探索を使用できることを意味します。`x`。 

ブルート フォース アプローチは、候補値の評価が簡単であるため機能しますが、値を 1 つずつ試して十分に正確な候補を見つけるにはコストがかかりすぎるため、失敗します。 未知の抵抗と最終的な回路抵抗の間の単調な関係により、反復ごとに探索空間の半分を破棄できます。 

検索間隔はゼロから開始できます。 上限は、計算された抵抗が少なくとも 2 倍になるまで繰り返し 2 倍にすることで動的に求められます。`R`。 可能な最大回路抵抗は既知のすべての抵抗の合計に近づき、ステートメントはターゲットがこの値の半分を超えないことを保証するため、必要な答えが存在することが保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k * 試行された値の数) | お(1) | 遅すぎる |
 | 最適 | O(k 対数精度) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 既知の抵抗を保存し、選択した未知の抵抗値の合計回路抵抗を計算する関数を定義します。`x`。 この関数は各段の並列抵抗を加算し、未知の抵抗が存在する場合に回路が持つであろう抵抗を与えます。`x`。 
2. 以下の下限から開始します。`0`そして上限`1`。 計算された抵抗が少なくとも目標値になるまで、上限を 2 倍にして増やします。`R`。 これにより、未知の抵抗のサイズについての仮定を必要とせずに、実際の答えを含む区間が作成されます。 
3. この間隔で二分探索を繰り返します。 中間の値をとり、それによって生じる回路抵抗を計算します。 結果がより小さい場合`R`、未知の抵抗器の方が大きいはずなので、下限を上方に移動します。 それ以外の場合、未知の抵抗はこの値以下になるため、上限を下方に移動します。 
4. 十分な反復を実行して、間隔を必要な誤差よりも大幅に小さくします。 間隔は毎回半分に縮むため、約 100 回の反復で十分です。 
5. 最終的な中点を謎の抵抗の推定値として出力します。 

これが機能する理由: 計算された合計抵抗は、未知の抵抗に対して厳密に増加しています。 すべての二分探索の決定はこの順序に基づいているため、中間点が生成する抵抗が小さすぎる場合、それより小さい値もすべて無効になります。 抵抗値が大きすぎる場合は、それ以上の値も無効になります。 探索区間には常に真の答えが含まれており、半減を繰り返すことで区間はその答えに収束します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    k, R = map(int, input().split())
    r = list(map(int, input().split()))

    def calc(x):
        total = 0.0
        for v in r:
            total += v * x / (v + x)
        return total

    lo = 0.0
    hi = 1.0

    while calc(hi) < R:
        hi *= 2.0

    for _ in range(100):
        mid = (lo + hi) / 2.0
        if calc(mid) < R:
            lo = mid
        else:
            hi = mid

    print("{:.10f}".format((lo + hi) / 2.0))

if __name__ == "__main__":
    solve()
```の`calc`関数は、候補となる未知の抵抗値の電気式を直接実装します。 答えは必ずしも整数である必要はなく、必要な精度は 10 進数であるため、浮動小数点演算が使用されます。 

上限検索は固定ではなく動的です。 これにより、推測された最大の答えに依存することがなくなり、未知の抵抗が既知のすべての抵抗よりも大きい場合に対処できます。 必要な答えの範囲は入力制約によって制限されるため、2 倍化はすぐに終了します。 

二分探索は、イプシロン条件をチェックする代わりに、固定回数の反復で実行されます。 これにより、正確なコーナーケースが回避され、保証された量の収縮が得られます。 100 回反復すると、必要な精度をはるかに上回る精度が得られます。`10^-6`。 

最大の中間値は十分に小さく、最終的な答えには小数点以下 6 桁だけが必要なため、ここでは Python 浮動小数点値で十分です。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(k 対数精度) | 約 100 回の反復ごとに、すべての項目が評価されます。`k`ステージ 1 回 |

## テストケース```python
import sys
import io

def solve(inp):
    data = inp.strip().split()
    k = int(data[0])
    R = int(data[1])
    r = list(map(int, data[2:]))

    def calc(x):
        s = 0.0
        for v in r:
            s += v * x / (v + x)
        return s

    lo = 0.0
    hi = 1.0
    while calc(hi) < R:
        hi *= 2.0

    for _ in range(100):
        mid = (lo + hi) / 2
        if calc(mid) < R:
            lo = mid
        else:
            hi = mid

    return "{:.6f}".format((lo + hi) / 2)

 ## 特殊なケース

 1段の場合```
1 5
10
```検索されている関数は$$f(x)=\frac{10x}{10+x}$$二分探索は狭い範囲から始まり、関数が少なくとも次の範囲に達するまで上限を拡張します。`5`、そして次に収束します`x=10`。 複数のステージがあるかどうかは関係ありません。 

正確な境界の場合```
2 10
10 10
```既知の抵抗の合計は`20`、目標はちょうどその半分です。 正しい答えは、`10`。 で`x=10`、各ステージが貢献します$$\frac{10\cdot10}{10+10}=5$$したがって、合計は`10`。 動的な上限により、この値を含む検索が可能になります。 

すべての抵抗が等しい場合、```
3 3
3 3 3
```答えは`1`。 各段階が貢献します$$\frac{3\cdot1}{3+1}=0.75$$そして合計は`2.25`したがって、アルゴリズムは正確に与える値が見つかるまで検索を続けます。`3`。 単調チェックでは、特別な場合を除いて繰り返し値が処理されます。 

最大値については、```
4 100000
100000 100000 100000 100000
```未知の抵抗は`100000`。 最初の上限は小さすぎますが、2 倍にするとすぐに答えが含まれる範囲に達します。 その後、検索は小規模な場合と同じように機能し、動的上限がハードコードされた制限よりも安全である理由がわかります。
