 ## 解決策
 ## 問題の理解

 与えられた正の整数を、最大 5 つの整数立方体の合計として記述する必要があります。 入力数値は非常に大きくなる可能性があり、最大で$10^{100000}$, そのため、通常の整数型には適合しません。 出力は、立方体の合計が入力となる最大 5 つの整数のリスト、または`-1`そのような表現が見つからない場合。 

数字の大きさによってアプローチ全体が変わります。 入力を保存するだけでも既に 100,000 桁の 10 進数が必要なため、可能な立方根を線形スキャンすることは不可能です。 アルゴリズムは大きな整数を処理し、少数の算術演算のみを使用する必要があります。 Python に組み込まれた任意精度の整数は、演算自体のコストに比べて演算数が少ないため、ここでは適しています。 

よくある間違いは、小さな立方根を検索しようとすることです。 たとえば、入力の場合`1000000000000`、数値の立方根までの立方体をチェックすることは、通常のサイズの整数に対してのみ機能しますが、ここでは入力の長さによりそのような列挙は無意味になります。 もう 1 つの間違いは、正の立方体のみが有用であると想定していることです。 マイナス キューブは、大きな期間のキャンセルを可能にするため、不可欠です。 

主なエッジ ケースは、小さい値と、その剰余が異常な値です。 入力用`1`、正解は 1 つの立方体です、`1^3`。 剰余を処理する前に常に大きな構成を減算するメソッドでは、誤って不要な負の値が作成されたり、小さな数値で失敗したりする可能性があります。 入力用`5`、答えは 5 部になります。`1`一方、6 で割ることのみに基づいた構築では、残りの剰余も正しく処理する必要があります。 

## アプローチ

 ブルート フォース アプローチでは、数値の立方根に近い 5 つの整数を見つけて、考えられるすべての組み合わせをテストしようとします。 これは正しいです。なぜなら、考えられるすべてのタプルをチェックすると、最終的に表現が存在する場合にそれが見つかるからです。 問題は可能性の数です。 数値に大きさがある場合$M$、約あります$M^{1/3}$可能な立方根と 5 つのネストされた選択肢から大まかに作成されます。$M^{5/3}$組み合わせ。 と$M=10^{100000}$、これはリモートでも不可能です。 

有益な観察はアイデンティティから生まれる$$(y+1)^3+(y-1)^3+(-y)^3+(-y)^3=6y$$これは、6 で割り切れる数値は 4 つの立方体を使用して記述できることを意味します。 すべての整数には 6 を法とする 0 から 5 までの剰余があり、そのような剰余はそれ自体、6 を法とする整数の立方体になります。 最初にその余りを削除してから、残りの分割可能な部分に恒等式を適用できます。 

問題全体は、一定数の大きな整数演算になります。 小さな立方体を見つけます$r^3$入力モジュロ 6 と同じ剰余を使って計算します$y=(x-r^3)/6$、その ID を次の目的で使用します。$6y$。

 | 最適 | O(d^2) ここで、d は桁数です。 O(d) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力数値のモジュロ 6 の余りを計算します。 6 を法とする立​​方体は可能なすべての剰余をカバーするため、小さな整数を選択してください`r`から`0`に`5`その立方体の余りは同じです。 
2. 減算`r^3`番号から。 どちらの値も 6 を法とした同じ剰余を持つため、残りの値は 6 で割り切れることが保証されます。 
3. 残りの値を 6 で割って、`y`。 
4. ID を使用する$$(y+1)^3+(y-1)^3+(-y)^3+(-y)^3=6y$$そして追加します`r`5番目の立方体として。 もし`r`がゼロの場合、許可されるキューブの数が少ないため、出力する必要はありません。 

不変条件は、ステップ 2 の後、残りの値が正確に 6 の倍数になるということです。 ステップ 4 の恒等式は 4 つの立方体を使用してその倍数を表し、削除された剰余は 1 つの立方体で表されるため、最終的な合計は常に元の数値と等しくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    x = int(input().strip())

    r = None
    for i in range(6):
        if (i * i * i - x) % 6 == 0:
            r = i
            break

    ans = []

    if r != 0:
        ans.append(r)

    y = (x - r * r * r) // 6

    if y != 0:
        ans.extend([y + 1, y - 1, -y, -y])

    if not ans:
        ans.append(0)

    print(len(ans))
    print(*ans)

if __name__ == "__main__":
    solve()
```6 を法とする剰余には 6 つの可能性しかないため、プログラムは最初に 6 つの候補だけを検索します。 これは入力サイズとは無関係です。 

変数`y`最大 100,000 桁を含めることができますが、Python 整数はこれを直接処理します。 表現`(x - r * r * r) // 6`前のループで割り算が保証されているため、安全です。 

いつ`y`がゼロの場合、4 つの立方体恒等式により冗長なゼロ項が作成されます。 コードではそれらを省略し、必要な剰余キューブのみを出力します。 答えは依然として 5 つの数値の制限を満たしています。 

## 実用的な例

 入力用`5`、選択された剰余立方体は次のとおりです。 

| × | r | y | 出力キューブ |
 | --- | --- | --- | --- |
 | 5 | 5 | 0 | 5 |

 アルゴリズムはそれを認識します`5^3`と同じ余りがある`5`モジュロ6だから`125 mod 6 = 5`。 残った部分はゼロなので立方体だけ`5^3`が必要です。 

入力用`17`、次のようになります。 

| × | r | y | 出力キューブ |
 | --- | --- | --- | --- |
 | 17 | 5 | -19 | 5、-18、-20、19、19 |

 4 つの大きな立方体の合計は次のようになるため、これは有効な構成です。$6y$、そして最後の立方体は除去された残留物を復元します。 出力はサンプルと一致する必要はなく、方程式を満たすことだけが必要です。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(d²) | 大きな整数の加算、減算、乗算、除算は d 桁の数値で演算されます。 
| スペース | O(d) | 保存される数値は、最大でも入力桁の長さに小さな定数を加えたものになります。 

このアルゴリズムは、100,000 桁の値に対して大きな整数演算をいくつか実行するだけなので、制限内に問題なく収まります。 

## テストケース```python
import sys
import io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)

    x = int(sys.stdin.readline().strip())

    r = None
    for i in range(6):
        if (i * i * i - x) % 6 == 0:
            r = i
            break

    ans = []
    if r != 0:
        ans.append(r)

    y = (x - r * r * r) // 6

    if y != 0:
        ans.extend([y + 1, y - 1, -y, -y])

    if not ans:
        ans.append(0)

    out = str(len(ans)) + "\n" + " ".join(map(str, ans)) + "\n"

    sys.stdin = old
    return out

def check(inp):
    out = run(inp).split()
    k = int(out[0])
    vals = list(map(int, out[1:]))
    assert k == len(vals)
    assert k <= 5
    x = int(inp)
    assert sum(v ** 3 for v in vals) == x

check("5")
check("17")
check("1")
check("6")
check("1000000000000000000000000")

 | 17 | 最大 5 つの立方体を含む任意の有効な表現 | 非ゼロの剰余プラス負の立方体 |
 | 1 |`1`3乗 | 最小値 |
 | 6 | 4 つの立方体のアイデンティティ | 6 の境界で割り切れる |

 ## 特殊なケース

 入力用`1`、アルゴリズムは次のことを見つけます。`r = 1`、 それで`y = 0`。 印刷のみです`1`、立方体の合計はちょうど 1 になります。 これにより、一般的なアイデンティティから不必要な用語が生成されることが回避されます。 

入力用`6`、余りはゼロなので、`r = 0`そして`y = 1`。 生成されたキューブは、`2, 0, -1, -1`、その立方体の合計は$$8+0-1-1=6$$ゼロ項は省略できますが、保持または削除しても正確さに影響しません。 

非常に大きな値の場合、アルゴリズムは数値を数字に変換したり、その大きさを反復したりすることはありません。 一定数の算術演算のみを実行するため、100,000 桁の入力は小さな入力と同じように処理されます。
