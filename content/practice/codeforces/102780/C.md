 ## 問題の理解

 入力は、もともといくつかの絵文字を次々に書いたもので、スクランブルされた文字の集合です。 文字の順序は失われましたが、各文字の合計出現数は保持されました。 タスクは、まさにこの複数の文字セットを生成する可能性のある顔文字のリストを復元し、復元された各顔文字を印刷して終了することです。`LOL`。 

重要な点は、文字の順序は関係ないということです。 入力内の部分文字列は検索しません。 私たちは、利用可能な情報が各文字の頻度だけである再構成問題を解決しています。 

入力長は 10000 文字に達することがあります。 顔文字の数が増えると組み合わせの数が指数関数的に増加するため、顔文字のあらゆる組み合わせを試すソリューションはすぐに不可能になってしまいます。 可能な顔文字タイプは 16 種類しかないため、目的のソリューションでは入力長ではなく文字構造を利用する必要があります。 文字を数えて定数サイズの算術演算を行うだけで十分です。問題の負荷がかかる部分は文字列の長さではなく、有効な分解を見つけることだからです。 

いくつかのエッジケースでは、単純な実装が壊れる可能性があります。 よくある間違いは、顔文字は見た目によって貪欲に削除できると想定することです。 たとえば、入力```
:-0
```ゼロ、ダッシュ、コロンが 1 つずつ含まれます。 それは表現することしかできませんでした`:-0`、 ない`:-`それらの残りの部分だけで構成される顔文字は存在しないため、さらに何か他のものを追加します。 

もう 1 つの注意が必要なケースは、括弧を含む 2 つの顔文字間の相互作用です。 考慮する：```
;:((
```不注意なアプローチは、`;-)`または`;-(`セミコロンがあるため、必ず表示する必要があります。 正しい解釈は次のとおりです。```
;-(
:(
```セミコロンは、セミコロンの絵文字が 1 つ存在することを示すだけであり、括弧とコロンは残りの選択肢のバランスを決定します。 

最後のエッジケースは、記号が繰り返された長い絵文字です。```
[:|||:]
```3 本の縦棒はこの絵文字に特有のものですが、コロン文字は他の多くの絵文字と共有されています。 コロンの数を数えるだけでは十分ではありません。 角括弧は、これらの絵文字の正確な数を示します。 

## アプローチ

 直接的なアプローチでは、16 個の顔文字をそれぞれ変数として扱い、各顔文字の可能な数をすべて試します。 考えられるすべての選択について、結果の文字周波数を入力周波数と比較します。 すべての有効な回答がそのような選択の 1 つに対応するため、これは正しいです。 

問題は検索スペースです。 最大 10,000 文字があり、複数の絵文字に使用できる値がほんの少ししかない場合、組み合わせの数は膨大になります。 ブルートフォース検索では、同じ不可能な状態を繰り返し探索することになり、制約内に快適に収まることはできません。 

絵文字の構造により、より優れたルートが得られます。 ほとんどの絵文字には、他の絵文字に含まれていない文字が含まれています。 例えば、`\`、`P`、`D`、`C`、`8`、`E`、`%`、`X`、`~`、`[`そして`]`それぞれが 1 つの絵文字タイプをすぐに識別します。 これらの数が判明すると、不明な顔文字は 6 つだけになります。```
;-)
;-(
:)
:(
:-0
:-|
```残りの方程式は直接解くことができるほど小さいものです。 の数`0`そして`|`与える`:-0`そして`:-|`。 セミコロン、閉じ括弧、開き括弧の数によって、残りの 4 つの顔文字に対する小さなシステムが作成されます。 このシステムには自由変数が 1 つあるため、有効範囲内の任意の値が機能します。 

重要な観察は、元の順序を再構築する必要がないということです。 文字頻度には、有効な顔文字のマルチセットを復元するのに十分な情報がすでに含まれています。

 ## アルゴリズムのチュートリアル

 1. 入力文字列内のすべての文字の出現をカウントします。 再構成はこれらの周波数のみに依存するため、元の順序は完全に無視できます。 
2. 1 つの絵文字にのみ表示される文字を使用して、その数を直接決定します。 登場人物たち`\`、`P`、`D`、`C`、`8`、`E`、`%`、`X`、`~`、`[`そして`]`対応する絵文字の数がすぐに表示されます。 角括弧の数は次の数を示します。`[:|||:]`、チルダの数は次の数を示します。`:~(`。 
3. の数を計算します。`:-0`ゼロの数からなる絵文字。 すべてのゼロはどこから来ている必要があります`:-0`、`8-0`、 または`%0`、後の2つはすでに決定されていました。 
4. の数を計算します。`:-|`縦棒の数から顔文字を作成します。 残りの 3 本のバーのグループはすべて、`[:|||:]`、したがって、残ったバーはから来る必要があります`:-|`。 
5. 残りの 4 つの顔文字の数を解きます。 させて`a`、`b`、`c`、 そして`d`代表する`;-)`、`;-(`、`:)`、 そして`:(`。 セミコロンの数は次のとおりです`a + b`、右括弧の数は次のようになります。`a + c`、および削除後の開き括弧の数`:~(`与える`b + d`。 

有効な最小値を選択してください`a`。 もし`b + d`すべてのセミコロンをカバーするには小さすぎるため、増加させます`a`それに応じて。 これにより、4 つの値はすべて負ではなくなります。 
6. 回復した数に応じてすべての絵文字を出力し、次で終了します。`LOL`。 

機能する理由: すべての絵文字タイプは、文字数への寄与によって表されます。 ユニークなキャラクターが 9 種類の絵文字を曖昧さなく修正します。 残りの 6 つのタイプは、正確な周波数方程式によって制約されます。 最後の 4 つの方程式は、唯一残っている不確実性を記述し、任意の値を選択します。`a`有効な範囲内では、すべての文字数を維持しながら、他のすべての変数に負でない値が生成されます。 最終的なマルチセットは元の周波数と一致するため、生成された絵文字は有効な復元となります。 

## Python ソリューション```python
import sys
from collections import Counter

input = sys.stdin.readline

def solve():
    s = input().rstrip("\n")
    cnt = Counter(s)

    ans = []

    def add(name, amount):
        for _ in range(amount):
            ans.append(name)

    # Unique-character emoticons
    add(":-\\", cnt["\\"])
    add(":-P", cnt["P"])
    add(":D", cnt["D"])
    add(":C", cnt["C"])
    add("8-0", cnt["8"])
    add(":-E", cnt["E"])
    add("%0", cnt["%"])
    add(":-X", cnt["X"])
    add(":~(", cnt["~"])
    add("[:|||:]", cnt["["])

    # Determined by remaining unique symbols
    zero_count = cnt["0"] - cnt["8"] - cnt["%"]
    pipe_count = cnt["|"] - 3 * cnt["["]

    add(":-0", zero_count)
    add(":-|", pipe_count)

    # Remaining four emoticons
    semis = cnt[";"]
    close = cnt[")"]
    open_par = cnt["("] - cnt["~"]

    # b + d = open_par, a + b = semis, a + c = close
    a = max(0, semis - open_par)
    b = semis - a
    c = close - a
    d = open_par - b

    add(";-) ", 0)  # keeps the function shape clear, never adds output

    ans.extend([";-)"] * a)
    ans.extend([";-("] * b)
    ans.extend([":)"] * c)
    ans.extend([":("] * d)

    sys.stdout.write("\n".join(ans))
    sys.stdout.write("\nLOL\n")

if __name__ == "__main__":
    solve()
```プログラムは最初に周波数テーブルを構築します。これは、スクランブル操作の後に必要な唯一の表現です。 ヘルパー関数は、一意の文字からカウントが直接判明する顔文字に使用されます。 

の数`:-0`そして`:-|`それらの文字を共有する絵文字の寄与を差し引いた後に計算されます。 この順序が重要です。 ゼロまたはバーの合計数を直接使用すると、プログラムが誤って余分な絵文字を作成してしまいます。 

最後の 4 つのカウントは代数的に導出されます。 の選択`a`は維持される最小値です`d`非否定的。 より大きな有効な値でも機能しますが、最小値を使用すると構築が決定的になり、検証が容易になります。 

出力セクションでは、繰り返し印刷する代わりに、繰り返しリスト拡張を使用します。 これにより、入力に多くの絵文字が含まれる場合の不要な I/O オーバーヘッドが回避されます。

 ## 特殊なケース

 この場合の場合:```
:-0
```プログラムはゼロを 1 つ認識します。 の数`8`そして`%`両方ともゼロなので、ゼロは次のものに属します`:-0`。 答えには 1 つだけが含まれます`:-0`、他の顔文字は発明されていません。 

あいまいな括弧の場合:```
;-(:(
```数はセミコロン 1 つ、開き括弧 2 つ、閉じ括弧 1 つです。 方程式により次のことが得られます。`;-(`そして1つ`:(`。 アルゴリズムはセミコロンを貪欲に消費しません。 キャラクターの関係性の完全なセットを解決します。 

長い絵文字の場合:```
[:|||:]
```角括弧の数はすぐに 1 になります`[:|||:]`。 アルゴリズムは、計算する前に 3 本の垂直バーを減算します。`:-|`これにより、3 本のバーが 3 つの別々のパイプ絵文字として誤解されるのを防ぎます。 

同じ絵文字の繰り返しが多数含まれる大規模な入力の場合、アルゴリズムはスキャン中にカウンターのみをインクリメントし、その後、回答リストを繰り返します。 検索は実行されないため、実行時間は入力サイズに比例して増加します。
