 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、`n`異なる整数。 すべての番号は 2 つのグループのいずれかに割り当てる必要があります。 

数字の場合`x`グループに入れられます`A`、次にそれに関する補数`a`、つまり`a - x`も存在し、以下に属している必要があります。`A`。 

同様に、`x`グループに入れられます`B`、次にそれに関する補数`b`、つまり`b - x`も存在し、以下に属している必要があります。`B`。 

数値自体は固定です。 欠損値を追加することはできません。 既存の各番号がグループに属するかどうかのみを選択します`A`またはグループ`B`。 

出力は、すべての入力数値に対する代入です。 従来、`0`番号が属することを意味します`A`、 そして`1`に属していることを意味します`B`。 

制約`n ≤ 100000`指数関数的な検索は直ちに除外されます。 たとえ`O(n²)`アルゴリズムには次のようなものが必要です`10¹⁰`限界をはるかに超えた最悪の場合の動作。 線形に近いものが必要です。`O(n log n)`。 

いくつかの特殊なケースが問題を難しくしています。 

考慮する：```
n = 1
a = 10
b = 20
p = [3]
```番号`3`どちらの補完もありません`7`補完もしない`17`セットで。 割り当ては不可能なので、答えは次のようになります。`NO`。 

ここで次のことを考えてみましょう。```
n = 2
a = 5
b = 100
p = [2, 3]
```ここ`2`そして`3`和のために有効なペアを形成する`5`。 どちらの番号にも合計の有効なパートナーがありません`100`。 両方の数値が強制的に設定されます`A`。 

個別に数値を決定しようとする不注意なソリューションは、次のような状況で失敗する可能性があります。```
a = 10
b = 12
p = [1, 9, 3]
```番号`1`合計のみに参加できます`10`、 以来`9`存在します。 番号`3`合計のみに参加できます`12`、 しかし`9`その場合、両方のセットに同時に存在する必要があります。 答えは`NO`。 

主な困難は、決定が補数関係のグラフを通じて伝播することです。 

## アプローチ

 最も直接的なアプローチはブルートフォースです。 すべての番号について、いずれかのセットを選択します`A`またはセット`B`、次に、すべての補数要件が満たされるかどうかを確認します。 

がある`2ⁿ`課題。 と`n = 100000`、これはまったく不可能です。 

ブルートフォースが概念的に機能する理由は、制約がローカルであるためです。 数値は、次の点についての補数のみを考慮します。`a`そして`b`。 問題は、ローカルな選択が相互作用し、依存関係の長いチェーンが作成されることです。 

重要な観察は、すべての数字が合計のパートナーを最大 1 つ持つことができるということです。`a`合計のパートナーは最大 1 名`b`。 

頂点が指定された数値であるグラフを作成すると、次のようになります。 

Aタイプエッジ：`x ↔ a - x`両方の数値が存在する場合はいつでも。 

B型エッジ：`x ↔ b - x`両方の数値が存在する場合はいつでも。 

数値に A パートナーが欠けているとします。 その場合、セットに属することはできません`A`、つまり強制的にセットされます`B`。 

同様に、数値に B パートナーが欠けている場合、その数値は強制的にセットされます。`A`。 

こうした強制的な選択は伝播していきます。 頂点が強制的に押し込まれた場合`A`の場合、A エッジを介して接続されているすべての頂点も、`A`。 それらの頂点の 1 つが既に強制的に配置されている場合、`B`、矛盾があります。 

この構造は、Disjoint Set Union 構造に最適です。 

2 つの特別なノードを導入します。`SA`「Aに属する」という意味`SB`「Bに属する」という意味

 すべての番号について:

 A パートナーが存在しない場合は、それを結合します。`SB`。 

B パートナーが存在しない場合は、それを結合します。`SA`。 

既存のすべての A エッジに対して`(x, a-x)`:

 対応する頂点を結合します。 

既存のすべての B エッジに対して`(x, b-x)`:

 対応する頂点を結合します。 

古典的に受け入れられている解決策は、実際には、接続されたコンポーネントがパスまたはサイクルであるグラフとして問題をモデル化します。 各コンポーネント内では、すべての頂点が同じグループに属する必要があります。 DSU はこの伝播を正確に捕捉します。 

結局のところ、労働組合があれば、`SA`そして`SB`接続されると、制約が矛盾します。 

それ以外の場合は、接続されているすべてのコンポーネントが`SA`セットに割り当てられています`A`に接続されているすべてのコンポーネント`SB`セットに割り当てられています`B`、残りの空きコンポーネントは任意に割り当てることができます。

 ## アルゴリズムのチュートリアル

 1. すべての数値を読み取り、値からインデックスまでのハッシュ マップを構築します。 
2. DSU を作成します。`n + 2`頂点。 

最後の 2 つの頂点は特別な状態を表します`SA`そして`SB`。 
3. 数字ごとに`x`、どうかを確認してください`a - x`存在します。 

存在しない場合は、`x`セットに所属できません`A`。 その頂点を結合します`SB`。 
4. 数字ごとに`x`、どうかを確認してください`b - x`存在します。 

存在しない場合は、`x`セットに所属できません`B`。 その頂点を結合します`SA`。 
5. 既存の A パートナー ペアごとに、2 つの対応する頂点を結合します。 

1 つの頂点が属する場合`A`、もう一方も属している必要があります`A`。 
6. 既存の B パートナー ペアごとに、対応する 2 つの頂点を結合します。 

1 つの頂点が属する場合`B`、もう一方も属している必要があります`B`。 
7. すべての結合が完了したら、次のことを確認します。`SA`そして`SB`同じ DSU コンポーネントに属します。 

そうした場合、ある数値が両方のセットに同時に強制的に入力され、有効な代入が存在しません。 
8. それ以外の場合は、すべての番号の割り当てを決定します。 

そのコンポーネントが接続されている場合`SA`、出力`0`。 

それ以外の場合は出力`1`。 

### なぜ効果があるのか

 A パートナーが欠落しているということは、その番号をセットに入れることができないことを意味します`A`、したがって、それはに属している必要があります`B`。 対称的なステートメントは、欠落している B パートナーにも当てはまります。 

すべての補完関係では、両方のエンドポイントが同じ割り当てを受け取る必要があります。 DSU は、常に一緒に移動する必要がある頂点を正確にマージします。 

このようなすべての影響が処理された後、すべての DSU コンポーネントは、割り当てが分離できない数値のグループを表します。 コンポーネントを接続する`SA`設定するように修正します`A`に接続しながら、`SB`設定するように修正します`B`。 

もし`SA`そして`SB`最終的には同じコンポーネントに収まる場合、何らかの影響の連鎖により、数値は両方のセットに同時に属することが強制されます。 それ以外の場合、すべてのコンポーネントに一貫した割り当てがあり、有効なパーティションが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)

        if a == b:
            return

        if self.size[a] < self.size[b]:
            a, b = b, a

        self.parent[b] = a
        self.size[a] += self.size[b]

def solve():
    n, a, b = map(int, input().split())
    p = list(map(int, input().split()))

    pos = {x: i for i, x in enumerate(p)}

    SA = n
    SB = n + 1

    dsu = DSU(n + 2)

    for i, x in enumerate(p):
        ax = a - x
        bx = b - x

        if ax not in pos:
            dsu.union(i, SB)

        if bx not in pos:
            dsu.union(i, SA)

    for i, x in enumerate(p):
        ax = a - x
        bx = b - x

        if ax in pos:
            dsu.union(i, pos[ax])

        if bx in pos:
            dsu.union(i, pos[bx])

    if dsu.find(SA) == dsu.find(SB):
        print("NO")
        return

    rootA = dsu.find(SA)

    ans = []
    for i in range(n):
        if dsu.find(i) == rootA:
            ans.append("0")
        else:
            ans.append("1")

    print("YES")
    print(" ".join(ans))

solve()
```ハッシュマップ`pos`補数の定数時間ルックアップが可能になります。 これがなければ、すべての補数検索に線形スキャンが必要となり、解は二次関数になります。 

2 つの特別な DSU 頂点が中心的なアイデアです。 これらは、2 つのセットのうちの 1 つへの強制的なメンバーシップを表します。 補数が欠落していると、それらの強制割り当てが即座に作成されます。 

2 番目のパスでは、すべての補数ペアがマージされます。 すべての補数ルールは等しい割り当てを必要とするため、DSU はまさに正しい構造です。 

最終チェックでは、次の代表者を比較します。`SA`そして`SB`。 一致とは、矛盾する要件が同じコンポーネントに到達したことを意味します。 

答えを構築するとき、接続されているすべてのコンポーネントは、`SA`セットに割り当てられています`A`。 残りのコンポーネントはすべてセットに属します`B`。 なぜなら`SA`そして`SB`接続されていない場合でも、この割り当ては常に一貫しています。

import sys
import io

def run(inp: str) -> str:
    out = io.StringIO()

    class DSU:
        def __init__(self, n):
            self.parent = list(range(n))
            self.size = [1] * n

        def find(self, x):
            while self.parent[x] != x:
                self.parent[x] = self.parent[self.parent[x]]
                x = self.parent[x]
            return x

        def union(self, a, b):
            a = self.find(a)
            b = self.find(b)
            if a == b:
                return
            if self.size[a] < self.size[b]:
                a, b = b, a
            self.parent[b] = a
            self.size[a] += self.size[b]

    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n, a, b = map(int, input().split())
    p = list(map(int, input().split()))

    pos = {x: i for i, x in enumerate(p)}

    SA = n
    SB = n + 1

    dsu = DSU(n + 2)

    for i, x in enumerate(p):
        if a - x not in pos:
            dsu.union(i, SB)
        if b - x not in pos:
            dsu.union(i, SA)

    for i, x in enumerate(p):
        if a - x in pos:
            dsu.union(i, pos[a - x])
        if b - x in pos:
            dsu.union(i, pos[b - x])

    if dsu.find(SA) == dsu.find(SB):
        return "NO"

    rootA = dsu.find(SA)
    ans = []

    for i in range(n):
        ans.append("0" if dsu.find(i) == rootA else "1")

    return "YES\n" + " ".join(ans)

# single value, impossible
assert run("1 10 20\n3\n") == "NO"

# pair forced into A
assert run("2 5 100\n2 3\n") == "YES\n0 0"

# contradiction through chain

assert run("2 100 5\n2 3\n") == "YES\n1 1"

 ## 特殊なケース

 次のことを考慮してください。```
1 10 20
3
```番号`3`両方の補体が欠けている`7`そして`17`。 アルゴリズムはそのコンポーネントを両方と結合します。`SA`そして`SB`。 これらの代表者は同一になるので、答えはすぐにわかります。`NO`。 

考慮する：```
2 5 100
2 3
```どちらの番号にも有効な A パートナーはありますが、有効な B パートナーはありません。 アルゴリズムは両方の頂点を接続します。`SA`、A エッジを介してそれらをマージし、決して接触しません。`SB`。 最終的な割り当ては設定どおりに一意に決定されます`A`。 

考慮する：```
3 10 12
1 9 3
```頂点`1`強制されています`A`、頂点`3`強制されています`B`。 補完エッジのマージ`1 ↔ 9`そして`9 ↔ 3`したがって、3 つの頂点すべてが 1 つの DSU コンポーネントになります。 このコンポーネントは両方の特別なノードに触れるため、矛盾が生じます。 アルゴリズムは正しく出力します`NO`。 

考慮する：```
4 8 8
1 7 3 5
```ここで、両方の合計は同一です。 すべての補数関係は同じ関係です。 DSU は、一致するペアを単純にマージします。 矛盾は見られず、一貫した割り当てが機能します。 共用体は冪等であるため、アルゴリズムはこれを自然に処理します。
