 ## 解決策
 ## 問題の理解

 ほぼすべての要素が 1 であり、少数のエントリのみが異なる大きな正方行列の永続値を計算するように求められます。 パーマネントは行列式に似ていますが、交互の符号はありません。つまり、その順列に沿った行列要素の積のすべての順列の合計です。 正式には、$n \times n$マトリックス$A$、$$\text{perm}(A) = \sum_{\sigma \in S_n} \prod_{i=1}^{n} A_{i, \sigma(i)}.$$ここ、$n$まで可能です$10^5$、しかし、ただ$k \le 50$エントリは 1 とは異なります。これは重要です。パーマネントを直接計算するには、合計を計算する必要があります。$n!$順列は不可能です$n = 10^5$。 したがって、この問題は対処可能なものにすぎません。$k$非常に小さいです。 

変更されたエントリの 1 つが 0 の場合、その要素を使用するすべての置換がブロックされるため、エッジ ケースが発生します。 たとえば、次の場合$n=3$そして唯一の変更は$A_{1,1} = 0$の場合、行 1 を列 1 にマップする順列は何も寄与しませんが、他の順列は 1 を寄与します。そのため、すべての要素を乗算するか、変更を単に合計するだけの単純なアプローチでは、間違った答えが得られます。 同様に、複数の変更が同じ行または列で重複する場合は、二重カウントを避けるために慎重に計算する必要があります。 

## アプローチ

 ブルートフォース手法では、すべてを反復処理することになります。$n!$順列を作成し、それぞれの行列要素を乗算します。 これは数学的には正しいですが、実行不可能です。$n = 10^5$、$n!$天文学的に大きく、$n=20$これはすでに非現実的です。 複雑さは$O(n! \cdot n)$、これは受け入れられません。 

重要な観察は、ほとんどすべての行列エントリが 1 であるということです。すべて 1 の行列の永続性は、単純に次のようになります。$n!$。 変更された各要素は、その要素を含む順列の寄与を変更します。 以来$k$が非常に小さい場合、変更されたエントリに対して包含/除外を適用できます。 具体的には、変更された要素のすべてのサブセットを検討します。 各サブセットについて、行または列を共有する 2 つの要素がない場合は、1 からの偏差の積を計算し、残りの空き位置の階乗を乗算します。 これらを適切な符号 (包含-除外に従って) で合計すると、永続的な値が得られます。 

ここでは、各変更が含まれるか含まれないか、およびサイズが異なるため、包含/排他が機能します。$k$反復処理が可能$2^k$サブセット、これは実現可能です$k \le 50$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * n) | O(n^2) | 遅すぎる |
 | 包含-除外 | O(2^k * k) | O(k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. マトリクスサイズを読み取ります$n$および変更された要素の数$k$。 変更されたエントリの配列を初期化し、行、列、重みを格納します。 
2. 階乗を事前計算します。$n$モジュロ$10^9+7$、残りの位置の順列を数えるために必要になるためです。 また、モジュロ演算の下で除算のモジュラー逆数を事前計算します。 
3. のすべてのサブセットを列挙します。$k$変更されたエントリ。 サブセットごとに、2 つの要素が行または列を共有しているかどうかを確認します。 含まれる場合は、同じ行または列の 2 つのエントリを順列に含めることはできないため、サブセットをスキップします。 
4. 有効なサブセットの場合、サブセット内の各要素の 1 からの差の積を計算します。つまり、$(w_i - 1)$。 これに残りのポジション数の階乗を掛けます。$n - \text{size of subset}$。 
5. サブセット サイズのパリティに応じて、これらの寄与を合計または減算することにより、包含/除外を適用します。 サブセットのサイズが奇数の場合は減算します。 偶数の場合は追加します。 
6. すべてのサブセットを処理した後、最終結果のモジュロを出力します。$10^9+7$。 

機能する理由: 変更されたエントリのサブセットを列挙し、それらのエントリを正確に使用する順列を注意深くカウントすることにより、すべての順列を 1 回だけ正確に考慮します。 包含/除外を使用すると、行または列の重複が確実に正しく削除されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(a):
    return pow(a, MOD-2, MOD)

def solve():
    n, k = map(int, input().split())
    mods = []
    rows = set()
    cols = set()
    for _ in range(k):
        x, y, w = map(int, input().split())
        mods.append((x-1, y-1, w))
    fact = [1]*(n+1)
    for i in range(1, n+1):
        fact[i] = fact[i-1]*i % MOD
    ans = 0
    for mask in range(1<<k):
        used_rows = set()
        used_cols = set()
        prod = 1
        valid = True
        bits = 0
        for i in range(k):
            if mask & (1<<i):
                r, c, w = mods[i]
                if r in used_rows or c in used_cols:
                    valid = False
                    break
                used_rows.add(r)
                used_cols.add(c)
                prod = prod * (w-1) % MOD
                bits += 1
        if not valid:
            continue
        rem = n - bits
        contrib = prod * fact[rem] % MOD
        if bits % 2 == 1:
            ans = (ans - contrib) % MOD
        else:
            ans = (ans + contrib) % MOD
    ans = (ans + fact[n]) % MOD
    print(ans)

solve()
```コードは、入力を読み取り、変更を保存することから始まります。 効率を高めるために階乗が事前に計算されます。 変更されたエントリのサブセットごとに、アルゴリズムは行または列の競合をチェックし、調整された積を計算し、包含/除外を適用します。 最後に、次の階乗を追加します。$n$1 のみを使用して順列を考慮し、永久モジュロを与えます。$10^9+7$。

 ## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(2^k * k) | 変更されたエントリの各サブセットの競合がチェックされ、積が計算されます。 k ≤ 50 の場合、2^k が実現可能になります。 |
