 ## 解決策
 ## 問題の理解

 数直線上の一連の個別の整数位置と開始位置が与えられます。 開始位置から、一度に 1 単位ずつ左または右に移動できます。 私たちの目標は、指定されたすべての位置を少なくとも 1 回訪問することであり、これを達成するために必要な最小移動数を計算したいと考えています。 

入力は複数のテスト ケースを提供します。 各テスト ケースは、訪問する位置の数、開始点、および位置の並べ替えられたリストを示します。 各テスト ケースの出力は、すべての位置を確実に訪問するための最小ステップ数を表す単一の整数です。 

制約は小さいです: ポジションの数`n`は最大 10、開始位置とターゲット位置は 1 ～ 100、テスト ケースは最大 1000 個です。 なぜなら`n`非常に小さく、指数関数的なアルゴリズム`n`実現可能です。 訪問順序のすべての順列を試すことさえ計算上合理的であるため、複雑度の高いグラフや動的プログラミング手法を考慮する必要はありません。 

開始位置で微妙なエッジケースが発生します。`s`訪問する必要があるポジションの範囲外です。 たとえば、次の場合`s = 1`そしてポジションは`[3, 4, 5]`の場合、最適なパスは、最も近いエンドポイントに直接移動し、すべての位置を順番に横断することです。 を前提とした素朴な実装`s`常に位置の範囲内にあると、間違った答えが生成されます。 

もう 1 つのエッジケースは次のような場合です`s`いずれかの位置と一致します。 たとえば、次の場合`s = 3`そしてポジションは`[3, 4, 5]`、開始位置に到達するために移動する必要がないため、最小ステップ数が減少します。 

## アプローチ

 ブルートフォースアプローチでは、位置のすべての順列が生成され、からの移動距離が計算されます。`s`それぞれの順列を通して。 これは、すべての可能な次数を考慮するため正しいですが、数直線の線形的な性質により不要です。 と`n = 10`、 がある`10! = 3,628,800`テストケースごとの順列。 1000 のテスト ケースを掛けると、このアプローチは遅すぎます。 

重要な洞察は、すべての位置が 1 次元の線上にあり、並べ替えられているということです。 最小ステップ数は、訪問する必要がある左端と右端の位置によって完全に決まります。 開始位置がこの間隔内にある場合、最適な戦略は、最初に近い端点に移動し、次にもう一方の端までトラバースすることです。 開始位置が間隔の外にある場合は、最も近い終点に直接移動し、遠端までトラバースします。 したがって、最小ステップは、左端と右端の位置の間の距離に、開始点から間隔に到達するための追加距離を加えたものになります。 

これにより、問題は単純な算術に単純化されます。つまり、左端と右端の位置を見つけ、そこからそこに到達するまでの距離を計算します。`s`、間隔の長さを追加します。 このアプローチは次の点で線形です。`n`テストケースごとであり、実装は簡単です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべての順列) | O(n! * n) | O(n) | 遅すぎる |
 | 最適 (間隔 + 距離) | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. 各テスト ケースについて、次の内容を読んでください。`n`、`s`、および位置のソートされたリスト`x`。 
3. 一番左の位置を特定します`L = x[0]`そして一番右の位置`R = x[-1]`。 
4. 開始位置の場合`s`の間にあります`L`そして`R`(両端を含む)、最小パスは次のいずれかです。`R - s + s - L = R - L`、最初に近い端に移動してから間隔を横切ると、合計距離は常に同じになるためです。 コンピューティング`max(R - s, s - L) + (R - L)`; 実際には、これを単純化すると、`(R - L)`いつ`s`区間内にあります。 
5. 開始位置の場合`s`未満です`L`、手順は次のとおりです`R - s`から移動する必要があるため、`s`に`L`次にトラバースします`R`。 
6. 開始位置の場合`s`より大きい`R`、手順は次のとおりです`s - L`から引っ越してきたので、`s`に`R`次にトラバースします`L`。 
7. 計算された最小ステップを出力します。 

機能する理由: このソリューションは位置の一次元の性質を利用します。 ステップの最小シーケンスは常に、間隔の 1 つの終点に到達し、もう 1 つの終点に移動することです。 非連続的な順序で位置を訪問するなど、何らかの逸脱があると、ステップ数が不必要に増加します。 これにより正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, s = map(int, input().split())
    x = list(map(int, input().split()))
    L, R = x[0], x[-1]

    if s < L:
        steps = R - s
    elif s > R:
        steps = s - L
    else:
        steps = (R - L) + min(R - s, s - L)
    
    print(steps)
```コードは入力を効率的に読み取ります。`sys.stdin.readline`多くのテストケースを迅速に処理します。 間隔を特定します`[L, R]`すべてのポジションが含まれます。 開始位置かどうかに応じて`s`この間隔の外側または内側にある場合、コードは最小ステップ数を計算します。 の`min(R - s, s - L)`次の場合に、近い端から開始するようにします。`s`間隔内にあるため、移動距離が減少します。
