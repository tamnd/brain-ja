 ## 解決策
 ## 問題の理解

 いくつかの短い文字列が与えられ、それぞれについて、隙間や繰り返しのない単一の連続したアルファベットのブロックを形成しているかどうかを判断する必要があります。 小文字のアルファベットは「a」から「z」までの直線であると考えてください。 文字列に含まれる文字を確認したときに、その文字がこの行の連続したセグメントに対応し、すべての文字が 1 回だけ出現する場合、その文字列は有効です。 

したがって、「dabcef」のような文字列は、その文字が {a、b、c、d、e、f} であり、アルファベットの連続した間隔を形成しているため機能します。 文字列内の順序は定義にとって重要ではなく、文字のセットのみが重要です。 一方、「az」は「a」と「z」の間のすべての文字を飛び越えるため失敗し、「babc」は「b」を繰り返すため失敗します。 

各テスト ケースは独立しており、文字列がこれらの条件を満たしている場合は単に「Yes」を出力し、そうでない場合は「No」を出力します。 

制約は非常に小さく、文字列は最大 100 個、それぞれの長さは最大 100 です。これにより、文字列ごとの線形作業を超えるものは即座に排除されます。 文字列ごとに O(n^2) のアプローチでもまだ許容されますが、頻度のチェックやアルファベットのスキャンよりも複雑なものは不要なオーバーヘッドです。 

主な失敗例は、通常、2 つの条件のうちの 1 つを忘れたことが原因です。 1 つは重複です。たとえば、「aa」は単一の文字種であっても拒否されるべきです。 もう 1 つはアルファベットのギャップです。たとえば、「ac」は、両方の文字が異なっていても、それらの間に「b」がないため、拒否されなければなりません。 

## アプローチ

 この問題を考える強引な方法は、連続するアルファベットのセグメントの可能な開始文字をすべて試して、文字列をそのセグメントに再配置できるかどうかを確認することです。 候補セグメントごとに、ソートされた文字を比較するか、頻度配列を構築して同等性を検証します。 これは機能しますが、やりすぎです。 

重要な点は、有効な文字列がアルファベット行の「パス」のように動作する必要があるということです。 文字セットについてソートまたは推論する場合、最小文字と最大文字によって唯一可能なセグメントが決まります。 文字列が有効な場合、これらの両端の間にあるすべての文字が 1 回だけ出現する必要があり、重複は許可されません。 

これにより、問題は単純なチェックに集約されます。一意性を確認し、最小文字と最大文字を計算し、個別の文字の数が文字間の間隔の長さに等しいことを確認します。 

すべての操作は文字列長において線形であり、アルファベットのサイズは一定であるため、これは効率的です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(26 · n²) | お(1) | 受け入れられるが不要 |
 | 最適 | 文字列あたり O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 文字列ごとに個別に処理します。 

1. 文字列をスキャンし、繰り返し文字があったかどうかを記録します。 文字が繰り返される場合、その文字列は直ちに無効になります。 これが必要なのは、重複は「各文字を 1 回ずつ」というルールに違反するためです。 
2. スキャン中に、アルファベット順で検出された最小文字と最大文字も追跡します。 これにより、潜在的なセグメントのエンドポイントが得られます。 
3. スキャン後、確認された異なる文字の数を計算します。 重複が検出された場合、答えは「いいえ」であることがすでにわかっています。 
4. 次に、最小文字と最大文字によって定義される間隔のサイズを比較します。 間隔の長さは`(max_char - min_char + 1)`。 
5. 個別の文字の数がこの間隔の長さに等しい場合は、範囲内のすべての文字が 1 回だけ存在する必要があるため、「Yes」を返します。 それ以外の場合は、「いいえ」を返します。 

### なぜ効果があるのか

 重要な不変条件は、有効な文字列が要素を欠落することなくアルファベット上の完全な間隔を表さなければならないということです。 重複が禁止されている場合、各文字はその間隔内で 1 つの位置にのみ寄与します。 観察された文字セットのサイズが k であるが、間隔が k よりも大きい場合、中央の少なくとも 1 つの文字が欠落し、連続性が損なわれます。 逆に、サイズが間隔の長さと一致し、重複がない場合は、ギャップや余分なものが入る余地がないため、セットは正確に間隔である必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_diverse(s: str) -> bool:
    seen = [False] * 26
    mn = 26
    mx = -1

    for ch in s:
        idx = ord(ch) - ord('a')
        if seen[idx]:
            return False
        seen[idx] = True
        mn = min(mn, idx)
        mx = max(mx, idx)

    # number of distinct characters
    cnt = sum(seen)

    return (mx - mn + 1) == cnt

def main():
    n = int(input())
    for _ in range(n):
        s = input().strip()
        print("Yes" if is_diverse(s) else "No")

if __name__ == "__main__":
    main()
```実装はアルゴリズムに直接従います。 ブール配列`seen`重複を一定時間検出することが保証されます。 トラッキング`mn`そして`mx`並べ替えやセットベースの範囲の再構築を回避します。 最後の比較では、文字が隙間なく間隔全体を満たしているかどうかがチェックされます。 

微妙な点は、文字列内の順序ではなく、文字のセットのみに依存していることです。 この条件は文字列自体の隣接関係ではなく、アルファベットの隣接関係のみに依存するため、これは安全です。 

## 実用的な例

 2 つの入力 (1 つは有効で、もう 1 つは無効) をトレースします。 

### 例 1:`"dabcef"`| ステップ | キャラクター | 見たセットサイズ | 最小インデックス | 最大インデックス | 重複？ |
 | --- | --- | --- | --- | --- | --- |
 | 1 | d | 1 | 3 | 3 | いいえ |
 | 2 | | 2 | 0 | 3 | いいえ |
 | 3 | b | 3 | 0 | 3 | いいえ |
 | 4 | c | 4 | 0 | 3 | いいえ |
 | 5 | e | 5 | 0 | 4 | いいえ |
 | 6 | f | 6 | 0 | 5 | いいえ |

 加工後、`cnt = 6`、`mn = 0`、`mx = 5`。 間隔サイズは`5 - 0 + 1 = 6`、これは個別の文字の数と一致するため、結果は「はい」になります。 

これにより、順序付けされていない入力が依然として連続したアルファベット ブロックを形成していることが確認されます。 

### 例 2:`"babc"`| ステップ | キャラクター | 見たセットサイズ | 最小インデックス | 最大インデックス | 重複？ |
 | --- | --- | --- | --- | --- | --- |
 | 1 | b | 1 | 1 | 1 | いいえ |
 | 2 | | 2 | 0 | 1 | いいえ |
 | 3 | b | - | - | - | はい |

 3 文字目で、「b」がすでに表示されていることが検出されるため、すぐに「No」を返します。 

これは、たとえアルファベットの間隔条件が満たされていたとしても、重複だけで文字列を無効にするのに十分であることを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n・L) | 各文字列は 1 回スキャンされ、すべての操作は 1 文字あたり O(1) 回です。 
| スペース | お(1) | 固定長の 26 配列のみが使用されます。

## テストケース```python
import sys, io

def solve():
    import sys
    input = sys.stdin.readline

    def is_diverse(s: str) -> bool:
        seen = [False] * 26
        mn = 26
        mx = -1

        for ch in s:
            idx = ord(ch) - ord('a')
            if seen[idx]:
                return False
            seen[idx] = True
            mn = min(mn, idx)
            mx = max(mx, idx)

        cnt = sum(seen)
        return (mx - mn + 1) == cnt

    n = int(input())
    for _ in range(n):
        s = input().strip()
        print("Yes" if is_diverse(s) else "No")

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from contextlib import redirect_stdout
    out = io.StringIO()
    with redirect_stdout(out):
        solve()
    return out.getvalue().strip()

 ## 特殊なケース

 長さ 1 の文字列は、ギャップや重複のない連続したセグメントを自明に形成するため、常に有効です。 アルゴリズムはこれを処理します。`mn == mx`そして`cnt == 1`, したがって、間隔チェックはパスします。 

「az」のようなケースは、範囲チェックが必要な理由を示しています。 スキャンで見つかるのは、`mn = 0`、`mx = 25`、 そして`cnt = 2`。 間隔のサイズは 26 であり、一致しないため、重複がないにもかかわらず、正しく「No」が返されます。 

「aa」のようなケースは、重複ルールを示しています。 2 番目の文字は、範囲ロジックが重要になる前に即座に拒否をトリガーし、間隔チェックに依存せずに正確さを保証します。
