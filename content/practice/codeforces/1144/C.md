[CF 1144C - 2 つのシャッフルされたシーケンス](https://codeforces.com/problemset/problem/1144/C)

 **評価:** 1000
 **タグ:** 建設的アルゴリズム、並べ替え
 **解決時間:** 1 分 48 秒
 **確認済み:** いいえ

 ## 解決策
 ## 問題の理解

 2 つのシーケンス (1 つは厳密に増加し、もう 1 つは厳密に減少) を取得し、それらのすべての要素をマージし、結果をシャッフルすることによって作成された整数のマルチセットが与えられます。 

マージされた配列内の元の順序は失われます。 私たちが知っているのは、現れた値だけです。 私たちのタスクは、結合された要素が指定された数値と正確に一致するシーケンスの有効なペアを再構築することです。 

重要な要件は、増加するシーケンスには重複した値を含めることはできず、減少するシーケンスにも重複した値を含めることはできないということです。 最終的なマルチセットはこれら 2 つのシーケンスの結合から得られるため、値が出現するたびに 2 つのシーケンスのいずれかに割り当てる必要があります。 

入力サイズが到達しました$2 \cdot 10^5$。 さまざまな割り当てを試したり、可能性を模索したりする解決策は、直ちに除外されます。 に近いものが必要です$O(n \log n)$、これは、並べ替えが関係する場合の自然なターゲットです。 

いくつかの特殊なケースは注目に値します。 

考慮する：```
3
5 5 5
```値 5 が 3 回現れます。 1 つのコピーを増加シーケンスに配置し、もう 1 つのコピーを減少シーケンスに配置することはできますが、3 番目のコピーを配置する場所がありません。 両方のシーケンスが厳密である必要があるため、同じシーケンス内に値を複数回出現させることはできません。 正しい答えは次のとおりです。```
NO
```重複が存在するかどうかだけをチェックする不注意な解決策では、2 を超える頻度は不可能であるということを見逃してしまいます。 

考慮する：```
4
1 2 3 4
```すべての値は 1 回出現します。 正しい構造は、すべての値を増加シーケンスに配置し、減少シーケンスを空のままにすることです。```
YES
4
1 2 3 4
0
```一部の実装では、すべての値を両方のシーケンスに不必要に強制し、一意の値で失敗します。 

別の微妙なケースは次のとおりです。```
4
1 1 2 2
```有効な答えが存在します。```
Increasing: 1 2
Decreasing: 2 1
```降順は厳密に降順で出力する必要があります。 重複する値を単純に昇順に収集すると、次のように出力されます。`1 2`、減少していません。 

## アプローチ

 ブルートフォース手法では、すべての出現を昇順または降順のいずれかに割り当ててから、厳密な順序付け要件を満たすように両方のシーケンスを配置できるかどうかを確認します。 

値が表示された場合$k$各コピーには割り当ての選択肢があります。 中程度の入力であっても、これは指数関数的に増加します。 と$n = 2 \cdot 10^5$、可能な割り当ての数はまったく実行不可能です。 

問題の構造からは、より強力な観察が得られます。 

どちらのシーケンスも厳密であるため、値は各シーケンスで最大 1 回しか現れません。 つまり、どの値も全体で最大 2 回出現する可能性があります。 ある周波数が 2 を超えた瞬間、答えは不可能になります。 

値が 1 回だけ出現するとします。 安全に増加シーケンスに配置できます。 

値がちょうど 2 回出現するとします。 1 つのコピーは昇順に配置し、もう 1 つのコピーは降順に配置する必要があります。 代替手段はありません。 

これにより割り当てが完全に決まります。 

個別の値を並べ替えた後、すべての個別の値のコピーを 1 つずつ昇順に配置します。 これにより、厳密に増加するシーケンスが自動的に生成されます。 

2 回出現するすべての値は、降順シーケンスに 1 つの追加コピーを提供します。 これらの重複した値を保存し、最終的に並べ替え順序を逆にすると、結果は厳密に減少します。 

問題全体は、頻度を数えることと個別の値を並べ替えることに帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^n)$|$O(n)$| 遅すぎる |
 | 最適 |$O(n \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての数値を読み取り、各値の頻度を数えます。 
2. 値が 2 回以上出現する場合は、出力します。`"NO"`そしてやめてください。 

値は増加シーケンスで最大 1 回、減少シーケンスで最大 1 回出現できるため、頻度が 3 以上になることは不可能です。 
3. すべての個別の値を昇順に並べ替えます。 
4. すべての個別の値を 1 回だけ取得して、増加するシーケンスを構築します。 

値はソートされて個別であるため、シーケンスは厳密に増加します。 
5. 頻度がちょうど 2 であるすべての値について、コピーを 1 つずつ 2 番目のリストに追加します。 

これらは、増加シーケンスに留まることのできない追加のコピーです。 
6. この 2 番目のリストを反転します。 

重複する値は昇順で収集されました。 それらを逆にすると、厳密に減少するシーケンスが生成されます。 
7. 印刷`"YES"`両方のシーケンスを出力します。 

### なぜ効果があるのか

 頻度が 1 のすべての値は、正確に 1 つのシーケンスに出現する必要があり、それを増加するシーケンスに配置しても競合が発生することはありません。 

頻度 2 のすべての値は、各シーケンスに 1 つのコピーを提供する必要があります。 1 つのコピーを増加シーケンスに配置し、もう 1 つのコピーを減少シーケンスに配置することが、可能な唯一の有効な割り当てです。 

増加シーケンスには、それぞれの個別の値が昇順で 1 回ずつ含まれているため、厳密には増加しています。 

降順シーケンスには、それぞれ 1 回出現する重複した値が降順で正確に含まれているため、厳密には減少しています。 

すべての出現は 1 回だけ割り当てられ、2 を超える頻度は拒否されるため、生成されたシーケンスは、解が存在する場合は常に元のマルチセットの有効なパーティションを形成します。 

## Python ソリューション```python
import sys
from collections import Counter

input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

freq = Counter(a)

for cnt in freq.values():
    if cnt > 2:
        print("NO")
        sys.exit()

inc = []
dec = []

for x in sorted(freq):
    inc.append(x)
    if freq[x] == 2:
        dec.append(x)

dec.reverse()

print("YES")
print(len(inc))
if inc:
    print(*inc)
else:
    print()

print(len(dec))
if dec:
    print(*dec)
else:
    print()
```頻度表は中心的なデータ構造です。 値が 2 回以上出現するあり得ないケースを即座に検出します。 

増加するシーケンスは、ソートされた個別の値から構築されます。 個別の値を使用すると、厳密性が自動的に保証されます。 

減少するシーケンスには、2 回出現した値が正確に含まれます。 順序は重要です。 昇順トラバース中に重複を収​​集すると増加するリストが得られるため、印刷する前にリストを反転します。 

空のシーケンスは明示的に処理されます。 この問題ではそれらが許可されているため、シーケンスの長さがゼロの場合でも、必要な行を出力します。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io
from collections import Counter

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    n = int(input())
    a = list(map(int, input().split()))

    freq = Counter(a)

    for cnt in freq.values():
        if cnt > 2:
            return "NO"

    inc = []
    dec = []

    for x in sorted(freq):
        inc.append(x)
        if freq[x] == 2:
            dec.append(x)

    dec.reverse()

    out = []
    out.append("YES")
    out.append(str(len(inc)))
    out.append(" ".join(map(str, inc)))
    out.append(str(len(dec)))
    out.append(" ".join(map(str, dec)))

    return "\n".join(out)

# sample
assert run("7\n7 2 7 3 3 1 4\n").startswith("YES")

# minimum size
assert run("1\n5\n") == "YES\n1\n5\n0\n"

# all equal, impossible
assert run("3\n7 7 7\n") == "NO"

# duplicates exactly twice
assert run("4\n1 1 2 2\n") == "YES\n2\n1 2\n2\n2 1"

# all distinct
assert run("5\n1 2 3 4 5\n") == "YES\n5\n1 2 3 4 5\n0\n"

# boundary style case
assert run("2\n0 200000\n") == "YES\n2\n0 200000\n0\n"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1 / 5`| 単一要素ソリューション | 最小サイズ |
 |`7 7 7`|`NO`| 2 を超える頻度 |
 |`1 1 2 2`| 有効な分割 | 重複の処理 |
 |`1 2 3 4 5`| 空の減少シーケンス | すべての値は一意です |
 |`0 200000`| 有効な分割 | 極値範囲 |

 ## 特殊なケース

 次のことを考慮してください。```
3
5 5 5
```5 の頻度は 3 です。頻度スキャン中に、アルゴリズムは 2 より大きいカウントを直ちに検出し、次のように出力します。```
NO
```2 つの厳密なシーケンスには、任意の値のコピーを最大 2 つ含めることができるため、これは正しいです。 

考慮する：```
4
1 2 3 4
```すべての周波数は 1 に等しい。 

アルゴリズムは以下を構築します。```
inc = [1, 2, 3, 4]
dec = []
```減少シーケンスは空ですが、問題では明示的に許可されています。 

考慮する：```
4
1 1 2 2
```アルゴリズムは以下を構築します。```
inc = [1, 2]
dec before reverse = [1, 2]
```反転後:```
dec = [2, 1]
```どちらのシーケンスも厳密であり、元のマルチセットのすべての出現箇所が 1 回だけ使用されます。 

考慮する：```
5
1 1 2 3 3
```アルゴリズムにより次のものが生成されます。```
inc = [1, 2, 3]
dec = [3, 1]
```増加シーケンスは厳密に増加したままであり、減少シーケンスは厳密に減少のままであり、元の 5 つの出現はすべて考慮されます。 これにより、値が 2 回以上出現しない限り、重複した値が安全に共存できることが確認されます。
