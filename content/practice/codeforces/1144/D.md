 ## 解決策
 ## 問題の理解

 一列に並べられた一連の整数が与えられます。 1 回の移動で、2 つの隣接するポジションを選択し、それらの値の差を使用して、その差だけ正確に一方のポジションを増加または減少させます。 各操作の主な効果は、方向に応じて、1 つの要素が、大きい値の 2 倍から小さい値を引いた値、または小さい値の 2 倍から大きい値を引いた値に等しくなることです。 

目標は、隣接する演算をできるだけ少なく使用して、すべての位置が同じ値を保持するように配列全体を変換し、一連の演算を明示的に出力することです。 

制約が十分に大きいため、離れた位置間の任意のバランスをシミュレートするソリューションは実行不可能です。 最大 20 万の要素を使用すると、配列全体に値を 2 次または 2 次に近い方法で繰り返し伝播するアプローチは失敗します。 唯一の実行可能な戦略は、違いが局所的に伝播する構造を利用する線形または線形に近い構造です。 

微妙な点は、操作によって非常に大きな中間値が作成される可能性があるため、配列を段階的に「平滑化」しようとする単純な貪欲なバランシングは、計算的にも概念的にも危険であるということです。 もう 1 つの重要な問題は、最終値が任意ではないということです。 操作では特定のグローバル構造が保持されるため、最終値は配列内の最大要素である必要があります。 これより小さい値に等化しようとすると、一般に実現可能性が損なわれます。 

エッジケースは、最大値が複数回出現する場合、またはすでに支配的な場合に発生します。 常に最初の要素から伝播するか、隣接する値の平均を試みる単純なアプローチは、次のような入力では失敗します。`[0, 0, 100000]`、盲目的に平滑化すると不必要な操作が増加し、値が誤ってプッシュされる可能性があります。 別の失敗モードは、中央値または平均値に等しくしようとすることですが、これは許可された操作では不可能です。 

## アプローチ

 ブルート フォースのアイデアは単純です。等しくない隣接するペアを繰り返し選択し、それらを近づける操作を適用します。 各演算は差分だけ増加または減少する可能性があるため、配列が均一になるまで分散を局所的に貪欲に減少させようとする場合があります。 これは直感的には魅力的ですが、すぐに管理できなくなります。 各操作によって値が拡大される可能性があり、ローカル スムージングによってグローバルな不均衡が軽減されるという保証はありません。 最悪の場合、値がエッジを越えて前後に押し出され、二次関数またはさらに悪い動作が発生する可能性があります。 

重要な洞察は、視点を逆転させることです。 すべてを均質化しようとするのではなく、最初に最終的な値を選択します。 ターゲットとして安全に使用できる唯一の値は、配列内の最大要素です。 これが修正されると、問題は制御された伝播タスクになります。近傍を使用して配列全体に最大値を「注入」し、制限された一連の操作を使用して各位置が最終的にその最大値で上書きされるようにします。 

この構築は、要素を左から右に (必要に応じて右から左に対称的に) 処理することによって機能し、常に固定済みの最大近傍を使用して、一定の操作数で次の要素を最大値に変換します。 各ステップは隣接する相互作用のみに依存するため、プロセスは自然に制約を尊重します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 貪欲なローカルスムージング | O(n²) | お(1) | 遅すぎる |
 | 最大伝播構築 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列内の最大値を見つけて、開始アンカーとしてその最大値を 1 つ選択します。 このアンカーは変更する必要がないため、最終値の安定したソースとして機能します。 
2. アンカーから左に移動し、すでに固定されている右隣を使用して各要素を最大値に変換します。 各ステップで、右側がすでに最大値に等しい隣接するインデックスのペアを操作します。 
3. 値を変換するには`x`最大値に近い`M`、強制する操作を適用します。`x`なる`M`制御された方法で。 この操作構造により、エッジ全体に値を「反映」することができ、小さい値が大きい値に置き換えられるか、大きい値に向けて調整されます。 
4. 左側の終了後、アンカーから右に移動して同じプロセスを繰り返し、すべての要素が最大値に等しくなるようにします。 
5. 出力形式の要求に応じてすべての操作を明示的に記録し、伝播するインデックス ペアを追跡します。 

重要な考え方は、インデックスが最大値を保持すると、それ自体の値を失うことなく隣接する要素を永続的に変換できるため、正しい値のフロンティアが決定論的に拡大するということです。 

### なぜ効果があるのか

 アルゴリズムは不変条件を維持します。つまり、すべてのステップで、すべての値がグローバル最大値に等しい配列の連続セグメントが存在し、このセグメントは外側にのみ拡張されます。 各操作は、エッジの 1 つの端点がすでに最大値に等しく、もう 1 つの端点が安定側を変更することなくそれに一致するように変換されるように設計されています。 安定領域では最大値を超えたり破壊したりすることはないため、伝播が逆転することはなく、プロセスは正確に終了した後に終了します。`n-1`拡張。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    mx = max(a)
    pos = a.index(mx)
    
    ops = []
    
    # expand left
    for i in range(pos - 1, -1, -1):
        if a[i] != mx:
            ops.append((1, i + 1, i + 2))
            a[i] = mx
    
    # expand right
    for i in range(pos + 1, n):
        if a[i] != mx:
            ops.append((1, i + 1, i))
            a[i] = mx
    
    print(len(ops))
    for t, i, j in ops:
        print(t, i, j)

if __name__ == "__main__":
    solve()
```解決策は、最大の要素を特定し、1 つの要素をアンカーとして選択することから始まります。 これにより、その位置を変更する必要がなくなり、不安定性が回避されます。 

左のスイープは、アンカーから外側に向かってインデックスを処理します。 最大値以外の値に遭遇するたびに、記録された 1 つの操作を適用し、概念的にはそれを最大値に設定します。 右のスイープはこの動作を反映しています。 

重要な実装の詳細は、構造が最終値のレベルで正確さを保証するため、中間の算術変更を正確にシミュレートしないことです。 保存された操作は再構築には十分です。 

## 実用的な例

 配列を考慮してください`[2, 4, 6, 6, 6]`。 

選択します`6`最大値とピック位置として`3`。 

| ステップ | インデックス | 操作 | 状態変化 |
 | --- | --- | --- | --- |
 | 1 | 2 | (2,3) に適用します | 4 が 6 になります |
 | 2 | 1 | (1,2) に適用する | 2 が 6 になります |

 これらの操作の後、配列は均一になります。 

トレースは、安定した最大値が存在すると、以前の位置を再検討することなく、各近傍を独立して変換できることを示しています。 

ここで考えてみましょう`[1, 3, 2]`。 

| ステップ | インデックス | 操作 | 状態変化 |
 | --- | --- | --- | --- |
 | 1 | 2 | 3 でアンカー | |
 | 2 | 1 | (1,2) | 1 が 3 になります |
 | 3 | 3 | (2,3) | 2 が 3 になります |

 これは中心から外側への対称的な伝播を示しており、プロセスが方向には依存せず、固定最大値への隣接性のみに依存することが確認されています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | 単一スキャンで最大プラス線形伝播を検出 |
 | スペース | O(1) おまけ | 出力リストのみが保存されます。 

各要素は伝播中に最大 1 回しかアクセスされないため、線形動作が必要です。 と`n ≤ 2·10^5`、これは制限内に快適に収まります。

 ## 特殊なケース

 のために`n = 1`、実行可能な操作や必要な操作はありません。 伝播ループが実行されないため、アルゴリズムはゼロ操作を正しく出力します。 

次のようなすでに均一な配列の場合`[7, 7, 7]`、最大値は配列全体であり、すべての要素がすでにアンカーに一致しているため、ループはすべての位置をスキップし、操作は生成されません。 

最大値が複数出現する場合、たとえば、`[5, 1, 5, 2, 5]`、アンカーとして任意の出現を選択しても、他のすべての要素が最大値に至る何らかのパスに隣接し、伝播が複数の最大値間の干渉なしに一貫して外側に拡張されるため、正確性が保証されます。
