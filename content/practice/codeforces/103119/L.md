 ## 問題の理解

 サイズのランダムな上限配列を生成しています。$n$、各エントリは$a_i$整数から独立して均一に選択されます$1$に$n$。 この配列が修正された後、次のすべての順列を調べます。$1$に$n$そして、どの順列がすべての位置で次の制約を尊重するかを尋ねます。$i$、そこに配置された値は境界を超えません$a_i$。 

固定配列の場合$a$、「有効な順列数」を順列の数として定義します。$p$そのような$p_i \le a_i$すべてのインデックスに対して。 タスクは、すべてのランダムな選択に対してこのカウントの期待値を計算することです。$a$。 

出力は単一の実数であり、期待値は非常に大きく非整数になる可能性があるため、高精度で計算する必要があります。 

制約からの重要な構造観察は次のとおりです。$n \le 50$これは、階乗または指数サブセットを含む解は実行可能であることを即座に示唆していますが、すべての順列を直接列挙しようとするものは実行可能ではありません。 完全な順列列挙は次のとおりです。$n!$、すでに超えています$10^{64}$で$n=50$, したがって、それは完全に不可能です。 

単純な確率的シミュレーションも不可能です。$a$は$n^n$、中程度の場合でも計算可能な範囲をはるかに超えて増加します。$n$。 

すべてが揃った場合、微妙なエッジケースが発生します。$a_i = 1$。 その場合、潜在的に機能するのは恒等順列のみであり、それもすべての制約に一致する場合に限り、非常に小さなカウントが強制されます。 位置間の独立性を前提とした不注意な期待値の計算は、このような縮退した配列では大幅にオーバーカウントされる可能性があります。 

## アプローチ

 直接的なアプローチは、特定の配列を修正することです$a$そして、二部一致解釈を使用して有効な順列をカウントします。 各ポジション$i$の値を許可します$[1, a_i]$、これらの制約の下で位置と値の間の完全な一致をカウントします。 これは古典的な割り当てカウント問題であり、次のサブセットにわたる DP で計算できます。$O(n 2^n)$。 ただし、以来、$a$それ自体はランダムなので、これを全体で平均する必要があります$n^n$可能性のある配列なので、強引な期待値の計算は不可能になります。 

重要なシフトは、推論の順序を逆にすることです。 直す代わりに$a$順列を数えて、順列を修正します$p$そしてそれがランダムの下で有効である確率を尋ねます$a$。 次に、順列に対する期待の線形性を使用します。 

順列$p$は次の場合にのみ有効です$a_i \ge p_i$みんなのために$i$。 それぞれなので$a_i$独立していて均一である$[1,n]$、その確率は$a_i \ge p_i$は$\frac{n - p_i + 1}{n}$。 立場間の独立性は、妥当性の確率を立場間の積に変えます。 

したがって、有効な置換の期待数は、独立した位置ごとの確率の積のすべての置換の合計になります。 これはまだ指数関数的ですが、現在、構造は値のマルチセットのみに依存しており、値がすでに位置に割り当てられている DP を有効にします。 

順列合計を状態 DP に変換し、値を割り当てます。$1$に$n$「きつさ」の昇順で、各値を受け入れることができる位置の数に対応する重みを蓄積します。 これは、次の標準サブセット DP に縮小されます。$O(n2^n)$各状態では、どの位置にすでに小さい値が割り当てられているかが追跡されます。

 ## アルゴリズムのチュートリアル

 期待値を順列の寄与の合計として再解釈し、計算を再編成して、次の値を代入して順列を段階的に構築します。$1$に$n$。 

1. 各値について$v$から$1$に$n$、順列内のどの位置が受け取るかを決定します$v$。 現時点で私たちが割り当てているのは、$v$、制約にはその位置が必要です$i$持っている必要があります$a_i \ge v$。 以来$a_i$均一であるため、これが一因となります$\frac{n-v+1}{n}$私たちが置くたびに$v$位置で$i$。 
2. 位置のサブセットにわたって DP を維持します。状態マスクは、どの位置にすでに値が割り当てられているかを表します。 次のステップは次の値を配置することです$v$未割り当ての位置に移動します。 
3. 固定マスクと値の場合$v$、割り当てられていない各位置を試してトランジションを計算します$i$。 各トランジションでは DP 値が次のように乗算されます。$\frac{n-v+1}{n}$、それは確率ですから$a_i \ge v$。 
4. 以下の値を反復します。$1$に$n$、徐々に課題を作成していきます。 DP は、制約と一致するすべての部分置換の予想される寄与の合計を累積します。 
5. 答えは、すべての値を処理した後のフルマスクでの DP 値です。 

重要な考え方は、ランダムな配列を明示的に反復処理しないということです。 すべてのランダム性は、設定された値のみに依存するステップごとの生存確率に圧縮されます。 

### なぜ効果があるのか

 各順列は、値の割り当ての 1 つのシーケンスに正確に対応します。$1$を通して$n$ポジションに。 固定割り当てがランダムな選択の後に生き残る確率$a$各位置と値のペアの独立した制約に因数分解します。 DP はそのような割り当てをすべて 1 回だけ列挙し、それぞれが正しい確率の重みを提供します。 期待値の線形性により、これらの寄与を合計すると期待されるカウントが得られることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    # dp[mask] = expected contribution for assigning first k values
    dp = [0.0] * (1 << n)
    dp[0] = 1.0

    for v in range(1, n + 1):
        ndp = [0.0] * (1 << n)
        prob = (n - v + 1) / n

        for mask in range(1 << n):
            if dp[mask] == 0:
                continue
            for i in range(n):
                if not (mask >> i) & 1:
                    nmask = mask | (1 << i)
                    ndp[nmask] += dp[mask] * prob

        dp = ndp

    print(dp[(1 << n) - 1])

if __name__ == "__main__":
    solve()
```コードは、各状態がどの位置に既に値が割り当てられているかを表すビットマスク DP を維持します。 遷移ループは次の値を割り当てます$v$利用可能なすべての位置に、その位置でのランダムな上限が十分である確率を乗算します。 

確率項は、値にのみ依存するため、値ごとに 1 回計算されます。$v$、ポジションではありません。 DP は、すべての配置にわたって対称的に貢献を蓄積します。 

微妙な点は、期待値を集計するときにポジションの数を明示的に乗算しないことです。 各配置は個別の部分順列であり、DP 構造は遷移による多重性を自然に考慮します。

 ## 特殊なケース

 いつ$n=1$、制約が唯一であるため、DP は確率 1 の単一状態に減少します。$a_1 \ge 1$常に保持されます。 アルゴリズムが初期化されます$dp[0]=1$、プロセス$v=1$確率係数 1 で、最終状態に直接到達します。 

のために$n=2$、両方の順列が調査されます。 DP は最初に値 1 を自由に割り当てます。$a_i \ge 1$常に保持されます。 値 2 では、各配置が係数に寄与します。$1/2$したがって、両方の順列は同じ減少された重みで存続し、合計は正しく 1.333333... となり、ランダムな上限の下で有効な割り当ての予想される対称性と一致します。
