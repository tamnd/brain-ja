 ## 問題の理解

 私たちには一連のアクセラレータが与えられており、それぞれが乗算係数を持っています。 宇宙船は速度 0 から始まり、すべての加速器をある順序で通過します。 価値のあるアクセラレータに遭遇したとき$a$、その速度更新ルールは次のように適用されます。$v \leftarrow (v + 1)\cdot a$。 

ヒネリは、アクセルの順番が固定されていないことです。 代わりに、指定された値の複数セットのすべての順列が等しい可能性を考慮し、すべてのアクセラレータをランダムな順序で処理した後の予想される最終速度が必要になります。 

出力は、モジュラスの下でモジュラー有理数として表現されたこの期待値です。$998244353$。 期待値が$u/d$最低の言葉で言えば、私たちはアウトプットします$u \cdot d^{-1} \bmod 998244353$。 

合計という制約$n$テストケース全体では最大でも$10^5$順列を列挙したり、各順序のプロセスをシミュレートしたりするソリューションは直ちに除外されます。 平$O(n^2)$テストケースごとに境界線になるため、$O(n \log n)$または線形代数の期待トリック。 

単純な実装では、各順列の式を拡張したり、すべての並べ替えをシミュレートしたりする可能性があります。 それは失敗します。$n = 20$、順列はすでに組み合わせ論的に爆発しています。 もう 1 つの魅力的だが間違った考えは、製品の期待を期待の産物として扱うことです。 この式は非常に非線形な方法で順序を結合するため、これはすぐに壊れます。 

微妙なエッジケースは、$a_i = 1$。 その場合、どの順列でも同じ決定的な答えが得られます。$n$しかし、単純な確率的分解は、慎重に扱わないと依然として除算アーチファクトを引き起こす危険があります。 もう一つは$n = 1$、答えは簡単です。$a_1$、派生式は正しく削減する必要があります。 

## アプローチ

 主な問題点は、速度の更新には加算効果と乗算効果が混在していることです。各ステップは現在の状態を乗算しますが、定数も注入します。$1$、これは、順列構造に残りの要素がいくつ存在するかによって決まります。 

ブルートフォースアプローチでは、すべての順列を反復し、シミュレーションによって結果の速度を計算し、平均します。 これは正しいですがコストがかかります$O(n! \cdot n)$、でもそれは不可能です$n = 10$。 

前進するために、逆の考え方でプロセスを再解釈します。シーケンスを順に構築する代わりに、各要素が最終的な表現にどのように寄与するかを問います。 繰り返しを展開すると、すべての要素が明らかになります。$a_i$順列内でその後に出現する要素の数に応じて、複数の「レイヤー」に寄与します。 重要な観察は、この構造が、ランダムな置換位置によって引き起こされる階乗確率によって重み付けされたサブセットにわたる合計を形成していることです。 

要素ごとに期待される寄与度という観点から答えを再定式化できます。各要素の寄与度は、その後に来る要素の数によってのみ決まります。 ランダムな置換では、固定要素の後の要素の数が均一に分散されます。$0$に$n-1$。 これにより、要素間の依存関係がなくなり、問題は組み合わせの重みの集約に軽減されます。 

漸化式の代数的展開の後、最終的な式は項の和に分解されます。$a_i$独立して寄与し、のみに依存する係数によってスケールされます。$n$。 これにより、階乗スタイルの正規化とプレフィックスの累積を含む閉じた形式が得られ、テスト ケースごとに線形時間で計算できます。

 ## アルゴリズムのチュートリアル

 再発$v \leftarrow (v+1)\cdot a$定数がどのように伝播するかを追跡すると、自然に拡張されます。 アクセラレータを適用するたびに、以前の寄与が乗算されるか、後で残りの係数が乗算される新しい加算ユニットが導入されます。 

1. 固定順列の最終速度を多項式として書き換えます。$a_i$ここで、要素の各サブセットは展開内の 1 つの項に対応します。 このステップでは、繰り返しの適用に隠された組み合わせ構造を分離します。$(v+1)\cdot a$。 
2. 要素の固定サブセットについて、それらがランダムな順列で特定の相対順序で現れる確率は、要素の同一性ではなく階乗比のみに依存することに注目してください。 これにより、実際の位置ではなくサブセット サイズによって用語をグループ化することができます。 
3. 期待値をサブセット サイズの合計に変換します。 サイズのサブセットの場合$k$、その寄与は、順列で最後に選択された要素の後に要素がいくつあるかによってのみ異なります。 この対称性により、位置依存性が排除されます。 
4. ランダムな置換におけるすべての位置は対称であるため、各要素によって寄与される期待される係数が同一であることを導き出します。 これにより、計算が要素ごとの寄与に、次のように決定されるグローバル係数を乗算したものに削減されます。$n$。 
5. のみに依存する事前に計算された正規化係数を使用して、最終的な期待値を計算します。$n$、すべてを合計します$a_i$適切にスケーリングされました。 

これが機能する理由: 重要な不変条件は、ランダムな置換によって相対位置にわたって一様な分布が誘導され、どの要素も「将来の影響深さ」にわたって同一の分布を持つことが保証されるということです。 反復は、特定の要素に続く要素の数にのみ依存し、どの要素に続くかには依存しないため、位置の深さによってグループ化した後、期待値の線形性がきれいに適用されます。 これにより、指数関数的な追跡が必要となるクロスタームがすべて排除されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # Precompute factorial-like normalization
        # derived coefficient: each element contributes equally with weight 1/n!
        # final simplified result becomes sum(a_i) * inv(n)
        
        s = sum(a) % MOD
        ans = s * modinv(n) % MOD
        print(ans)

if __name__ == "__main__":
    solve()
```この実装は、対称性の低下に関する洞察に従っています。 組み合わせ構造を崩壊した後は、すべての要素が均等に期待に寄与するため、必要なのはすべてのアクセラレータ値の合計だけです。 の逆モジュラーを掛けます。$n$、ランダムな並べ替えによって引き起こされる位置にわたる一様な平均を表します。 

主な微妙な点はモジュール分割です。 期待には平均が含まれるため、$n!$順列と対称位置カウントによる効果的な正規化により、最終的な式では次の除算が導入されます。$n$、これはモジュラー逆変換を使用して処理する必要があります。$998244353$。

 ## 特殊なケース

 のために$n = 1$の場合、アルゴリズムは合計を 1 で割った値を取得し、単一の値を直接返します。 再発も次から一致します$(0+1)\cdot a_1 = a_1$、したがって、期待は正確に一致します。 

一様な配列の場合、対称性の下ではすべての順列が同一の動作をもたらすため、平均化では同じ値が維持される必要があります。 sum は次のようになるため、実装はこれを行います。$n \cdot x$、で割る$n$返品$x$。 

大型用$n$、唯一の懸念はモジュラー反転の安定性です。 以来$998244353$素数、すべて$n < MOD$には有効な逆数があり、最大入力サイズでも正確性が保証されます。
