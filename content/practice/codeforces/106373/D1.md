 ## 解決策
 ## 問題の理解

 無向平面グラフが与えられます。 各頂点は、次のいずれかを受け取る必要があるオブジェクトを表します。`k`色。 すべてのエッジが異なる色の 2 つの頂点を接続している場合、カラーリングは有効です。 タスクは、有効な色の割り当てがいくつ存在するかを数えることです。 

入力には複数のテスト ケースが含まれています。 それぞれのケースについて、頂点の数、エッジの数、使用可能な色の数がわかります。 次の行はエッジを説明します。 出力は、各グラフの適切な色の数です。 

D1 バージョンではグラフが小さく保たれます。 最大のグラフには頂点が約 12 個しかないため、大規模なインスタンスに必要となる多項式アプローチは除外されますが、慎重に最適化された指数関数アルゴリズムが可能になります。 単純な列挙では、考えられるすべての色の割り当てが試行されます。`k^n`試み。 たとえ`n = 14`そして`k = 7`、これは何十億もの可能性があるため、検索順序と枝刈りが全体的な解決策になります。 

単純な実装が失敗する可能性があるエッジケースがいくつかあります。 エッジのないグラフには、すべての割り当てが有効な色付けとして含まれます。 例えば：```
1
3 0 2
```答えは`8`3 つの頂点のそれぞれが独立していずれかの色を選択できるためです。 エッジを確認した後にのみ選択肢をカウントするプログラムは、誤ってゼロを返す可能性があります。 

自己ループを含むグラフはステートメントでは予期されていませんが、自己ループが出現した場合、頂点はそれ自体と異なる必要があるため、有効な色付けはゼロになります。 

完全なグラフも有用な境界ケースです。 例えば：```
1
3 3 2
1 2
2 3
1 3
```答えは`0`なぜなら、互いに隣接する 3 つの頂点には 3 つの異なる色が必要だからです。 各頂点に少なくとも 1 つの可能な色があるかどうかだけをチェックする貪欲な実装では、このグローバルな競合を見逃す可能性があります。 

## アプローチ

 簡単な解決策は、頂点に 1 つずつ色を割り当て、現在の選択がすでに色付けされている隣接する頂点と競合するかどうかを確認することです。 これは正しいです。考えられるすべての割り当てが 1 回だけ考慮されるからです。 ただし、最悪のケースを検討する`k^n`州。 このアルゴリズムは、ほとんどの時間をブランチの探索に費やしますが、ブランチは、ずっと後になって発見された競合により最終的に失敗します。 

重要な観察は、頂点の数が少ないため、目標は指数関数的な動作を完全に回避することではないということです。 代わりに、指数ツリーをできるだけ小さくする必要があります。 DSATUR ヒューリスティックによるバックトラッキング検索を使用します。 次に色を付ける頂点は、色付きの隣接頂点の中で現在最も多くの異なる色が表示されている頂点として選択されます。 このような頂点は最も制約が大きいため、無効な分岐は早期に拒否されます。 

検索では、現在の部分的な色付けが維持されます。 選択した頂点について、その色付きの隣接頂点で使用されていないすべての色を試します。 すべての頂点が割り当てられると、有効なカラーリングが 1 つ見つかります。 

グラフが小さいため総当り攻撃は機能しますが、不適切な選択に時間を浪費すると失敗します。 DSATUR は、矛盾を早期に明らかにすることで検索スペースを削減します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k^n) | O(n) | 枝刈りをしないと遅すぎる |
 | DSATUR バックトラッキング | O(k^n) 最悪の場合、実際にははるかに小さい | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グラフを隣接リストとして保存します。 また、色が利用可能かどうかを一定時間でチェックできるように、エッジのマトリックスも保持します。 
2. すべての頂点の現在の色を含む配列を維持します。 の値`-1`頂点がまだ色付けされていないことを意味します。 
3. 飽和度が最も高い次の頂点を選択します。 彩度は、隣接する色の中に現在存在する異なる色の数です。 複数の頂点の飽和度が同じ場合は、隣接する頂点が多い方を選択します。 
4. すべての色を試してください`0`に`k - 1`すでに色付けされている隣り合うものの中には表示されません。 一時的に色を割り当て、再帰的に続行します。 
5. すべての頂点が色付けされたら、完全に有効な割り当てに達したため、回答に 1 を追加します。 

これが機能する理由: 再帰の不変条件は、検索によって維持されるすべての部分的なカラーリングがすべてのカラー頂点ですでに有効であるということです。 このアルゴリズムは、エッジ制約を破らない色を使用してこの部分的な解決策のみを拡張します。 アルゴリズムは最終的にすべての頂点に同じ色を同じ順序で割り当てるため、すべての有効な最終的なカラーリングには再帰ツリーを通るパスが 1 つだけあります。 したがって、色付けが見逃されることはなく、2 回カウントされることもありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(n, m, k, edges):
    adj = [[] for _ in range(n)]
    mat = [[False] * n for _ in range(n)]

    for u, v in edges:
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
        mat[u][v] = True
        mat[v][u] = True

    color = [-1] * n
    ans = 0

    def choose_vertex():
        best = -1
        best_sat = -1
        best_deg = -1

        for v in range(n):
            if color[v] != -1:
                continue

            used = set()
            for u in adj[v]:
                if color[u] != -1:
                    used.add(color[u])

            sat = len(used)
            deg = len(adj[v])

            if sat > best_sat or (sat == best_sat and deg > best_deg):
                best = v
                best_sat = sat
                best_deg = deg

        return best

    def dfs(done):
        nonlocal ans

        if done == n:
            ans += 1
            return

        v = choose_vertex()

        forbidden = [False] * k
        for u in adj[v]:
            if color[u] != -1:
                forbidden[color[u]] = True

        for c in range(k):
            if not forbidden[c]:
                color[v] = c
                dfs(done + 1)
                color[v] = -1

    dfs(0)
    return ans

def main():
    t = int(input())
    out = []

    for _ in range(t):
        n, m, k = map(int, input().split())
        edges = []
        for _ in range(m):
            u, v = map(int, input().split())
            edges.append((u, v))
        out.append(str(solve_case(n, m, k, edges)))

    print("\n".join(out))

if __name__ == "__main__":
    main()
```隣接関係リストをヒューリスティックに使用すると、隣接関係を迅速に検査できるようになります。 ここでは隣接行列は厳密には必要ありませんが、表現を明示的にしておくと、後で競合チェックが変更された場合の間違いを避けることができます。 

の`choose_vertex`function implements the DSATUR rule. 重要な点は、彩度では隣接する色の数ではなく、異なる色の数がカウントされるということです。 3 つの赤い近傍に接続されている頂点の彩度は 3 ではなく 1 です。 

再帰関数は一度に 1 つの頂点を変更し、戻った後に常に古い状態を復元します。 このロールバックにより、検索ツリーの異なるブランチが同じ配列を共有できるようになります。 

Python の整数には任意の精度があるため、応答カウンターがオーバーフローすることはありません。 この問題では、最終的な答えが要求された範囲内に収まることが保証されます。

 | 測定 | 複雑さ | 説明 |

 | 時間 | O(k^n) 最悪の場合 | DSATUR は多くの枝を剪定しますが、あらゆるカラーリングを検討できます。 
| スペース | O(n + m) | グラフの保存と再帰状態 |

## テストケース```python
import sys
import io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    data = sys.stdin.read().split()
    sys.stdin = old

    it = iter(data)
    t = int(next(it))
    ans = []

    for _ in range(t):
        n = int(next(it))
        m = int(next(it))
        k = int(next(it))
        edges = []
        for _ in range(m):
            edges.append((int(next(it)), int(next(it))))
        ans.append(str(solve_case(n, m, k, edges)))

    return "\n".join(ans)

 ## 特殊なケース

 次のような空のグラフの場合:```
1
3 0 2
```検索では、いかなる色も禁止としてマークされることはありません。 すべての再帰的ブランチは、すべての頂点が割り当てられるまで存続し、`2^3 = 8`。 

より少ない色を使用した完全なグラフの場合:```
1
3 3 2
1 2
2 3
1 3
```最初の 2 つの頂点は異なる色を受け取ることができますが、3 番目の頂点では両方の色が禁止されています。 そのブランチはすぐに終了し、他のすべてのブランチも同様に失敗し、ゼロが生成されます。 

単一の頂点の場合:```
1
1 0 5
```再帰では唯一の頂点が選択され、5 つの可能な色が試行されます。 それぞれが完全な色を作成するため、答えは 5 つです。 これは、グラフにエッジが含まれず、再帰的な深さが必要ないときに終了条件が機能することも検証します。
