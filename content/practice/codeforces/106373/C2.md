 ## 解決策
 ## 問題の理解

 小文字で構成される単一の文字列が与えられます。 タスクは、その連続する部分文字列をすべて分析し、そのうちの「グローバルな意味で一意」なものの数をカウントすることです。つまり、カウントされた各部分文字列は元の文字列に 1 回だけ出現します。 

これを操作上正確にするには、開始位置と終了位置によってすべての部分文字列を列挙することを想像してください。 一部の部分文字列は複数の位置で繰り返される場合がありますが、他の部分文字列は 1 つの位置でのみ発生します。 出力は、文字列全体の合計頻度がちょうど 1 である部分文字列の数です。 

制約 (このような問題では文字列の長さが典型的な Codeforce 範囲の数十万まで) により、部分文字列を明示的に列挙するソリューションは即座に除外されます。 すべての部分文字列を保存することさえメモリ内では 2 次であり、頻度を単純にカウントすることは時間で 3 次です。 

構造上の重要な問題は、部分文字列が重なり合っていることです。 部分文字列を直接比較しようとすると、重複する大きなセグメント間の等価性を繰り返し再計算することになります。 

いくつかの特殊なケースは、素朴な推論がどこで破綻するかを示しています。 次のような文字列を考えてみましょう`aaaaa`。 1 を超える長さのすべての部分文字列が何度も繰り返されるため、単一の文字のみが寄与しますが、各文字が複数回出現するため、それらの文字列さえも一意ではありません。 したがって、正解はゼロです。 多重度を注意深く追跡せずに、部分文字列が別の場所に存在するかどうかだけをチェックする単純なアプローチでは、これらの繰り返される単一文字の部分文字列の多くが誤ってカウントされてしまいます。 

別のエッジケースは次のような文字列です`abc`。 すべての文字は個別であるため、すべての部分文字列は 1 回だけ出現します。そのため、答えは部分文字列の総数と等しくなります (長さ 3 の文字列の場合は 6)。 出現頻度ではなく、個別の部分文字列のみをカウントするアプローチでは、すべての個別の部分文字列が頻度においても一意であることを見逃してしまいます。 

最後に、次のような混合繰り返しケース`ababa`ここでは、誤った貪欲な推論が失敗することがよくあります。 のような部分文字列`aba`内部構造が「変化している」ように見えても、重複により複数回出現するため、構造的な区別性は十分ではなく、グローバルな出現数のみが問題となります。 

## アプローチ

 直接的なブルート フォース ソリューションでは、すべての部分文字列を列挙して保存し、ハッシュ マップを使用して頻度をカウントします。 これにより、ただちに O(n²) 個の部分文字列が生成され、各部分文字列の比較またはハッシュには最悪の場合 O(n) のコストがかかり、O(n³) 時間かかります。 ローリング ハッシュを使用しても、依然として O(n²) 個の部分文字列と大きなメモリ負荷に直面します。 このアプローチは概念的には正しいですが、計算的には実行不可能です。 

重要な洞察は、部分文字列を独立したオブジェクトとして扱うべきではないということです。 代わりに、「文字列内の同じ出現セット」の等価クラスによって部分文字列をグループ化します。 これはまさに接尾辞オートマトンが設計されたものです。 

接尾辞オートマトンは、文字列のすべての部分文字列を O(n) 状態に圧縮します。 各状態は、同じ終了位置のセットを共有する部分文字列のセットを表します。これは、元の文字列内のまったく同じ位置に出現することを意味します。 オートマトンは、遷移と、長さの間隔によって部分文字列を分割するサフィックス リンク ツリーも追跡します。 

オートマトンを構築すると、各状態は対応する終了位置の数を認識します。 状態が 1 つの終了位置に正確に対応する場合、その状態によって表されるすべての部分文字列が元の文字列内に 1 回だけ出現します。 州によって提供されるそのような部分文字列の数は、その最大長と最小長の差であり、当然次のようにエンコードされます。`len[state] - len[link[state]]`。 

これにより、問題は部分文字列の列挙からオートマトンの状態の反復に軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n³) (またはハッシュを使用した O(n² log n)) | O(n²) | 遅すぎる |
 | 接尾辞オートマトン | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 文字列に対して接尾辞オートマトンを構築します。 各状態は、同じ終了位置を共有する部分文字列のセットを表します。 この構造では、文字を 1 つずつ処理し、遷移構造と接尾辞のリンクを維持しながらオートマトンを拡張します。 
2. 構築中に初期化された周波数カウンタを各状態に対して維持します。 新しい文字を挿入するたびに、現在の終了状態をマークします。 これにより、文字列内のすべての位置が、対応する状態の終了位置のカウントに寄与することが保証されます。 
3. オートマトンを構築した後、長さの降順で、カウントを長い状態からサフィックスにリンクされた状態に伝播します。 このステップでは、各状態が文字列内の終了位置として出現する回数を累積します。 
4. 伝播が完了すると、各状態には、その部分文字列が元の文字列に何回出現するかを表す正しい出現数が表示されます。 
5. 出現回数がちょうど 1 に等しいすべての状態について、その寄与を加算します。`len[state] - len[link[state]]`最終的な答えへ。 
6. 累計を出力します。 

使用する理由`len[state] - len[link[state]]`それは、各状態が連続した間隔内のすべての部分文字列長をカバーするということです。 接尾辞リンクは最大の適切な接尾辞状態を指し、長さの差は、この状態によって導入される別個の部分文字列の長さの正確な数を数えます。 

### なぜ効果があるのか

 接尾辞オートマトンは、すべての部分文字列を、各クラスが状態に対応する素の等価クラスに分割します。 1 つの状態内では、すべての部分文字列が同一の出現セットを共有するため、すべてが 1 回だけ出現するか、すべてが複数回出現します。 これにより、個々の部分文字列に関する曖昧さが解消されます。 すべての部分文字列が正確に 1 つの状態とその状態内の正確に 1 つの長さの間隔に属するため、寄与式はすべての部分文字列を 1 回だけカウントします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class State:
    __slots__ = ("next", "link", "len", "cnt")
    def __init__(self):
        self.next = {}
        self.link = -1
        self.len = 0
        self.cnt = 0

class SuffixAutomaton:
    def __init__(self, s):
        self.st = [State() for _ in range(2 * len(s))]
        self.size = 1
        self.last = 0

        for ch in s:
            self.extend(ch)

        self.order = sorted(range(self.size), key=lambda i: self.st[i].len, reverse=True)
        self.process_counts()

    def extend(self, c):
        cur = self.size
        self.size += 1
        self.st[cur].len = self.st[self.last].len + 1
        self.st[cur].cnt = 1

        p = self.last
        while p != -1 and c not in self.st[p].next:
            self.st[p].next[c] = cur
            p = self.st[p].link

        if p == -1:
            self.st[cur].link = 0
        else:
            q = self.st[p].next[c]
            if self.st[p].len + 1 == self.st[q].len:
                self.st[cur].link = q
            else:
                clone = self.size
                self.size += 1

                self.st[clone].len = self.st[p].len + 1
                self.st[clone].next = self.st[q].next.copy()
                self.st[clone].link = self.st[q].link

                while p != -1 and self.st[p].next.get(c) == q:
                    self.st[p].next[c] = clone
                    p = self.st[p].link

                self.st[q].link = self.st[cur].link = clone

        self.last = cur

    def process_counts(self):
        for i in self.order:
            link = self.st[i].link
            if link != -1:
                self.st[link].cnt += self.st[i].cnt

s = input().strip()
sam = SuffixAutomaton(s)

ans = 0
for v in range(1, sam.size):
    if sam.st[v].cnt == 1:
        link = sam.st[v].link
        ans += sam.st[v].len - sam.st[link].len

print(ans)
```オートマトンの構造は標準的です。すべての文字は最後の状態を拡張し、遷移を分割するときに新しい状態または複製された状態を作成する可能性があります。 の`cnt`フィールドは終了状態で初期化され、サフィックス リンクに沿って長さの降順にプッシュされます。これにより、短い部分文字列がカウントを集計する前に、長い部分文字列がカウントを正しく伝播することが保証されます。 

最後のループでは、初期状態が空の文字列を表すため、慎重に除外し、1 回だけ出現する部分文字列に対応する状態からの寄与のみを合計します。 

## 実用的な例

 ### 例 1:`abc`| ステップ | 状態の長さ | cnt 値 (簡略化) | 貢献が追加されました |
 | --- | --- | --- | --- |
 | ビルド後 | a、b、c およびその組み合わせの複数の状態 | すべてのリーフ状態は cnt = 1 | 伝播後に計算される |

 伝播後、すべての状態は 1 回だけ出現する部分文字列に対応します。 寄与はすべての部分文字列の合計になります。`a, b, c, ab, bc, abc`。 

これにより、各部分文字列が正確に 1 つの状態に割り当てられ、1 回カウントされるという不変条件が確認されます。 

### 例 2:`aba`| ステップ | 状態 | CNT | 貢献 |
 | --- | --- | --- | --- |
 | ビルド後 | a、b、ab、ba、aba の状態 | 混合 | 保留中 |
 | 伝播後 | 一部の状態では cnt = 1 | フィルタリング済み | 一意に出現する部分文字列のみがカウントされます。 

ここで、次のような部分文字列`a`2 回出現すると除外されますが、`b`、`ab`、`ba`、`aba`適切にカウントされます。 

これは、オーバーラップは問題ではなく、グローバル周波数のみがエンコードされることを示しています。`cnt`。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | 各文字はサフィックス オートマトンに 1 回挿入され、各状態はカウントの伝播中に 1 回処理されます。 
| スペース | O(n) | オートマトンは最大でも線形の数の状態と遷移を持ちます。 

すべての操作が状態ごとに定数で償却され、構造がペアごとの部分文字列の比較を完全に回避するため、制約は快適に満たされます。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    class State:
        __slots__ = ("next", "link", "len", "cnt")
        def __init__(self):
            self.next = {}
            self.link = -1
            self.len = 0
            self.cnt = 0

    class SAM:
        def __init__(self, s):
            self.st = [State() for _ in range(2 * len(s))]
            self.size = 1
            self.last = 0
            for ch in s:
                self.extend(ch)
            self.order = sorted(range(self.size), key=lambda i: self.st[i].len, reverse=True)
            for i in self.order:
                link = self.st[i].link
                if link != -1:
                    self.st[link].cnt += self.st[i].cnt

        def extend(self, c):
            cur = self.size
            self.size += 1
            self.st[cur].len = self.st[self.last].len + 1
            self.st[cur].cnt = 1

            p = self.last
            while p != -1 and c not in self.st[p].next:
                self.st[p].next[c] = cur
                p = self.st[p].link

            if p != -1:
                q = self.st[p].next[c]
                if self.st[p].len + 1 != self.st[q].len:
                    clone = self.size
                    self.size += 1
                    self.st[clone].len = self.st[p].len + 1
                    self.st[clone].next = self.st[q].next.copy()
                    self.st[clone].link = self.st[q].link
                    while p != -1 and self.st[p].next.get(c) == q:
                        self.st[p].next[c] = clone
                        p = self.st[p].link
                    self.st[q].link = self.st[cur].link = clone
                else:
                    self.st[cur].link = q
            else:
                self.st[cur].link = 0

            self.last = cur

    def solve(s):
        sam = SAM(s)
        ans = 0
        for v in range(1, sam.size):
            if sam.st[v].cnt == 1:
                link = sam.st[v].link
                ans += sam.st[v].len - sam.st[link].len
        return str(ans)

 ## 特殊なケース

 次のような同一の文字列の場合`aaaaa`、最初のいくつかを除く接尾辞オートマトン内のすべての状態は、単一の繰り返し構造に折りたたまれます。 伝播中に、すべての状態のカウントが 1 を超える結果になるため、条件を満たす状態はありません`cnt == 1`、正解はゼロになります。 周波数は構造から推測されるのではなくグローバルに蓄積されるため、アルゴリズムはこれを処理します。 

次のようなすべての異なる文字を含む文字列の場合、`abcde`、すべての部分文字列はオートマトン内の一意のパスに対応し、各状態は正確に 1 のカウントを受け取ります。 したがって、すべての状態はその全長区間に寄与し、最終的な合計は部分文字列の総数に等しくなります。 これにより、オートマトンが別個の部分文字列を人為的にマージしないことが確認されます。 

混合オーバーラップの場合`ababa`を表す州`aba`そして`ba`重複する位置で繰り返し発生するため、1 を超えるカウントが蓄積されます。 伝播ステップにより、これらの重複が確実に正しく反映されます。`cnt`、最終的な合計に誤って含まれることを防ぎます。
