 ## 解決策
 ## 問題の理解

 文字列が与えられ、それに含まれる空ではない部分文字列がいくつあるかを判断する必要があります。 2 つの部分文字列は、文字のシーケンスが同一であれば、たとえ異なる位置に現れたとしても同じとみなされます。 

入力は、英語の小文字アルファベットの上に単一の文字列を重ねたものです。 出力は、そこから形成できる一意の部分文字列値の数です。 

このタスクを直接解釈すると、開始位置と終了位置の可能なすべてのペアを取得し、その部分文字列を作成し、それをセットに保存することが示唆されます。 これは小さな文字列には機能しますが、可能な部分文字列の数は二次関数的に増加します。 文字列の長さが$n$、 がある$n(n+1)/2$位置ごとに部分文字列を抽出し、その内容を保存すると、総作業量が 1 に近づく可能性があります。$O(n^3)$。 大きな値の場合、$n$、これは通常の制限時間をはるかに超えています。 

厄介なケースは、多くの繰り返しパターンを持つ文字列です。 たとえば、次の入力を使用します。```
aaaa
```答えは次のとおりです。```
4
```部分文字列は次のとおりです。`a`、`aa`、`aaa`、 そして`aaaa`。 さまざまな文字列ではなく位置をカウントする不用意な解決策では、10 個の間隔が考えられるため、10 が返されます。 

別のケースは次のとおりです。```
ababa
```答えは次のとおりです。```
9
```次のような繰り返される部分文字列`a`、`b`、`ab`、 そして`aba`1 回だけカウントする必要があります。 以前のすべての部分文字列を効率的に表現せずに、部分文字列が前に出現したかどうかだけをチェックするアプローチでは、時間がかかりすぎる可能性があります。 

最後の境界ケースは 1 文字です。```
x
```答えは次のとおりです。```
1
```空ではない部分文字列、つまり文字列自体が 1 つだけ存在します。 

## アプローチ

 簡単な方法は、すべての部分文字列を生成し、それをセットに挿入することです。 これが正しい理由は簡単です。セットは、各個別の文字列のコピーを 1 つだけ保持するため、すべての間隔を処理した後、そのサイズが必要な答えになります。 

問題は仕事量です。 がある$O(n^2)$部分文字列を作成し、各部分文字列を構築するには最大で$O(n)$時間。 最悪の場合の複雑さは次のようになります。$O(n^3)$、次の場合には適していません。$n$大きいです。 

重要な点は、部分文字列が独立していないということです。 文字列を 1 文字拡張すると、多くの部分文字列が前の接頭辞と共有されます。 接尾辞オートマトンは、同等の状態をマージしながら、文字列のすべての部分文字列について必要な情報を正確に保存します。 

接尾辞オートマトンの各状態は、同じ終了位置のセットを持つ部分文字列のグループを表します。 状態には、そのグループ内の部分文字列の最大長と、そのサフィックス リンクによって表される最長のサフィックスの長さが格納されます。 文字を追加するときに導入される新しい部分文字列の数は、これら 2 つの値の差です。 

州が持っている場合`len[v]`それが表す最長の部分文字列の長さであり、その接尾辞のリンクが指すもの`link[v]`、その後、次のように貢献します。$$len[v] - len[link[v]]$$一意の部分文字列。 これをすべての州について合計すると、最終的な答えが得られます。 

ブルート フォース ソリューションでは、文字列を直接比較しようとします。 代わりに、サフィックス オートマトンはすべての同等の部分文字列履歴をグループ化し、作業を線形パスに減らします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n3) | O(n²) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 初期状態のみを含む空の接尾辞オートマトンから開始します。 この状態は空の部分文字列を表します。 
2. 文字列の文字を左から右に処理します。 新しい文字ごとに、現在の位置で終わるすべての部分文字列を表す新しい状態を作成してオートマトンを拡張します。 
3. 現在のキャラクターとの遷移がない間は、サフィックス リンクをたどります。 これらの状態から新しい状態への遷移を追加します。 これにより、ここで終わるすべての新しい部分文字列が記録されます。 
4. 既存の遷移がすでに存在する場合は、現在の構造が有効かどうかを確認します。 既存のステートの長さの関係が間違っている場合は、クローン ステートを作成します。 クローンを使用すると、同じ遷移を持つ異なる部分文字列を正しく分離できます。 
5. 文字列全体が挿入された後、すべての状態を反復処理します。 すべての州について、次を追加します。`len[state] - len[link[state]]`答えに。 これは、その状態で最初に出現する部分文字列の長さをカウントします。 

なぜ効果があるのか:

 すべての個別の部分文字列は、サフィックス オートマトン内の 1 つのパスに正確に対応します。 状態は、長さが次の範囲にあるすべての部分文字列を表します。`len[link[state]] + 1`そして`len[state]`。 これらの長さは、その状態によって提供される一意の新しい部分文字列です。 州は考えられるすべての部分文字列を分割するため、それらの寄与を合計すると、すべての個別の部分文字列が 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class State:
    __slots__ = ("next", "link", "length")

    def __init__(self):
        self.next = {}
        self.link = -1
        self.length = 0

def solve(s):
    states = [State()]
    last = 0

    for ch in s:
        cur = len(states)
        states.append(State())
        states[cur].length = states[last].length + 1

        p = last
        while p != -1 and ch not in states[p].next:
            states[p].next[ch] = cur
            p = states[p].link

        if p == -1:
            states[cur].link = 0
        else:
            q = states[p].next[ch]
            if states[p].length + 1 == states[q].length:
                states[cur].link = q
            else:
                clone = len(states)
                states.append(State())
                states[clone].next = states[q].next.copy()
                states[clone].length = states[p].length + 1
                states[clone].link = states[q].link

                while p != -1 and states[p].next.get(ch) == q:
                    states[p].next[ch] = clone
                    p = states[p].link

                states[q].link = clone
                states[cur].link = clone

        last = cur

    ans = 0
    for i in range(1, len(states)):
        ans += states[i].length - states[states[i].link].length

    return ans

s = input().strip()
print(solve(s))
```の`State`オブジェクトには、オートマトンに必要な 3 つの値が格納されます。 遷移辞書は文字によってラベル付けされたエッジを表します。`link`サフィックスリンクを指し、そして`length`状態によって表される最長の部分文字列を格納します。 

挿入中、`last`は常に、処理されたプレフィックス全体を表す状態を指します。 新しいキャラクターが追加されると、サフィックス リンクに続くループによって、不足しているトランジションがすべて追加されます。 これらの遷移は、現在の文字で終わる部分文字列に対応します。 

クローン作成部分は、実装の微妙な部分です。 クローンを作成しないと、2 つの異なる部分文字列グループが誤って状態を共有し、最終的なカウントが小さくなりすぎる可能性があります。 クローンはトランジションをコピーしますが、最大長が短くなり、オートマトンの構造を維持しながらグループを分割します。 

最後のループは状態から始まります`1`なぜなら状態`0`は空の文字列を表します。 各状態は、そのサフィックス リンクによってまだカウントされていない長さのみを提供します。 

## 実用的な例

 入力の場合:```
aaa
```オートマトンの状態は次のように寄与します。 

| 状態 | len[状態] | len[リンク[状態]] | 貢献 |
 | --- | --- | --- | --- |
 | 1 | 1 | 0 | 1 |
 | 2 | 2 | 1 | 1 |
 | 3 | 3 | 2 | 1 |

 合計は次のとおりです。$$1 + 1 + 1 = 3$$個別の部分文字列は次のとおりです。`a`、`aa`、 そして`aaa`。 このトレースは、文字の繰り返しによって重複した回答が作成されないことを示しています。 

入力の場合:```
ab
```州は次のように貢献します。 

| 状態 | len[状態] | len[リンク[状態]] | 貢献 |
 | --- | --- | --- | --- |
 | 1 | 1 | 0 | 1 |
 | 2 | 2 | 0 | 2 |

 合計は次のとおりです。$$1 + 2 = 3$$部分文字列は次のとおりです。`a`、`b`、 そして`ab`。 2 番目の状態は 2 つの新しい長さに寄与します。`ab`そして`b`新しい位置で終了します。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | 各文字は最大 2 つの状態を作成し、サフィックス リンク操作は線形に償却されます。 |
 | スペース | O(n) | 接尾辞オートマトンには最大でも次のものが含まれます`2n - 1`州。 |

 このアルゴリズムはすべての文字を 1 回処理し、部分文字列を明示的に列挙することはありません。 これが、文字列の長さが長くても高速なままである理由です。

 ## 特殊なケース

 のために`aaaa`、アルゴリズムは状態の連鎖を作成します。 より長い部分文字列はすべて以前のサフィックスによってすでに表されているため、新しい状態はそれぞれ 1 つの追加の長さのみを提供します。 最終的な貢献度は、`1`、`1`、`1`、 そして`1`、の正しい答えを与える`4`。 

のために`ababa`、繰り返し発生する`a`、`b`、 そして`aba`同じオートマトン状態にマージされます。 貢献度の計算式により、複数回カウントされることが防止されるため、答えは次のようになります。`9`部分文字列の位置の数の代わりに。 

1文字入力の場合`x`、空ではない部分文字列が 1 つだけ存在します。 オートマトンには寄与のある 1 つの実際の状態があります`1 - 0`、したがって、それは返されます`1`。
