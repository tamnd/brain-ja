 ## 解決策
 ## 問題の理解

 2 つの整数シーケンスが与えられます。1 つは元のシーケンスの赤で塗られた要素を表し、もう 1 つは青で塗られた要素を表します。 各色の順序は保持されますが、赤と青の要素をインターリーブして元のシーケンスを再構築する方法がわかりません。 タスクは、最大のプレフィックスの合計を最大化するこれら 2 つのサブシーケンスの順序を見つけることです。ここで、プレフィックスの合計は、最初の要素の合計、最初の 2 つの要素の合計などとして定義されます。 これらの合計とゼロの最大値のみを考慮します。 

入力サイズは小さく、各カラー シーケンスには最大 100 個の要素と最大 1000 個のテスト ケースが含まれます。 これは、テスト ケースごとに O(n + m) の解が許容されることを意味しますが、インターリーブの数は組み合わせであり、非常に大きくなる可能性があるため、考えられるすべてのインターリーブを試行するアルゴリズムは実行不可能です。 

微妙なエッジ ケースは、すべての要素が負の場合です。 この場合、任意の要素を取得すると合計が減少するため、最大プレフィックス合計はゼロになります。 もう 1 つは、一方のシーケンスがすべて負の値を持ち、もう一方のシーケンスが正の値を持つ場合です。 アルゴリズムは、負のプレフィックスを完全にスキップする可能性があることに注意する必要があります。 

## アプローチ

 ブルート フォース アプローチでは、赤と青のシーケンスの有効なインターリーブをすべて生成し、それぞれの最大プレフィックス合計を計算しようとします。 長さのシーケンスなので$n + m$もっている$\binom{n+m}{n}$インターリーブにより、たとえ最大の制約 (n = m = 100) であっても、このアプローチは完全に非実用的になります。$10^{58}$計算。 

重要な洞察は、最大プレフィックス合計は、各カラー シーケンス内のプレフィックスの合計に独立してのみ依存するということです。 ある色のすべての要素を他の色の要素の前に配置できるため、赤のシーケンスの最良のプレフィックスの合計と青のシーケンスの最良のプレフィックスの合計を別々に取得することを考慮するだけで済みます。 最大の正の合計を持つ接頭辞を最初に配置しても問題はなく、合計は加算されます。 したがって、解決策は、赤色シーケンスの最大プレフィックス合計、青色シーケンスの最大プレフィックス合計を計算し、それらを合計することになりますが、負の寄与を考慮しないようにします (max とゼロを使用します)。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(n+m)) | O(n+m) | 遅すぎる |
 | 最適 | O(n + m) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.初期化`max_red`そして`max_blue`ゼロに。 これらには、それぞれ赤と青のシーケンスの最大プレフィックス合計が保存されます。 
2. 赤いシーケンスを繰り返します。 現在の合計を維持します。 各要素を追加したら更新します`max_red`累計がそれを超える場合。 これは、赤色のシーケンスのプレフィックスを取得することによって得られる最大の合計を見つけます。 
3. 青色のシーケンスに対してステップ 2 を繰り返し、結果を`max_blue`。 
4. 可能な最大値`f(a)`は`max_red + max_blue`。 両方のプレフィックスの合計が正の場合、プラスに寄与します。 負の合計は無視されます。 

これが機能する理由は、1 つのシーケンスの最大プレフィックス合計の後に要素を追加しても、最良の赤と青のプレフィックスの合計を超えて最大値を増やすことができないためです。 カラー内の順序は固定されているため、唯一の決定はシーケンスをどのようにインターリーブするかだけです。 それぞれから独立して最大のプラスの寄与を取得することで、グローバルな最大値が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    r = list(map(int, input().split()))
    m = int(input())
    b = list(map(int, input().split()))
    
    max_red = max_blue = 0
    curr_sum = 0
    for val in r:
        curr_sum += val
        if curr_sum > max_red:
            max_red = curr_sum
    
    curr_sum = 0
    for val in b:
        curr_sum += val
        if curr_sum > max_blue:
            max_blue = curr_sum
    
    print(max_red + max_blue)
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 各シーケンスについて、累計を維持し、最大プレフィックス合計を更新して、負のプレフィックスによって結果が減少しないようにします。 最良の赤のプレフィックスと最良の青のプレフィックスの合計により、各テスト ケースの答えが得られます。 青色のシーケンスを処理する前に、累計をリセットするように注意する必要があります。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | テスト ケースあたり O(n + m) | 各要素は、累計を計算するために 1 回だけアクセスされます。 
| スペース | O(1) おまけ | 現在の合計と最大値のみが保存されます。 入力配列が与えられます |

 最大 1000 のテスト ケースで、合計操作数は最大で$1000 \times (100 + 100) = 2 \times 10^5$、2秒の制限時間に簡単に収まります。 メモリ使用量は、512 MB の制限に比べれば無視できます。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    
    t = int(input())
    for _ in range(t):
        n = int(input())
        r = list(map(int, input().split()))
        m = int(input())
        b = list(map(int, input().split()))
        
        max_red = max_blue = 0
        curr_sum = 0
        for val in r:
            curr_sum += val
            max_red = max(max_red, curr_sum)
        
        curr_sum = 0
        for val in b:
            curr_sum += val
            max_blue = max(max_blue, curr_sum)
        
        print(max_red + max_blue)
    
    sys.stdout = sys.__stdout__
    return output.getvalue().strip()

# Provided samples
assert run("4\n4\n6 -5 7 -3\n3\n2 3 -4\n2\n1 1\n4\n10 -3 2 2\n5\n-1 -2 -3 -4 -5\n1\n0\n1\n0\n") == "13\n13\n0\n0", "samples"

# Custom cases
assert run("1\n1\n-10\n1\n-5\n") == "0", "all negative"
assert run("1\n3\n1 2 3\n2\n-1 -2\n") == "6", "positive and negative mix"
assert run("1\n5\n0 0 0 0 0\n5\n1 1 1 1 1\n") == "5", "zeros and positives"
assert run("1\n1\n100\n1\n100\n") == "200", "single large positives"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 -10 -5 | 0 | すべての負の数はゼロを生成します。 
| 3 1 2 3 -1 -2 | 6 | 赤と青の合計によるプラスの寄与 |
 | 5 つのゼロ、5 つの 1 | 5 | ゼロ寄与を正しく無視します。 
| 1 100、1 100 | 200 | 大きな単一要素の正の合計を正しく処理します。 

## 特殊なケース

 すべての要素が負の場合、たとえば赤 = [-10]、青 = [-5] の場合、累計は 0 を超えることはありません。 アルゴリズムが初期化されます`max_red`そして`max_blue`これにより、負のプレフィックスが誤って選択されることが回避されます。 

シーケンスにゼロが含まれる場合、これらは合計を減少させないため、有益であれば自然に含まれます。 たとえば、red = [0, 0]、blue = [1, 2]、max_red = 0、max_blue = 3、total = 3 は、最適なインターリーブと一致します。
