 ## 解決策
 ## 問題の理解

 平らでない地面に一連のフェンスセクションを配置するように求められます。 各セクションの幅は 1 で、高さは固定です。`k`。 セクション下の地面`i`高さがある`h_i`。 最初と最後のセクションは地面に直接触れる必要がありますが、中間セクションは地面から最大で任意の整数だけ持ち上げることができます。`k-1`。 連続するセクションは、少なくとも 1 の長さの垂直辺を共有する必要があります。これは、それらの上端が少なくとも 1 単位だけ垂直に重なる必要があることを意味します。 

入力には複数のテスト ケースが含まれており、それぞれのテスト ケースは次のようになります。`n`、`k`、および地盤の高さの配列。 制約を満たすフェンスを構築できる場合、出力は YES、そうでない場合は NO になります。 の値`n`2·10^5 と次の合計に達する可能性があります`n`すべてのテスト ケースにわたる も最大 2·10^5 です。 2 秒の時間制限があるため、O(n^2) 個のアプローチを除外して、各セクションをセクションごとに基本的に O(1) 時間で処理する必要があることを意味します。 

地盤が急激に変動すると、明らかではないエッジケースが発生します。 たとえば、次の場合`h = [3,0,2]`そして`k = 2`、最初のセクションは高さ 3、最後のセクションは 2 です。中間セクションの範囲は次のとおりです。`h_2`に`h_2 + k - 1 = 1`、ただし、最初のセクションとオーバーラップするには、少なくとも 2 の高さが必要です。ここではオーバーラップ要件は不可能であり、正解は NO です。 許容される隆起高さを考慮せずに、連続する地面レベルの差をチェックするだけの単純なアプローチは失敗する可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、間の各セクションで可能なすべての高さを試します。`h_i`そして`h_i + k - 1`オーバーラップ制約が満たされているかどうかを確認します。 これは、再帰的または反復的な探索で実装できます。 それは正しいですが、高さの組み合わせの数は指数関数的になります。`n`、そのため、すぐに実行不可能になります。`n`10^5 のオーダーです。 

問題を扱いやすくするための重要な観察は、各セクションで **可能な高さの範囲** を維持するだけでよいということです。`[low_i, high_i]`これらは前のセクションを考慮すると有効です。 最初のセクションについては、`low_1 = high_1 = h_1`。 セクション用`i`、新しい範囲は前のセクションの範囲によって制限されます`[low_{i-1}, high_{i-1}]`そして許可されたもの`k`-身長差。 具体的には、上部のオーバーラップは少なくとも 1 である必要があるため、次のセクションの高さは次の条件を満たす必要があります。`next_low <= previous_high + k - 1`そして`next_high >= previous_low - k + 1`。 この制約を自然な境界と交差させます`[h_i, h_i + k - 1]`。 交差点が空いている場合は、フェンスを設置できません。 これにより、問題はテスト ケースごとに O(n) に減ります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k^(n)) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.初期化`low`そして`high`最初のセクションでは両方とも等しい`h[0]`、最初のセクションは地面に立っていなければならないためです。 
2. 残りのセクションを 1 から n-1 まで繰り返します。 
3. 各セクションについて`i`、可能な最小の高さを計算します`next_low`として`max(h[i], low - (k - 1))`。 これにより、新しいセクションが地面よりも低くならず、前のセクションと少なくとも 1 単位だけ重なることが保証されます。 
4. 可能な最大の高さを計算します。`next_high`として`min(h[i] + k - 1, high + (k - 1))`。 これにより、新しいセクションが許容値を超えず、依然として前のセクションと重複することが保証されます。 
5. もし`next_low > next_high`、セクションに有効な高さがありません`i`。 NO を出力し、このテスト ケースの処理を停止します。 
6. それ以外の場合は更新します`low = next_low`そして`high = next_high`次のセクションに進みます。 
7. すべてのセクションを処理した後、最後のセクションの高さが確認されます。`h[n-1]`中にある`[low, high]`。 そうであれば、「YES」と出力してください。 それ以外の場合は、NO を出力します。 

機能する理由: アルゴリズムは、次の不変条件を維持します。`[low, high]`現在のセクションまでのフェンス制約を満たすすべての高さが含まれます。 オーバーラップ条件と許容される高さの範囲を使用して各ステップで範囲を更新することで、有効な構成が確実にキャプチャされます。 範囲が崩れると、有効な構成は存在しません。 この範囲の伝播により正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can_build_fence(n, k, h):
    low = high = h[0]
    for i in range(1, n):
        next_low = max(h[i], low - (k - 1))
        next_high = min(h[i] + k - 1, high + (k - 1))
        if next_low > next_high:
            return "NO"
        low, high = next_low, next_high
    if low <= h[-1] <= high:
        return "YES"
    else:
        return "NO"

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    h = list(map(int, input().split()))
    print(can_build_fence(n, k, h))
```機能`can_build_fence`範囲を維持します`[low, high]`各セクションごとに。`next_low`オーバーラップ制約とグラウンド制約の両方を確実に満たす一方で、`next_high`許可された最大高さを超えないようにします。 最終チェックでは、最後のセクションが正確に地面にあることを確認します。
