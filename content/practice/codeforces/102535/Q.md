 ## 問題の理解

 入力には、正の整数の 2 つのコレクションが含まれています。 最初のコレクションには、次の可能な値が含まれています。`k`、2番目には可能な塩基が含まれています`b`。 各コレクションから 1 つの値を選択して形成されるすべての可能なペアについて、そのペアがクールかどうかを判断する必要があります。 答えは、条件を満たすペアの数です。 

この条件は、繰り返し桁の和を計算することを必要としているように見えますが、重要なのは、基数のデジタル根です。`b`剰余モジュロによってのみ決定されます`b - 1`。 正の整数の場合`x`、そのベース`b`デジタル ルートは、からの一意の値です。`1`に`b - 1`それは以下と同じ余りを持つ`x`モジュロ`b - 1`、余り`0`に代表される`b - 1`。 

制限が非常に大きいため、すべてのペアをチェックすることは不可能です。 まであります`300000`各セットの値をあきらめて、`9 * 10^10`可能なペア。 入力サイズに対する 2 次アプローチは 2 秒に収まりません。 すべての値は最大であるため、`10^6`、意図したソリューションでは、すべてのペアを反復処理するのではなく、値の数値構造を利用する必要があります。 

よくある間違いは、乗算ごとにデジタル和をシミュレートすることです。 これは不必要であると同時に危険です。 たとえば、`k = 6`そして`b = 8`、シーケンスは値に基づいています。`0, 6, 12, 18, ..., 42`ただし、唯一の関連情報は、これらの値がモジュロでどのように動作するかです。`7`。 

もう 1 つのエッジケースは次のような場合です`b = 2`。 ここ`b - 1 = 1`、すべての整数は互いに素です`1`。 シーケンスには次のものだけが含まれます`f_2(0)`そして`f_2(k)`、だからすべての`k`有効なペアを形成します。 で除算しようとする実装`b - 1`このケースを考慮しないと失敗する可能性があります。 

最後のエッジケースは次のような場合です`k`そして`b - 1`要素を共有します。 例えば：```
Input:
1 1
6
4
```ここ`b - 1 = 3`。 値は次の乗算に基づいています。`6`モジュロ`3`したがって、ゼロ以外のすべての位置は同じデジタルルートに折りたたまれます。 正しい出力は次のとおりです`0`。 生成された少数の値のみをチェックするソリューションでは、パターンが順列であると誤って想定される可能性があります。 

## アプローチ

 直接的な解決策は、すべてのペアを試すことになります`(k, b)`。 ペアごとに値を計算します。`f_b(0), f_b(k), ..., f_b((b - 1)k)`からのすべての数字かどうかを確認します`0`に`b - 1`ちょうど 1 回出現します。 これは定義に直接従うため、正しいです。 ただし、最大の入力には次のものを含めることができます。`300000`両側に値があり、最大で`90000000000`ペア。 各シーケンスをチェックするコストを無視しても、ペアの数はすでに可能な数をはるかに超えています。 

有益な観察は、デジタル ルートをモジュラー演算に置き換えることから得られます。 させて`m = b - 1`。 シーケンスには以下が含まれます`f_b(ik)`のために`0 <= i <= m`。 のために`1 <= i <= m - 1`、値は正確に次の非ゼロ残基です。`ik mod m`、最後の値`f_b(mk)`は`m`余りがゼロになるからです。 

乗算`k`モジュロ`m`次の場合に限り、すべての残基を 1 回だけ生成します。`k`乗法逆モジュロを持ちます`m`。 それはまさに次のときに起こります`gcd(k, m) = 1`。 元の問題は、次の場合のペアを数えることに帰着します。`gcd(k, b - 1) = 1`。 

残りのタスクは、多くの共素性のクエリに答えることです。 固定値の場合`x = b - 1`、その個別の素約数を次のようにします。`p1, p2, ...`。 値`k`これらの素数の少なくとも 1 つで割り切れる場合、は無効です。 包含/除外により、有効な数が得られます。`k`値:`|K| - count(multiples of p1) - count(multiples of p2) + count(multiples of p1*p2) ...`100 万未満の数の異なる素因数の数は少ないため、このサブセットの列挙は高速です。 に含まれる値の数を事前に計算します。`K`の周波数配列を使用すると、すべての可能な約数で割り切れます。`K`。

## アルゴリズムのチュートリアル

 1. すべての値の周波数配列を構築します。`K`。 次に、すべての整数について計算します`d`、値はいくつあるか`K`で割り切れます`d`。 これにより、包含/除外クエリですべてをスキャンするのではなく、倍数のカウントを即座に要求できるようになります。`K`。 
2. までのすべての数値について最小の素因数を事前計算します。`10^6`。 これにより、あらゆる値が許可されます`b - 1`早く因数分解すること。 
3. 拠点ごとに`b`で`B`、 セット`x = b - 1`そして因数分解する`x`異なる素約数に変換します。 数値が少なくとも 1 つの素因数を共有するかどうかだけを考慮するため、異なる素数のみが重要です。`x`。 
4. これらの素数に対して包含/除外を使用します。 素数のすべてのサブセットについて、その積を計算します。 サブセット サイズが奇数の場合は、次の値の数を減算します。`K`その積で割り切れます。 サブセットのサイズが偶数の場合は、それを追加し直します。 
5. 結果のカウントを答えに加算します。 それぞれのカウント値は、現在のベースとの 1 つのクール ペアに正確に対応します。 

なぜ効果があるのか:

 ベース用`b`、デジタルルートのシーケンスは、次の値を乗算すると正確に順列になります。`k`すべての剰余を剰余で並べ替えます`b - 1`。 乗算演算は、乗数が法と全く素であるときのモジュラー剰余の置換です。 したがって、このペアはまさに次のようなときにクールです`gcd(k, b - 1) = 1`。 

包含/除外ステップでは、次の値が正確にカウントされます。`k`の素因数を含まないもの`b - 1`。 これらは、gcd が 1 に等しい場合の値であるため、すべての塩基が正しい数のクール ペアに寄与します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    K = list(map(int, input().split()))
    B = list(map(int, input().split()))

    MAXV = 10**6

    freq = [0] * (MAXV + 1)
    for x in K:
        freq[x] += 1

    divisible = [0] * (MAXV + 1)
    for d in range(1, MAXV + 1):
        s = 0
        for j in range(d, MAXV + 1, d):
            s += freq[j]
        divisible[d] = s

    spf = list(range(MAXV + 1))
    for i in range(2, int(MAXV ** 0.5) + 1):
        if spf[i] == i:
            for j in range(i * i, MAXV + 1, i):
                if spf[j] == j:
                    spf[j] = i

    def factorize(x):
        res = []
        while x > 1:
            p = spf[x]
            res.append(p)
            while x % p == 0:
                x //= p
        return res

    ans = 0

    for b in B:
        x = b - 1
        primes = factorize(x)

        bad = 0
        cnt = len(primes)

        def dfs(pos, prod, bits):
            nonlocal bad
            if pos == cnt:
                if bits:
                    if bits & 1:
                        bad += divisible[prod]
                    else:
                        bad -= divisible[prod]
                return
            dfs(pos + 1, prod, bits)
            dfs(pos + 1, prod * primes[pos], bits + 1)

        dfs(0, 1, 0)
        ans += len(K) - bad

    print(ans)

if __name__ == "__main__":
    solve()
```周波数配列には元のセットが保存されます`K`除数のカウントをサポートする形式で。 ネストされたループは次のように計算します。`divisible[d]`、これは要素の数です`K`で割り切れる`d`。 

最小の素因数配列は、標準的なふるいの最適化です。 因数分解中に考えられるすべての約数を試す代わりに`b - 1`、最小の素因数を繰り返し削除します。 累乗の累乗は 2 つの数値が互いに素であるかどうかには影響しないため、個別の因数のみが保存されます。 

再帰関数は、個別の素因数のサブセットを列挙します。 の`bits`value は、選択された要素の数を記録します。 奇数サイズのサブセットは削除する必要がある数値を表し、偶数サイズの空でないサブセットは追加され直されます。 空のサブセットは無視されます。 

Python の整数はオーバーフローしません。また、100 万未満の数値には異なる素約数を多く持つことができないため、再帰の深さは最大 7 です。

 ## 特殊なケース

 のために`b = 2`、係数は`1`。 因数分解では素数が返されないため、包含/除外では値が無効としてマークされません。 アルゴリズムはすべての値を加算します。`K`これは、すべての正の整数が互いに素であるという事実と一致します。`1`。 

値の場合、`k`～と因子を共有する`b - 1`、その因子を含む素数サブセットはそれらを削除します。 たとえば、`k = 6`そして`b = 4`、係数は`3`。 素因数リストは次のとおりです。`[3]`、および次の倍数の数`3`含まれています`6`, なので除外されます。 

大きな入力の場合、アルゴリズムはすべてを比較することはありません。`k`あらゆるものと`b`。 の塩基のみを処理します。`B`であり、それぞれが独自の小さな素因数セットを使用します。 これにより不可能な事態が回避されます`|K| * |B|`ペアの列挙。
