 ## 解決策
 ## 問題の理解

 飛行機のキャビンの簡略化されたモデルが与えられています。このモデルでは座席が列状に配置されており、各列には左から右にインデックス付けされた 6 つの座席が含まれています。 各列の中央は、3 番目の座席と 4 番目の座席の間の固定通路です。 この対称性のため、左側のすべての座席には、同じ列の右側に鏡面の対応する座席があります。 

一部の座席はすでに占有されており、占有されているすべての座席にミラーリングされたパートナーも占有されている場合にのみ構成が有効であると見なされます。 言い換えれば、座席が埋まるたびに、通路を挟んだ対称の座​​席も埋まる必要があります。 この対称性がどこかで崩れている場合、その構成は無効になります。 

課題は、現在の座席配置がこの対称条件を満たしているかどうかを判断することです。 

入力は複数の座席列を記述し、各列には正確に 6 つの座席が含まれます。 出力は、座席計画全体が鏡面対称ルールを尊重しているかどうかを示す単純な二者決定です。 

この制約は、行ごとに固定幅の構造を扱っていることを意味しているため、すべての座席を直接チェックするソリューションはグリッド サイズに対して線形時間で実行されます。 行数が多い場合でも、各行が一定数のチェックのみに寄与するため、これは効率的です。 

主なエッジケースは、座席が占有されているが、その鏡像位置にない場合です。 たとえば、単一行では次のようになります。 

入力:```
X . . . . .
```最初のシートは占有されていますが、その対称的なパートナー (6 番目のシート) は空であるため、これは無効です。 正しい構成では、両端が一致する必要があります。 

もう 1 つの微妙なケースは、1 つの行内では対称性が維持されるが、複数の行では対称性が失われる場合です。 各行は独立して条件を満たす必要があります。 グローバルな正確性は、通過するすべての行に依存します。 

## アプローチ

 この強引なアイデアは簡単です。列ごと、座席ごとに、その鏡張りの座席も占有されているかどうかを確認します。 これには、すべての行と行ごとの 6 つの位置すべてをスキャンし、直接比較して対称性を検証する必要があります。 各行のサイズは一定であるため、このアプローチは行数に対して線形時間で実行されます。 

重要な観察は、行間に相互作用がないことです。 対称制約は各行に対して完全にローカルであるため、単一行を超えて情報を伝播したり状態を維持したりする必要はありません。 これにより、複雑なデータ構造や貪欲な決定が不要になります。 この問題は、インデックスの固定ペアに対する直接的な検証チェックに帰着します。 

各列には 6 つの座席しかないため、最初の 3 つの位置をハードコーディングまたはループして、ミラーリングされた対応する座席と比較できます。 この問題は、検索や最適化の問題ではなく、単純な整合性チェックになります。

 ## アルゴリズムのチュートリアル

 対称性が複数の行にまたがることはないため、各行を個別に処理します。 各列について、中央の通路を中心に鏡映された座席の位置を比較するだけで済みます。 

1. 行数を読み取り、各行を長さ 6 の文字列として処理します。 各文字は、座席が占有されているか空席であるかを表します。 
2. 特定の行について、座席 0 と座席 5、座席 1 と座席 4、座席 2 と座席 3 を比較します。これらは、すべてのミラーリングされたペアを 1 回だけカバーするため、意味のある比較のみです。 
3. いずれかのペアの占有ステータスが異なる場合は、構成が無効であると直ちに結論付けます。 単一の違反が大域的対称性を破るので、早期に停止できます。 
4. すべての行がこのチェックに合格した場合、構成は有効です。 

3 つのペアだけをチェックする理由は、各行がこれらのミラー関係によって完全に決定されるためです。 それらを超えてチェックすると、新しい情報を追加せずに作業が重複してしまいます。 

### なぜ効果があるのか

 各行は独立しており、対称性はインデックス j と 5 − j のペアによって行内で厳密に定義されます。 このようなすべてのペアがすべての列で一致する場合、すべての占有座席には必要なミラー パートナーが存在します。 逆に、いずれかのペアが異なる場合、その席は直接条件に違反します。 これにより、チェックが正確であるために必要かつ十分になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    for _ in range(n):
        row = input().strip()
        
        if row[0] != row[5]:
            print("NO")
            return
        if row[1] != row[4]:
            print("NO")
            return
        if row[2] != row[3]:
            print("NO")
            return
    
    print("YES")

if __name__ == "__main__":
    solve()
```ソリューションは各行を読み取り、すぐに 3 つのミラー化された座席ペアをチェックします。 不一致が見つかると、残りの行のスキャンを続ける必要がないため、早期に終了することが重要です。 

すべての行に正確に 6 文字が含まれることが保証されているため、インデックス付けは固定されており安全です。 正しい文字列長を解析すること以外に、境界に関する懸念はありません。
