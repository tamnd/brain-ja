 ## 問題の理解

 整数の配列とステップ サイズが与えられます。`e`。 開始インデックスごとに`i`、すべてを取得することで部分列を形成できます。`e`- 番目の要素:`a[i], a[i+e], a[i+2e], ...`インデックスが配列の境界を超えない点まで。 このようなサブシーケンスごとに、同じ長さの連続するプレフィックスがいくつあるかを数えるように求められます。`k+1`素数となる積があります。 有効な各プレフィックスはペアに対応します`(i, k)`。 

重要な観察は、積が素数になるのは、その要素の 1 つが素数であり、残りが素数である場合のみであるということです。`1`s. これは、任意の素数に次より大きい別の整数を乗算するためです。`1`合成数を生成します。 したがって、素数が 0 個以上で囲まれた部分列を探すだけで済みます。`1`s、場合によってはステップ サイズで区切られる`e`。 他のすべての数値は有効なペアに寄与しません。 

制約は高いです。`n`到達できるすべてのテストケースにわたって`2 * 10^5`、各数値は最大です。`10^6`。 考えられるすべてのサブシーケンスを調べる単純なアプローチでは、次の値に比例する操作が必要になります。`O(n^2/e)`最悪の場合、遅すぎます。 どのソリューションでも、各配列をほぼ線形な時間で処理する必要があります。 

エッジケースには、すべてのシーケンスが含まれます。`1`s、プライムが最初または最後に現れるシーケンス、および`e`に等しい`1`(サブシーケンスが連続しているため) または次と等しい`n`(したがって、サブシーケンスには単一の要素が含まれます)。 たとえば、次の場合`a = [1, 2, 1]`と`e = 1`、有効なペアは 3 つあります。`(2, 0)`プライムのために`2`一人で、`(1, 1)`後続のために`[1,2]`与える`2`、 そして`(1, 2)`のために`[1,2,1]`与える`2`。 

## アプローチ

 ブルートフォースアプローチでは、すべての開始インデックスに対して反復処理が行われます。`i`そして可能な限りすべてを繰り返します`k`部分列の積を明示的に計算します。 次に、その商品がプライムかどうかを確認します。 これは文字通りすべての有効なペアをカウントするため、これは正しいです。 ただし、最悪の場合の操作数は次のとおりです。`n^2/e`までです`10^10`最大の入力に対して。 これは制限時間の 2 秒を明らかに超えています。 

重要な洞察は、積が素数になる唯一の方法は、部分列に素数が 1 つだけ存在し、残りが素数である場合であるということです。`1`s. これにより、問題は、素数の両側に任意の数の素数が隣接する配列の数を数えるという問題に縮小されます。`1`に沿って両側にあります`e`-ステップのサブシーケンス。 位置の各素数について`p`、 させて`l`連続した数になる`1`その前に（通り過ぎて）`e`） そして`r`連続数`1`その後です。 この場合、この素数によって寄与される有効なペアの数は次のようになります。`(l + 1) * (r + 1) - 1`。 の引き算`1`次の場合を削除します`k = 0`プライムが含まれていないため、無効です。 

それぞれを処理することでこれを実装できます。`e`独立したサブシーケンスを個別にスキャンし、それぞれを線形にスキャンして連続したものをカウントします`1`s と素数を識別します。 これにより、全体的な複雑さが軽減されます。`O(n)`テストケースごとに、これは実現可能です。

 ## アルゴリズムのチュートリアル

 1. 以下のすべての素数を事前計算します。`10^6`エラトステネスの篩を使って。 これにより、数値が素数であるかどうかを定数時間内にチェックできます。 
2. 各テスト ケースについて、次の内容を読んでください。`n`、`e`、および配列`a`。 
3. 配列を次のように分割します。`e`インデックスモジュロに基づく独立したサブシーケンス`e`。 インデックス用`i`、後続は`a[i], a[i+e], a[i+2e], ...`。 
4. 各サブシーケンスについて、連続したシーケンスを追跡しながらそれをトラバースします。`1`s は各素数の左側と右側にあります。 カウンタを初期化する`cnt`連続した期間の長さに対して`1`現在の要素の前。 位置に素数が見つかった場合`p`、連続してカウントする`1`s の後に前方にスキャンします。 
5. 位置にある素数の場合`p`と`l`その前のものと`r`それ以降、有効なペアの数は`(l + 1) * (r + 1) - 1`。 これを合計して答えの合計を求めます。 
6. テスト ケースの有効なペアの合計数を出力します。 

なぜ機能するのか: それぞれの有効なペアは、特定の数の部分列内の素数に対応します。`1`前後です。 式`(l + 1) * (r + 1) - 1`正確に 1 つの素数を含むすべての接頭辞をカウントします。これには、次のすべての組み合わせが含まれます。`1`その周りにあります。 サブシーケンスを個別に処理することで、ステップ サイズが確実に尊重されます。`e`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAX_A = 10**6 + 1
is_prime = [True] * MAX_A
is_prime[0] = is_prime[1] = False
for i in range(2, int(MAX_A ** 0.5) + 1):
    if is_prime[i]:
        for j in range(i*i, MAX_A, i):
            is_prime[j] = False

t = int(input())
for _ in range(t):
    n, e = map(int, input().split())
    a = list(map(int, input().split()))
    res = 0
    
    for start in range(e):
        seq = []
        for i in range(start, n, e):
            seq.append(a[i])
        
        ones_before = 0
        i = 0
        while i < len(seq):
            if seq[i] == 1:
                ones_before += 1
                i += 1
            elif is_prime[seq[i]]:
                ones_after = 0
                j = i + 1
                while j < len(seq) and seq[j] == 1:
                    ones_after += 1
                    j += 1
                res += (ones_before + 1) * (ones_after + 1) - 1
                ones_before = 0
                i = j
            else:
                ones_before = 0
                i += 1
    print(res)
```ふるいは以下の素数を事前計算します`10^6`、O(1) の素数チェックが可能になります。 各サブシーケンスは線形にスキャンされます。`ones_before`そして`ones_after`連続した回数の追跡`1`s、有効なものがすべて正しくカウントされていることを確認します`(i, k)`ペア。 ループは慎重にリセットされます`ones_before`合成数に遭遇したときに、素数を生成できないシーケンスを数えることを避けるために使用します。
