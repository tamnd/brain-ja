 ## 解決策
 ## 問題の理解

 サイズの長方形のフィールドを分割するように求められます$n \times m$アリスとボブの間。 フィールドには以下が含まれます$k$別個のセルに噴水があり、アリスは、要求できるセルの数を最大化するために、上または左側から下または右側に向かって右または下のみに移動する単調なパスを選択したいと考えています。 アリスのプロットには左下のセルが含まれている必要があります$(n, 1)$一方、ボブのプロットには右上のセルが含まれている必要があります。$(1, m)$。 

問題の簡単なバージョンでは、噴水ごとに、それをアリスに与えることで彼女の最大可能面積が増加するかどうかを判断するだけで済みます。 実際の面積を計算する必要はありません。 

重要な制約は非常に大きい$n$そして$m$まで$10^9$、 そして$k$まで$2 \cdot 10^5$。 これにより、グリッド全体を反復するソリューションは即座に除外されます。 この解決策は噴水自体の上でのみ機能する必要があります。 の合計$k$すべてのテスト ケースにわたって、次のように制限されます$2 \cdot 10^5$、これは線形の解決策を提案します。$k$テストケースごとに許容されます。 

噴水がコーナーに配置されている場合、微妙なエッジケースが発生します。 噴水が右上または左下の近くにある場合、アリスの最大進路が即座に制限される可能性があります。 たとえば、次の場合$n = m = 2$そして噴水はここにあります$(1, 2)$そして$(2, 2)$, アリスは右上のセルを要求することはできませんが、左下のセルを要求することはできます。 彼女の面積を増やすためにどの噴水が重要であるかを誤って認識するのはよくある間違いです。 

## アプローチ

 ブルートフォースアプローチでは、上端または左端のすべての有効な開始セルからすべての単調パスを試行し、結果としてアリスの面積を計算し、各噴水を彼女に与えるシミュレーションを行って面積が増加するかどうかを確認します。 Even ignoring the$10^9 \times 10^9$グリッド サイズ、パスの数は指数関数的です$n + m$, したがって、このアプローチは実行不可能です。 

重要な観察は、対角線に沿った極端な位置にある噴水のみが重要であるということです。 アリスのプロットは、上/左から下/右へのパスによって制限されます。 アリスの左下の開始位置よりも「さらに上または右」にある噴水は、アリスの到達可能な最大エリアを減らす可能性があります。 具体的には、噴水なしでアリスが主張できる最大エリアは、最大の行または最大の列を持つ噴水によって決まります。噴水は彼女の進路を妨げるためです。 させて`max_r`噴水の中で最大の列であること、および`max_c`最大の列。 次に、アリスが要求できるセルの最大数は、次のいずれか小さい方になります。$(n - min_r + 1) * (m - min_c + 1)$単調なパスに沿って進みますが、簡単なバージョンでは、ゼロ以外のインジケーターのみが必要です。 

アリスに噴水を与えると、その噴水が現在彼女をブロックしている最大行または最大列を厳密に超えている場合、彼女の到達可能なエリアが増加します。 したがって、各噴水について、それがアリスを制限する最大行または最大列にあるかどうかを単純にチェックします。 この観察により、解決策は次のように簡略化されます。$O(k)$テストケースごとに合格します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(n+m)) | O(n*m) | 遅すぎる |
 | 最適 | O(k) | O(k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$、$m$、 そして$k$。 次に、すべての噴水の座標を読み取ります。 
2. 最大行を追跡するために変数を初期化します (`max_r`) および最大列 (`max_c`）噴水の間で。 
3. 噴水のリストを一度調べて更新します`max_r`そして`max_c`最大の行と列の値を見つけます。 
4. アリスが噴水を利用せずに主張できる最大エリアは、噴水を避けることに相当します。`max_r`そして`max_c`。 簡易版では出力するだけです`1`いずれかのエリアが可能な場合 (つまり、フィールドが開始行または列の噴水によって完全にブロックされていない場合)、そうでない場合`0`。 通常、これは次のようになります`1`なぜなら$n, m \ge 2$そして$k \le n*m - 1$。 
5. 各噴水について、出力`1`噴水に次の列がある場合`max_r`または次の列に等しい`max_c`-これは、この噴水をアリスに与えると、彼女の到達可能なエリアが増加することを示しています。 それ以外の場合は出力`0`。 
6. すべてのテスト ケースについて上記を繰り返します。 

重要な不変条件は、アリスの可能な最大のプロットが行方向と列方向の「最も遠い」噴水によってのみ制約されるということです。 これらの端にない噴水は、到達可能な最大エリアを変更しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        fountains = [tuple(map(int, input().split())) for _ in range(k)]
        
        # Determine limiting fountains
        max_r = max(r for r, c in fountains)
        max_c = max(c for r, c in fountains)
        
        # In the easy version, Alice can always claim at least one cell
        print(1)
        
        result = []
        for r, c in fountains:
            if r == max_r or c == max_c:
                result.append("1")
            else:
                result.append("0")
        print(" ".join(result))

if __name__ == "__main__":
    solve()
```コードは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 噴水間の最大の行と列を計算して、アリスの領域に対する極度の制約を決定します。 次に、各噴水がアリスのエリアを拡張できるかどうかがチェックされます。 出力は、各テスト ケースに必要な形式になります。
