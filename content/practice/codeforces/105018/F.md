## アルゴリズムのチュートリアル

 単一の状態変数の観点からプロセスを書き直します。 現在の状態を次のようにします`m = n / gcd(R, n)`。 最初は`R = 1`、 それで`m = n`。 プロセスは次の時点で終了します`m = 1`。 

それぞれのステップが倍増します`R`ランダムで`a`。 状態への影響は方法によってのみ異なります`a`～と要素を共有する`m`。 もし`g = gcd(a, m)`、その後、新しい状態は次のようになります`m / g`。 これにより、問題は次の約数間の遷移に帰着します。`n`。 

ここで期待値を計算します`E[m]`、状態に到達するために必要な予想されるステップ数`1`から始まる`m`。 

1. すべての約数を列挙します`n`。 到達可能なすべての状態は、これらの約数の 1 つです。 
2. オイラーの合計値を事前計算する`phi(x)`まで`10^6`。 これにより、範囲内で特定の gcd 構造を持つ数値がいくつあるかを数えることができます。 
3.固定状態の場合`m`、次のすべての状態への遷移確率を計算します。`m / g`、 どこ`g`分割する`m`。 
4. ランダムな結果が得られる確率`a`もっている`gcd(a, m) = g`は`phi(m / g) / m`、まさにそれ以来`phi(m/g)`剰余モジュロ`m`その gcd パターンがあり、リフティングすると`[0, n-1]`均一な周波数を維持します。 
5. 繰り返しを書く`E[m] = 1 + sum over g|m of (phi(m/g)/m) * E[m/g]`、 と`E[1] = 0`。 
6. 状態を降順で評価します。`m`、それですべてが`E[m/g]`処理時にすでに計算されています`m`。 

すべての遷移が厳密に削減されるため、順序付けは機能します。`m`。 

### なぜ効果があるのか

 プロセス全体は、乗算が共有素因数にどのような影響を与えるかによって決まります。`n`。 同じものを持つ 2 つの異なる残基`gcd`と`n`乗算はすでに存在する素数による割り算とのみ相互作用するため、分布においても同様に進化します。`n`。 これにより、完全なマルコフ連鎖が約数の格子に折りたたまれ、各遷移が要素を厳密に削除します。`m`。 したがって、反復により、吸収状態に達するまでの予想される打撃時間を正確に把握できます。`m = 1`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXN = 10**6

# sieve for phi
phi = list(range(MAXN + 1))
for i in range(2, MAXN + 1):
    if phi[i] == i:  # prime
        for j in range(i, MAXN + 1, i):
            phi[j] -= phi[j] // i

def get_divisors(x):
    divs = []
    i = 1
    while i * i <= x:
        if x % i == 0:
            divs.append(i)
            if i * i != x:
                divs.append(x // i)
        i += 1
    return divs

t = int(input())
for _ in range(t):
    n = int(input())

    if n == 1:
        print("0.000000")
        continue

    divs = get_divisors(n)
    divs.sort(reverse=True)

    idx = {d: i for i, d in enumerate(divs)}
    E = {}

    for m in divs:
        if m == 1:
            E[m] = 0.0
            continue

        res = 1.0
        for g in divs:
            if g > m:
                continue
            if m % g != 0:
                continue
            # transition m -> m/g
            p = phi[m // g] / m
            res += p * E[m // g]

        E[m] = res

    print(f"{E[n]:.6f}")
```実装はオイラーのトーティエント関数のグローバルふるいから始まり、各確率項が次のようになります。`phi(m/g)`一定時間でアクセスできる。 各テスト ケースについて、次のすべての約数を列挙します。`n`それらを降順に並べ替えて、計算時に`E[m]`、すべての州`E[m/g]`のために`g > 1`はすでに知られています。 

因子の数は任意であるため、因子を介したネストされたループは許容されます。`n ≤ 10^6`は小さいままであり、各遷移は有効な除数のペアのみを考慮します。 浮動小数点漸化式は、数学的な期待方程式を直接反映しています。`E[1]`ゼロに固定されています。 

## 実用的な例

 ### 例 1: n = 2

 約数は`{2, 1}`。 順番に計算していきます`2 → 1`。 

| メートル | 方程式 | 値 |
 | --- | --- | --- |
 | 1 | E[1] = 0 | 0 |
 | 2 | E[2] = 1 + (ファイ(2)/2)*E[2] + (ファイ(1)/2)*E[1] | 1 + (1/2)E[2] |

 解決中`E[2] = 1 + 0.5 E[2]`与える`E[2] = 2`。 

これは、たとえ最小の非自明なものであっても、`n`、繰り返しによってすでに自己ループ確率が取得されており、期待時間が 1 を超えて増加します。 

### 例 2: n = 9

 約数は`{9, 3, 1}`。 

| メートル | 方程式 | 値 |
 | --- | --- | --- |
 | 1 | E[1] = 0 | 0 |
 | 3 | E[3] = 1 + (2/3)E[3] | 3 |
 | 9 | E[9] = 1 + (2/9)E[9] + (2/9)E[3] | 9 |

 中間状態`3`必要な素因数の部分的な累積を反映しており、プロセスは完了するまでに部分的な進行の間で変動する可能性があるため、最終的な値は増加します。 

これらのトレースは、DP が問題を単一ステップの吸収として扱うのではなく、中間除数状態を正しく処理していることを確認します。

 ## 特殊なケース

 のために`n = 1`、除数セットには、`{1}`、したがってDPはすぐに割り当てます`E[1] = 0`遷移ロジックを入力せずにゼロを返します。 これにより、ゼロによる除算が回避され、不必要な確率計算が防止されます。 

プライム用`n`、 のような`n = 3`、除数グラフには 2 つのノードしかありません。 漸化式は自己ループ項を含む単一の線形方程式となり、解は成功までに繰り返される失敗を正確に考慮します。 

のような主要な権限については、`n = p^k`、約数の連鎖は線形数列を形成します。 各状態はより小さいべき乗にのみ遷移し、DP はプロセスを単一のジャンプとして扱うのではなく、すべての中間因子レベルにわたって予想される待ち時間を正しく累積します。
