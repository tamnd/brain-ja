 ## 解決策
 ## 問題の理解

 開き括弧と閉じ括弧のみで構成される文字列が与えられます。 文字列は古典的な意味で「バランスが取れている」ことが保証されており、文字の間にプラス記号と 1 を挿入すると、有効な算術式に変換できることを意味します。 これは、括弧のシーケンスが適切に形成されていると言うのと同じです。 

その後、攻撃者は文字列の連続したセグメントを選択し、それを反転します。 どのセグメントが反転されたかはわかりません。 結果として生じる文字列のバランスが取れなくなる可能性があります。 

私たちの仕事は、任意のセグメントを再度選択し、それをもう一度反転して、最終的な弦のバランスを再び整えることです。 このようなセグメントを記述する有効なインデックスのペアを出力する必要があります。 

主な難点は、恣意的な損傷を修復しているのではなく、もともと有効な構造に適用された 1 つの反転を具体的に取り消していることです。 この制限により、「損害」がどのようなものであるかが大きく制限されます。 

入力サイズでは、最大 10^3 のテスト ケース (全長が最大 10^4) が許可されます。 これは、定数係数が小さい場合にのみ、テスト ケースごとの O(n^2) 以下の解が許容されることを意味しますが、実際には、テストごとに線形または線形に近い動作を目指す必要があります。 

単純な考えは、すべてのセグメントを試し、それらを逆にして、妥当性をチェックすることです。 各チェックは O(n) であり、明らかにスケーリングできないため、テスト ケースごとの合計は O(n^3) になります。 

もう 1 つの微妙な障害モードは、元の文字列を復元する必要があると仮定した場合です。 それは必須ではありません。 元の文字列と異なっていても、1 回反転した後の有効な括弧シーケンスは受け入れられます。 

## アプローチ

 ブルート フォース ソリューションでは、インデックス i と j のすべてのペアが考慮され、部分文字列が反転され、結果のシーケンスがバランスが取れているかどうかがチェックされます。 これは、許可された操作の検索空間全体を明示的に探索するため機能します。 あらゆる可能性をテストするので、正しさは簡単です。 

ただし、コストは法外です。 O(n^2) 個のセグメントがあり、それぞれを検証するには文字列全体をスキャンする必要があり、テスト ケースごとに O(n^3) 時間がかかります。 最悪の場合、n は最大 5000 となり、これは実現可能な限界をはるかに超えています。 

重要な観察は、私たちが恣意的な修正を探しているのではなく、特にバランスの取れた文字列の最初の反転の後に妥当性を回復する 2 番目の反転を探しているということです。 バランスの取れたブラケット シーケンスは非常に厳格な構造を持っています。すべてのプレフィックスのバランスが負ではなく、全体のバランスはゼロです。 部分文字列を反転すると、プレフィックス合計に対するそのセグメントの寄与が変わるだけであり、導入されるグローバルな不均衡は高度に構造化されています。 

構造の再配置という観点から考える代わりに、接頭辞の合計の観点に切り替えます。 「(」は +1、「)」は -1 として扱います。 バランスの取れた文字列には、負になることがなく、ゼロで終わるプレフィックスの合計が含まれます。 単一セグメントの反転後、別の反転で構造を修正する唯一の方法は、誤ったプレフィックス ディップを有効な形状に「再配置」するセグメントを選択することです。 重要な洞察は、プレフィックスの最小位置とサフィックスの最大位置を組み合わせ、最も「負圧」の高い領域を補償領域と効果的に交換することで、常に有効なセグメントを見つけることができるということです。 

これにより、建設的な戦略が導き出されます。つまり、プレフィックスの合計が最小となる点と最大となる別の点を特定し、それらの間のセグメントを反転します。 この操作は、最初の反転によって生じた不均衡を、負でないプレフィックス合計を再度強制する方法で再分配するため、バランス制約を復元します。

 ## アルゴリズムのチュートリアル

 「(」を +1、「)」を -1 として扱い、プレフィックスの合計を計算します。

1. 文字列全体のプレフィックスの合計を計算し、プレフィックスの合計が最小となるインデックスと最大となるインデックスを追跡します。 これら 2 つの位置は、バランスにおける最も深刻な下方および上方の偏りを捉えます。 
2. i を最小プレフィックス合計インデックスの後の位置、j を最大プレフィックス合計インデックスとする。 これらは、反転するセグメントの候補です。 
3. i と j を選択したセグメントとして出力します。 

極端なプレフィックス位置を選択する背後にある直観は、セグメントを反転すると、セグメント内の寄与の順序が入れ替わるということです。 最も深い落ち込みの後に始まり、最も高いピークで終わるセグメントには、単調なバランス形状を崩す原因となる領域が正確に含まれています。 

1. 構築されたセグメントが自明または無効である場合 (i ≥ j)、フォールバック セグメント (通常は完全な文字列) を選択して調整します。 これが機能するのは、文字列全体を反転すると、バランスの取れた構造の有効性が維持されるからです。 

### なぜ効果があるのか

 バランスのとれたブラケット シーケンスのプレフィックスの合計は、Dyck パスのように動作します。つまり、ゼロから始まり、非負の値を維持し、ゼロに戻ります。 部分文字列を 1 回反転すると、このパスの連続した部分が 1 つ歪みます。 パスの最も深い点は、歪みがシーケンスを最も強く下方向に引っ張る場所を特定し、最も高い点は、補償する上向きの構造を特定します。 

これら 2 つの極値の間のセグメントを反転すると、乱れた領域が効果的に反映されて整列に戻ります。 これにより、以前の最も低いセグメントがプレフィックスにとって重要な場所に配置されなくなるため、プレフィックスの合計がゼロを下回らないという特性が復元されます。 反転しても「(」と「)」の合計数は変わらないため、グローバル合計はゼロのままです。 

したがって、構築された演算により、バランスの取れたブラケット シーケンスに正確に対応する有効な Dyck パスが再度保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input().strip())
        s = input().strip()

        pref = 0
        min_pref = 0
        max_pref = 0
        min_pos = 0
        max_pos = 0

        for i, ch in enumerate(s):
            if ch == '(':
                pref += 1
            else:
                pref -= 1

            if pref < min_pref:
                min_pref = pref
                min_pos = i + 1
            if pref > max_pref:
                max_pref = pref
                max_pos = i + 1

        i = min(min_pos, max_pos) + 1
        j = max(min_pos, max_pos)

        if i >= j:
            i, j = 1, n

        print(i, j)

if __name__ == "__main__":
    solve()
```この実装では、1 つのパスでプレフィックスのバランスが直接計算されます。 出力ではセグメント境界がその形式で想定されているため、位置は 1 から始まるインデックスで保存されます。 最終調整により、極端な位置が一致する縮退の場合でも、有効な空でないセグメントが保証されます。 

この構築フレームワーク内により適切な修正セグメントが存在しない場合、バランスのとれたシーケンスは完全な反転の下でもバランスが保たれるため、ストリング全体を反転するフォールバックは安全です。

 ## 特殊なケース

 重要なエッジ ケースは、プレフィックスの最小値と最大値が同じ位置または隣接する位置で発生する場合です。 その場合、構築されたセグメントは空または無効になります。 アルゴリズムは、文字列全体の反転にフォールバックすることでこれを処理します。これにより、入力がバランスのとれたシーケンスの 1 回の反転から生じているという保証の下で、常に有効な答えが生成されます。 

もう 1 つの微妙なケースは、複数の位置が同じ最小または最大プレフィックス値を共有する場合です。 正しさは一意性ではなく極端性に依存するため、それらのいずれも受け入れられます。 このアルゴリズムは、保存された極値を改善する最初の発生を記録するだけであり、構築には十分です。
