 ## 解決策
 ## 問題の理解

 2 つの正の整数を構築しようとしています$a$そして$b$、 と$a \le b$、最大公約数と最小公倍数を含む非常に特殊な算術制約の下で。 各テストケースの目標値$x$与えられているので選ばなければなりません$a$そして$b$の合計が$\gcd(a,b)$そして$\mathrm{lcm}(a,b)$等しい$x$。 すべての有効なペアのうち、次のペアが必要です。$b - a$できるだけ小さいです。 

重要な難点は、$\gcd$そして$\mathrm{lcm}$独立していない。 それらはアイデンティティを通じて緊密に結合されています$$a \cdot b = \gcd(a,b) \cdot \mathrm{lcm}(a,b).$$これは、gcd を修正すると、両方の数値の構造が制約され、検索空間が恣意的ではなく高度に構造化されることを意味します。 

入力スケールでは、最大 100 個のテスト ケースと値を使用できます。$x$まで$10^9$。 すべてのペアを試すあらゆるアプローチ$x$テストケースごとに次のオーダーが必要になります$10^{18}$実行可能な限界をはるかに超えた最悪の場合の操作。 すべての候補ペアに対してすべての約数を試しても、大きな制限がない限り、時間がかかりすぎます。 

よく起こる単純な間違いは、gcd 値を固定するだけで、lcm が残りを埋める 2 つの数値を個別に選択できると仮定することです。 たとえば、次の場合$x = 10$、次のようなランダムなペアを試してみることもできます$(2,8)$または$(3,6)$しかし、ほとんどのペアは失敗します。$\gcd + \mathrm{lcm}$小さな摂動の下では安定しません。 を選択すると、別の微妙な故障モードが表示されます。$a = \gcd$そして$b = \mathrm{lcm}$これら 2 つの値は一般に、同じ gcd と lcm を生成する実際の数値として互換性がないため、有効なペアが得られることはほとんどありません。 

実際の構造は、約数を分離する方法で条件を書き換えることに隠れます。$x$。 

## アプローチ

 定義式は次のとおりです。$$\gcd(a,b) + \mathrm{lcm}(a,b) = x.$$させて$g = \gcd(a,b)$。 We can write$a = g \cdot p$、$b = g \cdot q$、 どこ$\gcd(p,q) = 1$。 それから$$\mathrm{lcm}(a,b) = g \cdot p \cdot q.$$方程式に代入すると次のようになります。$$g + g p q = x \quad \Rightarrow \quad g(1 + pq) = x.$$これにより、問題は次の因数分解を求めるようになります。$x$の中へ$g$そして$1 + pq$。 2 番目の要素は特に重要です。これは 2 つの互いに素な整数の積より 1 大きい値です。 

ブルートフォース戦略ではすべてのペアを試します$(a,b)$まで$x$、gcdとlcmを計算し、条件を確認します。 つまり$O(x^2)$、小さな入力でも不可能です。 

重要な観察は、一度修正すると、$g$、残りの期間$t = x / g - 1$次のように表現できる必要があります$p q$と$\gcd(p,q) = 1$。 これにより、タスクが次の約数の反復処理に減ります。$t$そして有効な分割を構築します。 すべての有効な構造の中で、最小限に抑えることを好みます。$b - a = g(q - p)$、これは次の因子ペアを選択することと同じです。$t$最も近いもの。 

したがって、数値のすべてのペアから次の値までの検索スペースを削減します。$x$の約数を反復する$x$そして導出された商を因数分解する。

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

1. すべての約数を反復処理します。$g$の$x$。 までの値を確認するだけで済みます。$\sqrt{x}$、すべての約数には補数のペアがあるためです。 
2. それぞれの約数候補について$g$、計算する$t = x / g - 1$。 これは製品を表します$p \cdot q$。 
3. もし$t \le 0$、正の因数分解が存在しないため、この除数はスキップします。 
4. 約数を列挙する$p$の$t$。 それぞれについて$p$、 させて$q = t / p$。 
5. かどうかを確認します。$\gcd(p, q) = 1$。 この条件により、元の共素要件の下で構築が有効であることが保証されます。 
6. 有効なペアごとに$(p,q)$、候補値を計算します$a = g \cdot p$、$b = g \cdot q$、そして確実に$a \le b$。 
7. 最小化するペアを追跡します。$b - a$。 
8. 最適なペアを出力します。 

最小限にする理由$b - a$最小化する$q - p$固定用$g$それはスケーリングですか$g$順序付けと線形差分を保持します。 したがって、効果的に最も近い因子ペアを選択することになります。$t$共素性制約を満たします。 

### なぜ効果があるのか

 すべての有効なソリューションは、次の選択肢に一意に対応します。$g$分割する$x$そして因数分解$x/g - 1 = pq$と$\gcd(p,q) = 1$。 逆に、そのような構造はすべて有効な構造を生成します。$(a,b)$元の方程式を満たします。 除数の反復によってすべての可能性が列挙され、最小の差が明示的に選択されるため、有効な最適解が見逃されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def divisors(n):
    small, large = [], []
    i = 1
    while i * i <= n:
        if n % i == 0:
            small.append(i)
            if i * i != n:
                large.append(n // i)
        i += 1
    return small + large[::-1]

def solve():
    t = int(input())
    for _ in range(t):
        x = int(input())

        best_a = 1
        best_b = x

        # iterate over g = gcd(a,b)
        i = 1
        while i * i <= x:
            if x % i == 0:
                for g in (i, x // i):
                    if g == 0:
                        continue
                    tval = x // g - 1
                    if tval <= 0:
                        continue

                    # factor tval
                    j = 1
                    while j * j <= tval:
                        if tval % j == 0:
                            for p in (j, tval // j):
                                q = tval // p
                                if math.gcd(p, q) == 1:
                                    a = g * p
                                    b = g * q
                                    if a > b:
                                        a, b = b, a
                                    if b - a < best_b - best_a:
                                        best_a, best_b = a, b
                        j += 1
            i += 1

        print(best_a, best_b)

if __name__ == "__main__":
    solve()
```コードは分解の直後に続きます$a = g p$、$b = g q$。 外側のループは、考えられるすべての gcd 値を列挙します。$g$の約数として$x$。 そういったそれぞれに対して$g$、縮小積制約を計算します。$t = x/g - 1$、次に、次のすべての因子ペアを列挙します。$t$。 

gcd チェックは非常に重要です。 強制せずに$\gcd(p,q)=1$の場合、共有因子によって両方の値が誤って増大するため、再構成されたペアは gcd と lcm の元の構造に違反します。 

スワッピング$a$そして$b$出力制約を保証します$a \le b$比較する前に常に満たされます。

        while i * i <= n:
            if n % i == 0:
                res.append(i)
                if i * i != n:
                    res.append(n // i)
            i += 1
        return res

    t = int(input())
    out = []

 ## 特殊なケース

 のために$x = 2$、可能な唯一の構築は、$g = 1$、与える$t = 1$。 唯一の因子ペアは$(1,1)$、生産$(a,b) = (1,1)$。 除数ループにはまだ含まれているため、アルゴリズムはこれをきれいに処理します。$g = 1$、および因子の列挙$t$自明なペアが含まれます。 

のために$x = p$素数、唯一の約数は$1$そして$p$。 いつ$g = p$、$t = 0$そしてスキップされる。 いつ$g = 1$、我々は次のように還元します$t = p - 1$、そして、唯一の有効な構造は、可能であれば対称ペアに崩壊することがよくあります。 アルゴリズムは、次のすべての因子ペアを正確に探索します。$p - 1$、候補者を逃さないようにします。 

次のような平方数の場合$x = 16$、複数の gcd 選択肢が存在し、アルゴリズムは自然により大きいものを優先します。$g$差が縮まるため、価値観が変わる$b-a$。 例えば、$g = 4$収量$t = 3$、タイトなペアを提供します$(4,4)$、より広範な分解を支配します。
