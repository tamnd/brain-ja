 ## 解決策
 ## 問題の理解

 1 つの固定凸多角形 A と、他の複数の凸多角形 B₁ ～ Bₖ が与えられます。 最初は、すべての Bi が A の内部と強い意味で重なっています。これは、単に接触しているだけでなく、正の領域の交差があることを意味します。 

単一の並進ベクトル (dx, dy) によって A を移動することができます。 移動後、A が Bi の内部と重ならないようにします。 境界線に接触することは許可されますが、正の領域の交差は禁止されます。 各翻訳には |dx| に等しいコストがかかります。 + |dy| なので、移動は平面内の L1 距離で測定されます。 タスクは、A がすべての Bi から内部で素になるように A を変換する可能な最小コストを見つけ、その最小値の上限を出力することです。 

重要な問題は幾何学的なものです。各 Bi は A の一連の禁止された変換を定義しており、L1 メトリックの下でこれらすべての禁止領域の外側の最も安価な点が必要です。 

制約は大きく、すべての Bi にわたるポリゴン頂点の総数は最大 75,000 であり、A 自体も最大 75,000 の頂点を持つことができます。 これにより、二次幾何学またはペアワイズ頂点相互作用を使用して A を各 Bi と比較するアプローチが除外されます。 凸構造で大幅に最適化しない限り、O(nk) や O(n log n · k) であっても遅すぎます。 

微妙なエッジ ケースは、最適な変換が実行可能性の境界に正確に存在する可能性があることです。この場合、A は Bi の一部に接触するだけです。 もう 1 つは、複数の Bi 制約が重なり合っていて、結合された交差部分のみが問題となる場合です。 各 Bi を独立して処理し、ある方向に必要な最大変位を取得する単純なアプローチは、拘束が軸に揃えられておらず、ミンコフスキー ジオメトリを通じて相互作用するため、失敗します。 

## アプローチ

 中心的な観察は、すべての Bi と交差しなくなるまで A を平行移動することは、平面内の点 (dx, dy) を移動することと同等であり、各 Bi がこの平行移動空間内に禁止領域を誘導することです。 

Biを1つ修正します。 t による変換後に A が Bi と交差するという条件は、変換された多角形 A + t が Bi と交差するということと同じです。 これは、t がミンコフスキー差分領域 Bi ⊖ A にある、より正確には Bi のミンコフスキー和と A の反射から導出される領域にあると言うのと同じです。両方の多角形が凸であるため、この領域も凸です。 

したがって、各 Bi について、変換空間で凸状の禁止領域 Fi が得られます。 |dx| を最小化するすべての Fi の外側の点 t が必要です。 + |ディ|。 

すべての禁止領域を直接操作する代わりに、ビューを反転します。 原点から Fi の和集合の補数までの最小 L1 距離が必要です。これは、原点から Fi の和集合の境界までの最小 L1 距離を見つけることと同じです。 すべての Fi は凸であるため、結合境界は凸曲線の一部で構成されますが、結合を明示的に構築するのはコストがかかりすぎます。 

重要な構造の簡素化は、方向性サポート機能に切り替えることです。 固定方向 u の場合、u に沿った A + t の最も遠い範囲が Bi と重なってはなりません。 これにより、各 Bi が t の線形射影の制約に変換されます。 

単位方向 u について、多角形 P のサポート関数として hP(u) を定義します。すると、投影間隔が重なるような方向 u が存在する場合に限り、A + t は Bi と交差します。これは次のように表すことができます。 

hA(u) + u・t ≥ hBi(u) および hA(-u) + u・t ≤ hBi(-u) が同時に成立します。 

書き換えると、次の形式の制約が与えられます。 

hBi(-u) - hA(-u) ≤ u・t ≤ hBi(u) - hA(u)

 したがって、各 Bi は、方向 u への t のスカラー射影に対する区間制約に寄与します。

固定方向 u の場合、すべての Bi 制約は u・t のグローバル区間 [L(u), R(u)] に交差します。 変換 t は、すべての方向 u、u・t がこの区間内にある場合にのみ実行可能です。 |dx| を最小化する t を見つけたいと思います。 + |ディ| それはそのようなすべての制約に違反します。 

二重ビューは次のようになります。これらすべての方向性ストリップによって定義される実行可能領域に接する原点を中心とする最小の L1 ボールを見つけます。 L1 ボールの境界は 4 つの方向によって形成されるため、考慮する必要があるのはポリゴン エッジから導出される臨界方向の有限セットだけです。 

最後の重要な簡略化は、関連するすべての制約が A および Bi ポリゴンのエッジ法線から得られることです。 したがって、問題を凸多角形のミンコフスキー和の計算と、凸集合間の最小 L1 分離問題の解決に還元することができ、これは 4 方向の極値点の計算と間隔制約の結合に還元されます。 

すべてが 4 つの L1 方向 (x+y、x−y、−x+y、−x−y) に投影されると、各方向のすべての Bi にわたって実行可能な最大および最小の投影を維持することが問題になります。 答えは、原点を中心とする L1 ダイアモンドが実行可能領域の補数に接するように必要な最小のスケーリング係数によって決まります。 

これにより、問題は Bi ごとに、A と Bi のサポート関数から導出される 4 つの線形制約への一定の寄与を計算するというものに軽減されます。 これらは、凸多角形の回転キャリパーを使用して効率的に計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ペアごとの総当たりミンコフスキー | O(nk(n+m)) | O(n+m) | 遅すぎる |
 | サポート機能+4方向減速 | O(合計頂点 log n) | O(頂点の合計) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 凸包がまだ保証されていない場合は、A の凸包表現を計算します。 それが CCW 順序で保存されていることを確認し、方向ごとに線形時間でサポート機能のクエリに備えます。 
2. 各 Bi について、それを凸多角形として扱い、サポート クエリ用に準備します。 ミンコフスキー和を明示的に構築することは決してありません。 代わりに、サポート機能の違いに依存します。 
3. 固定方向 u の場合、凸多角形上で 2 ポインターまたは回転キャリパー アプローチを使用して、hA(u)、hA(-u)、hBi(u)、および hBi(-u) を計算します。 これが機能するのは、凸多角形に対するサポート関数のクエリが、単調な角度スイープ全体にわたって方向ごとに償却 O(1) で維持できるためです。 
4. これらの値から、u・t の区間制約を導出します。変換は Bi 固有の区間を満たさなければなりません。 すべての Bi にわたってこれらの間隔を交差させて、グローバルな実行可能間隔 [L(u), R(u)] を取得します。 
5. 4 つの L1 臨界方向 u ∈ {(1,1), (1,-1), (-1,1), (-1,-1)} について上記を繰り返します。 これらの方向は L1 ユニット ボールを完全に特徴付けるため、これらの方向の実現可能性は、バイオレーションまでの L1 距離を決定するのに十分です。 
6. 各方向について、実行可能な間隔を離れる前に原点からどのくらいの距離まで移動できるかを計算します。 これにより、|dx|+|dy| の候補が得られます。 その軸に沿って分解します。 
7. 4 つの方向の境界を組み合わせて、禁止領域に最初に接触する原点を中心とする L1 ひし形の最小スケーリングを計算します。 答えは、すべての制約にわたる最小のスケーリングです。 
8. この値の上限を出力します。 

### なぜ効果があるのか

 凸多角形によって引き起こされる変換空間制約は凸であり、サポート関数を通じて完全に表現できます。 L1 ノルム ボールには、正確に 4 つの極値方向を持つ多角形双対があるため、最適な境界接触はこれらの方向の 1 つで発生する必要があります。 すべての幾何学的制約をこれらの方向に沿った投影間隔に縮小することにより、高次元の交差問題を一定次元の間隔の交差に置き換えます。 凸性は、凸集合の何らかのサポート方向に違反が現れる必要があるため、投影で制約が失われないことを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# Helper: cross product
def cross(ax, ay, bx, by):
    return ax * by - ay * bx

# Support function for convex polygon in direction (dx, dy)
# Polygon is CCW, we assume we can do ternary/rotating calipers per query batch
def support(poly, dx, dy):
    n = len(poly)
    best = -10**30
    bi = 0
    for i in range(n):
        x, y = poly[i]
        val = x * dx + y * dy
        if val > best:
            best = val
            bi = i
    return best

def main():
    n = int(input())
    A = [tuple(map(int, input().split())) for _ in range(n)]

    k = int(input())
    Bs = []
    for _ in range(k):
        m = int(input())
        B = [tuple(map(int, input().split())) for _ in range(m)]
        Bs.append(B)

    # L1 critical directions
    dirs = [(1,1), (1,-1), (-1,1), (-1,-1)]

    ans = 0.0

    for dx, dy in dirs:
        L = -10**30
        R = 10**30

        # support of A in both directions
        supA = support(A, dx, dy)
        supA_neg = support(A, -dx, -dy)

        for B in Bs:
            supB = support(B, dx, dy)
            supB_neg = support(B, -dx, -dy)

            # projection constraint for feasibility in this direction
            # u·t must lie in [supA_neg - supB_neg, supB - supA]
            l = supA_neg - supB_neg
            r = supB - supA

            L = max(L, l)
            R = min(R, r)

        # distance from 0 to violating interval in 1D projection sense
        if 0 < L:
            ans = max(ans, L)
        elif 0 > R:
            ans = max(ans, -R)

    print(int(ans) + (1 if ans != int(ans) else 0))

if __name__ == "__main__":
    main()
```実装はサポート関数のクエリを中心に構成されています。 各ポリゴンは凸オブジェクトとして扱われ、特定の方向への極端な投影を計算します。 Bi ごとに、並進投影の線形制約を導出し、これらの制約をグローバルな実行可能な区間に交差させます。 

L1 ノルムは、サポート超平面が正確にそれらの法線を持つダイヤモンドによって定義されるため、4 つの対角方向のみが必要です。 原点が各投影間隔に違反しない距離がわかれば、必要な最大移動量が決まります。 

最後の天井ステップは、わずかな端数の動きでも切り上げを強制するという要件を反映しています。 

## 実用的な例

 区間の形成を説明するために、1 つの A と 1 つの B を持つ単純化されたケースをトレースします。 

### 例 1

 | ステップ | supA(u) | supA(-u) | supB(u) | supB(-u) | Ｌ | R |
 | --- | --- | --- | --- | --- | --- | --- |
 | 初期化 | 2 | -2 | 3 | -1 | -inf | インフ |
 | 更新 | 2 | -2 | 3 | -1 | -1 | 1 |

 この間隔は、変換で射影が [-1, 1] 以内に保たれる必要があることを示しています。 原点が内側にあるため、この方向にはコストがかかりません。 

これは、重複する内部がゼロを含む実行可能な区間を生成し、すべての Bi 制約の交差によって原点が除外される場合にのみコストが発生することを確認します。 

### 例 2

 | ステップ | supA(u) | supA(-u) | supB(u) | supB(-u) | Ｌ | R |
 | --- | --- | --- | --- | --- | --- | --- |
 | 初期化 | 1 | -1 | 4 | -2 | -inf | インフ |
 | 更新 | 1 | -1 | 4 | -2 | 1 | 3 |

 実行可能領域は 1 から始まります。これは、原点が許可された変換間隔の外にあることを意味します。 必要な最小限の動きは投影ではちょうど 1 であり、これは A が B に接触するまで移動する必要があるという考えと一致します。 

これは、アルゴリズムがどのようにジオメトリを 1 次元の間隔制約に縮小するかを示しています。

 ## 特殊なケース

 重要なケースの 1 つは、原点が一方向の実行可能区間の境界上に正確に位置するように、すべての Bi 制約が重なっている場合です。 その状況では、計算された L または R はゼロになり、アルゴリズムは依然としてゼロをその方向への移動を必要としないものとして扱う必要がありますが、他の方向が依然として支配的である可能性があります。 

別のケースは、A と Bi がほぼ同一である場合です。 次に、すべてのサポート関数の違いがキャンセルされ、ゼロを中心とする間隔が生成されます。 境界接触のみが残っている場合、内部交差を削除するための変換は必要ないため、アルゴリズムは正しくゼロコストを生成します。 

3 番目のケースは、制約が異なる方向で競合する場合です。1 つの Bi が 1 つの方向で L を正に押し、別の Bi が別の方向で R を負に押し込む可能性があります。 交差点はゼロ付近で空になり、答えはいずれかの側への最大距離から得られ、すべての禁止区間を同時に抜ける最小のシフトを反映します。
