 ## 解決策
 ## 問題の理解

 整数のシーケンスが与えられ、選択した 2 つの要素を削除してその積をシーケンスに挿入することによって、それらを繰り返しマージすることができます。 マージするたびにシーケンスの長さが 1 つ減少しますが、置換された値の素因数構造も変更されます。 

因数分解後に少なくとも 2 つの異なる素因数が含まれる場合、その数値は有効であると呼ばれます。 各クエリについて、連続したサブシーケンスを取得し、そのサブシーケンス内の残りのすべての要素が有効になるために必要なマージの最小数を知りたいと考えています。 不可能な場合、答えは -1 です。 

重要な点は、マージによって素因数のマルチセット全体が変更されるのではなく、素因数がより少ない数に再分配されるだけであるということです。 各最終要素は元の要素のグループに対応し、その素数構造はそのグループ内のすべての素因数の和集合です。 

この制約は、配列サイズとクエリ数の両方が 200,000 に達する可能性があり、値は最大 10^7 であることを意味します。 因数分解を再計算したり、クエリごとに答えを最初から再計算したりするソリューションは失敗します。 クエリあたり O(n√V) でも大きすぎます。 この構造は、因数分解を前処理してから、高速範囲集計をサポートするクエリ手法を使用することを提案しています。 

サブシーケンスに単一の素因数が繰り返される数値のみが含まれている場合、微妙な失敗のケースが発生します。 たとえば、[2、4、8]。 すべての要素には素数 2 しかないため、どのように結合しても、すべての積には素因数が 1 つしかありません。 正しい答えは -1 ですが、単純な貪欲マージでは、乗算を繰り返すと効果があると誤って想定される可能性があります。 

もう 1 つの重要なエッジ ケースは、サブシーケンスに 1 のみが含まれる場合です。 1 には素因数がないため、素因数を結合しても有効な数は作成されません。 [1, 1, 1] のようなシーケンスも -1 を返さなければなりません。 

## アプローチ

 直接シミュレーションでは、2 つの要素を繰り返し選択して結合し、すべての要素が有効になるかどうかを確認しようとします。 すべての操作が正確に定義されているため、これは原理的には正しいです。 ただし、各クエリではマージの線形シミュレーションまたは二次シミュレーションが必要になる場合があり、クエリが 200,000 個になると、これは実行不可能になります。 

構造的な変化は、最終的な構成が要素のグループ化方法のみに依存するという観察から生まれました。 各要素は 1 つのグループにのみ属し、各グループはそのメンバーの積に等しい単一の数値になります。 グループは、その要素にわたる素因数の和集合に少なくとも 2 つの異なる素数が含まれる場合にのみ有効です。 

したがって、問題は次のようになります。複数の要素セットが与えられた場合、それを最大数の有効なグループに分割します。これは、各グループが最終要素に対応しており、マージを最小限に抑えることは、最終グループを最大にすることと同じであるためです。 

すでに少なくとも 2 つの異なる素数を含むすべての要素はマージする必要がなく、すぐに有効なシングルトン グループを形成します。 構造が必要なのは残りの要素だけです。 このような各要素は、正確に 1 つの素因数に寄与します (1 の場合は何も寄与しません)。 これらは、各グループに全体として少なくとも 2 つの異なる素数が含まれるようにグループ化する必要があります。 

これにより、この問題は、素数タイプの頻度カウントに関するクエリごとの組み合わせの問題に縮小されます。 それぞれの単一の素因数を持つ要素の数と、さらに存在する素因数の数、およびその分布が異なる素因数にわたる完全なペアリングを許可するかどうかを知る必要があります。 

ブルートフォース手法では、クエリごとにこれらの頻度が再計算されますが、範囲ごとの因数分解とカウントが遅すぎます。 代わりに、各要素を小さな状態に前処理し、頻度統計を維持しながら要素の動的な挿入と削除をサポートする Mo のアルゴリズムのような手法を使用して範囲クエリに答えます。

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | クエリごとのブルート フォース | O(n√V) 以上 | O(n) | 遅すぎる |
 | 周波数維持を伴う Mo のアルゴリズム | O((n + q) √n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 重要な前処理ステップ

 まずすべての数値を因数分解し、有効 (少なくとも 2 つの異なる素数)、単一素数 (厳密に 1 つの異なる素数)、または中立 (1) の 3 つの形式のいずれかに分解します。 単一の素数値の場合、グループ化に重要なのは素数識別子だけであるため、その素数識別子のみを保存します。 

### クエリ処理構造

 クエリ間を移動しながら現在のセグメントの統計を効率的に維持できるように、配列に対してスライディング ウィンドウを使用します。 

### 1. 最小の素因数を事前計算し、各要素を分類します

 最大 10^7 までの数値を因数分解するふるいを構築し、配列要素ごとにその個別の素数集合のサイズを決定します。 これにより、クエリの更新中に一定時間の分類が可能になります。 

### 2. セグメントの状態変数を定義する

 現在のセグメントについては、すでに有効な要素の数、1 の数、および単一素数要素の素数の頻度マップを維持します。 また、これらの素数間の最大頻度も維持します。 

この最大頻度は、一致しない剰余を残さずに、異なる素数間で単一素数要素をペアにできるかどうかを決定するため、重要です。 

### 3. Mo のアルゴリズムを使用してセグメントを維持する

 クエリを Mo 順に並べ替え、スライディング ウィンドウを移動します。 要素がウィンドウに出入りすると、関連するカウンターへの寄与が更新され、頻度統計が調整されます。 

### 4. 単一素数要素の実現可能性を計算する

 現在の範囲内の単一素数要素の総数を S とし、それらの素数の最大頻度を mx とします。 mx ≤ S/2 の場合に限り、これらの要素を有効なグループに完全に分割できます。 そうしないと、1 つの素数が大きく支配しすぎて、対になり得ない余りが強制されます。 

可能な場合、単一素数要素から形成されるグループの最大数は S - mx です。 

### 5. ものを扱う

 1 に等しい要素は素数に寄与せず、単独で有効なグループを形成できません。 これらは、すでに有効なグループ、またはすでに少なくとも 2 つの異なる素数を持つグループにのみ挿入できます。 そのようなグループが存在せず、存在する場合、答えは不可能です。 

### 6. すべての貢献を結合する

 すでに有効な各要素は 1 つのグループに寄与します。 単一素数要素からの実行可能な各グループは、別のグループに寄与します。 答えは、要素の合計から形成されたグループの合計を引いたものです。 

### なぜ効果があるのか

 すべての最後の要素はパーティション グループに正確に対応します。 マージ操作ではグループ化のみが変更され、基礎となる素因数のマルチセットは変更されません。 グループは、少なくとも 2 つの異なる素数を含む場合にのみ有効です。 これにより、有効性がセット パーティションの制約に減らされます。 周波数条件 mx ≤ S/2 は、単一素数要素の半分以上を独占する素数がないことを保証します。これはまさに、単色の障害物が残らないように別個の素数間で要素をペアにするための条件です。 これらのグループが修正されると、残りのすべての構造が強制され、代替グループ化によって有効なグループの数を増やすことができなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXV = 10**7

spf = list(range(MAXV + 1))
for i in range(2, int(MAXV ** 0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, MAXV + 1, step):
            if spf[j] == j:
                spf[j] = i

def factor_type(x):
    if x == 1:
        return (0, 0)
    primes = set()
    while x > 1:
        p = spf[x]
        primes.add(p)
        while x % p == 0:
            x //= p
        if len(primes) > 2:
            break
    if len(primes) >= 2:
        return (2, 0)
    return (1, next(iter(primes)) if primes else 0)

n, q = map(int, input().split())
a = list(map(int, input().split()))

tp = [None] * n
for i, x in enumerate(a):
    tp[i] = factor_type(x)

import math

B = int(n ** 0.5) + 1

queries = []
for idx in range(q):
    l, r = map(int, input().split())
    l -= 1
    r -= 1
    queries.append((l, r, idx))

queries.sort(key=lambda x: (x[0] // B, x[1] if (x[0] // B) % 2 == 0 else -x[1]))

cnt_prime = {}
freq = {}
curL, curR = 0, -1

bad = 0
ones = 0
good = 0

def add(i):
    global bad, ones, good
    t, v = tp[i]
    if t == 2:
        good += 1
    elif t == 0:
        ones += 1
    else:
        bad += 1
        old = cnt_prime.get(v, 0)
        new = old + 1
        cnt_prime[v] = new

        freq[old] = freq.get(old, 0) - 1
        if freq[old] == 0:
            freq.pop(old, None)
        freq[new] = freq.get(new, 0) + 1

def remove(i):
    global bad, ones, good
    t, v = tp[i]
    if t == 2:
        good -= 1
    elif t == 0:
        ones -= 1
    else:
        bad -= 1
        old = cnt_prime[v]
        new = old - 1

        cnt_prime[v] = new

        freq[old] -= 1
        if freq[old] == 0:
            freq.pop(old)
        if new > 0:
            freq[new] = freq.get(new, 0) + 1
        else:
            cnt_prime.pop(v)

def current_max_freq():
    if not freq:
        return 0
    return max(freq.keys())

res = [0] * q

for l, r, idx in queries:
    while curL > l:
        curL -= 1
        add(curL)
    while curR < r:
        curR += 1
        add(curR)
    while curL < l:
        remove(curL)
        curL += 1
    while curR > r:
        remove(curR)
        curR -= 1

    S = bad
    mx = current_max_freq()

    groups_bad = 0
    if S > 0:
        if mx > S // 2:
            res[idx] = -1
            continue
        groups_bad = S - mx

    if S == 0:
        if ones > 0:
            res[idx] = -1
            continue
        groups_bad = 0

    total_groups = good + groups_bad
    res[idx] = (r - l + 1) - total_groups

print("\n".join(map(str, res)))
```この実装は、単一素数の素数カテゴリの動的頻度マップを維持することを中心に展開します。 重要な点は、素数ごとのカウントとそれらのカウントの分布の両方を追跡することです。これは、実現可能性の条件が各瞬間の最大周波数に依存するためです。 

因数分解ステップにより、各数値が一定の情報のみを提供することが保証されるため、Mo のアルゴリズムが実行可能になります。 

## 実用的な例

 小さなセグメントを考えてみましょう`[2, 3, 4, 6]`。 

分類した後、`2`そして`3`単素数であり、`4`単素数 (2) であり、`6`もういいです。 セグメントにはすでに 1 つの有効な要素 (`6`）。 単一素数要素についてはカウントがあります`{2:2, 3:1}`したがって、S = 3 および mx = 2 です。2 ≤ 3/2 は false であるため、ペアリングは不可能であり、完全な妥当性を得るには、答えは −1 になります。 

ここで考えてみましょう`[2, 3, 5, 1, 6]`。 

ここ`6`もういいです、`1`中立的であり、`{2,3,5}`単素数です。 S = 3、mx = 1 であるため、グループ化が可能であり、単一素数要素から 1 つのグループを形成できます。 これらは、すでに有効なグループに配置できます。 最終的な答えは、合計要素から有効なグループを差し引いたものになります。 

| ステップ | 悪い要素 | 素数カウント | MX | S | グループ悪い |
 | --- | --- | --- | --- | --- | --- |
 | イニシャル | 3 | {2:1,3:1,5:1} | 1 | 3 | 2 |
 | 最終 | - | - | - | - | 2 |

 これは、バランスの取れた分布により完全なペアリングが可能になり、有効なグループ形成が最大化されることを示しています。

 ## 特殊なケース

 1 だけを含むサブシーケンスは、マージによって常に素数性が向上すると仮定することが失敗していることを示しています。 1 をマージするたびに 1 が生成されるため、有効な要素が現れることはなく、正しい出力は常に -1 になります。 

単一の素数によって支配される部分列。たとえば、`[2, 4, 8, 16]`は、最大周波数の条件が必要な理由を示しています。 複数のマージが可能であっても、すべての結果は 2 のべき乗のままであるため、どのグループ化も 2 つの異なる素数の要件を満たすことができず、強制的に -1 になります。 

のようなバランスの取れたサブシーケンス`[2, 3, 5, 7]`は、すべての単一素数要素を異なる素数間で完全にペアにすることができ、有効なグループの数を最大化し、必要な演算の数を最小限に抑えることができる、反対の極端な例を示しています。
