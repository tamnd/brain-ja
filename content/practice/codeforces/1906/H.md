 ## 解決策
 ## 問題の理解

 2 つの文字列が与えられています。$A$長さの$N$そして$B$長さの$M$と$N \le M$、2人の双子の名前を表します。 ニックネームを作りたい$A'$そして$B'$彼らのために。$A'$の任意の順列にすることができます$A$、 その間$B'$の任意の順列を取ることによって得られます$B$そして正確に削除します$M-N$同じ長さになるように文字数を調整します$N$として$A'$。 

ニックネームは、役職ごとに、キャラクターごとの条件を満たしている必要があります。$i$から$1$に$N$、$i$の - 番目の文字$B'$次のいずれかに等しい必要があります$i$の - 番目の文字$A'$またはアルファベット順の次の文字。 目標は、有効なものをすべて数えることです$(A', B')$モジュロペア$998244353$。 

入力サイズ$N, M \le 200,000$という意味です$O(NM)$解決策は不可能です。 私たちが目指さなければならないのは、$O(N + M)$または$O(M \log M)$複雑。 すべての順列またはサブセットを生成する素朴なアプローチは、次のように組み合わせ的に爆発的に発生します。$N!$または$M \choose N$非常に急速に天文学的に大きくなります。 

明らかではないエッジ ケースには次のようなものがあります。$A$が同じであれば、任意の有効な$B'$場合はまだ複数の可能性があるかもしれません$B$アルファベットの次の文字が含まれます。 もう 1 つのエッジケースは次のような場合です$B$に存在しない文字が含まれています$A$次の文字ではありません。これらの文字は慎重に除外する必要があります。$B'$選択しないと、ペアが無効になります。 例えば、$A = "AAA"$、$B = "AAB"$、 有効$B'$には「AAA」と「AAB」が含まれますが、順序を無視して単純にカウントすると、誤ってカウントしすぎてしまう可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、次のすべての順列が考慮されます。$A$そしてすべて$N$-length の順列の部分列$B$、各ペアの文字ごとの条件を確認します。 正式には、$A'$がある$N! / \prod_{c} f_A(c)!$個別の順列 (マルチセット順列)、およびそれぞれについて$A'$すべてを考慮します$M \choose N$の続き$B$そして彼らの$N!$順列。 小さいものでも$N = 10$、これは譲ります$10^7$可能性。 これは原理的には正しいですが、現実的ではありません。 

重要な観察は、問題は文字の順序ではなく、文字の **マルチセット** のみに依存するということです。$A$そして$B$階乗および組み合わせカウントを使用してカウントできます。 のために$B'$、一致する文字を選択できる方法が何通りあるかを数えるだけで済みます。$A'$またはアルファベットの次の文字。 これにより、問題は位置ではなく文字数に関する組み合わせの DP に変換されます。 

具体的には、次のように表すことができます。$A$そして$B$アルファベット上の周波数配列として。 「A」から「Z」までの各文字について、何回出現する必要があるかがわかります。$A'$そしてどれだけのオプションが存在するか$B$各文字を一致または増分します。 階乗と逆モジュラーを使用すると、有効な順列の数を効率的に計算できます。 DP は文字数を効果的に選択します。$B'$と一致する$A'$、各アルファベットインデックスで「一致または次」を考慮します。

 | ブルートフォース |$O(N! \cdot M! / (M-N)!)$|$O(N + M)$| 遅すぎる |
 | 組み合わせDP / 周波数計数 |$O(N + M + 26^2)$|$O(26)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1.文字列を変換する$A$そして$B$周波数配列に変換する`freqA`そして`freqB`各大文字の数を表す長さ 26。 
2. 階乗とモジュラー逆関数を最大で事前計算します。$M$複数の集合の置換を効率的に処理するため。 
3.初期化`result = 1`。 これにより、文字を割り当てる方法の数が蓄積されます。$B'$特定のマルチセットが与えられた場合$A'$。 
4. 各文字を反復処理します。`c`「A」から「Z」まで。 それぞれについて`c`、 させて`countA = freqA[c]`。 割り当てる必要があります`countA`の文字$B'$それはどちらかです`c`または`c+1`。 
5. しましょう`available_c = freqB[c]`そして`available_next = freqB[c+1]`（もし`c+1`存在します）。 正確に選択する方法の数`countA`これら 2 つのプールからの手紙の合計は次のとおりです`k`から`max(0, countA - available_next)`に`min(countA, available_c)`の`C(available_c, k) * C(available_next, countA - k)`。 
6. 掛ける`result`この文字の法数 $998244353` で計算します。 
7. すべての文字を処理した後、乗算します。`result`マルチセットの置換数による$A$:$N! / \prod_{c} freqA[c]!$モジュロ$998244353$。 これはすべての異なる原因を説明します$A'$。 
8. 出力`result`。 

機能する理由: 各ステップで、すべての文字が$A'$に対応する文字があります$B'$それはそれに一致するか、次の文字です。 順列ではなくカウントに取り組むことで、二重カウントを発生させることなく、すべての順序付けの可能性をカバーします。 最後にマルチセット順列調整を行うと、すべての並べ替えが考慮されます。$A'$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAX = 200_000 + 10

# Precompute factorials and inverses
fact = [1] * MAX
inv_fact = [1] * MAX

for i in range(1, MAX):
    fact[i] = fact[i-1] * i % MOD

inv_fact[MAX-1] = pow(fact[MAX-1], MOD-2, MOD)
for i in range(MAX-2, -1, -1):
    inv_fact[i] = inv_fact[i+1] * (i+1) % MOD

def comb(n, k):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n-k] % MOD

def solve():
    N, M = map(int, input().split())
    A = input().strip()
    B = input().strip()

    freqA = [0]*26
    freqB = [0]*26

    for c in A:
        freqA[ord(c)-65] += 1
    for c in B:
        freqB[ord(c)-65] += 1

    result = 1
    for i in range(26):
        countA = freqA[i]
        if countA == 0:
            continue
        available_c = freqB[i]
        available_next = freqB[i+1] if i+1 < 26 else 0
        ways = 0
        for k in range(max(0, countA - available_next), min(countA, available_c)+1):
            ways = (ways + comb(available_c, k) * comb(available_next, countA - k)) % MOD
        result = result * ways % MOD

    # multiply by number of distinct permutations of A
    denom = 1
    for cnt in freqA:
        denom = denom * inv_fact[cnt] % MOD
    result = result * fact[N] % MOD * denom % MOD
    print(result)

solve()
```コードはまず階乗と逆モジュラーを設定して、組み合わせカウントを効率的に処理します。 周波数配列によりマッチング ロジックが簡素化され、文字に対する DP のような累積が可能になります。 文字のループは、文字を選択する有効な方法を計算します。$B'$独立して、これは有効です。2 つの文字が同じスロットを競合しないためです。$B'$。 最後に、次の順列を調整します。$A$自体。
