 ## 解決策
 ## 問題の理解

 偶数の長さのかっこのシーケンスを構築するように求められます。$N$つまり、すべての開き括弧に対応する閉じ括弧があり、ネストが正しいことを意味します。 さらに、シーケンスには正確な長さの最長回文サブシーケンス (LPS) が必要です。$K$。 タスクは、そのようなシーケンスが存在するかどうかを判断し、存在する場合は有効な例を構築することです。 

入力された整数$N$そして$K$シーケンスの制約を設定します。$N$括弧文字列の合計の長さです。$K$は、達成する必要がある LPS の正確な長さです。 以来$N$は偶数で、次のような完全にネストされたシーケンスです。`((()))`いつでも可能です$N \ge 2$。 ただし、バランスとは無関係に LPS 長を制御する際に課題が生じます。 

明らかではないエッジケースが現れるのは、$K$小さすぎるか大きすぎます。 たとえば、次の場合$K = 1$、バランスの取れたシーケンスでは単一の括弧が単独で存在できないため、単一文字の回文サブシーケンスを持つバランスの取れたシーケンスは存在しません。 もし$K = N$、シーケンス自体が回文である必要があります。 中間の値の場合、不注意に構築すると LPS をオーバーシュートまたはアンダーシュートする可能性があります。 たとえば、$N = 6$そして$K = 2$を使用して`()()()`結果の LPS は 2 ではなく 4 になります。$K$与えられた$N$重要です。 

## アプローチ

 ブルートフォースアプローチでは、長さのバランスの取れた括弧シーケンスをすべて列挙します。$N$それぞれの LPS を計算します。 すべてのバランスのとれたシーケンスの生成は再帰的に行うことができますが、シーケンスの数は次のように指数関数的に増加します。$N$(カタルーニャ語の数字$C_{N/2}$）、これは不可能です$N \le 2000$。 各シーケンスの LPS の計算にも時間がかかります$O(N^2)$、ブルートフォースは絶望的になります。 

重要な洞察は、バランスと回文の部分列を切り離すことです。 バランスの取れたシーケンスはペアで構成されます`()`。 LPS の長さは、連続して一致する括弧によって最大化されます。 バランスの取れたシーケンスで最小の LPS は、括弧ができるだけ交互に配置されたときに発生します (例:`()()()`）。 最大のものは、完全にネストされたシーケンスで発生します (例:`((()))`）。 これを観察すると、次のパターンがわかります。 

- 長さのバランスの取れたシーケンスの最大 LPS$N$は$N$(完全にネストされています)。 
- 長さのバランスの取れたシーケンスの最小 LPS$N$は$N/2 + 1$いつ`N/2`ペアは入れ子になっていないシーケンスに分割されます (例:`()()()...`）。 

これにより、最初に連続する数を決定することで、有効なシーケンスを構築できます。`(`ネストして、残りを交互のペアで埋めます。 これにより、バランスと正確な LPS 長さの両方が保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(C_{N/2} * N^2) | O(N^2) | 遅すぎる |
 | 建設的なネスト | O(N) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.次のことを確認します$K$実現可能です。 もし$K < 2$または$K > N$、印刷`-1`バランスの取れたシーケンスはこの範囲外の LPS を持つことができないため、終了します。 
2. 空の文字列を初期化してシーケンスを構築します。 
3. 特定の LPS を達成するには$K$、最初にネストする開き括弧の数を決定します。 させて`open_count = K // 2`。 追加`open_count` `(`シーケンスに。 
4. これらの括弧をすぐに閉じます。`open_count` `)`。 この時点で、ネストされたブロックは正確に貢献します。`2 * open_count`LPSに。 
5.残りの長さについて$N - 2 * open_count$、交互に追加します`()`ペア。 このような各ペアは、サブシーケンスの一部として選択された場合、LPS にちょうど 2 を与えます。 
6. 構築されたシーケンスを返します。 

これが機能する理由は、最初のネストされたブロックが LPS を明示的に定義しているのに対し、残りの交互のペアは LPS を必要な長さを超えて拡張しないためです。 シーケンスは常にバランスが保たれています。`(`対応するものがある`)`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    N, K = map(int, input().split())
    
    if K < 2 or K > N:
        print(-1)
        return
    
    seq = []
    open_count = K // 2
    # Step 1: add nested parentheses to control LPS
    seq.extend(['('] * open_count)
    seq.extend([')'] * open_count)
    
    # Step 2: fill the remaining with simple alternating pairs
    remaining = N - 2 * open_count
    seq.extend(['(' , ')'] * (remaining // 2))
    
    print(''.join(seq))

if __name__ == "__main__":
    main()
```コードはまず、有効なシーケンスが可能かどうかをチェックします。 の`open_count`ネストされたセクションが LPS に寄与することを保証し、残りのシーケンスは次のように埋められます。`()`LPS を増加させずにバランスを維持するためのペア。 乗算する`remaining // 2`2 倍すると、シーケンスの合計の長さの合計は次のようになります。$N$。 奇数の残りの長さのようなエッジ条件は不可能です。$N$は均等です。
