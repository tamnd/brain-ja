 ## 解決策
 ## 問題の理解

 私たちは循環トラックを扱っています。`n`等間隔の位置、ラベル付け`0`に`n-1`。 各犬は独自の位置からスタートします`i`そして、すべての犬は一定の速度で時計回りに動きます`v_i`、その後を意味します`t`タイムステップ、犬`i`の位置に配置されます`(i + t · v_i) mod n`。 

目標は、時間が存在するかどうかを判断することです`t`（から`0`まで`1000`) すべての犬が円上の同じ位置を占めるようにします。 そのような瞬間が存在する場合、私たちはそのような最小の瞬間を報告しなければなりません`t`、共通の立場とともに`p`すべての犬が出会う場所。 許可された時間枠内にそのような時間が存在しない場合、答えは次のようになります。`-1`。 

制約は小さいです。`n ≤ 1000`そして`v_i ≤ 100`、そして時間制限は暗黙のうちに、最大までしか考慮できないことを制限します。`t = 1000`。 これは、検査する州の総数が最大でも約 100 万位置であるため、すべてのタイム ステップにわたるシミュレーションが実行可能であることを直ちに示唆しています。 

微妙な点は、集合位置が事前に決まっていないこと。 それは時間の力学によって決まります`t`。 単純な間違いは、ターゲットの位置を推測できると仮定したり、問題を時間 0 でのペアごとの位置合わせに還元したりできると仮定することです。 同期は初期構造ではなく時間発展に依存するため、これは失敗します。 

もう 1 つの潜在的な落とし穴は、モジュロ動作を忘れることです。 すべての犬が直線的に動いているように見えても、犬の位置は円を囲んでいるため、位置合わせは生の整数ではなくモジュラー演算でチェックする必要があります。 

小さなエッジケースは、`n = 1`、答えは自明です`t = 0, p = 0`。 もう 1 つは、条件を満たす時間がない場合です。この場合、明示的に出力する必要があります。`-1`部分的な構成ではなく。 

## アプローチ

 直接的なアプローチは、システムをシミュレートすることです。 毎回`t`、次の式を使用してすべての犬の位置を計算します。`(i + t · v_i) mod n`、計算されたすべての位置が同じかどうかを確認します。 そうであれば、私たちは戻ります`t`そしてその位置。 

これが機能するのは、固定時刻におけるシステムの状態が完全に決定され、独立して計算できるためです。 正しさは定義からすぐにわかります。 

この強引なアプローチのコストは簡単に分析できます。 それぞれについて`t`まで`1000`、すべてスキャンします`n`犬、約につながる`1000 · 1000 = 10^6`最悪の場合の評価も。 各評価は一定時間であるため、これは十分に制限内です。 

時間制限が十分に小さいため、直接シミュレーションがすでに快適に適合しているため、ここではさらに深い代数的単純化は必要ありません。 閉じた形式の解を導出しようとすると、漸近的なパフォーマンスが向上することなく、不必要な複雑さが生じることになります。

 | 最適 (同じ考え) | O(n・T) | お(1) | 承認済み |

 ここ`T = 1000`。 

## アルゴリズムのチュートリアル

 時間をステップごとにシミュレーションし、整合性を確認します。 

### ステップ

 1.時間をかけて繰り返す`t`から`0`に`1000`。 

から始めます`0`最も早い解決策が必要であり、時間ゼロが有効な構成であるためです。 
2. それぞれについて`t`、最初の犬の位置を次のように計算します。`p0 = (0 + t · v_0) mod n`。 

これが待ち合わせ候補位置となります。 
3. 他の犬ごとに`i`、計算する`pi = (i + t · v_i) mod n`。 

もしあれば`pi`とは異なります`p0`、 この時`t`すべての犬が一致するわけではないので、解決策にはなりません。 
4. すべての犬が一致する場合`p0`、すぐに戻ります`(t, p0)`。 

そのような最初の`t`検出された値は自動的に最小になります。 
5. 範囲内の時間が完全に一致しない場合は、出力`-1`。 

### なぜ効果があるのか

 決まった時間にいつでも`t`、システム状態は、インデックスから位置への決定論的なマッピングによって完全に記述されます。 アルゴリズムは、このマッピングがすべてのインデックスにわたって一定になるかどうかを正確にチェックします。 時間を昇順に調べて最初の有効な構成を受け入れるため、返される時間は構造上最小限になります。 この条件では、すべてのドッグが段階的にではなく同時に一致する必要があるため、中間状態をスキップしたり、部分的に有効にしたりすることはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    v = list(map(int, input().split()))
    
    for t in range(1001):
        p0 = (0 + t * v[0]) % n
        ok = True
        
        for i in range(1, n):
            if (i + t * v[i]) % n != p0:
                ok = False
                break
        
        if ok:
            print(t, p0)
            return
    
    print(-1)

if __name__ == "__main__":
    solve()
```実装はアルゴリズムを直接反映しています。 外側のループは時間を列挙します。 毎回、犬から基準位置を計算します。`0`そして他のすべての犬をそれと比較します。 不一致が見つかった場合は早期に終了することで、不一致が見つかった場合の不必要な作業を防ぎます。 

よくある実装上の間違いは、モジュロを取るのを忘れることです。`n`各位置の計算時に。 それがなければ、値は急速に増大し、比較は無意味になってしまいます。 もう 1 つの微妙な問題は、タイム ステップごとに正確性チェックを独立して再開しないことです。これにより、反復間で状態が誤って引き継がれてしまいます。

import sys, io

def solve_io(inp: str) -> str:

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

        solve()
    return out.getvalue().strip()

 ## 特殊なケース

 のために`n = 1`、ループは、唯一の犬がすでに自分自身と整列していることをすぐに検出します。`t = 0`、アルゴリズムは戻ります`0 0`。 計算`(0 + 0 · v_0) mod 1`は`0`したがって、一貫性は自明のことです。 

速度が同じ場合、すべての犬は相対的な間隔のモジュロを保持します。`n`。 初期位置がまだ等しくない場合、後でオフセットを修正することはできないため、アルゴリズムは常に正しく実行して戻り値を返します。`-1`ない限り`n = 1`。 

時間範囲の後半で位置合わせが行われる場合、ステップバイステップのスキャンでは時間がスキップされないため、正確さが保証されます。 最も早い有効な`t`反復が厳密に増加しているため、常に返されます。
