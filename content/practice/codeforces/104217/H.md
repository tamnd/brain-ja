 ## 解決策
 ## 問題の理解

 順序付けられた長さのシーケンスを構築しています$N$、各位置は、斑点または茶色の 2 つの区別できないタイプのいずれかで埋められます。 同じ種類の牛は同一であるため、有効な構成は次の長さのバイナリ文字列によって完全に記述されます。$N$。 

制約は、次のことを避けなければならないということです。$K$シーケンス内の任意の場所に、またはそれ以上の連続した斑点のある牛。 褐色の牛は縞模様を区切るセパレーターとして機能するため、制限は完全に連続した斑点のあるエントリのランレングスに関するものです。 

タスクは、そのような長さのバイナリ文字列の数を数えることです。$N$この制限を満たし、結果を剰余として出力します。$10^9 + 7$。 

制約$N \le 10^6$すべての指数列挙または単純な再帰を即座に除外します。$2^N$文字列。 平$O(N^2)$最悪の場合、解決策は遅すぎるため、$N$100万に達する可能性があります。 解決策は線形またはほぼ線形である必要があります。 

位置と最後の実行長だけを追跡する単純な動的プログラミングはほぼ正しいですが、ネストされた遷移や再計算を使用して実装が不十分な場合は合格しません。 

微妙なエッジケースが発生する場合$K = 1$。 この場合、斑点のある牛は 1 頭でも長さ 1 のランを形成するため、斑点のある牛は禁止されます。そのため、唯一の有効なシーケンスは全茶色のシーケンスです。 もう一つのエッジケースは、$K > N$、制約がトリガーされることはありません。$2^N$シーケンスは有効です。 

## アプローチ

 ブルートフォースソリューションでは、長さのすべてのバイナリ文字列が生成されます。$N$少なくとも体長以上の斑点のある牛が含まれているかどうかを確認します$K$。 各文字列のチェックにかかる時間$O(N)$、そして、あります$2^N$文字列なので、合計作業量は次のようになります。$O(N 2^N)$、小さなものでも不可能になります$N$30くらい。 

重要な構造的観察は、妥当性が斑点牛の現在の連続実行期間のみに依存するということです。 茶色の牛が現れると、ストリークは完全にリセットされます。 これは、文字列の履歴全体が 1 つの状態変数 (現在プレフィックスを終了している連続斑点牛の数) に圧縮できることを意味します。 

これにより、左から右にシーケンスを構築し、長さごとに、正確に連続して終了する有効なシーケンスの数を維持する動的プログラミングの定式化が可能になります。$i$斑点のある牛のための$0 \le i < K$。 遷移は局所的であり、茶色または斑点のどちらを追加するかによってのみ決まります。 

茶色を追加すると、縞模様がゼロにリセットされます。 スポットを追加すると、次の範囲に達しない限り、ストリークの長さが 1 つ増加します。$K$、この場合、その遷移は許可されません。 

これにより、問題が指数関数的な列挙から線形時間の状態遷移に軽減されます。$K$状態を生成し、$O(NK)$DP。 ただし、以来、$N$そして$K$どちらも大きくなる可能性がありますが、これでも最悪の場合には遅すぎます。 

最後の改良点は、DP の反復がスライディング ウィンドウ構造であることを観察することです。つまり、斑点のある牛を含む遷移は、最後の期間にわたって合計されます。$K-1$州。 これにより、プレフィックスの合計を維持できるため、各ステップを一定時間で計算できるようになり、複雑さが軽減されます。$O(N)$。

 ## アルゴリズムのチュートリアル

 シーケンスの長さを左から右に処理する DP を定義します。 させて$dp[i]$現在処理されている長さで正確にストリークで終わる有効なシーケンスの数を表します。$i$連続斑点のある牛。 追跡も行います$dp[0]$茶色は縞をリセットするため、茶色で終わるシーケンスとして扱われます。 

合計を繰り返し再計算することを避けるために、すべての有効な状態の現在の合計を維持します。 

### ステップ

 1. 配列を初期化する$dp$サイズの$K$すべてゼロで設定します$dp[0] = 1$、斑点模様のない空のシーケンスを表します。 これが唯一の有効な開始設定です。 
2. 各ポジションについて、$1$に$N$、新しい配列を計算します$ndp$最初はすべてゼロです。 これは、新しい長さのすべてのシーケンスを表します。 
3. 最初に茶色の牛を配置します。 以前の長さの有効なシーケンスはブラウンによって拡張でき、ストリークがゼロにリセットされます。 そこで設定しました$$ndp[0] = \sum_{i=0}^{K-1} dp[i]$$茶色は以前の縞の長さに依存しないため、この手順は正しいです。 
4. 次に、斑点のある牛を配置します。 現在次で終わるシーケンスに斑点のある牛を追加すると、$i$斑点のある牛、私たちは州に移動します$i+1$。 これは次の場合にのみ有効です$i+1 < K$。 だからみんなにとって$i$、$$ndp[i+1] += dp[i]$$これにより、有効なストリークのみを延長し、長さに達することがなくなります。$K$。 
5. 交換する$dp$と$ndp$そしてすべてになるまで繰り返します$N$ポジションが処理されます。 
6. 最終的な答えは、すべての状態の合計です。$dp$、到達しない限り、どのような終了ストリークでも許可されるため$K$内部的に。 

### なぜ効果があるのか

 不変条件は、処理後のものです。$t$ポジション、$dp[i]$有効な長さのシーケンスの数を正確にカウントします$t$斑点のある牛の最後の走りは長さがある$i$、およびすべてのシーケンスがカウントされます$dp$どのプレフィックスでも制約に違反したことはありません。 

すべてのトランジションは有効性を維持します。ブラウンを追加すると禁止されたストリークを作成できません。スポットを追加すると、それが以下に留まる場合にのみ有効なストリークが拡張されます。$K$。 有効な長さのシーケンスはすべて$t+1$正確に 1 つの有効な長さのシーケンスから取得する必要があります$t$これら 2 つの操作のいずれかを介して、DP は重複や省略なしにすべての可能性をカバーします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, k = map(int, input().split())
    
    if k == 1:
        print(1)
        return
    
    if k > n:
        print(pow(2, n, MOD))
        return
    
    dp = [0] * k
    dp[0] = 1
    
    for _ in range(n):
        ndp = [0] * k
        
        total = sum(dp) % MOD
        
        ndp[0] = total
        
        for i in range(k - 1):
            ndp[i + 1] = dp[i] % MOD
        
        dp = ndp
    
    print(sum(dp) % MOD)

if __name__ == "__main__":
    solve()
```実装は状態定義を直接反映します。 特別な場合$k = 1$斑点のある牛は許可されていないため、最初に処理され、茶色のシーケンスを除くすべてのシーケンスが無効になります。 

茶色の遷移では、すべてのストリークがリセットと互換性があるため、以前の状態の合計が使用されます。 スポットされた遷移は状態を 1 つずつ右にシフトし、長さのストリークを決して構築しないようにします。$K$。 

ループが実行されます$N$回、各反復で実行される$O(K)$配列のシフトと合計により機能します。 制約を考慮すると、これで十分です。

### 例 2

 入力:```

```ここでは、長さ 0 のストリークのみが許可されます。これは、スポットの後に別のスポットが続くと違反となるためです。$K=2$。 

| ステップ | dp[0] | dp[1] | 合計 |

この例では、システムがどのように状態を切り替えながら、ストリークが制限に近づくとシーケンスを大幅にプルーニングするかを強調しています。

 ## 特殊なケース

 いつ$K = 1$、斑点のある牛はすぐに禁止された走行を作成するため、DP の定式化は退化します。 アルゴリズムはショートして、全茶色のシーケンスに対応する 1 を返します。 たとえば、入力`3 1`だけを生成します`BBB`。 

いつ$K > N$、長さはありません$K$物理的に発生する可能性があります。 アルゴリズムは正しく返します$2^N$すべてのバイナリ シーケンスが有効であるためです。 入力用`4 10`、16 個のシーケンスすべてが受け入れられます。 

いつ$K = 2$、システムは斑点のある牛の後に厳格な交代を強制します。 DP はストリーク 0 状態とストリーク 1 状態の間で変動しますが、ストリーク 1 を拡張しようとする試みは状態遷移を通じて暗黙的に排除されます。 入力用`3 2`、有効なシーケンスは、正確に、`SS`、DP はそれらを 5 として正しく列挙します。
