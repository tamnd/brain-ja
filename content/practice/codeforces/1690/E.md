 ## 解決策
 ## 問題の理解

 それぞれの重量が偶数個の商品が与えられ、それらをペアに梱包する必要があります。 ペアのコストは、その重みの合計を固定数で割ることによって計算されます。$k$、最も近い整数に切り捨てられます。 私たちの目標は、すべてのパッケージの総コストが最大化されるような方法でペアを作成することです。 各テスト ケースは、商品の重量と商品の価値を提供します。$k$。 各テスト ケースの最大合計コストを返す必要があります。 

制約により、私たちは次のことを可能にします。$2 \cdot 10^5$すべてのテスト ケースにわたる商品の合計。 これにより、ペアリングの方法は無数に存在するため、考えられるすべてのペアリングを試みるアプローチは除外されます。$n$アイテムは段階的に成長します。 具体的には、ブルートフォース ペアリングは次のようになります。$O((n-1)!!)$、でもそれは不可能です$n = 20$。 

すべての重みが次で割り切れる場合、微妙なエッジ ケースが発生します。$k$、またはすべてが以下より小さい場合$k$。 たとえば、$a = [2, 2, 2, 2]$そして$k = 3$、単純なペアリングでは、の倍数に到達するパッケージの数が誤って減少する可能性があります。$k$、最適ではない総コストが発生します。 もう 1 つの注意が必要なケースは、多数のゼロまたは より小さい項目があることです。$k/2$; 不用意に組み合わせると、フロア分割のゲインを最大化するためにより大きなウェイトと組み合わせることができたにもかかわらず、これらの小さなアイテムが無駄になる可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、すべてのペアを列挙し、合計を計算します。$\lfloor (a_i + a_j)/k \rfloor$。 これにより正しい答えが保証されますが、ペアリングの階乗数は受け入れられません。$n = 2 \cdot 10^5$。 

重要な洞察は、各パッケージのモジュロの寄与を考慮することで得られます。$k$。 各項目$a_i$次のように書くことができます$a_i = q_i \cdot k + r_i$、 どこ$q_i = a_i // k$合計に対する保証された貢献度であり、$r_i = a_i \% k$残りは、別の残りと結合して別の倍数を形成する可能性があります。$k$。 これにより、追加の倍数の数を最大化する方法での剰余のペアリングの問題が軽減されます。$k$。 

剰余を並べ替えたら、2 ポインタ戦略を使用できます。 最小の剰余と最大の剰余をペアにします。 それらの合計が少なくとも$k$、新しい追加パッケージ値を形成します。 それ以外の場合は、小さい方の余りを前方に移動します。 この貪欲な戦略により、高い剰余を低い剰余に無駄にすることなく、剰余からの追加の寄与を最大化できます。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$、$k$、および重みのリスト$a$。 
2. 整数除算により各アイテムからの保証貢献度を計算します。$q_i = a_i // k$それらを合計して総コストを初期化します。 
3. 剰余を計算する$r_i = a_i \% k$項目ごとにリストに保存します。 
4. 剰余のリストを昇順に並べ替えます。 
5. 2 つのポインターを初期化します。$i = 0$初めに、$j = n-1$最後に。 
6. ながら$i < j$:

 - どうかを確認してください$r_i + r_j \ge k$。 true の場合、合計コストを 1 増加させ、両方のポインターを内側に移動します ($i += 1, j -= 1$)、追加ユニットを生成するパッケージを形成します。 
- 合計が以下の場合$k$、小さい方の剰余ポインタを前方に移動します ($i += 1$）、それより大きな剰余と組み合わせても、それ以下の追加価値しか生み出されないからです。 
7. ループ後、合計コストを出力します。 

機能する理由: 各アイテムは保証された倍数を提供します。$k$。 最小および最大の剰余をソートしてペアリングすることにより、次の値を超えるペアの数を最大化します。$k$なぜなら、より小さな剰余は、別の小さな剰余と組み合わせると無駄になるからです。 この戦略により、残りからの潜在的な追加寄与がすべて確実に捕捉されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        total = sum(x // k for x in a)
        remainders = [x % k for x in a]
        remainders.sort()
        
        i, j = 0, n - 1
        while i < j:
            if remainders[i] + remainders[j] >= k:
                total += 1
                i += 1
                j -= 1
            else:
                i += 1
        print(total)

if __name__ == "__main__":
    solve()
```コードはまず、整数除算を使用して保証された寄与を計算します。 残りをソートすると、極値を効率的にペアにすることができます。 2 ポインターのアプローチにより、二重にカウントすることなく追加のユニットを生成できる組み合わせを見逃さないことが保証されます。 合計が低すぎる場合に小さい方の余りを前に移動すると、無駄なペアリング試行が防止されます。
