 ## 解決策
 ## 問題の理解

 各コンポーネントは整数座標を持つ平面上の点であり、各点は未テスト、肯定的にテスト済み、または否定的にテスト済みとしてラベル付けされます。 これらのポイントの一部が「漏洩源」であると仮定することが求められます。 

ある点での測定は次のように機能します。ある点でテストを実行すると、ヘリウムがそこから放出され、上向きに広がり、上昇するにつれて横にも広がります。 その結果、テストされた点自体が漏れている場合だけでなく、その上にある特定の広がった円錐形の領域に漏れ点が存在する場合も漏れが検出されます。 

幾何学形状はより具体的に言い換えることができます。 漏れ箇所$(x_j, y_j)$でのテストに影響を与える$(x_i, y_i)$それがその上にあり、水平に離れすぎていない場合。 与えられた条件としては、$$|x_i - x_j| \le \frac{y_j - y_i}{2},$$上向きに開いた対称の円錐を表します。 

タスクは、すべての陽性テストがその影響領域内の少なくとも 1 つのリーク ポイントまたはリーク自体によって説明できるように、リーク ポイントの最小数を選択することです。一方、すべての陰性テストはリーク ポイントによってまったく説明されてはならず、またそれ自体がリークであることもできません。 そのような選択ができない場合、回答は不可能です。 

入力サイズは最大 200,000 ポイントに達するため、ポイントのペアに対する二次推論は実行できません。 たとえ$O(n \log n)$または$O(n)$解決策が期待されています。 すべての点のペア間の影響を明示的にチェックしようとするアプローチは、幾何学的関係の密度によりすぐに失敗します。 

幾何学的な意味で、負の点が多くの正の点の「下」にある場合、微妙なエッジ ケースが発生します。 注意しないと、影響領域が拡大円錐内で上向きに制限されていないため、正の制約​​を満たすためにリーク ポイントを選択すると、誤ってその上の負の制約に違反する可能性があります。 

別の故障モードは、正の点の上に漏洩源の可能性がない場合に発生します。 ポイント自体が入力でリークとしてマークされていない場合でも、ポイントを含めることを強制される可能性があり、同時に負の制約構造によって禁止されている場合、インスタンスは不可能になります。 これらのグローバルな相互作用を無視する素朴な貪欲なアプローチは、実現可能性を誤って仮定することになります。 

## アプローチ

 ブルートフォース戦略では、ポイントのすべてのサブセットをリークコンポーネントのセットとして試し、すべてのポジティブポイントが説明され、すべてのネガティブポイントがクリーンなままであるかどうかをチェックします。 サブセットごとに制約を検証するには、点のペア間の影響をチェックする必要があります。$O(n^2)$。 と組み合わせると、$2^n$サブセットの場合、これはたとえ小規模なインスタンスであっても完全に実行不可能です。 

重要な構造的観察は、幾何学的影響関係が、修正された座標系における支配関係に変換できるということです。 条件$$|x_i - x_j| \le \frac{y_j - y_i}{2}$$は 2 つの線形不等式として書き直すことができます。$$y_j - 2x_j \ge y_i - 2x_i \quad \text{and} \quad y_j + 2x_j \ge y_i + 2x_i.$$これは、新しい座標を定義することを示唆しています$$p = y - 2x, \quad q = y + 2x.$$これらの座標では、点は$j$影響を与える$i$まさにいつ$p_j \ge p_i$そして$q_j \ge q_i$。 影響領域は２次元の半順序で北東の支配関係となる。 

ここで、各正の点には、この半順序で支配的な、選択された漏れ点が少なくとも 1 つ必要です。 選択した各リーク ポイントは、それが支配するすべてのポイントをカバーします。 

負の点は禁止された制約として機能します。選択された漏れ点が負の点を支配することは許可されません。これは、観察された負の結果と直ちに矛盾するためです。 

これにより、問題は、負の点によって引き起こされる禁止された優勢領域の完全に外側に留まりながら、優勢下にあるすべての正の点をカバーする点の最小サブセットを選択することになります。 このように表現すると、最大点はその下にあるすべての点をカバーするため、この構造は崩壊して、実行可能な最大要素を支配的な順序で選択することになります。 

ブルートフォースは相互作用をペアごとに扱うため失敗しますが、変換された構造はカバレッジが単調でグローバルな順序に崩壊していることを示しています。 この変換により、幾何学が半順序理論に還元され、極値要素に基づいた貪欲な構築が可能になります。

 ## アルゴリズムのチュートリアル

 私たちは変換された座標で作業します$p = y - 2x$そして$q = y + 2x$、影響力が座標方向の優位性になります。 

1. すべての点を次のように変換します。$(p, q)$形状。 これにより、幾何学的な影響が単調な部分順序に変換されます。 現在の目標は純粋に組み合わせによるものです。 
2. 潜在的な漏洩源として禁止されているすべてのポイントを特定します。 検査結果が陰性の場合、ポイントを選択することは観察と直ちに矛盾するため、そのポイントは禁止されます。 
3. すべての禁止事項を考慮から削除します。 有効なソリューションでは、残りのセットからのみ漏れポイントを選択する必要があります。 
4. すべての肯定的な点の実現可能性を確認します。 それぞれの正のポイントについて、それを支配する残りのポイントが少なくとも 1 つ存在することを確認します。 そのような点が存在しない場合、リーク構成がその観察を説明できないため、インスタンスは不可能です。 
5. 有効な解決策は残りの点から選択する必要があり、別の残りの点によって支配されていない点は、厳密に説明ソースとしてより強力であることに注意してください。 このような点は、その下のすべての点を支配するため、支配的な点に置き換えることによって改善することはできません。 
6. 支配関係の下で残りのセットのすべての最大点を収集します。 これらは、両方を備えた残りのポイントが存在しないポイントです。$p$そして$q$それ以上か等しい。 
7. これらの最大点の数を、漏れ成分の最小必要数として出力します。 

### なぜ効果があるのか

 禁止点を削除した後、有効な漏れ集合はすべての正の点を優性を使用して説明する必要があります。 正の点が選択された漏れ点によって説明される場合、その漏れ点を最大支配点で置き換えても、カバレッジが減少することはなく、実現可能性を侵害することはできません。これは、最大点が代替点のすべてを支配するためです。 この置換を繰り返し適用すると、最大の要素だけが残るまで、有効な解が優先順位の上位に押し上げられます。 これは、実行可能な最小セットが常に最大要素のサブセットとして取得でき、最大要素のより小さなサブセットが必要な支配的なカバレッジを失うことなくすべての正の点をカバーできないことを示しています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = []
    
    for _ in range(n):
        x, y, c = input().split()
        x = int(x)
        y = int(y)
        
        p = y - 2 * x
        q = y + 2 * x
        
        pts.append((p, q, c))
    
    allowed = []
    
    # negative points cannot be selected
    forbidden = set()
    
    for p, q, c in pts:
        if c == 'N':
            forbidden.add((p, q))
    
    for p, q, c in pts:
        if (p, q) not in forbidden:
            allowed.append((p, q, c))
    
    # check feasibility: every P must be dominated by some allowed point
    for p, q, c in allowed:
        if c == 'P':
            ok = False
            for p2, q2, _ in allowed:
                if p2 >= p and q2 >= q:
                    ok = True
                    break
            if not ok:
                print("impossible")
                return
    
    # extract maximal points in allowed set
    ans = 0
    for i, (p1, q1, _) in enumerate(allowed):
        dominated = False
        for j, (p2, q2, _) in enumerate(allowed):
            if j != i and p2 >= p1 and q2 >= q1:
                dominated = True
                break
        if not dominated:
            ans += 1
    
    print(ans)

if __name__ == "__main__":
    solve()
```最初のステップでは、幾何学的影響を単調な支配関係に変換する座標変換を実行します。 第 2 段階では、負の点を選択するとすぐに制約に矛盾するため、すべての負の点が削除されます。 

実現可能性チェックにより、すべての正の点が少なくとも 1 つの許可された点の支配領域内にあることが保証されます。 このチェックがなければ、何らかの正の制約が根本的に説明できない場合に、解決策が存在すると誤って仮定する可能性があります。 

最後に、極大要素のカウントが機能するのは、極大でない点は説明ソースとしては厳密に言うと悪いからです。極大要素は支配的な点がカバーするもののサブセットをカバーするため、最小構成では決して必要ありません。 

## 実用的な例

 1 つの点が正で、2 つの点が潜在的なソースである小規模な構成を考えてみましょう。 

| ステップ | アクション | 残りポイント | 最大の候補 |
 | --- | --- | --- | --- |
 | 開始 | 座標を変換する | すべてのポイント | - |
 | フィルター | ネガを削除 | 許可されたセット | - |
 | チェックP | カバレッジを確認する | 同じ | - |
 | 最大スキャン | 支配されていない点を特定する | 同じ | 選択されたセット |

 右上の 1 つの点がすべてを支配する場合、それが唯一の最大要素となるため、答えは 1 になります。これは、支配性が考慮されると、下位のすべての点がどのように無関係になるかを示しています。 

ここで、分離された 2 つの極大領域が存在する場合を考えてみましょう。 各領域には相互に支配しない点が含まれているため、両方が最大要素として残ります。 これは、応答が独立した優勢ピークをカウントしていることを示しています。

 ## 特殊なケース

 重大なエッジケースは、マイナス点が多くの潜在的な漏洩源の上にある場合に発生します。 変換された空間では、これにより候補点の大きな領域が削除されます。 このアルゴリズムは、優位性を推論する前にすべての禁止ポイントを除外することでこれを処理し、無効なソースが考慮されないようにします。 

別のケースは、正のポイントが孤立しており、支配的な許可ポイントがない場合に発生します。 実現可能性チェックは、許可されたドミネーターをスキャンすることでこれを早期に検出し、最大ポイントが十分であるという誤った想定を防ぎます。 

3 番目のケースは、すべてのポイントの優位性が相互に比較できない場合です。 その状況では、許容されるすべてのポイントが最大になり、アルゴリズムは正確に全カウントを返します。これは、ポジティブをカバーする際に他のポイントを置き換えることができないことを反映しています。
