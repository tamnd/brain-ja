 ## 解決策
 ## 問題の理解

 正確に単純な無向グラフを構築するように求められます。$n$頂点。 自己ループとエッジの重複を避ける限り、任意のエッジを自由に選択できます。 

グラフは 2 つの数理論上の制約を同時に満たさなければなりません。 まず、すべての頂点次数は素数でなければなりません。 次に、エッジの総数も素数でなければなりません。 

したがって、タスクはコストや接続性などを最適化することではなく、すべての頂点の次数が素数のセットに収まり、すべての次数の合計を 2 で割った値も素数になるように、エッジのサブセットを慎重に選択することです。 

以来$n \le 1000$、余裕があります$O(n^2)$推論と構築。 私たちは明らかに建設的な体制にあり、素数の構造がグラフの次数の合計と相互作用します。 主な問題点は、次数制約が頂点ごとにローカルであるのに対し、エッジ数制約はグローバルであることです。 

素朴な試みは、エッジのすべてのサブセットを試すか、ランダムにグラフを構築して素数制約をテストすることです。 グラフの数が指数関数的であるため、これはすぐに失敗します。$n^2$、候補者ごとの次数制約を検証することさえ遅すぎます。 

さらに微妙な失敗例は、度数を「局所的に修正」しようとした場合に発生します。 たとえば、各頂点の次数が 2 (2 が最小の素数であるため) であることを確認しようとする場合がありますが、その場合、グラフはサイクルの集合に強制されます。 エッジの総数は厳しく制限され、多くの場合、任意のエッジを素数にできなくなります。$n$。 たとえば、次の場合$n = 6$、2 正規グラフにはちょうど 6 つの辺があり、これは素数ではありません。 

問題は本質的に、全体的なエッジ数を素数に調整できる規則的な、または規則に近い構造を見つけることです。 

## アプローチ

 強引なアプローチは、これを全体的な制約満足問題として扱うことです。$\binom{n}{2}$エッジ。 各エッジの存在または不在を割り当て、すべての次数を計算し、各頂点とエッジ数の素数性を検証します。 これには、$2^{O(n^2)}$可能性があり、たとえそれが完全に不可能である$n = 20$。 

重要な観察は、実際には度数の値に柔軟性が必要ないということです。 すべての頂点が同じ次数を持つ構造のみが必要です。その場合、制御する必要があるのは 1 つの数値だけであるためです。$n$独立したもの。 

を構築すると、$k$- 通常のグラフの場合、各頂点には次数があります$k$したがって、次数条件は次のことを確認することになります。$k$プライムです。 エッジの総数は次のようになります。$$m = \frac{n \cdot k}{2}$$したがって、私たちにも必要です$m$プライムになること。 

これは問題を素数の選択に変換します$k$そのような$\frac{n k}{2}$も素数なので、$k$-通常の単純なグラフ。 

構造自体は標準です:$n$が偶数であれば、各頂点を次の頂点に接続できます$k/2$円形に配置された隣人。 もし$n$これは奇妙です。少し異なる対称構造を使用することでパリティの問題を回避していますが、中心となるアイデアは循環グラフを構築することに変わりはありません。 

残りの課題は、適切なソリューションを選択することです。$k$。 以来$n \le 1000$、最大で素数を総当たりすることができます。$n-1$、かどうかをテストします$m$プライムです。 そのようなものを見つけたら、$k$、決定論的にグラフを構築します。

 ## アルゴリズムのチュートリアル

 1. ふるいを使用して、約 1000 までのすべての素数を事前計算します。 これは、頂点次数候補とエッジ数の両方を効率的にテストするために必要です。 
2. 可能な度数を繰り返します。$k$2から$n-1$。 私たちはただ考慮します$k$すべての頂点次数が素数でなければならないため、これらは素数になります。 これにより、検索スペースが大幅に減少します。 
3. 各候補者について$k$、意図したエッジの数を計算します。$$m = \frac{n \cdot k}{2}$$もし$m$は整数ではないので、これをスキップしてください$k$。 次数の総和は偶数でなければならないため、これによりハンドシェイク補題が適用されます。 
4. かどうかを確認します。$m$プライムです。 そうでない場合は、続行してください。 頂点次数とエッジ数の両方が同時に素数になる必要があります。 
5. 有効なペアになると$(n, k)$が見つかった場合は、$k$-通常のグラフオン$n$頂点。 各頂点を接続します$i$次へ$k/2$円形の順序で頂点を配置します。 

接続する$i$と$(i + j) \bmod n$のために$1 \le j \le k/2$。 
6. この構築によって生成されたすべてのエッジを出力します。 

### なぜ効果があるのか

 この構造では、すべての頂点が正確に存在することが保証されます。$k$各頂点は同じオフセットのセットに対称的に参加しているため、隣接します。 この対称性により、どの頂点も異なる方法で扱われないことが保証されるため、すべての次数が等しく、次の場合には自動的に素数になります。$k$プライムです。 

エッジの総数はハンドシェイク補題によって固定され、正確に次のようになります。$nk/2$。 この値の素数性を明示的にテストするため、グローバル制約は調整ではなく選択によって満たされます。 

重要な不変条件は、グラフが常に$k$構築中は -normal であり、オフセットは一方向にのみ適用されるため、エッジは複製されません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def sieve(n):
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    for i in range(2, int(n ** 0.5) + 1):
        if is_prime[i]:
            for j in range(i * i, n + 1, i):
                is_prime[j] = False
    return is_prime

def is_prime_small(x):
    if x < 2:
        return False
    if x < len(PRIME):
        return PRIME[x]
    return False

n = int(input())
PRIME = sieve(2000)

for k in range(2, n):
    if not PRIME[k]:
        continue
    if (n * k) % 2 != 0:
        continue
    m = (n * k) // 2
    if m >= len(PRIME) or not PRIME[m]:
        continue

    edges = []
    for i in range(n):
        for j in range(1, k // 2 + 1):
            u = i
            v = (i + j) % n
            edges.append((u + 1, v + 1))

    print(m)
    for u, v in edges:
        print(u, v)
    sys.exit()

print(-1)

構築ループは循環グラフを構築します。各頂点は次の頂点に接続されます。$k/2$頂点モジュロ$n$。 これにより対称性が確保され、エッジの重複が回避されます。 

有効なグラフはどれでも受け入れられるため、プログラムは最初の有効な構造を見つけた直後に終了します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n = int(input())

    is_prime = [True] * 5000
    is_prime[0] = is_prime[1] = False
    for i in range(2, int(len(is_prime) ** 0.5) + 1):
        if is_prime[i]:
            for j in range(i * i, len(is_prime), i):
                is_prime[j] = False

    for k in range(2, n):
        if not is_prime[k]:
            continue
        if (n * k) % 2 != 0:
            continue
        m = (n * k) // 2
        if m >= len(is_prime) or not is_prime[m]:
            continue

        edges = []
        for i in range(n):
            for j in range(1, k // 2 + 1):
                edges.append((i + 1, (i + j) % n + 1))

        out = [str(m)]
        out += [f"{u} {v}" for u, v in edges]
        return "\n".join(out)

    return "-1"

 ## 特殊なケース

 のために$n = 3$、単純なグラフには最大でも 3 つのエッジがありますが、次数制約により次数 0、1、または 2 のいずれかが強制され、そのいずれも一貫して素数性とグローバル エッジ素数性の両方を同時に満たすものはないため、通常、正しい答えは次のようになります。$-1$。 

偶数の場合$n$、2 つの通常のサイクルが機能すると予想されるかもしれませんが、エッジ数は正確になります。$n$、そしてそれ以来$n$が素数になることはほとんどなく、これはほとんどの場合失敗します。 たとえば、$n = 10$、サイクルは 10 個のエッジを与えますが、これは素数ではありません。 

大型の場合$n$、密な循環構造により次数が均一であることが保証され、正確さは完全に互換性のある素数ペアの選択にかかっています。$(k, m)$これにより、局所的な不一致の問題がすべて回避されます。
