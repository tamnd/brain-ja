 ## 解決策
 ## 問題の理解

 のサイズの長方形グリッドをタイル状に並べています$w \times h$, ここで、各セルには 1 つの正方形タイルが含まれている必要があります。 各タイルは、対角線に沿って黒と白の三角形の半分に分割された正方形です。 この構造のため、すべてのタイルは 2 つの色のエッジを持ちます。回転方法に応じて、色が単位正方形の異なる側面に表示されます。 

制約はローカルです。2 つのタイルがエッジを共有する場合は常に、そのエッジに沿って接する色は異なっていなければなりません。 言い換えれば、2 つの隣接するセル間の共有面ごとに、1 つのタイルはその面で黒を露出し、もう 1 つのタイルは白を露出する必要があります。 

タスクは満杯になった数を数える事です$w \times h$タイリングはこのルールを満たしており、各タイルは独立して回転でき、答えはモジュロで計算されます。$998244353$。 

制約により許可されるのは、$w, h \le 1000$これは、グリッドに最大 100 万個のタイルを含めることができることを意味します。 セルごとに独立して方向を割り当てようとしてから制約を素朴にチェックするソリューションは、すぐに爆発してしまいます。$4^{wh}$生の設定。 すべてのビットマスクにわたる行ごとまたは列ごとの DP であっても、状態をあまりにも明示的に扱う場合は大きすぎます。$2^w$実行不可能になるとき$w = 1000$。 

主な問題点は、選択はローカルであるにもかかわらず、制約がグリッド全体にグローバルに伝播することです。 

どちらかの次元が 1 の場合、微妙なエッジ ケースが発生します。$1 \times h$または$w \times 1$ストリップすると、隣接関係の制約が単純なチェーンになり、セル間の独立性の単純な解釈が崩れます。 もう 1 つのエッジケースは、次のような小さなグリッドです。$2 \times 2$ここで、対称性は実際に存在する構成よりも少ない構成を示唆する可能性がありますが、回転では見落としやすい多くの有効なローカル パターンが保存されます。 

## アプローチ

 各タイルは、エッジに沿って黒と白の間に「流れ」の方向を課しているように見えます。 重要な観察は、すべてのタイル構成でエッジ全体で黒と白が交互に配置されることです。これは、2 つのセル間のエッジに沿って、対角線の相対的な方向が一貫して異なる必要があることを意味します。 

ブルート フォース アプローチでは、4 つの回転のうち 1 つを各タイルに割り当て、すべての隣接制約を検証します。 これは探索します$4^{wh}$無効な部分的な状態は多くの場合、数回配置した後にのみ現れ、指数関数的な爆発につながるため、無効な部分的な状態を削除しても状態は保存されません。 

タイルの観点から考えるのをやめ、代わりにエッジのパリティ制約の観点から考えると、構造は管理可能になります。 上部の境界が固定されると、各行は一連の独立した選択のように動作し、それらの選択は決定論的な方法で下に伝播します。 重要なのは、各セルがその上と左に隣接するセルとのみ相互作用することです。これにより、グリッドが各セルの状態が 2 つの二分決定によって決定され、制約によってローカル ルールを超える長距離結合が決して作成されないシステムになります。 

これにより、構成空間をきれいに因数分解することができます。上の行と左の列の状態を自由に選択し、他のすべてのセルは強制されます。 有効な各タイリングは、グリッド構造全体にわたる独立したバイナリ選択肢の一貫した割り当てに対応し、セル全体で 2 のべき乗に因数分解された合計数が得られます。 

最終結果は、係数 4 を独立して寄与するすべてのセルに単純化されます。これは、隣接タイルが互換性を持って調整される限り、各タイルはローカル隣接条件に違反することなく 4 つの方法で方向を設定でき、制約によってローカル一貫性の確保を超えて自由度が低下することはなく、常に満足できるためです。 

したがって、タイリングの数は次のようになります。$4^{w \cdot h}$モジュロ$998244353$。

 ## アルゴリズムのチュートリアル

 1. グリッドを次のものとして解釈します。$w \cdot h$独立したセルであり、それぞれが有効なローカル構成の倍数に寄与します。 この独立性は、適切な回転ペアリングによってすべての隣接制約をローカルに満たすことができるという事実から生まれます。 
2. 各タイルには正確に 4 つの回転があり、これらの回転はいずれもエッジ互換性を強制する以上に他のタイルをグローバルに制限していないことを観察します。これにより、隣接するタイルには常に一致する選択肢が存在します。 
3. 各セルは総数の 4 倍に寄与すると結論づけます。したがって、答えは次のようになります。$4^{w \cdot h}$。 
4. モジュラスを使用した高速モジュラーべき乗を使用してべき乗を計算します。$998244353$、 以来$w \cdot h$まで可能です$10^6$。 

重要な不変条件は、タイルのサブセットを配置した後でも、配置されたタイル間のすべての境界が、次のタイルの回転の少なくとも 1 つの選択によって満たされるということです。 これにより、タイリングを拡張するときに自由度が低下することがなくなり、カウントは独立したセルの寄与に対する純粋な積のままになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modexp(base, exp):
    res = 1
    while exp > 0:
        if exp & 1:
            res = (res * base) % MOD
        base = (base * base) % MOD
        exp >>= 1
    return res

w, h = map(int, input().split())
print(modexp(4, w * h))
```コードは指数を計算します$w \cdot h$そしてモジュロ演算で 4 をその累乗します。 高速べき乗ループにより、指数サイズにおける対数時間が確保されます。 

唯一の微妙な実装の詳細は、製品の処理です。$w \cdot h$安全に。 Python では、標準の整数に問題なく収まりますが、他の言語では、べき乗の前にオーバーフローを回避する必要があります。

## テストケース```python
import sys, io

MOD = 998244353

def solve():
    w, h = map(int, sys.stdin.readline().split())
    def modexp(base, exp):
        res = 1
        while exp:
            if exp & 1:
                res = (res * base) % MOD
            base = (base * base) % MOD
            exp >>= 1
        return res
    print(modexp(4, w * h))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    from io import StringIO
    old_stdout = sys.stdout
    sys.stdout = StringIO()
    solve()
    out = sys.stdout.getvalue()
    sys.stdin = old_stdin
    sys.stdout = old_stdout
    return out.strip()

# provided sample
assert run("2 2\n") == "16"

# custom cases
assert run("1 1\n") == "4", "single tile"
assert run("1 3\n") == str(pow(4, 3, MOD)), "chain grid"
assert run("3 2\n") == str(pow(4, 6, MOD)), "rectangular grid"
assert run("1000 1000\n") == str(pow(4, 1000000, MOD)), "maximum size"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 1 | 4 | 基本セルの動作 |
 | 1 3 | 64 | 線形グリッドの正確性 |
 | 3 2 | 4096 | 一般的な長方形の一貫性 |
 | 1000 1000 | 大きなMODパワー | パフォーマンスと制限 |

 ## 特殊なケース

 あ$1 \times 1$グリッドはすべての隣接制約を削除し、1 つのタイルの 4 つの回転のみを残します。これは次の式に直接一致します。$4^1 = 4$。 あ$1 \times h$グリッドは、各エッジ制約が両方向で局所的に満たされるため、各タイルが依然として独立した回転自由度を持つチェーンに縮小されます。 いっぱい$1000 \times 1000$この定式化ではグリッド サイズに応じてカップリングが増加しないため、グリッドは組み合わせ構造ではなく、べき乗のみを強調します。
