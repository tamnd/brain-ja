 ## 問題の理解

 2 文字だけからなる文字列が与えられました。`v`そして`o`。 パターンを形成するこの文字列のサブシーケンスの数を数える必要があります。`"wow"`。 サブシーケンスとは、必ずしも連続しているわけではないインデックスを昇順に選択し、それらの位置にある文字を読み取ることを意味します。 したがって、有効なインデックスのすべてのトリプルは、$i < j < k$文字が`w`、`o`、`w`1 つのオカレンスに貢献します。 

重要な問題は、リテラルな表現がないことです。`w`入力内の文字。 代わりに、次のことが起こるたびに、`"vv"`単一の可能性として解釈する必要があります`w`、サブシーケンスはどちらかを選択できます`v`さまざまな方法で。 これは事実上、すべてのペアが`v`キャラクターは次のように行動できます`w`、そして 2 つを選択する方法が何通りあるかを数えています。`v`の前に`o`、そして2つ`v`その後です。 

文字列の長さは最大です$10^6$、これは直ちに除外します$O(n^2)$またはそれより悪いアプローチ。 平$O(n \log n)$不要です。 この構造は、スキャンしながらカウントを蓄積することで線形時間で解決できるはずであることを示唆しています。 

すべてのペアを列挙する素朴なアプローチ`v`すべての両側の文字`o`組み合わせ的に爆発するだろう。 あれば$k$の発生`v`、 がある$O(k^2)$それらのうち 2 つを選択し、それぞれに対してこれを行う方法`o`そのコストは再び倍増することになります。 これは、大規模な入力では実現不可能です。 

微妙なエッジケースは、何もない文字列から生じます。`o`まったく、答えはゼロでなければなりません。`"wow"`サブシーケンスは中間文字なしでも存在できます。 もう 1 つのケースは、2 つ未満の文字列です。`v`の合計です。ここでも、配置に関係なく、答えはゼロになります。

 ## アルゴリズムのチュートリアル

 を含む各立場からの貢献の観点から問題を書き直します。`o`。 

1. 何個数えるか`v`文字列全体に文字が出現します。 これにより、サフィックス計算用の初期プールが得られます。 右側の寄与は次の数に依存するため、これが必要です。`v`は各位置の後に残ります。 
2. プレフィックス配列を事前計算する`pref_v`、 どこ`pref_v[i]`の数です`v`インデックスで終わるプレフィックス内の文字`i`。 これにより、その数がすぐにわかります`v`はどの位置の左側にもあります。 
3. サフィックス配列を事前計算する`suf_v`、 どこ`suf_v[i]`の数です`v`インデックスの文字`i`最後まで。 これにより、右側の寄与を一定時間で計算できるようになります。 
4. ポジションごとに`i`どこ`s[i] == 'o'`、何ペアかを計算します。`v`を使用して左側に存在します$\binom{pref_v[i-1]}{2}$。 これは、左翼を形成する方法がどれだけあるかを表しています。`"w"`模様の一部。 
5. 同様に、次のペアの数を計算します。`v`を使用して右側に存在します$\binom{suf_v[i+1]}{2}$。 これは権利を表します`"w"`一部。 
6. これら 2 つの値を乗算し、その結果を答えに加算します。 左のペアと右のペアのそれぞれの選択により、有効な 1 つのペアが形成されます。`"wow"`これを中心とした続き`o`。 

### なぜ効果があるのか

 すべての有効な`"wow"`サブシーケンスは 2 つの異なるものを選択することによって一意に決定されます`v`の左側の位置`o`そして2つの異なる`v`同じ右側の位置`o`。 真ん中`o`固定されています。 プレフィックスとサフィックスのカウントにより、それらの位置が正確に考慮されることが保証され、組み合わせにより各選択が 1 回カウントされることが保証されます。 違うので`o`位置はサブシーケンスの中心として互いに素であるため、それらすべてを合計すると、重複や省略のない合計数が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def comb2(x):
    return x * (x - 1) // 2

def solve():
    s = input().strip()
    n = len(s)

    pref_v = [0] * (n + 1)
    for i in range(n):
        pref_v[i + 1] = pref_v[i] + (s[i] == 'v')

    suf_v = [0] * (n + 2)
    for i in range(n - 1, -1, -1):
        suf_v[i] = suf_v[i + 1] + (s[i] == 'v')

    ans = 0
    for i, ch in enumerate(s):
        if ch == 'o':
            left = pref_v[i]
            right = suf_v[i + 1]
            ans += comb2(left) * comb2(right)

    print(ans)

if __name__ == "__main__":
    solve()
```コードはまず、次のプレフィックスとサフィックスの数を構築します。`v`そのため、各クエリはいくつあるかについて`v`の両側に横たわります`o`一定時間になります。 ヘルパー関数`comb2`2 つを選択する方法の数を計算します`v`グループの出身です。 

それぞれを反復処理するとき`o`、私たちは意図的に使用します`pref_v[i]`それよりも`pref_v[i+1]`それは、厳密に左側の文字のみを考慮することが保証されるからです。 同様に、`suf_v[i+1]`厳密に右側の文字のみを考慮し、誤って再利用することを防ぎます。`o`位置。

 ## 特殊なケース

 なしの文字列の場合`o`、位置をめぐるループは寄与ステップをトリガーしないため、答えはゼロのままです。 たとえば、入力`vvvvvv`プレフィックス数は得られますが、センターは得られないため、`"wow"`サブシーケンスがカウントされます。
