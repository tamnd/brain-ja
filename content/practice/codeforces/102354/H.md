 ## 解決策
 ## 問題の理解

 原点の周りには偶数の衛星があります。 各衛星は、整数の極角、原点からの距離、および質量によって記述されます。 2 つの衛星が角度を共有することはないため、すべての整数角度位置には最大でも 1 つの衛星が含まれます。 

Elphaba は原点から始まる光線を選択します。 彼女は、原点からすべての正の距離で、光線自体に沿って正確に指すために、その光線に沿ったすべての重力を必要とします。 出力は、アーク秒単位で測定された、そのようなすべての光線方向のセットです。 直線には 2 つの反対の光線があるため、1 つの有効な対称軸により 64,800 秒角離れた 2 つの出力方向が得られます。 

物理公式は複雑に見えますが、関連する性質ははるかに単純です。 原点を通る候補線の場合、線の片側のすべての衛星には、原点からの距離と質量がまったく同じで、反対側に一致する衛星がなければなりません。 回線を介した反射では、完全な加重衛星構成が維持される必要があります。 これが問題の中心的な軽減です。 同じ対称性の観察は、元の問題の意図された単純化でもあります。 

角度ドメインには 129,600 個の整数位置のみが含まれます。 このステートメントでは (n) を (2\cdot10^5) まで許可しますが、整数の角度の一意性は実際には (n\le129600) を意味します。 二次アルゴリズムでは、2 秒の制限をはるかに超えて、可能な最大入力でおよそ (1.7\cdot10^{10}) の比較が必要になります。 固定角度領域における線形または線形に近いアルゴリズムが必要です。 

間違った実装がサイレントに失敗する簡単な場所が 3 つあります。 まず、軸は衛星上に正確に存在することができます。 のために```
2
1 0 1
1 64800 1
```この構成には (0^\circ) と (90^\circ) に反射軸がありますが、(0^\circ) 軸は両方の衛星を通過するため禁止されています。 (90^\circ) 行だけが残り、次のようになります。```
2
32400.0000000
97200.0000000
```固定衛星を明示的に拒否しない対称チェッカーは、誤って 4 方向を出力します。 

第 2 に、対称軸は整数の角度を持つ必要はありません。 と```
2
1 0 1
1 1 1
```2 つの衛星は (0.5) 秒角でラインを越えて互いに反射します。 正しい出力は次のとおりです```
2
0.5000000000
64800.5000000000
```答えを整数の円弧秒としてのみ保存するソリューションでは、この軸が失われます。 

3 番目に、角度は (129600) で回り込みます。 と```
2
1 1 1
1 129599 1
```衛星は角度 (0) に関して対称であるため、答えは次のようになります。```
2
0.0000000000
64800.0000000000
```(1) と (129599) を円上で隣接するのではなく遠く離れたものとして扱う実装では、この対称性が失われる可能性があります。 

## アプローチ

 ブルートフォースアプローチは、幾何学的特徴付けから始まります。 考えられるすべての反射軸について、すべての衛星を反射し、同じ半径と質量を持つ衛星が反射角に存在するかどうかを確認します。 (129600) 個の可能な 2 倍軸位置があり、各チェックで (n) 個の衛星を検査できるため、(O(129600n)) が得られます。これは、最大サイズで約 (1.7\cdot10^{10}) 回の操作になります。 衛星ペアから候補軸を生成し、各候補を直接チェックする場合でも、同じ二次関数のボトルネックがあります。 

リフレクションがまさに必要な条件であるため、総当たり攻撃は機能しますが、ほぼ同じ構成が繰り返しチェックされます。 重要な観察は、角度領域が長さ 129,600 の小さな固定円であるということです。 完全な衛星情報を角度でインデックス付けされた配列に入れることができます。 各配列要素にはペア ((\rho,m)) が含まれており、空の角度には特別なマーカーが付けられます。 

ここで、問題は純粋に組み合わせの問題になります。 反射軸の角度が 2 倍 (s) であると仮定します。これは、実際の角度が (s/2) であることを意味します。 角度 (x) の衛星が反射されます。 

[
 s-x \pmod {129600}。 
]

 したがって、構成は次の場合に正確に対称になります。 

[
 A[x]=A[s-x\bmod129600]
 ]

 すべての角度位置 (x) について。 

反転した循環配列を定義する

 [
 B[x]=A[-x\bmod129600]。 
]

 すると、対称条件は次のようになります。 

[
 A[x]=B[x-s\bmod129600]。 
]

 言い換えれば、(A) は (B) の巡回シフトと等しくなければなりません。 2 つの文字列が等しいすべての巡回シフトを見つけることは、標準的な線形文字列マッチング問題です。 (B) を複製し、KMP を使用して (B+B) 内の (A) を検索し、(O(129600+n)) 時間ですべての可能な反射軸を取得できます。 

対称軸を見つけた後も、飛行ラインに衛星が含まれていないという要件を強制する必要があります。 (s) が奇数の場合、方程式は次のようになります。 

[
 2x=s\pmod{129600}
 ]

 には整数解がないため、衛星は軸上に存在できません。 (s) が偶数の場合、2 つの固定角度位置は次のようになります。 

[
 x=\frac{s}{2}
 ]

 そして

 [
 x=\frac{s}{2}+64800。 
]

 いずれかの位置に衛星が含まれている場合、その対称軸は拒否されます。 

最後に、2 倍の角度 (s) を持つ有効な線は 2 つの飛行方向を表します。 それらの 2 倍の角度は (s) と (s+129600) であるため、実際の角度は (s/2) と (s/2+64800) になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(n\cdot129600)) | (O(n)) | 遅すぎる |
 | 最適 | (O(n+129600)) | (O(129600)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 長さ (L=129600) の配列 (A) を作成します。 位置 (\varphi_i) にペア ((\rho_i,m_i)) を格納します。 衛星のないあらゆる角度で特別な空の値を保存します。 反射では単に角度位置だけでなく実際の衛星を保存する必要があるため、このペアには半径と質量の両方が含まれている必要があります。 
2. 設定により循環逆配列 (B) を構築します。 

[
 B[x]=A[-x\bmod L]。 
]

 配列形式では、これは (A[0]) であり、その後に (A[L-1])、(A[L-2]) が続き、(A[1]) まで続きます。 この正確なインデックス作成により、リフレクションが循環シフトに変わります。 

1. (A) の KMP プレフィックス関数を構築します。 プレフィックス関数を使用すると、不一致後に比較を再開することなく、別のシーケンス内の (A) のすべての出現を線形時間で見つけることができます。 
2. シーケンス (B+B) をスキャンしますが、位置 (0,\ldots,L-1) から始まる出現のみを考慮します。 (A) が位置 (p) から始まる場合、

 [
 A[x]=B[p+x]=A[-p-x]。 
]

 これを (A[x]=A[s-x]) と比較すると、次のようになります。 

[
 s\equiv-p\pmod L.
 ]

 したがって、KMP の一致ごとに、2 倍の軸角度 (s=(-p)\bmod L) の候補が 1 つ与えられます。

1. 候補が偶数で、固定位置 (s/2) または (s/2+L/2) に衛星が含まれている場合、候補を拒否します。 これらはまさに、計画されている飛行ライン上にあるであろう地点です。 
2. 残りの (s) ごとに、2 倍の飛行方向 (s) と (s+L) を追加します。 角度を 2 倍にして保存すると、アルゴリズム中の浮動小数点演算が完全に回避され、0.5 秒角の答えも正確に処理されます。 
3. 二重化された方向をすべてソートし、それぞれを 2 で割って印刷します。 偶数の 2 倍の角度は、小数部が 0 の整数として出力されますが、奇数の 2 倍の角度は末尾が 0 になります。`.5`。 

これが機能する理由: 有効な飛行ラインには、その上のすべての点でラインに垂直な重力成分がゼロです。 候補線を(x)軸とする座標を考えます。 ((a,b)) にある衛星は、次の値に比例する垂直成分に寄与します。 

[
 \frac{m b}{((x-a)^2+b^2)^{3/2}}。 
]

 この合計が (x) ごとに消えるには、すべての軸外衛星によって生成される特異な寄与が、同じ質量、したがって同じ半径と質量のペアを持つ ((a,-b)) で反射された衛星によってキャンセルされなければなりません。 したがって、すべての有効な線は、重み付けされた衛星構成の反射対称軸になります。 逆に、構成が対称の場合、反射衛星の各ペアは軸上に等しい逆向きの垂直力を生成するため、力の合計はどこでも軸に平行になります。 KMP ステップではこれらの反射対称性を正確に検出し、固定位置チェックでは衛星を含む禁止軸を正確に削除します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

L = 129600
EMPTY = (-1, -1)

def solve():
    n = int(input())

    a = [EMPTY] * L

    for _ in range(n):
        rho, phi, mass = map(int, input().split())
        a[phi] = (rho, mass)

    # B[x] = A[-x mod L].
    b = [a[0]] + a[:0:-1]

    # KMP prefix function for pattern A.
    pi = [0] * L
    j = 0

    for i in range(1, L):
        while j and a[i] != a[j]:
            j = pi[j - 1]
        if a[i] == a[j]:
            j += 1
        pi[i] = j

    candidates = []

    # Search A inside B+B.
    # We only need starts p in [0, L-1], so the text needs 2L-1 elements.
    j = 0

    for i in range(2 * L - 1):
        value = b[i] if i < L else b[i - L]

        while j and value != a[j]:
            j = pi[j - 1]

        if value == a[j]:
            j += 1

        if j == L:
            p = i - L + 1
            if p < L:
                s = (-p) % L

                # If s is even, these are the two fixed angular positions.
                if s % 2 == 0:
                    x = s // 2
                    y = x + L // 2
                    if a[x] != EMPTY or a[y] != EMPTY:
                        j = pi[j - 1]
                        continue

                candidates.append(s)

            j = pi[j - 1]

    # Each reflection axis gives two opposite flight directions.
    directions = []
    for s in candidates:
        directions.append(s)
        directions.append(s + L)

    directions.sort()

    out = [str(len(directions))]
    for d in directions:
        if d & 1:
            out.append(f"{d // 2}.5000000000")
        else:
            out.append(f"{d // 2}.0000000000")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```実装の最初の部分では、角度構成全体を長さ 129,600 の配列に格納します。 角度はすでに配列インデックスで表されているため、リフレクションで必要な衛星情報を識別するにはタプル ((\rho,m)) で十分です。 

建設`a[0] + a[:0:-1]`注目に値する。 インデックス (x) の目的の要素は (A[-x\bmod L]) であるため、インデックス 0 は先頭に残り、残りの要素は逆の順序で表示されます。 普通の`a[::-1]`(A[L-1]) をインデックス 0 に置き、代わりにシフトされた反射を表します。 

KMP プレフィックス関数はタプルの等価性を直接使用します。 Python の整数は、オーバーフローすることなく入力半径と質量を保持でき、配列の構築後に (\rho_i) または (m_i) を伴う算術演算は必要ありません。 

KMP スキャンでは、(2L-1) 個のテキスト位置が使用されます。 位置 (p<L) で始まる完全なパターンの出現は (p+L-1) で終了するため、(2L-2) までの位置で十分です。 変換`s = (-p) % L`これは、逆順での一致と反映の間の関係から直接導き出されます。 

固定小数点テストは、対称性テストとは別のものです。 衛星をその線上に配置しながら、構成を線の周りで真に対称にすることができます。 そのようなラインはエルファバでは使用できないため、それらの候補は破棄される必要があります。 

出力は、最終的なフォーマットまで 2 倍の角度を使用して表されます。 これにより、浮動小数点の丸めが完全に回避されます。 特に、(0.5) 秒角の軸は 2 倍の角度 (1) で表され、次のように正確に印刷されます。`0.5000000000`。 

## 実用的な例

 ### サンプル 1

 角度 (0) と (64800) にある 2 つの衛星の場合、角度配列には互いに向かい合った 2 つの同一のエントリが含まれています。 反転された循環配列は元の配列と同一であるため、KMP は 2 つの循環一致を見つけます。 

| KMP スタート (p) | 2 倍軸 (s=(-p)\bmod L) | 固定衛星 | 有効 |
 | --- | --- | --- | --- |
 | 0 | 0 | 角度 0 と 64800 | いいえ |
 | 64800 | 64800 | なし | はい |

 候補 (s=0) は水平軸を表しますが、両方の衛星がその上に直接あります。 候補 (s=64800) は垂直軸を表しており、その上には衛​​星がありません。 その 2 つの飛行方向は (64800/2=32400) と ((64800+129600)/2=97200) です。 

### 半秒角の例

 検討してください```
2
1 0 1
1 1 1
```有効な対称軸は、2 つの占有位置の中間にあります。 

| KMP スタート (p) | 倍軸 (秒) | 固定位置 | 有効 |
 | --- | --- | --- | --- |
 | 129599 | 1 | なし | はい |

 ここでは (s=1) なので、軸角度は (1/2=0.5) になります。 その逆の方向は (0.5+64800=64800.5) です。 

このトレースは、2 倍の角度が役立つ理由を示しています。 半整数の答えを見つけたり比較したりするために浮動小数点計算を行う必要はありません。

        if value == a[j]:

 最初のエッジ ケースは、軸が衛星を通過する対称構成です。 のために```

1 0 1
1 64800 1
```候補 (s=0) は両方の占有位置が反射によって固定されているため、真の反射対称です。 固定位置チェックでは位置 (0) と (64800) に衛星があることが確認されるため、候補は拒否されます。 もう 1 つの候補 (s=64800) には固定の占有位置がなく、2 つの有効な方向 (32400) と (97200) が生成されます。 

2 番目のエッジ ケースは半整数方向です。 のために```
2
1 0 1
1 1 1
```一致する巡回シフトにより (s=1) が得られます。 (s) が奇数であるため、(2x=s) を満たす整数の角度位置は存在しないため、衛星は軸上に存在できません。 このアルゴリズムは、2 倍の方向 (1) を保存してから出力 (1/2=0.5) し、さらに反対方向 (64800.5) も出力します。 

3 番目のエッジ ケースは、角度のあるラップアラウンドです。 のために```
2
1 1 1
1 129599 1
```軸 (0) の周りの角度 (1) の反射位置は次のとおりです。 

[
 0-1\equiv129599\pmod{129600}。 
]

 円形反転配列と KMP マッチングは完全な角円を法として動作するため、この対称性は角度がゼロに近い場合の特別なケースなしで見つかります。 結果として得られる方向は (0) と (64800) です。 

最後のエッジ ケースは、完全に占有された角円です。 すべての整数角度に 1 つの同一の衛星がある場合、すべての奇数 2 倍軸は有効な鏡映対称になります。これは、整数位置をペアで交換し、固定整数位置がないためです。 すべての偶数には固定の占有位置があり、禁止されています。 ([0,129600)) には (s) の奇数値が 64,800 個あり、それぞれが 2 つの反対方向を生成するため、出力には正確に 129,600 方向が含まれます。 これは、角度ドメインで許可される最大の出力でもあります。
