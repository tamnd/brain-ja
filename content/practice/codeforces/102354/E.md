 ## 解決策
 ## 問題の理解

 定数は次のように書き換えることができます

 [
 \varphi=\prod_{k=1}^{\infty}(1-10^{-k})、
 】

 なぜなら、(k) 番目の因数は正確に ((10^k-1)/10^k) であるからです。 小数点以下の位置 (n) を占める数字が必要です。(n) は (10^{18}) と同じくらい大きい場合があります。 

最大 (10^5) 個の独立したクエリがあります。 クエリごとに (O(n)) または (O(\sqrt n)) 個の作業を費やすメソッドは遅すぎます。 最大 (n) の場合、(O(n)) は 1 つのクエリに対して約 (10^{18}) の演算を必要としますが、(O(\sqrt n)) は依然としてクエリ当たり約 (10^9) の演算を必要とします。 解決策は、無限積の正確な構造を利用し、基本的に一定時間で各位置に応答する必要があります。 

最初の罠は、製品自体が 10 進数を直接公開しないことです。 たとえば、有用な展開の最初の項の係数が (-1) であっても、最初の 2 桁は (8) と (9) です。 (10^{-n}) の係数を単純に見ると、負の値が得られ、小数借用が必要であることを忘れてしまいます。 入力用```
1
1
```答えは```
8
```展開は (0.89\ldots) から始まるため、(-1) ではありません。 

2 番目の境界ケースは、(n) が展開に現れる特殊指数の 1 つである場合に発生します。 例えば、```
1
5
```答えは(1)です。 指数 (5) は (+10^{-5}) に寄与しますが、その後の項は借用が必要かどうかに影響します。 ここでは、係数のみを最終桁として扱うことはたまたま機能しますが、同じショートカットは (n=7) で失敗します。係数は (+1) ですが、正しい桁は (0) です。 

3 番目の境界は特殊指数の直後に表示されます。 のために```
1
6
```小数点以下の桁数が (6) に達した時点で、(10^{-5}) の寄与はすでに整数接頭辞の一部になっているため、答えは (0) です。 次の特殊指数のみを調べる不注意な実装では、誤って (1) が返される可能性があります。 

## アプローチ

 直接的なアプローチでは要因が倍増します

 [
 (1-10^{-1})(1-10^{-2})(1-10^{-3})\cdots
 】

 十分に高い精度を実現し、目的の小数点以下の位置を検査します。 (n) より大きいインデックスを持つ因子は、小数点以下の最初 (n) 桁にかなりの量の影響を与えることができないため、これは小さい (n) 場合に機能します。 ただし、(n=10^{18}) の場合、最初の (n) 桁の 10 進数を構成することさえ不可能です。 1 つのクエリに対するブルート フォース作業は (\Theta(n)) であり、許可される最大位置ですでに (10^{18}) 桁レベルの操作になります。 

重要な観察は、オイラーの五角形の数定理です。 正確な拡張を実現します

 1+\sum_{k=1}^{\infty}(-1)^k
 \左(
 x^{k(3k-1)/2}+x^{k(3k+1)/2}
 \右）。 
】

 (x=1/10) を代入すると、次のようになります。 

1+\sum_{k=1}^{\infty}(-1)^k
 \左(
 10^{-k(3k-1)/2}
 +
 10^{-k(3k+1)/2}
 \右）。 
】

 したがって、ほぼすべての小数点の係数はゼロになります。 非ゼロ係数のみが一般化五角形数で発生します

 [
 P_k^-=\frac{k(3k-1)}2,
 \qquad
 P_k^+=\frac{k(3k+1)}2,
 】

 両方の位置に係数 ((-1)^k) があります。 

この疎性により、問題は、(n) の周りの 2 つの連続する一般化五角形数を見つけることに帰着します。 10 進数の接頭辞を作成する必要はありません。 拡張に (10^n) を乗算すると、指数が (n) より小さいすべての項は (10) の整数倍になるため、(10) を法とする最後の 10 進数の桁には影響しません。 重要なローカル情報は、指数 (n) の係数と、(n) の後に始まる無限の尾部が正か負かだけです。 

尾部の大きさは (1/9) 未満です。 その最初の項は、後のすべての項の合計よりも厳密に大きいため、尾部の符号は正確に最初の項の符号となります。 したがって、次の一般化五角形指数が係数 (+1) を持つ場合、借用は発生しません。 係数 (-1) がある場合、位置 (n) の係数から 1 単位を借用する必要があります。 

関連する (k) は (\sqrt{n}) 付近にありますが、そこまでは繰り返しません。 解決中

 [
 \frac{k(3k-1)}2\le n
 】

 与える

 [
 k\le \frac{1+\sqrt{24n+1}}6.
 】

 整数の平方根を使用すると、この (k) を直接取得できるため、すべてのクエリで (O(1)) の算術演算が必要になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(n)) クエリごと | (O(n)) | 遅すぎる |
 | 最適 | (O(1)) クエリごと | (O(1)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. クエリ (n) について、次を計算します。 

[
 k=\left\lfloor\frac{1+\sqrt{24n+1}}6\right\r フロア。 
】

 これは、(P_k^-\le n) の最大 (k) です (P_k^-=k(3k-1)/2)。 

1. これ (k) に属する 2 つの一般化された五角形の位置を計算します。 

[
 a=P_k^-、
 \qquad
 b=P_k^+。 
】

 これらは、(b) の後の次の位置が (P_{k+1}^-) であることを除いて、展開内で連続して表示されます。 

1. 位置 (n) の係数を決定します。 (n=a) の場合、係数は ((-1)^k) です。 (n=b) の場合、係数も ((-1)^k) になります。 それ以外の場合、係数はゼロになります。 
2. (n) より厳密に大きい最初の指数を決定します。 (n<b) の場合は (b) です。 (n\ge b) の場合、(P_{k+1}^-) となります。 その係数の符号は、最初の場合は ((-1)^k)、2 番目の場合は ((-1)^{k+1}) になります。 
3. 位置 (n) の係数から開始します。 最初に省略された項が負の場合は、1 を減算します。 最後に、結果のモジュロ (10) を取得します。これにより、(-1) などの値が 10 進数 (9) に変換されます。 
4. 結果の数字を出力に追加します。 すべてのクエリを個別に処理すると、必要な一連の数字が得られます。 

借用ルールの理由は、(10^n) を乗算すると最も簡単にわかります。 書く

 [
 10^n\varphi=S+R、
 】

ここで、(S) には最大でも指数 (n) を持つすべての項が含まれ、(R) には残りの項が含まれます。 数値 (S) は整数です。 剰余は (|R|<1/9) を満たし、その符号は最初の項の符号と等しくなります。 したがって、(\lfloor10^n\varphi\rfloor) は、(R>0) の場合は (S)、(R<0) の場合は (S-1) になります。 モジュロ (10) では、指数 (n) の係数のみが (S) に残り、上記のアルゴリズムが正確に得られます。 

### なぜ効果があるのか

 不変条件は、位置 (n) 以降、(10^n\varphi) の整数部分を決定する目的で、無限の尾全体が小さな正の分数または小さな負の分数とまったく同様に動作することです。 最初に省略された五角形の項は、その絶対値がその後の省略されたすべての項を支配するため、どのケースが発生するかを決定します。 一方、以前の各項は (10^n) を乗算した後に (10) の倍数に寄与するため、指数 (n) の係数のみが整数プレフィックスの最後の桁を決定します。 したがって、アルゴリズムは、ローカル係数と単一の借入の両方の考えられる影響を考慮し、異なる桁を生成することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def digit(n):
    # k is the largest integer with k(3k-1)/2 <= n.
    k = (1 + (24 * n + 1) ** 0.5) // 6

    # Floating point is not safe for n up to 10^18.
    # Recompute using integer square root.
    s = math.isqrt(24 * n + 1)
    k = (1 + s) // 6

    while (k + 1) * (3 * (k + 1) - 1) // 2 <= n:
        k += 1
    while k * (3 * k - 1) // 2 > n:
        k -= 1

    a = k * (3 * k - 1) // 2
    b = k * (3 * k + 1) // 2

    if n == a or n == b:
        cur = 1 if k % 2 == 0 else -1
    else:
        cur = 0

    if n < b:
        next_sign = 1 if k % 2 == 0 else -1
    else:
        next_sign = -1 if k % 2 == 0 else 1

    if next_sign < 0:
        cur -= 1

    return cur % 10

def solve():
    t = int(input())
    ns = list(map(int, input().split()))

    ans = []
    for n in ns:
        ans.append(str(digit(n)))

    print(" ".join(ans))

if __name__ == "__main__":
    import math
    solve()
```最初の計算では、(n) を含む一般化された五角形ブロックが見つかります。 整数の平方根が使用されるのは、(n) が (10^{18}) に達する可能性があり、浮動小数点の平方根では、(k) を 1 つ移動するには完全平方に近い精度が失われる可能性があるためです。 補正ループは実際には定数時間であり、整数の平方根の式が隣接する候補に到達した場合でも境界を正確にします。 

変数`a`そして`b`は (k) に属する 2 つの指数です。 (n) をそれらと比較すると、現在の係数が (0) であるか ((-1)^k) であるかが決まり、次にどの五角形の数が来るかもわかります。 

表現`next_sign`無限サフィックスが作成できる唯一のキャリーまたはボローをキャプチャします。 負の接尾辞はフロアを 1 つ変更します。`cur -= 1`は完全な小数桁上げ調整です。 

Python の整数には任意の精度があるため、(24n+1) や (k) を含む積などの値は、特別なオーバーフロー処理を行わなくても安全です。 このコードでは、バッファリングされた入力も使用し、1 回の出力操作ですべての応答を生成します。これは、(10^5) テスト ケースにとって重要です。
