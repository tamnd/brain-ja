 ## 解決策
 ## 問題の理解

 同じセットに 2 つの異なるツリーがあります。`N`頂点。 最初のツリーは現在の構造で、2 番目のツリーは目的の最終構造です。 1 つの操作で既存のエッジを 1 つ切り取り、別のエッジを追加するため、グラフはツリーのままになります。 

目標は、操作の最小数を見つけることだけではなく、ターゲット ツリーに到達する実際の操作シーケンスを出力することです。 

重要な数量は、両方のツリーが共有するエッジの数です。 すべての共有エッジはすでに正しいので、移動する必要はありません。 元のツリー内の 1 つおきのエッジが消える必要があり、ターゲット ツリーから失われたすべてのエッジが表示される必要があります。 1 回の操作で 1 つのエッジが置き換えられるため、答えは元のツリー内の非共有エッジの数になるはずです。 

と`N`まで`100000`の場合、操作ごとにツリー全体を繰り返し検索するソリューションは、速度が非常に遅くなります。 二次アプローチでは次のことが必要になります`10^10`通常のコンテストの制限では不可能な、最悪の場合のチェックを行います。 線形に近い、または`N log N`工事。 

難しい部分は、答えを計算することではなく、すべての中間グラフがツリーのままになる順序で有効な演算を生成することです。 

小さな特殊なケースとしては、両方のツリーがすでに同一である場合があります。 

例：```
Input
3
1 2
2 3
1 2
2 3
```正しい出力は次のとおりです。```
0
```すべての元のエッジの置換を常に実行しようとする不注意な解決策は、正しいエッジを破壊し、不必要な操作を生成することになります。 

もう 1 つのエッジ ケースは、最初のツリーにターゲット ツリーにないエッジが含まれているが、それを削除すると、1 つのターゲット エッジだけがコンポーネントを再接続できるように頂点が分離される場合です。 

例：```
Input
4
1 2
2 3
3 4
1 3
3 4
2 4
```アルゴリズムは、間違ったエッジを削除することによって作成されたカットと交差するターゲット ツリーからエッジを選択する必要があります。 任意の欠落しているターゲット エッジを選択すると、グラフが切断される可能性があります。 

## アプローチ

 ブルートフォースのアイデアは、現在のツリーとターゲット ツリーの間で異なるエッジを繰り返し見つけて削除し、結果として得られる 2 つのコンポーネントを再接続するエッジが見つかるまですべてのターゲット エッジを検索することです。 これは正しいです。カットを横切るエッジは木を復元するからです。 ただし、置換のたびにすべてのエッジをスキャンすると、最悪のケースは次のようになります。`O(N^2)`操作が遅すぎるため、`N = 100000`。 

有益な観察は、すべてのターゲット エッジが存在するまでターゲット エッジを追加するだけでよいということです。 すべての操作で、共有エッジの数が 1 つだけ増加します。 課題は、現在のカットを横切る有効なターゲット エッジを効率的に見つけることです。 

原木を葉から上に向かって加工していきます。 元のエッジがターゲット ツリーにすでに存在する場合は、それを保持して 2 つの辺をマージします。 それ以外の場合は、それを削除し、同じカットと交差するターゲット エッジを見つけます。 ターゲットツリーが接続されているため、ターゲットエッジは存在することが保証されます。 

このようなエッジを効率的に見つけるために、現在マージされているすべてのコンポーネントを残してターゲット エッジを維持します。 セットは小から大への手法を使用してマージされるため、すべてのエッジはセットのみを変更します。`O(log N)`回。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(N²) | O(N) | 遅すぎる |
 | 最適 | O(N log N) | O(N log N) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ターゲット ツリーのすべてのエッジをセットに保存すると、最終構造にエッジがすでに存在するかどうかをすぐに確認できます。 
2. 元のツリーを任意にルートし、事後走査を取得します。 親よりも前に子を処理するということは、親へのエッジを処理するときに、子側がすでにファイナライズされていることを意味します。 
3. すでに追加されているターゲット エッジによって接続されているコンポーネントを表す DSU 構造を維持します。 DSU コンポーネントごとに、コンポーネントから出るターゲット エッジを保存します。 
4. 元の木の端ごとに`(u, parent[u])`、ターゲットツリーにすでに存在するかどうかを確認します。 
5. エッジが共有されている場合、この接続は永久に残るため、2 つの DSU コンポーネントをマージします。 
6. エッジが共有されていない場合は、削除します。 を含むコンポーネントの出力ターゲット エッジを検索します。`u`もう一方の端点が別のコンポーネントに属するエッジが見つかるまで。 そのエッジを置換として追加し、2 つの DSU コンポーネントをマージします。 
7. すべての元のエッジが処理されるまで続行します。 記録された操作は必要最小限のシーケンスです。 

なぜ効果があるのか:

 非共有エッジを処理するたびに、間違ったエッジを 1 つ削除し、欠落しているターゲット エッジを 1 つ追加します。 共有エッジの数が 1 つ増加します。 ターゲット ツリーには、現在のツリーからエッジを削除することによって作成されたカットと交差するエッジが常に含まれます。そうしないとターゲット ツリーが切断されてしまうからです。 したがって、すべての置換は有効です。 すべての操作で 1 つの間違ったエッジが修正されるため、操作の数は最小限で済みます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    tree = [[] for _ in range(n)]
    edges1 = []

    for _ in range(n - 1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        edges1.append((u, v))
        tree[u].append(v)
        tree[v].append(u)

    target_edges = []
    target_set = set()

    for _ in range(n - 1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        target_edges.append((u, v))
        target_set.add((min(u, v), max(u, v)))

    parent = [-1] * n
    order = [0]
    parent[0] = -2

    for u in order:
        for v in tree[u]:
            if parent[v] == -1:
                parent[v] = u
                order.append(v)

    dsu = list(range(n))
    bag = [set() for _ in range(n)]

    for i, (u, v) in enumerate(target_edges):
        bag[u].add(i)
        bag[v].add(i)

    def find(x):
        while dsu[x] != x:
            dsu[x] = dsu[dsu[x]]
            x = dsu[x]
        return x

    def merge(a, b):
        a = find(a)
        b = find(b)
        if a == b:
            return a
        if len(bag[a]) < len(bag[b]):
            a, b = b, a
        dsu[b] = a
        bag[a].update(bag[b])
        bag[b].clear()
        return a

    def get_crossing(comp):
        comp = find(comp)
        s = bag[comp]
        while s:
            eid = next(iter(s))
            a, b = target_edges[eid]
            if find(a) == find(b):
                s.remove(eid)
            else:
                return eid
        return -1

    ans = []

    for u in reversed(order[1:]):
        p = parent[u]
        key = (min(u, p), max(u, p))

        if key in target_set:
            merge(u, p)
        else:
            eid = get_crossing(u)
            a, b = target_edges[eid]
            ans.append((u + 1, p + 1, a + 1, b + 1))
            merge(u, p)
            merge(a, b)

    print(len(ans))
    for a, b, c, d in ans:
        print(a, b, c, d)

if __name__ == "__main__":
    solve()
```実装の最初の部分では、2 つのツリーを構築し、ターゲット エッジを正規化された形式で保存します。`(min, max)`形状。 これにより、方向のないエッジが 2 方向に書き込まれる可能性があるという事実によって引き起こされる間違いが回避されます。 

DSU は、既に修正されているエッジによって形成されるコンポーネントを追跡します。 の`bag`配列には、コンポーネントを別のコンポーネントに接続する可能性のあるターゲット エッジが格納されます。 マージ ルーチンは常に小さいセットを大きいセットに移動します。`O(N log N)`縛られた。 

元のツリーはリーフからルートに向かって処理されるため、走査順序は逆になります。 エッジが削除されると、アルゴリズムは、子側が現在の DSU コンポーネントによってすでに表されていることを認識します。

## 特殊なケース

 ツリーが同一である場合、元のエッジはすべて共有されているものとして認識されます。 DSU は、ツリー全体が 1 つのコンポーネントになるまでコンポーネントをマージするだけで、操作は生成されません。 

すべてのエッジが異なる場合、処理されたすべてのエッジを交換する必要があります。 削除するたびにカットが作成され、ターゲット ツリーにはそのカットを横切るエッジが含まれている必要があるため、アルゴリズムは引き続き機能します。 DSU 検索はそのようなエッジを正確に検出し、操作のたびに接続を維持します。 

チェーン状のツリーの場合、最初に葉を処理することが不可欠です。 ツリー構造を尊重せずに内部エッジを早期に削除すると、正しいコンポーネント情報を見つけることが困難になる可能性があります。 ポストオーダー トラバーサルにより、コンポーネント情報がツリーのすでに固定された部分を表すことが保証されます。
