 ## 解決策
 ## 問題の理解

 文字列があります`S`長さの`N + 1`、グリッドの対角線上の各位置には、次のいずれかのラベルが付けられます。`A`または`B`。 

トークンは次から始まります`(0, 0)`で`(N + 1) × (N + 1)`グリッド。 プレーヤーは交互に移動し、移動するたびに行インデックスまたは列インデックスが 1 ずつ増加します。 トークンがセルに到達するとすぐにゲームが停止します`(i, j)`と`i + j = N`。 

対角セル`(i, N - i)`性格に対応する`S[i]`。 

もしそのキャラクターが`A`, アリスが勝ちます。 そうであれば`B`、ボブが勝ちます。 

アリスが最初に動き、両方のプレイヤーが最適にプレイします。 課題は、単一のゲーム インスタンスを解決することではありません。 その代わりに、すべての中で`2^(N+1)`可能な文字列`S`、何人がアリスを勝者にするかを数えなければなりません。 答えは必須です`10^9 + 3233`。 

重要な制約は、`N ≤ 100000`。 すべての文字列を検査する解決策は不可能です。 ゲームグラフ全体にわたる動的なプログラムさえも必要ありません。 意図された解決策は、閉じた形式の計数引数であり、べき乗モジュラーのみが必要であるため、対数時間になります。 

よくある間違いは、文字列のすべての文字が重要であると考えることです。 実際には、最適なプレーを行うと、ゲームは中央のポジションが 2 つだけになります。`N`が奇数で、中央の位置が 3 つだけの場合`N`は均等です。 文字列の残りの部分はまったく関係ありません。 

たとえば、`N = 1`、文字列には長さがあります`2`。```
AA
AB
BA
BB
```アリスは、どちらかの対角エンドポイントを直接選択できます。 彼女は最初の 3 つの訴訟で勝ち、負けたのは次の場合だけです。`BB`。 

のために`N = 2`、トリプルのみ`(S0,S1,S2)`重要です。 優勝文字列は次のとおりです。```
AAA
AAB
BAA
```回答例と一致するもの`3`。 

## アプローチ

 ブルートフォースアプローチでは、すべてが列挙されます。`2^(N+1)`文字列。 各文字列について、グリッド上のミニマックスによってゲームを解くことができます。 これはゲームの定義に直接従うため、正しいです。 残念ながら、たとえ`N = 50`、文字列の数はすでに天文学的な数に達しているため、この方向は絶望的です。 

画期的な進歩は、ゲームの形状を理解することから始まります。 

まさにその後`N`移動すると、トークンは対角線に到達します。 実際のパスは、どの対角セルに到達するかを決定するだけです。 最適なプレイにより、プレーヤーは行の移動と列の移動のバランスを制御できます。 

まず奇数の値を考えてみましょう`N = 2K + 1`。 アリスは最後の行動に出る。 ペアリング戦略は、彼女が移動した後、インデックスに対応する 2 つの中央の対角セルの 1 つに常にトークンを強制できることを示しています。`K`そして`K + 1`。 逆に、これらの両方のセルが彼女に負けている場合、ボブはゲームを強制して、アリスの最終的な動きはまさにこれら 2 つの負けているセルのどちらかを選択する必要があるようにすることができます。 したがって、アリスは次のうちの少なくとも 1 つが存在する場合にのみ勝ちます。`S[K]`または`S[K+1]`は`A`。 

次に偶数の値を考えてみましょう`N = 2K`。 アリスが最初の手を選択し、その後ボブが奇数長さのサブゲームの最初のプレイヤーになります。 アリスが一方向に移動すると、関連する中央のペアは次のようになります。`(S[K-1], S[K])`。 彼女が反対方向に移動した場合、関連する中央のペアは次のようになります。`(S[K], S[K+1])`。 ボブは、中央のペアの両方のセルが一致しない限り、奇数のサブゲームに勝ちます。`A`。 したがって、アリスは、これらのペアの少なくとも 1 つが完全に以下のもので構成されている場合に正確に勝ちます。`A`。 

奇数の場合`N`、中央ペアの 4 つの割り当てのうち、3 つが勝利しています。```
AA, AB, BA
```のみ`BB`負けます。 

偶数の場合`N`、中央トリプルの 8 つの割り当てのうち`(S[K-1], S[K], S[K+1])`、ちょうど 3 人が勝っています。```
AAA, AAB, BAA
```カウントは次のようになります。 

奇数の場合`N = 2K + 1`:```
3 * 2^(N-1)
= 3 * 4^K
```偶数の場合`N = 2K`:```
3 * 2^(N-2)
= 3 * 4^(K-1)
```どちらの式も単純化すると、```
3 * 4^floor((N-1)/2)
```これがまさに最終的な式です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(N+1)) | お(1) | 遅すぎる |
 | 最適 | O(log N) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`N`。 
2. コンピューティング`e = floor((N - 1) / 2)`。 
3. コンピューティング`4^e mod (10^9 + 3233)`高速べき乗剰余演算を使用します。 
4. 結果を乗算します。`3`。 
5. 最終値の剰余を取得します。`10^9 + 3233`。 
6. 答えを出力します。 

### なぜ効果があるのか

 奇数の場合`N`、最適なプレーは中央の 2 つの対角位置にのみ依存します。 両方にラベルが付けられない限り、アリスの勝ちです`B`、正確に与える`3`これら2つのポジションの割り当てを獲得しました。 

偶数の場合`N`、最適なプレーは中央の 3 つのポジションのみに依存します。 アリスは 3 つの課題で正確に勝利します`AAA`、`AAB`、 そして`BAA`。 

文字列の残りの文字はすべて結果に影響を与えることはなく、自由に選択できます。 空き位置を数えた後、両方のパリティ ケースが同じ閉じた形式に折りたたまれます。$$3 \cdot 4^{\lfloor (N-1)/2 \rfloor}.$$アルゴリズムはこの式を正確に評価します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 3233

def main():
    n = int(input())
    exp = (n - 1) // 2
    ans = 3 * pow(4, exp, MOD)
    print(ans % MOD)

if __name__ == "__main__":
    main()
```実装はほぼ数式を直訳したものです。`exp = (n - 1) // 2`閉じた形式で現れる指数を計算します。 Python の組み込みの 3 つの引数`pow`累乗剰余演算を対数時間で実行します。これは、繰り返し乗算するよりもはるかに高速です。 

の乗算`3`その後に実行され、最後のモジュロ演算により結果が必要な範囲内に収まります。 

難しい境界条件はありません。 最小の入力は`N = 1`、指数を与えます`0`、 そして`pow(4, 0, MOD)`正しく返します`1`、答えを生成します`3`。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

MOD = 10**9 + 3233

def solve():
    n = int(input())
    print((3 * pow(4, (n - 1) // 2, MOD)) % MOD)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided sample
assert run("2\n") == "3\n", "sample"

# minimum N
assert run("1\n") == "3\n", "N=1"

# odd N
assert run("3\n") == "12\n", "3 * 4^1"

# even N
assert run("4\n") == "12\n", "3 * 4^1"

# larger value
assert run("5\n") == "48\n", "3 * 4^2"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |

 |`2`|`3`| サンプルケース |
 |`3`|`12`| 奇数`N`式 |
 |`4`|`12`| 平`N`式 |

 ## 特殊なケース

 のために`N = 1`、アリスの最初の動きでゲームは終了します。

入力：```
2
```勝利したトリプルは次のとおりです。```
AAA
AAB
BAA
```ちょうど 3 つの割り当てが機能するため、答えは次のようになります。`3`。 

次のような大きな奇数の場合、`N = 99999`、文字列を列挙することは不可能になります。 このアルゴリズムは、依然としてべき乗剰余演算を 1 つだけ実行します。$$3 \cdot 4^{49999} \pmod{10^9+3233}.$$実行時間は指数の対数のままであり、十分に高速です。
