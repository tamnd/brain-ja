 ## 解決策
 ## 問題の理解

 2 つの多項式が与えられます。$P(x)$そして$Q(x)$の降べき乗で書かれています。$x$。 タスクは以下を計算することです。$$\lim_{x \to \infty} \frac{P(x)}{Q(x)}$$入力により、2 つの多項式の次数と、最高次項から定数項までのすべての係数が得られます。 

重要な観察は、次のような場合です。$x$が非常に大きくなると、最高次項が他のすべてを支配します。 より低い検出力は、主要な項と比較して重要ではなくなります。 

例えば：$$\frac{3x^5 + 2x + 1}{7x^5 - 9}$$ほぼ次のように動作します。$$\frac{3x^5}{7x^5} = \frac{3}{7}$$非常に大きい$x$。 

制約は小さく、次数は最大でも 100 であるため、ここではパフォーマンスはそれほど問題になりません。 多項式を数値的に評価しても、制限内に問題なく収まります。 本当の課題は数学的な正しさです。 浮動小数点評価では精度の問題が発生し、大きな入力に対して完全に間違った答えが生成される可能性さえあります。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

考慮する：```
2 1
1 1 1
2 5
```これは次のとおりです。$$\frac{x^2 + x + 1}{2x + 5}$$分子の次数が大きいため、比率は際限なく大きくなります。 両方の主要係数が正であるため、答えは次のようになります。```
Infinity
```大きな有限値で評価する不注意な実装では、依然として有限数が生成される可能性があります。 

次に、次のことを考えてみましょう。```
2 1
-1 0 0
2 1
```これは次のとおりです。$$\frac{-x^2}{2x+1}$$依然として分子が優勢ですが、主要な係数は負です。 制限は次のようになります。```
-Infinity
```分子の次数が大きい場合には常に符号が重要になります。 

もう 1 つの重要なケースは、分母の次数が大きい場合に発生します。```
1 2
5 1
1 0 0
```これは次のとおりです。$$\frac{5x+1}{x^2}$$として$x \to \infty$、分母がより速く増加するため、結果はゼロに近づきます。```
0/1
```最後に、両方の次数が等しい場合、分数を正しく約分する必要があります。```
1 1
6 0
8 1
```制限は次のとおりです。$$\frac{6x}{8x} = \frac{6}{8} = \frac{3}{4}$$印刷`6/8`この問題には既約分数が必要なので、これは間違いです。 

## アプローチ

 ブルートフォースアプローチでは、両方の多項式を直接評価して、次のような非常に大きな値を求めます。$x = 10^9$、次に結果を分割して、極限を推測してみます。 

支配的な用語が小さな用語を圧倒するため、これは多くの通常のケースで機能します。 次数が等しい場合、比率は主要な係数の比率に近づきます。 程度が異なると、その大きさは極端に大きくなったり、極端に小さくなったりします。 

問題は信頼性です。 多くの言語では大きなべき乗がすぐにオーバーフローし、浮動小数点演算の精度が失われます。 Python の任意サイズの整数でも、不必要に天文学的に大きな値が生成されてしまいます。 さらに重要なことは、答えは正確であり、多項式の次数と主要な係数によって純粋に決定されるため、数値近似は根本的に間違ったツールであるということです。 

多項式成長の構造により、よりクリーンなソリューションが得られます。 

仮定する：$$P(x)=a_0x^n+\dots$$そして$$Q(x)=b_0x^m+\dots$$として$x \to \infty$:$$\frac{P(x)}{Q(x)} \sim \frac{a_0x^n}{b_0x^m} = \frac{a_0}{b_0}x^{n-m}$$今、すべてはただそれに依存しています$n-m$。 

もし$n>m$、要因$x^{n-m}$無限に大きくなる。 サインの由来は、$\frac{a_0}{b_0}$。 

もし$n<m$、係数はゼロになる傾向があります。 

もし$n=m$、べき乗は完全にキャンセルされ、主要な係数の比率のみが残ります。 

これにより、問題全体が数回の比較と 1 回の gcd 計算に減ります。

 ## アルゴリズムのチュートリアル

 1. 度数を読む$n$そして$m$。 
2. 両方の多項式の係数配列を読み取ります。 
3. 主要な係数を抽出します。 

係数は最高次数から最低次数まで与えられるため、主な係数は次のようになります。$$a_0 = A[0], \quad b_0 = B[0]$$4. 度数を比較する$n$そして$m$。 
5. もし$n > m$、分子は分母よりも速く増加します。 

制限は、次の符号に応じて正または負の無限大になります。$$a_0 \times b_0$$製品がポジの場合は印刷します`"Infinity"`。 

それ以外の場合は印刷します`"-Infinity"`。 
6. もし$n < m$、分母の増加が速くなります。 

制限がゼロに近づくので、次のように出力します。```
0/1
```7. もし$n = m$、換算分数を計算します。$$\frac{a_0}{b_0}$$計算:$$g = \gcd(|a_0|, |b_0|)$$両方の数値を次の値で割ります$g$。 
8. 分母が正であることを確認します。 

分母が負の場合は、分子と分母の両方に を掛けます。$-1$。 
9. 分数を次の形式で出力します。```
p/q
```### なぜ効果があるのか

 非常に大きい場合$x$、低次の多項式項は、主要な項と比較して無視できるほどになります。 商:$$\frac{P(x)}{Q(x)}$$は次と同じ漸近的な動作をします。$$\frac{a_0x^n}{b_0x^m} = \frac{a_0}{b_0}x^{n-m}$$指数$n-m$式が無限に拡大するか、ゼロに縮小するか、または一定値で安定するかどうかを完全に決定します。 アルゴリズムのすべてのステップはこの漸近形式に直接従うため、生成される答えは数学的に正確です。 

## Python ソリューション```python
import sys
from math import gcd

input = sys.stdin.readline

n, m = map(int, input().split())

A = list(map(int, input().split()))
B = list(map(int, input().split()))

a0 = A[0]
b0 = B[0]

if n > m:
    if a0 * b0 > 0:
        print("Infinity")
    else:
        print("-Infinity")

elif n < m:
    print("0/1")

else:
    g = gcd(abs(a0), abs(b0))

    p = a0 // g
    q = b0 // g

    if q < 0:
        p *= -1
        q *= -1

    print(f"{p}/{q}")
```最初の部分では、次数と係数の配列を読み取ります。 入力順序はすでに最高次の係数から始まっているため、先頭の係数はインデックスですぐに利用できます。`0`。 

次数の比較がソリューション全体を推進します。 分子の次数が大きい場合は、符号のみが重要になります。 先頭の係数を乗算すると、制限の符号が得られます。 

等次分岐は、比較を超えた算術演算が必要な唯一の場所です。 次を使用して端数を減らします`gcd`、次に、ステートメントで要求されているとおりに、分母が正のままになるように符号を正規化します。 

微妙な点の 1 つは、内部で絶対値を使用していることです。`gcd`。 パイソンの`math.gcd`負の値は安全に処理されますが、絶対値を取ることで意図が明示的に保たれ、言語間での移植性の問題が回避されます。 

もう 1 つの微妙な詳細は、分母の正規化です。 のような結果`1/-2`は数学的には正しいですが、分母が正でなければならないため、必要な出力形式に違反しています。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io
from math import gcd

def solve():
    input = sys.stdin.readline

    n, m = map(int, input().split())

    A = list(map(int, input().split()))
    B = list(map(int, input().split()))

    a0 = A[0]
    b0 = B[0]

    if n > m:
        if a0 * b0 > 0:
            print("Infinity")
        else:
            print("-Infinity")

    elif n < m:
        print("0/1")

    else:
        g = gcd(abs(a0), abs(b0))

        p = a0 // g
        q = b0 // g

        if q < 0:
            p *= -1
            q *= -1

        print(f"{p}/{q}")

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    out = io.StringIO()
    backup = sys.stdout
    sys.stdout = out

    solve()

    sys.stdout = backup
    return out.getvalue().strip()

# provided sample

1 1 1
2 5
"""
) == "Infinity", "sample 1"

# equal degrees, reducible fraction

 ## 特殊なケース

 次のことを考慮してください。```
2 1
-1 0 0
2 1
```主な用語は次のとおりです。$$\frac{-x^2}{2x} = -\frac{x}{2}$$アルゴリズムは次数を比較して次の値を見つけます。$2 > 1$。 次に、次の符号をチェックします。$$(-1) \times 2 = -2$$符号が負なので、次のように出力されます。```
-Infinity
```これにより、発散方向が正確に捉えられます。 

次に、次のことを考えてみましょう。```
1 2
5 1
1 0 0
```主な動作は次のとおりです。$$\frac{5x}{x^2} = \frac{5}{x}$$として$x$増加すると、値はゼロに向かって縮小します。 

アルゴリズムが見ているのは、$1 < 2$そしてすぐに出力します:```
0/1
```正確な制限はゼロであるため、端数の削減は必要ありません。 

最後に、分母の符号の正規化について考えます。```
1 1
1 0
-2 3
```生の先行係数比は次のとおりです。$$\frac{1}{-2}$$gcd は$1$なので、還元されていない部分が残ります。`1/-2`。 

アルゴリズムは負の分母を検出し、両方の符号を反転します。$$\frac{1}{-2} = \frac{-1}{2}$$出力されます:```
-1/2
```必要な出力形式を満たしています。
