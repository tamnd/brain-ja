 ## 解決策
 ## 問題の理解

 厳密に増加する正の整数のシーケンスが与えられます。 タスクは、サブセットの「美しさ」が最大化されるように、これらの数値のサブセットを選択することです。 美しさは最大の整数として定義されます$v \ge 0$サブセット内のすべての数値のビット単位の AND が次で割り切れるようになります。$2^v$。 そうでない場合$v$存在する場合、美しさは-1です。 最大限の美しさを備えたすべてのサブセットの中で、要素数が最も多いサブセットを選択するように求められます。 

より簡単な言葉で言い換えると、数値のサブセットごとに、ビットごとの AND により、2 の累乗で割り切れる数値が得られます。 美しさを最大化することは、選択した数値の AND 内の末尾のゼロの数を最大化することと同じです。 次に、この最大数の末尾ゼロに達するすべてのサブセットの中で、最も多くの数値を含むサブセットを優先します。 

入力サイズ$n$まで可能です$10^5$そしてそれ自体を最大まで番号付けします$10^9$。 すべてのサブセットを調べる単純なアプローチでは、次のことが必要になります。$O(2^n)$まったく実行不可能な操作です。 この制約は、ソリューションが時間に対して線形または線形に近い時間で動作する必要があることを示唆しています。$n$。 

明らかではないエッジ ケースには、すべての数値が奇数であるシーケンス、単一の要素を含むシーケンス、または 2 の累乗が大きく異なる数値が含まれます。 たとえば、次のようなシーケンス`[1, 3, 5]`には AND で割り切れるサブセットがないため、シングルトン サブセットの美しさは 0 になります。 常に最大の数値を取得する単純なアプローチでは、最適なサブセット サイズを逃す可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、すべてのサブセットを考慮し、それぞれの AND を計算し、後続のゼロを数え、最大の末尾ゼロと最大サイズを持つサブセットを選択します。 操作数は次のようになります。$O(n 2^n)$、これは実行不可能です$n=10^5$。 

重要な洞察は、美しさは各数値のバイナリ表現における末尾のゼロの数によって決まるということです。 計算できる$f(x)$、各数値の末尾のゼロの数$x$、 として$\text{tz}(x) = \text{lowest power of two dividing } x$。 達成可能な最大の美しさは単に最大のものです$v$少なくとも 1 つの数字が$f(x) = v$。 一度$v$が決定されると、最適なサブセットは、末尾のゼロが等しいすべての数値で構成されます。$v$。 これにより、末尾のゼロが少なくなる追加の数値は以下の AND 結果を減少させるため、最大の美しさと最大のサブセット サイズの両方が保証されます。$2^v$。 

この観察により、問題は指数関数的な複雑さから線形的な複雑さへと軽減されます。 各数値の末尾のゼロを計算するのは次のとおりです。$O(1)$数値ごとに、配列を反復処理すると、$O(n)$、最適なサブセットをフィルタリングすることもできます。$O(n)$。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n * 2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数の入力シーケンスを読み取ります。 
2. 各数値について、バイナリ表現内の末尾のゼロの数を計算します。 これは、2 で繰り返し除算するか、ビット操作を使用することで実行できます。 これらのカウントを保存します。 
3. すべての数値にわたる末尾のゼロの最大数を決定します。 この値は最高の美しさを表します$v$。 
4. 末尾ゼロの最大数がまさにこの値であるすべての数値を収集します。 これらの数値は、最大の美しさと最大のサイズを同時に実現するサブセットを形成します。 
5. このサブセットのサイズと数値自体を出力します。 

機能する理由: 複数の数値のビット単位の AND では、選択した数値の末尾のゼロの最小数を超える末尾のゼロを含めることはできません。 末尾のゼロが最大数だけある数値を選択することにより、サブセットの AND にちょうど同じ数の末尾のゼロが含まれることが保証されます。 末尾のゼロが少ない数値を含めると美しさが低下し、末尾のゼロが同じ数値を除外するとサブセットのサイズが小さくなります。 したがって、この戦略は両方の基準によって最適なソリューションを生成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def trailing_zeros(x):
    count = 0
    while x % 2 == 0:
        x //= 2
        count += 1
    return count

def main():
    n = int(input())
    a = list(map(int, input().split()))
    
    # Step 1: compute trailing zeros for each number
    tz_counts = [trailing_zeros(x) for x in a]
    
    # Step 2: find maximum trailing zeros
    max_tz = max(tz_counts)
    
    # Step 3: select numbers with exactly max trailing zeros
    result = [a[i] for i in range(n) if tz_counts[i] == max_tz]
    
    # Step 4: print results
    print(len(result))
    print(" ".join(map(str, result)))

if __name__ == "__main__":
    main()
```の`trailing_zeros`関数は繰り返し 2 で除算し、何回除算できるかを数えます。 最大でも次の数値なのでこれは安全です$10^9$したがって、ループは数値ごとに最大 30 回の反復を実行します。 効率化のためにビット単位の演算を使用することもできますが、複雑さは線形のままです。 リストの内包により、最大の末尾ゼロを持つサブセットを効率的に収集できます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
