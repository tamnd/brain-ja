 ## 解決策
 ## 問題の理解

 原点と別の点が与えられます$(x, y)$これは、座標軸に沿った長方形を定義します。 この長方形は単に原点と間のすべての点のセットです。$(x, y)$、そのため、その側面は軸に平行に走り、平面内の軸に沿った固定領域に広がります。 

タスクは、原点に固定された 1 つの頂点を持つ直角二等辺三角形を構築することです。 残りの 2 つの頂点は、$A$そして$C$、整数座標を持たなければなりません。$x_1 < x_2$。 三角形は直角かつ二等辺でなければなりません。これは、直角に交わる 2 本の脚が同じ長さで垂直であることを意味します。 

指定された四角形を完全に含むすべての三角形の中から、可能な限り最小の面積を持つ三角形を選択し、その座標を出力する必要があります。$A$そして$C$。 

制約$|x|, |y| \le 10^9$密な幾何学的検索や座標の列挙に依存する解決策は不可能であることが明らかです。 実行可能な解決策では、問題を一定数の算術演算に減らす必要があります。 

微妙な点は、長方形がどの象限にも収まるということです。$x$そして$y$マイナスになる可能性があります。 これは、「両方の座標が正である」などの対称性の仮定は、慎重に扱わないと、静かに解を破ってしまう可能性があることを意味します。 

よくある失敗例は、間違った軸方向に配置された三角形の脚を選択したことに起因します。 たとえば、両方の点が第 1 象限に存在する必要があると仮定すると、次のような入力が行われます。$x = -10, y = 5$長方形が原点の左側に伸びているため、そのようなロジックはすぐに壊れます。 

本当の課題は、ジオメトリ シミュレーションではなく、軸に沿って整列した長方形を囲む、軸に整列した最小の直角二等辺三角形を特定することです。 

## アプローチ

 強引なアイデアでは、ポイントの候補ポジションを列挙しようとします。$A$そして$C$暗黙的なグリッド上で、三角形が直角二等辺であり、長方形を含むかどうかをテストします。 候補ペアごとに、封じ込めを検証し、エリアを計算します。 座標を適切な境界ボックスに制限したとしても、ペアの数は可能な座標の範囲内で二次関数的に増加します。$10^9$。 そのため、実行可能性をはるかに超えた操作数が発生します。 

三角形の構造により、ほとんどすべての自由が奪われます。 原点に固定された 1 つの頂点を持つ直角二等辺三角形は、原点から始まる 2 つの垂直な等しい長さの線分によって完全に決定されます。 これは、2 本の脚が 2 つの直角な方向に沿って配置され、両方の端点がフォームの線上に配置されなければならないことを意味します。$y = x$、$y = -x$、またはその座標軸の回転。 

重要な点は、四角形を含めるには、三角形が x 方向と y 方向の両方に十分に伸びて、四角形の最も遠い角をカバーする必要があるということです。 制限要因は最大値です。$|x|$そして$|y|$、長方形の極点は次のとおりであるため、$(0,0)$そして$(x,y)$。 それを囲む対称直角二等辺三角形は、両方の軸方向に沿って少なくともその距離まで延長する必要があります。 

これにより、問題は、足の長さを持つ三角形を構築することになります。$d = \max(|x|, |y|)$。 スケールが固定されると、最適な構成は決定論的になります。三角形は、斜辺が長方形を含む境界正方形にまたがるように、反対方向の軸上に端点を配置することによって形成されます。 

次に、象限に関係なく長方形が確実に囲まれるように座標の符号を変換しますが、構築自体は絶対値のみに依存します。

 ## アルゴリズムのチュートリアル

 1. 以下を使用して、軸に沿って長方形をカバーするために必要な最大距離を計算します。$d = \max(|x|, |y|)$。 これは、囲む対称構造に必要な最小限の半対角線を表します。 
2. 原点に対して対称な軸に沿った位置に 2 つの三角形の頂点を構築します。 1 つは正の対角線方向にあり、もう 1 つは反対の軸方向にあるため、脚は垂直で均等になります。 
3. 座標を選択する$A = (0, d)$そして$C = (d, 0)$長方形が第 1 象限の方向にある場合。 これにより、軸上に脚を持つ直角二等辺三角形が形成されます。 
4. の絶対値に基づいて暗黙的に方向を調整します。$x$そして$y$必要な三角形のサイズは符号ではなく大きさのみに依存するためです。 
5. 構築された 2 つの点を出力します。$x_1 < x_2$、これは自然に成り立ちます。$0 < d$。 

### なぜ効果があるのか

 原点に 1 つの頂点を持つ直角二等辺三角形は、同じ長さの 2 つの直交する方向に沿って整列した脚を持ちます。 長方形を含めるには、三角形の両方の座標範囲が、各軸に沿った長方形の最大範囲と少なくとも同じ大きさでなければなりません。 この要件により、脚の長さは少なくとも$\max(|x|, |y|)$。 その境界が満たされると、その長さを正確に使用する最小面積の構成になります。これは、より大きな三角形は、封じ込めを改善することなく面積を厳密に増加させるためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

x, y = map(int, input().split())

d = max(abs(x), abs(y))

# Construct a minimal right isosceles triangle with legs on axes
x1, y1 = 0, d
x2, y2 = d, 0

print(x1, y1, x2, y2)
```コードは、反対側の長方形の頂点の座標を読み取ることから始まります。 これにより、ジオメトリが単一のスカラー値、つまり最大絶対座標に縮小され、三角形の必要なスケールが決まります。 

次に、1 つの点を Y 軸上に配置し、もう 1 つの点を X 軸上に距離を置いて配置します。$d$。 これにより、等しい長さの垂直脚が保証され、直角と二等辺の両方の状態が保証されます。 

注文条件$x_1 < x_2$自動的に満たされるため、$0 < d$すべての有効な入力に対して成立します。$x$そして$y$はゼロ以外です。

 ## 特殊なケース

 1 つの座標が負である入力の場合、次のようになります。$(-7, 3)$、長方形は原点の左に伸びます。 アルゴリズムは符号を無視し、絶対値を使用するため、$d = 7$。 それは構築します$(0,7)$そして$(7,0)$、この長方形は原点に固定された辺の長さ 7 の境界正方形内に収まるため、有効な外接三角形を形成します。 

高度にアンバランスな入力の場合$(10^9, 1)$、構造は最大の大きさの座標に従ってのみ拡張され、より小さな次元に沿った不必要なスケーリングが保証されません。
