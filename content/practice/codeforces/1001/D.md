[CF 1001D - プラス状態とマイナス状態を区別する](https://codeforces.com/problemset/problem/1001/D)

 **評価:** 1400
 **タグ:** *特別な
 **解決時間:** 57 秒
 **確認済み:** はい

 ## 解決策
 ## 問題の理解

 2 つの可能な状態のいずれかで準備された単一の量子ビットが与えられます。 これら 2 つの状態は |0⟩ や |1⟩ のような計算上の基底状態ではなく、相対位相のみが異なる重ね合わせ状態です。 具体的には、量子ビットは正符号付き等重ね合わせ、または負符号付き等重ね合わせのいずれかであることが保証されます。 

タスクは、許可された量子操作を使用してこの量子ビットと対話し、測定を実行し、与えられた 2 つの状態のどちらかを識別する整数を返すことです。 出力は、正の重ね合わせの場合は 1、負の重ね合わせの場合は -1 である必要があります。 

入力サイズはわずか 1 量子ビットですが、計算ベースでの直接測定ではこれら 2 つの状態を区別できないという微妙な点があります。 標準基底で直接測定すると位相情報が破壊され、どちらの場合もランダムな結果が生じます。 これが重要な問題点です。識別情報は振幅ではなく位相で保存されます。 

単一の量子ビットのみを操作するため、計算上の制約は簡単です。 一定数の量子ゲートと 1 回の測定で十分であるため、時間計算量は実質的に O(1) になります。 本当の制約は、アルゴリズムの効率性ではなく、量子測定ルールに基づいた正確性です。 

最初に基底を変換せずに直接測定しようとすると、よくある失敗例が発生します。 たとえば、入力状態を測定すると、両方の入力に対して同じ確率で 0 または 1 がすぐに返されるため、単純なマッピングでは実際の状態に関係なく 1 を返す場合もあれば、-1 を返す場合もあります。 測定により特徴が消去されるため、これは不正確です。 

## アプローチ

 ブルートフォースの古典的な考え方では、隠れ位相を推測するために量子ビットを複数回「サンプリング」しようとします。 古典的な例えでは、測定を繰り返すとバイアスが明らかになる可能性がありますが、量子力学では測定によって状態が崩壊するため、これは不可能です。 最初の測定後、量子ビットは基底状態に破壊され、元の位相に関する追加情報にはアクセスできなくなります。 したがって、繰り返しのサンプリングに依存する戦略はすぐに失敗します。各実行では、隠れた兆候とは関係のない独立したランダムな結果が得られるためです。 

重要な洞察は、位相は計算ベースでは目に見えませんが、アダマール変換を適用すると振幅情報になるということです。 アダマール ゲートは、位相差を測定可能なビット フリップに変換します。 具体的には、正の重ね合わせを |0⟩ にマッピングし、負の重ね合わせを |1⟩ にマッピングします。 これにより、問題は 1 つの標準測定に集約されます。 

この変換が適用されると、単一の測定によって状態が完全に決定されます。 次に、測定結果を必要な出力値にマッピングします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース反復測定 | O(原則として∞だが無効) | お(1) | 状態の崩壊により不正解 |
 | アダマール + 測定 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. アダマール ゲートを入力量子ビットに適用します。 これにより、状態が位相ベースから計算ベースに回転され、位相情報が測定可能な振幅差に変換されます。 
2. 計算ベースで量子ビットを測定します。 変換後の結果は決定的です。2 つの元の状態の 1 つは |0⟩ にマップされ、もう 1 つは |1⟩ にマップされます。 
3. 測定結果を必要な整数出力に変換します。 結果が |0⟩ に対応する場合は 1 を返します。|1⟩ に対応する場合は -1 を返します。 

この順序が重要である理由は、測定は基底変換後にのみ行われなければならないためです。 順序を逆にすると、識別信号が破壊されます。 

### なぜ効果があるのか

正しさは、アダマール ゲートがそれ自体の逆関数であり、特に X 基底表現と Z 基底表現を交換するという事実から得られます。 2 つの入力状態は、固有値 +1 および -1 を持つ Pauli X 演算子の固有状態です。 アダマールを適用すると、これらの固有状態が Z の計算基礎固有状態にマッピングされ、測定によって完全に区別できるようになります。 固有状態は直交基底状態にマッピングされるため、変換後に確率の重複が残らず、決定論的な識別が保証されます。 

## Python ソリューション

 元のインターフェイスは Q# ですが、論理構造は決定論的な変換とそれに続く測定として表現できます。```python
import sys
input = sys.stdin.readline

def solve():
    q = input().strip()
    # In the quantum model, we would apply H and measure.
    # Conceptually:
    # if state is |+> -> measurement becomes 0
    # if state is |-> -> measurement becomes 1
    #
    # Then map:
    # 0 -> 1
    # 1 -> -1

    meas = input().strip()  # placeholder for measurement result

    if meas == "0":
        print(1)
    else:
        print(-1)

if __name__ == "__main__":
    solve()
```実際の量子環境では、唯一の意味のある操作は、測定前に量子ビットに適用されるアダマール ゲートです。 残りは古典的な後処理です。 重要な実装の詳細は、変換後に測定が 1 回だけ行われるようにすることです。これは、それ以前の測定では位相情報が破壊されるためです。 

## 実用的な例

 量子ビットが正の重ね合わせ状態にある入力を考えてみましょう。 アダマール適用後の状態は |0⟩ になります。 測定は常に 0 を返します。 

| ステップ | 状態 |
 | --- | --- |
 | イニシャル | |

 | 測定 | 0 |
 | 出力 | 1 |

 これにより、正の状態が決定論的に 1 にマップされることが確認されます。 

次に、負の重ね合わせ状態を考えます。 

| ステップ | 状態 |
 | --- | --- |
 | イニシャル | |
 | H後 | |

 これにより、負の状態が正しく区別されたことが確認されます。 

これらのトレースは、変換によって確率的な曖昧さがすべて取り除かれていることを示しています。

 ## 特殊なケース

 主なエッジケースは、基底変換を適用する前に測定を試みることです。 すぐに測定すると、|+⟩ と |−⟩ の両方が同じ確率で 0 または 1 に崩壊するため、実行を繰り返すと一貫性のない出力が生成されます。 たとえば、入力 |+⟩ は 0 を返し、別の実行では 1 を返す可能性があり、決定論的なマッピングは不可能になります。 

アダマール ゲートを適用すると、この問題はなくなります。 |+⟩ を検討してください:

 | ステップ | 状態 |
 | --- | --- |
 | イニシャル | |
 | H無しで測定後 | ランダム 0/1 |
 | Hの後、測定 | 常に 0 |

 |−⟩ の場合:

 | ステップ | 状態 |
 | --- | --- |
 | イニシャル | |
 | H無しで測定後 | ランダム 0/1 |
 | Hの後、測定 | 常に 1 |

 これは、変換が不可欠であり、変換がなければ問題は根本的に決定論的に解決できないことを裏付けています。
