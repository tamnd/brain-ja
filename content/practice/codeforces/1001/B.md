 ## 解決策
 ## 問題の理解

 私たちは、両方がゼロであることに対応する計算基底状態を最初に形成する 2 つの量子ビットを使用した量子設定で作業しています。 タスクは、これら 2 つの量子ビットを、0 から 3 の整数インデックスによって選択される 4 つの特定のもつれ状態の 1 つにインプレースで変換することです。 

これらのターゲット状態は 4 つのベル状態であり、基底状態 |00⟩、|01⟩、|10⟩、および |11⟩ 全体に確率質量がどのように分布するか、およびそれらのコンポーネント間の相対位相によって異なります。 値を返す代わりに、操作では量子ゲートを使用して、提供された量子ビットの量子状態を直接変更する必要があります。 

入力は、ちょうど 2 量子ビットの固定サイズのレジスタと整数インデックスで構成されます。 出力は古典的な意味で出力されたり返されたりするのではなく、一連のユニタリ変換を適用した後の結果として得られる量子状態です。 

入力サイズが一定であるため、古典的な意味では制約は最小限です。 重要な制約は計算上のものではなく概念的なものです。すべての変換は有効な量子操作を使用して実装する必要があり、解決策は古典的なシミュレーションや量子状態の分岐を回避する必要があります。 

主な微妙な点は、異なるベル状態は、共通の準備手順の後に適用される単純なローカル変換によってのみ異なることです。 単純なアプローチでは、アドホックな推論を使用して各状態を最初から個別に構築しようとする可能性がありますが、これでは冗長性が生じたり、フェーズ処理で間違いが発生したりする危険があります。 

エッジケースは限られていますが、それでも検討する価値があります。 エンタングルの前にビット 反転を適用することは、エンタングルの後にビット 反転を適用することと同等であると誤って仮定すると、誤った位相構造が生成される可能性があります。 たとえば、X と Z の順序を誤って入れ替えると、意図したベル状態が崩れて振幅の符号が変更される可能性があります。 もう 1 つの潜在的な落とし穴は、位相反転が量子ビットが |1⟩ である基底状態にのみ影響することを忘れていることです。これは、|Φ+⟩ と |Φ−⟩ を区別するときに関係します。 

## アプローチ

 この問題を考える強引な方法は、各 Bell 状態を独立して直接構築することです。 各状態の定義から推論して、|00⟩ を目的の重ね合わせにマッピングする回路を手動で設計することもできます。 たとえば、(|00⟩ + |11⟩)/√2 を生成するには、他の基底状態を抑制しながら、これら 2 つの基底状態の間で等振幅を明示的に強制しようとするかもしれません。 

このアプローチは原理的には正しいですが、すぐに間違いが発生しやすくなります。 各状態では異なる回路を再導出する必要があり、異なるゲート シーケンスの下で振幅符号を追跡することは簡単ではありません。 さらに悪いことに、4 つの回路を独立して設計すると、すべてのベル状態間の共有構造が隠蔽されてしまいます。 

重要な観察は、4 つのベル州すべてが共通のバックボーンを共有しているということです。 まず、最初の量子ビットでアダマールを使用し、続いて最初の量子ビットから 2 番目の量子ビットまで制御された NOT を使用して、常に単一のもつれペアを作成します。 これにより、標準的な |Φ+⟩ 状態が生成されます。 この単一の状態から、残りの 3 つのベル状態は、単一量子ビットのパウリ演算のみを使用して取得できます。これは、計算基底状態を反転するか、相対位相を調整します。 

これにより、4 つの回路の設計から 1 つの基本回路と小さな条件付き後処理ステップの設計に問題が軽減されます。

 ## アルゴリズムのチュートリアル

1. 最初の量子ビットにアダマール ゲートを適用します。 これにより、量子ビット上の |0⟩ と |1⟩ の間に均一な重ね合わせが作成され、これがもつれの必要な開始点となります。 
2. 最初の量子ビットをコントロールとして、2 番目の量子ビットをターゲットとして CNOT ゲートを適用します。 これにより、値が一致するように 2 つの量子ビットが関連付けられ、もつれ状態 |Φ+⟩ = (|00⟩ + |11⟩) / √2 が生成されます。 
3. インデックスが 0 の場合は、|Φ+⟩ がすでに望ましい状態であるため、これ以上何もしません。 
4. インデックスが 1 の場合、最初の量子ビットに Z ゲートを適用します。 これにより、最初の量子ビットの |1⟩ コンポーネントにのみ位相反転が導入され、 |00⟩ を変更せずに |11⟩ を −|11⟩ に変換し、 |Φ−⟩ を生成します。 
5. インデックスが 2 の場合、2 番目の量子ビットに X ゲートを適用します。 これにより、両方の基底成分の 2 番目の量子ビットが反転され、|00⟩ が |01⟩ に、|11⟩ が |10⟩ にマッピングされ、|Ψ+⟩ が得られます。 
6. インデックスが 3 の場合、2 番目の量子ビットに X ゲートを適用し、続いて最初の量子ビットに Z ゲートを適用します。 X ゲートは計算基底状態を |01⟩ と |10⟩ のペアに交換し、Z ゲートは最初の量子ビットが 1 であるコンポーネントに相対位相反転を導入し、|Ψ−⟩ を生成します。 

これが機能する理由は、初期のアダマールと CNOT が固定のもつれ基底状態を生成し、パウリ X ゲートと Z ゲートがベル基底内で対称操作として機能するという事実から来ています。 これらの操作は、エンタングルメントを破壊することなくベル状態を並べ替えたり位相シフトしたりするため、これらのローカル変換の一意の組み合わせによって、 |Φ+⟩ からすべてのターゲット状態に到達できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def Solve(qs, index):
    from Microsoft.Quantum.Canon import H, CNOT, X, Z  # conceptual Q# style imports

    H(qs[0])
    CNOT(qs[0], qs[1])

    if index == 1:
        Z(qs[0])
    elif index == 2:
        X(qs[1])
    elif index == 3:
        X(qs[1])
        Z(qs[0])
```実際の Q# 実装では、ゲートは Quantum.Canon 名前空間から取得され、操作によって量子ビット レジスタが直接変更されます。 ソリューションの構造は意図的に線形になっています。最初にエンタングルメントを確立し、次にインデックスに基づいて最小限の補正を適用します。 

微妙な点は、インデックス 3 の場合の X と Z の順序は、ここでは正しさに影響を与えないことです。これは、これらが異なる量子ビットに作用し、したがって交換できるためです。 ただし、一貫した順序を維持すると、転流が成り立たないより複雑な回路について推論するときに間違いを避けることができます。

 ## 特殊なケース

 微妙なエッジ ケースの 1 つは、変換が意図した順序とは異なる順序で適用される場合です。 たとえば、X の後に Z を適用するのと、Z の後に X を適用するのは一般的に重要ですが、ここではゲートが異なる量子ビットに作用するため安全です。 入力:

 インデックス = 3

 もつれ後の状態は (|00⟩ + |11⟩)/√2 になります。 2 番目の量子ビットに X を適用すると、(|01⟩ + |10⟩)/√2 が得られます。 最初の量子ビットに Z を適用すると、|10⟩ のみの位相が反転し、必要に応じて (|01⟩ − |10⟩)/√2 が生成されます。 

もう 1 つの潜在的な問題は、Z が振幅を交換せず、位相を変更するだけであることを忘れていることです。 誤った直観は、両方の基底成分に同等に影響を与えると想定し、Φ+ と Φ- の区別を誤って破壊する可能性があります。
