 ## 解決策
 ## 問題の理解

 4 つの特定の 2 量子ビットもつれ状態のいずれかで準備された量子ビットのペアが与えられます。 これら 4 つの状態はベル基底を形成します。これは、それらが最大限にもつれており、各量子ビットの局所的な古典的情報ではなく、相対位相とビット反転によってのみ異なることを意味します。 

タスクは、振幅を再構成したり、量子状態トモグラフィーを実行したりすることではありません。 代わりに、量子ゲートの固定シーケンスを適用してから量子ビットを測定し、測定結果によって 4 つのベル状態のどれから開始したかを一意に識別する必要があります。 出力は、その ID を表す 0 ～ 3 の単一の整数です。 

キー制約は数値的なものではなく概念的なものです。 正確に 2 量子ビットに対する一定数の量子操作のみが許可されます。 これにより、統計的なサンプリングや反復測定に類似したものは除外されます。 正しい解決策は、エンタングルメント情報をシングルショットで決定論的に計算基礎情報に変換する必要があります。 

単純な間違いは、量子ビットをすぐに測定することです。 これにより、エンタングルメントが破壊され、相関のあるランダム性だけが残り、4 つのベル状態すべてが区別できなくなります。 たとえば、両方とも$|\Phi^+\rangle$そして$|\Psi^+\rangle$直接測定すると、相関が異なる場合でも、一様にランダムなビット ペアが得られます。 別の失敗例は、各量子ビットを独立して測定し、結果を古典的に解釈しようとすることです。これにより、プラスとマイナスの状態を区別する位相情報が失われます。 

2 番目の微妙なエッジ ケースは、CNOT ゲートのみまたはアダマール ゲートのみを適用することです。 これらのそれぞれは基底を部分的に変換しますが、4 つのベル状態すべてを直交する計算基底状態に完全に分離するわけではありません。 欠落している変換により、位相差が測定可能なビット 反転に分解されます。 

## アプローチ

 ブルートフォース量子戦略は、同一のシステムを繰り返し準備し、測定結果の確率を推定することによって状態を区別しようとします。 これは分布の統計的分離に依存します。 原理的には、各ベル状態はランダムなゲートシーケンス後の測定結果に異なる分布を引き起こしますが、それらを高い信頼度で区別するには多くの繰り返しが必要になります。 状態のコピーが 1 つしかないため、問題設定ではこのアプローチは不可能です。 

重要な観察は、ベルの状態は恣意的ではないということです。 これらはまさに、アダマール ゲートとそれに続く CNOT ゲートを計算基底状態に適用した結果です。$|00\rangle, |01\rangle, |10\rangle, |11\rangle$。 これは、回路を逆にすることでベルの基礎を「元に戻す」ことができることを意味します。 CNOT を適用し、次にアダマールを正しい順序で適用すると、各ベル状態が固有の計算基礎状態にマッピングされます。 

計算基礎形式に変換し直すと、両方の量子ビットの 1 回の測定により、元の状態インデックスを直接エンコードする 2 つの古典的なビットが得られます。

 ## アルゴリズムのチュートリアル

 最初の量子ビットがコントロール、2 番目がターゲットであると仮定します。 

1. 最初の量子ビットから 2 番目の量子ビットに CNOT ゲートを適用します。 

このステップにより、ベル状態のビット反転コンポーネントのもつれ構造が除去されます。 この操作の後、4 つのベル状態は、最初の量子ビットの単一量子ビット変換によってのみ異なります。 
2. 最初の量子ビットにアダマール ゲートを適用します。 

これは、間の位相差を変換します。$|+\rangle$そして$|-\rangle$測定可能な計算ベースの違いに変換します。 このステップがなければ、測定後に「プラスとマイナス」のベル状態を区別できないままになります。 
3. 両方の量子ビットを計算ベースで測定します。 

測定により、状態が古典的なビット文字列に分解されます。$b_0 b_1$。 
4. 結果のビットを整数として解釈します$2 \cdot b_0 + b_1$。 

この整数は、元のベル状態の ID です。 

### なぜ効果があるのか

 この正しさは、最初の量子ビット上で CNOT とそれに続くアダマールが標準的なベル状態準備回路のまさに逆であるという事実から来ています。 ベル状態は、計算基底のユニタリ変換によって生成される正規直交基底を形成するため、逆ユニタリ マップを適用すると、各ベル状態が固有の計算基底ベクトルにマップされます。 したがって、その基礎における測定は、初期状態の同一性に関して決定論的です。 

## Python ソリューション```python
import sys

# Quantum solution is conceptual; in actual Codeforces MQL environment,
# these operations are provided by the framework.
# We return the measurement result encoded as integer.

def Solve(qs):
    # Apply CNOT: qs[0] controls qs[1]
    CNOT(qs[0], qs[1])

    # Apply Hadamard to first qubit
    H(qs[0])

    # Measure both qubits
    b0 = M(qs[0])
    b1 = M(qs[1])

    return b0 * 2 + b1
```この構造は、標準的なベル基底反転回路に従います。 CNOT ゲートは、計算コンポーネント間のもつれを除去するために最初に適用されます。 次に、最初の量子ビットのアダマールにより、位相の曖昧性が測定可能な基底差に分解されます。 最後に、測定により、元のベル インデックスを直接エンコードする 2 つの古典的なビットが生成されます。 

実装の微妙な詳細は、整数変換における量子ビットの順序です。 最初に測定された量子ビットが上位ビットに寄与します。 このマッピングを逆にすると、量子変換自体は正しい場合でも、出力が並べ替えられ、不正確なインデックス付けが行われる可能性があります。

 ## 特殊なケース

 一般的なエッジケースは、完全な逆回路を適用する前に測定することです。 たとえば、すぐに測定すると、$|\Psi^-\rangle$状態の場合、結果は同じ確率で 01 または 10 となり、他のベル状態と区別できません。 このアルゴリズムは、測定前に CNOT とアダマールの両方が適用されることを保証することでこれを回避します。 

もう 1 つの微妙なケースは、CNOT での量子ビットの役割の交換です。 ターゲットとコントロールが逆になると、変換は逆ベル準備回路と一致しなくなり、ビット文字列とベル インデックス間のマッピングが矛盾します。 ベル状態は任意の局所反転の下では対称ではないため、固定された制御ターゲットの方向は正確性のために不可欠です。 

3 番目のケースは、アダマールが最初の量子ビットではなく 2 番目の量子ビットに適用される場合に発生します。 これにより、位相情報と計算ベースのエンコーディングの間の調整が崩れ、複数のベル状態が同じ測定結果分布に崩れる混合出力が発生します。
