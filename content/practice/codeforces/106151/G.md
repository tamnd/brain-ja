 ## 解決策
 ## 問題の理解

 2D 平面上に配置された軸に沿った長方形のコレクションが与えられ、それぞれがウィンドウを表します。 また、すべてのウィンドウには固有の高さの値があり、これによって可視性が決まります。2 つのウィンドウが重なっている場合、高さの高い方が、重なっている領域でもう一方を覆います。 

タスクは可視領域を計算することではなく、より構造的なものです。 すべてのウィンドウ境界線を高さ順に積み重ねた後、表示されている部分だけを描画することを想像します。 ウィンドウの境界線セグメントが上位のウィンドウによって完全に隠されていない場合、描画コストの原因となります。 目的は、シーン全体の最終的な目に見える輪郭に、水平および垂直の線分が何本現れるかを数えることです。 

主な問題点は、ウィンドウが重なっているとエッジが複数の可視フラグメントに分割され、上位の長方形で覆われていない部分のみが寄与する可能性があることです。 

座標拘束の形状は小さいですが、量は多くなります。 座標は 1000 で区切られており、固定グリッド構造が利用できることを示しています。 ただし、長方形の数は最大 100,000 であるため、長方形ごとのグリッド ペイントやセルごとのシミュレーションは除外されます。 ウィンドウごとにすべてのグリッド セルにアクセスするソリューションは、すぐに実行不可能になります。 

これは、ソリューションがジオメトリを固定グリッド表現に圧縮してから、単一のグローバル スイープまたは伝播プロセスを実行する必要があることを強く示唆しています。 

多くの長方形が境界上で正確に重なる場合、微妙なエッジ ケースが発生します。 たとえば、2 つの長方形がエッジを共有し、上の長方形がその境界を完全に覆っている場合、その側にある下の長方形のセグメントはカウントされません。 もう 1 つのケースは、長方形が上位の長方形によって完全に隠され、セグメントがゼロになる場合です。 

最小限の例で、非表示動作を示します。 

入力:```
2
0 0 2 2 1
0 0 2 2 2
```出力：```
8
```2 番目の長方形は最初の長方形を完全に覆っているため、上の長方形の外側の境界線のみが表示されます。 

すべての長方形の周囲を個別にカウントする単純なアプローチでは、重複する境界を誤って複数回カウントしてしまいます。 

## アプローチ

 直接的な総当たり手法では、各四角形を個別に処理し、その 4 つの辺のどれが表示されているかを判断しようとします。 各辺について、それに沿ったすべての点がより高い長方形で覆われているかどうかを確認します。 座標は有界範囲内の連続整数であるため、エッジを離散化し、間隔チェックを使用してカバレッジをテストできます。 

離散化を使用する場合でも、長方形の各辺について、すべての高 Z 長方形に対してスキャンして、重複がそれを覆っているかどうかを確認する可能性があります。 これにより、密なオーバーラップの場合には O(N^2) の動作が発生します。 100,000 個の長方形では、これは実現可能な限界をはるかに超えています。 

重要な構造的観察は、座標空間が 1 次元 (1000 x 1000) で小さいことです。これにより、視点を反転できます。長方形ごとに推論する代わりに、グリッド エッジ セグメントごとに推論します。 目に見えるすべてのセグメントは、「最も高い Z 長方形で覆われている」状態と「何も覆われていない」状態の間の遷移に対応します。 

最高の z から最低の z まで長方形を処理する場合、境界線をグリッド上にペイントすることをシミュレートしながら、境界セグメントが可視であると主張されると、それが再度カウントされることはありません。 これにより、問題は、各エッジ セルが最大 1 回訪問される、固定グリッド上の 2D カバレッジ マーキング問題に変換されます。 

2 つのグリッドを維持します。1 つは垂直エッジ用、もう 1 つは水平エッジ用です。 長方形を処理するとき、そのセグメントがまだ上位の長方形で覆われていない場合にのみ、セグメントを追加します。 これにより、より高い四角形が最初に処理されるため、正確さが保証されます。 

重要な削減点は、他のすべての四角形に対して可視性を再計算する必要がないことです。 境界セグメントがすでに上位層によって要求されているかどうかを知る必要があるだけです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(N²) | O(1)-O(N) | 遅すぎる |
 | グリッド + 下降 Z スイープ | O(N + C²) ただし、C ≤ 1000 | O(C²) | 承認済み |

 ## アルゴリズムのチュートリアル

 平面を単位エッジの離散グリッドとして扱います。 すべての長方形は 4 つの境界辺に影響しますが、上位の長方形によってまだ覆われていない辺のみがカウントされます。 

1. すべての長方形を Z 値の降順に並べ替えます。 これにより、常に最上位のウィンドウが最初に処理されるため、記録した境界は確実に表示されるようになります。 
2. 2 つのブール グリッドを維持します。1 つは水平エッジ用、もう 1 つは垂直エッジ用です。 水平エッジは固定の y および x 間隔によって識別され、垂直エッジは固定の x および y 間隔によって識別されます。 各単位セグメントは、これらの構造のグリッド セルに対応します。 
3. 並べ替えられた順序で各長方形について、その 4 つの辺を調べます。 下辺と上辺については、x を x1 から x2 まで繰り返し、y = y1 および y = y2 での水平セグメントを考慮します。 左側と右側については、y を y1 から y2 まで繰り返し、x = x1 および x = x2 での垂直セグメントを考慮します。 
4. まだマークされていない境界セグメントに遭遇するたびに、回答をインクリメントし、カバー済みとしてマークします。 これにより、そのセグメントを公開する最初の (Z の最も高い) 長方形のみがカウントに寄与することが保証されます。 
5. すべての四角形が処理されるまで続行し、累積されたカウントを出力します。 

座標が 1000 で区切られているため、セグメントの反復は安全です。そのため、各四角形は最大でも O(1000) の作業に寄与し、最悪の場合でも合計は約 O(10^8) になります。これは、単純な配列操作で慎重に実装された場合、最適化された Python では許容されます。 

### なぜ効果があるのか

グリッド内の各ユニット境界セグメントには、潜在的に露出する可能性がある固有の最高 Z 長方形があります。 z の最高値から最低値まで長方形を処理することにより、最初に検出されたセグメントがその位置の可視表面に正確に対応することが保証されます。 そのセグメントに接触する下位の長方形は、上位の長方形がすでにその領域を主張しているため、必然的にその領域に隠されます。 これにより、最終的なスタック構成で表示される場合にのみ、各セグメントが 1 回だけカウントされることが確立されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    rects = []
    for _ in range(n):
        x1, y1, x2, y2, z = map(int, input().split())
        rects.append((z, x1, y1, x2, y2))

    rects.sort(reverse=True)

    # grids for unit segments
    # horizontal: (y, x) means segment from (x,y) to (x+1,y)
    # vertical: (x, y) means segment from (x,y) to (x,y+1)
    hor = [[False] * 1001 for _ in range(1001)]
    ver = [[False] * 1001 for _ in range(1001)]

    ans = 0

    for z, x1, y1, x2, y2 in rects:
        # bottom edge
        y = y1
        for x in range(x1, x2):
            if not hor[y][x]:
                hor[y][x] = True
                ans += 1

        # top edge
        y = y2
        for x in range(x1, x2):
            if not hor[y][x]:
                hor[y][x] = True
                ans += 1

        # left edge
        x = x1
        for y in range(y1, y2):
            if not ver[x][y]:
                ver[x][y] = True
                ans += 1

        # right edge
        x = x2
        for y in range(y1, y2):
            if not ver[x][y]:
                ver[x][y] = True
                ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```この解決策は、単位セグメントの直接グリッド マーキングに依存します。 重要な点は、エッジが整数座標間の単位間隔として扱われるため、Python の range(x1, x2) を使用してループが暗黙的に x2-1 または y2-1 まで進むことです。 もう 1 つの重要な詳細は、水平エッジと垂直エッジは異なる幾何学的方向に存在するため、別々に保存されることです。 

z によるソートは必須です。 これがないと、下位の長方形が上位の長方形に属するはずのエッジを誤って主張する可能性があります。

これにより、セグメントが上位の長方形によって要求されると、下位の長方形は答えを増やすことができないことが確認されます。

 ## 特殊なケース

 重要なエッジケースは、長方形がエッジを正確に共有する場合です。 考慮する：```
2
0 0 2 2 1
2 0 4 2 2
```長方形は x=2 で接触しますが、重なり合いません。 正しい出力では、両方の全周が独立してカウントされますが、共有境界は重なり合う長さがゼロであるため、まったくセグメントではありません。 ループ範囲には x2 自体が含まれないため、アルゴリズムはこれを自然に処理します。そのため、接触境界でセグメントが二重にカウントされることはありません。 

もう 1 つのケースは完全な封じ込めです。```
2
0 0 10 10 1
2 2 8 8 2
```ここでは内側の長方形が完全に表示されていますが、外側の境界は消去されていません。 外側の長方形はその外周のみに寄与しますが、内側の長方形はそのエッジがいずれもより高い Z で覆われていないため、それ自体の全周に寄与します。 

可視性は単位セグメントごとに個別に評価されるため、グリッド マーキングによって正確さが保証されます。そのため、部分的なオーバーラップでは、幾何学的に隠れているセグメントのみが正確に削除されます。
