 ## 問題の理解

 大きな整数でインデックス付けされたハウスのラインと、このラインに沿った複数のバー位置のセットが与えられます。 複数のバーが同じハウスを占有することができますが、各バーは別個のポイントとして扱われます。 

どの候補の家に対しても$x$からの合計距離としてコスト関数を定義します。$x$残りのすべてのバーに。 選ぶ前に$x$、削除できるのはせいぜい$k$バー。 削除後、最適なコスト関数を計算し、すべての位置を考慮します。$x$この絶対距離の合計を最小化するもの。 タスクは、個別の整数の位置がいくつあるかをカウントすることです。$x$有効な削除戦略の下では最適になる可能性があります。 

重要な隠れた構造は、絶対偏差の合計の最小化が残りのマルチセットの中央値のみに依存するということです。 いくつかのバーを削除すると、最適な$x$は常に残りの点の間隔の中央値です。 したがって、問題は、最大で何個の整数を削除して得られる部分集合の中央値にできるかということです。$k$要素。 

制約が意味するもの$n$合計すると$10^5$したがって、テストごとに大まかに必要なものは$O(n \log n)$または並べ替え後の線形。 サブセットの数は指数関数的であるため、二次関数やすべての削除を列挙することは不可能です。$n$。 すべての選択肢を試してみても$k$削除するバーはすでに組み合わせになっています。 

単純な落とし穴は、単一の「最良のサブセット」を選択し、その中央値を計算する必要があると想定していることです。 それは違うことを見逃しています$x$値はさまざまな削除戦略の下で最適になる可能性があるため、ソリューションでは 1 つの構成ではなく、達成可能なすべての中央値位置を集約する必要があります。 

すべてのバーが同一である場合、エッジケースの直感が重要です。 たとえば、すべてが$a_i = 5$の場合、すべての削除ではすべてのポイントが 5 のままになるため、$x = 5$動作します。 もう一つの微妙なケースは次のような場合です。$k$片側を完全に取り除くのに十分な大きさなので、極端な位置を実現できます。 ここで区間拡張が起こります。 

## アプローチ

 ブルートフォース方式では、最大ですべての削除方法が試行されます。$k$バーを取得し、残りのマルチセットの間隔の中央値を計算します。 各サブセットについて、すべての有効な中央位置を追加します。 サブセットの数が次のとおりであるため、これはすぐに失敗します。$\sum_{i=0}^k \binom{n}{i}$、これは指数関数的です$n$。 たとえ$n = 10^5$、これは不可能です。 

構造的な洞察は、問題をソートされた順序で書き直すことで得られます。 バーの位置を並べ替えた後、中央値はインデックスの中間セグメントによって決定されます。 バーの削除は、最適な構成でこのソートされた配列の端から要素を削除することに相当します。これは、内部点の削除は、極値を削除するより効果的に可能な中央値間隔を拡張できないためです。 

したがって、問題は次のようになります。残りのサイズのウィンドウを選択したいのです。$m = n - t$どこ$0 \le t \le k$、およびそのようなウィンドウのすべての可能な中央間隔を考慮します。 サイズが偶数の場合、マルチセットの中央値は単一の点ではありません。 それは 2 つの中間要素間の間隔になります。 どちらを選択するかは異なりますが、$t$要素が削除されると、ウィンドウを効果的にスライドさせながら、削除を費やすことでエンドポイントの拡張も可能になります。 

これは、中央領域の周囲の中央値範囲をどこまで拡張できるかを計算することに帰着します。 最終的な答えは、許可されたすべての削除にわたるすべての実行可能な中央間隔の和集合になります。これは、少なくとも半分の要素を保持しながら、ソートされた配列の左右からいくつの要素を破棄できるかを分析することによって計算できます。 

問題を間隔を見つけることに落とし込みます$[L, R]$ソートされた配列内で、中央値が次の範囲のどこかにある有効なサブセットが存在するようにする$a_L$そして$a_R$。 エンドポイントは、各側に割り当てる削除の数によって異なります。

 ## アルゴリズムのチュートリアル

 1. バー位置の配列を並べ替えます。 中央値は元の位置ではなく順序のみに依存するため、並べ替えが必要です。 
2. しましょう$n$バーの数になります。 固定の最終サブセット サイズの場合$m = n - t$、中央領域はインデックスによって決定されます$\left\lfloor \frac{m-1}{2} \right\rfloor$そして$\left\lceil \frac{m-1}{2} \right\rceil$ソートされたサブセット内。 これは、すべての有効な中央値が、削除後にソートされた元の配列の連続したセグメントに対応していることを示しています。 
3. 削除により、効果的に最大の無視が可能になることに注目してください。$k$要素は任意の場所に配置できますが、可能な中央値の範囲を最大化するために、ソートされた配列の両端で削除が最適に使用されます。 内部要素を削除しても、境界要素を削除する場合よりも到達可能な中央値は拡張されません。 
4. しましょう$m = n - k$。 これは可能な限り最小の残りのサイズです。 この場合、サブセットが小さいほど中央位置の不確実性が大きくなるため、中央間隔は最大化されます。 
5. 有効な中央位置は、サイズのすべてのウィンドウに対応します。$m$ソートされた配列内。 各ウィンドウは、次のパリティに応じて 1 つまたは 2 つの中央値候補を提供します。$m$。 これらの間隔を結合すると、値空間内の連続セグメントが得られます。 
6. 答えは、すべての有効なウィンドウにわたって、可能な最小の中央値と可能な最大の中央値との間の間隔に整数値がいくつあるかを数えることに帰着します。 これらの極端な値は、左端のウィンドウと右端のウィンドウのサイズを取得することによって実現されます。$m$。 
7. 以下を計算します。 

-$L = a[\lfloor (n-k-1)/2 \rfloor]$-$R = a[n - 1 - \lfloor (n-k-1)/2 \rfloor]$そうすると答えは$R - L + 1$。 

### なぜ効果があるのか

 マルチセットの中央値は、ソート順の中央の要素にのみ依存します。 せいぜい削除が許可されているため、$k$要素を削除することで、中央位置を占める要素を移動できます。 極端な中央値は、右側の境界についてはできるだけ多くの小さな要素を中央値ウィンドウの外に押し出し、左側の境界についてはできるだけ多くの大きな要素を押し出すことによって取得されます。 内部削除戦略は、境界削除より効果的に中央値インデックスをシフトすることなく削除予算を消費するため、これらの極端な値を超えることはできません。 したがって、到達可能な中央値は、並べ替えられた順序で正確に連続したセグメントを形成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        a.sort()

        m = n - k
        mid = (m - 1) // 2

        L = a[mid]
        R = a[n - 1 - mid]

        print(R - L + 1)

if __name__ == "__main__":
    solve()
```並べ替えステップでは、中央値を推論するための固定順序を確立します。 変数$m = n - k$より多くの要素を削除しても柔軟性が低下するだけであるため、考慮する必要がある最小のサブセット サイズを表します。 

重要な実装の詳細は、同じ中間点オフセットを使用することです。$mid = (m-1)//2$配列の両端から。 この対称性により、達成可能な最小および最大の中央位置が捕捉されます。 最後の引き算$R - L + 1$実行可能な区間内の整数のハウス位置をカウントします。

 ## 特殊なケース

 重要なエッジケースは、すべての値が同一である場合です。 入力用`[5,5,5,5]`どれでも$k$、要素を削除しても中央値は変わりません。 アルゴリズムは配列をソートして計算します$mid$、しかし両方とも$a[mid]$そして$a[n-1-mid]$5 に等しい場合、答え 1 が生成され、唯一の実行可能な家と一致します。 

もう 1 つのエッジケースは次のような場合です$k = n-1$。 1 つのバーを除くすべてのバーを削除した後、残った要素は自明のことながら中央値になります。 式は次のようになります。$mid = 0$、 それで$L = a[0]$そして$R = a[n-1]$つまり、すべての元の値が単一の中央値として達成可能になり、考えられる結果の完全な広がりが正しく得られます。 

3 番目のケースは、次のような非常に偏った分布です。`[1,1,1,100,100,100]`中程度の$k$。 このアルゴリズムは、中間点のインデックス境界が絶対値ではなく並べ替えられた位置によって固定されたままであるため、いくつかの極端な点を削除しても中央値を 2 つのクラスターの中央の重なりを超えて移動できないことを正確に捉えています。
