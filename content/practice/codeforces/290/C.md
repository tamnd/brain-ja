 ## 解決策
 ## 問題の理解

 入力は従来の数学的仕様ではありません。 代わりに、これは LOLCODE で書かれた小さなプログラムです。 タスクは、プログラムが何を計算するかを決定し、結果の実数を出力することです。 

最初の入力値は、ループを制御する変数に読み込まれます。 その値を`n`。 その後、プログラムは正確に読み取ります`n`追加の数字、それぞれの間の`0`そして`9`。 

シーケンスの処理中に、以下が維持されます。 

-`FOO`、これまでに確認されたすべての値の合計。 
-`BAR`、これまでに確認された値の数。 
-`BAZ / QUZ`、これまでに見つかった最良のプレフィックス平均を表す分数。 

新しい値を読み取るたびに、プログラムは現在のプレフィックスの平均を比較します。$$\frac{\text{FOO}}{\text{BAR}}$$保存された最良の平均値と$$\frac{\text{BAZ}}{\text{QUZ}}.$$現在の平均値が少なくとも同程度の大きさであれば、保存されている部分が置き換えられます。 

最後に印刷します$$\frac{\text{BAZ}}{\text{QUZ}},$$これは、まさにシーケンスのすべてのプレフィックスの最大平均です。 

以来`n`それ自体は数字であり、間にあります`0`そして`9`。 このステートメントでは、入力に 1 ～ 10 行が含まれていると述べており、これは次の 1 行に一致します。`n`最大 9 つの追加値。 データ サイズが小さいため、二次解でも問題なく適合します。 本当の課題は、プログラムが何を行うのかを理解することです。 

よくある間違いは、最大プレフィックス平均ではなく最大個別値を検索することです。 

考慮する：```
3
0
1
1
```最大の値は`1`ですが、プレフィックスの平均は次のとおりです。```
0
0.5
0.666667
```正しい答えは次のとおりです。```
0.666667
```もう 1 つの簡単な間違いは、プレフィックスではなく任意のサブ配列の平均を最大化することです。 

のために：```
3
1
0
9
```サブアレイ`[9]`平均的です`9`、ただし、プログラムはプレフィックスのみを考慮します。 プレフィックスの平均は次のとおりです。```
1
0.5
3.333333
```正しい答えは次のとおりです。```
3.333333
```3 番目の微妙な点は、分数間の比較です。 元のプログラムは決して浮動小数点に変換しません。 比較する$$\frac{a}{b} \ge \frac{c}{d}$$チェックすることで$$a \cdot d \ge c \cdot b.$$数値が小さいため、ここで浮動小数点を使用してもこの問題には対処できますが、プログラムを正確に再現するには、整数演算を使用した方がきれいです。 

## アプローチ

 最も直接的な解釈は、文字通りプログラムをシミュレートすることです。 

シーケンスを読み取り、すべてのプレフィックスの平均を計算し、これまでに確認された最大のものを保持し、最後にそれを出力します。 値は最大 9 つであるため、すべての平均を保存し、後でスキャンすることさえ簡単です。 

興味深いのは、プログラム自体が比較をどのように実行するかを理解することです。 実数を計算する代わりに、最良の平均を分数として保存します。`BAZ / QUZ`。 合計を含む新しいプレフィックスの場合`FOO`そして長さ`BAR`表示される、比較する$$\frac{\text{FOO}}{\text{BAR}}$$そして$$\frac{\text{BAZ}}{\text{QUZ}}$$交差乗算を使用する:$$\text{FOO} \cdot \text{QUZ}$$対$$\text{BAR} \cdot \text{BAZ}.$$これにより、浮動小数点演算が完全に回避されます。 

ここでは、入力サイズが非常に小さいため、総当たりのアイデアと最適なアイデアは事実上同じです。 プレフィックスを左から右に 1 回処理し、これまでに確認された最良の平均を維持します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべてのプレフィックスの平均を保存) | O(n) | O(n) | 承認済み |
 | 最適 (オンラインで最良の部分を追跡) | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最初の数字を読みます`n`。 
2. 初期化します。 

-`sum_prefix = 0`-`count = 0`-`best_sum = 0`-`best_count = 1`分数`best_sum / best_count`は、これまでに見つかった最良のプレフィックス平均を表します。 
3. 繰り返します`n`回:

 - 次の桁を読み取ります`x`。 
- に追加します`sum_prefix`。 
- インクリメント`count`。 
4. 相互乗算を使用して、現在のプレフィックス平均と保存されている最良の平均を比較します。 

- もし$$\text{sum\_prefix} \cdot \text{best\_count} \ge \text{count} \cdot \text{best\_sum},$$次に更新します:

 -`best_sum = sum_prefix`-`best_count = count`これはまさに LOLCODE プログラムによって実行される比較です。 
5. すべての値が処理された後、出力します。$$\frac{\text{best\_sum}}{\text{best\_count}}.$$### なぜ効果があるのか

 プレフィックスを処理した後、ペアは`(best_sum, best_count)`これまでに確認されたすべてのプレフィックスの中で最大のプレフィックス平均が保存されます。 

格納されている値は次のとおりであるため、最初はこれは true です。`0/1`。 新しいプレフィックスが処理されるたびに、その平均が保存されている最大値と比較されます。 それが大きいか等しい場合は、格納されている小数部を置き換えます。 それ以外の場合は、以前のものを保持します。 帰納法により、最後の反復の後、保存された小数はすべてのプレフィックスの最大平均を表し、それがプログラムによって正確に出力されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    data = [int(line.strip()) for line in sys.stdin if line.strip()]

    n = data[0]

    prefix_sum = 0
    cnt = 0

    best_sum = 0
    best_cnt = 1

    for x in data[1:1 + n]:
        prefix_sum += x
        cnt += 1

        if prefix_sum * best_cnt >= cnt * best_sum:
            best_sum = prefix_sum
            best_cnt = cnt

    print(best_sum / best_cnt)

if __name__ == "__main__":
    solve()
```最初の値によって、シーケンスに属する後続の数値の数が決まります。 各値が読み取られると、累計とプレフィックス長が更新されます。 

重要なのは比較です```
prefix_sum * best_cnt >= cnt * best_sum
```かどうかをチェックします$$\frac{\text{prefix\_sum}}{\text{cnt}} \ge \frac{\text{best\_sum}}{\text{best\_cnt}}$$浮動小数点演算を使用せずに。 

保存された部分は、現在のプレフィックス平均が以前に確認された最良の平均と少なくとも同じくらい大きい場合にのみ更新されます。 最後に、保存された分子と分母を除算することで、プログラムの最終出力が再現されます。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    data = [int(line.strip()) for line in sys.stdin if line.strip()]
    n = data[0]

    prefix_sum = 0
    cnt = 0
    best_sum = 0
    best_cnt = 1

    for x in data[1:1 + n]:
        prefix_sum += x
        cnt += 1

        if prefix_sum * best_cnt >= cnt * best_sum:
            best_sum = prefix_sum
            best_cnt = cnt

    return f"{best_sum / best_cnt}\n"

# provided sample
out = float(run("3\n0\n1\n1\n"))
assert abs(out - 0.666667) < 1e-4

# minimum non-empty sequence

# single positive value
assert run("1\n9\n") == "9.0\n", "single element"

# best prefix is the first one
assert run("3\n5\n0\n0\n") == "5.0\n", "early maximum"

# all equal values
assert run("4\n7\n7\n7\n7\n") == "7.0\n", "constant average"

# maximum average appears at the end
out = float(run("3\n1\n0\n9\n"))
assert abs(out - (10.0 / 3.0)) < 1e-9
