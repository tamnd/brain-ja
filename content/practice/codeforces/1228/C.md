 ## 問題の理解

 整数のペアから導出された一連の数値の積を計算するように求められます。$x$そして$n$。 機能$f(x, y)$のすべての素因数を調べます$x$そしてそのような素数ごとに$p$の最大電力を決定します$p$それは分ける$y$。 次に、これらの値をすべての素数にわたって乗算します。$x$そして全体にわたって$y$から$1$に$n$。 最終結果は予期されるモジュロです$10^9 + 7$。 

入力は 2 つの整数で構成されます。$x$そして$n$。$x$と同じ大きさにすることができます$10^9$, したがって、最大約 9 または 10 個の素因数を持つ可能性があります。$n$まで可能です$10^{18}$、すべてに対して単純な反復を行います$y$不可能。 計算する余裕がない$f(x, y)$それぞれに直接$y$これには必要になるため$O(n \cdot \text{number of primes of } x)$操作が多すぎます。 

考慮すべきエッジケースには次のような場合があります。$x$が素数である (つまり、素因数が 1 つだけ存在する) 場合、$n$最小の素因数より小さい、または$n$の素数の累乗に比べて巨大です$x$。 たとえば、次の場合$x = 2$そして$n = 1$、結果は次のようになります。$1$しかし、不注意な実装では、次のべき乗を計算しようとする可能性があります。$2$まで$1$間違っています。 

## アプローチ

 ブルートフォースアプローチでは因数分解されます。$x$素数まで繰り返します$y$から$1$に$n$、計算する$g(y, p)$素数ごとに$p$、それらを乗算し、積の剰余を求めます。$10^9 + 7$。 問題はそれです$n$できる$10^{18}$したがって、1 回の反復でも、$y$実行不可能です。 操作数は次のとおりです。$10^{18} \cdot \text{number of primes}$、それは不可能です。 

重要な洞察は、各素数について$p$、$f(x, y)$の指数のみに依存します$p$で$y$。 貢献総額は、$p$全体的に$y$から$1$に$n$の倍数を数えることによって計算できます$p^k$に存在する$[1, n]$みんなのために$k \ge 1$。 これにより、問題は、線形的に多くの数値ではなく、素数あたりの対数的に多くのべき乗の合計に縮小されます。 残りの素数は、$x$は独立しているため、それらの寄与を個別に計算し、モジュラー演算を使用して最後に組み合わせることができます。 

ストーリーは次のとおりです。小規模な組織にはブルートフォースが機能します。$n$しかし、大きい場合は失敗します$n$。 関数が素数累乗のみに依存していることを観察すると、すべてを反復する必要がなく、倍数を直接数えることができます。$y$。 これにより、潜在的な問題が軽減されます。$O(n)$複雑さへの$O(\log n \cdot \pi(x))$、それは実現可能です。

 ## アルゴリズムのチュートリアル

 1.因数分解$x$を素約数に変換します。 までの数値については、$10^9$、トライアル分割まで$\sqrt{x}$で十分です。 素数のリストを保持する$p_1, p_2, ..., p_m$。 
2. 変数を初期化する`result = 1`。 これにより、最終積モジュロが累積されます。$10^9 + 7$。 
3. 各素数について$p$因数分解では:

 1.セット`power = 0`。 これにより、次の合計指数が計算されます。$p$製品の中で$f(x, 1) * ... * f(x, n)$。 
2.セット`cur = p`。 これは、$p^1, p^2, ...$繰り返していくうちに。 
3. その間`cur <= n`、 追加$\lfloor n / cur \rfloor$に`power`そして掛け算する`cur`による`p`次の反復のために。 これは、中の数字が何個あるかを数えます。$[1, n]$で割り切れます$p^k$それぞれに$k$。 
4. 乗算`result`による$p^{\text{power}} \mod 10^9 + 7$。 べき乗剰余演算を使用して、大きな累乗を効率的に処理します。 
4. すべての素数を処理した後、印刷します。`result`。 

なぜ機能するのか: の累乗の倍数を数えるループ$p$それぞれのことを保証します$g(y, p)$正しく計上されています。 それぞれ$p$は独立して貢献するため、貢献を掛け合わせると機能します。 べき乗剰余演算は、オーバーフローすることなく大きなべき乗を処理します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mod_pow(a, b, mod):
    result = 1
    a %= mod
    while b > 0:
        if b & 1:
            result = result * a % mod
        a = a * a % mod
        b >>= 1
    return result

def solve():
    x, n = map(int, input().split())
    primes = []
    temp = x
    i = 2
    while i * i <= temp:
        if temp % i == 0:
            primes.append(i)
            while temp % i == 0:
                temp //= i
        i += 1
    if temp > 1:
        primes.append(temp)
    
    result = 1
    for p in primes:
        power = 0
        cur = p
        while cur <= n:
            power += n // cur
            if cur > n // p:
                break
            cur *= p
        result = result * mod_pow(p, power, MOD) % MOD
    
    print(result)

solve()
```説明: 因数分解ループにより、すべての素数が確実に収集されます。$x$。 内側の while ループは、範囲全体の各素数の合計電力をカウントします。$[1, n]$すべての数値を反復処理することなく効率的に実行できます。 べき乗剰余演算によりオーバーフローが防止されます。 小切手`if cur > n // p`大きな累乗を乗算するときの整数のオーバーフローを回避します。
