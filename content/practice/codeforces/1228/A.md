 ## 解決策
 ## 問題の理解

 以下から整数の閉区間が与えられます。`l`に`r`、そして、この範囲内で 10 進数表現が数字を繰り返さない任意の数値を見つける必要があります。 つまり、数値を数字の文字列として書き込む場合、すべての文字は一意である必要があります。 

このタスクは、最小値や最大値などを最適化することではありません。 範囲内の有効な数値はどれでも受け入れられるため、そのような数値が存在する場合はそれが確実に見つかる限り、解の構造は単純になります。 

制約`r ≤ 100000`は十分小さいため、間隔内のすべての数値をチェックすることも可能です。 間隔のサイズは最大で`10^5`、各番号については最大 6 桁のみを検査します。 それはおおよそ次のことにつながります`6 * 10^5`最悪の場合でも操作が可能になりますが、これは Python の制限時間内に収まります。 

単純な間違いは、人々が貪欲に数字を構築しようとしたり、常に選択するなどのパターンを想定したりするときによく発生します。`l`それが機能する場合、または「修正」しようとすると、桁ごとに重複が発生します。 数字の一意性はグローバルな特性であるため、これらのアプローチは失敗する可能性があります。 例えば、`121`ローカルの問題ではなく、数字が原因で失敗する`1`2 つの別々の位置に表示されます。 

もう 1 つの微妙なエッジ ケースは、間隔内に有効な数値がない場合です。 例えば、`l = 110`そして`r = 120`次のような数字のみが含まれます`110, 111, 112 ...`、すべて数字を繰り返します。 このような場合、正しい出力は次のとおりです。`-1`。 

最後に、最初は 1 桁しかないため、1 桁の数値は常に条件を満たします。 どの実装でも、次から始まる範囲を処理する必要があります。`1`正しく。 

## アプローチ

 最も直接的なアイデアは、すべての整数を反復処理することです。`x`から`l`に`r`そして、その数字がすべて異なるかどうかを確認します。 数値のチェックは簡単です。数値を文字列に変換し、通常はセットを使用して、文字が複数回出現しないことを確認します。 

この総当たりアプローチは、入力サイズが小さいため機能します。 最悪の場合は検査いたします`100000`数字、および各小切手は最大 6 桁をスキャンします。 これにより、制限された小さな定数因子ワークロードが得られます。 

重要な観察は、悪用できる隠された構造がないということです。 この制約は、ブルート フォースが目的の解決策となるように意図的に設計されています。 組み合わせて数値を構築したり、範囲をスキップしたりする試みは不要です。 

したがって、問題を間隔をスキャンして各候補を検証することに集約します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((r - l + 1) * d) | お(1) | 承認済み |
 | 最適 | O((r - l + 1) * d) | お(1) | 承認済み |

 ここ`d ≤ 6`は各数値の桁数です。 

## アルゴリズムのチュートリアル

 1. すべての整数を反復処理する`x`から`l`に`r`。 このようにするのは、有効な回答はすべてこの範囲内になければならず、候補を安全にスキップできる構造がないためです。 
2. それぞれについて`x`を文字列表現に変換します。 これにより、数字を文字として扱うことができ、一意性のチェックが簡素化されます。 
3. 文字列内のすべての数字が異なるかどうかを確認します。 セットを維持し、スキャンしながら各桁を挿入します。 セット内にすでに数字が含まれている場合は、その数字をすぐに拒否します。 
4. 数値が一意性チェックに合格した場合は、直ちに出力して終了します。 どのような解決策でも受け入れられるため、これは有効です。 
5. 有効な数値が見つからずにループが終了した場合は、次を出力します。`-1`。 

### なぜ効果があるのか

 各候補数値は必要なプロパティについて個別に検証され、区間内のすべての数値が 1 回だけ検査されます。 チェックは正確であり、変換は適用されないため、有効な候補をスキップすることはできません。 セットメンバーシップテストを使用して繰り返しが明示的に検出されるため、アルゴリズムは無効な数値を誤って受け入れることができません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    l, r = map(int, input().split())
    
    for x in range(l, r + 1):
        s = str(x)
        seen = set()
        ok = True
        for ch in s:
            if ch in seen:
                ok = False
                break
            seen.add(ch)
        if ok:
            print(x)
            return
    
    print(-1)

if __name__ == "__main__":
    solve()
```コア ループはブルート フォース スキャンを直接実装します。 文字列への変換は数字の抽出にのみ使用され、このセットにより重複の定数検出が保証されます。 有効な番号が見つかると、それ以上の検索は不要になるため、早期に終了することが重要です。 

注意すべき唯一の境界条件は包含範囲です`r + 1`Pythonでは`range`これにより、エンドポイントが確実にチェックされます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O((r - l + 1) * d) | 間隔内のすべての数値をスキャンし、各桁を 1 回チェックします。 
| スペース | お(1) | セットは最大 10 桁を保持します。 

最大反復回数は次のとおりです。`10^5`、各反復で最大 6 桁を処理するため、ソリューションは時間とメモリの制限内に問題なく収まります。 

## テストケース```python
import sys, io

def solve():
    l, r = map(int, input().split())
    for x in range(l, r + 1):
        s = str(x)
        seen = set()
        ok = True
        for ch in s:
            if ch in seen:
                ok = False
                break
            seen.add(ch)
        if ok:
            print(x)
            return
    print(-1)

def run(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    old_stdout = sys.stdout
    sys.stdout = io.StringIO()
    
    solve()
    
    out = sys.stdout.getvalue().strip()
    sys.stdin = old_stdin
    sys.stdout = old_stdout
    return out

# provided sample
assert run("121 130") == "123"

# custom cases
assert run("1 9") == "1", "single digit always valid"
assert run("11 11") == "-1", "all digits repeated"
assert run("98 102") in ["98", "102"], "cross boundary behavior"
assert run("123 123") == "123", "already valid single value"

 ## 特殊なケース

 次のような単一値の範囲の場合`11 11`、アルゴリズムはその数字のみをチェックし、繰り返される数字を検出します`1`、正しく出力されます`-1`。 

最初の数値が有効な範囲の場合、次のようになります。`1 9`、アルゴリズムはすぐに受け入れます`1`と停止します。これは、早期終了によって不必要なスキャンが防止されることを示しています。 

次のような境界遷移の場合`98 102`の場合、すべての数値が文字列として均一に扱われるため、アルゴリズムは特別な大文字と小文字を区別せずに、さまざまな桁の長さを正しく処理します。 

すべての候補が無効であるような劣化したケースの場合、`110 115`、すべての反復が一意性チェックに失敗し、アルゴリズムはループを正しく実行して戻り値を返します。`-1`。
