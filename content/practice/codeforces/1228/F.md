 ## 問題の理解

 高さの完璧な二分木から始めます`n`つまり、すべての内部ノードにちょうど 2 つの子があり、すべてのリーフが同じ深さに位置します。 このツリーには正確に含まれています`2^n - 1`ノードがあり、非常に厳格な再帰構造を持っています。すべてのサブツリー自体が完全なバイナリ ツリーです。 

この理想的な構造を構築した後、頂点が 1 つ`v`が削除されます。 許可される唯一の修復はローカル、つまり親の修復です。`v`のすべての子供たちと直接つながっています`v`、接続を維持します。 もし`v`はリーフであり、何も再接続されないため、単純にリーフを削除します。 

1 つのノードが欠落している最終ツリーが与えられ、これらの再接続はすでに暗黙的に適用されています。 タスクは、このツリーがそのような削除によって生じた可能性があるかどうかを判断し、そうであれば、削除されたノードの親である可能性のあるすべての頂点を識別することです。 

制約が意味するのは、`n ≤ 17`なので、木のサイズは最大でも約`1.3 × 10^5`ノード。 ノード数が 2 次に近いソリューションは、すでに遅すぎます。 これにより、削除を明示的にシミュレートするのではなく、サブツリーに対する構造的推論または再帰的推論が求められます。 

微妙な難しさは対称性から生じます。 完全な二分木では、多くの頂点が構造的に同じ位置を占めます。 ノードを削除すると、複数の異なる元の構成が最終的に同じツリーになる可能性があります。 削除された可能性のあるすべてのノードを試してツリー全体を再構築する単純なアプローチでは、構造を検証する必要もありますが、繰り返し行うとコストが高くなります。 

もう 1 つの落とし穴は、学位のみが妥当性を特徴付けると仮定していることです。 削除後、内部ノードは、削除されたノードの子を吸収したかどうかに応じて、次数 3、2、または 1 を持つことができます。 最終ツリーの次数 2 のノードは、明らかなように、必ずしも元のツリーの葉または内部ノードである必要はありません。 

## アプローチ

 ブルートフォース解釈では、削除されたノードを仮定します。`v`そして元の完璧な二分木を再構築してみます。 候補者ごとに`v`概念的には、新しいノードをアタッチし、エッジを適切に分割し、結果の構造が高さの完全な二分木であるかどうかを確認します。`n`。 完全性を検証するには、すべてのノードが厳密なサブツリー サイズ規則に従っていることを確認する必要があり、それにはコストがかかります。`O(N)`小切手ごとに。 あるので`O(N)`候補者、これは次のことにつながります`O(N^2)`操作が遅すぎるため、`N ≈ 10^5`。 

重要な洞察は、完全な二分木の構造はサブツリーのサイズによって完全に決定されるということです。 元のツリー内のすべてのノードのサブツリー サイズは、2 の累乗から 1 を引いたものになります。 ノードを削除した後、ツリー全体でこのパターンに違反するのは 1 か所だけです。削除されたノードの親 (そのサブツリー サイズはちょうど 1 だけ減少します)、およびおそらく、接続がローカルに変更される削除されたノードの子です。 

これは、プロセスを逆にすることを示唆しています。削除されたノードを推測する代わりに、各候補を削除されたノードの親として扱い、その親の 1 つの子を削除することで観察されたツリーが生成されるかどうかを検証します。 親候補を決定したら`p`の場合、他のすべてのノードは依然として独自のサブツリーの完全なバイナリ ツリー ルートのように動作する必要があるため、構造はほぼ決定的になります。 

これにより、問題は、単一ルートの仮定の下でサブツリー サイズと隣接制約の一貫性をチェックすることになります。 完全なバイナリ ツリーのグローバルな剛性により、ルートが固定されるとすべてのノードの位置が強制されるため、ローカルな欠陥が 1 つだけ存在するかどうかを確認するだけで済みます。

 ## アルゴリズムのチュートリアル

 私たちは、完全な二分木がルートと高さによって一意に決定されるという事実を利用します。 ノードが欠落していると、局所的な構造の不一致が 1 つだけ発生し、その親は、近傍が完全な 2 値動作から逸脱する唯一の頂点になります。 

各ノードをテストします`p`削除された頂点の潜在的な親として。 

1. 任意のノードで指定されたツリーをルート化し、DFS を使用して親子関係とサブツリーのサイズを計算します。 これは構造的なアクセスのみを対象としています。 ツリーには方向性がありませんが、方向性を強制します。 
2. 各候補ノードについて`p`、その隣人の誰が元の完璧な木の中で行方不明になった子供である可能性があるかを考えてください。 完全な二分木では、葉以外のすべての子がちょうど 2 つあるため、`p`元々、最終ツリーには次数 3 があったはずです。つまり、2 つの保存されたエッジと、再ルーティングされた 1 つの「失われた子接続」です。 
3. それぞれの近傍を一時的に解釈します。`p`元のツリーの左または右の子として、残りの構造が適切な高さの 2 つの完全なバイナリ サブツリーに分割されるかどうかを確認します。 失われた子のサブツリーは、構造上の逸脱を正確に考慮する必要があります。 
4. 隣接するサブツリーをルートとするすべてのサブツリーについて、それが完全な二分木を形成しているかどうかを検証します。 これは、サブツリーのサイズをチェックすることによって行われます。サブツリーは、そのサイズが次の場合に有効です。`2^k - 1`ある整数に対して`k`であり、その内部構造は一貫しています。 
5. 候補者`p`子が欠落している 1 つの構成だけがツリー全体で完全な一貫性をもたらす場合、有効です。 

重要な考え方は、1 つのノードだけが厳密な再帰的サイズ パターンを破り、その破りは制御された方法で上方に伝播するということです。 他のすべてのノードは、そのサブツリーのサイズが 2 のべき乗から 1 を引いた値であるという不変条件を満たさなければなりません。 

### なぜ効果があるのか

 完全なバイナリ ツリーは再帰的に厳密です。すべてのサブツリーはそれ自体が完全なバイナリ ツリーでなければなりません。 1 つのノードを削除すると、そのようなサブツリー条件が 1 つだけ破壊されます。 再接続ルールにより、この違反が恣意的に拡散するのではなく、削除されたノードの親に吸収されることが保証されます。 

したがって、最終的なツリーでは、1 つを除くすべてのノードが、完全なバイナリ サブツリーの有効なルートとまったく同じように動作します。 削除されたノードの親は、そのローカル構造が 2 つの完全なサブツリーへの有効な分解によって説明できない唯一の頂点です。 候補をテストすることで、この再帰的不変式が単一の削除で許容されるのとまったく同じ方法で失敗する固有のポイントを特定します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

def solve():
    n = int(input())
    N = (1 << n) - 2

    g = [[] for _ in range(N + 1)]
    for _ in range(N - 1):
        a, b = map(int, input().split())
        g[a].append(b)
        g[b].append(a)

    parent = [0] * (N + 1)
    depth = [0] * (N + 1)
    order = []

    # root at 1
    stack = [1]
    parent[1] = -1

    while stack:
        v = stack.pop()
        order.append(v)
        for to in g[v]:
            if to == parent[v]:
                continue
            parent[to] = v
            depth[to] = depth[v] + 1
            stack.append(to)

    # compute subtree sizes
    sz = [1] * (N + 1)
    for v in reversed(order):
        for to in g[v]:
            if parent[to] == v:
                sz[v] += sz[to]

    # check perfect power form
    def is_full(x):
        return x > 0 and (x & (x + 1)) == 0  # x = 2^k - 1

    res = []

    for p in range(1, N + 1):
        deg = len(g[p])

        # candidate parent must have degree at least 2
        if deg < 2:
            continue

        # try assuming missing node is one of neighbors
        ok = False

        for bad in g[p]:
            comp_sizes = []
            for to in g[p]:
                if to == bad:
                    continue
                comp_sizes.append(sz[to])

            # we need remaining components to form two perfect subtrees
            if len(comp_sizes) != 2:
                continue

            a, b = comp_sizes

            if is_full(a) and is_full(b):
                ok = True
                break

        if ok:
            res.append(p)

    print(len(res))
    if res:
        print(*sorted(res))

if __name__ == "__main__":
    solve()
```これらが必要な唯一のグローバル構造信号であるため、実装ではまずツリーをルート化してサブツリー サイズを取得します。 重要な単純化は、元の問題がルート化されていない場合でも、ツリーをルート化されたものとして扱うことです。 これは、無向ツリー内のサブツリーのサイズが選択されたルートにのみ依存し、再構築候補はルートと一貫して位置合わせできるため、有効です。 

各ノードについて`p`、その近隣を検査し、どのエッジが行方不明の子供に対応する可能性があるかをシミュレートします。 隣接する 1 つを削除すると、残りのインシデント構造がコンポーネントに分割されます。 有効な構成では、このようなコンポーネントが 2 つだけ完全なバイナリ サブツリーに対応する必要があります。 小切手`is_full`サブツリーのサイズが一致するかどうかをテストする`2^k - 1`、これは完全な二分木の定義的な特性です。 

実装の微妙な点は、サブツリーを明示的に再構築しないことです。 事前に計算されたサブツリー サイズのみに依存するため、複雑さが線形に保たれます。 ちょっとしたトリック`(x & (x + 1)) == 0`かどうかを確認するコンパクトな方法です`x`という形です`2^k - 1`。

 ## 特殊なケース

 エッジ ケースの 1 つは、削除されたノードがリーフである場合です。 この状況では、最終的なツリーは依然としてほぼ完璧であり、親は単に 1 つの葉の子を失うだけです。 1 つの近傍削除により、未処理の子に正確に対応する 2 つの完全なサブツリーが生成されるため、アルゴリズムはこれを処理します。 

もう 1 つのエッジ ケースは、削除されたノードがルートの 1 レベル下にある場合です。 ルートは、その子のサブツリー サイズが対称でなくなる唯一の頂点になります。 適切な近傍を削除すると 2 つの有効な完全なサブツリーが生成されるため、このチェックではルートが有効な候補として正しく識別されます。 

最後のエッジ ケースは対称性です。ツリーの異なる部分にある複数の頂点が、同一のサブツリー サイズ条件を満たすことができます。 アルゴリズムは一意性を前提とせず、一貫性のみを前提としているため、自然にそれらをすべて収集します。
