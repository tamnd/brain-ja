 ## 問題の理解

 私たちは満たしています$n \times n$からの整数を含むグリッド$1$に$k$。 制限は個々のセルに関するものではなく、構造に関するものです。すべての行には値が少なくとも 1 回含まれている必要があります。$1$また、すべての列には、次のものが少なくとも 1 回含まれている必要があります。$1$。 

したがって、任意の行列について考える代わりに、制約全体は値がどこにあるのかに帰着します。$1$が表示されます。 これらの位置が固定されると、他のすべてのセルに独立して任意の値を入力できます。$\{2, 3, \dots, k\}$。 

タスクは、この条件を満たすグリッドの数を法で数えることです。$10^9 + 7$。 

サイズの制約$n \le 250$セルまたは行に対する指数関数的なサブセット列挙を直接除外します。 パラメータ$k$と同じ大きさにすることができます$10^9$したがって、どのソリューションでも、 の値を反復することは避けなければなりません。$k$その代わりにそれを象徴的に扱います。 

素朴なアプローチは、すべての行と列が少なくとも 1 回ヒットするように、セルのサブセットを選択してセルを配置することです。 これは、2 部構成のセット カバー構成を数えることとすぐに似ています。$2^{n^2}$最悪の場合はそれすら不可能になる$n = 20$。 

2 番目の微妙な問題は、他の値が独立して入力されている場合に 1 の構成を過剰にカウントすることです。 構造上の制約を注意深く無視すると、一部の行または列に何も含まれていない配置を誤って数えてしまう可能性があります。$1$、ローカルでは各セルの選択が適切であるように見えても、これらは無効です。 

最低限の健全性の例は次のとおりです$n=1$。 単一セルには、$1$、つまり、答えは正確に$1$、 かかわらず$k$。 のような素朴な式$k^{n^2}$間違って出力されてしまう$k$、独立した細胞計数よりも構造が重要である理由を示しています。 

## アプローチ

 ブルートフォース解釈では、値を配置するセルのサブセットを選択します。$1$、残りのすべてのセルに値を入力します$2$を通して$k$。 これはすでに次の要因を示唆しています$(k-1)^{n^2 - t}$、 どこ$t$配置されたものの数です。 難しいのは、すべての行と列に少なくとも 1 つが含まれるような、1 の有効な配置を数えることです。 

これにより、問題は 2 部構成の発生パターンのカウントに変換されます。すべての行と列をカバーするマークされたセルのセットが必要です。 これは、完全な 2 部グラフのエッジ セットを数えるのと同じです。$K_{n,n}$どちらの側にも孤立した頂点はありません。 行と列に対する直接の包含/除外は次のようになります。$2^{2n}$サブセット、これはまだ実現可能です$O(4^n)$しかし改良が必要です。 

重要な観察は視点を切り替えることです。構成を直接配置するのではなく、構成を「欠落している」行と列の数によってカウントし、欠落しているセットに対して包含/除外を使用します。 セットを修正すると、$i$行と$j$列に 1 を含めることはできません。その場合は、すべての列が残りの列の中になければなりません。$(n-i)\times(n-j)$サブグリッド。 その領域内の 1 の位置を選択する方法の数はセル間で独立しており、単純なべき乗項が得られます。 次に、交互の符号を使用して過剰カウントを修正します。 

これにより、行と列のサブセットに対する二重の包含と除外が発生します。 対称性によりサイズごとにグループ化が可能$i$そして$j$、サブセット数を二項係数に置き換えます。 

1 の位置が決定されると、他のすべてのセルは次のいずれかを取得できます。$k-1$値は、1 ではないセルの数のみに応じて乗算係数に寄与します。

 ## アルゴリズムのチュートリアル

 含まれる行と列の数を合計することで寄与度を計算します。$1$。 

1. それぞれの選択肢について$i$行が「悪い」と判断され、$j$列が「悪い」場合は、すべて修正します$1$s は残りの部分の中になければなりません$(n-i)\times(n-j)$部分行列。 これは、二項係数を介して暗黙的に行と列のサブセットを選択することによってカウントされます。 
2. これらの不正な行と列を選択する方法は次のとおりです。$\binom{n}{i}\binom{n}{j}$。 
3. 許可された部分行列内では、各セルに独立して次のいずれかを含めることができます。$1$かどうかは関係ありませんが、包含排他によって完全に空の行や列が存在しないようにします。 これにより、有効な各構成が (k-1)^{n^2 - \text{(#ones)}} に寄与する、きれいに変換された式が得られます。 
4. 配置の明示的な列挙を避け、構造カウントのみに基づいて貢献を集計します。 
5. 最終的な答えは、すべての寄与を交互の符号で合計することによって得られます。$(-1)^{i+j}$、無効な行/列が空の構成の過剰カウントを修正します。 

### なぜ効果があるのか

 このアルゴリズムは、「行 i に 1 がない」および「列 j に 1 がない」というイベントに対する包含/排他を直接適用したものです。 すべての無効なグリッドは、1 が欠落している行と列の数に応じて複数回カウントされ、交互の合計により、少なくとも 1 つの行または列に 1 が空であるすべての構成がキャンセルされます。 残りの構成は、すべての行と列に少なくとも 1 つの 1 (必須の制約) が含まれる構成です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modpow(a, e):
    r = 1
    while e:
        if e & 1:
            r = r * a % MOD
        a = a * a % MOD
        e >>= 1
    return r

def solve():
    n, k = map(int, input().split())

    # precompute binomials
    C = [[0] * (n + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        C[i][0] = 1
        for j in range(1, i + 1):
            C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD

    # precompute powers
    pw = [1] * (n * n + 1)
    for i in range(1, n * n + 1):
        pw[i] = pw[i-1] * (k - 1) % MOD

    ans = 0

    for i in range(n + 1):
        for j in range(n + 1):
            sign = -1 if (i + j) % 2 else 1

            ways_rows = C[n][i]
            ways_cols = C[n][j]

            free_cells = (n - i) * (n - j)

            # inclusion-exclusion contribution
            contrib = ways_rows * ways_cols % MOD
            contrib = contrib * pw[free_cells] % MOD
            contrib = contrib * sign % MOD

            ans = (ans + contrib) % MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```このコードは、除外された行と列の選択肢をカウントできるように、最初に二項係数を構築します。 次に、次のべき乗を事前計算します。$k-1$1 つではないすべてのセルが独立してそれらの値の 1 つを提供するためです。 

ダブルループオーバー$i$そして$j$禁止された行と列に対する包含/除外を実装します。 符号の変更は非常に重要です。少なくとも 1 つの空の行または列を持つ構成が強制的にキャンセルされます。 

用語$(n-i)(n-j)$固定禁止構造の下に 1 以外の値を配置するために使用できるセルがいくつ残っているかを表します。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math

    MOD = 10**9 + 7
    n, k = map(int, sys.stdin.readline().split())

    C = [[0]*(n+1) for _ in range(n+1)]
    for i in range(n+1):
        C[i][0] = 1
        for j in range(1, i+1):
            C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD

    pw = [1]*(n*n+1)
    for i in range(1, n*n+1):
        pw[i] = pw[i-1]*(k-1)%MOD

    ans = 0
    for i in range(n+1):
        for j in range(n+1):
            sign = -1 if (i+j)%2 else 1
            free = (n-i)*(n-j)
