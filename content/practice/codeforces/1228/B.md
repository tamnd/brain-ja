 ## 解決策
 ## 問題の理解

 サイズのグリッドが与えられています\(h \times w\)、最初は完全に空であり、塗りつぶされたセルのブロックが上端と左端からどのくらいの距離まで延ばさなければならないかを記述する 2 つの制約セットがあります。 

行ごとに\(i\)、値\(r_i\)最初のことを教えてくれます\(r_i\)その行のセルは埋められ、その直後のセル (存在する場合) は空になります。 だから漕ぐ\(i\)は、空白のセルだけが後に続く、塗りつぶされたセルのプレフィックスのように見えるように強制されます。 

各列ごとに\(j\)、値\(c_j\)同様に、最初の\(c_j\)その列の上から順にセルが埋められ、その下の次のセル (存在する場合) は空になります。 

タスクはグリッドを構築することではなく、行制約と列制約の両方を同時に満たす異なるグリッドの数を法で数えることです。\(10^9+7\)。 

制約\(h, w \le 1000\)までを暗示\(10^6\)細胞。 各セルを 1 回検査するか、行と列にわたって線形スキャンを実行するソリューションが必要です。 行と列を個別に扱う二次関数はすべて合格しますが、サブセットにわたる指数関数または状態ベースの DP は不可能です。 

重要な微妙な点は、これらの制約がグリッドを完全に決定しないことです。 一部のセルは制約を受けずに自由に選択できますが、これは行と列によって引き起こされるプレフィックス構造に違反しない場合に限られます。 

一般的な失敗例は、行と列の制約が微妙な点で矛盾している場合に発生します。 たとえば、行がすでに空になっている位置の下にある列に入力されたセルが必要な場合、構成は無効になり、答えはゼロでなければなりません。 

もう 1 つのエッジケースは次のような場合です\(r_i = 0\)または\(c_j = 0\)。 これらにより、行または列全体が空のセルで始まることが強制され、「空は制約がないことを意味する」という素朴な仮定は崩れます。 

## アプローチ

 ブルートフォース手法では、すべてのセルを塗りつぶしまたは空として割り当て、すべての行および列の接頭辞条件が満たされるかどうかを検証します。 各チェックには \(O(hw)\) がかかり、\(2^{hw}\)これは非常に小さなグリッドであっても完全に実行不可能です。 

制約がプレフィックスベースであるため、各行と列が単調になるという事実を利用する必要があります。 重要な観察は、グリッドを独立したセルとしてではなく、塗りつぶされた領域と空の領域の間の境界条件の集合として再解釈することです。 

各セル \((i, j)\) について、それが強制であるかオプションであるかを検討します。 セルが行プレフィックスと列プレフィックスの両方内にある場合、そのセルは強制的に入力されます。 いずれかの制約に違反する形で行プレフィックスの外側および列プレフィックスの外側にある場合は、強制的に空になります。 唯一の自由は、制約の 1 つと互換性があるが、両方によって同時に固定されないセルで発生します。 

問題は、これらの「自由セル」が矛盾なくいくつ存在するかを数えることに帰着します。 このような各セルは独立して選択でき、係数 2 が答えに寄与します。 いずれかのセルが矛盾する要件 (入力と空の両方が必要) を受け取った場合、答えは 0 になります。 

したがって、ソリューションはすべてのセルの線形スキャンとなり、次を使用してセルの強制ステータスを計算します。\(r_i\)そして\(c_j\)。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 |---|---|---|---|
 | ブルートフォース | \(O(2^{hw} \cdot hw)\) | \(O(hw)\) | 遅すぎる |
 | 最適 | \(O(hw)\) | \(O(1)\) 余分 | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのセル \((i, j)\) について、その行の強制埋め込みプレフィックス内にあるかどうかを判断します。つまり、\(j \le r_i\)。 これにより、行制約によって強制的に 1 になるかどうかがわかります。 

2. 同じセルについて、そのセルがその列の強制埋め込みプレフィックス内にあるかどうかを判断します。\(i \le c_j\)。 これにより、列制約によって強制的に 1 になるかどうかがわかります。 

3. 両方の制約がセルを塗りつぶす必要があることに一致する場合、そのセルを固定塗りつぶしとしてマークします。 

4. 両方の制約がセルが空である必要があることに一致する場合、そのセルを空固定としてマークします。 

5. 1 つの制約によって強制的に埋められ、もう一方の制約によって強制的に空になる場合、構成は不可能であるため、すぐに 0 を返します。 

6. どちらの制約もセルを強制しない場合、このセルは自由であり、塗りつぶされるか空であるかを独立して選択でき、答えに乗算係数 2 が寄与します。 

7. すべてのフリーセルの答えをモジュロで乗算します。\(10^9+7\)。 

これが機能する主な理由は、行制約と列制約がプレフィックス条件を課すだけであるため、各セルの状態は行と列内の相対位置にのみ依存し、矛盾を超えたグローバルな結合が存在しないためです。 

### なぜ効果があるのか

 各行制約は塗りつぶされたセルの連続するプレフィックスを固定し、各列制約は垂直方向に同じことを行います。 セルは、これらのプレフィックス内にあるかどうかによって完全に決まります。 有効なグリッドは両方のプレフィックス システムを同時に満たす必要があるため、すべてのセルは、強制充填、強制空、または制約なしの 3 つのカテゴリのいずれかに分類されます。 制約のないセルでは、セルの選択を他の制約のないセルにリンクする制約がないため、独立性が保たれます。 すべての対話はプレフィックス境界によってすでに解決されています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    h, w = map(int, input().split())
    r = list(map(int, input().split()))
    c = list(map(int, input().split()))

    # grid is 1-indexed conceptually
    ans = 1

    for i in range(h):
        for j in range(w):
            row_fill = j < r[i]
            col_fill = i < c[j]

            if row_fill and not col_fill:
                return print(0)
            if col_fill and not row_fill:
                return print(0)

            if not row_fill and not col_fill:
                ans = (ans * 2) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、各セルの分類が直接エンコードされます。 ループはすべてを網羅します\(h \cdot w\)位置を確認し、セルが行プレフィックスと列プレフィックス内にあるかどうかを確認します。 注意すべき部分はインデックス付けです。Python は 0 から始まるインデックスを使用するため、\(j < r[i]\)「最初に」正しくモデル化する\(r_i\)並んだセル\(i\)”。

 1 つの不可能なセルがグリッド全体を無効にするため、矛盾チェックは即時に返されます。 

乗算は、どちらの制約によっても固定されていないセルにのみ適用されます。

 | 測定 | 複雑さ | 説明 |
 |---|---|---|

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    from math import prod

    MOD = 10**9 + 7

    def solve():
        h, w = map(int, input().split())
        r = list(map(int, input().split()))
        c = list(map(int, input().split()))

        ans = 1

                col_fill = i < c[j]

                    print(0); return
                if col_fill and not row_fill:
                    print(0); return

                if not row_fill and not col_fill:
                    ans = (ans * 2) % MOD

        print(ans)

    solve()
    return sys.stdout.getvalue().strip()

 ## 特殊なケース

 両方の場合に重大なエッジケースが発生します。\(r_i\)そして\(c_j\)同じ位置で矛盾する要件を意味します。 たとえば、次の場合\(r_2 = 0\)しかし\(c_1 \ge 2\)の場合、セル (2,1) は行によって強制的に空になりますが、列によって強制的に入力され、即時無効化がトリガーされます。 

もう 1 つの特殊なケースは、すべてが\(r_i = w\)そしてすべて\(c_j = h\)。 すべてのセルは両方向で強制的に埋められ、有効な構成が 1 つだけ残ります。係数 2 に寄与するセルがないため、アルゴリズムはその構成をキャプチャします。 

最後に、すべての値が 0 の場合、すべてのセルは行と列の両方のプレフィックスによる制約を受けないため、すべてのセルが独立して寄与し、次の結果が得られます。\(2^{hw}\)。
