 ## 解決策
 ## 問題の理解

 正の整数のマルチセットが与えられており、順序付けされていないすべての要素のペアの合計を評価する必要があります。 各ペアについて、2 つの数値が互いに素であるかどうか、つまり最大公約数が 1 であるかどうかを調べます。それらが互いに素である場合、そのペアは両方の要素から導出される値、具体的には 2 つの数値の合計に寄与します。 

タスクを再構成する有効な方法は、要素ごとの貢献度の観点から考えることです。 ペアを直接反復する代わりに、各値に対して、それが互いに素のペアを形成する要素の数を尋ね、それに応じてその寄与を蓄積することができます。 

入力は整数のリストを表します。 出力は単一の整数、つまりすべての共素ペアにわたる合計寄与率です。 

制約 (このクラスの問題に典型的なもの) により、最大約$10^5$おそらく最大の値を持つ要素$10^5$もしくは少し上くらい。 これにより、二次ペアのチェック戦略が即座に除外されます。$10^5 \times 10^5$操作は 2 秒の制限をはるかに超えています。 平$O(n \sqrt{A})$最悪の場合、要素ごとの処理が遅すぎる可能性があります。$A$大きいです。 

単純な実装では、すべてのペアを反復処理して gcd を直接計算します。 これは概念的には機能しますが、計算的には失敗します。 

いくつかの特殊なケースでは、よくある間違いが明らかになります。 すべての数値が同一で 1 より大きい場合、どのペアも互いに素でないため、答えはゼロになる必要があります。 たとえば、入力`[4, 4, 4]`収量`0`。 単純な実装でも、gcd を適切にチェックすることを忘れると、貢献度が誤って蓄積される可能性があります。 別のケースは、すべての数値が`1`、すべてのペアが互いに素であり、答えは急速に大きくなります。 重複処理を省略したり、二重にカウントしたりすると、結果が水増しされてしまいます。 

## アプローチ

 ブルートフォース手法では、すべてのインデックスのペアをチェックし、`gcd(a[i], a[j])`、1 に等しい場合は追加します。`a[i] + a[j]`答えに。 これは定義に直接従うため、単純かつ正しいです。 ただし、実行します$O(n^2)$gcd の計算。 と$n = 10^5$、これは次の順序です。$10^{10}$実行不可能な操作です。 

重要な観察は、ペアについて直接推論する必要がないということです。 代わりに、値ごとに数えることができます$x$、それと互いに素である配列要素の数。 その数がわかれば、$x$単純に$x \cdot \text{cnt}(x)$。 これをすべての要素について合計すると最終的な答えが得られ、この変換により、問題は gcd 制約の下での高速カウントに軽減されます。 

互いに素な要素を効率的に数えることは、約数に関する古典的な包含排除問題です。 gcd を直接チェックする代わりに、公約数を共有する要素の数を数えます。$x$、次にメビウス関数を使用して条件を反転します。 値の頻度を事前に計算し、複数の頻度を集計することで、各クエリに大まかに答えることができます。$O(\sqrt{x})$前処理に応じて、さらに高速になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^2)$|$O(1)$| 遅すぎる |
 | メビウス + 約数の数え方 |$O(A \log A + n \sqrt{A})$|$O(A)$| 承認済み |

 ここ$A$配列内の最大値です。 

## アルゴリズムのチュートリアル

 ペアの列挙から除数ベースのカウントに移行します。 

1. 配列内の最大値を計算し、周波数配列を構築します。`freq`、 どこ`freq[x]`何回ですか`x`が表示されます。 これにより、値を個別ではなく全体的に推論できるようになります。 
2. アレイを構築する`cnt_mul[d]`配列内の何個の数値が割り切れるかを格納します。`d`。 これは、それぞれの倍数を反復することによって行われます。`d`そして周波数を加算します。 このステップでは、生の値を除数構造に変換します。 
3. メビウス関数を事前計算する`mu[d]`最大値まで。 この関数は、素因数に対する包含と排他をエンコードし、割り算制約を組み合わせるときに過大なカウントを修正できるようにします。 
4. それぞれの個別の値について`x`配列内で、恒等式を使用して、配列と互いに素である要素の数を計算します。$$\text{coprime}(x) = \sum_{d \mid x} \mu(d) \cdot cnt\_mul[d]$$この式は、共通の素因数を共有しない要素をカウントします。`x`。 
5. 乗算`x`互いに素数で計算し、すべての出現を合計して答えに累積します。`x`。 
6. 最終累積値を返します。 

### なぜ効果があるのか

 各番号は、有効なパートナーの数に基づいて独立して寄与します。 メビウス反転により、すべての整数がカウントされることが保証されます。`cnt_mul[d]`素因数を共有するかどうかに応じて、正確に含まれるか除外されます。`x`。 これにより、gcd が 1 に等しい数値のみが最終的なカウントに残ることが保証されます。 順序付けされた各寄与はこの変換を通じて 1 回だけ考慮されるため、合計はペアごとの定義と一致します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_mobius(n):
    mu = [1] * (n + 1)
    prime = []
    is_comp = [False] * (n + 1)

    for i in range(2, n + 1):
        if not is_comp[i]:
            prime.append(i)
            mu[i] = -1
        for p in prime:
            if i * p > n:
                break
            is_comp[i * p] = True
            if i % p == 0:
                mu[i * p] = 0
                break
            else:
                mu[i * p] = -mu[i]
    return mu

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    mx = max(a)

    freq = [0] * (mx + 1)
    for x in a:
        freq[x] += 1

    cnt_mul = [0] * (mx + 1)
    for d in range(1, mx + 1):
        for m in range(d, mx + 1, d):
            cnt_mul[d] += freq[m]

    mu = build_mobius(mx)

    def coprime_count(x):
        res = 0
        i = 1
        while i * i <= x:
            if x % i == 0:
                d = i
                res += mu[d] * cnt_mul[d]
                if d != x // d:
                    d2 = x // d
                    res += mu[d2] * cnt_mul[d2]
            i += 1
        return res

    ans = 0
    for x in a:
        ans += x * coprime_count(x)

    print(ans)

if __name__ == "__main__":
    solve()
```この解決策は、配列を頻度表に圧縮することから始まり、その後のすべての計算がインデックス空間ではなく値空間で実行されるようにします。 の`cnt_mul`配列は倍数をスキャンすることによって構築されます。これは、点の値を除数の集合体に変換する標準的な方法です。 

メビウス関数は線形ふるいを使用して構築されており、素因数分解の再計算を回避します。 除数の反転は、最大値までのすべての整数にわたる正しい符号処理に依存するため、これは重要です。 

の`coprime_count`関数は、メビウス反転を約数に適用します。`x`。 実装の微妙な詳細は、各約数が 1 回だけ処理されるようにすることです。 これが繰り返しを行う理由です`i`そしてペア`i`と`x // i`。 

最後に、各要素が貢献します`x * coprime_count(x)`これは、すべての順序付けられた共素ペアにわたる寄与の合計に対応します。

| × | 周波数 |

 | 4 | 2 | 8 |

このトレースは、順序ペア変換がペアごとの定義と一致することを確認します。

```| × | 周波数 | 素数 | 貢献 |

 ## 特殊なケース

 次のような完全に繰り返される配列`[4, 4, 4]`除数キャンセルロジックを実行します。 毎`cnt_mul[d]`約数 4 の はゼロではありませんが、すべての要素が 1 より大きい共通因数を共有するため、メビウス反転によりすべての寄与がキャンセルされます。計算された互いに素の数は各要素でゼロになり、ゼロ和が生成されます。 

2 番目の微妙なケースは、すべての要素が`1`。 ここで、すべての整数は互いに素であるため、各要素の互いに素な数は次となります。$n-1$。 アルゴリズムはこれを正しく反映しています。`cnt_mul[1] = n`そして、他のすべての寄与はメビウス反転の下で消え、完全なペアごとの接続性がそのまま残ります。
