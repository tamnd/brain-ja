 ## 解決策
 ## 問題の理解

 1 次元の数直線、具体的には X 軸上に 3 つの整数点が与えられます。 タスクは、この選択した点から指定された 3 つの点までの距離の合計が最小になるような単一の整数座標を見つけることです。 距離メトリックは通常の絶対差であるため、ポイントの場合$a$そしてポイント$x_i$、距離は$|a - x_i|$。 

入力は複数のテスト ケースで構成され、それぞれが 1 ～ 10 の範囲の 3 つの整数を指定します。各テスト ケースの出力は、達成可能な最小合計距離を表す 1 つの整数です。 

点は非常に狭い範囲に限定されているため、単純なアプローチでは 1 から 10 までのすべての可能な整数座標をチェックすることさえできます。ただし、問題の一般的な構造を理解するには、数学的特性を考慮することが役立ちます。つまり、直線上の 3 点の場合、選択した点が 3 点の中央値である場合、距離の合計は最小になります。 これは、中央値が左端と右端までの距離のバランスをとるためです。 

明らかではないエッジケースには、2 点または 3 点すべてが一致する状況が含まれます。 たとえば、すべての点が 1 にある場合、最適な点も 1 となり、合計距離は 0 になります。2 つの点が 1 にあり、1 つの点が 10 にある場合、最適な選択は 1 または 10 ですが、慎重に計算すると、中央値アプローチにより距離のバランスがとれた点が自然に選択されることがわかります。 

## アプローチ

 ブルートフォースアプローチでは、1 から 10 までのすべての整数座標が考慮され、それぞれの距離の合計が計算されます。 座標範囲が非常に狭いため、この問題にはこのアプローチが実行可能ですが、数学的な観点からは不要です。 候補者ごとに$a$、アルゴリズムの合計$|a - x_1| + |a - x_2| + |a - x_3|$。 3 つの点と 10 の候補位置がある場合、テスト ケースごとに最大 30 回の距離計算が必要になります。 とすれば$t \leq 1000$、これはわずか 30,000 回の計算であり、2 秒の制限時間内に簡単に収まります。 

最適なアプローチは、差の絶対値の合計が点の中央値で最小化されることを観察することから得られます。 3 つの点をソートし、中央の値を直接取得すると、最適な座標が得られます。$a$。 これにより、問題は単純に 3 つの数値 (定数時間) を並べ替えることになります。 候補位置を繰り返したり、合計を繰り返し実行したりする必要はありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(t * 10) = O(t) | お(1) | 入力範囲が狭いため受け入れられます |
 | 中央値に基づく最適 | O(t) | お(1) | 受け入れられ、最適 |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 各テストケースを個別に処理します。 
2. 各テスト ケースについて、X 軸上の点を表す 3 つの整数を読み取ります。 
3. 3 つの整数を並べ替えます。 これにより、最小値、中央値、最大値を簡単に識別できるようになります。 
4. ソートされたリストの中央の値を最適な座標として選択します$a$。 これは中央値であり、距離の最小合計が保証されます。 
5. からの距離の合計を計算します。$a$を使用して 3 つのポイントのそれぞれに$|a - x_1| + |a - x_2| + |a - x_3|$。 
6. 現在のテスト ケースに対して計算された合計を出力します。 

機能する理由: 直線上の 3 つの点のセットの場合、選択した点を中央線から遠ざけると、少なくとも 1 つの方向の合計距離が増加しますが、もう一方の方向の合計距離は十分に減少しません。 したがって、中央値は絶対差の合計を最小化する固有の点です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    x = list(map(int, input().split()))
    x.sort()
    median = x[1]
    total_distance = abs(median - x[0]) + abs(median - x[1]) + abs(median - x[2])
    print(total_distance)
```コードは最初にテスト ケースの数を読み取ります。 テスト ケースごとに、3 つの座標を解析して並べ替え、中央の要素を中央値として取得します。 絶対値関数を使用して、すべての点までの距離の合計を計算し、出力します。 3 つの要素のソートは定数時間であるため、このステップはパフォーマンスの点で簡単です。 中央の要素を使用すると、すべての候補座標をチェックしなくても正確さが保証されます。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()

    t = int(input())

        x = list(map(int, input().split()))
        x.sort()
        median = x[1]

    return output.getvalue().strip()

 ## 特殊なケース

 3 つの点がすべて同じ場合、例:`5 5 5`、アルゴリズムは中央値を選択します`5`。 距離の合計は`0 + 0 + 0 = 0`、このエッジケースを正しく処理します。 

2 つの点が一致し、一方が遠く離れている場合、例:`1 1 10`、収量の選別`[1, 1, 10]`そして中央値は`1`。 距離の合計は`0 + 0 + 9 = 9`を選択することに比べて最小限です。`10`(だろう`9 + 9 + 0 = 18`）。 

点が連続している場合、例:`1 2 3`、ソートされたリストは次のとおりです。`[1, 2, 3]`と中央値`2`合計を生成します`1 + 0 + 1 = 2`。 選択する`1`または`3`産むだろう`1 + 1 + 2 = 4`したがって、アルゴリズムは中央値を正しく識別します。 

これは、中央値ベースのアプローチが、特別なケースを処理することなく、すべての狭い範囲のエッジ ケースを正しく処理することを確認します。
