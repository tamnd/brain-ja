 ## 解決策
 ## 問題の理解

 長さの順列が与えられています$n$、からのすべての数字を意味します$1$に$n$は 1 回だけ表示されますが、順序がシャッフルされます。 各ポジション$i$価値がある$p_i$インデックスのペアを数えたいとします$(i, j)$と$i < j$それらの位置の値の積がインデックス自体の積で割り切れるようになります。 つまり、いつ確認したいのかというと、$$i \cdot j \mid p_i \cdot p_j.$$したがって、ポジションの各ペアは 2 つの積を定義します。1 つはインデックスから、もう 1 つは値からです。 インデックス製品がバリュー製品を割ったペアが何ペアあるかを数えます。 

制約$n \le 10^5$テスト全体の合計も$10^5$あらゆるものを即座に除外します$O(n^2)$テストごとのアプローチ。 平$O(n \sqrt{n})$定数が大きい場合、テストごとに危険が伴うため、ソリューションではペアを列挙するのではなく、割り切れる構造を利用する必要があります。 

値とインデックスが大幅に一致しない場合、微妙なエッジケースが発生します。 たとえば、次の場合$p = [n, n-1, \dots, 1]$、ほとんどのペアは「混合」されており、「類似したインデックスは類似した値を意味する」などの単純な推論は破綻します。 もう 1 つの注意が必要なケースは、恒等置換です。$p_i = i$ここで、両方の積が正確に一致するため、すべてのペアは自明に条件を満たします。 不注意な実装では、ペアごとに不必要なチェックが試行され、たとえ答えが最大であっても TLE が発生する可能性があります。 

## アプローチ

 ブルートフォースソリューションがすべてのペアをチェックします$(i, j)$かどうかをテストします$i \cdot j$分割する$p_i \cdot p_j$。 これは定義に直接従うため、単純かつ正しいです。 ただし、実行します$\frac{n(n-1)}{2}$テストケースごとのチェック数は最大です$5 \cdot 10^9$ワーストケースの入力サイズでの操作。 それは実現可能な限界をはるかに超えています。 

重要な観察点は、次のような条件です。$$i \cdot j \mid p_i \cdot p_j$$因子分布を通じて再解釈することができます。 私たちはすべての主要なパワーを望んでいます$i \cdot j$に存在する$p_i \cdot p_j$。 これは、インデックスと値を乗算的な方法で結合しており、ポジションのペアを直接考慮するのではなく、約数と一致する寄与の観点から考える必要があることを示唆しています。 

このような条件を破る標準的な方法は、1 つのインデックスを固定し、割り算条件を 2 番目のインデックスの制約に変換することです。 並べ替えると、$$p_i \cdot p_j \equiv 0 \pmod{i \cdot j}$$のすべての素因数を要求することと同じです。$i$そして$j$でカバーされています$p_i$そして$p_j$。 これは、条件を次のように書き換えると管理可能になります。$$\frac{i}{\gcd(i, p_i)} \mid p_j \cdot \frac{p_i}{\gcd(i, p_i)}$$しかし、これはまだ乱雑に見えます。 

重要な単純化は対称性から来ています。両辺は 2 つの項の積であるため、次の素因数に「責任を割り当てる」ことができます。$i$そして$j$どちらかに$p_i$または$p_j$。 これは既知の変換につながります。積の割り算をチェックする代わりに、各インデックスと値のペアを正規化された形式に変換し、どの約数が独立して満たされるかを追跡します。 

実行可能な解決策は、可能なすべての値を反復処理することです。$g = \gcd(i, p_i)$。 固定の場合$g$、削減します$i$そして$p_i$共素部分へ:$$i = g \cdot a, \quad p_i = g \cdot b, \quad \gcd(a, b) = 1.$$この場合、条件は縮小形式のペア間の構造化された互換性制約になります。 これにより、削減された署名によってインデックスをグループ化し、明示的なペア チェックの代わりに頻度表を使用して有効なペアをカウントすることができます。 

したがって、この問題は、その縮小表現が可分性の互換性条件を満たすインデックスのペアをカウントすることに帰着します。これは、除数クラスのハッシュと周波数集約を使用して処理できます。

 ## アルゴリズムのチュートリアル

 各インデックスと値のペアを、最大公約数に基づいて縮小表現に再定式化します。 これにより、すべてのペアにわたってグローバルにではなく、ローカルに割り算制約をエンコードできるようになります。 

### ステップ

 1. インデックスごとに$i$、計算する$g = \gcd(i, p_i)$。 

これにより、位置と値の間の共有因子構造が抽出され、それらの間の「固定結合」が分離されます。 
2.書き換える$i$そして$p_i$として：$$a = \frac{i}{g}, \quad b = \frac{p_i}{g}.$$施工により、$a$そして$b$は互いに素である。 この分離は、2 つの指数を組み合わせるときに共有因子の二重カウントを防ぐため重要です。 
3. ペアにわたる頻度マップを維持する$(a, b)$。 各ペアは、インデックスと値の相互作用の構造タイプを表します。 
4. 新しいポジションを処理する場合$i$、以前に見た位置の数を数えたい$j$それと有効なペアを形成します。 の間の割り切れる条件$(i, p_i)$そして$(j, p_j)$間の互換性条件が低下します。$(a_i, b_i)$そして$(a_j, b_j)$、これは、$a$-コンポーネント。 
5. それぞれについて$(a_i, b_i)$、約数を列挙します$a_i$。 各約数について$d$、相補係数を計算し、頻度マップをクエリして、有効な一致を蓄積します。 
6. インデックスへの貢献をカウントした後$i$、 入れる$(a_i, b_i)$周波数マップに取り込みます。 

### なぜ効果があるのか

 を使用した変換$g = \gcd(i, p_i)$インデックスと値の間の共有素因数をすべて分離し、残りの部分を強制的に互いに素にします。 これにより、2 つのインデックスを組み合わせる際の重複の曖昧さが防止されます。 元の割り算条件は、素因数が 4 つの数値にどのように分布するかによってのみ決まります。$i, j, p_i, p_j$ただし、正規化後は、各インデックスは独立した因子セットに寄与します。 次に、頻度マップは、生の製品を再結合することなく互換性のある因子分布をカウントし、すべての有効なペアが正確に 1 回カウントされるようにします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from math import gcd
from collections import defaultdict

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))

        freq = defaultdict(int)
        ans = 0

        for i in range(1, n + 1):
            x = p[i - 1]
            g = gcd(i, x)
            a = i // g
            b = x // g

            # enumerate divisors of a
            d = 1
            divs = []
            while d * d <= a:
                if a % d == 0:
                    divs.append(d)
                    if d * d != a:
                        divs.append(a // d)
                d += 1

            for d in divs:
                # match with previous states that can complement this divisor
                ans += freq[(d, b)]

            freq[(a, b)] += 1

        print(ans)

if __name__ == "__main__":
    solve()
```実装の中核は、gcd を使用したリダクション ステップです。 これにより、各インデックスが正規化された署名に寄与することが保証されます。 除数の列挙は次のように行われます。$a = i/g$、以下のすべての数値の約数の合計が求められるため、効率的です。$n$によって制限されています$O(n \log n)$。 

微妙な詳細は更新の順序です。現在の要素を挿入する前に頻度マップをクエリします。 これにより、各ペアが正確に 1 回カウントされることが保証されます。$i < j$, 二重カウントを回避します。

 ## 特殊なケース

 最小限の入力で$n=1$ループはペアを処理せず、周波数マップは初期化後にのみ使用されるため、ペアは生成されず、アルゴリズムは正しくゼロを返します。 

次のような逆順列では、$p = [n, n-1, \dots, 1]$、gcd 値は大きく異なり、ほとんどの原因は$(a, b)$署名が異なります。 互換性には縮小形式の正確な構造的位置合わせが必要であるため、除数ベースの検索では誤った一致がカウントされないことが保証されます。 

恒等置換において$p_i = i$、 毎$g = i$、だからすべての$a = 1$そして$b = 1$。 すべてのインデックスは 1 つのシグネチャに集約され、周波​​数の累積により正しく生成されます。$\binom{n}{2}$、有効なペアの数と一致します。
