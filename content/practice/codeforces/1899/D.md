 ## 解決策
 ## 問題の理解

 一連の整数が与えられます`a_1, a_2, ..., a_n`ここで、各整数は音符を形成する 2 の指数を表します。`b_i = 2^{a_i}`。 Yarik は 2 つの音符の組み合わせを定義します`(b_i, b_j)`として`b_i^{b_j}`。 彼はペアの数を数えたいと思っています`(i, j)`と`i < j`ノートを交換しても組み合わせは変わらないように、つまり、`b_i^{b_j} = b_j^{b_i}`。 

各テスト ケースにそのようなペアがいくつ存在するかを数える必要があります。 出力はテスト ケースごとに 1 つの整数です。 

入力制約により、最大で次のことが可能になります。`2*10^5`すべてのテスト ケースにわたるメモの合計と各テスト ケース`a_i`と同じ大きさにすることができます`10^9`。 以来`b_i`と指数関数的に成長します`a_i`、の直接計算`b_i^{b_j}`実現不可能です。 大きな累乗を計算するのではなく、数学的に推論する必要があります。 

主な所見は次のとおりです。 

1. もし`b_i = b_j`、 それから`b_i^{b_j} = b_j^{b_i}`些細なことに。 
2. もし`b_i != b_j`、 それから`b_i^{b_j} = b_j^{b_i}`もし、そしてその場合に限り`b_i`そして`b_j`特別な数値プロパティを満たします。`b_i^{b_j} = b_j^{b_i}`と同等です`b_i^{1/b_i} = b_j^{1/b_j}`。 2 のべき乗の場合、これは関係の小さな有限セットになります。 

明らかではないエッジケースには、すべての値が等しいシーケンス、小さなべき乗と大きなべき乗が相互作用するシーケンス (例:`2`そして`4`)、または次のような繰り返し番号を含むシーケンス`[1, 1, 1]`。 

たとえば、入力が次の場合:```
3
1 1 1
```正しい答えは`3`同一の音符のすべてのペアが条件を満たすためですが、単純なアプローチでは単にカウントされるだけになる可能性があります。`1`重複の組み合わせカウントを無視する場合。 

## アプローチ

 ブルートフォースソリューションでは、すべてのペアに対して反復処理が行われます。`(i, j)`そしてチェックしてください`b_i^{b_j} == b_j^{b_i}`直接。 時間計算量は次のようになります。`O(n^2)`テストケースごとに。 最大の場合`n`2_10^5 の場合、約 4_10^10 回の操作が必要になりますが、これでは遅すぎます。 さらに、次の直接計算`b_i^{b_j}`整数オーバーフローのため不可能です。 

重要な洞察は、**対数領域**で作業することです。 もし`b_i^{b_j} = b_j^{b_i}`、取る`log`両側で与えます`b_j * log(b_i) = b_i * log(b_j)`。 と`b_i = 2^{a_i}`そして`b_j = 2^{a_j}`、これを単純化すると、`a_j * 2^{a_i} * log(2) = a_i * 2^{a_j} * log(2)`、これはさらに減少します`a_j * 2^{a_i} = a_i * 2^{a_j}`。 

この方程式には、いくつかの整数解しかありません。`a_i != a_j`なぜなら`2^x`指数関数的に成長します。 具体的には、解決策は次のとおりです。`(a_i, a_j) = (2, 4)`そして`(4, 2)`小さな整数とすべての同一の値の場合`(a_i = a_j)`。 

これにより、問題は同一の数と少数のクロスペアを数えるという問題に軽減されます。`(2, 4)`または`(4, 2)`。 辞書にカウントを保存することで、テスト ケースごとに線形時間で答えを計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`そして配列`a`。 
2. の各数値の出現を数えます。`a`辞書を使って`count`。 これにより、同一のペアの数を迅速に計算できます。 数字の場合`x`登場する`k`時々、あります`k * (k - 1) // 2`ペア`(i, j)`と`i < j`。 
3. 有効なペアの総数を同一のペアの合計として初期化します。 
4. クロスペアをチェックする`(2, 4)`そして`(4, 2)`。 させて`c2 = count[2]`そして`c4 = count[4]`。 そのようなペアの数は`c2 * c4`。 これを合計に加えます。 
5. このテスト ケースの有効なペアの合計数を出力します。 

なぜ機能するのか: すべての有効なペアは、同一の数字のペアか、小さな特別な解の 1 つのいずれかです。`(2, 4)`または`(4, 2)`。 このアルゴリズムは、組み合わせ式を使用して各タイプを 1 回だけカウントし、辞書検索は O(1) です。 これにより正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    count = {}
    for x in a:
        count[x] = count.get(x, 0) + 1

    total_pairs = 0
    # count identical pairs
    for val in count.values():
        total_pairs += val * (val - 1) // 2

    # count (2, 4) or (4, 2) cross pairs
    c2 = count.get(2, 0)
    c4 = count.get(4, 0)
    total_pairs += c2 * c4

    print(total_pairs)
```コードはまず、繰り返される数値を効率的に処理するための頻度マップを構築します。 次に、同じ番号のペアを組み合わせてカウントします。 最後に、唯一の自明ではない有効なペアをチェックします。`(2, 4)`そしてそれを追加します。 すべてのステップは線形であり、大きな数のべき乗を回避します。
