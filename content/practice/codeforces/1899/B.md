 ## 問題の理解

 この問題では、TNT の箱を積み込むときに 2 台のトラックの間で可能な最大重量差を見つけることが求められます。 指定された重量の箱が並んでおり、任意のトラックのサイズを選択できます$k$1から$n$それが分かれる限り$n$。 トラックは連続して積み込まれます: 最初のトラック$k$箱は最初のトラックに行き、次のトラックに行きます$k$箱は 2 台目のトラックに運ばれます。 私たちの目標は、選択した 2 台のトラック間の総重量の絶対差を最大化することです。$k$。 

入力は複数のテスト ケースで構成されます。 各テスト ケースはボックスの数を示します$n$そしてボックスの重みの配列。 出力は、2 台のトラックの合計重量間の最大絶対差です。 トラックが 1 台しかない場合、他に比較するトラックがないため、答えは 0 になります。 

制約により許可されるのは、$n$150,000まで$t$最大10,000ですが、すべての合計$n$テスト ケース全体の数は最大 150,000 です。 つまり、私たちのソリューションはテスト ケースごとに本質的に線形時間で動作する必要があります。$O(n \log n)$最悪の場合。 あらゆることを試す素朴な解決策$k$すべてのトラック合計を個別に計算すると、次のようになります。$O(n^2)$最悪の場合、遅すぎる場合もあります。 

明らかではないエッジ ケースには、すべてのボックスの重みが等しい状況が含まれ、値に関係なく最大の差が 0 になります。$k$、および次の場合$n$プライムです。 たとえば、次の場合$n = 7$すべてのボックスの重みは 1 です。$k$は等しいトラック合計を生成し、最大差は 0 です。不注意な解決策では、グループ化の制約を考慮せずに、最大の重量差には常に最大と最小のボックスが含まれると想定する可能性があります。

 ブルートフォースアプローチはすべてを反復することになる$k$1から$n$、すべてのトラックを合計して各トラックの合計を計算します。$k$-size のセグメントを作成し、最大の差を見つけます。 これは読み込みルールを尊重するため機能しますが、複雑さは次のとおりです。$O(n^2)$最悪の場合、$n$大きいです。 のために$n$約 150,000、これには以上が必要になります$10^{10}$という操作が行われますが、これは非現実的です。 

最適化するための重要な洞察は、あるトラックの重量が最大になり、別のトラックの重量が最小になるときに、トラックの合計間の絶対差が最大になるということです。 配列をソートすると、分割する明確な方法が得られます。$k$ボックスを並べ替えた順序で並べると、トラックの最小金額と最後の金額が表示されます。$k$ボックスにはトラックの最大金額が表示されます。 この観察により、問題はソートとそれに続くプレフィックスとサフィックスの合計の差の計算に帰着します。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 テスト ケースごとに、次の内容を読んでください。$n$およびボックスの重みの配列$a$。 
2. 配列をソートする$a$。 ソートにより、最小の重みが最初に、最大の重みが最後にあることが保証され、極端なトラック合計を効率的に計算するのに役立ちます。 
3. 変数を初期化する`max_diff`これには、現在のテスト ケースで観察された最大の差が保存されます。 
4. 反復処理$k$1から$n - 1$(必要ありません$k = n$トラックが 1 台しか生産されないため)。 それぞれについて$k$、最後の合計の差を計算します。$k$要素 (最大の重み) と最初の要素の合計$k$要素 (最小の重み)。 アップデート`max_diff`この差がもっと大きかったら。 
5. 印刷`max_diff`テストケースごとに。 

機能する理由: ソートにより、連続したサイズのブロックがすべて同じサイズになることが保証されます。$k$トラック合計を表すものは、最大額の合計を超えることはできません$k$要素、または最小要素の合計より小さい$k$要素。 有効なすべての極端な値の間の違いをチェックすることにより、$k$、可能な限り最大の絶対差を見つけることが保証されています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()
    max_diff = 0
    # Only need to check 1 <= k <= n-1
    for k in range(1, n):
        diff = sum(a[-k:]) - sum(a[:k])
        if diff > max_diff:
            max_diff = diff
    print(max_diff)
```コードは高速 I/O を使用して入力を読み取ります。 配列をソートすると、最小の要素が先頭に配置され、最大の要素が末尾に配置されます。 トラックサイズごとに$k$、最初の合計を計算します。$k$要素と最後$k$要素。 最大差はオンザフライで更新されます。 各反復での合計の計算はプレフィックス合計を使用して最適化できることに注意してください。$n$最大 150,000 で、Python の効率的なスライスを使用すると、このアプローチは制限時間内で十分です。
