 ## 解決策
 ## 問題の理解

 ロボットは毎日決まった順序で箱を運びます。 2 日間に 1 回だけ潤滑が行われ、その潤滑の瞬間を選択することができます。 ボックスは移動するとすぐにロボットにダメージを与え始め、次の潤滑が行われるまで 1 時間ごとにダメージを与え続けます。 タスクは、1 日の合計ダメージができるだけ小さくなるように、ボックスの循環順序で最適なポイントを選択することです。 

入力には、いくつかの独立したシナリオが含まれています。 それぞれについて、箱の数とその質量を受け取ります。 出力は、最適な潤滑モーメントを選択した後の可能な最小の総損傷です。 

この制約により、すべてのシナリオにわたるボックスの合計数が到達可能になります。$2 \cdot 10^5$。 これにより、損傷全体を再計算する際に、考えられるすべての潤滑位置をチェックする必要がなくなります。$O(n^2)$動作し、約に到達できます$4 \cdot 10^{10}$操作。 シナリオごとに線形のソリューションが必要です。 

難しいのは、潤滑モーメントが円形であることです。 最後のボックスの後の瞬間は、最初のボックスの前の瞬間と同じであるため、シーケンスを単純な線として扱うと、余分なケースが発生したり、最適な位置を逃したりする可能性があります。 

たとえば、次のことを考えてみましょう。```
1
3
5 1 5
```正しい答えは次のとおりです。```
16
```不用意に実装すると、ボックスの後の位置のみをチェックし、最初のボックスの前の潤滑も有効であることを忘れる可能性があります。 この場合、最小値は 2 番目のボックスの後に達成されますが、循環解釈により再帰が正しく導出されます。 

もう 1 つのよくある間違いは、32 ビット整数の使用です。 のために：```
1
5
10000000 10000000 10000000 10000000 10000000
```答えはそれよりもはるかに大きいです$2^{31}$したがって、狭い整数演算を行う実装ではオーバーフローが発生します。 

## アプローチ

 直接的な解決策は、考えられるあらゆる潤滑瞬間をシミュレートすることです。 循環シーケンス内の考えられるカットごとに、各ボックスがロボットにダメージを与え続ける時間を計算し、対応する寄与を追加できます。 がある$n$考えられるカットと、そのうちの 1 つを計算するのにかかる時間$O(n)$、与える$O(n^2)$時間。 と$n=100000$、これは可能性をはるかに超えています。 

有益な観察は、隣接する潤滑位置がほぼ同一であるということです。 潤滑ポイントを 1 つ前に移動すると、通過したばかりのボックスを除くすべてのボックスは同じ損傷時間を維持します。 そのボックスは、1 時間のダメージを与えるものから、サイクル全体のダメージを与えるものに変わります。 

させて$cur$最初のボックスの前に注油が起こると損傷する可能性があります。 ボックス後の潤滑ポイントの移動$i$そのボックスの寄与が増加します$n-1$何時間も。 その理由は、ボックスが次のサイクルで潤滑前の最後のボックスから潤滑後の最初のボックスに変わるためです。 したがって、変更は次のようになります。$$cur = cur + (n-1)\cdot a_i$$これにより単純な反復が得られます。 最初の位置を一度計算し、現在の答えを維持しながらシーケンスを通じて潤滑ポイントを回転させます。 見つかった最小値が結果となります。 

考えられるすべての位置が個別にチェックされるため、ブルート フォースが機能します。 連続するポジションは予測可能な調整が 1 回だけ異なるため、反復が機能します。

 ## アルゴリズムのチュートリアル

 1. 最初のボックスの前で潤滑が行われた場合の損傷を計算します。 最初のボックスはロボットにダメージを与えます$n$時間、2番目は$n-1$時間など、最後のボックスまで続き、1 時間ダメージを受けます。 これにより、回転プロセスの開始値が得られます。 
2. この値を現在の最小応答として保存します。 最初の位置は有効な候補であるため、含める必要があります。 
3. 給油ポイントをボックス前から移動$i$ボックスの後に$i$。 を追加して現在のダメージを更新します$(n-1)\cdot a_i$。 カットを 1 位置ずらすことによって生じる変化はこれだけです。 
4. シフトごとに、現在のダメージをこれまでに見つかった最良の答えと比較します。 最小値が最適潤滑モーメントとなります。 

なぜ効果があるのか:

 シーケンスを通じてカットを回転する際に、考えられるすべての潤滑位置が 1 回だけ表示されます。 反復により、2 つの隣接する位置間の正確な差が得られるため、維持される値が常に現在のカットの真のダメージになります。 すべての候補が検査され、最小限が維持されるため、最終的な答えは最適なものでなければなりません。 

## Python ソリューション```python
import sys

input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        cur = 0
        for i, x in enumerate(a):
            cur += x * (n - i)

        best = cur

        for i in range(n):
            cur += (n - 1) * a[i]
            if cur < best:
                best = cur

        ans.append(str(best))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```最初のループは、最初のボックスの前に潤滑のためのダメージを構築します。 最初のボックスの係数は次のとおりです。$n$、2番目はそれです$n-1$、最後の係数が次になるまでこれが続きます。$1$。 

2 番目のループでは回転式を適用します。 各ステップで潤滑ポイントが 1 ボックスを超えて移動するため、必要な更新は追加することだけです。$(n-1)$その箱の質量の倍になります。 

Python の整数は、関連する大きな値を自動的に処理します。 この実装では、入力シーケンス以外の余分な配列は保存されないため、メモリ使用量が少なく抑えられます。
