 ## 解決策
 ## 問題の理解

 この問題では、同じ長さの 2 つの配列が得られます。 1 つの配列、それを呼び出す`a`、すでに修正されており、システムの損傷状態を表します。 別の配列を構築する必要があります`b`同じサイズで、各要素が 0 から 10^9 の間で、すべての位置に対して非常に具体的な制約の下にあります。`i`、絶対的な差`|a_i - b_i|`奇妙でなければなりません。 

より簡単な言葉で言い換えると、各ポジションは独立しており、インデックスごとに数値を選択する必要があります。`b_i`それは逆のパリティを持ちます`a_i`。 もし`a_i`均等です、`b_i`奇妙でなければなりません。 もし`a_i`奇妙です、`b_i`均等でなければなりません。 

0 と 1 は両方とも偶数と奇数を表す有効な値であり、常に許容範囲内にあるため、値の大きさに対する制約はここでは限定的ではありません。 

入力サイズは大きくてもよく、すべてのテスト ケースにわたる合計要素数は最大 2·10^5 です。 これは、二次関数や対数線形の要素ごとの大量の計算が不要であることを直ちに示唆しています。 それぞれを決定するだけなので、テスト ケースごとに直接的な線形構成で十分です。`b_i`独立して。 

チェックする価値のある微妙な点は、インデックス間に隠れた結合があるかどうかです。 単純に解釈すると、何らかのグローバル構造が示唆されるかもしれませんが、条件は純粋に要素ごとです。 これにより、並べ替え、動的プログラミング、または貪欲なバランシングの必要がなくなります。 

エッジケースは主にパリティと境界値に関するものです。 たとえば、次の場合`a_i = 0`、それでも奇数を生成する必要があります。`a_i = 10^9`、範囲内にとどまる偶数または奇数の調整がまだ必要です。 これはいつでも可能です。 

## アプローチ

 強引な考え方では、値を次のように割り当てようとします。`b`各位置の考えられるすべての候補をスキャンし、パリティ条件が成立するかどうかをチェックします。 インデックスごとに`i`、0 から 10^9 までのすべての値を反復処理して、有効な値を選択することもできます。 条件は検証しやすいため、これは原理的には正しいですが、要素ごとの検索スペースは 10^9 の可能性があるため、最悪の場合は約 10^14 の演算が必要になります。`n`大きいです。 それはまったく不可能です。 

重要な観察は、制約が最適化を要求せず、実現可能性のみを要求し、パリティのみに依存するということです。 条件がパリティ照合に帰着すると、各位置には、同じパリティを持つ数値と反対のパリティを持つ数値という 2 つの等価クラスが存在します。 私たちは常に適切なクラスから自由に代表者を選ぶことができます。 

これにより、「広大な範囲の検索」から「要素ごとに 2 つの固定値のいずれかを選択する」という問題が解消されます。 便利な構造は、偶数ごとにマッピングすることです`a_i`1 とすべての奇数に`a_i`これは常にパリティ反転条件を満たし、範囲内に収まります。

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、配列を読み取ります。`a`。 各値の処理以外に何も保存する必要はありませんが、保存することで実装が簡素化されます。 
2. 各要素について`a_i`、そのパリティを決定します。 これはチェックすることで行われます`a_i % 2`。 
3. もし`a_i`偶数である場合、割り当てます`b_i = 1`。 これにより保証されます`|a_i - b_i|`偶数マイナス奇数は常に奇数であるため、奇数です。 
4. もし`a_i`奇数です、割り当てます`b_i = 0`。 奇数マイナス偶数は奇数なので、これでも奇数の差が保証されます。 
5. 構築された配列を出力します。 

ステップ 3 と 4 の背後にある理由は、可能な限り最小の代表値を使用してパリティ反転を意図的に強制するためです。 パリティは 2 を加算しても不変であり、その差が 2 で割り切れるかどうかのみを考慮するため、0 と 1 を使用するだけで十分です。 

### なぜ効果があるのか

 維持される不変条件は、すべてのインデックスに対して`i`、のパリティ`b_i`のパリティとは常に異なります`a_i`。 パリティは差が偶数か奇数かを完全に決定するため、これにより次のことが保証されます。`|a_i - b_i|`は常に奇数です。 インデックス間に相互作用は存在しないため、各位置を独立して満たすだけで、配列全体の制約を満たすのに十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    res = []
    for x in a:
        if x % 2 == 0:
            res.append(1)
        else:
            res.append(0)
    
    print(*res)
```このソリューションは、各テスト ケースを個別に読み取り、単一パスで答えを構築します。 重要な実装の詳細は、出力生成をシンプルに保つことだけです。これは、入力が大きい場合、ループ内の印刷が遅くなる可能性があるためです。 

ここでよくある間違いは、次のようなものを選択して値を「最適化」しようとすることです。`x + 1`または`x - 1`。 これも多くの場合有効ですが、不必要であり、次の場合にオーバーフローや境界の問題が発生する危険性があります。`a_i = 10^9`。 固定パリティ代表を使用すると、このような問題がすべて回避されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        res = []
        for x in a:
            res.append(1 if x % 2 == 0 else 0)
        out.append(" ".join(map(str, res)))
    return "\n".join(out)

 ## 特殊なケース

 のために`a_i = 0`、構築はまだきれいに機能します: 0 は偶数なので、次のように割り当てます。`b_i = 1`、与える`|0 - 1| = 1`、これは奇数であり、範囲内です。 特別な取り扱いは必要ありません。 

次のような大きな値の場合`a_i = 10^9`、パリティはまだ明確に定義されており、0 または 1 を割り当てると結果が有効に保たれます。 入力値をミラーリングしたりインクリメントしたりすることはないため、オーバーフローや境界違反のリスクはありません。 

交互のパリティ入力の場合、各インデックスは独立しているため、出力は干渉することなくパリティを要素ごとに反転するだけで、グローバルな一貫性制約が存在しないことが確認されます。
