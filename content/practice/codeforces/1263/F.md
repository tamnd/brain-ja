 ## 解決策
 ## 問題の理解

 宮殿内に 2 つの独立した電力網があり、それぞれがノード 1 を先頭とする根付きツリーを形成しています。 木は葉を通して機器に電力を供給します。 各ツリーの各リーフは 1 つのデバイスにのみ接続され、各デバイスにはメイン グリッドへの接続が 1 つと予備グリッドへの接続が 1 つあります。 

課題は、すべてのデバイスが 1 つのグリッドを介して少なくとも 1 つのヘッド ノードに接続されたままであることを保証しながら、できるだけ多くのワイヤを削除することです。 ワイヤを切断するとノードは親から切断されますが、メイン接続または予備接続が対応するルートに到達している限り、デバイスは安全です。 

入力により、親配列を使用した 2 つのツリーの構造とデバイス接続が得られます。 出力は、すべてのデバイスに電力を供給したまま取り外すことができるワイヤの最大数です。 

制約は小さく、n ≤ 1000、a および b は 2000 までです。これにより、O(n²) 個の解が可能になりますが、O(n² log n) を超えると厳しくなる可能性があります。 ツリーには正確に n 個のリーフがあり、リーフは DFS 順序でデバイスに対応します。 これにより、任意の相互接続を防止するという意味で、ツリーが「順序付けられている」ことが保証されます。 

明らかではないエッジ ケースには、チェーン状のツリー、葉を貪欲に切り取ると複数のデバイスが切断される可能性がある場合、またはすべてのデバイスが単一の「ハブ」ノードに接続されている場合などがあります。 たとえば、メイン ツリーがスター型でルートがすべてのリーフに接続されている場合、1 本を除いてすべてのワイヤを切断すると、予備ツリーで覆われていない限り、他のデバイスの接続が切断されます。 他のグリッドと調整せずに単独で葉をカットしようとする単純なアプローチは失敗します。 

## アプローチ

 ブルート フォース アプローチでは、ワイヤのすべてのサブセットを削除することを検討し、各デバイスに電力が供給されているかどうかを確認します。 これは、ツリーごとに線形時間で到達可能性を計算できるため機能しますが、サブセットの数は指数関数的です。 最大 2000 ノードでは、2^2000 は完全に不可能です。 

重要な洞察は、この問題は、すべてのデバイスでリーフからルートまでの少なくとも 1 つのパスが保持されるようにしながら、**2 つのツリーから削除するエッジの最大セット**を見つけることと同等であるということです。 これを言い換えると、各デバイスは各ツリーのリーフに接続されており、2 つのパスのうち少なくとも 1 つを維持する必要があります。 

DFS 順序に従ってリーフにインデックスを割り当てると、問題はメイン ツリーとリザーブ ツリーのデバイス リーフのシーケンス間の **最長共通部分シーケンス (LCS)** に減ります。 LCS は、接続パスを**最小限の状態に維持**できるデバイスのサブセットを表し、残りのエッジは積極的に削除できます。 

なぜLCSなのか？ 各グリッドのリーフは順序付けされています。 両方のツリーの順序を維持するデバイスを選択すると、必要な親エッジのみを維持することで接続を維持できます。 LCS にないデバイスでは、そのパスの 1 つのグリッドを完全に削除して、そのパスに沿ったすべてのエッジを解放できます。 各 LCS エッジでは一部のワイヤが強制的に残されますが、代替パスに沿った他のすべてのワイヤは削除できます。 

LCS を計算した後、取り外し可能なワイヤの最大数は、両方のツリーのワイヤの合計から各ツリーの LCS パスの合計を引いたものになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべてのサブセットを試す) | O(2^(n)) | O(n) | 遅すぎる |
 | LCS ベースの DP | O(n²) | O(n²) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 親配列からツリーを構築します。 隣接リストを走査するために、隣接リストを保持します。 
2. 両方のツリーのリーフに DFS 番号を割り当てます。 これは、ルートから DFS を実行し、出現する順序でリーフに番号を付けることを意味します。 デバイスの接続はこの順序と一致することが保証されます。 
3. 各デバイスを両方のツリーのリーフ インデックスにマッピングします。 長さ n の 2 つのシーケンスができました。`seq_main`そして`seq_reserve`、メイン リーフと予備リーフのデバイスの順序を表します。 
4. 間の最長共通部分列 (LCS) を計算します。`seq_main`そして`seq_reserve`。 これにより、接続を維持するために **両方のツリーで親エッジがそのまま残される必要がある**デバイスの最大セットが識別されます。 
5. 残さなければならないワイヤの数は次のとおりです。`2 * n - LCS_length`。 なぜ？ 両方のツリーの葉からルートへの各パスは、削除できないワイヤに寄与しています。 LCS の外部にあるデバイスの場合、パスを 1 つのツリーに保持するだけで済みます。 
6. 両方のツリーのワイヤの総数から、残さなければならないワイヤの数を減算します。`removable = (a - 1 + b - 1) - (n + n - LCS_length) = a + b - 2 - (2n - LCS_length) = a + b - 2n - 2 + LCS_length`。 

不変条件は、LCS 内のデバイスのサブセットが両方のツリー内の順序を維持することです。 これらのデバイスの最小限のパス エッジを維持し、すべての代替エッジを解放することで、すべてのデバイスに少なくとも 1 つのツリーを通じて電力が供給されるようにしながら、取り外し可能なワイヤを最大化します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def dfs_leaves(adj, node, leaves):
    if not adj[node]:
        leaves.append(node)
        return
    for child in adj[node]:
        dfs_leaves(adj, child, leaves)

def solve():
    n = int(input())
    
    a = int(input())
    p = list(map(int, input().split()))
    x = list(map(int, input().split()))
    
    adj_main = [[] for _ in range(a + 1)]
    for i, parent in enumerate(p, start=2):
        adj_main[parent].append(i)
    
    leaves_main = []
    dfs_leaves(adj_main, 1, leaves_main)
    mapping_main = {leaf: i for i, leaf in enumerate(leaves_main)}
    seq_main = [mapping_main[device] for device in x]
    
    b = int(input())
    q = list(map(int, input().split()))
    y = list(map(int, input().split()))
    
    adj_res = [[] for _ in range(b + 1)]
    for i, parent in enumerate(q, start=2):
        adj_res[parent].append(i)
    
    leaves_res = []
    dfs_leaves(adj_res, 1, leaves_res)
    mapping_res = {leaf: i for i, leaf in enumerate(leaves_res)}
    seq_res = [mapping_res[device] for device in y]
    
    # LCS DP
    dp = [[0] * (n + 1) for _ in range(n + 1)]
    for i in range(n):
        for j in range(n):
            if seq_main[i] == seq_res[j]:
                dp[i + 1][j + 1] = dp[i][j] + 1
            else:
                dp[i + 1][j + 1] = max(dp[i][j + 1], dp[i + 1][j])
    
    lcs_length = dp[n][n]
    removable = (a - 1) + (b - 1) - (2 * n - lcs_length)
    print(removable)

solve()
```このコードは、親配列から隣接リストを構築し、リーフを検索し、デバイスをリーフ インデックスにマップし、LCS を計算し、最後に取り外し可能なエッジを計算します。 微妙な点としては、1 ベースのインデックス付け、ノード 1 から DFS を開始すること、シーケンスでノード ID ではなくリーフ インデックスが使用されるようにすることなどが挙げられます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
