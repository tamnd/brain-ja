 ## 解決策
 ## 問題の理解

 エッジが色付きの無向グラフが与えられます。`R`または`B`。 

グラフ内に、順番に読み取ったエッジの色が文字列の文字と正確に一致するウォークが存在する場合、その文字列はウォーク可能と呼ばれます。 ウォークでは頂点とエッジを再訪する場合があります。 

各テスト ケースでは、歩行可能ではない最短の文字列を出力する必要があります。 可能なすべての文字列が終わった場合`{R,B}`歩きやすいので印刷します`-1`。 

グラフには最大で次のものを含めることができます`2·10^5`すべてのテスト ケースにわたる頂点とエッジ。 オートマトンのサブセットを明示的に構築したり、指定された長さのすべての文字列をチェックしたりする解決策は絶望的です。 長さ 30 の文字列をすべてチェックするだけでも、すでに 10 億を超える候補が必要になります。 

課題は、バイナリ アルファベットの特殊な構造を利用することです。 

微妙な点は、最も短い禁止文字列は、必ずしも単一の色が何度も繰り返されるわけではないということです。 

考慮する：```
1 --R-- 2
```文字列`RR`歩ける距離ではありませんが、`R`は。 最短の答えは、`RR`。 

もう 1 つの簡単な間違いは、両方の色がどこかに出現する場合、長さ 1 の文字列はすべてウォーク可能であり、長い長さだけをチェックすればよいと考えることです。 

例：```
1 --R-- 2

3 --B-- 4
```両方`R`そして`B`歩いて行けますが、`RB`そうではありません。 どのウォークも赤コンポーネントから青コンポーネントに切り替えることはできません。 The correct answer has length 2.

A third pitfall is handling cycles incorrectly.

 グラフに、その色パターンが正しい方法で永遠に繰り返される歩行が含まれている場合、任意の長さの文字列が可能になります。 この状況を検出することがまさに、`-1`有限応答ケースからのケース。 

## アプローチ

 まず、強引な視点が役に立ちます。 

文字列がウォーク可能かどうかを知りたいとします。 すべての頂点を現在の位置の可能性として扱うことができます。 各文字を読んだ後、対応する色の端に沿って移動します。 これは単なる NFA のシミュレーションです。 

これは、BFS 順序で文字列をレベルごとにチェックし、最初の歩行不可能な文字列で停止することを直ちに示唆します。 

問題は候補文字列の数です。 がある`2^k`一定の長さの文字列`k`。 たとえ最短の禁止文字列の長さが 40 しかないとしても、すでに約 1 兆の候補があることを意味します。 

したがって、まったく異なる視点が必要です。 

重要な観察は、バイナリ ウォーカビリティ問題に使用される美しい組み合わせ補題です。 

無限の周期パターンを定義する```
RRBBRRBBRRBB...
```およびその 4 つの循環シフト:```
RRBBRRBB...
RBBRRBBR...
BBRRBBRR...
BRRBBRRB...
```これら 4 つの周期的な文字列を呼び出します`P0, P1, P2, P3`。 

古典的な結果は次のとおりです。 

4 つすべての長さがある場合、`k`これらの周期的な文字列の接頭辞はウォーク可能であり、長さの **すべて** バイナリ文字列`k`歩きやすいです。 

これにより問題は完全に変わります。 

全部チェックするのではなく、`2^k`文字列の場合、これら 4 つの周期シーケンスのそれぞれの最長のウォーク可能なプレフィックスを理解するだけで済みます。 

ここで、グラフの構造が重要になります。 

サイクル内の位置に対応する 4 つのフェーズ状態を作成します```
R -> R -> B -> B -> R -> ...
```元の頂点ごとに`v`、コピーを 4 つ作成します`(v,0)...(v,3)`。 

位相の場合`p`色を期待しています`c`、次に色の元のエッジすべて`c`有向遷移になる```
(u,p) -> (v,(p+1) mod 4)
(v,p) -> (u,(p+1) mod 4)
```この新しいグラフの有向パスは、特定のフェーズからの周期シーケンスをたどることに正確に対応します。 

この有向グラフにサイクルが含まれている場合、ある周期シーケンスは永久に延長される可能性があります。 このサイクルを繰り返すと任意の長さのプレフィックスが生成され、補題はすべてのバイナリ文字列がウォーク可能であることを意味します。 答えは`-1`。 

それ以外の場合、グラフは DAG です。 

DAG では、フェーズからの最長のウォーク可能プレフィックスは、そのフェーズの任意のノードから始まる最長の有向パスにすぎません。 

これら 4 つの最大長がわかれば、最大のウォーキング可能なプレフィックスが最も小さいフェーズから最短の禁止文字列が取得されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 文字列に対するブルートフォース | 指数 | 指数 | 遅すぎる |
 | 位相グラフ + DAG DP | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 次のコマンドを使用して有向グラフを構築します。`4n`ノード。 
2. 位相パターンを使用します。```
phase 0 -> R
phase 1 -> R
phase 2 -> B
phase 3 -> B
```1. 元のエッジごとに`(u,v,color)`期待される色が等しいすべてのフェーズ`color`、 追加：```
(u,phase) -> (v,next_phase)
(v,phase) -> (u,next_phase)
```1. この有向グラフ上でトポロジー プロセスを実行します。 
2. トポロジー プロセスによってすべてのノードが削除されない場合、グラフには有向サイクルが含まれます。 出力`-1`。 
3. それ以外の場合は、逆のトポロジー順序でノードを処理し、以下を計算します。```
dp[x] = longest number of edges in a path starting from x
```1. フェーズごとに`p`、次を計算します。```
best[p] = max(dp[(v,p)])
```元のすべての頂点にわたって`v`。 

1. しましょう```
p = argmin(best[p])
```そのフェーズからの最長のウォーク可能なプレフィックスには長さがあります`best[p]`、したがって、最短の歩行不可能なプレフィックスの長さは次のようになります。```
L = best[p] + 1
```1.最初の出力`L`フェーズから始まる周期シーケンスの文字`p`。 

### なぜ効果があるのか

 構築された位相グラフは、文字列の周期的なファミリーを 1 つだけエンコードします。 

長さの有向パス`t`段階的に開始`p`カラーシーケンスが最初であるウォークに対応します`t`フェーズで始まる周期文字列の文字`p`。 

位相グラフにサイクルが含まれている場合、その周期ファミリーには任意の長さのウォーク可能なプレフィックスが含まれます。 位相が 4 を法として進むため、サイクル長は 4 の倍数になります。 このサイクルを繰り返すと、4 つのシフトすべてに対して任意の長さのプレフィックスが生成されます。これは、補題により、すべてのバイナリ文字列がウォーク可能であることを意味します。 

位相グラフが非巡回の場合、最長パスの計算によって各シフトの最大の歩行可能なプレフィックス長が得られます。 一部のシフトで失敗した最初のプレフィックスの長さは正確に`best[p] + 1`。 補題は、これがバイナリ文字列が歩行不可能になる最小長でもあることを保証します。 したがって、構築された周期的なプレフィックスが有効な最短の答えとなります。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

PAT = "RRBB"

def solve():
    t = int(input())

    out = []

    for _ in range(t):
        n, m = map(int, input().split())

        N = 4 * n
        g = [[] for _ in range(N)]
        indeg = [0] * N

        for _ in range(m):
            u, v, c = input().split()
            u = int(u) - 1
            v = int(v) - 1

            for p in range(4):
                if PAT[p] == c:
                    np = (p + 1) & 3

                    a = u * 4 + p
                    b = v * 4 + np
                    g[a].append(b)
                    indeg[b] += 1

                    a = v * 4 + p
                    b = u * 4 + np
                    g[a].append(b)
                    indeg[b] += 1

        q = deque(i for i in range(N) if indeg[i] == 0)
        topo = []

        while q:
            v = q.popleft()
            topo.append(v)

            for to in g[v]:
                indeg[to] -= 1
                if indeg[to] == 0:
                    q.append(to)

        if len(topo) != N:
            out.append("-1")
            continue

        dp = [0] * N

        for v in reversed(topo):
            best = 0
            for to in g[v]:
                cand = 1 + dp[to]
                if cand > best:
                    best = cand
            dp[v] = best

        phase_best = [0] * 4

        for phase in range(4):
            mx = 0
            for v in range(n):
                mx = max(mx, dp[v * 4 + phase])
            phase_best[phase] = mx

        phase = min(range(4), key=lambda p: phase_best[p])
        length = phase_best[phase] + 1

        ans = []
        for i in range(length):
            ans.append(PAT[(phase + i) & 3])

        out.append("".join(ans))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```グラフには、`4n`これは、元のすべての頂点がノード内の位置ごとに 1 回複製されるためです。`RRBB`サイクル。 

トポロジカルソートには 2 つの目的があります。 これはサイクルを検出し、DAG 内の最長パス DP に必要な順序付けも提供します。 

DP は、パスの長さを頂点ではなくエッジに保存します。 長さの文字列なので`L`正確にトラバースに対応します`L`色付きのエッジ、これが必要な量です。 

最終的な答えの長さは、`best + 1`、 なぜなら`best`ウォーク可能なプレフィックスの最大長です。 次の文字は、歩行性が損なわれる最初のポイントです。

 ## 特殊なケース

 エッジのないグラフを考えてみましょう。```
1 0
```空でない文字列はウォーク可能ではありません。 位相グラフにはエッジがないため、すべての DP 値はゼロになります。 このアルゴリズムは、次のような長さ 1 の周期的なプレフィックスを出力します。`R`。 それは正しいです。 

赤いエッジのみを含むグラフを考えてみましょう。```
3 3
1 2 R
2 3 R
3 1 R
```次で始まる任意の周期シーケンス`B`ウォーク可能なプレフィックスの最大長はゼロです。 アルゴリズムはすぐに戻ります`B`、これは最も短い禁止文字列です。 

2 つの切り離された単色コンポーネントを考えてみましょう。```
4 2
1 2 R
3 4 B
```シングル`R`そしてシングル`B`どちらも歩きやすいです。 ただし、色の切り替えが必要なストリングは不可能です。 DP は、すべての周期的シフトが最長のウォーク可能なプレフィックス長 1 を持っていることを発見し、次のような長さ 2 の禁止された文字列を生成します。`RB`。 これにより、個々の色だけをチェックするというよくある間違いを防ぐことができます。 

サイクルの場合はトポロジカルソートによって処理されます。 位相グラフに有向サイクルが含まれている場合、アルゴリズムは次のように出力します。`-1`、任意の長さの周期的なプレフィックスが存在し、その結果としてすべてのバイナリ文字列がウォーク可能であることを認識します。
