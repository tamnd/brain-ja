 ## 解決策
 ## 問題の理解

 同じサイズの 2 つの隠れた順列が与えられています。これらを次のように呼びます。$a$そして$b$。 それらを直接見る代わりに、2 つの順列が逆方向にどのように相互に構成されるかをエンコードする 2 つの派生配列が与えられます。 

あらゆるポジションについて$i$、最初の配列は次の値を与えます。$a$位置にある$b_i$、2 番目の配列は次の値を返します。$b$位置にある$a_i$。 言い換えれば、各配列は他の順列による「クロスルックアップ」です。 タスクは、任意の順列のペアを再構築することです。$a$そして$b$これらの制約と一致するか、そのようなペアが存在しないと判断します。 

これを読み取るのに便利な方法は、すべてのインデックスが 2 つの未知の全単射に同時に関与しているということです。 1 つの全単射によって、それがどこにマッピングされているかがわかります$b$、もう 1 つは、どこにマッピングされるかを示します。$a$。 入力はどちらのマッピングも直接提供せず、各インデックスで評価されるそれらの構成のみを提供します。 

制約は十分に大きいため、すべてのテスト ケースにわたる合計入力サイズが$2 \cdot 10^5$。 順列や強引な代入を推測しようとする試みは、すぐに失敗します。$O(n^2)$動作はすでに制限を数桁超えている可能性があります。 

微妙な問題は、入力が単一のグラフのエッジとして構造を直接公開しないことです。 代わりに、未知の順列の 2 つの相互依存画像が得られ、両方を同時に一貫させる必要があります。 

小規模な健全性チェックによって、すでに失敗例が明らかになります。 両方の配列が同一である場合、自動的に意味するわけではありません。$a = b$。 たとえば、両方の配列が$[1]$、答えは自明ですが、それが長くなると、サイクルがどのように相互作用するかによっては一貫性が崩れる可能性があります。 誤解を招くもう 1 つの状況は、両方の配列が同一のサイクル構造を持つ順列であるが、一貫した因数分解が不可能になる方法でシフトされている場合です。 各配列を順列再構成問題として個別に扱う単純な試みでは、これらの相互制約が無視され、不正確な結果が生成されます。 

## アプローチ

 直接的なブルートフォース戦略では、値を割り当てようとします。$a$そして$b$繰り返して。 各インデックスについて、推測することができます$b_i$を導出します。$a_{b_i}$、制約を前方に伝播します。 これはすぐに後戻り問題になり、分岐係数が最大で$n$、そしてそれぞれの選択は両方の順列にグローバルに影響します。 最悪の場合、すべての値の配置が将来の複数の配置を制約するため、階乗多の割り当てを探索することになります。 枝刈りを行ったとしても、各方程式は局所的な位置だけでなく 2 つの未知の関数を接続するため、伝播は弱すぎます。 

重要な観察は、考えるのをやめるということです$a$そして$b$それらを配列として扱い、代わりに共通セットの全単射として扱います。 制約$$p[i] = a[b[i]], \quad q[i] = b[a[i]]$$それを暗示します$p$そして$q$独立したオブジェクトではありません。 それらは未知の順列を通じて共役します。 具体的に応用すると、$a$後$b$収量$p$、申請中$b$後$a$収量$q$。 この対称性により、強い構造条件が強制されます。$p$そして$q$同一のサイクル構造を持たなければなりません。 

その理由は、共役によってサイクル分解が保存されるためです。 要素の再ラベル付けによって 2 つの順列が関連付けられている場合 (これはまさに未知のものです)$a$そして$b$do) の場合、それらのサイクル長は一致する必要があります。 これにより、問題は「2 つの順列を構築する」から「サイクル分解を一致させ、サイクル内の要素を一貫して再ラベルする」に軽減されます。 

両方を分解すると$p$そして$q$サイクルに分割、各サイクルで$p$のサイクルに対応する必要があります$q$同じ長さの。 一致するサイクルの各ペア内で、要素がどのように対応するかを自由に選択でき、この対応により両方の要素が決定されます。$a$そして$b$地元で。 次に、これらのサイクルレベルのマッピングをつなぎ合わせることで、グローバルなソリューションが得られます。 

これにより、問題は関数方程式系ではなく、制御された再ラベル付けタスクに変わります。

 ## アルゴリズムのチュートリアル

 1. 指定された 2 つの配列を構築します$p$そして$q$入力から。 これらは合成された効果を表します$a \circ b$そして$b \circ a$。 
2.分解する$p$ばらばらのサイクルに。 各インデックスは正確に 1 つのサイクルに属します。$p$は順列です。 サイクルとその中の各要素の位置の両方を記録します。 
3.分解する$q$同様にばらばらのサイクルに分割します。 
4. グループサイクル$p$そして$q$その長さによって。 有効な再構成は、長さごとにサイクル数が次の場合にのみ可能です。$p$のサイクル数に等しい$q$。 これが失敗すると、一貫した再ラベル付けが存在できなくなります。 
5. 同じ長さの一致するサイクルのペアごとに、それらの要素間の対応関係を選択します。 一貫した方法の 1 つは、それらを循環的な順序で整列させ、$k$サイクルの - 番目の要素$p$に$k$のペアになったサイクルの - 番目の要素$q$。 
6. この対応関係を使用して定義します$a$そして$b$。 各要素が 1 つの順列のどこに配置されるかを決定すると、方程式は次のようになります。$p[i] = a[b[i]]$そして$q[i] = b[a[i]]$各サイクル内で他のマッピングを一意に決定します。 
7. すべてのサイクルを満たした後、構築された順列を出力します。 

ステップ 5 と 6 の基本的な考え方は、サイクル内ではすべてが回転システムのように動作するということです。 2 つのサイクル間の開始位置合わせを決定すると、残りのマッピングは構成の一貫性によって強制されます。 

### なぜ効果があるのか

 各順列はサイクルの素結合とみなすことができ、順列の共役では、サイクルの長さを変更せずにサイクル内の要素の名前のみが変更されます。 以来$p = a \circ b$そして$q = b \circ a$、両方とも、異なる座標系で観察される同じ構造作用を表します。 同じ長さのサイクルを一致させると、これらの座標系間の隠れた再ラベル付けが再構築されます。 サイクルの対応が固定されると、方程式によって各サイクル内の固有の一貫した遷移が決定され、曖昧さが防止されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    p = list(map(int, input().split()))
    q = list(map(int, input().split()))

    def get_cycles(arr):
        n = len(arr)
        vis = [False] * n
        cycles = []
        pos_in_cycle = [-1] * n

        for i in range(n):
            if not vis[i]:
                cur = []
                v = i
                while not vis[v]:
                    vis[v] = True
                    pos_in_cycle[v] = len(cur)
                    cur.append(v)
                    v = arr[v] - 1
                cycles.append(cur)
        return cycles

    cp = get_cycles(p)
    cq = get_cycles(q)

    from collections import defaultdict, deque
    mp = defaultdict(deque)
    mq = defaultdict(deque)

    for c in cp:
        mp[len(c)].append(c)
    for c in cq:
        mq[len(c)].append(c)

    a = [-1] * n
    b = [-1] * n

    for length in mp:
        if len(mp[length]) != len(mq[length]):
            print("NO")
            return

        while mp[length]:
            c1 = mp[length].popleft()
            c2 = mq[length].popleft()

            k = len(c1)
            for i in range(k):
                u = c1[i]
                v = c2[i]
                a[v] = c1[(i + 1) % k] + 1
                b[u] = c2[i] + 1

    if any(x == -1 for x in a) or any(x == -1 for x in b):
        print("NO")
        return

    print("YES")
    print(*a)
    print(*b)

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```コードは最初に、両方の派生順列のサイクル分解を構築します。 重要な実装の詳細は、サイクル リストを明示的に維持することです。これは、インデックスから位置へのマッピングだけでは 2 つの独立したサイクル システム間の調整を制御するのに十分ではないためです。 

各サイクル内の割り当てステップでは、最も多くの間違いが発生します。 マッピングは循環的である必要があるため、次の要素は常にサイクル長を法として取得されます。 ここでの off-by-one エラーは、置換の有効性を即座に破棄します。 

この構造により、すべての要素が両方に 1 回だけ割り当てられるようになります。$a$そして$b$これは、両方の分解において、すべてのノードがちょうど 1 つのサイクルに属するためです。

 ### 例 1

 導出された両方の順列が 1 つのサイクルを形成する、小規模な一貫したケースを考えてみましょう。 

入力:```
n = 3
p = [3, 1, 2]
q = [2, 3, 1]
```サイクル分解:

 | ステップ | pサイクル | qサイクル |
 | --- | --- | --- |
 | 1 | (1 → 3 → 2 → 1) | (1 → 2 → 3 → 1) |

 の唯一のサイクルに一致します$p$の唯一のサイクルで$q$。 位置を揃えると次のようになります。 

-$1 \leftrightarrow 1$-$3 \leftrightarrow 2$-$2 \leftrightarrow 3$この調整から、$a$そして$b$一貫した循環シフトとなり、有効な順列が生成されます。 

このトレースは、サイクルが一致すると、再構成が回転まで決定論的であることを確認します。 

### 例 2

 マッチングが不可能な場合を考えてみましょう。```
n = 2
p = [1, 2]
q = [2, 1]
```| ステップ | p サイクル | q サイクル |

これは、サイクル構造が決定的な不変条件である理由を示しています。

 ## 特殊なケース

 いつ$n = 1$、両方の配列は自明です$[1]$。 サイクル分解により、両方の置換で単一の固定点が生成され、それらは直接一致し、次の結果が得られます。$a = b = [1]$。 

すべてのサイクルが固定点の場合、両方とも$p$そして$q$に分解する$n$アルゴリズムはそれらを 1 対 1 でペアにし、各要素は独立して割り当てられ、有効性が維持されます。 

サイクル数が一定の長さで異なる場合、アルゴリズムは早期に停止します。 これは、共役によってサイクルのタイプを変更できないため、再ラベル付けによって修正できない構造的非互換性に対応します。 

サイクルが長くても内部的に位置がずれている場合は、サイクル内の各要素の後続要素が選択された位置合わせを法として保持されるため、位置ペアリングによって一貫性が保証されます。
