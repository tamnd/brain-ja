 ## 解決策
 ## 問題の理解

 次のサイズの長方形の壁が与えられています。$2m \times 2n$、整数グリッド上の原点を中心に配置されます。 各単位正方形セルは整数座標によって識別されます$(x, y)$この長方形の中にあります。 

セルの値は次のように定義されます。$\max(|x|, |y|)$。 これにより、グリッド全体が同心の正方形の「リング」に分割されます。 同じ値を持つすべてのセルが同じリング上にあり、中心の周りに閉じたサイクルを形成します。 

タイルは接続されたセルのグループであり、タイル内のすべてのセルが完全に単一のリング内にある場合にのみ許可されます。 したがって、タイルはあるリングから別のリングに渡ることはできませんが、接続性が保たれている限り、穴のある形状を含め、リング内の接続された形状を占有することができます。 

一方のタイリングでは 1 つのタイル内に一緒に存在するが、もう一方のタイリングでは異なるタイルに分離されているセルのペアが少なくとも 1 組存在する場合、2 つのタイリングは異なるものとみなされます。 

このような有効なタイリングがいくつ存在するかを数える必要があります。$10^9 + 7$まで、$10^4$テストケース、$m, n \le 10^6$。 

主な制約の意味は、テスト ケースごとにグリッドをシミュレートしたり、明示的な構造を構築したりできないことです。 すべては次の閉形式関数に還元されなければなりません。$m$そして$n$、一定時間で計算可能。 

次のような、グリッドが最小の場合に重要なエッジ ケースが表示されます。$m = n = 1$、ここで全体$2 \times 2$グリッドは単一のリングを形成します。 その場合、どのソリューションも 4 サイクル内のすべての接続されたパーティションを考慮する必要があります。 各セルが独立して動作するという単純な仮定は過剰カウントにつながります。これは、接続性の制約によってサイクルに沿った選択が結合されるためです。 

もう 1 つの微妙な問題は、すべてのリングが線形ではなく環状であることです。 リングをパスとして扱うと、サイクルの最後のエッジと最初のエッジの間の「ラップアラウンド」接続が誤って禁止されてしまいます。 

## アプローチ

 強引な解釈では、各リングを個別に検討し、そのセルを接続されたコンポーネントに分割する可能なすべての方法を列挙します。 各コンポーネントは 1 つのリング内に留まらなければならないため、異なるリングは相互作用しないため、合計の答えはリングの積となります。 

1 つのリング内の構造は、その層のセルを頂点とする単純なサイクル グラフです。 単純なアプローチでは、このサイクルのすべてのパーティションを接続された誘導サブグラフに列挙しようとします。 これは、サイクルを連続したブロックに分割するためのすべての方法を検討することと同じです。 このようなパーティションの数はリング サイズに応じて指数関数的に増加し、単一のリングの長さの場合でも増加します。$O(m+n)$、ブルートフォースは実行不可能です。 

重要な観察は、サイクル上、エッジのサブセットが接続されたコンポーネントへの分割を一意に決定するということです。 エッジごとにカットするかどうかを個別に決定すると、接続性が各セグメント内で正確に保持されるため、結果として得られる各接続コンポーネントは自動的に有効なタイルになります。 

したがって、それぞれの長さのリング$L$貢献する$2^L$可能な方法。 

すべてのリングを合計すると、すべてのセルは正確に 1 つのリングに属するため、リングの長さの合計はグリッド セルの総数に等しくなります。$4mn$。 これにより、問題全体がコンピューティングに帰着します。$2^{4mn} \bmod (10^9+7)$。 

ブルート フォースは、問題を独立したエッジの決定に帰着させるため、概念的には機能しますが、明示的にリングをモデル化するか、リングごとの構成を列挙することはグリッド サイズが線形であり、大規模な入力では不可能であるため、計算的には失敗します。 各リングは、カットがタイリングを完全に特徴付けるサイクルであるという観察により、すべてが単一の指数に圧縮されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | リングごとのブルート フォース列挙 | 指数 | O(mn) | 遅すぎる |
 | サイクルエッジの独立性の削減 | テスト ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各セルが、次のように決定される 1 つのレベルに正確に属していることを確認します。$\max(|x|, |y|)$。 これにより、グリッドが互いに素なリングに分割されます。 
2. 1 つのリング内では、隣接関係が単純なサイクル グラフを形成していることを認識します。 各セルには、そのリングの境界横断に沿って正確に 2 つの隣接セルがあります。 
3. リング内の有効なタイリングを、サイクル グラフの連結コンポーネントへの分割として再定式化します。 各コンポーネントは、サイクルに沿った連続したセグメントに対応します。 
4. サイクルの各エッジを二者択一の選択肢に関連付けます。エッジを「カット」する (タイル境界を終了する) か、それともカットしません。 これにより、接続されたコンポーネントが正確に最大の未切断セグメントであることが保証されます。 
5. 一定の長さのリング内の構成を数える$L$として$2^L$エッジのすべてのサブセットが有効なパーティションに対応するためです。 
6. すべてのリングにわたる寄与を合計します。 リングは互いに素であり、すべてのセルをカバーしているため、合計の指数はグリッド内のセルの数になります。$4mn$。 
7. コンピューティング$2^{4mn} \bmod (10^9+7)$高速べき乗剰余演算を使用します。 

正確性は、カットのすべての構成が連結コンポーネントへの一意のパーティションを生成し、すべての有効なパーティションが 1 つのカット パターンに正確に対応するという不変条件に依存します。 サイクル内のエッジを削除しても、目的のセグメント以外の切断されたフラグメントを作成できないため、構成は接続に違反しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mod_pow(a, e):
    res = 1
    while e:
        if e & 1:
            res = (res * a) % MOD
        a = (a * a) % MOD
        e >>= 1
    return res

t = int(input())
for _ in range(t):
    m, n = map(int, input().split())
    exp = (4 * m * n) % (MOD - 1)
    print(mod_pow(2, exp))
```この実装では、ジオメトリ全体が累乗されます。 唯一の微妙な点は、フェルマーの小定理を使用して指数モジュロを減らすことです。$10^9+6$、係数が素数であるため。 

## 実用的な例

 2 つのケースについて、指数と最終値の計算を追跡します。 

### 例 1:$m = 1, n = 1$| ステップ | 値 |
 | --- | --- |
 | グリッドサイズ |$2 \times 2$|
 | セル | 4 |
 | 指数$4mn$| 4 |
 | 結果 |$2^4 = 16 \bmod MOD$|

 これは、縮小前の生のサイクル独立性の解釈を示しています。 

### 例 2:$m = 3, n = 1$| ステップ | 値 |
 | --- | --- |
 | グリッドサイズ |$6 \times 2$|
 | セル | 12 |
 | 指数$4mn$| 12 |
 | 結果 |$2^{12} = 4096$|

 これは、いずれかの次元をスケーリングしても、セルの数に応じて指数が線形に増加するだけであることを確認します。 

このトレースは、サイクル分解が認識されると、タイルの構造上の複雑さがすべて消失することを示しています。 

## 複雑さの分析

 | スペース |$O(1)$| 少数の整数のみが保存されます。

## テストケース```python
import sys, io

MOD = 10**9 + 7

def mod_pow(a, e):
    res = 1
    while e:
        if e & 1:
            res = (res * a) % MOD
        a = (a * a) % MOD
        e >>= 1
    return res

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    t = int(input())
    out = []
    for _ in range(t):
        m, n = map(int, input().split())
        out.append(str(mod_pow(2, 4 * m * n)))
    return "\n".join(out)

# sample-like sanity checks
assert run("1\n1 1\n") == "16"
assert run("1\n2 1\n") == str(pow(2, 8, MOD))
assert run("1\n1 2\n") == str(pow(2, 8, MOD))
assert run("1\n3 4\n") == str(pow(2, 48, MOD))
```| テスト入力 | 期待される出力 | 検証内容 |

 ## 特殊なケース

 いつ$m = n = 1$、グリッドは長さ 4 の単一サイクルに縮小します。アルゴリズムはこれを次のように解釈します。$4mn = 4$、生産$2^4$。 これは、4 つのサイクル エッジのそれぞれを独立してカットできる、またはカットできず、すべての有効な接続されたパーティションが生成されるという考えと一致します。 

一方の次元が 1 でもう一方の次元が大きい場合、構造は多数の入れ子のリングを含む長い長方形の境界になります。 各リングは依然として独立して寄与しており、合計指数は長方形内のセルの数と同じままです。 すべてがグローバル カウントに吸収されるため、アルゴリズムは内側のリングと外側のリングを区別しません。$4mn$、細長いグリッドの一貫した処理を保証します。
