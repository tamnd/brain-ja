 ## 問題の理解

 数字の文字列として書かれた大きな整数が与えられ、別の整数を構築するように求められます。$n$非常に特殊なプロパティが保持されるようにする: からいくつかの数字を削除することによって形成できるすべての整数を考慮します。$n$順序を維持しながら、結果として得られるすべての数値のセットを取得します。 このセットから、10 進形式のサブシーケンス値として現れない最小の非負の整数を計算します。 その値は指定されたターゲットと等しくなければなりません$x$。 

このタスクを言い換えると便利な方法は、数値の部分列が抽出できるすべての可能な数字列に対応しており、少なくとも 1 つのそのような数字部分列でどの整数を表現できるかに興味があるということです。 目標は、「欠落している表現可能な整数」（部分列の意味で）が正確に一致する数値を設計することです。$x$。 

の制約$x$これは、構造が数値の大きさベースではなく数字ベースであることを示す最初の信号です。 以来$x$まで持つことができます$10^4$数字に関しては、値の算術特性を扱っているのではなく、数字の存在パターンを扱っていることは明らかです。 サイズの桁が 2 次のものはすべて、入力表現の長さに対してほぼ線形な時間で実行される必要があります。$10^4$それ以上の場合は、一般的な制限内に収まりません。 

微妙な点は、ここでのサブシーケンスの長さに制限がないことです。数字のサブセットはすべて有効であるため、非常に大きな数値も可能です。 これは、複雑な組み合わせによる数字の配置ではなく、どの数字が少なくとも 1 回出現するかによって答えが制御されることを直ちに示唆しています。 

重要なエッジケースの 1 つは、サブシーケンスの先頭のゼロが重要かどうかです。 これらはサブシーケンスの有効性には影響しませんが、セット内に数値が存在するかどうかの数値解釈に影響します。 たとえば、数字「0」と「1」を使用すると、0 と 1 の両方をサブシーケンスとして形成できますが、必要な数字が正しい順序と多重度で存在しない限り、それ以上の数字は形成できません。 

2 番目のエッジ ケースは、「数字としての部分列」と「整数としての部分列」の混同です。 この問題では、サブシーケンスを整数として解釈される数字列として定義します。これは、「01」と「1」が MEX 計算コンテキストでは事実上同じ整数表現であることを意味します。 これらを別の文字列として扱う単純なアプローチでは、カウントが過剰になってしまいます。

公式のソリューションのアイデアで使用される構造は、1 つの特殊な数字を除くすべての数字が確実に存在するようにすることです。$n$。 正確に数字の場合$d$が欠落している場合は、10 進表現に含まれるすべての整数が含まれます。$d$後続としては不可能になります。 その後、MEX はどの桁が除外されるかによって厳密に制御されます。

 ## アルゴリズムのチュートリアル

 1. 入力文字列を変換する$x$含まれる一連の数字に変換されます。 これにより、構築される数値でどの桁を避けなければならないかを推論することができます。 
2. に存在しない数字を選択します。$x$、またはすべての数字が表示されている場合は、次の数字の形成をブロックする数字を選択します。$x$構築数から除外した場合。 このステップにより、次のことが保証されます。$x$サブシーケンスとして形成することはできません。 
3. 構築する$n$数字の連結として$0$を通して$9$、選択した除外された数字をスキップします。 順序は固定されており、すべての小さい桁の組み合わせが構造的に利用可能なままであるため、増加しています。 
4. この構築された数値を文字列として直接出力します。 

この構造で十分である理由は、サブシーケンスは繰り返し構造ではなく、数字が存在するかどうかのみに依存するためです。 1 つを除くすべての数字が存在すると、シーケンス内の適切な位置を選択することで、欠落した数字を回避する任意の整数を形成できます。 

### なぜ効果があるのか

 不変条件は、構築後、除外された数字を除くすべての数字が少なくとも 1 回は出現するということです。$n$。 部分列として表現できる整数は、使用可能な桁のみを使用する必要があるため、除外された桁を含むすべての数値は不可能ですが、それを回避するすべての数値は構成可能です。 MEX は表現不可能な最初の整数として定義されており、除外された数字により次のことが保証されます。$x$がそのような失敗の最初である場合、結果として生じる MEX は次となります。$x$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x = input().strip()

        used = set(x)

        # find a digit to exclude; if possible pick one not in x
        exclude = None
        for d in "0123456789":
            if d not in used:
                exclude = d
                break

        # if all digits appear, exclude '0' (any choice works in construction)
        if exclude is None:
            exclude = "0"

        res = []
        for d in "0123456789":
            if d != exclude:
                res.append(d)

        print("".join(res))

if __name__ == "__main__":
    solve()
```コードは各テスト ケースを個別に処理し、慎重に選択した 1 つの数字を欠いた数字列を構築します。 重要な実装の詳細は、除外の選択を徹底的に最適化する必要がないことです。 有効な欠落数字があれば、正しい MEX 構造が保証されます。 

実装の微妙な点は、すべての数字が次のように表示される場合の処理​​です。$x$。 その場合、任意の数字を除外しても、次のことが保証されます。$x$構築された数値には少なくとも 1 つの必要な数字が欠落しているため、形成できません。 これにより、位置的な推論を必要とせずに、構造が堅牢に保たれます。
