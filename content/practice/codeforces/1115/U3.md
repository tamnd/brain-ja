 ## 解決策
 ## 問題の理解

 量子ユニタリー演算を実装するように求められています。$N$量子ビット、ここで$N$は 2 ～ 5 の小さい値です。演算は で表されます。$2^N \times 2^N$特定のブロック構造を持つマトリックス。 マトリックスは 4 つの四半期として視覚化できます。 

1. 左上 4 分の 1 : サイズの反対角行列$2^{N-1}$つまり、1 は対角線 (右上から左下) にのみ表示され、それ以外の場所には 0 が表示されます。 
2. 右上と左下の 4 分の 1 : すべてゼロ。 
3. 右下の 4 分の 1 : 任意の非ゼロ値 (非常に小さなイプシロンを超える値は非ゼロとみなされます)。 

インデックスはリトルエンディアン表記に従います。最下位量子ビットは行列の最初の列と行に対応します。 これは、マルチ量子ビット ゲートが基底状態にどのようにマッピングされるかに影響します。 

私たちのタスクは、そのような行列を生成する量子演算を実装することです。 正しい実装が複数存在するため、解決策は特定の値ではなく、ブロック パターンを満たすだけで済みます。 

なぜなら$N$が最大 5 の場合、最大の行列は$32 \times 32$、これは一連のゲートを適用するという点で管理可能です。 課題はパフォーマンスではなく、正しい位置にゼロと非ゼロを残しながら、左上の反対角ブロックを生成する量子回路を設計することです。 

明らかではないエッジケースは、小さな問題から発生します。$N$価値観。 たとえば、$N=2$、左上の対角線は単なる$2 \times 2$交換、とても簡単です`SWAP`2 つの量子ビットのゲートで十分です。 しかし、として$N$が増加すると、すべての量子ビットにわたって反対角構造を正しく一般化する必要があります。 

## アプローチ

 ブルートフォースアプローチは、手動でサイズの行列を構築しようとすることです。$2^N$基本的な量子ゲートを使用して、行列を要素ごとに埋めます。 これは技術的には可能ですので、$N \le 5$、でも面倒になります。$N=5$、問題の対称性を利用していません。 マトリックス パターンは予測可能です。左上のブロックは反対角で、他の 4 分の 1 には自明なパターンがあります。 これをコードで手動で記述すると、1024 個のエントリが必要になります。$N=5$。 

重要な洞察は、左上の反対角ブロックは、量子ビットの順序を逆にし、以下を適用することで生成できるということです。`X`(NOT) 条件付きゲート。 概念的には、最初の量子ビットを反転して左上と左下のブロックを交換し、同じ操作を残りの量子ビットに再帰的に適用できます。 実際には、これは次の単純なシーケンスに帰着します。`X`そして`SWAP`ゼロブロックに触れずに反対角パターンを処理する操作。 

小さな量子ビット配列での量子演算は寛容です。 必要な左上の反対角を生成し、そのブロックの外側にゼロを設定しないシーケンスは許容されます。 この観察により、すべてのユーザーに対して機能するコンパクトな再帰的または反復的なソリューションを書くことができます。$N$許容範囲内です。

 | 建設的な量子 | O(N) ゲート | O(1) おまけ | N ≤ 5 で受け入れられ、クリーンでスケーラブルです |

 ## アルゴリズムのチュートリアル

 1. 左上の対角ブロックを特定します。 のために$N$量子ビット、これは$2^{N-1} \times 2^{N-1}$マトリックス。 このブロック内の量子ビットの順序を逆にすると、反対角が生成されます。 これは簡単な方法で実現できます`X`最初の量子ビットにゲートを設定して、上半分と下半分を切り替えます。 
2.次のシーケンスを適用します。`CNOT`ゲートや`SWAP`残りのゲートに反対角を再帰的に実装するゲート$N-1$量子ビット。 量子ビットが追加されるたびに、反対角線のサイズが 2 倍になるため、量子ビットが 1 つ必要になります。`SWAP`再帰内の各ペアのゲート。 
3. 右上と左下の 4 分の 1 はそのままにしておきます。 左上の 4 分の 1 に影響を与える量子ビットのみを操作することで、それらのブロックにゼロが残ることが保証されます。 
4. 右下の 4 分の 1 にゼロ以外の要素を入力します。 量子用語では、次のように適用できます。`X`最初の量子ビットに設定するか、変更しないままにしておきます。 最初の量子ビットを反転して一番下のブロックに到達するシーケンスは、右下の要素がゼロ以外であることを保証し、チェッカーを満足させます。 

機能する理由: この操作は各ブロック内の基底状態を並べ替えるだけであり、反対角の外側のゼロ パターンは維持されます。 反対角パターンは、最初の量子ビットを反転し、残りの量子ビットに再帰的にスワップを適用することで自然に現れます。 右下のブロックにはゼロ以外の任意のエントリを含めることができます。これは、エントリをゼロにすることがないためです。 

## Python ソリューション

 説明のために、古典的な配列を使用して量子演算を模倣する Python スタイルの擬似コードを以下に示します。 実際の Q# ソリューションでは、次のように使用します。`X`、`CNOT`、 そして`SWAP`門。```python
import sys
input = sys.stdin.readline

def solve(n):
    # initialize the matrix with zeros
    size = 1 << n
    mat = [[0]*size for _ in range(size)]
    
    # top-left anti-diagonal
    for i in range(size//2):
        mat[i][(size//2 - 1) - i] = 1
    
    # bottom-right block filled with 1
    for i in range(size//2, size):
        for j in range(size//2, size):
            mat[i][j] = 1
    
    return mat

# demonstration for N=3
N = 3
result = solve(N)
for row in result:
    print(''.join(['X' if x else '.' for x in row]))
```このソリューションでは、ゼロ ブロックとゼロ以外のブロックを考慮して、行列をインプレースで作成します。 Q# では、これは次のようになります。`X`そして`SWAP`ゼロのままであるべき量子ビットに触れずに演算を行うことができます。
