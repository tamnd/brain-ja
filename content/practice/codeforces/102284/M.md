 ## アルゴリズムのチュートリアル

 1.ストア`1`最初のシーケンス要素として。 素因数分解が空であるため、これは有効です。 
2. 各素数に 1 つずつ、計 5 つのポインターを作成します。`2`、`3`、`5`、`7`、 そして`11`。 最初はすべてのポインタが`0`、すべてのジェネレーターが次から始まることを意味します。`1`。 
3. 次のシーケンス位置について、5 つの候補を計算します。`dp[p2] * 2`、`dp[p3] * 3`、`dp[p5] * 5`、`dp[p7] * 7`、 そして`dp[p11] * 11`。 最小の候補は、まだ生成されていない最小の有効な数値です。 
4. その最小値を次の値に追加します`dp`。 すべての候補は有効な数値であり、現在の最後の要素より大きいすべての有効な数値は、以前の有効な数値に 5 つの素数の 1 つを乗じたものとして表すことができるため、最小の候補は次のシーケンス要素でなければなりません。 
5. 候補が新しく生成された値に等しいすべての素数について、そのポインタを 1 つ進めます。 一致するすべてのポインターは移動する必要があります。そうしないと、後の反復で同じ値が再び表示されてしまうからです。 
6. まで続けます`n+k`要素が生成されました。 要求された回答は 0 から始まる位置を占めます`n`を通して`n+k-1`ので、出力します`dp[n:n+k]`。 

重要な不変条件は、生成後の`dp[i]`、配列には最初のものが正確に含まれます`i+1`必要なシーケンスの要素を厳密に昇順に並べます。 許可されるすべての素数について`p`、そのポインタは、積が以下の最初のインデックスを識別します。`p`最後に生成された値よりもまだ大きいです。 したがって、現在の 5 つの積は、5 つの乗算ファミリーすべてからまだカバーされていない最小の候補を表します。 最小値を取る場合、有効な数値をスキップすることはできません。 最小値を生成したすべてのポインターを進めると、重複が防止されます。 帰納法により、生成されたすべての要素は、まさに数学的シーケンスの次の要素になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def get_terms(n, k):
    total = n + k
    primes = (2, 3, 5, 7, 11)

    dp = [1]
    ptr = [0] * 5

    while len(dp) < total:
        candidates = [
            dp[ptr[i]] * primes[i]
            for i in range(5)
        ]

        nxt = min(candidates)
        dp.append(nxt)

        for i in range(5):
            if candidates[i] == nxt:
                ptr[i] += 1

    return dp[n:n + k]

def solve():
    n, k = map(int, input().split())
    print(*get_terms(n, k))

if __name__ == "__main__":
    solve()

最終ループでの等価性チェックは不可欠です。 現在の候補者には次のようなものがあるとします。`6`両方から`2 * 3`そして`3 * 2`。 ポインタが 1 つだけ移動した場合、`6`は他のジェネレーターの候補として残り、再び追加されます。 すべての等しい候補を進めると、消費されたばかりの値のすべての表現が削除されます。 

停止条件は次を使用します`len(dp) < total`、まさにそのとおりです`n+k`シーケンス値が構築されます。 これにより、要求された間隔付近での off-by-one エラーが回避されます。 数列は 1 から始まりますが、Python リストは 0 から始まるので、`a_{n+1}`に対応する`dp[n]`、まさにこれがスライスが で始まる理由です。`n`。 

Python の整数には任意の精度があるため、次の乗算が可能です。`11`オーバーフローすることはできません。 固定幅の整数を使用する言語では、対応する実装では、生成される最大値に十分な大きさの型を使用する必要があります。 

5 つのポインタは前方にのみ移動します。 実行全体にわたって、各ポインタは最大で次の方向に進みます。`n+k`そのため、ポインタのメンテナンスは直線的な作業に貢献します。 生成された要素ごとに 5 つの候補計算が継続的に行われます。

import sys
import io
import heapq

input = sys.stdin.readline

def get_terms(n, k):
    total = n + k
    primes = (2, 3, 5, 7, 11)

    dp = [1]
    ptr = [0] * 5

    while len(dp) < total:
        candidates = [
            dp[ptr[i]] * primes[i]
            for i in range(5)
        ]

        nxt = min(candidates)
        dp.append(nxt)

        for i in range(5):
            if candidates[i] == nxt:
                ptr[i] += 1

    return dp[n:n + k]

def solve():
    n, k = map(int, input().split())
    print(*get_terms(n, k))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    try:
        sys.stdin = io.StringIO(inp)
        sys.stdout = io.StringIO()
        solve()
        return sys.stdout.getvalue().strip()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

def reference_heap(count):
    primes = (2, 3, 5, 7, 11)
    heap = [1]
    seen = {1}
    result = []

    while len(result) < count:
        x = heapq.heappop(heap)
        result.append(x)

        for p in primes:
            y = x * p
            if y not in seen:
                seen.add(y)
                heapq.heappush(heap, y)

    return result
