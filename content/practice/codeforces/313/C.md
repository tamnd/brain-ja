 ## 解決策
 ## 問題の理解

 を構築するように求められています。$2 \times n \times 2 \times n$指定されたリストからの正方行列$4n$再帰的に定義された「美しさ」の尺度が最大化されるような整数。 美しさは、現在の行列の最大要素に、行列を両次元に沿って半分に分割することによって得られる 4 つの象限の美しさの合計を加えたものとして定義されます。 言い換えると、あるサイズの行列の場合、$2^k \times 2^k$、まず行列全体の最大値を取得し、次にそれを 4 つの等しい象限に分割し、それらの美しさを再帰的に計算し、すべてを合計します。 

入力により、次のフラットなリストが得られます。$4n$に入れる必要がある整数$2 \times n$正方行列。 私たちの出力は、達成可能な最大の美しさを表す単一の整数です。 

制約により許可されるのは、$4n$まで$2 \cdot 10^6$これにより、行列への数値のすべての置換を試みるアプローチは即座に除外されます。 すべての配置に対してブルートフォース再帰を行うと階乗的な複雑さが伴いますが、これは実行不可能です。 問題のサイズから、次のものが必要であることがわかります。$O(n \log n)$または$O(n)$アプローチ。 

明らかではないエッジ ケースには、最小の行列が含まれます。$n=1$。 たとえば、数値が次の場合、$1,2,3,4$、不用意に配置すると、再帰的な合計により全体の美しさにまったく寄与しない象限に最大の数値が割り当てられる可能性があります。 トップレベルの美しさに影響を与えるには、分割後の最終マトリックスの境界に最大数が表示される必要があります。そうでない場合は、最大値への寄与が最小限に抑えられます。 

もう 1 つの特殊なケースは、すべての数値が等しい場合です。 どの配置でも同じ美しさを生み出すため、アルゴリズムはこれを適切に処理する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、数値のあらゆる配置を試みます。$2n \times 2n$マトリックスを作成し、それぞれの美しさを再帰的に計算し、最大値を追跡します。 これは正しいですが、次のことが必要です$O((4n)!)$操作は天文学的に遅い$n > 5$。 部分行列にメモ化を使用することさえ不可能です。$\binom{4n}{2n}$各分割の選択肢はまだ多すぎます。 

重要な洞察は、再帰的な美しさの計算は各レベルの最大要素にのみ依存するということです。 のために$2n \times 2n$マトリックスでは、トップレベルの美しさは、マトリックス全体の最大の要素と、分割後の 4 つの象限の最大値の合計によって決まります。 このロジックを繰り返すと、最大のものだけが$n \times n$象限の「十字」エッジに沿った数字が最大限の美しさに貢献します。 問題は最大のものを選択することに帰着します$2n - 1$エッジの各再帰レベルでの数値。 

より簡単なアプローチは、再帰式が行列内の最大数と、最終的な合計に表示される境界に沿った最大数を取得することを単純化することを観察することです。 最大の美しさは、数値を降順に並べ替えた後に形成される行列の 4 つの角の最大値を合計することで計算できます。 

したがって、最適な解決策は、数値を並べ替えて、最終的な行列の 4 隅に沿った象限の最大の数値を選択することです。 残りの数字は内側の部分を埋めますが、美しさに直接影響するものではありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((4n)!) | O(4n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 要素の数を読み取ります。$4n$、および整数のリスト。 
2. もし$n = 1$、行列として単にリスト内の最大数を返します。$2 \times 2$そしてそれぞれの数値が美しさに直接貢献します。 
3. のために$n > 1$、数値の配列を昇順に並べ替えます。 並べ替えることにより、最大の数値を効率的に選択できるようになります。 
4. 最上位の再帰的な美しさに寄与する「エッジ」に到達する 4 つの数値を特定します。 のために$2n \times 2n$行列の場合、これらは、並べ替えられた数値を 2D 行列に配置した後の、最初の行の最後の 2 つの数値と最後の行の最後の 2 つの数値です。 
5. 最大の美しさは、最小値を除くすべての数値の合計です。$(2n-1)^2$最小の数値は、より高いレベルの最大値に影響を与えない部分行列内にのみ表示されるためです。 より簡単な方法は、最大のものを取ることです$2n$最終行と最終列の両方の数値を取得し、二重カウントを避けるために 4 隅の数値の最小値を取得します。 
6. 計算された最大の美しさを返します。 

これが機能する理由: すべての再帰ステップで、美しさは現在の部分行列の最大数に依存します。 外側の象限に沿って最大の数値を並べ替えて配置することで、再帰のすべてのレベルで可能な限り最大の値が追加されるようにします。 不変条件は、再帰的な分割のたびに、部分行列の最大数が既に選択された最大数の中に含まれており、美しさの合計が最大化されることを保証することです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    arr = list(map(int, input().split()))
    
    if n == 1:
        print(max(arr))
        return
    
    arr.sort()
    
    # The size of the original matrix
    size = 2 * n
    # Pick the four corners after arranging in matrix form
    # The maximum beauty is the sum of all numbers except the smallest (size-1)^2 numbers
    # Which is equivalent to sum of the largest (size-1)*2 numbers in last row/column
    ans = arr[-n] + arr[-n-1] + arr[-1] + arr[-2]
    
    # Actually, in the problem we only need to consider 2 largest numbers from each of the last row/column
    # But simpler way: maximum beauty is sum of all numbers except the smallest (2*n-1)^2 numbers
    total = sum(arr)
    min_inside = arr[0:(size-1)*(size-1)]
    ans = total - sum(min_inside)
    
    print(ans)

if __name__ == "__main__":
    main()
```ソリューションは最初に、$n = 1$基本ケースを直接。 より大きな行列の場合、ソートにより、ビューティサムに重要な数値を直接選択できます。 重要なステップは、実際に美しさに影響を与える数値、つまりエッジとコーナーの最大の数値を特定することです。 最小の内数値の合計を減算することで、不要な数値が含まれないようにします。
