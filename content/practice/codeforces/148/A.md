 ## 解決策
 ## 問題の理解

 この問題は、自分自身を守る独自の方法を持つ王女によって何匹のドラゴンが影響を受けるかを把握することを求めています。 彼女は、_k_ 番目、_l_ 番目、_m_ 番目、_n_ 番目のドラゴンをそれぞれ異なるアクションでターゲットにします。 ドラゴンの総数は _d_ です。 入力により、_k_、_l_、_m_、_n_、_d_ の 5 つの整数が得られます。 出力は、これらのアクションの少なくとも 1 つによって攻撃されたドラゴンの数を表す単一の整数です。 

重要な観察は、ドラゴンは複数回影響を受ける可能性があるが、それを数えているのは 1 回だけであるということです。 たとえば、ドラゴンが 6 番目のドラゴン (2 番目のアクションの影響を受ける) と 12 番目のドラゴン (3 番目のアクションの影響を受ける) の両方である場合でも、ダメージを受けた 1 匹のドラゴンとしてカウントされます。 課題は、すべてのドラゴンの間でこれらの固有のインデックスを効率的にカウントすることです。 

制約は中程度です。 ドラゴンの最大数 _d_ は 10^5 にすることができ、これにより、単純なループですべてのドラゴンを反復処理できます。 約数 _k_、_l_、_m_、_n_ はすべて ≤10 であるため、ドラゴン インデックスがこれらの数値で割り切れるかどうかを確認するのは低コストです。 考慮すべきエッジケースには、最小の _d_ が 1 であること、または約数が 1 であることが含まれており、これはすべてのドラゴンに影響します。 単純なソリューションでは、すべての約数が 1 であるエッジ ケースを見逃す可能性があり、_d_ 自体を返す必要があります。 

## アプローチ

 ブルートフォースの解決策は簡単です。 1 から _d_ までのすべてのドラゴンを反復処理し、インデックスが _k_、_l_、_m_、または _n_ で割り切れるかどうかを確認できます。 そうであれば、カウンターをインクリメントします。 これが機能するのは、_d_ が 10^5 のみであるため、反復ごとに最大 4 つのモジュロ演算を含む単純なループでは、合計 4 × 10^5 の演算となり、2 秒の制限時間内で許容されます。 この問題は基本的に反復範囲が十分に小さい計数問題であるため、総当たりアプローチは機能しますが、数式ベースのアプローチと比較すると洗練されていないように感じるかもしれません。 

最適なアプローチでは、包含-除外の原理を使用して、任意の数値で割り切れるすべてのドラゴンを数えます。 _k_ で割り切れるドラゴンを数え、次に _l_ で割り切れるドラゴンを数えます。ただし、重複の数を減算し、3 倍の重複を追加し、4 倍の重複を減算します。 これを可能にする観察は、これらの数値が小さく、その倍数が規則的に繰り返されるため、反復せずに数値を数学的に計算できるということです。 この規模の問題の場合、ブルート フォースは十分効率的で、実装と推論が容易であるため、パフォーマンスを心配することなくブルート フォースを使い続けることができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(d) | お(1) | 承認済み |
 | 包含-除外 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数 _k_、_l_、_m_、_n_、および _d_ を読み取ります。 これらは攻撃頻度とドラゴンの総数を表します。 
2. カウンタの初期化`damaged`ゼロに。 これにより、影響を受けるドラゴンの数が追跡されます。 
3. 1 から _d_ までのすべてのドラゴン インデックスをループします。 各ドラゴンについて:

 1. インデックスが _k_、_l_、_m_、または _n_ で割り切れるかどうかを確認します。 これらの条件のいずれかが当てはまれば、増分します`damaged`。 
4. ループ後、次の値を出力します。`damaged`。 

機能する理由: すべてのドラゴンが 1 回だけ考慮され、攻撃されるための 4 つの条件がすべてチェックされます。 少なくとも 1 つの数字で割り切れるドラゴンはすべてカウントされますが、複数の数字で割り切れるドラゴンは 1 回だけカウントされます。 これにより、二重にカウントすることなく正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

k = int(input())
l = int(input())
m = int(input())
n = int(input())
d = int(input())

damaged = 0
for i in range(1, d + 1):
    if i % k == 0 or i % l == 0 or i % m == 0 or i % n == 0:
        damaged += 1

print(damaged)
```コードはアルゴリズムに直接続きます。 それぞれ`input()`単一の整数を読み取ります。 ループは 1 から`d`包括的、モジュロで割り算をチェックします。 使用する`or`複数のアクションの影響を受けたドラゴンが 1 回だけカウントされるようにします。 決勝戦`print`正しいカウントを出力します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    k = int(input())
    l = int(input())
    m = int(input())
    n = int(input())
    d = int(input())

    damaged = 0
    for i in range(1, d + 1):
        if i % k == 0 or i % l == 0 or i % m == 0 or i % n == 0:
            damaged += 1
    return str(damaged)

# Provided samples
assert run("1\n2\n3\n4\n12\n") == "12", "sample 1"
assert run("2\n3\n4\n5\n12\n") == "9", "sample 2"

# Custom cases
assert run("1\n1\n1\n1\n1\n") == "1", "minimum d"
assert run("10\n10\n10\n10\n100000\n") == "10000", "maximum d with large k,l,m,n"
assert run("2\n2\n2\n2\n7\n") == "3", "all equal divisors, small d"
assert run("2\n3\n5\n7\n30\n") == "20", "combination of primes"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 1 1 1 1 | 1 | 最小 d、すべてのドラゴンが影響を受ける |
 | 10 10 10 10 100000 | 10000 | 大きな約数を持つ大きな d |
 | 2 2 2 2 7 | 3 | 等しい約数、小さい d、off-by-one の処理 |
 | 2 3 5 7 30 | 20 | 混合素数、倍数を正しく数える |

 ## 特殊なケース

 k=l=m=n=1 および d=1 の場合、ドラゴンのみが影響を受け、モジュロ チェックがトリガーされるため、コードは正しく 1 を返します。 約数がすべて 10 で d=100000 の場合、ダメージ数は 100000 を 10 で割って 10000 になります。一部の約数が d より大きい場合、たとえば k=50 や d=30 の場合、i%50==0 を満たすドラゴンは存在しないため、ループは二重カウントやエラーを発生させることなくこれらを正しく無視します。
