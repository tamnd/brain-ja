 ## 解決策
 ## 問題の理解

 整数グリッド上に同じ数の点を持つ 2 つの構成が与えられています。 これらは、格子点上に配置された区別できない粒子の 2 つの図であると考えてください。 粒子は移動できますが、それは非常に特殊な集団操作によってのみ可能です。 

1 回の操作で、単一のパーティクルを選択し、4 つの基本的な方向の 1 つを選択します。 選択したパーティクルはその方向に 1 ステップ移動し、他のすべてのパーティクルは同時に反対方向に 1 ステップ移動します。 各移動の後、2 つのパーティクルが同じセルを占有することはできません。 

問題は、最後に画像全体の全体的なシフトを適用することもでき、どの粒子がどのラベルに対応するかを気にしない場合、一連のこのような動きの後に、初期構成がターゲット構成になることが可能かどうかです。 

n が 100000 までの制約により、あらゆる解が線形または線形演算に近くなるように強制されます。 n の 2 乗は 10^10 の演算に相当するため、ペアごとの比較、移動のシミュレーション、またはポイント間のグラフ マッチングを伴うものはすべて、すぐに遅くなりすぎます。 

微妙な難点は、この操作ですべてのポイントが一度に結合されることです。 素朴な解釈では、座標を個別に追跡することを示唆するかもしれませんが、すべての動きはすべてのポイントを同時に変更するため、局所的な推論は誤解を招きます。 

2 番目の隠れた問題は、ポイントの同一性が無関係であることです。 i 番目の初期点を i 番目のターゲット点に一致させようとする解法は、同一の構造の順列では失敗します。 

## アプローチ

 直接的な総当りアプローチでは、考えられるすべての一連の動きをシミュレートします。 各状態は n 個のポイントの完全な構成であり、各移動は方向の 4 つの選択肢と、移動を「導く」ポイントの n 個の選択肢に分岐します。 これにより、膨大な状態グラフが生成され、分岐を無視しても、個別の構成の数は移動の数で指数関数的に増加します。 これは、n が非常に小さい場合でもすぐに管理できなくなります。 

重要な観察は、各移動が非常に構造化された効果を持っているということです。つまり、1 つの点が v 方向に移動し、他のすべての点が反対方向に移動します。 これは、-v によるすべてのポイントのグローバル変換と、選択したポイントにのみ適用される追加の 2v として書き直すことができます。 最終的な答えでは任意の変換が許可されるため、構成を比較するときにグローバル シフト コンポーネントを無視できます。 残るのは、移動するたびに ±2e_x または ±2e_y の形式のベクトルが単一の選択された点に効果的に追加される一方で、移動まで他のすべては維持されるということです。 

これは、情報モジュロ 2 のみが重要であることを直ちに示唆しています。 更新のたびに、すべてのポイントの座標が ±1 ずつ変更されます。これは、すべての座標パリティが同時に反転することを意味します。 したがって、絶対位置は複雑な方法で変化しますが、ポイントが 4 つのパリティ クラスにどのように配置されるかの構造は、非常に限定された方法で進化します。つまり、パリティのグローバル XOR シフトのみが行われます。 

これにより、問題は幾何学的問題から 4 つのパリティ クラスにわたる計数問題に縮小されます。

 ## アルゴリズムのチュートリアル

 すべてのポイントをそのパリティ クラスに変換します。つまり、(x mod 2, y mod 2) のみを保存します。 考えられるクラスは正確に 4 つあります。 

次に、すべての操作がパリティ空間内のすべての点の両方の座標を同時に反転するという事実を利用します。これは、すべてのパリティ クラスを同じ固定 2 ビット ベクトルで XOR 演算することに相当します。

1. すべての初期点のパリティ クラスを計算し、4 つのクラスのそれぞれに分類される点の数を数えます。 これにより、4 次元の周波数ベクトルが得られます。 
2. ターゲット構成に対しても同じことを行います。 
3. 考えられる 4 つのグローバル パリティ シフトをすべて試します。 シフトは、{0,1}² の固定 (dx, dy) によるすべての初期点の両方の座標の XOR 演算に対応します。 
4. シフトごとに、初期パリティ分布が適用後にどのようになるかを再計算します。 
5. 初期パリティ カウントのシフトされたバージョンがターゲット パリティ カウントと正確に一致する場合、答えは可能です。 
6. そうしないと、一連の操作で一方の構成をもう一方の構成に変換できません。 

これが機能する唯一の理由は、この操作ではポイント間の相対的なパリティ構造を作成したり破壊したりすることができず、すべてを一貫して反転するか、ペアごとのパリティ関係を維持するだけであるためです。 

### なぜ効果があるのか

 すべての動きは、すべての点のすべての座標のパリティを反転します。 したがって、任意の回数の移動の後、すべての点はパリティ空間内の同じグローバル XOR によって変換され、場合によってはラベルの順列と組み合わせられます。 これは、唯一の不変情報が、グローバル シフトまでの Z₂ × Z₂ の点の複数セットであることを意味します。 最終的な回答では変換が許可されているため、パリティ クラス間の相対的な分布のみが重要となり、その分布は XOR まで正確に保持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    init = [tuple(map(int, input().split())) for _ in range(n)]
    targ = [tuple(map(int, input().split())) for _ in range(n)]
    
    def build(points):
        cnt = [[0, 0], [0, 0]]
        for x, y in points:
            cnt[x & 1][y & 1] += 1
        return cnt
    
    A = build(init)
    B = build(targ)
    
    for dx in (0, 1):
        for dy in (0, 1):
            ok = True
            for i in range(2):
                for j in range(2):
                    if A[i ^ dx][j ^ dy] != B[i][j]:
                        ok = False
            if ok:
                print("YES")
                return
    
    print("NO")

if __name__ == "__main__":
    solve()
```このソリューションでは、各ポイントを 4 つのパリティ バケットのいずれかに圧縮します。 機能`build`この 2x2 頻度テーブルを作成します。 次に、4 つの可能性すべてを試して、重要な唯一の影響であるパリティ空間におけるグローバル XOR シフトをシミュレートします。 

入れ子になったループ`dx`そして`dy`初期パリティ分布をターゲット分布と正確に一致させるシフトが存在するかどうかをテストします。 n は大きくなる可能性があるため、その他はすべて線形です。 

よくある間違いは、ソートされた座標を直接照合しようとしたり、実際の変位を追跡しようとしたりすることです。 これらのアプローチは、操作がすべてのポイントをグローバルにエンタングルするという事実を無視しますが、パリティはそのエンタングルから生き残ったものを正確に分離します。 

## 実用的な例

 3 つのポイントがある小さなケースを考えてみましょう。 

初期値: (0,0)、(0,1)、(1,0)

 ターゲット: 同じ構造のシフトされたバージョン

 パリティ数を計算します。 

| 点セット | (0,0) | (0,1) | (1,0) | (1,1) |
 | --- | --- | --- | --- | --- |
 | イニシャル | 1 | 1 | 1 | 0 |
 | ターゲット | 1 | 1 | 1 | 0 |

 すべてのシフトを試行するとマルチセットが同一に保たれるため、アルゴリズムは受け入れます。 

ここで不一致について考えてみましょう。 

初期値: (0,0)、(1,1)、(2,2)

 ターゲット: (0,0)、(0,0)、(1,1)

 パリティ数は根本的に異なります。 

| 点セット | (0,0) | (0,1) | (1,0) | (1,1) |
 | --- | --- | --- | --- | --- |
 | イニシャル | 3 | 0 | 0 | 0 |
 | ターゲット | 1 | 0 | 0 | 2 |

 XOR シフトはこれらの分布を調整できないため、アルゴリズムは拒否します。 

2 番目のケースは、幾何学的形状や距離ではなく、パリティ質量分布が真の不変量であることを示しています。

 ## 特殊なケース

 n が 1 に等しい場合、単一の点は繰り返しの移動によって任意に移動できるため、すべての構成は同等になります。 初期パリティ テーブルとターゲット パリティ テーブルの両方に単一の非ゼロ エントリがあり、一致するシフトが常に存在するため、アルゴリズムはこれを自然に処理します。 

すべてのポイントが同じパリティ クラスにある場合、構造は単一のバケットに崩壊します。 4 つのバケットのいずれかに同じカウントを保持するターゲット構成は、対応するシフト後に受け入れられ、アルゴリズムは 4 つのシフトすべてを明示的にチェックします。 

分布が大きく偏っている場合、たとえば、あるクラスに n−1 点、別のクラスに 1 点がある場合、シフト チェックにより不均衡パターンが正確に保存されることが保証されます。 許可されたすべての操作ではパリティ数が不変であるため、ジオメトリを介して不一致を「隠す」試みは失敗します。
