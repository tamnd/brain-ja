 ## 問題の理解

 このタスクでは、有効なセキュリティ キーとして機能する一連の正の整数を作成するように求められます。 所定の長さの場合`n`、印刷する必要があります`n`すべての数値を加算して得られる合計値が、すべての数値を掛け合わせて得られる値とまったく同じである数値。 すべての数値は正以下でなければなりません`10^9`。 裁判官は、1 つの特定の答えではなく、方程式を満たす任意のシーケンスを受け入れます。 

入力には、いくつかの独立したリクエストが含まれています。 各リクエストはシーケンスの必要な長さのみを提供し、出力には長さごとに 1 つの有効なシーケンスが含まれている必要があります。 要求されたすべての長さの合計は数百万に達する可能性があるため、ソリューションは生成される数ごとに一定の時間のみを費やす必要があります。 可能な値を検索したり、多くの組み合わせを試したりするアプローチは、すぐに不可能になってしまいます。 

重要な問題はシーケンスをチェックしないことですが、それは簡単です。 難しいのはそれを構築することです。 単純な考えでは、小さな数値のセットを構築し、和と積が一致するまでそれらを調整しようとするかもしれませんが、単一の大きな数値であっても、`n`、検索スペースは膨大です。 制約は、答えを直接生成する数学的パターンを見つける方向に私たちを後押しします。 

いくつかの特殊なケースでは、一般的なパターンのみを考慮した実装が壊れる可能性があります。 のために`n = 1`、答えは、スペースがないため、2 つの特殊な数値を使用した構文を使用できません。 正しい入力と出力は次のとおりです。```
Input:
1

Output:
1
```単一の数値はそれ自体の合計と積の両方に等しくなければなりません。`1`動作します。 

もう一つの重要な事例は、`n = 2`。 不用意に実装すると、印刷しようとする可能性があります。`[2, n]`あらゆる人にとって`n`、しかしここではそれがなります`[2, 2]`、それはたまたま機能します。 チェック内容は次のとおりです。```
Input:
2

Output:
2 2
```合計は`4`そしてその製品もまた`4`。 

値が大きい場合は、値の配置が重要になります。 たとえば、`n = 5`、印刷`[1, 2, 3, 4, 5]`妥当に見えますが、合計が以下であるため失敗します。`15`そしてその製品は`120`。 正しい構造では次のようになります。```
Input:
5

Output:
1 1 1 2 5
```合計は`10`そしてその製品は`10`。 

## アプローチ

 ブルートフォース ソリューションでは、数値を推測し、その合計が積に等しいかどうかをテストしようとします。 候補者を確認するのは簡単です`O(n)`, しかし、問題は候補者を見つけることです。 すべての位置に対してある限界までの値を試した場合、可能性の数は次のように指数関数的に増加します。`n`。 合計出力サイズが数百万の数値に達すると、テスト ケースごとの小さな検索でも遅すぎます。 

問題を解決する観察は、次のことを乗算することです。`1`追加中は何もしません`1`合計が1増えるだけです。 これは、和と積の差を制御するために多くの値を自由に追加できることを意味します。 

のために`n >= 2`、配置を検討してください`n - 2`1 つを選択し、残りの 2 つの数字を選択します。 これら 2 つの数字を次のようにします`x`そして`y`。 商品は単純に、`xy`全部消えてしまうから。 合計は次のとおりです。`(n - 2) + x + y`必要なものは次のとおりです。`xy = (n - 2) + x + y`並べ替えると次のようになります。`xy - x - y = n - 2`便利な形式で両側に 1 つを追加します。`(x - 1)(y - 1) = n - 1`非常に単純な因数分解が可能です。`1 * (n - 1) = n - 1`。 つまり、選択できるということです`x = 2`そして`y = n`。 シーケンスは次のようになります。`1, 1, ..., 1, 2, n`今の製品は、`2n`。 合計は`(n - 2) + 2 + n = 2n`したがって、方程式は常に成り立ちます。

 ## アルゴリズムのチュートリアル

 1.長さを読み取ります`n`必要なシーケンスの。 

もし`n`は`1`、出力`1`すぐに。 単一の値が満たさなければなりません`a = a`、 それで`1`が唯一可能な選択肢です。 

1. もし`n`少なくとも`2`を含むシーケンスを作成します。`n - 2`のコピー`1`。 

これらの値は積を変更せず、挿入された値ごとに合計をちょうど 1 ずつ増やすことができるため便利です。 

1. 残りの 2 つの値を追加します`2`そして`n`。 

製品は、`2 * n`。 合計は、1 の数にこれら 2 つの値を加えたものになります。`(n - 2) + 2 + n = 2n`。 

1. 構築されたシーケンスを印刷します。 

この構造では正の整数のみが使用され、最大値は次のとおりです。`n`、これは必要な制限内です。 

なぜ機能するのか: 不変条件は、挿入されたすべてのものが`1`積を変更せずに合計を 1 増やします。 必要な値をすべて加算した後、積が新しい合計と正確に一致するように、2 つの最終値が選択されます。 等価性は試行錯誤によって見つかるのではなく、代数恒等式によって保証されます。`(2 - 1)(n - 1) = n - 1`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())

        if n == 1:
            ans.append("1")
        else:
            ans.append(" ".join(["1"] * (n - 2) + ["2", str(n)]))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```コードは例外的な長さのみを処理します。`n = 1`、別途。 他のすべてのケースでは、1 のリストが作成され、その構造から 2 つの特別な値が付加されます。 

表現`["1"] * (n - 2)`必要な数のニュートラル要素を正確に作成します。 最後の 2 つの値は変換後に追加されます。`n`出力はテキストとしてアセンブルされるため、文字列に変換されます。 Python の整数には任意の精度があるため、オーバーフローの心配はありません。 

作業の合計量は、出力の合計サイズに比例します。 これは、すべての合計の要件に一致します。`n`値は大きくなる可能性があります。

## 特殊なケース

 のために`n = 1`、アルゴリズムは決して作成しようとしません`n - 2`それはマイナスになるからです。 直接返却します`1`、和と積が両方とも 1 であるため、条件を満たします。 

のために`n = 2`、アルゴリズムはゼロの 1 を作成し、追加するだけです`2`そして`n`。 シーケンスは次のようになります`2 2`。 製品は`4`そしてその合計は`4`したがって、境界ケースは追加のロジックなしでカバーされます。 

のために`n = 5`、アルゴリズムは 3 つの 1 を作成し、追加します。`2`そして`5`。 合計の計算は`1 + 1 + 1 + 2 + 5 = 10`、製品が`1 * 1 * 1 * 2 * 5 = 10`。 これは、1 の数が正確でなければならない理由を示しています。`n - 2`。
