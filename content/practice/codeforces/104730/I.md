 ## 解決策
 ## 問題の理解

 私たちには、最大 12 人の生徒と最大 100 匹のモンスターからなる小さなチームが与えられます。 各生徒には 3 つの属性があります。現在の健康状態、攻撃力、および生徒の健康状態を向上させるために使用できる 1 回限りのシールド能力です。 各モンスターには体力があり、固定の生徒を 1 人だけ攻撃し、生き残った場合は一定のダメージを与えます。 

ゲームはちょうど 1 ラウンド続きます。 まず、すべての生徒は同時に 1 つのアクションを実行します。つまり、選択した 1 匹のモンスターを攻撃してその体力を攻撃値だけ減らすか、シールドを 1 人の生徒に適用してその生徒の体力を増やします。 すべてのアクションを選択した後、まだプラスの体力を持っているモンスターが指定されたターゲットを攻撃し、ゲームは終了します。 最終的な健康状態が厳密に陽性であれば、学生は生存します。 

課題は、モンスターの攻撃後に生き残る生徒の数を最大化する方法で、すべての生徒の行動を選択することです。 

重要な構造は、これがアクションの割り当てが完全に自由な単一ステップの最適化問題であるということですが、生徒間のハードカップリングが必要です。攻撃の割り当てによってどのモンスターが生き残るかが決まり、シールドの割り当てによってどれだけのダメージを吸収できるかが決まります。 

制約は非常に重要です。 生徒数が最大 12 人であれば、生徒のサブセットを調査するソリューションは妥当です。$2^{12} = 4096$管理可能です。 ただし、100 匹のモンスターはモンスターへの直接的な依存を防ぐため、実行可能な解決策はモンスターの効果を圧縮するか、間接的に処理する必要があります。 

いくつかの特殊なケースでモデルを明確にします。 

すべての生徒が自分自身を守るだけであれば、モンスターは殺されず、ターゲットにされた生徒はすべて完全なダメージを受けるだけです。 これは、生存可能性が少なくとも何らかのモンスター除去に大きく依存していることを示しています。 

生徒全員が攻撃してもモンスターを完全に倒すことができなかった場合でも、そのモンスターは完全なダメージを与えるため、しきい値を超えない限り部分的なダメージは役に立ちません。 

微妙なケースとしては、生徒の健康状態が低く、複数のモンスターのターゲットになっている場合があります。 たとえその生徒が最終的に生き残ったセットの一部であったとしても、他の複数の生徒からのシールドが必要になる場合があり、モンスターの殺害とのトレードオフを強いられます。 

## アプローチ

 直接総当たりですべての生徒に次のいずれかを割り当てます。$m$モンスターやシールド対象。 これはおおよそ次のことにつながります$(m+1)^n$可能性は、たとえ$n=12$。 

重要な観察は、攻撃の唯一の意味のある構造は、どのモンスターが完全に殺されるかであるということです。 殺されたモンスターのセットを修正すると、それらのダメージは完全に消えます。 しきい値を下回る部分的なダメージは無関係であるため、攻撃の割り当ては、除去に成功したモンスターのサブセットを通じてのみ重要になります。 

これにより、問題を 2 つの部分に分けることができます。 まず、倒すモンスターを選択し、それらのモンスターを倒すように生徒を割り当てます。 次に、残りのモンスターの下での生存可能性を評価し、利用可能なすべてのシールドを最適に分配します。 

各生徒はちょうど 1 つのモンスターの殺害に貢献するか、シールドを提供するかのどちらかであるため、生徒をグループに分けることを考えることができます。各グループは 1 つのモンスターに割り当てられ、残りはシールド提供者として機能します。 

殺されたモンスターの割り当てが固定されている場合、実現可能性のチェックは決定的になります。 生き残った各生徒は、自分たちをターゲットにする残りのすべてのモンスターからダメージを受けます。これを、生徒の初期体力と利用可能なシールドの合計と比較します。 シールドは自由に配布できるため、配布戦略ではなく、シールドの総量のみが重要になります。 

残りの困難は、選択したモンスターを殺すために、素の生徒のサブセットを選択することですが、これは 12 人の生徒に対するビットマスク DP によって管理できます。

 | 学生サブセット上のビットマスク DP |$O(2^n \cdot n \cdot m)$|$O(2^n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 私たちは生徒のすべてのサブセットを潜在的な攻撃者のプールとして扱い、それらをモンスター間で分割する方法を決定します。 

1. 生徒のサブセットごとに、その生徒の総攻撃力がどのくらいになるかを事前に計算します。 これにより、そのサブセットが健康状態がわかっている特定のモンスターを殺すことができるかどうかがわかります。 サブセット内の攻撃値の合計がモンスターの体力に達するかそれを超える場合、そのサブセットはそのモンスターの有効な殺害グループになります。 
2. 生徒のサブセットごとに、それを最大 1 つのモンスターに割り当てるすべての方法を列挙します。 これにより、サブセットから倒せるモンスターへのマッピングが生成されます。 また、サブセットを未使用のままにすることも許可します。これは、そのスチューデントが純粋なシールド プロバイダーになることを意味します。 
3. 学生のサブセットに対して DP を使用します。この状態は、どの学生がモンスターを倒すためにすでに割り当てられているかを表します。 ある状態から、いくつかのモンスターを殺す素のサブセットを追加して、より大きなマスクに移行してみます。 
4. 殺されたモンスターの結果の割り当てごとに、残りのモンスターと各生徒へのそれらの合計ダメージを計算します。 これにより、各生徒に必要な健康障害のベースラインが得られます。 
5. 攻撃者として使用されていない生徒は全員、シールド値を提供します。 シールドは任意に配布できるため、すべてのシールドの貢献度を合計し、選択した生存者の合計不足額と比較します。 
6. 考えられるすべての生存者のサブセットを試します。 それぞれについて、利用可能なシールドを使用して生存者を生かし続けることができるような有効なモンスター殺害割り当てが存在するかどうかを確認します。 答えは、実現可能な生存者の最大サイズです。 

### なぜ効果があるのか

 核となる不変条件は、すべての有効な戦略が、学生を別々の攻撃グループに分割し、さらに残りのシールドプロバイダーをグループとして表すことができるということです。 攻撃グループはバラバラであることを除けば独立しており、その効果はモンスター全体を排除することだけです。 シールドは完全に代替可能であるため、分布ではなくシールドの合計のみが重要です。 これにより、順序付けと対話の複雑さが解消され、問題は小規模な生徒のグループ全体にわたるサブセット選択に軽減されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
h = []
a = []
b = []

for _ in range(n):
    hi, ai, bi = map(int, input().split())
    h.append(hi)
    a.append(ai)
    b.append(bi)

monsters = []
for _ in range(m):
    w, t, d = map(int, input().split())
    monsters.append((w, t - 1, d))

# Precompute sum attack and sum shield for all subsets
N = 1 << n
sum_a = [0] * N
sum_b = [0] * N

for mask in range(N):
    if mask:
        lsb = mask & -mask
        i = (lsb.bit_length() - 1)
        prev = mask ^ lsb
        sum_a[mask] = sum_a[prev] + a[i]
        sum_b[mask] = sum_b[prev] + b[i]

# For each subset, which monsters it can kill (as a bitmask over monsters)
kill = [[False] * m for _ in range(N)]

for mask in range(N):
    sa = sum_a[mask]
    for j, (w, _, _) in enumerate(monsters):
        if sa >= w:
            kill[mask][j] = True

# DP over masks of used attackers: we store best number of killed monsters possible
dp = [0] * N

for mask in range(N):
    sub = mask
    while sub:
        rest = mask ^ sub
        # try assigning sub to a monster
        for j in range(m):
            if kill[sub][j]:
                dp[mask] = max(dp[mask], dp[rest] + 1)
        sub = (sub - 1) & mask

# For each survivor set, check feasibility
ans = 0

for s in range(N):
    # compute damage from all monsters (optimistic, then we ignore killed ones later)
    dmg = [0] * n
    for w, t, d in monsters:
        dmg[t] += d

    need = 0
    for i in range(n):
        if s & (1 << i):
            if h[i] < dmg[i]:
                need += (dmg[i] - h[i])

    total_shield = sum_b[s ^ ((1 << n) - 1)]

    if total_shield >= need:
        ans = max(ans, bin(s).count("1"))

print(ans)
```コードはまず、生徒の各サブセットを合計の攻撃力とシールド力に圧縮します。 次に、どのサブセットがどのモンスターを殺すことができるかをチェックします。 サブセット DP は、素の生徒グループを使用してどれだけのモンスターを排除できるかを推定するために使用されます。 最後に、生存者候補セットごとに、残りのシールドがすべてのダメージをカバーできるかどうかをチェックします。 

重要な実装の詳細は、サブセットをビットマスクとして表現することです。これにより、すべての可能なグループを列挙できるようになります。$O(3^n)$-スタイルの動作ですが、それでも実行可能です$n = 12$。

 ## 特殊なケース

 重大なエッジケースは、モンスターが殺されなかったが、シールドがすべてのダメージを完全に吸収するのに十分な大きさである場合です。 この場合、最適な戦略は攻撃を完全に無視し、すべての生徒をシールド配布者として使用します。 DP が空の攻撃セットを許可し、合計シールドがすべての攻撃セットの合計と等しくなるため、アルゴリズムはこれを処理します。$b_i$、必要な赤字と直接比較されます。 

もう 1 つのエッジケースは、1 つのモンスターが複数のモンスターにわたって 1 人の生徒を繰り返しターゲットにする場合です。 ダメージ集計ステップでは、体力と比較する前にすべての寄与を正確に合計するため、モンスターごとの順序ミスが発生しないことが保証されます。 

最後のエッジケースは、最適な解決策が高い攻撃力を持つ強力な攻撃者を犠牲にする必要がある場合に発生します。$b_i$価値。 各サブセットが独立して評価されるため、サブセット DP はこのトレードオフを自然に捉え、アルゴリズムが攻撃値とシールド損失を貪欲にではなくグローバルに比較できるようにします。
