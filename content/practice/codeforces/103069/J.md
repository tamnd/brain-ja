 ## 問題の理解

 反時計回りの順序で頂点によって記述される凸多角形が与えられます。 この多角形を平面上の剛体形状と考えてください。 半径も修正します$r$。 ここで、半径の円を配置することを想像します。$r$中心を選択することで平面内のどこでも$p$。 センター$p$対応する円が多角形全体を完全にカバーする場合、有効とみなされます。 

各テスト ケースのタスクは、そのような中心を 1 つ見つけることではなく、すべての有効な中心によって形成される幾何学的領域を計算することです。 この領域は次のように表されます$S$。 出力は次の面積です。$S$、考えられるすべての円の中心のセットの大きさを意味します。 

幾何学的には、多角形の各頂点には制約が課せられます。中心は距離以内になければなりません。$r$ただし、形状が凸状であるため、厳しい制約は任意の点ではなくエッジから発生します。 これにより、問題は、多角形によって引き起こされる幾何学的領域の交差を理解することに変わります。 

テスト ケースごとの制約は小さく、$n \le 1000$、ただし、合計は$n$テスト全体で到達できる$2 \cdot 10^5$。 これにより、素朴に繰り返された場合、テスト ケースごとの二次関数が排除され、エッジごとの幾何学的処理、または問題を少数の構造化領域の交差に限定する定式化に進むことになります。 

ポリゴンが点またはセグメントに縮退すると、微妙なエッジ ケースが発生します。 いつ$n = 1$、有効な中心は距離内のすべての点です$r$その時点で円盤が形成されます。 いつ$n = 2$、領域は 2 つの半径のストリップの交点になります。$r$ただし、最終的な形状は依然として境界があり、セグメントの長さに依存します。$r$。 どのアプローチでも、ポリゴンのみの仮定に依存せずに、これらの縮退を処理する必要があります。 

候補中心をサンプリングしたり、平面を離散化しようとする単純な実装は、領域の境界が湾曲しており、円の制約に継続的に依存するため、すぐに失敗します。 円を直接交差させようとしても、ペアごとの円弧の処理により、二次関数またはさらに悪い動作が発生します。 

## アプローチ

 条件「を中心とする円」$p$半径の$r$「多角形をカバーします」は、多角形のすべての点がその円の内側にあることを要求するのと同じです。多角形は凸状であるため、この条件をその境界に適用するだけで十分であり、さらに、その条件をそのエッジに適用するだけで十分です。固定エッジ セグメントの場合$AB$、条件は両方のエンドポイントが距離内にある必要があるということになります。$r$から$p$しかし、より厳密には、セグメント全体がディスク内に存在する必要があります。 

標準的な幾何学的再定式化では、これを半径の円板の交点として表現します。$r$多角形の各点の中心に配置されます。 ただし、無限に多くのディスクを交差させることは現実的ではありません。 重要な単純化は、凸多角形の場合、多角形のすべての点までの距離が最大で次の点の集合であるということです。$r$は、ミンコフスキー和によって定義される半平面の交差に相当し、二重の視点につながります。 

主平面で作業する代わりに、有効な中心のセットがまさに半径の円盤による凸多角形のミンコフスキー浸食であることが観察されます。$r$。 同等に、多角形までの距離が少なくとも次の点の集合です。$r$逆の意味ですが、より便利には、距離だけ内側にオフセットされた半平面の交点です。$r$各エッジに沿って垂直にします。 

これは問題を、各エッジを内側に距離だけシフトすることによって得られる凸多角形の面積を計算する問題に変換します。$r$そして、結果として得られるすべての半平面と交差します。 結果として得られる形状は依然として凸状であり、その境界は直線エッジと、オフセット操作によって丸い角が作成される場合の頂点の円弧によって形成されます。 したがって、地域$S$は、オフセット ポリゴンとも呼ばれる、丸みを帯びたポリゴンです。 

ブルート フォースの試行では、すべてのオフセット エッジと円弧の交差が明示的に計算されます。$O(n^2)$線と円のペアごとの計算。合計すると遅すぎます。$n = 2 \cdot 10^5$。 

重要な観察は、これがまさに半径の円盤を持つ多角形のミンコフスキー和であるということです。$r$、続いて定式化に応じた補体型の解釈が続きます。 具体的には、半平面を距離を置いて交差させた凸多角形が有効中心領域となります。$r$各エッジと頂点の円形セクターから。 この構造は、頂点を順番に走査すると、ポリゴンごとに線形時間で処理できます。 

この領域を 2 つの部分に分解できます。1 つは内側のオフセット ポリゴン (エッジを内側にシフトすることで形成された小さな凸状のポリゴン) の領域、もう 1 つはポリゴンの外角と等しい角度を持つ各頂点の円セクターの合計です。 多角形は凸面であり、頂点が順序付けられているため、角度を直接計算して扇形領域を累積することができます。 

これにより、問題は、標準の凸多角形の面積と角度を含む補正項をすべて計算することになります。$O(n)$。

 ## アルゴリズムのチュートリアル

 有効な中心領域を、各エッジを内側に距離だけシフトすることによって形成された凸形状として解釈します。$r$、頂点のギャップを円弧で埋めます。 

1. 各有向エッジについて$(P_i, P_{i+1})$、その単位方向と内向きの法線を計算します。 内方向は、多角形の反時計回りの順序によって決まります。 これにより、距離によってシフトされたサポートラインが得られます$r$。 
2. これらのシフトされた半平面をすべて順番に交差させます。 ポリゴンは凸状であり、すでに順序付けされているため、これは現在のポリゴンを維持しながら段階的に行うことができます。 新しい各半平面は既存のポリゴンをクリップします。 これにより、エッジ距離制約を満たすすべての点を表す小さな凸多角形が生成されます。 
3. 靴紐の公式を使用して、このクリップされた多角形の面積を計算します。 これにより、有効領域の多角形のコアが得られます。 
4. 各頂点について$P_i$、エッジ間の外角を計算します。$P_{i-1}P_i$そして$P_iP_{i+1}$。 有効な領域は半径の円セクターに寄与します$r$そして角度はこの外角に等しい。 
5. すべてのセクター領域を次のように合計します。$\frac{1}{2} r^2 \theta_i$、 どこ$\theta_i$頂点の外角です$i$。 これは、コーナーをオフセットすることによって導入された湾曲した境界部分を考慮しています。 
6. ポリゴン領域とすべてのセクターの寄与の合計を出力します。 

なぜそれが機能するかは、ミンコフスキー和の幾何学に関係しています。 オフセット操作は、各エッジを平行エッジに変換し、各頂点を円弧に変換します。その角度は、その頂点における多角形の回転角度と正確に一致します。 多角形は凸状であるため、これらの部分は重なり合わず、有効な中心領域の境界に正確にタイル表示されます。 直線エッジと円弧への分解により、二重にカウントすることなく面積の加法性が維持されます。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def polygon_area(poly):
    n = len(poly)
    area = 0.0
    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]
        area += x1 * y2 - x2 * y1
    return abs(area) * 0.5

def angle(a, b, c):
    ax, ay = a
    bx, by = b
    cx, cy = c
    v1x, v1y = ax - bx, ay - by
    v2x, v2y = cx - bx, cy - by
    ang1 = math.atan2(v1y, v1x)
    ang2 = math.atan2(v2y, v2x)
    d = ang2 - ang1
    if d < 0:
        d += 2 * math.pi
    return d

def solve():
    t = int(input())
    for _ in range(t):
        n, r = map(int, input().split())
        pts = [tuple(map(int, input().split())) for _ in range(n)]

        if n == 1:
            print(math.pi * r * r)
            continue

        if n == 2:
            x1, y1 = pts[0]
            x2, y2 = pts[1]
            dx, dy = x2 - x1, y2 - y1
            L = math.hypot(dx, dy)
            if L >= 2 * r:
                print(math.pi * r * r)
            else:
                theta = 2 * math.acos(L / (2 * r))
                sector = r * r * (theta - math.sin(theta)) / 2
                print(math.pi * r * r - sector)
            continue

        area_poly = polygon_area(pts)

        ext_sum = 0.0
        for i in range(n):
            ext_sum += angle(pts[i - 1], pts[i], pts[(i + 1) % n])

        result = area_poly + 0.5 * r * r * ext_sum
        print(result)

if __name__ == "__main__":
    solve()
```コードは問題を 3 つのケースに分割します。 単一点の場合は、半径内のすべての中心があるため、ディスク領域を直接返します。$r$動作します。 セグメントの場合は、2 つの半径が$r$エンドポイントの周囲のディスクは十分に重なり合っています。 

一般的なポリゴンの場合、実装は幾何学的な同一性に依存します。つまり、オフセット領域の面積は、元のポリゴンの面積に半分を加えたものに等しくなります。$r^2$外角の合計の合計を倍します。 機能`angle`次を使用して各頂点での回転角度を計算します。`atan2`、向きと回り込みが正しく処理されるようにします。 

微妙な点は、角度の計算では常に正の値が得られる必要があることです。$(0, 2\pi)$負のラップアラウンドは合計を壊し、不正確な領域スケーリングを生成するためです。

 ### 例 1

 ## 特殊なケース

 単一点入力の場合、アルゴリズムはすぐに半径の円板の領域を返します。$r$。 ポリゴン構造が存在しないため、角度の合計は実行されず、結果は正確に$\pi r^2$。 

2 点セグメントの場合、アルゴリズムは円の交差ジオメトリに基づいて別の幾何学式に切り替わります。 重要な計算は弦の長さです$L$。 もし$L \ge 2r$、エンドポイントの周囲のディスクは重なり合わず、有効な領域は半径の完全な円のままになります。$r$。 もし$L < 2r$、オーバーラップによってレンズ状の領域が削除され、コードによって対応する円形のセグメント領域が差し引かれ、正しい中心セットが生成されます。 

一般的な凸多角形の場合、角度合計ループにより、不規則な形状も正しく処理されます。 各頂点はその回転角度に影響し、多角形は凸面であるため、計算されたすべての角度は厳密に次の角度になります。$(0, \pi)$、ラップアラウンドの曖昧さを防ぎます。
