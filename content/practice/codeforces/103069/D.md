 ## 解決策
 ## 問題の理解

 すべての道路が最初に通過するのに 1 秒かかる無向グラフが与えられています。 私たちは個々の道路に資金を投資することが許されており、1ドルごとにその道路の「速度レベル」が1ずつ上がります。 道路に速度レベルがある場合$a$、それを横断するにはかかります$1/a$秒。 

後で 2 人が同時に旅行することになります。1 人は$s_1$に$t_1$、そしてもう一つから$s_2$に$t_2$。 せいぜい配布後$k$エッジ間の移動時間の合計を最小限に抑えるために、各旅行者は結果として得られるエッジ通過時間の下で最短時間のパスを使用します。 

重要な問題は、私たちが直接パスを選択しているわけではないということです。 代わりに、エッジ コストを変更し、2 つの最短経路の問題が共有の予算制約を通じて相互作用します。 

制約$n, m \le 5000$での最短経路の計算を提案します。$O(m \log n)$あるいは$O(nm)$それは問題ありませんが、エッジ全体の予算のすべての割り当てを調査しようとすることは不可能です。$k$と同じ大きさにすることができます$10^9$。 これにより、各エッジに割り当てられた予算を追跡する DP が直ちに除外されます。 

微妙な点は、最適解は完全に組み合わせた方法で任意のグラフ構造に依存しないことです。 各エッジのコスト関数は、割り当てられた予算内で滑らかで凸状であり、これは、ソリューションが任意のサブグラフではなく最短パスに沿って構造を集中させる必要があることを強く示唆しています。 

素朴な推論による一般的な失敗例は、現在の最短パスで有用と思われるエッジを貪欲に改善する必要があると仮定することです。 1 つのエッジを改善すると、最短パスのアイデンティティが完全に変更され、以前の貪欲な選択が無効になる可能性があるため、これは問題になります。 

たとえば、2 つの互いに素なパスが競合する単純なグラフでは、$s$そして$t$1 つのエッジに投資すると、最短パスが切り替わり、以前の限界利益の計算が無意味になる可能性があります。 

## アプローチ

 強引な視点は分散を考えることです$k$すべてのエッジにわたる予算の単位。 割り当てごとに、ダイクストラを使用して両方のペアの最短パスを再計算し、結果の合計を計算します。 これは原理的には正しいですが、割り当ての数は指数関数的であるため、完全に実行不可能です。$m$、そして継続的なリラックスでもパスの切り替えにより役に立ちません。 

重要な観察は、固定パスの場合、そのエッジに沿って予算を割り当てる最適な方法は恣意的ではないということです。 各エッジには、$x_e$アップグレードはコストに寄与する$1/(1+x_e)$、パス上の固定の合計割り当ての場合、この関数は次のように凸になります。$x_e$。 凸性は、エッジ間で予算を不均等に分割すると、総移動時間が増加するだけであることを意味します。 したがって、固定的に選択されたパスの場合、最適な戦略は、そのパスのすべてのエッジに均等に予算を配分することです。 

これにより、各パスの最適化がホップ長のみの関数に分解されます。$L$、個々のエッジではなく。 パスに$L$エッジとレシーブ$k_i$予算に応じて、各エッジが効果的に取得します$k_i / L$、合計時間は次のようになります。$$L \cdot \frac{1}{1 + k_i / L} = \frac{L^2}{L + k_i}.$$現在、グラフの構造は、関連するエンドポイント間の最短ホップ距離によってのみ重要になります。 各トラベラーは、異なる長さのすべてのパスの中で、関数$\frac{L^2}{L+k_i}$で増加しています$L$固定用$k_i$。 

したがって、必要なグラフ計算は、次の間の重み付けされていない最短経路長だけです。$s_1, t_1$そしてその間$s_2, t_2$。 

その後に残る問題は純粋に連続的な問題です: 分割$k$の中へ$k_1$そして$k_2$、最小化:$$\frac{L_1^2}{L_1 + k_1} + \frac{L_2^2}{L_2 + k - k_1}.$$これは 1 次元の凸最適化問題であり、導関数が釣り合う点をチェックするか、関数が単峰性であるため三分探索によって解決できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべての割り当てを試して最短パスを再計算する | 指数 | O(m) | 遅すぎる |
 | BFS + 予算の継続的分割 | O(n + m + log k) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 1. 重み付けされていない最短経路長を計算します。 

BFS を実行する場所$s_1$に$t_1$取得するため$L_1$、そしてから$s_2$に$t_2$取得するため$L_2$。 すべてのエッジは最初はホップ数の意味で等しい重みを持っているため、BFS で十分です。 このステップにより、グラフ全体が構造上の制約を捉える 2 つの整数に縮小されます。 

### 2. コスト関数への各パスを削減します。 

各パスを予算を消費するものとして解釈します$k_i$、コストを与える:$$f_i(k_i) = \frac{L_i^2}{L_i + k_i}.$$このステップは、固定パス上の最適な割り当てがエッジ全体で均一であるという凸性の議論によって正当化されます。 

### 3. 全体的な最適化を再定式化する

 次に、以下を最小限に抑えます。$$f_1(k_1) + f_2(k - k_1)$$本物以上$k_1 \in [0, k]$。 これにより、問題全体が単一変数の凸関数に還元されます。 

### 4. 予算の最適な分割を見つける

 検索して最小値を見つけます$k_1$。 この関数は凸関数であるため、安全に三分探索を使用したり、微分等式を介して解くことができます。$$\frac{L_1^2}{(L_1 + k_1)^2} = \frac{L_2^2}{(L_2 + k - k_1)^2}.$$連続最適値を計算し、離散化を処理するために近くの整数を評価します。 

### 5. 最適値を出力する

 候補分割点で目標を評価し、最小値を出力します。 

### なぜ効果があるのか

 重要な不変条件は、最適なソリューションは、コストを増加させることなく、各パスがそのエッジ全体にバジェットを均一に配分するソリューションに変換できるということです。 これにより、内部エッジ構造への依存が取り除かれ、凸性によりパスごとの合計割り当てのみが重要になるため、最適性が維持されます。 削減されると、残る問題は 2 つの独立したコスト関数間の凸型の割り当てであり、これにより、分割変数の局所的な最適性がグローバルな最適性でもあることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def bfs(n, adj, s, t):
    dist = [-1] * (n + 1)
    q = deque([s])
    dist[s] = 0
    while q:
        u = q.popleft()
        if u == t:
            return dist[u]
        for v in adj[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist[t]

def f(L, k):
    return L * L / (L + k)

def solve_one(L1, L2, k):
    if L1 == 0 and L2 == 0:
        return 0.0
    if L1 == 0:
        return f(L2, k)
    if L2 == 0:
        return f(L1, k)

    lo, hi = 0, k
    for _ in range(80):
        m1 = (2 * lo + hi) / 3
        m2 = (lo + 2 * hi) / 3
        v1 = f(L1, m1) + f(L2, k - m1)
        v2 = f(L1, m2) + f(L2, k - m2)
        if v1 < v2:
            hi = m2
        else:
            lo = m1
    return f(L1, lo) + f(L2, k - lo)

n, m, k = map(int, input().split())
adj = [[] for _ in range(n + 1)]
for _ in range(m):
    a, b = map(int, input().split())
    adj[a].append(b)
    adj[b].append(a)

s1, t1, s2, t2 = map(int, input().split())

L1 = bfs(n, adj, s1, t1)
L2 = bfs(n, adj, s2, t2)

ans = solve_one(L1, L2, k)
print(f"{ans:.12f}")
```BFS 部分はホップ距離のみを抽出します。これは、エッジの改善によって隣接関係が変更されることはなく、トラバーサルの重みのみが変更されるため、これで十分です。 三分探索は予算分割の継続的な緩和に基づいて動作しますが、これはコスト関数の凸性により有効です。 

ここでよくある落とし穴は、パスごとではなくエッジごとに予算を割り当てようとすることです。 これにより、最短パス構造と最適化の間には扱いにくい結合が生じますが、正しいビューでは各パスが単一の凸関数に折りたたまれます。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、パスの 1 つが長さ 0 である場合です。$s_i = t_i$。 その場合、その旅行者のコスト関数は予算の割り当てに関係なく常にゼロとなり、すべての予算が他のパスに送られる必要があります。 アルゴリズムは、ゼロコストを返すことでこれを直接処理します。$L=0$ゼロ除算や不正な分割が発生しないようにします。 

もう 1 つの微妙なケースは、両方のパスの長さが等しい場合です。 次に、対称性により、最適解が予算を均等に分割するように強制され、三分探索は自然に中間点に収束します。 これにより、凸面緩和が対称のもとで正しく動作し、離散化アーティファクトによって結果が変化しないことが確認されます。
