 ## 解決策
 ## 問題の理解

 一連の整数が与えられ、すべての位置に厳密に正の乗数を割り当てることができます。 これらの乗数を割り当てた後、元の値の隣接するすべてのペアが式を通じて結合されます。$a_i t_i a_{i+1} t_{i+1}$、そのような各積は完全な正方形を形成する必要があります。 すべての有効な代入の中で、すべての乗算器の積を最小にする代入が必要であり、最終的な答えは大きな素数を法として求められます。 

重要な視点の変化は、これを「数値の選択」として考えるのをやめ、代わりに素指数のパリティ条件を固定することとして考えることです。 因数分解におけるすべての素指数が偶数である場合、数値は完全平方になります。 制約はローカルであり、隣接する位置のみが関係しますが、乗数はグローバルに決定されます。$t_i$2 つの制約に参加します (エンドポイントを除く)。 

制約は十分に大きいので、可能なことを列挙するあらゆるアプローチが可能です。$t_i$値や除数をチェックすることは直ちに不可能になります。 と$n$まで$10^5$および最大値$10^6$、すべての解は本質的に線形または線形に近いものでなければならず、エッジごとにゼロから因数分解を繰り返すことは避けなければなりません。 

素朴だが重要なエッジケースは、$a_i = 1$。 この場合、隣接するすべての積はすでに正方形であるため、すべてを設定すると最適な答えは 1 になります。$t_i = 1$。 自明でない乗数を不必要に導入するアプローチは、最適性を損なうことになります。 もう 1 つの微妙なケースは、素数が 1 つの要素のみに出現する場合です。 その素数は、対応する関数によって完全に「固定」される必要があります。$t_i$そして、そのような寄与を正しく分離できないと、誤ったパリティ処理が発生します。 

## アプローチ

 強引な解釈では、それぞれを処理します。$t_i$を未知数として扱い、値を貪欲に調整するか、指数を使ってシステムを解こうとすることによって、すべてのエッジで二乗条件を適用しようとします。 具体的に、すべてを因数分解すると、$a_i$、すると、各制約は素数の指数に関するパリティ方程式になり、指数を次のように割り当てようとします。$t_i$すべてのエッジの合計が均等になるようにします。 

直接的な総当たりアプローチでは、素数ごとに個別に指数を割り当てようとしますが、それでも次のようなシステムを解決する必要があります。$n$変数と$n-1$素数ごとの制約。 素数ごとに削減したとしても、素数ごとにガウス消去またはバックトラッキングを行うと、$O(n^2)$または実際の行動が悪い。 

構造上の洞察は、すべてが素数ごとにきれいに分解されるということです。 固定素数の場合$p$、指数のパリティのみが重要です。 各位置は 0 または 1 パリティに寄与し、それぞれ$t_i$パリティを反転します。 エッジ上の制約は、エッジ上の合計パリティを示します。$a_i t_i a_{i+1} t_{i+1}$偶数でなければなりません。これは、連続する変換された状態間のパリティを強制的に等しくすることと同じです。 

これにより、問題はパスに沿った伝播問題に変わります。 すべてを独立して選択するのではなく、$t_i$、それらを順番に決定できます。$t_1$、その後のすべての$t_i$前の制約によって強制されます。 唯一残っている自由度は最初の選択であり、これは総寄与を最小化することで解決されます。 

さらに単純化すると、最適解は各素数のバランスをとり、その寄与が可能な限り左に押し出され、最小の指数が全体的に累積されるようにすることに対応します。 これにより、アレイを流れる「比類のないプライム需要」の量を維持する線形スイープが得られます。

 ## アルゴリズムのチュートリアル

 平方条件は乗法的であり、素数を混合しないため、素因数を独立して処理します。 

1. 因数分解する$a_i$素数に変換し、指数パリティのみを維持します。 偶数の指数は二乗制約には無関係であるため、各素数が各位置で偶数回出現するか奇数回出現するかだけを考慮します。 これにより、各数値が素数上のパリティ マスクに還元されます。 
2. 各素数について$p$、配列を構築します$b_i$どこ$b_i = 1$もし$a_i$含まれています$p$奇数乗、それ以外の場合は 0。この制約により、すべてのエッジに対して、以下を含む結合パリティが保証されます。$t_i$合計が均等になります。 
3. 選択を解釈する$t_i$パリティフリップを決定するとき$x_i$この素数の各位置に対して。 すると条件はこうなります$b_i + x_i + b_{i+1} + x_{i+1} \equiv 0 \pmod 2$、これは連続する間の線形関係に単純化されます。$x_i$。 
4. 並び替えると$x_{i+1} = x_i + b_i + b_{i+1} \pmod 2$。 これは一度という意味です$x_1$が選択されると、全体のシーケンスが決定されます。 考えられる 2 つの完全な割り当てを計算します。1 つは次のとおりです。$x_1 = 0$そして一つは$x_1 = 1$を選択し、貢献度の合計が小さい方を選択します。 
5. 各選択肢について、この素数によって寄与される合計コストを計算します。これは、次の合計です。$x_i$の指数で重み付けされる$p$因数分解で$t_i$。 2 つの可能性の最小コストを集計します。 
6. すべての素数の寄与を剰余で乗算します。$10^9+7$素数間の選択は独立しているためです。 

### なぜ効果があるのか

 核となる不変条件は、各素数がパス グラフ上で 2 値線形システムとして独立して動作することです。 各制約は、隣接する状態間のパリティ関係を強制し、グローバルな問題を接続コンポーネント (ここでは配列全体) ごとに 2 つの可能な一貫した割り当てに分解します。 コストを最小限に抑え、各素数の寄与は指数空間では加算的ですが、値空間では乗算的であるため、素数ごとに独立して最適化すると、全体的に最適な積が得られます。 平方条件は素数ごとの指数のパリティのみに依存するため、素数間相互作用は存在しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def factorize(x, spf):
    res = {}
    while x > 1:
        p = spf[x]
        cnt = 0
        while x % p == 0:
            x //= p
            cnt ^= 1
        if cnt:
            res[p] = 1
    return res

def build_spf(n):
    spf = list(range(n + 1))
    for i in range(2, n + 1):
        if spf[i] == i:
            for j in range(i * i, n + 1, i):
                if spf[j] == j:
                    spf[j] = i
    return spf

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    maxa = max(a)
    spf = build_spf(maxa)

    parity = {}
    for i, v in enumerate(a):
        fac = factorize(v, spf)
        for p in fac:
            parity.setdefault(p, [0] * n)
            parity[p][i] = 1

    ans = 1

    for p, b in parity.items():
        n = len(b)

        def cost(start):
            x = start
            total = 0
            cur = 0
            for i in range(n):
                if i > 0:
                    x = (x + b[i - 1] + b[i]) & 1
                if x:
                    total += 1
            return total

        # number of t_i contributions is 2^{count of x_i=1}, but we only need minimal structure
        cnt = cost(0)
        cnt2 = cost(1)
        best = min(cnt, cnt2)

        ans = ans * pow(p, best, MOD) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```実装は、各数値を効率的に因数分解するための最小の素因数を構築することから始まります。 偶数累乗は二乗条件に影響を与えないため、各素数について、各インデックスで奇数回出現するかどうかだけを保存します。 

各素数について、配列に沿った 2 つの可能なパリティ伝播をシミュレートします。 遷移ルール​​はエッジ制約をエンコードし、乗数に素数が現れるために必要な位置の数を計算します。 2 つの開始選択肢の最小値は、最終的な答えに対するその素数の最適な指数寄与を与えます。 

微妙な点は、明示的に構築することは決してないということです。$t_i$。 最終的な答えは指数の合計にのみ依存するため、各素数が解に強制的に組み込まれる回数のみを計算します。 

## 実用的な例

 2 つの数値を含む単純なケースを考えてみましょう。 

入力:

 n = 2

 a = [2, 8]

 素数 2 はパリティ [1, 0] で存在します。 

| 私 | b[i] | x[i] (0 から開始) | 貢献 |
 | --- | --- | --- | --- |
 | 1 | 1 | 0 | 0 |
 | 2 | 0 | 1 | 1 |

 代わりに 1 から開始すると、異なる伝播が得られますが、最終的には同等になるため、最良のコストは 1 です。つまり、合計 2 の 1 つの因数が必要になります。 

これは、パリティの不均衡により、少なくとも 1 つの乗算器に欠落した指数が導入されることを強制する様子を示しています。 

ここで次のことを考えてみましょう。 

入力:

 n = 3

 a = [3, 6, 3]

 素数 3 の場合、パリティは [1, 1, 1] です。 

| 私 | b[i] | x[i] |
 | --- | --- | --- |
 | 1 | 1 | 0 |
 | 2 | 1 | 0 |
 | 3 | 1 | 0 |

 この場合、システムは追加の寄与を強制することなく一貫性を保つことができ、対称分布が局所的に相殺されることを示しています。 これにより、制約がすでにバランスされている場合、伝播によって不必要な乗算が正しく回避されることが確認されます。

 ## 特殊なケース

 すべて 1 の入力の場合、すべてのエッジ積はすでに完全な正方形です。 このアルゴリズムは空のパリティ構造を生成するため、素数は答えに寄与せず、最終積は 1 のままになります。 

次のような単一要素配列の場合`[p]`、制約はまったくありません。 伝播ステップは決してアクティブ化されないため、どちらの開始状態でもコストはゼロになり、答えは正しく 1 になります。 

のような完全交互パリティの場合`[2, 3, 2]`、各素数は内部でキャンセルされる制約を独立して伝播します。 このアルゴリズムは両方の初期状態をテストし、すでに存在するものを超える強制的な追加の指数を検出せず、ローカル制約がグローバル コストを不必要に膨張させないことを確認します。
