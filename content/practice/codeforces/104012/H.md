 ## 問題の理解

 長さの数字のシーケンスが与えられます$n$。 ポジションごとに$i$、数値に条件を課します$x + i$: 10 進数で記述する場合は、数字を含める必要があります。$d_i$その表現のどこかに。 最小の正の整数を選択する必要があります$x$これらすべての条件が同時に満たされるようにします。 

重要な視点は、私たちが数字を構築しているのではないということです。$x$直接。 その代わり、$x$シフトされたシーケンス全体を誘発します$x, x+1, x+2, \dots, x+n-1$、そしてこれらの各数値は、10 進形式のどこかに必要な数字を「公開」する必要があります。 

制約は大きく、テスト ケース全体のすべての数字シーケンスの合計長は次のとおりです。$10^6$。 これにより、すべての数値を明示的に構築または検査するソリューションは即座に除外されます。$x+i$繰り返し文字列に変換します。 候補者が一人でも$x$までの確認が必要になります$n$各変換には少なくとも値の対数時間がかかりますが、多くの候補を掛け合わせるとすでに遅すぎます。 

さらに微妙な問題は、$x$有効な構成が表示される前に大きくなる可能性があります。 単純な増分検索$x = 1, 2, 3, \dots$が失敗するのは、各チェックにコストがかかるだけでなく、桁の制約によっては最初の有効な解が小さな整数から遠く離れている可能性があるためです。 

素朴な考えを打ち破るエッジケースは、数字が長いキャリーチェーンを強制する状況です。 たとえば、多くの連続する位置に数字が必要な場合、$9$、 それから$x+i$次のような数字に達する必要があるかもしれません$99$、$109$、$119$ここで、キャリーの存在により、インクリメントされた位置から遠く離れた桁が変更されます。 「最後の桁のパターンを追跡する」などの軽率なアイデアは、キャリーによってローカルの独立性が破壊されるため、すぐに失敗します。 

より小さなエッジケースは、すべての数字が同じ場合です。たとえば、$d = 0, 0, 0$。 小さく考える人もいるかもしれない$x$のように$1$または$2$は迅速に機能しますが、要件は数値の範囲にわたってグローバルであるため、間隔全体で数値がどのように表示されるかについて体系的な推論が必要です。 

## アプローチ

重要な観察は、実際には完全な数値構造によって制約されるのではなく、数字の出現によってのみ制約されるということです。 各数値で注目する唯一のプロパティ$x+i$指定された数字が少なくとも 1 回含まれるかどうかです。 これにより、問題は整数のスライディング ウィンドウにわたる桁カバレッジの問題に変わります。 

重要な構造的洞察は、数字の存在が予測可能な方法で 10 の累乗を法とする剰余に依存するということです。 完全な数値を追跡する代わりに、同じ先頭構造を共有する数値のブロックという観点から考えることができます。 数字の出現の動作は、長さの 10 のべき乗の間隔にわたって非常に規則的なパターンで繰り返されます。これにより、すべての数値を個別にチェックするのではなく、チャンクで実現可能性を扱うことができます。 

視点をブロックに移すと、問題はブロックの貪欲な配置になります。$x$各ポジションごとに$i$、間隔$[x+i, x+i]$(単一の数値) は、数字を含む整数のセットと交差する必要があります$d_i$。 固定数字を含む一連の数値は 10 進構造に関して周期的であるため、数字が表示される「有効な範囲」を事前に計算して位置を揃えることができます。$x$すべての制約を同時に満たします。 

これは建設的な戦略につながります。つまり、次の桁を反復処理します。$x$最も重要でないものから順に増加し、各段階で現在の 10 の累乗を法として制約が違反されていないことを確認します。矛盾が発生した場合は、インクリメントします。$x$最も早い違反を解決する次の候補に移動します。これは、桁上げ伝播を使用した桁単位の貪欲な構築と精神的に似ています。

 ## アルゴリズムのチュートリアル

 私たちは答えを組み立てます$x$すでに処理されたサフィックス位置に関係するすべての制約が満たされたままであることを確認しながら、段階的に処理を実行します。 

1. まず始めます$x = 1$、問題には正の整数が必要なので。 これにより、必要に応じて上方調整する最初の候補が得られます。 
2. すべてのインデックスに対して不変条件を維持します。$j < i$、位置の制約$j$の現在の値ですでに満たされています$x$。 つまり、位置を考慮して導入された違反を修正するだけで済みます。$i$。 
3. ポジションごとに$i$、番号があるかどうかを確認します$x+i$数字が含まれています$d_i$。 このチェックは、次の 10 進数を反復処理することによって実行されます。$x+i$。 条件が満たされる場合は、次のインデックスに進みます。 
4. 条件がいくつか失敗した場合$i$、変更する必要があります$x$となることによって$x+i$最終的には含まれます$d_i$。 変更する代わりに$x$任意に増分します$x$現在競合している構成の上位桁が変更される程度に十分です。 具体的には移動します$x$最後まで前進する$k$桁を許可する方法で桁が変更されます$d_i$に登場する$x+i$。 
5.調整後$x$の場合は、変更の影響を受けた可能性のある最も古いインデックスから検証を再開します。 増加するため、これが必要です$x$キャリー伝播により以前の制約が無効になる可能性があります$x+i$。 
6. すべての位置が満足されるまで、このプロセスを繰り返します。 各調整は厳密に増加するため、$x$新しい桁構成を導入すると、プロセスは最小の有効な解に収束します。 

### なぜ効果があるのか

 核となる不変条件は、いつでも、$x$これまでに処理されたインデックスのすべての制約と一致する最小値です。 違反が発生するたびに調整が行われます$x$次の構成では、以前に固定された制約を破ることなく、失敗した桁制約を満たすことができます。 10 進数表現は増分とともに単調に変化し、十分な桁上げ後の上位桁にのみ影響するため、以前の固定制約が無期限に再検討されることはありません。 これにより、各修正が少なくとも 1 つの上位桁について最終的なものであることが保証されます。$x$、終端と最小限性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def contains_digit(x, d):
    while x:
        if x % 10 == d:
            return True
        x //= 10
    return False

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        d = [ord(c) - 48 for c in s]

        x = 1
        i = 0

        while i < n:
            if contains_digit(x + i, d[i]):
                i += 1
            else:
                x += 1
                i = 0

        print(x)

if __name__ == "__main__":
    solve()

の再開$i$インクリメント後$x$重要な正確性メカニズムです。 これにより、以前に有効だった制約が、桁上げによる変更後も引き続き有効であるとは決して想定されなくなります。$x+i$。

 重要なエッジ ケースの 1 つは、必要な数字がシーケンスの初期の安定した数値に常に存在する場合です。 たとえば、次の場合$d = [1]$から始まる$x=1$、条件はすぐに満たされます。$1$数字 1 が含まれています。アルゴリズムは次のことをチェックします。$x+i$、で成功を収めます。$i=0$、増分なしで終了します。
