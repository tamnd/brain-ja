 ## 解決策
 ## 問題の理解

 最大 5 人のプレーヤー用のサイコロのセットを作成するように求められます。 各プレイヤーは 1 つのサイコロを受け取り、すべてのサイコロは k で示される同じ数の面を持ち、k は最大 120 です。すべてのサイコロが振られると、各サイコロは 1 つの数字を生成します。すべてのサイコロのすべての数字はグローバルに異なるため、結果として得られる結果は、出た値に基づいてプレイヤーの厳密な合計順序になります。 この順序により、プレーヤーの順列が定義されます。 

kⁿ の可能なロール結果すべてにわたって、各結果はプレイヤーの 1 つの順列を正確に引き起こします。 すべての順列を正確に同じ確率にする必要はありませんが、分布は均一に非常に近くなければなりません。任意の 2 つの順列を生成する結果の数は、相対的に最大 0.2 パーセント異なる場合があります。 

入力はプレイヤーの数である n だけです。 出力では、k を記述し、それぞれ k 個の異なる整数のリストとして n 個のサイコロをリストする必要があります。すべてのサイコロにわたるすべての kn 整数は個別であるというグローバル制約があります。 

重要な問題は、kⁿ 個の結果が存在するにもかかわらず、誘発される順列が異なるサイコロ間の比較に依存し、単純または構造化されていない数値の割り当てがこれらの比較にバイアスを導入する傾向があることです。 

n が最大 5 であるため、可能な順列の数は最大 120 であり、ターゲットの分布は非常に粗くなります。 この小さな n は、漸近的に最適な確率的機構が必要ないことを示唆しています。 代わりに、慎重にバランスのとれた有限構造で十分です。 

微妙なエッジ ケースは、単一のダイ内の局所的な対称性では、ダイ間の比較の対称性が保証されないことです。 たとえば、定数によってシフトされた同一の増加シーケンスを各ダイに与えると、1 つのダイが別のダ​​イより系統的に大きくなり、順列分布が完全に崩壊します。 もう 1 つの障害モードは、ダイごとにランクを独立して処理することです。これは、ダイ間の比較が内部ランクではなく絶対値に依存することを無視しています。 

したがって、目標は、サイコロ間のすべてのペアごとの比較がすべての kⁿ 結果にわたって可能な限りバランスがとれるように、n 個の同一構造セットに配置された kn 個の異なる整数を構築することです。 

## アプローチ

 最も直接的な強引なアイデアは、各サイコロを、kn 値のプールから選択された個別の整数の任意の長さ k 個のシーケンスとして扱い、すべての kⁿ ロールの結果をシミュレートすることです。 各構成について、ロール値をソートすることによって、誘発される順列を決定します。 各順列が発生する回数をカウントし、すべてのカウントが近づくまでシーケンスを調整しようとします。 

このアプローチは、関心のある量を直接測定するため、概念的に簡単です。 ただし、n = 5 で k が 120 に近い場合でも計算上不可能です。結果の数は kⁿ (およそ 120⁵) になるほど増加し、列挙をはるかに超えており、単一の候補構成を評価する場合でも、すべての順列カウントを最初から再計算する必要があります。 

重要な観察は、実際には正確な均一性は必要ないということです。 必要なのは、順列周波数全体にわたる極めて小さい偏差だけです。 これにより、プレーヤーを並べ替えても誘導分布がほぼ不変となる高度に対称的な構造を使用することができます。 すべてのダイが慎重に設計された同じ構造から構築されており、ダイ間の比較のバランスがとれている場合、並べ替えが系統的に他の並べ替えをわずかな丸め効果以上に支配することはありません。 

これは構築的な考え方につながります。つまり、周波数を直接最適化する代わりに、ペアごとの比較のレベルで近似対称性を強制し、n が小さい場合、これによって完全な順列分布がすでに制御されているという事実に依存します。

 ## アルゴリズムのチュートリアル

 この構築では、シンプルだが強力なアイデアを使用します。各ダイを、同じ構造化ソースからのサンプルのように動作する k 値としてエンコードしますが、すべての kn 値が区別できるようにシフトされます。 構造は、すべてのダイの値が他のダイとどのように比較されるかという点で統計的に区別できないように選択されます。 

すべての場合に k = 120 を設定します。 次に、サイズ kn の単一の塩基順序付けを構築し、これを kn 個の異なるランクのシーケンスとして解釈します。 このシーケンスは、サイズ k の n 個のブロック (ダイごとに 1 ブロック) に分割されます。 各ブロック内では、単純に連続した整数を取得しません。これは、ダイ間での強いバイアスが発生するためです。 代わりに、各ダイがグローバル順序の「拡張された」サブセットを受け取るように値をインターリーブします。 

### アルゴリズムのチュートリアル

 1. k = 120 を固定し、1 から kn までの kn 個の異なる整数のリストを作成します。 これは、サイコロ間の比較を決定するグローバルな順序を表します。 
2. プレーヤーのインデックスに関して可能な限り構造を持たないように、これらの kn 値の単一の順列を構築します。 実際には、これを固定擬似ランダム順列または決定論的シャッフルとして扱うことができます。 
3. この順列をサイズ k の n 個のグループに分割し、各ダイに 1 つのグループを割り当てます。 したがって、各ダイは k 個の異なる整数を受け取り、すべての kn 値が 1 回だけ使用されます。 
4. 各サイコロの額面を、割り当てられた整数として任意の順序 (通常は順列に表示される順序) で定義します。 印刷された面の順序ではなく、サイコロ間の比較のみが重要であるため、内部順序は無関係です。 
5. ロールが発生すると、各ダイスはその k 値の 1 つを均一に選択します。 誘導される比較構造は、これらの値がグローバル順列のどこに位置するかによって異なります。 各サイコロは同様に分散されたランクのサブセットを受け取るため、サイコロの各ペアは、一方が他方に勝つほぼバランスの取れた結果をもたらします。 
6. プレーヤーの順列は、n 個の選択された値を並べ替えることによって決定されます。 ペアごとの関係はほぼ対称であり、体系的な利点を持つダイがないため、結果として得られる置換の分布は均一に近く、サイズが約 1/k の離散化効果による偏差のみが生じます。 

### なぜ効果があるのか

 不変条件は、すべてのサイコロが、サイズ kn の単一のグローバルなランダムのような順序付け内の k 位置のサブセットに対応するということです。 すべてのサブセットは同じサイズであり、同じ順列から得られるため、各ダイはランク全体にわたって同一の周辺分布を持ちます。 さらに重要なことは、どのサイコロのペアでも、一方のサイコロが選択した要素が他方のサイコロよりも大きい位置の数がほぼ正確にバランスが取れていることです。 これにより、すべてのペアごとの比較がほぼ対称になります。 

n ≤ 5 であるため、完全な順列分布を制御するには、ペアごとの不均衡を制御するだけで十分です。 任意の順列確率は、これらのペアごとの関係の一貫した結果に分解できるため、ほぼ均一なペアごとのバランスに矛盾することなく、どの順列も大きく逸脱することはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    k = 120

    vals = list(range(1, n * k + 1))

    # deterministic shuffle using a simple linear congruential permutation
    # (enough for construction purposes since n is tiny)
    mod = len(vals)
    for i in range(mod):
        j = (i * 37 + 11) % mod
        vals[i], vals[j] = vals[j], vals[i]

    for i in range(n):
        die = vals[i * k:(i + 1) * k]
        print(*die)

if __name__ == "__main__":
    solve()
```実装では、まず、制約の要求に応じて k = 120 を固定します。 次に、kn 整数のグローバル プールを作成し、決定論的なシャッフルを適用します。 特定のシャッフルは、真のランダム性をシミュレートすることを目的としたものではありません。 これは、単調な割り当てや循環的な割り当てなどの異常な構造を回避することのみを目的としています。 

各ダイは、この並べ替えられたリストから k 個の要素の連続したブロックを取得することによって形成されます。 これにより、サイコロ全体での素性が保証され、各サイコロが同じグローバル分布から抽出された値を受け取ることが保証されます。 

よくある間違いは、各ダイ内の順序を保持しようとしたり、等差数列を割り当てようとしたりすることです。 これらのアプローチでは、ダイ間の比較に強いバイアスが生じます。 ブロックベースの割り当てでは、ダイが他のダイの上にグローバルにシフトされないようにすることで、これを回避します。 

## 実用的な例

 n = 3 を考えます。k = 120 を構成し、360 個の値の順列を生成します。 次に 3 つのブロックに分割します。 

正確な値は無関係であるため、実際の数値ではなく、割り当ての構造のみを追跡します。 

### トレース 1

 | 死ぬ | 割り当てられたブロック位置 |
 | --- | --- |
 | 1 | シャッフルされた順位 1 ～ 120 |
 | 2 | シャッフル位置 121-240 |
 | 3 | シャッフル位置 241-360 |

 このトレースは、各ダイがまったく同じ数のグローバル ランクを受け取っていることを示しています。 各ダイスが面を振ると、同じグローバル分布からランダムなランクが 1 つ実質的に選択されるため、系統的に支配的なダイスはありません。 これにより、順列にわたるほぼ対称性がサポートされます。 

### トレース 2 (エッジ動作の直感)

 2 つのサイコロ i と j を仮定します。 それぞれには、素ではあるが同一に分散されたランク位置から抽出された 120 の値があります。 ペアで考えられる 120 平方の結果全体にわたって、離散順序付けによって引き起こされる小さな境界効果まで、ペアのおよそ半分が i < j を満たし、残りの半分が j < i を満たします。 

これは、ペアごとの比較がバランスが取れていることを裏付けており、これが順列に偏りが生じる唯一のメカニズムです。

 ## 特殊なケース

 n = 2 の場合、この構築は、k 値の 2 つの等しいサイズのブロックに縮小されます。 各ダイは同一に分散されたランクからサンプリングするため、どちらのダイにも体系的な利点はありません。 したがって、2 つの可能な次数にわたる順列分布はほぼバランスが取れており、ランクの有限分割による離散化ノイズのみが存在します。 

n = 5 の場合、プレイヤーの最大数に達します。 ここでも、各ダイは同じグローバル順列から抽出されたちょうど k 個の値を受け取ります。 サイコロ間の依存関係はより複雑になりますが、対称性の議論は依然としてペアごとの比較のレベルで維持され、並べ替えが他の並べ替えから大きく逸脱することを防ぎます。
