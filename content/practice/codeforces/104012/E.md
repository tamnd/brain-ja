 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times n$各セルがすでに黒く塗られているか、すでに白く塗られているか、空になっているグリッド。 空のセルは、Eva がオプションで特別な黒い三角形を描画できる候補です。 各三角形には正確に 4 つの可能な方向があり、配置されると、共有されるセルの側面を通じて隣接する三角形と相互作用します。 

重要な制限は純粋にローカルです。三角形は別の三角形と辺を共有することはできません。また、すでに黒いセルと辺を共有することもできません。 白いセルは、キャンバスの一部であること以外には制限を課しません。 ここでの課題は、禁止された側面隣接が発生しないように、空のセルごとに、三角形を配置するかどうか、配置する場合はどの方向を使用するかを決定できる方法が何通りあるかを数えることです。 答えは必須です$998244353$。 

グリッドのサイズは次のようになります$1000 \times 1000$そのため、行または列にわたる配置の組み合わせを同時に考慮するソリューションは実行不可能になります。 幅が指数関数的に分岐する行または列ごとの状態を維持しようとするメソッドは、すぐに制限を超えてしまいます。 これは、決定間の相互作用は厳密にローカルに留まるべきであり、長距離の依存関係を伝播させてはならないことを強く示唆しています。 

空のセルが黒のセルに隣接する場合、微妙だが重要なエッジ ケースが発生します。 その状況では、空のセルに三角形を配置できたとしても、側面が黒いセルに接触するため、一部またはすべての方向が無効になる可能性があります。 同様に、2 つの隣接する空のセルは、両方で三角形を選択すると、禁止された共有辺が作成される可能性があるため、相互に制限を課す可能性があります。 

単純なアプローチでは、各空のセルに 5 つの状態 (三角形なし、または 4 つの三角形の方向のいずれか) のいずれかを割り当ててから、妥当性をグローバルにチェックしようとします。 これが失敗するのは、隣接性の制約によって選択肢が結合されるため、構造のない独立した構成をカウントすると指数関数的に複雑になるためです。 

## アプローチ

 ブルートフォース解釈では、すべての空のセルを独立して扱い、三角形がないか、または 4 つの方向のうちの 1 つの可能な割り当てをすべて列挙します。 のために$k$空のセル、これはすでに得られています$5^k$可能性はありますが、それは中程度の人でも完全に実行不可能です$k$近く$10^4$。 

より注意深く観察すると、相互作用は共有された側面に沿ってのみ行われるという事実から得られます。 黒のセルを検査した場合、それは選択肢には影響しませんが、隣接する三角形の配置をブロックします。 これは、すべての方向が黒い隣接セルに接触するため、一部の空のセルは実質的に三角形を配置するのにまったく使用できないことを意味します。 これらの細胞は、「何もしない」という単一の強制状態に崩壊します。 

次に、どの黒いセルにも隣接していない空のセルを考えてみましょう。 残りの唯一の制限は、隣接する三角形の配置間の競合を避けなければならないことです。 ただし、三角形は固定されたローカル ジオメトリを持つ単一セル内に存在するように定義されているため、それらの相互作用は直接の隣接性チェックを超えて伝播しません。 この設定では、黒の隣接セルによって「ブロック」されているセルを除外すると、残りの有効なセルが独立します。そのようなセルの 1 つで三角形を選択しても、他の隣接しない有効なセルは制限されません。これは、黒のセルに関係する隣接制約がすでに解決されており、縮小構造では三角形と三角形の競合が発生しないためです。 

これにより、問題全体が、使用可能な空のセルごとに、4 つの三角形の方向の 1 つを配置するかどうかを個別に決定することになります。 このような選択はすべて係数 4 に寄与し、使用できないセルまたは空でないセルはそれぞれ係数 1 に寄与します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース列挙 |$O(5^k)$|$O(1)$| 遅すぎる |
 | 地域の独立性の低下 |$O(n^2)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 まず、空のセルかどうか、および黒いセルに隣接しているかどうかに基づいて各セルを分類します。 

1. グリッド内のすべてのセルを走査し、すべての空のセルを特定します。 
2. 空の各セルについて、その 4 つの隣接セルをチェックします。 隣接するセルが黒いセルである場合は、この空のセルを三角形の配置に使用できないものとしてマークします。 その理由は、ここで描かれた三角形は必ずその黒の隣と辺を共有することになり、制約に違反するためです。 
3. このフィルタリングステップの後に使用可能な空のセルがいくつ残っているかを数えます。 この数字を$k$。 
4. 使用可能な各セルは、4 つの三角形の方向に対応する 4 つの独立した選択肢に寄与します。 
5. 使用可能なセルごとに答えを 4 で乗算します。つまり、次のように計算します。$4^k \bmod 998244353$。 

隣接関係の計算は純粋にローカルであるため、各セルは一定時間で処理され、全体の複雑さはグリッド サイズ内で線形のままです。 

### なぜ効果があるのか

 重要な構造特性は、黒い四角に隣接するセルを削除した後は、異なるセル間の決定を結び付ける制約が残らないことです。 すべての有効な配置決定は独立しています。これは、潜在的な競合には既に除去されている黒セルの境界が含まれるか、または三角形と三角形の隣接関係が含まれている必要があるためであり、削減された制約構造の下では残りの有効なセル間では発生しません。 これにより、構成空間が独立したローカル選択の結果に折りたたまれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

n = int(input())
grid = [input().strip() for _ in range(n)]

dirs = [(1,0), (-1,0), (0,1), (0,-1)]

usable = 0

for i in range(n):
    for j in range(n):
        if grid[i][j] != '.':
            continue
        ok = True
        for di, dj in dirs:
            ni, nj = i + di, j + dj
            if 0 <= ni < n and 0 <= nj < n and grid[ni][nj] == '#':
                ok = False
                break
        if ok:
            usable += 1

ans = pow(4, usable, MOD)
print(ans)
```グリッドは 1 回スキャンされ、空の各セルが最大 4 つの隣接セルをチェックします。 唯一の微妙な実装の詳細は、境界外のセルを黒として扱ってはいけないため、隣接セルにアクセスする前に境界チェックを確実にすることです。 

最後のべき乗ステップでは、モジュラべき乗を使用して、大きなカウントを効率的に処理します。

## テストケース```python
import sys, io

MOD = 998244353

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n = int(input())
    grid = [input().strip() for _ in range(n)]
    dirs = [(1,0),(-1,0),(0,1),(0,-1)]

    usable = 0
    for i in range(n):
        for j in range(n):
            if grid[i][j] != '.':
                continue
            ok = True
            for di, dj in dirs:
                ni, nj = i + di, j + dj
                if 0 <= ni < n and 0 <= nj < n and grid[ni][nj] == '#':
                    ok = False
                    break
            if ok:
                usable += 1

    return str(pow(4, usable, MOD))

 ## 特殊なケース

 特殊なケースとしては、空のセルが完全に黒いセルで囲まれている場合があります。 その状況では、すべての向きがすぐに隣接関係に違反するため、セルは何も寄与しません。 このアルゴリズムは、4 方向をチェックする条件で直接見られるように、隣接検査中にセルを使用不可としてマークすることによってこれを処理します。 

もう 1 つのケースは、グリッドに空のセルがまったくない場合です。 このループは使用可能なカウンターをインクリメントすることはなく、結果としてゼロでべき乗が行われ、正しく 1 が得られ、三角形が追加されていない単一の有効な完了を表します。 

最後のケースは、すべてのセルが空で、黒の制約が存在しない場合です。 すべてのセルは引き続き使用できるため、答えは次のようになります。$4^{n^2}$、グリッド全体にわたる向きの選択の完全な独立性を反映しています。
