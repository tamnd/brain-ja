 ## 解決策
 ## 問題の理解

 2 つの文字列が与えられています。`s`そして`t`。 課題は、変換可能かどうかを判断することです。`s`の中へ`t`2 つの操作を使用して、文字を削除します。`s`または、次の部分文字列を並べ替えます`s`アルファベット順に。 変換は次で終了する必要があります`t`正確には、その文字の単なる並べ替えではありません。 

入力は複数のテスト ケースで構成されます。 各テスト ケースの長さは、`s`そして`t`、次に文字列自体。 変換が可能であれば出力は「YES」、それ以外の場合は「NO」になります。 

制約が示すのは、`n`すべての合計は 200,000 に達する可能性があります`n`テスト ケース全体の数も 200,000 に制限されます。 これにより、線形演算より悪いアルゴリズムが除外されます (`O(n log n)`) 各テストケースの複雑さ。 可能なすべての部分列を試すなどの 2 次アプローチ`s`が鈍くなるにもほどがあります。 

素朴なアプローチを打ち破る可能性のあるエッジケースには、次のような状況が含まれます。`t`のソートされたバージョンのサブシーケンスです`s`しかし、のではありません`s`自体。 たとえば、次の場合`s = "cba"`そして`t = "bc"`、サブシーケンスをチェックする不注意なアルゴリズム`s`ソート操作を考慮しないと誤って拒否される可能性がありますが、プレフィックスをソートすると正しい答えが得られます。 別のエッジケースが発生するのは次の場合です。`t`に欠けている文字が含まれています`s`; これはすぐに「NO」を返すはずです。 

## アプローチ

 ブルートフォースアプローチは、削除と部分文字列の並べ替えのすべてのシーケンスをシミュレートすることです。 概念的には、考えられるすべてのソートされた部分文字列を試すことができます。`s`一致するまで文字を削除します`t`。 これは原理的には正しいですが、まったく現実的ではありません。`n = 100`、その組み合わせの数は天文学的です。 各部分文字列のソート操作自体は、`O(n log n)`、そして、あります`O(n^2)`部分文字列。 

重要な洞察は、任意の部分文字列を並べ替える 2 番目の操作により、文字をブロックする小さな文字がない限り、文字を文字列内で前に移動できるということです。 つまり、形成するには`t`、位置の均等性を考慮して、文字が右から左へ同じ相対順序で表示される必要があります。 ソートでは、同じパリティ (偶数または奇数のインデックス) の位置にある文字のみを移動できます。これは、辞書編集順序により、文字が反対のパリティの小さい文字を飛び越えることは、ソート操作でカバーすることができないためです。 

これを実装するには、スキャンします`t`右から左に向かって、各文字を対応する文字と一致させてみます。`s`。 また、文字が「ブロック」されているかどうかを判断するために、値の小さい残りの文字の数も維持します。 必要な文字がその右側の (同じパリティの) 小さな文字によってブロックされている場合、変換は不可能です。 

これにより、問題は周波数テーブルを使用した線形スキャンに縮小され、効率的な解決策が得られます。

 ## アルゴリズムのチュートリアル

 1. カウンタ配列を初期化する`cnt`それぞれの文字ごとに`a`に`z`各文字が何回残っているかを追跡する`s`端からスキャンしていきます。 
2. 2 つのポインタを設定します。`i`終わりに`s`そして`j`終わりに`t`。 
3. その間`j >= 0`、一致を試みます`t[j]`と`s[i]`：

- もし`s[i] == t[j]`、両方をデクリメントします`i`そして`j`そしてカウンタを更新します`s[i]`。 
- もし`s[i] != t[j]`、どうかを確認してください`s[i]`よりも小さいです`t[j]`。 そうであれば、そのカウンターをインクリメントして移動します`i`左、このキャラクターはブロックできる可能性があるため`t[j]`後で並べ替えようとすると。 
- より小さな文字（より小さいアルファベット値を持つ文字）が存在する場合`t[j]`) 正のカウンターを使用すると、`t[j]`はブロックされており、答えは「NO」です。 
4. のすべての文字が正常に一致すると、`t`、「はい」を返します。 ポインタの場合`i`-1に達し、`j`-1 ではない場合は、「NO」を返します。 

機能する理由: 右からスキャンすることで、`t`～から「引き出す」ことができます`s`右側の小さな文字に邪魔されずに、削除と並べ替えを使用します。 カウンタアレイは潜在的なブロッカーを効率的に追跡します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can_transform(s, t):
    n, m = len(s), len(t)
    cnt = [0] * 26
    i, j = n - 1, m - 1
    while j >= 0:
        target = ord(t[j]) - ord('a')
        while i >= 0 and ord(s[i]) - ord('a') != target:
            cnt[ord(s[i]) - ord('a')] += 1
            i -= 1
        if i < 0:
            return "NO"
        # Check if there is any smaller character blocking the target
        for k in range(target):
            if cnt[k] > 0:
                return "NO"
        i -= 1
        j -= 1
    return "YES"

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    s = input().strip()
    t_str = input().strip()
    print(can_transform(s, t_str))
```このコードは、次の文字のカウンターを設定します。`s`両方の文字列の末尾から反復して、次の各文字が`t`小さな文字に遮られることなく一致させることができます。 カウンタとポインタを慎重にデクリメントして、不変条件を維持します。`s[i+1:]`安全に無視または削除できる文字のみが含まれています。
