 ## 解決策
 ## 問題の理解

 文字列から始めて、正確に含むセットを構築したいと考えています。`k`異なるサブシーケンス。 長さの部分列の追加`L`削除される文字数のコストがかかります。`n - L`。 同じサブシーケンスを 2 回追加することはできません。 タスクは、総コストを最小限に抑えること、または十分な個別のサブシーケンスが存在しないことを報告することです。 

コスト構造は、より長いサブシーケンスが好ましいことを直ちに示唆します。 長さの部分列`n`費用`0`、 長さ`n-1`費用`1`、 等々。 長さごとに異なるサブシーケンスがいくつ存在するかがわかっていれば、最適な戦略は明らかです。長さからできるだけ多くのサブシーケンスを取得します。`n`、次に長さから`n-1`を収集するまで下に進みます。`k`彼らのうち。 

簡単バージョンには、`n ≤ 100`、これにより、おおよその動的プログラミングが可能になります。`O(n²)`または`O(n³)`操作。 長さの文字列があるため、すべてのサブシーケンスを列挙することは不可能です。`100`もっている`2^100`実行可能な限界をはるかに超えたサブシーケンス。 

誤って対処しやすい状況がいくつかあります。 

考慮する```
1 2
a
```個別のサブシーケンスは次のとおりです。`"a"`そして`""`。 彼らのコストは`0`そして`1`、したがって、答えは次のとおりです```
1
```空のサブシーケンスを忘れたソリューションでは、誤って出力されます。`-1`。 

別の例は```
3 8
aaa
```個別のサブシーケンスは次のとおりです。```
"aaa"
"aa"
"a"
""
```多くの削除パターンでは同一の文字列が生成されるため、異なるサブシーケンスは 4 つだけ存在します。 正しい出力は次のとおりです```
-1
```個別の文字列ではなく削除マスクをカウントすると、8 つの選択肢があると誤って結論付けられてしまいます。 

3番目の例は、```
4 5
abcd
```キャラクターはすべて異なります。 多くの異なるサブシーケンスがあり、最も安価な 5 つは次のとおりです。```
abcd  cost 0
abc   cost 1
abd   cost 1
acd   cost 1
bcd   cost 1
```答えは```
4
```短いサブシーケンスを選択するのが早すぎると、総コストが不必要に増加します。 

## アプローチ

 ブルートフォース手法では、すべてのサブシーケンスを生成し、結果の文字列をセットに保存して重複を削除し、長さで並べ替えて、最も長い時間を要します。`k`。 この方法は定義に直接従っているため、正しいです。 問題はマスクの数だ。 のために`n = 100`、 がある`2^100 ≈ 10^30`サブシーケンスが存在するため、このアプローチは完全に不可能になります。 

重要な点は、サブシーケンス自体は必要ないということです。 それぞれの可能な長さを持つ個別のサブシーケンスがいくつあるかを知る必要があるだけです。 

文字列を左から右に処理するとします。 させて`dp[i][j]`長さの異なる部分列の数を示します`j`位置で終わる接頭辞を使用して形成できます`i`。 追加すると`s[i]`、同じキャラクターの以前の出現によってすでに作成されている重複を作成しないようにする必要があります。 各文字が最後に出現することで、それらの重複を正確に減算することができます。 

これにより、指数列挙問題が多項式動的計画問題に変わります。 文字数がわかったら、削除される文字ごとにコストが 1 ずつ増加するため、より長い長さからより短い長さまで貪欲にサブシーケンスを取得します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n · n) | O(2^n) | 遅すぎる |
 | 最適 | O(n²) | O(n²) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 定義する`dp[i][j]`長さの異なる部分列の数として`j`最初のものを使用して形成できます`i`文字。 
2.初期化`dp[0][0] = 1`空の文字列には 1 つのサブシーケンス、つまりそれ自体があるためです。 
3. 文字を 1 つずつ処理します。 ポジションについて`i`、最初にすべての値をコピーします`dp[i-1][j]`、新しい文字を使用しないサブシーケンスを表します。 
4.あらゆる長さについて`j ≥ 1`、現在の文字を長さの異なるすべてのサブシーケンスに追加します。`j-1`前の接頭辞から。 これは貢献します`dp[i-1][j-1]`。 
5. 現在のキャラクターが以前に登場した場合、その前の位置を`p`。 現在の文字を、位置の前にすでに存在していたサブシーケンスに追加します。`p`重複を作成します。 減算`dp[p-1][j-1]`寄稿から。 

減算により、この文字が以前に使用されたときにすでに生成されていたサブシーケンスが正確に削除されます。 

1. 現在の位置をこの文字の最新の出現位置として保存します。 
2. テーブルに記入したら、`dp[n][j]`長さの異なる部分列の数を与える`j`。 
3. 長さから始める`n`下に移動しながら、できるだけ多くのサブシーケンスを取得します。`k > 0`。 
4. もし私たちが取るなら`x`長さの部分列`j`、答えに対する彼らの貢献度は、```
x × (n - j)
```1.長さを考慮した場合`0`私たちはまだ持っています`k > 0`、未満`k`異なるサブシーケンスが存在するため、出力します`-1`。 

### なぜ効果があるのか

 すべてのプレフィックスとすべての長さに対して、`dp[i][j]`異なるサブシーケンスを 1 回だけカウントします。 文字が再び出現するとき、生成される唯一の重複サブシーケンスは、その文字の最後に出現したものが前のコピーに由来するものだけです。 前回の発生以前からの寄与分を減算すると、それらの重複のみが削除され、それ以外は何も削除されません。 

サブシーケンスの長さが増加するとコストが減少するため、最適なソリューションでは、短いサブシーケンスを検討する前に、できるだけ多くの長いサブシーケンスを使用する必要があります。 したがって、貪欲な収集フェーズにより、最小の総コストが生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
s = input().strip()

dp = [[0] * (n + 1) for _ in range(n + 1)]
dp[0][0] = 1

last = [-1] * 26

for i in range(1, n + 1):
    c = ord(s[i - 1]) - ord('a')

    for j in range(n + 1):
        dp[i][j] = dp[i - 1][j]

    prev = last[c]

    for j in range(1, i + 1):
        add = dp[i - 1][j - 1]
        if prev != -1:
            add -= dp[prev][j - 1]
        dp[i][j] += add

    last[c] = i - 1

ans = 0

for length in range(n, -1, -1):
    take = min(k, dp[n][length])
    ans += take * (n - length)
    k -= take

if k > 0:
    print(-1)
else:
    print(ans)
```テーブルには寸法があります`(n+1) × (n+1)`。 行`i`最初のものを表します`i`文字。 新しい文字を追加した後も、以前に存在したすべてのサブシーケンスが引き続き存在するため、すべての行は前の行のコピーから始まります。 

微妙な部分は引き算です。 現在の文字がインデックスに以前に出現したと仮定します。`prev`。 位置の前にすでに存在していたものを拡張することによって形成されたサブシーケンス`prev`は、以前の出現が使用されたときにすでに作成されていました。 引き算`dp[prev][j-1]`それらの繰り返しを正確に削除します。 

貪欲なフェーズは長さから始まります`n`、これらのサブシーケンスのコストが最も低いためです。 下方に移動すると、最小の総コストが保証されます。 

Python には整数オーバーフローの問題は存在しません。 簡単なバージョンでは、個別のサブシーケンスの総数が超えることはありません。`2^100`、Python は自然に処理します。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    n, k = map(int, input().split())
    s = input().strip()

    dp = [[0] * (n + 1) for _ in range(n + 1)]
    dp[0][0] = 1
    last = [-1] * 26

    for i in range(1, n + 1):
        c = ord(s[i - 1]) - ord('a')

        for j in range(n + 1):
            dp[i][j] = dp[i - 1][j]

        prev = last[c]

        for j in range(1, i + 1):
            add = dp[i - 1][j - 1]
            if prev != -1:
                add -= dp[prev][j - 1]
            dp[i][j] += add

        last[c] = i - 1

    ans = 0
    k = int(k)

    for length in range(n, -1, -1):
        take = min(k, dp[n][length])
        ans += take * (n - length)
        k -= take

    if k > 0:
        print(-1)
    else:
        print(ans)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    solve()
    sys.stdout = sys.__stdout__
    return out.getvalue().strip()

# provided sample
assert run("4 5\nasdf\n") == "4"

# custom cases
assert run("1 1\na\n") == "0", "minimum size"
assert run("1 2\na\n") == "1", "empty subsequence needed"
assert run("3 8\naaa\n") == "-1", "not enough distinct subsequences"
assert run("2 4\nab\n") == "4", "all subsequences are used"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1 1 / a`| 0 | 最小サイズ |
 |`1 2 / a`| 1 | 空のサブシーケンスの処理 |
 |`3 8 / aaa`| -1 | 文字の繰り返しによってサブシーケンスが重複する |
 |`2 4 / ab`| 4 | 可能なすべてのサブシーケンスを使用する |
