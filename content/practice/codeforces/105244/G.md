 ## 解決策
 ## 問題の理解

 私たちにはいくつかの小さな進化シナリオが与えられており、それぞれが種の根を張った木と、いくつかの葉と既知のゲノム文字列の間の部分的なマッピングを記述しています。 すべてのゲノム文字列は同じ長さを持ち、4 つの可能なヌクレオチドで構成されます。 ツリーの内部ノードは未知の祖先種を表しており、そのゲノム文字列は私たちが自由に選択できます。 

固定ツリーの場合、すべてのノードに完全なゲノム文字列が割り当てられると、各エッジは 2 つのエンドポイント文字列が異なる位置の数に等しいコストに寄与します。 ツリーの総重量は、これらのエッジ コストの合計です。 タスクは、指定されたすべてのリーフ割り当てが尊重され、総エッジ コストが最小化されるように、すべての内部ノードに文字列を割り当てることです。 

入力には最大 100 の独立したツリーが含まれており、それぞれの頂点の数は最大 500、ゲノム長も最大 500 です。これにより、各ノードのゲノムをグローバルな組み合わせ検索空間内の単一のオブジェクトとして扱うアプローチは即座に除外されます。これは、ツリーのサイズとアルファベットの長さの両方が指数関数的に増大するためです。 ツリーごとのソリューションであっても、ノード数とアルファベット サイズの積が線形または二次に近い必要があります。 

重要な構造特性は、ゲノム内の位置に応じてコストが加算されることです。 各エッジは位置にわたる合計に寄与し、各位置での寄与は文字が一致するかどうかのみに依存します。 この独立性が、問題を解決可能にする主な単純化です。 

ツリーが単一ノードの場合、微妙なエッジ ケースが発生します。 この場合、エッジがないため、どのゲノムが割り当てられているかに関係なく、答えはゼロでなければなりませんが、そのノードが特定のゲノムにもマップされている場合、割り当ては制約されます。 単一ノード ツリーを個別に処理せずにエッジ全体で一貫性を強制しようとするソリューションでは、未定義の遷移や初期化されていない DP 値が誤って導入される可能性があります。 

もう 1 つのエッジ ケースは、ある木に直接的な順序でゲノムにマッピングされていない葉がある場合です。 マッピングは任意であるため、明示的なリーフとゲノムのペアリングではなく位置の仮定に依存すると、誤った割り当てと誤った DP 初期化が発生します。 

## アプローチ

 直接的なアプローチでは、完全なゲノム文字列をすべての内部ノードに割り当て、すべての可能性を評価しようとします。 各ノードが G ゲノムのいずれか、または 4^L 個の可能な文字列のいずれかを受け取ることができる場合、これは直ちに実行不可能になります。 最適な祖先文字列が入力にまったく表示されない可能性があるため、内部ノードを特定のゲノムのみに制限することさえ不正確です。 

重要な観察は、ゲノムの長さが位置によって独立していることです。 2 つのノード間のコストは、単にそれらの文字列のハミング距離、つまり文字が異なるかどうかの位置の合計です。 これは、各位置について個別に問題を解決し、結果を合計できることを意味します。 

単一の位置を固定すると、すべてのノードには 4 つの状態しかありません。 問題は次のようになります。葉の固定値を尊重して、{A、C、G、T} の文字をすべてのノードに割り当て、不一致ペナルティのエッジ上の合計を最小限に抑えます。 これは、各ノードがその子から最適なコストを集計する古典的なツリー動的プログラミングの問題です。 

位置ごとのブルートフォースソリューションでは、すべてのノードに対して 4 つの選択肢すべてが試行され、位置ごとに 4^N 通りの可能性が与えられますが、これは大きすぎます。 この改善は、サブ構造の再利用によってもたらされます。サブツリーのコスト寄与は、親が選択した文字にのみ依存するため、各ノードが代入を列挙する代わりに 4 つの値を計算するボトムアップ DP が可能になります。

各ノード u と各文字 c について、u に c が割り当てられていると仮定して、u をルートとするサブツリーの最小コストを計算します。 u の状態が与えられた場合、子は独立しているため、その貢献を合計することができ、それぞれが c に対する不一致ペナルティを備えた独自の文字選択よりも最適に選択されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ノードごと、位置ごとのブルート フォース割り当て | O(4^N・L) | O(N・L) | 遅すぎる |
 | ポジションごとのツリー DP | O(N・L・16) | O(N・4) | 承認済み |

 ## アルゴリズムのチュートリアル

 各ツリーを独立して処理し、各ツリー内で各ゲノム位置を独立して処理します。 

1. ゲノム内の 1 つのツリーと 1 つの位置を修正します。 すべてのノードのゲノムを、リーフの場合は単一の文字制約に、そうでない場合は制約のない変数に削減します。 これにより、問題はノードごとに 4 つの状態のうちの 1 つを割り当てるという問題に集約されます。 
2. ノード 1 でツリーをルートします。すべてのノード u について、u が文字 c を持つと仮定して、u をルートとするサブツリーの最小コストとして dp[u][c] を定義します。 この定義は、u の寄与を分離しながら、u 以下のすべての制約を取得します。 
3. 葉の dp を初期化します。 リーフが現在の位置に文字 x を持つゲノムにマッピングされている場合、dp[leaf][x] = 0 および dp[leaf][other] = 無限大となります。 これにより、後の移行で特別なケースが発生することなく、固定割り当てが強制されます。 
4. 子が親の前に計算されるように、ノードを事後順序で走査します。 各ノード u とキャラクター c について、各子 v からの寄与を独立して結合します。 
5. 各子 v について、u が選択した c に対して不一致コストを追加して、v に文字 PC を割り当てる最適な方法を計算します。 これにより、pc に対する遷移コスト min が dp[v][pc] + (pc != c) になります。 これをすべての子で合計して dp[u][c] を取得します。 
6. すべてのノードを処理した後、この位置の答えは dp[root][c] の c に対する min になります。 この値をすべてのポジションにわたって累積します。 

完全な答えは、これらの位置ごとの結果のすべてのゲノム位置にわたる合計です。 

### なぜ効果があるのか

 ノードの特性が固定されると、そのサブツリーが独立した最適化問題になるため、DP は有効です。 親と子の間の唯一の相互作用は接続エッジの不一致コストであり、これは選択した文字のみに依存し、より深い構造には依存しません。 これにより、最適な部分構造が作成されます。サブツリーに対する最適な割り当ては、選択した親文字の下にあるすべての子サブツリーに対して最適な割り当てを誘発する必要があります。そうでない場合は、子割り当てをより適切なものに置き換えて、総コストを削減できます。 この矛盾により、DP 再発の正しさが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = 10**18
idx = {"A": 0, "C": 1, "G": 2, "T": 3}

def solve_tree(n, m, parent, leaf_map, genomes, L):
    children = [[] for _ in range(n + 1)]
    for i in range(2, n + 1):
        p = parent[i]
        children[p].append(i)

    # leaf constraints: node -> genome index
    leaf_char = {}
    for v, g in leaf_map:
        leaf_char[v] = g

    # dp[node][4]
    dp = [[0] * 4 for _ in range(n + 1)]

    sys.setrecursionlimit(10**7)

    def dfs(u):
        if u in leaf_char:
            g = leaf_char[u]
            for c in range(4):
                dp[u][c] = 0 if c == genomes[g][0] else INF

        else:
            for c in range(4):
                dp[u][c] = 0

            for v in children[u]:
                dfs(v)
                new = [INF] * 4
                for c in range(4):
                    best = INF
                    for pc in range(4):
                        cost = dp[v][pc] + (pc != c)
                        if cost < best:
                            best = cost
                    new[c] = best
                for c in range(4):
                    dp[u][c] += new[c]

    dfs(1)

    return min(dp[1])

def main():
    G = int(input())
    genomes = []
    for _ in range(G):
        s = input().strip()
        genomes.append(s)

    T = int(input())
    out = []

    for _ in range(T):
        n, m = map(int, input().split())
        parent = [0] * (n + 1)
        for i in range(2, n + 1):
            parent[i] = int(input())

        leaf_map = []
        for _ in range(m):
            v, g = map(int, input().split())
            leaf_map.append((v, g - 1))

        if n == 0:
            out.append("0")
            continue

        L = len(genomes[0])
        ans = 0
        children = [[] for _ in range(n + 1)]
        for i in range(2, n + 1):
            children[parent[i]].append(i)

        # preprocess dfs per position
        for pos in range(L):
            dp = [[0] * 4 for _ in range(n + 1)]

            def dfs(u):
                if u in leaf_pos:
                    ch = leaf_pos[u]
                    for c in range(4):
                        dp[u][c] = 0 if c == ch else INF
                    return

                for c in range(4):
                    dp[u][c] = 0

                for v in children[u]:
                    dfs(v)
                    tmp = [INF] * 4
                    for c in range(4):
                        best = INF
                        for pc in range(4):
                            cost = dp[v][pc] + (pc != c)
                            if cost < best:
                                best = cost
                        tmp[c] = best
                    for c in range(4):
                        dp[u][c] += tmp[c]

            leaf_pos = {}
            for v, g in leaf_map:
                leaf_pos[v] = idx[genomes[g][pos]]

            dfs(1)
            ans += min(dp[1])

        out.append(str(ans))

    print("\n".join(out))

if __name__ == "__main__":
    main()
```この実装では、ツリー構造が位置ごとの文字制約から分離されます。 重要な点は、DP 状態が位置固有であるため、グローバル文字列を再利用するのではなく、文字ルックアップを使用してリーフ制約が位置ごとに再構築されることです。 

DFS 内の反復はソリューションの中核です。各ノードと各可能な文字について、各子に最適な割り当てを個別に計算し、コストを累積します。 不一致ペナルティはエッジ レベルでローカルに適用されるため、二重カウントやインタラクションの欠落が回避されます。 

## 実用的な例

 1 つの根と 2 つの葉を持つ単純な木を考えてみましょう。 ゲノム長が 2 で、「AC」と「AT」の 2 つのゲノムがあるとします。 根は両方の葉に接続されており、各葉は 1 つのゲノムに固定されています。 

位置 1 では、両方のゲノムに文字 A があるため、DP はコストゼロでどこにでも A を割り当てます。 位置 2 の場合、一方のリーフは C、もう一方のリーフは T であるため、ルートでの競合が強制されます。 

| ノード | dp[A] | dp[C] | dp[G] | dp[T] |
 | --- | --- | --- | --- | --- |
 | 葉1(C) | INF | 0 | INF | INF |
 | 葉2(T) | INF | INF | INF | 0 |
 | ルート | 2 | 1 | 1 | 0 |

 ルートでは、T または C を選択すると対称的にコストが最小化され、その位置の合計コストは 1 になります。 

このトレースは、ルートが 1 つのサブツリーを最適に一致させ、一方の不一致を他方に支払うことによって競合を解決していることを示しています。 

次に、下部の葉が A に固定され、ゲノム長が 1 である 3 つのノードのチェーンを考えます。最適な割り当ては A を上向きに伝播し、コストをゼロにします。 内部ノードで逸脱が発生すると、少なくとも 1 つのエッジでの不一致によりコストが直ちに増加し、DP がローカル エッジの決定を通じてグローバルな一貫性を正しく強制していることが確認されます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

| スペース | O(N・4) | ツリーごとの DP テーブルと隣接ストレージ |

 ## 特殊なケース

 単一の頂点ツリーは、DFS が子に拡張されず、答えがゼロのままでなければならないという基本条件を示しています。 DP はルートを初期化し、エッジを検出せず、その状態の min を返します。これは、許可された割り当てではゼロです。 

すべての葉が同一のゲノム文字列にマッピングされているツリーは、どこにも突然変異が必要ないことを確認します。 いかなる偏差も少なくとも 1 つのエッジに沿った不一致コストを厳密に増加させるため、DP は一貫して同じ文字を上向きに伝播します。 

複数の分岐でリーフ制約が競合するツリーでは、内部ノードが調整ポイントとして機能するように強制されます。 DP は、各内部ノードが子の不一致の合計を最小化する文字を個別に選択することを保証します。また、エッジ コストはツリー構造全体で分離可能かつ加算的であるため、この局所的な最適性はグローバルな最小値に正しく集約されます。
