 ## 問題の理解

 私たちに与えられたのは、`n`それぞれ 1 から 1 までの個別の整数`n`。 タスクは、各数値に赤または青の色を割り当てることです。`k`数字は赤です。 カラーリングのコストは、すべてのペアを数えることによって定義されます。`(x, y)`どこ`x`青です、`y`赤です、そして`y`で割り切れます`x`。 目標は、それぞれの最大コストを計算することです。`k`1から`n`。 

入力は単一の整数です`n`、セットのサイズとセット内の値の範囲の両方が決まります。 出力は次のシーケンスです。`n`整数、ここで、`k`-th 整数は、正確な場合の最大コストを表します。`k`数字は赤です。 

制約が意味するのは、`n`最大 100,000 に達する可能性があり、サイズのすべての可能なサブセットをチェックする単純なアプローチ`k`組み合わせには天文学的に遅い時間がかかります。 どのアルゴリズムも、ほぼ線形または線形に近い時間で実行する必要があります。 主な課題は、コストが緻密なネットワークを形成する割り算関係に依存することです。つまり、すべての数字が他の数字を複数で割り、多数の潜在的なペアが作成される可能性があります。 

微妙なエッジケースが境界で発生します。`k`。 もし`k = n`、すべての数字は赤であるため、有効なペアを形成するための青い数字はなく、コストはゼロでなければなりません。 同様に、`k = 0`、すべての数字は青で、再びコストがゼロになります。 これらの極端な値を明示的に処理しないソリューションでは、誤った値が生成される危険があります。 

## アプローチ

 ブルートフォースアプローチでは、サイズのすべてのサブセットに対して反復処理が行われます。`k`、それらを赤でマークし、残りの青の数字に対して割り切れるすべてのペアを数えます。 各サブセットには次のものが必要です`O(n^2)`それぞれの赤い数字がすべての青い数字と相互作用する可能性があるため、チェックします。 と`n`100,000 までの場合、このアプローチはまったく実行不可能です。 

最適な解決策を見つけるための重要な洞察は、これを可分性構造を使用した貪欲な問題として扱うことです。 大きな数字はより小さな数字で割り切れる傾向があるため、大きな数字を赤で塗りつぶし、小さな数字を青で塗るとカウントが最大になる傾向があります。 正式には、すべての数字に対して`x`、赤の倍数の数`x`次の場合にその貢献度を決定します。`x`は青です。 コストを正確に最大化するには`k`赤い数字、選択したいのは`k`最大の数値は赤で表示されます。これは、それぞれの小さな数値が割り切れるペアの最大数に寄与する可能性があるためです。 

各数値の約数を効率的に事前計算し、プレフィックスの合計を使用してカウントを追跡することで、すべての数値の最大コストを計算できます。`k`で`O(n log n)`時間。 このアプローチでは、すべてのサブセットを個別にチェックすることを回避し、1 から 2 までの整数の順序付けされた構造を利用します。`n`。

 ## アルゴリズムのチュートリアル

 1. 配列を初期化する`red_count`サイズの`n+1`ゼロに。 この配列は、各整数で割り切れる赤い数字の数を追跡します。 
2. のために`k`1から`n`を選択し、`k`最大の数値は赤になります。 数字は1からなので、`n`、これは単にセットです`{n, n-1, ..., n-k+1}`。 
3. 赤い数字ごとに`y`、約数を反復処理します`x`より小さいもの`y`。 約数ごとに増分します`red_count[x]`by 1。これは、潜在的なそれぞれの青い数値で割り切れる赤い数値の数を追跡します。 
4. 与えられた条件に対して`k`、合計コストを計算します。`red_count[x]`すべての数字に対して`x`赤として選択されていないもの。 これはすべて有効なものをカウントします`(blue, red)`ペア。 
5. すべてに対してこのプロセスを繰り返します`k`1から`n`、結果を出力配列に保存します。 

機能する理由: 各ステップで、最大の数字を赤として選択することで、それぞれの小さな数字 (潜在的な青) が相互作用できる赤の倍数の数を最大化します。 除数を事前に計算すると、有効な各ペアが 1 回だけカウントされることが保証されます。 不変条件というのは、`red_count[x]`常に割り切れる赤い数字の数と等しくなります`x`現在のために`k`したがって、青い数字を合計すると最大コストが生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    result = [0] * n

    # Track counts of red multiples for each number
    red_count = [0] * (n + 1)

    # Generate cost for each k
    for k in range(1, n + 1):
        # The new red number is n - k + 1
        y = n - k + 1
        # Update divisors
        for x in range(1, int(y**0.5) + 1):
            if y % x == 0:
                red_count[x] += 1
                if x != y // x:
                    red_count[y // x] += 1
        # Calculate cost: sum over blue numbers (numbers < n-k+1)
        cost = sum(red_count[1:n-k+1])
        result[k-1] = cost

    print(" ".join(map(str, result)))

if __name__ == "__main__":
    main()
```このコードは高速 I/O を使用し、すべての赤と青のペアにわたるネストされたループを回避します。 効率を維持するために、除数は平方根ループを使用して計算されます。 青い数字のみを合計すると、有効なペアのみがカウントされることが保証されます。

 ## 特殊なケース
