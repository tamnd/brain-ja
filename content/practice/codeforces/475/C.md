 ## 解決策
 ## 問題の理解

 いくつかのセルがマークされているグリッドが与えられます`X`。 これらは少なくとも 1 回ペイントされたセルです。 

もともとは、サイズの長方形のブラシ`h × w`グリッドのどこかに配置されました。 その後、何度かブラシを動かしました。 すべての移動は、右または下に 1 セル正確に行われました。 ブラシは決して回転せず、その長方形全体が常にボードの内側に留まりました。 

最終的に描かれた絵は、その単調なパス中に訪れたすべてのブラシ位置の結合です。 

私たちの仕事は、与えられた画像がこの方法で生成されたかどうかを判断することです。 可能であれば、可能な限り最小限のブラシ領域が必要です。 

グリッドの寸法は最大でも`1000 × 1000`, したがって、最大 100 万個のセルが存在する可能性があります。 多数の候補ブラシ サイズを求めてグリッド全体を繰り返しスキャンするアルゴリズムは、遅すぎます。 周りに何か`O(nm)`快適ですが、`O(n²m)`または`O(nm²)`すでに限界をはるかに超えています。 

最初の微妙な観察は、左上のペイントされたセルが非常に特別であるということです。 ブラシは左にも上にも移動しないため、そのセルは初期ブラシ位置の左上隅である必要があります。 

よくある間違いは、両方のブラシの寸法が独立して変化する可能性があると想定することです。 それはできません。 

考慮する：```
XX..
XX..
XXXX
XXXX
```最初にペイントされた行には、連続する 2 つの行が正確に含まれています。`X`細胞。 一番最初の動きが下向きだった場合、ブラシの幅は強制的に次のようになります。`2`なぜなら、後で一番上の行を拡張することはできないからです。 

対称的なステートメントは高さにも当てはまります。 

もう 1 つの簡単な罠は、純粋な長方形です。```
....
.XXX
.XXX
....
```答えは必ずしも長方形の領域全体であるとは限りません`6`。 

あ`1 × 3`ブラシを一度下に移動してもまったく同じ絵が作成されるため、正解は`3`。 

最後の厄介なケースは次のとおりです。```
XXXX.
XXXX.
.XX..
.XX..
```2 つの長方形が重なり合っているように見えますが、単調な右/下ブラシ パスでは生成できません。 正しい出力は次のとおりです。```
-1
```ローカルの四角形のプロパティのみをチェックするソリューションでは、この画像が誤って受け入れられます。 

## アプローチ

 ブルートフォースのアイデアは単純です。 

ブラシの高さと幅を選択します。 考えられるすべての右/下の移動シーケンスをシミュレートし、結果として描画されたセルが入力と一致するかどうかを確認します。 

これはステートメントからプロセスを直接モデル化しているため、明らかに正しいです。 

問題は可能性の数です。 まであります`1000`高さの選択肢と、`1000`幅の選択肢。 単一の候補をチェックするだけでも、グリッドの大部分をスキャンする必要があります。 最悪の場合の操作数は許容範囲をはるかに超えて爆発的に増加します。 

重要な観察は、最初にペイントされたセルが 1 つのブラシの寸法を即座に修正することです。 

させて`(sx, sy)`最初になる`X`行優先の順序で。 

連続で見てください`X`から右に伸びている細胞`(sx, sy)`。 この値を呼び出します`W`。 

連続で見てください`X`～から下に伸びる細胞`(sx, sy)`。 この値を呼び出します`H`。 

最初のブラシの移動が下向きの場合、ブラシの幅は正確に一致する必要があります。`W`。 

最初のブラシの移動が右方向の場合、ブラシの高さは正確に一致する必要があります。`H`。 

意味のあるケースはこれら 2 つだけです。 

1 つの次元が固定されると、一連の動作は基本的に強制的なものになります。 すべてのステップにおいて、安全な方向は 1 つだけです。 間違った方向に移動すると、一部のペイントされたセルに永久にアクセスできなくなります。 

これにより、検索スペースが数千のブラシ サイズから 2 つの候補のみに減ります。 

候補ごとに、可能な固有の移動パスを貪欲に再構築し、不足しているブラシの寸法を特定し、グリッドを再描画して、描画されたすべてのセルが元の画像と一致することを確認します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²m²) 以上 | O(nm) | 遅すぎる |
 | 最適 | O(nm) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 左上のペイントされたセルを見つけます。`(sx, sy)`。 
2. コンピューティング`W`、連続数`X`から始まる右のセル`(sx, sy)`。 
3. コンピューティング`H`、連続数`X`から始まる下向きのセル`(sx, sy)`。 
4. 画像にペイントされたセルが 1 つだけ含まれているという特殊なケースを処理します。 答えは`1`。 
5. 「最初の手がダウン」シナリオを試してください。 

この場合、ブラシの幅は次のように固定されます。`W`。 

から始まる`(sx, sy)`、唯一の有効な動きシーケンスを再構築します。 ペイントされたセルを見逃さないように右に移動する必要がある場合は、必ず右に移動してください。 それ以外の場合は下に移動します。 

この再構築中に、ペイントされたすべてのセルと一致する最小ブラシの高さを決定します。 
6. その再構築によって生成されたすべてのブラシ位置を再ペイントします。 

ペイント結果が入力画像と同じである場合は、ブラシ領域を記録します。 
7. 「最初の動きが正しい」シナリオに対して対称手順を繰り返します。 

今回はブラシの高さは固定です`H`。 
8. 2 つの候補の中から最小の有効領域を選択します。 
9. どちらの候補者も画像を正確に再現できない場合は、印刷します。`-1`。 

### なぜ効果があるのか

 ブラシは左または上に移動しないため、最初にペイントされたセルは最初のブラシ コーナーである必要があります。 

そこから先手は下か、先手は右のどちらかになります。 それらが唯一の可能性です。 一番上の行または左の列を後から拡張することはできないため、各可能性は 1 つのブラシの寸法を即座に修正します。 

1 つの次元が固定されると、あらゆる動作の決定が強制されます。 方向を選択した後にペイントされたセルに到達できなくなる場合、その方向は無効です。 貪欲な再構築は常に、残りのペイントされたセルすべてに到達できるようにする唯一の方向に従います。 

したがって、再構築されたパスは一意になります。 そのパスを再描画すると画像が正確に再現される場合、ブラシは有効です。 そうしないと、その固定寸法のブラシは機能しません。 

すべての有効な絵画は 2 つの初動ケースのいずれかに属している必要があるため、両方のケースをチェックするだけで十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    sx = sy = -1
    cnt = 0

    for i in range(n):
        for j in range(m):
            if g[i][j] == 'X':
                cnt += 1
                if sx == -1:
                    sx, sy = i, j

    if cnt == 1:
        print(1)
        return

    W = 0
    while sy + W < m and g[sx][sy + W] == 'X':
        W += 1

    H = 0
    while sx + H < n and g[sx + H][sy] == 'X':
        H += 1

    ans = float('inf')

    def check(width_fixed):
        vis = [[False] * m for _ in range(n)]

        x, y = sx, sy

        if width_fixed:
            w = W

            h = 0
            while x + h < n and g[x + h][y] == 'X':
                h += 1

            while True:
                for i in range(x, x + h):
                    for j in range(y, y + w):
                        if i >= n or j >= m:
                            return None
                        vis[i][j] = True

                right = (y + w < m and g[x][y + w] == 'X')
                down = (x + h < n and g[x + h][y] == 'X')

                if right:
                    y += 1
                elif down:
                    x += 1
                else:
                    break

        else:
            h = H

            w = 0
            while y + w < m and g[x][y + w] == 'X':
                w += 1

            while True:
                for i in range(x, x + h):
                    for j in range(y, y + w):
                        if i >= n or j >= m:
                            return None
                        vis[i][j] = True

                right = (y + w < m and g[x][y + w] == 'X')
                down = (x + h < n and g[x + h][y] == 'X')

                if down:
                    x += 1
                elif right:
                    y += 1
                else:
                    break

        for i in range(n):
            for j in range(m):
                if (g[i][j] == 'X') != vis[i][j]:
                    return None

        return h * w

    a = check(True)
    if a is not None:
        ans = min(ans, a)

    b = check(False)
    if b is not None:
        ans = min(ans, b)

    print(-1 if ans == float('inf') else ans)

solve()
```最初の部分では、左上のペイントされたセルを特定し、そこから始まる最大の水平ランと垂直ランを計算します。 

これら 2 つの実行が固定次元の唯一の候補です。 有効なブラシはすべて、これら 2 つのケースのいずれかに属している必要があります。 

の`check`関数は 1 つのケースの動作シーケンスを再構築します。 次の動きが残りのペイントされたセルのジオメトリによって強制されるため、再構成は貪欲です。 

すべてのブラシ位置を生成した後、コードはグリッドを次のように再描画します。`vis`。 

最終的な検証が重要です。 多くの誤った実装では、局所的な条件のみをチェックし、描かれた絵全体を比較することはありません。 完全な比較により、余分なセルが描画されておらず、必要なセルが欠落していないことが保証されます。 

最も一般的なバグの原因は、次の右または下への動きをチェックするときの境界条件です。 コードは、セルを読み取る前に、次の座標がグリッド内にあるかどうかを常に検証します。

 単一のペイントされたセルを考えてみましょう。```
1 1
X
```移動は必要ありません。 可能な限り最小のブラシはまさに`1 × 1`、したがって、答えは次のようになります。```

```アルゴリズムは、再構築ロジックの前にこれを検出します。

....
.XXX
.XXX
....
```外接する長方形には面積があります`6`、しかし、`2 × 1`ブラシを右に 2 回移動すると、同じ画像が生成されます。 

再構築では両方の初手シナリオをチェックし、エリアを正しく検出します。`2`。

4 5
XXXX.
XXXX.
.XX..
.XX..
```形状には、切断された幾何学的依存関係が含まれています。 ある時点で、ペイントされたセルに到達できないようにブラシを右と下の両方に移動する必要があります。

```最後の正確なグリッドの比較により、不正な画像の誤検出を防ぐことができます。
