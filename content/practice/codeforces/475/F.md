 ## 解決策
 ## 問題の理解

 私たちには、「メタ宇宙」の惑星を表す、無限の 2D グリッド上の一連の点が与えられています。 目標は、惑星のセットを空の行または列に沿って繰り返し分割し、セットを 2 つの空でないサブセットに完全に分離し、それぞれが行または列の片側に位置するようにすることです。 行または列は、惑星が含まれておらず、その両側に惑星がある場合にのみ分割に使用できます。 考えられるすべての分割を実行した後、残りの惑星のセットは「宇宙」と呼ばれ、それらを数えるように求められます。 

入力は、最大 100,000 個の惑星で構成され、座標は ±10^9 までの大きさになる可能性があります。 グリッドは事実上無限であるため、これにより、グリッド全体をスキャンしたり、考えられるすべての分割を直接試行したりするアルゴリズムは即座に除外されます。 どのソリューションも点のセット自体を操作し、空のスペースを個別に考慮することを避ける必要があります。 エッジ ケースには、同じ行または列に並んだ惑星のセット、単一惑星の宇宙、または複数の分割が可能だが宇宙を二重に数えてはいけない構成が含まれます。 

不注意な実装では、x 値と y 値の最小値と最大値の間のすべての座標を反復処理して分割をシミュレートしようとする可能性がありますが、分割が間違った順序で適用された場合、パフォーマンスとユニバースが失われるリスクの両方により失敗します。 たとえば、座標 (0,0)、(0,2)、(2,0)、(2,1)、(2,2) に惑星があるメタユニバースは、1 回の分割で複数の惑星を含む可能性があるため、3 回分割して 4 つではなく 3 つのユニバースを生成する必要があります。 

## アプローチ

 ブルートフォースアプローチは、あらゆる垂直方向と水平方向の分割を試みることです。 最小 x から最大 x まで空の列をスキャンし、各候補列の両側に惑星が存在するかどうかを確認します。 同様に、行の最小 y から最大 y までをスキャンします。 このアプローチは正しいですが、潜在的な分割線のスキャンには O(座標範囲) の操作が含まれるため、非常に時間がかかります。これは、座標が ±10^9 になる可能性があることを考えると実行不可能です。 スキャンを惑星を含む座標に限定したとしても、分割を再帰的に適用すると、最悪の場合でも O(n^2) の動作が発生します。これは、各分割で残りのすべての惑星をスキャンして、それらがどちらかの側にあるかを確認する必要があるためです。 

重要な洞察は、分割はソートされた x 座標または y 座標のギャップに沿ってのみ発生する可能性があるということです。 惑星を x でソートし、このソートされたリストの接頭語と接尾語の最小値と最大値 y を追跡すると、惑星を 2 つの空でないセットに分ける 2 つの x 座標間に垂直線が存在するかどうかをすぐに識別できます。 同様に、y でソートすると、水平方向の分割をチェックできます。 これにより、問題は、無限のグリッドをスキャンする代わりに境界を追跡する、ソートされた点のリストに対する再帰的な分割統治に帰着します。 すべての再帰呼び出しはセットを分割し、サブセットの境界ボックスを比較することによって垂直または水平の分割が可能かどうかを確認します。 分裂が不可能であれば、私たちは宇宙に到達したことになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

1. すべての惑星を (x, y) タプルのリストとして保存します。 これは、再帰的に分割する基本データ構造です。 
2. 惑星とその境界ボックス (min_x、max_x、min_y、max_y) のリストを受け取る再帰関数を定義します。 リストに惑星が 1 つだけ含まれている場合は、1 つの惑星がすでに宇宙であるため、1 を返します。 
3. 惑星のリストを X 座標で並べ替えます。 最小および最大の y 座標のプレフィックス配列とサフィックス配列を計算します。 連続する惑星のペアごとに、それらの間に垂直方向の分割があるかどうかを確認します。左側のサブセットの最大 y が右側のサブセットの最小 y より小さい場合、またはその逆の場合、分割は有効です。 有効な分割が見つかった場合は、左と右のサブセットで関数を再帰的に呼び出し、両側からのユニバースの合計を返します。 
4. 垂直分割が不可能な場合は、y 座標によるソート、x のプレフィックス配列とサフィックス配列の計算、および有効な水平分割のチェックというプロセスを繰り返します。 
5. 垂直分割も水平分割も不可能な場合は、このサブセットがユニバースを形成するため 1 を返します。 
6. 元の惑星リストに対して再帰関数を呼び出します。 戻り値はユニバースの総数です。 

機能する理由: ソートされた順序で境界ボックスのみを追跡することにより、無限グリッドをスキャンすることなく分割が可能かどうかを効率的にチェックできます。 分割するたびに、惑星は空ではなく重複しない 2 つのセットに分割されます。 各分割によりセットのサイズが厳密に縮小されるため、再帰は終了します。 境界ボックスは、分割が見逃されないことを保証し、分割が不可能になった場合、サブセットはユニバース条件を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(1 << 20)

def count_universes(planets):
    if len(planets) == 1:
        return 1

    planets_x = sorted(planets, key=lambda p: p[0])
    n = len(planets_x)
    pref_ymin = [0] * n
    pref_ymax = [0] * n
    suff_ymin = [0] * n
    suff_ymax = [0] * n

    pref_ymin[0] = pref_ymax[0] = planets_x[0][1]
    for i in range(1, n):
        pref_ymin[i] = min(pref_ymin[i-1], planets_x[i][1])
        pref_ymax[i] = max(pref_ymax[i-1], planets_x[i][1])
    
    suff_ymin[-1] = suff_ymax[-1] = planets_x[-1][1]
    for i in range(n-2, -1, -1):
        suff_ymin[i] = min(suff_ymin[i+1], planets_x[i][1])
        suff_ymax[i] = max(suff_ymax[i+1], planets_x[i][1])
    
    for i in range(n-1):
        if pref_ymax[i] < suff_ymin[i+1] or pref_ymin[i] > suff_ymax[i+1]:
            return count_universes(planets_x[:i+1]) + count_universes(planets_x[i+1:])
    
    planets_y = sorted(planets, key=lambda p: p[1])
    pref_xmin = [0] * n
    pref_xmax = [0] * n
    suff_xmin = [0] * n
    suff_xmax = [0] * n

    pref_xmin[0] = pref_xmax[0] = planets_y[0][0]
    for i in range(1, n):
        pref_xmin[i] = min(pref_xmin[i-1], planets_y[i][0])
        pref_xmax[i] = max(pref_xmax[i-1], planets_y[i][0])
    
    suff_xmin[-1] = suff_xmax[-1] = planets_y[-1][0]
    for i in range(n-2, -1, -1):
        suff_xmin[i] = min(suff_xmin[i+1], planets_y[i][0])
        suff_xmax[i] = max(suff_xmax[i+1], planets_y[i][0])
    
    for i in range(n-1):
        if pref_xmax[i] < suff_xmin[i+1] or pref_xmin[i] > suff_xmax[i+1]:
            return count_universes(planets_y[:i+1]) + count_universes(planets_y[i+1:])
    
    return 1

n = int(input())
planets = [tuple(map(int, input().split())) for _ in range(n)]
print(count_universes(planets))
```このソリューションは、x 次元と y 次元の両方で再帰的な境界ボックス チェックを実装します。 プレフィックス配列とサフィックス配列は最小値と最大値を効率的に追跡し、リストの繰り返しスキャンを回避します。 惑星間で厳密に分割するように注意する必要があるため、チェックには i および i+1 インデックスが使用されます。
