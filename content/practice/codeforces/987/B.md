 ## 解決策
 ## 問題の理解

 2 つの正の整数が与えられます$x$そして$y$、そして 2 つの指数の値を比較するように求められます。$x^y$そして$y^x$。 これらの値は、中程度の入力でも天文学的に大きくなる可能性があるため、タスクはこれらの値を直接計算することではなく、どちらが大きいか、または等しいかどうかを判断することです。 

入力は 2 つの塩基を表します。 各基数は他の基数で累乗され、結果の値の順序を決定する必要があります。 出力は、最初の式が 2 番目の式より小さいか、大きいか、または等しいかを示す単一の比較記号です。 

制約$1 \le x, y \le 10^9$権力の直接の計算を直ちに排除します。 たとえ小さな値であっても、$x = y = 10^9$、関係する数値は、あらゆる数値タイプをはるかに超えています。 正しい解決策は構築を避ける必要があります$x^y$または$y^x$代わりに、代数的推論を使用してそれらを明示的に比較します。 

次のいずれかの場合に、微妙なエッジケースが発生します。$x = 1$または$y = 1$。 もし$x = 1$、 それから$x^y = 1$、 その間$y^x = y$。 これにより、次の場合を除き、比較が簡単になります。$y = 1$同じように。 浮動小数点ログを使用しようとする単純なアプローチも、値が近い場合や対数変換で一方がゼロになる場合に精度の問題により失敗する可能性があります。 

もう 1 つの例外的なケースは次のような場合です。$x = y$。 この場合、両方の式は同一であるため、答えは等しい必要があります。 どのような変換方法でも、この正確な対称性を維持する必要があります。 

## アプローチ

 ブルートフォース解釈では両方の累乗を直接計算しますが、中間結果を保存することさえ不可能になります。 それぞれのべき乗には、次までの数値の乗算が含まれます。$10^9$そのため、実行時間は入力の大きさに応じて指数関数的に増加し、まったく実行不可能になります。 

重要な点は、指数関数の計算を避け、その対数を比較することです。 対数関数は厳密に増加しているため、次のように比較できます。$$x^y \quad \text{and} \quad y^x$$比較して:$$y \cdot \ln x \quad \text{and} \quad x \cdot \ln y$$この変換により、問題はテスト ケースごとの定数時間の算術演算に縮小されます。 ただし、浮動小数点比較では、値が非常に近い場合に不安定が生じる可能性があります。 より堅牢なアプローチでは、構造的なケースを個別に処理することで浮動小数点を完全に回避します。 

機能を分析します$f(x) = \frac{\ln x}{x}$。 比較$x^y$対$y^x$比較するのと同じです$\frac{\ln x}{x}$そして$\frac{\ln y}{y}$。 この機能は次のように減少します。$x \ge 3$、特別な小さなケース付き$1$そして$2$。 この単調性構造により、ケースベースの明確な比較が可能になります。 

大きな値の場合、順序は主に、数値の 1 つが次の値であるかどうかによって決まります。$1$または$2$、これらは単調なパターンを壊すためです。 

エッジ推論により完全なルールが得られます。 

もし$x = y$、答えは平等です。 

もし$x = 1$、そうでない限り、常に小さくなります。$y = 1$。 

もし$y = 1$、そうでない限り、常に大きくなります。$x = 1$。 

どちらでもない場合$1$、既知の順序を使用して比較します。$2^3 = 8$そして$3^2 = 9$与える$2^3 < 3^2$、その間$x, y \ge 3$、関数$\ln x / x$減少しているため、より大きな塩基が特定の方向に優勢になります。 

これにより、浮動小数点演算を行わない直接比較ロジックが実現します。

 ## アルゴリズムのチュートリアル

 1. 整数の読み取り$x$そして$y$。 比較は対称であるため、引数を交換しても正確さが変わることはありません。 
2. もし$x = y$、両方の式が同一であるため、すぐに「=」を出力します。 
3. もし$x = 1$、そうでない場合は「<」を出力します。$y = 1$。 これは以下から導き出されます$1^y = 1$そして$y^1 = y$。 
4. もし$y = 1$、「>」を出力します。$x^1 = x$そして$1^x = 1$、 そして$x \ge 1$。 
5. 残りのすべてのケースについて、比較します。$x$そして$y$。 もし$x > y$の場合は「>」を出力し、それ以外の場合は「<」を出力します。 

最後のステップは、1 より大きい整数の場合、関数が機能するため機能します。$x^y$変換下でこの順序を維持する方法で、指数は底よりも速く成長します。$x^y \leftrightarrow y^x$ただし、先に処理した特殊な場合は除きます。 

### なぜ効果があるのか

 比較は関数による順序付けに帰着します$g(x) = \frac{\ln x}{x}$、これは厳密に減少しています$x \ge 3$。 したがって、すべての十分に大きな値について、次の不等式は次のようになります。$x^y$そして$y^x$かどうかのみに依存します$g(x)$より大きい$g(y)$。 単調性の違反のみが発生するのは、$x = 1$そして$x = 2$、明示的に処理されます。 これにより、一貫した合計順序が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

x, y = map(int, input().split())

if x == y:
    print("=")
elif x == 1:
    print("<")
elif y == 1:
    print(">")
else:
    if x > y:
        print(">")
    else:
        print("<")
```この実装は構造的なケース分析を反映しています。 同一の入力が特殊なケースとして誤って分類されることを避けるために、等価性チェックが最初に行われます。 取り扱い$x = 1$そして$y = 1$next は、べき乗が定数値に崩壊する唯一の状況を分離します。 最終的な比較では、単純な整数の順序付けが使用されます。これは、すべての病理学的ケースがすでに削除されているため安全です。 

浮動小数点演算は使用されないため、精度エラーが防止され、極端な値でも正確さが保証されます。

 ## 特殊なケース

 入力用$1, 1$の場合、アルゴリズムは直ちに等価性チェックを実行し、特殊な場合のロジックを入力せずに「=」を返し、両方の式が 1 に等しいという事実と一致します。 

のために$1, y$大きい$y$、小切手`x == 1`'<' をトリガーして出力し、正しく反映します$1^y = 1 < y = y^1$。 逆の場合$x, 1$対称分岐をトリガーし、一致する「>」を出力します。$x^1 = x > 1$。
