 ## 解決策
 ## 問題の理解

 整数座標を持つ 2D グリッド上の雪の吹きだまりのセットが与えられます。 Bajtek は、X 軸または Y 軸に沿った直線でのみ移動でき、あるドリフトから別のドリフトにぶつかるまでスライドします。 言い換えれば、2 つの雪の吹きだまりは、同じ x 座標または同じ y 座標を共有する場合に接続されます。 Bajtek は、任意の 2 つの雪の吹きだまりの間を直接的または間接的に移動できるようにしたいため、これらの移動ルールに基づいてセットを完全に接続するには、最小限の数の新しい雪の吹きだまりを追加する必要があります。 

入力は既存のドリフトの数を示します$n$(最大 100) とその座標。 出力は単一の整数、つまりすべての既存のドリフトを接続するために必要な追加ドリフトの最小値です。 の小さな値$n$ことを示します$O(n^2)$これにより、接続性を決定する際にドリフトのすべてのペアを考慮できるようになります。 

ドリフトが孤立したクラスター内にある場合、微妙な点が生じます。 たとえば、(1,1) と (2,2) に 2 つのドリフトがある場合、それらは直接相互に到達できません。 (1,2) または (2,1) にドリフトを 1 つ追加すると、それらが接続されます。 不用意なアプローチでは、ペアごとの直接の移動のみを考慮しようとしたり、対角の隣接関係が機能すると仮定したりする可能性があり、この場合、不正確な答えが 0 になります。 

もう 1 つのエッジ ケースは、すべてのドリフトが同じ行または列にある場合です。 たとえば、(1,1)、(1,2)、(1,3) の 3 つのドリフトはすでに 1 つの連結成分を形成しているため、新しいドリフトは必要ありません。 これを誤解すると、不必要なドリフトが追加される可能性があります。 

## アプローチ

 強引な方法では、グリッドが接続されるまで、x 方向と y 方向の両方で 1 ～ 1000 のすべての整数座標に新しいドリフトを配置しようとします。 これは非現実的です。$n = 100$、可能な配置数は次のとおりです。$10^6$接続を繰り返し確認するとコストがかかります。 

重要な洞察は、雪の吹きだまりをグラフとして表示することで得られます。各吹きだまりはノードであり、ノードが同じ x または y 座標を共有する場合、ノード間にエッジが存在します。 次に、問題は、このグラフ内の連結成分の数を見つけることになります。 接続されている各コンポーネントはすでに内部的に到達可能です。 接続するには$k$コンポーネントを単一の接続されたネットワークに統合するには、正確に必要です$k-1$新しいドリフトはそれぞれ 2 つのコンポーネントをブリッジできるため、追加のドリフトが必要になります。 これは、ネットワーク内の別々のアイランドを接続することに似ています。$k$島々を一つに、$k-1$橋は十分であり必要です。 

これを理解すると、解決策は簡単になります。グラフを作成し、連結成分を数え、1 を引くと答えが得られます。

 | --- | --- | --- | --- |
 | ブルートフォース | O((1000*1000)^n) | O(1000*1000) | 遅すぎる |
 | グラフ + DFS/BFS | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各雪の吹きだまりをグラフ内のノードとして表します。 2 つのノードは、X 座標または Y 座標が一致する場合に接続されます。 これにより、スライド移動の制約が正確にモデル化されます。 
2. 訪問された配列を初期化して、どのドリフトが調査されたかを追跡します。 
3. 各ドリフトを繰り返します。 ドリフトがまだ訪問されていない場合は、そのドリフトから深さ優先検索 (DFS) を開始して、到達可能なすべてのドリフトをマークします。 各 DFS 呼び出しは、単一の接続コンポーネントを識別します。 
4. 手順 3 で検出された接続コンポーネントの総数を数えます。 
5. 必要な追加ドリフトの最小数は、接続されたコンポーネントの数から 1 を引いたものです。 新しいドリフトごとに 2 つのコンポーネントを接続できるため、$k-1$ドリフト接続$k$コンポーネントを 1 つにまとめます。 

機能する理由: DFS は、有効な移動に沿って、指定された開始ドリフトから到達可能なすべてのドリフトを正しく検出します。 定義上、各 DFS トラバーサルは 1 つの接続されたコンポーネントを正確にマークします。 新しいドリフトはそれぞれ 2 つのコンポーネントを正確にブリッジできるため、接続$k$コンポーネントに必要なもの$k-1$追加のドリフトにより、最小性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10000)

def main():
    n = int(input())
    drifts = [tuple(map(int, input().split())) for _ in range(n)]
    
    graph = [[] for _ in range(n)]
    for i in range(n):
        for j in range(i + 1, n):
            if drifts[i][0] == drifts[j][0] or drifts[i][1] == drifts[j][1]:
                graph[i].append(j)
                graph[j].append(i)
    
    visited = [False] * n
    
    def dfs(u):
        visited[u] = True
        for v in graph[u]:
            if not visited[v]:
                dfs(v)
    
    components = 0
    for i in range(n):
        if not visited[i]:
            dfs(i)
            components += 1
    
    print(components - 1)

if __name__ == "__main__":
    main()
```隣接リストの構築により、各ドリフトが x または y を共有する他のすべてのドリフトに確実に接続され、合法的な動きを直接モデル化します。 DFS は、開始ドリフトから到達可能なすべてのドリフトをマークし、各コンポーネントが 1 回カウントされることを保証します。`components - 1`すべてのコンポーネントを接続するための追加ドリフトの最小数を与えます。 すべてのドリフトが単一の線形チェーンを形成する場合、DFS で最悪の場合の深さを処理するために再帰制限を増やします。

## 複雑さの分析

## 特殊なケース

 シングルドリフトの場合`(5,5)`, DFS はそのノードを訪問しますが、近隣ノードは見つかりません。 コンポーネント = 1、出力 = 0。1 つの行または列に沿って整列されたドリフトの場合、DFS はすべてのノードを正しくマークするため、コンポーネント = 1、出力 = 0。複数の分離されたクラスターが存在する場合、DFS はそれぞれを個別に検出し、`components - 1`必要な接続ドリフトの正確な数をカウントします。 重複する x または y 座標の場合、隣接リストの構築により、考えられるすべての正当な動きが表現されることが保証されます。
