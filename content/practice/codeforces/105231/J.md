 ## 解決策
 ## 問題の理解

 私たちには、28 文字の文字列としてエンコードされた 14 枚のタイルで構成される、麻雀の複数の独立した手が与えられています。 各タイルは値とスーツまたは名誉マーカーとして書き込まれるため、各タイルは入力内でちょうど 2 文字を占めます。 私たちのタスクは、各ハンドを 3 つのカテゴリのいずれかに分類することです。特別な「13 人の孤児」ハンド、「7 ペア」ハンド、またはそのどちらでもないハンドです。 

ハンドが正確に 7 つの異なるタイル タイプで構成され、それぞれのタイルが正確に 2 回出現する場合、そのハンドは有効な「7 ペア」となります。 順序は重要ではなく、多重度だけが重要です。 

必要なすべての「ターミナルと名誉」タイルが含まれており、それらのタイルのいずれか 1 つの追加の複製が 1 つある場合、ハンドは有効な「13 人の孤児」です。 ターミナル セットは各スートの極端な番号のタイルで構成され、栄誉はすべて風タイルとドラゴン タイルです。 合計 13 個の必要な個別のタイルがあり、有効なハンドにはそれぞれのタイルが少なくとも 1 回含まれている必要があり、そのうちの 1 つが 2 回出現するため、合計サイズは 14 になります。 

各テスト ケースは小さく、ハンドは最大 1000 個で、各ハンドは固定サイズの 14 タイルです。 これにより、高度なデータ構造や漸近的に高価な検索の必要性が即座に排除されます。 自然な操作は、一定サイズの麻雀牌の固定アルファベットにわたる頻度をカウントすることです。 両手を 1 回か 2 回スキャンするソリューションであればどれでも十分です。 

単純なアプローチの主な失敗例は、構造要件の誤解から生じます。 

よくある間違いの 1 つは、必要なタイル タイプがすべて存在することを確認せずに、ハンドに 13 人の孤児の 13 枚の異なるタイルがあることだけを確認することです。 たとえば、9m の欠落を除くすべての 1p 重複と同様のハンドは、不用意に実装されると「個別カウント」チェックを誤ってパスしてしまいます。 

もう 1 つの微妙な問題は条件の混合です。7 ペアのハンドでは、たとえ全長が 14 であってもタイルを 3 回または 4 回出現させることはできません。たとえば、1p のコピーが 4 枚と他のタイルの 3 ペアのようなハンドには 7 つの異なるタイプがありますが、1 つのタイルが多重度 2 を超えているため無効です。 

最後に、チェックが間違っていれば理論上、ハンドは両方の条件を満たす可能性がありますが、正しい麻雀ルールでは、これらのカテゴリは適切に適用されると互いに素になるため、実装では近似条件ではなく正確に一致する条件を優先する必要があります。 

## アプローチ

 ブルートフォース解釈では、セットを構築し、手動で条件をチェックすることによって、各ルールを明示的に検証しようとします。 7 ペアの場合、すべてのタイルを抽出して並べ替え、同一のものをグループ化し、各グループのサイズが 2 であり、グループが 7 つあることを確認できます。 これはすでに手のサイズに比例しており、十分に十分です。 

13 人の孤児の場合、単純なアプローチでは、サイズ 13 のすべてのサブセットをチェックするか、テンプレートに対して順列を検証する可能性があります。 これは不必要に複雑になりますが、手のサイズが固定されているため、それでも一定のままです。 ただし、これでは重要な簡略化が欠けています。つまり、構造は純粋に周波数ベースであり、必要なセットが固定されています。 

重要な観察は、どちらの条件も完全に各タイルの出現をカウントすることになるということです。 タイルの世界は小さくて固定されているため、すべてのタイルを整数 ID にマッピングし、周波数配列を維持できます。 その後、両方のチェックがその頻度配列に対する直接の述語になります。 

7 ペアの場合、正確に 7 つの異なるキーの頻度が 2 であり、他のすべてのキーが 0 であることを確認するだけで済みます。 

13 人の孤児の場合、必要なタイルのセットを事前に定義します。 必要な各タイルが少なくとも 1 回出現することを確認し、次にそのうちの 1 つだけが 2 回出現し、他のすべてのタイルが 1 回出現し、セットの外に余分なタイルが存在しないことを検証します。 

これにより、各テスト ケースが一定のアルファベットに対する O(1) 作業に削減されます。

 ## アルゴリズムのチュートリアル

 ### 1. タイルをコンパクトな表現にエンコードする

 可能な各タイル文字列を次のようにマッピングします。`1p`、`9s`、`5z`整数インデックスに変換します。 これにより、文字列を比較せずに高速な頻度カウントが可能になります。 

### 2. 各ハンドの周波数配列を構築する

 28 文字の文字列を 2 のステップで繰り返し、対応する頻度バケットを増加させます。 

どちらの勝利条件も多重度パターンのみに依存するため、このステップは不可欠です。 

### 3. 7 ペアの状態を確認します。 

正確に 2 の頻度を持つ個別のタイルの数を数えます。この数が正確に 7 で、0 または 2 以外の頻度を持つタイルがない場合、そのハンドは有効な 7 ペアです。 

14 タイルすべてがペアのみで構成されることを明示的に強制し、トリプルまたはクアッドが誤って受け入れられることを防ぎます。 

### 4. 13 人の孤児の状態を確認する

 必要なタイル (13 個の固有のタイル) の固定ブール マスクを維持します。 2 つのプロパティを検証します。すべての必要なタイルが少なくとも 1 回表示される必要があり、そのうちの 1 つが 2 回表示される必要があります。 また、必要なセット以外のタイルがまったく表示されないことも保証します。 

これにより、13 個の固有の端末/名誉とその中の 1 つの重複という厳密な構造が強制されます。 

### 5. 優先順位によって出力を決定する

 「十三人の孤児」の条件が成立した場合、それを出力します。 それ以外の場合、7 ペアが成立する場合、それを出力します。 それ以外の場合は、「Otherwise」を出力します。 

### なぜ効果があるのか

 どちらの勝利条件も、固定された有限のタイル領域における正確な頻度パターンのみに依存します。 タイルをインデックスにマッピングすることで、各ハンドを周波数ベクトルに変換します。 チェックは、このベクトルに対する決定的な述語になります。 

7 ペアの場合、不変条件は、周波数マルチセットが正確に 7 つの 2 と残りのすべてが 0 でなければならないということです。 13 人の孤児の場合、不変条件は、周波数ベクトルのサポートが事前定義された 13 タイル セットと一致し、ちょうど 1 つのエントリが値 2 を持ち、セット内の他のすべてのエントリが値 1 を持つことです。これらの条件が定義を完全に特徴付けるため、構造的な曖昧さは残らず、順序付け情報も必要ありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

tiles = []

# build tile universe
suits = ['p', 's', 'm']
for s in suits:
    for i in range(1, 10):
        tiles.append(f"{i}{s}")
for i in range(1, 8):
    tiles.append(f"{i}z")

idx = {t:i for i, t in enumerate(tiles)}

orphans = set()
# terminals
for t in ["1p","9p","1s","9s","1m","9m"]:
    orphans.add(idx[t])
# honors
for i in range(1, 8):
    orphans.add(idx[f"{i}z"])

def check_7_pairs(freq):
    cnt_pairs = 0
    for f in freq:
        if f == 0:
            continue
        if f != 2:
            return False
        cnt_pairs += 1
    return cnt_pairs == 7

def check_orphans(freq):
    used = 0
    pair_found = False

    for i, f in enumerate(freq):
        if f == 0:
            continue
        if i not in orphans:
            return False
        if f == 2:
            if pair_found:
                return False
            pair_found = True
        elif f != 1:
            return False
        used += 1

    return used == 13 and pair_found

t = int(input())
for _ in range(t):
    s = input().strip()

    freq = [0] * len(tiles)

    for i in range(0, len(s), 2):
        tile = s[i:i+2]
        freq[idx[tile]] += 1

    if check_orphans(freq):
        print("Thirteen Orphans")
    elif check_7_pairs(freq):
        print("7 Pairs")
    else:
        print("Otherwise")
```このソリューションでは、まずタイル文字列からインデックスへの固定マッピングを構築し、すべてのタイル タイプが均一に処理されるようにします。 次に、入力文字列に対する 1 回のパスで周波数配列が埋められます。 

7 ペア チェックでは、アクティブなタイルごとに正確に 2 という厳密な多重度が適用され、そのようなタイルが正確に 7 つ存在することがカウントされます。 

「十三人の孤児」チェックでは、すべてのアクティブなタイルが事前定義されたセットに制限され、それらの間で重複が 1 つだけ確保され、他のタイルはすべて 1 回表示されます。 ブール値フラグは、1 つのタイルのみが周波数 2 を持つことを許可することを保証します。 

有効な 13 人の孤児ハンドが 7 ペアとして誤って分類されるべきではないため、決定順序は重要です。

## テストケース```python
import sys, io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    tiles = []
    suits = ['p','s','m']
    for s in suits:
        for i in range(1,10):
            tiles.append(f"{i}{s}")
    for i in range(1,8):
        tiles.append(f"{i}z")

    idx = {t:i for i,t in enumerate(tiles)}

    orphans = set()
    for t in ["1p","9p","1s","9s","1m","9m"]:
        orphans.add(idx[t])
    for i in range(1,8):
        orphans.add(idx[f"{i}z"])

    def ok7(f):
        c=0
        for x in f:
            if x==0: continue
            if x!=2: return False
            c+=1
        return c==7

    def ok13(f):
        used=0
        pair=False
        for i,x in enumerate(f):
            if x==0: continue
            if i not in orphans: return False
            if x==2:
                if pair: return False
                pair=True
            elif x!=1:
                return False
            used+=1
        return used==13 and pair

    t=int(input())
    out=[]
    for _ in range(t):
        s=input().strip()
        f=[0]*len(tiles)
        for i in range(0,len(s),2):
            f[idx[s[i:i+2]]]+=1
        if ok13(f):
            out.append("Thirteen Orphans")
        elif ok7(f):
            out.append("7 Pairs")
        else:
            out.append("Otherwise")
    return "\n".join(out)

 ## 特殊なケース

 微妙なエッジ ケースは、手にターミナル タイルと名誉タイルのみが含まれているが、必要な孤立タイルが 1 つ欠けている場合です。 周波数ロジックでは引き続き有効なタイル カテゴリのみが表示されますが、`used == 13`条件は失敗し、誤検知を防ぎます。 

もう 1 つのエッジ ケースは、タイルが 4 回出現する場合です。 これにより、両方の条件が即座に破棄されます。 7 ペアでは、厳密に 2 に等しいという要件に違反します。 Three Orphans では、1 つのタイルのみが周波数 2 を持つことができ、他のすべてのタイルは 1 でなければならないというルールに違反するため、タイルが許可されたセットに含まれていても拒否されます。 

3 番目のケースは、「十三人の孤児」の重複が孤立していないタイルで発生する場合です。 カウントが構造的に類似しているように見えても、事前定義された孤立セットに対するメンバーシップ チェックで拒否され、正確さが保証されます。
