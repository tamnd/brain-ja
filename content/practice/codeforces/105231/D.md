 ## 解決策
 ## 問題の理解

 一連の正の整数が与えられます。 シーケンス内の任意の 2 つの位置を繰り返し選択し、決定論的変換を使用してペアを置き換えることができます。一方の位置はペアの gcd になり、もう一方の位置はペアの lcm になります。 この操作は、任意の回数、任意の順序で適用できます。 

タスクは、これらの操作をシミュレートすることではなく、そのような操作のシーケンスを実行した後にすべての要素の合計の最大値を決定することです。 最終的な答えは 998244353 を法として指定する必要があります。 

各テスト ケースは独立しており、すべてのテスト ケースにわたって要素の総数が十分に大きいため、すべての解は合計入力サイズにおいて線形または線形演算に近くなければなりません。 

主要な構造上の制約は、gcd(a, b) · lcm(a, b) = a · b であるため、すべての演算で選択した 2 つの数値の積が保存されることです。 これは、値が個別に移動して変化する可能性がある一方で、配列全体にわたる素因数分解のレベルには厳格な保存則が存在することを直ちに意味します。 

素朴な解釈では、gcd と lcm を任意に繰り返し混合すると、多くの可能な状態が生じる可能性があることが示唆されますが、素指数の再配分方法に関する制約により、最終的な構成が実際にどのようなものになるかが厳しく制限されます。 

すべての数値が同一である場合、微妙な特殊なケースが発生します。 その場合、すべての操作で配列が変更されないままになり、「常に合計を改善できる」と仮定したソリューションでは、役に立たない変換が誤って試行されることになります。 もう 1 つの特殊なケースは、数値がペアごとに互いに素である場合です。 その場合、gcd は 1 になり、lcm は積になります。不注意な局所推論により、複数の操作にわたってこれをどこまで押し上げることができるかを過大評価する可能性があります。 

## アプローチ

 ブルートフォース解釈では、考えられるすべての操作シーケンスをシミュレートしようとします。 各演算はペアを選択し、それらを gcd と lcm に置き換えます。これを任意に繰り返すことができるため、整数ベクトルの巨大な状態空間を効果的に探索することになります。 n が小さい場合でも、分岐係数は各ステップで n² 程度であり、ステップ数に制限がないため、このアプローチは直ちに実行できません。 

重要な観察は、この演算が素指数のレベルで完全にローカルであるということです。 各数値を素数の積として記述する場合、任意の固定素数 p について、指数 x と y を持つ 2 つの数値の演算は、単純にそれらを min(x, y) と max(x, y) に置き換えます。 これは、各素数について独立して、指数のマルチセットが保存され、位置間でのみ再分配されることを意味します。 

したがって、プロセス全体が、素数ごとに 1 つずつ、独立した並べ替え問題に分解されます。 各素数 p について、配列全体のすべての指数を取得し、それらをインデックス間で自由に並べ替えることができます。 グローバル構造では、各インデックスは素数ごとに 1 つの指数を受け取りますが、それらの割り当てはすべて、そのインデックスで同じ最終数値を表すため、素数間で一貫している必要があります。 

次のステップは、これらの独立した並べ替えを組み合わせて、結果の数値の合計を最大化する方法を決定することです。 各要素の値は素数に対して乗算され、すべての素数が指数にプラスかつ独立して寄与するため、異なる素数にわたる大きな指数が同じインデックス上に整列すると、合計は最大化されます。 これはまさに、指数空間に適用される並べ替え不等式です。すべての素数の指数を降順で並べ替え、すべての素数の k 番目に大きい指数を同じ位置 k に割り当てます。 

これにより、最終的な配列の単一の一貫した構造が得られ、その後、すべての値を計算して合計します。

## アルゴリズムのチュートリアル

 入力の最大値を 10^6 までとします。 数値を効率的に因数分解できるように、最小素因数 (SPF) ふるいを事前に計算します。 

### 1. 素数指数バケットを構築する

 各数値を処理し、SPF を使用して因数分解します。 すべての素数 p について、その数値の指数を抽出し、それを p に関連付けられたリストに追加します。 これにより、素数ごとに、その素数が配列全体にどのように分布するかを説明するリストが得られます。 

これが機能する理由は、gcd/lcm 操作では異なる素数が決して混在しないため、問題全体を素数ごとに安全に分離できるためです。 

### 2. 指数リストを素数ごとに並べ替える

 各素数 p について、その指数リストを降順に並べ替えます。 

このステップは、この演算により各素数の指数を任意に並べ替えることができるため、ソートによって到達可能な完全な空間が記述されるという事実を反映しています。 

### 3. アライメントによる最終値の構築

 0 から n − 1 までのインデックスを繰り返します。各インデックス i について、すべての素数 p に対して p^(exponent[p][i]) を掛け合わせます。 

この位置合わせステップは重要な構造上の選択です。インデックス i はすべての素数から i 番目に大きい指数を収集し、大きな寄与が同じ数値に結合されることを保証します。 

### 4. 合計結果

 すべての再構築された値を 998244353 を法として合計します。 

### なぜ効果があるのか

 この演算は、指数ペア (x, y) を (min(x, y), max(x, y)) に変換します。これは、まさに 2 つの値に対する並べ替え演算です。 任意のペアにわたって繰り返し適用すると、各素数の指数マルチセットを個別に完全にソートできます。 

すべての有効な構成は、素数ごとにその指数マルチセットの順列を選択することに対応するため、残された唯一の自由度は、これらの順列が素数間でどのように配置されるかです。 積の和は、より大きな指数がすべての素数にわたって同じインデックスで一致するときに最大化されます。これは、ペアごとの交換引数から導き出されます。つまり、より大きな指数をすでに大きな積に交換すると、合計が増加し、このプロセスは完全な整列に収束します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAXV = 10**6

spf = list(range(MAXV + 1))
for i in range(2, int(MAXV**0.5) + 1):
    if spf[i] == i:
        for j in range(i * i, MAXV + 1, i):
            if spf[j] == j:
                spf[j] = i

def factor(x):
    res = {}
    while x > 1:
        p = spf[x]
        cnt = 0
        while x % p == 0:
            x //= p
            cnt += 1
        res[p] = cnt
    return res

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    prime_map = {}

    for v in a:
        f = factor(v)
        for p, c in f.items():
            if p not in prime_map:
                prime_map[p] = []
            prime_map[p].append(c)

    # ensure missing exponents are zeros implicitly handled later

    for p in prime_map:
        prime_map[p].sort(reverse=True)

    ans = 0

    # compute each index value
    for i in range(n):
        val = 1
        for p, arr in prime_map.items():
            if i < len(arr):
                val = val * pow(p, arr[i], MOD) % MOD
        ans = (ans + val) % MOD

    print(ans)
```SPF ふるいは一度構築され、テスト ケース全体で再利用されるため、因数分解が合計入力サイズに対して十分な速度を維持できるようになります。 

因数分解ステップでは、最小の素因数による繰り返し除算が使用され、数値ごとの対数動作が保証されます。 

辞書`prime_map`素数ごとの指数リストを保存します。 リストが n より短いため、一部のインデックスで素数の欠落寄与は暗黙的にゼロとして扱われます。 

最終的な再構成では、インデックスごとに素数の剰余べき乗を乗算します。 Python の組み込みのべき乗剰余演算を使用すると、このステップが効率的に保たれます。

 ## 特殊なケース

 特殊なケースの 1 つは、すべての数値が同一である場合です。 すべての素指数リストには同一のエントリが含まれるため、並べ替えても何も変わりません。 再構築された配列は入力と同一であり、不正なインフレーションは発生しません。 

もう 1 つの特殊なケースは、数値がペアごとに互いに素である場合です。 各数値は異なる素数に寄与するため、指数リストのサイズはほとんど 1 です。ソートでは依然として自明に位置合わせが行われ、再構成では同じ値の複数セットが得られるため、人為的な増幅が防止されます。 

最後のエッジケースは、一部の素数が非常に少数しか出現しない不均一な素数分布です。 その場合、欠落しているインデックスはゼロ指数として扱われるため、それらの素数は元の位置にのみ寄与し、アラインメント ステップによって余分な値が作成されることはありません。
