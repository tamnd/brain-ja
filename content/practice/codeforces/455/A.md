 ## 解決策
 ## 問題の理解

 整数の配列が与えられます。 1 回の操作で値を選択します`x`現在存在している、獲得する`x`1 つの出現とすべての出現を削除することでポイントが得られます。`x - 1`そして`x + 1`結果として配列から消えます。 

一見すると、この操作は配列内の個々の位置に依存しているように見えます。 実際には値のみに依存します。 その価値を決めるたびに`x`あらゆる出来事を受け入れる価値がある`x`1つを削除するため、最終的には収集できます`x`他のものは削除しません`x`価値観。 唯一の衝突は隣接する価値観との衝突です`x - 1`そして`x + 1`。 

入力には最大で次のものが含まれます`10^5`数字、そしてそれぞれの数字は最大で`10^5`。 さまざまな一連の動きを直接調査しようとする解決策は絶望的です。 二次アルゴリズムでも約`10^10`限界をはるかに超えた最悪の場合の動作。 線形に近いものが必要です。`O(M)`、 どこ`M`配列内に現れる最大値です。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

考慮する：```
3
2 2 2
```正しい答えは、`6`。 

不注意な解決策は、価値を選択することを考える可能性があります`2`だけを与える`2`ポイントは1回。 実際には、隣接する値が削除された後、次の 3 つの出現はすべて、`2`まだ取ることができます、`2 + 2 + 2 = 6`。 

考慮する：```
4
1 1 2 2
```正しい答えは、`4`。 

全部取って`1`が与えます`2`ポイント。 全部取って`2`が与えます`4`ポイント。 両方を採用することはできません。`1`そして`2`対立。 等しい値をグループ化するのではなく、オカレンスを独立して処理するソリューションでは、間違った結果が生成されます。 

考慮する：```
5
1 3 5 7 9
```正しい答えは、`25`。 

どの値も隣接していないため、すべての値を取得できます。 隣接する数値ではなく、隣接する配列の位置のみを比較するソリューションでは、これが見逃されます。 

## アプローチ

 最も直接的なアイデアは、考えられるすべての動きのシーケンスを考えることです。 各ステップで値を選択し、競合する値を削除し、再帰的に続行します。 これは、すべての法的結果を調査するものであるため、正しいです。 

問題は可能性の数です。 まで`10^5`要素を追加すると、検索スペースが膨大になります。 残りの値セットはさまざまに変化する可能性があるため、状態をメモ化することさえ現実的ではありません。 

重要な観察は、ポジションはまったく重要ではないということです。 値の頻度のみが重要です。 

値を仮定する`x`表示されます`cnt[x]`回。 value を使用することにした場合`x`、最終的には収集できます```
x * cnt[x]
```ポイント。 

その決断をした後の価値観は、`x - 1`そして`x + 1`利用できなくなります。 他には何も影響しません。 

これにより、問題ははるかに単純なものに変わります。 すべての整数値に対して`x`、私たちには「家」の価値があります```
points[x] = x * cnt[x]
```家に持って行けば`x`、家を取ることはできません`x - 1`または`x + 1`。 

これは、古典的な House Robber 動的計画法の問題とまったく同じ構造です。 

させて`dp[i]`の値を使用して取得できる最大スコアになります。`1`を通して`i`。 

価値のために`i`、可能性は2つだけです。 

飛ばしても答えは残る`dp[i - 1]`。 

それを取れば得られる`points[i]`そしてスキップしなければなりません`i - 1`、与える```
dp[i - 2] + points[i]
```したがって、繰り返しは次のようになります。```
dp[i] = max(
    dp[i - 1],
    dp[i - 2] + points[i]
)
```これにより、問題は値空間上の単純な線形動的プログラムに縮小されます。

 | ブルートフォース | 指数 | 指数 | 遅すぎる |
 | 最適なDP | お(お) | お(お) | 承認済み |

 ここ`M`入力に現れる最大値です。`100000`。 

## アルゴリズムのチュートリアル

 1. 配列を読み取ります。 
2. 各値が何回出現するかを数えます。 
3. あらゆる値について`x`、その合計寄与度を計算します。```
points[x] = x * cnt[x]
```価値を選ぶなら`x`、これは、すべての発生から獲得できる合計スコアです。`x`。 
4. しましょう`mx`配列内の最大値になります。 
5. サイズの DP 配列を作成します`mx + 1`。 
6. 以下を設定します。```
dp[0] = 0
dp[1] = points[1]
```7. あらゆる値について`i`から`2`に`mx`、次を計算します。```
dp[i] = max(
    dp[i - 1],
    dp[i - 2] + points[i]
)
```最初のオプションは値をスキップします`i`。 

2 番目のオプションは値を受け取ります`i`、だから価値がある`i - 1`は使用できません。 
8. 出力`dp[mx]`。 

### なぜ効果があるのか

 等しい数値をグループ化した後、すべての値`i`報酬を伴う独立した決定となる`points[i]`。 唯一の制限は、1 つ異なる値を両方選択できないことです。 

計算するとき`dp[i]`、値に対するすべての有効な解`1..i`どちらかを除外します`i`またはそれを含みます。 除外する場合`i`、ベストスコアはまさに`dp[i-1]`。 含まれている場合`i`、 それから`i-1`最高のスコアを残すために除外する必要があります`dp[i-2] + points[i]`。 これらが唯一の可能性であり、再発はより良い方を採用します。 

誘導により`i`、`dp[i]`常に、最大の値に対する最適な答えを保存します。`i`、 それで`dp[mx]`問題全体に対する最適な答えです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    mx = max(a)

    points = [0] * (mx + 1)
    for x in a:
        points[x] += x

    if mx == 1:
        print(points[1])
        return

    dp = [0] * (mx + 1)
    dp[1] = points[1]

    for i in range(2, mx + 1):
        dp[i] = max(dp[i - 1], dp[i - 2] + points[i])

    print(dp[mx])

if __name__ == "__main__":
    solve()
```最初のステージでは、すべての等しい値が集計されます。 周波数を個別に保存して後で乗算する代わりに、実装では直接累積します。`x`の中へ`points[x]`あらゆる出来事に対して。 配列を処理した後、`points[x]`すでに等しい`x * cnt[x]`。 

動的プログラミング配列には、元の配列内の位置ではなく、値によってインデックスが付けられます。 これがソリューションの中心となるアイデアです。 繰り返しは、前の 2 つの値の状態にのみ依存します。 

特別な取り扱いは、`mx == 1`アクセスを回避します`dp[1]`それ以外の場合、DP 配列のサイズは 1 になります。 これは、明示的な注意が必要な唯一の境界条件です。 

Python の整数は、大きな値を自動的に処理します。 可能な最大の答えは次のとおりです`10^10`、これは Python の整数型に簡単に適合します。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    n = int(input())
    a = list(map(int, input().split()))

    mx = max(a)

    points = [0] * (mx + 1)
    for x in a:
        points[x] += x

    if mx == 1:
        return str(points[1])

    dp = [0] * (mx + 1)
    dp[1] = points[1]

    for i in range(2, mx + 1):
        dp[i] = max(dp[i - 1], dp[i - 2] + points[i])

    return str(dp[mx])

# provided sample
assert run("2\n1 2\n") == "2", "sample 1"

# minimum size
assert run("1\n1\n") == "1", "single element"

# all equal values
assert run("5\n2 2 2 2 2\n") == "10", "all equal"

# adjacent conflict
assert run("4\n1 1 2 2\n") == "4", "must choose better side"

# non-adjacent values
assert run("5\n1 3 5 7 9\n") == "25", "all values can be taken"

# classic mixed case
assert run("9\n1 2 1 3 2 2 2 3 3\n") == "10", "dp transition check"
```| テスト入力 | 期待される出力 | 検証内容 |

|`4 / 1 1 2 2`|`4`| 隣接する値が競合する |
 |`5 / 1 3 5 7 9`|`25`| 隣接しない値はすべて選択できます。
