 ## 問題の理解

 各位置に整数値が格納される配列が与えられます。 連続セグメントを 1 つだけ選択し、そのセグメント内のすべての要素に同じ整数値を追加することができます。 この値は、正、負、またはゼロのいずれかになります。 この 1 つの変更の後、配列内のできるだけ多くの要素が固定ターゲット値と等しくなるようにします。$c$。 

重要な問題は、セグメントの変更は、すでに等しい要素を助けるだけではないことです。$c$。 非変換も可能です$c$要素を$c$ただし、追加された値がそれらの要素に完全に一致する場合に限ります。 同時に、元々等しい要素は、$c$存在しなくなるかもしれない$c$選択したセグメント内にある場合。 したがって、すべての候補セグメントは、「新しいものを獲得する」ことと「$c$"そして"既存のものを失う$c$」。 

制約$n \le 5 \cdot 10^5$セグメントの二次列挙は即座に除外されます。 平$O(n \log n)$ソリューションは、各ステップが線形またはほぼ線形である場合にのみ受け入れられます。 これは、解決策では問題をリニア スキャンまたは少数のパスに減らす必要があることを強く示唆しています。 

最適な戦略が何もしないことである場合、微妙なエッジ ケースが発生します。これは、最良のセグメントに実質的に有益な変換がないことを意味します。 もう 1 つの重要なケースは、複数の異なる値が次のように変換される場合です。$c$ただし、特定のオフセットは 1 つだけです$k$が選択されているため、セグメントごとに 1 つの値クラスのみをターゲットにできます。

 ## アルゴリズムのチュートリアル

 1. すでに等しい要素の数を数えます。$c$。 何もしないセグメント、または有害なセグメントを選択する可能性があるため、これが基本的な答えになります。 
2. 個別の値ごとに$x \ne c$を選択した場合の効果を考慮してください。$k = c - x$。 この選択により、あらゆることが可能になります$x$選択したセグメント内は次のようになります$c$。 
3. インデックスに対して暗黙的なスコア配列を構築します。配列をスキャンするときに、各位置を次のように扱います。$+1$等しい場合$x$、$-1$等しい場合$c$、 そして$0$さもないと。 
4. この暗黙的な配列に対して最大部分配列合計 (Kadane のアルゴリズム) を実行します。 これにより、回転価値に最適なセグメントが見つかります。$x$の中へ$c$既存のものを失うコストを考慮しながら$c$セグメント内の値。 
5. すべての値に対する最良のゲインを追跡する$x$。 このゲインを元のカウントに加算します。$c$。 

### なぜ効果があるのか

 固定セグメントおよび固定選択の場合$x$の数の変化$c$要素は 2 つの効果によって完全に決定されます: 新しく作成される$c$の出来事から$x$、そして破壊されました$c$セグメント内。 他の値は重要ではありません。$c$として開始することもできません$c$。 これにより、セグメントの評価が独立した位置寄与の合計に還元されます。これは、まさに Kadane のアルゴリズムが最適化する構造です。 すべての有効な操作はまさに 1 つのそのような操作に対応するため、$x$-ベースのスコアリング システム、すべての中で最大値を取る$x$あらゆる可能性をカバーします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, c = map(int, input().split())
    a = list(map(int, input().split()))

    base = 0
    for v in a:
        if v == c:
            base += 1

    positions = {}
    for i, v in enumerate(a):
        if v != c:
            positions.setdefault(v, []).append(i)

    ans = base

    for x, idxs in positions.items():
        best = 0
        cur = 0

        for i in idxs:
            val = 1  # a[i] == x

            # we need to account for c's, so check full scan logic via pointer
            # instead of compressing incorrectly, we rebuild contributions locally

        # proper Kadane over full array implicitly
        cur = 0
        best = 0
        for v in a:
            if v == x:
                cur += 1
            elif v == c:
                cur -= 1
            if cur < 0:
                cur = 0
            best = max(best, cur)

        ans = max(ans, base + best)

    print(ans)

if __name__ == "__main__":
    solve()

 ## 特殊なケース

 エッジ ケースの 1 つは、配列に候補値が含まれていない場合です。$x$。 その場合、Kadane スキャンはプラスの寄与をまったく加えず、最良のゲインはゼロのままです。 アルゴリズムはベースラインの改善を正しく回避します。 

もう 1 つのケースは、最適なセグメントが事実上空である場合です。つまり、変換を試行するたびに、セグメントの数が減少します。$c$。 Kadane のリセット ルールにより、負の寄与が確実に破棄されるため、アルゴリズムは自然にゼロ ゲインを返します。 

さらに次のようなケースがあります。$x = c$と偶然考えられます。 このような変換は次のような変換に対応するため、実装ではこれを明示的に除外または無力化します。$k = 0$これは何も変更せず、結果を水増しする必要はありません。
