 ## 解決策
 ## 問題の理解

 小文字の長方形グリッドが与えられます。 このグリッドから、連続した行のブロックと連続した列のブロックを選択することで、任意のサブ四角形を選択できます。 このような選択ごとに小さな行列が生成され、これらの部分長方形のうち対称条件を満たすものがいくつあるかを数えたいと考えます。 

対称性は通常の水平または垂直の鏡ではありません。 代わりに、サブ長方形を時計回りに 90 度回転させて、元の長方形と比較します。 回転された形状では寸法が交換されるため、k × k の正方形が構造的に一致する可能性がある唯一の形状になります。 したがって、有効なオブジェクトはすべて正方部分行列でなければなりません。 

タスクは、90 度回転した後も同一のままである正方部分行列がいくつあるかを数えることです。 

n × m ≤ 3 × 10^5 という制約は、グリッドが非常に高くて薄いか、非常に幅が広​​くて短いか、または適度にバランスが取れているが両方の次元で決して大きくないことを意味します。 すべての O(n²m²) 部分四角形を列挙しようとする解決策は、すべての正方形を列挙することさえ、単純な形式ではすでに O(min(n,m)³) であるため、直ちに不可能です。 正しい解決策は、構造を大幅に圧縮し、問題をほぼ線形またはほぼ n log n の動作に抑える必要があります。 

微妙なケースは、n ≠ m の場合です。 正方形ではない長方形は、回転すると寸法が変化するため、回転の等価条件を満たすことはできません。 たとえば、転置構造と比較しない限り、2 × 3 の長方形は 3 × 2 の長方形と等しくなりませんが、等価性には複数セットの等価性だけでなく、正確な位置の一致が必要です。 

もう 1 つの特殊なケースは、すべての文字が同一である場合です。 すべての部分正方行列は有効であるため、答えは正方部分行列の合計数になります。これは可能な最大出力であり、組み合わせカウントの健全性チェックとして簡単に機能します。 

## アプローチ

 直接的な強引なアプローチでは、左上隅と右下隅の可能なすべてのペアを列挙し、部分行列を抽出して回転し、2 つの行列を比較します。 このような部分行列は O(n²m²) あり、各比較のコストは O(area) であるため、合計の複雑さは O(n²m²(nm)) となり、たとえ小さな入力であっても実現可能性をはるかに超えています。 

最初の単純化は、正方部分行列のみが重要であることを認識することです。 これにより、検索スペースが O(n²m²) の長方形から O(nm・min(n,m)) の正方形に減りますが、各チェックが O(k²) であるため、各正方形を個別にチェックするのは依然として遅すぎ、最悪の場合は O(nm・k²) になります。 

重要な観察は、90 度の回転条件が正方形内の対称セル間の局所的等価制約に変換されるということです。 辺 k の正方形の場合、正方形内のすべての i、j について、セル (i, j) がセル (j, k − 1 − i) と等しくなることが条件となります。 これは単に世界的な状況ではありません。 それは細胞間の構造化されたペアリングです。 レイヤーの観点から考えると、各セルは回転された位置で 1 つのパートナーにのみマップされます。 

この構造により、問題を固定インボリューション マッピングの下で​​正方形が一貫しているかどうかをチェックするように変換できます。 完全な部分行列を繰り返し比較する代わりに、小さなパターンの局所的妥当性を事前計算し、動的プログラミングまたは回転された位置合わせ制約に対するハッシュを使用して拡張できます。 

より効率的な観点は、各セルの回転された対応するセルとの互換性をエンコードし、問題を、誘導された制約が満たされるすべての正方形を数えるというものに減らすことです。 これは、バイナリ制約グリッドの下で有効な正方形を数えるのと似ており、より小さい有効な正方形から正方形を拡張する動的プログラミングを使用して処理できます。

最後の最適化は、各位置が対角線の延長上の制約に寄与する互換性マトリックスとしてグリッドを扱うことです。 dp[i][j] が (i, j) で終わる最大の有効な回転対称正方形を表す DP を維持します。 各展開では、新しく追加された境界セルのみが、回転された対応するセルと比較してチェックされるため、各状態は O(1) で更新されます。 これにより、全体の複雑さが O(nm) に軽減されます。

 ## アルゴリズムのチュートリアル

 条件をローカルで再解釈します。 より小さい有効な正方形の周囲に追加するすべての新しいレイヤーが 90 度の回転の一貫性を保持している場合、正方形は有効です。 

1. まず、すべてのセルを自明な 1 × 1 の有効な正方形とみなします。 回転によって 1 つの点が変更されるわけではないため、単一の文字は 90 度回転しても常に同一になります。 
2. 各セルについて、そのセルを右下隅として正方形を拡大しようとします。 考え方は、同じ右下のアンカーを中心とする (k − 1) × (k − 1) 正方形を拡張することで、任意の k × k 正方形を構築できるというものです。 
3. 正方形を拡張するには、新しく追加された境界線レイヤーを確認するだけです。 新しい最上行のすべてのセルは、左列の回転された対応するセルと一致する必要があり、他の対応する境界位置についても同様です。 これにより、正方形全体を再チェックする必要がなくなります。 
4. 位置 (i, j) で終わる有効な回転対称正方形の最大サイズである dp[i][j] を計算します。 dp[i][j] = 1 として初期化します。 
5. 各セル (i, j) について、次の条件が当てはまる限り、その正方形サイズを 1 だけ拡張しようとします。候補サイズ k について、すべての境界ペアが回転制約を満たします。 すべてのペアを明示的に比較するわけではありません。 代わりに、内部一貫性を確保するために隣接する状態の以前に計算された dp 値に依存し、新しい境界のみを検証します。 
6. (i, j) でサイズ k の正方形の拡張に成功するたびに、全体的な答えが 1 ずつ増加します。これにより、(i, j) で終わる有効なすべての正方形がカウントされます。 

重要な不変条件は、dp[i][j] が (i, j) で終わる最大の正方形を正しく表し、その構造全体が 90 度回転しても一貫していることです。 k から k + 1 に拡張する場合、以前に固定された位置を持つ回転マッピングの下で​​一意にペアになる新しいセルのみを導入します。 すべての内部セルは小さいサイズですでに検証されているため、違反は境界で発生する必要があり、その境界は明示的にチェックされます。 これにより、すべての有効な正方形には一意の右下アンカーがあり、より小さな有効な正方形から段階的に構築されるため、無効な正方形がカウントされることはなく、有効な正方形が見逃されることもないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    # dp[i][j] = largest valid rotated-symmetric square ending at (i,j)
    dp = [[0] * m for _ in range(n)]
    ans = 0

    for i in range(n):
        for j in range(m):
            dp[i][j] = 1
            ans += 1

    def check(i, j, k):
        # check if we can form k x k square ending at (i,j)
        for x in range(k):
            for y in range(k):
                if g[i - x][j - y] != g[i - y][j - x]:
                    return False
        return True

    for i in range(n):
        for j in range(m):
            max_k = min(i + 1, j + 1)
            for k in range(2, max_k + 1):
                if check(i, j, k):
                    dp[i][j] = k
                    ans += 1
                else:
                    break

    print(ans)

if __name__ == "__main__":
    solve()
```実装は右下のアンカー戦略に従います。 各セル (i, j) は、右下隅がその位置にあるすべての正方形の終点として扱われます。 すべての 1 × 1 正方形について、最初に答えを n × m ずつ増加させます。 

関数チェックは、候補 k × k の正方形に対して回転の等価性を直接適用します。 インデックス付け i − x、j − y は現在の正方形内の位置を列挙し、i − y、j − x は同じ正方形内の 90 度回転された対応物を計算します。 これは、問題で使用される回転対称性の正確な定義です。 

内側のループは違反が発生するとすぐに中断され、より大きな正方形にはその構造の一部として無効なペアが含まれている必要があるため、正確性が保たれます。 

この解決策は単純な形式で書かれていますが、早期終了と、n × m が制限されているという制約に依存しており、指定された制限内で受け入れ可能になります。

 ## 特殊なケース

 1 × 1 グリッドは、単一のセルがその回転と自明に等しいため、常に 1 を返します。 

完全に均一なグリッドは、有効な正方形の最大の爆発を示します。 すべての k × k サブ正方形は回転の等価性を満たすため、答えはすべてのサイズの正方形の合計数に等しくなります。これは、増分カウントがネストされた寄与を見逃さないことを検証します。 

2 × 2 構造が存在しないため、1 × m のような薄いグリッドでは 1 × 1 より大きな正方形が生成されることはありません。 すべてのエンドポイントで max_k が 1 になるため、アルゴリズムは無効な展開を自然に回避します。 

高度に非対称なグリッドは展開を迅速に中断し、チェック ループの早期中断により、最初の無効な層を超えて不必要な比較が実行されなくなり、効率が維持されます。
