 ## 解決策
 ## 問題の理解

 特定の周期的制約が満たされるように、最初の m 個の小文字のラテン文字を使用して、長さ n の文字列をいくつ形成できるかを数えるよう求められます。 

制約は固定オフセット k によって定義されます。 1 から n − k までのすべての位置 i について、位置 i の文字は位置 i + k の文字とは異なっていなければなりません。 言い換えれば、文字列を見て、すべての位置をちょうど k ステップ先の位置と比較した場合、それらのペアはどれも一致しません。 

これにより、位置が距離 k だけリンクされた構造が作成されます。 文字列を単一の行として考えるのではなく、インデックスを法 k として取得して形成される k 個の独立した列として考える方が便利です。 このような各列は、隣接する要素 (k ステップ) が異なる必要があるチェーンのように動作します。 

制約は小さく、n ≤ 40、m ≤ 8、k ≤ 8 です。これにより、ポジションに対する指数関数的アプローチまたは状態圧縮アプローチが実行可能であることがすぐにわかります。 O(n · m^k) や O(m^n) さえも受け入れられませんが、k 個の小さな独立した部分問題に分解するもの、または位置と前の k 文字に対して DP を使用するものはすべて実行可能です。 

k ≥ n の場合、微妙なエッジケースが発生します。 この状況では、i + k ≤ n となるようなインデックス i が存在しないため、制約はまったくありません。 答えは単純に m^n になります。 これをチェックせずにトランジションを盲目的に適用するソリューションは引き続き機能しますが、一部の DP 定式化では、依存関係が存在すると想定している場合、誤って過小評価される可能性があります。 

もう 1 つの明白でないコーナーは、k = 1 の場合です。この場合、隣接するペアはすべて異なる必要があり、これは標準的な「等しい文字が 2 つ連続して存在しない」という問題です。 k = 1 を慎重に扱わずに k を法とする位置間の独立性を誤って仮定する方法はいずれも機能する可能性がありますが、DP 遷移に大きな負荷がかかるため、適切な健全性チェックになります。 

## アプローチ

 ブルートフォース手法は簡単です。m 文字にわたる長さ n の可能なすべての文字列を生成し、それが k 差分制約を満たすかどうかを確認します。 各文字列について、1 から n − k までのすべての i をスキャンし、s[i] ≠ s[i + k] であることを確認します。 m^n 個の文字列があり、各検証には線形時間がかかるため、最悪の場合、O(m^n · n) 時間がかかります。 n = 40、m が最大 8 であるため、これは天文学的に大きく、まったく実行不可能です。 

重要な観察は、制約は k によって分離された位置のみを接続するということです。 これは、位置 i が i − k および i + k とのみ相互作用するため、構造が k を法とする残基クラスに基づいて独立した鎖に分割されることを意味します。 各チェーンは、連続する要素が異なる必要があるシーケンスです。 1 つのチェーンの割り当てを修正すると、他のチェーンには影響しません。 

したがって、n 個の位置をグローバルに考える代わりに、i mod k によってインデックスをグループ化します。 各残基クラス r について、シーケンス r、r + k、r + 2k などを考慮します。 このような各シーケンスは独立しており、短い長さでは単純な「隣接しない」制約のように動作します。 次に、すべての k チェーンにわたって有効なシーケンスの数を掛けます。 

これにより、問題は、長さ L のチェーンごとに、隣接する要素が異なるように m 文字で埋める方法の数を数えるということになります。 これは標準的な線形 DP で、最初の要素には m 個の選択肢があり、次の各要素には (m − 1) 個の選択肢があります。

 ## アルゴリズムのチュートリアル

 k を法とする各剰余クラスを個別に処理し、結果を乗算します。

1. インデックス法 k に基づいて位置を k 個のグループに分割します。 各グループは、r、r + k、r + 2k などのチェーンを形成します。 これが機能するのは、制約が正確に k の距離にあるインデックスのみを接続するためであり、異なるグループ間で相互作用が発生しないためです。 
2. 各グループについて、その長さ L を計算します。これは、i ≤ n および i ≡ r (mod k) となるインデックス i の数です。 グループの構造は長さ L の単純な数列になります。 
3. 隣接する位置が異なるように m 個の文字を使用して長さ L のチェーンを埋める方法が何通りあるかを数えます。 dp[j] をチェーンの最初の j 要素を埋める方法の数として定義します。 
4. 最初の位置は m 文字のいずれかになるため、dp[1] = m を初期化します。 
5. 次の位置 j ≥ 2 ごとに、前の文字とは異なる文字を選択します。 前の位置に m 個の選択肢がある場合、それらの各選択肢は次の位置に対して (m − 1) 個の選択肢を許可するため、 dp[j] = dp[j − 1] · (m − 1) となります。 
6. 各グループのグローバルな答えに dp[L] を掛けます。 

最終結果は、すべての k グループにわたる積です。 

### なぜ効果があるのか

 核となる不変条件は、各モジュロ クラスが独立したチェーンを形成し、制約がそのチェーン内の連続する要素のみを関連付けるということです。 あるグループの固定割り当てを条件にすると、禁止されたペア i および i + k が同じ剰余クラス内に留まるため、制約が別のグループに交差することはありません。 したがって、グローバル構成空間は独立したチェーン構成のデカルト積に因数分解され、各チェーンを個別に数えて乗算すると、有効なシーケンスの合計数が正確に得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())

    # answer is product over k independent chains
    ans = 1

    for r in range(k):
        # compute length of this residue class
        length = 0
        i = r + 1
        while i <= n:
            length += 1
            i += k

        if length == 0:
            continue

        # first position: m choices, rest: (m-1) choices each
        if length == 1:
            ways = m
        else:
            ways = m * (m - 1) ** (length - 1)

        ans *= ways

    print(ans)

if __name__ == "__main__":
    solve()
```実装は、剰余クラスへの分解の後に直接続きます。 各クラスについて、ストライド k でインデックスをステップ実行することにより、その長さを明示的に計算します。 これは制約 (n ≤ 40) を考慮すると安全であり、算術式の必要がなくなりますが、整数の除算を使用して長さを計算することもできます。 

各チェーンは閉じた形式 m · (m − 1)^(L − 1) を使用して評価されます。これは、最初の要素が自由であり、後続の各要素は前の値のみを除外するという事実から来ています。 

よくある落とし穴は、異なる残基クラスが独立していることを忘れていることです。 もう 1 つは、式 m · (m − 1)^(n − 1) を文字列全体に誤って適用することです。隣接関係はシーケンス全体ではなくチェーン内にのみ存在するため、これは誤りです。

 ## 特殊なケース

 k ≥ n の場合、おそらく 1 つを除くすべての剰余クラスは長さ 0 または 1 になります。各チェーンは長さに応じて m または 1 を提供し、無効な制約は導入されないため、アルゴリズムはこれを自然に処理します。 

k = 1 の場合、シーケンス全体が 1 つのチェーンになり、式は m · (m − 1)^(n − 1) になります。 アルゴリズムはこれを特別に扱いません。これは残差クラスの構築から直接現れます。 

m = 1 の場合、(m − 1) = 0 であるため、1 を超える長さのチェーンはゼロウェイを生成します。これは正しいです。距離 k にある 2 つの位置は等しくないため、長さ ≥ 2 は不可能です。
