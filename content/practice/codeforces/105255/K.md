 ## 解決策
 ## 問題の理解

 最大 6 個のサイコロが与えられ、ロール後に各サイコロの上面に 1 つのシンボルが表示されますが、内部的には各サイコロが表示できる 6 つのシンボルがあり、すべて同じ確率で表示されます。 これに加えて、許可された単語の辞書が与えられます。各単語はサイコロごとに 1 文字だけを持つため、単語はすべてのサイコロの位置へのシンボルの完全な割り当てに対応します。 

1 回のプレイでは、すべてのサイコロを振り、結果として得られるシンボルのタプルを確認し、どのサイコロを保持し、どのサイコロを振り直すかを決定します。 維持されたダイスは現在の面を保持しますが、再ロールされたダイスは 6 つの面のうち 1 つを個別にリサンプリングします。 これは、ロール後のある時点で、すべてのサイコロの目に見えるシンボルが辞書の単語の 1 つと正確に一致するまで続きます。 

目標は、ラウンド数ではなく、個々のダイスロールの予想総数を最小限に抑えることです。 サイコロを振るたびに、1 単位のコストがかかります。 

重要な問題は、単語に対する現在の部分的な進行状況に応じて、どのサイコロを振り直すかを適応的に決定できることです。 これにより、問題は、単語ごとの非常に小さい状態空間にわたる制御された確率過程に変わりますが、ターゲット単語の候補は多数あります。 

制約は非常に具体的な意味で重要です。 サイコロの数は最大 6 であるため、d の指数関数的なアプローチはすべて実現可能です。 単語数は 200,000 に達する可能性があるため、各単語を単語長にわたって線形時間で処理したり、単語ごとに大量のシミュレーションを実行したりするソリューションは遅すぎます。 単語ごとにサイコロのサブセットごとに定数因子の作業を行うソリューションは許容されます。$2^6 = 64$サブセット。 

単純なアプローチでは、サイコロの値のすべての可能な構成にわたって最適な戦略を動的にシミュレートしますが、その状態空間は$26^d$アルファベットの意味で、あまりにも大きすぎます。 少数のサイコロを利用せずに、単語ごとにすべての戦略を独立してシミュレートしても、タイムアウトになってしまいます。 

一部のダイに必要なシンボルが含まれていないため、単語がまったく形成できない場合、微妙なエッジ ケースが発生します。 たとえば、サイコロに面がある場合、`GHI234`、それは決して生み出すことはできません`A`、したがって、必要な単語はすべて`A`その位置では戦略に関係なく不可能です。 その場合、その単語は完全に無視する必要があります。 

## アプローチ

 強引なアイデアは、サイコロの面のすべての可能な構成と、凍結することを選択する可能性のあるサイコロのすべてのサブセットに対する完全なマルコフ決定プロセスとしてプロセスを扱うことです。 どのような構成であっても、どのダイスを振り直すかの選択肢をすべて列挙し、期待値を再帰的に計算します。 構成の数はサイコロの値の数に応じて指数関数的に増加し、各遷移は多くのリロール結果に分岐します。 たとえ$d \le 6$、フルフェイスの割り当てを超える分岐により、これは実行不可能になります。 

重要な単純化は、単一の候補単語に注意を向けることから生まれます。 言葉にこだわるなら、唯一関連する問題は、現在のサイコロの状態をその正確なターゲット構成にどれだけ早く変換できるかということになります。 サイコロがターゲットの単語の正しいシンボルを示したら、再度振り直す理由はありません。振り直しは完了を遅らせるだけであるためです。 これは、正しく一致した位置のセットが増加するだけであるという意味で、プロセスが単調になることを意味します。 

固定ワードの場合、どのサイコロがすでに正しいシンボルにロックされているかを状態が表すサブセット DP を使用してプロセスをモデル化できます。 州から$S$、すべてのサイコロを入れます$S$が凍結され、残りのダイスが同時に振り直されます。 再ロールされたダイスはそれぞれ独立して、$1/6$そのラウンドで正解する可能性があるため、成功したダイスを独立して追加することによって次の状態が形成されます。$S$。 

これにより、問題は 1 ワードあたり最大 64 状態にわたる小さな確率的 DP に変換されます。 各状態からの期待コストは、そのステップで振られたサイコロの数と、結果として得られる状態分布の期待値に依存します。 

最後に、各単語のこの期待値を計算し、すべての有効な単語の最小値を取得します。

 | ダイス状態に対する単語ごとのサブセット DP |$O(w \cdot 2^d)$|$O(2^d)$| 承認済み |

 ## アルゴリズムのチュートリアル

 単語を修正し、それが到達したいターゲット構成であると仮定します。 

1. まず、すべての位置について、その位置のダイの面のどこかに必要なシンボルが含まれていることを確認して、実現可能性をチェックします。 いずれかの位置がこのテストに合格しない場合、その単語は不可能なのでスキップできます。 
2. ビットマスクによる DP 状態の定義$S$、どこビット$i$死ぬことを示します$i$すでに現在、ターゲット単語の正しい記号が表示されており、一度表示されると永久に保持されます。 
3. 状態について$S$、 させて$U$サイコロのセットが入っていないこと$S$。 1 ラウンドですべてのサイコロを振ります$U$一度。 このようなサイコロはそれぞれ、必要なシンボルを確率で個別に照合します。$1/6$。 
4. このラウンドのコストは$|U|$、それぞれが死ぬので、$U$ちょうど 1 回ロールされます。 
5. サブセットごとに$T \subseteq U$、サイコロが正確に当たる確率$T$このラウンドで正解するのは$$\prod_{i \in T} \frac{1}{6} \cdot \prod_{i \in U \setminus T} \frac{5}{6}.$$次の状態は次のようになります$S \cup T$。 
6. 繰り返しを書きます。$$E[S] = |U| + \sum_{T \subseteq U} P(T) \cdot E[S \cup T].$$7. サブセット サイズの降順で DP 値を計算します。$S$計算時にすでに知られている$E[S]$。 基本的なケースは$E[\text{all bits}] = 0$。 
8. この言葉の答えは、$E[\emptyset]$。 すべての単語に対して繰り返し、最小値を取得します。 

この DP が有効である理由は、プロセスが、どのサイコロがすでに正解であるかにのみ依存し、どのようにサイコロが正解になったかには依存しないためです。 サイコロがターゲットシンボルと一致したら、それをフリーズしても、最終的な成功条件に影響を与えることなくランダム性の原因が除去されるため、将来の期待が悪化することはありません。 これにより、ロックされた位置のセットによってのみ定義された状態が、固定ターゲット ワードに対する最適な戦略の完全なマルコフ表現を形成することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    d, w = map(int, input().split())
    dice = [input().strip() for _ in range(d)]
    
    # precompute face sets
    face_set = [set(s) for s in dice]
    
    words = []
    for _ in range(w):
        words.append(input().strip())
    
    INF = 1e100
    ans = INF
    
    # iterate words
    for word in words:
        ok = True
        for i in range(d):
            if word[i] not in face_set[i]:
                ok = False
                break
        if not ok:
            continue
        
        size = 1 << d
        dp = [0.0] * size
        
        # process subsets in reverse by number of bits set
        for mask in range(size - 1, -1, -1):
            if mask == size - 1:
                dp[mask] = 0.0
                continue
            
            U = []
            for i in range(d):
                if not (mask >> i) & 1:
                    U.append(i)
            
            k = len(U)
            cost = k
            
            # enumerate all subsets of U
            exp_val = cost
            
            # iterate subsets via bitmask
            for sub in range(1 << k):
                prob = 1.0
                new_mask = mask
                for j in range(k):
                    i = U[j]
                    if (sub >> j) & 1:
                        prob *= (1.0 / 6.0)
                        new_mask |= (1 << i)
                    else:
                        prob *= (5.0 / 6.0)
                
                exp_val += prob * dp[new_mask]
            
            dp[mask] = exp_val
        
        ans = min(ans, dp[0])
    
    if ans == INF:
        print("impossible")
    else:
        print(f"{ans:.10f}")

if __name__ == "__main__":
    solve()
```この実装は、サイコロのサブセット上に DP を直接反映します。 各マスクは、どのサイコロがターゲットの単語にすでに一致しているかを表します。 コードは状態ごとに、まだ一致していないサイコロのすべてのサブセットを列挙し、遷移分布を計算します。 状態ごとに追加されるコストは、そのステップで振られたサイコロの数とまったく同じです。 

完全なマスクから下に向かって順序付けすることで、すべての遷移が、すでに計算されている、より多くのビットが設定された状態に移行することが保証されます。 これにより再帰が回避され、計算が厳密にボトムアップに保たれます。 

微妙な点は、浮動小数点の安定性です。 確率には、最大 6 項の積が含まれます。$1/6$または$5/6$なので、倍精度で十分です。

| 状態マスク | サイコロを振った | 写真 コスト | 主な移行アイデア |
 | --- | --- | --- | --- |
 | 00000 | サイコロ5個 | 5 | 新しい正しい一致のすべてのサブセット |
 | 00001 | サイコロ4個 | 4 | 必要なロールが少なくなる |

 初期状態から、サブセットがターゲットの文字と一致するまで、ラウンドごとに 5 つのサイコロすべてを振ります。 より多くのダイスが固定されると、ラウンドごとに必要なロールの数が減り、それに応じて期待値も減少します。 DP は、この減少するコスト構造を正確に捉えています。 

これは、ロックされた正しい位置のセットのみが将来的に重要であるという不変条件を裏付けます。 

### サンプル 2

 2 つのサイコロと単語の場合を考えてみましょう`AB`、ここで、ダイ 2 はどちらも生成できません`A`または`B`。 

| ステップを確認 | 結果 |
 | --- | --- |
 | ダイス 1 には次のものが含まれます`A`または`B`| はい |

これは、サブセット DP を実行する前に実現可能性フィルタリングが不可欠である理由を示しています。

 ## 特殊なケース

 重要なエッジケースは、少なくとも 1 つのサイコロに必要な記号が含まれていないため、単語が構造的に不可能である場合です。 その状況では、DP は強制された場合でも数学的に値を生成しますが、それは存在しない成功パスに対応することになります。 実現可能性チェックにより、これらの単語が DP に入力されないことが保証されるため、最終的な最小値が常に真に到達可能なターゲットに引き継がれます。 

もう 1 つの微妙なケースは、すべてのサイコロが最初のロールの単語とすでに一致している場合です。 その状態では、吸収状態であるため、DP はゼロコストを割り当てます。$S = \text{all}$すでに到達しているため、これ以上ロールする必要はありません。 

最後に、複数の単語が重複構造を共有するケースは、各単語が独立した DP を誘発し、単語の切り替えを動的にモデル化する必要がなく、それらすべての最小値が切り替え戦略を正しく捕捉するため、自然に処理されます。
