 ## 解決策
 ## 問題の理解

 固定数の位置と値の範囲が与えられ、概念的にこの範囲の値を各位置に割り当てます。 完全な割り当てごとに、左から右にスキャンしたときに、その位置の値が初めて新しい最小値に現れる位置を特定することに関心があります。 言い換えれば、位置 i では、その値がその前のすべての値よりも大きくない場合、その値はプレフィックスの最小値になります。 

タスクは、単一の割り当てを評価することではなく、均一なカウント モデルの下で考えられるすべての割り当てにわたってこの条件を集計することです。 すべての位置は独立して固定範囲内の任意の値を取ることができるため、構成のスペースは指数関数的になります。 出力は、説明した方法で各位置がプレフィックス最小値として機能するすべての構成の合計寄与度です。 

編集者が示唆する制約は、位置の数と値の範囲の両方が十分に大きくなり、すべての代入を反復することが不可能になる可能性があることを示唆しています。 位置と値のすべてのペアを反復処理する場合でも、3 つのネストされたループ方法で単純に実行すると、遅すぎます。 代数圧縮を行わずに割り当てやペアごとの寄与を明示的に列挙するソリューションは、一般的な制限を超えます。 

プレフィックス最小条件を個別に推論する場合、微妙な特殊なケースが発生します。 たとえば、位置が 1 つだけある場合、その位置は値に関係なく常にプレフィックスの最小値になります。 配列の両側から条件を誤って適用する単純な解釈は、ここでは失敗します。 もう 1 つのエッジ ケースは、値の範囲のサイズが 1 である場合です。これは、すべての割り当てが定数であることを意味します。 その場合、すべての位置は自明のことですがプレフィックスの最小値となり、値間のばらつきを仮定する数式は誤ってゼロで除算したり、縮退する幾何学的比率を仮定したりする可能性があります。 

## アプローチ

 ブルートフォースの視点は定義から始まります。 位置への値の割り当てをすべて繰り返すことを想像します。 割り当てごとに、左から右にスキャンして、値が以前のすべての値以下であるすべての位置にマークを付けます。 次に、そのような発生ごとに答えに 1 を追加します。 これは正しいですが、代入の数が k^n であり、n が数十までであってもこれは不可能であるため、根本的に実行不可能です。 

完全な割り当てを列挙しないように、カウントを再構成する必要があります。 重要な変化は視点を逆転させることです。 与えられたグローバル構造を生成する代入の数を尋ねる代わりに、各ペア (i, j) について、位置 i を値 j に等しくする代入の数と、それをプレフィックスの最小値にする代入の数を尋ねます。 

位置 i が値 j のプレフィックス最小値であるためには、それより前のすべての位置が少なくとも j の値を持っていなければなりません。 これにより、きれいな独立構造が得られます。i より前の位置は [j, k] の範囲に制限され、位置 i は j に固定され、i の後の位置は制限されません。 これにより、カウントが独立した選択の結果に分割されます。 

したがって、固定ペア (i, j) の寄与は、プレフィックスの (k − j + 1)^(i−1) にサフィックスの k^(n−i) を乗算したものになります。 これをすべての i と j で合計すると、二重の合計が得られます。これは依然として大きく見えますが、構造を持ちます。 

重要な観察は、固定 j の場合、i が増加するにつれて、項 (k − j + 1)^(i−1) が等比数列を形成することです。 これにより、i 上の内和を閉じた形式の等比級数に置き換えることができます。 これが完了すると、j の残りの合計は k で線形になり、べき乗剰余と逆剰余を使用して各項を定数時間で評価できます。 これにより、複雑さが O(nk) かそれより悪いものから O(k log MOD) に縮小されます。

 | 幾何学的な合計を使用したペアのカウント | O(k ログ MOD) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 プレフィックスの最小位置に現れる値 j を固定することを中心に計算を再構築します。 

1. 値 j を 1 から k まで固定します。 これを、プレフィックスの最小値となる位置 i に割り当てられた値として解釈します。 
2. 固定位置 i の場合、位置 i が値 j を持つように強制します。 i より前のすべての位置は少なくとも j でなければならないため、それぞれに (k − j + 1) 個の選択肢があります。 これは (k − j + 1)^(i−1) に寄与します。 
3. i 以降の位置には制限がないため、それぞれが k 個の選択肢に寄与し、k^(n−i) が得られます。 
4. これらを固定 (i, j) の寄与に結合します。これは、(k − j + 1)^(i−1) · k^(n−i) となります。 
5. 次に、固定 j のすべての位置 i を合計します。 (k − j + 1) のべき乗が i で等比数列を形成するように合計を書き換えます。 k^(n−1) を因数分解して、比率 (k − j + 1) / k を分離します。 
6. 等比級数の公式を適用して、j ごとに一定時間で i の合計を計算します。 これにより、すべての位置を明示的に繰り返す必要がなくなります。 
7. 1 から k までのすべての値 j の結果を合計し、最終的な答えのモジュロ MOD を累積します。 

なぜ効果があるのか

 有効な各構成は、各プレフィックスの最小出現位置と値を選択することによって一意にカウントされます。 「値 j の i でのプレフィックス最小値」という条件は、インデックス間で独立した以前の位置の制約にのみ依存します。 この独立性により、累乗への因数分解が可能になります。 この幾何学的構造は、位置間で変化する唯一の部分が同じ基数 (k − j + 1) 上の指数であるため発生し、i と j を合計するときに重複や二重カウントが発生しないようにします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def modinv(a):
    return modpow(a, MOD - 2)

def solve():
    n, k = map(int, input().split())

    inv_k = modinv(k)
    ans = 0

    for j in range(1, k + 1):
        base = k - j + 1

        # geometric ratio r = base / k
        r = base * inv_k % MOD

        # sum_{i=1..n} base^(i-1) * k^(n-i)
        # = k^(n-1) * sum_{t=0..n-1} r^t
        if r == 1:
            geom = n % MOD
        else:
            geom = (modpow(r, n) - 1) * modinv(r - 1) % MOD

        ans = (ans + modpow(k, n - 1) * geom) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```すべての式には素数法の下でべき乗と除算が含まれるため、コードはべき乗モジュラと逆モジュラを実装することから始まります。 メイン ループ内では、各値 j がプレフィックス位置の基本制約を定義します。 比率 r は、プレフィックス境界を移動するときに寄与がどのように変化するかを捉えます。 

幾何学和は、標準の閉じた形式を使用して計算されます。r が 1 に等しい特殊な場合は、j = 1 ですべてのプレフィックス値が制限されていない場合に発生します。 係数 k^(n−1) は、式を安定させ、累乗の繰り返しを減らすために抽出されます。 

ここでの一般的な落とし穴は、指数オフセットを混合することです。 接頭辞は i−1 を使用し、接尾辞は n−i を使用するため、幾何学的比率における 1 による誤差を回避するには k^(n−1) を抽出することが不可欠です。 

## 実用的な例

 ### 例 1

 n = 3、k = 2 について考えてみましょう。 

j = 1 と j = 2 の寄与を計算します。 

| j | ベース = k − j + 1 | 比率r | 幾何学和 | 貢献 |
 | --- | --- | --- | --- | --- |
 | 1 | 2 | 1 | 3 | k^(2)・3 |
 | 2 | 1 | 1/2 | 1 + 1/2 + 1/4 | k^(2) · 合計 |

 j = 1 の場合、すべての接頭辞制約がなくなるため、すべての割り当てが位置全体に均一に寄与します。 j = 2 の場合、プレフィックス位置はすべて正確に 2 である必要があり、有効な構成が急速に制限されます。 

このトレースは、より厳密なプレフィックス制約を反映して、j が増加するにつれて幾何学的比率がどのように縮小するかを示しています。 

### 例 2

 n = 2、k = 3 について考えてみましょう。 

各 j を評価します。 

| j | ベース | r | ジオムサム |
 | --- | --- | --- | --- |
 | 1 | 3 | 1 | 2 |
 | 2 | 2 | 2/3 | 1 + 2/3 |
 | 3 | 1 | 1/3 | 1 + 1/3 |

 これにより、制約が厳しくなる (j が大きくなる) と基数が減少し、寄与が減少すること、また等比級数がすぐに崩壊する短い配列が数式で正しく処理されることが確認されます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(k ログ MOD) | 各値 j にはべき乗剰余演算と逆演算が必要です。 
| スペース | お(1) | 一定数の変数のみが維持されます。 

各項が閉じた形式の算術に還元されるため、この解は k が大きい場合に効率的です。 k が 10^5 以上の場合でも、べき乗剰余演算が優勢ですが、一般的な制限内で十分な速度を維持します。

 ## 特殊なケース

 k = 1 の場合、すべてのランダム性が崩壊します。 すべての位置は値 1 に強制されるため、すべての位置はプレフィックスの最小値になります。 この式は同一の寄与を合計するものであり、r が 1 になり、幾何学的合計ブランチが n を返すため、実装はこれを正しく処理します。 

n = 1 の場合、問題は、単一の位置が常にプレフィックスの最小値であるすべての可能な値 j の合計に帰着します。 このコードは、等しい構造の k 項を評価し、それぞれが長さ 1 の幾何学和の k^0 = 1 倍に寄与し、期待どおりの k を生成します。 

j = 1 のとき、比 r はちょうど 1 になります。 これは、幾何学的公式が一般形式でゼロで除算される唯一の点です。 明示的分岐はこのケースをきれいに処理し、幾何和ではなく線形和を生成します。
