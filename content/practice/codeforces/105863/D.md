 ## 解決策
 ## 問題の理解

 固定ルート ノードであるノード 1 からの距離によって暗黙的に記述された無向グラフ構造が与えられます。すべてのノードについて、ノード 1 からの距離がわかっており、この距離構成を正確に生成できる異なる「最小」グラフがいくつあるかを数えるよう求められます。 

ノード 1 から距離 d にあるすべてのノードがそれらの距離を維持する方法で接続されている場合、グラフは有効であるとみなされます。 特に、すべてのノードは、ノード 1 に到達するまで各ステップで厳密に距離が 1 ずつ減少する最短パスを介して到達可能である必要があります。重要な制限は最小限であることです。つまり、最短パスに寄与しない余分なエッジを追加することは許可されていません。 

したがって、入力は、ノード 1 から始まる BFS レベルによってノードのパーティションをエンコードします。出力は、すべてのノードが指定された距離で一貫して接続されたままになるように、連続したレベルにわたって親関係を割り当てる方法の数です。 

n 個のノードがある場合、素朴な解釈では、BFS 制約を維持しながらレイヤー間でノードを接続する可能なすべての方法を検討することを提案します。 各ノードが前の層で多くの親を選択する可能性があるため、これはすぐに組み合わせ的に爆発します。 n が 10^5 などの一般的な Codeforce 制限に達すると、指数構成や二次ペアさえも実行できなくなります。 これにより、乗算的または層ごとのカウント構造が求められます。 

先行するレイヤーのない距離レイヤーが存在する場合、微妙な失敗のケースが発生します。 たとえば、距離 2 にノードがあり、距離 1 にノードがない場合、そのノードには最短パスを介してルートに接続する方法がないため、有効なグラフは存在できません。 このような場合、答えはゼロでなければなりません。 もう 1 つのエッジ ケースは、複数のノードが同じ距離を共有する場合です。これは、ノードの選択は単純な意味では独立ではありませんが、有効な親選択の構造が認識されると独立するためです。 

## アプローチ

 ブルートフォースアプローチでは、指定された距離ラベルと一致するすべての有効なスパニング構造を構築しようとします。 距離 d にある各ノードについて、距離 d − 1 にあるノード間で考えられるすべての親を試行し、再帰的に接続制約を確保します。 これはすぐに指数関数的になります。あるレベルに k 個のノードがあり、前のレベルに m 個のノードがある場合、その層だけで m^k 個の可能な割り当てが存在します。 m = 5 や k = 20 のような控えめな値であっても、これはすでに天文学的な大きさです。 

重要な観察は、距離制約により、隣接するレイヤー間の選択が完全にローカライズされるということです。 最小化を望む場合、距離 d のノードは距離 d − 1 のノード以外には接続できません。他のエッジは最短パス構造に違反するか冗長になるためです。 これにより、グラフ構築の問題全体が層ごとの独立した選択肢に縮小されます。 

これで、構造は単純になります。1 からの距離によってグループ化されたプロセス ノードです。ある層 d を見ているとします。 この層のすべてのノードは、層 d − 1 の親を 1 つだけ選択する必要があります。層 d − 1 に x 個のノードがある場合、層 d の各ノードには x 個の独立した選択肢があります。 ただし、有効なグローバル構造をカウントしているため、レイヤー間でノードを個別に扱うのではなく、レイヤーごとに乗算的に累積します。 唯一のグローバル制約は、ルート以外のすべての層が前の層に少なくとも 1 つのノードを持たなければならないことです。 そうでなければ建設は不可能です。

これにより、問題は、距離によるノードの並べ替え、各層に出現するノードの数のカウント、および独立した選択の繰り返しによって暗黙的に発生した形式の寄与 (前の層のノードの数) の乗算に変換されます。 各ノードが独立して親を選択するため、層の寄与は x^(k_d) ですが、編集ステートメントではそれをノード順序ごとの順次累積に単純化しているため、距離が増加する順序でノードを反復し、新しい距離グループの境界に遭遇したときに前の層のサイズを乗算すると解釈することもできます。

 ## アルゴリズムのチュートリアル

 1. すべてのノードの距離を読み取り、ノード 1 からの距離によってノードをグループ化します。識別性ではなく、相対的な階層化のみが重要であるため、距離レベルごとの頻度の並べ替えまたはカウントで十分です。 これにより、グラフをレイヤーごとに処理できるようになります。 
2. 個別の距離値を昇順に並べ替えます。 これにより、ノード 1 の距離 0 から始まる BFS 階層化順序が確立されます。 
3. 応答変数を 1 として初期化し、前の層のノード数を表す変数 prev を維持します。 ノード 1 が距離 0 にある唯一のノードであるため、prev = 1 から開始します。 
4. 各距離レイヤー d を昇順に繰り返します。 cur をこの距離にあるノードの数とします。 レイヤの存在に関して d が正確に prev_ distance + 1 ではない場合 (距離にギャップがあることを意味します)、すぐに 0 を返します。これにより、連続する BFS レイヤを介した接続が強制されます。 
5. 有効なレイヤーごとに、概念モデルで cur に上げられた prev を答えに乗算します。 問題文で使用されている簡略化された解釈では、これは層内の各ノードに対する prev による乗算の繰り返しとして処理されます。 次に、次の反復のために prev = cur を更新します。 
6. 最終的に蓄積された答えを返します。 

正確性は、層 d の処理後、層 ≤ d のすべてのノードに最短パス制約と一致する有効な親接続が割り当てられており、次の層で利用可能な選択肢の数は内部構造ではなく現在の層のサイズのみに依存するという不変条件に依存します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input())
    dist = list(map(int, input().split()))

    freq = {}
    for d in dist:
        freq[d] = freq.get(d, 0) + 1

    layers = sorted(freq.items())

    # must start from distance 0 (node 1)
    if layers[0][0] != 0:
        print(0)
        return

    ans = 1
    prev = layers[0][1]  # nodes at distance 0, should be 1

    for i in range(1, len(layers)):
        d, cur = layers[i]

        # distance must be consecutive
        if layers[i - 1][0] + 1 != d:
            print(0)
            return

        # each node chooses a parent in previous layer
        ans = (ans * pow(prev, cur, MOD)) % MOD

        prev = cur

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、まず入力を距離レベルごとの頻度カウントに圧縮します。 これにより、アイデンティティ レベルの複雑さが取り除かれ、構造情報のみが残ります。 

並べ替えられた`layers`list により、BFS レベルが順番に処理されることが保証されます。 連続距離のチェックでは、すべてのレイヤーが前のレイヤーから到達可能でなければならないことが強制されます。 そうでなければ、最小のグラフは存在できません。 

重要な移行は、`ans = ans * pow(prev, cur, MOD)`、それぞれの`cur`ノードは独立して次のいずれかを選択します`prev`両親。 べき乗剰余演算が必要なのは、`cur`大きくなる可能性があり、乗算を繰り返すと遅すぎる可能性があります。 

変数`prev`に更新されます`cur`各レイヤーを処理した後、常に前の BFS レベルのサイズを表すという不変条件を維持します。 

## 実用的な例

 ### 例 1

 距離を考慮してください。`[0, 1, 1, 2]`| ステップ | レイヤー | 前へ | カー | 貢献 | 答え |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 0 | 1 | 1 | 初期化 | 1 |
 | 2 | 1 | 1 | 2 | 1^2 = 1 | 1 |
 | 3 | 2 | 2 | 1 | 2^1 = 2 | 2 |

 これは、距離 1 にある 2 つのノードにはそれぞれ 1 つの親選択肢 (ノード 1) があり、距離 2 にあるノードには前のレイヤーの中で 2 つの選択肢があることがわかります。 

最終的な答えは 2 です。 

### 例 2

 距離を考慮してください。`[0, 1, 2, 2]`| ステップ | レイヤー | 前へ | カー | 貢献 | 答え |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 0 | 1 | 1 | 初期化 | 1 |
 | 2 | 1 | 1 | 1 | 1^1 = 1 | 1 |
 | 3 | 2 | 1 | 2 | 1^2 = 1 | 1 |

 距離 2 に 2 つのノードがありますが、それぞれの親の選択肢は 1 つだけなので、答えは 1 のままです。 

これらのトレースは、計算が内部構造ではなく層のサイズのみに依存していることを確認しています。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    MOD = 10**9 + 7

    n = int(input())
    dist = list(map(int, input().split()))

    freq = {}
    for d in dist:
        freq[d] = freq.get(d, 0) + 1

    layers = sorted(freq.items())

    if layers[0][0] != 0:
        return "0\n"

    ans = 1
    prev = layers[0][1]

    for i in range(1, len(layers)):
        d, cur = layers[i]
        if layers[i - 1][0] + 1 != d:
            return "0\n"
        ans = (ans * pow(prev, cur, MOD)) % MOD
        prev = cur

    return str(ans) + "\n"

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、距離 0 の後の最初のレイヤーが欠落しているか、位置がずれている場合です。 のような入力の場合`0 2`、距離 2 にはノードがありますが、距離 1 にはノードがありません。アルゴリズムは、連続した層の差分をチェックするときにこれを検出し、乗算が行われる前にすぐに 0 を返します。 

もう 1 つのケースは、単一ノード グラフです。 入力あり`[0]`の場合、周波数マップは 1 つのレイヤーのみを生成します。 アルゴリズムが初期化されます`ans = 1`ループに入ることはなく、単純なグラフが 1 つだけ存在するため、正しく 1 が返されます。 

3 番目のケースは、レイヤーが存在するが連続していない場合です。`[0, 1, 1, 3]`。 レイヤ 3 を処理する場合、前のレイヤは 1 であり、次の予想される距離は 2 である必要があります。チェックは失敗して 0 を返し、無効な部分的な計算が防止されます。
