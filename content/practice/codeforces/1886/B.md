 ## 解決策
 ## 問題の理解

 Monocarp は原点から始まります$(0,0)$そしてその時点で彼の家に着きたいと思っています$P$。 点在する 2 つのランタンからのみライトアップされる領域$A$そして$B$。 両方のランタンは同じ電力を使用する必要があります$w$、つまり、各ランタンが半径の円盤を照らします。$w$。 

の最小値が必要です$w$原点から家まで、照らされた領域から決して離れることのない連続した経路が存在するように。 

照らされる領域は、等しい半径の 2 つの円を結合したものにすぎません。$w$。 両方の終点、原点と家が、接続されている同じ照明コンポーネントに属している場合、有効なパスが存在します。 

座標は最大でも$1000$大きさは最大で、$10^4$テストケース。 テスト ケースごとに実質的な作業を行うソリューションは無駄になります。 該当箇所が4つしかないので、$O$、$P$、$A$、 そして$B$、定数時間の幾何学的解を期待する必要があります。 

見落としがちな状況がいくつかあります。 

原点と家が同じ提灯で覆われているとします。 例えば：```
P=(2,0)
A=(1,0)
B=(100,100)
```答えは単に次の大きい方です。$AO$そして$AP$。 常に両方のランタンを使用しようとするソリューションでは、結果が過大評価されてしまいます。 

もう 1 つの注意が必要なケースは、原点が 1 つのランタンで覆われ、家がもう 1 つのランタンで覆われている場合です。 次に、Monocarp が一方の照明領域からもう一方の照明領域に移動できるように、2 つの照明された円が交差するか接触する必要があります。 例えば：```
P=(10,0)
A=(0,0)
B=(10,0)
```最小半径は$5$、 ない$0$。 各エンドポイントはすでにランタンの中心にありますが、円は接続する必要があります。 

円の境界が点灯するため、タッチすると接続されたものとしてカウントされます。 ランタンの中心間の距離が正確であれば、$2w$、円はある点で交わっており、パスはまだ存在しています。 

## アプローチ

 自然な最初のアイデアは、答えの二分探索です。 

固定半径の場合$w$、有効な照明されたパスが存在するかどうかを確認できます。 原点はサークルに属します$A$もし$AO \le w$、他のすべての点と円の関係についても同様です。 二つの円はいつでも繋がる$AB \le 2w$。 これにより、原点、家、および 2 つの円で構成される小さなグラフが作成されます。 原点と家が同じ接続された照明コンポーネント内にあるかどうかを判断できます。 

チェックには一定の時間がかかり、実数に対する二分探索では必要以上の精度を達成するために約 60 回の反復が必要です。 これはもう快適に過ぎます。 

重要な観察は、ランタンが 2 つしかないことです。 有効なパスはすべて、非常に少数の構成のいずれかに該当する必要があります。 

1 つのランタンだけで両方の終点をカバーするか、起点を 1 つのランタンでカバーし、家をもう 1 つのランタンでカバーします。 他に可能性はありません。 

1 つのランタンが両方の端点をカバーする場合、必要な半径は単に 2 つの端点までの距離の最大値になります。 

異なるランタンが 2 つのエンドポイントを担当する場合、次の 3 つの条件が同時に満たされる必要があります。 

1. 最初のランタンが終点を覆います。 
2. 2 番目のランタンが終点を覆います。 
3. 2 つの円が交差します。 

必要な半径は、これら 3 つの要件のうちの最大値です。 

エンドポイントへのランタンの可能な割り当ては 2 つだけであるため、すべての候補を直接計算して最小値を取得できます。 これにより、二分探索の必要性が完全になくなります。

 ## アルゴリズムのチュートリアル

 1. 関連するすべての距離を計算します。 

-$AO, AP, BO, BP,$そして$AB$。 
2. ランタンの場合を考えてみましょう。$A$それだけで起源と家の両方がカバーされます。 

必要な半径は次のとおりです。$$\max(AO, AP)$$3. ランタンの場合を考えてみましょう。$B$それだけで起源と家の両方がカバーされます。 

必要な半径は次のとおりです。$$\max(BO, BP)$$4. 原点がランタンで覆われている場合を考える$A$そしてランタンの家$B$。 

起源が必要とするのは、$AO \le w$、家が必要とする$BP \le w$、円が交差する必要があります。それには次のことが必要です。$$AB \le 2w$$したがって、次のようになります。$$w=\max\left(AO,\ BP,\ \frac{AB}{2}\right)$$5. 原点がランタンで覆われている対称割り当てを検討します。$B$そしてランタンの家$A$。 

必要な半径は次のとおりです。$$w=\max\left(BO,\ AP,\ \frac{AB}{2}\right)$$6. 答えは 4 つの半径候補のうちの最小値です。 

### なぜ効果があるのか

 照らされた領域は、正確に 2 つのディスクを結合したものです。 原点から家までのパスは、原点を含むディスクで始まり、家を含むディスクで終わる必要があります。 

両方のエンドポイントが同じディスク内にある場合、そのディスクのみが接続された照明付きルートを提供します。 これにより、最初の 2 つの候補が得られます。 

それ以外の場合、原点とハウスは異なるディスクに存在する必要があります。 ディスクが 2 つしか存在しないため、Monocarp は一方のディスクからもう一方のディスクに移動する必要があります。 それはまさにディスクが交差するか接触するときに可能になります。 半径は、2 つの端点のカバレッジ要件と交差要件を同時に満たす必要があります。 これにより、残りの 2 つの候補が得られます。 

考えられるすべての有効な構成はこれら 4 つのケースのいずれかに属し、各候補はそのケースを実現可能にする最小の半径になります。 すべてのケースで最小値を取ると、全体的な最適値が得られます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def dist(x1, y1, x2, y2):
    return math.hypot(x1 - x2, y1 - y2)

t = int(input())

for _ in range(t):
    px, py = map(int, input().split())
    ax, ay = map(int, input().split())
    bx, by = map(int, input().split())

    ao = dist(ax, ay, 0, 0)
    ap = dist(ax, ay, px, py)

    bo = dist(bx, by, 0, 0)
    bp = dist(bx, by, px, py)

    ab = dist(ax, ay, bx, by)

    ans = min(
        max(ao, ap),
        max(bo, bp),
        max(ao, bp, ab / 2.0),
        max(bo, ap, ab / 2.0),
    )

    print(f"{ans:.10f}")
```最初の部分では、問題に関連するジオメトリを完全に記述する 5 つの距離を計算します。 

次の 4 つの式は、証明で説明した 4 つの可能な接続パターンに正確に対応します。 

微妙な点は見た目です。`ab / 2.0`。 半径が等しい 2 つの円$w$交差するとき$AB \le 2w$、これは以下と同等です$w \ge AB/2$。 この 2 の係数を忘れることは、最も一般的な間違いです。 

使用する`math.hypot`数値の安定性を維持しながら、手動での二乗や平方根の計算を回避します。 

小数点以下 10 桁を印刷すると、必要な条件を簡単に満たすことができます。$10^{-6}$精度。

 ## 特殊なケース

 ### ランタンは 1 つだけで十分です

 入力:```
1
2 0
1 0
100 100
```距離は次のとおりです。```
AO = 1
AP = 1
```ランタン$A$両方の端点を半径でカバーします$1$。 アルゴリズムは計算します`max(AO, AP)=1`そしてそれを返します。 両方のランタンに参加を強制するアプローチは、より大きな答えを生み出すでしょう。 

### 異なるランタンが 2 つのエンドポイントをカバーします

 入力:```
1
10 0
0 0
10 0
```原点はランタンにあり$A$の中心で、家はランタンのところにあります$B$のセンターです。 カバレッジだけで半径が示唆される$0$ただし、照らされた領域は切断されます。 

アルゴリズムもチェックします$AB/2 = 5$、生産:```
max(AO, BP, AB/2) = 5
```これが真の最小半径です。 

### 円はタッチのみ

 入力:```
1
4 0
0 0
4 0
```最適な半径は$2$。 

円は正確に 1 点で交わります。その理由は次のとおりです。$$AB = 4 = 2 \times 2$$境界線が光るのでタッチするだけで十分です。 式は非厳密な条件を使用するため、これを自然に処理します。$AB \le 2w$。 

### 対称的な割り当て

 入力:```
1
3 3
4 3
-1 -1
```ランタンのラベルを入れ替えたサンプル第2弾です。 

アルゴリズムは両方の混合割り当てを評価します。$$\max(AO, BP, AB/2)$$そして$$\max(BO, AP, AB/2)$$したがって、どのランタンが原点を覆い、どのランタンが家を覆っているかに関係なく、正しいままです。
