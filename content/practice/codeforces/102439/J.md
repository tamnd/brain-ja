 ## 解決策
 ## 問題の理解

 Josya は入力の最初の参加者です。 各アスリートは同じように 5 周を走り、合計 20 個の標的を撃ちます。 10 個の標的は伏臥位から、10 個は立位から発射されます。 ヒットには追加時間はかかりませんが、ミスするたびに正確に 60 秒が追加されます。 

アスリート (i) の場合、(K_i) を見逃したターゲットの総数とします。 この場合、すべての比較で相殺される一般的な撮影時間を除いたレース時間は次のようになります。 

[
 5\cdot time_i + 60K_i。 
】

 10 回の伏せショットにより、10 回の試行とミス確率 (1-down_i) の二項確率変数が得られます。 10 回のスタンディング ショットにより、10 回の試行とミス確率 (1-up_i) を持つ別の二項確率変数が得られます。 したがって、(K_i) は 0 から 20 までの 21 個の値のみを取ることができます。 

Josya が表彰台に立つのは、他の 2 人のアスリートが厳密に彼女よりも速くゴールしたときです。 等しいことは高速であるとはみなされません。これが、比較における境界ケースの主な原因です。 

入力には最大 50,000 人のアスリートが含まれており、ラップタイムは最大 600 秒です。 可能性のあるミスカウントの数はわずか 21 であるため、大きな要素は競技者の数であり、可能性のあるレースタイムの範囲ではありません。 (O(n^2)) メソッドでは、最大サイズで約 (2.5\cdot10^9) 個のペアごとの操作がすでに必要になりますが、これは 2 秒の制限をはるかに超えています。 アスリート一人当たりの仕事量が一定になるような方法が必要です。 

一見合理的な実装が間違っている可能性がある特殊なケースがいくつかあります。 まず、同点は速い選手としてみなされてはなりません。 例えば、```
4
10 1.000 1.000
10 1.000 1.000
10 1.000 1.000
10 1.000 1.000
```答えがあります`1.000000000000`。 すべてのアスリートがまったく同じ時間に終了するため、ジョシャには自分より速い対戦相手はいません。 を使用した比較`<=`の代わりに`<`誤って同点の 3 人の選手を数えてしまう可能性があります。 

1 分のペナルティも正確な境界線を作成します。 考慮する```
4
10 0.500 0.500
22 1.000 1.000
22 1.000 1.000
22 1.000 1.000
```Josya の基本タイムは (50) 秒です。 たった 1 回のミスで、彼女は (110) 秒でフィニッシュします。これは、他の対戦相手とまったく同じ時間です。 その場合でも彼女はまだ表彰台に上っている。 2 回以上ミスした場合、3 人の対戦相手全員が厳密に速くなります。 Josya にはミス確率 (1/2) の独立したショットが 20 個あるため、答えは次のようになります。 

\frac{21}{1048576}。 
】

 誤って等価性を高速なものとして扱う式は、全体 (K=1) の寄与を失うことになります。 

参加人数の少なさも特別です。 アスリートが 1 人、2 人、または 3 人いる場合、Josya は厳密に 3 人のアスリートを自分より先に置くことはできないため、答えは常に 1 になります。たとえば```
1
100 0.000 0.000
```答えがあります`1.000000000000`、Josyaの射撃分布に関係なく。 

最後に、正確に 0 または 1 の確率は、(1-p) などの確率で除算することなく機能する必要があります。 以下を含む二項漸化式に基づく実装`p / (1-p)`アスリートが確率 1 を打った場合、ゼロで割ることができます。二項項を計算することで、この問題が直接回避されます。 

## アプローチ

 直接的なブルート フォース ソリューションでは、最初にすべてのアスリートの考えられるすべてのミス カウントの確率を計算し、次にミス カウントのすべての組み合わせを列挙します。 各アスリートには 21 の可能な合計があるため、(n) 人のアスリートについては (21^n) 通りのレース結果が考えられます。 各結果が確率によって重み付けされる必要があるという事実を無視しても、(n=50000) の場合、これは絶望的に大きいです。 

ミスカウントの完全な割り当てがすべてのレースタイムを完全に決定するため、ブルートフォースが機能します。 実際にはすべてのアスリートの正確な結果を知る必要がないため、これは失敗します。 Josya の結果を固定するには、各競技者を 1 つのベルヌーイ イベントに減らすことができます。つまり、この競技者は厳密に Josya よりも速くゴールしたか?

 この観察によって問題は完全に変わります。 Josya のミス数を (k) に修正します。 他のすべてのアスリート (i) について、次のように計算できます。 

[
 q_i(k)=P(\text{アスリート }i\text{ は厳密には Josya よりも早く終了します}\mid K_J=k)。 
】

 (k) が固定されると、さまざまな競技者のイベントは独立します。 成功したベルヌーイ イベントの数が 0、1、または 2 であるかどうかのみを考慮します。3 以上の値は、Josya が表彰台を逃したことを意味するためです。 

3 状態の動的プログラミング配列を維持できます。 最初は、より速いアスリートが 0 人いる確率は 1 です。Josya より速い確率 (q) で競技者を処理した後、現在のカウントを維持するか、1 ずつ増やすことによって状態が更新されます。 2 つ以上の状態は答えに寄与できないため、破棄します。 

残りの問題は、(q_i(k)) を効率的に計算する方法です。 Josya がラップ タイム (T) と (k) のミスを持ち、競合他社 (i) がラップ タイム (t_i) と (j) のミスを持っているとします。 競合他社は次の場合に厳密に高速です。 

[
 5t_i+60j < 5T+60k。 
】

 5で割るとこうなります

 [
 t_i+12j < T+12k。 
】

 固定 (k) の場合、許容される最大の整数 (j) は次のとおりです。 

[
 m=\left\lfloor\frac{T+12k-t_i-1}{12}\right\r フロア。 
】

 したがって、(q_i(k)) は単に、アスリート (i) が最大 (m) 回のミスをする確率です。 (m) は、関連する場合には常に 0 から 20 の間であるため、すべてのアスリートのミス数の累積分布関数を事前に計算できます。 

(k) の可能な値は 21 個だけです。 それぞれについて、すべての (n-1) 競合他社を処理し、3 つの DP 状態を維持します。 これにより、(O(21n)) 個の最終計算が行われます。 各アスリートの 21 値のミス分布の計算にも一定量の作業がかかります。これは、サイズ 11 の 2 つの二項分布の畳み込みであるためです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(21^n)) | (O(n)) | 遅すぎる |
 | 最適 | (O(21n)) | (O(21n)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. Josya のラップタイムとシュート確率を読み取り、次に残りのアスリートを読み取ります。 (n) の後の最初の入力行は Josya を説明しているため、彼女を競合他社から分離する必要があります。 
2. すべてのアスリートについて、合計ミス数の確率分布を作成します。 うつ伏せ部分は 10 回の試行とミス確率 (1-down_i) の二項分布ですが、立っている部分は 10 回の試行とミス確率 (1-up_i) があります。 これら 2 つの分布を畳み込むと、合計 0 ～ 20 のミスの確率が得られます。 
3. すべての競技者のミス分布を累積分布に変換します。 0 から 20 までのすべての (x) に対して (F_i[x]=P(K_i\le x)) を格納します。累積形式を使用することで、Josya よりも高速なクエリを定数時間で答えることができます。 
4. 0 から 20 までのすべての (k) について Josya 独自の分布 (P_J[k]=P(K_J=k)) を計算します。(k) の考えられる各値を個別に条件付けします。 
5. 特定の Josya ミス カウント (k) を修正します。 一般的な射撃時間を除いた彼女の有効レースタイムは (5T+60k) です。 競合他社 (i) については、次のように計算します。 

[
 m_i=\left\lfloor\frac{T+12k-t_i-1}{12}\right\r フロア。 
】

1 による減算は、厳密な不等式を整数の上限に変換するものです。 これがないと、正確な同点が誤ってより速いフィニッシュとしてカウントされてしまいます。 

1. (m_i<0) の場合、競合他社 (i) の方が速い可能性は低いため、(q_i=0) に設定します。 (m_i\ge20) の場合、あらゆるミス回数がその競技者を速くするため、(q_i=1) に設定します。 それ以外の場合は、(q_i=F_i[m_i]) を使用します。 
2. DP 配列で競合他社を 1 つずつ処理します`dp`。 その 3 つのエントリは、正確に 0、1、または 2 つの処理された競合他社が Josya よりも厳密に高速である確率を表します。 確率 (q) が速い競合他社の場合、遷移は次のようになります。 

[
 new_0=dp_0(1-q),
 】

 [
 new_1=dp_1(1-q)+dp_0q、
 】

 [
 new_2=dp_2(1-q)+dp_1q。 
】

 3 人以上の速い選手がいる州はジョシャを表彰台に乗せることができないため除外されます。 

1. すべての競合他社の処理が完了したら、`dp[0] + dp[1] + dp[2]`は、Josya が与えられた表彰台に立つ条件付き確率 (K_J=k) です。 これに (P_J[k]) を掛けて、グローバルな答えに追加します。 
2. 考えられる 21 個の Josya ミス カウントすべてに対して DP を繰り返し、結果の確率を出力します。 

### なぜ効果があるのか

 Josya のミスカウント (k) を修正すると、彼女のレースタイムが完全に修正されます。 すべての競技者にとって、より速いというイベントはベルヌーイ イベントであり、その確率は、導出されたしきい値での競技者のミスカウント CDF と正確に一致します。 さまざまなアスリートが独立して射撃するため、これらのベルヌーイ イベントは独立しています。 

DP の不変条件は、いくつかの競合他社を処理した後、`dp[x]`は、これらの処理された競合他社のうち正確に (x) 個が Josya よりも厳密に高速である確率です ((x\in{0,1,2}))。 新しい競合他社はそれぞれ、より高速なセットの外側に留まるか、それに参加して、指定されたトランジションを正確に実行します。 表彰台になれるのは最大 2 カウントまでであるため、それ以上のカウントを破棄しても有効な結果は失われません。 

最後に、Josya のミス数の 21 の可能な値は、ばらばらであり、網羅的です。 各条件付き表彰台確率を Josya の対応するミスカウント確率で重み付けすると、必要な合計確率が正確に得られます。 

## Python ソリューション```python
import sys
from array import array

input = sys.stdin.readline

C10 = [1, 10, 45, 120, 210, 252, 210, 120, 45, 10, 1]

def distribution(down, up):
    # Number of misses in the 10 prone shots.
    miss_down = 1.0 - down
    prone = [
        C10[k] * (miss_down ** k) * (down ** (10 - k))
        for k in range(11)
    ]

    # Number of misses in the 10 standing shots.
    miss_up = 1.0 - up
    standing = [
        C10[k] * (miss_up ** k) * (up ** (10 - k))
        for k in range(11)
    ]

    # Convolution: total misses range from 0 to 20.
    dist = [0.0] * 21
    for i in range(11):
        pi = prone[i]
        for j in range(11):
            dist[i + j] += pi * standing[j]

    return dist

def solve():
    n = int(input())

    t0, down0, up0 = input().split()
    t0 = int(t0)
    down0 = float(down0)
    up0 = float(up0)

    # Store competitors' lap times separately. Their CDFs are
    # stored transposed: cdfs[m][i] is competitor i's P(K <= m).
    times = []
    cdfs = [array('d') for _ in range(21)]

    for _ in range(n - 1):
        t, down, up = input().split()
        t = int(t)
        down = float(down)
        up = float(up)

        times.append(t)

        dist = distribution(down, up)
        cur = 0.0
        for k in range(21):
            cur += dist[k]
            cdfs[k].append(cur)

    josya = distribution(down0, up0)

    ans = 0.0
    competitors = n - 1

    for k in range(21):
        pj = josya[k]
        if pj == 0.0:
            continue

        dp0, dp1, dp2 = 1.0, 0.0, 0.0

        for i in range(competitors):
            # Competitor is faster iff
            # 5 * times[i] + 60 * misses
            # < 5 * t0 + 60 * k.
            #
            # Equivalent to
            # 12 * misses < t0 + 12*k - times[i].
            #
            # Maximum integer misses is floor((D - 1) / 12).
            D = t0 + 12 * k - times[i]
            m = (D - 1) // 12

            if m < 0:
                q = 0.0
            elif m >= 20:
                q = 1.0
            else:
                q = cdfs[m][i]

            nq = 1.0 - q

            ndp2 = dp2 * nq + dp1 * q
            ndp1 = dp1 * nq + dp0 * q
            ndp0 = dp0 * nq

            dp0, dp1, dp2 = ndp0, ndp1, ndp2

        ans += pj * (dp0 + dp1 + dp2)

    print(f"{ans:.12f}")

if __name__ == "__main__":
    solve()
```の`distribution`関数は最初に 2 つの二項分布を作成します。 指数はミスの数であり、残りの指数はヒットの数です。 式を直接記述すると、ヒット確率が正確に 0 または 1 の場合に、ゼロによる除算が回避されます。 

畳み込みは、10 回の伏せショットと 10 回のスタンディング ショットを組み合わせます。 各分布には 11 項しかないため、アスリートごとに 121 回の乗算が継続的に行われます。 

累積分布は次の場所に保存されます。`array('d')`float のネストされた Python リストではなく、オブジェクトです。 保存される値は最大 (21\cdot49999) で、double は 8 バイトを占めるため、数値データとして約 8.4 MB が必要になります。 これにより、メモリ使用量が 256 MB の制限を快適に下回ります。 

比較には、`D = t0 + 12 * k - times[i]`。 表現`(D - 1) // 12`意図的です。 たとえば、次の場合`D`はちょうど 12 です。条件は次のとおりです。`12 * misses < 12`、したがって、ゼロミスのみが許可されます。 式は次のようになります`(12 - 1) // 12 = 0`。 使用する`D // 12`誤って 1 つのミスを許可し、同点を競合他社の勝利に変えてしまう可能性があります。 

希望するイベントでは、より速いアスリートが最大 2 名いることであるため、DP は 3 つの州のみを保持します。 4 番目の状態は答えには決して寄与しないため、それを保存しても不必要な作業が追加されるだけです。 

Python では整数オーバーフローは発生せず、すべての確率計算で倍精度浮動小数点が使用されます。 必要な誤差は (10^{-9}) ですが、計算には小さな確率分布と約 100 万回の DP 遷移のみが含まれるため、結果として生じる浮動小数点誤差は安全に必要な許容範囲内に収まります。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | (O(21\cdot121\cdot n + 21n)) = (O(n)) | 各アスリートの 2 つの 11 要素の二項分布が畳み込まれ、21 の Josya 結果のすべてが 3 つの DP 状態ですべての競技者を処理します。 |
 | スペース | (O(21n)) | すべての競技者の 21 の累積確率とラップタイムを保存します。 |

 最大ミス数が 20 に固定されているため、定数係数は小さくなります。50,000 人のアスリートの場合、メイン DP は約 100 万回の競技者のトランジションのみを実行しますが、分散構築では約 600 万回の単純な算術演算が実行されます。 コンパクト`array('d')`ストレージもメモリ使用量を 256 MB 未満に抑えます。

def distribution(down, up):
    miss_down = 1.0 - down
    prone = [
        C10[k] * (miss_down ** k) * (down ** (10 - k))
        for k in range(11)
    ]

    miss_up = 1.0 - up
    standing = [
        C10[k] * (miss_up ** k) * (up ** (10 - k))
        for k in range(11)
    ]

    dist = [0.0] * 21
    for i in range(11):
        for j in range(11):
            dist[i + j] += prone[i] * standing[j]

    return dist

def solve():
    input = sys.stdin.readline
    n = int(input())

    t0, down0, up0 = input().split()
    t0 = int(t0)
    down0 = float(down0)
    up0 = float(up0)

    times = []
    cdfs = [array('d') for _ in range(21)]

    for _ in range(n - 1):
        t, down, up = input().split()
        t = int(t)
        down = float(down)
        up = float(up)

        times.append(t)

        dist = distribution(down, up)
        cur = 0.0
        for k in range(21):
            cur += dist[k]
            cdfs[k].append(cur)

    josya = distribution(down0, up0)

    ans = 0.0

    for k in range(21):
        pj = josya[k]
        if pj == 0.0:
            continue

        dp0, dp1, dp2 = 1.0, 0.0, 0.0

        for i in range(n - 1):
            D = t0 + 12 * k - times[i]
            m = (D - 1) // 12

            if m < 0:
                q = 0.0
            elif m >= 20:
                q = 1.0
            else:
                q = cdfs[m][i]

            nq = 1.0 - q

            ndp2 = dp2 * nq + dp1 * q
            ndp1 = dp1 * nq + dp0 * q
            ndp0 = dp0 * nq

            dp0, dp1, dp2 = ndp0, ndp1, ndp2

        ans += pj * (dp0 + dp1 + dp2)

    print(f"{ans:.12f}")

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        solve()
        return sys.stdout.getvalue().strip()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

 ## 特殊なケース

 等しい時間のケースは次のように処理されます。`D - 1`閾値の式で。 のために```
4
10 1.000 1.000
10 1.000 1.000
10 1.000 1.000
10 1.000 1.000
```Josya は (k=0)、すべての競合他社については (D=0) を持っています。 式は (m=(-1)//12=-1) を与えるため、より速い確率はすべてゼロになります。 DPは残る`(1, 0, 0)`そして答えはまさに 1 です。 

正確な 1 分の境界も同様に処理されます。 のために```
4
10 0.500 0.500
22 1.000 1.000
22 1.000 1.000
22 1.000 1.000
```Josya が 1 回ミスしたとき (D=0)、与えました (m=-1)。 競合他社は 110 秒で並んでおり、より速い確率は正確にゼロです。 Josya が 2 回ミス (D=60)、ギブ (m=4) をした場合、クリーンな競技者はすべて厳密に速くなります。 したがって、アルゴリズムは (k=0) および (k=1) のケースを正確に保持し、(21/1048576) を生成します。 

参加者が一人の場合、```
1
100 0.000 0.000
```競合他社の移行はまったくありません。 DP は次から始まります`(1, 0, 0)`考えられるすべての Josya ミス カウントに対して、Josya 分布の合計は 1 になります。したがって、メイン アルゴリズムで特別なケースを必要とせずに、答えは 1 になります。 

決定論的な射撃確率が 0 または 1 に等しい場合、直接二項式は引き続き有効です。 ヒット確率が 1 の場合、すべての正のミス カウントの確率は 0 になります。 ヒット確率が 0 の場合、最大ミス カウントのみが確率 1 を受け取ります。 実装ではヒットまたはミスの確率で除算することがないため、両方のエンドポイントが数値的な例外なく処理されます。
