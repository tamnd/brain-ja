 ## 問題の理解

 整数に対して定義された関数が与えられています`x`バイナリ表現を通じて解釈されます。 各整数はビット位置のセットとすべての数値に対応します。`y ≤ x`と`y & x = y`まさに次のサブマスクです`x`、つまり、すでに存在するビットのみを使用します。`x`。 

関数はベースレイヤーから始まります。`f(0, x)`は単に次の値です`x`自体。 次の各層はすべてのサブマスクを取得して構築されます`y`の`x`以前の値を合計します`f(k-1, y)`。 したがって、各ステップで情報がビットマスクのサブセット格子を通じて下方に拡散され、すべてのサブセットからの寄与が繰り返し蓄積されます。 

入力は複数の独立したクエリを提供し、それぞれが指定された深さでこの関数の値を要求します。`k`そしてマスク`x`、両方とも最大`3 × 10^5`、そして最大`10^5`クエリ。 

素朴な解釈では、すべてのテストおよびすべてのレベルのすべてのサブマスクにわたってサブセットの合計が繰り返されることが示唆されます。`k`。 サブマスクの数は設定ビット数に応じて指数関数的に増加するため、これはすでに問題を示唆しています。 最大 19 ビットであっても、クエリごと、およびクエリごとにこのような操作を繰り返すと、`k`実現可能な限界をはるかに超えているでしょう。 

実際の制約圧力は、大きな制約の組み合わせから生じます。`t`そして大きい`k`。 クエリごとにサブマスクを再計算するアプローチ、または構造を単純化せずに各ビットを個別に再計算するアプローチは、時間制限を超えます。 

再発を直接シミュレートしようとすると、微妙な失敗例がすぐに現れます。 

たとえば、`x = 7 (111₂)`そして`k = 2`、直接実装すると、すべてのサブセットが 2 回列挙され、同じサブ構造の再計算が繰り返されることになります。 均等キャッシュごと`(k, x)`どちらの次元も大きく、状態空間はビット単位で指数関数的であるため、これは不可能です。 

最大の問題点は、再発が局所的に見えることです。`x`ですが、実際にはサブセット格子全体に繰り返し伝播します。 

## アプローチ

 再帰は、繰り返し適用される古典的なサブセット合計演算子です。 変換の 1 つの適用により関数が置き換えられます`g(x)`の合計で`g(y)`すべてのサブマスクにわたって`y ⊆ x`。 これはサブセット ゼータ変換として知られています。 問題はこの変換を適用します`k`から始まる回`g(0, x) = x`。 

ブルート フォース シミュレーションでは、各レイヤーのすべてのサブマスクの合計が明示的に再計算されます。 1 つのアプリケーションにはすでに費用がかかります`O(3^n_bits)`サブセット列挙を使用して集合的にマスクごとに実行し、それを繰り返す`k`時代はそれを絶望的にします。 

重要な構造的観察は、この変換がビット全体にわたって線形であり、サブセットの独立性が尊重されていることです。 各ビットはサブセットの形成方法において独立して動作するため、値を繰り返し合計するのではなく、サブセット格子内のチェーンをカウントするプロセスとして再解釈できます。 

値を直接追跡する代わりに、繰り返しを組み合わせて再解釈します。 変換の各アプリケーションは、ビットを異なる層に導入できるようにすることに対応するため、プロセスはサブセットに含まれるシーケンスをカウントすることになります。 これは問題を、各ビットが 0 から 1 に遷移する方法を数えることに変換します。`k`開始サブセットの元の値によって寄与を重み付けしながら、ステップを実行します。 

このように表現すると、ビット間の独立性が使用可能になります。寄与がビットごとの選択に考慮され、すべてのサブマスクの合計がきれいに因数分解されます。 

これにより、次の 3 つの量のみに依存する閉じた形式の式が得られます。`x`、設定されたビット数`x`、および力`k`そして`(1 + k^{-1})`。

 ## アルゴリズムのチュートリアル

 サブマスクチェーンの観点から繰り返しを書き直し、ビットごとの寄与を分離することにより、閉じた形式を導き出します。 

1. 再帰の各ステップを、すべてのサブマスクにわたって関数を拡張するものとして解釈します。これは、サブセット ラティス内を下に移動することに対応します。 後`k`ステップ、すべての値はすべてのチェーンの長さに依存します`k`で終わる`x`。 
2. 開始サブマスクを修正する`y ⊆ x`。 の貢献`y`後`k`ステップは、私たちがどれだけ成長できるかによってのみ決まります`y`の中へ`x`まさに`k`層。 に存在する各ビット`x`しかし、中にはありません`y`あるステップで導入する必要があり、そのような各ビットは独立して次のいずれかを選択します。`k`ステップ。 
3. これは、固定長を拡張する方法が多数あることを意味します。`y`に`x`は`k^(popcount(x) - popcount(y))`。 繰り返しはすべてのサブマスクの重み付けされた合計となり、重みはサブマスクのサイズのみに依存します。 
4. 関数を、各ビットの寄与の合計として書き換えます。`y`。 各ビットは独立して整数値に寄与します。`y`したがって、ビットを固定し、それを含むすべてのサブマスクをカウントすることで合計を分離します。 
5.固定ビットの場合`i`、残りのビットは、より小さな独立したサブセットを形成します。 これにより、合計をビット単位の積に因数分解することができ、ヘルパー項のコンパクトな式が得られます。`S(x)`、ビット上の幾何積になります。 
6. サブマスクの合計`S(x)`単純化すると`(1 + k^{-1})^(popcount(x))`各ビットが存在しない (重み 1) か、存在する (重み 1) かのいずれかであるため、`k^{-1}`）。 
7. 因数分解を組み合わせると、最終的な式は次のようになります。`f(k, x) = x × k^(popcount(x) - 1) × (1 + k^{-1})^(popcount(x) - 1)`。 
8. モジュラー逆関数を事前計算します。`k`、ポップカウントと値を計算します。`x`、累乗剰余を使用して効率的にべき乗を評価します。 

### なぜ効果があるのか

 再帰は、サブセット上の関数に対する線形演算子を定義し、繰り返し適用することは、同じ線形変換を複数回適用することに対応します。 サブセット構造は独立したビットを因数分解するため、演算子はビットごとの寄与に分解されます。 これにより、グローバルな組み合わせ爆発のように見えるものが、元の数値を使用したビットごとの独立した幾何学的スケーリングに変わります。`x`各寄与ビットに付加された線形重みとしてのみ機能します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

t = int(input().strip())
for _ in range(t):
    k, x = map(int, input().split())

    pc = x.bit_count()

    if pc == 1:
        print(x % MOD)
        continue

    invk = modpow(k, MOD - 2)

    base = (k % MOD) * ((1 + invk) % MOD) % MOD
    base = modpow(base, pc - 1)

    print(x % MOD * base % MOD)
```実装は完全に閉じた形式に依存しています。 唯一重要な部分は、モジュラー逆関数を計算することです。`k`、式が使用しているため、`k^{-1}`モジュラー算術設定内。 累乗はクエリごとに 1 回だけ適用されるため、ソリューションの効率が維持されます。 

特別な場合`popcount(x) = 1`式では無害ですが、明示的に記述することで指数ゼロに関する混乱が回避され、構造がより明確になります。関数は直接次のように還元されます。`x`。 

## 実用的な例

 小さなケースを考えてみましょう。`x = 3 (11₂)`そして`k = 1`。 2 つのサブマスクがあります。`0`そして`3`。 1 つのステップの後、各値はそのサブマスクの合計になります。 

| y | f(0, y) | f(1, x) | に寄与します。 
| --- | --- | --- |
 | 0 | 0 | 0 |
 | 1 | 1 | 1 |
 | 2 | 2 | 2 |
 | 3 | 3 | 3 |

 すべてのサブマスクを合計すると、`6`。 式は次のようになります`x × 2^(pc(x)-1) = 3 × 2 = 6`、正確に一致します。 

ここで考えてみましょう`x = 5 (101₂)`そして`k = 2`。 ビット数は`2`。 式は次のようになります。`f(2, 5) = 5 × 2^(1) × (1 + 1/2)^1 = 5 × 2 × 3/2 = 15`。 

概念的に追跡すると、各サブマスクは、そのビットがサブセット拡張の 2 つの層で生き残る回数によって異なる重み付けをして寄与し、閉じた形式では、これらの重み付けされた寄与を列挙せずに集計します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math

    MOD = 10**9 + 7

    def modpow(a, e):
        res = 1
        while e:
            if e & 1:
                res = res * a % MOD
            a = a * a % MOD
            e >>= 1
        return res

    t = int(input().strip())
    out = []
    for _ in range(t):
        k, x = map(int, input().split())
        pc = x.bit_count()
        if pc == 1:
            out.append(str(x % MOD))
            continue
        invk = modpow(k, MOD - 2)
        base = (k % MOD) * ((1 + invk) % MOD) % MOD
        base = modpow(base, pc - 1)
        out.append(str((x % MOD) * base % MOD))
    return "\n".join(out)

 ## 特殊なケース

 いつ`x`が 2 の累乗である場合、ビットが 1 つしかないため、反復は 1 つのチェーンに崩壊します。 アルゴリズムはこれをきれいに処理します。`popcount(x) = 1`指数をゼロにして返します`x`すべてのサブマスク チェーンが次のいずれかに還元されるという事実と直接的に一致します。`0`または、組み合わせ分岐なしの完全な値。 

いつ`k = 1`、式はすべてのサブマスクにわたる古典的なサブセットの合計に減ります。 式を簡略化すると、`x × 2^(popcount(x)-1)`これは、すべてのサブセットにわたって独立して寄与する各ビットと一致しており、変換がオーバーカウントすることなく単一のゼータ展開を正しくモデル化していることを確認します。
