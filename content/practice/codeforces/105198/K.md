 ## 解決策
 ## 問題の理解

 私たちに与えられた一行は、`n = b + g`ポジション。 その通り`g`これらのポジションのうち、女の子に割り当てられているポジションは、残りのポジションです。`b`ポジションは男子です。 これは、すべての有効な構成は単にどれを選択するかだけであることを意味します。`g`間のインデックス`1..n`女の子が含まれています。 

配置が修正された後、モンケは少年がいるポジションに立つことが許可されます。 彼は選ばれたポジションで成功していると考えられている`i`少なくともあれば`x`女の子は厳密に彼の左側、そして少なくとも`y`女の子は厳密に彼の右側にいます。 

固定配置の場合、モンケは、この条件が当てはまるボーイ ポジションが少なくとも 1 つ存在するかどうかを確認します。 タスクは、選択する方法が何通りあるのかを数えることです。`g`女の子の立場は、そのような男の子の立場が存在するようなものです。 

制約は大きく、最大で`10^5`テストケースと最大値`10^6`。 これにより、ポジションを反復したり、各配置を直接評価しようとしたりするソリューションは即座に除外されます。 答えは、各テスト ケースが一定時間で処理されるように、事前に計算された階乗とモジュラー逆関数を使用した閉形式の組み合わせを使用して表現する必要があります。 

単純なアプローチでは、すべてが生成されてしまいます。`C(b+g, g)`それぞれを調整してテストします。 単一のテスト ケースであっても、これは不可能です。`C(2×10^6, 10^6)`天文学的に大きいです。 

より巧妙な単純な試みは、女の子のセットを修正し、すべての男の子の位置をスキャンして、プレフィックスの女の子の数を再計算することです。 それはまだ費用がかかります`O(n)`取り決めに従っており、依然として実行不可能です。 

重要な問題は、この条件が女の子の正確な身元ではなく、接頭辞の数のみに依存することです。 これは、この問題を、ラインを通過する際にプレフィックス数がどのように変化するかに関する制約に置き換えることを示唆しています。 

よくある落とし穴は、モンケのポジションが配置構造とは無関係に選択できると想定していることです。 実際、有効な男の子のポジションが存在するかどうかは、考えられるすべての接頭辞の周りの女の子の分布に世界的に依存します。 

## アプローチ

 ブルートフォースの観点では、各配置を長さのバイナリ文字列として扱います。`n`まさに`g`もの。 各配置について、すべての位置でプレフィックス ガール カウントを計算し、プレフィックス カウントが適切な間隔にあるゼロ位置が存在するかどうかを確認します。 これは正しいですが、すべてをスキャンする必要があります`n`配置ごとの位置が決まり、全体的に指数関数的になります。 

重要な洞察は、視点を反転することです。 有効なボーイのポジションが存在するかどうかを尋ねるのではなく、そのようなポジションがいつ不可能であるかを尋ねます。 ポジション`i`プレフィックス数が次の場合に有効です`k = #girls in [1, i-1]`を満たす:`x ≤ k ≤ g - y`そして`i`それ自体は男の子です。 

したがって、唯一の「良い」インデックスは、プレフィックスの女の子数が一定の間隔内に収まる位置です。 そのようなポジションがすべて女の子によって占められている場合、この取り決めは失敗します。 

次に、線に沿って歩くプロセスを観察してください。 女の子を配置するたびに、プレフィックスの数は 1 つずつ増加します。 男の子を配置するたびに、プレフィックス数は変わりません。 これは、プレフィックス数が、位置ではなく、配置された女の子の数に関して単調に進化することを意味します。 

これにより、配置された女の子の数に基づいて、文字列の構築をフェーズに分割することができます。 

初めに、プレフィックス数は次のようになります。`0`。 私たちが最初に到達するのは`x`女の子たち。 この段階では、男の子には制限がありません。 正確にヒットしたら`x`女子の場合、条件を超えると男子禁制の範囲に入ります。`g - y`。 この中間範囲内に男子を配置すると、すぐに有効なモンケのポジションが作成されるため、すべてのポジションに女子が配置される必要があります。 通過後`g - y`、男の子は再び制限されなくなります。 

したがって、すべての有効な構造は厳格な構造を持っています。つまり、`x`-番目の女の子、連続する女の子の強制ブロック、そして最後のフリーインターリーブフェーズ。 

これにより、問題は、各セグメントの女の子の数が固定された 2 つの組み合わせフェーズに男の子を分配する数え方に変換されます。 各セグメントは標準的な星と棒の計数問題になり、最終的な式は単一の二項係数恒等式に分解されます。

 | 組み合わせ位相分解 | テストごとに O(1) | O(n) 事前計算 | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 最適な計数戦略

 1. まず中間区間の実現可能性を確認します。 もし`x > g - y`の場合、条件を満たすプレフィックス数は存在しないため、Monke は決して成功できず、答えは次のようになります。`0`。 
2. それ以外の場合は、配置インデックスではなく、配置された女の子の数によって構築が進化すると解釈します。 
3. プロセスを 3 つのフェーズに分割します。 

まず、`x`〜人目の女の子が登場。 このフェーズでは、男の子も女の子も自由に配置できますが、セグメントはちょうどその時点で終了します。`x`-番目の女の子が配置されます。 これによりプレフィックス構造が一意に決まります。 
4.到達後`x`女の子たち、私たちはそこから動かなければなりません`x`に`g - y`。 このインターバルでは、男子生徒が有効なモンケのポジションを形成してしまうため、男子生徒の立ち入りは禁止されています。 したがって、このセグメント全体は女の子だけで構成されており、固定ブロックに貢献します。 
5.到達後`g - y`女の子たち、残りは`y`女の子と残りの男の子全員を任意に配置できます。 
6. これらの相転移が発生する場所を選択する方法の数を数えてください。 最初のフェーズは、配置のための二項選択に貢献します。`x-1`以前のポジションの女の子。 最終フェーズは、最後のフェーズを配置するための別の二項選択に寄与します。`y`残りの枠には女の子がいます。 
7. すべての有効な分割点の合計は、ヴァンデルモンド型恒等式を介して単一の二項係数に折りたたまれます。 

### なぜ効果があるのか

 男の子はプレフィックス数を変更しないため、構造は女の子の挿入順序によって完全に決定されます。 この禁止された間隔は、連続する女子数の州の範囲に男子を配置することを禁止する制約となります。 これにより、すべての有効な設定が独立したプレフィックスとサフィックスの組み合わせの選択に考慮されるようになります。 すべての有効な配置は、女の子の位置を 2 つの独立した選択に分割することに一意に対応し、プレフィックスが到達するまでにフェーズ境界が一意に定義されるため、どの構成も 2 回カウントされません。`x`女の子たち。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

# Precompute factorials up to max needed value
MAXN = 2_000_000 + 5
fact = [1] * MAXN
invfact = [1] * MAXN

for i in range(1, MAXN):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAXN - 1] = pow(fact[MAXN - 1], MOD - 2, MOD)
for i in range(MAXN - 2, -1, -1):
    invfact[i] = invfact[i + 1] * (i + 1) % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

t = int(input())
for _ in range(t):
    b, g, x, y = map(int, input().split())

    if x > g - y:
        print(0)
        continue

    # final simplified formula
    n = b + g
    ans = C(b + x + y, x + y)
    print(ans)
```この実装は、事前に計算された階乗とモジュラー逆関数に完全に依存しています。 各クエリは定数時間の二項係数評価に帰着します。 唯一微妙な部分は実現可能性のチェックです`x > g - y`これは、有効なプレフィックス間隔が空であってはいけないという事実を捉えています。 

閉じた形式`C(b + x + y, x + y)`すべての有効な分割点にわたる 2 相の組み合わせの合計を折りたたむことから得られます。

## テストケース```python
import sys, io

MOD = 10**9 + 7

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    MAXN = 2000000 + 5
    fact = [1] * MAXN
    invfact = [1] * MAXN
    for i in range(1, MAXN):
        fact[i] = fact[i - 1] * i % MOD
    invfact[MAXN - 1] = pow(fact[MAXN - 1], MOD - 2, MOD)
    for i in range(MAXN - 2, -1, -1):
        invfact[i] = invfact[i + 1] * (i + 1) % MOD

    def C(n, r):
        if r < 0 or r > n:
            return 0
        return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

    t = int(input())
    out = []
    for _ in range(t):
        b, g, x, y = map(int, input().split())
        if x > g - y:
            out.append("0")
        else:
            out.append(str(C(b + x + y, x + y)))
    return "\n".join(out)

 ## 特殊なケース

 いつ`x > g - y`、許容されるプレフィックス数の間隔は空です。 その状況では、配置に関係なく、どの位置も左右の制約を同時に満たすことはできません。 アルゴリズムは、組み合わせ論を試行せずにゼロを返すことでこれを即座に処理します。 

いつ`x = 0`または`y = 0`、制約は片側の要件に退化します。 この公式は、境界が 1 つだけ重要であるすべての配置を効果的にカウントし、二項式が正しく減少するため、引き続き機能します。 

いつ`b`は非常に小さいため、構造によりほとんどのポジションが女子に強制されますが、特定の地域での男子の空き状況ではなく、女子の数のみに依存するため、位相分解は依然として適用されます。
