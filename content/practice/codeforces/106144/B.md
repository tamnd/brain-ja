 ## 解決策
 ## 問題の理解

 平面内に一連の点が与えられますが、これらの点の順序は固定されています。 このシーケンスから、たとえばインデックス l から r までの連続したセグメントを選択し、これらの点を順番に訪問することによって形成された多角形が、その順番で閉じられたときに厳密に凸多角形であるかどうかを確認したいと考えています。 

セグメントは、少なくとも 3 つの点が含まれている場合にのみ有効です。 セグメントが資格を得るには、セグメント内の連続する 3 つのポイントがすべて同じ方向を向く必要があり、連続する 3 つのポイントが同じ直線上に存在することは許可されません。 言い換えれば、すべての内部ターンは厳密に一貫性があり、ゼロ以外である必要があるため、ポリゴンが局所的に「平坦化」することはありません。 

各テスト ケースの出力は、そのような連続した凸セグメントの可能な最大長です。 少なくとも 3 つの長さのセグメントが条件を満たさない場合、答えは 0 になります。 

この制約により、テスト ケースごとに線形または線形に近い時間で考えることが求められます。 すべてのテスト ケースにわたるポイントの合計数は最大 2 · 10^5 であるため、テスト ケースごとに 2 次の動作を伴う解はすぐに失敗します。 これは、単純な凸性チェックでも O(n) であるため、すべての O(n^2) 間隔を明示的にチェックすることをすでに除外しており、最悪のケースは O(n^3) になります。 

重要な点は、ポイントが固定された順序で与えられることです。 凸包を形成するためにポイントを並べ替えているのではなく、指定された順序の連続したサブシーケンスをチェックしているだけです。 

単純なソリューションでは見逃される可能性のあるいくつかの失敗例:

 単一の同一線上にあるトリプルが原因で、セグメントは凸性を失敗する可能性があります。 たとえば、点 (0,0)、(1,1)、(2,2)、(3,0) はほとんどが「形状形成」されていますが、最初の 3 つは同一線上にあるため、残りが凸状に見えても、それらを含むセグメントは無効になります。 

もう 1 つの問題は、凸面に方向性があることです。 3 点が同一直線上にない場合でも、左折と右折を交互に繰り返すシーケンスは無効です。 

最後に、長さ 3 の短いセグメントは明示的にチェックする必要があります。これらは三角形を表し、同一直線上にない場合は常に凸状になります。 不用意に実装すると、それらをスキップしたり、方向の一貫性を誤って処理したりする可能性があります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 区間 [l, r] ごとに、点 l から r によって形成される多角形が順番に厳密に凸であるかどうかをテストします。 区間ごとに、すべてのトリプル (i、i+1、i+2) の向きを計算し、それらがすべてゼロではなく同一であることを確認します。 これには間隔ごとに O(r − l) の作業が必要で、間隔が O(n^2) であるため、最悪の場合合計 O(n^3) になりますが、これは n が 2 · 10^5 までの場合には遅すぎます。 

これを改善するには、間隔ごとに凸性を最初から再計算することを避ける必要があります。 重要な観察は、凸性は連続するトリプルにわたる局所的な特性であるということです。凸性はベクトル (p[i+1] − p[i]) × (p[i+2] − p[i+1]) の外積の符号にのみ依存します。 開始点 l を固定する場合、r を右に拡張するときに、すべての新しいターンが最初の方向と一致していることを確認するだけで済みます。 

これにより、問題は、導出された方向記号のシーケンスが一定で非ゼロである最長の連続部分配列を見つけることに変換されます。 ポイントを方向転換標識に変換すると、タスクは、すべての連続する標識が等しく定義されている最長のセグメントを見つけることになります。 

すべてのトリプルの方向を事前に計算し、長さ n − 2 の配列を生成します。次に、この派生配列内で、同一の非ゼロ値で構成される最長の連続セグメントを検索します。 このような各セグメントは、2 つのインデックスだけシフトされた、元の点シーケンスの最大凸間隔に対応します。

 | ブルートフォース | O(n^3) | お(1) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

1. すべてのテスト ケースについて、ポイントのリストを順番に読んでください。 順序は固定されており、変更しないでください。 
2. 連続するすべての点のトリプルの向きを計算します。 インデックス i、i+1、i+2 について、ベクトル (p[i+1] − p[i]) と (p[i+2] − p[i+1]) の外積を計算します。 この値は、ターンが時計回り、反時計回り、または同一直線上であるかどうかを示します。 
3. 外積がゼロの場合、厳密な凸性により 3 つの連続した同一線上の点が禁止されるため、この位置を無効としてマークします。 これにより、このトリプルを通過するインターバルは即座に中断されます。 
4. 外積のシーケンスを、各要素が有効なターンの場合は +1 または -1、無効な場合は 0 である符号配列に変換します。 
5. この配列をスキャンし、同じ非ゼロ符号のみを含む最長の連続セグメントを計算します。 これは、現在のストリークの継続長を維持し、符号が変わるかゼロになるたびにリセットすることによって行われます。 
6. 方向配列内の最適なストリーク長が k の場合、元の点配列内の対応する凸状間隔の長さは k + 2 になります。そのようなストリークすべてにわたって最大値を追跡します。 
7. 有効なストリークが存在しない場合、答えは 0 です。 

### なぜ効果があるのか

 順序付けされた点によって定義される多角形の凸性は、連続するすべてのトリプルが同じ方向符号を持ち、縮退がないことを要求することと同じです。 外積は局所的な回転方向を捕捉し、この符号の一貫性により、多角形が左折と右折の間で切り替わらないことが保証されます。 ゼロクロス積は、直ちに厳密な凸性に違反します。 すべての区間の有効性は隣接するトリプルにのみ依存するため、問題を符号配列に圧縮すると、必要な情報がすべて保存されます。 したがって、最長の有効な間隔は、正確に、ポイント インデックスにマッピングされた同一の非ゼロ方向標識の最長の連続です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = [tuple(map(int, input().split())) for _ in range(n)]
        
        if n < 3:
            print(0)
            continue
        
        def cross(a, b, c):
            # (b-a) x (c-b)
            return (b[0] - a[0]) * (c[1] - b[1]) - (b[1] - a[1]) * (c[0] - b[0])
        
        best = 0
        cur_len = 0
        cur_sign = 0
        
        for i in range(n - 2):
            val = cross(p[i], p[i+1], p[i+2])
            if val == 0:
                cur_len = 0
                cur_sign = 0
                continue
            
            s = 1 if val > 0 else -1
            
            if s == cur_sign:
                cur_len += 1
            else:
                cur_sign = s
                cur_len = 1
            
            best = max(best, cur_len)
        
        # cur_len is length in triple-array, convert to points
        print(best + 2 if best > 0 else 0)

if __name__ == "__main__":
    solve()
```実装の中核は、連続するトリプルの外積です。 ベクトルを明示的に構築せずに、座標から直接計算されます。 スキャンでは、現在の一連の等方向符号が維持されます。 ゼロクロス積が出現するたびに、そのトリプルを含む区間は凸になることができないため、ストリークはリセットされます。 

k 個の連続する有効なトリプルのストリークは、元のシーケンスの k + 2 点に対応するため、最終的な答えは 2 を加えます。 

## 実用的な例

 ### 例 1

 単純な凸状チェーンを形成する点を考えてみましょう。 

| 私 | ポイント3倍 | クロス | サイン | cur_len | 最高 |
 | --- | --- | --- | --- | --- | --- |
 | 0 | (0,0)、(0,2)、(1,1) | >0 | +1 | 1 | 1 |
 | 1 | (0,2),(1,1),(2,2) | >0 | +1 | 2 | 2 |
 | 2 | (1,1)、(2,2)、(2,0) | <0 | -1 | 1 | 2 |

 一貫した符号の最も長いセグメントは長さ 2 で、答えは 2 + 2 = 4 になります。これは、4 つの点の最大凸間隔に対応します。 

### 例 2

 共線ブレークのあるケースを考えてみましょう。 

| 私 | ポイント3倍 | クロス | サイン | cur_len | 最高 |
 | --- | --- | --- | --- | --- | --- |
 | 0 | (0,0)、(1,1)、(2,2) | 0 | 無効 | 0 | 0 |
 | 1 | (1,1)、(2,2)、(3,0) | <0 | -1 | 1 | 1 |
 | 2 | (2,2)、(3,0)、(4,1) | <0 | -1 | 2 | 2 |

 最初のトリプルは、それを横切るすべての間隔を無効にします。 有効な最長のストリークは 2 なので、答えは 4 です。 

これらのトレースは、一貫したターンが凸状の間隔を蓄積しながら、単一の同一線上にあるトリプルがどのように実現可能性を完全にリセットするかを示しています。

 ## 特殊なケース

 シーケンス内の任意の場所にある同一線上のトリプルは、それを通過する凸状の間隔を即座に壊します。 (0,0)、(1,1)、(2,2)、(3,3) のような入力の場合、すべてのトリプルの外積がゼロになるため、アルゴリズムはステップごとにリセットされ、有効なストリークが構築されず、出力 0 が生成されます。 

凸状であるが 1 つのフラット ターンを含むシーケンスも失敗します。 たとえば、1 つの直線セグメントを除いて凸状チェーンを形成する点は方向ストリークを 2 つの部分に分割し、アルゴリズムは有効な長い辺のみを正しく取得します。 

サイズ 3 の最小有効凸面間隔は、最初の非ゼロ外積が長さ 1 のストリークを開始し、2 を加算した後に 3 点にマッピングされるため、自然に処理されます。 

左折と右折を交互に繰り返すことで、1 より長い連続が発生することはありません。そのため、一貫したトリプルが 1 つ存在する場合にのみ、答えは 3 になります。 それ以外の場合は 0 です。
