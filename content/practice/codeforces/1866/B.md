 ## 問題の理解

 2 つの整数が与えられますが、それらは 10 進数形式で記述されるのではなく、素因数分解によって記述されます。 1 つの番号に電話してください$X$、素数とその指数のリストによって完全に決定されます。 他の番号$Y$も同様に説明されています。 

タスクは、順序付けられたペアの数をカウントすることです$(p, q)$の最小公倍数が成立するように正の整数が存在します。$p$そして$q$等しい$X$、およびの最大公約数$p$そして$q$等しい$Y$。 答えはモジュロで計算する必要があります$998244353$。 

制約について考えるのに役立つ方法は、どちらの数値も非常に大きくなる可能性があるということです。$2 \times 10^6$素数値と大きな指数の場合。 異なる素数の数は最大です$10^5$したがって、どのような解法も各素数を独立して処理し、因子リスト全体にわたって基本的に線形時間で機能する必要があります。 素数や指数の数の二次関数は 1 秒以内には不可能です。 

重要な構造要件は、gcd と lcm の定義からすぐにわかります。 素数が現れる場合$Y$にも表示される必要があります。$X$なぜなら、gcd にはどちらの数値にも存在しない素数を含めることはできず、lcm には両方の数値のすべての素数がすでに含まれている必要があるからです。 いずれかの素数についてこの条件が満たされない場合、答えはゼロでなければなりません。 この一貫性チェックを無視した不注意なソリューションは、次のような場合に誤った肯定的な応答を生成します。$X = 2^1 \cdot 5^1$、$Y = 3^1$、ペアは存在できません。 

もう 1 つの微妙な問題は、素数が存在しないことです。$Y$しかし存在する$X$それでも選択肢に貢献します。 多くの誤った解法は、これらの素数の処理を忘れているか、gcd 素数と対称的に扱うため、正確性が損なわれます。 

最後に、順序が重要です: ペア$(p,q)$順序付けされているため、次の場合を除き、それらを交換すると異なる有効なソリューションが生成されます。$p = q$。 

## アプローチ

 ブルートフォースアプローチでは、すべてのペアを構築しようとします。$(p,q)$gcd と lcm が必要な値と一致するようにします。 両方の数値の各素数に対する可能な指数の割り当てをすべて列挙してみることもできます。 与えられた素数について、その指数が$X$は$a$、次に、次の指数$p$そして$q$gcd 制約と lcm 制約によって決まる特定の範囲の間になければなりません。 ただし、単一の素数の場合でも、すべての有効な指数ペアを列挙することは問題ありませんが、それを個別に列挙すると、$10^5$素数は依然として明示的に生成するのではなく、慎重にカウントする必要があります。 

重要な観察は、gcd 制約と lcm 制約が素数に関して完全に分離していることです。 素数ごとに$x$、その指数を次のように仮定します。$X$は$a$そしてで$Y$は$b$。 もし$b > a$の場合、gcd はどの素数指数でも lcm を超えることができないため、解決策はありません。 

次に、単一の素数を修正します。 その素数の指数を入れます$p$なれ$i$、そして$q$なれ$j$。 次に、gcd 条件が強制します$\min(i,j) = b$、および lcm 条件の力$\max(i,j) = a$。 これはすぐに、両方が$i$そして$j$セットの中になければなりません$\{b, a\}$ただし、各エンドポイントに少なくとも 1 つが等しくなります。 これにより、順序ペア割り当てごとに 2 つの可能性が得られます。$i=b, j=a$または$i=a, j=b$ただし、次の場合に限ります。$a \ne b$。 もし$a = b$の場合、両方が等しい必要があり、選択肢は 1 つだけになります。 

に現れない素数については、$Y$、 我々は持っています$b = 0$。 その場合、$\min(i,j)=0$少なくとも 1 つを強制する$i,j$ゼロになる一方で、$\max(i,j)=a$もう一方を正確に強制します$a$。 繰り返しますが、次の条件を満たす限り、そのような素数ごとに 2 つの順序付けられた構成が得られます。$a > 0$。 

全体の問題は、すべての素数に対する独立した寄与を乗算することに帰着します。$X$ただし、すべての素数が入っている場合に限ります。$Y$に含まれています$X$。 素数が存在する場合$Y$しかし、中にはありません$X$、答えはすぐにゼロです。 

したがって、各素数は、その指数が$X$に等しい$Y$。

 ## アルゴリズムのチュートリアル

 両方の素因数リストを 2 つのマップ間の比較問題として処理します。 

1. 各素数の指数を次の場所に格納します。$X$ハッシュマップまたは辞書内。 

これにより、素数をチェックするときに定数時間のルックアップが可能になります。$Y$。 
2. 答えを 1 として初期化します。 

各素数からの独立した寄与を乗算します。 
3. 各素数を反復処理します。$C_j$で$Y$。 

それぞれについて、次の場所に存在するかどうかを確認します。$X$。 存在しない場合、lcm に存在しない素数を gcd に含める方法はありません。そのため、答えは 0 になり、停止できます。 
4. この素数の指数を入力します$X$なれ$a$、そして$Y$なれ$b$。 

もし$b > a$とすると、gcd はどの素成分でも lcm を超えることができないため、再び直ちに不可能であると結論付けます。 
5. もし$a = b$、この素数は正確に 1 方向に寄与します。 

両方$p$そして$q$には同じ指数を持つこの素数が含まれている必要があるため、自由は存在しません。 
6. もし$a > b$、この素数は正確に 2 つの方法で貢献します。 

1 つの数値には指数がかかります$a$もう一方は指数を取ります$b$、ペアは順序付けされているため、両方の割り当てが有効です。 
7. 貢献度を答えのモジュロに乗算します。$998244353$。 

すべての素数を処理した後、$Y$、すべての素数$X$入っていないもの$Y$暗黙的に次のように振る舞う$b=0$そして、同じ推論を拡張すると、それらはすでに説明されています。そのような各素数も、正確に 2 つの方法で寄与します。 ただし、計算を注意深く構成すれば、それらを個別に反復する必要はありません。つまり、素数の数を追跡します。$X$マッチ$Y$、いくつ違うのか。 

クリーンな実装では、すべての素数を直接反復します。$X$、存在をチェックします$Y$、それに応じて貢献を倍増します。 

### なぜ効果があるのか

 各素数に対する制約$\gcd(p,q)$そして$\text{lcm}(p,q)$の指数に独立した条件を課す$p$そして$q$。 gcd と lcm は素数ごとに独立して計算されるため、ある素数の選択は他の素数に影響を与えません。 これにより、素数上の積構造が作成されます。 各素数は固定数の有効な指数割り当てに寄与し、ペアの総数はこれらの寄与の積になります。 正確さは、素因数分解の一意性と指数制約の独立性から決まります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    A = list(map(int, input().split()))
    B = list(map(int, input().split()))
    
    x_exp = {}
    for p, e in zip(A, B):
        x_exp[p] = e

    m = int(input())
    C = list(map(int, input().split()))
    D = list(map(int, input().split()))
    
    y_exp = {}
    for p, e in zip(C, D):
        y_exp[p] = e

    # consistency check: all primes in Y must exist in X
    for p, e in y_exp.items():
        if p not in x_exp or e > x_exp[p]:
            print(0)
            return

    ans = 1

    # process primes in X (covers both shared and extra primes)
    for p, a in x_exp.items():
        b = y_exp.get(p, 0)

        if a == b:
            ans = (ans * 1) % MOD
        else:
            ans = (ans * 2) % MOD

    print(ans)

if __name__ == "__main__":
    solve()

よくある落とし穴は、素数のみを反復処理することです。$Y$。 これは、に存在する素数からの寄与を過小評価します。$X$しかし欠席$Y$、それぞれの係数は 2 になります。

 ## 特殊なケース

 最初のエッジケースは次のような場合です。$Y$に存在しない素数が含まれています$X$。 その状況では、gcd には lcm にはない素因数が必要になりますが、これは不可能です。 アルゴリズムは、乗算が発生する前に、実行可能性ループ内でこれを即座に捕捉します。

最後のケースは次のような場合です。$X$素数が 1 つあります。 アルゴリズムは、その素数が出現するかどうかに応じて、単純な二項選択に帰着します。$Y$同じ指数またはゼロを使用して、最小の非自明な構造の正しさを確認します。
