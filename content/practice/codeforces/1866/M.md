 ## 解決策
 ## 問題の理解

 高さの塔を建設するために予想される移動数を計算するように求められます。`N`同一の小さな岩を使用しており、配置するたびに上部の岩が滝のように落下する可能性があります。 石が高いところに置かれるたびに`x`、一番上の岩には確率がある`P_x/100`落ちること。 落ちれば同じ確率でその下の岩も落ち、この鎖が根元まで続きます。 タワーが最大の高さに達するまでこのプロセスが繰り返されます`N`石も落ちずに。 

入力は整数です`N`ターゲットの高さと確率の配列を表す`P_1`を通して`P_N`。 出力は、モジュロで表された予想される移動数である必要があります。`998244353`分数を形式に変換した後`P * Q^{-1}`。 

制約を考慮すると、`N`まで可能です`2 * 10^5`。 これにより、落石の考えられるすべてのシーケンスを明示的にシミュレートするアプローチは除外されます。これは、指数関数的な複雑さを伴うためです。 ほぼ直線的な時間で機能するソリューションが必要です。 

エッジケースは、次のような確率で発生します。`0`または非常に高い。 もし`P_x = 0`みんなのために`x`、塔は常に高さに達します`N`まさに`N`動きます。 逆に、いくつかの場合、`P_x`に近いです`100`、上部の岩は繰り返し落ちる可能性があり、単純なアプローチでは予想される移動数を過小評価する可能性があります。 もう一つの微妙なケースは次のような場合です。`N = 1`インデックス作成エラーを避けるためには慎重な取り扱いが必要です。 

## アプローチ

 ブルートフォース ソリューションでは、考えられるすべての転倒シーケンスをシミュレートして、予想される手の数を計算しようとします。 それぞれの岩の配置は、ゼロから`x`落石。 これらすべてのシナリオを直接追跡するには、`O(2^N)`最悪の場合の操作は明らかに実行不可能です。`N = 2 * 10^5`。 

重要な洞察は、動的プログラミングを使用して問題を線形再発として扱うことです。 定義する`E[x]`高さに到達するまでの予想移動回数として`x`。 高いところに石を置くと`x`、成功する可能性はあります`q = 1 - P_x / 100`それは留まり、私たちを高みへ連れて行ってくれるということ`x`。 岩が落ちると、私たちは事実上、より低い高さにリセットされ、予想通りの幾何級数を形成します。 これらの確率を上から下に注意深く計算することで、それぞれの確率を計算できます。`E[x]`で`O(1)`高さあたりの時間、合計複雑さは次のようになります。`O(N)`。 

それぞれの観察は、`E[x]`自分自身だけに依存しており、`E[x-1]`これにより、組み合わせ爆発を回避し、上から下への 1 回のパスで解決策を導き出すことができます。

 ## アルゴリズムのチュートリアル

 1. パーセンテージを変換する`P_i`確率に`p_i`モジュロ`998244353`モジュラー演算を使用します。 定義する`p_i`として`P_i * modinv(100) % MOD`、 どこ`modinv`は逆モジュラーです。 
2. 配列を初期化する`E`どこ`E[x]`高さに到達するまでに予想される移動回数を表します`x`高さから始める`x-1`。 
3. 高さから反復する`1`に`N`。 身長ごとに`x`、一番上の岩が落ちない確率は`q = 1 - p_x`。 予想される移動数`E[x]`幾何分布の期待値の公式を使用して計算できます。`E[x] = 1 / q`。 
4. 連続落下を考慮して、高さに対して成功確率を乗算します。`x`すでに計算された予想される動きによる`E[x-1]`。 これにより、`E[x] = (1 + p_x * E[x-1]) * modinv(q)`。 
5. 最終的な答えは次のとおりです。`E[N]`モジュロ`998244353`。 

なぜ機能するのか: 各ステップで次のことを維持します。`E[x]`高さに到達したことを条件とした予想移動数として`x-1`。 この反復では、期待値の線形性と幾何学的分布の特性を使用して、すべてのシーケンスをシミュレートすることなく、連鎖的な障害の影響を捉えます。 それぞれの期待値は正確に計算され、前の高さのみに依存するため、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(a):
    return pow(a, MOD - 2, MOD)

def solve():
    N = int(input())
    P = list(map(int, input().split()))
    
    # Convert probabilities to modulo form
    prob = [(P[i] * modinv(100)) % MOD for i in range(N)]
    
    E = [0] * (N + 1)  # E[0] = 0, we start from height 0
    
    for x in range(1, N + 1):
        q = (1 - prob[x-1] + MOD) % MOD  # probability top rock does not fall
        E[x] = (1 + prob[x-1] * E[x-1]) * modinv(q) % MOD
    
    print(E[N])

if __name__ == "__main__":
    solve()
```この実装では、`prob[x-1]`落石のモジュラー確率を格納します。 私たちは計算します`q`落ちない相補確率として。 逆モジュラーを使用して、モジュラー算術で除算を処理します。単純な除算ではモジュロ制約が破られるため、これは非常に重要です。 再発`E[x] = (1 + p * E[x-1]) / q`潜在的なカスケードフォールを含む、予想される動きを正確にモデル化します。
