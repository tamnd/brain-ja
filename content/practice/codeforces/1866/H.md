 ## 問題の理解

### なぜ効果があるのか

 任意の固定値で$x$、重要な唯一の情報は、セットに含まれているかどうかです。$x$、それは、次の存在によって制約される必要があるかどうかを決定するためです。$x+1$より高い層で。 チェーン条件は、そのメンバーシップを強制します。$x$のメンバーシップを意味します$x+1$順序の上のどこかに配置され、厳密な階層化が作成されます。 これは、異なる値での決定が各レベルを通過するセットの数を除いて干渉しないことを意味し、アクティブ セットの数に対して DP を 1 次元のままにすることができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    N, K = map(int, input().split())

    # dp[i] = ways after processing value level, with i "active constraints"
    dp = [0] * (N + 1)
    dp[0] = 1

    # precompute binomial coefficients up to N
    C = [[0] * (N + 1) for _ in range(N + 1)]
    for i in range(N + 1):
        C[i][0] = 1
        for j in range(1, i + 1):
            C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % MOD

    for _ in range(K):
        ndp = [0] * (N + 1)
        for used in range(N + 1):
            if dp[used] == 0:
                continue
            remaining = N - used
            for add in range(remaining + 1):
                ways = C[remaining][add]
                ndp[used + add] = (ndp[used + add] + dp[used] * ways) % MOD
        dp = ndp

    print(dp[N])

if __name__ == "__main__":
    solve()
```この実装では、より高い値によってすでに「アクティブ化」されているセットの数を超えて DP が維持されます。 の値に対応する各レイヤー$1$に$K$その値を含む新しいセットの数を決定し、二項係数は残りのセット間でそれらの選択がどのように行われるかをカウントします。 

DP 遷移は、現在のアクティブ カウントを繰り返し、残りのセットを新しいアクティブ化に分配します。 すべてが揃った最終状態$N$考慮されたセットは、有効な構成の合計数を示します。 

微妙な点は、各層が残りのセットのサブセットを繰り返し選択するため、二項係数の事前計算が必要であることです。 セットに値が含まれ始めると、DP は正確さを維持します。$x$、上位の制約をすべて満たすことにすでに取り組んでいます。
