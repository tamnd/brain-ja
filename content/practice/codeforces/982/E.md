 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、角のある長方形のビリヤード テーブルです。$(0,0)$、$(n,0)$、$(0,m)$、 そして$(n,m)$。 点のようなボールはから始まります$(x,y)$方向成分を制限して直線的に移動します。$-1, 0, 1$、つまり、水平、垂直、または 45 度の対角線に沿って移動します。 

ボールが壁に当たると、通常の鏡の法則に従って反射するため、速度の水平成分と垂直成分が独立して反転します。 ボールが四隅のいずれかに正確に着地しない限り、その動きは永遠に続き、その場合、ボールはポケットに落ちて停止します。 

タスクは、軌道がコーナーに到達するかどうか、到達する場合はどのコーナーに到達するかを判断することです。 

重要な難点は、$n$そして$m$と同じ大きさにすることができます$10^9$したがって、反射を段階的にシミュレートすることは不可能です。 壁から壁へ移動するシミュレーションでは、潜在的に時間がかかります。$O(n+m)$バウンスごとに異なり、バウンスの数に制限がないため、このアプローチは直ちに実行不可能になります。 

素朴な試みでは、ボールがコーナーに当たるか、ある状態を繰り返すまでシミュレーションすることになります。 状態空間の境界は次のとおりです。$(x,y,v_x,v_y)$ただし、座標は反射間で連続しているため、壁にぶつかったことで離散化した場合でも、潜在的に巨大なサイクルが発生する可能性があります。 

素朴な考え方によるよくある失敗例は、パリティを正しく処理せずに周期性を仮定することです。 たとえば、ボールが斜めに移動するが、$x-y$は、テーブル サイズの対角パリティと一致していないため、たとえ対称的に跳ね返っているように見えても、角に到達することはありません。 

もう 1 つの微妙なエッジ ケースは、1 つの速度成分がゼロの場合です。 たとえば、次の場合$v_x = 0$、ボールは垂直方向にのみ移動し、正確に開始しない限り水平方向のコーナーに到達することはありません。$x=0$または$x=n$。 同様に、$v_y = 0$。 

これらの問題は、問題が基本的に、繰り返される反射パスが角と交差するかどうかに関するものであることを示しており、これは、反射を拡張周期グリッド上の直線運動に変換することを示唆しています。 

## アプローチ

 この強引なアイデアは、ボールの動きをシミュレートし、ボールが壁に当たるたびにそれを反映するというものです。 各ステップでは、次の壁の衝突を計算し、方向を更新し、ボールがコーナーに到達するかどうかを確認する必要があります。 

これはシステムの物理学に直接従うため、原理的には正しいです。 ただし、問題は、コーナーにぶつかったりサイクルに入る前の反射回数が非常に多くなる可能性があることです。 最悪の場合、ボールがコーナーに当たることはなく、シミュレーションが無限に実行されることになります。 ステップに上限を設けたとしても、各セグメントの計算には依然として一定の時間がかかるため、複雑さは管理できなくなります。$O(nm)$-縮退解釈におけるスケール動作。 

重要な洞察は、ビリヤード テーブルをミラーリングされたコピーの無限のグリッドに展開することによって、反射を完全に除去することです。 境界で反射するのではなく、ボールが長方形のタイル化されたコピーを横切って直線を続けると想像します。 この変換された空間では、ボールは一定の方向に移動し、元のテーブルの角が格子点に対応します。$(k n, \ell m)$。 

したがって、問題は、ラインが$$(x,y) + t(v_x,v_y)$$両方の座標が の倍数である点に到達したことがある$n$そして$m$同時に、一定の整数時間の間$t$。 

これは線形合同系となり、両方の座標が同時に境界に一致するときについて推論することで解決できます。 

以来$v_x, v_y \in \{-1,0,1\}$、モーションは非常に構造化されています。 いずれかの成分がゼロの場合、軌道は純粋に水平または垂直であり、もう一方の座標が既に境界に位置合わせされている場合にのみコーナーに到達します。 両方がゼロ以外の場合、動きは斜めであり、いつ起こるかを追跡できます。$x$と一致します$0$または$n$同時に$y$と一致します$0$または$m$。 

反射パリティは、垂直壁と水平壁に衝突する時間がそれらの周期を法として同期できるかどうかをチェックすることに変換されます。

 ## アルゴリズムのチュートリアル

 反射サイクルの観点から各軸を独立して扱います。 

1. 動きを無限のミラーリングされたグリッド内の直線の動きとして解釈します。 ボールはバウンドするのではなく、一定の方向に継続的に移動します。$(v_x, v_y)$。 
2. この展開図では、角に到達するということは、両方の座標が の整数倍である点に同時に到達することを意味します。$n$そして$m$。 したがって、次のものが必要です。$$x + t v_x \equiv 0 \ (\text{mod } n) \quad \text{or} \quad x + t v_x \equiv n \ (\text{mod } n)$$そして同様に$y$。 

これはそれを要求するのと同じです$x + t v_x$境界線に着地し、$y + t v_y$同時に境界線に着地する。 
3. もし$v_x = 0$、x 座標は決して変わりません。 ボールは次の場合にのみコーナーに当たることができます。$x$すでに 0 または$n$、それ以外の場合は戻ります$-1$。 有効な場合、ヒットの垂直方向の動きのみがチェックされます。$y = 0$または$y = m$。 
4. 同様に、$v_y = 0$かどうかを確認します。$y$すでに 0 または$m$、それ以外の場合は戻ります$-1$、次に水平方向の動きに減らします。 
5. 両方の場合$v_x$そして$v_y$ゼロ以外の場合、両方の座標は周期的に移動します$2n$そして$2m$それぞれ反省中。 各座標が初めて境界に達するときをシミュレートします。 

- 計算時間$t_x$x が 0 または n に達したとき
 - 計算時間$t_y$y が 0 または m のいずれかに達したとき
 6. 時間を段階的に進めます$\min(t_x, t_y)$、コーナーに正確に着地するか、同期が決して発生しない一貫したサイクルを検出するまで、それに応じて方向コンポーネントを反転します。 

よりクリーンな定式化によりシミュレーションが完全に回避されます。考えられる 4 つのコーナー ターゲットをチェックします。$(0,0), (0,m), (n,0), (n,m)$。 それぞれについて、存在するかどうかを解決します。$t$反射パリティの下で両方の座標が同時に一致するようにします。これは、境界までの距離のパリティ アライメントをチェックすることになります。 

### なぜ効果があるのか

 アンフォールディング変換は反射を周期的なタイリングに変換し、区分的な線形軌道を格子内の単一の直線に変換します。 すべての有効な反射パスは、この拡張された空間内の直線パスと 1 対 1 で対応します。 元のグリッドの角は格子点に正確に対応します$(kn, lm)$したがって、ポケットに到達することは、同時の線形整列条件を解くことと同じです。 運動は決定論的かつ線形であるため、そのような時間が存在する場合、それは一意のモジュロ周期性となり、それが存在しない場合、軌道は決して角にぶつかることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, x, y, vx, vy = map(int, input().split())

    # handle vertical movement only
    if vx == 0:
        if x != 0 and x != n:
            print(-1)
            return
        # only y matters
        if vy == 1:
            print(x, m)
        else:
            print(x, 0)
        return

    # handle horizontal movement only
    if vy == 0:
        if y != 0 and y != m:
            print(-1)
            return
        if vx == 1:
            print(n, y)
        else:
            print(0, y)
        return

    # general case: simulate reflections via state transitions on boundaries
    # we track position and direction until we hit a corner or repeat a state

    seen = set()
    while True:
        # next time to hit vertical wall
        if vx == 1:
            tx = n - x
        else:
            tx = x

        if vy == 1:
            ty = m - y
        else:
            ty = y

        t = min(tx, ty)
        x += vx * t
        y += vy * t

        if (x == 0 or x == n) and (y == 0 or y == m):
            print(x, y)
            return

        if tx < ty:
            vx *= -1
        elif ty < tx:
            vy *= -1
        else:
            vx *= -1
            vy *= -1

        state = (x, y, vx, vy)
        if state in seen:
            print(-1)
            return
        seen.add(state)

solve()
```この実装では、問題を軸に沿った縮退動作と一般的な対角線の場合に分割します。 ゼロ速度コンポーネントの場合、固定座標が壁上にあるかどうかがすぐにチェックされます。壁上になければ角に到達することは不可能だからです。 

一般的なケースでは、シミュレーションは、x および y に沿った各境界までの残りの距離を計算することによって、ボールを次の壁に直接移動させます。 距離が小さいほど、次のイベントが決まります。 各イベントでは、どの壁にぶつかったかに応じて方向が反転します。 両方の距離が一致すると、ボールはコーナーに当たります。 

訪問済み状態セットは、サイクルを検出することで終了を保証します。$(x,y,v_x,v_y)$反射は決定論的であり、明確な境界状態の数は有限であるため、これで十分です。

 ## 特殊なケース

 などの垂直方向のみの動き$(x,y,v_x,v_y) = (3,1,0,1)$すぐに構造上の制約が明らかになります。 x 座標は決して変化しないため、次の場合$x$0に等しくない、または$n$、軌道はコーナーに到達する可能性はありません。 アルゴリズムは、シミュレーション前の早期拒否によってこれを処理します。 

非対称の寸法を持つ斜めのケース、たとえば$n=4, m=3, (x,y)=(1,1)$、素朴な対称性の直観が失敗することを示しています。 視覚的にはパスが「均等に跳ね返る」場合でも、算術条件が正確に一致しない限り、水平方向と垂直方向の反射の周期が一致しないため、同時整列は妨げられます。 シミュレーションでは、両方の軸を独立してではなく、同じ反射イベントで強制的に位置合わせすることで、この問題を解決します。
