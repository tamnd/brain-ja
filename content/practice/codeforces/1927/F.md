 ## 解決策
 ## 問題の理解

 無向の重み付きグラフで、そのサイクル内の最小エッジができるだけ小さい単純なサイクルを見つけるように求められます。 入力は一連のグラフです。各グラフは、頂点の数、エッジの数、および重みを含むエッジのリストによって記述されます。 単純なサイクルとは、頂点やエッジが繰り返されないサイクルです。 出力は、見つかったサイクル内の最小エッジの重み、そのサイクル内の頂点の数、および通過した頂点のシーケンスです。 

制約はいくつかの重要なことを教えてくれます。 各グラフには最大約$2 \cdot 10^5$つまり、頂点のすべてのペアを反復するアルゴリズムは実行不可能です。 グラフは次のような意味でまばらです。$m \le n(n-1)/2$ただし、数千頂点までの密なグラフも可能です。 常に少なくとも 1 つの単純なサイクルがあるため、サイクルのないグラフを処理する必要はありません。 エッジの重みは最大の正の整数です。$10^6$したがって、負のサイクルを処理する必要はありません。 

単純なアプローチでは、すべてのサイクルを列挙しようとする可能性がありますが、グラフ内のサイクルの数は頂点の数に応じて指数関数的に増加する可能性があるため、これはすぐに非現実的になります。 もう 1 つの微妙な点は、複数のサイクルがエッジを共有する可能性があり、最も明るいエッジを最小化するサイクルが必ずしも最小または最短のサイクルであるとは限らないことです。 不注意な解決策では、任意のサイクル、または DFS 経由で最初に見つかったサイクルが選択される可能性があり、必要以上に重い最小エッジが生成される可能性があります。 

単純なアプローチでつまずく可能性のあるエッジ ケースには、一方のエッジが他方のエッジよりもはるかに軽い三角形や、一部の部分のみに小さなエッジが含まれる切断されたコンポーネントなどがあります。 たとえば、頂点 1 ～ 3 がエッジの重み 1、100、100 を持つ三角形を形成するグラフについて考えてみましょう。最小の最軽量エッジ サイクルは、明らかに最小エッジ 1 を持つ三角形自体です。他の場所で短いサイクルだけを探した場合、誤って 100 を最小エッジとして報告する可能性があります。 

## アプローチ

 ブルートフォース手法では、すべての単純なサイクルを列挙し、最小の最も軽いエッジを持つサイクルを選択しようとします。 1 つの方法は、各エッジを選択して削除し、その端点を接続するパスを見つけようとすることです。 パスが存在する場合、削除されたエッジを追加するとサイクルが完了します。 どのサイクルもこの方法で分解できるため、これは正しいです。 問題は、経路探索がエッジごとに O(n + m) であるため、合計の複雑さが O(m(n + m)) となり、与えられた条件を考慮すると遅すぎることです。$m \sim 2 \cdot 10^5$。 

重要な洞察は、小さなサブグラフに焦点を当てることで最小の最軽量エッジ サイクルを見つけることができるということです。 多くの場合、三角形 (3 サイクル) が最適です。これは、長いサイクルの最小エッジは、それを含む三角形の最小エッジより小さくなることはできないためです。 これにより、問題はグラフ内の三角形を効率的に見つけることになります。 頂点次数を活用することができます。つまり、エッジを重みでソートし、共通の頂点に接続されたエッジによって形成されるサイクルを見つけようとします。 祖先の追跡を行う Union-Find (DSU) または小さな近傍に限定された BFS/DFS は、候補サイクルを迅速に見つけるのに役立ちます。 

また、重みの増加順にエッジを試行できることもわかります。 サイクルを完了する最初のエッジには、そのサイクル内に可能な最小限のエッジが含まれることが保証されています。これは、すべての軽いエッジがサイクルを形成せずに処理されているためです。 これは Kruskal の MST アルゴリズムに似ていますが、コンポーネントを最小限に接続する代わりに、サイクルの終了をチェックします。

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、すべてのエッジを読み取り、それらの重みとともに保存します。 エッジを重みの昇順に並べ替えます。 ソートにより、エッジが最小のものから処理されることが保証されます。これは、サイクル内の最小エッジを最初に考慮する必要があるため重要です。 
2. 接続されたコンポーネントを維持するために Union-Find (DSU) 構造を初期化します。 各頂点について、その親とランクを追跡して、高速なマージと祖先の検索を可能にします。 
3. 重みの順にエッジを繰り返します。 各エッジについて、DSU を使用して、そのエンドポイントが同じ接続コンポーネントに属しているかどうかを確認します。 存在する場合、このエッジを追加するとサイクルが形成されます。 
4. サイクルが検出されたら、それを再構築します。 現在のエッジを除く既存のグラフ エッジに沿って、エッジの一方の端点からもう一方の端点まで BFS または DFS を実行します。 パスを収集し、現在のエッジを追加してサイクルを閉じます。 すべての軽いエッジはすでに処理されており、サイクルを形成していないため、このサイクルの最小エッジは現在のエッジです。 
5. エンドポイントが同じコンポーネント内にない場合は、それらを DSU にマージします。 これにより、将来のエッジがサイクルを適切に検出できるようになります。 
6. サイクルの検出に使用されるエッジの重み、サイクル内の頂点の数、および頂点の走査順序を出力します。 

機能する理由: 不変条件は、重みを増加させながらエッジを処理することです。 DSU は、初めてエッジがサイクルを閉じるときに、そのサイクルに現在のエッジよりも軽いエッジが含まれていないことを保証します。 より明るいエッジを含むサイクルは、より早く検出されていたでしょう。 したがって、私たちが報告するサイクルの最小エッジは世界的に最小です。 

## Python ソリューション```python
import sys
from collections import deque
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n+1))
        self.rank = [0]*(n+1)

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        xr, yr = self.find(x), self.find(y)
        if xr == yr:
            return False
        if self.rank[xr] < self.rank[yr]:
            self.parent[xr] = yr
        else:
            self.parent[yr] = xr
            if self.rank[xr] == self.rank[yr]:
                self.rank[xr] += 1
        return True

def find_cycle(n, edges):
    edges.sort(key=lambda x: x[2])
    dsu = DSU(n)
    graph = [[] for _ in range(n+1)]
    
    for u, v, w in edges:
        if dsu.find(u) == dsu.find(v):
            # cycle detected
            # BFS to find path from u to v
            prev = [-1]*(n+1)
            q = deque()
            q.append(u)
            visited = [False]*(n+1)
            visited[u] = True
            while q:
                node = q.popleft()
                if node == v:
                    break
                for nei in graph[node]:
                    if not visited[nei]:
                        visited[nei] = True
                        prev[nei] = node
                        q.append(nei)
            # reconstruct path
            path = []
            curr = v
            while curr != -1:
                path.append(curr)
                curr = prev[curr]
            path.reverse()
            path.append(u)
            return w, len(path), path
        else:
            dsu.union(u, v)
            graph[u].append(v)
            graph[v].append(u)
    return None

def main():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        edges = [tuple(map(int, input().split())) for _ in range(m)]
        b, k, path = find_cycle(n, edges)
        print(f"{b} {k}")
        print(" ".join(map(str, path)))

if __name__ == "__main__":
    main()
```コードはエッジを並べ替えて、最小のエッジを最初に考慮することを保証します。 DSU は、新しいエッジがサイクルを形成するタイミングを効率的に検出します。 BFS は、サイクルの正確なパスを O(n + m) 時間で再構築するために使用されます。これは、サイクルごとに 1 回しか実行しないため、実現可能です。 現在のエッジを追加するとサイクルが閉じられ、最小限のエッジが含まれることが保証されます。
