 ## 解決策
 ## 問題の理解

 私たちは一次元のセルのストリップを与えられており、各セルには固定半径の「ペイント電荷」が含まれています。 位置 i での電荷のアクティブ化は、そのセルに影響を与えるだけでなく、正確に a[i] セル (原点を含む) だけ左または右に伸びる連続セグメントをペイントします。 各チャージは最大 1 回のみ使用でき、完全に無視することができます。 

目標は、ストリップ内のすべてのセルが少なくとも 1 回ペイントされるように、最小数のチャージをアクティブにすることです。 重複は許可されており問題ではないため、これは純粋に、可能な限り少ない有向間隔でインデックス範囲全体をカバーすることを目的としています。各間隔は、選択したインデックスの方向を選択することで得られます。 

テスト ケースごとの制約は小さく、n は最大 100、テスト全体の n の合計は最大 1000 です。これにより、テスト ケースあたり約 O(n³) よりも悪いものはすぐに排除されますが、より重要なのは、次のアクションのすべての選択肢を試行する遷移を伴う、間隔または位置にわたる動的プログラミングが可能になることです。 

素朴な考えは、各電荷を 2 つの候補区間を生成するものとして扱い、電荷のすべてのサブセットを試してみることです。 これは、各選択が方向性とすでにカバーされている領域との相互作用に依存するため、失敗します。 もう 1 つのよくある誤った試みは、最も左のカバーされていないセルをカバーする最長の間隔を貪欲に選択することですが、方向性により貪欲な最適性が損なわれます。 局所的に最適に見える電荷は、その延長方向を無駄にし、後でより良いカバレッジをブロックする可能性があります。 

主な問題は、各インデックスが 2 つの非対称間隔に寄与しており、最小限のカーディナリティでライン全体をカバーするサブセットを選択する必要があることです。 

## アプローチ

 ブルート フォース アプローチでは、電荷のすべてのサブセットを試行し、サブセットごとにすべての左または右の向きを試行します。 各構成では最大 n 個の間隔が生成され、カバレッジの検証は O(n) で、およそ O(3ⁿ) の動作が得られます。 これはn=100でも不可能です。 

重要なのは、グローバルにどの料金を選択するかではなく、セグメントを左から右にどのように段階的にカバーするかであることに気づくと、この構造は管理しやすくなります。 何らかのプレフィックスがカバーされると、次の決定は基本的に、カバレッジを開始点から可能な限り右に拡張する料金を選択することになります。場合によっては、すでにカバーされている範囲内の一部のセルをスキップすることもあります。 

これにより、当然のことながら、各セルを潜在的な「カバーされていない領域の開始点」として扱い、すべての位置に到達または通過するために必要な最小間隔数が計算される、位置に対する DP が導き出されます。 各位置 i から、すべての電荷 j ≥ i を考慮し、i をカバーする方向に j を使用してシミュレーションすることができます。これにより、到達可能な最も遠い端点が生成されます。 遷移はインデックス上の最短パスになります。 

n が小さいため、i と各 j について、i をカバーするために適切な方向に j を使用する効果を事前計算し、dp 遷移を緩和することができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース サブセット | O(3ⁿ) | O(n) | 遅すぎる |
 | ポジション + トランジション上の DP | O(n3) | O(n²) | 承認済み |

 ## アルゴリズムのチュートリアル

 dp[x] を位置 x までのすべてのセルをカバーするのに必要な最小電荷数として定義します。dp[0] = 0 およびその他の状態は無限大に初期化されると解釈します。

1. カバレッジを左から右への単調なプロセスとして扱います。 有効なソリューションはどれも、現在のカバレッジを正しい境界まで拡張する一連のセグメントとして見ることができます。 これは、プレフィックスが完全にカバーされると、内部の重複が正確さには関係なくなるため、有効です。 
2. 各開始位置 i について、次のアクティブな間隔寄与者として電荷 j を選択しようとします。 この電荷は、左または右のいずれかのカバレッジを拡張するために使用できますが、i は DP 状態で最初にカバーされていないポイントであるため、実際に i をカバーするオプションのみが関係します。 
3. j を右側に使用すると、[j, j + a[j] - 1] がカバーされるため、j ≤ i ≤ j + a[j] - 1 の場合にのみ状態 i に役立ちます。 j を左側に使用すると、[j - a[j] + 1, j] がカバーされるため、j - a[j] + 1 ≤ i ≤ j の場合に便利です。 
4. 有効な方向が選択されたら、そのアクションから到達可能な最も右のエンドポイントを計算します。 そのエンドポイントは、dp の次の状態の候補になります。 そのエンドポイントの dp を dp[i] + 1 で更新します。 
5. この緩和をすべての i に対して昇順で繰り返し、i を処理するときに dp[i] がそれに到達するための最適な方法をすでに反映していることを確認します。 

このアルゴリズムは、セグメントをカバーする電荷を使用してエッジが表す位置に有向グラフを効果的に構築し、1 から n までの最短経路を計算します。 

### なぜ効果があるのか

 有効な解はすべて、使用されたチャージのシーケンスに対応し、各チャージは使用時に最初にカバーされていない位置をカバーする必要があります。 これにより、カバレッジが増加し、間隔の一意の順序が誘導されます。 DP は、常に左端のカバーされていない位置から拡張し、それをカバーできるすべての料金を考慮することで、まさにこの順序を強制します。 すべての有効なソリューションはそのようなシーケンスに分解でき、すべての遷移が考慮されるため、DP はより良い構築を見逃すことはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = 10**9

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        dp = [INF] * (n + 1)
        dp[0] = 0
        
        for i in range(1, n + 1):
            # compute best ways to reach i as a covered prefix end
            best = dp[i]
            for j in range(1, n + 1):
                if dp[j - 1] == INF:
                    continue

                # use j to cover a segment that reaches i or beyond
                # try left orientation
                l = j - a[j - 1] + 1
                r = j
                if l <= i <= r:
                    best = min(best, dp[l - 1] + 1)

                # try right orientation
                l = j
                r = j + a[j - 1] - 1
                if l <= i <= r:
                    best = min(best, dp[l - 1] + 1)

            dp[i] = min(dp[i], best)

        print(dp[n])

if __name__ == "__main__":
    solve()
```DP 配列は、左からどれだけカバーしたかによってインデックスが付けられます。 各エンドポイント i について、i に到達または通過するのに役立った最後のセグメントとして、考えられるすべてのチャージを試みます。 遷移は、セグメント寄与の開始点を明示的に計算し、問題を以前に解決されたプレフィックスに還元します。 

重要な詳細は、選択されたセグメントは i よりも前に開始される可能性がありますが、依然として i をカバーする責任があるため、dp[i - 1] ではなく dp[l - 1] からのみ遷移することです。

 ## 特殊なケース

 すべての a[i] = 1 を持つ完全に均一な配列では、すべてのセルが個別にカバーされるように強制されます。 セグメントが 1 つのセルを超えて拡張することはできず、すべての遷移で dp が正確に 1 単位のカバレッジだけ改善されるため、アルゴリズムは dp[i] = i を正しく割り当てます。 

最初の位置に非常に大きな a[i] がある場合、DP はすぐに崩壊します。これは、インデックス 1 からの右方向の間隔がプレフィックス全体をカバーし、dp[n] = 1 に設定されるためです。DP はこれを考慮します。これは、i ごとに j = 1 がチェックされ、特別なケースが必要ないことが保証されるためです。 

配列を厳密に増加させると、後の位置ではより大きなサフィックスをカバーできるが、前の位置ではカバーできないことが保証され、DP が複数の部分カバーを正しく比較するようになります。 緩和ステップにより、すべての有効な開始が確実に考慮されるため、局所的に最適な初期の選択がより適切なグローバル セグメンテーションを妨げることはありません。
