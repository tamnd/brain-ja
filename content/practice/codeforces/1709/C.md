 ## 解決策
 ## 問題の理解

 次の 3 種類の文字で構成される文字列が与えられます。`'('`、閉じ括弧`')'`、疑問符`'?'`。 元の文字列は正しい括弧シーケンス (通常括弧シーケンス (RBS) とも呼ばれます) でしたが、一部の括弧が疑問符に置き換えられました。 私たちのタスクは、結果の文字列が有効な RBS になるように疑問符を置き換える方法が 1 つだけ存在するかどうかを判断することです。 

各テスト ケースは独立しており、少なくとも 1 つの有効な RBS が存在することが保証されています。 各文字列の長さは、すべてのテスト ケースで合計で最大約 200,000 文字に達する可能性があるため、文字列の長さが線形であるソリューションが必要です。 考えられるすべての疑問符の置換を試みる単純なアプローチでは、指数関数的な時間がかかりますが、これらの制約ではまったく実現不可能です。 

考慮すべきエッジケースには、すべての文字が疑問符である文字列、あいまいな位置が 1 つだけあるすでにほぼ完全な RBS である文字列、および複数の小さな順列が可能である長さ 2 または 4 の文字列が含まれます。 たとえば、次の文字列`"??"`可能な RBS は 2 つあります。`"()"`そして`"()"`(技術的には同一ですが、1 つの一意のパターンとしてカウントされます)、次のような文字列`"?))"`次のようにのみ完了できます`"(())"`そしてユニークです。 

不注意なアプローチでは、単に必要な数を数えるだけであると想定する可能性があります。`'('`そして`')'`弦のバランスをとるだけで十分です。 これは有効な RBS を構築するために機能しますが、一部の位置にある疑問符を再配置すると代替の有効な RBS が生成される可能性があるため、一意性は保証されません。 

## アプローチ

 ブルートフォースアプローチは、各疑問符を両方の疑問符に置き換えることによってすべてのシーケンスを生成することです。`'('`そして`')'`そしてどれが有効な RBS であるかを確認してください。 有効性のチェックには、シーケンスをトラバースしながらバランス カウンタを維持することが含まれます。 ある長さの文字列の場合`n`と`k`疑問符の場合、このアプローチには次のことが必要です`2^k * O(n)`操作が不可能になる場合`k`たとえ入力が小さくても、これは遅すぎます。 

重要な洞察は、RBS を一意にするためには、疑問符の配置に柔軟性があり得ないということです。 すべての疑問符を、すべての位置で必要なバランスを正確に保つ割り当てに置き換えると、代替割り当ては一時的または最後にバランスを崩し、無効な RBS が生成されます。 したがって、「クリティカル位置」、つまり曖昧さによって代替の有効な割り当てが可能になる最初と最後の位置のみをチェックする必要があります。 シーケンスの途中で 2 つの疑問符を交換しても有効な RBS が生成される場合、解決策は一意ではありません。 

事実上、正確な数を計算します。`'('`そして`')'`必須。 次に、最初の`'('`それは次のものに置き換えることができます`'('`または`')'`そして最後`'('`それは次のものに置き換えることができます`'('`重要です。 これら 2 つの位置を移動しても有効性が維持される場合、解決策は一意ではありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^k * n) | O(n) | 遅すぎる |
 | 貪欲 + バランスチェック | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 疑問符の数と存在する疑問符の数を数えます。`'('`そして`')'`。 必要な数を計算します`'('`そして`')'`RBS を完成させるには、文字列の各半分を次のようにする必要があります。`'('`または`')'`したがって、合計数のバランスが取れています。 
2. 最初に必要な数の疑問符を`'('`そして残りは`')'`。 
3. バランスカウンターを左から右に維持することによって、シーケンスが有効な RBS であるかどうかを確認します。 残高はゼロから始まり、1 ずつ増加します。`'('`そして1ずつ減少します`')'`。 残高がマイナスになるか、ゼロで終わらない場合、シーケンスは無効になります。 少なくとも 1 つの有効な RBS が保証されているため、ここでは常に成功します。 
4. 一意性を判断するには、最後の`'('`割り当てられ、最初の`')'`割り当てが発生します。 この 2 つの文字を交換します。 それでも残高チェックが成功する場合、解決策は一意ではありません。 
5. スワップが失敗した場合、考えられる有効な割り当ては 1 つだけであり、解決策は一意です。 

機能する理由: バランス チェックにより、ブラケットが正しくネストされていることを確認します。 曖昧さによって異なる割り当てが可能となる最初と最後の位置に焦点を当てることで、複数の有効な RBS を生成できる唯一の柔軟性を分離します。 他の疑問符のスワップでは、シーケンスが初期または最後に中断され、スワップが失敗した場合でも一意性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_rbs(s):
    balance = 0
    for c in s:
        balance += 1 if c == '(' else -1
        if balance < 0:
            return False
    return balance == 0

def solve_case(s):
    n = len(s)
    half = n // 2
    count_open = s.count('(')
    count_close = s.count(')')
    count_q = s.count('?')
    
    need_open = half - count_open
    need_close = half - count_close

    arr = list(s)
    for i in range(n):
        if arr[i] == '?':
            if need_open > 0:
                arr[i] = '('
                need_open -= 1
            else:
                arr[i] = ')'

    # Check uniqueness
    first_close_index = None
    last_open_index = None
    for i, c in enumerate(arr):
        if s[i] == '?':
            if c == '(':
                last_open_index = i
            else:
                if first_close_index is None:
                    first_close_index = i

    if last_open_index is not None and first_close_index is not None:
        arr[last_open_index], arr[first_close_index] = ')', '('
        if is_rbs(arr):
            return "NO"
    
    return "YES"

def main():
    t = int(input())
    for _ in range(t):
        s = input().strip()
        print(solve_case(s))

if __name__ == "__main__":
    main()
```コードはまず、次の数を計算します。`'('`そして`')'`が必要です。 疑問符を貪欲に埋めてから、重要なスワップ位置を特定して一意性をテストします。 の`is_rbs`関数は残高をチェックし、マイナスになった場合はすぐに False を返します。
