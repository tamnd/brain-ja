 ## 解決策
 ## 問題の理解

 グリッドが与えられています$n$行と$m$列。 各列の下部には、配列で指定されたいくつかのブロックされたセルがあります。$a$どこ$a[i]$列の下部にあるセルの数を示します$i$ブロックされています。 残りのセルは空いています。 ロボットは特定のセルから開始し、ターゲットのセルに到達する必要があります。 コマンドはロボットを 4 方向のいずれかに動かしますが、各コマンドは正確に実行されます。$k$回。 ロボットがブロックされたセルに入ろうとしたり、グリッドの外に出ようとすると爆発します。 クエリごとに、ロボットがターゲット セルに安全に到達し、そこで正確に終了することを可能にする一連のコマンドが存在するかどうかを判断する必要があります。 

重要な制約は次のとおりです。$n$と同じ大きさにすることができます$10^9$、 しかし$m$までです$2 \cdot 10^5$、最大で$2 \cdot 10^5$クエリ。 これにより、ロボットの動きをセルごとにシミュレートするアプローチは除外されます。 代わりに、ロボットが到達できる最大の安全な行と、行と列の座標の差が次の値で割り切れるかどうかを推論する必要があります。$k$。 

微妙な点は、ロボットがすべての作業を実行することです。$k$各コマンドの手順。 ロボットが上昇するように命令された場合、$k$行 7 から行 10 までのステップでは、行 8、9、および 10 がすべて安全であることを確認する必要があります。そうしないと、ターゲットに到達する前にロボットが爆発します。 同様に、開始セルまたはターゲット セルが次の数で割り切れない距離にある場合、$k$、目標に正確に停止することは不可能です。 エッジ ケースは、到達可能な最大行が終了セルの行より小さい場合、または行の距離が次の倍数ではない場合によく発生します。$k$。 

## アプローチ

 ブルートフォース手法では、ロボットがターゲットに到達するか爆発するまで、ロボットが 4 方向すべてに行う可能性のある各動作をシミュレートします。 までの検討が必要となります。$n$各列に行があり、反復される可能性があります$k$各クエリのコマンドごとのステップ。 と$n$まで$10^9$そして$q$まで$2 \cdot 10^5$、このアプローチは明らかに実行不可能です。 

重要な洞察は、列が十分に高い場合、ロボットは常に水平方向に移動でき、垂直方向の移動は、その経路に沿った列の最大安全な列によって制限されるということです。 ロボットは、スタートとフィニッシュの間の垂直距離と水平距離が次の倍数である場合にのみ、フィニッシュセルで停止できます。$k$。 したがって、開始列と終了列の間のパスに沿ってロボットが安全に到達できる最大の行を見つけて、次の方法で上または下に移動しているかどうかを確認する必要があります。$k$ステップは正確に目標に到達できます。 これにより、問題は次の 2 つの条件をチェックすることになります。$k$水平経路に沿った最大限の安全な列。 

ブロックされたセルのプレフィックスの最大値を事前計算して、水平パスに沿って最も高いブロックされたセルをすばやくクエリしたり、単に範囲内でブロックされたセルの最大値を取得したりすることができます。$[y_s, y_f]$各クエリ中に。 以来$m \le 2 \cdot 10^5$、これは次の方法で実行できます。$O(\log m)$セグメントツリーを使用してクエリごとに、または$O(m)$単純なスキャンを使用する場合はクエリごとに (許容されます)$q \le 2 \cdot 10^5$セグメントツリーが使用されている場合)。

 ## アルゴリズムのチュートリアル

 1. ブロックされたセルの配列を前処理する$a$最大値を効率的にクエリするためにセグメント ツリーに変換します。$a[i]$任意の 2 つの列の間。 これにより、パス内で最もブロックされたセルを対数時間でチェックできます。 
2. 各クエリについて、抽出します。$x_s, y_s, x_f, y_f, k$。 垂直距離を計算する$|x_s - x_f|$そして水平距離$|y_s - y_f|$。 
3. 垂直距離が割り切れない場合$k$または水平距離が次の値で割り切れない$k$、ロボットはターゲット上で正確に停止できないため、答えは「NO」です。 
4. セグメント ツリーに最大ブロック セルを問い合わせます。$max_a$柱に沿って$[y_s, y_f]$。 ロボットは列の上には行けません$n$行を入力できません$\le max_a$したがって、最大安全行は次のようになります。$n - ((n - max_a) \% k)$。 この最大安全行が以下の場合$x_f$、ロボットは爆発せずに終了セルに到達できないため、答えは「NO」です。 
5. 両方の分割条件が満たされ、最大安全列により垂直移動が許可される場合、$x_f$、答えは「YES」です。 

### なぜ効果があるのか

 このアルゴリズムは、ロボットの動きとブロックされたセルによって課されるすべての制約を考慮するため、正確性が保証されます。 ロボットは正確に動きます$k$コマンドごとにステップを実行できるため、割り算によりターゲット上で正確に停止することが保証されます。 水平経路に沿って最大のブロックされたセルを取得することで、ロボットがブロックされたセルを通過しないようにします。 最大安全列の計算により、垂直方向の動きがロボットの安全限界を超えないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class SegmentTree:
    def __init__(self, data):
        self.n = len(data)
        self.size = 1
        while self.size < self.n:
            self.size *= 2
        self.tree = [0] * (2 * self.size)
        for i in range(self.n):
            self.tree[self.size + i] = data[i]
        for i in range(self.size - 1, 0, -1):
            self.tree[i] = max(self.tree[2*i], self.tree[2*i + 1])

    def query(self, l, r):
        l += self.size
        r += self.size
        res = 0
        while l <= r:
            if l % 2 == 1:
                res = max(res, self.tree[l])
                l += 1
            if r % 2 == 0:
                res = max(res, self.tree[r])
                r -= 1
            l //= 2
            r //= 2
        return res

n, m = map(int, input().split())
a = list(map(int, input().split()))
seg = SegmentTree(a)

q = int(input())
for _ in range(q):
    x_s, y_s, x_f, y_f, k = map(int, input().split())
    y_s -= 1
    y_f -= 1

    if abs(x_f - x_s) % k != 0 or abs(y_f - y_s) % k != 0:
        print("NO")
        continue

    l, r = min(y_s, y_f), max(y_s, y_f)
    max_block = seg.query(l, r)
    max_safe_row = n - ((n - max_block) % k)

    if max_safe_row >= x_f:
        print("YES")
    else:
        print("NO")
```セグメント ツリーは、水平パスに沿って最大ブロック セルを効率的にクエリするために使用されます。 サイズのステップに合わせて、ロボットが安全に到達できる最高の行を計算します。$k$。 これにより、垂直移動と水平移動の両方を安全に完了できます。
