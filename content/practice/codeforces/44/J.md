 ## 解決策
 ## 問題の理解

 いくつかのセルが欠けている長方形のボードが与えられました。 残りのすべてのセルは、すでにチェス盤のパターンで黒または白に色付けされています。 タスクは、次のサイズのストレート トリミノを使用して、既存のすべてのセルをカバーすることです。`1 × 3`または`3 × 1`。 

トリミノは常に 3 つの連続するセルをカバーします。 ボードの色が交互になるため、有効なトリミノは向きに応じて白-黒-白または黒-白-黒のパターンでセルをカバーする必要があります。 このステートメントは、ボードの色がチェス盤の色と一致していることを保証するため、自分自身でそれを確認する必要はありません。 

出力は単に「はい/いいえ」の回答ではありません。 タイリングが存在する場合は、4 つの文字のいずれかを割り当てる必要があります`a`、`b`、`c`、`d`隣接するトリミノが同じ文字を共有しないように、すべてのトリミノに適用します。 

ボードサイズに達することができます`1000 × 1000`、これは最大 100 万個のセルを意味します。 指数関数的な検索は直ちに不可能になります。 定数係数が大きいアルゴリズムであってもリスクが高くなります。 セルの数が本質的に線形であることが必要です。 

最初の重要な観察は、トリミノが常に 1 行または 1 列内の 3 つの連続するセルを占有することです。 色が交互に表示されるため、中央のセルは自動的に両端とは逆の色になります。 難しいのは色ではなく幾何学です。 

単純な実装では、切断された領域でエラーが発生する可能性があります。 考慮する：```
1 4
wb.w
```最初の 3 つのセルは穴があるため連続して存在しません。 セルを 3 を法としてカウントするだけの不注意な貪欲な場合、その行はタイル化可能であると誤って認識する可能性があります。 

もう 1 つの微妙なケースは、長さが 4 のコリドーです。```
1 4
wbwb
```を配置する方法はありません`1 × 3`覆われていないセルを 1 つも残さずにタイルします。 残り物をチェックせずにタイルを左から右に貪欲に配置するアルゴリズムは失敗します。 

色の制約によってもトラップが作成されます。 任意の場所を配置しようとするとします`1 × 3`不正なカラーリング上の四角形:```
1 3
www
```このような配置は、必要な交互の色に違反します。 このステートメントは有効な色付けを保証しますが、アルゴリズムはそれによって引き起こされる構造を尊重する必要があります。 

文字の割り当てもバグの原因です。 タイリング自体が正しい場合でも、各トリミノに 1 つのシンボルだけを使用すると、2 つのタイルがエッジに沿って接触するたびに失敗します。 例えば：```
3 3
wbw
bwb
wbw
```3 つの列すべての垂直タイリングは幾何学的に有効ですが、隣接する列で同じラベルを再利用することはできません。 

## アプローチ

 ブルートフォースのアイデアは単純です。 覆われていないすべてのセルに、可能な限り水平または垂直のトリミノを配置し、再帰的に配置し、配置が行き止まりにつながる場合はバックトラックしてみます。 

これが機能するのは、ボードが有限であり、再帰ステップごとにカバーされていないセルの数が減少するためです。 残念ながら、分岐要素は膨大です。 100 万個のセルを備えたボードでは、天文学的な数のタイルを探索する必要があります。 もっと小さいものでも`20 × 20`ボードはすでに実行不可能になります。 

重要な洞察は、ボードの色がトリミノがどのように相互作用するかを完全に決定するということです。 ストレート トリミノは常に 1 つの黒マスと 2 つの白マスを正確にカバーし、チェス盤のパリティに応じてその逆も同様です。 さらに重要なことは、有効な配置はすべて 1 行または 1 列内に完全に収まることです。 

これにより、問題は一般的なタイル問題から局所的な建設的なプロセスに変換されます。 グローバルに検索する代わりに、小さなパターンでボードを貪欲に処理できます。 

標準的なソリューションでは再帰的分解が使用されます。 私たちは、まさに 1 つの自然な方法でタイル化できる必要がある単純なローカル構成を繰り返し探します。 1 つのトリミノを配置した後、残りの問題は小さくなりますが、構造的には同じです。 

中心的な観察は、サイズが 3 で割り切れるすべての連結コンポーネントは葉状セルを使用して縮小できることです。 セルにトリミノへの可能な拡張が 1 つしかない場合、それを使用する必要があります。 強制トリミノを繰り返し削除することで、ボード全体を並べるか、不可能な構成を発見します。 

各セルは一定の回数だけ処理されるため、アルゴリズムは線形になります。

 ## アルゴリズムのチュートリアル

 1. ボードを読み、既存のすべてのセルにマークを付けます。 
2. 直交する隣接セル間の隣接情報を構築します。 各セルには最大 4 つの隣接セルがあります。 
3. すべてのセルについて、その現在の次数、つまり隣接するセルがまだいくつ存在するかを計算します。 
4.すべてのセルを度付きでプッシュします`1`列に並びます。 このようなセルは狭い領域のエンドポイントであるため、それらをカバーする有効なトリミノは大きく制限されます。 
5. キューが空になるまで処理します。 
6. 次数 1 のセルを取得します。`(x, y)`。 その唯一の隣人にしましょう`(nx, ny)`。 
7. トリミノの中央のセルは次のようにする必要があります。`(nx, ny)`。 次に、次のセルに隣接する 3 番目のセルを検索します。`(nx, ny)`それは違います`(x, y)`そしてまだ未使用です。 
8. そのような 3 番目のセルが存在しない場合、タイリングは不可能です。`(x, y)`もうどのトリミノにも属せない。 
9. それ以外の場合は、これら 3 つのセル上に 1 つのトリミノを配置します。 
10. いずれかの文字を割り当てます`a`、`b`、`c`、`d`それは、隣接するすでに着色されたトリミノとは異なります。 各タイルは最大 3 つの隣接するタイルに触れるので、常に 4 つの文字で十分です。 
11. グラフから 3 つのセルを削除します。 隣接する残りのセルごとに、その次数を減らします。 ある程度なれば`1`、キューにプッシュします。 
12. 強制配置がなくなるまで続けます。 
13. 最後に、一部のセルがカバーされていないままになっている場合、その構成には縮小できないサイクル状の構造が含まれています。 出力`NO`。 
14. それ以外の場合は出力`YES`そして構築されたラベル。 

### なぜ効果があるのか

 不変条件は、以前に配置されたトリミノが削除された後、残りのすべての接続コンポーネントがすべての有効なタイリングを保持することです。 次数 1 のセルが表示されると、それをカバーする有効なトリミノには、その唯一の隣接セルが強制的に含められます。 代替手段はありません。 

アルゴリズムは、そのようなセルに対して任意の幾何学的選択を行うことはありません。 すべての配置はローカル構造によって論理的に強制されます。 ある時点で、次数 1 のセルをトリミノに完成できない場合、そのセルをカバーすることが不可能になっているため、有効なタイリングは存在しません。 

カバーされていないセルが残ったままアルゴリズムが終了した場合、それらのセルは、すべての次数が少なくとも 2 であるコンポーネントを形成します。 このような構造は、これらの制約の下では直線のトリミノによってタイル化することができません。 したがって、アルゴリズムはそれらを正しく拒否します。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

DIRS = [(-1, 0), (1, 0), (0, -1), (0, 1)]

def solve():
    n, m = map(int, input().split())
    grid = [list(input().strip()) for _ in range(n)]

    alive = [[grid[i][j] != '.' for j in range(m)] for i in range(n)]
    ans = [['.' for _ in range(m)] for _ in range(n)]

    deg = [[0] * m for _ in range(n)]

    def inside(x, y):
        return 0 <= x < n and 0 <= y < m

    for i in range(n):
        for j in range(m):
            if not alive[i][j]:
                continue
            cnt = 0
            for dx, dy in DIRS:
                ni = i + dx
                nj = j + dy
                if inside(ni, nj) and alive[ni][nj]:
                    cnt += 1
            deg[i][j] = cnt

    q = deque()

    for i in range(n):
        for j in range(m):
            if alive[i][j] and deg[i][j] == 1:
                q.append((i, j))

    def choose_letter(cells):
        used = set()

        for x, y in cells:
            for dx, dy in DIRS:
                nx = x + dx
                ny = y + dy
                if inside(nx, ny):
                    ch = ans[nx][ny]
                    if ch != '.':
                        used.add(ch)

        for ch in "abcd":
            if ch not in used:
                return ch

        return None

    while q:
        x, y = q.popleft()

        if not alive[x][y] or deg[x][y] != 1:
            continue

        middle = None

        for dx, dy in DIRS:
            nx = x + dx
            ny = y + dy
            if inside(nx, ny) and alive[nx][ny]:
                middle = (nx, ny)
                break

        if middle is None:
            print("NO")
            return

        mx, my = middle

        third = None

        for dx, dy in DIRS:
            tx = mx + dx
            ty = my + dy

            if (tx, ty) == (x, y):
                continue

            if inside(tx, ty) and alive[tx][ty]:
                third = (tx, ty)
                break

        if third is None:
            print("NO")
            return

        tx, ty = third

        cells = [(x, y), (mx, my), (tx, ty)]

        letter = choose_letter(cells)

        for cx, cy in cells:
            ans[cx][cy] = letter

        for cx, cy in cells:
            alive[cx][cy] = False

        affected = set()

        for cx, cy in cells:
            for dx, dy in DIRS:
                nx = cx + dx
                ny = cy + dy

                if inside(nx, ny) and alive[nx][ny]:
                    affected.add((nx, ny))

        for nx, ny in affected:
            cnt = 0
            for dx, dy in DIRS:
                px = nx + dx
                py = ny + dy

                if inside(px, py) and alive[px][py]:
                    cnt += 1

            deg[nx][ny] = cnt

            if cnt == 1:
                q.append((nx, ny))

    for i in range(n):
        for j in range(m):
            if alive[i][j]:
                print("NO")
                return

    print("YES")
    for row in ans:
        print("".join(row))

```この実装では、グラフの解釈が直接反映されます。 既存のすべてのセルは、隣接するセルに接続されたノードのように動作します。 

の`alive`配列はどのセルがまだカバーされていないかを追跡します。 トリミノが配置されると、その 3 つのセルは永久に削除されます。 

キューにはすべての次数 1 のセルが格納されます。 これらは強制的な位置です。 よくある間違いは、キュー エントリをポップした後に再検証するのを忘れることです。 次数は動的に変化するため、生きていないセルや次数を持たないセルはスキップされます。`1`。 

の`choose_letter`関数は、隣接するすでに色付けされたセルをスキャンし、その中から最初の未使用の文字を選択します。`a`、`b`、`c`、`d`。 タイルには隣接するタイルがわずかしかないため、常に 4 文字で十分です。 

もう 1 つの微妙な点は、削除されたセルの周囲のみの度数を更新することです。 毎回ボード全体を再計算すると、アルゴリズムが 2 次になります。 

最終検証では、すべてのセルが削除されたかどうかがチェックされます。 一部が残っている場合、それらは貪欲なリダクションでは解決できなかった構造に属しており、有効なタイリングが存在しないことを意味します。

import io
from collections import deque

def run(inp: str) -> str:

    input = sys.stdin.readline

    out = []

    n, m = map(int, input().split())
    grid = [list(input().strip()) for _ in range(n)]

    alive = [[grid[i][j] != '.' for j in range(m)] for i in range(n)]
    ans = [['.' for _ in range(m)] for _ in range(n)]

        for j in range(m):
            if not alive[i][j]:

                ni = i + dx
                nj = j + dy
                if inside(ni, nj) and alive[ni][nj]:
                    deg[i][j] += 1

    q = deque()

    for i in range(n):
        for j in range(m):
            if alive[i][j] and deg[i][j] == 1:

    while q:
        x, y = q.popleft()

        if not alive[x][y] or deg[x][y] != 1:

            nx = x + dx
            ny = y + dy
            if inside(nx, ny) and alive[nx][ny]:
                middle = (nx, ny)
                break

        if middle is None:
            return "NO\n"

        mx, my = middle

        third = None

        for dx, dy in DIRS:
            tx = mx + dx
            ty = my + dy

            if (tx, ty) == (x, y):
                continue

            if inside(tx, ty) and alive[tx][ty]:
                third = (tx, ty)
                break

        if third is None:
            return "NO\n"

        tx, ty = third

            ans[cx][cy] = 'a'
            alive[cx][cy] = False

    for i in range(n):
        for j in range(m):
            if alive[i][j]:
                return "NO\n"

    out.append("YES")
    for row in ans:
        out.append("".join(row))

    return "\n".join(out) + "\n"

 孤立した単一細胞の場合を考えてみましょう。```

w
```セルは度から始まります`0`, したがって、キューに入ることはありません。 処理が完了すると、カバーされていないセルが 1 つ残り、アルゴリズムは正しく出力します。`NO`。 

ここで、切断されたボードを考えてみましょう。```

wb.w
bw.b
```この穴により、ボードが互換性のない領域に分割されます。 一部の細胞は程度を取得します`1`しかし、最終的には 1 つのコンポーネントを 3 つのグループに拡張することができなくなります。 アルゴリズムは、有効な 3 番目のセルが見つからない場合にこれを検出します。

wbwbwb
