 ## 解決策
 ## 問題の理解

 ウィンタースクールの主催者が正確に購入できる方法が何通りあるのかを判断するよう求められています。`n`0.5 リットル、1 リットル、2 リットルの 3 つのサイズのボトルを数量限定で使用して、リットルのコーラを販売します。 入力`a`、`b`、 そして`c`はそれぞれ、各サイズで利用可能なボトルの数を表します。 タスクは、ボトルの数の異なる組み合わせを数えて、総量の合計が正確に一致するようにすることです。`n`リットル。 少なくとも 1 つのサイズで異なる数のボトルを使用する 2 つの組み合わせは、異なるものとみなされます。 

制約は中程度ですが、注意が必要です。 希望の合計ボリューム`n`は最大 10,000 まで、ボトルの種類ごとに最大 5,000 まで可能です。 考えられるすべての組み合わせを直接試す単純な総当りアプローチでは、次のような処理が必要になります。`a * b * c`繰り返し。 最悪の場合、`5000 * 5000 * 5000`反復回数は 1,250 億回であり、2 秒の制限時間では明らかに実行不可能です。 

一部のボトルの種類が総容量を満たすのに不十分である場合、または不要な場合には、明らかではないエッジケースが発生します。 たとえば、次の場合`n = 1`そして`a = 0, b = 0, c = 1`2 リットルのボトルだけで正確に 1 リットルを得るのは不可能なので、正しい出力は 0 です。別の微妙なケースが次の場合に発生します。`n`小さいですが、より大きいボトルも利用できます:`n = 1`そして`a = 2, b = 0, c = 1`の場合、ソリューションでは 2 リットルのボトルではなく 2 つの 0.5 リットルのボトルを使用する必要がありますが、単純な実装では常に大きなボトルを優先する場合にこれを見落とす可能性があります。 

## アプローチ

 最も直接的なアプローチは総当たりです。0.5 リットルのボトルを 0 から 0 まですべてカウントしてみます。`a`、1 リットルのボトルを 0 から 0 まで数えます。`b`、および 2 リットルのボトルの 0 から 0 までのすべてのカウント`c`。 組み合わせごとに総体積を計算します。 等しい場合`n`、カウンターをインクリメントします。 これが機能するのは、あらゆる可能性を徹底的にチェックするためです。 ただし、反復回数は最大に達する可能性があります。`5000 * 5000 * 5000 = 125,000,000,000`最悪の場合、2 秒のウィンドウで実現可能な範囲をはるかに超えます。 

複雑さを軽減するための重要な洞察は、0.5 リットルと 1 リットルのボトルが寄与する体積は線形であり、すべての可能性を反復する代わりに、必要な 2 リットルのボトルの正確な数を計算できることに注意することです。 具体的には、選択した後、`x`半リットルと`y`1リットルのボトル、残りの到達量`n`リットルは次のように表すことができます`n - (0.5 * x + 1 * y)`。 この残量が負でなく 2 で割り切れ、必要な 2 リットルボトルの数が超えない場合`c`の場合、この組み合わせは有効です。 これにより、三重にネストされたループが 0.5 リットル ボトルと 1 リットル ボトルの二重ループに減り、ソリューションが実現可能になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(a * b * c) | お(1) | 遅すぎる |
 | 最適化された 2D ループ | O(a * b) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. カウンタを初期化する`count`これにより、有効な組み合わせの数が追跡されます。 
2. ループオーバー`half`0から`a`、使用された 0.5 リットルのボトルの数を表します。 各反復は、0.5 リットルのボトルの候補数を表します。 
3. ループオーバー`one`0から`b`、使用された 1 リットルのボトルの数を表します。 
4. 選択した 0.5 リットル ボトルと 1 リットル ボトルが寄与する現在の体積を計算します。`current_volume = 0.5 * half + 1 * one`。 
5. 到達する残りの体積を計算します`n`:`remaining_volume = n - current_volume`。 この値が負の場合、より多くのボトルを使用すると超過するため、内側ループの次の反復にスキップします。`n`。 
6.次のことを確認します`remaining_volume`各 2 リットルのボトルは正確に 2 リットルを提供するため、これは 2 で割り切れます。 そうでない場合は、次の反復に進みます。 
7. 必要な 2 リットルボトルの数を計算します。`two_needed = remaining_volume / 2`。 もし`two_needed`を超える`c`、この組み合わせはスキップしてください。 
8. すべての条件が満たされる場合、インクリメントします。`count`。 
9. 両方のループが終了したら、印刷します。`count`。 

機能する理由: ループは、0.5 リットルおよび 1 リットルのボトルの実行可能なすべての数を反復します。 選択ごとに、正確な目標容量を達成するための 2 リットル ボトルの固有の数を計算します。 条件により、この数値が負ではなく整数であり、利用可能な供給量を超えないことが保証されます。 有効な組み合わせはスキップされず、無効な組み合わせはカウントされません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, a, b, c = map(int, input().split())

count = 0
for half in range(a + 1):
    for one in range(b + 1):
        current_volume = 0.5 * half + 1 * one
        remaining_volume = n - current_volume
        if remaining_volume < 0:
            continue
        if remaining_volume % 2 != 0:
            continue
        two_needed = int(remaining_volume // 2)
        if two_needed <= c:
            count += 1

print(count)
```このコードは、説明されている二重ループを直接実装しています。 慎重に計算しています`remaining_volume`割り算をチェックして、2 リットルのボトルの有効な数のみが考慮されていることを確認します。 使用する`remaining_volume // 2`の整数値を保証します`two_needed`。 ループ境界には、使用可能なボトルの数が含まれます。`range(a + 1)`そして`range(b + 1)`ボトルがゼロになった場合にケースをカバーします。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, a, b, c = map(int, input().split())
    count = 0
    for half in range(a + 1):
        for one in range(b + 1):
            current_volume = 0.5 * half + 1 * one
            remaining_volume = n - current_volume
            if remaining_volume < 0:
                continue
            if remaining_volume % 2 != 0:
                continue
            two_needed = int(remaining_volume // 2)
            if two_needed <= c:
                count += 1
    return str(count)

# provided sample
