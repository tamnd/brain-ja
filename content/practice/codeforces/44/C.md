 ## 解決策
 ## 問題の理解

 連休中に花の水やりスケジュールを確認してもらいます。 毎日、正確に 1 回水をやる必要があります。 スケジュールには、数人の人それぞれについて、花に水をやるために割り当てられる日の範囲が指定されています。 目的は、誰も花に水をあげない日、または複数の人が花に水をやる日のいずれかに間違いがあるかどうかを検出することです。 間違いがあった場合は、間違った水やり回数とその日の花に何回水をやったかを最も早い日で報告しなければなりません。 それ以外の場合は、単に「OK」を報告します。 

入力は、日数と人数を表す 2 つの整数 _n_ と _m_ で構成されます。 次に、各人の水やり割り当ての開始日と終了日を示す整数の _m_ 組を続けます。 各割り当て範囲は合計日数以内です。 制約は小さく、_n_ と _m_ は両方とも最大 100 です。これにより、時間計算量が最大 O(n・m) のアルゴリズムを時間制限内で効率的に実行できます。 

単純な実装では、単に毎日を個別にチェックし、その日をカバーする割り当ての数をカウントするだけかもしれません。 2 人の人物が連続または重複する範囲を持っている場合、微妙なエッジ ケースが発生します。 たとえば、2 人に [2, 4] と [4, 6] が割り当てられた場合、4 日目は 2 回カバーされます。 もう 1 つのエッジ ケースは、スケジュールにギャップがある場合 (例: 割り当て [1、2] と [4、5]) で、3 日目に水を与えられないままになる場合です。 開始日または終了日のみを確認する不注意なソリューションでは、これらの問題を見逃してしまう可能性があります。 

## アプローチ

 ブルートフォース手法は簡単です。1 日から _n_ までの毎日、_m_ 人全員を反復処理して、その日をカバーできる割り当ての数を数えます。 これが機能するのは、毎日 _m_ 個の間隔をチェックし、結果として O(n·m) 回の操作が行われるためです。 n と m が最大 100 の場合、これは最大 10,000 回の操作であり、許容範囲内です。 欠点は概念的なものです。重複を繰り返しチェックすることになりますが、散水回数を直接追跡する場合にはこれは不要です。 

より効率的なアプローチでは、ゼロに初期化されたサイズ _n_ の配列を使用して、1 日あたりの水やりの回数を保存します。 各割り当て範囲 [a_i, b_i] について、その範囲内のすべての日を増分します。 すべての割り当てを処理した後、配列をスキャンして値が 1 ではない日を見つけます。これにより、1 日あたりの水やりの回数を明示的にカウントし、間違いを即座に特定できるため、正確さが保証されます。 制約を考慮すると効率は許容範囲内であり、実装は毎日個別に繰り返し確認するよりも簡単でエラーが発生しにくくなります。

 ## アルゴリズムのチュートリアル

 1. 配列を初期化する`watered`長さ _n_ はゼロで埋められます。 各要素は、その日の水やりの回数を表します。 これは、鍵の不変式を明示的にモデル化します。`watered[i]`i+1 日目をカバーする割り当ての数に等しくなります。 
2. 各人の割り当てを繰り返します。 範囲 [a_i, b_i] ごとに増分します`watered[j]`a_i-1 から b_i-1 までのすべての j に対して。 1 を減算する理由は、Python で入力内の 1 から始まる日を 0 から始まる配列インデックスに変換するためです。 
3. すべての割り当てが処理された後、次の手順を繰り返します。`watered`初日から最後まで。 毎日、値が正確に 1 であるかどうかを確認します。そうである場合は、続行します。 そうでない場合は、この日が最初のミスです。 日番号 (インデックス + 1) と値を出力します。`watered`その日は終了します。 これにより、誤った水やり回数で最小日が報告されるようになります。 
4. 間違った日が見つからずにループが完了した場合は、「OK」を出力します。 

このアルゴリズムが機能するのは、ステップ 2 の最後に、不変式が維持されているためです。`watered[i]`i+1 日目に水やりが予定されている回数を正確にカウントします。 ステップ 3 では、毎日 1 回だけ水やりをするというルールの最初の違反を確実に検出します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
watered = [0] * n

for _ in range(m):
    a, b = map(int, input().split())
    for day in range(a - 1, b):
        watered[day] += 1

for i in range(n):
    if watered[i] != 1:
        print(i + 1, watered[i])
        break
else:
    print("OK")
```配列`watered`1 日あたりの水やりの正確な回数をモデル化します。 off-by-one エラーを避けるために、1 から始まる入力インデックスを 0 から始まる Python 配列インデックスに慎重に変換します。 ループオーバー`i`間違いがあった最小の日が確実に見つかるようにします。 使用する`else`on the loop ensures that if no mistakes exist, "OK" is printed.

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    n, m = map(int, input().split())
    watered = [0] * n
    for _ in range(m):
        a, b = map(int, input().split())
        for day in range(a - 1, b):
            watered[day] += 1
    for i in range(n):
        if watered[i] != 1:
            print(i + 1, watered[i])
            break
    else:
        print("OK")
    return output.getvalue().strip()

 ## 特殊なケース

 [1, 2] と [2, 3] など、重複する割り当ての場合は、対象となるすべての日について配列のカウントがインクリメントされるため、処理されます。 2日目は`watered[1] = 2`、アルゴリズムは「2 2」を正しく出力します。 割り当てから最初の日が欠落している場合 (割り当て [2, 3] など)、1 日目は 0 のままとなり、アルゴリズムは「1 0」を出力します。 すべての場合において、アレイは水やりを正確にカウントし、最も早い間違いが確実に報告されるようにします。
