 ## 解決策
 ## 問題の理解

 私たちは、高度に構造化されているものの、明示的に構築するには大きすぎるグラフ上で、非常に大規模な有向歩行カウント問題を扱っています。 

がある$2m$DZY はホーム ノードから開始されます。 自宅から島に移住できる$i$で$a_i$さまざまな方法で。 その最初の動きの後、彼は正確に歩きます$t$島々を巡る日々。 毎日、彼は現在の島に滞在することも、橋を渡って別の島に行くこともできます。 個別のアイランドのすべての順序付きペアの間には、複数の並列無向ブリッジがあり、その数はインデックス間の可分性条件のみに依存します。 

The task is to compute, for each island$i$、で終了する個別の方法の数$i$まさにその後$t$自宅から始まる日数を計算し、これらすべてのカウントのモジュロ XOR を返します。$1051131$。 

決定的に難しいのは、ウォークの定義そのものではなく、スケールです。$t$まで可能です$10^{18}$したがって、私たちは明らかに、長期にわたる直接動的計画法が不可能な状況にあります。 グラフの構造は何らかの代数的単純化を引き起こす必要があり、ほぼ確実にあるサイズの空間で行列のべき乗が行われます。$2m \le 50$。 

素朴な解釈は、これを最短またはカウント歩行の問題として扱うことです。$50 \times 50$遷移マトリックス。 それはすでに示唆しています$O(n^3 \log t)$または同様のアプローチ。これは境界線にありますが、マトリックスが疎であるか構造化されている場合には許容されます。 

微妙な落とし穴は「Stay」操作です。 留まると、すべてのノードに重み 1 の自己ループが導入され、これを遷移行列に含める必要があります。 もう 1 つの微妙な点は、エッジの多重度です。ブリッジの数は 0 または 1 ではなく、割り算に依存します。つまり、隣接重みは任意の入力ではなく算術演算になります。 

最後に、答えはすべてのエンドポイントに対する XOR です。 これにより、中間値を破棄することがなくなり、それぞれの値が必要ないことが強く示唆されます。$ans[i]$独立して完全な精度で計算できますが、最後に XOR が適用されるため、最初に計算する必要があります。 

## アプローチ

 構造を無視すると、自然モデルは次の重み付き有向グラフになります。$n = 2m \le 50$。 させて$T$遷移行列になります。$T[u][v]$から移動する方法の数です$u$に$v$宿泊も含めて1日で。 

ホームからの最初の移動が初期ベクトルを定義します$v_0$どこ$v_0[i] = a_i$。 その後、毎日状態が次のように乗算されます。$T$、それでその後$t$計算する日数$v_t = v_0 \cdot T^t$。 答えは次のとおりです。$v_t$。 

これにより、問題は最大でもサイズの行列べき乗を計算することになります。$50 \times 50$。 直接的なブルート フォースは簡単です。行列を乗算します。$t$回。 それには費用がかかります$O(n^2 t)$、それは不可能です$t = 10^{18}$。 

行列のべき乗により、これは次のようになります。$O(n^3 \log t)$、それは約です$50^3 \cdot 60$、快適に実現可能です。 

本当に重要な部分は構築です$T$効率的に。 すべてのペアごとのエッジ数を直接計算すると、次のようになります。$O(n^2)$可分性チェックを使用すると、これは問題ありません$n = 50$。 繰り返しの定義$a_i$も線形であり、次のように生成できます。$O(n)$。 

重要な洞察は、システムが線形変換として記述されると、巨大な時間次元が完全に消滅し、行列代数における反復二乗に置き換えられるということです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 数日間にわたるブルート フォース シミュレーション |$O(t \cdot n^2)$|$O(n^2)$| 遅すぎる |
 | 行列のべき乗 |$O(n^3 \log t)$|$O(n^2)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を構築する$a$指定された繰り返しを使用します。 これにより、自宅から各島への直接移動の数が得られます。 このステップは、ウェイの初期分布を定義するために必要です。 
2. 移行マトリックスを構築する$T$サイズの$2m \times 2m$。 それぞれの島ごとに$i$、自己ループを含む$T[i][i] += 1$留まるという選択肢を表すため。 
3. 異なる島のペアごとに$u, v$、問題で与えられた割り算ルールを使用して、それらの間のブリッジの数を計算します。 この値を両方に加算します$T[u][v]$そして$T[v][u]$これらの橋は方向性がないためです。 このステップでは、起こり得るすべての日常動作をエンコードします。 
4. 初期状態を行ベクトルとして解釈します。$v$、 どこ$v[i] = a_i$、家からの最初の移動で私たちは島に着陸するので、$i$で$a_i$方法。 
5. コンピューティング$T^t$2進累乗を使用します。 各乗算は 1 ステップの遷移を構成し、べき乗は圧縮されます。$t$に移行します$O(\log t)$行列の乗算。 
6. 乗算$v$による$T^t$最終的な分布を取得するには$t$日々。 
7. 結果として得られるベクトルモジュロのすべてのエントリの XOR を計算します。$1051131$。 

重要な不変条件は、次のとおりです。$k$手順＃すしっぷ＃, エントリ$v[i]$島で終わる個別の有効なウォークの合計数を表します$i$まさにその後$k$日々。 各行列の乗算では、有効なパスごとにすべての中間状態を 1 回だけ合計し、べき乗構造によってパスの長さがスキップされたり重複したりしないため、この解釈が保持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1051131

def mat_mul(A, B):
    n = len(A)
    res = [[0] * n for _ in range(n)]
    for i in range(n):
        Ai = A[i]
        Ri = res[i]
        for k in range(n):
            if Ai[k] == 0:
                continue
            aik = Ai[k]
            Bk = B[k]
            for j in range(n):
                Ri[j] = (Ri[j] + aik * Bk[j]) % MOD
    return res

def mat_pow(M, e):
    n = len(M)
    R = [[0] * n for _ in range(n)]
    for i in range(n):
        R[i][i] = 1
    while e:
        if e & 1:
            R = mat_mul(R, M)
        M = mat_mul(M, M)
        e >>= 1
    return R

def vec_mul(v, M):
    n = len(v)
    res = [0] * n
    for i in range(n):
        if v[i] == 0:
            continue
        vi = v[i]
        for j in range(n):
            res[j] = (res[j] + vi * M[i][j]) % MOD
    return res

def solve():
    m, t, s = map(int, input().split())
    n = 2 * m

    a = [0] * n
    for i in range(s):
        a[i] = int(input().split()[0])

    for i in range(s, n):
        a[i] = (101 * a[i - s] + 10007) % MOD

    T = [[0] * n for _ in range(n)]

    for i in range(n):
        T[i][i] = 1

    for u in range(n):
        for v in range(u + 1, n):
            cnt = 0
            a_uv = a[u]
            a_vu = a[v]
            for d in range(1, int(min(a_uv, a_vu) ** 0.5) + 1):
                if a_uv % d == 0:
                    if a_vu % d == 0:
                        cnt += 1
                    other = a_uv // d
                    if other != d and a_vu % other == 0:
                        cnt += 1
            T[u][v] += cnt
            T[v][u] += cnt

    Tt = mat_pow(T, t)

    v = a[:]
    v = vec_mul(v, Tt)

    ans = 0
    for x in v:
        ans ^= x % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```実装では、プロセスが 3 つの段階に分かれています。$a$、遷移行列を構築し、高速累乗を適用します。 

行列の乗算はゼロエントリをスキップして最適化されます。これは、割り算に応じて多くの遷移がゼロになる可能性があるため重要です。 自己ループの初期化は非常に重要です。これを忘れると「滞在」操作が削除され、すべてのパス数が誤って減少するためです。 

最後のベクトルと行列の乗算は、初期ポストホーム状態から完全な状態への最終的な伝播です。$t$-ステップ分布。

 ## 特殊なケース

 微妙なケースとしては、$t = 0$。 この状況では、家を出た後に遷移は発生しないため、結果は初期分布と等しくなる必要があります。$a_i$。 指数がゼロの場合、行列のべき乗は単位行列を返すため、アルゴリズムはこれを正しく処理します。$v \cdot I = v$、初期状態を保存します。 

別のケースは、すべてが$a_i$は同一です。 この場合、すべてのペアは同一の可分性構造を持ち、遷移行列は高度に対称になります。 行列のべき乗は乗算時に対称性を維持するため、このアルゴリズムは引き続き機能します。 

最後に、最悪の場合の割り算構造は、多くの場合に発生します。$a_i$小さな要素を共有します。 除数カウント ループは、各除数のペアを 1 回正確に列挙し、並列ブリッジの二重カウントを確実に防止します。これは、遷移行列のエッジの重みを正確にするために重要です。
