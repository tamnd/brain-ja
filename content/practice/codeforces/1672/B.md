 以下の範囲の各整数を表すように求められます。$-10$に$10$基数を使用した記数法を使用する$-2$。 このシステムでは、すべての整数が$N$という形式で書かれています$$N = \sum_{i=0}^{k} d_i (-2)^i,$$ここで、各桁は$d_i \in {0,1}$そして、式が正確に評価されるように表現が選択されます。$N$。 

この塩基の構造は、累乗が増加するにつれて符号が交互になるため、通常の正の塩基とは異なります。 これにより、別の符号記号を導入することなく、正と負の両方の整数を表すことができます。 主な困難は、次の乗算でキャリーが一貫して処理されるように桁を選択することです。$-2$それよりも$2$。 

このような表現を構築する標準的な方法は、数値を繰り返し除算することです。$-2$、残りを記録します${0,1}$各ステップで剰余が負でないことを確認しながら。 剰余が負の場合は、追加して調整します。$2$and compensating in the quotient.

 ## アルゴリズムのチュートリアル

 与えられた整数に対して$N$、その基数を構築します$-2$以下のように表現します。 

1. から始める$x \leftarrow N$そして空の数字列。 
2. その間$x \neq 0$、剰余を計算します$r$の$x$モジュロ$2$。 この余りは常に次のいずれかです$0$または$1$適切に調整されている場合。 もし$r = 0$、追加$0$数字列に合わせて設定します$x \leftarrow x / (-2)$。 
3. もし$r = 1$、追加$1$数字列に合わせて設定します$x \leftarrow (x - 1) / (-2)$。 
4. まで続けます$x$になる$0$。 収集された数字は逆の順序で表現を形成します。 

ケース内の調整手順$r = 1$減算後に次のことを保証します$1$、残りの商は整数です。$(x - 1)$いつでも常に均一です$x$奇数です。 で割る$-2$その後、表現と位置システムとの一貫性が保たれます。 

## なぜ機能するのか

 各反復で、次の不変条件を維持します。$$x = \sum_{i \ge k} d_i (-2)^{i-k}$$すでに構築されている数字の場合、現在の反復深さによって適切にシフトされます。 による除算$-2$を選択しながら、残りのすべての寄与の位置の重みを正しくシフトします。$d_0 \in {0,1}$の残りのクラスが確実に$x$モジュロ$2$正しく保存されています。 すべての整数は除算を繰り返すと絶対値が減少するため、$-2$、プロセスは終了し、有限桁展開が行われます。 これで工事は完了です。 ∎

 ## Python ソリューション```python
import sys
input = sys.stdin.readline

def to_base_neg2(x: int) -> str:
    if x == 0:
        return "0"
    digits = []
    while x != 0:
        r = x & 1
        digits.append(str(r))
        x -= r
        x //= -2
    return "".join(digits[::-1])

def solve():
    for i in range(-10, 11):
        print(to_base_neg2(i))

if __name__ == "__main__":
    solve()
