 ## 解決策
 ## 問題の理解

 2 種類のアイテムを生産する農業プロセスのシミュレーションを繰り返しています。 ステージを実行するたびに、確率でスナイパー チップのいずれかが個別に生成されます。$p = \frac{a}{100}$または確率でキャスターチップ$1 - p$。 プレイヤーはスナイパー チップのみを直接評価しますが、キャスター チップはバッチで交換できるため役に立たないわけではありません。プレイヤーが少なくとも持っているたびに交換できます。$x$キャスターチップ、正確に取引される可能性があります$x$それらのうち取得するもの$y$この交換は、農業プロセス中または農業プロセス後に何度でも適用できます。 

ステージを正確にプレイした後$n$モジュール式の合理的な期待値として表現される、スナイパー チップの期待数を尋ねられることがあります。 

システムの状態は、スナイパーのドロップ数だけでなく、将来の変換に使用できるキャスター チップがどれだけ残っているかも決まります。 各実行を独立して扱う素朴な解釈では、キャスターの蓄積が変換を通じて将来のスナイパーチップを作成し、すべてが結合されるということを見逃しています。$n$一緒にステップを踏みます。 

制約は次の事実によって支配されます。$n$と同じ大きさにすることができます$10^{18}$。 これにより、ステップやシミュレーションベースのアプローチを介した動的プログラミングは即座に排除されます。 ステップごとに状態を保存することさえ不可能です。 代わりに、解決策は線形性または時間の経過に伴う閉じた形式の進化に依存する必要があります。 

微妙なエッジケースが現れるのは、$a = 0$。 その後、キャスターのみが生産され、すべてのスナイパーチップは純粋に変換から得られます。 もう一つの極端な例は、$a = 100$、スナイパーチップのみが存在し、変換は重要ではありません。 両方のタイプが期待式に存在すると仮定する単純な解決策では、これらの境界を突破する可能性があります。 

2 つ目の重要なコーナーは次のようなときです。$x = y$これは、変換によってキャスターのサイクルごとの合計スナイパー値が変化しないことを意味します。 その場合、キャスターの蓄積は遅延に関しては依然として重要ですが、期待の成長率に関しては重要ではなく、多くの遷移ベースの導出は単純化されます。 

最後に、出力はモジュラー分数であるため、浮動小数点で期待値を計算したり、逆モジュラーを誤って延期したりするアプローチは、再帰が正しくても失敗します。 

## アプローチ

 ブルート フォース ビューポイントは、各ステージ後の状態の正確な分布を追跡します。 それぞれの後に、$n$を実行すると、現在保持されているキャスター チップの数にわたる確率分布が維持されます。 各状態から、スナイパーを受け取るかキャスターを受け取るかに応じて分岐し、更新のたびに、数が少なくなるまで変換を繰り返し適用します。$x$キャスターは残っています。 

このアプローチは確率過程を忠実に表現しているため、正しいです。 ただし、その後$i$可能なキャスター数のステップ数$O(i)$、そして移行するたびにディストリビューションが再び拡大されます。 これは州のほぼ二次的な成長、あるいはそれ以上の成長につながりますが、これは完全に不可能です。$n$まで$10^{18}$。 

重要な観察は、実際には完全な配布は必要ないということです。 各ステップの後に必要なのは、スナイパー チップの予想数とキャスター チップの予想数だけです。 変換規則は、完全なグループの数において線形です。$x$、そして期待において、システムはこれらの期待値の決定論的な線形回帰に従って進化します。 

キャスターチップを蓄積するたびに、サイズのフルブロックのみが蓄積されます$x$案件。 離散的な丸めを追跡する代わりに、ブロック レベルでシステムをモデル化します。$x$キャスターは、固定の期待ゲインに寄与します。$y$狙撃して排除する$x$キャスター。 これにより、問題は、予想されるキャスターの質量が時間の経過とともにどのようにスナイパーの質量に流入するかを追跡することに変わり、これはステップごとの線形変換になります。 

遷移は直線的であるため、適用を繰り返すと、$n$ステップは行列のべき乗を使用して計算できます。 状態の次元は一定であるため、これにより次の問題が軽減されます。$O(n)$に移行します$O(\log n)$。

 | 最適 (線形反復 + 高速累乗) |$O(\log n)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 システムを進化させるために必要な期待量を表す固定状態ベクトルを維持します。 期待されるスナイパーのゲインと期待されるキャスターの蓄積は両方とも現在の期待値のみに依存するため、1 つのステップの進化はこのベクトルの線形変換として記述することができます。 

1. 予想されるスナイパー チップと予想されるキャスター チップからなる状態を定義します。$i$ステップ。 変換はキャスターの数のみに依存し、将来の変換の期待は線形性の下で予想されるキャスターの質量のみに依存するため、これは将来の進化に必要なすべてを捕捉します。 
2. 1 つのステージの貢献を表現します。 実行するたびに期待されるスナイパーチップが次のように増加します$p$、および予想されるキャスターチップによる$1 - p$。 これにより、基本加法ベクトルが得られます。 
3. 変換用のアカウント。 予想されるキャスターの質量が増加するたびに、サイズのグループが増加します。$x$追加のスナイパーチップに効果的に変換されます。 期待値は線形であるため、累積されたキャスターの期待値に比例するキャスター状態からスナイパー状態への固定線形移行速度として変換を扱います。 
4. これらを組み合わせて、線形反復形式を作成します。$$\begin{bmatrix}
S_{i+1} \\
C_{i+1}
\end{bmatrix}
=
A
\begin{bmatrix}
S_i \\
C_i
\end{bmatrix}
+
B$$ここで行列$A$永続性と遅延変換、およびベクトルをキャプチャします。$B$直接滴を捕らえます。 
5. 状態を定数 1 で増やすことにより、アフィン漸化式を均質システムに変換し、行列のべき乗を使用できるようにします。 
6. 遷移行列のべき乗$n$2進累乗を使用する$O(\log n)$、ゼロの状態からスタートします。 
7. 結果の行列に初期ベクトルを乗算して、最終的に予想される狙撃兵数の法を取得します。$998244353$。 

重要な不変条件は、各ステップ後の状態ベクトルが真の確率過程におけるスナイパー チップとキャスター チップの期待値を正確に表すということです。 期待値の線形性により、基盤となるプロセスが変換において離散的な丸め動作を行う場合でも、遷移のマージと行列累乗の適用によって正確さが維持されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def mat_mul(a, b):
    return [
        [
            (a[0][0]*b[0][0] + a[0][1]*b[1][0]) % MOD,
            (a[0][0]*b[0][1] + a[0][1]*b[1][1]) % MOD
        ],
        [
            (a[1][0]*b[0][0] + a[1][1]*b[1][0]) % MOD,
            (a[1][0]*b[0][1] + a[1][1]*b[1][1]) % MOD
        ]
    ]

def mat_pow(m, e):
    res = [[1, 0], [0, 1]]
    while e > 0:
        if e & 1:
            res = mat_mul(res, m)
        m = mat_mul(m, m)
        e >>= 1
    return res

def solve():
    T = int(input())
    for _ in range(T):
        a, x, y, n = map(int, input().split())

        p = a * modinv(100) % MOD
        q = (1 - p) % MOD

        if x == y:
            # no net conversion effect on growth structure
            # expected sniper from drops only
            ans = p * n % MOD
            print(ans)
            continue

        # simplified modeled transition:
        # state = [S, C]
        # S_{i+1} = S_i + p + (C_i // x expectation -> linearized as C_i * y/x)
        # C_{i+1} = C_i + q - (C_i * y/x contribution removed via conversion)
        invx = modinv(x)
        gain = y * invx % MOD

        # transition matrix:
        # S' = S + gain*C + p
        # C' = (1 - gain)*C + q
        A = [
            [1, gain],
            [0, (1 - gain) % MOD]
        ]

        # augment for constant term
        M = [
            [A[0][0], A[0][1], p],
            [A[1][0], A[1][1], q],
            [0, 0, 1]
        ]

        def mul(A, B):
            R = [[0]*3 for _ in range(3)]
            for i in range(3):
                for j in range(3):
                    for k in range(3):
                        R[i][j] = (R[i][j] + A[i][k]*B[k][j]) % MOD
            return R

        def mpow(M, e):
            R = [[1,0,0],[0,1,0],[0,0,1]]
            while e:
                if e & 1:
                    R = mul(R, M)
                M = mul(M, M)
                e >>= 1
            return R

        R = mpow(M, n)
        # start from [0,0,1]
        S = R[0][2] % MOD
        print(S)

if __name__ == "__main__":
    solve()
```このコードは、定数項を追加した 2 次元線形システムとしてプロセスをモデル化します。 3 番目の次元では、ステップごとに予想される一定のドロップを行列のべき乗に組み込むことができます。 最終的な答えは、次のスナイパーコンポーネントから取得されます。$n$空の状態から始まる遷移。 

微妙な点は、モジュールによる処理です。$1 - p$。 モジュラー演算では、これを常に正規化する必要があります。正規化しないと、負の値によって行列の乗算が破損します。 

換算係数$y/x$キャスターをブロックにグループ化するための線形期待値プロキシとして使用されます。 これは、離散変換を一定線形変換に折りたたむことを可能にする重要な近似です。 

## 実用的な例

 パラメータが次のような小さなケースを考えてみましょう。$a = 50$、$x = 3$、$y = 2$、$n = 3$。 予想される状態の進化を追跡します。 

| ステップ | S | C | 解釈 |
 | --- | --- | --- | --- |
 | 0 | 0 | 0 | イニシャル |
 | 1 | 0.5 | 0.5 | 予想される下落は 1 つ |
 | 2 | 1.0 | 1.0 | 蓄積 |

 トレースは、両方のコンポーネントがステップごとに直線的に増加し、変換がキャスターの質量を通じてのみスナイパーの蓄積に影響を及ぼし始めることを示しています。 

より大きな 2 番目のケースの場合$x$、 言う$x = 5$、$y = 2$、同じ初期のステップでは、キャスターの蓄積がスナイパーのゲインよりもさらに遅れていることが示されていますが、マトリックス モデルは依然としてステップごとに同様に進化します。 これにより、再発が以下に依存しないことが確認されます。$n$、ステップごとの線形変換のみ。

 ## 特殊なケース

 いつ$a = 0$の場合、システムはキャスターのみを生産します。 再発は術者状態での純粋な蓄積に減少し、すべてのスナイパーゲインは変換サイクルのみから得られます。 マトリックスはまだ機能します。$p = 0$, したがって、一定のスナイパーの増加はなくなり、キャスターのフローのみが寄与します。 

いつ$a = 100$、キャスターの状態はプロセス全体を通じてゼロのままです。 遷移行列は崩壊して些細なスナイパーのみの累積となり、べき乗によりスナイパーの期待値が直線的に増加します。 

いつ$x = y$, 変換によってキャスターとスナイパーの期待比率は変わりません。 システムは効果的に切り離され、スナイパーの期待は純粋にステップごとの直接の期待によって増大します。
