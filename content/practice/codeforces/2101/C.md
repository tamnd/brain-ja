 ## 問題の理解

 与えられた配列から派生した配列の「美しさ」を最大化することが求められます。`a`。 それぞれのポジションについて、`a`、新しい配列`b`満たさなければなりません`1 ≤ b_i ≤ a_i`。 の美しさ`b`内の各値の繰り返し出現間の最大ギャップの合計です。`b`。 具体的には、価値観としては`x`、`d_x(b)`の最初と最後の出現の間の距離です。`x`で`b`。 もし`x`一度発生するかまったく発生しない、`d_x(b) = 0`。 全体的な美しさはすべての合計です`d_x(b)`に存在する値については`b`。 

入力サイズ`n`テスト ケースごとに 200,000 に達する可能性があり、すべてのテスト ケースの合計も 200,000 に制限されます。 考えられるすべての配列を反復する単純なアプローチ`b`組み合わせは指数関数的に多く存在するため、明らかに不可能です。 アルゴリズムは線形に近いものでなければなりません`n`、そうでない場合はタイムアウトになります。 の制約`a_i`(`1 ≤ a_i ≤ n`) の潜在的な値は、`b`によって制限されています`n`同じように。 

明らかではないエッジ ケースには、すべての値が同じである配列、値が厳密に増加または減少している配列、エッジで値が繰り返されている配列が含まれます。 たとえば、次の場合`a = [1, 1, 1, 1]`、任意の選択`b`もなります`[1, 1, 1, 1]`そして美しさは`3`、 ない`0`。 もし`a = [1, 2, 1, 2]`、選択する`b = [1, 2, 1, 2]`距離を最大化します。 単純に最大値を選択したり、貪欲に順次割り当てを行おうとする単純な試みは、特に同じ数値がさまざまな距離で複数回出現する可能性がある場合、エッジの配置で失敗することがよくあります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての配列を列挙します。`b`満足するもの`1 ≤ b_i ≤ a_i`そしてそれぞれの美しさを計算します。 各配列について、各数値の位置を追跡し、計算します。`d_x(b)`最大距離として。 これは正しいですが、実行不可能です。`a_i`数が多い、`b`配列は指数関数的に増加します。 たとえ`n = 20`の要素がある場合、配列の数は 100 万を超えます。`a`制限がないため、ブルートフォースは使用できません。 

重要な洞察は、`d_x(b)`価値のために`x`、配置するだけです`x`左端と右端の位置で、`x`許可されています。 中間ポジションでは距離は伸びません。 したがって、考えられるそれぞれの値に対して、`x`、私たちは位置を追跡します`a`どこ`x`出現する可能性があります（`x ≤ a_i`）。 次に、最大距離は、`x`は`last - first`、 どこ`first`そして`last`は、このリストの最初と最後のインデックスです。 美しさはすべての総和である`x`。 これにより、問題は線形スキャンに帰着します。`a`および各値の候補位置。これはテスト ケースごとに O(n) です。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 各テスト ケースをループします。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして配列`a`。 
3. 辞書の初期化`positions`それぞれの潜在的な値をマッピングする`x`空のリストに。 
4. 配列を反復処理する`a`インデックスによって。 それぞれについて`i`、追加`i`に`positions[x]`みんなのために`1 ≤ x ≤ a[i]`。 
5. 各値について`x`に登場する`positions`、距離を次のように計算します。`positions[x][-1] - positions[x][0]`。 
6. これらの距離をすべて合計します。`x`テストケースで最大限の美しさを得るために。 
7. 結果を出力します。 

ステップ 4 の理由は微妙です。 以下のすべての番号を追跡する必要はありません。`a_i`; 代わりに、実際に表示される数字のみを追跡します。`a`少なくとも一度は。 距離を計算するときは数値のみを考慮します`x`そのような`x ≤ a_i`ある位置で。 これにより、不必要なストレージを回避しながら正確性が保証されます。 

なぜ機能するのか: 各数字を配置することで`x`可能な限り早い位置と最新の位置で、美しさへの貢献を最大限に高めます。 中間に配置しても最大ギャップは増加しません。 寄与分は独立しているため、それらを合計すると全体的に最大の美しさが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        from collections import defaultdict
        positions = defaultdict(list)
        
        for i, val in enumerate(a):
            positions[val].append(i)
        
        beauty = 0
        for val, pos_list in positions.items():
            if len(pos_list) > 1:
                beauty += pos_list[-1] - pos_list[0]
        
        print(beauty)

if __name__ == "__main__":
    main()
```このソリューションは、次を使用して入力をすばやく読み取ります。`sys.stdin.readline`。 辞書`positions`各値が発生するインデックスを収集します。 各値の最後のインデックスと最初のインデックスの差を取ることで、最大距離を効率的に計算します。 単一の出現は自動的にゼロとなり、配列外の値は決して出現しません。`positions`。
