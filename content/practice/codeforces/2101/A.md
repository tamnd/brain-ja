 ## 解決策
 ## 問題の理解

 記入するよう求められます$n \times n$の整数を含むグリッド$0$に$n^2 - 1$、それぞれが 1 回だけ使用されます。 すべての長方形サブグリッドは、その内部の数値の MEX に等しい値を提供します。目的は、すべての可能なサブ長方形にわたってこれらの MEX 値の合計を最大化することです。 

主な困難は、固定グリッドの MEX を計算することではなく、多くのサブグリッドに次のような小さな値が含まれるように数値の配置を選択することです。$0, 1, 2, \dots$これらの値が MEX を増加できる唯一の値であるため、できるだけ頻繁に実行してください。 大きな数値は事実上不活性です。すべての小さな数値がすでに存在しない限り、MEX の増加には決して役立ちません。 

制約により許可されるのは、$n$最大500なので、$n^2$250,000 に達する可能性があります。 サブグリッドをシミュレートしたり、サブグリッドごとに MEX を直接計算したりするソリューションには、大まかに次の作業が含まれます。$O(n^4)$または$O(n^3)$それは実現可能性をはるかに超えています。 平$O(n^2 \log n)$構造は問題ありませんが、サブグリッドごとに理由があるものは除外されます。 

数値がランダムに分散されている場合、または行優先の順序で配置されている場合、微妙な失敗例が発生します。 たとえば、$n=3$、配置:```
0 1 2
3 4 5
6 7 8
```左上の領域にのみ小さな値が集中するという強いバイアスが生じます。 小さな値を含む可能性のある多くのサブグリッドではそれらが完全に欠落し、MEX の寄与が減少します。 最適な配置では、代わりに、多くのサブ四角形がそれらを早期に含むように、小さな値が確実に分散されるようにする必要があります。 

## アプローチ

 強引なアイデアは、次のすべての順列を試してみることです。$n^2$数値を計算し、各配置の MEX 合計を計算します。 これは定義上は正しいですが、次のような理由から不可能です。$(n^2)!$順列があり、それぞれを評価するにはすべてを反復する必要があります$O(n^2)$最大のサブグリッド$O(n^2)$サブグリッドごとに機能し、少なくとも$O((n^2)! \cdot n^4)$複雑。 

構造的な観察が必要です。MEX は完全に、初期の小さな数値が四角形内にどのように表示されるかによって決まります。 固定サブグリッドの場合、その MEX は少なくとも$k$すべての数字がそうである場合に限り$0$を通して$k-1$その中にいます。 したがって、各値の寄与は$x$すべての数値を含むサブグリッドの数によって決まります$0 \dots x-1$。 

これは問題を再構成します。MEX について直接考える代わりに、集合が$\{0,1,\dots,x\}$多くの長方形の中に横たわる傾向があります。 

これを最大化する古典的な方法は、小さな値をコンパクトな領域にクラスタリングすることです。これは、密集したクラスタには、分散した構成よりも多くのサブ長方形が含まれるためです。 最適な戦略は、数値の接頭語が空間的にコンパクトなままになるように、「蛇のような」またはらせんのような順序を構築することです。 

シンプルで最適な構築の 1 つは、左上隅から開始してレイヤーごとに内側に向かって螺旋状にグリッドを埋めることです。 これにより、最小のセットが保証されます。$k$数値は常に接続されたほぼ正方形の領域を形成し、その領域を完全に含む部分長方形の数が最大になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |

 | スパイラル/積層構造 |$O(n^2)$|$O(n^2)$| 承認済み |

 ## アルゴリズムのチュートリアル

 目標は番号を割り当てることです$0 \dots n^2-1$そのため、小さな値が空間的にクラスター化されます。 

1. 空の状態から始めます$n \times n$グリッドと現在値$v = 0$。 値$v$は常に次に小さい未使用の番号を表し、プレフィックスのジオメトリを確実に制御します。 
2. 上の行、下の行、左の列、右の列の 4 つの境界を維持します。 これらは、現在の塗りつぶされていない四角形を定義します。 最初は、これらは完全なグリッドです。 
3. 現在の境界を使用して上の行を左から右に埋め、連続した値を割り当てます。 塗りつぶしたら、上の境界線を内側に移動します。 これにより、最小値が最外層を占めるようになり、多くの長方形からそれらの値にアクセスできるようになります。 
4. 右側の列を上から下まで埋めてから、右側の境界を縮小します。 これにより、小さな値の接続性を維持しながら、内向きの階層化が継続されます。 
5. 下の行を右から左に塗りつぶし、下の境界を縮小します。 
6. 左の列を下から上に埋めてから、左の境界を縮小します。 
7. すべてのセルが埋まるまでこのプロセスを繰り返します。 完全なサイクルごとに、中心の周囲に増加する値の「リング」が作成されます。 

この順序が重要である理由は、値の接頭辞が$0 \dots k$常に、制御された方法で内側に縮小する単一の連続領域を形成します。 これにより、プレフィックスを完全に含めることができるサブ四角形の数が最大になります。 

### なぜ効果があるのか

 あらゆる値に対して$k$を含むセルのセットを考えます。$0 \dots k$。 この構造では、これらのセルは常に、最小の境界長方形を持つ接続された領域を形成します。 サブグリッド内の MEX は、これらの値がすべて含まれるかどうかに依存するため、外接する四角形を含むサブグリッドの数を最大化すると、合計の寄与が最大化されます。 スパイラルにより、この境界四角形が可能な限りゆっくりと対称的に成長するようになり、考えられるすべての四角形の包含頻度が最大化されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        grid = [[0] * n for _ in range(n)]
        
        top, bottom = 0, n - 1
        left, right = 0, n - 1
        val = 0
        
        while top <= bottom and left <= right:
            for j in range(left, right + 1):
                grid[top][j] = val
                val += 1
            top += 1

            for i in range(top, bottom + 1):
                grid[i][right] = val
                val += 1
            right -= 1

            if top <= bottom:
                for j in range(right, left - 1, -1):
                    grid[bottom][j] = val
                    val += 1
                bottom -= 1

            if left <= right:
                for i in range(bottom, top - 1, -1):
                    grid[i][left] = val
                    val += 1
                left += 1

        for row in grid:
            print(*row)

if __name__ == "__main__":
    solve()
```このコードは、標準のスパイラル塗りつぶしを実装します。 重要な実装の詳細は、下の行と左の列を埋める前に慎重に境界をチェックすることです。 これらのチェックを行わないと、スパイラルが中央に崩れるときに、奇数サイズのグリッドがすでに割り当てられているセルを上書きします。 

変数`val`厳密に増加しており、からの各数値を保証します$0$に$n^2-1$は 1 回だけ使用されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    
    t = int(input())
    for _ in range(t):
        n = int(input())
        grid = [[0]*n for _ in range(n)]
        
        top, bottom, left, right = 0, n-1, 0, n-1
        val = 0
        
        while top <= bottom and left <= right:
            for j in range(left, right+1):
                grid[top][j] = val
                val += 1
            top += 1
            
            for i in range(top, bottom+1):
                grid[i][right] = val
                val += 1
            right -= 1
            
            if top <= bottom:
                for j in range(right, left-1, -1):
                    grid[bottom][j] = val
                    val += 1
                bottom -= 1
            
            if left <= right:
                for i in range(bottom, top-1, -1):
                    grid[i][left] = val
                    val += 1
                left += 1
        
        output.append("\n".join(" ".join(map(str, row)) for row in grid))
    
    return "\n".join(output)

 ## 特殊なケース

 最小限のグリッドのような$n=1$単一の値のみが含まれます。 アルゴリズムは直ちにループに入り、セル (0,0) に 0 を入力して終了します。 ループ条件が存在するため、境界の破損は発生しません。`top <= bottom and left <= right`正確に 1 回保持されます。 

次のような奇数サイズのグリッドの場合$n=3$、螺旋は最終的に中央のセルに崩壊します。 その瞬間、すべての境界が収束し、割り当てが 1 つだけ残ります。 境界チェックにより、すでに入力されたセルの再処理が防止され、中心値が正確に 1 回書き込まれることが保証されます。
