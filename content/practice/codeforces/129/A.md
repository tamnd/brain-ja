 ## 解決策
 ## 問題の理解

 私たちにはクッキーが入った袋がいくつか渡され、各袋にはある程度の数のクッキーが入っています。 オルガはちょうど 1 つのバッグを盗もうとしています。 その袋を取り出した後、2 人の姉妹が均等に分割できるように、残されたクッキーの総数は偶数でなければなりません。 

課題は、残りの合計が均等になるように、オルガが選択できるバッグの数を数えることです。 

入力は、バッグの数と各バッグ内のクッキーの数で構成されます。 出力は単一の整数、つまり削除できる有効なバッグの数です。 

制約は非常に小さいです。 袋は最大 100 個あり、各袋には最大 100 個のクッキーが含まれます。 最悪の場合でも約 10,000 回の演算しか実行されないため、二次解法であっても即座に実行されます。 つまり、最適化のトリックではなく、明確さと正確さに完全に集中できるということです。 

難しいのは、1 つのバッグを削除した後にパリティがどのように動作するかを理解することです。 不用意に実装すると、合計が誤って再計算されたり、合計が偶数のままであると誤解したりする可能性があります。 

次の例を考えてみましょう。```
1
1
```クッキーの総数は 1 です。オルガが唯一の袋を取り除くと、残りの総数は 0 になり、偶数になります。 正しい答えは次のとおりです。```
1
```バグのあるソリューションでは、ゼロが偶数であることを忘れ、誤って 0 が出力される可能性があります。 

もう 1 つの間違いが起こりやすいのは、パリティ ロジックです。 考慮する：```
3
1 2 3
```合計は6で偶数です。 偶数の袋を取り出すと残りの合計は偶数のままですが、奇数の袋を取り出すと奇数になります。 ここでは 2 つ入ったバッグのみが機能するため、答えは次のようになります。```
1
```奇数のバッグだけを数えたり、慎重に推論せずに元の合計平価だけをチェックしたりすると、間違った結果が得られる可能性があります。 

最後のエッジケースは、すべてのバッグが同じパリティを持つ場合です。 例えば：```
4
2 2 2 2
```合計は 8 です。バッグを取り除くと 6 が残り、これは偶数になります。 答えは 4 です。誤って残りの合計ではなく、削除されたバッグのパリティをチェックする実装は、ここで通知なく失敗する可能性があります。 

## アプローチ

 最も直接的な解決策はブルートフォースです。 まず Cookie の総数を計算します。 そして、すべての袋について、それを取り出すことを想像し、残りの合計が均等であるかどうかを確認します。 

バッグ用`i`、残りの合計は次のとおりです。```
total_sum - a[i]
```その値が 2 で割り切れる場合、このバッグは有効な選択です。 

このアプローチはすでに十分に高速です。 バッグが最大 100 個の場合、合計を 1 回計算した後、最大 100 回のチェックを実行します。 

この問題の背後には、有益なパリティ観察もあります。 残りの合計のパリティは、合計と取り出されたバッグのパリティのみに依存します。 

合計が偶数の場合、偶数のバッグを削除すると結果は偶数のままですが、奇数のバッグを削除すると結果は奇数になります。 

合計が奇数の場合、奇数のバッグを削除すると、残りの合計が偶数になります。 

したがって、この問題は、パリティが合計のパリティと一致するバッグを数えるという問題とも見なすことができます。 

すべての候補バッグを個別にチェックできるため、総当たりバージョンが機能します。 パリティの観察により、これらのチェックが非常に簡単である理由が説明されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n) | お(1) | 承認済み |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. バッグの数とクッキー数の配列を読み取ります。 
2. すべてのバッグのクッキーの総数を計算します。 
3. 応答カウンタを 0 に初期化します。 
4. すべてのバッグを繰り返し処理します。 
5. 現在のバッグについて、バッグを取り出した後の残りの合計を計算します。```
remaining = total_sum - current_bag
```6.次のことを確認します。`remaining`は均等です。 

もし`remaining % 2 == 0`、答えを増やします。 
7. すべてのバッグを処理した後、回答を印刷します。 

### なぜ効果があるのか

 すべてのバッグについて、アルゴリズムはそのバッグを取り出した後に残る Cookie の数を直接計算します。 バッグの数は、残りの合計が偶数の場合に正確に数えられ、問題の要件と正確に一致します。 

考えられるすべてのバッグが 1 回チェックされ、パリティ テストが数学的に正しいため、アルゴリズムは有効な答えを見逃したり、無効な答えをカウントしたりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

total = sum(a)

answer = 0

for x in a:
    if (total - x) % 2 == 0:
        answer += 1

print(answer)
```この解決策は、バッグの数とクッキーの数を読み取ることから始まります。 合計金額は最初に 1 回計算されるため、バッグごとに繰り返し再計算する必要はありません。 

ループは各バッグを個別にチェックします。 入っているバッグの場合`x`クッキー、それを取り除く`total - x`後ろにはクッキー。 この残りの量が 2 で割り切れる場合、バッグは有効な選択肢を 1 つ提供します。 

制約が小さいため、実装は単純です。 Python ではオーバーフローの懸念はなく、ゼロに対する特別な処理は必要ありません。`0 % 2 == 0`自然に機能します。 

微妙な点の 1 つは、操作の順序です。 パリティをチェックする前に、現在のバッグを減算する必要があります。 合計のパリティについて別途推論しない限り、バッグ自体のパリティだけをチェックすることは必ずしも正しいとは限りません。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    total = sum(a)

    ans = 0

    for x in a:
        if (total - x) % 2 == 0:
            ans += 1

    print(ans)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    return sys.stdout.getvalue().strip()

# provided sample
assert run("1\n1\n") == "1", "sample 1"

# minimum size, even remaining becomes zero
assert run("1\n7\n") == "1", "single bag"

# all even values
assert run("4\n2 2 2 2\n") == "4", "all bags valid"

# mixed parity
assert run("4\n1 2 3 4\n") == "2", "only even bags work"

# no valid choices
assert run("2\n2 2\n") == "0", "removing any bag leaves odd total"

# larger case
assert run("5\n2 2 2 2 99\n") == "1", "only odd bag works"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1 / 7`|`1`| 残りの Cookie がゼロの場合は偶数として扱われます。 
|`4 / 2 2 2 2`|`4`| すべてのバッグは取り外し可能です。 
|`4 / 1 2 3 4`|`2`| 混合パリティの処理 |
 |`2 / 2 2`|`0`| 有効な削除はありません |
 |`5 / 2 2 2 2 99`|`1`| 条件を満たすバッグは 1 つだけ |

 ## 特殊なケース

 可能な最小の入力を考えてみましょう。```
1
1
```合計は 1 です。バッグのみを削除すると、次のようになります。```
1 - 1 = 0
```0 は偶数であるため、アルゴリズムは答えをインクリメントし、1 を出力します。これにより、残りの空の Cookie が正しく処理されることが確認されます。 

ここで、すべてのバッグが均等である場合を考えてみましょう。```
4
2 2 2 2
```合計は 8 です。バッグを取り除くと 6 が残り、これは偶数になります。 

アルゴリズムは 4 つのバッグすべてをチェックします。```
8 - 2 = 6
```毎回なので、答えは 4 になります。 

最後に、バッグが 1 つだけ機能する場合を考えてみましょう。```
5
2 2 2 2 99
```合計は 107 で奇数です。 

偶数のバッグを取り除くと 105 が残り、依然として奇数です。 

99枚の葉が入った袋を取り出す：```
107 - 99 = 8
```それは均等です。 

アルゴリズムは、有効な選択肢を 1 つだけ正確にカウントします。
