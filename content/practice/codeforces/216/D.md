 ## 解決策
 ## 問題の理解

 パウ・ザ・スパイダーの巣は以下のもので構成されています`n`中心から放射状に伸びるメインスレッドで、平面を次のように分割します。`n`等しいセクター。 各セクターには、境界メイン スレッドを接続するブリッジがある場合があります。 すべてのブリッジには、中心から同じ距離に接続ポイントがあります。 ウェブ内のセルは、2 つの隣接するブリッジとそのセクターの 2 つのメインスレッドの間に形成される台形として定義されます。 セルの 2 つの非平行な側面 (境界の主ねじ山) に沿った接続点の数が等しくない場合、セルは不安定になります。これは、不等な接続点により張力の不均衡が生じるためです。 

入力により、セクターの数と、各セクターのブリッジの距離のリストが提供されます。 タスクは、すべての不安定なセル、つまり、2 つの隣接するメイン スレッドの対応する距離にあるブリッジの数が同じではない台形セルの総数をカウントすることです。 各ブリッジは、その上のブリッジとともに 1 つのセルにのみ寄与します。 

制約が与える`n`最大 1000、ブリッジの総数は最大 10^5 です。 これにより、ブリッジの総数がほぼ線形になるアルゴリズムが可能になりますが、セクター全体ですべてのブリッジを他のすべてのブリッジと比較するアルゴリズムは許可されません。 エッジケースは、セクターにブリッジが 1 つしかない場合、または隣接するセクターの距離が大きく異なるブリッジの数が大きく異なる場合に発生します。 たとえば、1 つのセクタに距離 1 と 2 にブリッジがあり、隣接するセクタには距離 2 にのみブリッジがある場合、距離 1 と 2 の間に形成されたセルは、両側に沿ったブリッジの数が一致しないため不安定になります。 

## アプローチ

 ブルート フォース アプローチでは、隣接するセクターのすべてのペアが考慮され、各ブリッジについて、隣接するセクターに同じ距離に一致するブリッジが存在するかどうかがチェックされます。 これには、あるセクターのすべてのブリッジと次のセクターのすべてのブリッジを比較する必要があり、最悪の場合の複雑さは O(total_bridges^2) になりますが、ブリッジの数が 10^5 までの場合、これでは遅すぎます。 

重要な観察は、セルが安定するには、2 つの連続する距離間のブリッジの数がセクター境界の両側で一致する必要があるということです。 各セクターの距離を並べ替えると、2 ポインター手法を使用できるようになります。 各セクターのソートされたブリッジ距離を隣接セクターと並行して調べて、不一致をカウントできます。 ブリッジ距離が 1 つのセクターに存在するが、隣接するセクターには存在しないたびに、セルが不安定になります。 これにより、複雑さがソートの O(total_bridges * log k_i) とカウントの O(total_bridges) に軽減されます。これは、指定された制限の下で実現可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((合計ブリッジ数)^2) | O(トータルブリッジ数) | 遅すぎる |
 | 最適 | O(total_bridges log k_i) | O(トータルブリッジ数) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. セクタ数を読み取る`n`。 
2. 各セクターについて、橋の数と中心からの橋の距離を読み取ります。 各セクターの距離をリストに保存します。 
3. 各セクターの橋の距離のリストを並べ替えます。 ソートにより、隣接するセクターの橋を効率的に比較できます。 
4. 不安定なセルのカウンターをゼロに初期化します。 
5. 分野ごとに`i`、その隣人を考慮してください`(i + 1) % n`(モジュロは、最後のセクターが最初のセクターにラップすることを保証します)。 2 つのポインターを使用して、セクター内のブリッジのソートされたリストを横断します。`i`そしてその隣人も同時に。 
6. どちらのポインタもリストの最後に到達していない間に、距離を比較します。 距離が等しい場合は、両方のポインタを前方に移動します。 一方のセクターに距離が存在し、もう一方のセクターには存在しない場合は、不安定セル カウンタを 1 つインクリメントし、小さい方の距離のポインタを進めます。 
7. 一方のリストが使い果たされると、もう一方のリストに残っているブリッジも不安定なセルを形成します。 残りのブリッジの数だけカウンターをインクリメントします。 
8. すべてのセクタに対してステップ 5 ～ 7 を繰り返し、隣接するセクタのすべてのペアを考慮します。 
9. 不安定セルの合計数を出力します。 

機能する理由: 並べ替えにより、セクター内のすべての橋が、隣接するセクター内の最も近い可能性のある橋と比較されます。 2 ポインター法により、一致しない距離を見逃さないことが保証されます。 一致しないブリッジは、まさに 1 つの不安定なセルに対応します。 モジュロは、最後のセクターが最初のセクターにラップアラウンドすることを保証し、Web の周期的な性質を捉えます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
sectors = []

for _ in range(n):
    data = list(map(int, input().split()))
    k = data[0]
    bridges = sorted(data[1:])
    sectors.append(bridges)

unstable_cells = 0

for i in range(n):
    a = sectors[i]
    b = sectors[(i + 1) % n]
    p1 = p2 = 0
    while p1 < len(a) and p2 < len(b):
        if a[p1] == b[p2]:
            p1 += 1
            p2 += 1
        elif a[p1] < b[p2]:
            unstable_cells += 1
            p1 += 1
        else:
            unstable_cells += 1
            p2 += 1
    unstable_cells += (len(a) - p1) + (len(b) - p2)

print(unstable_cells)
```コードはセクターを読み取り、ブリッジ距離を並べ替えます。 2 点比較では、不一致をチェックして不安定なセルをカウントします。 いずれかのリストが使い果たされた後の残りのブリッジも不安定なものとしてカウントされ、セクターのブリッジ数が異なるエッジ ケースに対応します。
