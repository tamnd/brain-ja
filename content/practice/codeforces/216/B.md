 ## 解決策
 ## 問題の理解

 学生を無向グラフとしてモデル化できます。 各生徒が頂点であり、敵の各ペアがエッジを作成します。 残りの生徒を同じサイズの 2 つのチームに分割し、1 つのチーム内にエッジが残らないようにしたいと考えています。 グラフの観点から言えば、敵は常に反対側にいる必要があるため、2 部グラフが必要です。 

接続されたコンポーネントが 2 部構成でない場合は、そのコンポーネントから少なくとも 1 人の生徒を削除する必要があります。 2 つのチームのサイズは同じでなければならないため、削除後、残っている生徒の総数も偶数でなければなりません。 

グラフには最大 100 個の頂点と 100 個のエッジがあるため、かなり遅いグラフ アルゴリズムでも合格します。 すべての頂点にわたる DFS または BFS は、制限内では自明です。 さらに興味深いのは、いつ削除が必要かを正確に理解することです。 

すべての学生の学位が最大 2 であるという条件により、グラフの構造が大幅に制限されます。 すべての接続コンポーネントは次のいずれかです。 

- パス、
 - サイクル、
 - または孤立した頂点。 

パスは常に 2 部構成です。 偶数サイクルも 2 部構成です。 奇数サイクルは 2 部構成ではなく、1 つの頂点を削除するとそれがパスに変わります。 

微妙な特殊なケースの 1 つは、孤立した生徒です。 考慮する：```
3 0
```すべての学生は独立しているため、グラフは 2 部構成になります。 それでも、3 人の生徒を 2 つの同じチームに分けることはできません。 生徒の 1 人は欠席しなければならないので、答えは次のようになります。`1`。 

もう 1 つの簡単な間違いは、たとえその後残りの生徒の総数が偶数になったとしても、奇数サイクルごとに 1 回の除去が必要であることを忘れていることです。 

例：```
3 3
1 2
2 3
3 1
```これは三角形です。 グラフは 2 部構成ではありません。 1 人の生徒を削除すると、他の 2 人の生徒の間にエッジが残りますが、これは機能します。 正しい答えは、`1`。 

より微妙なケースでは、両方の問題が組み合わされています。```
6 3
1 2
2 3
3 1
```サイズ 3 の奇数サイクルが 1 つと、孤立した頂点が 3 つあります。 サイクルから 1 つの頂点を削除すると、合計 5 人の生徒が残りますが、それでも奇数です。 さらに 1 人の生徒も欠席しなければなりません。 正しい答えは、`2`。 

奇数サイクルのみをカウントする不注意な実装では、誤って出力されてしまいます。`1`。 

## アプローチ

 ブルートフォースアプローチでは、生徒のすべてのサブセットを削除しようとします。 各サブセットについて、残りのグラフが 2 部構成であるかどうか、および残りの生徒の数が偶数であるかどうかを確認します。 あるので`2^n`サブセットの場合、これはすぐに不可能になります。 たとえ`n = 100`、検索空間は天文学的に大きいです。 

グラフ構造により、より明確な方向性が得られます。 すべての頂点の次数は最大 2 であるため、接続されたコンポーネントは非常に単純になります。 唯一問題となる構造は奇数サイクルです。 

接続された 2 部コンポーネントは常に 2 色で着色できます。これは、その頂点を敵のない 2 つのグループに分けることができることを意味します。 奇数のサイクルでは、サイクル内を歩き回ると色付けに矛盾が生じるため、この特性が崩れます。 

したがって、問題は次の 2 つの観察に帰着します。 

まず、奇数サイクルごとに、正確に 1 つの除去が強制されます。 

次に、すべての奇数サイクルを修正した後、残りのグラフは 2 部構成になります。 残った生徒の数が奇数の場合は、任意の生徒をもう 1 人削除して合計を偶数にします。 

DFS カラーリングは奇数サイクルを自然に検出します。 隣接する頂点を反対の色で着色しようとして競合が見つかった場合、その接続されたコンポーネントは 2 部構成ではありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * (n + m)) | O(n + m) | 遅すぎる |
 | 最適 | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グラフの隣接リストを作成します。 

すべての生徒は、自分に関係する敵のリストを保存します。 
2. で初期化されたカラー配列を維持します。`-1`。 

A value of`-1`頂点がまだ訪問されていないことを意味します。 色`0`そして`1`2 つのチームを 2 つのカラーリングで表しています。 
3. すべての頂点を反復処理します。 

未訪問の頂点が見つかったら、そこから DFS を開始します。 
4. DFS 中に、隣接する頂点に交互の色を割り当てます。 

近隣が未訪問の場合は、反対の色を指定して DFS を続行します。 
5. 同じ色の 2 つの頂点を接続するエッジが見つかった場合、接続されたコンポーネントは 2 部構成ではありません。 

すべてのコンポーネントの最大次数は 2 であるため、これはコンポーネントに奇数のサイクルが含まれていることを意味します。 
6. 非 2 部構成要素ごとに、答えを 1 ずつ増やします。 

奇数サイクルから 1 人の生徒を削除すると、必ずサイクルが中断され、コンポーネントが 2 部グラフに変わります。 
7. すべてのコンポーネントを処理した後、残っている生徒の数を計算します。 

もし`n - answer`奇数の場合は、答えを 1 増やします。 

残りの生徒は同じ数の 2 つのチームに分割する必要があるため、その数は偶数でなければなりません。 
8. 最終的な答えを印刷します。 

### なぜ効果があるのか

 DFS カラーリングは、2 部グラフを正しく特徴付けます。 グラフは、2 色付け中に同じ色の頂点を接続するエッジがない場合に限り、2 部構成になります。 

ここでのすべての連結成分の次数は最大 2 であるため、可能な唯一の非二部構造は奇数サイクルです。 このようなサイクルから 1 つの頂点を削除すると、サイクルが破壊され、2 部構成のパスが残ります。 

すべての奇数サイクルを修正すると、グラフは 2 部構成になります。 任意の 2 部グラフは、敵のいない 2 つのグループに分割できます。 残る唯一の問題はパリティです。 残っている生徒の合計数が奇数の場合、均等なチームは不可能なので、さらに 1 人の生徒を削除する必要があります。 

各奇数サイクルには少なくとも 1 つの削除が必要であり、パリティにはさらに 1 つの削除が必要な場合があるため、アルゴリズムは可能な最小限の答えを生成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

adj = [[] for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * (n + 1)

def dfs(start):
    stack = [start]
    color[start] = 0

    while stack:
        u = stack.pop()

        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                stack.append(v)
            elif color[v] == color[u]:
                return False

    return True

removed = 0

for i in range(1, n + 1):
    if color[i] == -1:
        if not dfs(i):
            removed += 1

remaining = n - removed

if remaining % 2 == 1:
    removed += 1

print(removed)
```隣接リストはグラフをコンパクトに保存し、効率的な走査をサポートします。 以来`n`そして`m`が小さい場合は、再帰的 DFS または反復的 DFS が機能しますが、反復的 DFS では再帰の深さの問題が完全に回避されます。 

の`color`配列は、訪問状態と 2 部構成のカラーリングの両方を処理します。 未訪問の頂点はそのまま残ります`-1`。 走査中、隣接するものは常に、XOR を使用して反対の色を受け取ります。`1`。 

DFSが返す`False`対立点を見つけたらすぐに。 これにより、コンポーネントに奇数のサイクルが含まれていることがすぐに分かります。 

微妙な点の 1 つは、非 2 部コンポーネントごとに削除を 1 つだけカウントしていることです。 すべての頂点の次数は最大 2 であるため、連結成分には複数の独立した奇数サイクルを含めることはできません。 一般的なグラフでは、このショートカットは失敗します。 

パリティ調整は、すべての奇数サイクルが修正された後にのみ行われます。 奇数サイクルから頂点を削除すると、残っているスチューデントの総数が変わるため、後でパリティをチェックする必要があります。

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + m) | すべての頂点とエッジは DFS 中に 1 回処理されます。 
| スペース | O(n + m) | 隣接リストと色の配列 |

 このソリューションは、最大 100 個の頂点と 100 個のエッジを使用して、制限内で快適に実行されます。 はるかに遅いグラフ走査でも合格しますが、線形アプローチはクリーンかつ最適です。 

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n, m = map(int, input().split())

    adj = [[] for _ in range(n + 1)]

    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * (n + 1)

    def dfs(start):
        stack = [start]
        color[start] = 0

        while stack:
            u = stack.pop()

            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    stack.append(v)
                elif color[v] == color[u]:
                    return False

        return True

    removed = 0

    for i in range(1, n + 1):
        if color[i] == -1:
            if not dfs(i):
                removed += 1

    if (n - removed) % 2 == 1:
        removed += 1

    print(removed)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    return sys.stdout.getvalue().strip()

# provided sample
assert run(
"""5 4
1 2
2 4
5 3
1 4
"""
) == "1", "sample 1"

# minimum graph, already balanced
assert run(
"""2 0
"""
) == "0", "two isolated students"

# odd cycle
assert run(
"""3 3
1 2
2 3
3 1
"""
) == "1", "triangle requires one removal"

# odd cycle plus parity issue
assert run(
"""6 3
1 2
2 3
3 1
"""
) == "2", "triangle fixed but remaining count still odd"

# even cycle
assert run(
"""4 4
1 2
2 3
3 4
4 1
"""
) == "0", "even cycle is bipartite"

# isolated vertices causing parity problem
assert run(
"""5 0
"""
) == "1", "odd number of isolated students"

 ## 特殊なケース

 完全に切断された場合を考えてみましょう。```
3 0
```DFS は各頂点を個別に訪問し、色の競合を見つけることはありません。`removed = 0`グラフ処理後。 以来`3`学生は残りますが、パリティは奇数であるため、さらに 1 人の学生が削除されます。 アルゴリズムは出力します`1`。 

ここで、単一の三角形を考えてみましょう。```
3 3
1 2
2 3
3 1
```DFSカラー`1`と`0`、`2`と`1`、 そして`3`と`0`。 エッジを加工する場合`(3,1)`、両方のエンドポイントに色があります`0`、したがって、コンポーネントは非二部構成です。`removed`になる`1`。 残りの生徒数は同等`2`、すでに均等になっています。 最終的な答えは、`1`。 

最後に、複数のコンポーネントを検討します。```
8 5
1 2
2 3
3 1
4 5
6 7
```コンポーネント`{1,2,3}`は奇数サイクルなので、生徒を 1 人削除する必要があります。 コンポーネント`{4,5}`そして`{6,7}`二部構成であり、頂点である`8`孤立している。 1回取り外した後、`7`学生たちはまだ奇妙なままです。 アルゴリズムはさらに 1 人の生徒を削除し、出力します。`2`。 

これは、奇数サイクルの修正とパリティの修正という 2 つの独立した除去源を裏付けています。
