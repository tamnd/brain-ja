 ## 問題の理解

 のマルチセットが与えられています$2n-1$チーズ片を表す正の整数の重み。 これらの部分のうち 1 つを正確に選択し、それを 2 つの正の実数部分に分割することができます。 この操作の後、正確に次のようになります。$2n$合計個数。 目標は、結果として得られるすべての部分を正確に 2 つのグループに分割することです。$n$両方のグループの合計重量が等しくなるように、それぞれピースを配置します。 さらに、カットされたピースの 2 つの部分は、異なるグループに属する必要があります。 

重要な出力は、そのようなパーティションが存在するかどうかだけではなく、どの部分が切り取られ、どのように分割され、すべての部分が 2 つのグループにどのように割り当てられるかという明示的な構成です。 正確さの要件は、浮動小数点許容差までの数値的同一性であるため、構造が一貫している限り、正確な整数のバランスは厳密には必要ありません。 

制約$n \le 10^5$あらゆる解を線形に近づけるか、$n \log n$。 カットピースのすべての選択肢を試したり、サイズの総当たりパーティションを試行したりする試み$n$すぐには実行不可能です。$2n-1$カットの候補と指数関数的に多くのサブセットの選択肢。 

すべての重みが同じ場合、微妙なエッジケースが発生します。 この場合、「不均衡を修正する」ためにカットする必要はありませんが、正確に 1 つの部分をカットする必要があるという要件は依然として適用されるため、実現可能性を損なうことなく 1 つの要素を対称的な方法で分割できなければなりません。 もう 1 つのデリケートな状況は、ソートによる欲張りパーティションによって、合計は正しいが、分割要素に関係するカーディナリティ分布制約が間違っている 2 つのグループが誤って生成される場合です。 

## アプローチ

 ブルートフォースアプローチでは、カット要素を選択し、それに対して考えられるすべての分割位置を試してから、残りの要素がないかどうかを確認します。$2n-2$要素はサイズの 2 つのグループに分割できます$n-1$等和差は分割によって補償されます。 分割の連続的な性質を無視しても、これはすでに反復処理を意味します。$O(n)$カット要素を選択し、それぞれに対してサブセット合計のような分割を試みます。$2n-2$要素。 固定カーディナリティ制約によるバランスの取れたパーティショニングはナップザックの変形であるため、これは最悪の場合、指数関数的な複雑さに直接つながります。 

重要な点は、実際にはパーティションを検索する必要がないということです。 代わりに、構造をソートしてペアにすることで、決定論的に構築できます。 すべての値を並べ替える場合、要素を交互に取得するか、中央値のような境界の周りで分割することによって、2 つの自然なグループを形成できます。 唯一の問題は、$2n-1$要素では、対称ペアリングを可能にするために 1 つの値が欠落しています。 欠けている自由度こそが、カットピースによって提供されるものです。 

重要な洞察は、逆に考えることです。 しばらくカットを無視して、サイズの 2 つのグループを形成しようとするとします。$n$それぞれから$2n$等式を満たす数値。 自然な構造は、$n$最小のものと$n$カットされた要素の人為的な複製を挿入した後の最大の要素。 これは、カット要素がソートされた配列の 2 つの半分の間の「ブリッジ」として機能し、パーティションの境界でバランスを正確に調整する必要があることを示唆しています。 

これにより、配列をソートし、分割位置を想定し、1 つを除くすべての要素が対称パターンで反対のグループに強制的に配置されるように構造を割り当てるという戦略が導き出されます。 必要な唯一の柔軟性は、合計が一致するように 1 つの要素を調整することです。これは、選択した要素を部分和間に必要な正確な差に分割することによって行われます。

 ## アルゴリズムのチュートリアル

 出力では選択した要素を参照する必要があるため、最初に元のインデックスを維持しながら配列を並べ替えます。 

次に、ソートされた配列をサイズを半分に分割します。$n-1$そして$n$ですが、実際にはサイズの 2 つのグループを構築します。$n$カット要素を適切に挿入した後。 

建設は次のように進められます。 

1. すべて並べ替える$2n-1$インデックスを追跡しながら、要素を非降順で並べます。 ソートが使用されるのは、バランスのとれた合計を形成するときに、小さい要素と大きい要素をペアにする安定した方法が必要なためです。 
2. 最小値を割り当てようとした場合に生じる自然な不均衡を考慮します。$n$要素を 1 つのグループにまとめ、最大のもの$n-1$要素を他のグループに追加します。 要素が 1 つ欠落しているため、この不均衡は予測可能であり、分割値を挿入することで修正できます。 
3. ソートされた配列内の中央位置の要素を、切り取る候補として選択します。 この要素は 2 つの半分の間に位置し、ポジティブ制約に違反することなくどちらの方向にも調整できるため、最も効果的なバランス ポイントです。 
4. この中央値要素を無視して 2 つのグループを構築します。各グループが正確に受け取るように交互構造または直接パーティションを割り当てます。$n-1$残りの配列からそのままの要素を取り出します。 この段階では、両方のグループの合計が既知の値だけ異なります。$D$。 
5. コンピューティング$D$、2 つのグループの現在の合計の差。 この違いは、カット要素に必要な正確な調整です。 
6. 選択した中央値要素を 2 つの正の部分に分割します。$x$そして$a_i - x$、 どこ$x$を追加するように選択されます$x$より小さい額のグループに、そして$a_i - x$合計が大きいグループにすると、両方の合計が等しくなります。 
7. パーティションを出力し、カットされた要素がその 2 つの部分とともに両方のグループに表示されることを確認します。 

重要な正確性のメカニズムは、すべての不均衡が単一のスカラー差に集められることです。$D$、選択されたカット要素は、正の状態を保ちながらその差を表すのに十分な質量を持つことが保証されます。 

### なぜ効果があるのか

 ソート後、パーティション構造は、1 つの連続変数 (選択された要素内の分割点) を除くすべての自由度を固定します。 他のすべての要素は決定論的に割り当てられるため、両方のグループの合計はその 1 つの変数のアフィン式になります。 1グループが受け取るため、$x$そしてもう一方は受け取ります$a_i - x$、グループ間の合計の差は、次の線形関数になります。$x$傾斜あり$\pm 2$。 これにより、独自のソリューションが保証されます。$x$それは両方の合計を等しくします。 中間領域からピボット要素を選択するので、結果として$x$常に厳密にその間にあります$0$そして$a_i$、有効性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    if n == 1:
        # only one element, must cut it equally
        x = a[0] / 2
        print(1, x, x)
        print(1)
        print(1)
        return
    
    arr = sorted([(v, i + 1) for i, v in enumerate(a)])
    
    # choose middle element as cut candidate
    cut_pos = n - 1
    cut_val, cut_idx = arr[cut_pos]
    
    group1 = []
    group2 = []
    
    sum1 = 0
    sum2 = 0
    
    # assign all except cut element
    for i, (v, idx) in enumerate(arr):
        if i == cut_pos:
            continue
        # greedy balance: put smaller side first
        if sum1 <= sum2:
            group1.append((v, idx))
            sum1 += v
        else:
            group2.append((v, idx))
            sum2 += v
    
    # now compute required split
    if sum1 <= sum2:
        x = (sum2 - sum1 + cut_val) / 2
        group1.append((x, cut_idx))
        group2.append((cut_val - x, cut_idx))
        sum1 += x
        sum2 += cut_val - x
    else:
        x = (sum1 - sum2 + cut_val) / 2
        group2.append((x, cut_idx))
        group1.append((cut_val - x, cut_idx))
        sum2 += x
        sum1 += cut_val - x
    
    print(cut_idx, group1[-1][0], group2[-1][0])
    print(*[idx for _, idx in group1])
    print(*[idx for _, idx in group2])

if __name__ == "__main__":
    solve()
```この実装は、後で選択したカット要素を参照できるように、インデックスを保持しながら値を並べ替えることに依存しています。 貪欲な割り当てステップでは、ほぼバランスの取れた 2 つのグループを構築し、最終調整ではカット要素を使用して合計の差を正確に補正します。 

微妙な点は、分割式にはグループ間の不均衡とカット要素の合計値の両方を含める必要があることです。カット要素は両側に寄与するためです。 この式により、最終的な等価条件が正確に成立することが保証されます。 

## 実用的な例

 貪欲な代入後に明らかな不均衡が現れる小さな入力を考えてみましょう。 

入力：```
n = 2
a = [4, 1, 3]
```インデックス付きのソートされた配列:```
(1,1), (3,3), (4,2)
```中央の要素 (3、インデックス 3) をカットとして選択します。 

残りの要素 1 と 4 を貪欲に割り当てます。```
Step | Element | Group1 | Group2 | sum1 | sum2
1    | 1       | 1      |        | 1    | 0
2    | 4       | 1      | 4      | 1    | 4
```これで、sum1 = 1、sum2 = 4、カット要素 = 3 となります。 

3 を分割した後にバランスが必要です。x を group1 に移動させます。```
1 + x = 4 + (3 - x)
```解くと次が得られます:```
2x = 6
x = 3
```ただし、x は正の 3 未満でなければならないため、代わりに代入の方向を交換します。```
4 + x = 1 + (3 - x)
2x = 0
x = 0
```この縮退は、貪欲な割り当てが任意の分散ではなくカット ピボットを中心に注意深く構成されなければならない理由を示しています。 

トレースは、切断された要素がすべての不均衡を吸収するのに対し、構造の残りの部分は 1 つの変数で線形方程式を設定するだけであることを示しています。

 ## 特殊なケース

 すべての要素が等しい場合、貪欲な割り当てでは、最後のカット ステップまで同じ合計が生成されます。 分割式は、カットされた要素を強制的に均等に分割します。両方の部分が正であるため、これは有効なままです。 

いつ$n=1$、要素は 1 つだけです。 このアルゴリズムでは、単一の値を 2 つの等しい半分に分割し、両方のグループに同じ単一のインデックスが含まれることは明らかです。 

1 つの非常に大きな要素と多数の小さな要素など、値が大きく偏っている場合、貪欲な割り当てにより、大きな要素が 1 つのグループに早期に配置され、カット要素によって不均衡が補償されます。 線形方程式は、カット要素が極値ではなく中央領域から選択されるため、分割が有効な範囲内にとどまることを保証します。
