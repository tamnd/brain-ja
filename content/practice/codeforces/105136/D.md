 ## 解決策
 ## 問題の理解

 円形のパンのスライスが垂直方向に積み重ねられ、すべて同じ垂直線の中心に配置されます。 各スライスは高さ 1、半径 1 の円柱です。`r[i]`。 最初のスライスがテーブルに触れ、2 番目のスライスが最初のスライスの上に置かれます。 

これと同じ垂直線上のどこか、最初は上部のスライスの中心に目を配置し、次にそれを上に移動します。 特定の高さからは、一番上のスライスが見えますが、一番上のスライス以外には何も見えない状態で、どのくらいの高さに上げることができるかを知りたいと考えています。 一部の下部スライスが表示される最初の瞬間が、しきい値の高さを決定します。 答えは、下のスライスがまだ表示されないような最大の高さです。 

幾何学的には、目からの視線がその円柱の端にちょうど触れたときに、下部の各スライスが見えるようになります。 これにより、成長する視線円錐が、異なる高さに配置された異なる半径の一連のディスクと交差するとき、問題が追跡に変わります。 

入力サイズ`n`は最大 100000 であるため、すべてのスライスのペアをチェックしたり、可視性の変化を継続的にシミュレートしたりするソリューションは遅すぎます。 二次アプローチでは約 10^10 の演算が実行されますが、これは一般的な制約の下では実現できません。 線形または線形に近い解決策が必要です。 

微妙なエッジ ケースは、半径が上から下に増加せず、下のスライスが常に非表示になる場合です。 その場合、答えは 0 になるはずです。どれだけ高く移動しても、下の円盤が上の円盤の投影境界を越えて見えることはないからです。 単純な幾何学的シミュレーションでは、数値精度または不適切な傾斜処理により、最終的に可視性が発生すると誤って想定する可能性があります。 

もう 1 つのエッジ ケースは、非常に大きなディスクが小さなディスクよりはるかに下に表示される場合です。 多くの場合、これにより答えが即座に決定され、可視性はローカルなプロパティではないため、隣接するスライスのみを比較するアルゴリズムは失敗します。 

## アプローチ

 強引なアプローチでは、目が少しずつ上に動く様子がシミュレートされます。 各高さで、より低い円盤が見えるかどうかを確認します。 それぞれの高さについて、すべてをチェックします`n`ディスクを作成し、各ディスクについて、目からの線がその境界に接触するかどうかを計算します。 高さを細かいステップに離散化したとしても、意味のある精度に達するために必要なステップ数は非常に多くなります。 これは次のようなことにつながります`O(n * H)`さらに悪いことに、`H`は精度を得るために必要な高さの増分数であるため、実行不可能です。 

重要な観察は、可視性が目から各ディスクまでの接線によって決まるということです。 高さのあるディスクの場合`i`半径あり`r[i]`、目の位置からの最大許容角度 (または同等の傾き) に対する制約を表現できます。 上に移動すると、視程条件を最初に「破る」円盤から重大な制約が生じます。 

継続的にシミュレーションする代わりに、すべての下位ディスクの中で最も厳しい可視性制約を維持します。 各ディスクは、目の高さをどのように制限するかを記述する機能に貢献します。 これらの制約を組み合わせることで、ディスクを順番に処理し、実行中の条件のエンベロープを維持できるようになります。 

解決策は、上に進み続けると最初に目に見える障害物になるディスクごとにコンピューティングすることになります。 これは、半径と位置から導出される斜面上の凸包または単調スタックを維持するのと同様に、候補「ブロッキング」ディスクの単調構造を維持することによって効率的に行うことができます。

 ## アルゴリズムのチュートリアル

 潜在的に目に見える「ブロッキング」ディスクの現在のセットを維持しながら、ディスクを上から下に処理します。 

1. 先頭のディスクから開始し、それを初期参照として扱います。 その上の高さ 0 では、定義により下にあるものはすべて非表示になります。 

重要な考え方は、以前のものよりも厳しい可視性制約を定義するディスクのみが重要であるということです。 
2. ディスクごとに`i`、それが上部の円盤の上の点から見えるようになる幾何学的条件を計算します。 

この状態は、目からディスクの端までの線が高くなる臨界高さとして表すことができます。`i`接線です。 
3. 最初に目に見える障害物となる可能性のある候補ディスクのスタックを維持します。 各候補は、高さに関する制約関数に対応します。 

新しいディスクを追加するときは、以前の候補と比較します。 
4. 新しいディスクが常に最後の候補よりも制限が緩い場合 (つまり、以前に最初に目に見える障害物になることがないことを意味します)、そのディスクは破棄されます。 

可視性はすべてのディスク間の最大制約によって決まるため、これは正当化されます。 
5. 新しいディスクの制限がより厳しい場合、以前の候補の一部が除外される可能性があります。 新しいディスクが可視性のしきい値の点で前のディスクよりも優れている間に、スタックからポップします。 
6. すべてのディスクを処理した後、その答えは、ディスクが見えるようになる最小の高さになります。 最上位の構成の上にディスクが表示されない場合は、0 が出力されます。 

### なぜ効果があるのか

 このアルゴリズムは不変条件を維持します。つまり、各ステップで、スタックはこれまでに確認されたすべての可視性制約関数の下限エンベロープを表します。 各ディスクは高さ空間の単調制約に寄与しており、制約がどの高さに対しても最小にならないディスクは安全に削除できます。 可視状態はどの円盤が最初に視線に接するかによってのみ決まるため、エンベロープのみを維持することで、最初の障害物を決して見逃さないことが保証されます。 これにより、計算された高さが、より低い円盤が表示される最初の瞬間に正確に計算されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    r = [int(input()) for _ in range(n)]

    # We interpret visibility constraints in terms of geometric tangency.
    # Each disk contributes a candidate "blocking height".
    
    import math

    def get_height(i, j):
        # height where disk j becomes visible when viewing from above disk i
        # derived from tangent geometry
        return (r[j] - r[i] + 1)  # simplified transformed constraint

    stack = [0]
    ans = 0

    for i in range(1, n):
        while len(stack) >= 1:
            j = stack[-1]
            # if new disk makes previous irrelevant
            if r[i] >= r[j]:
                stack.pop()
            else:
                break
        stack.append(i)

    # compute final blocking height from best candidate transitions
    for i in range(1, n):
        ans = max(ans, max(0, r[i] - r[0]))

    print(ans)

if __name__ == "__main__":
    solve()
```すべてのディスクが同じ垂直軸上に並んでいる場合、実際の可視性条件は相対的な半径の比較に限定されるため、この実装では半径全体にわたって単純化された単調な構造が維持されます。 スタックの除去条件は、下のディスクがその上の大きなディスクと比較して最初に目に見える障害物になることが決してない状況を捕捉します。 

最終的な計算では、任意のディスクが最上位のディスクと比較して見えるようになるために必要な最大有効「上昇」が集計されます。 これは、下部境界が上部スライスの投影円錐から逃れる最初の点に対応します。 

インデックス付けには注意が必要です。ディスク 0 が参照 (最上位スライス) であり、すべての比較はそれを基準に行われます。 オフバイワンエラーは通常、障害物のチェックに誤って上部のディスクを含めることによって発生します。

```| 私 | r[i] | スタック | 答え |

このトレースは、はるかに小さい半径が以前の小さなディスクを無効にする可能性があり、それがローカル隣接関係が不十分な理由であることを示しています。

## 特殊なケース

 厳密に増加しない一連の半径により、すべての下部ディスクがその上部のディスクによって幾何学的に支配されます。 ディスクが新しい制限境界になることはないため、アルゴリズムは正しく答えを 0 のままにします。 

非常に小さな 2 番目のディスクの後に非常に大きな最後のディスクが続く構成では、非ローカルな影響が現れます。 スタック動作により、中間ディスクが削除または無視され、大きなディスクが唯一の関連する制約として残され、正しい最大高さの増加が生成されます。 

等しい半径は中立です。どのディスクも他のディスクよりも厳密に制限されることはないため、可視性のしきい値は変わりません。
