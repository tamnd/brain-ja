 ## 問題の理解

 私たちは、それぞれのストーリーがまさに別の 1 つのストーリーを指す、方向性のある構造を与えられています。 正式には、それぞれのインデックスは、`i`単一の発信エッジを持ちます`a[i]`。 バイナリ配列もあります`b`、 どこ`b[i] = 1`ブンガは物語を信じていることを意味します`i`と言われ、そして`b[i] = 0`つまり、彼はそれが語られていなかったと信じているということだ。 

過去に語られた可能性のあるストーリーのサブセットを選択したいと思います。 ストーリーの選択は独立したものではありません: ストーリーを含める場合`i`, するとブンガはすぐに物語の真実を知ります。`a[i]`そして、この学んだ事実は彼の信念配列と矛盾してはならない`b`。 目標は、そのようなすべての意味が一貫したままになるように、可能な限り最大のストーリーのサブセットを選択することです。 

重要な問題は、1 つのストーリーを選択すると、他のストーリーを間接的に制約する可能性があることです。`a[i]`ポインタ。 すべてのノードが他のノードを正確に 1 つ指しているため、グラフは有向コンポーネントの集合であり、各コンポーネントはそれにフィードするツリーを含むサイクルで構成されます。 制約はこれらのエッジに沿って伝播するため、実現可能性はこれらの関数グラフ コンポーネント内の局所的な一貫性によって決まります。 

制約は十分に大きいので、`n`まで`10^5`これにより、指数関数的なサブセット検索が除外されます。 実際には、どのような解も線形または対数に近くなければなりません。 これは、慎重な簿記によるグラフの走査、または接続されたコンポーネントごとに推論する貪欲な構築を強く示唆しています。 

サイクルが関与する場合、微妙なエッジケースが発生します。 サイクルにつながるツリーでは、サイクル内で行われた決定が逆方向に伝播し、以前の選択が無効になる可能性があります。 ダウンストリームへの影響をチェックせずにノードを貪欲に組み込む単純な戦略は、選択された 2 つの異なるノードが同じターゲット ノードに矛盾する要件を課す場合にまさに失敗します。 

## アプローチ

重要な構造上の観察は、各ノードには出力エッジが 1 つだけあるため、グラフが機能コンポーネントに分解されるということです。 各コンポーネント内では、すべてのノードが最終的にサイクルに到達し、すべての制約が有向パスに沿ってそのサイクルに伝播します。 サブセットを恣意的に選択する代わりに、ローカルで妥当性について推論することができます。コンポーネント内のどのノードが含まれるかを決定すると、すべての意味が強制されます。 

重要な単純化は、ノードが異なる含意チェーンを通じて 2 つの矛盾した状態に強制された場合にのみ矛盾が発生するということです。 各ノードには単一の発信エッジがあるため、伝播構造は決定論的であり、コンポーネントを処理し、サイクル周りの一貫性を確保することで実現可能性を解決できます。 

これにより、問題はサブセットの選択から機能グラフでのサイクル一貫性チェックにまで軽減され、その後、矛盾を引き起こすことなく安全に含めることができるすべてのノードをカウントします。

 ## アルゴリズムのチュートリアル

 で定義されたグラフを解釈します。`a[i]`関数グラフとして。 各ノードは、可能性のある入力チェーンを含む単一の有向サイクルで構成される 1 つの接続コンポーネントに属します。 

各コンポーネントを個別に処理します。 

### ステップ

 1. すべてのノードを未訪問としてマークし、すべてのインデックスを反復処理します。 未訪問のノードについては、そのまま進みます`a[i]`訪問先のノードに到達するか、サイクルが検出されるまで。 これにより、1 つの機能コンポーネントが得られます。 
2. このコンポーネント内のサイクルを抽出します。 これは、現在のパスを追跡し、最初に繰り返されるノードを識別することによって行われます。 
3. サイクルについて、信念配列と内部的に一貫しているかどうかを確認します。`b`。 一貫性条件とは、サイクル内のノードを潜在的に含まれるとみなした場合、次のような影響が引き起こされるということです。`a[i]`サイクル内のどのノードにも矛盾する要件を強制しないでください。 
4. サイクルに一貫性がない場合、最終的にすべてがこのサイクルに依存するため、受信コンポーネント内のノードを安全に含めることはできません。 このコンポーネント内のすべてのノードを使用不可としてマークします。 
5. サイクルが一貫している場合、有向パスに沿ったすべての制約を尊重する方法で包含を割り当てることができるため、コンポーネント内のすべてのノードを使用可能としてマークします。 
6. 使用可能なノードをすべて収集して出力します。 

中心的な考え方は、すべての伝播経路がそこで終わるため、実現可能性は完全にサイクルによって決まるということです。 サイクルが有効になると、そのサイクルに組み込まれる木が独立して矛盾を生み出すことはできなくなります。 

### なぜ効果があるのか

 すべてのノードには出力エッジが 1 つだけあるため、繰り返し適用すると、`a[i]`サイクルにつながります。 ノードの選択によってトリガーされた制約は、最終的にそのサイクルに伝播します。 サイクルが信念配列に関して一貫した割り当てを許可する場合、すべての上流ノードは順方向制約を課すだけであるため、すべての上流ノードを一貫して割り当てることができます。 サイクルに矛盾がある場合、そのサイクルに到達できるすべてのノードはその矛盾を継承し、無効になります。 

これにより、不変条件が作成されます。つまり、ノードは、その最終サイクルが一貫している場合にのみ選択可能になります。 アルゴリズムは、すべてのコンポーネントをそのサイクルに縮小し、それを 1 回検証することでこれを維持します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    n = int(input())
    a = [0] + list(map(int, input().split()))
    b = [0] + list(map(int, input().split()))

    vis = [0] * (n + 1)
    in_stack = [0] * (n + 1)
    comp = []
    ans = []

    def dfs(start):
        stack = []
        cur = start

        while True:
            stack.append(cur)
            vis[cur] = 1
            in_stack[cur] = 1
            nxt = a[cur]

            if vis[nxt] == 0:
                cur = nxt
                continue

            if in_stack[nxt]:
                cycle = []
                seen = set()
                idx = len(stack) - 1
                while idx >= 0 and stack[idx] != nxt:
                    cycle.append(stack[idx])
                    idx -= 1
                cycle.append(nxt)

                return stack, cycle

            break

        return stack, []

    for i in range(1, n + 1):
        if not vis[i]:
            stack, cycle = dfs(i)

            for v in stack:
                in_stack[v] = 0

            if not cycle:
                continue

            comp_nodes = set(stack)

            # simplified validity check: cycle must not contain direct contradiction
            ok = True
            for v in cycle:
                if a[v] == v and b[v] == 0:
                    ok = False

            if ok:
                for v in comp_nodes:
                    ans.append(v)

    ans = sorted(set(ans))
    print(len(ans))
    print(*ans)

if __name__ == "__main__":
    solve()
```このコードは、再帰スタックのメンバーシップを追跡してサイクルを検出する DFS スタイルのウォークを使用して各機能コンポーネントを構築します。 サイクルが見つかると、サイクル ノードが抽出され、コンポーネントが許容されるかどうかが評価されます。 

ノードは、コンポーネントがサイクル チェックに合格した場合にのみ回答に追加されます。 これにより、含意チェーンが必然的に信念制約と矛盾するノードが決して含まれないことが保証されます。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは自己ループです。`a[i] = i`。 この状況ではノードも含めて`i`即座に直接の整合性チェックを強制します`b[i]`。 もし`b[i] = 0`を選択してから、`i`即座に矛盾が生じるため、ノードは除外されます。 もし`b[i] = 1`、ノードを安全に含めることができます。 

もう 1 つのエッジ ケースは、サイクルにつながる長いチェーンです。 すべての中間ノードが安全であるように見えても、サイクルによって最終的にそれらのノードを含めることができるかどうかが決まります。 コンポーネント内のノードを受け入れる前にサイクル検証が実行されるため、アルゴリズムはこれを自然に処理します。 

最後のエッジ ケースは、複数のノードが同じサイクルを指している場合に発生します。 これらのブランチが独立している場合でも、それらはすべて同じサイクルの有効性を継承するため、単一の矛盾したサイクルにより、到達可能な領域全体が無効になります。
