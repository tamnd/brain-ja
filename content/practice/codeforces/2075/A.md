 ## 問題の理解

 数を減らすよう求められています`n`パリティによって制約された一連の減算を使用してゼロにします。 各演算では、次の間の任意の数値を減算できます。`1`そして`k`、しかし、現在の場合`n`が偶数の場合は、偶数を減算する必要があります。`n`が奇数である場合は、奇数を減算する必要があります。 目標は、これを最小限の操作で実行することです。 入力は複数のテスト ケースを提供し、それぞれが指定します`n`そして奇妙な`k`(少なくとも 3 つ)。 各テスト ケースの出力は、ゼロに達するまでの最小操作数です。 

重要な制約は、`n`と同じ大きさにすることができます`10^9`まであります`10^4`テストケース。 これにより、すべての減算を素朴に試行するソリューションは除外されます。`n`テストケースごとの操作は約`10^13`合計操作量は 2 秒で実行可能なものをはるかに超えています。 テスト ケースごとに定数時間または対数時間で結果を計算するソリューションが必要です。 

次の場合、微妙なエッジケースが発生します。`n`よりも小さいです`k`。 以来`k`は奇数です、常に引き算できるわけではありません`k`特にパリティが一致しない場合は、直接。 たとえば、次の場合`n = 2`そして`k = 3`、引き算はできません`3`より大きいので`n`ただし、偶数 (2 そのもの) も減算する必要があるため、解では正しく選択する必要があります。`2`。 同様に、`n = 1`そして`k = 3`、引き算できます`1`すぐに。 常に引き算をしようとする不用意なアプローチ`k`最初はこれらの小さな値では失敗します。 

## アプローチ

 ブルートフォースアプローチは簡単です。`n > 0`、有効な最大の数値を繰り返し選択します`x`(パリティを尊重し、`1 <= x <= k`）からそれを引きます`n`。 操作をカウントします。 これが機能するのは、各ステップで削減するためです。`n`が遅すぎるときは、`n`各減算が個別の演算になる可能性があるため、この値は大きくなり、最大で`n`テストケースごとの反復回数。 

最適なソリューションを見つけるための重要な洞察は、パリティ構造を考慮することです。 以来`k`が奇数の場合、奇数の減算が常に利用可能であり、偶数の減算が常に少なくとも少なくとも利用可能であることが保証されます。`2`。 この場合、問題は 2 つのケースに集約されます。`n`が奇数の場合、常に最大の奇数を減算できます。`k`そして減らす`n`素早く。 もし`n`が偶数である場合、最大の偶数減算は次のいずれかです。`k-1`（もし`k > 1`） または`2`。 一般に、操作の数は次のように計算できます。`ceil(n / k)`いつ`n`奇数です、そして`n / 2`いつ`n`均等であり、`k`十分な大きさです。 単純化すると、最小限の操作は次のとおりです。 

- もし`n`奇数です:`(n + k - 1) // k`- もし`n`偶数です:`n // 2`もし`k > 1`このテスト ケースごとの一定時間の計算により、すべての減算を繰り返す必要がなくなります。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして`k`。 
3. もし`n`2で割り切れる場合は計算してください`n // 2`操作の数として。 その推論は、最小の偶数は次のとおりです。`2`、そして減算`2`繰り返してゼロに達します`n / 2`ステップ。 以来`k >= 3`、いつでも減算できます`2`。 
4. もし`n`奇数です、計算してください`(n + k - 1) // k`。 これは天井に相当します`n / k`なぜなら、引き算できる最大の奇数は`k`。 減算するたびに減少します`n`奇数パリティ制約を尊重しながら効率的に実行できます。 
5. 各テスト ケースの結果を出力します。 

これが機能する理由: 不変条件は、各減算が次のパリティを尊重することです。`n`。 常に正しいパリティを使用して最大許容数を減算することで、操作の総数を最小限に抑えます。 ケースはあらゆる可能性をカバーします`n`偶数は引き算で常に半分になるからです`2`奇数は常に最大の奇数減算を使用して効率的に減らすことができます。`k`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    if n % 2 == 0:
        print(n // 2)
    else:
        print((n + k - 1) // k)
```このソリューションは、まずテスト ケースの数を読み取り、次にテスト ケースの各ペアを処理します。`n`そして`k`。 との同等性をチェックします`n % 2`。 偶数の場合`n`、減算`2`最小限の動作を繰り返し保証するため、`n // 2`答えを出します。 奇数の場合`n`、天井分割を使用します`(n + k - 1) // k`可能な最大の奇数減算を使用して最小限の演算を決定します。 off-by-one エラーを避けるために、整数の除算を正しく実行するように注意してください。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        if n % 2 == 0:
            print(n // 2)
        else:
            print((n + k - 1) // k)
    return output.getvalue().strip()
