 ## 解決策
 ## 問題の理解

 フェンスをペイントする方法の数を数えるように求められます。`n`正確に 2 色を使用して連続した板を使用し、各色が連続したブロックで使用され、各塗料の入手可能な数量が制限されています。 入力は板の数を提供します`n`、ペイントの色の数`m`、および配列`a`どこ`a[i]`色で塗装できる板の数を示します`i`。 テスト ケースごとに、フェンスに沿った個別の有効な色の配置の数を出力する必要があります。 

この制約では、各色の板の連続したブロックを考慮する必要があります。 これは重要です。連続性を維持せずに、これを単なる組み合わせ選択として処理しようとすると、無効な構成が過剰にカウントされてしまいます。 もう 1 つの微妙な点は、色の順序が重要であることです。`[color1 block][color2 block]`とは異なります`[color2 block][color1 block]`。 各カラー ブロックの長さは少なくとも 1 である必要があり、その色の利用可能な数量を超えることはできません。 

と`n`そして`m`潜在的に到達する`2·10^5`そして最大まで`10^4`テスト ケースでは、すべてのパーティションとすべての色のペアを反復する単純な総当たりアプローチでは、遅すぎます。 すべての配置を明示的に列挙することなく、実現可能なブロック長を効率的にカウントする戦略が必要です。 エッジケースとしては、一部の色で使用できる板が 1 つだけである場合、`n`等しい`2`、または 2 つの色の組み合わせが合計にならない場合`n`個人の制限に違反することなく。 

## アプローチ

 ブルートフォースアプローチでは、異なる色のすべてのペアを考慮し、考えられるすべての分割を反復処理します。`n`2 つの色の間の板。 これは正しいですが、非効率的です: 各色のペアに対して`(i,j)`まであります。`n-1`板をそれらの間で分割し、O(m²・n) の複雑さを与える方法。 最大境界の場合、これはおおよそ次のとおりです`4·10^15`実行不可能な操作。 

重要な洞察は、分割問題を分析的に処理できるということです。 異なる色のペアごとに、有効な配置の数は整数の数と同じになります。`x`そのような`1 ≤ x ≤ min(a[i], n-1)`そして`1 ≤ n - x ≤ a[j]`。 これは最小値と最大値を使用して直接計算でき、テスト ケースごとに O(m²) の時間を与えます。 合計から`m`すべてのテスト ケースの境界は次のとおりです`2·10^5`、これは許容範囲です。 

その戦略は、順序のない個別の色のすべてのペアを反復処理し、利用可能な数量に基づいて有効な分割の範囲を計算し、有効な分割の数を合計することです。 これにより、個々の取り決めの不必要な列挙が回避され、制約が直接利用されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(m²・n) | お(1) | 遅すぎる |
 | 最適 | O(㎡) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして`m`、配列を読み取ります`a`長さの`m`。 
3. カウンタを初期化する`count`ゼロに。 
4. 順序のない個別の色のすべてのペアを反復処理します。`(i,j)`。 各ペアについて:

 1. 最初の色のブロックの可能な最小および最大長を計算します。`min_len = max(1, n - a[j])`、`max_len = min(a[i], n - 1)`。 
2. もし`min_len > max_len`、このペアには有効な分割はありません。 
3. それ以外の場合、このペアの有効な配置の数は次のようになります。`max_len - min_len + 1`。 これを追加`count`。 
5. 出力`count`現在のテストケースの場合。 

なぜ機能するのか: 維持される不変条件は、各ペアが`(i,j)`は、両方の色の最大量を尊重し、ブロックごとに少なくとも 1 つの板を維持する有効な分割のみを考慮します。 すべてのペアを合計すると、フェンスをペイントする可能なすべての個別の方法がカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        count = 0
        for i in range(m):
            for j in range(i + 1, m):
                min_len = max(1, n - a[j])
                max_len = min(a[i], n - 1)
                if min_len <= max_len:
                    count += max_len - min_len + 1
                # also consider the symmetric case: first block color j, second block color i
                min_len_rev = max(1, n - a[i])
                max_len_rev = min(a[j], n - 1)
                if min_len_rev <= max_len_rev:
                    count += max_len_rev - min_len_rev + 1
        print(count)
```このソリューションは、色の各ペアの有効なシーケンスの数を正確に計算します。 対称性を明示的に処理し、両方の色の順序が確実にカウントされるようにします。 最小値と最大値の計算により、各ブロックに少なくとも 1 つの厚板があり、使用可能なペイント量を超えないことが保証されます。

 ## 特殊なケース

 - **最小フェンス:** n=2。 両方のブロックは正確に長さ 1 である必要があります。アルゴリズムは両方の色の順序を正しくカウントします。 
- **単一で十分なペイント:** 色は n に等しい。 アルゴリズムは、他のブロックに少なくとも 1 枚の板を配置できないような不可能な分割を正確に除外します。 
- **対称容量:** アルゴリズムは両方の色の順序を明示的にカウントし、過少カウントを防ぎます。
