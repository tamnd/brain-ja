 ## 解決策
 ## 問題の理解

 整数座標を持つ 2 次元平面上の一連の点が与えられます。 同じ x 座標を共有しない点のペアごとに、次の形式の放物線を一意に定義できます。$y = x^2 + bx + c$両方の点を通過します。 この問題では、これらの放物線のうち「空」の放物線がいくつあるかを数えるよう求められます。これは、放物線の厳密に上に他の入力点が存在しないことを意味します。 概念的には、上に開いた放物線の場合、「内部領域」は曲線の上のすべてです。 放物線は、他のすべての点がその上または下にある場合に数えられます。 

制約は大きいです:$n$到達できる$10^5$、座標は次のように大きくできます。$10^6$。 すべての点のペアをチェックし、放物線に対して他のすべての点を検証する総当り的なアプローチでは、$O(n^3)$最悪の場合の運用。 これは 1 秒の制限時間内では明らかに不可能です。つまり、次のような解決策が必要です。$O(n \log n)$または$O(n^2)$最悪の場合でも、余分な計算を避けるために慎重に処理する必要があります。 

単純な実装でつまずく可能性のあるエッジ ケースには、複数の点が同じ X 座標、垂直対称、または最小限の入力を共有するセットが含まれます。 例えばポイントの場合$(0,0)$そして$(1,1)$不注意な実装では、x が同じで y が異なる点を無効なペアと誤ってみなしたり、内部領域の計算を誤ったりする可能性があります。 すべての点がまっすぐ上に開く放物線上にある場合、有効な空の放物線を定義できるのは「エッジ」だけです。 

## アプローチ

 ブルートフォースアプローチは概念的には単純です。 ポイントのペアごとに$(x_1, y_1)$そして$(x_2, y_2)$と$x_1 \neq x_2$、係数を計算します$b$そして$c$そのような$y = x^2 + bx + c$両方の点を通過します。 次に、他のすべての点を繰り返して、放物線の上に厳密に存在する点があるかどうかを確認し、存在しない場合のみカウントします。 このアプローチは、すべての放物線候補を徹底的にチェックするため、正しいです。 ただし、$n \approx 10^5$、これは$O(n^3)$、それは周りにあります$10^{15}$実行可能性をはるかに超えた操作。 

最適化するための重要な洞察は、x 座標によるポイントのソートから得られます。 点が x でソートされたら、点の「包絡線」、つまりプロット時に上部の凸状チェーンのみを考慮する必要があります。$y - x^2$に対して$x$。 2 つの点で定義される U 字型の放物線の場合、x 軸上のそれらの間のすべての点が、変換された点を結ぶ線分上または下にある場合に限り、その放物線は空になります。$(x_i, y_i - x_i^2)$。 これにより、問題は、この変換された空間内で上部凸包のエッジを定義する点のペアが何組あるかを見つけることに帰着します。 変換された空間で最大値を維持することで、空間の空虚さを確認できます。$O(1)$候補ペアごとに、全体の複雑さを軽減します。$O(n \log n)$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n) | 遅すぎる |
 | 凸包 / 変換 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての点を変換します$(x_i, y_i)$の中へ$(x_i, y_i - x_i^2)$。 これにより放物線が線形化されます。$y = x^2 + bx + c$直線になる$y' = bx + c$変換された座標で。 
2. x 座標を増やして点を並べ替えます。 これにより、放物線の候補を左から右に検討することができ、「内部領域のチェック」で 2 つの端点間の点を調べることだけが必要になることが保証されます。 
3. 変換された点の上凸包を構築します。 他の凸包点と線分を形成する場合、凸包上の点の上に別の点を置くことはできません。 したがって、放物線は、その定義点が上部凸包上の連続した点である場合にのみ空になります。 
4. 上部凸包上の連続する点のペアをすべて数えます。 このような各ペアは、元の空間内で 2 つの点を通過し、その上に他の点がない U 字型の放物線を定義します。 
5. 同じプロセスを右から左に繰り返して、他の方向に空の放物線が含まれる可能性があることを考慮します。 有効な放物線の総数は、両方向からのカウントの合計です。 

機能する理由: 座標を変換し、問題を上部の凸包に帰着させることにより、候補となる線分が厳密に上に点のない放物線に対応することが保証されます。 凸包は、x 座標間のすべての最大 y 値をキャプチャするため、セグメントの上の内部点があると、その放物線がカウントされなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def count_empty_parabolas(points):
    # Transform points
    trans = [(x, y - x * x) for x, y in points]
    trans.sort()  # sort by x

    def upper_convex_hull_count(pts):
        hull = []
        count = 0
        for x, y in pts:
            while len(hull) >= 2:
                (x1, y1), (x2, y2) = hull[-2], hull[-1]
                # check if new point makes a right turn
                if (y2 - y1) * (x - x2) >= (y - y2) * (x2 - x1):
                    hull.pop()
                else:
                    break
            hull.append((x, y))
        # each consecutive pair is an empty parabola
        return len(hull) - 1

    return upper_convex_hull_count(trans) + upper_convex_hull_count(trans[::-1])

def main():
    n = int(input())
    points = [tuple(map(int, input().split())) for _ in range(n)]
    print(count_empty_parabolas(points))

if __name__ == "__main__":
    main()
```変革$y' = y - x^2$放物線を線形化し、凸包テクニックを可能にします。 ソートにより、連続したポイントが内部ポイントのチェックに適していることが保証されます。 右折チェックでは、クロス積ロジックを使用して上部船体を維持します。 連続するハルの各ペアは、有効な空の放物線を定義します。
