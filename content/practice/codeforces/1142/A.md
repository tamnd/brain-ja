 ## 問題の理解

 を通る循環ルートが与えられました。$n \cdot k$連続して配置された都市。 その中には、$n$連続する 2 つのレストランの間の円に沿った距離が次のように等間隔に配置されたファーストフード レストラン$k$キロメートル。 セルゲイは未知の都市から出発する$s$円に沿って一方向に移動し、毎回停止します。$l$キロメートル、最終的にはに戻ります$s$。 彼は出発都市から最も近いレストランまでの距離を覚えています$a$そして最初の停留所から$b$。 

私たちの目標は、セルゲイが帰還するまでに行うことができた最小および最大の停止回数を決定することです。$s$, 最初の都市を除きます。 これは、可能なすべての歩幅を見つけることと同じです。$l$と一致する$a$そして$b$それぞれに必要な停止数を計算します。$l$一周するために。 

入力制約は次のことを意味します。$n$そして$k$それぞれ最大 100,000 まで増加でき、都市の総数は最大 200,000 になります。$10^{10}$。 これにより、セルゲイの経路を都市ごとに明示的にシミュレートするアルゴリズムは除外されます。 代わりに、距離を法的に扱うアプローチが必要です。$n \cdot k$。 距離$a$そして$b$それぞれせいぜい$k/2$これは、重要な情報がレストランの絶対的な位置ではなく、レストランに対する開始地点と最初の停止地点の位置関係から得られることを示唆しています。 

微妙なエッジケースが発生する場合$a$または$b$はゼロです。これは、セルゲイがレストランから直接始めることを意味します。 もう一つは、レストランが 1 軒しかない場合です ($n=1$)-次に歩幅$l$円の長さと正確に一致する可能性があるため、最小停止点と最大停止点は等しくなる可能性があります。 円の周囲のすべての対称位置を考慮しないと、有効な歩幅の一部が失われることになります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての都市を反復しようとします。$s$最初の目的地となる可能性のあるすべての都市を計算し、すべてのレストランまでの距離を計算し、一致性をチェックします。$a$そして$b$。 有効なペアごとに、次の計算が行われます。$l$円に沿った差を計算し、元に戻るまでに何回停車するかを数えます。$s$。 正しいですが、これには反復処理が必要です$n \cdot k$出発地と最初の停留所の両方に都市が含まれるため、実行不可能になります。$O((n \cdot k)^2)$複雑なとき$n$そして$k$大きいです。 

重要な観察は、セルゲイの距離が$a$そして$b$最寄りのレストランに制限する$s$そして最初の目的地は$\pm a$または$\pm b$どこかのレストランのモジュロから$k$。 すべての都市を反復する代わりに、各レストランの位置を反復し、次のようにシフトできます。$\pm a$または$\pm b$候補ポジションを見つけるためです。 各候補は潜在的な歩幅を定義します$l$、円を完成するまでのストップ数は単純に次のようになります。$\frac{n \cdot k}{\gcd(n \cdot k, l)}$。 これにより、問題は反復処理に減ります。$n$レストランにはそれぞれ 4 つの候補ポジションがあり、$O(n^2)$ステップ長の候補。これは実行可能です。$n \le 10^5$。

 ## アルゴリズムのチュートリアル

 1. のすべての位置を列挙します。$n$サークル沿いのレストラン: これらは$1, k+1, 2k+1, ..., (n-1)k + 1$。 
2. レストランのポジションごと$r_s$、可能な開始都市位置を生成します$s$として$r_s \pm a$、位置が以内であることを確認します$1$に$n \cdot k$。 
3. 同様に、レストランの各ポジションについても$r_t$、最初の目的地となる可能性のある都市の位置を生成します$t$として$r_t \pm b$。 
4. 各候補ペアについて$(s, t)$、歩幅を計算します$l = (t - s) \mod (n \cdot k)$。 もし$l = 0$、最初の停留所がすでに にあることを意味します$s$; 完全な円のステップを考慮してこれに対処してください$l = n \cdot k$。 
5. 戻る停留所の数を計算します。$s$として$\frac{n \cdot k}{\gcd(n \cdot k, l)}$。 これは移動するため機能します$l$繰り返しモジュロ$n \cdot k$まさにこの商の長さを持つサイクルが生成されます。 
6. すべての有効なステップ長の候補にわたる停止の最小数と最大数を追跡します。 

機能する理由: このアルゴリズムは、距離に応じて開始位置と最初の停止位置の有効な組み合わせをすべて探索します。$a$そして$b$。 最大公約数を使用すると、円形パスのモジュラー演算の性質が確実に考慮されます。 これらのサイクル長の最小値と最大値は、セルゲイが帰還する前に行うことができる最小停止点と最大停止点に対応します。$s$。 

## Python ソリューション```python
import sys
from math import gcd
input = sys.stdin.readline

n, k = map(int, input().split())
a, b = map(int, input().split())

circle = n * k
restaurants = [1 + i * k for i in range(n)]
candidates = []

for rs in restaurants:
    for delta_s in [-a, a]:
        s = rs + delta_s
        if 1 <= s <= circle:
            for rt in restaurants:
                for delta_t in [-b, b]:
                    t = rt + delta_t
                    if 1 <= t <= circle:
                        l = (t - s) % circle
                        if l == 0:
                            l = circle
                        stops = circle // gcd(circle, l)
                        candidates.append(stops)

print(min(candidates), max(candidates))
```コードはまず、記憶された距離に基づいてレストランの位置と候補都市の位置を構築します。$a$そして$b$。 二重ネストされたループは、開始位置と最初の停止位置の候補のすべての組み合わせを列挙し、円の長さを法とする有効ステップ長を計算し、最大公約数を使用して停止の数を導き出します。 開始都市にすぐに戻るなどのエッジケースは、置き換えることによって処理されます。$l = 0$円全体の長さで。
