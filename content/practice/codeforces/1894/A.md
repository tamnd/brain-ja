 ## 問題の理解

 各キャラクターがプレーヤー A またはプレーヤー B のいずれかが勝った 1 つのプレイを表す一連の試合結果を観察します。これらのプレイはセットにグループ化されます。セットは、1 人のプレーヤーが累積するとすぐに終了します。$X$そのセット内で勝ちます。 その後セットが累積され、1 人のプレイヤーが到達した時点でゲーム全体が終了します。$Y$セット勝ち。 

難しいのは、そのどちらでもないことです$X$または$Y$が与えられる。 明示的に設定された境界はなく、平坦化された再生シーケンスのみが表示されます。 タスクは、ゲーム全体の最終勝者がシーケンスから一意に決定されるかどうか、または異なる有効な選択肢が存在するかどうかを判断することです。$X$そして$Y$異なる勝者が生まれる可能性があります。 

重要な制約は、$n \le 20$, なので再生数が極端に少ないです。 これにより、大規模な前処理や最適化の必要性が即座に排除されます。 配列の合理的な構造解釈を列挙する解決策であればどれでも十分です。 

シーケンスの初期のプレフィックスによって設定境界の複数の一貫した解釈がすでに許可されている場合、微妙なエッジ ケースが発生します。 たとえば、シーケンスがすべて A の場合、$X \ge 1$A がすべてのセットに勝つことになりますが、勝利に必要なセット数は状況によって異なります。$Y$、それでも勝者は固定されたままです。 逆に、交互のシーケンスでは、セットがどこで終了するかについて複数の矛盾した解釈が許容される可能性があり、セットがどのようにセグメント化されているかに応じて、最終的な勝者の識別が反転する可能性があります。 

## アプローチ

 強引な視点は、治療することから始まります。$(X, Y)$未知のパラメータとして。 候補ペアごとにゲームをシミュレートします。プレイシーケンスをスキャンし、誰かが到達したときにセットに分割します。$X$勝ち、セットの勝者を数え、誰かが到達したら停止します$Y$セット勝ち。 このシミュレーションは簡単で正確です。 

問題はそれです$X$までの範囲で可能$n$、 そして$Y$までの範囲も可能です$n$、与える$O(n^2)$パラメータのペア。 各ペアについてシミュレーションすることができます$O(n)$が再生され、$O(n^3)$テストケースごとに作業します。 その間$n \le 20$これは技術的には可能ですが、不必要であり、問​​題の構造を曖昧にします。 

重要な点は、すべてを考慮する必要はないということです。$(X, Y)$。 意味のある唯一の候補は、$X$は、設定された境界内のプレフィックス勝利数として実際に表示される値です。 同様に、$X$有効なセグメンテーション内で最終的に負けたプレイヤーの連続勝利の最大回数によって決定されます。 一度$X$が固定されている場合、セットの結果シーケンスは貪欲なセグメンテーションの下で決定的になります。残る唯一の曖昧さは、決定するために必要なセットの数です。$Y$。 これにより、問題は、一貫した貪欲な分割の下でどのプレイヤーが勝利を余儀なくされるか、そして結果が解釈に依存するかどうかを評価することに帰着します。 

より単純で直接的な再定式化は、いくつかの条件と一致するすべての可能な有効な集合分解をシミュレートすることです。$X$、しかし、なぜなら$n$が小さい場合、代わりに両方の極端な動作、つまり A と B の可能な限り早いフィニッシュをチェックできます。両方が異なる勝者につながる場合、結果は曖昧になります。 それ以外の場合は固定されます。

 ## アルゴリズムのチュートリアル

 私たちは、有効なゲームではプレイ シーケンスが連続セットに分割され、プレイヤーが到達した最初の瞬間に各セットが終了するという事実を利用します。$X$勝ちます。 最終的な勝者が強制されるかどうかをテストします。 

以下のように進めていきます。 

1. グローバル勝者について両方の可能性を試します。A が勝ったと仮定し、B が勝ったと別々に仮定します。 
2. 固定された想定勝者の場合、そのプレーヤーが可能な限り早くセットを獲得するのと一致する、可能な限り最も早いセット分解をシミュレートします。 これは、A または B のいずれかが潜在的なしきい値に達する最も早い位置で各セットを貪欲に終了することに対応します。 
3. シミュレーション中に、両方のプレーヤーのセットの勝ちを追跡します。 プレイヤーが新しいセット勝利に到達するたびに、セットカウントをインクリメントし、次のセットのカウンターをリセットします。 
4. 有効なセグメンテーションの下で、いずれかの時点で相手が追いついたり追い越すことを余儀なくされた場合、この仮定は無効です。 
5. A が最終勝者になれるかどうか、および B が最終勝者になれるかどうかを記録します。 

出力はこれらの可能性に依存します。A のみが可能であれば、A を出力します。 B のみが可能な場合は B を出力します。 それ以外の場合は?を出力します。 

### なぜ効果があるのか

 有効なゲームの構造は細分化において単調です。セットの終了を早めることは、そのセットで現在リードしているプレイヤーにのみ有利であり、セットの終了を遅らせることは対戦相手を助けることしかできません。 したがって、極端な貪欲な構造は、すべての実現可能な結果を​​捕捉します。 有効なセグメンテーションの下で両方のプレイヤーが勝者になれる場合、曖昧さは現実のものになります。 それ以外の場合、勝者は一意に決定されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def possible_winner(s, target):
    n = len(s)
    
    # simulate greedy set formation where target wins per set is minimal (1..n)
    for x in range(1, n + 1):
        a_sets = 0
        b_sets = 0
        
        i = 0
        while i < n:
            a = b = 0
            while i < n and a < x and b < x:
                if s[i] == 'A':
                    a += 1
                else:
                    b += 1
                i += 1
            
            if a == x:
                a_sets += 1
            else:
                b_sets += 1
        
        if target == 'A' and a_sets > b_sets:
            return True
        if target == 'B' and b_sets > a_sets:
            return True
    
    return False

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        
        a_ok = possible_winner(s, 'A')
        b_ok = possible_winner(s, 'B')
        
        if a_ok and not b_ok:
            print('A')
        elif b_ok and not a_ok:
            print('B')
        else:
            print('?')

if __name__ == "__main__":
    solve()
```コードは、実行可能なすべての値を反復処理します。$X$、それぞれをセット終了の可能なしきい値として解釈します。 それぞれについて$X$、シーケンスを貪欲にセットに分割し、セットの勝者をカウントします。 これは、最初の到達時に正確に終了を設定する構造的制約と一致します。$X$勝ちます。 外側のチェックでは、一貫したセグメンテーションの下でプレーヤーが最終勝者になれるかどうかを集計します。 

よくある落とし穴は、固定されたものを想定してしまうことです。$X$完全な配列から導出されます。 早期終了の動作によりセグメンテーションが変化し、結果が設定されるため、これは不正確です。 もう 1 つの微妙な点は、貪欲なセグメンテーションが不可欠であるということです。セットを遅延させると、有効なゲームに対応しない非物理的な構成が人為的に導入されます。

 ## 特殊なケース

 シーケンス全体が 1 人のプレーヤーで構成されている場合、すべての有効なセグメント化により、そのプレーヤーのみがセットの勝者として生成されます。 入力用`AAAA`、可能な限り$X$これにより、A が最初に各セットを終了し、シミュレーションは A の即時セット勝利が繰り返され、出力 A が確認されます。 

プレイヤーが頻繁に交代する場合、セグメンテーションは変化する可能性がありますが、貪欲な構築により同じプレイヤーに対して一貫した支配パターンが得られ、すべての有効な解釈の下で結果の安定性が保証されます。
