 ## 解決策
 ## 問題の理解

 整数の配列が与えられ、1、2、または 3 のみを含むラベルの並列配列を構築する必要があります。目標は、元の数値が等しく、割り当てられたラベルがペア (1,2)、(1,3)、または (2,3) のいずれかを形成する 2 つのインデックスを含む 3 つのペアリング条件のうち 2 つを正確に満たすことです。 基本的に、これら 3 つの「色のペア」のうち 2 つが重複のどこかに表示されるように、配列内の重複に色を付けようとしていますが、3 つ目は表示されません。 

入力は複数のテスト ケースで構成されます。 各テスト ケースには最大 100 のサイズの配列があり、配列要素は 100 によって制限されます。配列のサイズが小さいため、テスト ケースごとに 2 次演算を使用した解を得ることができますが、それでも単純で直接的な方法を探す必要があります。 エッジケースには、すべての数値が同一である配列、重複がない配列、または正確に 2 つの重複がある配列が含まれます。 たとえば、配列`[7,7,7,7,7,7,7]`重複のラベル付けは 3 つの条件をすべて満たすため、正確に 2 つの条件を満たすことはできません。したがって、出力は次のようにする必要があります。`-1`。 もう 1 つの微妙なケースは、一意の要素のみを含む配列です。 ペアが存在しないため、解決は不可能です。 

## アプローチ

 単純な総当り手法では、各要素へのラベル (1、2、3) の割り当てをすべて試し、正確に 2 つの条件が満たされるかどうかを確認します。 サイズの配列の場合`n`、つまり`3^n`可能性は、たとえ誰にとっても手に負えないものである`n=20`, したがって、より賢明なアプローチが必要です。 重要な観察は、3 つの条件すべてが等しい数のペアのみに依存しているということです。 したがって、重複に焦点を当てることができます。 

要素が 3 回以上出現する場合、正確に 2 つの条件を満たすラベルを自由に割り当てることができます。 最初の 2 つの出現を 1 および 2 としてラベル付けし、条件 (1,2) を満たし、3 番目の出現を 3 に割り当てることができます。これにより、条件 (1,3) または (2,3) のいずれかを満たすことができます。 注意すれば、3 つの条件のうち 2 つを正確に満たすラベルを選択できます。 

すべての重複が最大 2 回発生する場合は、慎重に分析する必要があります。 すべての要素が正確に 2 回複製されている配列では、ラベル 1 と 2 を 1 つの要素に割り当て、次に 1 と 2 を別の要素に割り当てることができますが、条件 (1,3) または (2,3) が失敗する可能性があります。 どの要素も 2 回以上出現せず、ラベルを区別するのに十分な重複がない場合、問題は解決できない可能性があります。 すべての一意の要素または重複のペアのみを含む配列は、多くの場合、正確に 2 つの条件を満たすことができず、次のような結果が得られます。`-1`。 

最適な解決策は、配列要素を周波数によって分類することによって機能します。 要素が 3 回以上出現する場合、その要素は「flex」要素となり、どの 2 つの条件が保持されるかを制御できるようになります。 それ以外の場合、すべての重複が 2 回しか出現しない場合は、1 つの要素にラベル 1 と 2 を割り当て、他の要素には 1 と 2 を慎重に割り当てて、2 つの条件のみが満たされるようにします。 構造が正確に 2 つの条件を許可しない場合は、次のように出力します。`-1`。 このアプローチは次の点で線形です。`n`配列を反復処理し、カウントに基づいてラベルを割り当てるだけなので、テスト ケースごとに異なります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(3^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列内の各数値の頻度を数えます。 これにより、どの番号が重複しているのか、またその番号が何回出現するのかを知ることができます。 
2. 出力配列を初期化する`b`ゼロ付き。 これにはラベル 1、2、または 3 が保持されます。 
3. 少なくとも 3 の頻度を持つ数値が存在するかどうかを追跡します。そのような数値が存在する場合、最初の 3 つの出現にラベル 1、2、3 を割り当てることができます。 これは、どの 2 つの条件が満たされるかを制御できるため、非常に重要です。 
4. 他のすべての重複 (頻度 2) については、ラベル 1 と 2 を割り当てます。これらの割り当ては、その番号の最初の条件 (1,2) を自動的に満たします。 
5. 頻度 3 以上の数値がなく、頻度 2 の重複数が奇数の場合、2 つの条件を正確に満たすことは不可能です。 出力`-1`この場合。 奇数のカウントでは、3 つの条件をすべて満たす必要があります。 
6. 残りの要素 (周波数 1) には、デフォルトでラベル 1 を割り当てます。 これらは 3 つの条件のいずれにも寄与しないため、カウントには影響しません。 
7. 構築された配列を出力します`b`。 

機能する理由: 「flex」要素に 3 つの出現を与えることで、ラベル 1、2、3 を割り当てて、正確に 2 つの条件を選択的に満たすことができます。 頻度 2 の重複は (1,2) 条件のみを満たすため、不用意に 3 番目の条件を作成することを避けます。 周波数 3 以上の要素がなく、周波数 2 の要素の数が奇数の場合、どのラベル付けも 3 つの条件をすべて満たすため、レポートします。`-1`。 不変条件は、注意深くラベル付けされた重複のみが満たされた条件に寄与するということであり、これによりカウントを制御できるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    freq = {}
    for x in a:
        freq[x] = freq.get(x, 0) + 1
    
    b = [0] * n
    idx_map = {}
    for i, x in enumerate(a):
        if x not in idx_map:
            idx_map[x] = []
        idx_map[x].append(i)
    
    # Find a number with at least 3 occurrences
    flex_idx = -1
    for num, positions in idx_map.items():
        if len(positions) >= 3:
            flex_idx = num
            break
    
    if flex_idx != -1:
        # assign 1,2,3 to first three occurrences
        positions = idx_map[flex_idx]
        b[positions[0]] = 1
        b[positions[1]] = 2
        b[positions[2]] = 3
        # assign 1,2 to remaining duplicates if any
        for pos in positions[3:]:
            b[pos] = 1
        # assign 1,2 to all other duplicates (frequency 2)
        for num, positions in idx_map.items():
            if num == flex_idx:
                continue
            if len(positions) == 2:
                b[positions[0]] = 1
                b[positions[1]] = 2
            elif len(positions) == 1:
                b[positions[0]] = 1
    else:
        # Count elements with frequency 2
        pairs = [num for num, positions in idx_map.items() if len(positions) == 2]
        if len(pairs) % 2 == 1:
            print(-1)
            continue
        flip = True
        for num, positions in idx_map.items():
            if len(positions) == 2:
                if flip:
                    b[positions[0]] = 1
                    b[positions[1]] = 2
                else:
                    b[positions[0]] = 2
                    b[positions[1]] = 1
                flip = not flip
            else:
                b[positions[0]] = 1
    print(' '.join(map(str, b)))
```コードはまず、重複を効率的に処理するために頻度マップとインデックス リストを構築します。 の`flex_idx`要素では、1、2、3 を選択的に割り当てることができます。これは、正確に 2 つの条件を満たすための核となる洞察です。 flex 要素のない配列の場合、frequency-2 要素に交互に代入することで、3 番目の条件が誤って作成されるのを防ぎます。 シングルトンはどの条件にも影響を与えないため、デフォルトでは 1 というラベルが付けられます。
