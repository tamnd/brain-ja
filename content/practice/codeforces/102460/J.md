 ## 問題の理解

 各マシンには一連の機能があり、すべてテストする必要があります。 テスト データセットは、長さのバイナリ文字列で表される、これらの特徴の一部のサブセットを検出できます。\(n\)。 複数のデータセットを選択するということは、それらのデータセットによって検出されたすべての特徴を結合することを意味します。 タスクは、結合にすべての特徴が含まれる最小数のデータセットを見つけることです。 ある特徴がどのデータセットでも検出されなかった場合、答えは次のようになります。\(-1\)。 

制約は意図的に非対称になっています。 最大 500 個の機能が存在する可能性がありますが、これは機能のサブセットとしては多すぎます。\(2^{500}\)全く実現不可能です。 一方、テスト データセットは最大 15 個です。 それにより、\(2^m\)、せいぜい\(2^{15}=32768\)、すべてのマシンを列挙できるほど小さい。 マシンの数も最大 10 台であるため、マシンごとにすべてのサブセットを処理することも簡単に管理できます。 

不注意な実装は、いくつかの境界で失敗する可能性があります。 テストできない 1 つのデータセットを持つ 1 つの特徴を考えてみましょう。```text

 ## アプローチ

 直接的な総当たりアプローチは、\(m\)テストデータセット。 サブセットごとに、データセットのスキャン コレクションが 1 回だけ表示されます。\(2^m\)サブセット。 

カバレッジが単純にブール配列として表現される場合、1 つのサブセットの処理に \(O(mn)\) 時間がかかる可能性があります。 最悪の場合、これにより、\[
O(2^m mn).
\]と\(m=15\)そして\(n=500\)、それはおおよそです\(32768 \times 15 \times 500\)、またはマシンあたり約 2 億 4,600 万の基本機能チェック。 2 秒の制限の下では、Python にはそれを行う余地はほとんどありません。 

重要な観察点は、小さい次元はフィーチャの数ではなく、データセットの数であるということです。 データセットのサブセットを列挙する必要がありますが、カバーされる特徴のセットをコンパクトに表現する必要があります。 

Python の整数は、任意精度のビットセットです。 各バイナリ文字列を 1 つの整数に変換できます。\(j\)特徴があるかどうかを表します\(j\)カバーされています。 データセットの結合は、単純にビットごとの OR です。 500 個の特徴の結合は内部的には少数の機械語にのみ適合し、Python は最適化されたネイティブ コードで OR 演算を実行します。 

もう 1 つ便利な改善があります。 サブセットを検討する場合は、選択した 1 つのデータセットを削除し、より小さいサブセットのカバレッジを再利用します。 もし`mask`は現在のサブセットであり、`bit`がその最低設定ビットである場合、```text
coverage[mask] = coverage[mask without bit] | dataset[bit]
```したがって、各サブセットは、選択したすべてのデータセットから結合を再構築するのではなく、整数 OR 演算を 1 つだけ必要とします。 

ブルートフォース手法は、考えられるすべての選択を考慮する必要があるため機能しますが、同じ部分結合を繰り返し再計算するため失敗します。 の小さな値\(m\)を維持しましょう\(2^m\)一方、ビットセットと増分サブセット構築により、サブセットごとの作業が小さくなります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 |---|---|---|---|
 | ブルートフォース | \(O(2^m mn)\) | \(O(n)\) | Python では遅すぎる |
 | 最適 | \(O(2^m \lceil n/w\rceil)\) | \(O(2^m \lceil n/w\rceil)\) | 承認済み |

 ここ\(w\)ビットセット表現によって内部的に使用されるマシンワードのサイズです。 以来\(n\le500\)、この問題にとっては事実上小さな定数です。 

## アルゴリズムのチュートリアル

 1. すべてのデータセットのバイナリ文字列を整数に変換します。 少し\(j\)データセットのときに正確に設定されます\(j\)対応する機能をテストできます。 整数を使用するということは、テストされた 2 つのセットの特徴を結合すると、単一のビット単位の OR になることを意味します。 

2.構築する`full = (1 << n) - 1`。 この整数にはすべてが含まれます\(n\)特徴ビットが設定されているため、カバレッジの整数が次の値に等しい場合、コレクションはすべての特徴を正確にカバーします。`full`。 

3. 配列の割り当て`coverage`サイズの\(2^m\)。 エントリ`coverage[mask]`で表されるサブセットによって選択されたすべてのデータセットの結合を格納します。`mask`。 空のサブセットには、`coverage[0] = 0`。 

4. 空でないすべてのサブセットを列挙する`mask`。 最低設定ビットを次のように抽出します。`mask & -mask`。 そのビットの位置により、サブセットに属する 1 つのデータセットが識別されます。 

5. サブセットからそのデータセットを削除して取得します。`previous = mask ^ bit`。 現在のサブセットのカバレッジは次のようになります。`coverage[previous] | datasets[index]`。 小さいサブセットはすでに処理されているため、これは中心的な再利用ステップです。 

6. 結果として得られるカバレッジが次の値に等しいときはいつでも`full`、計算する`mask.bit_count()`そしてそれを使用して最小の答えを更新します。 すべてのサブセットが検査されるため、最小の有効なサブセットが見つかることが保証されます。 

7. サブセットが到達しない場合`full`、印刷`-1`。 それ以外の場合は、見つかった選択されたデータセットの最小数を出力します。 

### なぜ効果があるのか

 不変条件は、サブセットを処理した後、`mask`、`coverage[mask]`は、によって選択されたすべてのデータセットの結合です。`mask`。 これは、最初は空のサブセットに当てはまります。 空ではないサブセットの場合、選択した 1 つのデータセットを削除すると、カバレッジがすでに正しいより小さいサブセットが得られ、削除されたデータセットの OR 演算により、テストできる機能が正確に追加されます。 したがって、すべてのサブセットが正確にカバーされます。 このアルゴリズムは可能なすべてのサブセットを検査し、カバレッジにすべての特徴が含まれるサブセットを正確に受け入れるため、記録される最小母集団数は、まさに必要なデータセットの最小数となります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    answers = []

    for _ in range(T):
        n, m = map(int, input().split())

        datasets = []
        for _ in range(m):
            datasets.append(int(input().strip(), 2))

        full = (1 << n) - 1
        total_masks = 1 << m

        coverage = [0] * total_masks
        answer = m + 1

        for mask in range(1, total_masks):
            bit = mask & -mask
            index = bit.bit_length() - 1
            previous = mask ^ bit

            coverage[mask] = coverage[previous] | datasets[index]

            if coverage[mask] == full:
                count = mask.bit_count()
                if count < answer:
                    answer = count

        answers.append(str(answer if answer <= m else -1))

    sys.stdout.write("\n".join(answers))

if __name__ == "__main__":
    solve()
```入力文字列は次のように変換されます。`int(string, 2)`。 左端の文字が上位ビットになりますが、すべての位置がすべてのデータセットにわたって一貫してカバーされているかどうかだけを考慮しているため、それは問題ではありません。`full = (1 << n) - 1`正確に作成します\(n\)ワンビット。 すべてのデータセットは正確に\(n\)文字、無関係なビットをその位置より上に表示することはできません\(n-1\)。 

表現`mask & -mask`選択した最下位のデータセットを分離します。`bit.bit_length() - 1`その分離されたビットを、対応するゼロベースのデータセット インデックスに変換します。`mask ^ bit`このビットは必ず設定されるため、削除されます。`mask`。 

配列`coverage`もっている\(2^m\)空のサブセットを含むエントリ。 で列挙を開始します`1`空のサブセットをソリューションとして扱うことを回避します。 以来\(n>0\)、空のサブセットは決してカバーできません`full`ともかく。 

Python の整数はオーバーフローしないため、特徴数 500 には特別な数値処理は必要ありません。 負荷の高い作業は、個々の機能に対する Python レベルのループではなく、整数 OR 演算によって実行されます。
