 ## 解決策
 ## 問題の理解

 要素間のすべてのペアごとの距離から増加する整数配列 (X) を再構築する必要があります。 最初の要素は 0 に固定されており、すべての要素は 0 ～ 999 の範囲にあります。すべての位置のペア (i<j) について、スペクトルには値 (x_j-x_i) (繰り返し値を含む) が含まれます。 入力はこれらの (\frac{n(n-1)}2) 距離をソートされた順序で与えます。タスクは、正確にそのマルチセットを生成した可能性のあるすべての配列を見つけることです。 

たとえば、(n=3) のスペクトル (1,2,3) は、(0,1,3) または (0,2,3) のいずれかから取得できます。 これらの配列は異なりますが、ペアごとの距離は同じです。 両方を辞書順に出力する必要があります。 

上限 (n\le62) は、スペクトルに最大 (\frac{62\cdot61}{2}=1891) 個の値が含まれることを意味します。 これは、距離によってインデックス付けされた度数表を維持するには十分な大きさです。 999 という座標境界はさらに便利です。すべての距離は 1 から 999 までの小さな範囲に属しているため、残りの距離のチェックと特定は、バランスの取れたツリーやハッシュ テーブルではなく、固定サイズの配列を使用して行うことができます。 一般的なターンパイク問題では探索自体を多項式にすることはできないため、解決策は分岐を極めて小さくするために残りの最大距離の構造を利用する必要があります。 

最初の非自明なケースは (n=2) です。 距離は1つだけです。 入力用`2`に続く`7`、唯一の答えは`0 7`。 再構築する内部点があることを前提とした再帰的実装は、ここで失敗します。 

2 番目のケースは、最大値が座標制限を超える無効なスペクトルです。 例えば、```
2
1000
```唯一可能な配列は次のとおりであるため、有効な答えはありません。`0 1000`、これは境界 (x_i\le999) に違反します。 不用意に実装すると、座標制約をチェックせずにエンドポイントを再構築する可能性があります。 

繰り返される距離もマルチセットとして扱う必要があります。 例えば、```
4
2 2 2 4 4 6
```答えがあります`0 2 4 6`。 3 つの異なるペアが 2 で区切られているため、値 2 が 3 回出現します。 スペクトルをセットとして扱うと、この情報が失われ、無効な配列を受け入れる可能性があります。 

特に重要なケースは、現在説明されていない最大距離が 2 回発生し、全幅のちょうど半分である場合です。 のために```
5
1 1 1 1 2 2 2 3 3 4
```答えは`0 1 2 3 4`。 距離 2 は端点と中点の間に 2 回発生しますが、中間の座標は 2 という 1 つだけです。(d) と (W-d) の両方を盲目的に挿入するルールでは、同じ座標が 2 回挿入されます。 

## アプローチ

 直接的なブルート フォース ソリューションでは、エンドポイントを 0 と何らかの最大値 (W) に固定し、それらの間の整数から残りの (n-2) 座標を選択します。 (W\le999) 以降、最悪のケースを考慮します。 

[
 \binom{998}{n-2}
 】

 さまざまなインテリアコーディネートのセット。 次に、すべての候補配列について、すべての (\frac{n(n-1)}2) 個の距離を生成し、その多重度を入力スペクトルと比較します。 したがって、最悪の場合の作業は次のとおりです。 

[
 O\left(\binom{998}{n-2}n^2\right)。 
】

 (n=62) の場合、これは実現不可能です。 

すべての候補を明示的にチェックすることは確かに正しいため、ブルート フォースが機能しますが、スペクトルに含まれる最も強力な情報、つまり最大距離が完全に無視されます。 

最大距離を (W) とします。 最大距離は最小座標と最大座標の間の距離のみであるため、有効な配列には 0 と (W) の両方が含まれている必要があります。 これらの端点が固定されたら、すでに選択された点によってまだ説明されていない最大距離 (d) を考慮します。 

端点を通るこの距離を説明できる座標は 2 つだけです。 0 からの距離が (d) であるため、1 つは (d) です。 もう 1 つは、(W) からの距離が (d) であるため、(W-d) です。 したがって、すべての有効な補完には、これら 2 つの座標のうち少なくとも 1 つが含まれている必要があります。 

これにより、標準的なターンパイク再建戦略が得られます。 説明のつかない最大距離を繰り返し取得し、それを説明できる唯一の座標を試みます。 座標が提案されるときは常に、すでに選択されている座標までのすべての距離が残りのマルチセットに存在する必要があります。 必要な距離が 1 つでも欠けている場合、分岐は不可能であり、すぐに破棄できます。 

この問題に対しては、その基本的な後戻りだけではまだ十分ではありません。 等差数列では、対称的に見える分岐が多数作成されることがあります。 追加の観察は多重性に関するものです。 

説明されていない最大の距離が (d) で、その残りの多重度が 2 より大きいと仮定します。 その状態は不可能です。 この段階では、(d) の説明できない発生は、(d) または (W-d) を配置することによってのみ説明できます。 使用できるのは、エンドポイントによって生成された 2 つのオカレンスだけです。 差が (d) である将来の未配置ポイントのペアも、エンドポイントまでの距離が長くなり、その距離が最初に処理されることになります。 したがって、現在の最大距離のコピーが最大 2 つ残ることができます。 

(d) が 2 回出現し、(d\ne W-d) の場合、(d) と (W-d) の両方が強制されます。 分岐する理由はありません。 それらの 1 つだけが挿入された場合、(d) の 1 つのコピーのみがエンドポイントによって説明され、もう 1 つのコピーは、より大きなエンドポイント距離がすでに処理されている将来のペアから取得される必要があります。 

(d=W-d) の場合、2 つの候補は同じ点になります。 これは中間点の場合であるため、単一の座標で両方の端点の距離が説明されます。 

これらの多重度ルールは、実際に単純なターンパイク DFS を指数関数的にする問題のある分岐を崩壊させます。 結果として得られる検索は、理論上の最悪のケースでも依然として指数関数的ですが、座標制限と強力な強制配置ルールにより、指定された制限内で実用的になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O\left(\binom{998}{n-2}n^2\right)) | (O(n^2)) | 遅すぎる |
 | 最大距離枝刈りによるバックトラック | (O(2^n n^2 + Rn\log n)) 最悪の場合 | (O(1000+n+Rn)) | 承認済み |

 ここで (R) は有効な解の数です。 (2^n) 項は、理論的な検索ツリーの範囲を表します。 実際には、多重度ルールにより、ナイーブ バージョンがタイムアウトになる大きな対称サブツリーが削除されます。 

## アルゴリズムのチュートリアル

1. (\frac{n(n-1)}2) の距離を読み取り、その最大値 (W) を見つけます。 (W>999) の場合は、有効な配列がありません。 それ以外の場合は、周波数配列を初期化します`cnt`、 どこ`cnt[d]`未使用の距離 (d) のコピーがいくつあるかを格納します。 
2. 現在の座標セットに 0 と (W) を入れます。 距離 (W) はこのペアですでに説明されているため、減少させます。`cnt[W]`1つずつ。 他のペアは最小座標と最大座標の間の距離よりも大きな距離を持つことができないため、これらのエンドポイントは強制されます。 
3. すべての再帰状態で、残りの周波数が正である最大距離 (d) を見つけます。 これは次に説明しなければならない距離です。 
4. すべて (n) の座標が配置されている場合は、現在のセットを解として記録します。 挿入が成功するたびに、新しいポイントによって導入された距離が正確に削除されるため、(n) ポイントに到達するということは、完全なスペクトルが消費されたことを意味します。 
5. (d) の残りの多重度が 2 より大きい場合、この分岐を停止します。 現在の最大距離を表すことができるエンドポイント位置は (d) と (W-d) の 2 つだけです。 
6. もし`cnt[d] == 2`および (d\ne W-d) の場合は、(d) と (W-d) の両方を一緒に配置してみてください。 これは強制的なものであるため、この状態では分岐はありません。 
7. それ以外の場合は、(d) を候補座標として試してください。 その候補について、すでに配置されているすべての座標までの距離を計算します。 必要な距離すべてに十分な多重度が残っている場合にのみ、候補は正当です。 正当な場合は、それらの距離を削除し、座標を追加して再帰し、バックトラックしながらすべてを復元します。 
8. (d\ne W-d) の場合は、同様に (W-d) も試してください。 これらは、現在の最大距離を説明できる唯一の可能な座標です。 
9. 検索が終了したら、再構築されたすべての配列を辞書順に並べ替えます。 必要な出力表現が増加しているため、ソリューション内の座標も保存前に並べ替えられます。 

### なぜ効果があるのか

 重要な不変条件は次のとおりです`cnt`は常に、現在の座標によってまだ生成されていない距離を正確に表します。`points`。 最初は、終点距離 (W) のみが削除されています。 新しい座標が追加されるたびに、既存のすべての座標までの正確な距離が削除されるため、不変条件は true のままになります。 

残りの最大距離 (d) の場合、有効な補完には (d) または (W-d) が含まれている必要があります。 どちらも存在しない場合、距離 (d) を生成する将来の点のペアは、(d) よりも大きな終点距離を持つことになり、(d) が現在説明されていない最大の距離であるという事実に矛盾します。 したがって、検索によって有効な解決策が破棄されることはありません。 

多重度の枝刈りも同じ引数に従います。 (d) の 2 つを超える説明されていないコピーは、2 つの終点の位置によって説明できないため、その状態から解決策を導くことはできません。 ちょうど 2 つのコピーが残っており、(d\ne W-d) の場合、両方のエンドポイントの位置が強制されます。 中点の場合は、(W/2) にある 1 つの点が両方の端点までの距離 (d) があるため異なります。 

すべての候補は、新しく作成されたすべての距離が残りのマルチセットで見つかった後にのみ受け入れられます。 したがって、記録されたすべての配列には、要求されたスペクトルが正確に含まれます。 すべての有効な補完は再帰によって検討される候補のいずれかの後に続くため、すべての有効な配列が最終的に見つかります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(n, spec):
    m = n * (n - 1) // 2

    if len(spec) != m:
        return []

    width = spec[-1]

    if width > 999:
        return []

    cnt = [0] * (width + 1)

    for d in spec:
        if d <= 0 or d > width:
            return []
        cnt[d] += 1

    # The maximum distance must be between 0 and width.
    cnt[width] -= 1

    points = [0, width]
    answers = []

    def largest_remaining():
        for d in range(width, 0, -1):
            if cnt[d]:
                return d
        return 0

    def place(candidates):
        """Try placing all candidates as one forced/branched operation."""
        k = len(candidates)

        if len(points) + k > n:
            return

        if len(set(candidates)) != k:
            return

        for x in candidates:
            if x <= 0 or x >= width or x in points:
                return

        need = {}

        # Distances from every new point to every old point.
        for x in candidates:
            for y in points:
                d = abs(x - y)
                need[d] = need.get(d, 0) + 1

        # Distances between new points when two are inserted together.
        for i in range(k):
            for j in range(i + 1, k):
                d = abs(candidates[i] - candidates[j])
                need[d] = need.get(d, 0) + 1

        # Check whether the remaining spectrum contains all
        # distances introduced by the new points.
        for d, amount in need.items():
            if d == 0 or d > width or cnt[d] < amount:
                return

        # Apply the changes.
        for d, amount in need.items():
            cnt[d] -= amount

        points.extend(candidates)

        dfs()

        for _ in candidates:
            points.pop()

        for d, amount in need.items():
            cnt[d] += amount

    def dfs():
        if len(points) == n:
            answers.append(tuple(sorted(points)))
            return

        d = largest_remaining()

        if d == 0:
            return

        # At the current largest unexplained distance, at most
        # two copies can still be possible.
        if cnt[d] > 2:
            return

        reflected = width - d

        # Two copies force both symmetric positions, except when
        # they coincide at the midpoint.
        if cnt[d] == 2 and d != reflected:
            place((d, reflected))
            return

        # One copy means either endpoint-side candidate may be used.
        # When d == reflected there is only one distinct candidate.
        place((d,))

        if reflected != d:
            place((reflected,))

    dfs()

    answers.sort()
    return answers

def main():
    n_line = input().strip()
    if not n_line:
        return

    n = int(n_line)
    m = n * (n - 1) // 2

    spec = []
    while len(spec) < m:
        spec.extend(map(int, input().split()))

    answers = solve_case(n, spec)

    out = [str(len(answers))]
    for ans in answers:
        out.append(" ".join(map(str, ans)))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```周波数配列には距離によって直接インデックスが付けられます。 ここでは、可能な最大距離が 999 にすぎず、すべての検索と更新が非常に小さな定数を含む定時間であるため、これが辞書よりも好ましいです。 

初期化により 2 つのエンドポイントが固定され、それらの距離が削除されます。`cnt`。 これは、(n=2) の場合を自然に処理します。これは、唯一の距離を削除した後、再帰によって、必要な点が両方ともすでに存在していることがすぐに確認されるためです。 

の`place`関数は中央のマルチセット操作を実行します。 まず、端点がすでに 0 と (W) を占有しているため、開いた区間 ((0,W)) の外側の座標が拒否されます。 また、元の配列には個別の値が含まれている必要があるため、重複した座標も拒否されます。 

の`need`新しく生成されたいくつかのペアが同じ距離を持つ可能性があるため、辞書が必要になります。 たとえば、中間点を偶数幅の間隔に挿入すると、両方の端点まで同じ距離が生成されます。 変更前の多重度の集計`cnt`一連の個々のチェックで、コピーが不十分なマルチセットを誤って受け入れることを防ぎます。 

候補が 2 つある場合は、両方の座標を次の関数に渡すことによって処理されます。`place`すぐに。 彼らの相互距離は以下に含まれます`need`、これも微妙な点です。 この距離を省略すると、スペクトルに説明のつかないコピーが残り、再構成が誤って受け入れられる可能性があります。 

再帰の深さは最大 62 であるため、Python の再帰制限は問題になりません。 Python の整数にも任意の精度がありますが、この問題で関連する値はすべて最大 999 であり、大規模な算術演算は必要ありません。 

最後に、再構築後に答えが並べ替えられます。 DFS 順序は辞書編集順序ではなくスペクトル多重度によって決定されるため、検索順序に依存すると出力要件を満たせなくなります。

 | 時間 | (O(2^n n^2 + Rn\log n)) 最悪の場合 | 通常の状態では候補ブランチは最大で 2 つ存在し、各候補は最大 (n) 個の既存の点までの距離をチェックします。 残りの最大距離を見つけるには、最大 999 エントリをスキャンします。 |
 | スペース | (O(1000+n+Rn)) | 頻度配列は (O(1000)) を使用し、再帰と現在の座標セットは (O(n)) を使用し、すべての答えを保存するには (O(Rn)) が必要です。 |

 一般的なターンパイク再構成問題では多項式時間の解が得られることが知られていないため、理論的な探索は指数関数的なままです。 関連する実際的な改善点は、最大距離多重度ルールにより、頻繁に二方向分岐が 2 つの座標の強制挿入に変わることです。 また、座標制限が 999 であるため、周波数操作が非常に安価になります。 入力距離が最大 1891、再帰深度が最大 62 であるため、これは、規定の 5 秒および 1024 MB の制限によく適合します。

 ## 特殊なケース

 (n=2) の場合、入力```
2
7
```エンドポイント 0 と 7 から始まります。唯一のスペクトル値はそれらのペアによってすぐに消費されるため、現在のセットには必要な 2 つの要素がすでに含まれています。 アルゴリズムの記録`0 7`内部座標を挿入しようとせずに。 

座標境界については、```
2
999
```幅はちょうど 999 なので受け入れられます。 結果は`0 999`。 実装チェック`width > 999`、 それよりも`width >= 999`これにより、法的な上限での off-by-one エラーが回避されます。 

範囲外の幅の場合は、```
2
1000
```最初の要素はゼロに固定されているため、最大距離自体には 1000 の要素が必要になります。 アルゴリズムは、検索を開始する前にケースを拒否します。 

距離を重ねると、```
4
2 2 2 4 4 6
```幅 6 はエンドポイントを固定します。 次に大きい距離は多重度 2 の 4 なので、4 と (6-4=2) の両方が強制されます。 相互の距離はさらに 2 になり、距離 2 の 3 つのコピーすべてが消費されます。最終的な配列は次のようになります。`0 2 4 6`。 

中間点の場合、```
5
1 1 1 1 2 2 2 3 3 4
```幅は 4 です。多重度 2 で距離 2 が残りの最大距離になると、(4-2=2) であるため、2 つの候補は両方とも座標 2 になります。 アルゴリズムは候補が一致することを認識し、点を 1 つだけ挿入します。 この点により 2 つの端点距離が 2 つ作成され、他の選択された座標までの距離が残りのコピーを占めます。 

無効なスペクトルの場合、```
3
1 1 1
```幅は 1 なので、端点は 0 と 1 でなければなりません。3 番目の個別の座標は厳密にそれらの間に適合することはできません。 再帰的検索では正当な候補が見つからず、ゼロの解が返されます。 

2 つの解決策の場合、```
3
1 2 3
```端点は 0 と 3 です。残りの最大距離は 2 で、その候補は 2 と 1 です。1 を配置すると、`0 1 3`、2つの生産物を置きながら`0 2 3`。 どちらもまったく同じスペクトルを消費し、最終的な答えを並べ替えると、`0 1 3`前に`0 2 3`。 

これらすべてのケースの背後にある中心的な不変条件は、残りの頻度テーブルです。 単にその座標がもっともらしいという理由だけで分岐が受け入れられることはありません。 新しく作成されたすべてのペアは、入力マルチセットから 1 つの一致するコピーを消費する必要があり、消費されたすべてのコピーは、ブランチが放棄されたときに復元されます。 これにより、反復距離、中点距離、対称解が誤って処理されるのを防ぐことができます。
