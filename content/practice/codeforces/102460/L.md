 ## 問題の理解

 平面内には最大 4096 個の点があり、そのうちの 4 つを四角形の頂点として選択できます。 入力自体に重複が含まれている可能性があり、縮退した四角形も許可されるため、4 つの点は座標として個別である必要はありません。 タスクは、可能な最大の領域を見つけて、可能な範囲を含めて正確に印刷することです。`.5`小数部分。 

中心となる幾何学的な事実は、最適な四角形は凸面として扱うことができ、場合によっては三角形に縮退する可能性があるということです。 対角線が固定されると、その面積は、その対角線の両側にある 2 つの三角形の面積の合計になります。 固定対角線の場合、四角形の領域を最大化することは、各辺の対角線から最も遠い点を見つけることと同じになります。 これは、意図した (O(N^2)) ソリューションの背後にある重要な観察です。 

座標境界は最大 (10^9) と大きいため、浮動小数点ジオメトリは不必要であり、望ましくありません。 2 倍になったすべての面積は整数の外積なので、計算全体を正確な整数演算で実行できます。 C++ では、必要な外積には符号付き 64 ビット整数で十分ですが、Python 整数の精度は任意です。 

値 (N=4096) は、(O(N^4)) はもちろん、(O(N^3)) に近いものを除外するのに十分な大きさです。 すべての 4 点サブセットを列挙すると、すでに次のようになります。 

[
 \binom{4096}{4}=11,710,951,848,960
 】

 およそ (1.17\times10^{13}) の可能性があります。 意図したソリューションでは、すべての 4 要素を個別に検査するのではなく、幾何学的構造を利用する必要があります。 凸包のコストは (O(N\log N)) のみで、その後は二次回転キャリパー フェーズが主な作業となります。 

実装を静かに破壊する可能性のあるエッジケースがいくつかあります。 

たとえば、すべての点が同一である場合、```

0 0
0 0
0 0
0 0
```答えは`0`。 少なくとも 3 つの異なる点を想定した凸包の実装は、ここで失敗する可能性があります。

1 0
2 0
3 0
```答えもまた`0`。 入力には 4 つの点が含まれていますが、ハルには頂点が 2 つしかありません。

最終的に、答えは半整数になる可能性があります。 入力```

```面積が最大2倍になる`5`したがって、必要な出力は次のようになります。`2.5`。 浮動小数点を使用した印刷は不要であり、書式設定エラーが発生する可能性があります。 最終出力まで、面積の 2 倍を整数として保持します。 

## アプローチ

 直接的なアプローチは、4 つの入力ポイントのすべての選択肢を列挙することです。 それぞれの 4 つの頂点について、考えられる頂点の順序を考慮したり、より効率的に、一定時間内にこれら 4 つの点から取得できる最大面積を決定したりすることができます。 いずれにしても、4 倍の数は (O(N^4)) です。 (N=4096) には、約 (1.17\times10^{13}) 個の 4 倍数があり、使用可能な時間をはるかに超えています。 

有用な観察は、縮退三角形の場合は別個に処理して、最大面積の四角形を凸状とみなすことができるということです。 1 つの対角線 (A C) を選択すると、四角形は 2 つの三角形 (A B C) と (A C D) に分割されます。 それらのベースは両方とも同じセグメント (AC) であるため、一方の側では線 (AC) から最も遠い点を選択し、もう一方の側では線 (AC) から最も遠い点を選択することによって、それらの結合面積が最大化されます。 2 倍の三角形の面積は、まさに絶対外積です。 

これは、凸包点のみが重要である理由も示しています。 固定線からの距離を最大にする点が厳密に凸包の内側にある場合、包点はその方向のさらに遠くに位置します。 したがって、最適な選択を船体に適用することができます。 このハル縮小と固定対角定式化は、(O(N^2)) 法の標準的な幾何学的基礎です。 

巡回順序で凸包を計算した後、固定包頂点 (i) を考慮します。 対角線のもう一方の端点 (j) を船体の周囲で前方に移動します。 各対角線 (i,j) について、(i) と (j) の間の最良の頂点と、もう一方の円弧上の最良の頂点が必要です。 多角形は凸状であるため、(j) が前方に移動するにつれて、これらの最も遠い頂点は単調に移動します。 すでに前方に移動しているポインタを後方に移動する必要はありません。 これは、キャリパーを回転させるステップです。 

したがって、反対側の頂点のすべてのペアに対する総当り検索は二次関数になります。 すべての (i) に対して、(O(N)) 個の可能な (j) が存在しますが、2 つの最遠点ポインタも合わせて (O(N)) 回だけ進みます。 船体が既知の場合、結果として得られるアルゴリズムは (O(N^2)) です。

 | ブルートフォース | (O(N^4)) | (O(N)) | 遅すぎる |
 | 最適 | (O(N^2)) | (O(N)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての点を読み取り、その凸包を計算します。 

ポイントを辞書順に並べ替え、単調連鎖構造を使用します。 重複する座標は幾何学的なハルを構築する目的で削除され、エッジに沿った同一線上の点は面積の最大値を決して増やすことができないため不要です。 ハルに少なくとも 4 つの頂点がある場合、元の多重度は答えに影響しません。 
2. ハルの頂点が最大 2 つである場合、出力`0`。 

すべての入力点は 1 つの直線上にあるため、可能なすべての四角形の面積はゼロになります。 
3. ハルにちょうど 3 つの頂点がある場合、その三角形の 2 倍の面積を計算して出力します。 

4 番目の点は三角形の内側にあるか、三角形の頂点の 1 つと一致します。 このような点は三角形自体より大きい領域を作成できませんが、問題では縮退した四角形が許可されるため、三角形の領域が必要な最大値となります。 
4. からのインデックスを考慮して、概念的に巡回ハル配列を複製します。`0`を通して`2h-1`。 

これにより、対角線の 2 つの円弧を横断する際の厄介なモジュロ演算が回避されます。 インデックスのポイント`i+h`インデックスと同じ幾何学点です`i`。 
5. 船体の頂点を修正する`i`そしてさせてください`j`から逃げる`i+2`を通して`i+h-2`。 

これらは正確に、各側に少なくとも 1 つのハル頂点がある対角線です。 すべての凸四角形にはそのような対角線があるため、これらのペアを考慮するとすべての候補がカバーされます。 
6. ポインタを維持する`k`からの円弧上の最適な頂点を求める`i`に`j`。 

その間`k+1 < j`交換すると2倍の三角形の面積が増加します`k`による`k+1`、 前進`k`。 凸多角形の場合、固定弦から連続する頂点までの距離は単峰性であるため、値が減少し始めると、それ以上移動してもより良い頂点を見つけることはできません。 
7. ポインタを維持する`l`からの相補的な円弧上の最適な頂点を求める`j`に戻る`i`。 

同じ単峰性の議論がこの側にも当てはまります。 として`j`進歩、最適な`l`後退する必要はありません。これにより、3 次検索が 2 次検索に変わります。 
8. 候補となる 2 倍の領域を次のように計算します。 

[
 \オペレーター名{クロス}(i,j,k)+\オペレーター名{クロス}(i,j,l)。 
】

 ハルは反時計回りに保存されるため、両方の項は対応する 2 つの円弧に対して同じ符号を持ちます。 各外積は 1 つの三角形の面積の 2 倍であり、その和は四角形の面積の 2 倍になります。 
9. グローバル最大値を更新し、すべての対角線を続行します。 

考えられる凸四角形のそれぞれには、ステップ 5 で考慮されたペアの中に対角線があり、その対角線に対して、アルゴリズムは各辺で可能な限り最良の頂点を選択します。 したがって、その候補値は少なくともその四角形の面積となります。 すべての候補はそれ自体が有効な四角形構成であるため、最大の候補が正確に答えになります。 
10. 2 倍になった領域を必要なテキスト形式に変換します。 

2倍の面積が偶数の場合は印刷`answer // 2`。 奇数の場合は印刷する`answer // 2`に続く`.5`。 浮動小数点演算は必要ありません。 

これが機能する理由: 選択したすべての対角線について、四角形の領域は 2 つの三角形の領域の正確な合計になります。 両方の三角形の底辺は固定されているため、対角線からの最大垂直距離で船体の頂点を取得することにより、各辺が個別に最適化されます。 凸性は各辺の距離シーケンスを単峰にし、対角線の端点が進むにつれて最大化インデックスを単調にします。 したがって、2 つの回転ポインタは、対向する頂点の考えられるすべてのペアをスキャンすることなく、すべての対角線に対して正確な最適なペアを見つけます。 すべての最大面積の四角形は外殻上に頂点を持つ凸面を選択できるため、これらの対角線の候補にわたる全体的な最大値が必要な答えになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(a, b, c):
    return ((b[0] - a[0]) * (c[1] - a[1])
            - (b[1] - a[1]) * (c[0] - a[0]))

def convex_hull(points):
    points = sorted(set(points))

    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def largest_quadrilateral(points):
    hull = convex_hull(points)
    h = len(hull)

    if h <= 2:
        return 0

    if h == 3:
        return abs(cross(hull[0], hull[1], hull[2]))

    # Duplicate the hull so that all cyclic arcs can be traversed
    # with ordinary integer indices.
    p = hull + hull

    ans = 0
    limit_offset = h - 1

    for i in range(h):
        k = i + 1
        l = i + 3

        last_j = i + h - 2

        for j in range(i + 2, last_j + 1):
            if k >= j:
                k = j - 1

            # Best point on the arc i ... j.
            while k + 1 < j:
                cur = cross(p[i], p[k], p[j])
                nxt = cross(p[i], p[k + 1], p[j])
                if cur <= nxt:
                    k += 1
                else:
                    break

            if l <= j:
                l = j + 1

            # Best point on the complementary arc j ... i+h.
            while l + 1 <= i + h - 1:
                cur = cross(p[i], p[j], p[l])
                nxt = cross(p[i], p[j], p[l + 1])
                if cur <= nxt:
                    l += 1
                else:
                    break

            candidate = (
                cross(p[i], p[j], p[k])
                + cross(p[i], p[j], p[l])
            )

            if candidate > ans:
                ans = candidate

    return ans

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        points = [tuple(map(int, input().split())) for _ in range(n)]

        doubled = largest_quadrilateral(points)

        if doubled % 2 == 0:
            out.append(str(doubled // 2))
        else:
            out.append(str(doubled // 2) + ".5")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```の`convex_hull`関数は標準の単調チェーン構造を使用します。 の`<= 0`条件は、ハルのエッジの内側に厳密に存在するポイントと重複したポイントを削除します。 最大領域の検索には、端点のみを保持するだけで十分です。 

対角線ベースの四辺形には少なくとも 4 つのハル頂点が必要なので、二次ループの前の特殊なケースが必要です。 ハルの頂点が 2 つあるため、セット全体が同一線上にあります。 ハルの頂点が 3 つある場合、許容される最適な四辺形はハルの三角形に縮退するため、その 2 倍の面積は 1 つの外積になります。 

の`p = hull + hull`line は小さいですが便利な実装の詳細です。 それは可能にします`j`、`k`、 そして`l`船体の完全な循環コピーを繰り返さずに移動します。`% h`最もホットなループ内の操作。 

反時計回りの凸包の場合、2 つの円弧で使用される外積は非負になります。 これにより実装で回避できるようになります`abs()`二次ループ内。 2 つの外積は、対角線によって形成される 2 つの三角形の面積を 2 倍にしたものとまったく同じです。 

条件`k + 1 < j`防ぐ`k`対角線の端点の 1 つになることを防ぎます。 同様に、`l + 1 <= i + h - 1`保つ`l`相補的な円弧の内側。 これらの境界は、off-by-one エラーが最も発生しやすい場所です。 

ポインタは次のように意図的に初期化されます。`k = i + 1`そして`l = i + 3`。 最小の有効な対角線は次のとおりです。`j = i + 2`、したがって、その最初のアークには、`i+1`、もう一方のアークは から始まります`i+3`。 

すべての面積計算は整数のままです。 (10^9) ほど大きい座標では、外積は (10^{18}) 程度になる可能性があるため、固定幅の算術演算を行う言語には十分な幅の整数型が必要です。 Python の任意精度の整数は、これを自動的に処理します。
