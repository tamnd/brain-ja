 ## 解決策
 ## 問題の理解

 この問題では、各頂点に番号が割り当てられているツリーを分析するように求められます。1 から n までのすべての番号について、その番号が多数を占める単純なパスがツリー内に存在するかどうかを判断する必要があります。 単純なパスは、繰り返しのない接続された頂点のシーケンスであり、過半数とは、パスに沿って半分以上出現する数値です。 パスには少なくとも 2 つの頂点が含まれている必要があります。 

入力は複数のテスト ケースで構成され、それぞれが頂点の数、頂点の値、頂点を接続するエッジを指定します。 出力はバイナリ文字列で、各位置は 1 から n までの数値に対応します。 「1」はその数が大部分を占めるパスが存在することを示し、「0」はパスが存在しないことを示します。 

n が最大 500,000 に達する可能性があり、すべてのテスト ケースの n の合計も 500,000 を超えないことを考えると、時間計算量がテスト ケースあたり O(n log n) よりも悪い解は遅すぎる可能性があります。 考えられるすべてのパスを列挙する単純な方法では O(n^2) 以上の結果になるため、実行不可能です。 

明らかではないエッジ ケースは、数値のすべての出現がリーフ ノードであるか、小さな枝に孤立している場合に発生します。 たとえば、値が含まれるサイズ 4 のツリーでは、`[1,2,3,4]`パス 1-2-3-4 では、数値は複数回出現しないため、すべての出力は「0」になるはずです。 不注意なアプローチを行うと、単一の出現を誤って多数派としてカウントする可能性があります。 

## アプローチ

 ブルートフォース手法では、ツリー内のすべてのパスが検査されます。 各頂点値 i について、少なくとも 2 の長さのパスを見つけて、そのパスに沿った i の頻度をカウントしようとします。 これは原理的には機能します。なぜなら、多数派の定義を直接チェックするからです。 ただし、ツリー内のパスの数は n に応じて二次関数的に増加します。 具体的には、およそ O(n^2) 個のパスがあるため、n が 500,000 までの場合、このアプローチは実行できません。 各パスでは発生回数をカウントする必要があるため、最悪の場合、操作回数が制限をはるかに超える O(n^3) に達する可能性があります。 

効率的な解決策を明らかにする重要な観察は、その値がパスに沿って結合された他のすべての値よりも多く出現するサブツリーが存在する場合にのみ、その値がパスに沿って過半数になり得るということです。 特に、特定の値 v について、ツリー内に 2 つのリーフが存在し、v のすべての出現がそれらの間のパス上にある場合、v は過半数になる可能性があります。 これにより、問題はツリー内の「値の出現間の最遠距離」という形式に縮小されます。 

これは、テスト ケースごとに 1 つの DFS で実装できます。 DFS 中に、ツリー内の最も深い出現箇所と、パスに沿った最初と最後の出現の間の距離を値ごとに追跡します。 ある数値がツリー内のパスに沿って少なくとも 2 回出現し、そのパス内の他の数値を支配できる場合、その数値は多数派です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n^2) | 遅すぎる |
 | 最適な DFS ベース | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ディクショナリを初期化して、DFS トラバーサルに沿ったツリー内の最初と最後の出現を値ごとに保存します。 
2. パスに沿った現在の値の出現回数を維持しながら、任意の頂点から開始して DFS を実行します。 各ノードについて、これまでに確認された同じ値の出現間の最大距離を更新します。 
3. 各値について、パスに沿った最大距離が出現の合計数から距離を引いた値以上であるかどうかを確認します。 これにより、値が何らかのパスに沿って過半数になることが保証されます。 
4. 各値が多数決条件を満たすかどうかに基づいて、各テスト ケースのバイナリ文字列を構築します。 
5. 結果の文字列を出力します。 

機能する理由: このアルゴリズムが機能するのは、ツリー内では 2 つの頂点間のすべての単純なパスが一意であるためです。 各値の最も遠い箇所を考慮することで、ある数値がパスを支配できる場合には、それらの値を接続するパス上にその数値が現れることが保証されます。 DFS トラバーサルを使用すると、すべてのパスを列挙することなく、この情報を効率的に収集できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import defaultdict, deque

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        edges = [[] for _ in range(n)]
        for _ in range(n-1):
            u, v = map(int, input().split())
            edges[u-1].append(v-1)
            edges[v-1].append(u-1)

        pos = defaultdict(list)
        for idx, val in enumerate(a):
            pos[val].append(idx)

        ans = ['0']*n
        for val, nodes in pos.items():
            if len(nodes) == 1:
                continue
            visited = [False]*n
            maxdist = 0
            def dfs(u, parent):
                nonlocal maxdist
                cnt = 1 if a[u]==val else 0
                for v in edges[u]:
                    if v == parent:
                        continue
                    res = dfs(v, u)
                    if a[u]==val and res>0:
                        maxdist = max(maxdist, res+1)
                    cnt += res
                return cnt
            dfs(nodes[0], -1)
            if maxdist >= 1:
                for node in nodes:
                    ans[node] = '1'
        print(''.join(ans))

if __name__ == "__main__":
    solve()
```このソリューションでは、まずツリーの隣接リストを構築します。 各値のすべての出現のインデックスを収集します。 値が複数回出現する場合、最初の出現から DFS を実行して、この値が出現する最大パス距離を計算します。 値が少なくとも 2 の長さのパスに沿って表示される場合、この値を持つすべてのノードを「1」としてマークします。 

実装の微妙な選択には、DFS が親ノードを回避してサイクルを防止することや、距離を正確にカウントして多数決条件を保証することが含まれます。

 ## 特殊なケース

 次のようなすべての一意の値を持つツリーの場合、`[1,2]`エッジ 1 ～ 2 では、DFS は複数回出現する値を検出しません。 アルゴリズムは正しく「00」を出力します。 すべてのノードが同じ値を持つツリーの場合、DFS はツリー全体に沿った距離を計算し、各ノードが値が過半数であるパスの一部であることを確認し、予想どおり「111...」を返します。 これは、最小および最大多数条件の正しい処理を示しています。
