 ## 解決策
 ## 問題の理解

 私たちは、非常に制約されたおもちゃの言語ですでに単数形になっている単語を与えられています。 すべての単語はルート文字列から構築され、単数形は常にそのルートに接尾辞「us」を追加することによって作成されます。 私たちのタスクは、このプロセスを逆にすることです。単数形の接尾辞を削除し、残りの語根に「i」を追加して複数形に変換します。 

入力サイズは非常に小さく、各単語の長さは最大 10 文字で、英小文字のみです。 これにより、高度なデータ構造や最適化の必要性が即座に排除されます。 各文字を一定の回数だけ処理するソリューションであれば、簡単に十分です。 

微妙なエッジケースが最小限のルートです。 「us」という単語は空のルートに対応します。 「us」を削除すると空の文字列が生成され、正しい複数形は「i」になります。 もう 1 つの特殊なケースは、「sussus」など、ルート自体が内部の接尾辞パターンに似た文字で終わっている場合です。 最後の 2 文字のみが重要です。 以前に出現した「us」は無視する必要があります。 

## アプローチ

 ブルートフォース解釈では、考えられるすべてのルート分割を明示的に解析しようとしますが、言語の構造が厳格であるため、これは不要です。 すべての有効な入力は「us」で終わることが保証されているため、変換ルールは決定的です。 

重要な点は、何も検索したり検証したりする必要がないということです。 サフィックスは固定されているため、ルートは常に最後の 2 文字を削除することによって取得されます。 語根が抽出されると、複数形は「i」と直接連結されます。 

これにより、あらゆる種類の解析やパターン マッチングの問題が単純な文字列スライス操作に軽減されます。

 ## アルゴリズムのチュートリアル

 1. 単数名詞を表す入力文字列を読み取ります。 
2. 文字列の最後の 2 文字を削除します。 この問題では接尾辞「us」が常に存在することが保証されているため、これは安全です。 
3. 残りの接頭辞を単語のルートとして扱います。 
4. 語根に文字「i」を追加して複数形を形成します。 
5. 結果の文字列を出力します。 

ここでの唯一の推論手順は、サフィックスの削除は常に有効であり、追加のチェックには依存しないということです。 

### なぜ効果があるのか

 すべての有効な単語はルート + 「us」として構成されます。 最後の 2 文字を削除すると、常に元のルートが正確に再構築されます。 複数形はルート + 「i」として独立して定義されるため、変換は完全に決定され単射的であり、曖昧さは存在しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    w = input().strip()
    root = w[:-2]
    print(root + "i")
```各単語を読んだ後、最後の 2 文字を切り取るだけです。 これは、スライスがルートを決して破損しないことを保証する「保証は当社にあります」ため、安全に機能します。 次に、「i」を連結して複数形を形成します。 この実装では、空のルート ケースでも正しく動作するため、条件文や特殊なケースが回避されます。つまり、「us」が「」になり、次に「i」になります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(sys.stdin.readline())
    out = []
    for _ in range(t):
        w = sys.stdin.readline().strip()
        out.append(w[:-2] + "i")
    return "\n".join(out)

## 特殊なケース

 入力「us」の場合、最後の 2 文字を削除すると空の文字列が生成されます。 アルゴリズムは特別なロジックを使用せずにこれを正しく処理し、必要な複数形に一致する「i」を出力します。 

「sussus」などの内部に「us」シーケンスが含まれる単語の場合、最後の 2 文字のみが削除されます。 ルートは「sus」となり、「i」を追加すると「sussi」となり、内部パターンが正しさに影響を与えないことを示しています。
