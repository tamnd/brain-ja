 ## 解決策
 ## 問題の理解

 私たちは、三角形の植物の長年にわたる成長をモデル化するように求められています。 各植物の三角形には「上向き」または「下向き」という方向があります。 成長ルールは決定的です。毎年、各三角形から 4 つの新しい三角形が生成されます。 新しい三角形のうち 3 つは親の方向を継承しますが、4 つ目は反対方向を指します。 タスクは、後で上を向いている三角形の数を計算することです。`n`単一の上向き三角形から開始して年を計算し、この数値を 10^9+7 を法として返します。 

入力は単一の整数です`n`年数を表し、出力は 10^9+7 を法とした上向き三角形の数である単一の整数です。 の上限`n`は 10^18 と非常に大きいため、年ごとの成長をシミュレートするソリューションは除外されます。 単純なシミュレーションでは、n 年後に 4^n 個の三角形が生成されますが、これは実行可能な計算をはるかに超えて増加します。 これは、明示的な列挙ではなく、数学的または組み合わせ的なアプローチの必要性を示しています。 

エッジケースには以下が含まれます：`n = 0`ここでは何年も経過しないため、植物は単一の上向き三角形のままになります。`n = 1`これにより、4 つの三角形が生成され、そのうちの 3 つは上向きになります。 どのアプローチでも、固定サイズの整数を使用する言語での整数オーバーフローを回避するために、モジュロを正しく処理する必要があります。 

## アプローチ

 ブルートフォース手法は毎年反復され、上向き三角形と下向き三角形のカウントを更新します。 0 年には、上向きの三角形が 1 つ、下向きの三角形が 0 つあります。 その後の各年では、すべての上向き三角形から 3 つの上向き三角形と 1 つの下向き三角形が生成され、すべての下向き三角形から 1 つの上向き三角形と 3 つの下向き三角形が生成されます。 このプロセスでは、カウントを n 年間繰り返し更新する必要があります。 ただし、n は 10^18 まで大きくなるため、このアプローチでは 10^18 回の反復が必要となり、2 秒以内には不可能です。 

重要な観察は、問題が線形漸化関係であるということです。 させて`U_n`は上向き三角形の数であり、`D_n`年の下向き三角形の数と。 成長ルールにより次のことが得られます。```
U_{n+1} = 3 * U_n + 1 * D_n
D_{n+1} = 1 * U_n + 3 * D_n
```これは行列の乗算として表すことができます。```
|U_{n+1}|   |3 1|   |U_n|
|D_{n+1}| = |1 3| * |D_n|
```これにより計算が可能になります`U_n`行列のべき乗を O(log n) 時間で効率的に使用します。 これが機能するのは、行列の乗算の繰り返しが線形漸化の繰り返しに正確に対応し、二乗による累乗によって n 年すべての繰り返しが回避されるためです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n) | お(1) | 10^18 までの n には遅すぎます |
 | 行列のべき乗 | O(log n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. マトリックスを定義する`M = [[3,1],[1,3]]`上向き三角形と下向き三角形の繰り返しを表します。 
2. 初期ベクトルを定義する`V_0 = [[1],[0]]`0年目用。 
3. 高速行列累乗を使用して計算する`M^n`モジュロ 10^9+7。 これにより、毎年個別に計算する必要がなくなります。 
4. 乗算`M^n`と`V_0`入手する`V_n = [[U_n],[D_n]]`。 このベクトルの最初の要素は、上向きの三角形の数です。 
5. 出力`U_n % 10^9+7`。 

これが機能する理由: 反復は線形であり、2x2 マトリックスによって完全に捕捉されます。 行列のべき乗は、再帰を n 回適用した効果を正しく累積します。 モジュロ演算では、値が整数の制限内に保たれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mat_mult(A, B):
    return [
        [(A[0][0]*B[0][0] + A[0][1]*B[1][0]) % MOD,
         (A[0][0]*B[0][1] + A[0][1]*B[1][1]) % MOD],
        [(A[1][0]*B[0][0] + A[1][1]*B[1][0]) % MOD,
         (A[1][0]*B[0][1] + A[1][1]*B[1][1]) % MOD]
    ]

def mat_pow(M, power):
    result = [[1,0],[0,1]]  # Identity matrix
    while power > 0:
        if power % 2 == 1:
            result = mat_mult(result, M)
        M = mat_mult(M, M)
        power //= 2
    return result

def solve():
    n = int(input())
    M = [[3,1],[1,3]]
    if n == 0:
        print(1)
        return
    Mn = mat_pow(M, n)
    U_n = (Mn[0][0]*1 + Mn[0][1]*0) % MOD
    print(U_n)

solve()
```の`mat_mult`関数はモジュロで行列の乗算を処理します。`mat_pow`二乗による累乗を使用して、べき乗を効率的に計算します。 最終的な行列と初期ベクトルを乗算すると、上向きの三角形の数が得られます。 取り扱っております`n=0`不必要な計算を避けるために個別に実行します。 

## 実用的な例

 のために`n = 0`:

 | ステップ | ん | V_n | う_ん |
 | --- | --- | --- | --- |
 | 0 | 私 | [[1],[0]] | 1 |

 予想どおり、出力は 1 です。 

のために`n = 1`:

 | ステップ | ん | V_n | う_ん |
 | --- | --- | --- | --- |
 | 1 | [[3,1],[1,3]] | [[3],[1]] | 3 |

 最初の年は 3 つの上向きの三角形と 1 つの下向きの三角形を生成します。 

のために`n = 2`:

 | ステップ | ん | V_n | う_ん |
 | --- | --- | --- | --- |
 | 2 | [[10,6],[6,10]] | [[10],[6]] | 10 |

 予想通り再発が増加していることがわかります。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(log n) | 各行列の乗算は定数時間であり、二乗による累乗は log n 乗算を使用します。 
| スペース | お(1) | 常に少数の 2x2 行列のみが保存されます。 

これにより、ソリューションは時間とメモリの制限内で最大 10^18 の n を快適に処理できるようになります。

 ## 特殊なケース

 のために`n = 0`の場合、アルゴリズムは行列演算を実行せずにすぐに 1 を出力し、初期のプラント数を正しく返します。 

非常に大きい場合`n`10^18 など、行列のべき乗は対数的にスケールされます。 各乗算には 2x2 行列のみが含まれるため、モジュロ演算により結果が整数の制限を超えることはありません。 初期ベクトルを乗算すると最初の成分が得られます。`U_n`、常に正しく 10^9+7 を法とする上向き三角形を表します。
