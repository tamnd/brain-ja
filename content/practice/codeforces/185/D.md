 ## 問題の理解

 私たちは、キノコ大王を複数回訪問できるドワーフの数を計算するように求められます。 各訪問は 3 つの整数で指定されます$k$、$l$、 そして$r$、一連の数値を定義します。$k \cdot 2^l + 1, k \cdot 2^l + 2, \dots, k \cdot 2^r + 1$。 このシーケンスの最小公倍数に対応するインデックスを持つドワーフだけが王を見ることができます。 各訪問では素数も提供されます$p$そして、この最小公倍数を次の値で割ったときの余りを報告する必要があります。$p$。 

入力は非常に大きくなる可能性があります。$r$到達できる$10^{18}$したがって、シーケンスを反復して LCM を直接計算することは不可能です。 まで$10^5$訪問の場合、総当たりアプローチでは、シーケンスの LCM を計算する必要があります。$10^{18}$妥当な時間内でそれは不可能です。 したがって、モジュラー演算と素数係数の特性を利用して計算を簡素化する必要があります。 

明らかではないエッジケースには、次のようなシナリオが含まれます。$k$で割り切れます$p$または指数が$2^r$モジュラスを超えると、直接乗算がオーバーフローしたり、冗長モジュロになる可能性があります。$p$。 たとえば、次の場合$k = 2$、$l = 0$、$r = 1$、 そして$p = 3$、の単純な乗算$k \cdot 2^i + 1$数字を生み出すだろう$3$そして$5$、その LCM モジュロ 3 は$0$。 不注意なアプローチでは、LCM を正確に計算しようとして、整数の制限をオーバーフローしてしまう可能性があります。

重要な洞察はフェルマーの小定理から得られます。$p$素数、任意の数$x$満足する$x^{p-1} \equiv 1 \pmod{p}$もし$p$分けない$x$。 シーケンス内の各項は次の形式になります。$k \cdot 2^i + 1$。 もし$k \cdot 2^i \equiv -1 \pmod{p}$の場合、項は次のように割り切れます。$p$。 存在する場合$i$そのような$k \cdot 2^i \equiv -1 \pmod{p}$、LCM モジュロ$p$LCM には次の倍数が含まれるため、自動的にゼロになります。$p$。 

項が割り切れない場合$p$、すべての項は互いに素です$p$。 次に、LCM モジュロ$p$2 の個別の累乗モジュロの積として表すことができます$p$、これは計算に帰着します$2^{\text{sum of exponents}} \pmod{p}$。 指数の合計は、モジュラー算術の等比級数公式を使用して計算できます。 これにより、シーケンス全体の反復処理が回避されます。

## Python ソリューション```python
import sys
input = sys.stdin.readline

def mod_pow(a, b, m):
    result = 1
    a = a % m
    while b > 0:
        if b % 2:
            result = result * a % m
        a = a * a % m
        b //= 2
    return result

def solve():
    t = int(input())
    for _ in range(t):
        k, l, r, p = map(int, input().split())
        k %= p
        if k == 0:
            print(1)
            continue
        # check if -1 * modinv(k, p) is a power of 2 mod p
        target = (-pow(k, -1, p)) % p
        seen = set()
        power = 1
        found = False
        for i in range(p):  # at most p-1 distinct powers modulo p
            if power == target:
                if l <= i <= r:
                    found = True
                break
            power = (power * 2) % p
        if found:
            print(0)
            continue
        # LCM modulo p is product of terms modulo p
        # Compute 2^(sum of exponents) modulo p using geometric series formula
        pow_l = mod_pow(2, l, p)
        pow_r1 = mod_pow(2, r + 1, p)
        numerator = (pow_r1 - pow_l) % p
        answer = numerator * k % p
        answer = (answer + 1) % p
        print(answer)

solve()
