 ## 解決策
 ## 問題の理解

 合計制約に従って、3 つの非負の実数変数 _x_、_y_、および _z_ で定義された関数を最大化するように求められます。 関数の形式は _f(x, y, z) = x^a · y^b · z^c_ です。ここで、_a_、_b_、_c_ は非負の整数です。 変数は、_x + y + z ≤ S_ および _x, y, z ≥ 0_ を満たさなければなりません。 入力は合計制限値 _S_ と指数 _a、b、c_ を提供します。 出力は、対数精度の許容範囲内で関数を最大化するトリプル (_x_、_y_、_z_) である必要があります。 

主な制約は、_S_ が最大 1000、指数が最大 1000 であることです。関数は、指数に累乗される各変数で乗算的に増加するため、考えられるすべての実数を単純に列挙することは不可能です。 効率的に最大値に収束する継続的な最適化アプローチが必要です。 対数スケールは問題によって示唆されており、微分を単純化するために積を対数の和に変換することを示唆しています。 

この問題では 0^0 が 1 として定義されているため、明白でないエッジ ケースには、指数がゼロになることが含まれます。 たとえば、入力が次の場合`S=5`そして`a=0, b=0, c=0`、関数は 1 に評価されるため、(_x_、_y_、_z_) の合計が 5 になるどの選択肢も許容されます。もう 1 つのエッジ ケースは、一部の指数がゼロで、他の指数が正である場合です。 例えば`S=3`そして`a=1, b=0, c=2`可能なすべての合計を _x_ と _z_ に割り当てる必要がありますが、_y_ はゼロでもかまいません。 

## アプローチ

 ブルート フォース ソリューションでは、合計制約を満たす _x_、_y_、_z_ のすべての実数値を反復処理し、_x^a · y^b · z^c_ を評価します。 ドメインは連続的であり、離散化されたグリッドでさえ必要な精度を保証するには細かすぎるため、これは明らかに実行不可能です。 ステップ サイズが 0.001 の場合でも、組み合わせの数は天文学的な数になり、およそ (S/0.001)^3 となり、妥当な時間制限をはるかに超えます。 

重要な洞察は、対数を使用して関数を変換することで得られます。 _L(x, y, z) = ln(x^a · y^b · z^c) = a ln x + b ln y + c ln z_ とします。 ここで、_x + y + z = S_ を条件とする対数の線形結合を最大化する必要があります。 対数の負は凸であり、正の重みは凹を維持するため、これは凸の最適化問題です。 ラグランジュ乗数の方法を使用すると、偏導関数が最大で a/x = b/y = c/z に比例することがわかります。これは、最適解が変数間で _S_ をそれらの指数に比例して分配することであることを意味します。 

指数の合計が 0 の場合、関数は 1 で定数であるため、すべての変数は任意の非負の数値を合計すると S になります。それ以外の場合、解決策は単純です。 

_x = S * a / (a + b + c)_

 _y = S * b / (a + b + c)_

 _z = S * c / (a + b + c)_

 これにより、反復探索を行わずに直接閉形式の解が得られ、アルゴリズムの時間と空間が O(1) になります。

 | ラグランジュ乗数 / 比例配分 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 合計限度値 _S_ と指数 _a、b、c_ を読み取ります。 
2. 指数の合計、_total = a + b + c_ を計算します。 これは、座標間で配分する合計の「重み」を表します。 
3. _total == 0_ の場合、すべての指数はゼロです。 この場合、関数は同じ 1 であるため、_S_ に合計される非負の数の 3 つの値は有効です。 便宜上、_(0, 0, S)_ を出力できます。 
4. それ以外の場合は、各座標を比例的に割り当てます: _x = S * a / total_、_y = S * b / total_、_z = S * c / total_。 これは、合計の制約と、座標が指数に比例するときに関数が最大化されるという特性の両方を満たします。 
5. 対数差の要件 (10^-6) が確実に満たされるように、十分な精度で座標を出力します。 

これが機能する理由: 線形制約の下で積 x^a · y^b · z^c を最大化すると、a ln x + b ln y + c ln z が最大化されることになります。 この関数は正の象限で厳密に凹面であるため、導関数の等価化から導出される比例配分によってグローバル最大値が保証されます。 いずれかの指数がゼロの場合、その対応する座標は積に影響を与えることなく安全にゼロにすることができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

S = int(input())
a, b, c = map(int, input().split())

total = a + b + c

if total == 0:
    # All exponents zero: any allocation works
    x, y, z = 0.0, 0.0, float(S)
else:
    x = S * a / total
    y = S * b / total
    z = S * c / total

print(f"{x:.10f} {y:.10f} {z:.10f}")
```最初のブロックは入力を効率的に読み取ります。 指数の合計を計算して、すべてがゼロになる縮退ケースを検出します。 その場合、合計制約を満たす任意の割り当てを返します。 それ以外の場合は、各座標をその指数に比例してスケールします。 印刷フォーマットにより、浮動小数点精度が問題の許容範囲に十分であることが保証されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    S = int(input())
    a, b, c = map(int, input().split())
    total = a + b + c
    if total == 0:
        x, y, z = 0.0, 0.0, float(S)
    else:
        x = S * a / total
        y = S * b / total
        z = S * c / total
    return f"{x:.10f} {y:.10f} {z:.10f}"

# Provided sample
assert run("3\n1 1 1\n") == "1.0000000000 1.0000000000 1.0000000000", "sample 1"
# Custom cases
assert run("10\n2 0 3\n") == "4.0000000000 0.0000000000 6.0000000000", "zero exponent"
assert run("5\n0 0 0\n") == "0.0000000000 0.0000000000 5.0000000000", "all exponents zero"
assert run("7\n1 2 0\n") == "2.3333333333 4.6666666667 0.0000000000", "mixed zero exponent"
assert run("1\n1000 1 1\n") == "0.5 0.0005 0.0005", "large exponent ratios"
