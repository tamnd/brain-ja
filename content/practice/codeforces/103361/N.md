 ## 解決策
 ## 問題の理解

 それぞれ正の整数の高さを持つクリスマス ツリーの小さなコレクションが与えられています。 このタスクは、3 本すべてがまったく同じ高さになるように 3 本の異なる木を選択することです。 出力はこれら 3 つのツリーのインデックスです。 そのようなトリプルが存在しない場合、それは不可能であると報告します。 

入力サイズは非常に小さく、最大でも 100 個のツリーであり、各高さも 100 によって制限されます。これにより、比較的遅い 2 次または 3 次アプローチでも受け入れられることがすぐにわかります。これは、最悪の場合の演算の合計数が 10^6 または 10^7 のオーダーであり、これは Python の 2 秒の制限としてはわずかなものであるためです。 

「繰り返しの高さ」を選択したくなると、微妙な失敗モードが現れます。 少なくとも 2 つの同じ高さがあるだけでは十分ではありません。 たとえば、高さが次の場合、`[5, 5, 7]`、繰り返しはありますが、トリプルを形成するのに十分なコピーがないため、答えは依然として次のようになります。`-1`。 条件は厳密には、ある値が少なくとも 3 回出現することです。 

もう 1 つの危険な状況は、複数の有効な回答が存在する場合です。 別個のインデックスの有効なトリプルはどれも受け入れられるため、アルゴリズムは選択を考えすぎたり、辞書編集上の順序を最適化しようとすべきではありません。 

## アプローチ

 直接的な強引なアイデアは、インデックスのすべてのトリプルを調べることです。`(i, j, k)`かどうかを確認してください`h[i] == h[j] == h[k]`。 これは、考えられるすべてのトリプルを明示的に検証するため、簡単で正しいものです。 ただし、そのコストはトリプルの数に比例します。`n^3 / 6`。 と`n = 100`、これは約 160,000 回の反復であり、Python では実際には問題ありませんが、構造の単純さを考えると不必要に重くなります。 

重要な観察は、値が等しいことを超えてどのトリプルを選択するかは気にしないということです。 特定の値が少なくとも 3 回出現するかどうかを知る必要があるだけであり、出現する場合は、その値が出現する 3 つのインデックスが必要になります。 これにより、問題はインデックスの組み合わせの検索から頻度と簿記のタスクに変換されます。 

トリプルを生成する代わりに、各高さがどこで発生するかを追跡します。 記録された 3 つの位置で高さが見つかると、すぐにそれらを出力できます。 これにより、問題はアレイ上の 1 回のパスに軽減されます。

 ## アルゴリズムのチュートリアル

 各高さから、それが表示されるインデックスのリストへのマッピングを維持します。 

1. 各高さのインデックスを記録しながら、木のリストを左から右に繰り返し処理します。 これにより、自然な発生順序が確実に保持され、有効なインデックスが即座に得られます。 
2. 特定の高さのリストに新しいインデックスを追加するたびに、リストのサイズが 3 に達したかどうかを確認します。3 に達した瞬間に、有効な答えがすでに得られているため、それ以上の処理を停止できます。 
3. 保存されている 3 つのインデックスを任意の順序で出力し、プログラムを終了します。 
4. 高さが周波数 3 に達することなくすべての木のスキャンを終了すると、出力が出力されます。`-1`。 

重要な設計上の選択は、ステップ 2 での早期終了です。有効なトリプルが見つかったら、度数テーブルを完全に構築する必要はありません。 

### なぜ効果があるのか

 各高さの値について、それが表示されるインデックスのセットを正確に維持します。 任意の高さが少なくとも 3 回出現する場合、その 3 回の出現は、問題の定義により有効な解を形成します。 入力からの実際のインデックスのみを保存するため、ポジションを捏造したり複製したりすることはありません。 したがって、アルゴリズムは無効なインデックスや不一致の高さを出力できません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    h = list(map(int, input().split()))
    
    pos = {}
    
    for i, val in enumerate(h, start=1):
        if val not in pos:
            pos[val] = []
        pos[val].append(i)
        if len(pos[val]) == 3:
            print(pos[val][0], pos[val][1], pos[val][2])
            return
    
    print(-1)

if __name__ == "__main__":
    solve()
```このソリューションでは、身長をキーとする辞書を使用してインデックスを保存します。 各インデックスは、一般的な競技プログラミングの規則に合わせて 1 から始まります。 早期リターンにより、有効なトリプルが見つかったらすぐに停止します。 唯一の微妙な点は、現在のインデックスが候補トリプルに含まれるように、長さの条件をチェックする前に必ず追加することです。

def solve():
    input = sys.stdin.readline

 ## 特殊なケース

 すべての木の高さが同じである場合、最初の 3 つのインデックスはすぐに有効な答えを形成します。 アルゴリズムは、3 番目の出現に到達すると、配列の残りの部分をスキャンせずにこれを処理します。 

すべての高さの出現がちょうど 2 つある場合、サイズ 3 に達するリストは存在しないため、スキャンは完全に完了し、正しく出力されます。`-1`。 

有効なトリプルが配列の後半に現れた場合でも、アルゴリズムはインデックスを継続的に蓄積し、逐次処理以外の順序付けの仮定に依存しないため、それを検出します。
