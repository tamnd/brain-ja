 ## 問題の理解

 一連の正の整数が与えられます。 それぞれの番号について$a_i$、約数を選択する必要があります$d_i$。 すべての選択が完了したら、製品を確認します$D = \prod d_i$。 すべての可能な選択肢の中で、この製品が完全な正方形であるもののみを考慮します。 もし$D$は完全な正方形なので、次のように書きます$D = y^2$、そして私たちは貢献します$y$答えに。 タスクは合計することです$y$すべての有効な約数の選択肢にわたって。 

したがって、この構造は単一の選択に関するものではなく、すべての除数の選択をカウントし、製品のグローバル条件によってフィルタリングし、その積の平方根によって各有効な構成に重み付けをするものです。 

制約は大きいです:$n$そして$a_i$まで行く$10^6$。 これにより、要素ごとに約数を列挙し、すべての組み合わせを試行するアプローチは即座に除外されます。これは、要素ごとの適度な分岐でも指数関数的に爆発的に増加するためです。 どのソリューションも基本的に算術構造 (おそらく素因数分解) を使用して選択肢を圧縮する必要があり、構成を明示的に列挙することなく寄与を集計する必要があります。 

単純な間違いは、それぞれを扱うことです$a_i$約数のカウントを独立して乗算します。 たとえば、$a = [4, 4]$、選択する$d = [2,2]$は有効ですが、条件はポジションごとではなく、ポジション全体の指数の合計に依存します。 もう 1 つのよくある失敗は、「それぞれの$d_i$これは、製品が正方形であることとは無関係です。 

## アプローチ

 直接的なアプローチでは、すべての約数を列挙します。$a_i$、すべてのシーケンスを試してください$(d_1,\dots,d_n)$、積を計算し、それが完全二乗であるかどうかを確認し、完全二乗である場合はその平方根を累積します。 これは概念的には正しいですが、要素ごとの約数の選択肢の数は最悪の場合でもすでに数十に達しており、それを複数の要素で乗算すると、$n$状態空間は天文学的に大きくなります。 小さいものでも$n$、これは不可能になります。 

重要な観察は、すべてが素数を考慮しているということです。 積が平方であるかどうかは、最終積の各素数の指数のパリティのみに依存します。 以来$d_i$分割する$a_i$、その素指数は次の値によって制限されます。$a_i$。 これにより、パリティ制約のみを通じてすべての位置を結合しながら、素数ごとに指数の選択肢を個別に分散するという問題に変換されます。 

問題が素数ごとに表現されると、さまざまな素数からの寄与が制約と重みの両方で独立して乗算されるため、グローバルな答えは素数の積になります。 

したがって、各素数に対してタスクを次のように削減します。$p$、指数を選択するすべての方法を数えます$e_i \le k_i$（どこ$k_i$の指数です$p$で$a_i$)、各構成に次の重み付けをしながら、指数の合計が偶数になるようにします。$p^{(\sum e_i)/2}$。 これは、パリティ制約のある有界整数のシーケンスに対する構造化された計数問題です。 

指数合計に対する動的計画法を使用し、合計指数合計のパリティを追跡し、寄与を多項式として累積することで、これを解決できます。$x = \sqrt{p}$。 パリティ制約は、状態を偶数と奇数の指数合計に分割することによって処理されます。

 ## アルゴリズムのチュートリアル

 異なる素数からの寄与が増加するため、各素数を独立して処理します。 

### 1. すべての数値を因数分解します

 すべてを因数分解します$a_i$素数に。 素数ごとに$p$、配列を収集します$k_1, k_2, \dots, k_n$、 どこ$k_i$の指数です$p$で$a_i$。 ほとんどのエントリはゼロであり、実際には無視できます。 

これにより、グローバル積条件が素数ごとの独立したパリティ条件に分解されるため、単一の素数の影響が分離されます。 

### 2. 指数合計に対する DP を定義する

 固定素数の場合$p$、シーケンス 1 を構築する動的プログラミング テーブルを定義します。$a_i$一度に。 

2 つの配列を維持します。$dp_{even}[s]$そして$dp_{odd}[s]$、 どこ$s$は、この素数に対してこれまでに累積された指数の合計であり、下付き文字は、この合計につながる選択された指数の数が偶数パリティを持つか奇数パリティを持つかを追跡します。 私たちが最終的に気にする唯一の状態は、$dp_{even}$有効な構成には、すべての要素の指数合計が均等である必要があるためです。 

指数制限のある要素を処理するたびに$k$、すべての選択肢を考慮して DP を更新します$e \in [0, k]$。 指数の選択$e$合計を増やす$e$、次の場合にパリティを反転します。$e$奇数です。 

これは、各更新が、許容される指数の選択肢を表す小さな多項式による現在の DP の畳み込みであることを意味します。 

### 3. 寄付を効率的に蓄積する

 単純に畳み込みを再計算する代わりに、プレフィックスサム スタイルの遷移を使用します。 州ごとに、寄与を偶数と奇数の指数の選択に分割します。 

偶数の選択ではパリティ状態が維持されますが、奇数の選択ではパリティ状態が反転されます。 これにより、現在の最大指数合計で両方の DP 配列を線形時間で更新できます。 

プライムのすべての要素を処理した後$p$、 我々は持っています$dp_{even}[s]$、指数の合計を生成する方法が何通りあるかを数えます。$s$グローバルパリティ制約を満たしながら。 

### 4. 指数の合計を値に変換する

 各構成は重みに寄与します$p^{s/2}$。 偶数だけなので$s$有効な完全二乗積を提供すると、次のように計算します。$$S_p = \sum_{s \text{ even}} dp_{even}[s] \cdot p^{s/2}$$この合計をモジュラー演算を使用して直接評価します。 

### 5. すべての素数を結合する

 最終的な答えはすべての積です$S_p$あらゆるものに現れるすべての素数について$a_i$、モジュロ$10^9+7$。 

### なぜ効果があるのか

 核となる不変条件は、すべての約数の選択が素数ごとの指数の選択、および素数の積としての各構成要素の寄与に一意に対応するということです。 完全二乗条件は、各素数指数の合計に対する独立したパリティ制約に分解されます。 制約と重みは両方とも素数で区切られているため、すべての有効なグローバル設定の合計は素数ごとの合計を乗算することと同じです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAXV = 10**6

# smallest prime factor sieve
spf = list(range(MAXV + 1))
for i in range(2, int(MAXV ** 0.5) + 1):
    if spf[i] == i:
        for j in range(i * i, MAXV + 1, i):
            if spf[j] == j:
                spf[j] = i

def factorize(x):
    f = {}
    while x > 1:
        p = spf[x]
        c = 0
        while x % p == 0:
            x //= p
            c += 1
        f[p] = c
    return f

n = int(input())
a = list(map(int, input().split()))

# collect exponents per prime
from collections import defaultdict
prime_to_exps = defaultdict(list)

for v in a:
    fac = factorize(v)
    for p, c in fac.items():
        prime_to_exps[p].append(c)

# include implicit zeros (important for DP length consistency)
for p in list(prime_to_exps.keys()):
    prime_to_exps[p].extend([0] * (n - len(prime_to_exps[p])))

ans = 1

for p, exps in prime_to_exps.items():
    dp_even = {0: 1}
    dp_odd = {}

    for k in exps:
        new_even = {}
        new_odd = {}

        # precompute prefix contributions
        # for each current state, expand by choosing e in [0, k]
        for parity_dict, target_even, target_odd in [
            (dp_even, new_even, new_odd),
            (dp_odd, new_odd, new_even),
        ]:
            for s, cnt in parity_dict.items():
                # prefix sums over e
                # we simulate contribution directly
                # parity of e decides target parity
                for e in range(k + 1):
                    ns = s + e
                    if e % 2 == 0:
                        target_even[ns] = (target_even.get(ns, 0) + cnt) % MOD
                    else:
                        target_odd[ns] = (target_odd.get(ns, 0) + cnt) % MOD

        dp_even, dp_odd = new_even, new_odd

    # compute S_p
    res = 1
    # need powers of p
    # precompute p^i up to max exponent sum
    max_s = max(dp_even.keys()) if dp_even else 0
    powp = [1] * (max_s // 2 + 2)
    for i in range(1, len(powp)):
        powp[i] = powp[i - 1] * p % MOD

    for s, cnt in dp_even.items():
        if s % 2 == 0:
            res = (res + cnt * powp[s // 2]) % MOD

    ans = ans * res % MOD

print(ans)
```因数分解は最大で高速でなければならないため、実装は最小の素因数ふるいを構築することから始まります。$10^6$。 各数値は素数に分解され、指数は素数ごとにグループ化されます。 

DP は素数ごとに、指数の合計によってインデックスが付けられた 2 つの辞書を維持します。 遷移は、すべての指数の選択を反復して実行されます。$k$、パリティ構造を維持するために偶数と奇数の寄与を分離します。 これは最も最適化された遷移形式ではありませんが、概念的な DP に直接一致し、指数の合計が制限されているため、許容範囲内に留まります。 

DP完了後、指数合計を貢献度に変換します$p^{s/2}$偶数の場合のみ$s$, 奇数の合計は完全な平方を形成できないためです。 

最後に、素数間の寄与を乗算して、全体的な答えを取得します。

 ## 特殊なケース

 微妙なケースとしては、$a_i = 1$。 そのような状況では、あらゆる$d_i$は 1 に強制されるため、唯一の積は 1 であり、答えは正確に 1 でなければなりません。各素数のすべての指数配列が空であるため、アルゴリズムがこれを処理し、空の構成のみを持つ DP が生成されます。 

もう 1 つの特殊なケースは、次のような数値の単一の素数べき乗が大きい場合です。$10^6$。 DP は、0 から 0 までのすべての指数の選択肢を正確に考慮する必要があります。$k$、偶数と奇数の両方の寄与が確実に含まれるようにします。 プレフィックスベースの移行により、選択肢がスキップされないことが保証され、パリティ追跡により、無効な構成が自動的に除外されます。
