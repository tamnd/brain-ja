 ## 解決策
 ## 問題の理解

 各トリプルが乗法パターンに従って「魔法」である配列内のインデックスのトリプルの数を数えるように求められます。 具体的にはトリプル$(i, j, k)$魔法なら$a_j$整数の倍数です$b$の$a_i$そして$a_k$同じ倍数です$b$の$a_j$。 インデックスは個別である必要があり、乗数は$b$ポジティブである必要があります。 配列には最大で次のものを含めることができます$2 \cdot 10^5$すべてのテスト ケースの合計要素数、および値は最大で$10^9$。 

考えられるすべてのトリプルをチェックする単純な方法には、3 つのネストされたループが含まれます。 たとえ$n = 200{,}000$、これは次のことにつながります$O(n^3)$まったく実行不可能な操作です。 大幅に高速なものが必要です。 

エッジケースには、要素が繰り返される配列、倍数が存在しない配列、およびすべての要素が同じであるシーケンスが含まれます。 たとえば、配列が次の場合、`[1, 1, 1, 1]`、異なるインデックスのトリプルはカウントされ、組み合わせカウントが生成されますが、配列が`[2, 3, 5]`、有効なトリプルが存在しない可能性があります。 実装を不注意にすると、繰り返される数値を見逃したり、同じトリプルを異なる順序で過剰にカウントしたりする可能性があります。 

## アプローチ

 ブルートフォースソリューションはすべてを反復します$(i, j, k)$3 倍にして、乗算条件が成立するかどうかを確認します。 定義を明示的に評価するため、その正しさは保証されていますが、遅すぎます。 と$n \le 2 \cdot 10^5$、操作数$O(n^3)$周りに届く$8 \cdot 10^{15}$最悪の場合、適切な時間内に実行できなくなる可能性があります。 

これをスピードアップするための重要な洞察は、次のような状態に気づくことです。$a_i \cdot b = a_j$そして$a_j \cdot b = a_k$暗示する$b = a_j / a_i$そしてまた$a_k / a_j = b$。 したがって、それぞれについて、$a_j$、比率$a_j / a_i$等しい必要があります$a_k / a_j$、または同等の$a_i \cdot a_k = a_j^2$。 これにより、問題は任意の乗算器の操作からペアのカウントに変換されます。$(i, k)$それらの積が次の式で決定される完全二乗に等しくなるようにします。$a_j$。 頻度マップを使用すると、各数値の出現を効率的に数えることができ、配列の反復処理を 1 回か 2 回だけ行うことができます。 並べ替えは必要ありません。 純粋に数えることに頼ることができます。 

この観察により、有効なペアの数を計算できます。$(i, k)$それぞれに$a_j$約数を反復することによって$a_j^2$(または配列内に存在する値以上)、頻度カウントを使用します。 これにより、複雑さが大まかに軽減されます。$O(n \sqrt{\text{max}_a})$最悪の除数数シナリオでは、あるいは既存の配列値に限定すればより良いシナリオになります。 この問題については、頻度を事前に計算し、候補に対してインテリジェントに反復処理を行うことで、$O(n \log n)$実際の解決策。

 ## アルゴリズムのチュートリアル

 1. 辞書を使用して、配列内の各数値の頻度を数えます。 これは、潜在的な候補者が何人存在するかを迅速に判断するのに役立ちます。$i$または$k$固定されたものを与える$a_j$。 
2. マジック トリプルのカウンターをゼロに初期化します。 
3. 各要素を反復処理する$a_j$配列の。 それぞれについて$a_j$、ペアを見つける必要があります$(a_i, a_k)$そのような$a_i \cdot a_k = a_j^2$。 
4. これらのペアを効率的に見つけるには、すべての約数を反復処理します。$d$の$a_j^2$配列内に存在するもの。 もし$d$が約数である場合、相補因数を次のようにします$a_j^2 / d$。 
5. 有効な約数ペアごとに$(d, a_j^2 / d)$、それらの周波数を乗算してカウンターに加算します。 もし$d = a_j$または因子が同一である場合は、同じインデックスが複数回使用されないようにカウントを調整します。 
6. すべてを繰り返した後$a_j$、インデックスが繰り返されるトリプルを減算します。 実際には、頻度カウントを持つ個別の数値のみを反復処理することで、これが自動的に処理されます。 
7. テスト ケースの合計数を出力します。 

なぜ効果があるのか​​: 方程式に注目することで$a_i \cdot a_k = a_j^2$そして、頻度カウントを使用して、乗法特性を満たす個別のインデックスのすべての組み合わせを説明します。 度数表により、すべての出現が正しくカウントされ、約数によって有効な候補のみが生成され、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import Counter
from math import isqrt

def magic_triples(arr):
    freq = Counter(arr)
    total = 0
    for x in arr:
        count = 0
        limit = isqrt(x * x)
        for d in freq:
            if (x * x) % d == 0:
                other = (x * x) // d
                if other in freq:
                    count += freq[d] * freq[other]
        count -= 1  # subtract the case where i=j=k
        total += count
    return total // 2  # each triple counted twice

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(magic_triples(a))
```このソリューションでは、まず各数値の出現をカウントして、候補に効率的にアクセスします。 配列要素ごとに$x$、配列内に存在するすべての潜在的な約数を反復処理し、その周波数を乗算して、マジック トリプルを形成するペアの数を取得します。$x$。 1 を引くと自己カウントが削除され、2 で割ると対称性による二重カウントが修正されます。 使用する`Counter`整数演算によりオーバーフローが防止されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import Counter
    from math import isqrt

    def magic_triples(arr):
        freq = Counter(arr)
        total = 0
        for x in arr:
            count = 0
            for d in freq:
                if (x * x) % d == 0:
                    other = (x * x) // d
                    if other in freq:
                        count += freq[d] * freq[other]
            count -= 1
            total += count
        return str(total // 2)

    t = int(input())
    res = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        res.append(magic_triples(a))
    return "\n".join(res)
