 ## 問題の理解

 固定整数が与えられます$N$および整数の範囲$[L, R)$、すべての整数を意味します$X$そのような$L \le X < R$。 そういったものごとに$X$、次の最大公約数に関する条件を満たすかどうかを判断する必要があります。$N$。 

条件は次のことをチェックすることを単純化します。$\gcd(N, X)$等しい$\min(N, X)$。 問題が保証されているため、$N \le L < R$、すべての候補者$X$範囲内には少なくとも$N$、 それで$\min(N, X)$いつもです$N$。 これにより、条件が以下のことをチェックするようになります。$\gcd(N, X) = N$、これは次のことを言うのと同じです$N$分割する$X$。 

したがって、タスクは次のようになります。$[L, R)$の倍数です$N$、そのカウントを出力します。 

制約が意味するのは、$R$非常に大きくなる可能性があり、最大約$10^{18}$これにより、範囲内のすべての整数の反復処理が即座に除外されます。 リニアスキャンには最大で次のものが必要です$10^{18}$これは、gcd 計算のコストを無視しても実行不可能です。 

微妙なエッジケースは、オフバイワン境界から発生します。 間隔が半開きなので、$[L, R)$、値$R$それ自体を含めてはいけません。 からの単純な包含ループ$L$に$R$間違って数えてしまう$R$で割り切れるとき$N$。 

素朴な gcd ベースの考え方では、別の問題が発生します。たとえ gcd が効率的に計算されたとしても、すべての数値をチェックすることが依然として複雑さを支配しており、gcd の最適化は無意味になります。 

## アプローチ

 直接的なアプローチでは、あらゆることを試みます。$X$から$L$に$R - 1$、計算します$\gcd(N, X)$、一致をカウントします。 これは定義を直接適用するため、概念的には正しいです。 ただし、そのコストは間隔のサイズに応じて直線的に増加します。 いつ$R - L$到達する$10^{18}$、アルゴリズムは基本的に使用できません。 

重要な観察は、gcd 条件が割り切れる条件に崩壊することです。つまり、次の倍数を数えています。$N$。 それぞれの数値を個別に検査するのではなく、視点を切り替えて、次の数値の倍数を数えます。$N$指定された境界の下にあります。 これにより、問題は値の反復から整数範囲の算術に変換されます。 

の倍数をカウントする関数を定義すると、$N$厳密に値を下回る$S$、次の答えは$[L, R)$以下のカウントの差になります$R$そして以下のカウント$L$。 これらの各カウントは、整数除算を使用して定数時間で計算できます。

 ## アルゴリズムのチュートリアル

 1. 以降のことを観察してください。$X \ge L \ge N$、式$\min(N, X)$単純化すると$N$。 これにより、gcd 条件構造への依存が取り除かれ、問題が可算性テストに減らされます。 
2. 条件を置き換える$\gcd(N, X) = N$と$N \mid X$。 このステップでは、問題を整数論から等差数列の計算に変換します。 
3. インターバル数をプレフィックス数の差として再定式化します。つまり、次の倍数をカウントします。$N$で$[L, R)$厳密に小さい倍数がいくつあるかを計算することにより、$R$、次に厳密に小さい数を引きます。$L$。 これにより、範囲エンドポイントを直接処理することが回避されます。 
4. の倍数を計算します。$N$値より小さい$S$整数の除算を使用します。 すべての倍数には形式があります$kN$、有効な最大値$k$満足する$kN < S$、つまり$k \le \frac{S-1}{N}$。 
5. 式を適用する$\left\lfloor \frac{R-1}{N} \right\rfloor - \left\lfloor \frac{L-1}{N} \right\rfloor$そして結果を出力します。 

### なぜ効果があるのか

 正しさは、次の倍数であるという事実に基づいています。$N$完全に規則的な等差数列を形成します。 プレフィックスカウントへの変換により、すべての有効な倍数が$[L, R)$までのプレフィックス内で 1 回だけカウントされます$R$までプレフィックスから除外されます$L$。 減算により、以下のすべての寄与が除去されます$L$、ターゲット間隔内のそれらを正確に残します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, L, R = map(int, input().split())
    
    def count_less(x):
        if x <= 0:
            return 0
        return (x - 1) // N
    
    ans = count_less(R) - count_less(L)
    print(ans)

if __name__ == "__main__":
    solve()
```ヘルパー関数`count_less(x)`の倍数の閉じた形式のカウントを実装します。$N$厳密に以下$x$。 表現`(x - 1) // N`の整数形式です$\lfloor (x-1)/N \rfloor$、サイズのフルステップ数を直接カウントします。$N$前にフィット$x$。 

減算構造により、範囲を明示的に反復することがなくなります。 境界処理は、以下を介して厳密な不等式でエンコードされます。`x - 1`、これにより、誤って含めることが回避されます。$x$自体。

 ## 特殊なケース

 エッジケースの 1 つは次のような場合です$L$それ自体はの倍数です$N$。 例えば、$N=4, L=4, R=9$。 正解には 4 が含まれます。数式はこれを処理します。$count\_less(4)=0$そして$count\_less(9)=2$、結果 2 が得られます。これは 4 と 8 に対応します。

最終境界ケースが非常に大きい$R$。 計算には除算のみが使用されるため、オーバーフローやパフォーマンスの低下はなく、Python の任意精度整数は最大制約までの値を変更せずに安全に処理します。
