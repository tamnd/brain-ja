 ## 解決策
 ## 問題の理解

 私たちは、$N \times N$各セルが通常の交互パターンで黒または白に色付けされるチェス盤。 単にセルを数えるのではなく、各セルには増加する整数値が割り当てられ、ボード上のすべての値の合計が必要になります。 

重要な点は、値の割り当て方法です。 セルは行ごとに処理され、各行内では同じ色のセルのみが左から右の順に考慮されます。 行内の固定カラー セグメント内では、値は 1 ずつ増加する単純な等差数列を形成します。したがって、ある行のカラー セグメントが value で始まる場合、$S$そして含まれています$K$セルの場合、値は次のようになります。$S, S+1, \dots, S+K-1$、それらの合計は標準の等差級数の公式です。 

難しいのは、$S$行のみに対してローカルではありません。 これは、前の行に出現した同じ色のセルの数と、白のセルの総数から得られる黒のセルのグローバル オフセットにも依存します。 

タスクは、すべてのセルをシミュレートすることなく、ボード全体の合計を効率的に計算することです。 

入力サイズは基本的に$N$、したがって、解決策は次のようになります。$O(N)$または$O(1)$。 どれでも$O(N^2)$セル上のシミュレーションも概念的には問題ありませんが、構造を利用できるため不要です。 ただし、複数のクエリが存在する場合、テストごとの線形よりも悪いものは遅すぎます。 

主なエッジ ケースはパリティに関連しています。$N$が奇数の場合、黒と白のセルの数は 1 だけ異なり、黒のセルのグローバル オフセットが変更されます。 もう 1 つの微妙なケースは、行が交互に配置されるパターンです。これは、行ごとに各色のセルが何個表示されるか、したがってプレフィックスの合計がどのように計算されるかに影響します。$P(i)$進化。 

## アプローチ

 直接的な総当たりアプローチでは、ボードを構築し、行ごとに値を割り当て、合計を累積します。 各セルについて、その色を追跡し、各色の次の値のカウンターを維持し、それを結果に追加します。 これは定義を正確に反映しているため、これは正しいです。 

ただし、このアプローチのパフォーマンスは、$N^2$すべてのセルが訪問されるため、操作が行われます。 大きい$N$の場合、ボードには強い規則性があるため、これは非効率的かつ不必要になります。各行が同じカウント パターンを繰り返し、各色の値はボード全体で連続したセグメントになります。 

重要な観察は、実際には個々のセルが必要ないということです。 各行と各色について必要なのは、セルの数とそのセグメントの開始値の 2 つの数量だけです。 これらが判明すると、各行は一対の等差数列の合計に寄与します。 グローバル構造により、シミュレーションの代わりにプレフィックス数を使用して開始位置を計算することもできます。 

これにより、行寄与の閉じた形式の式を計算するという問題が軽減されます。$N$そして行パリティ。

 ## アルゴリズムのチュートリアル

 ### 主要な構造観察

 チェス盤の色が交互に切り替わります。 どの行でも、白と黒のセルの数は固定されています。$$L = \left\lfloor \frac{N}{2} \right\rfloor,\quad G = N - L$$ただし、その順序は行ごとに入れ替わります。 したがって、各色は行ごとに連続したセグメントとして表示され、各セグメントは等差数列を形成します。 

また、グローバル番号付けを白と黒のシーケンスに分けます。 白は 1 から始まります。黒は白のセルの総数に等しいオフセットから始まります。 

### ステップ

 1. コンピューティング$L = \lfloor N/2 \rfloor$そして$G = N - L$。 これにより、パリティに応じて各行に各色のセルが何個表示されるかが決まります。 
2. ボード全体の白と黒の合計数を計算します。 それぞれの$N$行に正確に含まれる$N$セルと色を交互に選択すると、これらの合計を直接求めることができます。 黒のシーケンスは次から始まります$B = \text{white count} + 1$。 これにより、すべての白の値の後でも黒の番号付けが継続されます。 
3. 指定された行の前に各色のセルが何個あるかを計算します。$i$。 これは、プレフィックス構造を使用して行われます。 

奇数行ではパターンが固定され、偶数行ではパターンが入れ替わります。 行ごとに再計算する代わりに、行の各ペアが正確に寄与することを利用します。$N$白人と$N$黒人であるため、プレフィックス数は直線的に増加します。 
4. 各行について、次のことを決定します。 

細胞の数$K$その行の各色の値と開始値$S$その列のその色の。 

開始値は次のとおりです。$$S = B + P(i) + 1$$どこ$P(i)$行の上に表示されたその色のセルの数です$i$。 
5. 行内の各カラー セグメントについて、等差数列を使用してその合計を計算します。$$\text{Sum} = \frac{(S + (S + K - 1)) \cdot K}{2}$$6. すべての行と両方の色にわたって寄与を累積します。 

### なぜ効果があるのか

 このアルゴリズムは、行の境界に関係なく、各色内で値がボード全体にわたって厳密な昇順で割り当てられるという不変式に依存しています。 行に入るたびに、その色の前のシーケンスを継続するだけです。 したがって、必要な唯一の状態は、その色にすでに割り当てられている値の数です。これはまさに$P(i)$トラック。 行構造は決定的であるため、プレフィックス数によってすべての開始点が完全に決定され、各行の寄与が独立して正しく構成可能になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())

    L = n // 2
    G = n - L

    # total number of white cells in an n x n chessboard
    if n % 2 == 0:
        white_total = n * n // 2
    else:
        white_total = (n * n + 1) // 2

    black_start = white_total + 1

    def row_colors(i):
        # returns (white_cells, black_cells) in row i (1-indexed)
        if i % 2 == 1:
            return (G, L)
        else:
            return (L, G)

    def prefix_white(i):
        # number of white cells above row i
        full_pairs = (i - 1) // 2
        rem = (i - 1) % 2
        return full_pairs * n + (G if rem == 1 else 0)

    def prefix_black(i):
        full_pairs = (i - 1) // 2
        rem = (i - 1) % 2
        return full_pairs * n + (L if rem == 1 else 0)

    def ap_sum(s, k):
        return (2 * s + k - 1) * k // 2

    ans = 0

    for i in range(1, n + 1):
        w, b = row_colors(i)

        sw = 1 + prefix_white(i)
        ans += ap_sum(sw, w)

        sb = black_start + prefix_black(i)
        ans += ap_sum(sb, b)

    print(ans)

if __name__ == "__main__":
    solve()
```この実装は行ベースの分解を反映しています。 機能`row_colors`交互のチェス盤構造をエンコードします。 プレフィックス関数は、指定された行の前に各色のセルが何個割り当てられているかを計算し、これによってその行の等差数列の開始値が直接決まります。 

等差数列の合計は、次を使用して定数時間で実装されます。$(2s + k - 1)k / 2$、浮動小数点除算を回避します。 メイン ループは行のみを実行し、線形の複雑さを保証します。 

2 行ごとに固定パターンが寄与するため、プレフィックス計算でのパリティ処理には注意が必要です。$n$色ごとのセル。

 ## 特殊なケース
