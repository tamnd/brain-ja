 ## アルゴリズムのチュートリアル

 まず、基底の素因数分解に焦点を当てて条件の構造を分離します。$k$。 すべての異なる素数を抽出します$k$, には素数が現れないため、$k$終了動作には無関係です。

## Python ソリューション```python
import sys
input = sys.stdin.readline

def factorize(n):
    res = {}
    d = 2
    while d * d <= n:
        while n % d == 0:
            res[d] = res.get(d, 0) + 1
            n //= d
        d += 1
    if n > 1:
        res[n] = res.get(n, 0) + 1
    return res

def solve():
    p, x, k = map(int, input().split())

    fk = factorize(k)

    # remove primes of k already covered by p
    d = 1
    fp = factorize(p)

    for pr, ek in fk.items():
        ep = fp.get(pr, 0)
        if ep < ek:
            d *= pr ** (ek - ep)

    primes = list(fk.keys())

    ans = 0
    m = len(primes)

    for mask in range(1 << m):
        mult = 1
        bits = 0
        ok = True
        for i in range(m):
            if mask >> i & 1:
                bits += 1
                mult *= primes[i]
                if mult > x:
                    ok = False
                    break
        if not ok:
            continue
        cnt = x // (mult * d)
        if bits % 2 == 0:
            ans += cnt
        else:
            ans -= cnt

    print(ans)

if __name__ == "__main__":
    solve()

次に、素数のすべてのサブセットに対して包含-排他を実行して分割します。$k$。 サブセットごとに、選択した素数の積を計算し、その倍数を数えます。$d \cdot \text{mult}$中に横たわる$[1, x]$。 交互の符号により、複数の素数で割り切れる数値が二重に数えられなくなります。
