 ## 解決策
 ## 問題の理解

 単一の整数から始めます$x$。 この番号から次までの申し込みが可能です$k$各演算では、整数の平方根を取る (下敷きにする) か、それを 2 乗します。 どちらの演算も整数演算で適用されるため、すべての中間結果は整数のままでなければなりません。 タスクは、以下から開始して、いくつの異なる整数を取得できるかを決定することです。$x$、 含む$x$それ自体、最大でもすべての可能なシーケンスを考慮した場合、$k$操作。 

したがって、問題は 1 つの最適なシーケンスを求めるのではなく、各ノードが整数であり、各ノードが最大 2 つの出力エッジを持つ有向グラフ内の遷移の制限された数の下で到達可能な値のセットのサイズを求めます。$v \to \lfloor \sqrt{v} \rfloor$そして$v \to v^2$。 

この制約により、最大の整数範囲全体にわたって文字通りに解釈された場合、ブルートフォース状態拡張は実行不可能になります。$10^9$そして深さまで$10^9$。 ただし、演​​算の構造は非常に制限的です。二乗演算は非常に速く増加しますが、平方根を繰り返すと値はすぐに 1 に向かって崩壊します。この非対称性により、状態空間が自由に拡張することができなくなります。 

単純なアプローチでは、操作のすべてのシーケンスを深度までシミュレートします。$k$、ただし、深さの分岐係数 2 は同じです$k$与える$2^k$シーケンスは、$k = 50$、ましてや$10^9$。 同じ状態をマージしても、深さまで盲目的に遷移を探索する$k$構造的な洞察がなければ、依然として非常に多くの繰り返し値が生成されてしまいます。 

微妙なエッジケースは次のような場合です$x = 1$。 どちらの操作でも 1 が維持されるため、答えは常に 1 になります。$k$。 もう 1 つのエッジケースは次のような場合です$x = 2$。 二乗法は急速な成長につながりますが、平方根はすぐに崩壊し、値がしきい値を超える前にのみ多くの個別の値が表示され、限られたステップ内で二乗法は無意味になります。 

主な問題点は、二乗は際限なく上向きに拡大しますが、平方根は小さな固定領域に向かって縮小することです。 したがって、到達可能なセットは周囲の小さな「コア」に集中します。$1$に加えて、初期値を超えて指数関数的に増加する値の短いチェーンが追加されます。 

## アプローチ

 ブルートフォース解釈では、問題を深さ制限のあるグラフ到達可能性として扱います。$k$。 値から$v$、両方を押します$v^2$そして$\lfloor \sqrt{v} \rfloor$そしてすべての状態を深部まで探索します$k$訪問した値の重複を排除する際に BFS または DFS を使用します。 これは、すべての有効な操作シーケンスを列挙するため、原理的には正しいです。 

失敗点は二乗演算の増大です。 単一の値から始めたとしても、二乗を繰り返すと次のような値が生成されます。$x, x^2, x^4, x^8, \dots$、合理的な限界を非常に早く超えます。 訪問済みセットを使用する BFS は重複を回避しますが、安定化する前に潜在的に非常に多くの異なる状態を探索します。これは、特に平方根によって大きな数が戻され、小さな領域と大きな領域の間にサイクルが作成される可能性があるためです。 

重要な観察は、状態空間が均一に大きくないということです。 平方根は常に数値を減らし、平方根を繰り返すと最終的に 1 に達します。$O(\log \log x)$ステップ。 これは、大きな値がすぐに小さな正規領域に収まることを意味します。 一方、二乗は、値が意味のある範囲を超える前に、値が少数のステップ内に留まっている間のみ問題になります。平方根を使用して再検討することができます。$k$ステップ。 

これは、到達可能なセットが 2 つの部分で構成されていることを示唆しています: からの平方根の繰り返しによって生成される下向きのチェーン$x$、およびからの繰り返しの二乗によって生成される短い上向きのチェーン$x$というのは、数値が十分に大きくなると、限られたステップ内で新しい領域に戻すことができないため、それ以上の構造は無関係になるからです。 

したがって、両方の方向を明示的に計算しますが、安定するまでのみ計算します。

 ## アルゴリズムのチュートリアル

 このプロセスは、完全なグラフではなく 2 つの決定論的なチェーンを探索するものとして扱われます。 

1. まず、平方根を繰り返し適用することで到達可能なすべての値を生成します。$x$。 すでに 1 でない限り、各ステップで値が厳密に減少します。これにより、1 ですぐに終了する必要がある単調減少シーケンスが生成されます。すべての訪問値は最大 1 秒以内に到達できるため、すべての訪問値をセットに格納します。$k$歩行中は制限を超えない限り操作できます。 
2. 並行して、次から始まる二乗を繰り返して得られる値を生成します。$x$ただし、二乗ステップ数を超えると停止します。$k$または、値が大きくなりすぎて、平方根チェーンとのさらなる相互作用によって演算制限内で新しい値を生成できなくなります。 重要な考え方は、数ステップを超えて二乗すると、制限されたステップ内で平方根が意味のある範囲に戻ることができる領域を超えて数値が爆発的に増加するということです。 
3. 両方の方向が同じ到達可能なセットに寄与できるようにすることで、混合遷移も暗黙的に考慮します。 平方根はすぐに崩壊するため、これらのチェーンの外側に基本的に新しい中間値を生成することなく、混合シーケンスを最初にいくつかの二乗を適用してからいくつかの平方根を適用する、またはその逆のパターンに正規化できます。 
4. 見つかったすべての値をセットに挿入します。 答えは単純にこのセットのサイズです。 
5. 私たちは以下を超えないことを保証します$k$それに応じて上向きと下向きの両方のトラバースを制限することにより、合計の操作が可能になります。 実際には、個別の値の数は、下向きのチェーンの長さに意味のある二乗ステップの数を加えたものによって制限されます。 

### なぜ効果があるのか

 重要な不変条件は、到達可能なすべての数値が、最初に 1 に近い固定点に到達するまで可能なすべての平方根を適用し、次にその基数から適用される二乗の数を考慮することによって得られる正準形式にマッピングできることです。 平方根は、より小さい整数に折りたたまれる完全平方の領域に対して冪等であり、厳密に大きさを小さくするため、新しい大規模な構造を生成することはできません。 一方、二乗法では、制限された操作バジェット内で未探索の領域にループバックできない、厳密に増加するシーケンスが生成されます。 これにより、到達可能なすべての状態が、下向きの崩壊チェーンのいずれかに強制的に配置されます。$x$または、からの上向き指数関数チェーンの短いプレフィックス上にあります。$x$、追加の分岐構造はありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    x, k = map(int, input().split())

    seen = set()

    # downward chain: repeated floor sqrt
    v = x
    steps = 0
    while steps <= k:
        if v in seen:
            break
        seen.add(v)
        if v == 1:
            break
        v = int(v ** 0.5)
        steps += 1

    # upward chain: repeated squaring
    v = x
    steps = 0
    while steps <= k:
        if v in seen:
            # still record but avoid pointless repetition
            pass
        seen.add(v)
        if v > 10**18:
            break
        v = v * v
        steps += 1

    print(len(seen))

if __name__ == "__main__":
    solve()
```下向きのループは、次から始まる平方根の繰り返しをシミュレートします。$x$。 各反復では、1 に達するか使い果たされるまで、到達可能なセットに新しい値が追加されます。$k$ステップ。 上向きのループは二乗の繰り返しをシミュレートし、指数関数的に増加するシーケンスを生成します。 値は非常に急速に増加する可能性がありますが、必要なのは、依然として新しい個別の状態に寄与できる可能性のあるプレフィックスだけです。 

セットを使用すると、多くの異なる操作シーケンスが同じ数値に集約されるため、重複が自動的に削除されます。 バインドされたチェックは、二乗プロセスでの暴走を防ぎます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 |$O(k)$| 各チェーンのパフォーマンスは最大でも$k$遷移、各操作は O(1) |
 | スペース |$O(k)$| 到達可能なセット | のステップごとに最大 1 つの値を保存します。 

操作の制限は次のとおりです。$k$、各ステップは急速に減少するか、意味のある再訪問領域を超えて爆発するため、個別の値の合計数は、シミュレートされた遷移の数において線形のままです。 これは、たとえ$k = 10^9$実際には、チェーンが早期に終了するためです。

 ## 特殊なケース

 のために$x = 1$の場合、アルゴリズムはすぐに 1 をセットに挿入し、どちらの操作でもそれを変更しないままにします。 下向きのチェーンは即座に終了し、上向きのチェーンも 1 だけ生成するため、最終的なセット サイズは、関係なく 1 になります。$k$。 

次のような値の場合$x = 2$、下向きの連鎖が生成します$2 \to 1$、上向きのチェーンが生成する間、$2 \to 4 \to 16 \to 256$。 すべての値がセットに収集され、混合シーケンスは依然としてこれらの正規表現に折りたたまれるため、それ以上の分岐は発生しません。
