 ## 解決策
 ## 問題の理解

 2D 整数グリッド上の一連の点が与えられ、すべての点は座標系の中心にある固定原点から観察されます。 その原点から、原点から始まる 2 本の光線によって定義されるくさび形の領域内のみを見ることができる「カメラ」を想像します。 これら 2 つの光線上、またはこれら 2 つの光線の間にあるものはすべて表示されます。 

タスクは、指定されたすべての点がウェッジの内側に収まるように、そのようなウェッジの可能な最小の角度幅を選択することです。 ウェッジは原点の周りを自由に回転できるため、方向は固定せず、開き角度のみを固定します。 

入力は、単純に点の数とその座標が続くものです。 出力は単一の実数、つまりすべての点を同時にカバーできるウェッジの最小角度 (度単位) です。 

制約では最大 100,000 点が許可されるため、すべてのペアを直接比較したり、候補ウェッジのすべての回転を試行したりするソリューションは遅すぎます。 O(n²) アプローチでは、すべての点のペアを潜在的な境界光線としてチェックする必要がありますが、これは最悪の場合約 10¹⁰ の操作につながり、実行可能ではありません。 したがって、前処理後に O(n log n) または O(n) 構造が必要になります。 

角度のラップアラウンドでは微妙な問題が発生します。 角度 0 度に近い点と 359 度に近い点は、実際には循環順序で近いかもしれませんが、角度の単純な線形スキャンではそれらが遠く離れているものとして扱われます。 正しいソリューションは、この周期的な性質に対処する必要があります。 

もう 1 つのエッジ ケースは、複数の点が原点からの同じ光線上にある場合です。 たとえば、点 (2, 0) と (5, 0) は角度分離を導入すべきではありません。 それらは一方向として動作します。 角度を慎重に正規化しない単純な実装でも機能しますが、違いについて推論するときは注意が必要です。 

最後に、答えは 1e-6 許容範囲内で求められるため、浮動小数点の精度が重要になります。 逆三角関数に依存する方法は、丸め誤差の下でも安定している必要があります。 

## アプローチ

 強引なアイデアは、ウェッジのあらゆる可能な方向を考慮することです。 これを行う自然な方法の 1 つは、atan2 を使用して原点に対するすべての点の角度を計算し、これらの角度を並べ替えてから、開始点を選択して、そこからすべての点をカバーするために必要な最大角度ギャップを計算してみることです。 各開始インデックス i について、前方にスキャンして前方 180 度以内の最も遠い点を見つけるか、回転後のすべての点を含む円上の最小間隔を同等に決定します。 

ただし、すべての開始点を個別にチェックするこのアイデアの単純な実装では、O(n²) の動作が発生します。これは、最大角距離を計算するために各点について他のすべての点をスキャンする可能性があるためです。 n = 10⁵ では、これは遅すぎます。 

重要な観察は、すべての点をカバーする最小の円弧を実際に探しているということです。 すべての点が [0, 360) の角度に変換されると、問題は次のようになります。すべての点を含む円上の円弧の最小長を見つけます。 これは、最後の点と最初の点の間のラップアラウンド ギャップを含む、ソートされた連続する角度間の最大ギャップを見つけることと同じです。 この最大のギャップを取り除くと、すべての点をカバーする最小の円弧が残ります。 

これが機能するのは、最適なウェッジはその境界が点の 1 つと揃うように回転でき、すべての点をカバーする唯一の障害は最大の空の角度領域であるためです。 その領域を削除すると、最小の囲み円弧が得られます。 

これにより、角度を並べ替えて 1 回スキャンするだけの問題が軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 (ソート + 最大ギャップ) | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

1. atan2(y, x) を使用して、すべての点 (x, y) をその極角に変換します。 これにより、各点がラジアン単位で円表現上に配置されます。 arctan の代わりに atan2 を使用する理由は、手動調整なしですべての象限を正しく処理できるためです。 
2. すべての角度を一貫した範囲 (通常は [0, 2π)] に正規化します。 これにより、ソートによって正しい循環順序が生成されることが保証されます。 
3. すべての角度を昇順に並べ替えます。 ソート後、連続する要素は原点の周りの隣接する方向を表します。 
4. ソートされたリスト内の連続する要素間の角度の差を計算します。 また、最後の角度に 2π を加えたものと最初の角度の間のラップアラウンドの差も計算します。 これらの違いは、円上の空のギャップを表します。 
5. これらすべての違いの間の最大ギャップを見つけます。 このギャップは、点を含まない最大の角度セクターを表します。 
6. この最大ギャップを 2π から減算して、すべての点を含む最小の円弧を取得します。 
7. 180 / π を乗算して、結果をラジアンから度に変換します。 

機能する理由: すべての点をカバーするウェッジは、円上の連続する空の領域を最大でも 1 つ除外する必要があります。 最適なウェッジは、最大の空のギャップが覆う必要のない唯一の領域であるため、開口部をその最大の空のギャップのちょうど反対側に配置することによって実現されます。 したがって、ウェッジ角度を最小化することは、連続する角度位置間の最大間隔である除外ギャップを最大化することと同じです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def solve():
    n = int(input())
    angles = []
    
    for _ in range(n):
        x, y = map(int, input().split())
        ang = math.atan2(y, x)
        if ang < 0:
            ang += 2 * math.pi
        angles.append(ang)

    angles.sort()

    if n == 1:
        print(0.0)
        return

    max_gap = 0.0

    for i in range(n):
        j = (i + 1) % n
        if j == 0:
            gap = (angles[0] + 2 * math.pi) - angles[i]
        else:
            gap = angles[j] - angles[i]
        max_gap = max(max_gap, gap)

    answer = 2 * math.pi - max_gap
    print(answer * 180 / math.pi)

if __name__ == "__main__":
    solve()
```このソリューションは、幾何学的構成を循環順序付け問題に変換することを中心に構成されています。 atan2 を使用すると、すべての象限にわたって正確さが保証され、正規化ステップにより負の角度の不一致が回避されます。 

よくある実装上の間違いは、最後の角度と最初の角度の間のラップアラウンド ギャップを忘れることです。 これがないと、すべてのポイントが 0 度付近に集まっているが、1 つのポイントが 360 度付近にある場合、小さなウェッジではなく、誤った大きなウェッジが生成されます。 

もう 1 つの微妙な点は、n = 1 の処理です。この場合、角度は必要なく、正解は 0 です。

```| ステップ | 角度 (rad) | 並べ替え済み | ギャップ | 最大ギャップ |

## テストケース```python
import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import atan2, pi
    n = int(sys.stdin.readline())
    ang = []
    for _ in range(n):
        x, y = map(int, sys.stdin.readline().split())
        a = math.atan2(y, x)
        if a < 0:
            a += 2*math.pi
        ang.append(a)
    ang.sort()
    if n == 1:
        return "0.0\n"
    mx = 0.0
    for i in range(n):
        j = (i+1) % n
        if j == 0:
            gap = ang[0] + 2*math.pi - ang[i]
        else:
            gap = ang[j] - ang[i]
        mx = max(mx, gap)
    ans = (2*math.pi - mx) * 180 / math.pi
    return str(ans) + "\n"

# provided samples
assert abs(float(run("2\n3 0\n0 3\n")) - 90.0) < 1e-6

# custom cases
assert abs(float(run("1\n5 7\n")) - 0.0) < 1e-6, "single point"

assert abs(float(run("3\n1 0\n2 0\n3 0\n")) - 0.0) < 1e-6, "collinear points"
assert abs(float(run("3\n1 0\n0 1\n-1 0\n")) - 180.0) < 1e-6, "half circle"

 ## 特殊なケース

 エッジ ケースの 1 つは、すべての点が原点から同じ光線上にある場合です。 この状況では、計算された角度はすべて同一であるため、並べ替えると定数配列が生成されます。 ギャップの計算では、ラップアラウンドの差分として完全な 2π ギャップが得られ、残りの円弧はゼロになります。これは正しいことです。ゼロ角度レンズは単一方向をカバーするからです。 

もう 1 つのエッジ ケースは、ポイントが 0/360 度の境界の周りに集まっている場合です。 たとえば、1 度および 359 度の点は、358 度の大きな円弧ではなく、2 度の小さな円弧を生成する必要があります。 ラップアラウンド ギャップの計算では、並べ替え後の最後の角度と最初の角度の間の循環差を考慮することで、これを明示的に処理します。 

最後のエッジ ケースは、点がほぼ同一線上にある場合の浮動小数点精度です。 atan2 を使用すると、安定した順序付けが保証され、変換を繰り返さずにラジアンで作業すると、累積誤差が最小限に抑えられます。 度への最終変換は 1 回だけ行われるため、精度が必要な許容範囲内に保たれます。
