 ## 問題の理解

 幾何学的記述には、より単純な組み合わせ構造が隠されています。 

ペアのポイントを取得します$(l,0)$そして$(r,0)$、 と$l<r$。 左の端点は小文字でマークされ、右の端点は対応する大文字でマークされます。 

2 つのペアが交差する場合、それらの正方形は交差します。 あるペアが別のペアの内側に完全にある場合、対応する正方形は大きい方の正方形の内側に完全に存在し、それらは接触しません。 有効なペアは、適切にネストされたか、または互いに素な括弧のペアとまったく同じです。 この構造は、25 種類のブラケット タイプを含む正しいブラケット シーケンスと同じです。 

Petya の消去後:

 - 目に見えるすべての小文字は、間違いなく既知のタイプの開き括弧です。 
- すべての大文字が消えました。 
- 毎`?`次のいずれかになります。 

- タイプが不明な、消去された左括弧、または
 - 消去された閉じ括弧。 

完全に正しい括弧シーケンスがいくつあれば、指定された文字列が生成されるかを数えなければなりません。 

届く長さは$10^5$これにより、次のような古典的なブラケット DP 状態が即座に除外されます。`dp[position][balance]`。 二次アルゴリズムには次のものが必要です$10^{10}$操作は不可能です。

## アプローチ

 最も直接的なアイデアは、標準のブラケット シーケンス DP です。 

させて`dp[i][bal]`最初の処理後のウェイの数になります`i`現在のスタック サイズでの位置`bal`。 

目に見える文字は常に残高を増やします。 あ`?`増やすことも減らすこともできます。

重要な観察は、目に見えるすべての小文字が左括弧であることがすでにわかっているということです。 唯一の決定は次の時点で行われます。`?`ポジション。 

現在の残高を保存する代わりに、これまでに配置された閉じ括弧の数を保存します。 

させて$m=n/2$、有効なシーケンス内の閉じ括弧の合計数。

 - せいぜい$\lfloor i/2 \rfloor$終わりは出現する可能性がありますが、そうでない場合、一部のプレフィックスには始まりよりも終わりが多く含まれることになります。

 ## アルゴリズムのチュートリアル

 1. もし$n$奇数です、出力`0`。 
2. しましょう$m=n/2$。 有効なシーケンスには正確に含まれている必要があります。$m$開口部と$m$クロージング。 
3. 表示されている小文字がすでにいくつ存在するかを数えます。 この値を呼び出します`fixed_open`。 
4. しましょう`dp[j]`正確に配置しながら現在のプレフィックスを処理する方法の数になります。`j`右括弧。 
5.初期化`dp[0] = 1`。 
6. 位置を左から右に処理します。 
7. 現在の文字が表示されている小文字の場合、強制的に左括弧になります。 DP 移行は必要ありません。 
8. 現在のキャラクターが`?`、次のいずれかになる可能性があります。 

- 開始ブラケット、
 - または閉じ括弧。 

これを閉じ括弧として選択すると、閉じの数が 1 つ増えます。```
dp[j] += dp[j-1]
```更新は降順に実行されます。`j`。 
9. 更新中は、次のことのみを考慮してください。```
i - m <= j <= floor(i/2)
```どこ`i`は、現在の 1 から始まる位置です。 

上限により、プレフィックスの有効性が保証されます。 下限により、正確に到達するのに十分な残りのポジションが保証されます。`m`クロージング。 
10. すべてのポジションが処理された後、`dp[m]`ブラケット タイプが 1 つだけであると仮定した場合、有効な開閉レイアウトの数に等しくなります。 
11. からの求人数`?`ポジションは```
m - fixed_open
```1. 乗算```
25^(m - fixed_open)
```なぜなら、そのような各開口部では、許可されている 25 文字のいずれかを選択できるからです。 

1. 結果のモジュロを出力します。$2^{32}$。 

### なぜ効果があるのか

 DP は閉じ括弧の位置のみをカウントします。 

有効な長さの括弧シーケンス$n$正確に含まれています$m$クロージング。 すべての接頭辞について、閉じの数が開始の数を超えることはありません。これは次と同等です。$j \le i/2$。 下限$j \ge i-m$残りのサフィックスが正確に終了するのに十分な終了を提供できることを保証します$m$。 

すべての有効な開閉配置は、正確に 1 つの正当な入れ子構造に対応します。 開始位置が固定されると、すべての閉じ括弧のタイプは、一致する開始括弧によって決まります。 残された唯一の自由は、それぞれの開口部のタイプを選択することです。`?`を係数として与えます。$25$そのような開口部ごとに。 

したがって、DP はすべての有効な構造を 1 回だけカウントします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1 << 32

def solve():
    n = int(input())
    s = input().strip()

    if n & 1:
        print(0)
        return

    m = n // 2

    dp = [0] * (m + 1)
    dp[0] = 1

    fixed_open = 0

    for i, ch in enumerate(s, 1):
        if ch == '?':
            lo = max(1, i - m)
            hi = min(m, i // 2)

            for j in range(hi, lo - 1, -1):
                dp[j] = (dp[j] + dp[j - 1]) & 0xFFFFFFFF
        else:
            fixed_open += 1

    ans = dp[m]

    for _ in range(m - fixed_open):
        ans = (ans * 25) & 0xFFFFFFFF

    print(ans)

solve()
```配列`dp[j]`これまでに使用されたクロージングの数のみによってインデックス付けされたストア数。 表示されている小文字は左括弧であることが強制されるため、この数は変わりません。 

のために`?`、既存の値`dp[j]`はすでに左括弧として選択することを表しています。 追加`dp[j-1]`これは閉じ括弧として選択することに相当します。 

反復順序は降順であることが重要です。 これにより、現在位置で作成された値が同じ更新中に再度再利用されるのを防ぎます。 

モジュロは$2^{32}$。 使用する```
