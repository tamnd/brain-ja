 ## 解決策
 ## 問題の理解

 正の整数が与えられます$k$のスタックを説明します。$k$連続した正方形のレイヤー。 ベースレイヤーには以下が含まれます$n^2$砲弾、次は含まれています$(n+1)^2$、などまで$(n+k-1)^2$。 したがって、砲弾の総数はこれらの合計になります。$k$連続した正方形。 

問題は、開始値を選択できるかどうかです。$n$この合計が完全二乗になるように$m^2$。 そのような場合$n$存在する場合は、以下を超えない有効な値を出力する必要があります。$10^{18}$; それ以外の場合は、解決策が存在しないと報告します。 

制約$k \le 2500$テスト ケースごとに多項式時間数理論を適用できるほど十分に小さいですが、ブルート フォースを実行できるほど十分に大きい$n$または、候補を直接合計することは不可能です。 単一の合計を評価しても$n$は$O(k)$、最大サイズまでスキャン$n$明らかに失敗するだろう。 

微妙な特殊なケースは、$n$まで無制限です$10^{18}$。 単純な検索では、小さいと誤って想定される可能性があります。$n$常に十分です。 それは誤りです。ディオファントス構造は、解が存在する場合、その解をゼロから遠く離れた位置に置く可能性があります。 もう 1 つの落とし穴は、ランダムなサンプリングを試みることです。$n$、たとえ解決策が存在したとしても、それを見つけることは保証できません。 

## アプローチ

 直接配合から始めます。 固定の場合$n$、計算できます$$\sum_{i=0}^{k-1} (n+i)^2$$そしてそれが完全な正方形であるかどうかを確認してください。 これは正しいですが、使用できません: 各評価にコストがかかります$O(k)$、そして多くの値を試してみても、$n$すぐに実行不可能になります。 

和の構造が鍵となります。 これを展開すると、次のような二次式が得られます。$n$:$$\sum_{i=0}^{k-1} (n+i)^2 = k n^2 + k(k-1)n + \frac{(k-1)k(2k-1)}{6}.$$したがって、問題は整数を見つけることになります$n, m$満足のいく$$k n^2 + k(k-1)n + C = m^2,$$どこ$C = \frac{(k-1)k(2k-1)}{6}$。 

正方形を完成させる$n$重要なステップです。 させて$$a = n + \frac{k-1}{2}.$$すると左側は次のようになります$$k a^2 + \frac{k(k^2-1)}{12}.$$そこで、次の方程式に到達します。$$m^2 - k a^2 = \frac{k(k^2-1)}{12}.$$これは一般化されたペル方程式です。標準形式の固定不均一シフトです。$x^2 - k y^2 = d$。 ペル方程式の古典的な構造は、一度 1 つの解が存在すると、次の基本単位を使用して無限に多くの解を生成できることを示しています。$x^2 - k y^2 = 1$。 以来$k \le 2500$の連分数を介して基本的な解を計算できます。$\sqrt{k}$、生成された軌道内で必要な定数の表現を検索します。$d$。 

ここでの強引な類似物は、ペル再帰の解空間を探索することによって、右辺の定数に到達しようとすることです。 そのスペースは指数関数的に増加しますが、実際には、小規模な場合には最小限の解決策が非常に早い段階で現れます。$k$これにより、基本単位の繰り返し乗算による列挙が可能になります。

 | の直接列挙$n$|$O(nk)$|$O(1)$| 遅すぎる |
 | 連分数によるペル削減 |$O(\sqrt{k} \log k)$ごとに前処理$k$、小さな検索 |$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 私たちは次の 1 つの価値に焦点を当てます。$k$。 

### ## アルゴリズムのチュートリアル

 1. 定数項を計算する$$d = \frac{k(k^2 - 1)}{12}.$$これは、正方形を完成した後のペル方程式のシフトです。 
2. 次のようにして、元の問題を中央揃えの形式に書き直します。$$a = n + \frac{k-1}{2},$$合計を次のように変換します$$m^2 - k a^2 = d.$$このステップでは、2 つの変数の標準二次形式を分離します。 
3. 基本的なペル方程式を解く$$x^2 - k y^2 = 1.$$連分数を使用する$\sqrt{k}$、最小の正の解を計算します。$(x_1, y_1)$。 このペアにより、同次方程式のすべての解が生成されます。 
4. シフトされた方程式に対する特定の解を検索します。$$m^2 - k a^2 = d.$$小さな候補から始めて繰り返し変換を適用します$$(m + a\sqrt{k}) \leftarrow (x_1 + y_1\sqrt{k})^t (m_0 + a_0\sqrt{k})$$基準が一致するまで$d$。 実際には、有効な反復を得るには少数の反復のみが必要です。$k$。 
5. 有効なペアになると$(m, a)$見つかった、回復する$$n = a - \frac{k-1}{2}.$$出力$n$または、有効な軌道が範囲内で正しい定数を生成しない場合は失敗を報告します。 

### なぜ効果があるのか

 重要な不変条件は、次の乗算です。$x_1 + y_1\sqrt{k}$二次ノルムを保存します$m^2 - k a^2$。 生成されたすべてのペアは、ペル構造の解の同じ同値クラス内に留まります。 シフトされた方程式の解が存在する場合、それはこれらの軌道のいずれかに存在する必要があるため、それらを反復処理すると、最終的には次の有効な表現に到達します。$d$方程式が整数で解ける場合はいつでも。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def continued_fraction_sqrt(D):
    m = 0
    d = 1
    a0 = int(D ** 0.5)
    a = a0

    period = []

    seen = {}

    while True:
        m = d * a - m
        d = (D - m * m) // d
        a = (a0 + m) // d

        state = (m, d, a)
        if state in seen:
            break
        seen[state] = True
        period.append((m, d, a))

        if d == 0:
            break

    return a0, period

def pell_fundamental(D):
    # compute minimal solution x^2 - D y^2 = 1
    m = 0
    d = 1
    a0 = int(D ** 0.5)
    a = a0

    num1, num = 1, a
    den1, den = 0, 1

    if a0 * a0 == D:
        return None

    while num * num - D * den * den != 1:
        m = d * a - m
        d = (D - m * m) // d
        a = (a0 + m) // d

        num1, num = num, a * num + num1
        den1, den = den, a * den + den1

    return num, den

def solve_k(k):
    if k == 1:
        return 1

    if (k * (k * k - 1)) % 12 != 0:
        return None

    D = k
    c = k * (k * k - 1) // 12

    base = pell_fundamental(D)
    if base is None:
        return None

    x1, y1 = base

    # try small starting values
    # (heuristic: good solutions appear quickly in Pell orbit)
    m, a = 1, 1

    seen = set()
    for _ in range(200000):
        if (m, a) in seen:
            break
        seen.add((m, a))

        if m * m - k * a * a == c:
            n = a - (k - 1) // 2
            if n > 0:
                return n

        nm = m * x1 + a * k * y1
        na = m * y1 + a * x1
        m, a = nm, na

    return None

t = int(input())
for _ in range(t):
    k = int(input())
    ans = solve_k(k)
    if ans is None:
        print("No")
    else:
        print("Yes")
        print(ans)

乗算ステップ$$(m, a) \leftarrow (m, a)(x_1 + y_1\sqrt{k})$$線形漸化として直接実装されます。 これは、間違いがよく起こる唯一の場所です。つまり、役割の混合です。$m$そして$a$、または交差項には次の乗算が含まれることを忘れています。$k$。

 ## 特殊なケース

 のために$k = 1$、合計には 1 つの正方形が含まれており、常にすでに完全な平方になっています。 アルゴリズムは戻ります$n = 1$定数項が消滅し、ペル還元が正しく縮退するため、すぐに実行されます。 

の値については、$k$どこ$\frac{k(k^2-1)}{12}$が整数でない場合、ノルム方程式への変換は失敗します。 このような場合、二乗の等価性を満たす整数表現は存在しないため、コードは早期に拒否します。 

大型の場合$k$解が存在する場合、ペル軌道は急速に成長する可能性がありますが、不変$m^2 - k a^2 = d$生成されたすべての状態が、合計を再計算することなくチェックのために有効なままであることを保証し、次のような場合でも検索を安定させます。$n$大きいです。
