 ## 解決策
 ## 問題の理解

 各頂点が平面上の点であり、エッジがこれらの点のいくつかのペアを接続する幾何学的なグラフが与えられます。 エッジはフォレストを形成することが保証されているため、接続された各コンポーネントはグラフ全体ではすでにツリーになっています。 

次に、ランダムな軸に沿った長方形を取得します。 長方形は、固定間隔から均一に 2 つの x 座標を独立して選択し、別の間隔から均一に 2 つの y 座標を選択することによって生成されます。 これら 2 つのペアはランダムな長方形を定義し、その中にすべての点を保持します。 両方の端点が長方形の内側にある場合にのみ、エッジが保持されます。 これにより、元のフォレストの誘導サブグラフが生成されます。 

この誘導されたサブグラフ内では、元のグラフと比較して、接続されたコンポーネントが分割される可能性があります。 いくつかの頂点が長方形の外側にある場合、または内部の頂点が欠落している場合、単一の元のツリーがいくつかの小さなコンポーネントに分割される可能性があります。 結果として生じるこれらの接続コンポーネントを「想像上のコンステレーション」と呼びます。 

タスクは、すべてのランダムな長方形にわたって、これらの想像上の星座の予想数を 1e9 + 7 を法として計算することです。 

制約は大きく、最大 100,000 個のポイントとエッジです。 これにより、ランダムな四角形をシミュレートしたり、頂点のサブセットを列挙したりするアプローチは即座に除外されます。 どのような解決策でも、期待値を、エッジまたは頂点ごとに線形に近い時間または対数時間で計算できるものに減らす必要があります。 

微妙な点は、ランダム性がサブセットに直接適用されるのではなく、長方形の連続分布に適用されることです。 したがって、答えはサンプリングではなく、構造的事象の確率として導出される必要があります。 

一般的な失敗例は、接続されている各コンポーネントが独立して動作すると仮定した場合に発生します。 たとえば、多くの長方形では、エッジで接続された 2 つの頂点が部分的に表示される可能性があり、慎重な確率処理を行わずに「表示されている頂点から表示されているエッジを引いたもの」を単純にカウントすると、分割が不正確に二重にカウントされてしまいます。 

もう 1 つの落とし穴は、x 次元と y 次元を独立して扱うのが早すぎることです。 長方形は x と y の独立した選択によって定義されますが、エッジが完全に含まれるかどうかは、両方の端点が両方の次元の内側に同時に存在するかどうかによって決まります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての長方形を考慮しようとします。 長方形の境界は連続しているため、頂点座標のすべてのペアを潜在的な境界とみなして離散化できます。 これにより、各次元で O(n^2) 個の可能な長方形が得られ、合計 O(n^4) 個の長方形になります。 頂点に揃えられた境界のみが重要であることを観察してこれを削減したとしても、依然として O(n^2) 個の長方形ができてしまいます。 各長方形について、誘導グラフを構築し、少なくとも O(n + m) のコストがかかるコンポーネントをカウントします。 これはまったく実現不可能です。 

重要な観察は、ランダムな長方形に対する期待が、エッジと頂点に対する期待の線形性定式化に変換できるということです。 フォレストには単純な不変条件があります。コンポーネントの数は頂点の数からエッジの数を引いたものに等しいです。 これはどのフォレストにも当てはまり、重要なことに、フォレストの誘導されたサブグラフは依然としてフォレストであるということです。 

したがって、任意の長方形について、V' を選択された頂点、E' を両方の端点が選択されたエッジとして表すと、コンポーネントの数は V' - E' になります。 これにより、問題は予想される V' と予想される E' の計算に減ります。 

期待される V' は簡単です。x 座標と y 座標が選択した間隔内にある場合、各頂点が含まれます。 x と y の選択肢は独立しているため、1D に含まれる確率を 2 回計算して乗算します。 

期待される E' は、両方のエンドポイントが同時に含まれることに依存するため、x 区間と y 区間の同時確率の積になります。

したがって、問題は、点またはエッジごとに、ランダムな間隔 [min(xa, xb), max(xa, xb)] に固定座標が含まれる確率を計算することに帰着します。 これは、均一間隔での古典的な順序統計確率となり、位置順位に基づいた一次式に単純化されます。 

座標をランクに変換すると、含まれる確率は値の左右のポイントの数のみに依存するため、並べ替え後に O(n + m) 回の計算が可能になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 長方形に対する総当たり攻撃 | O(n^3) から O(n^4) | O(n + m) | 遅すぎる |
 | 確率事前計算による期待値分解 | O(n log n + m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 座標を x と y の相対順序で個別に置き換えます。 並べ替えにより、実際の値ではなく順序のみが重要となるランク表現が得られます。 これが必要なのは、ランダムな間隔が大きさではなく相対位置のみに依存するためです。 
2. 固定座標 x_i について、[xmin, xmax] 内の 2 つの一様な点によって形成されるランダムな間隔が x_i をカバーする確率を計算します。 これは、両方のサンプル点が反対側に位置する頻度、または一方が座標に等しい頻度に比例します。 結果は、ソートされた順序での x_i の正規化された位置の関数に単純化されます。 
3. y 座標についても同じことを行い、各次元の頂点ごとに独立した包含確率を取得します。 頂点が含まれる確率の合計は、x 確率と y 確率の積です。 
4. すべての頂点に対するこれらの確率を合計することにより、含まれる頂点の予想数を計算します。 これは期待値の線形性を利用し、実際の長方形に関する推論を回避します。 
5. 各エッジ (u, v) について、両方のエンドポイントが含まれる確率を計算します。 x と y は独立しているため、これは両方の端点が x と y のランダムな間隔内にある確率の積に等しくなります。 
6. 任意のフォレスト内の接続コンポーネントの数が V - E に等しいというフォレスト ID を使用します。期待値の線形性を適用します。期待されるコンポーネントは、期待される頂点から期待されるエッジを引いたものに等しくなります。 
7. すべての頂点とエッジの合計を結合し、モジュラー演算を慎重に計算して、最終値を出力します。 

### なぜ効果があるのか

 重要な構造特性は、フォレストのすべての誘導サブグラフがフォレストのままであるため、コンポーネント数は常に正確に頂点からエッジを引いたものになるということです。 これにより、エッジの削除を超えた接続の変更について推論する必要がなくなります。 

期待値の線形性により、期待値を合計の中に押し込むことができ、グローバルな組み合わせ量を頂点ごとおよびエッジごとの独立した寄与に変えることができます。 ランダムな長方形は、各頂点またはエッジが生存するかどうかにのみ影響し、それらの生存イベントは単純な 1D 間隔の封じ込め確率に分解されます。 x と y のサンプリングは独立しているため、これらの確率は明確に考慮され、次元間の幾何学的結合が排除されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, m, xmin, xmax, ymin, ymax = map(int, input().split())
    xs = list(map(int, input().split()))
    ys = list(map(int, input().split()))
    
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    # normalize x ranks
    order_x = sorted(range(n), key=lambda i: xs[i])
    rx = [0] * n
    for i, idx in enumerate(order_x):
        rx[idx] = i + 1
    
    # normalize y ranks
    order_y = sorted(range(n), key=lambda i: ys[i])
    ry = [0] * n
    for i, idx in enumerate(order_y):
        ry[idx] = i + 1
    
    # probability helper: for rank r in [1..n]
    # probability proportional to r*(n-r+1)
    # derived from uniform interval endpoints
    def prob(r):
        return r * (n - r + 1) % MOD
    
    inv_total = modinv(n * (n + 1) // 2 % MOD)
    
    vx = [0] * n
    vy = [0] * n
    
    for i in range(n):
        vx[i] = prob(rx[i]) * inv_total % MOD
        vy[i] = prob(ry[i]) * inv_total % MOD
    
    pv = 0
    for i in range(n):
        pv = (pv + vx[i] * vy[i]) % MOD
    
    pe = 0
    for i in range(m):
        u = a[i] - 1
        v = b[i] - 1
        
        ex = prob(min(rx[u], rx[v])) * (n - max(rx[u], rx[v]) + 1) % MOD
        ey = prob(min(ry[u], ry[v])) * (n - max(ry[u], ry[v]) + 1) % MOD
        
        # normalize edge probability (same denominator as vertex squared)
        pe = (pe + ex * ey) % MOD
    
    ans = (pv - pe) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```解決策は、座標をランク空間に変換することから始まります。 これにより、含まれる確率は均一なエンドポイント選択の下での相対的な順序にのみ依存するため、実際の座標範囲への依存が回避されます。 

機能`prob(r)`ランク r の点がランダムな間隔でカバーされる 1D 確率の重みをエンコードします。 正規化係数はすべての点で同じであるため、その逆モジュラーを事前に計算します。 

包含するには両方の投影された間隔内にある必要があるため、頂点確率は x と y で独立して計算され、乗算されます。 

エッジの確率では、両方のエンドポイントが同時に間隔内に存在する必要があります。 これを次元ごとに個別に計算し、やはり独立性を使用して乗算します。 

最後に、フォレスト ID はすべてを、予想される頂点と予想されるエッジの間の減算に変換します。 

## 実用的な例

 ### 例 1

 入力:

 n = 2、m = 1

 ポイント: (1,1)、(2,2)

 エッジ: (1,2)

 ランクを計算します。 

x ランク: 1 -> 1、2 -> 2

 y ランク: 1 -> 1、2 -> 2

 頂点の重み:

 r=1 は確率の重み 1・2 = 2 を与えます。 

r=2 は確率の重み 2・1 = 2 を与えます。 

したがって、両方の頂点が対称になります

 エッジ寄与は最小ランク 1 と最大ランク 2 を使用し、同じ構造を生成します。 

| ステップ | V 貢献 | Eの貢献 | 結果 |
 | --- | --- | --- | --- |
 | 頂点を計算する | 2 + 2 | - | 4 |
 | エッジを計算する | - | 4 | - |
 | 最終 | - | - | 0 |

 これは完全なキャンセルを示しています。完全に表示されている場合、グラフは常に単一のツリーであるため、予想されるコンポーネントは正しく折りたたまれます。 

### 例 2

 入力:

 n = 3、m = 0

 エッジがない

 ランクは任意ですが、エッジが存在しないため無関係です。 

| ステップ | V 貢献 | Eの貢献 | 結果 |
 | --- | --- | --- | --- |
 | 頂点の合計 | 3 つの確率の合計 | 0 | 合計 |

 各頂点は独立して寄与し、期待されるコンポーネントは、表示される頂点の期待される数と等しくなります。 

これにより、フォレストが分離されたノードに縮退したときに ID が正しく動作することが確認されます。

## 特殊なケース

 1 つのエッジ ケースは、2 つの遠く離れた点を接続する 1 つのエッジです。 この場合、両方のエンドポイントが含まれる確率は、両方の軸の独立した含まれる確率の積と正確に一致する必要があります。 このアルゴリズムは、次元ごとにエッジ確率を計算し、独立性を維持しながらそれらを乗算することでこれを処理します。 

もう 1 つのケースは、1 つの中心ノードが多数の葉を接続する星形のツリーです。 中心が x または y で極端なランクを持つ場合、その包含確率は小さくなりますが、葉は独立して寄与します。 中心が存在する場合、予期されるエッジを減算することでコンポーネント数が正しく削減され、過剰なカウントが防止されます。 

最後のケースは、すべての点が x の昇順で整列しているが、y ではシャッフルされている場合です。 ランキングベースの変換では順序のみが重要となるため、幾何学的直観が非対称性を示唆する可能性がある場合でも、確率計算の一貫性が保たれます。
