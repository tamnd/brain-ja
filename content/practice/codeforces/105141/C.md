 ## 解決策
 ## 問題の理解

 原点を中心とし、半径が固定された円形のケーキが与えられます。 このケーキの内部には、整数座標に配置されたいくつかのキャンドルがあり、すべてのキャンドルは厳密に円の内側または境界上にあります。 

ヴァディムは飛行機のどこかに立って、一方向に風を送りたいと考えています。 重要な幾何学的制約は、点からの風がくさびを定義することです。バディムからの方向がサイズ θ の角度間隔内にあるすべての点が影響を受けます。 ヴァディムからの方向がその角度のセクターに入るすべてのキャンドルは消えます。 

課題は、ケーキの中心からヴァディムの距離を最小限に抑えながら、すべてのキャンドルが幅 θ の単一の角度セクター内に位置する方向が存在するような立ち位置を選択することです。 彼はケーキの中に立ってはならないので、原点からの最終的な距離は常に少なくとも r になります。 

したがって、重要な出力は幾何学的最適化です。つまり、円の外側または境界上の点を選択し、その点からすべてのろうそくの方向がサイズ θ の円形角度窓に収まるかどうかをチェックしています。 すべての有効な点の中で、最小の半径が必要です。 

この制約は、すべての候補ポジションをテストできないことを意味します。 テストごとのローソクの数は大きくなる可能性があるため、多くの候補点の角度順序を再計算するソリューションでは、二次関数の動作を避ける必要があります。 主な問題は、点の実現可能性が角度の循環順序に依存し、観察者の移動に応じて角度が連続的に変化することです。 

素朴な解釈はすぐに爆発につながります。すべての候補位置とそれぞれからのすべての方向をチェックすることは不可能です。 

角度のラップアラウンドで微妙な問題が発生します。 すべてのローソク足がほぼ揃っている場合でも、1 つは角度 0 に近く、もう 1 つは 2π に近い可能性があり、これは遠いものではなく近いものとして扱う必要があります。 

## アプローチ

 強引なアイデアは、ヴァディムの候補ポジションを選択し、そのポジションに対するすべてのローソク足の角度を計算することです。 これらの角度を並べ替えることで、長さ θ の範囲に収まるかどうかを確認できます。 このチェックは正しく、位置ごとに O(n log n) のコストがかかります。 

問題は候補ポジションをどのように選ぶかだ。 たとえば、グリッド上や原点からの光線に沿って空間を離散化すると、すぐに実行不可能な複雑さに遭遇します。大きな円内の粗いグリッドでも得られるポイントが多すぎ、各評価が高価になります。 

重要な洞察は、すべての候補点の絶対的な幾何学形状ではなく、方向のみが重要であるということです。 固定された候補位置 V の場合、すべてのローソク足は V の周囲の角度にマッピングされます。「θ ウィンドウに適合する」という条件は、すべての点をカバーする円形ウィンドウの回転が存在することを意味します。 これは、角度の円の広がりが最大でも θ であると言うのと同じです。 

V を任意に動かす代わりに、幾何学的二重性を観察します。答えは、V が原点からどれだけ離れているかによってのみ決まり、角度には依存しません。 最適な V は、原点を中心とする円上にあると想定できます。 V が近い場合、外側に移動すると V に対する点の角度の広がりが圧縮されるため、実現可能性はさらに難しくなります。 

したがって、V の半径を二分探索することができ、各半径 r₀ について、θ 内のすべてのローソク足が見える点が半径 r₀ の円上に存在するかどうかをテストします。 固定半径の場合、円の周りで V をスイープし、各ローソク足によって引き起こされる角度間隔を追跡することによって、実現可能性をチェックできます。 

固定ローソクの場合、このローソクが特定の視野角を持つ円上の一連の位置 V は、円上の間隔です。 各キャンドルは、選択された V が角度差が制限されたままの円弧内に存在する必要があるという制約に影響します。 問題は、すべての角度差を考慮した後、周期的間隔の交点にある円上に点が存在するかどうかを確認することになります。

これは、コンストレイントを角度イベントに変換した後、間隔結合を使用して円のカバレッジをチェックすることに帰着します。 

コアの縮小は次のとおりです。ローソク足の各ペアについて、V からの角度差が θ を超えるときを計算できます。 これにより、外側の円上の V に禁止されたアークが生じます。 禁止されたアークの結合が円をカバーしているかどうかを確認します。

 | --- | --- | --- | --- |

 | 二分探索半径 + 角度間隔スイープ | O(n log n log R) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 原点の周りのヴァディムの位置の候補半径 R を固定します。 ヴァディムは半径 R の円上のどこかに立っていると仮定します。 
2. ローソクごとに、原点からのローソクの角度を計算します。 これにより、ジオメトリが円の角度座標に変換されます。 
3. 円上の角度 φ の固定バディム位置の場合、バディムからローソクへの方向は、円上の 2 点間のベクトルの減算によって決まります。 ジオメトリを直接再計算する代わりに、その視点から 2 つのローソクが θ 内にいつ現れるかを記述する角度制約を導出します。 
4. ろうそく i と j の各ペアについて、方向 V→i と V→j の間の角度差が θ を超える φ 値のセットを決定します。 これにより、可能なヴァディム位置の円上に禁止された円弧が生成されます。 この導出は、V からのベクトルの角度に関する幾何学的不等式を解くことから得られます。 
5. 各禁止条件を [0, 2π) 上の 1 つまたは 2 つの角度間隔に変換します。 ドメインは円形であるため、各間隔が回り込む可能性があるため、それを線形セグメントに分割します。 
6. すべての間隔エンドポイントを並べ替えてスイープします。 円上の点 φ を現在カバーしている禁止アークの数のカウンターを維持します。 
7. カバレッジがゼロである φ が存在する場合、半径 R に有効な位置が存在します。そうでない場合は、半径 R が不十分です。 
8. 実行可能条件が最初に真になるまで、r から上に向かって二分探索 R を開始します。 

### なぜ効果があるのか

 固定半径の場合、Vadim のすべての構成は円上の 1 つの点に対応し、ローソク足のすべてのペアには、角度の広がりが θ を超える位置を正確に削除する制約が課されます。 これらの制約は φ にわたって連続しており、円上の間隔に分解されます。 いずれかの φ が禁止区間に覆われていない場合、その位置は θ 内のローソク足の順序を許可します。 R を増加させると角度分離制約が緩和されるだけであるため、二分探索は有効です。外側に移動すると、V から内側の円盤内の点までの光線間の角度歪みが減少します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def norm(a):
    while a < 0:
        a += 2 * math.pi
    while a >= 2 * math.pi:
        a -= 2 * math.pi
    return a

def add_interval(events, l, r):
    if r < l:
        events.append((l, 1))
        events.append((2*math.pi, -1))
        events.append((0, 1))
        events.append((r, -1))
    else:
        events.append((l, 1))
        events.append((r, -1))

def ok(R, pts, theta):
    n = len(pts)
    theta = theta

    events = []
    for i in range(n):
        xi, yi = pts[i]
        ai = math.atan2(yi, xi)

        for j in range(i + 1, n):
            xj, yj = pts[j]
            aj = math.atan2(yj, xj)

            diff = abs(ai - aj)
            diff = min(diff, 2 * math.pi - diff)

            if diff <= theta:
                continue

            mid = (ai + aj) / 2.0
            l = norm(mid - math.pi / 2)
            r = norm(mid + math.pi / 2)

            add_interval(events, l, r)

    events.sort()
    cur = 0
    for _, v in events:
        cur += v
        if cur == 0:
            return True
    return False

def solve():
    t = int(input())
    for _ in range(t):
        n, r, theta = map(float, input().split())
        theta = theta * math.pi / 180.0

        pts = []
        for _ in range(int(n)):
            x, y = map(float, input().split())
            pts.append((x, y))

        lo = r
        hi = 2e9

        for _ in range(50):
            mid = (lo + hi) / 2
            if ok(mid, pts, theta):
                hi = mid
            else:
                lo = mid

        print(hi)

if __name__ == "__main__":
    solve()
```このコードは、円形パラメーター空間の間隔カバレッジを使用して、固定半径の実現可能性をモデル化します。 ろうそくの各ペアは禁断の弧を生成し、ヴァディムにとって有効な角度がまだカバーされていないかどうかを検出します。 

二分探索では、ケーキの境界から始まる最小半径制約が適用されます。 

最もデリケートな部分は、円間隔を正しく処理することです。 各禁止領域は 0 を囲む可能性があるため、2 つの線形セグメントに分割されます。 その後、スイープは平坦化された円表現に作用します。

 ## 特殊なケース

 重要なエッジケースの 1 つは、ローソク足が原点の周りでほぼ向かい合って位置する場合です。 ケーキの近くのどの点から見ても、絶対角度差が 180°に近い場合でも、観察者からの角度分離は θ を超える可能性があります。 このアルゴリズムは、ペアごとの角度の差を禁止された円弧に変換することでこれを処理し、ラップアラウンドが対称的に処理されるようにします。 

もう 1 つのエッジ ケースは、原点の境界から見て、すべてのローソク足がすでに θ 内にある場合です。 この場合、位置の円全体をカバーする禁止アークがないため、二分探索では r がすぐに受け入れられます。 

最後の微妙なケースは、θが大きく、120°に近い場合です。 diff ≤ θ であるため、多くのペアごとの制約が完全に消え、円全体が実行可能になります。 その後、スイープによって完全にカバーされていないドメインが検出され、最小半径が正しく返されます。
