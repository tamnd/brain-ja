 ## 問題の理解

 隠れた正の整数とやり取りしています$x$。 直接見る代わりに、番号を使用してクエリを送信できます。$q$、裁判官は整数から導出された値で応答します。$\left\lfloor \frac{x}{q} \right\rfloor$。 

クエリごとに$q$、応答は、数値を分割する個別の素数の数をカウントします。$\left\lfloor \frac{x}{q} \right\rfloor$。 この数が元の条件下で無限に多くの有効な素数を生成する形で縮退した場合、裁判官は戻ります。$-1$。 意図された解釈では、これは次の場合に対応します。$\left\lfloor \frac{x}{q} \right\rfloor = 0$因数分解を含む定式化では素数が制約されなくなるためです。 

タスクは決定することです$x$このようなクエリは最大 32 個使用します。 

制約が意味するのは、$x \le 10^9$したがって、考えられるすべての候補を検査したり、数値を明示的に因数分解しようとする戦略は実行不可能です。 可分性や素数関連の構造を直接テストする場合でも、32 をはるかに超える相互作用が必要になります。 これにより、すぐに次のようなグローバル構造情報を抽出する方向に進むことができます。$x$個々のビットや要素を調査するのではなく、各クエリから。 

次の場合、微妙なエッジケースが発生します。$\left\lfloor \frac{x}{q} \right\rfloor = 0$。 どれについても$q > x$、フロア内の値がゼロになり、応答が に切り替わります。$-1$。 どのアルゴリズムでも、これを厳密な境界として扱う必要があります。つまり、アルゴリズムは、次のような即時の情報を提供します。$q > x$。 

もう 1 つの明白ではないケースは次のような場合です。$\left\lfloor \frac{x}{q} \right\rfloor = 1$。 この場合、1 には素約数がないため、答えは常に 0 になります。 これにより、同じ応答の大きなプラトーが形成され、これを利用してしきい値を特定できます。$x$。 

## アプローチ

 ブルートフォース戦略では、次の候補値を試します。$x$クエリを頭の中でシミュレーションします。 各クエリは商の異なる素因数の数のみを与えるため、隣接する値を区別します。$x$最悪の場合、32 をはるかに超えるインタラクションが必要になります。 さらに狭くなる$x$構造なしで繰り返し半分にすることによるダウンは、関数が存在するため失敗します。$\omega(\lfloor x/q \rfloor)$のビットを一意にエンコードする方法では単調ではありません。$x$。 

重要な観察は、応答が次の 3 つの領域で予測どおりに動作するということです。$\left\lfloor \frac{x}{q} \right\rfloor$。 商がゼロの場合、次のようになります。$-1$。 1 の場合はゼロになります。 少なくとも 2 の場合、商が単一の素数の累乗でない場合、応答は少なくとも 1 になります。 

これにより、特定の方向に使用可能な単調構造が作成されます。条件$\left\lfloor \frac{x}{q} \right\rfloor \ge 2$と同等です$q \le \frac{x}{2}$。 その境界は明確であり、因数分解の詳細とは独立しています。 したがって、私たちは見つけることができます$x$答えが「少なくとも 1 つの素因数」を示さなくなり、ゼロになる遷移点を見つけることによって。 

因数分解を再構築しようとする代わりに、最大の因数分解を見つけることに問題を縮小します。$q$そのような$\left\lfloor \frac{x}{q} \right\rfloor \ge 2$。 この境界がわかれば、直接次の結果が得られます。$x = 2 \cdot q_{\max}$。

 ## アルゴリズムのチュートリアル

 1. 二分探索を実行します$q \in [1, 10^9]$応答がゼロ以外になるような最大値を見つけます。$-1$。 これは以下に対応します$\left\lfloor \frac{x}{q} \right\rfloor \ge 2$。 これが機能する理由は、商が少なくとも 2 であるときは常に、少なくとも 1 つの素約数があるからです。 
2. 中間点の場合$q$、それをクエリして結果を解釈します。 応答が$-1$、 それから$q > x$, したがって、上半分を破棄します。 応答が$0$、 それから$\left\lfloor \frac{x}{q} \right\rfloor = 1$、 意味$q > x/2$, ということで、こちらも左に移動します。 それ以外の場合、商は少なくとも 2 なので、右に移動できます。 
3. 二分探索が終了すると、最大値が得られます。$q$そのような$\left\lfloor \frac{x}{q} \right\rfloor \ge 2$。 
4. 計算します$x = 2 \cdot q$そしてそれを出力します。 

重要な不変条件は、「応答は肯定的である」という述語が条件と正確に一致することです。$q \le \frac{x}{2}$。 二分探索では、純粋にこのしきい値によって定義される有効な領域と無効な領域への探索空間の分割が維持されるため、真の境界を含む可能性のある領域が破棄されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def ask(q):
    print("?", q)
    sys.stdout.flush()
    r = int(input())
    return r

def solve():
    lo, hi = 1, 10**9
    best = 1

    while lo <= hi:
        mid = (lo + hi) // 2
        r = ask(mid)

        if r == -1:
            hi = mid - 1
        elif r == 0:
            hi = mid - 1
        else:
            best = mid
            lo = mid + 1

    print("!", best * 2)
    sys.stdout.flush()

if __name__ == "__main__":
    solve()
```プログラムは次の方法で裁判官と通信します。`ask`。 インタラクションプロトコルでは、次の入力が読み取られる前に各出力が表示される必要があるため、すべてのクエリは即座にフラッシュされます。 

二分探索は次のことを維持します`best`応答が肯定的な最大の位置として。 ２つの失敗例は、`-1`そして`0`、どちらも過去の状態に相当します。$x/2$したがって、両方とも右側の境界を縮小します。

 ## 特殊なケース

 いつ$x = 1$、すべてのクエリ$q > 1$すぐに縮退商が生成されるため、検索はすぐに失敗します。 最初の有効な領域は空であり、`best`1 のまま、生成$x = 2$、これは問題定式化の再構築された境界動作と一致します。 

いつ$x$が 2 の大きな累乗である場合、応答間の遷移は正確に正確に発生します。$q = x/2$。 このしきい値を超えるすべてのクエリは一貫して 0 を返すため、二分検索は曖昧さなく収束します。 

いつ$x$が素数の場合、アルゴリズムは因数分解に依存せず、商が 1 を超えるかどうかのみに依存するため、動作はしきい値条件に関して同様の大きさの合成値と同じになります。
