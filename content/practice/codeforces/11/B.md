 ## 解決策
 ## 問題の理解

 ジャックはその位置からスタートします`0`数直線上で。 彼のジャンプの長さは固定されています。最初のジャンプには長さがなければなりません`1`、2番目のジャンプの長さ`2`、3番目のジャンプの長さ`3`、 等々。 ジャンプするたびに、どちらかの方向を選択できます。 課題は、正確な位置に着地するために必要な最小限のジャンプ数を見つけることです。`x`。 

方向性の選択が興味深い部分です。 後`k`ジャンプの場合、移動距離の合計は常に次のようになります。$1+2+3+\dots+k=\frac{k(k+1)}{2}$私たちが制御できる唯一のことは、どのジャンプがポジティブでどのジャンプがネガティブであるかです。 

入力サイズは最大です`10^9`これにより、位置に対する状態空間検索が即座に除外されます。 到達可能な座標に対する幅優先検索は爆発的に発生します。`k`ジャンプはあります`2^k`方向性の選択。 平`k = 40`すでに1兆以上の可能性を生み出しています。 

三角数は二次関数的に増加するため、答え自体は小さいままです。 周囲の距離に到達するには`10^9`、大まかに必要なものは次のとおりです。$\frac{k(k+1)}{2}\approx 10^9$それは与える`k ≈ 44721`。 つまり、`O(sqrt(x))`溶液は完全に安全です。 

ネガティブな目標は間違いを犯しやすいものです。 左右のジャンプのすべてのシーケンスをミラーリングできるため、問題はゼロの周りで対称になります。 到達`-5`到達するのと同じ回数のジャンプが必要です`5`。 負の値を個別に扱う不用意な実装は、不必要な複雑さを引き起こす可能性があります。 

もう 1 つの微妙なケースは、累積合計が最初に目標を上回ったものの、パリティが間違っている場合に発生します。 たとえば:

 入力:```
2
```2回ジャンプした後の合計距離は、`1 + 2 = 3`。 私たちには作れません`2`ジャンプの方向を変更すると、最終的な位置がジャンプの長さの 2 倍だけ変更されるためです。 違い`3 - 2 = 1`は奇数であるため、ジャンプのサブセットでは修正できません。 もう 1 回ジャンプする必要があるので、合計を計算すると、`6`、そして今`6 - 2 = 4`は偶数なので、答えは次のようになります`3`。 

2 番目のパリティ トラップは次のとおりです。 

入力:```
5
```3回ジャンプした後の合計は`6`、すでに超えています`5`、 しかし`6 - 5 = 1`奇数です。 4 回ジャンプした後の合計は次のようになります`10`、 そして`10 - 5 = 5`まだ奇妙です。 5回ジャンプして初めて得られるのは、`15 - 5 = 10`、これは偶数です。 正しい答えは、`5`、 ない`3`または`4`。 

## アプローチ

 ブルートフォースのアイデアは単純です。 ジャンプ時`i`、左または右のいずれかを選択し、再帰的に続行します。 後`k`ジャンプはあります`2^k`可能なパス。 この方法は、法的な一連の指示をすべて調査するため正しいものですが、すぐに役に立たなくなります。 だけでも`40`飛躍的に、検索空間は 1 兆の州を超えます。 

重要な点は、符号付きの合計のみが重要であるということです。 後だと仮定します`k`ジャンプの総距離は次のとおりです。$S=1+2+\dots+k$最初にすべてのジャンプが右に行くと想像すると、次のように着地します。`S`。 一定の長さのジャンプを反転する`d`反対方向に移動すると、最終位置が次のように変化します。`2d`、そのジャンプが貢献するからです`+d`の代わりに`-d`。 

したがって、その後の到達可能なすべての位置`k`ジャンプの形式は次のとおりです。$S-2t$どこ`t`ジャンプ長の一部の合計です。 

これにより、到達するために必要な 2 つの条件が即座に得られます。`x`。 

初め、`S`少なくとも`|x|`そうでない場合は、単純に全体的な動きが不十分です。 

2番、`S - |x|`等しいので偶数でなければなりません`2t`。 

素晴らしいのは、これらの条件も十分に満たされているということです。 数字以来`1,2,3,...,k`からあらゆる値を形成できます`0`に`S`、偶数の差は、ジャンプの適切なサブセットを反転することで修正できます。 

これにより、問題は最小のものを見つけることに減ります`k`次のような:$\frac{k(k+1)}{2}\ge |x|$そして$\left(\frac{k(k+1)}{2}-|x|\right)\bmod 2=0$単純に増加し続けることができます`k`両方の条件が成立するまで。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^k) | O(k) | 遅すぎる |
 | 最適 | O(sqrt(x)) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 目標位置を読み取る`x`。 
2. 交換する`x`と`abs(x)`。 到達`-x`到達するのと同じ回数のジャンプが必要です`x`すべての方向を鏡に映すことができるからです。 
3.初期化`k = 0`そして`total = 0`。 ここ`k`これまでに使用されたジャンプの数、および`total`合計です`1 + 2 + ... + k`。 
4. 繰り返し増加する`k`1つずつ追加してください`total`。 
5. 更新するたびに、次の 2 つの条件を確認します。 

1.`total >= x`2.`(total - x) % 2 == 0`6. 両方の条件が true になったらすぐに停止します。 この時点で、ジャンプの一部のサブセットを反転して正確に生成できることがわかりました。`x`。 
7. 出力`k`。 

パリティ チェックは重要な洞察です。 ジャンプを反転すると、最終的な座標は偶数だけ変化します。`total`そして`x`均等でなければなりません。 

### なぜ効果があるのか

 後`k`ジャンプする場合、到達可能な最大座標は`total = 1 + 2 + ... + k`。 他の到達可能な座標は、いくつかのジャンプを反転することで取得され、反転されたジャンプごとに最終値が変更されます。`2d`。 つまり、到達可能な座標はすべて異なることになります。`total`偶数で。 

したがって、到達可能な位置は、次と同じパリティを持つ正確にすべての整数です。`total`間隔の中で`[-total, total]`。 

アルゴリズムは最初のものを検索します`k`どこ`x`この到達可能なセットの中にあります。 テストするので`k`昇順で、最初の有効な値が最小の答えになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

x = abs(int(input()))

k = 0
total = 0

while total < x or (total - x) % 2 != 0:
    k += 1
    total += k

print(k)
```この実装は数学的推論を直接反映しています。 

最初の行では、ターゲットを絶対値に変換します。 これにより、左右を別々に考える必要がなくなります。 の答えは、`-17`の答えと同じです`17`。 

変数`k`そして`total`現在のジャンプ数とそれらのジャンプ後の三角和を追跡します。 各反復では、次の必須ジャンプ長の追加をシミュレートします。 

ループ条件には、両方の必須プロパティが含まれています。 最初の部分では、ターゲットに到達するのに十分な距離を蓄積したかどうかを確認します。 2 番目の部分では、パリティの互換性をチェックします。 

よくある間違いは、すぐにやめてしまうことです。`total >= x`。 次のような場合には失敗します`x = 2`、 なぜなら`3`そして`2`パリティが異なります。 もう 1 つの間違いは、検証する前にパリティをチェックすることです。`total >= x`、不可能な状態を誤って受け入れる可能性があります。 

Python の整数は大きな値を自動的に処理するため、オーバーフローのリスクはありません。 固定幅の整数を使用する言語では、最大の三角和が近くに留まるため、32 ビットの符号付き整数でも十分です。`10^9`。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    import sys
    input = sys.stdin.readline

    x = abs(int(input()))

    k = 0
    total = 0

    while total < x or (total - x) % 2 != 0:
        k += 1
        total += k

    print(k)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided sample
assert run("2\n") == "3\n", "sample 1"

# minimum value
assert run("0\n") == "0\n", "already at origin"

# negative target
assert run("-2\n") == "3\n", "symmetry around zero"

# exact triangular number
assert run("6\n") == "3\n", "1+2+3 reaches target exactly"

# parity adjustment case
assert run("5\n") == "5\n", "needs extra jumps for parity"

# large boundary
assert run("1000000000\n") == "44723\n", "large input performance"
