 ## 解決策
 ## 問題の理解

 ジャックは、3 つの可能なアクションから構成される循環シーケンスを繰り返します。`L`左足のステップを意味し、`R`右足のステップを意味し、`X`1拍の間静止することを意味します。 軍曹は無限の交互パターンを期待しています。`L R L R L R ...`ジャックは、追加の挿入によってのみ元のサイクルを変更できます。`X`好きな場所に文字を配置できます。 既存のキャラクターを変更したり削除したりすることはできません。 変更後、結果のシーケンスは永久に繰り返されます。 

物理的な制限が 1 つあります。 2回連続非`X`サイクルのステップは足を交互に行う必要があります。 のようなシーケンス`RR`または`LL`なしで`X`その間は無効です。 シーケンスは循環しているため、最後と最初の非`X`行動も重要です。 

時間ごとに、ジャックのアクションと予想される交互のコマンドを比較します。 私たちは正しいビートの長期的な部分を可能な限り最大限にしたいと考えています。 

入力長は最大でも`10^6`、二次関数は即座に除外されます。 大きな定数係数を使用するリニア スキャンであっても、慎重に記述する必要があります。 に近いものが必要です`O(n)`または`O(n log n)`少数の配列のみを使用します。 

難しいのは、任意の数の一時停止を挿入できることです。 一見すると、これにより無限に多くの候補シーケンスが作成されます。 重要な観察は、一時停止はタイミングを変えるだけであり、新しいステップの方向を作成することはないということです。 最終的に、問題は循環バイナリ シーケンスのスケジューリング問題になります。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

考慮する：```
X
```ジャックはまったくステップを踏まないので、要求された条件に一致することは決してありません。`L`または`R`。 答えは次のとおりです。```
0.000000
```不注意な実装では、すべての一時停止を削除した後、ゼロで除算する可能性があります。 

ここで次のことを考えてみましょう。```
RR
```右足のステップが 2 つ隣接しているため、このシーケンスは物理的に無効です。 少なくとも 1 つを挿入する必要があります`X`彼らの間で。 一時停止を挿入した後、達成可能な最高の精度は次のとおりです。`0.500000`。 元のシーケンスがすでに有効であると仮定した解決策はナンセンスになります。 

もう 1 つの微妙なケースは、循環隣接です。```
LRR
```問題のあるペアは内部だけではありません`RR`。 変更後は、サイクルの最後のステップと最初のステップも相互作用します。 周期性を忘れると、多くの場合、不正確な答えが生じます。 

最後に、次のことを考慮してください。```
LXLXLX
```実際のステップはすべて左足ステップです。 いくらポーズを挿入しても、その一部を右足のステップに変えることはできません。 長期的に最高の精度はまだ`0.500000`。 最適な戦略は繰り返されるサイクルのグローバル パリティに依存するため、貪欲なローカル アライメントは失敗します。 

## アプローチ

 強引なアイデアは、ポーズを挿入するあらゆる方法を試してみることです。 候補サイクルを構築した後、正しい拍動の割合を推定するために十分な繰り返しをシミュレートします。 

挿入された一時停止はタイミング調整にのみ影響するため、これは概念的に機能します。 最終サイクルがわかっていれば、そのスコアの計算は簡単です。 

問題は、挿入の選択肢の数に制限がないことです。 挿入される一時停止の数を人為的に制限したとしても、状態空間は指数関数的に爆発的に増加します。 までの長さで`10^6`、総当たりは完全に絶望的です。 

画期的な進歩は、そうでないものだけに焦点を当てることからもたらされます。`X`ステップ。 

シーケンスからすべての一時停止を削除するとします。 以上の巡回シーケンスを取得します。`{L, R}`。 挿入された一時停止は、連続する実際のステップの間に経過する時間を決定するだけです。 これらのステップの順序は変更されません。 

軍曹は交互に足を永遠に続けることを期待しています。 つまり、ジャックの実際のステップはすべて、次のいずれかと比較されます。```
L R L R ...
```または```
R L R L ...
```現在の時間の等価性に応じて。 

一時停止を挿入すると、実際の各ステップがいつ発生するかを選択できるようになります。 ポーズは 1 ビートを消費するため、パリティが反転されます。 これは、サイクルに関する 1 つのグローバルな一貫性条件を除いて、各実際のステップが実行されるパリティを独立して決定できることを意味します。 

問題ははるかに単純になります。 すべての実際のステップは、期待されるパリティと一致することもあれば、一致しないこともあります。 マッチングにより 1 つの正しいビートが得られます。 一時停止は正確さに寄与しません。 

2 つの連続する実際のステップが等しい場合、マーチング パリティが正しく反転するように、それらの間に奇数のポーズを挿入する必要があります。 それらが異なる場合は、偶数の一時停止 (おそらくゼロ) が必要です。 

これにより、サイクル上でパリティ制約システムが自然に形成されます。 最大の分数を求めます。```
correct_steps / total_time
```分母は次のとおりです。```
number_of_real_steps + inserted_pauses
```目標の精度のために`p`、それが達成可能かどうかを尋ねることができます。 これにより、最適化が二分探索に変わります。 

実現可能性テストは、循環パリティ状態に関する最短パス形式の動的計画法問題になります。 少なくとも一定数の正しいステップを達成するために必要な、挿入される一時停止の最小数を計算します。 

代数を単純化した後、最適な戦略は、パリティ制約の下で一致を最大化することになります。これは、線形時間で DP を使用して貪欲に解くことができます。

 ## アルゴリズムのチュートリアル

 しましょう`s`元のシーケンスになります。 

まずは全部削除`X`文字。 残りの巡回シーケンスを呼び出します`t`。 

もし`t`は空で、ジャックは何も歩かないので、答えはすぐに得られます。`0.000000`。 

させて`m`の長さになる`t`。 

サイクル内のすべての隣接するペア (最後の文字と最初の文字を含む) について、次のように定義します。```
need[i] = 0 if t[i] != t[i+1]
need[i] = 1 if t[i] == t[i+1]
```

`need[i]`は、これら 2 つのステップ間に必要な一時停止の同等性を表します。 

ここで、実際の各ステップが発生するパリティについて考えてみましょう。 させて：```
p[i] = parity of the time position of step i
```ステップは次の場合に正確です。```
p[i] = 0 and t[i] = L
or
p[i] = 1 and t[i] = R
```連続する実際のステップ間:```
p[i+1] = p[i] xor need[i]
```奇数に挿入されたポーズはパリティを反転し、偶数の挿入されたポーズはパリティを保持するためです。 

一度選択すると、この反復によりすべてのパリティが決定されます`p[0]`。 

可能性は 2 つだけです。 

1. 仮定する`p[0] = 0`。 
2. 仮定する`p[0] = 1`。 

選択ごとに、サイクル全体に繰り返しを伝播し、最後に一貫性をチェックします。 

最終パリティが開始パリティと矛盾する場合、その開始選択は不可能です。 

それ以外の場合は、その割り当ての下で正しいステップの数を数えます。 

仮定する`good`手順は正しいです。 

必要なパリティ パターンを実現するには、次のものを正確に挿入します。```
sum(need)
```強制的な一時停止。 

追加の一時停止は常にペアで挿入できるため、比率が向上することはありません。 最適な分母は次のとおりです。```
m + sum(need)
```結果の精度は次のようになります。```
good / (m + sum(need))
```両方の有効な開始パリティの最大値を取得します。 

### なぜ効果があるのか

 挿入されたポーズはタイミング パリティのみを変更します。 実際の左右のステップの順序は永久に固定されます。 

2 つの連続する実際のステップでは、挿入された一時停止のパリティのみが問題になります。 連続する等しいフィートでは、次の実際のステップの前にパリティ フリップが必要ですが、異なるフィートではパリティの保存が必要です。 これにより、サイクル全体のパリティの進化が一意に決定されます。 

ステップのパリティが固定されると、そのステップが正しいかどうかが決定的になります。 追加の一時停止は追加の正しいビートを作成せずに合計時間を増やすだけであるため、最適な構築では常にパリティ制約を満たす最小の一時停止が使用されます。 

したがって、実行可能なすべてのマーチング パターンは、2 つの伝播されたパリティ割り当ての 1 つに正確に対応し、両方を評価することで最適なパターンが見つかります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()

    t = [c for c in s if c != 'X']

    if not t:
        print("0.000000")
        return

    m = len(t)

    need = []
    extra = 0

    for i in range(m):
        j = (i + 1) % m
        v = 1 if t[i] == t[j] else 0
        need.append(v)
        extra += v

    ans = 0.0

    for start in range(2):
        parity = start
        good = 0

        parities = [0] * m
        parities[0] = parity

        for i in range(1, m):
            parity ^= need[i - 1]
            parities[i] = parity

        final_parity = parities[-1] ^ need[-1]

        if final_parity != start:
            continue

        for i in range(m):
            expected = 'L' if parities[i] == 0 else 'R'

            if t[i] == expected:
                good += 1

        ans = max(ans, good / (m + extra))

    print(f"{ans:.6f}")

solve()
```最初のステップでは、既存の一時停止をすべて削除します。 これらは正確さに直接寄与することは決してないので、実際のステップの順序のみが重要です。`need[i]`連続する実ステップ間のパリティ条件を保存します。 同じフィートの場合は奇数の一時停止が必要ですが、異なるフィートの場合は偶数の一時停止が必要です。 

伝播ループは、選択された開始パリティによって暗示される一意のパリティ割り当てを再構築します。 シーケンスは周期的であるため、サイクル全体を通過した後のパリティが最初のパリティと再度一致することを確認する必要があります。 このチェックを忘れるのが最も一般的なバグです。 

分母は必須の一時停止のみを使用します。 一時停止を 2 つ追加すると、パリティと正確性のカウントが維持され、合計時間が増加するため、役に立ちません。 

この実装では、制約に快適に適合する線形スキャンと少数の配列のみを使用します。
