 ## 解決策
 ## 問題の理解

 各セルの色がすでに固定されているか、まだ決定されていないグリッドが与えられます。 最終的な目標は、未決定のすべてのセルに色を割り当て、結果として得られる完全に色付けされたグリッドに有効な 2 × 2 の「チェッカー」ブロックができるだけ多く含まれるようにすることです。 

2 × 2 ブロックは、その 4 つのセルが完全に交互のパターンを形成する場合、つまりチェス盤のように、反対側の角が同じ色を共有し、隣接するセルが異なる場合にスコアに貢献します。 有効な方向は正確に 2 つあり、それらは互いのグローバルな色を交換するだけです。 

重要な制約は、一部のセルはすでに固定されており変更できないため、グローバルなチェス盤の色を自由に選択できないことです。 代わりに、部分的な制約を、チェッカー パターンに一致する 2 × 2 サブグリッドの数を最大化する完全なカラーリングに拡張しようとしています。 

テスト ケースごとのグリッド サイズは最大 100 × 100 ですが、すべてのテスト ケースのセルの合計は最大 10^6 になります。 これにより、すべての割り当てに対してヘビーステートまたは正方形ごとのシミュレーションを使用して 2 × 2 正方形ごとに最適な選択肢を個別に再計算するものは即座に除外されます。これは、指数関数的または正方形ごとの組み合わせ推論が複数のテスト ケースの下で爆発するためです。 

固定セル強制がグローバル チェッカーボードと競合する場合、微妙なエッジ ケースが発生します。 たとえば、隣接する 2 つの固定セルがすでに同じ色に一致している場合、それらを含む 2 × 2 の 2 つのチェッカーの方向のうちの 1 つが局所的に壊れます。 単一のグローバル パターンを割り当て、グリッドごとに 1 回反転する単純なアプローチは、大きく失敗する可能性があります。 

入力:```
2 2
W W
W ?
```(1,1) で W で始まるチェッカーボードを選択すると、(1,2)=B が強制され、固定 W と矛盾します。反対のパターンを選択すると、同様に他の場所で制約が破られます。 正しいソリューションは、グローバルにコミットするのではなく、ローカルに適応する必要があります。 

もう 1 つの失敗例は、各「?」を個別に貪欲に割り当てることです。 各セルは最大 4 つの異なる 2 × 2 ブロックに参加するため、ローカルで貪欲な選択を行うと、複数の将来のチェッカーの寄与を一度に減らすことができます。これは、一度に 1 つの正方形だけを考慮する場合には目に見えません。 

## アプローチ

 ブルートフォース解釈では、「?」セルの可能なすべての割り当てが試行されます。 各割り当ては完全な色付けを定義し、チェッカー プロパティを満たす 2 × 2 ブロックの数を数えます。 k 個の色付けされていないセルの場合、これは 2^k 通りの可能性があり、最悪のレイアウトでは k はテストごとに 10^4 になる可能性があります。 テスト ケースが 1 つだけでも、これは完全に不可能になります。 

重要な構造的観察は、すべての 2 × 2 チェッカー条件がパリティのみに依存するということです。色を 0 と 1 と考えると、有効なチェッカー正方形は、向かい合う角が等しく、隣接する角が異なることを強制します。 これは、(i, j) の値が (i + j) パリティとグローバル 反転によって決定されると言うのと同じですが、固定された制約によりいくつかの正方形に違反することが許可されます。 

各セルを個別に決定する代わりに、視点を切り替えます。グローバルなパリティベースの色付けは 2 つだけであり、有効なローカル チェッカー スクエアはいずれもそれらの 1 つと一致する必要があります。 したがって、考えられる 2 つのチェス盤テンプレートのそれぞれについて、固定制約と既に競合しているセルの数を測定できます。 テンプレートが選択されたら、それに応じて残りのセルをすべて埋めて、そのテンプレートとの一貫性を最大限に高めます。 

ここで重要な単純化: 完全なチェス盤の色付けによって誘発されるチェッカー 2 × 2 マスの数は決定的かつ最大です。 完璧なチェッカーボードからの逸脱は、ローカルで有効な 2 × 2 ブロックの数を減らすため、最適な戦略は、固定セルに最もよく一致する 2 つのグローバル チェス盤の色のうち良い方を選択し、その構造を維持するために残りを貪欲に完成させることです。 

したがって、固定セルに関しては、(0,0) の W で始まる 1 つと (0,0) の B で始まる 2 つの完全な充填候補のみを評価します。 それぞれについて、一致する固定セルの数を数えます。 より良い方を選択し、最終的なグリッドを構築します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべての割り当てに対するブルートフォース | O(2^k・n・m) | O(n・m) | 遅すぎる |
 | 2パターン評価 | O(n・m) | O(n・m) | 承認済み |

 ## アルゴリズムのチュートリアル

 W と B を 2 つのバイナリ状態として扱い、2 つの候補チェッカーボード パターンを評価します。 

1. セル (0,0) が W であるパターンを想定します。(i + j) が偶数の場合はすべてのセル (i, j) が強制的に W になり、そうでない場合は B になります。 これにより、曖昧さのない完全なグリッドが定義されます。 これは一貫したチェッカーボードです。 
2. このパターンにすでに一致する固定セルの数を計算します。 「?」ではないすべてのセルについて、その指定された色が計算された色と一致するかどうかを確認します。 互換性を表すスコアを蓄積します。 
3. (0,0) が B である 2 番目のパターンに対して同じプロセスを繰り返します。これにより、すべての色が反転されますが、同じパリティ構造が維持されます。 
4. 互換性スコアが高いパターンを選択します。 これにより、固定制約との一致が最大化され、不一致があると少なくとも 1 つのローカル違反が強制されるため、達成可能なチェッカー 2 × 2 ブロックが間接的に最大化されます。 
5. 選択したパターンに従ってすべてのセルを埋め、「?」セルを残さずに最終的なグリッドを構築します。 

これが機能する理由は、有効な 2 × 2 チェッカー パターンがグリッド上の一貫したパリティ割り当てと一致している必要があるという事実から来ています。 各 2 × 2 ブロックは、グローバルに伝播するパリティ制約を強制します。 したがって、最適なソリューションは 2 つのパリティ割り当てのいずれかに対応する必要があり、唯一の自由は、どのグローバル フェーズを使用するかを選択することです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, m = map(int, input().split())
        g = [list(input().strip()) for _ in range(n)]

        def score(start):
            s = 0
            for i in range(n):
                for j in range(m):
                    if g[i][j] == '?':
                        continue
                    expected = start if (i + j) % 2 == 0 else ('B' if start == 'W' else 'W')
                    if g[i][j] == expected:
                        s += 1
            return s

        s1 = score('W')
        s2 = score('B')

        start = 'W' if s1 >= s2 else 'B'

        for i in range(n):
            row = []
            for j in range(m):
                if (i + j) % 2 == 0:
                    row.append(start)
                else:
                    row.append('B' if start == 'W' else 'W')
            print("".join(row))

solve()
```このソリューションは、テスト ケースごとにグリッドを 2 回スキャンすることによって両方のグローバル チェッカーボード フェーズを評価します。これは、合計 10^6 セルの制約の下で安全です。 

その後、構築フェーズではパリティに基づいて各セルを単純に割り当てます。 重要な実装の詳細は、両方の候補の中間グリッドの再計算や保存を避けることです。これは、メモリが 2 倍になってメリットがありません。 代わりに、その場でスコアを計算し、一度再構築します。 

よくある間違いは、ローカル修正を強制することで固定セルを「尊重」しようとすることです。 これにより、グローバルな一貫性が損なわれ、有効な 2 × 2 の正方形の数が大幅に減少する可能性があります。

 ## 特殊なケース

 競合するローカル パターンを持つ完全に制約されたグリッドは、スコアリング ステップがより適切なグローバル フェーズを正しく選択するかどうかをテストします。 例えば：```
2 2
W B
B W
```どちらのパターンもスコアは同等ですが、どちらもすべての固定制約を保持するため、どちらの出力も有効です。 アルゴリズムは決定論的に 1 つを選択し、再構築によって有効なチェッカーボードが生成されます。 

単行または単列のグリッドには、2 × 2 のサブグリッドがまったくありません。 このアルゴリズムは引き続き一貫した色付けを生成し、答えは常にゼロ パターンですが、正確さは固定セルを維持するかどうかに依存します。 パリティ構造は、スコアリングの選択によって強制されない限り、決して制約に違反しないため、これを自然に満たします。 

すべてのセルが固定されたグリッドは、スコアリングが完全一致ケースを正しく処理するかどうかをテストします。 入力がすでにチェッカーボードに一致する場合、選択されたパターンはすべてのセルに一致し、再構築では有効な 2 × 2 ブロックの最大数が保持されます。
