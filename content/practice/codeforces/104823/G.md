 ## 解決策
 ## 問題の理解

 同じサイズのバイナリ行列がいくつか与えられています。 各行列はグリッド位置からビットまでの関数として見ることができ、入力内の 2 つの行列は同じではありません。 

タスクは、グリッド位置の可能な限り最小のセットを選択し、それらの位置だけを見た場合でも、すべての行列が一意の署名を生成するようにすることです。 署名は、選択されたセルを固定順序で読み取り、それらの値を連結することによって形成されます。 2 つの行列は、それらの署名が少なくとも 1 つの選択された位置で異なる場合に区別可能です。 与えられたすべての行列がペアごとに異なる署名を持つように、必要な位置の最小数が必要です。 

キー次元における制約は非常に小さいです。 各行列は最大 10 × 10 なので、最大 100 個の位置があります。 行列の数は最大でも 6 です。これは、考慮する必要がある組み合わせオブジェクトは最大 100 個の要素のサブセットだけであり、動的プログラミングの意味で完全なグリッド構造を関与させる試みは不要であるため、位置に対する指数関数的検索が実行可能であることを直ちに示唆しています。 テスト ケースの数は最大 50 であるため、指数列挙が効果的に枝刈りされるか、ビットセットとして表現されることを確認する必要があります。 

単純な間違いは、特徴的なポジションの貪欲な選択が機能すると仮定することです。 たとえば、行列が最も頻繁に異なる位置を選択しても失敗する可能性があります。これは、初期に選択すると後で区別がつかなくなる可能性があるためです。 

3 つの行列 A、B、C がある状況を考えてみましょう。単一セルは最大でも 1 つのペアを区別しますが、3 つすべてを一緒に区別する単一セルはありません。 貪欲な選択では、A と B を分離するセルを選択し、後でさらに 2 つのセルが必要になる可能性がありますが、最適なソリューションでは、3 つすべてを一度に分離する別のセルのペアが選択されます。 

もう 1 つの落とし穴は、大域的な分離を保証せずに、ペアごとの差異を個別にチェックするだけで十分であると想定していることです。 行列のすべてのペアが選択したセット内のどこかで異なる場合でも、署名の完全な一意性を明示的に強制しない限り、より小さいセットが存在すると誤って仮定する可能性があります。 

## アプローチ

 ブルートフォースの観点は単純です。 グリッド内の各位置は選択することも選択しないこともできるので、位置のすべてのサブセットを試すことができます。 各サブセットについて、選択した位置の値を読み取ることによってすべての k 行列の署名を構築し、すべての署名が異なるかどうかを確認します。 これは条件を直接実装しているため、これは正しいです。 ただし、位置は最大 100 個あるため、サブセットは 2^100 個になり、これは完全に不可能です。 

重要な観察は、k が非常に小さく、最大でも 6 であるということです。これは、実際の制約はグリッド サイズではなく、分離する必要があるオブジェクトの数であることを意味します。 位置のサブセットについて考える代わりに、区別する必要がある行列のペアのサブセットについて考えることができます。 

選択された各セルは、少しの情報を提供します。つまり、行列のセットが、その位置で値 0 を持つものと値 1 を持つものに分割されます。 私たちの目標は、行列のすべてのペアが少なくとも 1 つの選択された位置によって確実に分離されるような分割の最小のコレクションを見つけることです。 言い換えれば、行列のすべてのペアについて、それらが異なる選択された位置が存在する必要があります。 

これにより、問題はペアに関する古典的なカバー問題に変換されます。 ペアは最大で k(k−1)/2、つまり最大 15 です。各グリッド位置はこれらのペアのサブセットを定義します。つまり、そのセルで異なる行列のペアが正確にカバーされます。 カバーされるペア和集合にすべてのペアが含まれるポジションの最小数を選択する必要があります。

これは、最大 15 要素をカバーする最大 100 セットにわたる最小セット カバーであり、ペア セットに対するビットマスク動的プログラミングには十分小さいです。 各セルは 15 ビットのマスクに対応しており、ビット単位の OR がフルになるマスクの最小数が必要です。 

0 から 2^15 − 1 までのマスクに対して DP を実行できます。グリッド位置ごとに、そのペア差分マスクを計算し、遷移を緩和します。

 | ペアマスク上の DP | O(nm · 2^{k^2}) (実質的には nm · 2^15) | O(2^15) | 承認済み |

 ## アルゴリズムのチュートリアル

 まず、特定のセルによってどの行列のペアが区別されるかのみに焦点を当てて問題を圧縮します。 

1. 順序付けされていない行列のペアをすべて列挙し、各ペアに 0 から P−1 までのインデックスを割り当てます。ここで、P = k(k(k−1)/2)。 これにより、各ビットが特定のペアがすでに区別されているかどうかを表すビットマスク空間が得られます。 
2. すべてのグリッド位置 (i, j) について、マスクを計算します。 その位置ですべての行列を比較します。 2 つの行列が異なる場合は常に、対応するペア ビットを設定します。 このマスクは、この単一セルがどのペアを区別できるかを正確に表します。 
3. このようなマスクをすべてリストに集めます。マスクが 0 のセルは、どのペアも区別できないため無視します。 
4. ペア マスク上の DP 配列を定義します。ここで、dp[x] は、カバレッジ x を達成するために必要な選択された位置の最小数を表します。 dp[0] = 0 を初期化し、その他すべてを無限として初期化します。 
5. セル マスクごとに、サブセットに対して標準のナップサック方式で DP を更新します。 既存の状態 x ごとに、x | に遷移できます。 コスト+1のマスク。 
6. すべてのセルを処理した後、答えは dp[full_mask] になります。ここで、full_mask にはすべてのペア ビットが設定されています。 

順序や繰り返し構造について心配する必要がない理由は、各セルが独立してペアの分離に寄与し、それらの寄与の結合のみが問題となるためです。 

### なぜ効果があるのか

 選択されたセットが有効であるためには、行列の各ペアが少なくとも 1 つの選択されたセルで異なっている必要があります。 ペアをビットとしてエンコードすると、要件が有限領域にわたる完全なカバレッジ条件に変換されます。 すべてのセルはこのユニバースの固定サブセットに対応するため、セルを選択することは、すべての要素をカバーするサブセットを正確に選択することになります。 DP は、これらのサブセットの達成可能なすべての結合を調査します。また、各結合状態の最小数を常に維持するため、最終値は、完全なカバレッジに達するために必要な最適なセル数になります。 すべてのサブセット選択が一連の DP 遷移に対応するため、有効なソリューションはスキップされません。また、完全なカバレッジが明示的にチェックされるため、無効なソリューションは受け入れられません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, m, k = map(int, input().split())
        mats = []
        for _ in range(k):
            mat = [input().strip() for _ in range(n)]
            mats.append(mat)

        # build pair index
        pairs = []
        for i in range(k):
            for j in range(i + 1, k):
                pairs.append((i, j))
        p = len(pairs)

        full = (1 << p) - 1

        cell_masks = []
        for i in range(n):
            for j in range(m):
                mask = 0
                for idx, (a, b) in enumerate(pairs):
                    if mats[a][i][j] != mats[b][i][j]:
                        mask |= (1 << idx)
                if mask:
                    cell_masks.append(mask)

        INF = 10**9
        dp = [INF] * (1 << p)
        dp[0] = 0

        for mask in cell_masks:
            ndp = dp[:]
            for state in range(1 << p):
                if dp[state] == INF:
                    continue
                nxt = state | mask
                if dp[state] + 1 < ndp[nxt]:
                    ndp[nxt] = dp[state] + 1
            dp = ndp

        print(dp[full])

if __name__ == "__main__":
    solve()
```このソリューションでは、まず行列の比較をペアごとの差分に変換して、各セルが行列ペアのビットマスクになるようにします。 次に、動的プログラミング層はこれらのマスクを繰り返しマージしてカバレッジを構築します。 重要な点は、コピーされた DP 配列をトランジションに使用して、1 回の反復内で同じセルを複数回再利用することを回避することです。これにより、誤って 1 つの位置を複数回選択できるようになります。 

最終状態`full`は区別されるすべてのペアに対応し、すべての行列が一意であることが保証されます。 

## 実用的な例

 2 × 2 グリッド上に 3 つの行列がある小さなシナリオを考えてみましょう。 目標は、3 つすべてを分離するセルの最小数を特定することです。 

セルマスクが次のように計算されると仮定します。 

| セル | 初期状態 | ペアAB | ACをペアにする | ペアBC | マスク |
 | --- | --- | --- | --- | --- | --- |
 | (0,0) | すべて等しい | 0 | 1 | 1 | 110 |
 | (0,1) | ABは異なります | 1 | 0 | 1 | 101 |
 | (1,0) | ACは異なります | 0 | 1 | 0 | 010 |
 | (1,1) | BCは異なります | 0 | 0 | 1 | 001 |

 初期 dp 状態は dp[000] = 0 のみです。 

(0,0) を処理した後は、コスト 1 で状態 110 に到達できます。(0,1) の後は、前の状態に応じてコスト 2 で 111 に、またはコスト 1 で 101 に到達できます。 DP は、最小限のコスト 2 で完全なマスク 111 に達するまで、徐々にカバレッジを蓄積します。 

これは、異なるセルからの重複するカバレッジがビットごとの OR によって自然に結合されることを示しています。 

2 番目の例は、2 つの位置のみを必要とする 2 つの行列のサンプルケースです。 選択された各位置は部分的な分離に寄与しますが、すべてのペアを分離できるのはそれらの組み合わせだけです。 DP では、単一の位置ですべてを区別できない場合でも、組み合わせが系統的に検討されるようにします。

 ## 特殊なケース

 多くのセルがそれぞれ 1 つのペアだけを個別に区別しているが、集合的には冗長である場合、微妙なケースが発生します。 たとえば、あるセルでは A と B が異なり、別のセルでは B と C、3 番目のセルでは A と C が異なる 3 つの行列が考えられます。 このアルゴリズムはマスク 100、010、001 を正しく割り当てますが、完全にカバーするには 3 つすべてが必要です。 より安価な方法で 2 回カバーされるペアは存在しないため、DP は自然に 3 つのマスクすべてを蓄積します。 

もう 1 つのケースは、単一のセルがすでにすべてのペアを区別している場合です。 その後、マスクがいっぱいになり、DP はすぐに dp[full] を 1 に更新します。DP は最小値を維持するため、セルを追加しても結果は改善されません。 

最後のエッジ ケースは、すべての行列が同じ値を共有するため、一部のセルのマスクがゼロである場合です。 これらは、どのペアのカバレッジにもまったく貢献せず、これらを含めても DP 状態が改善されずに計算が増大するだけであるため、無視しても問題ありません。
