 ## アルゴリズムのチュートリアル

 解決策を学習に分割します$l$そして入力プロセスを完了します。 

### 1. 後のコストを計算します。$l$知られています

 固定の場合$l$、最善の戦略は、正確に入力した後、常に保存することです。$l$文字。 チャンクが小さいと保存回数が増加し、チャンクが大きいと失敗する危険があります。 

したがって、セグメントの数は$\lceil n / l \rceil$。 各セグメントのコスト$l$タイピング時間プラス$t$時間を節約できるため、総コストは次のようになります。$$n + \lceil n/l \rceil \cdot t$$後でこれを全体で平均します$l \in [x,y]$。 

### 2. 学習フェーズの DP 状態を定義する

 しましょう$dp[L][R]$の正確な値を決定するための最小予想コストになります。$l$にあるとわかっていると仮定すると、$[L,R]$。 

### 3. プローブ長の選択による移行$k$値を選択します$k \in [L,R]$入力後に保存しようとします$k$文字。 

この試みには常に費用がかかります$k + t$。 その後:

 - 成功すればそれがわかります$l \in [k, R]$。 
- 障害が発生した場合、私たちはそれを知っています$l \in [L, k-1]$。 

したがって、予想されるコストは次のようになります。$$k + t + \frac{R-k+1}{R-L+1} dp[k][R] + \frac{k-L}{R-L+1} dp[L][k-1]$$すべてにおいて最低限のものを採用します$k$。 

これが機能する理由は、すべてのアクションが間隔を分割することで不確実性を軽減し、それ以外の情報が存在しないためです。$l$存在します。 

### 4. 学習と完了を組み合わせる

 最終的な答えは次のとおりです。$$\frac{1}{y-x+1} \sum_{l=x}^{y} \left(dp[x][y] + n + \lceil n/l \rceil \cdot t \right)$$学習コストは独立しています$l$なぜなら$dp[x][y]$すでに、$l$。 

### なぜ効果があるのか

 プロセスのどの時点でも、関連する知識は、可能な値の間隔だけです。$l$。 各保存操作では、選択されたデータとの比較に基づいて、この間隔の決定的な分割が生成されます。$k$。 これは、システムが決定論的な間隔調整プロセスとして進化することを意味します。 

DP は、この改良を最適に制御します。 あらゆる戦略は、ノードが区間である決定木に対応します。 同一間隔を折りたたむと DP 構造が得られます。 期待コストは確率に対して線形であり、遷移は区間の境界のみに依存するため、最適な部分構造が維持されます。つまり、区間が固定されると、将来の最適な決定はその区間のみに依存し、過去のパスには依存しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(a):
    return pow(a, MOD - 2, MOD)

def solve():
    n, x, y, t = map(int, input().split())
    m = y - x + 1

    # dp[L][R] for learning l in [L,R]
    dp = [[0] * (y + 2) for _ in range(y + 2)]

    # intervals by length
    for length in range(2, m + 1):
        for L in range(x, y - length + 2):
            R = L + length - 1
            best = 10**30

            for k in range(L, R + 1):
                prob_fail_num = k - L
                prob_succ_num = R - k + 1

                cost = k + t

                if k > L:
                    cost += prob_fail_num / length * dp[L][k - 1]
                if k < R:
                    cost += prob_succ_num / length * dp[k][R]

                if cost < best:
                    best = cost

            dp[L][R] = best

    learn_cost = dp[x][y]

    inv = modinv(m)

    total = 0
    for l in range(x, y + 1):
        seg = (n + l - 1) // l
        total += n + seg * t
        total %= MOD

    ans = (int(learn_cost) + total * inv) % MOD
    print(ans)

if __name__ == "__main__":
    solve()

最後のループでは、次の平均完了コストを計算します。$l$知られています。 整数演算は各部分に対して純粋に決定的であるため、その部分に使用されます。$l$。
