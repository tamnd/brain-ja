 ## 解決策
 ## 問題の理解

 私たちには隠されたものが与えられています$N \times N$兵士の身長を表す整数のグリッド。 グリッドは非常に構造化されています。各行は厳密に左から右に増加し、各列は厳密に上から下に増加します。 高さは異なる行や列にわたって繰り返すことができますが、同じ行や列内で重複することはできません。 

このグリッドから、最初に誰かがすべてを抽出しました$N$行とすべて$N$列。それぞれがソートされたリストとして書き込まれます。 それは与える$2N$長さのリスト$N$。 ただし、そのうちの 1 つは、$2N$リストが失われ、残りのリストが与えられました$2N-1$任意の順序でリストします。 課題は、欠落リストを再構築することです。 

主要な構造上の制約は、行と列にわたる元の値のマルチセットがグリッド プロパティによって緊密にリンクされていることです。 グリッド内のすべての値は、ソート制約によって引き起こされる構造の境界上にある値を除き、行リストと列リストの組み合わせセット内で正確に 2 回出現します。これにより、利用できるパリティ パターンが得られます。 

制約により許可されるのは、$N$最大 50、つまりテスト ケースごとの整数の合計は最大で約$2N^2 \le 5000$。 これは十分に小さいため、すべての数値の並べ替えと頻度のカウントは簡単です。 あらゆる解決策$O(N^2 \log N)$あるいは$O(N^2)$テストケースごとの処理は簡単に十分に高速です。 

素朴だが間違った本能は、行と列を貪欲に一致させることによってグリッドを明示的に再構築しようとするかもしれません。 これは、複数の有効なグリッドが同じリストのセットに対応する可能性があり、ローカルの貪欲な配置ではグローバルな一貫性が維持されないため、失敗します。 

2 番目のよくある落とし穴は、行と列が「最小要素」や「辞書順」などの単純なヒューリスティックによって区別できると想定していることです。 この問題では、入力表現では行と列が対称であるため、これは信頼できません。 

重要な観察は、グリッド自体を再構築しているのではなく、どの単一リストが欠落しているかを特定していることです。 これにより、問題は、すべてのリストを一緒に検討したときに、どのリストに「奇妙な出現パターン」があるかを検出することに変わります。 

## アプローチ

 ブルートフォース再構築では、$2N-1$リストに入れる$N$行と$N$列を調べて、どのリストが欠落しているかすべての可能性を試し、候補グリッドを構築し、単調制約が成立するかどうかを確認します。 欠落リストを修正したとしても、依然として行と列の一致に直面しており、これが組み合わせペアリングにつながります。 割り当ての数は要因的に増加します$N$というのは、本質的には未知の分割の下で完全な二部マッチングを決定しようとしているからです。 これは中程度の人でも実行不可能になります$N$、 以来$N = 50$天文学的に多くの構成を意味します。 

重要な簡素化は、最初に構造を再構築する試みを放棄することから生まれます。 代わりに、すべてのリストのすべての値を均一に扱います。 すべての行とすべての列が正確に寄与します$N$数字なので、すべてであれば$2N$リストが存在する場合、各グリッド位置は、行リストから 1 回、列リストから 1 回の合計 2 回カウントされます。 完全なリストを 1 つ失うと、このバランスが崩れます。 

したがって、幾何学的な観点から考えるのではなく、純粋に周波数パリティに焦点を当てます。 すべてのリストが存在する場合、すべての値はすべてのリストにわたって偶数回出現します。 リスト全体を 1 つ削除すると、そのリスト内の値のパリティが偶数から奇数に反転されます。 したがって、欠損リストは正確に、入力内に奇数回出現する値の複数セットです。 

これにより、問題は、すべての数値の頻度を数えるということになります。$2N-1$リストを作成し、カウントが奇数のものを抽出します。

 ## アルゴリズムのチュートリアル

 パリティの観察から直接進めます。 

1.すべて読む$2N-1$すべての高さの周波数マップをリストし、維持します。 

各数値は、すべてのリストで出現ごとに 1 回増加します。 
2. すべてのリストを処理した後、頻度マップを反復処理し、カウントが奇数であるすべての値を収集します。 

これらの値は、欠落リストの要素に正確に対応します。 
3. 収集した値を昇順に並べ替えます。 

これが必要なのは、欠損リストは厳密に昇順で出力する必要があり、抽出された値が順序どおりであることが保証されていないためです。 
4. ソートされたリストをテスト ケースの回答として出力します。 

唯一の微妙な点は、収集されたセットがなぜ正確に$N$要素。 元のリストにはそれぞれ長さがあるので、$N$、リストを 1 つ削除すると正確に削除されます$N$マルチセット全体からの出現なので、正確に$N$値はパリティを反転します。 

### なぜ効果があるのか

 各グリッド セルは、正確に 1 つの行リストと 1 つの列リストに寄与します。 完全なデータセットでは、$2N$リストでは、値の出現はすべて同じグリッド構造の別の出現とペアになるため、すべてのリストにわたる出現の合計は偶数になります。 完全なリストを 1 つ削除すると、そのリスト内の各値の出現箇所が 1 つだけ削除され、パリティが切り替わります。 したがって、奇数の頻度を持つ値は正確に欠落リスト内の値であり、他のすべての寄与はペアのままであるため、他の値は奇数になることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from collections import Counter

def solve():
    T = int(input())
    for tc in range(1, T + 1):
        n = int(input())
        cnt = Counter()

        for _ in range(2 * n - 1):
            arr = list(map(int, input().split()))
            for x in arr:
                cnt[x] += 1

        missing = []
        for x, c in cnt.items():
            if c % 2 == 1:
                missing.append(x)

        missing.sort()

        print(f"Case #{tc}: " + " ".join(map(str, missing)))

if __name__ == "__main__":
    solve()
```このソリューションでは、すべてのリストのすべての数値に対して頻度カウンターを使用します。 コア ループは単にカウントを集計するだけであり、グリッド構造内の何も明示的に再構築する必要はありません。 

最も重要な実装の詳細は、すべての行にわたるすべての整数が頻度カウントに 1 回だけ含まれるようにすることです。 解析中に行の欠落や二重カウントが発生すると、パリティ ロジックが即座に壊れます。 

## 実用的な例

 ### 例 1

 入力リスト (簡略化されたビュー):

 | ステップ | 処理済みリスト | 更新頻度 (部分的) |

| 値 | カウント | パリティ |
 | --- | --- | --- |

 | 6 | 1 | 奇数 |

 奇数のカウントを抽出すると、$\{2, 3, 4, 6\}$、並べ替えると欠落リストが得られます。 

このトレースは、パリティだけで欠落しているマルチセットを正確に分離できることを確認します。 

### 例 2 (最小構造)

 検討してください$N = 2$、リスト付き:

 | ステップ | リスト | カウンタの状態 |
 | --- | --- | --- |
 | 1 | 1 2 | 1:1、2:1 |
 | 2 | 2 3 | 1:1、2:2、3:1 |

 奇数のカウントはありません。これは、リストが 1 つだけ欠落していない限り、有効な構造では起こり得ません。 欠損リストを調整すると、それに対応する 2 つの奇数の値が得られます。 

これは、不変式が完全に依存していることを示しています。$2N-1$有効なグリッドと一致する構造。

    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    out_lines = []

        n = int(input())

            arr = list(map(int, input().split()))

    return "\n".join(out_lines)

 ## 特殊なケース

 微妙なエッジ ケースは、生の検査が誤解を招くような方法で、値が異なる行と列にわたって繰り返される場合です。 たとえば、複数のリストが共通のプレフィックスまたはサフィックスを共有する場合がありますが、この方法では順序付けが完全に無視され、グローバル周波数パリティのみに依存するため、これは正確さに影響しません。 

もう 1 つのケースは、欠落リストに他のリストと比較して繰り返される値が含まれている場合です。 各値は位置に関係なく 1 つのパリティ フリップに寄与するため、これは依然として機能します。 たとえば、値が複数の行に表示されているが、欠落している列にその値が 1 回含まれている場合でも、最終的な集計では 1 回だけ奇数になります。 

多くのリストが同一に見える極端な構成でも、パリティ メカニズムはリストの区別にまったく依存せず、入力マルチセット全体の合計出現数のみに依存するため、安定したままになります。
