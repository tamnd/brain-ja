 ## 解決策
 # 問題の理解

 私たちは、$a \times b \times c$単位立方体のトロイダル グリッド。 各セルは次のいずれかを受け取ります。$k$色、そして色$i$正確に表示されなければなりません$d_i$回。 

3 つの座標軸に沿った循環シフトによって一方を他方に変換できる場合、2 つのカラーリングは同じであるとみなされます。 によるシフト$(x,y,z)$すべての立方体をこれらのオフセットを法として移動します$a,b,c$。 

タスクは、この翻訳グループに属する色の等価クラスをカウントすることです。 

セルの総数は、$$N = abc \le 3\cdot 10^6.$$この境界が重要な観察です。 それでも$a,b,c$それ自体は大きくなる可能性がありますが、関連するすべての整数は最大でも$3\cdot 10^6$。 これにより、階乗、逆階乗、オイラー合計値、およびメビウス値のグローバルな事前計算が可能になります。 

強引にカラーリングを列挙するのは絶望的です。 たとえ$N=30$、課題の数はすでに膨大です。 対称群には以下が含まれます$abc$そのため、目的のソリューションでは、カラーリングを構築するのではなく、同値クラス全体を直接カウントする必要があります。 

すべての色数が大きな公約数を共有する場合、微妙なエッジ ケースが 1 つ発生します。 例えば：```
a=b=c=2
d=[4,4]
```変換により立方体が長さのサイクルに分割される場合があります$2$、すべてのサイクルを単色にすることができます。 ID 変換のみを考慮したソリューションでは、過大なカウントが発生します。 

もう 1 つの簡単な間違いは、変換によって長さが次の要素のみに依存するサイクルを作成すると仮定することです。$\gcd(x,a)$、$\gcd(y,b)$、 そして$\gcd(z,c)$別に。 実際のサイクル長は、3 つの成分次数の最小公倍数です。 lcm 構造体を無視すると、不正確な固定小数点カウントが生成されます。 

3 番目の落とし穴は、グループ サイズによるバーンサイドの除算を忘れていることです。 すべての変換によって修正されたすべてのカラーリングを単純に合計すると、結果はすべての軌道を正確にカウントすることになります。$abc$回。 

## アプローチ

 自然な強引なアイデアは、必要な多重度ですべてのカラーリングを生成し、それをすべての循環シフトの下で正規化し、個別の代表をカウントすることです。 

着色数は、$$\frac{N!}{\prod_i d_i!},$$それはすでに天文学的な数字です$N$数十に達します。 強引なアプローチは、実際の限界に達するずっと前に不可能になります。 

対称群の構造は、別の観点を示唆しています。 翻訳グループで許可される操作$$G = \mathbb Z_a \times \mathbb Z_b \times \mathbb Z_c,$$誰のサイズは$abc$。 

バーンサイドの補題は、同値クラスの数がグループ要素によって固定される色の平均数に等しいと述べています。 翻訳の場合$g$、変更されていない色を数えるだけで済みます。$g$。 

変換により、セルがサイクルに分割されます。 同じサイクル内のすべてのセルは、固定された色で同じ色を受け取る必要があります。 翻訳のサイクル構造を理解すると、固定カラーリングのカウントは多項係数の問題になります。 

残りの課題は、翻訳を効率的に集約することです。 すべてを繰り返すのではなく$abc$シフトに応じて、翻訳を順序に従って分類します。 次に、約数に対するメビウス反転により、それぞれの可能な順序を持つ翻訳の数が計算されます。 

これにより、問題全体が除数の列挙、多項係数、および単一のバーンサイド合計に還元されます。

## 主な所見

 ### 翻訳のサイクル構造

 翻訳を検討してください$$(x,y,z).$$長さの一次元で$a$、シフト$x$秩序がある$$r_a=\frac{a}{\gcd(a,x)}.$$まさにその後$r_a$アプリケーションでは、座標は開始位置に戻ります。 

同様に、$$r_b=\frac{b}{\gcd(b,y)}, \qquad r_c=\frac{c}{\gcd(c,z)}.$$全文翻訳の順番は、$$t=\operatorname{lcm}(r_a,r_b,r_c).$$どの軌道にも大きさがある$t$、したがって、翻訳により作成されます$$\frac{N}{t}$$サイクル。 

### カラーリングを修正

 カラーリングが固定されている場合、各サイクルは単色でなければなりません。 

色が現れる$d_i$時間が占める$$\frac{d_i}{t}$$サイクル全体。 

これが可能なのは次の場合のみです$$t \mid d_i$$あらゆる色に。 

させて$$G=\gcd(d_1,d_2,\dots,d_k).$$約数のみ$t\mid G$貢献できる。 

いつ$t\mid G$、固定カラーリングの数は$$\frac{(N/t)!} {\prod_i (d_i/t)!}.$$### 特定の注文の翻訳数をカウントする

 しましょう$F(t)$順序が正確に一致する翻訳の数になります。$t$。 

コンピューティングの代わりに$F$直接定義する$$S(t)= \#\{\text{translations with order dividing }t\}.$$長さの循環グループの場合$a$、順序が分割される要素の数$t$等しい$$\gcd(a,t).$$したがって、$$S(t)= \gcd(a,t)\gcd(b,t)\gcd(c,t).$$今$$S(t)=\sum_{d\mid t}F(d),$$したがって、メビウス反転は次のようになります$$F(t)= \sum_{d\mid t} \mu\!\left(\frac{t}{d}\right) S(d).$$これは重要な圧縮ステップです。 

## アルゴリズムのチュートリアル

 1. 階乗および逆階乗モジュロを事前計算する$998244353$まで$3\cdot10^6$。 
2. メビウス値を事前計算する$\mu(n)$まで$3\cdot10^6$直線ふるいを使用します。 
3. テストケースの場合、次のように計算します。$$N=abc, \qquad G=\gcd(d_1,d_2,\dots,d_k).$$4. すべての約数を列挙します$G$。 

分割されていない翻訳順序$G$固定カラーリングがゼロであるため、他の除数は必要ありません。 
5. すべての約数について$t$の$G$、計算する$$\text{fix}(t) = \frac{(N/t)!}      {\prod_i (d_i/t)!} \pmod{998244353}.$$6. すべての約数について$t$、計算する$$S(t)= \gcd(a,t)\gcd(b,t)\gcd(c,t).$$7. メビウス反転を除数格子に適用します。$$F(t)= \sum_{d\mid t} \mu(t/d)\,S(d).$$8. バーンサイドの公式を評価します。$$\text{ans} = \frac{1}{N} \sum_{t\mid G} F(t)\,\text{fix}(t).$$9. 結果のモジュロを出力します$998244353$。 

### なぜ効果があるのか

 バーンサイドの補題は、問題を各翻訳によって修正される色を数えるというものに縮小します。 すべての変換は、すべてのサイクルの長さが変換順序と等しい順列として機能します。 固定カラーリングでは、すべてのサイクルに 1 つの色を割り当てる必要があり、各サイクルに強制的に$d_i$その順序で割り切れます。 多項係数は、サイクル カラーのすべての有効な割り当てをカウントします。 

値$F(t)$順序が次の翻訳を正確にカウントします。$t$。 合計する$F(t)\cdot\text{fix}(t)$可能なすべての順序にわたって、すべてのグループ要素の固定カラーリングを 1 回だけカウントします。 次に、Burnside はその合計を軌道の数に変換します。軌道の数は、まさに循環シフトまでの個別の平行六面体です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAXN = 3000000

fact = [1] * (MAXN + 1)
for i in range(1, MAXN + 1):
    fact[i] = fact[i - 1] * i % MOD

ifact = [1] * (MAXN + 1)
ifact[MAXN] = pow(fact[MAXN], MOD - 2, MOD)
for i in range(MAXN, 0, -1):
    ifact[i - 1] = ifact[i] * i % MOD

mu = [0] * (MAXN + 1)
mu[1] = 1
primes = []
is_comp = [False] * (MAXN + 1)

for i in range(2, MAXN + 1):
    if not is_comp[i]:
        primes.append(i)
        mu[i] = -1
    for p in primes:
        v = i * p
        if v > MAXN:
            break
        is_comp[v] = True
        if i % p == 0:
            mu[v] = 0
            break
        mu[v] = -mu[i]

def divisors(n):
    ds = []
    i = 1
    while i * i <= n:
        if n % i == 0:
            ds.append(i)
            if i * i != n:
                ds.append(n // i)
        i += 1
    ds.sort()
    return ds

t = int(input())

for _ in range(t):
    a, b, c, k = map(int, input().split())
    d = list(map(int, input().split()))

    n = a * b * c

    g = d[0]
    for x in d[1:]:
        while x:
            g, x = x, g % x

    divs = divisors(g)
    pos = {x: i for i, x in enumerate(divs)}

    m = len(divs)

    S = [0] * m
    for i, tord in enumerate(divs):
        S[i] = (
            (a if tord > a else __import__("math").gcd(a, tord))
            * (__import__("math").gcd(b, tord))
            * (__import__("math").gcd(c, tord))
        )

    F = [0] * m
    for i, tord in enumerate(divs):
        val = 0
        for ddiv in divs:
            if ddiv > tord:
                break
            if tord % ddiv == 0:
                val += mu[tord // ddiv] * S[pos[ddiv]]
        F[i] = val

    fix = [0] * m
    for i, tord in enumerate(divs):
        cur = fact[n // tord]
        for cnt in d:
            cur = cur * ifact[cnt // tord] % MOD
        fix[i] = cur

    total = 0
    for i in range(m):
        total = (total + F[i] * fix[i]) % MOD

    total = total * pow(n, MOD - 2, MOD) % MOD
    print(total)
```実装はほぼ 1 行ずつ証明に従います。 

階乗テーブルおよび逆階乗テーブルを使用すると、すべての多項係数を色数ごとに一定時間で評価できます。 この事前計算がなければ、階乗作業の繰り返しが実行時間の大半を占めてしまいます。 

メビウス配列は、線形ふるいを使用して一度構築されます。 関連するすべての数値は最大でも$3\cdot10^6$、これは制約内に快適に収まります。 

除数リストは次の場合にのみ生成されます。$G=\gcd(d_i)$。 それが重要な最適化です。 分割されていない翻訳順序$G$固定カラーリングはゼロであるため、次のすべての約数を考慮します。$a$、$b$、 または$c$仕事を無駄にするでしょう。 

計算するとき$F(t)$、この式はまさに約数メビウス反転です。$$F(t)=\sum_{d\mid t}\mu(t/d)S(d).$$それを超える包含排除は必要ありません。

## 特殊なケース

 次のことを考慮してください。```
a=2, b=2, c=1
d=[2,2]
```色数の gcd は次のとおりです。$2$。 注文の翻訳$2$各色数は次で割り切れるため、固定の色付けに貢献します。$2$。 アルゴリズムには以下が含まれます$t=2$約数の中で$G$、その多項寄与を計算し、バーンサイドを通じてそれを組み込みます。

d=[1,2]
```ここ$G=1$。 次より大きい順序のすべての翻訳$1$一部の色数は次数で割り切れないため、すぐにゼロになります。 このアルゴリズムは、そのような次数の多項式を評価することさえありません。

a=1, b=1, c=1
d=[1]
```グループ要素、軌道、カラーリングは 1 つだけです。 数式は 1 つの項にまとめられ、答えが得られます。$1$その通り。
