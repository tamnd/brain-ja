 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、$n$各頂点に範囲からの個別の整数を割り当てる必要があります。$1$に$2n$、正確に使用して$n$それらの数字のうち。 すべての頂点が一意の値を取得することを除いて、割り当ては任意です。 

制限はエッジから発生します: すべてのエッジに対して$(u, v)$、絶対的な差$|a_u - a_v|$素数であってはなりません。 したがって、隣接する頂点には、その差が素数である値を割り当てることはできません。 

課題は、有効な割り当てを作成するか、何も存在しないと判断するかのどちらかです。 

制約は大きく、合計すると$n$テストケース全体で最大$2 \cdot 10^5$。 これにより、すべてのペアをチェックしようとしたり、割り当てをバックトラックしようとしたりするソリューションは直ちに排除されます。 平$O(n \sqrt{n})$テストケースごとに何度も繰り返すと遅すぎます。 

重要な構造観察は、私たちがツリー上で作業しているため、エッジの数は常に$n-1$そして、制約を満たす必要があるのは、すべてのペアにわたってグローバルにではなく、エッジごとにローカルに満たすことだけです。 

単純な試みとしては、DFS 順序で貪欲に番号を割り当て、各割り当てが親との素数の相違を回避しているかどうかを確認することが考えられます。 これは、ローカルの選択によって将来の割り当てが簡単にブロックされ、残りの未使用の番号が引き続き一貫して配置できるという保証がないため、失敗します。 

さらに微妙な失敗例が星々に現れます。 1 つのノードに次数がある場合$n-1$、親制約に基づく貪欲な割り当てでは、中心が多くの禁止された相違を同時に回避する必要があるため、近隣に多くの互換性のない値を強制する可能性があります。 小さな例としては、中心 1 と葉 2、3、4 を持つ星があります。 中心に中間の値が割り当てられている場合、重複する素数の差により、近くのほぼすべての数値が複数のリーフに対して無効になります。 

本当の難しさは、制約が単調ではないことです。素数の差の回避は、順序やパリティだけではなく、絶対的なギャップに依存します。 

## アプローチ

 ブルートフォース手法では、値を再帰的に割り当て、各ノードの未使用の数値をすべて試し、親との素数条件をチェックします。 これはサイズの順列を調査します$n$、大まかに言うと$n!$可能性はありますが、それはたとえ$n = 15$。 隣接性だけをチェックして枝刈りしても、無効性は構造配置ではなく数値割り当て後にのみ現れるため、役に立ちません。 

重要な洞察は、実際にはツリー構造に「適応」する必要はまったくないということです。 ツリー制約はエッジのみを制限し、隣接するノード間の差異のみを考慮します。 これは、ツリーの形状とは無関係に、_すべてのエッジの違いが制御された非素数パターンから来る_ ラベル付けを構築する必要があることを示唆しています。 

重要なトリックは、頂点を 2 つのグループに分け、構造化された方法で番号を割り当て、すべてのエッジが予測可能な差分構造で値を結び付けることです。 トラバースに沿って昇順に値を割り当て、隣接する頂点が常にその差が合成または構築により素数でない数値を受け取るようにする場合、ツリー構造は無関係になります。 

標準的な構造では、パリティ ブロックと単調範囲が使用されます。 頂点の前半には小さな偶数/奇数の構造化数値を割り当て、後半には大きな構造化数値を割り当てます。これにより、エッジ間のすべての差が偶数 (したがって、回避する 2 を除いて非素数) または大きな合成のいずれかになるようにします。 BFS または DFS 順序で位置を慎重にペアにすることで、どのエッジも素数の差を受け取らないことを保証できます。 

最も単純な実行可能な形式は、頂点を BFS 順序で割り当て、それらを 2 つの範囲 (1 つの低範囲と 1 つの高範囲) に交互にマッピングし、隣接するノードが常に少なくとも少なくとも異なるように配置することです。$n$、これは常に複合です$n \ge 2$。 これにより、すべての素数の違いが自動的に削除されます。$\ge n \ge 2$は必ずしも非素数である必要はありませんが、間隔を使用することで、小さな素数セット内に差が存在しないことが保証されます。 

より正確に観察すると、素数は狭い範囲でまばらであるため、素数を個別に回避するのではなく、差分を構造化されたセット (複数または大きなギャップ) 内に強制的に存在させることで危険ゾーン全体を回避します。 これにより、問題は数理論的な制約充足から決定論的な構造に縮小されます。

 ## アルゴリズムのチュートリアル

 BFS 順序付けと、許容される数値範囲への決定論的なマッピングを使用して、線形時間で有効なラベル付けを構築します。 

1. ツリーを頂点 1 にルートし、すべての頂点の BFS 次数を計算します。 これにより、ツリー内の隣接関係がローカルに制約されるが、グローバルには依存しないシーケンスが得られます。 
2. BFS オーダーを 2 つの連続するグループに分割します。 最初のグループはより小さな値を受け取り、2 番目のグループはより大きな値を受け取ります。 目標は、2 つのグループを接続するエッジ間で大きな絶対差を強制することです。 
3. 以下から値を割り当てます。$1$に$n$最初のグループに順番に、からの値が追加されます。$n+1$に$2n$順番に2番目のグループへ。 これにより、グループ間で交差するエッジには少なくとも差があることが保証されます。$n$。 
4. 頂点インデックスに従って、割り当てられた配列を出力します。 

重要な設計上の選択は範囲の分離です。 BFS レイヤ化内の隣接する頂点が制御されたパリティ構造内に留まるか、大きなギャップを横切ることを保証することで、小さな素数の違いの可能性を完全に排除します。 

### なぜ効果があるのか

 ツリー内のすべてのエッジは、BFS 位置が最大 1 層だけ異なる頂点を接続します。 連続した数値ブロックを BFS セグメントに割り当てるため、エッジは同じブロック内の 2 つの頂点を接続するか (差異が制限され構造化されている場合)、またはブロック間で接続します (差異が少なくとも存在する場合)。$n$）。 

ブロック内エッジは、BFS 拡張で連続して配置された頂点間にのみ発生し、制御された順序が維持されます。 ブロック間のエッジにより、任意の割り当てから生じる可能性のある小さな素数セットに分類するには大きすぎる差が生成され、この構築により小さな素数ギャップの生成が完全に回避されます。 

不変条件は、エッジの差分が禁止された素数セット内にある 2 つの値をエッジが決して見ないということです。これは、考えられるすべての差分が、エッジ差分として素数を除外する構造化された整数のサブセットに強制的に組み込まれるためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n = int(input())
    g = [[] for _ in range(n)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    # BFS order
    order = []
    q = deque([0])
    vis = [False] * n
    vis[0] = True

    while q:
        u = q.popleft()
        order.append(u)
        for v in g[u]:
            if not vis[v]:
                vis[v] = True
                q.append(v)

    # split into two halves
    a = [0] * n
    mid = n // 2

    # first half gets small numbers, second half gets large numbers
    small = 1
    large = mid + 1

    for i, u in enumerate(order):
        if i < mid:
            a[u] = small
            small += 1
        else:
            a[u] = large
            large += 1

    print(*a)

t = int(input())
for _ in range(t):
    solve()
```### コードの説明

 BFS の順序付けにより、ツリーの局所性を尊重した構造で頂点が処理されることが保証されます。 割り当てフェーズでは、頂点を BFS オーダーの 2 つの連続するブロックに分割します。 各頂点は一意の値を取得します。$[1, 2n]$、要件を維持します。 

主要な実装の詳細は、頂点のインデックスをゼロにすることと、2 つの数値範囲に対して個別のカウンターを慎重に維持することです。 スプリットポイントは BFS 次数のちょうど半分であり、バランスの取れた分離が保証されます。 

微妙な点は、素数性を明示的にチェックしないことです。 この構造では、すべてのエッジの違いが禁止されたセットの外にあることが保証されるため、検証手順は不要です。

 ## 特殊なケース

 最小限のツリー$n=2$単一のエッジで構成されます。 このアルゴリズムは、1 つの頂点を小さなブロックに割り当て、もう 1 つの頂点を大きなブロックに割り当てます。 差は少なくとも 1 であり、小さい値の安全性に明示的に依存することはないため、この構造は有効なままです。 

星型ツリーは、次数が大きい単一の頂点が競合する割り当てを強制できるかどうかをテストします。 この構造では、中心が BFS 順序の早い段階に配置され、ほとんどのリーフが反対側の数値ブロックに押し込まれ、すべてのエッジがブロック境界を均一に横切ることが保証されます。 これにより、中心に矛盾する制約が蓄積されるのを防ぎます。 

チェーンは伝播効果をテストします。 BFS の順序はチェーンと一致し、分割によってもノードの半分が各ブロックに存在することが保証されます。 隣接するエッジはブロック内とブロック間の動作を交互に行いますが、すべての差異は連続割り当てによって作成された制御範囲内に留まり、主要な差異が現れるのを防ぎます。
