 ## 解決策
 ## 問題の理解

 与えられた数のコインを 3 人の姉妹に分配して、最終的にコインの総数が同じになるかどうかを決定するように求められます。 各姉妹はすでにいくつかのコインを持っています: アリスは`a`、バーバラは`b`、そしてセリーンは`c`。 ポリカルプがもたらす`n`追加のコインがあれば、各姉妹にこれらのコインを負でない任意の数与えることができます。 問題は、すべてを配布する方法が存在するかどうかです。`n`コインなので`a + A = b + B = c + C`、 どこ`A + B + C = n`そして`A, B, C ≥ 0`。 

各テスト ケースは独立しており、数値は 10^8 まで大きくなり、最大 10^4 のテスト ケースが存在します。 これは、考えられるすべてのコインの分布をループするソリューションは遅すぎるということを示しています。 テスト ケースごとに O(1) のアプローチが必要です。 

注意すべきエッジケースとしては、姉妹の 1 人がすでに他の姉妹よりもはるかに多くのコインを持っている場合や、姉妹のバランスを正確に保つために必要なコインの総数が均等に分割されない場合などがあります。 たとえば、姉妹が 1、2、3 枚のコインを持っていて、`n = 3`単純にコインを 1 枚ずつ追加する単純なアプローチでは、それが可能であると誤って想定される可能性がありますが、注意深く計算すると、最大の差は 2 であり、残りを均等に分割できないため、すべての合計を等しくするために 3 枚のコインを分配することはできないことがわかります。 

## アプローチ

 ブルートフォース手法では、次のすべての組み合わせが試行されます。`(A, B, C)`そのような`A + B + C = n`。 整数解をチェックする必要があるだけなので、これは原理的には機能しますが、可能性の数は次のように 3 次的に増加します。`n`。 とすれば`n`10^8 にすることもできますが、これは明らかに実行不可能です。 

重要な洞察は、すべてのディストリビューションを試す必要はないということです。 させて`max_coins`姉妹が現在持っているコインの最大数になります。 それらを平等にするには、少なくとも他の 2 人の姉妹を引き上げる必要があります。`max_coins`。 そのレベルに到達するために必要なコインの総数を次のようにします。`(max_coins - a) + (max_coins - b) + (max_coins - c)`。 この数値を超えると`n`、それは不可能です。 

十分なコインがある場合、均等化後の残りのコインは`max_coins`これは、3 つの姉妹すべての平等を維持するために、ベースラインを超えた余分なコインを均等に分配する必要があるためです。 この 2 段階のチェック - まず、到達するのに十分なコインがあることを確認します`max_coins`、次に 3 で割り切れるかどうかを確認する - 問題を単純な定数時間の計算に落とし込みます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | お(1) | 遅すぎる |
 | 最適 | テスト ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、姉妹が現在所有しているコインの最大数を特定します。`max_coins = max(a, b, c)`。 これは、すべての姉妹が達成しなければならない最低限の目標を表しています。 
2. 各姉妹を最大まで育てるのに必要なコインの合計数を計算します。`max_coins`:`needed = (max_coins - a) + (max_coins - b) + (max_coins - c)`。 これは、3 つすべてを等しくするためのベースラインを説明します。 
3. Polycarp が持ってきたコインを確認します (`n`) で十分です:`needed > n`、「NO」を出力します。 配布は無理です。 
4. 十分なコインがある場合は、残りのコインを計算します。`extra = n - needed`。 3 人の姉妹に均等に分割するには、これらを 3 で割り切れる必要があります。 もし`extra % 3 == 0`、「YES」を出力します。 それ以外の場合は「NO」を出力します。 

**Why it works:** The invariant is that after step 2, all sisters have been brought to at least`max_coins`。 平等を保つために、残ったコインは 3 で割り切れなければなりません。 他に制約はないため、このチェックにより正確さが保証されます。 それ以上の反復や複雑な配布は必要ありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c, n = map(int, input().split())
    max_coins = max(a, b, c)
    needed = (max_coins - a) + (max_coins - b) + (max_coins - c)
    if n < needed:
        print("NO")
    else:
        extra = n - needed
        print("YES" if extra % 3 == 0 else "NO")
```コードは、以下を使用して複数のテスト ケースを効率的に読み取ります。`sys.stdin.readline`。 の`max`関数は、最高の開始コイン数を素早く見つけます。 全員のバランスを保つために必要なコインを計算し、2 つの単純な条件で実現可能性と割り切り可能性をチェックします。 整数演算を使用すると、丸め誤差がなく、すべての計算が正確であるため、1 による誤差の問題も発生しません。 

## 実用的な例

**サンプル入力 2:**`3 2 1 100000000`| | b | c | n | 最大コイン数 | 必要な | 番外編 | 決定 |

 説明: 全員を 3 に導きます。`needed = 3`。`extra = 99999997`は 3 で割り切れないので、3 人の姉妹に均等に分割することはできません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        a, b, c, n = map(int, input().split())
        max_coins = max(a, b, c)
        needed = (max_coins - a) + (max_coins - b) + (max_coins - c)
        if n < needed:
            print("NO")
        else:
            extra = n - needed
            print("YES" if extra % 3 == 0 else "NO")
    return output.getvalue().strip()

# Provided samples
assert run("5\n5 3 2 8\n100 101 102 105\n3 2 1 100000000\n10 20 15 14\n101 101 101 3\n") == \
"YES\nYES\nNO\nNO\nYES", "sample 1"

# Custom cases
assert run("1\n1 1 1 0\n") == "YES", "all equal, no extra coins"
assert run("1\n1 2 3 3\n") == "YES", "small numbers, divisible extra"
assert run("1\n1 2 3 2\n") == "NO", "small numbers, insufficient extra"
assert run("1\n100000000 100000000 100000000 3\n") == "YES", "max input, small extra divisible"
assert run("1\n1 1 1 2\n") == "NO", "all equal, extra not divisible"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 1 1 0 | はい | 余分なコインはありません、すでに等しい |
 | 1 2 3 3 | はい | 均等にして割り切れるのに十分なコイン |
 | 1 2 3 2 | いいえ | 均等化するにはコインが不十分です |
 | 100000000 100000000 100000000 3 | はい | 最大入力値を処理します。 
| 1 1 1 2 | いいえ | 3 で割り切れない余分なコイン |

 ## 特殊なケース

 すべての姉妹がすでに等しいコインを持っている場合、次のように`a = b = c = 1`そして`n = 0`、`needed = 0`そして`extra = 0`。 割り算チェックに合格したため、出力は「YES」になります。 もし`n = 2`その代わり、`extra = 2`は 3 で割り切れないため、出力は「NO」になります。 これは、分配が必要ないケースや分割できない残りのコインのケースをアルゴリズムが正しく処理していることを示しています。
