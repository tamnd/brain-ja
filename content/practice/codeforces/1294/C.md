 ## 解決策
 ## 問題の理解

 テスト ケースごとに、単一の整数が与えられます。`n`。 どうかを判断する必要があります。`n`3 つの **別個の** 整数の積として書くことができます`a`、`b`、 そして`c`、それぞれが少なくとも`2`。 

そのような分解が存在する場合、次のように出力します。`"YES"`有効なトリプルが 1 つあります。 そのようなトリプルが存在しない場合は、次のように出力します。`"NO"`。 

入力には最大 100 個のテスト ケースが含まれており、それぞれの値は`n`せいぜい`10^9`。 このサイズの数値でも、最大の試行除算によって因数分解できます。`√n`、 なぜなら`√(10^9) ≈ 31623`。 この作業をすべてのテスト ケースに対して実行したとしても、総計算量は制限時間内に余裕で収まります。 

The main difficulty is not factorization itself. 課題は、すべて異なる 3 つの要素を見つけることです。 

考慮する`n = 64 = 2^6`。 分解が存在します。```
64 = 2 × 4 × 8
```3 つの要素はすべて別個のものであり、少なくとも`2`。 

ここで考えてみましょう`n = 32 = 2^5`。 

考えられる因数分解は次のとおりです。```
32 = 2 × 2 × 8
32 = 2 × 4 × 4
```すべての分解は因数を繰り返すため、正しい答えは次のとおりです。`"NO"`。 

もう一つの微妙なケースは次のような場合です。`n`正確に 2 つの異なる素因数がありますが、そのうちの 1 つは 1 回しか現れません。 例えば：```
n = 12 = 2^2 × 3
```私たちは選ぶことができます`2`そして`3`、出発`2`残りの要素として。 要因は次のようになります。```
2, 3, 2
```これらは区別されません。 解決策はこのケースを拒否する必要があります。 

別の例は次のとおりです。```
n = 72 = 2^3 × 3^2
```選択する`2`そして`3`葉：```
72 / (2 × 3) = 12
```与える：```
2, 3, 12
```それは有効です。 

任意の 2 つの約数を検索し、その余りを 3 番目の要素として使用するだけの不注意な実装では、誤って重複した値が生成される可能性があります。 

## アプローチ

 ブルートフォースソリューションでは、考えられるすべてのトリプルを試します。`(a, b, c)`そのような`a × b × c = n`。 1 つの方法は、すべての約数を反復処理することです。`a`のすべての約数`b`、残りの商が形成されるかどうかを確認します`c`。 

たとえ約数に限定したとしても、このアプローチは非現実的になります。 特に最大 100 個のテスト ケースに対して実行される場合、検索スペースは急速に増大します。 

重要な点は、すべての要素が必要なわけではないということです。 必要なのは **3 つの異なる要素**だけです。 

自明ではない約数を 1 つ抽出するとします。`a`から`n`。 で割った後`a`、より小さい数が得られます。 2 番目の約数を抽出できれば`b`それは違う`a`、残りの商は自動的に次のようになります。```
c = n / (a × b)
```問題は、最終的な商が両方と異なることを確認しながら、2 つの異なる約数を見つけることに帰着します。 

素因数分解を使えばこれが簡単になります。 現在の数の最小の約数を繰り返し検索します。 

最初に見つかった約数は次のようになります。`a`。 

取り外し後`a`、再度検索します。 と異なる次の約数`a`になる`b`。 

残ったものはすべてに割り当てられます`c`。 

もし`c`より大きい`1`そしてその両方とは異なります`a`そして`b`、有効な答えがあります。 それ以外の場合は、有効なトリプルが存在しません。 

これが機能するのは、有効な分解は最終的に次の素因数に由来する必要があるからです。`n`。 因子を貪欲に抽出すると、最終的な数値に可能な限り多くの因子質量が残されるため、3 つの異なる値を取得しやすくなります。

 ## アルゴリズムのチュートリアル

 1. 元の値を保存します。`n`。 
2. の最小の約数を見つけます。`n`より大きい`1`。 

この約数を`a`。 
3. 約数が存在しない場合、`n`プライムです。 

素数は、以下の 3 つの整数の積として書くことはできません。`1`ので、印刷します`"NO"`。 
4. 分割`n`による`a`。 
5. 削減された数の別の約数を検索します。 

除数は次のものとは異なる必要があります`a`。 
6. Let this divisor be`b`。 
7. そのような約数が存在しない場合は、次のように出力します。`"NO"`。 
8. Compute```
c = original_n / (a × b)
```9.次のことを確認します。`c`両方とは異なります`a`そして`b`、そして`c > 1`。 
10. すべてのチェックに合格したら、印刷します。`"YES"`そしてトリプル`(a, b, c)`。 それ以外の場合は印刷します`"NO"`。 

### なぜ効果があるのか

 このアルゴリズムは、次の 2 つの異なる重要な要素を抽出します。`n`。 それらを削除した後、残りのすべての素因数が収集されます。`c`。 

有効な答えが存在する場合、次の素因数分解が行われます。`n`3 つの異なる数値を作成するのに十分な多重度と、十分な異なる素因数が含まれています。 最初の 2 つの要素を貪欲に取得すると、可能な限り最大の残りが残ります。`c`、その可能性を最大化します。`c`以前の選択肢とは異なります。 

アルゴリズムがトリプルを出力するたびに、積は正確に次のようになります。`n`なぜなら：```
c = n / (a × b)
```3 つの値すべてが個別であり、次の値よりも大きいかどうかがチェックされます。`1`。 

アルゴリズムが失敗すると、3 つの異なる要素を構築する方法がなくなります。 残りの因数分解構造が小さすぎるため、因数の 1 つが繰り返されるか、次のようになります。`1`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    original = n

    a = -1
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            a = d
            n //= d
            break

    if a == -1:
        print("NO")
        continue

    b = -1
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0 and d != a:
            b = d
            n //= d
            break

    if b == -1:
        print("NO")
        continue

    c = original // (a * b)

    if c > 1 and c != a and c != b:
        print("YES")
        print(a, b, c)
    else:
        print("NO")
```最初のループでは、元の数値の最小の約数を検索します。 これは次のようになります`a`。 

で割った後`a`、2 番目のループは、次とは異なる別の約数を検索します。`a`。 これは次のようになります`b`。 

残りの商は、変更された値からではなく、元の数値から計算されます。`n`。 どちらのアプローチでも機能しますが、元の値を使用すると式が明示的になり、コードを推論する際の間違いを避けることができます。 

最終的な識別性チェックは不可欠です。 それがないと、次のようなケースが発生します。`12 = 2 × 3 × 2`誤って受け入れられてしまうでしょう。 

すべての算術演算は Python 整数内に快適に収まり、オーバーフローの危険はありません。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        original = n

        a = -1
        for d in range(2, int(n ** 0.5) + 1):
            if n % d == 0:
                a = d
                n //= d
                break

        if a == -1:
            out.append("NO")
            continue

        b = -1
        for d in range(2, int(n ** 0.5) + 1):
            if n % d == 0 and d != a:
                b = d
                n //= d
                break

        if b == -1:
            out.append("NO")
            continue

        c = original // (a * b)

        if c > 1 and c != a and c != b:
            out.append("YES")
            out.append(f"{a} {b} {c}")
        else:
            out.append("NO")

    sys.stdout.write("\n".join(out))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    result = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return result

# provided sample structure
out = run("5\n64\n32\n97\n2\n12345\n")
assert out.splitlines()[0] == "YES"
assert out.splitlines()[2] == "NO"
assert out.splitlines()[3] == "NO"
assert out.splitlines()[4] == "NO"

# prime number
assert run("1\n97\n").strip() == "NO"

# smallest input
assert run("1\n2\n").strip() == "NO"

# valid case with two prime factors
res = run("1\n72\n").splitlines()
assert res[0] == "YES"

# power of two that fails
assert run("1\n32\n").strip() == "NO"

# power of two that succeeds
res = run("1\n64\n").splitlines()
assert res[0] == "YES"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`97`|`NO`| 素数は分解できない |
 |`2`|`NO`| 最小入力値 |
 |`72`|`YES`| べき乗を繰り返す複数の素因数 |
 |`32`|`NO`| 重複した因子がすべての分解に現れます。
