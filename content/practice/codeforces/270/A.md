 ## 解決策
 ## 問題の理解

 私たちは、一定の角度 _a_ でしかフェンスの角を作ることができないロボットが正多角形を構築できるかどうかを判断するように求められています。 正多角形は、すべての辺とすべての角が等しい閉じた形状として定義されます。 入力は複数のテスト ケースで構成され、それぞれが単一の角度 _a_ を度単位で与えます。 各テスト ケースの出力は、各内角が正確に _a_ である正多角形が存在する場合は「YES」、そうでない場合は「NO」になります。 

_n_ 個の辺を持つ正多角形の内角は、次の式を使用して計算できます。$$\text{angle} = \frac{(n-2) \cdot 180}{n}$$これは、与えられた _a_ に対して、次を満たす整数 _n ≥ 3_ を見つける必要があることを意味します。$$a = \frac{(n-2) \cdot 180}{n} \quad \text{or equivalently} \quad n = \frac{360}{180 - a}$$制約は単純です: 0 < a < 180。テスト ケースの数は指定されていませんが、典型的な競技プログラミングの範囲を想定できるため、各テスト ケースは一定時間内に効率的に処理される必要があります。 

_a_ が 0 または 180 に非常に近い場合、エッジ ケースが発生します。たとえば、_a = 179_ は非常に高い辺の多角形を示唆するため、整数チェックで浮動小数点エラーなしで割り切れることが正しく検出されることを確認する必要があります。 もう 1 つの微妙な点は、整数 _n ≥ 3_ のみがカウントされることです。 小数辺または _n = 2_ は無効です。 

## アプローチ

 素朴なブルートフォースでは、3 から上のすべての可能な _n_ を反復処理し、対応する内角を計算し、それが _a_ と一致するかどうかを確認します。 これが機能するのは、考慮する必要がある最大整数 _n_ が以下によって制限されるためです。$$n = \frac{360}{180 - a} \le 360$$したがって、総当たり法は正しいことになりますが、分析的に解決できる場合、テスト ケースごとに最大 360 回繰り返す必要はありません。 重要な洞察は再配置です。$$n = \frac{360}{180 - a}$$問題は、次のことを確認することに帰着します。$360 / (180 - a)$は 3 以上の整数です。これにより、整数演算を使用する場合のループや浮動小数点の丸めの問題が排除されます。検証する必要があるのは、360 が (180 - a) で割り切れるかどうか、および結果の商が少なくとも 3 かどうかだけです。

 | --- | --- | --- | --- |
 | ブルートフォース | テストごとに O(360) | お(1) | 正しいが不要 |
 | 分析部門チェック | テストごとに O(1) | お(1) | 受け入れられ、最適 |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数 _t_ を読み取ります。 これにより、処理する必要がある角度の数がわかります。 
2. 各テスト ケースについて、ロボットが作ることができる角度 _a_ を読み取ります。 
3. 値を計算する`x = 180 - a`。 各内角は次のとおりであるため、これは多角形の外角を表します。$180 - \text{external angle}$。 
4. 360 が割り切れるかどうかを確認します。`x`。 そうでない場合は、整数辺の多角形がその内角を持つことができないため、「NO」を出力します。 
5. 割り切れる場合は計算する`n = 360 // x`。 多角形には少なくとも 3 つの辺が必要であるため、_n ≥ 3_ であることを確認します。 
6. 両方の条件が満たされる場合は、「YES」を出力します。 それ以外の場合は「NO」を出力します。 

このアルゴリズムが機能するのは、多角形の外角の合計が正確に 360 度であるためです。 360 が外角で割り切れることを確認すると、整数の辺を持つ閉じた形状を形成できることが保証されます。 _n ≥ 3_ のチェックにより、有効なポリゴンが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a = int(input())
    x = 180 - a
    if x <= 0:
        print("NO")
        continue
    if 360 % x == 0 and 360 // x >= 3:
        print("YES")
    else:
        print("NO")
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`複数のテストケースを処理します。 引き算`x = 180 - a`外角を直接計算します。 無効な角度はすぐに削除されます (`x <= 0`) 可分性チェックを実行する前に。 整数の除算を行うと、120 度や 179 度などの角度に対して不正確な結果が生じる可能性がある浮動小数点の丸め誤差が生じなくなります。

 ## 特殊なケース

 179 度のような角度の場合、`x = 180 - 179 = 1`。 チェック中`360 % 1 == 0`それは本当ですが、`n = 360`は 3 より大きいので、可能であるように思われるかもしれません。 ただし、360 角形の多角形は幾何学的に有効であるため、これを受け入れる必要があります。 ソリューションのハンドル`a`正しく 0 に近づき、負またはゼロを拒否します`x`、無効なポリゴンが提案されないようにします。 のために`a = 0`または`a >= 180`、`x <= 0`即座に「NO」をトリガーし、無意味なポリゴンを防ぎます。
