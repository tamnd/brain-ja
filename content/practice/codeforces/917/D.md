 ## 解決策
 ## 問題の理解

 与えられたラベル付きツリーのバリエーションを調べるように求められます。$n$頂点、正確に共有するラベル付きツリーの数を数える$k$それぞれに指定されたエッジを持つ$k$0から$n-1$。 入力は頂点の数であり、その後に次の値が続きます。$n-1$ウィルのツリーを定義するエッジ。 出力は一連の整数です。$i$-th 値は、正確に共有するラベル付きツリーの数を表します。$i-1$ウィルの木を使ったエッジ、モジュロ$10^9 + 7$。 

重要な観察は、次のようなラベルが付けられたツリーであるということです。$n$頂点には常に正確な値があります$n-1$エッジ。 この問題では、正確なエッジの重なりの制約の下で木を数えることが求められます。 単純にすべてを生成する$n^{n-2}$Cayley の式を使用してラベルを付けた木は、$n$100まで$100^{98}$天文学的に大きいです。 これにより、総当りの列挙が排除され、理想的には動的プログラミングとサブツリーのプロパティを使用して、組み合わせで推論することが強制されます。 

考慮すべきエッジケースには、星型、線型、またはすでに単純なパターンで完全に接続されているツリーが含まれます。 たとえば、次の場合$n=2$、ラベル付きツリーは 1 つだけであり、重複の可能性は 1 だけです。共有エッジのサブセットが切断されたコンポーネントを形成するときに不用意にカウントすると計算が誤り、サブ問題数の誤った乗算が発生する可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、すべてを列挙しようとします。$n^{n-2}$ラベル付けされたツリーを確認し、元のツリーと共有されるエッジの数を確認します。 各チェックでは、すべてのチェックを繰り返す必要があります$n-1$両方のツリーのエッジに影響を与えるため、最悪の場合の操作が考慮されます。$O(n^{n})$。 これは絶望的に遅いです$n=100$。 

最適なアプローチは、問題には自然な再帰構造があるという観察から生まれます。つまり、共有エッジのサブセットが元のツリーをフォレストに分割します。 このフォレストの各コンポーネントは、独立してツリーに完成する必要があります。 したがって、エッジの特定のサブセットを含むラベル付きツリーの数は、各コンポーネントのラベル付きツリーの数を乗算し、頂点ラベル付けを考慮した組み合わせ選択を使用することによって計算できます。 これは、サブツリーまたはフォレストに対する動的プログラミングです。 正確に言うと最終的な答えは$k$共有エッジは包含-除外を使用して計算できます。少なくとも次の要素を含む木の数を数えます。$k$エッジと減算カウントにより、オーバーラップが大きくなります。 

重要な洞察は、ケイリーの公式によれば、選択された各エッジのサブセットがフォレストを誘導し、このフォレストを完成させる木の数は、そのコンポーネントのサイズをサイズから 2 引いた値を乗算したものであるということです。 サブセットに対する動的プログラミングと慎重な組み合わせ乗算により、効率的な計算が保証されます。

 ## アルゴリズムのチュートリアル

 1. 頂点数を読み取る$n$そしてウィルの木の端を保管します。 便宜上、隣接リストを作成します。 
2. DP テーブルの初期化`dp[v][k]`頂点をルートとするツリーを形成する方法の数を表す`v`正確に使用して`k`をルートとするサブツリー内にある元のツリーのエッジ`v`。 
3. 再帰的 DFS 関数を定義します。 頂点ごとに`v`、その子を処理します`u`DP テーブルをマージします。`v`'安定した。 組み合わせ乗算を使用します。`v`の現在のサブツリーには`i`エッジと`u`のサブツリーには`j`エッジ、その後`dp[v][i+j]`増加します`dp[v][i] * dp[u][j] * C(size_v + size_u - 2, size_v - 1)`モジュロ$10^9+7$。 ここ、`size_v`そして`size_u`サブツリーのサイズです。 
4. 各サブツリーについて、マージに必要な二項係数を計算するためにノードの数も追跡します。 階乗および逆階乗モジュロの事前計算$10^9+7$組み合わせを高速に計算します。 
5. DFS 後、ルート頂点の DP テーブルには、少なくとも共有するツリーの数が含まれます。`k`エッジ。 包含/除外を使用してカウントを正確に計算します`k`エッジ。 
6. シーケンスモジュロを出力します$10^9+7$。 

**それが機能する理由:** 不変条件は次のとおりです。`dp[v][k]`をルートとするサブツリー内のすべてのツリーを常に正確にカウントします。`v`正確に含む`k`そのサブツリー内のウィルのツリーからのエッジ。 子のサブツリーをマージすると、サブツリーの独立性と組み合わせラベル付けの両方が尊重され、正確さが保証されます。 包含/除外により、正確にそれが保証されます。`k`オーバーラップは、より大きなオーバーラップから分離されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1000)

MOD = 10**9 + 7

def main():
    n = int(input())
    edges = [[] for _ in range(n)]
    for _ in range(n-1):
        u, v = map(int, input().split())
        u -= 1; v -= 1
        edges[u].append(v)
        edges[v].append(u)

    fact = [1] * (n+1)
    inv_fact = [1] * (n+1)
    for i in range(1, n+1):
        fact[i] = fact[i-1]*i % MOD
    inv_fact[n] = pow(fact[n], MOD-2, MOD)
    for i in range(n-1, -1, -1):
        inv_fact[i] = inv_fact[i+1]*(i+1) % MOD

    def comb(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a]*inv_fact[b]%MOD*inv_fact[a-b]%MOD

    size = [0]*n
    dp = [dict() for _ in range(n)]

    def dfs(u, p):
        dp[u][0] = 1
        size[u] = 1
        for v in edges[u]:
            if v == p:
                continue
            dfs(v, u)
            ndp = dict()
            for i1, c1 in dp[u].items():
                for i2, c2 in dp[v].items():
                    ways = comb(size[u]+size[v]-2, size[v]-1)
                    ndp[i1+i2] = (ndp.get(i1+i2, 0) + c1*c2%MOD*ways)%MOD
            size[u] += size[v]
            dp[u] = ndp
        # Optionally include the edge u-v itself
        for v in edges[u]:
            if v == p:
                continue
            ndp = dict(dp[u])
            for k, val in dp[v].items():
                ndp[k+1] = (ndp.get(k+1, 0) + val)%MOD
            dp[u] = ndp

    dfs(0, -1)

    result = [0]*n
    for k, val in dp[0].items():
        if k < n:
            result[k] = val
    print(' '.join(map(str, result)))

if __name__ == "__main__":
    main()
```**説明:** 階乗と逆関数は、サブツリーをマージするときに高速に組み合わせ計算できるように事前計算されています。`dp[u]`をルートとするサブツリーに含まれるエッジの可能な数ごとにカウントを保持します。`u`。 DFS は、組み合わせロジックを使用して子 DP テーブルを再帰的にマージします。 オプションで親エッジを含めることで、重複の正確な数をカウントできます。 最後に、結果はルートの DP から直接抽出されます。
