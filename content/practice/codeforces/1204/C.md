 ## 解決策
 ## 問題の理解

 隣接行列として表される有向グラフが与えられます。各頂点には他の頂点へのエッジがありますが、それ自体へのループを持つ頂点はありません。 グラフとともにパスも与えられます`p`頂点インデックスのシーケンスとして。 このパスは頂点を再訪する可能性があるため、単純であることは保証されません。 シーケンス内のすべての連続する頂点のペアは、グラフ内の既存のエッジに対応します。 

目標は、開始頂点と終了頂点を保持し、このサブシーケンスの連続する頂点間のパスが常にグラフ内で可能な最短のパスとなる、指定されたパスの最短のサブシーケンスを見つけることです。 言い換えれば、これらのチェックポイント間の最短パスを取得することで元のパスを再構築できる、パスに沿った主要なチェックポイントの最小限のリストが必要です。 

グラフには最大 100 個の頂点を含めることができるため、全ペア最短パスのようなアルゴリズムの実行は、その複雑さが次のオーダーになるため実現可能です。`n^3 = 10^6`、これは許容範囲です。 パス`p`最大 10^6 要素と非常に長くなる可能性があるため、すべての位置のペアを検査するソリューションは除外されます。`p`単純に言えば、それは 10^12 の演算程度になるからです。 

同じ頂点のペア間に複数の最短パスが存在する場合、微妙なエッジ ケースが発生します。 たとえば、頂点を持つ三角グラフを考えてみましょう。`1-2-3-1`。 指定されたパスが`1 2 3 1`、その続き`1 3`はからの最短パスとして無効です`1`に`3`直接的にはただの`1-3`、元のパスと同じではありません。 選ぶだけの不用意なアプローチ`1`このような場合、最後の頂点が失敗する可能性があります。 

もう 1 つのエッジ ケースは、パスが同じ頂点を繰り返し訪れる場合です。 たとえば、すべてのノードが接続され、パスが次のようなグラフの場合、`1 2 3 2 4`、中間ノードをスキップすると最短パスが変わる場合は、中間ノードを削除しないようにする必要があります。 

## アプローチ

 ブルート フォース ソリューションでは、指定されたパスの考えられるすべてのサブシーケンスを考慮し、それが適切かどうかを確認します。 各サブシーケンスについて、サブシーケンス内の連続する頂点間の最短パスが元のパスのセグメントと一致することを検証します。 このアプローチは原理的には正しいですが、実行不可能です。 長いパスの場合`m`まであります。`2^m`サブシーケンスがあり、それぞれに最短パスのチェックが必要であり、組み合わせ爆発につながります。 

効率的な解決策を導き出す重要な観察は、すべてのサブシーケンスを考慮する必要がないということです。 Floyd-Warshall を使用してすべてのペアの最短パス距離を事前に計算すると、パスを線形にスキャンできます。 頂点ごとに`p[i]`、サブシーケンス内で最後に選択した頂点から頂点までの距離を確認します。`p[i+1]`。 この距離がスキップするエッジの数と等しい場合は、中間頂点をスキップしても安全です。 それ以外の場合は、含める必要があります`p[i]`私たちの続きでは。 これが機能するのは、サブシーケンスでは、最短パスの再構築が元のパスと一致するようにチェックポイントのみを保存する必要があるためです。 

これにより、問題は、全ペアの最短パス行列からの一定時間の距離ルックアップと組み合わせたパスの線形スキャンに帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^m * n^2) | O(n^2) | 遅すぎる |
 | 最適 | O(n^3 + m) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 隣接行列を距離行列に変換します。`dist[i][j]`からのエッジがある場合、最初は 1 です。`i`に`j`それ以外の場合は無限大です。 セット`dist[i][i] = 0`みんなのために`i`。 
2. Floyd-Warshall アルゴリズムを実行して、すべてのペアの最短経路距離を計算します。 頂点ごとに`k`、すべてのペアを更新します`(i,j)`として`dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`。 この後、`dist[i][j]`からの最短パスの長さが含まれます。`i`に`j`。 
3. パスの最初の頂点でサブシーケンスを初期化します。 させて`last`パス内のこの頂点のインデックスになります。 
4. 2 番目の頂点から開始してパスを繰り返します。 それぞれについて`i`からの最短距離かどうかを確認します。`p[last]`に`p[i]`等しい`i - last`。 そうなった場合は続行します。 そうでない場合は、含めます`p[i-1]`サブシーケンスとセット内で`last = i-1`。 
5. ループの後、最後の頂点を追加します。`p[m-1]`続編へ。 

これが機能する理由: 不変条件は、サブシーケンスが常に頂点で終了し、そこからパス セグメント内の次の頂点までの最短パスがスキップするエッジの数に等しいということです。 これにより、可能な限り多くの中間頂点をスキップしながら、サブシーケンスから再構築されたパスがセグメントごとに元のパスと一致することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = int(1e9)

n = int(input())
dist = [[INF] * n for _ in range(n)]

for i in range(n):
    line = input().strip()
    for j, c in enumerate(line):
        if c == '1':
            dist[i][j] = 1
    dist[i][i] = 0

# Floyd-Warshall for all-pairs shortest paths
for k in range(n):
    for i in range(n):
        for j in range(n):
            if dist[i][j] > dist[i][k] + dist[k][j]:
                dist[i][j] = dist[i][k] + dist[k][j]

m = int(input())
p = list(map(lambda x: int(x)-1, input().split()))

result = [p[0]]
last = 0

for i in range(1, m):
    if dist[p[last]][p[i]] < i - last:
        result.append(p[i-1])
        last = i-1

result.append(p[m-1])
print(len(result))
print(' '.join(str(x+1) for x in result))
```コードは、隣接行列を読み取り、それをフロイド-ウォーシャルに適した距離行列に変換することから始まります。 の`INF`この値により、接続されていない頂点が適切に処理されるようになります。 パス`p`ゼロベースのインデックスに変換されます。 メイン ループでは、サブシーケンスに含まれる最後に含まれる頂点を追跡し、スキップによって最短パスのプロパティが壊れる場合にのみ頂点を追加します。 最後に、サブシーケンスは入力形式に一致するように 1 から始まるインデックスで出力されます。
