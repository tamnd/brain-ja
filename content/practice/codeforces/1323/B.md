### なぜ効果があるのか

 正確さは、マトリックス構造の分離可能性にかかっています。 有効な長方形はすべて、一連の長方形の中に完全に収まっていなければなりません。$a$そして、1の実行$b$。 このような実行では、乗算構造により、すべてのセルが 1 であることが保証されます。 逆に、行セグメントの長さの任意の選択$h$一連の中で$a$および長さの列セグメント$w$一連の中で$b$有効な 1 の長方形を生成します。 面積は正確なので、$k$、の因数ペアのみ$k$それぞれの有効な長方形は、そのようなペアの 1 つに一意に対応します。 各四角形は行間隔と列間隔によって一意に決定されるため、オーバーカウントは発生しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def count_segments(arr):
    n = len(arr)
    res = {}
    i = 0
    while i < n:
        if arr[i] == 0:
            i += 1
            continue
        j = i
        while j < n and arr[j] == 1:
            j += 1
        length = j - i
        for x in range(1, length + 1):
            res[x] = res.get(x, 0) + (length - x + 1)
        i = j
    return res

def solve():
    n, m, k = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    cntA = count_segments(a)
    cntB = count_segments(b)

    ans = 0
    h = 1
    while h * h <= k:
        if k % h == 0:
            w = k // h
            if h in cntA and w in cntB:
                ans += cntA[h] * cntB[w]
            if h != w and w in cntA and h in cntB:
                ans += cntA[w] * cntB[h]
        h += 1

    print(ans)

if __name__ == "__main__":
    solve()

次に、メイン ソルバーは次の除数のペアを反復処理します。`k`。 各ペアは長方形の形状を定義します。 両方の配列がこれらの次元をサポートできるかどうかを確認し、配置数を増やします。 

微妙な点は、次の場合の対称性の処理です。$h × w = k$。 次の場合には二重カウントを避けなければなりません$h = w$したがって、対角の場合を明示的にチェックします。 もう一つの微妙な点は、`cntA[x]`長さのセグメントの数を正確に表します$x$、有効な開始位置がいくつ存在するかがすでにエンコードされています。

 ## 特殊なケース

 すべてゼロの配列の場合、セグメント テーブルは空であり、除数のペアは寄与しません。 例えば：```
3 3 2
0 0 0
0 0 0
```両方`cntA`そして`cntB`は空であるため、すべての検索は失敗し、答えはゼロのままです。 このアルゴリズムは、四角形のカウントを正しく回避します。 

1 回の長期実行の場合:```
1 5 3
1
1 1 1 1 1
```ここ`cntA[1]=1`、`cntB[3]=3`、`cntB[1]=5`など。3 の因子ペア、特に (1,3) と (3,1) のみが寄与します。 このアルゴリズムは、2D 列挙を必要とせずに、有効な配置を正しく乗算します。 

k = 6 のような不均一な因子構造の場合、(2,3) と (3,2) の両方が独立して寄与し、h = w の場合、対称性の処理により重複がないことが保証されます。
