 ## 解決策
 ## 問題の理解

 有向関数グラフが与えられます。各イグアナ i には p[i] への出力エッジが 1 つだけあるため、すべてのノードからは決定的な次の位置が 1 つだけ存在します。 イグアナ 1 は特別であり、決して移動せず、ノード 1 に固定されたままであり、これをパスが最終的に終了するシンクとして解釈します。 

すべてのイグアナは、各タイム ステップで出力エッジを繰り返したどります。 したがって、時間 t では、イグアナ i は i に t 回適用されると p になります。 一部のイグアナは最終的にノード 1 に到達しますが、他のイグアナはノード 1 を含まないサイクルに閉じ込められて到達しません。 

このタスクは、ノード 1 に到達できるイグアナが実際にノード 1 に到着するまでの予想時間を、時間 0 から計算して計算することです。期待値は、最終的に 1 に到達する一連のイグアナに対して均一に取得され、イグアナ 1 自体は到着時間 0 に含まれます。 

直接読むと、すべてのノードが出次数 1 を持つ有向グラフで距離を扱っていることがわかりますが、1 に到達できるノードのみが重要であり、それらの距離を平均して 1 にする必要があります。 

制約は大きく、テスト ケース全体のノードの総数は最大 2×10^5 です。 これにより、長いチェーンのような最悪のケースでは O(N^2) のコストがかかる可能性があるため、一歩ずつ前進することで各イグアナを個別にシミュレートするソリューションは除外されます。 

サイクルが存在する場合、微妙なエッジケースが発生します。 1 を含まないサイクル内のノードは宛先に到達しないため、完全に除外する必要があります。 もう 1 つのエッジ ケースは、長いプレフィックスの後に最終的にそのようなサイクルに入るノードです。 また、最初はプレフィックス パスが有効なルートのように見えても、除外する必要があります。 

たとえば、1 → 2 → 3 → 2 を考えてみましょう。ノード 2 と 3 は決して 1 に達しないため、ノード 1 のみがカウントされ、答えは 0 になります。サイクルを適切に検出しない単純な DFS では、有限距離が誤って割り当てられてしまいます。 

もう 1 つのケースは、5 → 4 → 3 → 2 → 1 のように 1 にフィードする長いチェーンです。すべてのノードはそれぞれ 0、1、2、3、4 の距離で寄与し、期待値はそれらの平均です。 ノードごとにパスを個別に再計算するソリューションでは、同じチェーンを繰り返し通過する危険があります。 

## アプローチ

 この構造は、各ノードが出力エッジを 1 つだけ持つ関数グラフです。 自然な総当たりアプローチは、1 に到達するかループが検出されるまで p[i] を繰り返したどることにより、ノード 1 に到達するために必要なステップ数をノードごとに計算することです。 

各パスが決定的であるため、これは概念的に機能します。 ただし、最悪の場合、グラフは長さ N の単一チェーンまたは長さ N のサイクルになる可能性があります。各ノードのウォークを個別に再計算すると、各ウォークに O(N) かかる可能性があり、合計 O(N^2) 回の操作が必要となり、これは 2×10^5 ノードには遅すぎます。 

重要な観察は、サイクルが削除されると、これは逆ツリー問題になるということです。 関数グラフでは、すべての接続コンポーネントに 1 つのサイクルが含まれます。 ノード 1 を含むコンポーネントのみが関連します。 そのコンポーネント内では、エッジを反転して、1 をルートとするツリーのように扱うことができます。1 に到達できるすべてのノードは、この反転されたグラフの 1 の逆到達可能セット内にあります。 

1 に到達できるノードに制限すると、ノードから 1 までの距離は、この逆 BFS ツリーにおける単純な深さになります。 したがって、タスクはノード 1 から開始する重み付けされていないグラフ内のすべての最短距離を計算することになりますが、エッジが逆になっています。 

次に、到達可能なすべてのノードにわたってこれらの距離を平均します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ノードごとのブルート フォース ウォーク | O(N^2) | お(1) | 遅すぎる |
 | グラフ BFS を 1 から反転 | O(N) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 関数グラフを逆隣接構造に変換し、ノード 1 から BFS を実行することで、この問題を解決します。

1. 各 i に対して i を rev[p[i]] に追加する逆隣接リストを作成します。 これにより、動きの方向が反転し、後方への移動が「誰が 1 歩でこのノードに到達できるか」に対応します。 これは、ノード 1 への距離が必要なため必要です。 
2. 反転したグラフに対してノード 1 から開始して BFS を実行します。 dist[1] = 0 を割り当ててキューにプッシュします。 
3. キューからノードをポップします。 各ノード u について、rev[u] 内のすべての v を反復します。 v が訪問されていない場合は、dist[v] = dist[u] + 1 を設定し、v を押します。これにより、1 に到達するために必要なステップ数が増加して外側に拡張することが保証されます。 
4. BFS が完了すると、訪問されたノードのみがノード 1 に到達できます。訪問されたノードのすべての dist 値の合計を計算し、訪問されたノードの数もカウントします。 
5. 答えは合計/個数です。 

未訪問のノードを安全に無視できる理由は、反転グラフの BFS がノード 1 への到達可能性を正確にキャプチャしているためです。訪問されていないノードは、サイクル内、または逆方向に 1 から切断されたコンポーネント内にあります。つまり、元のグラフでは 1 に到達できません。 

### なぜ効果があるのか

 BFS は、ノード v に最初に距離が割り当てられるとき、その距離が 1 に到達するために必要な逆方向エッジの最短数であることを保証します。これは、v が 1 に到達するために必要な順方向ステップ数に正確に対応します。すべてのエッジには単位重みがあるため、BFS レイヤーは正確なステップ数と一致します。 訪問ノードのセットは正確に 1 までの有限距離を持つノードのセットであるため、プロセスの定義により、他のノードを除外することは正しいことになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())
        p = list(map(int, input().split()))
        
        rev = [[] for _ in range(n + 1)]
        for i in range(1, n + 1):
            rev[p[i - 1]].append(i)
        
        dist = [-1] * (n + 1)
        q = deque([1])
        dist[1] = 0
        
        while q:
            u = q.popleft()
            for v in rev[u]:
                if dist[v] == -1:
                    dist[v] = dist[u] + 1
                    q.append(v)
        
        total = 0
        cnt = 0
        for i in range(1, n + 1):
            if dist[i] != -1:
                total += dist[i]
                cnt += 1
        
        print(total / cnt)

if __name__ == "__main__":
    solve()
```実装は BFS の定式化に直接従います。 逆隣接リストは線形時間で構築されます。 BFS は各ノードが 1 回処理されることを保証し、dist[i] にはノード 1 に到達するために必要な正確なステップ数が保存されます。 

唯一の微妙な点は、到達不能なノードが平均に含まれないようにすることです。 これは dist[i] != -1 をチェックすることで処理されます。 もう 1 つの重要な詳細は、答えが実数として期待されるため、最後に浮動小数点除算を使用することです。 

## 実用的な例

 ### 例 1

 入力:```
3
5
5 2 3 1 4
```エッジを構築します: 1→5、2→2、3→3、4→1、5→4。 逆エッジは、5←1、2←2、3←3、1←4、4←5です。 

BFS は 1 から始まります。 

| ステップ | ノード | 距離 | 新しく到達した |
 | --- | --- | --- | --- |
 | 1 | 1 | 0 | 4 |
 | 2 | 4 | 1 | 5 |
 | 3 | 5 | 2 | 1 (すでに見た) |

 ノード 2 と 3 は逆に 1 から到達できないため、除外されます。 

距離: ノード 1 = 0、ノード 4 = 1、ノード 5 = 2。平均 = (0 + 1 + 2) / 3 = 1。 

これは、逆到達可能セット内のノードのみが寄与していることを示しています。 

### 例 2

 入力:```
3
3
1 2 3
```すべてのノードはそれ自体を指すか、簡単な自己ループを形成します。 

逆グラフでは、各ノードがそれ自体を指しています。 

BFS:

 | ステップ | ノード | 距離 | 新しく到達した |
 | --- | --- | --- | --- |
 | 1 | 1 | 0 | なし |

 ノード 1 のみが到達可能です。 答えは0 / 1 = 0です。 

これは、1 を含まない孤立したサイクルが正しく除外されていることを示しています。

| スペース | O(N) | 逆隣接リストと距離配列 |

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque

    def solve():
        T = int(input())
        out = []
        for _ in range(T):
            n = int(input())
            p = list(map(int, input().split()))
            rev = [[] for _ in range(n + 1)]
            for i in range(1, n + 1):
                rev[p[i - 1]].append(i)

            dist = [-1] * (n + 1)
            q = deque([1])
            dist[1] = 0

            while q:
                u = q.popleft()
                for v in rev[u]:
                    if dist[v] == -1:
                        dist[v] = dist[u] + 1
                        q.append(v)

            total = 0
            cnt = 0
            for i in range(1, n + 1):
                if dist[i] != -1:
                    total += dist[i]
                    cnt += 1

            out.append(str(total / cnt))
        return "\n".join(out)

    return solve()

 ## 特殊なケース

 エッジ ケースの 1 つは、ノード 1 のみが自分自身に到達できる場合です。 その場合、BFS は正確に 1 つのノードを訪問し、分母は 1 となり、0 が生成されます。dist[1] = 0 であり、他のノードはカウントされないため、アルゴリズムはこれを自然に処理します。 

もう 1 つのエッジ ケースは、1 から切り離された純粋なサイクルです。たとえば、2 → 3 → 2。1 からの逆 BFS はこれらのノードに到達しないため、完全に除外されます。 これにより、ノード 1 が常にカウントされるため、不正な無限ループが防止され、ゼロ除算の問題が回避されます。 

3 番目のケースは、1 にフィードする長いチェーンです。たとえば、4 → 3 → 2 → 1 です。BFS は、ルートから昇順に距離 0、1、2、3 を正しく割り当てます。 平均は 4 つのノードすべてにわたって計算され、「到達可能なイグアナ」の定義と一致します。
