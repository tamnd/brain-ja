 ## 解決策
 ## 問題の理解

 各卵には、値を抽出する 2 つの独立した方法があります。フライすると 1 つのスコアが与えられ、スクランブルすると別のスコアが与えられ、スキップするとゼロの貢献が得られます。 制約は、イワンがすべての前向きな選択肢を自由に選択できないことです。 彼はせいぜい以下に限られている$F$目玉焼きとせいぜい$S$すべての選択肢にスクランブルエッグが含まれています。 各卵は 1 つの方法でのみ使用できるため、2 つのグローバル容量制限の下でアイテムごとに分割を決定します。 

タスクは、収集された合計値を最大化しながら、2 つの容量の上限を尊重する方法で、各卵を 3 つの状態のいずれかに割り当てることです。 値は負の値になる可能性があるため、一部のエッグは完全にスキップした方がよく、許容される容量内であってもスロットを未使用のままにしておくのが最適な場合があります。 

入力サイズは最大です$N = 10^4$、 その間$F + S \le 100$。 この組み合わせが重要な構造上の手がかりです。アイテムはたくさんありますが、「有料スロット」の数は非常に少ないのです。 大規模な状態空間で卵ごとの決定を追跡しようとするソリューションは困難を伴いますが、容量を主要な次元として扱うソリューションは効率を維持できます。 ナイーブ$O(N \cdot F \cdot S)$DP はすでに許容範囲ギリギリですが、より慎重な削減や貪欲な最適化が魅力的になります。 

負の値からは微妙なエッジケースが発生します。 すべての値が負の場合、すべての卵をスキップすることが許可されるため、正解は 0 になります。 1 つのカテゴリが無効になっている場合、次のような別のエッジ ケースが発生します。$F = 0$これにより、選択されたすべてのエッグがスクランブルまたはスキップされ、トランジションの構造が変更されます。 

## アプローチ

 直接的なアプローチは、それぞれの卵を個別に検討し、すべての可能性を試すことです。フライする（容量が残っている場合）、スクランブルする（容量が残っている場合）、スキップするなどです。 これにより、当然のことながら、項目と残りの容量に関する動的プログラミングの定式化が行われます。 させて$dp[i][f][s]$最初の処理後の最大の満足度を表す$i$卵入り$f$フライドスロットと$s$スクランブルされたスロットはすでに使用されています。 卵ごとに 3 つのトランジションを試します。 これは、すべての有効な割り当てを調査するため、正しいです。 

問題はそれです$N = 10^4$, したがって、DP の単一レイヤーでも$F \cdot S \le 100$まだ周囲を暗示します$10^6$状態、および各状態は 3 つの選択肢に渡って遷移します。$3 \cdot 10^6 \cdot 10^4$動作が遅すぎます。 

重要な観察は、卵の順序は容量の制約を超えて重要ではないということです。 各卵は独立して貢献しており、私たちは最大で次のものを選択しています。$F + S \le 100$すべての卵にわたる「割り当て」の合計。 これにより視点が変わります。最初に卵を繰り返すのではなく、全体で何個の目玉焼きとスクランブルエッグを採用するかを繰り返し、それらのスロットを満たすのに最適な卵を選択します。 

これを最大まで選択すると再解釈できます。$F$「フライドプール」までのアイテム$S$「スクランブルプール」用のアイテムですが、各アイテムは1回しか使用できないという制限があります。 標準的なトリックは、小さな容量のスペースで DP を維持しながら、卵を 1 つずつ処理することです。 容量が小さいため、各アイテムが 3 つの状態のいずれかになる 2 次元のナップサックを用意でき、再利用を避けるために容量を逆に DP を更新します。 

これは機能しますが、$N$は大きく、各卵は 2 つの潜在的なゲインのみに寄与し、容量状態空間はすべての遷移を効率的に吸収できるほど十分に小さいです。

 ## アルゴリズムのチュートリアル

 私たちは DP テーブルを維持します。$dp[f][s]$卵の接頭辞を考慮した後に達成可能な最高の総合満足度を表します。正確に使用します。$f$揚げ物の選択肢と$s$乱雑な選択肢。 

1. すべての DP 状態を非常に負の値に初期化します。$dp[0][0] = 0$。 これは、卵が選択されておらず、満足度がゼロの状態から開始することを表します。 
2. 卵を1つずつ処理します。 
3. 値を持つ各卵について$f_i$（揚げたもの）と$s_i$(スクランブル)、容量に対して逆の順序で DP テーブルを更新します。 
4. ペアごとに$(f, s)$、卵を未使用のままにし、保管しておくことを検討します。$dp[f][s]$変わらない。 
5. もし$f > 0$、この卵を目玉焼きに割り当てることを検討します。$dp[f-1][s] + f_i$。 これは、揚げたスロットを 1 つ消費し、揚げた満足感を得ることを表します。 
6. もし$s > 0$、この卵をスクランブルエッグに割り当て、から移行することを検討します。$dp[f][s-1] + s_i$。 これは、スクランブルされたスロットを 1 つ消費することを表します。 
7. 各州について、これらの選択肢の中から最大値を採用します。 
8. すべての卵を処理した後、答えはすべての卵の最大値になります。$dp[f][s]$のために$0 \le f \le F$、$0 \le s \le S$すべてのスロットを完全に使用する必要はないためです。 

容量に対する逆の反復が不可欠です。 これがないと、単一のエッグが同じ反復内で複数回再利用される可能性があり、各エッグは最大 1 回使用されるという制約に違反します。 

### なぜ効果があるのか

 エッグのサブセットを処理した後の任意の時点で、各 DP 状態は、各エッグを最大 1 回使用して、達成可能な最良の値をエンコードします。 新しいエッグを処理する場合、遷移はこのエッグがまだ含まれていない状態からのみ拡張されます。 容量を逆方向に反復するため、状態の更新を同じ反復内の同じエッグの別の更新にフィードすることはできません。 これにより、各卵が最大 1 回だけ寄与するという不変条件が保存されます。 

DP は、容量制限の下で卵のすべての有効な割り当てを 3 つのカテゴリに効果的に探索していますが、指数関数的な割り当て空間を、純粋にリソースの使用量によって定義される多項式状態空間に圧縮します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

NEG = -10**30

def solve():
    N, F, S = map(int, input().split())
    
    dp = [[NEG] * (S + 1) for _ in range(F + 1)]
    dp[0][0] = 0

    for _ in range(N):
        f_i, s_i = map(int, input().split())

        for f in range(F, -1, -1):
            for s in range(S, -1, -1):
                best = dp[f][s]

                if f > 0 and dp[f - 1][s] != NEG:
                    best = max(best, dp[f - 1][s] + f_i)

                if s > 0 and dp[f][s - 1] != NEG:
                    best = max(best, dp[f][s - 1] + s_i)

                dp[f][s] = best

    ans = 0
    for f in range(F + 1):
        for s in range(S + 1):
            ans = max(ans, dp[f][s])

    print(ans)

if __name__ == "__main__":
    solve()
```DP テーブルは、到達不能な状態と有効な低スコア構成を区別するために、非常に負の値で初期化されます。 ゼロは空の選択範囲にのみ割り当てられます。 

ネストされたループは逆方向に反復されます。$f$そして$s$各卵が状態レイヤーごとに正確に 1 回処理されるようにします。 この更新では、卵を目玉焼きにするかスクランブルにするかによって、現在の最良の状態が改善されるかを計算します。 未使用の容量が許容され、場合によっては最適化されるため、すべての状態にわたる最終スキャンが必要です。

 ## 特殊なケース

 主なエッジケースは、容量がゼロの場合です。 この状況では選択はできないため、すべての卵をスキップする必要があります。 DP は次から始まります$dp[0][0] = 0$また、無効な状態への遷移は決して許可されないため、すべての値が大きく正の場合でも、当然のことながら 0 が出力されます。 

もう 1 つのケースは、すべての値が負の場合です。 DP はスコアを下げる遷移を試行する可能性がありますが、すべての状態の最終的な最大値には空の選択が含まれており、最適な答えとしてゼロが維持されます。 例えば卵1個の場合$(-5, -10)$そして$F = S = 1$、DP は否定的な状態を一時的に検討しますが、最終的には維持します$dp[0][0] = 0$最高として。 

より微妙な状況は、同じ卵に対して、あるカテゴリーが別のカテゴリーを支配している場合です。 DP は、同じ卵に対する両方の選択肢を組み合わせずに前の状態からのみ遷移するため、排他性が保証されます。 これにより、二重カウントが防止され、各卵が最大 1 つの値に寄与し、問題の制約に正確に一致することが保証されます。
