 ## 解決策
 ## 問題の理解

 非常に厳密な形状を形成する一連の地形の高さが与えられています。高く始まり、下がり、上がり、再び下がり、最後に再び上がります。 言い換えれば、配列は「W」のように動作し、方向が減少から増加に変わるちょうど 2 つの下位点があります。 

それぞれの最低点は谷の底に対応します。 このような谷はちょうど 2 つあるため、形状を厳密に解釈すると、配列内にはちょうど 2 つの極小値が存在します。 

タスクは、2 つの谷の底を特定し、2 つの値のうち大きい方を出力することです。 

入力サイズは小さく、最大でも 1000 要素です。これは、単純な線形スキャンやわずかに冗長なスキャンでも十分であることをすでに示唆しています。 O(n²) まではそれでも十分高速ですが、この構造により、線形ソリューションが可能かつクリーンであることが保証されます。 

唯一の微妙なケースは、「谷の底」がどのように解釈されるかによって決まります。 単純な実装では、値が両方の近傍よりも小さいインデックスを検索する可能性がありますが、境界処理と形状の厳密さが重要です。 

たとえば、うっかりしてチェックばかりしていたら、`h[i] < h[i-1] and h[i] < h[i+1]`、その場合、プラトーまたは等しい値は、より一般的なバリアントでの正確性を損なうことになります。 ここでの問題は厳密な単調セグメントを保証するため、遷移内部での等価性は期待されませんが、最も安全な推論は依然として純粋な比較ではなく、方向の変化の検出に依存しています。 

もう 1 つの潜在的な間違いは、谷が 1 つしか存在しないと想定していることです。 この問題には 2 つあるため、最初の極小値の後で停止すると不完全な答えが得られます。 

## アプローチ

 強引な解釈では、すべての指標を調べ、近隣の指標と比較して谷底かどうかを判断します。 ポジションごとに`i`、シーケンスが以下に続くかどうかを確認します。`i`そしてその後に上がっていきます。 もしそうであれば、それを谷底として記録します。 最後に、記録されたすべての底値の最大値を取得します。 

これは、谷底の定義が純粋にローカルであるため機能しますが、それでもすべての位置をスキャンし、位置ごとに一定の作業を実行する必要があります。 それは O(n) であり、漸近複雑さの観点からはすでに最適です。 

ただし、より構造的に考えることもできます。 配列は W 字型を形成することが保証されているため、差異のパターンは厳密には下、上、下、上となります。 これは、方向が減少から増加に変わるインデックスで谷の底が正確に発生することを意味します。 完全な近傍条件をチェックする代わりに、隣接する差分における符号の変化を検出するだけで済みます。 

連続する要素を比較することによって、方向配列を暗黙的に計算します。 いつでも`h[i-1] > h[i]`そして`h[i] < h[i+1]`、すぐに谷底を特定します。 これによりあいまいさがなくなり、実装が最小限に抑えられます。 

どちらのアプローチも直線的です。 違いは概念的な明瞭さです。2 つ目は問題の形状を直接エンコードします。

 ## アルゴリズムのチュートリアル

 1. 1 から n − 2 までのインデックスを繰り返します。これは、これらの位置のみが左と右の両方の近傍を持つことができるためです。 これにより、谷底を定義できない境界チェックが回避されます。 
2. 各インデックスで`i`、地形が減少しているかどうかを確認します。`i`そして、`i`、 意味`h[i-1] > h[i]`そして`h[i] < h[i+1]`。 この条件は、厳密に変化するシーケンスにおける極小値の定義を直接捉えます。 
3. 条件が成立する場合は、保存します。`h[i]`谷底候補として。 
4. アレイをスキャンした後、記録されたすべての谷底の最大値を計算します。 これは、2 つの谷の中で最も標高の高い盆地を選択することに対応します。 
5. この最大値を出力します。 

重要な設計上の選択は、配列を明示的に谷に分割しようとしないことです。 単調な構造により、局所的な比較を通じて谷の底を一意に識別できるようになります。 

### なぜ効果があるのか

 W 字型の制約により、アレイは厳密なパターンで方向を交互に切り替えます。 すべての谷の底は、まさに、傾きが負から正に変わる点です。 数列は谷の前では厳密に減少し、谷の後には厳密に増加するため、他の点は両方の不等式を同時に満たすことはできません。 これにより、局所的な条件が必要かつ十分になるため、検出されたすべての点が真の谷底となり、有効な谷底が見逃されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
h = list(map(int, input().split()))

valleys = []

for i in range(1, n - 1):
    if h[i - 1] > h[i] and h[i] < h[i + 1]:
        valleys.append(h[i])

print(max(valleys))
```この実装は、極小値をスキャンするというアイデアに直接従っています。 ループ境界により、無効なインデックスにアクセスしないことが保証されます。 条件`h[i - 1] > h[i] and h[i] < h[i + 1]`谷底の特徴である下り坂から上り坂への移行をエンコードします。 

正確に 2 つある場合でも、谷の底をすべて保存します。これは、ロジックを一般的に保つことで、正確な数に依存することが回避されるためです。 決勝戦`max`必要に応じて 2 つの盆地のうち高い方を選択します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n = int(input())
    h = list(map(int, input().split()))

    valleys = []
    for i in range(1, n - 1):
        if h[i - 1] > h[i] and h[i] < h[i + 1]:
            valleys.append(h[i])

    return str(max(valleys))

 ## 特殊なケース

 エッジケースの 1 つは、両方の谷が同じ深さである場合です。 例えば：```
5
9 1 2 1 9
```スキャンでは、インデックス 1 と 3 (両方とも 1 に等しい) で谷底が検出されます。アルゴリズムは両方の値を追加して返します。`max([1, 1])`ロジックは一意性に依存しないため、重複する最小値は自然に処理されます。 

もう 1 つのケースは、谷の一方が非常に浅く、もう一方が深い場合です。```
7
8 5 1 4 10 3 6
```検出された底値は 1 と 3 です。アルゴリズムは両方の局所条件を独立して評価し、3 を正しく選択します。対称性に関する仮定は使用されないため、不均衡は正確さに影響しません。 

最終的な構造上のエッジ ケースは、最小サイズの入力です。```
5
10 2 3 1 9
```インデックス 1、2、3 のみがチェックされます。 アルゴリズムは 2 と 1 を潜在的な谷として識別し、2 を返します。境界制限により無効なメモリ アクセスがないことが保証され、厳密な不等式により端での誤検知がないことが保証されます。
