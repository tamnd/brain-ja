 ## 解決策
 ## 問題の理解

 それぞれのサイズが異なる 2 枚の同一の長方形のシートが与えられます。$M \times N$。 側面に平行な直線カットを使用して、各シートを軸に沿った小さな長方形にカットすることができます。 切断後、両方のシートから得られたすべての部分を自由に再配置および回転できます (部分から新しい長方形を形成するときに方向は問題にならないため、暗黙的に)。これらを単一のターゲットのサイズの長方形に組み立てたいと考えています。$P \times Q$。 

多くのタイリング問題とは異なり、すべてのマテリアルを使用する必要はありません。 ターゲットの長方形を形成するのに必要のない残りの部分は未使用のままになるため、それらの合計面積を計算する必要があります。 ターゲットの四角形をまったく構築できない場合は、「IMPOSSIBLE」を出力します。 

重要な点は、実際の制限は利用可能な総面積だけであるということです。 初期の各長方形は寄与します$M \cdot N$、それで一緒に$2MN$単位正方形分の材料。 任意の軸に合わせたカットが許可されるため、各長方形を単位正方形に至るまで洗練することができます。$2MN$面積制約が満たされる限り、任意の長方形に再配置できる独立した 1x1 セル。 

制約$M, N, P, Q \leq 1000$これは、すべての計算が 32 ビット整数内に快適に収まるため、Python でのオーバーフローを心配する必要がないことを意味します。 ソリューションはテスト ケースごとに一定時間で実行する必要があります。 

よくある間違いは、アスペクト比を一致させようとしたり、切断戦略をシミュレートしようとしたりするなど、幾何学的制約を考えすぎることです。 たとえば、2 つの長方形だけから開始するため、ターゲットは何らかの形で次の長方形に整列する必要があると誤って仮定する可能性があります。$M$または$N$。 これは、次のような誤った拒否につながります。 

入力:```
4 4
5 3
```単純な幾何学的アプローチは、5 が 4 を除算しないため失敗する可能性があり、またその逆も同様ですが、総面積のみを考慮しているため、正しい答えは有効です。 

別の失敗例は次のとおりです。 

入力:```
2 2
3 3
```ここでは総面積が8、対象が9なので、形は似ていても無理です。 

## アプローチ

 ブルートフォースの考え方では、2 つの長方形の考えられるすべての切断パターンをシミュレートし、それらを再帰的に分割し、ターゲットの長方形を組み立てようとします。 カットごとにピースの数が増加し、各ピースはさまざまな方法で再度分割できるため、これはすぐに爆発します。 カットを整数座標に制限したとしても、長方形の分割数は両方の次元で指数関数的に増加するため、このアプローチは、$M, N \leq 1000$。 

重要な洞察は、自由な切断により構造上の制約がなくなるということです。 グリッド線に沿って繰り返しカットできるので、$M \times N$長方形は次のように縮小できます$MN$単位正方形。 2 つの長方形を使用すると、実質的に次のマルチセットが得られます。$2MN$単位正方形。 このレベルまで縮小すると、ターゲット長方形を形成するための残りの要件は、十分な合計単位正方形があることだけです。 

これにより、問題全体が単純な面積比較に集約されます。

 ## アルゴリズムのチュートリアル

 1. 利用可能な合計面積を次のように計算します。$2 \cdot M \cdot N$。 これは、任意のカット後に 2 つの長方形から抽出できる単位正方形の最大数を表します。 
2. 必要な面積を次のように計算します。$P \cdot Q$。 これは、ターゲットの長方形を形成するために必要な単位正方形の正確な数です。 
3. 必要な面積と利用可能な面積を比較します。 必要な領域が利用可能な領域を超える場合、再配置または切断戦略では存在するよりも多くのマテリアルを作成できないため、ターゲットの長方形を構築することはできません。 
4. 建設が可能であれば、残りの面積を次のように計算します。$2MN - PQ$、これはターゲットを形成した後に未使用の単位正方形に対応します。 

### なぜ効果があるのか

 任意の直線カットにより、最初の両方の長方形を単位 1x1 セルまで細分化できるため、元のジオメトリにはこれらのセルの合計数を超える制約が課されません。 整数の辺の長さをもつ長方形は、同じ単位セルの異なる配置にすぎません。 再配置には制限がないため、実現可能性はターゲット領域をカバーするのに十分なセルが存在するかどうかによってのみ決まります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    M, N = map(int, input().split())
    P, Q = map(int, input().split())

    total = 2 * M * N
    need = P * Q

    if need > total:
        print("IMPOSSIBLE")
    else:
        print(total - need)

if __name__ == "__main__":
    solve()
```このソリューションは 2 つの長方形を読み取り、利用可能な合計面積と必要な面積を直接計算します。 重要な実装の詳細は、幾何学的なシミュレーションを行わずに、すべてを整数演算で維持することです。 減算は、負の残り値が生成されるのを避けるために、実行可能性チェックの後にのみ実行されます。

 ## 特殊なケース

 エッジ ケースの 1 つは、ターゲットが元の長方形の 1 つに正確に一致する場合です。 たとえば、次の場合$M=N=5$そして$P=5, Q=5$、アルゴリズムは合計面積を計算します$50$、必要な領域$25$、そして戻ります$25$。 これは、材料の半分だけを使用することに相当し、残りの部分が許可されるため、これは有効です。 

もう 1 つのエッジ ケースは、ターゲット領域が利用可能な領域の合計と等しい場合です。 もし$M=N=3$そして$P=3, Q=6$、総面積は$18$そして必要な面積も$18$。 アルゴリズムは 0 を出力します。これは、無駄なものがないことを意味します。 これにより、完全な使用率が特別な分岐なしでクリーンに処理されることが確認されます。 

最後のエッジ ケースは、次のような、1 つの次元が元の長方形と比較して極端に大きい場合です。$M=N=1000$、$P=1$、$Q=1$。 このアルゴリズムは面積のみを比較するため、引き続き正しく動作し、結果は次のようになります。$2 \cdot 10^6 - 1$、これは有効です。
