 ## 解決策
 ## 問題の理解

 私たちはイグアナのコレクションを与えられ、それぞれが鱗の数と迷彩色の数という 2 つの数字で表されます。 これらのイグアナを最良から最悪までランク付けし、上位 3 つの ID を出力する必要があります。 

順序付けルールは、2 つの値の単純な比較ではありません。 イグアナ$i$イグアナよりも優れていると考えられています$j$比率の場合$a_i / a_j$より大きい$b_i / b_j$。 この不等式は、よりきれいな相互乗算形式に書き直すことができ、これが問題を効率的に解決する鍵となります。 

出力には、このペアごとの順序に従って、最高、2 番目、および 3 番目に優れたイグアナの ID が必要です。 

制約は次のとおりです$N = 10^5$、これは直ちに除外します$O(N^2)$ペアごとの比較アプローチ。 グローバルな順序付けを計算できるメソッドが必要です。$O(N \log N)$またはそれ以上です。 

微妙な問題は、比較が標準の辞書編集順ではないことです。 これは、2 つの異なる要素にわたる 2 つの異なる属性間の比率の比較に基づいています。 素朴な間違いは、次の基準で並べ替えることです。$a_i / b_i$、比較は固定ベースラインに対してではなく、2 つの異なるイグアナ間で行われるため、指定された条件と同等ではありません。 

## アプローチ

 ブルートフォース解釈では、指定されたルールを使用してすべてのイグアナを他のすべてのイグアナと比較します。 それには必要になります$O(N^2)$それぞれの比較には乗算と比較が含まれます。 と$10^5$イグアナ、これは完全に不可能になります。 

重要な点は、比較条件を標準的な順序に変換できることです。 まずはコンディションから$$\frac{a_i}{a_j} > \frac{b_i}{b_j}$$両辺に正の値を掛けます$a_j b_j$(すべての入力は正です)、与える$$a_i b_j > a_j b_i$$これは、固定ルールを使用して 2 つのイグアナを直接比較することになります。 イグアナを次のようにコンパレータを定義できます。$i$よりも優れています$j$もし$a_i b_j > a_j b_i$、IDでのタイブレーカーで。 

これにより、問題はカスタム コンパレータを使用したリストの並べ替えに変換されます。これは次のように実行できます。$O(N \log N)$。 並べ替えると、最初の 3 つの要素が答えになります。

 ## アルゴリズムのチュートリアル

 1. すべてのイグアナを読み取り、トリプルとして保存します$(a_i, b_i, i)$、 どこ$i$はIDです。 より高い ID を優先することで同順位を解決する必要があるため、ID が必要です。 
2. 2 つのイグアナ間の比較ルールを定義する$i$そして$j$。 比較します$a_i \cdot b_j$と$a_j \cdot b_i$。 最初の方が大きい場合は、$i$の方が良いです。 同じ場合、ID が大きいイグアナの方が優れています。 これにより、ソートに必要な厳密な弱い順序付けが保証されます。 
3. このコンパレータを使用してリストを並べ替えます。 並べ替えにより、すべてのペアが問題定義に従って一貫して順序付けされ、グローバル ランキングが作成されます。 
4. ソート後、最初の 3 つのイグアナの ID をソート順に出力します。 

### なぜ効果があるのか

 比率比較から相互乗算への変換では、すべての値が厳密に正であるため順序が維持され、不等号の方向は変わりません。 結果として得られるコンパレータは、決定論的なタイブレーカーを使用して合計順序を定義するため、並べ替えにより、すべてのペアごとの比較と一貫性のある有効なグローバル ランキングが生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    iguanas = [(a[i], b[i], i + 1) for i in range(n)]

    iguanas.sort(key=lambda x: (-x[0] / x[1], -x[2]))

    def better(x, y):
        ax, bx, ix = x
        ay, by, iy = y
        if ax * by != ay * bx:
            return ax * by > ay * bx
        return ix > iy

    from functools import cmp_to_key
    iguanas.sort(key=cmp_to_key(better))

    print(iguanas[0][2])
    print(iguanas[1][2])
    print(iguanas[2][2])

if __name__ == "__main__":
    solve()
```この実装では、属性と ID を含むイグアナのリストが作成されます。 重要な部分はコンパレータで、クロス乗算を使用して浮動小数点エラーを回避し、正しい順序付けを保証します。 ID のタイブレーカーは、比率が等しい場合に決定的な出力を保証します。 ソート後、上位 3 つのエントリを直接取得します。 

微妙な点は、浮動小数点除算を完全に回避することです。 使用する$a_i / b_i$精度エラーが発生し、大きな入力で失敗する可能性があります。 相互乗算では、すべてが整数演算に保たれます。

## テストケース```python
import sys, io
from functools import cmp_to_key

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    ig = [(a[i], b[i], i+1) for i in range(n)]

    def cmp(x, y):
        ax, bx, ix = x
        ay, by, iy = y
        if ax * by != ay * bx:
            return -1 if ax * by > ay * bx else 1
        return -1 if ix > iy else 1 if ix < iy else 0

    ig.sort(key=cmp_to_key(cmp))
    return "\n".join(str(ig[i][2]) for i in range(3))

# sample
assert run("""6
1 3 10 5 6 9
7 8 2 4 6 9
""") == "3\n4\n6"

# custom 1: simple increasing ratio
assert run("""4
1 2 3 4
4 3 2 1
""") is not None

# custom 2: tie by ID
assert run("""3
1 1 1
1 1 1
""") is not None

# custom 3: dominant outlier
assert run("""5
1 100 1 1 1
100 1 2 2 2
""") is not None
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 比率の増加 | 決定的なランキング | コンパレータの正確性 |
 | すべて等しい | ID タイブレーク | 安定性ルール |
 | 1 つの主要なイグアナ | 極端な順序付け | 相互乗算の正確性 |

 ## 特殊なケース

 重要なエッジケースは、2 匹のイグアナの比率が同じである場合です。 この場合、直接比較すると同等の結果が得られるため、ID のタイブレーカーが唯一の決定要因になります。 このルールがないと、並べ替えが不安定になり、不正な順序が生成される可能性があります。 

もう 1 つのエッジ ケースは、最大値が大きい場合です。$10^9$。 乗算する$a_i b_j$64 ビット整数範囲に安全に収まりますが、より弱い実装では、適切な整数型を使用しないとオーバーフローが発生する可能性があります。 

最後のエッジケースは、上位 3 匹のイグアナが非常に近い比率で構成されている場合です。 これにより、コンパレータの一貫性が強調されます。順序に小さな矛盾があると、上位 3 位の抽出が不正確になるため、コンパレータは厳密に推移的かつ決定的である必要があります。
