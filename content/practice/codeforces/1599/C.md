 ## 問題の理解

 私たちは、ジョニーが学習したマップでプレイすることになる確率が少なくとも$P$。 ゲームの流れは以下の通りです。$N$マップは合計で 3 つがランダムに提示され、各プレイヤーは 1 つのマップを破棄します。 次に、システムは残りのマップの 1 つをゲーム マップとしてランダムに選択します。 ジョニーは、最終的なマップが彼が研究したマップの中に含まれる可能性を最大限に高めたいと考えています。 

入力により得られるものは、$N$、マップの総数、および$P$、ターゲット確率。 出力はマップの最小整数です。$k$ジョニーが何か勉強したら$k$マップの場合、最終的なマップが研究対象のセットに属する確率は少なくとも$P$。 

制約は中程度です。$N$までです$10^3$、 そして$P$は、小数点以下 4 桁までの 10 進数です。 これは、次のようなアルゴリズムを意味します。$O(N^2)$動作は問題ありません。$O(N^3)$まだ通過できますが、上限に近づいています。 確率は、特に比較する場合、浮動小数点の精度の問題を避けるために慎重に処理する必要があります。$P$0.0001 や 1.0 などの値。 

明らかではないエッジケースが発生するのは次の場合です。$P=1$。 たとえジョニーがほぼすべてのマップを研究したとしても、システムが彼の研究セット外のマップを選択する可能性は依然としてあります。 たとえば、$N=7$そして$P=1.0$、彼は6つのマップを勉強する必要があります。 調査するマップの数を減らすと、最終的なマップが調査されないことになり、要件に違反します。 同様に、$P=0$の場合、確率ゼロのしきい値を満たすために学習されたマップは必要ないため、答えは 0 です。 

## アプローチ

 ブルートフォースアプローチは、可能なすべての数のマップを反復処理することです。$k$0から$N$、それぞれについて$k$、調査対象のマップが選択される正確な確率を計算します。 これを行うには、表示されている 3 つのマップのすべての組み合わせを列挙し、ランダムな破棄をシミュレートします。 これは正確性を保つために機能しますが、複雑さは次のとおりです。$O(N^3)$マップのトリプレットごとに結果を評価する必要があるためです。 のために$N=1000$、これでは約 10 億回の操作が行われますが、これは遅すぎます。 

重要な洞察は、確率関数が単調であるということです。より多くのマップを研究しても、研究されたマップがプレイされる可能性は決して減少しません。 したがって、確率式を計算する必要があるのは、次の関数として 1 回だけです。$k$、最小のものを見つけます$k$確率が以上になるように$P$。 組み合わせで推論できます: ジョニーが勉強していれば$k$マップでは、表示されるマップのランダムな 3 つのシナリオについて 3 つのシナリオがあります。 

1. 3 つのマップすべてが調査されます。 
2. 2 つの学習済みマップ、1 つは未学習のマップ。 
3. 1 つは学習済みのマップ、2 つは未学習のマップです。 
4. 研究された地図はゼロ。 

それぞれのケースについて、マップを選択する方法の数で重み付けを行い、最終的なマップが研究対象セットに属する確率を計算できます。 単純化すると、最終的な確率式は次のようになります。$$\text{probability} = \frac{k}{N} + \frac{k}{N} \cdot \frac{k-1}{N-1}$$または同様に、慎重な組み合わせ論を使用します。 正確な導出には、表示されている 3 つのマップのうちのいくつが調査されるかを数えることと、均一な破棄仮定を使用することが含まれます。 

数式を取得したら、単純に繰り返すだけです$k=0$に$N$、各ステップで確率を計算し、到達した時点で停止します。$P$。 これは$O(N)$、完全に受け入れられます$N \le 1000$。

 ## アルゴリズムのチュートリアル

 1.読む$N$そして$P$入力から。$N$はマップの総数、$P$ターゲットの確率。 
2. もし$P = 0$、すぐに0を出力します。 ゼロしきい値を満たすためにマップを検討する必要はありません。 
3. 反復する$k$1から$N$。 各ステップで、システムによって選択されたマップがマップの中に含まれる確率を計算します。$k$地図を勉強しました。 確率は、調査されたマップが両方の破棄にも耐えて最終的に選択される結果の割合として計算されます。 
4. 計算された確率が少なくとも以下であるかどうかを確認します。$P$。 そうであれば、印刷してください$k$そして反復を停止します。 これ$k$1 から増加するため、最小になります。 
5. いいえの場合$k < N$確率を満たします (これは次の場合にのみ発生します)$P=1$)、出力$N-1$。 破棄はランダムであるため、ジョニーが 1 つのマップを除くすべてのマップを研究しない限り、システムは 100% の確率を保証することはできません。 

なぜ機能するのか: 確率関数の単調性により、$k$確率≧を達成する$P$、すべて大きい$k$それも満足させます。 したがって、最初の$k$見つかったものは最小限です。 組み合わせ式は、マップ結果のカウントとランダムな選択に基づいて正しい確率を取得するため、シナリオが見逃されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    N, P = input().split()
    N = int(N)
    P = float(P)
    
    if P == 0:
        print(0)
        return
    
    for k in range(1, N+1):
        # probability formula: chance that at least one studied map survives
        prob = 1 - ((N-k)/N) * ((N-k-1)/(N-1)) * ((N-k-2)/(N-2)) if N >= 3 else 0
        if prob + 1e-9 >= P:  # floating point tolerance
            print(k)
            return

if __name__ == "__main__":
    main()
```式`1 - ((N-k)/N)*((N-k-1)/(N-1))*((N-k-2)/(N-2))`表示されている 3 つのマップの**どれも**が調査されない確率をカウントします。 1 から減算すると、**少なくとも 1 つの調査済みマップが生き残る** 確率が得られます。 浮動小数点の丸めを処理するために小さなイプシロンを追加し、過小評価しないようにします。
