 ## 解決策
 ## 問題の理解

 パイを表すバイナリ文字列が与えられているので、各セグメントが同じ「美しさ」を持つように、それを連続したセグメントに分割する必要があります。 文字列の美しさは、連続する文字が異なる箇所の数として定義されます。 たとえば、文字列では`0101`、連続する数字が異なるインデックスが 3 つあるため、その美しさは 3 です。タスクは、文字列の接頭辞ごとに、その接頭辞を正確に分割できる方法が何通りあるかを計算することです。`k`同等の美しさを持ったパーツ。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは、バイナリ文字列と文字列自体の長さを提供します。 制約により許可されるのは、`n`最大 10^6 になり、次の合計`n`すべてのテスト ケースにわたる最大値も 10^6 です。 これは、どのソリューションもテスト ケースごとに直線的な時間で実行する必要があることを意味します。 二次アプローチでは制限時間を超えてしまいます。 

文字列にすべて同じ文字が含まれている場合、微妙なエッジ ケースが発生します。`0000`。 完全な文字列の美しさは 0 であり、すべてのプレフィックスも美しさ 0 を持ちます。このような文字列の場合、可能な値は次のとおりです。`k`はすべてプレフィックス長の約数です。 不注意なアプローチでは、すべての分割を明示的にチェックしようとする可能性があり、大規模な場合は失敗します。`n`。 もう 1 つのエッジケースは、次のような文字列を交互に配置することです。`0101...`、キャラクターを追加するたびにビューティーポイントの数が増加します。 全体の美しさプラス 1 の約数をすべて正確に数えることが必要です。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのことを列挙します。`k`各プレフィックスについて、プレフィックスのすべての可能なパーティションをチェックします。`k`部品を分割し、その美しさを計算し、それらが等しいことを確認します。 これは原理的には正しいですが、それぞれのプレフィックスの長さが異なるため、実用的ではありません。`i`まであります`i`候補者`k`、各分割のチェックには最大 O(i) かかります。 これにより、最悪の場合、テスト ケースごとに O(n^2) が生成され、これでは遅すぎます。`n`最大 10^6。 

重要な洞察は、セグメントの連結の美しさは、境界を除いたセグメント内の美しさの寄与の合計であるという意味で、美しさは相加的であるということです。 より正式には、長さのプレフィックスの場合、`i`総合的な美しさを持っています`B`に分割します`k`セグメントは次の場合にのみ可能です`B`に分割できます`k`等しい部分。 ただし、美しさはトランジション (キャラクター間のトランジション) をカウントするため、分割する実質的な合計は次のようになります。`B`プラス`k`(各セグメントの長さは少なくとも 1 です)、これは約数の問題に帰着します: 長さのプレフィックスの場合`i`そして美しさ`b`、に分割`k`部品であれば可能です`b`に分割できます`k`各セグメントが整数のビューティー ポイントを保持できるように整数を指定します。 すべての約数を計算する`b+1`in O(sqrt(B)) は効率的です。 プレフィックスごとに、美しさを段階的に更新し、約数の数を数えることができます。

 ## アルゴリズムのチュートリアル

 1. ビューティー ポイントのカウンターを初期化します。 セット`beauty = 0`。 
2. 文字列プレフィックスを一度に 1 文字ずつ繰り返します。 新しい文字ごとに、前の文字と異なる場合は増分します。`beauty`。 
3. 現在の長さのプレフィックスの場合`i`、約数の数を計算します。`beauty + 1`以下のもの`i`。 各約数は有効な値を表します`k`これは、セグメント間でトランジションを均等に分割するためです。 
4. 有効回数を保存する`k`このプレフィックスの場合。 
5. すべてのプレフィックスに対して繰り返し、各プレフィックスのカウントを順番に出力します。 

機能する理由: 部分文字列の美しさは、0 と 1 の間の遷移をカウントします。`k`セグメントの場合、各セグメントは同じ数のトランジションを提供する必要があります。 トランジションは文字の間にあるため、トランジションの合計数に 1 を加えた数値がセグメント間で均等に分割されます。 これは、約数を数えるということになります。`beauty + 1`プレフィックス長まで。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def count_valid_k(prefix_length, beauty):
    count = 0
    for k in range(1, int((beauty + 1) ** 0.5) + 1):
        if (beauty + 1) % k == 0:
            if k <= prefix_length:
                count += 1
            if k != (beauty + 1) // k and (beauty + 1) // k <= prefix_length:
                count += 1
    return count

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    beauty = 0
    prev = s[0]
    res = []
    for i, c in enumerate(s):
        if i > 0 and c != prev:
            beauty += 1
        prev = c
        res.append(str(count_valid_k(i + 1, beauty)))
    print(' '.join(res))
```このコードはビューティー カウンターを初期化し、前の文字を追跡して遷移を検出し、有効な文字を繰り返しカウントします。`k`を使用して`count_valid_k`関数。 除数のカウントは、プレフィックスごとに O(sqrt(beauty)) に最適化されます。 文字列構築を使用し、`join`繰り返しの印刷のオーバーヘッドを回避します。
