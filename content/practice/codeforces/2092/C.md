 ## 解決策
 ## 問題の理解

 アスナの崇拝者からの贈り物を表す、正の整数の高さをもつ塔のコレクションが与えられました。 アスナは自分の才能の美しさを最も高い塔の高さと評価します。 彼女は、高さの合計が奇数になる 2 つのタワーを選択し、どのタワーもマイナスにせずに 1 つのユニットを一方のタワーからもう一方のタワーに移すという操作を繰り返し実行することができます。 目標は、この操作を何度も適用した後、可能な限り最大限の美しさを決定することです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースでは、タワーの数とその高さを指定します。 各テスト ケースの出力は単一の整数、つまり達成可能な最大の美しさです。 

制約は重要です。 すべてのテスト ケースにわたって最大 200,000 のタワーがあり、各高さは最大 200,000 です。$10^9$、個々の操作をシミュレートするアプローチは実行不可能です。 単純なシミュレーションでは、最大で次のように実行できます。$10^9$ペアごとの操作は 2 秒の制限時間には決して収まりません。 このため、文字通りのシミュレーションではなく、数学的なパターンを探す必要があります。 

すべてのタワーが同じパリティを持つ場合、エッジ ケースが発生します。 たとえば、すべてのタワーの高さが偶数の場合、合計が奇数になるペアはありません。 この場合、操作はまったく実行できず、美しさは単にタワーの最大高さだけです。 逆に、少なくとも 1 つの偶数タワーと 1 つの奇数タワーがある場合、操作によりそれらの間でユニットを転送できます。 もう 1 つの微妙なケースは、タワーが 1 つしかない場合です。操作は不可能であり、最大の美しさはその 1 つのタワーです。 

## アプローチ

 ブルート フォース アプローチでは、タワーのすべてのペアに対して反復処理が行われ、パリティ条件がチェックされ、有効なペアがなくなるまで操作が実行されます。 これにはネストされたループが必要になり、最悪の場合は数億回の操作が必要になるため、非現実的になります。 

重要な観察点は、この操作によりすべてのタワーの高さの合計が維持されるということです。 また、反対のパリティのタワー間でユニットを再分配することもできます。 したがって、単一のタワーの高さを最大化することを妨げる唯一の制限はパリティです。すべてのタワーが同じパリティを持つ場合、再分配は不可能であり、最大タワーは変更されません。 奇数タワーと偶数タワーの両方がある場合は、すべての高さのユニットが 1 つのタワーに集まるようにユニットを移動できます。 その場合、最大の美しさはすべての塔の高さの合計です。 

最適な解決策は、タワーのパリティをチェックするだけです。 両方のパリティが存在する場合は、すべての高さの合計を返します。 それ以外の場合は、最大の高さを返します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2 × max(a_i)) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、タワーの数を読み取ります。`n`そして高さの配列`a`。 
2. 2 つのフラグを初期化します。`has_odd`そして`has_even`、奇数および偶数の高さの存在を追跡します。 
3. 配列を反復処理する`a`。 身長ごとに更新します`has_odd`高さが奇数の場合、そして`has_even`高さが均等であれば。 
4. すべての高さの合計を計算します。`total`。 
5. 両方の場合`has_odd`そして`has_even`True の場合、出力`total`最大限の美しさとして。 それ以外の場合は出力`max(a)`。 

これが機能する理由: すべての高さの合計は、許可された操作の下では不変です。 この操作は、奇数タワーと偶数タワーの間でのみ実行できます。 両方のパリティが存在する場合、ユニットはタワー間で自由に移動できるため、1 つのタワーで合計を蓄積できます。 すべての塔が同じパリティを共有する場合、いかなる操作も不可能であり、最大の美しさは単純に既存の最大の塔になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    has_odd = has_even = False
    total = 0
    for x in a:
        total += x
        if x % 2 == 0:
            has_even = True
        else:
            has_odd = True
    
    if has_odd and has_even:
        print(total)
    else:
        print(max(a))
```コードは最初にテスト ケースの数を読み取ります。 テスト ケースごとに、タワーの高さの同等性を追跡し、合計を計算します。 ブール フラグを使用すると、追加のデータ構造を使用せずに両方のパリティの存在を効率的に検出できます。 高さの合計は、再配分が可能な場合にのみ使用されます。

サンプル 2:

 説明: 奇数と偶数の両方があるため、すべてのユニットを 1 つのタワーに蓄積できます。 美しさの最大値は5です。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | テスト ケースあたり O(n) | シングルパスで合計を計算し、パリティを検出します。 |
 | スペース | お(1) | 少数のカウンターとフラグのみが使用されます。 |

 すべてのテスト ケースにわたるタワーの合計数が ≤ 2 × 10^5 であるとすると、ソリューションは 2 秒の制限時間内で快適に実行されます。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        has_odd = has_even = False
        total = 0
        for x in a:
            total += x
            if x % 2 == 0:
                has_even = True
            else:
                has_odd = True
        if has_odd and has_even:
            output.append(str(total))
        else:
            output.append(str(max(a)))
    return "\n".join(output)

# Custom cases
assert run("2\n1\n7\n3\n2 4 6\n") == "7\n6", "Single tower and all even"
assert run("1\n5\n1 1 1 1 1\n") == "1", "All same odd"
assert run("1\n4\n2 2 2 3\n") == "9", "One odd among evens"
assert run("1\n2\n999999999 1\n") == "1000000000", "Large numbers with both parities"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 タワー、奇数 | 7 | 単一要素の配列を正しく処理します。 
| すべて同じパリティ | 6 | 操作はできません。 最大値が返されます |
 | パリティの組み合わせ | 9 | 再配布は許可されています。 合計が最大になります |
 | 大きな数 | 1000000000 | 境界値をオーバーフローせずに処理します。 

## 特殊なケース

 単一タワーの場合`[7]`、操作は存在しません。 アルゴリズムはパリティが 1 つだけ存在することを検出し、次の値を返します。`7`、それは正しいです。 

すべての偶数タワーの配列の場合`[2, 4, 6]`、奇数がないため、演算はできません。 アルゴリズムは正しく出力します`6`。 

混合配列の場合`[2, 2, 2, 3]`、両方のパリティが存在します。 合計`2+2+2+3 = 9`が返され、すべてのユニットを 1 つのタワーに蓄積できることが示されます。 

大きな高さの場合`[999999999, 1]`、両方のパリティが存在し、合計`1000000000`オーバーフローせずに返されます。 

これらの例は、アルゴリズムが、いつ再配布が可能であるか、いつパリティによって最大値が制限されるかを正しく識別することを確認します。
