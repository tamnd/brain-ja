 ## 解決策
 ## 問題の理解

 それぞれに異なる美しさのレベルを持つ羊のリストが与えられます。 Kamilka はすべての羊に同じ数の追加の草の束を与えることができ、すべての美しさのレベルを同じ整数だけ効果的に向上させることができます。$d \ge 0$。 この餌を与えた後、彼女は正確に 2 頭の羊を選択しなければなりません。彼女が得る喜びは、結果として得られる美しさのレベルの最大公約数 (GCD) です。 タスクは、この GCD を最大化することです。 

入力は複数のテスト ケースで構成され、それぞれが指定します$n$、羊の数、続いて$n$美しさのレベルを表す個別の整数。 出力はテスト ケースごとに 1 つの整数、つまり達成可能な最大 GCD です。 

制約は中程度です。$n$最大 100、美しさのレベルは最大 100 まで可能です。$10^9$、最大 500 のテスト ケースがあります。 なぜなら$n$小さい、アルゴリズム$O(n^2)$テスト ケースあたりの時間は実現可能ですが、総当たりですべてのテストを試みます。$d$まで$10^9$不可能です。 

重要なエッジ ケースには、羊が 2 匹だけ存在するシナリオが含まれるため、それらの違いを慎重に考慮する必要があります。 もう 1 つの特殊なケースは、美しさのレベルがすでに互いに素である場合です。 ユニフォームを追加する$d$GCD を増やす唯一の方法かもしれません。 たとえば、入力の場合`2\n1 3\n`、選択する$d=1$最適な GCD 2 が生成されます。 制服追加の可能性を無視した甘いアプローチ$d$誤って 1 が出力されます。 

## アプローチ

 ブルートフォースアプローチは単純明快です。$d$、結果として得られるすべての美しさレベルを計算し、すべてのペアの GCD を確認します。 これは、実行可能なすべての給餌方法をテストするため正しいですが、実際には完全に失敗します。$d$非常に大きくなる可能性があり、最大で$10^9$、実行不可能になります。 

重要な洞察は、一様な加算の下で GCD がどのように動作するかを考慮することです。 選ばれた2匹の羊に美しさのレベルを持たせる$x$そして$y$。 After adding$d$、それらの値は次のようになります$x+d$そして$y+d$、そして 2 つの GCD は次のようになります。$\gcd(x+d, y+d)$。 GCD の特性により、これは次のように単純化されます。$\gcd(x+d, y+d) = \gcd(x - y, y + d)$。 これは、達成可能な最大 GCD が常に何らかの差の約数であることを意味します。$y - x$。 

したがって、繰り返す代わりに、$d$、すべての羊のペアを反復処理して、それらの美しさのレベルの差を計算できます。 それぞれの違いについて$diff = y - x$、のすべての約数$diff$は最大 GCD の候補です。 次に、各候補約数について、存在するかどうかを確認します。$d$これをすべての羊に加算すると、約数で割り切れる 2 つの数が生成されます。 いつでもシフトできるから$d$大きい数を約数で割り切れるようにするには、2 匹の羊の差の最大の約数を常に達成できます。 したがって、最適な戦略は、任意の 2 匹の羊の間の最大の差を見つけて、その約数を取ることになります。 

これにより、シンプルかつ効率的な作業が可能になります。$O(n^2)$アルゴリズム: 羊のすべてのペアを反復処理し、それらの差を計算し、最大の差を記録します。 その最大差の最大約数が答えです。

 ## アルゴリズムのチュートリアル

 1. 各テストケースについて、羊の数を読み取ります。$n$そしてその美しさのレベル$a$。 
2. 変数を初期化する`max_beauty`美しさのレベルを最大限に高め、`min_beauty`最小限に。 違い`max_beauty - min_beauty`任意の 2 頭の羊間の最大間隔を与えます。 
3. カミルカが達成できる最大の喜びは、まさにこの違いです。$d = max_beauty - max(a_i)$数値をシフトして GCD を差と等しくします。 
4. この値をテスト ケースの答えとして出力します。 

なぜ機能するのか: 同じものを追加する$d$すべての数値に適用しても、数値間の差異は変わりません。 加算後の 2 つの数値の GCD$d$は、最大値と最小値の差を取ることで常に最大化できます。 美しさのレベルの違いによってすべての可能な GCD が決定されるため、全体的な最大値が最大の差そのものになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    max_a = max(a)
    min_a = min(a)
    print(max_a - min_a)
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`、羊の数とその美しさレベルを抽出し、美しさの最大値と最小値を計算し、その差を出力します。 これは、適切なパラメータを追加した後にその差が達成可能な最大 GCD を捕捉するため機能します。$d$。 このソリューションは不必要な計算を回避し、すべての制約内で機能します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    t = int(input())
    res = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        res.append(str(max(a)-min(a)))
    return "\n".join(res)

# Provided samples
assert run("4\n2\n1 3\n5\n5 4 3 2 1\n3\n5 6 7\n3\n1 11 10\n") == "2\n4\n2\n10"

# Custom cases
assert run("1\n2\n1000000000 1\n") == "999999999", "large difference"
assert run("1\n3\n7 7 7\n") == "0", "all equal"
assert run("1\n2\n1 2\n") == "1", "minimum size"
assert run("1\n4\n10 1 2 3\n") == "9", "non-sorted input"
```| テスト入力 | 期待される出力 | 検証内容 |

## 特殊なケース

 すべての羊が同じ美しさを持っているなら、その差はゼロです。 たとえば、入力`3\n7 7 7`出力を生成します`0`。 アルゴリズムはこれを正確に識別します。`max(a) - min(a)`は0です。 

羊が2匹しかいない場合は、次のように入力します。`2\n1 2`、違いは 1 です。$d$数値は連続しているため、GCD は 1 を超えて増加しません。 アルゴリズムは計算によってこれを処理します`max(a)-min(a)`直接、1を生成します。 

美しさのレベルが全範囲にわたる場合、たとえば、`2\n1 1000000000`、アルゴリズムは次のように計算します。`1000000000 - 1 = 999999999`Python の整数は任意の大きな値を処理するため、オーバーフローすることなく効率的に処理できます。 

この解決策はシンプルかつ効率的であり、一様な加算の下での GCD の最大化は最大の差によって決定されるという数学的特性を直接利用しています。
