 ## 解決策
 ## 問題の理解

 個別の非負の整数の配列が与えられます。`s`長さの`n`。 目標は各要素を分割することです`s[i]`非負の整数のペアに変換`a[i]`そして`b[i]`そのような`a[i] + b[i] = s[i]`。 両方欲しいです`a`そして`b`ほぼユニークであること。 繰り返される要素の最大半分 (切り捨て) を削除すると、配列が厳密に一意の配列になる場合、その配列はほぼ一意になります。 実際には、これにより、サイズ 2 の配列では 1 つの重複、サイズ 5 では 2 つの重複などを許容できます。 

制約は中程度です。`n`と同じ大きさにすることができます`10^5`そして`s[i]`まで`10^9`。 これは、考えられるすべての分割を試みる強引な方法は使用できないことを意味します。これは、指数関数的に複雑になるためです。 代わりに、おそらく線形時間で実行されるアルゴリズムが必要です。`O(n log n)`操作。 

明らかではないエッジ ケースには、小さな値を含む配列、連続する番号を含む配列、および間隔の広い大きな数値を含む配列が含まれます。 例えば、`s = [0,1]`非負の分割は次のとおりであるため、注意が必要です。`[0,0]`そして`[0,1]`タイプ分割。 単純なアプローチでは、ほぼ一意性の条件を破る負の数や重複した分割が生成される可能性があります。 

## アプローチ

 ブルートフォースソリューションでは、考えられるすべてのペアに対して反復処理が行われます。`(a[i], b[i])`そのような`a[i] + b[i] = s[i]`それぞれに`i`。 次に、次のことを確認します。`a`そして`b`ほぼユニークです。 これは完全な検索空間を探索するため、原理的には機能しますが、組み合わせの数は、次のように指数関数的に増加します。`n`、それは完全に不可能になります`n`まで`10^5`。 

重要な洞察は次のとおりです`s`厳密に増加しているか、少なくともユニークです。 これにより、利用可能な最大の数値を一方の配列に貪欲に割り当て、残りをもう一方の配列に割り当てることができます。 並べ替えると`s`昇順で、すでに使用した要素を追跡するために 2 つのセットを維持します。`a`そして`b`、割り当てることができます`a[i]`を超えない最大の未使用値`s[i]`、そしてさせてください`b[i] = s[i] - a[i]`。 どちらかの場合`a[i]`または`b[i]`がすでに取得されている場合は、その補数を他の配列に代入します。 これにより、各重複は 1 回だけ発生し、重複は簡単に削除してほぼ一意の条件を満たすため、ほぼ一意であることが保証されます。 

この貪欲な戦略が機能する理由は、`s`は一意であり、各配列内の未使用の値の使用を常に優先します。 競合は当然のことながら 1 回の繰り返しに限定されており、ほぼ独自の定義の下では許容されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 貪欲な分割 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 並べ替え`s`昇順で。 これにより、ほぼ一意性を妨げる可能性のある多数の値を見逃すことなく、体系的に分割を割り当てることができます。 
2. 2 つの空のセットを初期化します。`used_a`そして`used_b`すでに配置されている要素を追跡するため`a`そして`b`。 
3. ソートされたものを反復処理します。`s`降順で。 それぞれについて`value`:

 1. もし`value`入っていない`used_a`、割り当てます`a[i] = value`そして`b[i] = 0`、次にマークを付けます`value`で使用されるように`a`。 
2. それ以外の場合は、割り当てます`a[i] = 0`そして`b[i] = value`、次にマークを付けます`value`で使用されるように`b`。 
3. 両方の場合`a[i]`そして`b[i]`一意性に違反する場合は、「NO」を出力します。 
4. すべての要素を処理した後、配列を返します`a`そして`b`「はい」と。 

なぜ機能するのか: 不変条件は、すべての数値が`s`完全に配置されているか、`a`または`b`、重複は必要な場合にのみ導入されます。 以来`s`は一意であり、利用可能な最大数で貪欲に分割します。どちらの配列でも重複の最大数は 1 であり、ほぼ一意の条件を満たします。 並べ替えにより、大きな数値が一意性のプロパティに違反する方法で小さな数値が配置されるのを妨げないようにすることができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
s = list(map(int, input().split()))

a_set = set()
b_set = set()
a = [0] * n
b = [0] * n

# Sort with original indices
s_with_idx = sorted([(val, idx) for idx, val in enumerate(s)], reverse=True)

possible = True
for val, idx in s_with_idx:
    if val not in a_set:
        a[idx] = val
        b[idx] = 0
        a_set.add(val)
    elif val not in b_set:
        a[idx] = 0
        b[idx] = val
        b_set.add(val)
    else:
        possible = False
        break

if possible:
    print("YES")
    print(" ".join(map(str, a)))
    print(" ".join(map(str, b)))
else:
    print("NO")
```このソリューションでは、元のインデックスを追跡しながら配列を並べ替えるので、出力できるようになります。`a`そして`b`元の順序で。 それぞれの値に対して、貪欲に割り当てます。`a`可能であれば、そうでなければ`b`。 両方がブロックされている場合、分割は不可能です。 セットを使用すると、`O(1)`メンバーシップのチェックとソートにより`O(n log n)`全体的な複雑さ。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    s = list(map(int, input().split()))
    a_set = set()
    b_set = set()
    a = [0] * n
    b = [0] * n
    s_with_idx = sorted([(val, idx) for idx, val in enumerate(s)], reverse=True)
    possible = True
    for val, idx in s_with_idx:
        if val not in a_set:
            a[idx] = val
            b[idx] = 0
            a_set.add(val)
        elif val not in b_set:
            a[idx] = 0
            b[idx] = val
            b_set.add(val)
        else:
            possible = False
            break
    if possible:
        return "YES\n" + " ".join(map(str, a)) + "\n" + " ".join(map(str, b))
    else:
        return "NO"

# Provided samples
assert run("6\n12 5 8 3 11 9\n") == "YES\n12 5 8 3 11 9\n0 0 0 0 0 0", "sample 1"

# Custom cases
assert run("2\n0 1\n") == "YES\n0 1
```
