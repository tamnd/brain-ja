 ## 問題の理解

 2 つの括弧のシーケンスを作成するように求められます。`a`そして`b`、指定されたバイナリ文字列と同じ長さ`s`。 それぞれのポジションで`s`間の関係を決定します`a`そして`b`： もし`s[i]`は`1`、 それから`a[i]`そして`b[i]`等しい必要があり、もし`s[i]`は`0`、 それから`a[i]`そして`b[i]`違うはずだ。 両方のシーケンスはバランスの取れた括弧シーケンスである必要があります。つまり、各文字列を左から右にトラバースすると、左括弧の数が増えます。`(`右括弧の数を下回ることはありません`)`、および合計数`(`の合計数に等しい`)`。 

入力は複数のテスト ケースを提供します。 各文字列の長さ`n`は偶数であり、バランスの取れたブラケットに必要です。 すべての合計`n`は 200,000 を超えないため、テスト ケースごとに線形時間で機能するアプローチが必要です。 括弧のあらゆる組み合わせを試すという単純なアプローチでは、次のことが必要になります。`2^n`試みても実行不可能です。 数が多すぎるとエッジケースが発生します`0`s となり、等差制約と平衡条件の両方を満たすことができなくなります。 例えば、`s = "1001"`バランスを維持できない構成を強制するため、不可能です。

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    
    ones = s.count('1')
    zeros = s.count('0')
    
    if s[0] == '0' or s[-1] == '0' or zeros % 2 != 0:
        print("NO")
        continue
    
    a = []
    b = []
    half_ones = ones // 2
    ones_used = 0
    flip = True
    
    for ch in s:
        if ch == '1':
            if ones_used < half_ones:
                a.append('(')
                b.append('(')
            else:
                a.append(')')
                b.append(')')
            ones_used += 1
        else:
            if flip:
                a.append('(')
                b.append(')')
            else:
                a.append(')')
                b.append('(')
            flip = not flip
    print("YES")
    print(''.join(a))
    print(''.join(b))
```このソリューションでは、まず不可能なケースをフィルタリングし、次に、次の数の不変条件を維持することによってシーケンスを構築します。`(`決して下に落ちない`)`どちらの順序でも。 数える`1`交互に配置しながら対称的な配置を保証します。`0`s は異なる制約を満たします。
