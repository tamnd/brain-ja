 ## 解決策
 ## 問題の理解

 一連のプロセスをシミュレートしています$n$同一のサイコロ。各サイコロは独立して均一にランダムな面を示します。$1$に$k$巻くたびに。 ゲームはラウンド形式で進行します。 各ラウンドでは、残っているすべてのサイコロが振られ、結果を観察した後、額面を選択します。$x$。 あらゆるダイスが示すもの$x$永久に削除されます。 残りのサイコロは次のラウンドに進み、そこで再び独立して振られます。 

プレイヤーは選択することができます$x$ロールを見た後に最適化されるため、各ラウンドで現在のサイコロの中で最も頻繁に現れる額面が選択されます。 サイコロが残らなくなるとプロセスは停止し、目的は終了までの予想ラウンド数を計算することです。 

ランダム性は完全にサイコロの出目にあります。 戦略はロールを考慮すると決定的です。つまり、最も頻繁に使用される顔を常に削除します。 このプロセスが自明ではないのは、ラウンドで削除されるサイコロの数が多項分布の最大頻度に依存し、残りの状態が同じ確率変数に依存するためです。 

制約は、テスト ケース全体の合計サイズが小さく、$n \le 700$と合計$n$また、によって制限されます$700$。 This strongly suggests an$O(n^2)$または、テスト ケースごとにわずかに悪いソリューションは許容されますが、3 次的なものはすべて許容されます。$n$テストごとに個別に適用すると遅すぎます。 

微妙なエッジケースがタイから発生します。 複数の値がラウンド内の最大頻度に達する場合、それらのいずれかを選択できますが、取り除かれるサイコロの数は依然としてその最大頻度と同じです。 したがって、同点は状態遷移を変更せず、最大値の確率分布のみを変更します。 

もう 1 つの重要な点は、各ラウンドの後、残りのサイコロは「固定」されないということです。 それらは独立して再ロールされます。 これは、プロセスがサイコロの履歴や以前の額面ではなく、現在のサイコロの数のみに依存することを意味します。 どのソリューションも、このメモリレス構造に依存する必要があります。 

## アプローチ

 直接シミュレーションでは、最大で多項結果が繰り返し生成されます。$700$サイコロを振り、最大周波数を選択して続行します。 予想としては正しいですが、分岐要素が膨大であるため、これは役に立ちません。 1 つの州の結果の分布を推定するだけでも、すでに次のことが含まれます。$k^n$可能性。 

より構造化されたビューは次のように定義します。$E[n]$から始まる必要なラウンド数の予想として$n$サイコロ。 1 ラウンド後、次の中で最大の頻度を仮定します。$n$ロールは$m$。 それではまさに$m$サイコロが取り除かれ、プロセスは次から続行されます。$n-m$。 これにより再発が起こります$$E[n] = 1 + \sum_{m=1}^{n} \Pr(\text{max frequency} = m) \cdot E[n-m].$$したがって、最も重要な問題は、投げるときの最大占有率の分布を計算することになります。$n$ボールを入れる$k$ビンを均一にランダムに配置します。 

各ダイはボールに対応し、各面はビンに対応し、ビンの最大負荷の分布が必要です。 

重要な洞察は、ビンの包含/除外を使用して末尾の確率を計算することです。 正確な最大値で構成を直接カウントするのではなく、$m$、最初に計算します$$\Pr(\max \ge m),$$それから導出します$$\Pr(\max = m) = \Pr(\max \ge m) - \Pr(\max \ge m+1).$$計算するには$\Pr(\max \ge m)$、少なくとも 1 つのビンに少なくとも$m$ボール。 ビンに対して包含/除外を適用します。次のセットを選択します。$s$少なくとも必須のビン$m$ボール。 固定セットの場合、$s$ゴミ箱、私たちが予約します$m$それぞれに異なるボールを割り当て、残りを分配します。$n - sm$みんなで自由にボールを$k$ビン。 

固定された選択の方法の数$s$ビンは$$\frac{n!}{(m!)^s (n-sm)!} \cdot k^{n-sm},$$そして乗算する$\binom{k}{s}$交互の符号は包含と除外の合計を示します。 

これにより、組み合わせ最大分布問題が管理可能な合計に変換されます。$s$、そして期待のために動的プログラミングの繰り返しに入ります。

 ## アルゴリズムのチュートリアル

 ## アルゴリズムのチュートリアル

 1.修正$n$そして$k$、すべての結果を関数として解釈します。$n$ラベル付きサイコロ$k$顔。 各結果の確率は等しい$k^{-n}$。 これにより、確率を直接追跡するのではなく、プロセスが組み合わせ構造をカウントするように変換されます。 
2. 階乗および逆階乗を最大で事前計算します。$n$モジュロ$998244353$。 これらは、次の形式の多項式スタイルの式を評価するために必要です。$\frac{n!}{(m!)^s (n-sm)!}$効率的に。 
3. 考えられるしきい値ごとに$m$、計算する$\Pr(\max \ge m)$数値に対して包含/除外を使用する$s$少なくとも強制的に設置が義務付けられているゴミ箱の数$m$要素。 各用語は構成をカウントします。$s$選択されたビンは少なくとも受信します$m$サイコロ。 
4. 包含/除外ステップでは、固定の$s$、概念的に割り当てます$m$それぞれに異なるダイス$s$ゴミ箱、出発$n-sm$サイコロは無料です。 残りのサイコロは任意に割り当てることができ、$k^{n-sm}$。 この分離が機能するのは、サイコロにラベルが付けられているため、サイコロのサブセットの選択が組み合わせ的に有効であるためです。 
5.すべてを組み合わせる$s$寄与を交互の符号で乗算します。$\binom{k}{s}$。 これにより、選択したすべての制約が同時に適用される割り当ての正確な数が生成されます。 
6. で割って正規化します。$k^n$カウントを確率に変換して、$\Pr(\max \ge m)$。 
7. テール確率を正確な確率に変換します。$\Pr(\max = m) = \Pr(\max \ge m) - \Pr(\max \ge m+1)$。 これにより、1 ラウンドで除去されるサイコロの数の分布が得られます。 
8. 残りのサイコロに対して動的プログラミングを使用します。 定義する$E[n]$から始まる予想ラウンド数として$n$サイコロ。 それぞれについて$m$、プロセスはから移行します。$n$に$n-m$確率的に$\Pr(\max = m)$、だから蓄積する$E[n] = 1 + \sum_m \Pr(\max=m) E[n-m]$。 

### なぜ効果があるのか

 正確さは 2 つの構造的特性に基づいています。 まず、各ラウンドでは以前の出目が完全に忘れられるため、プロセスはサイコロの履歴ではなく、残っているサイコロの数のみに依存します。 第 2 に、最適なアクションの選択は、単一の多項実験における最大頻度のみに依存します。 これにより、各遷移が単一のスカラー確率変数に縮小されます。$m$、状態空間を 1 次元にします。 包含-除外計算はそのスカラーの分布を正確に捕捉し、DP の反復がプロセスの真の確率的発展と一致することを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    t = int(input())
    tests = []
    maxn = 0
    maxk = 0

    for _ in range(t):
        n, k = map(int, input().split())
        tests.append((n, k))
        maxn = max(maxn, n)
        maxk = max(maxk, k)

    N = maxn

    fact = [1] * (N + 1)
    invfact = [1] * (N + 1)
    for i in range(1, N + 1):
        fact[i] = fact[i - 1] * i % MOD
    invfact[N] = modinv(fact[N])
    for i in range(N, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    def C(n, r):
        if r < 0 or r > n:
            return 0
        return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

    def power(a, b):
        return pow(a, b, MOD)

    for n, k in tests:
        if n == 0:
            print(0)
            continue

        inv_kn = modinv(power(k, n))

        # precompute P[max >= m]
        P_ge = [0] * (n + 2)

        for m in range(1, n + 1):
            total = 0
            max_s = n // m
            for s in range(1, min(k, max_s) + 1):
                ways_choose_bins = C(k, s)
                ways_assign = fact[n] * invfact[n - s * m] % MOD
                ways_assign = ways_assign * modinv(power(m, s)) % MOD
                ways_assign = ways_assign * power(k, n - s * m) % MOD

                term = ways_choose_bins * ways_assign % MOD

                if s % 2 == 1:
                    total = (total + term) % MOD
                else:
                    total = (total - term) % MOD

            P_ge[m] = total * inv_kn % MOD

        P_ge[n + 1] = 0

        P_eq = [0] * (n + 1)
        for m in range(1, n + 1):
            P_eq[m] = (P_ge[m] - P_ge[m + 1]) % MOD

        E = [0] * (n + 1)
        for i in range(1, n + 1):
            val = 1
            for m in range(1, i + 1):
                val = (val + P_eq[m] * E[i - m]) % MOD
            E[i] = val

        print(E[n] % MOD)

if __name__ == "__main__":
    solve()
```実装では、最初に階乗テーブルを構築して、繰り返しの組み合わせクエリをサポートします。 機能$P_{\ge m}$しきい値を超えることを強制されたビンの数に対して包含/除外式を使用して計算されます。 各タームは、ビンの選択、強制サイコロの割り当て、残りのサイコロを自由に分配することを慎重に分離します。 

テール確率を正確な確率に変換した後、DP は次の昇順で期待値を計算します。$n$、すべての遷移はから始まるので、$n$厳密に小規模な州に限定されます。 

よくある落とし穴は、ラウンド後に残ったダイスが完全に振り直されることを忘れることです。そのため、DP は$n$配布履歴にもありません。 

## 実用的な例

 ### 例 1:$n=2, k=2$最大頻度の確率を追跡します。 

| メートル | P(最大 ≥ m) | P(最大 = m) |
 | --- | --- | --- |
 | 1 | 1 | 0 |
 | 2 | 1/2 | 1/2 |

 のために$n=2$、両方のサイコロが異なる場合、最大は 1 です。 等しい場合、最大値は 2 です。 

DP は次のようになります。$$E[2] = 1 + P(1)E[1] + P(2)E[0].$$以来$E[1]=1$、$E[0]=0$、私たちは得ます$E[2]=1 + 1 \cdot 1 + 1/2 \cdot 0 = 2$。 

これは、1 ラウンドで両方のサイコロが取り除かれる場合もあれば、1 つのラウンドのみが取り除かれるという考えと一致します。 

### 例 2:$n=3, k=3$最大頻度が 1、2、3 の間で変化する結果を考慮します。 

| メートル | 解釈 |
 | --- | --- |
 | 3 | すべてのサイコロが等しい |
 | 2 | 1 つの顔が 2 回現れる |
 | 1 | すべて異なる |

 DP はこれらの結果を組み合わせて、システムの予想される縮小を計算します。 この例では、プロセスが速い終了 (すべて等しい) と遅い減衰 (すべて異なる) をどのように混合し、再帰によって自然にバランスがとられるかを示しています。

 ## 特殊なケース

 いつ$n=1$、最大周波数は常に$1$, したがって、すべてのラウンドで唯一のダイスが削除されます。 DP は正しく与えます$E[1]=1$なぜなら$P(\max=1)=1$そして遷移は直接に進みます$E[0]$。 

いつ$k=1$、すべてのダイには常に顔が表示されます$1$したがって、最大周波数は常に次のようになります。$n$、プロセスはちょうど 1 ラウンドで終了します。 包含-除外式は正しく折りたたまれます。これは、ビンが 1 つだけ存在し、すべての質量が強制的に$m=n$。 

いつ$n$大きくて、$k$に近いです$n$、すべてのサイコロが明確である構成が確率の質量を支配します。 DP はこれを処理します。$P(\max=1)$が大きくなり、多くのラウンドにわたってゆっくりと減衰することが保証され、ラウンドごとに取り除かれるダイスがほとんどないという直感と一致します。
