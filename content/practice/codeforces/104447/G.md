 ## 解決策
 ## 問題の理解

 複数の独立したテスト ケースが与えられます。 各テスト ケースには、Kaito の友達を表す整数のリストと目標値 x があります。 選択したすべての値のビット単位の AND が正確に x になるような友人のグループを選択したいと考えています。また、すべての有効なグループの中で可能な限り最大のサイズが必要です。 AND が x に等しいグループを形成できない場合は、-1 を出力します。 

キー操作は、選択されたすべての数値に対するビット単位の AND です。 この操作では、選択したすべての番号にビットが設定されている場合にのみ、そのビットが設定されたままになります。 したがって、最終結果は、サブセット内のすべてのバイナリ表現の共通部分になります。 

制約は大きく、テスト ケース全体の合計数は最大 5 × 10^5 です。 これにより、すべてのサブセットを試行したり、すべてのペアやトリプルを試行したりするアプローチは即座に除外されます。 テスト ケースごとの線形より悪いものは失敗します。 

x に、選択した数値に存在しないビットが含まれている場合、微妙な失敗のケースが発生します。 たとえば、x = 6 (110₂) であるが、1 (001₂) のような数値を選択した場合、AND は必要なビットを即座に失い、それらを回復することはできません。 したがって、そのような数値は有効なサブセットの一部になることはできません。 もう 1 つの重要なエッジ ケースは、使用される可能性のあるすべての数値が、x にない追加ビットを共有している場合です。 その場合、要素を削除すると AND が減少するだけなので、サブセットは AND からそのビットを削除できません。また、すべての要素にそのビットが設定されていれば、その要素は常に存続します。 

## アプローチ

 最も直接的なアイデアは、友人のすべてのサブセットを試し、各サブセットのビットごとの AND を計算し、結果が x に等しい最大サイズを追跡することです。 これは正しいです。すべての可能性を検討するからです。 問題は、サブセットの数が n で指数関数的であることです。n = 40 の場合でも、これはすでに実行不可能になりますが、ここでは n が 10^5 まで増加します。 

AND がどのように動作するかを理解することで、より構造化された観察が可能になります。 数値は、x が必要とするビットを欠落していない場合にのみ、有効なサブセットに参加できます。 つまり、選択されたすべての値は (ai & x) = x を満たす必要があります。 これにより、入力が即座にフィルタリングされ、候補プールが絞り込まれます。 

ここでは、このフィルタリングされたプールのみを操作します。 それらをすべて取得すると、それらの AND は固定されます。 この AND がすでに x と等しい場合は、要素を追加しても AND がビット単位で小さくなるか等しくなるだけで、大きくなることはないため、すべての候補を取るのが最適です。 したがって、すでに正確に x にある場合は、すべてを維持する必要があります。 

すべての有効な候補の AND が x に等しくない場合は、すべての候補で 1 であるが x で 0 であるビットが少なくとも 1 つ存在します。 このビットは、一部の要素を削除しても決して削除できません。削除しても、存在しない場所にゼロが導入されるわけではないからです。 その場合、有効なサブセットはまったく存在しません。 

これにより、問題は、ビットごとのフィルタリングと最後の AND 計算による配列の 1 回のパスに分解されます。

 | すべてのサブセットに対するブルート フォース | O(2^n · n) | お(1) | 遅すぎる |
 | フィルター + グローバル AND チェック | テスト ケースあたり O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 各テスト ケースを個別に処理し、問題を単純なフィルタリングと集計のステップに削減します。 

### ステップ

 1. n と x、および配列 a を読み取ります。 
2. (ai & x) = x を満たさないすべての値 ai を破棄します。 

このステップにより、最後の AND で x の必要なビットが失われないことが保証されます。 
3. フィルタリング後に値が残っていない場合は、-1 を出力します。 
4. 残りのすべての値のビット単位の AND を計算します。 
5. この最後の AND が x に等しい場合、残りの要素の数を出力します。 
6. それ以外の場合は -1 を出力します。 

### なぜ効果があるのか

 単一の違反により最後の AND で x が破壊されるため、有効なサブセットは x のすべてのビットを含む数値のみで構成されている必要があります。 したがって、フィルタリングは制限ではなく、実現可能性のための必要条件です。

有効な数値に制限すると、要素を削除しても 1 ビットを 0 ビットに変えることしかできないため、サブセットの AND は、ビットの包含という点で完全なセットの AND 以上にすることができます。 これは、フィルタリングされた完全なセットが可能な限り最も強力な AND を与えることを意味します。 この最強の AND でも x と一致しない場合、欠落ビットまたは余分なビットを修正できるサブセットはないため、解決策は存在しません。 x と一致する場合、要素を削除しても AND が弱まり x から離れるだけなので、すべてを維持するのが最適です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x = map(int, input().split())
        arr = list(map(int, input().split()))

        filtered = []
        for v in arr:
            if (v & x) == x:
                filtered.append(v)

        if not filtered:
            print(-1)
            continue

        cur = filtered[0]
        for v in filtered[1:]:
            cur &= v

        if cur == x:
            print(len(filtered))
        else:
            print(-1)

if __name__ == "__main__":
    solve()
```実装はその推論を直接反映しています。 フィルタリング ステップでは、選択されたすべての数値に x のすべてのビットが含まれている必要があるという必要な条件が強制されます。 2 番目のループは、残りのすべての候補のグローバル AND を計算します。これは、サブセットから達成可能な最も強力な AND を表します。 

よくある落とし穴は、フィルタリング後のサブセットについて賢明になろうとすることですが、その必要はありません。 ビットごとの AND の単調な性質により、フィルターされたセット全体が機能するか、何も機能しないかのどちらかが保証されます。 

## 実用的な例

 ### 例 1

 入力:

 n = 4、x = 2

 a = [2、4、7、6]

 まず、(ai & x) = x でフィルタリングします。 x = 2 (010₂) なので、2 番目のビットが設定されている数値のみを保持します。 これにより、[2, 7, 6] が得られます。 

次に、それらの AND を段階的に計算します。 

| ステップ | 現在の AND |
 | --- | --- |
 | 開始 | 2 (010) |
 | かつ 7 | 2 (010) |
 | かつ 6 | 2 (010) |

 最終結果は 2 で、x と一致するため、3 を出力します。 

これは、有効な候補をすべて保持すると、目標を達成するのに十分な構造が維持されることを示しています。 

### 例 2

 入力:

 n = 3、x = 3

 a = [1、2、3]

 (ai & 3) = 3 でフィルタリングすると、1 と 2 の両方が必要なビットを欠落しているため、3 のみが保持されます。 

現在フィルタリング済み = [3]。 AND は 3 で、x と一致するため、答えは 1 になります。 

これは、ほとんどの要素が無効なケースをアルゴリズムが正しく処理していることを示しています。

    sys.stdin = io.StringIO(inp)

    output = []

    def input():

 ## 特殊なケース

 重要なエッジ ケースは、x = 0 の場合です。この状況では、x にはビットが設定されていないため、すべての数値は自動的に (ai & x) = x を満たします。 フィルタリングされたセットが配列全体となり、すべての数値の AND によって追加の制約が存在するかどうかが決まります。 すべての数値が共通のビットを共有する場合、AND はゼロにはならず、答えは -1 になります。 それ以外の場合は、すべての要素を取得できます。 

もう 1 つの重要なエッジ ケースは、フィルタリングによってすべてが削除される場合です。 たとえば、x が数値に含まれていないビットを必要とする場合、(ai & x) = x を満たす要素はありません。 このアルゴリズムは、それ以上の計算を試行することなく、即座に -1 を正しく出力します。 

最後の微妙なケースは、フィルターされたセットが空ではないが、すべての要素が x に存在しない追加の共通ビットを共有する場合に発生します。 この場合、グローバル AND はそのビットを保持し、サブセットがそれを削除できないため、最終的な答えは正確に -1 になります。
