 ## 解決策
 ## 問題の理解

 無限整数グリッド上の座標 (0, 0) にあるコインから始めます。 時間は 1 から始まる離散的なステップで進行します。各ステップ i で任意の整数 xi を選択すると、ステップが奇数であるか偶数であるかに応じて、コインは制約された方法で移動します。 

i が奇数の場合、移動により両方の座標に xi が追加されるため、(a, b) は (a + xi, b + xi) になります。 i が偶数の場合、移動により最初の座標に xi が加算され、2 番目の座標から xi が減算されるため、(a, b) は (a + xi, b − xi) になります。 タスクは、最小限の移動回数を使用してターゲット ポイント (n, m) に到達し、選択した xi 値のシーケンスを出力することです。 それができない場合は、-1 を出力します。 

制約は最大 100,000 のテスト ケースに適用され、最大 ±10^9 まで調整されます。 これにより、多数のステップにわたるテストごとのシミュレーションや、xi 値に対する反復検索に依存する構築が即座に排除されます。 各テストは一定時間またはほぼ一定時間内に解決する必要があります。 

微妙な点は、xi の大きさと符号に制限がないことです。 つまり、各動作は自由に選択されたスカラーによる線形変換であるため、その構造は組み合わせではなく完全に代数的です。 

単純な間違いは、これを x 座標と y 座標の独立した動きのように扱うことです。 たとえば、x と y を別々に解こうとすると、すべての動きがそれらを結合するため失敗します。 もう 1 つのよくある誤った仮定は、パリティの変更によって不可逆的な制約が生じるというものです。 実際、それは符号パターンを交互に変えるだけです。 

素朴な推論による具体的な失敗例は、最初に n を貪欲に一致させようとすることです。 x に対してのみ x の寄与を蓄積することによって (n, m) に到達しようとするとします。 すべての動きは連動して y にも影響を与えるため、独立した貪欲な蓄積が壊れることがすぐにわかります。 

## アプローチ

 この問題の鍵は、動きをより構造化された形式に書き直すことです。 

k 移動後の位置を (X, Y) とします。 各移動は常に xi を X に寄与しますが、Y はパリティに応じて +xi と -xi の間で切り替わります。 したがって、X と Y への寄与を別々に考えることができます。 

奇数 i の場合: 寄与率は (xi, xi)

 偶数 i の場合: 寄与は (xi, −xi)

 したがって、k が移動した後は次のようになります。 

X = sum(すべての i に対する xi)

 Y = sum(奇数 i の場合は xi) − sum(偶数 i の場合は xi)

 以下を紹介します。 

S = すべての xi の合計

 O = 奇数 i xi の合計

 E = 偶数 i xi の合計

 次に:

 X = S = O + E

 Y = O − E

 これらの方程式を解くと、次のようになります。 

O = (X + Y) / 2

 E = (X − Y) / 2

 したがって、任意の解の必要条件は、(n + m) と (n − m) の両方が偶数であることです。 それ以外の場合、O と E は整数ではないため、整数シーケンスはターゲットを生成できません。 

実現可能性が決定された後も、最小限の移動数が必要です。 各移動は 1 つの xi にのみ寄与するため、O と E を整数の合計として表現したいと考えます。 最適な戦略は、最大 2 回の動作でそれを実行することです。 

O と E の両方がゼロ以外の場合、次の 2 つの手を使用できます。 

1 つの奇数インデックスの移動による貢献度は O

 1 つの偶数インデックス移動が E に寄与します

 どちらかがゼロでもう一方がゼロでない場合でも、パリティが正しく揃っている場合に限り (最初の手が奇数である必要があります)、1 回の移動でそれを行うことができます。そうでない場合は、補償ゼロのような調整を導入することで 2 回の移動が必要になります。 

ただし、クリーンな観察はより単純です。常に最大 2 つの手を使用して有効な (O, E) を実現できます。1 つの手は、Y = X または Y = −X の場合、つまり m = n または m = −n の場合にのみ可能です。 

したがって、最適な答えは次のようになります。 

(n + m) または (n − m) が奇数の場合、-1 を出力します。 

それ以外の場合、(n, m) が (0, 0) の場合、答えは 0 になります。 

それ以外の場合、m = n または m = −n の場合、答えは 1 です。 

それ以外の場合、答えは 2 です。 

2 つの動きのシーケンスを構築するには、次のように設定します。 

x1 = O

 x2 = E

 ## アルゴリズムのチュートリアル

各テスト ケースを、ターゲット ポイントから導出される 2 つの変数に関する代数に還元します。 

1. S1 = n + m および S2 = n − m を計算します。 S1 または S2 のいずれかが奇数の場合、O および E の連立方程式は整数を生成できないため、-1 を返します。 これは、寄与を定義する線形システムを解くことから直接得られます。 
2. (n, m) が (0, 0) に等しい場合、移動は必要ないため、0 を出力します。 
3. m = n の場合、1 を出力し、x1 = n を選択します。 これが機能するのは、奇妙な動きはすべて両方の座標に均等に加算されるため、単一のステップが正確に対角線上に着地することができるためです。 
4. m = −n の場合、1 を出力し、x1 = n を選択します。 この場合、最初の動きは (n, −n) を生成し、ターゲットに直接一致します。 
5. それ以外の場合は 2 手を出力します。 O = (n + m) / 2 および E = (n − m) / 2 を計算します。x1 = O および x2 = E を設定し、奇数および偶数の寄与を独立して構築します。 

### なぜ効果があるのか

 この変換により、プロセスは、グリッド軸に沿った対称および非対称の動きに対応する 2 つの独立した線形コンポーネントに分割されます。 すべての動きは固定パターンで両方の成分に寄与するため、システムは整数上の 2×2 線形システムを解くことになります。 パリティ条件は解の完全性を保証し、各独立コンポーネントを専用の時間パリティ クラスに割り当てることができるため、2 移動の構築で十分です。 

最適なシーケンスよりも短いシーケンスは、派生コンポーネントの 1 つが 0 であり、1 手の対角線に正確に対応する縮退ケースを除いて、両方の制約を同時に表すことはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    
    for _ in range(t):
        n, m = map(int, input().split())
        
        if n == 0 and m == 0:
            out.append("0")
            continue
        
        if (n + m) % 2 != 0 or (n - m) % 2 != 0:
            out.append("-1")
            continue
        
        if n == m or n == -m:
            out.append(f"1 {n}")
            continue
        
        o = (n + m) // 2
        e = (n - m) // 2
        out.append(f"2 {o} {e}")
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```このソリューションはすべてのテスト ケースを読み取り、それぞれを個別に処理します。 パリティ チェックは、O と E が整数でなければならないという要件から直接得られます。 1 移動のケースは、ターゲットが 2 つの対角線のいずれかにある場合に正確に対応し、1 回の対称または非対称ジャンプで到達可能になります。 それ以外の場合、O と E に分割すると、構築されたシーケンスが両方の座標を正確に再現することが保証されます。 

よくある実装の落とし穴は、E の構築における符号を混同することです。正しい導出は、座標の動作に基づく推測からではなく、線形システムを解くことから得られます。 

## 実用的な例

 入力を考慮してください。 

n = 2、m = 7

 次のように計算します。 

S1 = 9、S2 = -5

 どちらも奇妙であるため、このシステムは実行不可能です。 

| ステップ | n | メートル | n+m | n-m | アクション |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 2 | 7 | 9 | -5 | パリティの不一致を検出する |

 これは、答えが -1 である理由を裏付けています。O と E は整数ではありません。 

ここで次のことを考えてみましょう。 

n = -10、m = 8

 計算:

 S1 = -2、S2 = -18

 どちらも偶数なので、次のようになります。 

O = -1

 E = -9

 | ステップ | ああ | E | 建設 |
 | --- | --- | --- | --- |
 | 1 | -1 | -9 | x1 = -1 |
 | 2 | -1 | -9 | x2 = -9 |

 移動後 1 (奇数): (0,0) → (-1,-1)

 移動 2 後 (偶数): (-1,-1) → (-10,8)

 これは、対称コンポーネントと非対称コンポーネントを分離すると、両方の座標がどのようにきれいに再構築されるかを示しています。

 ## 特殊なケース

 元のケース (0, 0) の場合、アルゴリズムは分解を試行せずにすぐに 0 を返します。 これにより、偽の 2 段階の解を生成する不必要な xi 値の構築が回避されます。 

(n, n) のような斜めのターゲットの場合、アルゴリズムは m = n を検出し、単一の動きを出力します。 たとえば、(3, 3) は x1 = 3 となり、奇数ステップを介して直接 (3, 3) を生成します。 

(n, −n) のような反対角ターゲットの場合、同じ 1 移動ロジックが適用されます。 たとえば、(2, −2) は x1 = 2 を生成し、最初の移動はターゲットと正確に一致します。 

(-10, 8) などの一般的なケースでは、アルゴリズムは 2 つの動きにフォールバックし、O と E を明示的に計算し、曖昧さなく決定論的に軌道を再構築します。
