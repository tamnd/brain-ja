 ## 解決策
 ## 問題の理解

 のセットをご用意しております。$n$黒板上の正の整数と数字$k \ge 2$。 どの整数も割り切れません$k$。 任意の 2 つの数字を繰り返し選択することができます$x$そして$y$、消して書き込んでください。$f(x+y)$その代わり。 機能$f$繰り返し除算します$k$結果が次で割り切れなくなるまで$k$。 目標は、これらの操作のシーケンスを実行して、1 つの数値だけが残り、その数値が$1$。 

入力は次のもので構成されます$n$16 までの数字とその合計が 2000 を超えない数字。$n$配列のサブセットにわたって指数関数的な解を探索できることがすぐに示唆されます。 合計が最大 2000 であるという制約は、合計と中間数値を効率的に追跡できることを示唆しています。 機能$f$2 つの数値を足して で減らすため、非線形性が生じます。$k$合計より小さい数値を生成する可能性があります。 ペアを任意の順序で合計するだけという不注意で貪欲なアプローチでは、1 に到達できない可能性があります。 

エッジ ケースには、すべての数値が 1 である状況、またはどの合計の組み合わせも 1 にならないように数値が選択されている状況が含まれます。$n = 2$、$k = 3$、および数字$[2, 2]$の場合、唯一の合計は 4 ですが、3 で割り切れないため、4 になります。その場合、最終的な数値は 1 ではなく 4 になります。単純なアルゴリズムでは、数値を繰り返し組み合わせると常に 1 に近づくと誤って仮定する可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、ペアを結合する可能なすべてのシーケンスが試行されます。 あるので$n-1$オペレーションと各オペレーションには最大$\binom{m}{2}$選択肢が増えると、シーケンスの数は階乗的に増加します。 具体的には、$\prod_{i=2}^{n} \binom{i}{2}$可能な操作シーケンスが、$n = 16$。 この方法は原理的には正しいですが、遅すぎます。 

重要な観察点は、操作が$f(x+y)$の和モジュロべき乗のみに依存します$k$。 事前計算ができる$f(s)$みんなのために$1 \le s \le 2000$。 以来$n \le 16$、サブセットに対して動的プログラミングのアプローチを使用できます。 初期数値のサブセットごとに、そのサブセットから取得できるすべての値を追跡できます。 サブセットから 2 つの数値を結合するたびに、それらの合計を検討し、以下を使用して減算します。$f$。 これにより、問題はすべてのサブセットとその達成可能な値を調査することになります。 

この洞察は、ビットマスキングを使用して問題をサブセット上の管理可能な DP に変換します。$2^{16} = 65536$、それは実現可能です。 各サブセットの達成可能な値を保存すると、1 が達成可能であれば一連の操作を再構築できます。 ビットマスクにより、親ポインターを使用して操作を追跡することも当然可能になります。

 ## アルゴリズムのチュートリアル

 1. 関数を事前計算する$f(x)$みんなのために$x \le 2000$。 各数値について、繰り返し除算します。$k$割り切れなくなるまで。 結果を配列または辞書に保存します。 
2. ビットマスクを使用して、初期数値のサブセットを表します。 サブセットごとに、達成可能なすべての数値の辞書を維持します。 各シングルトンのサブセットを初期化する$\{a_i\}$番号と一緒に$a_i$。 
3. 1 より大きいサイズのサブセットを繰り返します。サブセットごとに、それを 2 つの空ではない素のサブセットに分割することを検討してください。 2 つの部分から得られる達成可能な数値のペアごとに、次のように計算します。$f(x+y)$そしてそれを現在のサブセットの達成可能な値に追加します。 
4. 親ポインターを使用して、それぞれの新しい値を生成した操作を追跡します。 これにより、DP の完了後に一連の動きを再構築できるようになります。 
5. すべてのサブセットを処理した後、完全なセット (すべての数値) が達成可能な値として 1 を持っているかどうかを確認します。 そうでない場合は、「NO」を出力します。 
6. 1 が達成可能な場合は、完全なセットからシングルトンのサブセットまで親ポインターをたどることによって操作のシーケンスを再構築し、各ステップでどの 2 つの数値が結合されたかを記録します。 

機能する理由: DP は各ステップで、サブセットごとに考えられるすべての結果を正確に記録します。 素なサブサブセットのすべてのペアを考慮するため、達成可能な値が失われることはありません。 不変条件は、各サブセットの DP 辞書に、そのサブセットから取得できる数値が正確に含まれていることです。 これにより、1 に到達できる場合、アルゴリズムがそれを見つけることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import defaultdict

def f(x, k):
    while x % k == 0:
        x //= k
    return x

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    S = sum(a)
    
    # Precompute f(x) for 1..S
    F = [0] * (S + 1)
    for i in range(1, S + 1):
        F[i] = f(i, k)
    
    dp = [defaultdict(lambda: None) for _ in range(1 << n)]
    for i in range(n):
        dp[1 << i][a[i]] = None  # singletons
    
    for mask in range(1, 1 << n):
        if bin(mask).count('1') == 1:
            continue
        sub = mask
        while sub:
            sub = (sub - 1) & mask
            other = mask ^ sub
            if sub == 0 or other == 0:
                continue
            for x in dp[sub]:
                for y in dp[other]:
                    val = F[x + y]
                    if val not in dp[mask]:
                        dp[mask][val] = (sub, x, other, y)
    
    full = (1 << n) - 1
    if 1 not in dp[full]:
        print("NO")
        return
    
    print("YES")
    ops = []
    def build(mask, val):
        parent = dp[mask][val]
        if parent is None:
            return [val]
        sub1, val1, sub2, val2 = parent
        l1 = build(sub1, val1)
        l2 = build(sub2, val2)
        ops.append((l1[-1], l2[-1]))
        return l1[:-1] + l2[:-1] + [val]
    
    build(full, 1)
    for x, y in ops:
        print(x, y)

solve()
```このソリューションは事前計算します$f(x)$そして、すべてのサブセットにわたって DP テーブルを構築します。 の`build`関数は、DP に格納されている親ポインターを使用して操作を再構築します。 微妙な点は、サブセットごとに空の分割を二重にカウントしないようにする必要があることです。これはスキップすることで処理されます。`sub == 0`または`other == 0`。 最終操作は、実行される順序で出力されます。
