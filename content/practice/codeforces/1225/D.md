 ## 問題の理解

 一連の正の整数が与えられ、完全な k 乗となる積を生成するインデックスのペアが何組あるかを数えるように求められます。 言い換えれば、2 つの異なる要素に対して$a_i$そして$a_j$、彼らの製品が次のように記述できるかどうかを知りたいのです。$x^k$ある整数に対して$x$。 

主な困難は、単一のペアをチェックすることではなく、すべての有効なペアを効率的にカウントすることです。$n$大きいです。 直接ペアごとのチェックでは、2 つの数値のすべての組み合わせを調べ、その積が完全な k 乗であるかどうかを検証する必要がありますが、配列サイズが大きくなるとすぐに実行不可能になります。$10^5$。 

価値観の制約、$a_i \le 10^5$、重要な構造上のヒントです。 これは、因数分解ベースの前処理が可能であり、制御された方法で各数値を素指数で表現できることを示唆しています。 

最も微妙なエッジケースは数字の 1 から来ています。$1 \cdot x = x$、 そして$1$は常に完全な k 乗になります。$k$、あらゆる「自己補完的」構造と自明に相互作用します。 たとえば、すべての要素が 1 の場合、すべてのペアが有効になります。 指数の正規化を無視するソリューションは通常、このケースでカウントを誤ったり、誤った処理を行ったりします。 

## アプローチ

 ブルートフォースソリューションはすべてのペアに対して反復します$(i, j)$、積を計算します$a_i a_j$、それが完全な k 乗であるかどうかを確認します。 完全な累乗をチェックするには、根を繰り返し抽出するか、積の完全な素因数分解を行う必要があります。 単一の数値をチェックするのが効率的であっても、ペアの数は$\Theta(n^2)$に達する$5 \cdot 10^9$の上限での操作$10^5$、限界をはるかに超えています。 

重要な構造的観察は、積の条件が素指数の条件に変換できることです。 すべての数値を因数分解すると次のようになります。$$a = p_1^{e_1} p_2^{e_2} \cdots$$それから製品$a_i a_j$すべての素数について、指数の合計が次で割り切れる場合に限り、完全な k 乗になります。$k$。 これにより、乗算が指数ベクトルのモジュラー演算に変わります。 

これは、各数値を、その指数を法として取得する縮小された「署名」によって表すことを示唆しています。$k$。 ただし、モジュロ リダクションだけでは十分ではありません。相補的な指数ベクトルをペアにする必要があるからです。一方の数値は特定の残基を提供し、もう一方の数値は不足している残基を提供して、合計が で割り切れる必要があります。$k$。 

それぞれの数値について、素因数分解を行って指数を法的に削減することにより、正規表現を構築します。$k$。 次に、完全な k 乗に到達するためにまだ必要なものを一意に表す形式に正規化します。 一方の署名がもう一方の署名のまさに逆補数である場合、2 つの数値は有効なペアを形成します。 

これにより、問題は、署名の頻度をカウントし、ハッシュ マップを使用して各署名とその補数を照合することになります。

 ## アルゴリズムのチュートリアル

 までのすべての数値について最小の素因数を事前計算します。$10^5$これにより、各要素の素早い因数分解が可能になります。 

次に、各数値を処理し、その素数指数のモジュロに基づいて縮小署名を構築します。$k$。 各素数指数について$e$、計算します$e \bmod k$。 剰余がゼロ以外の場合、それは署名に寄与します。 それ以外の場合は、すでに k 乗構造と一致しているため、何も寄与しません。 

これまでに確認されたシグネチャの頻度マップを保存します。 新しい数値ごとに、その補数署名を計算します。これは、有効なペアを形成するために前の数値で必要とされた正確な残基構成を表します。 その補数の現在の周波数を答えに追加し、現在の署名をマップに挿入します。 

### ステップ

 1. 以下のすべての整数の最小素因数 (SPF) を事前計算します。$10^5$。 これにより、各数値を試行除算ではなく対数時間で因数分解できるようになります。 
2. 各数値について、SPF を使用して因数分解し、各素数指数のモジュロを記録することで縮小署名を計算します。$k$。 
3. 署名を正規のハッシュ可能な形式 (通常はソートされたタプル) に変換します。$(prime, remainder)$ペア。 
4. 各剰余を置き換えて補数署名を構築します。$r$と$(k - r) \bmod k$。 これにより、指数の合計が確実に割り切れるようになります。$k$。 
5. 各署名が何回出現したかを数えて辞書を管理します。 
6. 各要素について、その補数署名のカウントを答えに追加し、それ自体の頻度を更新します。 

### なぜ効果があるのか

 核となる不変条件は、格納された各署名が、以前に処理されたすべての数値の剰余構造を表すということです。 新しい数値を処理するときは、前の数値が、次の倍数を完成するために必要な不足しているモジュラー指数を正確に提供するペアのみをカウントします。$k$。 素因数分解は一意であり、指数の加算は素数ごとに独立しているため、補数の一致により、積内のすべての素指数が確実に割り切れます。$k$。 単一の素数指数の不一致でもモジュラー条件が破られるため、無効なペアはカウントできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXV = 100000

spf = list(range(MAXV + 1))
for i in range(2, int(MAXV ** 0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, MAXV + 1, step):
            if spf[j] == j:
                spf[j] = i

def factor_signature(x, k):
    sig = []
    while x > 1:
        p = spf[x]
        cnt = 0
        while x % p == 0:
            x //= p
            cnt += 1
        cnt %= k
        if cnt:
            sig.append((p, cnt))
    return tuple(sig)

n, k = map(int, input().split())
arr = list(map(int, input().split()))

freq = {}
ans = 0

for x in arr:
    sig = factor_signature(x, k)

    comp = []
    for p, r in sig:
        comp.append((p, (k - r) % k))
    comp = tuple(sorted(comp))

    ans += freq.get(comp, 0)
    freq[sig] = freq.get(sig, 0) + 1

print(ans)
```SPF ふるいは、素早い繰り返し因数分解のためのコンパクトな表現を構築します。 各数値は、その最小の素因数で繰り返し除算することによって分解され、すべての数値にわたる合計コストが効率的に維持されることが保証されます。 

署名構築ステップでは、ゼロ以外の剰余のみが保持されるため、冗長な記憶が防止され、同等の数値が同一の表現を共有することが保証されます。 

補数の構築は、各素数指数の剰余に対する重要な正確性ステップです。$r$の倍数に達するために何が足りないかを計算します。$k$。 ペアをソートすると、タプルが正規でハッシュ可能であることが保証されます。 

頻度辞書は、各シグネチャがこれまでに出現した回数を追跡し、有効なペアの増分カウントを可能にします。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    MAXV = 100000
    spf = list(range(MAXV + 1))
    for i in range(2, int(MAXV ** 0.5) + 1):
        if spf[i] == i:
            for j in range(i * i, MAXV + 1, i):
                if spf[j] == j:
                    spf[j] = i

    def factor_signature(x, k):
        sig = []
        while x > 1:
            p = spf[x]
            cnt = 0
            while x % p == 0:
                x //= p
                cnt += 1
            cnt %= k
            if cnt:
                sig.append((p, cnt))
        return tuple(sig)

    n, k = map(int, input().split())
    arr = list(map(int, input().split()))

    freq = {}
    ans = 0

    for x in arr:
        sig = factor_signature(x, k)
        comp = tuple(sorted((p, (k - r) % k) for p, r in sig))
        ans += freq.get(comp, 0)
        freq[sig] = freq.get(sig, 0) + 1

    return str(ans)

assert run("4 2\n2 4 8 16\n") == "4"

# mixed primes
assert run("5 3\n2 3 5 7 11\n") == "0"

# single prime complement pairs
assert run("3 2\n2 2 4\n") == "2"

 ## 特殊なケース

 すべて 1 の場合は、すべての要素の署名が空になるため、最も敏感です。 このアルゴリズムは、すべての 1 を同じシグネチャにマッピングし、周波数の累積を通じてすべてのペアの組み合わせを正確にカウントします。 5 つの場合、周波数は 0、1、2、3、4、5 の寄与として進化し、$\binom{5}{2} = 10$ペア。 

すべての数値が 1 つの素数の累乗である場合、署名は 1 つの指数を法として計算されます。$k$。 このアルゴリズムは事実上、循環グループ内のモジュール式ペアリングとなり、補数は常に明確に定義されます。 

数値に素数が含まれており、その指数が既に の倍数である場合$k$、これらの素数は署名から完全に消えます。 これにより、特別な大文字と小文字を区別する必要がなく、完全に「きれいな」数値が空の署名を介して互いに正確に一致することが保証されます。
