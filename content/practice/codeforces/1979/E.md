 ## 解決策
 ## 問題の理解

 2 次元平面上の点のセットと正の偶数の整数が与えられます。`d`。 タスクは、すべてのペア間のマンハッタン距離が正確に一致するように 3 つの異なる点を選択できるかどうかを判断することです。`d`。 点間のマンハッタン距離を思い出してください。`(x1, y1)`そして`(x2, y2)`は`|x1 - x2| + |y1 - y2|`。 出力は、そのような 3 点のインデックス、または`0 0 0`そのようなトリプルが存在しない場合。 

入力サイズは以下に達します`n = 2 * 10^5`単一のテスト ケース内のポイントと合計`n`すべてのテスト ケースでこれを超えることはありません。 制限時間が 3 秒であるとすると、すべての 3 つの点を反復処理するアルゴリズムには O(n³) 回の操作が必要ですが、これは明らかに実行不可能です。 したがって、すべてのポイント トリプルのブルート フォース チェックは遅すぎます。 

微妙なエッジケースが発生する場合`d`座標範囲に比べて大きいか、ポイントが密集しているためマンハッタン三角形が存在できません。 たとえば、すべての点が直線上にある場合、または点間の距離が常に より小さい場合、`d`、出力は次のようになります。`0 0 0`。 不用意に実装すると、無効なインデックスが返されたり、存在しないケースが見逃されたりする可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、すべてのトリプルに対して反復処理が行われます。`(i, j, k)`そして、3 つのペアすべての間のマンハッタン距離を計算します。 これは正しいですが、O(n³) 時間がかかるため、`n ~ 2*10^5`。 

重要な洞察は、マンハッタンの距離に関する幾何学的推論から得られます。 マンハッタン距離はひし形の等高線を形成し、3 つの点が等しいマンハッタン距離を持つには、`d`、特定の軸平行パターンで整列する必要があります。 具体的には、偶数の場合`d`、マンハッタン三角形は、ある点から開始して、軸に沿った直角二等辺パターンによって常に形成できます。`(x, y)`、残りの2点は`(x + d/2, y + d/2)`そして`(x + d/2, y - d/2)`または同様の対称的なバリエーション。 

したがって、三角形を完成させるために必要な他の 2 つの点がセット内に存在するかどうかを点ごとに効率的に確認できます。 O(1) ルックアップにハッシュ セットを使用すると、全体の複雑さがポイント数で線形になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n3) | O(n) | 遅すぎる |
 | 最適 | テスト ケースあたり O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、すべてを読みます。`n`ポイントを取得してリストに保存します。 O(1) メンバーシップ チェック用の点のタプルのセットを構築します。 
2. 各点を反復処理します。`(x, y)`三角形の潜在的な頂点として。 
3. 各点について、マンハッタン三角形のパターンに従って他の 2 つの頂点の候補位置を計算します。`d/2`軸に沿って移動します。 可能な構成は次の 4 つです。`(x ± d/2, y ± d/2)`Y オフセットの符号が反対になります。 
4. 各構成について、両方の候補点が点セットに存在するかどうかを確認します。 
5. そのようなペアが見つかった場合は、3 つの点のインデックスを返します。 全点を確認して三角形が見つからなかった場合は出力`0 0 0`。 
6. すべてのテスト ケースに対して繰り返します。 

なぜ機能するのか: 幾何学的対称性により、均等な距離にあるマンハッタンの三角形`d`軸揃えパターンのいずれかに準拠する必要があります。 私たちの方法では、各候補頂点のすべての対称の可能性を列挙し、存在を検証します。 ハッシュ セット メンバーシップにより高速な検索が保証され、このアプローチが正確かつ効率的になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    results = []

    for _ in range(t):
        n, d = map(int, input().split())
        points = []
        point_set = set()
        for i in range(n):
            x, y = map(int, input().split())
            points.append((x, y))
            point_set.add((x, y))

        found = False
        half_d = d // 2
        for idx, (x, y) in enumerate(points):
            candidates = [
                ((x + half_d, y + half_d), (x + half_d, y - half_d)),
                ((x - half_d, y + half_d), (x - half_d, y - half_d)),
                ((x + half_d, y + half_d), (x - half_d, y + half_d)),
                ((x + half_d, y - half_d), (x - half_d, y - half_d))
            ]
            for (p1, p2) in candidates:
                if p1 in point_set and p2 in point_set:
                    idx1 = points.index(p1) + 1
                    idx2 = points.index(p2) + 1
                    results.append(f"{idx+1} {idx1} {idx2}")
                    found = True
                    break
            if found:
                break
        if not found:
            results.append("0 0 0")

    sys.stdout.write("\n".join(results))

solve()
```### 説明

 インデックスを取得するためにポイントをリストに保存し、O(1) 存在チェックのためにセットにポイントを保存します。 の`half_d = d // 2`単純化により、三角形の他の 2 つの頂点の相対位置を効率的に計算できます。 すべてのポイントを潜在的なアンカーとして反復処理し、4 つの構成にわたるネストされたループにより、すべての対称の可能性がチェックされるようにします。 の`index`すべてのポイントが個別であるため、呼び出しは安全です。

## 特殊なケース

 すべての点が直線に並んでいる場合、マンハッタン三角形は存在しません。 たとえば、ポイント`(0,0),(0,2),(0,4)`と`d=2`有効な三角形が生成されません。 アルゴリズムは正しく反復され、候補が見つからず、次の結果を返します。`0 0 0`。 大きな座標は整数のみを使用して処理されます。`d//2`シフトは正確なので、`d`均等であることが保証されています。
