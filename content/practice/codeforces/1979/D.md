 ## 問題の理解

 長さのバイナリ文字列が与えられます`n`そして数字`k`それは分ける`n`。 タスクは、文字列に対して特別な操作を 1 つだけ実行して、`k`-ちゃんとした。 あ`k`-適切な文字列は次で始まります`k`同一の文字と、その後の長さのすべてのブロック`k`前のブロックと比較して値が変わります。 

この操作には 2 つのステップがあります。まず、長さのプレフィックスを反転します。`p`(`1 ≤ p ≤ n`)、文字列全体を左に循環シフトします。`p`。 これらの手順を組み合わせると、プレフィックスが効果的に最後に移動され、同時にその内部順序が逆転し、元の文字列の回転および再配置されたバージョンが作成されます。 

入力制約は次のことを示しています。`n`と同じ大きさにすることができます`10^5`すべてのテスト ケースの合計は次のようになります。`2·10^5`。 これにより、考えられるすべてをチェックするソリューションは即座に除外されます。`p`直接シミュレーションでは時間がかかるため、それぞれに対して完全な文字列シミュレーションを単純に実行します。`O(n^2)`最悪の場合、遅すぎます。 エッジケースには、すでに存在する文字列が含まれます。`k`-proper、すべて同一のビットを持つ文字列、および不可能な文字列`p`特性を満たすことができます。 

たとえば、`s = "1110"`そして`k = 2`、ありません`p`を生み出すことができます`k`-proper string は、どの操作でも 1 または 0 の繰り返しパターンが保持され、交互の要件を破るためです。 単純なブルートフォースは誤ってすべてを試みる可能性があります`p`シミュレートしますが、遅すぎます。 

## アプローチ

 ブルートフォースアプローチでは、あらゆる可能性が試みられます`p`から`1`に`n`、逆シフトと巡回シフトをシミュレートし、結果の文字列が以下であるかどうかを確認します。`k`-ちゃんとした。 シミュレーションだけでも費用がかかります`O(n)`あたり`p`、与える`O(n^2)`テストケースごとに。 これなら小規模でも実現可能`n`、しかし、`n ~ 10^5`それは不可能になります。 

重要な観察点は、`k`-適切な条件では、次の文字列で構成される必要があります。`n/k`長さのブロック`k`、それぞれがすべて 0 のブロックとすべて 1 のブロックを交互に配置します。 これは、最初のブロックとそのビットの位置のみが文字列の残りの部分を決定することを意味します。 さらに、この特別な操作には予測可能な効果があります。プレフィックスを反転して左にシフトした後、最初の`p`元の文字列の文字が最後に移動して反転され、残りのサフィックスが前に移動します。 したがって、最初のことを考慮すると、`k`演算後の文字はすべて 0 かすべて 1 でなければならず、循環的な性質により候補を見つけることができます。`p`を揃える`k`-正しくブロックします。 

私たちは問題をポジションを見つけることに落とし込みます`p`最初はどこで`k`回転および再配置された文字列の文字は均一なブロックを形成します。 これは、文字列をスキャンすることで効率的に実行できます。`O(n)`最大でも 2 つの候補を検討します`p`値: 先頭で 0 を揃える値と 1 を揃える値。 なぜなら`k`分割する`n`、最初だけを確認する必要があります`k`各ブロックの文字を確認して、パターンが正しく続いているかどうかを判断します。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`、`k`、およびバイナリ文字列`s`。 
2. 最初の 0 と 1 の数を数えます。`k`文字。 これらにより、どの値が最初の均一ブロックを形成できるかが決まります。 
3. 最初の文字がすべて入っている場合`k`が同一である場合、文字列はすでに`k`最初のブロックに -proper があります。 「正確に 1 つの操作」を満たすには、次を選択します。`p = k`またはその他の有効な`p`保存するもの`k`-手術後の適切さ。

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        s = input().strip()
        if k == n:
            # Any p will result in a string with only one block
            print(1)
            continue
        # Count the first k characters
        first_k = s[:k]
        zeros = first_k.count('0')
        ones = k - zeros
        # If already uniform, choose p = k to satisfy "exactly one operation"
        if zeros == 0 or ones == 0:
            print(k)
            continue
        # Otherwise, find the first p that moves enough of the same type to the front
        # Optimal strategy: pick the first block boundary where we can align
        p = -1
        for i in range(k, n + 1):
            block = s[i-k:i]
            if block.count('0') == k or block.count('1') == k:
                p = i
                break
        print(p)
        
if __name__ == "__main__":
    solve()
```コードは最初にエッジケースを処理します。`k = n`, すべての操作は単一のブロックを満たすためです。 次に、最初の`k`文字が均一である場合、`p = k`操作結果が有効であることを保証します。`k`-適切な文字列。 最後に、一定の長さのブロックをスキャンします`k`プレフィックスを見つけるには`p`操作後の開始時に均一なブロックを揃えます。 使用する`count`均一性を効率的に検証できるようになります。

 ## 特殊なケース

 文字列がすでにある場合`k`-そうですね、まだ操作を適用する必要があります。 例えば、`s = "0000"`と`k = 4`。 アルゴリズムは最初のブロック内のゼロをカウントし、それが均一であることを確認してから、`p = k`動作要件を満たすため。 のために`s = "101010"`と`k = 3`、スキャンは `p = 3 で整列できるブロックを見つけます。
