 ## 解決策
 ## 問題の理解

 アリスとボブという 2 人の水泳選手が 50 単位のセグメント上を前後に移動しながら、まったく同じ位置で観察される一連の瞬間が与えられます。 どちらも時間 0 の位置 0 から開始し、50 に移動し、即座に逆転し、一定の正の速度で永遠に繰り返します。 それらの速度は異なり、両方とも実数です。 

残された唯一の情報は、彼らが会ったときのソートされたリストです。 課題は、これらの記録された時間が正確に 2 人の水泳選手の最初の出会いの瞬間となるような 2 つの明確な正の速度が存在するかどうかを判断することです。 

主な問題点は、動きが端点での反射によって周期的であるため、位置が全体的に時間的に線形ではなく、方向の変化に対して区分的に線形になることです。 このような 2 つの周期的な軌跡の間の交差点は、構造化された、しかし自明ではない一連の時間を形成します。 

制約は大きく、テスト ケース全体の合計 n は最大 200,000 です。 これにより、モーションをシミュレートしたり、ポイントのペアごとに候補速度をチェックしたりするアプローチは除外されます。 テスト ケースごとに n の二次関数は不可能であり、テスト ケースごとに O(n log n) であっても非常に厳密でなければならず、線形パスが推奨されます。 

局所的な一貫性は維持されるが、グローバルな構造が不可能な場合、微妙な失敗のケースが発生します。 たとえば、算術的またはほぼ算術的であるように見えるシーケンスでも、速度が等しいか位相調整が不可能であることを意味するため、無効になる可能性があります。 もう 1 つの注意が必要なケースは、n が小さい場合、特に n = 1 または n = 2 です。この場合、ほとんどすべてのパターンが局所的に実行可能ですが、それでも鏡映対称制約を慎重に処理する必要がある場合があります。 

## アプローチ

 強引なアイデアは、2 つの速度を仮定し、両方の水泳選手をシミュレートし、すべての集合時間を計算してから、入力プレフィックスと比較することです。 1 つの速度比を固定したとしても、反射をシミュレートする必要があり、実数値のイベント時間の一致は離散的に制限されません。 時間 T までの会議の数は T 内で直線的に増加し、候補者の速度は連続空間に存在するため、これはすぐに実行不可能になります。 

構造的な洞察は、長さ 50 のセグメント上の反射を、周期的な拡張を使用して直線の動きに展開できるということです。 各スイマーは、鋸歯状マッピングを使用して無限の線上を移動することに相当し、これにより、位置の等価性が時間と整数の反射インデックスを含む一次方程式に変換されます。 このような 2 つの周期的線形関数が交差すると、結果として生じる集合時間は、相対速度と反射位相によって決定される等差数列の和集合を形成します。 

重要な簡素化は、一連の会議全体が複雑である一方で、最初の数回の会議は非常に制限されているということです。 連続する有効な会議時間の差は、単一の線形反復構造から導出された制御されたパターンで交互に現れる必要があります。 特に、順序を修正すると、シーケンスは、反射状態のパリティによって引き起こされる最大 2 つの等差数列のインターリーブとして表現可能でなければなりません。 

これにより、問題は、シーケンスを少数の一貫した線形パターンに分割できるかどうかを確認するだけになります。 標準換算により、交互の項間の差異が安定する一貫した分解が存在するかどうかのテストが行​​われます。

 ## アルゴリズムのチュートリアル

 重要な考え方は、有効な会議時間は、インターリーブされた 2 つの線形シーケンスから得られるかのように動作する必要があるということです。 反射パリティから生じる可能性のある唯一の意味のある構造的分割を試すことによって、これをテストします。

1. n ≤ 2 の場合、答えは常に有効です。 1 つまたは 2 つのポイントを使用すると、常に速度と位相オフセットを選択して単一の交差を強制したり、それに応じて初期アライメントを調整したりできます。 この規模では構造的な矛盾はあり得ません。 
2. n ≥ 3 の場合、シーケンスを、反射状態によってインターリーブされた 2 つの等差数列の潜在的な混合として調べます。 保持する必要がある最も単純な不変条件は、シーケンス自体が算術であるか、任意の 1 つの要素を削除すると等差数列が得られるということです。 

これは、速度が固定されると、実際の基礎となる構造では間隔の自由度が 1 つしかないという事実から来ています。 反射は方向を反転するだけで、非線形の時間歪みは生じません。 
3. 連続する要素間の差を計算します。 すべての差が等しい場合、シーケンスは算術的であり、直ちに有効になります。 
4. それ以外の場合は、各インデックス i を (概念的に) 1 回削除して、残りのシーケンスが等差数列を形成しているかどうかを確認してみてください。 これが機能するのは、有効な反射誘起構造であれば、観測されたプレフィックスに最大でも 1 つの「位相不一致」が存在する可能性があるためです。 その不一致は、進行中の単一の外れ値に対応します。 
5. 削除によって一定の差が得られる場合は、VALID を返します。 
6. そのような削除が機能しない場合、シーケンスは周期的な反射の下で別個の速度のどのペアにも対応できないため、無効になります。 

### なぜ効果があるのか

 セグメント上のモーションは、位置空間 (0 ～ 50 ～ 0 のミラーリング) で周期 100 の実線上の直線モーションに展開できます。 位置の等価性は、この周期構造を法とする線形等価性に帰着します。 その結果、相対位相が固定されると、会議時間は最大でも 1 つの一貫した線形発生器を使用してシーケンスを形成します。 

2 回以上の中断の後に 2 つの異なる局所的な傾斜が現れた場合、それは複数の反射フェーズにわたって速度比が一貫していないことを意味し、等速運動と矛盾します。 したがって、観察されたプレフィックスの算術構造からの逸脱の可能性は 1 つだけであり、これは 1 つの要素を削除することに正確に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_arith(arr):
    if len(arr) <= 2:
        return True
    d = arr[1] - arr[0]
    for i in range(2, len(arr)):
        if arr[i] - arr[i - 1] != d:
            return False
    return True

def solve_case(t):
    n = len(t)

    if n <= 2:
        return True

    if is_arith(t):
        return True

    # try removing one element
    for i in range(n):
        prev = None
        diff = None
        ok = True
        first = True
        last = None

        for j in range(n):
            if j == i:
                continue
            if prev is None:
                prev = t[j]
                continue
            cur_diff = t[j] - prev
            if diff is None:
                diff = cur_diff
            elif cur_diff != diff:
                ok = False
                break
            prev = t[j]

        if ok:
            return True

    return False

def main():
    c = int(input())
    out = []
    for _ in range(c):
        n = int(input())
        t = list(map(int, input().split()))
        out.append("VALID" if solve_case(t) else "INVALID")
    print("\n".join(out))

if __name__ == "__main__":
    main()
```このソリューションは、構造上の制約に違反できないため、最初に小さなシーケンスを直接処理します。 次に、シーケンス全体がすでに等差数列になっているかどうかを確認します。これは、安定した会議頻度に対応します。 

そうでない場合は、各要素の削除を試み、残りのシーケンスが算術になるかどうかを確認します。 内部チェックは 1 回のパスで実行され、一定の差異が検証されます。 

重要な点は、不一致があるとその候補が即座に無効になるため、ローリング構造を維持しようとするのではなく、除去ごとに新たな差異を再計算することです。

 ## 特殊なケース

 n = 1 の場合、最初の会議がその時間に正確に揃うように速度を選択することで単一のタイムスタンプを生成できるため、アルゴリズムはすぐに VALID を返します。 

すでに算術的であるシーケンスの場合、削除は不要であり、有効性のみを維持できるため、アルゴリズムは削除を試行せずに正しく受け入れます。 

ちょうど 1 つの点が算術パターンを妨害する場合、除去ループはその点を分離し、一定の差を復元します。これは、単一の位相のずれが構造上の欠陥ではなく 1 つの一貫性のない観測に対応するという事実と一致します。 

複数の矛盾したギャップを持つシーケンスの場合、除去しても一定の差は生じず、複数の矛盾した速度レジームが必要となるため、アルゴリズムはそれらを正しく拒否しますが、これは等速運動では不可能です。
