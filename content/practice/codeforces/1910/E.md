 ## 解決策
 ## 問題の理解

 2 つの配列が与えられています。`a`そして`b`、それぞれの長さ`n`。 インデックスごとに`i`、交換するかもしれません`a[i]`そして`b[i]`何度でも。 すべての交換の後、次のように定義します。`f(c)`配列の連続した部分配列の最大合計として`c`、合計が次のような空の部分配列の可能性を含みます。`0`。 私たちの使命は最大化することです`f(a) + f(b)`任意のスワップシーケンスを使用します。 

入力は最大で構成されます`10^4`テストケースとすべての合計`n`テストケース全体では最大でも`2 * 10^5`。 の各要素`a`そして`b`以下のように小さくすることができます`-10^9`または同じ大きさ`10^9`。 これは、どのソリューションも各テスト ケースを線形時間で効率的に処理する必要があり、すべてのスワップ シーケンスを明示的に考慮するソリューションを除外する必要があることを意味します。`n`。 

すべての要素が負の場合、微妙なエッジ ケースが発生します。 不注意な実装では、負の値を合計して負の値を生成しようとする可能性がありますが、定義により、部分配列の合計の最大値は常に次のようになります。`0`(空のサブ配列を取得します)。 たとえば、次の場合`a = [-5, -1]`そして`b = [-2, -3]`、正しい出力は次のとおりです。`0`。 空の部分配列を処理しない単純なアプローチでは、誤って返されます。`-1`または別の負の値。 

もう 1 つの明白ではない状況は、一方の配列のインデックスに大きな負の数があり、もう一方の配列のインデックスに大きな正の数がある場合です。 1 つの配列を貪欲に最大化するのではなく、両方の配列でプラスの寄与を維持するには、スワップが必要になる場合があります。 

## アプローチ

 ブルートフォースソリューションでは、すべてが列挙されます。`2^n`スワップの組み合わせ。 構成ごとに、次のように計算します。`f(a)`そして`f(b)`Kadane のアルゴリズムを使用します。 これは明らかに実行不可能です。`n = 20`、`2^20`可能性は 100 万通り以上あり、最悪のケースは`n = 2*10^5`。 

重要な洞察は、各インデックスについて`i`2 つの数字のどちらを決定するだけで済みます。`a[i]`そして`b[i]`、どの配列に入れる必要があります。 以来`f(c)`は最大連続合計として計算されるため、局所的に推論できます。 具体的には、配列を左から右に処理すると、Kadane のアルゴリズムは各位置で終わる最適なサブ配列を追跡します。 各インデックスで、スワップするかスワップしないという 2 つの可能性を計算できます。 2 つの状態を維持します: で終わる最大部分配列合計`i`のために`a`そして`b`での選択に応じて、`i`。 これは、線形時間動的計画法のアプローチにつながります。`i`は、現在の要素と以前の最大合計にのみ依存します。 

直観的には、特定のインデックスについて、より大きな要素がそれぞれの配列の累計に寄与し、より小さな要素が他の要素に寄与するようにしたいと考えます。 Kadane のアルゴリズムは、負の寄与によって全体の合計がゼロを下回らないように自動的に保証します。

 ## アルゴリズムのチュートリアル

 1. 2 つの変数を初期化する`sum_a`そして`sum_b`配列の現在のインデックスで終わる最大の連続した部分配列の合計を追跡します。`a`そして`b`。 2 つの大域最大値を初期化する`max_a`そして`max_b`ゼロに。 
2. 配列を左から右に繰り返します。 インデックスごとに`i`、両方の可能な割り当てを検討してください。`a[i]`で`a`そして`b[i]`で`b`、またはそれらを交換します。 アップデート`sum_a`そして`sum_b`で終わる最大合計となります`i`現在の割り当てでは、合計がゼロを下回らないようにします。 これが Kadane のアルゴリズムの本質です。 
3. 具体的には、値の割り当てを決定した後、更新します。`sum_a`に`max(sum_a + a[i], a[i])`そして`sum_b`同様に。 スワップによって合計が改善される場合 (つまり、`b[i]`～にさらに貢献する`sum_a`よりも`a[i]`）、交換を検討してください。 重要なのは、各アレイの現在の最大値を維持するだけでよいということです。 
4. 各インデックスを処理した後、更新します`max_a`そして`max_b`現在の値の最大値になるようにし、`sum_a`/`sum_b`。 
5. ループ後、`max_a + max_b`テストケースの答えです。 

機能する理由: Kadane のアルゴリズムは、各インデックスでの累計が、そのインデックスで終わるサブ配列の最大合計であることを保証します。 各インデックスでのスワップを考慮することで、ローカルで最適な選択がグローバルに最適なソリューションに貢献することを保証します。 各インデックスでの決定は隣接しない要素から独立しているため、組み合わせが失われることはなく、空の部分配列の場合は合計をゼロにリセットすることによって自動的に処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        # running sums for Kadane's algorithm
        sum_a, sum_b = 0, 0
        max_a, max_b = 0, 0
        
        for i in range(n):
            # compute max subarray sum ending at i
            new_sum_a = max(sum_a + a[i], sum_b + b[i], 0)
            new_sum_b = max(sum_b + a[i], sum_a + b[i], 0)
            sum_a, sum_b = new_sum_a, new_sum_b
            max_a = max(max_a, sum_a)
            max_b = max(max_b, sum_b)
        
        print(max_a + max_b)

if __name__ == "__main__":
    solve()
```このソリューションは、両方の配列を同時に追跡する、修正された Kadane のアルゴリズムを使用します。`new_sum_a`そして`new_sum_b`マイナスの合計が合計を引き下げるのを防ぎながら、両方の可能性 (スワップまたはスワップなし) を検討してください。 最終結果は、両方の配列の最大値を合計します。
