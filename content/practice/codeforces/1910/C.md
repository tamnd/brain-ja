 ## 問題の理解

 として表される沼が与えられています。$2 \times n$グリッド。 各列には、アスタリスクでマークされたスイレンの葉が 1 つと、ドットでマークされた空のセルが 1 つあります。 すべてのスイレンの葉の上にカエルが座っています。 すべてのカエルは、1 回の移動で隣接するセル (左、右、上、下のいずれか) にジャンプする必要があります。 カエルはグリッドの外に移動したり、別のカエルと同じスイレンの葉に着地したり、同じ列内の位置を交換して互いに交差したりすることはできません。 カエルはスイレンの葉の上に落ちた場合にのみ生き残ることができます。 課題は、ジャンプ方向を選択した場合に生き残ることができるカエルの最大数を決定することです。 

入力は複数のテスト ケースで構成され、それぞれのテスト ケースは次のとおりです。$n$列。$n$まで可能です$2 \cdot 10^5$、との合計$n$すべてのテスト ケースにわたって、最大でも$2 \cdot 10^5$これは、各テスト ケースを大まかに解決する必要があることを意味します。$O(n)$時間。 カエルのジャンプのすべての順列をチェックするアプローチは指数関数的であり、明らかに実行不可能です。 

複数のカエルが同じ隣接するセルに移動しようとする可能性がある場合、またはカエルが安全なジャンプをブロックされている場合、明らかではないエッジケースが発生します。 たとえば、単一の列について考えてみましょう。```
*
.
```ここで、カエルにはジャンプできる隣接するスイレンの葉がないため、答えはゼロです。 もう 1 つのエッジ ケースは、次のように、スイレンの葉が上部の行と下部の行で交互に配置される連続した列です。```
*.*.*
.*.*.
```単純な左右の貪欲な割り当てでは、1 つのカエルを動かすと別のカエルがブロックされる可能性があるため、誤って可能な限り多くのカエルを数えてしまう可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、各カエルに対して可能なすべての方向を試みます。 各カエルには最大 3 つの選択肢 (上/下、左、右) があるため、可能性の総数は次のようになります。$O(3^n)$テストケースごとに。 これは正しいですが、実行不可能です$n$まで$2 \cdot 10^5$。 

重要な洞察は、生存は隣接するスイレンの葉にのみ依存するということです。 各列の一番上の行または一番下の行にカエルがいます。 カエルは、隣接する細胞にスイレンの葉があれば生き残ることができます。 グリッドを 0 と 1 の文字列として表し、1 が上の行のカエル、0 が下の行のカエルである場合、問題は、カエルが競合することなく隣接する列に安全にジャンプできる遷移をカウントすることに帰着します。 

最適なアプローチでは、グリッドを一連の列として扱い、各列の上部または下部にカエルが配置されます。 左から右に繰り返します。 上の行のカエルが同じ列の一番下の行を空にしている場合、垂直方向に移動することはできません。そのため、次の列の一番下の行にカエルが含まれており、斜めに移動できる場合にのみ生き残ることができます。 2 匹のカエルが同じスイレンの葉にジャンプしないように、「キャリーオーバー」状態を維持します。 これにより問題は次のように縮小されます$O(n)$各列が 1 回検査されるため、テスト ケースごとに実行されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(3^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. カウンタを初期化する`survivors = 0`。 これで生き残れるカエルの数が決まります。 
2. 列を左から右に繰り返します。 各列の上部と下部の行のスイレンの位置を確認します。 
3. 両方の行にカエルが含まれている場合、カエルにはジャンプできる隣接するスイレンの葉がないため、この列では生き残ることができません。 次の列に移動します。 
4. 1 つの列にカエルがいて、もう 1 つの列が空の場合、カエルは生き残る可能性があります。 次の列をチェックして、カエルが競合せずにそこにジャンプできるかどうかを確認します。 
5. カエルが競合せずにジャンプできる斜めまたは水平方向に隣接するスイレンの葉を持っている場合、インクリメントします。`survivors`そして、そのセルをこの移動のために占有されているものとしてマークします。 
6. すべての列が処理されるまで繰り返します。 
7. 出力`survivors`テストケース用。 

機能する理由: 各カエルには最大 2 つの可能な動き (垂直または水平) があります。 左から右にスキャンし、占有されているターゲット セルをマークすることで、すべての制約を尊重しながら、2 匹のカエルが同じスイレンの葉に移動しないようにします。 カエルを隣接する利用可能なスイレンのパッ​​ドに移動するという貪欲な選択は、その後のカエルが競合せずにカエルを移動させることができないため、生存者の数を最大化します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    top = input().strip()
    bottom = input().strip()
    survivors = 0
    i = 0
    while i < n:
        if top[i] == '*' and bottom[i] == '*':
            i += 1
            continue
        if top[i] == '*' and bottom[i] == '.':
            if i+1 < n and bottom[i+1] == '*':
                survivors += 1
                i += 2
            else:
                i += 1
        elif top[i] == '.' and bottom[i] == '*':
            if i+1 < n and top[i+1] == '*':
                survivors += 1
                i += 2
            else:
                i += 1
    print(survivors)
```ソリューションは列を反復処理します。 カエルが 1 つの行にいて、隣接する列が競合せずにジャンプできる場合、生存者数をインクリメントします。 の`i += 2`カエルを収容するために使用されている場合は、次の列をスキップします。
