 ## 問題の理解

 配列が与えられ、そのプレフィックスの合計を処理します。 させて`pref[i]`最初の合計を示します`i`要素、`pref[0] = 0`。 サブアレイ`[l, r]`合計がゼロの場合は良好と呼ばれます。これは次と同等です。`pref[r] - pref[l-1] = 0`、 または`pref[r] = pref[l-1]`。 

次に、この問題は、より強い概念を数えることを求めます。つまり、合計が 0 であるサブサブ配列が少なくとも 1 つ含まれている場合、そのサブ配列は良好であると言えます。 プレフィックスの合計に関して、これは範囲内であることを意味します。`[l-1, r]`、2 つのインデックスが存在する必要があります`i < j`そのような`pref[i] = pref[j]`。 すべてのプレフィックスを合計すると、`[l-1, r]`が異なる場合、ゼロサム部分配列は存在せず、セグメントは不良または良好とみなされます。 

したがって、タスクは部分配列を数えることに減ります。`[l, r]`プレフィックスの合計が`[l-1, r]`すべてが異なるわけではありません。

 ## アルゴリズムのチュートリアル

 問題は完全にプレフィックス値の等しいことに関するものであるため、最初に配列をプレフィックスの合計に変換します。

5.アップデート`last[pref[r]] = r`。

### なぜ効果があるのか

 いつでも固定`r`、窓`[l, r]`で終わる最長の接尾辞です`r`すべてのプレフィックスの合計が異なります。 任意の出発点`l' < l`それを保証します`[l', r]`で繰り返されるプレフィックスの合計が含まれている必要があります。`l-1`そして、以前の位置がセグメント内に強制的に挿入されます。 逆に、どれでも、`l' >= l`セグメント内のすべてのプレフィックス合計を区別します。 これにより、有効な開始点と無効な開始点のクリーンなパーティションが作成され、`l`正確な寄与境界。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    pref = [0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + a[i]

    last = {}
    l = 0
    ans = 0

    for r in range(n + 1):
        x = pref[r]

        if x in last and last[x] >= l:
            l = last[x] + 1

        last[x] = r
        ans += l

    print(ans)

if __name__ == "__main__":
    solve()
```この実装は、プレフィックス合計に関するスライディング ウィンドウのアイデアに直接準拠しています。 重要な点は、反復処理を行うことです。`pref[0..n]`、元の配列ではありません。 地図`last`プレフィックスの合計の位置とポインタを格納します`l`常に前方にジャンプし、後方にジャンプすることはなく、直線的な複雑さを保証します。 

蓄積`ans += l`それぞれで終わるサブ配列の有効な開始位置をすべてカウントすることに相当します。`r`。

 ## 特殊なケース

 すべての要素がゼロの場合、すべてのプレフィックスの合計がすべてのステップで繰り返されます。 アルゴリズムは次から始まります`l = 0`、そしてそれぞれ新しい`0`力`l`最後の出現箇所に 1 を加えた値にジャンプします。 これにより、最大限のシフトが生じ、貢献度が増加します。`0 + 1 + 2 + 3`。
