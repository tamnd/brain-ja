 ## 解決策
 ## 問題の理解

 家を表すグリッドが与えられ、各セルには射手、壁、鏡、または空きスペースを含めることができます。 一部のセルには、連続レーザービームを放射するビームシューターが含まれています。 各シューターは 2 つの方向のいずれかで、水平方向または垂直方向に発射できます。 射手のサブセットを独立して回転させることができます。タスクは、2 つの条件が同時に成立するように方向を選択することです。 

まず、すべてのビームがミラーでシミュレートされた後、すべての空のセルを少なくとも 1 つのレーザー ビームが横切る必要があります。 第二に、ビームを発射した射手も含めて、その経路にある射手に対してビームを当てることは許可されません。 ビームは壁に当たるかグリッドから離れると停止しますが、ミラーを使用するとビームの向きを 90 度変えて、新しい方向に進むことができます。 

グリッドは最大でも 50 x 50 で、射手の総数は最大でも 100 人です。これは、2 の 100 乗の可能性があるすべての向きの割り当てをブルート フォースすることは完全に不可能であることをすでに示唆しています。 たとえ単一の割り当てを迅速に評価できたとしても、検索空間は大きすぎます。 

重要な問題は、ビームが独立したローカル効果ではないことです。 1 人の射手はミラーを通して長いセルの連鎖に影響を与える可能性があり、たった 1 つの間違った方向の射手は別の射手を破壊する可能性があり、さらに遠くの空のセルをカバーする必要がある場合もあります。 この結合は、貪欲なローカル決定が失敗する傾向があることを意味します。 

単純な失敗ケースは、射手が近くの空のセルをカバーする有効な方向を持っているが、別の射手も通過する場合に発生します。 そのような方向性は、たとえそれが局所的には役立つと思われる唯一の方向性であっても、世界的に拒否されなければなりません。 

もう 1 つの微妙な失敗例は、空のセルに、矛盾する方向に強制された射手からのビームしか到達できない場合に発生します。 たとえば、ある射手は別の射手に当たることを避けるために垂直である必要があるが、重要なセルをカバーするために水平である必要がある場合があります。 これにより、射手ごとに独立した選択を行うのではなく、制約システムが作成されます。 

## アプローチ

 ブルートフォースソリューションでは、すべての射手に対して可能な方向の割り当てをすべて試し、割り当てごとにビーム伝播全体をシミュレートします。 各構成について、最大 100 個のビームをシミュレートします。各ビームは O(RC) セルを通過して複数回反射する可能性があります。 2^100 の構成では、シミュレーション コストを無視しても、これはすでに天文学的な規模になります。 

重要な観察は、問題は割り当ての列挙に関するものではなく、無効なローカル選択の排除とグローバル カバレッジ制約の確保に関するものであるということです。 各シューターには可能な状態が 2 つだけあるため、各シューターをブール変数として扱うことができます。 各割り当ては決定論的なビーム経路を引き起こし、各経路は空のセルをカバーするか、別の射手に当たって制約に違反します。 

これにより、各方向における各射手の効果を事前計算することができます。 ビームについて動的に推論する代わりに、各方向を固定された一連の結果、つまりどの空のセルをカバーし、どの射手を破壊するかに変換します。 射手に当たった方向は即座に無効となり、破棄できます。 

この前処理の後、残りのタスクは、すべての空のセルが少なくとも 1 つの選択された方向でカバーされるように、射手ごとに有効な方向を 1 つだけ選択することです。 これは、最大 2500 個のセルにわたるカバレッジ制約を持つ、最大 100 個の変数にわたる制約充足問題になります。 各変数には 2 つの値しかないため、増分カバレッジ追跡を使用した強力な枝刈りを伴うバックトラッキングを使用してそれを解決できます。

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース列挙 | O(2^S・RC・S) | O(RC) | 遅すぎる |
 | 事前計算された光線によるバックトラッキング | O(最悪の場合は 2^S、大幅に剪定される) | O(RC・S) | 承認済み |

 ## アルゴリズムのチュートリアル

 まず、各射手を最大 2 つの候補状態を持つ変数として書き換えます。 各射手について、ミラーを考慮したグリッド シミュレーションを使用して、水平方向と垂直方向のビームを 1 回シミュレートします。 このシミュレーション中に、ビームが訪問したすべての空のセルを記録します。 ビームが別の射手に到達した場合、その方向は無効としてマークされ、削除されます。 

次に、空のセルからそのセルをカバーするすべての射手方向のペアへの逆インデックスを構築します。 これにより、部分的な割り当てでもカバレッジ要件を満たすことができるかどうかを迅速に評価できます。 

探索は、枝刈りを伴う深さ優先探索を使用して射手に 1 つずつ方向を割り当てることによって進行します。 

1. 割り当てられていない射手、できれば有効な方向が少ないか制約が強い射手を選択します。 これにより、早期の分岐が減少します。 
2. 有効な方向の 1 つを割り当ててみます。 
3. 方向を割り当てるとき、その方向がカバーするすべての空のセルを潜在的に満たされているものとしてマークします。 私たちは、未割り当ての方向が各空のセルをカバーできる残りの数のグローバル カウンタを維持します。 
4. 空のセルが残りの割り当てでカバーできない状態に達した場合は、すぐにバックトラックします。 これにより、絶望的な部分的な割り当てを探索することがなくなります。 
5. すべての射手が割り当てられるまで続行します。 その時点で、すべての空のセルが少なくとも 1 回カバーされていることを確認します。 

正しさは、各決定がセルを満たすことを厳密に不可能にする場合にのみ、将来の可能性を排除するという事実にかかっています。 選択された方向の追加に関してカバレッジは単調であるため、セルがすべての潜在的なカバー方向を失うと、現在の部分的な割り当てを完了してもそれを修正できません。 これで剪定作業が安全になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

DIRS = {
    0: (0, 1),   # right
    1: (0, -1),  # left
    2: (-1, 0),  # up
    3: (1, 0)    # down
}

def reflect(ch, d):
    if ch == '/':
        return {0:2, 1:3, 2:0, 3:1}[d]
    else:  # '\'
        return {0:3, 1:2, 2:1, 3:0}[d]

def simulate(grid, R, C, sr, sc, horizontal):
    if horizontal:
        starts = [0, 1]
    else:
        starts = [2, 3]

    covered = set()
    bad = False

    for sd in starts:
        r, c = sr, sc
        d = sd
        while True:
            dr, dc = DIRS[d]
            r += dr
            c += dc

            if r < 0 or r >= R or c < 0 or c >= C:
                break
            if grid[r][c] == '#':
                break
            if grid[r][c] in '-|':
                bad = True
                break
            if grid[r][c] == '/':
                d = reflect('/', d)
            elif grid[r][c] == '\\':
                d = reflect('\\', d)

            if grid[r][c] == '.':
                covered.add((r, c))

        if bad:
            return None

    return covered

def solve():
    T = int(input())
    for tc in range(1, T + 1):
        R, C = map(int, input().split())
        grid = [list(input().strip()) for _ in range(R)]

        shooters = []
        empties = []

        for i in range(R):
            for j in range(C):
                if grid[i][j] in '-|':
                    shooters.append((i, j))
                elif grid[i][j] == '.':
                    empties.append((i, j))

        S = len(shooters)
        E = len(empties)

        options = [[] for _ in range(S)]

        empty_id = {pos: idx for idx, pos in enumerate(empties)}

        covers = [[] for _ in range(S * 2)]

        valid = True

        for i, (r, c) in enumerate(shooters):
            cov_h = simulate(grid, R, C, r, c, True)
            cov_v = simulate(grid, R, C, r, c, False)

            if cov_h is None and cov_v is None:
                valid = False
                break

            if cov_h is not None:
                options[i].append(0)
                covers[i * 2] = [empty_id[x] for x in cov_h]

            if cov_v is not None:
                options[i].append(1)
                covers[i * 2 + 1] = [empty_id[x] for x in cov_v]

        if not valid:
            print(f"Case #{tc}: IMPOSSIBLE")
            continue

        need = [0] * E
        for i in range(S):
            for opt in options[i]:
                for e in covers[i * 2 + opt]:
                    need[e] += 1

        for x in need:
            if x == 0:
                print(f"Case #{tc}: IMPOSSIBLE")
                break
        else:
            assign = [-1] * S
            best = None

            sys.setrecursionlimit(10000)

            def dfs(idx):
                nonlocal best

                if idx == S:
                    # check coverage
                    cov = [0] * E
                    for i in range(S):
                        opt = assign[i]
                        for e in covers[i * 2 + opt]:
                            cov[e] = 1
                    if all(cov):
                        best = assign[:]
                        return True
                    return False

                for opt in options[idx]:
                    assign[idx] = opt
                    dfs(idx + 1)
                    if best is not None:
                        return True
                assign[idx] = -1
                return False

            dfs(0)

            if best is None:
                print(f"Case #{tc}: IMPOSSIBLE")
            else:
                print(f"Case #{tc}: POSSIBLE")
                out = [row[:] for row in grid]
                for i, (r, c) in enumerate(shooters):
                    if best[i] == 0:
                        out[r][c] = '-'
                    else:
                        out[r][c] = '|'
                for row in out:
                    print(''.join(row))

if __name__ == "__main__":
    solve()
```シミュレーション機能は正確性の核心部分です。 ビームの伝播をセルごとに明確に追跡し、ミラー反射を適用し、壁またはシューター セルで停止します。 他の射手と遭遇すると、その方向は即座に無効になりますが、そのような構成はカバー範囲に関係なく禁止されているため、これは非常に重要です。 

DFS は、一度に 1 人の射撃者に方向を割り当てます。 各射手には最大 2 つの選択肢があるため、分岐要素には制限があり、ソルバーは無効な方向と到達不能な割り当てによって引き起こされる枝刈りに依存します。 最終的な検証により、部分的なローカル推論がグローバル カバレッジの失敗を見逃さないことが保証されます。 

## 実用的な例

 2 人の射手とその間に 1 つの空のセルがあり、両方のビームが衝突していない場合にのみ到達できる小さなグリッドを考えてみましょう。 ソルバーは最初に各射手について両方の方向を計算し、他の射手にすぐに当たる可能性のあるものを破棄します。 次に、割り当てを調べて、空のセルをカバーしたままにする割り当てを見つけます。 

| ステップ | シューター 1 | シューター 2 | 覆われたセル |
 | --- | --- | --- | --- |
 | 1 | 水平 | 未割り当て | 部分的 |
 | 2 | 水平 | 垂直 | いっぱい |

 このトレースは、無効な方向を枝刈りすると、運命の状態を早期に探索できないことを示しています。 

ここで、ビームが空のセルの廊下に曲がる、ミラーの多いグリッドを考えてみましょう。 ある射撃手の向きは反射を通じて長いチェーンをカバーすることができ、もう一方は短いセグメントのみをカバーする可能性があります。 DFS はローカル グリードよりも実現可能性を正しく優先し、どちらかが完全な範囲を満たすまで両方の方向性が検討されます。 

## 複雑さの分析

 ## 特殊なケース

 重大なエッジケースは、射手が有効な方向を 1 つだけ持っており、もう一方がすぐに別の射手に当たる場合です。 その場合、DFS には実際の分岐がなく、正確性は完全に強制割り当ての伝播に依存します。 シミュレーション ベースのフィルタリングにより、無効な方向が検索空間に入らないことが保証されるため、ソルバーは特別な処理を必要としません。 

もう 1 つのエッジ ケースは、空のセルに長い反射パスを通ってのみ到達できる場合に発生します。 カバレッジはシミュレーション中に事前に計算されるため、このセルは対応する射手方向カバレッジ セットに正しく含まれ、DFS はそれを直接見通し内セルと同様に扱います。 

最後の微妙なケースは、すべての射手が個別にすべての空のセルをカバーするが、1 つの方向の選択によってビームが別の射手に当たる場合です。 カバレッジが十分であるように見えても、無効なヒットにより方向性が完全に削除され、ソルバーはグローバルに一貫したサブセットを選択する必要があります。
