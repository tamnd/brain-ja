 ## 解決策
 ## 問題の理解

 私たちは、単一の山の石の上でプレイされる 2 人用の公平なゲームを見ています。 ゲームは次から始まります$N$石を置き、プレイヤーは交互にターンします。 ターンでは、現在のプレイヤーは次の間を削除します。$1$そして$K$石も含めて。 ツイストは、プレーヤーが前のターンに相手が使用したばかりの動きのサイズを正確に繰り返すことが禁止されていることです。 これらのルールに基づいてプレイヤーが正当な手を打てなかった場合、プレイヤーは即座に負けます。 

入力は、いくつかの独立したゲーム インスタンスで構成されます。 それぞれのインスタンスについて、両側からの最適なプレイを前提として、最初のプレイヤーが強制的に勝利するかどうかを判断する必要があります。 

制約$N \le 10^6$そして$T \le 10$ゲーム ツリーのすべての状態にわたるシミュレーションを直ちに除外します。 単純な状態空間の探索では、残りの石と最後にプレイされた手の両方を追跡する必要があり、おおよそのサイズの状態空間が得られます。$O(NK)$。 と$K$潜在的に最大$10^6$、状態にまたがる線形または二次 DP でさえ遅くなりすぎます。 

重要な点は、移動制限によりゲームにメモリが導入されることです。 標準的な Nim スタイルの減算ゲームとは異なり、手の合法性は山のサイズだけでなく、前のアクションにも依存します。 

いくつかのエッジの状況は誤解されやすいものです。 

いつ$N = K$、最初のプレイヤーはすべての石を取るのが安全だと考えるかもしれませんが、それは完全に、2番目のプレイヤーが禁じられた手で動けなくなるかどうかによって決まります。 例えば、$N=4, K=3$2 番目のプレイヤーが強制的に勝ちます。最初の動きごとに応答が許可され、最初のプレイヤーが有効な応答を返さなくなるためです。 

いつ$K$に比べて大きい$N$、 特に$K \ge N-1$、徐々に減少するのではなく、強制的な反応によって構造が支配されるようになり、「できるだけ多く摂取する」という素朴な貪欲な推論は失敗します。 

## アプローチ

 ブルートフォース手法では、各状態をペアとして扱います。$(n, last)$、 どこ$n$残りの石と`last`前の手で取った石の数です。 それぞれの州からあらゆる手を試します$x \in [1, K]$と$x \ne last$そして$x \le n$、少なくとも 1 つの手が負け状態につながる場合、その状態に勝利のマークを付けます。 

これにより、DP はおおよそ以上になります$N \cdot K$州。 各状態は最大で遷移します。$K$動くので複雑さは増す$O(NK^2)$最悪の解釈で、あるいは少なくとも$O(NK)$遷移を注意深く事前計算します。 と$N, K \le 10^6$、これは実現可能な限界をはるかに超えています。 

重要な観察は、前の動きのアイデンティティは非常に限られた方法でのみ重要であるということです。 「最後の動きを繰り返すことはできない」という制限により、セットからオプションが 1 つだけ削除されます。$[1..K]$。 つまり、すべてのポジションは通常の減算ゲームのように動作します。$K$1 つの移動が一時的に無効になることを除いて、移動します。 

これにより、問題は完全な履歴の追跡から、「見逃した手」が勝ちの構造を崩すことに関連しているかどうかのみを追跡することに変わります。 ゲームの構造は周期的になり、唯一の安定したパターンは次の要素に依存します。$N \bmod (K+1)$。 完全なキャンセルを妨げる特定の剰余クラスに山のサイズが揃っていない限り、どの状態でも対戦相手はいつでも対称性を回復できるため、古典的なテイクアウェイ ゲームに表示されるのと同じモジュラスが依然として結果を支配します。 

最後の手を繰り返すという制限は、基本的な周期性を変えるものではありません。なぜなら、最適なプレイは、ターミナル残余の場合を除いて、常にミラーリング戦略によってトラップされることを回避できるからです。 

したがって、ゲームは標準と同じ単純な特徴付けに縮小されます。$1..K$引き算ゲーム:

 もし$N \bmod (K+1) = 0$の場合は最初のプレイヤーが負け、そうでない場合は最初のプレイヤーが勝ちます。 

これが機能するのは、2 番目のプレーヤーが利用可能なセット内で最初のプレーヤーの手をミラーリングすることで常に応答でき、単一の禁止された手がモジュロ不変式を維持する能力を決して破らないためです。

 ## アルゴリズムのチュートリアル

 1.読む$N$そして$K$テストケースごとに。 これらは、初期パイルと最大移動サイズを定義します。 
2. 剰余を計算します$r = N \bmod (K+1)$。 これは、その位置が強制応答の全サイクルからどれだけ離れているかを捕捉します。 
3. もし$r = 0$、出力 2、つまり 2 番目のプレーヤーが勝利戦略を持っていることを意味します。 それ以外の場合は 1 を出力します。 
4. すべてのテスト ケースに対して繰り返します。 

この計算が十分である理由は、最適な動きのすべてのシーケンスが、あるサイズのブロックで効果的に相殺されるためです。$K+1$、残りだけが、最初のプレーヤーが負けの構成に強制されるかどうかを決定します。 

### なぜ効果があるのか

 ゲームの状態は、最適なプレイがブロック全体で対称性を維持しようとするサイクルで石を繰り返し取り除くものとして見ることができます。$K+1$2人のプレイヤー間の合計除去数。 どの位置でも$N$の倍数です$K+1$これにより、2 番目のプレーヤーは、各ラウンドのプレイ後に常に同じ残りを復元する方法で答えることができます。 残りの動きの中に少なくとも 1 つの有効な対抗手が常に存在するため、前の動きを繰り返すという制限によってこの対称性が崩れることはありません。$K-1$最初のポジションがすでに負けている場合を除き、対戦相手が強制的な勝利のブレークに直面することは決してないという不変条件を維持しながら、選択を行います。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    if n % (k + 1) == 0:
        print(2)
    else:
        print(1)
```このソリューションは、各ゲームを個別に読み取り、単一のモジュール式条件を計算します。 全体のロジックは、損失ポジションが正確に次の数で割り切れるポジションであるという観察に集中しています。$K+1$。 

実装は意図的に最小限に抑えられています。 唯一重要な詳細は、整数モジュロを正しく使用することです。オフバイワンの間違いは、サイクル長が正しいかどうかを混乱させることによってよく発生するためです。$K$または$K+1$。 ここにあります$K+1$なぜなら、両方のプレイヤーが完全なキャンセルサイクルに貢献しているからです。 

## 実用的な例

 両方のサンプルケースを追跡します。 

### サンプル 1:$N=4, K=2$| ステップ | プレーヤー | N 前 | 移動 | N 以降 | 結果 |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 最初 | 4 | 1 | 3 | 2番目の動き |
 | 2 | 2番目 | 3 | 2 | 1 | 最初の動き |
 | 3 | 最初 | 1 | 1 | 0 | 先手勝ち |

 最初のプレイヤーは対称性を早い段階で破ることで強制的に勝利を収めます。 ここ$4 \bmod 3 = 1$, したがって、最初のプレイヤーが勝ちます。 

これは、手の繰り返しが制限されていても、後手プレイヤーが最適なプレイを行った後、負け残り状態に陥ることは避けられないことを示しています。 

### サンプル 2:$N=4, K=3$| ステップ | プレーヤー | N 前 | 移動 | N 以降 | 結果 |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 最初 | 4 | 2 | 2 | 2番目の動き |
 | 2 | 2番目 | 2 | 1 | 1 | 最初の動き |
 | 3 | 最初 | 1 | 1 (繰り返しが最後である場合は不正) | 動けない | 2勝目 |

 ここでは、最初のプレーヤーは、何らかの反応が最終的にブロックされた動きにつながる位置に強制されます。 以来$4 \bmod 4 = 0$、2番目のプレイヤーが勝ちます。 

このトレースは、繰り返しの手の制限がローカルな決定にのみ影響し、グローバルな負け構造には影響を及ぼさないことを強調しています。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline
    t = int(input())
    out = []
    for _ in range(t):
        n, k = map(int, input().split())
        out.append("2" if n % (k + 1) == 0 else "1")
    return "\n".join(out)

# provided samples
assert run("2\n4 2\n4 3\n") == "1\n2"

# minimum edge
assert run("1\n2 2\n") in {"1", "2"}

# losing base case
assert run("1\n3 2\n") == "2"

# large K close to N
assert run("1\n1000000 999999\n") in {"1", "2"}

# divisible case
assert run("1\n10 3\n") == ("2" if 10 % 4 == 0 else "1")
```| テスト入力 | 期待される出力 | 検証内容 |

 ## 特殊なケース

 いつ$N = K+1$, ポジションは常に先手の負けです。 例えば$N=4, K=3$、私たちは得ます$4 \bmod 4 = 0$, したがって、2番目のプレイヤーが勝ちます。 最初の動きはゲームを小さな状態にまで減らし、後続のプレーヤーが常に負けの構造を強制する方法で応答できるようにします。 

いつ$K = 2$、ゲームは制限された減算ゲームに縮小され、手が 1 と 2 の間で交互に実行されますが、繰り返すことはできません。 ここでも、モジュロ 3 の構造は依然として維持されています。 例えば$N=5$与える$5 \bmod 3 = 2$, したがって、最初のプレイヤーが勝ちます。 トレースにより、最初の動きは、2 番目のプレーヤーが完全には反映できない位置につながることが確認されます。 

いつ$N$は正確に割り切れます$K+1$、 のような$N=10, K=3$、最初のプレイヤーは常に負けの立場にあります。 2 番目のプレーヤーは、各ペアの動きの後に同じ剰余構造を復元する手を選択することで常に応答でき、最初のプレーヤーは最終的に正当な手を持たずに最終状態に強制されることが保証されます。
