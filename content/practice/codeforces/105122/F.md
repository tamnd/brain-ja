 ## 問題の理解

私たちは、すべてのワークショップから、出発するコンベアを追い続ければ、最終的にはノードに到達できることを確認したいと考えています。$N$。 タスクは、追加されたコンベヤの総コストを最小限に抑え、どのコンベヤが追加されたかを出力することです。

コンポーネントにすでにパスがある場合、微妙なケースが発生します。$N$。 このようなコンポーネントでは、余分なエッジは必要ありません。 簡単な例としては、チェーンが次のような状態につながる場合です。$N$、 例えば$1 \to 2 \to N$。 ここで、ノード 1 はすでに到達しています$N$、新しいエッジを強制するのは無駄です。

 ## アルゴリズムのチュートリアル

 まず、どのノードがすでにパスを持っているかを特定します。$N$オリジナルのコンベヤを使用します。 

1. 各エッジの逆隣接リストを構築します。$i \to e_i$、追加します$i$の前任者リストへ$e_i$。 ノードから開始$N$、この逆グラフに対して BFS または DFS を実行します。 この走査で到達したすべてのノードは、すでに到達できるため、「良好」とマークされます。$N$オリジナルのシステムでは。 
2. 残りのノードはすべて「不良」です。つまり、それらのコンベア チェーンは決して$N$。 これらのノードは、各ノードが出力エッジを 1 つだけ持つ、互いに素な機能コンポーネントを形成します。 
3. 未訪問の不良ノードごとに、ノードを繰り返すまでその出力エッジに従って前方に歩きます。 グラフは機能するため、このウォークは最終的にサイクルに入らなければなりません。 この走査で見つかったすべてのノードは、1 つの不良コンポーネントに属します。 
4. このようなコンポーネントごとに、最小コスト ノードを計算します。$u$。 このノードは、コストを最小限に抑えながらコンポーネント全体に影響を与えるため、新しいコンベヤを追加するのに最適な場所です。 
5. 単一の新しいコンベアを追加します。$u$直接に$N$、この操作を記録します。 
6. すべての不良ノードがコンポーネントに割り当てられるまで繰り返します。 

重要な決定は、不良コンポーネントはすべて独立して解決され、コンポーネントごとに 1 つのエッジだけで十分であるということです。 

### なぜ効果があるのか

 「良好な」セットの外側のすべてのノードは、前方走査が決して到達しない領域にあります。$N$これは、その最終的なサイクルが、到達可能なノードのセットから完全に切り離されていることを意味します。$N$。 このようなコンポーネント内では、すべてのノードが最終的に同じサイクルに集中するため、そのコンポーネント内の任意のノードから単一の出口エッジを導入すると、サイクルの分離が破壊されます。 コンポーネント内の 1 つのノードが到達すると、$N$、同じコンポーネント内の他のすべてのノードは、その出口点に到達するまで既存の決定的なパスをたどることができます。 エッジ コストはソース ノードのみに依存するため、コンポーネントごとに最小コストのノードを選択することが最適であり、コンポーネント間で独立しています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

n = int(input())
e = [0] * (n + 1)

arr = list(map(int, input().split()))
for i in range(1, n):
    e[i] = arr[i - 1]
e[n] = 0  # N has no outgoing edge

c = [0] + list(map(int, input().split()))

rev = [[] for _ in range(n + 1)]
for i in range(1, n):
    rev[e[i]].append(i)

from collections import deque

good = [False] * (n + 1)
dq = deque([n])
good[n] = True

while dq:
    v = dq.popleft()
    for u in rev[v]:
        if not good[u]:
            good[u] = True
            dq.append(u)

visited = [False] * (n + 1)
ans_edges = []
total_cost = 0

for i in range(1, n + 1):
    if good[i] or visited[i]:
        continue

    cur = i
    comp = []

    while not visited[cur]:
        visited[cur] = True
        comp.append(cur)
        nxt = e[cur]
        if nxt == 0:
            break
        cur = nxt

    best = min(comp, key=lambda x: c[x])
    total_cost += c[best]
    ans_edges.append((best, n))

print(total_cost, len(ans_edges))
for a, b in ans_edges:
    print(a, b)

2 番目のフェーズでは、残りのノードのみが処理されます。 各ノードには出力エッジが 1 つだけあるため、未訪問のノードから前方に進むと、分岐することなく不良コンポーネント全体が検出されます。 ノードを訪問済みとしてマークすると、各ノードが 1 回処理されることが保証されます。 

各コンポーネントについて、最小コスト ノードを計算し、そこから正確に 1 つのエッジを追加します。$N$。 目的地は常に固定です$N$それは私たちが強制したいユニバーサルシンクだからです。

 ## 特殊なケース

 重要なエッジケースは、グラフにすでに到達するノードが含まれている場合です。$N$間接的に。 たとえば、次の場合$3 \to 4 \to N$、リバース BFS では 3 と 4 の両方が良好とマークされます。 アルゴリズムはそれらを完全にスキップするため、不必要なエッジは追加されません。
