 ## 解決策
 ## 問題の理解

 システムの各次元は、独立した 1 次元のランダム ウォークのように動作します。 船はその位置からスタートします$a_i$次元で$i$、システムがその次元で不安定である間 (座標が少なくとも 1 であることを意味します)、確率で 1 ステップ右に移動します。$p_i$そして確率はあと一歩$q_i = 1 - p_i$。 座標が厳密に 1 未満になった瞬間、その次元は回復したとみなされ、進化が停止します。 

タスクは、初期位置ベクトルから始めて、すべての次元が最終的にこの「回復」状態に少なくとも 1 回到達する確率を計算することです。 

各次元は独立して進化するため、グローバル イベントは独立したイベントの交差点となります。 これは、答えが次元ごとの確率の積に織り込まれていることを直ちに示唆しています。各次元の確率は、次から始まるバイアスのあるランダム ウォークが実行される確率です。$a_i$0に達することはありません。 

この制約により、直接シミュレーションが不可能になります。 各座標は最大 1000 まで可能で、確率は分子と分母が最大で大きい分数です。$10^9$したがって、単純なモンテカルロやステップバイステップのシミュレーションは時間内に収束しません。 この構造は、次元ごとの閉じた形式の確率計算を強く示唆しています。 

ウォークが完全に右に偏っている場合、微妙なエッジケースが現れます。$p_i = 1$。 その場合、歩数は決して減らないので、どの位置からスタートしても$a_i > 0$回復が不可能になります。 逆に、歩き方が左に偏っていたり、偏っていない場合には回復は確実になります。 確率が 0 または 1 の場合、割り算を伴う直接式が壊れる可能性があるため、これらの境界ケースを正しく処理することが重要です。 

## アプローチ

 ブルートフォースアプローチでは、各次元のランダムウォークを独立して何度もシミュレートし、それがゼロに達するかどうかを推定します。 状態に対する動的計画法によって正確な確率を計算しようとしたとしても$[0, 1000]$、遷移をモデル化することはできますが、問題は計算上のものではなく概念的なものです。無制限に上方への移動を許可すると状態空間は無限になり、切り捨てによりエラーが発生します。 たとえ次元ごとに 2000 の状態に制限されていたとしても、全体的な複雑さは次のようになります。$O(n \cdot m^2)$、これは大きすぎます$n = 1000$。 

重要な観察は、各次元が無限の半直線上にある古典的なギャンブラーの破滅問題であるということです。 私たちが気にするのは、次から始まる 0 に到達する確率だけです。$a_i$。 バイアスのあるランダム ウォークの場合:

 もし$p_i \le q_i$、歩は左に偏っているため、確率 1 で 0 にヒットします。$p_i > q_i$、右へのドリフトがあり、0 に到達する確率は次のようになります。$(q_i / p_i)^{a_i}$。 これは、マルコフ連鎖におけるヒット確率の標準漸化式を解くことから得られます。 

各次元が閉じた形式の値に削減されると、最終的な答えは単純にすべての次元の積になります。

 ## アルゴリズムのチュートリアル

 ### 1. 各確率を分数形式に変換します。 

各次元について、以下を読んでください。$p_i = \frac{s_i}{t_i}$そして計算する$q_i = \frac{t_i - s_i}{t_i}$。 

これにより、比較と比を整数で正確に実行できるクリーンな表現が得られます。 

### 2. 吸収が確実かどうかを判断する

 もし$p_i \le q_i$、同等に$2s_i \le t_i$、その後、四球は最終的に確率 1 で 0 に当たります。 

これは、プロセスを 0 から遠ざけるドリフトがないためです。 

### 3. 完全に右偏ったケースを処理する

 もし$s_i = 0$、 それから$p_i = 0$, そのため、歩き方は常に左に進み、吸収は確実です。 

もし$s_i = t_i$、 それから$p_i = 1$、したがって、歩行は決して左に移動することはなく、吸収は不可能です。$a_i = 0$、制約によって除外されます。 

### 4. 右にドリフトした場合のヒット確率を計算する

 もし$p_i > q_i$、次の式を使用します。$$\left(\frac{q_i}{p_i}\right)^{a_i}
= \left(\frac{t_i - s_i}{s_i}\right)^{a_i}$$これをべき乗モジュラーと逆モジュラーを使用してモジュロで計算します。 

### 5. すべての次元の確率を乗算します。 

次元は独立しているため、すべての次元ごとの確率を剰余で乗算します。$10^9+7$。 

### なぜ効果があるのか

 各次元は、吸収イベントが「ヒット 0」であるマルコフ連鎖として独立して進化します。 吸収の確率はドリフト方向のみによって決まります。 ドリフトが正でない場合、再発により最終的な吸収が保証されます。 ドリフトが正の場合、ヒット確率の漸化式を解くと、開始位置で指数関数的に減衰します。 次元の独立性により、結合イベントがスカラー確率の積に変わり、モジュラー演算によりこの構造が正確に保存されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modexp(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

n = int(input())
a = list(map(int, input().split()))

ans = 1

for i in range(n):
    s, t = map(int, input().split())

    if s == 0:
        continue

    if s * 2 <= t:
        continue

    q = t - s

    ratio = q * pow(s, MOD - 2, MOD) % MOD
    ans = ans * modexp(ratio, a[i]) % MOD

print(ans)
```このソリューションは、各次元を個別に読み取り、すぐにそれをスカラー確率寄与に換算します。 モジュラーの逆$s$を形成するために使用されます$q/p$モジュロ演算の下で。 高速累乗でべき乗を処理します$a_i$、最大 1000 まで指定でき、ソリューションを制限内に十分に保つことができます。 

比較には注意が必要です$2s \le t$これにより、除算が完全に回避され、精度の問題が防止されます。 ケース$s = 0$逆モジュラーが壊れてしまうため、早期に分離されます。

 ## 特殊なケース

 重大なエッジケースは次のような場合です。$s_i = 0$。 この状況では、四球は常に左に移動するため、関係なくすぐに 0 になります。$a_i$。 このアルゴリズムはモジュラー反転を完全にバイパスし、1 を積に直接寄与します。 

もう 1 つのエッジケースは次のような場合です$s_i = t_i$。 歩き方は決して左に動かないので、$a_i > 0$、確率は 0 です。 条件$2s_i > t_i$幾何学式を正しくトリガーしますが、$t_i - s_i = 0$、比率は 0 になり、正の指数は 0 になり、正しい動作と一致します。 

最後に、閾値ケース$2s_i = t_i$対称ランダムウォークを表します。 アルゴリズムはこれを確率 1 として分類します。これは、0 での吸収が確実である非負の整数における不偏ランダム ウォークの反復特性と一致します。
