 ## 問題の理解

 寸法が記載された長方形の紙が渡されます$n \times m$。 このシートから切り出したいのは、$k$同一の正方形のステッカー。各ステッカーは一辺の長さを持つ正方形です。$x$。 正方形はシート内に完全に含まれている必要があり、重なることは許可されません。 

タスクは、可能な最大の整数または実数値を決定することです。$x$少なくともそうなるように$k$正方形の大きさ$x \times x$長方形の中に入れることができます。 

重要な観察点は、辺の長さが固定されている場合、$x$、配置できる正方形の数は、各次元にどれだけ適合するかによって決まります。 水平方向に合わせることができます$\lfloor n / x \rfloor$正方形と垂直方向に合わせることができます$\lfloor m / x \rfloor$平方なので、合計はその積になります。 

制約$n, m \le 10^3$は十分小さいので、固定関数の場合、この関数の評価は簡単です。$x$、 しかし$k \le 10^9$配置数の可能性を直接列挙することは不可能になります。 最適な正方形のサイズは分数になる可能性があるため、答えは必ずしも整数であるとは限りません。 

単純なアプローチでは、考えられるすべての正方形サイズを次から試してみます。$1$非常に小さな増分までは可能ですが、答えの精度が最大で連続的であるため、これは失敗します。$10^{-6}$。 離散化しても$10^{-6}$解決には約$10^6$チェック、そしてそれぞれのチェックは$O(1)$これは境界線にありますが、よりクリーンな構造を考えると不要です。 

エッジケースは次の場合に発生します。$k$が非常に大きいため、正方形のサイズが小さくなります。 たとえば、次の場合$n = m = 2$そして$k = 3$、 それから$x = 1$機能するので$2$正方形は行と列ごとに収まり、次のようになります。$4$合計、ただし任意$x > 1$以下のカウントを減らします$3$。 もう 1 つのエッジケースは次のような場合です$k = 1$、答えは簡単です。$\min(n, m)$1 つの正方形が可能な限り大きな辺を占めることができるためです。 

## アプローチ

 強引なアイデアは、可能なすべての正方形の辺の長さを試してみることです。$x$、適合する正方形の数を計算し、有効な最大値を追跡します。 離散化すると$x$などの小さなステップに分けて、$10^{-6}$、各チェックには計算が必要です$\lfloor n/x \rfloor \cdot \lfloor m/x \rfloor$、これは定数時間です。 ただし、この離散化により、$10^6$各評価には浮動小数点除算とフロア演算が含まれます。 場合によってはこれで済む場合もありますが、不必要であり、精度が高くても脆弱です。 

重要な構造的観察は、適合する正方形の数が次の点に関して単調であるということです。$x$。 指定されたサイズの場合$x$正方形のサイズを小さくしても、各次元に適合する数が増えるだけなので、それより小さなサイズでも機能します。 逆に、もし$x$が大きすぎるため、さらに増やすと実現可能性が低下するだけです。 この単調な動作により、問題を継続的な二分探索として扱うことができます。$x$。 

述語を定義します$f(x)$かどうかをチェックします$\lfloor n/x \rfloor \cdot \lfloor m/x \rfloor \ge k$。 この述語は単調なので、最大値を二分探索できます。$x$それは真実であり続けます。 

検索スペースは次のとおりです。$0$に$\max(n, m)$。 二分探索の各ステップは述語を一定時間で評価し、十分な反復回数を対数で与えます。$10^{-6}$精度。

 ## アルゴリズムのチュートリアル

 最大のものを見つけるように問題を再定式化します$x$少なくともそうなるように$k$辺の正方形$x$フィット。 

1. 関数を定義する`can(x)`適合する正方形の数を計算します。$(n // x) * (m // x)$。 この値が少なくとも$k$、 それから$x$実現可能です。 フロア分割は、各軸に沿っていくつの完全な正方形が収まるかをキャプチャします。 
2. 二分探索間隔を次のように設定します。`left = 0`そして`right = max(n, m)`。 長方形より大きい正方形は一度も収まらないため、答えはこの範囲内にあるはずです。 
3. 繰り返し計算する`mid = (left + right) / 2`そしてテスト`can(mid)`。 
4. もし`can(mid)`それは本当です。正方形のサイズを大きくすることができるので、次のように移動します。`left = mid`。 それ以外の場合は、次のようにしてサイズを縮小します。`right = mid`。 
5. 間隔幅が以下になるまで続けます。$10^{-7}$これにより、必要な誤差範囲内の正確性が保証されます。 
6. 出力`left`実行可能な最良の近似値として。 

### なぜ効果があるのか

 機能$can(x)$は単調減少です$x$。 あるサイズが実行不可能になると、それより大きなサイズはすべて実行不可能のままになります。$x$適合する正方形の数を減らすか維持することしかできません。 この単調性により、二分探索が最適な境界を飛び越えることがなく、最終的な収束点が実現可能な最大値に近似することが保証されます。$x$要求される精度の範囲内で。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can(n, m, k, x):
    return (n // x) * (m // x) >= k

def solve():
    n, m, k = map(int, input().split())

    # handle edge case: no squares fit unless x <= min(n, m)
    left, right = 0.0, float(max(n, m))

    for _ in range(60):
        mid = (left + right) / 2
        if mid == 0:
            left = mid
            continue
        if (n // mid) * (m // mid) >= k:
            left = mid
        else:
            right = mid

    print(left)

if __name__ == "__main__":
    solve()
```実装の中核となるのは、`can`ロジック。各次元に沿って適合する正方形の数を直接エンコードします。 二分探索は固定反復回数 (60 回) 実行されます。これは倍精度収束には十分です。 

微妙な点の 1 つは、次のような場合にゼロ除算を避けることです。`mid`極端に小さくなります。 実際には、ループは問題になる前に収束しますが、チェックによって数値的な安全性が確保されます。 もう 1 つの微妙な点は、イプシロン条件の代わりに 60 回の反復を使用することです。これにより、浮動小数点の不安定性が回避されます。

 ## 特殊なケース

 いつ$k = 1$、アルゴリズムは自然に、実現可能な最大の正方形に向かって拡張します。$\min(n, m)$。 二分探索はゼロから開始され、真の最大値に収束するまで、大きな中間値の実現可能性をすぐに確認します。 

いつ$k$が非常に大きい場合、実行可能性チェックは、ゼロ付近を除くほぼすべての中間値で false になります。 検索では、正方形のサイズが十分に小さくなり、両方のフロア分割で十分な配置が生成されるまで、間隔が縮小されます。 

いつ$n = m$, 対称性はロジックを単純化するものではありませんが、実現可能性の境界をより明確にします。 対称性に関係なく単調性が維持されるため、アルゴリズムは依然として正しく収束します。
