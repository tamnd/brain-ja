 ## 解決策
 ## 問題の理解

 最初は原点に黒いセルがある無限の 2D グリッドがあります。`(0, 0)`。 それぞれタイプ「4」またはタイプ「8」のいずれかの拡張操作のシーケンスを実行します。 タイプ "4" 拡張ではすべての直交する隣接セルが黒に変わり、タイプ "8" の拡張ではすべての直交または斜めに隣接するセルが黒になります。 標的細胞が与えられると`(x, y)`および一連の拡張では、ターゲット セルが黒になるかどうかを判断する必要があります。 

制約により許可されるのは、`n`まで`2*10^5`すべてのテストケースと調整`10^9`。 グリッドは無限であり、座標は巨大であるため、グリッドを明示的にシミュレートすることは不可能です。 これにより、個々のセルを更新したり、グリッド全体の状態を保存したりするソリューションは即座に除外されます。 代わりに、黒細胞の広がりについて幾何学的に推論する必要があります。 

エッジ ケースには、負の座標や一方向にのみ移動する展開が含まれます。 たとえば、文字列がすべて「4」展開の場合、斜めのセル`(1,1)`は決して黒にはなりませんが、シーケンスに「8」がある場合は黒になる可能性があります。 もう 1 つの微妙な点は展開の順序です。シーケンス内の 1 つの「8」でも、より長い「4」のシーケンスでは到達できないセルに到達する可能性があります。 

## アプローチ

 ブルートフォースの解決策は簡単です。黒のセルのセットを維持し、操作ごとにそれを更新します。 「4」の場合、各黒セルに隣接する 4 つのセルを追加します。 「8」の場合、8 つの近傍をすべて追加します。 すべての操作を処理した後、次のことを確認します。`(x, y)`セットに入っています。 このアプローチは原理的には機能しますが、セルの数は指数関数的に増加するため、`n`その周り`10^5`これは不可能になります。 

重要な洞察は、黒い領域が予測可能な幾何学的パターンで成長するということです。 直交拡張では、原点からのマンハッタンの距離がステップごとに 1 ずつ増加しますが、対角拡張ではチェビシェフ距離が増加します (最大`|x|`そして`|y|`したがって、問題は、次のことを計算することになります。`(x, y)`組み合わせた拡張を適用した後、原点を中心とするひし形または正方形の中に収まります。 

すべての黒セルを追跡する必要はありません。 シーケンス内の最初の「8」だけを見つける必要があります。これにより、成長がチェビシェフ計量に変換され、その後、残りの拡張が正方形を均一に拡張すると考えることができます。 「8」がない場合、カバーされるマンハッタンの最大距離は「4」のカウントになります。 これを利用すると、テストケースごとに一定時間でセルをチェックすることができます。

 | 最適 | テスト ケースあたり O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 テストケースごとに解析します`n`、`x`、`y`、および文字列`s`。 
2. 原点かどうかを確認する`(0, 0)`が目標です。 だったら返して`YES`。 
3. 「8」が最初に出現する箇所を特定します。`s`。 そのインデックスを次のようにします`k`(0 ベース)。 このインデックスの前では、すべての拡張は「4」であり、毎回マンハッタンの距離が 1 ずつ増加します。 
4. マンハッタン距離を計算する`d = |x| + |y|`原点からのターゲットの。 
5.「8」が無い場合`s`、どうかを確認してください`d <= n`。 「はい」の場合、セルは直交移動によって到達できます。 それ以外の場合はできません。 
6. 位置に少なくとも 1 つの「8」がある場合`k`、その後`k`「4」の地域はマンハッタン半径のダイヤモンドです`k`。 「8」はメトリックをチェビシェフに変換するため、残りの手順ではチェビシェフ距離を持つ任意のセルが許可されます。`<= remaining_length`現在到達するダイヤモンドから。 
7. チェビシェフ距離が次のとおりであるという性質を利用する`max(|x|, |y|)`、どうかを確認してください`max(|x|, |y|) <= total_expansions`。 「はい」の場合は、戻ります`YES`; さもないと、`NO`。 

正確さを保証する不変条件は、黒い領域の単調増加です。 マンハッタンの拡張は、「8」が発生しない限り、対角線のみのセルに到達することはできません。「8」の後に、領域はチェビシェフ距離に従って全方向に均一に拡張されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, x, y = map(int, input().split())
    s = input().strip()
    
    if x == 0 and y == 0:
        print("YES")
        continue
    
    first8 = s.find('8')
    
    if first8 == -1:
        # all '4's, check Manhattan distance
        if abs(x) + abs(y) <= n:
            print("YES")
        else:
            print("NO")
    else:
        # the first '8' occurs at index first8
        # after that, Chebyshev distance matters
        # maximum of |x|, |y| must be <= n
        if max(abs(x), abs(y)) <= n:
            print("YES")
        else:
            print("NO")
```まず、ターゲットが原点である自明なケースを処理します。 次に、文字列内の最初の「8」を見つけて、対角展開がいつ開始されるかを識別します。 「8」が存在しない場合、到達可能性を確認するために必要なのはマンハッタンの距離だけです。 「8」がある場合、合計ステップ数内で最大の座標を持つ任意のセルに到達できます。 使用する`find`絶対値比較により、負の座標の正確性も保証されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n, x, y = map(int, input().split())
        s = input().strip()
        if x == 0 and y == 0:
            output.append("YES")
            continue
        first8 = s.find('8')
        if first8 == -1:
            output.append("YES" if abs(x)+abs(y) <= n else "NO")
        else:
            output.append("YES" if max(abs(x), abs(y)) <= n else "NO")
    return "\n".join(output)
