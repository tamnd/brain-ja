## アプローチ

 ブルートフォースアプローチでは、ミッションの難易度と期間のあらゆる可能なシーケンスを試し、すべての開始スキル値をシミュレートします。 初期スキルが到達したかどうかを確認できるため、原理的には機能します`n`。 問題は組み合わせによるものです。`n=250000`、各ミッションの期間を狭い範囲で繰り返すだけでも、何兆もの可能性が生まれますが、これは実行不可能です。

import sys

# Step 1: long mission at difficulty 1 to boost any starting at 1 to n

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    missions = []
    missions.append((1, n))
    for d in range(2, n+1):
        missions.append((d, 1))
    out = [str(len(missions))]
    out += [f"{y} {l}" for y, l in missions]
    return "\n".join(out)
