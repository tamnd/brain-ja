 ## 解決策
 ## 問題の理解

 整数の配列が与えられており、目標はそれを「バランス」にすることです。 配列は、各数値が次の場合にバランスが取れています。`x`そこに表示されるものはまさにそのとおりです`x`回。 したがって、数値の出現回数が少なすぎる、または多すぎる場合は、いくつかの要素を削除して修正する必要があります。 例えば、`[1, 4, 2, 4, 4, 4, 2]`バランスが取れているので、`1`一度登場すると、`2`2回登場し、`4`4回登場します。 対照的に、`[2, 2, 2]`バランスが取れていないので、`2`は 3 回表示されますが、正確に 2 回表示される必要があります。 

入力には、それぞれのサイズの配列を持つ複数のテスト ケースが含まれています。`n`と間の値`0`そして`n`。 私たちの仕事は、バランスのとれた配列に到達するために必要な最小の削除数を見つけることです。 

制約はかなり小さいです。`n`最大 100 で、最大 500 のテスト ケースがあります。 つまり、2 次アプローチでも`n`テストケースごとに許容されます。`100^2 * 500 = 5*10^6`操作は 1 秒以内に快適に完了します。 

いくつかの明らかではないエッジケースは、数字が複数回出現しても「平衡数」に達しない場合、または次のような場合に発生します。`0`が発生します。 たとえば、配列`[0, 0, 0]`すべてのゼロを削除するには減らす必要があります。`0`0 回出現する場合もあり、最小削除は 3 になります。同様に、その値よりも多く出現する数値は次のようになります。`[3, 3, 3, 3]`、カウントを正確に 3 に減らすには削除が必要です。 

## アプローチ

 ブルートフォース手法では、配列の考えられるすべてのサブセットを列挙し、それらがバランスが取れているかどうかをチェックします。 これは要素を自由に削除できるため理論的には機能しますが、サブセットの数は指数関数的であるため、`n=20`。 

より高速なソリューションに対する重要な洞察は、アレイには`n`最大でも個別の値なので、各数値の頻度に焦点を当てることができます。 それぞれの番号について`x`、表示される場合`f`場合によっては、賢明なオプションは 2 つだけです。`x`または正確に離れる`x`彼らのうち。 これら 2 つのうちの良い方を選択すると、局所的な削除が最小限に抑えられます。 それぞれの個別の数値の選択は独立しているため、それぞれの個別の数値の最適な削除を合計することで最小の削除を計算できます。 

辞書やツールを使用して頻度をカウントすることで、これを効率的に実装できます。`Counter`そして配列内のすべての一意の値を反復処理します。 値がゼロの場合、バランスの取れた配列にはゼロを含めることができないため、常にすべてのゼロが削除されます。 頻度が値を超える場合、超過分は削除されます。 頻度が値より小さい場合は、その数値をさらに「作成」できないため、すべての出現が削除されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n) | O(n) | 遅すぎる |
 | 最適 | テスト ケースあたり O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 テスト ケースごとに、配列サイズを読み取ります。`n`そして配列自体。 
2. 辞書または`Counter`。 これにより周波数が得られます`f`一意の番号ごとに`x`。 
3. 削除用のカウンターを初期化します。 それぞれの一意の数値を反復処理します。 

- もし`x`がゼロである場合は、その全頻度を削除に追加します。これは、バランスの取れた配列ではゼロが出現できないためです。 
- もし`f < x`、 追加`f`発生を増やすことはできないため、削除へ。 唯一の選択肢は、それらをすべて削除することです。 
- もし`f >= x`、 追加`f - x`必要な数と正確に一致するように余分な出現を削除します。 
4. すべての一意の数値を処理した後、このテスト ケースの削除の合計を出力します。 

機能する理由: 各数値について、その値を正確に一致させるか、すべてのインスタンスを削除します。 この局所的な最適な選択により、数値の出現が独立しており、互いの有効性に影響を与えることができないため、全体的に最小の削除数が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import Counter

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    freq = Counter(a)
    deletions = 0
    for x, f in freq.items():
        if x == 0:
            deletions += f
        elif f < x:
            deletions += f
        else:
            deletions += f - x
    print(deletions)
```この解決策は、まず次のようにして各数値の出現をカウントします。`Counter`。 次に、一意の番号を反復処理し、アルゴリズムのチュートリアルで説明されている削除ロジックを適用します。 使用する`Counter`O(n) 個のカウントと最大での反復を保証します`n`キーは効率的です。

 出力: 2. 1 つを削除します`1`そしてシングル`3`バランスをとるために。 

これらのトレースは、削除数が番号ごとに独立して計算され、意図したバランスと一致していることを確認します。

## テストケース```python
import sys, io
from collections import Counter

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        freq = Counter(a)
        deletions = 0
        for x, f in freq.items():
            if x == 0:
                deletions += f
            elif f < x:
                deletions += f
            else:
                deletions += f - x
        output.append(str(deletions))
    return "\n".join(output)

# provided samples
assert run("4\n3\n1 2 2\n5\n1 1 2 2 3\n10\n1 2 3 2 4 4 4 4 5 2\n1\n0\n") == "0\n2\n3\n1", "sample 1"

# custom cases
assert run("2\n3\n0 0 0\n4\n3 3 3 3\n") == "3\n1", "zeros and overcount"
assert run("1\n5\n5 5 5 5 5\n") == "0", "perfect balance"
assert run("1\n6\n1 1 1 2 2 3\n") == "3", "mixed under and over counts"
assert run("1\n1\n0\n") == "1", "single zero"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`0 0 0`| 3 | ゼロの正しい処理 |
 |`3 3 3 3`| 1 | 出現回数がちょうど 3 回に減ります |
 |`5 5 5 5 5`| 0 | すでにバランスが取れており、削除はありません |
 |`1 1 1 2 2 3`| 3 | アンダーカウントとオーバーカウントの混合 |
 |`0`| 1 | 単一のゼロが正しく処理されました。 

## 特殊なケース

 アレイの場合`[0, 0, 0]`、`Counter`与える`{0: 3}`。 ゼロを残すことができないため、アルゴリズムは 3 つすべてを削除に追加し、3 を生成します。`[3, 3, 3, 3]`、`Counter`与える`{3: 4}`。 アルゴリズムは 1 を削除してカウントを 3 に減らしますが、これは正しいです。 次のような完全にバランスのとれた配列の場合`[5, 5, 5, 5, 5]`、削除する必要はありません。 このソリューションは、ゼロ、オーバーカウント、アンダーカウントを一貫して処理します。
