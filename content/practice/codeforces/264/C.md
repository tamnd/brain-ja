 ## 解決策
 ## 問題の理解

 私たちには、固定された順序で配置された一連のボールが与えられます。 各ボールには、色と数値という 2 つの情報が含まれています。 このシーケンスから、元の順序を維持しながらサブシーケンスを選択することも、まったく選択しないこともできます。 

サブシーケンスが選択されると、それを左から右にスキャンしてスコアが計算されます。 選択されたすべてのボールは、その色に係数を乗じた値に寄与します。この係数は、その色がランを継続するか、新しいボールを開始するかによって決まります。 ボールが前に選択したボールと同じ色の場合、そのボールは継続として扱われ、その値に次の値を乗算します。`a`。 色が異なる場合は、新しいセグメントを開始し、その値に次の値を乗算します。`b`。 

各クエリのペアは、`(a, b)`変化しますが、値と色の配列は固定されたままになります。 タスクは、各クエリのすべてのサブシーケンスに対して可能な最大スコアを個別に計算することです。 

制約`n ≤ 10^5`そして`q ≤ 500`二次時間でクエリごとに完全な動的プログラムを最初から再計算するソリューションは直ちに除外されます。 サブシーケンスに対する単純な DP には、以前のすべての位置間の遷移が含まれます。`O(n^2)`この規模では遅すぎるでしょう。 

さらに微妙な問題は、負の値から発生します。 値が負の場合もあり、係数も負の場合があるため、より多くのボールを獲得することが必ずしも有益であるとは限りません。 「常にプラスの寄与を選択する」または「常に同じ色の実行を延長する」などの単純な貪欲な戦略は失敗します。決定は、色を切り替えるか、または高価値のセグメントを再利用する将来の機会に依存するためです。 

よくある失敗例は、色を維持するのは局所的にはコストがかかるが、後で大幅に利益を得ることができる場合です。 たとえば、ある色の小さな負の値のボールは、その色の後の大きなブロックに乗算できるのであれば、含める価値があるかもしれません。`a`新たに始めるのではなく`b`。 

## アプローチ

 直接定式化すると、次のように定義されます。`dp[i]`までのプレフィックスを使用したベストスコアとして`i`、で終わる`i`もしくは全然終わらない。 トランジションでは、ボールをスキップするか、ボールをサブシーケンスに追加するかが考慮され、場合によってはカラー セグメントを継続するか、新しいセグメントを開始することが考えられます。 ただし、すべての状態は、一致する色または異なる色の以前のすべての状態に依存する可能性があります。 これは自然に次のことにつながります`O(n^2)`トランジション。 

重要な構造上の観察は、サブシーケンスを拡張するときに重要なのは、完全な履歴ではなく、最後に選択された色だけであるということです。 色ごとに、その色で終わる最適なサブシーケンスがわかっていれば、効率的に移行できます。 

させて`best[c]`最後に選択されたボールに色があるサブシーケンスの最大スコアを表します`c`。 新品ボールを加工する場合`(c_i, v_i)`、それを使用して新しいサブシーケンスを開始するか、同じ色の既存のサブシーケンスを拡張します。 色から拡張する`c_i`からの恩恵を受ける`best[c_i] + v_i * a`、他の色からの切り替えも影響しますが、`max(best all colors) + v_i * b`。 

これにより、すべての全体にわたってグローバル最大値を維持する限り、各更新が一定数の集計値に削減されます。`best[c]`。 難しいのは、`a`そして`b`change per query, so we cannot precompute a single DP. 代わりに、各クエリの DP を再計算します。`O(n)`同じ構造を使用しています。 

配列を維持します`dp[c]`現在のクエリとグローバル最大値`mx`。 サブシーケンスはどの位置からでも新しく開始できるため、実行中の応答も追跡します。 

クエリごとに、配列をリセットし、シーケンスを 1 回スイープし、上で導出した繰り返しを使用して状態を更新します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | サブシーケンスに対するブルート フォース DP | クエリあたり O(n^2) | O(n) | 遅すぎる |
 | クエリごとに最適化されたカラー DP | O(nq) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 各クエリを独立して処理します。`(a, b)`は毎回異なります。 

1. 配列を初期化する`dp[c]`すべての色が非常に負の値になります。これは、現在その色で終了するサブシーケンスがないことを意味します。 メンテナンスも行っております`ans = 0`空のサブシーケンスが許可されるためです。 これにより、すべてを破棄するオプションが常に確保されます。 
2. グローバル変数を維持する`mx`、すべての中での最大値`dp[c]`現在のステップで。 これは、これまでのところ最高のサブシーケンスのエンディングを表しています。 
3. ボールを左から右に繰り返します。 
4. 現在のボールについて`(color c, value v)`、2 つの候補遷移を計算します。 1つ目は、このボールで新たなスタートを切り、価値を与えることです`v * b`。 2 つ目は、異なる色で終了した前のサブシーケンスを拡張し、次のようにします。`mx * b + v * b`、ただし、これはすでにキャプチャされています`mx`。 
5. すでに同じ色で終わっているサブシーケンスを拡張することも検討します。`c`、与える`dp[c] + v * a`。 これが継続の場合です。 
6. カラーで終わる最良のサブシーケンス`c`処理後、このボールは、このボールで新たに開始するか、前の同じ色のサブシーケンスを延長するかの最大値になります。 更新します`dp[c]`それに応じて。 
7. アップデート後`dp[c]`、リフレッシュします`mx`if this value improves it.
 8. アップデートする`ans`その中で最高のものと`ans`、`dp[c]`、およびこのボールで新しいサブシーケンスを開始する値。 これにより、任意の位置で始まるサブシーケンスがキャプチャされます。 

### なぜ効果があるのか

 すべてのステップで、色ごとにサブシーケンスのすべての可能な履歴を、その色で終わる単一の最良値に圧縮します。 位置で終了する任意の最適なサブシーケンス`i`同じ色で終了する最適なサブシーケンスを拡張するか、異なる色で以前の最良の終了から開始する必要があります。 州`dp[c]`未来は最後の色にのみ依存し、その寄与が達成可能な最良のスコアに要約されると、以前の構造はすべて無関係になるため、これで十分です。 

世界最大値`mx`クロスカラートランジションを常に一定時間で利用できるようにすることで、ステップごとにすべてのカラーをスキャンする必要がなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, q = map(int, input().split())
    v = list(map(int, input().split()))
    c = list(map(int, input().split()))

    colors = set(c)

    for _ in range(q):
        a, b = map(int, input().split())

        dp = {}
        mx = 0
        ans = 0

        for i in range(n):
            col = c[i]
            val = v[i]

            prev_same = dp.get(col, 0)

            # extend same color
            extend_same = prev_same + val * a

            # start new segment here
            start_new = mx + val * b

            best = max(0, extend_same, start_new)

            if best > dp.get(col, 0):
                dp[col] = best

            mx = max(mx, dp[col])
            ans = max(ans, dp[col])

        print(ans)

if __name__ == "__main__":
    solve()
```実装は辞書を保持します`dp`実際には表示される色のみが重要であるため、色の状態については説明しません。`mx`これまでの色で終わる最良のサブシーケンス値です。 ボールごとに、同じ色のサブシーケンスを拡張する方が良いか、前の最良のエンドポイントから新しいセグメントを開始する方が良いかを計算します。 

微妙な点としては、`ans`とは別に維持されます`mx`。 これにより、適切に伝播される前に中間状態で終了するサブシーケンスの欠落が回避されます。

 ## 特殊なケース

 重要なエッジケースは、すべての値が負の場合です。 この状況での最適な戦略は、何も選択せず、結果をゼロにすることです。 すべての遷移には次の要素が含まれるため、アルゴリズムがこれを処理します。`max(0, ...)`- の初期化を通じて暗黙的にスタイルを選択`ans = 0`過去の最高値との比較。 

もう 1 つの微妙なケースは、大きな正の値を持つ色が交互に遅く表示されることです。 素朴なアプローチでは初期の低い値が破棄される可能性がありますが、DP は色ごとに最適なプレフィックス状態を保持し、以前に表示された色に戻っても、蓄積された最良のサブシーケンスの恩恵を受けることができます。 

最後に、異なる色の長いストレッチで区切られた繰り返しの色では、正しく使用する必要があります。`mx`。 グローバル最大値がないと、異なる色間の遷移にはすべての状態をスキャンする必要があり、効率が損なわれ、実際には不正確な部分更新が発生することがよくあります。
