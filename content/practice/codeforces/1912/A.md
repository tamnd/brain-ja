 ## 問題の理解

 この問題では、Allyn は整数アキュムレータから始めます。`x`、と与えられます`k`整数のシーケンス。 各ターンで、Allyn は空でないシーケンスから最初 (左端) の数字を取得し、それを次の値に追加できます。`x`ただし、結果の値が`x`非負のままです。 目標は最大化することです`x`シーケンスから取得した数値の順序と数量を選択します。 出力は最大値です`x`それは達成できるのです。 

入力は初期値を指定します`x`そしてシーケンスの数。 各シーケンスは、シーケンス要素が後に続く長さとして指定されます。 重要な課題は、どの数値をどの順序で取得するかを決定することです。負の数値を使用すると、数値が減少する可能性があるためです。`x`ゼロにするか、それ以上の動きをブロックします。 正の数が増加する`x`ただし、アキュムレータが同じシーケンス内の先行する負の値を吸収するのに十分な大きさになった後でのみ使用できます。 

制約により許可されるのは、`x`最大 10^9 および最大 10^5 のシーケンス。すべてのシーケンスにわたる要素の合計数は 10^5 を超えません。 これは、ソリューションが要素をほぼ線形に処理する必要があることを意味します。 考えられるすべての順序をネストしたループは非常に遅くなります。 シーケンスを個別に考慮し、不必要なチェックを回避する戦略が必要です。 

シーケンスが大きな負の数で始まり、その後に大きな正の数が続く場合、エッジ ケースが発生します。 たとえば、`x = 1`そしてシーケンス`[-5, 10]`、単に利用可能な要素を取得する単純なアプローチでは、このシーケンスが完全に拒否される可能性があります。`x + (-5) < 0`。 正しいアプローチでは、シーケンスの先頭に負の数値があると、次の場合に将来の利益が妨げられる可能性があることを考慮する必要があります。`x`彼らが生き残るには十分ではありません。 

## アプローチ

 ブルートフォース手法では、シーケンスから要素を取得するあらゆる可能な順序が試行されます。 各ステップで、最初の要素が一致しないすべてのシーケンスをチェックします。`x`否定、要素を取得、更新`x`、再帰的に続行します。 これは正しいですが、操作の総数は要素の総数で指数関数的に増加する可能性があり、制約が与えられた場合の実行可能な範囲をはるかに超えます。 たとえば、10^5 要素の場合、すべての順序を列挙することは不可能です。 

重要な洞察は、シーケンスごとに、そこから利益を得る唯一の方法は、累積合計が減らないシーケンスのプレフィックスを処理することであるということです。`x`ゼロ以下。 これは、前の要素を取得せずに後の要素を取得することは許可されていないためです。 したがって、シーケンスごとに、安全に追加できる最大プレフィックス合計シーケンスを計算できます。`x`。 これを計算した後、すべてのシーケンスは最大の安全寄与まで減少し、問題は任意の順序でシーケンスを選択することになります。 シーケンスの安全なプレフィックスを取得すると常に増加または維持されるため、`x`、順序は関係ありません。 すべての非負の安全な寄与を単純に追加することができます。 

したがって、最適なアプローチでは、シーケンスごとに実行中のプレフィックスの合計を計算し、最小のプレフィックスの合計を追跡し、次の点までの要素のみを含めます。`x + min_prefix_sum >= 0`。 これにより、決して削減しようとしないことが保証されます`x`ゼロ以下。 次に、このプレフィックスの要素を合計すると、`x`。

 ## アルゴリズムのチュートリアル

 1. 初期アキュムレータを読み取ります。`x`とシーケンスの数`k`。 
2.初期化`x_max`の初期値で`x`。 
3. 各シーケンスについて:

 1. 現在のプレフィックス合計と、これまでに発生した最小プレフィックス合計を追跡します。 
2. シーケンスの要素を繰り返し、実行中のプレフィックス合計にそれぞれを加算します。 
3. もし`x + min_prefix_sum < 0`いつでも停止してください。 残りの要素を安全に追加することはできません。 
4. それ以外の場合は、この時点までのプレフィックスの合計を追加できます。`x`。 
5.アップデート`x`この安全なプレフィックスの合計を追加することによって。 
4. すべてのシーケンスを処理した後、最終シーケンスを出力します。`x`。 

累積合計が減らないプレフィックスのみを追加するため、正確性が保証されます。`x`ゼロ以下。 シーケンスは独立しており、最大限の安全なプレフィックスを採用しているため、他の順序は増加しません。`x`さらに遠く。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    x, k = map(int, input().split())
    for _ in range(k):
        data = list(map(int, input().split()))
        l = data[0]
        seq = data[1:]
        prefix_sum = 0
        min_prefix = 0
        safe_sum = 0
        for num in seq:
            prefix_sum += num
            min_prefix = min(min_prefix, prefix_sum)
            if x + min_prefix < 0:
                break
            safe_sum = prefix_sum
        x += safe_sum
    print(x)

if __name__ == "__main__":
    main()
```このソリューションでは、まず初期値とシーケンスを読み取ります。 各シーケンスについて、プレフィックスの合計と最小のプレフィックスの合計を追跡します。 いつ`x`シーケンスの負のディップに耐えるのに十分な大きさであれば、プレフィックス全体を追加できます。 の`safe_sum`変数により、影響を与えない要素のみを追加することが保証されます。`x`ネガティブ。 The loop breaks early if continuing the sequence would make`x`ネガティブ。

 ## 特殊なケース

 シーケンスの最初の要素が負で、次の要素よりも大きいというエッジ ケースの場合`x`、 のような`x = 1`そして`seq = [-2, 5]`、アルゴリズムは次のように計算します。`min_prefix = -2`そして見つけます`x + min_prefix = -1`、これはゼロより小さいため、シーケンスを完全にスキップします。 出力はそのまま残ります`x = 1`。 これにより、さらなる利益を妨げるマイナス要素の摂取が防止されます。 このアルゴリズムは、どのシーケンスが安全に貢献しているかを正確に識別し、追加のロジックなしでこれらの状況を処理します。
