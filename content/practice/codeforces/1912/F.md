 ## 解決策
 ## 問題の理解

 警察官と逃亡者が交代で移動する木の上での追跡の予想時間を計算するように求められました。 都市は方向性のない木として表現されます。$n$頂点。 警察官は固定された頂点から開始しますが、逃亡者は他の頂点を選択して開始します。 役員が最初に移動し、隣接する頂点に足を踏み入れるか、静止して 1 単位の時間を消費します。 その後、逃亡者は警官への経路上にない頂点に即座に移動し、強制されない限り事実上捕獲を回避します。 どちらも最適にプレイされます。警官は予想される捕獲時間を最小限に抑え、逃亡者はそれを最大限に高めます。 

出力は、逃亡者が逮捕されるまでの予想時間 (分) です。 逃亡者は瞬時に移動し、警官の位置を常に知っているため、問題は逃亡者にとって完璧な情報を備えた 2 人用ゲームで予想される捕獲時間を計算することに帰着します。 

頂点の数が少ない($n \le 100$)、つまり 3 次のアルゴリズム$n$実現可能です。 ツリー構造により、任意の 2 つの頂点間の一意のパスが保証され、逃亡者の安全な移動の計算が簡素化されます。 エッジケースには次のようなものがあります。 

-$n = 2$、そこでは警察と逃亡者が隣接する頂点におり、即時逮捕につながります。 
- 逃亡者が遠くの頂点に継続的に移動できる「長い道」を持つ木。 逃亡者の瞬間的な動きを無視した単純な幅優先の捜索では、正しい期待は得られません。 

これらの微妙な点を理解することは非常に重要です。逃亡者の瞬間的な動きは、ターンごとの位置を素朴にシミュレートできないことを意味します。 

## アプローチ

 ブルートフォース手法では、警官と逃亡者の一連の動きをすべて列挙し、予想される捕獲時間を再帰的に計算しようとします。 役員職位ごとに$p$そして逃亡者の立場$f$、すべての警察官の動きとすべての可能な逃亡者の安全な動きを試し、可能性を平均化することができます。 これは次のことにつながります$O(n^2 \cdot n \cdot n)$最悪の場合には再帰が起こります。$n^2$ポジションペア以下$n$それぞれに動きます。 メモ化しても状態空間は$O(n^2)$ですが、期待値を計算するための再帰により、これを次のように乗算できます。$O(n^4)$、これは許容されます$n \le 100$、しかし面倒で間違いが起こりやすいです。 

重要な洞察は、警官がすでに逃亡者を捕まえるのに「十分に近づいている」場合を除き、逃亡者はいつでも警官を避けることができるということです。 つまり、立場的には$(p, f)$、予想される捕獲時間は、サブツリーの距離、つまり警察官が 1 回の移動で短縮できる最長の距離にのみ依存します。 逃亡者は最大限に安全なすべての位置に配置されます。 これにより、問題が線形方程式系に還元されます。$(p, f)$不明な予想キャプチャ時間を表します$E[p][f]$。 もし$p = f$、$E[p][f] = 0$。 それ以外の場合、役員は最小限に抑えるための行動を選択します。$1 + E[p'][f']$、そして逃亡者は選択します$f'$最大化する$E[p'][f']$。 これにより、反復または行列反転によって解ける最小-最大線形システムが得られます。 

この洞察により、ナイーブな考えが軽減されます。$O(n^4)$確率を伴う再帰は反復に分岐します$O(n^3)$解決策: 役員の位置ごとに、動的プログラミングを使用して、考えられるすべての逃亡者の位置に対する予想時間を計算し、収束するまで値を伝播します。

 ## アルゴリズムのチュートリアル

 1. ツリー入力を解析し、隣接リスト表現を構築します。 各頂点には近隣の頂点が保存され、役員の移動に常時アクセスできるようになります。 
2. 2D 配列を初期化する$E[p][f]$警察官がいる場合の予想捕獲時間を表します。$p$そして逃亡者は$f$。 セット$E[p][p] = 0$みんなのために$p$, since capture occurs instantly.
 3. Precompute the "safe moves" for the fugitive. 各ペアごとに$(p, f)$、すべての頂点を検索します$f'$からのパスが$f$に$f'$通過しない$p$。 これは、BFS または DFS を使用して効率的に実行できます。$f$を含むサブツリーを無視します。$p$。 
4.初期化$E[p][f] = 1$のために$p \ne f$最初の推測として。 これは、役員の次の移動の基準時間を表します。 
5. 収束するまで繰り返します。 

1.役員職位ごと$p$そして逃亡者の立場$f$、 もし$p \ne f$、すべての役員の移動の最小値を計算します$p' \in \{p\} \cup \text{neighbors}(p)$の$1 + \text{average of } E[p'][f']$安全な逃亡行動全般にわたって$f'$。 
2.アップデート$E[p][f]$この最小値まで。 変化が小さなイプシロンを下回るまで繰り返します ($1e-9$）。 
6. 最終的な答えは、からの予想時間です。$E[s][f]$、すべての可能な逃走開始位置の平均$f \ne s$なぜなら、逃亡者は任意の初期頂点を最適に選択できるからです。 

これが機能するのは、ステップ 5 の演算子が短縮マッピングであるためです。更新ごとに値が真の期待値に近づき、一意の固定小数点がすべての位置の最小値と最大値の期待値を表します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    adj = [[] for _ in range(n)]
    for _ in range(n-1):
        u, v = map(int, input().split())
        adj[u-1].append(v-1)
        adj[v-1].append(u-1)
    s = int(input()) - 1

    # Precompute distances and safe moves
    from collections import deque
    safe = [[[] for _ in range(n)] for _ in range(n)]
    for p in range(n):
        for f in range(n):
            visited = [False]*n
            visited[p] = True
            q = deque([f])
            safe[p][f] = []
            while q:
                u = q.popleft()
                safe[p][f].append(u)
                for v in adj[u]:
                    if not visited[v]:
                        visited[v] = True
                        q.append(v)

    # Initialize expected times
    E = [[0.0 if i==j else 1.0 for j in range(n)] for i in range(n)]
    eps = 1e-9
    changed = True
    while changed:
        changed = False
        for p in range(n):
            for f in range(n):
                if p == f:
                    continue
                best = float('inf')
                for np_ in [p] + adj[p]:
                    # Fugitive maximizes
                    sume = 0
                    moves = safe[np_][f]
                    for nf in moves:
                        sume += E[np_][nf]
                    sume /= len(moves)
                    best = min(best, 1 + sume)
                if abs(E[p][f] - best) > eps:
                    E[p][f] = best
                    changed = True

    # Fugitive chooses initial position to maximize expectation
    ans = 0.0
    for f in range(n):
        if f != s:
            ans = max(ans, E[s][f])
    print(ans)

if __name__ == "__main__":
    main()
```隣接リストにより、役員の移動に常時アクセスできます。 逃亡者の安全な動きは、警官を含むサブツリーを無視して、BFS を使用して事前計算されます。 DP のアップデート$E[p][f]$収束するまで。 安全な逃亡者の動きを平均することで、逃亡者の混合戦略の確率的期待が実現されます。 逃亡者は開始頂点を最適に選択するため、初期位置の最大値を取得します。
