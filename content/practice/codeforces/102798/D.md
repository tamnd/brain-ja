## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(c):
    if c == 1:
        return "no"

    p = 2
    while p * p <= c:
        if c % (p * p) == 0:
            return "yes"
        p += 1

    return "no"

def main():
    t = int(input())
    ans = []
    for _ in range(t):
        c = int(input())
        ans.append(solve_case(c))
    print("\n".join(ans))

if __name__ == "__main__":
    main()
```このソリューションでは、根号を明示的に計算するのではなく、繰り返される因子をチェックします。 これにより、大きな積を扱う必要がなくなり、素平方が分割されるかどうかを検出するだけで済みます。`c`。 

ループ条件では、`p*p <= c`、これは試行分割の標準境界です。 この時点までの約数が存在しない場合、より小さなマッチング係数が存在しない限り、より大きな係数は 2 乗寄与を持つことができません。 

Python の整数はオーバーフローしないため、乗算は`p*p`近くでも安全`10^18`。 反復回数が唯一の懸念事項であり、平方根の境界により、指定された数のテスト ケースに対して管理可能な範囲内に維持されます。
