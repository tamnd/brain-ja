 ## 解決策
 ## 問題の理解

 頂点 0 がセキュリティ チームの開始点、頂点 N − 1 が重要な目的を含むターゲットの場所である無向グラフが与えられます。 チームは 0 から N − 1 までできるだけ早く移動したいと考えています。通常、各エッジの走査には 1 単位の時間がかかります。 

旅が始まる前に、「妨害」する頂点を K 個まで選択できます。 遮られた頂点に入ると、その頂点訪問にさらに 1 単位の時間が追加されます。 ガードはどの頂点が妨げられているかを十分に認識しているため、これらの修正された頂点コストの下で可能な限り最短のパスを常に選択します。 

タスクは、この変更されたグラフの 0 から N − 1 までの最短経路距離ができるだけ大きくなるように、遮られた頂点を選択することです。 

グラフは N の点では小さく、最大でも 100 頂点ですが、M が N² に近い可能性があるため、潜在的に密になります。 これは、O(N3) または O(N² log N) の解は許容されるが、サブセットまたはパスにわたる指数関数的なものは許容されないことを強く示唆しています。 

重要な微妙な点は、パスを選択しているのではなく、考えられるすべてのパスが影響を受けるようにグラフを変更し、攻撃者が残りの最適なパスを選択することです。 これにより、単一の最短経路だけを求める貪欲な推論が排除されます。 

よくある失敗例は、元の最短パス上の頂点のみを遮ろうとした場合に発生します。 1 つのパスを増やしても、単に最適なルートが別のパスに移動する可能性があるため、これでは十分ではありません。 

たとえば、0 から N − 1 までの 2 つの互いに素な最短ルートがあるとします。一方のルートのみの頂点をブロックすると、もう一方のルートは変更されないため、直感的に「進行が遅れている」ことが示唆されても、答えは増加しません。 

正しい解決策は、単一のパスだけではなく、全体的な意味で距離を推論する必要があります。 

## アプローチ

 ブルートフォースのアイデアは、サイズが最大 K の頂点のすべてのサブセットを試し、それらを障害物としてマークし、毎回 0 から N − 1 までの最短パスを再計算することです。 すべてのベース エッジの重みが 1 であるため、各最短パスの計算は BFS で実行できますが、状態をエンコードしない限り、頂点ペナルティによって純粋な BFS 構造が壊れます。 単純化したとしても、サブセットの列挙にはすでに O(2^N) のコストがかかり、各サブセットの最短パスを再計算することは完全に不可能になります。 

ボトルネックは、障害セットが最短パス構造を非線形に直接変更するため、単純な列挙が爆発的に起こることです。 

重要な洞察は、頂点の障害をグラフの変換として再解釈することです。 各頂点 v のコストは 1 (通常) または 2 (選択した場合) です。 これは、これまでに使用された障害物の数を追跡する、拡張状態空間上の最短経路問題の観点から考えることを示唆しています。 

これを実行すると、問題は層状グラフ上の最短パスになります。状態は (node, k_used) であり、v を障害物として入力するかどうかに応じて、遷移は 0 または 1 つの障害物を消費します。 ただし、状態空間で事前に固定サブセットを選択しているわけではありません。 代わりに、敵対的ルーティングの下で​​最短パス距離を最大化する、パスに沿った最大 K 個の障害物の可能な限り最適な割り当てを探します。 

これは当然ミニマックス問題になります。私たちは (障害物を配置することによって) 重みを選択し、敵は最短経路を選択します。 このタイプの「最短パスを最大化するために最大 K 個のノードを変更する」を処理する標準的な方法は、使用される障害物のすべての可能な数について、各ノードまでの達成可能な最適な距離を計算することです。

レイヤー全体にわたって距離配列を維持します。各レイヤーは、そのノードへのパス上で使用した障害物の数を表します。 各遷移は、障害物を消費せずに隣接ノードに移動するか、障害物を 1 つ費やして進入中のノードに追加コストを追加しながら移動します。 この層状状態空間に対してダイクストラのような緩和を実行すると、最適な結果が得られます。 

この構造は基本的に、拡張された状態を含むグラフ内の最短パスであり、エッジ コストは障害バジェットをすでに使用したかどうかによって異なります。 これにより、組み合わせ選択の問題が決定論的な最短経路の計算に縮小されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース サブセット | O(2^N · N²) | O(N²) | 遅すぎる |
 | 階層化された最短パス (K 状態) | O(K・M log (K・N)) | O(K・N) | 承認済み |

 ## アルゴリズムのチュートリアル

 この問題を、各状態が頂点に存在し、いくつかの障害物を使用したことを表す拡張状態グラフ上の最短経路に変換します。 

1. 状態が (v, c) である状態定義を構築します。これは、これまでに c 個の障害物を使用して頂点 v にいることを意味します。 これにより、関連するすべての履歴がキャプチャされます。これは、将来の選択において重要なのは障害物の位置ではなく、障害物の数のみであるためです。 
2. 0 に設定されている (0, 0) を除くすべての距離を無限大に初期化します。障害物を使用せずに入り口から開始します。 
3. プライオリティ キューを使用して、状態を超えてダイクストラを実行します。 最小距離状態 (v, c) を抽出するたびに、すべての近傍 u を緩和しようとします。 
4. v から u に移行するときは、2 つの可能性を考慮してください。 u を妨害しなければ、コスト +1 で移動し、層 c に残ります。 u を妨害し、c < K の場合、コスト +2 で移動し、レイヤーを c + 1 に増やします。u にコストを追加する理由は、妨害が頂点の通過時間に影響するためで、u を入力するときに適用されます。 
5. 状態 (u, c) または (u, c + 1) のより良い距離が見つかるたびに、それを優先キューにプッシュします。 
6. すべての状態を処理した後、最大 K 個の障害物を使用できるため、答えは 0 から K までの c のすべての状態 (N − 1, c) 間の最小距離になります。 

正確さは、考えられるすべての有効な障害物構成がこの展開された状態グラフ内の何らかのパスに対応し、この状態グラフ内のすべてのパスが有効な障害物構成に対応するという事実にかかっています。 ダイクストラは、すべてのエッジの重みが負ではなく、すべての選択肢が遷移で明示的にエンコードされるため、そのような構成すべての間で最適な距離を保証します。 

## Python ソリューション```python
import sys
import heapq

input = sys.stdin.readline

def solve():
    T = int(input())
    for tc in range(1, T + 1):
        N, M, K = map(int, input().split())
        g = [[] for _ in range(N)]
        for _ in range(M):
            u, v = map(int, input().split())
            g[u].append(v)
            g[v].append(u)

        INF = 10**18
        dist = [[INF] * (K + 1) for _ in range(N)]
        dist[0][0] = 0

        pq = [(0, 0, 0)]

        while pq:
            d, v, c = heapq.heappop(pq)
            if d != dist[v][c]:
                continue

            for u in g[v]:
                nd = d + 1
                if nd < dist[u][c]:
                    dist[u][c] = nd
                    heapq.heappush(pq, (nd, u, c))

                if c < K:
                    nd2 = d + 2
                    if nd2 < dist[u][c + 1]:
                        dist[u][c + 1] = nd2
                        heapq.heappush(pq, (nd2, u, c + 1))

        ans = min(dist[N - 1])
        print(f"Case #{tc}: {ans}")

if __name__ == "__main__":
    solve()
```コア構造は、積状態空間上の標準ダイクストラです。 エッジごとに 2 つのトランジションにより、ターゲット頂点でオブストラクション バジェットを費やすかどうかの決定が実装されます。 

距離テーブルは 2 次元であり、障害物の数を追跡せずに状態を結合すると、将来の柔軟性が異なるパスが誤って混合されるため、これは不可欠です。 優先キューにより、現在最もよく知られている部分パスが常に拡張され、正確さが維持されます。 

実装の微妙な詳細は、両方の遷移が、同じ隣接ノードにつながる場合でも、独立して許可されることです。 これは、サブセットを列挙することなく、障害物の配置の組み合わせ選択をエンコードするものです。 

## 実用的な例

 K = 1 の単純な折れ線グラフ 0 − 1 − 2 を考えてみましょう。 

dist[0][0] = 0 から開始します。(0,0) からは、コスト 1 の (1,0) またはコスト 2 の (1,1) に移動できます。(1,0) から、コスト 2 の (2,0) に到達します。(1,1) から、コスト 4 の (2,1) に到達します。 

| ステップ | 状態 | 距離 | アクション |
 | --- | --- | --- | --- |
 | 1 | (0,0) | 0 | 開始 |
 | 2 | (1,0) | 1 | 障害物がない |
 | 3 | (1,1) | 2 | ノード 1 を妨害する |
 | 4 | (2,0) | 2 | 障害なく続行 |
 | 5 | (2,1) | 4 | 妨害を続ける |

 最良の答えは min(dist[2][0], dist[2][1]) = 2? 実際には注意深く比較します。 dist[2][0]=2、dist[2][1]=4 なので、2 を採用します。これは、ノード 1 を妨害することは、選択したパスに影響を与える場合にのみ有益であることを示しています。 それ以外の場合は使用できない場合があります。 

次に、K = 1 で、0 が 1 と 2 の両方に接続し、両方が 3 に接続するグラフを考えます。最短パスは、いずれかの中間ノードを経由して常に長さ 2 になります。 中間ノードの 1 つだけを妨害しても、もう一方のパスは距離 2 を与えるため、答えは変わりません。 

| ステップ | dist[3][0] 経由 1 | dist[3][0] 経由 2 | ベスト |
 | --- | --- | --- | --- |
 | 障害物がない | 2 | 2 | 2 |
 | ブロック1 | 3 | 2 | 2 |
 | ブロック2 | 2 | 3 | 2 |

 これにより、アルゴリズムが敵対的な再ルーティングを正しくキャプチャしていることが確認されます。

| スペース | O(K・N) | 拡張状態に対する距離テーブルと優先キュー |

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    T = int(input())
    out = []
    import heapq

    for tc in range(1, T + 1):
        N, M, K = map(int, input().split())
        g = [[] for _ in range(N)]
        for _ in range(M):
            u, v = map(int, input().split())
            g[u].append(v)
            g[v].append(u)

        INF = 10**18
        dist = [[INF] * (K + 1) for _ in range(N)]
        dist[0][0] = 0
        pq = [(0, 0, 0)]

        while pq:
            d, v, c = heapq.heappop(pq)
            if d != dist[v][c]:
                continue
            for u in g[v]:
                if d + 1 < dist[u][c]:
                    dist[u][c] = d + 1
                    heapq.heappush(pq, (d + 1, u, c))
                if c < K and d + 2 < dist[u][c + 1]:
                    dist[u][c + 1] = d + 2
                    heapq.heappush(pq, (d + 2, u, c + 1))

        out.append(str(min(dist[N - 1])))

    return "\n".join(out)

 ## 特殊なケース

 重要なエッジ ケースは K = 0 の場合です。この場合、状態空間は重み付けされていないグラフ上で標準的な BFS/ダイクストラに崩壊します。 c = 0 の遷移のみが許可されるため、アルゴリズムはこれを自然に処理し、インフレートされたエッジは導入されません。 

もう 1 つのエッジ ケースは、入口 (ノード 0) を遮断することが最適な場合です。 状態 (0,0) から、隣接する u へのすべての発信遷移は、オプションで、1 つのオブストラクションを費やした場合に直ちにコストを増加させることができます。 このアルゴリズムは、最初のステップでコスト 2 の (u,1) を正しく考慮します。これは、エントランス ペナルティが完全にモデル化されていることを意味します。 

3 番目のエッジ ケースは、最適な戦略で使用される障害物の数が K 未満である場合です。 答えはすべての c ≤ K にわたって min(dist[N−1][c]) として取得されるため、不必要な障害を強いることなく、未使用のバジェットが自動的に許可されます。
