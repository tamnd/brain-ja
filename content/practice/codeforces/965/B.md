 ## 問題の理解

 ## アルゴリズムのチュートリアル

 1. すべての水平方向の有効な長さのセグメントを事前計算します。$k$。 各行について、左から右にスキャンし、最大の連続ブロックを特定します。`.`。 それぞれの長さのブロック内で$L$、長さのすべてのサブセグメント$k$は有効なので、$L-k+1$異なる列から始まるセグメント。 
2. から始まる有効な水平セグメントごとに$(i, j)$、すべてのセルの寄与カウンタをインクリメントします$(i, j), (i, j+1), \dots, (i, j+k-1)$。 これは、各セルが含まれる有効な配置の数を直接カウントします。 
3. 垂直セグメントに対しても同じプロセスを繰り返します。 各列について、連続するものを検索します。`.`ブロックを作成し、長さのすべての垂直セグメントを列挙します$k$。 
4. グローバルな環境を維持する$n \times n$配列`cnt`ゼロに初期化されます。 有効なセグメントが見つかるたびに、そのセグメントがカバーするすべてのセルが増分されます。 
5. 両方の方向を処理した後、グリッド全体をスキャンし、最大値を持つセルを選択します。`cnt`。 複数のセルが最大値を共有する場合は、任意の 1 つを返すことができます。 

### なぜ効果があるのか

 すべての有効な船舶配置は、完全に連続したセグメント内にある 1 つの水平または垂直セグメントに正確に対応します。`.`ブロック。 アルゴリズムは、そのようなセグメントをすべて 1 回だけ列挙します。 セグメントに遭遇するたびに、そのセグメントが占めるすべてのセルに 1 単位の貢献を分配します。 したがって、セルに格納される値は、そのセルを含む有効な船舶配置の数と正確に一致します。 すべてのセルにわたってこの値を最大化すると、問題は直接解決されます。

import sys
input = sys.stdin.readline

def add_segment(cnt, i, j, di, dj, k):
    for _ in range(k):
        cnt[i][j] += 1
        i += di
        j += dj

n, k = map(int, input().split())
grid = [input().strip() for _ in range(n)]

cnt = [[0] * n for _ in range(n)]

# horizontal segments

    j = 0
    while j < n:
        if grid[i][j] == '#':
            j += 1
            continue
        start = j

        length = j - start
        if length >= k:

                add_segment(cnt, i, s, 0, 1, k)

# vertical segments

            i += 1

                add_segment(cnt, s, j, 1, 0, k)

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    input = _sys.stdin.readline

    n, k = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    cnt = [[0] * n for _ in range(n)]

    def add(i, j, di, dj):
        for _ in range(k):
            cnt[i][j] += 1
            i += di
            j += dj

    for i in range(n):
        j = 0
        while j < n:
            if grid[i][j] == '#':
                j += 1
                continue
            s = j
            while j < n and grid[i][j] == '.':
                j += 1
            for st in range(s, j - k + 1):
                add(i, st, 0, 1)

    for j in range(n):
        i = 0
        while i < n:
            if grid[i][j] == '#':
                i += 1
                continue
            s = i
            while i < n and grid[i][j] == '.':
                i += 1
            for st in range(s, i - k + 1):
                add(st, j, 1, 0)

    best = (0, 0)
    bestv = -1
    for i in range(n):
        for j in range(n):
            if cnt[i][j] > bestv:
                bestv = cnt[i][j]
                best = (i, j)

    return f"{best[0]+1} {best[1]+1}"

 ## 特殊なケース

 グリッドに有効な長さのセグメントが含まれていない場合$k$、寄与行列はすべてゼロのままです。 この場合、より良い候補が存在しないため、アルゴリズムは依然として (1,1) を返します。 これは、どのセルでも受け入れられるという問題の要件と一致します。
