 ## 解決策
 ## 問題の理解

 タスクは、一連の範囲加算を再構築することです。 ゼロの配列から始めます。 1 回の操作で連続セグメントを選択し、そのセグメント内のすべての要素を 1 ずつ増やします。 未知数のこのような操作の後、最終的な配列が与えられ、それを生成する可能性のある最小数の操作を、使用されたセグメントとともに出力する必要があります。 

重要なオブジェクトは配列値そのものではなく、隣接する位置間で値がどのように変化するかです。 配列の場合`a`、差分配列を定義します。`d[i] = a[i] - a[i - 1]`と`a[0] = 0`、仮想要素をもう 1 つ追加します`a[n + 1] = 0`したがって、最後の差分が含まれます。 セグメントに対する単一の操作`[l, r]`を追加してこの差分配列を変更します`1`位置で`l`そして引き算`1`位置で`r + 1`。 言い換えれば、すべての操作により、差分配列に正の変化が 1 つと負の変化が 1 つだけ作成されます。 

入力の長さは次のように大きくできます。`100000`。 配列への演算の適用を繰り返しシミュレートしたり、可能なセグメントを検索したりするアプローチでは、二次作業が必要になる可能性があるため、時間がかかりすぎます。 直線または直線に近い構造が必要です。 

いくつかの特殊なケースは見落とされがちです。 次のように、配列全体が同じ正の値を持つ場合:```
3
2 2 2
```答えは、個々の要素に対する 3 つの操作ではありません。 正解は 1 回の操作です。```
1
1 3
```1 つのセグメントが配列全体をカバーするためです。 

もう 1 つの注意が必要なケースは、配列内にゼロがある場合です。```
5
1 0 1 0 1
```正解は 3 つの操作です。```
3
1 1
3 3
5 5
```次に大きな値が得られるまですべての正のセグメントを拡張しようとする不注意な解決策は、ゼロのままでなければならない位置を誤ってカバーしてしまう可能性があります。 

3 番目の境界ケースは配列の終わりです。```
4
1 1 1 1
```正解は 1 回の操作です。```
1
1 4
```最終的にゼロに戻るのは配列の後で発生するため、仮想位置は`n + 1`対処しなければなりません。 これを無視すると、増分が一致しないままになります。 

## アプローチ

 直接的なアプローチは、考えられるすべてのセグメントを考慮し、ターゲット配列に到達するまで増分を繰り返し適用することです。 すべての操作を正確にシミュレートできるため、これは正しいですが、有用な構造は得られません。 最悪の場合、長さの配列`100000`周りの価値観で`100000`個別の要素の更新は何十億回も必要となる可能性があり、これは利用可能な時間をはるかに超えています。 

有益な観察は、違いを観察することで得られます。 すべての範囲の増分は 1 つの位置から始まり、別の位置の直後に配列への影響を停止します。 つまり、差分配列が変更されるのは開始境界と終了境界だけです。 

差分配列が正の値を持つと仮定します。`d[i] = 3`。 これは、さらに 3 つのセグメントをその位置で開始する必要があることを意味します。`i`そこで終わるよりも。 同様に、負の値は、多くのアクティブなセグメントがその位置より前に終了する必要があることを意味します。 各操作は開始点を 1 つだけ提供できるため、操作の最小数は正確に正の差の合計量となります。 

構造は簡単です。 左から右にスキャンします。 プラスの差が現れるたびに、同じ数の新しいセグメントの開始を作成します。 マイナスの差が現れるたびに、現在開いている多数のセグメントを閉じます。 差分のプレフィックス合計は常に現在の配列値であるため、負になることはありません。 したがって、閉じるのに十分な開いたセグメントが常にあります。 

ブルートフォース方式では、配列を変更してセグメントを検出しようとします。 最適な方法では、セグメントの境界から同じ情報を直接検出します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(演算回数 × n) | お(1) | 遅すぎる |
 | 最適 | O(n + 答え) | ○（答え） | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 差分配列を計算します。 最初の位置より前の要素と最後の位置より後の要素をゼロとして扱います。 これにより、すべての範囲演算が 1 つの正の境界と 1 つの負の境界に正確に対応するようになります。 
2. 差分配列を左から右にスキャンします。 いつ`d[i]`が正である場合、追加します`d[i]`ポジションのコピー`i`現在開いているセグメント開始のリストに追加します。 これらはここで開始しなければならない操作です。 
3. いつ`d[i]`マイナスです、削除します`-d[i]`リストから開始し、削除された各開始位置と終了位置をペアにします。`i - 1`。 このペアで表される操作は、その開始から終了までのセグメントです。`i - 1`。 
4. 生成されたすべてのセグメントを出力します。 セグメントの数は、差分配列内の正の寄与の数であり、これは最小限です。 

この構造が最適である理由は、すべての演算で差分配列に正の境界を 1 つだけ作成する必要があるためです。 合計のプラスの差が`x`、これより少ない数を使用できるソリューションはありません`x`操作。 アルゴリズムは正確に作成します`x`操作が行われるため、下限に達します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    diff = []
    prev = 0
    for x in a:
        diff.append(x - prev)
        prev = x
    diff.append(-prev)

    starts = []
    ans = []

    for i, x in enumerate(diff, start=1):
        if x > 0:
            for _ in range(x):
                starts.append(i)
        elif x < 0:
            for _ in range(-x):
                l = starts.pop()
                ans.append((l, i - 1))

    print(len(ans))
    for l, r in ans:
        print(l, r)

if __name__ == "__main__":
    solve()
```最初の部分では差分配列を構築します。 追加の最終値`-prev`は、最後の要素からゼロに戻る遷移を表します。 この位置がないと、配列の最後に到達したセグメントは決して閉じられません。 

の`starts`list には、セグメントが開始されていてもまだ終了していない位置が格納されます。 負の差が見つかった場合、コードは必要な開始回数を正確にポップします。 操作は独立しているため、どの順序でも機能するため、最新の開始を使用するのが便利な実装選択です。 

保存されたすべての開始が 1 つの避けられない操作に対応するため、出力カウントは自動的に最小になります。 構築中に余分な操作が追加されることはありません。 

インデックスが使用するのは、`enumerate(..., start=1)`この問題では 1 から始まるインデックスが使用されているためです。 正しいエンドポイントは`i - 1`、位置でのマイナスの差があるため、`i`セグメントがその位置の直前で停止することを意味します。

def solve(inp: str) -> str:
    data = inp.strip().split()
    if not data:
        return ""
    n = int(data[0])
    a = list(map(int, data[1:]))

    prev = 0
    for x in a:

    out = [str(len(ans))]
    out += [f"{l} {r}" for l, r in ans]
    return "\n".join(out)

 ## 特殊なケース

 定数の正の配列の場合:```
3
2 2 2
```差分の配列は次のとおりです。`[2, 0, 0, -2]`アルゴリズムは位置で 2 つのセグメントを開きます`1`、仮想終了位置で両方を閉じます`4`。 出力は次の 2 つのコピーです。`[1,3]`。 各操作では高さの 1 単位しか寄与できないため、2 つの操作が必要です。 

ギャップがゼロの配列の場合:```
5

```差は正の値と負の値の間で交互に現れます。 すべての正の差がセグメントを開き、次の負の差がすぐにセグメントを閉じます。 生成されたオペレーションはまさに単一要素セグメントです`[1,1]`、`[3,3]`、 そして`[5,5]`。 

正の値で終わる配列の場合:```
4
1 1 1 1
```差分の配列は次のとおりです。`[1,0,0,0,-1]`最後の負の値は、配列の後の仮想ゼロから取得されます。 アルゴリズムは、その時点までセグメントを開いたままにして出力します。`[1,4]`、右側の境界を正しく処理します。
