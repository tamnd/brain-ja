 ## 解決策
 ## 問題の理解

 このタスクは、通常の意味での組み合わせではなく、幾何学的なものです。 平面上には個別の点の集合が与えられますが、それらのうち 3 つが 1 つの直線上に存在することはありません。 このセットから、点のサブセットを選択し、それらを頂点として使用して多角形を形成できる場合に、その構成がどの程度「凸状」になるかを判断します。 

ここでの有効な多角形とは、選択した点が自己交差のない単純な閉じた形状を形成するように順序付けすることを意味します。 作成できるこのようなポリゴンすべての中で、目標は、ポリゴンを凸状に保ちながら頂点の数を最大化することです。 言い換えれば、凸多角形の頂点として表示できる点の最大のサブセットを探しています。 

出力はポリゴン自体ではなく、その最大のサブセットのサイズのみです。 

このタイプの Codeforces 問題の制約レジームでは、通常、最大約$10^5$合計入力サイズが大きいポイントまたは複数のテスト ケース。 これにより、ポイントのすべてのサブセット、さらにはすべての 3 つのポイントを検査するものはすぐに除外されます。これらのポイントは急速に成長するためです。 ポリゴンを明示的に列挙したり、多くの候補サブセットの凸性をチェックしようとしたソリューションは失敗します。これは、凸性チェックだけではすでにサブセット サイズが線形であり、サブセットの数が指数関数的であるためです。 

すべての点が凸包の境界上にある場合、微妙なエッジ ケースが表示されます。 その状況では、すべての点が凸多角形に寄与し、答えは単純に点の合計数になります。 より限定的な意味での「極端な」点のみが重要であると誤って想定する素朴なアプローチは、ここで過小評価される可能性があります。 

もう 1 つの特殊なケースは、点がほぼ凸状に配置されているが、1 つ以上の点が厳密にハルの内側にある場合です。 たとえば、内部点が 1 つある凸状の四角形: 内部点は、すべての点を使用する凸状多角形の一部になることはできないため、単純な「すべてを取得する」アプローチは失敗します。 正解は船体の構造のみに依存し、内部の分布には依存しません。 

## アプローチ

 ブルートフォース戦略では、ポイントのすべてのサブセットを選択し、それが凸多角形を形成するかどうかをテストし、最大サイズを追跡しようとします。 サブセット選択における組み合わせ爆発を無視したとしても、多角形の凸性を検証するには、連続するすべてのターンが同じ向き、つまりサブセット サイズで線形であることを確認する必要があります。 と$n$ポイント、これは次のようなことにつながります$O(2^n \cdot n)$、さえ不可能になります。$n = 30$。 

重要な構造的洞察は、点のサブセットから形成された凸多角形はそのサブセットの凸包上になければならないということです。 凸多角形を徐々に拡張することを想像すると、頂点となる点は最終的に、選択したセット全体の凸包の境界上に位置する必要があります。 これは、点のセットから形成できる最大の凸多角形が、まさに完全なセットの凸包であることを意味します。 

したがって、問題はサブセットについて推論するのではなく、点セット全体の凸包を計算し、その上にいくつの点があるかをカウントすることに集約されます。 3 つの点が同一線上にないという制限により、船体の境界上で縮退した同一線上のチェーンを処理する必要がないため、実装が簡素化されます。 

問題が凸包計算として認識されると、Andrew のアルゴリズムなどの標準的な単調スタック構造が適用されます。 船体は組み立て可能です$O(n \log n)$ソートとそれに続く線形時間スキャンによるものです。 船体の下部と上部の両方を構築した後、船体の固有ポイントの数が答えとなります。

 ## アルゴリズムのチュートリアル

 タスクを、平面点セットの凸包を見つけて頂点を数えることに縮小します。 

1. すべての点を X 座標で並べ替え、Y 座標で結合を解除します。 凸包アルゴリズムは決定論的な左から右の順序での処理ポイントに依存するため、ソートが必要です。 
2. 点を左から右にスキャンし、候補ハル頂点のスタックを維持することによって、下部ハルを構築します。 新しいポイントごとに、スタック内の最後の 2 ポイントと新しいポイントが左折以外の方向に曲がるかどうかを確認します。 存在する場合、中間点は下側の境界の一部となることができず、削除されます。 
3. 同じ方法で上部船体を構築しますが、右から左にスキャンします。 上部境界の凸性を維持するために、同じターン条件が使用されます。 
4. 下部ハルと上部ハルを連結し、各ハルの最初と最後の点が重なっているため、重複する端点を削除します。 
5. 残っているユニークポイントの数が凸包のサイズとなり、これが答えとなります。 

ステップ 2 と 3 で重要な操作は、外積を使用した方向テストです。 3点与えられると$A, B, C$、計算します$(B - A) \times (C - B)$。 負の値またはゼロの値 (規則に応じて) は、右折または共線性を示します。これは、中間点が凸性を壊すため、削除する必要があることを意味します。 

### なぜ効果があるのか

 スキャン中のどの時点でも、スタックは処理されたポイントのプレフィックスの凸包を表します。 新しいポイントがスタック内の最後の 2 つのポイントとの凸性を侵害する場合、その中間ポイントは隣接するポイントによって形成される三角形の内側に位置するか、凹型のターンを作成するため、最終的なハルに表示できません。 これを削除すると、スタック境界が常に凸状であるという不変条件が保持されます。 すべてのポイントが正確に 1 回処理され、場合によっては 1 回削除されるため、有効なハル頂点が永久に破棄されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def convex_hull(points):
    points = sorted(points)
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]
    hull = convex_hull(pts)
    print(len(hull))

if __name__ == "__main__":
    solve()
```実装は標準の単調スタック構造に従います。 の`cross`関数は方向をエンコードし、必要な唯一の幾何学的プリミティブです。 厳しい削除条件`<= 0`は、問題の「同一直線上に 3 点がない」制約の下では安全であり、厳密に凸状のターンのみがスタックに保存されることが保証されます。 

両方のハル パスが左端と右端のポイントを共有するため、最後の連結では重複したエンドポイントが削除されます。 

## 実用的な例

 ### 例 1

 1 つの内部点を持つ正方形を形成する点を考えてみましょう。$$(0,0), (2,0), (2,2), (0,2), (1,1)$$| ステップ | 船体下部 | 上部船体 | アクション |
 | --- | --- | --- | --- |

 | より低く構築する | (0,0)、(2,0)、(2,2) | - | ターン テストによって削除された内部ポイント |

 内側の点 (1,1) は、常に隣接する境界点と非左折を形成するため、破棄されます。 これにより、内部の点が船体に寄与しないことが確認されます。

 ## 特殊なケース

 エッジ ケースの 1 つは、すべての点が同一線上にある場合です。 その状況では、すべてのトリプルはゼロ外積を生成するため、ハル構造は 2 つのエンドポイントだけが残るまで継続的にポイントをポップします。 このアルゴリズムは、結果をセグメントの端点に自然に還元します。これが、構築下で許可される唯一の有効な凸ポリゴン縮退です。 

もう 1 つのケースは、ポイントがすでに凸の位置にある場合です。 すべてのターンは厳密に残されているため、スタック構築中に削除は発生せず、両方の船体パスで完全なポイント セットが返されます。 したがって、アルゴリズムは特別な処理を行わずに最大値を保持します。 

最後の微妙なケースは、最小入力サイズです。 3 つの点を使用すると、アルゴリズムは同一の上部ハルと下部ハルを構築し、マージ ステップで重複を正確に削除し、唯一可能な凸多角形と一致する正確に 3 つの頂点を返します。
