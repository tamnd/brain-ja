 ## 解決策
 ## 問題の理解

 数字列が与えられます`a`そして整数`k`。 実際のプレートはそうではありません`a`それ自体ではなく、連結して得られる文字列`a`それ自体で`k`回。 

この長い文字列から、すべての桁を削除することはできない場合を除き、位置のサブセットを削除することができます。 残りの数字は元の相対的な順序を維持し、場合によっては先頭にゼロを付けて数値を形成します。 

さまざまな削除の選択肢がどれだけ多くなり、次の数で割り切れるかを数えなければなりません。`5`。 異なる位置のセットを削除する場合、2 つの選択肢は異なるものとみなされます。 

長さ`a`せいぜい`10^5`、ただし最後の文字列には長さがあります`|a| · k`、 そして`k`と同じ大きさにすることができます`10^9`。 完全な文字列を構築することは不可能です。 最悪の場合、含まれる可能性があります`10^14`数字。 展開された文字列のすべての桁を扱うアルゴリズムは直ちに除外されます。 

答えは必須です`10^9+7`これは、有効な削除セットの数が指数関数的に増加し、モジュラー演算がソリューション全体に関与することを示す強力なヒントです。 

重要なエッジケースは、部分文字列ではなく部分シーケンスを数えているという事実から来ています。 

考慮する：```
a = "1256"
k = 1
```有効な数値は次のとおりです。`5`、`15`、`25`、 そして`125`。 続いて`5`は、その前の数字がすべて削除されても有効です。 部分文字列ベースの解釈では、いくつかの答えが見つからない可能性があります。 

別の微妙なケースは次のとおりです。```
a = "0"
k = 1
```唯一の空ではないサブシーケンスは、`"0"`で割り切れます。`5`、したがって、答えは次のとおりです`1`。 不注意な解決法を行うと、先頭のゼロの数字が除外され、誤った値が返される可能性があります。`0`。 

さらに興味深い例は次のとおりです。```
a = "5"
k = 2
```展開された文字列は、`"55"`。 

有効なサブシーケンスは次のとおりです。```
first 5
second 5
55
```答えは`3`。 を含む位置のみをカウントします。`5`与えるだろう`2`、複数の数字を保持できることを忘れています。 

最後に、すべての数字が次のいずれかの場合、`0`または`5`、空でないすべての部分列は次のように割り切れます。`5`。 

例えば：```
a = "55"
k = 1
```有効なサブシーケンスは次のとおりです。```
first 5
second 5
55
```与える`2² - 1 = 3`。 どのソリューションでも、前の桁の可能な選択肢をすべて正確にカウントする必要があります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 完全な文字列を構築する`s`、位置の空でないすべてのサブセットを列挙し、対応するサブシーケンスを構築し、その値が次で割り切れるかどうかをテストします。`5`。 

数値は次で割り切れます`5`まさにその最後の桁が`0`または`5`, したがって、割り算テスト自体は簡単です。 問題は部分列の数です。 長さの文字列`n`もっている`2^n - 1`空ではないサブシーケンス。 たとえ`n = 60`、これはすでに超えています`10^18`。 実際の問題は、約長さに達する可能性があります`10^14`, なので力技は絶望的です。 

すべてを変える観察は、`5`最後の桁のみに依存します。 

その位置を決めたとします`i`最後の文字列の は、最後に保持された数字です。 結果の数値が次の数で割り切れるようにするためには、`5`、数字`i`どちらかである必要があります`0`または`5`。 

1回の位置`i`以降のすべての位置の最後の数字として選択されます。`i`削除する必要があります。 以前のすべてのポジション`i`独立して保持または削除できます。 

あれば`i`その前に位置が正確にあります`2^i`どちらを残すかを選択する方法。 

これは、次のことが起こるたびに、`0`または`5`2 の累乗に寄与します。 

位置に番号が付けられている場合`0`、有効な終了位置の寄与は次のとおりです。```
2^position
```したがって、文字列の答えは`s`は```
Σ 2^i
```すべてのポジションにわたって`i`誰の数字は`0`または`5`。 

ここで、繰り返し構造を利用します。 

させて`m = |a|`。 

位置`j`のコピーの中に`a`グローバルな位置に表示されます```
j,
j + m,
j + 2m,
...
j + (k-1)m
```もし`a[j]`どちらでもない`0`または`5`、何も貢献しません。 

それ以外の場合、その合計貢献度は、```
2^j (1 + 2^m + 2^(2m) + ... + 2^((k-1)m))
```2 番目の要素は等比級数です。 

させて```
r = 2^m
```すると答えはこうなります```
(Σ valid positions j of 2^j)
×
(1 + r + r² + ... + r^(k-1))
```すべての算術演算はモジュロです`10^9+7`。 

幾何和は次のように計算できます。```
(r^k - 1) / (r - 1)
```モジュロ`MOD`、モジュラーインバースを使用します。

 ## アルゴリズムのチュートリアル

 1.読む`a`そして`k`。 
2. しましょう`m = len(a)`。 
3.トラバース`a`左から右に計算します```
base = Σ 2^j
```すべてのポジションにわたって`j`数字はどこにありますか`0`または`5`。 

このような各位置は、最後の保持桁がコピー内のその位置に由来するすべてのサブシーケンスを表します。 
4. コンピューティング```
r = 2^m mod MOD
```コピー全体を 1 つシフトすると指数が増加するため、`m`。 
5. コンピューティング```
geom = 1 + r + r² + ... + r^(k-1)
```モジュロ`MOD`。 

等比級数の公式を使用すると、次のようになります。```
geom = (r^k - 1) * inverse(r - 1)
```モジュロ`MOD`。 
6. 乗算:```
answer = base * geom mod MOD
```7. 結果を出力します。 

### なぜ効果があるのか

 すべての有効なサブシーケンスには、最後に保持された一意の位置があります。 最後の位置には次のいずれかを含める必要があります`0`または`5`そうでない場合、結果の数値は次の数で割り切れません。`5`。 

そのような位置を修正します`i`。 その後のすべてのポジション`i`は削除する必要がありますが、その前の各位置は`i`独立して保持または削除できます。 これは正確に与えます`2^i`で終わるサブシーケンス`i`。 

すべてのサブシーケンスには最後の位置が 1 つだけあるため、終了位置が異なると、部分シーケンスの素のセットが生成されます。 

合計する`2^i`を含むすべての位置にわたって`0`または`5`すべての有効なサブシーケンスを 1 回だけカウントします。 

文字列の繰り返し構造により、コピー全体の等しいオフセットを等比級数にグループ化し、アルゴリズムで使用される式を生成できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def solve():
    a = input().strip()
    k = int(input())

    base = 0
    p2 = 1

    for ch in a:
        if ch == '0' or ch == '5':
            base = (base + p2) % MOD
        p2 = (p2 * 2) % MOD

    m = len(a)
    r = pow(2, m, MOD)

    geom = (pow(r, k, MOD) - 1) % MOD
    geom = geom * pow(r - 1, MOD - 2, MOD) % MOD

    ans = base * geom % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```変数`base`の 1 つのコピーからの貢献を保存します`a`。 文字列をスキャンしながら、`p2`常に等しい`2^j`モジュロ`MOD`、 どこ`j`現在の位置です。 

あらゆる出来事に対して、`0`または`5`、対応する 2 の累乗を加算します。 これは、その位置で終了するサブシーケンスの数を実装します。 

値`r = 2^m`は、1 つの完全なコピーを右に移動したときに得られる乗算係数を表します。 異なるコピー内の同じオフセットを持つ位置は等比数列に寄与します。 

幾何学和はモジュロで計算されます`MOD`フェルマーの小定理を使用すると、次のようになります。```
inverse(x) = x^(MOD-2)
```なぜなら`MOD`プライムです。 

よくある間違いは、通常の整数の除算を使用して幾何和を計算しようとすることです。 すべての演算はモジュラー演算のままでなければなりません。 

もう 1 つの簡単なバグは、逆剰余を乗算する前に剰余を忘れることです。 表現```
(pow(r, k, MOD) - 1) % MOD
```負の中間値を回避します。
