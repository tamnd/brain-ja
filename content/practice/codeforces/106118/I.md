 ## 解決策
 ## 問題の理解

 直線上の整数座標に配置された一連の垂直極が与えられます。`i`定位置に座る`x = i`そして高さがある`h[i]`。 左側から、光はベクトルで表される一定の方向に進みます。`(tx, ty)`と`tx > 0`したがって、ライトは常に右に移動しますが、状況に応じて上昇または下降する可能性があります。`ty`。 

各ポールは、その右側にあるすべてのものに対して光を遮断する可能性があります。 この問題は、個々の光線の観点から考えるのではなく、「シャドウ エンベロープ」を定義します。これは、すべての極を左に取り、その上部から所定の方向に光線を発射し、各 x 位置で到達する最大高さを考慮することによって形成される上部境界です。 ポールに到達したときにその頂点がこのエンベロープより厳密に上にある場合、ポールは照らされていると見なされます。 封筒上に正確に配置されている場合は、ブロックされていると見なされます。 

タスクは、何本のポールが点灯しているかを数えることです。 

合計に関する制約`n`テスト ケース全体の数は最大 500,000 であり、各極を以前のすべての極と比較する二次アプローチは即座に除外されます。 ソリューションは、各テスト ケースを線形または線形に近い時間で処理する必要があります。 

微妙な問題は、シャドウ エンベロープが単純にこれまでの最大の高さではないことです。 これは多くの斜線にわたる最大値であるため、エンベロープは時間の経過とともに傾きが変化します。 最大の高さを追跡したり、単一の線と比較したりする単純なアプローチは失敗します。 

いくつかの特殊なケースでは、典型的な間違いが明らかになります。 すべての高さが等しい場合、`ty = 0`、すべての光線は水平であり、すべてが正確に重なっているため、最初の極のみが照らされます。 単純な「以前の最大高さよりも厳密に大きい」アプローチでは、より多くの極が表示可能として誤ってマークされてしまいます。 

もし`ty < 0`、光線は下向きに傾斜しており、影があまり積極的に落ちないことを意味し、後の極は高さが低くても照らされる可能性があります。 エンベロープの高さが単調増加することを前提としたアプローチは、ここですぐに破綻します。 

もし`ty > 0`、光線は上向きに傾斜しているため、初期の高い極がより長く支配し、右端に影を落とすことができます。 これは、エンベロープが凸状の上部ハル問題として隠れてしまうため、最も困難な状況です。 

## アプローチ

 強引なアイデアは簡単です: 各極ごとに`i`、以前のすべての極をシミュレートします`j < i`、から始まる行を計算します`(j, h[j])`方向に`(tx, ty)`、位置での高さを評価します`i`、最大値を取ります。 もし`h[i]`がこの最大値よりも厳密に大きい場合、ポールは点灯します。 

各評価は定数時間なので、それぞれ`i`費用`O(n)`仕事、与えること`O(n^2)`テストケースごとに。 と`n = 5 * 10^5`テスト全体を合計すると、これでは遅すぎます。 

重要な観察は、各極が平面内の線を定義していることです。 各 x 座標で、整数点で評価される線形関数の増大するセットの最大値が必要です。 これはまさに動的な凸包/ラインコンテナの問題ですが、座標系がわずかに変換されています。 

各極`(i, h[i])`行を定義します。$$y = h[i] + (x - i)\cdot \frac{t_y}{t_x}$$書き換え:$$y = \frac{t_y}{t_x} x + \left(h[i] - i \cdot \frac{t_y}{t_x}\right)$$すべてのラインは同じ傾き成分を共有します。`x`なので因数分解できます`t_y / t_x`線間の比較を切片のような値の比較に減らします。 実数値のラインを明示的に維持する代わりに、離散的な位置での寄与を比較します。 

よりクリーンな方法は、浮動小数点のスロープを完全に回避することです。 すべてに次の値を掛けます`tx`:$$y \cdot tx = h[i]\cdot tx + (x - i)\cdot ty$$位置で`x = j`、ポールからの投稿`i`は次のようになります:$$h[i]\cdot tx + (j - i)\cdot ty$$したがって、それぞれについて`j`、私たちが望むのは：$$\max_{i < j} (h[i]\cdot tx - i \cdot ty) + j \cdot ty$$に依存する用語`i`から独立しています`j`したがって、現在の最大値を維持します。$$best = \max(h[i]\cdot tx - i \cdot ty)$$次に、エンベロープ値は`j`は：$$best + j \cdot ty$$次の場合にポールが点灯します。$$h[j]\cdot tx > best + j \cdot ty$$これにより、問題全体が、最大値を維持する単一の線形スキャンに縮小されます。

 ## アルゴリズムのチュートリアル

 1. 極の条件を書き換える`j`幾何学的比較の両側に次の値を乗算することで解明されます。`tx`、分数を削除し、シャドウ エンベロープを次の線形式に変換します。`j`。 
2. 以前の極からのすべての寄与が`i < j`のみに依存する用語に分割できます`i`とのみに依存する用語`j`。 これにより、実行最大値を事前に計算できます。`i`-依存部分。 
3. 変数を維持する`best`、最初は非常に負で、次の最大値を表します。`h[i] * tx - i * ty`加工されたポール全体にわたって。 
4. 各極について`j`、その「明るさスコア」を計算します。`h[j] * tx`そしてそれと比較してください`best + j * ty`。 
5. スコアが厳密に大きい場合は、極がシャドウ エンベロープの上にあるため、答えが増加します。 等価性は、問題の厳密な条件に一致する、明確なものとしてカウントされません。 
6.アップデート`best`現在の極の寄与を使用して`h[j] * tx - j * ty`。 

### なぜ効果があるのか

 前の各極は次の線形関数に寄与します。`j`方向ベクトルへの投影後。 エンベロープは、これらの関数の点単位の最大値です。 すべての関数は、変換された空間での切片によってのみ異なるため、各ステップの最大値は、これまでの最良の切片のみに依存します。 アルゴリズムはその最大値を正確に維持するため、すべてのインデックスで`j`すべてのラインを明示的に保存せずに、真のエンベロープ値を再構築します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        h = list(map(int, input().split()))
        tx, ty = map(int, input().split())

        best = -10**30
        ans = 0

        for i in range(n):
            cur_score = h[i] * tx
            envelope = best + (i + 1) * ty

            if cur_score > envelope:
                ans += 1

            cand = h[i] * tx - (i + 1) * ty
            if cand > best:
                best = cand

        out.append(str(ans))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```このソリューションは、各テスト ケースを 1 回の左から右へのスキャンで処理します。 重要な実装の詳細は次のとおりです。`i + 1`ジオメトリ内では位置のインデックスが 1 であるため、一貫して一致します。 比較は厳密であるため、等価性は認められたものとしてカウントされません。 

すべての算術演算は Python 整数を使用して行われ、最大約`1e18`以上で、オーバーフローの心配はありません。

 ## 特殊なケース

 主なエッジケースは、すべてのポールの高さが同じで、`ty = 0`。 エンベロープは一定の水平線になります。 入力用`n = 5, h = [3,3,3,3,3], tx = 2, ty = 0`、最初の極は最初の空のエンベロープの上にあるため点灯しますが、後続のすべての極は最初の極によって形成されたエンベロープ上に正確に位置します。 アルゴリズムは計算します`best = h[i]*tx`、そしてそれぞれの新しい極を比較します`h[j]*tx`と`best`、平等をもたらし、厳密な不平等により照明を正しく拒否します。 

もう 1 つのケースは負の傾きです。 と`h = [1,2,3], tx = 1, ty = -5`、エンベロープは急激に減少します。 アルゴリズムは維持します`best = h[i] - i*(-5)`、急速に増加しますが、`j*ty`エンベロープ項を効果的に引き上げて、後の極がチェックを通過できるようにします。 これは、変換された線形形状が正しいままであるにもかかわらず、最大高さのみの追跡が失敗する理由を示しています。 

最後のエッジケースは、非常に大きな初期の極が後のすべての極を支配する場合です。 のために`h = [10^9, 1, 1, 1], tx = 1, ty = 1`、最初のポールは巨大な`best`、その後のすべての比較は厳密な不等式を満たしません。 スキャンでは、再計算やオーバーフローのリスクがなく、答えが 1 として正しく維持されます。
