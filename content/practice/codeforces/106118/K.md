 ## 解決策
 ## 問題の理解

 3×3の三目並べボードが与えられました。 各セルには次のいずれかが含まれます`X`、`O`、 または`.`。 ボードは通常のゲームから有効な状態であることは保証されていないため、`X`そして`O`関係ありません。 

のび太は特別な力を手に入れる：彼は2つ置くことができる`O`任意の 2 つの空のセルに連続してマークを付けます。 これら 2 つの配置の後、ゲームはすぐに終了します。 結果として得られるボードに、完全な行、列、または対角線が少なくとも 1 つ含まれている場合、`O`, すると、のび太が勝ちます。 

すべてのテスト ケースで、そのような手のペアが存在するかどうかを判断する必要があります。 その場合は印刷します`YES`そしてその結果得られた勝利ボードが 1 つあります。 それ以外の場合は印刷します`NO`。 

ボード サイズは 3 × 3 に固定されています。最大 1000 個のテスト ケースがあっても、各ボードに含まれるセルは 9 個だけです。 ボードごとに一定量の作業を実行するアルゴリズムは、簡単に十分に高速です。 検索スペースが小さいため、高度な最適化は必要ありません。 

主な課題はパフォーマンスではなく正確さです。 私たちは、2 つの新しいものを配置するためのあらゆる可能な方法を慎重に検討する必要があります。`O`マーク。 

簡単な間違いの 1 つは、既に何らかの内容が含まれている行のみをチェックすることです。`O`s. 勝ちラインには、2 つの空のセルを埋める必要がある場合があります。 

例えば：```
...
OO.
...
```を配置する`O`中央の行の最後のセルにあるものがすぐに勝ちます。 のび太はちょうど2手動かなければならないので、2番目の手を置くことができます。`O`他のどこでも。 正しい答えは、`YES`。 

もう 1 つの微妙なケースは、勝ちラインに既存のラインが含まれていない場合です。`O`全然。```
...
.X.
...
```のび太は2つ置けます`O`は同じ行にありますが、それでも 2 つのマークしか与えられません。 フルラインには 3 つ必要です`O`したがって、答えは次のとおりです`NO`。 

別の間違いは、勝てない手を見つけた後で停止することです。 空のセルのすべてのペアを考慮する必要があります。```
X.X
.O.
...
```一部の配置は失敗しますが、中央の行の左右のセルを選択すると、`OOO`。 正しい答えは、`YES`。 

## アプローチ

 最も直接的なアイデアはブルートフォースです。 すべての空のセルを収集し、異なる空のセルの可能なすべてのペアを選択し、配置します`O`それらの位置で、結果のボードに勝ちラインが含まれているかどうかを確認します。 

三目並べボードには最大 9 個のセルがあるため、空きポジションは最大 9 個あります。 ペアの最大数は次のとおりです。$$\binom{9}{2} = 36$$各ペアについて、8 つの勝ちライン、つまり 3 行、3 列、2 つの対角線を調べます。 テスト ケースごとの合計作業量はわずか数百操作です。 

ボードのサイズは固定されているため、この総当たり検索は実際にはすでに最適です。 これ以上に活用できる大きな構造はなく、これ以上複雑なアプローチを採用しても、不必要な複雑さが増すだけです。 

重要な観察は、ボードが非常に小さいため、徹底的な検索は事実上一定時間であるということです。 潜在的な勝ち筋を個別に推論する代わりに、すべての正当な手のペアを単純にテストし、結果を直接検証することができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべてのムーブペアに対するブルートフォース | O(E²) ただし、E ≤ 9 | お(1) | 承認済み |
 | 最適 | O(E²) ただし、E ≤ 9 | お(1) | 承認済み |

 以来`E`が最大 9 の場合、どちらの説明も同じ実際的な解決策を表します。 

## アルゴリズムのチュートリアル

 1. 3 × 3 ボードを読み取ります。 
2. すべての空のセルの座標を収集します。 
3. 個別の空のセルのペアごとに次のようにします。 

場所`O`ボードの一時コピー上の両方の位置にあります。 
4. 変更されたボードに勝ちラインが含まれているかどうかを確認します。`O`。 

勝ちラインとは、3 つのセルがすべて一致する行、列、または対角線です。`O`。 
5. 勝ちラインが存在する場合は、出力します。`YES`そして改造した基板。 

この問題はどのような勝ちボードでも受け入れられるため、すぐに中止する場合があります。 
6. すべてのペアがテストされ、どのペアも勝利をもたらさなかった場合は、次のように出力します。`NO`。 

### なぜ効果があるのか

 このアルゴリズムは、のび太が倍の技を使用できるすべての合法的な方法を検査します。 2 つの配置の後に考えられる結果はそれぞれ、空のセルの 1 つのペアに正確に対応しており、そのようなすべてのペアがテストされます。 

ペアがテストされるとき、アルゴリズムは 8 つの勝ちラインすべてを明示的にチェックします。 行全体が次のもので構成されている場合`O`、そのボードは勝っています。 どのラインも一致しない場合、そのボードは勝っていません。 

すべての有効な手のペアが考慮され、結果として得られるすべてのボードが正しく評価されるため、アルゴリズムは勝利ボードが存在するたびにそれを見つけて報告します。`NO`何も存在しない場合のみ。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_win(board):
    for r in range(3):
        if all(board[r][c] == 'O' for c in range(3)):
            return True

    for c in range(3):
        if all(board[r][c] == 'O' for r in range(3)):
            return True

    if all(board[i][i] == 'O' for i in range(3)):
        return True

    if all(board[i][2 - i] == 'O' for i in range(3)):
        return True

    return False

t = int(input())

for _ in range(t):
    board = [list(input().strip()) for _ in range(3)]

    empty = []
    for r in range(3):
        for c in range(3):
            if board[r][c] == '.':
                empty.append((r, c))

    found = False

    m = len(empty)
    for i in range(m):
        for j in range(i + 1, m):
            temp = [row[:] for row in board]

            r1, c1 = empty[i]
            r2, c2 = empty[j]

            temp[r1][c1] = 'O'
            temp[r2][c2] = 'O'

            if is_win(temp):
                print("YES")
                for row in temp:
                    print("".join(row))
                found = True
                break

        if found:
            break

    if not found:
        print("NO")
```ヘルパー関数`is_win`8 つの勝ちラインすべてをチェックします。 ボードのサイズは固定されているため、行、列、対角を明示的にテストするのが最も単純で安全な実装です。 

リスト`empty`利用可能なすべての移動場所を保存します。 ネストされたループは、空のセルの順序付けされていないすべてのペアを反復します。 使用する`j = i + 1`同じペアを 2 回テストすることを回避し、同じセルを 2 回選択することを防ぎます。 

候補ペアごとに、ボードの新しいコピーが作成されます。 これにより、後で移動を元に戻す必要がなくなり、ロジックが単純になります。 

勝ちのボードが見つかった瞬間にループが終了し、ボードが印刷されます。 有効な勝ちボードであればどれでも使用できるため、検索を続ける必要はありません。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    def is_win(board):
        for r in range(3):
            if all(board[r][c] == 'O' for c in range(3)):
                return True

        for c in range(3):
            if all(board[r][c] == 'O' for r in range(3)):
                return True

        if all(board[i][i] == 'O' for i in range(3)):
            return True

        if all(board[i][2 - i] == 'O' for i in range(3)):
            return True

        return False

    t = int(input())

    out = []

    for _ in range(t):
        board = [list(input().strip()) for _ in range(3)]

        empty = []
        for r in range(3):
            for c in range(3):
                if board[r][c] == '.':
                    empty.append((r, c))

        found = False

        for i in range(len(empty)):
            for j in range(i + 1, len(empty)):
                temp = [row[:] for row in board]

                r1, c1 = empty[i]
                r2, c2 = empty[j]

                temp[r1][c1] = 'O'
                temp[r2][c2] = 'O'

                if is_win(temp):
                    out.append("YES")
                    out.extend("".join(row) for row in temp)
                    found = True
                    break

            if found:
                break

        if not found:
            out.append("NO")

    print("\n".join(out))

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()
    solve()
    return sys.stdout.getvalue()

res = run("""1
X.X
.O.
...
""")
assert res.startswith("YES")

# sample 2
res = run("""1

.O.
X..
""")
assert res.startswith("YES")

# impossible case
assert run("""1
X.X
.X.
...
""").strip() == "NO"

# diagonal completion
res = run("""1
O..
.X.
...
""")
assert res.startswith("YES")

# many empty cells
res = run("""1
...
...
...
""")
assert res.strip() == "NO"

 ## 特殊なケース

 ### 勝利ラインには両方の新しい動きが必要です

 入力:```
...
.O.
...
```中央の行には 1 つだけ含まれています`O`。 のび太が置ける`O`その行の残りの両方のセル:```
...
OOO
...
```アルゴリズムはそのペアをテストし、正しくレポートします`YES`。 

### 多くのペアは、一方が成功する前に失敗します

 入力:```
X.X
.O.
...
```空のセルのペアがいくつかあると勝ちラインは作成されません。 アルゴリズムは、中央の行の 2 つの側のセルに対応するペアに到達するまで検索を続けます。 すべてのペアが検査されるため、最適な構成が見逃されることはありません。 

### 回線に対する既存のサポートはありません

 入力:```
...
.X.
...
```2回移動すると、のび太は最大で2つまで作成できます。`O`任意の行、列、または対角線にあります。 勝利ラインには 3 つ必要です。 アルゴリズムはすべてのペアを使い果たし、勝ちのボードを見つけず、出力します。`NO`。 

### 複数の勝利の答えが存在します

 入力:```
OO.
...
...
```を配置する`O`一番上の行の残りのセルではすでにラインが完成しており、2 番目の移動は他の場所に行うことができます。 複数の有効な出力が存在します。 アルゴリズムは、問題ステートメントで許可されている、最初に遭遇した勝ちボードを返します。
