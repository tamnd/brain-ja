 ## 解決策
 ## 問題の理解

 整数セグメントが与えられます$[l,r]$。 セグメント$[a,b]$2 つのエンドポイントが一致する場合、共素と呼ばれます。$a$そして$b$～に等しい最大公約数を持つ$1$。 

すべての共素セグメントの中で、最小のものだけを考慮します。 厳密に小さい共素セグメントが完全に含まれていない場合、共素セグメントは最小になります。 

各テスト ケースについて、指定された範囲内に最小の共素セグメントがいくつ含まれているかをカウントする必要があります。$[l,r]$。 

制約は非常に明らかです。 エンドポイントは次のような大きさにすることができます$10^9$これは、すべてのサブセグメントを反復する解決策は不可能であることを意味します。 たとえ 1 つの長さの間隔でも$10^9$おおよそ含まれています$10^{18}$サブセグメント。 テスト ケースは最大 100 個あるため、目的のソリューションはテスト ケースごとに一定時間で実行する必要があります。 

難しいのは、最小の共素セグメントが実際にどのようなものかを理解することです。 

セグメントを考慮する$[2,3]$。 以来$\gcd(2,3)=1$、それは共素です。 適切に含まれる唯一のセグメントは、$[2,2]$そして$[3,3]$、どちらも素ではないので、$\gcd(2,2)=2$そして$\gcd(3,3)=3$。 したがって$[2,3]$最小限です。 

ここで考えてみましょう$[2,5]$。 共素なので$\gcd(2,5)=1$、しかし、それには含まれています$[2,3]$、これはすでに共素セグメントです。 したがって、$[2,5]$最小限にすることはできません。 

特に見逃しやすいのは 1 番目のケースです。セグメント$[1,1]$は互いに素であるため、$\gcd(1,1)=1$。 これより小さいセグメントが含まれていないため、最小限になります。 

たとえば:

 入力:```
1 1
```出力：```
1
```長さ 1 のすべてのセグメントが非共素であると仮定する不注意な解決策は、誤って 0 を返します。 

もう 1 つの重要なケースは次のとおりです。 

入力:```
2 2
```出力：```
0
```ここ$\gcd(2,2)=2$, したがって、セグメントは互いに素ではありません。 

もう 1 つの例:

 入力:```
2 4
```最小の共素セグメントは次のとおりです。$[2,3]$そして$[3,4]$, したがって、答えは2です。 

単純な試みでは、以下を含むすべての共素ペアをカウントする可能性があります。$[2,4]$、ただし、そのセグメントには次の内容が含まれています$[2,3]$そして最小限ではありません。 

## アプローチ

 ブルートフォースのアイデアは単純です。 含まれるすべてのセグメントを列挙する$[a,b]$、どうかを確認してください$\gcd(a,b)=1$を確認し、別の共素セグメントが含まれているかどうかを確認します。 

これは定義に直接従うため、正しいです。 残念ながら長さの範囲は$n$含まれています$O(n^2)$サブセグメント。 たとえ$n$だけだった$10^5$、これはすでに約について意味します$5 \times 10^9$セグメント。 までのエンドポイント$10^9$、ブルートフォースは完全に実行不可能です。 

重要な観察は、最小の共素セグメントは非常に剛直な構造を持っているということです。 

仮定する$[a,b]$最小限であり、$a<b$。 

もし$b-a\ge 2$、次に含まれるセグメント$[a,a+1]$その中にあります。 連続する整数は常に互いに素です。$$\gcd(a,a+1)=1$$それで$[a,a+1]$内部に含まれる共素セグメントです$[a,b]$。 それはミニマルさと矛盾します。 

したがって、すべての最小の共素セグメントの長さは 0 または 1 でなければなりません。 

長さ 0 は、$[x,x]$。 このようなセグメントが互いに素になるのは、次の場合のみです。$x=1$、 なぜなら$$\gcd(x,x)=x.$$したがって、長さ 0 の唯一の最小セグメントは次のとおりです。$[1,1]$。 

長さ 1 の意味$[x,x+1]$。 連続する整数は常に互いに素であり、含まれるセグメントは次のとおりです。$[x,x]$そして$[x+1,x+1]$。 のために$x\ge2$、どちらも素ではないので、$[x,x+1]$最小限です。 

ケース$x=1$は特別です。 セグメント$[1,2]$含まれています$[1,1]$、これは互いに素なので、$[1,2]$最小限ではありません。 

すべての最小の共素セグメントを完全に特徴付けました。 

1.$[1,1]$2.$[x,x+1]$あらゆる人にとって$x\ge2$これで数えるのが楽になりました。 

隣接するすべてのペア$[x,x+1]$内部$[l,r]$1 つの最小セグメントに寄与します。 このようなペアはすべての人に存在します$$x \in [l,r-1].$$がある$r-l$彼らのうち。 

唯一の調整は、範囲に特別なセグメントが含まれる場合です。$[1,1]$。 それはまさにそのときに起こります$l=1$。 

もし$l=r=1$、答えは1です。 

それ以外の場合は、$l=1$、ペア$[1,2]$カウントに含まれます$r-l$、しかし、それは最小限ではありません。 これを次のように置き換える必要があります$[1,1]$。 合計が残ります$r-l$。 

これにより、非常に単純な式が得られます。 

もし$(l,r)=(1,1)$、答え1。 

それ以外の場合は答えてください$r-l$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O((r-l+1)^2)$それより悪い |$O(1)$| 遅すぎる |
 | 最適 |$O(1)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む$l$そして$r$。 
2. かどうかを確認します。$l=r=1$。 

これは、単純な差分の公式で答えがカバーされない唯一の範囲です。 
3. もし$l=r=1$、1を印刷します。 
4. それ以外の場合は、印刷します$r-l$。 

ステップ 4 が機能する理由は、区間内のすべての最小の共素セグメントが 1 つの隣接するペアに正確に対応するためです。$[x,x+1]$と$x\ge2$、特別なシングルトンに加えて$[1,1]$。 カウントは常に次のように単純化されます。$r-l$を除くすべての間隔$[1,1]$。 

### なぜ効果があるのか

 少なくとも 2 の長さの互いに素なセグメントには、連続するペアが含まれます。$[x,x+1]$、それ自体が互いに素です。 このようなセグメントを最小にすることはできません。 

したがって、すべての最小の共素セグメントの長さは 0 または 1 になります。 

長さ 0 のセグメントのうち、$[1,1]$は素です。 

長さ 1 のセグメント間では、すべての$[x,x+1]$は素です。 まさにそのときは最小限です$x\ge2$、 なぜなら$[1,2]$共プライムセグメントを含む$[1,1]$。 

これらはすべて可能な最小の共素セグメントなので、内側で数えます。$[l,r]$上記の式が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    l, r = map(int, input().split())

    if l == 1 and r == 1:
        print(1)
    else:
        print(r - l)
```実装は、上で証明された特性に直接従うものです。 

最初の条件は、数値 1 だけからなる一意の間隔を処理します。その答えは 1 です。$[1,1]$最小の共素です。 

1 つおきの間隔では式が使用されます$r-l$。 以来$l$そして$r$せいぜい$10^9$、通常の整数演算で十分です。 Python の整数はこれらの値を簡単に処理します。 

最も一般的な間違いは、カウントを複雑にしすぎて、間隔全体の gcd 値について推論しようとすることです。 最小セグメントの構造が理解できれば、特殊なケースのみが理解できます。$[1,1]$残っています。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        l, r = map(int, input().split())

        if l == 1 and r == 1:
            ans.append("1")
        else:
            ans.append(str(r - l))

    print("\n".join(ans))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out
