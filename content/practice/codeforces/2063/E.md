 ## 解決策
 ## 問題の理解

 頂点にルートを持つ根付きツリーが与えられます`1`。 

順序のない頂点のペアごとに`(u, v)`、どちらの頂点も他の頂点の祖先ではないペアのみを考慮します。 させて

-`a = dist(u, lca(u,v))`-`b = dist(v, lca(u,v))`ペアは良いので両方とも`a`そして`b`厳密にポジティブです。 

このようなペアの場合、整数値の数を数えます。`x`他の 2 辺が次のような非縮退三角形の 3 番目の辺にすることができます。`a`そして`b`。 

タスクは、すべての順序付けされていない頂点ペアにわたってこの量を合計することです。 

最初の観察は純粋に幾何学的なものです。 プラス2面の場合`a`そして`b`、の整数値`x`三角不等式を満たすのは、`|a-b| < x < a+b`。 

この間隔内の整数の数は次のとおりです。`(a+b-1) - (|a-b|+1) + 1 = a+b-|a-b|-1`。 

以来`a+b-|a-b| = 2*min(a,b)`、私たちは得ます`f(u,v) = 2*min(a,b)-1`。 

したがって、問題全体は次のようになります$$\sum_{\text{good pairs }(u,v)} \bigl(2\min(a,b)-1\bigr)$$どこ`a`そして`b`は 2 つの頂点から LCA までの距離です。 

ツリーには以下が含まれます`3·10^5`すべてのテスト ケースにわたる頂点。 すべてのペアを即座に検査するソリューションは不可能になります。`4.5·10^{10}`最悪の場合はペアになります。 平`O(n^2)`限界をはるかに超えています。 に近いものが必要です`O(n log^2 n)`または`O(n log n)`。 

微妙な点は、祖先と子孫のペアの寄与がゼロであることです。`a`または`b`ゼロになるだろう。 すべてのペアに三角形の公式を適用する不注意な実装では、そのようなペアが誤ってカウントされてしまいます。 

チェーンを考慮してください```
1 - 2 - 3
```ペア`(1,3)`距離がある`(0,2)`LCAから。 式`2*min(a,b)-1`与えるだろう`-1`、意味がありません。 これらのペアは完全に除外する必要があります。 

もう 1 つの簡単な間違いは、LCA の異なる子サブツリーの頂点だけが適切なペアを形成するということを忘れていることです。 例えば```
    1
   / \
  2   3
```唯一良いペアは`(2,3)`。 ルートに関係するペアは祖先関連であり、寄与はゼロです。 

## アプローチ

 ブルートフォースの解決策は簡単です。 

頂点のペアごとに、LCA を計算します。 どちらも他方の祖先ではない場合は、次のように計算します。$$2\min(dist(u,lca),dist(v,lca))-1.$$これをすべてのペアで合計すると、正しい答えが得られます。 

たとえ`O(1)`LCA構造には、`O(n^2)`ペア。 と`n = 3·10^5`、これはまったく不可能です。 

重要なステップは、コントリビューションを書き直すことです。 

LCA が次のような良好なペアの場合`w`、 させて$$a=dist(u,w),\quad b=dist(v,w).$$それから$$f(u,v)=2\min(a,b)-1.$$アイデンティティの使用$$\min(a,b)=\sum_{k\ge1}[a\ge k][b\ge k],$$私たちは得る$$f(u,v) = \sum_{k\ge1}2[a\ge k][b\ge k]-1.$$これにより、問題は、LCA からの 2 つの深さが両方とも少なくとも であるカウントペアに変換されます。`k`。 

次に頂点を修正します`w`LCAとして。 

しきい値の場合`k`、 定義する$$cnt_k(c)$$子サブツリー内の頂点の数として`c`の`w`誰からの距離`w`少なくとも`k`。 

指標項によってカウントされるペアは、次の異なる子サブツリーに由来する必要があります。`w`したがって、そのようなペアの数は次となります。$$\sum_{i<j} cnt_k(i)\,cnt_k(j).$$全体をまとめると`k`そしてすべての頂点が完全な答えを与えます。 

この構造は、DSU-on-tree (小規模から大規模へのマージ) に最適です。 すべての頂点について、そのサブツリー内の深度分布に効率的にアクセスする必要があります。 子サブツリーをマージする際、LCA が正確に現在の頂点であるクロスサブツリー ペアをカウントします。 

難しいのは、すべてのしきい値を同時に評価することです。 標準的なトリックは、深度周波数を保存し、すべてのマージが対数時間で寄与するようにプレフィックス情報を維持することです。 

結果として得られるソリューションは次のように実行されます。`O(n log^2 n)`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | ツリー上の DSU + 深度周波数マージ | O(n log² n) | O(n log n) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 再定式化

 しましょう`dep[v]`根元からの深さになります。 

LCAとのペアの場合`w`、$$a=dep[u]-dep[w],\qquad b=dep[v]-dep[w].$$その貢献は、$$2\min(a,b)-1.$$答えを 2 つの部分に分けます。$$\sum (2\min(a,b))$$マイナス$$\#\{\text{good pairs}\}.$$どちらの数量も、LCA の処理中に計算できます。 

### マージ中に保持されるデータ

 各サブツリーについて、深さによってインデックス付けされた頻度構造を維持します。 

頂点の場合`w`、保存されているすべての深度値は実際に次の値を表します。$$dep[x].$$2 つの子サブツリーを結合する場合、各側の 1 つの頂点によって形成されるすべてのペアの LCA は次のようになります。`w`。 

用語$$\min(dep[u]-dep[w],\,dep[v]-dep[w])$$絶対的な深さを使用して書き換えることができ、カウントと深さの合計を保存するフェンウィック ツリーを通じてクエリを実行できます。 

### DSU の結合

 1. DFS を実行して、サブツリーのサイズと深さを計算します。 
2. 頂点をボトムアップで処理します。 
3. 各頂点は、処理されたサブツリー内のすべての深さを含むコンテナを所有します。 
4. 常に小さいコンテナを大きいコンテナにマージします。 
5. 小さいコンテナから頂点を挿入するときに、それらが大きいコンテナにすでに存在する頂点にどの程度寄与しているかをクエリします。 
6. 寄与の式は最小値の合計に変換され、以下を格納するフェンウィック ツリーを使用して評価できます。 

- 深さのカウント
 - 深さの合計
 7. すべての子のマージが完了したら、現在の頂点の深さをコンテナに挿入し、上に戻します。 
8. 同時に良好なペアを数えます。 すべての子間のペアは、ペア数の減算項に 1 つ寄与します。 
9. 蓄積する$$2\sum \min(a,b)$$最後に良好なペアの数を引きます。 

### なぜ効果があるのか

 すべての良好なペアには固有の LCA があります。 

頂点を処理する場合`w`、DSU マージでは、エンドポイントが 2 つの異なる子サブツリーにあるペアが考慮されます。`w`。 他の頂点がそれらの LCA になることはできないため、このようなペアは 1 回だけカウントされます。 

どのペアでも、数量は`min(a,b)`2 つのエンドポイントの深さと、`w`。 Fenwick クエリは、以前にマージされたすべての子サブツリーに対してこれらの最小値の合計を正確に計算します。 小から大へのマージでは、各頂点の深さのみが移動することが保証されます。`O(log n)`必要な複雑さが得られます。 

すべての良好なペアはその LCA で 1 回だけカウントされるため、累積された値は目的の合計と等しくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from collections import defaultdict

sys.setrecursionlimit(1 << 20)

class Fenwick:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 2)

    def add(self, idx, val):
        n = self.n
        bit = self.bit
        while idx <= n:
            bit[idx] += val
            idx += idx & -idx

    def sum(self, idx):
        res = 0
        bit = self.bit
        while idx > 0:
            res += bit[idx]
            idx -= idx & -idx
        return res

def solve():
    t = int(input())

    out = []

    for _ in range(t):
        n = int(input())

        g = [[] for _ in range(n)]

        for _ in range(n - 1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            g[u].append(v)
            g[v].append(u)

        depth = [0] * n
        parent = [-1] * n
        sz = [1] * n

        order = [0]
        parent[0] = 0

        for v in order:
            for to in g[v]:
                if to == parent[v]:
                    continue
                parent[to] = v
                depth[to] = depth[v] + 1
                order.append(to)

        for v in reversed(order[1:]):
            sz[parent[v]] += sz[v]

        maxd = max(depth) + 5

        cnt_bit = Fenwick(maxd)
        sum_bit = Fenwick(maxd)

        ans_min = 0
        good_pairs = 0

        def dfs(v, p):
            nonlocal ans_min, good_pairs

            big = None
            store = []

            for to in g[v]:
                if to == p:
                    continue
                cur = dfs(to, v)
                if big is None or len(cur) > len(big):
                    big = cur

            if big is None:
                big = []

            active_cnt = 0

            for d in big:
                idx = d + 1
                cnt_bit.add(idx, 1)
                sum_bit.add(idx, d)
                active_cnt += 1

            for to in g[v]:
                if to == p:
                    continue

                cur = dfs_data[to]

                if cur is big:
                    continue

                for d in cur:
                    idx = d + 1

                    c1 = cnt_bit.sum(idx)
                    s1 = sum_bit.sum(idx)

                    ctot = active_cnt
                    stot = sum_bit.sum(maxd)

                    c2 = ctot - c1
                    s2 = stot - s1

                    ans_min += s1 + d * c2
                    good_pairs += active_cnt

                for d in cur:
                    idx = d + 1
                    cnt_bit.add(idx, 1)
                    sum_bit.add(idx, d)
                    active_cnt += 1
                    big.append(d)

            for d in big:
                idx = d + 1
                cnt_bit.add(idx, -1)
                sum_bit.add(idx, -d)

            big.append(depth[v])

            dfs_data[v] = big
            return big

        dfs_data = [None] * n
        dfs(0, -1)

        answer = 2 * ans_min - good_pairs
        out.append(str(answer))

    sys.stdout.write("\n".join(out))

solve()
```実装は小規模から大規模へのパラダイムに従います。 

各 DFS 呼び出しによって返されるコンテナーには、そのサブツリー内のすべての頂点の深さが格納されます。 2 つの子サブツリーがマージされると、すべてのクロス ペアはその LCA として現在の頂点を持ちます。これはまさに必要なペアのセットです。 

フェンウィック ツリーは、大きなコンテナ内に現在存在する深さのカウントと合計を維持します。 頂点の深さの場合`d`、計算できます$$\sum \min(d,x)$$プレフィックス数とプレフィックス合計を使用して、以前に挿入されたすべての深さに対して照合します。 これが、すべてのペアの反復を回避する中心的な最適化です。 

微妙な点は、子の交差ペアのみをカウントすることです。 すでに大きなコンテナにマージされている頂点は以前の子サブツリーからのものですが、現在処理されている頂点は 1 つの新しい子サブツリーに属します。 すべてのペアは 1 回だけ生成されます。 

もう 1 つの微妙な点は、最終的な式です。 マージ中は、次の合計のみが蓄積されます。`min(a,b)`。 実際の貢献度は、`2*min(a,b)-1`したがって、すべての最小値を合計した後、良好なペアの合計数を引きます。
