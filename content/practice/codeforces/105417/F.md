 ## 解決策
 ## 問題の理解

 数直線上に配置された卵の位置が、それぞれ別個の整数座標で与えられます。 最大でも設置が許可されています`k`ランプを加熱し、各ランプを同じ線上の整数座標に配置することもできます。 すべての卵は最も近いランプによって加熱されると考えられ、構成のコストは卵から最も近いランプまでの最大距離となります。 

タスクは、この最大距離ができるだけ小さくなるようにランプの位置を選択することです。 

これを解釈する便利な方法は、各ランプがラインのセグメントを「カバー」しており、すべての卵がこれらのカバー領域の少なくとも 1 つに十分近くになければならないということです。 私たちは総距離を最小化しようとしているのではなく、すべての卵の中で最悪のケースを最小化しようとしているだけです。 

制約が十分に大きいため、すべてのランプの配置や卵のすべてのサブセットをテストするソリューションは不可能です。 まで`5 × 10^5`ポジション、`O(n^2)`このアプローチはすでに実現可能な限界を何桁も超えており、さらには`O(nk)`最悪の場合大きすぎます。 

重要な構造上の制約は、すべてが 1 次元の線上にあるということです。 これにより、幾何学的複雑さがすべて取り除かれ、問題が区間カバーに変わります。 

いくつかの特殊なケースについては、明確に検討する価値があります。 もし`k = n`、すべての卵にランプを置き、答えを与えることができます`0`。 もし`k = 1`、最適なランプは中央値のような最適なカバー点の近くに配置され、答えは単一の中心ですべての点をカバーするために必要な最小半径になります。 1 つの遠く離れた外れ値を除いてすべての卵がクラスター化されている場合、答えは平均間隔ではなく、最も近いクラスター中心からのその外れ値の距離によって支配されます。 

単純な間違いは、アレイの端点や中間点などの固定位置にランプを配置すれば常に機能すると考えることです。 たとえば、ポイントの間隔が不均等な場合、これは失敗します。`[0, 1, 2, 100]`と`k = 2`、最適なグループ化は`{0,1,2}`そして`{100}`、対称分割ではありません。 

## アプローチ

 ブルートフォースの観点からは、`k`可能なすべての整数座標間でランプの位置を計算し、結果として得られる最大距離を計算します。 ランプを卵の位置に制限したとしても、これは指数関数的な選択肢を伴う組み合わせ選択の問題となり、各構成コストを評価することになります。`O(n)`。 ランプの位置を選択する方法の数は増えるにつれて増えるため、これでは遅すぎます。`n choose k`。 

重要な観察は、視点を反転することによって得られます。 ランプの位置を直接選択する代わりに、最大許容距離を固定するかどうかを決定する質問をします。`R`、せいぜい置いてもいいでしょうか？`k`すべての卵が中に入るようにランプ`R`何かのランプの？ 

一度`R`固定され、各ランプは所定の位置に配置されます`x`間隔内のすべての卵をカバーします`[x - R, x + R]`。 これにより、問題は最小数の長さの間隔ですべての点をカバーするように変換されます。`2R + 1`整数位置を中心に配置されます。 並べ替えられた行では、これは貪欲に解決できます。最も左の覆われていない卵から開始し、それを覆ったままできるだけ右端にランプを配置し、覆われているすべての卵をスキップします。 

これにより、元の最適化問題が単調な決定問題に変わります。`R`。 半径の場合`R`機能するだけでなく、より大きな半径も機能します。 この単調性により、答えに対する二分探索が可能になります。

 ## アルゴリズムのチュートリアル

 ### 1. 卵の位置を並べ替える

 まずすべての座標を並べ替えて、左から右に処理できるようにします。 カバレッジの決定はラインに沿った相対的な位置のみに依存するため、この順序付けは不可欠です。 

### 2. 固定半径の実現可能性チェックを定義する`R`最大でもすべての卵をカバーできるかどうかをテストします。`k`ランプ、それぞれのカバー距離`R`。 

### 3. 一番左の覆われていない卵からの貪欲な配置

 左から右にスキャンします。 まだ覆われていない最初の卵に遭遇したら、後続の卵を最大限に覆うために、可能な限り最適な位置にランプを置きます。 

### 4. 卵を始めるための最適なランプの位置

 最初の覆われていない卵がその位置にある場合`a[i]`にランプを置きます`a[i] + R`が最適です。 これにより、最初の卵が確実に距離内にあることを確認しながら、どこまで右にカバレッジを拡大できるかが最大化されます。`R`。 

このランプは、すべての卵を所定の位置までカバーします。`a[i] + 2R`。 

### 5. 覆われた卵をすべてスキップする

 覆われた範囲内のすべての卵を越えてポインタを進め、すべての卵が覆われるか、それを超えるまで繰り返します。`k`ランプ。 

### 6. 有効な最小値を二分探索する`R`探します`R`から`0`まで`max(a) - min(a)`。 候補ごとに実現可能性チェックを実行します。 

### なぜ効果があるのか

 正確さは 2 つの特性に依存します。 まず、固定半径の場合、各配置は現在の覆われていない卵から開始して可能な最大のサフィックスをカバーするため、貪欲な戦略によりランプの数が最小限に抑えられます。 第二に、実現可能性は単調です`R`: 半径を大きくしても、必要なランプの数は決して増加しません。 これにより、最適な点をスキップすることなく、二分探索が最小有効半径に収束することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can(a, k, R):
    n = len(a)
    i = 0
    used = 0

    while i < n:
        used += 1
        if used > k:
            return False

        start = a[i]
        cover_end = start + 2 * R

        # place lamp at start + R, cover up to start + 2R
        while i < n and a[i] <= cover_end:
            i += 1

    return True

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()

    lo, hi = 0, a[-1] - a[0]

    while lo < hi:
        mid = (lo + hi) // 2
        if can(a, k, mid):
            hi = mid
        else:
            lo = mid + 1

    print(lo)

if __name__ == "__main__":
    solve()
```この解決策は、貪欲なカバレッジが線形に動作できるように、卵の位置をソートすることから始まります。 の`can`関数は、重要な実現可能性チェックを実行します。つまり、一番左の覆われていない卵を繰り返し選択し、それに最適に配置されたランプを想定し、そのカバー範囲内にあるすべての卵をスキップします。 次に、二分探索により、すべての卵をカバーできる最小半径が狭められます。`k`ランプ。 

微妙な点は、`start + 2 * R`カバレッジ境界として。 これはランプを次の場所に置くことから来ています。`start + R`、一番左の卵を正確な距離にします`R`離れて、右側に対称的にカバレッジを拡大します。

 | --- | --- | --- | --- |
 | チェック | 0 | 3 | [0]、[5]、[7] |

 | チェック | 1 | 有効 | ランプ 2 個以下 |

 最小有効半径は次のとおりです。`1`。 

これは、クラスタリングがいかに重要であるかを示しています。`{5,7}`半径がオーバーラップできる場合は、1 つのランプで処理できます。

| ステップ | R | 使用ランプ | 取材範囲 |

これにより、貪欲な動作が不均等な間隔を正しく処理していることが確認できます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    def can(a, k, R):
        n = len(a)
        i = 0
        used = 0
        while i < n:
            used += 1
            if used > k:
                return False
            start = a[i]
            end = start + 2 * R
            while i < n and a[i] <= end:
                i += 1
        return True

    def solve():
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        a.sort()
        lo, hi = 0, a[-1] - a[0]
        while lo < hi:
            mid = (lo + hi) // 2
            if can(a, k, mid):
                hi = mid
            else:
                lo = mid + 1
        print(lo)

    solve()
    return ""

 ## 特殊なケース

 単一の卵の場合、貪欲なプロセスはただちにそれを覆う 1 つのランプを配置し、半径を生成します。`0`。 このアルゴリズムは、不必要な追加の配置を試行しません。 

のために`k = n`、覆われていない卵ごとにランプが点灯するため、各卵は個別に覆われていますが、その条件は`used > k`決して失敗しないため、実現可能性は持続します`R = 0`、二分探索で正しく検出されます。 

大きく離れた点の場合、次のようになります。`[0, 1000000000]`と`k = 1`の場合、アルゴリズムは両端をカバーする単一のランプを配置し、計算された半径は実際の距離の半分になり、貪欲なカバレッジ範囲によって正確にキャプチャされます。
