 ## 解決策
 ## 問題の理解

 ショートリバーの町には、非常に長い蔓の花が 1 本あります。 各国民は正確に作られた花輪を受け取ります`k`花は常に次の植物を取り出す機械によってつる植物から順番に切り取られます。`k`順番に花を咲かせます。 ダイアナには好みの花の順序があり、それを彼女の図式と呼ぶことができます。 彼女は、この図式に一致する少なくとも 1 つの花輪を望んでいます。これは、順序に関係なく、少なくとも必要な数の各花の種類が含まれていることを意味します。 事前につる植物から花を取り除くこともできますが、機械が少なくとも花を咲かせるのに十分な花を残しておかなければなりません。`n`花輪。 

入力はつる植物を花の種類の配列として提供します。`a[1..m]`そしてダイアナの回路図は`b[1..s]`。 目標は、離れるときに少なくとも 1 つの花輪がダイアナの図式と一致するように、削除する花の位置のセットを決定することです。`n`または、より完全な花輪を作成するか、またはこれは不可能であると結論付ける必要があります。 

制約は大きいです:`m`、`n`、 そして`k`それぞれ最大 500,000 本の花があり、花の総数は少なくとも`n*k`。 サブ配列またはサブセットの数は組み合わせ的に増加するため、単純な方法で除去の考えられるすべての組み合わせをスキャンまたはシミュレートするソリューションは除外されます。 代わりに、適切なセグメントを効率的に見つけて、削除する位置を計算する線形または線形に近いソリューションが必要です。 

見落としやすいエッジケースとしては、次のような場合があります。`n=1`そしてダイアナは事実上唯一の市民であり、彼女の回路図で必要とされる花を除いて、ほぼすべての花を取り除くことができます。 もう 1 つの微妙なケースは、つる植物の k ブロックの境界に完全なワークピースがすでに含まれている場合です。 不注意なスライディング ウィンドウ ロジックは、慎重に実装しないと見逃す可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、可能な限りすべての連続したものを試します。`k`-length 部分配列、花の数を数えて、回路図が満足できるかどうかを確認します。 各候補について、生産するのに十分な花が残っているかどうかを計算できます。`n`完全なワークピース。 各部分配列の花の種類を数えるには O(k) が必要で、可能な開始位置は O(m) 個あるため、合計の複雑さは O(m*k) になります。 と`m`最大500,000および`k`潜在的に等しい`m`、このアプローチは遅すぎます。 

重要な観察は、Diana が考慮するのは最大でも 1 つの長さの部分配列だけであるということです。`k`彼女の回路図と一致します。 必要な花をすべて含むセグメントが見つかった場合は、このセグメントの外側にある余分な花を削除して、最初のお花を確保します。`n`ワークはまだ存在します。 これにより、問題は、回路図で必要な花の数を追跡するためのハッシュ マップと組み合わせた、つる植物上の 2 ポインターまたはスライディング ウィンドウ手法に集約されます。 

適切なウィンドウが見つかったら、どの花が「余分」であるかを計算します。残りの花を埋めるためにウィンドウの外側にある花のいずれかが必要です。`n-1`花輪、または回路図で必要とされる範囲を超えたウィンドウの内側。 これらの余分な花は除去の対象となり、その数は最小限に抑えることができます。 この洞察により、ハッシュ マップと 2 つのポインターを使用した単一パスを使用して、O(m) 時間で問題を解決できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(m*k) | O(k) | 遅すぎる |
 | スライディング ウィンドウ + カウント マップ | O(m) | O(max(a_i, b_i)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. Diana の回路図内の各花の出現を数えます。 させて`needed[type]`花の種類が出現する回数になります。`b`。 
2. 2 つのポインターを備えたスライディング ウィンドウを使用する`l`そして`r`つる植物の上に。`r`すべての種類が終わるまで花を含めるように拡張します。`needed`満足しています。 ハッシュマップを維持する`current[type]`窓の中にそれぞれの種類の花が何本あるか数えます。 カウンターを維持する`missing`回路図を満たすためにさらに多くの花を必要とする別の種類がどれだけあるのか。 
3. いつ`missing`ゼロに達すると、窓ができます`[l, r]`少なくとも必要な花が含まれているもの。 このウィンドウの外側に残りの花を作成するのに十分な花があるかどうかを確認してください。`n-1`ワーク（各長さ）`k`）。 窓には、回路図以外に取り外し可能な追加の花が含まれる場合もあります。 
4. どの花を取り除くかを決めます。 まず、ウィンドウ内の必要な数を超える花にマークを付けます。 第二に、窓の後に残っている花の数が超過した場合`(n-1)*k`、正確に終わるまでリムーバブルとしてマークします。`(n-1)*k`花は選択した窓の外に残ります。 取り外し可能な花の総数は最大で`m - n*k`。 
5. 削除する花の数とその位置を出力します。 

機能する理由: スライディング ウィンドウにより、回路図を含む連続ブロックが 1 回だけ見つかることが保証されます。 窓の内側の余分な花と、他のワークに必要のない外側の花だけを除去することで、少なくとも機械が生産する要件に違反しません。`n`花輪。 このアプローチは、あらゆる有効なソリューションには回路図を満たすウィンドウと正確なウィンドウが含まれている必要があるため、可能な最小限の削除をすべてカバーします。`n-1`他のワーク、最大でも残す`m - n*k`取り外し可能な花。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import Counter

m, k, n, s = map(int, input().split())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

needed = Counter(b)
current = Counter()
missing = len(needed)
res_l = res_r = -1

l = 0
for r in range(m):
    if a[r] in needed:
        current[a[r]] += 1
        if current[a[r]] == needed[a[r]]:
            missing -= 1
    while missing == 0:
        # window [l, r] satisfies schematic
        # check if enough flowers remain outside to make n-1 workpieces
        left_flower_count = l
        right_flower_count = m - r - 1
        total_outside = left_flower_count + right_flower_count
        if total_outside >= (n-1)*k:
            res_l, res_r = l, r
            break
        if a[l] in needed:
            if current[a[l]] == needed[a[l]]:
                missing += 1
            current[a[l]] -= 1
        l += 1
    if res_l != -1:
        break

if res_l == -1:
    print(-1)
else:
    to_remove = []
    # extra inside window
    inside_count = Counter()
    for i in range(res_l, res_r+1):
        if a[i] in needed:
            if inside_count[a[i]] < needed[a[i]]:
                inside_count[a[i]] += 1
            else:
                to_remove.append(i+1)
        else:
            to_remove.append(i+1)
    # extra outside window
    remaining = m - len(to_remove) - n*k
    for i in range(m):
        if remaining == 0:
            break
        if i < res_l or i > res_r:
            to_remove.append(i+1)
            remaining -= 1
    print(len(to_remove))
    print(' '.join(map(str, to_remove)))
```このコードは、スライディング ウィンドウを使用して、Diana の回路図を満たすセグメントを見つけます。 まず右ポインタでウィンドウを拡大し、必要な花がすべて存在する間に左から縮小します。 適切な窓を見つけた後、窓の内側と外側の両方で余分な花を特定して除去し、残りの花が少なくとも形成されていることを確認します。`n`完成したワークピース。 

境界の扱いは微妙です。 インデックスは、出力のために 0 ベースから 1 ベースに変換されます。 ウィンドウ内の余分な花を数えるときは、必要な花を削除しないように別のカウンターを追跡します。
