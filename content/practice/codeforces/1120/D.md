 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、根を張った木です。`n`各頂点の価格は負ではありません。 ルートは頂点 1 です。リーフは次数 1 の非ルート頂点です。 Arkady は頂点のサブセットを購入し、Vasily がリーフに割り当てた番号に関係なく、購入した頂点を使用してリーフの値を操作して、すべてのリーフの番号が 0 になるようにしたいと考えています。 各頂点は、サブツリー内のすべてのリーフを整数 (正、負、またはゼロ) で調整できます。 課題は、すべての葉をゼロにできることを保証するために Arkady が支払わなければならない最小の合計価格を見つけ、どの頂点がそのような最適なセットの少なくとも 1 つに属するかを特定することです。 

入力により、頂点数、価格の配列、およびツリー エッジが与えられます。 出力には、最小限のコストと、最適な購入で表示される頂点のセットが必要です。 

与えられた`n`は最大 200,000、各価格は最大 10^9 になる可能性があるため、頂点のすべてのサブセットを考慮する強引なアプローチは実行不可能です。 ツリー構造は、階層関係を活用する必要があることを意味します。`n`O(n) または O(n log n) アプローチが必要です。 リーフの隣接性のみに基づいた素朴な貪欲な選択では、重複するサブツリーを考慮できません。ルート近くの頂点を購入すると、各リーフを個別に購入するよりも安価に多くのリーフをカバーできる可能性があります。 

明らかではないエッジ ケースには、頂点の価格がその子の価格の合計よりも高いツリーが含まれます。 たとえば、それぞれ価格 1 の 2 つの葉をカバーするコスト 10 の頂点は、より安価な代替品が存在する場合には購入すべきではありません。 また、すべてのリーフのコストがゼロの場合、内部頂点を不必要に購入するとコストが膨らみます。 

## アプローチ

 ブルートフォース手法では、空ではない頂点のすべてのサブセットを列挙し、リーフへの可能なすべての整数の割り当てをシミュレートし、Arkady がサブツリー操作でそれらをゼロにできるかどうかを確認します。 これには O(2^n) 個のサブセットが必要ですが、n が 200,000 までの場合は不可能です。 サブセットを追跡することによるツリー全体の DP による枝刈りでも、最悪の場合は指数関数的になります。 明らかに、構造的な洞察が必要です。 

重要な観察は、最適なセット内の頂点は、**いくつかの葉の「最小限のカバー」** として機能する必要があるということです。サブツリー内の葉をカバーするための最小コストを再帰的に計算できます。葉の場合は、それを購入する必要があります。内部ノードの場合、それを購入するか、すべての葉をカバーするためにその子に依存します。各ノードで安価なオプションを選択することで、最小総コストが保証されます。これは、重み付けに適応した「頂点カバー」の考え方を備えた古典的な **ツリー DP 問題**です。 さらに、どの頂点が少なくとも 1 つの最適なセットに属しているかを追跡するために、選択肢を上方に伝播し、いくつかの最小コストのソリューションに表示される頂点をマークすることができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n 2^n) | 遅すぎる |
 | ツリー DP (最適) | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ツリーを頂点 1 でルート化し、標準のルート化されたツリーとして扱います。 各ノードについて、子のリストを維持します。 
2. DP 配列を定義する`dp[v]`のサブツリー内のすべてのリーフをカバーするための最小コストを保存します。`v`。 
3. 再帰的に計算する`dp[v]`葉から根まで。 葉っぱに関しては、`dp[leaf] = c[leaf]`、ゼロにするにはリーフを購入する必要があるためです。 内部ノードの場合、`dp[v] = min(c[v], sum(dp[u] for u in children of v))`。 これは、ノード自体を購入するか、子に依存するかの選択を表します。 
4. 少なくとも 1 つの最適なセットに属する頂点を見つけるには、別の再帰プロシージャを定義します。`mark(v, parent_choice)`。 もし`parent_choice`親を購入していないことを示します。`c[v] <= sum(dp[u])`含める`v`最適なセットで。 それ以外の場合は、その選択を子供たちにまで伝えます。 
5. マークされた頂点をすべて収集し、最小コストを出力します。`dp[1]`マークされた頂点のソートされたリスト。 

機能する理由: DP 不変条件により、次のことが保証されます。`dp[v]`すべてのリーフをカバーするための最小の総コストです。`v`のサブツリー。 ノードの購入コストと子ノードに依存するコストを比較することで、グローバルな最小性を保証します。 マーキングは、すべてのサブツリーでの最小コストを考慮して、最適なセットに現れる可能性のある頂点を識別するための決定を伝播します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(300000)

n = int(input())
c = list(map(int, input().split()))
tree = [[] for _ in range(n)]

for _ in range(n - 1):
    a, b = map(int, input().split())
    tree[a - 1].append(b - 1)
    tree[b - 1].append(a - 1)

dp = [0] * n
children = [[] for _ in range(n)]
parent = [-1] * n

def dfs(u, p):
    parent[u] = p
    is_leaf = True
    sum_dp = 0
    for v in tree[u]:
        if v == p:
            continue
        is_leaf = False
        children[u].append(v)
        dfs(v, u)
        sum_dp += dp[v]
    if is_leaf:
        dp[u] = c[u]
    else:
        dp[u] = min(c[u], sum_dp)

dfs(0, -1)

res_set = set()
def mark(u, must_take):
    take = False
    sum_children = sum(dp[v] for v in children[u])
    if must_take:
        take = True
    elif c[u] <= sum_children:
        take = True
    if take:
        res_set.add(u + 1)
        for v in children[u]:
            mark(v, False)
    else:
        for v in children[u]:
            mark(v, True)

mark(0, False)

res_list = sorted(res_set)
print(dp[0], len(res_list))
print(' '.join(map(str, res_list)))
```説明: DFS は、各サブツリーの最小コストを計算します。 葉には`dp = cost`。 内部ノードは、自分自身を購入するか、その子を合計するか、どちらか安い方を選択します。 2 番目の再帰では、最適なセットに現れる可能性のある頂点を識別するための決定が伝播されます。 Off-by-one エラーは、計算における一貫した 0 ベースのインデックス付けと 1 ベースの出力によって回避されます。 最大 200,000 ノードのツリーを処理できるように、再帰の深さが増加しました。
