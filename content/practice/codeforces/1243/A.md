 ## 解決策
 ## 問題の理解

 いくつかのテスト ケースが与えられ、それぞれのテスト ケースは板の高さのリストで構成されます。 すべての板には幅 1 と整数の高さがあります。 これらの板のサブセットを選択し、任意の順序で並べて再配置して、選択した各板が垂直の柱となるスカイラインのような形状を形成することができます。 

板を配置したら、辺が軸と一致する正方形を切り抜きます。 正方形は、結合された形状の内側に完全に収まる必要があります。 目標は、このような正方形の辺の長さを最大化することです。 

この問題における重要な自由度は、板のサブセットを選択し、それらを任意に並べ替えることができることです。 これにより、元の配列から位置の制約がすべて削除され、構造が純粋に複数の高さのセットに縮小されます。 

制約制限は小さく、テスト ケースあたりの板数は最大 1000、テスト ケースの数は最大 10 です。 これにより、二次関数または O(n log n) の解が可能になりますが、三次関数や繰り返しの重いシミュレーションを伴うものは不要になります。 線形スキャンまたは周波数ベースの推論で十分です。 

最大の高さや合計の合計だけに注目すると、単純な推論による微妙な失敗例が現れます。 たとえば、高さの場合`[5, 1, 1, 1, 1]`, 5 が存在するので、5×5 の正方形が可能であると考えたくなります。しかし、少なくとも 5 の高さを持つ列は 1 つだけなので、幅 5 の正方形を形成することはできません。 正解は 1 です。 

誤解を招きやすいもう 1 つのケースは、背の高い板がたくさんあるのに十分ではない場合です。 のために`[4, 4, 4, 1, 1]`, 4×4 の正方形を期待するかもしれませんが、少なくとも 4 の高さを持つ板は 3 枚だけなので、幅 4 は不可能です。 

これらの例は、高さとカウントの両方の制約を同時に満たさなければならないことを示しています。 

## アプローチ

 強引なアイデアは、可能なすべての正方形サイズ k を試してみることです。 各 k について、高さが少なくとも k である少なくとも k 枚の板を選択できるかどうかを確認します。 「はい」の場合、k × k の正方形は、それらの k 個の背の高い板を取り、それらを連続的に配置することによって形成できます。 

単一の k をチェックするには O(n) がかかり、n までのすべての k を試すとテスト ケースごとに O(n²) になります。 n が 1000 までの場合、これは許容されますが、不要です。 

重要な観察は、固定 k の場合、高さ ≥ k の板だけが重要であるということです。 そのような板が少なくとも k 枚ある場合は、いつでもそのうち k 枚を選択して並べて配置できます。 配置の自由度により、幾何学的な複雑さがすべて解消されます。 問題はカウント条件に帰着します。 

すべての k 値を個別にチェックする代わりに、頻度を数えたり、配列を並べ替えたりして、考えられる k ごとに、k ≧ k である要素の数を計算できます。 答えは、この条件を満たす最大の k です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | k に対するブルート フォース | O(n²) | お(1) | 承認済み |
 | ソート / 度数カウント | O(n log n) または O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 幾何学的な問題を高さの数え方の問題に変換します。 

1. 固定候補辺の長さ k の場合、高さが少なくとも k である k 枚の板が必要であると要件を解釈します。 これは、辺 k の正方形には k 個の列があり、それぞれの列が少なくとも高さ k に達する必要があるためです。 
2. 高さ ≥ k を満たす板の数を数えます。 この数が少なくとも k であれば、サイズ k の正方形が実現可能です。 
3. 1 から n までのすべての可能な k を試し、実現可能な最大値を追跡します。 
4. カウントを効率的に計算するには、配列を並べ替えるか、頻度配列を構築します。 並べ替えを行うと、インデックスの位置を使用して、しきい値を超えている要素の数をすばやく判断できます。 
5. 実現可能条件を満たす最大の k を返します。 

配置の詳細を無視しても問題ない理由は、k 個の有効な板を選択すると、それらを常に連続して配置できるためです。 間隔や順序に制限はないため、実現可能性は構造ではなく量にのみ依存します。 

### なぜ効果があるのか

 このアルゴリズムは、k×k の正方形には少なくとも k 以上の高さの k 個の独立した垂直サポートが必要であるという事実に基づいています。 板は自由に再配置できるため、選択したサブセットを連続させることができます。 これにより、空間的な制約がなくなり、問題はしきい値とカウントの間の単純な不等号の検証に減ります。 この条件が満たされると、この条件に違反する構成は存在しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    k = int(input())
    for _ in range(k):
        n = int(input())
        a = list(map(int, input().split()))
        
        a.sort()
        
        ans = 0
        for i in range(1, n + 1):
            # number of elements >= i
            # in sorted array, this is n - first index where a[idx] >= i
            lo, hi = 0, n
            while lo < hi:
                mid = (lo + hi) // 2
                if a[mid] >= i:
                    hi = mid
                else:
                    lo = mid + 1
            cnt = n - lo
            if cnt >= i:
                ans = i
        
        print(ans)

if __name__ == "__main__":
    solve()
```このソリューションは板の高さを並べ替えて、各候補しきい値を超える値の数を効率的に計算できるようにします。 潜在的な正方形の辺 i ごとに、高さが少なくとも i になる最初の位置を二分探索し、その位置からカウントを導き出します。 

主な微妙な点は、条件を正しく解釈することです。幾何学的な正方形を直接構築しているのではなく、それを支えるのに十分な高さの板が存在することを確認しています。

 ### 例 1

これは、高さ 5 が存在するとしても、幅には複数の高い板が必要であるため、それが答えを支配しないことを示しています。

 ## 特殊なケース

 一般的なエッジケースは、多数の小さな板の中に 1 つの非常に大きな板が存在する場合です。 例えば、`[100, 1, 1, 1, 1]`高さ 100 をサポートできるのは 1 つの板だけであるため、1 を返す必要があります。 

もう 1 つの特殊なケースは、すべての板が同一である場合です。 のために`[3, 3, 3]`の場合、高さとカウントの両方の制約が 3 までのすべてのしきい値で完全に一致するため、答えは 3 です。
