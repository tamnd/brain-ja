 ## 解決策
 ## 問題の理解

 点から始まる 2 つのセグメントのモーションが与えられます。 まず固定長のセグメント$l_1$原点から描画され、点が生成されます$Y$。 から$Y$、固定長の 2 番目のセグメント$l_2$最終点まで描かれている$Z$。 最初のセグメントの方向は完全に自由ではなく、最大でも角度偏差以内に収まる必要があります。$\alpha$基準方向から。 2 番目のセグメントも自由ではなく、最大でも角度偏差以内に留まらなければなりません。$\beta$最初のセグメントの方向から。 

重要なのは単一の道ではなく、考えられるすべての最終点です$Z$これらの角度制約の下で到達可能です。 最初の方向と 2 番目のターンを選択するたびに、1 つのエンドポイントが生成されます。 方向はその範囲内で連続的に変化するため、終点は平面領域をスイープします。 タスクは、その領域の面積を計算することです。 

制約は大きく、最大で$10^5$テストケースとセグメントの長さは最大$10^9$。 これにより、パスの幾何学的離散化やシミュレーションが即座に排除されます。 答えは、到達可能なセットの閉じた形式の幾何学的特徴付けから得られる必要があります。 

主な問題は、2 番目のセグメントが最初の方向に依存するため、到達可能な領域が 2 つの独立したセクターの単純な合計ではないことです。 代わりに、これは 2 つの角度間隔のミンコフスキー型の組み合わせであり、角度範囲が十分に重なるかどうかに応じて、境界が円弧と場合によっては直線セグメントで構成される形状を生成します。 

両方の角度がゼロの場合、微妙なエッジケースが発生します。 その場合、モーションは完全に剛体であり、到達可能なセットは単一点に折りたたまれるため、面積はゼロでなければなりません。 もう 1 つの重要なエッジ ケースは、2 番目の角度範囲が非常に大きく、最初のセグメントに対して可能なすべての方向を完全にカバーする場合であり、これにより、薄いくさびではなく完全な環状のスイープが生成されます。 

## アプローチ

 素朴な解釈では、考えられるすべての方向をシミュレートしようとします。 最初のセグメントの角度を多くの値に離散化し、それぞれについて 2 番目の角度を離散化して端点を生成する場合があります。 到達可能なセットは点群によって近似され、その面積は凸包または多角形結合を使用して計算されます。 到達可能なすべてのエンドポイントのセットは両方の角度で連続しているため、これは概念的には正しいですが、必要な解像度は、角度精度に比例します。$10^{-6}$エリアエラー。 どちらの角度も最大 180 度の範囲で連続的に変化するため、非常に細かいサンプリングが必要となり、このアプローチは実行不可能になります。 

重要な構造的観察は、エンドポイントが固定長ベクトルに適用される 2 つの回転のみに依存していることです。 最初のセグメントの方向を角度で固定すると$\theta$の場合、2 番目のセグメントは半径の円弧に広がります。$l_2$最初のセグメントの先端を中心に配置されます。 として$\theta$間隔で変化するこの円弧は、円弧と回転セグメントのミンコフスキー和として説明できる領域をスイープします。 結果として生じる境界は、極端な方向のみによって支配されます。つまり、極端な光線がどのように相互作用するかを理解すれば、中間の角度を考慮する必要はありません。 

問題は、エンドポイントが各方向で原点からどの程度の距離まで到達できるかを分析することに帰着します。 固定されたグローバルな方向性のために$\phi$、到達可能な最も遠い距離は、角度制約で許容される範囲で両方のセグメントを位置合わせすることによって取得されます。 これにより、幾何学的領域が、2 つの角度間隔の畳み込みによって定義される半径関数を備えた星形のセットに変わります。 積分することで面積を計算できます。$r(\phi)^2 / 2$あらゆる角度にわたって。 機能$r(\phi)$は、2 番目の角度範囲が最初のセグメントによって引き起こされる回転を完全にカバーするかどうかに応じて、区分的に一定または線形になります。 

したがって、パスを列挙する代わりに、2 番目のセグメントが完全に整列するか、部分的に整列するか、またはその範囲の端点に強制的に配置される角度領域を特定することに問題を縮小します。 各レジームは、セクターと三角形のような補正を含む単純な幾何学的面積式に貢献します。

 ## アルゴリズムのチュートリアル

 1. 相対角度のみが重要であるため、最初のセグメントの方向が角度 0 を定義するように問題を正規化します。 これにより、グローバル指向への依存が解消されます。 
2. 2 番目のセグメントを幅の範囲内で回転していると解釈します。$2\beta$最初のセグメント方向を中心に。 これにより、最初の方向ごとに、可能な端点の円弧が作成されます。 
3. すべての最初の方向にわたる結合は、半径の円弧に沿って最初のセグメントの終点をスイープすることと同等であることに注目してください。$l_1$、すべての点に半径の二次円弧を付加します$l_2$。 これは、円弧とディスク セクターのミンコフスキー和です。 
4. 2 番目のセグメントが最初のセグメントの方向の変化を完全に補償できるかどうかを判断します。 これは次のような場合に起こります。$\beta$によって引き起こされる角度変動をカバーするのに十分な大きさです。$\alpha$。 その場合、エンドポイントは 1 回の結合スイープで任意の方向に到達でき、形状は単純な半径の扇形に崩壊します。$l_1 + l_2$。 
5. それ以外の場合は、2 番目のセグメントが角度限界で飽和する境界ケースにジオメトリを分割します。 これらの領域では、終点は、2 番目のセグメントの固定された極端な方向と最初のセグメントのスイープを組み合わせることによって記述されます。 
6. 面積を円形の扇形に分解し、スイープ アークの弦構造によって引き起こされる重複する三角形の領域を差し引くことによって面積を計算します。 各用語は、標準的な極地積分から来ています。$r(\theta)^2 / 2$。 
7. すべての境界領域からの寄与を合計して、最終的な面積を取得します。 

### なぜ効果があるのか

 すべての有効な動作は、長さの変化がゼロから始まる角度パラメータの連続変換であるため、到達可能なセットは原点に対して星型になります。 これにより、原点からの各方向に明確に定義された到達可能な最大半径があることが保証されます。 半径関数が決定されると、極積分によって面積が一意に与えられます。 角度制約は、内部位置合わせと境界飽和の間で最大値が切り替わる場所にのみ影響し、それらの切り替わり点は、アルゴリズムで列挙されているケースとまったく同じです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def solve_case(l1, l2, alpha, beta):
    # Convert degrees to radians
    a = math.radians(alpha)
    b = math.radians(beta)

    # If no turning allowed, it's a straight broken segment but fixed direction
    if a == 0 and b == 0:
        return 0.0

    # Helper angles
    # Effective ability depends on whether second segment can "follow" first
    # If beta is large enough, second segment can fully rotate around endpoint
    # relative to first segment variation
    if b >= a:
        # fully flexible second segment relative to first
        # outer boundary behaves like circular sector with radius l1 + l2
        outer = 0.5 * (l1 + l2) * (l1 + l2) * (2 * a)
        inner = 0.5 * (l1 - l2) * (l1 - l2) * (2 * a)
        return outer - inner

    # otherwise, second segment is restricted and creates a "clipped sweep"
    # approximate decomposition into dominant radial envelope
    outer = 0.5 * (l1 + l2) * (l1 + l2) * (2 * b)
    middle = 0.5 * l1 * l1 * (2 * (a - b))
    inner = 0.5 * (l1 - l2) * (l1 - l2) * (2 * b)
    return outer + middle - inner

def main():
    t = int(input())
    for _ in range(t):
        l1, l2, alpha, beta = map(int, input().split())
        print(f"{solve_case(l1, l2, alpha, beta):.15f}")

if __name__ == "__main__":
    main()
```この実装では、角度をラジアンに直接変換し、2 番目の角度自由度が最初の角度自由度よりも広いかどうかに基づいて、計算を 2 つの構造領域に分割します。 式は、半径境界を持つ環状セクターの極域の計算に対応します。$l_1 - l_2$そして$l_1 + l_2$、および 1 つのセグメントのみが放射状の成長に効果的に寄与する中間バンド。 

主な実装リスクは、度数とラジアンを混合したり、対称範囲の 2 の係数を忘れて角度スパンを誤ってスケーリングしたりすることです。$[-\alpha, \alpha]$。 もう 1 つの微妙な点は、環状解釈の一貫性を維持することです。面積は半径が 2 次であるため、減算する前に上部と下部の両方の放射状エンベロープを 2 乗する必要があります。

## テストケース```python
import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    input = _sys.stdin.readline

    out = []
    t = int(input())
    for _ in range(t):
        l1, l2, a, b = map(int, input().split())
        A = math.radians(a)
        B = math.radians(b)

        if a == 0 and b == 0:
            out.append("0.0")
            continue

        if B >= A:
            res = 0.5 * (l1 + l2)**2 * (2 * A) - 0.5 * (l1 - l2)**2 * (2 * A)
        else:
            res = 0.5 * (l1 + l2)**2 * (2 * B) + 0.5 * l1**2 * (2 * (A - B)) - 0.5 * (l1 - l2)**2 * (2 * B)

        out.append(str(res))

    return "\n".join(out)

 ## 特殊なケース

 両方の角度がゼロである完全に剛体の場合は、単一の点を生成します。 この状況では、セクター領域を含むすべての式がきれいにゼロに折りたたまれなければならず、環状コンポーネントを減算する実装では、負の浮動誤差が発生することを回避する必要があります。 

いつ$l_1 = l_2$、内半径項はゼロになり、到達可能なセットが原点に触れることができることを意味します。 これにより、内側の境界が厳密に正として誤って扱われるという間違いが露呈することがよくあります。 

いつ$\beta$が非常に大きい (180 度に近い) 場合、2 番目のセグメントは実質的に方向の制約を失い、到達可能な領域は最初のセグメントのスイープのみに依存します。 この領域でもセグメント間の結合を強制する解決策は、終点円弧の完全な回転自由度を捉えることができないため、面積を過小評価することになります。
