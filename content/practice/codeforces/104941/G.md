 ## 解決策
 ## 問題の理解

 各頂点にすでに最大 1 つの入力エッジと最大 1 つの出力エッジがある有向グラフが与えられます。 この制限は、すべての接続コンポーネントが構造的に非常に単純であることを意味します。つまり、それは有向パスまたは有向サイクルのいずれかであり、頂点が分岐点になることはありません。 

各頂点には重みがあります。 ゲームはこの固定グラフから始まり、許可される唯一のアクションは有向エッジを追加することですが、そうするたびに、どの頂点も複数の出力エッジと 1 つ以上の入力エッジを持たないというルールを維持する必要があります。 頂点 u から頂点 v までのすべての新しいエッジは、(w_u + w_v)^2 のスコアを与えます。目標は、追加されたすべてのエッジによって得られる合計スコアを最大化することです。 

重要な構造上の結果は、初期グラフが各頂点の「容量」の一部のみを消費することです。 頂点は、発信スロット、着信スロット、またはその両方をすでに使用している場合もあれば、どちらも使用していない場合もあります。 残るのは、1 対 1 の制約を尊重する限り、任意に接続できる空き送信スロットと空き受信スロットのコレクションです。 

n、m が 100000 までの制約は、実際には、n log n のソート ステップを伴う、いかなる解も本質的に線形または線形に近いものでなければならないことを意味します。 頂点またはエッジ上の二次関数は、約 10^10 の演算が必要になるため、直ちに不可能になります。 

大域的な構造を考慮せずに局所的な最良のペアを貪欲に接続できると仮定すると、素朴な推論による微妙な失敗例が現れます。 たとえば、重み [1、10、100、1000] と任意の利用可能なエンドポイントがある場合、局所的に 1000 と 1 をペアリングすることは、大きな二乗項が生成されるため、単独で考えると魅力的に見えますが、全体的に最適な構造は、個々のエッジの貪欲さではなく、すべての頂点にわたる一貫したペアリングに依存します。 もう 1 つの問題は、容量の対称性を無視することです。すべての頂点が入力スロットと出力スロットに最大 1 つしか寄与しないことを忘れると、実現可能性に反する方法でエンドポイントを一致させようとする可能性があります。 

## アプローチ

 直接的な総当りアプローチでは、考えられるすべての追加エッジを候補として扱い、入次数制約と出次数制約を尊重するエッジのサブセットの選択を試みます。 これは、すべての空き送信スロットがすべての空き受信スロットに接続でき、エッジの重みが (w_u + w_v)^2 になる、最大重みの 2 部マッチング問題になります。 単純な実装ではすべてのペアリングを試行しますが、k 個の自由発信頂点と k 個の自由着信頂点の間で可能な一致の数は k! であり、k が約 20 の場合でも実行不可能になります。 

重要な観察は、目的関数が展開されると非常に単純化されるということです。 選択した任意のペア (u, v) の寄与は、w_u^2 + w_v^2 + 2 w_u w_v です。 すべての一致したペアを合計すると、合計は、選択されたセットにのみ依存する定数項と、ペアごとの積のみに依存する項になります。 定数部分は頂点をどのようにペアにするかには依存せず、どの頂点が一致するかにのみ依存します。 すべての空き送信スロットは、いくつかの空き受信スロットと一致する必要があるため、セットは初期グラフによって固定され、最適化は完全に 2 つのマルチセット間の完全な一致に対する積 w_u w_v の合計を最大化することになります。 

これはまさに再配置不等式が適用される設定です。 最大の重みと最大の重みを組み合わせると、積の合計が最大になります。 したがって、両側をソートして順番に一致させると、最適な結果が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースマッチング | O(k!) | O(k) | 遅すぎる |
 | ソート + 貪欲なペアリング | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 最初のグラフからすべての頂点の現在の入次数と出次数を計算します。 各頂点は受信エッジと送信エッジの両方で容量 1 から開始するため、送信接続と受信接続用に空きスロットがいくつあるかを決定します。 
2. 2 つのリストを作成します。1 つは空きの発信スロットを持つすべての頂点を含み、もう 1 つは空きの受信スロットを持つすべての頂点を含みます。 この分離は、新しいエッジがどこで始まり、どこで終わることができるかを正確に表します。 
3. 両方のリストのサイズが同じであることを暗黙的に検証します。 これは、任意の有向グラフ内の入力エッジの合計数が出力エッジの合計数に等しいため、残りの合計容量も同様にバランスする必要があるため当てはまります。 
4. 両方のリストを頂点の重みで降順に並べ替えます。 このステップでは、再配置不等式を適用するための構造を準備し、値の高い頂点が確実に一致するようにします。 
5. 発信リストの i 番目の頂点と着信リストの i 番目の頂点をペアにし、各ペアの寄与 (w_u + w_v)^2 を累積します。 
6. 最終的な累積合計を出力します。 

### なぜ効果があるのか

 どの頂点が新しいエッジに参加できるかを修正すると、有効な解決策はすべて、同じ 2 つのセット間の並べ替えペアにすぎなくなります。 二乗式を展開すると、目的のペアリングに依存する部分が正確に積 w_u w_v の合計であることがわかります。 並べ替えの不等式により、このような合計を最大化するには、両方のシーケンスを順序付けして直接一致させることが最適です。 グラフの制約により、次数制限を超えてエッジ間の相互作用が発生しないことが保証されるため、追加の構造制約がこの削減を妨げることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    w = list(map(int, input().split()))

    indeg = [0] * n
    outdeg = [0] * n

    for _ in range(m):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        outdeg[a] += 1
        indeg[b] += 1

    out_nodes = []
    in_nodes = []

    for i in range(n):
        if outdeg[i] == 0:
            out_nodes.append(i)
        if indeg[i] == 0:
            in_nodes.append(i)

    out_nodes.sort(key=lambda x: w[x], reverse=True)
    in_nodes.sort(key=lambda x: w[x], reverse=True)

    ans = 0
    for i in range(len(out_nodes)):
        u = out_nodes[i]
        v = in_nodes[i]
        ans += (w[u] + w[v]) * (w[u] + w[v])

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、最初に、初期グラフによって引き起こされる残りの次数容量を抽出します。 重要なステップは、「有効なグラフ」を接続性の構造的な制約ではなく、厳密な容量制約として解釈することです。 その解釈が行われると、コードの残りの部分は、空きエンドポイントの 2 つのリストを作成することになります。 

両方のリストを重みで並べ替えることが、最適化原則が適用されるポイントです。 よくある間違いは、片側だけをソートしたり、ソートせずに貪欲なペアリングを試行したりすることで、最適性が損なわれます。 

最後のループは、二乗寄与を直接計算します。 Python は整数演算を安全に処理し、式をそのまま維持することで項の分割ミスを回避できるため、コード内で正方形を拡張する必要はありません。 

## 実用的な例

 頂点が 3 つあり、最初のエッジがない小さなケースを考えてみましょう。 重みを [1, 3, 2] とします。 この場合、すべての頂点には空きの受信スロットと送信スロットの両方があるため、両方のリストは同一になります。 

| ステップ | アウトリスト | リスト内 | ペアリング | 部分合計 |
 | --- | --- | --- | --- | --- |
 | ビルド後 | [3、2、1] | [3、2、1] | - | 0 |
 | ペア 1 | 3 と 3 | 3 と 3 | (3+3)^2 = 36 | 36 |
 | ペア 2 | 2 と 2 | 2 と 2 | (2+2)^2 = 16 | 52 |
 | ペア 3 | 1 と 1 | 1 と 1 | (1+1)^2 = 4 | 56 |

 これは、並べ替えによって同じ大きさが揃えられ、各積の寄与が最大化されることを示しています。 

ここで、初期エッジからの制約があるケースを考えてみましょう。頂点 1 が 2 を指し、頂点 3 が孤立しており、重み [5, 1, 4] があるとします。 頂点 1 には送信容量がなく、頂点 2 には受信容量がありませんが、頂点 3 には両方の容量があります。 

| 頂点 | w | アウトキャップ | インキャップ |
 | --- | --- | --- | --- |
 | 1 | 5 | 0 | 1 |
 | 2 | 1 | 1 | 0 |
 | 3 | 4 | 1 | 1 |

 したがって、送信リストは [2, 3]、受信リストは [1, 3] です。 重量で並べ替えると、次のようになります。 

| ペア | 貢献 |
 | --- | --- |
 | 3→1 | (4+5)^2 = 81 |
 | 2→3 | (1+4)^2 = 25 |

 合計は 106 となり、元の構造ではなく容量だけがペアリングに影響することがわかります。

## 特殊なケース

 特殊なケースは、頂点が受信フリー セットと送信フリー セットの両方にある場合に発生します。 これは孤立した頂点で発生します。 同じ頂点が両方のリストに出現する可能性があり、ソートによって頂点自体ではなく別の頂点と一貫して一致することが保証されるため、アルゴリズムはこれを自然に処理します。 

もう 1 つのケースは、最初のグラフがすでに単一の有向サイクルを形成している場合です。 すべての頂点の入次数と出力次数の両方が 1 に等しくなります。これは、新しいエッジに使用できる頂点がないことを意味します。 両方のリストは空であり、アルゴリズムはペアリングを試行せずにゼロを返します。 

さらに微妙なケースは、重みが大きく偏っている場合です。たとえば、1 つの頂点が他のすべての頂点と比べて非常に大きな重みを持っている場合です。 ソートにより、この頂点が次に大きい利用可能な頂点とペアになることが保証されます。これはまさに二次相互作用項を最大化し、複数の小さな重みの頂点にわたる最適以下の分散を防ぎます。
