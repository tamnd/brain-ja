 ## 解決策
 ## 問題の理解

 私たちには、道路で結ばれた町の無向グラフが与えられており、そこでウーマイは何度でもエッジを横切ることができ、自由に頂点を再訪することさえできます。 彼は決まった町からスタートする$s$そして目的地に到達したいと思っています$t$。 道路を横断するたびに、歩行距離の合計に長さ 1 が加算されます。 

問題は最短経路を見つけることではなく、すべての可能な経路のパリティ構造についてです。$s$に$t$。 すべての有効なウォークが$s$に$t$全長は均等です。 1 歩でも奇数の長さの歩行があれば、答えは「いいえ」になります。 

グラフは大きくてもよく、$2 \cdot 10^5$したがって、パスを列挙したり、単純なパスをすべて保存したりするアプローチは不可能です。 パリティは頂点に到達したかどうかだけではなく、頂点に到達する方法に依存するため、頂点のみを追跡する単純な BFS であっても不十分です。 

重要な点は、ノードを再訪問するとすべてが変わるということです。 サイクルを含むグラフでは、同じ 2 つのノード間で無限に多くの異なる歩行長が可能になります。 たとえば、から到達可能なサイクルがある場合、$s$へのルート上で$t$、そのサイクルを一周することで、ウォークのパリティを調整できる可能性があります。 

素朴な考えを打ち破る典型的なエッジケースは三角形です。 

入力:```
3 3
1 2
1 3
3 2
2 1
```1 から 2 には、直接 (長さ 1) と経由 3 (長さ 2) の 2 つの異なるウォークがあります。 両方のパリティが存在するため、正解は「いいえ」です。 

もう 1 つの重要なケースは木です。 ツリーには単純なパスが 1 つだけ存在するため、すべてのウォークはそのパスに長さ 2 のバックトラッキング サイクルを加えたものになり、パリティが維持されます。 したがって、ツリーは常に、一意のパスの長さのみに応じて「はい」または「いいえ」を返します。 

最も難しいのは、グラフがどのような場合に固有のパリティを強制するかを特定することです。$s$そして$t$、およびパリティが代替ルートによって反転できる場合。 

## アプローチ

 ブルートフォースアプローチでは、すべての可能なウォークを調査しようとします。$s$に$t$、パスの長さを追跡し、偶数の長さの歩行の横に奇数の長さの歩行が存在するかどうかを確認します。 サイクルのあるグラフではウォークが無限であるため、これはすぐに失敗します。 サイクルは任意に何度も横断することができ、任意に大きなパスのファミリーを生成する可能性があるため、制限された深さに制限しても役に立ちません。 状態空間はエッジの数が指数関数的に増加するため、このアプローチは計算上実行不可能になります。 

より構造化されたビューは、問題をパリティ到達可能性の質問に変換することで得られます。 どの頂点が到達可能かを追跡するだけでなく、頂点からの偶数距離または奇数距離で到達可能かどうかを追跡します。$s$。 これは当然、グラフの複製のアイデアを示唆しています: 各ノード$u$2つの状態に分かれており、$u_0$そして$u_1$、距離の等価性を表します。 すべてのエッジがパリティを反転するので接続します$u_0 \to v_1$そして$u_1 \to v_0$。 

ここで問題は、からの道が存在するかどうかになります。$s_0$に$t_1$。 そのような道が存在する場合、奇数の長さの歩道が存在します。 存在しない場合は、到達可能なすべてのものがそこに進みます。$t$均等でなければなりません。 

ただし、これではまだ問題の要件を完全には捉えていません。 奇数のウォークが存在するかどうかではなく、すべてのウォークが偶数であるかどうかが問われます。 それは次のことを確認するのと同じです。$t_1$からは到達できません$s_0$パリティ拡張グラフ内。 

重要な観察は、拡張されたグラフの構造が接続コンポーネントと二部性のような制約にのみ依存しているということです。 両方のパリティで頂点に到達できる場所で競合が存在する場合、パリティの反転を許可するサイクルが存在します。これは、偶数ウォークと奇数ウォークの両方が存在することを意味します。 したがって、パリティ割り当てが一貫しているかどうかを検出することは、修正された意味で二部性をチェックすることと同等になります。 

各ノードにパリティを割り当てる BFS を効果的に実行します。$s$。 競合するパリティを同じノードに割り当てようとすると、グラフ内のどこかで両方のパリティが存在する可能性があることが検出されます。これは、ノード間に偶数ウォークと奇数ウォークの両方が存在することを意味します。$s$そして$t$。 それ以外の場合、パリティは一貫性があり、固定されます。 

これにより、パリティ追跡を使用したグラフ上の単一の BFS/DFS に問題が軽減されます。

 ## アルゴリズムのチュートリアル

 開始ノードを基準としたパリティ状態で各頂点をモデル化します。$s$。 

1. 配列を初期化する`dist`サイズの$n$値が -1 で、未訪問を意味します。 セット`dist[s] = 0`それ自体までの距離は等しいので。 
2. 以下から開始して BFS を実行します。$s$、頂点のキューを使用します。 エッジを横切るたびに$u \to v$を割り当てようとします`dist[v] = dist[u] XOR 1`。 これは、すべてのエッジがパリティを反転するという事実をエンコードします。 
3. 頂点に到達したら$v$すでに値があり、新しく計算されたパリティが既存のパリティと競合する場合、それを上書きせず、矛盾が存在することを記録します。 
4. BFS が完了したら、次のことを確認します。$t$パリティが割り当てられているかどうか、矛盾が観察されたかどうかを確認します。 
5. 接続要素のどこかに矛盾が存在する場合$s$の場合、偶数と奇数の両方のウォークが可能です。$s$そして$t$, したがって、「いいえ」を出力します。 
6. それ以外の場合、パリティは固定されます。 もし`dist[t] == 1`の場合、奇数長の構造のみが存在しますが、矛盾が存在しないため、すべてのウォークはパリティを維持します。 もし`dist[t] == 0`、すべての歩数が偶数であるため、「はい」を出力します。 

重要な考え方は、矛盾は、次から到達可能な奇数のサイクルに対応するということです。$s$、接続を変更せずにパリティ反転が可能になります。 

### なぜ効果があるのか

 各 BFS 割り当てでは、接続されているコンポーネントの一貫したパリティ ラベル付けが強制されます。$s$。 コンポーネントが 2 部構成の場合、すべてのエッジで一貫して反対のパリティ割り当てが強制されるため、2 つのノード間のすべてのウォークは同じパリティを持ちます。 コンポーネントが 2 部構成でない場合は、少なくとも 1 つの奇数サイクルが存在し、パリティが反転された同じ頂点にウォークが戻ることができます。 これにより、そのコンポーネント内の任意の 2 つの頂点間で偶数長と奇数長の両方のウォークが可能になります。 したがって、一貫したパリティ ラベリングが存在するということは、まさにすべてが間を行き来する条件となります。$s$そして$t$同じパリティを共有します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, m = map(int, input().split())
    s, t = map(int, input().split())
    s -= 1
    t -= 1

    g = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    dist = [-1] * n
    q = deque()
    dist[s] = 0
    q.append(s)

    ok = True

    while q:
        u = q.popleft()
        for v in g[u]:
            nd = dist[u] ^ 1
            if dist[v] == -1:
                dist[v] = nd
                q.append(v)
            elif dist[v] != nd:
                ok = False

    if not ok:
        print("No")
        return

    print("Yes")

if __name__ == "__main__":
    solve()
```グラフは標準の隣接リストとして構築されます。 BFS はから始まります$s$そしてパリティレベルを割り当てます。 XOR 演算は重要な実装の詳細であり、余分な状態構造を使用せずにエッジ トラバーサル パリティ フリップをエンコードします。 の`ok`flag は、パリティ矛盾が発生するかどうかを追跡します。これは、連結成分内の奇数サイクルの検出に対応します。 

最終的な決定は、パリティの割り当てが一貫しているかどうかに完全に依存します。 そうすれば、全員がその間を歩きます$s$そして$t$これは、この定式化では、偶数と奇数の両方の代替を構築する方法が存在しないことを意味します。

 ## 特殊なケース

 重要なエッジケースは、グラフが単純なパスである場合です。 その状況では、BFS は矛盾なく交互パリティをきれいに割り当てます。 例えば：```
4 3
1 4
1 2
2 3
3 4
```トラバーサルでは 1→0、2→1、3→0、4→1 が割り当てられます。 競合は発生しないため、すべてのウォークにわたってパリティが固定されます。 サイクルがないため、代替パリティ パスは存在しません。 

別のケースは、から到達可能な奇数サイクルを含むグラフです。$s$しかし、必ずしも最短距離にあるわけではありません。$t$。 たとえ$t$がサイクルの外側にある場合、サイクルによりパリティが反転された以前のノードに戻ることができ、最終的に到達可能な構造に矛盾が伝播します。 これにより、サイクルが直接実行されていない場合でも、アルゴリズムが一貫性のないフラグを立て続けることが保証されます。$s \to t$ルート。 

最後の微妙なケースは次のような場合です。$s$等しい$t$。 この問題はそれらが異なることを保証しますが、それらが等しい場合、空のウォークの長さはゼロであり、どのサイクルも追加の無関係な代替手段を導入するだけであるため、答えは常に「はい」になります。
