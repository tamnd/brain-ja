 ## 解決策
 ## 問題の理解

 アップロードされた写真の寸法、身長が与えられます。`h`と幅`w`。 そこから小さな長方形を切り出したいと思います。 カットされた長方形は 3 つの条件を満たしている必要があります。 

まず、その次元は整数でなければなりません。 

次に、アスペクト比が許容範囲内に収まっている必要があります。$0.8 \leq \frac{H}{W} \leq 1.25$第三に、長方形の少なくとも 1 つの辺が正確な 2 の累乗でなければなりません。 

すべての有効な長方形の中で、面積が最も大きい長方形を選択します。 複数の長方形の面積が同じ場合、高さの大きい長方形が優先されます。 

元の写真の大きさは次のとおりです。`10^9 × 10^9`。 これにより、考えられるすべての高さと幅を反復するアプローチは即座に除外されます。 寸法に対する二重ループには、次のようなものが必要になります。`10^18`最悪の場合に備えてチェックしますが、これは完全に不可能です。 可能なすべての高さを反復処理するだけでも、すでに遅すぎます。 

制約から得られる重要な観察は、2 のべき乗が指数関数的に増加するということです。 まで`10^9`、2 のべき乗は約 31 種類しかありません。 この小さな検索スペースにより、問題は対処可能になります。 

不注意な実装を黙って破壊する可能性のあるエッジケースがいくつかあります。 

次の入力を考えてみましょう。```
2 1
```元画像の比率は`2`、これは許容範囲外です。 全体像を保持することはできません。 最も有効な長方形は次のとおりです。`1 × 1`。 常に片側を変更しないという貪欲なアプローチは、ここでは失敗します。 

考慮する：```
100 3
```高さに比べて幅が極端に小さいです。 高さを 2 の累乗に強制すると、ほとんどの選択で無効な比率が生成されます。 最適な答えは、元の寸法によって直接制約されるのではなく、比率要件によって制約されます。 

もう 1 つの注意が必要なケースは、複数の長方形の面積が同じである場合です。 例えば：```
8 10
```両方`8 × 8`そして`4 × 10`面積がある`64`そして`40`それぞれ大きいため、面積が大きい方が優先されます。 ただし、面積が等しい場合もあり、その場合は高さの大きい長方形を選択しなければなりません。 このタイブレーク ルールを怠ると、隠しテストで間違った答えが生成されます。 

もう 1 つの微妙な問題は、整数の除算に起因します。 比率の範囲は包括的であり、浮動小数点比較では精度の問題が発生する可能性があります。 次のような不等式を使用すると、$4H \geq 5W \quad \text{and} \quad 5H \leq 4W$精度を完全に回避します。 

## アプローチ

 ブルートフォースのアイデアは単純です。 可能なすべての長方形を試します`(H, W)`そのような`1 ≤ H ≤ h`そして`1 ≤ W ≤ w`。 各長方形について、比率が有効であるかどうか、および少なくとも 1 つの辺が 2 の累乗であるかどうかを確認します。 すべての有効な候補のうち、面積が最大のものを保持します。 

検索は網羅的であるため、これは論理的に機能します。 考えられるすべてのカットが検査されるため、最高のものを逃すことはできません。 

問題は規模だ。 両方の次元が次の場合`10^9`、長方形の数はおよそ`10^18`。 高さを超える単一ループに減らしても、最大 10 億回の反復が残り、2 秒に収まる反復をはるかに超えます。 

2 のべき乗条件の構造はすべてを変えます。 任意の次元の代わりに、少なくとも 1 つの辺が極小セットに属している必要があります。```
1, 2, 4, 8, 16, ...
```まで`10^9`、そのような数字は 31 個しかありません。 

つまり、考えられるすべての 2 のべき乗の辺を反復処理して、互換性のある最大の反対側を直接導出できるということです。 

高さを固定するとします`H`2 のべき乗として。 その場合、幅は次の条件を満たす必要があります。$0.8 \leq \frac{H}{W} \leq 1.25$並べ替えると次のようになります。$\frac{4H}{5} \leq W \leq \frac{5H}{4}$この固定高さの領域を最大化するには、その範囲内および元の画像の境界内で可能な最大の幅が必要であることは明らかです。 

幅を 2 ​​の累乗に固定して同じプロセスを繰り返します。 

検索全体で約 62 個の候補のみが検査されるようになり、事実上一定時間になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(h × w) | お(1) | 遅すぎる |
 | 最適 | O(log(max(h, w))) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 以下の 2 の累乗をすべて生成します。`max(h, w)`。 

2 のべき乗は指数関数的に増加するため、そのような値は約 31 個しかありません。 
2. 2 の累乗をそれぞれ可能な高さとして扱います。 

この固定高さを`ph`。 
3. 比率条件で許可される最大幅を計算します。 

から$\frac{ph}{W} \geq 0.8$得られるもの:$W \leq \frac{5ph}{4}$したがって、実現可能な最大幅は次のようになります。```
min(w, floor(5 * ph / 4))
```4. この幅が比率の下限も満たしていることを確認します。 

必要なものは次のとおりです。$\frac{ph}{W} \leq 1.25$これは次のようになります。$4ph \leq 5W$条件が満たされない場合、この固定高さに有効な四角形は存在しません。 
5. 面積を計算し、最良の回答を更新します。 

まず面積を最大化します。 面積が等しい場合は、高さの大きい長方形が優先されます。 
6. 幅を 2 ​​の累乗に固定して、同じプロセスを繰り返します。 

この対称パスにより、幅のみが 2 の累乗であるケースを見逃さないことが保証されます。 

### なぜ効果があるのか

 固定の 2 のべき乗の高さの場合、すべての有効な四角形は連続した間隔内に幅を持ちます。 エリアなので、`height × width`、高さが固定されている場合、面積は幅とともに単調増加します。 つまり、この高さの最適な選択は常に実現可能な最大幅であるということです。 

幅を固定する場合も同じ引数が適用されます。 

すべての有効な四角形は少なくとも 1 つの辺が 2 の累乗に等しい必要があるため、アルゴリズムは有効な四角形の考えられるすべてのクラスをチェックします。 各クラス内で最適な領域が選択されます。 すべてのクラスの中で、全体最適を維持します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def better(h1, w1, h2, w2):
    a1 = h1 * w1
    a2 = h2 * w2

    if a1 != a2:
        return a1 > a2

    return h1 > h2

def solve():
    h, w = map(int, input().split())

    best_h = 1
    best_w = 1

    p = 1
    while p <= max(h, w):
        # Fix height = p
        if p <= h:
            max_w = min(w, (5 * p) // 4)

            if 4 * p <= 5 * max_w:
                if better(p, max_w, best_h, best_w):
                    best_h = p
                    best_w = max_w

        # Fix width = p
        if p <= w:
            max_h = min(h, (5 * p) // 4)

            if 4 * max_h >= 5 * p:
                if better(max_h, p, best_h, best_w):
                    best_h = max_h
                    best_w = p

        p *= 2

    print(best_h, best_w)

solve()
```ヘルパー関数`better`比較ロジックを一元化します。 この問題では、最初に最大面積、次に最大高さという 2 つの基準を使用するため、このロジックを 1 か所に保持することで条件の重複を回避できます。 

ループは、2 の乗算を繰り返して 2 の累乗を繰り返します。丸めの問題がないため、対数や浮動小数点演算を使用するよりもはるかに安全です。 

高さを固定した場合`p`では、元の画像と比率制約の両方で許容される最大の幅を選択します。 面積は幅とともに増加するため、より小さな幅をテストする理由はありません。 

比率チェックでは整数演算のみが使用されます。$4H \leq 5W \quad \text{and} \quad 4H \geq 5W$これにより、境界付近での浮動小数点精度のバグが回避されます。`0.8`そして`1.25`。 

アルゴリズムは対称的です。 1 つのパスでは高さを 2 の累乗として固定し、もう 1 つのパスでは幅を固定します。 どちらかの半分が欠けていると、有効な最適な長方形が失われます。

 ## 特殊なケース

 次の入力を考えてみましょう。```
2 1
```アルゴリズムは力をテストします`1`そして`2`。 

のために`p = 2`高さと同様に、候補長方形は次のようになります。`(2, 1)`。 比率チェック:$4 \cdot 2 \leq 5 \cdot 1$失敗する理由`8 ≤ 5`は誤りです。 長方形は正しく拒否されます。 

残りの有効な候補は`(1, 1)`、それが答えになります。 

次に、次のことを考えてみましょう。```
100 3
```試しています`p = 64`高さにより最大幅が生成されます。```
floor(5 × 64 / 4) = 80
```ただし、実際の画像の幅は`3`, したがって、候補の幅は次のようになります。`3`。 長方形の高さが依然として高すぎるため、比率条件はすぐに失敗します。 

最終的にアルゴリズムは次の段階に到達します。`p = 2`そして`p = 1`ですが、最も有効な長方形は次のようになります。`(3, 3)`固定幅から`3`。 正方形はすべての条件を満たし、面積を最大化します。 

最後に、タイブレークの場合を考えてみましょう。```
10 13
```アルゴリズムは両方を見つけます`(8, 10)`そして`(10, 8)`、それぞれ面積付き`80`。 

比較関数は、最初に面積をチェックし、次に高さをチェックします。 エリアが一致しているので、`(10, 8)`高さがあるから勝つ`10`よりも大きいです`8`。 これは問題の要件と正確に一致します。
