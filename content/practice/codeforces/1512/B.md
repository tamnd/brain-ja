 ## 解決策
 ## 問題の理解

 正方形のグリッドが与えられており、ちょうど 2 つのセルがすでに星印でマークされています。 これら 2 つの星が最初の唯一の情報であり、グリッド上の部分的な幾何学的形状を定義します。 私たちの仕事は、4 つの星が軸に沿った長方形の頂点になるように、正確に 2 つの追加の星を配置することです。 

私たちが構築する長方形は、その辺がグリッド線に平行でなければなりません。つまり、その角は純粋に 2 行 2 列を選択することによって決定されます。 重要な制約は、既存の 2 つの星がこの長方形の一部でなければならないということです。結果として得られる形状がグリッド境界内の有効な長方形である限り、他の 2 つの角は自由に選択できます。 

出力は、欠落している 2 つの星を追加した後の最終グリッドです。 私たちは何かを最適化したり、可能性を数えたりすることを求められるのではなく、有効な完了を生成することだけを求められます。 

制約は十分小さいため、テスト ケースごとにグリッドを直接線形スキャンするだけでも十分です。 すべてのテスト ケースにわたるセルの総数は次元合計で最大 400 であるため、テスト ケースごとに O(n²) のアプローチを使用すれば十分に高速になります。 これは、単純なグリッド処理よりも複雑なものを即座に除外し、解決策は検索ではなく直接座標推論に依存する必要があることを示唆しています。 

指定された 2 つの星が同じ行または同じ列に並んでいる場合、微妙な特殊なケースが発生します。 このような場合、長方形は、別の行または列を選択して 1 つの次元を拡張する必要がある状況に陥ります。 等価性を処理せずに常に個別の行と列を想定する単純なアプローチは、ここでは失敗します。 

たとえば、両方の星が同じ行にある場合 (位置 (1, 1) と (1, 4) など)、長方形は別の行を使用する必要があり、欠けている星はその直下に配置されます。 同様に、両方の星が列を共有する場合、長方形は水平に広がります。 

## アプローチ

 この問題を考える強引な方法は、長方形を定義できるすべての行と列のペアを試し、指定された星がその 2 つの角として機能できるかどうかを確認することです。 候補となる各長方形について、その角が制約に一致するかどうかを検証し、見つかったら有効な構成を出力します。 これが機能するのは、軸に揃えられた四角形は、2 つの異なる行と 2 つの異なる列を選択することによって完全に決定されるためです。 

ただし、このアプローチは、グリッドが小さいにもかかわらず、概念的に不必要に高価になります。 さらに重要なのは、問題の構造が隠蔽されてしまうことです。 指定された 2 つの星はすでに 2 つの座標を固定しており、長方形はそれらの座標に揃える必要があります。 つまり、正しい長方形はグローバルに検索するものではなく、星の位置によって直接暗示されるものです。 

重要な観察は、長方形が x 座標と y 座標を個別にペアにすることによって定義されるということです。 2 つの星が (r1, c1) と (r2, c2) にある場合、r1 が r2 に等しいか、c1 が c2 に等しい場合を除き、欠けている角は (r1, c2) と (r2, c1) でなければなりません。 このような縮退の場合には、同じ構造を維持しながら新しい行または列を導入します。 

これにより、問題は、組み合わせ検索ではなく、単純な座標処理に軽減されます。

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。

1. まず、グリッドをスキャンして、既存の 2 つの星の座標を見つけます。 それらを (r1, c1) および (r2, c2) として保存します。 入力は座標ベースではなく位置であるため、このステップが必要です。 
2. 2 つの星が異なる行および異なる列にあるかどうかを確認します。 行と列の両方が異なる場合、長方形の対角線はすでに得られています。 この場合、長方形は行と列のペアを独立して保持するため、欠けている角は当然 (r1, c2) と (r2, c1) になります。 
3. 星が同じ行を共有している場合、列だけを交換して長方形を形成することはできません。これは、直線に崩れてしまうためです。 代わりに、別の行を選択します。 共有行が 0 でない場合は安全に行 0 を選択できますが、それ以外の場合は行 1 を選択します。次に、(new_row, c1) と (new_row, c2) に星を配置して、垂直方向に長方形を完成させます。 
4. 星が同じ列を共有する場合、対称の考え方を適用します。 別の列 (通常は可能であれば 0、それ以外の場合は 1) を選択し、(r1, new_col) と (r2, new_col) に星を配置します。 
5. 最後に、変更したグリッドを出力します。 

ステップ 3 と 4 での重要な決定は、共有次元に直交する新しい座標を意図的に導入することです。 これにより、n が少なくとも 2 であるため、境界内に留まりながら有効な四角形が保証されます。 

### なぜ効果があるのか

 正確さは、軸に揃えられた四角形が行と列の次元で独立して決定されるという事実から得られます。 両方の座標が異なる場合、長方形は端点のペアによって一意に形成されます。 1 つの座標が同一の場合、長方形は欠落している次元内に拡張する必要があり、n ≥ 2 であるため、常に少なくとも 1 つの代替インデックスが存在します。これにより、境界に違反したり構造制約を上書きしたりすることなく、有効な長方形を完成させる 2 つの新しいコーナーを常に構築できることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    g = [list(input().strip()) for _ in range(n)]

    stars = []
    for i in range(n):
        for j in range(n):
            if g[i][j] == '*':
                stars.append((i, j))

    (r1, c1), (r2, c2) = stars

    if r1 != r2 and c1 != c2:
        g[r1][c2] = '*'
        g[r2][c1] = '*'
    elif r1 == r2:
        nr = 0 if r1 != 0 else 1
        g[nr][c1] = '*'
        g[nr][c2] = '*'
    else:
        nc = 0 if c1 != 0 else 1
        g[r1][nc] = '*'
        g[r2][nc] = '*'

    for row in g:
        print("".join(row))
```実装は、グリッドを読み取り、2 つの星の位置を抽出することから始まります。 この明示的な抽出は、グリッドを繰り返しスキャンするのではなく、純粋に座標で推論できるため重要です。 

3 ケース構造は、長方形の幾何学形状を直接反映します。 最初のケースは、一般的な対角線の状況を処理します。 2 番目と 3 番目のケースは、行または列に沿って位置合わせが行われる場合の縮退を処理します。 

唯一の微妙な実装の詳細は、有効な代替行または列を選択することです。 n は少なくとも 2 であるため、元の座標を避ける限り、0 または 1 を選択しても常に安全です。

## テストケース```python
import sys, io

def solve():
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        g = [list(input().strip()) for _ in range(n)]

        stars = []
        for i in range(n):
            for j in range(n):
                if g[i][j] == '*':
                    stars.append((i, j))

        (r1, c1), (r2, c2) = stars

        if r1 != r2 and c1 != c2:
            g[r1][c2] = '*'
            g[r2][c1] = '*'
        elif r1 == r2:
            nr = 0 if r1 != 0 else 1
            g[nr][c1] = '*'
            g[nr][c2] = '*'
        else:
            nc = 0 if c1 != 0 else 1
            g[r1][nc] = '*'
            g[r2][nc] = '*'

        for row in g:
            out.append("".join(row))

    print("\n".join(out))

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    solve()
    return sys.stdout.getvalue()

 ## 特殊なケース

 両方の星が既に 1 列に並んでいる場合、構築では欠けている角に同じ列を再利用することを避ける必要があります。 アルゴリズムは明示的に別の行に切り替えます。グリッドには少なくとも 2 つの行があるため、存在することが保証されます。 これにより、長方形が線に崩れてしまうことがなくなります。 

両方の星が列を共有する場合、同じロジックが対称的に適用されます。 他の列を選択するだけで十分であり、インデックス 0 と 1 の間で単純に選択するだけで、検索を行わなくても正確さが保証されます。 

すべての場合において、各軸が独立して処理されるため、生成された座標は境界内に残り、四角形のプロパティが維持されます。
