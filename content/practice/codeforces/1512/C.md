 ## 解決策
 ## 問題の理解

 文字「0」、「1」、「?」と 2 つの整数で構成される文字列が与えられます。`a`そして`b`最終的な文字列に含める必要がある「0」と「1」の合計数を表します。 タスクは、すべての「?」を置き換えることです。 カウントを正確に一致させながら文字列が回文になるように、「0」または「1」を使用します。`a`そして`b`。 回文では、文字列が前方と後方で同じように読める必要があるため、位置にあるすべての文字が`i`位置の文字と一致する必要があります`n-i-1`。 

この問題は、回文プロパティの維持と、「0」と「1」の正確な数の一致という 2 つの制約を同時に組み合わせています。 文字列の長さはすべてのテスト ケースで最大 200,000 に達する可能性があり、テスト ケースの数は 10,000 に達する可能性があります。 これは、二次または総当たりアプローチではあまりにも多くの操作が必要となるため、ソリューションは文字列ごとに線形時間で実行する必要があることを意味します。 

競合する固定文字がある場合、微妙なエッジケースが存在します (例: インデックスの「0」)`i`インデックスに「1」`n-i-1`)、または「0」または「1」の残りの数が「?」を満たすことができない場合 交換品。 もう 1 つの注意が必要なケースは、中央の文字が「?」である奇数の長さの文字列です。 アルゴリズムは、中央の文字が残りのカウントと一貫して割り当てられることを保証する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、「?」の可能な置換をすべて列挙します。 「0」または「1」を使用して、各候補の回文プロパティを確認し、正確さを数えます。 このアプローチは原理的には正しいですが、各「?」が発生するため実行不可能になります。 可能性の数が 2 倍になり、「?」の数が指数関数的に複雑になります。 2*10^5 までの長さの文字列の場合、これは不可能です。 

重要な洞察は、すべての組み合わせを試す必要はないということです。 回文制約を使用すると、ミラーリングされた位置全体に既知の値を伝播させ、「?」の数を減らすことができます。 埋めるために。 具体的には、`s[i]`は '？' しかし`s[n-i-1]`が「0」の場合は置き換える必要があります`s[i]`「0」が付いています。 この伝播の後、カウントされているかどうかを確認できます。`a`そして`b`まだ達成可能です。 次に、残りの「?」のペアに対して、ミラーリングされた位置に「0」または「1」を貪欲に割り当て、残りのカウントを使い切ることができます。 文字列の長さが奇数の場合、使用可能なカウントがまだあれば、中央の文字が '?' であれば独立して割り当てることができます。 

このアプローチは、各位置が最大 2 回訪問されるため、線形です。1 回は伝播のため、もう 1 回は残りの「?」を埋めるためです。 競合とカウント不足はペアごとに一定時間でチェックされます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 文字列を可変操作用の文字リストに変換します。 残りの「0」と「1」のカウンターを初期化します。`a`そして`b`、文字列内の既存の「0」と「1」の数を減算します。 
2. 既知の文字をミラーリングされた位置に伝播します。 インデックスごとに`i`文字列の前半にある場合、`s[i]`は '？' そして`s[n-i-1]`そうではありません、交換してください`s[i]`と`s[n-i-1]`そして適切なカウンタをデクリメントします。 両方の位置が固定されており等しくない場合、出力`-1`解決策としては不可能です。 
3. 伝播後、カウンタが負になっているかどうかを確認します。 ある場合は出力します`-1`必要な数を満たせないためです。 
4. 残りの「?」のペアを埋めます。 文字列の前半。 各ペアごとに`(i, n-i-1)`それは両方とも「?」であり、少なくとも 2 つのゼロが残っている場合は「0」を割り当て、それ以外の場合は少なくとも 2 つの 1 が残っている場合は「1」を割​​り当てます。 それに応じてカウンターを更新します。 どちらも不可能な場合は、出力します`-1`。 
5. 文字列長が奇数の場合は、中央の文字を別個に扱います。 「?」の場合、ゼロが 1 つ残っていれば「0」、1 が 1 つ残っていれば「1」を代入します。 利用可能なカウントがない場合は、出力します。`-1`。 
6. すべての位置を埋めると、0 と 1 のカウンタは正確に 0 になるはずです。 そうでない場合は出力`-1`。 それ以外の場合は、リストを結合して文字列に戻し、出力します。 

機能する理由: このアルゴリズムは、各伝播および充填ステップの後でも、現在の部分文字列をカウントを満たす回文に完成できるという不変条件を維持します。 競合は即座に検出され、無効なソリューションが回避されます。 残りの「?」に対する貪欲な割り当て 競合が解決され、合計数が追跡されると、任意のペアを独立して割り当てることができるため、機能します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a, b = map(int, input().split())
        s = list(input().strip())
        n = len(s)
        possible = True

        # Step 1: initial count deduction
        a -= s.count('0')
        b -= s.count('1')

        # Step 2: propagate known characters
        for i in range(n // 2):
            j = n - i - 1
            if s[i] == '?' and s[j] != '?':
                s[i] = s[j]
                if s[i] == '0': a -= 1
                else: b -= 1
            elif s[i] != '?' and s[j] == '?':
                s[j] = s[i]
                if s[j] == '0': a -= 1
                else: b -= 1
            elif s[i] != '?' and s[j] != '?' and s[i] != s[j]:
                possible = False
                break

        if a < 0 or b < 0:
            possible = False

        # Step 3: fill remaining '?'
        for i in range(n // 2):
            j = n - i - 1
            if s[i] == '?' and s[j] == '?':
                if a >= 2:
                    s[i] = s[j] = '0'
                    a -= 2
                elif b >= 2:
                    s[i] = s[j] = '1'
                    b -= 2
                else:
                    possible = False
                    break

        # Step 4: handle middle character if odd length
        if n % 2 == 1 and s[n // 2] == '?':
            if a > 0:
                s[n // 2] = '0'
                a -= 1
            elif b > 0:
                s[n // 2] = '1'
                b -= 1
            else:
                possible = False

        if possible and a == 0 and b == 0:
            print("".join(s))
        else:
            print(-1)

if __name__ == "__main__":
    solve()
```この解決策では、最初に固定文字を考慮して、残りの 0 と 1 の数を減らします。 次に、ミラーリングされた値を伝播して「?」を解決します。 決定論的に。 残りの「?」のペア これは、回文の対称性により両方の位置を同時に割り当てることができるため、機能します。 最後に、必要に応じて中央の文字が個別に処理されます。 競合またはカウント違反があると、ただちに次のような結果が生じます。`-1`。
