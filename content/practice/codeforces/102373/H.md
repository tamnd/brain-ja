 ## 問題の理解

 グリッドは、頂点がすべて非壁セルであり、セル間のエッジが辺を共有しているグラフです。 友達はから始まります`s`そして到達する必要がある`f`。 

水平方向に移動するたびに温度が変化します`-1`、移動が左に進むか右に進むかに関係なく。 垂直方向に移動するたびに次のように変化します`+1`、移動が上昇するか下降するかに関係なく。 したがって、以下を含む散歩のために、`H`水平移動と`V`垂直方向に移動すると、最終温度は初期温度と異なります。 

[
 V-H.
 】

 友達はセルとエッジを任意に何度でも再訪問する可能性があります。 可能な限り最小の値が必要です

 [
 |V-H|。 
]

もし`f`からは到達できません`s`、答えは`-1`。 

グリッドには最大 (10^6) 個のセルを含めることができます。 これにより、考えられるすべての経路長または温度値に対して大きな状態を保存するものは即座に除外されます。 各セルと各ローカル隣接関係を一定の回数だけ検査する必要があり、(O(nm)) の目標を与えます。 到達可能なセルが (O(nm)) しかないため、線形メモリを使用したトラバーサルも自然に適合します。 

一見合理的と思われるショートカットが間違った結果をもたらすケースがいくつかあります。

## アプローチ

 直接的な総当たりアプローチでは、次からのウォークが列挙されます。`s`蓄積された温度変化を追跡します。 考えられるすべての歩行が 1 つの考えられる最終温度に対応するため、これは概念的には正しいです。 問題は、ウォークがセルを再訪問する可能性があるため、無限に多くのウォークが存在することです。 検索を最大 (L) の長さの歩行に人為的に制限したとしても、グリッド頂点は各ステップで最大 4 つの選択肢を持つことができ、最悪の場合には (O(4^L)) 個の候補歩行が得られます。 有効な最適なウォークには意図的に繰り返しが含まれる可能性があるため、(L) を大きくしても問題はきれいに解決されません。 

単純なパスのみを列挙しようとすることは、有効な置き換えではありません。 このステートメントでは、セルの再訪問を明示的に許可しており、これらの繰り返しにより、まさに温度変化を補正することができます。 

重要な観察は、1 つのエッジを 2 回横断することによって得られます。 エッジが水平の場合、エッジを横切ってすぐに戻ってくるとコストがかかります`-2`。 エッジが垂直の場合、エッジを横切ってすぐに戻ってくるとコストがかかります`+2`。 友人は有効な散歩のどこにでもそのような往復を挿入できるため、水平エッジの存在により合計を次のように減らすことができます。`2`必要に応じていつでも、垂直エッジの存在により合計を増やすことができます。`2`いつでも好きなときに。 

連結コンポーネントに次のものが含まれているとします。`s`そして`f`水平エッジと垂直エッジの両方があります。 どれからでも始めてください`s`に`f`温度変化が(W)となるパス。 水平往復を繰り返し挿入することで (W) を (W-2k) に置き換えることができ、垂直往復を繰り返し挿入することで (W+2k) に置き換えることができます。 したがって、(W) と同じパリティを持つすべての整数が実現可能です。 

(W) のパリティは特に単純です。 移動するたびにパスの長さが 1 ずつ変化し、

 [
 V-H=(V+H)-2H。 
】

 したがって、(V-H) は総手数と同じパリティを持ちます。 からのすべてのパス`s`に`f`グリッド座標のパリティを変更するには 1 回の移動が必要なため、同じ長さのパリティを持ちます。 したがって、両方のエッジ タイプが存在する場合、答えは次のようになります。`0`均一なパス長の場合、`1`奇数のパス長の場合。 

特殊なケースが 1 つあります。 コンポーネントに水平エッジのみが含まれている場合、考えられるすべての歩行には水平方向の移動のみが含まれるため、その温度変化はまさにその長さのマイナスになります。 次に、最小の絶対値が次の最短経路によって取得されます。`s`に`f`。 温度変化が正の経路長であることを除いて、コンポーネントに垂直エッジのみが含まれる場合にも同じ推論が当てはまります。 

単一の BFS で必要なものがすべて提供されます。 への最短距離を見つけます`f`、どうかを決定します。`f`に到達可能であり、コンポーネントをトラバースしているときに、少なくとも 1 つの水平エッジと少なくとも 1 つの垂直エッジが存在するかどうかがわかります。

 ## アルゴリズムのチュートリアル

 1. グリッドを読み取り、開始セルを見つけます。`s`そしてセルを出る`f`。 を除くすべての文字を扱います`#`横断可能として。 
2.BFS を実行します。`s`。 ～からの最短距離を保存する`s`訪問したすべてのセルに。 すべてのグリッドの移動には単位長があるため、BFS が適切です。そのため、最初にセルに到達すると最短のパス長が得られます。 
3. セルとその到達可能な隣接セルをそれぞれ検査しながら、対応するエッジを分類します。 行が変更されると、コンポーネントには垂直エッジが含まれます。 列が変更されると、その列には水平エッジが含まれます。 必要なのは 2 つのブール値フラグだけです。 
4. もし`f`決して訪問されなかった、出力`-1`。 友達は出口に全くたどり着けない。 
5. コンポーネントに水平エッジと垂直エッジの両方が含まれる場合、出力`dist[f] % 2`。 最短経路長は、考えられるすべての温度変化のパリティと、変化の両方の兆候を決定します。`2`エッジラウンドトリップを通じて利用可能です。 したがって、偶数パリティでは正確なキャンセルが可能ですが、奇数パリティでは絶対差が最小限に抑えられます。`1`。 
6. コンポーネントに水平エッジのみがある場合、出力`dist[f]`。 可能なすべての歩行では、その長さのマイナスに等しい温度変化が発生するため、最短経路が最適です。 
7. コンポーネントに垂直エッジのみがある場合、出力`dist[f]`同じように。 可能なすべての歩行にはその長さに等しい温度変化があるため、やはり最短経路が最適です。 

### なぜ効果があるのか

 中心的な不変条件は、水平エッジを往復挿入すると温度が正確に変化するということです。`-2`、垂直エッジの往復を挿入すると、正確に変更されます`+2`。 両方のエッジ タイプが接続コンポーネントで発生する場合、ウォークの温度変化は偶数の整数だけシフトされる可能性があります。 温度変化 (V-H) は移動数と同じパリティを持ち、すべての動きのパリティは同じであるため、パリティは変更できません。`s`に`f`walk には同じエンドポイント パリティがあります。 したがって、ゼロに最も近い達成可能な値は正確に次のようになります。`0`偶数パリティの場合と`1`奇数パリティの場合。 

エッジ タイプが 1 つだけ存在する場合、すべてのウォークには温度変化の固定符号があり、その大きさはその長さに等しくなります。 したがって、最短経路は絶対温度差を最小限に抑えます。 BFS はその最短の長さを正確に計算します。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    start = None
    finish = None

    for r in range(n):
        for c in range(m):
            if grid[r][c] == 's':
                start = (r, c)
            elif grid[r][c] == 'f':
                finish = (r, c)

    sr, sc = start
    fr, fc = finish

    dist = [[-1] * m for _ in range(n)]
    dist[sr][sc] = 0

    q = deque([(sr, sc)])

    has_horizontal = False
    has_vertical = False

    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    while q:
        r, c = q.popleft()

        for dr, dc in directions:
            nr = r + dr
            nc = c + dc

            if nr < 0 or nr >= n or nc < 0 or nc >= m:
                continue
            if grid[nr][nc] == '#':
                continue

            if dr == 0:
                has_horizontal = True
            else:
                has_vertical = True

            if dist[nr][nc] != -1:
                continue

            dist[nr][nc] = dist[r][c] + 1
            q.append((nr, nc))

    d = dist[fr][fc]

    if d == -1:
        print(-1)
        return

    if has_horizontal and has_vertical:
        print(d & 1)
    else:
        print(d)

if __name__ == "__main__":
    solve()
```グリッドは文字列のリストとして保存されるため、セルが壁であるかどうかを確認するのは定数時間の操作です。 2 つの特別なセルは最初のスキャンで検出されます。 

BFS 距離配列は次を使用します。`-1`未訪問のセルについては、`0`まずは。 あらゆる法的措置には 1 つのステップが必要となるため、`dist[f]`出口に到達できる場合の最短経路長です。 

エッジ タイプ フラグは、有効な壁以外の隣接エッジに対してのみ更新されます。 水平方向の隣接性は次のように検出されます。`dr == 0`、一方、垂直方向の隣接関係には`dr != 0`。 両方のエンドポイントから同じエッジに遭遇する可能性がありますが、ブール値を 2 回設定しても効果はありません。 

境界チェックは、グリッドにインデックスを付ける前に実行する必要があります。 これにより、グリッド BFS で特に発生しやすいバグである負の Python インデックスを誤って有効なセルとして扱うことがなくなります。 

Python では整数オーバーフローの問題はありません。 C++ 実装でも、最大最短距離は (O(nm)) のみであるため、標準の整数型で十分です。 

最終的な決定では、そのパスの実際の温度変化ではなく、BFS 距離を意図的に使用します。 両方のエッジ タイプが存在すると、そのパリティのみが問題になります。 1 つのタイプが欠落している場合、距離自体が可能な最小の絶対変化となります。

```最初の水平移動が到達する`f`距離を置いて`1`。 BFS はコンポーネント内の他の場所でも垂直エッジに遭遇するため、両方のフラグが true になります。 アルゴリズムの出力`1 & 1 = 1`。 垂直往復により追加できる可能性があるのは、`+2`、水平方向の往復で追加できる`-2`, しかし、どちらの操作も奇数パリティを変更しないため、ゼロは不可能です。 

切断された場合には、```
1 3

```中央のセルは壁であるため、BFS は開始セルのみを訪問します。`dist[f]`残っている`-1`、アルゴリズムはすぐに出力します`-1`。 存在しないパスに対しては温度計算は試行されません。 

最大サイズの場合、完全に開いた (1000 \times 1000) グリッドには水平エッジと垂直エッジの両方があります。 もし`s`にあります`(0,0)`そして`f`にあります`(999,999)`、最短距離は`1998`、これは偶数です。 したがって、アルゴリズムは次の値を返します。`0`。 最短パス自体が長い場合でも、BFS は最大 100 万個のセルのそれぞれを 1 回だけ処理し、(O(nm)) 境界を維持します。
