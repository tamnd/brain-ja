 ## 解決策
 ## 問題の理解

 パリティのみで、長さの順序付けされたシーケンスの数をカウントする必要があります。`N`で許可されている値を使用して形成できます。`A`それらの合計が正確になるように`S`。 シーケンス内の位置が異なるため、選択した番号の順序が重要になります。 答えは実際のカウントではなく、そのカウントが奇数か偶数かです。 

難しいのは、`N`そして`S`どちらも次のように大きくすることができます`10^18`したがって、シーケンスの長さにわたって反復するメソッドは不可能です。 まで繰り返しても`S`遅すぎます。 唯一の小さなパラメータは、`K`、許可される値の数。最大 200 です。内の最大値`A`は十分小さいので、出現する可能性のあるさまざまな状態の数を推論するときにも使用できます。 

合計に対する直接的な動的計画法アプローチには、次のようなものが必要です。`N * S`どちらの次元も巨大になる可能性があるため、これは完全に不可能です。 解決策は、答えがモジュロ 2 である必要があるという事実を利用する必要があります。モジュロ 2 を使用すると、フロベニウス恒等式のため、多項式のべき乗が劇的に変化します。$$(f(x))^2 = f(x^2)$$バイナリフィールド上で。 

無視すると実装が壊れる可能性のあるいくつかのエッジケースがあります。 いつ`N = 0`再帰中に出現した場合、答えは次のとおりです。`1`合計のみ`0`空のシーケンスが 1 つだけ存在するためです。 たとえば、還元状態が次の状態に達した場合、`N = 0, S = 3`、正しい結果は次のとおりです`0`一方、不注意な実装では、すべてのビットを処理するため、それが受け入れられる可能性があります。`N`。 

もう 1 つのケースは、次のような番号です。`A`現在の 2 進数のパリティが間違っています。 入力の場合:```
1
1 1
0
```可能な唯一の順序は`[0]`、したがって、答えは次のとおりです`0`。 2 で割る前にパリティをチェックしない遷移では、誤って次の状態が作成されます。`(1 - 0) / 2`無効な合計をカウントする可能性があります。 

3 番目のケースは、モジュロ 2 をキャンセルする重複状態です。次に例を示します。```
1
2 2
1 3
```有効なシーケンスは次のとおりです。`[1,1]`、`[1,3]`、`[3,1]`、 そして`[3,3]`。 最初と最後のものだけが合計 2 または 6 になります。`S = 2`答えは`1`。 異なる選択肢が同じ縮小状態に達する場合、それらの寄与は通常のカウントとして加算するのではなく、XOR 演算する必要があります。 

## アプローチ

 簡単なアプローチは、生成関数を使用することです。$$P(x)=\sum_{a\in A}x^a$$答えは次の係数です。`x^S`で`P(x)^N`。 強引な多項式乗算では、項を繰り返し結合し、到達可能なすべての合計を追跡します。 すべての乗算はシーケンスの要素をもう 1 つ選択することを表すため、これは正しいです。 ただし、次数は次のように大きくなる可能性があります`N * max(A)`、それは周りにあります`10^23`。 到達可能な金額をすべて保存することすら不可能です。 

重要な観察は、すべての算術演算が 2 を法とするという事実から来ています。この分野では、$$P(x)^{2}=P(x^2)$$したがって、のバイナリ表現を見ると、`N`、設定されたすべてのビットは、次の 1 つのコピーを表します。`P(x^{2^i})`。 

同じアイデアを表示するためのより便利な方法は、再帰的削減を使用することです。 もし`N`偶数、すべての指数が寄与する`P(x)^N`は偶数なので奇数です`S`すぐにゼロを返します。 もし`N`均等であり、`S`両方とも偶数です`N`そして`S`2で割ることができます。 

もし`N`奇数です、コピー 1 つ`P(x)`残っています。 私たちは価値を選択します`a`そのコピーによって貢献され、残りの部分が均等なパワーになります。 遷移は次のようになります。$$F(N,S)=\bigoplus_{a\in A,\ a\equiv S\pmod 2}F(\lfloor N/2\rfloor,(S-a)/2)$$残りの課題は州の数です。 ビットを処理します`N`現在のすべての換算された和をそのパリティとともに保存しながら、最下位側から順に計算します。 取り外し後`i`ビットの場合、2 つの可能な状態は、削除された下位ビットで行われた選択によってのみ異なります。 選択された値はすべて最大で`100000`、考えられる差異の間隔には制限があります。 これにより、アクティブな状態の数が管理可能に保たれます。

 | ブルートフォース | 指数関数的`N`、または少なくとも到達可能な合計の数に比例します。 最悪の場合は指数関数的 | 遅すぎる |
 | 最適 |`O(60 * K * M)`どこ`M`は維持される状態の数です |`O(M)`| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 元の合計を含む 1 つの状態から開始します`S`パリティあり`1`。 保存されたパリティは、その削減された合計に到達する方法の数が奇数か偶数かを示します。 
2. の 2 進数を処理します。`N`最下位ビットから上に向かって。 すべてのステップで、繰り返しから 1 を 2 で除算します。 
3. 現在のビットが`N`がゼロの場合、すべての寄与はこのレベルに均等になります。 合計が奇数の状態を削除し、残りの合計をすべて 2 で割ります。 これは、偶数のべき乗のみを含む多項式からは奇数の和を生成できないという事実からわかります。 
4. 現在のビットが`N`が 1 つである場合は、残りの 1 つのコピーを削除します`P(x)`。 アクティブな合計ごとに`s`およびすべての許可された値`a`と同じパリティを持つ`s`、新しい状態を追加します`(s-a)/2`。 すべてのカウントはモジュロ 2 であるため、等しい状態のパリティは XOR と結合されます。 
5. すべての部分を終えて`N`が処理されると、残りの指数はゼロになります。 答えはステートに保存されているパリティです`0`。 

なぜ機能するのか: 処理後`i`のビット`N`、保存されたすべての状態は、残りの未処理の問題の目標合計がその保存された値と同じになるように、処理されたバイナリ位置の値を選択する方法のパリティを正確に表します。 この遷移は、まさに特性 2 の多項式恒等式の 2 つのケースです。 等しい状態は XOR 演算されるため、不変式は各ステップの後でも true のままになります。 最後に、空の多項式累乗を満たすことができるのは、残りのターゲット合計 0 のみであるため、0 に格納されている値が必要な答えとなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(N, S, A):
    states = {S: 1}

    bit = 0
    while N:
        if N & 1:
            nxt = {}
            for s, val in states.items():
                if val == 0:
                    continue
                parity = s & 1
                for a in A:
                    if (a & 1) == parity:
                        ns = (s - a) // 2
                        nxt[ns] = nxt.get(ns, 0) ^ val
            states = {k: v for k, v in nxt.items() if v}
        else:
            nxt = {}
            for s, val in states.items():
                if (s & 1) == 0:
                    ns = s // 2
                    nxt[ns] = nxt.get(ns, 0) ^ val
            states = {k: v for k, v in nxt.items() if v}

        N >>= 1
        bit += 1

        if not states:
            return 0

    return states.get(0, 0)

def main():
    T = int(input())
    ans = []
    for _ in range(T):
        N, S, K = map(int, input().split())
        A = list(map(int, input().split()))
        ans.append(str(solve_case(N, S, A)))
    print("\n".join(ans))

if __name__ == "__main__":
    main()
```辞書`states`最終的な答えに到達できる合計のみを保存します。 演算は XOR であるため、その値は常に 0 または 1 になります。 キャンセルされたパスが今後の遷移に影響を与えなくなるため、ゼロ エントリを削除すると便利です。 

ループは次のバイナリ表現に従います。`N`。 偶数の場合は、除算ステップを直接実行します。 奇妙なケースでは、最下位ビットが現在のターゲット ビットと一致するすべての許可された値が試行されます。 このパリティ チェックが必要なのは、間違った最下位ビットで値を減算すると、2 で除算した後に整数が残らないためです。 

Python の整数は入力サイズを自然に処理するため、オーバーフローの問題はありません。 ループの反復数は最大 60 です。`N`最大 60 の 2 進数を持ちます。

## テストケース```python
import sys
import io

def solve_case(N, S, A):
    states = {S: 1}
    while N:
        nxt = {}
        if N & 1:
            for s, v in states.items():
                for a in A:
                    if (a & 1) == (s & 1):
                        nxt[(s - a) // 2] = nxt.get((s - a) // 2, 0) ^ v
        else:
            for s, v in states.items():
                if s % 2 == 0:
                    nxt[s // 2] = nxt.get(s // 2, 0) ^ v
        states = {k: v for k, v in nxt.items() if v}
        N >>= 1
    return str(states.get(0, 0))

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    T = int(sys.stdin.readline())
    out = []
    for _ in range(T):
        N, S, K = map(int, sys.stdin.readline().split())
        A = list(map(int, sys.stdin.readline().split()))
        out.append(solve_case(N, S, A))
    sys.stdin = old
    return "\n".join(out)

 ## 特殊なケース

 のために`N = 0`すべての削減の後、実装はそれ以上ループを実行せず、状態のみを受け入れます。`0`。 これは空のシーケンス定義と一致し、ゼロ以外の残りがカウントされるのを防ぎます。 

パリティの不一致の場合、奇数遷移は次の場合にのみ状態を作成します。`(s & 1) == (a & 1)`。 たとえば、`N=1`、`S=1`、 そして`A={0}`、現在の状態は`{1:1}`。 唯一の値はパリティ 0 を持つため、次の状態は作成されず、答えは 0 になります。 

重複パスをキャンセルする場合、辞書の更新には XOR が使用されます。 2 つの異なる選択肢が同じ減算和を生成する場合、その状態は 2 回カウントされる代わりに消滅します。 2 を法とするカウントのみが重要であるため、これはまさに必要な動作です。
