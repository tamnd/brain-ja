 ## 解決策
 ## 問題の理解

 2D 平面上の一連の点が与えられ、それぞれがコインを表します。 ヘビは原点から始まり、右と上の 2 方向にのみ移動できます。つまり、どの座標系を選択しても、そのパスに沿って x 座標と y 座標が減少することはありません。 ヘビがコインを訪問すると、それを収集します。単一の有効なパスで収集できるコインの数を最大化したいと考えています。 

ゲームを開始する前に、平面全体を原点を中心に任意の角度で回転させることができます。 回転後、ヘビの動きのルールは回転した軸に固定されたままになります。つまり、ヘビは正の x 方向と正の y 方向にのみ動きます。 

したがって、本当の自由は、座標系を選択し、両方の座標が減少しないシーケンスで訪問できる点の最大数を選択することです。 

入力は、大きさが 10000 で区切られた整数座標を持つ最大 50 個のポイントで構成されます。出力は単一の整数、つまり最適な回転を選択した後に収集できるポイントの最大数です。 

n は最大 50 であるため、およそ O(n^3) または O(n^4) までの解が許容されます。 すべての順列の列挙や連続的な角度シミュレーションを必要とするものは遅すぎます。 

微妙な難点は、回転によって点間の支配関係が変化することです。 ある回転ではある順序で訪問できるポイントのペアは、別の回転では逆の順序で訪問する必要がある場合があります。 たとえば、2 つの点 (1, 0) と (0, 1) は、標準軸の x および y の昇順で両方を取得することはできませんが、45 度回転すると同等になります。 

もう 1 つのエッジ ケースは、選択した方向で複数の点が同一線上にある場合です。 その場合、射影同点が発生し、慎重に処理しない単純な並べ替えでは、有効なシーケンスが誤って破棄されたり、単調性制約が破られたりする可能性があります。 

最後に、回転は連続的であるため、すべての角度を直接試すことはできません。 問題の構造により、探索空間を有限の多くの候補方向に縮小する必要があります。 

## アプローチ

 回転角度を固定すれば問題は標準になります。 すべての点を回転座標系に変換し、x と y の両方が減少しないように順序付けできる最大の点のサブセットが必要になります。 これは、2D 半順序で最長のチェーンを見つけることと同じです。点を x でソートし、次に y で最長の非減少部分列を計算します。 これにより、固定角度に対して O(n^2) の解が得られます。 

強引なアイデアは、円を細かく離散化して多くの角度を試すことです。 角度ごとに、すべての点を回転し、並べ替え、LIS を計算し、最大値を取得します。 これは概念的には正しいです。なぜなら、答えは点の相対的な順序に依存し、順序は 2 つの点の投影順序が入れ替わる場合にのみ変更されるからです。 ただし、一様離散化の問題は、臨界角を見逃す可能性があり、必要なサンプル数に制限がないことです。 

重要な観察は、回転後の x 座標による点の順序が変更されるのは、2 つの点が等しい x 投影を持つ場合のみであるということです。 これは、回転軸が 2 点間のベクトルの差に対して垂直である場合に正確に発生します。 点の各ペアは、順序が入れ替わる境界角度を定義します。 このような 2 つの連続するイベント間では、x によるすべてのポイントのソート順序が固定されるため、LIS の結果は安定します。 

これにより、回転の無限セットが O(n^2) の意味のある間隔に縮小されます。 各間隔から 1 つの代表的な角度をテストし、誘導次数を計算し、その構成で LIS を解くだけで済みます。 

これにより、問題は O(n^2) 回の回転を試行することになり、それぞれのコストは O(n^2 log n) または O(n^2) になります。これは n ≤ 50 の場合には十分です。

 ## アルゴリズムのチュートリアル

 回転の各方向を新しい X 軸を定義するものとして扱います。 すべての角度を反復する代わりに、点のペアから候補方向を生成します。 

1. 個別の点のペアごとに、それらの x 投影が等しくなる方向を計算します。 この方向は、それらの間のベクトルが選択した x 軸に対して垂直になる角度に対応します。 これらの方向は、x による並べ替え順序が変わらない間隔に円を分割します。 
2. それぞれの方向に対して、厳密に間隔内に着地するようにわずかに摂動させます。 これにより、2 つの点が完全に等しい X 投影を持つことがなくなり、並べ替えが安定して決定的になります。 
3. 選択した方向について、新しい軸の単位ベクトルとの内積を使用して、すべての点の回転座標を定義します。 
4. すべての点を回転された x 座標で並べ替えます。 2 つの点が結びつく場合は、意図的に避けた境界でのみ正確な結合が発生するため、任意にまたは y 座標によって結合を解除します。 
5. ソート後、y 座標の最長の非減少サブシーケンスを計算します。 これは、有効なスネーク パスで訪問できる最大のサブセットを表します。これは、x が構築によってすでに増加しており、y が決して減少しないように強制しているためです。 
6. テストされたすべての方向にわたって最大 LIS 値を追跡します。 

x によるソート後にのみ LIS が必要になる理由は、これらの座標内の有効なスネーク パスは x の全体的な順序を尊重する必要があり、その順序内で y も単調でなければならないためです。 

### なぜ効果があるのか

 最適なソリューション、つまり最適なローテーションと訪問コインの最適なセットを修正します。 その構成では、これらの選択された点の x 順序付けは、メジャー ゼロ境界回転の場合を除いて厳密です。 その順序は、投影順序が同一である角度の一定の間隔に対応します。 私たちの構築では、その区間内の少なくとも 1 つの代表的な角度を列挙するため、その区間をテストするときに同じ順序を再構築します。 LIS はその順序に対して最適に計算されるため、同じ数のポイントが回復されます。 これにより、テストされたすべての方向の最大値が全体的な最適値と等しくなることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def lis(seq):
    dp = []
    for x in seq:
        lo, hi = 0, len(dp)
        while lo < hi:
            mid = (lo + hi) // 2
            if dp[mid] <= x:
                lo = mid + 1
            else:
                hi = mid
        if lo == len(dp):
            dp.append(x)
        else:
            dp[lo] = x
    return len(dp)

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]
    
    if n == 0:
        print(0)
        return
    
    # collect candidate directions
    angles = []
    
    for i in range(n):
        x1, y1 = pts[i]
        for j in range(i + 1, n):
            x2, y2 = pts[j]
            dx = x2 - x1
            dy = y2 - y1
            ang = math.atan2(dy, dx)
            angles.append(ang)
            angles.append(ang + math.pi / 2)
    
    # also add some base angles
    angles += [0.0, 0.1, 1.0, 2.0]
    
    ans = 1
    
    for ang in angles:
        ux, uy = math.cos(ang), math.sin(ang)
        vx, vy = -uy, ux
        
        proj = []
        for x, y in pts:
            px = x * ux + y * uy
            py = x * vx + y * vy
            proj.append((px, py))
        
        proj.sort()
        seq = [p[1] for p in proj]
        ans = max(ans, lis(seq))
    
    print(ans)

if __name__ == "__main__":
    solve()
```このソリューションは、角度で定義された単位ベクトル基底を使用して回転座標を構築します。 各角度は、x 軸方向とそれに垂直な y 軸を定義します。 投影後、x 座標による並べ替えにより、ヘビの制約に沿った移動の実現可能性が強化されます。 

y の LIS ステップは標準の忍耐ソート方法を使用して実装され、角度ごとに O(n log n) が保証されます。 コードは、ペアごとのポイント方向から導出された複数の候補角度を保持し、エッジ間隔をカバーするためにいくつかの任意のベース角度も追加します。 

微妙な点は、浮動小数点角度を使用すると、境界ケース付近で数値が不安定になることです。 厳密なコンテストの実装では、通常、有理ベクトルを使用して方向を正規化するか、角度の代わりに傾きを比較します。 ただし、n ≤ 50 の場合、このアプローチは実際には十分に安定しています。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべての点が原点を通る線上にある場合です。 その場合、多くの回転により同一の投影が生成されます。 適切な順序付けの後にすべての点が単調なチェーンに整列するため、テストされたすべての角度で LIS が完全なセットになるソート順序が得られるため、アルゴリズムは引き続き機能します。 

もう 1 つのエッジ ケースは、点が対称である場合です ((1,0)、(-1,0)、(0,1)、(0,-1) などです。 ほとんどの方向では、2 つの点のみをチェーンできます。 回転では 4 つの点すべてを単一の単調象限順序に配置できないため、アルゴリズムはこれを正しく捉えます。 

最後のエッジ ケースは、2 つの点が選択した軸とほぼ同一線上にある場合です。 境界に近い角度では、順序が一貫して入れ替わる浮動精度の問題が発生する可能性があります。 正確なペアの方向から導出された複数の候補角度を使用すると、少なくとも 1 つの安定した区間表現がテストされ、この不安定性が最大の結果に影響を与えるのを防ぎます。
