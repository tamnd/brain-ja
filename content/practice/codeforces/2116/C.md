 ## 解決策
 ## 問題の理解

 正の整数の配列が与えられます。 1 回の操作で 2 つの異なる位置を選択し、1 つの値を 2 つの値の gcd に置き換えます。 

このプロセスは必要に応じて何度でも繰り返すことができます。 目標は、可能な限り最小限の操作を使用しながら、配列内のすべての要素を等しくすることです。 

重要な問題は、それができるかどうかではありません。なぜなら、声明は常にそれができることを保証しているからです。 課題は、最小の操作数を見つけることです。 

制約は異常に小さいです。 すべての配列値は最大 5000 であり、入力全体のすべての配列の長さの合計も最大 5000 です。これは、可能な gcd 値に対する状態を含むアルゴリズムが実行可能であることを直ちに示唆しています。 gcd 値は 5000 を超えることはできないため、値空間における動的プログラミングまたは最短パス スタイルのソリューションが実用的です。 

到達可能な配列の数は指数関数的に増加するため、配列に対するブルート フォース検索は不可能です。 すべての可能性をシミュレートするのではなく、gcd 操作の構造を活用する必要があります。 

簡単に誤った推論につながる可能性のある、明白ではない状況がいくつかあります。 

考慮する：```
3
2 2 2
```答えは`0`。 配列はすでに等しいです。 新しい gcd 値を自動的に構築しようとするソリューションではオーバーカウントが発生します。 

考慮する：```
3
2 4 6
```配列全体の gcd は次のとおりです。`2`、 そして`2`はすでに存在します。 答えは`2`。 

私たちは向きを変えることができます`4`の中へ`2`1回の操作で、`6`の中へ`2`別のところで。 よくある間違いは、gcd 値がすでに存在しているにもかかわらず、最初にそれを「作成」してしまうことです。 

考慮する：```
3
6 10 15
```グローバル gcd は次のとおりです。`1`、ただし等しい要素はありません`1`。 

答えは単純ではありません`n-1 = 2`。 価値を広める前に`1`、まず、`1`どこかで。 この追加コストが問題の中心的な難点です。 

考慮する：```
2
6 10
```グローバル gcd は次のとおりです。`2`、しかしどちらの要素も等しくありません`2`。 

1回の操作で生成できるのは、`2`いずれかの要素から:```
6 -> gcd(6,10)=2
```与える`[2,10]`。 

2 番目の操作が変化します`10`の中へ`2`。 

答えは`2`、 ない`1`。 ターゲット値の生成とそれを伝播することは別のタスクです。 

## アプローチ

 自然な総当たりのアイデアは、各配列構成を状態として扱い、すべての要素が等しくなるまで BFS を実行することです。 

これは正しいです。すべての操作には単位コストがあるため、BFS は操作の最小数を見つけます。 

残念ながら、それは完全に不可能です。 値が小さい場合でも、可能な配列の数は次のように指数関数的に増加します。`n`、各州には`O(n²)`可能な動き。 状態空間はほぼ即座に爆発します。 

より良いものを見つけるには、最終的な配列にどのような値を含める必要があるかを理解する必要があります。 

すべての操作で値が gcd に置き換えられます。 Gcd 操作では数値を減らすことしかできず、増やすことはできません。 そのため、最終的にどこにでも出現できる唯一の値は、配列全体の gcd です。 

させて```
G = gcd(a1, a2, ..., an)
```最終的な配列は次のようになります。```
[G, G, ..., G]
```現在、問題はさらに構造化されています。 

要素がすでに等しいと仮定します`G`。 その後、その要素を「ソース」として使用できます。 他の要素は次のように変換できます。`G`たった 1 回の操作で:```
x -> gcd(x, G) = G
```すでにある場合`cnt`の発生`G`、必要なのは次のものだけです。```
n - cnt
```操作。 

興味深いケースは、等しい要素がない場合です。`G`。 

広める前に`G`、最初に次のオカレンスを 1 つ作成する必要があります。`G`。 

それには何回の操作が必要ですか?

 gcd 操作を 1 つの位置に繰り返し適用すると何が起こるかを観察してください。 いくつかの操作の後、その位置は配列要素の一部のサブセットの gcd になります。 

例えば：```
gcd(a3, a7, a2, a5)
```gcd を 1 か所に繰り返し取り込むことで生成できます。 

したがって、最初の`G`これは、gcd が次の最小のサブセットを見つけることと同じです。`G`。 

サブセットにサイズがある場合`k`、その後、その gcd を生成するには、正確に次のものが必要です`k-1`操作。 

1 部入手後、`G`、まだ必要です`n-1`残りのすべてのポジションを変換するには、さらに操作を行います。 

総費用:```
(k - 1) + (n - 1)
= n + k - 2
```したがって、問題は、gcd が等しい最小のサブセット サイズを見つけることになります。`G`。 

すべての配列値は最大 5000 であるため、gcd 値に対して DP を実行できます。 

させて：```
dp[g] = minimum subset size whose gcd is g
```配列要素を 1 つずつ処理します。 既存の gcd 状態ごとに、現在の要素で新しいサブセットを開始するか、前のサブセットを拡張します。 

可能な gcd 値の数はわずか 5000 であるため、このアプローチは効率的です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 配列状態に対するブルート フォース | 指数 | 指数 | 遅すぎる |
 | GCD 値の DP | O(n · V) ここで、V=5000 | O(V) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グローバル gcd を計算します。`G`配列全体の。 
2. すでに等しい要素の数を数えます。`G`。 
3. このカウントが正の場合は、戻り値を返します。`n - count`。 

残りの要素はすべて次のように変換できます。`G`既存のオカレンスを使用した 1 回の操作で`G`。 
4. それ以外の場合は、gcd が等しい最小サブセット サイズを計算します。`G`。 
5. DP 配列を維持します。`dp[g]`gcd を取得するために必要な選択された要素の最小数を保存します`g`。 
6. 配列要素ごとに`x`:

 以下のみで構成される新しいサブセットを開始します`x`。 

また、以前に到達可能なすべての gcd 状態を拡張します。`g`新しい状態へ`gcd(g, x)`。 
7. すべての要素を処理した後、`k = dp[G]`。 

これは、gcd がターゲット値と等しい最小サブセット サイズです。 
8. 最初のオカレンスの作成`G`必要`k - 1`操作。 
9. 1回限り`G`存在する場合、残りのすべてのポジションを変換する必要があります`n - 1`操作。 
10. 返却:```
n + k - 2
```### なぜ効果があるのか

 gcd 操作では値が増加することはなく、すべての最終要素が元のすべての要素を除算する必要があるため、最終値は配列全体の gcd でなければなりません。 

発生した場合`G`すでに存在しており、それぞれの非`G`要素は直接変換できます`G`このような要素はすべて少なくとも 1 回は変更する必要があるため、より高速な解決策は存在しません。 

発生しないとき`G`存在する場合、一部の操作シーケンスで最初のオブジェクトを作成する必要があります。`G`。 1 つの位置で gcd を繰り返し取得することによって得られる値は、元の要素のサブセットの gcd と等しくなります。 そのような最小のサブセットにサイズがある場合`k`、それでは少なくとも`k-1`これらの要素を組み合わせるには操作が必要であり、正確には`k-1`操作は十分です。 

1 部コピーした後、`G`存在しても、残りのすべての位置が存在するためには 1 回の操作が必要です。`G`、別のものを与える`n-1`操作。 

DP は、到達可能なすべての gcd 値の最小サブセット サイズを計算し、最適な値を見つけます。`k`。 2 つのフェーズを組み合わせると、最小限の答えが得られます。 

## Python ソリューション```python
import sys
from math import gcd

input = sys.stdin.readline

MAXV = 5000
INF = 10**9

t = int(input())

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    G = 0
    for x in a:
        G = gcd(G, x)

    cnt = sum(1 for x in a if x == G)

    if cnt > 0:
        print(n - cnt)
        continue

    dp = [INF] * (MAXV + 1)

    for x in a:
        ndp = dp[:]

        ndp[x] = min(ndp[x], 1)

        for g in range(1, MAXV + 1):
            if dp[g] == INF:
                continue

            ng = gcd(g, x)
            ndp[ng] = min(ndp[ng], dp[g] + 1)

        dp = ndp

    k = dp[G]
    print(n + k - 2)
```最初の部分ではグローバル gcd を計算します。`G`。 

次に、既に等しい要素の数を数えます。`G`。 少なくとも 1 つ存在する場合、答えはすぐに得られます。 他のすべての要素には 1 つの操作が必要であり、使用可能なソース値がすでに存在します。 

2 番目のブランチは、より困難なケースを処理します。 DP には、各 gcd 値を達成できる最小のサブセット サイズが格納されます。 

数値を処理する場合`x`、2つの可能性があります。 のみを含む新しいサブセットを開始するか、`x`、または追加します`x`以前に形成されたサブセットに。 追加すると gcd が変更されます`g`に`gcd(g,x)`サブセットのサイズを 1 つ増やします。 

コピーした配列の使用`ndp`重要です。 DP を適切に更新すると、1 回の反復中に同じ要素を複数回使用できるようになります。 

最後に、`dp[G]`は、gcd がグローバル gcd と等しい最小サブセット サイズです。 式`n + k - 2`上記の証明から直接導かれます。 

すべての値は 5000 未満のままであるため、DP 状態空間は小さいです。
