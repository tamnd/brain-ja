 ## 解決策
 ## 問題の理解

 この問題は次のように再構成できます。 クラゲが群衆と対峙する`n`それぞれに指定された HP を持つモンスター`h_i`。 彼女はすべてのモンスターのHPを正確に減らしたいと考えています`1`。 彼女が持っている`m`攻撃のラウンドごとに、確率で特別な剣が「光る」場合があります。`p`。 剣が光る場合、彼女はすべてのモンスターのHPを減らす全体攻撃のみを実行できます。`1`。 光らない場合はモンスター1体を対象とし、そのHPを`1`。 彼女は行動する前に、そのラウンドで剣が光るかどうかを知っています。 目標は、彼女がすべてのモンスターの HP を正確に減らすことができる確率を計算することです。`1`彼女が最適にプレーすれば、すべてのラウンドが終わった後に。 

制約は適度ですが、注意が必要です。`n`までです`20`したがって、すべてのモンスターを直接反復処理することは可能です。`m`まで可能です`4000`そのため、ラウンドのあらゆる組み合わせをシミュレートすることが不可能になります。 モンスターのHPは最大で`400`、したがって、各モンスターに必要な「作業」の合計は`399`単位。 なぜなら`n`が小さい場合、全体的および個別に削減する必要がある HP ユニットの数を考慮できます。 

微妙なエッジケースは、すべてのモンスターが既に HP を持っている場合です。`1`。 すると確率は`1.0`攻撃は必要ないのですぐに。 もう 1 つのエッジケースは次のような場合です`p = 0`そして`m`必要な個々の攻撃の合計より小さい。 この場合、確率は次のようになります。`0.0`。 不注意なアプローチは、すべてのモンスターを盲目的に攻撃しようとし、カウントを過剰に増やして、より大きな確率をもたらす可能性があります。`1.0`または、最適な単一ターゲットの選択を考慮していない。 

## アプローチ

 ブルートフォース手法では、考えられるすべてのシーケンスをシミュレートします。`m`ラウンドごとに剣が光るかどうかで分岐し、単体攻撃の対象をすべて考慮します。 各ラウンドには 2 つの可能性 (光沢または光沢なし) があり、最大で`4000`ラウンド、パスの数は`2^4000`、計算上の実現可能性をはるかに超えています。 各モンスターの HP は最大`400`したがって、状態空間は次のようになります。`401^20`、天文学的に大きい。 

重要な洞察は、光る剣が均一に **すべてのモンスターをまとめて減らす**一方、光らない弾は **残りの最大 HP** に対して標的を絞った攻撃を可能にするということです。 したがって、問題は、モンスターの正確な組み合わせではなく、**残りのグローバル ヒットと個々のヒットの数**に関する動的プログラミング タスクに帰着します。 

させて`global_needed = max(h_i) - 1`グローバル攻撃が必要な回数を表します。 各ラウンドで、剣が光っている場合、次の場合にはそれを使用する必要があります。`global_needed > 0`; それ以外の場合はスキップします。 光らない場合は上記の残りHPが最も大きいモンスターを選択します`1`。 この洞察を使用して、確率 DP 配列をモデル化できます。`dp[remaining_global][remaining_rounds]`そして成功の確率を再帰的または反復的に計算します。 

これにより、問題が対処可能なものに縮小されます。`n <= 20`そして`m <= 4000`、残されたグローバル攻撃の数と残されたラウンドの数のみを追跡することは実現可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^m) | O(2^m) | 遅すぎる |
 | グローバル/個別ヒットの動的プログラミング | O(n * m) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.変換`p'`確率に`p = p'/100`。 させて`q = 1-p`剣が光らない可能性があります。 
2. テスト ケースごとに、次の値を計算します。`global_needed = min(h_i) - 1`。 これは、シャイニング攻撃によってすべてのモンスターに適用される最小 HP 減少です。 
3. コンピューティング`individual_needed = sum(h_i - 1 - global_needed)`。 これは、必要な残りの単一目標の削減を表します。 
4. DP 配列を初期化する`dp[r][g]`どこ`r`残りラウンドです`g`グローバル攻撃は依然として必要です。`dp[0][g] = 1`もし`g = 0`そして`0`さもないと。 
5. ラウンドを繰り返します。 ラウンドごとに更新`dp[r][g]`期待される確率として:

 - 剣が光る場合、次の場合全体攻撃から 1 を減算します。`g > 0`。 確率を掛ける`p`。 
- 剣が光らない場合は、individual_needed から 1 つ減らします。`individual_needed > 0`。 確率を掛ける`q`。 
6. 全ラウンド終了後、`dp[m][0]`ジェリーフィッシュがすべてのモンスターを減らすことに成功する確率が含まれます。`1`。 

その理由は、ラウンドごとに、全体的に攻撃するか個別に攻撃するかを最適に選択するためです。 これにより、可能性が無駄にならず、確率の計算が正確に保たれることが保証されます。 

**機能する理由**: 不変条件は次のとおりです。`global_needed`すべてのモンスターに適用される最小 HP 減少を正確に追跡し、`individual_needed`残りの目標削減量を追跡します。 すべてのラウンドで、ジェリーフィッシュは最適に動作します。剣が光っているときは可能であれば全体的に攻撃し、そうでない場合は残っている最大のモンスターを減らします。 すべての確率的結果が線形的に結合されるため、最終的な DP は正しい成功確率を示します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, p_percent = map(int, input().split())
        h = list(map(int, input().split()))
        p = p_percent / 100
        q = 1 - p
        
        min_hp = min(h)
        global_needed = min_hp - 1
        individual_needed = sum(x - 1 - global_needed for x in h)
        
        if individual_needed == 0 and global_needed == 0:
            print("1.000000")
            continue

        dp = [0.0] * (global_needed + 1)
        dp[global_needed] = 1.0

        for _ in range(m):
            new_dp = [0.0] * (global_needed + 1)
            for g in range(global_needed + 1):
                if dp[g] == 0:
                    continue
                # Sword shines
                if g > 0:
                    new_dp[g-1] += dp[g] * p
                else:
                    new_dp[g] += dp[g] * p
                # Sword does not shine
                new_dp[g] += dp[g] * q
            dp = new_dp

        result = 1 - dp[global_needed]  # probability not succeed
        print(f"{result:.6f}")

if __name__ == "__main__":
    solve()
```**説明**: まず、最小のグローバル削減と残りの個別ヒットを計算します。 DP アレイ`dp[g]`その確率を正確に追跡します`g`各ラウンド後にグローバルヒットが残ります。 ラウンドごとに、剣が光るかどうかに応じて確率を更新します。 最後にから引きます`1`なぜなら`dp[global_needed]`失敗の確率を表します (すべてのグローバル ヒットが必要です)。 使用する`float`要求された精度には算術演算で十分です。
