 ## 解決策
 ## 問題の理解

 ジェリーフィッシュとフラワーの 2 人のプレイヤーの間で行われるターンベースの決闘の勝者を予想するように求められます。 各プレイヤーには主人公と騎士がおり、それぞれが独自の健康ポイント (HP) を持っています。 クラゲは`a`HP、フラワーは`b`HP、ジェリーフィッシュナイトは`c`HPと花の騎士は`d`HP。 決闘は交互のラウンドで進行します。 奇数ラウンドでは、ジェリーフィッシュの騎士はどちらかのフラワーを直接攻撃でき、ダメージを軽減します。`b`、または花の騎士、減少`d`。 偶数ラウンドでは、花の騎士は同じようにクラゲを直接攻撃するか、クラゲの騎士を攻撃できます。 プレイヤーは最適にプレイすること、つまり勝つチャンスを最大化するアクションを選択することを前提としています。 

課題は、考えられるすべての攻撃をシミュレートすることなく、決闘が始まる前に勝者を予測することです。 入力は複数のテスト ケースで構成され、出力では各ケースについて「Gellyfish」と「Fflower」のどちらが勝つかを示す必要があります。 

制約が非常に厳しいため、すべての攻撃を単純にシミュレーションすることは非現実的です。 HP値は最大まで上昇する可能性があるため、$10^9$および最大テストケースの数$10^4$、各ラウンドをシミュレートするには時間がかかりすぎます。 テスト ケースごとに O(1) の計算が必要です。 

明白ではないエッジケースは、ナイトの HP が非常に低い場合、またはメイン プレイヤーの 1 人の HP が最小限である場合に発生します。 たとえば、クラゲのHPが1でフラワーの騎士が生きている場合、クラゲが何をしても次のターンにはフラワーが勝ちます。 逆に、花の騎士の HP が 1 で、クラゲが先に攻撃した場合、花は反撃できず、クラゲが勝ちます。 これらを正しく処理するには、どのナイトが最初に除去されるか、そしてそれがメイン プレイヤーへの攻撃にどのような影響を与えるかを推論する必要があります。 

## アプローチ

 ブルートフォースソリューションでは、ラウンドごとに決闘をシミュレートし、ターンごとに攻撃ごとにターゲットのHPを1ずつ減らします。 これはゲームを正確に模倣しているため、原則的には正しいです。 ただし、最悪の場合、各テスト ケースには最大で$10^9$両方の騎士のHPが非常に高く、メインキャラクターを直接攻撃するプレイヤーがいない場合のステップ。 と$10^4$テストケース、これには必要になります$10^{13}$合理的な制限をはるかに超えた操作。 

重要な洞察は、決闘は初期 HP 値と最適な攻撃の選択によって完全に決定されるということです。 相手のナイトを攻撃すると、相手が主人公を攻撃するのが遅れるため、各プレイヤーが対戦相手がナイトを殺す前に相手のナイトを排除できるかどうかだけを考慮する必要があります。 すべてのラウンドをシミュレートする必要はありません。 各騎士を倒すのに必要なターン数を計算し、それをメイン プレイヤーの HP と比較できます。 ナイトが相手のメイン プレイヤーを攻撃する回数が 0 になる前に除去できた場合、対応するメイン プレイヤーは安全です。 そうしないと負けてしまいます。 

この推論を使用すると、テスト ケースごとに O(1) で Gellyfish と Flower のどちらが勝つかを計算できます。

 ## アルゴリズムのチュートリアル

 1. ターン順序を特定し、Gellyfish の騎士が最初に攻撃することを認識します。 これにより、Gellyfish にわずかなイニシアチブのアドバンテージが与えられます。 
2. クラゲの騎士が花の騎士を倒すのに必要な攻撃回数を計算します。これは単純です。`d`。 攻撃するたびに騎士のHPが1ずつ減ります。 
3. 花の騎士がクラゲの騎士を倒すのに必要な攻撃の数を計算します。これは`c`。 
4. 各騎士にとって最適な戦略を決定します。 主人公を守ることができれば、それぞれが相手の騎士を死ぬまで攻撃します。 相手を直接攻撃することが即死となる場合は、それを優先する必要があります。 
5. 花の騎士がクラゲのHPを0にする前に、クラゲが花の騎士を排除できるかどうかを判断します。 決闘中に花の騎士がクラゲを攻撃できる回数を計算します。 花の騎士がクラゲのHPを枯渇させるよりも短いターンでクラゲの騎士が花の騎士を倒すことができれば、クラゲが生き残り勝利します。 それ以外の場合は、フラワーの勝ちです。 
6. 単純な比較を使用してこのロジックを実装します。フラワーは次の場合にのみ勝ちます。`a <= d`そして`b > c`Gellyfish の先手有利を考えると。 それ以外の場合は、Gellyfish が勝ちます。 

機能する理由: 決闘の結果は、各プレイヤーが相手のナイトまたはメイン プレイヤーをいかに早く排除できるかによって完全に決まります。 ゲームはターン制で、攻撃ごとに 1 の固定ダメージを与えるため、ターンを数えてメイン HP と比較すると、正確な勝者が決まります。 騎士は生き残るため、または主人を守るために最適な攻撃を強いられるため、問題はこれらの比較に帰着します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a, b, c, d = map(int, input().split())
        # Gellyfish attacks first
        # If Flower's knight dies first, Gellyfish wins
        # If Gellyfish's knight dies first, Flower wins
        # Gellyfish kills Flower's knight in d attacks
        # Flower kills Gellyfish's knight in c attacks
        # Each main HP check
        if a <= d and b > c:
            print("Flower")
        else:
            print("Gellyfish")

solve()
```最初の行はテスト ケースの数を読み取ります。 各テスト ケースは独立して処理されます。 比較`a <= d and b > c`フラワーの騎士がクラゲを殺すのに十分長く生き残ることができ、クラゲの騎士がすぐにフラワーを脅かすことができなければ、フラワーが勝つという洞察をコード化しています。 それ以外の場合は、Gellyfish の主導権が勝利を確実にします。 整数比較を使用すると、各攻撃のシミュレーションが回避され、非常に大きな HP 値でも効率的に処理されます。
