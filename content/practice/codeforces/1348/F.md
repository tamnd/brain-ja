 ## 解決策

 ## 問題の理解

 最終ラインナップの各ポジションには制約があります。`i`、そこに座っている人は、連続した範囲からのラベルを持っている必要があります`[a_i, b_i]`。 ラベル自体は次の順列を形成します。`1`に`n`, したがって、すべての数値が 1 回だけ使用されます。 

タスクには 2 つの層があります。 まず、すべての位置制約を満たす少なくとも 1 つの有効な順列を構築する必要があります。 次に、この順列が一意であるかどうかを判断する必要があります。 一意であれば出力します。 そうでない場合は、2 つの異なる有効な順列を生成して、曖昧さを証明する必要があります。 

この構造は非常に厳密であるため、順列に対する単純な後戻りアプローチは不可能です。 適度な分岐要素でも爆発的に爆発する`n = 2 \cdot 10^5`。 どのソリューションも、基本的に直線または直線に近い時間で実行する必要があります。通常、`O(n log n)`または`O(n α(n))`。 

主な困難は、間隔制約を満たすだけでなく、複数のグローバル割り当てが存在するかどうかを検出することです。 1 つの位置での局所的な自由が伝播して、まったく異なる有効な順列を作成する可能性があるため、貪欲な選択は強制性についてテストする必要があります。 

いくつかのエッジケースでは、典型的な障害が明らかになります。 

問題のあるシナリオの 1 つは、すべての間隔が広い場合です。たとえば、`a_i = 1, b_i = n`みんなのために`i`。 多くの順列は有効であり、将来の柔軟性を追跡せずに貪欲に割り当てるアルゴリズムは、一意性を誤って主張します。 

もう 1 つの微妙なケースは、次のような間隔は狭いが重複している場合です。```
1: [1,2]
2: [1,2]
3: [1,2]
```複数の順列がありますが、素朴で貪欲な「利用可能な最小のものを取る」と、代替を認識せずに順列が 1 つ生成されます。 

3 番目の問題は、初期のポジションが厳しく制限され、特定の値を強制される一方で、後のポジションが依然として柔軟に見える場合に発生します。 一意性を検出するには、ローカルな実行可能性だけではなく、グローバルな推論が必要です。 

## アプローチ

 ブルートフォースアプローチでは、間隔制約の下ですべての有効な順列を構築し、その数が存在するかを数えようとします。 これは、2 部グラフで位置と値の間の完全な一致をすべて生成することと同じです。 このグラフを明示的に表現するだけでもすでにコストがかかります`O(n^2)`最悪の場合、エッジが増加し、一致の列挙が階乗的に増加します。 これはすぐに実行不可能になります。 

重要な観察は、問題は実際には番号の割り当てにあるということです。`1..n`一貫した方法で位置に変換され、位置と値の両方が完全に順序付けされます。 これにより、位置または値をソートされた順序で処理するときに貪欲な構築が可能になります。これは、各値がどこかに移動する必要があり、各位置が最終的に 1 つの値を受け取る必要があるためです。 

標準的な構造では、次の値を処理することによって辞書編集的に最小の有効な順列を構築します。`1`に`n`そして、常に各値を、それを受け入れることができ、実行可能性を維持できる左端の位置に割り当てます。 これは、その間隔に現在値が含まれているアクティブなポジションを維持するデータ構造を使用して実装できます。 

一意性を検出するために、辞書編集的に最小の有効な置換と辞書編集的に最大の有効な置換の 2 つの極端な解を構築します。 これらが異なる場合、複数の解決策が存在します。 それらが一致する場合、解決策は一意になります。 

これが機能するのは、代替の有効な置換は、それが逸脱する最初の位置で異なっている必要があり、その逸脱により、あるステップでより小さいまたはより大きい選択のいずれかに向かうためです。 したがって、有効な解決策はすべて、これら 2 つの極端な値の間に挟まれます。

 ## アルゴリズムのチュートリアル

 2 つの順列を独立して構築します。1 つは貪欲な最小値、もう 1 つは貪欲な最大値です。 

### 最小順列

 以下の値を処理します。`1`に`n`、間隔に現在の値が含まれる利用可能なポジションの構造を維持します。 それぞれの値について、それを受け入れることができる最小のインデックスの有効な位置にその値を割り当てます。 

1. 次の未使用位置の検索をサポートする DSU 構造を初期化します。 
2. 値を反復する`v`から`1`に`n`。 
3. それぞれについて`v`、最小の位置を見つけます`i`そのような`i >= a_i`、`i <= b_i`、および位置`i`まだ割り当てられていません。 
4.割り当て`ans_min[i] = v`そして位置をマークします`i`使用済みとして。 
5. 削除する`i`DSU から取得されるため、今後の検索ではスキップされます。 

DSU は、範囲内で次に利用可能な位置に効率的にジャンプするために使用されます。 

### 最大順列

 同じ考え方を繰り返しますが、各値の可能な最大の位置を優先します。 

1. 以前の未使用位置の検索をサポートするリバース DSU を初期化します。 
2. 値を反復する`v`から`1`に`n`。 
3. それぞれについて`v`、最大の位置を見つけます`i`そのような`a_i <= v <= b_i`。 
4.割り当て`ans_max[i] = v`。 
5.マーク位置`i`逆の構造で使用されるものと同じです。 

### 決定

 両方の構築後、結果として得られる順列を比較します。 

それらが同一の場合、順序付けはすべてのステップで強制されます。 それ以外の場合、少なくとも 1 つの値に実際の配置の選択があり、複数の有効な順列が生成されます。 

### なぜ効果があるのか

 各ステップで、greedy-min 構築は常に左端の実行可能な位置を選択し、greedy-max は常に右端の実行可能な位置を選択します。 有効な置換では、各値を何らかの実行可能な位置に割り当てる必要があり、両方のエンドポイントが制約内にある限り、割り当ての交換は間隔の有効性に違反することはできません。 したがって、有効な解決策はすべて、位置の選択という点でこれら 2 つの極端な構造の間にあります。 両方の極端な値が一致した場合、グローバルに存続する分岐オプションを持つポジションは存在せず、一意性が強制されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    seg = [tuple(map(int, input().split())) for _ in range(n)]

    # DSU for next free (for minimum construction)
    parent_next = list(range(n + 2))

    def find_next(x):
        if parent_next[x] != x:
            parent_next[x] = find_next(parent_next[x])
        return parent_next[x]

    def erase_next(x):
        parent_next[x] = find_next(x + 1)

    # DSU for previous free (for maximum construction)
    parent_prev = list(range(n + 2))

    def find_prev(x):
        if parent_prev[x] != x:
            parent_prev[x] = find_prev(parent_prev[x])
        return parent_prev[x]

    def erase_prev(x):
        parent_prev[x] = find_prev(x - 1)

    ans_min = [0] * n
    ans_max = [0] * n

    # positions grouped by interval for activation
    import heapq

    pos_by_start = [[] for _ in range(n + 2)]
    for i, (l, r) in enumerate(seg):
        pos_by_start[l].append(i)

    active = []
    ptr = 1

    for v in range(1, n + 1):
        while ptr <= n:
            for i in pos_by_start[ptr]:
                l, r = seg[i]
                heapq.heappush(active, (r, i))
            ptr += 1

        while True:
            r, i = heapq.heappop(active)
            l, rr = seg[i]
            if l <= v <= rr:
                pos = i + 1
                break

        ans_min[pos - 1] = v

    # rebuild for max using reverse greedy
    pos_by_end = [[] for _ in range(n + 2)]
    for i, (l, r) in enumerate(seg):
        pos_by_end[r].append(i)

    active = []
    ptr = n

    for v in range(1, n + 1):
        while ptr >= 1:
            for i in pos_by_end[ptr]:
                l, r = seg[i]
                heapq.heappush(active, (-l, i))
            ptr -= 1

        while True:
            lneg, i = heapq.heappop(active)
            l = -lneg
            r = seg[i][1]
            if l <= v <= r:
                pos = i + 1
                break

        ans_max[pos - 1] = v

    if ans_min == ans_max:
        print("YES")
        print(*ans_min)
    else:
        print("NO")
        print(*ans_min)
        print(*ans_max)

if __name__ == "__main__":
    solve()
```最初の構造では、値が増加するにつれて候補間隔を拡張することで貪欲な割り当てを構築し、常に現在の値と一致する有効な位置を抽出します。 ヒープにより、現在の値が含まれる間隔の位置を効率的に選択できるようになります。 

2 番目の構成は、同じアイデアを逆の順序で反映しており、有効な選択肢の反対端を確実に探索できます。 ネガティブインデックスのトリックにより、より大きな左境界を持つ位置を優先することができます。 

最後の比較は、全体の一意性テストです。両方の構成が一致する場合、すべての強制された選択は両方向で同一であり、グローバルな解空間で分岐がないことを意味します。

 ## 特殊なケース

 すべての間隔がシングルトンである完全に制約されたインスタンスでは、一意の置換が即座に強制され、両方の貪欲な構造は曖昧さなく同じシーケンスに崩壊します。 

すべての間隔が完全に制約されていないインスタンス`[1, n]`は最大の分岐を作成し、すべての値をどこにでも配置できるため、2 つの極値構造は最初のステップで分岐します。 

部分的に拘束されたチェーン。間隔が次のように交互に重なり合います。`[1,2], [2,3], [3,4], ...`、初期の割り当ては強制されるが、後のポジションは柔軟なままであり、初期の安定後にのみダイバージェンスを生み出す状況を作り出します。
