 ## 解決策
 ## 問題の理解

 (N) 個の記念碑があります。 記念碑 (i) は座標 ((x_i,y_i)) と正のグレード (g_i) を持ちます。 モルガンヌは、ラインの終点として 2 つの異なる記念碑を選択します。 気球はこれら 2 つの記念碑の間に配置され、線は残りのすべての記念碑を 2 つの開いた半平面に分割します。 

各写真には、選択した 2 つの終点記念碑と、線路の両側のいずれかにあるすべての記念碑が含まれています。 2 枚の写真の合計が (A) と (B) である場合、考えられるすべてのエンドポイント モニュメントのペアにわたって (|A-B|) を最小化したいと考えます。 

入力により、記念碑の数とその座標とグレードが続きます。 出力は、2 つの写真グレード間の可能な限り最小の差です。 

幾何学的に重要な単純化は、2 つの終点のモニュメントが両方の写真に現れていることです。 したがって、彼らの成績は両方の合計に加算され、差額が取られるとキャンセルされます。 端点の固定ペア (i,j) について、厳密に線分の片側の記念碑のグレードの合計が (S) になると仮定します。 全遺跡のグレードの合計を(T)とする。 反対側にはグレードがあります

 [
 T-g_i-g_j-S。 
]

 したがって、違いは次のとおりです

 \左|2S-T+g_i+g_j\右|。 
]

 したがって、問題全体は次のようになります。2 つの記念碑を通るすべての行について、片側の点の等級合計をできるだけ早く見つけます。 

座標の制限が (10^9) に達するため、座標の差および外積は 32 ビット整数よりもはるかに大きくなる可能性があります。 外積はおよそ (10^{18}) に達する可能性があり、すべての等級の合計は (4\cdot10^{12}) に達する可能性があります。 Python の整数はこれらの値を直接処理するため、実装ではオーバーフローの問題は発生しません。 

制限 (N\le 4000) が主要なアルゴリズム信号です。 すべてのエンドポイント ペアを列挙すると、すでに約 (N^2/2) 個の可能性が得られるため、すべてのペアに (O(N)) 個の作業を費やすには、おおよその時間が必要になります。 

31,976,004,000
 ]

 最悪の場合のポイント分類。 これは 15 秒の制限をはるかに超えています。 1 つの固定エンドポイントに関連付けられたすべてのペアをまとめて処理する必要があります。 

最初のエッジ ケースは (N=2) です。 例えば、```
2
0 0 1
1 2 999
```答えがあります`0`。 線路の両側には記念碑はありません。 どちらの写真にも両方のエンドポイントが含まれているため、両方のグレードは (1000) です。 各エンドポイントを 1 回だけカウントする不用意なソリューションでは、誤って (998) が報告されます。 

2 番目のエッジ ケースは (N=3) です。 例えば、```
3
0 0 5
1 0 10
0 1 7
```答えがあります`5`。 どちらのペアが境界モニュメントとして選択されたとしても、残りのモニュメントは一方の側に完全にあり、もう一方の側は空です。 エンドポイントはキャンセルされ、残りの記念碑のグレードに等しい差が残ります。 最良の選択では、記念碑にグレード (5) が付けられます。 

もう 1 つの簡単な間違いは、線の両側をテストするときに間違った厳密性を使用することです。 この声明は、3 つの記念碑が同一線上にないことを保証しているため、3 つ目の記念碑が境界線上に正確に存在することはあり得ません。 厳密な製品間テストを安全に使用できます。 エンドポイント自体をサイドの一部として扱うのは間違いであり、それをサイドサムに複製すると、答えも破損します。 

公式の SWERC 分析では、各固定モニュメントの周囲に他のモニュメントを順序付けし、差分を段階的に更新することによって、(O(N^3)) 解から (O(N^2\log N)) 解への同じ削減を記述しています。 

## アプローチ

 直接的な解決策は簡単です。 すべてのペア (i,j) を 2 つの境界モニュメントとして列挙します。 次に、1 つおきのモニュメント (k) を検査し、外積を使用して (i,j,k) の向きを計算し、(g_k) を 2 つの辺の合計の 1 つに加算します。 すべての点が分類されたら、2 つの辺の合計から差を計算します。 

これは正しいです。境界記念碑の考えられるすべての選択が明示的に考慮されており、外積によって残りの記念碑が境界線のどちら側を占めるかが正確にわかるからです。 問題はコストです。 (O(N^2)) 個のエンドポイントのペアがあり、それぞれに (O(N)) 個の分類が必要で、(O(N^3)) になります。 (N=4000) の場合、最悪のケースには約 (3.2\cdot10^{10}) 個の点分類が含まれるため、このアプローチは実行できません。 

(N) の余分な要素を取り除く観察は、1 つの固定記念碑 (i) について、考えられるすべての 2 番目の端点を角度順に考慮できるということです。 

記念碑 (i) を原点に一時的に配置し、(i) から他のすべての記念碑へのベクトルを調べます。 これらのベクトルを極角で並べ替えます。 2 番目の境界モニュメントがこのソートされた順序で時計回りに移動すると、特定の開いた半平面にあるモニュメントのセットが連続的に変化します。 より正確には、新しい境界線の片側にある記念碑は、(180^\circ) 未満の幅の連続した角度間隔を形成します。 

この間隔は 2 ポインタ スイープで維持できます。 左の端点は現在の境界ベクトルです。 境界ベクトルを回転しても対応する半円の端を後方に移動させることはできないため、右端点は前方にのみ移動します。 したがって、1 つの固定 (i) のスイープ全体にわたって、すべてのポインターは (O(N)) 回のみ移動します。 

固定 (i) に対して残っている唯一の高価な操作は、他の (N-1) 個のモニュメントを角度によってソートすることであり、コストは (O(N\log N)) です。 (i) のすべて (N) 個の可能な選択肢に対してこれを繰り返すと、(O(N^2\log N)) が得られます。 

公式の分析はまさにこの複雑さを示しており、すべての固定された制限記念碑の周囲に記念碑を順序付けし、段階的に勾配の差を計算することを説明しています。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(N^3)) | (O(N)) | 遅すぎる |
 | 最適 | (O(N^2\log N)) | (O(N)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての記念碑を読み取り、合計グレード (T) を計算します。 2 つの境界記念碑を除くすべての記念碑の合計グレード (T-g_i-g_j) を繰り返し使用します。 
2. 1 つのモニュメント (i) を最初の境界モニュメントとして固定します。 1 つおきの記念碑 (j) について、ベクトルを形成します。 
[
 v_j=(x_j-x_i,\ y_j-y_i)。 
]
 その方向、ベクトル成分、勾配を保存します。 これらのベクトルを (i) を中心とした極角によって並べ替えます。 

ソートにより、2 番目の境界記念碑が (i) を中心に回転できる循環順序が得られます。 
3. (2(N-1)-1) までのインデックスを許可することで、概念的に角度シーケンスを複製します。 ベクター オブジェクトを物理的に複製する必要はありません。 インデックス (k) は、`vectors[k % m]`、ここで、(m=N-1)。 

これにより、円の角度順序が線形シーケンスに変わるため、特別な場合を除き、半円の間隔は (0^\circ) 境界を越えることができます。 
4. 現在開いている半円の終点のポインタ (k) を維持します。 現在の境界ベクトル (v_j) については、(k) 進みながら、
 [
 \演算子名{cross}(v_j,v_k)>0。 
]

 正の外積は、(v_k) が (v_j) から厳密に (0^\circ) と (180^\circ) の間の角度だけ反時計回りにあることを意味します。 3 つのモニュメントが同一線上にないため、同じ固定モニュメントからの 2 つの異なるベクトルの外積がゼロになることはありません。 
5. 角度順序でグレードのプレフィックス合計を維持します。 現在の半円に (j+1) から (k-1) までのインデックスが含まれている場合、その等級合計はプレフィックス合計から (O(1)) で取得されます。 

区間は厳密に (j) の後に始まるため、境界記念碑自体は除外されます。 これはまさに必要なサイドサムです。 
6. 境界記念物 (i) と (j) について、次のようにします。`side`現在の半円内の成績の合計になります。 すべての非境界記念碑のグレードは次のとおりです。 
[
 T-g_i-g_j.
 ]
 したがって、両辺の和は次のようになります。`side`そして
 [
 T-g_i-g_j-\text{side}。 
]
 写真の違いは結果的に
 [
 \left|2\cdot\text{side}-(T-g_i-g_j)\right|。 
]
 7. この差を使用してグローバル最小値を更新します。 答えがゼロになった場合は、これより小さい絶対差は存在しないため、すぐに停止します。 
8. 考えられるすべての最初の境界モニュメント (i) に対して角度ソートと 2 ポインター スイープを繰り返します。 これらのスイープの少なくとも 1 回中に、順序付けされていない境界モニュメントのペアがすべて検出されるため、大域的最小値には真の最適値が含まれます。 

### なぜ効果があるのか

 固定モニュメント (i) の場合、ソートされたベクトルは 2 番目の境界モニュメントのすべての可能な方向を表します。 現在の方向 (v_j) について、対応する境界線の片側にある記念碑は、その方向が (v_j) から厳密に (180^\circ) 未満だけ反時計回りにあるものです。 外積条件は、この間隔を正確に特定します。 

(j) が角度順に進むにつれて、その (180^\circ) 区間の終点が後方に移動することはありません。 したがって、2 ポインタ スイープは、グレードの合計を維持しながら、可能なすべての側間隔を訪問します。 プレフィックスの合計は、各間隔を (O(1)) クエリに変換します。 

境界モニュメントの各ペアはそのような間隔を 1 つ定義し、2 枚の写真は正確に 2 つの相補的な側方和に同じ 2 つのエンドポイント グレードを加えたものです。 したがって、アルゴリズムで使用される式は、考えられるすべてのペアの正確な差を計算します。 すべてのペアの最小値を取ると、必要な答えが得られます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    n = int(input())
    points = [tuple(map(int, input().split())) for _ in range(n)]

    total_grade = sum(g for _, _, g in points)
    answer = total_grade

    for i in range(n):
        xi, yi, gi = points[i]

        vectors = []
        for j in range(n):
            if i == j:
                continue

            xj, yj, gj = points[j]
            dx = xj - xi
            dy = yj - yi

            vectors.append((math.atan2(dy, dx), dx, dy, gj))

        vectors.sort(key=lambda v: v[0])
        m = n - 1

        grades = [v[3] for v in vectors]

        prefix = [0] * (2 * m + 1)
        for p in range(2 * m):
            prefix[p + 1] = prefix[p] + grades[p % m]

        k = 1

        for j in range(m):
            if k < j + 1:
                k = j + 1

            _, ax, ay, gj = vectors[j]

            limit = j + m

            while k < limit:
                _, bx, by, _ = vectors[k % m]

                cross = ax * by - ay * bx

                if cross <= 0:
                    break

                k += 1

            side = prefix[k] - prefix[j + 1]
            other = total_grade - gi - gj

            diff = abs(2 * side - other)

            if diff < answer:
                answer = diff

                if answer == 0:
                    print(0)
                    return

    print(answer)

if __name__ == "__main__":
    solve()
```外側のループは最初の境界記念碑を選択します。 その固定点に対して、内部構造は他の記念碑ごとに 1 つのベクトルを作成します。 後の外積計算では元の整数コンポーネントを使用する必要があるため、ベクトルには角度ソート キーと正確な整数座標の両方が格納されます。`atan2`循環順序を取得するためにのみ使用されます。 実際の (180^\circ) メンバーシップ テストでは正確な整数の外積が使用されるため、記念碑がどちらのサイドに属するかを決定するために浮動小数点演算は使用されません。 これは、(10^9) ほど大きい座標の場合に特に便利です。 

ベクトルは ([-\pi,\pi]) の角度によって並べ替えられます。 プレフィックス配列の長さは (2m+1) で、グレード シーケンスの 2 つのコピーを表します。 ベクトル オブジェクト自体を複製しないため、ピボットごとのメモリが小さく保たれます。 

ポインタ`k`がリセットされることはありません`j`が増えます。 これは重要な 2 ポインター プロパティです。 開いた半円の端は円の周りを単調に移動します。`k`1 回の完全なスイープ中にのみ増加できます。 したがって、固定ピボットの外積テストの総数は、(O(N^2)) ではなく (O(N)) になります。 

条件`cross <= 0`半円を止めます。 ゼロクロス積は、2 つのベクトルが同一直線上にあることを意味しますが、1 つの線上に 3 つのモニュメントが存在しないため、他の 2 つの異なるモニュメントではこのようなことは起こり得ません。 使用する`<= 0`それにもかかわらず、これは安全な境界規則であり、完全な 1 回転後の現在のベクトルの複製コピーも除外されます。 

表現```
side = prefix[k] - prefix[j + 1]
```意図的に後から開始する`j`。 現在の境界記念碑は、どちらかの側の合計の一部として数えてはなりません。 2 つのエンドポイント グレードは両方の写真グレードに別々に挿入され、それらの差が計算されるとキャンセルされます。 

Python の整数は自動的に任意の精度に拡張されるため、(10^{18}) 付近の外積や (4\cdot10^{12}) 付近の合計評定には特別な処理は必要ありません。

            side = prefix[k] - prefix[j + 1]
            other = total_grade - gi - gj
            diff = abs(2 * side - other)

            if diff < answer:
                answer = diff

            if answer == 0:
                return "0\n"

    return str(answer) + "\n"

 ## 特殊なケース

 二つの記念碑については、```
2
0 0 1
1 2 999
```唯一の境界ペアにはすべての記念碑が含まれます。 側面の合計は両方ともゼロですが、両方の写真にはエンドポイントのグレード (1+999) が含まれています。 写真のグレードは(1000)と(1000)なので、答えは`0`。 アルゴリズムはこれを処理します。`other = total_grade - gi - gj`はゼロであり、プレフィックス間隔は空です。 

３つの記念碑については、```
3
0 0 5
1 0 10
0 1 7
```記念碑を最初の境界として固定します。 他の 2 つのベクトルは厳密に (0^\circ) と (180^\circ) の間の角度で分離されているため、考えられる境界ペアの 1 つは、3 番目の記念碑を一方の側に置き、もう一方の側を空のままにします。 各ペアの違いは、まさに残りの記念碑のグレードです。 グレード (5) を残すペアを選択すると答えが得られます`5`。 

同等の成績の場合、```
4
0 0 7
3 0 7
0 4 7
3 4 7
```このアルゴリズムは、両側の合計が等しいペアを見つけて、差がゼロになるようにします。 出来るだけ早く`answer == 0`、絶対差がこれより小さくなることはないため、実装はすぐに戻ります。 

最大の座標値については、```
3
0 0 1000000000
1000000000 0 999999999
0 1000000000 1
```3 つの点はすべて有効な三角形を形成します。 モニュメントは3つしかないので、答えは最小のグレードですが、`1`。 外積には (10^{18}) 付近の値が含まれており、Python はこれを正確に処理します。 

最大サイズのテストの場合、点は (0\le i<4000) の ((i,i^2)) です。 直線が厳密な二次曲線 (y=x^2) と交差できるのは最大 2 点であるため、これらの点のうち 3 つが同一線上にありません。 すべてのグレードは (1) であるため、ゼロの差が存在し、アルゴリズムは差が見つかるとすぐに終了します。 このテストは、幾何学的仮定と意図した (O(N^2\log N)) スケーリングの両方を検証します。
