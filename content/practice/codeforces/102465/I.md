 ## 解決策
 ## 問題の理解

 いくつかの石を表す白黒のピクセル グリッドがあります。 黒ピクセルには 3 つの役割があります。 一部はすべての石の外側のつながった黒い領域に属し、一部は石の内側に実際の石工の跡を形成し、一部は孤立したノイズ ピクセルです。 すべての石にはマークが 1 つだけ含まれており、マークは白いピクセルで囲まれています。 

グリッドの寸法は最大でも 1000 x 1000 なので、最大 100 万ピクセルになります。 検出されたオブジェクトごとに画像の大部分を繰り返しスキャンするソリューションでは、簡単に数十億、さらには数兆の操作に達する可能性があります。 4 秒の制限は、総作業量がピクセル数に比例し、ピクセルあたりの作業量がわずかで一定であるアルゴリズムに非常に有利です。 グリッドが十分に大きいため、Python では再帰的な塗りつぶしも安全ではありません。これは、再帰の深さがグリッド サイズ内で線形になる可能性があるためです。 

中心的な観察は、3 つのマークがトポロジー的に異なるということです。 マークで囲まれた白い領域を見ると、A はちょうど 1 つの白い領域を囲み、B はちょうど 2 つの白い領域を囲み、C はまったく囲みません。 パラメーター x と y は任意であるため、これらのマークの寸法は変わる可能性があり、境界ボックスや黒ピクセルの正確な数を測定することは信頼できません。 囲まれた白成分の数は x や y に依存しません。 

この定式化にはいくつかの罠が隠されています。 1 つ目は外側の黒い領域です。 考慮する```
#######
#.....#
#..#..#
#.....#
#######
```孤立した`#`マークのように見えますが、実際にはノイズです。 さらに重要なことは、外側領域に属する黒いピクセル自体が C または別のマークに似ている可能性があることです。 分類を試みる前に、それらを削除する必要があります。 

2 番目の罠は、外側の領域では斜めの接続性が重要であるということです。 例えば、```
#######
#.....#
#.#...#
##....#
#######
```対角線で接する 2 つの黒い領域は、8 連結性の下では同じ外側の領域に属します。 外側の領域を 4 接続として扱うと、ピクセルの一部が取り残され、誤ってマークとして分類される可能性があります。 

3 番目の罠はノイズです。 ノイズ ピクセルは、正確に 1 つのピクセルで構成される黒のコンポーネントです。 周囲の白いピクセルは、マークの囲まれた内部ではなく、石の表面の通常の部分を形成します。 すべての黒コンポーネントに隣接する白コンポーネントを単純にカウントする不注意な解決策では、そのようなピクセルを C のようなマークと間違えたり、誤った穴をカウントしたりする可能性があります。 

4 番目のトラップは、白いサーフェスが 8 接続ではなく 4 接続を使用していることです。 斜めのギャップは 2 つの白い領域を接続しません。 例えば、```
#######
#..#..#
#.#.#.#
#..#..#
#######
```どの白いピクセルが同じ領域に属するかを決定するときは、垂直方向と水平方向の隣接性を使用して解釈する必要があります。 8 接続を使用すると、対角線の接触によって分離された領域がマージされ、穴の数が変化する可能性があります。 

## アプローチ

 直接的なアプローチでは、最初にすべての黒いコンポーネントを見つけてから、候補コンポーネントごとに周囲の白いピクセルを調べて、それが囲まれている領域の数を決定します。 マークのタイプは囲まれた白い領域によって完全に決定されるため、これは概念的には正しいです。 問題は、すべての候補に対して周囲のグリッドの個別のフラッドフィルを実行すると、同じピクセルが繰り返し処理されることです。 

最悪の場合、Θ(WH) 個の小さなコンポーネントが存在する可能性があります。 すべてのコンポーネントが別の Θ(WH) スキャンを引き起こす場合、総作業量は Θ((WH)^2) になります。 100 万ピクセルの場合、これは 10^12 ピクセルの訪問数に相当し、4 秒の制限をはるかに超えています。 個々の分類は簡単であるため、強引な方法は機能しますが、同じ白い表面が何度も探索されるため、失敗します。 

有益な観察は、白い領域がグローバルに計算できることです。 すべての白ピクセルは 1 つの 4 接続白コンポーネントに属しているため、すべての白コンポーネントを 1 回だけフラッドフィルできます。 フラッド フィルを実行している間、それに接触している黒いコンポーネントを検査します。 

石の外面は、石の周囲の黒い領域に接しています。 マークに属する内部領域は、その外側の黒い領域に触れません。 各石には正確に 1 つのマークがあるため、このような内部の白コンポーネントは、正確に 1 つの非ノイズ黒コンポーネントに関連付けることができます。 ノイズは、黒いコンポーネントのサイズが 1 であるため、無視できます。 

この場合、問題は 1 対のグローバル接続コンポーネント計算になります。 まず、8 接続された外側の黒い領域を特定します。 次に、残っているすべての黒いコンポーネントにラベルを付け、そのサイズを記録します。 最後に、すべての白いコンポーネントを 4 接続でフラッドフィルします。 外側の黒領域に接触しない各白コンポーネントについて、それに接触する固有の非ノイズ黒コンポーネントのホール数を増加させます。 

結果として得られる穴の数は、マークのタイプを直接示します。 穴が 0 個は C、穴が 1 個は A、穴が 2 個は B を意味します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((WH)^2) | O(WH) | 遅すぎる |
 | 最適 | O(WH) | O(WH) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 画像を文字列のリストとして保存し、各ピクセルをグリッド グラフの頂点として扱います。 黒いピクセルは後で 8 隣接隣接関係を使用して接続され、白いピクセルは 4 隣接隣接関係を使用します。 
2. 隅のピクセルから塗りつぶしを開始します。`(0, 0)`隣接する 8 方向すべてを使用します。 境界線全体は黒であり、このステートメントは、外側の領域に属するすべての黒いピクセルが 8 接続性で境界線に接続されていることを保証します。 したがって、この塗りつぶしは外側の黒い領域に正確にラベルを付けます。 
3. 残りの黒いピクセルをすべてスキャンします。 ラベルのない黒いピクセルが見つかるたびに、8 接続フラッド フィルを実行し、そのコンポーネントに新しい ID を与えます。 サイズを保存します。 サイズ 1 のコンポーネントはノイズですが、それより大きなコンポーネントはすべて本物の石工の痕跡です。 
4. すべての白いピクセルをスキャンします。 未訪問の白いピクセルごとに、4 接続のフラッド フィルを実行します。 塗りつぶし中に、隣接するすべての黒ピクセルを検査し、この白コンポーネントが外側の黒領域に接触しているかどうか、どの非ノイズ黒コンポーネントに接触しているか、および複数のそのようなコンポーネントに接触しているかどうかという 3 つの情報を記憶します。 
5. 白いコンポーネントを完全に調べたら、その役割を分類します。 外側の黒い領域に触れている場合、それは通常の石の表面の一部であり、マークの内部にはなりません。 外側の領域に触れておらず、ちょうど 1 つの非ノイズ ブラック コンポーネントに隣接している場合、それはそのマークに属する囲まれた領域であるため、そのコンポーネントのホール カウントを増やします。 ノイズ成分は意図的に無視されます。 
6. すべての白色コンポーネントが処理された後、すべての非ノイズ黒色コンポーネントの穴数を検査します。 穴が 0 個のコンポーネントは C を表し、穴が 1 つある場合は A、穴が 2 つある場合は B を表します。対応する答えをインクリメントします。 

重要な不変条件は、白色コンポーネントの塗りつぶしが終了した後、すべての白色コンポーネントが通常の石の表面または囲まれた内部のいずれかとして一度だけ分類されることです。 石の表面は 4 つに接続されており、すべての石には正確に 1 つのマークがあるため、囲まれたコンポーネントはその石のマークのみに属することができます。 すべてのノイズ コンポーネントはサイズ 1 を持つため、サイズ 1 の黒コンポーネントを無視すると、ノイズがホールに寄与するのを防ぐことができます。 したがって、すべての本物のマークは、囲まれた白い領域の実際の数を正確に受け取ります。 

## Python ソリューション```python
import sys
from array import array

input = sys.stdin.readline

def solve():
    W, H = map(int, input().split())
    grid = [input().strip() for _ in range(H)]
    n = W * H

    # comp[idx] == -1: not a black component yet
    # comp[idx] == 0: outside black region
    # comp[idx] > 0: a genuine/noise black component
    comp = array('i', [-1]) * n

    # 1. Flood-fill the outside black region using 8-connectivity.
    stack = [0]
    comp[0] = 0

    while stack:
        p = stack.pop()
        r = p // W
        c = p - r * W

        r0 = max(0, r - 1)
        r1 = min(H - 1, r + 1)
        c0 = max(0, c - 1)
        c1 = min(W - 1, c + 1)

        for nr in range(r0, r1 + 1):
            base = nr * W
            for nc in range(c0, c1 + 1):
                if nr == r and nc == c:
                    continue
                q = base + nc
                if comp[q] == -1 and grid[nr][nc] == '#':
                    comp[q] = 0
                    stack.append(q)

    # sizes[component_id] is the number of black pixels.
    # Component 0 is the outside region.
    sizes = [0]
    sizes[0] = sum(1 for p in range(n) if comp[p] == 0)

    # 2. Label every remaining black component.
    for r in range(H):
        base = r * W
        for c in range(W):
            p = base + c
            if grid[r][c] != '#' or comp[p] != -1:
                continue

            cid = len(sizes)
            sizes.append(0)
            comp[p] = cid
            stack = [p]
            size = 0

            while stack:
                q = stack.pop()
                size += 1
                qr = q // W
                qc = q - qr * W

                r0 = max(0, qr - 1)
                r1 = min(H - 1, qr + 1)
                c0 = max(0, qc - 1)
                c1 = min(W - 1, qc + 1)

                for nr in range(r0, r1 + 1):
                    nbase = nr * W
                    for nc in range(c0, c1 + 1):
                        if nr == qr and nc == qc:
                            continue
                        nq = nbase + nc
                        if grid[nr][nc] == '#' and comp[nq] == -1:
                            comp[nq] = cid
                            stack.append(nq)

            sizes[cid] = size

    # 3. Flood-fill all white components with 4-connectivity.
    seen = bytearray(n)
    holes = [0] * len(sizes)

    for r in range(H):
        base = r * W
        for c in range(W):
            start = base + c
            if grid[r][c] != '.' or seen[start]:
                continue

            seen[start] = 1
            stack = [start]

            touches_outside = False
            candidate = -1
            multiple_marks = False

            while stack:
                p = stack.pop()
                pr = p // W
                pc = p - pr * W

                # Up
                if pr > 0:
                    q = p - W
                    if grid[pr - 1][pc] == '.':
                        if not seen[q]:
                            seen[q] = 1
                            stack.append(q)
                    else:
                        cid = comp[q]
                        if cid == 0:
                            touches_outside = True
                        elif sizes[cid] > 1:
                            if candidate == -1:
                                candidate = cid
                            elif candidate != cid:
                                multiple_marks = True

                # Down
                if pr + 1 < H:
                    q = p + W
                    if grid[pr + 1][pc] == '.':
                        if not seen[q]:
                            seen[q] = 1
                            stack.append(q)
                    else:
                        cid = comp[q]
                        if cid == 0:
                            touches_outside = True
                        elif sizes[cid] > 1:
                            if candidate == -1:
                                candidate = cid
                            elif candidate != cid:
                                multiple_marks = True

                # Left
                if pc > 0:
                    q = p - 1
                    if grid[pr][pc - 1] == '.':
                        if not seen[q]:
                            seen[q] = 1
                            stack.append(q)
                    else:
                        cid = comp[q]
                        if cid == 0:
                            touches_outside = True
                        elif sizes[cid] > 1:
                            if candidate == -1:
                                candidate = cid
                            elif candidate != cid:
                                multiple_marks = True

                # Right
                if pc + 1 < W:
                    q = p + 1
                    if grid[pr][pc + 1] == '.':
                        if not seen[q]:
                            seen[q] = 1
                            stack.append(q)
                    else:
                        cid = comp[q]
                        if cid == 0:
                            touches_outside = True
                        elif sizes[cid] > 1:
                            if candidate == -1:
                                candidate = cid
                            elif candidate != cid:
                                multiple_marks = True

            if not touches_outside and candidate != -1 and not multiple_marks:
                holes[candidate] += 1

    # 4. Translate the number of holes into A, B, or C.
    ans = [0, 0, 0]

    for cid in range(1, len(sizes)):
        if sizes[cid] == 1:
            continue

        if holes[cid] == 1:
            ans[0] += 1       # A
        elif holes[cid] == 2:
            ans[1] += 1       # B
        elif holes[cid] == 0:
            ans[2] += 1       # C

    print(*ans)

if __name__ == "__main__":
    solve()
```最初の塗りつぶしでは 8 方向が使用されます。これは、問題が水平および垂直の接続に加えて斜めの接続を使用して外側領域を定義しているためです。 から開始`(0, 0)`すべての境界ピクセルがその領域に属するため、これで十分です。 

2 番目の黒い塗りつぶしは、残りのすべてのコンポーネントにラベルを付けます。 そのサイズは、マークの可能性をノイズから区別するために必要な唯一の情報です。 すべての本物のマークには複数の黒ピクセルが含まれているため、シングルトンの黒コンポーネントはマークにはなりません。 

白い塗りつぶしは意図的に 4 つに接続されています。 白色コンポーネントの処理中に、コードは外側の黒い領域であるコンポーネント 0 に触れているかどうかを記録します。 普通の石の表面には常にそのようなつながりがあります。 囲まれたマークの内側にはありません。 

の`candidate`変数は、白領域を所有できる唯一の非ノイズ黒コンポーネントを記録します。 この決定を行う際、ノイズ ピクセルは無視されます。 ノイズ ピクセルは、マークのアイデンティティを変えることなく、通常の白い表面の内部、またはマークの白い内部の内部にさえ存在する可能性があるため、これは重要です。 

再帰は使用されません。 再帰的な塗りつぶしは、長いコリドーを含むグリッド上で Python の再帰制限を超える可能性があります。 明示的なスタックにより、メモリ使用量も予測可能になります。 Python 整数は一時的な DFS スタックでのみ使用されますが、コンポーネント ラベルはコンパクトな形式で保存されます。`array('i')`。 

Python では整数オーバーフローの問題はありません。 関連する最大のインデックスは 100 万未満で、すべてのコンポーネントのサイズは最大でも 100 万です。 

## 実用的な例

 ### サンプル 1

 指定されたサンプルには、外側の 8 接続の黒い領域が削除された後の 2 つの本物のマークが含まれています。 1 つの黒いコンポーネントには 2 つの囲まれた白いコンポーネントがあり、もう 1 つの黒いコンポーネントには 1 つの囲まれた白いコンポーネントがあります。 孤立した黒画素はノイズであり、文中のC字パターンは外側の領域とつながっているため破棄する。 

| ステージ | オブジェクト | ブラックサイズ | 同封の白いコンポーネント | 分類 |
 | --- | --- | --- | --- | --- |
 | 黒の洪水塗りつぶし | 写真 黒い洪水塗りつぶし 地域外 | たくさん | 考慮されていません | 外側 |
 | 黒のコンポーネント | 左のマーク | 1 より大きい | 2 | B |
 | 黒のコンポーネント | その他の純正マーク | 1 より大きい | 1 | あ |
 | 黒のコンポーネント | 孤立したノイズ | 1 | 無視 | ノイズ |
 | 黒のコンポーネント | C型外側パターン | 外側の部分 | 考慮されていません | 外側 |

 最終的なカウントは、`A = 1`、`B = 1`、 そして`C = 0`、与える`1 1 0`。 

このトレースの便利な点は、分類がマークの幅や高さに依存しないことです。 パラメータが別のマークと異なる場合でも、2 つの穴があれば B を識別するのに十分です。

## テストケース

 次のテストでは、提出されたソリューションと同じコンポーネントとホールカウント ロジックを使用します。 1 つ目は提供されたサンプルをチェックし、2 つ目はマークなしの最小寸法をチェックし、3 つ目は同じ画像内にいくつかの B 字型マークを配置し、4 つ目は最大サイズのオールブラック画像をチェックします。```python
import io
import sys
from array import array

def run(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    W, H = map(int, input().split())
    grid = [input().strip() for _ in range(H)]
    n = W * H

    comp = array('i', [-1]) * n

    stack = [0]
    comp[0] = 0

    while stack:
        p = stack.pop()
        r, c = divmod(p, W)

        for nr in range(max(0, r - 1), min(H - 1, r + 1) + 1):
            for nc in range(max(0, c - 1), min(W - 1, c + 1) + 1):
                if nr == r and nc == c:
                    continue
                q = nr * W + nc
                if comp[q] == -1 and grid[nr][nc] == '#':
                    comp[q] = 0
                    stack.append(q)

    sizes = [sum(1 for x in comp if x == 0)]

    for r in range(H):
        for c in range(W):
            p = r * W + c
            if grid[r][c] != '#' or comp[p] != -1:
                continue

            cid = len(sizes)
            comp[p] = cid
            stack = [p]
            size = 0

            while stack:
                q = stack.pop()
                size += 1
                qr, qc = divmod(q, W)

                for nr in range(max(0, qr - 1), min(H - 1, qr + 1) + 1):
                    for nc in range(max(0, qc - 1), min(W - 1, qc + 1) + 1):
                        if nr == qr and nc == qc:
                            continue
                        nq = nr * W + nc
                        if grid[nr][nc] == '#' and comp[nq] == -1:
                            comp[nq] = cid
                            stack.append(nq)

            sizes.append(size)

    seen = bytearray(n)
    holes = [0] * len(sizes)

    for r in range(H):
        for c in range(W):
            start = r * W + c
            if grid[r][c] != '.' or seen[start]:
                continue

            seen[start] = 1
            stack = [start]
            outside = False
            candidate = -1
            multiple = False

            while stack:
                p = stack.pop()
                pr, pc = divmod(p, W)

                for nr, nc in (
                    (pr - 1, pc),
                    (pr + 1, pc),
                    (pr, pc - 1),
                    (pr, pc + 1),
                ):
                    if not (0 <= nr < H and 0 <= nc < W):
                        continue

                    q = nr * W + nc

                    if grid[nr][nc] == '.':
                        if not seen[q]:
                            seen[q] = 1
                            stack.append(q)
                    else:
                        cid = comp[q]
                        if cid == 0:
                            outside = True
                        elif sizes[cid] > 1:
                            if candidate == -1:
                                candidate = cid
                            elif candidate != cid:
                                multiple = True

            if not outside and candidate != -1 and not multiple:
                holes[candidate] += 1

    ans = [0, 0, 0]
    for cid in range(1, len(sizes)):
        if sizes[cid] == 1:
            continue
        if holes[cid] == 1:
            ans[0] += 1
        elif holes[cid] == 2:
            ans[1] += 1
        elif holes[cid] == 0:
            ans[2] += 1

    sys.stdin = old_stdin
    return " ".join(map(str, ans))

 | --- | --- | --- |

 ## 特殊なケース

 外側の黒い領域は最初の塗りつぶしによって処理されます。 塗りつぶしは境界線で開始され、8 方向すべてを使用するため、水平、垂直、または対角線の接触によって境界線に接続されたすべての黒ピクセルはコンポーネント ID 0 を受け取ります。 視覚的には C に似ていますが、この領域に属する黒い形状は、後の分類段階には到達しません。 

シングルトン ノイズ ピクセルは、黒成分のサイズ チェックによって処理されます。 ノイズ ピクセルが大きな白い表面で囲まれていると仮定します。 黒いコンポーネントのサイズは 1 であるため、隣接する白いコンポーネントは穴を数えるときに意図的に無視されます。 本物のマークはコンポーネントが大きいため、囲まれた白い領域もカウントされます。 

囲まれた白い領域がないマークは C に分類されます。そのようなマークの周囲の白い部分は、通常の石の表面を介して外側の黒い領域に接しているため、穴としてカウントされません。 マーク自体は非ノイズブラックコンポーネントとして残り、ホールカウントゼロを受け取ります。 

1 つの囲まれた白い領域を持つマークは A として分類されます。白い塗りつぶし中、囲まれた領域は外側の黒いコンポーネントに到達できないため、`touches_outside`偽のままです。 A コンポーネントに触れると、次のようになります。`candidate`、そのコンポーネントの穴の数は 1 に増加します。 

2 つの囲まれた白い領域を持つマークは B として分類されます。2 つの内部は別個の 4 接続の白いコンポーネントであるため、白のスキャンはそれらを独立して検出します。 それぞれ、同じ黒コンポーネントの穴の数が増加し、2 のままになります。 最終的な分類では B が生成されます。 

白塗りつぶしは 4 方向のみを使用するため、斜めの白接触は領域を結合することはできません。 これは石の表面の定義と一致し、斜めのタッチによって実際の穴が破壊されるのを防ぎます。 

画像には多数のノイズ ピクセルが含まれる場合があります。 たとえ 1 つおきのピクセルが孤立したノイズであるとしても、各黒成分は 1 回検出され、それぞれのサイズは 1 であり、答えに寄与するものはありません。 総作業量はピクセル数において線形のままです。 

グリッドは完全に黒にすることもできます。 その場合、最初の塗りつぶしが画像全体を消費し、他の黒いコンポーネントは存在せず、処理する白いコンポーネントもありません。 答えは正解です`0 0 0`。 

グリッドには、多数の個別の石やマークを含めることもできます。 各白コンポーネントは依然として 1 回だけ処理され、各マークはそれに属する囲まれた白コンポーネントに対してのみ課金されます。 グリッド全体のマークごとのスキャンは必要ありません。これがアルゴリズムを O(WH) に保つ特性です。
