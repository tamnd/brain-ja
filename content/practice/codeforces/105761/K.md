 ## 解決策
 ## 問題の理解

 1 から n までの位置がラベル付けされた円形のボードが与えられます。 トークンは位置 1 から始まります。各移動は、1 から d までの面を持つ公平なサイコロを転がし、円に沿って同じステップ数だけ前進することで構成されます。 n を超えると 1 に戻ります。 

一部のポジションは特殊です。 トークンが勝ちの位置に着くと、ゲームは勝ちですぐに終了します。 負けた位置に着地した場合、ゲームは即座に負けで終了します。 他の位置では、ゲームは別のロールで続行できます。 

タスクは、位置 1 から開始して、プロセスが最終的に勝利に終わる確率を計算することです。答えは、法 10007 の剰余分数として出力する必要があります。つまり、確率が p/q の場合、q の剰余逆数の p 倍を法 10007 で出力します。 

重要な点は、一定の移動回数を超えてもゲームが停止しないことです。 これは特定の状態で吸収する確率過程であるため、正しい観点は吸収ノードを含む円グラフ上のマルコフ過程です。 

n ≤ 50 および d ≤ 120 という制約は、状態空間が非常に小さいことを直ちに示唆しています。 n に 3 次またはわずかに超 3 次依存性を持つ解はどれでも受け入れられます。 ただし、パスの数は深さとともに指数関数的に増加し、理論的には終了時間に制限がないため、すべてのランダム ウォークの単純なシミュレーションは不可能です。 

微妙なエッジ ケースは、位置 1 自体が最終状態である場合です。 ポジション 1 が勝っている場合、答えはすぐに 1 になります。 負けていれば即答は0です。 もう 1 つの重要なエッジ ケースは、ある状態から出るすべての遷移が常に終端状態につながる場合です。この場合、再発は浅くなりますが、それでも即時吸収を正しく処理する必要があります。 

## アプローチ

 直接的なアイデアは、各ポジションから勝つ確率を定義し、シミュレーションまたは動的探索によって計算しようとすることです。 位置 i から、考えられるすべてのサイコロの出目を考慮し、前に進み、結果を再帰的に計算します。 これにより正しい再帰が生成されますが、ステップごとに d 個の可能性に分岐し、状態を何度も再訪します。 ボードは循環的であるため、再帰には循環があり、f[i] は将来の f[j] の値に依存し、その値も f[i] に依存するため、単純なメモ化では依存関係がきれいに解決されません。 これにより、連立方程式を解くことなく、再帰状態に対する単純な DP が無効になります。 

重要な観察は、各位置が他のすべての位置と一定の線形関係を持っているということです。 f[i] を i から開始して最終的に勝つ確率として定義すると、各 f[i] は、f[i] が 0、1、または別の f[j] のすべてのサイコロの出目の平均に等しいという形式の線形方程式を満たします。 これにより、問題は 10007 を法とする有限体上の n 連立一次方程式を解くことになります。 

n は最大 50 であるため、ガウス消去法で十分です。 各方程式には最大 d 個の項が含まれており、O(n^3) 内の変数を削除しますが、これは制約の下では自明です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | メモ化によるブルート再帰 | 指数 | O(n) | 遅すぎると循環依存関係が壊れます。 
| ガウス消去法による線形システム | O(n^3) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 各位置 i を未知の f[i] でモデル化し、i から開始して最終的に勝利に達する確率を表します。

1. すべてのポジションを勝ち、負け、または通常に分類します。 勝ちの位置は固定値 1 を持ち、負けの位置は固定値 0 を持ちます。これにより、これらの状態から未知数が削除され、通常の状態の方程式のみが残ります。 
2. 通常の位置 i ごとに、1 つのサイコロの目を展開して方程式を書きます。 i から、1 から d までの各結果 s は、位置 j = i + s (mod n) につながります。 j が勝っている場合、期待値に 1 が寄与します。 j が負けている場合は 0 を寄与します。j が正常な場合は f[j] を寄与します。 
3. すべての遷移に d の逆剰余を掛けて、確率が 10007 を法とする算術係数になるようにします。これにより、期待値が線形結合に変換されます。 
4. すべての未知の f[j] 項が左側にあり、定数が右側にあるように方程式を再配置します。 これにより、線形システム A * f = b が形成されます。 
5. モジュロ 10007 に対してガウス消去法を実行して、すべての f[i] を解きます。 10007 は素数であるため、ゼロ以外のすべての要素には逆数があり、消去が有効になります。 
6. ゲームは位置 1 から始まるため、最終的な答えは f[1] になります。 

重要な考え方は、各状態が他の状態に線形的に寄与しており、確率間に非線形の相互作用は存在しないということです。 これにより、確率的プロセス全体が決定論的な線形代数システムを解くことと同等になります。 

### なぜ効果があるのか

 システムは、すべての状態について正確な確率保存をエンコードします。 各方程式は、最初の手を条件とする合計確率の法則を表します。 すべての将来の状態は同じ一連の方程式によって完全に決定されるため、システムの解はすべての確率的遷移を一貫して満たす必要があります。 吸収状態は境界条件を修正し、曖昧さを取り除き、システム内の特異なドリフトを防ぎます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10007

def modinv(x):
    return pow(x, MOD - 2, MOD)

def gauss(a, b, n):
    for col in range(n):
        pivot = col
        while pivot < n and a[pivot][col] == 0:
            pivot += 1
        if pivot == n:
            continue
        a[col], a[pivot] = a[pivot], a[col]
        b[col], b[pivot] = b[pivot], b[col]

        inv = modinv(a[col][col])
        for j in range(col, n):
            a[col][j] = a[col][j] * inv % MOD
        b[col] = b[col] * inv % MOD

        for i in range(n):
            if i != col and a[i][col]:
                factor = a[i][col]
                for j in range(col, n):
                    a[i][j] = (a[i][j] - factor * a[col][j]) % MOD
                b[i] = (b[i] - factor * b[col]) % MOD

def main():
    n, d, w, l = map(int, input().split())

    win = [False] * n
    lose = [False] * n

    for _ in range(w):
        x = int(input()) - 1
        win[x] = True
    for _ in range(l):
        x = int(input()) - 1
        lose[x] = True

    idx = [-1] * n
    vars_count = 0
    for i in range(n):
        if not win[i] and not lose[i]:
            idx[i] = vars_count
            vars_count += 1

    if win[0]:
        print(1 % MOD)
        return
    if lose[0]:
        print(0)
        return

    m = vars_count
    a = [[0] * m for _ in range(m)]
    b = [0] * m

    invd = modinv(d)

    for i in range(n):
        if idx[i] == -1:
            continue
        row = idx[i]
        a[row][row] = 1

        for s in range(1, d + 1):
            j = (i + s) % n
            coef = invd
            if win[j]:
                b[row] = (b[row] + coef) % MOD
            elif lose[j]:
                continue
            else:
                a[row][idx[j]] = (a[row][idx[j]] - coef) % MOD

    gauss(a, b, m)

    print(b[idx[0]] % MOD)

if __name__ == "__main__":
    main()
```この実装では、非終端状態ごとに 1 つの方程式が構築されます。 各方程式は f[i] の係数 1 から始まり、他の非終端状態への遷移の寄与を差し引きます。 勝利状態への遷移は定数ベクトル b に吸収されますが、敗北状態は何も寄与しません。 

ガウス消去は行列上でその場で実行されます。 逆モジュラーはピボットを正規化するために使用され、各ピボットが 1 になり、それに応じて他の行が削除されます。 

最終出力は、開始状態の解決された値を直接表します。 

## 実用的な例

 ### 例 1

 両面ダイスの 4 セルの円上で、位置 1 がスタート、位置 3 が勝ち、位置 4 が負けている小さなボードを考えてみましょう。 

3 と 4 は終端なので、変数 f[1]、f[2] を定義します。 

位置 2 では、ロールは 3 または 4 につながる可能性があります。したがって、f[2] は 1/2 * 1 + 1/2 * 0 に等しく、f[2] = 1/2 となります。 

位置 1 では、両方の結果が f[2] または最終状態に依存します。 

| 状態 | 方程式 |
 | --- | --- |
 | f[2] | f[2] = 1/2 |
 | f[1] | f[1] = 1/2 * f[2] + 1/2 * 1 |

 f[2] を代入すると、f[1] = 1/2 * 1/2 + 1/2 = 3/4 が得られます。 

このトレースは、ソルバーが同時に処理しているにもかかわらず、端子吸収がどのようにしてより深い状態を最初に単純化するかを示しています。 

### 例 2 (サンプル 1 のスタイル)

 入力は n = 4、d = 6 に対応し、5 での 1 つの勝利状態がシステムに効果的にマッピングされ、既知の最終結果は 4/7 になります。 

| ステップ | f[1] 式 | 解釈 |
 | --- | --- | --- |
 | 初期化 | 不明 | すべての非終端状態は不明 |
 | 方程式の構築 | 6 ムーブにわたるリニア ミックス | 均一なサイコロの展開 |
 | システムを解決する | 単一の分数に変換します | 一貫した固定小数点 |

 この結果は、複数の循環遷移にもかかわらず、線形システムが単一の有理確率に崩壊することを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n^3) | 最大 50 個の変数にわたるガウス消去法が支配的であり、サイコロの遷移は n·d | で線形です。 
| スペース | O(n^2) | 線形システムの係数行列を格納します |

 制約によって n が極めて小さく保たれるため、モジュラー演算のオーバーヘッドがあっても 3 次消去は問題なく制限内に収まります。

 ## 特殊なケース

 位置 1 が勝ちセルの場合、システムは方程式を構築する前に崩壊します。 アルゴリズムはこれを明示的にチェックし、1 を返します。これは、吸収条件が 1 回のロールなしで即座にトリガーされるという事実と一致します。 

位置 1 が負けのセルの場合、同じ理由で答えは 0 になります。 マルコフ連鎖は決して進化し始めることはなく、そうでなければ DP システムは不要になります。 

状態から出るすべての遷移が常に終端セルに到達する場合、対応する方程式には未知数が残りません。 この場合、線形システムの行は定数に減少し、ガウス消去法により変数の係数がゼロである完全に決定された方程式として自然に処理されます。
