 ## 解決策
 ## 問題の理解

 X 軸の上に軸に沿って配置された長方形の建物で構成されるスカイラインのような都市が与えられます。 各建物は、ある x 座標から始まり、一定の幅だけ右に伸び、指定された高さまで垂直に上昇します。 建物は面積的に重なり合うことはありませんが、端で接触する場合があります。 

キャタピラは地表 y = 0 の原点から開始し、点 (100, 0) に到達する必要があります。 地面、建物の垂直の壁、水平な屋根に沿ってのみ這います。 建物に遭遇すると、左の壁を登り、屋根を横切り、右の壁を降り、すべての建物が結合した輪郭に沿って左から右に移動します。 

タスクは、水平移動と垂直移動の両方を含む、この歩行に沿って移動した合計距離を計算することです。 

各建物は、開始 x 位置 s、幅 w、および高さ h によって定義されます。 建物は、x 軸に沿って、y = 0 から y = h までの間隔 [s, s + w] を占めます。 

重要な観察は、キャタピラの経路がまさにすべての建物によって形成される地平線の上部包絡線に、建物が存在しない最初と最後の地面セグメントを加えたものであるということです。 したがって、問題は、x 軸とスカイラインに沿ってトレースされた境界曲線の全長を計算することに帰着します。 

制約は小さく、建物の数は最大 50 です。 これにより、高度な空間データ構造や高度な最適化によるスイープの必要性が即座に排除されます。 O(n²) または O(n² log n) 推論でも快適に安全です。 主な課題はパフォーマンスではなく、重複する水平セグメントを正しくマージし、垂直遷移を考慮することです。 

いくつかの特殊なケースが重要です。 

2 つの建物が X 範囲で重なっている場合、最大の高さのみが屋根に寄与しますが、スカイラインが上昇または下降する垂直壁には両方が寄与する場合があります。 たとえば、(0, 10, 2) と (1, 9, 5) を考えてみましょう。 スカイラインは、x = 1 で 0 から 5 に上昇し、x = 10 で 5 から 0 に下がります。各建物を個別に追加する単純なアプローチでは、内部構造が二重にカウントされ、間違ったパスが生成されます。 

建物がちょうど x = 10 で終わり、次の建物が x = 10 で始まるなど、エッジで正確に接触している場合、その境界では垂直方向の動きはありません。 不用意に実装すると、誤って幅ゼロの「ギャップ遷移」を追加したり、垂直セグメントを二重にカウントしたりする可能性があります。 

最後に、ある領域に建物が存在しない場合、キャタピラは y = 0 に沿って歩きます。これは水平方向の距離のみに寄与しますが、垂直方向の成分を導入してはなりません。 

## アプローチ

 この問題を考えるための直接的かつ正しい方法は、スカイラインの構築を明示的にシミュレートすることです。 X 軸を離散化し、小さなステップごとに、そのセグメントをカバーする建物の最大高さを計算できます。 パスの長さは、水平ステップと隣接セグメント間の垂直ジャンプの合計になります。 これは概念的には簡単です。高さプロファイル関数 h(x) を構築し、その周囲のような横断コストを計算します。 

ただし、座標が大きい場合、高解像度での離散化は不要であり、非効率となる可能性があります。 この問題では、座標が十分小さいため、強引な離散化でも問題なく通過できますが、構造がわかりにくくなります。 

より原則的なアプローチは、スカイラインが建物の境界、つまり各 s および s + w でのみ変化することを理解することです。 これらの点の間では、高さは一定です。 これは、X 軸を臨界点のソートされたリストに圧縮し、各間隔の最大高さを計算して、遷移を測定できることを意味します。 

強引なアイデアは、すべての小さな x について、x をカバーするすべての建物の最大の高さを計算し、遷移を合計するというものです。 これは O(U · n) です。ここで、U は 100 までの座標範囲です。最悪の一般化では、これは非常に遅くなりますが、ここではそれは簡単です。

最適化された推論は、連続スキャンを間隔推論に置き換えます。 すべてのセグメントのエンドポイントを収集し、並べ替えて、間隔ごとの高さを評価します。 n は最大 50 であるため、間隔ごとにすべての建物をチェックするのは継続的な作業です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | x = 0..99 にわたるブルート フォース スキャン | O(100・n) | お(1) | 承認済み |
 | インターバル圧縮 | O(n² log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 関心のあるすべての X 座標の間のセグメントに焦点を当てて、スカイラインを段階的に構築します。 

1. すべての建物エンドポイント s および s + w を収集します。 スカイラインの高さを変えることができるのはこれらの場所だけです。 連続する端点間の間隔は一定の高さになります。 
2. これらの座標を並べ替えて重複を削除し、圧縮された座標リストを作成します。 これにより、スカイラインの高さが固定される互いに素な間隔 [x[i], x[i+1]] が得られます。 
3. 区間ごとに、その区間をカバーする建物の最大高さを計算します。 水平スパンが交差する場合、建物はその区間をカバーします。 目に見える最も高い構造のみが上部の境界を決定するため、最大値を採用します。 
4. 次に、歩行距離を計算します。 区間ごとに、地上レベルでの x[i+1] − x[i] に等しい水平距離と、おそらく垂直遷移によって暗黙的に処理される追加の構造を追加します。 
5. 垂直方向の動きを考慮して、連続する間隔間の高さの変化を追跡します。 高さが増加すると、キャタピラはその差を登ります。 減少すれば減少します。 
6. 合計の答えは、すべての水平間隔の長さと、連続するスカイラインの高さの間のすべての絶対差の合計です。 

重要な点は初期化です。高さ 0 から開始し、最初のゼロ以外の高さによって地面から垂直に上昇します。 

これが機能する理由は、キャタピラの経路が x に沿って投影されたとき、正確に長方形の結合の周囲であるという事実に基づいています。 スカイライン関数は上部境界をエンコードし、高さのすべての変化は境界の垂直セグメントに対応します。 水平セグメントは間隔の幅に正確に対応します。 建物はエリア内で重なり合わないため、セグメントが二重にカウントされたり、欠落したりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    buildings = []
    xs = set()

    for _ in range(n):
        s, w, h = map(int, input().split())
        buildings.append((s, s + w, h))
        xs.add(s)
        xs.add(s + w)

    xs = sorted(xs)

    def height_at_interval(l, r):
        best = 0
        for s, e, h in buildings:
            if not (e <= l or s >= r):
                best = max(best, h)
        return best

    prev_h = 0
    ans = 0

    for i in range(len(xs) - 1):
        l, r = xs[i], xs[i + 1]
        h = height_at_interval(l, r)

        ans += (r - l)
        ans += abs(h - prev_h)
        prev_h = h

    ans += prev_h
    print(ans)

if __name__ == "__main__":
    solve()
```この実装は、間隔圧縮のアイデアに直接準拠しています。 座標のセットにより、変化が発生する可能性のある間隔のみを評価することが保証されます。 間隔ごとに、すべての建物をチェックして最大高さを再計算します。制約が小さい場合はこれで十分です。 

変数`prev_h`前の間隔の高さを追跡するため、変更があれば垂直方向の寄与が生じます。 最後に追加したのは、`prev_h`最後に地上に戻る原因となります。 

微妙な点は、キャタピラが常に地面または屋根に沿って各セグメントの X スパンを正確に 1 回横断するため、水平移動は高さに関係なく常に間隔ごとにカウントされることです。 これが理由です`(r - l)`が常に追加されます。

 ## 特殊なケース

 重要なエッジケースは、境界でのみ接している建物です。 たとえば:

 入力:```
2
0 10 3
10 10 4
```x = 10 では、建物間で共有される水平方向の隙間も垂直方向の壁もありません。 このアルゴリズムは、高さ 3 の [0,10] と高さ 4 の [10,20] を正しく処理し、境界に 1 つの垂直立ち上がりを生成します。 間隔を分割することで遷移が 1 回だけ確実にキャプチャされるため、二重にカウントされることはありません。 

もう 1 つのエッジ ケースは、建物がより高い建物の中に完全に含まれている場合です。 

入力:```
2
0 20 5
5 5 2
```内部の建物はスカイラインにまったく影響を与えません。 高さ関数はすべての間隔にわたって 5 のままであるため、オーバーラップ内で垂直方向の遷移は発生しません。 このアルゴリズムは、寄与を合計するのではなく、常に間隔ごとに最大の高さを取得するため、内部構造を正しく無視します。
