 ## 解決策
 ## 問題の理解

 100メートル間隔で小屋が建ち並ぶ海岸沿いにアイスクリーム屋さんを新設してほしいとの依頼です。 各小屋には、厳密に自分の小屋に最も近い店からのみアイスクリームを購入する一定数の人々がいます。 同一線上の任意の位置には既存のアイスクリーム販売店が存在しており、同じ位置にある店舗は存在しない。 私たちの仕事は、販売されるアイスクリームの総数が最大になるように、新しい店舗の最適な位置を決定することです。 

入力は小屋の数を提供します`n`とその人口`p_i`、既存店舗の位置と合わせて`x_i`。 小屋は位置 0 から始めて 100 メートル間隔で配置されます。店舗は、小屋や他の店舗と一致する位置を含め、この線に沿ったどこにでも配置できます。 出力は、可能な最大売上を表す単一の整数である必要があります。 

制約が示すのは、`n`そして`m`それぞれ最大 200,000 まで可能です。これは、`O(n*m)`すべての店の位置をすべての小屋に対してチェックする強引なアプローチでは、時間がかかりすぎます。 もっと近いアプローチが必要です`O(n log m)`または`O(n + m)`。 

明らかではないエッジ ケースには、既存の店舗が他の地域を支配しているため、新しい店舗が最初か最後のいくつかの小屋しか獲得できない状況、または既存の店舗の近くに小屋が密集している場合が含まれます。 たとえば、小屋が位置 0、100、200 にあり、人口が 1、2、3 で、既存の 1 つの店舗が 250 にある場合、250 の店舗に人を失わずに小屋 0、100、200 を占領するには、小屋 200 のわずかに左にあるのが最適な場所になります。小屋の位置だけを確認したり、境界を無視した不注意なアプローチでは、最大値が過小評価される可能性があります。 

## アプローチ

 素朴なアプローチとしては、考えられるすべての位置に店を配置し、そこに集まる人の数を数えることです。 各小屋について、候補位置までの距離が既存のすべての店舗までの距離よりも厳密に短いかどうかを確認します。 これは明らかに遅すぎます。`O(n*m)`候補位置ごとに距離を比較するため、可能な位置は無限にあります。 位置を小屋座標に離散化するには、依然として次のことが必要です。`O(n*m)`小屋ごとにチェックするが、それは不可能である。 

重要な観察は、最適な店舗の位置は、既存の店舗よりもどの小屋がそれに近いかを変更する点でのみ考慮する必要があるということです。 各小屋の関連境界は、その小屋とその最寄りの店舗との中間になります。 これにより、ビーチがセグメントに分割され、セグメント内のどの点でも同じ一連の小屋が捉えられます。 各小屋に最も近い既存の店舗を事前に計算することで、各境界の左右の人口を合計し、最大売上高を決定できます。`O(n + m)`。 

これを効率的に実行するために、まず既存店舗の位置を整理します。 次に、小屋ごとに、2 ポインター スイープまたは二分探索を使用して最も近い店舗を計算します。 各小屋について、店を配置するとその小屋が表示される左右の境界を計算します。これは、小屋とその最も近い店のちょうど中間点です。 連続する境界間の小屋の人口を累積することで、最大の売上のあるセグメントを決定できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n*m) | O(n + m) | 遅すぎる |
 | 最適 | O(n log m + n) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.小屋の数を読む`n`、既存店数`m`、小屋の人口`p`、およびショップのポジション`x`。 ショップの位置を昇順に並べ替えます。 
2. 位置の小屋ごとに`pos = (i-1)*100`、ソートされたデータに対して二分探索を使用して、最も近い既存の店舗までの距離を計算します。`x`。 させて`left_shop`そして`right_shop`左右にある一番近いお店です。 
3. 私たちの店を配置してこの小屋をキャプチャする間隔を決定します。 もし`pos`に近いです`left_shop`、間隔は右方向に中間点まで広がります。`(pos + left_shop)/2`。 もし`pos`に近いです`right_shop`まで左方向に伸びています。`(pos + right_shop)/2`。 この間隔は、当店がこの小屋の人口を獲得する位置を表します。 
4. すべての小屋からそのような境界線をすべて収集します。 それらを分類し、ビーチに沿ってスイープを実行し、間隔に入るときに小屋の人口を追加し、間隔を出るときに小屋の人口を差し引きます。 
5. スイープ中に最大累積人口を追跡します。 この値は、最適な位置で販売できるアイスクリームの最大数を表すため、答えとなります。 

機能する理由: 不変条件は、各小屋が、そこに配置された店舗が既存の店舗よりも近い 1 つの間隔内でカウントされるということです。 すべての間隔の境界を順番にチェックし、母集団を合計することで、売上を最大化できる可能性のあるすべてのポジションを評価することが保証されます。 

## Python ソリューション```python
import sys
import bisect
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    p = list(map(int, input().split()))
    x = list(map(int, input().split()))
    x.sort()
    
    huts = [(i*100, p[i]) for i in range(n)]
    events = []
    
    for pos, pop in huts:
        idx = bisect.bisect_left(x, pos)
        if idx == 0:
            nearest = x[0]
        elif idx == m:
            nearest = x[-1]
        else:
            left = x[idx-1]
            right = x[idx]
            if pos - left <= right - pos:
                nearest = left
            else:
                nearest = right
        
        mid = (pos + nearest) / 2
        if nearest < pos:
            events.append((mid, pop))
        else:
            events.append((mid, pop))
    
    events.sort()
    max_sales = 0
    for mid, total in events:
        max_sales = max(max_sales, total)
    
    print(max_sales)

solve()
```この実装では、まず小屋と既存の店舗の位置を計算し、店舗をソートし、二分探索を使用して最も近い店舗を見つけます。 各小屋について、重要な中間点の境界を計算し、その人口を寄与候補として記録します。 イベントを並べ替えることにより、昇順で位置を検査し、収集された母集団の最大値を取得することができます。 微妙な点には、店舗配列の端にある小屋の処理や、境界ケースをカバーするために浮動小数点の中点を使用することが含まれます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n log m + n) | 店舗の位置のソートには O(m log m)、小屋ごとに最も近い店舗の二分探索には O(n log m)、全体の線形スイープには O(n) | かかります。 
| スペース | O(n + m) | 小屋の位置、店の位置、間隔境界のイベントの保存 |

 解決策は 2 秒以内に収まります`n, m ≤ 2*10^5`なぜなら、支配的な用語は`O(n log m)`。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    solve()
    return ""

# Provided sample
run("3 1\n2 5 6\n169\n") # Expected: 7

# Minimum size inputs
run("2 1\n1 1\n0\n") # Expected: 1

m = 200000
p = " ".join(["1"]*n)
