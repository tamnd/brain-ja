 ## 解決策
 ## 問題の理解

 私たちの使命は、各参加者から集合場所までの距離の合計が特定のしきい値を超えないように、3 人の友人の任意のペアに会うことができる 2D 平面内の居住点を見つけることです。$r$。 友人たちは 3 つの異なる座標に住んでおり、各会議にはあなたとそのうちの 2 人が参加します。 目標は、最小限の値を決定することです$r$可能な 3 つの会議すべてが実現可能です。 

入力は、友人の家の座標を表す 3 つの整数のペアで構成され、値の範囲は次のとおりです。$-10^4$に$10^4$。 出力は単一の実数、つまり最小値です。$r$、範囲内まで正確$10^{-4}$。 座標は大きくなる可能性があるため、精度をグリッドベースの列挙に依存することはできません。 

エッジ ケースには、最適な居住地が 2 人の友人間の線分上に正確に存在する場合、または 3 人の友人によって形成される三角形が大きく歪んでいるため、単純な重心ベースの推測が不正確になる場合の構成が含まれます。 たとえば、友人が 2 人いる場合、$(0,0)$そして$(10,0)$そして3番目は$(0,10000)$、最小限の$r$は重心ではなく、長い三角形の底辺近くで発生します。 

この問題により、非整数座標を含む平面内の任意の場所に滞留点が存在することが暗黙的に許可されるため、連続空間で機能する方法が必要になります。 

## アプローチ

 ブルートフォース手法では、飛行機を高密度にサンプリングし、3 回の会議の距離の合計を計算することで各候補居住点をテストします。 これは、距離関数が連続であるため機能しますが、中程度の解像度であっても、数百万の候補点と候補ごとに 3 つの距離の合計が必要になります。 サイズの 2D バウンディング ボックスの場合$2 \times 10^4$各次元で、0.01 間隔でサンプリングすると、$4 \times 10^{12}$チェックすることですが、これは明らかに実行不可能です。 

重要な洞察は、距離の合計が各ペアのミーティング ポイントの位置に関して凸であるということです。 より正確には、2 つの不動点の場合$A$そして$B$、関数$f(P) = |P-A| + |P-B|$を結ぶ線分に沿って凸状かつ最小化される$A$そして$B$。 3 ペアの場合、最小値は$r$は、3 つのペアすべての合計のバランスがとれた位置に対応します。 これにより、2D 空間での三分探索の使用が可能になり、候補の居住点を繰り返し調整して 3 つの合計関数の最大値を最小化することができます。 

これにより、問題は平面全体にわたる継続的な最適化に縮小され、各 3 値探索ステップによって不確実性領域が減少し、必要な精度によって結果が正確であることが保証されます。$10^{-4}$。

 ## アルゴリズムのチュートリアル

 1. 関数を定義する`meeting_sum(P, A, B)`点からの距離の合計を計算します`P`2点まで`A`そして`B`。 
2. 関数を定義する`max_sum(P)`3 つの可能な会議のうちの最大会議合計を計算します。`(you, Fabio+Flavio)`、`(you, Fabio+Francesco)`、 そして`(you, Flavio+Francesco)`。 これは、次の制約を捉えています。`r`3 つの会議すべてに対応する必要があります。 
3. 3 人の友人すべてを含む検索四角形を初期化します。 セット`x_low`、`x_high`、`y_low`、`y_high`3 点の境界ボックスとして、最適な点が内側に収まるようにオプションでわずかに拡張します。 
4. で三項検索を実行します。`x`軸:

 - 固定用`x`、三項検索を実行します。`y`を見つけるための軸`y`それは最小限に抑えます`max_sum((x, y))`。 
- 内部の 2 点の値を比較します`y1`そして`y2`、間隔を小さい値に向かって縮小し、間隔が目的の精度より小さくなるまで繰り返します。 
5.最適化後`y`いくつかの`x`三項検索を使用してポイントを選択するには、`x`最小最大合計を与える間隔。 三項検索を繰り返します`x`変化が以下になるまで`10^{-7}`。 
6. 結果として得られる最小値は、`max_sum((x, y))`望ましいです`r`。 

機能する理由: 各ペアの距離和関数はどの直線に沿っても凸であり、凸関数の最大値は準凸のままです。 したがって、2D での三分探索は大域最小値に収束します。 精度限界により、答えが必要な誤差許容度を満たしていることが保証されます。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def distance(a, b):
    dx = a[0] - b[0]
    dy = a[1] - b[1]
    return math.hypot(dx, dy)

def max_sum(P, points):
    x, y = P
    res = 0
    for i in range(3):
        for j in range(i+1, 3):
            d = distance(P, points[i]) + distance(P, points[j]) + distance(points[i], points[j])
            res = max(res, d)
    return res

def ternary_search(points, eps=1e-7):
    x_min = min(p[0] for p in points) - 1
    x_max = max(p[0] for p in points) + 1
    y_min = min(p[1] for p in points) - 1
    y_max = max(p[1] for p in points) + 1

    for _ in range(100):
        x1 = x_min + (x_max - x_min)/3
        x2 = x_max - (x_max - x_min)/3

        def y_search(x):
            ly, ry = y_min, y_max
            for _ in range(100):
                y1 = ly + (ry - ly)/3
                y2 = ry - (ry - ly)/3
                f1 = max_sum((x, y1), points)
                f2 = max_sum((x, y2), points)
                if f1 < f2:
                    ry = y2
                else:
                    ly = y1
            return max_sum((x, (ly+ry)/2), points)

        f1 = y_search(x1)
        f2 = y_search(x2)
        if f1 < f2:
            x_max = x2
        else:
            x_min = x1
    return y_search((x_min + x_max)/2)

def main():
    points = [tuple(map(int, input().split())) for _ in range(3)]
    res = ternary_search(points)
    print(f"{res:.10f}")

if __name__ == "__main__":
    main()
```このソリューションでは、ネストされた三項検索を使用します。内側のループが最適化します。`y`固定用`x`、外側のループは最適化します`x`。 距離の計算には次のものを使用します。`math.hypot`数値の安定のために。 検索ボックスを 1 単位ずつ拡張すると、グローバル最小値がその中に確実に含まれます。
