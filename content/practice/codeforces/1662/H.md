 ## 解決策
 ## 問題の理解

 ベサニーは、長方形のバスルームを特定のパターンでタイル張りしたいと考えています。 境界を除いて内部は標準で覆われている必要があります。$1 \times 1$タイル。 境界は、内部を囲む 1 タイルの厚さのフレームです。 彼女は境界をタイル状に表示したいと考えています。$1 \times a$タイル、ここで$a$は正の整数であり、タイルは 90 度回転できます。 タスクは、次のすべての値を決定することです。$a$この境界タイリングが可能です。 

入力により複数のテスト ケースが提供されます。 各テスト ケースは幅を提供します$w$そして長さ$l$少なくとも両方のバスルームの$3$、したがって、タイルを貼るインテリアが常にあります。 各テスト ケースの出力は有効な数でなければなりません。$a$値自体も昇順で並べられます。 

可能な最大の幅または長さは次のとおりです。$10^9$、タイリングをシミュレートしたり、すべてをチェックしようとするアルゴリズムを除外します。$a$まで$w$または$l$。 除数を効率的に計算し、広い範囲にわたる反復ではなく算術プロパティを使用するソリューションが必要です。 

明らかではないエッジケースが発生するのは次の場合です。$w$または$l$小さいです。 例えば、$w = 3$そして$l = 5$周囲に 12 単位の境界があります。 内部が少なくとも$2 \times 2$タイリング式は有効な最小内部サイズと正しい周囲数を処理する必要があるため、失敗する可能性があります。 

もう 1 つの微妙な点は、タイルを回転できることです。$1 \times a$タイルは幅または長さに沿って配置できます。 これは、タイリングが厳密に各辺で個別に拘束されるのではなく、ユニットの周囲によって拘束されることを意味します。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのことを列挙することになります。$a$から$1$まで$w-1$または$l-1$、それぞれについて$a$かどうかを確認してください$1 \times a$タイルで境界を埋めることができます。 周囲は 2 つの水平ストリップと 2 つの垂直ストリップで構成されます。$2 \cdot (w + l - 4)$合計ユニット数。 それぞれについて$a$すべての境界ユニットが正確にカバーされるような水平配置と垂直配置の組み合わせが存在するかどうかを確認します。 これは原理的には正しいですが、現実的ではありません。$w$そして$l$到達できる$10^9$。 チェック中$10^9$テスト ケースごとの値が遅すぎます。 

重要な洞察は、問題は正の整数を見つけることに帰着するということです。$a$どちらかを分けるもの$w-2$または$l-2$何らかの線形結合で。 より具体的には、境界ユニットの総数を次のように表します。$2(w + l - 4)$。 あ$1 \times a$幅に沿って配置されたタイルは消費します$a$その側に沿ったユニット。 長さに沿って配置すると、消耗します$a$その側にあるユニット。 可分性について推論すると、すべてが有効です$a$～の約数のいずれかです$w-2$、の約数$l-2$、または約数$w+l-2$水平タイリングと垂直タイリングを組み合わせる場合。 境界は一様なので、$a$分割する$w-2$または$l-2$タイルを隙間なく正確にフィットさせることができます。 さらに、$a = 1$常に機能するため$1 \times 1$タイルは任意の長さに並べることができます。 

これにより、効率的な解決策が得られます。つまり、約数を計算します。$w-2$そして$l-2$、1を含めて結合し、並べ替えます。 任意の数の約数の最大数$10^9$十分に小さいため、アルゴリズムは最大 100 個のテスト ケースに対して高速です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(w + l) | お(1) | 遅すぎる |
 | 最適 | テスト ケースごとに O(√w + √l) | O(√w + √l) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. テスト ケースごとに、整数を読み取ります。$w$そして$l$浴室の幅と長さを表します。 
3. コンピューティング$w' = w-2$そして$l' = l-2$、これは内寸です。 
4. 有効なセットを初期化します。$a$値を 1 にします。 
5. すべての約数を求めます$w'$そしてそれらをセットに追加します。 

- ループ$d$2から$\sqrt{w'}$。 
- もし$w' \bmod d = 0$、両方を追加します$d$そして$w'/d$セットへ。 
6. 同じ除数を求めるプロセスを繰り返します。$l'$。 
7. 有効なセットを変換します$a$値をソートされたリストに追加します。 
8. 有効回数を出力$a$その後に値そのものが続きます。 

機能する理由: すべての有効な$a$境界ストリップを正確に並べて表示するには、境界ストリップの少なくとも 1 辺の長さを分割する必要があります。 両方を含む$w-2$そして$l-2$あらゆる組み合わせを捉えます。 セットを使用すると重複が自動的に回避され、並べ替えによって確実に昇順が保証されます。 ステップ 4 により、$a = 1$は常に含まれており、これは自明のことながら有効です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def divisors(n):
    result = set()
    d = 1
    while d * d <= n:
        if n % d == 0:
            result.add(d)
            result.add(n // d)
        d += 1
    return result

t = int(input())
for _ in range(t):
    w, l = map(int, input().split())
    w_interior = w - 2
    l_interior = l - 2
    a_values = set([1])
    a_values.update(divisors(w_interior))
    a_values.update(divisors(l_interior))
    a_list = sorted(a_values)
    print(len(a_list), *a_list)
```の`divisors`この関数は、平方根までループすることにより、数値のすべての約数を効率的に計算します。 両方を追加すると`d`そして`n // d`大小の約数を確実に捕捉します。 セットを使用すると、幅と長さの両方に同じ除数が表示される場合に重複が排除されます。 最後にソートすることで出力要件を満たします。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    def divisors(n):
        result = set()
        d = 1
        while d * d <= n:
            if n % d == 0:
                result.add(d)
                result.add(n // d)
            d += 1
        return result

    t = int(input())
    res = []
    for _ in range(t):
        w, l = map(int, input().split())
        w_interior = w - 2
        l_interior = l - 2
        a_values = set([1])
        a_values.update(divisors(w_interior))
        a_values.update(divisors(l_interior))
        a_list = sorted(a_values)
        res.append(f"{len(a_list)} {' '.join(map(str,a_list))}")
    return "\n".join(res)
