 ## 解決策
 ## 問題の理解

 長方形の頂点に立っている 4 人の出場者を選択する方法の数を数えるように求められます。$n \times n$最年少の 2 人の出場者を 1 つのポールとして使用し、最年長の 2 人の出場者をもう 1 つのポールとして使用してバナーを形成するときに、ポールが交差しないようにグリッドを作成します。 各出場者には明確な年齢があります$1$そして$n^2$, したがって、参加者全員の厳密な合計順序があります。 入力はグリッド内の年齢を示し、出力は単一の整数、つまり有効な 4 倍体の数です。 

グリッドのサイズ$n$まで可能です$1500$、まであることを意味します$2.25 \times 10^6$細胞。 グリッド内のすべての四角形を反復処理する単純なソリューションでは、次のことを考慮する必要があります。$O(n^4)$4 倍の可能性があります。これはおよそ$5 \times 10^{12}$最大の入力に対する操作。 2秒の制限時間ではこれは不可能です。 したがって、すべての四角形を明示的に列挙することを避ける戦略が必要です。 

グリッドが非常に小さい場合、または「交差」条件が頻繁に発生するように年代が配置されている場合、明らかではないエッジ ケースが発生します。 たとえば、$2 \times 2$グリッド：```
1 3
4 2
```4 人の出場者全員が長方形を形成しますが、最年少の 2 人 (1 と 2) と最年長の 2 人 (3 と 4) を選択すると、極が交差するため、有効なカウントは 0 になります。長方形の角に沿った年齢の順序を無視する不用意な解決策では、これが誤って有効としてカウントされます。 

## アプローチ

 ブルート フォースのアプローチは簡単です。グリッド内のすべての可能な四角形を反復処理します。 各長方形について、角の 4 つの年齢を特定して並べ替え、最小の 2 つを一方の極に割り当て、最大の 2 つをもう一方の極に割り当て、結果の極が交差するかどうかを確認します。 これは問題を直接モデル化しているので正しいですが、$O(n^4)$四角形をチェックするのは現実的ではありません$n$1500もの大きさ。 

より迅速な解決を可能にする重要な観察は、行と列に沿った年齢の相対的な順序が、極が交差するかどうかを判断するのに十分であるということです。 2 つの行を固定すると、列のペアごとに、上の行の年齢が下の行の年齢よりも何歳小さいかを数えることができます。 これにより、問題は長方形の列挙から順序付きペアの効率的なカウントへと変換され、複雑さが軽減されます。$O(n^4)$に$O(n^2 \log n)$あるいは$O(n^2)$プレフィックスサムまたはフェンウィックツリーを使用します。 

行のペアをスイープし、行のペアごとに、「古いものよりも若い」条件を満たす列の数を継続的にカウントし、これらのカウントから組み合わせ的に交差しない四角形の数を計算することを想像できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^4) | O(n^2) | 遅すぎる |
 | 行ペアのカウント | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各年齢をグリッド内の座標にマッピングします。 これにより、グリッド全体をスキャンすることなく、任意の 2 つの年齢の位置を迅速に比較することができます。 
2. 年齢のすべてのペアを反復処理します。$(x, y)$そのような$x < y$。 させて$(r_x, c_x)$そして$(r_y, c_y)$彼らの座標になります。 
3. 各ペアについて、他の 2 つの年齢と交差しない有効な長方形を形成する長方形の対角にあることができるかどうかを確認します。 これは、次のように形成される長方形の場合に発生します。$(r_x, c_x)$そして$(r_y, c_y)$他のコーナーの残り 2 つの年齢は、極に沿った最年少/最年長の分割を満たします。 
4. 交差を避けるために必要な順序を満たす行ペア間の列ペアの数を数えます。 これは、ソートされた位置の配列内の反転またはペアをカウントすることになります。 
5. すべての有効な四角形の寄与を合計して、合計数を取得します。 

これが機能する理由: 不変条件は、各長方形について、最年少の 2 名と最年長の 2 名が 1 つの軸に沿って反対側の角を占め、極が交差しないようにする必要があることです。 年齢のペアを昇順に反復処理し、互換性のある列のペアを効率的にカウントすることで、すべての有効な四角形が正確に 1 回カウントされるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
grid = [list(map(int, input().split())) for _ in range(n)]

# Map each age to its (row, col)
pos = [None] * (n * n + 1)
for r in range(n):
    for c in range(n):
        pos[grid[r][c]] = (r, c)

# Initialize a 2D BIT for counting columns
bit = [0] * (n + 1)

def update(idx, val):
    while idx <= n:
        bit[idx] += val
        idx += idx & -idx

def query(idx):
    res = 0
    while idx:
        res += bit[idx]
        idx -= idx & -idx
    return res

ans = 0
for val in range(1, n * n + 1):
    r, c = pos[val]
    # Count rectangles ending at this cell using BIT
    ans += query(c)
    update(c, 1)

print(ans)
```このソリューションは、年齢を昇順に処理し、バイナリ インデックス付きツリーを使用して有効な四角形の数を効率的にカウントすることに依存しています。 各更新では、すでに処理された年齢が含まれているものとして列にマークが付けられ、各クエリでは、現在の年齢とペアになって交差しない四角形を形成できる列の数がカウントされます。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    grid = [list(map(int, input().split())) for _ in range(n)]
    pos = [None] * (n * n + 1)
    for r in range(n):
        for c in range(n):
            pos[grid[r][c]] = (r, c)
    bit = [0] * (n + 1)
    def update(idx, val):
        while idx <= n:
            bit[idx] += val
            idx += idx & -idx
    def query(idx):
        res = 0
        while idx:
            res += bit[idx]
            idx -= idx & -idx
        return res
    ans = 0
    for val in range(1, n * n + 1):
        r, c = pos[val]
        ans += query(c)
        update(c, 1)
    return str(ans)
