 ## 解決策
 ## 問題の理解

 迷路は中心を始点とした極座標で描画されます。 壁を横切ったり触れたりしない限り、どの方向への移動も継続的に許可されます。 目標は、中心から始まり任意の大きな半径に達し、壁によって形成された外側の境界を効果的に回避する連続したパスが少なくとも 1 つ存在するかどうかを判断することです。 

各壁は円形または放射状です。 円形の壁は、特定の角度セグメントの固定半径に沿った動きをブロックします。 直線の壁は、特定の放射状セグメントの固定角度に沿った動きをブロックします。 これらの壁は一緒になって、平面を接続された領域に分割します。原点を含む領域が無限に接続されているかどうかを確認する必要があります。 

これは基本的に、平面サブディビジョンにおける接続性の問題です。 各壁は幾何学的なグラフのエッジのように機能し、壁間の交差により移動の選択肢が分かれる頂点が作成されます。 

半径が最大 20 であるという制約は重要です。 これは、角構造が密集している場合でも、すべての構造が非常に狭い半径範囲に集中していることを意味します。 テストあたり最大 5000 の壁と 20 のテストを使用すると、単純な方法ですべての幾何学的交差を明示的に構築するアプローチは合格する可能性がありますが、これは二次ペアごとの交差処理を回避する場合に限られます。 

壁がある半径で角度方向に完全な囲いを形成する場合、微妙なエッジケースが現れます。 たとえば、同じ半径にあるいくつかの円弧は、個別に 360 度全体に及ぶものがない場合でも、集合的に完全なバリアを形成できます。 同様に、直線セグメントを組み合わせて放射状のセパレーターを形成し、全方向への逃げをブロックすることができます。 各壁を個別にチェックする単純なアプローチでは、これらの組み合わせられたクロージャーを見逃してしまいます。 

もう一つの問題はラップアラウンド角度です。 350° から 10° までの円形の壁は、実際には 0° の境界をまたいでおり、モジュール処理を行わずに角度を直線間隔として扱うと、正確さが損なわれます。 

## アプローチ

 強引なアイデアは、壁間のすべての交点をグラフ ノードとして扱い、壁に沿って隣接するセグメントを接続し、中心から塗りつぶしを試みることです。 壁の各ペアは交差する可能性があり、壁の数は最大 5000 であるため、交差の数は最悪の場合数千万に達する可能性があります。 各壁を交差点ごとに複数のセグメントに分割する必要があるため、隣接関係の生成さえも遅くなりすぎます。 

迷路は平面グラフであり、平面内の接続性は領域間のグラフの接続性に正確に対応するため、このアプローチは正しいです。 ただし、その取り決めを明示的に構築するとコストがかかりすぎます。 

重要な観察は、動径座標が非常に小さいということです。 可能な半径レベルは 20 のみです。これは、連続平面を層状グラフに離散化できることを意味します。 各層は、整数半径間の環に対応します。 各層の内側では、壁は角度の動きのみを制限します。 直線の壁は層内で角度のあるバリアとして機能し、円形の壁は層間の放射状バリアとして機能します。 

このように問題を再解釈すると、タスクは層全体の角度間隔間の接続を構築することになります。 各層は円形のセグメント グラフになり、各壁は接続遷移の制約に影響します。 次に、レイヤー 0 の起点のノードが半径 20 を超える無制限の外部状態に到達できるかどうかを確認します。 

これにより、この問題は、最大約 20 の放射状レイヤーと O(n) 個の角度制約を持つグラフ接続タスクに変換され、幾何学的交差の列挙ではなく並べ替えと間隔スイープで処理できます。

 ## アルゴリズムのチュートリアル

 1. すべての壁を、放射状レイヤーまたは角度セグメント間の遷移の拘束に変換します。 円形の壁は特定の角度間隔で半径を横切る動きをブロックしますが、直線の壁は 2 つの半径の間の角度に沿った動きをブロックします。 
2. すべての角度を [0, 360) で一貫した表現に正規化します。 0° を囲む円形の壁の場合は、それらを 2 つの間隔に分割します。 これにより、すべての角度制約が標準間隔になります。 
3. r と r+1 の間の各放射状レイヤーについて、そのレイヤーを横切る直線の壁によって引き起こされるすべての角度ブロック セグメントを収集します。 それぞれの真っすぐな壁は、放射状のバンドの内側にブロックされた角度間隔を形成します。 
4. これらの角度間隔を並べ替えて、重複部分をマージします。 マージ後、各レイヤーで最大のブロック領域が得られます。 
5. ブロックされた角度間隔がレイヤーの円を完全にカバーしているかどうかを確認します。 任意の半径バンドでブロックされた角度の和集合が 360° をカバーする場合、その層は閉じたリングとなり、ブロックはそれを越えて逃げます。 
6. さらに、円形の壁により放射状のカットが作成されます。 各半径 r について、円弧はブロックされた角度セグメントに寄与し、層 r-1 から r への交差を防ぎます。 これらを、角度を完全にカバーするために同様にチェックする必要があるバリアとして扱います。 
7. 最も内側の領域から開始して、レイヤーを介した外側への横断をシミュレートします。 完全に閉じられた角度の障壁に遭遇することなく、すべての放射状の境界を通過できれば、脱出は可能です。 
8. ブロックされずに最大半径を超えて到達した場合は、YES を出力します。 それ以外の場合は NO を出力します。 

### なぜ効果があるのか

 このアルゴリズムが機能するのは、原点から無限大までのすべての有効なパスが放射状のレイヤーを単調に横断する必要があるためです。 半径は脱出経路に沿って厳密に増加するため、r と r+1 の間の各遷移は、壁によってブロックされていない角度セクターを介して発生する必要があります。 ジオメトリをレイヤーごとの角度範囲に折りたたむことにより、交差が可能な条件を正確に保存します。 どの層でも角度が完全にカバーされているということは、内側と外側の領域を切り離し、脱出を不可能にするジョルダン曲線のような障壁を意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def norm(a):
    a %= 360
    return a

def add_interval(intervals, l, r):
    if l <= r:
        intervals.append((l, r))
    else:
        intervals.append((l, 360))
        intervals.append((0, r))

def merge(intervals):
    if not intervals:
        return []
    intervals.sort()
    res = []
    cur_l, cur_r = intervals[0]
    for l, r in intervals[1:]:
        if l <= cur_r:
            cur_r = max(cur_r, r)
        else:
            res.append((cur_l, cur_r))
            cur_l, cur_r = l, r
    res.append((cur_l, cur_r))
    return res

def covered(intervals):
    total = 0
    for l, r in intervals:
        total += r - l
    return total >= 360

def solve():
    n = int(input())
    layers = [[] for _ in range(21)]

    for _ in range(n):
        parts = input().split()
        t = parts[0]
        if t == 'S':
            r1, r2, th = map(int, parts[1:])
            # straight wall blocks angle th between r1 and r2
            for r in range(r1, r2):
                layers[r].append((norm(th), norm(th)))
        else:
            r, a, b = map(int, parts[1:])
            add_interval(layers[r], a, b)

    for r in range(1, 21):
        intervals = layers[r]
        merged = merge(intervals)
        if covered(merged):
            print("NO")
            return

    print("YES")

if __name__ == "__main__":
    solve()
```直線壁は、半径とは無関係に角度ブロッカーとして機能するため、交差するすべての放射状レイヤーに分散されます。 円形の壁は、角度がブロックされた円弧としてその半径に直接配置されます。 レイヤーごとにすべての制約を収集した後、間隔をマージすると、その半径の円が完全に密閉されているかどうかがわかります。 

重要な実装の詳細は、円弧のラップアラウンド間隔を分割することです。分割しないと、ブロッキング カバレッジが誤って過小評価されるためです。 もう 1 つの微妙な点は、直線の壁を幅ゼロの角度カットとして扱うことです。 これらは線ですが、接続性のために、セグメント内のすべての半径に対してその角度でブロッカーとして機能します。

これは、放射状のセグメントを組み合わせることで、避難経路を徐々に閉鎖できることを示しています。

 ## 特殊なケース

 重要なエッジ ケースは、0° 境界を横切る円形の壁です。 たとえば、350 度から 10 度の壁は 2 つの間隔に分割する必要があります。 それ以外の場合、単純なマージでは、大きなブロック円弧の代わりに小さなセグメントが表示されます。 正しい解釈では、円の大部分をカバーする 2 つの区間として扱われます。 

もう 1 つのエッジ ケースは、複数の直線の壁が結合後に初めて完全にカバーされるまで蓄積されることです。 個別には孤立した角度をブロックしますが、集合的には残りのギャップをすべて閉じることができます。 結合ステップでは、完全なカバレッジをチェックする前に、隣接関係が適切に結合されていることを確認します。 

3 番目のケースは、レイヤーを直接覆う壁がないが、隣接するレイヤー間の組み合わせによって上向きの放射状の横断が妨げられる場合です。 階層化された集約により、各放射状遷移が独立して検証されることが保証されるため、部分的なローカル開口部がグローバル エスケープを誤って暗示することはありません。
