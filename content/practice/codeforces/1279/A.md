 ## 問題の理解

 いくつかの独立したテスト ケースが与えられています。 各テスト ケースでは、赤、緑、青の 3 つの色のランプを記述します。 ここでの課題は、すべてのランプを 1 回だけ使用しながら、隣接する 2 つのランプが同じ色を共有しないように、すべてのランプを 1 列に配置できるかどうかを決定することです。 

言い換えれば、等しいシンボルが決して互いに接触しないような 3 つのシンボルのマルチセットの順列が存在するかどうかを知りたいのです。 各テスト ケースは、そのような再配置の実現可能性をチェックするだけです。 

制約はカウントに対して大きく、最大で$10^9$ただし、テスト ケースの数は少なく、最大 100 です。これにより、シーケンスを明示的に構築したり、配置を段階的にシミュレートしようとするアプローチは即座に除外されます。 建設ベースのシミュレーションには、ランプの総数に比例した時間が必要となり、最悪の場合は数十億にも及ぶ可能性があります。 

問題の構造は、相対周波数のみが重要であることを示唆しています。 最大の山と残りの山との比較を除いて、絶対的なサイズは無関係です。 

いくつかのエッジ パターンについては、早めに検討する価値があります。 

1 つの色が大きく優勢な場合 (たとえば、赤 1 個、緑 10 個、青 2 個)、緑以外のランプをすべて配置した後、他の色によって作られる十分な「ギャップ」が存在しないため、緑を連続して配置することを避ける方法はありません。 

3 3 3 のように、すべてのカウントが等しい場合、有効な交互配置が明らかに存在します。 

2 1 1 など、2 つの色が小さく、1 つがわずかに大きい場合でも、大きい方の色を常に他の色と分離することで、それらをインターリーブすることができます。 

重大な失敗のケースは、最大カウントが他の 2 つの合計と比較して大きすぎる場合です。 

## アプローチ

 ブルートフォース戦略では、明示的に取り決めを構築しようとします。 1 つの方法は、空のシーケンスから開始し、最後に配置されたものとは異なる残りのランプの色を繰り返し配置することです。 各ステップで、前の色を除くすべての使用可能な色を試し、可能であれば 1 つを選択します。 

この貪欲な構築は機能しますが、慎重に実装したとしても、長さが次のシーケンスで動作します。$r + g + b$、次のように大きくすることができます$3 \cdot 10^9$。 それは完全に不可能になります。 このようなシーケンスを保存したり反復したりすることさえ不可能です。 

重要な観察は、問題全体が 1 つの制約によって支配されているということです。同じ色が隣接しないようにするには、十分な「セパレーター」が必要です。 2 つの小さなパイルは一緒に、最大のパイルのセパレーターとして機能します。 

カウントを次のように並べ替えると、$a \ge b \ge c$、最大の色を最初に配置することが考えられます。 このドミナントカラーを連続して配置する間に、少なくとも 1 つの非ドミナントランプが必要です。 つまり、少なくとも$a - 1$利用可能な分離ポジション、それがまさに$b + c$提供します。 

したがって、条件は、最大の山が他の 2 つの山の合計を 1 つ以上上回るかどうかに帰着します。 

より正確に言えば、実現可能性が成立するのは、$a \le b + c + 1$。 

この 1 つの不等式はすべての有効なインターリーブを捕捉し、他のすべてはそこから導き出されます。

 ## アルゴリズムのチュートリアル

 各テスト ケースについて、カウントのみを推論して有効な配置が存在するかどうかを判断します。 

1. 各色のランプの数を表す 3 つの整数を読み取ります。 

正規化するため、最初は順序は関係ありません。 
2. 最大数になるように 3 つの値を並べ替えます。$a$、残りの2つは$b$そして$c$。 

この手順では、隣接問題を引き起こす可能性が最も高い色を特定します。 
3. 最大のカウントが他のカウントと比較して大きすぎるかどうかを確認します。 

具体的には、次のことをテストします。$a > b + c + 1$。 

この不等式が成り立つ場合、「No」を返します。 その理由は、たとえ完全に交互に配置したとしても、小さい 2 つの色が生み出すことしかできないということです。$b + c$これは、最大の色の出現をすべて分離するには不十分です。 
4. それ以外の場合は、「はい」を返します。 

この場合、小さい色は主要な色の出現を分離するのに十分であり、それらを大きいブロック間で分散することにより、常に有効なシーケンスを構築できます。 

### なぜ効果があるのか

 配置の問題は、同一のシンボルを分離するために作成できる「スロット」の数によって完全に制御されます。 有効なシーケンスでは、最も頻繁に出現する色の出現を個別の位置に配置する必要があり、各分割には少なくとも 1 つの異なる色のランプが必要です。 使用可能なセパレータの合計数は、他の 2 色の合計とまったく同じになります。 その合計が小さすぎると、配置に関係なく衝突が避けられなくなります。 それが十分に大きい場合は、2 つの同一の隣接要素を強制することなく、いつでも貪欲にインターリーブすることができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    r, g, b = map(int, input().split())
    a, b1, c = sorted([r, g, b], reverse=True)
    if a > b1 + c + 1:
        print("No")
    else:
        print("Yes")
```この実装は数学的条件を直接反映しています。 並べ替えにより、最も頻繁に使用される色が潜在的なボトルネックとして常に扱われるようになります。 比較`a > b1 + c + 1`ギャップカウントから導き出された不可能条件をエンコードします。 他のすべてはテスト ケースごとに一定時間であるため、このソリューションは最大入力サイズでも非常に効率的です。

 ## 特殊なケース

 微妙なケースは、最大の山が他の山の合計よりちょうど 1 つ多い場合です。 たとえば、4 1 1 は (4, 1, 1) にソートされます。 ここ$b + c = 2$、 そして$a = 4$、 それで$a > b + c + 1$になる$4 > 3$、それは本当なので、それは不可能です。 十分な区切り文字がないため、アルゴリズムはこれを正しく拒否します。 

別のケースは、すべてのカウントが等しい場合です。 5 5 5 の場合、条件は次のようになります。$5 \le 10 + 1$、これは自明に成り立ちます。 構造は循環インターリーブが存在することを保証し、不等式はそれを構築することなくそれを捕捉します。 

2 つの色が 1 つの大きな色と比較して非常に小さい場合でも、ルールは純粋に算術比較によって解決可能なケースと解決できないケースを明確に分離し、明示的な調整の必要性を回避します。
