 ## 解決策
 ## 問題の理解

 私たちには偶数人の生徒が与えられ、それぞれの生徒はプログラミング スキル レベルを持っています。 目標は正確に形を整えることです$n/2$チームにはそれぞれ 2 人の学生が含まれます。 チームは、両方の学生が同じスキルレベルを持っている場合にのみ有効です。 これを達成するために、生徒は問題を解決し、それぞれのスキルを 1 つずつ向上させます。 

入力は次のもので構成されます$n$(生徒の数) とスキルを表す整数の配列。 出力は 1 つの整数です。これは、すべての生徒が同等のスキルを持つチームにペアになるために、生徒が解決する必要がある問題の最小総数です。 

制約は小さいです。$2 \le n \le 100$そして$1 \le a_i \le 100$。 と$n$上限は 100、任意のアルゴリズムは最大 100$O(n^2 \log n)$または$O(n^2)$制限時間内で快適に走ります。 これは、ペアごとの比較アプローチでも実行可能であることを示唆していますが、より単純で直接的なアプローチを目指す必要があります。 素朴な解決策がつまずく可能性のあるエッジ ケースには、複数の重複またはすべてが一意の値があることが含まれます。この場合、問題の最小数には自明でないペアリングが必要になる可能性があります。 

不用意なアプローチは、単に入力順に生徒をペアにすることです。 たとえば、入力の場合`4\n1 3 2 2`、ペアリング`(1,3)`そして`(2,2)`費用がかかる`2`最初のペアについては問題ありませんが、より良い解決策は`(1,2)`そして`(2,3)`費用だけかかるのは`1`。 これはペアリングの順序を示しています。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての組み合わせが考慮されます。$n$学生たち。 がある$(n-1)!!$ペアを形成する方法 (二重階乗) ですが、これは成長の階乗であり、$n=20$。 ペアリングごとに、スキルを均等にするためのコストを計算します。 このアプローチは原理的には正しいですが、計算的には実行不可能です。 

重要な観察は、2 人の生徒を平等にするためのコストは、彼らのスキルの絶対的な違いにのみ依存するということです。 これは、学生をスキル別に分類する場合、隣接する学生をペアにすることでコストが最小限に抑えられることを示唆しています。 並べ替えにより、ペアになった生徒間の差が可能な限り最小になることが保証され、他のペアでは差の合計が増加するだけです。 分類したら、最適な戦略は、最初の生徒と 2 番目の生徒、3 番目の生徒と 4 番目の生徒というようにペアにすることです。 これにより問題は次のように縮小されます$O(n \log n)$ソートプラス用$O(n)$差分を合計するため。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((n-1)!!) | O(n) | 遅すぎる |
 | 最適 (ソート + 隣接ペア) | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む$n$そしてスキルの数々$a$。 並べ替えには、順序付けを可能にするデータ構造が必要です。 リストで十分です。 
2. 配列をソートする$a$降順ではない順に。 これにより、連続する要素間の差異が確実に最小限に抑えられます。 
3. 変数を初期化する`total_cost`ゼロに。 そうすることで、解決すべき問題の数が蓄積されていきます。 
4. 配列を 2 つのステップで繰り返し、ペアリングします$a[i]$と$a[i+1]$。 各ペアについて、次のようにコストを計算します。$a[i+1] - a[i]$そしてそれを追加します`total_cost`。 ソートされた順序でペアリングすると、総コストが最小限に抑えられます。 
5. すべてのペアを処理した後、出力します。`total_cost`。 

機能する理由: 分類後、各生徒は可能な限り最も近いスキル レベルとペアになります。 生徒をクロスペアにしようとすると、小さな差異がより大きな差異に置き換えられ、必要な問題の総数が増加します。 不変条件は、ソート後、連続する要素が全体的に最適な最小差分のペアを形成するということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))
a.sort()

total_cost = 0
for i in range(0, n, 2):
    total_cost += a[i+1] - a[i]

print(total_cost)
```解決策は入力を効率的に読み取ることから始まります。 ソートにより、ペアごとの差異が最小限に抑えられます。 ループは 2 つのステップで反復され、ペアが正しく形成されます。 コンピューティング`a[i+1] - a[i]`各チームに必要な問題の数を直接与えます。 重複や同一のスキルなどのエッジケースには問題は必要なく、減算によって自動的に処理されます。
