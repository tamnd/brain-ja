 ## 解決策
 ## 問題の理解

 文字列のマルチセットが与えられていますが、それらはすべて長さの不明な単一の文字列に由来しています。$n$。 あらゆる長さに対して$k$から$1$に$n-1$、その長さの文字列が 2 つだけ与えられ、それら 2 つの文字列はそれぞれ、非表示文字列の接頭辞または接尾辞のいずれかになります。 

重要な問題は、各弦がどのような役割を果たしているかが分からないことです。 それぞれの長さごとに$k$、1 つの文字列は長さの接頭辞です。$k$、もう 1 つは長さの接尾辞です$k$, しかしその順番は不明です。 タスクは、各入力文字列にプレフィックスまたはサフィックスのいずれかのラベルを割り当て、同じ長さの文字列が少なくとも 1 つ存在するようにすることです。$n$これらすべての選択と一致しています。 

出力は入力リストのバイナリラベルです。正確には、$n-1$文字列はプレフィックスとしてマークされ、$n-1$接尾辞としてマークされています。 有効な元の文字列に由来するラベルはすべて受け入れられます。 

制約$n \le 100$ということを暗示します$2n-2 \le 198$。 この小さな境界は、複数のグローバル候補をチェックすることが実現可能であることを強く示唆しています。 特に、制限された数の再構築を試行し、それらを検証するアプローチは、$O(n^2)$で十分です。 

素朴だが重要な落とし穴は、プレフィックスとサフィックスのペアが文字列の等価性のみの一致によって一意に決定されると想定していることです。 同じ文字列が異なる長さで複数回出現する場合、またはプレフィックスとサフィックスが共通の構造を共有する場合、これは失敗します。 たとえば、すべての文字が同一の場合、すべての部分文字列は区別できず、多くの代入が有効になります。 

別の微妙なケースは、異なる長さのプレフィックス文字列とサフィックス文字列が重なり合う場合に発生します。 長さごとの貪欲な割り当ては失敗する可能性があります。これは、完全な候補文字列を構築した後でのみ明らかになるように、初期の決定が後の一貫性を制限するためです。 

## アプローチ

 強引なアイデアは、すべての長さに個別にプレフィックスまたはサフィックスを割り当ててみることです。 あるので$n-1$長さには 2 つの可能性があり、それぞれに次の結果が得られます。$2^{n-1}$課題。 割り当てごとに、元の文字列の再構築を試み、すべての部分が一致するかどうかを確認できます。 これは明らかに指数関数的であり、$2^{99}$、これは大きすぎます。 

重要な構造的観察は、答えがたった 2 つの候補文字列によって全体的に制約されるということです。 長さの正しいプレフィックスを選択したら$n-1$の場合、そのプレフィックスによって以前のすべてのプレフィックスがすでに決定されており、サフィックスは一貫性によって強制されるため、文字列全体が固定されます。 したがって、問題は、完全な文字列に対して 2 つの可能性のみを試行することになります。つまり、2 つの長さの文字列です。$n-1$入力で。 

候補ごとに、すべてのプレフィックスとサフィックスを再構築し、マルチセットと照合しようとします。 候補が機能する場合は、各入力文字列を、再構築された文字列の長さのプレフィックスまたはサフィックスと比較することで、一貫してラベルを割り当てることができます。 

これが機能するのは、最長の不適切な接頭辞と接尾辞が、最大 2 つの可能性まで完全な文字列を一意に再構築する方法で重複する必要があるためです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^{n} \cdot n)$|$O(n)$| 遅すぎる |
 | 最適 |$O(n^2)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての入力文字列を収集し、長さ別にグループ化します。 それぞれの長さごとに$k$、候補はちょうど 2 つあります。 2 つの文字列の長さを識別する$n-1$これらは、「ほぼ完全な」プレフィックスまたはサフィックス情報の唯一の候補であるためです。 完全な文字列の潜在的な構成要素として両方を試してみます。 
2. 各候補文字列について$c$長さの$n-1$、長さの完全な文字列を再構築しようとします。$n$。 2 つの可能性を試します: 他の長さの文字列の最後の文字を追加します。$n-1$重複が一貫している場合、または対称的に他の候補をプレフィックスとして使用します。 
3. 完全な文字列を 1 回$s$が構築され、そのすべての長さのプレフィックスとサフィックスを計算します$1$に$n-1$。 複数セットのマッチングを可能にする構造にそれらを保存します。 
4. 生成されたプレフィックスとサフィックスを入力マルチセットと比較します。 それらが（マルチセットとして）正確に一致する場合、これは$s$は有効な非表示文字列です。 
5. 有効期限が切れたら$s$が見つかった場合は、各入力文字列をチェックしてラベルを割り当てます: の接頭辞と一致する場合$s$その長さの場合は P とマークし、それ以外の場合は S とマークします。妥当性によって一貫性が保証されるため、各文字列に対して正確に 1 つのロールが正しいことになります。 

### なぜ効果があるのか

 正確さは、長さのセットが次のとおりであるという事実にかかっています。$n-1$文字列には、同じ長さの真のプレフィックスが少なくとも 1 つ含まれています$n-1$隠し文字列の。 その文字列を選択すると、未知の文字が 1 文字だけ残るため、候補文字列全体が一意に修正されます。 有効なソリューションはすべて、その再構成と一致する必要があります。 長さの候補は最大で 2 つまでなので、$n-1$入力に文字列が含まれている場合、両方を試してみると、基になる文字列が正しいとみなされることが保証されます。 完全な文字列が修正されると、プレフィックスとサフィックスの役割が比較によって決定的に決定されるため、あいまいさは残りません。

## 実用的な例

 ### 例 1

 入力:```

a, ab, b, ab
```長さ 2 の候補が「ab」と「ba」であるとします。 接頭辞として「ab」を試します。 

| ステップ | 候補者 | 完全な文字列 | プレフィックス/サフィックス マルチセットが有効 |
 | --- | --- | --- | --- |
 | 1 | アブ | アバ | 生成されたチェック |
 | 2 | ば | バブ | 生成されたチェック |

 1 つの再構築のみがマルチセットと一致します。 有効な完全な文字列を選択した後のラベル付けは簡単です。長さ 1 と 2 の接頭辞は P とマークされ、残りは S とマークされます。 

これにより、複数の候補が存在する場合でも、グローバル一貫性を通過するのは 1 つだけであることが確認されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n = int(input())
    arr = [input().strip() for _ in range(2 * n - 2)]

    by_len = {}
    for x in arr:
        by_len.setdefault(len(x), []).append(x)

    candidates = by_len[n - 1]

    def build(s):
        n2 = len(s) + 1
        for t in candidates:
            for first, second in [(s, t), (t, s)]:
                full = first + second[-1]
                cnt = {}
                for i in range(1, n2):
                    cnt[full[:i]] = cnt.get(full[:i], 0) + 1
                    cnt[full[n2-i:]] = cnt.get(full[n2-i:], 0) + 1
                ok_cnt = {}
                for x in arr:
                    ok_cnt[x] = ok_cnt.get(x, 0) + 1
                if cnt == ok_cnt:
                    return full
        return None

    full = build(candidates[0])
    if full is None:
        full = build(candidates[1])

    res = []
    for x in arr:
        res.append('P' if full[:len(x)] == x else 'S')
    return ''.join(res)

 ## 特殊なケース

 非表示文字列内のすべての文字が同一である場合、同じ長さの接頭辞と接尾辞もすべて同一になります。 この場合、2つの長さは、$n-1$候補者は平等です。 どちらの再構築試行でも同じ完全な文字列が生成され、検証に合格するため、アルゴリズムは引き続き機能します。そのため、ラベル付けは任意ですが一貫性のあるものになります。 

小型用$n$、 特に$n = 2$、プレフィックス/サフィックスの長さは 1 つだけです。 このアルゴリズムは、単一の長さ 1 の文字列ペアによって暗示される長さ 2 の唯一可能な再構成を直接テストし、些細な場合でも決定論的なプレフィックス マッチングに基づいて役割を割り当てるため、引き続き機能します。
