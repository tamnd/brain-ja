 ## 解決策
 ## 問題の理解

 整数点を選択するように求められます$x$次のような行に$(k+1)$- 番目に小さい距離から$x$与えられた点のセットが最小化されます。 それぞれのクエリで得られるのは、$n$ソートされた整数$a_1, a_2, \dots, a_n$上の点を表す$OX$軸と整数$k$。 機能$f_k(x)$からの絶対距離を計算することによって定義されます。$x$それぞれに$a_i$、それらを並べ替えて、$(k+1)$- 番目の値。 目標は選択することです$x$それは最小限に抑えます$f_k(x)$。 

制約は厳しいです:$n$まで可能です$2 \cdot 10^5$そしてすべての合計$n$クエリ全体でも最大で$2 \cdot 10^5$。 これにより、考えられるすべてのソリューションを反復するソリューションが除外されます。$x$全範囲の値。最大値は次のとおりです。$10^9$。 線形の解決策が必要です$n$クエリごと、または最悪の場合$O(n \log n)$、制限時間内にとどまること。 

明らかではないエッジケースには、次のようなシナリオが含まれます。$k = 0$または$k = n-1$。 のために$k = 0$、$f_0(x)$は任意の点までの最小距離であるため、最適$x$既存の点のいずれかと一致する必要があります。 のために$k = n-1$、$f_{n-1}(x)$は任意の点までの最大距離であり、極点の中点で最小になります。 境界を確認せずに固定式を仮定する不用意なアプローチは、これらの極端な問題に対して誤った答えを生み出す可能性があります。$k$価値観。 

## アプローチ

 ブルートフォースアプローチは簡単です: 各整数に対して$x$からの範囲で$a_1$に$a_n$、すべての距離を計算し、並べ替えて、$(k+1)$- 番目に小さい距離。 これは正しいですが、ソートするため非常に遅くなります。$n$までの距離$10^9$可能$x$価値観は実現不可能です。 指定された点のみを候補として反復処理し、すべての点の距離を計算することもできます。$n$だろう$O(n^2)$最悪の場合、遅すぎる$n \approx 2 \cdot 10^5$。 

重要な洞察は次のとおりです$f_k(x)$のみに依存します$k$- 番目に近い隣人。 ポイントが整理されているので、$(k+1)$- 番目に近い距離$x$長さのセグメントを考慮することで達成できます$k$ソートされた配列内。 具体的には、どのような場合でも、$x$、$(k+1)$- 番目に近い点はいくつかになります$a_i$配列内で最小値が発生するのは次の場合です。$x$の中点に配置されます$a_i$そして$a_{i+k}$。 これにより、問題はすべての反復処理に軽減されます。$i$から$0$に$n-k-1$、中点を計算します$(a_i + a_{i+k}) // 2$、の値を選択します$x$これにより、セグメントの端までの距離が最小限に抑えられます。 これは線形です$n$クエリごとに実行され、各候補点での並べ替えが回避されます。

 ## アルゴリズムのチュートリアル

 1. インデックスを反復処理する$i$から$0$に$n-k-1$。 各セグメントから$a_i$に$a_{i+k}$を表します$k+1$連続ポイント。 どれでも$x$この間隔外で選択した場合、$(k+1)$このセグメントの - 番目に小さい距離なので、最適$x$はこの間隔内になければなりません。 
2. 各セグメントについて、中点を計算します。$m = (a_i + a_{i+k}) // 2$。 配置する$x$この中間点で、セグメント内の最初と最後の点までの距離のバランスがとれ、最大距離が最小限に抑えられます。$|x - a_i|$そして$|x - a_{i+k}|$。 
3. 最小距離を追跡する$d = a_{i+k} - a_i$すべてのセグメントにわたって。 小さいときは$d$が見つかった場合は、候補を更新します$x$対応する中間点に移動します。 
4. すべてのセグメントを繰り返した後、選択されたセグメントが$x$最小の長さのセグメントに対応します。 これにより保証されます$f_k(x)$最小化されます。 

なぜ効果があるのか​​:$(k+1)$- 点での 2 番目に小さい距離$x$によって決定されます$k$-周りの最も近い隣人$x$。 最小距離はバランスによって達成されます$x$長さの最小セグメントの内側$k$ソートされたポイント内で、最も遠い点が保証されます。$k+1$最近接点は可能な限り近くにあります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        min_len = float('inf')
        ans = 0
        for i in range(n - k):
            length = a[i + k] - a[i]
            if length < min_len:
                min_len = length
                ans = (a[i] + a[i + k]) // 2
        print(ans)

solve()
```ソリューションはクエリの数を読み取り、クエリごとに次の情報を読み取ります。$n$、$k$、およびソートされた配列。 考えられるすべての長さのセグメントにわたって反復されます。$k+1$、セグメントの長さを計算し、最小セグメントの中点で答えを更新します。 整数除算を使用すると、$x$は整数です。 最終的な回答はクエリごとに出力されます。
