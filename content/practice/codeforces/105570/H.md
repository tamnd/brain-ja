 ## 解決策
 ## 問題の理解

 長さのリズムチャートが与えられます$N$。 各ポジションは、ヒットを必要とする音符 (`D`または`K`) または休憩 (`.`）。 休符以外のすべての位置は、左右いずれかの片手に正確に割り当てられる必要があります。つまり、割り当て文字列を構築します。$T$どこ$T[i] \in \{L, R\}$もし$S[i] \neq '.'$、 そして$T[i] = '.'$さもないと。 

代入には構造上の制約があります。$T$、同じ役が 2 つの連続した位置に現れることはできません。 休止位置はドットとして固定されているため、隣接関係は自動的に解除されるため、制約は元のタイムライン内の連続する非ドット位置間でのみ問題になります。 

コストモデルはさらに微妙です。 正確に 2 時間単位離れた 2 回のヒットで同じハンドが使用された場合、つまり位置を意味します。$i$そして$i+2$、両方のポジションが実際のノートである場合、ペナルティが発生する可能性があります。 ペナルティは、2 つの紙幣が異なる種類である場合にのみ適用されます。$S[i] \neq S[i+2]$。 その場合、両方に同じ手が使用された場合は、私たちが支払います$L$左手用または$R$右手用。 

タスクは、合計のペナルティを最小限に抑えるために、すべてのノートに手を割り当てることです。 

制約により、最大で次のことが許可されます。$2 \times 10^5$ポジションなので何でも$O(N^2)$戦略はすぐには実行不可能です。 解決策は線形または線形に近いものでなければなりません。 これはまた、長距離の依存関係が問題を許容以上に困難にするため、相互作用が局所的で構造化されていることも示唆しています。 

音符がドットで区切られている場合、微妙なエッジケースが表示されます。 たとえば、文字列が次の場合、`D.K`の場合、位置 0 と 2 は、アクションの点では隣接していませんが、テレポート ルール内で直接相互作用します。 単純な隣接関係ベースの DP は、この依存関係を完全に見逃してしまいます。 もう 1 つの特殊なケースは、次のようなノート タイプを交互に使用することです。`D K D K`、2 歩離れたペアごとに、ハンドの一貫性に応じてペナルティが発生する可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、各ノートを左または右に割り当て、有効性とコストをチェックします。 これは次のことにつながります$2^M$可能性はどこにあるのか$M$はドット以外の位置の数です。 枝刈りを行っても、各選択が距離 2 の相互作用を通じて将来のコストに影響を与えるため、状態の数は指数関数的なままです。 すべての有効な割り当てを列挙するため、正確さは簡単ですが、一度実行すると実行できなくなります。$M$約25を超えると成長します。 

重要な観察は、コストが正確に 2 の距離にある位置のペアにのみ依存するということです。 それ以上の範囲での相互作用はありません。 これは、パリティによって問題を分割することを直ちに示唆します。 偶数インデックスのポジションは 2 ステップ離れた他の偶数インデックスとのみ相互作用し、奇数インデックスは独立して動作します。 これにより、元のシーケンスが 2 つの独立した線形チェーンに縮小され、各ノードはそのチェーン内の先行ノードとのみ対話します。 

分割されると、各チェーンは単純な逐次動的計画法の問題になり、各位置は 2 ステップ前の割り当てにのみ依存します。 これにより、指数関数的な分岐が崩壊し、位置ごとに 2 つの状態を持つ線形遷移システムになります。

 | パリティ チェーン上の DP |$O(N)$|$O(N)$| 承認済み |

 ## アルゴリズムのチュートリアル

 文字列は偶数インデックスと奇数インデックスで別々に処理されます。 

1. インデックスパリティに基づいて、メモのあるすべてのポジションを 2 つのグループに分割します。 各グループは、インデックスの昇順で独立したシーケンスを形成します。 
2. 各パリティ グループについて、動的プログラミング状態を維持しながら、インデックスを左から右に処理します。 各位置で 2 つの値を追跡します。左手を割り当てた場合の最小コストと、右手を割り当てた場合の最小コストです。 
3. ポジションからの移行$i-2$に$i$なぜなら、ちょうど 2 つ離れた位置だけが相互作用できるからです。 可能な割り当てごとに、$i$で両方の代入を検討します。$i-2$。 同じ手が両方のポジションで使用され、ノートの種類が異なる場合、対応するペナルティを追加します。$L$または$R$。 
4. 各パリティ チェーンの最後の位置で可能な 2 つのハンド割り当ての最小値を取得します。 

遷移はローカルです。各状態は、同じパリティ チェーン内の以前の有効な相互作用状態にのみ依存するため、複数の前の層を保存する必要はありません。 

### なぜ効果があるのか

 すべてのペナルティは、距離 2 の位置のペアにのみ依存します。 これらのペアは常に 1 つのパリティ クラス内に完全に存在します。 したがって、パリティによって分割すると、すべての相互作用が保存されます。 分割されると、すべての制約は、そのチェーン内のノードとその先行ノードとの間の依存関係になります。 次に、DP はすべての有効な割り当てを正確に取得し、考えられるすべての一貫した選択に対してコストを最適に蓄積します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, L, R = map(int, input().split())
    s = input().strip()

    INF = 10**30

    def process(indices):
        if not indices:
            return 0

        dp_prev = [0, 0]  # 0 = L, 1 = R

        first = indices[0]
        # initialize first position: no previous constraint
        dp_prev = [0, 0]

        for idx_pos in range(1, len(indices)):
            i = indices[idx_pos]
            j = indices[idx_pos - 1]

            dp_curr = [INF, INF]

            for cur in range(2):
                for prv in range(2):
                    cost = dp_prev[prv]
                    if cur == prv and s[i] != s[j]:
                        cost += L if cur == 0 else R
                    dp_curr[cur] = min(dp_curr[cur], cost)

            dp_prev = dp_curr

        return min(dp_prev)

    even = []
    odd = []

    for i, ch in enumerate(s):
        if ch == '.':
            continue
        if i % 2 == 0:
            even.append(i)
        else:
            odd.append(i)

    print(process(even) + process(odd))

if __name__ == "__main__":
    solve()
```この実装では、インデックス パリティに基づいて 2 つの独立した DP チェーンを構築します。 各チェーンは、実際のノートを含むインデックスのみを処理します。 

各チェーン内での DP 状態`dp_prev`前のノートを左手または右手に割り当てるための最小コストを保存します。 新しいノートごとに、両方の割り当てを試し、コストを前方に伝播します。 

条件`i - j == 2`各パリティ リスト内の連続する要素は、そのチェーン内の潜在的な相互作用ペアに正確に対応するため、暗黙的に処理されます。 同じハンドが再利用され、2 つのノートが異なる場合、対応するペナルティを追加します。

 | --- | --- | --- | --- | --- |
 | 開始 | 0 | 0 | 0 | 最初の音には以前の制約はありません |
 | ステップ 1 | 2 | 0 | 0 | 前の偶数音符が距離 2 にないため、相互作用はありません |

 現在、奇数チェーンは独立しており、同様に処理されます。 

トレースは、元の文字列では距離 2 の関係を表すのは各パリティ チェーン内の連続する要素のみであるため、それらの要素のみが重要であることを示しています。

これは、ノートの種類が異なる場合にアルゴリズムがコストのかかる同時使用の再利用をどのように選択的に回避するかを示しています。

 ## 特殊なケース

 主なエッジケースは、次のように音符がドットで区切られている場合です。`D.K`。 単純な隣接 DP はこれらを独立したものとして扱いますが、実際には、正確に 2 ステップ離れているため、相互作用します。 両方のインデックスが同じパリティ チェーンに分類され、そのチェーン内で連続しているため、アルゴリズムはこれを正しく処理します。 

もう 1 つのケースは、次のような交互パターンです。`D K D K`、2 番目の位置ごとに最初の位置と相互作用します。 DP はこれらのステップ全体に制約を正しく伝播し、ノートの種類が異なる場合にのみ同じハンドの割り当てがペナルティを受けるようにします。 

最後のエッジケースは、いくつかの孤立した音符を除いてすべての文字がドットである場合です。 この場合、両方のパリティ チェーンの長さが 1 または 0 になる可能性があり、どのチェーンにも距離 2 の有効なペアが存在しないため、DP は正しくコスト 0 を返します。
