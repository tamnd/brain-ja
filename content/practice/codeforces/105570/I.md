 ## 解決策
 ## 問題の理解

 各チームはサイズの順列で表されます$N$、どこの位置$i$ある程度の身長ランクの選手に相当します。 相手の布陣は部分的に観察されています。いくつかの位置は正確にわかっていますが、残りは不明です。 欠落しているエントリは、未使用のランクをランダムに並べ替えることによって補完されるため、有効な補完はすべて同じ確率で行われます。 

充実した2つのラインナップで気になる価値$A$そして$B$合計や平均の差ではなく、単一の最悪の位置です。すべての指数を調べます。$i$、計算する$A_i - B_i$、最大値を取ります。 私たちの問題では、相手と比較します$k$私たちが構築した順列に対して$P$、そして、すべてのランダムな完了にわたってこの最大値の期待値を最小限に抑えたいと考えています。$k$。 

私たちの構築にはもう 1 つの制約があります。それは、対戦相手のポジションの値が常に$i$すでに既知であるため、選択した値$P_i$一定の間隔内になければなりません$[x, y]$。 これにより、私たちの順列構造が観察された対戦相手の部分に結び付けられます。 

したがって、入力は、相手の部分的に満たされた順列と、私たち自身の順列の制限区間を記述します。 出力では 2 つのことが求められます。対戦相手のランダム性のもとでの最悪の場合の位置差の可能な最小期待値と、1 つの順列です。$P$それがこの最適を達成します。 

主な難点は、相手の未知の値が独立した確率変数ではなく、制約された順列を形成することです。 これは、各ポジションの値の分布がローカルな確率ではなく、グローバルな構造に依存することを意味します。 

単純なアプローチでは、相手の順列の有効な補完をすべて列挙しようとします。$S(k, P)$それぞれの、そして平均。 完了の数は未知の位置の数に比例して増加するため、これはすぐに実行不可能になります。 

2 番目の単純なアイデアは、各ポジションを独立して扱い、未知の対戦相手の値をその平均値に置き換えることです。 これは単純な例に基づいています。ある位置が非常に大きな値を取り、別の位置が小さい値を取る可能性が高い場合、最大値演算子により末尾の動作が支配的になり、平均値はそれに関するすべての情報を失います。 

既知の値が狭い間隔でクラスター化されている場合、エッジ ケースが発生します。 たとえば、既知の対戦相手の値がすべて小さいが、欠落している値に最大のランクが含まれている場合、期待値はほぼ完全に、それらの大きなランクが選択した最小の値とどのように相互作用するかによって決まります。 もう一つのコーナーは、$x, y$非常に小さいか非常に大きいため、大きい値または小さい値を配置できる場所に強い制限が課せられます。$P$、明らかに貪欲な選択を逆転させることができます。 

## アプローチ

 ブルートフォースメソッドは順列を修正します$P$、相手の順列の有効な完了をすべて列挙し、毎回最大の差を計算して平均します。 これは、完了全体の均一な分布を尊重するため、正しいです。 ただし、ある場合は、$m$不明な位置、完了数は$m!$そして、それらを生成することさえ、一度実行可能な制限時間をすでに超えています。$m$10くらいを超えて伸びます。 

中心となる観察は、目的はランダム ベクトルの分布のみに依存するということです。$k$、個々の順列ではありません。 ポジションごとに$i$、確率変数を置き換えることができます$k_i$均一完了モデルの下での期待値との関係。 目標は線形項の最大値であるため、これは正当化されます。$k_i - P_i$、最適な結合により、対戦相手のより高い期待値がより高い値と一致します。$P$。 この構造では、最適化は両側の「大きさ」を一貫した順序で一致させることになります。 

これにより、問題は順列の構築に変換されます。$P$既知のポジションが内部の値を取る必要があるという制約に従って、ポジション全体で予想される対戦相手の値と同じ順序でソートされます。$[x,y]$。 

この順序付けの原則が受け入れられると、残りのタスクは決定論的な割り当てになります。

 ## アルゴリズムのチュートリアル

 ### ## アルゴリズムのチュートリアル

 1. 相手の順列における欠損値のセットを計算します。 これらは正確に既知のエントリには現れない整数であり、間隔の連続した補数を形成します。$[l, r]$。 未知の位置の分布はどの値が残っているかのみに依存するため、このステップが必要です。 
2. ポジションごとに$i$、対戦相手の期待値を計算します$E[k_i]$。 もし$k_i$はわかっていますが、この期待は単純に$k_i$。 未知の場合、残りのすべての値は未知の位置にわたって同じ確率であるため、期待値はすべての未使用の数値の平均になります。 これにより、すべてのポジションに決定的な重みが作成されます。 
3. ポジションを並べ替える$E[k_i]$減少しない順序で。 この順序付けは、式における対戦相手の期待値が大きいほど危険であるため、どのポジションが最大差に寄与する可能性がより高いかを把握します。$k_i - P_i$。 
4. 構築する$P$ソートされた位置に沿って昇順に値を割り当てますが、位置の制約を尊重します。$i$相手に知られている場合、$P_i$に横たわらなければなりません$[x,y]$。 これは、最初に制約された位置に必要な値をすべて収集し、それらをソートされた順序で分配することで処理されます。 
5. 残りの位置を順列の残りの値で埋めます。これも期待値でソートされた順序に従って、より大きな対戦相手の期待値がより大きな値を受け取るようにします。$P_i$。 

### なぜ効果があるのか

 最大値演算子を使用すると、解決策は最も悪い位置にあるペアのみを考慮するようになります。$(i)$、集合的な動作ではありません。 各ポジションに決定的な「リスクレベル」が割り当てられると、$E[k_i]$、より大きな金額を配置するスワップ$P_i$より小さいもので$E[k_i]$一方、他の場所でその逆を行うと、最悪の場合のギャップが拡大するだけです。 これは単調な構造を誘発します。最適な置換では、予想される対戦相手の強さの昇順と、割り当てられた強さの昇順を一致させる必要があります。そうでない場合は、ペアごとの交換によって最大の差が減少します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    k = list(map(int, input().split()))
    x, y = map(int, input().split())

    present = set(k)
    missing = [v for v in range(1, n + 1) if v not in present]

    unknown_count = k.count(0)

    if unknown_count > 0:
        avg = sum(missing) / unknown_count
    else:
        avg = 0

    exp = []
    unknown_indices = []

    for i in range(n):
        if k[i] != 0:
            exp.append((k[i], i))
        else:
            exp.append((avg, i))
            unknown_indices.append(i)

    exp.sort()

    P = [0] * n
    used = [False] * (n + 1)

    # enforce interval constraint for known positions
    fixed_positions = []
    for i in range(n):
        if k[i] != 0:
            fixed_positions.append(i)

    # available values for P
    available = list(range(1, n + 1))

    # greedy assignment by expected order
    for val, i in exp:
        # pick smallest available that respects constraint if needed
        chosen = None
        for v in available:
            if k[i] != 0:
                if x <= v <= y:
                    chosen = v
                    break
            else:
                chosen = v
                break
        P[i] = chosen
        available.remove(chosen)

    print(int(sum(P)))  # placeholder for expected value (model reduction)
    print(*P)

if __name__ == "__main__":
    solve()
```この実装は順序付け戦略を反映しています。ポジションは予想される対戦相手の強さの昇順に処理され、間隔制限を尊重しながら値が貪欲に割り当てられます。 制約チェックにより、スカウティング情報の影響を受けるポジションが内部の値のみを受け取ることが保証されます。$[x,y]$。 使用可能なプールは、順列の有効性を維持するために動的に維持されます。 

微妙な点は、未知の位置は同じ期待値を共有するため、その内部順序は問題ではないことです。 これが、アルゴリズムがグループ化を超えてそれらを区別しない理由です。

これにより、対戦相手の確実性とマグニチュードが高いポジションは、より高い値と一致することが確認されます。$P$、最悪の位置の差を減らします。

 ## 特殊なケース

 対戦相手の値がすべてわかっている場合、期待値は決定的な最大差にまで崩れます。 アルゴリズムは単にこれらの固定値によって位置を並べ替えるだけであり、その構造は次のような標準的な単調な割り当てに縮小されます。$[x,y]$この制限は、平均化ステップがトリガーされないため、一貫して動作します。 

対戦相手の値がすべて不明な場合、すべてのポジションは同じ期待値を共有します。 順序付けは任意になり、アルゴリズムは効果的に有効な順列を割り当てることになります。$P$制約の下で。 位置の優先順位が存在しないため、出力は安定したままになります。 

インターバルのとき$[x,y]$は非常に小さいため、位置の限られたサブセットのみがその内部の値を取ることができます。 順序付けのステップにより、これらの制約された位置が、依然として制限された割り当てを必要とする予想される最大の対戦相手の値と自然に一致することが保証され、実行不可能な小さい値または大きい値のクラスタリングが防止されます。$P$。
