 ## 解決策
 ## 問題の理解

 2 組のカードが与えられ、それぞれ上から下まで特定の順序があり、各カードは表向きか裏向きになります。 最初のデッキには、`n`カード、2番目のデッキには`m`カード。 私たちの目標は、元の各デッキのカードの相対的な順序を維持しながら、2 つのデッキを 1 つのデッキにマージすることです。 結合後は、最小限の「ターン」操作を使用して、すべてのカードが裏向きになる必要があります。 ターンはトップを取ることで構成されます`k`カードをそれぞれ裏返し、デッキ内の順序を逆にします。 

入力は、カードが最初に表向きであるかどうかを表す整数で構成されます (`1`) または裏向き (`0`）。 出力は、結合されたデッキ順序を示すすべてのカード インデックスの順列であり、その後に必要なカードを裏返し、すべてが裏になる一連のターン操作が続きます。 

カードの枚数`n + m`最大 200,000 まで可能です。 カードの数が 2 次である解決策は遅すぎます。 これは、デッキを直線的に、または数回の直線的なパスでスキャンするアプローチが必要であることを直ちに示唆しています。 

エッジケースには、すでにすべてが裏向きまたはすべてが表になっているデッキ、または 1 つのデッキに表と裏のカードが交互に含まれているデッキが含まれます。 一度に 1 枚のカードを裏返す単純なアプローチでは、不必要に大量の操作が発生します。 連続した上部セグメントをめくると 1 回のターンで複数のカードを処理できるという事実を活用する必要があります。 

たとえば、最初のデッキが`[1,0,1]`そして2番目のデッキは`[1,1,1,1]`、素朴なアプローチでは、それぞれを反転させようとする可能性があります`1`個別に。 ただし、最初に上の 5 枚のカードを裏返し、次に上の 6 枚、次に上の 7 枚を裏返すと、ターンが最小限に抑えられます。 

## アプローチ

 強引なアプローチは、結合されたデッキのすべての順列を試してから、貪欲に一番上をひっくり返すことです。`k`表向きのカードが現れるたびに、カードが表示されます。 これは正しいですが、順列の数は階乗であるため、絶望的に遅いです。`n + m`。 2 つのデッキを順番にインターリーブするように制限したとしても、フリップを 1 つずつスキャンすると、最悪の場合、O((n+m)^2) の操作が必要になります。 

重要な洞察は、マージの順序が複雑である必要はないということです。 ターン数を最小限に抑えるために、各ターンでできるだけ多くの表向きのカードを裏返せるように、最終的なデッキで表向きのカードをグループ化したいと考えています。 これは、相対的な順序を保ちながらすべての表向きのカードを一番上に置き、すべての裏向きのカードを一番下に置くことを意味します。 結果として結合されたデッキには、表向きのカードの連続した接頭辞と、それに続く裏向きのカードの連続した接尾辞が含まれます。 このように配置すると、上から下への単一の直線パスで回転操作を貪欲に適用できるようになります。 

最適なアルゴリズムは次の点で線形です。`n + m`。 各デッキをスキャンして、表向きのカードと裏向きのカードのインデックスを収集します。 最初にすべての表向きのインデックスを結合し (内部デッキ順序を維持)、次にすべての裏向きのインデックスを結合します。 最後に、裏返しをシミュレートします。前の一連のカードの裏返しの後に新しい表向きのカードに到達するたびに、それまで裏返されたカードの数に等しいサイズのターン操作を実行します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((n+m)^2) | O(n+m) | 遅すぎる |
 | 最適 | O(n+m) | O(n+m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. カードの枚数を読み取ります`n`最初のデッキとデッキ配列内`a`。 のカードごとに`a`、そのインデックスを次のいずれかに保存します。`face_up_first`リスト (カードが`1`) または`face_down_first`リスト (カードが`0`）。 インデックスは次から始まります`1`。 
2. カードの枚数を読み取ります`m`2番目のデッキとデッキアレイで`b`。 インデックスを保存する`face_up_second`または`face_down_second`リスト。 2 番目のデッキのインデックスは次から始まります`n + 1`に`n + m`。 
3. 両方のデッキの表向きのインデックスと、その後に両方のデッキの裏向きのインデックスを連結したものとして結合デッキを構築します。 これにより、すべての表向きのカードが一番上に、裏向きのカードが一番下に配置され、各デッキ内の相対的な順序が維持されます。 
4. ターン操作の最小シーケンスを計算するには、結合されたデッキを上から下にスキャンします。 カードが現在表向きになっているセグメントを追跡します。 表向きのカードの連続するセグメントごとに、ターン操作としてそのセグメントの最後のカードまでプレフィックスのサイズを追加します。 このプレフィックスのカードを仮想的に裏返し、続行します。 最初はすべての表向きのカードが一番上にあるため、この手順により、毎ターンの操作で効率的に表向きのカードの数が減ります。 
5. マージされたデッキ インデックス、ターン操作の数、およびターン サイズのシーケンスを出力します。 

機能する理由: 合成後、表向きのカードはすべて一番上になります。 表向きのカードの連続したセグメントはすべて裏返すことができ、上部を裏返すことができます。`k`カードはセグメントを反転し、順序を逆にします。 内部のデッキ順序はマージ時に保持され、アルゴリズムは最大の連続するプレフィックスを反転するため、最小限の操作ですべてのカードが裏向きになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))
m = int(input())
b = list(map(int, input().split()))

face_up_first = []
face_down_first = []
for i in range(n):
    if a[i] == 1:
        face_up_first.append(i+1)
    else:
        face_down_first.append(i+1)

face_up_second = []
face_down_second = []
for i in range(m):
    if b[i] == 1:
        face_up_second.append(n + i + 1)
    else:
        face_down_second.append(n + i + 1)

merged_deck = face_up_first + face_up_second + face_down_first + face_down_second

# Compute turns
turns = []
for i in range(len(merged_deck)):
    if (i == 0 or merged_deck[i-1] <= n+m) and i < len(face_up_first + face_up_second):
        turns.append(i+1)

# Optimized: each face-up card corresponds to a turn operation
turns = [len(face_up_first + face_up_second) - i for i in range(len(face_up_first + face_up_second))]

print(*merged_deck)
print(len(turns))
print(*turns)
```このソリューションでは、内部の順序を維持しながら、インデックスを表向きのカードと裏向きのカードで分離します。 統合されたデッキはすべての表向きのカードを一番上に置きます。 ターン操作は、すべての表向きのカードをカバーするプレフィックスを取得することによって効率的に計算され、合計操作が最小限に抑えられます。 2 番目のデッキのインデックスを正しくオフセットし、相対的な順序を維持するように注意が必要です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    m = int(input())
    b = list(map(int, input().split()))

    face_up_first = []
    face_down_first = []
    for i in range(n):
        if a[i] == 1:
            face_up_first.append(i+1)
        else:
            face_down_first.append(i+1)

    face_up_second = []
    face_down_second = []
    for i in range(m):
        if b[i] == 1:
            face_up_second.append(n + i + 1)
        else:
            face_down_second.append(n + i + 1)

    merged_deck = face_up_first + face_up_second + face_down_first + face_down_second
    num_turns = len(face_up_first + face_up_second)
    turns = list(range(len(face_up_first + face_up_second), 0, -1))

    out = []
    out.append(' '.join(map(str, merged_deck)))
    out.append(str(num_turns))
    out.append(' '.join(map(str, turns)))
    return '\n'.join(out)
