 ## 解決策
 ## 問題の理解

 Vasya は映画のリストと好きな俳優のリストを持っています。 各映画にはキャストの一部がリストされていますが、一部の俳優 ID が欠落している場合があります (0 で表されます)。 Vasya は、各映画を 3 つのカテゴリのいずれかに分類したいと考えています。つまり、確実にお気に入りになる、間違いなくお気に入りではない、または欠落している俳優 ID に応じてどちらかになる可能性があります。 すべての俳優 ID が明らかになり、少なくとも他の映画と同じくらい多くのお気に入りの俳優が含まれている映画はお気に入りです。 

入力により、俳優の総数、Vasya のお気に入りの俳優の ID、キャストが含まれる映画のリスト (未知の俳優を含む) が提供されます。 出力はムービーごとに 1 行で、カテゴリを 0、1、または 2 で示します。 

制約は小さく、俳優が最大 100 人、映画が 100 本あるため、O(n・m) アルゴリズムが実現可能です。 重要な課題は、不確実性に対処することです。俳優の中には無名の俳優もおり、そのアイデンティティによって映画がお気に入りになるかどうかが変わる可能性があります。 

明らかではないエッジケースとしては、俳優全員が未知である映画や、お気に入りの俳優がすでに全員出演しているが、お気に入りではない可能性のある未知のスポットがまだある映画などがあります。 既知のお気に入りのみをカウントする不注意なアプローチは、これらのシナリオを誤って分類する可能性があります。 

たとえば、3 人のお気に入りの俳優 {1,2,3} が出演する 3 本の映画について考えてみましょう。```
movie1: actors = [0,0,0]   # all unknown
movie2: actors = [1,2,3]   # all favorite known
movie3: actors = [1,0,4]   # mix known favorite, unknown, non-favorite
```Movie1 には、0 ～ 3 人のお気に入りの俳優を含めることができます。 Movie2 には 3 つが保証されています。Movie3 には、未知の俳優に応じて 1 つまたは 2 つのお気に入りがある可能性があります。 正しく分類するには、お気に入りの俳優の可能性のある最小値と最大値の両方を考慮する必要があります。 

## アプローチ

 ブルートフォース手法では、各映画の未知の俳優 ID に対する考えられるすべての割り当てを列挙し、すべての割り当てのお気に入りを数えて、お気に入りの映画を決定します。 これは正しいですが、実行不可能です。各映画には`u`未知の俳優には O((m)^u) 通りの組み合わせがあり、最大 100 本の映画では組み合わせ的に爆発的に増加します。 

重要な洞察は、すべての可能性を列挙することなく、**各映画に登場するお気に入りの俳優の可能な最小数と最大数**を計算することです。 映画ごとに、既知のお気に入りの俳優を数えることができます (`f_known`) と未知の俳優 (`u`）。 可能な最大のお気に入りは次のとおりです`f_known + min(u, k - f_total)`、 どこ`f_total`他の映画ですでに使用されているお気に入りの俳優の合計数です。 可能な最小限のお気に入りは次のとおりです`f_known`(無名の俳優がお気に入りではないと仮定して) または`f_known + max(0, u - (m - k))`お気に入り以外の俳優が十分に残っていないため、何人かの無名の俳優がお気に入りに違いない場合。 

各映画の最小値と最大値がわかったら、次のように分類できます。 

- 最小カウントが他のすべてのムービーの最大カウント以上であれば、確実にお気に入りです。 
- 最大カウントが他の映画の最大カウントよりも小さい場合は、確かにお気に入りではありません。 
- そうでなければ、どちらの方向にも進む可能性があります。 

これにより、問題は O(n·m) の複雑さまで軽減されます。つまり、各ムービーを 1 回スキャンし、カウントを計算してから、ムービー間で比較します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((m^u)・n) | O(n) | 遅すぎる |
 | 最小/最大カウント | O(n・m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. アクターの数を読み取る`m`そして好きな俳優`k`。 O(1) ルックアップ用にお気に入りの ID をセットに保存します。 
2. 動画の本数を読み取る`n`。 映画ごとに、タイトル、俳優の数を保存します`d`、およびアクター ID のリスト。不明な ID (0) を追跡します。 
3. 映画ごとにカウントします。`f_known`すでに存在するお気に入りの俳優の数として、そして`u`未知の俳優の数として。 
4. 映画の中で可能な最大のお気に入り俳優を次のように計算します。`f_known + min(u, k - f_known_other)`。 俳優は映画内で区別されるため、最大値は、この映画にまだ出演していないお気に入りの俳優によって制限されます。 
5. 可能な最小限のお気に入りの俳優を次のように計算します。`f_known`。 未知のアクターの数が利用可能な非お気に入りアクターの数を超える場合、一部はお気に入りになるはずなので、それに応じて最小値を増やします。 
6. すべてのムービーの最小カウントと最大カウントを収集します。 
7. 各ムービーについて、出力を決定します。 

- 最小可能お気に入り数が少なくとも他のすべての映画の最大可能お気に入り数である場合、0 (確かにお気に入り) を出力します。 
- 最大可能お気に入り数が他のムービーの最大可能お気に入り数よりも小さい場合、1 を出力します (確かにお気に入りではありません)。 
- それ以外の場合は、出力 2 (どちらでも可能)。 
8. 入力順に結果を出力します。 

**機能する理由:** 各映画のお気に入り数の極端な値を追跡することで、未知の俳優の割り当てが分類に矛盾しないことを保証します。 すべての決定は可能な範囲のみに依存し、正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

m, k = map(int, input().split())
fav = set(map(int, input().split()))
n = int(input())

movies = []

for _ in range(n):
    title = input().strip()
    d = int(input())
    actors = list(map(int, input().split()))
    f_known = sum(1 for a in actors if a in fav)
    u = actors.count(0)
    movies.append({'title': title, 'f_known': f_known, 'unknown': u, 'd': d})

min_favs = []
max_favs = []

for movie in movies:
    f_known = movie['f_known']
    u = movie['unknown']
    d = movie['d']
    
    # maximum possible favorite actors
    max_possible = f_known + min(u, k - f_known)
    
    # minimum possible favorite actors
    non_favs_total = m - k
    max_non_favs_in_movie = min(u, non_favs_total - (d - f_known - u))
    min_possible = f_known + max(0, u - max_non_favs_in_movie)
    
    min_favs.append(min_possible)
    max_favs.append(max_possible)

results = []

for i in range(n):
    sure_fav = all(min_favs[i] >= max_favs[j] for j in range(n) if j != i)
    sure_not = any(max_favs[i] < max_favs[j] for j in range(n) if j != i)
    if sure_fav:
        results.append(0)
    elif sure_not:
        results.append(1)
    else:
        results.append(2)

print('\n'.join(map(str, results)))
```**説明:** ソリューションは最初にすべての入力を読み取り、映画ごとに既知のお気に入りの俳優と未知の俳優を計算します。 次に、可能性のあるお気に入りの俳優の範囲を計算します。 最後に、その最小値/最大値と他の映画の最大値を比較して、各映画を分類します。 微妙な部分には、お気に入りを残すことで最大値を制限することと、お気に入り以外のものが十分にないために未知のものを強制的にお気に入りにする可能性がある場合の最小値を計算することが含まれます。
