 ## 解決策
 ## 問題の理解

 私たちは、ヴァシャさんが電車に乗って教科書を読むのに最適な時間を選ぶのを手伝ってほしいと頼まれました。 列車の旅は _n_ 時間続き、各時間には 0 から 100 までの特定の光レベルがあります。Vasya はちょうど _k_ 時間読書したいと考えています。 彼の目標は、選択した時間のうち最も暗い時間ができるだけ明るくなるように _k_ 時間を選択することです。 言い換えれば、彼が光レベル 20、30、および 40 の時間帯に読書をする場合、これらの最小値である 20 が、_k_ 時間のすべての可能なセットにわたって最大化される必要があります。 

入力により、時間数 _n_、読書時間数 _k_、およびすべての時間の光レベルが得られます。 出力では、最初に達成可能な最小光レベルの最大値が報告され、次に Vasya が選択する必要がある時間のインデックスが続きます。 複数の最適なソリューションが存在する可能性があります。 

制約は中程度です: _n_ は最大 1000 までです。これは、$O(n \log n)$または$O(n^2)$アプローチは実現可能ですが、次のような指数関数的なものは何でも$O(n^k)$遅すぎるでしょう。 光レベルは 0 ～ 100 であるため、この小さな範囲を利用することもできますが、より簡単なアプローチは、値の頻度ではなく時間の選択に焦点を当てることです。 

エッジ ケースには、すべての時間が同じ光である場合、読書時間数 _k_ が _n_ に等しい場合、または光の最大値と最小値が等しい場合が含まれます。 不注意なアプローチでは、連続した時間を選択しようとしたり、正しいインデックス作成に失敗したりして、間違った答えが得られる可能性があります。 

## アプローチ

 単純なアプローチでは、_n_ 時間のうちの _k_ 時間のすべての組み合わせを考慮し、各組み合わせの最小光を計算し、最小値が最も高いものを選択します。 これは正しいですが、実行不可能です。組み合わせの数は次のとおりです。$\binom{n}{k}$これは非常に速く成長します (_n_ = 1000 および _k_ = 500 の場合、それは天文学的に大きくなります)。 

重要な洞察は、すべての組み合わせを調べる必要はないということです。 選択した時間帯の中で最小の光を最大化することのみを考慮するため、最適なセットには _k_ 番目の最も明るい時間が含まれている必要があります。 光レベルで時間を並べ替え、_k_ 最も大きい時間を選択することで、可能な限り最大の最小値が保証されます。 これらの選択された時間帯の最小光は、単に選択されたサブセット内の最小値であり、これが$k$-完全な配列内で 2 番目に大きい。 これらの時間を選択した後、元のインデックスを出力します。 

このアプローチにより、問題は並べ替えと選択のタスクに集約されます。 テイクの並べ替え$O(n \log n)$時間がかかり、上位 _k_ を選択してインデックスを取得するには時間がかかります$O(n)$。 これは、特定の制約に対して効率的です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n は k × k を選択します) | O(k) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力値: _n_ と _k_ を読み取り、その後に光レベルのリストを読み取ります。 
2. 各ライト レベルを元の 1 から始まるインデックスと組み合わせます。 これにより、並べ替え後の時間の位置が保持されます。 
3. ペアのリストを光レベルの降順に並べ替えます。 これにより、最初の _k_ 要素が光レベルが最も高い時間になることが保証されます。 
4. ソートされたリストから最初の _k_ ペアを取得します。 読書に最適な時間です。 
5. 選択した時間帯の最小光レベルを抽出します。これは、リストが降順でソートされているため、上位 _k_ サブセットの最後の要素です。 
6. 選択した時間のインデックスをペアから収集し、任意の順序で出力します。 

機能する理由: 光によって時間を並べ替えると、より小さい光レベルを含むセットでは、より良い最小値が得られないことが保証されます。 上位の _k_ 値を取得することで、このサブセット内の最小値が可能な限り大きくなるようにします。 インデックスは光レベルと一緒に保存することで保存されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
lights = list(map(int, input().split()))

# Pair light levels with their original indices
hours = [(lights[i], i+1) for i in range(n)]

# Sort descending by light level
hours.sort(reverse=True, key=lambda x: x[0])

# Take top k hours
selected = hours[:k]

# Minimum light among chosen hours
min_light = min(l[0] for l in selected)

# Extract indices
indices = [l[1] for l in selected]

print(min_light)
print(" ".join(map(str, indices)))
```このソリューションはデータを読み取り、光レベルと時間インデックスを組み合わせて位置を保持し、ペアを光の降順に並べ替えて、上位 _k_ を選択します。 Pythonの組み込み機能を使用して最小限の光を抽出します`min`ただし、ソートされた上位 _k_ リストの最後の要素である可能性もあります。 インデックスは任意の順序で印刷されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n log n) | リストの並べ替えが実行時間を支配します。 
| スペース | O(n) | 光レベルとインデックスのペアを保存する |

 n ≤ 1000 とすると、これは 1 秒の時間制限と 256 MB のメモリ制限内に十分収まります。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, k = map(int, input().split())
    lights = list(map(int, input().split()))
    hours = [(lights[i], i+1) for i in range(n)]
    hours.sort(reverse=True, key=lambda x: x[0])
    selected = hours[:k]
    min_light = min(l[0] for l in selected)
    indices = [l[1] for l in selected]
    return f"{min_light}\n{' '.join(map(str, indices))}"

# Provided sample
assert run("5 3\n20 10 30 40 10\n") == "20\n4 3 1"

# Minimum-size input
assert run("1 1\n0\n") == "0\n1"

# Maximum-size input (all 100)
assert run("1000 1000\n" + " ".join(["100"]*1000) + "\n") == "100\n" + " ".join(str(i) for i in range(1,1001))

# All-equal values, k<n
assert run("5 2\n10 10 10 10 10\n") == "10\n1 2"

# Mixed values, k<n
assert run("6 3\n5 1 9 2 8 3\n") == "5\n3 5 1"
