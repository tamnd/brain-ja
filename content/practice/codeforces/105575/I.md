 ## 解決策
 ## 問題の理解

 同じ頂点セットに対する有向制約と無向関係を備えたグラフ構造が与えられています。 有向エッジは違反できない厳密な順序付けルールを表しますが、無向エッジは柔軟性があり、最終結果で方向を割り当てる必要があります。 

タスクは、指定された有向エッジを維持しながら、グラフ全体が非巡回になるようにすべての無向エッジを方向付けることが可能かどうかを判断することです。 可能であれば、すべての無向エッジに対して一貫した方向を出力する必要があります。 それ以外の場合は、有効な構造が存在しないと出力されます。 

重要な問題は、有向エッジがすでに半順序制約を課していることです。 これらの制約にサイクルが含まれている場合、有向エッジは不変であるため、無向エッジに方向を割り当てても矛盾を解決できません。 有向部分が非巡回である場合、無向エッジは常に、その非巡回構造から導出されるグローバル順序付けに従って一貫して方向付けられます。 

この制約は、最大 200,000 個の頂点とエッジを持つグラフを意味します。 これにより、あらゆるソリューションが線形または線形に近い時間で実行されます。 エッジまたは頂点を越える二次関数の動作は直ちに失敗します。 これにより、エッジ方向のシミュレーションを繰り返したり、割り当てのバックトラックを試みたりして一貫性をテストしようとするアプローチが除外されます。 

直観的にそれを「壊す」ことができるように見える無向エッジが存在するにもかかわらず、有向エッジがサイクルを形成する場合、微妙な失敗ケースが発生します。 たとえば、1 → 2、2 → 3、3 → 1 がすべて有向辺である場合、たとえ無向辺がたくさんあったとしても、答えはすぐに不可能になります。 最初に無向エッジの方向を設定しようとする単純なアプローチでは、サイクルを回避できると誤って信じてしまう可能性がありますが、有向サイクルはすでに致命的です。 

もう 1 つのエッジ ケースは、有向エッジがまったくない場合です。 その場合、頂点の任意の順序が機能するため、常に無向エッジの有効な方向を生成できます。 

## アプローチ

 強引なアイデアは、すべての方向のないエッジを二者択一として扱い、可能なすべての方向を試すことです。 方向を割り当てた後、トポロジカル ソートまたは DFS サイクル検出を使用して、結果の有向グラフが非循環であるかどうかを確認します。 最悪の場合、無向エッジが最大 O(m2) 存在する可能性があるため、このアプローチは 2^m 個の構成に爆発的に増加し、単一の妥当性チェックでさえ O(n + m) のコストがかかるため、完全に実行不可能になります。 

重要な観察は、有向エッジが半順序を定義するということです。 この部分順序が一貫している場合、つまりサイクルがない場合は、すべての頂点の完全な線形順序に拡張できます。 このような線形順序を設定すると、すべての無向エッジをその順序で前から後へ単純に方向付けることができます。 すべてのエッジが単一のグローバル順序を尊重するため、これによりサイクルが導入されないことが自動的に保証されます。 

したがって、問題全体は、有向サブグラフが DAG であるかどうかを確認し、DAG である場合はトポロジカルな順序付けを構築することに帰着します。 この順序が存在すると、すべての無向エッジの方向を設定するのが簡単になります。

 ## アルゴリズムのチュートリアル

1. 有向エッジのみを使用して有向グラフを構築します。 すべての頂点の入次数を計算します。 これにより、無向エッジの処理方法に関係なく、必須で満たさなければならない制約が分離されます。 
2. キューを使用してトポロジカル ソートの標準カーン アルゴリズムを実行します。 入次数が 0 のすべての頂点から開始します。 これらの頂点には前提条件がなく、有効な順序で最も早く現れることができます。 
3. キューから頂点を繰り返し削除し、グローバル順序付けで次の位置を割り当て、その近傍の次数を減らします。 近傍の次数が 0 になるたびに、それをキューにプッシュします。 
4. 最後に処理される頂点の数が n 未満の場合、有向グラフ内にサイクルが存在します。 この場合、有向制約は本質的に矛盾しているため、有効な方向は存在できません。 
5. 完全な順序が得られた場合は、それを使用してすべての無向エッジに方向を割り当てます。 各無向エッジ (u、v) について、位相順序での位置を比較し、エッジを前の頂点から後の頂点に向けます。 

### なぜ効果があるのか

 トポロジー的順序は、すべての有向エッジと一致する厳密な全体的な順序を定義します。 すべての有向エッジ u → v は、この順序で u が v の前に現れることを保証します。 この順序に従って指向されたエッジは、有向サイクルを作成することはできません。これは、後続のエッジが常に順序内の位置を厳密に増加させるためです。 すべての無向エッジはこの単調規則に従うことを強制されるため、最終的なグラフは線形順序から直接非巡回性を継承します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m1, m2 = map(int, input().split())

    undirected = []
    adj = [[] for _ in range(n + 1)]
    indeg = [0] * (n + 1)

    # undirected edges
    for _ in range(m1):
        u, v = map(int, input().split())
        undirected.append((u, v))

    # directed edges
    for _ in range(m2):
        u, v = map(int, input().split())
        adj[u].append(v)
        indeg[v] += 1

    from collections import deque
    q = deque([i for i in range(1, n + 1) if indeg[i] == 0])

    topo = []
    while q:
        u = q.popleft()
        topo.append(u)
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)

    if len(topo) != n:
        print(-1)
        return

    pos = [0] * (n + 1)
    for i, v in enumerate(topo):
        pos[v] = i

    for u, v in undirected:
        if pos[u] < pos[v]:
            print(u, v)
        else:
            print(v, u)

t = 1
for _ in range(t):
    solve()
```この解決策は、有向エッジのみが実現可能性に影響を与えるため、無向エッジと有向エッジを即座に分離します。 隣接リストと度数配列は、純粋にカーンのアルゴリズムのために使用されます。 キューには最初、入力される有向エッジのないすべての頂点が含まれており、有効な部分順序を常に拡張することが保証されます。 

重要な手順は、トポロジカル ソートがすべての頂点をカバーしているかどうかを確認することです。 そうでない場合、有向制約はすでに矛盾しているため、これ以上の処理は意味がありません。 

順序が計算されたら、各頂点をその位置にマッピングします。 これにより、すべての無向エッジの定数時間比較が可能になります。 各無向エッジは、このグローバルな順序に従って厳密に方向付けられ、一貫性が保証されます。 

## 実用的な例

 小さな有向構造を持つケースを考えてみましょう。 

入力:

 n = 4

 有向エッジ: 1 → 2、2 → 3

 無向エッジ: (1, 3)、(4, 2)

 トポロジカルプロセス:

 | ステップ | キュー | ポップ | トポ | 度数変化 |
 | --- | --- | --- | --- | --- |
 | 1 | [1,4] | 1 | [1] | 2→0 |
 | 2 | [4,2] | 4 | [1,4] | なし |
 | 3 | [2] | 2 | [1,4,2] | 3→0 |
 | 4 | [3] | 3 | [1,4,2,3] | 完了 |

 最終順位は[1,4,2,3]です。 次に、無向エッジの方向を設定します。 

エッジ (1,3): 3 の前の 1、1 → 3 になります。 

エッジ (4,2): 2 の前の 4、4 → 2 になります。 

これは、トポロジー的順序が存在すると、すべての無向エッジがその順序と一致することを示しています。 

ここで失敗例を考えてみましょう。 

入力:

 n = 3

 有向エッジ: 1 → 2、2 → 3、3 → 1

 無向エッジ: なし

 キューはすぐに空になるか、処理されるノードが 3 つ未満で終了します。 アルゴリズムは、すべてのノードがトポに含まれていないことを検出したため、出力は -1 になります。 これは、有向サイクルを修復できないことを示しています。

 ## 特殊なケース

 重要なエッジ ケースは、有向エッジがまったく存在しない場合です。 その状況では、すべての頂点は最初に次数 0 を持っているため、キューはすべてのノードから開始されます。 トポロジー的な順序付けはどれも有効であり、アルゴリズムは完全な順列を即座に生成します。 すべての無向エッジは、その順列に従って任意に方向付けられますが、これは常に有効です。 

別のエッジ ケースは、有向エッジがチェーンと孤立したノードを形成する場合です。 トポロジー的順序により、孤立したノードはチェーンに対して任意の位置に配置されますが、孤立したノードには制約が課されないため、これは正確さに影響しません。 

障害エッジ ケースは、多くのノード間に隠された有向サイクルです。 たとえば、より大きなグラフ内で 3 つのノードだけがサイクルを形成している場合、カーンのアルゴリズムは早期に停止します。 最後のトポ長チェックでは、サイクルを明示的に検索する必要なく、これが検出されます。
