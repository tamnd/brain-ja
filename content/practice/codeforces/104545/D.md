 ## 解決策
 ## 問題の理解

 長さのシーケンスが与えられます$n$、各位置はセットの固定数字のいずれかです。$\{0,1,2\}$または次のようにマークされた欠損値$-1$。 タスクは、すべての配列を置き換えることによって形成できる完全な配列の数を数えることです。$-1$数字が入っている$\{0,1,2\}$、グローバル制約の下では、連続する 3 つの要素の合計が正確に 3 になる必要があります。 

すべてのトリプルを結合するため、制約は強力です$(a_i, a_{i+1}, a_{i+2})$。 2 つの連続する値が固定されると、3 番目の値が強制されます。 これは、配列が位置ごとに自由に選択されているわけではないことを直ちに示唆しています。 代わりに、有効なシーケンスが最初の 2 つの値によって完全に決定される 2 次反復のように動作します。 

入力サイズが到達しました$n = 10^6$これにより、すべての割り当て、さらにはすべてのローカル構成を個別に試行するアプローチが不要になります。 どのような解も線形である必要があります$n$、さえ$O(n \log n)$許容範囲ですが、$O(n^2)$不可能です。 

初期の値が欠落している場合、微妙な問題が発生します。 最初の要素と 2 番目の要素の両方が$-1$、各選択は決定論的に伝播するため、可能なシーケンスの数は単なるローカル分岐の問題ではありません。 もう 1 つの失敗ケースは、部分的な代入によって後で矛盾が生じる場合です。たとえば、固定値が繰り返しの意味するものと一致しない場合です。 

重要な課題は、シーケンスを構築することではなく、すべての制約と固定位置と一致する初期シードの数を数えることです。 

## アプローチ

 強引なアイデアは単純明快です。すべてを扱います。$-1$分岐点として、からのすべての割り当てを試してください。$\{0,1,2\}$、次に完全なシーケンスが三重和条件を満たすかどうかを確認します。 これは定義を直接適用するため正しいですが、欠落しているエントリの数が指数関数的に増加します。 最悪の場合、すべての位置が等しい場合、$-1$、これは次のようになります$3^n$、非常に小さい場合でも完全に実行不可能です。$n$。 

構造的な洞察は、制約を書き直すことで得られます。 から$$a_i + a_{i+1} + a_{i+2} = 3,$$私たちは得ます$$a_{i+2} = 3 - a_i - a_{i+1}.$$これは一度という意味です$a_1$そして$a_2$are fixed, the entire sequence is uniquely determined. There are only nine possible starting pairs, so instead of exploring all full sequences, we only simulate nine deterministic propagations.

 The only remaining problem is consistency with the given partially filled array. For each candidate starting pair, we generate the full sequence and verify that every fixed position matches. If it does, this candidate contributes 1 to the answer.

 This reduces the problem from exponential search over all completions to a constant number of linear simulations.

 ## アルゴリズムのチュートリアル

 1. 可能なすべての値を反復処理します。$(a_1, a_2)$ここで、それぞれは 0、1、または 2 です。候補はちょうど 9 つあり、それぞれが再発の可能性のあるシードを表します。 
2. 候補ペアごとに、次の長さのシーケンスを構築します。$n$。 Set the first two values accordingly and propagate forward using the rule$a_i = 3 - a_{i-1} - a_{i-2}$。 このステップが必要なのは、トリプルサム条件によって次のすべての要素が一意に決定されるためです。 
3. シーケンスの生成中に、計算された各値を入力配列と比較します。 入力に固定値がある場合 (そうでない場合)$-1$)、正確に一致する必要があります。 不一致が発生した場合は、違反した反復制約を修復できない拡張機能がないため、この候補はすぐに破棄されます。 
4. 完全なシーケンスが矛盾なく生成された場合、この候補は有効としてカウントされます。 
5. すべての有効な開始ペアを合計し、合計を出力します。 

### なぜ効果があるのか

 漸化式により、問題は 2 次の線形制約システムに変換されます。 有効なシーケンスはすべて、インデックス順に同じ決定論的ルールを満たすため、すべての解は最初の 2 つの値によって一意に決定されます。 したがって、すべての有効なシーケンスを列挙することは、すべての有効な初期条件を列挙することと同じです。 一貫性チェックにより、部分的に観察された値と互換性のあるシーケンスのみがカウントされることが保証されるため、無効な再構成は含まれません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    def valid(a1, a2):
        if a[0] != -1 and a[0] != a1:
            return False
        if n > 1 and a[1] != -1 and a[1] != a2:
            return False

        x0, x1 = a1, a2
        for i in range(2, n):
            x2 = 3 - x0 - x1
            if x2 < 0 or x2 > 2:
                return False
            if a[i] != -1 and a[i] != x2:
                return False
            x0, x1 = x1, x2

        return True

    ans = 0
    for a1 in range(3):
        for a2 in range(3):
            ans += valid(a1, a2)

    print(ans)

if __name__ == "__main__":
    solve()
```このソリューションは、固定開始ペアが入力制約と一致するシーケンスを生成できるかどうかをテストするヘルパー関数を中心に構築されています。 繰り返しは繰り返し適用され、最後の 2 つの値のみが維持されるため、シーケンス全体の保存が回避されます。 

微妙な点は、計算値が範囲外の場合の早期拒否です。$\{0,1,2\}$。 これが必要なのは、漸化式では代数的に負​​の値または 2 を超える値が許容されますが、そのようなシーケンスは定義上無効であるためです。

 ## 特殊なケース

 重要なエッジケースは、最初の 2 つの値が指定されていない場合です。 次のような入力の場合:```
n = 3
-1 -1 -1
```このアルゴリズムは、9 つ​​の開始ペアすべてをテストします。 各ペアは有効なシーケンスを 1 つだけ生成し、制約によってフィルタリングされるものはありません。 これにより、答えは 9 になります。これは、制約が適用される前は最初の選択肢がすべて独立しているという事実と一致します。 

もう一つのケースは初期矛盾です。 のために：```
n = 3
0 0 0
```最初の 2 つの値により、3 番目の値が 3 に強制されます。これは、許容範囲に違反します。 すべての開始ペアは伝播中に拒否され、アルゴリズムは完全な列挙を必要とせずに正しく 0 を返します。 

3 番目の微妙なケースは、固定値が遅れて表示され、拒否を強制される場合です。 シーケンスが多くのステップで一貫しているが、伝播された値と一致しない位置が 1 つある場合、候補は直ちに破棄されます。 これにより、無効なシーケンスが部分的に寄与することがなくなり、カウントの正確さが維持されます。
