 ## 解決策
 ## 問題の理解

 軸に揃えられたいくつかの長方形が与えられ、各長方形の左下隅は原点に固定され、右上隅は次のように与えられます。$(w_i, h_i)$。 したがって、各入力ペアはすべての点をカバーする長方形を定義します。$(x, y)$そのような$0 \le x \le w_i$そして$0 \le y \le h_i$。 

これらすべての四角形は和集合を使用して結合されます。つまり、点が少なくとも 1 つの四角形内に存在する場合、その点は許可されます。 タスクは、この結合によってカバーされる総面積を計算することです。 

重要な観察は、すべての長方形が同じ角を共有していることです。$(0,0)$、つまり、それらはすべて同じ場所に「固定」されています。 これにより、ジオメトリが高度に構造化されます。結合は任意の重なり合う長方形ではなく、原点から広がる長方形の集合になります。 

制約により、最大で$10^5$長方形と座標まで$10^9$。 これにより、カバレッジをポイントごとにチェックしたり、グリッド全体を離散化したりするアプローチは即座に排除されます。 両方の次元を対称的に扱おうとすると、単純に座標をスイープすることさえ不可能になります。 

重複推論では微妙な問題が発生します。 長方形が1つある場合、$(3, 10)$そしてもう一つは$(10, 3)$どちらももう一方を完全に含んでいないため、単純な「最大幅と最大高さを取得する」は正しくありません。 すべてのペアが両方の次元で同等でない限り、和集合は単一の長方形ではありません。 

2 番目のエッジ ケースは、多くの長方形が他の長方形を部分的に支配する場合です。 例えば、$(5, 100)$、$(100, 5)$、$(6, 6)$。 構造を慎重に検討しない限り、結合は明らかではありません。 

正しい出力は単一の整数、つまり少なくとも 1 つの四角形でカバーされる合計領域です。 

## アプローチ

 ブルートフォースアプローチでは、飛行機をモデル化し、カバレッジをマークしようとします。 1 つの方法は、グリッドを次のように想像することです。$10^9 \times 10^9$、それは直ちに不可能です。 座標を圧縮しても、まだ次の作業が必要です$10^5$明確な x 境界と y 境界があり、それらによって形成されるグリッド内のすべてのセルをチェックすると、$O(n^2)$またはより悪い行動。 

もう 1 つの大胆なアイデアは、長方形を並べ替えて貪欲に結合しようとすることです。 ただし、長方形は完全な順序でネストされていないため、幅または高さのみに基づいて貪欲なマージは失敗します。 

重要な構造的洞察は、次の形式の長方形の結合であるということです。$[0, w_i] \times [0, h_i]$別の解釈が可能です。 2D で直接考える代わりに、X 軸に沿って列ごとに考えることができます。 

いくつかの×を修正します。 この X 座標では、長方形は高さまでの範囲に寄与します。$h_i$もし、そしてその場合に限り$x \le w_i$。 したがって、位置 x では、結合の高さは最大になります。$h_i$少なくとも x 内に広がるすべての長方形の中で。 

これにより、問題は 1 次元のスイープに変換されます。 各長方形は間隔に寄与します$[0, w_i]$価値のあるもの$h_i$。 各 x について、アクティブな間隔の最大の高さを求めてから、x にわたって積分します。 

長方形を降順にソートします$w_i$。 大きな x から小さな x に移動すると、より多くの四角形がアクティブになります。 2 つの連続する幅の間にある現在の回答セグメントは、これまでに確認された最大高さのみに依存します。 

これにより、ソートされたエンドポイントをスイープする際に実行最大値を維持するという問題が軽減されます。

 ## アルゴリズムのチュートリアル

 各四角形を、0 から 0 までの x 軸上の寄与範囲として再解釈します。$w_i$、一定の高さで$h_i$。 このカバレッジの開始位置と終了位置をソート順に処理します。 

1. すべての長方形を降順に並べ替えます。$w_i$。 これにより、x 軸上を左から右に (大きい x から小さい x に) 移動するにつれて、より多くの四角形が徐々に「アクティブ化」されます。 
2. 変数を初期化する`max_h = 0`そして変数`prev_w = 0`最後に処理された x 境界を追跡します。 にエリアを蓄積していきます`ans`。 
3. ソートされた順序で四角形を移動します。 長方形ごとに$(w_i, h_i)$、 扱う$w_i$新しい影響の間隔が始まるブレークポイントとして。 
4. アップデートの前に`max_h`、間のセグメントが寄与する面積を追加します。`w_i`そして`prev_w`。 このセグメントの幅は`prev_w - w_i`、その高さは`max_h`。 そこで追加します`(prev_w - w_i) * max_h`答えに。 これが機能するのは、この範囲ではアクティブな四角形のセットが変化しないため、最大の高さが一定のままであるためです。 
5.アップデート`max_h = max(max_h, h_i)`この四角形は次の時点でアクティブになるため、$x \le w_i$。 
6.セット`prev_w = w_i`そして続けます。 
7. すべての長方形を処理した後、最小の長方形を超えるものは何も残りません。$w_i$したがって、実質的に x = 0 から開始するため、追加の貢献は必要ありません。 

### なぜ効果があるのか

 どの x 座標においても、アクティブな四角形のセットは正確に次のものとなります。$w_i \ge x$。 ソート後、これは処理された四角形の接頭辞に対応します。 アルゴリズムは、このプレフィックスを超える最大高さを維持します。 連続ソート間$w_i$、アクティブ セットは変化しないため、結合の高さは一定です。 これにより、x の正しい区分定数関数が作成され、総面積はその関数の積分になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    rects = []
    for _ in range(n):
        w, h = map(int, input().split())
        rects.append((w, h))

    rects.sort(reverse=True)

    max_h = 0
    prev_w = rects[0][0]
    ans = 0

    for w, h in rects:
        ans += max_h * (prev_w - w)
        if h > max_h:
            max_h = h
        prev_w = w

    print(ans)

if __name__ == "__main__":
    solve()
```この解決策は、幅の減少を処理するために長方形を並べ替えることから始まります。 変数`max_h`幅が少なくとも現在の x 位置であるすべての四角形の中で、現在到達可能な最適な高さを格納します。 重要なのは蓄積です`ans += max_h * (prev_w - w)`、高さが変化しない垂直ストリップの面積を計算します。 

微妙な点の 1 つは、`prev_w`。 この定式化では最大幅を超える領域が存在しないため、最大幅から開始します。 もう 1 つの重要な詳細は、更新`max_h`これは、現在のセグメントの領域を追加した後に発生し、まだアクティブではない領域に四角形が早まって含まれないようにします。

 ## 特殊なケース

 重要なエッジケースは、長方形が 1 つしかない場合です。 アルゴリズムが初期化されます`prev_w`長方形の幅に合わせて拡大され、意味のあるセグメントに入ることはなく、面積がゼロになります。 これは、積分する幅間隔がないスイープの解釈と一致します。 

もう 1 つのケースは、幅が広くて短い長方形の後に、非常に高いが幅の狭い長方形が表示される場合です。 スイープにより、その高さが左側の領域にのみ影響することが保証され、前のセグメントが誤って膨張することはありません。`max_h`セグメントの貢献後に更新されます。 

最後に、複数の長方形が同じ幅を共有する場合、それらは同一の境界間に水平セグメントに寄与しません。 アルゴリズムはそれらを自然に崩壊させます。`(prev_w - w)`はゼロになるため、重複は面積計算に影響しません。
