 ## 解決策
 ## 問題の理解

 私たちには、各グループのサイズが固定されたいくつかのノームのグループと、それぞれが指定されたサイズの代表団を必要とするいくつかの王宮が与えられています。 正確に 2 つの異なるコートと 1 つの gnome コミュニティを選択し、そのコミュニティを、選択したコートの要件に一致するサイズの 2 つの独立したグループに分割する必要があります。 

具体的に、ある程度の規模のコミュニティを選択すると、`a`、および2つの裁判所が要求する`b_i`そして`b_j`を確保しなければなりません`a ≥ b_i + b_j`。 その後、順序付けられていないセットを選択します。`b_i`コミュニティからノームを選択し、順序のない別のノームのセットを選択します。`b_j`残りのノームからのノーム。 残りのノームは無関係です。 

課題は、このプロセス全体を実行できる方法が何通りあるのかを数えることであり、コミュニティのさまざまな選択や実際のノームのさまざまなサブセットが区別されると考えられます。 答えは 998244353 を法として求められます。 

制約は大きく、コミュニティとコートの数は最大 200,000、サイズは最大 200,000 です。すべてのコートのペアとすべてのコミュニティを反復しようとするソリューションは、約 10^10 またはさらに悪い操作に直接つながり、これは実行可能な制限をはるかに超えています。 これにより、法廷での単純な 2 次または 3 次の組み合わせ論や部分集合の強引な列挙が即座に排除されます。 

両方の選択されたコートが同じ数のノームを必要とする場合、微妙な問題が発生します。 その場合、どのサブセットがどのコートに属するかを交換しても、サブセットの選択は変わりませんが、コート自体は異なるため、カウントの順序を明示的に正規化しない限り、割り当ては依然として異なります。 順序付けされた割り当てと順序付けされていないコート ペアの間のこの相互作用は慎重に処理する必要があります。そうしないと、二重にカウントされたり、有効な構成を見逃したりすることになります。 

## アプローチ

 直接的な解釈では、すべてのコミュニティを試し、次にすべての裁判所のペアを試し、二項選択肢を数えることになります。 コミュニティの規模が固定されている場合`a_k`そして固定ペア`(b_i, b_j)`、方法の数は`C(a_k, b_i) * C(a_k - b_i, b_j)`。 これをすべてのコミュニティとすべてのコート ペアにわたって合計することは正しいですが、三重ループ構造が導入されるため、計算上不可能です。`n`、`m`、そしてもう一つ`m`。 

重要な観察は、組み合わせ部分は値のみに依存するということです。`a_k`、`b_i`、 そして`b_j`、アイデンティティではありません。 これにより、必要なサイズごとにコートを集約することができます。 させて`cnt[b]`必要なサイズのコートの数を示します`b`。 

次に、コミュニティのサイズごとに評価したいと思います。`a`、裁判所の要件のすべてのペアの合計。 この式は、当然のことながら、二項係数を含む組み合わせ因子と、次の周波数因子に分かれます。`cnt`。 

主な難点は、表現に次のような用語が含まれていることです。`C(a, b1)`そして`C(a - b1, b2)`, これでも 2 つのコート サイズが結合されています。 コツは、畳み込みを適用できるように階乗形式を使用して二項係数を書き直すことです。 具体的には、`C(n, k) = n! / (k! (n-k)!)`、これにより、依存関係を分離することができます。`k`そして`n-k`。 

これにより、問題は、次から導出されたシーケンスに対する複数の畳み込み計算に変換されます。`cnt`、`1/k!`、および関連する変換。 これらの畳み込みが NTT を使用して事前計算されると、各コミュニティ サイズを一定時間で評価できます。 

最後に、順序付きコートペアと順序なしコートペアの区別を扱います。 最初に別個のコートの順序付きペアを数えてから、両方のコートのサイズが同じでも異なるインデックスに対応する場合を修正しながら、適切に分割する方が簡単です。

 ## アルゴリズムのチュートリアル

 ### ステップ 1: 必要なサイズごとにコートをグループ化する

 法廷要件のリストを周波数配列に圧縮します`cnt[b]`、 どこ`b`は必要な委任のサイズです。 これにより、裁判所のアイデンティティへの依存が取り除かれ、価値ベースの構造のみが残ります。 

すべての組み合わせ式はサイズのみに依存し、どのコートから来たのかには依存しないため、このステップは不可欠です。 

### ステップ 2: 階乗表現を事前計算する

 可能な最大サイズまで階乗と逆階乗を計算します。 これにより、変換された形式での二項係数の定数時間計算が可能になります。 

また、2 つの補助配列も定義します。`P[b] = cnt[b] / b!`そして`Q[x] = 1 / x!`。 

これらは、二項和を畳み込みに変換するために使用されます。 

### ステップ 3: 単一二項集計の最初の畳み込み

 の畳み込みを構築します`P`逆転した状態で`Q`、配列を生成します`C1`任意の値に対して`x`、それは次のようにエンコードします。`sum_b cnt[b] * C(x, b)`乗法因数まで。 

このステップでは、すべてのコート サイズにわたる二項合計を単一の事前計算された配列ルックアップに変換します。 

### ステップ 4: 二重構造の変換された畳み込みを構築する

 ここで、2 番目の二項係数が最初のコート サイズを選択した後の残りのキャパシティに依存する式が必要になります。 これにより、以前に計算された構造に 2 番目の畳み込みが導入されます。 

効果的に集約する別の畳み込みを構築します。`sum_b1 cnt[b1] * C(a, b1) * (a - b1)! * C1[a - b1]`。 

これもまた、次の間の標準的な畳み込みになります。`P`そして次から導出された変換された配列`C1`、2番目の事前計算配列を生成します`C2`。 

### ステップ 5: 同一インデックスの除外を処理する

 法廷の順序付きペアを数えるとき、両方の選択が同じ法廷インスタンスに対応するケースを誤って含めてしまいました。 これらのケースを明示的に差し引きます。 

この修正により、シーケンスに対する 2 番目の畳み込みが行われます。`cnt[b]^2 / (b!)^2`、シフト階乗逆配列と組み合わせます。 これにより、別の事前計算された配列が生成されます`C3`。 

### ステップ 6: コミュニティのサイズごとに結果を結合する

 コミュニティの規模ごとに`a`、以下を組み合わせます。`answer_ordered[a] = a! * (C2[a] - C3[a])`。 

これにより、2 つの異なる裁判所の順序付けられた割り当ての数が得られます。 

最後に、順序のないコートのペアはそれぞれ 2 回カウントされるため、必要な答えを得るために 2 で割ります。 

### なぜ効果があるのか

 構築全体は、選択したサブセット サイズへの依存性を分離できるように、二項係数を階乗形式に書き直すことに依存しています。 分離可能になると、コート サイズにわたるすべての合計は、事前計算されたシーケンスの畳み込みになります。 正確さは、すべての有効な選択がこれらの変換された合計のインデックスのペアに一意に対応し、すべての無効な自己ペアが修正ステップで明示的に削除されるという事実から得られます。 最後に削除される意図的な順序付けされた重複を除き、構成が二重にカウントされることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAXV = 200000

# factorials
fact = [1] * (MAXV + 1)
invfact = [1] * (MAXV + 1)

for i in range(1, MAXV + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAXV] = pow(fact[MAXV], MOD - 2, MOD)
for i in range(MAXV, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def ntt(a, invert=False):
    n = len(a)
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            a[i], a[j] = a[j], a[i]

    length = 2
    while length <= n:
        wlen = pow(3, (MOD - 1) // length, MOD)
        if invert:
            wlen = pow(wlen, MOD - 2, MOD)
        for i in range(0, n, length):
            w = 1
            half = length >> 1
            for j in range(i, i + half):
                u = a[j]
                v = a[j + half] * w % MOD
                a[j] = (u + v) % MOD
                a[j + half] = (u - v) % MOD
                w = w * wlen % MOD
        length <<= 1

    if invert:
        inv_n = pow(n, MOD - 2, MOD)
        for i in range(n):
            a[i] = a[i] * inv_n % MOD

def convolution(a, b):
    n = 1
    while n < len(a) + len(b):
        n <<= 1
    fa = a[:] + [0] * (n - len(a))
    fb = b[:] + [0] * (n - len(b))
    ntt(fa)
    ntt(fb)
    for i in range(n):
        fa[i] = fa[i] * fb[i] % MOD
    ntt(fa, invert=True)
    return fa

n, m = map(int, input().split())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

cnt = [0] * (MAXV + 1)
for x in b:
    cnt[x] += 1

P = [0] * (MAXV + 1)
for i in range(MAXV + 1):
    P[i] = cnt[i] * invfact[i] % MOD

Q = [invfact[i] for i in range(MAXV + 1)]
Q_rev = Q[::-1]

C = convolution(P, Q_rev)

# first transform
D = [0] * (MAXV + 1)
for x in range(MAXV + 1):
    if x < len(C):
        D[x] = C[x] % MOD

E = convolution(P, D[::-1])

# main term per a
res1 = [0] * (MAXV + 1)
for x in range(MAXV + 1):
    if x < len(E):
        res1[x] = fact[x] * E[x] % MOD

# second correction term
S = [0] * (MAXV + 1)
for i in range(MAXV + 1):
    S[i] = cnt[i] * cnt[i] % MOD * invfact[i] % MOD * invfact[i] % MOD

T = [invfact[i] for i in range(MAXV + 1)]
S2 = [0] * (MAXV + 1)
for i in range(MAXV + 1):
    if 2 * i <= MAXV:
        S2[2 * i] = S[i]

F = convolution(S2, T[::-1])

res2 = [0] * (MAXV + 1)
for x in range(MAXV + 1):
    if x < len(F):
        res2[x] = fact[x] * F[x] % MOD

ans = 0
for ak in a:
    if ak <= MAXV:
        ans = (ans + (res1[ak] - res2[ak]) % MOD) % MOD

inv2 = (MOD + 1) // 2
ans = ans * inv2 % MOD

print(ans)
```この実装では、すべての組み合わせ構造が階乗ベースの変換に分離されるため、コート ペアへのあらゆる重度の依存性が畳み込み空間に消えます。 各畳み込みは、コート サイズに対する入れ子列挙であったものを置き換え、コミュニティに対する最後のループは定数時間の検索と演算のみを実行します。

 ## 特殊なケース

 多くのコートが同じ必要なサイズを共有する場合、微妙なエッジケースが発生します。 この状況では、裁判所は別個の組織であるため、同じ値は同じ選択を意味しません。 アルゴリズムはこれを正しく処理します。`cnt[b]`は集計のみに使用されますが、畳み込み構造は本質的に異なるインデックスの多重度を保持します。 

もう 1 つの重要なケースは、コミュニティの規模が 2 つの法廷要件の合計に正確に等しい場合に発生します。 その状況では、コミュニティの 1 つの分割のみが可能ですが、二項定式化は引き続き正しく生成されます。`C(a, b1) * C(0, b2) = 1`。 畳み込み表現では、この境界動作が維持されます。`C(0,0)`は当然 1 となり、無効な用語はすべて消えます。 

最後に、1 つのコート タイプのみが小さく、他のすべてのコート タイプがコミュニティ サイズを超えている場合、階乗ベースの式内で無効なパラメーターを持つ二項係数がゼロに評価されるため、すべての寄与は自動的にゼロに崩壊します。
