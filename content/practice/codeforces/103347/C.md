 ## 問題の理解

 私たちに与えられた円形の庭園は、$n$～のラベルが付いた花壇$1$に$n$、その後$n$折り返します$1$。 ジュリエットはベッドから始まります$1$。 時間は分単位で進行し、分単位で進みます。$i$、彼女の動きのステップサイズは正確です$i$、毎分増加します。 

より正確に言えば、彼女が所定の位置にいる場合$c$分の始まりに$i$、彼女は前に歩きます$i$円に沿って時計回りにステップし、その位置でその分を終了します$c + i \pmod n$。 そこで少し停止した後、次の数分でその位置から続行します。 

問題は、無限の時間をかけて、ジュリエットが少なくとも一度はすべての花壇に正確に止まるかどうかです。 言い換えれば、訪問した停止位置のセットが最終的にすべての剰余モジュロをカバーするかどうかを知りたいのです。$n$。 

重要な観察は、プロセスが決定論的であり、純粋に算術的であるということです。 後$k$分、彼女の位置は最初の合計です$k$自然数の剰余$n$、これは三角数です。$$S_k = 1 + 2 + \dots + k = \frac{k(k+1)}{2}$$したがって、問題は、シーケンスが次の順序であるかどうかを尋ねることに帰着します。$S_k \bmod n$最終的にはすべての剰余クラスのモジュロにヒットします$n$。 

制約$n \le 10^4$最大範囲について推論する必要がある可能性があるため、訪問したすべての状態を広い範囲に対して単純にチェックすることと組み合わせて、多くのステップにわたるシミュレーションを即座に除外します。$O(n)$またはそれ以上の別個の残基があり、プロセスは無限です。 直接シミュレーションも誤解を招きます。シーケンスが二次的に増加するため、構造を持たずに周期性について単純に考えると失敗する可能性があります。 

小さいときに微妙なエッジケースが表示されます$n$大きなものとは異なる動作をします。 例えば、$n = 2$2 つの残基間で自明に交互になりますが、$n = 3$自明ではない動きにもかかわらず、すべての残基をカバーできません。 これは、トラバーサル問題ではなく、隠れた数理論構造を示唆しています。 

## アプローチ

 ブルートフォース解釈では、多数のステップにわたってジュリエットの位置をシミュレートし、すべてのステップが終了するまで訪問した残基をセットに保存します。$n$が見られるか、繰り返しパターンが検出されます。 それぞれのステップは、$O(1)$ただし、必要なステップ数は制限されません。$n$、シーケンスモジュロなので$n$三角数に依存し、長い周期で繰り返すことができます。 最悪の場合、それをはるかに超えてシミュレーションする可能性があります。$O(n^2)$構造を検出するまでのステップ数は 1 秒の制限では信頼できません。 

重要な洞察は、「円上の移動」について考えるのをやめ、代わりに訪問した位置を二次多項式モジュロの値として扱うことです。$n$。 シーケンス$S_k = k(k+1)/2$は剰余算術によって管理され、到達可能な剰余のセットは、この 2 次多項式が全射法であるかどうかによって決まります。$n$。 

その後、問題は古典的な構造に崩壊します。つまり、動作は次のいずれかにのみ依存します。$n$は 2 の累乗です。 いつ$n$奇数の素因数を持つ場合、二次剰余構造のカバレッジが崩壊し、一部の剰余が到達不能になります。 いつ$n$が 2 の累乗である場合、増分の倍増構造により、時間の経過とともに残基が完全にカバーされることが保証されます。 

したがって、シミュレーションの代わりに、因数分解します。$n$より大きい奇数要素が含まれているかどうかを確認します。$1$。 「はい」の場合、答えは「いいえ」です。 それ以外の場合、答えは「YES」です。

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る$n$、円形の庭園の大きさを表します。 目標は、すべての位置を停止点として訪問できるかどうかを分類することです。 
2. 連続分割$n$による$2$均等なうちに。 これにより、因数分解において 2 の累乗がすべて分離されます。 このステップは、モジュラスの 2 進構造を抽出することに相当します。これは、このプロセスで完全にカバーできる唯一の構造です。 
3. 2 の因数をすべて削除した後、残りの値が以下であるかどうかを確認します。$1$。 それより大きい場合$1$、 それから$n$奇妙な要素を持っています。 
4. 奇数の要因が存在する場合は、完全なカバレッジは不可能であると直ちに結論付け、NO を出力します。 それ以外の場合、減額された値が$1$、YESを出力します。 

これが機能する理由は、三角数列を法とするためです。$n$有限リング上の二次マップのように動作します。 奇数の因数をもつモジュライ上では、このマップは制限されたサブセットに崩壊します。$1/2$は明確に定義されており、均一な適用を妨げる構造が導入されています。 2 の累乗を超えると、可逆性が欠如します。$2$残基の十分な混合が作成され、シーケンスが最終的にすべてのクラスにヒットできるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    # remove all factors of 2
    while n % 2 == 0:
        n //= 2
    
    # if anything other than 1 remains, there is an odd factor
    if n == 1:
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```この実装は因数分解ロジックを直接反映しています。 係数 2 を除去するループは安全です。$n \le 10^4$、だからせいぜい$O(\log n)$反復が発生します。 最終チェックでは、純粋な 2 の累乗を他のすべての整数から区別します。 

よくある間違いは、ジュリエットの動きを直接シミュレートしようとすることです。 このアプローチは失敗します。位置が二次関数的に増加し、小さなシミュレーション ウィンドウ内ではサイクルが明確にならないためです。
