 ## 問題の理解

 この問題は、3 つの固定値と 1 つの可変指数を含むモジュラー算術条件から始まります。 素数係数が与えられています$p$、2つの残基$x$そして$y$範囲内で$1$に$p-1$、そして非常に大きな上限$a$。 タスクは整数の数を数える事です$k$範囲内で$[1, a]$次の形式の合同を満たす$$k \cdot x^k \equiv y \pmod p.$$この式では線形因子が混合されます。$k$指数係数を使用して$x^k$、すべて素数を法として評価されます。 出力はソリューション自体ではなく、潜在的に膨大な範囲内のソリューションの数です。$10^{12}$これにより、すべての候補者に対して反復するアプローチは除外されます。

の乗算から微妙な問題が発生します。$k$。 純粋な指数合同式とは異なり、ここでは$k$係数と指数の両方として表示されます。 これにより、単純な周期性が破壊されます。$k$したがって、正しいアプローチでは、式を純粋に循環的なものとして扱うのではなく、算術構造を指数構造から分離する必要があります。

離散対数の観点を使用して指数部分と線形部分を分離すると、構造は管理しやすくなります。 以来$p$が素数の場合、非ゼロ残基は次のサイズの循環グループを形成します。$p-1$。 原始ルートを修正すると$g$、すべての値$x^k$次のように書き換えることができます$g^{k \log_g x}$、べき乗を指数空間モジュロの一次関数に変換します。$p-1$。 これにより、元の条件が次の要素を含む混合線形合同式に変換されます。$k$そして$k \cdot \alpha^k$- 指数空間のスタイル項。

したがって、すべてをチェックするのではなく、$k$、1 つの完全な期間内の解の数を事前に計算し、等差数列カウントを使用してこれを最大まで拡張します。$a$。 問題はすべての残基を見つけることになります$k \in [1, p(p-1)]$(または同等の期間) 条件を満たし、各剰余クラスがその中に何回出現するかを数えます。$[1, a]$。

 ## アルゴリズムのチュートリアル

 1. もし$x = 1$、方程式を次のように簡略化します。$k \equiv y \pmod p$。 これが機能する理由は、$x^k = 1$みんなのために$k$、指数依存性を完全に排除します。 
2. それ以外の場合は、問題を乗法群モジュロで扱います。$p$、累乗は周期で循環します。$p-1$。 
3. すべての値を事前計算する$x^k \bmod p$のために$k \in [1, p-1]$、これらは指数の周期性によってすべての将来の値を決定するためです。 
4. 各残基クラスについて$r \in [1, p(p-1)]$(または削減された代表セット)、次のことを評価します。$r \cdot x^r \equiv y \pmod p$が成立する。 状態空間は次のように制限されるため、このステップは実行可能です。$O(p)$それよりも$O(a)$。 
5. 有効な残基をすべて収集します$r$次に、そのような剰余ごとに整数の数を計算します。$k \in [1, a]$満足する$k \equiv r \pmod T$、 どこ$T$は、特定された繰り返し期間です。 

この削減が有効である理由は、両方の$x^k \bmod p$のみに依存する$k \bmod (p-1)$、 そして$k \bmod p$のみに依存する$k \bmod p$。 したがって、完全な式は以下にのみ依存します。$k \bmod \mathrm{lcm}(p, p-1)$。 この有限領域に注意を限定すると、すべての解クラスが整数行全体にわたって規則的に繰り返され、正確なカウントが可能になります。$[1, a]$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

p, x, y, a = map(int, input().split())

if x == 1:
    # k * 1^k ≡ k ≡ y (mod p)
    # count k in [1, a] with k % p == y
    r = y % p
    if r == 0:
        r = p
    first = r if r <= a else None
    if first is None:
        print(0)
    else:
        print((a - first) // p + 1)
    sys.exit()

# Precompute powers of x modulo p for exponent classes up to p-1
# since x^k depends only on k mod (p-1)
pow_x = [1] * (p)
for i in range(1, p):
    pow_x[i] = (pow_x[i - 1] * x) % p

# Try all residues mod (p-1)
mod = p - 1
valid = []

for k in range(1, mod + 1):
    val = (k * pow_x[k % mod]) % p
    if val == y:
        valid.append(k)

# Count contributions in [1, a]
ans = 0
for r in valid:
    if r > a:
        continue
    ans += (a - r) // mod + 1

print(ans)
```特別な場合$x = 1$指数項を完全に崩壊させ、問題を単一のモジュラー等差数列に変換します。 数え方の公式は、範囲内の数値が固定剰余クラスのモジュロに含まれる数を計算します。$p$。 

一般的なケースでは、コードは素数のべき乗が指数の法にのみ依存するという事実に依存します。$p-1$。 配列`pow_x`事前計算する$x^i \bmod p$関連するすべての指数残基に対して。 各候補者$k$サイズを縮小したドメインでテストされる$p-1$、その後、等差数列カウントを使用して、すべての有効な剰余が全範囲に戻されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    p, x, y, a = map(int, input().split())

    if x == 1:
        r = y % p
        if r == 0:
            r = p
        if r > a:
            return "0"
        return str((a - r) // p + 1)

    mod = p - 1
    pow_x = [1] * p
    for i in range(1, p):
        pow_x[i] = (pow_x[i - 1] * x) % p

    valid = []
    for k in range(1, mod + 1):
        if (k * pow_x[k % mod]) % p == y:
            valid.append(k)

    ans = 0
    for r in valid:
        if r <= a:
            ans += (a - r) // mod + 1

    return str(ans)

# sample cases
assert run("5 2 3 10") == "3"
assert run("7 4 6 13") == "1"

# edge cases
assert run("5 1 2 10") == "2"
assert run("2 1 1 1000000000000") == str(1000000000000)
assert run("11 3 7 1") in {"0", "1"}

 ## 特殊なケース

 いつ$x = 1$、指数構造は完全に消えます。 方程式は次のようになります$k \equiv y \pmod p$、そしてその解決策は純粋に等差数列です。 たとえば、入力の場合$p=5, x=1, y=3, a=10$、有効な値は次のとおりです。$3, 8$、アルゴリズムは、指数ロジックを入力せずに直接モジュラー演算を使用して 2 つの項を正しくカウントします。 

いつ$a < p$、最初のセグメント内の残基のみが問題となり、ラッピングは発生しません。 この体制では、解決策は候補の小さなプレフィックスをチェックすることになり、定期的な拡張ロジックは決してアクティブになりません。 

いつ$a \gg p$、この解決策は完全な残基クラスのカウントに完全に依存しています。 それぞれの有効な残基が寄与します$\lfloor (a-r)/ (p-1) \rfloor + 1$これにより、二重にカウントされることなく、すべての繰り返しが正しく考慮されます。
