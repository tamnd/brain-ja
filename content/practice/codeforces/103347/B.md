 4和音を4つの組み合わせとする$c_4c_3c_2c_1$と$n > c_4 > c_3 > c_2 > c_1 \ge 0.$1 つの「隣接キー移動」で 1 つだけが置き換えられます$c_j$による$c_j \pm 1$厳格な不平等を維持しながら。 

セクション 7.2.1.3 の (10) から標準ギャップ変数を書き込みます。$p_4 = n - c_4,\quad p_3 = c_4 - c_3,\quad p_2 = c_3 - c_2,\quad p_1 = c_2 - c_1,\quad p_0 = c_1 + 1.$それからそれぞれ$p_i \ge 1$そして$p_4 + p_3 + p_2 + p_1 + p_0 = n+1.$変化$c_j \mapsto c_j + 1$または$c_j \mapsto c_j - 1$隣接する 2 つのギャップのみに影響します。$c_j \mapsto c_j + 1 \;\Longleftrightarrow\; (p_{j-1},p_j) \mapsto (p_{j-1}-1,p_j+1),$

$c_j \mapsto c_j - 1 \;\Longleftrightarrow\; (p_{j-1},p_j) \mapsto (p_{j-1}+1,p_j-1).$したがって、各合法的な移動は、ベクトルの隣接する座標間での 1 単位の移動となります。$(p_0,p_1,p_2,p_3,p_4)$、ポジティブさを保ちながら。 

シフトされた変数を導入する$x_i = p_i - 1 \quad (0 \le i \le 4).$それからそれぞれ$x_i \ge 0$そして$x_0 + x_1 + x_2 + x_3 + x_4 = n - 4.$スパン条件$c_4 - c_1 < m$になる$(p_3 + p_2 + p_1) < m - 1,$同等に$x_1 + x_2 + x_3 < m - 4.$したがって、許容されるコードのセットは、ポリトープ内の整数点のセットです。$x_0 + x_1 + x_2 + x_3 + x_4 = n - 4,$と$x_i \ge 0$そして、連続する座標ブロックに対する追加の線形制約が 1 つあります。 この領域は、次の弱い組成のグリッド グラフの有限誘導サブグラフです。$n-4$5つの部分に分かれています。 

コード内の移動は、隣接する座標間で 1 単位を移動することに正確に対応します。$x_i$そして$x_{i\pm1}$、それは単一の変更から生じるため、$c_j$による$\pm 1$。 したがって、隣接グラフは、弱い組成に関する標準の「ユニット転送」グラフのサブグラフです。 

作品を注文する$(x_0,\dots,x_4)$最後の座標での反射されたグレイコード再帰によって。 固定用$(x_0,x_1,x_2,x_3)$、座標$x_4$が決定され、再帰は、構成の回転ドアのグレイ コードとまったく同じように、構造の各レベルで方向を変えることによって、隣接する座標間を一度に 1 単位ずつ移動します。 各遷移は 1 つの隣接するペアを変更します$(x_i,x_{i+1})$による$(\pm 1,\mp 1)$したがって、オリジナルの単一の隣接キー移動に対応します。$c$-変数。 

制約$x_1 + x_2 + x_3 < m-4$は、隣接する座標間で 1 つのユニットを移動すると、部分和の範囲がすべて保持され、局所的な不等式が 1 つだけ変更されるため、合法である場合は常に同じユニット移動移動の下で閉じられる、この合成格子の凸スライスを定義します。$\pm 1$ポジティブさを損なうことなく。 したがって、再帰的グレイコード構築は、接続性やユニット転送構造を壊すことなく、このサブ領域に制限することができます。これは、各制限された状態では、エンドポイントを除いて、再帰順序における正当な先行者および後続者が引き続き許可されるためです。 

結果として得られる順序付けでは、許容されるすべての構成を 1 回だけ訪問し、各ステップで隣接するペアを 1 つだけ変更します。 逆翻訳$p_i = x_i + 1$そしてそして$(c_1,c_2,c_3,c_4)$各ステップで 1 つだけ変更されるという特性が保持されます。$c_j$による$\pm 1$。 

これにより、スパン制約を満たすすべての 4 和音のハミルトニアン パスが生成され、すべての遷移が 1 本の指の隣接するキーへの移動に対応します。
