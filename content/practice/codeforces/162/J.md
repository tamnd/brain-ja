 ## 解決策
 ## 問題の理解

 開始丸括弧と終了丸括弧のみで構成される文字列が与えられます。 タスクは、このシーケンスのバランスが取れているかどうか、つまり、数式内の括弧の正しい配置を表すことができるかどうかを判断することです。 つまり、すべての開始括弧には対応する終了括弧が必要であり、括弧は適切にネストされている必要があります。 たとえば、「(())()」は、各「(」が正しい順序で閉じられているためバランスがとれていますが、「(()」は 1 つの左括弧が一致していないためバランスが取れていません。また、「)(」は、一致する左括弧の前に閉じ括弧が出現するためバランスが取れていません。

 入力文字列の長さは 1 ～ 100 文字であることが保証されます。 この小さな上限は、線形時間計算量以上のアルゴリズムが許容されることを意味します。 二次またはより複雑な解も、下限があるため十分に高速に実行されますが、単純さと明瞭さが優先されます。 注意すべきエッジ ケースには、閉じ括弧で始まるシーケンス、開き括弧で終わるシーケンス、中央に一致しない括弧があるシーケンス、完全に 1 種類の括弧で構成されるシーケンスなどがあります。 たとえば、文字列 ")" は "NO" を返す必要があります。これは、左括弧が前になければ右括弧を表示できないためです。 同様に、「(((」は、余分な左括弧が一致しないままであるため、「NO」を返す必要があります。

 ## アプローチ

 ブルートフォース手法では、考えられるすべての部分文字列をチェックして、有効な括弧シーケンスを形成しているかどうかを確認しようとします。 これには、再帰的または反復的に各開始括弧と終了括弧を組み合わせ、すべてのネストされたシーケンスを検証することが含まれます。 このアプローチは正しいですが、指数関数的な時間計算量 (最悪の場合は O(2^n)) があり、制約を考慮すると不要です。 長さが 20 以上の文字列であっても、チェックの数が爆発的に増加するため、明らかに過剰になります。 

最適なアプローチでは、単一の整数をバランス カウンターとして使用する単純なカウント メカニズムを活用します。 文字列を左から右に繰り返し、開始括弧ごとにカウンターを増やし、終了括弧ごとにカウンターを減らします。 カウンタが負になった場合は、対応する開始括弧なしで閉じ括弧が出現したことを示しているため、シーケンスは直ちに無効になります。 文字列全体を処理した後、カウンタが 0 の場合にのみシーケンスのバランスがとられます。これは、すべての左括弧が右括弧と一致することを意味します。 このアプローチは、バランスを維持するために必要な整数が 1 つだけであるため、O(n) 時間と O(1) 空間で機能します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. カウンタ変数をゼロに初期化します。 このカウンターは、シーケンスをスキャンする際に、一致しない開始括弧の正味の数を追跡します。 
2. 文字列内の各文字を繰り返し処理します。 文字が左括弧「(」の場合、一致しない開始括弧がもう 1 つあるため、カウンタをインクリメントします。文字が右括弧「)」の場合、一致しない開始括弧が 1 つ一致したため、カウンタをデクリメントします。 
3. 反復中のいずれかの時点でカウンタが負になった場合は、すぐに「NO」を出力して終了します。 これは、対応する開始括弧の前に閉じ括弧が発生し、シーケンスのバランスが崩れていることを示します。 
4. 文字列全体を反復処理した後、カウンターを確認します。 ちょうど 0 の場合は、すべての左括弧に対応する右括弧があるため、「YES」と出力されます。 それ以外の場合は、いくつかの左括弧が一致しないままになるため、「NO」を出力します。

機能する理由: カウンタは、現在一致しない左括弧の数を表す不変式を維持します。 負の値は無効な状態を示し、末尾のゼロ値はすべての括弧が適切に一致し、ネストされていることを示します。 この不変式により正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s = input().strip()
balance = 0

for char in s:
    if char == '(':
        balance += 1
    else:  # char == ')'
        balance -= 1
    if balance < 0:
        print("NO")
        sys.exit()

print("YES" if balance == 0 else "NO")
```このソリューションは入力を読み取り、末尾の改行を削除します。 バランスカウンターはゼロから始まります。 キャラクターごとに、ブラケットのタイプに応じてカウンターを調整します。 いずれかの時点でバランスがマイナスになると、シーケンスのバランスが取れないことを反映して、すぐに「NO」を出力して終了します。 ループの後、バランスがゼロに等しいかどうかをチェックして、すべての括弧が一致していることを確認します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from contextlib import redirect_stdout
    out = io.StringIO()
    with redirect_stdout(out):
        s = input().strip()
        balance = 0
        for char in s:
            if char == '(':
                balance += 1
            else:
                balance -= 1
            if balance < 0:
                print("NO")
                return
        print("YES" if balance == 0 else "NO")
    return out.getvalue().strip()

# Provided sample
assert run("(()(()))()") == "YES", "sample 1"

# Custom cases
assert run("(") == "NO", "single opening"
assert run(")") == "NO", "single closing"
assert run("()()()") == "YES", "repeated balanced pairs"
assert run("((()))") == "YES", "nested balanced"
assert run("((())") == "NO", "unmatched opening inside"
assert run("())(") == "NO", "early closing unmatched"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | "(" | NO | 単一の不一致の開口部 |
 | ")" | いいえ | 単一の一致しないクロージング |
 | "()()()" | はい | 複数のバランスの取れたペア |
 | "((()))" | はい | ネストされたバランスの取れたブラケット |
 | "((())" | いいえ | 内部の開口部が一致しません |
 | "())(" | NO | 開く前に閉じます |

 ## 特殊なケース

 右括弧で始まる文字列 (例: ")" の場合、残高はステップ 1 ですぐにマイナスになり、"NO" がトリガーされます。 「(((」などの不一致の開始部分で終わる文字列の場合、残高は最後で正となり、結果は「NO」となります。「((()))」のような完全にネストされたシーケンスでは、カウンタは正しく増減し、ゼロで終了し、「YES」を確認します。アルゴリズムは、早期終了と最終残高チェックにより、すべてのシナリオを正しく処理します。
