 ## 解決策
 ## 問題の理解

 印刷可能な ASCII 文字を含む単一の文字列が与えられます。 これらの文字の一部は、次の数字である可能性があります。`'0'`に`'9'`。 タスクは、すべての数字を削除し、残りの文字を元の順序で印刷することです。 

このステートメントでは、削除後に文字が左にシフトすると述べていますが、その詳細は文字列の削除が概念的にどのように機能するかを説明しているだけです。 実際には、繰り返しの削除をシミュレートする必要はありません。 最終結果は、単純に非数字文字の部分列になります。 

入力長は最大 100 文字と非常に小さいです。 非効率的なアプローチであっても、制限内に問題なく収まります。 削除が繰り返される二次解では、最大でも約 10,000 文字の操作が実行されますが、これは 3 秒の制限ではわずかです。 それでも、最もクリーンなソリューションは、文字列を 1 回スキャンして、答えを直接構築します。 

不注意な実装を静かに破壊する可能性のあるエッジケースがいくつかあります。 

数字のみを含む文字列は空の行を生成する必要があります。 

入力：```
12345
```正しい出力:```

```バグのある実装では、誤ってスペースが印刷されたり、改行の印刷に失敗したりする可能性があります。 

数字は末尾だけでなくどこにでも表示できます。 

入力：```
a1b2c3
```正しい出力:```
abc
```最初の桁だけを削除したり、途中で停止したりする間違った解決策は、ここで失敗します。 

文字列には、文字や数字ではない記号が含まれる場合があります。 

入力：```
VK-Cup-2012!
```正しい出力:```
VK-Cup-!
```ハイフンと感嘆符はそのままにしておく必要があります。 数字のみが削除されます。 

## アプローチ

 最も直接的な総当たり攻撃のアイデアは、数字を繰り返し検索して文字列から削除することです。 Python では文字列は不変であるため、削除するたびに新しい文字列が作成されるため、1 文字を削除すると直線的な時間がかかります。 文字列に長さがある場合`n`、数字を 1 つずつ削除すると、全体の複雑さは次のようになります。`O(n^2)`最悪の場合。 

この問題については、そのアプローチでも十分高速です。`n ≤ 100`。 それでも、不必要な作業が行われます。 削除するたびに文字が左に移動します。つまり、同じ文字が何度もコピーされる可能性があります。 

もっと良い観察は、文字を物理的に削除する必要がないということです。 最終的な答えは、数字ではない文字だけで構成されます。 元の文字列を変更する代わりに、それを左から右に 1 回スキャンして、結果に数字以外の文字をすべて追加することができます。 

これにより、作業が文字列の 1 回のパスに減ります。 各文字は 1 回チェックされ、最大 1 回追加されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 承認済み |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力文字列を読み取ります。 
2. 保持したい文字を格納する空のリストを作成します。 
3. 文字列を 1 文字ずつ繰り返します。 
4. 各文字について、それが数字であるかどうかを確認します。 

Pythonでは、`ch.isdigit()`返品`True`数字の場合と`False`さもないと。 
5. 文字が数字でない場合は、その文字を結果リストに追加します。 

すべての文字、句読点、記号は変更されません。 
6. 文字列全体を処理した後、収集した文字を結合して最終的な 1 つの文字列にします。 
7. 結果を印刷します。 

### なぜ効果があるのか

 アルゴリズムはすべての文字を 1 回だけ処理します。 数字以外の文字は入力に現れるのと同じ順序で追加されるため、スキャン中、すべての非数字文字の相対的な順序が保持されます。 すべての桁がスキップされるため、出力に桁が表示されることはありません。 すべての文字はスキップされるか、正確に 1 回追加されるため、生成される文字列は、すべての桁が削除された元の文字列とまったく同じになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s = input().strip()

result = []

for ch in s:
    if not ch.isdigit():
        result.append(ch)

print("".join(result))
```プログラムは入力文字列を読み取ることから始まります。 使用する`strip()`入力から末尾の改行を削除します。 

の`result`list には、フィルタリング ステップを生き残ったすべての文字が格納されます。 文字を追加するのは簡単なので、リストを使用すると効率的です。`O(1)`一方、文字列を繰り返し連結すると、多数の一時文字列が作成されます。 

ループは各文字を個別に検査します。 もし`isdigit()`返品`False`、文字が答えに追加されます。 数字は完全に無視されます。 

ついに、`"".join(result)`収集した文字を最終的な文字列に変換します。 すべての文字が数字の場合、リストは空のままになり、`join`空の文字列が正しく生成されます。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    import sys
    input = sys.stdin.readline

    s = input().strip()

    result = []

    for ch in s:
        if not ch.isdigit():
            result.append(ch)

    print("".join(result))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output

# provided sample
assert run("VK-Cup-2012!\n") == "VK-Cup-!\n", "sample 1"

# custom cases
assert run("12345\n") == "\n", "all digits"
assert run("abc\n") == "abc\n", "no digits"
assert run("a1b2c3\n") == "abc\n", "digits between letters"
assert run("9\n") == "\n", "minimum size, single digit"
assert run("!@#456$%^789&*\n") == "!@#$%^&*\n", "symbols preserved"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`12345`| 空の文字列 | 全桁入力を処理します。 
|`abc`|`abc`| 数字のない文字列を変更しないままにします。 
|`a1b2c3`|`abc`| 中間の数字を削除します |
 |`9`| 空の文字列 | 最小サイズのエッジケース |
 |`!@#456⟦PROTECT_15⟧%^&*`| 句読点と記号を保持します。
