 ## 解決策
 ## 問題の理解

 この状況は、2 人の宇宙飛行士と、ブラック ホール システムによって引き起こされる相対論的な時間差を表しています。 1人の宇宙飛行士、レオは地球に残り、もう1人の宇宙飛行士、エマは、時間がよりゆっくりと流れる遠い惑星へ旅立ちます。 重要な詳細は、地球上の時間は地球の時間と 1 対 1 で直線的に一致するのではなく、固定係数によって引き伸ばされるということです。 

3 つの整数が与えられます。 1つ目は、エマが地球を離れる瞬間のレオの初期年齢です。 2 つ目は、地球上での時間が地球と比べてどれだけ遅く経過するかを示す時間遅延係数です。 3つ目は、地球の時計に基づいてエマが地球で何年過ごすかです。 

課題は、エマが地球に戻るときのレオの年齢を判断することです。これは、エマの旅行中にどれだけ地球時間が経過するかによって決まります。 

重要な解釈ステップは、地球上で費やした時間を地球時間に変換することです。 地球上の 1 年が地球上の X 年に相当する場合、Y 惑星年の長さは X × Y 地球年に相当します。 獅子座は地球のこの期間全体で通常どおり老化します。 

入力制限は非常に小さく、すべての値が 100 で制限されています。これにより、最適化や高度なデータ構造の必要性が即座に排除されます。 直接の算術計算でも一定時間で十分です。 

微妙な失敗例は、乗算ステップの処理を誤った場合に発生します。 たとえば、X と Y が浮動小数点として扱われる場合、またはより大きな制約で整数オーバーフローが発生する可能性がある場合、結果が不正確になる可能性があります。 ただし、ここでは値が十分小さいため、標準の整数演算は安全です。 

もう 1 つの潜在的な間違いは、時間の遅れの方向を誤解することです。 「時間の経過が X 倍遅くなる」という表現は、掛け算ではなく割り算と誤って読まれる可能性があります。 X × Y の代わりに Y / X を計算すると、A = 20、X = 3、Y = 4 のような単純な入力であっても、小さくて不正確な結果が得られます。ただし、正しい地球時間の寄与は 1 ではなく 12 です。 

## アプローチ

 プロセスを単純に解釈すると、時間を年ごとにシミュレートすることになります。 エマの滞在を一度に 1 惑星年ずつ進め、それぞれを X 倍することで地球時間に変換し、それに応じてレオの年齢を増加させることを想像することもできます。 これは論理的に機能しますが、Y ステップにわたる不必要な反復が発生します。 各ステップは一定の作業を実行するため、合計の複雑さは O(Y) になります。これはここではまだ自明ですが、概念的には非効率になります。 

重要な観察は、惑星時間から地球時間への変換が線形かつ均一であるということです。 地球上のすべての時間単位は、地球上では正確に X 単位に拡張されます。 この固定比率により、累算を繰り返す代わりに、期間全体を 1 回の乗算で変換できます。 

これにより、問題は直接的な算術式に帰着します。つまり、レオの最終年齢は、初期年齢にイーマのミッション中に経過した地球時間の合計を加えたもの、つまり X × Y に等しいということになります。 

中間状態間には依存関係がないため、シミュレーションや状態追跡は必要ありません。

 ## アルゴリズムのチュートリアル

 1. 初期年齢 A、時間遅れ係数 X、および惑星の継続期間 Y を読み取ります。これらは、システムの状態を表す独立したスカラー値です。 
2. X と Y を掛けて、Ema のミッション中に経過する合計地球時間を計算します。この変換は、2 つの時間スケール間の物理的な関係を反映しています。 
3. この地球時間を獅子座の初期年齢 A に加算します。獅子座は地球時間と同じ割合で年齢を重ねるため、地球で 1 年ごとに年齢が 1 つずつ増えます。 
4. 結果の値を、Ema が戻った瞬間の Leo の年齢として出力します。 

## なぜ機能するのか

正確さは、時間の遅れが間隔全体にわたって一定であるという事実に依存します。 各惑星年はちょうど X 地球年に寄与するため、惑星の存続期間から地球の存続期間へのマッピングは線形スケーリングになります。 レオの老化は地球時間のみに依存し、エマの現地時間には依存しないため、結果は A + X × Y によって完全に決定されます。中間の相互作用や状態の変化は結果に影響を与えません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a = int(input().strip())
    x = int(input().strip())
    y = int(input().strip())
    print(a + x * y)

if __name__ == "__main__":
    solve()
```このソリューションは、指定どおりに、別々の行から 3 つの整数を読み取ります。 掛け算`x * y`ループや変換を行わずに直接実行されます。 結果はに追加されます`a`、これはすでにレオの最初の年齢を表しています。 

よくある実装の間違いは、単一行からすべての値を読み取ろうとすることですが、入力形式では明示的に各値を独自の行に配置するため、各呼び出しは`input()`個別に処理する必要があります。 

もう 1 つの詳細は、演算子の優先順位により式が次のようになりますが、乗算が加算の前に確実に行われるようにすることです。`a + x * y`当然正しい。

 ## 特殊なケース

 直接的な特殊なケースは、時間遅延係数がゼロの場合です。 その場合、エマがどれだけ地球上に滞在しても、地球時間は経過しません。 入力用`A=10, X=0, Y=100`、計算結果は次のようになります`10 + 0 = 10`、つまり、レオはミッション間隔中に老化しないことを意味します。 

もう 1 つのケースは、エマが地球上で時間をまったく費やさない場合です。 のために`A=10, X=5, Y=0`、地球時間の寄与はゼロになり、獅子座の年齢は 10 歳のままです。 

最後の境界ケースは、すべての値が制約内で最大になる場合です。たとえば、`A=100, X=100, Y=100`。 乗算により 10000 地球年が得られ、最終的な年齢は 10100 年になります。これは依然として整数の制限内に簡単に収まり、この問題設定ではオーバーフローの予防策が必要ないことを示しています。
