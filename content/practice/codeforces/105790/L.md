 ## 問題の理解

 私たちは持っています`N`岩の種類。 一部のタイプのペアには互換性がないため、2 つのタイプを同じバッグに保管することはできません。 Dudu にはちょうど 2 つのバッグがあり、すべての岩の種類をそのうちの 1 つに割り当てる必要があります。 有効な割り当てとは、すべての有毒ペアが異なるバッグに分割される割り当てです。 

入力は無向グラフを記述します。 それぞれの岩石の種類は頂点であり、あらゆる有害な関係はエッジです。 問題は、同じグループ内に両方の端点を持つエッジが存在しないように、頂点を 2 つのグループに分割できるかどうかです。 可能であれば、2 つのグループを出力する必要があります。 そうでない場合は、分離ができないことを報告します。 

制限は十分に大きいため、解は線形である必要があります。 まで`100000`頂点と`100000`エッジ、すべてのペアを繰り返しチェックするアルゴリズムは、`10^10`最悪の場合、1 秒の制限をはるかに超えた操作が行われます。 に近い解決策が必要です`O(N + M)`、すべての頂点とエッジは一定の回数だけ処理されます。 

主なエッジ ケースは、入力サイズではなくグラフ構造に由来します。 すべての石はどちらかのバッグに入る可能性があるため、有害な関係がないグラフは有効です。 例えば：```
Input:
3 0

Output:
POSSIVEL
3 0
1 2 3
```頂点からしか検索を開始しない迂闊な実装`1`他のコンポーネントの孤立した頂点が失われる可能性があります。 

単一の頂点は別の特殊なケースです。```
Input:
1 0

Output:
POSSIVEL
1 0
1
```解決すべき競合がないため、唯一のタイプを 1 つのバッグに入れることは有効です。 両方のバッグが空ではないことを前提としたコードは、ここで失敗します。 

三角形は最小の不可能なケースです。```
Input:
3 3
1 2
2 3
3 1

Output:
IMPOSSIVEL
```サイクル全体で色を交互にしようとすると、最初と最後の頂点が接続されている場合でも、強制的に同じ色を受け取ることになります。 この矛盾を検出せずにローカル近傍をチェックするだけのアプローチは、矛盾を誤って受け入れてしまいます。 

## アプローチ

 簡単なアプローチは、岩を 2 つの袋にできる限り分割してみることです。 各岩には 2 つの選択肢があるため、これにより、`2^N`可能な割り当て。 割り当てごとに、すべての有毒ペアを検査し、両方のエンドポイントが同じバッグに入っているかどうかを確認できます。 この方法は、有効な分離の定義を直接テストするため正しいですが、次の場合には使用できません。`N`到達する`100000`。 最悪の場合は確認が必要です`2^100000`課題。 

グラフ構造は、問題についてより適切に考える方法を提供します。 有効な 2 つのバッグの分離は、まさにグラフの 2 分割です。 グラフ理論の用語では、各バッグは独立した集合であり、無向グラフは 2 部の場合に限り、2 つの独立した集合に分割できます。 

二部グラフは、すべての頂点に 2 つの色のいずれかを割り当て、すべてのエッジが異なる色を接続することによって認識できます。 未訪問の頂点から開始して、それに色を付け、グラフ トラバーサルを使用して、接続されているコンポーネントに強制的に色を交互に適用することができます。 同じ色の 2 つの頂点を接続するエッジが見つかった場合、必要な分離は不可能になります。 

この強引な解決策は、考えられるすべての色を探索するため機能します。 重要なのは 2 色だけであるという観察により、すべての可能性を探索するのではなく、色を直接構築することができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^N * M) | O(N) | 遅すぎる |
 | 最適 | O(N + M) | O(N + M) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グラフの隣接リストを作成します。 非互換性は両方向に作用するため、各有毒ペアは無向エッジを作成します。 
2. すべての頂点の色を格納する配列を保持します。 使用`-1`未訪問の頂点の場合は、`0`そして`1`可能なバッグは 2 つあります。 
3. すべての頂点を反復処理します。 頂点がまだ色付けされていない場合は、そこから走査を開始し、色を割り当てます。`0`。 グラフには複数の切断されたコンポーネントが含まれる可能性があるため、この手順が必要です。 
4. トラバース中に、隣接する頂点のすべてに反対の色を割り当てます。 隣接する頂点がすでに現在の頂点と同じ色を持っている場合、グラフには矛盾が含まれており、答えは不可能です。 
5. すべてのコンポーネントが処理されたら、色付きの頂点を収集します`0`最初のバッグと頂点に色を追加します`1`2番目のバッグに。 色付けにより、すべての有毒ペアがこれら 2 つのグループに分割されることが保証されます。 

これが機能する理由: トラバース中に維持される不変条件は、処理されたすべてのエッジが異なる色の頂点を接続することです。 色のない隣接するエッジに反対の色を割り当てると、そのエッジのこのプロパティが保持されます。 すでに色付けされている隣接部分の色が間違っている場合、そのエッジには同じ色と異なる色の両方が同時に必要となるため、有効な 2 色の割り当ては存在できません。 トラバースが矛盾なく終了した場合、すべてのエッジが 2 つのカラー グループ間を交差するため、2 つのバッグは有効になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    graph = [[] for _ in range(n)]

    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        graph[u].append(v)
        graph[v].append(u)

    color = [-1] * n
    bag0 = []
    bag1 = []

    for start in range(n):
        if color[start] != -1:
            continue

        color[start] = 0
        stack = [start]

        while stack:
            u = stack.pop()

            for v in graph[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    stack.append(v)
                elif color[v] == color[u]:
                    print("IMPOSSIVEL")
                    return

    for i in range(n):
        if color[i] == 0:
            bag0.append(i + 1)
        else:
            bag1.append(i + 1)

    print("POSSIVEL")
    print(len(bag0), len(bag1))
    print(*bag0)
    print(*bag1)

if __name__ == "__main__":
    solve()
```隣接リストには既存の有害な関係のみが保存されるため、メモリ使用量は実際のグラフ サイズに比例して維持されます。 Python のデフォルトの再帰制限はチェーンに対して小さすぎるため、トラバーサルでは再帰ではなく明示的なスタックが使用されます。`100000`頂点。 

すべての頂点にわたる外側のループは、切断されたグラフを処理します。 よくある間違いは、頂点からのみ DFS または BFS を実行することです。`1`, これにより、他のコンポーネントはチェックされなくなります。 

表現`color[u] ^ 1`間を反転します`0`そして`1`。 これにより、余分な条件チェックが回避され、2 つのバッグの割り当てが直接行われます。 

最後の収集ステップでは、内部の 0 から始まるインデックスを、問題で使用される 1 から始まる番号付けに変換します。
