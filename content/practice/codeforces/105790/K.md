 ## 問題の理解

 次のように定義されるシーケンスが与えられます。$$F(0)=1,\quad F(1)=2$$そしてあらゆる人にとって$n \ge 2$、$$F(n)=F(n-1)\cdot F(n-2).$$入力には単一の整数が含まれています$N$、 どこ$N$と同じ大きさにすることができます$10^{18}$。 タスクは計算することです$F(N)$モジュロ$998244353$。 

漸化式は加算的ではなく乗算的です。 数値のサイズが爆発的に増大するため、値を 1 つずつ計算することはすぐに不可能になります。 均等に保管$F(100)$まさに、すでに非現実的でしょう。 

重要な制約は、$N \le 10^{18}$。 0 から 0 まで反復するアルゴリズム$N$はすぐに除外されます。 おおよその対数解が必要です$O(\log N)$これは、繰り返しの中に隠された何らかの構造を使用することを示唆しています。 

よくある間違いは、再帰モジュロを適用することです。$998244353$直接、最大まで反復してみてください$N$。 たとえ剰余算術によって数値が小さく保たれても、$10^{18}$反復は不可能です。 

小さな例を考えてみましょう。```
N = 5
```順序は$$1, 2, 2, 4, 8, 32$$したがって、答えは 32 です。 

興味深い観察は、すべての項が 2 のべき乗であるということです。 この構造が欠けていると、アプローチが不必要に複雑になります。 

もう一つの微妙なケースは次のような場合です。$N=0$。```
Input
0
```答えは```
1
```最初の項は明示的に 1 として定義されているためです。フィボナッチ指数を含む式はすべて、この基本ケースを正しく保持する必要があります。 

最後の落とし穴は、次のような巨大な値に現れます。```
N = 10^18
```フィボナッチ指数自体は巨大です。 正確に計算することは不可能なので、べき乗する前にモジュラー演算を使用して指数を減らす必要があります。 

## アプローチ

 ブルート フォース ソリューションでは、シーケンスを左から右に計算します。 

あらゆるインデックスに対して$i$、$$F(i)=F(i-1)\cdot F(i-2)\pmod{998244353}.$$モジュラー乗算ではモジュロ結果が保存されるため、この繰り返しは正しいです。$998244353$。 

問題は反復回数です。 と$N$まで$10^{18}$、アルゴリズムには約$10^{18}$乗算ですが、これは完全に不可能です。 

より迅速な解を見つけるには、各項を 2 のべき乗として記述します。 

以来$$F(0)=2^0,\qquad F(1)=2^1,$$仮定する$$F(n)=2^{a_n}.$$再帰式に代入すると、$$2^{a_n}=2^{a_{n-1}} \cdot 2^{a_{n-2}}
       =2^{a_{n-1}+a_{n-2}}.$$したがって、$$a_n=a_{n-1}+a_{n-2}.$$指数列はフィボナッチ漸化式に従います。$$a_0=0,\qquad a_1=1.$$それで$a_n$まさに$n$-番目のフィボナッチ数。 

これにより閉じた形式が得られます$$F(n)=2^{Fib(n)}.$$さて、問題はコンピューティングです$$2^{Fib(N)} \bmod 998244353.$$弾性率$998244353$プライムです。 フェルマーの小定理により、$$2^{k \bmod (998244353-1)}
\equiv
2^k
\pmod{998244353}.$$したがって、必要なのは$$Fib(N)\bmod 998244352.$$値を法とするフィボナッチ数は次のように計算できます。$O(\log N)$行列のべき乗または高速 2 倍算を使用します。 指数モジュロを取得した後$998244352$、1 つのべき乗剰余演算で最終的な答えが得られます。

### なぜ効果があるのか

 すべてのシーケンス値は 2 のべき乗です。 書き込み$F(n)=2^{a_n}$乗法漸化式を次のように変換します$$a_n=a_{n-1}+a_{n-2},$$これはまさに初期値を伴うフィボナッチ回帰です$0$そして$1$。 したがって$a_n=Fib(n)$、与える$$F(n)=2^{Fib(n)}.$$係数は素数であるため、フェルマーの定理により指数モジュロを減らすことができます。$998244352$。 高速 2 倍化ではその指数が対数時間で計算され、べき乗剰余演算によって必要な値が生成されます。 各変換では正確なモジュロ値が保持されます。$998244353$, したがって、最終的な答えは正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
PHI = MOD - 1

def fib(n):
    if n == 0:
        return (0, 1)

    a, b = fib(n >> 1)

    c = (a * ((2 * b - a) % PHI)) % PHI
    d = (a * a + b * b) % PHI

    if n & 1:
        return (d, (c + d) % PHI)
    else:
        return (c, d)

n = int(input())

exp = fib(n)[0]
print(pow(2, exp, MOD))
```解決策は、素数係数とそのオイラー係数の値を定義することから始まります。$MOD-1$係数が素数だからです。 

の`fib`関数は高速倍増アイデンティティを実装します。$$Fib(2k)=Fib(k)\cdot(2Fib(k+1)-Fib(k))$$そして$$Fib(2k+1)=Fib(k)^2+Fib(k+1)^2.$$再帰呼び出しごとに引数が半分になり、対数的な複雑さが生じます。 

すべてのフィボナッチ計算はモジュロで実行されます$998244352$、指数モジュロのみであるため、$MOD-1$が必要です。 

入手後$Fib(N)\bmod 998244352$、答えは Python の 3 つの引数を使用して計算されます。`pow`、べき乗剰余を効率的に評価します。 

微妙な実装の詳細は次の式です。```
(2 * b - a) % PHI
```モジュロ演算を行わないと、中間値が負になる可能性があります。
