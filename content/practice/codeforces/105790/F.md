 ## 解決策
 ## 問題の理解

 エリックは、最初はエネルギーがゼロのレーザー兵器から始めます。 

各レベルでは、2 つのアクションが可能です。 

通常ルートでは殺害が必要`s_i`突然変異体。 すべてのショットは、非正のエネルギーであっても、1 単位のエネルギーを消費するため、レベルを通過すると現在のエネルギーが次のように変化します。`e_i - s_i`。 その後、エリックは次のレベルに進みます。 

代替ルートはワームホールです。 使用するとスキップされる`k`先のレベル。 ワームホールに入るには、エリックは人を殺さなければなりません`X`ミュータントを守っているため、彼のエネルギーは次のように減少します。`X`。 彼は戦争をしない`s_i`通常のミュータントであり、エネルギーバンクを受け取りません`e_i`。 

すべてのレベルが終了した後、エリックは光の女王に到達します。 武器のエネルギーが厳密に正である間のみ、ショットはボスにダメージを与えます。 エリックがエネルギーを持って到着したら`E`、彼は正確に対処できます`max(E, 0)`エネルギーが非プラスになる前にダメージを与えます。 

タスクは、ボスに到達したときに残っているエネルギーを最大化することです。 答えは、それが正の場合は最大エネルギー、そうでない場合は最大エネルギーです。`0`。 

制約は重要な観察事項です。 まであります`2 · 10^5`レベル。 すべての可能なパスを明示的に探索するソリューションは不可能です。なぜなら、各レベルには 2 つの選択肢があり、大まかに`2^N`パス。 たとえ`O(N^2)`動的プログラムには次のものが必要です`4 · 10^10`限界をはるかに超えた最悪の場合の操作。 線形または線形に近いものが必要です。 

考えられるすべてのパスが非正のエネルギーで終わる場合、微妙なエッジケースが現れます。 

例：```
1 1 5
3 0
```正規ルートがエネルギーを与える`-3`、ワームホールはエネルギーを与えます`-5`。 エリックはボスに到達しますが、ダメージを与えることができません。 正しい答えは次のとおりです。```
0
```不用意に実装すると、到達可能な最大エネルギーが出力される可能性があります。`-3`、負の値をゼロに変換する代わりに。 

別のエッジケースは、ワームホールが最後のレベルを超えてジャンプするときに発生します。 

例：```
2 2 1
10 100
10 100
```レベル1でワームホールを使用すると、すぐにボスに到達します。 宛先は、無効な状態としてではなく、「すべてのレベルの後」として扱われなければなりません。 この詳細が欠けていると、通常、範囲外エラーや遷移の損失が発生します。 

3 番目のエッジケースは次のような場合です。`X = 0`。 

例：```
3 1 0
5 0
5 0
5 0
```ワームホールはフリースキップになります。 大きなマイナスを避けるため、アルゴリズムはそれを考慮する必要があります。`(e_i - s_i)`値は最適になる可能性があります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 すべてのレベルで、通常のルートまたはワームホール ルートのいずれかを選択し、すべての可能な未来を再帰的に探索します。 各レベルには 2 つの選択肢があるため、パスの数は指数関数的に増加します。 と`N = 200000`、これはまったく不可能です。 

興味深いのは、現在のエネルギーが重要な唯一の量であるということです。 未来は、私たちがどのようにしてそのレベルに到達したかには依存せず、そこで利用可能な最大のエネルギーにのみ依存します。 

仮定する`dp[i]`最初の作業を終えた後に達成可能な最大エネルギーを示します。`i`レベル、または同等のレベルの開始時に立っているとき`i + 1`。 

州から`i`、トランジションは 2 つだけです。 

通常のルートでレベルを通過する`i + 1`エネルギーを変える`e_i - s_i`。 

ワームホールを使用すると、エネルギーが次のように変化します。`-X`そしてレベルに直接移動します`i + k`。 

どちらの遷移も現在のエネルギーに固定値を加算するだけなので、各状態に最適なエネルギーのみを保持するだけで十分です。 同じ位置でのエネルギーが小さいと、将来的により良い結果が得られることはありません。 

これにより、指数関数的な検索が位置全体にわたる線形動的プログラムに変換されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^N) | O(N) | 遅すぎる |
 | 最適なDP | O(N) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を作成する`dp`長さの`N + 1`、負の無限大で初期化されます。 
2.セット`dp[0] = 0`、最初のレベルに入る前の開始状態を表します。 
3. 左から右にレベルを処理します。 
4.州から`i`、通常のルートを試してください。 

エネルギーの変化は、`(e_i - s_i)`ので、次のように更新します。`dp[i + 1] = max(dp[i + 1], dp[i] + e_i - s_i)`。 
5.州から`i`、ワームホールルートを試してください。 

目的地は`min(N, i + k)`最後のレベルを超えてジャンプすると、すぐにボスに到達することを意味するためです。 

アップデート：`dp[min(N, i + k)] = max(dp[min(N, i + k)], dp[i] - X)`。 
6. すべてのトランジションが処理された後、`dp[N]`ボスに到達したときに達成できる最大エネルギーです。 
7. 出力`max(dp[N], 0)`マイナスまたはゼロのエネルギーはボスにダメージを与えることができないためです。 

### なぜ効果があるのか

 不変条件とは、`dp[i]`状態に到達するためのあらゆる方法の中で、常に最大のエネルギーを蓄えます。`i`。 

州からのすべての法的措置は、まさに 1 つの DP 移行に対応します。 各遷移は現在のエネルギーに固定量を追加するため、同じ状態でのエネルギーが大きいほど、常に小さいエネルギーと少なくとも同じくらい優れています。 将来のいかなる決定によっても、より弱い国家が望ましいと判断されることはありません。 

すべての状態を処理し、すべての入力遷移の最大値を取得することにより、DP はすべての位置に対して達成可能な最良のエネルギーを計算します。 特に、`dp[N]`光の女王に到達した際に得られる最大エネルギーとなります。 ボスはエネルギーがプラスのときにのみダメージを与えることができるため、最大ダメージは次のようになります。`max(dp[N], 0)`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k, x = map(int, input().split())

    s = [0] * n
    e = [0] * n

    for i in range(n):
        s[i], e[i] = map(int, input().split())

    NEG = -(10 ** 30)
    dp = [NEG] * (n + 1)
    dp[0] = 0

    for i in range(n):
        if dp[i] == NEG:
            continue

        dp[i + 1] = max(dp[i + 1], dp[i] + e[i] - s[i])

        nxt = min(n, i + k)
        dp[nxt] = max(dp[nxt], dp[i] - x)

    print(max(dp[n], 0))

solve()
```DP 配列はインデックスを使用します`i`最初の処理後の状態を表す`i`レベル。 

通常のルート遷移では、`e[i] - s[i]`、レベルとの戦いとそのエネルギーバンクの収集から得られる正味エネルギーと一致します。 

ワームホール遷移は次のようにジャンプします。`min(n, i + k)`。 ここは間違いが最も起こりやすい場所です。 ジャンプが最後のレベルを超えると、ゲームはすぐにボスに到達するため、そのようなジャンプはすべて 状態に着地する必要があります。`n`。 

値の範囲はおよそに達します`2 · 10^5 × 10^9`したがって、64 ビット演算が必要です。 Python の整数はこれを自動的に処理します。 

最終的な答えはそうではありません`dp[n]`自体。 負のエネルギーはボスにダメージを与えることができないため、結果はゼロにクランプする必要があります。

 ## 特殊なケース

 すべてのエネルギーが非正である場合を考えてみましょう。```
1 1 5
3 0
```初期化すると、`dp[0] = 0`。 

通常ルート：```
dp[1] = -3
```ワームホール:```
dp[1] = max(-3, -5) = -3
```到達可能な最高のエネルギーは`-3`。 負のエネルギーはボスにダメージを与えることができないため、アルゴリズムは次のように出力します。```
0
```次に、終わりを超えてジャンプすることを考えてみましょう。```
2 2 1
10 100
10 100
```状態で`0`:```
normal -> dp[1] = 90
wormhole -> dp[2] = -1
```状態で`1`:```
normal -> dp[2] = 180
wormhole -> dp[2] = max(180, 89)
```ワームホールの行き先は州です`2`、状態ではありません`3`、最後のレベルを超えて到達することは、ボスに到達することを意味するためです。 最終的な答えは次のようになります。```
180
```最後に、無料のワームホールについて考えてみましょう。```
3 1 0
5 0
5 0
5 0
```通常ルートはすべてエネルギーを 5 失います。 すべてのワームホールが失うエネルギーは 0 です。

```これにより、アルゴリズムがあらゆるレベルで両方の選択肢を正しく比較し、常に到達可能な最良のエネルギーを維持していることが確認されます。
