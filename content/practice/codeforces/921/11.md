 ## 解決策
 ## 問題の理解

 私たちには、`n × m`グリッド。各セルは空か壁が含まれています。 左上隅から開始して、右下隅に到達したいと考えています。 許可される移動は、空のセルへの上下左右の 1 ステップです。 課題は、パスを見つけることだけではなく、大きな素数を法とする最短パスの数を計算することです。 

入力により提供されるのは、`n`そして`m`(それぞれ最大 1000) その後にグリッドが続きます。 出力は単一の整数である必要があります。つまり、からの最短パスの数です。`(1,1)`に`(n,m)`モジュロ`10^9+7`。 

この制約は、パスの総数がグリッド サイズで指数関数的に増加する可能性があるため、すべてのパスの総当り探索が実行不可能であることを意味します。 すべてのパスを明示的に保存してもメモリ制限を超えます。 障害物のあるグリッドでの正確性を確保しながら、カウントを効率的に計算する必要があります。 

明らかではないエッジ ケースには、開始点または終了点がブロックされているグリッドや、通路が狭いために最短パスが一意でない場合が含まれます。 たとえば、`2×2`右下のセルのみが開始部分を除いて空であるグリッド、正解は次のとおりです。`0`。 パスの長さを考慮せずに到達可能なすべてのノードをカウントする不注意な BFS は、誤った結果を返す可能性があります。`1`。 

## アプローチ

 素朴なアプローチは、最初から最後まですべてのパスを再帰的に探索し、最小限のステップでターゲットに到達するパスをカウントすることです。 これは、パス長を追跡する DFS を使用して実装できます。 正しさはあらゆる可能性を探ることから生まれますが、複雑さは`O(4^(n*m))`最悪の場合、明らかに実行不可能`n, m ≤ 1000`。 

効率的なソリューションを実現するための重要な洞察は、明示的なルートではなく、最短パスの数のみが必要であるということです。 この観察により、修正された幅優先検索 (BFS) を使用できるようになります。 BFS はノードをレベルごとに探索するため、すべてのセルへの最短距離を自然に計算します。 BFS を拡張して各セルに最短距離で到達する方法の数も維持することで、結果を効率的に計算できます。 

各セルは、開始点からの距離とそこに到達する最短パスの数という 2 つの情報を保持します。 BFS が近隣に到達したとき、その近隣が訪問されていない場合は、その距離とパス数を設定します。 以前に同じ距離で近隣に到達したことがある場合は、そのパス数を増やします。 これにより、最短パスのみが寄与することが保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(4^(n*m)) | O(n*m) | 遅すぎる |
 | パスカウントを使用した BFS | O(n*m) | O(n*m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2D 配列を初期化する`dist`サイズの`n × m`無限大は、各セルまでの最短距離を表します。 2D配列を初期化する`count`ゼロは各セルへの最短パスの数を表します。 セット`dist[0][0] = 0`そして`count[0][0] = 1`。 
2. キューを初期化し、開始セルをプッシュします`(0,0)`。 
3. キューが空でない間にセルをポップします`(x,y)`。 4 つの近隣のそれぞれについて`(nx,ny)`、壁ではなくグリッドの内側にあるかどうかを確認してください。 
4. もし`dist[nx][ny] > dist[x][y] + 1`、 アップデート`dist[nx][ny] = dist[x][y] + 1`そしてセット`count[nx][ny] = count[x][y]`。 押す`(nx,ny)`列に並びます。 
5. もし`dist[nx][ny] == dist[x][y] + 1`、増分`count[nx][ny] += count[x][y]`モジュロ`10^9+7`。 
6. BFS が完了したら、`count[n-1][m-1]`最短パスの数を保持します。 もし`dist[n-1][m-1]`は無限大、出力`0`。 

**機能する理由:** BFS は、すべてのセルが開始点から可能な限り最短距離で最初に訪問されることを保証します。 パス数更新ルールにより、最短パスのみが寄与することが保証されます。 更新中`count`同じ最短距離に遭遇した場合、より長いパスをカウントせずに、考えられるすべての最短パスが正しく集約されるようにします。 

## Python ソリューション```python
import sys
from collections import deque
input = sys.stdin.readline

MOD = 10**9 + 7

n, m = map(int, input().split())
grid = [input().strip() for _ in range(n)]

dist = [[float('inf')] * m for _ in range(n)]
count = [[0] * m for _ in range(n)]

dist[0][0] = 0
count[0][0] = 1

q = deque([(0, 0)])
dx = [1, -1, 0, 0]
dy = [0, 0, 1, -1]

while q:
    x, y = q.popleft()
    for dir in range(4):
        nx, ny = x + dx[dir], y + dy[dir]
        if 0 <= nx < n and 0 <= ny < m and grid[nx][ny] == '.':
            if dist[nx][ny] > dist[x][y] + 1:
                dist[nx][ny] = dist[x][y] + 1
                count[nx][ny] = count[x][y]
                q.append((nx, ny))
            elif dist[nx][ny] == dist[x][y] + 1:
                count[nx][ny] = (count[nx][ny] + count[x][y]) % MOD

print(count[n-1][m-1] if dist[n-1][m-1] != float('inf') else 0)
```の`dist`配列は各セルへの最小ステップを追跡しますが、`count`最短経路の数を累積します。 モジュロ演算により、値が絶対に超過しないことが保証されます。`10^9+7`。 BFS は、セルが距離の増加順に訪問されることを保証するため、パスのカウントは正確になります。
