 ## 解決策
 ## 問題の理解

 家事の困難のリストがあります。 Vasya は正確に受信する必要があります`b`難易度がせいぜいの雑務`x`一方、Petya は正確に受信する必要があります`a`難易度が厳密にそれよりも高い雑用`x`。 

値`x`must be an integer. 分割を満たす整数がいくつあるかを数える必要があります。 

困難を整理すると、その状態を推論するのがはるかに簡単になります。 Since exactly`b`雑用は満たさなければなりません`h[i] ≤ x`、 最初`b`最小の雑事はヴァシャの仕事であり、残りの仕事はヴァシャの仕事である必要があります。`a`雑用はペティアのものでなければなりません。 

これにより、すぐに 2 つの境界値が作成されます。 

- Vasya が受ける最大の雑用は`b`- 番目に小さい値。 
- Petya が受ける最小の雑用は、`(b + 1)`- 番目に小さい値。 

それらを次のように表すとします。 

-`L = sorted_h[b - 1]`-`R = sorted_h[b]`それから`x`以下を満たす必要があります:

 -`x ≥ L`、そうでない場合、Vasyaはより少ないものを受け取ります`b`家事。 
-`x < R`、そうでない場合、Petya が受け取るのは次の値よりも少なくなります。`a`家事。 

したがって、すべての有効な整数は`x`狭間にある`[L, R - 1]`。 

ここでは制約が小さく、最大 2000 要素のみであるため、二次解でも問題なく通過できます。 それでも、問題の構造により、非常にコンパクトになります。`O(n log n)`並べ替え後の解決策。 

厄介なケースは、境界付近で値が重複している場合に発生します。 

次の入力を考えてみましょう。```
7 3 4
1 2 3 3 3 4 5
```ソート後、4 番目に小さい値は次のとおりです。`3`、5 番目に小さい値も`3`。 

必要なものは次のとおりです。```
3 ≤ x < 3
```それは不可能です。 正しい答えは、`0`。 

不注意な実装では、2 つの境界位置間の数値を包括的に数えようとして、誤って結果が返される可能性があります。`1`。 

大きなギャップがある場合には、別の微妙なケースが発生します。```
5 2 3
1 2 10 20 30
```ここ：```
L = 2
R = 10
```からの任意の整数`2`を通して`9`動作するので、答えは次のとおりです`8`。 

有効な値は既存の困難に限定されません。 ギャップ内のそれらはすべて整数です。 

## アプローチ

 ブルートフォースのアイデアは単純です。 可能なすべての整数を試すことができます`x`、どれだけの家事が満足できるかを数えてください`h[i] ≤ x`、そのカウントが等しいかどうかを確認します`b`。 

最小の困難は少なくとも`1`、最大のものは到達できます`10^9`可能な限りすべてを繰り返します`x`価値観はまったく非現実的です。 たとえそれぞれのチェックにたったの時間がかかったとしても`O(n)`、最大スキャン`10^9`整数には約が必要です`2 × 10^12`最悪の場合の運用。 

重要な観察は、Vasya の雑用と Petya の雑用の間の境界のみが重要であるということです。 

配列がソートされると、最初の`b`要素は Vasya に属している必要があり、残りは`a`要素は Petya に属している必要があります。 これらのグループ内の正確な値はもはや重要ではありません。 

仮定する：```
sorted_h[b - 1] = L
sorted_h[b] = R
```Vasya が正確に受信できるようにするには`b`家事、`x`少なくとも`L`、なぜなら、ヴァシャに割り当てられた最も難しい雑用は満足させる必要があるからです`h[i] ≤ x`。 

Petya が正確に受信できるようにするには`a`家事、`x`厳密に以下より小さくなければなりません`R`なぜなら、Petya に割り当てられた最も簡単な家事は満足できるものでなければならないからです。`h[i] > x`。 

つまり、有効な整数は正確に次のとおりです。```
L, L + 1, ..., R - 1
```カウントは次のとおりです。```
R - L
```もし`L == R`、答えは自然になります。`0`。

 | 最適 | O(n log n) | O(1) 並べ替え以外の余分なスペース | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 値を読み取る`n`、`a`、 そして`b`、家事の難しさのリストとともに。 
2. 難易度の配列を降順でない順に並べ替えます。 

並べ替えたら、最初に`b`雑用は、ヴァシャが正確に引き受けなければならない場合に受け取ることができる唯一の雑用です`b`許容できる最小限の雑務。 
3. 次のようにしましょう。```
L = h[b - 1]
R = h[b]
```

`L`Vasya に割り当てられた最大の難易度であり、`R`Petya に割り当てられる最小の難易度です。 
4. すべての有効な整数`x`以下を満たす必要があります:```
L ≤ x < R
```左の条件は、Vasyaがすべての家事を行うことを保証します。 適切な状態があれば、ペティアはすべての家事を確実にこなすことができます。 
5. その間隔内の整数の数は次のとおりです。```
R - L
```6. 印刷`R - L`。 

### なぜ効果があるのか

 ソート後、2 人の兄弟間の分割点が固定されます。 Vasya は正確に最初のものを受け取る必要があります`b`Petya は残りの家事を正確に受け取らなければなりません`a`家事。 

Vasya に割り当てられたすべての雑用には、次のものが必要です。`h[i] ≤ x`。 最も強力な制限は、ヴァシャの最も困難な雑用から生じ、それには価値がある`L`。 

Petya に割り当てられたすべての雑用には、次のものが必要です。`h[i] > x`。 最も強力な制限は、Petya の最も簡単な雑用から生じますが、これには価値があります。`R`。 

したがって、有効な整数は正確にこれら 2 つの境界間の整数です。 値が小さい場合は Vasya の家事の 1 つが除外され、値が大きい場合は Petya の家事の 1 つが含まれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, a, b = map(int, input().split())
    h = list(map(int, input().split()))

    h.sort()

    print(h[b] - h[b - 1])

solve()
```この解決策は完全にソート順に依存します。 

並べ替え後、インデックスを作成します`b - 1`はヴァシャに割り当てられた最後の雑用であり、インデックス`b`Petya に割り当てられた最初の雑用です。 Python は 0 から始まるインデックスを使用するため、問題が 1 から始まる順序付けを使用して概念的に雑務を説明しているとしても、これらの位置は正しいです。 

答えは単に次の整数の数です。`h[b - 1]`を通して`h[b] - 1`に等しい`h[b] - h[b - 1]`。 

よくある間違いは、次のようなものを使用しようとすることです。`h[a - 1]`そして`h[a]`。 境界は、Petya のカウントではなく、Vasya のカウントによって決定されます。`b`並べ替えられた要素は Vasya に属します。 

もう 1 つの簡単な間違いは、手動で 1 を減算することです。```
h[b] - h[b - 1] - 1
```これにより、左側のエンドポイントが誤って除外されてしまいますが、`x = h[b - 1]`有効です。

def solve():

    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    backup = sys.stdout
    sys.stdout = out

    solve()

    sys.stdout = backup
    return out.getvalue()

 ## 特殊なケース

 境界が重複する場合を考えてみましょう。```
7 3 4
1 2 3 3 3 4 5
```並べ替え後:```
[1, 2, 3, 3, 3, 4, 5]
```次のように計算します。```
L = h[3] = 3
R = h[4] = 3
```アルゴリズムは次を返します。```
3 - 3 = 0
```これは正しいです。次の条件を同時に満たす整数はないからです。```
x ≥ 3
x < 3
```ここでギャップが大きい場合を考えてみましょう。```
5 2 3
1 2 10 20 30
```並べ替え後:```
[1, 2, 10, 20, 30]
```得られるものは次のとおりです。```
L = 2
R = 10
```アルゴリズムは次を返します。```
10 - 2 = 8
```有効な整数は次のとおりです。```
2, 3, 4, 5, 6, 7, 8, 9
```これにより、配列にすでに存在する問題だけでなく、解答が区間内のすべての整数をカウントすることが確認されます。 

最後に、可能な最小の入力を調べます。```
2 1 1
1 2
```並べ替え後:```
[1, 2]
```次のように計算します。```
L = 1
R = 2
```アルゴリズムは戻ります`1`、のみの意味`x = 1`動作します。 

もし`x = 0`、ヴァシャは雑用を受けません。 もし`x = 2`, Petyaは雑務を受けません。 境界ロジックは最小サイズでも完全に機能します。
