 ## 解決策
 ## 問題の理解

 それぞれのボウルは錐台、つまり先端が切り取られた円錐形です。 ボウルはその高さで表されます`h`、底部半径`r`、および上部半径`R`。 ボウルは指定された順序で積み重ねられ、常に同じ垂直軸を共有します。 新しいボウルはすべて、前のボウルと交差しないようにできるだけ下げられます。 

最も低いボウルの底から最も高いボウルの上端までを測定した、スタックの最終的な合計高さを計算する必要があります。 

ボウルは円柱ではないため、形状が重要になります。 ボウルの半径は高さに応じて線形に変化するため、2 つのボウルが衝突するかどうかは、それらの側面がどこで出会うかによって決まります。 

制約`n ≤ 3000`が重要な観察です。 二次解では約 900 万のペア チェックが実行されますが、各チェックが定数時間である場合、Python ではまったく問題ありません。 立方体的なものはすでに近づいています`2.7 × 10^10`2秒以内に操作は不可能です。 

難しいのは、以前のボウルがすでにいくつか存在する場合に、新しいボウルをどこまで下に配置できるかを決定することです。 不注意な実装では、上部と下部の半径のみを比較することがよくありますが、最初の衝突は傾斜面の中央のどこかで発生する可能性があります。 

次の例を考えてみましょう。```
2
10 1 100
10 99 100
```2 番目のボウルは最初のボウルの傾斜とほぼ一致しています。 それらは底部ではなく上部近くで衝突します。 底部の半径だけを比較すると、2 番目のボウルが非常に遠くまで下降できると誤って考えることになります。 

もう 1 つの微妙なケースは、完全な封じ込めです。```
2
100 1 100
10 2 3
```2 番目のボウルは最初のボウルの中に完全に収まるので、その底は最初のボウルの底に達します。 全高はそのまま`100`、 ない`110`。 

新しいボウルの幅がはるかに広い、逆の状況もあります。```
2
10 1 2
10 100 200
```2番目のボウルは最初のボウルにはまったく入りません。 その底部が最初のボウルの上に正確に収まり、全体の高さが決まります。`20`。 

これらのケースは、ヒューリスティックな比較ではなく、正確な幾何学的条件が必要な理由を示しています。 

## アプローチ

 最も直接的なシミュレーションは、ボウルを 1 つずつ処理することです。 新しいボウルを作るたびに、前のボウルに触れるまでボウルを下げてみてください。 すべてのボウルの垂直方向の位置はすでに固定されているため、唯一不明なのは、新しいボウルの底の高さです。 

ブルート フォース バージョンでは、以前のすべてのボウルとの交差をチェックしながら、位置を継続的にテストしたり、配置の高さをバイナリ検索したりできます。 半径は高さに応じて直線的に変化するため、ジオメトリのチェック自体は簡単です。 残念ながら、ボウルのペアごとに高精度で二分探索を行うと、総作業量はおよそ次のようになります。`O(n² log precision)`。 ここではまだ通過しますが、必要以上に複雑になり、基礎となる構造が隠れてしまいます。 

重要な観察は、2 つのボウル間の制限位置が相似な三角形を使用して直接導出できるということです。 

ボウルを想定します`i`底部が同じ高さになるようにすでに配置されています`pos[i]`。 丼を置きたい`j`できるだけ以下に。 

垂直オフセット時`x`ボウルの中`j`、その半径は次のとおりです。$$r_j + \frac{R_j - r_j}{h_j} x$$ボウル用`i`、高所で`y`底部より上：$$r_i + \frac{R_i - r_i}{h_i} y$$ボウルが最初に接触すると、これらの半径は、ある共通のグローバル高さで等しくなります。 方程式を解くと、非常に単純な条件がわかります。 

傾きが等しい場合、1 つのボウルは完全に適合するか、まったく適合しません。 

それ以外の場合は、接触点によって固有の相対シフトが決定されます。 

これにより、一定時間内に 1 つの以前のボウルに対する最小有効配置を計算できます。 以前のすべてのボウルの最大値を取ると、新しいボウルの最終位置が得られます。 

以来`n = 3000`すべてのペアを直接チェックすることは完全に許容されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 二分探索によるブルートフォース | O(n² 対数精度) | O(n) | 受け入れられるが、不必要に複雑 |
 | 直接幾何学計算 | O(n²) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 底面の高さを記憶する`pos[i]`ボウルごとに。 

最初のボウルは常に高さから始まります`0`。 
2. 指定された順序でボウルを処理します。 

ボウルの位置はその後変更されることはないため、以前のボウルは固定障害物として機能します。 
3. 現在のボウルの場合`j`、その一番下の位置を次のように初期化します。`0`。 

これは、まず完全に降下できると仮定することを意味します。 
4. ボウルを比較する`j`それまでのすべてのボウルに対して`i`。 

ボウルの最も低い高さを計算します`j`ボウルと交差しない`i`。 
5. しましょう$$k_i = \frac{R_i - r_i}{h_i}, \quad k_j = \frac{R_j - r_j}{h_j}$$これらはボウルの側面の斜面です。 

1. もし`k_i == k_j`、ボウルは幾何学的に似ています。 

この場合:

 - もし`r_j >= R_i`、ボウル`j`全体的に幅が広くてボウルに入りません`i`。 その底部は少なくとも`pos[i] + h_i`。 
- それ以外の場合はボウル`j`ボウル内で完全にスライドできます`i`したがって、このペアにはそれ以上の制限は課されません。`pos[i]`。 
2. それ以外の場合は、側面の最初の接触点を求めます。 

最小有効ボトム位置の導出式は次のとおりです。$$need = pos[i] + \frac{r_i - r_j + k_j h_j}{k_j - k_i}$$この式はボウルの外面の位置を示します。`j`初めてボウルに触れます`i`。 

1.ボウル`j`ボウルの底よりも下に行くこともできません`i`。 

次の値を使用して値をクランプします。$$need = \max(need, pos[i])$$1. 現在のボウルは以前の制限をすべて満たす必要があるため、次のように更新します。$$pos[j] = \max(pos[j], need)$$1. すべてのボウルを配置すると、答えは次のようになります。$$\max_i (pos[i] + h_i)$$これはスタック内で最も高い上端です。 

### なぜ効果があるのか

 ボウルの各ペアについて、それらが交差しない最低の相対配置が存在します。 位置が低いと傾斜面が交差してしまいます。 導出された方程式は、この境界位置を正確に計算します。 

ボウルを加工する場合`j`、以前のすべてのボウルにはすでに固定位置があります。 すべてのペアの下限の最大値を取得すると、ボウルの実行可能な最小の独自の配置が得られます。`j`。 ボウルは常に可能な限り低い位置に配置されるため、この欲張りな構造は物理的なスタッキングプロセスと一致します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

EPS = 1e-12

def main():
    n = int(input())

    h = [0.0] * n
    r = [0.0] * n
    R = [0.0] * n

    for i in range(n):
        hh, rr, RR = map(float, input().split())
        h[i] = hh
        r[i] = rr
        R[i] = RR

    pos = [0.0] * n

    for j in range(n):
        best = 0.0

        kj = (R[j] - r[j]) / h[j]

        for i in range(j):
            ki = (R[i] - r[i]) / h[i]

            if abs(ki - kj) < EPS:
                if r[j] >= R[i] - EPS:
                    need = pos[i] + h[i]
                else:
                    need = pos[i]
            else:
                need = pos[i] + (r[i] - r[j] + kj * h[j]) / (kj - ki)
                need = max(need, pos[i])

            best = max(best, need)

        pos[j] = best

    ans = 0.0

    for i in range(n):
        ans = max(ans, pos[i] + h[i])

    print(f"{ans:.10f}")

if __name__ == "__main__":
    main()
```配列`h`、`r`、 そして`R`各ボウルの幾何学的パラメータを保存します。 の`pos`配列には、各ボウルの底の垂直座標が格納されます。 

メインループはボウルを挿入順に処理します。 以前のボウルは二度と移動しないため、以前の位置が固定されると、配置の決定はすべて独立して行われます。 

傾きの計算は最も重要な幾何学的要素です。```
k = (R - r) / h
```これは、単位高さあたりの半径の増加です。 ボウルの壁は直線であるため、任意の高さの半径は単純な一次関数になります。 

平行な斜面には別個の処理が必要です。 2 つのボウルの側面の角度が同じ場合、一方の方が完全に幅が広い場合を除き、傾斜面に沿って交差することはありません。 浮動小数点比較では、`EPS`なぜなら、double の正確な等価性は信頼できないからです。 

式:```
need = pos[i] + (r[i] - r[j] + kj * h[j]) / (kj - ki)
```は、接触点での半径の等価性を解くことから直接得られます。 この導出では、最初の接触が側壁で発生すると仮定しています。 

クランプ:```
need = max(need, pos[i])
```現在のボウルが以前のボウルの底より下になるのを防ぎます。 この線がないと、構成によってはボウルが物理的に可能なよりも深く誤って配置されてしまいます。 

最後に、答えは単に最後のボウルの上部だけではありません。 以前のボウルはその後のボウルよりも高く伸びる可能性があるため、すべてのボウルの最大値を計算します。

 ## 特殊なケース

 封じ込めの場合を考えてみましょう。```
2
100 1 100
10 2 3
```最初のボウルは、2番目のボウルに比べて非常に幅が広​​いです。 処理中、計算された制限によって 2 番目のボウルが上向きに強制されることはありません。 その底はそのままです`0`。 

上位は次のとおりです。 

- ボウル 0:`0 + 100 = 100`- ボウル 1:`0 + 10 = 10`アルゴリズムは正しく出力します`100`。

```したがって、2 番目のボウルは最初のボウルが終了した時点から始まります。 最終的な高さは、`20`。
