 ## 解決策
 ## 問題の理解

 各論文では、2 つの都市間の無向エッジについて説明しています。 すべての論文は正確に 2 冊の旅行雑誌から引用されたものであると言われています。 ある日記の中に、旅行者は通過した一連の道を書き留めました。旅行者はそれを再利用できるため、同じ道路が複数回表示されることがあります。 

タスクは、与えられたすべてのエッジを 2 つの空ではない順序付けされたシーケンスに分割し、各シーケンスがグラフ内で有効なウォークを形成するようにすることです。 旅行者はある道路から次の道路へと継続的に移動するため、1 つのシーケンス内の連続するエッジは都市を共有する必要があります。 

この問題を別の言い方で表現すると、次のようになります。すべての紙がエッジであるマルチグラフが与えられています。 すべてのエッジを 2 つのエッジの切り離されたトレイルに分割する必要があります。 

グラフは必ずしもつながっているとは限りません。 平行なエッジは許可されます。 ステートメントが保証しているため、自己ループは禁止されています。`a != b`。 

限界はただ`m <= 10000`したがって、線形または線形に近いグラフ アルゴリズムは完全に安全です。 アン`O(m^2)`解決策はすでに近づいているでしょう`10^8`最悪の場合、Python では操作が危険になります。 問題の構造はオイラー グラフ推論を強く示唆しています。これは、2 つのパスにわたってすべてのエッジを 1 回だけ使用するトレイルにエッジを配置する必要があるためです。 

危険な部分は、1 つのオイラー トレイルを構築しているのではなく、正確に 2 つのトレイル (どちらも空ではない) を構築していることです。 単純な分解では、誤って 3 つ以上のコンポーネントが生成されたり、すべてのエッジが 1 つのトレイルに消費されたりする可能性があります。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

次のグラフを考えてみましょう。```
3
1 2
2 3
3 1
```すべての次数は偶数であるため、すべてのエッジを使用する 1 つのオイラー サイクルが存在します。 しかし、この問題には 2 つの空ではないパスが必要です。 正しい答えは、サイクルをどこかで分割することです。次に例を示します。```
2
1 2
1
3
```オイラー条件をチェックして 1 つの証跡を出力するだけのソリューションは失敗します。 

次に、次のことを考えてみましょう。```
2
1 2
3 4
```すでに 2 つの切断されたエッジがあります。 各エッジ自体が有効なパスを形成するため、答えはすぐに存在します。 

不注意な実装では、接続されたコンポーネントをマージしようとし、単一の接続された走査がないためにグラフを誤って拒否する可能性があります。 

もう一つの微妙なケース:```
4
1 2
2 3
3 4
4 5
```これは奇数の頂点が 2 つだけある単純なチェーンです。 オイラー軌跡は 1 つだけ許可されます。 2 つのトレイルに分割することも可能です。```
2
1 2
2
3 4
```重要な観察点は、トレイルはグローバルに接続する必要がないということです。 すべてのエッジが 2 つのトレイルのいずれかに属している必要があるだけです。 

最後に、奇数の頂点が多すぎるグラフは不可能です。 例えば：```
3
1 2
1 3
1 4
```頂点`1`学位を持っています`3`、および頂点`2,3,4`それぞれに学位がある`1`。 つまり、1 つの連結コンポーネント内の 4 つの奇数の頂点です。 2 つのトレイルを合わせてグローバルに最大 4 つの奇数エンドポイントに貢献できますが、接続の制約によりこの構成は不可能です。 

奇数の頂点をいつペアにできるかを正確に理解することが問題の核心です。 

## アプローチ

 ブルートフォースの観点は単純明快です。 すべてのエッジは、2 つの順序付けされたトレイルのいずれかに属している必要があります。 エッジのすべてのパーティションを 2 つのグループに分けて試し、各グループがオイラー トレイルを許可するかどうかを確認できます。 

がある`2^m`パーティション。 たとえ`m = 40`、これは不可能になります。 と`m = 10000`、力技は完全に絶望的です。 

よりグラフ理論的な力技を使用すると、状況がわずかに改善されます。 2 つのトレイルのエンドポイントを選択してから、オイラー走査を構築することができます。 しかし、各接続コンポーネントはさまざまな方法で 2 つのパスと相互作用する可能性があり、組み合わせの数は依然として指数関数的に増加しています。 

画期的な進歩は、頂点のパリティに注目することから生まれます。 

すべての連結成分に 0 個または 2 個の奇数次の頂点がある場合、グラフを 1 つのオイラー軌跡で正確に横断できます。 より一般的には、すべてのエッジをカバーしたい場合は、`k`トレイルの場合、各トレイルは最大 2 つの奇数エンドポイントに寄与します。 これは、次の接続コンポーネントを意味します。`2t`奇数の頂点には少なくとも必要です`t`トレイル。 

合計でちょうど 2 つのトレイルが許可されるため、接続されているすべてのコンポーネントには最大 2 つのトレイルが必要であり、すべてのコンポーネントの合計も 2 以内に収まる必要があります。 

これにより、問題は検索問題からパリティ問題に変換されます。 

コンポーネントに次のものがあるとします。 

-`0`奇数の頂点。 これにはすでにオイラー サイクルが含まれており、1 つのトレイルが必要です。 
-`2`奇数の頂点。 すでにオイラー トレイルが含まれており、トレイルが 1 つ必要です。 
-`4`奇数の頂点。 正確に 2 つのトレイルが必要です。 
- より多い`4`奇数の頂点。 不可能。 

ここで、複数の接続コンポーネントを考えてみましょう。 空ではないすべてのコンポーネントには少なくとも 1 つのトレイルが必要です。 グローバルにトレイルが 2 つしかないため、グラフには最大 2 つの「トレイル要件」を含めることができます。 

これはすぐに完全な特徴を示唆します。 

実現可能性を決定した後、トレイルの構築はオイラートラバース問題になります。 奇数の頂点を偽のエッジと人為的に組み合わせて、すべてのコンポーネントをオイラー型にし、Hierholzer のアルゴリズムを実行して、偽のエッジでトラバースをカットして必要なトレイルを回復することができます。 

これは、オイラー分解問題の背後にある標準的なトリックです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^m) | O(m) | 遅すぎる |
 | 最適 | O(m α(m)) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. マルチグラフを構築します。 

各紙は、入力インデックスが保持された 1 つの無向エッジになります。 後でオイラー走査が必要になるため、隣接リストを保存します。 
2. DSU を使用して、接続されているコンポーネントを検索します。 

オイラー条件は接続された各コンポーネント内で個別にチェックされるため、コンポーネントは重要です。 
3. すべてのコンポーネント内の奇数次の頂点を数えます。 

コンポーネントの場合`2t`少なくとも奇数の頂点`t`すべての端をカバーするにはトレイルが必要です。 
4. 最低限必要なトレイルの数を計算します。 

空ではないコンポーネントごとに次のようにします。 

- ある場合`0`奇数の頂点、それが貢献します`1`- それ以外の場合は貢献します`odd_count / 2`すべてのコンポーネントのこれらの値を合計します。 

合計が正確でない場合`2`、調整するか拒否する必要があります。 
5. 不可能なケースは拒否します。 

最小必要トレイル数を超えた場合`2`、解決策は存在しません。 

必要なトレイルが 1 つだけで、グラフに少なくとも 2 つのエッジがある場合は、後でオイラー サイクル/トレイルを 2 つの空でない部分に分割できます。 

グラフにエッジが 1 つしかない場合、両方のパスが空ではない必要があるため、答えは不可能です。 
6. 偽のエッジを追加して、すべての度数を均等にします。 

すべてのコンポーネント内で、奇数の頂点を任意にペアにして、偽のエッジで接続します。 

このステップの後、すべてのコンポーネントはオイラー型になります。 
7. Hierholzer のアルゴリズムを実行します。 

すべてのコンポーネントを調べて、オイラー サイクルを構築します。 

実際のエッジは、元のインデックスによって記録されます。 フェイクエッジには特別なマークが付けられています。 
8. 偽のエッジでトラバースを分割します。 

すべての偽のエッジが 2 つのトレイルを分離します。 

偽のエッジを削除すると、オイラー サイクルがそのコンポーネントに必要なトレイルの正確な数に分解されます。 
9. 取得したすべての証跡を結合します。 

グラフにはグローバルに最大 2 つのトレイルが必要です。 

正確に 2 つ得られた場合は、それらを出力します。 

1 つの証跡を取得した場合、それを空ではない 2 つの連続した部分に分割します。 

### なぜ効果があるのか

 奇数の頂点と偽のエッジを組み合わせると、各コンポーネントがオイラー グラフに変換されます。 Hierholzer のアルゴリズムは、すべての本物のエッジと偽のエッジを 1 回だけ使用してサイクルを生成します。 

偽のエッジを削除すると、オイラー サイクルが別々のトレイルに分割されます。 各フェイク エッジにより奇数ペアの数が 1 つずつ減るため、分解によってそのコンポーネントの可能な最小数のトレイルが生成されます。 

すべてのコンポーネントにわたるトレイルの合計最小数は、パリティによって課される下限と正確に一致します。 その値が 2 を超えると、構築は成功しません。 それ以外の場合、分解により 1 つまたは 2 つのトレイルが得られ、少なくとも 2 つのエッジがある限り、1 つのトレイルは常に 2 つの空でない部分に分割できます。 

すべての実際のエッジはオイラー探索で 1 回だけ出現し、偽のエッジは破棄されるため、最終的な答えではすべての紙が 1 回だけ使用されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from collections import defaultdict

class DSU:
    def __init__(self, n):
        self.p = list(range(n + 1))
    
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x
    
    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a != b:
            self.p[b] = a

def solve():
    m = int(input())
    
    edges = [None]
    maxv = 10000
    
    dsu = DSU(maxv)
    deg = [0] * (maxv + 1)
    used_vertex = [False] * (maxv + 1)
    
    for i in range(1, m + 1):
        a, b = map(int, input().split())
        edges.append((a, b))
        
        dsu.union(a, b)
        deg[a] += 1
        deg[b] += 1
        used_vertex[a] = True
        used_vertex[b] = True
    
    comps = defaultdict(list)
    
    for v in range(1, maxv + 1):
        if used_vertex[v]:
            comps[dsu.find(v)].append(v)
    
    need = 0
    
    for verts in comps.values():
        odd = 0
        edge_cnt = 0
        
        for v in verts:
            if deg[v] % 2 == 1:
                odd += 1
            edge_cnt += deg[v]
        
        edge_cnt //= 2
        
        if edge_cnt == 0:
            continue
        
        if odd == 0:
            need += 1
        else:
            need += odd // 2
    
    if need > 2 or m < 2:
        print(-1)
        return
    
    adj = defaultdict(list)
    edge_id = 0
    
    for i in range(1, m + 1):
        a, b = edges[i]
        edge_id += 1
        
        adj[a].append((b, edge_id, i))
        adj[b].append((a, edge_id, i))
    
    fake_index = -1
    
    for verts in comps.values():
        odds = []
        
        for v in verts:
            if deg[v] % 2 == 1:
                odds.append(v)
        
        for i in range(0, len(odds), 2):
            if i + 1 < len(odds):
                a = odds[i]
                b = odds[i + 1]
                
                edge_id += 1
                
                adj[a].append((b, edge_id, fake_index))
                adj[b].append((a, edge_id, fake_index))
                
                fake_index -= 1
    
    used = set()
    trails = []
    
    for start in range(1, maxv + 1):
        if not adj[start]:
            continue
        
        stack = [(start, None)]
        path = []
        
        while stack:
            v, incoming = stack[-1]
            
            while adj[v] and adj[v][-1][1] in used:
                adj[v].pop()
            
            if not adj[v]:
                stack.pop()
                if incoming is not None:
                    path.append(incoming)
            else:
                to, eid, idx = adj[v].pop()
                
                if eid in used:
                    continue
                
                used.add(eid)
                stack.append((to, idx))
        
        if path:
            path.reverse()
            
            cur = []
            
            for x in path:
                if x < 0:
                    if cur:
                        trails.append(cur)
                        cur = []
                else:
                    cur.append(x)
            
            if cur:
                trails.append(cur)
    
    if len(trails) == 1:
        t = trails[0]
        trails = [t[:1], t[1:]]
    
    if len(trails) != 2 or not trails[0] or not trails[1]:
        print(-1)
        return
    
    print(len(trails[0]))
    print(*trails[0])
    print(len(trails[1]))
    print(*trails[1])

solve()
```DSU セクションでは、パリティ制約がコンポーネントごとにチェックされるため、頂点が連結コンポーネントにグループ化されます。 よくある間違いは、奇数の頂点をグローバルに数えることです。 それぞれ 2 つの奇数頂点を持つ 2 つの別個のコンポーネントには、すでに 2 つのトレイルが個別に必要です。 

の`need`計算により、必要な最小数のトレイルがエンコードされます。 すべて偶数の次数を持つコンポーネントでも、エッジを何らかの方法で横断する必要があるため、1 つのトレイルが必要です。 

フェイクエッジの構築は重要な変革です。 奇数の頂点をペアにすると、すべての次数が均等になり、オイラー サイクルが可能になります。 偽のエッジには負の識別子が割り当てられるため、後で認識して削除できます。 

Hierholzer のアルゴリズムはスタックを使用して反復的に実装されます。 これにより、多くの繰り返しエッジを持つ大きなグラフでの再帰の深さの問題が回避されます。 

微妙な詳細の 1 つは、マルチグラフでのエッジ処理です。 平行なエッジが存在する可能性があるため、単純に頂点ペアを使用済みとしてマークすることはできません。 各エッジは一意の内部 ID を受け取ります。 

オイラー サイクルを取得した後、すべての疑似エッジはトレイル間のセパレーターとして機能します。 偽のエッジで分割すると、元の分解が再構築されます。 

最後の特殊なケースでは、最小要件が 1 つのトレイルであるグラフを処理します。 少なくとも 2 つのエッジを持つオイラー トレイルは、空ではない連続する 2 つの部分に切り分けることができ、各部分は有効なトレイルのままになります。

 ## 特殊なケース

 あり得ない最小のケースを考えてみましょう。```
1
1 2
```エッジは 1 つだけです。 有効なトレイルには少なくとも 1 つのエッジが含まれている必要があるため、空ではない 2 つのトレイルは不可能です。 アルゴリズムはこれを即座に捕捉します。`m < 2`。 

ここで、純粋なオイラー サイクルを考えてみましょう。```
3
1 2
2 3
3 1
```すべての頂点の次数は偶数であるため、トレイルの最小数は次のようになります。`1`。 このアルゴリズムは、次のような 1 つのオイラー サイクルを構築します。`[1,2,3]`、それを次のように分割します。`[1]`そして`[2,3]`。 連続するエッジは依然としてエンドポイントを共有しているため、各部分は有効な証跡のままです。 

次に、接続されていないコンポーネントについて考えます。```
2
1 2
3 4
```各コンポーネントには奇数の頂点が正確に 2 つあるため、それぞれに 1 つのトレイルが必要です。 合計要件は次のようになります`2`、許可された数と一致します。 このアルゴリズムは、コンポーネントごとに 1 つの証跡を独立して抽出します。 

最後に、奇数の頂点が多すぎることを考慮します。```
5
1 2
1 3
1 4
1 5
1 6
```頂点`1`学位を持っています`5`、葉にはそれぞれ度があります`1`。 奇数の頂点が合計 6 つあります。つまり、コンポーネントには少なくとも 3 つのトレイルが必要です。 許可されるのは 2 つだけであるため、アルゴリズムはすぐに拒否します。
