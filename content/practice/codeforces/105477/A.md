 ## 解決策
 ## 問題の理解

 いくつかの独立したシナリオが与えられています。 各シナリオで、Baq はコインのコレクションを所有しており、各コインは正の整数値を持っています。 これらのコインを任意の数使用して、サブセットを選択し、その値を加算することで合計を計算できます。 問題は、どれだけの合計を形成できるかということではなく、そのような合計として表すことができない最小の正の整数についてです。 

したがって、テスト ケースごとに、正の整数のマルチセットのすべてのサブセットの合計を効果的に調べ、達成可能な合計のセット内の最初のギャップを求めます。 

重要な制約は、コインの数が多くなり、最も困難なケースでは最大 10,000 枚になる可能性があり、コインの値が 10^9 に達する可能性があることです。 これにより、サブセット合計を明示的に列挙しようとする試みが即座に除外されます。これは、n が中程度であっても、サブセット合計の数が指数関数的に増加するためです。 合計の範囲には制限がなく、非常に大きくなる可能性があるため、合計に対する動的計画法さえも実行不可能です。 

素朴な考えによる微妙な失敗例は、到達可能なすべての合計を生成し、次に最初に不足している合計をスキャンする必要があると仮定することです。 たとえば、コイン [1, 3] の場合、到達可能な合計は {1, 3, 4} であるため、2 が欠落しています。 しかし、すべての組み合わせを総当りで計算しようとすると、任意のコイン 30 枚など、わずかに大きな入力に対して実行可能な計算をすでに超えてしまいます。 

もう 1 つの誤解を招く直感は、並べ替えだけで十分であるというものです。 並べ替えは推論を構造化するのに役立ちますが、正しい貪欲な蓄積ロジックがなければ、答えは直接得られません。 

## アプローチ

 ブルートフォースのアイデアは簡単です。すべてのサブセットの合計を生成し、どの正の整数が欠落しているかをチェックします。 これは、到達可能性の定義を直接モデル化するため、概念的に機能します。 ただし、コインごとにサブセットの数が 2 倍になるため、n 個のコインでは 2^n の合計が得られます。 n = 40 では、これはすでに天文学的に大きくなり、制約により最大 10,000 枚のコインが許可されるため、このアプローチは基本的に不可能になります。 

重要な観察は、視点を変えることで得られます。すべての合計を追跡するのではなく、1 から開始してすでに連続的に形成できる正の整数の最小の接頭辞を追跡します。1 から x までのすべての値が形成できるとすでに決定しているとします。 次に、新しいコインの値 v を考えます。 v が x + 1 より大きい場合、x + 1 はすぐに到達できなくなります。これは、既存の合計はすべて x であり、v を追加するとギャップが埋まらずにオーバーシュートしてしまうためです。 v が最大 x + 1 の場合、x までのすべての値を v と組み合わせて次のセグメントを満たすことができるため、到達可能な間隔を x + v まで拡張できます。 

この貪欲な間隔の拡張が中心的なアイデアです。 組み合わせの観点から考える代わりに、表現可能な合計の増大する連続セグメントを維持します。 最初のギャップは、次の欠損値を埋めることができないコインが到着したときに正確に現れます。 

可能な限り効率的に最小の連続範囲を構築するために、最初に小さな値を処理したいため、コインのソートは不可欠です。

 ## アルゴリズムのチュートリアル

 1. コインの価値を降順でない順に並べ替えます。 これにより、常に最小の到達可能な範囲を最初に拡張しようとすることが保証されます。 
2. 変数を初期化する`reach = 0`つまり、現在 1 から までのすべての合計を計算できます。`reach`継続的に。 
3. 各コインの値を反復処理します。`v`ソートされた順序で。 
4. もし`v > reach + 1`、すぐに停止して出力します`reach + 1`。 これは、埋められない溝があるために形成できない最初の価値です。 
5. それ以外の場合は更新します`reach = reach + v`。 これにより連続到達範囲が拡大します。 
6.すべてのコインを処理した後、出力します`reach + 1`まですべてを形成できるため、`reach`しかしそれ以上は何もありません。 

ステップ 4 の主な推論は、次の点にギャップがある場合です。`reach + 1`、後のコインはすべて少なくとも次のサイズと同じ大きさであるため、それを修正することはできません。`v`したがって、欠損値を埋めるには大きすぎます。 

### なぜ効果があるのか

 ソートされたコインのプレフィックスを処理した後はいつでも、範囲内のすべての整数が不変であることが維持されます。`[1, reach]`処理されたコインの一部を使用して表現できます。 コインを見ると`v`そのような`v <= reach + 1`、それを以前に達成可能なすべての合計と組み合わせて、ギャップを作らずに到達可能な範囲を拡張できます。 もし`v > reach + 1`、構築する方法はありません`reach + 1`、すべての組み合わせは以下のいずれかに収まるため、`[1, reach]`またはそれを飛び越えます。 この不変条件により、最初の違反が到達不可能な最小の合計に正確に対応することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    arr = list(map(int, input().split()))
    arr.sort()

    reach = 0
    for v in arr:
        if v > reach + 1:
            break
        reach += v

    print(reach + 1)
```この解決策は、常に昇順で考慮されるようにコインを並べ替えることから始まります。これは、連続した到達可能な間隔を維持するために必要です。 変数`reach`現在形成できる最大の連続合計を追跡します。 各コインはこの間隔を延長するか、ギャップを露出させます。 条件`v > reach + 1`最初の到達不能な整数を正確にキャプチャします。`reach + 1`は、どの段階でも最小の欠損値です。 

よくある実装ミスは初期化です`reach`間違っています。 コインを使用する前は空の合計のみが達成可能であり、注目する最初の正の合計は 1 であるため、これは 0 から開始する必要があります。もう 1 つの微妙な点は、厳密な不等式です。`>=`の代わりに`>`コインは次と等しいため、正しさが失われます。`reach + 1`到達可能な範囲はさらに広がるはずです。

import sys, io

def run(inp: str) -> str:

 ## 特殊なケース

 値 1 の単一コインの場合、ソートされた配列は次のようになります。`[1]`。 アルゴリズムセット`reach = 1`、ギャップが現れないので、出力します`2`。 これは、1 だけが構築可能で、2 が欠落しているという事実と一致します。 

のようなコインの場合`[2, 3]`、並べ替えると同じ順序になります。 最初は`reach = 0`、最初のコインは 2 です。`2 > 1`、アルゴリズムはすぐに停止し、戻ります`1`、正の和を形成できないことが正しく識別されます。 

次のような完全に密なセットの場合`[1, 2, 3, 4]`、各コインは満たします`v <= reach + 1`したがって、到達可能な間隔は 10 まで連続的に増加し、答えは 11 になります。これは、新しいコインが次の欠落している整数を埋めるのに十分な大きさである場合、ギャップは発生しないという不変条件を裏付けます。
