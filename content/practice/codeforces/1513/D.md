 ## 解決策
 ## 問題の理解

 正の整数の配列から構築された重み付きグラフの最小スパニング ツリー (MST) を計算するように求められます。 配列の各要素は頂点に対応し、隣接する要素の間にエッジが固定の重みで存在します。`p`または任意の頂点のペアの間`(i, j)`すべての要素の最大公約数 (GCD) が`a[i]`に`a[j]`はその部分配列の最小値に等しい。 このようなエッジの重みは部分配列の最小値です。 目標は、すべてのエッジを明示的に構築することではなく、MST 重みを効率的に計算することです。 

制約は次のことを示しています`n`テスト ケースごとに最大 2 · 10^5 にすることができ、次の合計`n`すべてのテスト ケースにわたる も 2·10^5 です。 これは、テスト ケースあたり O(n^2) 時間のアプローチは、およそ 4 · 10^10 の演算が必要となるため、直ちに実行不可能であることを意味します。 線形または線形演算に近いアルゴリズムが必要です。`n`。 

すべての配列要素が以下の場合に、微妙なエッジ ケースが発生します。`p`。 たとえば、次の場合`n = 3`、`p = 5`、 そして`a = [3, 3, 3]`、単純な隣接処理では、隣接しない頂点間に不必要にエッジを作成しようとしたり、安価なエッジを見逃したりする可能性があります。 同様に、配列に大きな要素で囲まれた 1 つの小さな要素がある場合、貪欲接続は、この小さな要素を介して接続することで MST コストを以下に削減できることを正しく認識する必要があります。`p`エッジごとに。 

## アプローチ

 ブルートフォースアプローチは、文字通りすべての候補エッジを生成することです。 すべてのペアについて`(i, j)`GCD を計算すると、`a[i..j]`そしてその範囲内の最小値。 等しい場合は、重みを付けてエッジを追加します`min(a[i..j])`。 隣接する頂点には常にウェイトのエッジが適用されます`p`。 エッジを生成した後、Kruskal または Prim のアルゴリズムを実行して MST を計算します。 これは問題のルールに正確に従っているので正しいですが、エッジの生成と並べ替えでは最悪の場合でも O(n^2 log n) となり、これはあまりにも遅すぎます。`n = 2·10^5`。 

重要な洞察は、すべてのエッジが必要なわけではないということです。 を超える重みを持つエッジ`p`隣接するものを使用するよりも決して安くなりません`p`MST のエッジ。 したがって、注意をエッジに限定することができます。`min(a[i..j]) < p`。 それらについては、各要素を考慮してください`a[k]`連続する範囲を接続する候補として、それが最小値となり、その範囲内のすべての要素が分割されます。 これにより、問題は貪欲な構造に変換されます。つまり、最小の要素から開始し、GCD がその要素で割り切れる範囲内で左右に拡張します。 これらの範囲により、disjoint-set Union (DSU) を使用して MST に追加できるエッジが得られます。 これにより、すべてのペアに対する明示的な GCD 計算を回避でき、問題を配列の大まかなソートと共用体検索操作の実行に軽減し、テスト ケースごとに O(n log n) の複雑さを実現します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2 log n) | O(n^2) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`、`p`、および配列`a`。 
2. 素セット共用体 (DSU) 構造体を初期化します。`n`要素。 これにより、MST でどの頂点がすでに接続されているかが追跡されます。 
3. インデックスのリストを作成する`idx`対応する配列値でソート`a[i]`。 これにより、潜在的な最小値を昇順に処理できるようになります。 
4.初期化`mst_weight = 0`そして`edges_used = 0`。 これらは MST の合計重みを蓄積し、追加したエッジの数を追跡します。 
5. ソートされたインデックスを繰り返し処理します。 それぞれについて`i`:

 - 次の場合はスキップします`a[i] >= p`なぜなら、そのようなエッジは固定エッジより決して安くならないからです。`p`エッジ。 
- 左に拡張してみます。前の要素は存在しますが、DSU ではまだ接続されておらず、次の要素で割り切れます。`a[i]`、それらを結合して追加します`a[i]`に`mst_weight`。 
- 同様に、右側に拡張して、隣接する分割可能な要素を結合します。 
- 各結合は MST エッジの追加に対応するため、インクリメントします`edges_used`。 
6. すべての小さな要素を処理した後、接続されていないペアが残る場合があります。 隣接するペアごとに`(i, i+1)`同じ DSU コンポーネント内にない場合は、それらを結合して追加します`p`に`mst_weight`。 
7. 印刷`mst_weight`テストケース用。 

機能する理由: 配列要素を最小から最大まで処理することにより、MST エッジを作成するたびに、そのコンポーネントにとって可能な限り低コストで作成できるようになります。 可分性により、連続した範囲で GCD 条件が満たされることが保証されます。 ウェイト付きの残りの隣接エッジ`p`より小さい要素が 2 つの頂点を接続できないケースを処理し、MST が完全であることを確認します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
    
    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x
    
    def union(self, x, y):
        x_root, y_root = self.find(x), self.find(y)
        if x_root == y_root:
            return False
        self.parent[y_root] = x_root
        return True

def solve():
    t = int(input())
    for _ in range(t):
        n, p = map(int, input().split())
        a = list(map(int, input().split()))
        dsu = DSU(n)
        idx = sorted(range(n), key=lambda i: a[i])
        mst_weight = 0
        edges_used = 0
        
        for i in idx:
            if a[i] >= p:
                break
            j = i - 1
            while j >= 0 and a[j] % a[i] == 0 and dsu.union(i, j):
                mst_weight += a[i]
                edges_used += 1
                j -= 1
            j = i + 1
            while j < n and a[j] % a[i] == 0 and dsu.union(i, j):
                mst_weight += a[i]
                edges_used += 1
                j += 1

        for i in range(n - 1):
            if dsu.union(i, i + 1):
                mst_weight += p
                edges_used += 1

        print(mst_weight)

if __name__ == "__main__":
    solve()
```コードはまず、効率的な結合と検索のためにパス圧縮を使用して DSU を定義します。 インデックスを並べ替えることで、最も安価な潜在的な MST エッジが最初に処理されるようになります。 左右の拡張は、GCD 条件を満たすエッジに対応する、隣接する分割可能な要素を結合します。 最後に、ウェイトの残りの隣接エッジ`p`接続された MST を保証します。 

## 実用的な例

 サンプル入力 1:```

a = [10, 10]
```| ステップ | アクション | DSU 親 | MST 重量 | 使用されるエッジ |

 | 1 | インデックスを値で並べ替える | [0, 1] | 0 | 0 |

 | 3 | 残りの隣接ペア (0,1) を p=5 | で接続します。 [0,0] | 5 | 1 |

これらのトレースは、小さな要素が GCD ベースの接続に貪欲に使用され、残りの隣接エッジが残りを処理することを示しています。
