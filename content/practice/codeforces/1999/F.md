 ## 解決策
 ## 問題の理解

 のみを含むバイナリ配列が与えられます。`0`そして`1`。 長さのすべての部分列に対して`k`、 どこ`k`が奇数である場合、その中央値を計算し、これらの中央値をすべて加算します。 

配列はバイナリであるため、中央値の性質が完全に変わります。 奇数長のバイナリ シーケンスの中央値は次のとおりです。`0`または`1`。 このようなシーケンスを並べ替えると、中央値は次のようになります。`1`まさにその要素の半分以上が`1`。 

させて

-`z`元の配列内のゼロの数になります。 
-`o`元の配列内の 1 の数になります。 

タスクは、長さを数えることです。`k`部分列には中央値があります`1`、そのようなすべてのサブシーケンスが正確に寄与するため、`1`中央値を持つすべての部分列を合計します。`0`貢献する`0`。 

制約は大きいです。 の合計額`n`すべてのテストケース全体で最大でも`2·10^5`。 すべてのサブシーケンスを列挙することは不可能です。`C(200000,100000)`天文学的に大きいです。 サブシーケンスの明示的な生成を伴う解決策は、直ちに除外されます。 

この制限は、次のような解決策を提案します。`O(n)`または`O(n log MOD)`いくつかのグローバルな前処理後のテスト ケースごと。 係数は素数であり、組み合わせは自然に現れるため、階乗と逆階乗を事前に計算することは強力なヒントになります。 

いくつかの特殊なケースは注目に値します。 

考慮する：```
n = 5, k = 1
array = [1,1,1,1,1]
```すべての要素自体はサブシーケンスです。 答えは`5`。 部分列から少なくとも 2 つの要素が選択されると仮定する式は、ここでは失敗します。 

考慮する：```
n = 5, k = 5
array = [0,1,0,1,0]
```サブシーケンスは 1 つだけ、配列全体です。 2 つの 1 と 3 つのゼロが含まれるため、その中央値は次のようになります。`0`。 答えは`0`。 不注意な実装では、使用可能な 1 の数を考慮せずに、過半数を選択するためにあらゆる方法がカウントされる可能性があります。 

考慮する：```
n = 4, k = 3
array = [1,0,1,1]
```長さ 3 のすべての部分列には少なくとも 2 つの値が含まれるため、すべての中央値は以下に等しくなります。`1`。 答えは`4`。 このケースでは、過半数のしきい値が次のように正しく計算されているかどうかをチェックします。`(k+1)/2`。 

## アプローチ

 最も直接的なアプローチは、あらゆる長さを生成することです。`k`後続のシーケンスをソートし、中央値を計算し、結果を累積します。 

これは定義に正確に従っているため、正しいです。 残念ながら、サブシーケンスの数は$$\binom{n}{k}$$これは、中程度の値ではすでに巨大です`n`。 たとえ`n = 50`そして`k = 25`、カウントが超えています$10^{14}$。 ブルートフォースアプローチは完全に実行不可能です。 

重要な観察は、0 と 1 の位置は重要ではないということです。 選択されるゼロと 1 の数だけが重要です。 

配列はバイナリであるため、長さの中央値は`k`後続は`1`サブシーケンスに少なくとも次のものが含まれる場合に限り、$$\frac{k+1}{2}$$もの。 

させて$$m=\frac{k+1}{2}.$$サブシーケンスに正確に含まれていると仮定します。`i`もの。 それからそれは含まれています`k-i`ゼロ。 このような部分列は次の場所に存在します。$$\binom{o}{i}\binom{z}{k-i}$$なぜなら、私たちはどの 1 とどの 0 が参加するかを独自に選択するからです。 

すべてのサブシーケンス`i ≥ m`貢献する`1`答えに。 すべてのサブシーケンス`i < m`貢献する`0`。 

したがって、答えは次のようになります$$\sum_{i=m}^{k} \binom{o}{i} \binom{z}{k-i}.$$ここで、問題は組み合わせの合計を評価することに移ります。 

以来`n`すべてのテスト ケースで最大でも`2·10^5`階乗と逆階乗を一度事前計算し、すべての組み合わせクエリに答えることができます。`O(1)`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O\left(\binom{n}{k}\cdot k\log k\right)$|$O(k)$| 遅すぎる |
 | 最適 |$O(n + k)$前処理後のテスト ケースごと |$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 1の数を数えます`o`配列内で。 
2. ゼロの数を次のように計算します。`z = n - o`。 
3. しましょう$$m=\frac{k+1}{2}.$$少なくとも次の部分シーケンス`m`中央値がある`1`。 
4. 階乗および逆階乗モジュロを事前計算する`10^9+7`まで`2·10^5`。 

これにより、すべての組み合わせ値を一定時間で評価できるようになります。 
5. 反復する`i`から`m`に`k`。 
6. それぞれについて`i`、選択されたものの数として解釈します。 
7. 正確に一致する有効な部分列の数`i`等しい$$\binom{o}{i}\binom{z}{k-i}.$$どちらかの組み合わせが不可能な場合は、ゼロとして扱います。 
8. この量を答えのモジュロに加算します`10^9+7`。 
9. 最終的な合計を出力します。 

### なぜ効果があるのか

 バイナリ部分列には中央値があります`1`厳密に言うと、その要素の半分以上が`1`。 以来`k`が奇数である場合、この条件は少なくとも`(k+1)/2`もの。 

すべての有効なサブシーケンスは、正確な番号によって一意に分類できます。`i`含まれるもののうち。 固定の場合`i`、サブシーケンスを選択することは、`i`からの要素`o`利用可能なものと`k-i`からの要素`z`利用可能なゼロ。 これは正確に与えます$$\binom{o}{i}\binom{z}{k-i}$$後続。 

さまざまな値のカテゴリ`i`互いに素であり、中央値が`1`。 全体をまとめると`i ≥ (k+1)/2`は、寄与するすべてのサブシーケンスを 1 回だけカウントします。これがまさに必要な答えです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAXN = 200000

fact = [1] * (MAXN + 1)
for i in range(1, MAXN + 1):
    fact[i] = fact[i - 1] * i % MOD

inv_fact = [1] * (MAXN + 1)
inv_fact[MAXN] = pow(fact[MAXN], MOD - 2, MOD)

for i in range(MAXN, 0, -1):
    inv_fact[i - 1] = inv_fact[i] * i % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

t = int(input())

for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    ones = sum(a)
    zeros = n - ones

    need = (k + 1) // 2

    ans = 0

    for i in range(need, k + 1):
        ans = (ans + C(ones, i) * C(zeros, k - i)) % MOD

    print(ans)
```前処理では階乗と逆階乗が 1 回計算されます。 係数は素数なので、フェルマーの小定理は次のようになります。$$x^{-1}=x^{MOD-2}\pmod{MOD}.$$ヘルパー関数`C(n,r)`組み合わせが不可能な場合は常にゼロを返します。 これは非常に重要です。`C(3,5)`合計には何も寄与してはならない。 

各テスト ケースでは、0 と 1 の数のみが重要です。 要素の実際の配置が式に現れることはありません。 

ループオーバー`i`から始まります`(k+1)//2`これは中央値を次と等しくできる最小の数であるため、`1`。

 ## 特殊なケース

 次のことを考慮してください。```
1
5 1
1 1 1 1 1
```ここ`need = 1`。 合計には次の内容のみが含まれます`i = 1`:$$\binom{5}{1}\binom{0}{0}=5.$$アルゴリズムは戻ります`5`これは、すべての要素が有効なサブシーケンスを形成するという事実と一致します。 

考慮する：```
1
5 5
0 1 0 1 0
```我々は持っています`ones = 2`、`zeros = 3`、 そして`need = 3`。 

どの用語でも少なくとも 3 つを選択する必要がありますが、これは不可能です。$$\binom{2}{3}=0.$$すべての貢献が消滅し、答えが生まれる`0`。 アルゴリズムは、組み合わせ関数を通じてこれを自然に処理します。 

考慮する：```
1
4 3
1 0 1 1
```我々は持っています`ones = 3`、`zeros = 1`、 そして`need = 2`。 

計算は$$\binom{3}{2}\binom{1}{1} + \binom{3}{3}\binom{1}{0} = 3+1 = 4.$$4 つの長さ 3 の部分列すべてが寄与するため、答えは次のようになります。`4`。 これにより、過半数のしきい値が正しく実装されており、すべての有効な構成が正確に 1 回カウントされることが確認されます。
