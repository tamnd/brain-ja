 ## 解決策
 ## 問題の理解

 3 つの独立した壁が与えられ、それぞれが断面高さの配列として記述されます。 各配列には以下が含まれます$n$各整数はその壁のセグメントの高さを表します。 目標は、壁全体の位置を一致させることではなく、3 つの配列すべてに表示される高さの値を見つけることだけです。 このようなすべての共有高さの中で、最大のものを返さなければなりません。 3 つの壁すべてに高さが共有されていない場合、答えは次のようになります。$-1$。 

重要な点は、インデックスではなく値を比較しているということです。 高さは、ウォール マリアに少なくとも 1 回、ウォール ローゼに少なくとも 1 回、ウォール シーナに少なくとも 1 回出現する場合に有効です。 

制約$n \le 10^5$これは、各壁に最大 10 万の値を含めることができ、そのような配列が 3 つあることを意味します。 配列間で直接 2 次または 3 次比較を行うと、おおよその結果が得られます。$10^{10}$2 秒の制限をはるかに超えた最悪のケースでの操作が可能になります。 これにより、3 つの配列のすべての要素間のペアごとのスキャンが直ちに除外されます。 

値自体は次の制限を受けます。$10^5$、これは重要な構造上のヒントです。 これは、固定領域にわたる頻度カウントまたは存在マーキングがおそらく実現可能であることを示唆しています。 

実際には、いくつかの特殊なケースが重要です。 すべての配列内のすべての値が異なる場合、重複はなく、出力は次のようになります。$-1$。 すべての配列に同じ値が含まれている場合、答えは単に存在する最大値になります。 もう 1 つの微妙なケースは、配列内に重複が存在する場合に発生します。 頻度ではなく存在のみを考慮するため、重複は正確さに影響を与えるべきではありません。 

## アプローチ

 ブルートフォースのアイデアは単純です。 最初の壁のすべての値について、それが 2 番目の壁と 3 番目の壁に表示されるかどうかを確認します。 これは、ネストされたループまたは線形検索を使用して実装できます。 

これを単純に行うと、それぞれについて、$n$最初の配列の要素まで、最大でスキャンできます。$n$2 番目と別の要素$n$3番目に。 これは次のことにつながります$O(n^3)$最悪の場合、生のループで実装された場合、または$O(n^2)$リストとリニアスキャンを使用してメンバーシップを事前チェックする場合。 平$O(n^2)$翻訳すると$10^{10}$実行不可能な操作です。 

重要な観察は、要素をペアごとに比較する必要がないということです。 各配列に値が存在するかどうかだけを知る必要があります。 これにより、問題は集合交差問題に変換されます。 各配列がメンバーシップ構造に変換されると、3 つすべてに値が出現するかどうかのチェックが定数時間になります。 

値は次のように制限されているため、$10^5$、ブール周波数配列またはハッシュ セットを使用することもできます。 各壁の存在をマークした後、可能な値の範囲を調べて、3 つすべてに存在する最大値を選択します。 

これにより、繰り返しの検索の問題が、値ドメインにわたる単一の線形スイープに軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^2)$に$O(n^3)$|$O(1)$| 遅すぎる |
 | 存在配列/セット |$O(n + V)$|$O(V)$| 承認済み |

 ここ$V = 10^5$、可能な最大値。 

## アルゴリズムのチュートリアル

 1. 各壁に表示される値を表す 3 つのブール配列 (またはセット) を作成します。 このステップでは、生のリストを高速なメンバーシップ構造に変換するため、存在クエリに一定時間で答えることができます。 
2. ウォール マリアの各高さについて、最初の構造物に存在するものとしてマークします。 私たちは存在だけを気にしているので、繰り返される値は問題ではありません。 
3. ウォール ローゼとウォール シーナにも同じマーキング プロセスを繰り返し、それぞれ 2 番目と 3 番目の構造を埋めます。 
4. から可能なすべての高さを反復処理します。$1$に$10^5$値が 3 つの構造体すべてに存在するとマークされているかどうかを確認します。 すべての有効な高さが指定された境界内に収まる必要があるため、これが機能します。 
5. 3 つのアレイすべての存在を満たす最大値を追跡します。 昇順にスキャンするため、有効な値が見つかった場合は常に答えを上書きすることができます。 
6. スキャン後、値が見つからなかった場合は、戻り値を返します。$-1$それ以外の場合は、記録された最大値を返します。 

### なぜ効果があるのか

 このアルゴリズムは、各ウォールのメンバーシップが独立しており、順序がないという事実に基づいています。 各壁を現在の値のセットに変換することで、問題に必要な情報を正確に保存し、順序や重複などの無関係なものをすべて破棄します。 最終スキャンでは、各候補の高さを 3 つの壁すべての存在の正確な表現と照合してチェックし、報告されたすべての値がすべての配列に実際に表示されることを確認します。 許容範囲内のすべての可能な高さを評価するため、有効な答えが見逃されることはなく、その中で最大値を選択することで正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    m = list(map(int, input().split()))
    r = list(map(int, input().split()))
    s = list(map(int, input().split()))
    
    MAXV = 100000
    
    in_m = [False] * (MAXV + 1)
    in_r = [False] * (MAXV + 1)
    in_s = [False] * (MAXV + 1)
    
    for x in m:
        in_m[x] = True
    for x in r:
        in_r[x] = True
    for x in s:
        in_s[x] = True
    
    ans = -1
    for v in range(1, MAXV + 1):
        if in_m[v] and in_r[v] and in_s[v]:
            ans = v
    
    print(ans)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず 3 つのプレゼンス テーブル (壁ごとに 1 つ) を構築します。 各テーブルは、その壁に高さが存在するかどうかを記録します。 これにより、スキャンの繰り返しが回避され、メンバーシップの定期的なチェックが保証されます。 

最後のループでは、考えられるすべての高さを昇順にスキャンします。 3 つの配列すべてで高さが見つかるたびに、答えが更新されます。 上向きにスキャンするため、最後に記録された値が有効な最大高さになります。 

微妙な点は固定範囲です$1 \le h \le 10^5$。 これにより、一定のサイズの配列を安全に割り当てることができます。$100001$動的境界を気にする必要はありません。
