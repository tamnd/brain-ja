 ## 解決策
 ## 問題の理解

 私たちはスチュワードの強みのリストを与えられ、ジョン・スノウがどのスチュワードをサポートするかを決定する必要があります。 スチュワードは、厳密に小さい強度を持つ少なくとも 1 人のスチュワードと、厳密に大きい強度を持つ少なくとも 1 人のスチュワードが存在する場合にのみサポートされます。 

この条件は、配列内の各位置に独立して適用されます。 サブセットを選択したり値を変更したりするのではなく、要素ごとに、完全なコレクションのどこかで小さい値と大きい値の間に「挟まれている」かどうかを確認しているだけです。 

入力サイズは 100,000 要素に達する可能性があり、各値は 10^9 まで大きくなる可能性があります。 これにより、各要素を他のすべての要素と比較するソリューションは即座に除外されます。 二次アプローチでは、最悪の場合でも 10^10 のオーダーで比較が実行されますが、これは 2 秒の制限に収まる値をはるかに超えています。 

すべての値が同一の場合、微妙なエッジケースが発生します。 その状況では、厳密に小さい隣接要素と厳密に大きい隣接要素の両方を持つ要素は存在しません。 要素はたくさんありますが、条件を満たすものはありません。 もう 1 つの特殊なケースは、異なる値が 2 つだけ存在する場合です。 この場合、より大きな値のみがより小さな近傍を持ち、より小さな値のみがより大きな近傍を持ちますが、両方を同時に満たす要素はありません。 

## アプローチ

 各スチュワードの条件を確認する直接的な方法は、配列全体をスキャンして、小さい値と大きい値を検索することです。 インデックスごとに 2 つのスキャンを実行します。1 つは値が小さいかどうかを検出し、もう 1 つは値が大きいかどうかを検出します。 これは定義内の条件を明示的に検証するため、正しく機能します。 

ただし、これにより合計 O(n^2) 個のチェックが行われることになります。 n が 100,000 までの場合、これはおよそ 10^10 の比較となり、遅すぎます。 

重要な観察は、値の条件が配列内の全体的な極値のみに依存するということです。 値がグローバル最小値より大きい場合、値は厳密に小さい要素のみを持つことができます。 同様に、グローバル最大値よりも小さい場合にのみ、厳密に大きな要素を持つことができます。 これにより、問題は、配列の最小値と最大値の間に厳密に存在する要素を特定することになります。 

最小値と最大値が判明すると、各要素を一定時間で分類できるため、ソリューション全体が 1 回の線形スキャンに減ります。

 ## アルゴリズムのチュートリアル

 「少なくとも 1 つの小さい要素と少なくとも 1 つの大きい要素がある」という条件を、最小値と最大値を使用してグローバルな特徴付けに変換します。 

1. 配列内の最小値を計算します。 これは可能な限り最小の強度を表すため、これに等しい要素は厳密に小さい隣接要素を持つことはできません。 
2. 配列内の最大値を計算します。 これは可能な最大の強度を表すため、これに等しい要素は厳密に大きな隣接要素を持つことはできません。 
3. すべての要素を反復処理し、条件値 > 最小値および値 < 最大値を満たす要素の数を数えます。 これは、小さい要素と大きい要素の両方が配列内のどこかに存在するという要件を直接エンコードします。 
4. カウントを答えとして返します。 

重要な考え方は、小さな要素の存在はグローバル最小値より厳密に大きいことと同等であり、より大きな要素の存在はグローバル最大値より厳密に小さいことと同等であるということです。 これにより、ペアごとの比較が不要になります。 

### なぜ効果があるのか

正確さは、グローバル極値がすべての可能な比較をどのようにエンコードするかによって決まります。 要素が最小値と等しい場合、厳密に小さい要素は配列内のどこにも存在しません。 それが最小値よりも大きい場合、最小値自体がより小さい要素の存在を保証します。 同じ推論が最大値にも対称的に当てはまります。 したがって、両方の不等式を満たすことは、元の条件を満たすこととまったく同じです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    a = list(map(int, input().split()))
    
    mn = min(a)
    mx = max(a)
    
    ans = 0
    for x in a:
        if mn < x < mx:
            ans += 1
    
    print(ans)

if __name__ == "__main__":
    solve()
```この解決策は、配列を読み取り、その最小値と最大値を線形時間で計算することから始まります。 これら 2 つの値は、すべての要素を評価するために必要な唯一のグローバル情報です。 

次に、ループは厳密な不等式に対して各要素をチェックします。 境界要素が確実に除外されるように、条件は mn < x < mx として慎重に記述されます。 よくある間違いは、非厳密な比較を使用することです。これにより、最小値または最大値に等しい要素が誤って含まれてしまいます。 

全体的な構造は意図的にシンプルになっています。負荷の高い計算はすべて 1 つのパスに押し込まれ、分類は要素ごとに一定の時間で行われます。

 ## 特殊なケース

 すべての要素が同一の場合、最小値と最大値は同じ値になります。 この状況では、厳密に等しい範囲の間に数値が存在できないため、条件 mn < x < mx はすべての要素で失敗します。 すべての要素が両方の比較で除外されるため、アルゴリズムは正しくゼロを返します。 

異なる値が 2 つだけある場合、たとえば [1, 1, 1, 5, 5] のような配列では、最小値は 1、最大値は 5 です。1 も 5 も厳密にはそれらの間に存在しないため、やはり要素はカウントされません。 これは、選択された要素が要件の少なくとも 1 つの側面を満たしていないという事実と一致します。 

配列に要素が 1 つだけある場合、最小値と最大値は両方ともその要素と等しく、厳密な不等式により直ちに削除されます。 このアルゴリズムは、特別な処理を行わなくても、当然のことながらゼロを返します。
