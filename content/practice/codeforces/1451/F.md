 ## 解決策
 ## 問題の理解

 この問題は、$n \times m$非負の整数の行列。 プレイヤーはアシシュから始めて交互に動きます。 各移動で、プレイヤーはゼロ以外の値を持つ開始セルを選択し、開始セルの上または左ではない終了セルを選択し、開始セルを正の整数だけ減らし、開始から終了までの最短パスに沿って値を調整する場合があります。 すべてのマスがゼロになるとゲームは終了し、行動できなかったプレイヤーが負けとなります。 

初期行列が与えられた場合、タスクは両方が最適にプレイすると仮定して勝者を予測することです。 入力は複数のテスト ケースで構成され、それぞれが行列の次元と初期行列値を持ちます。 

制約は控えめです:$n, m \le 100$そして$a_{i,j} \le 10^6$、最大 10 個のテスト ケース。 これにより、行列サイズでおよそ最大 2 次時間のアルゴリズムが可能になります。$10^6$制限時間内に快適に走行するための操作。 

明らかではない側面は、動きによって複雑なパス操作が可能であるにもかかわらず、ゲームをより単純な戦略にまとめることができるということです。 分岐要素が膨大であるため、考えられるすべての手を単純にシミュレートすることは不可能です。 エッジ ケースには、すべてが 0 の行列、単一行または単一列の行列、および 1 つのセルのみが非ゼロである行列が含まれます。 このような特殊なケースでは、最初のプレイヤーが移動できるかどうかについて慎重に推論する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、すべての可能な動きをシミュレートし、各ターンでパスと値を調整しようとします。 これは原理的には正しいですが、移動シーケンスの数は行列のサイズとセルの値との組み合わせで増加するため、扱いにくくなります。 

重要な洞察は、このゲームが 2 部グラフ上の古典的な公平なゲーム、特に 2 次元 nim ゲームの変形と同等であるということです。 各移動は事実上 1 行と 1 列を「削除」します (ゼロ以外のセルが選択され、最小パスが四角形に影響するため)。 勝者は、少なくとも 1 つの非ゼロ要素を含む行と列の数を数えることによって決定できます。 これらのカウントの最小値が奇数の場合、最初のプレーヤーは常にその最小セット内のセルをターゲットにすることで強制的に勝利を得ることができます。 互角の場合、2 番目のプレーヤーは勝つために同じ動きをすることができます。 

この削減により、移動のシミュレーションからゼロ以外の行と列のカウントまでの問題が大幅に簡素化されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O(2^(n*m)) | O(n*m) | 遅すぎる |
 | 最適な計数 | O(n*m) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースの寸法を読み取ります。$n$そして$m$そしてマトリックス。 
2. 少なくとも 1 つの非ゼロ要素を含む行の数を数えます。 これは、各行を反復処理し、ゼロ以外のセルをチェックすることで実行できます。 
3. 少なくとも 1 つの非ゼロ要素を含む列の数を数えます。 これは、各列を反復処理し、ゼロ以外のセルをチェックすることで実行できます。 
4. ゼロ以外の行数とゼロ以外の列数の最小値を計算します。 この値は、各移動が一意の行と列の交差をターゲットにすることができる移動の最大数を表します。 
5. この最小値が奇数の場合、アシッシュは最初のプレーヤーとして勝利を強制することができます。 それ以外の場合は、2 番目のプレーヤーである Jeel が Ashish の動きをミラーリングすることで勝つことができます。 
6. Ashish が勝った場合は「Ashish」を出力し、そうでない場合は「Jeel」を出力します。 

機能する理由: ゲーム内の各移動は、1 つのアクティブな行と 1 つのアクティブな列を効果的に削除します。 最後にそのような動きをすることができたプレイヤーが勝ちます。 アクティブな行と列をカウントすることで、最小数に等しいサイズの単一の山を持つ nim のようなシナリオにゲームを縮小します。 これにより、考えられるすべてのパスをシミュレートしなくても正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        matrix = [list(map(int, input().split())) for _ in range(n)]
        
        # count non-zero rows
        rows = sum(1 for row in matrix if any(cell != 0 for cell in row))
        # count non-zero columns
        cols = sum(1 for c in range(m) if any(matrix[r][c] != 0 for r in range(n)))
        
        min_count = min(rows, cols)
        print("Ashish" if min_count % 2 == 1 else "Jeel")

if __name__ == "__main__":
    solve()
```コードの各部分はアルゴリズムのステップに直接対応します。 ゼロ以外の行と列をカウントするのは簡単ですが、off-by-one エラーを避けるために慎重に反復する必要があります。 最小値を取ることで、利用可能な動きの制限要因を確実に把握できます。 パリティ チェックは、勝者を決定することに直接変換されます。

## 特殊なケース

 1 行または 1 列のみがゼロ以外の値を持つ行列の場合、アルゴリズムは最小カウントを 1 として正しく識別します。たとえば、1x5 行列です。`[0,0,0,0,7]`1 つの非ゼロ行と 1 つの非ゼロ列があります。 最小値は 1 であるため、Ashish は最後の非ゼロ セルを削除することで勝ちます。 これは、アルゴリズムがスパース行列を適切に処理していることを示しています。 同様に、完全にゼロの行列の場合、両方のカウントがゼロで、最小値もゼロとなり、最初のプレイヤーは何も動けないため、2 番目のプレイヤーが勝ちます。
