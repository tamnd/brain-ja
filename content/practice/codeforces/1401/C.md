 ## 解決策
 ## 問題の理解

 正の整数の配列が与えられます。 許可される操作は、2 つの要素の最大公約数 (GCD) が配列の最小要素と等しい場合、2 つの要素間のスワップです。 目的は、これらのスワップを使用して配列を非減少順序に再配置できるかどうかを判断することです。 

入力は複数のテスト ケースで構成されます。 各テストケースには長さがあります`n`そして配列`n`整数。 各テスト ケースの出力は、ルールに従って配列を非降順に並べ替えることができる場合は「YES」、それ以外の場合は「NO」になります。 

重要な制約は、以下の合計が`n`すべてのテスト ケースの数は最大 100,000 です。 これにより、スワップを明示的にシミュレートしようとするソリューションは除外されます。これは、テスト ケースごとに最大 O(n^2) の操作が必要になる可能性があり、これでは遅すぎるためです。 

配列がすでに減少していない場合、または最小要素のコピーが複数含まれている場合、微妙なエッジ ケースが発生します。 たとえば、配列が`[2, 2, 3]`、すでに並べ替えられています。 配列が`[3, 6, 2, 9]`の場合、最小値 (2) で割り切れる要素のみを交換できます。 割り算の制限を考慮せずに単純に並べ替えを試みると、誤った「YES」または「NO」が生成されてしまいます。 

もう 1 つの注意が必要なケースは、要素が最小値より小さいにもかかわらず、後で出現する場合です。 考慮する`[4, 6, 2, 5]`。 5 は、ソートされた位置に到達するのに役立つ要素と交換することはできません。`gcd(5, any other number)`が 2 になることはありません。したがって、答えは「NO」でなければなりません。 

## アプローチ

 ブルートフォースアプローチは、考えられる有効なスワップをすべて試すことですが、最大 10^5 の要素があり、スワップの数が O(n^2) になる可能性があるため、これは実行不可能です。 また、スワップが伝播する可能性があるため、確実に終了することは非常に困難です。 

重要な洞察は、最小限の要素が「交換可能なグループ」を定義するということです。 最小値で割り切れる要素は、一連の許可されたスワップを通じて相互に自由に交換できます。 したがって、最小値で割り切れない要素に対してのみ制限が発生します。 これらの要素は、最小値で割り切れない他の要素と比較して、配列内ですでに正しい相対順序になっている必要があります。 

この観察を使用すると、最適なアプローチは次のようになります。 

1. 配列のソートされたバージョンを計算します。 
2. 配列を反復処理し、最小値で割り切れない要素がすでにソートされた位置にあるかどうかを確認します。 そうでない場合、所定の位置に移動することはできず、答えは「いいえ」です。 
3. すべての要素が最小値で割り切れるか、すでにソートされた位置にある場合、最小値を含むスワップを使用して配列をソートできます。 

これにより、問題は単純なスキャンと GCD/可分性チェックに軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O(n^2) | O(n) | 遅すぎる |
 | 並べ替え + 割り算チェック | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`そして配列`a`。 
2. 最小要素を計算する`mn`で`a`。 
3. ソートされたコピーを作成します。`a`、呼んでください`sorted_a`。 
4. 以下のインデックスを反復処理します。`a`。 

1. もし`a[i]`等しい`sorted_a[i]`、 続く。 
2. もし`a[i]`で割り切れます`mn`、自由に移動できます、続行します。 
3. それ以外の場合は、`a[i]`で割り切れない`mn`そして定位置にない。 このテスト ケースでは「NO」を返します。 
5. "NO" を返さずにループが完了した場合は、"YES" を返します。 

これが機能する理由: 不変条件は、最小値で割り切れる要素は、最小値を含む交換の連鎖を通じて任意に交換できるということです。 最小値で割り切れない要素は、それらを移動する有効なスワップがないため、すでに正しい並べ替え位置に存在している必要があります。 これにより、必要な再配置には交換可能な要素のみが含まれ、すべての制限が明示的にチェックされるため、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can_sort(a):
    mn = min(a)
    sorted_a = sorted(a)
    for original, target in zip(a, sorted_a):
        if original != target and original % mn != 0:
            return "NO"
    return "YES"

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        print(can_sort(a))

if __name__ == "__main__":
    main()
```このソリューションでは、まず最小値が計算されます。 ソートされたバージョンがターゲット構成として機能します。 このループにより、正しい場所にない要素は最小値で割り切れる必要があります。 そうしないと、並べ替えが不可能になります。 使用する`zip`クリーンなペアごとの比較が可能になります。 これは並べ替えのためにテスト ケースごとに O(n log n) を使用しますが、制約を考慮すると効率的です。
