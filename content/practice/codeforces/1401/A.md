 ## 問題の理解

 我々に点が与えられる$A$整数直線上の座標に配置$n$。 この点は、移動ごとに 1 単位ずつ左または右に調整できます。 最終的な位置に調整した後$n'$、別の整数点を選択したい$B$原点から距離までの絶対差が同じ線上にある$B$、からの距離$A$に$B$、固定値に等しい$k$。 

より単純な幾何学的用語で言えば、選択すると、$n'$、整数が存在するかどうかを尋ねています。$b$次のような:$$\big||b| - |b - n'|\big| = k$$そのような場合$b$存在する場合、構成は有効です。 そうでなければ、私たちは移動しなければなりません$A$それが可能になるまで、そして最小限の移動数が必要です。 

重要な問題は、妥当性が次の関係にのみ依存することです。$n'$そして$k$、オンではありません$b$直接。 したがって、実際のタスクは、次の値がどのようなものであるかを理解することです。$n'$解決策は存在します。 

制約は大きく、最大で$6000$テストケースとコーディネート$10^6$。 これにより、可能性のある位置をシミュレートするあらゆる試みが即座に除外されます。$B$またはすべての構成を試してください。 テスト ケースごとのリニア スキャンでも、以下に依存する場合は遅すぎます。$n$または$k$。 

よくある失敗例は、式の対称性の誤解から生じます。 たとえば、次のように仮定すると、$b = 0$または$b = n'$問題は誤った結論につながります。$b$の相対的な順序に依存します$0$、$b$、 そして$n'$。 

もう 1 つの微妙な問題は、式を線形として扱うことです。 絶対値の存在により区分的な動作が作成されるため、条件は複数の幾何学的領域に分割されます。 

## アプローチ

 私たちはまず、ブルートフォースのアイデアを理解しようとします。 候補ポジションを確定する$n'$。 次に、考えられるすべての整数値を試します。$b$そして、次のことを確認してください。$$\big||b| - |b - n'|\big| = k$$それぞれについて$b$、これを計算すると定数時間なので、たとえば$n'$これは$O(M)$、 どこ$M$は、考慮される可能な座標の範囲です。 以来$n'$それ自体は最大で変化する可能性があります$10^6$、両方に対する完全な総当たり攻撃$n'$そして$b$のオーダーになります$10^{12}$、それは完全に不可能です。 

重要な観察は、実際には検索する必要がないということです。$b$。 この式は、原点と点に対する距離の不均衡を表します。$n'$、そしてこの構造には既知の簡略化があります。$b$、式は線形形式に崩壊します。 これは、純粋にソリューションが存在する場合の特徴付けにつながります。$n'$そして$k$。 

ジオメトリを分析すると、有効な構成は、配置できるかどうかに依存することがわかります。$n'$と比べて「小さすぎ」ないように$k$。 具体的には、この状態は次のようになります。$$n' \ge k \quad \text{or} \quad n' \equiv k \pmod{2}$$より正確には、標準的な単純化により、最小限の調整は距離にのみ依存することがわかります。$n$セット内の最も近い有効な値からのものです。$$\{x \mid x \ge k \text{ and } x \equiv k \ (\mathrm{mod}\ 2)\}$$これにより、問題は整数直線上の単純な最近点調整に帰着します。 

したがって、探索する代わりに$b$かどうかを確認することに問題を落とし込みます。$n$すでに構造上の制約を満たしている場合は、それを最も近い有効な整数に最小限に移動します。

 ## アルゴリズムのチュートリアル

 正しい解決策は、下限条件とパリティ条件という 2 つの制約から導き出すことができます。 

1.現在位置かどうかを計算します$n$すでに満足しています$n \ge k$。 

存在する場合は、パリティの互換性を確認するだけで済みます。 そうでない場合は、少なくとも次の目標まで上方に移動する必要があることはすでにわかっています。$k$なぜなら、有効な構成には絶対的な違いを実現するために十分な「距離バジェット」が必要だからです。 
2. もし$n < k$、最も近い有効な候補は$k$それ自体なので、答えは単純です$k - n$。 

増えているからです$n$パリティの変更を 1 つずつ保持するため、最短のパスはしきい値に直接移動することになります。 
3. もし$n \ge k$、のパリティを計算します。$n$そしてそれを比較してください$k \mod 2$。 

一致する場合は、適切なものを選択できます$b$それ以上調整しないと、答えは次のようになります。$0$。 
4. パリティが一致しない場合は、以上の値を維持しながらパリティを反転するための追加の手順が 1 つ必要です。$k$。 そのような値に最も近いのは次のいずれかです。$n-1$または$n+1$、両方とも有効な領域に留まります。 したがって、答えは次のとおりです$1$。 

### なぜ効果があるのか

 表現$\big||b| - |b - n|\big|$場所に応じて区分的線形構造を誘発します$b$～に対して嘘をつく$0$そして$n$。 いつ$n$に比べて十分大きい$k$、システムは常に解を許可しますが、パリティ アライメントによって絶対値の対称性が正確に一致する場合に限ります。$k$。 それ以外の場合はシフトする$n$実現可能性を損なうことなくパリティを 1 つずつ切り替えるだけで、パリティの反転は単位ステップでのみ発生するため、これ以上の調整は不可能です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())

    if n < k:
        print(k - n)
    else:
        if (n - k) % 2 == 0:
            print(0)
        else:
            print(1)
```実装は導出された条件に直接に従います。 最初のブランチは次の場合を処理します。$n$は実現可能性のしきい値を下回っているため、線形増加が強制されます。 2 番目のブランチは、パリティ アライメントに依存し、有効かどうかを決定します。$b$すでに構築可能です。 

微妙な点は、$(n - k) \% 2$個別にチェックするのではなく$n \% 2$そして$k \% 2$なぜなら、それらの相対的な同等性のみが重要だからです。 これにより、冗長なロジックが回避され、条件の対称性が維持されます。

# helper: run solution on input string, return output string
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = []
    t = int(sys.stdin.readline())

        n, k = map(int, sys.stdin.readline().split())
        if n < k:
            out.append(str(k - n))
        else:
            out.append(str(0 if (n - k) % 2 == 0 else 1))
    return "\n".join(out)

 ## 特殊なケース

 重要な境界線の 1 つは、次の場合です。$k = 0$。 その場合、条件は点を見つけることになります。$b$そのような$|b| = |b - n|$、これは常に何らかの整数に当てはまります$b$いつ$n$等距離バランスです。 アルゴリズムの下では、$n \ge 0$、パリティを直接チェックします$k = 0$。 もし$n$が偶数であれば、答えはゼロです。 それ以外の場合は、パリティを反転するには 1 回の移動で十分です。 

もう 1 つのエッジケースは次のような場合です$n = 0$。 もし$k > 0$に陥ってしまいます。$n < k$分岐して直接移動$k$。 例えば、$n = 0, k = 1000000$答えが得られます$1000000$、最小実現可能領域に到達する必要性に一致します。 

最後のエッジケースは次のような場合です$n = k$。 パリティ条件が自動的に満たされ、設定がすでに有効な境界上にあるため、アルゴリズムはこれをゼロコストとして扱います。$b$選択することができます。
