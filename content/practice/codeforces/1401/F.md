 ## 解決策
 ## 問題の理解

 長さの配列を扱っています$2^n$、 どこ$n$最大 18 まで指定できるため、配列には最大 18 個まで含めることができます。$262{,}144$要素。 クエリは配列を変更するか、部分配列の合計を要求します。 改造には4種類あります。 1 つ目は要素を直接置き換えます。 2番目、$Reverse(k)$、同じサイズのすべての連続ブロックを反転します。$2^k$。 3番目、$Swap(k)$、サイズの連続したブロックを交換します$2^k$。 4 番目のタイプは、部分配列の合計をクエリします。 

一見すると、リバーサルとスワップを単純に適用するには、$O(2^n)$クエリごとの操作は遅すぎます。$q$まで$10^5$。 すべての操作を文字通りに実装しようとすると、処理を要求される可能性があります。$10^5 \cdot 2^{18} \approx 2.6 \cdot 10^{10}$合理的な時間制限を超えた操作。 したがって、実際に要素を毎回移動させることなく、反転、交換、合計クエリを実行できる配列の表現が必要です。 

複数の反転またはスワップが相互作用する場合、明らかではないエッジケースが発生します。 たとえば、同じブロックを 2 回反転すると、元の順序が復元されます。 異なるレベルでのスワップは、単純ではない方法で配列の順序を変更します。 これらの変換を追跡しない単純なセグメント ツリーでは、複数の操作を行った後に不正確な合計が返されます。 同様に、$Swap(k)$と$k = 0$隣接する要素のみを交換しますが、これは境界が微妙な場合です。 

## アプローチ

 ブルートフォースアプローチでは、配列を明示的に維持します。 あ$Replace(x, k)$単純に設定する$a[x-1] = k$。$Reverse(k)$そして$Swap(k)$すべてを反復処理する$2^n$変換を適用する要素、および$Sum(l, r)$要素を直接合計します。 これは正しいですが遅すぎます。$Reverse(n)$すべてに触れます$2^n$要素。 と$q = 10^5$、このアプローチで達成できるのは、$10^{10}$操作。 

最適なアプローチは、次のような観察に基づいています。$Reverse(k)$そして$Swap(k)$構造化された変換です。 各インデックス$i$配列内の はバイナリで次のように表現できます。$i = b_{n-1}b_{n-2}\dots b_0$。 反転とスワップは、インデックスのビットを反転することに対応します。$Reverse(k)$をひっくり返す$k$各ブロック内の最下位ビット、および$Swap(k)$をひっくり返す$(k+1)$-番目のビット。 したがって、配列を物理的に変更する代わりに、各レベルでどのビットが反転されるかを追跡し、オンデマンドで論理インデックスを物理的な位置にマッピングできます。 このマッピングが明確になると、標準のセグメント ツリーを使用して、実際に要素を移動することなくポイントの更新と範囲の合計を実行できます。 

この観察により、問題は仮想インデックス マッピングを使用したセグメント ツリーの実装に集約されます。 各クエリはマッピングを更新するか (Reverse と Swap の場合)、ツリーにアクセスします (Replace と Sum の場合)。 ビットごとの XOR 演算により、これらのインデックス変換を効率的に実装できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(q・2^n) | O(2^n) | 遅すぎる |
 | 最適 (セグメント ツリー + ビットマスク インデックス マッピング) | O(q・log(2^n)) = O(q・n) | O(2^n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各インデックスを表す$i$配列の$n$-bit の 2 進数。 変数を初期化する`flip_mask = 0`リバースクエリとスワップクエリによって引き起こされるすべてのビット反転を追跡します。 
2. 配列上にセグメント ツリーを構築して、ポイントの更新と範囲合計のクエリをサポートします。 セグメント ツリーはまだフリップについて知る必要はありません。 
3. 取り扱いについて`Replace(x, k)`、XOR 演算により実際の物理インデックスを計算します。`x-1`と`flip_mask`。 その位置のセグメント ツリーを更新します。 
4. 取り扱いについて`Reverse(k)`、裏返します$k$最下位ビット`flip_mask`。 コード内でマスクを計算します`(1 << k) - 1`そしてそれをXORします`flip_mask`。 
5. 取り扱いについて`Swap(k)`、裏返します$(k)$-番目のビット (0 ベース)`flip_mask`。 コード内で計算する`1 << k`そしてそれをXORします`flip_mask`。 
6. 取り扱いについて`Sum(l, r)`セグメント ツリーに直接クエリを実行することはできません。`flip_mask`位置を並べ替えます。 セグメント ツリーを下位に移動する再帰関数を実装します。 各ノードで、現在のレベルのビットが反転されているかどうかを検討します。`flip_mask`。 反転した場合は、再帰中に左と右の子を入れ替えます。 合計を返します`[l, r]`論理インデックスを物理位置にマッピングした後。 
7. すべてのクエリの後、各 Sum クエリは、配列を物理的にシャッフルすることなく、仮想マッピングを使用して正しい結果を返します。 

機能する理由: すべてのリバースまたはスワップは、インデックスの特定のビットを反転することで表現できます。 XOR は独自の逆演算であるため、同じレベルでの複数の反転またはスワップは正しくキャンセルされます。 セグメント ツリーは、基本配列の合計を保持します。 再帰合計クエリは、どの子が現在の論理インデックスに対応するかを正しく解釈します。`flip_mask`。 すべての変更で同じインデックス マッピングが使用されるため、Replace と Sum は一貫して動作し、正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

class SegmentTree:
    def __init__(self, data):
        n = len(data)
        self.N = 1
        while self.N < n:
            self.N <<= 1
        self.data = [0] * (2 * self.N)
        for i in range(n):
            self.data[self.N + i] = data[i]
        for i in range(self.N - 1, 0, -1):
            self.data[i] = self.data[2*i] + self.data[2*i+1]

    def update(self, idx, value):
        idx += self.N
        self.data[idx] = value
        while idx > 1:
            idx >>= 1
            self.data[idx] = self.data[2*idx] + self.data[2*idx+1]

    def query(self, l, r, node=1, nl=0, nr=None, flip_mask=0, level=0):
        if nr is None:
            nr = self.N
        if r <= nl or nr <= l:
            return 0
        if l <= nl and nr <= r:
            return self.data[node]
        mid = (nl + nr) >> 1
        bit = 1 << level
        left_child, right_child = 2*node, 2*node+1
        if flip_mask & bit:
            left_child, right_child = right_child, left_child
        return self.query(l, r, left_child, nl, mid, flip_mask, level+1) + \
               self.query(l, r, right_child, mid, nr, flip_mask, level+1)

n, q = map(int, input().split())
a = list(map(int, input().split()))
st = SegmentTree(a)
flip_mask = 0
for _ in range(q):
    tmp = list(map(int, input().split()))
    if tmp[0] == 1:
        x, k = tmp[1]-1, tmp[2]
        phys = x ^ flip_mask
        st.update(phys, k)
    elif tmp[0] == 2:
        k = tmp[1]
        flip_mask ^= (1 << k) - 1
    elif tmp[0] == 3:
        k = tmp[1]
        flip_mask ^= (1 << k)
    else:
        l, r = tmp[1]-1, tmp[2]-1
        res = st.query(l, r+1, flip_mask=flip_mask)
        print(res)
```このソリューションでは、範囲の合計を維持するために SegmentTree クラスを定義します。 の`flip_mask`すべての反転とスワップをエンコードします。 置換を実行するときは、次の XOR 演算によって物理インデックスを計算します。`flip_mask`。 Sum クエリの場合、再帰では各ツリー レベルで反転されたビットが考慮され、必要に応じて子が交換されます。 リバースおよびスワップ更新の変更`flip_mask`XORを使用します。 XOR を使用すると、反転と交換が簡単に元に戻せ、効率的に構成できるようになります。
