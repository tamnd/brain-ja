 ## 解決策
 ## 問題の理解

 入力は、庭園内の動物の個体数調査を説明します。 最初の行以降の各行には 1 つの種の名前が含まれます。 課題は、ある種の個体数が他のすべての種の個体数を合わせたものよりも厳密に大きいかどうかを見つけることです。 そのような種が存在する場合は、その名前を印刷します。 それ以外の場合は印刷します`NONE`。 

条件はカウントを使用して書き換えることができます。 種族が現れたら`x`間で回`N`動物、他のすべての種が一緒に表示されます`N - x`回。 私たちには、次のような種が必要です。`x > N - x`、これは以下と同等です`2x > N`。 これは、答えが厳密に過半数の種でなければならないことを意味します。 

の限界`N`までである`2 * 10^5`これは、どの動物もわずかな回数しか処理できないことを意味します。 すべての種を他のすべての種と比較するアプローチには、次のようなものが必要になる可能性があります。`N^2`このサイズでは操作が多すぎます。 線形または線形に近い解決策が必要です。 

いくつかのケースでは、誤って処理されやすいものがあります。 最大の種が動物のちょうど半分に出現する場合は、要件が厳しいため十分ではありません。 例えば：```
4
cat
dog
cat
dog
```正しい出力は次のとおりです。```
NONE
```をチェックする不用意な解決策`>=`の代わりに`>`間違って選択してしまうだろう`cat`または`dog`。 

もう 1 つの特殊なケースは、動物が 1 匹しかいない場合です。 反対側のサイズが 0 であるため、唯一の種は他のすべての種を合わせたよりも多く表示されます。```
1
lion
```正しい出力は次のとおりです。```
lion
```少なくとも 2 つの異なる種が存在する必要があると仮定した解決策は、ここでは失敗する可能性があります。 

最後の微妙なケースは、複数の種が存在するが、そのうちの 1 つが閾値をほとんど超えていない場合です。```
5
bird
bird
bird
fish
frog
```正しい出力は次のとおりです。```
bird
```数えられるのは 3 ですが、他のすべての種には 2 匹の動物がいます。 大多数の条件をチェックせずに最も頻度の高い種だけを探すソリューションでは、最大数がまだ十分ではない場合に不正確な答えが生成される可能性があります。 

## アプローチ

 直接的なアプローチは、すべての種を数えてから、それぞれの種を個別にテストすることです。 カウントを構築した後、各種を取得し、そのカウントを他のすべてのカウントの合計と比較できます。 このメソッドは、ステートメントから正確な条件をチェックするため、正しいです。 ただし、すべての候補についてすべての種をスキャンするという不適切な実装が行われた場合、比較の数が動物の数の 2 乗に達する可能性があります。 と`N = 200000`、これは 400 億の操作に近づく可能性がありますが、これは実現不可能です。 

有益な観察は、条件が最大数のみに依存するということです。 ある種に他のすべてを合わせたよりも多くの動物がいる場合、その種は最も頻度の高い種でもあるはずです。 どの種が最大の頻度を持つか、そしてその頻度が次の値より大きいかどうかを知る必要があるだけです。`N / 2`。 

This allows a simple two-pass solution. First, count how many times every species appears. Second, search for a species whose count satisfies`2 * count > N`。 辞書は数え方を効率的に処理し、総作業量は動物の数に比例します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(N^2) | O(N) | 遅すぎる |
 | 最適 | O(N) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての種名を読み取り、ハッシュ マップを使用してその出現数を数えます。 各動物はその種カウンターに正確に 1 つの増分を与えるため、このステップで完全な個体群分布が取得されます。 
2. 動物の総数を次のように保存します。`N`。 頻度のある種の多数条件`c`は`c > N - c`と同じです`2 * c > N`。 
3. 頻度マップを繰り返して、条件を満たす種を見つけます。`2 * count > N`。 2 つの異なる種が両方とも総個体数の半分を超えることはできないため、有効な種を 1 つ見つけるだけで十分です。 
4. 条件を満たす種がない場合、出力`NONE`。 

これが機能する理由: 必要な種の数は、他のすべての種を合わせた数よりも大きくなければなりません。 つまり、その数は全動物の半分よりも多くなければなりません。 アルゴリズムは、正しい頻度を計算した後、すべての種についてこの特性を正確にチェックします。 有効な答えはすべて条件を通過しますが、不等式がまさに必要な多数派の定義であるため、無効な種は条件を通過できません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n_line = input().strip()
    if not n_line:
        return

    n = int(n_line)
    count = {}

    for _ in range(n):
        species = input().strip()
        count[species] = count.get(species, 0) + 1

    for species, freq in count.items():
        if freq * 2 > n:
            print(species)
            return

    print("NONE")

if __name__ == "__main__":
    solve()
```辞書には、種ごとの出現数が保存されます。 Python 辞書は平均一定時間の挿入と検索を行うため、すべての入力行の処理は線形のままです。 

最後のループでは、他の種と比較する必要はありません。 表現`freq * 2 > n`この種が残りのすべての動物を合わせたものよりも大きいかどうかをすでに示しています。 整数の除算による境界の問題を避けるために、除算の代わりに乗算が使用されます。 

整数は必要に応じて自動的に増加するため、Python では整数オーバーフローの心配はありません。 入力読み取り値は次を使用します。`sys.stdin.readline`、行数が多い場合に適しています。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(N) | 各種名が 1 回読み取られ、保存されている各頻度が 1 回チェックされます。 |
 | スペース | O(N) | 最悪の場合、すべての動物が異なる種名を持っているため、辞書には N 個のエントリが保存されます。 |

 最大入力サイズは`200000`動物。 線形パスは利用可能な時間制限に簡単に適合し、辞書のサイズはメモリ制限内に収まります。 

## テストケース```python
import sys
import io

def solution(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    data = sys.stdin.readline
    n = int(data())
    count = {}

    for _ in range(n):
        s = data().strip()
        count[s] = count.get(s, 0) + 1

    ans = "NONE"
    for s, c in count.items():
        if c * 2 > n:
            ans = s
            break

    sys.stdin = old_stdin
    return ans

assert solution("3\nfrog\nfish\nfrog\n") == "frog", "sample 1"
assert solution("4\ncat\nmouse\nmouse\ncat\n") == "NONE", "sample 2"

assert solution("1\nlion\n") == "lion", "single animal"
assert solution("5\na\na\na\nb\nc\n") == "a", "bare majority"
assert solution("6\nx\nx\ny\ny\nz\nz\n") == "NONE", "exact half"
assert solution("200000\n" + "bird\n" * 200000) == "bird", "maximum size all equal"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1`1 つの種の動物 | 写真 1 つの種の動物`lion`| 可能な限り最小の入力を処理します。 |
 | 5 つの動物のうち 1 つの種の 3 つのコピー |`a`| 境界のすぐ上の厳密な過半数をチェックします。 |
 | 数が等しい 3 つの種 |`NONE`| 正確なハーフコンディションをチェックし、防止します。`>=`間違い。 |
 | 20 万種の同一種 |`bird`| 線形アプローチが最大入力サイズを処理することを確認します。 |

 ## 特殊なケース

 ちょうど 2 分の 1 の場合は、乗算チェックによって処理されます。 のために：```
4
cat
dog
cat
dog
```辞書には以下が含まれています`cat: 2`そして`dog: 2`。 アルゴリズムチェック`2 * 2 > 4`これは両方とも false なので、次のように表示されます。`NONE`。 

唯一の頻度が次のとおりであるため、1 匹の動物のケースは機能します。`1`、条件は次のようになります`2 * 1 > 1`、それは本当です。 このアルゴリズムは、特別な処理を必要とせずに種のみを出力します。 

かろうじて多数派のケース:```
5
bird
bird
bird
fish
frog
```生成する`bird: 3`、`fish: 1`、 そして`frog: 1`。 小切手`2 * 3 > 5`成功するので、`bird`が返されます。 アルゴリズムは、他の種の正確な合計を知る必要はありません。これは、大多数の不等式が既にそれを捉えているからです。
