 # 問題の理解

 いくつかの氷山が与えられ、各氷山はその境界上の点の順序付きリストによって記述されます。 点は単純な多角形を形成します。つまり、境界線が交差することはありません。 タスクは、すべてのポリゴンの合計表面積を見つけて、その面積の整数部分 (切り捨てを意味します) を出力することです。 

入力サイズは、ジオメトリ データの総量が少ないという事実に基づいて設計されています。 ポリゴンは最大 1000 個まで存在でき、各ポリゴンには最大 50 個の頂点があるため、頂点の合計数は最大 50000 になります。これにより、頂点のすべてのペアを繰り返し比較したり、大きな座標グリッドをスキャンしたりするアルゴリズムが排除されます。 座標は 10^6 まで大きくなり、単一方向に 10^12 セルのエリアが作成されるため、グリッド ベースのソリューションは不可能です。 目的のソリューションでは、各頂点を一定の回数処理する必要があります。 

主なエッジケースは、ポリゴン領域の表現方法に由来します。 多角形は時計回りまたは反時計回りにリストすることができ、どちらの記述も同じ物理的な氷山を表します。 1 つの方向を想定した不用意な実装は、否定的な答えを生み出す可能性があります。 

例えば：```
1
4
0 0
0 1
1 1
1 0
```正しい出力は次のとおりです。```
1
```ポイントは時計回りに与えられるため、靴紐の式から得られる符号付き面積は負になります。 絶対値を適用せずに値を取得すると、誤って負の結果が生成されます。 

もう 1 つのエッジ ケースは、面積が整数ではない多角形です。```
1
3
0 0
1 0
0 1
```正しい出力は次のとおりです。```
0
```三角形の面積は 0.5 で、必要な操作は小数部分を切り捨てることです。 最も近い整数に丸めると異なる答えが得られるため、実装では正確に 2 倍の領域を維持する必要があります。 

## アプローチ

 簡単なアプローチは、各ポリゴンの内側を直接測定してみることです。 考えられる方法の 1 つは、外接する四角形内のすべての座標のグリッドを作成し、すべてのセルをテストすることです。 これは、座標が平面を定義しているため機能しますが、この問題ではすぐに失敗します。 両方の次元で 0 から 10^6 の範囲にわたるポリゴンでは、約 10^12 個のセルをチェックする必要がありますが、これは許容時間を大幅に超えています。 

より良い幾何学的観察は、ポリゴン領域がその内部の個々の形状に依存しないということです。 境界点には十分な情報が含まれています。 すべての頂点を固定原点に接続すると、多角形を三角形に分割できます。 連続する各頂点ペアの符号付き面積の寄与は、外積を使用して計算されます。 

[
 x_i y_{i+1} - y_i x_{i+1}
 】

 これらの寄与の合計は、多角形の符号付き面積の 2 倍になります。 符号は頂点の順序を示すだけなので、絶対値を取得すると実際の 2 倍の面積が得られます。 

この強引なアプローチは、氷で覆われた領域を直接モデル化するため機能しますが、境界に保存されているはるかに少量の情報は無視されます。 境界点からポリゴン領域を回復できるという観察により、問題は座標サイズに依存するものから頂点の数のみに依存するものに軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(境界ボックスの面積) | O(境界ボックスの面積) | 遅すぎる |
 | 靴紐の公式 | O(頂点の総数) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのポリゴンを読み取り、その頂点を順番に保存します。 靴紐の式では境界付近の隣接する点のペアが使用されるため、順序が重要になります。 
2. 頂点からすべてのエッジに対して`i`頂点へ`i + 1`、外積寄与を追加します。`x_i * y_{i+1} - y_i * x_{i+1}`ポリゴンの 2 倍の符号付き領域に。 
3. ポリゴンの累積値の絶対値を取得します。 これにより、頂点が時計回りに指定されたか反時計回りに指定されたかによる影響が取り除かれます。 
4. すべてのポリゴンの 2 倍の面積をグローバル合計に加算します。 氷山は重なり合わないので、その面積を単純に合計することができます。 
5. 整数除算を使用して、最終的に 2 倍になった領域を 2 で除算します。 これにより、小数部分が削除された必要な値が得られます。 

なぜ効果があるのか:

 靴紐の式は、連続するポリゴン エッジと原点によって形成される三角形の符号付き面積を合計することによって導出されます。 ポリゴン内のすべての三角形は 1 回だけ寄与しますが、原点によって作成された外側の領域は反対の符号によってキャンセルされます。 多角形は単純であるため、結果は正確に多角形の符号付き領域になります。 絶対値を取得すると実面積が得られ、2 倍の面積を合計すると、最終的な切り捨てまで正確さが保たれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n_line = input().strip()
    if not n_line:
        return
    n = int(n_line)

    total_twice = 0

    for _ in range(n):
        p = int(input())
        points = []
        for _ in range(p):
            x, y = map(int, input().split())
            points.append((x, y))

        twice = 0
        for i in range(p):
            x1, y1 = points[i]
            x2, y2 = points[(i + 1) % p]
            twice += x1 * y2 - y1 * x2

        total_twice += abs(twice)

    print(total_twice // 2)

if __name__ == "__main__":
    solve()
```各氷山は独立しているため、入力はポリゴンごとに処理されます。 最後のエッジを計算するときに最後の頂点が最初の頂点に接続し直さなければならないため、頂点のリストは一時的に保存されます。 

エッジ上のループは次を使用します。`(i + 1) % p`多角形の閉じ側を処理します。 モジュロ演算を行わないと、最後のポイントから最初のポイントに戻るエッジが失われ、これが誤答の一般的な原因となります。 

計算は浮動小数点数の代わりに 2 倍の面積で実行されます。 すべての座標は整数であるため、すべての靴紐の寄与も整数です。 この値を正確に保つと精度エラーが回避され、最終的なフロア演算は単なる整数の除算になります。 

Python の整数は、固定マシン サイズを超えて自動的に増加します。外積の合計が約 10^16 になる可能性があるため、これはここでは役に立ちます。

 ## 特殊なケース

 時計回りのポリゴンは、反時計回りのポリゴンと同じ物理的な氷山を生成しますが、靴紐の合計の符号が変わります。 入力の場合:```
1
4
0 0
0 1
1 1
1 0
```累積された2倍の面積は`-2`。 アルゴリズムはそれを次のように変換します`2`答えに追加する前に、正しい出力を生成します`1`。 

端数の面積を持つ多角形は丸めてはいけません。 のために：```
1
3
0 0
1 0
0 1
```2倍の面積は`1`、したがって、整数除算は次のようになります`1 // 2 = 0`。 アルゴリズムは、必要なフロアの動作に正確に従います。 

多角形の最後のエッジも微妙なケースです。 のために：```
1
3
0 0
2 0
0 2
```最後のエッジはからです`(0,2)`に戻る`(0,0)`。 モジュロ演算にはこのエッジが含まれており、面積が 2 倍になります。`4`そして出力`2`。 このエッジを省略すると、リストされたすべてのポイントが処理されたとしても、間違った結果が生成されます。
