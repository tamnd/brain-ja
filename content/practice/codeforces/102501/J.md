 ## 解決策
 ## 問題の理解

 入力は、木の高さの順序リストです。 考えられるあらゆる種類は、左から右に読むと、ノードがまさにこの一連の高さを持つ 1 つの二分木に対応します。 すべてのノードの親の高さはその子よりも大きくてはなりません。そのため、間隔内の最小の高さはその間隔のルートに配置される必要があります。 

タスクは、これらの規則を満たすさまざまな二分木の形状がいくつあるかを数えるということです。 高さが同じであることが、曖昧さの唯一の原因です。 間隔の最小値が複数回出現する場合、それらの位置のいずれかがルートとなり、複数の可能な構造が作成される可能性があります。 

シーケンスの長さは 100 万に達する可能性があるため、区間動的計画法によるソリューションは不可能です。 すべてのサブ配列を反復するには、2 次またはそれよりも悪い作業が必要になりますが、これは 2 秒の制限をはるかに超えています。 アルゴリズムは各位置を一定の回数だけ処理する必要があります。 

主なエッジ ケースは、すべての値が等しいシーケンスです。 例えば：```
3
5
5
5
```答えは`5`3 つのノードは任意のバイナリ ツリー形状を形成できるためです。 最小位置が一意であると仮定するソリューションでは、誤って最小位置が返されます。 

もう 1 つの重要なケースは、分離された等しい最小値です。```
3
1
2
1
```答えは`2`。 高さの 2 つのノード`1`他のものの左または右の子として配置できます。 等しい値を独立した最小値として扱うと、この相互作用が見逃されてしまいます。 

## アプローチ

 直接再帰的な解決策は定義に従います。 間隔の場合、最小値を見つけ、その最小値が出現するたびにルートとして試行し、残りの 2 つの間隔の答えを掛け合わせます。 これは正しいです。すべての有効なツリーには、その区間のルート位置が 1 つだけ存在するからです。 

問題は、等しい値の配列が最悪の再帰を引き起こすことです。 長さについて`n`、状態の数は二次関数であり、すべての最小位置を試すと別の要素が追加されます。 最悪の場合、許容される操作数を大幅に超えてしまいます。 

重要な観察は、等しい最小値がグループとして動作するということです。 区間の最小の高さが現れると仮定します。`k`回。 それらの`k`ノードは任意のバイナリ ツリーのノードを形成しますが、ノード間のギャップにはより大きな値のみが含まれており、独立して解決できます。 アレンジ方法の数は、`k`最小ノード数は`k`カタルーニャ語の番号。 

残りの問題は、これらのグループを効率的に見つけることです。 最小デカルト ツリーは、必要な分解を正確に提供します。 単調なスタックで構築します。 値が等しい場合、左端の最小値を親として保持することによってタイが解決され、等しい最小値ノードが右のチェーンに表示されます。 このようなチェーンはすべて、1 つのカタルーニャ語因子に対応します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n^2) | 遅すぎる |
 | デカルト ツリー | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. シーケンスから最小のデカルト ツリーを構築します。 このツリーの順序トラバーサルは元のシーケンスであり、各ノードはその子よりも大きくありません。 単調なスタック構造により線形時間が保証されます。 
2. カタルーニャ語数を最大で事前計算します。`N`。 チェーンに含まれている場合`k`最小ノードが等しい場合、その寄与は`Catalan(k)`。 
3. デカルト ツリーを下から上にたどります。 ノードを処理するときは、値が等しい間は右側の子に従います。 これにより、等しい最小ノードの完全なグループが得られます。 
4. そのチェーンにぶら下がっているすべての左のサブツリーの答えを掛け、チェーンの後のサブツリーの答えを掛け、そしてチェーンの長さのカタロニア数を掛けます。 
5. 根に対して保存されている答えは、有効な品種の数です。 

不変条件は、処理されたすべてのデカルト サブツリーが元のシーケンスの 1 つの連続した間隔を表すということです。 その間隔のルートはその最小値です。 等しい最小ノードはルート グループの選択肢を正確に形成し、残りの子間隔はすべて独立しているため、これらの寄与を乗算すると、すべての有効なツリーが 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def solve():
    n = int(input())
    a = [int(input()) for _ in range(n)]

    if n == 0:
        print(1)
        return

    cat = [0] * (n + 1)
    cat[0] = 1
    for i in range(1, n + 1):
        s = 0
        for j in range(i):
            s = (s + cat[j] * cat[i - 1 - j]) % MOD
        cat[i] = s

    left = [-1] * n
    right = [-1] * n
    stack = []

    for i in range(n):
        last = -1
        while stack and a[stack[-1]] > a[i]:
            last = stack.pop()
        if stack:
            right[stack[-1]] = i
        if last != -1:
            left[i] = last
        stack.append(i)

    root = stack[0]

    ans = [0] * n
    group = [0] * n

    order = [(root, 0)]
    while order:
        u, state = order.pop()
        if state == 0:
            k = 0
            v = u
            while v != -1 and a[v] == a[u]:
                k += 1
                v = right[v]
            group[u] = k
            order.append((u, 1))

            v = u
            while v != -1 and a[v] == a[u]:
                if left[v] != -1:
                    order.append((left[v], 0))
                v = right[v]
            if v != -1:
                order.append((v, 0))
        else:
            res = cat[group[u]]
            v = u
            while v != -1 and a[v] == a[u]:
                if left[v] != -1:
                    res = res * ans[left[v]] % MOD
                v = right[v]
            if v != -1:
                res = res * ans[v] % MOD
            ans[u] = res

    print(ans[root] % MOD)

if __name__ == "__main__":
    solve()
```デカルト ツリー構造では、現在の右スパインを含むスタックが使用されます。 小さい値が到着すると、大きいノードが削除され、新しいノードの左側のサブツリーになります。 等しい値は削除されないため、左端の等しい最小値は後の等しい値の上に残ります。 

ツリーの深さは 100 万であるため、動的走査は反復的です。 最初の訪問では、等値チェーンを発見し、すべての独立したサブツリーをスケジュールします。 2 回目の訪問では、すでに計算された回答が結合されます。 

カタロニア語の計算では、標準の再帰法が使用されます。`C[n] = sum(C[i] * C[n - 1 - i])`どこ`C[0] = 1`。 これは、次から作成できるバイナリ ツリーの数と一致します。`n`ノード。
