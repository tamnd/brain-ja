 ## 解決策
 ## 問題の理解

 主人公はポイントから始まります`A`、ポイントまで乗ります`B`、その後ポイントに向かって続行する必要があります`C`。 時点で`B`、彼はからの方向を向いています。`A`に`B`。 に達するかどうかを判断する必要があります`C`左折、右折、または直進する必要があります。 

ジオメトリ制約により、問題が大幅に単純化されます。 道路は平行、同一直線上、または直交することが保証されています。 つまり、からの動き`B`に`C`と同じ方向のいずれかです`A -> B`、まったく反対の方向、または正確に 90 度回転します。 このステートメントはさらに、3 つの点すべてが同一線上にあるか、角度があることを保証します。`ABC`は直角です。 

座標は次のように大きくできます。`10^9`、ポジティブとネガティブの両方。 これにより、グリッド、シミュレーション、または浮動小数点ジオメトリを含むアプローチは除外されます。 座標に対していくつかの算術演算が必要なだけなので、`O(1)`解決策が自然な目標です。 

よくある間違いは、向きの方向を混同することです。 主人公が立っているのは、`B`背を向けながら`A`したがって、関連する方向ベクトルは次のようになります。```
AB = B - A
```そしてそうではありません`BA = A - B`。 

例えば：```
A = (0, 0)
B = (0, 1)
C = (1, 1)
```主人公は上に向かって移動します`A`に`B`。 到達するには`C`、彼は右に曲がらなければなりません。 逆ベクトルを使用すると、誤って生成されます。`LEFT`。 

もう 1 つの簡単な間違いは直線の場合に現れます。 

例：```
A = (0, 0)
B = (1, 0)
C = (2, 0)
```正しい答えは次のとおりです。```
TOWARDS
```外積の符号のみをチェックする不注意な実装では、外積がゼロであるためにこれを誤って分類する可能性があります。 共線性のケースを明示的に個別に処理する必要があります。 

負の座標も符号エラーを引き起こす可能性があります。 

例：```
A = (0, 0)
B = (-1, 0)
C = (-1, -1)
```主人公は左に移動し、次に下に移動します。 それは右折ではなく左折です。 負の軸では視覚的な直観が難しくなるため、頭でケースを描くよりも方向の公式に依存する方が安全です。 

## アプローチ

 この問題を解決する強引な方法は、ヒーローの方向を明示的にモデル化し、それを可能なすべての有効な動きと比較することです。 移動ルールでは直進、左折、または右折のみが許可されているため、次から方向ベクトルを構築できます。`A`に`B`、手動で両方向に回転し、各結果をからのベクトルと比較します。`B`に`C`。 

たとえば、主人公がベクトルで移動する場合`(dx, dy)`、 それから：```
Left rotation  = (-dy, dx)
Right rotation = (dy, -dx)
```比較することができました`BC`これらの変換されたベクトルに対して答えを決定します。 この問題ではこれら 3 つの可能性のみが保証されているため、これは正しく機能します。 

ブルートフォース手法はすでに定数時間であるため、パフォーマンスの問題はありません。 それでも、幾何学的変換と共線性のための特殊なケースを手動で処理することに依存しています。 

もっと明確な観察は、これがまさに計算幾何学による標準的な方向テストであるということです。 2 つのベクトルが与えられると:```
u = AB
v = BC
```それらの 2D 外積により、回転方向がわかります。```
cross = ux * vy - uy * vx
```外積が正の場合、からの回転は`u`に`v`は反時計回り、つまり左折を意味します。 

負の場合、回転は時計回り、つまり右折を意味します。 

ゼロの場合、ベクトルは同一線上にあるため、主人公はまっすぐ進み続けます。 

これにより、問題全体が 1 つの算術式に縮小されます。

 ## アルゴリズムのチュートリアル

 1. 点の座標を読み取る`A`、`B`、 そして`C`。 
2. 以下から方向ベクトルを構築します。`A`に`B`。```
AB = (xb - xa, yb - ya)
```これは主人公が現在向いている方向を表します。 

1. 以下から方向ベクトルを構築します。`B`に`C`。```
BC = (xc - xb, yc - yb)
```これは主人公が次に進みたい方向を表します。 

1. 2D 外積を計算します。```
cross = AB.x * BC.y - AB.y * BC.x
```この値の符号によって、2 つのベクトル間の方向が決まります。 

1. もし`cross > 0`、印刷`"LEFT"`。 

正の外積は、からの回転を意味します。`AB`に`BC`は反時計回りです。 

1. もし`cross < 0`、印刷`"RIGHT"`。 

負の外積は、回転が時計回りであることを意味します。 

1. それ以外の場合は、印刷します`"TOWARDS"`。 

ゼロクロス積は、両方のベクトルが同じ線上にあることを意味します。 

### なぜ効果があるのか

 外積は、2D ジオメトリの符号付き面積と方向を測定します。 ベクターの場合`u`そして`v`、次の兆候:```
u.x * v.y - u.y * v.x
```から回転するかどうかを示します`u`に`v`反時計回りまたは時計回りに進みます。 

主人公の現在の向いている方向はまさにベクトルです`AB`、そして望ましい次の方向は`BC`。 この問題は左折、右折、直進のみを保証しているため、外積によって完全に正解が決まります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

xa, ya = map(int, input().split())
xb, yb = map(int, input().split())
xc, yc = map(int, input().split())

abx = xb - xa
aby = yb - ya

bcx = xc - xb
bcy = yc - yb

cross = abx * bcy - aby * bcx

if cross > 0:
    print("LEFT")
elif cross < 0:
    print("RIGHT")
else:
    print("TOWARDS")
```コードの最初の部分は 3 つの点を読み取り、それらを方向ベクトルに変換します。 ターンは位置ではなく相対的な動きに依存するため、絶対座標の代わりにベクトルを使用することが重要な幾何学的ステップです。 

外積計算はソリューションの中心です。```
cross = abx * bcy - aby * bcx
```順序が重要です。 ベクトルを交換すると、符号が反転し、答えの左右が反転します。 

Python の整数は非常に大きな値を自動的に処理するため、それに近い座標`10^9`安全です。 C++ などの言語では、`long long`製品が約`10^18`。 

最後の条件は、方向を必要な出力に直接マップします。 共線ベクトルは左折でも右折でもないため、ゼロは個別にチェックする必要があります。

# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    xa, ya = map(int, input().split())
    xb, yb = map(int, input().split())
    xc, yc = map(int, input().split())

    abx = xb - xa
    aby = yb - ya

    bcx = xc - xb
    bcy = yc - yb

    cross = abx * bcy - aby * bcx

    if cross > 0:
        print("LEFT")
    elif cross < 0:
        print("RIGHT")
    else:
        print("TOWARDS")

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output.strip()
