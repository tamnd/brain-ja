 ## 解決策
 ## 問題の理解

 説明されている構造は、配列形式に埋め込まれたルート付きバイナリ ツリーです。 各ノードには次のラベルが付けられます$1$に$N$、各ノードは最大 2 つの子、左の子と右の子を指すことができます。 の値$0$対応する子が存在しないことを意味します。 ノード$1$左側のルートソースに接続され、ノード$2$が右側に接続されているため、これら 2 つは構造の最初の分岐になります。 

子のないノードのみが意味のあるエンドポイントとみなされます。 このような各エンドポイントには深さがあり、ルート ソースからそのノードまでのエッジの数として定義されます。 その深さをアルファベットに変換すると、$1 \mapsto A$、$2 \mapsto B$、 等々。 

最終出力は、すべてのエンドポイント ノードを厳密な走査順序でリストすることによって形成されます。 トラバーサルは標準的な事前順序または順序ではありません。 代わりに、すべての左側のサブツリーが最初にそのすべての葉を提供し、次に右側のサブツリーがそのすべての葉を提供し、各サブツリー内で同じルールが再帰的に繰り返されます。 

制約により、最大で$10^5$ノード。 これにより、トラバーサルの二次シミュレーションやサブツリーの再計算の繰り返しは時間制限を数桁超えてしまうため、線形または線形に近い解決策が強制されます。 

ルートから繰り返し DFS を使用して各リーフの深さを独立して計算しようとすると、微妙な問題が発生します。 このアプローチではパスが繰り返し再計算され、次のように縮退します。$O(N^2)$歪んだ木々の中で。 

別の失敗例は、リーフの順序どおりの走査が必要な順序と一致すると仮定した場合に発生します。 順序付けの制約は、左右のサブツリー間で対称ではありません。 これは、すべてのノードにおける「すべての左側の葉がすべての右側の葉の前にある」という厳密なルールであり、標準の順序動作よりも強力です。 

## アプローチ

 直接解釈では、ツリーが構築され、深さを保持するルートから DFS が実行されます。 リーフに到達するたびに、現在の深さが文字に変換され、結果に追加されます。 これは正しいです。根から葉までの一意のパスに沿って深さが蓄積されるからです。 常に右の子の前に左の子を探索することによって、走査順序を自然に強制できます。 

非効率性は、実装が深さを再計算するか、サブツリーを繰り返しスキャンする場合にのみ現れます。 正しい DFS は各ノードを 1 回訪問するため、合計の作業量は直線的になります。 

重要な観察は、必要な順序付けは、出力がリーフでのみ発生するという制約を伴う、まさに事前順序トラバーサルであるということです。 これにより、後処理や並べ替えの必要がなくなります。

 ## アルゴリズムのチュートリアル

 1. 各ノードがその左と右の子を格納する隣接表現を構築します。 これは入力構造と直接一致し、一定時間のナビゲーションを可能にします。 
2. ルートを暗黙的にノードとして識別する$1$これは電源からのエントリ ポイントとして定義されているためです。 
3. ノードから開始して深さ優先トラバーサルを実行します。$1$初期深さあり$1$、ルートからの最初のエッジが 1 レベル下の深さに寄与するためです。 
4. ノードにアクセスするときは、まずその左側の子が存在する場合は再帰的に走査します。 これにより、左側のサブツリーのすべてのリーフが右側のサブツリーのリーフより前に出現する必要があるという、必要な順序付けの制約が強制されます。 
5. 左側のサブツリーを終了した後、右側の子が存在する場合はそれを再帰的に走査します。 これにより、出力シーケンスの正しい辞書編集構造が、アルファベット順ではなく走査順に保証されます。 
6. ノードに子がない場合は、ノードをリーフとして扱い、その深さに対応する文字を出力文字列に追加します。 
7. ASCII オフセット、マッピングを使用して深度を文字に変換します。$1$「A」に、$2$「B」などに。 

### なぜ効果があるのか

 各ノードは、サブツリーの順序付けの再帰的定義を尊重する走査で 1 回だけ訪問されます。 すべての葉は根から正確に 1 つの経路を通って到達するため、その深さは訪問した瞬間に一意に決定されます。 強制的に左から右への再帰により、連結順序が問題の読み取り葉の定義と一致することが保証されます。 並べ替えやグローバルな並べ替えは必要ないため、トラバーサル出力は完全かつ正確に順序付けされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(200000)

N = int(input())
left = [0] * (N + 1)
right = [0] * (N + 1)

for i in range(1, N + 1):
    l, r = map(int, input().split())
    left[i] = l
    right[i] = r

res = []

def dfs(node, depth):
    if node == 0:
        return
    if left[node] == 0 and right[node] == 0:
        res.append(chr(ord('A') + depth - 1))
        return
    dfs(left[node], depth + 1)
    dfs(right[node], depth + 1)

dfs(1, 1)

print("".join(res))
```この実装は、トラバーサル構造を直接反映しています。 配列`left`そして`right`各再帰呼び出しが定数時間になるように子を格納します。 再帰の深さは木の高さに対応し、`sys.setrecursionlimit`最悪の場合のスキューチェーンにおけるスタックオーバーフローを防ぎます。 リーフの検出は、両方の子が存在しないことをチェックして、終端ノードのみが文字に寄与することを確認することによって行われます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    sys.setrecursionlimit(200000)

    N = int(input())
    left = [0] * (N + 1)
    right = [0] * (N + 1)

    for i in range(1, N + 1):
        l, r = map(int, input().split())
        left[i] = l
        right[i] = r

    res = []

    def dfs(node, depth):
        if node == 0:
            return
        if left[node] == 0 and right[node] == 0:
            res.append(chr(ord('A') + depth - 1))
            return
        dfs(left[node], depth + 1)
        dfs(right[node], depth + 1)

    dfs(1, 1)
    return "".join(res)

assert run("""5

0 0
0 0
0 5
0 0
""") == "BCA"

# single leaf chain
assert run("""3

0 0
""") == "ABC"

# full binary root
assert run("""1
0 0
""") == "A"

# skewed right tree

0 0
""") == "ABCD"

 ## 特殊なケース

 完全に歪んだツリーは再帰の深さを強調します。 深さは単一のチェーンに沿って増加するため、DFS は依然として各ノードを 1 回訪問し、正しい深さを生成します。 

右の子のみが存在するツリーでは、左のサブツリーが存在しない場合でも、トラバーサルが順序付けルールを遵守していることが検証されます。 再帰では、出力シーケンスに影響を与えることなく、空の左分岐を単純にスキップします。 

単一ノード ツリーでは、ルートが同時にリーフであり、再帰なしで即座に文字を生成する必要があるため、基本ケースが正しいことが保証されます。
