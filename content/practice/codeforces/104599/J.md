 ## 問題の理解

 数直線上に配置されたロボット グループのセットが与えられます。 各グループには位置と、その位置に座るロボットの数があります。 複数のグループが同じ座標を共有する場合、それらの寄与は同一であり、集約できるため、それらは効果的に 1 つの大きなグループにマージされます。 

結合後、概念的には、線上に重み付けされた点ができます。 整数の位置を選択できます$Y$それは既存のロボットの位置と等しくありません。 一度$Y$が固定されている場合、すべてのロボットを 2 つの側面に分割します。厳密に左側のロボットです。$Y$そして厳密に右側のもの$Y$。 各辺について、合計距離を計算します。$Y$多重性を考慮して、その側のすべてのロボットに適用されます。 

ここで注目する値は、左距離の合計と右距離の合計の間の絶対差です。 タスクは有効な整数を選択することです$Y$この値を最小化します。 

制約により、最大で$10^5$までのグループと座標$10^9$したがって、すべての可能な位置をチェックすることに依存するアプローチは、$Y$すぐには実行不可能です。 すべての座標またはそれらの間のすべての整数ギャップを反復処理する場合でも、各ステップが定数時間であり、ステップの合計数が線形のままでない限り、受け入れられません。 

したがって、解決策は、すべての整数の列挙ではなく、構造から導出される少数の候補位置に問題を削減する必要があります。 

素朴な推論を打ち破る重要なエッジケースが 2 つあります。 まず、すべてのロボットが 1 つの座標に集中している場合、有効なすべてのロボットが$Y$はその点から離れており、対称引数は定数式に崩壊します。 たとえば、次のように入力します。```
1
10 5
```どれでも$Y \neq 10$次と等しい差が生じます$5 \cdot |Y-10|$、最小値は次のとおりです。$Y=9$または$Y=11$、答えを与える$5$。 誤って許可する素朴なアプローチ$Y=10$ゼロを出力しますが、これは無効です。$Y$すべてとは異なっていなければなりません$X_i$。 

第二に、グループがまばらに分散している場合、最適な$Y$多くの場合、2 つの連続した占有座標上ではなく、その間にあります。 既存の座標のみを評価するメソッドでは、有効な最適化がすべて失われます。 

## アプローチ

 直接的なアプローチは、すべての有効な整数を試すことです。$Y$どれとも等しくない$X_i$、各候補について、左と右への重み付き距離の合計という 2 つの合計を計算します。 各計算にはすべてのグループをスキャンする必要があるため、総コストは次のようになります。$O(N^2)$最悪の場合、密集した座標範囲を考慮すると、 候補を座標範囲に制限しても、依然として課題は残っています$10^9$可能性、それは不可能です。 

式の構造が鍵となります。 固定の場合$Y$、位置にあるすべてのロボット$x$どちらかに貢献する$A_i (Y-x)$もし$x < Y$、 または$A_i (x-Y)$もし$x > Y$。 両辺を展開すると、目的が次の線形項から構築されていることがわかります。$Y$、点が左側にあるか右側にあるかによって分割されます。$Y$。 これにより、ロボットの位置でのみ傾きが変化する区分的線形関数が作成されます。 

任意の 2 つの連続した別個の座標間では、各側のロボットのセットは変化しないため、式は次の線形関数になります。$Y$。 線形関数は、端点の 1 つでセグメント上で最小値に達します。 選ぶことを禁じられているので、$Y = X_i$、可能な最適な場所は既存の座標のすぐ隣だけです。 

これにより、ソートされた個別の座標間のギャップのみを考慮するように問題が軽減されます。 ギャップごとに評価します$Y = X_i + 1$または同等の、厳密に次の範囲にある任意の整数$X_i$そして$X_{i+1}$。 この値は、重みと重み付けされた位置のプレフィックス合計を使用して効率的に計算できます。

 ## アルゴリズムのチュートリアル

 重みを合計することで重複した座標を圧縮し、各位置が 1 回表示されるようにします。 次に、結果のペアを座標で並べ替えます。 

1. すべてのグループを位置で並べ替え、重みを合計して重複をマージします。 これにより、各座標が 1 回だけ寄与することが保証され、同一の位置を個別に推論する必要がなくなるため、プレフィックスの計算が簡素化されます。 
2. 重みと重み付けされた位置に基づいてプレフィックスの合計を計算します。 保守します$W[i]$インデックスまでのロボット全体として$i$、 そして$S[i]$合計として$x \cdot a$インデックスまで$i$。 これらにより、任意の分割ポイントの左右の寄与を高速に計算できます。 
3. 連続する座標間のギャップごとに、次の配置を検討します。$Y$厳密にそれらの間のどこでも。 コストの式は、プレフィックス配列から抽出できるギャップの左右に何台のロボットが存在するかによってのみ決まります。 
4. すべての隣接するペア間の境界におけるコストを評価します。 実際には、次のように値を計算します。$Y$の無限小右にあります$X_i$、これは最大のプレフィックスを使用することに対応します。$i$左側が残り、右側が残りです。 
5. このようなすべての分割位置の最小値を取得します。 

境界のみを評価することが機能する理由は、2 つの連続する座標間の任意の間隔内では、左セットと右セットの両方が変化しないため、関数は線形であるためです。$Y$内部最小値を持つことはできません。 

### なぜ効果があるのか

 並べ替え後の任意の有効な位置$Y$ラインを 2 つの固定インデックス セット (座標が以下のもの) に分割します。$Y$そしてそれ以上のもの$Y$。 連続する個別の座標間のどの間隔内でも、このパーティションは変化しません。 目的関数は次の線形関数になります。$Y$各区間内で線形関数は終点で最小値に達します。 端点は禁止された座標と一致するため、最適な有効位置はそれらの座標に直接隣接する整数点であり、並べ替えられた位置間の各分割の評価に対応します。 これにより、チェックされた候補以外に、より良い解決策が存在しないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = {}

    for _ in range(n):
        x, a = map(int, input().split())
        pts[x] = pts.get(x, 0) + a

    arr = sorted(pts.items())

    m = len(arr)
    x = [0] * m
    w = [0] * m

    for i, (xi, wi) in enumerate(arr):
        x[i] = xi
        w[i] = wi

    prefix_w = [0] * (m + 1)
    prefix_sw = [0] * (m + 1)

    for i in range(m):
        prefix_w[i + 1] = prefix_w[i] + w[i]
        prefix_sw[i + 1] = prefix_sw[i] + x[i] * w[i]

    total_w = prefix_w[m]
    total_sw = prefix_sw[m]

    ans = float('inf')

    for i in range(m - 1):
        left_w = prefix_w[i + 1]
        left_sw = prefix_sw[i + 1]

        right_w = total_w - left_w
        right_sw = total_sw - left_sw

        left_cost = left_w * x[i] - left_sw
        right_cost = right_sw - right_w * x[i]

        ans = min(ans, abs(left_cost - right_cost))

    print(ans)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず辞書を使用して同一の座標をマージし、各位置が単一の重みに寄与するようにします。 ソートは、接頭辞の合計が数直線上の連続した間隔に対応していることを確認するために必要です。 

プレフィックス配列には、累積重みと累積重み付け位置が格納されます。 これらにより、分割ごとに左側と右側の寄与を一定時間で計算できます。 

間の分割ごとに$i$そして$i+1$、分割を次のように扱います。$Y$のすぐ右側にあります$x[i]$。 この選択は、有効なあらゆるものを正確にモデル化します。$Y$合間に。 左のコストは、からの合計距離として計算されます。$x[i]$左側のすべてのポイントに適用され、右側も同様です。 絶対差を取得すると、その領域の客観的な値が得られます。
