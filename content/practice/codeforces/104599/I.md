 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、根を張った木です。$n$ノード。 各ノード$i$正の値を持ちます$a_i$。 構造はすでにツリーになっているため、正確に$n-1$エッジ、それぞれが暗黙的に重みを持っています$1$。 この構造の上に、任意の 2 つの異なるノード間に新しいエッジを 1 つだけ追加することができます。$u$そして$v$。 

ツリーでは任意の 2 つのノード間に一意のパスがあるため、このエッジを追加すると 1 つの単純なサイクルが作成されます。 そのサイクルは、次の間の元のパスで構成されます。$u$そして$v$、新しいエッジをプラス$(u,v)$。 サイクルの合計「爆発の大きさ」は、そのサイクル上のすべてのエッジの重みの合計として定義されます。 あらゆるオリジナルのエッジが貢献します$1$、追加されたエッジが貢献します$a_u + a_v$。 

したがって、間の距離が$u$そして$v$木の中には$\text{dist}(u,v)$、その結果生じる爆発は次のようになります。$$\text{dist}(u,v) + (a_u + a_v).$$課題は最適なペアを選択することです$(u,v)$この値を最大化します。 

制約により、最大で$10^5$これにより、すべてのペアを明示的に検査するソリューションは除外されます。 ナイーブ$O(n^2)$ペアのスキャンには約$10^{10}$これは 1 秒の制限をはるかに超えています。 ペアごとに BFS または LCA を実行するアプローチでも、慎重に削減しない限り遅すぎます。 

重要な構造上の制約は、ツリーが親ポインターを介して与えられることです。これは、ツリーをルート形式で処理し、深さと構造集約を効率的に計算できることを意味します。 

いくつかの特殊なケースでは、典型的な間違いが明らかになります。 もしすべてなら$a_i$が等しい場合、問題は最大化に帰着します。$a_u + a_v + \text{dist}(u,v)$したがって、最適なペアは単純に直径エンドポイントのペアになります。 たとえば、長さ 3 のチェーンでは、$a_i = 1$、答えは$2 + 2 = 4$プラス距離$2$、 合計$6$。 隣接するノードのみを考慮する単純なアプローチでは、これを見逃してしまいます。 

もう 1 つのエッジ ケースは、最大規模の場合です。$a_i$はリーフ内に存在し、それを近くのノードとペアにすることは魅力的であるように見えますが、距離の項が優先され、代わりに最も遠いノードとペアになることが強制されます。 

## アプローチ

 ブルートフォース方式ですべてのペアをチェックします$(u,v)$。 各ペアについて、LCA または BFS などを使用してツリーの距離を計算します。 各距離クエリは次のように実行できます。$O(\log n)$前処理が必要ですが、$O(n^2)$ペア、につながる$O(n^2 \log n)$。 これはすぐに大きすぎます$n = 10^5$。 

重要な観察は、目標が 2 つの部分に分かれていることです。$$a_u + a_v + \text{dist}(u,v).$$の$a$-term は端点のみに依存しますが、距離はツリー構造のみに依存します。 これは、各ノードがパスに沿って独立して寄与する形式で式を書き直すことを示唆しています。 

ノードのルートを修正する$1$。 させて$d[u]$の深さになる$u$。 どのペアでも、$$\text{dist}(u,v) = d[u] + d[v] - 2d[\text{lca}(u,v)].$$したがって、目的は次のようになります$$(a_u + d[u]) + (a_v + d[v]) - 2d[\text{lca}(u,v)].$$問題は LCA 用語であり、完全な分離が妨げられます。 ただし、構造を再解釈することはできます。グローバルに考える代わりに、再ルート形式の推論と組み合わせた「サブツリー内の最良の 2 つの候補」というアイデアを使用して、ツリーをルート化し、コントリビューションを処理できます。 

固定ノードの場合$x$最適なペアの LCA として考慮される場合、両方のエンドポイントは、次の異なる子サブツリーに存在する必要があります。$x$、または 1 つのエンドポイントは$x$自体。 これにより、問題が局所的に軽減されます。ノードごとに、次のように測定された、各子サブツリーからの最適な候補値を知りたいと考えます。$$f[u] = a_u + d[u].$$次にノードについて$x$、異なる子サブツリー内のノードの任意のペアは候補を与えます:$$f[u] + f[v] - 2d[x].$$したがって、各ノードについては、各サブツリーの最上位の値のみが必要であり、子全体で最適な組み合わせを維持します。 

これにより、問題は各ノードが最良の 2 つを集約するツリー DP に変換されます。$f$- 子サブツリーからの値を取得し、上方向に伝播します。 

最終的な答えは次のとおりです。 

1. 一部の LCA で異なるサブツリー内の 2 つのノードをペアリングする
 2. ノードとそれ自体のペアリングは無効です。$u \ne v$### 複雑さの表

 ## アルゴリズムのチュートリアル

 1. ノードでツリーをルート化します$1$そして深さを計算します$d[u]$。 

すべてのエッジに重みがあるため、深さが必要です$1$, そのため、LCA の観点から距離が直接得られます。 
2. 変換された値を定義する$f[u] = a_u + d[u]$。 

これにより、ノードの寄与がツリー内の上向きの動きから分離されます。 
3. ツリーに対してポストオーダー DFS を実行します。 

各ノードは最大の 2 つの値を計算します。$f$- 子ブランチごとにグループ化されたサブツリー全体に表示される値。 
4. 各ノードで$x$、最高のものを集めてください$f$-各子サブツリーからの値。 

これが必要なのは、有効な LCA ベースのペアは 2 つの異なるブランチから取得されなければならないためです。 
5. ノードでそのような最大の 2 つの値を結合します。$x$。 

最適な値が$f[u]$そして$f[v]$さまざまな子から候補を計算します。$$f[u] + f[v] - 2d[x].$$これはまさに拡張に対応します$\text{dist}(u,v)$LCA経由。 
6. すべてのノードの最大値を追跡します。 

これにより、考えられるすべての LCA が構造結合点として 1 回だけ考慮されることが保証されます。 
7. 見つかった最大値を返します。 

### なぜ効果があるのか

 すべてのノードのペアには、固有の最小共通祖先があります。$x$。 そのペアの寄与は完全に次のように決定されます。$x$各子サブツリーから最適な代表者が判明したら。 変革$f[u] = a_u + d[u]$距離式を合計に変換します。ここで、唯一の補正項は LCA 深度のみに依存し、LCA 深度は集約ポイントごとに固定されます。 各ペアはその LCA で正確に考慮されるため、どのペアも見逃されず、どのペアも 2 回カウントされません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n = int(input())
a = list(map(int, input().split()))
parent = [0] + list(map(int, input().split()))

g = [[] for _ in range(n)]
for i in range(1, n):
    p = parent[i]
    g[p-1].append(i)

depth = [0] * n

def dfs_depth(u, p):
    for v in g[u]:
        depth[v] = depth[u] + 1
        dfs_depth(v, u)

dfs_depth(0, -1)

ans = 0

def dfs(u):
    global ans
    best = []  # store f-values from different child subtrees

    f_u = a[u] + depth[u]

    for v in g[u]:
        child_best = dfs(v)
        best.append(child_best)

    # include node itself as candidate subtree
    best.append(f_u)

    # take top two
    best.sort(reverse=True)

    if len(best) >= 2:
        ans = max(ans, best[0] + best[1] - 2 * depth[u])

    return best[0]

dfs(0)

print(ans)
```このソリューションでは、まず親配列からルート付きツリーを構築し、次に DFS を使用して深さを計算します。 これらの深さは定義するために使用されます。
