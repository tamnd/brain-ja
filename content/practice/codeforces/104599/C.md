 ## 解決策
 ## 問題の理解

 各テスト ケースでは、期待される出力とモデルによって生成される実際の出力という 2 つの数値リストが提供されます。 すべてのペアについて$(e_i, a_i)$、絶対差があるかどうかを確認することで、予測が受け入れられるかどうかを判断します。$|a_i - e_i|$せいぜい$K$。 そうである場合、そのケースは正しいものとしてみなされます。 

タスクは、すべてのケースのうち正しいケースの割合を計算することです。$N$最も近い整数に四捨五入したパーセンテージとして出力します。 

入力サイズは最大で$N = 10^4$テストごとに、値は次のようになります。$10^9$したがって、意味のある作業はデータを 1 回渡すだけです。 値ごとの前処理や並べ替えを試みるソリューションは不要です。 リニアスキャンで十分かつ最適です。 

よくある失敗例は、丸めが正しくないことです。 たとえば、3 つのケースのうち 1 つが正しい場合、生のパーセンテージは次のようになります。$33.333\ldots$、正しい出力は次のとおりです。$33$、 ない$34$。 もう 1 つの微妙なケースは、整数の除算の切り捨てです。$(\text{correct} \cdot 100) / N$整数除算は、丸めが後で明示的に処理される場合にのみ問題ありません。 

## アプローチ

 ブルートフォース手法では、すべてのペアを単純に反復し、条件をチェックします。$|a_i - e_i| \le K$、それを満たす数を数え、パーセンテージを計算します。 各ペアを少なくとも 1 回検査する必要があるため、これはすでに最適な構造になっています。 

重要な観察は、ペア間に相互依存性が存在しないことです。 各チェックは独立しているため、解決策はストリーム内の条件を満たす要素をカウントし、最後にそのカウントをパーセンテージに変換するだけです。 ソート、プレフィックス構造、または変換は必要ありません。 

唯一重要な部分は、正しく丸められることです。 標準的なトリックは計算することです$$\text{ans} = \frac{100 \cdot \text{correct} + \frac{N}{2}}{N}$$これは、整数演算を使用して最も近い整数への丸めを実装します。

 | --- | --- | --- | --- |
 | ブルートフォーススキャン |$O(N)$|$O(1)$| 承認済み |
 | 正しい丸めによる同じスキャン |$O(N)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む$N$そして$K$。 これらは、比較の数と正確さの許容しきい値を定義します。 
2. カウンタの初期化$\text{correct} = 0$条件を満たすペアの数を累積します。 
3. ペアごとに$(e_i, a_i)$、計算する$|a_i - e_i|$そしてそれを比較してください$K$。 値が最大の場合$K$、増分$\text{correct}$これは、有効な予測の定義を直接実装します。 
4. すべてのペアを処理した後、パーセンテージを次のように計算します。$\frac{100 \cdot \text{correct}}{N}$ただし、追加によって最も近い整数に丸められます。$\frac{N}{2}$分割前。 
5. 結果の整数を出力します。 

### なぜ効果があるのか

 各ペアは独立して正しさのカウントに寄与するため、合計の正しさは各条件の指標変数を合計することによって完全に決定されます。$|a_i - e_i| \le K$。 最終的な値は、この合計を線形変換したものです。 丸めは最後に 1 回だけ適用されるため、中間精度の損失が正確さに影響を与えることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    correct = 0

    for _ in range(n):
        e, a = map(int, input().split())
        if abs(e - a) <= k:
            correct += 1

    # rounded percentage
    ans = (correct * 100 + n // 2) // n
    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、入力を線形に読み取り、ペアごとに一定時間でカウンターを更新します。 絶対差チェックでは、許容条件が直接適用されます。 丸め公式により、浮動小数点演算を行わずに正確な最も近い整数のパーセンテージが保証されるため、精度の問題が回避されます。
