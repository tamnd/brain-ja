[CF 1117F - 鮮明な文字列](https://codeforces.com/problemset/problem/1117/F)

 **評価:** 2500
 **タグ:** ビットマスク、DP
 **解決時間:** 2 分 1 秒
 **確認済み:** はい

 ## 解決策
 ## 問題の理解

 最初の文字列で構成される文字列が与えられます。`p`英語の小文字のアルファベットと対称隣接行列`A`どの文字を並べて表示できるかを指定します。 文字列内のすべての連続する文字のペアがこの行列で許可される場合、文字列は鮮明になります。 出現する文字をすべて一度に削除することができ、削除するたびに文字列が鮮明なままでなければなりません。 私たちの目標は、一連の削除を実行した後に文字列の可能な最小の長さを見つけることです。 

制約は小さい`p`(最大 17)、ただし大きい`n`(最大 10^5)。 これは、演算が指数関数的に行われることを示しています。`p`実現可能かもしれませんが、線形または二次関数は何でも構いません。`n`非常に効率的である必要があり、できれば O(n) または O(n log n) です。 対称的な行列とすでに鮮明な文字列により、どの文字がどの削除をブロックするかを推論することができます。 

重要なエッジ ケースは、文字を削除すると、以前に分離されていた 2 つの同一の文字が結合される可能性がある場合です。 たとえば、文字列「aba」について考えてみましょう。`A`「a」と「b」のみを隣接させることができます。 「b」を削除すると、「aa」が得られますが、これでも鮮明です。 元の文字列内の隣接するペアのみをチェックする不注意な実装では、この削除が誤って禁止される可能性があります。 もう 1 つの特殊なケースは、文字が 1 回だけ出現するか、鮮明さを損なうことなく文字の出現をすべて削除できる場合です。 

## アプローチ

 素朴なアプローチは、削除する文字のすべてのサブセットを試し、結果の文字列が鮮明なままであるかどうかを確認することです。 これは正しいですが、実行不可能です。`p = 17`、2^17 ≈ 131,072 のサブセットがあります。 各サブセットでは、文字列のスキャンに O(n) 時間がかかり、結果として O(n·2^p) が得られますが、これは n = 10^5 には遅すぎます。 

重要な洞察は、この問題がビットマスク動的プログラミング問題として表現できるということです。 DP の各州は、削除されていない文字のセットに対応します。 隣接制限によりどの文字が他の文字をブロックしているかを追跡すると、文字をある順序で削除することで得られる最小長をサブセットごとに計算できます。 なぜなら`p`が小さい場合、サブセットの数は管理可能です。 また、文字を削除するときに長さを正しく更新して、文字列の繰り返しスキャンを避けるために、文字列内に隣接する文字のペアが何組存在するかを事前に計算する必要もあります。 

これにより、状態ごとに O(p^2) の作業量を使用して 2^p 状態にわたる DP を計算するという問題が軽減されます。これは実現可能です。2^17 * 17^2 ≈ 3,700 万の操作で、2 秒の制限内で許容されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n・2^p) | O(n) | 遅すぎる |
 | ビットマスク DP | O(p^2・2^p + n) | O(2^p) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 文字列を文字を表す整数 0..p-1 の配列に変換します。 各文字の合計出現数を数えます。 また、元の文字列内の隣接するペア (i,j) の数を数えます。 これにより、文字が削除されたときに文字列の長さがどのように減少するかをすばやく計算できます。 
2. ビットマスクで表される文字のサブセットごとに`mask`と定義します。`dp[mask]`の文字が正確に一致する場合に達成可能な最小長として`mask`残る。 初期化する`dp[0] = 0`文字が残っていない場合、文字列は空になるためです。 
3. すべてのサブセットを反復処理します。`mask`人口数の多い順に。 文字ごとに`i`に存在する`mask`、削除を検討してください`i`の文字の最後`mask`。 新しい長さは`dp[mask ^ (1 << i)]`プラス文字数`i`元の文字列に、次の文字列間の禁止された隣接ペアの合計を加えたもの`i`そして残りの文字は`mask`。 アップデート`dp[mask]`すべての選択肢の最小値を使用して、`i`。 
4. レターを削除する「コスト」を事前計算する`i`文字列を繰り返しスキャンすることを避けるために、残りの文字を指定します。 これには、隣接するペアの数を合計することが含まれます。`(i,j)`どこ`j`マスクの中にまだ残っています。 
5. 答えは次のとおりです。`dp[(1<<p)-1]`、すべての文字が最初に存在するときの最小長。 

これが機能する理由は、各状態が残りの文字の組み合わせで達成可能な最小の文字列長を正確に表しており、隣接制約を考慮した場合の各文字を削除するコストが反復で正しく説明されているためです。 サブセットを昇順に反復することで、すべてのサブ問題が必要になる前に確実に解決されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, p = map(int, input().split())
s = input().strip()
A = [list(map(int, input().split())) for _ in range(p)]

# map letters to 0..p-1
letters = [ord(c) - ord('a') for c in s]

# count occurrences
cnt = [0] * p
for c in letters:
    cnt[c] += 1

# compute adjacency counts
adj = [[0]*p for _ in range(p)]
for i in range(n-1):
    x, y = letters[i], letters[i+1]
    adj[x][y] += 1
    adj[y][x] += 1

INF = 10**9
dp = [INF]*(1<<p)
dp[0] = 0

for mask in range(1<<p):
    # try removing each letter i last
    for i in range(p):
        if not (mask & (1<<i)):
            continue
        submask = mask ^ (1<<i)
        # compute cost to add i
        cost = cnt[i]
        for j in range(p):
            if mask & (1<<j) and not A[i][j]:
                cost += adj[i][j]
        dp[mask] = min(dp[mask], dp[submask] + cost)

print(dp[(1<<p)-1])
```コードはまず文字を整数としてエンコードし、出現数と隣接性をカウントします。`adj[i][j]`文字の回数を数えます`i`そして`j`文字列内で隣接しています。 DP はすべてのサブセットを反復処理し、最後にどの文字を削除するかを検討します。 コストは文字数と残りの文字との隣接違反を考慮し、鮮明さを強化します。 最終的な答えは、文字セット全体の DP 値です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, p = map(int, input().split())
    s = input().strip()
    A = [list(map(int, input().split())) for _ in range(p)]

    letters = [ord(c) - ord('a') for c in s]
    cnt = [0]*p
    for c in letters:
        cnt[c] += 1
    adj = [[0]*p for _ in range(p)]
    for i in range(n-1):
        x, y = letters[i], letters[i+1]
        adj[x][y] += 1
        adj[y][x] += 1
    INF = 10**9
    dp = [INF]*(1<<p)
    dp[0] = 0
    for mask in range(1<<p):
        for i in range(p):
            if not (mask & (1<<i)):
                continue
            submask = mask ^ (1<<i)
            cost = cnt[i]
            for j in range(p):
                if mask & (1<<j) and not A[i][j]:
                    cost += adj[i][j]
            dp[mask] = min(dp[mask], dp[submask] + cost)
    return str(dp[(1<<p)-1])
