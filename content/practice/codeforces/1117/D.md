 ## 問題の理解

 私たちは、全長が正確に一致するユニットサイズのポジションの最終シーケンスを構築する方法を数えています。$N$。 それぞれの位置は、通常のジェムまたは魔法のジェムを分割した結果のいずれかになります。 通常のジェムは常に 1 つのユニットを提供し、最終シーケンス内の位置を除いて区別できません。 

最終構成を構築するとき、Magic Gem は 2 つの可能な方法で動作します。 分割せずに単一のユニットとして提供することも、複数のユニットに分割することもできます。$M$通常の宝石、貢献$M$連続したユニット位置。 重要な制約は、いくつかの魔法の宝石のコレクションから開始して、分割するものを選択し、その結果として展開されたシーケンスの全長が正確でなければならないということです。$N$。 

2 つの構成は、元のマジック ジェム インデックスが使用されたか、分割されたものが異なる場合、異なるものとみなされます。これは、結果として展開されたシーケンス構造が似ている場合でも、選択の順序と同一性が重要であることを事実上意味します。 

入力により得られるのは、$N$、最終的な全長、および$M$分割魔石の展開サイズ。 出力は、最終的な長さのシーケンスを取得する個別の方法の数です。$N$、モジュロ$10^9 + 7$。 

制約$N \le 10^{18}$可能な数の gem を反復したり、DP を使用したりするソリューションは直ちに除外されます。$N$。 線形または二次的に成長する状態空間$N$不可能です。 唯一実行可能なアプローチは、遷移を一定サイズの状態に圧縮するか、線形再帰を利用するものです。 

微妙なエッジケースが現れるのは、$N < M$。 その場合、分割は不可能であり、長さに到達する唯一の方法です。$N$正確に使うことです$N$分割されていない魔法の宝石。構成は 1 つだけです。 少なくとも 1 つの分割を想定した単純な再帰実装は、誤ってゼロを返したり、無効な状態にアクセスしたりする可能性があります。 

別のエッジケースが発生するのは次の場合です。$N = M$。 ここでは 2 つの可能性があります。いずれか 1 つの分割されていない長さの gem シーケンス$M$、または正確に生成する 1 つの分割宝石$M$普通の宝石。 これらは別個の構成であるため、最終的なシーケンスは同一に見えますが、答えは 2 です。 

## アプローチ

 強引な解釈は、魔法の宝石をいくつ取り、どれを分割するかを決定することを想像することから始まります。 仮に$k$魔石の合計と分割$t$彼らのうち。 最終的な長さは次のようになります$$(k - t)\cdot 1 + t \cdot M = k + t(M - 1).$$これを等しくする必要があります$N$。 それぞれについて$k$、すべて試してみることができます$t$そして、有効なペアごとに、どの宝石を分割するかを選択する組み合わせを数えます。 ただし、これはすぐに組み合わせ爆発になります。$k$それ自体には制限がなく、事実上、$N$, したがって、すべての可能性を列挙することは不可能です。 

重要な観察点は、プロセスが順次的であり、順序に依存するということです。 左から右にシーケンスを構築しており、各ステップで単一のユニット (分割されていない宝石) を配置するか、一定のサイズのブロックを配置します。$M$（分割された宝石）。 これはまさに、ある長さの直線上のタイリング問題です$N$、タイルの長さは 1 または length です。$M$。 宝石のアイデンティティは、異なる構成だけでなく、異なる選択がこれらのタイルを順番に配置する異なる方法に対応するという意味で重要です。 

これにより、問題はすぐに次の構成を数える問題に変換されます。$N$パート 1 と$M$、順序が重要です。 させて$f(n)$長さを構築する方法の数になります$n$。 最後のステップは、単一のユニットを配置するか、貢献することです。$f(n-1)$、またはサイズのブロックを配置します$M$、貢献$f(n-M)$。 これにより、線形回帰が得られます。$$f(n) = f(n-1) + f(n-M).$$ブルートフォースDPオーバー$n$～のため不可能です$N \le 10^{18}$、ただし、繰り返しの幅は固定です$M$したがって、サイズの状態に対する行列の累乗を使用して加速できます。$M$。

 ## アルゴリズムのチュートリアル

 繰り返しをサイズのベクトルにわたる状態遷移に変換します。$M$、最後を追跡します$M$DPの値。 

1. DP の繰り返しを定義する$f(n) = f(n-1) + f(n-M)$。 これは、最終構成が単一ユニットまたは完全なユニットのいずれかで終了するという事実を捉えています。$M$-ブロック。 
2. を格納する状態ベクトルを構築します。$[f(n), f(n-1), \dots, f(n-M+1)]$。 これにより、固定メモリを使用して任意のステップでシステムを表現できるようになります。 
3. ステップの状態をマップする遷移行列を構築します。$n$ステップする$n+1$。 最初の行は繰り返しをエンコードします。新しい値は、前の最初のエントリとそれに対応するエントリに依存します。$n+1-M$。 
4. 状態のシフトが恒等構造によって処理されるように行列を埋めます。$f(n-i)$に移動します$f(n+1-(i+1))$。 
5. 遷移行列のべき乗$N-M+1$、基本値を最大で初期化できるため、$M$直接。 
6. 行列に基底ベクトルを乗算し、最初の成分を答えとして抽出します。 

重要な考え方は、行列のべき乗の各ステップが 1 つの増分をシミュレートするということです。$n$、二乗を繰り返すと、プロセスが対数時間に圧縮されます。 

### なぜ効果があるのか

 正しさは、再帰が最後のもののみに依存するという事実から来ます。$M$と述べているため、システムは固定次元の完全なマルコフ関数です。 すべての有効な長さの構造$n$最後のセグメントが長さ 1 であるか長さであるかに基づいて一意に分解可能です。$M$、そしてこの分解はばらばらであり、網羅的です。 行列表現ではこの遷移が正確に保存されるため、累乗すると、情報を失うことなく、長い範囲にわたる反復が保存されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mat_mul(a, b):
    m = len(a)
    res = [[0] * m for _ in range(m)]
    for i in range(m):
        for k in range(m):
            if a[i][k]:
                aik = a[i][k]
                for j in range(m):
                    res[i][j] = (res[i][j] + aik * b[k][j]) % MOD
    return res

def mat_pow(mat, p):
    m = len(mat)
    res = [[0] * m for _ in range(m)]
    for i in range(m):
        res[i][i] = 1
    while p:
        if p & 1:
            res = mat_mul(res, mat)
        mat = mat_mul(mat, mat)
        p >>= 1
    return res

def solve():
    N, M = map(int, input().split())

    if N < M:
        print(1)
        return

    if M == 1:
        print(1)
        return

    dp = [0] * M
    dp[0] = 1

    T = [[0] * M for _ in range(M)]
    T[0][0] = 1
    T[0][M - 1] = 1

    for i in range(1, M):
        T[i][i - 1] = 1

    power = N - M + 1
    T = mat_pow(T, power)

    base = [0] * M
    base[0] = 1

    ans = 0
    for i in range(M):
        ans = (ans + T[0][i] * base[i]) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```コードは遷移から直接漸化行列を構築します。$f(n) = f(n-1) + f(n-M)$。 行列の最初の行は、両方の可能性をエンコードしています: 単位ステップを続行するか、単位ステップで戻るか$M$。 サブ対角シフトは、以前の状態の伝播を処理します。 

微妙な点の 1 つは初期化です。 治療します$f(0) = 1$、すべての小さな基本ケースは、状態の構築を通じて暗黙的に処理されます。 指数$N - M + 1$正確に着地するようにシステムを調整します$f(N)$伝播後。 

エッジ処理$N < M$マトリックス遷移では反復がアクティブであると想定されているため、これが必要ですが、これはシーケンスが少なくとも長さになる場合にのみ意味を持ちます。$M$。

 ## 特殊なケース

 いつ$N < M$の場合、分割ブロックが収まらないため、繰り返しは適用されません。 この体制では、唯一の有効な構成はユニットの寄与のみを使用することであるため、構成は 1 つだけ存在します。 このアルゴリズムは行列計算の前に明示的に 1 を返し、遷移中の無効な負のインデックス付けを防ぎます。 

いつ$N = M$、単一の分割されていない gem と単一の分割 gem の両方が有効な構成を生成します。 反復では、遷移境界でこれをキャプチャします。$f(n-M)$term が最初にアクティブになり、特殊な場合の列挙を行わずに正しい値 2 が保証されます。 

のために$M = 2$、漸化式はフィボナッチ数に縮退し、行列は標準的な 2 次元のフィボナッチ遷移に還元されます。 アルゴリズムはこれを変更せずに自然に処理し、最小ではない分割サイズ全体にわたって正確さを確認します。
