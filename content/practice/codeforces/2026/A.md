 ## 解決策
 ## 問題の理解

 この問題では、2D 整数グリッド上に 2 つの線分を構築するように求められます。 次のように定義される長方形の領域が与えられます。$X$そして$Y$そして最小の長さ$K$。 各セグメントは長方形内に整数の端点を持っている必要があり、両方とも少なくとも長さがなければなりません$K$。 さらに、2 つのセグメントは垂直である必要があります。つまり、セグメント自体は交差する必要はありませんが、セグメントを含む線は直角に交わります。 

入力は最大で構成されます$5000$テスト ケース、それぞれ$X$、$Y$、 そして$K$。 なぜなら$X$そして$Y$それぞれせいぜい$1000$そして$K$せいぜい$1414$で操作できます。$O(1)$テストケースごとに制限時間を大幅に下回っています。 各テスト ケースは独立しているため、必要なのは単純な公式の構築だけです。 

エッジケースが発生するのは次の場合です$X$または$Y$に比べて非常に小さい$K$。 たとえば、次の場合$X=1$、$Y=1$、 そして$K=1$、を選ぶ素朴なアプローチ$K$最初のセグメントでは X 軸に沿って、2 番目のセグメントでは Y 軸に沿って動作しますが、$K>X$または$K>Y$不注意な実装により、グリッドの外に出るセグメントを構築しようとする可能性があります。 この問題によって解決策が存在することが保証されるため、必要なのはセグメントが長方形内に留まることを確認することだけです。 

## アプローチ

 ブルートフォースアプローチは、最初のセグメントの端点のすべての可能な整数座標を反復処理し、その長さが少なくとも$K$、次に 2 番目のセグメントの考えられるすべての端点を反復し、傾きを計算し、直角度をテストします。 これは整数エンドポイントが制限されているため機能しますが、最悪の場合の操作数は次のようになります。$O(X^2 Y^2)$テストケースごとに考えると遅すぎます$X,Y \le 1000$。 

重要な洞察は、検索する必要がないということです。 垂直なセグメントのペアは、一方のセグメントを水平に選択し、もう一方のセグメントを垂直に選択することによって構築できます。 たとえば、最初のセグメントを X 軸に沿って配置すると、その傾きが確実に次のようになります。$0$したがって、y 軸に沿った垂直セグメントには未定義の傾きがあり、ユークリッドの意味では垂直になります。 次に、各セグメントの長さが少なくとも次であることを確認するだけで済みます。$K$そして長方形の中に残ります。 1 つのセグメントを左下の角に沿って水平に配置し、もう 1 つのセグメントを同じ角に沿って垂直に配置することで、少なくとも整数の座標、垂直性、および長さを保証します。$K$に限って$K \le X$そして$K \le Y$、これは入力制約によって保証されます。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$X$、$Y$、 そして$K$。 
2. 最初のセグメントを水平方向に配置します。$(0,0)$に$(K,0)$。 これにより、整数のエンドポイントが保証され、長方形内に収まり、長さが決まります。$K$。 
3. 2 番目のセグメントを垂直方向に配置します。$(0,0)$に$(0,K)$。 これは、整数のエンドポイントも保証し、長方形内にあり、長さを持ちます。$K$。 
4. 2 つのセグメントの座標を出力します。 

最初のセグメントが水平で 2 番目のセグメントが垂直であるため、この構築は機能し、それらの誘導線は垂直になります。 どちらのセグメントも原点から始まりますが、終点が境界内にある限り、始点はどこにでも移動できます。 なぜなら$K$に比べて常に十分小さい$X$そして$Y$、この選択は常に長さの要件を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        X, Y, K = map(int, input().split())
        # First segment horizontal
        A_x, A_y = 0, 0
        B_x, B_y = K, 0
        # Second segment vertical
        C_x, C_y = 0, 0
        D_x, D_y = 0, K
        print(A_x, A_y, B_x, B_y)
        print(C_x, C_y, D_x, D_y)
```最初のセグメントは水平方向にフィットすることが保証されています。$K \le X$、2番目は垂直にフィットします。$K \le Y$。 どちらのセグメントも原点から始まるため、整数座標を確保しながら構築が簡素化されます。 別の開始点を選択することも有効ですが、その必要はありません。

 ## 特殊なケース

 いつ$X$等しい$K$または$Y$等しい$K$、セグメントは長方形の境界に正確に到達する必要があります。 たとえば、$X=1000$、$Y=500$、 そして$K=500$、水平セグメントは次から始まります。$(0,0)$に$(500,0)$そして垂直から$(0,0)$に$(0,500)$。 どちらのセグメントも長さの要件を満たしており、範囲内に留まります。 アルゴリズムは、左下隅のみをアンカーとして使用し、各セグメントを正確に拡張するため、長方形を超えることなくこれらを正しく構築します。$K$。
