 ## 解決策
 ## 問題の理解

 各クレーターは中心座標によって記述されます`c`そして半径`r`。 ロボットはラインに沿って移動するため、すべてのクレーターはそのライン上の間隔によって表現できます。$[c-r,\ c+r]$オクロフ教授の規則によれば、選択した 2 つのクレーターは完全に分離しているか、一方が完全に他方の内側に存在していなければなりません。 部分的な重複は禁止です。 

間隔の場合、これは、選択された 2 つの間隔について次のことを意味します。 

1. それらはまったく交差しません。 
2. 一方の区間がもう一方の区間の中に完全に含まれています。 
3. エンドポイントでのタッチは許可されます。 

この条件を満たすクレーターの可能な最大のサブセットを選択し、最適なセットを出力する必要があります。 

制約`n ≤ 2000`が主な手がかりです。 周囲を含む立方体ソリューション`8 * 10^9`操作は不可能です。 二次動的計画法のソリューションは、特に Python で慎重に実装すれば現実的です。 このタスクでは選択したセットの再構築も要求されるため、回答のサイズだけでなく遷移も保存する必要があります。 

難しいのは、間隔間の関係が、通常の間隔スケジュールのように単純に「互換性がある」または「非互換性」ではないということです。 一方にもう一方が含まれている場合、2 つの区間が共存でき、適切に一致した括弧と同様の入れ子構造が作成されます。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

接線間隔を考慮します。```
2
0 1
2 1
```これらの間隔は、`[−1,1]`そして`[1,3]`。 それらは一点で接触し、一緒にいることを許可されます。 重複をチェックするときに厳密な不等式を使用すると、重複が誤って拒否されます。 

ここで、間隔をまたぐことを考えてみましょう。```
2
0 3
4 3
```これらの間隔は、`[−3,3]`そして`[1,7]`。 それらは重なっていますが、どちらも他方を含んでいません。 両方を選択することはできません。 「素ではない」ことだけをチェックする不注意な実装では、それらが誤って受け入れられてしまいます。 

ネストされた間隔にも注意が必要です。```
3
0 10
0 5
0 2
```小さなクレーターはすべて大きなクレーターの内側に完全に収まるため、3 つすべてが一緒に有効です。 常に小さい間隔を優先する、または常に大きい間隔を優先する貪欲な戦略は、より複雑な場合に最適なソリューションを簡単に失う可能性があります。 

2 つの間隔が 1 つのエンドポイントを共有する場合、別の微妙な状況が発生します。```
2
0 5
5 0
```間隔は`[−5,5]`そして`[5,5]`。 2 番目の要素は最初の要素に完全に含まれており、接線は許可されます。 非厳密な封じ込めの代わりに厳密な封じ込めを使用すると、このケースは解決されません。 

## アプローチ

 ブルートフォースのアイデアは単純です。 クレーターのすべてのサブセットを試し、すべてのペアがルールを満たすかどうかを検証します。 ペアチェックテイク`O(n²)`、そして、あります`2^n`サブセットなので、全体の複雑さは次のようになります。`O(2^n * n²)`。 たとえ`n = 40`、これはすでに絶望的ですが、実際の限界は`2000`。 

より洗練されたブルートフォースの方向性は、間隔を考えることです。 2 つの区間は交差しない限り互換性があります。 横断とは次のことを意味します。$l_1 < l_2 < r_1 < r_2$または対称的に逆の順序。 

これにより、問題の本当の構造が明らかになります。 有効な区間ファミリは正確に層状ファミリであり、区間が素であるかネストされているという意味です。 間隔がその終点によってソートされると、構造は再帰的になります。 1 つの間隔内で、その子に対して同じ問題を再度解きます。 互いに素なグループを独立して連結することもできます。 

これは間隔 DP を示唆しています。 

重要な観察は、左のエンドポイントと右のエンドポイントによって順序付けされた間隔を処理すると、すべての有効なソリューションが適切にネストされたセグメントのように動作するということです。 間隔を選択すると、選択した他のすべての間隔は完全にその内側にあるか、完全に外側にあります。 

間隔範囲にわたって DP を構築できます。 間隔ごとに`i`、完全に内側にある最も有効なサブセットを計算します。`i`。 次に、加重間隔スケジューリングと同様に、交差しない子間隔を結合します。 

以来`n ≤ 2000`、`O(n²)`または`O(n² log n)`解決策は受け入れられます。 標準的に受け入れられているソリューションでは、ソート間隔の後に二次動的計画法を使用します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n · n²) | O(n) | 遅すぎる |
 | 最適なDP | O(n²) | O(n²) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 間隔表現

 それぞれのクレーターは間隔になります。$[l_i,r_i]=[c_i-r_i,\ c_i+r_i]$また、出力では入力番号付けを使用する必要があるため、元のインデックスも保持します。 

### 並べ替え

 1. 左端の値を増やして間隔を並べ替えます。 
2. 左側のエンドポイントが等しい場合は、右側のエンドポイントの降順で並べ替えます。 

この順序は非常に重要です。 より大きな含まれる間隔は、より小さな含まれる間隔の前に表示されます。 これにより、ネストされた関係の処理が容易になります。 

### 交差点の定義

 1. 次の場合、2 つの区間が交差します。$l_i < l_j \le r_i < r_j$交差する区間の両方が答えに属することはできません。 

### 動的プログラミングの状態

 1. しましょう`dp[i]`選択された最も外側の間隔が間隔である有効なサブセットの最大サイズである`i`。 

私たちは常に含めます`i`それ自体はこの状態です。 

### 移行

 1. インターバルごとに`i`、すべての間隔をその内部で厳密に処理します。 
2. 内側の間隔の間`i`、結合していない「トップレベル」の子のみを結合したいと考えています。 2 つの子が包含されずに重なる場合、それらは交差し、一緒に無効になります。 
3. これは、直接互換性のある子に対する重み付き間隔スケジューリング問題になります。`i`。 

候補児ごとに`j`内部`i`:

 - に基づいた最適な構造を採用する可能性があります。`j`、 価値`dp[j]`。 
- 次に、次の結合されていない子を続行します。 

### セカンダリ DP

 1. 別の DP を位置に使用して、重複しない順序で子を結合します。 

これにより、間隔内の素の部分構造の最適なコレクションが計算されます。`i`。 

1. 最後に:```
dp[i] = 1 + best_inside
```の`1`カウント間隔`i`自体。 

### 再建

 1. 遷移中に親の選択を保存します。 
2. 最大の間隔を見つけた後`dp[i]`、選択されたすべての間隔を再帰的に再構築します。 

### なぜ効果があるのか

 重要な不変条件は、すべての有効な間隔ファミリーが層状構造を形成するということです。 選択した間隔内の間隔は、1 つのネストされたブランチ、または完全に独立した別のブランチに属します。 構造物を横断することは不可能です。 

そのため、あらゆる最適解は間隔を置いて根づいています。`i`は、素の直接の子の独立した最適解に分解されます。 DP はまさにそれらの可能性を探求しており、交差する間隔を組み合わせることはありません。 この方法ですべての有効な構成を一意に分解できるため、DP は最適なソリューションを見逃すことはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    segs = []

    for idx in range(1, n + 1):
        c, r = map(int, input().split())
        l = c - r
        rr = c + r
        segs.append((l, rr, idx))

    segs.sort(key=lambda x: (x[0], -x[1]))

    l = [0] * n
    r = [0] * n
    idxs = [0] * n

    for i in range(n):
        l[i], r[i], idxs[i] = segs[i]

    dp = [1] * n
    choice = [[] for _ in range(n)]

    inside = [[] for _ in range(n)]

    for i in range(n):
        for j in range(i + 1, n):
            if l[i] <= l[j] and r[j] <= r[i]:
                inside[i].append(j)

    for i in range(n - 1, -1, -1):
        children = inside[i]

        m = len(children)

        best = [0] * (m + 1)
        take = [False] * m
        nxt = [m] * m

        for a in range(m):
            j = children[a]

            b = a + 1
            while b < m and l[children[b]] <= r[j]:
                b += 1

            nxt[a] = b

        pick = [False] * m

        for a in range(m - 1, -1, -1):
            j = children[a]

            skip_val = best[a + 1]
            take_val = dp[j] + best[nxt[a]]

            if take_val > skip_val:
                best[a] = take_val
                pick[a] = True
            else:
                best[a] = skip_val

        dp[i] = 1 + best[0]

        cur = 0
        selected = []

        while cur < m:
            if pick[cur]:
                j = children[cur]
                selected.append(j)
                cur = nxt[cur]
            else:
                cur += 1

        choice[i] = selected

    root = max(range(n), key=lambda x: dp[x])

    ans = []

    def build(v):
        ans.append(idxs[v])
        for to in choice[v]:
            build(to)

    build(root)

    print(len(ans))
    print(*ans)

solve()
```最初のステップでは、すべてのクレーターを間隔に変換します。 間隔のエンドポイントを使用すると、すべての幾何学的条件が数値間の比較に直接単純化されます。 

左の端点を増加させ、右の端点を減少させることによる並べ替えが不可欠です。 2 つの間隔が同じ左端点を共有しているとします。 DP 遷移中に包含関係が有効なままとなるように、大きい方が最初に出現する必要があります。 

配列`inside[i]`間隔に完全に含まれるすべての間隔を格納します`i`。 間隔はすでにソートされているため、すべての子孫がその後に表示されます。`i`。 

各間隔内のセカンダリ DP は、加重間隔スケジューリングのように動作します。 子間隔を選択したら`j`、左端点がまだ内側にある後のすべての子`j`に属しています`j`のサブツリーであり、別の最上位の子として処理してはなりません。 ポインタ`nxt[a]`次の互いに素な子に直接スキップします。 

実装の微妙な詳細の 1 つは条件です。```
while b < m and l[children[b]] <= r[j]:
```の`<=`同じ入れ子レベルでは接触間隔が素ではないため、これは正しいです。 別の間隔がその前またはちょうどその時刻に始まる場合`r[j]`の場合、交差するか、内部にネストされます。`j`、したがって、それはに属している必要があります`j`兄弟になるのではなく、 のサブツリーになります。 

再構築フェーズでは、保存された選択肢が再帰的に実行されます。 選択されたすべての子はすでに最適なネストされたサブツリーを表しているため、再帰によって完全な最適な答えが再構築されます。

import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())

    segs = []

    for idx in range(1, n + 1):
        c, r = map(int, input().split())
        segs.append((c - r, c + r, idx))

    segs.sort(key=lambda x: (x[0], -x[1]))

    l = [x[0] for x in segs]
    r = [x[1] for x in segs]
    ids = [x[2] for x in segs]

    dp = [1] * n
    choice = [[] for _ in range(n)]

    inside = [[] for _ in range(n)]

    for i in range(n):
        for j in range(i + 1, n):
            if l[i] <= l[j] and r[j] <= r[i]:
                inside[i].append(j)

        m = len(children)

        nxt = [m] * m
        pick = [False] * m

            while b < m and l[children[b]] <= r[j]:
                b += 1

            nxt[a] = b

            skip = best[a + 1]

            if take > skip:
                best[a] = take
                pick[a] = True
            else:
                best[a] = skip

        cur = 0

                choice[i].append(children[cur])
                cur = nxt[cur]
            else:
