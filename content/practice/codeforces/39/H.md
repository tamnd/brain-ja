 ## 解決策
 ## 問題の理解

 このタスクは、基数を使用して位置記数法の数字の九九を生成することです。`k`。 10 進法とは異なり、このシステムの数字の範囲は 0 から 0 までです。`k-1`。 Petya は 1 から 1 までの数値の積を見たいと考えています`k-1`このシステムで表現します。 入力は単一の整数です`k`基数を表し、2 ～ 10 の範囲に制限されます。出力は`(k-1) × (k-1)`テーブルの行のエントリ`i`そしてコラム`j`製品が含まれています`i × j`塩基で表現する`k`。 

なぜなら`k`最大 10 の場合、最大テーブル サイズは`9 × 9`。 表内の各製品は最大でも`(k-1) × (k-1) = 81`いつ`k = 10`。 これは十分に小さいため、パフォーマンスを気にせずにテーブルを明示的に生成できます。 主な微妙な点は、10 進積をターゲットの基数に変換し、数字が文字列として正しく表現されるようにし、複数桁の数値を適切に処理することにあります。 

エッジケースが発生するのは次のような場合です`k = 2`。 この場合、テーブルにはエントリが 1 つだけ含まれます。`1 × 1 = 1`。 不用意に実装すると、誤ってループしたり、テーブルに 0 を含めようとしたりして、間違ったサイズが生成される可能性があります。 

## アプローチ

 ブルート フォースのアプローチは簡単です。すべての整数をループします。`i`そして`j`1から`k-1`、その積を計算し、それをbaseの文字列表現に変換します。`k`。 テーブルのサイズが最大であっても小さいため、これは機能します。`k`。 各積は最大 81 であるため、除算と剰余演算を繰り返すことで基数の変換を行うことができます。 

この問題ではすべてのエントリを明示的に出力する必要があるため、これより速い漸近アプローチはありません。 重要な洞察は、ベースで数値を生成することです。`k`変換を慎重に扱えば簡単です。除算を繰り返します。`k`残りを記録し、収集した数字を反転します。 テーブル自体にゼロの行または列を含めることはできません。また、すべての数値はターゲット ベースに文字列としてスペースで区切って出力する必要があります。 Python の組み込み整数演算は、オーバーフローすることなくすべての積を安全に処理します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k^2 log k) | O(k^2 log k) | 承認済み |
 | 最適 | O(k^2 log k) | O(k^2 log k) | 承認済み |

 の`log k`因数は、数値を表すために必要な桁数から得られます。`(k-1)^2`基地内で`k`。 

## アルゴリズムのチュートリアル

 1. 基数を読み取る`k`入力から。 これによりテーブルのサイズが決まります。`(k-1) × (k-1)`。 
2. 10 進整数を変換するヘルパー関数を定義します。`n`ベースの文字列に`k`。 空のリストを初期化する`digits`。 その間`n`ゼロより大きい、除算`n`による`k`、剰余を取得し、剰余を文字列として追加します。`digits`、商を続けます。 逆行する`digits`最後に。 もし`n`ゼロの場合は戻ります`"0"`。 
3. 各行インデックスをループします。`i`1から`k-1`。 それぞれについて`i`、空のリストを初期化します`row`。 
4. 行ループ内で、各列インデックスをループします。`j`1から`k-1`。 積を計算する`i × j`。 
5. 製品をベースに変換する`k`ヘルパー関数を使用して追加します`row`。 
6. 行のすべての列を処理した後、行エントリをスペースで結合し、結果を出力します。 
7. すべての行が印刷されるまで繰り返します。 

このアプローチは、各エントリが明示的に計算され、ターゲット ベースに正しく変換されるため機能します。 ループ境界により、テーブル サイズの一致が保証されます。`(k-1) × (k-1)`、基本変換により、暗黙的な 10 進形式に依存せずに数字が文字列として表現されるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def to_base(n, k):
    if n == 0:
        return "0"
    digits = []
    while n > 0:
        digits.append(str(n % k))
        n //= k
    return ''.join(reversed(digits))

def main():
    k = int(input())
    for i in range(1, k):
        row = []
        for j in range(1, k):
            product = i * j
            row.append(to_base(product, k))
        print(' '.join(row))

if __name__ == "__main__":
    main()
```の`to_base`除算と剰余抽出を繰り返して基数変換を行う関数です。 の`main`関数はすべてのテーブル インデックスをループし、行を動的に構築します。 行要素を結合すると、適切な間隔が確保されます。 コードは有効な最小値と最大値を正しく処理します。`k`値を含む`k = 2`これにより、単一のエントリが生成されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(k^2 log k) | (k-1)^2 の各積では、(k-1)^2 までの数値を基数 k に変換する必要があり、これには O(log_k((k-1)^2)) = O(log k) の演算が必要です。 |
 | スペース | O(k^2 log k) | 各行には、k-1 個の数値が文字列形式で格納されます。 各数値は最大 O(log k) 桁です。 |

 k ≤ 10 の場合、アルゴリズムは、2 秒および 64 MB の制限内で、最大 2 桁の 10 進数を使用して最大 81 個のテーブル エントリを実行します。
