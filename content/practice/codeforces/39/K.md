 ## 問題の理解

 私たちに与えられているのは、$n \times m$フィールドを表す長方形のグリッド。このフィールド内には$k$オブジェクトを表す重なり合わない四角形。 各四角形は「*」でマークされた連続したセルを占め、他のすべてのセルは「.」になります。 このタスクは、オブジェクトを部分的に覆うことなく、少なくとも 1 つ、最大 3 つのオブジェクトを完全にカバーするように、グリッド内の長方形領域を選択する方法の数を数えることです。 長方形はグリッド軸と一致する必要があり、グリッドの外側に拡張することはできません。 

入力サイズは重要な指針を与えてくれます。$n$そして$m$それぞれ最大 1000 になる可能性があるため、考えられるすべての四角形を単純に反復するソリューションでは、最大 1000 個が必要になります。$10^{12}$明らかに不可能な操作です。$k$オブジェクトの数は最大 90 です。これは、考えられるすべての四角形を反復処理する代わりに、オブジェクト自体とその相対位置に焦点を当てる必要があることを示唆しています。$k^3$わずか約 729,000 ですが、これは実現可能です。 

オブジェクトがグリッド境界に隣接している場合、または単一の行または列に並んでいる場合、微妙なエッジ ケースが発生します。 単純に四角形を左上隅と右下隅でカウントする不注意なアプローチでは、複数のオブジェクトが完全に位置合わせされている構成を二重にカウントしたり、見逃したりする可能性があります。 たとえば、コーナーにのみオブジェクトがある 3×3 グリッドは、別のオブジェクトと部分的に重なる空きスペースを含めずに、1、2、または 3 つのコーナーに当たるすべての長方形をカウントするために慎重に処理する必要があります。 

## アプローチ

 ブルートフォース手法では、左上と右下の座標によって定義されるすべての可能な四角形を考慮し、どのオブジェクトがこの四角形の中に完全に収まっているかを確認します。 上のすべての四角形をチェックする$n \times m$グリッドは$O(n^2 m^2)$、そして次のどれかを検証します。$k$オブジェクトが各四角形の内側にある場合、次の係数が追加されます。$k$。 これにより、$O(n^2 m^2 k)$、それは周りにあります$10^{12}$最悪の場合、明らかに動作不能になります。 

重要な洞察は、オブジェクトの数です。$k$小さいです。 各オブジェクトは長方形なので、単純にその境界座標によって表すことができます。 有効な攻撃長方形を数えるには、1、2、または 3 つのオブジェクトを完全にカバーする長方形のみを考慮する必要があります。 1、2、または 3 つのオブジェクトのすべての組み合わせを列挙すると、組み合わせごとに、選択したすべてのオブジェクトを含む最小外接四角形を計算できます。 他のオブジェクトを含めずにグリッド内でこの境界四角形を拡張する方法の数は、グリッドの境界と他のオブジェクトの座標を使用して直接計算できます。 

これにより、すべてのグリッド四角形の反復からオブジェクトの組み合わせの反復に問題が軽減されます。これは実現可能です。$C(k,3) + C(k,2) + C(k,1)$最大値が 120,000 未満である$k=90$。 各組み合わせでは、有効な四角形の数をカウントするために一定量の演算が必要ですが、これは非常に効率的です。

 ## アルゴリズムのチュートリアル

 1. グリッドを解析してすべてを見つけます$k$オブジェクト。 各オブジェクトについて、その上下左右の境界を記録します。 これにより、2D 問題が 1D の長方形のセットに縮小されます。 
2. 1、2、および 3 のオブジェクトのすべての組み合わせを列挙します。 組み合わせごとに、これらのオブジェクトを正確にカバーする最小外接四角形を計算します。 外接する四角形の上の境界は、選択したオブジェクトの中で最小の上、下境界は最大の下、左は最小の左、右は最大の右です。 
3. 各組み合わせについて、外接する四角形の内側に選択されていないオブジェクトがないことを確認します。 選択されていないオブジェクトが完全に含まれている場合は、この組み合わせを破棄します。 
4. 有効な境界四角形の場合、グリッド境界または選択されていないオブジェクトに達するまで上、下、左、右の端を拡張することによって、グリッド内に四角形を配置できる方法の数を計算します。 垂直方向の拡張数と水平方向の拡張数を乗算して、この組み合わせの四角形の数を取得します。 
5. すべての組み合わせのカウントを合計します。 この合計は、1 ～ 3 個のオブジェクトを攻撃する方法の合計です。 

機能する理由: サイズ 1 ～ 3 のすべての可能なサブセットを反復処理し、それらのオブジェクトを正確にカバーするすべての四角形をカウントすることで、すべての有効な四角形が 1 回カウントされることが保証されます。 ステップ 3 のため、選択されていないオブジェクトを覆う四角形は含まれません。拡張により、各四角形のすべての位置が確実にカウントされます。 

## Python ソリューション```python
import sys
from itertools import combinations
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())
    grid = [input().strip() for _ in range(n)]
    objects = []

    # Step 1: find all objects
    visited = [[False]*m for _ in range(n)]
    for i in range(n):
        for j in range(m):
            if grid[i][j] == '*' and not visited[i][j]:
                # find the rectangle
                r1, c1 = i, j
                r2, c2 = i, j
                while r2 + 1 < n and grid[r2 + 1][j] == '*':
                    r2 += 1
                while c2 + 1 < m and all(grid[r][c2 + 1] == '*' for r in range(r1, r2+1)):
                    c2 += 1
                # mark visited
                for r in range(r1, r2+1):
                    for c in range(c1, c2+1):
                        visited[r][c] = True
                objects.append((r1, c1, r2, c2))

    total = 0

    # Step 2: consider all 1, 2, 3 object combinations
    for cnt in range(1, 4):
        for combo in combinations(objects, cnt):
            # bounding rectangle
            top = min(obj[0] for obj in combo)
            left = min(obj[1] for obj in combo)
            bottom = max(obj[2] for obj in combo)
            right = max(obj[3] for obj in combo)

            # check no other object is inside
            ok = True
            for obj in objects:
                if obj not in combo:
                    if top <= obj[0] and bottom >= obj[2] and left <= obj[1] and right >= obj[3]:
                        ok = False
                        break
            if not ok:
                continue

            # count extensions
            top_ext = top + 1
            left_ext = left + 1
            bottom_ext = n - bottom
            right_ext = m - right

            total += top_ext * left_ext * bottom_ext * right_ext

    print(total)

solve()
```このソリューションでは、まずグリッド内のすべての四角形を識別し、二重カウントを避けるためにそれらにマークを付けます。 1、2、および 3 のオブジェクトの組み合わせを使用して、外接する四角形を計算し、選択されていないオブジェクトが完全に内側に入っていないことを確認します。 展開は、グリッド境界を使用した単純な乗算です。 慎重な使用`visited`各オブジェクトが正確に 1 回検出されるようにします。
