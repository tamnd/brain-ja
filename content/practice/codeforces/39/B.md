 ## 解決策
 ## 問題の理解

 2001 年から始まる企業の年間収入を表す一連の整数が与えられます。最初の数字は 2001 年の収入、2 番目の数字は 2002 年の収入、というようになります。 その年に会社が損失を被った場合、これらの値はマイナスになる可能性があります。 Petya は、収入が毎年 10 億ずつ直線的に増加する「完璧な」成長シナリオを提示したいと考えています。1 年目は 10 億、2 年目は 20 億、3 年目は 30 億というように増加します。 実際の収入はこの完全なパターンに従っていない可能性があるため、収入が 1、2、3、... の順に正確に一致する一連の年を抽出したいと考えています。 

私たちの目標は、そのような最長のサブシーケンスを選択することです。 次に、その長さと対応する年 (2000 + 年のインデックス) を出力します。 

入力制約は小さいです。`n`は最大 100 です。これは、2 秒の制限の下では最新のプロセッサーでは 10,000 回の演算さえも些細なことであるため、O(n^2) 演算のアルゴリズムが実現可能であることを意味します。 収入がマイナスになる可能性があるため、最初の不一致で停止する単純なアプローチは失敗します。 また、完璧な成長に一致する年が存在しない可能性にも対処する必要があります。その場合、答えは 0 になります。 

明らかではないエッジ ケースには、同じ目標値に対して複数の一致する年が存在するシーケンスが含まれます。 たとえば、`[1, 1, 2, 2, 3]`、完全なシーケンスは、最初の 1 または 2 番目の 1 のいずれかをとります。もう 1 つのエッジ ケースは、すべての数値が負の場合です。`[-1, -2, -3]`不注意なアプローチでは、予想される完全な成長に対して実際の値をチェックせずにインデックスを返す可能性があります。 

## アプローチ

 強引なアプローチは、収入配列のすべての部分列を試し、その要素が完全な成長を形成しているかどうかをチェックすることです。 長さ k のサブシーケンスの数は組み合わせであるため、合計演算数は指数関数的に増加し、およそ O(2^n) になります。 のために`n = 100`、これはまったく不可能です。 

重要な洞察は、この問題は、指定された増加シーケンスに一致する最長のサブシーケンスを見つけることと同じであるということです。`1, 2, 3, …`。 これはまさに最長増加部分列 (LIS) 問題のバリエーションですが、任意の比較ではなく、各要素が特定の期待値と一致する必要があります。 なぜなら`n`が小さい場合は、動的プログラミングのアプローチが効率的に機能します。 

DP 配列を維持しながら配列を反復処理します。`dp[i]`位置で終わる最長の完全なシーケンスの長さです`i`。 位置ごとに、以前のすべての位置をチェックして、シーケンスを拡張できるかどうかを確認します。 これにより、問題は指数関数から O(n^2) に軽減されますが、制約を考慮すると許容範囲内です。 また、`prev`実際の年のシーケンスを再構築するための配列。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 動的プログラミング | O(n^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を初期化する`dp`長さの`n`ゼロ付き。`dp[i]`インデックスで終わる最長の完全なサブシーケンスの長さを保存します`i`。 
2. 配列を初期化する`prev`長さの`n`と`-1`再構築のためにシーケンス内の以前のインデックスを保存します。 
3. インデックスを使用して配列をループします。`i`0からn-1まで。 要素ごとに`a[i]`、次のように完全なシーケンスでターゲット値を計算します。`dp[i] + 1`。 もし`a[i]`等しい`dp[i] + 1`以前のサブシーケンスを拡張することもできます。`dp[i]`に`dp[j] + 1`一部の人にとっては`j < i`どこ`dp[j]`最大化して記録する`prev[i] = j`。 前の要素が拡張できない場合は、次のように設定します。`dp[i] = 1`。 
4.充填後`dp`、インデックスを見つけます`max_index`最大のもので`dp[max_index]`。 これにより、最長の完全なシーケンスの長さが得られます。 
5. 次の手順に従ってシーケンスを再構築します。`prev`からの配列`max_index`後ろ向きに。 2001 を追加して、各配列インデックスを実際の年に変換します。 
6. シーケンスの長さと再構成された年を出力します。 完全な成長に一致する要素がなかった場合は、0 を出力します。 

なぜ効果があるのか: 各ステップで、`dp[i]`で終わる最長の完全なシーケンスを正確に表します`i`有効な拡張子のみが考慮されるためです。 の`prev`array を使用すると、サブシーケンスを順番に再構築できるようになります。 このアルゴリズムは、各位置で完全なシーケンスを終了するためのすべての可能性を体系的に考慮するため、最も長いシーケンスを見逃すことはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

dp = [0] * n
prev = [-1] * n

for i in range(n):
    if a[i] == 1:
        dp[i] = 1
    for j in range(i):
        if dp[j] > 0 and a[i] == dp[j] + 1:
            if dp[j] + 1 > dp[i]:
                dp[i] = dp[j] + 1
                prev[i] = j

# Find the index of the maximum length
max_len = 0
max_index = -1
for i in range(n):
    if dp[i] > max_len:
        max_len = dp[i]
        max_index = i

if max_len == 0:
    print(0)
else:
    sequence = []
    idx = max_index
    while idx != -1:
        sequence.append(2001 + idx)
        idx = prev[idx]
    sequence.reverse()
    print(max_len)
    print(*sequence)
```まず初期化します`dp`そして`prev`最長のシーケンスとその再構成パスを追跡します。 すべてのペアをループします`(j, i)`と`j < i`シーケンスを拡張できるかどうかを確認します。 ここでは、期待される完璧な成長を注意深く扱うことが重要です。 それなし`a[i] == dp[j] + 1`の場合、サブシーケンスは無効になります。 最終的な再構成では、`prev`シーケンスを逆方向に構築し、時系列順に逆にします。
