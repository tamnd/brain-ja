 ## 解決策
 ## 問題の理解

 フットボールチームのシーズンの概要が与えられました。 各チームは 5 つの数字で表されます。勝った試合、引き分け、負けた試合の数、および全試合での得点と失点の合計です。 問題はシーズンを再構築することではなく、この要約が個々の試合結果の考えられる複数のセットから正確に得られるかどうかを推論することです。 

各試合は、2-1 や 0-0 などの 1 つの順序付けられたスコアラインに貢献します。 シーズン全体の試合から、勝ち、引き分け、負けを計算し、勝敗のゴールを合計することができます。 多くの異なる一致コレクションが同じ概要を生成する可能性があります。 タスクは、指定された要約が一致結果への有効な分解を 1 つだけ許可するか、複数を許可するかを判断することです。 分解がまったく存在しない場合も、無効とみなされます。 

主な問題点は、入力が一致の数を直接記述していないことですが、W + D + L として推測できることです。各一致は 1 つの結果カテゴリにのみ寄与するため、その部分は厳密です。 不確実性は完全に、結果のカウントと一致して試合全体にゴールがどのように配分されるかにあります。 

制約は大きく、最大 100,000 のテスト ケースと最大 10^9 の値があります。 これにより、試合レベルの構築や目標に対する動的プログラミングを列挙しようとするアプローチは即座に排除されます。 実行可能なソリューションでは、各テスト ケースを定数時間または対数時間のチェックに減らす必要があります。 

タプルが内部的に矛盾している場合、微妙なエッジケースが発生します。 たとえば、W + D + L = 0 であるがゴールがゼロ以外の場合、またはゴールの制約が可能な試合結果と矛盾している場合です。 もう 1 つの注意が必要な状況は、構造的に異なる試合パーティションによって同じ集計統計が実現できる場合、特に合計に影響を与えることなく勝ちと引き分けにわたってゴールを再配置できる場合です。 

## アプローチ

 ブルートフォース解釈では、勝ち、引き分け、負けの数が W、D、L に一致し、合計ゴール数が G_f と G_a に一致する、考えられるすべての試合のマルチセットを構築しようとします。 有効な構築ごとに、それが同じ集約状態に一致するかどうかを確認します。 これは、固定数の試合をラベル付きの結果に分割し、それらにゴールを分配することと同じです。 中程度の W + D + L の場合でも、目標分布の分割数は組み合わせ的に増加します。 各一致には複数の整数の自由度が導入されるため、このアプローチは入力が小さい場合でも不可能になります。 

重要な単純化は、個々の一致という観点から考えるのをやめ、代わりに構造的な自由度という観点から推論することです。 勝利は厳密にプラスの得失点差に寄与し、引き分けはゼロに寄与し、負けはマイナスの得失点差に寄与します。 ただし、目標自体は、勝ち/引き分け/負けの構造が示すよりも柔軟です。 勝ちがプラス、負けがマイナス、引き分けがゼロである限り、さまざまな内部スコア割り当てを使用して、同じ W、D、L を達成できます。 

合計ゴール数の制約 G_f と G_a は、すべての試合に対して 2 つの線形方程式を課しますが、構造が極度に制約されていない限り、これらは個々の試合間でゴールを分割する方法を一意に決定するものではありません。 一意性は、分解に内部の自由がない場合にのみ発生します。各一致は、W、D、L、G_f、および G_a と互換性のある正確に 1 つのスコアライン パターンに強制的に組み込まれる必要があります。

これにより、問題はシステムが一致レベルのスコアの複数の有効な割り当てを許可するかどうかをチェックすることになります。 決定的な観察は、合計を分割せずに試合間でゴールを移動することで調整できる少なくとも 1 つの勝敗が存在する場合に、曖昧さが発生するということです。 これは構成が「タイト」でない限り起こります。つまり、すべての勝利は強制的な方向で正確に 1-0 または 0-1 でなければならず、すべての引き分けは 0-0 でなければならず、ゴールを再分配する余裕はありません。 

したがって、解決策は、目標の合計が勝ち/引き分け/負けの構造によって完全に固定されているかどうかをチェックすることになります。 そうであれば、答えはユニークです。 それ以外の場合は、複数の分解が存在します。

 ## アルゴリズムのチュートリアル

 各テスト ケースを個別に処理し、タプルが一意の分解を許容するかどうかを判断します。 

1. 合計一致数を N = W + D + L として計算します。N が 0 の場合、唯一の有効な構成は空であり、一意性はゴールが 0 かどうかに完全に依存します。 G_f と G_a が両方ともゼロの場合、分解は自明に一意です。 そうでなければ不可能です。 
2. 目標構造の実現可能性を確認します。 有効な試合セットはいずれも、弱い意味で G_f ≥ 勝利数および G_a ≥ 敗北数を満たさなければなりません。これは、勝利にはどこかで少なくとも 1 つのゴールが必要であり、負けには少なくとも 1 つのゴールが必要であるためです。 これに違反すると、割り当ては存在しません。 
3. 描画がすべての自由度を消費するかどうかを判断します。 引き分けの場合は両チームに等しいゴールが与えられますが、プラスのゴールが許可された場合はさまざまな方法で分割される可能性があります。 D > 0 で、G_f または G_a のいずれかが一致間の再分配を可能にするのに十分な大きさである場合、複数の分解が直ちに存在します。 
4. すべての一致が強制されているかどうかを確認します。 一意性は、すべての試合結果に強制的な最小限の得点パターンがある場合にのみ発生します。 

勝利はすべて 1-0 でなければなりません。 

損失はすべて0-1でなければなりません。 

引き分けはすべて 0-0 でなければなりません。 

この制約の下では、合計は次の条件を満たす必要があります。 

G_f = W および G_a = L。 
5. 両方の等式が成り立ち、引き分けがない場合には柔軟性がもたらされ、「Amazing」を返します。 それ以外の場合は、「次回も頑張ってください」を返します。 

### なぜ効果があるのか

 重要な不変条件は、各試合タイプが一定の最小ゴール貢献度を貢献するが、総ゴール数に余裕があると再分配の自由度が生じるということです。 G_f が W を超えるか、G_a が L を超えるとすぐに、一部の試合では強制最小値を超える追加ゴールを実行する必要があります。 この追加容量は、W、D、L を維持しながら一致間でシフトでき、少なくとも 2 つの異なる有効な分解が生成されます。 両方の目標の合計が強制された最小構成と正確に一致する場合にのみ、分解は厳密になり、一意性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        W, D, L, Gf, Ga = map(int, input().split())

        n = W + D + L

        # no matches
        if n == 0:
            if Gf == 0 and Ga == 0:
                out.append("Amazing")
            else:
                out.append("Better luck next time")
            continue

        # minimal forced goals assumption
        min_gf = W
        min_ga = L

        if Gf < min_gf or Ga < min_ga:
            out.append("Better luck next time")
            continue

        # uniqueness only when no slack exists
        if Gf == min_gf and Ga == min_ga:
            out.append("Amazing")
        else:
            out.append("Better luck next time")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装は、一貫した分解において、勝利は少なくとも 1 つのゴールに貢献し、負けは少なくとも 1 つのゴールに貢献するという考えに従います。 提供された合計をこれらの強制最小値と比較します。 過剰がある場合、その過剰は W、D、L に影響を与えることなく一致間で再分配できます。これは、複数の有効な構成を即座に意味します。 

一致しない特殊なケースは、最小限の制約が崩壊し、ゼロのゴールのみが有効であるため、明示的に処理されます。 

よくある間違いは、目標の実現可能性を強制せずに、W + D + L の一貫性のみを使用しようとすることです。 これにより、不可能な状態を有効としてマークすることができます。 もう 1 つの微妙な問題は、ドローによってゴールがまったく制約されないことを忘れていることです。つまり、すべてがすでに平等に固定されていない限り、ゼロ以外のドロー数によって柔軟性が高まることを意味します。

## 特殊なケース

 W = D = L = 0 のようなゼロ一致の場合は、構造制約がなくなるため特別です。 目標もゼロの場合、有効な分解は 1 つだけあり、一致はまったくありません。 いずれかのゴール合計がゼロ以外の場合、すべての試合で少なくとも 0 ゴールが寄与しますが、既存の試合がなければゼロ以外の集計を生成できないため、試合結果を割り当てる方法はありません。 

W = 2、L = 2 など、勝ち負けのみのケースは、ゴールが最小パターンと正確に一致する場合にのみ厳密です。 Gf または Ga が大きい場合、少なくとも 1 つの一致を拡張しながら別の一致を補償し、複数の有効な構造を作成できます。 

引き分けの場合には、最も強いあいまいさが生じます。 引き分けは得失点差を制限しないため、合計が最小強制構造に正確に固定されていない限り、試合全体でのプラスのゴール配分は、W、D、L を維持しながら再配置できることがよくあります。
