 ## 解決策
 ## 問題の理解

 数直線上には有限の点の集合が 2 つあります。 1 つのセットは鳥の位置を表し、もう 1 つのセットはカメラの位置を表します。 すべてのカメラを正または負の同じ整数オフセットでシフトすることができ、カメラ構成全体をラインに沿って厳密に効果的に変換できます。 このシフトの後、鳥が少なくとも 1 つのカメラ位置と正確に一致する場合、その鳥は「捕らえられた」と見なされます。 

タスクは、あるカメラ位置に正確に横たわっている鳥の数が最大になるように変換を選択することです。 

問題を言い換える有効な方法は、違いの観点から考えることです。 鳥がその位置にいる場合`a`そしてカメラが所定の位置にあります`b`次に、すべてのカメラをある値だけシフトした後、`x`、それらは正確に一致します`a = b + x`、または同等の`x = a - b`。 これは、鳥とカメラの各ペアが、それらを位置合わせするための特定のシフト値を提案することを意味します。 

答えは、すべてのペアごとの差の中で最も頻繁に現れるシフト値です。 

制約は二次解としては十分小さいものです。 と`n, m ≤ 1000`、ペアの総数は最大 100 万です。 率直な`O(nm)`計算は Python の制限内に十分収まっており、より重いデータ構造や漸近的に高速なテクニックは必要ありません。 

主な微妙な点は、複数の鳥やカメラが同じシフトに独立して同意できることを理解していることです。 これは、ペアを選択しているのではなく、単一のグローバル翻訳に一致する鳥の数を数えていることを意味します。 単純な間違いは、各カメラを貪欲に一致させようとしたり、シフトをシミュレートして重複を繰り返し確認したりすることです。 どちらのアプローチでも、二重にカウントされるか、同じアライメントを何度も再計算するリスクがあります。 

単純なシミュレーション アプローチの具体的な失敗例は、多くのシフトによって部分的なオーバーラップが生成される場合です。 たとえば、鳥`[1, 3, 5]`そしてカメラは`[2, 4]`シフトを許可する`-1, -3, 1, ...`完全な再計算を使用して各シフトを個別に試行すると、たとえ`nm`小さいです。 

もう 1 つの間違いは、これを区間の重複問題として扱い、ウィンドウの並べ替えやスライドを試みることです。 これは、位置合わせが相対的な順序ではなく、変換後の正確な同等性に依存するため、失敗します。 

## アプローチ

 ブルートフォース手法では、考えられるすべてのシフト値を試し、シフトごとに、何羽の鳥がシフトされたカメラと一致するかをチェックします。 すべての候補シフトを考慮すると、それらは鳥とカメラの間の違いによって制限されるため、最大でも`n × m`可能性。 シフトごとに、すべての鳥をすべてのカメラに対してチェックすると、別の要素がかかり、`O(n^2 m^2)`最悪の解釈では、あまりにも遅すぎます。 

重要な観察は、実際にはシフトを明示的にシミュレートする必要がないということです。 それぞれの有効な配置は 1 つの違いによって決定されます`a[i] - b[j]`。 シフトの場合`x`を満たすすべてのペアが選択されます`a[i] - b[j] = x`は、そのシフトで捕らえられた鳥 1 羽だけを提供しますが、私たちが本当に望んでいるのは、シフトごとに、少なくとも 1 台のカメラに一致する鳥の数を数えることです。 鳥は別個であり、カメラも別個であるため、同じ鳥に複数のカメラを合わせても鳥の数は変わらないため、ここではペアを数えるだけで十分です。 

これにより、問題は差の頻度を計算し、最大頻度を取得することになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 完全チェックによるブルートフォースオーバーシフト | O(n²m²) | お(1) | 遅すぎる |
 | ペアごとの差を数える | O(nm) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各シフト値が発生する回数を保存する空のハッシュ マップを修正します。 それぞれのシフトは、少なくとも 1 つのペアが一致するようにカメラと鳥の位置を合わせる方法を表します。 
2. 鳥の位置ごとに`a[i]`、すべてのカメラ位置を反復します`b[j]`必要なシフトを計算します`x = a[i] - b[j]`。 このシフトは、まさにこの鳥がこのカメラと一致するようにすべてのカメラに適用する必要がある量です。 
3. 頻度を増やす`x`マップ内に 1 つずつ表示されます。 各増分は、そのシフトの下での 1 つの有効な鳥とカメラの位置合わせに対応します。 
4. すべてのペアを処理した後、度数テーブルをスキャンして最大値を取得します。 この値は、鳥とカメラのペアの最大数を揃えるシフトを表します。 
5. この最大周波数を答えとして返します。 

### なぜ効果があるのか

 各ペア`(a[i], b[j])`正確に 1 つのシフト値に寄与します。 シフトを固定したら`x`、すべてのペアと`a[i] - b[j] = x`そのシフトを適用すると整列されます。 それぞれの鳥とカメラの位置は固有であるため、寄与する各ペアは、そのシフトの下で撮影された個別の鳥に対応します。 したがって、特定のシフトでペアの数を最大化することは、捕獲された鳥の数を最大化することと同じです。 

このアルゴリズムは、明示的に列挙することなく、すべての可能な翻訳を暗黙的に検索します。 この正しさは、すべての有効な位置合わせが鳥とカメラの違いから生じているはずであり、そのようなすべての違いは 1 回だけ説明されるという事実から来ています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    freq = {}

    for i in range(n):
        ai = a[i]
        for j in range(m):
            diff = ai - b[j]
            freq[diff] = freq.get(diff, 0) + 1

    print(max(freq.values()))

if __name__ == "__main__":
    solve()
```実装の中核は、鳥とカメラを介したネストされたループです。 辞書`freq`各シフトのカウントを保存します。 使用する`ai - b[j]`特定のペアを調整するために必要な正確な変換を計算していることを保証します。 

一般的な実装の落とし穴は、減算の順序が逆になることです。 使用する`b[j] - a[i]`の代わりに`a[i] - b[j]`一貫して使用されている限り正確性が損なわれることはありませんが、規則を混合すると不正確な集計が発生します。 

もう 1 つの微妙な点は、すべてのカメラのシフトを明示的にシミュレートする必要がないことです。 翻訳は差分値に完全にエンコードされます。

| a[i] | b[j] | シフト x = a[i] - b[j] |

 | 1 | 5 | -4 |

 | 7 | 11 | -4 |

 すべてのペアに対してこのプロセスを続けると、シフトは`-4`が最も頻繁に現れます。 これは、複数のカメラが複数の鳥に合わせて配置される変換に対応します。 

トレースの蓄積:

 | シフト | カウント |
 | --- | --- |
 | -4 | 3 |
 | -2 | 1 |
 | -5 | 2 |

 最大値は`3`、したがって、答えは次のとおりです`3`。 

これは、アルゴリズムが個々のペアのマッチングではなく、翻訳によってアラインメントを効果的にグループ化していることを裏付けています。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    freq = {}
    for i in range(n):
        for j in range(m):
            d = a[i] - b[j]
            freq[d] = freq.get(d, 0) + 1

    return str(max(freq.values()))

 ## 特殊なケース

 1 羽の鳥と 1 台のカメラによる最小限の入力により、実装が自明な周波数マップを正しく処理するかどうかが明らかになります。 入力あり`1 1`と同じ位置にある場合、唯一のシフトは`0`、その答えは次のようになります。`1`。 ループは引き続き 1 回実行され、辞書には 1 つのエントリが記録されます。 

すべての鳥とカメラが遠く離れている場合は、負のシフトが正しく処理されるかどうかをテストします。 たとえば、鳥`[1, 100]`とカメラ`[50, 60]`シフトを生成する`-49, -59, 40, 50`、すべて別個であり、最大周波数は依然として`1`。 このアルゴリズムでは正の値が想定されていないため、負のキーも当然サポートされます。 

鳥のように整列したケース`[1,2,3]`とカメラ`[1,2,3]`ゼロシフトが何度も繰り返されます。 すべてのペアが同じキーに寄与します`0`、周波数は次のようになります。`9`これは、すべてのペアがゼロ平行移動の下で整列することを正しく反映しています。
