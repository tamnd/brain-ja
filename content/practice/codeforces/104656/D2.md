 ## 解決策
 ## 問題の理解

 金属タイプのコレクションが与えられました。 各金属には決定的なルールがあります。つまり、金属を 1 ユニット取得すると、それを破壊して他の 2 つの金属を 1 ユニットずつ取得できます。 これにより、すべてのノードが 2 つの出力エッジに分割される有向変換システムが定義されます。 

金属の初期在庫もございます。 目標は、これらの変換ルールを任意の順序で何度でも適用し、最終的に生産できる特定のターゲット金属、通常は「鉛」 (金属 1) の量を最大化することです。 

重要な観察は、すべての操作で総質量が保存され、再分配されるだけであるということです。 したがって、問題は量を蓄積することではなく、既存のユニットがメタル 1 に到達するか、メタル 1 に到達できないグラフの部分に引っかかるまで、有向システムを通じて既存のユニットをルーティングすることです。 

Code Jam スタイルの問題の D2 バージョンの制約には、通常、最大 2×10^5 の金属または変換が含まれるため、繰り返し変換のシミュレーションは即座に除外されます。 単一のユニットであっても長いチェーンまたはサイクルを通過する可能性があるため、段階的な伝播は遅すぎます。 

素朴な解釈では、各ユニットを個別にシミュレートし、それ以上の変化が発生しなくなるまで変換ルールを繰り返し適用します。 最悪の場合、単一のユニットが操作ごとに O(n) 状態を通過する可能性があり、O(n) 個のユニットが存在して O(n^2) 以上の動作が発生する可能性があり、これは実行不可能です。 

サイクルが存在する場合には、さらに微妙な障害が発生します。 たとえば、金属 A が B と C を生成し、B と C の両方が最終的に再び A を生成できる場合、慎重に制御しない限り、単純なシミュレーションは安定した結論に達せずに永遠にループする可能性があります。 

正しい出力は、最終的にメタル 1 に変換できる初期メタルの総量です。 

## アプローチ

 この強引なアイデアは、各ユニットから独立して変換をシミュレートすることです。 金属を取得するたびに、それをその 2 つの出力に置き換え、金属 1 に到達するか可能性を使い果たすまで続けます。 これは、考えられるすべての変換パスを調査するため、原則的には正しいです。 

ただし、各ユニットは分岐する可能性があり、重複するサブ問題全体で探索を繰り返すと指数関数的に爆発的に増加します。 ある金属が他の 2 つの金属に繰り返し変換できる場合、状態空間は二分木のように成長します。 メモ化しても、サイクルは単純な再帰を壊します。 

重要な構造的洞察は、金属が「どのように」鉛になるかは問題ではなく、金属がそもそも鉛になるかどうかだけを気にするということです。 すべての変換では、到達可能な状態間で質量を任意に分割する機能が維持されるため、問題は有向グラフの到達可能性に集約されます。 

各金属をノードとして解釈し、各変換を 2 つの有向エッジとして解釈すると、タスクはノード 1 に到達できるすべてのノードを識別するようになります。そのようなノードの初期ユニットは、最終的な答えに 1 ユニットだけ寄与します。 

循環下では到達可能性が不変であるため、循環は値の伝播にとって重要ではなくなりました。 強く接続されたコンポーネントは圧縮でき、結果として得られるグラフは、ノード 1 からのリバース BFS または DFS を使用して到達可能性をクリーンに計算できる DAG です。

 ## アルゴリズムのチュートリアル

 各金属が生成する 2 つの金属を指す有向グラフとしてシステムをモデル化します。

1. 逆隣接リストを作成します。 各変換 i → (a, b) に対して、反転グラフにエッジ a → i および b → i を追加します。 この反転は、どのノードが最終的にメタル 1 に到達できるかを計算するために使用されます。 
2. 反転したグラフのノード 1 からトラバースを開始します。 私たちが訪問するすべてのノードは、何らかの一連の操作を通じて最終的にメタル 1 に変換できるメタルを表します。 
3. BFS または DFS を使用して、この走査中に到達可能なすべてのノードをマークします。 訪問した各ノードは、その初期量全体が最終的な答えに寄与することが確認されます。 
4. すべての訪問ノードの初期数量を合計します。 この合計が、達成可能なリードの最大量です。 

エッジを反転する理由は、フォワード シミュレーションでは「ここから何を生み出すことができるか」という答えが得られる一方で、「リードで終了できるか」が必要であるためです。 逆にすると、質問が標準の到達可能性に変換されます。 

### なぜ効果があるのか

 各変換は、損失なしで 1 単位の質量のみを再分配します。 したがって、メタル i のユニットをメタル 1 に変換する一連の変換が存在する場合、中間の分岐に関係なく、そのユニットをリードに完全にルーティングできます。 逆に、そのようなパスが存在しない場合、一連の変換によってそのユニットからリードが生成されることはありません。 到達可能性はこのプロパティを正確に特徴付けるため、ノード 1 に到達できるすべてのノードをマークすると、完全なソリューション スペースが取得されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, m = map(int, input().split())
    
    # initial amounts of each metal (assumed from standard version)
    initial = list(map(int, input().split()))
    
    # each metal i produces (a, b)
    rev = [[] for _ in range(n)]
    
    for i in range(n):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        rev[a].append(i)
        rev[b].append(i)
    
    # BFS from lead (node 0)
    q = deque([0])
    vis = [False] * n
    vis[0] = True
    
    while q:
        u = q.popleft()
        for v in rev[u]:
            if not vis[v]:
                vis[v] = True
                q.append(v)
    
    ans = 0
    for i in range(n):
        if vis[i]:
            ans += initial[i]
    
    print(ans)

if __name__ == "__main__":
    solve()
```この実装は、逆到達可能性のアイデアを直接反映しています。 唯一の微妙な部分は、反転グラフを正しく構築することです。変換ごとにエッジを反転して、「リードに到達できる」情報を外側に伝播できるようにします。 

BFS は各ノードが 1 回処理されることを保証し、循環コンポーネントでの冗長な探索を防ぎます。 

## 実用的な例

 ### 例 1

 金属が 3 つあり、金属 1 が鉛であるとします。 メタル2は1と3に、メタル3は2と1に変身できます。初期量は`[5, 3, 2]`。 

逆エッジを構築し、ノード 1 から BFS を開始します。 

| ステップ | キュー | 訪問 |
 | --- | --- | --- |
 | 開始 | [1] | {1} |
 | 訪問 1 | [2、3] | {1,2,3} |
 | 訪問 2 | [3] | {1,2,3} |
 | 訪問 3 | [] | {1,2,3} |

 すべてのノードが到達可能であるため、答えは 5 + 3 + 2 = 10 となります。 

これは、サイクルが単一の到達可能な領域にどのように崩壊するかを示しています。 

### 例 2

 金属 2 と 3 が相互に変換するだけで、1 に到達しない場合を考えてみましょう。金属 1 だけが自己完結しています。 

| ステップ | キュー | 訪問 |
 | --- | --- | --- |
 | 開始 | [1] | {1} |
 | 終わり | [] | {1} |

 金属 1 のみが寄与するため、答えは頭文字 [1] だけです。 

これは、内部サイクルに関係なく、到達不能なコンポーネントは何も寄与しないことを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

 この制約により、最大数十万のノードとエッジが許可されるため、線形グラフの走査は制限内に快適に収まります。

## 特殊なケース

 クリティカルなエッジ ケースは、メタル 1 を含む完全に周期的なコンポーネントです。その場合、サイクル内のすべてのノードが到達可能としてマークされている必要があります。これは、いずれかのノードが、繰り返しの変換を通じて最終的に質量をリードにルーティングする可能性があるためです。 

もう 1 つのエッジ ケースは、複数のコンポーネントが存在するが、そのうちの 1 つだけがメタル 1 に接続する、切断されたグラフです。ノード 1 からの BFS が他のコンポーネントに入ることはないため、アルゴリズムはこれを自然に処理します。 

最後の微妙なケースは、金属がそれ自身と別の金属を生成する自己ループです。 自己ループは到達可能性に影響しません。 これらは、ノードが独自の到達可能なコンポーネント内に留まることを強化するだけです。
