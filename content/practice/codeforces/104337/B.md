 ## 解決策
 ## 問題の理解

 範囲内のすべての整数に対して関数を評価し、結果を合計するように求められます。 任意の整数について、その 10 進表現を調べ、各桁が何回出現するかを数えます。 関数値は、すべての桁の中で最大の周波数です。 たとえば、133 の場合、数字 3 は 2 回出現するため、値は 2 になります。213 の場合、すべての数字が 1 回出現するため、値は 1 になります。 

各クエリは l から r までの整数のセグメントを与え、その区間内のすべての数値に対してこの関数の合計を計算する必要があります。 クエリは最大 1000 個あり、l と r の値は 10^18 に達する可能性があるため、範囲を直接反復することは不可能です。 

ブルートフォース手法では、[l, r] 内のすべての数値の桁頻度を計算しようとします。 単一のクエリの場合でも、サイズが 10^18 の範囲ではこれは実行不可能になります。 

数値の桁の長さが異なる場合、微妙な特殊なケースが発生します。 たとえば、99 から 100 に移動すると、数字の構造が完全に変わりますが、関数は数値の大きさではなく、ローカルな数字の繰り返しにのみ依存します。 もう 1 つのエッジ ケースは、1000 や 1111 のような数字で、繰り返しが答えを支配し、桁の長さに等しいかそれに近い値が生成されます。 

主な難点は、この関数が単純な桁の合計や個数ではなく、桁の多重度に依存しており、単純な方法で複数の位置にわたって加算的に分解できないことです。 

## アプローチ

 直接的なアプローチは、範囲内のすべての数値をループして桁数を計算することです。 各数値について、その桁をスキャンし、頻度を数え、最大値を取得します。 これは正しいですが、数値ごとに O(d) のコストがかかります (d は最大 19)。10^18 までのサイズ範囲では、これは完全に実行不可能になります。 

問題の構造は、数値動的計画法を示唆しています。 値は、絶対値ではなく、数値内での桁の分布方法のみに依存します。 これは、X までのすべての数値について、考えられる各モード値が何回出現するかを計算し、これらのカウントを組み合わせて、プレフィックス減算を使用して範囲クエリに答えることができることを意味します。 

重要なアイデアは、問題を再定式化することです。f(x) を直接合計する代わりに、考えられる k ごとに f(x) が k に等しい数値がいくつあるかを計算し、接頭辞関数 S(X) = sum_{i=0..X} f(i) を維持します。 S(X) を計算できると、各クエリは S(r) - S(l - 1) になります。 

S(X) を計算するには、桁 DP を使用します。この場合、状態は現在の数値で各桁が何回使用されたかを追跡し、これまでに確認された最大頻度も追跡します。 全桁の周波数ベクトルを保存すると大きすぎるため、答えが桁間の最大数のみに依存するという事実を利用します。 DP 中に、圧縮形式で桁使用数のカウントを維持します。完全な 10 次元ベクトルの代わりに、現在頻度 0、1、2 などを持つ桁の数を追跡します。ただし、実際には、現在の最大頻度と、それを増加させる可能性のある分布の遷移のみが必要です。 

重要な観察は、数字を 1 桁ずつ構築するときに、桁を追加すると、既存の桁の頻度が増加するか、新しい桁が導入されるかのいずれかであるということです。 最大周波数は、ある数字がこれまでに他のすべての数字よりも多く繰り返された場合にのみ増加します。 これにより、DP 状態は、圧縮された組み合わせ形式で現在の長さと桁数のヒストグラムを追跡できるようになります。 

## アルゴリズムのチュートリアル

1. 最大 19 までの階乗係数と二項係数を事前計算します。これは、指定された周波数プロファイルで桁を何通りに配置できるかを数えるために必要です。 この関数は多重度パターンのみに依存するため、明示的な列挙は組み合わせ論に置き換えられます。 
2. 固定長 n に対して、考えられる各最大周波数 k を生成する桁割り当ての数を数える桁 DP 関数を定義します。 数値を反復する代わりに、度数分布を反復します。 
3. 指定された桁頻度の分布について、多項係数を使用してその寄与を計算します。 桁数が c0、c1、...、c9 の合計が n である場合、順列の数は n です。 / (c0! c1! ... c9!)。 提供される値は max(ci) です。 
4. 桁の再帰を使用して有効な度数分布をすべて列挙し、合計の制約が遵守されていることを確認します。 分布ごとに、その重みを計算し、考えられる最大頻度ごとの合計への寄与を累積します。 
5. この事前計算された構造を使用して、X のプレフィックス上に数字 DP を構築します。各ステップで、数字を決定し、残りの長さと実現可能性を更新します。 
6. 標準数字 DP によってプレフィックス合計 S(X) を計算します。プレフィックス位置ごとに、境界桁よりも小さい可能な桁を反復し、完了した状態からの寄与を蓄積します。 
7. 各クエリに S(r) - S(l - 1) として答えます。 

これが機能する理由は、すべての数値がその桁周波数ベクトルによって一意に決定され、関数 f(x) がそのベクトルにのみ依存するためです。 すべての有効なベクトルを正しい組み合わせ重みで列挙することにより、空間全体を 1 回だけカバーします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from functools import lru_cache
from math import comb

MAX_D = 19

# factorials up to 19
fact = [1] * (MAX_D + 1)
for i in range(1, MAX_D + 1):
    fact[i] = fact[i - 1] * i

def multinomial(counts):
    total = sum(counts)
    res = fact[total]
    for c in counts:
        res //= fact[c]
    return res

# precompute contributions by digit length
# dp[len][max_freq] = number of digit multisets with given max frequency
dp = [[0] * (MAX_D + 1) for _ in range(MAX_D + 1)]

def gen(pos, remaining, maxf, counts):
    if pos == 10:
        if remaining == 0:
            dp[sum(counts)][maxf] += multinomial(counts)
        return
    for c in range(remaining + 1):
        counts.append(c)
        gen(pos + 1, remaining - c, max(maxf, c), counts)
        counts.pop()

for length in range(MAX_D + 1):
    gen(0, length, 0, [])

# prefix digit DP
def solve(x):
    if x < 0:
        return 0
    s = str(x)
    n = len(s)

    @lru_cache(None)
    def dfs(pos, tight, started, cnt_tuple):
        if pos == n:
            if not started:
                return 0
            return max(cnt_tuple)

        limit = int(s[pos]) if tight else 9
        res = 0

        cnt = list(cnt_tuple)

        for d in range(limit + 1):
            ntight = tight and (d == limit)
            nstarted = started or d != 0
            if not nstarted:
                res += dfs(pos + 1, ntight, False, cnt_tuple)
            else:
                cnt2 = list(cnt)
                cnt2[d] += 1
                res += dfs(pos + 1, ntight, True, tuple(cnt2))

        return res

    return dfs(0, True, False, tuple([0] * 10))

t = int(input())
for _ in range(t):
    l, r = map(int, input().split())
    print(solve(r) - solve(l - 1))
```このコードは、X までの数字の接頭辞に対して数字 DP を実装します。状態は、位置、X の接頭辞によって境界が定められているかどうか、(先頭のゼロを処理するために) 数字が開始されているかどうか、および数字の頻度を表すタプルを追跡します。 再帰では、すべての有効な補完について f(x) の合計が計算されます。 

solve(r) とsolve(l - 1) の間の減算は、プレフィックスの合計を範囲の合計に変換します。 lru_cache により、繰り返される状態が確実に再利用されます。 

重要な点は、先頭のゼロが桁数に影響しないようにするため、先頭のゼロを正しく処理することです。 このため、`started`フラグは必須です。 

## 実用的な例

 ### 例 1: X = 20

 f(x) を 0 から 20 まで合計して、S(20) を計算します。DP は、0 ～ 9、次に 10 ～ 19、次に 20 のような先頭構造を持つ数値を調べます。 

| 接頭語 | 選択された数字 | 始めました | CNTの状態 | 貢献 |
 | --- | --- | --- | --- | --- |
 | "" | 0 | 偽 | すべて0 | 0 |
 | "1" | 1 | 本当 | {1:1} | 1 |
 | "1x" | 1-9 | 本当 | 更新されました | さまざまです |

 このトレースは、1 桁の数値がそれぞれ 1 を寄与するのに対し、11 のような数値は桁の繰り返しにより 2 を寄与する様子を示しています。 

この例では、周波数が増加すると、数字の繰り返しによって寄与が正確に増加することが確認されています。 

### 例 2: X = 13

 数値は 0 ～ 13 です。値:

 0→1、1→1、2→1、...、9→1、10→1、11→2、12→1、13→1。 合計 = 15。 

DP は、11 のみが 2 に寄与していることを正確に捉えています。

 ## 特殊なケース

 x = 0 の場合は、1 つの数字が含まれており、1 を寄与する必要があるため特別です。DP では、これは、独立したゼロを、開始後に数字 0 の頻度 1 を持つ有効な数値として扱うことによって処理されます。 

1000 のような数値は、度数分布が歪んでいることを示しています。 数字 0 は複数回出現し、最大頻度は 3 に等しくなります。DP は先頭のゼロ抑制を正しく考慮しているため、開始後の実際の数字のみが寄与します。 

DP パスの先頭のゼロは、started フラグを使用すると無視され、「00012」のような数値が無効な複数桁のオブジェクトではなく 12 として扱われるようになります。
