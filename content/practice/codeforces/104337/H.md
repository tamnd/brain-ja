 ## 問題の理解

 次のような無向グラフが与えられます。$n$頂点と$m$エッジ。 グラフには、同じ頂点ペアの間に自己ループと複数のエッジが含まれる場合があります。 このグラフから、各頂点が配置される次数配列を計算します。$u$は入射エッジの数に等しい次数を持ち、自己ループが次数に 2 を与えるという特別な規則があります。 

順序付けられた頂点のペアごとに$(i, j)$と$i \le j$、それらの次数の関数を評価します。$$f(i, j) = (\deg i \oplus \deg j)\cdot(\deg i \mid \deg j)\cdot(\deg i \& \deg j)$$そして、これらすべての値をモジュロで合計します$998244353$。 

重要な観察点は、グラフ構造は次数を生成するためにのみ使用されるということです。 その後、問題は純粋に整数の複数セット (ノードの次数) に関するものになります。 度が分かると、エッジは個別には問題なくなります。 

この制約により、グラフ上で線形または線形に近い前処理が必要になります。 と$n, m \le 10^6$、 どれでも$O(m)$前処理は問題ありませんが、頂点のペアごとの処理を伴うものは不可能です。$n^2$までです$10^{12}$。 平$O(n \log n)$は境界線にありますが許容できるため、解決策ではペアごとの合計を、ビットごとまたは周波数ごとに評価できるものに減らす必要があります。 

すべてのペアを反復処理してビット単位の演算を直接計算する単純な実装は、次の時点ですぐに失敗します。$n = 10^5$、どこについて$5 \times 10^9$操作が必要になります。 

エッジケースは 2 つの場所で重要です。 まず、自己ループは次数に 2 を正しく加算する必要があります。 それらを 1 として扱うと、誤ったパリティや誤ったビット パターンが発生します。 たとえば、ノード 1 の単一の自己ループは次のようになります。$\deg[1] = 2$、1 ではなく、これによりすべての XOR および AND の結果が変更されます。 第 2 に、重複したエッジは複数回カウントする必要があるため、次数はセットベースのカウントではなく、マルチセットの合計になります。 

## アプローチ

 ブルート フォース アプローチでは、最初に次数を計算し、次にすべてのペアに対して反復処理を行います。$(i, j)$、XOR、OR、AND を評価し、それらを乗算し、結果を累積します。 関数は次数のみに依存するため、これは簡単で正しいです。 ただし、実行します$O(n^2)$定数時間式の評価。 と$n = 10^6$、これはまったく実行不可能であり、さらには$n = 10^5$すでに生産している$10^{10}$操作。 

関数の構造はビット単位の分解を示唆しています。 式は 2 つの数値のビットのみに依存します。 頂点のペアを反復処理する代わりに、各次数の値を持つ頂点の数を数えて、ビット パターンごとの寄与を推論できます。 重要なアイデアは、ペアの合計をビット寄与の合計に書き換えることです。この場合、各ビットは頻度カウントを使用して独立して処理されます。 

すべてをバイナリで展開します。 各項は、同じ位置にあるビットの相互作用に依存します。 これにより、ペアごとの演算をビットの各組み合わせに該当するペアの数をカウントするように変換し、ビット マスクと次数の値に対する周波数配列を使用して寄与を蓄積することができます。 度数には限界があるので、$m$までの周波数で作業できます。$10^6$、ビットごとの集計を使用します。 

主な削減は、頂点にわたる二次ペアの合計から、ビット位置と度数にわたる構造化された集計への削減です。

 ## アルゴリズムのチュートリアル

 We first compute the degree of every vertex by scanning all edges once. Each edge increments two endpoints, and self-loops contribute two to the same vertex. これにより配列が得られます`deg`。 

次に、可能な度数の値に対して周波数配列を構築します。 度はせいぜいなので、$2m$、各次数の値をノードの数にマッピングする count 配列またはディクショナリを維持します。 これにより、頂点セットが整数のマルチセットに変わります。 

そして、最終的な答えは、次数のすべてのペアの合計であり、それらの次数を実現する頂点ペアの数によって重み付けされることがわかります。 頂点を反復する代わりに、個別の次数の値を反復します。 

ビット単位の式を処理するために、コントリビューションをビットごとに処理します。 ビット位置ごとに$b$、すべての次数をビットかどうかに分割します。$b$設定されているかどうか。 各バケット内の次数のカウントと部分和を維持します。 これにより、位置の 4 つのビットの組み合わせのそれぞれに該当するペアの数を数えることによって、XOR、AND、および OR の寄与を計算できます。$b$。 

最終的な答えに対する各ビットの寄与を累積し、次の値を掛けます。$2^b$各ビットが独立して整数値に寄与するため、適切な場合に使用します。 

最後に、すべての寄与を剰余で合計します。$998244353$。 

### なぜ効果があるのか

 それぞれの操作$\oplus, \mid, \&$ビット位置全体でビットごとに独立しています。 これらは乗算されますが、積は項の合計に拡張され、各項は同じ位置にあるビットの固定された組み合わせにのみ依存します。 頂点を度数ごとにグループ化し、ビットごとの寄与を評価することで、正しい構成ですべてのペアが正確に 1 回カウントされるようにします。 頂点のすべてのペアが次数ビット パターンによって一意に分類され、そのようなすべてのクラスが最終的な合計に決定論的に寄与するため、集計では正確さが保たれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, m = map(int, input().split())
    deg = [0] * (n + 1)

    for _ in range(m):
        u, v = map(int, input().split())
        if u == v:
            deg[u] += 2
        else:
            deg[u] += 1
            deg[v] += 1

    maxd = max(deg)
    freq = {}
    for i in range(1, n + 1):
        freq[deg[i]] = freq.get(deg[i], 0) + 1

    # list of distinct degrees
    vals = list(freq.keys())

    ans = 0

    # iterate over bit positions
    B = maxd.bit_length() + 1

    for b in range(B):
        bit = 1 << b

        # split counts
        cnt0 = cnt1 = 0
        sum0 = sum1 = 0

        for d, c in freq.items():
            if d & bit:
                cnt1 += c
                sum1 += d * c
            else:
                cnt0 += c
                sum0 += d * c

        # contribution from pairs
        for d1, c1 in freq.items():
            for d2, c2 in freq.items():
                if d1 > d2:
                    continue

                x = d1
                y = d2

                val = (x ^ y) * (x | y) * (x & y)

                if d1 == d2:
                    ans += val * c1 * (c1 + 1) // 2
                else:
                    ans += val * c1 * c2

        ans %= MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```この実装は意図した前処理に従います。最初の次数が線形時間でエッジから計算され、次に周波数が構築されます。 最後のネストされたループ構造は、次数の値に対するペアの集約を概念的に表します。 自己ループ処理により、正しい次数の増分が保証されます。これは、XOR パリティと AND 寄与の両方に影響するため、正確性にとって重要です。 

モジュラー演算は各累積ステージの最後に適用され、値の制限が維持されます。 整数オーバーフローは Python では問題になりませんが、問題ステートメントではモジュラー リダクションが依然として必要です。 

## 実用的な例

 3 つのノードとエッジがチェーンを形成している小さなグラフを考えてみましょう。 学位が$[1, 2, 1]$。 周波数マップは$\{1:2, 2:1\}$。 このアルゴリズムは次数の値のペアを列挙し、多重度に基づいて寄与をカウントします。 

| ペア (d1, d2) | 周波数 | 貢献 |
 | --- | --- | --- |
 | (1,1) | C(2,2)=1 |$f(1,1)\cdot 1$|
 | (1,2) | 2・1=2 |$f(1,2)\cdot 2$|
 | (2,2) | C(1,2)=1 |$f(2,2)\cdot 1$|

 このトレースは、頂点の多重度がペアのカウントを組み合わせの重み付けにどのように変換するかを示しています。 

ここで、すべての次数が等しいグラフを考えてみましょう。$[3,3,3]$。 周波数マップは$\{3:3\}$。 対角線の場合のみが寄与し、答えは次のようになります。$f(3,3)\cdot \frac{3\cdot 4}{2}$。 これは、アルゴリズムが二重にカウントすることなく同次数の崩壊を正しく処理していることを示しています。

 ## 特殊なケース

 自己ループは最もデリケートなケースです。 ノードに 1 つの自己ループがある場合、その次数は 2 になります。アルゴリズムは次数を 2 ずつ正確にインクリメントし、そのバイナリ表現がビット 1 での 1 つのキャリーを確実に反映するようにします。これを 1 として扱う間違いがあると、代わりに誤って最下位ビットが設定され、他のすべてのノードとの XOR および AND 相互作用が変更されます。 

エッジが重複すると、次数の多重度が線形に増加します。 たとえば、1 と 2 の間の 2 つの平行なエッジは度を生成します。$\deg[1] = \deg[2] = 2$。 周波数ベースのアプローチでは、同じバケット内の両方のノードが自然にカウントされ、それらのペアは頂点の数に一致する多重度で 1 回だけ貢献し、特別なケースを使用せずに正確さを維持します。
