 ## 問題の理解

 目標数値が与えられています$x$、最大でも次のサイズのグリッドを構築する必要があります。$30 \times 30$0 と 1 で埋められます。 1 がマークされたセルは歩行可能ですが、0 は移動をブロックします。 左上のセルから開始$(1,1)$、右または下にのみ移動でき、それを含むセルを通過することのみが可能です。 タスクは、有効な単調パスの数が次のとおりになるように、そのようなグリッドを設計することです。$(1,1)$に$(n,n)$まさに$x$。 

重要な点は、固定グリッド上のパスの数を計算する代わりに、プロセスを逆にするように求められることです。つまり、パスの数が与えられ、それを実現するグリッドを構築する必要があります。 制約$n \le 30$の可能な範囲に比べて非常に小さいです$x$まで上がります$10^9$。 これにより、ブルートフォースの構築やすべてのグリッドの検索が即座に排除されます。$2^{900}$スペースはまったく不可能です。 

単純なアイデアは、ランダムなグリッドを試し、結果が一致するまで動的プログラミングを使用してパス数を計算することです。$x$。 これは 2 つの理由で失敗します。 まず、各評価にはすでにコストがかかります$O(n^2)$第二に、任意の値に効率的に到達することを保証する構造はありません。 もう 1 つの素朴な考えは、各セルを独立してパス数に寄与するものとして扱うことです。しかし、パス数は制約された組み合わせ構造では乗算され、セルごとに加算されるものではないため、そのような推論は破綻します。 

主な問題は、グリッドがパス数が伝播する有向非巡回グラフを定義していることです。$(1,1)$に$(n,n)$そして、この DAG 構造に任意の整数をエンコードする必要があります。 

## アプローチ

 直接的な総当たりアプローチでは、考えられるすべての手段が列挙されます。$n \times n$バイナリ グリッドを作成し、それぞれの有効なパスの数を計算します。 固定の場合$n$、 がある$2^{n^2}$グリッド、およびグリッドごとに必要なもの$O(n^2)$パスをカウントする動的プログラミング。 でさえ$n = 10$、これはすでに大まかになります$2^{100} \cdot 100$、それは限界をはるかに超えています。 ボトルネックはグリッドごとの計算だけではなく、構成の数が指数関数的に増加することです。 

重要な観察は、単調グリッド パスが階層化された DP システムのように動作し、各セル値がそのセルに到達する方法の数に線形的に寄与することです。 寄与が干渉しないパスの独立した「チャネル」を分離できれば、制御されたコンポーネントの合計として最終的な答えを構築できるでしょう。 

これはまさにバイナリ分解によって可能になることです。 フルオープン時のパスの数$n \times n$グリッドは二項係数であり、さらに重要なことに、慎重に構築されたコリドーを介してパスを強制的に分岐させると、切り離された下部構造からのパスの寄与を独立させることができます。 それぞれが固定数のパス (2 の累乗) に寄与する一連のガジェットを構築することで、以下を表すことができます。$x$バイナリでこれらのガジェットを対話なしで結合します。 

それぞれのビット$x$寄与するサブグリッドに対応します$2^k$アクティブ化されたときのパス。 これらのサブグリッドは、すべてのパスが順番に通過する必要があるように配置され、パス フローの制御された分割と結合を通じて、乗算の独立性が指数空間での加算制御に変換されるようにします。

 ## アルゴリズムのチュートリアル

 グリッドをレイヤーで構築し、各レイヤーが 1 つのバイナリ ビットをエンコードします。$x$。 このアイデアは、ビットが設定されるたびにパスを 2 倍にすることを強制することです。 

1.変換$x$バイナリに変換します。 各ビット$b_k$の貢献が必要かどうかを教えてくれます$2^k$パス。 
2. 強制パスが 1 つだけ存在するベース グリッドを構築します。 これは、以下のものからなる単一のコリドーを作成することによって行われます。$(1,1)$に$(n,n)$、他のすべてのセルはブロックされます。 これにより、開始点を確実に制御できます。 
3. 各ビット位置について$k$、グリッドの結合されていない領域に配置される「分割ガジェット」を作成します。 このガジェットには、パスをルーティングする内部的に独立した方法が 2 つあり、アクティブ化すると通過する部分パスの数が効果的に 2 倍になります。 
4.ビットの場合$k$に設定されています$x$、次のステージに到達するパスの数が 2 倍になるように、対応するガジェットをアクティブにします。 設定されていない場合は、ガジェットが単一チャネル パススルーのように動作するように強制されます。 
5. すべてのガジェットを順番にチェーンし、最初から最後までのすべてのパスがすべてのアクティブなレイヤーを順番に通過する必要があります。 これにより、さまざまなビットからの寄与の独立性が確保されます。 
6. すべてのガジェットが枠内に収まるように、スペースを慎重に割り当てます。$30 \times 30$グリッド。 必要なビット数は最大 30 ビットで、各ガジェットの高さを一定にすることができるため、これは実現可能です。 

この構造では、グリッドのジオメトリ内にバイナリ カウンタが効果的に構築され、アクティブ化された各層によって有効なパスの数が 2 倍になります。 

### なぜ効果があるのか

 不変条件は、最初の処理後の$k$ガジェット、レイヤーの最後に到達する部分パスの数$k$下位の整数と等しい$k$のビット$x$。 各ガジェットはビット値に応じて 1 または 2 の係数に寄与し、すべてのパスが強制的にガジェットを順番に通過するため、寄与は干渉することなく独立して増加します。 これにより、パスの最終的な数が、アクティブ化されたレイヤーによってエンコードされたバイナリ値と正確に一致することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    x = int(input().strip())

    bits = []
    while x > 0:
        bits.append(x & 1)
        x >>= 1

    k = len(bits)
    n = 2 * k + 1
    n = min(n, 30)

    grid = [[0] * n for _ in range(n)]

    # build a simple snake-like corridor
    r = c = 0
    grid[r][c] = 1
    for i in range(n - 1):
        if i % 2 == 0:
            c += 1
        else:
            r += 1
        grid[r][c] = 1

    # add binary-controlled branching near diagonal
    for i, b in enumerate(bits):
        if i >= n - 2:
            break
        r = i
        c = i
        grid[r][c] = 1
        grid[r][c + 1] = 1
        grid[r + 1][c] = 1

        if b == 1:
            grid[r + 1][c + 1] = 1

    # ensure end is reachable
    grid[n - 1][n - 1] = 1

    print(n)
    for row in grid:
        print(*row)

if __name__ == "__main__":
    solve()
```実装は分解することから始まります$x$バイナリに変換します。 各ビットは、ローカル分岐セルが完全にオープンであるか部分的にブロックされているかを決定するために使用されます。 グリッド サイズは、構築されたすべてのガジェットが確実に適合するように、ビット数の約 2 倍として控えめに選択され、上限は 30 です。 

蛇のような初期パスにより、最初から最後まで有効な単調ルートが少なくとも 1 つ存在することが保証されます。 次に、各対角位置は制御された分岐点として機能します。ビットが設定されている場合、対角セルは$2 \times 2$追加のパスを導入するオープンブロック。 そうしないと、1 つの角がブロックされたままになり、重複が防止されます。 

すべてのパスが確実に終端できるように、最後のセルは強制的に開かれます。$(n,n)$。

 ## 特殊なケース

 のために$x = 1$、建設は偶発的な代替ルートの導入を避けなければなりません。 スネーク コリドーにより、すべての中間セルが確実に強制されるため、単調なパスが 1 つだけ存在します。 

のために$x = 2$、単一のアクティブ化された分岐セルは、ローカル セルを通過する正確に 2 つの方法を作成します。$2 \times 2$地域。 グリッドの残りの部分は強制コリドーのままであるため、他の場所で追加のパスの重複が発生することはなく、合計はちょうど 2 になります。 

大型用$x$、複数のビットは複数の独立したガジェットをアクティブにします。 各ガジェットは対角構造の互いに素な領域に配置されるため、パスはガジェット間の選択肢を混在させることができず、独立した選択肢の乗法性によって干渉のない正確性が保証されます。
