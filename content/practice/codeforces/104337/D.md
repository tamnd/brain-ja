 ## 解決策
 ## 問題の理解

 無限の整数グリッド上に、最初は黒い格子点の有限セットが与えられます。 時間は離散的なステップで進化します。 各ステップで、その 4 つの直交する隣接セルのうち少なくとも 2 つがすでに黒であれば、白セルは黒になります。 一度細胞が黒くなると、その細胞は永久に黒のままになります。 タスクは、プロセスが安定した後に黒のセルの数を判断することです。 

重要な問題は、このプロセスが初期点のみに局所的ではないことです。 新しく作成された黒セル自体がさらなるセルの作成に役立つため、最終セットは、単一ステップの近傍計算ではなく、幾何学的伝播ルールに基づく閉包となります。 

入力サイズでは最大 100,000 ポイント、最大 1e9 の大きさの座標が許可されます。 これにより、グリッド上のシミュレーションや、空間内で近隣を動的に探索しようとするアプローチが即座に排除されます。 グリッドには境界がなく、到達可能な領域が座標の広がりで二次になる可能性があるため、訪問したグリッド セルを明示的に格納することさえ不可能です。 

意図したソリューションは、初期構成の組み合わせ構造のみを使用して、入力ポイント全体にわたってほぼ線形またはほぼ線形の時間で機能する必要があります。 

縮退構成では微妙な問題が発生します。 すべての初期点が単一の水平または垂直線上にある場合、新しいセルは 2 つの黒の隣接セルを取得できないため、プロセスは決して拡張されません。 したがって、「すべてが境界ボックスを満たす」という素朴な直観は、一般的に間違っています。 初期点が 2 つしかない場合、別の故障モードが発生します。 たとえそれらが遠く離れていたとしても、中間セルは 2 つのサポートする隣接セルを受け取ることはできないため、答えは正確に 2 のままです。 

さらに興味深いエッジ ケースは、(0,0)、(1,0)、(0,1) などの最小の L 字型構成です。 ここでは、新しいセル (1,1) がすぐに黒になり、そこからプロセスがさらに拡大する可能性があります。 これは、最初の新しいセルを作成するのに十分なローカル構造が初期セットに含まれている場合にのみ、システムが「アクティブ化」されることを示しています。 

全体の問題は、そのようなトリガー構成が存在するかどうかを判断することに帰着します。 そうなった場合、プロセスは極端な座標によって決定される大きな安定領域に拡大します。 そうでない場合、構成は凍結されたままになります。 

## アプローチ

 ブルート フォース シミュレーションでは、現在の黒セルのセットを明示的に維持し、各ステップで少なくとも 1 つの黒セルに隣接するすべてのグリッド セルをチェックして、隣接する 2 つの黒セルが蓄積されているかどうかを確認します。 新たにアクティブ化されたセルごとに最大 4 つの新しい候補が導入されるため、探索空間は急速に拡大し、領域は最終形状の境界ボックスに比例して拡大する可能性があります。 最悪の場合、塗りつぶされた領域の直径は 2 次になりますが、1e9 までの座標ではこれは実行不可能です。 

重要な観察は、このプロセスには非常に強い二分法があるということです。 新しいセルが作成されないか、単一の有効な「シード」の作成によってカスケード拡張がトリガーされ、初期セットの軸に沿った境界四角形内のすべてが満たされます。 これは、新しいセルが出現すると、すぐに追加の隣接構造が提供され、両方の軸に沿ったさらなるセルがアクティブになり、最終的に境界ボックス内のギャップがなくなるために発生します。 

したがって、問題は 2 つのタスクに集約されます。初期構成から少なくとも 1 つの新しいセルを作成できるかどうかを判断し、作成できる場合はすべての点の外接する四角形を計算します。 

新しいセルは、初期セットにすでに 4 つの隣接セルのうち少なくとも 2 つを含むグリッド ポイントが存在する場合にのみ作成されます。 この条件は、入力ポイントから純粋に組み合わせ的にチェックできます。

このような構成が存在する場合、最終的なセットは、x 座標と y 座標の最小値と最大値にわたる完全な長方形になります。 それ以外の場合、伝播は起こらず、答えは単純に n になります。

 | アクティブ化 + 境界ボックスを検出 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 まず、システムが初期設定を超えて拡張を開始できるかどうかを判断します。 

1. 定数時間メンバーシップ クエリのハッシュ セットにすべての入力ポイントを保存します。 これにより、セット全体を毎回スキャンすることなく、特定の隣接構成が存在するかどうかをテストできます。 
2. 新しい黒セルをすぐに作成する構成を確認します。 1 ステップで少なくとも 2 つの黒色の隣接セルを生成できる幾何学パターンはわずかしかありません。 1 つは長さ 2 の水平または垂直ギャップで、2 つの点が中点を共有します。 もう 1 つは、2 つの点が 3 番目のセルの周囲に垂直に隣接する L 字型です。 
3. 具体的には、各点 (x, y) について、(x+2, y) が存在するかどうかをテストします。これら 2 つは (x+1, y) をアクティブにするためです。 同様に、(x, y+2) を使用して垂直ギャップをテストします。 これにより、直線的な活性化が得られます。 
4. L 字型のアクティブ化もテストします。 各点 (x, y) について、(x+1, y) と (x, y+1) の両方が存在するかどうかを確認します。 これら 2 つは共同して (x+1, y+1) をアクティブ化します。 対称性を捉えるには、4 つの方向すべてを確認する必要があります。 
5. そのような構成が見つからない場合、システムは新しいセルを生成しないため、プロセスは静的であり、答えは n です。 
6. 少なくとも 1 つの構成が存在する場合、すべての初期点にわたって min_x、max_x、min_y、max_y を計算します。 最後の領域はこれらの境界によって定義される長方形全体を満たすため、答えは (max_x - min_x + 1) × (max_y - min_y + 1) になります。 

### なぜ効果があるのか

 このルールでは、セルがアクティブ化される前に、セルが 2 つのサポートする隣接セルを持つ必要があります。 最初の新しいセルを作成する唯一の方法は、空の場所に 2 つの隣接セルをすでに供給する初期構造を用意することです。 このようなセルが作成されると、それが新しいサポート源となり、プロセスは障害なく両方の座標方向に伝播する能力を獲得します。 これにより、フロンティアが内側に拡張するにつれて、すべての内部セルが最終的に 2 つの独立した隣接寄与を受け取るため、バウンディング ボックス内の残りの穴がすべて排除されます。 

重要な不変条件は、最初のアクティブ化の後、黒いセルのセットが両方の軸で十分に密になり、凸軸に整列した包内の有界の空の領域が永続的にサポートされないままにならないということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    pts = []
    s = set()

    xs = []
    ys = []

    for _ in range(n):
        x, y = map(int, input().split())
        pts.append((x, y))
        s.add((x, y))
        xs.append(x)
        ys.append(y)

    if n <= 2:
        print(n)
        return

    def exists(p):
        return p in s

    can_expand = False

    for x, y in pts:
        if exists((x + 2, y)) or exists((x - 2, y)):
            can_expand = True
            break
        if exists((x, y + 2)) or exists((x, y - 2)):
            can_expand = True
            break

        if (exists((x + 1, y)) and exists((x, y + 1))) or \
           (exists((x - 1, y)) and exists((x, y + 1))) or \
           (exists((x + 1, y)) and exists((x, y - 1))) or \
           (exists((x - 1, y)) and exists((x, y - 1))):
            can_expand = True
            break

    if not can_expand:
        print(n)
        return

    print((max(xs) - min(xs) + 1) * (max(ys) - min(ys) + 1))

if __name__ == "__main__":
    solve()
```このソリューションでは、まず、近隣の存在チェックが一定時間になるように、すべてのポイントのハッシュ セットを構築します。 次に、各ポイントをスキャンし、そのポイントが最初の新しい黒セルを生成できる構成に含まれているかどうかをテストします。 チェックは、長さ 2 の直線ギャップと L 字型パターンのすべての方向の両方をカバーします。 

そのような構成が存在しない場合、構成は凍結され、答えは正確に初期点の数になります。 それ以外の場合は、境界ボックスを計算し、プロセスが安定した後の完全に飽和した領域に対応するその面積を返します。 

よくある実装の落とし穴は、各パターンの正方向と負方向の両方をテストするのを忘れることです。 座標は対称であるため、有効な活性化構造の欠落を避けるために、4 つの方向すべてを含める必要があります。 

## 実用的な例

 アクティベーションが可能な小規模な構成を考えてみましょう。 

入力点: (0,0)、(1,0)、(0,1)

 | ステップ | 新しいセルが検出されました | 理由 |
 | --- | --- | --- |
 | イニシャル | (0,0)、(1,0)、(0,1) | 設定を開始する |
 | チェック | (1,1) がアクティブになります | これには 2 つの黒の近傍があります: (1,0) と (0,1) |

 これにより、完全な 2×2 ブロックが生成されます。 境界ボックスは [0,1] × [0,1] で、答えは 4 になります。 

このトレースは、単一の L 字型が完全な伝播をトリガーするのに十分であることを示しています。 

ここで、凍結された構成を考えてみましょう。 

入力点: (0,0)、(10,0)、(100,0)

 | ステップ | 新しいセルが検出されました | 理由 |
 | --- | --- | --- |
 | イニシャル | (0,0)、(10,0)、(100,0) | すべて同じ行にあります |
 | チェック | なし | どこにも 2 つの隣接セルを持つセルはありません。 

最初のアクティベーションを生成できる構成はないため、答えは 3 のままです。これは、「シードなし、成長なし」の動作を裏付けています。

 ## 特殊なケース

 すべての点が y = 0 であるような純粋な同一線上のセットでは、空のグリッド点が 2 つの黒い隣接点を同時に認識できないため、新しいセルがアクティブになることはありません。 アクティブ化パターンがハッシュ セットに現れないため、アルゴリズムはこれを正しく処理し、n を出力します。 

(0,0)、(2,0)、(1,1) などの最小活性化構造は、(1,0) で中間点活性化を生成します。これは、距離 2 の水平ルールによって検出されます。 これにより、can_expand フラグが正しく反転され、答えが境界ボックスのサイズに切り替わります。 

疎な大きな座標入力では、数値的な問題は発生しません。これは、ソリューションが座標を反復せず、座標を保存して比較するだけであるためです。
