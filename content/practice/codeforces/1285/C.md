 ## 問題の理解

 単一の整数が与えられます$X$そしてそれを 2 つの正の整数に分割する必要があります$a$そして$b$それらの最小公倍数が正確に一致するように、$X$。 このようなすべての有効なペアのうち、2 つの数値のうち大きい方を最小化するペアが必要です。 

言い換えれば、単に因数分解を探しているわけではありません。$X$、ただし、のすべての素数パワーを「カバー」するペアです。$X$LCM を介して、最大要素ができるだけ小さくなるように、両方の数値のバランスを可能な限り保ちます。 

制約$X \le 10^{12}$immediately rules out any quadratic or even naive linear search over all pairs. すべてを超えた強引な力$a \le X$それは不可能です、なぜなら$X$非常に大きくなる可能性があり、最大でおよそ$10^6$最悪の場合の密度シナリオにおける潜在的な約数。 

微妙なエッジケースが現れるのは、$X = 1$。 その場合はどちらも$a = 1$そして$b = 1$LCM(1,1) = 1 であり、他のペアが存在しないため、これらは必須です。 どのソリューションもこれを明示的に処理するか、自然にこれに収束する必要があります。 

もう 1 つの潜在的な失敗例は、$a$の約数として$X$そして設定$b = X / a$は常に有効です。 これは真実ではありません。LCM は積の構造だけでなく素数指数にも依存するからです。 たとえば、次の場合$X = 12$、選択する$a = 4$、$b = 3$動作しますが、$a = 6$、$b = 2$も機能します。 ただし、次のような多くの約数のペア$a = 12$、$b = 1$有効ですが最適ではありません。 

主な困難は、最大値を最適化しながら LCM 条件を確保することです。 

## アプローチ

 ブルートフォースのアイデアは簡単です。すべてのペアを列挙します。$(a, b)$そのような$\text{lcm}(a, b) = X$、次にペアを追跡して最小化します$\max(a, b)$。 当面の問題は、$O(X)$約数に限定したとしても、次のような候補が考えられます。$O(\sqrt{X})$約数、それにつながる$O(D^2)$ペア。 と$X$まで$10^{12}$、これは計算上不可能になります。 

ターニングポイントは、両方のことに気づくことです$a$そして$b$分けなければなりません$X$、なぜなら、$\text{lcm}(a,b) = X$、のすべての素因数$a$そして$b$すでに含まれています$X$。 したがって、次の約数を検索するだけで済みます。$X$、任意の整数ではありません。 

ここで、問題は次のようになります。約数のペアの間で$a, b$、LCMが等しいものを見つけます$X$そして最小化します$\max(a,b)$。 約数を1つ固定すると$a$、最小の有効なパートナー$b$任意ではありません。 LCM が$X$。 

これにより、よりクリーンな再配合が可能になります。 すべての約数を反復処理します$a \mid X$、そして次を計算します:$$b = \frac{X}{\gcd(a, X/a)}$$ただし、より単純で標準的な観察によってすべてが解決されます。$a \cdot b = X$そして$\gcd(a,b)=1$とすると、LCM は次のようになります。$X$。 最適な答えは常に分割に対応します$X$2つの互いに素な部分に分かれます。 目標は因子ペアを見つけることです$(a, b)$製品付き$X$、次に、どのペアが互いに素で、最大値を最小化するかを確認します。 

さらに直接的に言えば、最適解の既知の構造は次のとおりです。すべての約数を試します。$a \le \sqrt{X}$、 セット$b = X/a$、そして次のようにして LCM を計算します。$\text{lcm}(a,b) = X \cdot \frac{a}{\gcd(a,b)} / a = \frac{X}{\gcd(a,b)}$。 したがって、条件は次のように減少します$\gcd(a,b) = 1$。 すべての有効なペアの中から、最小化するペアを選択します。$\max(a,b)$。 

したがって、最適な解決策は、最大で除数を 1 回通過することです。$\sqrt{X}$、gcd チェックを使用します。

 ## アルゴリズムのチュートリアル

 このタスクを約数のペアを見つけるように書き換えます。$(a, b)$の$X$そのような$a \cdot b = X$そして$\gcd(a,b)=1$、最小化する$\max(a,b)$。 

1. すべての整数を反復処理します。$i$から$1$に$\lfloor \sqrt{X} \rfloor$。 

約数は対称のペアになるため、平方根までのみチェックします。$(i, X/i)$、冗長な作業は避けたいと考えています。 
2. もし$i$分割する$X$、 セット$a = i$そして$b = X / i$。 

これにより、有効な因子ペアのみを考慮することが保証されます。 
3. コンピューティング$g = \gcd(a, b)$。 

このステップでは、ペアが LCM を歪めてしまうような素因数を共有しているかどうかをチェックします。$X$。 
4. もし$g = 1$、ペアは LCM 条件に対して有効です。 

次に検討します$\max(a,b)$答えの候補として。 
5. 最小化するペアを追跡します。$\max(a,b)$すべての有効な候補者にわたって。 

答えは、すべての反復後に保存された最良のペアです。 

### なぜ効果があるのか

 有効な解法では、以下の素因数のみを使用する必要があります。$X$。 ペアなら$(a,b)$共通の素因数を共有する場合、その因数は最小公倍数で 1 回だけカウントされます。つまり、最小公倍数は厳密に以下よりも小さくなります。$X$より高い指数によって補償されない限り、数値の 1 つが対応する指数構造を超えることになります。$X$。 最適な構成では重複が完全に回避されます。つまり、最適なペアは、$X$。 すべての約数をチェックすると、考えられるすべての分解が確実に考慮され、最小化されます。$\max(a,b)$バランスを確保します。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    x = int(input().strip())

    best_a, best_b = 1, x
    best_max = x

    i = 1
    while i * i <= x:
        if x % i == 0:
            a = i
            b = x // i

            if math.gcd(a, b) == 1:
                if max(a, b) < best_max:
                    best_a, best_b = a, b
                    best_max = max(a, b)

            # check the symmetric pair is not needed since (a,b) already covers it

        i += 1

    print(best_a, best_b)

if __name__ == "__main__":
    solve()
```コードは最大でのみ反復されます。$\sqrt{X}$、以下の条件の下で効率を確保します。$10^{12}$制約。 各除数ペアは 1 回テストされ、gcd フィルタリングによって LCM 条件の正確さが保証されます。 最適化ターゲットを直接エンコードする、より小さい最大値が見つかるたびに最適なペアが更新されます。 

微妙な点の 1 つは初期化です。$(1, X)$有効なベースラインを保証します。$\gcd(1,X)=1$常に保持します。

 ## 特殊なケース

 のために$X = 1$、ループは 1 回実行されます$i = 1$。 得ます$a = 1$、$b = 1$、 そして$\gcd(1,1)=1$なので、アルゴリズムは (1,1) を返しますが、これは正しいです。 

プライム用$X$、除数ペアのみが$(1,X)$。 gcd は 1 なので自動的に選択され、他に候補は存在しません。 

次のような完全な正方形の場合$X = 36$、(6,6) などの対称約数は、gcd が 1 ではないため gcd テストに失敗し、無効な LCM 削減が防止されます。 (4,9) のような互いに素なペアだけが生き残り、アルゴリズムは最もバランスのとれたペアを正しく選択します。 

のような大きな権力に対しては、$X = 10^{12}$、ループはまだ最大までしか実行されません$10^6$、gcd チェックは一定時間のままです。 このアルゴリズムは、除数の数や因数分解の深さへの依存を回避し、平方根の列挙のみに依存します。
