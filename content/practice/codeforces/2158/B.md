 ## 問題の理解

 長さの配列が与えられます$2n$。 その要素を 2 つのサブシーケンスに分割する必要があります$p$そして$q$、それぞれが正確に含む$n$要素。 サブシーケンス内の順序は重要ではなく、選択された値のマルチセットのみが重要です。 

あらゆるシーケンスに対応$b$と定義します。$f(b)$次のように: それぞれの個別の値が何回出現するかを調べます。$b$、奇数回出現する値の数を数えます。 言い換えると、$f(b)$は周波数パリティを持つ要素の数です。$b$奇数です。 

目標は、$2n$要素を同じサイズの 2 つのグループに分けて、2 つのグループの奇数周波数カウントの合計が最大になるようにします。 

主な難点は、値が出現するたびに両方のサブシーケンス内のパリティに影響があり、値ごとに独立してではなく、グローバルに割り当てを調整する必要があることです。 

制約は、テスト ケースごとの線形または線形に近い解決策を意味します。 合計から$n$すべてのテストにわたって$2 \cdot 10^5$、それよりも悪い解決策$O(n \log n)$テストごとにタイムアウトの危険性があります。 単純なサブセット列挙やディストリビューションに対する動的プログラミングは、直ちに実行不可能になります。 

いくつかの特殊なケースから構造が明らかになります。 

すべての要素が同一の場合、次のようにします。$a = [1,1,1,1]$と$n=2$、任意の分割により、偶数パリティまたは平衡パリティを持つ両方のサブシーケンスが生成されます。$f(p)+f(q)=0$。 これは、生のカウントではなく、周波数パリティ制約が支配的であることを示しています。 

すべての要素が異なる場合は、次のようにします。$[1,2,3,4]$、に分けることができます。$[1,3]$そして$[2,4]$、両方のサブシーケンスですべての要素が 1 回出現するようにすることで、それぞれが最大のパリティに寄与します。 これは、重複を慎重に配布することが重要であることを示唆しています。 

より微妙なケースは、値が何度も出現する場合です。 たとえば、値が 4 回出現する場合、2 と 2 を分配できますが、他の値がどのように割り当てられるかによって、パリティに役立つ場合とそうでない場合があります。 これは、決定が値ごとにローカルであるが、サブシーケンス サイズによってグローバルに制約されることを示しています。 

## アプローチ

 ブルートフォースソリューションでは、あらゆる方法で各$2n$どちらかに位置します$p$または$q$、各サイズ$n$。 これは選択するのと同じです$n$のインデックス$p$、与える$\binom{2n}{n}$可能性。 割り当てごとに、両方のサブシーケンスのパリティ カウントを計算します。$O(n)$、おおよそにつながります$O(n \binom{2n}{n})$小規模であっても天文学的な規模のオペレーション$n$。 

一度に 1 つの値に注目すると、構造がより明確になります。 値を仮定します$x$表示されます$k$回。 私たちは、それらの出来事のうち何件が次の段階に入るかを事実上決定しています。$p$そして何個入りますか$q$。 何が重要なのか$f(p)$そして$f(q)$はこれらのカウントのパリティです。 

置いたら$t$の発生$x$の中へ$p$、 それから$k-t$入る$q$。 の貢献$x$答えは次のとおりです。 

- それはに貢献します$f(p)$もし$t$奇妙です、
 - それはに貢献します$f(q)$もし$k-t$奇数です。 

したがって、それぞれの値について、選択したいのは、$t$これは、これらのパリティが奇数になるかどうかを最大化します。 

どちらもという制約は、$p$そして$q$サイズが必要です$n$すべての値を結合します。 ただし、すべての値が固定数の要素に寄与しており、唯一の柔軟性は 2 つのグループ間の出現を「ペア」にする方法であることに注意してください。 

重要な再定式化は、ペアリングの発生という観点から考えることです。 同じ値が 2 つ発生し、それらを異なるグループに送信しても、パリティには役立ちません。 アンバランスな状態を維持すると、奇数のカウントが発生する可能性があります。 最適な戦略は、最終的に、答えに 2 を与えることができる値の数 (各サブシーケンスで 1 つの奇数) と、1 または 0 のみに寄与する値の数によって決まります。 

クリーンな貪欲な解決策は、頻度をカウントし、少なくとも 2 回出現する値の数を決定することです。 そのような各値は、その出現を適切に分割すると、両方のサブシーケンスに寄与する可能性があります。 ただし、各サブシーケンスのサイズは固定されているため、$n$, 実現できる「二重貢献」の数には限界があります。 

最適な答えは、貪欲なペアリングの発生に帰着します。つまり、奇数パリティの寄与を持つ両方のサブシーケンスに出現できる値の数を最大化します。 これは、重複からいくつのペアを形成できるか、そしていくつのシングルトンが残るかを計算することにつながります。 

具体的には、度数をカウントし、それぞれの値からペアを抽出することを繰り返します。 各ペアは、両方のサブシーケンスを支援できる 1 つのユニットに対応します。 ペアの使用量を最大化した後、残った要素はシステム全体で 1 回だけ貢献できるシングルトンのように動作します。 最終的な答えは次のようになります。$$\text{answer} = \min(2n, \text{number of odd contributions achievable by pairing})$$より正確な導出は次のように単純化されます。 

合計ペアを計算します$S = \sum \lfloor \frac{cnt[x]}{2} \rfloor$。 各ペアは潜在的に答えを 2 増やすことができますが、要素の数によって制限されます。$n$サブシーケンスごとなので、最大でも「使用」することしかできません。$n$両側のペア。 最終的な貢献度は次のようになります。$$\min(2S, 2n)$$しかし、各ペアは実質的に 2 に寄与するため、$f(p)+f(q)$、最終的な答えは次のとおりです。$$\min(2S, 2n)$$これはさらに単純化して次のようになります。$$2 \cdot \min(S, n)$$この貪欲な解釈は、独立したパリティの柔軟性を作成するには、2 つの等しい要素を使用するのが最適であるという考えと一致します。

 ## アルゴリズムのチュートリアル

 1. 配列内のすべての値の頻度を数えます。 これにより、相互作用は合計カウントによってのみ発生するため、値ごとに独立した構造が分離されます。 
2. 各値について、その値が寄与する素のペアの数を計算します。$\lfloor cnt[x]/2 \rfloor$。 このような各ペアは、パリティの柔軟性を最大化するためにサブシーケンス間で分離できる 2 つの出現を表します。 
3. Sum all these pair counts into a global value$S$。 これにより、アレイ内の使用可能なすべての「ペア リソース」が集約されます。 
4. 最終的な答えを次のように計算します。$2 \cdot \min(S, n)$。 要因$n$各サブシーケンスが保持できるのは$n$要素により、実現できる効果的なパリティ生成分割の数が制限されます。 
5. この値をテスト ケースごとに出力します。 

### なぜ効果があるのか

 同一の値の各ペアは、両方のサブシーケンスに有用なパリティ寄与を作成するために分割できる唯一の構造です。 単一のオカレンスは本質的に制限されており、どちらかに配置されます。$p$または$q$1 か所のみでパリティを切り替えます。 ペアを使用すると、サブシーケンス間のバランスを制御でき、最適な配置は、そのようなペアの数を「アクティブ化」するかどうかを決定するだけで済みます。 各部分列にはサイズがあるため、$n$、せいぜい$n$このようなアクティベーションを使用できます。 これにより、解が制限され、ペアの貪欲なパッキングが最適化されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        freq = {}
        for x in a:
            freq[x] = freq.get(x, 0) + 1
        
        pairs = 0
        for c in freq.values():
            pairs += c // 2
        
        print(2 * min(pairs, n))

if __name__ == "__main__":
    solve()
```この実装は、テスト ケースごとに 1 つの周波数辞書に依存します。 各値は使用可能なペアのプールに独立して寄与するため、実際の割り当てをシミュレートする必要はありません。$p$そして$q$。 

重要な点は、サブシーケンスを明示的に構築しないことです。 両方ともサイズがなければならないという制約$n$使用可能なペアの数を制限することで間接的に強制されます。$n$。 これにより、組み合わせによる構築が回避されます。

 ## 特殊なケース

 重要なエッジケースは、すべての要素が異なる場合です。 その状況では、周波数マップには 1 つしかないため、すべての$c // 2$はゼロであり、答えはゼロに崩壊します。 このアルゴリズムは、シングルトン要素をパリティ寄与に強制しようとしないため、これを自然に処理します。 

もう 1 つのエッジ ケースは、1 つの値が優勢な場合です。 たとえば、次の場合$a = [x,x,x,x,x,x]$、頻度は 6 で、3 つのペアが得られます。 同一の要素がたくさんあるとしても、答えの上限は次のとおりです。$n$したがって、次の場合は最大 2 ペアのみを使用します。$n=2$。 アルゴリズムは明示的な方法でこれを処理します。$\min(S,n)$キャップを付け、数えすぎを防ぎます。 

次のような混合ケース$[1,1,1,2,2,2]$それぞれ 1 つのペアに寄与する 2 つの値を生成します。 周波数の寄与は加算的であり、相互作用しないため、合計は干渉のない独立した寄与を正確に反映します。
