 ## 解決策
 ## 問題の理解

 配列が与えられています$a$そして別の配列$b$同じ長さの。 2 人のプレイヤーが交互にターンを正確に行います$k$動く。 各移動で、現在のプレーヤーはインデックスを選択し、対応する値を加算または減算します。$b_i$から$a_i$。 すべての移動が終了したら、結果の配列を確認し、古典的な Kadane の意味で部分配列の合計の最大値を計算します。 アリスはこの最終値をできるだけ大きくしたいと考えていますが、ボブはできるだけ小さくしたいと考えています。 

重要な問題は、配列の「状態」が敵対的な更新を通じて進化するが、最終スコアは単一要素のローカル プロパティではないことです。 これは連続するセグメントに依存するため、異なるインデックスでの変更はサブ配列構造を通じて相互作用します。 

この制約は、どのソリューションでもゲーム ツリーのシミュレーションを回避する必要があることを示唆しています。 まで$2 \cdot 10^5$テストごとの要素と最大$2 \cdot 10^5$合計、指数関数的なもの$k$または二次関数でさえも$n$不可能です。 1 ターンあたりのリニアですら遅すぎるため、$k$大きくすることもできます。 

単純なアプローチでは、すべての動きをシミュレートしたり、ゲームの状態全体にわたって DP を維持しようとしたりしますが、それはすぐに次のような問題に遭遇します。$2^k$分岐または少なくとも$O(nk)$、両方とも不可能です。 

微妙なエッジケースが現れるのは、$b_i = 0$。 この場合、移動によって配列はまったく変更されないため、答えは単純に最初の部分配列の最大合計になります。 もう 1 つのエッジケースは次のような場合です$k$に比べて大きいです$n$、複数の更新が同じインデックスに蓄積される可能性があるため、シーケンスよりもインデックスごとの操作のパリティが重要になります。 

隠れた主な難しさは、ゲームは敵対的であるにもかかわらず、それぞれの動きは限定された線形効果のみに寄与し、最終スコアは操作の順序ではなく、インデックスごとの累積純変更に依存することです。 

## アプローチ

 強引な解釈では、各手は分岐の決定として扱われます。プレイヤーは毎ターン、インデックスを選択し、+ または − のいずれかを選択します。 これにより、大まかに分岐要素を含むゲーム ツリーが形成されます$2n$動きごとに、$O((2n)^k)$州。 配列値が大きくなり、シーケンス間で区別されたままになる可能性があるため、状態をキャッシュしても役に立ちません。 

動きの順序を最終的な効果から切り離す方法が必要です。 重要な点は、パリティとインデックスごとの操作数のみが重要であるということです。 各インデックス$i$最終的にはフォームの何らかの変更が必要になります$x_i \cdot b_i$、 どこ$x_i$減算よりも多くの加算が適用されたことを表す整数です。 

各移動はちょうど 1 つの座標を変更するため、$\pm b_i$、指数に対する合計の影響$i$選択された回数とサインがどのように配布されたかによって完全に決まります。 

これにより、配布の問題が軽減されます$k$交互制御の下でインデックス全体の符号付きユニット寄与度。 アリスは、サブ配列の最大合計が増加するインデックスに寄与をプッシュしたいと考えています。 ボブはその逆を望んでいます。 

重要な簡素化は、最終スコアを再構成することで実現します。 サブ配列プロセス全体を動的に考える代わりに、サブ配列の合計の最大値はプレフィックスの寄与に依存し、各操作が効果的に$\pm b_i$一部のセグメントへの貢献。 最適な再生は、正の増分と負の増分をどこに配置するかを決定することに集約されます。 

より深く観察すると、ゲームは完全に解決されます。各操作は効果的に次のいずれかに貢献します。$+b_i$または$-b_i$そして、最適なプレイとは、アリスが可能な限り最高の蓄積を最大化しようとする一方で、ボブが最も有益な配置を破壊しようとすることに帰着します。 両方のプレーヤーが最適に動作し、サインに対して対称的なパワーを持っているため、最終的な効果は、各インデックスの最終的な寄与は、タッチされた回数と、どちらのパリティがそれらのタッチを支配するかによってのみ依存することになります。 

これは貪欲な削減につながります。アリスは常に、正の変更によって最終的な最大部分配列合計が最も改善されるインデックスをターゲットにしますが、ボブは同じ構造をターゲットにしますが、負の圧力を加えます。 スコアはサブ配列ベースであるため、最適な戦略は崩れて、すべての効果的な純プラスの動きを 1 つの最良のセグメントの寄与に集中させることになります。 

これにより、問題はキャンセル後にどれだけの効果的なプラスの寄与が残るかを評価することになり、プレフィックス推論と制御された分布を使用して線形時間で計算できます。$k$動く。

 ## アルゴリズムのチュートリアル

 重要なのは、交互のゲームを最終配列の正味の「使用可能なアドバンテージ」に変換し、その調整された配列の下で最適なサブ配列を計算することです。 

1. Kadane のアイデアを使用して、初期配列のプレフィックス構造を計算します。 

変更を加える前に、サブ配列がローカルでどのように動作するかを知りたいと考えています。 更新はシフト値のみであり、隣接関係は変更しないため、このベースラインは重要です。 
2. 各操作で 1 つの要素だけが変更されることを観察します。$+b_i$または$-b_i$したがって、すべての移動の後、各インデックスは$i$選択された回数と符号のバランスのみに依存する正味の調整があります。 

これにより、移動順序への依存がなくなります。 
3. プレイヤーが交代するため、アリスはどちらかを獲得します。$\lceil k/2 \rceil$移動するとボブが取得します$\lfloor k/2 \rfloor$動く。 最終的な効果は、次の場合にアリスが制御単位を 1 つ追加できることです。$k$奇数です。 

この不均衡は、ゲームにおける唯一の戦略的非対称です。 
4. 各移動は、符号付きの値を何らかのインデックスに寄与するものとして解釈される必要があります。 アリスは正の符号を割り当て、ボブは負の符号を割り当てます。 

最適な方法は、最終的な部分配列の合計を最大化または最小化するインデックスにこれらの符号を割り当てることになります。 
5. 各インデックスについて$i$、サブ配列の合計を増やす最良の方法は、次の場合にそこにすべての正の圧力を適用することです。$b_i$規模が大きく、有益なセグメントの一部です。 

サブアレイの合計は連続するセグメントにわたって加算されるため、ゲインの集中化が常に最適になります。 
6. したがって、元の配列の可能な限り最良の部分配列合計を計算し、ボブが可能な限りキャンセルした後に正味の正の増分がどれだけ残るかをシミュレートします。 
7. 生き残る利点は事実上$\max(0, k \bmod 2)$可能な限り最高の倍$b_i$-最適な部分配列に合わせて重み付けされた寄与。 
8. 最後に、この生き残った寄与を初期配列の最良の部分配列合計に加算します。 

### なぜ効果があるのか

 不変条件は、プレイヤーがオペレーションをどのように分散するかに関係なく、重要なのはインデックスごとの正味署名数のみであり、最適な敵対的プレイでは、ターン順序によって引き起こされる避けられない不均衡を除いて、常にすべてがキャンセルされるということです。 目的はグローバルな最大サブアレイ合計であるため、分散した利点は最適なサブアレイ間隔に集中するよりも厳密には劣ります。 したがって、ゲームは、最適な静的部分配列と、パリティと最大値によってのみ決定される決定論的な調整を計算することになります。$b_i$-アライメント。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def kadane(arr):
    best = -10**30
    cur = 0
    for x in arr:
        cur = max(x, cur + x)
        best = max(best, cur)
    return best

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        base = kadane(a)

        # compute best possible gain from b inside any subarray
        # idea: subarray contribution is linear, so we test +b as potential boost
        gain = kadane(b)

        # only parity matters for net uncontested move
        if k % 2 == 1:
            ans = base + max(0, gain)
        else:
            ans = base

        print(ans)

if __name__ == "__main__":
    solve()
```このコードは、問題を 2 つの独立した要素、つまり元の配列の最適な部分配列の合計と、$b$配列。 Kadane のアルゴリズムは両方の部分で最大の連続累積を見つけることに帰着するため、両方に使用されます。 

パリティ チェックは、アリスとボブの間に唯一残っている非対称性をエンコードします。 追加の動きが 1 つある場合、アリスは 1 つの追加のプラスの貢献を強制できます。 そうしないと、ボブのあらゆる利点がアリスの行動を完全に打ち消してしまう可能性があります。

 ## 特殊なケース

 いつすべて$b_i = 0$、あらゆる動きが無効になります。 アルゴリズムはこれを処理します。`gain = 0`、したがって、答えは次のカダネ値に帰着します。$a$、ゲームが無関係であるという事実と一致します。 

いつ$k$が偶数の場合、アルゴリズムはすべてのゲインを破棄します。$b$。 これは、アリスとボブの間の完全なキャンセルに対応します。つまり、すべての肯定的な行動は否定的な反応によって反映される可能性があります。 

いつ$k$is odd, exactly one net positive contribution remains. The algorithm captures this by allowing a single Kadane-based gain term, reflecting the unavoidable advantage of the first player.

 いつ$a$が完全に負である場合でも、Kadane は最適な単一要素を返します。このソリューションでは、パリティやパリティによって許可されない限り、人為的な改善が導入されないことが保証されます。$b$-駆動のゲイン構造。
