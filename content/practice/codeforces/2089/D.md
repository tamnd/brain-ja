 ## 問題の理解

 長さのバイナリ文字列が与えられます`2n+1`。 目標は正確に挿入することです`n`条件演算子`?:`文字の間に有効な C++ スタイルの式を形成し、必要に応じて括弧を追加し、最終的な式が次のように評価できるかどうかを判断します。`1`。 言い換えれば、最上位の結果が true になるように条件を使用して評価を「ルーティング」できるかどうかを判断したいのです。 

文字列内の各文字はリテラルを表します。`0`は誤りです、`1`それは本当です。 条件演算子は次のように機能します。`a?b:c`、値は`b`もし`a`それは真実であり、`c`もし`a`は誤りです。 演算子は右に関連付けられているため、`a?b:c?d:e`次のように解析されます`a?b:(c?d:e)`。 

制約は次のことを教えてくれます`n`と同じ大きさにすることができます`1.5 * 10^5`テストケースごととすべての合計`n`テスト全体で同じ数に制限されます。 これにより、テスト ケースごとに O(n) よりも悪いアルゴリズムが除外されます。 あらゆる方法で配置を試みる強引なアプローチ`?`また、括弧にはカタロニア数のような構造を列挙する必要があり、1 つのケースに対して 10^5 の演算をゆうに超えます。 文字列を線形に検査するソリューションが必要です。 

単純なエッジケースは、文字列がすべてゼロである場合に発生します。`"00000"`。 ここでは、`?`そして`:`結果を出すことができる`1`、条件文には決して`1`を選択します。 もう 1 つの微妙なエッジ ケースは、最初の文字が`0`そしてすべての`1`s は文字列の後ろにあります。 右結合性により、最初の文字は`0`右のブランチに評価を強制します。ブランチには少なくとも 1 つが含まれている必要があります。`1`成功するために。 

## アプローチ

 ブルートフォースアプローチは、すべての有効な括弧を生成することです。`n` `?`演算子全体`2n+1`オペランドを作成し、各式を評価し、結果が得られるかどうかを確認します。`1`。 有効な括弧の数はカタロニア語の数字に対応し、おおよそ次のように増加します。`4^n / (n^(3/2))`。 のために`n=10^5`、これは天文学的に巨大であり、明らかに不可能です。 

最適化するための重要な観察は次のとおりです。条件演算子を使用すると、条件を「選択」できます。`1`文字列内に存在する場合。 より正確には、式は次のように評価できます。`1`少なくとも 1 つ存在する場合に限り、`1`文字列の中で。 ない場合`1`、条件文のシーケンスが結果をもたらすことはありません。`1`。 少なくとも 1 つあれば`1`、単純な線形貪欲アプローチを使用して有効な式を構築できます。 最初の文字を初期条件として配置し、最初の文字が次のように右に関連付けられた条件のチェーンを再帰的に構築します。`1`遭遇したものが選択されています。 優先順位の要件を満たすために括弧を挿入できますが、次のような単純なパターンは`(a?b:c)?d:e`正確性を保証します。 

この観察により、問題は組み合わせ爆発から単純な線形スキャンと制御された式の構築に縮小されます。

 ## アルゴリズムのチュートリアル

 1. 文字列を左から右にスキャンし、少なくとも 1 つが含まれているかどうかを確認します。`1`。 文字列にのみがある場合`0`s、すぐに出力`No`。 
2. 少なくとも 1 つある場合`1`、答えはわかっています。`Yes`。 私たちの目標は、次のように評価される有効な式を構築することです。`1`。 
3. 貪欲に式の構築を開始します。 最初の 3 文字をミニ式として考えます。最初の文字が`1`、 それから`first?second:third`と評価される`second`最初の場合`1`そして`third`最初の場合`0`。 少なくとも 1 つはすでに持っているため、`1`文字列内でこのように連鎖すると、最上位の式で確実に選択できるようになります。`1`。 
4. 挿入を続けます`?`そして`:`部分式を括弧で囲みながら、演算子を右関連形式で使用します。 常に左端を扱います`1`選択するプライマリ ブランチとして。 
5. 構築された文字列を出力します。 

これが機能する理由: 不変条件は、これまでに構築された部分式が次のように評価できることです。`1`少なくとも1つはあるので`1`文字列の未処理部分に残ります。 右結合性により、それぞれが追加されたことが保証されます。`?:`オペレータは選択を後の文字に「延期」できるため、常に次の条件に到達することができます。`1`。 常に知っているので、選択を誤ることはありません。`1`残りの部分に存在します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        if '1' not in s:
            print("No")
            continue
        print("Yes")
        # Build a simple right-associated expression
        expr = s[-1]
        for i in range(len(s)-2, -1, -1):
            expr = f"({s[i]}?{expr}:{s[i+1]})"
        print(expr)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず文字列に次のものが含まれているかどうかを確認します。`1`。 そうでない場合は印刷されます`No`。 それ以外の場合は、右に関連付けられた条件分岐のチェーンが構築され、すべてのステップが括弧で囲まれます。 これにより、正しい優先順位が保証されます。 文字列の構築は右から左に行われ、右に関連付けられた形式で式が自然に構築されます。 

微妙な点：入力長は`2n+1`、 それで`s[-1]`は常に最後の文字です。 Off-by-one エラーは、逆に反復して使用することで回避されます。`i+1`表現的には正しく。 それぞれの周りに括弧が追加されます`?:`曖昧さを防ぐため。
