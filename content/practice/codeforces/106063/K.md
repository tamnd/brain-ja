 ## 解決策
 ## 問題の理解

 この問題では、数直線上の 2 つの道路セグメントがどの程度重なっているかを測定するように求められます。 各セグメントは閉じた区間であるため、両方の端点が含まれますが、答えは長さに基づいており、単一の接触点の寄与はゼロになります。 2 つの間隔が与えられた場合`[a, b]`そして`[c, d]`、共通部分の長さを出力する必要があります。共通部分に正の長さがない場合はゼロを出力する必要があります。 

入力には、多数の独立したテスト ケースが含まれています。 到達できるケースの数は、`10^5`、座標は次のように大きくできます。`10^18`絶対値で言うと。 これにより、ケースごとの定数または対数仕事以上のものは即座に除外されます。`10^5`ケースには、およそ数百万の単純な操作の余地しか残されていません。 座標サイズは、実装で 64 ビット値を処理できる整数演算を使用する必要があることも意味します。 

主なエッジ ケースは、交点を長さとした点のセットとしての混同された交点から発生します。 例えば：```
1
0 1 1 2
```間隔は座標で一致します`1`, ただし、共通部分は要点のみです。`{1}`。 長さはゼロなので、答えは次のようになります。```
0
```間隔が重複しているかどうかだけをチェックするソリューションでは、誤った結果が返される可能性があります。`1`。 

もう 1 つのケースは、ある区間が完全に別の区間の内側にある場合です。```
1
0 10 3 7
```交差点は、`[3,7]`、長さは`4`。 1 つのエンドポイントのみをチェックする不注意な実装では、この状況を見逃す可能性があります。 

最後の厄介なケースは、両方の間隔がポイントである場合です。```
1
5 5 5 5
```間隔は同一ですが、端点間に距離がないため、長さはゼロのままです。 

## アプローチ

 直接的なアプローチは、間隔を比較し、考えられるすべての重複状況を見つけることです。 ある区間がもう一方の区間内で始まるかどうか、一方の区間が他方の区間を含んでいるかどうか、またはそれらの区間が互いに素であるかどうかを確認できます。 これが機能するのは、2 つの間隔の間に考えられるすべての関係がこれらのカテゴリのいずれかに分類されるからです。 ただし、これにより不要な分岐が発生し、エンドポイントの接触に関して間違いを犯しやすくなります。 

間隔の構造により、より簡単な観察が可能になります。 両方の区間がその座標に到達している必要があるため、交差点の左境界は 2 つの左端点のうちの遅い方の境界線である必要があります。 同様に、右境界は 2 つの右端点のうちの早い方でなければなりません。 結果として得られる左側の境界が右側の境界よりも小さい場合、正の長さの交差が存在します。 それ以外の場合、交差点の長さはゼロになります。 

強引なケース分析スタイルも定数時間で機能しますが、最小値と最大値の観察によってロジックが 1 つの式に縮小されます。 問題は検索やシミュレーションに関するものではなく、共有領域の 2 つの境界を特定することだけです。

 ## アルゴリズムのチュートリアル

 1. 2 つの間隔の 4 つのエンドポイントを読み取ります。 

2 つの区間の交点はそれらの境界によって完全に決定されるため、端点のみが必要です。 
2. 交差点の左側を次のように計算します。`max(a, c)`。 

交差点内の点は両方の区間に属している必要があるため、どちらかの区間が始まる前に置くことはできません。 
3. 交差点の右側を次のように計算します。`min(b, d)`。 

交差内の点はいずれかの間隔が終了する前に終了する必要があります。 
4. 左辺が右辺より小さい場合は、その差を出力します。 それ以外の場合はゼロを出力します。 

境界が等しいということは交点が 1 つの点のみであることを意味するため、厳密な不等式が必要です。 

機能する理由: アルゴリズムは、両方の間隔に同時に点を含めることができる正確な可能な範囲を維持します。 最大開始点は、いずれかの間隔で使用できないすべての位置を削除し、最小終了点は、いずれかの間隔の外側にあるすべての位置を削除します。 残りのセグメントはまさに交差点です。 正の幅がない場合、長さはゼロになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        a, b, c, d = map(int, input().split())

        left = max(a, c)
        right = min(b, d)

        if left < right:
            ans.append(str(right - left))
        else:
            ans.append("0")

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```このソリューションはすべてのテスト ケースを読み取り、それぞれを個別に処理します。 変数`left`そして`right`は、交差を記述するために必要な 2 つの値のみを表します。 

比較には、`<`の代わりに`<=`。 これにより、エンドポイントに接触するケースが正しく処理されます。`[2,2]`長さはゼロです。 Python の整数には任意の精度があるため、大きな座標には特別な処理は必要ありません。

 ## 特殊なケース

 接触エンドポイントの場合:```
1
0 1 1 2
```アルゴリズムが計算します`left = max(0,1) = 1`そして`right = min(1,2) = 1`。 2 つの値が等しいため、条件は失敗し、答えはゼロになります。 アルゴリズムは、共有ポイントを長さがないものとして正しく処理します。 

含まれる間隔の場合:```
1
0 10 3 7
```計算された交差点は次のとおりです`3`に`7`, なぜなら、スタートが遅いからです。`3`そしてその前の終わりは`7`。 答えは`7 - 3 = 4`、特別な封じ込めロジックが必要ないことを示しています。 

負の座標の場合:```
1
-10 -2 -7 0
```交差点は`[-7,-2]`。 アルゴリズムは次のことを見つけます`left = -7`そして`right = -2`、与える`5`。 順序のみが重要であるため、ネガティブ ポジションはポジティブ ポジションとまったく同じように動作します。
