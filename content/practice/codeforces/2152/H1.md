 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、`n`頂点の場合、各エッジには正の重みがかかります。 タスクは、「勝利の色付け」(頂点を少なくとも 1 つの赤で赤または黄色に色付けする) の最小コストを計算するときに、この最小コストが少なくとも`l`、特定のクエリに対して`l`。 頂点の重みの合計は最小化する必要があります。 コスト関数は、すべての赤い頂点の重みの合計と、異なる色の頂点を接続するエッジの重みの合計をカウントします。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは、すべてのテスト ケース全体で合計最大 250,000 個の頂点を持つツリー、最大 10^9 の重みを持つエッジ、および指定された下限の最小頂点合計を求める最大 10 個のクエリを記述します。`l`勝利のカラーリングの代償として。 

なぜなら`n`最大 2.5×10^5 で、複数のテスト ケースが存在する可能性があり、どのソリューションも大まかに実行する必要があります。`O(n log n)`または`O(n)`テストケースごとに。 すべての頂点の重みの割り当てやカラーリングを列挙する総当り的なアプローチは絶望的です。`2^n`着色料。 

微妙なエッジ ケースは、本質的にパスまたはスターであるツリーです。 たとえば、エッジの重みが高い 2 つの頂点のパスには、クエリを満たすかそれを超える頂点の重みが必要です。`l`最も安価な方法で。 もう 1 つは星です。中心を赤に着色するか、葉を赤に着色するかによってコストが大きく異なる可能性があるため、単純に貪欲な割り当ては失敗する可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、頂点の重みのすべての割り当てを試みます。`[x_1, ..., x_n]`そして計算します`f([x])`すべての 2^n 色をテストして最小コストを見つけます。 クエリごとに、どの割り当てがしきい値を満たすかを確認します。`l`そして最小の合計があります。 2^n は n=20 の場合でも爆発するため、これは明らかに不可能です。 

重要な洞察は、ツリーでは、**最大エッジ重みマッチング引数**を使用して、最小の勝利カラーリング コストを記述できるということです。 コストを最小限に抑える勝利のカラーリングを検討してください。頂点が赤で、それ自体の重みに寄与するか、頂点を赤い頂点に接続するエッジがその重みに寄与します。 したがって、問題は **最大値の合計を計算することになります。`k`いくつかの頂点カットに沿ったエッジ寄与**。 

簡単なバージョンでは、**ツリー内の 2 つの最も重いエッジ**を考慮するだけで十分です。勝利したカラーリングでは常に 1 つの頂点の赤を選択することができ (その重みを追加)、2 つの最大の入射エッジの合計によって最小限のエッジ寄与が決定されるためです。 したがって、クエリごとに`l`、次を使用して頂点合計の最小値を計算できます。```
minimum_sum = max(l, sum of two largest edges)
```このアプローチは、ツリー構造によって最悪の場合のカラーリング コストが 2 つの最大の入射エッジによって実現されることが保証されるため、すべてのカラーリングまたはウェイトに対する反復処理が回避され、機能します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n × n) | O(n) | 遅すぎる |
 | 最適 | O(n log n) (または O(n)) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 テスト ケースごとに、次の内容を読んでください。`n`そしてのリスト`n-1`エッジ`(u, v, w)`。 必要に応じて隣接リストを作成しますが、このバージョンではエッジの重みのみが問題になります。 
2. ツリー内の 2 つの最大のエッジの重みを計算します。 これは、すべてのエッジを反復処理し、最大と 2 番目に大きい重みを追跡することによって行われます。 そのままにしておきます`max1`そして`max2`。 
3. クエリ数を読み取る`q`そしてクエリのリスト`l_i`。 
4. 各クエリについて`l_i`、最小頂点合計は次のように計算されます。`max(l_i, max1 + max2)`。 これにより、どの色を選択しても、少なくともコストはかかります。`l_i`そして頂点の重みの合計は最小化されます。 
5. 各クエリの結果を出力します。 

**機能する理由**: 勝利したカラーリングには、少なくとも 1 つの赤い頂点が含まれている必要があります。 最小コストは、最も重い 2 つのエッジの合計によって制限されます。これは、コストを最小限に抑えようとするカラーリングでは、条件を満たすためにこれらのエッジの支払いを避けることができないためです。`l`。 頂点の重みを正確に選択する`l - sum_of_heavy_edges`残りを単一の赤い頂点に分配し、最小合計を達成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        edges = []
        for _ in range(n - 1):
            u, v, w = map(int, input().split())
            edges.append(w)
        edges.sort(reverse=True)
        max1 = edges[0]
        max2 = edges[1] if n > 2 else 0
        q = int(input())
        for _ in range(q):
            l = int(input())
            print(max(l, max1 + max2))

if __name__ == "__main__":
    solve()
```コードは最初にエッジを読み取り、それらを並べ替えて最大の 2 つを見つけます。 並べ替えというのは、`O(n log n)`制約を考慮すると、これで十分です。 各クエリについて、答えは以下の最大値として計算されます。`l`そして最大の 2 つのエッジの合計。 ツリーに頂点が 2 つしかない場合は特別な注意が必要です。この場合、2 番目に大きいエッジは存在せず、0 として扱われます。
