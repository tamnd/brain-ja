 ## 問題の理解

 長さの隠された順列が与えられています$n^2 + 1$そして、長さの単調部分列を正確に見つける必要があります$n+1$。 サブシーケンスは増加または減少のいずれかになります。 問題は、順列を直接見ることができないことです。 代わりに、一連のインデックスを使用してインタラクターにクエリを実行すると、インタラクターはそれらのインデックスの値の左から右への最大値を返します。 つまり、クエリされたサブシーケンスについては、左から右に見た場合にどの要素が表示されるかだけを学習します。 

この問題は、長さのあらゆる置換が保証されます。$n^2 + 1$長さの単調サブシーケンスが含まれています$n+1$、これはエルドス・セーケレスの定理から来ています。 これが私たちの目標が常に達成可能な理由です。 

制約は控えめです。$n$100まで上がるので、$n^2 + 1$最大でも 10,001 です。 限られているので、$n$テスト ケースごとのクエリでは、非常に少ない対話で十分な情報を抽出する必要があります。 これにより、個々の要素をクエリしたり、すべてのサブシーケンスをチェックしたりするブルートフォース戦略が排除されます。 インタラクション メカニズムは、取得される情報を最大化するクエリを慎重に構築する必要があることも意味します。各クエリは、増加または減少する要素のかなりのチェーンを提供する必要があります。 

エッジケースは、順列に大きなプラトーがある場合、またはほぼ降順にソートされている場合に発生します。 たとえば、次の場合$n=2$順列が [3,1,2,5,4] である場合、連続するインデックスを選択するような単純なクエリでは 1 つの可視要素しか返されないため、単調なサブシーケンスを構築できなくなります。$n$クエリ。 もう 1 つの微妙なケースは、隠れた順列が厳密に減少している場合です。 増加するシーケンスを検出するように設計されたクエリは、毎回最初の要素のみを返すため、対称的なケースを考慮する必要があります。 

## アプローチ

 ブルートフォースアプローチは、個々の要素または小さなセットを順番にクエリし、順列を完全に再構築しようとすることです。 これが機能するのは、最終的にはすべての要素を比較して単調なサブシーケンスを構築できるためです。 ただし、ほぼすべてのクエリを実行する必要があります。$n^2 + 1$限界をはるかに超える要素$n$クエリ。 たとえば、次の場合$n = 100$これは、許可されている 100 件ではなく、潜在的に 10,001 件のクエリを意味します。明らかに、インタラクション制限によりブルート フォースは失敗します。 

重要な洞察はエルドス・セーケレスの定理自体から得られます。 これは、長さがどのような順序であっても、$n^2+1$、長さの増加する部分列が存在します。$n+1$または減少します。 したがって、完全な置換は必要ありません。 これらのシーケンスの 1 つを「釣り出す」クエリを慎重に構築する必要があるだけです。 

順列を次のように分割すると、$n$およその長さの連続したブロック$n$、各ブロックをクエリすると、左から右への最大値が得られます。 各最大値チェーンは厳密に増加しています。 いずれかのブロックが少なくとも$n+1$マキシマ、終わりました。 それ以外の場合は、ブロック全体でチェーンをマージできます。 なぜなら私たちは持っているから$n$ブロックと各チェーンの長さは最大で$n$、これらのチェーンの結合には少なくとも次のものが含まれます。$n+1$要素。 これらの収集された要素に忍耐によるソート (または標準の LIS/LDS 動的プログラミング アプローチ) を適用すると、長さの単調なサブシーケンスを抽出できることが保証されます。$n+1$。 これは正確に使用します$n$クエリを実行し、問題の制約に適合します。

 ## アルゴリズムのチュートリアル

 1. を分割します。$n^2+1$要素を$n$ブロック、それぞれに大まかな内容が含まれる$n$インデックス。 これにより、すべての要素が正確に 1 つのブロックに含まれ、空のブロックがないことが保証されます。 
2. ブロックごとに、そのブロック内のすべてのインデックスを使用してインタラクターにクエリを発行します。 応答は、そのブロックの左から右への最大値を示します。 これらの最大値をリストに集めます。 各リストは厳密に増加するチェーンを表します。 
3. 結局のところ$n$クエリは最大でも$n^2$収集された最大値の要素 (各ブロックが最大で寄与するため)$n$最大値）。 エルドス・セーケレスの定理によれば、これらの要素の間には、長さの増加する部分列が存在します。$n+1$または減少します。 
4. 忍耐ソートを使用して、収集された最大値の中から最長増加部分列 (LIS) と最長減少部分列 (LDS) を見つけます。 最初に長さに達したもの$n+1$が私たちの答えを与えてくれます。 そのサブシーケンス内の要素は、元の順列内のインデックスに対応します。 
5. モノトーンサブシーケンスのインデックスをソートされた順序で出力します。 

正確さは 2 つの不変式から得られます。各ブロック クエリは厳密に増加するチェーンと、$n$せいぜいそのような長さの鎖$n$常に長さの単調サブシーケンスが含まれます$n+1$エルドス＝シェケレス著。 私たちは決して超えることはありません$n$クエリ、インタラクション制限を満たす。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
print_flush = lambda x: (print(x), sys.stdout.flush())

def lis_or_lds(seq, n):
    from bisect import bisect_left, bisect_right
    # Try LIS
    piles = []
    idx_map = []
    for idx, val in enumerate(seq):
        pos = bisect_left(piles, val)
        if pos == len(piles):
            piles.append(val)
            idx_map.append([idx])
        else:
            piles[pos] = val
            idx_map[pos].append(idx)
    if len(piles) >= n+1:
        result = []
        k = n+1
        last = float('inf')
        for i in range(len(seq)-1, -1, -1):
            if seq[i] <= last and k > 0:
                result.append(seq[i])
                last = seq[i]
                k -= 1
        return result[::-1]
    # Else LDS
    piles = []
    idx_map = []
    for idx, val in enumerate(seq):
        pos = bisect_left(piles, -val)
        if pos == len(piles):
            piles.append(-val)
            idx_map.append([idx])
        else:
            piles[pos] = -val
            idx_map[pos].append(idx)
    result = []
    k = n+1
    last = float('-inf')
    for i in range(len(seq)-1, -1, -1):
        if seq[i] >= last and k > 0:
            result.append(seq[i])
            last = seq[i]
            k -= 1
    return result[::-1]

def solve_case():
    n = int(input())
    indices = list(range(1, n*n + 2))
    block_size = (n*n + 1 + n - 1) // n
    maxima_indices = []

    for i in range(n):
        block = indices[i*block_size : (i+1)*block_size]
        if not block:
            continue
        print_flush(f"? {len(block)} {' '.join(map(str, block))}")
        resp = list(map(int, input().split()))
        c = resp[0]
        maxima_indices.extend(resp[1:])

    answer = lis_or_lds(maxima_indices, n)
    print_flush(f"! {' '.join(map(str, answer))}")

def main():
    t = int(input())
    for _ in range(t):
        solve_case()

if __name__ == "__main__":
    main()
