 ## 解決策
 ## 問題の理解

 私たちには、一定数のおもちゃのブロックが入った箱のセットが与えられます。 このゲームは、子供が 1 つのボックスを選択し、そのすべてのブロックを他のボックスに均等に再分配しようとすることで構成されます。 再分配の結果、他のすべてのボックスが同じブロック数を持つようになった場合、子供は満足します。 そうでないと彼は悲しいです。 私たちの仕事は、どのボックスが選択されても再配布が常に成功するように、ボックスに余分なブロックを先制して追加することです。 この質問では、この結果を保証するために必要な追加ブロックの最小数を尋ねます。 

入力は複数のテスト ケースを指定し、それぞれにボックスの数と現在のブロック数が含まれます。 テスト ケースが最大 1000 個、ボックスが合計 10^5 個まである場合、あらゆる再配布を試みる強引なアプローチでは遅すぎます。 テスト ケースごとのボックスの数が線形に動作するアルゴリズムが必要です。 エッジ ケースには、すべてのボックスがすでに等しい場合、一部のボックスが空である場合、および 1 つのボックスに他のボックスよりもはるかに多くのブロックが含まれている場合が含まれます。 例えば箱の場合`[0, 3, 0]`、選択したボックスが残り物を残さずに均等に再分配できるように、追加のブロックを慎重に分配する必要があります。 

## アプローチ

 単純なアプローチでは、各ボックスの選択をシミュレートし、各シナリオに必要な追加ブロックの数を計算し、最大値を取得しようとします。 正しいのですが、これは、潜在的なターゲット構成ごとにすべてのボックスを反復する必要があり、テスト ケースごとに O(n^2) の操作が必要になります。 n が 10^5 までの場合、このアプローチは実行できません。 

効率的なソリューションに対する重要な洞察は、エクストラを追加した後のブロックの総数が n-1 で割り切れる場合にのみ再配布が成功するという観察から得られます。 させて`sum_a`初期ブロック数と`max_a`最大のブロック数。 どのボックスが選択されても、選択したボックスのブロックは他のボックスに追加されるため、他のボックスは合計で少なくとも到達する必要があります`max_a * (n-1)`ブロック。 同時に、余分なものを含むすべてのブロックの合計は次で割り切れる必要があります。`n-1`均等な分配を可能にするため。 これら 2 つの制約により、必要な最小合計が得られ、そこから余分なブロックの数を次のように計算できます。`max(target_sum - sum_a, 0)`。 この洞察により、問題がシミュレーションなしの単純な計算に削減され、線形時間処理が可能になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 |---|---|---|---|
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、ボックスの数を読み取ります。`n`現在のブロック数`a`。 
2. コンピューティング`sum_a`、すべてのブロックの合計、および`max_a`、配列内の最大ブロック数。 
3. 計算する`min_required`、子供の幸せを保証するために必要なブロックの最小合計。 これは最大です`n-1`回`max_a`そして最小の倍数`n-1`それは少なくとも`sum_a`。 この 2 番目の値を計算するには、切り上げを使用して整数の除算を実行します。`(sum_a + n - 2) // (n-1) * (n-1)`。 
4. 必要な追加ブロックの数は次のとおりです。`min_required - sum_a`。 以来`min_required`常に少なくとも`sum_a`、この値は負ではありません。 
5. 各テスト ケースの結果を出力します。 

機能する理由: 総ブロック数が次の上限倍数に確実に達するようにすることで、`n-1`お互いのボックスが少なくとも到達できること`max_a`、任意のボックス選択が他のボックス間で均等に分配されることを保証します。 これらの制約は、シミュレーションなしで再分配を満たすために必要なものを正確に捉えます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    sum_a = sum(a)
    max_a = max(a)
    # minimal total sum that is >= sum_a and divisible by n-1
    target_sum = max(sum_a, (max_a * (n - 1)))
    if target_sum % (n - 1) != 0:
        target_sum = ((target_sum + n - 2) // (n - 1)) * (n - 1)
    print(target_sum - sum_a)
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`複数のテストケースを処理します。 計算します`sum_a`そして`max_a`線形時間で、整数演算を使用して最も近い倍数に切り上げます。`n-1`。 重要な点は、合計が次の値で割り切れない場合に正しく切り上げることです。`n-1`これにより、off-by-one エラーが回避されます。 入力ストレージ以外の余分なスペースは必要ありません。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 |---|---|---|
 | 時間 | テスト ケースあたり O(n) | 合計と最大の計算は線形であり、倍数への丸めは定数時間です。 
| スペース | テスト ケースあたり O(n) | 入力配列の保存 |

 すべてのテスト ケースの n の合計が ≤ 10^5 であるとすると、このソリューションは制限時間内で快適に実行されます。 

## テストケース```python

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    # solution
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        sum_a = sum(a)
        max_a = max(a)
        target_sum = max(sum_a, max_a * (n - 1))
        if target_sum % (n - 1) != 0:
            target_sum = ((target_sum + n - 2) // (n - 1)) * (n - 1)
        print(target_sum - sum_a)
    return output.getvalue().strip()

# provided samples

# custom cases

## 特殊なケース

 エッジケースの場合`[0, 3, 0]`の場合、アルゴリズムは合計を 3、最大値を 3、次に必要な最小合計を 6 として計算し、3 つの追加ブロックを与えます。 これにより、子供がどのボックスを選択しても、他のボックス間での再配布が常に可能になります。 のために`[1,1,1]`、合計は 3、最大は 1、2 で割り切れる最小合計は 4 となり、式ごとに 1 つの余分なブロックが得られます。 これらのトレースは、極端な不均衡と均一なケースの両方が正しく処理されていることを示しています。
