 ## 解決策
 ## 問題の理解

 1 から n までのラベルが付けられた木の行が与えられ、常に木 1 から始まり、木 n で終わります。 有効な「ツリー パス」は、両方のエンドポイントを含む訪問されたツリーのシーケンスを選択することによって定義され、次の各移動は少なくとも k 位置ずつ前方にジャンプします。 シーケンスの長さは m に固定されているため、a1 が 1 に等しく、am が n に等しく、シーケンスが厳密に増加し、すべてのステップが ai+1 − ai ≥ k を満たすように、m 個のインデックス a1 から am を効果的に選択します。 

選択した訪問インデックスのセットが異なる場合、2 つのパスは異なるものとみなされます。 タスクは、そのようなパスの正確な数を計算することではなく、この数が奇数であるか偶数であるかを判断することだけです。 

制約は非常に大きく、n と m は最大 10^9、テスト ケースの数は 10^5 に達する可能性があります。 これにより、位置を反復したり、n または m を介して動的プログラミングを使用したりするソリューションは即座に除外されます。 テスト ケースごとに m 単位でさえ線形なアプローチは、遅すぎるでしょう。 ソリューションでは、理想的には閉形式の組み合わせ特性評価を使用して、各テスト ケースを定数時間または対数時間に短縮する必要があります。 

微妙なエッジ条件は、m が 2 に近い場合、または k が大きい場合です。 m が 2 に等しい場合、距離制約が許可する場合、パスは強制的に {1, n} のみになるため、解は最大 1 つになります。 もう 1 つの注意が必要な状況は、k が 1 に等しい場合です。これにより、ジャンプ制限がなくなり、問題は、エンドポイントを含む長さ m が 1 から n まで増加するシーケンスを選択することになります。 どちらの場合も、注意深い変換を行わずに単純にカウントすると、中間値が直接計算される場合に不正確な組み合わせ解釈やオーバーフローの問題が発生します。 

## アプローチ

 ブルートフォース解釈では、1 から n までの長さ m のすべての有効なシーケンスを、少なくとも k の間隔で構築し、それらをカウントしようとします。 これは概念的には簡単です。現在の位置から後の有効な位置までの次の位置を再帰的に選択します。 ただし、分岐係数は大きくなる可能性があり、深さは m であるため、状態の数は n に応じて組み合わせ的に増加します。 中程度の値であっても、これは m で指数関数的となり、制約の下では不可能になります。 

重要な観察は、間隔制約を正規化して取り除くことができるということです。 各ジャンプには少なくとも k 個の距離が必要なので、必須の間隔を差し引くことでシーケンスを「圧縮」できます。 この変換が適用されると、すべての有効なシーケンスは、順序付け以外の制約なしに、縮小された範囲から m-2 個の中間点を選択することに正確に対応します。 これにより、問題は二項係数計数問題に変換されます。 

二項係数に換算した後は、それを数値的に計算しません。 必要なのはその同等性だけです。 二項係数のパリティはよく知られた構造を持っています。つまり、二項表現のみに依存し、ルーカスの定理モジュロ 2 から導出されたビットごとの条件を使用してチェックできます。これにより、階乗、剰余逆算、または大規模な算術が完全に回避されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 |---|---|---|---|
 | ブルートフォース列挙 | 指数 | O(m) 再帰 | 遅すぎる |
 | 圧縮 + 二項パリティ | テストごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 制約シーケンス a1 = 1 および am = n から開始します。ここで、すべての隣接する差分は少なくとも k です。 エンドポイントは固定されているため、シーケンスの内部構造に焦点を当てます。 

2. 必須のスペースを削除して、各位置を変換します。 新しいシーケンス xi = ai − (i−1)(k−1) を定義します。 これにより、順序を維持しながら、各ステップから k−1 の「組み込みスラック」が除去されます。 

3. 変換後、制約は xi+1 − xi ≥ 1 になります。これは、xi が厳密に増加する整数列を形成することを意味します。

4. 有効なエンドポイントを計算します。 am = n なので、xm = n − (m−1)(k−1) が得られます。 これにより、問題は 1 から始まりこの圧縮されたエンドポイントで終わる m 個の異なる整数を選択することになります。 

5. x1 = 1 および xm を計算どおりに修正します。 残りの m−2 値は、区間 (1, xm) 内で厳密に増加する任意の整数です。 有効な選択肢の数は、xm-2 個の利用可能な位置から m-2 個の要素を選択する方法の数に等しくなります。 

6. これにより、二項係数 C(N, K) が得られます。ここで、N = xm − 2 および K = m − 2 です。 

7. C(N, K) のパリティのみが必要です。 バイナリ条件を使用します。C(N, K) は、K と N−K を加算するときにバイナリ キャリーが発生しない場合にのみ奇数になります。これは、ビット単位の条件 K & (N − K) = 0 と同等です。 

### なぜ効果があるのか

 この変換は、必須の距離を線形シフトに吸収することにより、制約された間隔の問題を純粋な組み合わせの問題に変換します。 これにより、元のパスと変換された整数シーケンスの間の 1 対 1 の対応が維持されます。 削減されると、カウントは標準のサブセット選択になり、モジュロ 2 の二項係数はビット単位の包含関係のように動作するため、パリティはバイナリ構造のみに依存します。 正確さは、元のパスと圧縮後の制約のない整数の選択の間のこの全単射に依存します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_odd_binom(n, k):
    if k < 0 or k > n:
        return False
    return (k & (n - k)) == 0

t = int(input())
out = []

for _ in range(t):
    n, m, k = map(int, input().split())

    if m == 1:
        out.append("yes")
        continue

    # transformed endpoint
    end = n - (m - 1) * (k - 1)
    N = end - 2
    K = m - 2

    if N < K or K < 0:
        out.append("no")
        continue

    out.append("yes" if is_odd_binom(N, K) else "no")

sys.stdout.write("\n".join(out))
```この解決策は、まず幾何学的ジャンプ制約を線形シフトに変換し、次に計数問題を二項係数に変換します。 最後のステップでは、係数を直接計算することを避け、代わりにビット単位のパリティ テストを使用します。 実装でよくある落とし穴は、C(N, K) に変換するときに最後の 2 シフトを忘れることです。これは、エンドポイント 1 と n の両方を固定することに起因します。 もう 1 つの微妙な問題は、変換されたエンドポイントが小さすぎる場合の処理​​です。これにより、有効なシーケンスが即座にゼロになる必要があります。 

## 実用的な例

 n = 10、m = 3、k = 2 の入力を考えます。変換後、エンドポイントは end = 10 − 2·1 = 8 になります。その場合、N = 6 および K = 1 となります。C(6, 1) を計算していますが、これは 6 であり、偶数であるため、答えはノーです。 

| ステップ | 終わり | N | K | パリティチェック |
 |---|---|---|---|---|
 | 変換 | 8 | 6 | 1 | C(6,1) | を計算します。 

これは、間隔制約によって利用可能な範囲がどのように減少するか、そして最終的なパリティがどのように二項構造のみに依存するかを示しています。 

ここで、n = 15、m = 5、k = 3 を考えます。end = 15 − 4·2 = 7 が得られるため、N = 5、K = 3 となります。C(5,3) は 10 に等しく、これは偶数であるため、答えはやはり no です。 

| ステップ | 終わり | N | K | パリティチェック |
 |---|---|---|---|---|
 | 変換 | 7 | 5 | 3 | C(5,3) | を計算します。 

このケースは、変換された空間が非常に小さくなり、少数の組み合わせしか存在しないにもかかわらず、パリティが大きさではなく純粋にバイナリ構造によって依然として決定される状況を示しています。

 変換とパリティ チェックにより、基本的な算術を超えた n または m への依存が回避され、ソリューションが最大 10^5 のテスト ケースに適したものになります。 

## テストケース```python
import sys, io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    def is_odd_binom(n, k):
        return 0 <= k <= n and (k & (n - k)) == 0

    t = int(input())
    res = []
    for _ in range(t):
        n, m, k = map(int, input().split())
        if m == 1:
            res.append("yes")
            continue
        end = n - (m - 1) * (k - 1)
        N = end - 2
        K = m - 2
        if N < K or K < 0:
            res.append("no")
        else:
            res.append("yes" if is_odd_binom(N, K) else "no")
    return "\n".join(res)

assert solve("1\n10 3 2\n") in ["yes", "no"]

# minimum case
assert solve("1\n2 2 1\n") == "yes"

# tight m=2 case
assert solve("1\n10 2 3\n") == "no"

# k=1 case
assert solve("1\n5 3 1\n") in ["yes", "no"]

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、m が 2 に等しい場合です。この場合、内部ノードがないため、唯一の候補パスは 1 から n への直接接続です。 アルゴリズムは K = 0 および N = end − 2 を設定し、二項パリティ チェックは C(N, 0) を可能な限り常に 1 として正しく評価し、構造が 1 つだけ存在するという事実と一致します。 

k が 1 の場合、別のエッジ ケースが発生します。変換によりゼロ間隔が削除されるため、end は n になり、問題は端点を含む長さ m の増加するシーケンスを選択することになります。 この式は引き続き正しい二項形式を生成し、パリティ チェックは特別なケースを使用せずに純粋に組み合わせ的に動作します。 

最後のエッジ ケースは、圧縮されたエンドポイント end が m 未満になるときに発生します。 この状況では、十分な個別のポイントを配置することは不可能であり、アルゴリズムはパリティ ルールを適用する前に N < K をチェックすることで正しく拒否します。
