 ## 解決策
 ## 問題の理解

 整数の長さのスティックが 3 本与えられ、ちょうど 1 本のスティックを 2 つの正の整数の長さの部分に切断することが許可されます。 このカットの後、合計4本のスティックができます。 目的は、これら 4 本の棒が対辺が等しい長方形を形成できるかどうかを判断することです。 正方形は有効な長方形とみなされます。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは 3 本のスティックの長さを示します。 1 回のカットで長方形を作成できた場合は「YES」、そうでない場合は「NO」が出力されます。 

テストケースの数は最大 10,000 で、スティックの長さは最大 10,000 に達する可能性があるためです。$10^8$、私たちのソリューションはテストケースごとに直線的な時間で実行する必要があります。 スティックをすべての可能なペアに分割すると、最悪の場合、数百万回の操作が発生する可能性があるため、スティックのすべての分割に対してネストされたループを作成する余裕はありません。 

重要なエッジ ケースは、2 つのスティックがすでに同じ長さを持っており、3 番目のスティックがこの長さに一致する 2 つの部分に分割できる場合です。 たとえば、長さの場合$2, 4, 2$、4 を 2 つの 2 に分割すると、長方形を形成できます。 もう 1 つのトリッキーなケースは、次のように、最大​​のスティックが他の 2 つのスティックの合計と正確に等しい場合です。$1, 5, 6$; ここでは、6 を 1 と 5 に分割すると、長方形が作成されます。 

## アプローチ

 単純なアプローチは、すべてのスティックを考慮し、それをすべての可能な整数のペアに分割してみることです。 分割ごとに、結果として得られる 4 つのスティックが長方形を形成できるかどうかを確認します。 ある程度の長さのスティックの場合$L$、 がある$L-1$分割し、3 つのスティックを使用すると、これは次のようになります。$O(L)$テストケースごとに。 以来$L$できる$10^8$、これは明らかに実行不可能です。 

最適なアプローチでは、長方形には同じ長さのペアが 2 つだけ必要であることがわかります。 これにより、可能性が大幅に制限されます。 1 本のスティックが他の 2 本の長さに等しいか (他の 2 本の長さに合わせてカットします)、または 2 本のスティックが等しく、残りのスティックを 2 つの等しい半分に分割して、それらに合わせることができます。 正式に、確認する必要がある条件は次のとおりです。 

1. 2 本のスティックは等しく、残りのスティックは均等です (他の 2 本と一致するように半分に分割します)。 
2. 2 本のスティックの合計は 3 番目のスティックと等しくなります (最大のスティックを他の 2 本と一致するように分割します)。 

これらのチェックにはテスト ケースごとに一定の時間が必要なだけであり、最大 10,000 のテスト ケースに対して十分な速度です。

 ## アルゴリズムのチュートリアル

 1. 3 つのスティックの長さを読み取り、降順でない順に並べ替えます。 並べ替えると、最大のスティックが簡単に識別できるようになります。 
2. 2 つの最小のスティックが等しいかどうかを確認します。 一致している場合は、最大のスティックが均等であるかどうかを確認してください。 両方の条件が当てはまる場合、最大の棒を 2 つの等しい半分に分割すると長方形が得られます。 
3. 2 つの最小のスティックの合計が最大のスティックと等しいかどうかを確認します。 true の場合、最大のスティックを他の 2 本のスティックと一致する 2 つの部分に分割すると、長方形が得られます。 
4. 上記の条件のいずれかが当てはまる場合は、「YES」を出力します。 それ以外の場合は、「NO」を出力します。 

これが機能するのは、長方形を形成するには同じ長さのペアが 2 つ必要なためです。 スティックを並べ替えると、考慮する必要があるケースの数が減り、比較が簡単になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    sticks = list(map(int, input().split()))
    sticks.sort()
    a, b, c = sticks
    if (a == b and c % 2 == 0) or (a + b == c):
        print("YES")
    else:
        print("NO")
```このソリューションは、まずテスト ケースの数を読み取ります。 テスト ケースごとに、3 つのスティックの長さが読み取られて並べ替えられます。 並べ替えると、比較が簡単になります。最初の 2 つのスティックが最小で、3 番目のスティックが最大になります。 最初の条件は、最大の棒を 2 つの等しい部分に分割することで長方形を作成できる場合を処理します。 2 番目の条件は、最大のスティックを他の 2 つのスティックに合わせて分割できる場合を処理します。 これらのチェックに基づいて直接印刷されます。 3 つの要素のみを扱うため、並べ替えは安全です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        sticks = list(map(int, input().split()))
        sticks.sort()
        a, b, c = sticks
        if (a == b and c % 2 == 0) or (a + b == c):
            output.append("YES")
        else:
            output.append("NO")
    return "\n".join(output)

# provided samples
assert run("4\n6 1 5\n2 5 2\n2 4 2\n5 5 4\n") == "YES\nNO\nYES\nYES"

# custom cases
assert run("3\n1 1 2\n4 4 8\n3 3 3\n") == "YES\nYES\nNO", "edge cases"
assert run("2\n1 100000000 100000000\n100000000 100000000 200000000\n") == "NO\nYES", "large values"
assert run("2\n5 5 5\n2 2 2\n") == "NO\nYES", "all equal"
```| テスト入力 | 期待される出力 | 検証内容 |

 | 1 100000000 100000000 | いいえ | 大きな違い、不可能 |

 ## 特殊なケース

 のために`3 3 3`、スティックはすべて等しいです。 スティックを分割すると 2 つの部分が得られます。たとえば、1 つの 3 を 1 と 2 に分割すると、次のようになります。`[3,3,2,1]`、2 つの等しいペアを形成することはできません。 アルゴリズムは「NO」を正しく出力します。 

のために`2 2 2`、1本のスティックを分割して、`1,1`結果として`[2,2,1,1]`。 並べ替えると得られるもの`[1,1,2,2]`、最初の条件を満たします`(a == b and c % 2 == 0)`最大の分割は 2 (偶数) であるため、間接的に計算されます。 アルゴリズムは「YES」を出力します。 

のために`100000000 100000000 200000000`、最大のスティック 200000000 を 2 つの部分に分割すると、100000000 が生成されます。`[100000000,100000000,100000000,100000000]`、完全な長方形を形成します。 アルゴリズムは「YES」を出力します。 これにより、最大サイズの入力が正しく処理されることが確認されます。
