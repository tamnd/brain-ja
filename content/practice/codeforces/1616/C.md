 ## 解決策
 ## 問題の理解

 整数の配列が与えられ、要素を任意の実数に自由に置き換えることができます。 目標は、非常に強力な構造特性が保持されるように配列を変換することです。すべてのサブ配列は、その合計をその端点のみに結び付ける線形平均条件を満たさなければなりません。 

この条件は一見複雑に見えますが、非表示の形状制約が適用されています。 要件をすべてのサブ配列に拡張すると、基本的に、すべての連続するセグメントがその値が直線上にあるかのように動作するように強制されます。 直線性から逸脱すると、重複するサブセグメントを比較するときに矛盾が生じます。 

したがって、このタスクは合計を直接扱うものではありません。 最小限の要素を変更するだけで配列をグローバルに線形にするには、どれだけの位置を固定する必要があるかが重要です。 

入力サイズは小さく、テスト ケースあたり最大 70 要素、最大 100 テスト ケースです。 これは、セグメント上の二次または三次解が実現可能であることを直ちに示唆しますが、修正のすべてのサブセットを単純に探索しようとすると、サブセットの数が膨大になるため、爆発する可能性があります。$2^{70}$。 

「価値観の固定」という観点から考えると、微妙な問題が見えてきます。 置換には任意の実数を使用できるため、どのインデックスを変更せずに残すかを決定すると、一貫した構造が存在する場合には、残りを常に選択して一貫した構造に適合させることができます。 本当に難しいのは、有効な構成を形成しながら、インデックスのどのサブセットを変更しないでよいかを特定することです。 

現地の状況だけで十分だと考えるのは素朴な間違いです。 たとえば、トリプルのみをチェックしたり、隣接する制約のみをチェックすると、全体的な不整合が見逃されます。 のような小さな例`[1, 2, 4, 7]`ローカル チェックには合格する可能性がありますが、すべてのポイントに適合する単一の線はないため、グローバルでは失敗します。 

## アプローチ

 構造を理解する鍵は、条件をより幾何的な方法で書き直すことです。 この方程式により、すべての部分配列の合計が、値が線形関数からサンプリングされた場合に得られる値と等しくなることが強制されます。 これは、配列が次の形式の線形シーケンスのように動作する必要があることを意味します。$$a_i = x + (i - 1)d$$いくつかの実数については$x$そして$d$。 

配列がすでにこの等差数列に従っている場合は、すべての部分配列が自動的に条件を満たします。 逆に、等差数列に違反すると、一部のセグメントのプロパティが破壊されます。 

したがって、問題は次のようになります。結果の配列が等差数列になるように、要素の最小数を変更します。 

次に、これにどのようにアプローチするかを考えてみましょう。 2 つのポジションを選択すると$i < j$の場合、これら 2 つの値によって一意の等差数列が決まります。 1 つおきのインデックス$k$以下を満たす必要があります:$$a_k = a_i + (k - i)\cdot \frac{a_j - a_i}{j - i}$$固定ペアの場合$(i, j)$、この進行にすでに一致する元の要素の数を数えることができます。 他のものはすべて交換する必要があります。 

ブルートフォースソリューションはすべてのペアを試行します$(i, j)$すべてのインデックスの一貫性をチェックし、原価計算を行います。$O(n^3)$テストケースごとに。 と$n = 70$、これはすでに近づいていますが、Python では枝刈りを行うことでまだ安全です。 ただし、より直接的な観察が役に立ちます。最適解は、選択された 2 つのインデックスによって定義される 1 つの等差数列上にある点の最大数です。 

必要なのは、保存された要素を最大化することだけです。 答えは$n - \text{best alignment}$。 

重要な洞察は、進行は傾きによって完全に決定されるため、すべてのペアが候補解を定義し、それらすべてを評価するだけであるということです。

 ## アルゴリズムのチュートリアル

 1. インデックスのペアを修正します$i$そして$j$、 どこ$i < j$、それらをターゲットの等差数列を定義するものとして扱います。 

傾きはこれら 2 つの点によって一意に決定され、シーケンスの残りの部分を構築する際のあいまいさがなくなります。 
2. 差を計算します$d = (a_j - a_i) / (j - i)$。 これは、インデックス ステップごとに値がどのように変化するかを定義します。 

この問題では実数の置換が可能であるため、実数を使用します。 
3. この進行に一致する要素の数のカウンターを初期化します。 すべてのインデックスから始めて、式との一貫性をチェックします$a_k = a_i + (k - i)d$。 
4. すべてのインデックスについて$k$、元の値が既に進行状況に適合しているかどうかを確認します。 そうであれば、私たちはそれを保持します。 そうしないと交換が必要になります。 

各一致は、変更の必要のない位置を表します。 
5. すべてのペアにわたる一致の最大数を追跡する$(i, j)$。 これは、有効な等差数列を形成する際に変更しないことができる最大のサブセットを表します。 
6. 答えは次のとおりです。$n - \text{maximum matches}$。 

### なぜ効果があるのか

 元の条件ではすべてのサブセグメントにわたって線形性が強制されるため、有効な最終配列は等差数列である必要があります。 等差数列は、任意の 2 つの異なる点によって一意に定義されるため、すべての有効な解は、変更されない少なくとも 1 組のインデックスに対応します。 

逆に、ペアを固定して完全な進行に拡張すると、すべてのポジションがすでに適合しているか、交換する必要があり、結果として得られる構造は常に条件を満たします。 したがって、すべてのペアを検索することで、考えられるすべての有効な最終構成が考慮されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        if n <= 2:
            print(0)
            continue

        best = 1

        for i in range(n):
            for j in range(i + 1, n):
                cnt = 0

                ai, aj = a[i], a[j]
                di = j - i

                for k in range(n):
                    # check collinearity without floating instability
                    # (a[k] - ai) * (j - i) == (a[j] - ai) * (k - i)
                    if (a[k] - ai) * di == (aj - ai) * (k - i):
                        cnt += 1

                best = max(best, cnt)

        print(n - best)

if __name__ == "__main__":
    solve()
```この実装では、傾きを直接計算する代わりに相互乗算を行うことで、浮動小数点精度の問題を回避します。 これにより、整数を使用した正確な比較が保証されます。これは、最終値が実数であることが許容される場合でも重要です。 コーナーケース$n \le 2$任意の 2 つの点が常に有効な進行を定義するため、個別に処理されます。

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

 ## 特殊なケース

 次のような定数配列`[5, 5, 5, 5]`傾きがゼロの縮退等差数列であるため、すでに条件を満たしています。 アルゴリズムは、すべてのインデックスを任意のペアに一致するものとして正確にカウントするため、最適なのは$n$、操作はゼロです。 

サイズ 1 または 2 の小さな配列の場合、任意の 2 つの点が一意の線を定義するため、すべての構成が有効です。 このような場合、実装は明示的に 0 を返し、不必要な計算を回避し、ゼロによる除算や未定義の勾配の処理を防ぎます。 

複数の異なる等差数列が部分的に適合する場合、次のようになります。`[1, 3, 2, 4]`、異なるペアは異なる候補線を誘導します。 アルゴリズムはそれらすべてを調査し、最も調整されたものを自然に選択し、常に最小限の置換数が達成されるようにします。
