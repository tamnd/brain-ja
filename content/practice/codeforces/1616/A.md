 ## 解決策
 ## 問題の理解

 整数のリストが与えられ、それらのサブセットを否定することができます。 目標は、一部の要素を否定した後、配列内の個別の整数の数を最大化することです。 各テスト ケースは整数の新しいリストを提供し、出力は単にこれらの否定を通じて取得できる異なる値の最大数です。 

入力制約、配列サイズを見ると、`n`は最大でも 100 であり、値は -100 から 100 の間にあります。これは、漸近的な複雑さの高さを気にせずに、各値の頻度または存在を直接検査するソリューションを検討するのに十分な大きさです。 テストケースの数も 100 と中程度であるため、`O(n^2)`テスト ケースごとのアプローチは許容可能な時間内で実行されます。 

注意すべきエッジ ケースは、ゼロ、重複、対称的な正と負です。 たとえば、配列が次の場合、`[0, 0]`、ゼロを否定しても何も変わらないため、答えは 1 になります。配列が`[1, 1, -1]`重複を慎重に扱う必要があります。1 と -1 を 1 つずつ使用できますが、-1 から 2 つ目の 1 を再度作成することはできません。 この微妙な点を無視すると、過大なカウントが発生する可能性があります。 

## アプローチ

 ブルートフォース手法では、配列のすべてのサブセットを試し、それを否定し、個別の値をカウントします。 各要素に対して、否定するか否定するかの 2 つの選択肢があります。`2^n`可能性。 たとえ`n = 20`、これは 100 万を超えるサブセットに達します。`n = 100`、これは天文学的な大きさです。 したがって、ブルートフォースは実行不可能です。 

重要な観察は、**個別の絶対値** のみを考慮しているということです。 それぞれの正の数は、それ自体、その否定、またはその両方として現れることがあります。 それぞれの負の数値は、正の絶対値の負のバージョンにすぎません。 ゼロは特別で、否定に関係なく 1 回だけ出現できます。 したがって、問題は、異なる絶対値がいくつあるかを数えるということになりますが、数値の正と負の両方が存在する場合をどのように処理するかを決定する必要があります。 

最適な戦略は次のとおりです。ゼロを個別に数えて 1 に制限し、その他の絶対値ごとに最大 2 つの数値 (正と負の 1 つずつ) を含めることができます。 元の配列に同じ絶対値の両方の符号が含まれている場合は、両方を含めます。 それ以外の場合は、存在するものを含めます。 これにより、個別の要素の最大数が保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(1) (セットの場合は O(n)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. カウンタをゼロと 2 つのセット (正の数に 1 つ、負の数に 1 つ) に初期化します。 
2. 配列を反復処理します。 数値がゼロの場合は、ゼロ カウンタをインクリメントします。 正の場合は、正のセットに追加します。 負の場合は、その絶対値を負のセットに追加します。 
3. 個別値の最大数は、ゼロ カウント (最大 1)、正のみの数値の数、負のみの数値の数、および正と負の両方の形式で存在する数値の数の合計です。 
4. 各絶対値について、それが正のセットと負のセットの両方に現れる場合は、両方をカウントします。 1 セットのみに出現する場合は、その 1 つの出現をカウントします。 ゼロが存在する場合はそれを追加します。 
5. この合計をテスト ケースごとに出力します。 

**機能する理由:** 個別の絶対値をカウントし、最大 1 つのゼロを考慮することで、重複がカウントされず、数値が見落とされないことが保証されます。 これを超えて重複を否定しても個別の値は増加しないため、この戦略は最大限です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    pos = set()
    neg = set()
    zero = 0
    
    for x in a:
        if x > 0:
            pos.add(x)
        elif x < 0:
            neg.add(-x)
        else:
            zero = 1
    
    both = pos & neg  # numbers that appear in both positive and negative
    pos_only = pos - both
    neg_only = neg - both
    
    result = len(both) * 2 + len(pos_only) + len(neg_only) + zero
    print(result)
```コードは、正の数値、負の数値、およびゼロの数値を区切ります。 正と負の両方の形式で表示される数値をカウントし、それらを正しく処理します。 ゼロは最大 1 回カウントされます。 セットを使用すると、重複が確実に無視されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | テスト ケースあたり O(n) | 各数値は 1 回処理され、セットは O(1) の挿入と検索をサポートします。

## 特殊なケース

 配列の場合`[0, 0]`、アルゴリズムセット`zero = 1`正または負の数はありません。`both`、`pos_only`、`neg_only`は空です。 結果は 1 となり、繰り返されるゼロが正しく処理されます。 

のために`[1, 1, -1]`、`pos = {1}`、`neg = {1}`、`both = {1}`、`pos_only = {}`、`neg_only = {}`、結果 = 2。これは 1 を 1 つと -1 を 1 つ正確に数えます。
