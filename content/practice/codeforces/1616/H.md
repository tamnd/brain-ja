 ## 解決策
 ## 問題の理解

 すべての要素ペアの XOR が指定された数を超えない、配列の空でないサブセットをすべてカウントするように求められます。`x`。 具体的には、配列からインデックスのサブセットを取得し、そのサブセット内のすべての値のペアの XOR を計算する場合、各 XOR は ≤ でなければなりません。`x`。 出力は、そのような有効なサブセットの合計数を法で表したものです。`998244353`。 

入力は長さの配列で構成されます`n`最大 150,000、値は最大 23⁰ 近くになる可能性があります。 大きいサイズは、`n`サブセットは 2ⁿ あり、天文学的に大きいため、すべてのサブセットを反復するブルートフォース アプローチは即座に除外されます。 したがって、すべてのサブセットをペアごとにチェックすることは不可能です。 ソリューションでは、数値のビット単位表現の構造を利用して、問題を管理可能なものに減らす必要があります。 

主なエッジケースは次の場合に発生します。`x`ゼロの場合、有効なサブセットは同一の要素に制限されます。 たとえば、配列が次の場合、`[0,0,1]`そして`x = 0`、サブセットのみ`[0]`、`[0]`、 そして`[0,0]`有効です。 XOR ビット パターンの構造を無視する不注意な実装では、異なる数値を含むサブセットが誤って含まれる可能性があります。 

もう 1 つの微妙な状況は、数値が下位ビットのみで異なり、上位ビットが次の制約を受ける場合に発生します。`x`。 このような場合、数値を間違ってグループ化したり、バイナリの位置を無視したりすると、無効なサブセットが過大にカウントされる可能性があります。 問題を正しく処理するには、数値のバイナリ表現と、XOR がどのようにビットごとに比較されるかという観点から考える必要があります。`x`。 

## アプローチ

 ブルートフォース手法では、配列の 2ⁿ サブセットをすべて生成し、各サブセット内のすべてのペアごとの XOR を計算し、それらが ≤ を満たすかどうかを確認します。`x`状態。 これは問題定義を直接実装しているため機能しますが、時間計算量は O(n * 2ⁿ) であり、n が 150,000 までの場合は遅すぎます。 

高速な解決策を可能にする観察は、XOR 制約がビット レベルで解釈できることです。 2 つの数値を超える`x`XOR では、ビットが異なる場合、`x`はゼロです。 これにより、当然のことながら、最上位ビットに対する分割統治アプローチが行われます。 ビットが設定されている場合と設定されていない場合に配列を数値に分割し、各パーティションで有効なサブセットを再帰的に計算できます。 現在のビットが`x`が 1 の場合、特定の条件下でパーティション間で要素を混合するサブセットを含めることができます。 0 の場合、サブセットは完全に 1 つのパーティション内に留まる必要があります。 この再帰的戦略を使用すると、各ステップで問題のサイズが指数関数的に減少し、管理可能な O(n log M) のソリューションが得られます (M は最大ビット数 (ここでは 30))。 

動的プログラミングと組み合わせカウントは、この再帰内で自然に発生します。各パーティションについて、サブセットをカウントし、パーティション間のペアが現在のビットで許可されているかどうかに応じてカウントを結合します。`x`。 これにより、明示的に列挙することなく、すべての有効なサブセットを正確に 1 回カウントできるようになります。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n * 2ⁿ) | O(n) | 遅すぎる |
 | ビットの分割統治 | O(n log M) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 問題をバイナリ ドメインに変換します。 最上位ビット位置を考慮してください。`x`は 1 または 0 です。これにより、配列を分割する方法が決まります。 
2. 現在のビットに従って配列を 2 つのグループに分割します。`A0`ここでビットは 0、そして`A1`ここでビットは 1 です。 
3. 現在のビットが`x`が 0 の場合、両方を含む有効なサブセットはありません`A0`そして`A1`要素、XOR が超過するため`x`この時点で。 独立して再帰する`A0`そして`A1`、それらのサブセット数を合計します。 
4. 現在のビットが`x`が 1 の場合、サブセットは両方のパーティションの要素を混合できますが、無効な組み合わせを過剰にカウントしないようにする必要があります。 再帰では、次のサブセット サイズごとにカウントが計算されます。`A0`そして`A1`次に、包含/排他を使用してそれらを慎重に結合し、両方のパーティションにまたがる有効なサブセットをすべてカウントします。 
5. 基本的なケースでは、配列が空の場合は 0 を返します。 1 つの要素が含まれる場合、1 を返します (単一要素のサブセットが有効です)。 
6. 再帰的な結果を結合し、必要に応じて空のサブセットに 1 を加算し、問題では空ではないサブセットが求められているため、最後に 1 を減算します。 

再帰全体で不変なのは、再帰呼び出しが各ビット位置で、XOR が次の部分を超えないパーティション内のすべてのサブセットを正しくカウントすることです。`x`上位ビットで表されます。 現在のビットを 0 か 1 に応じて処理することで、無効なサブセットがカウントされないようにします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 998244353

def solve(a, bit=29):
    if not a or bit < 0:
        return (1 << len(a)) % MOD
    zeros, ones = [], []
    for v in a:
        if (v >> bit) & 1:
            ones.append(v)
        else:
            zeros.append(v)
    if (x >> bit) & 1 == 0:
        return (solve(zeros, bit - 1) + solve(ones, bit - 1)) % MOD
    else:
        sz0 = solve(zeros, bit - 1)
        sz1 = solve(ones, bit - 1)
        return (sz0 + sz1 + (sz0 * sz1 % MOD)) % MOD

n, x = map(int, input().split())
a = list(map(int, input().split()))
res = (solve(a) - 1) % MOD
print(res)
```機能`solve`現在のビットで配列を再帰的に分割します。 いつ`x`そのビットに 0 がある場合、サブセットは単一のパーティションに存在する必要があります。 いつ`x`が 1 の場合、サブセットはパーティション間で混在することができ、サブセット数の外積が加算されます。 最後に 1 を減算すると、空のサブセットが削除されます。 使用する`1 << len(a)`基本的なケースでは、反復せずに現在の配列のすべてのサブセットを効率的にカウントします。 

## 実用的な例

 入力用`[0,1,2,3]`と`x=2`、ビット 1 (0 から数えます) から開始します。 パーティション:

 | ビット | ゼロ | ワンズ |
 | --- | --- | --- |
 | 1 | [0,1] | [2,3] |

 のビット 1`x`は 1 なので、組み合わせることができます。 再帰的`[0,1]`:

 | ビット | ゼロ | ワンズ |
 | --- | --- | --- |
 | 0 | [0] | [1] |

 のビット0`x`が 0 の場合、サブセットはパーティション内に残ります。`solve([0]) = 2`、`solve([1]) = 2`、 組み​​合わせる：`2+2+2*2=8`。 

再帰的`[2,3]`同様に、カウントを結合すると、サブセット全体で 8 が得られます。 空のサブセットの場合は 1 を減算します: 8-1 = 7。カウントされた空でないサブセットを加算し直すと 8 になります。 

このトレースは、再帰的パーティションが各ビットの XOR 制約を正しく尊重し、すべての有効なサブセットをカウントしていることを示しています。
