 ## 解決策
 ## 問題の理解

 整数が与えられます$N$サッカーチームの選手の数を表します。 これらを何通りに分割できるかを数えなければなりません$N$プレーヤーは、ゴールキーパー、ディフェンス、ミッドフィールド、アタックの 4 つの順序付けされたグループに分けられます。 

ゴールキーパー グループには 1 人のプレーヤーが含まれている必要があります。 他の 3 つのグループには、それぞれ少なくとも 1 人のプレーヤーが含まれている必要があります。 すべてのプレーヤーは 1 つのグループにのみ属し、どの特定のプレーヤーが割り当てられるかではなく、グループのサイズのみが問題になります。 

したがって、問題は整数の 4 倍の数を数えるということになります。$(g,d,m,a)$そのような$$g = 1,\quad d \ge 1,\quad m \ge 1,\quad a \ge 1,\quad g+d+m+a = N.$$置き換える$g=1$、解の数が必要です。$$d + m + a = N - 1$$少なくともすべての変数を使用して$1$。 

これは、古典的な制約付き整数合成問題です。 

制約$N \le 10^6$あらゆる解決策は次のようにする必要があることを意味します$O(1)$あるいは最悪の場合$O(\log N)$テストケースごとに。 すべてのパーティションにわたるループや組み合わせ列挙は不可能です。これは、次のように二次または三次的に増大するためです。$N$。 

小さい場合には微妙なエッジケースが発生します。$N$。 もし$N < 4$、ゴールキーパーを1人固定した後、3つのポジティブグループを満たすことができないため、有効なフォーメーションが存在しません。 

## アプローチ

 ブルートフォースソリューションでは、考えられるすべての分割を試みます。$N$プレイヤーを4つのグループに分けます。 ゴールキーパーを修正し、考えられるすべてのサイズのディフェンス、次にミッドフィールドを繰り返し、残りを攻撃に割り当てます。 これにより、2 つのネストされたループが発生します。$d$そして$m$、 と$a$自動的に決定されます。 反復回数は次のように増加します$O(N^2)$が遅すぎるときは、$N$到達する$10^6$。 

重要な観察は、プレーヤーのアイデンティティではなく、グループのサイズのみが重要であるということです。 ゴールキーパーを修正したら、残る問題は正の整数解を数えることです。$d+m+a=N-1$。 これは標準的な星と棒の問題です。 

設定により変数を変換します$d' = d-1$、$m' = m-1$、$a' = a-1$。 それから$$d' + m' + a' = N - 4,$$ここで、すべての変数は負ではありません。 

非負の解の数$x_1 + x_2 + x_3 = S$は$$\binom{S+2}{2}.$$ここ$S = N-4$、したがって、答えは次のようになります$$\binom{N-2}{2}.$$拡大すると、$$\binom{N-2}{2} = \frac{(N-2)(N-3)}{2}.$$これにより、$O(1)$式。

 ## アルゴリズムのチュートリアル

 1. 整数の読み取り$N$。 この値は、ゴールキーパーを含む合計プレーヤーを表します。 
2. もし$N < 4$、出力$0$。 これが必要なのは、残り 3 つのグループにそれぞれ少なくとも 1 人のプレーヤーが含まれている必要があり、少なくとも$1 + 3 = 4$プレイヤーの合計。 
3. コンピューティング$N - 2$。 このシフトは、制約付きパーティションを二項係数式に変換することで生じます。 
4. コンピューティング$(N-2)(N-3)/2$。 これは直接評価します$\binom{N-2}{2}$標準 ID を使用します。 
5. 計算値を出力します。 

### なぜ効果があるのか

 ゴールキーパーを修正すると、合計から 1 人のプレーヤーが削除され、残りのプレーヤーが残ります。$N-1$配布するプレイヤー。 残りの 3 つのグループがそれぞれ空でないことを要求すると、3 つの正の部分の合計が次のようになる標準的な合成問題が発生します。$N-1$。 各変数をシフトする$1$問題を分散に変換します$N-4$3 つのビン間でユニットの区別がつきません。 各ソリューションは有効なフォーメーションに一意に対応するため、構成をカウントすると、有効な戦術分布の正確な数が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input().strip())

if n < 4:
    print(0)
else:
    print((n - 2) * (n - 3) // 2)
```実装は、派生した閉じた形式から直接続きます。 整数の除算は安全です。$(N-2)(N-3)$は常に偶数です: 2 つの連続する整数のうち 1 つは偶数であり、次の割り算が保証されます。$2$。 

唯一の条件付きチェックが無効なレジームを処理します$N < 4$、有効な分割が存在しません。

 のために$N=3$、アルゴリズムは正しく返します$0$これは、公式が適用されず、制約により少なくとも 4 人のプレーヤーが強制されるためです。 実行は条件分岐に到達し、すぐに終了します。 

のために$N=4$、計算により次のように評価されます。$(2 \cdot 1)/2 = 1$、一意の分解に対応$(1,1,1,1)$。 ゴールキーパー以外の各グループには少なくとも 1 人のプレーヤーが含まれている必要があり、自由度がないため、代替の分割は存在しません。
