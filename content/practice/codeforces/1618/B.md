 ## 解決策
 ## 問題の理解

 「a」と「b」のみからなる単語から派生した、重複する 2 文字の文字列、つまりバイグラムのシーケンスが与えられます。 元のシーケンスから 1 つのバイグラムが削除されています。私たちの目標は、残りのバイグラムを 1 つだけ削除した後、残りのバイグラムを生成する可能性がある指定された長さの有効な単語を再構築することです。 

入力は複数のテスト ケースで構成されます。 各テストケースについて、単語の長さがわかっています。$n$そして一連の$n-2$バイグラム。 各バイグラムは次のバイグラムと 1 文字ずつ重なるため、通常は 1 つの単語の長さになります$n$まさに$n-1$バイグラム。 1 つが足りないので、$n-2$バイグラム。 私たちの仕事は、ある長さの単語を再構築することです$n$指定されたシーケンスと一貫性があり、必要に応じて不足している文字を自由に挿入できます。 

制約は控えめです。$3 \le n \le 100$最大 2000 のテスト ケース。 これにより、テスト ケースごとに単純な線形時間で作業できるようになります。$100 \times 2000 = 200,000$操作は簡単です。 

主な微妙な点は、削除されたバイグラムによって重なり合うパターンに「ギャップ」が生じた場合、各バイグラムの 2 番目の文字を連結するだけによる単純な再構成が失敗する可能性があることです。 たとえば、シーケンスが次の場合、`ab aa ba`中央のバイグラムが欠落している場合、単純にバイグラムを連鎖すると次のようになります。`abaa`、短すぎます。 アルゴリズムはそのようなギャップを検出し、正しい語長を維持するために文字を挿入する必要があります。 

## アプローチ

 ブルートフォースアプローチは、欠落しているバイグラムのすべての位置を試し、それを挿入し、結果として得られる長さの単語かどうかを確認することです。$n$1 つを削除すると、観察されたバイグラムが生成されます。 これが機能する理由は、$n \le 100$、しかしそれは面倒で不要です。 可能な挿入数は次のように直線的に増加します。$n$理論的には許容可能であっても、実装では非効率になります。 

重要な洞察は、単語の大部分が貪欲に再構築できるということです。最初のバイグラムの最初の文字が単語の最初の文字であり、後続の各バイグラムがその 2 番目の文字を単語に提供します。 これは、連続するバイグラムが適切に重なっている限り機能します。 現在の単語の最後の文字が次のバイグラムの最初の文字と一致しない場合は、それらの間にバイグラムが欠落していることがわかります。 その場合、2 番目の文字を追加する前に、次のバイグラムの最初の文字を追加してギャップを埋めるだけです。 

この貪欲な方法では、すべてのギャップが欠落しているバイグラムに正確に対応し、アルゴリズムによって結果の単語が正確に一致することが保証されるため、正確さが保証されます。$n$手紙。 エッジケースは暗黙的に処理されます。すべてのバイグラムが完全に重なっている場合、最後のバイグラムの最後の文字で単語が完成します。

 | ギャップチェックで貪欲に再構築 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 単語は最初のバイグラムの最初の文字で始まります。 これにより、再構築された単語の最初の文字が設定されます。 
2. 各バイグラムを最初から最後まで順番に繰り返します。 各バイグラムについて、その最初の文字が現在の単語の最後の文字と一致するかどうかを確認します。 存在する場合は、バイグラムの 2 番目の文字のみを追加します。 そうでない場合は、バイグラムの両方の文字を追加します。 
3. すべてのバイグラムを処理した後、再構成された単語の長さを確認します。 それより短い場合$n$、必要な長さに達するまで、最後のバイグラムの最後の文字を追加します。 

これが機能する理由: 不変条件は、各反復後に、それまでに再構築された単語が、処理されたすべてのバイグラムと一致することです。 連続するバイグラム間の不一致は、欠落しているバイグラムの位置を示しており、両方の文字を追加することで自動的に埋められます。 これにより、最後の単語が常に正確に一致することが保証されます。$n$文字と観察されたすべてのバイグラムが正しく配置されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    bigrams = input().split()
    word = bigrams[0][0]  # start with first character of first bigram
    for bigram in bigrams:
        if word[-1] == bigram[0]:
            word += bigram[1]
        else:
            word += bigram  # missing bigram detected
    if len(word) < n:
        word += bigrams[-1][1]  # ensure length n
    print(word)
```最初の行はテスト ケースの数を読み取ります。 各テスト ケースについて、単語の長さとバイグラムのリストを読み取ります。 再構成は、最初のバイグラムの最初の文字から始まります。 バイグラムに対するループは、通常のオーバーラップと、バイグラムの欠落によって生じるギャップの両方を処理します。 最終的な長さチェックにより、単語が正確であることが保証されます。$n$文字。 重複のない連続したバイグラムや最小限の単語などのエッジ条件は、自然に処理されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    t = int(input())
    for _ in range(t):
        n = int(input())
        bigrams = input().split()
        word = bigrams[0][0]
        for bigram in bigrams:
            if word[-1] == bigram[0]:
                word += bigram[1]
            else:
                word += bigram
        if len(word) < n:
            word += bigrams[-1][1]
        print(word)
    return out.getvalue().strip()
