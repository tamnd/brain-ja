 ## 問題の理解

 円形の配置があります$n$それぞれの町には、最初のレパートリーを持つ歌手がいます。$a_i$分。 すべての歌手が時計回りにすべての町を巡り、各町で演奏します。 演奏するたびに、新しい長さの曲が追加されます$a_i$彼らのレパートリーに追加され、将来のコンサートの期間が増加します。 これが意味するのは、$i$-番目の歌手が出演します$a_i$彼らの故郷で数分間、$2a_i$次の町で数分後、$3a_i$次以降も同様に、最大で$n a_i$最後の町で数分、家に帰ります。 

各町でのすべてのコンサートの合計時間が配列として与えられます。$b$、そして初期レパートリーの長さの可能なシーケンスを再構築する必要があります$a$もしくは無理だと判断する。 

制約が示すのは、$n$まで可能です$4 \cdot 10^4$テスト ケースごとに、すべてのテスト ケースの合計が以下を超えないようにします。$2 \cdot 10^5$。 これは、どのソリューションもおおよそ次の条件で動作する必要があることを意味します。$O(n)$テストケースごとに、$O(n^2)$操作が制限時間を超える可能性があります。 

エッジケースが発生するのは次の場合です$n = 1$または合計期間が$b_i$非常に小さいため、正の整数を取得できない場合があります$a_i$。 もう 1 つの注意を要するシナリオは次のような場合です。$b_i$値は、コンサートの累積によって強制される等差数列構造と一致しません。 

## アプローチ

 強引なアプローチでは、各歌手のすべての町への貢献をシミュレートしようとします。 歌手ごとに$i$、追加します$a_i, 2a_i, \dots, n a_i$それぞれの街へ。 これには必要です$O(n^2)$操作が遅すぎるため、$n \approx 10^5$。 

重要な洞察は、各町の合計が$b_i$の貢献の合計です$a_j$各歌手から$j$、適当に回転させました。 これは、整数に関する線形方程式系として数学的に表すことができます。$$b_i = \sum_{k=0}^{n-1} ((k+1) \cdot a_{(i-k-1+n)\bmod n +1})$$構造モジュロを観察することにより$n$、すべての合計が$b_i$で割り切れます$n$、そして最小限のものを選択することにより、$b_i$参考として、再構築できます$a_i$モジュラー演算を使用します。 具体的には、次の倍数を引くと、$n$から$b_i - b_{i-1}$確実に陽性であることを確認すると、それぞれを計算できます$a_i$直接。 

最適なアプローチでは、モジュラー演算と配列の単一パスを使用します。その結果、$O(n)$テストケースあたりの時間。

 ## アルゴリズムのチュートリアル

 1. すべてのコンサートの所要時間の合計を計算します。$S = \sum b_i$。 もし$S$で割り切れない$n$、それぞれ NO を出力します。$a_i$は整数の分を表し、合計は割り切れる必要があります。 
2. 最小のものを特定する$b_i$配列内で。 モジュール調整を処理し、マイナスを回避するための参考として使用してください。$a_i$。 これにより、再構築されたシーケンスが正の整数で始まることが保証されます。 
3. それぞれについて$i$0から$n-1$、計算する$diff_i = b_i - b_{(i-1+n)\% n}$。 次に計算します$a_i$使用:$$a_i = \frac{diff_i - k \cdot n}{n}$$ある整数に対して$k \ge 0$そのような$a_i > 0$。 用語$k \cdot n$町の数に合わせて差が調整されるようにします。 

1. ある場合$a_i \le 0$、NOを出力します。 それ以外の場合は、YES を出力し、シーケンス$a_1, a_2, \dots, a_n$。 

機能する理由: モジュラー演算により、各歌手の累積貢献量が合計時間と一致することが保証されます。$b_i$町を越えて。 このアルゴリズムは、すべての人の貢献度の合計が不変であることを維持します。$a_i$それぞれの合計$b_i$、配列の循環的な性質を調整しながら。 全てを確保することで、$a_i$が正であれば、問題の制約を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        b = list(map(int, input().split()))
        total = sum(b)
        
        if total % n != 0:
            print("NO")
            continue
        
        a = [0] * n
        possible = True
        for i in range(n):
            diff = b[i] - b[i-1] if i > 0 else b[0] - b[-1]
            # Adjust diff to be positive modulo n
            if diff % n != 0:
                possible = False
                break
            a[i] = diff // n
            if a[i] <= 0:
                possible = False
                break
        
        if possible:
            print("YES")
            print(' '.join(str(x) for x in a))
        else:
            print("NO")

solve()
```コードはすべてのテスト ケースを読み取り、線形時間で処理します。 主要なセクションでは差分を法的に計算しています。$n$すべてが再構築されたことを確認します$a_i$ポジティブです。 循環インデックスを処理する$(i-1+n) \% n$負のインデックスを回避します。
