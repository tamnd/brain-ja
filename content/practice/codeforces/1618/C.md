 ## 解決策
 ## 問題の理解

 正の整数の配列が与えられます。 タスクは正の整数を選択することです$d$配列の要素を 2 色で色付けします: で割り切れる要素は赤です。$d$、および青で割り切れない要素$d$。 隣接する 2 つの要素が同じ色を共有しない場合、その色は「美しい」と言えます。 出力は有効なものでなければなりません$d$綺麗な発色が可能な場合は0、それが不可能な場合は0です。 

制約は中程度です: 配列の長さ$n$最大でも 100 ですが、配列の値は最大 100 まで可能です$10^{18}$。 これは、すべての数値の考えられるすべての約数を素朴に反復処理することはできないことを意味します。$10^{18}$潜在的な約数が多すぎます。 ただし、小さいものは、$n$は、二次的にスケールするアルゴリズムを提供できることを示唆しています。$n$、配列の最初の 2 つの要素について推論して、約数の候補を見つけることができると考えられます。 

すべての要素が等しい場合、微妙なエッジケースが発生します。 たとえば、配列が次の場合、`[5, 5, 5]`、その後任意$d$5 を除算すると、すべての要素が赤色になり、直ちに無効になります。 最初の要素を次のように選択する単純なアプローチ$d$ここで失敗するだろう。 もう 1 つの注意が必要なケースは、配列が数値の倍数と非倍数の間で完全に切り替わる場合です。`[2, 3, 4, 5]`。 私たちは選ばれたものを確実にしなければなりません$d$交互パターンと一致します。 

## アプローチ

 ブルートフォースアプローチでは、あらゆる可能性が試みられます$d$1 から最小の配列要素まで。 それぞれについて$d$の場合は、すべての要素の色を計算し、隣接する要素が同じ色を共有しているかどうかを確認します。 最悪の場合、こうなります$O(n \cdot \text{min}(a_i))$。 とすれば$a_i$できる$10^{18}$、これは不可能です。 

重要な洞察は、美しいカラーリングを実現するには、隣接する要素の可分性が異なることだけが必要であるということです。 したがって、最初の 2 つの要素を調べるだけで十分です。$a_1$そして$a_2$最初の 2 つの要素になります。 有効な$d$、 どちらか$a_1$で割り切れます$d$そして$a_2$そうでない、またはその逆。 これはつまり$d$いずれかの約数を指定できます$a_1$または$a_2$それは他方を分割するものではありません。 以来$n \le 100$のすべての約数を生成する余裕があります。$a_1$そして$a_2$それぞれを候補としてチェックしてください$d$配列全体に対して。 

これにより、検索スペースが大幅に減少します。 まで繰り返す代わりに、$10^{18}$、2 つの数値の約数のみをチェックします。 平均すると、ある数の約数の数は次のようになります。$10^{18}$特に有効なものは 1 つだけ必要なので、管理可能です$d$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * min(a_i)) | お(1) | 遅すぎる |
 | 最適 | O(n * sqrt(max(a_1, a_2))) | O(sqrt(max(a_1, a_2))) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.長さの配列を読み取ります$n$。 もし$n = 2$、 どれでも$d$1 つの要素だけを分割する方法は機能するため、これは簡単なケースとして扱います。 
2. 最初の 2 つの要素を取得します。$a_1$そして$a_2$、すべての正の約数を生成します。 数字の場合$x$、約数は反復することで見つけることができます$i$1から$\sqrt{x}$、そして両方を追加します$i$そして$x/i$いつ$i$分割する$x$。 
3. 各約数について$d$の$a_1$、どうかを確認してください$d$分割する$a_2$。 そうなった場合は破棄してください。 そうでない場合は、これを試してください$d$候補としては。 
4. 同様に、各約数を確認します。$a_2$それは分けない$a_1$。 
5. 各候補者について$d$、配列を反復処理して、各要素の色を計算します。 隣接する要素が同じ色の場合は破棄します。$d$。 それ以外の場合は、印刷して停止します。 
6. 機能する候補がない場合は、0 を出力します。 

機能する理由: アルゴリズムにより、最初の 2 つの要素が異なる方法で描画されるようになります。$d$それらのうちの 1 つを正確に分割するために選択されます。 隣接する要素は割り算パターンで交互に配置され続けるため、配列の中央でいずれかの候補が失敗した場合は、次の割り数を試します。 最初の選択が有効なカラーリングを伝播しない場合にのみ配列が失敗する可能性があるため、これにより正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import isqrt

def divisors(x):
    result = set()
    for i in range(1, isqrt(x) + 1):
        if x % i == 0:
            result.add(i)
            result.add(x // i)
    return result

def beautiful_coloring(a):
    a1, a2 = a[0], a[1]
    candidates = divisors(a1).union(divisors(a2))
    for d in candidates:
        color = [0] * len(a)
        color[0] = 1 if a[0] % d == 0 else 0
        valid = True
        for i in range(1, len(a)):
            color[i] = 1 if a[i] % d == 0 else 0
            if color[i] == color[i-1]:
                valid = False
                break
        if valid:
            return d
    return 0

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(beautiful_coloring(a))
```コードは、次を使用して入力をすばやく読み取ります。`sys.stdin.readline`複数のテストケースの場合。 最初の 2 つの要素のすべての約数を生成し、各候補を反復して有効な色付けが生成されるかどうかを確認します。 カラーリング チェックでは、単純な配列を使用してカラーを 1 または 0 として保存し、繰り返されるカラーが見つかった場合は早期に終了するフラグを使用します。 

## 実用的な例

 **例 1**:

 配列`[1, 2, 3, 4, 5]`。 1の約数は`{1}`。 2の約数は、`{1, 2}`。 候補者:`{1, 2}`。 

| 私 | a[i] | d=1 の色 | d=2 の色 |
 | --- | --- | --- | --- |
 | 0 | 1 | 1 | 0 |
 | 1 | 2 | 1 | 1 |
 | 2 | 3 | 1 | 0 |
 | 3 | 4 | 1 | 1 |
 | 4 | 5 | 1 | 0 |

 隣接する 1 と 2 が両方ともカラー 1 であるため、d=1 は失敗します。d=2 は機能します。 出力: 2。 

**例 2**:

 配列`[10, 5, 15]`。 10の約数`{1, 2, 5, 10}`。 5の約数`{1, 5}`。 候補者:`{1, 2, 5, 10}`。 

各候補をテストすると、隣接する一致がなければ交互の色が得られるものはありませんでした。 出力: 0。 

## 複雑さの分析

 | 時間 | O(n * sqrt(max(a_1, a_2))) | 各候補約数 (~sqrt(a1) + sqrt(a2)) について、n 個の要素をチェックします。 |
 | スペース | O(sqrt(max(a_1, a_2))) | 最初の 2 つの要素の約数を格納します。 |
