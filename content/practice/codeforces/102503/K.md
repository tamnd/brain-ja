 ## 問題の理解

 長方形のボードがあります`j`行と`g`列。 配置する必要があります`p`すべてのペアの 2 つの靴が正確に離れているように、靴をペアにします。`c`4 つの基本方向のいずれかにあるセル。 どのセルにも 2 つの靴を含めることはできません。 問題は、取締役会に十分な独立した有効なポジションのペアがあるかどうかです。 

難しさは大きな制限から来ています。 到達できるテストケースの数は、`100000`、すべての次元は次のように大きくできます。`10^18`。 ボードを構築したり、すべてのセルをスキャンしたり、すべての行や列を反復したりするようなソリューションは不可能です。 次元の算術のみを使用した定数時間または対数時間の計算が必要です。 

よくある間違いは、水平ペアと垂直ペアを別々に数えて加算することです。 水平ペアで使用されるセルは垂直ペアでも使用できないため、これにより機会が 2 倍にカウントされます。 方向間の相互作用が問題の主要な部分です。 

距離が 1 次元よりも大きい場合、別のエッジ ケースが発生します。 たとえば、入力の場合`1 5 10 1`、基板が狭すぎて距離が短すぎるため、2 つのセルを接続できません。`10`。 正しい答えは、`NAY`。 セルの合計数のみをチェックするソリューションでは、使用可能なセルが 5 つあるため、誤って受け入れられる可能性があります。 

2 番目のエッジ ケースは、圧縮された次元が奇数の場合に発生します。 例えば、`3 3 2 5`唯一の残差コンポーネントに 9 つのセルがあります。 ペアの最大数は`4`、したがって、答えは次のとおりです`NAY`。 不注意な解決策は、2 つのセルごとにペアを形成し、`floor(total_cells / 2)`その動きを考慮せずに世界的に`c`ボードを個別のコンポーネントに分割します。 

## アプローチ

 直接的なアプローチでは、すべてのセルをグラフの頂点としてモデル化します。 2 つの頂点のセルが正確に一致する場合、エッジが存在します。`c`水平方向または垂直方向に離して配置します。 次に問題は、一致する最大サイズを見つけることになります。 これは正しいです。選択されたすべての一致エッジが 1 つの靴のペアに対応し、一致によりセルが再利用されないことが保証されます。 

問題は、グラフに最大で次のものを含めることができることです。`10^36`セルなので、頂点を保存することさえ不可能です。 グラフは非常に規則的な構造をしているため、小さなボードでも一般的なマッチング アルゴリズムを実行するのは不要な作業です。 

重要な観察は、正確に移動していることです。`c`行または列がセルの行モジュロを変更することはありません`c`または列モジュロ`c`。 したがって、細胞は 2 つの残基に基づいて独立した成分に分割されます。 1 つのコンポーネント内で、座標を係数で圧縮した後`c`の場合、グラフは隣接する圧縮セルが接続された通常の長方形のグリッドになります。 

長方形グリッド グラフ`a`行と`b`列の最大一致数は次のとおりです`floor(a*b/2)`。 セルの数が偶数の場合、市松模様の色は等しい辺を与え、完全に一致します。 セルの数が奇数の場合、一致しないセルは最大 1 つだけになります。 

残りのタスクは、次の合計を計算することです。`floor(rows_in_residue * cols_in_residue / 2)`残基を反復せずに、すべての残基ペアに対して実行します。 行数の形式は単純です。 その中で、`c`考えられる行残基の数の違いは、最大でも 1 です。 列についても同様です。 より大きなサイズを持つ残基グループがいくつあるかを知る必要があるだけです。 

させて：`A = j // c`、`ar = j % c`は、基本行グループ サイズと、追加の 1 行を受け取る行残基の数になります。 同様に、`B = g // c`、`br = g % c`列について説明します。 

がある`ar`サイズの行グループ`A + 1`そして`c - ar`サイズのグループ`A`、しかし、ただ`min(j, c)`グループは実際に存在します。 以下の場合にも同じ調整が適用されます。`c`次元よりも大きいです。 

合計は、行グループの大小、列グループの大小に応じて 4 種類の剰余成分に分けることができます。 これら 4 つの組み合わせの数は積であり、各コンポーネントはその面積の半分を切り捨てたものになります。

 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 実際の行剰余グループと列剰余グループの数を計算します。 もし`c`次元より大きい場合、その数の剰余のみが表示されます。 
2. 行グループを 2 つのカテゴリに分割します。 小さい行グループにはサイズがあります`j // c`、 そして`j % c`グループは1つ大きくなります。 列についても同じことを行います。 
3. 4 つの可能なコンポーネント タイプによってもたらされる、一致するペアの合計数を計算します。 すべての行カテゴリと列カテゴリについて、そのようなコンポーネントの数に次の値を掛けます。`floor(component_height * component_width / 2)`。 
4. 結果として得られるペアの最大数を次と比較します。`p`。 印刷する`YAY`最大値が少なくとも`p`、それ以外の場合は印刷します`NAY`。 

これが機能する理由: 両方の座標が剰余を剰余として保持しているため、有効な靴のペアはすべて 1 つの剰余コンポーネント内に留まります。`c`。 コンポーネントは独立しているため、最大限のマッチングを追加できます。 各コンポーネントは長方形グリッドであり、長方形グリッドは常に 1 つを除くすべてのセルと一致します。 この式では、すべてのコンポーネント タイプのセルの正確な数が計算されるため、合計は靴のペアの可能な最大数となります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(j, g, c, p):
    row_groups = min(j, c)
    col_groups = min(g, c)

    row_small = j // c
    row_big_count = min(j % c, row_groups)
    row_small_count = row_groups - row_big_count

    col_small = g // c
    col_big_count = min(g % c, col_groups)
    col_small_count = col_groups - col_big_count

    ans = 0

    ans += row_small_count * col_small_count * ((row_small * col_small) // 2)
    ans += row_small_count * col_big_count * ((row_small * (col_small + 1)) // 2)
    ans += row_big_count * col_small_count * (((row_small + 1) * col_small) // 2)
    ans += row_big_count * col_big_count * (((row_small + 1) * (col_small + 1)) // 2)

    return "YAY" if ans >= p else "NAY"

def main():
    t = int(input())
    out = []
    for _ in range(t):
        j, g, c, p = map(int, input().split())
        out.append(solve_case(j, g, c, p))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```コードはまず、実際に出現する剰余クラスの数を計算します。 これが重要になるのは、`c`よりも大きいです`j`または`g`空でないグループの数が行または列の数を超えることはできないためです。 

変数`row_big_count`そして`col_big_count`追加の行または列を 1 つ受け取る剰余クラスを表します。 残りのクラスのサイズは小さくなります。 4 つの追加は、これらのカテゴリの 4 つの組み合わせに直接対応します。 

Python の整数は、オーバーフローを心配することなく、必要な範囲までの値を処理します。 最大の乗算は約`10^36`、これは Python の任意精度整数によって依然として安全にサポートされています。

 ## 特殊なケース

 のために`1 5 10 1`の場合、アルゴリズムは 1 つの行グループと 5 つの列グループを計算しますが、すべてのコンポーネントの幅は圧縮後に必要な動きよりも小さくなります。 計算された最大一致はゼロであるため、次の値が返されます。`NAY`。 

のために`3 3 2 5`、残基グループのサイズは両方の次元で 2 と 1 です。 4 つの構成領域は次のとおりです。`4`、`2`、`2`、 そして`1`、寄付をする`2`、`1`、`1`、 そして`0`。 合計は`4`より小さい`5`、したがってアルゴリズムは戻ります`NAY`。 

のために`1 1 1 1`、唯一のコンポーネントには単一のセルが含まれます。 その一致する貢献度は、`floor(1/2) = 0`これにより、すべてのセルをペアリングできると仮定した無効な回答が防止されます。
