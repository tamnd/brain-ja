 ## 問題の理解

 (n \times n) 個のチェス盤があります。 個々のセルには最大 (n) 個のチェッカーを配置できます。 残りのすべてのセルは 1 つのドミノでカバーされなければなりません。ドミノは常に 1 面を共有する 2 つのセルをカバーします。 チェッカーの配置は、残りのボードに可能なドミノ タイリングが 1 つだけ存在するように選択する必要があります。 

入力には (2 \le n \le 100) を含む (n) のみが含まれています。 出力は (n \times n) グリッドです。`#`チェッカーを表し、`.`フリーセルを表します。 構築は存在することが保証されています。 公式の制限は 2 秒および 512 MB です。 

100 という小さな上限は、少し誤解を招きます。 これは、ボード全体を検索する必要がある問題ではありません。 (n^2) 個のセルがあり、正確に (n) 個のチェッカーを含む配置のみを考慮しても、(\binom{n^2}{n}) 個の候補が得られます。 (n=100) の場合、これはおおよそ (10^{242}) となるため、網羅的な構築は完全に不可能です。 意図したソリューションでは、慎重に設計されたパターンが 1 つだけ必要という事実を利用する必要があります。 

一般的なパリティベースの構造では誤って処理される可能性のあるエッジケースがいくつかあります。 (n=2) の場合、最初の行の両方のセルにチェッカーを入れると 2 行目 (ちょうど 1 つのドミノ) が残ります。`##`に続く`..`はすでに有効です。 (n=3) の場合、一般的な奇数サイズの交互コーナー構造は機能しないため、別の小さな構造が必要です。 サンプル自体は、そのような構造の 1 つを提供します。```

## アプローチ

 ブルート フォース ソリューションでは、最大 (n) 個のチェッカー セルの可能なすべてのセットを試すことができます。 次に、すべての候補について、残りのセルをタイル化できるかどうか、およびそのタイル化が一意であるかどうかを判断する必要があります。 候補セットだけでも少なくとも (\binom{n^2}{n}) 個あります。 (n=100) では、タイリングをチェックする作業を行う前は、これは約 (10^{242}) になります。 ブルートフォースは定義を明示的にテストするため正しいですが、検索空間は実行可能なものをはるかに超えています。 

有益な観察は、タイリングを検出する必要がないということです。 境界上のチェッカーがすべてのドミノを次々と強制するようにボードを構築できます。 セルに隣接する可能性のある空きセルが 1 つだけあると、そのドミノは強制されます。 そのドミノを配置すると、別のセルに可能なパートナーが 1 つだけになる可能性があり、強制配置のチェーンが作成されます。 

偶数 (n) の場合、すべての奇数行の最初と最後の列にチェッカーを置きます。 これは正確に (n) 個のチェッカーを使用します。 次に、すべての偶数行の端にあるセルが水平方向に強制され、これにより奇数行の隣接するセルが中心に向かって強制されます。 

奇数 (n \ge 5) の場合、チェッカーを 2 つの極端な列の間で交互に実行します。 奇数行は最初の列にチェッカーを受け取り、偶数行は最後の列にチェッカーを受け取ります。 ここでも正確に (n) 個のチェッカーがあります。 交互の境界により、ボード全体に広がる強制ドミノのチェーンが作成されます。 公式チュートリアルで紹介されている構築です。 

唯一の例外的な値は (n=3) であり、これに対してサンプルからの小さな構造を使用します。 ケース (n=2) は直接処理されます。

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    board = [['.' for _ in range(n)] for _ in range(n)]

    if n == 2:
        board[0][0] = '#'
        board[0][1] = '#'

    elif n == 3:
        board = [
            list("..."),
            list("##."),
            list("#.."),
        ]

    elif n % 2 == 0:
        for r in range(0, n, 2):
            board[r][0] = '#'
            board[r][n - 1] = '#'

    else:
        for r in range(n):
            if r % 2 == 0:
                board[r][0] = '#'
            else:
                board[r][n - 1] = '#'

    sys.stdout.write('\n'.join(''.join(row) for row in board))

if __name__ == "__main__":
    solve()

import sys
import io

def solve_data(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        n = int(sys.stdin.readline())
        board = [['.' for _ in range(n)] for _ in range(n)]

        if n == 2:
            board[0][0] = '#'
            board[0][1] = '#'

        elif n == 3:
            board = [
                list("..."),
                list("##."),
                list("#.."),
            ]

        elif n % 2 == 0:
            for r in range(0, n, 2):
                board[r][0] = '#'
                board[r][n - 1] = '#'

        else:
            for r in range(n):
                if r % 2 == 0:
                    board[r][0] = '#'
                else:
                    board[r][n - 1] = '#'

        sys.stdout.write('\n'.join(''.join(row) for row in board))
        return sys.stdout.getvalue()

    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

def run(inp: str) -> str:
    return solve_data(inp)

def count_tilings(board):
    n = len(board)
    free = []

    for r in range(n):
        for c in range(n):
            if board[r][c] == '.':
                free.append((r, c))

    index = {cell: i for i, cell in enumerate(free)}
    full = (1 << len(free)) - 1

    memo = {}

    def dfs(mask):
        if mask == full:
            return 1

        if mask in memo:
            return memo[mask]

        for i, (r, c) in enumerate(free):
            if mask & (1 << i):
                continue

            ways = 0

            for dr, dc in ((1, 0), (0, 1)):
                nr, nc = r + dr, c + dc
                j = index.get((nr, nc))

                if j is not None and not (mask & (1 << j)):
                    ways += dfs(mask | (1 << i) | (1 << j))

            memo[mask] = ways
            return ways

        return 0

    return dfs(0)

def validate_small(inp: str):
    n = int(inp)
    out = run(inp).strip().splitlines()

    assert len(out) == n
    assert all(len(row) == n for row in out)

    checkers = sum(row.count('#') for row in out)
    assert checkers <= n

    board = [list(row) for row in out]
    assert count_tilings(board) == 1

# Small odd case that needs the special construction
validate_small("5\n")

# Boundary and parity case
validate_small("6\n")

assert all(len(row) == 100 for row in out)
assert all(ch in ".#" for row in out for ch in row)
