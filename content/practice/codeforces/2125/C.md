 ## 解決策
 ## 問題の理解

 素因数分解でどの素数も 1 桁の素数でない場合、その数値は良好であると呼ばれます。 1 桁の素数は 2、3、5、7 のみであるため、これら 4 つの素数のいずれでも割り切れない数値は正確に適切です。 

タスクは、範囲内の整数の個数をカウントすることです$[l,r]$この性質を満たします。 

限界によって、問題をどのように考えるかが完全に変わります。 間隔のエンドポイントは次のように大きくできます。$10^{18}$, したがって、数字を1つずつ因数分解することは不可能です。 範囲自体には最大で 1 つの範囲が含まれるため、その間隔を反復することさえ不可能です。$10^{18}$数字。 エンドポイントで直接機能するカウント式が必要です。 

重要な観察は、その定義が 4 つの特定の素数による割りやすさのみに依存しているということです。 少なくとも 2 桁の素数はすべて許可されるため、数値に大きな素数が含まれているかどうかは気にしません。 

いくつかの特殊なケースは見落とされがちです。 

次の範囲を考慮してください。```
13 37
```答えは 25 ではなく 7 です。この範囲内のほとんどの数値は 2、3、5、または 7 で割り切れるため、除外する必要があります。 

考慮する：```
11 11
```答えは 1 です。11 という数字自体は 2 桁の素数なので、問題ありません。 

考慮する：```
14 14
```答えは 0 です。14 には素数 7 が 1 回しか含まれていませんが、それだけで問題が生じます。 多重度は関係ありません。 

考慮する：```
49 49
```答えは 0 です。一部のソリューションでは、1 回出現する 7 未満の素因数だけを誤ってチェックします。 以来$49=7^2$、まだ 7 で割り切れず、悪いままです。 

この問題は実際には、2、3、5、または 7 のいずれでも割り切れない整数の数を求めています。 

## アプローチ

 ブルート フォース ソリューションでは、区間内のすべての数値を反復処理し、因数分解して、すべての素因数が少なくとも 10 であるかどうかを検証します。これは、定義を直接実装しているため、正しいです。 

残念ながら、単一の間隔の長さをチェックするだけでも$10^{18}$不可能です。 1 つの数値を因数分解するには、大まかに次のことが必要です$O(\sqrt n)$仕事、あるかもしれない$10^{18}$検査する数値。 

重要な観察は、数値が 2、3、5、または 7 で割り切れない場合にのみ有効であるということです。 

これにより、問題は古典的な計数問題に変換されます。 適切な数値を直接特定するのではなく、これら 4 つの素数のうち少なくとも 1 つで割り切れる数値をすべて数え、合計から引きます。 

複数の集合で割り切れる数を同時にカウントする必要がある場合には、包含-除外が自然なツールになります。 関係する素数は 4 つだけなので、サブセットの数はごくわずかです。$$2^4=16.$$どれについても$x$、 させて$F(x)$内の適切な整数の数を示します$[1,x]$。 

素数の特定のサブセットで割り切れる整数の数は以下に等しい$$\left\lfloor \frac{x}{\operatorname{lcm}(\text{subset})} \right\rfloor.$$素数は個別であるため、LCM は単純にその積です。 

包含-排他を適用すると、少なくとも 1 つの禁止された素数で割り切れる整数の数が得られます。 から引く$x$収量$F(x)$。 クエリに対する答えは次のようになります。$$F(r)-F(l-1).$$| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O((r-l+1)\sqrt r)$|$O(1)$| 遅すぎる |
 | 最適 |$O(2^4)$テストケースごと |$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 禁止された素数を次のようにします。$$P=\{2,3,5,7\}.$$与えられた値に対して$x$、 定義する$F(x)$適切な整数の数として$[1,x]$。 

1. から始める`bad = 0`。 
2. 空でないすべてのサブセットを列挙します。$\{2,3,5,7\}$。 
3. サブセット内の素数の積を計算します。 素数は個別であるため、この積はそれらの最小公倍数でもあります。 
4. の整数がいくつあるかを計算します。$[1,x]$はこの積で割り切れます:$$\left\lfloor \frac{x}{\text{product}} \right\rfloor.$$5. サブセットのサイズが奇数の場合は、この量を`bad`。 
6. サブセットのサイズが偶数の場合、この数量を次の値から引きます。`bad`。 

これはまさに包含排他原理です。 
7. すべてのサブセットを処理した後、`bad`の整数の数に等しい$[1,x]$少なくとも 1 つの禁止された素数で割り切れる。 
8. コンピューティング$$F(x)=x-bad.$$9. 各クエリについて$[l,r]$、出力$$F(r)-F(l-1).$$### なぜ効果があるのか

 数値が少なくとも 1 つのセットに属している場合、その数値は不正です。$$A_2,A_3,A_5,A_7,$$どこ$A_p$で割り切れる数値が含まれています$p$。 

包含-排他により結合のサイズが計算されます。$$|A_2\cup A_3\cup A_5\cup A_7|$$その通り。 1 つの禁止された素数で割り切れるすべての数値が 1 回寄与します。 複数の禁止素数で割り切れるすべての数値は、包含と除外の交互の符号によって補正されます。 

合計数からユニオン サイズを減算する$x$禁止されている素数で割り切れない数値をそのまま残します。 これらはまさに良い数字ですので、$F(x)$は正しいです。 取る$F(r)-F(l-1)$カウントを要求された間隔に制限します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

PRIMES = [2, 3, 5, 7]

def count_good(x):
    if x <= 0:
        return 0

    bad = 0

    for mask in range(1, 16):
        prod = 1
        bits = 0

        for i in range(4):
            if mask & (1 << i):
                prod *= PRIMES[i]
                bits += 1

        cnt = x // prod

        if bits & 1:
            bad += cnt
        else:
            bad -= cnt

    return x - bad

def solve():
    t = int(input())

    ans = []

    for _ in range(t):
        l, r = map(int, input().split())
        ans.append(str(count_good(r) - count_good(l - 1)))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```機能`count_good(x)`プレフィックス内の適切な整数の数を計算します$[1,x]$。 

マスク上のループは、空でないすべてのサブセットを表します。`{2,3,5,7}`。 素数は 4 つだけなので、ちょうど 15 個の空ではないサブセットが存在します。 

各サブセットについて、その積とプレフィックス内の倍数を計算します。 奇数サイズのサブセットはプラスに寄与し、偶数サイズのサブセットはマイナスに寄与し、包含と排除が一致します。 

表現`x - bad`悪い数値の数を良い数値の数に変換します。 

最終的な答えは、標準的なプレフィックスカウント手法を使用します。$$\text{answer}=F(r)-F(l-1).$$最大の中間積は次のとおりであるため、すべての算術演算は 64 ビット整数に快適に収まります。$$2\cdot3\cdot5\cdot7=210,$$一方、Python の整数はとにかく任意の精度をサポートします。
