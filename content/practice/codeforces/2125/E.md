 ## 解決策
 ## 問題の理解

 この問題では、正の整数の配列から補和として生成できる整数のセットを数えるように求められます。 具体的には、一定のサイズを指定すると、`n`そして上限`x`、個別のセットの数が必要です`Q`まさに`n`各要素が間にある要素`1`そして`x`。 各セット`Q`何らかの配列に対応する`a`正の整数の各要素について`a_i`で`a`私たちは含めます`s - a_i`セット内で、ここで`s`配列の合計です。 重複する値は破棄されます。`Q`マルチセットではなくセットです。 

入力は大規模です:`n`そして`x`最大 200,000、最大 10,000 のテスト ケースが可能で、合計は`n`そして`x`すべてのテスト ケースでも 200,000 に制限されます。 これにより、複雑度が O(n^2) または O(x^2) の解は除外され、O(n x) であっても、10^8 の演算を超えないよう慎重に実装する必要があります。 ほぼ線形のアルゴリズムが必要です。`x`テストケースごとに。 

微妙なエッジケースが発生する場合`n`よりも大きいです`x`。 たとえば、次の場合`n = 5`そして`x = 4`、すべての要素が ≤ 4 でなければならないため、サイズ 5 のセットは存在できません。別の厄介な状況が次の場合に発生します。`n`1 に等しい: 1 から 1 までの任意の数`x`単独で有効なセットを形成します。 配列を列挙しようとする単純な試み`a`配列の数が指数関数的に増加するため、失敗します。 

## アプローチ

 ブルートフォースアプローチは、考えられる配列をすべて列挙することです。`a`そしてそれらの相補的な合計セットを生成します`Q`。 次に、これらのセットをサイズと上限によってフィルタリングします。 これは非常に小さな入力では機能しますが、次の場合は不可能になります。`n`そして`x`何十万もの単位で。 具体的には、配列の数が指数関数的に増加します。`n`、最小の入力サイズですら実行不可能になります。 

重要な観察は、問題は次の整数のセットを数えることに帰着するということです。`1`に`x`それは次のように表すことができます`s - a_i`一部の人にとっては`s`およびいくつかの正の整数`a_i`。 セットをソートする場合は、その要素を呼び出します`b_1 < b_2 < ... < b_n`、ある程度の金額がかかることがわかります`s`、 それぞれ`a_i = s - b_i`ポジティブである必要があります。 したがって、`s > b_i`みんなのために`i`。 少なくとも`n`明確な正の数`a_i`、これは、セットの最小要素が最大でも次の要素であることを意味します。`s - n + 1`。 

このことから、必要なセットはまさに次のシーケンスであることがわかります。`n`各要素の数値`b_i`少なくとも`i`。 次に、有効なセットの数は、組み合わせカウントの問題、つまり、次のサブセットをカウントするという問題に帰着します。`{1, 2, ..., x}`サイズの`n`ここで、最大要素と要素数の差は単純な不等式を満たします。 これにより、動的プログラミング アプローチまたは二項係数を法とする組み合わせ式の使用が可能になります。`998244353`。

 ## アルゴリズムのチュートリアル

 1. 階乗および逆階乗モジュロを事前計算する`998244353`最大まで`x`すべてのテストケースにわたって。 これにより、二項係数の効率的な計算が可能になります。 
2. パラメーターを含む各テスト ケースについて`n`そして`x`、どうかを確認してください`n > x`。 その場合、サイズのセットを形成することが不可能であるため、0 を出力します。`n`までの要素を含む`x`。 
3. それ以外の場合は、選択する方法の数を計算します。`n`からの要素`x`連続した整数。 重要な洞察は、有効なセットが次のシーケンスに対応しているということです。`n`最大の数値は次のとおりです`x`。 組み合わせ公式を使用すると、カウントは次のように求められます。`C(x, n)`モジュロ`998244353`。 
4. 各テストケースの計算値を出力します。 

正確さを保証する不変条件は、有効な相補和セットが厳密に増加する一連の数値に対応し、各数値が ≤ でなければならないということです。`x`。 サイズのサブセットを数える`n`内で`1..x`あらゆる可能性を正確に捉えます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAX = 2 * 10**5 + 5

# Precompute factorials and inverse factorials
fact = [1] * MAX
inv_fact = [1] * MAX

for i in range(1, MAX):
    fact[i] = fact[i - 1] * i % MOD

inv_fact[MAX - 1] = pow(fact[MAX - 1], MOD - 2, MOD)
for i in range(MAX - 2, -1, -1):
    inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

def comb(n, k):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n - k] % MOD

t = int(input())
for _ in range(t):
    n, x = map(int, input().split())
    if n > x:
        print(0)
    else:
        print(comb(x, n))
```階乗と逆乗の事前計算により、あらゆる二項係数を O(1) 時間で計算できることが保証されます。 メインループは、境界チェックを伴う組み合わせ式を単純に適用します。`n > x`。 全体でモジュラー演算を使用すると、オーバーフローが防止されます。

 ## 特殊なケース

 いつ`n > x`、 のような`n = 6`そして`x = 5`の場合、アルゴリズムはすぐに 0 を返します。数値 1 から 5 からサイズ 6 のセットを形成することは不可能であるため、階乗や組み合わせを計算する必要はありません。`n = x`の場合、アルゴリズムは 1 を返します。これは単一セットに対応します。`{1,2,...,x}`。 のために`n = 1`、アルゴリズムは戻ります`x`、すべての単一要素セットを正確にカウントします。 これらの特殊なケースは、組み合わせ計算の前に単純な境界チェックによって処理されます。
