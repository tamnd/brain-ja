 私たちは与えられています$n$一定濃度の溶液が入ったボトル$w_i$。 クエリごとに、正確な目標濃度の溶液を得るためにこれらのボトルのサブセットをいくつ混合できるかが尋ねられます。$x$。

最も微妙な点は、実現可能性は、$x$選択したサブセットの最小値と最大値の間にあります。 サブセットに上下両方の値が含まれる場合$x$、凸の組み合わせで到達可能$x$。 すべての値が片側にある場合$x$、選択されたすべての値が正確に等しくない限り不可能です$x$。

 ブルートフォースのアイデアは単純です。 クエリごとに、ボトルのすべてのサブセットを列挙し、目標濃度を形成できるかどうかを確認します。 固定サブセットの場合、実現可能性は、サブセット内の最小値と最大値が許容するかどうかをチェックすることになります。$x$凸包内にあることをサブセットごとに線形時間で検証できます。 これは次のことにつながります$O(2^n \cdot n)$、これはすぐに実行不可能になります。 

重要な観察は、サブセットの実現可能性は、その下に選択された要素がいくつあるかによってのみ決まるということです。$x$、 その上$x$、と等しい$x$。 クエリ値を修正したら$x$、すべての要素は 3 つのカテゴリに分割されます。$x$、に等しい$x$、およびそれ以上$x$。 サブセットが形成される可能性があります$x$厳密に小さい要素と厳密に大きい要素が少なくとも 1 つ含まれるか、または次と等しい要素のみが含まれる場合$x$。

 ## アルゴリズムのチュートリアル

 ### 前処理

 1. すべて並べ替える$w_i$。 並べ替えを使用すると、しきい値以下の値がいくつあるかをバイナリ検索することで各クエリに答えることができます。 これにより、すべての要素をスキャンするのではなく、各クエリが単純なカウントに変換されます。 
2. 最大 2 の累乗を事前計算します。$n$モジュロ$10^9 + 7$。 後の各サブセットの数は、独立したグループからの任意のサブセットの選択に依存します。 

### クエリ処理

 各クエリ値について$x$:

 1. 探す$L$、要素の数が厳密に小さい$x$、ソートされた配列に対して二分探索を使用します。 
2. 探す$E$、要素の数は次のとおりです$x$、2 つの二分探索 (下限と上限) を使用します。 これにより、厳密な不等号とは異なる動作をする完全一致が分離されます。 
3. コンピューティング$G = n - L - E$、要素の数が厳密に大きい$x$。 
4. 小さい要素と大きい要素の両方を含まないすべてのサブセットを数えます。 これらはまたがることができないため無効です$x$。 そのようなサブセットは次のとおりです。 

- 完全に内部のサブセット$L \cup E$、貢献$2^{L+E}$、
 - 完全に内部のサブセット$G \cup E$、貢献$2^{G+E}$、
 - ただし、完全にその中にあるサブセット$E$は 2 回カウントされるため、減算します$2^E$。 
5. 有効なサブセットの合計は次のとおりです。$$2^n - 2^{L+E} - 2^{G+E} + 2^E$$6. この値をモジュロで出力します$10^9 + 7$。 

### なぜ効果があるのか

 すべてのサブセットは、次の 3 つの構造カテゴリのいずれかに分類されます。$x$: 小さい要素と大きい要素の両方が含まれているか、含まれていません。 両方を含む場合、凸の組み合わせは常に実現できます。$x$。 そうでない場合は、選択されたすべての要素が完全に片側に配置されます。$x$またはそれに等しい。そのようなサブセットは、以下の要素のみで構成されていない限り失敗します。$x$。 この式はすべてのサブセットをカウントし、またがる機能を欠いているサブセットを正確に削除します。$x$、等価グループに対する包含-除外によって重複を修正します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def build_powers(n):
    pw = [1] * (n + 1)
    for i in range(1, n + 1):
        pw[i] = (pw[i - 1] * 2) % MOD
    return pw

def lower_bound(a, x):
    lo, hi = 0, len(a)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid
    return lo

def upper_bound(a, x):
    lo, hi = 0, len(a)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] <= x:
            lo = mid + 1
        else:
            hi = mid
    return lo

def solve():
    n, q = map(int, input().split())
    w = [float(input().strip()) for _ in range(n)]
    w.sort()

    pw = build_powers(n)

    out = []

    for _ in range(q):
        x = float(input().strip())

        L = lower_bound(w, x)
        R = upper_bound(w, x)
        E = R - L
        G = n - R

        total = pw[n]
        bad1 = pw[L + E]
        bad2 = pw[G + E]
        bad3 = pw[E]

        ans = (total - bad1 - bad2 + bad3) % MOD
        out.append(str(ans))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装は並べ替えに依存して、各クエリが 2 つのバイナリ検索のみに依存するようにします。 この制御された形式で浮動小数点として読み取られた場合、固定精度の浮動小数点入力は一貫して動作するため、注意が必要なのは 2 つの境界を使用して正確な等価性を計算することです。 

包含-排他構造は、事前に計算された 2 のべき乗の算術演算として直接実装され、サブセットごとの推論を回避します。

 ## 特殊なケース

 いつすべて$w_i$に等しい$x$、私たちは得ます$L = 0$、$G = 0$、$E = n$。 式は次のようになります$2^n - 2^n - 2^n + 2^n = 2^n$、すべてのサブセットが有効であることを意味します。 これは、同じ値の凸状の組み合わせが同一のままであるという事実と一致します。
