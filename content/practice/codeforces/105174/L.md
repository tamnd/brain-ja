 ## 解決策
 ## 問題の理解

 都市 1 に根を持つ根付きツリーが与えられています。他のすべての都市は接続されているため、2 つの都市の間には 1 つの単純なパスが存在します。 王の毎年の旅行にとって重要な都市は国境の都市であり、これは根そのものを除いた木の葉を意味します。 

毎年、王はまだ訪れていない国境の都市を1つ選びます。 彼は首都から独特の木道を通ってその街へと旅します。 道に沿って歩いているときに、国王が遭遇した首都以外の都市はすべて、国王が過去の年に初めてその都市を通過した場合には「新たに視察」されたものとしてカウントされます。 選ばれた葉に到達した後、彼は王都に戻ります。 時間の経過とともに、すでに検査が行われている国内都市が増えていくため、後の旅行では新たに検査を受ける都市が少なくなる可能性があります。 

毎年、その旅行中に新たに視察された都市の数が気になります。 すべての年にわたって、これにより、選択したリーフごとに 1 つの値のシーケンスが生成されます。 目標は、年間値の最大値と最小値の差ができるだけ小さくなるように、葉を訪問する順序を選択することです。 

入力サイズは最大 20 万ノードに達する可能性があるため、毎年の走査を明示的にシミュレートしたり、クエリごとに線形時間でパスを再計算したりするアプローチは除外されます。 ノード数が 2 次または 2 次に近いソリューションは失敗します。 

ツリーがルート 1 のスターである場合、微妙なエッジ ケースが発生します。その場合、他のすべてのノードはリーフであり、各トリップはその単一ノードのみを直接訪問します。 年の値はすべて同一であるため、答えはゼロでなければなりません。 誤ってより深い構造をカウントしたり、自明ではない重複を仮定したりするソリューションでは、ここで誤って正の値が出力されます。 

もう 1 つのエッジケースはチェーンです。 リーフが 1 つだけ存在するため、トリップは 1 つだけであり、範囲は自明のことながらゼロです。 これにより、複数年または複数のリーフが常に存在することを前提とした誤ったソリューションが捕捉されます。 

## アプローチ

 主な困難は、年ごとに実際に何が変化するかを理解することです。 ツリー構造自体は決して変更されず、既に訪問したノードのセットのみが変更されます。 各ノードは、そのサブツリー内のいずれかのリーフが訪問された最初の年に最初に「要求」されます。 その後の旅行には何の貢献もありません。 

この視点により、プロセスを逆転させることができます。 歩行経路の観点から考える代わりに、首都以外のすべてのノードを 1 つのリーフ (そのノードを訪問するきっかけとなる最初のリーフ) に割り当てます。 ノードがリーフに割り当てられると、そのノードはそのリーフの年間カウントに寄与します。 

これが機能するのは、サブツリー内の最初に選択されたリーフが処理される場合に限り、ノードが訪問されるためです。 したがって、すべてのノードは、それを担当するサブツリー内の 1 つのリーフを独立して選択します。 これにより、問題はサブツリー制約の下でノードからその子孫の葉に単位重みを分配するという問題に変換されます。 

各リーフには、割り当てられたノードの数に等しい負荷がかかります。 年間値はまさにこれらの負荷です。 目的は、リーフの負荷が可能な限りバランスがとれるように割り当てを選択し、最大負荷と最小負荷の差を最小限に抑えることです。 

重要な構造上の観察は、各ノードがその割り当てを、そのサブツリー内に完全に含まれるリーフのセットにのみ制限していることです。 これらのセットはツリー全体でネストされているため、無関係なブランチ内のノード間の任意の競合が防止されます。 結果として、唯一のグローバル制約は合計値であり、リーフ間で負荷のバランスをほぼ自由に分散できます。 

これにより、負荷は常に可能な限り等しく、最大で 1 単位の差にすることができるという結論に達します。 可能な限り最善の配置は、非ルート ノードの総数をすべての境界リーフに均等に分散することです。

 ## アルゴリズムのチュートリアル

 次に、ツリーの葉の構造を中心にソリューションを構築します。 

1. すべての国境都市、つまり次数が 1 のルートを除くすべてのノードを特定します。これらは、年間訪問の唯一の有効なターゲットです。 これにより、k 個の葉のセットが得られます。 
2. 正確に n − 1 個の非ルート ノードが存在し、それらのそれぞれがそのサブツリー内の正確に 1 つのリーフに割り当てられている必要があることに注意してください。 これは、すべてのノードがちょうど 1 年以内に最初に訪問されるためです。 
3. 各リーフには割り当てられたノードが一定数蓄積され、これらの値によって年間コストが決定されることを認識します。 
4. 各ノードはサブツリー内のリーフを独立して選択し、サブツリー構造は選択をローカルに制限するだけであるため、割り当てをリーフ間で可能な限り均等に分散できます。 
5. 割り当て可能なノードの総数 (n − 1) を計算し、それらを k 個のリーフに分散します。 達成可能な最良のバランスは、各リーフが ⌊(n − 1) / k⌋ ノードまたは ⌈(n − 1) / k⌉ ノードのいずれかを受け取ることです。 
6. 答えは、リーフ負荷の最大値と最小値の差であり、最大でも 1 ですが、(n − 1) が k で割り切れる場合は正確に 0 になります。 

なぜ効果があるのか:

 各ノードは 1 回だけ貢献し、その貢献は単一の子孫リーフに送信されます。 すべてのノードの有効な宛先セットはそのサブツリー内に完全に含まれており、これらのサブツリー制約が層状ファミリを形成するため、整数の丸め効果を超えて不均一な分布を強制するグローバル結合は存在しません。 不均衡は、合計を k 個のコンテナー間で分割することによってのみ発生するため、最適な分散は最大 ±1 までの均一な分散によって達成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    if n == 1:
        print(0)
        return

    parent = list(map(int, input().split()))

    deg = [0] * (n + 1)
    deg[1] = 0

    # build degrees
    for i, p in enumerate(parent, start=2):
        deg[i] += 1
        deg[p] += 1

    leaves = 0
    for i in range(2, n + 1):
        if deg[i] == 1:
            leaves += 1

    # if only one leaf, only one trip
    if leaves == 1:
        print(0)
        return

    total = n - 1
    k = leaves

    if total % k == 0:
        print(0)
    else:
        print(1)

if __name__ == "__main__":
    solve()
```コードは最初に次数をカウントして、ノード 2 ～ n の間でリーフを識別します。 ルートは、縮退ケース n = 2 で次数 1 であっても、境界都市とはみなされないため、リーフのカウントから除外されます。 有効なリーフの数が判明すると、解決策は問題全体を、それらのリーフ間で n − 1 単位の寄与を分配することに縮小します。 

最終的な決定は、この分布が完全に均等になるかどうかによってのみ決まります。 可能であれば、すべての年の値が正確に一致します。 それ以外の場合、一部のリーフは追加の 1 単位を受け取る必要があり、1 の差が強制されます。 

## 実用的な例

 ノード 1 がノード 2、3、および 4 に接続し、それぞれがリーフである小さなツリーを考えてみましょう。 このとき、n − 1 は 3 に等しく、k = 3 枚の葉があります。 

| 年 | 選ばれた葉 | 写真 新しく訪問したノード |
 | --- | --- | --- |
 | 1 | 2 | 1 |
 | 2 | 3 | 1 |
 | 3 | 4 | 1 |

 毎年、新しいノードが 1 つだけ提供されるため、差はゼロです。 

ここで、ノード 4 のみがリーフであるチェーン 1-2-3-4 を考えてみましょう。 すると、k = 1、n − 1 = 3 となります。 

| 年 | 選ばれた葉 | 写真 新しく訪問したノード |
 | --- | --- | --- |
 | 1 | 4 | 3 |

 1 年しかないので、範囲はゼロです。 

これらの例は、変動がノードの寄与を吸収するために存在する独立したリーフ「バケット」の数に完全に依存することを示しています。

 ## 特殊なケース

 単一ノードの場合、有効なトリップはありません。 考慮すべき葉がないため、アルゴリズムはすぐに 0 を返します。

スター構造では、ルートを除くすべてのノードがリーフです。 各ノードは正確に 1 つのユニットを提供し、分割は完全に均一であるため、すべての年間値は同一であり、計算された差はゼロです。
