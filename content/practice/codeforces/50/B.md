 ## 解決策
 ## 問題の理解

 小文字と数字で構成される文字列が与えられます。 タスクは、文字列内の位置の文字が同一である、順序付けされた位置のペアの数を数えることです。 ペアで注文されるため、ポジションについては`i`そして`j`、 両方`(i, j)`そして`(j, i)`分けて数えます。 セルフペアリング`(i, i)`文字自体が自明に一致するため、これらも含まれます。 

文字列の長さは最大 100,000 文字です。 考えられるすべてのペアを調べるブルートフォース ソリューションには、大まかに次のものが必要です。$10^{10}$最悪の場合の比較は、2 秒で計算できる量を超えます。 これにより、単純なネストされたループが即座に除外されます。 

微妙なエッジ ケースには、非常に短い文字列や、すべての文字が同一である文字列が含まれます。 たとえば、単一文字の文字列`"a"`唯一のペアであるため、1 を返す必要があります`(1, 1)`有効です。 のような文字列`"aaaa"`4 文字のそれぞれが 4 つの位置のそれぞれに一致するため、16 が返されるはずです。$4 \times 4 = 16$注文したペア。 自己ペアを使用せず、または順序を考慮せずに個別のペアのみをカウントする不注意なアプローチでは、間違った答えが得られます。 

## アプローチ

 ブルート フォースのアプローチは簡単です。文字列内の各文字について、他のすべての文字と照合して一致を数えます。 すべての有効なペアを検査するため、これは正しいですが、次のことが必要です。$O(n^2)$実行不可能な操作$n = 10^5$。 最悪の場合、パフォーマンスが低下します$10^{10}$比較。 

最適化する上で重要な点は、各文字を個別に比較する必要がないということです。 それぞれの異なる文字が何回出現するかを知る必要があるだけです。 キャラクターが登場したら`k`何度も貢献します`k * k`順序付きペア:`k`最初のポジションの選択肢と、`k`2番目に。 これをすべての個別の文字について合計すると、最終的な答えが得られます。 これにより、問題は文字の頻度のカウントに軽減され、文字列に対する 1 回のパスで実行できます。 

この観察により、アルゴリズムが 2 次から線形に変わりますが、これは制約を考慮すると必要です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 遅すぎる |
 | 最適 | O(n) | O(1) (36 文字の固定サイズのマップ) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 文字の頻度辞書 (または配列) を初期化します。 文字列には小文字と数字のみが含まれるため、文字でインデックス付けされたサイズ 36 の配列を使用できます。 
2. 文字列内の各文字を反復処理して、頻度表内の文字数を増やします。 このステップの最後に、各文字が何回出現するかがわかります。 
3. 変数を初期化する`total_pairs`ゼロに。 
4. 度数表を繰り返し処理します。 登場するキャラクターごとに`count`回、追加`count * count`に`total_pairs`。 理由は次のとおりです。`count`最初のポジションのオプションと`count`2 番目はセルフペアを含みます。 
5. 印刷`total_pairs`結果として。 

これが機能する理由: 不変条件は、順序ペアの総数に対する各文字の寄与がその頻度の正確な 2 乗であるということです。 すべての文字を考慮し、自己ペアを含めるため、すべての有効なペアは 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s = input().strip()
freq = [0] * 36  # 26 letters + 10 digits

def char_index(c):
    if 'a' <= c <= 'z':
        return ord(c) - ord('a')
    else:
        return 26 + ord(c) - ord('0')

for ch in s:
    freq[char_index(ch)] += 1

total_pairs = sum(f * f for f in freq)
print(total_pairs)
```の`char_index`関数は、各小文字を 0 ～ 25 に、数字を 26 ～ 35 にマップし、辞書の代わりに固定サイズの配列を使用できるようにします。 文字列を 1 回反復して頻度配列を設定し、カウントの二乗を合計します。 固定配列を使用すると、辞書のオーバーヘッドが回避され、文字ごとに O(1) アクセスが保証されます。 

微妙な点は、単一の配列で文字と数字の両方を処理することです。 ASCII コードが文字と数字の間で連続していると考えると、間違いがよく起こります。 もう 1 つの潜在的な落とし穴は、自己ペアを含めることを忘れることです。二乗ステップには自然に自己ペアが含まれます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    s = input().strip()
    freq = [0] * 36
    def char_index(c):
        if 'a' <= c <= 'z':
            return ord(c) - ord('a')
        else:
            return 26 + ord(c) - ord('0')
    for ch in s:
        freq[char_index(ch)] += 1
    return str(sum(f * f for f in freq))

# Provided samples
assert run("great10\n") == "7", "sample 1"

# Custom test cases
assert run("aaaa\n") == "16", "all same characters"
assert run("1\n") == "1", "single character"
assert run("ab1ab\n") == "9", "mixed letters and digits with repeats"
assert run("abc123abc123\n") == "24", "repeated letters and digits"
assert run("z9z9z9\n") == "18", "alternating letters and digits"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`"aaaa"`| 16 | すべて等しい文字、カウント順序と自己ペア |
 |`"1"`| 1 | 最小長の入力 |
 |`"ab1ab"`| 9 | 文字と数字の組み合わせ、文字の繰り返し |
 |`"abc123abc123"`| 24 | 文字と数字の繰り返し、複数出現 |
 |`"z9z9z9"`| 18 | 複数出現する交互パターン |

 ## 特殊なケース

 単一文字列の場合`"1"`、の周波数`'1'`は 1. 2 乗すると次の結果が得られます`1`、それは正しいです。 式には自然に自己ペアが含まれるため、アルゴリズムはこれを簡単に処理します。 

すべて同一の文字を含む文字列の場合、`"aaaa"`、周波数は 4 です。二乗すると次のようになります。`16`、16 個の順序ペアすべてを占めます。 ネストされたループは必要ありません。そうしないとカウントが複雑になり、off-by-one エラーが発生する危険があります。 

文字と数字が混在する文字列の場合、`"ab1ab"`、周波数は`'a':2`、`'b':2`、`'1':1`。 Contributions are`4 + 4 + 1 = 9`, which confirms the formula works across character types.

 この社説は、文字頻度と順序対カウントを活用することにより、読者を単純な 2 次アプローチから線形時間、固定空間の解決策に導きます。 Following this reasoning, similar problems involving counting pairs with specific matching criteria can be approached efficiently.
