 ## 解決策
 ## 問題の理解

 次の形式の二次方程式の実根をすべて数えるよう求められます。$x^2 + 2bx + c = 0$、 どこ$b$範囲は 1 から$n$そして$c$範囲は 1 から$m$。 各ペア$(b, c)$1 つの二次方程式を定義します。 出力は、これらすべての二次方程式にわたる個別の実根の合計数です。 

二次方程式を書き直すと、根は次のように求められます。$$x = -b \pm \sqrt{b^2 - c}.$$したがって、本当のルートは次の場合にのみ存在します。$b^2 - c \ge 0$、これは以下と同等です$c \le b^2$。 したがって、それぞれについて$b$、のみ$c$満足のいく価値観$1 \le c \le \min(m, b^2)$本物の根を作ります。 有効な各ペアはいずれか 1 つのルートを与えることができます ($b^2 = c$) または 2 つの異なるルート (場合$b^2 > c$）。 

制約は大きいです:$n$そして$m$最大 5,000,000 まで可能です。 すべてを反復するブルートフォースソリューション$b \times c$ペアは最大でパフォーマンスを発揮します$25 \times 10^{12}$操作、それは不可能です。 これは、どのソリューションもすべてのペアに対する明示的な反復を避け、代わりに何らかの算術プロパティまたは数学的カウント手法に依存する必要があることを意味します。 

明らかではないエッジケースが発生するのは次の場合です。$b^2 - c$は完全な正方形です。 たとえば、$n = 3$そして$m = 3$、方程式$x^2 + 4x + 3 = 0$根がある$-1$そして$-3$、 その間$x^2 + 6x + 3 = 0$根がある$-3 \pm \sqrt{6}$、異なるルート間で重複するルートを示しています$b$。 各方程式を個別にカウントする単純なアプローチでは、ルートが 2 倍にカウントされます。 

## アプローチ

 素朴なアプローチは簡単です。$b$1から$n$そしてそれぞれ$c$1から$m$、計算する$D = b^2 - c$。 もし$D \ge 0$、根を計算します$-b \pm \sqrt{D}$一意性を確保するためにそれらをセットに保存します。 正しいとはいえ、このアプローチは次まで反復されます。$n \times m$どちらも 5,000,000 回に達する場合、これは遅すぎます。 

効率的なソリューションのための重要な洞察は、公式を調べることから得られます。$x = -b \pm \sqrt{b^2 - c}$。 隔離できる$\sqrt{b^2 - c}$整数として$k$、完全平方のみが異なる間で共有できる有理根を生成するため、$b$。 つまり、設定できます$\sqrt{b^2 - c} = k \Rightarrow c = b^2 - k^2 = (b-k)(b+k)$。 それぞれについて$b$、可能性のある$k$値は満足する整数です$1 \le c = b^2 - k^2 \le m$、間隔を与える$\max(0, b^2 - m) \le k < b$。 それぞれ$k$根が出ます$-b \pm k$。 これにより、問題は反復処理に減ります。$b$そしてその小さな範囲は$k$すべてではなく$c$。 

ブルート フォースは、すべてのルートを明示的に列挙し、セットを介して一意性を処理するため機能しますが、次の場合には失敗します。$n \times m$合理的な計算を超えています。 根は次のように表現できるという観察$-b \pm k$正確さを維持しながら反復回数を減らし、繰り返しの作業を回避します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n*m) | O(n*m) | 遅すぎる |
 | 最適 | O(n * sqrt(m)) | O(個別のルートの数) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 空のセットを初期化して、すべての個別のルートを保存します。 セットを使用すると、各ルートを 1 回だけカウントすることが保証され、異なるルートから生じる重複が回避されます。$(b, c)$同じルートを生成するペア。 
2. 反復する$b$1から$n$。 それぞれについて$b$、計算します$b^2$繰り返しの計算を避けるために 1 回だけ実行します。 
3. それぞれについて$b$、反復します$k$0から$b-1$。 それぞれ$k$の値を表します$\sqrt{b^2 - c}$、 それで$c = b^2 - k^2$。 考慮するだけ$k$どこ$1 \le c \le m$。 この範囲は次のように取得されます。$k_{\min} = \max(0, b^2 - m)$そして$k_{\max} = b-1$。 
4. 有効なそれぞれについて$k$、2つの根を計算します$-b + k$そして$-b - k$。 もし$k = 0$、ルートは 1 つだけです$-b$。 これらのルートをセットに挿入します。 
5. すべてを繰り返した後$b$そして$k$、セットのサイズは、個別の実根の数です。 

なぜ機能するのか: アルゴリズムはすべてを反復します$b$そしてすべて$k$有効な値を生成する値$c$。 そういったそれぞれに対して$c$、対応する二次方程式の根が正しく計算されます。 結果をセットに保存することで、重複するルートからの重複が自動的に削除されます。 すべての整数があるため、有効なルートはスキップされません$k$それは満足する$1 \le c = b^2 - k^2 \le m$と考えられます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, m = map(int, input().split())
    roots = set()
    
    for b in range(1, n + 1):
        b2 = b * b
        k_min = max(0, b2 - m)
        k_max = b - 1
        for k in range(k_min, k_max + 1):
            roots.add(-b + k)
            if k != 0:
                roots.add(-b - k)
    
    print(len(roots))

if __name__ == "__main__":
    main()
```コードは最初に計算します$b^2$それぞれについて再計算しないようにするため$k$。 最小値を計算します$k$として$b^2 - m$ゼロに固定されているため、$c$少なくとも 1 である必要があります。ループアップは次のとおりです。$b-1$確実にする$k < b$、 以来$k = b$与えるだろう$c = 0$、これは無効です。 ルートはセットに挿入され、個別の値のみをカウントします。 小切手$k \neq 0$次の場合に同じルートを 2 回追加することを防ぎます。$k = 0$。
