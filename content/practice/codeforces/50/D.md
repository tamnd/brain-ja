 ## 解決策
 ## 問題の理解

 私たちには、固定の 2D 座標と固定の攻撃ポイントにある一連の敵オブジェクトが与えられます。 目的は、核弾頭の不活性化に失敗する確率が少なくとも低くなるよう、核弾頭の最小衝突半径を決定することです。`K`これらの物体の最大εパーミルです。 建物が破壊される確率は、爆弾の半径に対する攻撃点からの距離に依存します。半径内の建物は常に破壊されますが、半径外の建物は指数関数的減衰式に従って確率的に破壊されます。 

入力により提供されるのは、`N`オブジェクト (最大 100)、必須のターゲット`K`(≤ N)、失敗しきい値`ε`(1 ≤ ε ≤ 999 パーミル、つまり、最大 0.999 の確率)、ストライク座標、およびオブジェクトの座標。 出力は、最小半径を表す単一の浮動小数点数です。 

制約は次のことを示唆しています`N`3 次または 2 次の複雑さを持つアルゴリズムが 2 秒で快適に実行できるほど十分に小さいです。 距離は |1000| で制限されます。 各座標での距離の二乗は整数の範囲内になります。 

エッジケースが発生するのは次の場合です`K = 1`または`ε = 999`そしてオブジェクトがストライクポイントと重なったとき。 重なっているオブジェクトや非常に近いオブジェクトの確率を正しく処理しない単純なアプローチでは、必要な半径が過小評価される可能性があります。 たとえば、衝突からの距離が 0 にある単一のオブジェクトの場合、最小半径は 0 です。 不用意に実装すると、負の半径が出力されたり、収束に失敗したりする可能性があります。 

## アプローチ

 ブルートフォースアプローチは、あらゆる可能な半径を試し、すべてのオブジェクトの確率を計算し、すべての組み合わせを列挙することです。`K`破壊されたオブジェクト、失敗の確率を合計し、それが ε を下回っているかどうかを確認します。 これは各確率が独立しているため機能しますが、最悪の場合は O(2^N) となり、N = 100 では法外です。 

重要な洞察は、問題を確率的動的計画問題としてモデル化することです。 各オブジェクトには破壊確率があります`p_i(R)`半径の関数として`R`。 させて`dp[i][k]`正確に破壊する確率`k`最初のものの中のオブジェクト`i`オブジェクト。 再発により:```
dp[i+1][k] = dp[i][k] * (1 - p_i) + dp[i][k-1] * p_i
```少なくとも破壊する確率は計算できる`K`効率的にオブジェクトを取得します。 これにより、指定された半径を確認できます`R`O(N*K) 時間以内に完了します。 次に、二分探索を行うことができます`R`破壊の確率は半径の増加とともに単調減少するため、半径が大きくなると破壊の確率が増加するだけです。 

これにより、複雑さが大幅に軽減されます: O(N_K_log(max_ distance/epsilon))。これは、N ≤ 100 の場合に実現可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^N) | O(N) | 遅すぎる |
 | DP + 二分探索 | O(N_K_log(1e6)) | O(N*K) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. **距離の事前計算**: オブジェクトごとにユークリッド距離を計算します。`D_i`ストライクポイントへ。 距離は float として保存できます。 破壊確率は距離に依存するため、これは必要です。 
2. **確率関数の定義**: 候補半径の場合`R`、確率を計算します`p_i(R)`その物体`i`破壊されます。 物体が半径内にある場合、`p_i = 1`。 それ以外の場合は、問題で示されている指数公式を使用して計算します。 
3. **DP アレイをセットアップします**:`dp[k]`正確に破壊する確率を表す`k`これまでに検討したすべてのオブジェクトのうちの 1 つです。 初期化する`dp[0] = 1.0`。 
4. **Iterate over objects**: For each object, update the DP array in reverse order (to avoid overwriting values). 更新の式は次のとおりです。```
dp[k] = dp[k] * (1 - p_i) + dp[k-1] * p_i
```これには、オブジェクトが破壊されない場合と破壊される場合の 2 つのケースが考えられます。 

1. **失敗確率の確認**: すべてのオブジェクトを処理した後、合計を計算します。`dp[0]`を通して`dp[K-1]`少なくとも破壊に失敗する確率を取得するには`K`オブジェクト。 ε パーミルを 1000 で割って確率に変換します。 
2. **半径の二分探索**: 初期化`low = 0`、`high = max_distance_possible`(たとえば 5000)、差が 1e-7 未満になるまで繰り返します。 各中間点について、DP を計算し、故障確率 ≤ ε かどうかを確認します。 調整する`low`または`high`それに応じて。 
3. **出力**: 二分探索の後、`low`確率要件を満たす最小半径に収束します。 

**機能する理由**: 破壊に失敗する確率`K`オブジェクトは半径とともに単調減少します。 DP は、破壊されたオブジェクトのすべてのサブセットを明示的に列挙することなく正確に説明し、正確な確率計算を保証します。 二分探索では単調性を利用して、十分な最小半径を見つけます。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def bombing():
    N = int(input())
    K, eps = map(int, input().split())
    eps /= 1000  # convert per mils to probability
    X0, Y0 = map(int, input().split())
    objects = [tuple(map(int, input().split())) for _ in range(N)]
    
    def prob(dist, R):
        if dist <= R:
            return 1.0
        else:
            return math.exp(1 - (dist / R) ** 2)
    
    distances = [math.hypot(x - X0, y - Y0) for x, y in objects]
    
    left, right = 0.0, 5000.0
    for _ in range(100):
        mid = (left + right) / 2
        dp = [0.0] * (N + 1)
        dp[0] = 1.0
        for d in distances:
            p = prob(d, mid)
            for k in range(N, 0, -1):
                dp[k] = dp[k] * (1 - p) + dp[k-1] * p
            dp[0] *= (1 - p)
        fail_prob = sum(dp[:K])
        if fail_prob <= eps:
            right = mid
        else:
            left = mid
    print(f"{(left + right) / 2:.12f}")

bombing()
```コードはまず、ミルあたりのεを適切な確率に変換します。 計算の繰り返しを避けるために距離を事前計算します。 DP は、正しい以前の値を保存するために逆方向に更新されます。 二分探索ループは 100 回反復され、問題の範囲が与えられた場合に 1e-6 以内の精度が保証されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from contextlib import redirect_stdout
    f = io.StringIO()
    with redirect_stdout(f):
        bombing()
    return f.getvalue().strip()
