 ## 解決策
 ## 問題の理解

 テーブルに _n_ 人が座っていますが、それぞれが常に正直であるか、常に嘘をついています。 正直な人は、テーブルに正直な人が何人いるかについて常に正直に答えます。 嘘つきは、本当の数字を除いて、1 から _n_ までの任意の数字を選ぶことができます。 小さなセルジュはすべての答えを順番に書き留め、そのうちの _k_ 個が合計と矛盾していることに気づきました。そのため、これらの _k_ 個は「明らかに嘘をついている」と見なされます。 

入力では数値 _n_ と _k_ が与えられ、長さ _n_ の回答の可能なシーケンスが何個あると、正確に _k_ 人が明らかに嘘をついている可能性があるかを数えるように求められます。 答えは 777777777 を法として計算する必要があります。 

制約は小さいです: _n_ は最大 28 で、2 の累乗です。これは、2^28 ≈ 2.7×10^8 であるため、_n_ で指数関数的なアルゴリズムを使用できるが、O(2^n * n) より悪くはないことを意味します。これは、1 秒の時間制限で実現可能な境界線です。 すべてのシーケンスの O(n!) または総当たりの列挙は不可能です。 この問題は組み合わせ構造を持っているため、動的プログラミングが適切なツールである可能性があります。 

_k = n_ の場合、微妙なエッジ ケースが発生します。これは、すべての人が嘘をついているように見えることを意味します。 人が 1 人だけの場合 (_n = 1_)、これは不可能です。なぜなら、その 1 人が真実の数を 1 にするには正直でなければならないからです。したがって、出力は 0 になるはずです。正直な人と嘘つきの数の分布の不可能性を無視する単純な解決策は失敗します。 

## アプローチ

 ブルートフォース手法では、人々を正直か嘘つきかのラベル付けする 2^n 通りの方法をすべて列挙し、すべての有効な回答シーケンスを割り当て、正確に _k_ 人が嘘をついているように見えるシーケンスを数えようとします。 これは正しいですが、非効率的です。各嘘つきには答えに対する選択肢が最大 n-1 個あり、複雑さは O(2^n * (n-1)^n) になります。 n = 28 の場合、これは完全に不可能です。 

重要な洞察は、問題を 2 つの部分に分けることです。正直な人々の数 _h_ を選択し、次に、明らかな嘘つき _k_ 人と正確に一致するシーケンスを数えます。 _h_ が固定されると、ちょうど _h_ 人が正しい数字 _h_ で答える必要があり、残りの _n ～ h_ 人は間違って答えることができます。 嘘つきごとに、_n ～ 1_ 個のオプション (_h_ を除くすべての数字) から選択できます。 シーケンスには、明らかに _k_ 個の嘘つきが含まれている必要があります。これは、n - h = k または h = n - k を意味します。 したがって、正直な人の数は _k_ によって決定され、シーケンスの数は、どの人が正直であるかを選択し、嘘つきに間違った番号を割り当てることに帰着します。 

組み合わせ論を使用してカウントを計算できます。 どの n - k 人が正直であるかを選択します: C(n, n - k)。 k 人の嘘つきのそれぞれについて、正解数 h 以外の任意の数を選択でき、(n-1)^k 個のオプションが与えられます。 乗算すると、合計シーケンスのモジュロ 777777777 が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * (n-1)^n) | O(n) | 遅すぎる |
 | 組み合わせDP | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 正直な人の数を特定します。 正確に _k_ 人が嘘をついているように見えるため、n - k 人の正直な人が存在します。 これを _h = n - k_ と呼びます。 
2. k = n で h が負またはゼロの場合、0 を返す特別なケースとして処理します。これは、すべての人が嘘をついているように見えるが、一致する有効な正直なカウントが存在しない場合に発生します。 
3. どの人が正直であるかを選択する方法の数を計算します: C(n, h)。 これは二項係数で、サイズ h のすべてのサブセットを表します。 
4. k 人の嘘つきのそれぞれに対して、本当の数 h とは異なる答えを割り当てます。 各嘘つきには (n-1) 個のオプションがあり、(n-1)^k 個のシーケンスが与えられます。 
5. 正直な人を選ぶ方法の数と嘘つきに対する割り当ての数を掛けます。 オーバーフローを避けるために、777777777 を法として取ります。 
6. 結果を出力します。

これが機能する理由: 不変条件は、正直な人は h を正確に答えなければならず、嘘つきは h を選択できないということです。 k 個の明らかな嘘つきの要件によって h が決定されると、制約を満たすすべてのシーケンスが組み合わせ計数によって捕捉されます。 正直な人々の選択と嘘つきの回答の独立した選択が解決空間を完全にパラメータ化するため、シーケンスが見逃されたり二重にカウントされたりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 777777777

def mod_pow(a, b, mod):
    result = 1
    a %= mod
    while b > 0:
        if b % 2:
            result = (result * a) % mod
        a = (a * a) % mod
        b //= 2
    return result

def comb(n, k):
    if k < 0 or k > n:
        return 0
    res = 1
    for i in range(1, k+1):
        res = res * (n - i + 1) // i
    return res

def main():
    n, k = map(int, input().split())
    h = n - k
    if h < 0 or h > n:
        print(0)
        return
    ways_honest = comb(n, h)
    ways_liars = mod_pow(n - 1, k, MOD)
    print((ways_honest * ways_liars) % MOD)

if __name__ == "__main__":
    main()
```このソリューションでは、浮動小数点エラーを回避するために、まず整数演算を使用して二項係数を計算します。 べき乗剰余演算は、n-1 の大きなべき乗を効率的に処理します。 特殊なケース h < 0 または h > n は、不可能なカウントを防ぐために必要です。 乗算と剰余演算を行うと、最終結果が得られます。

 ## 特殊なケース

 n = 1、k = 1、h = 0、ways_liars = 0 の場合、出力は 0 になります。アルゴリズムは、有効な応答シーケンスが存在しないことを正確に識別します。 k = 0、h = n の場合、正直な構成は 1 つだけあり、嘘つきは影響力を持ちません。 k = n、h = 0 の場合、すべてが嘘つきである必要があり、ways_liars = (n-1)^n となり、有効なシーケンス数が得られます。 各エッジ ケースは、二項および剰余累乗ロジックによって処理されます。
