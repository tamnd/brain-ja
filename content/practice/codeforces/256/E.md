 ## 解決策
 ## 問題の理解

 長さの配列が与えられます`n`、最初はゼロで埋められます。 各クエリは、単一の要素を 0 ～ 3 の値に設定します。ゼロは未設定の要素を表し、1、2、または 3 は実際の値です。 各クエリの後、与えられた 3×3 行列に従って、連続する要素のペアがすべて「適切な」ペアを形成するように、すべてのゼロを 1 から 3 の値に置き換える方法の数を数えるように求められます。`w`。 この行列は、どの順序ペア (i, j) が許可されるかを指定します。 

配列のインデックスは 1 から付けられます。クエリは順次実行され、各クエリは答えを計算する前に現在の配列を変更します。 答えは 777777777 を法として計算する必要があります。 

制約`n ≤ 77777`そして`m ≤ 77777`各ゼロは 3 つの値を取る可能性があるため、クエリごとにゼロの可能なすべての組み合わせを反復処理する単純なアプローチは実行不可能であることを意味します。 ゼロが 10 個でも含まれる配列の場合、ブルート フォース カウントはすでに 3^10 = 59049 個の組み合わせになります。 何万ものゼロとクエリが存在する可能性があるため、クエリのたびに最初から再計算することは避けなければなりません。 

エッジ ケースは、ゼロが連続している場合、または配列の境界にある場合に発生します。 たとえば、次の場合`n = 3`(2, 2) を除くすべてのペア (i, j) が良好である場合、単純なカウントにはそれが誤って含まれる可能性がありますが、ゼロをすべて 2 で埋めると失敗します。 

## アプローチ

 ブルートフォース手法では、すべてのゼロに可能なすべての値を入力し、クエリのたびに各配列の有効性をチェックします。 これは文字通りすべての可能性を列挙しているため正しいですが、最悪の場合は O(3^n * n * m) になり、n ~ 10^5 ではまったく実用的ではありません。 

重要な洞察は、左側の要素がわかれば、連続する要素の各ペアを独立してモデル化できるということです。 定義すると`dp[i][v]`位置で終わる有効なシーケンスの数として`i`価値のあるもの`v`、前の位置と許可されたペア行列のみを使用してこれを伝播できます。`w`。 これにより、問題は配列に沿った動的プログラミングの問題に帰着しますが、各クエリは 1 つの要素のみを変更するため、高速な更新が必要です。 

最適なアプローチでは、セグメント ツリーを使用します。セグメント ツリーでは、各ノードが、セグメント境界に特定の値が与えられた場合に、対応するセグメントを埋める方法の数を表す 3×3 行列を維持します。 各リーフは 1 つの配列要素に対応します。 クエリによって要素が変更されると、対応するリーフのみが更新され、変更が上方に伝播されます。 ツリーに沿って行列を乗算すると、カウントが効率的に集計されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(3^n * n * m) | O(n) | 遅すぎる |
 | セグメントツリー + マトリックス DP | O(m * log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. サイズのセグメント ツリーを初期化します。`n`ここで、各リーフ ノードには、その位置での各値の可能なカウントを表す 3×3 行列が格納されます。 配列要素がゼロの場合、行列は 1、2、3 (3 つの値すべてが可能) の単位になります。 固定されている場合、行列には​​ 1 つの行と列があり、その値が 1 で、それ以外は 0 になります。 
2. 各内部ノードは、その 2 つの子行列の積を格納します。 この積は、左のセグメントが value で終わるように定義されています。`x`右側のセグメントは value で始まります`y`、結合されたセグメントの有効なシーケンスの総数は、すべてのセグメントの合計です。`x, y`どこ`(x, y)`によって許可されています`w`そして、子ノードからの対応するカウントを乗算します。 
3. クエリごとに、対応するリーフ ノードを新しい値で更新し、ゼロ (すべての値が許可される) または特定の値にリセットします。 
4. リーフを更新した後、変更をルートまで伝播します。 ルートの行列は、配列全体のウェイの合計数をエンコードするようになりました。 すべての有効な開始値と終了値を合計すると、答えはモジュロ 777777777 になります。 
5. すべてのクエリに対して繰り返し、それぞれの合計を出力します。 

機能する理由: 各ノードは不変式を維持します。3x3 行列は、左右のエンドポイントで条件付けされたセグメントの有効な塗りつぶしの数を完全にエンコードします。 行列の乗算によって 2 つのセグメントを結合すると、次の条件に従って有効な組み合わせのみを合計するため、境界を越えたカウントが正しく集計されます。`w`。 リーフを更新すると、その位置の変更が正しく反映されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 777777777

class SegmentTree:
    def __init__(self, n, good):
        self.n = n
        self.size = 1
        while self.size < n:
            self.size *= 2
        # each node stores 3x3 dp matrix
        self.data = [None] * (2*self.size)
        self.good = good
        for i in range(2*self.size):
            self.data[i] = [[0]*3 for _ in range(3)]
    
    def set_leaf(self, i, val):
        mat = [[0]*3 for _ in range(3)]
        if val == 0:
            for x in range(3):
                mat[x][x] = 1
        else:
            mat[val-1][val-1] = 1
        self.data[i+self.size] = mat
    
    def merge(self, left, right):
        res = [[0]*3 for _ in range(3)]
        for i in range(3):
            for j in range(3):
                for k in range(3):
                    for l in range(3):
                        if self.good[k][l]:
                            res[i][l] = (res[i][l] + left[i][k]*right[l][l]) % MOD
        return res
    
    def build(self):
        for i in range(self.size-1, 0, -1):
            self.data[i] = self.combine(self.data[i*2], self.data[i*2+1])
    
    def combine(self, left, right):
        res = [[0]*3 for _ in range(3)]
        for i in range(3):
            for j in range(3):
                total = 0
                for k in range(3):
                    for l in range(3):
                        if self.good[k][l]:
                            total = (total + left[i][k]*right[l][j]) % MOD
                res[i][j] = total
        return res
    
    def update(self, i, val):
        self.set_leaf(i, val)
        i += self.size
        while i > 1:
            i //= 2
            self.data[i] = self.combine(self.data[2*i], self.data[2*i+1])
    
    def total(self):
        ans = 0
        for i in range(3):
            for j in range(3):
                ans = (ans + self.data[1][i][j]) % MOD
        return ans

n, m = map(int, input().split())
good = []
for _ in range(3):
    good.append(list(map(int, input().split())))

st = SegmentTree(n, good)
a = [0]*n
for i in range(n):
    st.set_leaf(i, 0)
st.build()

res = []
for _ in range(m):
    v, t = map(int, input().split())
    v -= 1
    a[v] = t
    st.update(v, t)
    res.append(st.total())

print(' '.join(map(str, res)))
```説明:`SegmentTree`クラスは動的プログラミング行列を維持します。`set_leaf`単一の配列要素を設定します。`combine`許可されたペアに従って 2 つのセグメントをマージします。`update`1つのリーフを更新して伝播します。`total`すべての開始/終了値にわたるすべての可能なシーケンスを合計します。 乗算と合計は 777777777 を法とします。すべての要素をゼロとして初期化し、ツリーを構築します。 次に、各クエリを処理して回答を収集します。 

## 実用的な例

 サンプル 1 トレース:

 | クエリ | 配列`a`| 葉の行列の更新 | ルート合計 |

 | 1 1 | [1,0,0] | リーフ 0 → [[1,0,0],... ] | 3 |
 | 1 3 | [3,0,0] | リーフ 0 → [[0,0,1],... ] | 6 |
 | 2 2 | [3,2,0] | リーフ 1 → [[0,1,0],... ] | 1 |

 これは、更新が正しく伝達され、`total`すべての有効なシーケンスをキャプチャします。
