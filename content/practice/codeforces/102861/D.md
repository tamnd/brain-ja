 ## 解決策
 ## 問題の理解

 人の円形配置は 2 つあります。 初期ペアリングは位置ごとに行われるため、位置`i`1つの円の中での顔の位置`i`他のサークルでは。 ダンス中、各ステップは円の 1 つだけを回転します。 回転すると、2 つの円間の現在のオフセットが変化します。 同じオフセットが 2 回表示されるということは、同じペアが再び向かい合うことを意味するため、出現するすべてのオフセットが新しい場合にのみ、ダンス全体が有効になります。 

完全なダンスは、各ステップ後の一連のオフセットによって決まります。 回転自体は、現在のオフセットでゼロ以外の変化を選択することと同じです。これは、ゼロ以外の変化はすべてモジュロであるためです。`N`正確に 1 つの有効な回転量に対応します。 

最後に、最終オフセットは、年齢の合計がすべて同じ剰余モジュロを持つペアを作成する必要があります。`M`。 有効なシーケンスの数を数える必要があります。`K`ゼロ以外の変更は、許容可能なオフセットの 1 つで終了します。 

入力サイズが主な難点です。`N`到達できる`10^6`したがって、完全な検証ですべての位置のペアまたはすべての可能なオフセットを試行するアルゴリズムは遅すぎます。 最終的なカウント部分は線形に近い必要があります。`N`、そしてダンスの長さ`K`と同じ大きさにすることができます`10^9`, そのため、手順をシミュレーションすることはできません。 

いくつかの特殊なケースは見落とされがちです。 もし`K >= N`、初期オフセットと`K`後のオフセットには少なくとも次のものが含まれます`N+1`のみの訪問`N`可能な位置。 たとえば、`N = 3`、`K = 3`、3 つの動きのシーケンスごとにオフセットが繰り返されるため、答えは次のようになります。`0`。 

オフセット 0 が開始状態であるため、最終オフセットを 0 にすることはできません。 たとえば、`N = 3`、`K = 1`、元のペアリングのみが年齢条件を満たす場合、正解は依然として`0`、 ない`1`なぜなら、最初のペアリングを繰り返さないとその状態に到達できないからです。 

複数の有効な最終オフセットは個別にカウントする必要があります。 たとえば、2 番目の円の 2 つの異なる循環シフトが有効な年齢の合計を生成する場合、各シフトは独自のダンス数に寄与します。 

## アプローチ

 直接的なアプローチでは、考えられるすべての回転シーケンスを列挙します。 各ステップには、`N-1`ゼロ以外の変更が発生する可能性があるため、これにより大まかに作成されます`(N-1)^K`可能性。 小さいものでも`K`、これは成長が早すぎます。 より優れた総当たりの方法では、すべての最終シフトを列挙し、年齢条件が満たされているかどうかを確認しますが、1 つのシフトを確認するにはコストがかかります`O(N)`、与える`O(N^2)`が遅すぎて最悪の場合、`N = 10^6`。 

重要な観察は、年齢条件は円周差のみに依存するということです。 最終シフトを想定します`s`有効です。 次に、隣接する女性のポジションのペアごとに、`A[i] + B[i+s] = A[i+1] + B[i+1+s]`。 

並べ替えると`B[i+1+s] - B[i+s] = A[i] - A[i+1]`。 

左側は循環差分列です。`B`、右側は次から導出された固定パターンです。`A`。 したがって、有効なシフトを見つけることは循環パターン マッチングの問題になります。 

の差分配列を構築します`B`との違いのパターンを検索します。`A`差分配列の 2 つのコピー内。 Knuth-Morris-Pratt アルゴリズムは、一致するすべての開始位置を線形時間で見つけます。 

有効な最終シフトの数を見つけた後、残る問題は純粋に組み合わせの問題です。 有効な長さのダンス`K`のシーケンスです`K+1`offset で始まる個別のオフセット`0`。 もし`K < N`、最終オフセットを修正する`K-1`他のオフセットから選択して注文するための中間オフセット`N-2`ポジション。 有効なゼロ以外の最終シフトの可能性の数は次のとおりです。`(N-2) * (N-3) * ... * (N-K)`それは`(N-2)! / (N-K-1)!`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((N-1)^K) | O(K) | 遅すぎる |
 | すべてのシフトを確認する | O(N^2) | お(1) | 遅すぎる |
 | 最適 | O(N) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 女性の循環差分パターンを計算します。 ポジションごとに、`A[i] - A[i+1]`モジュロ`M`。 これは、男性の有効なローテーションのたびに再現しなければならないパターンです。 
2. 男性の循環差分配列を計算します。 ポジションごとに、`B[i+1] - B[i]`モジュロ`M`。 有効な最終シフトは、この差分シーケンスが女性のパターンと一致する位置です。 
3. 一度複製した男性差分配列に対して KMP を実行します。 次の位置から始まるすべての試合`0`に`N-1`は 1 つの有効な最終シフトを表します。 複製された配列は、円の終端を囲む一致を処理します。 
4. 最終シフトのケースを削除する`0`これは、ダンスが始まる前に最初のオフセットがすでに訪問されているためです。 
5. もし`K >= N`、出力`0`有効なオフセットのシーケンスには、次の値を超えるものを含めることはできないためです。`N`異なる州。 
6. それ以外の場合は、中間オフセットを選択する方法の数を計算します。 この値に有効な最終シフトの数を乗算し、その結果を剰余とします。`10^9+7`。 

それが機能する理由: すべてのダンスは、オフセットの循環グループを通るパスに正確に対応します。 有効性条件は個別のオフセットを訪問することと同等であるため、最終オフセットを修正した後は、残りの訪問オフセットの順序付けされた選択をカウントするだけで済みます。 すべてのペアの合計が等しいことは、すべての隣接する差分が等しいことと等しいため、KMP ステップは、最終的なペアリング条件が満たされるシフトを正確に見つけます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10 ** 9 + 7

def kmp_count(text, pattern, n):
    m = len(pattern)
    pi = [0] * m

    for i in range(1, m):
        j = pi[i - 1]
        while j and pattern[i] != pattern[j]:
            j = pi[j - 1]
        if pattern[i] == pattern[j]:
            j += 1
        pi[i] = j

    count = 0
    j = 0
    for i, x in enumerate(text):
        while j and x != pattern[j]:
            j = pi[j - 1]
        if x == pattern[j]:
            j += 1
        if j == m:
            start = i - m + 1
            if start < n:
                count += 1
            j = pi[j - 1]

    return count

def solve():
    N, M, K = map(int, input().split())
    A = [int(x) % M for x in input().split()]
    B = [int(x) % M for x in input().split()]

    if K >= N:
        print(0)
        return

    pattern = [(A[i] - A[(i + 1) % N]) % M for i in range(N - 1)]
    diff_b = [(B[(i + 1) % N] - B[i]) % M for i in range(N)]

    valid = kmp_count(diff_b + diff_b, pattern, N)

    if K == 1:
        ways = 1
    else:
        ways = 1
        for x in range(N - 2, N - K - 1, -1):
            ways = ways * x % MOD

    print(valid * ways % MOD)

if __name__ == "__main__":
    solve()
```KMP 前処理は、差分パターンの失敗関数を構築します。 これにより、アルゴリズムは不一致の後も最初からやり直すことなく検索を続けることができ、これが線形の複雑さをもたらします。 

循環一致が配列の最後を横切る可能性があるため、複製された差分配列が必要です。 最初からのみ開始します`N`位置は実際の循環シフトであるため、カウントされます。 

積ループは、階乗やモジュラー逆関数を使用する代わりに、下降階乗を直接計算します。 これにより、余分なモジュラー演算が回避され、`K = 1`当然のこと。 

プログラムがダンス シーケンス自体を構築することはありません。 考えられる最終オフセットをカウントし、そこに至るまでのオフセット注文の数を乗算するだけです。

 ## 特殊なケース

 いつ`K >= N`の場合、アルゴリズムはすぐにゼロを返します。 例えば：```
3 100 3
1 2 3
4 5 6
```可能なオフセットは開始オフセットを含めて 3 つだけです。 長さ 3 のダンスには 4 つの異なるオフセットが必要ですが、そんなことは起こり得ません。 

唯一の有効なペアリングが最初のペアリングである場合、それはカウントされません。 KMPフェーズはシフトを見つけることができます`0`ただし、訪問されたすべてのオフセットは個別である必要があるため、組み合わせフェーズでは開始オフセットに戻ることはできません。 

いくつかのシフトが年齢条件を満たす場合、アルゴリズムはそれぞれを独立してカウントします。 差分マッチング ステップでは、すべての有効な循環スタートが返され、中間オフセットの数は次の要素のみに依存するため、各スタートは同じ数の有効なダンス履歴に寄与します。`N`そして`K`、最終的な場所ではありません。
