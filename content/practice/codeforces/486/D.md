 ## 解決策
 ## 問題の理解

 すべての頂点が整数値を持つツリーが与えられます。 頂点のセットが空ではなく、ツリーの接続されたサブグラフを形成し、セット内の最大値と最小値の差が以下を超えない場合、その頂点セットは有効であるとみなされます。`d`。 

タスクは、そのような接続された頂点セットがいくつ存在するかを数えることです。 

ツリーには最大 2000 個の頂点が含まれ、すべての値は最大 2000 個です。2000 個の頂点という制限は十分に小さいため、`O(n²)`または`O(n² log n)`解決策は現実的ですが、頂点の数が指数関数的に増加することは不可能です。 2000 個の頂点を持つツリーには 1999 個のエッジがあるため、すべての頂点から DFS を実行することは完全に実現可能です。 

難しいのは、二重カウントを避けることです。 接続されたセットには、同じ最小値を持つ多くの頂点が含まれる場合があります。 値制限を満たす接続されたサブセットを単純に列挙すると、同じセットが複数回発見される可能性があります。 

Consider a tiny example:```
d = 0

1 -- 2
values: [5, 5]
```有効なセットは次のとおりです。`{1}`、`{2}`、 そして`{1,2}`。 

すべての最小値の頂点をルートとする接続されたサブセットを数えようとすると、次のようになります。`{1,2}`頂点 1 から 1 回カウントされ、頂点 2 から再度カウントされます。 

より大きな連結成分内に複数の等しい最小値が存在する場合、別の微妙なケースが現れます。```
1 -- 2 -- 3
values: [1, 1, 2]
d = 1
```セット`{1,2,3}`有効です。 一意の代表的な最小頂点を確立しない計数スキームでは、このセットを複数回計数することになります。 

3 番目のエッジケースは、`d = 0`。 したがって、すべての有効なセットは、同じ値を持つ頂点だけで構成されている必要があります。 アルゴリズムは必然的に、接続された単色サブセットをカウントすることに帰着する必要があります。 

## アプローチ

 ブルート フォース ソリューションでは、頂点のすべてのサブセットを列挙し、接続されているかどうかを確認し、最大値から最小値を引いた値が以下であることを確認します。`d`。 

がある`2^n`サブセット。 たとえ`n = 40`、これはすでに大きすぎますが、実際の制限は 2000 です。総当たり的なアプローチは完全に実行不可能です。 

ツリー構造は別の視点を示唆しています。 サブセットを直接列挙する代わりに、頂点を選択するとします。`r`これは、セットの最小値の頂点として機能します。 

有効なセットはカウントスルーされます`r`2つの条件を満たさなければなりません。 

まず、セット内のすべての頂点は次の範囲の値を持つ必要があります。`a[r]`そして`a[r] + d`。 

第二に、値が正確にある頂点の間で`a[r]`、各有効なセットが正確に 1 回カウントされるように、タイブレーク ルールが必要です。 

ツリーに関する非常に一般的な手法は、識別されたルートを含む接続されたサブグラフをカウントすることです。 ルートが固定されると、ツリー DP はそのルートを含むすべての接続されたサブセットをカウントできます。 

選択したルートに対して`r`、値が範囲内にある頂点のみを許可しましょう```
[a[r], a[r] + d]
```さらに、次の頂点を禁止します。```
a[v] = a[r] and v < r.
```このタイブレークルールにより、`r`最小値を持つすべての頂点の中でインデックスが最小の頂点。 

これで、すべての有効なセットには代表的なルートが 1 つだけ含まれます。 

有効なセットに最小値がある場合`m`、値が等しいセット内のすべての頂点を調べます。`m`。 させて`r`それらの中で最小のインデックスになります。 セットは処理時にカウントされます`r`、タイブレーク制限のため、他のすべての最小値頂点に対して拒否されます。 

許可される頂点が固定されたら、次を含む接続されたサブセットをカウントする必要があります。`r`許可された頂点の誘導ツリー内。 

これは標準的なツリー DP です。 頂点ごとに`u`、 定義する`dp[u]`DFS サブツリー内の接続されたサブセットの数として`u`を含む`u`。 

すべての子供たちにとって`v`、次のいずれかを行うことができます。 

1. その子の側から何も取らない。 
2. カウントされた接続されたサブセットを接続します。`dp[v]`。 

したがって、子供の貢献は、`(dp[v] + 1)`、 そして```
dp[u] = ∏ (dp[v] + 1).
```root が投稿した回答`r`は`dp[r]`。 

この DFS を頂点ごとに繰り返すことで、最終的な答えが得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n · n) | O(n) | 遅すぎる |
 | 最適 | O(n²) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ツリーと値を読み取ります。 
2. すべての頂点を反復処理します。`r`そしてそれを有効なセットの識別された最小頂点として扱います。 
3. 処理中`r`、頂点`v`次の場合に許可されます。 

-`a[v] >= a[r]`-`a[v] <= a[r] + d`- もし`a[v] == a[r]`、 それから`v >= r`最後の条件はタイブレークルールです。 
4. 以下から DFS を実行します。`r`。 
5. 訪問した頂点ごとに`u`を含む接続されたサブセットの数を計算します。`u`そして完全に DFS サブツリーの内側にあります。 
6. 許可されたすべての子供に対して`v`、再帰的に計算します`dp[v]`。 
7. 子を結合するときは、その分岐を無視するか、または次のように数えて接続されたサブセットの 1 つを接続します。`dp[v]`。 現在の結果を乗算します`(dp[v] + 1)`。 
8. Store the resulting product as`dp[u]`。 
9. DFS が完了したら、次のコマンドを追加します。`dp[r]`グローバルな答えへ。 
10. すべての根に対して繰り返し、和の剰余を出力します。`10^9 + 7`。 

### なぜ効果があるのか

 有効な接続セットを修正します`S`。 

させて`m`その最小値になります。 の頂点の間で`S`価値がある`m`、最小のインデックスを選択します`r`。 

ルート処理時`r`、のすべての頂点`S`満足する```
m ≤ a[v] ≤ m + d,
```値の頂点はありません`m`より小さいインデックスがあります`r`。 したがって、すべての頂点は、`S`許可されています。 

以来`S`接続されており、含まれています`r`、DFS DP を構築する方法は 1 つだけです。 

次に、他のルートを考えてみましょう`x`。 

もし`a[x] > m`、 それから`x`の最小値にすることはできません`S`。 

もし`a[x] = m`そして`x > r`、 それから`r`処理中はタイブレーク ルールにより禁止されています`x`、 それで`S`cannot be formed.

 したがって、すべての有効なセットは 1 回だけカウントされ、カウントされたすべてのセットが有効になります。 これにより正しさが確立されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000000007

d, n = map(int, input().split())
a = list(map(int, input().split()))

g = [[] for _ in range(n)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append(v)
    g[v].append(u)

sys.setrecursionlimit(10000)

answer = 0

for root in range(n):
    base = a[root]

    def dfs(u, parent):
        res = 1

        for v in g[u]:
            if v == parent:
                continue

            if a[v] < base or a[v] > base + d:
                continue

            if a[v] == base and v < root:
                continue

            res = (res * (dfs(v, u) + 1)) % MOD

        return res

    answer = (answer + dfs(root, -1)) % MOD

print(answer)
```外側のループは、代表的な最小頂点を選択します。 変数`base`その値を保存します。 

DFS は、値間隔制約を満たす頂点のみをトラバースします。 ルートと同じ値を持つがインデックスが小さい頂点も除外されます。 これは、重複カウントを防ぐ重要なタイブレーク条件です。 

の戻り値`dfs(u, parent)`を含む接続されたサブセットの数です。`u`以下の DFS サブツリーの頂点のみを使用します`u`。 

それぞれの子供にとって、選択肢は 2 つあります。 そのブランチ全体を無視して貢献するか、`1`または、子を含む有効な接続サブセットの 1 つを接続して、`dp[child]`。 これらの選択肢を子全体で乗算すると、合計数が得られます。 

すべての乗算はモジュロで実行されるため、`10^9 + 7`、オーバーフローは回避されます。
