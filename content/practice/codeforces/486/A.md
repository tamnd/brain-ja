 ## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`。 
2. かどうかを確認します。`n`は均等です。 
3. もし`n`偶数、出力`n // 2`。 

すべての奇数と偶数のペアが正確に寄与します`1`、そして、あります`n/2`そんなペアたち。 
4. それ以外の場合は出力`-(n + 1) // 2`。 

最初`n-1`数値は完全なペアを形成し、最後の不対項は次のようになります。`-n`。 

### なぜ効果があるのか

 奇数の整数ごとに`k`、連続した期間`-k`そして`k+1`貢献する：$$-k + (k+1) = 1.$$いつ`n`が偶数である場合、シーケンス全体は正確に次のように構成されます。`n/2`このようなペアの合計は`n/2`。 

いつ`n`奇数です、最初の`n-1`規約フォーム`(n-1)/2`貢献度が`(n-1)/2`。 残りの任期は、`-n`、生産$$\frac{n-1}{2} - n = -\frac{n+1}{2}.$$これらの式は元の合計と正確に一致するため、アルゴリズムは正しいです。
