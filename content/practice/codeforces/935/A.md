 ## 解決策
 ## 問題の理解

 Fafa は、プロジェクト管理のために会社の従業員をグループに分ける必要があります。 彼は、_l_ で示されるチーム リーダーを何名か選出し、残りの従業員を均等に割り当てたいと考えています。 各チーム リーダーは同数の従業員を監督する必要があり、リーダーがいない従業員は存在しません。 入力は単一の整数 _n_、つまり従業員の総数です。 出力は、この公平な分割が可能な _l_ の可能な値の数です。 

言い換えると、非リーダーの数 _n - l_ が _l_ で割り切れる、_n_ より厳密に _l_ 小さいすべての正の整数を探しています。 これにより、残りの従業員をリーダー間で均等に分割できるようになります。 たとえば、従業員が 6 人の場合、リーダーを 2 名選択すると、リーダー以外の 4 名が残ります。 4は2で割り切れるので、各リーダーは2人の従業員を管理できます。 

制約は控えめですが重要です。 _n_ は最大 100,000 まで可能です。 _n_ までのすべての値に対して考えられるすべてのグループ化を試行する単純なソリューションでは、最大 100,000 回の操作が必要になります。 各操作が単純であれば、これは 1 秒の制限時間内で許容されますが、不必要なチェックを避けるために除数について考える価値があります。 エッジ ケースには、従業員の最小数である _n = 2_ が含まれます。この場合、有効なリーダーの数は 1 だけです。もう 1 つの微妙なケースは、_n_ が素数である場合です。 この場合、他の選択肢が残るため、リーダーは 1 つだけ機能します。 

## アプローチ

 ブルート フォース アプローチでは、1 から _n - 1_ までのリーダーのすべての可能な数が考慮されます。 _l_ ごとに、残りの従業員の数 _n - l_ が _l_ で割り切れるかどうかを確認します。 これは正しいですが、_n-1_ 個の除算演算を実行します。 _n = 100,000_ の最悪のケースでは、約 100,000 回のチェックが行われることになりますが、これは実現可能ですが、やや洗練されていません。 

重要な観察は、問題が _n_ より小さい _n - l_ の約数を数えることに帰着するということです。 より具体的には、_n - l_ を _l_ で割るすべての _l_ を探します。 この条件を書き直すと、k ≥ 1 の整数に対して _n - l = k * l_ になります。並べ替えると、_n = l * (k + 1)_ となります。 したがって、_l_ は、_n_ より厳密に小さい、_n_ の約数でなければなりません。 この変換により不要なチェックが排除され、古典的な約数の問題になります。 √n までの約数のみを反復すると、O(√n) の複雑さが確保されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n) | お(1) | 動作しますが、最適化することができます。 
| 最適 | O(√n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力整数 _n_ を読み取ります。 これは、Fafa の会社の従業員の総数を表します。 
2. カウンタを 0 に初期化します。これにより、チーム リーダーの有効な選択肢の数が追跡されます。 
3. _l_ を 1 から √n まで繰り返します。 _l_ ごとに、_n_ を分割するかどうかを確認します。 
4. _l_ が _n_ を除算する場合、_n = l * (k + 1)_ を満たすため、それが潜在的な候補になります。 _l_ が _n_ より小さい場合、カウンターをインクリメントします。 
5. 対応する除数 _n // l_ も確認します。 _l_ とは異なり、_n_ より小さい場合は、カウンターをインクリメントします。 
6. すべての約数を処理した後、カウンターを出力します。 これは、チーム リーダーを選択する有効な方法の数です。 

機能する理由: 重要な不変条件は、引出線の数 _l_ が _n_ を分割し、厳密に _n_ より小さい場合にのみ有効であるということです。 _n_ のすべての約数を反復処理することにより、すべての潜在的な有効な _l_ が 1 回だけ考慮されることが保証されます。 他の値は公平性条件を満たすことができないため、カウンタは正確です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
count = 0
i = 1
while i * i <= n:
    if n % i == 0:
        if i < n:
            count += 1
        if i != n // i and n // i < n:
            count += 1
    i += 1
print(count)
```このソリューションでは、整数の除算を使用して約数を効率的に見つけます。 _i_ と _n // i_ の両方をチェックして、除数のペアを考慮します。 境界チェックにより、リーダー数が厳密に _n_ 未満であることが保証され、すべての従業員がリーダーである無効なケースが回避されます。 ループは √n で停止するため、冗長なチェックが行われず、ソリューションが効率的になります。 

## 実用的な例

 **例 1**: n = 2

 | 私 | n % i == 0? | カウント |
 | --- | --- | --- |
 | 1 | はい | 1 |

 i=1 を反復すると、2 が除算され、1 < 2 となるため、count = 1 となります。対応する除数 n // i = 2 は < n ではないため、それ以上増分しません。 結果は 1 です。 

**例 2**: n = 6

 | 私 | n % i == 0? | 除数のペア | カウント |
 | --- | --- | --- | --- |
 | 1 | はい | 1 & 6 | 1 |
 | 2 | はい | 2&3 | 3 |

 6 未満の約数は 1、2、3 です。それぞれが有効です。 カウント = 3。 

これは、有効な選択肢がすべてキャプチャされ、余分な値がカウントされていないことを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(√n) | すべての約数を見つけるには、√n まで反復するだけです。 |
 | スペース | お(1) | 少数の整変数のみが使用されます。 |

 n ≤ 100,000 の場合、√n ≈ 317 となるため、必要な反復は 400 回未満になります。 このソリューションは、1 秒の時間制限と 256 MB のメモリ制限内に簡単に収まります。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    count = 0
    i = 1
    while i * i <= n:
        if n % i == 0:
            if i < n:
                count += 1
            if i != n // i and n // i < n:
                count += 1
        i += 1
    return str(count)

# Provided sample
assert run("2\n") == "1", "sample 1"

# Custom cases
assert run("6\n") == "3", "divisors 1, 2, 3"
assert run("12\n") == "5", "divisors 1, 2, 3, 4, 6"
assert run("17\n") == "1", "prime number, only 1 leader"
assert run("100000\n") == "35", "large n, many divisors"
assert run("3\n") == "1", "small n, minimal case"

 ## 特殊なケース

 For _n = 2_, only one leader is possible. ループは i = 1 を繰り返します。1 < 2 であるため、カウントは 1 に増加します。対応する除数 2 はカウントされないため、出力は 1 となり、最小の入力が正しく処理されます。 

素数 _n = 17_ の場合、i = 1 のみが i < 17 で 17 を除算するため、count = 1 になります。対応する除数 17 は無視されます。 このアルゴリズムは過剰カウントを正しく回避し、素数を処理します。 

_n = 36_ のような完全な平方の場合、約数には平方根である 6 が含まれます。 チェック i != n // i は 6 を二重にカウントすることを防ぎ、有効な各リーダー カウントが正確に 1 回カウントされるようにします。
