 ## 解決策
 ## 問題の理解

 記号で構成されるアルファベット上に同じ長さの 2 つの単語が与えられます。`1...m`。 一部の位置は既知ですが、その他は消去され、次のように表されます。`0`。 

消去されたすべての位置は、独立して均一に次のいずれかで埋められます。`m`アルファベットの記号。 すべての置換が行われた後、2 つの完全な単語が得られます。 最初の単語が 2 番目の単語よりも辞書編集的に大きい確率を計算する必要があります。 

答えは分数である必要はありません。 確率が$$\frac{P}{Q},$$印刷しなければなりません$$P \cdot Q^{-1} \pmod{10^9+7}.$$以来$m \le 10^5$、分母は常に法と互いに素です。$10^9+7$、したがってモジュラー逆関数が存在します。 

単語の長さも$10^5$。 消去されたシンボルの割り当てを明示的に列挙するアルゴリズムは不可能です。 たとえ 1 つの未知の位置であっても、すでに導入されています$m$可能性があり、未知の位置が多い場合、完了の数は指数関数的に増加します。 

時間制限は、線形または線形に近い解決策を強く示唆しています。 各位置を一度処理することは完全に安全ですが、二次関数はすべて$n$は除外されます。 

誤って対処しやすい状況がいくつかあります。 

考慮する```
n = 1, m = 2
S1 = [0]
S2 = [1]
```の未知のシンボル`S1`どちらかになる`1`または`2`。 2 つの可能性のうち 1 つだけがより大きな単語を生成するため、答えは次のようになります。$1/2$。 未知の位置を確率論的にではなく貪欲に扱うソリューションは失敗します。 

考慮する```
n = 2, m = 3
S1 = [0, 3]
S2 = [0, 1]
```両方のシンボルが不明であるため、最初の位置によって比較がすぐに決定されるわけではありません。 両者が等しくなって 2 位に進む確率を考慮する必要があります。 「まだ等しい」状態を無視すると、誤った結果が生成されます。 

考慮する```
n = 2, m = 5
S1 = [2, 1]
S2 = [2, 4]
```最初の位置は等しく、固定されています。 2 番目の位置では比較が即座に決定され、答えは正確に 0 になります。 確率的遷移は、固定された不等ペアに遭遇するとすぐに停止する必要があります。 

もう一つの微妙なケースは、```
n = 1, m = 5
S1 = [0]
S2 = [0]
```どちらの記号も不明です。 その中で、$25$割り当て、まさに$10$満足する`S1 > S2`。 確率は$$\frac{10}{25}=\frac{2}{5}.$$2 つの未知のシンボルの数え方は慎重に導出する必要があります。 

## アプローチ

 ブルート フォース ソリューションでは、両方の単語の可能なすべての補完を生成し、結果の文字列を比較し、成功した結果を数え、結果の合計数で割ります。 

あると仮定します$k$合計で消去されたポジション。 完成数は、$m^k$。 と$m=10^5$そして$k$潜在的に近い$2\cdot10^5$、これは天文学的な大きさです。 非常に小さな値であっても実行不可能になります。 

重要な観察は、辞書編集的な比較がどのように機能するかに由来します。 

2 つの単語を比較する場合、それらが異なる最初の位置のみが問題になります。 その位置以降はすべて無関係になります。 これは、左から右にスキャンするときに、1 つの情報だけを知る必要があることを意味します。 

以前のすべてのポジションが最終的に同じになる確率はどれくらいですか?

 この確率を`same`。 

ある位置で、代入の一部により最初の単語がすぐに大きくなります。 それらの結果は、最終的な答えに直接貢献します。 別の部分により 2 つの接頭辞が等しくなり、比較を続行できるようになります。 

これにより、問題は 1 つの状態のみを含む単純な左から右への確率 DP に変換されます。 

位置ごとに次のように計算します。 

1. このポジションが成立する確率`S1 > S2`、以前のすべての位置が等しいと仮定します。 
2. この位置によりそれらが等しく保たれる確率。 

最初の量が答えに影響します。 2 番目の数量の更新`same`。 

すべての位置を一定時間内に独立して処理でき、$O(n)$解決。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(m^k)$|$O(k)$| 遅すぎる |
 | 最適 |$O(n)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 しましょう`MOD = 10^9 + 7`。 

させて`same`は、これまでに処理されたすべての位置が等しい確率を示します。 

当初は、$$same = 1.$$させて`ans`最初の単語が辞書編集的に大きいことがすでにわかっている確率を格納します。 

### 1. モジュラー逆関数を事前計算する

 で割ることを繰り返します`m`そして`m²`、それで計算してください$$inv_m = m^{-1} \pmod{MOD}.$$### 2. 位置を左から右にスキャンします

 ポジションごとにペアを調べます`(a[i], b[i])`。 

貢献度は 4 つのケースによって異なります。 

### 3. どちらのシンボルも既知です

 両方の値が固定されている場合:

 もし`a[i] > b[i]`、次に、次のように表されるすべての代入`same`成功するようになる。 

追加`same`答えに戻って停止します。 

もし`a[i] < b[i]`、成功は不可能になり、停止します。 

それらが等しい場合は続行します。 

### 4. 最初のシンボルは不明、2 番目は既知

 仮定してください`a[i]=0`そして`b[i]=x`。 

その中で、`m`可能な値`a[i]`:`m-x`値が次より大きい`x`。 

したがって、この位置がすぐに得られる確率は`S1>S2`は$$\frac{m-x}{m}.$$追加$$same \cdot \frac{m-x}{m}$$答えに。 

厳密に 1 つの値によって等価性が維持されます。`a[i]=x`。 

アップデート$$same \leftarrow same \cdot \frac1m.$$### 5. 最初は既知、2番目は不明

 仮定してください`a[i]=x`そして`b[i]=0`。 

その中で、`m`～の選択肢`b[i]`:`x-1`値が以下より小さい`x`。 

したがって、このポジションが成り立つ確率は`S1>S2`等しい$$\frac{x-1}{m}.$$追加$$same \cdot \frac{x-1}{m}.$$等しい値が維持されるのは 1 つの値だけです。$$same \leftarrow same \cdot \frac1m.$$### 6. 両方の記号が不明

 あります$m^2$同様に可能性の高い割り当て。 

最初のシンボルが 2 番目のシンボルより大きいペアの数は、$$\frac{m(m-1)}2.$$したがって、この位置がすぐに生成される確率は`S1>S2`は$$\frac{m(m-1)/2}{m^2} = \frac{m-1}{2m}.$$追加$$same \cdot \frac{m(m-1)/2}{m^2}.$$平等は正確に起こります`m`課題、それで$$same \leftarrow same \cdot \frac1m.$$### 7. スキャンを終了します

 すべての位置が等しい場合、単語は等しく、確率には寄与しません。 

出力`ans`。 

### なぜ効果があるのか

 あらゆる段階で、`same`ランダムな置換後に、以前に処理されたすべての位置が等しい確率に等しい。 

辞書編集的な比較は、単語が異なる最初の位置のみに依存します。 ポジションを処理するとき、すべての結果は次の 3 つのカテゴリのいずれかに正確に当てはまります。 

1. 最初の単語が大きくなります。 
2. 2 番目の単語が大きくなります。 
3. 立場は同等のままです。 

最初のカテゴリは、最終的な回答に永続的に貢献します。 2 番目のカテゴリは、後で貢献することはできません。 3 番目のカテゴリは、将来のポジションを考慮できる唯一のカテゴリであるため、その確率は次の新しい値になります。`same`。 

これらのカテゴリは可能なすべての割り当てを分割し、以前のすべての位置が等しいという条件の下ですべての位置が処理されるため、累積された確率は正確に最初の単語が辞書編集上大きい確率となります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def main():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    inv_m = pow(m, MOD - 2, MOD)
    inv_m2 = inv_m * inv_m % MOD
    inv2 = (MOD + 1) // 2

    same = 1
    ans = 0

    for x, y in zip(a, b):
        if x == 0 and y == 0:
            greater_pairs = m * (m - 1) // 2
            ans = (ans + same * (greater_pairs % MOD) % MOD * inv_m2) % MOD
            same = same * inv_m % MOD

        elif x == 0:
            ans = (ans + same * (m - y) % MOD * inv_m) % MOD
            same = same * inv_m % MOD

        elif y == 0:
            ans = (ans + same * (x - 1) % MOD * inv_m) % MOD
            same = same * inv_m % MOD

        else:
            if x > y:
                ans = (ans + same) % MOD
                break
            elif x < y:
                break

    print(ans)

if __name__ == "__main__":
    main()
```変数`same`アルゴリズムの中心的な状態です。 これは、処理されたすべての位置が最終的に等しくなる確率を常に表します。 

3 つの確率的なケースは、ウォークスルーのカウント引数に直接対応します。 すべての算術演算はモジュロで実行されるため、`MOD`、除算は逆剰余を使用した乗算に置き換えられます。 

2 つの未知のシンボルがある場合は特に注意が必要です。 注文したペアの数`(u,v)`満足のいく`u>v`ではありません`m²/2`。 等しいペアを最初に除外する必要があります。 正しいカウントは$$1+2+\cdots+(m-1)=\frac{m(m-1)}2.$$もう 1 つの微妙な詳細は、2 つの固定シンボルが異なる場合に停止することです。 最初の異なる位置が判明すると、その後の位置が辞書編集結果に影響を与えることはありません。 

## 実用的な例

 ### サンプル 1

 入力```
1 2
0
1
```| ポジション | a[i] | b[i] | 以前も同じ | 貢献 | その後も同じ | 答え |
 | --- | --- | --- | --- | --- | --- | --- |
 | 1 | 0 | 1 | 1 | (2-1)/2 = 1/2 | 1/2 | 1/2 |

 唯一の未知のシンボルは次のいずれかです`1`または`2`。 正確に 1 つの選択肢からより大きな単語が生成されるため、確率は次のようになります。$1/2$。 

### 例 2

 入力```
2 3
0 3
0 1
```| ポジション | a[i] | b[i] | 以前も同じ | 貢献 | その後も同じ | 答え |
 | --- | --- | --- | --- | --- | --- | --- |
 | 1 | 0 | 0 | 1 | 3/9 = 1/3 | 1/3 | 1/3 |
 | 2 | 3 | 1 | 1/3 | 1/3 | 停止 | 2/3 |

 最初の位置では、すべての割り当ての 3 分の 1 がすでに満たされています。`S1>S2`。 さらに 3 分の 1 で最初のシンボルが等しくなり、2 番目の位置が決定できるようになります。 以来`3>1`、残りの確率をすべて加算すると、次のようになります。$2/3$。 

このトレースは、重要な不変条件を示しています。`same`は常に将来のポジションまで生き残る確率の塊を表します。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

MOD = 1000000007

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    inv_m = pow(m, MOD - 2, MOD)
    inv_m2 = inv_m * inv_m % MOD

    same = 1
    ans = 0

    for x, y in zip(a, b):
        if x == 0 and y == 0:
            greater_pairs = m * (m - 1) // 2
            ans = (ans + same * (greater_pairs % MOD) % inv_m2) % MOD
            same = same * inv_m % MOD

        elif x == 0:
            ans = (ans + same * (m - y) % MOD * inv_m) % MOD
            same = same * inv_m % MOD

        elif y == 0:
            ans = (ans + same * (x - 1) % MOD * inv_m) % MOD
            same = same * inv_m % MOD

        else:
            if x > y:
                ans = (ans + same) % MOD
                break
            elif x < y:
                break

    return str(ans)

# provided sample
assert run("1 2\n0\n1\n") == "500000004"

# minimum size, fixed equal symbols
assert run("1 5\n3\n3\n") == "0"

# minimum size, fixed greater
assert run("1 5\n4\n2\n") == "1"

# both unknown, m=2 => probability 1/4
assert run("1 2\n0\n0\n") == "250000002"

# fixed equal prefix, later position decides
assert run("2 5\n2 5\n2 1\n") == "1"

 |`1 5 / 4 / 2`|`1`| 即固定勝利 |

## 特殊なケース

 検討してください```
1 2
0
0
```同様に可能性の高い割り当てが 4 つあります。```
(1,1)
(1,2)
(2,1)
(2,2)
```のみ`(2,1)`満足する`S1>S2`、したがって、確率は次のようになります。`1/4`。 アルゴリズムは計算します$$\frac{2(2-1)/2}{2^2} = \frac14,$$これは正確なカウントと一致します。 

考慮する```
2 5
2 1
2 4
```最初のシンボルは等しいため、処理は続行されます。 2番目の位置では、`1<4`、最初の異なる位置がすでに 2 番目の単語を優先していることを意味します。 アルゴリズムは直ちに停止し、ゼロを返します。 

考慮する```
2 3
0 3
0 1
```最初の位置は、大きい、小さい、等しいという 3 つのグループに確率質量を与えます。 同じグループだけが 2 位に生き残ります。 アップデート$$same \leftarrow same \cdot \frac13$$生存確率を正確に捉えます。 2 番目のポジションが処理されると、残っているすべての割り当てが優先されます。`3>1`。 

これらの例は、基本的な不変条件を示しています。`same`は常に、以前の位置がすべて等しい確率と等しくなります。これはまさに、後の位置が辞書編集上の比較に影響を与えるために必要な条件です。
