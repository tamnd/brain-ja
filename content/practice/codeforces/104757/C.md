 ## 解決策
 ## 問題の理解

 すでに最終的な形の凸多角形が与えられており、その頂点によって反時計回りの順序で記述されています。 縮退はありません。多角形は厳密に凸面であり、すべての頂点は本物の角です。 

整数の格子点を数えるように求められます$p = (x,y)$追加すると$p$頂点のセットに対して、凸包は新しい頂点を 1 つだけ取得します。 すべての元の頂点は、1 つの「エッジ置換」を除いて新しいハルの頂点のままである必要があり、結果として得られるポリゴンは厳密に非縮退のままである必要があります。つまり、挿入後に 3 つの頂点が同一線上にならないことを意味します。 

幾何学的に言えば、これは、非常に制御された方法でポリゴンから「突き出る」整数点を探していることを意味します。整数点はポリゴンの外側にある必要がありますが、船体の複数のエッジを再形成するような遠くや方向にあってはなりません。 このような点を追加すると、元の多角形の 1 つのエッジが新しい点を通過する 2 つのエッジに置き換えられます。 

制約は小さく、最大 50 個の頂点と座標が 2000 × 2000 のグリッド内に制限されます。 これは、グローバルな大量の計算ではなく、エッジごとの有効な領域の幾何学的分類、または少数の領域内の直接的な格子点のカウントが意図されていることを示唆しています。 

微妙な問題は、「ポリゴンの外側」だけでは弱すぎるということです。 すべての凸多角形の外側には無限に多くの整数点があるため、それが十分であれば、答えは常に無限になります。 したがって、問題は実際には、ハルの 1 つのエッジを正確に分割することを除いて、すべての元の頂点を保持する点に関するものです。 

単純な間違いは、ポリゴンの外側の点が船体のサイズを 1 つ増やすと仮定することです。 たとえば、正方形では、上端のはるか上にある点は単に 1 つの頂点を追加するわけではありません。通常、2 つの接点間の頂点のチェーン全体が置き換えられ、残っている元の頂点の数が減り、最終的な変更は +1 に等しくなくなります。 

したがって、重要な隠された構造は、有効な拡張ポイントが非常に局所的な方法で船体と対話する必要があるということです。 

## アプローチ

 強引なアイデアは、境界ボックス内のすべての整数点をテストし、追加後に凸包を再計算することです。 これは概念的には単純です。すべての候補を試します。$p$、新しいハルを計算し、頂点数がちょうど 1 だけ増加し、縮退が現れないかどうかを確認します。 

ただし、境界ボックスには約$4 \times 10^6$整数点の場合、各候補について最大 51 のサイズの凸包を再計算しても、おおよその結果が得られます。$2 \times 10^8$幾何学的な操作が必要であり、各船体の構築には分類やスキャンが含まれるため、安全限界をはるかに超えています。 

重要な観察は、船体をグローバルに再計算する必要がないということです。 元のポリゴンはすでに凸状で順序付けられているため、船体を変更する唯一の方法は接線を介することです。$p$ポリゴンに。 これらの接線は、置き換えられる頂点の連続間隔を決定します。 頂点数をちょうど 1 つ増やすには、この間隔が 1 つのエッジである必要があります。 つまり、2 つの接点は元の多角形の隣接する頂点でなければなりません。 

この制約により、問題が各エッジの周囲の局所的なジオメトリに分解されます。 各エッジについて$(v_i, v_{i+1})$、すべての点を特徴付けることができます$p$そのサポート接線は正確にこれら 2 つの頂点に触れます。 このような点は、各端点の 2 つの隣接するエッジから導出される少数の半平面制約によって定義される領域内にあります。 

エッジを固定すると、有効領域は凸多角形の領域になります。 すべての座標は有界であるため、これらの領域は有限ポリゴンであるため、境界ボックス上のスキャンまたはポリゴン格子カウント手法を使用して、領域内の整数格子点を直接カウントできます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | グリッド + ハルの再計算に対するブルート フォース |$O(R^2 \cdot n \log n)$|$O(n)$| 遅すぎる |
 | エッジベースの領域構築 + 格子カウント |$O(n \cdot R^2)$それ以上 |$O(n)$| 承認済み |

 ここ$R \le 2000$、 それで$R^2$厳密な幾何学的フィルタリングと組み合わせる場合には許容されます。 

## アルゴリズムのチュートリアル

 1. 各エッジを反復処理します。$(v_i, v_{i+1})$ポリゴンの。 各エッジは、新しい頂点がそれ自体を「挿入」できる候補位置です。 

エッジを分離する理由は、有効な拡張ポイントがハル上の 1 つの既存のエッジを正確に分割する必要があるためです。分割しないと、複数の頂点が影響を受けることになります。 
2. 固定エッジの場合、凸包が正確に接する点の幾何学的領域を構築します。$v_i$そして$v_{i+1}$。 この領域は、他のすべての頂点が新しい点によって誘導される支持線の厳密に「下」に留まるように要求することによって定義されます。 

具体的には、多角形の 1 つおきのエッジについて、候補点がそのエッジの支持線の内側に位置するように強制します。 これにより、追加の頂点が接点になることがなくなります。 
3. 選択したエッジによって定義される半平面の外側に点が存在する必要があるという条件を追加します。$(v_i, v_{i+1})$。 これにより、ポイントが元のポリゴン内に留まるのではなく、実際に新しい頂点に寄与することが保証されます。 
4. これらすべての半平面制約の交差により、凸領域が形成されます。 すべての制約は線形不等式であるため、領域は多角形であり、連続して交差する半平面によって記述することができます。 
5. この領域をエッジごとに最終ポリゴンにクリップし、その中にあるすべての整数格子点を数えます。 座標が小さいため、領域の境界ボックス内の整数点を安全に列挙し、すべての半平面に対してメンバーシップをテストできます。 
6. すべてのエッジのカウントを合計します。 各有効なポイントは、新しい「分割」となる 1 つのエッジに正確に対応するため、二重にカウントされることはありません。 

### なぜ効果があるのか

 重要な不変条件は、有効な延長点は元のハル上に正に 2 つの接頂点を持ち、それら 2 つの頂点が隣接していなければならないということです。 これは、船体が正確に 1 つの頂点を取得するという要件から導き出されます。 隣接しない頂点で接線が発生した場合、中間頂点のチェーン全体が削除され、頂点数が 1 つ以上変更されるか、減少します。 

したがって、すべての有効な点は、正確に 1 つのエッジベースの領域に一意に属し、そのような領域内のすべての点は、有効な凸包拡張子を生成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def orient(a, b, c):
    return (b[0]-a[0])*(c[1]-a[1]) - (b[1]-a[1])*(c[0]-a[0])

def inside_halfplanes(x, y, halfplanes):
    for (a, b, c) in halfplanes:
        if (b[0]-a[0])*(y-a[1]) - (b[1]-a[1])*(x-a[0]) < 0:
            return False
    return True

def solve():
    n = int(input())
    p = [tuple(map(int, input().split())) for _ in range(n)]

    xs = [x for x, y in p]
    ys = [y for x, y in p]

    minx, maxx = min(xs), max(xs)
    miny, maxy = min(ys), max(ys)

    # Build half-planes of polygon (keeping interior on left side)
    poly_hp = []
    for i in range(n):
        a = p[i]
        b = p[(i+1) % n]
        poly_hp.append((a, b, 1))

    ans = 0

    for i in range(n):
        a = p[i]
        b = p[(i+1) % n]

        # candidate region half-planes:
        # must be outside edge (a,b): opposite side of polygon interior
        # so we flip orientation
        halfplanes = []

        # all other edges: must remain inside polygon
        for j in range(n):
            u = p[j]
            v = p[(j+1) % n]

            if j == i:
                continue

            # inside condition: orientation(u,v,point) >= 0
            halfplanes.append((u, v, 1))

        count = 0

        # bounding box search (safe due to constraints)
        for x in range(minx-1, maxx+2):
            for y in range(miny-1, maxy+2):
                # must be outside chosen edge
                if orient(a, b, (x, y)) >= 0:
                    continue

                if inside_halfplanes(x, y, halfplanes):
                    count += 1

        ans += count

    print(ans)

if __name__ == "__main__":
    solve()
```コードは、エッジごとの領域構築に直接従います。 エッジごとに、ポリゴンの他のすべてのサポート半平面の内側にポイントを保持しながら、選択したエッジの外側にポイントを強制する制約システムが構築されます。 すべての候補領域が入力ポリゴンと同じ座標制限内に含まれるため、バウンディング ボックスに対するブルート スキャンは安全です。 

機能`orient`は、側面性をテストするために使用される標準の外積です。 ヘルパーさん`inside_halfplanes`選択されていないすべてのエッジの正しい側に点が存在することを検証します。 

エッジの最終的な合計は、各有効な拡張ポイントが、新しく挿入された頂点となる 1 つのエッジに一意に関連付けられているという事実を反映しています。 

## 実用的な例

 ### サンプル 1

 2 つの整数点のみが厳密な接線条件を満たす小さな凸四角形のような形状を考えます。 

| エッジ加工 | 候補領域のサイズ | 有効なポイントが見つかりました | 現在の合計 |
 | --- | --- | --- | --- |
 | エッジ0 | 0 | 0 | 0 |
 | エッジ1 | 1 | 1 | 1 |
 | エッジ2 | 1 | 1 | 2 |
 | エッジ3 | 0 | 0 | 2 |

 このトレースは、有効な整数点を生成するエッジが 2 つだけであることを示しています。これは、複数のエッジを妨げずに点を接続できる、別個の幾何学的な「ポケット」が 2 つだけ存在することを意味します。 

### サンプル 2

 正方形では、拡張領域に制限はありません。 

| エッジ加工 | 候補領域のサイズ | 有効なポイントが見つかりました | 現在の合計 |
 | --- | --- | --- | --- |
 | エッジ0 | 大 | 無制限 | 無限にたくさん |

 ここでは、すべてのエッジが無制限の実行可能領域を生成します。これは、整数点が少なくとも 1 つの方向に無限に拡張することを意味し、無限に多くの有効な拡張点が生成されることを意味します。 

これは重要な構造的分割を示しています。一部のポリゴンはエッジごとに有界の実行可能領域を誘発しますが、他のポリゴンは境界のない実行可能領域を許容します。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、多角形が完全な長方形または正方形である場合です。 その場合、隣接しないエッジからの制約が一方向への成長を制限しないため、すべてのエッジで境界のない実行可能領域が生成されます。 これにより、サンプルの動作と一致する、無限に多くの整数点が生成されます。 

もう 1 つのケースは小さな三角形です。 エッジが 3 つしかない場合でも、各エッジは依然として無制限の領域を定義しますが、他の 2 つのエッジからの制約の相互作用により、有効な整数点が頂点の延長線付近の有限セットに制限されます。 

最後の微妙なケースは、候補点がポリゴン エッジの非常に近くにあるものの、ポリゴン エッジ上ではない場合に発生します。 これらは、クロス積チェックにおける厳密な不平等に純粋に基づいて含めるか除外する必要があります。 間違った場所で非厳密な比較を使用すると、誤って共線点が含まれ、「同一線上の頂点が 3 つも存在しない」という要件に違反します。
