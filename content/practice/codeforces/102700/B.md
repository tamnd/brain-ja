## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_suffix_start(s: str) -> int:
    n = len(s)
    if n == 1:
        return 0

    i = 0
    j = 1
    k = 0

    while j + k < n:
        a = s[i + k]
        b = s[j + k]

        if a == b:
            k += 1
            continue

        if a < b:
            i = j
            j = i + 1
            k = 0
        else:
            j = j + k + 1
            k = 0

    return i

def solve(a: str, b: str) -> str:
    p = max_suffix_start(a)
    q = max_suffix_start(b)

    first = b[q]

    end = p + 1
    while end < len(a) and a[end] >= first:
        end += 1

    return a[p:end] + b[q:]

def main():
    a = input().strip()
    b = input().strip()
    print(solve(a, b))

if __name__ == "__main__":
    main()
```の`max_suffix_start`機能が維持される`i`現在の最良のサフィックスとして、`j`チャレンジャーとして。 変数`k`2 つの接尾辞が何文字一致したかを記録します。 もし`a[i+k] < a[j+k]`、挑戦者の方が優れているので、`i`に移動します`j`。 もし`a[i+k] > a[j+k]`、現在のサフィックスが優先され、すでに一致したプレフィックスによってカバーされるすべての開始はスキップできます。`j`前方にジャンプして`k + 1`。 このスキップが、ルーチンが二次ではなく線形になる理由です。 

見つけた後`p`そして`q`、コードストア`b[q]`として`first`。 父親のパートは次から始まります`a[p]`、 それで`end`から始まります`p + 1`。 次の文字が少なくとも次の文字に到達するまで、ループは拡張され続けます。`first`。 厳格な`<`重要なのは条件です。 以下に等しい文字`first`保持されます。 

Python では整数オーバーフローの懸念はなく、インデックスはすべてゼロベースです。 ループ条件`end < len(a)`父親の文字列を超えて読み取られるのを防ぎます。 最後のスライスも安全です。`p`そして`q`有効なサフィックスの開始です。 

二人の呼びかけは、`max_suffix_start`それぞれの文字列で線形時間を消費します。 最後のスキャンは、父親の文字列の選択された部分のみに触れるので、これも線形です。 最後の連結により、出力文字列が正確に作成されます。
