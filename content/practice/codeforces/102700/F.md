### なぜ効果があるのか

 階層化されたダイクストラは、次の不変条件を維持します。`dist[c][v]`選択したソースから次のパスへのパスの最小コストです。`v`正確に使用して`c`無料の航空券。 すべての有効な次のフライトには、料金を支払うか、残りの無料フライトを 1 つ消費するかという 2 つの可能性があり、両方の可能性が階層化グラフの遷移として表されます。 すべての移行コストは負ではないため、ダイクストラはすべての状態の正確な最小値を見つけます。 

固定会議国の場合`x`、すべての有効なラウンドトリップは、次の場所で一意に分割できます。`x`。 旅行者が利用する場合`i`到着前の無料航空券`x`そして`j`去った後`x`、 それから`i+j <= k`。 対応する順方向および逆方向の階層化された距離は、正確にそれらのクーポン カウントを持つパスを表すため、それらの合計は有効な往復となります。 逆に、このような距離の有限ペアを組み合わせると、最大でも次の値を使用して有効な往復が生成されます。`k`クーポン。 したがって、すべての分割で最小値を取ると、その旅行者にとって最適な往復旅行が得られます。 

4 回のダイクストラ実行では、両方の旅行者にまさにこれらの値が提供されます。 すべての法的会合の国で最小値を取ると、世界全体の最小総コストが得られます。 

## Python ソリューション```python
import sys
import heapq

input = sys.stdin.readline

INF = 10**30

def dijkstra(graph, source, n, k):
    # dist[c][v] = minimum paid cost to reach v
    # using exactly c free flights.
    dist = [[INF] * n for _ in range(k + 1)]
    dist[0][source] = 0

    pq = [(0, source, 0)]

    while pq:
        d, u, used = heapq.heappop(pq)

        if d != dist[used][u]:
            continue

        for v, w in graph[u]:
            # Pay for this flight.
            nd = d + w
            if nd < dist[used][v]:
                dist[used][v] = nd
                heapq.heappush(pq, (nd, v, used))

            # Take this flight for free.
            if used < k and d < dist[used + 1][v]:
                dist[used + 1][v] = d
                heapq.heappush(pq, (d, v, used + 1))

    return dist

def solve():
    n, m = map(int, input().split())
    a, b, k = map(int, input().split())

    graph = [[] for _ in range(n)]
    reverse_graph = [[] for _ in range(n)]

    for _ in range(m):
        u, v, w = map(int, input().split())
        graph[u].append((v, w))
        reverse_graph[v].append((u, w))

    # Alice:
    # original graph: a -> x
    # reversed graph: x -> a
    alice_forward = dijkstra(graph, a, n, k)
    alice_backward = dijkstra(reverse_graph, a, n, k)

    # Bob:
    # original graph: b -> x
    # reversed graph: x -> b
    bob_forward = dijkstra(graph, b, n, k)
    bob_backward = dijkstra(reverse_graph, b, n, k)

    answer_country = -1
    answer_cost = INF

    for x in range(n):
        if x == a or x == b:
            continue

        alice_cost = INF
        bob_cost = INF

        # Split each person's k free flights between
        # the outbound and return parts of the trip.
        for i in range(k + 1):
            for j in range(k - i + 1):
                af = alice_forward[i][x]
                ar = alice_backward[j][x]

                if af != INF and ar != INF:
                    alice_cost = min(alice_cost, af + ar)

                bf = bob_forward[i][x]
                br = bob_backward[j][x]

                if bf != INF and br != INF:
                    bob_cost = min(bob_cost, bf + br)

        if alice_cost == INF or bob_cost == INF:
            continue

        total = alice_cost + bob_cost

        if total < answer_cost:
            answer_cost = total
            answer_country = x

    if answer_country == -1:
        print(">:(")
    else:
        print(answer_country, answer_cost)

if __name__ == "__main__":
    solve()
```の`dijkstra`関数は展開された状態の最短パスです。 その`dist`配列には`k+1`すでに消費された無料フライトの数によってインデックス付けされたレイヤー。 初期状態は`(source, 0)`コストゼロで。 

通常の移行では、クーポン数は変更されず、航空券の価格が追加されます。 無料移行により、クーポン数が 1 つ増加し、0 が追加されます。 条件`used < k`存在しないものへのアクセスを防ぐ境界チェックです。`k+1`層。 

元のグラフは往路に使用されます。 反転したグラフは復路に使用されます。 たとえば、パス`x -> p -> q -> a`元のグラフでは次のようになります`a -> q -> p -> x`反転したグラフで。 シーケンスは逆になりますが、すべてのエッジのコストは同じであるため、計算された距離は元のリターン パスのコストとまったく同じになります。 

アリスとボブは別々のチケットを持っており、各人のチケットは各自の往路と復路で共有する必要があるため、4 つのダイクストラ結果が保持されます。 国を評価するとき、`i`そして`j`は、これら 2 つの区間に割り当てられたクーポン数です。 条件`j <= k - i`と同等です`i + j <= k`。 

コードでは Python 整数を使用するため、整数オーバーフローの心配はありません。`INF`可能な実際の答えよりもはるかに大きい値が選択されます。 単純なパスであっても、`n-1`有料航空券の料金は以下です`10^7`、そして両方の旅行者の合計は、以下に比べて小さいままです。`10^30`。 

最終スキャンは国から行われます`0`上向きで、次の場合にのみ更新されます。`total < answer_cost`。 等コストは意図的に無視され、最小の国インデックスが自動的に保存されます。

 あるのは`k+1 <= 11`レイヤーがあるため、展開されたグラフには最大でも`11n`州。 4 つのダイクストラ実行のそれぞれで、グラフが一定の回数処理されます。 最終的な国スキャンは最大でも実行されます。`n(k+1)(k+2)/2`分割小切手、つまり`5.5 * 10^5`いつチェックしますか`k = 10`。 と`n,m <= 10^4`、解は意図した範囲内に留まります。 

## テストケース

 次のテスト ハーネスには、3 つの公式サンプルと 4 つの追加のケースが含まれています。 ヘルパーさん`run`完全な入力文字列を同じに渡します`solve`ロジックを作成し、その出力を返します。```python
import heapq
import io
import sys

INF = 10**30

def solve(data: str) -> str:
    it = iter(map(int, data.split()))

    n = next(it)
    m = next(it)

    a = next(it)
    b = next(it)
    k = next(it)

    graph = [[] for _ in range(n)]
    reverse_graph = [[] for _ in range(n)]

    for _ in range(m):
        u = next(it)
        v = next(it)
        w = next(it)

        graph[u].append((v, w))
        reverse_graph[v].append((u, w))

    def dijkstra(graph, source):
        dist = [[INF] * n for _ in range(k + 1)]
        dist[0][source] = 0

        pq = [(0, source, 0)]

        while pq:
            d, u, used = heapq.heappop(pq)

            if d != dist[used][u]:
                continue

            for v, w in graph[u]:
                nd = d + w

                if nd < dist[used][v]:
                    dist[used][v] = nd
                    heapq.heappush(pq, (nd, v, used))

                if used < k and d < dist[used + 1][v]:
                    dist[used + 1][v] = d
                    heapq.heappush(pq, (d, v, used + 1))

        return dist

    af = dijkstra(graph, a)
    ar = dijkstra(reverse_graph, a)
    bf = dijkstra(graph, b)
    br = dijkstra(reverse_graph, b)

    best_country = -1
    best_cost = INF

    for x in range(n):
        if x == a or x == b:
            continue

        alice = INF
        bob = INF

        for i in range(k + 1):
            for j in range(k - i + 1):
                if af[i][x] != INF and ar[j][x] != INF:
                    alice = min(alice, af[i][x] + ar[j][x])

                if bf[i][x] != INF and br[j][x] != INF:
                    bob = min(bob, bf[i][x] + br[j][x])

        if alice == INF or bob == INF:
            continue

        total = alice + bob

        if total < best_cost:
            best_cost = total
            best_country = x

    if best_country == -1:
        return ">:("

    return f"{best_country} {best_cost}"

def run(inp: str) -> str:
    return solve(inp).strip()

### 会合国間の結びつき

 サンプル 1 では、両国`2`そして`3`総コストがある`4`。 このアルゴリズムは、インデックスの昇順で国を調べます。 国を格納します`2`初めてコストを見たとき`4`。 いつ国`3`も生産します`4`、条件`total < answer_cost`は誤りなので、国`2`答えは残っています。

＃＃＃ その通り`k`無料航空券

 を考慮してください。`k=10`カスタムケース。 アリスの国への道`11`ちょうど 10 個のアウトバウンド フライトが含まれています。```
0 -> 2 -> 3 -> ... -> 10 -> 11
```10個すべて無料でご利用いただけます。 帰りの飛行機`11 -> 0`支払わなければならない、費用がかかる`1`。 ボブには対称ルートがあります`11 -> 1`。 したがって、各旅行者は料金を支払います`1`、与える:```
11 2
```階層化グラフにはレイヤーが含まれています`0`を通して`10`したがって、10 回目のフリー フライトによってステートがレイヤーに移動されます。`10`。 条件`used < k`航空券の制限に正確に一致するため、11 回目の無料フライトが妨げられます。 

### 同じ国間の複数のフライト

 入力では、フライトが一意のエンドポイントを持つ必要はないため、隣接リストはすべてのフライトを保持する必要があります。 ダイクストラ実装では、単純に各フライトを個別の遷移として扱います。 2便出発の場合`u`に`v`コストが異なると、当然、安価なものが高価なものよりも優先されますが、等コストの複製では正確性の問題は発生しません。 

### 整数のサイズ

 最大の通常の単純なパスは、最大でも次の値を使用します。`n-1`有料航空券、それぞれの費用は最大でも`1000`したがって、関連するルート コストは次のようになります。`10^7`。 アリスとボブのコストを追加した後でも、これは Python の整数の範囲内に収まります。 それにもかかわらず、実装では非常に大規模な`INF`到達不可能な状態を有効な距離と混同できないようにするための値です。 

中心的な教訓は、問題は実際には、特定の会合国への最安ルートを見つけることではないということです。 これは、少量の追加リソース、無料フライトの数を使用して最短経路を計算し、往路と復路の距離を組み合わせることです。 そのリソースがダイクストラ状態の一部になると、明らかに世界的な会議国の選択は単純な最終スキャンになります。 

提供されたステートメントから言及する価値のある小さな修正: 社説で使用されている最初のカスタム テスト`m = 5`、5つのフライトラインが含まれているためです。 アルゴリズムと他のすべてのテスト ケースは、元の制約と一致しています。
