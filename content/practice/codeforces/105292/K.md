 ## 解決策
 ## 問題の理解

 1枚に2枚あります$300 \times 300$ボード。 移動は位置にある駒を1つ選択します$(x,y)$そしてそれを長方形内の厳密に小さい位置に移動します$[1,x] \times [1,y]$。 目的地を現在のマス目にすることはできず、他のピースが占有することもできません。 

ゲームは公平かつ有限です。 すべての動きは少なくとも 1 座標を減らすため、ゲームは最終的に終了する必要があります。 動けなくなったプレイヤーが負けとなります。 

各開始構成について、その後の最適なプレイを想定して、最初の手が何回勝っているかをカウントする必要があります。 テストケースの数は$10^5$したがって、テスト ケースごとにゲーム理論の計算を実行するものは、非常に遅すぎます。 勝ち手のクローズドフォームの特徴付けが必要です。 

微妙な点は、2 つの部分が完全に独立していないことです。 他の作品への移動は禁止です。 2 つの独立したグランディ数の xor を盲目的に計算するソリューションでは、この相互作用が見逃されます。 

考慮する：```
(1,1) and (2,1)
```大きい部分は次の場所に移動したいと考えています$(1,1)$, しかし、そのマスは占有されているため、その手は存在しません。 

もう 1 つの重要なケースは、両方のピースが同じ対角線上にある場合です。$x+y=\text{constant}$。 例えば：```
(3,2) and (2,3)
```どちらのポジションも同じ単一ピースのグランディ番号を持ちます。 不注意な xor ベースの議論では、xor がゼロであるためにポジションが負けていると言うことになりますが、それは正しいことですが、なぜどの手がそのゼロの状態を維持できないのかを理解する必要があります。 

## アプローチ

 ブルートフォースアプローチは、駒の位置のすべてのペアをゲーム状態として扱い、ゲームグラフ上で動的プログラミングによってそのスプラーググランディ値を計算することです。 がある$90{,}000$ボードセルなので、順序付けされた 2 ピース状態の数は次のとおりです。$8 \times 10^9$。 状態を保存することさえ不可能です。 

重要な観察は、単一のピースがすでに非常に単純な構造を持っているということです。 

させて$g(x,y)$ワンピースのグランディナンバーになります。 から$(x,y)$、下と左の長方形内のすべての正方形に到達できます。 定義すると$$k=x+y-2,$$その後、より小さい値ごとに$0,1,\dots,k-1$到達可能な位置の中に出現し、到達可能な位置には値がありません$k$。 したがって、mex は正確に$k$。 

それで$$g(x,y)=x+y-2.$$ボードは斜めに倒れます。 同じ対角線上のすべての正方形には同じグランディ番号が割り当てられます。 

次に 2 つの部分を考えてみましょう。 

対角値が異なる場合は、次のようにします。$a<b$の場合、位置はサイズの 2 つの Nim ヒープとまったく同じように動作します。$a$そして$b$。 そのグランディ数は$a \oplus b$。 

両方のピースが同じ対角線上にある場合、その位置は特別です。 2 つのピースは異なる正方形を占めていますが、単一ピースのグランディ番号は同じです。 直接 mex 引数は、そのような状態がグランディ数を持つことを示します$0$。 

これにより、勝利戦略の構造がすぐに得られます。 

2 つの対角値が等しい場合、その局面は負けており、勝ちとなる初手はありません。 

対角値が異なる場合、負け状態に移行する唯一の方法は、より大きい対角値を持つ駒をより小さい対角値に移動することです。 その対角線上にあるすべての合法的な目的地は、勝利の手段となります。 

残りのタスクは純粋に幾何学的なものです。到達可能な場合は占有正方形を除き、許可された長方形内で指定された対角線の何個の正方形が到達可能かを数えます。

 ## アルゴリズムのチュートリアル

 1. 対角値を計算します。$$g_1=x_1+y_1-2,\qquad g_2=x_2+y_2-2.$$1. もし$g_1=g_2$、0を出力します。 

対角値が等しい州はポジションを失っているため、いかなる動きも別のポジションの喪失につながる可能性はありません。 
2. 仮定します$g_1>g_2$。 

勝ち手は最初の駒を対角線上に移動する必要があります$g_2$。 
3. 対角線上にある正方形の数を数えます$g_2$長方形の中に横たわる$$1 \le p \le x_1,\qquad 1 \le q \le y_1.$$対角線の条件は、$$p+q=g_2+2.$$させて$$L=\max(1,\ g_2+2-y_1),$$

$$R=\min(x_1,\ g_2+1).$$次に、その対角線上にある到達可能な正方形の数は次のようになります。$$\max(0,\ R-L+1).$$1. 相手の駒が正方形の場合$(x_2,y_2)$が移動駒の到達可能な長方形の内側にある場合、占有された正方形に移動することは違法であるため、1 を減算します。 
2. もし$g_2>g_1$、2 番目の部分に対して対称計算を実行します。 

### なぜ効果があるのか

 一枚で$(x,y)$グランディ番号あり$x+y-2$。 移動するたびにこの値は厳密に減少し、より小さい値はすべて到達可能です。 

異なる対角線上にある 2 つのピースの場合、ゲームは、サイズが対角値である 2 つの Nim ヒープに相当します。 ゼロ グランディ状態に到達する唯一の方法は、2 つの値を等しくすることです。 

すでに同じ対角線上にある 2 つのピースの場合、状態自体がグランディ番号を持ちます$0$。 どの移動も 1 つの対角値を変更し、等号が破られるため、すべての移動はゼロ以外の状態になります。 

したがって、勝ちの手は、移動した駒を他の駒の対角線上に置く、まさに正当な手です。 これらの移動をカウントすると、長方形内の対角線セグメントの格子点をカウントすることになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def count_on_diagonal(x, y, k):
    s = k + 2

    left = max(1, s - y)
    right = min(x, s - 1)

    if left > right:
        return 0
    return right - left + 1

t = int(input())
ans = []

for _ in range(t):
    x1, y1, x2, y2 = map(int, input().split())

    g1 = x1 + y1 - 2
    g2 = x2 + y2 - 2

    if g1 == g2:
        ans.append("0")
        continue

    if g1 > g2:
        res = count_on_diagonal(x1, y1, g2)

        if x2 <= x1 and y2 <= y1:
            res -= 1

        ans.append(str(res))
    else:
        res = count_on_diagonal(x2, y2, g1)

        if x1 <= x2 and y1 <= y2:
            res -= 1

        ans.append(str(res))

sys.stdout.write("\n".join(ans))
```機能`count_on_diagonal`満足する格子点をカウントします$$p+q=k+2$$長方形の中にあります。 座標を反復処理する代わりに、座標の有効範囲を計算します。$p$直接。 

減算ステップは、2 つの部分間の唯一の相互作用です。 占有された正方形が移動駒の到達可能な長方形の内側にある場合、有効な目的地としてカウントされるため、削除する必要があります。 

すべての算術演算は標準の Python 整数に簡単に適合します。 ボードのサイズはわずか 300 ですが、ソリューションはその制限に依存しません。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    def count_on_diagonal(x, y, k):
        s = k + 2
        left = max(1, s - y)
        right = min(x, s - 1)
        if left > right:
            return 0
        return right - left + 1

    t = int(input())
    out = []

    for _ in range(t):
        x1, y1, x2, y2 = map(int, input().split())

        g1 = x1 + y1 - 2
        g2 = x2 + y2 - 2

        if g1 == g2:
            out.append("0")
        elif g1 > g2:
            res = count_on_diagonal(x1, y1, g2)
            if x2 <= x1 and y2 <= y1:
                res -= 1
            out.append(str(res))
        else:
            res = count_on_diagonal(x2, y2, g1)
            if x1 <= x2 and y1 <= y2:
                res -= 1
            out.append(str(res))

    sys.stdout.write("\n".join(out))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    result = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return result

 ## 特殊なケース

 次のことを考慮してください。```
1
3 2 2 3
```どちらのピースも対角値を持ちます$3$。 すでに立場は負け状態だ。 どのような移動でも対角値が 1 つ減少し、等価性が崩れます。 アルゴリズムが検出するのは、$g_1=g_2$そしてすぐに出力します:```
0
```次に、次のことを考えてみましょう。```
1
3 3 1 1
```大きいほうに価値がある$4$、小さい方が価値がある$0$。 負け状態を作成するには、対角線 0 に移動する必要があります。その対角線には 1 つの正方形のみが含まれます。$(1,1)$、占領されています。 対角線上のカウントは 1 で、占有されている正方形に到達できるため、1 を減算して次を取得します。```
0
```ついに：```
1
6 6 2 2
```対角線 2 には 3 つの正方形が含まれます。```
(1,3), (2,2), (3,1)
```占領された広場$(2,2)$が削除され、合法的な勝ち手が 2 つ残ります。 アルゴリズムは次を返します。```
2
```これは期待される結果と一致します。
