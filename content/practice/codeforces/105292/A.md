 ## 問題の理解

 空のセルで構成される長方形のあかりボードが与えられます。`.`そして壁`#`。 

電球は空のセルにのみ配置できます。 その光は、壁またはボードの端に到達するまで、水平および垂直に進みます。 2 つの電球が相互に点灯することは許可されていません。つまり、同じ連続した行セグメントまたは同じ連続した列セグメントに 2 つの電球が存在することはできません。 

タスクは何かを最適化することではありません。 電球の有効な配置を出力し、それらのセルにマークを付けるだけです。`L`。 

グリッドの大きさは次のとおりです。`2000 × 2000`これは、最大 400 万個のセルが存在する可能性があることを意味します。 各電球の位置から行と列を繰り返しスキャンするアルゴリズムは、非常に遅すぎます。 セルの数が本質的に線形であることが必要です。 

よくある間違いの原因は、可視性セグメントではなく個々のセルについて考えることです。

## アプローチ

 ブルートフォースの観点では、電球の位置を繰り返し選択し、すべてのセルが点灯しているかどうか、および電球のペアが相互に認識できるかどうかを確認します。 単一の候補ソリューションをチェックする場合でも、長い行と列をスキャンする必要がある場合があります。 最大 400 万個のセルがあるため、配置を直接探索することは完全に不可能です。 

重要な観察は、可視性は行セグメントと列セグメントによってのみ決定されるということです。 

行セグメントは、最大の連続ブロックです。`.`行内のセル。 壁はセグメントを破壊します。 列セグメントも同様に定義されます。 

すべての空のセルは、正確に 1 つの行セグメントと正確に 1 つの列セグメントに属します。 

次に、2 部グラフについて考えてみましょう。 

片面にはすべての行セグメントが含まれます。 

反対側にはすべての柱セグメントが含まれます。 

すべての空のセルについて、行セグメントと列セグメントの間にエッジを追加します。 

セルに電球を配置するということは、対応するエッジを選択することを意味します。 

2 つの電球が互いに照らし合わないというルールは非常に単純になります。行セグメントには最大 1 つの電球を含めることができ、列セグメントには最大 1 つの電球を含めることができます。 グラフの用語では、選択したエッジが一致を形成する必要があります。 

イルミネーションはどうでしょうか？ 

行セグメントに電球が含まれている場合、その行セグメント内のすべてのセルが点灯します。 列セグメントについても同様です。 

セルの 2 つのセグメント端点の少なくとも 1 つが、選択された一致するエッジに入射する場合、セルは照明されます。 

これは、古典的なグラフの事実を示唆しています。つまり、最大一致の端点は頂点カバーを形成します。 すべてのエッジには少なくとも 1 つのエンドポイントが一致します。 

したがって、セグメント グラフで最大一致を構築すると、すべてのセルのエッジに少なくとも 1 つの一致する端点が存在します。 つまり、すべてのセルは行セグメントの電球または列セグメントの電球のいずれかによって照明されます。 

さらに良いことに、貪欲なマッチングはすでに最大化されています。 両方の対応するセグメントがまだ使用されていない場合は、すべてのセルをスキャンして電球を配置できます。 

明示的に構築するとグラフは巨大になりますが、グリッド構造により、ボードをスキャンしながらエッジを直接処理できます。

 ## アルゴリズムのチュートリアル

 1. すべての空のセルの行セグメント ID を計算します。 

各行を左から右にスキャンします。 連続した新しいブロックが出現するたびに、`.`セルが開始されると、それに新しい行セグメント ID を割り当て、その ID をブロック内のすべてのセルに与えます。 
2. すべての空のセルの列セグメント ID を計算します。 

各列を上から下にスキャンします。 連続した新しいブロックが出現するたびに、`.`セルが開始されると、それに新しい列セグメント ID を割り当て、その ID をブロック内のすべてのセルに与えます。 
3. 2 つのブール配列を維持します。 

1 つの配列は、行セグメントがすでに一致しているかどうかを記録します。 

もう 1 つは、列セグメントがすでに一致しているかどうかを記録します。 
4. グリッドのすべてのセルをスキャンします。 

空のセルごとに、その行セグメント ID と列セグメント ID を確認します。 

どちらのセグメントもまだ一致していない場合は、このセルに電球を配置し、両方のセグメントを一致としてマークします。 

これはまさに、最大マッチングの標準的な貪欲な構築です。 
5. ボードを出力します。 

選択されたすべてのセルは次のようになります。`L`。 壁は残る`#`。 他の空のセルはすべて残ります`.`。 

### なぜ効果があるのか

 各行セグメントと各列セグメントは最大 1 回使用されるため、選択されたバルブ位置はマッチングのエッジに対応します。 

貪欲なプロセスにより、最大限のマッチングが生成されます。 終了後、2 つの端点が両方とも一致しないエッジは存在しません。そうでない場合、そのエッジは追加される可能性があります。 

空のセルを選択します。 対応するグラフのエッジは、行セグメントと列セグメントを接続します。 

マッチングが最大であるため、そのエッジの少なくとも 1 つの端点がマッチングされます。 一致したエンドポイントには、同じセグメントのどこかに電球が含まれています。 

一致したエンドポイントが行セグメントの場合、電球はセルを含む行セグメント全体を照らします。 

一致したエンドポイントが列セグメントの場合、電球はセルを含む列セグメント全体を照らします。 

したがって、すべての空のセルが点灯します。 

選択したエッジが一致を形成するため、どの行セグメントにも 2 つのバルブが含まれず、どの列セグメントにも 2 つのバルブが含まれません。 したがって、2 つの電球がお互いを照らすことはできません。 

構築は常に有効です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
grid = [list(input().strip()) for _ in range(n)]

row_id = [[-1] * m for _ in range(n)]
row_cnt = 0

for i in range(n):
    j = 0
    while j < m:
        if grid[i][j] == '#':
            j += 1
            continue

        rid = row_cnt
        row_cnt += 1

        k = j
        while k < m and grid[i][k] == '.':
            row_id[i][k] = rid
            k += 1

        j = k

col_id = [[-1] * m for _ in range(n)]
col_cnt = 0

for j in range(m):
    i = 0
    while i < n:
        if grid[i][j] == '#':
            i += 1
            continue

        cid = col_cnt
        col_cnt += 1

        k = i
        while k < n and grid[k][j] == '.':
            col_id[k][j] = cid
            k += 1

        i = k

row_used = [False] * row_cnt
col_used = [False] * col_cnt

ans = [row[:] for row in grid]

for i in range(n):
    for j in range(m):
        if grid[i][j] != '.':
            continue

        r = row_id[i][j]
        c = col_id[i][j]

        if not row_used[r] and not col_used[c]:
            row_used[r] = True
            col_used[c] = True
            ans[i][j] = 'L'

for row in ans:
    print("".join(row))
```最初のフェーズでは、行セグメントにラベルを付けます。 空のセルの最大の水平ブロックごとに 1 つの識別子が与えられます。 

2 番目のフェーズでは、列セグメントに対して同じことを行います。 

その後、空の各セルは、そのエッジに対応する 2 つのグラフ頂点をすでに知っています。 

貪欲なマッチング段階は非常に小さいです。 両方のセグメントのエンドポイントが現在空いている場合は、それらを一致させてバルブを配置します。 

出力グリッドは、元のボードのコピーとして初期化されます。 マッチングで選択されたセルのみが に変更されます。`L`。 

孤立したセル、長さ 1 のセグメント、または多くの壁を含むボードの場合、特別な処理は必要ありません。 セグメント構造はそれらすべてを自然に処理します。
