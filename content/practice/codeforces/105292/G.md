 ## 解決策
 ## 問題の理解

 私たちは与えられています$N$座標が次から番号付けされる円上の円間隔。$0$に$2N-1$。 

グラフの各頂点は 1 つの区間に対応します。 2 つの頂点の間隔が重なっている場合、2 つの頂点は隣接しています。 タスクは、最大クリーク、つまりセット内のすべての間隔ペアが重複するような最大の間隔セットを出力することです。 

グラフ自体は明示的に与えられることはありません。 すべてのエッジを構築するにはすでに時間がかかります$O(N^2)$時間を費やすと、一般的なグラフで最大クリークを解決することは絶望的になります。 問題の要点は、グラフが円形の間隔から生成されており、より強力な構造を持っているということです。 

バウンド$N \le 2000$が重要な観察です。 アン$O(N^2)$解決策はまったく問題ありません。 アン$O(N^3)$解はすでに限界に近づいていますが、指数関数的なクリーク検索に似たものは不可能です。 

微妙な点は、円間隔は Helly 特性を満たさないことです。 3 つの間隔は、共通の座標を共有せずにペアごとに重なる場合があります。 最初のサンプルはまさにそのような構成です。 

例えば：```
3
0 3
2 5
4 1
```すべてのペアは重なっているため、答えのサイズは 3 になります。 

最大数の間隔に含まれる座標のみを検索するソリューションは、誤って 2 を返します。 

もう 1 つの起こりやすい間違いは、ラップされた間隔を 2 つの独立した間隔として扱うことです。 ラップされた間隔は、円上の 1 つの接続された円弧のままです。 それを分割し、両方の部分が同じ頂点に属していることを忘れると、実際には存在しないクリークが作成される可能性があります。 

## アプローチ

 ブルートフォースアプローチは、グラフを構築し、一般的な最大クリークアルゴリズムを実行することです。 

グラフの構築にはすでにコストがかかります$O(N^2)$というのは、間隔のすべてのペアの重複をチェックする必要があるからです。 その後、任意のグラフ上の最大クリークは NP 困難であるため、$N=2000$完全に手の届かないところにあります。 

円形の間隔の構造がすべてを変えます。 

円弧グラフに関する古典的な事実は次のとおりです。 

任意の間隔を取る$A$。 円の外側のカットポイントを選択してください$A$。 そこで円を切ると、すべての区間が直線上の普通の区間になります。 

次に、以下を含むクリークを考えてみましょう。$A$。 クリーク内のすべての間隔が交差するため、$A$、それらのどれも、間隔表現を壊す方法でカットを横切ることはできません。 この変換された画像内で間隔グラフが得られます。 

区間グラフはヘリー特性を満たします。つまり、ペアごとに交差する区間には常に共通点があります。 

それは、以下を含むすべてのクリークを意味します。$A$は、カット後のクリークのすべての間隔でカバーされる点に対応します。 

これは非常に有用な戦略を提供します。 

1 つの間隔を固定する$A$。 

外側の円を切り取る$A$。 

すべての間隔を直線上の間隔に変換します。 

を含む最大の派閥$A$は、まさに、共通点をカバーする変換された区間の最大セットです。 

その集合を見つけるのは標準的なスイープライン問題です。 

考えられるすべての選択肢についてこのプロセスを繰り返す$A$費用$O(N^2)$、これは十分に高速です$N=2000$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース最大クリーク | 指数 | O(N²) | 遅すぎる |
 | 1 つの間隔を固定し、円を切り取り、オーバーラップをスイープ | O(N²) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 間隔を固定する$i$。 
2. 間隔の右の終点の直後のカットポイントを選択します$i$。 構造上、カットは間隔の外側にあります$i$。 
3. 円を広げて一定の長さの線にします$2N$。 
4. すべての円形の間隔を、その線上の 1 つの通常の間隔に変換します。 
5. 間隔と交差する間隔のみを保持する$i$。 を含むあらゆるクリーク$i$そのような間隔のみを使用できます。 
6. 変換された区間上にスイープ ラインを実行します。 
7. スイープがこれまでに確認された最大数の間隔でカバーされるポイントに到達するたびに、対応する間隔インデックスのセットを記録します。 
8. そのセットは、間隔を含む最大クリークです$i$。 
9. 間隔ごとに繰り返します$i$。 
10. すべての選択肢で見つかった最大のクリークを出力します。$i$。 

### なぜ効果があるのか

 最大クリークを修正する$C$。 

任意の間隔を選択します$A \in C$。 

アルゴリズムは最終的にこの間隔を固定間隔として処理します。 

カットは外側を選択$A$、つまり、次のすべての間隔$C$直線上の等間隔になります。 以来$C$はクリークであり、これらの間隔のすべてのペアが交差します。 

直線上の間隔の場合、ペアごとの交差は共通点の存在を意味します。 したがって、次のすべての区間は、$C$スイープポジションをカバーします。 

スイープがその位置を処理するとき、少なくとも次のことを確認します。$|C|$インターバルが同時にアクティブになります。 

したがって、アルゴリズムは少なくとも次のサイズのクリークを見つけます。$|C|$。 

最大クリークを超えるクリークは存在できないため、アルゴリズムは正確に最大クリークを見つけます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def inside_arc(x, l, r, m):
    if l <= r:
        return l <= x <= r
    return x >= l or x <= r

def intersect(a_l, a_r, b_l, b_r, m):
    return inside_arc(a_l, b_l, b_r, m) or \
           inside_arc(a_r, b_l, b_r, m) or \
           inside_arc(b_l, a_l, a_r, m) or \
           inside_arc(b_r, a_l, a_r, m)

n = int(input())
seg = [tuple(map(int, input().split())) for _ in range(n)]

m = 2 * n

best = []

for root in range(n):
    l0, r0 = seg[root]

    events = []

    cut = (r0 + 1) % m

    for idx, (l, r) in enumerate(seg):
        if not intersect(l0, r0, l, r, m):
            continue

        L = (l - cut + m) % m
        R = (r - cut + m) % m

        if L <= R:
            events.append((L, 1, idx))
            events.append((R + 0.5, -1, idx))
        else:
            events.append((0, 1, idx))
            events.append((R + 0.5, -1, idx))

            events.append((L, 1, idx))
            events.append((m + 0.5, -1, idx))

    events.sort()

    active = set()

    for pos, typ, idx in events:
        if typ == 1:
            active.add(idx)
            if len(active) > len(best):
                best = list(active)
        else:
            active.remove(idx)

print(len(best))
print(*best)
```実装は証明に直接続きます。 

外側のループは 1 つの間隔を固定し、その外側の円を切り取ります。 

各円形の間隔は、カットを基準とした座標に変換されます。 ラップされた間隔は 2 つの通常の部分になり、2 つのイベント範囲を追加することで処理されます。 

スイープ ラインは一連のアクティブな間隔を維持します。 アクティブ セットが現在の答えより大きくなるたびに、それを保存します。 

唯一デリケートな部分は円上の区間交差です。 ヘルパー関数`inside_arc`そして`intersect`ラップされた間隔を正しく処理します。 

すべてのエンドポイントが異なるため、イベントの順序は明確であり、特別な結合処理は必要ありません。

 ## 特殊なケース

 もう一度考えてみましょう:```
3
0 3
2 5
4 1
```3 つの間隔すべてに属する座標がない場合でも、3 つの間隔はクリークを形成します。 最大カバレッジのみに基づくソリューションは 2 を返します。 

区間 0 を固定し、その外側の円を切り取ると、問題は区間グラフになります。 3 つの変換された間隔は共通のスイープ位置を共有し、アルゴリズムはサイズ 3 を正しく検出します。 

次に、次のことを考えてみましょう。```
2
0 1
2 3
```間隔がバラバラです。 どちらの固定間隔を選択しても、スイープに両方の間隔が同時に含まれることはありません。 最大のアクティブ セットのサイズは 1 で、これが正解です。 

ついに：```
4
0 7
1 2
3 4
5 6
```大きなラップ間隔は小さな間隔ごとに交差しますが、小さな間隔は互いに交差しません。 

スイープは次のような派閥を記録します。`{0,1}`、`{0,2}`、 そして`{0,3}`、サイズはすべて 2 です。より大きなクリークは表示されないため、答えは正しく 2 として報告されます。
