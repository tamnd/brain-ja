 ## アルゴリズムのチュートリアル

 1. 配列内の各値の頻度をカウントします。 これにより、後で任意の候補で割り切れる数値の数を計算できるようになります。`g`。 
2. 配列を作成する`cnt[g]`すべてゼロに初期化される`g`入力の最大値まで。 この配列には、何個の要素が割り切れるかが格納されます。`g`。 
3. 各値について`x`配列内で、のすべての約数を反復処理します。`x`そして増加します`cnt[d]`。 これにより、すべての約数がそれに寄与する数値の数を正確にカウントできるようになります。 
4. 構築後`cnt`、次のように解釈します。`cnt[g] = c`、次に以下のサイズの部分列`c`少なくとも GCD を持つことができる`g`。 
5. それぞれに最適な GCD が必要です`k`。 配列を構築します`best[k]`ゼロで初期化されます。 
6. それぞれについて`g`1 から最大値まで、その寄与をすべてに伝播します。`k ≤ cnt[g]`、潜在的に設定できます`best[k] = max(best[k], g)`。 
7. すべてを更新するのではなく、これを効率的に行うには`k`それぞれに対して明示的に`g`を繰り返します`g`降順で結果を貪欲に埋めて、より大きくなるようにします。`g`小さいものを最初に上書きします。 
8. 最後に出力`best[1..n]`。 

### なぜ効果があるのか

 サイズのすべての有効な部分列`k`選択されたすべての要素を除算する整数に対応します。 この整数は、選択したすべての要素の約数である必要があるため、少なくとも次の要素の約数として表示される必要があります。`k`配列内の要素。 したがって、問題は、少なくとも次の値に現れる最大の除数値を見つけることになります。`k`数字。 篩ベースの計数により、正確な割り算の頻度が保証され、降順で処理することで、最大値が正しく支配されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    maxa = max(a)

    freq = [0] * (maxa + 1)
    for x in a:
        freq[x] += 1

    cnt = [0] * (maxa + 1)

    for d in range(1, maxa + 1):
        for m in range(d, maxa + 1, d):
            cnt[d] += freq[m]

    best = [0] * (n + 1)

    for g in range(1, maxa + 1):
        c = cnt[g]
        if c == 0:
            continue
        for k in range(1, c + 1):
            if g > best[k]:
                best[k] = g

    print(*best[1:])

if __name__ == "__main__":
    solve()
```周波数を構築した後、古典的なふるいパターンを使用して除数カバレッジを計算します。 次に、考えられる GCD 候補ごとに、サポートできるすべてのサブシーケンスの長さを更新します。 内側のループは、除数にわたる高調波の総和によって制約に対して許容可能な複雑さが維持されるため、安全です。
