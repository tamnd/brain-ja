 ## 解決策
 ## 問題の理解

 2 つの独立したツリーが与えられ、それぞれがすでに内部で接続されています。 最初のツリーの頂点と 2 番目のツリーの頂点の間に、新しいエッジを 1 つだけ追加できます。 このエッジを追加すると、2 本の木が 1 つの大きな木になります。この最終構造の直径を最小化することが課題となります。 

ツリーの直径は、頂点のペア間の最長の最短経路距離です。 新しいエッジを追加すると、2 つのコンポーネント間の最短パスが変更されるため、エンドポイントの選択によって新しい最長パスが直接制御されます。 

入力サイズは最大 2 つのツリーのサイズになります`2 * 10^5`これにより、すべてのペアの最短パスを再計算したり、接続ポイントの可能なすべてのペアを試行したりするアプローチは除外されます。 ツリー全体のすべてのノード ペアに対する二次チェックでさえ、すでに遅すぎるでしょう。 これにより、各ツリーを少数の意味のある要約値に圧縮するソリューションが必要になります。 

素朴な推論による典型的な失敗例は、「中心」が何を意味するのかを慎重に定義せずに、ツリーの中心を接続する必要があると仮定することです。 もう 1 つの微妙な問題は、各ツリーで局所的に半径を最小化すると、グローバル直径が自動的に最小化されると仮定していることです。これは、新しいエッジ全体での距離の結合方法を考慮しない限り真実ではありません。 

## アプローチ

 ブルートフォース手法では、各ツリーから 1 つずつ、考えられるすべてのノードのペアを試し、それらの間にエッジを追加し、結果の直径を計算して、最小値を取得します。 直径の 1 回の計算は、2 回の BFS 実行を使用して線形時間で実行できますが、それをすべての計算に対して実行します。`n * m`ペアは約で完全に実行不可能です`10^10`最悪の場合の評価も。 

重要な洞察は、2 つのツリーを接続すると、結合されたツリー内の最長パスは完全に元のツリーの 1 つの内部に存在するか、または追加されたエッジを通って一方のツリーからもう一方のツリーに進み、最も遠いノードに到達するかのどちらかであるということです。 これは、答えの構造が、ノードがそのツリー内の選択された接続ポイントからどれだけ離れているかによってのみ依存することを意味します。 

各ツリーについて、その半径、つまりすべてのノードにわたる最小の離心率を計算します。 樹木の既知の事実は、半径が端点の直径から導出できるということです。直径を計算し、最長経路の中点を取得し、その中点までの最大距離を測定します。 

両方の半径がわかったら、ツリーを接続する最良の方法は、両側のバランスが取れるように一方のツリーのノードをもう一方のツリーのノードに接続することです。 結果として得られる直径は、元の 2 つの直径と、ツリー A の最も遠い点から接続を通ってツリー B に至るパスという 3 つの量の最大値になります。 

これにより、問題全体が単純化され、2 つの直径を計算し、それらを 1 つの式と組み合わせることができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべての接続を試す | O(nm) | O(n+m) | 遅すぎる |
 | 直径 + 半径の計算式 | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最初のツリー内の任意のノードから BFS を実行して、最も遠いノードを見つけます`a`。 これにより、直径の 1 つの端点が特定されます。 
2.BFS を実行します。`a`最も遠いノードを見つけるには`b`。 間の距離`a`そして`b`最初の木の直径です。 
3.BFS を実行します。`b`距離を再度計算します。 すべてのノードについて、その離心率はこれらの距離から近似でき、半径はすべてのノードまでの最小可能な最大距離になります。 ツリーでは、これは直径パスの中心を取ることに相当します。 
4. 2 番目のツリーに対して手順 1 ～ 3 を繰り返し、その直径と半径を取得します。 
5. 直径を取得したら`d1`、`d2`と半径`r1`、`r2`, 2本の木の中心を結ぶことを考えます。 マージされたツリー内の最悪の場合の距離は次のようになります。`max(d1, d2, r1 + r2 + 1)`。 
6. この値を出力します。 

### なぜ効果があるのか

 マージされたツリー内のパスはすべて、1 つの元のツリー内に完全に留まるか、追加されたエッジを 1 回だけ交差します。 交差する場合は、ツリー A のノードから接続ポイントまで移動し、次にエッジを越えて、ツリー B の接続ポイントから別のノードに移動する必要があります。 このような最長のパスは、選択した接続ノードからエンドポイントまでの距離によって決まります。これは、中心、つまり半径最小化ノードを選択することによって最小化されます。 これにより、全体的な最適化問題全体が 2 つの独立したツリー半径の結合に縮小されます。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

def bfs(start, adj):
    n = len(adj) - 1
    dist = [-1] * (n + 1)
    q = deque([start])
    dist[start] = 0
    far = start

    while q:
        v = q.popleft()
        for to in adj[v]:
            if dist[to] == -1:
                dist[to] = dist[v] + 1
                q.append(to)
                if dist[to] > dist[far]:
                    far = to

    return far, dist

def tree_diameter_and_radius(adj):
    u, _ = bfs(1, adj)
    v, dist_u = bfs(u, adj)
    _, dist_v = bfs(v, adj)

    diameter = dist_u[v]

    # compute eccentricity for each node using max distance from diameter endpoints
    radius = float('inf')
    for i in range(1, len(adj)):
        radius = min(radius, max(dist_u[i], dist_v[i]))

    return diameter, radius

def solve():
    n = int(input())
    adj1 = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        adj1[u].append(v)
        adj1[v].append(u)

    m = int(input())
    adj2 = [[] for _ in range(m + 1)]
    for _ in range(m - 1):
        u, v = map(int, input().split())
        adj2[u].append(v)
        adj2[v].append(u)

    d1, r1 = tree_diameter_and_radius(adj1)
    d2, r2 = tree_diameter_and_radius(adj2)

    print(max(d1, d2, r1 + r2 + 1))

if __name__ == "__main__":
    solve()
```両方のツリーを個別に計算した後、直径は最長パスの終点によって完全に決定され、半径はそれらの終点からの BFS 距離レイヤーの交差によって決定されるという事実に依存します。 最終的な式は、これらの量を一定時間で結合します。 

実装における微妙な点は、直径の端点の BFS が 2 倍であることと、一方向だけでは偏心に対して不十分であるため、半径の計算で両方の端点の距離配列を使用することを保証することです。 

## 実用的な例

 ### サンプル

 最初の木:```
5 nodes
1-2, 1-3, 3-4, 3-5
```直径の端点を計算します`2`そして`4`(例)、直径を与える`3`。 中心はノードにあります`3`、したがって半径は`2`。 

2 番目のツリー:```
7 nodes
1-2, 1-3, 3-4, 3-5, 3-6, 7-5
```その直径は`4`、その中心にも半径があります`2`。 

| 木 | 直径 | 半径 |
 | --- | --- | --- |
 | 1 | 3 | 2 |
 | 2 | 4 | 2 |

 最終的な答え:```
max(3, 4, 2 + 2 + 1) = 5
```これはサンプル出力と一致します。

| スペース | O(n + m) | 隣接リストと距離配列 |

 制約により、最大で`2 * 10^5`合計ノード数があるため、時間制限内ではツリーごとの線形走査で十分です。
