 ## 解決策
 ## 問題の理解

 バイナリ文字列が与えられます。これは、次のものだけを含む文字のシーケンスです。`0`そして`1`。 ゼロの数が 1 の数と異なる場合、その文字列は良好であると定義されます。 タスクは、すべての部分文字列が適切になるように、元の文字列を最小数の連続する部分文字列に分割することです。 出力では、最初に部分文字列の数を記載し、次に部分文字列自体をスペースで区切って記載する必要があります。 

制約は小さく、文字列の長さです。$n$は最大 100 です。これにより、次のアルゴリズムを実行できます。$O(n^2)$線形の解決策は存在しますが、快適です。 小さなバイナリ文字列を扱っているため、複雑さは処理能力よりもロジックの分割の単純さによって支配されます。 

明らかではないエッジケースには、すでに良好な文字列や、すべての文字が同一である文字列が含まれます。 たとえば、入力が`111`または`0`、文字列自体はすでに良好であるため、部分文字列の最小数は 1 です。 逆に、次のような文字列`10`または`01`は良くないので、各文字を個別の部分文字列に分割する必要があります。 不注意な解決策では、文字列を常に 2 つの半分に分割したり、隣接する文字が異なる場合にのみ貪欲に分割しようとする可能性があり、これは失敗します。`111000`または`1000`。 

## アプローチ

 ブルートフォース手法では、文字列を可能な限り連続した部分文字列に分割し、どの組み合わせが最小限の数で適切な部分文字列のみを生成するかを確認します。 特に、指数関数的に多くの分割が存在します。$2^{n-1}$、したがって、これは実用的ではありません$n = 100$。 

重要な観察は、良好であるという性質は、次の数にのみ依存するということです。`0`そして`1`。 すべての文字が同じである場合、または完全にバランスが取れていない場合、文字列は適切です。 これにより問題が軽減されます。すでに良好な文字列はそのまま維持できます。 同じ数の完全にバランスのとれた弦のみ`0`そして`1`分割する必要があります。 バイナリ文字列の場合、これは文字列が 1 つだけで構成されているかどうかを確認することと同じです。`0`そして1つ`1`長さは 2 以上です。 したがって、実際には、文字列にまったく同じ数の 0 と 1 が含まれている場合を除き、部分文字列の最小数はほとんど常に 1 です。 その場合、文字列を 2 つの部分に分割できます。1 つは単一の文字列を含みます。`0`または`1`そして残りは、両方の部分文字列が良好であることを保証します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力文字列内の 0 と 1 の合計数を数えます。 これにより、文字列全体がすでに良好であるかどうかを判断できます。 
2. カウントが異なる場合は、文字列全体が正常であることを意味します。 出力`1`元の文字列が続きます。 
3. カウントが等しい場合は、分割する必要があります。 最も単純な戦略は、最初の文字を 1 つの部分文字列として取得し、残りを 2 番目の部分文字列として取得することです。 これにより、最初の部分文字列は 1 つの文字に対してカウント 1 を持ち、2 番目の部分文字列はいずれかのタイプの 1 文字を削除した後のカウントが等しくないため、両方の部分文字列が良好であることが保証されます。 
4. 部分文字列の数を出力します。`1`弦が良ければ、または`2`分割が必要な場合は、部分文字列を出力します。 

機能する理由: 0 と 1 のカウントを維持することで、文字列全体が良好な条件を満たしているかどうかをすぐに判断できます。 カウントが等しいときに 1 つの文字を分割すると、残りのカウントが等しくないため、結果として得られる部分文字列が良好であることが保証されます。 他の分割では生成される部分文字列の数が少なくなり、最小限性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
s = input().strip()

zeros = s.count('0')
ones = s.count('1')

if zeros != ones:
    print(1)
    print(s)
else:
    # counts are equal, split into first character and the rest
    print(2)
    print(s[0], s[1:])
```コードはまず文字列内の 0 と 1 を数えます。これは文字列が良好かどうかを判断するために必要です。 カウントが異なる場合は、文字列全体が 1 つの部分文字列として出力されます。 それ以外の場合は、最初の文字で分割されます。 の使用`s.strip()`入力から末尾の改行を確実に削除し、部分文字列を出力するときの微妙なバグを回避します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    s = input().strip()
    zeros = s.count('0')
    ones = s.count('1')
    if zeros != ones:
        return f"1\n{s}"
    else:
        return f"2\n{s[0]} {s[1:]}"

# Provided samples
assert run("1\n1\n") == "1\n1", "sample 1"
assert run("2\n10\n") == "2\n1 0", "sample 2"
assert run("6\n100011\n") == "2\n1 00011", "sample 3"

# Custom cases
assert run("3\n000\n") == "1\n000", "all zeros"
assert run("3\n111\n") == "1\n111", "all ones"
assert run("4\n0101\n") == "2\n0 101", "equal zeros and ones"
assert run("5\n00100\n") == "1\n00100", "unequal counts"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 3\n000 | 1\n000 | 同一のゼロの文字列が良い |
 | 3\n111 | 1\n111 | 同一の文字列が良い |
 | 4\n0101 | 2\n0 101 | 等しい数の 0 と 1 が分割をトリガーします。 
| 5\n00100 | 1\n00100 | カウントが等しくない場合は、単一の部分文字列が許可されます。 

## 特殊なケース

 最小限の入力`1`紐付き`1`または`0`は正しく処理されます。デフォルトではカウントが異なるため、分割は発生しません。 長さの文字列`2`次のような等しい数字で`01`または`10`2 つの部分文字列を正しく生成します。 すべて同一の文字を含む文字列。例:`000`または`111`、単一の部分文字列として返されます。 このアルゴリズムでは、すべてのシナリオで最小限の部分文字列が保証されます。これは、分割が必要となる唯一の状況はカウントが等しい場合であり、これ以上改善することはできません。
