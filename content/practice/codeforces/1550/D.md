 ## 解決策
 ## 問題の理解

 長さの配列が与えられます$n$、および各ポジション$i$整数を格納する必要があります$a_i$一定の間隔内で$[l, r]$。 2 つの制約は、有効な構成を興味深いものにするものを定義します。 

まず、配列は「良好」である必要があります。つまり、どの位置にも独自のインデックス値を格納することはできません。 それで$a_i \neq i$あらゆるポジションに。 これにより、インデックスと値の間の非常に具体的な調整が禁止されます。 

次に、スコア関数を評価します。$F(a)$、インデックスのペアの数を数えます$(i, j)$と$i < j$満足する$a_i + a_j = i + j$。 この条件は次のように書き換えることができます$(a_i - i) + (a_j - j) = 0$、これにより隠れた構造が明らかになります。$b_i = a_i - i$の場合、カウントされた各ペアはまさに反対の値のペアになります。$b_i = -b_j$。 

したがって、問題は元の値に直接関係するのではなく、シフトされた値のバランスをとることです。$b_i$間隔によって引き起こされる制約の下で$[l, r]$そして制限$b_i \neq 0$（以来$a_i \neq i$）。 

すべての有効な配列の中で、そのようなキャンセル ペアの数を最大にする配列が必要であり、その最大値に達する配列の数を数えます。 

制約は大きいです:$n$まで可能です$2 \cdot 10^5$すべてのテストケースにわたって。 これにより、二次関数は除外されます。$n$テストごとに。 平$O(n \log n)$テストごとの作業量は、合計作業量がテスト全体で直線的である場合にのみ許容されます。 すべてのペアを考慮したり、ブルートフォース割り当てを試みたりする構築は、直ちに不可能になります。 

インターバルになると微妙な難しさが現れる$[l, r]$が小さいか、ゼロ付近に偏っています。 たとえば、次の場合$r = n$の場合、多くの値がインデックスと密接に一致し、禁止された等価性が生じます。$a_i = i$非常に制限的です。 もし$l = 1$、それからすべて$a_i$は正の近似指数であり、ゼロ付近の対称性が失われ、取り消し可能なペアの数が減少します。 有効性はマルチセット構造だけでなく位置にも依存するため、インデックス依存のシフトを考慮せずに値を単純に貪欲にペアリングすると、実現可能性が損なわれます。 

## アプローチ

 重要な変革は、問題を次のようなものに移すことです。$b_i = a_i - i$空間。 このビューでは、すべての有効な配列が選択に対応します。$b_i \in [l-i, r-i]$と$b_i \neq 0$、反対のペアの数を最大化したいと考えています$(x, -x)$。 

インデックスに依存する境界を少し無視すると、最適な構造は明らかです。できるだけ多くのインデックスをペアにして、それらのインデックスが一致するようにしたいと考えています。$b$- 値は互いに負の値になります。 このような各ペアはスコアに 1 つだけ貢献しますが、各貢献が 2 つの位置を消費するため、これより優れた構成はありません。 

したがって、最大値は、反対の値のペアに分割できるインデックスの数を最大化することによって達成されます。 残ったペアになっていないインデックスは、$F(a)$したがって、問題は、制約を尊重しながらこれらのペアを選択して方向付けることができる方法が何通りあるのかという組み合わせ数え上げ問題になります。 

ブルートフォースアプローチでは、すべての有効な配列を試し、チェックします。$F(a)$、最大値に達したものをカウントします。 単一の配列を生成するだけでも指数関数的になります。なぜなら、各位置には最大で$O(n)$選択肢。 

構造的なブレークスルーは、最適なペアリング パターンが強制されることです。ペアの最大数は、互換性のある値の間隔間で一致できるインデックスの数にのみ依存します。この構造が固定されると、残りの自由度は局所的かつ乗算的になります。 

これにより、タスクが値の割り当て方法を数える作業に減り、選択された各ペアが実行可能な値の間隔がゼロの周りで対称的に重なる 2 つのインデックスを使用するようになります。 

組み合わせのコアは、可能な値ごとに次のようになります。$x > 0$、値を取得できるインデックスの数を決定します$x$そして何人取れるか$-x$を選択し、最適にペアリングします。 答えへの貢献は、各絶対値クラスにどのインデックスを割り当てるかを選択し、制約内で並べ替えることから得られます。

 ## アルゴリズムのチュートリアル

 1. 値空間をシフトされた座標に変換します。$b_i = a_i - i$。 これにより、平等性への明示的な依存が解消されます。$a_i = i$、になるので$b_i \neq 0$。 スコア条件はペアリングとなります$b_i = -b_j$、構造的にはより単純です。 
2. インデックスごとに$i$、その許容範囲を計算します。$b_i$、つまり$[l - i, r - i]$、ゼロが内側にある場合は削除します。 これにより、各ポジションがどの符号付き値に参加できるかが定義されます。 
3. 絶対値に関する実行可能な区間の構造によってインデックスをグループ化します。 重要な観察は、指定された大きさをサポートするインデックスの数のみが存在することです。$x$反対のペアの形成を最大化するために重要です。 
4. それぞれの絶対値について$x > 0$、サポートできるインデックスの数を決定します$+x$そして何人がサポートできるか$-x$。 提供されたペアの数$x$は$\min(cnt_{+x}, cnt_{-x})$、そして最大化する$F(a)$この組み合わせを貪欲に実現することを私たちに強制します$x$。 
5. 最大ペアリング構造が決まったら、インデックスを値クラスに割り当てる方法の数を計算します。 各絶対値クラスは、そのクラスに割り当てられたインデックスの順列に対応する階乗因数に寄与しますが、対称制約によって適切に分割されます。 
6. すべての独立した値クラスにわたる寄与をモジュロで乗算します。$10^9+7$。 

### なぜ効果があるのか

 変換により、目標が次の期間の独立したキャンセル イベントに分離されます。$x$そして$-x$。 有効なペアリング構成はすべて、互いに素な絶対値クラスに分解でき、クラス間の相互作用によってスコアが増加することはありません。 これにより、問題が独立した計数ブロックに分割されます。 最適な戦略は常に可能なすべてを飽和させるため、$(x, -x)$クラスごとに一致し、偏差があれば減少します$F(a)$したがって、完全な飽和構成のみがカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, l, r = map(int, input().split())

        # Shifted range analysis
        # We track how many positions can support positive/negative balances.

        pos = [0] * (n + 2)
        neg = [0] * (n + 2)

        for i in range(1, n + 1):
            lo = l - i
            hi = r - i

            if hi < 0:
                neg[min(n, -lo)] += 1
            elif lo > 0:
                pos[min(n, hi)] += 1
            else:
                # interval crosses 0: can support both sides
                pos[min(n, hi)] += 1
                neg[min(n, -lo)] += 1

        # prefix accumulation
        for i in range(1, n + 1):
            pos[i] += pos[i - 1]
            neg[i] += neg[i - 1]

        res = 1
        for i in range(1, n + 1):
            ways = max(1, pos[i] + neg[i])
            res = (res * ways) % MOD

        print(res)

if __name__ == "__main__":
    solve()
```この実装では、実現可能性が絶対的な大きさよりもプレフィックス数に圧縮されます。 各インデックスについて、シフト後にプラスまたはマイナスのバランスに寄与する可能性がある値の数を計算します。 配列`pos`そして`neg`指定された大きさのしきい値をサポートできる位置の数を集計し、乗算のカウント構造に変換します。 

乗算ステップは、大きさレベル全体にわたる独立した選択をエンコードします。 各係数は、増加する絶対値制約を処理するときに残っている有効な割り当ての数を表し、実現可能性に違反する構成を過剰にカウントしないようにします。 

これらのインデックスは正のクラスと負のクラスの両方に寄与する可能性があるため、ゼロと交差する間隔の処理方法には注意が必要です。 これが、このようなインデックスが両方とも増加する理由です。`pos`そして`neg`。

 ## 特殊なケース

 シフト後に間隔が完全に正または完全に負の場合、アルゴリズムはペアリングが不可能な片側割り当て問題に陥ります。 このような場合、すべてのインデックスは独立して動作し、キャンセル構造なしで許可された選択肢をカウントすることに貢献します。 インデックスに無効なゼロ割り当てが強制されず、実現可能性配列が符号領域を正しく分離するため、実装はこれを処理します。 

シフト後のインデックスの間隔にゼロが含まれる場合、値は$b_i = 0$は禁止されていますが、肯定的な選択肢と否定的な選択肢の両方が残されています。 これにより、最大限の柔軟性が生まれます。 アルゴリズムは、そのようなインデックスを両方に寄与するものとして扱います。`pos`そして`neg`これにより、良好なアレイ制約に違反することなく、ペアリングの両方向でカウントされるようになります。 

いつ$n$大きくて、$l$非常にネガティブですが、$r$すぐ上にあります$n$、ほぼすべての間隔がゼロと交差し、ペア構造が密になります。 このアルゴリズムは、実現可能性クラスを超えて個々のインデックスを区別しないため、$O(n^2)$集計されたカウントを通じてすべての有効なペアをキャプチャしながら、動作を監視します。
