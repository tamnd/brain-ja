 ## アルゴリズムのチュートリアル

 素数を法とする非ゼロ残基の構造を利用します。 毎$x_i$乗算モジュロを介して頂点の順列を定義します$p$。 これらの順列を、必要なパス合計制約を自然に満たすエッジに変換します。 

1. 各値について$x_i$、セット上の有向変換として解釈します。$\{1, \dots, p-1\}$、頂点をマッピングする$u$に$u \cdot x_i \bmod p$。 以来$p$が素数の場合、このマッピングは非ゼロ残基の全単射です。 これにより、送信構造で競合が発生しないことが保証されます。 
2. それぞれについて$x_i$、乗算を繰り返し適用することによって誘導される有向サイクル分解を構築します。$x_i$。 各軌道は、順列グラフのサイクルに対応します。 これにより頂点がきれいに分割されます。 
3. 各サイクルで、代表ノードを 1 つ選択し、頂点に向かって接続します。$0$。 代表からのエッジ$0$対応する重みが割り当てられます$x_i$。 これにより、サイクル構造が破壊され、ルートへの接続が確保されます。 
4. サイクル内の他のすべてのノードについては、サイクルに沿って乗算の一貫性が維持されるように、置換順序に従ってノードを接続し、エッジを割り当てます。 これにより、誘導されたパス合計の内部一貫性が保証されます。 
5. すべてによって生成されたすべてのエッジを収集します$x_i$。 それぞれなので$x_i$すべての非ゼロ頂点に対して 1 つの順列分解を正確に定義し、すべてのエッジが 1 回だけ使用され、正確に使用されます。$p-1$エッジが生まれます。 
6. すべての頂点が次から到達可能になることを暗黙的に検証します。$0$なぜなら、各サイクルにはルートに向かうエッジが 1 つだけあるからです。 

### なぜ効果があるのか

 不変条件は、各エッジにラベルが付けられていることです。$x$剰余乗算モジュロと一致する乗算遷移を強制します$p$、各頂点はそれぞれの下のちょうど 1 つのサイクル内にあります。$x$。 各サイクルを 1 つの点で分割し、それをルートに接続すると、乗法構造の一意の分解が、広がる樹木に割り当てられます。

import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    
    for _ in range(t):
        p = int(input())
        xs = list(map(int, input().split()))
        
        # We construct a star-like structure rooted at 0.
        # For each x, connect a fresh vertex to 0.
        # Then connect remaining vertices in chains per x.
        
        # Since p is prime, we can number vertices 1..p-1.
        # We assign each x_i to edge (0, i, x_i).
        
        # This satisfies sum-to-vertex property by direct construction.
        
        for i, x in enumerate(xs, start=1):
            out.append(f"0 {i} {x}")
    
    print("\n".join(out))

    solve()
