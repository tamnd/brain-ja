 ## 解決策
 ## 問題の理解

 高さの長方形のグリッドを完全にカバーできる方法が何通りあるかを数えるよう求められます。`m`そして非常に広い幅`n`1×2のドミノを使います。 各ドミノは水平方向または垂直方向に 2 つの隣接するセルを正確にカバーし、グリッドのすべてのセルは 1 回だけカバーされる必要があります。 セルを覆うドミノが 2 つのタイリング間で異なるセルが少なくとも 1 つ存在する場合、2 つのタイリングは異なるものとみなされます。 

重要な構造上の詳細は次のとおりです。`m`は非常に小さく、最大でも 6 ですが、`n`最大 10^18 までの天文学的な大きさになる可能性があります。 これにより、列を 1 つずつ線形時間で処理するアプローチは即座に除外されます。`n`, O(n) ですら不可能なので。 唯一の実行可能な方向は、問題を圧縮して、`n`対数的になるか、周期性や行列のべき乗によって完全に消去されます。 

微妙な制約は、タイリングが隣接する列間の境界の相互作用の影響を受けやすいことです。 1 つの垂直ドミノは同じ列の 2 行にまたがりますが、水平ドミノは 2 列にまたがります。つまり、ある列の状態を次の列と独立して判断することはできません。 この依存関係により、部分的な列の充填状態をモデル化する必要があります。 

エッジケースは次の場合に発生します。`m = 1`、`m = 2`、小さい`n`、構造が退化し、素朴な状態推論が誤って過大評価または過小評価する可能性があります。 

いつ`m = 1`、可能なタイリングは水平ドミノのみであるため、次の場合、答えは 1 になります。`n`偶数、それ以外の場合は 0。 垂直配置が存在すると仮定する単純な DP では、誤って無効な状態が導入されてしまいます。 

いつ`m = 2`、問題はフィボナッチのような遷移に帰着しますが、不注意な実装では、垂直ドミノが 1 つの列の両方の行を占有し、水平ドミノが制約を次の列に伝播することを忘れることがよくあります。 

大型の場合`m ≤ 6`、状態空間は指数関数的になります。`m`、ただし 2^6 = 64 なのでまだ管理可能です。 

## アプローチ

 直接的な総当たり戦略では、グリッドを列ごとに並べて、各ステップでドミノのすべての配置を試みます。 任意の時点で、現在のフロンティア内のどのセルが前の列から伸びるドミノによってすでに占有されているかを追跡します。 状態ごとに、垂直方向と水平方向の配置を使用して、残りの空のセルを埋めるあらゆる方法を再帰的に試みます。 

このアプローチは、有効なタイリングをすべて明示的に列挙するため、正しいです。 ただし、各列に最大`2^m`占有パターンと状態間の遷移には、列構成のすべてのタイリングの探索が含まれ、列構成自体が指数関数的に分岐します。`m`。 以上`n`列の場合、これはおよそ O(n × m の指数関数) 演算につながりますが、次の場合にはまったく実行不可能です。`n`10^18 に達します。 

重要な観察は、プロセスが完全な履歴ではなく、現在の列の占有パターンのみに依存するということです。 列をサイズのビットマスクとしてエンコードしたら`m`、ある列の状態から次の列の状態への遷移は固定されています。 これにより、問題は最大 64 個のノードを持つ有限有向グラフでのウォーク数のカウントに変わります。 ある列マスクから別の列マスクに移行する方法の数は、単一列に対する DFS を使用して事前に計算できます。 

この遷移グラフを作成したら、長さの数を効果的に計算することになります。`n`グラフ内を歩きます。これは標準的な行列のべき乗問題です。 隣接行列は最大 64×64 であるため、O(64^3 log n) でのべき乗は容易に実現可能です。

 ## アルゴリズムのチュートリアル

 グリッドを列ごとに処理し、次のサイズのビットマスクを使用して各列境界で「保留中のドミノの形状」をエンコードします。`m`。 ビットが 1 に設定されている場合は、セルが前の列からの水平ドミノによってすでに占有されていることを意味します。 

まず、マスク間の有効な遷移をすべて計算します。 マスクからの移行`a`マスクする`b`意味：すでに満たされているいくつかのセルから開始します`a`、垂直ドミノと水平配置を使用して現在の列を完全に埋めることができ、次の列の占有を正確に生成します。`b`。 

遷移を計算するには、単一列の行に対して DFS を実行します。 

1. マスクからスタート`a`現在の列の事前に入力されたセルと空の次のマスクを表します。`b`。 行を上から下にスキャンし、常に最初の未入力の行を選択します。 
2. 現在の行がすでに入力されている場合`a`、次の行に移動します。 これは、セルが前の列からのドミノによってすでに占有されていることを反映しています。 
3. 現在の行が埋まっていない場合は、現在の列内に垂直ドミノを配置して、このセルと次の行のセルを埋めてみます。 これは、次の行が存在し、それも入力されていない場合にのみ機能します。`a`。 この選択は、次の列マスクには影響しません。 
4. また、現在のセルを占有し、次の列に広がる水平ドミノを配置してみます。 これは、対応するビットをマークします。`b`、次の列のセルが事前に入力されているためです。 
5. すべての行が処理されて列の終わりに到達すると、からの有効な遷移が記録されます。`a`に`b`。 

これにより、遷移行列が得られます。`T`サイズの`S × S`どこ`S = 2^m`。 

遷移が構築されると、各列はこの変換を状態ベクトルに適用するものとして解釈されます。 最初は、最初の列には入ってくる水平ドミノがないため、開始状態はマスク 0 です。処理後`n`ドミノがグリッドの境界を越えて拡張できないため、列をマスク 0 に戻します。 

次に計算します`T^n`2 進累乗を使用して、状態 0 から状態 0 までエントリを読み取ります。 

### なぜ効果があるのか

 すべてのタイリングは、各境界でどのセルがすでに占有されているかを示す一連の列状態に一意に分解できます。 DFS は、特定の境界条件と一致するすべての局所充填を正確に列挙するため、遷移行列はすべての有効な列間の展開を捕捉します。 状態はタイリングの拡張に必要なすべての情報を完全にキャプチャするため、将来の選択に影響を与える形で 2 つの異なる履歴が同じ状態にマージされることはなく、ビットマスク上の DP マルコフ行列が作成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mat_mul(A, B):
    n = len(A)
    res = [[0] * n for _ in range(n)]
    for i in range(n):
        Ai = A[i]
        Ri = res[i]
        for k in range(n):
            if Ai[k]:
                aik = Ai[k]
                Bk = B[k]
                for j in range(n):
                    Ri[j] = (Ri[j] + aik * Bk[j]) % MOD
    return res

def mat_pow(M, e):
    n = len(M)
    res = [[0] * n for _ in range(n)]
    for i in range(n):
        res[i][i] = 1
    base = M
    while e > 0:
        if e & 1:
            res = mat_mul(res, base)
        base = mat_mul(base, base)
        e >>= 1
    return res

def build_transitions(m):
    S = 1 << m
    trans = [[0] * S for _ in range(S)]

    def dfs(row, cur_mask, next_mask, m):
        if row == m:
            trans[cur_mask][next_mask] += 1
            return

        if cur_mask & (1 << row):
            dfs(row + 1, cur_mask, next_mask, m)
            return

        if row + 1 < m and not (cur_mask & (1 << (row + 1))):
            dfs(row + 2, cur_mask, next_mask, m)

        dfs(row + 1, cur_mask, next_mask | (1 << row), m)

    for mask in range(S):
        dfs(0, mask, 0, m)

    return trans

def solve():
    m, n = map(int, input().split())
    trans = build_transitions(m)
    Tn = mat_pow(trans, n)
    print(Tn[0][0] % MOD)

if __name__ == "__main__":
    solve()
```ソリューションの中核はトランジション ビルダーです。 開始マスクを修正し、結果の次のマスクを生成しながら 1 つの列を合法的に埋めるためのすべての方法を列挙します。 再帰では、事前に入力されたセルをスキップするか、垂直方向のドミノを配置するか、次の状態に寄与する水平方向のドミノを配置することにより、すべてのセルが 1 回だけ使用されることが慎重に保証されます。 

行列のべき乗によってこれらの列遷移が構成されます。`n`回。 ID の初期化により、列を処理する前はクリーンな空の境界状態にあり、処理後は正確に空の境界状態にあることが保証されます。`n`有効な完全なタイルを作成するには、空に戻す必要があるステップ。 

微妙な点は、乗算の順序が重要であるということです。`mat_mul`これは、遷移を通じて暗黙的に進化する行ベクトルを扱っているためです。 この実装は、状態遷移行列に適用される標準行列乗として記述されます。
