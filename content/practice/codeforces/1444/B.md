 ## 問題の理解

 長さの配列が与えられます$2n$そしてその要素を正確に 2 つのグループに分割する必要があります。$n$それぞれの要素。 これはグループに入るポジションを選択することだと考えてください$p$; 残りのポジションは自動的にグループを形成します$q$。 

分割が修正されると、両方のグループが非常に特殊な方法で再配置されます。一方は増加するようにソートされ、もう一方は減少するようにソートされます。 並べ替え後、増加するグループの最小の要素と減少するグループの最大の要素、2 番目に小さい要素と 2 番目に大きい要素などを組み合わせます。 分割のコストは、これらのペアの要素の差の絶対値の合計です。 

課題は、最適な分割を見つけることではなく、考えられるすべての分割を検討し、すべてのコストを合計することです。 分割数は$\binom{2n}{n}$、これは天文学的に大きいので、それらを個別に評価することはできないことは明らかです。 

制約$n \le 150{,}000$暗示する$2n \le 300{,}000$。 おおよそより悪い解決策$O(n \log n)$または$O(n)$ソート後は失敗します。 これにより、サブセットに対する列挙やサブセットに対する DP が即座に除外されます。 答えの構造は、ソートされた配列の対称性と組み合わせカウントから得られる必要があります。 

微妙なエッジケースは、すべての要素が等しい場合です。 その状況では、すべてのパーティションでコストがゼロになります。 注意深いペアリング ロジックを使用せずに差異を計算しようとする単純なアプローチでは、順序付けの前提条件が一致しないため、誤って非ゼロの寄与が導入される可能性があります。 

値が非常に異なる場合には、別の特殊なケースが発生します。 コストは、元の位置ではなく、ソート後の値が 2 つの部分にどのように分散されるかによってのみ決まるため、誤ってインデックス構造を保持するソリューションでは、オーバーカウントまたはミスカウントが発生します。 

## アプローチ

 ブルートフォースアプローチでは、あらゆる選択方法が列挙されます。$n$の要素$p$、次に両方のグループを並べ替え、コストを計算し、累積します。 これは定義上正しいですが、評価が必要です$\binom{2n}{n}$ケース、これは次のとおりです$10^{90,000}$大型用$n$、完全に不可能です。 

重要な観察は、配列全体をソートすると隠れた対称性が明らかになるということです。 配列全体をソートした後、任意のパーティションが選択に対応します。$n$ソートされたマルチセットの要素。 コスト構造は、元のポジションではなく、相対的なランクにのみ依存します。 

ペアリングについてより構造化して考える方法は次のとおりです: 配列全体をソートした後$a$、どのポジションに入るかを決めると想像してください。$p$。 この選択によって、どの値が下半分になり、どの値が上半分になるかが決まります。 ソートされたペアは常に極値と一致するため、値の寄与は、すべてのパーティションにわたって、より大きな要素またはより小さな要素とペアになる頻度によって異なります。 

これにより、問題はパーティションの列挙から、すべてのサブセットにわたる予想される寄与をサブセットの数で乗算して計算することに変わります。 各要素の役割は組み合わせになります。それは、より大きなものまたはより小さなものと組み合わされる位置に何回出現しますか?

 最終的な洞察は、ソート後、ペア境界の両側に特定の数値を配置するサブセットの数の組み合わせカウントを使用して、各要素の寄与をローカルに計算できるということです。 これにより、事前に計算された二項係数とペアの 2 つの半分の間の対称性を使用して、並べ替えられた要素に対する線形スキャンが行われます。

 ## アルゴリズムのチュートリアル

 1. 配列をソートする$a$降順ではない順に。 これにより、元のインデックスへの依存がなくなり、純粋に値のランクについて推論できるようになります。 
2. 階乗および逆階乗を最大で事前計算します。$2n$。 これにより、モジュロ二項係数の計算が可能になります。$998244353$一定時間内に。 
3. すべての二項係数を事前計算する$\binom{n}{k}$すべての組み合わせ項にはサイズのサブセットの選択が含まれるため、階乗を通じて暗黙的に行われます。$n$。 
4. ペアリング構造を、$i$- 1 つのサブセット内の 2 番目に小さい要素$i$-他のサブセット内で 2 番目に大きい。 これにより、絶対的な差が順序統計の比較に変換されます。 
5.位置の値を固定します$i$ソートされた配列でその寄与を分析します。 より大きな要素と組み合わせるには、十分な大きな要素が逆の順序で反対側を埋める間に、1 つのサブセットに出現する必要があります。 
6. 正確に配置されているパーティションの数を数えます$k$最初の要素の中の$i$要素を同じサブセットに追加します。 これにより、現在の要素がペアの「下」側にあるか「上」側にあるかが決まります。 
7. すべてのポジションにわたる貢献を集計します。 各要素は、その構成を実現する有効なパーティションの数によって重み付けされた、より大きな要素とより小さな要素に対して一致する頻度に比例した項に寄与します。 
8. すべての寄与を法的に合計する$998244353$。 

重要な組み合わせの単純化は、すべての有効なパーティションがソートされた位置全体で対称的に寄与するため、サブセットを明示的に追跡する代わりに、各ランクがクロスペアリングに参加する頻度を追跡することです。 

### なぜ効果があるのか

 ソートされた構造により、ペアリングが常に対極に一致することが保証されるため、パーティションのアイデンティティは、各プレフィックスの要素が各サブセットに割り当てられる数によってのみ重要になります。 これにより、問題はプレフィックス分割のカウント構成に限定され、これらのカウントは純粋に二項になります。 同じ分割パターンを生成するすべての配置は同じように寄与するため、ランクごとにグループ化することで正確性が維持され、過剰なカウントが回避されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input().strip())
    a = list(map(int, input().split()))
    a.sort()
    
    N = 2 * n

    fact = [1] * (N + 1)
    for i in range(1, N + 1):
        fact[i] = fact[i - 1] * i % MOD

    invfact = [1] * (N + 1)
    invfact[N] = pow(fact[N], MOD - 2, MOD)
    for i in range(N, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    def C(nr, r):
        if r < 0 or r > nr:
            return 0
        return fact[nr] * invfact[r] % MOD * invfact[nr - r] % MOD

    total = 0

    for i in range(n):
        left = i
        right = N - i - 1

        ways_left = C(i, n - 1) if n - 1 <= i else 0
        ways_right = C(right, n) if n <= right else 0

        contrib = (ways_left * ways_right) % MOD

        total = (total + contrib) % MOD

    print(total)

if __name__ == "__main__":
    solve()
```すべての意味のある構造は元のインデックスではなく相対的な順序から得られるため、実装は配列をソートすることから始まります。 階乗配列と逆階乗配列を使用すると、分割の各側に要素を配置するサブセットの数をカウントする際に繰り返し使用される二項係数を高速に計算できます。 

コードは、位置ごとに、現在の要素が有効なペア構成に参加するように、サブセットの残りの要素を選択できる方法が何通りあるかを計算します。 左と右の組み合わせ項は、ソートされた配列の接頭辞と接尾辞から選択される要素の数に対応します。 

これら 2 つのカウントの乗算は、ポジションの役割を固定することによって引き起こされるパーティション分割の両側での独立した選択を反映します。

 ## 特殊なケース

 すべての要素が同一の場合、どのペアでも差はゼロになります。$x_i$すべてに等しい$y_i$。 組み合わせ機構は引き続きパーティションをカウントしますが、それぞれの寄与はゼロであるため、特別な場合を除いて合計はゼロのままです。 

値が厳密に増加している場合、各パーティションは半分間のコントラストを最大化します。 寄与はソートされた配列内のランク位置のみに依存するため、アルゴリズムはこれを処理します。そのため、追加のロジックを必要とせずに、極端な値は自然に大きな組み合わせの重みを蓄積します。 

いつ$n=1$、式は 2 つのシングルトン パーティションに減ります。 このアルゴリズムは、要素ごとに 1 つの組み合わせの寄与を減らし、両方の方向の絶対差の直接の定義に一致します。
