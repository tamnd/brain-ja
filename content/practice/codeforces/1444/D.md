 ## 解決策
 ## 問題の理解

 この問題では、すべてのセグメントが水平または垂直であり、水平セグメントと垂直セグメントが交互になる 2D 平面上に閉じたポリラインを再構築するように求められます。 水平セグメントは厳密に x 軸に沿って移動し、垂直セグメントは厳密に y 軸に沿って移動します。 水平セグメントと垂直セグメントの長さは与えられますが、その順序や方向は与えられません。 同じ点で始まり同じ点で終わるポリラインの頂点の座標を生成するか、それが不可能であると判断する必要があります。 

主な制約は、ポリラインが閉じている必要があり、共有端点を越える自己交差を含めないことです。 これは、右への水平移動の合計は左への合計と等しく、上への垂直移動の合計は下への合計と等しくなる必要があることを意味します。 ポリラインは水平セグメント間で交互に配置されるため、水平セグメントの総数は垂直セグメントの総数と最大 1 だけ異なることがあります。 

入力サイズは中程度です。すべてのテスト ケースにわたるセグメントの合計数は最大 1000 です。これにより、O(n log n) の並べ替えベースの戦略を快適に検討できます。 エッジ ケースには、すべての水平セグメントが垂直セグメントよりも長い、または 1 つの水平セグメントと 1 つの垂直セグメントがあることが含まれます。これは、ポリラインを閉じるために両方の長さが等しい場合にのみ可能です。 

階乗増加が膨大であるため、セグメントの長さのすべての順列を試す単純なアプローチは実行不可能です。 さらに、方向を不用意に割り当てると単純でないポリラインが簡単に作成される可能性があるため、セグメントが不適切に重なり合うことなくポリラインが開始点に戻るような方向を割り当てるための系統的なアプローチが必要です。 

## アプローチ

 強引な方法では、水平セグメントと垂直セグメントのすべての順列を生成し、すべての可能な方向 (水平の場合は左/右、垂直の場合は上/下) を割り当て、ポリラインが禁止された交差なしで閉じているかどうかを確認します。 これは明らかにセグメント数が指数関数的であり、並べ替えの数が h! であるため、20 セグメントの場合でも非現実的になります。 *v! 方向の割り当ての数は 2^(h+v) です。 

より迅速なアプローチのための重要な洞察は、問題が全体の水平方向と垂直方向の動きのバランスにあることを認識することです。 各水平セグメントには、他のセグメントとは独立して方向を割り当てることができ、垂直セグメントについても同様です。 したがって、水平セグメントを等しい合計の 2 つのグループに分割し、垂直セグメントを等しい合計の 2 つのグループに分割するだけで済みます。 両方の分割が可能であれば、セグメントを「ジグザグ」に交互に配置することで単純な閉じたポリラインを構築できます。 

分割できたら、セグメントを並べ替えて、正と負のオフセットを交互に一貫した方向に割り当てることができます。 セグメント自体は、合計のバランスが取れている限り、閉包特性を満たすように任意に再配置できます。 これにより、問題は結合合計分割問題に帰着しますが、セグメント数の合計が小さい (≤ 1000) ため、これは実現可能です。 セグメントを並べ替えて代入を交互に行う貪欲な方法を使用すると、ポリラインが単純なままになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(h! * v! * 2^(h+v)) | O(h+v) | 遅すぎる |
 | バランスの取れたジグザグ構造 | O(h log h + v log v) | O(h+v) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 各テスト ケースについて、水平セグメントと垂直セグメントの長さのリストを読み取ります。 水平セグメントの合計と垂直セグメントの合計を計算します。 
2. 水平セグメントを等しい合計の 2 つのグループに分割し、垂直セグメントを等しい合計の 2 つのグループに分割できるかどうかを確認します。 水平セグメントまたは垂直セグメントの数が奇数の場合は、1 つのグループが中央セグメントの長さだけ大きくなるようにします。 
3. 水平セグメントを降順に並べ替えます。 これらを正と負の x 方向の動きを表す 2 つのグループに交互に割り当てます。 垂直セグメントについても同様に繰り返し、正と負の y 方向に割り当てます。 
4. 開始点を (0, 0) に初期化します。 割り当ての順序で水平セグメントをトラバースし、グループ (左または右) に従って各水平セグメントを X 座標に追加します。 水平方向に移動するたびに、垂直グループに従って垂直セグメントを対応する方向 (上または下) に移動します。 
5. 水平セグメントと垂直セグメントを交互に追加し続け、新しい座標をポリラインの頂点として追加します。 
6. すべてのセグメントを処理した後、最終座標が開始座標 (0, 0) と一致することを確認します。 そうでない場合、ポリラインは不可能です。 それ以外の場合は、座標のシーケンスを出力します。 

機能する理由: セグメントを 2 つの等和グループに割り当てると、水平方向の動きと垂直方向の動きが確実に相殺され、ポリラインが確実に閉じます。 割り当てを並べ替えて交互に行うことで、エンドポイントを超えた重複を防ぎ、シンプルさを維持します。 不変条件は、開始点と終了点を除き、すべてのステップでポリラインが一意の座標にあることです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        h = int(input())
        H = list(map(int, input().split()))
        v = int(input())
        V = list(map(int, input().split()))
        if _ != t-1:
            input()  # skip blank line
        
        H.sort(reverse=True)
        V.sort(reverse=True)
        
        if abs(h - v) > 1:
            print("No")
            continue
        
        x_pos, x_neg = [], []
        y_pos, y_neg = [], []
        
        for i, val in enumerate(H):
            if i % 2 == 0:
                x_pos.append(val)
            else:
                x_neg.append(val)
        for i, val in enumerate(V):
            if i % 2 == 0:
                y_pos.append(val)
            else:
                y_neg.append(val)
        
        xs = [0]
        ys = [0]
        for a, b in zip(x_pos + [0]*(len(x_neg)-len(x_pos)), x_neg + [0]*(len(x_pos)-len(x_neg))):
            xs.append(xs[-1]+a)
            xs.append(xs[-1]-b)
        for a, b in zip(y_pos + [0]*(len(y_neg)-len(y_pos)), y_neg + [0]*(len(y_pos)-len(y_neg))):
            ys.append(ys[-1]+a)
            ys.append(ys[-1]-b)
        
        if xs[-1] != 0 or ys[-1] != 0:
            print("No")
            continue
        
        # Construct coordinates
        coords = [(0,0)]
        xi, yi = 0, 0
        hx = x_pos + x_neg[::-1]
        vy = y_pos + y_neg[::-1]
        for i in range(len(H)):
            if i < len(hx):
                xi += hx[i]
            coords.append((xi, yi))
            if i < len(vy):
                yi += vy[i]
            coords.append((xi, yi))
        print("Yes")
        for x, y in coords[:-1]:
            print(x, y)

if __name__ == "__main__":
    solve()
```この解決策では、まず水平方向と垂直方向の動きのバランスをとります。 並べ替えにより、より大きなセグメントが最初に使用されるようになり、自己交差する可能性のある狭いループが防止されます。 移動のキャンセルを保証するために、割り当てを交互に行います。 座標は累積加算によって生成され、最終的には閉じられることが保証されます。
