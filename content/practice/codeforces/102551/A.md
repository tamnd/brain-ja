 ## 問題の理解

 タスクは、3 つの長方形のアーティファクトを長方形のはしけに配置することです。 各アーティファクトの辺の長さは固定されていますが、すべてのアーティファクトは 90 度回転できます。 アーティファクトはバージ内で重なり合ってはならず、その側面はバージの側面と平行のままでなければなりません。 目標は、3 つのアーティファクトすべてを含めることができるバージの可能な限り小さな領域を見つけることです。 

入力は、3 つのアーティファクトのそれぞれの幅と高さで構成されます。 出力は、適切な回転と位置を選択した後にそれらを含むことができる長方形の最小領域です。 

関係する長方形は 3 つだけなので、解決策はオブジェクトの数によって制限されません。 重要な制約は、辺の長さの制限です。$10^4$。 Trying every possible position of the rectangles on a grid would require billions of checks and is impossible. The useful observation is that with three rectangles, the number of possible relative layouts is very small. We only need to enumerate the meaningful geometric arrangements.

 A common mistake is to check only one orientation of the rectangles. たとえば、辺のある長方形$2 \times 10$そしてもう一つは側面付き$5 \times 5$最適なパッキングを実現するには、最初のものを回転させる必要がある場合があります。 

もう 1 つの特殊なケースは、すべての長方形が単純な行には収まるが、より複雑な配置には収まらない場合です。 例えば：```
1 2
3 4
5 6
```最適な配置は、単純に 3 つすべてを縦に配置して、幅を持たせることです。$5$と高さ$6$、面積あり$30$。 水平方向の配置のみをチェックするソリューションでは、この問題を見逃してしまいます。 

2 番目のエッジ ケースは、1 つの長方形を他の 2 つの長方形に対して分割することで最適な答えが得られる場合です。```
4 10
3 6
3 4
```最初の長方形は他の 2 つの長方形の上に立つことができます。 結果として得られる長方形には幅があります$6$と高さ$14$、エリアを与える$84$。 3 つすべてを 1 行に配置することのみをチェックするソリューションでは、より大きな答えが得られます。 

## アプローチ

 直接的な総当たりのアイデアは、十分に大きな境界ボックス内のすべての四角形のすべての可能な位置を試すことです。 座標は入力次元と同じくらい大きくなる可能性があるため、このアプローチはすぐに実行不可能になります。 たった 3 つの長方形であっても、それぞれの可能な座標をスキャンすると、それらの可能な位置の積に比例した検索空間が作成されます。 

重要な観察は、最適なパッキングにおいて、軸が整列した 3 つの長方形には可能な関係がわずかしかないということです。 長方形は別の長方形と一辺を共有するか、複数の長方形が行または列を形成します。 不要な空のギャップを削除して、それを含む長方形を小さくすることができるため、最適なソリューションは常にこれらのコンパクトなレイアウトのいずれかに属します。 

このソリューションは、3 つのアーティファクトのすべての回転とすべての次数を列挙します。 固定された向きと順序ごとに、長方形を行と列に分割できる方法をチェックします。 しかないので、$3! \times 2^3$方向と順序の選択の場合、この徹底的な検索は定数時間で行われます。

 ## アルゴリズムのチュートリアル

 1. 3 つの長方形を読み取り、各長方形の可能なすべての回転を生成します。 
2. 回転のあらゆる組み合わせについて、3 つの長方形のあらゆる順序を試してください。 これにより、どのアーティファクトがレイアウト内でどの役割を占めるかを推測する必要がなくなります。 
3. 現在の 3 つの方向を向いた長方形について、考えられるすべての外接する長方形を計算します。 市松模様は、1 行に 3 つの長方形、1 列に 3 つの長方形、および 1 つの長方形が他の 2 つの長方形から分離されているすべての場合です。 
4. 生成されたすべての外接四角形の中で最小の面積を使用して答えを更新します。 

これがすべての最適な配置をカバーする理由は、たった 3 つの長方形があれば、どんなコンパクトな梱包でも縦線または横線で小さなグループに分割できるためです。 これらのグループには 1 つの四角形または 2 つの四角形が含まれており、まさに列挙されているケースが当てはまります。 

機能する理由: このアルゴリズムは、3 つの長方形のあらゆる可能な回転とあらゆる構造的な配置を考慮します。 すべての最適なパッキングはこれらの構造パターンのいずれかに属している必要があるため、列挙によって見つかった最小面積はまさに可能な最小バージ面積です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from itertools import permutations, product

def solve():
    rects = []
    for _ in range(3):
        a, b = map(int, input().split())
        rects.append((a, b))

    ans = 10**30

    def add(w, h):
        nonlocal ans
        ans = min(ans, w * h)

    for order in permutations(range(3)):
        for rotations in product([0, 1], repeat=3):
            r = []
            for idx, rot in zip(order, rotations):
                a, b = rects[idx]
                if rot:
                    a, b = b, a
                r.append((a, b))

            a, b = r[0]
            c, d = r[1]
            e, f = r[2]

            add(a + c + e, max(b, d, f))
            add(max(a, c, e), b + d + f)

            add(max(a, c + e), b + max(d, f))
            add(max(a, c, e), b + d + f)

            add(max(a, c + e), b + max(d, f))
            add(max(a + c, e), max(b, d) + f)

            add(max(a + e, c), max(b, f) + d)
            add(max(a + c, e), max(b, d) + f)

    print(ans)

if __name__ == "__main__":
    solve()
```コードは最初に 3 つのアーティファクトを保存します。 可能な順序とローテーションの選択肢が 8 つしかないため、ネストされた列挙は小さくなります。 

生成された構成ごとに、コードは外接する四角形の候補を計算します。 最初の 2 つの式は、完全な行または列に対応します。 残りの式は、他の 2 つによって形成されるグループに対して 1 つの長方形を配置することを表します。 

すべての計算には Python 整数が使用されるため、オーバーフローのリスクはありません。 答えは非常に大きな値で始まり、より小さい有効な領域が見つかるたびに置き換えられます。 

主な実装の詳細は、回転がジオメトリ式内で処理されるのではなく、明示的に生成されることです。 これにより、レイアウトのチェックが簡素化され、向きの変更によって発生するケースの欠落が回避されます。

 ## 特殊なケース

 すべての長方形が正方形の場合、回転しても何も変わりません。 例えば：```
1 1
1 1
1 1
```アルゴリズムは依然として回転を列挙しますが、生成されたすべての状態は同等です。 それは正しく見つけます$1 \times 3$エリアを使った配置`3`。 

薄い長方形を回転する必要がある場合、回転を無視すると間違った答えが得られます。 のために：```

1 10
10 10
```最初の 2 つの長方形を正方形の横に垂直に配置すると、$20 \times 10$面積のある長方形`200`。 列挙にはこの方向が含まれており、元の入力方向によってトラップされません。

```アルゴリズムは 1 つのアーティファクトを他の 2 つに対して配置し、領域を取得できます。`144`一方、行のみのソリューションでは、この小さな四角形が見落とされます。
