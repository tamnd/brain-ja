 ## 解決策
 ## 問題の理解

 私たちは、木を模した寮で眠っている学生から音楽を分離するように求められます。 各頂点は部屋を表し、次のタイプの生徒が 1 人含まれます。`P`(パーティー)、`S`（寝ている）、または`C`（気ままに）。 パーティーに興じる学生たちの音楽は、広がりを阻止するために端に厚い壁を置かない限り、木を通して伝わります。 私たちの目標は、厚い壁をできるだけ少なく配置して、すべての`P`学生は音楽を演奏できますが、できません`S`学生がそれを聞きます。 入力は、頂点 2 ～ n の親参照と文字列としてのスチューデント タイプを使用したコンパクトなツリー エンコーディングを提供します。 

この制約により、n はテスト ケースごとに最大 10^5 にすることができ、すべてのテスト ケースにわたる n の合計が 10^5 を超えないことがわかります。 それぞれの間のすべてのパスを検査する単純なソリューション`P`そしてそれぞれ`S`最悪の場合、O(n^2) の操作が必要になりますが、これでは遅すぎます。 テスト ケースごとに O(n) または O(n log n) のソリューションが必要です。 

エッジケースには、生徒全員がパーティーをしたり寝たりする木々が含まれます。`P`すべての根幹にある`S`葉、または複数のクラスター`P`そして`S`のんきな生徒たちに引き離される。 隣接することのみを前提とした軽率なアプローチ`P`-`S`紛争は壁を過小評価するでしょう。 たとえば、木の中で`1-P, 2-C, 3-S`エッジ 1-2、2-3 の場合、1-2 または 2-3 のいずれかに壁が必要なので、正解は 1 です。 を無視して`C`頂点が壁を生成しない可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、各パスからのすべてのパスがチェックされます。`P`あらゆる人に`S`パスが交差する場所に壁を配置します。これは原理的には正しいですが、実行不可能です。 各パスは O(n) である可能性があり、そのようなパスが O(n^2) 個存在する可能性があるため、合計操作は O(n^3) になります。 

重要な洞察は、音楽がサブツリーに沿って流れるということです。 事後探索を実行して、サブツリーごとに、パーティーをしている生徒、寝ている生徒、またはその両方が含まれているかどうかを計算すると、両方を含むサブツリーを接続するエッジに壁を配置できます。`P`そして`S`その親に。 このボトムアップを行うことで、競合が発生する端にのみ壁を配置し、必要以上に壁を配置しないようにします。 

この観察により、問題はツリーごとに 1 つの DFS に縮小され、解決策は O(n) になります。 木の構造により、一度エッジを切ると、そこからすべての音楽が取り出されることが保証されます。`P`そのサブツリー内の学生は含まれており、どの学生にも到達できません`S`サブツリーの外側。 のんきな学生は音楽を広めたりブロックしたりしないため、この計算には影響しません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n^2) | 遅すぎる |
 | DFS サブツリー分析 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力を読み取り、隣接リストを使用してツリーを構築します。 各頂点は、親配列に基づいて子を格納します。 
2. 再帰関数を定義する`dfs(node)`これは 2 つのフラグを返します: サブツリーのルートが`node`が含まれています`P`学生と、それに含まれているかどうか`S`学生。 
3. カウンタの初期化`walls = 0`。 
4. で`dfs(node)`、再帰的に呼び出します`dfs(child)`それぞれの子供たちにとって。 を集計します。`P`そして`S`現在のノードのタイプを持つ子からのフラグ。 
5. 両方とも`P`そして`S`子サブツリーに存在する場合、増分`walls`そしてその子の考えを広めないでください`P`または`S`すでに壁で区切られているため、親にフラグを立てます。 
6. すべての子を処理した後、このノードのサブツリーにまだ何かが含まれているかどうかを親に戻します。`P`または`S`まだ壁で区切られていません。 
7. DFS が完了したら、合計を出力します。`walls`テストケースのカウント。 

機能する理由: 壁は、サブツリーを接続するエッジにのみ配置されます。`P`そして`S`存在する。 壁が設置されると、そのサブツリーからの音楽は外部に到達できなくなります。`S`、いいえ`S`そのサブツリーでは外から音楽が聞こえます。 ポストオーダートラバーサルでは、すべての競合がリーフアップから解決されることが保証され、壁の数が最小限に抑えられます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(200000)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        s = input().strip()
        tree = [[] for _ in range(n)]
        for i, p in enumerate(a):
            tree[p-1].append(i+1)
        walls = 0

        def dfs(u):
            nonlocal walls
            has_p = s[u] == 'P'
            has_s = s[u] == 'S'
            for v in tree[u]:
                child_p, child_s = dfs(v)
                if child_p and child_s:
                    walls += 1
                else:
                    has_p |= child_p
                    has_s |= child_s
            return has_p, has_s

        dfs(0)
        print(walls)

if __name__ == "__main__":
    solve()
```コードは親配列を読み取り、隣接リストとしてツリーを構築します。 DFS は、どのサブツリーが含まれているかを追跡します。`P`または`S`学生たち。 重要な微妙な点は、壁が配置されたときに伝播を停止することです。そうでないと、過大カウントまたは過小カウントされてしまいます。 また、深いツリーを安全に処理するために再帰制限を増やします。

 ## 特殊なケース

 一本の木`P`ルートと複数の`S`DFS が伝播するため、葉で処理されます`P`そして`S`フラグを上向きにします。 両方のフラグが子エッジで出会うと、壁が追加され、伝播が停止します。 たとえば、入力`4\n1 2 2\nPSSS`ルートから子 2 までのエッジに 1 つの壁が生成され、単一の壁が正しく分離されます。`P`全員から`S`。 これにより、深いサブツリーと複数のリーフが過少カウントを引き起こさないことが確認されます。
