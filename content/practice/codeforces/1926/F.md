 ## 解決策
 ## 問題の理解

 固定のものがあります$7 \times 7$セルが黒または白のボード。 4 つの斜めの隣接セルも黒である黒セルが存在する場合、構成は不良であると見なされます。 このようなパターンは、そのセルを中心とした X のように見えます。 

任意のセルを反転して、黒を白に、または白を黒に変えることができます。 目標は、ボード上のどこにも悪い X が残らないように、最小限の回数のフリップを実行することです。 

問題の最も顕著な部分は、基板のサイズが小さいことです。 あ$7 \times 7$グリッドには 49 個のセルしか含まれていませんが、$2^{49}$可能性のある色付けでは、依然として無制限の総当たり攻撃は不可能です。 テスト ケースの数は 200 に達する可能性があるため、ソリューションではすべてのボード状態を検索するのではなく、何らかの特別な構造を利用する必要があります。 

不正な X は、斜めに隣接するセルが 4 つあるセルの中心にのみ配置できます。 まさにそれらは、$5 \times 5$内部細胞。 可能な中心は 25 個だけです。 

ジオメトリ内に隠されている重要な制約はパリティです。 すべての対角線方向の移動では、次のパリティが維持されます。$r+c$。 X の中心と 4 つの斜めの隣すべては、常に同じ市松模様のカラー クラスに属します。 これにより、ボードが 2 つの完全に独立したセルのセットに分割されます。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

単一の孤立した X を考えてみましょう。```
.......
.B.B...
..B....
.B.B...
.......
.......
.......
```1回のフリップで十分です。 中心を反転すると X がすぐに破壊されます。 周囲の複数のセルを反転する貪欲な戦略は最適とは言えません。 

もう 1 つの微妙なケースは、X パターンの重複です。```
.......
.B.B.B.
..B.B..
.B.B.B.
..B.B..
.B.B.B.
.......
```1 つのセルが複数の不良 X パターンに同時に関与する可能性があります。 1 回の反転で多くの違反を除去できるため、各違反を個別に処理すると、過剰にカウントされる可能性があります。 

3 番目のトラップは、現在黒のセルのみが変更されるべきであると仮定することです。 最適化問題により、白いセルを黒に反転することもできます。 実際には、最適なソリューションでは新しい違反を意図的に作成する必要はありませんが、DP の定式化では、脆弱な貪欲なルールに依存するのではなく、すべての可能性を正しく検索する必要があります。 

## アプローチ

 最も直接的なアイデアは、すべてのセルをバイナリ変数として表示し、セルのすべてのサブセットを反転してみることです。 がある$2^{49}$可能性、それは周りにあります$5.6 \times 10^{14}$。 1 秒あたり 100 万の州をチェックするだけでも何年もかかります。 

次の観察は、違反には同じパリティのセルのみが関与するということです。 チェス盤のようにボードに色を付けると、すべての X パターンは完全に 1 つのカラー クラス内に収まります。 

パリティクラス$(r+c)\bmod 2=0$25個のセルが含まれています。 もう 1 つのクラスには 24 個のセルが含まれます。 2 つのクラスが相互作用することはありません。 

次に、パリティ クラスを 1 つだけ見てみましょう。 考えられるすべての X 中心は、それ自体がそのクラスのセルです。 1 つのパリティ クラスには最大 13 のセンターがあり、もう 1 つのパリティ クラスには最大 12 のセンターがあります。 

すべての反転後にパリティ クラスのどのセルが黒になるかを決定するとします。 すべてのセンターについて、禁止された X が存在するかどうかをすぐに確認できます。 

重要な観察は、1 つのパリティ クラスのセルが 1 つのパリティ クラスを形成していることです。$5 \times 5$斜めの接続から見ると格子状になります。 すべての制約には、中心とその 4 つの隣接格子のみが含まれます。 

1 つのパリティ クラスには関連するセルが 13 個しかないため、そのクラスの完全な最終的な色付けを最大 13 サイズのビットマスクで表すことができます。$2^{13}=8192$州。 

パリティ クラスごとに、考えられるすべての最終マスクを列挙します。 マスクの中心が禁止された X を形成しない場合、マスクは有効です。マスクのコストは、元のボードと異なるビット数です。 有効なマスクの中で最低限のコストを保ちます。 

2 つのパリティ クラスは独立しているため、最適コストは単純に加算されます。 

作業全体はごくわずかです。$$2^{13}+2^{12}=12288$$テスト ケースごとに状態を設定し、状態ごとに少量の一定量のチェックのみを行います。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 49 セルすべてに対するブルート フォース |$O(2^{49})$|$O(1)$| 遅すぎる |
 | パリティ クラスを個別に列挙する |$O(2^{13}+2^{12})$|$O(2^{13})$| 承認済み |

 ## アルゴリズムのチュートリアル

 ### パリティグループの構築

 禁止されたパターンは斜めの動きのみを使用するため、参加しているすべてのセルは同じパリティを持ちます。$r+c$。 

ボードを 2 つのグループに分割します。 

1. 偶数パリティを持つセル。 
2. 奇数パリティを持つセル。 

これらのグループは制約によって混合されることがないため、独立して最適化できます。 

### 1 つのパリティ グループを列挙する

 1 つのパリティ グループの場合:

 1. そのパリティに属するすべてのセルを収集し、0 から 0 までのインデックスを割り当てます。$k-1$、 どこ$k\le 13$。 
2. 元のカラーリングをビットマスクとして記録します`orig`。 
3. どのセルが X 中心として機能できるかを特定します。 4 つの斜めの隣接セルがすべて存在する場合、そのセルは中心になります。 
4. すべてのセンターについて、同じパリティ グループ内の 4 つの斜めの隣接センターのインデックスを事前計算します。 

### 最終マスクのテスト

 1. すべてのマスクを列挙します。`0`に`(1<<k)-1`。 
2. 各中心について、中心ビットが 1 であり、隣接する 4 つのビットもすべて 1 であるかどうかを確認します。 
3. そのような中心が存在する場合、マスクは無効であるため、破棄できます。 

マスクは、このパリティ グループの完全な最終的な色付けを表します。 禁止された X は、結果として得られるボードが受け入れられないことを意味します。 

### 反転コストの計算

 1. 有効なマスクごとに、変更されたセルの数を計算します。$$\text{cost} = \text{popcount}(mask \oplus orig)$$1. すべての有効なマスクの中で最小コストを維持します。 

### 両方のパリティの結合

 1. 偶数パリティ グループと奇数パリティ グループを別々に解きます。 
2. 2 つの最小コストを加算し、結果を出力します。 

### なぜ効果があるのか

 対角移動はパリティを維持するため、禁止された X はすべて単一のパリティ クラス内に完全に収まります。 1 つのパリティ クラスからセルを変更しても、パターンが他のクラスに存在するかどうかには影響しません。 

固定パリティ クラスの場合、考えられるすべての最終的なカラーリングは、列挙されたマスクの中で 1 回だけ表示されます。 有効性テストでは、禁止された X を含むカラーリングが正確に拒否されます。すべての有効なカラーリングの中で、元の構成からの反転が最も少ないカラーリングが選択されます。 

2 つのパリティ クラスは独立しているため、グローバル最適値は、各クラスの最適な有効なカラーリングを組み合わせることによって取得されます。 グローバル ソリューションは 2 つのパリティ ソリューションに分解され、パリティ ソリューションのペアは結合されて 1 つのグローバル ソリューションになります。 したがって、最小コストが追加されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_parity(board, parity):
    cells = []
    pos_to_idx = {}

    for r in range(7):
        for c in range(7):
            if (r + c) % 2 == parity:
                pos_to_idx[(r, c)] = len(cells)
                cells.append((r, c))

    k = len(cells)

    orig = 0
    for i, (r, c) in enumerate(cells):
        if board[r][c] == 'B':
            orig |= 1 << i

    centers = []

    for r, c in cells:
        if 1 <= r <= 5 and 1 <= c <= 5:
            neigh = [
                pos_to_idx[(r - 1, c - 1)],
                pos_to_idx[(r - 1, c + 1)],
                pos_to_idx[(r + 1, c - 1)],
                pos_to_idx[(r + 1, c + 1)],
            ]
            centers.append((pos_to_idx[(r, c)], neigh))

    limit = 1 << k
    best = k

    for mask in range(limit):
        valid = True

        for center, neigh in centers:
            if not (mask >> center) & 1:
                continue

            ok = True
            for v in neigh:
                if ((mask >> v) & 1) == 0:
                    ok = False
                    break

            if ok:
                valid = False
                break

        if valid:
            cost = (mask ^ orig).bit_count()
            if cost < best:
                best = cost

    return best

def solve():
    t = int(input())

    ans = []

    for _ in range(t):
        board = [input().strip() for _ in range(7)]

        res = solve_parity(board, 0) + solve_parity(board, 1)
        ans.append(str(res))

    sys.stdout.write("\n".join(ans))

solve()
```この解決策は、パリティに従ってセルを分離することから始まります。 各パリティ クラスはコンパクトなビットマスクで表され、考えられるすべての最終的なカラーリングを効率的に列挙できます。 

すべてのパリティ クラスについて、コードはすべての潜在的な X 中心を、それらの 4 つの対角線上に隣接するもののインデックスとともに事前計算します。 これにより、列挙ループ内で繰り返される座標演算が削除されます。 

有効性チェックは、中心自体が黒で、斜めに隣接する 4 つすべてが黒の場合にのみ、中心が違反となるように慎重に記述されています。 境界セルは 4 つの斜めの隣接セルを持つことができないため、中心とはみなされません。 

フリップコストは次のように計算されます。`mask ^ orig`。 異なるビットはすべて、色が変化した 1 つのセルに対応します。 パイソンの`bit_count()`効率的なポップカウントの実装を提供します。 

最大マスク サイズはわずか 13 ビットであるため、完全な列挙は非常に小さいままです。

import sys
import io

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out

    input = sys.stdin.readline

    def solve_parity(board, parity):
        cells = []
        pos = {}

        for r in range(7):
            for c in range(7):
                if (r + c) % 2 == parity:
                    pos[(r, c)] = len(cells)
                    cells.append((r, c))

        k = len(cells)

        orig = 0
        for i, (r, c) in enumerate(cells):
            if board[r][c] == 'B':
                orig |= 1 << i

        centers = []
        for r, c in cells:
            if 1 <= r <= 5 and 1 <= c <= 5:
                centers.append(
                    (
                        pos[(r, c)],
                        [
                            pos[(r - 1, c - 1)],
                            pos[(r - 1, c + 1)],
                            pos[(r + 1, c - 1)],
                            pos[(r + 1, c + 1)],
                        ],
                    )
                )

        best = k

        for mask in range(1 << k):
            good = True

            for center, neigh in centers:
                if (mask >> center) & 1:
                    if all((mask >> v) & 1 for v in neigh):
                        good = False
                        break

            if good:
                best = min(best, (mask ^ orig).bit_count())

        return best

    t = int(input())
    ans = []

    for _ in range(t):
        board = [input().strip() for _ in range(7)]
        ans.append(str(
            solve_parity(board, 0) +
            solve_parity(board, 1)
        ))

    print("\n".join(ans))

    sys.stdin = old_stdin
    sys.stdout = old_stdout
    return out.getvalue().strip()
