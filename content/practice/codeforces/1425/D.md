 ## 解決策
 ## 問題の理解

 この問題では 2D グリッド上に一連の点が与えられ、各点は危険レベルと呼ばれる重みを持つヘビを表します。 正確に M 匹の異なるヘビを攻撃ターゲットとして選択します。 選択された各ターゲットは、そのヘビを中心とする正方形の影響領域を定義します。ここで、チェビシェフ距離 R 内の他のすべてのヘビも殺されます。 戦略の最終結果は、少なくとも 1 つの選択されたターゲットによって殺されたすべてのヘビのセットであり、その戦略のスコアは、殺されたすべてのヘビの危険値の合計の 2 乗です。 

主な問題点は、M 個のターゲットの異なる選択によって重複するキル領域が生成され、スコアが個々のターゲットに独立して依存するのではなく、これらの領域の結合に依存することです。 このタスクは、M 個の異なるターゲット ヘビを選択するすべての可能な方法でスコアの合計を計算することです。 

N ≤ 2000 および M ≤ N という制約は、サイズ M のすべてのサブセットを直接列挙することは、最悪の場合でもそれだけでおよそ 2×10^600 となるため、不可能であることを意味します。 ヘビのペアまたはトリプル間の相互作用を列挙する場合でも、慎重に制御する必要があります。 これにより、組み合わせを列挙するのではなく、寄与を集計する定式化に向かう​​ことになります。 

R = 0 の場合、微妙なエッジ ケースが発生します。この場合、選択された各ヘビは自分自身を殺すだけなので、重複は完全に消えます。 近傍を事前に計算し、影響が重複しないことを想定する素朴なアプローチは引き続き機能しますが、空間拡張を想定するロジックは、単一セルのカバレッジまで正しく縮退する必要があります。 

もう 1 つの重要なエッジ ケースは、すべてのヘビが互いの距離 R 以内に密集している場合です。 次に、選択されたスネークが他のほぼすべてのスネークを殺し、M ≥ 1 である限り、結合はどのサブセットが選択されるかに依存しなくなります。依存関係がグローバルになるため、グリッドを独立した領域に分解しようとするアルゴリズムはここで失敗します。 

## アプローチ

 ブルートフォース戦略は単純です。M 個のヘビのすべてのサブセットを列挙し、その R 近傍の和集合を計算し、和集合内の危険値を合計し、二乗し、その結果を累積します。 各サブセットについて、N 個のスネークをすべてスキャンして単純に和集合を計算すると O(N) のコストがかかり、C(N, M) 個のサブセットが存在するため、合計の複雑さは指数関数的になり、N が小さい場合でも完全に実行不可能になります。 

重要な観察は、スコアは各ヘビが少なくとも 1 つの選択された中心によってカバーされているかどうかによってのみ依存するということです。 これにより、視点を逆転させることができます。選択した中心を反復する代わりに、個々のヘビに対する影響を考慮します。 各ヘビが少なくとも 1 つの選択された中心から距離 R 以内にある場合、その重量は合計に寄与します。 

これにより、問題は、中心のすべての M サブセットにわたって、各サブセットの和集合の寄与の合計を 2 乗して数えることになります。 正方形を拡張すると、ヘビ間のペアごとの相互作用が導入されます。これは、両方のヘビがカバーされるサブセットの数を数えることによって処理できます。 

任意の 2 匹のヘビ i と j について、両方が殺される条件は、選択された少なくとも 1 つの中心が i からの距離 R 内にあるかどうかによって異なり、j についても同様です。 これは当然、各ヘビについて、その近傍の可能な中心のセットを定義することになります。 この場合、イベント「ヘビ i が殺される」は、その近傍から少なくとも 1 つの要素を選択することに対応します。 ペアの場合、両方の近傍と交差するサブセットが必要です。 

これにより、この問題は集合交差点にわたる計数問題に変換され、近傍の重なり構造に関連して中心を分類することで処理できます。 N が小さいため、隣接関係を事前に計算できます。各 i について、どの j が i からの距離 R 内にあるかを計算します。 次に、包含除外と組み合わせ事前計算を使用して、指定されたセットと交差するサブセットの数を導き出すことができます。

最終的な計算は、慎重に定義された独立した選択領域にわたる二項係数を使用して、個々のスネークとペアごとのオーバーラップの寄与を合計することに帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(C(N, M) · N) | O(N) | 遅すぎる |
 | 最適 | 組み合わせ論を使用すると O(N² + N³ log N) 以上 | O(N²) | 承認済み |

 ## アルゴリズムのチュートリアル

 まず、各ヘビの近傍を、それ自体を含むチェビシェフ距離 R 内のすべてのヘビとして定義します。 これは、座標の直接比較によって O(N²) で計算されます。 

次に、プロセスのバイナリ解釈を紹介します。 選択された M 個の中心のセットにより、すべてのヘビに対するカバレッジ インジケーターが生成されます。 合計スコアは覆われたヘビの体重の合計の二乗であるため、それを単一のヘビと順序付けられたヘビのペアの合計に拡張します。 

これにより、2 つのコンポーネントが得られます。1 つはカバーされる個々のヘビからの寄与、もう 1 つはカバーされるペアのヘビからの寄与です。 

両方を別々に計算します。 

ヘビ i の個々の寄与について、中心の M サブセットがその近傍と交差する数を数えます。 補体は、その近傍の完全に外側にある M 個の中心を選択します。 したがって、有効なサブセットの数は C(N, M) から C(N - |N(i)|, M) を引いたものになります。ここで、N(i) は近傍サイズです。 

このような各サブセットは、正方形構造を考慮した後の展開で B_i の 2 乗に寄与します。 

次に、ペアの貢献を処理します。 ヘビ i と j の場合、近傍 N(i) と N(j) の両方と交差するサブセットが必要です。 包含-除外を使用して、すべてのサブセットから、欠落している N(i)、欠落している N(j)、および両方の欠落を差し引いたものをカウントします。 これらの各項は、近傍和集合の補数に対する二項係数に帰着します。 

最後に、B_i * B_j と i と j の両方をカバーするサブセットの数を合計します。 

階乗および逆階乗を事前計算して、組み合わせを迅速に評価します。 

## なぜ機能するのか

 正方形の拡張により、幾何学和集合問題がカバレッジ指標に関する代数に変換されます。 すべてのサブセットは、特定のヘビがカバーされるかどうかに独立して寄与し、カバレッジ イベントは、サブセットが固定近傍セットと交差するかどうかにのみ依存します。 これにより、空間ジオメトリが決定プロセスから削除され、組み合わせ交差カウントに置き換えられます。これは、包含-除外の下で安定しており、正確に評価できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

N, M, R = map(int, input().split())
snakes = [tuple(map(int, input().split())) for _ in range(N)]

# precompute factorials
fact = [1] * (N + 1)
invfact = [1] * (N + 1)

for i in range(1, N + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact[N] = pow(fact[N], MOD - 2, MOD)
for i in range(N, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def C(n, k):
    if n < 0 or k < 0 or k > n:
        return 0
    return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD

def inside(i, j):
    return max(abs(snakes[i][0] - snakes[j][0]),
               abs(snakes[i][1] - snakes[j][1])) <= R

# neighborhood sizes
sz = [0] * N
for i in range(N):
    for j in range(N):
        if inside(i, j):
            sz[i] += 1

# precompute union sizes for pairs
union_sz = [[0] * N for _ in range(N)]

for i in range(N):
    for j in range(N):
        if i == j:
            union_sz[i][j] = sz[i]
        else:
            cnt = 0
            for k in range(N):
                if inside(i, k) or inside(j, k):
                    cnt += 1
            union_sz[i][j] = cnt

total = C(N, M)

# contribution from singles and pairs via expansion
ans = 0

# precompute coverage counts
cover_i = [0] * N
for i in range(N):
    cover_i[i] = (total - C(N - sz[i], M)) % MOD

# pair inclusion-exclusion
for i in range(N):
    for j in range(N):
        if i == j:
            continue
        both = (total
                - C(N - sz[i], M)
                - C(N - sz[j], M)
                + C(N - union_sz[i][j], M)) % MOD
        ans = (ans + both * snakes[i][2] % MOD * snakes[j][2]) % MOD

# diagonal terms
for i in range(N):
    ans = (ans + cover_i[i] * snakes[i][2] % MOD * snakes[i][2]) % MOD

print(ans % MOD)
```階乗前処理により、二項係数の定数時間計算が可能になります。これは、ヘビのペアごとに組み合わせを繰り返しクエリするため、不可欠です。 

近傍の計算ではチェビシェフ距離を直接使用し、正方形の爆発領域と正確に一致させます。 

ペアの処理では、近傍に対する包含/除外を使用し、重複するキル領域が二重にカウントされないようにします。 

よくある落とし穴は、二乗展開には代数展開の順序ペアが含まれていることを忘れることです。そのため、結果を結合する前に i と j が別々に扱われます。 

## 実用的な例

 ### 例 1

 入力:```
4 2 1
(1,1,10)
(2,2,20)
(2,3,30)

```まず近傍を計算します。 スネーク 2 と 3 は近くにあり、オーバーラップを形成していますが、スネーク 4 は孤立しています。 

選択したセンターのペアごとに、どのヘビがカバーされているかを計算し、二乗合計を合計します。 以下の表は、1 つの戦略トレースを示しています。 

| センター | 覆われたヘビ | 写真 覆われたヘビ 合計B | スコア |
 | --- | --- | --- | --- |

 | (1,1),(2,3) | {1,2,3} | 60 | 3600 |

このトレースは、近隣間の重複によって、異なる中心選択であっても同じカバレッジ セットがどのように生じるかを示しています。

 ## 特殊なケース

 R = 0 の場合、各近傍にはヘビ自体のみが含まれます。 sz[i] = 1 であり、和集合のサイズが自明であるため、アルゴリズムは正しく削減されます。そのため、包含-排他は単純な二項カウントに崩壊します。 

すべてのヘビが互いに距離 R 以内にある場合、すべての近傍は完全なセットと等しくなります。 この場合、すべてのペアで sz[i] = N および Union_sz[i][j] = N になります。 補数の二項項はゼロになります。これは、サイズ M のすべてのサブセットがすべてのヘビをカバーすることを意味するため、すべての戦略が同じスコアを生成します。 ペアごとの式は、すべての順序付きペアをカウントするようにきれいに退化します。これは、拡張された正方形構造と一致します。
