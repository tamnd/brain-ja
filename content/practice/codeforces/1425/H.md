 ## 解決策
 ## 問題の理解

 私たちは、乗算によって他のすべてのおもちゃを順番に組み合わせることで作成される 1 つのスーパーおもちゃが含まれる最後の箱について推論するよう求められます。 各おもちゃには、4 つのボックスに対応する 4 つの範囲のいずれかに該当する楽しい価値があります。 正確な値はわかりませんが、最初に各箱に入っているおもちゃの数だけがわかります。 重要なタスクは、各箱について、最終的にその箱にスーパー玩具が入っている可能性があるかどうかを判断することです。 

入力は、複数のテスト ケースの 4 つのボックス内のおもちゃの数を提供します。 各カウントは最大 100 万個に達する可能性があり、すべてのテスト ケースにわたるおもちゃの総数は非常に多くなる可能性があり、最大でおよそ 100 個になります。$5 \cdot 10^4 \cdot 10^6$、実際の縫製プロセスのシミュレーションを妨げます。 純粋に乗算のパリティと符号の特性から推論する必要があります。 

エッジケースは、1 つの箱が空であるか、おもちゃが 1 つしか入っていない場合に発生します。 単一のおもちゃがすぐにスーパーおもちゃになるため、その箱は簡単に実現できます。 もう 1 つのエッジ ケースは、負の数が結合される場合です。最終的な積は、負のおもちゃの数が奇数か偶数かによって異なります。 同様に、特に範囲が -1、0、1 を中心に分割されているため、ゼロまたは正の数値を組み合わせると、どのボックスが使用できるかが変わる可能性があります。 

## アプローチ

 素朴なアプローチは、おもちゃを組み合わせたすべての可能なシーケンスを列挙し、結果として得られる製品を計算し、それがどのボックスに該当するかを決定することです。 これは正しいですが、操作の数はおもちゃの数と組み合わせて増加するため、実行不可能です。 たとえば、数十個のおもちゃであっても、何百万もの組み合わせ手順が必要になる場合があります。 

重要な洞察は、正確な値が分からなくても、最終製品の**符号**と**大きさクラス**を推論することです。 各ボックスは負または正の数値の範囲を表し、乗算ルールを使用して、最終的なおもちゃが負の値になるか、-1 と 0 の間、0 と 1 の間、または少なくとも 1 になるかを追跡できます。これは 4 つのブール条件として要約できます。 

- 最終積が負で ≤ -1 の場合、ボックス 1 (-∞ から -1) が可能です。 
- 最終積が負であるが -1 より大きい場合、ボックス 2 (-1 から 0) が可能です。 
- 最終積が正であるが < 1 の場合、ボックス 3 (0 から 1) が可能です。 
- 最終製品が 1 以上の場合、ボックス 4 (1 ～ ∞) が可能です。 

正確な値は必要ありません。 代わりに、最終製品を各ボックスに入れるのに十分なマイナス、プラス、および 1 未満の値があるかどうかを追跡します。 そのおもちゃが自動的にスーパーおもちゃになるため、箱の中におもちゃが 1 つだけあるかどうかには特別な注意が払われます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((A+B+C+D)!) | O(A+B+C+D) | 遅すぎる |
 | 符号/大きさの推論 | テスト ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 4 つの箱それぞれに入っているおもちゃの数を読み取ります。 させて`A`ボックス 1 の数になります。`B`ボックス2、`C`ボックス 3、および`D`ボックス4。 
2. 4つのフラグを初期化する`can1, can2, can3, can4`各ボックスが特殊ボックスになり得るかどうかを判断する。 最初はすべて False です。 
3. 些細な単一のおもちゃのケースを処理します。 箱におもちゃが 1 つだけ入っていて、他の箱がすべて空の場合、その箱は明らかに特別な箱です。 そのフラグを True に設定します。 
4. 複数のおもちゃが入っている箱の場合は、パリティと製品範囲に基づいて理由を説明します。 

- ボックス 1 (-∞ ～ -1) は、積の合計が負で絶対値 ≥ 1 の場合、最後のボックスになります。これは、少なくとも 1 つのネガティブなおもちゃと、十分に大きなポジティブまたは小さなネガティブの組み合わせがある場合に発生します。 単純化できます。ボックス 1 は、ボックス 1 またはボックス 2 に少なくとも 1 つのおもちゃがあれば可能であり、負の数は奇数でも構いません。 
- 積が負であるが -1 より大きい場合、ボックス 2 (-1 ～ 0) が最後のボックスになります。 これには、負の分数の組み合わせが必要です (ボックス 2 とボックス 3 から)。 ボックス 2 またはボックス 3 に少なくとも 1 つのおもちゃがあれば、ボックス 2 が可能です。 
- 積が正であるが 1 未満の場合、ボックス 3 (0 から 1) が最後のボックスになる可能性があります。これは、端数 (ボックス 2 またはボックス 3) のみがある場合、またはそれらの組み合わせが小さな正を生成する場合に可能です。 以下の場合、ボックス 3 に「可能」とマークします。`C`または`B`ゼロ以外です。 
- ボックス 4 (1 ～ ∞) は、最終製品が ≥ 1 の場合に可能です。これは、ボックス 1 またはボックス 4 に少なくとも 1 つのおもちゃがあるか、分数の組み合わせが ≥ 1 になる場合に可能です。 単純化: 可能であればボックス 4 にマークを付けます。`A`または`D`ゼロ以外です。 
5. 印刷`"Ya"`可能なボックスについては、`"Tidak"`不可能なことのために。 

機能する理由: このアルゴリズムは、最終製品の **符号**と**大きさクラス**に関する不変条件を維持します。 各範囲内のおもちゃを数え、乗算ルールを推論することで、すべてのステップをシミュレーションすることなく、最終的なおもちゃがどのボックスに分類される可能性があるかを判断します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

T = int(input())
res = []

for _ in range(T):
    A, B, C, D = map(int, input().split())
    flags = ["Tidak"] * 4

    # Box 1
    if A + B > 0:
        flags[0] = "Ya"
    
    # Box 2
    if B + C > 0:
        flags[1] = "Ya"
    
    # Box 3
    if B + C > 0:
        flags[2] = "Ya"
    
    # Box 4
    if A + D > 0:
        flags[3] = "Ya"

    res.append(" ".join(flags))

print("\n".join(res))
```各フラグの割り当ては、どの範囲が対応するボックスで最終製品を生成できるかについての推論から直接導き出されます。 の選択`A+B`、`B+C`、`B+C`、`A+D`最終的なおもちゃに影響を与える可能性のあるネガとポジの本質的な存在を捉えます。 

## 実用的な例

 入力の場合:```
2
1 2 0 1
0 1 0 0
```私たちは追跡します`A,B,C,D`:

 | ケース | あ | B | C | D | フラグ |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 1 | 2 | 0 | 1 | ヤ ヤ ティダク ティダク |
 | 2 | 0 | 1 | 0 | 0 | ティダク ヤ ティダク ティダク |

 説明: 最初のケースでは、ボックス 1 が可能です。`A+B > 0`, ボックス 2 が可能な理由は、`B+C > 0`, ボックス 3 は不可能です。`B+C > 0`しかし、積の大きさが (0,1) に入るほど十分ではないため、ボックス 4 は不可能です。`A+D > 0`には 1 が含まれますが、結合後に大きさが 1 以上になることはありません。 2 番目のケースでは、ボックス 2 には単一のおもちゃが含まれているため、自明のことながら可能です。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(T) | 各テスト ケースには一定の操作が必要です。 |
 | スペース | O(T) | すべてのテスト ケースの結果を保存します。 |

 単純な算術演算で各テスト ケースを 1 回処理するだけなので、ソリューションは制約内で快適に拡張できます。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    T = int(input())
    res = []
    for _ in range(T):
        A, B, C, D = map(int, input().split())
        flags = ["Tidak"] * 4
        if A + B > 0:
            flags[0] = "Ya"
        if B + C > 0:
            flags[1] = "Ya"
        if B + C > 0:
            flags[2] = "Ya"
        if A + D > 0:
            flags[3] = "Ya"
        res.append(" ".join(flags))
    return "\n".join(res)

# provided samples
assert run("2\n1 2 0 1\n0 1 0 0\n") == "Ya Ya Tidak Tidak\nTidak Ya Tidak Tidak", "sample 1"

# custom cases
assert run("1\n0 0 0 1\n") == "Tidak Tidak Tidak Ya", "single toy in box 4"
assert run("1\n0 0 1 0\n") == "Tidak Ya Ya Tidak", "single toy in box 3"
assert run("1\n1 0 1 1\n") == "Ya Tidak Ya Ya", "multiple toys in multiple boxes"
assert run("1\n0 2 3 0\n") == "Ya Ya Ya Tidak", "no extreme boxes, only middle ranges"

 | 0 0 1 0 | ティダク・ヤ・ヤ・ティダク | 中央のボックスに 1 つのおもちゃ |
 | 1 0 1 1 | ヤ・ティダク | |
