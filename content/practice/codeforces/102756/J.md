 ## 解決策
 ## 問題の理解

 私たちは次のラインを持っています$N$彫像。 それぞれの彫像は、$K$-ビット番号、ビットの場合$i$特徴があるかどうかを示します$i$その像に現れます。 連続した彫像のグループ内ですべての特徴が同じ回数出現する場合、そのグループは雄大と呼ばれます。 タスクは、そのような連続したグループの可能な最大長を見つけることです。 

入力サイズが大きい場合:$N$到達できる$100000$、 その間$K$と同じ大きさにすることができます$30$。 すべての間隔をチェックするソリューションでは、次の点を調べます。$N^2$範囲、つまり約$10^{10}$最大の入力のために。 各範囲の特徴数を更新するだけでも遅すぎます。 線形に近いアプローチが必要です。 の小さな値$K$特徴に関する情報を表現することは可能ですが、考えられるすべての特徴と数の組み合わせを保存する余裕はないことがわかります。 

よくある間違いは、設定されたビットの合計数がバランスが取れているかどうかだけをチェックすることです。 すべての個々の特徴が同じ周波数を持つ必要があるため、これでは十分ではありません。 

例えば：```
4 3
1
2
4
7
```正しい答えは、`1`。 次のような長さ 2 のセグメント`[1, 2]`フィーチャはそれぞれ 1 回ずつ表示されますか? いいえ、機能 1 は 1 回、機能 2 は 1 回表示されますが、機能 3 は 0 回表示されます。 条件は、3 つの特徴数がすべて等しいということであり、特徴の合計数に関するものではありません。 

もう一つのエッジケースは、$K=1$:```
5 1
0
1
0
1
1
```正しい答えは、`5`。 特徴が 1 つだけあると、比較するカウントが 1 つしかないため、すべての範囲のカウントが自動的に同じになります。 常にサイズの違いのベクトルを構築する実装$K-1$このケースは個別に処理する必要があります。 

3 番目の重要なケースは、最初の彫像から始まる壮大な範囲です。```
3 2
1
2
3
```正しい答えは、`3`。 プレフィックス ハッシュ ソリューションは、スタチューを処理する前に空のプレフィックスを保存する必要があります。保存しないと、インデックス 1 から始まる範囲を検出できません。 

## アプローチ

 直接的な解決策では、可能なすべての間隔を試します。 左のエンドポイントごとに右のエンドポイントを拡張し、すべての特徴の数を維持します。 いつでもすべて$K$カウントが等しい場合、答えを更新します。 考えられるすべての範囲が考慮されるため、これは正しいです。 ただし、$O(N^2)$範囲とそれらの間の等価性のチェック$K$カウンターは最悪の事態を引き起こす$O(N^2K)$。 と$N=100000$、これは利用可能な時間を大幅に超えています。 

重要な点は、実際のカウントを保存しないようにすることです。 すべての特徴の数が等しい場合、範囲は壮大になります。 すべてのカウントが同じ値を持つかどうかを尋ねる代わりに、すべての特徴を 1 つの選択された参照特徴と比較できます。 

特徴ゼロを参照として選択します。 配列のすべてのプレフィックスについて、相違点を保存します。$$count_1-count_0,\ count_2-count_0,\ ...,\ count_{K-1}-count_0$$2 つの接頭辞が同じ差分ベクトルを持つ場合、それらの接頭辞間の統計はすべての特徴数に同じ量を追加します。 2 つの等しいプレフィックス ベクトルの差は、すべての特徴数が等しいため、セグメントが雄大であることを意味します。 

これにより、問題は同じプレフィックス状態を持つ最長のサブ配列を見つけることに変換され、各状態の最初の出現を格納するハッシュ マップで解決できます。

 | --- | --- | --- | --- |
 | ブルートフォース |$O(N^2K)$|$O(K)$| 遅すぎる |
 | プレフィックス差分ハッシュ |$O(NK)$|$O(NK)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 統計を読み、特殊なケースに対処する$K=1$。 すべての間隔は有効なので、答えは次のようになります。$N$。 
2. 長さのプレフィックス差分ベクトルを維持する$K-1$。 彫像を処理するときに追加します$1$参照フィーチャを除く、それに含まれるフィーチャに対応するすべての位置に移動します。 スタチューに参照フィーチャが含まれている場合は、減算します。$1$他のすべての機能の違いから。 

ベクトルは常に、各非参照特徴数が現在のプレフィックス内の参照特徴数とどの程度異なっているかを表します。 
3. 各差分ベクトルが出現する最初のインデックスを保存します。 空のプレフィックスはすべてゼロのベクトルを持ち、インデックス 0 に格納されます。 
4. プレフィックス ベクトルが再び現れると、最初の出現位置と現在の位置の間のセグメントの特徴数は同じになります。 考えられる答えとして、これらの位置間の距離を使用します。 
5. すべてのスタチューが処理され、見つかった最大長が出力されるまで続行します。 

なぜ効果があるのか:

 保存されたベクトルには、特徴数を比較するために必要な情報が正確に含まれています。 2 つのプレフィックスが同じベクトルを持つ場合、参照フィーチャに対するすべての差異が相殺されるため、それらのプレフィックス間の変更によってすべてのフィーチャが同じ頻度のままになります。 逆に、範囲が壮大な場合、すべての特徴数はその範囲内で均等に変化するため、範囲の前後のプレフィックス差分ベクトルは同一である必要があります。 ハッシュ マップは、これらのプレフィックスのペアを正確に見つけます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(n, k, arr):
    if k == 1:
        return n

    first = {tuple([0] * (k - 1)): 0}
    diff = [0] * (k - 1)
    ans = 0

    for idx, x in enumerate(arr, 1):
        has_first = x & 1

        if has_first:
            for i in range(k - 1):
                diff[i] -= 1

        for i in range(1, k):
            if x & (1 << i):
                diff[i - 1] += 1

        state = tuple(diff)

        if state in first:
            ans = max(ans, idx - first[state])
        else:
            first[state] = idx

    return ans

def main():
    data = sys.stdin.read().split()
    if not data:
        return

    ptr = 0
    out = []

    while ptr < len(data):
        n = int(data[ptr])
        k = int(data[ptr + 1])
        ptr += 2

        arr = list(map(int, data[ptr:ptr + n]))
        ptr += n

        out.append(str(solve_case(n, k, arr)))

    print("\n".join(out))

if __name__ == "__main__":
    main()
```実装では、すべてのプレフィックス状態の最初の出現が常に保持されます。これは、より早く出現すると、常により長い有効なセグメントが得られるためです。 リストは変更可能であり、辞書キーにはできないため、タプル変換が必要です。 

参照フィーチャーは特別に扱われます。 それが現れると、参照カウントが 1 つ増加するため、すべての差が減少します。 他の特徴については、そのビットが存在する場合にのみ位置が増加します。 各スタチューは 1 回だけ寄与するため、これらの更新の順序は最終的な差分ベクトルには影響しません。 

空のプレフィックスは、スタチューを処理する前に挿入されます。 これにより、最初の彫像から始まる範囲が処理され、長さの計算における 1 つずれのエラーが防止されます。

## テストケース```python
import sys
import io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)

    data = sys.stdin.read().split()
    ptr = 0
    out = []

    while ptr < len(data):
        n = int(data[ptr])
        k = int(data[ptr + 1])
        ptr += 2
        arr = list(map(int, data[ptr:ptr+n]))
        ptr += n

        if k == 1:
            out.append(str(n))
            continue

        first = {(0,) * (k - 1): 0}
        diff = [0] * (k - 1)
        ans = 0

        for idx, x in enumerate(arr, 1):
            if x & 1:
                for i in range(k - 1):
                    diff[i] -= 1
            for i in range(1, k):

                    diff[i - 1] += 1

            state = tuple(diff)
            if state in first:
                ans = max(ans, idx - first[state])
            else:
                first[state] = idx

        out.append(str(ans))

    sys.stdin = old
    return "\n".join(out)
