 ## 問題の理解

 通常の括弧シーケンスが与えられます`s`。 通常の括弧シーケンス (RBS) は、すべてのプレフィックスに少なくとも同じ数が含まれるシーケンスです。`'('`として`')'`、左括弧と右括弧の合計数は同じです。 

から任意の文字を削除する場合があります。`s`、残りの文字は元の順序を維持します。 結果の文字列`t`また、空ではない通常の括弧シーケンスである必要があります。 

そのようなすべてのサブシーケンスの中で`t`、次のような可能な最大の長さが必要です。`t`より_良い_です`s`。 

順序付けは辞書順であり、追加のルールが 1 つあります。つまり、短い文字列がプレフィックスである場合、長い文字列はより大きいと見なされます。 以来`'(' < ')'`問題の順序では、文字列が異なる最初の位置には次の文字列が含まれている必要があります。`'('`で`t`そして`')'`で`s`。 

入力により次のことが保証されます。`s`それ自体はすでに RBS です。 すべてのテスト ケースの合計の長さは最大でも`2 · 10^5`つまり、線形時間に近いものが必要になります。 サブシーケンスの数は指数関数的であるため、多くのサブシーケンスを明示的に検査する解決策は直ちに不可能です。 

主な微妙な点は、サブシーケンスであることと辞書編集的に大きいことが、非自明な方法で相互作用することです。

考慮する`s = "(())()"`。 

いくつかの文字を削除して、シーケンスを辞書編集的に大きくするという魅力的なアイデアがあります。 ただし、すべての適切な RBS サブシーケンスの長さは最大でも`4`、オリジナルよりも優れたものはありません。 正しい答えは、`-1`。 

もう 1 つの簡単な間違いは、別の RBS を生成する削除が機能すると考えることです。 例えば：```

```続いて`"((()))"`有効です。 最初の異なる位置では、オリジナルは`')'`一方、サブシーケンスは`'('`、だからその方が良いです。 答えは`6`。 

課題は、そのようなサブシーケンスがいつ存在するかを正確に特定し、その長さを最大化することです。

 ## アルゴリズムのチュートリアル

 1. 現在のバランスを維持しながらブラケット シーケンスをスキャンします。 
2.残高を増やす`'('`そしてそれを減らします`')'`。 
3. 残高がゼロになるたびに、プリミティブ ブロックは終了します。 
4. スキャン中に残高がゼロに達した回数を数えます。 この数はプリミティブ ブロックの数と等しくなります。 
5. カウントがちょうど 1 の場合、出力します。`-1`。 

単一のプリミティブ ブロックでは、これより優れた通常のブラケット サブシーケンスを生成することはできません。 
6. それ以外の場合は出力`n - 2`。 

少なくとも 2 つのプリミティブ ブロックを使用すると、後のブロックの先頭から 1 つの開始括弧と 1 つの対応する終了括弧を削除し、次の長さの RBS サブシーケンスを取得できます。`n - 2`これは、辞書編集上、オリジナルよりも大きくなります。 

### なぜ効果があるのか

 通常のブラケット シーケンスのすべての通常のブラケット サブシーケンスは、一致するペアを削除することによって取得されます。 

シーケンスに少なくとも 2 つのプリミティブ ブロックがある場合、1 つのブロックが終了し、別のブロックが開始する境界が存在します。 後のブロックの外側の一致するペアを削除すると、比較の前に開始括弧が移動し、サブシーケンスに含まれる最初の異なる位置が作成されます。`'('`そしてオリジナルには以下が含まれています`')'`。 結果として得られるシーケンスは規則的なままであり、長さを持ちます。`n - 2`。 

適切な通常の括弧サブシーケンスでは、少なくとも 1 つの一致したペアを削除し、長さを少なくとも 2 短くする必要があるため、サブシーケンスは存在できなくなります。 

シーケンスが単一のプリミティブ ブロックである場合、すべての適切な正規括弧サブシーケンスは、元のブロックよりも辞書編集的に小さくなります。 必要な最初の異なる位置には決して指定できません`'('`続いて、そして`')'`原作では。 したがって、有効なサブシーケンスは存在しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    ans = []

    for _ in range(t):
        n = int(input())
        s = input().strip()

        bal = 0
        blocks = 0

        for ch in s:
            if ch == '(':
                bal += 1
            else:
                bal -= 1

            if bal == 0:
                blocks += 1

        if blocks == 1:
            ans.append("-1")
        else:
            ans.append(str(n - 2))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```実装は構造観察に直接続きます。 

変数`bal`現在のブラケットバランスを保存します。 それがゼロに戻るたびに、1 つのプリミティブ ブロックが完了したことになります。 入力は RBS であることが保証されているため、残高がマイナスになることはなく、ゼロで終了します。 

重要な実装の詳細は、最後のゼロへの戻りだけでなく、すべてのゼロへの戻りをカウントすることです。 例えば：```
(())()
```残高が 2 回ゼロになるため、プリミティブ ブロックは 2 つあります。 中間のゼロが欠落していると、シーケンスが誤って分類されます。 

ブロックの数がわかれば、答えはすぐにわかります。 単一のブロックで得られるのは、`-1`、複数のブロックが与える`n - 2`。
