 ## 解決策
 ## 問題の理解

 バイナリ文字列を使用した 2 人用ゲームを分析するように求められました。アリスが最初に行動し、ボブが順番に続きます。 自分の番では、プレイヤーは文字列の厳密に非増加のサブシーケンスを選択し、それを非減少になるように再配置できます。 実際には、これは、少なくとも 1 つの位置を含む連続または非連続の位置のシーケンスを見つけることを意味します。`1`そして1つ`0`、次にそのシーケンスを並べ替えて、すべてが`0`何よりも最初に来ます`1`最後に来ます。 有効な手が存在しない場合、ゲームは終了し、最後に手を出したプレイヤーが勝ちます。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは長さの文字列を与えます。`n`のみを含む`0`と`1`s. 出力では、最適なプレイの下で勝者を決定する必要があり、アリスが勝てる場合は、選択すべき局面をリストして最初の手を指定する必要があります。 

の制約`n`に達する`2·10^5`テスト ケースごとに、テスト ケース全体の合計の上限も`2·10^5`、考えられるすべての動きやサブシーケンスをシミュレートしようとする強引なソリューションは除外されます。 あらゆる潜在的な動きを列挙する単純なアプローチでは、O(n²) 以上のサブシーケンスを調べる必要がありますが、これは最大の入力では実行不可能です。 

重要なエッジ ケースは、文字列が既に非降順で並べ替えられている場合に発生します。`0000`または`111`。 このようなシナリオでは、サブシーケンスには次のいずれかが含まれるため、移動は存在しません。`0`またはのみ`1`s なので、ボブがすぐに勝ちます。 もう 1 つの微妙なケースは、文字列に単一の反転がある場合です。`10`または`101`。 ここで、アリスは反転を含むサブシーケンスを直接選択して並べ替え、場合によってはゲームを直ちに終了することができます。 

## アプローチ

 ブルートフォースアプローチでは、ゲームをシミュレートしようとします。ターンごとに、両方を含むすべての非増加サブシーケンスを生成します。`0`そして`1`、動きを適用し、次のプレイヤーの勝者を再帰的に決定します。 原理的には正しいですが、このアプローチはすぐに手に負えなくなります。`n = 1000`、部分列の数は最悪の場合でおよそ 2ⁿ となり、妥当な計算限界をはるかに超えます。 

最適なアプローチのための重要な洞察は、ゲームは反転の位置、つまり反転の位置によって完全に決定されるということです。`1`の前に発生します`0`。 文字列を変更できる唯一の動きは、これらの反転を反転することです。 より正式には、ポジションの数を数えます`i`どこ`s[i] = 1`そして`s[j] = 0`一部の人にとっては`j > i`。 この数値がゼロの場合、文字列はすでに減少していないため、ボブがすぐに勝ちます。 それ以外の場合、アリスはいつでも反転回数を減らす手を選択できます。 さらに、反転のパリティが勝者を決定します。反転が 1 つだけ存在する場合、アリスはすぐにそれを削除して勝ちます。 複数ある場合、アリスの最初の動きは一番左のものを選択する必要があります`1`と右端`0`反転を形成する s を並べ替えて、最適な方法で再生を続けます。 

最適なアプローチは、文字列の両端からスキャンして最初と最後の位置を見つけることです。`0`そして`1`交換する必要があります。 これにより、アリスの有効な最初の手を O(n) 時間で構築できるようになります。 この最初の動きの後、その後のプレイはすべて同じロジックに従いますが、ゲーム全体をシミュレートするのではなく、最初の勝ち手を特定するだけで済みます。

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、文字列を読み取ります。`s`長さの`n`。 
2. 2 つのポインターを初期化します。`l = 0`そして`r = n-1`。 動く`l`まで進む`s[l] = 1`そして移動します`r`まで後ろ向きに`s[r] = 0`。 目標は左端を見つけることです`1`そして一番右`0`それは故障しています。 もし`l >= r`、文字列は減少せず、ボブはすぐに勝ちます。 
3. それ以外の場合は、2 つのリストを作成します。1 つはインデックス用です。`1`左から始まり、`l`、および別のインデックス用`0`右から下に向かって`r`。 これらのインデックスは、アリスがソートできる最初の有効なサブシーケンスを形成します。 
4. 結合されたインデックスのリストを並べ替えて、昇順で移動を生成します。 
5. 出力`Alice`、移動内のインデックスの数、およびインデックス自体のリスト。 

機能する理由: アルゴリズムは、間のすべての反転を含む最小のサブシーケンスを識別します。`1`左側にあり、`0`右側にあります。 この部分シーケンスをソートすると、反転の数が減り、文字列がまだソートされていない場合でもアリスが強制的に勝つことができます。 正しさは、どの移動でも文字列を変更する必要があるという事実から来ます。`1`と右端`0`■ 有効なサブシーケンスを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        
        l, r = 0, n - 1
        while l < n and s[l] == '0':
            l += 1
        while r >= 0 and s[r] == '1':
            r -= 1
        
        if l >= r:
            print("Bob")
        else:
            ones = [i+1 for i in range(l) if s[i] == '1']
            zeros = [i+1 for i in range(r, n) if s[i] == '0']
            move = ones + zeros
            move.sort()
            print("Alice")
            print(len(move))
            print(*move)

if __name__ == "__main__":
    solve()
```コードはまず左端を識別します。`1`そして一番右`0`それは反転を形成します。 のインデックスを収集します`1`左側にあり、`0`右側の s を move に入力し、ソートして結果を出力します。 高速 I/O は、大量の入力を効率的に処理するために使用されます。 Off-by-one エラーは次の方法で回避できます。`i+1`この問題には 1 から始まるインデックスが必要であるためです。
