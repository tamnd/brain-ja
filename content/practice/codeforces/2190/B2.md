 ## 問題の理解

 指定された括弧シーケンスの空でないすべてのサブシーケンスの合計を計算するように求められます。 各サブシーケンスには、それ自体よりも厳密に「優れている」最長の通常の括弧サブシーケンスの長さとして定義される「スコア」があります。 通常の括弧シーケンスとは、次のように括弧が適切に一致するシーケンスです。`()()`または`(())`。 最初のシーケンスがプレフィックスとして厳密に長いか、最初の異なる位置に左括弧があり、もう一方が閉じ括弧がある場合、あるシーケンスは別のシーケンスよりも優れています。 

入力は複数のテスト ケースを提供します。 各テスト ケースでは、最大 100 個の括弧のシーケンスが提供されます。 すべてのテスト ケースにわたって、合計の長さは 100 を超えません。この低い上限は、より大きなシーケンスでは不可能な解決策を検討できるため、非常に重要です。 たとえば、長さ 100 の文字列のすべてのサブシーケンスを直接反復するには、次の処理が必要になります。$2^{100}$実現不可能な可能性。 これは、真の総当たり列挙ではなく、動的プログラミング アプローチの必要性を示しています。 

エッジ ケースは、非常に短いシーケンス、特に長さ 1 で発生します。単一の開始括弧または終了括弧は決して規則的ではないため、スコアは常に 0 になります。 それ自体は正規であるが、厳密にはより優れたサブシーケンスを持たないシーケンスも、ゼロを生成します。 たとえば、シーケンス`()`括弧を削除すると、改善されるのではなく短くなるため、厳密にはこれより良いサブシーケンスはありません。 「より良い」関係を誤解すると、間違った部分列を数えることにつながる可能性があります。 

## アプローチ

 素朴なアプローチでは、すべてを列挙することになります。$2^n - 1$空ではないサブシーケンス。 各サブシーケンスについて、そのすべてのサブシーケンスをチェックして、より適切な最も長い規則的なサブシーケンスを見つけます。 これの最悪の場合の複雑さは次のとおりです。$O(4^n)$なぜならそれぞれにとって$2^n$後続を再度確認する可能性があります$2^n$内部のサブシーケンス。 これはたとえとしても絶望的だ$n = 20$。 

重要な洞察は、問題を組み合わせて再解釈することです。 動的プログラミングを使用して、可能性のある規則的なシーケンスに対する文字列内の各位置の寄与をカウントできます。 すべてのサブシーケンスを明示的に追跡する代わりに、一定数の不一致の開始括弧 (`balance`）。 閉じ括弧を追加すると、正のバランスを持つシーケンスを拡張して、新しい規則的なシーケンスを形成できます。 

さらに、最初の異なる位置では開き括弧のみが閉じ括弧よりも「優れている」可能性があるため、問題は、後の閉じ括弧と一致する開始括弧のシーケンスをカウントすることに帰着します。 これにより、文字列を 1 回反復して、左括弧の現在のバランスによってインデックス付けされた DP 配列を更新し、より長いシーケンスに拡張できるサブシーケンスをカウントすることができます。 モジュラー演算により、大きなカウントの制約内に確実に収まるようになります。

 ## アルゴリズムのチュートリアル

 1. DP アレイを初期化する`dp`長さの`n+1`、 どこ`dp[b]`現在の位置で終了するサブシーケンスの数をバランスを保って保存します`b`比類のない`(`括弧。 から始める`dp[0] = 1`、空のシーケンスを表します。 
2. 文字列内の各文字を反復処理します。`s`。 
3. 文字ごとに、新しい DP 配列を維持します。`ndp`:

 - キャラクターの場合`(`、既存の残高ごとに`b`、増分`ndp[b+1]`による`dp[b]`。 これは、既存のすべてのサブシーケンスに左括弧を追加することを表します。 
- キャラクターの場合`)`、残高ごとに`b > 0`、増分`ndp[b-1]`による`dp[b]`。 これにより、既存のすべてのシーケンス内の 1 つの一致しない開始括弧が正のバランスで閉じられます。 
4. 文字を加工した後、`ndp`に戻る`dp`。 別の変数も維持します`score_sum`ここで、少なくとも 1 つの括弧を閉じたシーケンスの数を加算します (`b`減少します)。 これにより、「より良い」サブシーケンスに寄与するシーケンスがキャプチャされます。 
5. 最後に、`score_sum`モジュロ$998244353$文字列の合計スコアです。 

その考え方は、DP がすべてのサブシーケンスのバランスを自然に追跡し、閉じ括弧がプラスのバランスを減らすたびに、より良いサブシーケンスに貢献するというものです。 これにより、組み合わせカウントを取得する際に、すべてのサブシーケンスを明示的に列挙することが回避されます。 

なぜ機能するのか: DP 不変性は次のとおりです。`dp[b]`常に現在の文字で終わるサブシーケンスの数を正確に表します。`b`比類のない`(`。 を持つシーケンスのみなので、`b > 0`で拡張できます`)`新しい規則的なシーケンスを形成し、更新する`score_sum`いつでも`)`が追加されます`b > 0`より適切なサブシーケンスをすべて正確にカウントします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 998244353

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    
    dp = [0] * (n+1)
    dp[0] = 1
    score_sum = 0
    
    for c in s:
        ndp = dp[:]
        if c == '(':
            for b in range(n, 0, -1):
                ndp[b] = (ndp[b] + dp[b-1]) % MOD
        else:  # c == ')'
            for b in range(1, n+1):
                ndp[b-1] = (ndp[b-1] + dp[b]) % MOD
            score_sum = (score_sum + sum(dp[1:])) % MOD
        dp = ndp
    
    print(score_sum)
```DP 配列は、各バランスのサブシーケンスの数を追跡します。 遭遇して`(`、バランスを高めるためにサブシーケンスを拡張します。 の上`)`、残高を減らし、正の残高を持つ部分列の合計を次のように加算します。`score_sum`、「より良い」規則的なサブシーケンスを形成したばかりのシーケンスを反映しています。 コピーします`dp`に`ndp`現在の反復に必要なカウントを上書きしないように、各ステップで実行します。 モジュラー演算により、カウントが制限内に収まることが保証されます。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    MOD = 998244353
    out = []
    
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        
        dp = [0] * (n+1)
        dp[0] = 1
        score_sum = 0
        
        for c in s:
            ndp = dp[:]
            if c == '(':
                for b in range(n, 0, -1):
                    ndp[b] = (ndp[b] + dp[b-1]) % MOD
            else:
                for b in range(1, n+1):
                    ndp[b-1] = (ndp[b-1] + dp[b]) % MOD
                score_sum = (score_sum + sum(dp[1:])) % MOD
            dp = ndp
        out.append(str(score_sum))
    return "\n".join(out)
