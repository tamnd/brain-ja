 ## 解決策
 ## 問題の理解

 私たちは持っています`n`定理があり、各定理には熟練度値が割り当てられています。 試験には正確に次の内容が含まれます`k`異なるカード。 すべてのカードには正確に含まれています`floor(n / k)`異なる定理があり、複数のカードに定理が現れることはありません。 一部の定理は次の場合に未使用のままになる可能性があります。`n`で割り切れない`k`。 

すでに何人かの学生がカードに書かれた正確な定理セットを明らかにしました。 これらの公開されたカードは有効であることが保証されており、異なる生徒が同じカードを引くことができるため、同じカードが複数回表示される可能性があります。 

Vasya は次のいずれかを受け取ることができます。`k`カード。 一部のカードは報告書からすでに判明していますが、残りのカードは不明です。 未知のカードのすべての有効な完了を考慮して、Vasya がまだ受け取ることができるすべてのカードの中で可能な最小および最大の平均熟練度を計算する必要があります。 

制約は非常に小さいです。 両方`n`報告されたカードの数は最大で`100`。 これは、二次アルゴリズムや三次アルゴリズムであっても完全に安全であることを意味します。 集合を分割する方法の数が非常に急速に増加するため、すべての定理分割を網羅的に検索することは依然として不可能ですが、ソートや貪欲な割り当てに基づくものは制限内であれば些細なものです。 

難しいのは、どの情報が実際に重要なのかを理解することです。 私たちは正確に未知のカードを知りません。すべての定理が最大 1 枚のカードに属し、各カードのサイズが固定であることだけがわかります。 不用意に実装すると、すべての目に見えない定理が他のすべての目に見えない定理と任意に組み合わせることができると誤って仮定する可能性があります。 カードはパーティションを形成する必要があるため、これは誤りです。 

次の例を考えてみましょう。```
6 2
1 2 3 100 100 100
1
1 2 3
```各カードにはサイズがあります`3`。 1 枚のカードがすでに知られています。`{1,2,3}`。 残りのカードには次の内容が含まれている必要があります`{4,5,6}`。 最小値と最大値は両方とも`100`。 パーティション構造を無視して任意のサブセットを試した場合、平均は次のように誤って考えられる可能性があります。`(1+2+100)/3`可能です。 

いくつかのカードがレポート内で繰り返される場合、別の微妙なケースが発生します。```
4 2
1 2 10 20
2
1 2
2 1
```これら 2 つのレポートは同じカードについて説明しています。 既知のカードはまだ 1 枚だけであり、2 枚ではありません。 両方を独立してカウントするバグのあるソリューションでは、未知のカードは残っていないものと考えられます。 

最後の重要なエッジケースは次のような場合です。`n`で割り切れない`k`。```
7 3
1 2 3 4 5 6 7
0
```それぞれのカードのサイズは、`2`、だからそれだけ`6`定理はカードで使用されます。 1 つの定理は未使用のままです。 平均を最大化するための最適な戦略は、最小の定理を破棄し、残った最大のペアからカードを構築することです。 最小化するために、代わりに最大の定理を破棄します。 

## アプローチ

 強引なアイデアは、定理の有効なすべての部分をカードに生成し、考えられるすべてのカードの平均を計算することです。 これは、制約が小さいため概念的には機能しますが、組み合わせによりパーティションの数が爆発的に増加します。 均等分割`100`要素を周囲のサイズのグループに分割`50`天文学的に大きいです。 どれだけ枝刈りをしても、このアプローチは役に立ちません。 

重要な観察は、すべての未知のカードの正確な構成は重要ではないということです。 私たちは 1 枚のカードの可能な最小値と最大値の平均のみを考慮します。 

各カードに次の内容が含まれているとします。`m = floor(n / k)`定理。 一部の定理は既知のカードに登場するため、すでに修正されています。 残りの定理は、有効な方法で未知のカードに自由に配布できます。 

Vasya の可能な平均を最小限に抑えるために、1 枚の未知のカードに利用可能な最小の定理値が含まれるようにします。 未知のカードはすべて同じサイズなので`m`、未知のカード間で可能な最小の平均は、単にカードの平均です。`m`未使用の定理の最小値。 

同様に、未知のカード間で可能な最大の平均は、`m`未使用の定理の最大値。 

また、Vasya もこれらのカードのいずれかを受け取る可能性があるため、既知のカードと比較する必要があります。 それらの平均値は固定されており、すでに達成可能です。 

これにより、問題は単純な簿記に帰着します。 

1. 既知のカードをすべて識別します。 
2. これらのカードにあるすべての定理を使用済みとしてマークします。 
3. 既知のカードの平均を計算します。 
4. 未使用の定理値をソートします。 
5. 極限から貪欲に最良と最悪の未知のカードを構築します。 

未知のカード間には素性以外の追加の制約がないため、貪欲な選択が機能します。 1 枚のカードをできるだけ小さくしたい場合は、利用可能なグローバル最小値を採用することが常に最適です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | 指数 | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`n`そして`k`、次に計算します`m = n // k`、これはカードごとの定理の数です。 
2. すべての定理熟練度値を配列に読み取ります。 
3. 報告されたカードを処理します。 同じカードが異なる順序で複数回表示される可能性があるため、各カード表現を並べ替えてセットに保存し、異なるカードのみを保持します。 
4. 既知のカードごとに次のようにします。 

1. 平均熟練度を計算します。 
2. この平均を使用して、全体的な最小値と最大値の回答を更新します。 
3. すべての定理を使用済みとしてマークします。 

これらのカードは明示的に観察されたため、可能であることが保証されています。 
5. 未使用の定理値をすべて別の配列に収集し、並べ替えます。 
6. しましょう`remaining_cards`未知のカードの数になります：`remaining_cards = k - number_of_distinct_known_cards`。 
7. 少なくとも 1 枚の不明なカードがある場合:

 1. 未知のカードの可能な限り最小の平均は、`m`未使用の最小値。 
2. 未知のカードの可能な最大の平均は、`m`未使用の最大値。 
3. グローバル最小値と最大値をこれらの値で更新します。 
8. 最終的な最小値と最大値を出力します。 

### なぜ効果があるのか

 既知のカードは修正されており、観察されたとおりに正確に残っていなければなりません。 未使用の定理はすべて未知のカードにのみ属し、未知のカードに対する唯一の制限は、未使用の定理をサイズのグループに分割することです。`m`。 

未知のカードの平均を最小限にするには、そのカードに含まれる定理をできるだけ小さくする必要があります。 選択した定理をより小さい未使用の定理に置き換えても、平均が減少するだけです。 この交換引数を繰り返すと、最終的には世界最小の要素からなるカードが生成されます。`m`未使用の値。 

同じ議論が最大値を使用して最大値にも対称的に適用されます。 

未使用の定理を同じサイズのグループに分割することは有効であるため、これらの極値カードは常に構築可能です。 したがって、アルゴリズムは達成可能な正確な最小値と最大値の平均を計算します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    q = int(input())

    unique_cards = set()

    for _ in range(q):
        card = tuple(sorted(map(int, input().split())))
        unique_cards.add(card)

    m = n // k

    used = [False] * n

    INF = float('inf')
    mn = INF
    mx = -INF

    for card in unique_cards:
        total = 0

        for x in card:
            total += a[x - 1]
            used[x - 1] = True

        avg = total / m

        mn = min(mn, avg)
        mx = max(mx, avg)

    remaining = []

    for i in range(n):
        if not used[i]:
            remaining.append(a[i])

    remaining.sort()

    unknown_cards = k - len(unique_cards)

    if unknown_cards > 0:
        low_avg = sum(remaining[:m]) / m
        high_avg = sum(remaining[-m:]) / m

        mn = min(mn, low_avg)
        mx = max(mx, high_avg)

    print(f"{mn:.10f} {mx:.10f}")

solve()
```最初の重要な詳細は、報告されたカードの重複を排除することです。 2 人の生徒が同じカードを受け取る場合がありますが、入力行内の定理の順序は任意です。 定理インデックスをソートし、それらをセット内のタプルとして保存すると、正規表現が得られます。 

2 番目の微妙な点は、使用されている定理を個別のカードからのみマークすることです。 重複したレポートを個別に処理した場合、実際よりも多くの定理が修正されていると誤って考える可能性があります。 

残りの未使用の定理値は、すべての未知のカードを特徴付けるのに十分です。 未知のカードはすべて同じサイズであるため、最小平均は最小のカードから求められます。`m`値と最大値からの最大値`m`。 

必要な精度はわずかであるため、アルゴリズムは浮動小数点除算を直接使用します。`1e-6`。 パイソンの`float`十分すぎるほどです。
