 ## 問題の理解

 2 つの文字列が与えられています。`a`そして`b`、最大 100 万文字までの同じ長さ。 タスクはインデックスを見つけることです`i`そして`j`で`a`特定の変換を実行すると、次のようになります。`b`。 変換は次のように機能します。間の部分文字列を取得します。`i+1`そして`j-1`(包括的) そのままの状態で、部分文字列の逆を追加します。`j`最後まで`a`の先頭から部分文字列の逆が続きます。`a`に`i`。 最大化する必要がある`i`、複数の場合は`j`値は最大値として存在します`i`、最小限のものを選択してください`j`。 

重要な洞察は、私たちが効果的に分割しているということです。`a`真ん中（そのまま）、尻尾（反転）、頭（反転）の３つに分けます。 これら 3 つのセグメントを次のように調整する必要があります。`b`。 文字列は非常に長くなり、最大 100 万文字になる可能性があるため、すべてを試してみようという単純なアプローチは有効ではありません。`O(n^2)`ペア`(i, j)`はおよそ 10^12 の操作を実行することになり、2 秒の制限時間内では実行できません。 線形または線形に近いアプローチが必要です。 

微妙なエッジケースが発生する場合`i`または`j`境界線にいます。 たとえば、次の場合`i`=`n-2`そして`j`=`i+1`、中央の部分文字列は空です。 もし`i`= -1 または`j`= n の場合、アルゴリズムは空の先頭セグメントまたは末尾セグメントを正しく処理する必要があります。 もう 1 つのエッジケースは次のような場合です`a`等しい`b`まさに - その場合、`i`=`n-1`そして`j`=`n`ただし、インデックスエラーを避けるために注意する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのペアが考慮されます`(i, j)`。 ペアごとに、変換された文字列を計算し、それが一致するかどうかを確認します。`b`。 正しいのですが、文字列比較が単純に行われた場合は O(n^3) となり、効率的な部分文字列操作を使用した場合は O(n^2) になります。 n が 10^6 までなので、これは時間内に終了しません。 

最適なアプローチは、尾部と頭部の反転が次の反転された部分文字列に対応するという事実を利用します。`a`。 すべてを試すのではなく、`(i, j)`、可能な限り反復できます`i`値を降順に並べて一致を試みます`b`途中から始まる`a`。 中心的な観察は、次の最後の部分です。`b`の反転した頭と一致する必要があります`a`、の最初の部分`b`(反転したテールを削除した後) は中央と一致する必要があります。 2 ポインター手法または文字列ハッシュを使用すると、これらの一致を O(n) 時間で効率的にチェックできます。 

具体的には、逆にします`a`のプレフィックスと一致しようとします`b`逆の尾部と接尾辞に対して`b`逆頭に対して。 可能な限り大きなものからスキャンすることで、`i`下向きに、「最大 i」要件を自然に満たします。 一度有効になると`i`が見つかったら、対応する最小値を決定します`j`中間セグメントの残りの文字を照合することによって。

 ## アルゴリズムのチュートリアル

 1. 文字列全体を反転します`a`形成する`rev_a`。 
2. 反復する`i`から`n-1`まで`0`。 それぞれについて`i`、最後の一致を試みます`i+1`の登場人物`b`最初のものと`i+1`の登場人物`rev_a`（これは反転ヘッドのマッチングに相当します）。 一致が失敗した場合は、次の小さいレベルに進みます。`i`。 
3. 有効になったら`i`が見つかった場合は、残りの部分文字列を決定します。`b`（最初`n-(i+1)`文字）から来なければなりません`s[i+1:j] + reversed tail`。 スライド`j`から`i+1`に`n`そして、反転された末尾セグメントが対応する接尾辞と一致するかどうかを確認します。`b`。 
4. 一致する場合`j`が見つかったら、電流を出力します`(i, j)`。 それを繰り返したので、`i`降順で、そして`j`昇順で、これらは最大値を満たします`i`そして最小限の`j`要件。 
5. 反復後に有効なペアが見つからない場合は、「-1 -1」を出力します。 

機能する理由: 各ステップで、次のことのみを受け入れます。`i`頭が逆になっているところ`a`の対応する部分と一致します`b`。 残りの文字は、反転された末尾と中央の部分文字列によって一意に決定されます。 この順序でスキャンすることで、最大限のパフォーマンスを保証します。`i`そして最小限の`j`小さいので`i`それ以上の`j`以前に一致が発生しない場合にのみ考慮されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

a = input().rstrip()
b = input().rstrip()
n = len(a)

if len(a) != len(b):
    print("-1 -1")
    sys.exit()

rev_a = a[::-1]

found = False
for i in range(n-1, -1, -1):
    # check if head matches reversed part of b
    head_len = i + 1
    if b[-head_len:] != rev_a[:head_len]:
        continue

    # determine middle + reversed tail
    remaining = b[:n-head_len]
    # try all possible j starting from i+1
    for j in range(i+1, n+1):
        mid = a[i+1:j]
        tail_rev = a[j:][::-1]
        candidate = mid + tail_rev
        if candidate == remaining:
            print(i, j)
            found = True
            break
    if found:
        break

if not found:
    print("-1 -1")
```コードの最初の部分は文字列を読み取り、反転します。`a`。 外側のループは反復可能です`i`値を最大から最小の順に並べます。 反転ヘッドの確認は、スライスと比較を使用して行われます。 内側のループは可能な限りすべてのことを試みます`j`値を指定し、中央の部分文字列と反転した末尾を連結することによって候補文字列を構築します。 これにより、変換全体を最初から再構築する必要がなくなります。 早めの休憩により最小限の費用が保証されます`j`最大値が 1 回選択されます`i`固定されています。
