 ## 解決策
 ## 問題の理解

 私たちには次のような 3 次元空間が与えられています。$n$エネルギー球の中心を表す固定点。 がある$m$各レベルで、プレーヤーは原点を通過する平面から開始します。 プレイヤーは任意の半径の球を構築できます$R$指定されたセンターで、以下の費用を支払います$R$球体ごとに。 レベルごとに 1 回、プレーヤーは平面に対して垂直にレーザーを発射でき、交差するすべての球体が即座にアクティブになります。 タスクは、すべての球体が各レベルでアクティブ化できるように、球体の半径の最小総コストを決定することです。 

入力は次のもので構成されます$n$3D 空間内の点と$m$係数によって定義される平面$(a_i, b_i, c_i)$。 出力は$m$数字は、それぞれそのレベルを完了するための最小コストを表します。 

制約は次のことを示します$n \le 900$そして$m \le 100$。 以来$n$下にあります$10^3$、任意の 2 次アルゴリズム$n$は実現可能ですが、3 次以上の場合は制限時間を超える可能性があります。 それぞれの座標は次のとおりです$10^4$、および最大 100 の平面係数。これにより、極端な浮動小数点の丸めに敏感なアプローチが排除されます。 

すべての点が正確に平面上にある場合、微妙なエッジ ケースが発生します。 ゼロ以外の固定半径が必要であると単純に仮定すると、支出が過剰になる可能性があります。 たとえば、4 つの点が XY 平面上で正方形を形成し、水平面が XY 平面であるとします ($z=0$)、z 軸に沿ったレーザーは半径 0 のすべての点に当たるため、最小コストは 0 です。 垂直投影を無視した不注意な実装では、誤って正のコストが出力される可能性があります。 

## アプローチ

 ブルートフォース手法では、レーザーを発射する垂直線に沿ったあらゆる可能な点を考慮し、各球体を個別に起動するのに必要な半径を計算します。 これが機能するのは、どの発射点でも、球のコストは球の中心からレーザー ラインまでの距離であるためです。 各候補ラインポイントを反復処理して、すべてのラインポイントの距離を計算できます。$n$球体を作成し、最大値を取得し、最小値を追跡します。 これは正しいですが、遅すぎます。各レベルに対して、単純なアプローチでは次のことが必要になります。$O(n^2)$すべての候補位置に沿った距離を確認するだけの操作で、おおよその結果が得られます。$10^5 \times 10^2 = 10^7$計算は管理可能ですが不要です。 

重要な洞察は幾何学から得られます。必要な最小半径は、すべての点を平面の法線ベクトルに投影することによって決まります。 平面の法線に沿ってレーザーを選択すると、レーザーがその法線に沿って最も近いまたは最も遠い投影点を通過するときに、点からレーザーまでの距離が最小になります。 したがって、最小半径は、平面の法線に沿った点の最も遠い投影点と最も近い投影点の間の距離の半分に等しくなります。 これにより、問題がドット積の計算と最大値/最小値の検出に軽減され、線に沿った反復検索が回避されます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2m) | O(n) | n が大きいと遅すぎます |
 | 最適 | O(nm) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ポイント数を読み取る$n$とレベル$m$。 すべての点の座標を 3D ベクトルとして保存します。 
2. 各レベルについて、平面係数を読み取ります。$(a, b, c)$。 これらの係数から平面の法線ベクトルを構築します。 
3. 必要に応じて法線ベクトルを正規化しますが、この問題では距離を計算するときにスケーリング係数がキャンセルされるため、効率を高めるためにそのままにしておくことができます。 
4. 各点について、ドット積を計算して、平面の法線に沿った符号付き距離を計算します。$d_i = a x_i + b y_i + c z_i$。 
5. これらの投影距離の最大値と最小値を求めます。$d_\text{max}$そして$d_\text{min}$。 
6. 単一の垂直レーザーですべてのポイントをカバーする最小半径は、投影範囲の半分です。$R = (d_\text{max} - d_\text{min}) / 2 / ||\text{normal}||$。 これは、基本的な垂直距離の幾何学に従っています。 
7. 出力$R$少なくとも 10 桁の精度。 

機能する理由: 法線に沿った点から線までの距離は、線が法線に沿った極端な投影の間の中間を通過するときに最小化されます。 範囲の半分を使用すると、すべてのポイントが半径内に収まることが保証されます。$R$一方、ラインに沿って別の点を選択すると、必要な半径が増加するだけです。 この不変式は各レベルに独立して当てはまります。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

n, m = map(int, input().split())
points = [tuple(map(int, input().split())) for _ in range(n)]
planes = [tuple(map(int, input().split())) for _ in range(m)]

for a, b, c in planes:
    norm_sq = a*a + b*b + c*c
    norm = math.sqrt(norm_sq)
    projections = [a*x + b*y + c*z for x, y, z in points]
    R = (max(projections) - min(projections)) / (2 * norm)
    print(f"{R:.10f}")
```このソリューションは、最初にすべての点と平面を読み取ります。 各平面について、平面の法線に沿って投影を計算します。 最大投影と最小投影を使用して、半分の範囲を計算し、法線ベクトルの大きさで割って最小半径を取得します。 フォーマットにより、出力が精度要件を満たしていることが保証されます。 中間ステップでの正規化を回避すると、浮動小数点エラーが減少します。

チェック: 法線に沿った投影 = dot(n, p) = 0。最適なレーザー位置はラインに沿った任意の場所です。 レーザーは z 軸に沿っているため、半径 = レーザーからポイントまでの最大距離 = sqrt(x^2 + y^2) となります。 したがって、実際には、Z 軸に沿って点を選択する必要があります (半径 = XY 平面の最大距離 = sqrt(max x^2 + y^2))。 

ああ、訂正: **法線**に沿った投影は 1D 配置でのみ機能します。 ここでは、点は法線に対して垂直な方向に変化します。 最小半径は、**レーザー ラインからのポイントの最大距離**に等しく、ラインに沿った任意の場所に指定できます。 法線に沿った垂直レーザーにより、線に沿ってシフトして半径を最小限に抑えることができます。 3D では、線の周囲の点を囲む最小半径は、**線に垂直な平面への投影を囲む最小円の半径**です。
