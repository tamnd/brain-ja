 ## 解決策
 ## 問題の理解

 辺の長さが 2 つの未知の整数である、軸に揃えられた非表示の長方形と対話しています。$a$そして$b$、どちらも最大 100 です。これらの値を直接確認することはできません。 代わりに、辺のある別の長方形を提案することで、長方形を調べることができます。$c$そして$d$、そして裁判官は私たちにこれがどうかを言います$c \times d$長方形は非表示の内側に完全に配置できます。$a \times b$矩形。 

応答は決定論的です。両方の場合に正となります。$c \le a$そして$d \le b$、または方向が交換されたとき、$c \le b$そして$d \le a$。 このようなクエリは最大 20 個まで許可され、それぞれが最大 200 の次元を使用し、最終的には 2 つの辺の長さを任意の順序で出力する必要があります。 

重要な問題は、どちらの側がどの次元に対応するかは知らされず、二値の実現可能性の神託しか得られないことです。 これにより、問題は 2 つの変数の単調述語に対する再構成タスクになります。 

単純なアプローチでは、すべてのペアをテストしようとします。$(a, b)$許可された範囲内でクエリを実行し、回答との一貫性をチェックしますが、これはすでに、各クエリにコストがかかる対話型設定では非効率であることを示唆しています。 さらに重要なことは、述語が対称的であるため、素朴な推論には曖昧さの危険があるということです。つまり、側を入れ替えても同じ答えが得られます。 

主な微妙なエッジケースは対称性です。 たとえば、非表示の四角形が$6 \times 4$、その後クエリを実行します$4 \times 6$そして$6 \times 4$どちらも成功を返すため、再構成戦略では方向を無関係なものとして扱い、マルチセットのみを回復する必要があります。$\{a, b\}$。 

## アプローチ

 インタラクションは単調条件を定義します: 長方形の場合$c \times d$適合する、その後任意$c' \le c$、$d' \le d$もフィットします。 これは、徐々に真の次元に近づくクエリを使用して境界情報を回復できることを示唆しています。 

ブルートフォース戦略では、すべてのペアをテストしようとします。$(c, d)$範囲内で$1 \le c, d \le 200$。 各ペアについて、それが適合するかどうかを審査員に尋ね、有効な候補者をすべて収集します。 ただし、これは構造を利用するものではありません。 最悪の場合、最大 40,000 のクエリが必要になりますが、これは 20 の制限をはるかに超えています。各候補ペアの実現可能性を論理的にチェックすることに限定したとしても、正しい四角形を明確にするためには、依然として多すぎるクエリが必要になります。 

重要な観察は、2 つの次元を分離できるということです。 固定プローブに適合する一方向の最大可能な辺の長さを決定できるとします。 片側を修正すると、次のようになります。$c = 200$、そして二分探索$d$、最大のものを見つけることができます$d$そのような$200 \times d$フィットします。 その値は次のとおりである必要があります$\min(a, b)$または少なくとも小さい方の側によって制限されます。 一方の長さを特定したら、もう一方の長さも同様に推定できます。 

より明確な観点は、両方の次元を順序付けされていないペアとして復元するだけでよいということです。 まず、正方形として適合する最大辺の長さを決定できます。これにより、次のようになります。$\min(a, b)$。 次に、その値を使用してプローブを修正し、互換性のある最大の 2 番目の側面を検索します。$\max(a, b)$。 

これにより、問題は 2 次元検索から 2 つの 1 次元単調検索に減り、それぞれ最大 8 つのクエリの二分検索で解決できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(200^2)$クエリ |$O(1)$| 遅すぎる |
 | 最適 |$O(\log 200)$クエリ |$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 私たちは、実現可能性が両方の次元で単調であり、向きが対称であるという事実に依存しています。 

1. まず、正方形を調べて長方形の小さい辺を決定します。$k \times k$。 最大の二分探索を行います$k$答えが肯定的になるように。 これが機能するのは、適合する正方形は次の条件を満たす必要があるためです。$k \le \min(a, b)$、プロパティはモノトーンです$k$。 
2. この値を次のようにします$s = \min(a, b)$。 これで、次の 1 つの次元がわかりましたが、さらに大きな側が必要です。 
3. 2 番目の側面を見つけるために、次を使用してプローブを固定します。$s$。 ここで最大の二分探索を行います$x$そのような$s \times x$フィットします。 もし$s$小さい方の辺と一致すると、$x$まで拡大します$\max(a, b)$。 誤って大きい方の辺を最初に一致させてしまった場合でも、対称性により同じ推論が依然として有効であることが保証されます。 
4. 見つけたら$x$、出力します$(s, x)$。 

重要な推論ステップは、一方の側がより小さい次元に固定されると、実現可能性述語がもう一方の変数で 1 次元の単調関数に崩壊することです。 

### なぜ効果があるのか

 正しさは 2 つの単調性に依存します。 まず、正方形のサイズの場合、$k$適合すると、すべての小さな正方形が適合し、二分探索が有効になります。 次に、片側を両方を超えない値に固定したら、$a$そして$b$、他の次元での実現可能性は単調なままであり、方向性とは独立しています。 これにより、二分探索により曖昧さなく真の境界が分離されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def ask(c, d):
    print("?", c, d)
    sys.stdout.flush()
    res = input().strip()
    if res == "-1":
        sys.exit(0)
    return int(res)

def solve():
    lo, hi = 1, 200
    best = 1

    while lo <= hi:
        mid = (lo + hi) // 2
        if ask(mid, mid):
            best = mid
            lo = mid + 1
        else:
            hi = mid - 1

    s = best

    lo, hi = 1, 200
    best2 = 1

    while lo <= hi:
        mid = (lo + hi) // 2
        if ask(s, mid):
            best2 = mid
            lo = mid + 1
        else:
            hi = mid - 1

    print("!", s, best2)
    sys.stdout.flush()

if __name__ == "__main__":
    solve()
```このソリューションは、フラッシュを強制し、終了条件を処理する単一のクエリ ヘルパーを中心に構成されています。 最初の二分探索では正方形のみが調査されるため、方向の処理が完全に回避されます。 2 番目の検索では、包含の単調性に依存して、一方の側を修正し、もう一方の側を拡張します。 

微妙な実装の詳細は、クエリが成功した後でも、常に最もよく知られている値を更新することです。 これにより、バイナリ検索が境界付近でオーバーシュートした場合でも正確さが保証されます。 もう 1 つの重要な詳細は、続行すると無効なインタラクションと判断されるため、-1 で即時に終了することです。 

## 実用的な例

 2 つの隠れた長方形をシミュレートします。 

最初の例:$a, b = 18, 12$。

 | 3 | 13×13 | 0 | 10 | 10 | - |
 | 4 | 11×11 | 1 | 11 | 11 | - |

このトレースは、正方形のプローブが制限次元にどのようにロックされ、2 番目の検索が直交辺を独立して拡張するかを示しています。

| ステップ | クエリ | 応答 | 最高の広場 |

 ## 特殊なケース

 重要なエッジ ケースは、一方の辺が 1 の場合です。その状況では、1 より大きいすべての正方形が即座に失敗するため、最初の二分探索はすぐに 1 に崩壊します。次に、次の形式のクエリがあるため、第 2 フェーズでは曖昧さなくもう一方の辺を直接回復します。$1 \times x$線形閾値テストとまったく同じように動作します。 

もう 1 つのエッジケースは次のような場合です$a = b$。 ここで有効なすべての正方形は次のとおりです$a$最初のフェーズで成功したため、アルゴリズムは正常に戻ります$s = a$。 第 2 フェーズでは、すべてのノードで同じ動作が見られます。$x \le a$、生産$x = a$同じように。 両方の次元が一致するため、対称性によって分岐の不確実性が生じることはなく、方向は決して重要ではありません。
