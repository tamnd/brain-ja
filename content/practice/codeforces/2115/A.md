### なぜ効果があるのか

 不変条件は、gcd 操作のシーケンスは、元の要素のサブセットの gcd を段階的に構築することに対応するということです。 どの操作でも、初期値のサブセットの gcd ではない値を導入することはできません。 したがって、値を構築する$1$これは、gcd が次のサブセットを選択することと同じです。$1$、各操作により、このサブセットのサイズが寄与要素 1 つだけ増加する可能性があります。 これにより、サブセットのサイズとその gcd を実現するために必要な操作の数の間に 1 対 1 の対応関係が確立されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import gcd
from collections import defaultdict

INF = 10**9

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        g = 0
        for x in a:
            g = gcd(g, x)

        b = [x // g for x in a]

        ones = b.count(1)
        if ones:
            print(n - ones)
            continue

        dp = {}

        for v in b:
            ndp = dp.copy()

            ndp[v] = min(ndp.get(v, INF), 1)

            for x, val in dp.items():
                ng = gcd(x, v)
                ndp[ng] = min(ndp.get(ng, INF), val + 1)

            dp = ndp

        k = dp[1]
        print(k + n - 2)

if __name__ == "__main__":
    solve()
```実装は DP 解釈に直接準拠します。 辞書`dp`は、到達可能な gcd 値を、その値を達成するために必要な最小のサブセット サイズとともに保存します。 新しい要素はそれぞれ、以前のすべての状態を更新し、新しいサブセットを開始するか既存のサブセットを拡張するかの選択を反映します。 すべての要素を処理した後、gcd の値が 1 に等しいと、重要なサブセット サイズが得られます。 

微妙な点は、反復ごとにコピーした辞書を使用することです。 これにより、同じ反復内での状態の上書きが回避され、各要素がサブセット構築で最大 1 回使用されることが保証されます。
