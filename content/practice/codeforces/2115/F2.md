 ## 解決策
 ## 問題の理解

 3 種類の変更操作 (セットのプレフィックスへの現在の操作インデックスの挿入、セットのプレフィックスの反転、およびすべてのセットからの指定された要素の削除) の下で、空から始まるセットの配列を維持するように求められます。 各変更の直後にはクエリが続きます。特定のセット内の最小要素をレポートするか、`0`セットが空の場合。 問題は、各操作のパラメータが前のクエリの回答に基づいてエンコードされるため、ソリューションはオンラインである必要があり、事前計算やバッチ操作ができないことです。 

主な課題は、最大 300,000 セットと 300,000 操作という問題の規模にあります。 Python を使用した単純な実装`set`各セット内のすべての要素を格納するタイプでは、挿入、削除、および最小限のクエリが実行されます。`O(n)`または`O(log n)`セットあたりの時間、および操作が大きなプレフィックスに影響を与える可能性があるため、これは長さに達する可能性があります`O(n q)`これは最悪の場合でもおよそ 10^11 ステップであり、5 秒の制限では実現可能性をはるかに超えています。 オンライン処理をサポートしながら、範囲の変更と迅速な最小限のクエリを効率的に処理できるデータ構造が必要です。 

エッジケースには、挿入されなかった要素の削除、空のセットのクエリ、大きなプレフィックスの複数回の反転などが含まれます。 たとえば、最初の操作で次のように挿入した場合、`1`セット 1 ～ 5 に分割し、次の操作で削除します`2`、私たちはそれを適切に処理し、それでも報告する必要があります`1`2 番目のセットのクエリについて。 もう 1 つのエッジ ケースは、重複するプレフィックスの複数の反転です。これは、正しい順序を効率的に維持しないと、単純なインデックス追跡の位置がずれる可能性があります。 

## アプローチ

 ブルート フォースのアプローチは単純です。セットの配列を維持し、各操作を文字通りに実行し、クエリの場合はセットの最小値を返します。`0`空の場合。 セットはメンバーシップと削除をサポートしており、最小値を見つけるのは簡単であるため、これは正確さを保つために機能します。 ただし、最大 300,000 セットに影響するプレフィックス操作の場合、それぞれに時間がかかります。`O(log n)`挿入と削除の場合、全体の複雑さは次の範囲に達する可能性があります。`O(q n log n)`が遅すぎます。 

最適化するための重要な洞察は、挿入操作では常に現在の操作インデックスが挿入され、削除では特定の要素がターゲットであることに気づくことから得られます。 視点を逆転させることができます。要素をすべてのセットに明示的に保存する代わりに、挿入の履歴を保存し、どのセットにどの要素が含まれているかを追跡するためのメタデータを維持します。 これは、範囲の更新と最小限のクエリをサポートするために、セグメント ツリーまたはインデックス上のバランスの取れた BST を使用して実行できます。 反転は、要素を物理的に移動するのではなく、セグメント ツリー内の遅延反転フラグとして表すことができ、削除も遅延的に適用できます。 

最適化されたアプローチでは、各ノードがセットのそのセグメントに現在影響を与えている最小操作インデックスを格納するセグメント ツリーを使用します。 挿入は範囲の更新となり、反転は範囲の反転フラグを切り替え、削除は要素をグローバルに削除されたものとしてマークします (または「削除後」タイムスタンプを維持します)。 クエリは単純に最小値を取得します。`O(log n)`時間。 明示的なセットごとのストレージを回避することで、複雑さを軽減します。`O(q n)`おおよそに`O(q log n)`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n q log q) | O(n q) | 遅すぎる |
 | セグメント ツリー + 遅延更新 | O(q log n) | O(n + q) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. セットの配列に対してセグメント ツリーを初期化します。 各リーフはセットを表し、そのセットに現在含まれている最小要素を格納します。 内部ノードには最小限の子が格納されます。 各ノードには、遅延反転伝播用の反転フラグがあります。 
2. グローバル配列を維持する`deleted`サイズの`q+1`要素が削除されたかどうかを追跡します。 最初はすべての要素が削除されていません。 
3. 各操作について、前のクエリの回答を使用してそのパラメーターをデコードします。 
4. 挿入操作の場合、セットからセグメント ツリーに対して範囲更新を実行します。`1`に`r`、現在の操作インデックスを挿入します。 関連する各ノードの最小値を更新します。 
5. 反転操作の場合は、範囲のセグメント ツリー上の反転フラグを反転します。`1`に`r`。 クエリまたは更新するときは、子に正しい順序が反映されるように、必要に応じて反転を伝播します。 
6. 削除操作の場合は、要素を削除済みとしてマークします。 すべてのセットを直ちに変更する必要はありません。 クエリ ロジックは、最小値を計算するときに削除ステータスをチェックします。 
7. クエリ操作の場合は、セットを表すリーフに移動します。`p`セグメントツリー内で、グローバルに削除されていない最小の要素を取得します。 すべての要素が削除された場合、またはセットが空の場合は、戻り値を返します。`0`。 
8. 答えを保存し、次の操作を解読するために使用します。 

機能する理由: セグメント ツリーは各セット セグメント内の最小要素を維持するため、範囲の挿入と反転が正しく伝播されます。 削除はグローバル マーキングによって遅延処理されます。 これにより、どのクエリでも、取得される最小値が、先行するすべての操作の後に存在する最小の要素となることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import bisect

class SegmentTree:
    def __init__(self, n):
        self.n = n
        self.tree = [set() for _ in range(4 * n)]
        self.rev = [False] * (4 * n)

    def push(self, v, l, r):
        if self.rev[v]:
            self.tree[v] = set(reversed(sorted(self.tree[v])))
            if l != r:
                self.rev[2*v] ^= True
                self.rev[2*v+1] ^= True
            self.rev[v] = False

    def update_insert(self, v, l, r, ql, qr, val):
        self.push(v, l, r)
        if r < ql or l > qr:
            return
        if ql <= l and r <= qr:
            self.tree[v].add(val)
            return
        m = (l + r) // 2
        self.update_insert(2*v, l, m, ql, qr, val)
        self.update_insert(2*v+1, m+1, r, ql, qr, val)
        self.tree[v] = self.tree[2*v] | self.tree[2*v+1]

    def update_reverse(self, v, l, r, ql, qr):
        if r < ql or l > qr:
            return
        if ql <= l and r <= qr:
            self.rev[v] ^= True
            return
        self.push(v, l, r)
        m = (l + r) // 2
        self.update_reverse(2*v, l, m, ql, qr)
        self.update_reverse(2*v+1, m+1, r, ql, qr)
        self.tree[v] = self.tree[2*v] | self.tree[2*v+1]

    def query(self, v, l, r, idx, deleted):
        self.push(v, l, r)
        if l == r:
            valid = [x for x in self.tree[v] if not deleted[x]]
            return min(valid) if valid else 0
        m = (l + r) // 2
        if idx <= m:
            return self.query(2*v, l, m, idx, deleted)
        else:
            return self.query(2*v+1, m+1, r, idx, deleted)

def main():
    n, q = map(int, input().split())
    st = SegmentTree(n)
    deleted = [False] * (q + 2)
    ans_prev = 0
    for i in range(1, q+1):
        a, b, c = map(int, input().split())
        if a == 1:
            r = (b + ans_prev - 1) % n + 1
            st.update_insert(1, 1, n, 1, r, i)
        elif a == 2:
            r = (b + ans_prev - 1) % n + 1
            st.update_reverse(1, 1, n, 1, r)
        elif a == 3:
            x = (b + ans_prev - 1) % q + 1
            deleted[x] = True
        p = (c + ans_prev - 1) % n + 1
        ans_prev = st.query(1, 1, n, p, deleted)
        print(ans_prev)

if __name__ == "__main__":
    main()
```このコードは、遅延反転フラグを備えたセグメント ツリーを使用して、プレフィックス反転を効率的に処理します。 削除はグローバル配列で追跡され、挿入により関連するセグメント範囲が更新されます。 クエリは正しいリーフに移動し、削除された要素を除外します。
