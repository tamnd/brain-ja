 ## 問題の理解

 このタスクは、算術平均、中央値、範囲の 3 つのプロパティが等しくなるように、ボックス内のキャンディーの数を表す 4 つの整数のセットを再構築することです。 これら 4 つの数値 (0 から 4) の一部が任意の順序で与えられます。 出力では、条件を満たすために欠落しているボックスに値を割り当てることが可能かどうかを確認し、可能であれば有効な割り当てを提供する必要があります。 

算術平均は 4 つの数値の合計を 4 で割ったもの、中央値は並べ替えられたときの中央の 2 つの数値の平均、範囲は最大数値と最小数値の差です。 条件が成立するには、これら 3 つの数値が等しい必要があります。 この等価性により、数値に強力な制約が作成されます。最小値と最大値が設定されると、他の 2 つは強制されるか、強く制限されることがよくあります。 

与えられたボックスの数、$n$は 0 ～ 4 と小さく、キャンディーの数自体は 1 ～ 500 と中程度です。これは、欠損数が非常に少なく (最大 4)、すべての可能な候補が妥当な範囲内にあるため、欠損数の可能な構成に対する総当たりまたは列挙アプローチが実行可能であることを示唆しています。 

与えられたボックスがすべて同じである場合、または極端な数値のみが与えられた場合には、明らかではないエッジケースが発生します。 たとえば、次の場合$n=2$2 つの数値が両方とも 1 である場合、条件を満たす唯一の方法は、中央値、平均値、および範囲がすべて一致するように、より大きな 2 つの数値を加算することです。 不用意に実装すると、数値が繰り返される可能性や、指定された数値の複数の順序が可能であることを考慮できない可能性があります。 

## アプローチ

 最も単純なアプローチは、指定された数値を含む 4 つの数値の考えられるすべてのセットに対してブルート フォースを実行することです。 候補ごとに並べ替え、平均、中央値、範囲を計算し、それらが等しいかどうかを確認します。 これが機能するのは、数値が最大 4 つあり、値を 1 ～ 500 の範囲で制限できる (または 500 まで拡張できる) ためです。$10^6$問題文の通り）。 ただし、組み合わせの数は有限ではあるものの、不必要な順列を避けるために慎重にチェックする必要があるため、総当り攻撃は退屈になります。 

重要な洞察は、4 つの数字についてです。$x_1 \le x_2 \le x_3 \le x_4$、算術平均、中央値、範囲はすべて数値に等しい$d$単純な構造を暗示します。4 つの数値は次の形式で表現できます。$[a, b, c, d] = [m - k, m - k, m + k, m + k]$またはその順列、ここで$m$中央値/平均/範囲です。 このことから、考慮する必要があるのは、いくつかの候補パターンだけです。つまり、すべての数値が等しいか、数値が 2 つの等しいペアを形成するかのいずれかです。 いくつかの数値が与えられると、不足している数値は代数を使用して直接計算できることがよくあります。 

この解決策は、指定された数値を含む可能性のあるすべての有効な「特殊な 4 倍数」を列挙し、欠落している数値が許容範囲内にあるかどうかを確認することによって進められます。 このアプローチにより、問題は少数の算術計算と条件チェックに縮小されます。

 ## アルゴリズムのチュートリアル

 1.読む$n$既存のキャンディー数のリスト。 既存の数値を並べ替えて、最小位置、最大位置、中央値の位置についての推論を簡素化します。 
2. 「特別な番号」の考えられるすべての候補値を列挙します。$d$平均値 = 中央値 = 範囲を表します。 欠落ボックスの可能性のある数に基づいて、有効な 4 倍体の構造から導出された式を使用して、欠落ボックスの潜在的な値を計算します。 たとえば、2 つの数値があり、パターンが必要な場合$[x, x, y, y]$を解決します$y$与えられた数字に関して。 
3. 各候補について、欠落している数値が整数であり、許容範囲 1 ～ 1 内にあるかどうかを確認します。$10^6$。 
4. 少なくとも 1 つの有効な割り当てが存在する場合は、「YES」と不足している数値を出力します。 それ以外の場合は「NO」を出力します。 

機能する理由: 平均値 = 中央値 = 範囲のプロパティを満たす 4 倍数は、すべての数値が等しいか、2 つの等しいペアの形式である必要があります。 これらのパターンに基づいて欠損数に代数的関係を体系的に適用することで、網羅的な列挙を行わずに、考えられるすべての解を生成できます。 この制約により、正の整数で解が存在する場合、それが 1 ～ の範囲内に収まることが保証されます。$10^6$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = sorted([int(input()) for _ in range(n)])
    
    # Helper to check if all numbers in a list are within 1..10^6
    def valid(lst):
        return all(1 <= x <= 10**6 for x in lst)
    
    # Try to complete the list to a special quadruple
    for x in range(1, 10**6 + 1):
        # All equal pattern
        if n == 0:
            print("YES")
            print(x)
            print(x)
            print(x)
            print(x)
            return
        if n == 1:
            needed = [x, x, x]
            if valid(needed):
                print("YES")
                for b in needed:
                    print(b)
                return
        if n == 2:
            b = 2 * x - sum(a)
            if valid([b, b]):
                print("YES")
                print(b)
                print(b)
                return
        if n == 3:
            b = 4 * x - sum(a)
            if valid([b]):
                print("YES")
                print(b)
                return
        if n == 4:
            if sum(a)/4 == x and (a[1]+a[2])/2 == x and a[3]-a[0] == x:
                print("YES")
                return
    print("NO")

if __name__ == "__main__":
    solve()
```コードは体系的に各候補の特殊番号を試行します。$x$既存のボックスの数に基づいて不足している数字を埋めます。 有効性チェックにより、数値が範囲内に収まることが保証されます。 並べ替えにより中央値の計算が簡素化され、一貫性が確保されます。 特殊なケース$n=0$または$n=4$明示的に処理されます。 

## 実用的な例

 サンプル 1:

 | n | | 候補者 x | 箱がありません |

 | 2 | [1,1] | 2 | [3,3] |

 アルゴリズムは計算します$b = 2*2 - (1+1) = 2$不足しているボックスに対してそれを複製し、[3,3] を生成します。 これは、予想されるパターン [1,1,3,3] と一致します。 

サンプル 2:

 | n | | 候補者 x | 箱がありません |
 | --- | --- | --- | --- |
 | 2 | [1,2] | 2 | 不可能 |

 コンピューティング$b = 2*2 - (1+2) = 1$[1,1] が欠損として生成され、平均 = 中央値 = 範囲を満たさない 4 倍の [1,2,1,1] が得られます。 アルゴリズムは「NO」を返します。
