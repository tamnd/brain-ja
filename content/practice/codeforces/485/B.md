 ## 解決策
 ## 問題の理解

 整数の座標を持つ点として表される、指定されたすべての鉱山を囲むように 2D デカルト マップ上に正方形の都市を構築するように求められます。 正方形の辺は軸と平行に保つ必要があり、私たちの目標は正方形の面積を最小限に抑えることです。 入力は次のもので構成されます`n`それぞれの点に座標が含まれる`(x_i, y_i)`、出力は正方形の最小面積を表す単一の整数です。 

制約が示すのは、`n`は最大 1000、座標は最大 ±10^9 まで可能です。 これは、複雑性がより劣るアプローチはすべて、`O(n)`または`O(n log n)`1000 ポイントは管理しやすいため、許容されます。 考えられるすべての正方形の位置を反復しようとするブルート フォース アプローチには、以下が含まれます。`O(n^2)`あるいはさらに悪いことに、1000 ポイントの場合はまだ実現可能ですが、より直接的な幾何学的なアプローチが存在するため、その必要はありません。 

エッジ ケースは、すべての点が直線上にある場合に発生します。たとえば、次のとおりです。```
2
1 1
1 5
```ここで、垂直線を覆う正方形は水平方向にも拡張する必要があるため、正方形の辺はいずれかの次元の最大の広がりによって決まります。 不注意なアプローチでは、正方形の辺が 2 つの差の大きい方である必要があることを考慮せずに、x または y の最大の差だけを個別に取得する可能性があります。 

もう 1 つの微妙なケースは、すべての点が同一である場合です。```
3
0 0
0 0
0 0
```ここで、正方形の辺の長さは 0、面積は 0 である必要があります。ゼロ面積を正しく処理することが重要です。 

## アプローチ

 素朴なアプローチは、正方形の隅として考えられるすべての左上と右下の点のペアを試し、それらをカバーするために必要な正方形の辺を計算し、見つかった最小面積を維持することです。 各ペアについて、すべてのポイントをチェックして、内側に収まるかどうかを確認します。 これにより、おおよその結果が得られます`O(n^3)`運用上でも非効率的です。`n = 1000`、最悪の場合、10^9 の演算が行われる可能性があります。 

重要な点は、正方形の辺が鉱山の最端の X 座標と Y 座標をカバーする必要があるということです。 させて`min_x`そして`max_x`最小および最大の X 座標、および`min_y`そして`max_y`最小および最大の y 座標。 すべての点をカバーする正方形は、少なくとも次の範囲にまたがる必要があります`max_x - min_x`水平方向と`max_y - min_y`垂直に。 正方形の形状を満たすために、これら 2 つのスパンのうち大きい方を辺の長さとします。 この観察により、問題は最小/最大値の単純な線形スキャンに帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべてのコーナー ペア) | O(n^3) | O(n) | 遅すぎる |
 | 最小値と最大値の削減 (最適) | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 極値の座標を追跡するために 4 つの変数を初期化します。`min_x`、`max_x`、`min_y`、 そして`max_y`。 セット`min_x`そして`min_y`非常に大きな値 (無限大) に設定し、`max_x`そして`max_y`非常に小さな値 (-無限大) まで。 
2. 各鉱山座標を反復処理します。`(x_i, y_i)`。 ポイントごとに更新します`min_x`もし`x_i`より小さく、`max_x`もし`x_i`より大きく、`min_y`もし`y_i`より小さく、そして`max_y`もし`y_i`の方が大きいです。 このステップでは、すべての鉱山の外接する長方形を見つけます。 
3. 正方形の必要な辺の長さを次のように計算します。`side = max(max_x - min_x, max_y - min_y)`。 これにより、等しい辺を維持しながら、正方形が両端によって定義される長方形をカバーできるようになります。 
4. 面積を次のように計算します。`area = side * side`そして結果を出力します。 

機能する理由: ポイントの境界四角形によって、すべての地雷をカバーするために必要な最小の幅と高さが決まります。 より大きな寸法を採用すると、すべての点をカバーしながら都市が正方形のままになることが保証されます。 少なくとも 1 辺が短すぎて 1 次元の極点をカバーできないため、これより小さな正方形ですべての地雷を囲むことはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
min_x = float('inf')
max_x = float('-inf')
min_y = float('inf')
max_y = float('-inf')

for _ in range(n):
    x, y = map(int, input().split())
    if x < min_x:
        min_x = x
    if x > max_x:
        max_x = x
    if y < min_y:
        min_y = y
    if y > max_y:
        max_y = y

side = max(max_x - min_x, max_y - min_y)
area = side * side
print(area)
```上記のコードは、アルゴリズムのステップを直接反映しています。 の使用`float('inf')`そして`float('-inf')`最初の点が極値を正しく初期化することを保証します。 最小値/最大値を個別に更新すると、特に負の座標の場合、1 つずつずれてしまうミスを回避できます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | すべての点を単一パスして最小/最大座標を計算します。 
| スペース | お(1) | n | に関係なく、極値を追跡する変数は 4 つだけです。 

与えられた`n`≤ 1000 の場合、このアルゴリズムはほぼ即座に実行されます。 メモリの使用量はわずかです。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    min_x = float('inf')
    max_x = float('-inf')
    min_y = float('inf')
    max_y = float('-inf')

    for _ in range(n):
        x, y = map(int, input().split())
        min_x = min(min_x, x)
        max_x = max(max_x, x)
        min_y = min(min_y, y)
        max_y = max(max_y, y)

    side = max(max_x - min_x, max_y - min_y)
    return str(side * side)

# Provided sample
assert run("2\n0 0\n2 2\n") == "4", "sample 1"

# Minimum size input
assert run("2\n0 0\n0 0\n") == "0", "all points identical"

# Vertical line
assert run("2\n1 1\n1 5\n") == "16", "vertical line"

# Horizontal line
assert run("2\n3 7\n8 7\n") == "25", "horizontal line"

# Maximum spread
assert run("4\n-1000000000 -1000000000\n1000000000 1000000000\n0 0\n-500000000 500000000\n") == "4000000000000000000", "large coordinates"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 2 つの同一点 | 0 | ゼロエリアの場合 |
 | 縦線 | 16 | 辺は y 差と等しくなければなりません |
 | 水平線 | 25 | 辺は x 差と等しくなければなりません |
 | 大きい座標 | 4e18 | オーバーフローせずに極端な座標値を処理します。 

## 特殊なケース

 次のような同一の点については、`2\n0 0\n0 0`、`min_x = max_x = min_y = max_y = 0`、側面 = 0、面積 = 0。アルゴリズムはこれを正しく処理します。`max(max_x - min_x, max_y - min_y)`それは0です。 

縦ラインの場合`2\n1 1\n1 5`、`min_x = max_x = 1`、`min_y = 1`、`max_y = 5`、side = max(0, 4) = 4、area = 16。アルゴリズムは、正方形の辺として最大の寸法を正しく選択します。 

横線の場合`2\n3 7\n8 7`、`min_x = 3`、`max_x = 8`、`min_y = max_y = 7`、side = max(5, 0) = 5、area = 25。ここでも、正方形の辺が正しく識別されます。
