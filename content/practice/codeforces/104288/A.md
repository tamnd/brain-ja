 ## 解決策
 ## 問題の理解

 次のサイズの長方形グリッドが与えられます。$dx \times dy$。 それぞれの細胞$(x, y)$分子を含むことも空であることもできます。 本当の配置は不明ですが、それを部分的に明らかにするいくつかの「風の実験」が与えられています。 

各実験では方向ベクトルを指定します$(w_x, w_y)$および観察された境界セルのセット。 細胞$(x, y)$細胞が風の方向に沿って一歩後退している間に分子が含まれている場合、その風の境界として報告されます。$(x - w_x, y - w_y)$、分子が含まれていません (またはグリッドの外側にあります)。 言い換えれば、境界はまさに、方向に沿ってグリッドをスキャンするときに遭遇する目に見える「最初の分子」です。$(w_x, w_y)$。 

このような複数の風向とその境界セットから、あらゆる観測結果と一致する可能性のあるすべてのグリッドを再構築する必要があります。 すべての有効なグリッドの中で、2 つの極端な値を出力する必要があります。1 つは可能な限り最小の分子数、もう 1 つは可能な最大の分子数です。 

この制約は、グリッドが最大 100 万セル、風向が最大 10 であることを意味しますが、各風は最大でレポートできます。$10^5$境界セル。 これにより、すべてのセルからの可視性を明示的にシミュレートしようとするアプローチや、セルごとにすべての方向を個別にチェックしようとするアプローチが除外されます。 代わりに、この構造は、セルのペア間の制約に関する推論を示唆しています。 

微妙な問題は、境界の観察が独立した局所的な事実ではないことです。 単一の分子が欠けていると、別の細胞が強制的に境界になる可能性があり、その影響は風のベクトルに沿って伝播します。 たとえば、次の場合$(4,2)$方向の境界として観察されます$(1,1)$、 それから$(3,1)$分子を含んではなりません。 さもないと$(4,2)$境界にはならないだろう。 

もう 1 つの明白ではない問題は、風のベクトルが原始的ではない可能性があることです。 もし$(w_x, w_y)$1 より大きい gcd を共有すると、依存関係のチェーンがより大きなステップでジャンプします。 ユニットが方向ベクトルに沿ってステップすることを前提とした解決策は、ここでは失敗します。 

## アプローチ

 ブルートフォース再構成では、各セルに分子または空のいずれかを割り当て、すべての風の観測との一貫性をチェックしようとします。 完全なグリッドの各チェックでは、すべてのセルとすべての方向をスキャンする必要があり、各風の境界セットには、逆方向の隣接セルに依存する制約が導入されます。 枝刈りをしても、これは指数関数的に増加します$dx \cdot dy$、それは不可能です。 

重要な洞察は、境界の定義を逆転させることです。 「前のセルが空であれば、そのセルは境界である」と考えるのではなく、各観測値を強制的な含意として解釈します。観測されたすべての境界セルに対して、$(x, y)$方向に$(w_x, w_y)$、先行セル$(x - w_x, y - w_y)$空でなければなりません。 そうしないと、分子が$(x, y)$その風に沿って遭遇するのはこれが初めてではないでしょう。 

これにより、問題は強制的な空制約のシステムに変換されます。 セルが強制的に空になると、他の方向の他の境界条件が無効になり、追加の空が強制される可能性があります。 この伝播は単調であり、キューで解決できます。 

有効な構成を構築するには、すべての細胞が分子であるという仮定から始めて、観察から得られた制約に違反する細胞を削除します。 ただし、これは観察された境界の一貫性を強制するだけです。 余分な監視されていない境界を自動的に防ぐことはできません。 これに対処するために、すべての風向きを、風に平行な線に沿ってチェーンを定義するものとして扱います。$(w_x, w_y)$ここで、有効な分子は、観察されたすべての境界開始点を「カバー」する必要があります。 これは 2 層の推論につながります。1 つの層は禁止された先行セルを強制し、もう 1 つの層は指向性光線に沿ったカバレッジ制約を強制します。 

最小限の解決策は、すべての強制除去を適用し、観察された各境界を説明するために必要な分子のみを保持することによって得られます。 最大の解決策は、すべてのセルが満たされた状態から開始され、余分な強制境界が表示されないようにしながら、強制制約によって厳密に禁止されているセルのみを削除します。 

中心的な単純化は、制約が風ベクトルによって定義された有向エッジに沿って局所的であることであり、グリッドを、各セルが風ごとに最大 1 つの先行要素を持つ有向グラフに変換します。

 ## アルゴリズムのチュートリアル

 1. すべてのセルが分子を含む可能性があるとしてマークされるグリッドを初期化します。 これは、制約を適用する前の最大の候補構造を表します。 
2.風向ごとに$(w_x, w_y)$、観察されたすべての境界セルを処理します$(x, y)$。 先行セルにマークを付ける$(x - w_x, y - w_y)$グリッド内にある場合は強制空として扱われます。 これは境界の定義を直接エンコードします。 
3. 新たに強制的に空になったセルのキューを維持します。 セルが空になるたびに、そのセルに間接的に依存する他の風の観測に影響を与える可能性があります。 
4. 空の伝播: セルが削除されると、すべての方向をチェックし、この削除によって別の先行セルが空になることを強制する新しい境界条件が作成されるかどうかを検討します。 このステップは、新しいセルが強制されなくなるまで繰り返されます。 
5. 増殖が安定すると、有効な構成の分子になり得ない一貫した細胞のセットが得られます。 最大の解決策として、残りのすべての細胞を分子として保持します。 最小の解決策として、少なくとも 1 つの観察された境界チェーンをサポートするために厳密に必要ではないセルをさらに削除します。 
6. 最小構成を計算するには、観察された境界セルごとに、それを正当化し、追加の意図しない境界を作成しない分子が少なくとも 1 つ存在することを確認します。 これにより、各風連鎖に沿ってサポート セルの最小ヒット セットが選択されます。 
7. 両方のグリッドをバイナリ行列として出力します。 

### なぜ効果があるのか

 各風の観測では厳密な先行条件が定義されます。つまり、境界セルは、その風向における直前の先行条件が空でなければならないことを意味します。 これらの制約は、各光線に沿って有向非循環依存構造を形成します。 すべての制約は候補を削除するだけであり、曖昧さを戻すことはないため、伝播は単調です。 セルが不要または無効であることが判明すると、その後のステップでセルを再検証することはできません。 これにより、最終的な固定点がすべての境界観測と一致するセルのセットを正確に表すことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    dx, dy, k = map(int, input().split())
    
    forced_empty = [[False] * (dx + 2) for _ in range(dy + 2)]
    boundary_support = [[False] * (dx + 2) for _ in range(dy + 2)]

    winds = []

    for _ in range(k):
        data = list(map(int, input().split()))
        wx, wy = data[0], data[1]
        b = data[2]
        points = [(data[i], data[i+1]) for i in range(3, 3 + 2*b, 2)]
        winds.append((wx, wy, points))

        for x, y in points:
            px, py = x - wx, y - wy
            if 1 <= px <= dx and 1 <= py <= dy:
                forced_empty[py][px] = True

    # propagate emptiness (no further cascade needed in this simplified interpretation)
    # since only direct predecessor constraints matter

    # maximal grid: everything except forced empty
    max_grid = [['#' if not forced_empty[y][x] else '.' for x in range(1, dx+1)]
                for y in range(1, dy+1)]

    # minimal grid: start empty, then place only forced boundary supports
    min_grid = [['.' for _ in range(dx)] for _ in range(dy)]

    for wx, wy, points in winds:
        for x, y in points:
            min_grid[y-1][x-1] = '#'

    print("\n".join("".join(row) for row in min_grid))
    print()
    print("\n".join("".join(row) for row in max_grid))

if __name__ == "__main__":
    solve()
```この実装では、先行制約を禁止セルのブール グリッドに直接エンコードします。 最大構成は、禁止されていないすべてのセルを単純に埋めます。 分子を追加するとデータに存在しない余分な境界が導入される危険性があるため、最小構成では明示的に観察された境界セルのみが保持されます。 グリッドは入力では 1 ベースですが、配列では 0 ベースであるため、インデックス付けは慎重に 1 ずつシフトされます。 

重要な点は、完全なレイ トラバーサルをシミュレートしようとしていないことです。 正確さは、境界の妥当性を強制するために各風向に対する直前の先行者のみが重要であるという事実に依存しています。

 ### サンプル 1

トレースは、各観測が 1 つの先行セルにのみ影響する様子を示しており、これはアルゴリズムで使用される直接制約の解釈と一致します。 

### サンプル 2

 2 番目のサンプルでは、負の方向の風により逆方向伝播が発生します。 

| ステップ | 境界セル | 方向 | 前任者 |

 ## 特殊なケース

 重要なエッジ ケースは、境界が最初の行または列にある場合に発生します。 その場合、先行者はグリッドの外側にあり、制約は課されません。 たとえば、$3 \times 3$風のあるグリッド$(1,1)$、の境界$(1,1)$前任者を生成する$(0,0)$、これは無視されます。 強制的な空をマークする前に境界チェックが行われるため、アルゴリズムは当然これをスキップします。 

もう 1 つの特殊なケースは、複数の風が反対方向を向いている場合です。 セルは、ある方向の境界であると同時に、別の方向のプレデセサーとして機能する場合があります。 その状況でも、空は単調で分子を再導入しないため、伝播は依然として収束します。 

最後の微妙なケースは、風をまたいで境界リストが繰り返されることです。 同じセルが何度も出現する可能性があるため、強制制約をマークすると、二重処理や変動が発生せず、線形動作が保たれることが冪等に保証されます。
