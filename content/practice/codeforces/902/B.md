 ## 解決策
 ## 問題の理解

 _n_ 個の頂点を持つルート付きツリーが与えられます。頂点 1 がルートです。 各頂点は、入力で指定されたターゲット カラーで色付けする必要があります。 最初は、すべての頂点はカラー 0 です。カラーリング操作は、任意の頂点 _v_ とカラー _x_ を選択し、_v_ をルートとするサブツリー内のすべての頂点を _x_ でカラーリングすることで構成されます。 タスクは、すべての頂点で目標のカラーリングを実現するために必要な操作の最小数を見つけることです。 

入力はツリーを親配列として指定します。各エントリ _p_i_ は頂点 _i_ の親を示します。 色はサイズ _n_ の配列として指定されます。 出力は単一の整数、つまり色付け操作の最小数です。 

制約により、_n_ は最大 10⁴ であることがわかります。 頂点のすべてのサブセットまたはすべての可能な操作シーケンスを調査する総当りシミュレーションでは、操作の数が指数関数的に増加するため、非常に時間がかかりすぎます。 1 秒あたり約 105 回の操作が可能なため、線形時間アプローチ、理想的には O(n) が必要です。 

子が親と同じターゲットカラーを持つ場合、微妙なエッジケースが発生します。 単純なアプローチでは、子の色付けを別の操作としてカウントする可能性がありますが、親の色付けによってそのサブツリーがすでに設定されているため、追加の手順は必要ありません。 もう 1 つのケースは、ルート自体が 0 以外の色を持つ場合です。最初はすべての色が 0 であるため、これは常に最初の操作としてカウントされなければなりません。 たとえば、ルートがカラー 2 で、すべての子がカラー 2 である場合、答えは n ではなく 1 になります。 

## アプローチ

 ブルートフォース手法では、各頂点を個別に色付けするか、可能なすべてのサブツリーの色付けを再帰的にシミュレートしようとします。 葉から始めて、親に色を付けることが役立つかどうかをチェックすることは想像できますが、各操作の後にツリー全体の正確な状態を追跡するのは面倒で時間がかかります。 最悪の場合、各操作でサブツリー全体の走査が必要になる可能性があるため、O(n²) 回の操作が必要になります。 

重要な洞察は、サブツリーの色付けを明示的にシミュレートする必要がないということです。 カラーリング操作は、頂点のカラーが親から継承するカラーと異なる場合にのみ重要であることに注意してください。 頂点の色が親と同じ場合、親のサブツリーが色付けされると、頂点はすでに正しく色付けされます。 逆に、頂点がその親と異なる場合は、この頂点、またはそれを含むその祖先の 1 つでカラーリング操作を実行する必要があります。 したがって、最適な戦略は、ツリーを走査し、親と色が異なる各頂点を数えるというものです。 ルートは特別に扱われます。ルートには親がないため、ルートのゼロ以外の色は常に 1 つの操作としてカウントされます。 

この観察により、問題はツリー上の単一の DFS に帰着します。 各頂点について、そのターゲット カラーとその親のターゲット カラーを比較し、異なる場合は操作カウントを増加します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 入力を解析して、隣接リストとしてツリーを構築します。 各頂点は、簡単に走査できるように子のリストを保持します。 
2. 操作用のカウンタを初期化します。 ルートの色が 0 以外の場合、カウンターを 1 つ増やします。 これは、ルートでの最初の色付け操作を表します。 
3. ルートから開始して DFS を実行します。 訪問した各頂点について、そのターゲットの色とその親の色を比較します。 色が異なる場合は、動作カウンタをインクリメントします。 その理由は、親と異なる色の頂点は親の色を継承できないため、明示的な操作が必要になるためです。 
4. すべての子に対して DFS を再帰的に続行します。 ツリーは接続されており非循環であるため、この走査は各頂点を 1 回だけ訪問します。 
5. DFS が完了すると、カウンターには必要な最小限の操作が含まれます。 

機能する理由: カラーが親と一致するすべての頂点は、親のカラーリング操作によって自動的に処理されます。 明示的な操作が必要なのは、異なる色の頂点のみです。 ツリーを 1 回走査し、これらの頂点を数えることで、冗長性を持たずに必要な操作がすべて考慮されます。 DFS は頂点を見逃さないことを保証し、カラーリングのサブツリー プロパティにより、親子の色の違いのみをカウントするだけで十分であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(100000)

def main():
    n = int(input())
    parents = list(map(int, input().split()))
    colors = list(map(int, input().split()))
    
    tree = [[] for _ in range(n)]
    for i, p in enumerate(parents, start=1):
        tree[p-1].append(i)
    
    operations = 0
    
    def dfs(v, parent_color):
        nonlocal operations
        if colors[v] != parent_color:
            operations += 1
        for child in tree[v]:
            dfs(child, colors[v])
    
    dfs(0, 0)
    print(operations)

if __name__ == "__main__":
    main()
```この解決策は、親配列からツリーを構築することから始まります。 DFS 関数は、現在の頂点とその親の色を受け取ります。 各頂点の色が親と異なる場合、操作カウンターをインクリメントします。 現在の頂点の色をその子に渡して、同じ比較ができるようにします。 使用する`sys.setrecursionlimit`DFS が大きなツリーの再帰制限に達しないようにします。
