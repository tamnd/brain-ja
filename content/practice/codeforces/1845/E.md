 ## 解決策
 ## 問題の理解

 の行が与えられています`n`箱にはボールが入っているものもあれば、空のものもあります。 許可される操作は、隣接性を連続インデックスとして定義して、ボックスから隣接する空のボックスにボールを移動することです。 まさにその後`k`このような動きでは、ボックス内のボールの個別の構成の数を法で数えるよう求められます。`10^9 + 7`。 

この問題は基本的に、単純なローカル遷移を伴う離散システム内の到達可能な状態の数を求めます。 各ボックスの状態を指定できます`0`または`1`、トランジションは移動に限定されます。`1`隣へ`0`s. と`n`1500までと`k`1500 までは、状態の数が指数関数的に増加するため、すべての一連の動きを列挙する強引な方法は絶望的です。 これは、動的プログラミングが適切なツールであることを強く示唆しています。 

エッジケースは、ボールが一端に集まっているか、位置のサブセットのみに到達できるように広がっている場合に発生します。 たとえば、入力が`1 1 0 0`そして`k = 1`、ボールは 1 つだけ移動できるため、2 つの配置が可能です。 すべてのボールをあらゆる順序で動かす単純なシミュレーションでは、構成が 2 倍になったり、制限時間を超えたりする可能性があります。 複数のボールが異なるシーケンスで同じ空のボックスに移動する可能性がある場合、別の微妙な問題が発生します。これらのシーケンスでは最終的な構成が同じになるため、オーバーカウントを避ける方法が必要です。 

## アプローチ

 ブルートフォース ソリューションでは、すべてのシーケンスをシミュレートしようとします。`k`動く。 各ステップで、最初のボックスにボールが含まれ、2 番目のボックスが空である隣接するボックスのすべてのペアを識別し、ボールを移動し、再帰的に続行します。 このアプローチには、最大で分岐係数があります。`n`各ステップで結果が得られます`O(n^k)`可能なシーケンスですが、これは完全に不可能です`n, k`1500まで。 

重要な観察は、この問題は、隣接するスワップのみが許可され、ボールの位置によって定義される状態空間内で四球を数えるとしてモデル化できるということです。 シーケンスを追跡するのではなく、ある状態に到達する方法の数を正確に追跡できます。`k`動的計画法を使って動きます。 定義する`dp[i][j]`正確に移動する方法の数として`j`最初にボールを入れる`i`最大で使用するボックス`k`動く。 状態遷移は、ボールを特定の位置に移動するのに必要な移動回数を数えることによって決まります。 これにより、複雑さが指数関数から多項式に軽減されます。 

もう 1 つの有益な観察は、ボールが独立して動き、それぞれの動きが相対的な位置に影響を与えることです。 この問題は、非負の整数列を数えるというものとして再構成できます。`x1, x2, ..., xm`ボールが左右に移動する空のボックスの数を表します。`sum(xi) = k`。 これは組み合わせ DP につながります。ボールとゼロの連続するセグメントごとに、それらの間で動きを分配した後、配置の数を計算します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^k) | O(n^k) | 遅すぎる |
 | ボール位置の動的プログラミング | O(n^2 * k) | O(n * k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力を解析してボールの初期位置を決定します。 位置をリストに保存する`balls`。 ボールの数を決める`m`そして空箱の数`n-m`。 
2. DP テーブルを定義する`dp[i][j]`どこ`i`以上の範囲`0..m`(考慮されるボールの数) および`j`以上の範囲`0..k`(実行された移動の数)。`dp[i][j]`正確に分配する方法の数を保存します`j`最初の間で移動します`i`ボールを使用して、明確な最終配置を生成します。 
3.初期化`dp[0][0] = 1`、ゼロ手でゼロボールを表します。 
4. 各ボールを反復処理します。`b`（から`i = 1`に`m`）。 それぞれについて`j`で`0..k`、このボールを最大まで移動することを検討してください。`max_shift`現在の空のセグメント内の左または右に位置します。 必要な移動数は、元の位置からの距離に等しい。 アップデート`dp[i][j + moves_needed] += dp[i-1][j]`モジュロ`10^9 + 7`。 
5. すべてのボールを処理した後、答えは次の合計になります。`dp[m][k]`すべての有効なディストリビューションにわたって。 これにより、到達可能なすべての配置が正確にカウントされます。`k`同じ構成になるシーケンスを過剰にカウントせずに移動します。 

なぜ機能するのか: DP は次の不変条件を維持します。`dp[i][j]`最初の構成のすべての個別の構成をカウントします。`i`ボールを正確に使用する`j`動く。 ボールを段階的に処理し、ボール間で動きを分配することにより、到達可能なすべての有効な最終ポジションを考慮します。`k`動く。 組み合わせトランジションはオーバーラップを正しく処理し、配置が 2 回カウントされることを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

n, k = map(int, input().split())
a = list(map(int, input().split()))

balls = [i for i, val in enumerate(a) if val == 1]
m = len(balls)
dp = [[0] * (k + 1) for _ in range(m + 1)]
dp[0][0] = 1

for i in range(1, m + 1):
    pos = balls[i - 1]
    for j in range(k + 1):
        if dp[i - 1][j] == 0:
            continue
        for move in range(k - j + 1):
            # calculate new position index bounds
            left_bound = i - 1  # minimum left shifts (cannot cross previous ball)
            right_bound = n - m + i - 1  # maximum right shifts (cannot cross next empty)
            new_pos = pos + move
            if left_bound <= new_pos <= right_bound:
                dp[i][j + move] = (dp[i][j + move] + dp[i - 1][j]) % MOD

print(dp[m][k])
```このソリューションでは、まずボールの位置を収集してインデックス作成を簡素化します。 DP テーブルはゼロで初期化され、`dp[0][0] = 1`基本ケースの場合。 各ボールについて、隣接性の制約を考慮して、許可されたセグメント内でボールが移動できるすべての方法を考慮します。 前のボールと重複する動き、または合計手を超える動き`k`無視されます。 オーバーフローを防ぐために、各ステップでモジュロ演算が適用されます。
