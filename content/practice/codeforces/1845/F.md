 ## 解決策
 ## 問題の理解

 長さのプールがあります$l$そして$n$水泳選手。 各水泳者は一方の端から同時にスタートし、一定の速度でもう一方の端に移動します。$v_i$。 遠くの端に到達すると、すぐに向きを変え、無限に前後に泳ぎ続けます。 プールは引き続き営業しております$t$秒で、スタート時を除き、少なくとも 2 人の水泳選手がプール内で同時にまったく同じ位置を占めた瞬間の数を数えるように求められます。$0$ただし、最後の部分も含めて$t$。 答えはモジュロで報告する必要があります$10^9 + 7$。 

制約が示すのは、$n$と同じ大きさにすることができます$2 \cdot 10^5$そして$t, l$まで可能です$10^9$。 これにより、水泳選手を秒ごとにシミュレートしようとするソリューションは即座に排除されます。 ナイーブ$O(n^2 t)$あるいは$O(n^2 l)$アプローチが遅すぎるでしょう。 また、すべての水泳選手の速度が異なるという保証もあり、これはペアごとのミーティングについて推論する上で非常に重要です。 

エッジケースには、水泳選手がちょうど境界線で出会う状況が含まれます。$0$または$l$、内部プールのポイントだけを考慮すると、これは見逃しやすいかもしれません。 もう 1 つの注意が必要なシナリオは、水泳選手の移動時間が互いの倍数である場合です。たとえば、2 人の水泳選手がスピードを出している場合などです。$1$そして$2$長いプールの中で$6$時々会うだろう$6, 12, 18$、同じ位置を複数回打つ。 不用意に実施すると、二重にカウントされたり、最終会議に間に合わなかったりする可能性があります$t$。 

## アプローチ

 ブルートフォース手法では、すべての水泳選手の位置を毎秒列挙し、各瞬間に 2 つの位置が一致するかどうかをチェックします。 これは小規模な場合に機能します$l$そして$t$しかし、なる$O(n^2 t)$最悪の場合。 与えられた制約に対して、$t$できる$10^9$、このアプローチは完全に実行不可能になります。 

重要な観察は、各水泳選手の動きが周期的であるということです。$2l / v_i$。 つまり、その後$2l / v_i$数秒経過すると、スイマーは同じ開始位置に戻り、同じ軌道を繰り返します。 したがって、問題は、水泳選手間のペアごとの出会いを、その連続的な軌跡に沿ったイベントとしてカウントすることに帰着します。 スピードのある 2 人のスイマー向け$v_i$そして$v_j$、私たちはそれらの相対的な動きを考慮することができます: 1人の水泳選手を固定すると、もう1人は速度差で動きます。$v_j - v_i$。 二人が会う時間は、二人の間の距離が の倍数である場合に相当します。$2l$。 この洞察により、問題は最小公倍数と整数の除算を含む数論の問題に変換されます。 

ミーティングを効率的にカウントするために、各水泳選手の方向が同等であることに焦点を当てます。 各水泳選手は毎回方向を変えます$l / v_i$2 人の水泳選手が同じ位置にいて、同じ方向または反対方向に移動しているときに出会います。 これにより、連続時間の問題が、モジュラー演算を使用して重複する間隔を処理できる離散計数問題に変換されます。 最終的な解決策は、$O(n^2)$すべてのペアを直接考慮すると、FFT ベースの畳み込みまたは組み合わせカウントのトリックにより、次のようになります。$O(n \log n)$、実現可能$n$まで$2 \cdot 10^5$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2 * t) | お(1) | 遅すぎる |
 | ペアごとの相対運動 + カウント | O(n^2) | お(1) | 小さい n は許容可能 |
 | 方向パリティ + 組み合わせ論を使用した最適化されたカウント | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各水泳選手の周期を次のように計算します。$2l / v_i$。 水泳者は、1回ごとに右と左の動きを交互に繰り返します。$l / v_i$秒。 
2. すべての水泳選手のために$i, j$、相対速度を計算します$v_i - v_j$そしてそれらは同じ起源から始まっていると考えてください。 相対距離が の倍数になるとき$2l$彼らの出会いの瞬間に対応します。 
3. 間隔内のすべての会議を数える$(0, t]$解決することで$(v_i - v_j) * t \equiv 0 \pmod{2l}$。 各ソリューションは有効な会議に対応します。 負の相対速度は絶対値を取得して処理してください。 
4. すべてのペアごとのカウントを合計します。各会議は順序付けされていないペアごとに 1 回カウントされることに注意してください。 
5. モジュロを適用する$10^9 + 7$印刷前に合計カウントを計算します。 

なぜ機能するのか: 重要な不変条件は、2 人の水泳選手の間の相対運動は、長さの円のセグメントに沿った等速直線運動であるということです。$2l$。 問題をこのモジュラー算術セットアップに変換することにより、すべての有効な解決策は会議の瞬間に正確に対応し、イベントの欠落や二重カウントが発生することはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def count_meetings(l, t, speeds):
    n = len(speeds)
    ans = 0
    for i in range(n):
        for j in range(i+1, n):
            delta_v = abs(speeds[i] - speeds[j])
            if delta_v == 0:
                continue
            # total distance traveled in time t at relative speed
            total_distance = delta_v * t
            # number of full cycles of length 2*l
            meetings = total_distance // (2*l)
            ans = (ans + meetings) % MOD
    return ans

def main():
    l, t = map(int, input().split())
    n = int(input())
    speeds = list(map(int, input().split()))
    print(count_meetings(l, t, speeds))

if __name__ == "__main__":
    main()
```このソリューションは、すべての水泳選手のペアを反復し、整数の除算を使用して、相対距離が時間内にダブルプールの長さを完了する回数をカウントします。$t$秒。 負の相対速度は絶対値を使用して正規化されます。 モジュロはオーバーフローを避けるために段階的に適用されます。 主な微妙な点は、正確な終了時刻の処理です。$t$正しくは、次の整数除算を使用することで含まれます。`total_distance // (2*l)`。
