 ## 解決策
 ## 問題の理解

 目標金額が達成できるかどうかを決定するように求められます。`n`以下の任意の数の整数を使用して形成できます。`1`に`k`、単一の禁止された整数を除く`x`。 可能であれば、合計が正確に次のとおりである有効な整数シーケンスを 1 つ構築する必要があります。`n`。 各テスト ケースでは、次の 3 つの整数が提供されます。`n`(目標金額)、`k`(利用可能な最大の整数)、および`x`(禁止された整数)。 

制約は小さいです。`n`、`k`、 そして`x`最大 100 個であり、最大 100 個のテスト ケースを含めることができます。 これにより、およそ O(n²) の複雑さのアルゴリズムが可能になりますが、より単純な O(n) または O(1) の構成的なアプローチが推奨されます。 許可された各数値の無制限のコピーが許可されるため、問題は集合から数値の複数集合を見つけることになります。`[1, k] \ {x}`つまり、`n`。 

エッジケースは、禁止された整数の場合に発生します。`x`非常に小さいか非常に大きいかのどちらかです。 たとえば、次の場合`x = 1`そして`n = 1`、許可される最小数は 2 であるため、合計を計算することはできません。同様に、次の場合`x = k = 1`、使用可能な整数のセットは空であり、任意の正の整数`n`不可能です。 もう 1 つの微妙な点は、`n`許容される最小数より小さいです (例:`n = 2`しかし`1`は禁止されています）、ターゲットに到達することは不可能です。 

## アプローチ

 ブルート フォース ソリューションでは、次の整数のすべての組み合わせが試行されます。`1`に`k`除く`x`。 これは、再帰的に、または動的プログラミングを使用して実装できます。 時間計算量は高く、潜在的に O(n・k) であり、小規模な場合には不要です。`n`。 

重要な観察によって問題が単純化されます。許可された整数のコピーを無制限に使用できるため、次のことを確認するだけで済みます。`n`許可される最小の整数のコピーを繰り返し使用して形成できます。 もし`1`禁止されていません、いつでも結成できます`n`取ることによって`n`のコピー`1`。 もし`1`禁止されていますが、`2`許可されています、`n`少なくとも`2`2 の合計 (または、2 と 3 が利用可能な場合はそれらの組み合わせ) として書くことができます。 構築的な性質により、単純な貪欲なシーケンスを出力することができます。つまり、許容される最小の整数を可能な限り入力し、必要に応じて次に小さい整数で調整します。 

この洞察により、問題は、許容される最小の整数を単純にチェックし、合計を直接構築することに帰着します。これにより、テスト ケースごとに O(n) 時間が得られ、十分な速さになります。

 ## アルゴリズムのチュートリアル

 1. 許可される最小の整数を特定する`a`。 これは 1 (の場合) のいずれかです。`x != 1`) または 2 (場合`x = 1`そして`k >= 2`）。 もし`x = 1`そして`k = 1`、整数は使用できません。答えは「いいえ」です。 
2. 次のことを判断します。`n`を使用して到達可能です`a`。 もし`n < a`、形成できないため「NO」を出力します`n`より大きい整数`n`。 それ以外の場合は、シーケンスの構築に進みます。 
3. 貪欲にシーケンスを構築します。 もし`a = 1`、 取る`n`1のコピー。`a = 2`、 そして`n`均等です、取る`n / 2`2 のコピー。`n`奇妙であり、`k >= 3`そして`3`許可されている場合は、3 を 1 つ取り、`(n - 3)/2`そうでない場合は不可能です。 
4. 「YES」、シーケンス内の整数の合計数、およびシーケンス自体を出力します。 

これが機能する理由: 許容される最小の整数は、最も柔軟性が高いため、合計の構築に優先されます。 任意の合計`n`少なくとも許容される最小の整数である場合は、その整数の倍数を使用して構築できます。ただし、次の最小の許容される整数を使用して微調整します。`n`は最小の整数で割り切れません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k, x = map(int, input().split())
    
    if k == 1 and x == 1:
        print("NO")
        continue
    
    if x != 1:
        # 1 is allowed
        print("YES")
        print(n)
        print("1 " * n)
    else:
        # 1 is forbidden, use 2 if possible
        if n == 1:
            print("NO")
        elif n % 2 == 0:
            print("YES")
            print(n // 2)
            print("2 " * (n // 2))
        elif k >= 3:
            print("YES")
            count = 1 + (n - 3) // 2
            print(count)
            print("3 " + "2 " * ((n - 3) // 2))
        else:
            print("NO")
```このソリューションでは、まず、数値が許可されない場合の縮退ケースを処理します。 次に、次のことを確認します。`1`使えるのですぐに施工が可能です。 もし`1`禁止されている場合、ソリューションでは使用されます`2`均等に`n`そして`3 + 2`奇数の場合`n`可能であれば。 これは、上で説明した建設的な論理と一致します。

 ## 特殊なケース

 許可される数値が 2 のみである場合、`n`が奇数の場合、2 のみを使用して奇数を合計する方法がないため、アルゴリズムは正しく「NO」を出力します。 例えば、`n = 5, k = 2, x = 1`「いいえ」となります。 もし`1`たとえ大きくても許可されます`n`を使用して自明に構築されます`n`1のコピー。`n`が禁止された整数に等しいが、他の整数が使用可能な場合、アルゴリズムは許可される最小の整数を選択し、禁止された数値を使用せずに合計に到達できるようにします。
