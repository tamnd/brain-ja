 ## 解決策
 ## 問題の理解

 一連の整数が与えられますが、それぞれの整数は以下の非常に広い範囲にあります。$10^9$。 Mishka は、各値 (連続する整数のすべてのペア) に独立して作用するグローバル変換ルールを繰り返し適用します。$(1,2)$、$(3,4)$、$(5,6)$、などはその場でスワップされますが、すべてのスワップは単一の概念的な操作として同時に適用されます。 

重要な点は、プロセスが意味のある意味で反復的ではないということです。 すべてのスワップを 1 回完全に適用した後、同じ操作を再度繰り返すと、最初と同じ結果が得られます。 これは、変換が実際にはすべての要素に 1 回適用される固定順列であることを示唆しています。 

入力サイズ$n \le 1000$は小さいため、要素ごとに線形時間または一定時間で実行される任意のソリューションで十分です。 重要なのは、変換を広範囲にわたって段階的にシミュレートするのではなく、変換の構造を認識することです。$10^9$、それは不可能でしょう。 

素朴な誤解は、すべてのスワップをシミュレートしようとすることです。$1$に$10^9$、または安定するまでプロセスを繰り返し適用します。 どちらも不必要であり、計算上実行不可能です。 

配列には決して現れず、処理されたペアの間にある数値について考えると、微妙なエッジ ケースが発生します。 たとえば、部分的なマッピングや観測値のみをシミュレートしようとすると、変換が配列の内容ごとではなく数値ごとにグローバルかつ独立して定義されていることを見落とす可能性があります。 

## アプローチ

 ブルートフォース解釈は、記述された手順を文字通りに適用することです。$(2i-1, 2i)$、配列全体をスキャンし、出現箇所を交換します。 すべてのペアを通過するたびに、次の値に到達します。$10^9 / 2$たとえ配列内に現れる値のみに限定したとしても、繰り返しのパスは不要です。 

より具体的なブルートフォースの単純化は次のようになります。配列内の各値について、それがペアに属しているかどうかを繰り返しチェックし、それを交換します。 これでも、$O(n \cdot 10^9)$ドメイン全体に文字通り実装された場合、スタイルの概念が複雑になりますが、これは許容できません。 

重要な観察は、操作が値空間上で純粋にローカルであるということです。 各整数$x$独立してマッピングされます。 

- もし$x$奇数です、と交換します$x+1$。 
- もし$x$が偶数の場合、次のように交換されます$x-1$。 

したがって、各要素の最終値は、シミュレーションではなく、単一の算術規則によって決定されます。 奇数と偶数のペアリングは連続する各ペア内のパリティを正確に切り替えるため、プロセス全体は 2 進数の数値の最下位ビットを反転することに相当します。 

したがって、それぞれの値は$x$次のように変換されます。 

-$x \rightarrow x-1$もし$x$均等です
 -$x \rightarrow x+1$もし$x$奇妙です

 これにより、$O(n)$ダイレクトマッピングソリューション。

 ## アルゴリズムのチュートリアル

 1. 整数の配列を読み取ります。 各要素は他の要素から独立しているため、前処理は必要ありません。 
2. 各要素について$a_i$、奇数か偶数かを判断します。 変換は連続する整数の固定ペアであるため、この分類によって最終値が完全に決まります。 
3. 値が奇数の場合は、次のように置き換えます。$a_i + 1$。 これは、すべての奇数が次の整数と交換されることを反映しています。 
4. 値が偶数の場合は、次のように置き換えます。$a_i - 1$。 これは、すべての偶数が前の整数と交換されることを反映しています。 
5. 変換された配列を同じ順序で出力します。 

構造上の重要な点は、どの要素も他の要素に影響を与えないということです。 カスケードや依存関係がないため、単一のパスで十分です。 

### なぜ効果があるのか

 この変換は、隣接する各ペアが 1 回だけ交換される、正の整数のセットの順列を定義します。 各番号は正確に 1 つのペアに属し、そのパートナーにマッピングされます。 これらのペアは整数行全体を分割するため、マッピングは全体的かつ決定的になります。 配列構造は無関係です。 個人の価値観だけが重要です。 ルールを一度適用すると最終状態が生成され、再度適用すると元の構成が返され、それがインボリューションであることが確認されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    res = []
    for x in a:
        if x % 2 == 0:
            res.append(x - 1)
        else:
            res.append(x + 1)
    
    print(*res)

if __name__ == "__main__":
    solve()
```このソリューションは入力を 1 回読み取り、各値を個別に処理します。 パリティ チェックはスワップ ペアを直接エンコードし、大きな整数範囲にわたるシミュレーションを回避します。 変換には並べ替えが含まれないため、出力では元の順序が維持されます。

 ## 特殊なケース

 1 つのエッジ ケースは、単一の奇数値を持つ可能な最小の配列です。 入力用`1`、変換によりそれがマッピングされます。`2`。 他の要素との相互作用がないため、隠れた依存関係は現れません。 

別のエッジケースは最大値です$10^9$。 入力用`[1000000000]`、偶数であるため、次のようにマッピングされます。`999999999`。 このルールは、許可された範囲の境界に一律に適用され、Python の整数は減算を安全に処理し、結果は制約内にとどまるため、オーバーフローや特殊なケースは必要ありません。
