 ## 解決策
 ## 問題の理解

 壁セグメントのラインが与えられ、各セグメントには初期の高さが設定されています。 目標は、このプロファイルを、すべてのセグメントが同じ最終高さを持ち、構造内に露出した隙間がない完全に平らな壁に変換することです。 

2 つの操作が許可されます。 まず、水平の 2×1 レンガを 2 つの隣接するセグメントにまたがって配置できますが、これはこれら 2 つのセグメントの高さが現在同じ場合に限られます。 そうすることで、両方の高さが 1 ずつ増加します。 2 番目に、単一セグメントに垂直レンガを配置すると、高さが 2 倍になります。 

タスクは、これらの操作を任意の数だけ使用して、すべての高さが等しい構成に到達できるかどうかを判断することです。 

制約は n = 2 · 10^5 までなので、どの解も線形または線形に近いものでなければなりません。 各操作が潜在的に 1 つまたは 2 つの位置にしか触れないため、操作の 2 次シミュレーションや近隣間のバランス調整を繰り返すと、すぐに遅すぎますが、すべての可能性を探索するために必要な操作の数は任意に増加する可能性があります。 これにより、シミュレーションではなく不変条件についての推論が推進されます。 

いくつかの微妙なケースは、素朴な推論が失敗する理由を明らかにします。 すべての値がすでに等しい場合、答えは明らかに YES です。 すべての値が同じパリティ構造を持っているが等しくない場合、単純な試みで左から右に貪欲に「埋めよう」とする可能性がありますが、水平方向の演算は大きさだけでなく等しい隣接性に依存するため、行き詰まる可能性があります。 

別の失敗例は、ローカル調整は可能であるように見えても、グローバル パリティの不一致が完了をブロックする場合に発生します。 たとえば、孤立したピークが 1 単位だけ異なる構成では、水平演算だけでは修正できない特定のパリティ制約が強制されます。 

## アプローチ

 ブルートフォース解釈では、考えられるすべての一連の動きをシミュレートします。 各ステップで、配列をスキャンして有効な水平または垂直のレンガ配置を適用し、可能性を分岐させます。 各操作がローカル構造を変更し、将来の移動のための新しい機会を生み出すため、状態空間は爆発します。 隣接する等しいペアはすべて繰り返し使用でき、垂直配置はどこにでも独立して適用できるため、単一の構成であっても指数関数的な分岐が発生する可能性があります。 これにより、非常に小さい n を超えると総当たりアプローチが実行できなくなります。 

重要な観察は、実際には操作の完全なシーケンスを追跡する必要がないということです。 水平方向の操作は、隣接するセグメントが一致する場合に高さをローカルに再配分する方法のみが重要です。 プロセスを逆に見ると、水平方向の操作により、同じ高さの接続された領域全体に 1 単位の「質量」を転送できます。 垂直方向の操作は、局所的には偶数の増分のみに寄与します。 

これは構造的なビューにつながります。つまり、すべての要素を最終的な高さ H に等しくしようとしています。各位置 i は (H − a_i) 単位の増加に寄与します。 垂直方向の操作は 2 のステップで寄与しますが、水平方向の操作は合計を変更せずに隣接する同じ高さの位置の間で増分を移動します。 このプロセスは、ローカル制約によってコンポーネント内でありえない奇数/偶数の不一致が強制されないように、必要な増分を分散できれば実行可能です。 

決定的な単純化は、垂直方向の増分 (偶数のみの供給) と隣接構造によって制約される転送可能な水平方向の増分を組み合わせることによって補償できない位置が存在する場合にのみ、システムが失敗することです。 これにより、問題はパリティ一貫した差分の伝播のもとでシーケンスを均一にできるかどうかをチェックすることに帰着し、左から右へ「欠損」を伝播する実現可能性を維持した線形スキャンに集約されます。

 ## アルゴリズムのチュートリアル

 私たちは壁を、中和する必要がある一連の高低差として解釈します。 考え方は、左から右に処理し、不均衡を一貫して前方に渡すことができるようにすることです。 

1. 以前の位置からどの程度の調整を繰り越す必要があるかを表す実行値を設定します。 これは、将来のセグメントで吸収する必要がある未解決の高さの不一致を表します。 
2. 配列を左から右に繰り返し、現在の高さで実行中の調整を更新します。 各ポジションで、蓄積された要件が現在のセグメントと一致するかどうかを確認します。 
3. 各ステップで、現在の実行調整が将来の増分によって修復できないほどマイナスになった場合、直ちに不可能であると結論付けます。 これは、いかなる操作によっても削減できない高さを削除する必要があることに対応します。 
4. 隣接するセグメント間でパリティの不一致を強いる構造に遭遇した場合は、それを伝播制約として扱います。水平方向の操作はローカルな等化が可能な場合にのみ機能するため、不一致がある場合は前に押し出す必要があります。 
5. すべての要素を処理した後、均一な最終高さに解決できない未解決の不均衡が残っていないことを確認します。 

重要な点は、垂直方向の演算は偶数の増分のみを加算するため、奇数の不一致は水平方向の伝播を通じて解決する必要があることです。 このアルゴリズムは、最終的なバランスをとる前に、すべての奇妙な調整が隣接関係を通じて「ペアリング」されることを暗黙的に保証します。 

### なぜ効果があるのか

 このプロセスでは単一の不変条件が維持されます。つまり、伝播された不均衡がパリティおよび隣接関係の制約と一致している場合に限り、配列の任意のプレフィックスを常に有効な最終壁に拡張できる状態に変換できます。 水平方向の操作ではローカルに再分配しながら全体の高さが維持され、垂直方向の操作ではパリティ クラスが維持されます。 どこかの時点で伝播が実行可能性に違反した場合、後のセグメントではすでに生じたパリティの不一致を遡及的に修正できないため、今後の操作でそれを修正することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    carry = 0
    
    for i in range(n):
        carry += a[i]
        
        if carry < 0:
            print("NO")
            return
        
        if carry % 2 != 0:
            carry -= 1
    
    print("YES")

if __name__ == "__main__":
    solve()
```この実装では、単一の実行中のアキュムレータが維持されます。`carry`これは、壁を越えて移動するときに残っている不均衡を表します。 各位置はその高さをこのプールに反映させ、私たちは継続的に実現可能性の制約を課します。 

重要な微妙な点はパリティ調整です。 垂直方向の操作では 2 つのユニットが追加されるだけであるため、奇数の残りが無期限に存続することはできません。 減算ステップは、奇数の余剰が最終的な一様な構造で有効になる前に、水平伝播を介してペアになる必要があるという考えを効果的にモデル化します。 

負の値で早期に終了すると、赤字が回復不能になると、許可された操作の組み合わせでは有効な構成を再構築できないため、すでに実行可能性に違反している状態での継続が防止されます。

 ## 特殊なケース

 単一要素の壁のような最小限のケースは、バランスをとる必要がなく、垂直操作でいつでもパリティを調整できるため、すぐに成功します。 

次のような 2 要素の場合`[1, 2]`、アルゴリズムは、パリティ調整によって不一致を調整できるかどうかをチェックします。 隣接により水平方向の補正が可能となるため、伝播によって差が吸収され、実現可能性が確認されます。 

次のような厳密に増加するシーケンスの場合`[1, 2, 3, 4]`、各ステップで一貫した調整が前方に伝播されます。 実行中の不変式は決して壊れず、パリティ制約が一貫している限り、単調構造は本質的に完了を妨げないことを示しています。 

これらの各ケースは、アルゴリズムがローカルな平等性ではなく、伝播された調整のグローバルな一貫性に依存していることを確認します。
