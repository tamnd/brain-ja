 ## 問題の理解

 私たちは持っています$N$軸に揃えられた超長方形$M$-次元の整数グリッド。 超長方形は各座標で独立して記述されます: 次元の場合$j$、左の境界線の間のすべての整数座標を占めます。$a_j$そして右の境界線$b_j$、包括的。 

課題は、これらのオブジェクトの完全な結合を見つけることではありません。 正確にカバーされるグリッド点を数える必要があります。$N-1$指定された超長方形のうち、正確に 1 つの超長方形には点が含まれていないことを意味します。 

この制約により、点または四角形のペアを検査する方法は避けざるを得なくなります。 到達できる長方形の数$2 \cdot 10^5$、および製品$N \cdot M$によっても制限されます$2 \cdot 10^5$。 これは、目的のソリューションでは、すべての長方形の寸法ペアを一定の回数だけ処理する必要があることを意味します。 周囲のあらゆるアプローチ$O(N^2)$または$O(N^2M)$不可能です。 いつでも$M$が小さいため、四角形のすべてのペアをチェックすることはすでに数十億回の操作を必要とする可能性があります。 

よくある落とし穴は、長方形の境界線が含まれていることを忘れることです。 たとえば、1 つの次元では、間隔は$[1,2]$可能な値が 3 つ含まれていますか? いいえ、整数ポイントが含まれています$1$そして$2$、そのサイズは$2$。 整数の座標をカウントする代わりに連続した長さを使用する解決策は失敗します。 

もう 1 つの微妙なケースは、1 つの四角形を削除すると最大下限または最小上限が変更される場合に発生します。 考慮する：```
2 1
1 5
2 4
```ちょうど 1 つの間隔でカバーされるポイントは次のとおりです。$1$そして$5$、したがって、答えは次のとおりです`2`。 グローバル交差点のみを保存するメソッド$[2,4]$削除された長方形を個別に処理せずに残りを導出しようとすると、これらの境界点が失われます。 

2 番目のエッジ ケースは、すべての四角形が完全に重なっている場合です。```
3 1
1 3
1 3
1 3
```すべての点は 3 つの長方形すべてで覆われているため、正確に 2 つの長方形に属する点はありません。 答えは`0`。 完全な交差を修正せずに「1 つを除くすべて」の交差をカウントする不注意な包含式では、各ポイントを 3 回カウントすることになります。 

## アプローチ

 直接的なアプローチは、座標範囲内のすべての可能な点を調べ、その点が含まれる長方形の数を数え、その点をカバー範囲に保つことです。$N-1$。 これは定義に正確に従っているため、正しいです。 ただし、座標は次のような大きさにすることができます。$10^6$、次元の数も大きくなる可能性があるため、グリッドを列挙することはできません。 すべての四角形を他のすべての四角形と比較する圧縮バージョンでさえ遅すぎます。 すべてのペア関係を計算するには、$O(N^2M)$限界をはるかに超えた仕事。 

重要な点は、正確に 1 つの長方形から欠落している点だけが必要であるということです。 長方形を除くすべての長方形の交差を計算するとします。$i$。 この交差点内のすべての点は、少なくとも$N-1$長方形。 点が正確に含まれる場合$N-1$長方形、それはこれらのいずれかに正確に属します$N$交差、つまり欠落している四角形が除外されている交差。 

唯一の問題は、すべての要素にポイントが含まれていることです。$N$長方形はすべてとしてカウントされます$N$そういった交差点。 このような点は正確に削除する必要があります$N-1$延長戦。 同様に、最終的な答えは次のようになります。$$\sum_{i=1}^{N} |\bigcap_{j\neq i} A_j| - N \cdot |\bigcap_{j=1}^{N} A_j|$$完全にカバーされたポイントが貢献するため$N$最初の合計ではゼロを寄与する必要があります。 

さて、問題はコンピューティングです$N$交差点を効率的に通過します。 超長方形の交差点も超長方形です。 すべての次元について、残りの長方形の中で最大の下限と最小の上限のみが必要です。 

1 つの次元の場合、1 つの四角形を削除するということは、1 つの要素を除くすべての下限の最大値と、1 つの要素を除くすべての上限の最小値が必要になることを意味します。 これらは、最大および 2 番目に大きい下限と、最小および 2 番目に小さい上限で見つけることができます。 以来$N \cdot M$が小さい場合、これを次元ごとに独立して繰り返すことができます。

 ## アルゴリズムのチュートリアル

 1. すべての長方形の境界線を保存します。 保存される座標の総数は次のとおりであるため、入力サイズは十分に小さくなります。$2NM \leq 4 \cdot 10^5$。 
2. アレイを準備する`without[i]`長方形を除くすべての長方形の交点にある格子点の数を保存します。$i$。 最終的なサイズは寸法の積であるため、最初はすべての値が 1 です。 
3. 各次元について、すべての長方形の中で最大および 2 番目に大きい下限を見つけます。 また、最小と 2 番目に小さい上限も見つけます。 これら 4 つの値を使用すると、単一の長方形を一定時間内に削除できます。 
4. 長方形ごとに$i$、除外した後、この次元の交差範囲を決定します。$i$。 もし$i$最大の下限を提供する唯一の長方形である場合は、2 番目の最大値を使用します。 それ以外の場合は、最大値を使用します。 同じ考え方を最小上限にも適用します。 この次元で得られた整数座標の数を次のように乗算します。`without[i]`。 
5. 同じ次元のパス中に、すべての長方形の交差のサイズを計算し、それを乗算します。`all_intersection`。 
6. すべての次元を処理した後、すべての次元の合計として答えを計算します。`without[i]`マイナスの値$N$回`all_intersection`。 

なぜ機能するのか: すべてのポイントが正確にカバーされています$N-1$四角形は、欠落している四角形が削除された 1 つの交差点にのみ表示されます。 全員がカバーするポイント$N$すべてに長方形が表示されます$N$このような交差点なので、差し引きます$N$完全な交差を 3 回繰り返すと完全に削除されます。 より少ない長方形で覆われた点は、次の交点には現れません。$N-1$少なくとも 2 つの長方形から欠落しているため、長方形が見つかりません。 したがって、すべてのポイントが正確に希望の量に貢献します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    N, M = map(int, input().split())

    lows = [[0] * N for _ in range(M)]
    highs = [[0] * N for _ in range(M)]

    for i in range(N):
        row = list(map(int, input().split()))
        for j in range(M):
            lows[j][i] = row[2 * j]
            highs[j][i] = row[2 * j + 1]

    without = [1] * N
    all_intersection = 1

    for d in range(M):
        lo = lows[d]
        hi = highs[d]

        max1 = -10**18
        max2 = -10**18
        max_count = 0
        for x in lo:
            if x > max1:
                max2 = max1
                max1 = x
                max_count = 1
            elif x == max1:
                max_count += 1
            elif x > max2:
                max2 = x

        min1 = 10**18
        min2 = 10**18
        min_count = 0
        for x in hi:
            if x < min1:
                min2 = min1
                min1 = x
                min_count = 1
            elif x == min1:
                min_count += 1
            elif x < min2:
                min2 = x

        length_all = min1 - max1 + 1
        if length_all < 0:
            length_all = 0
        all_intersection = (all_intersection * length_all) % MOD

        for i in range(N):
            left = max1
            if lo[i] == max1 and max_count == 1:
                left = max2

            right = min1
            if hi[i] == min1 and min_count == 1:
                right = min2

            length = right - left + 1
            if length < 0:
                length = 0
            without[i] = (without[i] * length) % MOD

    ans = (sum(without) - N * all_intersection) % MOD
    print(ans)

if __name__ == "__main__":
    solve()

1 つの長方形を除外しても下限または上限のセットから 1 つの候補しか削除できないため、各次元の 4 つの極値で十分です。 削除された長方形が現在の極値の一意の所有者であった場合、2 番目の極値がアクティブになります。 

乗算はモジュロで行われます$998244353$交差サイズが非常に大きくなる可能性があるため、すべての次元の後で。 Python の整数はオーバーフローしませんが、計算中に削減すると値が小さく保たれ、必要なモジュラー演算が反映されます。 

最後の式は、さまざまな省略選択肢の交差が相互作用する唯一の場所です。 すべての中間積は独立した次元を表しますが、最後の減算では、カウントされすぎた点が削除されます。

import io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()

    data = sys.stdin.read().strip().split()
    if not data:
        return ""

    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    MOD = 998244353
    lows = [[0] * n for _ in range(m)]
    highs = [[0] * n for _ in range(m)]

    for i in range(n):
        for j in range(m):
            lows[j][i] = int(next(it))
            highs[j][i] = int(next(it))

    without = [1] * n
    all_intersection = 1

    for d in range(m):
        lo = lows[d]
        hi = highs[d]

        max1 = max(lo)
        max_count = lo.count(max1)
        max2 = max(x for x in lo if x != max1) if max_count == 1 else max1

        min1 = min(hi)
        min_count = hi.count(min1)
        min2 = min(x for x in hi if x != min1) if min_count == 1 else min1

            without[i] *= max(0, r - l + 1)

    ans = (sum(without) - n * all_intersection) % MOD
    sys.stdin = old
    return str(ans)
