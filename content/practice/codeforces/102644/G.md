 ## 解決策
 # 問題の理解

 次の値は前の値だけでなく、シーケンス内の現在の位置にも依存するため、この問題のシーケンスは標準的な線形反復ではありません。 シーケンスの最初のいくつかの値、前の値を結合する係数、およびインデックスの 2 次関数を作成する 3 つの追加係数が与えられます。 タスクは、潜在的に巨大なインデックスでシーケンスの値を見つけて、それを剰余として出力することです。$10^9+7$。 

繰り返しは、すべての新しい要素が以前の要素から作成されるという形式をとります。$n$要素と多項式項。 前の要素は固定係数によって重み付けされますが、追加部分はインデックス内の二次式として増加します。 

インデックス$k$と同じ大きさにすることができます$10^{18}$したがって、シーケンスを一度に 1 要素ずつシミュレートすることは不可能です。 平$O(k)$運営には、コンテストの制限時間よりもはるかに多くの作業が必要になります。 再発の順序は小さく、$n \le 10$したがって、目的のソリューションでは、要求されたインデックスのサイズではなく、小さな状態サイズを活用する必要があります。 

よくある間違いは、多項式の項がインデックスに依存することを忘れていることです。 たとえば、再発を通常の線形再発として扱い、以前の再発のみを使用します。$n$値は、将来の 2 次寄与を生成するために必要な情報を失います。 

次の入力を考えてみましょう。```
1 3
5
1
2 3 4
```値は次のように生成されます。$a_i = a_{i-1} + 2 + 3i + 4i^2$。 シーケンスは次のようになります$5, 14, 38, 85$、したがって、答えは次のようになります。```
85
```追跡するだけの不用意な実装$a_i$現在のインデックスを無視すると、追加された値が定数であると誤って想定されてしまいます。 

もう 1 つのエッジ ケースは、要求されたインデックスが初期値の範囲内にある場合です。 のために：```
3 1
7 8 9
1 1 1
0 0 0
```答えは次のとおりです。```
8
```再発ステップは実行しないでください。$a_1$はすでに提供されています。 常に最初の遷移から行列のべき乗を開始するソリューションでは、間違った状態にアクセスすることになります。 

## アプローチ

 直接的なアプローチは、インデックスに達するまで反復を繰り返し適用することです。$k$。 1 つの新しい要素を計算するには、前の要素を乗算します。$n$値を係数で計算し、二次式を追加します。 これにはかかります$O(n)$生成された要素ごとに動作するため、完全なシミュレーションには次の必要があります。$O(nk)$操作。 と$k$到達$10^{18}$、これは遠隔的には実現可能ではありません。 

ブルート フォースが機能する理由は、すべての新しい値が少量の情報のみに依存するためです。$n$二次項に必要なシーケンス値と現在のインデックス情報。 したがって、シーケンスには小さな固定サイズの状態が含まれます。 

重要な観察は、二次部分も漸化式として表すことができるということです。 現在のインデックスとその平方を追加の状態値として保存すると、次のインデックスと次の平方は線形変換で生成できます。 プロセス全体は、次のサイズのベクトルに対する行列の乗算になります。$n+3$。 

遷移が行列として表現されると、インデックスに到達します。$k$同じ変換を適用する必要がある$k-(n-1)$回。 高速累乗では、これが対数行列の乗算に変換されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(nk) | O(n) | 遅すぎる |
 | 行列のべき乗 | O((n+3)^3 log k) | O((n+3)^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 現在のシーケンス値、定数値、現在のインデックス、および現在のインデックスの 2 乗を含む状態ベクトルを構築します。 位置で$n-1$、状態は次のとおりです。$$[a_{n-1}, a_{n-2}, \dots, a_0, 1, n-1, (n-1)^2]$$追加の 3 つの値により、漸化式の二次部分を同じ線形変換で処理できるようになります。 

1. インデックスから状態を移動する遷移行列を構築します。$i$インデックスを付ける$i+1$。 最初の行は作成します$a_{i+1}$。 反復係数を使用して保存されたシーケンス値を結合し、以下を加算します。$$p + (i+1)q + (i+1)^2r$$これは次のようになります。$$(p+q+r) + (q+2r)i + r i^2$$保存された値を使用して$1$、$i$、 そして$i^2$。 

1. マトリックスの残りの行を埋めて、前のシーケンス値を前方にシフトします。 シーケンス部分は通常の線形反復のように動作するため、すべての値は単純に 1 つ下の位置に移動します。 
2. もし$k$よりも小さいです$n$、既知の初期値を返します。 それ以外の場合は、遷移行列をべき乗します。$k-(n-1)$。 

指数は、インデックスの初期状態から移行するために必要な遷移の数です。$n-1$目的のインデックスに移動します。 

1. べき乗行列に初期状態ベクトルを乗算します。 結果のベクトルの最初の要素は次のとおりです。$a_k$。 

なぜ効果があるのか:

 不変条件は、遷移行列を適用した後のものです。$t$状態ベクトルには、位置のシーケンス値とインデックス情報が正確に含まれています。$n-1+t$。 マトリックスは、同じ漸化式を使用して次のシーケンス値を計算し、インデックス情報を一貫して更新します。 行列のべき乗は遷移を繰り返し適用した場合と同じ結果を生成するため、次の最初の成分は$k-(n-1)$トランジションは次のようにする必要があります$a_k$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10 ** 9 + 7

def mat_mul(a, b):
    n = len(a)
    m = len(b[0])
    k = len(b)
    res = [[0] * m for _ in range(n)]
    for i in range(n):
        for x in range(k):
            if a[i][x]:
                ax = a[i][x]
                for j in range(m):
                    res[i][j] = (res[i][j] + ax * b[x][j]) % MOD
    return res

def mat_pow(a, e):
    n = len(a)
    res = [[0] * n for _ in range(n)]
    for i in range(n):
        res[i][i] = 1
    while e:
        if e & 1:
            res = mat_mul(res, a)
        a = mat_mul(a, a)
        e >>= 1
    return res

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    c = list(map(int, input().split()))
    p, q, r = map(int, input().split())

    if k < n:
        print(a[k] % MOD)
        return

    size = n + 3
    trans = [[0] * size for _ in range(size)]

    for i in range(n):
        trans[0][i] = c[i] % MOD

    trans[0][n] = (p + q + r) % MOD
    trans[0][n + 1] = (q + 2 * r) % MOD
    trans[0][n + 2] = r % MOD

    for i in range(1, n):
        trans[i][i - 1] = 1

    trans[n][n] = 1
    trans[n + 1][n] = 1
    trans[n + 1][n + 1] = 1
    trans[n + 2][n] = 1
    trans[n + 2][n + 1] = 2
    trans[n + 2][n + 2] = 1

    state = [[0] for _ in range(size)]
    for i in range(n):
        state[i][0] = a[n - 1 - i] % MOD

    idx = n - 1
    state[n][0] = 1
    state[n + 1][0] = idx % MOD
    state[n + 2][0] = (idx * idx) % MOD

    result = mat_mul(mat_pow(trans, k - (n - 1)), state)
    print(result[0][0] % MOD)

if __name__ == "__main__":
    solve()
```このコードは、最初に、答えが提供された初期値の中にあるという単純なケースを処理します。 これにより、不必要なマトリックス構築が回避され、インデックス作成エラーも防止されます。 

遷移行列は最初の$n$シーケンス履歴の列。 最初の行に係数を直接適用できるように、シーケンスは逆順で保存されます。$c_1, c_2, \ldots, c_n$。 

最後の 3 つの位置が格納されます$1$、現在のインデックス、および現在のインデックスの 2 乗。 正方形の遷移は次のようになります。$$(i+1)^2 = i^2 + 2i + 1$$これは最後の行の係数を説明しています。 すべての演算はモジュロで実行されます$10^9+7$, したがって、Python の整数のサイズは問題ではありません。 

指数は$k-(n-1)$、 ない$k$。 開始状態はすでに表されています$a_{n-1}$したがって、残りのトランジションのみを適用する必要があります。

## テストケース```python
import sys
import io

MOD = 10 ** 9 + 7

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    data = sys.stdin.read().split()
    sys.stdin = old

    it = iter(data)
    n = int(next(it))
    k = int(next(it))
    a = [int(next(it)) for _ in range(n)]
    c = [int(next(it)) for _ in range(n)]
    p = int(next(it))
    q = int(next(it))
    r = int(next(it))

    if k < n:
        return str(a[k] % MOD)

    size = n + 3
    trans = [[0] * size for _ in range(size)]

    for i in range(n):
        trans[0][i] = c[i] % MOD
    trans[0][n] = (p + q + r) % MOD
    trans[0][n + 1] = (q + 2 * r) % MOD
    trans[0][n + 2] = r % MOD

    for i in range(1, n):
        trans[i][i - 1] = 1

    trans[n][n] = 1
    trans[n + 1][n] = 1
    trans[n + 1][n + 1] = 1
    trans[n + 2][n] = 1
    trans[n + 2][n + 1] = 2
    trans[n + 2][n + 2] = 1

    def mul(a, b):
        m = len(a)
        res = [[0] * m for _ in range(m)]
        for i in range(m):
            for x in range(m):
                for j in range(m):
                    res[i][j] = (res[i][j] + a[i][x] * b[x][j]) % MOD
        return res

    def power(a, e):
        m = len(a)
        res = [[int(i == j) for j in range(m)] for i in range(m)]
        while e:
            if e & 1:
                res = mul(res, a)
            a = mul(a, a)
            e >>= 1
        return res

    state = [[0] for _ in range(size)]
    for i in range(n):
        state[i][0] = a[n - 1 - i]
    state[n][0] = 1
    state[n + 1][0] = n - 1
    state[n + 2][0] = (n - 1) * (n - 1)

    ans = mul(power(trans, k - n + 1), state)
    return str(ans[0][0] % MOD)

 ## 特殊なケース

 最初の重要なエッジ ケースは、初期シーケンス内のクエリです。 のために：```
