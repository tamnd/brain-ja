 ## 解決策
 ## 問題の理解

 整数の配列が与えられます$a_1, a_2, \dots, a_n$。 位置ごとに値を選択する必要があります$b_i$制限されたセットから${-3, -1, 1, 3}$。 すべて割り当てたら$b_i$、2 つのベクトルがどのように揃っているかに応じてスコアを評価します。$a$そして$b$具体的には、その内積と次の二乗ノルムの比です。$b$。 

最大化される量は、$$\frac{\sum_{i=1}^n a_i b_i}{\sum_{i=1}^n b_i^2}.$$これは次の加重平均です。$a_i$、ここで重みは次のように比例します。$b_i$ですが、分母は大きな値にペナルティを与えます。$b_i^2$どちらかです$1$または$9$。 それで選択する$b_i = \pm 3$は、分子の寄与と分母のコストの両方を、従来と比較して 9 倍に増加させます。$\pm 1$ただし、分子は線形にスケーリングされ、分母は二次的にスケーリングされるため、対称的な方法ではありません。 

重要な決定は、すべてのポジションが独立して 4 つの値の 1 つを選択することですが、目的はグローバルな分数を介してすべての選択肢を結合することです。 この構造は、インデックスごとの単純な独立した貪欲な選択が明らかに有効ではないことを意味します。 

制約により許可されるのは、$n \le 10^4$、だから、$O(n^2)$さらに悪いことに、割り当てに対する検索は実行不可能です。 平$O(n \log n)$は受け入れられますが、構造は貪欲または並べ替えベースの決定に近いものを示唆しています。 

素朴な推論による微妙な失敗例は、常に選択できると仮定していることです。$b_i$最大化する$a_i b_i$地元で。 たとえば、次の場合$a_i = 1$、地元では私たちが好む$b_i = 3$分子が増えるからです。 しかし、そのような選択が多数行われると、分母が爆発的に増加し、最終的な比率が低下する可能性があります。 

もう 1 つの特殊なケースは、すべてが$a_i = 0$。 この場合、分子は常に 0 になるため、どの割り当ても最適になります。 ただし、実装が間違っていると「最適化」しようとして誤ってバイアスが導入される可能性があるため、分母は依然として間接的に重要です。 

## アプローチ

 ブルートフォースソリューションでは、すべてが列挙されます。$4^n$の割り当て$b_i$、それぞれの分数を計算し、最良のものを維持します。 これは、考えられるすべての構成を評価するため正しいですが、次の理由により完全に実行不可能です。$4^{10^4}$天文学的に大きいです。 

式の構造は、古典的な最適化パターン、つまり二次関数のようなコストに対する線形形式の比率を最大化することを示唆しています。 標準的な手法は、分母をスケーリング係数として扱い、各位置が分子と分母の両方にどのように寄与するかを推論することです。 

目的をより構造的に書き直してみましょう。 以来$b_i^2$どちらかです$1$または$9$、分母は独立したポジションごとのコストの合計であり、分子も独立した貢献の合計です。 これにより、この問題は、それぞれを選択することによる限界効果を考慮する変換に適したものになります。$b_i$。 

重要な観察は、すべてをスケーリングすることです。$b_i$による$-1$分子の符号を反転しますが、分母は変更しません。 したがって、各インデックスについて、大きさを決定するだけで済みます ($1$または$3$) と個別に署名します。 

大きさを固定すると、最適な符号がすぐに得られます。$b_i$の符号と一致するように$a_i$、それが最大化されるため、$a_i b_i$。 

したがって、問題は次のいずれかを選択することになります。$|b_i| = 1$そして$|b_i| = 3$符号を揃えた後、インデックスごとに。 これは、各要素が 2 つの考えられる寄与を持つ選択問題になります。 

私たちが選ぶなら$|b_i| = 1$、貢献度は$|a_i|$分子と$1$分母に。 

私たちが選ぶなら$|b_i| = 3$、貢献度は$3|a_i|$分子と$9$分母に。 

私たちは以下を最大化したいと考えています。$$\frac{\sum c_i}{\sum d_i}$$ここで、各項目には 2 つの可能なペアがあります$(c_i, d_i)$。 

これは、独立した項目に対する古典的な部分最適化問題です。 アイテムの大きさからアップグレードするかどうかを比較して最適な構造を取得します$1$に$3$世界的な比率が向上します。 これにより、限界費用あたりの限界利益と現在の比率との比較から得られるしきい値条件が導き出され、並べ替えのない貪欲な選択が解決されます。つまり、各項目が独立して大きさを優先します。$3$大きさと比較して比率が改善されるたびに$1$最適なグローバルバランスの下で。 これは、代数後の統一ルールに単純化されます。すべての項目は次のようになります。$|a_i| > 0$大きさを好む$3$、ゼロのエントリだけが無関心です。 

したがって、ゼロ以外のすべての位置は次のようになります。$|b_i| = 3$、ゼロは任意の有効な値を取ることができます。 選択する$-1$で十分です。

 ## アルゴリズムのチュートリアル

 配列を構築します$b$直接。 

1. インデックスごとに$i$、検査する$a_i$そして大きさを決めます$b_i$。 もし$a_i \ne 0$、設定しました$|b_i| = 3$。 これは、ゼロ以外の値が存在するためです。$a_i$大域的最適解の二次分母によってペナルティを受けるよりも、分子の乗数を大きくした方がメリットが大きくなります。 
2. もし$a_i = 0$、どちらの選択も分子には何も寄与しないため、固定値を割り当てます。$b_i = -1$。 これにより、最適性に影響を与えることなく構築が有効に保たれます。 
3. 大きさを固定した後、符号を割り当てます。 もし$a_i \ge 0$、 セット$b_i$正、それ以外の場合は負に設定します。 これにより、各用語が保証されます$a_i b_i$符号を反転すると、分母は変更されずに分子が厳密に減少するため、 は個別に最大化されます。 
4. 構築されたベクトルを出力します$b$。 

### なぜ効果があるのか

 最適化は、分子と分母がインデックスごとの独立した寄与に分解される比率に依存します。 任意のインデックスに対して、$a_i \ne 0$、増加しています$|b_i|$から$1$に$3$分子を 3 の係数で線形にスケーリングし、分母を 9 でスケーリングします。これらの寄与はすべてのインデックスにわたって集約されるため、符号の調整によってキャンセル効果が保証されないため、結合制約に違反することなく非ゼロ要素を大きさ 1 のままにする構成は、その大きさを増やすことで改善できます。 したがって、最適な構成では、ゼロ以外のすべての位置が利用可能な最大の大きさにプッシュされ、ゼロのエントリのみが無関心のままになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    a = list(map(int, input().split()))
    b = []

    for x in a:
        if x == 0:
            b.append(-1)
        else:
            if x > 0:
                b.append(3)
            else:
                b.append(-3)

    print(*b)

if __name__ == "__main__":
    main()
```コードは各要素を個別に処理します。 ゼロ以外の値の場合、入力に合わせて符号を付けてマグニチュード 3 を割り当てます。 ゼロの場合は、目標に影響を与えないため、デフォルト値が割り当てられます。 

この実装では、構造がインデックスごとに完全に独立した決定になるため、浮動小数点計算やグローバル最適化が回避されます。

 ## 特殊なケース

 すべてゼロの場合、すべての$a_i = 0$に関係なく分子を同じゼロにします$b$。 アルゴリズムは次のように割り当てます。$b_i = -1$すべての位置に対して有効な出力を生成し、不必要な変動を回避します。 

単一要素配列の場合、決定は最大化に帰着します。$a_1 b_1 / b_1^2$これは、最大の大きさと正しい符号を選択​​することと同じです。 アルゴリズムの出力$\pm 3$したがって、これが最適な選択と一致します。 

混合符号入力の場合、各位置は独立して処理されるため、正の入力と負の入力の間に相互作用はありません。 このアルゴリズムは、各符号を単純に整列させて最大の大きさを選択します。これは、符号が激しく交互する場合でも有効です。
