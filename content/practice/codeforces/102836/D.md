 ## 問題の理解

 ゲームには、`k`プレーヤーと持続時間`m`夜。 毎晩、現在生きているプレイヤー同士でミーティングを行っています。 夜の終わりに、生きていたプレイヤーがちょうど 1 人マフィアによって殺されます。 殺されたプレイヤーは民間人である必要があり、この夜にそのプレイヤーと会ったマフィアのメンバーの1人が殺害を実行します。 

入力はゲームの完全な歴史を記述します。毎晩、誰が生きていて、誰と会い、誰が死んだのかがわかります。 課題は、まさにこの一連の死を引き起こした可能性のあるマフィアのメンバーを可能な限り最小限に特定することです。 

重要な制限は、民間人のみが死亡するということです。 後`m`夜はまさにそこにある`k - m`生存者。 すべてのマフィアのメンバーはこれらの生存者の中にいるはずです。 条件`k - m <= 15`が主要なアルゴリズムの手掛かりです。 プレイヤーの総数は 200 人ですが、マフィア候補の数は最大 15 人であるため、マフィアのメンバー候補のサブセットを試すことは可能です。 

すべてのプレーヤーのすべてのサブセットをチェックするソリューションには、最大で次のものが必要になります。`2^200`場合がありますが、それは不可能です。 生存者の数が少ないと、問題は完全に変わります。考慮する必要があるのは、最大 15 人のサブセット、つまり最大 32,768 通りの可能性だけです。 

不注意な実装が失敗するエッジケースがいくつかあります。 たとえすべての被害者に会ったとしても、死亡したプレイヤーはマフィアではありません。 たとえば、入力が 2 人のプレイヤーと、プレイヤー 1 が死亡した一晩について説明している場合、答えは次のようになります。`1`なぜなら、プレイヤー 1 がマフィアになることはできず、プレイヤー 2 が殺人者でなければならないからです。 もう 1 つのよくある間違いは、マフィアのメンバーは死亡当日の夜に被害者に会わなければならないことを忘れていることです。 前夜に被害者に会ったものの、殺害の夜にはその場にいなかったプレイヤーは、その死を説明することができません。 

小さな例:```
2 1
1 1
2
1 1
2
2
```最初の夜はプレイヤー 1 と 2 が生き残った状態で始まります。 彼らは出会い、その後プレイヤー 2 は死亡します。 答えは`1`、プレイヤー 1 だけが生き残り、マフィアは一晩経っても生きていなければならないからです。 

## アプローチ

 直接的なアプローチは、すべてのプレイヤーの中で可能な限りすべてのマフィア メンバーを試してみることです。 すべての候補者セットについて、一晩中シミュレーションし、各犠牲者がこのセットの誰かによって殺された可能性があるかどうかを確認しました。 マフィア セットの唯一の要件は、すべての死者に、その夜被害者に会った生き残ったマフィア メンバーがいることであるため、シミュレーションは正しいです。 

問題は候補者の数だ。 プレイヤーが 200 人いる場合、総当たり検索では次のようになります。`2^200`処理できる範囲をはるかに超えた可能性があります。 

重要な観察は、マフィアのメンバーは決して死なないということです。 一晩中考えられるのは、マフィアのメンバーだけです。`k - m`生存者。 このステートメントは、この数が最大 15 であることを保証します。生存者のすべてのサブセットを列挙し、それらをテストすることができます。 多くてもあります`2^15`各サブセットは最大 200 泊までチェックできます。 

ブルート フォースは有効なマフィア チームの正確な定義をテストするため機能しますが、無関係なプレイヤーを検索するため失敗します。 捜索を生存者に限定すると、問題は小規模なセットカバー形式の問題に変わります。マフィアのメンバー候補は全員、被害者を殺害できた可能性のある夜をカバーするため、すべての夜をカバーする最小のグループが必要です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^k * k * m) | O(k * m) | 遅すぎる |
 | 最適 | O(2^(k-m) * m * (k-m)) | O(k * m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ゲーム履歴全体を読み取り、徹夜後にどのプレイヤーが生き残っているかをシミュレーションします。 被害者として毎晩保存し、生前に行われた会議のリストを保存します。 
2. すべての生存者にビット位置を割り当てます。 マフィアのメンバーは殺すことができないため、これらのプレイヤーだけがマフィアである可能性があります。 
3. 毎晩、その夜に被害者に会った生存者プレイヤーのビットマスクを作成します。 有効なマフィア セットには、毎晩このマスクのビットが少なくとも 1 つ含まれている必要があります。 
4. 生存者のすべてのサブセットを列挙します。 各サブセットについて、毎晩チェックします。 サブセットがナイトマスクごとに交差する場合、それはマフィアのチームである可能性があります。 
5. 有効なサブセットの最小サイズを追跡し、それを出力します。 

なぜ効果があるのか:

 本物のマフィアのメンバーは皆、一晩中生き延びなければならないため、検索スペースには考えられるすべての答えが含まれています。 サブセットは、すべての被害者に、対応する夜に会ったそのサブセットのメンバーが少なくとも 1 人いる場合にのみ受け入れられます。 これはまさに、説明されているゲームが発生するために必要な条件です。 すべての有効なマフィア チームが考慮され、すべての無効なチームが拒否されるため、許容される最小サイズが必要な答えになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)

    k = int(next(it))
    m = int(next(it))

    nights = []
    alive = set(range(1, k + 1))

    for _ in range(m):
        t = int(next(it))
        meet = {}
        for _ in range(t):
            v = int(next(it))
            c = int(next(it))
            friends = []
            for _ in range(c):
                friends.append(int(next(it)))
            meet[v] = friends
        dead = int(next(it))
        nights.append((meet, dead))
        alive.remove(dead)

    survivors = sorted(alive)
    idx = {x: i for i, x in enumerate(survivors)}
    s = len(survivors)

    masks = []
    for meet, dead in nights:
        mask = 0
        for player in meet.get(dead, []):
            if player in idx:
                mask |= 1 << idx[player]
        masks.append(mask)

    ans = s
    for subset in range(1 << s):
        cnt = subset.bit_count()
        if cnt >= ans:
            continue
        ok = True
        for mask in masks:
            if subset & mask == 0:
                ok = False
                break
        if ok:
            ans = cnt

    print(ans)

if __name__ == "__main__":
    solve()
```すべての死亡が読み取られるまで最終的な生存者セットが不明であるため、パーサーはすぐに処理するのではなく毎晩保存します。 生存者を見つけた後は、考えられるすべてのマフィア メンバーを 1 ビットで表すことができるため、いくつかの整数演算で候補セットをチェックできます。 

の建設`masks`は中心となる実装の詳細です。 ビットは、その生存者がまさにその夜に被害者に会ったときにのみ設定されます。 サブセット テストは、2 つのビットマスク間の交差チェックになります。 必要なビット数は 15 ビットだけであるため、Python 整数はこれらのマスクを自然に処理します。 

列挙は、空のセットを含むすべてのサブセットから開始されます。 入力は有効なゲームを記述することが保証されているため、少なくとも 1 つのサブセットが通過します。 空のサブセットは夜がない場合にのみ通過しますが、ここでは不可能です。`m >= 1`ただし、ロジックを一般的なものにしておくことで、不必要な特殊なケースを回避できます。

| スペース | O(k * m) | 保存された履歴には、すべての会議の説明が含まれます。

import sys
import io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    data = sys.stdin.read().split()
    sys.stdin = old

    it = iter(data)
    k = int(next(it))
    m = int(next(it))

    nights = []
    alive = set(range(1, k + 1))

    for _ in range(m):
        t = int(next(it))
        meet = {}
        for _ in range(t):
            v = int(next(it))
            c = int(next(it))
            meet[v] = [int(next(it)) for _ in range(c)]
        dead = int(next(it))
        nights.append((meet, dead))
        alive.remove(dead)

    survivors = sorted(alive)
    idx = {x: i for i, x in enumerate(survivors)}
    masks = []

    for meet, dead in nights:
        mask = 0
        for x in meet[dead]:
            if x in idx:
                mask |= 1 << idx[x]
        masks.append(mask)

    ans = len(survivors)
    for sub in range(1 << len(survivors)):
        if sub.bit_count() >= ans:
            continue
        if all(sub & mask for mask in masks):
            ans = sub.bit_count()

    return str(ans) + "\n"

 ## 特殊なケース

 死亡したプレイヤーがマフィアとして選ばれるのは、最も一般的な概念上の間違いです。 アルゴリズムでは、すべての死亡が処理された後にのみ列挙が開始され、生存者のみが含まれるため、これは起こりません。 

生存者が被害者に会わなかった夜は、すべての候補者サブセットが不合格になるでしょう。 入力は、何らかのマフィアの割り当てが存在することを保証するため、この状況は有効なテストでは発生しませんが、チェック ループはすべてのサブセットを拒否することで正しく処理します。 

一人の生存者がすべての死を説明できる場合は自然に処理されます。 すべてのナイト マスクには同じビットが含まれており、そのビットのみを含むサブセットが最初の最小解になります。 

列挙では個々のプレイヤーだけでなく組み合わせもチェックされるため、複数の生存者が必要な場合もカバーされます。 サブセットは、毎晩その中に少なくとも 1 人の殺人犯の可能性があるものがある場合にのみ受け入れられます。
