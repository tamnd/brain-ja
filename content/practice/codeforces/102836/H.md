 ## 解決策
 ## 問題の理解

 平面上には最大 9 つのサポート ポイントが与えられます。 これらの点を単純な多角形の頂点として配置できるかどうかを決定する必要があります。つまり、多角形の境界線がそれ自体を横切ったり、隣接しない点でそれ自体に触れたりすることはできません。 同じ点のすべての有効な次数の中で、可能な限り最大の面積を与えるものを出力する必要があります。 

入力はサポートの座標を記述します。 出力は、単純なポリゴンを構築できないこと、またはポリゴンの頂点を訪問する順序を記述するポイント インデックスの順列のいずれかです。 

の非常に小さな値`n`問題に対する私たちの考え方が完全に変わります。 と`n <= 9`、すべての順列を試すには、最大でも`9! = 362880`候補者は少ないです。 すべての候補者に複数の幾何学的チェックが必要な場合でも、全体の作業は 2 秒の制限内で快適なままです。 多項式時間幾何学アルゴリズムは興味深いものですが、ここでは不要です。 

主な落とし穴はパフォーマンスに関係するものではなく、幾何学的なものです。 順列は、エッジが交差するため無効のままでありながら、大きな符号付き領域を持つ可能性があります。 たとえば、ポイントは、```
4
0 0
2 2
0 2
2 0
```として注文できます`1 2 3 4`、しかしエッジ`(1,2)`そして`(3,4)`クロス。 正しい答えは、このような自己交差を回避する必要があります。 

もう 1 つの注意が必要なケースは、すべての点が 1 つの線上にある場合です。```
3
0 0
1 0
2 0
```考えられるすべての順序によって縮退した形状が作成されるため、正の面積を持つポリゴンは存在しません。 アルゴリズムは、任意の順列を返す代わりに、それを拒否する必要があります。 

3 番目のよくある間違いは、ポリゴンのエッジがある点で別のエッジに接触してしまうことです。 このステートメントでは、交差だけでなく自己接触も禁止されているため、セグメント交差テストには、同一直線上にあるオーバーラップと、隣接しないエッジの端点接触のケースを含める必要があります。 

## アプローチ

 直接的なアプローチは、可能な限りのポイントの順序を生成することです。 順列ごとに、連続する点を接続し、最後に最後の点を最初の点に接続します。 結果として得られるサイクルが単純な多角形の場合、靴紐の公式を使用してその面積を計算し、最良のものを保持します。 

すべての点を使用するすべての可能なポリゴン境界が、生成された順列の 1 つとして表示されるため、この強引な方法は正しいです。 それらの中で最も有効な順列が、まさに必要な答えになります。 

このアプローチが実現可能な理由は、`n`。 最悪の場合は、`9!`順列。 順列ごとに検査します`n`エッジを検出し、エッジのペアを比較して交差を検出します。これは、ほぼ別の方法です。`n^2`要素。 プリミティブ演算の総数は依然として実用的な制限をはるかに下回っています。`9! * 9^2`単純小切手は約 2,900 万件です。 

より高度な幾何学構造では、中心の周りの点を並べ替えることによって最大面積のポリゴンを見つけることができますが、縮退したケースをより慎重に処理する必要があります。 入力サイズが小さいため、徹底的な検索がより安全かつ明確なソリューションになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * n^2) | O(n) | 承認済み |
 | 幾何学的構造 | O(n log n) | O(n) | 不要 |

 ## アルゴリズムのチュートリアル

 1. ポイント インデックスのすべての順列を生成します。 各順列は、トランポリンの境界の周りを歩く 1 つの可能な順序を表します。 
2. 現在の順序では、最後の頂点から最初の頂点までの最終エッジを含む、連続する頂点間にポリゴン エッジを構築します。 有効な答えには、これらすべてのエッジが単純なサイクルを形成している必要があります。 
3. 隣接しないエッジのペアをすべてチェックします。 いずれかのペアが交差する場合、この順列は拒否されます。 隣接するエッジは共有エンドポイントで接触できるため、このチェックではスキップされます。 
4. 有効な多角形ごとに、靴紐の式を使用してその 2 倍の面積を計算します。 2 倍の値を維持すると、浮動小数点精度の問題が回避されます。 
5. 見つかった最大面積の順列を保存します。 有効な置換がなかった場合は、出力`No`; それ以外の場合は出力`Yes`そして保存された注文。 

なぜ機能するのか: 与えられた点のあらゆる可能な配置が検査されます。 交差テストでは、単純な多角形を形成しない注文が正確に削除されます。 残りのすべての注文について、靴紐の式はその多角形の実面積を与えるため、すべての有効な候補の中から最大値を選択すると、最適な多角形が生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from itertools import permutations

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

def orientation(a, b, c):
    return cross(
        b[0] - a[0],
        b[1] - a[1],
        c[0] - a[0],
        c[1] - a[1]
    )

def on_segment(a, b, c):
    return (
        min(a[0], b[0]) <= c[0] <= max(a[0], b[0]) and
        min(a[1], b[1]) <= c[1] <= max(a[1], b[1])
    )

def segments_intersect(a, b, c, d):
    ab_c = orientation(a, b, c)
    ab_d = orientation(a, b, d)
    cd_a = orientation(c, d, a)
    cd_b = orientation(c, d, b)

    if ab_c == 0 and on_segment(a, b, c):
        return True
    if ab_d == 0 and on_segment(a, b, d):
        return True
    if cd_a == 0 and on_segment(c, d, a):
        return True
    if cd_b == 0 and on_segment(c, d, b):
        return True

    return (ab_c > 0) != (ab_d > 0) and (cd_a > 0) != (cd_b > 0)

def is_simple(order, pts):
    n = len(order)
    edges = []
    for i in range(n):
        edges.append((pts[order[i]], pts[order[(i + 1) % n]]))

    for i in range(n):
        for j in range(i + 1, n):
            if j == i + 1 or (i == 0 and j == n - 1):
                continue
            if segments_intersect(edges[i][0], edges[i][1], edges[j][0], edges[j][1]):
                return False
    return True

def area2(order, pts):
    s = 0
    n = len(order)
    for i in range(n):
        x1, y1 = pts[order[i]]
        x2, y2 = pts[order[(i + 1) % n]]
        s += x1 * y2 - y1 * x2
    return abs(s)

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    best = None
    best_area = -1

    for p in permutations(range(n)):
        if is_simple(p, pts):
            cur = area2(p, pts)
            if cur > best_area:
                best_area = cur
                best = p

    if best is None:
        print("No")
    else:
        print("Yes")
        print(*[x + 1 for x in best])

if __name__ == "__main__":
    solve()
```この実装では、まず幾何学的プリミティブを定義します。 外積は、有向セグメントに対して点が位置する側を決定し、すべての交差チェックの基礎となります。 

セグメント交差関数は、通常の交差ケースと同一線上のケースの両方を処理します。 隣接しないポリゴン エッジについては、点での接触や重なりも禁止されるため、共線性チェックが必要です。 

の`is_simple`関数はサイクル エッジを作成し、ポリゴン内で隣接しないペアのみを比較します。 定義上、隣接するエッジは頂点を共有するため、それらをチェックすると、有効なポリゴンがすべて誤って拒否されてしまいます。 

面積の計算には実際の面積の 2 倍が使用されます。 これにより、すべてが整数として保持され、精度エラーが回避されます。 すべての候補ポリゴンは同じ 2 倍の面積値を使用して比較されるため、最大値が保持されます。

 ## 特殊なケース

 同一線上の点の場合:```
3
0 0
1 0
2 0
```すべての順列により、面積がゼロの閉じたチェーンが作成されます。 アルゴリズムはすべての順序をチェックしますが、有効な正の領域のポリゴンを与えるものがないため、次のように出力します。`No`。 

交差候補の場合:```
4
0 0
2 2
0 2
2 0
```注文`1 2 3 4`自己交差する弓の形状を作成します。 アルゴリズムが 2 つの反対側のエッジを比較すると、交差テストによって交差が検出され、この順列が拒否されます。 他の順列も引き続き考慮され、有効な四角形の順序が見つかります。 

接触しているエッジについては、内部の共線性チェックが行われます。`segments_intersect`隣接しない 2 つのエッジが点を共有するか重なり合うケースを処理します。 これにより、正確なジオメトリを無視した場合にのみ有効に見える境界を持つポリゴンを受け入れることができなくなります。
