 ## 問題の理解

 魔方陣として知られる、部分的に塗りつぶされた 3×3 グリッドが与えられます。 つまり、グリッドには 1 から 9 までの数字が 1 回だけ含まれており、すべての行、すべての列、および両方の対角の合計が同じ値になります。 

ただし、9 つの位置すべてを受信するのではなく、特定の 5 つのセルのみを受信します。つまり、上の行の中央、真ん中の行の両端、および千鳥状に配置された下の 2 行の 3 つのセルです。 タスクは、完成したグリッドが有効な 3×3 の魔方陣になるように、欠落している 4 つの値を再構築することです。 

重要な構造上の制約は、1 ～ 9 の数字を使用する 3×3 の魔方陣が非常に厳格であることです。 いくつかの位置が固定されると、正方形全体が対称になるまで決定されます。 この厳密性により、既知の 5 つのエントリだけで問題を解決できるようになります。 

グリッド サイズは一定であるため、漸近的思考を強いるアルゴリズムの制約はありません。 定数時間推論、すべての有効な魔方陣に対する総当たり攻撃、または直接代数を試みるアプローチはどれも問題なく合格します。 

主な微妙な失敗例は、これを一般的な数独のような再構築問題として扱うことから生じます。 一般的なグリッド補完問題では、ローカルな一貫性はグローバルな一貫性を意味しません。 ここで、構造は完全に制約されているため、すべての制約を強制せずに部分的に貪欲なフィルを行うと矛盾が生じる可能性があります。 たとえば、合計を一致させるために行を個別に埋めると、列の一貫性が直ちに損なわれる可能性がありますが、これはすべての制約が同時にチェックされない限り検出できません。 

## アプローチ

 ブルートフォースの観点では、3×3 グリッドに配置された数字 1 から 9 のすべての可能な順列を考慮し、各構成が魔方陣の特性を満たすかどうかを確認し、指定された固定セルと一致するものを選択します。 9つあります！ = 362880 の順列、それぞれについて 8 つの線形制約 (3 行、3 列、2 つの対角線) をチェックします。 これはすでに Python で渡すのに十分な大きさですが、この検索のほとんどが不要であるという事実は無視されています。 

重要な観察点は、1 ～ 9 の数字を使用したすべての 3×3 魔方陣のセットはまったく大きくないということです。 実際、回転と反射までの基本的な構成は 1 つだけです。 すべての有効な正方形は、単一の標準正方形の 8 つの変換のうちの 1 つです。 これは、すべての有効な魔方陣を事前に定義し、それらに対して入力を単純に照合できることを意味します。 

標準的な正方形は次のとおりです。 

8 1 6

 3 5 7

 4 9 2

 他のすべての有効な正方形は、このグリッドの回転と反射から得られます。 したがって、順列を検索する代わりに、これら 8 つの候補を列挙し、指定された値と一致するものを選択できます。 

これにより、問題は定数時間のマッチングに帰着します。

 ## アルゴリズムのチュートリアル

 基本の魔方陣の 8 つの回転と反射をすべて構築し、各候補を部分的に埋められた入力と比較します。 既知のすべての位置と一致するものが答えです。 

1. 既知の標準構成を使用して標準魔方陣を構築します。 

この正方形は、対称性のあるすべての 3×3 魔方陣の唯一の代表です。 
2. 正方形のすべての変換 (0°、90°、180°、270° による回転、およびこれらのそれぞれの反射) を生成します。 

各変換では、行と列を対称的に並べ替えるだけであるため、マジック プロパティが保持されます。 
3. 変換された各正方形について、すべての既知の入力セルが候補内の対応する値と一致するかどうかを確認します。

不一致が発生した場合は、解決策にはならないため、候補を直ちに破棄します。 
4. 有効な候補が見つかったら、不足しているエントリを必要な形式で出力します。 

1 行目の欠落要素、2 行目の欠落要素、3 行目の欠落要素。 

これが機能する理由は、魔方陣構造が二面対称まで完全に決定されているためです。 有効な解はこれら 8 つの形式のいずれかである必要があるため、この有限セットに対する徹底的なチェックが完了し、あらゆる可能性を見逃すことはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# read input
a = [[0]*3 for _ in range(3)]

# mapping from problem input format:
# r1c2
a[0][1] = int(input().strip())

# r2c1, r2c3
x = list(map(int, input().split()))
a[1][0], a[1][2] = x

# r3c1, r3c2
x = list(map(int, input().split()))
a[2][0], a[2][1] = x

# base magic square
base = [
    [8, 1, 6],
    [3, 5, 7],
    [4, 9, 2]
]

def rot(mat):
    return [[mat[2-j][i] for j in range(3)] for i in range(3)]

def reflect(mat):
    return [row[::-1] for row in mat]

candidates = []
cur = base
for _ in range(4):
    candidates.append(cur)
    candidates.append(reflect(cur))
    cur = rot(cur)

def ok(mat):
    for i in range(3):
        for j in range(3):
            if a[i][j] != 0 and a[i][j] != mat[i][j]:
                return False
    return True

ans = None
for c in candidates:
    if ok(c):
        ans = c
        break

for i in range(3):
    if i == 0:
        print(ans[i][0], ans[i][2])
    elif i == 1:
        print(ans[i][1])
    else:
        print(ans[i][2], ans[i][1])
```コードは、入力形式で記述されているとおりに部分グリッドを再構築することから始まります。 5 つのポジションのみが埋まり、残りのポジションはゼロのプレースホルダーとして残されます。 

変換関数は、基本正方形の回転と反射を生成します。 回転関数は各セルを 90 度回転した位置にマップし、リフレクションにより各行を反転します。 

次に、生成された 8 つの正方形すべてを反復処理し、既知のエントリに対してそれぞれを検証します。 この問題では一意性が保証されているため、最初の一貫した候補が答えとして採用されます。 

最後に、出力は問題で必要とされる正確な非対称形式で出力され、各行から欠落しているエントリのみが選択されます。

 ## 特殊なケース

 部分入力が基本の向きではなく、正準正方形の回転または反射バージョンに対応する場合、微妙なケースが発生します。 たとえば、一番上の行の中心が 1 ではなく 2 である場合でも、アルゴリズムは回転された候補を正しく識別する必要があります。 

このような入力が与えられると、すべての候補が均一にテストされます。 既知の 5 つの位置のうち 1 つでも不一致があると、その方向は即座に失われます。 8 つの候補のうち 1 つがすべての制約に一致するため、アルゴリズムは常にそれを選択します。 

これにより、すべての変換が間接的に推論されるのではなく明示的にチェックされるため、対称性によって曖昧さが生じなくなります。
