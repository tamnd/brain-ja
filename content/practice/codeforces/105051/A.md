 ## 解決策
 ## 問題の理解

 選挙では 3 人の候補者が票を受け取っています。 第一候補者は現在、`a`2番目の票は`b`、3番目は`c`。 さらに多くの票が届く可能性がありますが、重要なのは最初の候補者への追加票のみです。 

タスクは、最初の候補者に与えなければならない追加投票の最小数を決定し、これらの票を追加した後、最初の候補者が全投票の少なくとも半分を保持するようにすることです。 「少なくとも半分」とは、最終的な投票数を次のように表すと、`A`、`B`、 そして`C`、 それから`A`満たさなければなりません`A ≥ (A + B + C) / 2`、または同等の`2A ≥ A + B + C`。 

入力サイズは最大です`10^9`、投票を 1 つずつ追加するシミュレーションは除外されます。 追加の投票の可能性を線形反復しても遅すぎるため、解は定数時間でなければなりません。 

微妙な点は「得票率50％」をどう解釈するかだ。 投票は整数であるため、四捨五入は扱いません。 この条件は純粋に算術的なものです。最初の候補は合計合計の少なくとも半分を持っていなければなりません。厳密にはそれ以上ではなく、四捨五入されてもなりません。 

素朴な間違いは、投票数を段階的に増やして「過半数になるまでシミュレーション」する必要があると考えることです。 これは大きな制約がある場合にはすぐに失敗し、小さな場合でも不必要に遅くなります。 

もう 1 つのよくある誤った解釈は、合計ではなく、他の候補の最大値と比較することです。 たとえば、`a+x ≥ max(b, c)`要件はペアごとの優位性ではなく、合計に関するものであるため、十分ではありません。 

## アプローチ

 強引なアプローチでは、追加投票数を増やそうとする可能性があります。`x`ゼロからスタートして、最初の候補者が総投票数の少なくとも半分に達しているかどうかを毎回チェックします。 各チェックでは合計を再計算して不等式を検証する必要があるため、コストは O(1) ですが、最悪の場合は`x`くらいまで成長するかもしれない`b + c`、全体の複雑さは O(b + c) になります。 までの値`10^9`、これはまったく不可能です。 

重要な観察は、条件が代数的に書き換えられるということです。 追加後`x`投票数、最初の候補者は`a + x`、合計は`a + b + c + x`。 要件は次のようになります。`2(a + x) ≥ a + b + c + x`拡張して単純化すると、合計の発展への依存がなくなり、問題が直接の不等式に還元されます。`x`。 これにより、タスクが検索ではなく単一の式の計算に変換されます。 

投票を追加すると分子と分母の両方が予測可能な方法で増加するため、問題の構造は線形です。 この単調性により、条件が一度真になると、それは真のままであることが保証されます。そのため、不等式を直接解くと正確な最小値が得られます。

 ## アルゴリズムのチュートリアル

 追加投票の数を最小限に抑えたい`x`最初の候補者が合計投票数の少なくとも半分を獲得するようにします。 

1. すべての候補者の現在の投票総数を計算します。 新たな投票を追加する前の合計は、`S = a + b + c`。 
2. 次のように追加するとします。`x`最初の候補者に投票するため、その新しいカウントは次のようになります。`a + x`、合計は次のようになります`S + x`。 
3. 「少なくとも半分」という条件を不等式に変換します。`2(a + x) ≥ S + x`。 これにより除算が削除され、浮動小数点推論が回避されます。 
4. 不等式を拡大して分離する`x`。 これにより、`2a + 2x ≥ a + b + c + x`。 
5. 用語を集めて簡略化します。`a + x ≥ b + c`。 
6. を解く`x`、降伏`x ≥ (b + c - a)`。 
7. Since`x`マイナスにはできません。`x = max(0, b + c - a)`。 

なぜ効果があるのか

 この不等式は、最初の候補者のシェアが全体の半分を超えるか、半分に達する点を正確に捉えています。 この変換により、分子と分母の間の動的な依存関係が削除され、すべてが 1 つの線形制約にまとめられます。 なぜなら、左側は右側よりも速く成長するからです。`x`が増加すると、不等式を満たす最小の整数が上で計算されたしきい値と正確に一致し、それより小さい値は条件を満たしません。 

## Python Solution```python
import sys
input = sys.stdin.readline

a = int(input().strip())
b = int(input().strip())
c = int(input().strip())

x = b + c - a
if x < 0:
    x = 0

print(x)
```実装では、派生した式が直接適用されます。 各入力は独立して読み取られるため、追加の処理は必要ありません。 

唯一の微妙な点は、結果がマイナスでないことを確認することです。 最初の候補者が条件を満たすのに十分な票をすでに持っている場合、計算された値は負になり、ゼロに固定されます。

 ## 特殊なケース

 最初の候補者がすでに十分な票を獲得している場合、派生式は`b + c - a`マイナスになる。 のような入力の場合`a = 100, b = 50, c = 49`、式は次のようになります`-1`ですが、正解は`0`。 クランプステップにより正確さが保証されます。 

入力の場合`a = 0`、 のような`0, 1, 1`、式は次のようになります`2`、段階的に検証すると、2 票を追加すると、最初の候補者が総投票数のちょうど半分に達することがわかります。 

近くの大きな値`10^9`解は反復シミュレーションやスケーリング動作ではなく、和と差のみに依存するため、同じように動作します。
