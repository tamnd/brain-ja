 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times n$グリッド。 1 人のキングは左下隅から始まります$(1,1)$もう 1 つは右上隅から始まります$(n,n)$。 コインが置かれている場所は、$(x,y)$、そして両方の王はできるだけ早くそこに到達しようとします。 彼らはチェスの王様のように動くので、一度の動きで対角線を含む隣接する 8 つのセルのいずれかに移動できます。 

この問題で重要なのは、キングがターゲット セルに到達するために必要な最小移動数です。 斜めの移動が許可されているため、キングは、可能な場合には行と列の両方の差を同時に効果的に削減します。 これにより、2 つのセル間の距離がチェビシェフ距離と等しくなります。$$\text{dist}((a,b),(c,d)) = \max(|a-c|, |b-d|)$$最初に白のキングが動き、次に黒のキングが交互に動きます。 各移動には、移動するキングの距離がちょうど 1 ステップかかります。 到達した人が勝者です$(x,y)$初め。 

制約により許可されるのは、$n$まで$10^{18}$, そのため、段階的に動きをシミュレーションすることは不可能です。 一定時間内に距離を計算しなければなりません。 

微妙なエッジケースは、キングがコインからスタートする場合です。 もし$x,y = 1,1$, 黒が動く直前に白が勝ちます。 もし$x,y = n,n$、黒はすぐに勝ちます。 どのソリューションでも、これらの即時勝利を正しく処理する必要があります。 

もう 1 つのエッジ ケースはパリティです。絶対距離が黒のほうが近い場合でも、黒がもう 1 手必要で後攻の場合は、白が勝つ可能性があります。 

## アプローチ

 ブルートフォースシミュレーションでは、両方のキングを段階的に動かし、常にコインに向かって最短の動きを選択します。 各王が必要とするのは$O(n)$最悪の場合の移動は一定時間となり、$O(n)$王ごとに。 以来$n$できる$10^{18}$、これはまったく不可能です。 

重要な観察は、最適なプレイは決定論的であるということです。両方のキングは常に最短経路に沿って移動するため、到着時間は最初の距離によって完全に決まります。$(x,y)$。 残る唯一の微妙な点はターン順序です。 

次のように計算します。 

-$d_w = \max(|x-1|, |y-1|)$-$d_b = \max(|n-x|, |n-y|)$ホワイトは時間通りに到着$2 \cdot d_w$またはより正確には$2 \cdot d_w$ゲームタイムラインのターンですが、白が最初に動くため、彼の実質的な到着ターンは次のとおりです。$2d_w - 1$。 

黒がターンに到着$2d_b$。 

したがって、比較は次のようになります。$$2d_w - 1 < 2d_b$$true の場合は白が勝ち、そうでない場合は黒が勝ちます。 

これにより、問題全体が 2 つのチェビシェフ距離を計算し、それらを小さなパリティ シフトと比較することに帰着します。

 | ブルートフォースシミュレーション |$O(n)$|$O(1)$| 遅すぎる |

 ## アルゴリズムのチュートリアル

 1. チェビシェフ計量を使用して、白のキングとコインまでの距離を計算します。 これは、白が最適にプレイする場合に必要な最小手数を表します。 
2. 同様に、次から始めて、黒の王からコインまでの距離を計算します。$(n,n)$。 
3. 両方の距離を「コインに到達したときのターン」に変換します。 白はターンでリーチします$1,3,5,\dots$、つまり、彼の到着順番は$2d_w - 1$。 黒はターンでリーチします$2,4,6,\dots$、だから彼のは$2d_b$。 
4. これら 2 つの値を比較します。 白の到着ターンが厳密に小さい場合は、白が勝ちます。 それ以外の場合は黒が勝ちます。 

ステップ 3 が有効である理由は、両方のプレイヤーが移動ごとに正確に 1 だけ距離を縮め、いかなる移動もチェビシェフの距離を 1 単位以上縮めることができないためです。 

### なぜ効果があるのか

 重要な不変条件は、最適なプレイの下では各キングのターゲットまでの距離が 1 手ごとに正確に 1 ずつ減少し、それをより速く短縮できる代替戦略は存在しないということです。 手の順序は固定されている（白は常に開始する）ため、非対称性は白にとって 1 手の利点だけです。 距離をターン インデックスに変換すると、この利点が正確に得られるため、$2d_w - 1$そして$2d_b$完全に勝者を決定します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    x, y = map(int, input().split())

    dw = max(abs(x - 1), abs(y - 1))
    db = max(abs(n - x), abs(n - y))

    white_turn = 2 * dw - 1
    black_turn = 2 * db

    if white_turn < black_turn:
        print("White")
    else:
        print("Black")

if __name__ == "__main__":
    solve()
```キングは斜めに移動できるため、白と黒の距離はチェビシェフ メトリックを使用して計算され、両方の座標が同時に減少します。 ターン インデックスへの変換は非常に重要です。白の最初の動きは、交互シーケンスで 1 ステップのアドバンテージを与えます。これは、最終到達時間で 1 を減算することで得られます。 

両方が同じターンに到着した場合は、黒が 2 番目に移動したために勝利したとみなされるため、この比較は厳密です。
