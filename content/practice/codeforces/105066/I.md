 ## 問題の理解

 整数の配列が与えられ、非負の整数パラメーターによって制御される変換を繰り返し適用します。$x$。 固定的な選択の場合、$x$、すべての配列要素$a_i$と XOR 演算されます$x$、これらすべての結果が合計されます。 これにより単一の値が生成されます$$S(x) = \sum_{i=1}^{n} (a_i \oplus x)$$タスクはこれを計算することではありません$x$、ただし、のすべての可能な値を理解する必要があります。$S(x)$として$x$すべての非負の整数にわたる範囲を調べ、その間隔内に含まれる個別の結果の数を数えます。$[l, r]$。 

重要な難点は、$x$入力には制限がないため、関数は$S(x)$は無限領域にわたって定義されていますが、その構造は次のビットのみに依存します。$x$、どのビットにも現れる最上位ビットまでのみ$a_i$。 ずっと$a_i \le 10^5$、基本値では約 17 ビットのみが重要であり、上位ビットは XOR パターンに均一にのみ影響します。 

この制約により、私たちは直接列挙することができなくなります。$x$。 と$n$まで$10^5$そして$x$潜在的に大規模で均一なコンピューティング$S(x)$みんなのために$x$まで$r$不可能です。 ソリューションはすべての効果を圧縮する必要があります$x$小さな構造化表現に変換します。 

単調性を仮定すると、微妙な問題が発生します。 素朴な推測としては、$S(x)$と滑らかに変化します$x$、しかし XOR は単調性を破壊します。 たとえば、単一の要素の場合$a = 5$、シーケンス$a \oplus x$振動します:$5,4,7,6,1,0,3,2,\dots$したがって、到達可能な値が連続した間隔を形成するという仮定は誤りです。 

もう 1 つの落とし穴は、XOR が配列全体の固定母数とどのように相互作用するかを考慮せずに、ビットを独立して処理することです。 この関数は組み合わせの意味ではビットごとに線形ですが、その数に応じて異なります。$a_i$各ビットを設定します。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのことを繰り返すことになります。$x$で$[0, r]$、計算する$S(x)$、個別の値を収集します。 それぞれの評価にかかる費用$O(n)$、につながる$O(nr)$最悪の場合の運用。 以来$r$と同じ大きさにすることができます$10^{18}$、これは不可能です。 

重要な観察は、固定値との XOR です。$x$各ビットに独立して影響します。 ビット位置固定の場合$k$、 かどうか$(a_i \oplus x)$ビットがある$k$セットはのみに依存します$a_i$のビット$k$そして$x_k$。 これにより、合計をビットごとの寄与の関数として書き直すことができます。 

ビットごとに$k$、 させて$c_k$要素の数になります。$k$-番目のビット$a_i$は 1. 次に、与えられた場合$x$、ビットさんの貢献$k$合計額は次のいずれかによって決まります。$x_k$は 0 または 1:

 もし$x_k = 0$、貢献度は$c_k \cdot 2^k$。 もし$x_k = 1$、になります。$(n - c_k) \cdot 2^k$。 これにより、問題は 2 つの寄与のうち 1 つをビットごとに独立して選択することに変わります。 

したがって、すべての$S(x)$各ビットに対して 2 つの値のうちの 1 つを選択することに対応します。 可能なすべての合計のセットは、関連するビットにわたるこれらの独立した選択のすべての組み合わせのセットです。 最大 17 ビットなので、最大でも$2^{17} = 131072$可能な金額。 

単純な DFS またはビットの反復構造を使用してすべての合計を生成し、それらを並べ替えて、範囲クエリに答えることができます。$[l, r]$二分探索経由。

 ## アルゴリズムのチュートリアル

 すべての効果を圧縮します$x$ビットごとに独立したバイナリ選択肢に分割されます。 

1. 各ビットが設定されている配列要素の数を数えます。 ビット位置ごとに$k$、計算する$c_k = |\{i : a_i \text{ has bit } k\}|$。 これにより、XOR がそのビットにどのような影響を与えるかをグローバルに分離できます。 
2. 各ビットについて$k$、2 つの考えられる寄与を事前計算します。$x_k = 0$、ビットが貢献します$c_k \cdot 2^k$、そしていつ$x_k = 1$、貢献します$(n - c_k) \cdot 2^k$。 これにより、ビットを切り替えたときの完全な効果が得られます。$x$。 
3. ビットを反復して、可能なすべての合計を計算します。 0 を含むセットから開始します。ビットごとに、そのビットの 2 つの寄与のいずれかを既存のすべての部分和に追加することによって、現在のセットを拡張します。 これが機能するのは、ビットが追加的かつ独立して寄与するためです。 
4. すべての関連ビットを処理した後 (任意のビットに存在する最上位ビットまで)$a_i$)、到達可能な値の完全なセットを取得します。$S(x)$。 このリストを並べ替えます。 
5. 二分探索を使用して、含まれる値の数を数えます。$[l, r]$。 

### なぜ効果があるのか

 XOR は位置間のキャリーなしでビット単位で動作するため、各ビットは独立して寄与します。 固定ビットの場合、寄与は次のいずれかにのみ依存します。$x_k$ビットを反転するかどうかを決定し、この決定は他のビットと相互作用しません。 したがって、すべての有効な$x$は、ビットごとに 1 つの寄与の一意の選択に対応し、そのようなすべての選択は、いくつかの$x$。 これにより、ビット選択と合計の間に 1 対 1 のマッピングが確立され、完全性が保証され、異なるビット パターンからの同一の合計を超える重複はなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, l, r = map(int, input().split())
    a = list(map(int, input().split()))

    MAXB = 0
    for v in a:
        MAXB = max(MAXB, v.bit_length())

    cnt = [0] * (MAXB + 1)

    for v in a:
        for b in range(MAXB + 1):
            if v >> b & 1:
                cnt[b] += 1

    # possible contributions per bit
    choices = []
    for b in range(MAXB + 1):
        bit_val = 1 << b
        c = cnt[b]
        choices.append((c * bit_val, (n - c) * bit_val))

    # build all possible sums
    sums = {0}
    for zero_val, one_val in choices:
        new = set()
        for s in sums:
            new.add(s + zero_val)
            new.add(s + one_val)
        sums = new

    arr = sorted(sums)

    # count in range [l, r]
    import bisect
    return bisect.bisect_right(arr, r) - bisect.bisect_left(arr, l)

print(solve())
```実装では、まず各ビットを 2 値の選択肢に圧縮します。$x_k = 0$または$x_k = 1$。 セットの構築では、以前の部分和を各ビットの寄与で拡張することによって、可能なすべての和を反復的に累積します。 最後の並べ替えステップにより、効率的な範囲カウントが可能になります。 

微妙な点は、明示的に構築することは決してないということです。$x$。 代わりに、考えられるすべての結果を直接構築します$S(x)$。 これにより、潜在的に巨大な値の処理が回避されます。$x$、最大ビットまでのビットパターンのみが重要であるため、これらは無関係です。$a_i$。

 ## 特殊なケース

 重要なエッジ ケースは、配列内のすべての数値がすべてのビットで同一である場合です。 その場合、任意のビットを反転すると、$x$1 と 0 の間のバランスは変更されないため、複数の構成は同じ合計に集約されます。 セットの挿入により重複が削除されるため、アルゴリズムはこれを自然に処理します。 

もう一つのケースは次のような場合です。$l = r = 0$。 このアルゴリズムは、生成されたセットに 0 が出現するかどうかを正確にカウントします。 貢献を追加する前の初期状態は常に 0 であるため、このケースは特別な処理なしで常に通過します。 

3 番目のケースは、1 つのビット位置のみがアクティブな場合です。 次に、各ビットは単純な 2 つの値の選択に寄与し、最終的なセットのサイズは最大 2 になります。各展開は独立しており、複数のアクティブ ビットを想定していないため、反復構造は依然としてきれいに適用されます。
