 **タグ:** *特殊、貪欲、並べ替え

 ## 解決策
 ## 問題の理解

 オブジェクトのコレクションが 2 つあります。 マーカーは次のように記述されます。`(color, diameter)`キャップについても次のように説明されています。`(color, diameter)`。 

キャップは、直径が等しい場合にのみマーカーに取り付けることができます。 有効な組み合わせの中には、色も一致する場合に「美しい」とみなされるものもあります。 

最適化目標には 2 つの層があります。 まず、一致するマーカーとキャップのペアの合計数を最大化します。 この最大値を達成するすべての方法の中で、美しい一致の数を最大化します。 

マーカーとキャップはそれぞれ 1 回ずつ使用できます。 

制約が大きいため、すべてのペアリングを直接試すことはできません。 両方`n`そして`m`到達できる`10^5`、だから、`O(n * m)`ソリューションは最大でパフォーマンスを発揮します`10^10`制限時間をはるかに超えた比較。 線形に近いものが必要です。`O(n log n)`。 

最も重要な観察は、直径が互換性を完全に決定するということです。 直径のあるキャップ`5`直径のマーカーと対話することはできません`7`。 これは、すべての直径グループを個別に処理できることを意味します。 

不用意なソリューションを簡単に破ってしまうようなエッジケースがいくつかあります。 

次の入力を考えてみましょう。```
2 2
1 5
2 5
3 5
4 5
```正しい答えは次のとおりです。```
2 0
```一致する色がなくても、すべての直径が一致するため、すべてのマーカーを閉じることができます。 美しい一致だけを検索する間違った貪欲な戦略は戻ってきます。`0 0`。 

次に、次のことを考えてみましょう。```
2 1
1 3
1 3
1 3
```正しい答えは次のとおりです。```
1 1
```キャップは 1 つだけ存在するため、閉じることができるマーカーは 1 つだけです。 各キャップが使い捨てであることを忘れると、誤って生成される可能性があります。`2 2`。 

もう 1 つの微妙なケースは、美しい一致を最大化するのが早すぎて、一致の総数が減少する場合です。```
2 2
1 1
2 1
1 1
3 1
```正しい答えは次のとおりです。```
2 1
```まずは貪欲に唯一のものを摂取してみると、`(1,1)`最初のマーカーにキャップを付けても、2 番目のマーカーは引き続き使用できます`(3,1)`、それですべてがうまくいきます。 しかし、より複雑なバリエーションでは、主な目的を尊重せずにキャップを消費すると、閉じられたマーカーの総数が減少する可能性があります。 この問題では、完全な一致が美しい一致よりも重要であることが明示されているため、アルゴリズムはその優先順位を維持する必要があります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 すべてのマーカーについて、すべてのキャップをスキャンし、同じ直径の未使用のキャップを選択します。 可能であれば、キャップの色も同じものが望ましいです。 

このアプローチは、有効なペアリングを直接構築しようとするため、論理的には正しいです。 概念的には問題は小さいように見えますが、制約によりこの解決策は破壊されます。 と`10^5`マーカーと`10^5`キャップ、私たちは実行するかもしれません`10^10`互換性チェック。 最適化された言語であっても、これは遅すぎます。 

重要な観察は、互換性は直径のみに依存するということです。 すべてを直径でグループ化すると、異なるグループは完全に独立したものになります。 

1 つの固定直径に焦点を当てたとします。`d`。 このグループ内では:```
marker colors: frequencies
cap colors: frequencies
```閉じることができるマーカーの最大数は次のとおりです。```
min(total markers with diameter d,
    total caps with diameter d)
```この最初の目的では、色の情報は重要ではありません。 

そして、それらの最大限の組み合わせの中で、できるだけ多くの美しい組み合わせが必要になります。 特定の色の場合`c`、作成できる美しいペアの数は次のとおりです。```
min(markers[d][c], caps[d][c])
```それぞれの美しい一致は、その正確な色の 1 つのマーカーと 1 つのキャップを消費するためです。 

重要なのは、美しい一致を最大化しても、一致の総数が減ることはありません。 美しいペアはすでに有効なペアであり、同じ直径グループ内の残りの不一致アイテムは、可能な最大数に達するまで任意にペアにすることができます。 

これにより、問題は頻度カウントに限定されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(nm) | O(m) | 遅すぎる |
 | 最適 | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのマーカーを読み取り、直径と色でグループ化します。 

マーカーごとに`(x, y)`、増分:```
markers_by_diameter[y]
markers_by_color[(y, x)]
```最初の構造は、直径に対していくつのマーカーが存在するかを追跡します。 2番目のトラックは正確です`(diameter, color)`周波数。 
2. すべての大文字を読み、同じ方法でグループ化します。 

キャップごとに`(a, b)`、増分:```
caps_by_diameter[b]
caps_by_color[(b, a)]
```3. 閉じたマーカーの最大数を計算します。 

表示される直径ごとに、次を追加します。```
min(markers_by_diameter[d],
    caps_by_diameter[d])
```等しい直径のみが相互作用できるため、これはその直径で可能なペアの最大数です。 
4. 美しい一致の最大数を計算します。 

あらゆる人にとって`(diameter, color)`マーカー間に表示されるペアに次を追加します。```
min(markers_by_color[(d, c)],
    caps_by_color[(d, c)])
```このような各ペアは、美しい一致の機会に対応します。 
5. 2 つの合計を出力します。 

### なぜ効果があるのか

 このアルゴリズムは、直径グループが独立しているという事実に基づいています。 ある直径のキャップは、別の直径のマーカーには決して役立ちません。 

固定直径グループ内では、有効なペアの最大数は小さい側によって完全に決定されます。 マーカーが 8 個、直径のキャップが 5 個ある場合`d`、どの戦略でも 5 つを超えるペアを作成することはできず、任意の組み合わせで 5 が達成されます。 

美しい一致とは、すでに有効な組み合わせを改良したものです。 各色について、可能な限り同じ色のペアを貪欲に作成します。 いずれにせよ、すべての美しいペアはすでに互換性のある 1 つのマーカーと 1 つのキャップを消費しているため、これによってペアの総数を減らすことはできません。 残りの不一致アイテムは、直径に基づいて任意にペアにすることができます。 

両方の目標はすべての直径グループ内で独立して一貫して最適化されるため、最終的な答えは全体的に最適になります。 

## Python ソリューション```python
import sys
from collections import defaultdict

input = sys.stdin.readline

n, m = map(int, input().split())

markers_by_diameter = defaultdict(int)
caps_by_diameter = defaultdict(int)

markers_by_color = defaultdict(int)
caps_by_color = defaultdict(int)

for _ in range(n):
    x, y = map(int, input().split())
    markers_by_diameter[y] += 1
    markers_by_color[(y, x)] += 1

for _ in range(m):
    a, b = map(int, input().split())
    caps_by_diameter[b] += 1
    caps_by_color[(b, a)] += 1

closed = 0
beautiful = 0

all_diameters = set(markers_by_diameter.keys()) | set(caps_by_diameter.keys())

for d in all_diameters:
    closed += min(markers_by_diameter[d], caps_by_diameter[d])

for key, cnt in markers_by_color.items():
    beautiful += min(cnt, caps_by_color[key])

print(closed, beautiful)
```実装の最初の部分では、頻度テーブルを構築します。 使用する`defaultdict(int)`繰り返しの存在チェックを回避し、更新を一定時間に保ちます。 

このコードは、直径によるカウントと正確なカウントを分離しています。`(diameter, color)`ペア。 これは、問題の 2 つの最適化目標を反映しています。 直径カウントは合計一致の最大数を決定し、正確なペア数は美しい一致の最大数を決定します。 

直径セットの和集合は、閉じたマーカーの合計を計算するときに使用されます。 これにより、片側にのみ表示される直径を見逃すことがなくなります。 

美しい一致を得るには、マーカー キーを反復処理するだけで十分です。 もし`(diameter, color)`ペアがキャップ間に存在しない場合、defaultdict は自動的にゼロを返します。 

問題は順序ではなく頻度のみに依存するため、並べ替えは必要ありません。

# helper: run solution on input string, return output string
import sys
import io
from collections import defaultdict

def solve():
    input = sys.stdin.readline

    n, m = map(int, input().split())

    markers_by_diameter = defaultdict(int)
    caps_by_diameter = defaultdict(int)

    markers_by_color = defaultdict(int)
    caps_by_color = defaultdict(int)

    for _ in range(n):
        x, y = map(int, input().split())
        markers_by_diameter[y] += 1
        markers_by_color[(y, x)] += 1

    for _ in range(m):
        a, b = map(int, input().split())
        caps_by_diameter[b] += 1
        caps_by_color[(b, a)] += 1

    closed = 0
    beautiful = 0

    all_diameters = set(markers_by_diameter) | set(caps_by_diameter)

    for d in all_diameters:
        closed += min(markers_by_diameter[d], caps_by_diameter[d])

    for key, cnt in markers_by_color.items():
        beautiful += min(cnt, caps_by_color[key])

    print(closed, beautiful)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    return sys.stdout.getvalue().strip()

 ## 特殊なケース

 色は決して一致しないが、直径は一致する場合を考えてみましょう。 

入力：```
2 2
1 5
2 5
3 5
4 5
```アルゴリズムは以下を計算します。```
diameter 5:
markers = 2
caps = 2
```したがって、閉じたマーカーの合計は次のようになります。`2`。 

美しいマッチングのために:```
(5,1): min(1,0) = 0
(5,2): min(1,0) = 0
```最終的な答えは次のとおりです。```
2 0
```これは、アルゴリズムが通常の一致に対して色の同等性を誤って要求していないことを確認します。 

ここで、キャップが少なすぎる同じマーカーが繰り返される場合を考えてみましょう。 

入力：```
3 1
1 2
1 2
1 2
1 2
```アルゴリズムは以下を計算します。```
diameter 2:
markers = 3
caps = 1
```したがって、合計一致は 1 つだけ可能です。 

美しいマッチングのために:```
(2,1): min(3,1) = 1
```答えは次のようになります。```
1 1
```これにより、すべてのキャップが最大 1 回消費されることが検証されます。 

最後に、孤立した直径グループを考慮します。 

入力：```
2 2
1 1
2 2
1 2
2 3
```直径の寄与:```
diameter 1: min(1,0) = 0
diameter 2: min(1,1) = 1
diameter 3: min(0,1) = 0
```美しい試合:```
(2,2): min(1,0) = 0
```出力：```
1 0
```これは、異なる直径のグループが完全に独立しており、互いに助け合うことができないことを示しています。
