 ## 解決策
 ## 問題の理解

 この問題では、接続されたグラフが得られます。`n`頂点と`m`エッジ。 各エッジには 3 つの情報があります。端点、以下の正の整数の重みです。`x`、および赤、緑、または青のいずれかの色。 タスクは頂点から歩くことです`1`頂点へ`n`エッジに沿って、頂点とエッジを複数回再訪する可能性があります。 特定の散歩について、次のように定義します。`s_r`、`s_g`、 そして`s_b`横断した赤、緑、青のエッジの合計の重みとして、複数の横断をカウントします。 目標は、これらの合計の最大値と最小値の差を最小限に抑えることです。 

出力はテスト ケースごとに 1 つの整数、つまり次の可能な最小値です。`max(s_r, s_g, s_b) - min(s_r, s_g, s_b)`すべての散歩の中で`1`に`n`。 

この制約により、すべてのウォークを強引に探索することは不可能になります。 と`n`そして`m`まで`2 * 10^5`そして最大まで`10^4`テスト ケースでは、すべてのパスを探索するアルゴリズムは簡単に超えてしまいます。`10^9`操作。 代わりに、ソリューションでは、明示的な列挙ではなく、代数または数論的な洞察を使用して、色付きのエッジの合計をどのようにバランスさせることができるかを推論する必要があります。 

重要な点は、エッジの繰り返しが許可されるため、ループを使用して合計を調整できることです。 たとえば、三角形の場合`1-2-3-1`色付き`r, g, b`そしてすべての重み付け`1`、サイクルを複数回横断して、`s_r = s_g = s_b`、差ゼロを達成します。 最小の合計ウェイトのみを考慮する単純な最短パスのアプローチは、色のバランスをとる必要性を無視しているため、失敗します。 

もう 1 つの微妙な点は、複数のエッジと自己ループが存在することです。 自己ループを使用すると、エンドポイントを変更せずに合計を微調整できます。 複数のエッジを使用すると、色のバランスをとるために異なる重みのエッジの中から選択できます。 

## アプローチ

 ブルートフォースアプローチでは、すべてのウォークを列挙します。`1`に`n`、計算する`(s_r, s_g, s_b)`それぞれについて、最小の差を追跡します。 これは原理的には正しいですが、ウォーク数が際限なく増加するため、指数関数的に遅くなります。`n`そして`m`増加。 

重要な観察は、グラフが接続されており、すべてのエッジの重みが正の整数であることです。 反復的な走査が許可されているため、サイクルと単純なパスの任意の整数の組み合わせを使用して合計を調整できます。 これにより、問題は、色の合計のバランスをとる線形システムの整数解を見つけることに帰着します。 本質的には、散歩道を見つける必要がある`P`から`1`に`n`イニシャル付き`(s_r, s_g, s_b)`次に、必要に応じてサイクルを走査して、次の倍数を追加します。`(Δ_r, Δ_g, Δ_b)`サイクルごとに。 達成可能な最小の差は、サイクルの最小の非負の整数の組み合わせに対応します。`s_r = s_g = s_b`可能であれば、または可能な限り近い。 

具体的には、スパニング ツリーを使用して、次のような単純なパスを定義できます。`1`に`n`。 このパスに沿った色の合計が開始点となります。 次に、ツリーに含まれていない残りの各エッジがサイクルを形成します。 サイクルを横断すると、そのサイクルに沿ってカラー ウェイトが追加されます。 重みは整数なので、問題は次の最小値を計算することになります。`max(s_r, s_g, s_b) - min(s_r, s_g, s_b)`これらのサイクル ベクトルの整数の組み合わせを使用して達成できます。 最小の差は、すべての合計が等しい解が存在する場合はゼロ、またはサイクルの線形結合を使用して達成可能な最小の差のいずれかです。 

この問題は、3 次元の部分集合和問題に関連しています。 最大重量なので`x`は制限されており、すべてのテスト ケースのすべての重みの合計は最大で`2 * 10^5`、到達可能な空間で幅優先検索を使用することが可能です。`(s_r, s_g, s_b)`小さな倍数を法として計算するか、等価的に、整数の差に関する動的計画法に還元します。 基本的に、サイクルを繰り返し追加することによって、達成可能な差はすべて、各色のエッジの重みの最大公約数の倍数であることがわかります。 これにより、`O(n + m)`各テスト ケースの DFS ベースのアルゴリズム。

 ## アルゴリズムのチュートリアル

 1. 入力を解析し、グラフの隣接リストを構築し、保存します。`(neighbor, weight, color)`各エッジごとに。 これにより、効率的なトラバースがサポートされます。 
2. 各色に数値インデックスを割り当てます: 赤=0、緑=1、青=2。 これにより、次のことを表現できるようになります。`(s_r, s_g, s_b)`長さ 3 の配列として。 
3. DFS または BFS を実行して、からのパスを検索します。`1`に`n`。 このパスに沿って各色のウェイトの合計を記録します。 これにより、初期値が得られます`(s_r, s_g, s_b)`。 
4. DFS ツリーで使用されていない残りのエッジをすべて特定します。 このような各エッジは、その端点間のツリー パスと組み合わせるとサイクルを形成します。 カラー重みベクトルを計算する`(Δ_r, Δ_g, Δ_b)`サイクルごとに。 これらのベクトルは、サイクルの反復走査によって合計がどのように調整されるかを表します。 
5. サイクル間の各色の差の最大公約数 (GCD) を計算します。 これにより、合計のバランスをとるために可能なゼロ以外の最小増分が決まります。 
6. GCD を使用して、達成可能な最小値を決定します。`max(s_r, s_g, s_b) - min(s_r, s_g, s_b)`。 初期の差が GCD で割り切れる場合、最小の差はゼロになります。 それ以外の場合は、GCD を法とした剰余になります。 
7. 各テストケースの結果を出力します。 

効果がある理由: から歩くたびに`1`に`n`は、初期パスとサイクル走査の線形結合として表すことができます。 サイクルは 3D カラーウェイト空間で格子を形成するため、達成可能な`(s_r, s_g, s_b)`ベクトルは、サイクル ベクトルと初期パスのすべての整数の組み合わせです。 GCD により、合計を均等化するための最小増分が確実にわかります。 これにより、計算された最小の差が正しいことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import gcd
from collections import defaultdict, deque

def solve():
    t = int(input())
    for _ in range(t):
        n, m, x = map(int, input().split())
        adj = [[] for _ in range(n)]
        edges = []
        color_idx = {'r':0, 'g':1, 'b':2}
        for _ in range(m):
            u,v,w,c = input().split()
            u = int(u)-1
            v = int(v)-1
            w = int(w)
            ci = color_idx[c]
            adj[u].append((v,w,ci))
            adj[v].append((u,w,ci))
            edges.append((u,v,w,ci))
        
        parent = [-1]*n
        used_edge = set()
        stack = [(0, -1)]
        path_found = False
        while stack:
            node, par = stack.pop()
            parent[node] = par
            if node == n-1:
                path_found = True
                break
            for nei,w,ci in adj[node]:
                if parent[nei]==-1:
                    stack.append((nei,node))
        s = [0,0,0]
        node = n-1
        while parent[node]!=-1:
            par = parent[node]
            for nei,w,ci in adj[node]:
                if nei==par:
                    s[ci]+=w
                    used_edge.add((min(node,nei), max(node,nei), ci, w))
                    break
            node = par
        
        # all cycles
        diffs = []
        for u,v,w,ci in edges:
            key = (min(u,v), max(u,v), ci, w)
            if key in used_edge:
                continue
            vec = [0,0,0]
            vec[ci] = w
            diffs.append(vec)
        
        if not diffs:
            print(max(s)-min(s))
            continue
        
        g = 0
        for d in diffs:
            diff_values = [d[i]-d[j] for i in range(3) for j in range(i+1,3)]
            for val in diff_values:
                g = gcd(g, val)
        if g==0:
            print(0)
        else:
            current_max = max(s)
            current_min = min(s)
            diff = current_max - current_min
            print(diff % g)
        
if __name__ == "__main__":
    solve()
```コードは頂点から DFS ツリーを構築します`1`頂点までのパスに沿って色の合計を計算します`n`。 次に、サイクル エッジを識別し、3D 色空間でのその影響を計算します。 サイクル間の色差の GCD によって、可能な最小限の調整が決まります。 モジュロ演算により、達成可能な最小の差が得られます。 エッジキーは慎重に扱われます`min(u,v)`そして`max(u,v)`二重カウントを避けるため。
