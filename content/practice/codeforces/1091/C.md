 1. すべての整数を反復処理します。$d$そのような$d \mid n$。 各サイクル構造は次のように一意に決定されるため、約数のみを考慮します。$\gcd(n, k)$、これはの約数でなければなりません$n$。

### なぜ効果があるのか

 あらゆるステップサイズ$k$円を素のサイクルに分割します。その構造は次のもののみに依存します。$d = \gcd(n, k)$。 2 つの異なる$k$同じ gcd を持つ値は同一の訪問セットを生成するため、同じ fun 値に寄与します。 逆に、異なる除数は異なるサイクル分解を生成するため、すべての個別の fun 値は 1 つの除数クラスに正確に対応します。 gcd クラスと回答の間のこの全単射により、完全性が保証され、過剰なカウントが回避されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    res = set()
    
    d = 1
    while d * d <= n:
        if n % d == 0:
            for div in (d, n // d):
                m = n // div
                # sum of arithmetic structure derived from cycle decomposition
                val = m * (2 * n - (m - 1) * div) // 2
                res.add(val)
        d += 1
    
    ans = sorted(res)
    print(*ans)

if __name__ == "__main__":
    solve()
