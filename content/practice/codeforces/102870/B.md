 # 問題の理解

 可能な限りあらゆる長さのユニークな Orz パンダ ブレスレットを販売することで、どれだけのお金が得られるか数えてみる必要があります。`m`。 ブレスレットは円形に配置されています`n`各位置は 1 つの長方形のブロックで占められます。 ブロックは高さ 2 の円柱のタイリングを形成するため、1 つの列に 1 つの垂直ブロックを含めることも、2 つの水平ブロックで隣接するブロックとペアにすることもできます。 円柱を中心の周りに回転させると一致する場合、2 つのブレスレットは同一とみなされます。 

固定長の場合`n`、タスクは生のタイリングの数を要求しません。 タイリングの回転クラスの数を求めます。 もしその数字が`b[n]`、お金への貢献は`n * b[n]`。 最終的な答えは、これらすべての貢献度の合計です。`1 <= n <= m`、剰余を取得`p`。 

入力値は意図的に極端になっています。 以来`m`到達できる`10^9`可能なすべてのブレスレットの長さを反復することは不可能です。 たとえ`O(m)`再発には数十億回の操作が必要になるため、遅すぎます。 問題をおおよそ平方根時間に短縮する公式を使用する必要があります。 

最初の隠れた問題は、ブレスレットの円形の性質です。 ブレスレットを通常通りに扱う`2 x n`長方形では、異なる切断位置が異なるオブジェクトとしてカウントされます。 たとえば、`n = 2`、3 つのユニークなブレスレットがサンプル回答の貢献を提供します。`1 * 1 + 2 * 3 = 7`一方、単純な線形タイリング カウントでは回転の等価性が考慮されません。 

もう 1 つのエッジ ケースは、すべての列が垂直になっているブレスレットです。 のために`m = 1`、入力は次のとおりです。```
1 114514
```唯一可能なブレスレットには垂直ブロックが 1 つあるため、出力は次のようになります。```
1
```円対称を慎重に扱わずに長さで割る方法は、回転が 1 つしかないため、ここで失敗する可能性があります。 

2 番目のエッジ ケースは、完全に周期的なブレスレットです。 例えば：```
2 1919810
```長さ 2 の場合、3 つの異なる回転クラスがあります。 彼らの加重貢献度は、`1 + 2 * 3 = 7`。 直線的な配置のみをカウントする方法では、同じブレスレットの 2 つの可能なカットを別々にカウントします。 

# アプローチ

 直接的なアプローチは、すべての長さのすべてのタイリングを列挙することから始まります。 タイリングは、どの隣接する列のペアが水平ブロックでカバーされるかを選択することとして表すことができます。 これは、長さのサイクルに基づいてマッチングを選択することと同じです。`n`。 このような一致の数はフィボナッチに似ていますが、すべての配置の生成は指数関数的です。 長さが約 40 の場合、これはすでに非現実的であり、実際の限界は次のとおりです。`10^9`, したがって、強引な方向性は考えられません。 

最初の有益な観察は、円柱タイリング問題が単純な構造をしているということです。 回転を無視すると、長さのサイクルのタイリングの数`n`はそのサイクルの一致の数です。$$L_n = F_{n-1}+F_{n+1}$$どこ`F`はフィボナッチ数列です。 

回転を削除するには、Burnside の補題を使用します。 すべてのブレスレットの代表を選択しようとするのではなく、考えられる各回転の下で変化しないタイリングの数を数え、これらの数を平均します。 

によるローテーション`k`位置はブレスレットの位置を次のように分割します。`gcd(n,k)`サイクル。 この回転によって固定されたタイリングは、まさに毎回繰り返されるタイリングです。`gcd(n,k)`ポジション。 したがって、固定タイリングの数は次のようになります。`L_gcd(n,k)`。 回転を gcd でグループ化すると、次のようになります。$$n \cdot b_n=\sum_{d|n}\varphi(n/d)L_d$$どこ`φ`はオイラーのトーティエント関数です。 

すべてのこの値の合計が必要です`n`まで`m`:$$\sum_{n=1}^{m}\sum_{d|n}\varphi(n/d)L_d$$合計の順序を変更すると、次のようになります。$$\sum_{d=1}^{m}L_d\sum_{k=1}^{\lfloor m/d\rfloor}\varphi(k)$$残りの課題は、これを効率的に計算することです。 商`floor(m/d)`変更のみ`O(sqrt(m))`回なので、範囲を処理できます`d`一緒に。 次のプレフィックスの合計も必要です`L_d`、フィボナッチには閉じた合計の公式があるため、これは簡単です。 もう 1 つの必要な関数は、メモ化された床除算再帰で計算されるオイラーの合計関数の接頭辞の合計です。

 ## アルゴリズムのチュートリアル

 1. オイラーの合計関数の接頭辞の合計を計算します。`Phi(x) = φ(1)+...+φ(x)`メモ化を使用します。 再帰は恒等式から生じます。$$\frac{x(x+1)}2=\sum_{i=1}^{x}\Phi(\lfloor x/i\rfloor)$$下限値は範囲にグループ化されているため、再帰は別個の商のみを対象とします。 

1. 無制限の円柱タイリングの数に対する接頭辞関数を計算します。$$\sum_{i=1}^{n}L_i=F_{n+1}+F_{n+3}-3$$高速 2 倍化では、近い値であってもフィボナッチ数を対数時間で計算します。`10^9`。 

1. 範囲を反復処理します。`m / d`同じ値を持ちます。 範囲の場合`[l,r]`、 毎`d`もっている：$$\lfloor m/d\rfloor=q$$したがって、貢献度は次のようになります。$$(P_L(r)-P_L(l-1)) \cdot \Phi(q)$$1. すべての範囲寄与モジュロを加算します。`p`そして結果を印刷します。 

なぜ効果があるのか:

 Burnside の補題は、すべての回転にわたる固定タイリングの数を平均すると、回転クラスの数が正確に得られることを保証します。 gcd グループ化は同じサイクル構造を持つすべての回転を考慮し、除数変換はすべての長さの合計をフロア分割の合計に変換します。 接頭辞の公式はこれらの正確な恒等性を加速するだけなので、近似は導入されません。 

# Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(1 << 25)

m, mod = map(int, input().split())

phi_cache = {}
fib_cache = {}
pl_cache = {}

def fib(n):
    if n in fib_cache:
        return fib_cache[n]
    if n == 0:
        return (0, 1)
    a, b = fib(n >> 1)
    c = (a * ((2 * b - a) % mod)) % mod
    d = (a * a + b * b) % mod
    if n & 1:
        res = (d, (c + d) % mod)
    else:
        res = (c, d)
    fib_cache[n] = res
    return res

def sum_l(n):
    if n <= 0:
        return 0
    if n in pl_cache:
        return pl_cache[n]
    ans = (fib(n + 1)[0] + fib(n + 3)[0] - 3) % mod
    pl_cache[n] = ans
    return ans

def phi_sum(n):
    if n == 0:
        return 0
    if n in phi_cache:
        return phi_cache[n]
    ans = (n % mod) * ((n + 1) % mod) % mod
    ans = ans * pow(2, -1, mod) % mod if mod != 1 else 0
    l = 2
    while l <= n:
        q = n // l
        r = n // q
        ans -= (r - l + 1) % mod * phi_sum(q)
        ans %= mod
        l = r + 1
    phi_cache[n] = ans
    return ans

ans = 0
l = 1
while l <= m:
    q = m // l
    r = m // q
    cur = (sum_l(r) - sum_l(l - 1)) % mod
    ans = (ans + cur * phi_sum(q)) % mod
    l = r + 1

print(ans % mod)
```フィボナッチヘルパーはペアを返します`(F_n, F_{n+1})`。 高速倍加により、最大の反復を回避できます。`m`、これは必要な理由です。`m`10億になる可能性があります。`sum_l`無制限のシリンダー タイリング カウントのプレフィックスを格納します。 この式ではフィボナッチ指数を直接使用するため、動的プログラミング配列やそれに比例するメモリはありません。`m`。`phi_sum`最も微妙な部分です。 ループは、次のすべての等しい値をグループ化します。`n // i`一緒に。 各再帰引数は個別の下限商であるため、再帰の深さは浅くなります。 2 の逆剰余は等差級数の式にのみ使用されます。 以来`p`が素数であることは保証されず、逆数は次の場合にのみ存在します。`p`奇数です。 偶数の場合`p`の場合、除算は係数を適用する前に行う必要があります。 

最後のループでは、同じフロアのグループ化トリックが使用されます。 値`q = m // d`区間全体で一定です`[l, r]`を使用すると、これらすべての項を 1 つの乗算に組み合わせることができます。
