 ## 解決策
 ## 問題の理解

 この問題は、双方向のパイプで接続された村々を含む水道ネットワークをモデル化します。 各村は毎日一定量の水を消費しますが、いくつかの村には無制限の水源があります。 パラメータを使用してパイプに水を送ります`c`二次保守コストがある: 移動`f`トントンの費用がかかります`f² * c`。 課題は、1 日の総コストを最小限に抑えながらすべての村に十分な水を供給できるように、各パイプを通過する水の量を決定することです。 公式声明では、同じグラフモデルが次のように与えられています。`n`村、`m`パイプ、および`k`ソースの場所。 

頂点とエッジの点では制約は小さく、村の数は最大 50、パイプの数は 200 です。 これは、考えられる実数値の流れの量が無限であるため、水の動きを繰り返しシミュレートしたり、考えられる流れを列挙したりするアプローチを除外します。 グラフ サイズが小さいことは、線形代数に基づく多項式時間アルゴリズムが適切であることを示唆しています。 サイズが最大 50 の行列を使用するソリューションは、十分に高速です。 

直接実装が失敗するケースがいくつかあります。 需要がプラスの村が、施設を含まない接続コンポーネント内にある場合、答えは不可能です。 

例えば：```
2 1 1
0 5
1
1 2 3
```正しい出力は次のとおりです。```
-1
```村 2 には水が必要ですが、その構成要素には水源がありません。 最短パス ベースのアプローチでも、ソースの欠落条件を無視する場合にのみ、村 1 から村 2 へのルートが見つかる可能性があります。 

もう 1 つの微妙なケースは、コストがゼロのパイプです。```
2 1 1
5 7
1
1 2 0
```正しい出力は次のとおりです。```
0
```パイプはいくらでも水を無料で送ることができます。 そのコストを通常の正の抵抗値として扱うと、間違った正の答えが生成されます。 

最後のエッジケースは、すべての村にすでに施設がある場合です。```
3 2 3
4 5 6
1 2 3
1 2 10
2 3 20
```正しい出力は次のとおりです。```
0
```各村は独自の無制限の供給を使用できるため、有料のパイプは必要ありません。 

## アプローチ

 最も直接的な考え方は、これをフローの問題として見ることです。 水源から村に水を送り、コストが改善しなくなるまでルートの調整を繰り返すことも考えられます。 流量値は整数ではなく実数であるため、これは現実的ではありません。 たとえ離散化したとしても、割り当て可能な数は爆発的に増加します。 最適化空間は連続的です。 

重要な観察は、コスト関数が二次関数であるということです。 無向エッジの二次コストは、電気ネットワークとまったく同じ数学的構造です。 パイプは抵抗器のように動作します。その端点間の電位差が既知であれば、そのパイプを通る可能な限り安価な流れが決定されます。 すべてのエッジフローを検索する代わりに、村の可能性を検索できます。 

このプロパティを使用する前に、ゼロコスト パイプには特別な処理が必要です。 それらは抵抗のないワイヤーのように動作するため、それらを介して接続されているすべての村は同じ電位を持ちます。 素の集合結合構造を使用してこれらの村を結合します。 この圧縮の後、残りのすべてのパイプには正のコストがかかります。 

施設を含むすべての圧縮コンポーネントについて、その可能性をゼロに固定します。 残りのコンポーネントは、これらのソースコンポーネントから水を受け取る必要があります。 最適なポテンシャルはラプラシアン線形システムを満たします。 ポテンシャルがわかれば、すべてのパイプの流れがわかり、二次コストの合計を直接計算できます。 

すべてのパイプ フローを最適化しようとするため、強引なアイデアは失敗します。 電気的解釈により、連続最適化問題全体が、最大 50 個の変数を含む 1 つの線形システムを解くことに帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | パイプ数の指数関数 | O(m) | 遅すぎる |
 | ガウス消去法による電気の流れ | O(n3 + m) | O(n²) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. DSU を使用して、ゼロコストのパイプで接続されているすべての村を結合します。 これらの村は答えを増やすことなく無制限に水を交換できるため、1 つのノードとして扱う必要があります。 
2. 少なくとも 1 つの水設備を含むすべての圧縮コンポーネントにマークを付けます。 これらのコンポーネントは無限の水源として機能し、その可能性はゼロに固定されます。 
3. すべての圧縮コンポーネントを機能なしでチェックします。 総需要がプラスの場合、その村のグループを満たす方法はありません。したがって、答えは次のとおりです。`-1`。 需要がゼロのコンポーネントは無視できます。 
4. 正の需要があるすべての非ソースコンポーネントのラプラシアン行列を構築します。 コストがかかるパイプの場合`c`コンポーネント間`a`そして`b`、コンダクタンスを追加します`1/c`。 対角のエントリにはコンポーネントから出る合計コンダクタンスが格納され、非対角のエントリには 2 つのコンポーネント間の負のコンダクタンスが格納されます。 
5. 方程式の右側を各非ソースコンポーネントの負の需要に設定します。 結果として得られるシステムは、`L * potential = demand_vector`。 
6. 部分ピボットを使用したガウス消去法を使用して線形システムを解きます。 ソース コンポーネントを削除した後のグラフは少なくとも 1 つのソースに接続されているため、マトリックスは固有の解を持ちます。 
7. すべての正のコストのパイプを反復して答えを計算します。 エンドポイントに可能性がある場合`p1`そして`p2`、流れは`(p1 - p2) / c`、コスト寄与分は`(p1 - p2)² / c`。 

なぜ効果があるのか:

 二次ネットワークの最適な流れは常に電気的平衡条件を満たします。 ノードが近隣ノードとは異なる潜在的な関係を持っている場合、フローを少し調整することで、すべての要求を満たしたまま、総二乗コストを削減できる可能性があります。 ラプラシアン方程式は、まさにこの平衡を説明します。 それらを解くと、唯一可能な最小エネルギー状態が得られ、結果として得られる流れを評価することで、最小の総コストが得られます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())
    w = list(map(int, input().split()))
    sources = list(map(int, input().split()))
    sources = [x - 1 for x in sources]

    pipes = []
    for _ in range(m):
        u, v, c = map(int, input().split())
        pipes.append((u - 1, v - 1, c))

    parent = list(range(n))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(a, b):
        a = find(a)
        b = find(b)
        if a != b:
            parent[b] = a

    for u, v, c in pipes:
        if c == 0:
            union(u, v)

    comp = {}
    idx = 0
    for i in range(n):
        r = find(i)
        if r not in comp:
            comp[r] = idx
            idx += 1

    cnt = idx
    demand = [0] * cnt
    has_source = [False] * cnt

    for i in range(n):
        c = comp[find(i)]
        demand[c] += w[i]

    for s in sources:
        has_source[comp[find(s)]] = True

    for i in range(cnt):
        if not has_source[i] and demand[i] > 0:
            print(-1)
            return

    edges = []
    for u, v, c in pipes:
        if c > 0:
            a = comp[find(u)]
            b = comp[find(v)]
            if a != b:
                edges.append((a, b, c))

    nodes = [i for i in range(cnt) if not has_source[i] and demand[i] > 0]
    pos = {x: i for i, x in enumerate(nodes)}
    size = len(nodes)

    if size == 0:
        print("0")
        return

    mat = [[0.0] * (size + 1) for _ in range(size)]

    for a, b, c in edges:
        g = 1.0 / c
        if a in pos:
            x = pos[a]
            mat[x][x] += g
        if b in pos:
            y = pos[b]
            mat[y][y] += g
        if a in pos and b in pos:
            x = pos[a]
            y = pos[b]
            mat[x][y] -= g
            mat[y][x] -= g

    for x in nodes:
        mat[pos[x]][size] = -float(demand[x])

    for col in range(size):
        pivot = max(range(col, size), key=lambda r: abs(mat[r][col]))
        if abs(mat[pivot][col]) < 1e-12:
            print(-1)
            return
        mat[col], mat[pivot] = mat[pivot], mat[col]

        div = mat[col][col]
        for j in range(col, size + 1):
            mat[col][j] /= div

        for r in range(size):
            if r != col:
                factor = mat[r][col]
                if abs(factor) > 1e-15:
                    for j in range(col, size + 1):
                        mat[r][j] -= factor * mat[col][j]

    potential = [0.0] * cnt
    for x in nodes:
        potential[x] = mat[pos[x]][size]

    ans = 0.0
    for a, b, c in edges:
        diff = potential[a] - potential[b]
        ans += diff * diff / c

    print("{:.12f}".format(ans))

if __name__ == "__main__":
    solve()
```DSU 部分は、計算が開始される前に、すべてのゼロコスト パイプを処理します。 これにより、ゼロ除算が回避され、水の自由な動きが正確にモデル化されます。 

行列の構築はグラフのラプラシアン定義に従います。 対角線はコンポーネントから出るすべてのコンダクタンスを収集し、非対角線の値は 2 つの未知の電位間の接続を表します。 ソースコンポーネントは、その電位がゼロであることがすでにわかっているため、省略されています。 

行列には浮動小数点値が含まれるため、ガウス消去法では部分ピボットが使用されます。 最大のピボットでのスワップは数値の不安定性を軽減し、必要な精度を得るために必要です。 

最後のループでは、個々の水の移動は再構築されません。 電位差には最適な流れに関するすべての情報がすでに含まれているため、電気式が直接適用されます。
