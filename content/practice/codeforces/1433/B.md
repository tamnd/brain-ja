 ## 解決策
 ## 問題の理解

 バイナリ配列として表される本棚が与えられます。 の値`1`本がその位置に存在することを意味しますが、`0`ポジションが空であることを意味します。 

移動すると、連続した本のブロック全体を取り出し、そのブロックを左または右に 1 つずつ移動して、隣接する空きスペースに移動することができます。 目標は、すべての本が連続する 1 つのセグメントを占め、その間に空の位置がないようにすることです。 

重要な観察は、書籍が既存の左端と右端の間の領域の外に移動する必要がないということです。 ギャップが問題となるのはブックを区切る場合のみであるため、その範囲外の空の位置は問題になりません。 

制約は非常に小さいです。 テスト ケースは最大 200 個あり、各本棚の長さは最大 50 個です。$O(n^2)$解決策は簡単に十分に高速になります。 これは、課題はパフォーマンスではなく、根底にある簡素化を認識することであることを意味します。 

いくつかの特殊なケースは誤解されやすいものです。 

考慮する：```
1 0 0 0 1
```答えは`3`、 ない`1`。 2 冊の本の間には 3 つの空きポジションがあり、それぞれの空きポジションは最終的にそれらの間から消える必要があります。 

考慮する：```
1 1 0 0 1
```答えは`2`。 

よくある間違いは、個々のゼロではなく、ゼロのグループを数えることです。 ここにはギャップが 1 つありますが、空いているポジションが 2 つ含まれているため、2 つの移動が必要です。 

考慮する：```
0 0 1 1 1 0 0
```答えは`0`。 

両側にゼロがありますが、本の間にゼロはありません。 すべてのゼロをカウントする不注意な実装では、誤った値が返されてしまいます。`4`。 

考慮する：```
1
```答えは`0`。 

1 つの本はすでに連続したセグメントです。 

## アプローチ

 この問題を考える強引な方法は、動きをシミュレートすることです。 すべての本が連続するまで、繰り返しセグメントを選択してシフトすることができます。 多くの異なる移動シーケンスが可能であるため、完全な検索では本棚の多くの状態を調査する必要があります。 

それでも$n \le 50$、そのような状態空間アプローチは不要です。 可能な本棚構成の数は急激に増加しており、魅力的なソリューションではありません。 

画期的な進歩は、その動きが実際に何を達成するかを観察することから生まれます。 

2 冊の本の間にゼロがあると仮定します。```
1 0 1
```このギャップを取り除くには、本のグループの 1 つがその空の位置を横切って移動する必要があります。 どちらの側が動いても、そのゼロには正確に 1 つの動きが必要です。 

ここで次のことを考えてみましょう。```
1 0 0 1
```本の間に 2 つの空の位置があります。 1 回の移動で、これらのポジションの最大 1 つを内部から排除できます。 最終的には両方のゼロが消える必要があるため、答えは次のようになります。`2`。 

このパターンは一般化されます。 重要な位置は、左端の本と右端の本の間の位置だけです。 その間隔内のすべてのゼロは、避けられない 1 つの作業単位を表しており、そのようなすべてのゼロは 1 回の移動で削除できます。 

その結果、最小移動数は単に最初の移動の間のゼロの数になります。`1`そして最後`1`。

 ## アルゴリズムのチュートリアル

 1. 最初の本の位置を見つけます。これは、最初に出現することを意味します。`1`。 
2. 最後の本の位置を見つけます。これは、最後の本の位置を意味します。`1`。 
3. これら 2 つのインデックス間のすべての位置を調べます。 
4. が含まれる位置の数を数えます。`0`。 
5. そのカウントを出力します。 

ステップ 4 が機能する理由は、すべての内部ゼロが本を区切るギャップを表すためです。 このような各ギャップ位置は、最終的には本を移動して埋める必要があり、1 回の移動で内部ゼロを 1 つだけ削除できます。 

### なぜ効果があるのか

 最初の本をその位置に置きます`L`そして最後の本が所定の位置にあること`R`。 

間隔外の本`[L, R]`定義上は存在しません。 すべての本を連続させるには、内側のすべての位置を`[L, R]`現在含まれているもの`0`最終的には本が含まれる必要があります。 

移動するたびに、隣接するブロックが 1 位置ずつ移動し、内部の空の位置の数を減らすことができます。`[L, R]`せいぜい1つまで。 したがって、少なくとも内部ゼロと同じ数の手が必要です。 

逆に、内部ゼロごとに、隣接するブロックをそれに向かって移動し、1 回の移動で埋めることができます。 このプロセスを繰り返すと、正確に同じ回数の移動を使用してすべての内部ゼロが削除されます。 

下限と上限が同一であるため、最小手数は最初のブックと最後のブックの間のゼロの数に等しくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        left = a.index(1)
        right = n - 1 - a[::-1].index(1)

        ans = 0
        for i in range(left, right + 1):
            if a[i] == 0:
                ans += 1

        print(ans)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず左端と右端の本を見つけます。 これらの位置は、重要な間隔だけを定義します。 

次に、ループはその間隔内のゼロをカウントします。 範囲外のゼロはブックを区切らないため無視されます。 

微妙な点の 1 つは、最後の発生を計算することです。`1`。 Python には組み込みの逆インデックス操作が提供されていないため、コードは配列を反転して最初の配列を見つけます。`1`そこには。 その位置を元のインデックスに変換すると、右端の本の位置がわかります。 

もう 1 つの詳細は、スキャンに両方のエンドポイントが含まれていることです。 これらのエンドポイントには書籍が含まれることが保証されているため、それらを含めてもカウントには影響せず、1 つずつ異なるミスを回避できます。
