 ## 解決策
 ## 問題の理解

 いくつかの独立したシナリオが与えられています。 それぞれのシナリオには、$n$各地区は整数ラベルで識別されるギャングに属しています。 私たちの仕事は、正確に次のセットを構築することです。$n-1$これにより、すべての地区が単一の接続されたコンポーネントとして接続されるようになり、これらの道路を介して他の地区からどの地区にも到達できるようになります。 

この制限は構造的なもので、同じギャングに属している 2 つの地区を直接接続することは許可されていません。 最終的なグラフのすべてのエッジは、異なるラベルを持つ 2 つの頂点を結合する必要があります。 すべての頂点にまたがり、この制約を尊重する限り、任意のツリー構造を自由に選択できます。 そのようなツリーが存在しない場合は、不可能であることを報告する必要があります。 

制約$\sum n \le 5000$これは、すべてのテスト ケースにわたって、テスト ケースごとにほぼ線形またはほぼ線形のソリューションを提供できることを意味します。 テスト ケースごとの最悪の場合の 2 次のものはまだ合格しますが、3 次のものや高価な再計算を繰り返すものは、多くのテストで繰り返されると安全でなくなります。 これにより、私たちは検索や後戻りではなく、構築ベースのソリューションを推進することになります。 

すべての地区が同じギャングに属している場合、重要なエッジケースが発生します。 この状況では、考えられるすべてのペアが制約に違反するため、最初のエッジさえ追加できません。 

もう 1 つの微妙なケースは、ギャングがちょうど 2 つあるのに、1 つのギャングにノードが 1 つしかない場合です。 たとえば、単一カラー クラスター内でノードを貪欲に接続しようとすると、そのシングルトンが分離される可能性があり、慎重な相互接続戦略のみが接続を維持します。 

## アプローチ

 ブルート フォース アプローチでは、接続性と色の制約を確認しながら、考えられるすべてのツリーをチェックするか、徐々にエッジを構築することによって、有効なスパニング ツリーを構築しようとします。 概念的には、ルールを尊重するすべてのエッジで DFS または BFS を試行し、すべてのノードに到達できるかどうかを確認できますが、これでは正確に出力する必要があるという要件が無視されます。$n-1$ツリーを形成するエッジ。 候補ツリーの列挙は指数関数的です$n$、ラベル付きの木の数は$n^{n-2}$、色の制約でフィルタリングすることすら不可能です。 

重要な構造的洞察は、ツリーを検索する必要がないということです。 構築する必要があるのは 1 つだけです。 唯一の障害は、エッジが常に異なるギャングを接続する必要があることです。 選択したルートとは異なるグループのノードが少なくとも 1 つ存在する場合、そのルートはハブとして機能できます。他のすべてのノードは、そのルートまたは慎重に選択された代表ノードに接続でき、制約に違反することなく接続を確保できます。 

これが失敗するのは、すべてのノードが同じギャングに属している場合のみです。その場合、有効なエッジがまったく存在しないためです。 

これは、単純な建設的な戦略を示唆しています。できれば多数派から、または単純にインデックス 1 から 1 つのノードを参照として選択し、その後、異なるグループのすべてのノードをそれに接続します。 ただし、これだけでは同じギャング構造のノード間の接続が保証されないため、アイデアを改良します。1 つのギャングからピボット ノードを選択し、すべての接続がこのピボットまたは異なるギャングのノードから行われるようにして、スターまたはスターに近い構造を効果的に構築します。 

次に、色がピボットと一致するすべてのノードについて、ピボットに直接接続することを避け、代わりに別の色のノードを介して接続するようにします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース (ツリー検索) | 指数 | O(n) | 遅すぎる |
 | 建設的なピボット戦略 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 固定された代表構造を使用して有効なスパニング ツリーを構築します。 

1. 参照として任意のノード (通常はノード 1) を選択し、そのギャング ラベルを記録します。$c$。 
2. すべてのノードを 2 つのグループ (ラベル付きグループ) に分割します。$c$、およびラベルが等しくないもの$c$。 少なくとも参照ノードが関与する場合、すべての有効なエッジがこの境​​界を越える必要があるため、この分割は非常に重要です。 
3. 異なるラベルを持つノードがない場合$c$、すぐに NO を出力します。 これは、すべてのエッジが制約に違反する場合に対応します。 
4. 1 つのノードを選択します$j$そのラベルは$c$。 このノードはユニバーサル コネクタとして機能します。 
5. ノード 1 をノードに接続します$j$。 これにより、2 つのグループ間に少なくとも 1 つの有効なブリッジが保証されます。 
6. 残りのノードごとに$i > 1$、ラベルが異なる場合はノード 1 に接続します。$c$。 それ以外の場合は、ノードに接続します$j$。 

アタッチメント ルールを分割する理由は、ノード 1 がその色のノードに安全に接続できないためですが、ノード$j$は、そのカラー グループの代替アンカーとして機能します。 

### なぜ効果があるのか

 この構造では、一緒に接続されている 2 つのアンカーを除き、すべてのノードが 1 つのエッジによって接続されていることを保証し、次のようなツリーを形成します。$n-1$エッジ。 すべてのノードがノード 1 またはノードに直接接続されているため、接続が確立されます。$j$、これら 2 つのアンカーが接続されています。 構築によって異なる色のノードのみを接続するため、すべてのエッジが有効になります。 2 つのアンカーを除くすべてのノードがちょうど 1 つの親を持ち、2 つのアンカーが唯一のクロスリンクを形成するため、この構造は非周期的です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        root_color = a[0]
        other = -1

        for i in range(n):
            if a[i] != root_color:
                other = i
                break

        if other == -1:
            print("NO")
            continue

        print("YES")

        # connect root (0) with first different color node
        print(1, other + 1)

        # attach remaining nodes
        for i in range(1, n):
            if i == other:
                continue
            if a[i] == root_color:
                print(other + 1, i + 1)
            else:
                print(1, i + 1)

if __name__ == "__main__":
    solve()
```コードは、2 番目のギャングが存在するかどうかを識別することから始まります。 変数`other`最初のインデックスを最初のノードとは異なるラベルで保存します。 それが残っている場合`-1`、すべてのノードが同じギャングを共有しており、解決策は存在しません。 

次に、エッジ構築によりノード 1 がプライマリ ハブとして固定されます。 最初のクロスギャング ノードがセカンダリ ハブになります。 すべてのノードは、ノード 1 のグループと一致するかどうかに応じて、ノード 1 またはこのセカンダリ ハブのいずれかに接続します。 これにより、すべてのノードが最大 2 つの中心頂点を介して接続されるようにしながら、同じギャング エッジの作成が回避されます。 

微妙なディテールが省略されています`other`ノードはすでに最初の接続エッジに参加しているため、ループ中にノードを削除します。 このスキップがないと、重複した構造または自己参照構造が作成されてしまいます。 

## 実用的な例

 ### 例 1

 入力:```
n = 5
a = [1, 2, 2, 1, 3]
```カラー 1 のルートとしてノード 1 を選択します。最初の異なるノードはインデックス 2 (カラー 2) です。 

| ステップ | アクション | これまでのエッジ |
 | --- | --- | --- |
 | 1 | 1 と 2 を接続する | (1,2) |
 | 2 | ノード 3 は色 2 を持ち、1 に接続します。 (1,2)、(1,3) |
 | 3 | ノード 4 は色 1 を持ち、2 に接続します。 (1,2)、(1,3)、(2,4) |
 | 4 | ノード 5 は色 3 を持ち、1 に接続します。 (1,2)、(1,3)、(2,4)、(1,5) |

 これにより、すべてのエッジが異なるギャングを接続し、すべてのノードがノード 1 またはノード 2 のいずれかを介して到達できる有効なツリーが形成されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque

    input = sys.stdin.readline
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        root_color = a[0]
        other = -1
        for i in range(n):
            if a[i] != root_color:
                other = i
                break

        if other == -1:
            out.append("NO")
            continue

        edges = []
        edges.append((1, other + 1))

        for i in range(1, n):
            if i == other:
                continue
            if a[i] == root_color:
                edges.append((other + 1, i + 1))
            else:
                edges.append((1, i + 1))

        out.append("YES")
        for u, v in edges:
            out.append(f"{u} {v}")

    return "\n".join(out)

 ## 特殊なケース

 すべての地区が同じギャングに属している場合、スキャンでは有効なセカンダリ ノードが見つからないため、アルゴリズムはすぐに NO を出力します。 のような入力の場合`1 1 1 1`、これは法的エッジがまったく存在しないことを正しく反映しています。 

ギャングが 2 つだけ存在するが、そのうちの 1 つが 1 回しか出現しない場合、セカンダリ ノードがクリティカル ブリッジになります。 例えば、`1 1 1 2`、ノード 2 が、色 1 のすべてのノードにとって唯一の安全なコネクタになります。この構築では、すべての同じ色のノードが反対色のノードを介してルーティングされ、接続されたツリーを生成しながら無効なエッジが作成されないことが保証されます。
