 ## 問題の理解

 平面上の直線の集合が与えられ、それぞれは次の形式の方程式で定義されます。$y = kx + b$。 任意の線のペア間の交点を分析したり、幾何学的な交点を見つけたりすることは求められません。 代わりに、これらの線が垂直軸と交差する場所のみを考慮します。$x = 0$、つまり y 軸です。 

すべてのラインは、Y 軸上の 1 つの点、つまり次の点に寄与します。$x = 0$、これは単純に$b$。 ただし、問題はこれらの値をリストすることだけではありません。 複数のラインが同じ切片を共有する場合があります$b$つまり、y 軸上の同じ点を通過します。 タスクは整数座標を選択することです$y$y 軸上で、最大数の線が点を通過するようにする$(0, y)$。 いくつかの y 値がこの最大頻度に達する場合、そのような最小の y を返さなければなりません。 

したがって、問題全体は、与えられたすべての値の中で最も頻度の高い値を見つけることに帰着します。$b$係数を決定し、最小値を優先するタイブレーカーを使用します。 

入力サイズは次のとおりです$10^5$、これは直ちに除外します$O(n^2)$比較。 この問題を、ハッシュまたはソートを使用して線形または線形に近い時間で解決できる周波数集約問題に帰着させる必要があります。 

多くのラインが同じ切片を共有する場合、素朴だが有益なエッジ ケースが表示されます。 

入力:```
4
2 5
3 5
-1 5
10 5
```すべての線は次の点で Y 軸と交差します。$y = 5$したがって、正解は 5 です。単に評価するのではなく、誤って線間の交差を考慮しようとするアプローチ$x = 0$タスクが複雑になりすぎて、時間の制約下では失敗する可能性が高くなります。 

もう 1 つの微妙なケースには、タイブレークが含まれます。 

入力:```
3
1 1
2 2
3 2
```ここで、y = 2 は 2 回現れ、y = 1 は 1 回現れるため、答えは 2 になります。周波数が等しい場合、たとえば次のようになります。```
3
1 1
2 2
3 1
```1 と 2 は両方とも 2 回出現するため、小さい 1 を出力する必要があります。 

## アプローチ

 強引な解釈は、すべての線のペアを比較し、どの Y 軸点が「最も共有されている」かを何らかの方法で推測することです。 ただし、各線は独立して 1 つの y 軸切片に寄与するため、ペアごとの比較は不要です。 単純なアプローチでは、各行を他の行と比較してカウントを計算しようとする可能性があり、その結果、次のような結果が得られます。$O(n^2)$時間。 と$n = 10^5$、これは次のようになります$10^{10}$実行不可能な操作。 

重要な観察は、すべての行がこの問題に関して 1 つの数値 (y 切片) によって完全に特徴づけられていることです。$b$。 坂道$k$y 軸と交わる場所には決して影響しません。 したがって、問題は、整数の頻度を数え、辞書編集上最小のタイブレークで最も頻度の高い整数を選択することになります。 

これにより、問題が最大で標準的なヒストグラム構築に変換されます。$10^5$整数は、辞書または並べ替えを使用して効率的に処理できます。

 ## アルゴリズムのチュートリアル

 各行を単一の値に削減してから、周波数最大化問題を解決します。 

1. すべての行を読み取り、切片のみを抽出します$b$それぞれの式から。 これは、y 軸の交点を決定する唯一の値です。$x = 0$傾き項を削除します。 
2. の整数値から周波数マップを維持します。$b$何回登場するか。 それぞれの出現は、y 軸上の同じ点を通過する 1 本の線に対応します。 
3. 周波数マップ内のすべてのエントリを反復処理し、最適な候補を追跡します。 最良の候補は、最初に最大頻度によって定義され、同点の場合はより小さい頻度によって定義されます。$b$。 
4. 選択した内容を出力します$b$。 

微妙な部分はタイブレークのルールです。 これは明示的に強制する必要があります。現在の最適値と同じ周波数が確認された場合は常に、新しい値が小さい場合にのみ答えを更新します。 

### なぜ効果があるのか

 各線は Y 軸上の 1 つの点にのみ影響し、2 本の異なる線はその切片以外に影響を与えることはできません。 したがって、特定の y 座標を通過するラインの数をカウントすることは、入力内にその切片が何回出現するかをカウントすることとまったく同じです。 このアルゴリズムはすべての寄与を徹底的にカウントし、決定論的なタイブレークで最大頻度値を選択するため、より良い候補を見逃したり、次善の候補を選択したりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    freq = {}

    for _ in range(n):
        k, b = map(int, input().split())
        freq[b] = freq.get(b, 0) + 1

    best_y = None
    best_cnt = 0

    for y, cnt in freq.items():
        if cnt > best_cnt or (cnt == best_cnt and (best_y is None or y < best_y)):
            best_cnt = cnt
            best_y = y

    print(best_y)

if __name__ == "__main__":
    solve()
```ソリューションはインターセプトを分離します$b$すぐに無視する$k$y 軸との交点には影響を与えないためです。 頻度ディクショナリは、線形時間での発生を集約します。 辞書の最終スキャンにより、一次順序条件と二次順序条件の両方で正しい選択が保証されます。 

初期化には注意が必要です。`best_y`として始まります`None`そのため、最初に見つかった値が常に受け入れられ、比較では同点規則が正しく処理されます。
