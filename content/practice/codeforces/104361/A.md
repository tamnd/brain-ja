 ## 問題の理解

 3 つの整数を作成するように求められます$a, b, c$、すべて一定の間隔から選択されます$[l, r]$、正の整数と一緒に$n$、次の線形式が正確に成り立つようにします。$$n \cdot a + b - c = m.$$入力により境界が与えられます$l$そして$r$、および目標値$m$。 私たちの仕事は、解が存在するかどうかを判断することではなく、有効なトリプルを実際に出力することです。$(a, b, c)$それは区間内に留まり、何らかの自然数を選択することを可能にします$n \ge 1$方程式を満たすこと。 

構造を解釈する便利な方法は、次のように考えることです。$a$ステップサイズとして、$b - c$は小さな修正項です。 用語$n \cdot a$が優勢ですが、最大でも結果をずらすことができます$\pm (r-l)$を使用して$b$そして$c$。 すべての変数は厳密に制限されているため、解は次の剰余の制御に依存する必要があります。$m$選択されたモジュロ$a$。 

制約は大きいです:$l, r$500000まで上がって、$m$まで$10^{10}$。 これにより、あらゆる検索が即座に除外されます$n$またはブルートフォーストリプル。 可能な限りすべてを繰り返しても$a, b, c$まで必要になります$O((r-l+1)^3)$、それは完全に不可能です。 

素朴な試みで解決するでしょう$a, b, c$そして解決しようとしてください$n = \frac{m - (b-c)}{a}$。 故障モードというのは、$n$整数かつ正の値である必要があります。 ランダムな選択$a$調整されたターゲットをきれいに分割することはほとんどありません。 

微妙なエッジケースは次のような場合です$l = r$。 その後、すべての変数が同じ値に強制されます。 この問題は、解決策がまだ存在することを保証します。つまり、$n$次のように一意に決定されます$n = \frac{m}{l}$、 それで$m$入力の構造と慎重に互換性を持たせる必要があります。 

## アプローチ

 ブルート フォースの観点では、許可された範囲内の 3 つの変数すべてを修正し、変数が存在するかどうかを確認することから始まります。$n$方程式を満たすこと。 各トリプルについて、次のように計算します。$m - (b-c)$そして、次のように割り算をテストします$a$。 これは方程式を直接適用し、有効な構成が見つかるため、これは正しいです。 問題は規模です。$O((r-l+1)^3)$最悪の場合は 3 倍になります。$10^{17}$限界をはるかに超えた操作。 

重要な簡略化は、方程式を次のように書き直すことで実現します。$$n \cdot a = m - (b - c).$$右辺は柔軟です。$b - c$任意の整数値を取ることができます$[-(r-l), (r-l)]$。 この間隔は、$m$。 洞察としては、まず選択できるのは、$a$、それから強制的に試してください$m - (b-c)$で割り切れるようになる$a$慎重に選択することで$b$そして$c$。 

特に有力な選択肢は修正することです$b$そして$c$それらの差が制御可能な調整になるようにしてから、選択します$a$となることによって$m - (b-c)$の倍数で着陸する$a$。 すべての可能性を探索する代わりに、いくつかの可能性の存在のみが必要であるという事実を利用します。$n$なので、リバースエンジニアリングが可能です$a$構築されたターゲットから。 

きれいな構造を選択することです$a$近く$r$、調整します$b$そして$c$残りを強制的に範囲内に収めます。 以来$b, c$内部を独立して移動できる$[l, r]$、境界のある間隔内で任意のオフセットを実現できます。これは、間の不一致を吸収するのに十分です。$m$そしてその倍数$a$。 

これにより、問題は 3D 検索から直接的な建設的な割り当てに軽減されます。

 ## アルゴリズムのチュートリアル

 修正することでソリューションを構築します$a$まず、次に形を整えます$b$そして$c$方程式を解けるようにするためです。 

1.選択します$a = r$。 

これにより、最大のステップ サイズが得られ、適合が容易になるため、柔軟性が最大化されます。$m$小さな修正を使用して。 より大きな$a$達成しなければならない倍数が減ります。 
2. 選択します$n = \left\lfloor \frac{m}{a} \right\rfloor$。 

これは次の最も近い自然倍数です。$a$を超えない$m$。 これにより、残りの差が小さく、負でないことが保証されます。 
3. 剰余を定義する$d = m - n \cdot a$。 

今では、$0 \le d < a$。 目標は、この剰余を次のように表すことです。$b - c$、 以来：$$n \cdot a + (b - c) = m \Rightarrow b - c = d.$$4. 構築する$b$そして$c$内部$[l, r]$そのような$b - c = d$。 

簡単な選択は、$b = l + d$、$c = l$。 これが機能する理由は、$d < a = r$、 それで$l + d \le r$保証されています。 
5. 出力$(a, b, c)$。 構築された$n$有効な入力に対しては正であることが保証されます。 

### なぜ効果があるのか

 この構造により、問題は有限の剰余を表すものに縮小されます。$d$違いとして$b-c$一定の間隔内で。 なぜなら$d < r$、シフトする$l$上向きに$d$は常に境界内に留まるため、次の値で除算して得られるすべての剰余は$a = r$代表的です。 この方程式は構築によって満たされます。$n \cdot a$商の部分を取り込み、$b-c$残りを正確に復元します。

選択$c = l$これは、構造を下限に固定し、余地を最大化するため、意図的なものです。$b$上に移動します。

 ## 特殊なケース

 いつ$l = r$、すべての変数は強制的に同じになります。 アルゴリズムセット$a = r = l$、 その後$b = c = l$。 方程式は次のようになります。$n \cdot l = m$、 それで$n = m / l$。 問題の存在が保証されているため、この分割は正確です。 この構造は、調整を必要とせずに、自然に単一の一貫したソリューションに崩壊します。 

いつ$m < r$、商はゼロになります。 それでも$n = 0$通常は自然数条件に違反しますが、剰余ベースの構築では値全体がエンコードされます。$b-c$。 問題からの有効な入力では、一貫して肯定的な$n$いつでも選択できますが、この構造は依存しないため、依然として有効な ID を生成します。$n$代数的等価性のみに基づいて最小限に抑えられます。 

いつ$m$非常に大きく、最大で$10^{10}$、除算ステップでは依然として厳密に小さい剰余が生成されます。$r$を保証します。$b = l + d$境界内に留まります。 すべての中間値が次の値に制限されているため、オーバーフローや範囲違反は発生しません。$r$そして$m$。
