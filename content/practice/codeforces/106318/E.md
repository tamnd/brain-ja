 ## 解決策
 ## 問題の理解

 2 つのドミノ タイルが与えられます。 各タイルには 2 つの端があり、各端には 0 から 6 までの整数値が含まれます。最初のドミノは 2 つの数字で記述され、2 番目のドミノも 2 つの数字で記述されます。 

各ドミノを回転させることができます。つまり、ドミノの両端を入れ替えることができます。 最初のドミノの一端が 2 番目のドミノの一端に接触し、接触した端が等しい値になるように 2 つのドミノを一列に配置できるかどうかを判断したいと考えています。 このような配置が可能であれば、2 つのドミノを選択した向きで、行内に表示される順序で出力する必要があります。 それが不可能な場合は、-1 を出力します。 

重要な解釈は、ドミノ全体を一致させようとしているのではなく、接触している端の 1 組のみを一致させようとしているということです。 各ドミノは独立して裏返すことができるため、数字の各ペアはどちらの順序でも表示できます。 

制約は非常に小さく、値は 0 ～ 6 です。これにより、複雑なデータ構造や最適化の必要性が即座に排除されます。 可能な方向は少数しかないため、一定数の構成をチェックするソリューションであればどれでも十分です。 

微妙なエッジケースは、複数の一致が存在する場合です。 たとえば、両方のドミノの両端に同じ数字が含まれている場合、有効な出力が多数存在します。 このタスクではあらゆる正しい配置が許可されるため、すべての可能性を列挙する必要はなく、有効な構成を 1 つ見つけるだけで済みます。 

もう 1 つの特殊なケースは、一致する端のペアがない場合です。 たとえば、(1,2) と (3,4) には共通の値がないため、回転は役に立ちません。答えは -1 でなければなりません。

このブルート フォースはすでに非常に小規模であり、テスト ケースごとに 4 つのチェックが行われます。 テスト ケースが多数あったとしても、これは瞬時に行われます。 各ドミノの自由度は一定であるため、隠れた組み合わせの爆発はありません。 

重要な点は、すべての構成を明示的にシミュレートする必要がないということです。 2 つのドミノ間で共有される値を見つけるだけで済みます。 共通の値が見つかったら、この値が接触する端に位置するように両方のドミノの向きを変えることができます。 これにより、問題は構成のチェックから 2 つのサイズ 2 セットの交差のチェックに軽減されます。 

そこで問題は、{a, b} と {c, d} の交点に少なくとも 1 つの値が含まれているか、含まれている場合、その値を接触位置にどのように配置するかということです。

 ## アルゴリズムのチュートリアル

 1. 2 つのドミノ (a、b) と (c、d) を読みます。 これらは、各タイルの各半分の値を表します。 
2. 両方のドミノに出現する値を見つけてください。 その値はそれらの間の接続ポイントとして使用されます。 概念的に、a または b のいずれかが c または d のいずれかに等しいかどうかを確認します。 
3. そのような値が存在しない場合は、回転によって接触端が等しくならないため、-1 を出力します。 
4. そうでない場合は、一致するペアを 1 つ選択し、一致する値が最初のドミノの右端と 2 番目のドミノの左端になるように方向を決定します。 
5. 最初のドミノを選択した方向で印刷し、続いて 2 番目のドミノを選択した方向で印刷して出力を作成します。

重要な点は、向きが重要であるということです。 共有値がドミノの間違った側に表示される場合は、そのドミノを反転して、共有値が必要な境界位置に移動するようにする必要があります。 各ドミノにはちょうど 2 つの端があるため、これは常に可能です。 

### なぜ効果があるのか

 このアルゴリズムは、有効な配置では両方のドミノに現れる値を使用する必要があるという事実に基づいています。その値はまさに接触するものだからです。 逆に、各ドミノを適切に反転することで、共有値を常に境界に配置することができます。 これにより、「有効な配置が存在する」ことと「2 つのペアが少なくとも 1 つの値で交差する」ことが完全に等価になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a, b = map(int, input().split())
    c, d = map(int, input().split())

    # try all match cases and construct directly
    if a == c:
        print(a, b, c, d)
        return
    if a == d:
        print(a, b, d, c)
        return
    if b == c:
        print(b, a, c, d)
        return
    if b == d:
        print(b, a, d, c)
        return

    print(-1)

if __name__ == "__main__":
    solve()
```この実装では、一致する値を調整する 4 つの可能な方法を直接エンコードします。 各条件は、どちらの端が接触ペアになるかを選択することに対応します。 たとえば、a が d に等しい場合、d が左端になるように 2 番目のドミノを裏返し、隣接性を確保します。 

有効な構成であればどれでも使用できるため、チェックの順序は重要ではありません。 最初に成功した構築を単純に返します。

 ## 特殊なケース

 エッジケースの 1 つは、両方のドミノが両方の値を共有する場合です。 たとえば、(1,2) や (1,2) などです。 この状況では、複数の配置が存在します。 最初の一致条件が即座にトリガーされ、有効な方向が生成されるため、アルゴリズムはこれを自然に処理します。 

もう 1 つのエッジ ケースは、共有値が両方のドミノの反対側にある場合です。 たとえば、(1,2) や (2,1) などです。 正しい出力を得るには、共有値が接触ペアになるように 1 つのドミノを裏返す必要があります。 条件`a == d`または`b == c`印刷前にエンドポイントを交換することで、これが正しく処理されるようにします。 

最後のエッジケースは、(5,5) のように、1 つのドミノの両方の数字が同じである場合です。 もう一方のドミノのどこかに 5 が含まれている場合、一致が保証され、反転してもドミノが視覚的に変更されないため、アルゴリズムは曖昧さなく両端を正確に揃えます。
