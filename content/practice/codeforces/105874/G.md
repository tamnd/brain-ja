 ## 解決策
 ## 問題の理解

 オートマトンは空の画面から始まり、単一の画面を追加できます。`0`またはブロック`k`連続した`1`文字。 任意の回数ボタンを押すと、バイナリ文字列が取得されます。 クエリごとに、指定された間隔内に長さがある異なる文字列がいくつ出現できるかをカウントする必要があります。 

生成された文字列の重要な特性は、すべての最大ブロックが`1`文字は割り切れる長さでなければなりません`k`。 2 番目のボタンを押すと正確に作成されます`k`1 を入力し、連続して押すと単純に長いブロックに結合されるため、1 の連続は長さのみを持つことができます。`k, 2k, 3k, ...`。 この条件を満たす任意の文字列は、ボタンを左から右に押すことで構築できます。 

クエリの最大長と最大数は両方とも次のとおりです。`2 * 10^5`したがって、すべてのクエリのすべての長さをスキャンするアルゴリズムには、約`4 * 10^10`操作は不可能です。 同じ小さなパラメータを持つクエリ間で作業を共有し、異なる観測値を持つ大きなパラメータを処理する必要があります。 

厄介なケースは、1 の数が の値によって制限されるケースです。`k`。 たとえば、次のようなとき`k = 3`、文字列`0110`1 の連続だけが長さを持っているため、これは有効です`2`? ランレングスは次の値で割り切れないため、実際には無効です。`3`。 入力に対する正解```
1
1 4 3
```は`3`、有効な文字列は次のとおりです。`0000`、`0111`、 そして`1110`。 1 の合計数をチェックするだけの不注意な解決策はカウントされてしまいます。`0110`有効として。 

もう一つのエッジケースは、`k = 1`。 この場合、すべてのランレングスは自動的に 1 の倍数になるため、すべての文字列が可能です。 例えば、```
1
1 2 1
```答えがあります`4`、フィボナッチのような値ではありません。 すべてを治療する`k`同じ繰り返しを行うと、ここでは失敗します。 

## アプローチ

 直接的な解決策は、各長さの可能なすべての文字列を生成し、一連のすべての文字列の長さが次の値で割り切れるかどうかを確認します。`k`。 この条件はオートマトンによって生成される文字列を正確に記述しているため、これは正しいです。 ただし、`2^L`一定の長さの文字列`L`, そのため、このアプローチは中程度の長さの場合でも使用できません。 

より良い方向性は動的プログラミングです。 させて`dp[i]`有効な長さの文字列の数になります`i`。 ゼロで終わる有効な文字列は、任意の長さの有効な文字列から取得されます。`i - 1`。 1 で終わる有効な文字列は、少なくとも次のブロック全体で終わる必要があります。`k`もの。 最後のブロックを削除すると、ゼロで終わる有効なプレフィックス、または空のプレフィックスが残ります。 これにより再発が得られます`dp[i] = dp[i - 1] + dp[i - k - 1]`仮想ベース値付き`dp[-1] = 1`。 特別な場合`k = 1`すべてのバイナリ文字列を与えるので、`dp[i] = 2^i`。 

残りの問題は、多くのクエリに答えることです。 小型用`k`、再帰は、プレフィックス テーブル全体を 1 回計算するのに十分な速さです。 大型用`k`、重要な用語の数は少なくなります。 漸化式は組み合わせ式として書き直すことができます。`dp[i] = sum C(i - j*k, j)`どこ`j`長さが 1 のブロックの数です`k`残りの位置はゼロです。 ホッケー スティックの ID を使用すると、一定期間にわたる合計を次のように答えることができます。`O(n/k)`条項。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n sqrt(n) + q sqrt(n)) | O(n平方(n)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最初にすべてのクエリを読み取り、作業を値ごとにグループ化します。`k`。 小さい値`k`大きい間は事前に計算されます`k`直接答えられます。 
2.ハンドル`k = 1`別に。 長さのすべてのバイナリ文字列`x`可能であるため、範囲の答えは次の合計になります。`2^x`。 
3. あらゆる小さなことに対して`k`、計算する`dp`再発から。 次のプレフィックスの合計を保存します`dp`値なので、すべての範囲クエリは減算になります。 
4. 大型の場合`k`、組み合わせ表現を使用します。 文字列が`j`一定の長さのブロック`k`、そのようなすべてのブロックを 1 つのオブジェクトとして扱った後、これらのオブジェクトをゼロの間に配置する方法の数は次のとおりです。`C(length - j*k, j)`。 
5. 可能なすべての値についてこれらの値を合計します。`j`。 以来`k`が大きい場合、可能な 1 のブロックの数はわずかしかありません。 

機能する理由: すべての有効な文字列は、ゼロの位置と 1 のブロックによって一意に記述されます。 動的プログラミング再帰では文字列を最後のブロックごとにカウントし、組み合わせ公式では同じオブジェクトを 1 つのブロックの数でカウントします。 どちらも有効な構造を正確にカウントするため、保存された値はすべてのクエリに正しく答えます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, q = map(int, input().split())
    queries = []
    for _ in range(q):
        l, r, k = map(int, input().split())
        queries.append((l, r, k))

    maxc = n + 5
    fact = [1] * (maxc + 1)
    invfact = [1] * (maxc + 1)
    for i in range(1, maxc + 1):
        fact[i] = fact[i - 1] * i % MOD
    invfact[maxc] = pow(fact[maxc], MOD - 2, MOD)
    for i in range(maxc, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    def comb(a, b):
        if b < 0 or a < b:
            return 0
        return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

    small = 450
    pref = {}

    for k in range(2, small):
        dp = [0] * (n + 1)
        dp[0] = 1
        cur = 1
        for i in range(1, n + 1):
            cur = dp[i - 1]
            if i >= k:
                cur += 1 if i == k else dp[i - k - 1]
            dp[i] = cur % MOD
        ps = [0] * (n + 1)
        for i in range(1, n + 1):
            ps[i] = (ps[i - 1] + dp[i]) % MOD
        pref[k] = ps

    pow2 = [1] * (n + 1)
    for i in range(1, n + 1):
        pow2[i] = pow2[i - 1] * 2 % MOD
    pref1 = [0] * (n + 1)
    for i in range(1, n + 1):
        pref1[i] = (pref1[i - 1] + pow2[i]) % MOD

    ans = []
    for l, r, k in queries:
        if k == 1:
            ans.append(str((pref1[r] - pref1[l - 1]) % MOD))
        elif k < small:
            ans.append(str((pref[k][r] - pref[k][l - 1]) % MOD))
        else:
            res = 0
            j = 0
            while j * k <= r:
                res += comb(r - j * k + 1, j + 1)
                res -= comb(l - j * k, j + 1)
                j += 1
            ans.append(str(res % MOD))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```事前計算セクションでは、次の小さな値に対する答えを構築します。`k`。 繰り返しは特別なケースで詳細に実装されます`k`これは、空のプレフィックスから 1 の最初のブロックを作成することに対応します。 

大きな`k`ループ回数は制限されているため、分岐が何度も繰り返されることはありません。`r / k`。 これらの値が大きいため、これは小さいままです。 結合式では階乗と逆階乗が使用されるため、すべての項は定数時間になります。 

小さい値と大きい値の間の境界は、合計の事前計算作業と大きなクエリ作業が両方とも入力サイズの平方根付近になるように選択されます。

 ## 特殊なケース

 いつ`k = 1`、オートマトンはどちらの文字も自由に追加できます。 このアルゴリズムでは、一般的な再帰の代わりに 2 の累乗を使用するため、入力は```

```としてカウントされます`4`。 

のような値の場合`k = 3`、1 が短く続く文字列は禁止されています。 の上```

```このアルゴリズムは、1 つのブロックが存在しないか、長さが 3 である文字列のみをカウントします。 無効な文字列`0110`1 の完全なブロックを追加することによって形成できないため、繰り返しには決して現れません。
