 ## 解決策
 ## 問題の理解

 このタスクは、特定の構造特性を持つ特定の配列の連続したサブ配列がいくつあるかを数えるというものです。サブ配列内を見て、その最小要素と最大要素を取得すると、大きい要素は小さい要素の正確な倍数でなければなりません。 

各クエリは配列を与えるので、その中で考えられるすべての間隔を考慮する必要があります。 各間隔について、その最小値と最大値を再計算し、それらの間の割り切り条件をチェックします。 出力は、この条件を満たす間隔の合計数です。 

この制約により、すべての間隔を明示的に評価するソリューションから遠ざけられます。 テスト全体で最大 50 万の要素があり、$O(n^2)$サブ配列の列挙は実現不可能です。 平$O(n \log n)$サブアレイごとには不可能です。$O(n^2)$サブアレイ。 

条件の構造により、単純なスライディング ウィンドウ手法も除外されます。 セグメントを拡張すると、最小値と最大値の両方が予期せず変化する可能性があり、割り算の制約は順序だけでなく正確な値に依存します。 

単純な試みでよくある失敗例は、単調性を仮定することです。 たとえば、ウィンドウを拡張して最小値と最大値を動的に追跡しようとすると、割り切れる条件は単調ではありません。 有効なセグメントは拡張後に無効になる可能性がありますが、拡張によって予期せず割り算が修正される場合もあります。 たとえば、次のような配列では、$[2, 6, 3]$、セグメント$[2, 6]$有効です、$[6, 3]$有効ですが、$[2, 6, 3]$両方のサブセグメントが成功しても失敗します。 

もう 1 つの微妙な落とし穴は、状態を局所的なものとして扱うことです。 のようなセグメント$[2, 3, 6]$すべての隣接するペアが何らかの単純な割り算の直感に合格したとしても、失敗します。 制約は、ローカルな遷移ではなく、グローバルな最小値と最大値のみに依存します。 

主な問題点は、すべての有効なセグメントが 2 つの極端な役割によって同時に管理され、両方の役割がグローバル構造に依存していることです。 

## アプローチ

 直接的なブルートフォース手法では、すべてのサブ配列を列挙し、それをスキャンして最小値と最大値を見つけ、最大値が最小値で割り切れるかどうかをチェックします。 これは定義に直接従うため、正しいです。 ただし、各サブアレイのスキャンにはコストがかかります$O(n)$、そして、あります$O(n^2)$サブ配列、全体を生成する$O(n^3)$解決。 最小値と最大値を最適化しても、$O(1)$前処理をしてもまだ残っています$O(n^2)$が遅すぎる$5 \cdot 10^5$。 

重要な点は、条件がセグメント内の 2 つの要素 (最小値になる要素と最大値になる要素) のみに依存するということです。 したがって、すべての有効な部分配列を位置のペアに関連付けることができます。$(i, j)$、 どこ$a[i]$はセグメントの最小値であり、$a[j]$が最大です。 

これにより、問題は「サブ配列の数」から「有効な極値ペアの数とそれらを実現するサブ配列の数」に変わります。 どのインデックスが最小の役割を果たし、どのインデックスが最大の役割を果たすかを決定したら、残りの自由は、これらの極端な制約を維持しながら左右の境界を選択することだけになります。 

To make this usable, we need two structural tools. まず、位置ごとに、部分配列の最小値として機能する最大間隔を計算します。 これは、前後の厳密に小さい要素を使用して取得されます。 次に、厳密に大きい前後の要素を使用して、各位置が最大値として機能する最大間隔を計算します。 

これらの範囲が判明したら、ペア$(i, j)$両方の要素が同じセグメント内で極端に留まるように範囲が重複する場合にのみ寄与します。 オーバーラップ内では、有効なサブ配列の数は、左右の境界の独立した選択の積として表すことができます。 

最後に、値が割り切れる条件を満たすペアのみを考慮します。$\max(a[i], a[j]) \bmod \min(a[i], a[j]) = 0$。 これにより、問題は、任意の間隔ではなく、有効な極値ペアにわたる構造化されたカウントに軽減されます。

 ## アルゴリズムのチュートリアル

 1. すべてのインデックスについて、左右の最も近い小さい要素を計算します。 これは、その要素が最小値として機能する最大間隔を定義します。 境界により、それより小さい値がセグメントに入らないようにするため、要素は全体を通じて最小値のままになります。 
2. すべてのインデックスについて、左右の最も近い大きい要素を計算します。 これは、その要素が最大値として機能する最大間隔を定義し、その領域内で最大値を維持することを保証します。 
3. インデックスごとに$i$、 扱う$a[i]$セグメントの潜在的な最小値として。 すべての有効なセグメント$i$最小値は完全にその最小間隔内になければなりません。 
4. 同じセグメントの場合、最大値は何らかのインデックスから取得する必要があります。$j$その値は次の倍数です$a[i]$。 これにより、候補者が制限されます$j$価値観に$a[j] = k \cdot a[i]$。 
5. それぞれの候補ペアについて$(i, j)$、最大間隔と最小間隔が、両方が極値である共通の部分配列を許可するのに十分に重複しているかどうかを確認します。 この重なりによって、有効な左右の境界の選択肢の数が決まります。 
6. 有効な左境界の選択肢と右境界の選択肢の数を乗算してペアの寄与を取得し、すべての有効なペアにわたって累積します。 

### なぜ効果があるのか

 すべての有効なサブ配列には一意の最小位置と一意の最大位置があります (インデックスは固定されているため、同数はカウントには関係ありません)。 これら 2 つのインデックスが固定されると、すべての有効な部分配列は、その極値の有効範囲内に留まりながら、両方のインデックスを含む境界を選択することに正確に対応します。 単調範囲の構築により、これらの範囲外に、より小さい要素が入る (最小値を超える) か、より大きな要素が入る (最大値を超える) ことが保証されます。 したがって、カウントされるすべての構成は有効なサブ配列に対応し、すべての有効なサブ配列はその極値ペアを通じて正確に 1 回カウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    maxv = max(a)

    # previous and next smaller for min-intervals
    prev_sm = [-1] * n
    next_sm = [n] * n
    stack = []

    for i in range(n):
        while stack and a[stack[-1]] >= a[i]:
            stack.pop()
        prev_sm[i] = stack[-1] if stack else -1
        stack.append(i)

    stack.clear()

    for i in range(n - 1, -1, -1):
        while stack and a[stack[-1]] > a[i]:
            stack.pop()
        next_sm[i] = stack[-1] if stack else n
        stack.append(i)

    # previous and next greater for max-intervals
    prev_gr = [-1] * n
    next_gr = [n] * n
    stack.clear()

    for i in range(n):
        while stack and a[stack[-1]] <= a[i]:
            stack.pop()
        prev_gr[i] = stack[-1] if stack else -1
        stack.append(i)

    stack.clear()

    for i in range(n - 1, -1, -1):
        while stack and a[stack[-1]] < a[i]:
            stack.pop()
        next_gr[i] = stack[-1] if stack else n
        stack.append(i)

    pos = {}
    for i, v in enumerate(a):
        pos.setdefault(v, []).append(i)

    ans = 0

    for i in range(n):
        m = a[i]
        Lm, Rm = prev_sm[i], next_sm[i]

        # try all multiples of m that exist
        k = m
        while k <= maxv:
            if k in pos:
                for j in pos[k]:
                    if j == i:
                        # same element acts as both min and max
                        L = max(Lm, prev_gr[i])
                        R = min(Rm, next_gr[i])
                        if L < i and i < R:
                            left = i - L
                            right = R - i
                            ans += left * right
                        continue

                    if j < Lm + 1 or j > Rm - 1:
                        continue

                    Lj, Rj = prev_gr[j], next_gr[j]

                    L = max(Lm, Lj)
                    R = min(Rm, Rj)

                    if L < min(i, j) and max(i, j) < R:
                        left = min(i, j) - L
                        right = R - max(i, j)
                        ans += left * right

            k += m

    print(ans)

t = int(input())
for _ in range(t):
    solve()
```この解決策は、単調スタックを構築して、各要素がどこで最小値または最大値として安全に機能できるかを決定することから始まります。 これらの間隔は、サブ配列に対するグローバルな推論を各インデックスの周囲のローカルな制約に置き換えるために不可欠です。 

ディクショナリはインデックスを値ごとにグループ化するため、有効な倍数を効率的に反復できます。 固定最小値の場合$m$、倍数のみ$k \cdot m$は潜在的な最大値として機能する可能性があるため、無関係な値を完全にスキャンすることは避けます。 

インデックスの有効なペアごとに、有効な最小範囲と最大範囲の間の重複を計算します。 サブアレイの数は、オーバーラップ内の左右の境界を独立して選択することによって決定されます。 

## 実用的な例

 ### 例: 小さな配列

 配列を考慮してください$[2, 4, 7, 14]$。 

最小範囲と最大範囲を計算し、有効なペアを列挙します。 

| 私 | 値 | 可能な最大値 j | 有効な貢献 |
 | --- | --- | --- | --- |
 | 1 | 2 | 4、14 | 有効なオーバーラップを中心とした部分配列 |
 | 2 | 4 | 重要なものはありません | 限られた重複 |
 | 3 | 7 | 14 | 有効なペア |
 | 4 | 14 | 自分 | 単一元素の貢献 |

 合計は、サンプルと一致する 7 つの有効なサブ配列に累積されます。 

このトレースは、両方の要素が共有区間で同時に極値として機能する場合にのみ寄与がどのように発生するかを示しています。 

### 例: 繰り返し構造

 配列$[16, 5, 18, 7, 7, 12, 14]$反復値と非反復値が含まれます。 このアルゴリズムは各値クラスを分離し、そのクラス構造内の倍数のみを考慮します。 これにより、不必要なペアリングが防止され、構造的に有効な極値ペアのみが寄与することが保証されます。

 ## 特殊なケース

 重要なエッジケースは、同じ要素が最小値と最大値の両方として機能する場合です。 のような配列では$[5, 5, 5]$、最小値が最大値に等しく、割り算が自明に成り立つため、すべての部分配列が有効です。 アルゴリズムは、最小範囲と最大範囲の両方の交差によってこれを処理し、すべてのサブ配列が有効な間隔ごとに 1 回カウントされるようにします。 

複合値と素数が混在するなど、値がまばらな場合には、別のエッジ ケースが発生します。 次のような配列で$[2, 3, 5, 10]$、特定の倍数のみが有効なペアを形成し、ほとんどの候補ペアはスキップする必要があります。 複数ベースの反復により、隣接関係やローカル構造を誤って想定しないことが保証されます。 

最後の微妙なケースは、インデックスの順序付けにおいて最大候補と最小候補が重なり合う場合です。 最小値と最大値のペア構造では左右の境界の計算が対称であるため、間隔交差ロジックにより、最小インデックスが最大インデックスの前に現れるか後に現れるかに関係なく、正確なカウントが保証されます。
