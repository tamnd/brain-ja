 ## 解決策
 ## 問題の理解

 さまざまな位置の値を表す整数の配列が与えられます。 Chaneka は 1 つ以上のインデックスを選択して黒色に着色できます。 その後、黒のインデックスの倍数の位置にあるすべての要素が緑に変わります。 特定の選択のスコアは、すべての黒と緑の要素の最大値です。 黒のインデックスの空でないすべての選択にわたってこれらのスコアの合計を計算するように求められます。 

配列は非常に大きくなる可能性があり、最大で$10^5$要素、および各要素の値は最大で$10^5$。 がある$2^n - 1$中級者でも天文学的に大きくなる黒インデックスの選び方$n$。 これにより、すべてのサブセットを反復するブルートフォース シミュレーションが即座に排除されます。 どのようなソリューションでも、サブセットを明示的に列挙することは避け、代わりにインデックス倍数の組み合わせまたは数論的特性を活用する必要があります。 

明らかではないエッジ ケースには、複数の要素が同じ最大値を持つ配列が含まれます。 たとえば、`[5, 1, 5]`、インデックス 1 を選択すると、すべての要素が緑色になり、最大値は 5 になります。インデックス 3 を単独で選択すると、最大値は 5 になります。位置を 2 重にカウントする単純なアプローチでは、不正確な合計が生成される可能性があります。 長さ 1 の配列またはすべて 0 の配列も、不注意な実装でつまずく可能性のあるエッジ ケースであり、1 倍の誤差や間違ったモジュロ計算が発生する可能性があります。 

## アプローチ

 ブルートフォースソリューションは概念的には単純です。 インデックスの空でないサブセットごとに、それらのインデックスを黒でマークし、倍数に従って緑を伝播し、最大値を計算して合計に加算します。 これは理論的には正しいですが、サブセットの数が次のとおりであるため、実際には実行できません。$2^n-1$。 のために$n=10^5$、サブセットごとに 1 つの操作さえ不可能です。 

重要な洞察は、視点を逆転させることで得られます。 黒のインデックスと緑の伝播について考える代わりに、それぞれの値について考えることができます。$a_i$そして尋ねてください: 黒のインデックスの選択が何個になるか$a_i$対応する色のセットの最大値は? これを効率的に数えることができれば、合計は次のようになります。$\sum a_i \times \text{count}_i$。 

効率的にカウントするには、インデックスの要素に注意してください。$i$は、その約数の少なくとも 1 つが黒として選択された場合にのみスコアの一部になります。 また、$a_i$が最大値になるように、それより大きい値を持つ要素はありません$a_i$黒または緑を含める必要があります。 値を降順に処理し、倍数に対する包含-除外の原則を使用して、値ごとに、その値を含みそれ以上の値を含まない有効な選択の数を計算できます。 これにより問題は次のように縮小されます$O(n \log n)$素数を法とする 2 の累乗の標準的な組み合わせ公式を使用した複雑さ。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * 2^n) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 値によって降順に並べ替えられたインデックスのリストを作成します。 これにより、最大の値を最初に処理できるようになります。 
2. ブール配列を維持する`used`すでに合計に含まれているインデックスを追跡するため。 最初は、すべてのインデックスは使用されません。 
3. 各値について$v$インデックスで$i$降順で:

 - このインデックスが最大として寄与できるサブセットの数を数えます。 
- これは、少なくとも 1 つの約数を含むインデックスのサブセットをカウントすることに相当します。`i`より大きな値によってまだ使用されていないインデックスの間。 
4. 効率的にカウントするために、次のすべての倍数を繰り返します。`i`（まで`n`) を参照して、まだ未使用のポジションがいくつあるかを確認します。 組み合わせ式を使用する$2^{\text{count}} - 1$空でない選択の場合。 
5.追加$v \times \text{number of selections}$結果をモジュロ 998244353 にします。 
6. Mark all multiples of`i`これは、より小さい値がこれらの位置に重なる選択をカウントできないようにするために使用されます。 
7. すべての値が処理されるまで続行します。 

Why it works: By processing in descending order of values and marking indices and their multiples as used, we ensure that each element is only counted in subsets where it is truly the maximum. 複数の包含/除外により、すべての選択が二重にカウントされることなく考慮されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    # store indices by value
    idx_by_value = sorted(range(n), key=lambda i: a[i], reverse=True)
    used = [False] * n
    result = 0

    pow2 = [1] * (n+2)
    for i in range(1, n+2):
        pow2[i] = (pow2[i-1] * 2) % MOD

    for idx in idx_by_value:
        if used[idx]:
            continue
        count = 0
        multiples = []
        for j in range(idx, n, idx+1):
            if not used[j]:
                count += 1
                multiples.append(j)
        if count > 0:
            result = (result + a[idx] * (pow2[count] - 1)) % MOD
            for j in multiples:
                used[j] = True

    print(result)

if __name__ == "__main__":
    solve()
```サブセット数は 2 の累乗であるため、コードは最初に 998244353 を法とする 2 の累乗を事前計算します。 次に、要素を降順に繰り返し、未使用の倍数をカウントします。 オーバーフローを避けるために、モジュロはすべてのステップで適用されます。 使用する`used`各インデックスが最大値となるサブセット内で 1 回だけカウントされるようにします。

 ## 特殊なケース

 アレイの場合`[1]`の場合、唯一選択できるのは最初の要素です。 コードは計算します`2^1-1=1`値を 1 倍すると 1 になります。これは予想される出力と一致します。 

のために`[5,1,5]`、最大値 5 が 2 回表示されます。 値の降順でインデックスを処理することにより、より高い値を含まない選択に対して各 5 がカウントされ、二重カウントが回避されます。 の`used`配列は次のことを保証します
