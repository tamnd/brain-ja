 ## 解決策
 ## 問題の理解

 正の整数の配列が与えられます`a`長さの`n`。 タスクは、要素に対して一連の「丸」操作を実行することです。`a`。 各操作はインデックスによって要素を選択し、それを「丸で囲みます」。同じ要素を複数回丸で囲むことができます。 すべての操作の後、丸で囲まれていない要素が元の順序で新しい配列を形成します。`r`。 丸で囲まれた要素インデックスの配列は、操作を実行した順序で別の配列を形成します。`p`。 私たちの目標は、次のような操作を実行することです。`r`最終的には次と等しくなります`p`。 無理な場合はご報告致します`-1`。 

制約は大きくなります。`n`到達できる`2·10^5`と要素`a`せいぜい`n`。 これにより、サブシーケンスの数が指数関数的に増加するため、丸で囲まれていない要素のすべての可能なサブシーケンスを試行する総当りのソリューションが即座に除外されます。 線形または線形に近いアプローチが必要です。`n`。 

問題の微妙な点は、`r`そして`p`。 素朴なアプローチは、要素を前から貪欲に丸くすることかもしれませんが、解決策では、残りの要素を正しい順序に「プッシュ」するために要素を複数回丸める必要がある場合があります。 たとえば、次の場合`a = [1,2,1]`、最初の部分だけを丸で囲むと考える人もいるかもしれません。`1`十分ですが、生成するには`r = [1,2,1]`必要に応じて、繰り返される要素を正しい位置に表示できるように、戦略的に円を描く必要がある場合があります。 

誤って処理されやすいエッジケースには、循環の順序が重要となる繰り返し番号を含む配列が含まれます。 例えば、`a = [2,2,2]`そして私たちが望んでいるのは`p = [2,2,2]`すべての要素を丸で囲んだ後、`r`空になり、決して等しくなりません`p`。 

## アプローチ

 ブルート フォース アプローチでは、可能なすべての操作数と丸で囲まれていない要素のすべてのサブシーケンスが考慮され、候補と一致するかどうかがチェックされます。`p`。 原理的には正しいですが、これには指数関数的な数のサブシーケンスを調べる必要があるため、`n = 2·10^5`。 

重要な洞察は、問題を配列からの一種の「貪欲な剥離」として扱うことができるということです。`a`。 作るには`r`に等しい`p`から要素を削除する必要があります。`a`の最後の要素と一致しないもの`r`逆の順序で。 つまり、逆に考えることができます。`p`丸で囲まれていない最後の要素として表示する必要があります。 横断したら`a`逆に、現在の目標値に達するたびに、`r`、丸を付けないままにします。 他のすべての要素は丸で囲まれ、操作に追加されます。 端からレイヤーを繰り返し剥がし、どの要素が残っているかを追跡することで、確実な動作を保証する一連の操作を再構築できます。`r = p`可能であれば。 

この方法は、複数回丸で囲まれた要素は複数回現れる可能性があるという事実を利用します。`p`、そして逆方向に作業することで、複雑なサブシーケンスのチェックを回避します。

 ## アルゴリズムのチュートリアル

 1. リストを初期化する`ops`丸で囲まれたインデックスのシーケンスを保存します。 初期化する`remaining`のコピーとして`a`。 
2. その間`remaining`は空ではありません。最後の一意の値を決定します`val`で`remaining`それは最後に表示される必要があります`r`。 この値は、現在のレイヤーで必要な最後の丸で囲まれていない要素に対応します。 
3.トラバース`remaining`最初から最後まで。 等しくない各要素について`val`、そのインデックスを追加します`ops`。 これは、妨げとなるすべての要素を丸で囲むことをシミュレートします。`val`正しい位置にいることから。 
4. すべての出現箇所を削除します。`val`から`remaining`これで、丸印を付けずにそのままにしても問題ありません。 残りの要素は、処理する次の層を形成します。 
5. まで手順 2 ～ 4 を繰り返します。`remaining`は空です。 
6. いずれかの段階で必要な場合は、`val`足りない、返す`-1`。 それ以外の場合は、長さを出力します。`ops`そしてリスト`ops`。 

機能する理由: レイヤーを端から逆方向に処理し、最後に必要な要素の配置を妨げる要素を丸で囲むことにより、丸で囲まれていない要素の各レイヤーが、対応する部分と一致することを保証します。`p`。 不変条件は、各層の後で、丸で囲まれていない要素が接頭辞を形成するということです。`r`要素が間違って配置されていないことを確認しながら、まだ構築する必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    from collections import Counter, deque
    
    ops = []
    remaining = deque(a)
    
    while remaining:
        # Find the last unique value
        counts = Counter(remaining)
        val = next(reversed(remaining))
        
        layer_ops = []
        new_remaining = deque()
        found = False
        
        for idx, x in enumerate(remaining):
            if x != val:
                layer_ops.append(idx + 1)
                new_remaining.append(x)
            else:
                found = True
        
        if not found:
            print(-1)
            return
        
        ops.extend(layer_ops)
        remaining = deque([x for i,x in enumerate(remaining) if x == val])
    
    print(len(ops))
    print(' '.join(map(str, ops)))

solve()
```ソリューションでは、`deque`要素を効率的にポップし、`Counter`レイヤーを識別します。 インデックスは、問題ステートメントに一致するように 1 から始まります。 最後から逆方向に作業することを選択すると、繰り返される要素の誤った配置の間違いを回避できます。
