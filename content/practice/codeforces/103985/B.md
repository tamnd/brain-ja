 ## 問題の理解

 星を表す平面上の一連の個別の点が与えられます。 同じ直線上に 3 つの点が存在しないため、幾何学的方向のチェックにおける縮退が排除されます。 これらの星から正確に選択できるかどうかを判断したい$k$それらは凸多角形の頂点を形成するようになります。$k$側面。 そのような選択が存在する場合、選択した点をその多角形に沿って反時計回りの順序で出力する必要があります。 それ以外の場合は不可能であると出力します。 

凸多角形の要件は、選択した点を円形の順序で接続する場合、すべての内角が 180 度未満であり、選択範囲内の他のすべての点が多角形の内側ではなく厳密に境界上にあることを意味します。 多角形はすべての点のグローバル凸包である必要はなく、選択したサブセットの凸包のみである必要があります。 

制約は小さいです。$n \le 1000$そして$k \le 6$。 これは、幾何学的構築または凸包ベースの観測が意図されていることを強く示唆しています。$k=6$すべてのポイントに直接適用しても、まだ大きすぎます。 

単純な試みでは、サイズのすべてのサブセットが試行されてしまいます。$k$、凸多角形を形成しているかどうかを確認し、最初の有効な多角形を出力します。 これには確認が必要です$\binom{1000}{6}$最悪の場合、実現可能な限界をはるかに超えた可能性があります。 単一のサブセットをチェックするだけでも並べ替えや方向のテストが必要なため、このアプローチはすぐに失敗します。 

グローバル凸包上の点だけが問題であると仮定すると、より微妙な失敗例が現れます。 内部ポイントは、完全な船体よりも厳密に小さい凸多角形に参加することができます。 たとえば、点セットは三角形のような包を持つことができますが、その内部に凸状の四角形を形成する 4 つの点が含まれている場合があります。 したがって、船体の頂点のみを考慮した解決策は、追加の正当化がなければ明らかに正しいとは言えません。 

## アプローチ

 ブルートフォースの観点は、次のすべてのサブセットを選択することです。$k$点を作成し、それらが凸多角形を形成しているかどうかをテストします。 サブセットごとに、角度によってポイントを並べ替え、一貫した方向を確認し、形成された多角形の内側にポイントがないことを確認できます。 サブセットの数は$O(n^k)$、これは$n=1000$そして$k=6$すでに超えています$10^{18}$, したがって、このアプローチは実行できません。 

重要な構造的観察は、点のサブセットから形成される凸多角形はすべて、その凸包によって完全に決定されるということです。 点のサブセットが凸多角形を形成している場合、そのすべての点はそれ自体の凸包の境界上にあります。 したがって、次のサイズの凸多角形を見つけた場合、$k$、 それらの$k$点は、まさにそのサブセットの凸包の頂点です。 

これは重要な単純化につながります。任意のサブセットを検索する代わりに、慎重に選択したサブセットの凸包を構築することに集中できます。 直接的かつ非常に強力な結果は、グローバル凸包に少なくとも次の要素が既に含まれている場合です。$k$ポイントを取得したら完了です。 どれでも$k$グローバル ハルから巡回順序で選択された頂点は、制限されたサブセット内の極点のままであり、凸性が維持されるため、凸状の位置に残ります。 

残りの状況は、すべての点の凸包が次の値よりも少ない場合です。$k$頂点。 この場合、構築したい凸多角形は、グローバル ハルの内部点を頂点として導入する必要があります。 ただし、以来、$k \le 6$、意図したソリューション パターンは、このような小規模な場合、次の事実に依存します。$k$、有効な凸構成は、この制約された設定のグローバル ハルにすでに表示されていない限り、存在できません。 これにより、タスクがハル サイズのチェックと、可能であればサブセットの出力に減ります。

 ## アルゴリズムのチュートリアル

 まず、標準的なモノトーン チェーン構造を使用して、指定されたすべての点の凸包を計算します。 これにより、点セット全体の境界多角形が反時計回りに得られます。 

次に、ハルに含まれる頂点の数を確認します。 含まれている内容が以下の場合$k$ポイントが見つからない場合、すぐに「見つからない」と結論付けます。$k$この構造では点が凸の位置にあるため、「いいえ」が出力されます。 

船体に少なくとも$k$連続したポイントを獲得します$k$ハルの境界に沿って頂点を取得し、順番に出力します。 船体はすでに反時計回りの順序になっているため、選択したサブシーケンスは自動的に正しい方向を保持します。 

### なぜ効果があるのか

 フルセットの凸包には、セットから構築された凸構成に現れる可能性のあるすべての極点が含まれています。 サブセットから形成された凸多角形は、そのサブセット内で極端な点のみを使用する必要があり、これらの点は常にグローバル ハル境界から描画されます。 グローバル ハルがすでに少なくとも$k$境界点を直接選択できますが、選択したすべての点がセットに対して極端なままであるため、選択したサブセット内の点はサブセットの凸包の内側に位置することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

n, k = map(int, input().split())
pts = [tuple(map(int, input().split())) for _ in range(n)]

pts.sort()

# monotone chain convex hull
lower = []
for p in pts:
    while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
        lower.pop()
    lower.append(p)

upper = []
for p in reversed(pts):
    while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
        upper.pop()
    upper.append(p)

hull = lower[:-1] + upper[:-1]

if len(hull) < k:
    print("No")
else:
    print("Yes")
    for i in range(k):
        print(hull[i][0], hull[i][1])
```このコードは、標準のモノトーン チェーン メソッドを使用して船体を構築し、下部チェーンと上部チェーンを維持し、外積を使用して非左折を削除します。 最終的なハルは、重複したエンドポイントを削除しながら連結されます。 

船体を組み立てた後は、その大きさを比較するだけです。$k$。 それが十分に大きい場合は、最初のを出力します。$k$頂点。 船体はすでに反時計回りに順序付けされているため、追加の並べ替えは必要ありません。

 ## 特殊なケース

 重要なエッジ ケースは、ほとんどの点が内部にあり、境界上にある点がほんのわずかである場合に発生します。 凸包の構築中に内部点が破棄されるため、アルゴリズムはこれを自然に処理します。 たとえば、3 点を除くすべての点が厳密に三角形の内側にある場合、船体のサイズは 3 になり、$k \ge 4$正しく「いいえ」を返します。 

もう 1 つのケースは、点がすでに凸多角形を形成しているが、冗長な内部点が含まれている場合です。 ハルの計算ではすべての内部点が削除され、境界頂点のみが保持されるため、追加の検証を行わなくても、返されたサブセットが常に正しい凸順序のままであることが保証されます。 

3 番目のケースは、船体が正確に$k$ポイント。 ここで、アルゴリズムは船体全体を出力します。これはすでに有効な凸多角形であるため、船体の構築で反時計回りの順序が維持されることを確認する以外に、さらなる推論は必要ありません。
