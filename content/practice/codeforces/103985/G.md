 ## 解決策
 ## 問題の理解

 私たちは、キャンディーが食べられた順番に並べられたキャンディーの包み紙の最終的な目に見えるシーケンスを与えられます。 各ラッパーは赤、青、または不明のいずれかです。 不明なシンボルは、食べたキャンディーが赤か青かわからないことを意味します。 重要な隠されたメカニズムは、食べる前にキャンディーがどのように選ばれたかです。 

各ステップには、赤と青のキャンディーがいくつか入った箱がありました。 食べる人は常に、現在厳密に大きい数を持つ色から選択します。 両方の色のカウントが同じ場合は、赤が選択されます。 キャンディーを食べた後、その包装紙が最終シーケンスに追加されました。 部分的な情報を含むこの最終シーケンスのみを観察し、ボックスの異なる初期構成がいくつあればこのシーケンスがある程度完成する可能性があることを数えたいと考えます。 

構成は、最初に存在した赤と青のキャンディーの数によってのみ決定されます。 これらの数が異なる場合、2 つのボックスは異なります。 すべての未知のラッパーを解釈し、貪欲なルールの下で観察されたシーケンスを再現する有効な方法が存在するように、非負の整数のペアを何組割り当てることができるかを数えるよう求められます。 

n が 200000 までの制約により、考えられるすべての初期状態または疑問符へのすべての割り当てをシミュレートしようとするアプローチが即座に除外されます。 構成を直接列挙する場合、候補構成ごとに O(n²) または O(n log n) であっても遅すぎます。 解決策では、問題を少数の候補状態に減らすか、線形スキャンで式を計算する必要があります。 

シーケンスが貪欲ルールと一致しない場合、微妙なエッジ ケースが発生します。 たとえば、ある接頭辞で観察された色により、貪欲ルールが必要な優勢条件に矛盾する色を選択するように強制された場合、答えはゼロでなければなりません。 もう 1 つのエッジ ケースは、すべての文字が不明な場合です。これは、複数の初期状態が適合する可能性がありますが、決定論的なタイブレーク ルールにより常に赤が優先されるため、すべての比率が有効であるわけではないためです。 

2 番目の明白ではないケースは、シーケンスが完全に決定的 (「?」なし​​) の場合です。この場合、初期設定は 1 つだけ機能するか、まったく機能しない可能性があり、貪欲ルールはプレフィックスの違いに必要な不等式を一意に再構築できます。 

## アプローチ

 この強引なアイデアは、赤と青のキャンディーの最初の数をすべて試してみることです。 各ペア (R、B) について、プロセスを段階的にシミュレートします。 各ステップで、貪欲ルールに従ってどの色を選択する必要があるかを確認し、それが観察された文字と一致するか、または「?」の場合は割り当てることができるかどうかを検証します。 矛盾が生じた場合、この最初のペアは無効になります。 

これが機能するのは、初期カウントが固定されるとプロセスが決定的になるためです。 ただし、可能な (R, B) ペアの範囲は有効な方法で制限されていません。 原則として、R と B は n まで大きくできるため、O(n²) 個の候補状態が存在します。 各シミュレーションのコストは O(n) で、合計の複雑さは O(n³) になりますが、これは n が 200000 までの場合はまったく実行不可能です。 

重要な観察は、プロセスが進行するにつれて、赤と青のカウントの差のみに依存するということです。 各ステップでは、選択した色から 1 を減算して差を更新します。 貪欲ルールは、固定のタイブレーク ルールを使用して、この差の符号のみに依存します。 フルカウントを追跡する代わりに、プロセスを、観察されたシーケンスによって制約される差分変数のウォークとして見ることができます。 それぞれの有効な初期設定は、貪欲な選択条件に決して違反しない、一貫した初期差分値に対応します。

これにより、問題は、どの初期差異がシーケンス制約と互換性があるかを確認するだけになります。 各位置は電流の差に不等式を課し、これらの不等式は線形に伝播します。 シーケンス全体が単一の整数パラメータに対する制約のセットとなり、すべての制約を同時に満たす整数値の数を数えます。

 ## アルゴリズムのチュートリアル

 各ステップの前の任意の時点での差 d = R - B の観点からプロセスを再構成します。 d > 0 の場合、赤を選択する必要があります。 d < 0 の場合、青を選択する必要があります。 d = 0 の場合、タイブレークにより赤が選択されます。 

各ステップでキャンディーが 1 つ消費されるため、赤を選択すると d が 1 減少し、青を選択すると 1 増加します。 

どの初期 d 値が有効であるかはわかりませんが、すべてのステップを処理した後、d が完全に決定されることはわかっています。 問題は、観察されたすべての制約と一致するシーケンスにつながる開始値の数を数えることになります。 

シーケンスのプレフィックスを処理した後に起こり得る現在の差異の範囲を記述する 2 つの境界 L と R を維持します。 

### ステップ

 1. 考えられる初期差 d₀ に対して、L = -∞ および R = +∞ を初期化します。 

これは、制約が適用される前は、任意の整数の差が可能であることを表します。 
2. シーケンスを左から右にスキャンし、各ステップ後に発生する可能性のある電流差の範囲を維持します。 

それぞれの位置で、観察結果を現在の差に関する制約に変換します。 
3. 文字が「r」の場合、赤が厳密に小さくない場合に赤が選択されるため、その時点で d ≥ 0 でなければなりません。 

赤を選択すると、新しい差は d - 1 になるため、制約を一貫して前方に伝播します。 
4. 文字が「b」の場合、d < 0 でなければなりません。青が厳密に多い場合、または赤が優勢でない場合にのみ青が選択されるからです。 

青を選択すると、新しい差は d + 1 になります。 
5. 文字が「?」の場合、d に応じて両方の遷移が可能です。 これは 2 つのケースに分かれます。 

d ≥ 0 の場合は「r」のように動作し、d < 0 の場合は「b」のように動作します。 結果として得られる両方の制約を統合された間隔にマージします。 
6. すべての位置を処理した後、最終区間 [L, R] はすべての有効な初期差 d₀ を表します。 答えは、この区間内の整数の数、つまり max(0, R - L + 1) です。 

### なぜ効果があるのか

 すべてのステップで、貪欲ルールは、現在の差の符号に基づいて整数ラインを 2 つの領域に分割します。 観察された各文字は、1 つの領域を強制するか、両方を許可します。 d の更新は線形かつ単調であるため、実行可能な初期値のセットは各ステップの後でも連続した間隔のままになります。 各ステップは単一のしきい値分割によるアフィン変換のみを適用するため、ばらばらの実行可能領域は表示されません。 これにより、実行可能な最小および最大の開始差を追跡するだけで十分であり、有効な構成が欠落したり二重にカウントされたりしないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    n = len(s)

    # We track possible current difference intervals [lo, hi]
    lo, hi = 0, 0  # current difference after 0 steps starts at 0 shift baseline

    for ch in s:
        if ch == 'r':
            # must have d >= 0 before choosing red
            new_lo = max(lo - 1, 0)
            new_hi = hi - 1
        elif ch == 'b':
            # must have d < 0 before choosing blue
            new_lo = lo + 1
            new_hi = min(hi + 1, -1)
        else:
            # '?' can be either
            # combine both transitions
            # red case
            r_lo = max(lo - 1, 0)
            r_hi = hi - 1
            # blue case
            b_lo = lo + 1
            b_hi = min(hi + 1, -1)

            new_lo = min(r_lo, b_lo)
            new_hi = max(r_hi, b_hi)

        lo, hi = new_lo, new_hi
        if lo > hi:
            print(0)
            return

    print(max(0, hi - lo + 1))

if __name__ == "__main__":
    solve()
```コードは、各プレフィックスの後に実行可能な電流差の間隔を維持します。 赤の観測値の場合、ステップの前の差が負でないことが強制され、1 を減算してシフトされます。 青の場合、マイナスを強制し、1 を追加することでシフトします。 未知の値の場合は、両方の可能性がマージされます。 間隔更新は、貪欲な選択ルールと差の進化の両方を単一の線形パスでエンコードします。 

実装上の微妙な問題は、符号制約を強制するときの境界の処理です。 シフトする前にゼロでの分割を適用する必要があります。適用しないと、変換によって互換性のない状態が混在します。 もう 1 つの微妙な点は、「?」をマージするときに、到達可能な間隔の結合を慎重に計算する必要があることです。 両方のブランチを完全に取得できないと、有効な初期構成が過小評価される可能性があります。

 ## 特殊なケース

 重大なエッジ ケースは、シーケンスが貪欲ルールに直ちに矛盾する場合です。 のために`"rr"`、最初の赤の後、状態は 2 番目の赤に対して負または無効な差を強制し、すべての可能性を排除します。 アルゴリズムは、2 番目のステップの処理後に間隔が空になることによってこれを検出します。 

もう 1 つのケースは、長いシーケンスです。`"?"`文字。 間隔はしばらく拡大しますが、各ステップはゼロ付近でシフトおよび反映するだけであるため、連続したままになります。 このアルゴリズムは、可能性のあるすべての初期差異を、明示的に列挙することなく正しく累積します。 

最後のケースは、次のような強制的な選択を交互に繰り返すことです。`"rbrb..."`、各ステップでは間隔が狭まりますが、分岐は許可されません。 このアルゴリズムは単一の進化可能な実行可能範囲を維持し、最終的なカウントは、変更によって引き起こされるすべてのパリティ制約と一致する整数の初期差の数に正確に対応します。
