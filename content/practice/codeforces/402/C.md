 ## 解決策
 ## 問題の理解

 特別なタイプの無向グラフを構築するように求められます。 グラフには _n_ 個の頂点と _p_ パラメータがあり、2 つのグローバル条件を満たす必要があります。 まず、エッジの総数はちょうど 2_n_ + _p_ です。 第二に、_k_ 頂点のサブグラフは 2_k_ + _p_ を超えるエッジを持つことはできません。 同じ頂点ペア間の自己ループと複数のエッジは禁止されています。 

実際には、入力には _n_ と _p_ を指定するいくつかのテスト ケースが与えられ、出力は基準を満たすグラフのエッジのリストになるはずです。 各エッジは、接続する頂点に対応する整数のペアとして表現されます。 _n_ (最大 24) の制約と、合計エッジが常に控えめであるという事実は、大量の組み合わせ検索に依存するのではなく、建設的に推論できることを示唆しています。 解の存在が保証されているということは、これらのグラフを生成するための単純で反復可能なパターンが存在することも示唆しています。 

繊細さは部分グラフの条件から生まれます。 _k_ が小さい場合、エッジを追加しすぎるとルールに違反する可能性があります。 たとえば、n = 6 および p = 0 の場合、ちょうど 12 個のエッジが必要になります。 すべての頂点を他の頂点に接続する単純なアプローチでは、合計エッジ数がほぼ正しい場合でも、15 個のエッジが生成され、部分グラフのルールに違反します。 したがって、アルゴリズムは、頂点のサブセット内のエッジ数が許可されたしきい値を決して超えないように、慎重にエッジを追加する必要があります。 

## アプローチ

 ブルートフォース手法では、_n_ 個の頂点上のすべての可能なエッジのセットを列挙し、各候補を部分グラフの条件に対してチェックします。 考えられるすべてのグラフを生成するには、m 個のエッジに対して C(n(n−1)/2, m) 個のエッジの組み合わせを考慮する必要があり、これは n = 24 の場合でも組み合わせ爆発的です。サブグラフの条件を単純にチェックするには、すべての 2^n サブセットを調べる必要があり、総当たりアプローチは完全に実行不可能になります。 

重要な洞察は、数式を調べることで得られます。 2_n_ + _p_ エッジ グラフは、「ほぼ 2 規則的な」構造として解釈できます。各頂点は約 2 つのエッジに属し、_p_ 個の余分なエッジが慎重に追加される必要があります。 各頂点を次の 2 つの隣接頂点に循環的に接続することから始めると、頂点の小さなサブセットには 2_k_ 個以下のエッジが含まれることが保証されます。 これは、k 個の頂点の接続されたサイクルが局所的に最大 2_k_ エッジに寄与するためです。 

基本サイクルが構築されると、サブグラフの境界に違反することなく、まだ完全に接続されていない頂点間に追加の _p_ エッジを順次追加できます。 問題によって解決策が存在することが保証されるため、そのようなペアを常に体系的に選択できます。 これにより、構築が単純で決定的なパターンに縮小されます。つまり、コードでサイクルを形成し、目的の合計 2_n_ + _p_ に達するまで残りのエッジを散りばめます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n^2) | O(n^2) | 遅すぎる |
 | 建設的 / パターン | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

1. エッジの空のリストを初期化します。 段階的にグラフを作成していきます。 
2. モジュラー演算で各頂点を次の 2 つの頂点に接続する単純なサイクルを構築します。 頂点 i について、辺 (i, i+1) と (i, i+2) を追加し、法 n を使用してラップアラウンドします。 これにより、各頂点が最初に次数 2 を持つことが保証され、すべての k の部分グラフの境界が満たされます。 
3. 追加されたエッジを数えます。 この時点で、正確に 2_n_ 個のエッジがあります。 
4. _p_ > 0 の場合、エッジを _p_ 追加する必要があります。 まだ接続されていない頂点のペア (i, j) を、小さい i および j > i から始めて繰り返します。 このようなペアごとにエッジを追加し、合計が 2_n_ + _p_ に達するまでカウントを増加します。 n が小さく、部分グラフの境界が緩やかであるため、これは常に可能です。 
5. エッジのリストを頂点ペアとして出力し、番号付けが 1 から始まることを確認します。 

機能する理由: この段階では次数 2 を超える頂点がないため、基本サイクルでは k 頂点のすべてのサブセットが最大 2_k_ エッジを持つことが保証されます。 _p_ はグローバルに考慮されるため、隣接しない頂点間に _p_ 個の余分なエッジを追加しても、2_k_ + _p_ 境界に違反するサブセットが作成されることはありません。 このアルゴリズムは、サブグラフの不変性を維持しながら、グラフを段階的に構築します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, p = map(int, input().split())
        edges = []
        
        # Step 1: add base 2*n edges using modular neighbors
        for i in range(n):
            edges.append((i+1, (i+1) % n + 1))      # connect to next
            edges.append((i+1, (i+2) % n + 1))      # connect to next-next
        
        # Step 2: add extra p edges
        if p > 0:
            added = 0
            for i in range(n):
                for j in range(i+3, n):
                    if added >= p:
                        break
                    edges.append((i+1, j+1))
                    added += 1
                if added >= p:
                    break
        
        for a, b in edges:
            print(a, b)

solve()
```このソリューションでは、まず、各頂点が隣接する頂点に対して 2 つのエッジを持つ、予測可能な基本パターンを構築します。 モジュロ演算はサイクルの折り返しを正しく処理します。 追加の _p_ エッジは、サブグラフの境界の違反を避けるために、直接隣接していない頂点に追加されます。 慎重にインデックスを作成することで、off-by-one エラーが発生しないようにします。
