 ## 解決策
 ## 問題の理解

 この問題では、それぞれに数字がラベル付けされたボックスの列が表示されます。テオファニスは、それらを非降順で並べたいと考えています。 問題は、任意のボックスを交換したり、標準的な並べ替え操作を実行したりできないことです。 彼のマシンでは、最大でも長さの部分配列を反転できます$k$。 サブ配列はボックスの連続したセグメントであり、それを逆にすることは、そのセグメント内のボックスの順序を反転することを意味します。 タスクは、このような反転を任意の数だけ使用して、配列全体を非降順にソートできるかどうかを判断することです。 

入力は複数のテスト ケースで構成され、それぞれがボックスの数を提供します。$n$、サブ配列の最大長$k$それは逆にすることができ、ボックス上の最初の数字のシーケンスです。 各テスト ケースの出力は、指定された操作でボックスを並べ替えることができる場合は「YES」、そうでない場合は「NO」になります。 

制約は控えめです。$n$そして$k$それぞれ最大 100 まで指定できます。これは、$O(n^2)$アルゴリズムは実現可能です。 しかし、$a_i$と同じ大きさにすることができます$10^9$これにより、値を圧縮しない限り、ソート配列または頻度配列のカウントに依存するソリューションは除外されます。 以来$n$が小さい場合は、直接比較、並べ替え、および位置分析に基づく解決策が合理的です。 

重要なエッジケースが発生するのは次のような場合です$k = 1$。 このシナリオでは、長さ 1 の部分配列を反転しても何も起こらないため、配列は既にソートされている場合にのみソート可能であると見なされます。 もう一つの微妙なケースは次のような場合です。$k \ge n$。 その後、配列全体を一度に反転できるため、配列を常に並べ替えることができます。 すべての要素が等しい配列は簡単にソート可能ですが、要素が厳密に増加する必要があると想定している場合、不注意な実装ではこれを誤って処理する可能性があります。 

## アプローチ

 ブルートフォースアプローチは、最大でも長さの反転のあらゆる可能なシーケンスをシミュレートすることです。$k$そして、あるシーケンスがソートされた配列につながるかどうかを確認します。 原理的には正しいですが、このアプローチは非現実的です。ポジションごとに、最大で$k$反転の長さを選択できるため、状態の数が指数関数的に増加します。 たとえ$n = 100$、これは計算上不可能です。 

重要な洞察は、配列の端近くの要素の柔軟性が限られているという観察から得られます。 インデックスの要素$i$せいぜい移動できる$k-1$反転によりどちらの端からも離れた位置に配置されます。 で表すと$sorted\_a$完全にソートされた配列、最終位置が$sorted\_a$元の位置とは少なくとも異なります$k$目標位置に到達できない場合$k < n$。 したがって、問題は、最初の$k-1$そして最後に$k-1$配列内の位置は、ソートされた配列とすでに互換性があります。 厳密に中央のポジションの場合、反転により完全なシャッフルが可能になります。 

形式的には、配列をソートしてターゲット構成を取得できます。 それから、ポジションについては、$i < k$または$i \ge n-k+1$、の値$a[i]$ソートされた配列とすでに一致している必要があります。 これらの境界位置がすべて一致する場合、反転を使用して配列を並べ替えることができます。 それ以外の場合はできません。 いつ$k \ge n/2$、これにより、すべての要素が正しい位置に到達できるようになり、配列は常に並べ替え可能になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 位置ベースのチェック | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$、$k$、および配列$a$。 
3. のコピーを作成します。$a$それを並べ替えて取得します$sorted\_a$。 
4. もし$k = 1$、 比較する$a$直接$sorted\_a$。 一致する場合は、「YES」を出力します。 それ以外の場合は、「NO」を出力します。 これは、効果的な反転が不可能な特殊なケースに対処します。 
5. それ以外の場合は、次の位置を繰り返します。$0$に$k-2$（最初$k-1$ポジション）とから$n-k+1$に$n-1$(最後の$k-1$ポジション）。 各要素が対応する要素と一致するかどうかを確認します。$sorted\_a$。 
6. すべての境界位置が一致する場合は、「YES」を出力します。 それ以外の場合は、「NO」を出力します。 

機能する理由: 次の場合、境界位置を十分に移動できません。$k < n$したがって、それらはすでに正しいソート位置に配置されている必要があります。 ミドルポジションは、重複する長さの反転に参加できるため、複数の反転を使用して常にシャッフルできます。$k$。 この不変式により正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    sorted_a = sorted(a)
    
    if k == 1:
        print("YES" if a == sorted_a else "NO")
        continue
    
    ok = True
    for i in range(k-1):
        if a[i] != sorted_a[i]:
            ok = False
            break
    for i in range(n-k+1, n):
        if a[i] != sorted_a[i]:
            ok = False
            break
    print("YES" if ok else "NO")
```コードは高速 I/O を使用して入力を読み取ります。 配列をソートすると、ターゲット構成を決定できます。 境界位置をチェックすることで、制限された反転長さという重要な制限に対処できます。 の使用`k-1`そして`n-k+1`端近くの要素の最大到達範囲を正確にキャプチャします。
