 ## 解決策
 ## 問題の理解

 整数の配列が与えられました。私たちの仕事は、それを連続した空ではないサブ配列に分割することです。 各サブ配列は、_Cypriot value_ と呼ばれる加重合計に寄与します。これは、サブ配列の合計にパーティション内の 1 から始まるインデックスを乗算したすべてのサブ配列の合計として計算されます。 私たちの目標は、この加重合計を最大化することです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースには配列の長さが含まれます`n`配列要素 (負または正の場合があります)。 出力はテスト ケースごとに 1 つの整数、つまり一部のパーティションで達成可能なキプロスの最大値です。 

制約が教えてくれる`n`最大 100,000 およびすべての合計`n`テスト ケース全体で最大 200,000 件です。 これは、二次方程式の解はすべて、`n`遅すぎるでしょう。 線形または線形に近い解決策が必要です。 

明らかでないエッジ ケースには、すべてが正、すべてが負、または符号が交互になる配列が含まれます。 たとえば、後の正の要素の重み付き合計が減らないように、単一の負の数は単一の部分配列として残す必要があります。 配列の場合`[5, -2, 3]`、すべての要素を単純に結合すると、負の数を中心に分割するよりも小さな値が得られます。 

## アプローチ

 ブルート フォース ソリューションでは、配列を分割するあらゆる可能な方法が考慮されます。 分割ごとに`k`部分配列の場合、重み付けされた合計を計算します。 動的プログラミングを使用した場合でも、各プレフィックスのすべての分割ポイントを反復処理すると、複雑さは O(n^2) になります。 のために`n = 10^5`、これにはおよそ 10^10 の操作が必要になりますが、これは実行不可能です。 

重要な洞察は、インデックス乗数がどのように動作するかを観察することで得られます。 大きな正の数は、パーティションの後半に出現すると、より大きなインデックスが乗算されるため、寄与度が高くなります。 逆に、負の数値が後から現れると、合計への寄与が少なくなるか、悪くなる場合さえあります。 したがって、最適な戦略は、同じ符号を持つすべての連続する要素シーケンスが単一のサブ配列として扱われるように配列を分割することです。 言い換えれば、符号が変わるたびに配列を分割します。 連続する正または負の各ブロック内で、ブロックが負の場合はそのブロックの最大の要素のみを取得し、ブロックが正の場合はすべての要素を合計します。 

この観察により、問題は単純な線形スキャンに帰着します。つまり、配列を反復処理し、現在の「符号ブロック」を追跡し、マージするか新しいブロックを開始するかを決定します。 このソリューションはテスト ケースごとに O(n) 時間で実行され、制約内に問題なく収まります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.初期化`total`0 として最終的なキプロス値を保持します。 初期化もする`current_max`配列の最初の要素として、現在の連続ブロック内の最良の値を表します。 
2. 2 番目の要素から最後まで配列を繰り返します。 
3. 現在の要素が次と同じ符号を持つ場合`current_max`、 交換する`current_max`それ自体と現在の要素の最大値を使用します。 これにより、ポジティブまたはネガティブ ブロック内で最も価値のある要素が確実に選択されます。 
4. 符号が変わった場合は追加します。`current_max`に`total`、次に設定します`current_max`現在の要素に。 これにより、符号の変更で配列が分割されます。 
5. 反復が終了したら、最後のを追加します。`current_max`に`total`最後のブロックを含めます。 
6. 印刷`total`。 

機能する理由: 各符号ブロックに最大の要素を含めることで、後のブロックに悪影響を与えることなくブロックの寄与を最大化します。 Adding smaller elements within a negative block would decrease the Cypriot value because multiplying them by the index gives a larger negative penalty. この貪欲なアプローチにより、最大額が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_cypriot_value(arr):
    total = 0
    current_max = arr[0]
    for num in arr[1:]:
        if (num > 0 and current_max > 0) or (num < 0 and current_max < 0):
            current_max = max(current_max, num)
        else:
            total += current_max
            current_max = num
    total += current_max
    return total

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(max_cypriot_value(a))
```最初のループでは、連続する各符号ブロック内の最良の候補を維持します。 比較`(num > 0 and current_max > 0) or (num < 0 and current_max < 0)`現在の要素が同じ符号のブロックに続いているかどうかを確認します。 2 番目のブランチは追加します`current_max`に`total`符号が変わると、新しいブロックが作成されます。 追加`current_max`最後に最後のブロックを処理します。

 ## 特殊なケース

 単一要素の配列`[830]`セット`total = 830`すぐに。 このアルゴリズムは、最大の負の要素を唯一の寄与要素として選択することにより、負の数のみを含む配列を正しく処理します。 各変更がブロック分割をトリガーするため、交互符号が処理され、複雑なロジックなしで最適なパーティションが保証されます。
