 ## 解決策
 ## 問題の理解

 2D 平面上の一連の点が与えられます。 各点は電柱を表し、各極のペアは無限の直線を定義し、これを「ワイヤー」として解釈します。 ただし、同じ幾何学的線​​上にある複数の極は、複数のコピーではなく、単一のワイヤに対応します。 したがって、事実上、少なくとも 2 つの極によって決定されるそれぞれの個別の線がワイヤとなります。 

タスクは、これらのワイヤの順序のないペアが平面内のどこかで何対交差するかを数えることです。 

2 本のワイヤ間の交差は、対応する線が平行でなく、同じ線ではない場合に発生します。 ワイヤは無限の線であるため、平行でない 2 本の別個の線は 1 回だけ交差するため、問題は異なる傾きを持つ別個の線のペアを数えるということになります。 

入力サイズは非常に小さく、最大でも 50 ポイントです。 これにより、すべての点のペアまたはすべての点のトリプルを考慮したソリューションが直ちに可能になります。 

微妙だが重要な問題は、重複行です。 3 つ以上の点が同じ直線上にある場合、それらの点のすべてのペアが同じワイヤを生成し、それらは 1 回だけカウントされる必要があります。 すべての点のペアを個別の線として扱う単純なアプローチでは、交差点が大幅にカウントされすぎてしまいます。 

多くの点が同一線上にある場合、別の特殊なケースが発生します。 たとえば、すべての点が 1 つの線上にある場合、ワイヤーは 1 本だけあり、答えは 0 でなければなりません。 単純なペアごとの交差数では、誤って正の数が生成されます。 

## アプローチ

 直接的なアイデアは、点のすべてのペアを線を定義するものとして扱い、そのような線のすべてのペアの交差をチェックすることです。 点が最大 50 個あるため、点のペアは最大 1225 個あり、候補線の数は最大でこれだけになります。 これらの線のすべてのペアをチェックするには、およそ 10^6 の操作が必要であり、これはまだ実行可能ですが、本当の困難は、2 つの点のペアが同じ幾何学的な線を定義するタイミングを識別することです。 注意して正規化しないと、重複によって正確性が損なわれてしまいます。 

より明確な観点は、最初に一意の行のセットを構築することです。 点のペアごとに、それらが定義する線の正規表現を計算し、それをセットに保存します。 これにより、すべての異なるワイヤーが得られます。 

すべての一意の線を取得したら、それらの線が交差するペアの数を数える必要があります。 2 本の線は平行な場合にのみ交差しません。 そこで、傾きの方向ごとにラインをグループ化し、各グループ内のペアの数を減算します。 

これが機能するのは、交差のカウントが、平行なペアを差し引いたすべての線のペアをカウントすることと同じであるためです。 各傾斜グループ内では、2 本の線が交差することはありません。 

重要な洞察は、幾何学的交差の計算がまったく必要ないということです。 必要なのは、傾きの等価クラスとラインの一意性だけです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースラインペア | O(M²) ただし、M ≤ 1225 | お(お) | 受け入れられたが乱雑 |
 | 正準線 + 傾きのグループ化 | O(n² log n) | O(n²) | 承認済み |

 ## アルゴリズムのチュートリアル

1. すべての点のペアを繰り返し、それらを通過する線を作成します。 同一の幾何学的ラインが同じキーにマップされるように、各ラインを正規化された形式で表現します。 これにより、同一線上にあるトリプルが重複を生成しないことが保証されます。 
2. それぞれの一意の行をハッシュ セットまたは辞書に保存します。 各エントリは、最終的なグラフ内の 1 つのワイヤを表します。 
3. 格納された各ラインについて、符号の曖昧さを避けるために正規化された方向ベクトル (dx, dy) を計算します。たとえば、gcd で割って符号を固定します。 
4. ラインを勾配キーでグループ化します。 各グループは、互いに平行なすべてのワイヤを表します。 
5. 個別のラインの総数を M とします。順序のないラインのペアの数は M(M-1)/2 です。 
6. サイズ k の各傾斜グループについて、これらのペアは平行で決して交差しないため、k(k−1)/2 を減算します。 
7. 残りの値は交差するペアの数です。 

### なぜ効果があるのか

 個別の非平行無限線の各ペアは、正確に 1 回交差します。 したがって、数えるべきではない唯一のペアは平行線です。 最初に同一の幾何学的な線を折りたたむことで、各ワイヤが一意であることが保証されます。 次に、傾きによってグループ化すると、交差しないケースがすべてきれいに分割され、有効な交差だけが残ります。 

正確さは、傾きの等価性が平面内の平行度の完全な特徴付けであるという事実に依存しています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import gcd
from collections import defaultdict

def norm_line(x1, y1, x2, y2):
    A = y2 - y1
    B = x1 - x2
    C = -(A * x1 + B * y1)

    g = gcd(gcd(abs(A), abs(B)), abs(C))
    if g:
        A //= g
        B //= g
        C //= g

    if A < 0 or (A == 0 and B < 0):
        A, B, C = -A, -B, -C

    return (A, B, C)

def slope_key(x1, y1, x2, y2):
    dx = x2 - x1
    dy = y2 - y1
    g = gcd(abs(dx), abs(dy))
    dx //= g
    dy //= g
    if dx < 0:
        dx, dy = -dx, -dy
    return (dx, dy)

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    lines = set()
    slope_groups = defaultdict(int)

    for i in range(n):
        for j in range(i + 1, n):
            x1, y1 = pts[i]
            x2, y2 = pts[j]

            line = norm_line(x1, y1, x2, y2)
            if line in lines:
                continue
            lines.add(line)

            slope = slope_key(x1, y1, x2, y2)
            slope_groups[slope] += 1

    m = len(lines)
    total_pairs = m * (m - 1) // 2

    parallel_pairs = 0
    for k in slope_groups.values():
        parallel_pairs += k * (k - 1) // 2

    print(total_pairs - parallel_pairs)

if __name__ == "__main__":
    solve()
```この解決策は、各行を正準代数形式で構築します。`Ax + By + C = 0`そして、すべての等価な行が同じタプルに折りたたまれるようにそれを正規化します。 これにより、複数の点のペアが同じ幾何学的線​​上にある場合の重複が防止されます。 

これとは別に、傾き正規化ステップにより、方向ベクトルが一貫した符号を持つ整数ペアに減らされ、すべての平行線をグループ化することができます。 平行線は決して交差しないため、このグループ化は不可欠であり、最終的なカウントから除外する必要があります。 

最後の算術ステップは純粋に組み合わせです。異なるラインのすべてのペアから開始し、同じ傾きを共有するペアを減算します。

## テストケース```python
import sys, io

def solve():
    import sys
    input = sys.stdin.readline
    from math import gcd
    from collections import defaultdict

    def norm_line(x1, y1, x2, y2):
        A = y2 - y1
        B = x1 - x2
        C = -(A * x1 + B * y1)
        g = gcd(gcd(abs(A), abs(B)), abs(C))
        if g:
            A //= g
            B //= g
            C //= g
        if A < 0 or (A == 0 and B < 0):
            A, B, C = -A, -B, -C
        return (A, B, C)

    def slope_key(x1, y1, x2, y2):
        dx = x2 - x1
        dy = y2 - y1
        g = gcd(abs(dx), abs(dy))
        dx //= g
        dy //= g
        if dx < 0:
            dx, dy = -dx, -dy
        return (dx, dy)

    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    lines = set()
    slope_groups = defaultdict(int)

    for i in range(n):
        for j in range(i + 1, n):
            x1, y1 = pts[i]
            x2, y2 = pts[j]
            line = norm_line(x1, y1, x2, y2)
            if line in lines:
                continue
            lines.add(line)
            slope_groups[slope_key(x1, y1, x2, y2)] += 1

    m = len(lines)
    total = m * (m - 1) // 2
    bad = sum(v * (v - 1) // 2 for v in slope_groups.values())
    print(total - bad)

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    solve()
    sys.stdin = old
    return out.getvalue().strip()

assert run("4\n0 0\n1 1\n0 3\n1 2\n") == "14"
assert run("3\n0 0\n0 2\n0 4\n") == "0"
assert run("2\n0 0\n1 1\n") == "1"
assert run("4\n0 0\n1 0\n2 0\n3 0\n") == "0"
assert run("4\n0 0\n1 2\n2 4\n3 6\n") == "0"

 | --- | --- | --- |
 | 2点 | 1 | 最小の非自明なケース |
 | すべて共線的 | 0 | 重複行の折りたたみ |

 ## 特殊なケース

 完全に共線的な構成は、最も重要なエッジ ケースです。 すべての点のペアは同じ正規化された線を生成するため、線のセットのサイズは 1 になります。 ラインの合計ペアがゼロであるため、アルゴリズムは交差部分を正確に生成しません。 

2 番目の特殊なケースは、複数の互いに素な並列ファミリ、たとえば、いくつかの垂直線といくつかの水平線です。 その状況では、勾配のグループ化により各ファミリーが正しく分離され、減算によりファミリー内のペアのみが削除され、すべてのファミリー間の交差部分が維持されます。
