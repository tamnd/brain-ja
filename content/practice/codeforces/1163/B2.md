 ## 解決策
 ## 問題の理解

 私たちには、時間の経過とともに到着する一連の色が、1 日に 1 つずつ与えられています。 毎日 1 つの色が発生します。 私たちの仕事は、最も長いプレフィックスを見つけて、そのプレフィックスから要素を 1 つだけ削除すると、残りの複数の色のセットが非常に特殊な方法で完全にバランスが取れるようにすることです。つまり、まだ表示されるすべての個別の色が同じ回数表示される必要があります。 

したがって、選択した長さのプレフィックスに対して$x$、正確に 1 日削除できる必要があり、削除後は、残りのすべての周波数が、まだ存在するすべての色にわたって等しくなります。 

出力は、そのようなプレフィックスの最大長です。 

制約$n \le 10^5$すべてのプレフィックスとすべての削除を明示的にチェックすることを即座に除外します。 各プレフィックスの単純なチェックにはコストがかかります$O(n)$、すべてのプレフィックスに対してそれを行うと、$O(n^2)$が遅すぎます。 

主な難しさは、頻度の等しいことをチェックするだけではなく、慎重に選択した 1 つの出現を削除した後の平等性をチェックしていることです。 そのため、この構造は、異なる色の数とその周波数の分布の両方に敏感になります。 

いくつかのエッジ パターンは、素朴な推論が失敗する場所を示しています。 

すべての色がすでに同じ頻度を持っている場合、削除された要素が頻度が低下する色からのものでない限り、要素を削除すると平等は失われますが、他のすべては依然として同じです。 たとえば、次のような完全に均一なプレフィックスでは、$[1,1,2,2,3,3]$、任意の 1 つの要素を削除すると、他の色よりも頻度が 1 低い 1 つの色が生成され、構造をより慎重に位置合わせしない限り均一性が損なわれます。 

もう 1 つの注意が必要なケースは、ちょうど 1 つの色の周波数が 1 だけ異なる場合です。たとえば、$[1,1,1,2,2,2,3]$、単一の 3 を削除すると、すべての頻度が等しくなります。 各周波数を共有する色の数を追跡せずに「最大周波数」のみを追跡する場合、多くの貪欲なチェックはここで失敗します。 

最後に、複数の周波数レベルが存在するが、1 回の削除だけで修正できるプレフィックスでは、周波数自体だけでなく、各周波数レベルに何色の色があるかをカウントする必要があります。 

## アプローチ

 ブルートフォース ソリューションでは、すべてのプレフィックスに対して反復処理が行われます。 各プレフィックスについて、すべての色の周波数を計算し、各インデックスを削除して、残りのすべての周波数が等しくなるかどうかを確認します。 プレフィックスを確認するには、頻度分布を再計算またはスキャンする必要があり、$O(n)$プレフィックスごとに。 これにより、$O(n^2)$が遅すぎる$10^5$。 

重要な洞察は、プレフィックスを最初から再チェックしないようにすることです。 代わりに、頻度カウントを増分的に維持し、現在特定の頻度を持つ色の数という二次構造も維持します。 

どのプレフィックスでも、「残りの周波数がすべて等しくなるように 1 つの要素を削除できる」という条件は、少数の構造構成でのみ発生します。 させて$f$を色の周波数マップとし、$cnt[x]$正確に何色表示されるか$x$回。 

プレフィックスを修正する場合、1 つの出現を削除すると、残りのすべての周波数が何らかの値に等しくなるかどうかを知りたいと考えます。$k$。 つまり、周波数マルチセットはすでにほぼ均一になっており、偏差は 1 回の減分で修正できるはずです。 

これにより、問題は周波数ごとに追跡され、各ステップで一定数の構造パターンをチェックすることになります。 

観察によれば、1 つの要素を削除した後、1 つの色の周波数のみが 1 減少します。 したがって、プレフィックスでは、1 つの周波数を減分した後、ゼロ以外の周波数がすべて 1 つの値に集約されるような方法が存在するかどうかをテストするだけで済みます。 これにより、次のような条件がチェックされます。 

周波数 1 の 1 つの追加要素を除いてすべての周波数がすでに等しいか、すべての周波数が正確に 1 レベルだけ異なり、より高いレベルに正確に 1 つの色があるか、または 1 つの色が他のすべての色と比較して正確に 1 だけ過剰に出現しています。 

こちらはチェックイン可能です$O(1)$頻度カウントのハッシュ マップを使用してプレフィックスごとに。

 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^2)$|$O(n)$| 遅すぎる |
 | 最適 (周波数 + 周波数対周波数マップ) |$O(n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 私たちは 2 つのマップを維持しています。`freq[color]`各色の頻度については、`count[f]`現在何色の周波数があるかについて`f`。 

配列を反復処理してこれらの構造を段階的に更新し、各位置でそこで終わるプレフィックスが有効かどうかをテストします。 

1. 空の周波数マップと周波数対周波数マップを初期化します。 目標は、プレフィックスの動的な概要を維持することです。 
2. 入ってくる色ごとに、その古い周波数を更新します。`count`、古い周波数のカウントをデクリメントしてから、新しい周波数をインクリメントします。 
3. 更新後、現在のプレフィックスの構造を分析して、現在のプレフィックスが有効かどうかを確認します。`count`。 
4. 有効性チェックは、少数のケースに基づいて行われます。 

最初のケースは、すべての色の頻度が 1 である場合で、すべての色が 1 回だけ出現することを意味します。 

2 番目のケースは、周波数値が 1 つだけ存在する場合です。 

3 番目のケースは、ちょうど 2 つの周波数値がある場合です。$f$そして$g$、それらは 1 だけ異なり、高い周波数が 1 回出現するため、1 つの出現を削除して周波数を平坦化できます。 
5. いずれかのプレフィックスが有効な場合は、その長さを使用して回答を更新します。 

### なぜ効果があるのか

 この正しさは、1 つの要素の削除が 1 つの色周波数にのみ影響し、その変更は厳密に局所的であるという事実から来ています。つまり、正確に 1 つの周波数バケットを 1 単位だけ削減します。 したがって、後で均一な状態に到達する唯一の方法は、現在の周波数分布が周波数マルチセットの空間内ですでに均一性から「一歩離れている」場合です。 の`count`map はこの構造を完全にキャプチャしているため、追加の順序情報は必要ありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def valid(count, total):
    # number of distinct frequency values
    keys = list(count.keys())
    if len(keys) == 1:
        f = keys[0]
        # all same frequency
        return True

    if len(keys) == 2:
        f1, f2 = keys
        c1, c2 = count[f1], count[f2]

        # ensure f1 < f2
        if f1 > f2:
            f1, f2 = f2, f1
            c1, c2 = c2, c1

        # case 1: freq 1 occurs once
        if f1 == 1 and c1 == 1:
            return True

        # case 2: higher freq is exactly one extra and occurs once
        if f2 == f1 + 1 and c2 == 1:
            return True

    return False

def solve():
    n = int(input())
    arr = list(map(int, input().split()))

    freq = {}
    count = {}
    ans = 0

    for i, x in enumerate(arr):
        old = freq.get(x, 0)
        if old > 0:
            count[old] -= 1
            if count[old] == 0:
                del count[old]

        new = old + 1
        freq[x] = new
        count[new] = count.get(new, 0) + 1

        if valid(count, i + 1):
            ans = i + 1

    print(ans)

if __name__ == "__main__":
    solve()
```の`freq`辞書は、各色が何回出現したかを追跡します。 の`count`辞書は、各周波数を共有する色が何色あるかを追跡します。 妥当性関数は、1 つの出現を削除することで修正できる 2 つの構造構成のみをエンコードします。 

実装の微妙な詳細は、常に更新されることです。`count`周波数を変える前と変えた後。 古い周波数バケットの削除を怠ると、有効性チェックに誤って合格するファントム周波数が発生します。

 ## 特殊なケース

 次のような最小限の入力`[1]`唯一の要素を削除すると空の均一な状態が残るため、これは自明に有効です。 アルゴリズムはこれを処理します。`count`エントリが 1 つだけある`{1:1}`。 

次のような完全に異なる配列`[1,2,3,4,5]`維持する`count = {1:5}`すべてのステップで、常に単一周波数条件を満たします。 

のような偏ったケース`[1,1,1,1,2]`周波数マップを生成します`{4,1}`そしてカウントマップ`{4:1,1:1}`。 有効性チェックは「単一の余分な出現」パターンを検出し、唯一のプレフィックスを削除した後にプレフィックスが有効であることを正しく許可します。`2`。
