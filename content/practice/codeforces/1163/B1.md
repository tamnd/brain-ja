 ## 解決策
 ## 問題の理解

 シロは毎日猫を迎えます。それぞれの猫は特定の色のリボンを付けています。 色は 1 から 10 までの整数です。彼女は、1 日目から開始して連続する最も長い日のシーケンスを見つけたいと考えています。このシーケンスからちょうど 1 日を削除すると、残りのリボンの色はすべて同じ回数表示されます。 私たちの仕事は、この最長シーケンスの長さを決定することです。 

入力は日数です`n`まで`10^5`、続いて各猫の色。 出力は単一の整数、つまり条件を満たす最大のプレフィックスの長さです。 なぜなら`n`が大きくなる可能性があるため、二次複雑度の解は遅すぎます。 線形時間に近いアプローチ (理想的には O(n)) が必要ですが、個別の色の数が少ないため、おそらく頻度テーブルを使用します。 

エッジ ケースは、シーケンスがすでに均一である場合、外れ値が 1 つある場合、またはすべての色が 1 回だけ出現する場合に発生します。 たとえば、入力`[1, 1, 2]`返すべきです`3`削除するので`2`葉`[1, 1]`、均一です。 考えられるすべてのプレフィックスとすべての削除をチェックする単純なアプローチでは、時間がかかりすぎます。 

## アプローチ

 ブルートフォース手法では、同じ長さのすべてのプレフィックスに対して反復処理が行われます。`x`1から`n`、各プレフィックスについて、毎日削除を試みて、残りのカウントが均一かどうかを確認します。 これはすべての可能性をチェックするので正しいですが、最悪の場合は O(n^2) になります。つまり、約`10^10`のための操作`n = 10^5`そして明らかに実行不可能です。 

重要な観察は、リボンの色の数は最大 10 であるため、頻度数を維持し、各頻度を持つ色の数を追跡できることです。 新しい日を追加すると、これらのカウントが更新され、現在のプレフィックスがいくつかのパターンのいずれかを満たしているかどうかが確認されます。 

1. すべての色は同じ周波数を持っています。 
2. 1 つを除くすべての色は同じ頻度を持ち、外れ値は 1 回だけ発生します。 
3. 1つを除くすべての色には周波数があります`f`、外れ値には周波数があります`f+1`。 

これらのパターンは、1 日を削除すると均一な頻度シーケンスが生成されるすべてのケースをカバーします。 2 つの辞書 (各色の数と各色の数の辞書) を維持することで、毎日の後に一定時間で状態をチェックできます。 これにより、複雑さが O(n) に軽減されますが、これは許容範囲内です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 周波数追跡 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 辞書を初期化する`count`各色が何回出現したかを追跡し、別の辞書を作成する`freq_count`特定の周波数を持つ色の数を追跡します。 
2. 変数を初期化する`max_streak`ゼロに。 
3. 毎日繰り返す`i`0から`n-1`。 させて`color`その日の猫の色になろう`i`。 
4. もし`color`以前に出現した、減少`freq_count`前回のカウントについては。 
5. インクリメント`count[color]`新しい日を迎えるために。 
6. インクリメント`freq_count`新しいカウントのために`color`。 
7. 現在のプレフィックスが次の 3 つの条件のいずれかを満たしているかどうかを確認します。 

- 1 つの色のみが存在します (すべての周波数が等しい)。 
- 一度出現する 1 つの色を除いて、すべての周波数は 1 です。 
- すべての周波数が等しい`f`発生する1つの色を除いて`f+1`。 
8. いずれかの条件が満たされた場合、更新します`max_streak`に`i + 1`。 
9. ループ後、出力`max_streak`。 

機能する理由: すべてのステップで、正確な色の数と色数を維持します。 これにより、1 つの要素を削除することで均一な周波数を生成できるかどうかを検出できます。 毎日 1 回処理し、小さな辞書 (最大 10 キー) のみを更新するため、不変式は常に正しく、有効な連続値を見逃すことはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
colors = list(map(int, input().split()))

count = {}
freq_count = {}
max_streak = 0

for i, color in enumerate(colors):
    prev = count.get(color, 0)
    if prev > 0:
        freq_count[prev] -= 1
        if freq_count[prev] == 0:
            del freq_count[prev]
    count[color] = prev + 1
    freq_count[prev + 1] = freq_count.get(prev + 1, 0) + 1
    
    if len(freq_count) == 1:
        key = next(iter(freq_count))
        if key == 1 or freq_count[key] == 1:
            max_streak = i + 1
    elif len(freq_count) == 2:
        keys = list(freq_count.keys())
        f1, f2 = keys[0], keys[1]
        c1, c2 = freq_count[f1], freq_count[f2]
        if (f1 == 1 and c1 == 1) or (f2 == 1 and c2 == 1):
            max_streak = i + 1
        elif (abs(f1 - f2) == 1):
            if (f1 > f2 and c1 == 1) or (f2 > f1 and c2 == 1):
                max_streak = i + 1

print(max_streak)
```このコードは 2 つの辞書を初期化してカウントを維持し、毎日それらを更新します。 色が初めて発生するケースを処理し、カウントを増加させ、古い周波数を慎重に減少させます。 ループ内の条件は、均一性を生み出すために 1 日を削除できる 3 つのパターンをチェックします。 この解決策は線形であり、更新することでオフバイワンエラーを回避します。`max_streak`と`i + 1`。
