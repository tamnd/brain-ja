 ## 解決策
 ## 問題の理解

 動的な座席シナリオをシミュレートするように求められます。 ホールがあります`n`行と`m`コラムを書くと、真面目な生徒やいたずらな生徒が次々と到着します。 最初の生徒は常に最初の行の最初の列に座り、新しく到着するたびに既存の生徒を行優先の順序で押し上げます。つまり、行内で生徒は右に移動し、行の最後の席が次の行の最初の席に回り込みます。 各生徒が座った後、少なくとも 1 人の真剣な生徒が含まれる行と列の数を数えるように求められます。 各テスト ケースの出力は、すべての学生が入力した後の累積カウントのリストです。 

制約については慎重に検討する必要があります。 テスト ケースごとのシート数は最大で`10^6`、すべてのテスト ケースの合計が次を超えません。`10^6`。 これにより、学生の 2D グリッド全体を維持し、到着ごとにエントリをシフトする単純なシミュレーションが除外されます。これは、最悪の場合の時間が 2 次となり、遅すぎるためです。 生徒ごとに一定時間でカウントを更新するアプローチが必要です。 エッジ ケースには、生徒全員が真面目である、または生徒全員がいたずらである、または行列に単一の行または列がある場合のシナリオが含まれます。これは、行と列の更新がどのように伝播するかに影響するためです。 

## アプローチ

 強引なアプローチは、座席を表す 2D マトリックスを維持し、学生が到着するたびにすべての行を右にシフトし、最後の列を次の行に折り返すことです。 挿入するたびに、すべての行と列をスキャンして、少なくとも 1 人の真面目な学生が含まれる行と列を数えます。 これにより正しい答えが得られますが、最悪の場合、各挿入のコストは O(n * m) となり、最大サイズの 1 つのテスト ケースでは O((n * m)^2) となり、制限時間を大幅に超えます。 

重要な洞察は、2D グリッドを分離し、行または列が「良好」であるかどうかという、必要な最小限の情報のみを追跡することです。 各生徒は 1 つの座席にのみ影響し、生徒が真剣であれば良い行と列を決定します。 したがって、2 つの配列を維持できます。1 つは正常な行の累積数で、もう 1 つは正常な列です。 行優先の順序でラップアラウンド効果を処理するには、次のようにして各生徒の列インデックスを事前計算します。`student_index % m`そして行インデックスは`student_index // m`。 列の場合、現在の学生だけでなく、同じ列内の以前のすべての学生も考慮する必要があります。 列ごとに真面目な学生のプレフィックスの合計を維持できます。 各新入生は行または列のカウントを 1 回だけインクリメントできるため、定数時間の更新が可能となり、全体で O(n * m) アルゴリズムになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((n * m)^2) | O(n * m) | 遅すぎる |
 | 最適 | O(n * m) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. サイズの 2 つの配列を初期化します。`m`:`col_count`各列に何人の真面目な学生が配置されたかを追跡するため、`col_good`列が良好かどうかを示すバイナリ配列として。 セットまたは配列を初期化する`row_good`サイズの`n`各行に真面目な学生が含まれているかどうかを追跡します。 初期化する`good_rows`そして`good_cols`ゼロにカウンターします。 
2. 生徒一人ひとりに対して`i`文字列の中で`s`、行インデックスを計算します`r = i // m`そして列インデックス`c = i % m`。 これらのインデックスによって、どの行と列が影響を受けるかが決まります。 
3. 生徒が真剣であれば (`s[i] == '1'`) と行`r`まだ良好とマークされていません。増分します`good_rows`そしてマークを付ける`row_good[r]`本当のように。 同様に、if 列`c`まだ良くありません、増分します`good_cols`そしてマークを付ける`col_good[c]`本当のように。 アップデート`col_count[c]`そのコラムに真剣な新入生を反映させるためです。 
4.追加`good_rows + good_cols`出力配列に。 これは、現在の学生以降の良好な行と列の合計数を表します。 
5. すべての生徒を処理した後、出力配列を 1 行として出力します。 

機能する理由: 各生徒は、自分が座っている行と列にのみ影響します。 どの行と列がすでに良好であるかを追跡することで、二重カウントを回避し、次の不変条件を維持します。`good_rows`そして`good_cols`各ステップで少なくとも 1 人の真剣な生徒を含む行と列の数を正確に反映します。 列インデックスがモジュロを繰り返すため、ラップアラウンド動作は暗黙的に処理されます。`m`行インデックスは順番に増加します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        s = input().strip()
        row_good = [0] * n
        col_good = [0] * m
        good_rows = 0
        good_cols = 0
        col_count = [0] * m
        prefix = [0] * (n * m)
        out = []
        for i in range(n * m):
            r = i // m
            c = i % m
            if s[i] == '1':
                col_count[c] += 1
                if row_good[r] == 0:
                    row_good[r] = 1
                    good_rows += 1
                if col_good[c] == 0:
                    col_good[c] = 1
                    good_cols += 1
            out.append(good_rows + good_cols)
        print(' '.join(map(str, out)))

solve()
```このソリューションは、行と列の良さを示す配列を維持し、生徒ごとに一定時間でカウンターを更新します。 の`col_count`配列は、列ごとに複数の真面目な学生を追跡する必要がある場合に潜在的な拡張をサポートするように準備されていますが、この問題では存在のみが問題となります。 整数の除算とモジュロを使用して行と列のインデックスを計算し、フラット化された配列の 2D レイアウトを処理します。

 ## 特殊なケース

 各列の最初の生徒は真面目だが、他の生徒はやんちゃな場合、トリッキーなエッジケースが発生します。 アルゴリズムは正しくインクリメントします`good_cols`列が真剣な学生を受け取り、同様に行を追跡するのは初めてです。 もう 1 つのケースは、単一の行または単一の列で、すべての生徒が同じ行または列に分類されます。 最初の真剣な生徒の行または列には良好のマークが付けられ、後続の生徒は再度カウントを増やさないため、二重にカウントされることはありません。 モジュロおよび整数の除算演算は、このようなエッジ ケースでも、平坦化された 1D から 2D へのマッピングを自然に処理します。
