 ## 解決策
 ## 問題の理解

 平面内の一連の点が与えられ、連続する点間の変位ベクトルを調べます。 このようなベクトルはそれぞれ、私たちがどのようにある点から次の点に移動するかを捉えています。 

タスクは、すべての変位ベクトルがこの新しいシステムで表現されるとき、すべての変位ベクトルがこの座標系の「右上」方向に位置するように、2 つの直交する方向によって形成される新しい座標系 (Ox と Oy と呼ぶ) を選択することです。 具体的には、すべてのベクトルは新しい基底で負でない x 座標を持たなければなりません。また、その x 座標がゼロの場合、その y 座標は厳密に正でなければなりません。 

幾何学的に言えば、これは、すべてのベクトルが Ox で区切られた単一の閉じた半平面内に収まり、負の x 側に落ちないように軸を回転および方向付けしようとしていることを意味します。 境界線に正確に到達するベクトルは、後方または平坦ではなく、常に正の Oy 方向を向いている必要があります。 

各ベクトルは、方向的には単位円上の点として扱うことができます。 この条件は基本的に、すべてのベクトルが Ox と最大 90 度の角度を形成し、正確に直交するベクトルが Oy に投影されたときに符号内で一貫して動作するような方向 Ox が存在するかどうかを尋ねます。 

複雑さの観点から見ると、最大 100,000 個の点、つまり最大 100,000 個の方向ベクトルが存在する可能性があります。 ベクトルのすべてのペアを比較したり、すべての候補座標系をテストしようとするソリューションは、二次関数であり、非常に遅すぎます。 構造は、徹底的なチェックではなく、グローバルな幾何学的プロパティから抽出する必要があります。 

ベクトルが半円以上に広がっている場合、微妙な失敗のケースが発生します。 たとえば、大まかに右、左、下を同時に指す方向がある場合、軸を回転してもすべてを単一の閉じた半平面に配置することはできないため、検証せずに実現可能性を仮定するアルゴリズムは誤った基底を出力します。 

もう 1 つの注意が必要な状況は、ベクトルがほぼ同一線上にあるものの、一方のベクトルが境界のわずかに反対側にある場合に発生します。 単純な「極端な方向を選択する」戦略では、整合性チェックが強制されない場合、無効な境界ベクトルが選択され、無効な座標系が構築される可能性があります。 

## アプローチ

 強引な解釈では、可能なすべての方向を Ox 軸の候補として試すことになります。 各候補について、座標系を回転し、投影後にすべてのベクトルが必要な符号条件を満たしているかどうかを確認します。 候補の方向を入力ベクトルのみに離散化した場合でも、O(n) 個のベクトルに対して O(n) 個の候補のそれぞれをチェックすることになり、結果として O(n²) 回の演算が必要となり、100,000 個のベクトルには遅すぎます。 

重要な点は、実際には全方向をテストする必要はないということです。 有効な軸が存在する場合、すべてのベクトルは半円内に収まる必要があります。 これにより、問題は「制約を満たす方向を見つける」から「すべてのベクトルを囲む最小の半円の境界方向を見つける」に軽減されます。 

すべてのベクトルが半平面内にあることを受け入れると、このセットの境界上に自然な極値ベクトルが存在します。 そのベクトルは、方向に応じて最も時計回りまたは反時計回りの方向を選択するように動作する相互積比較を伴う線形スキャンを使用して見つけることができます。 これにより、境界方向の標準的な候補が得られます。 

このような境界ベクトル Dm が見つかったら、Oy をそれに合わせて整列させるのが安全です。 その理由は、すべてのベクトルが半円内にある場合、1 つの極端な方向が境界として機能し、それに沿って Oy を配置すると、それに直交する Ox を選択した後、他のすべてのベクトルが Ox に非負に投影されることが保証されるからです。 

問題の残りの部分は、この構築された基底がすべてのベクトルの制約を満たすことを検証することに帰着します。

 ## アルゴリズムのチュートリアル

 変位ベクトル Di を直接操作します。 

1. 最初のベクトルを暫定候補 Dm として選択することから始めます。 これは、真の極値ベクトルに改良する予定の暫定的な境界方向を表します。 
2. すべてのベクトルをスキャンし、角度順序でより極端なベクトルが見つかるたびに Dm を更新します。 これは、外積条件 (Dm × Di) > 0 を使用してテストされます。これは、Di が角度の順序で Dm の左側にあることを意味するため、新しい境界候補になります。 これにより、スキャン後、Dm がセットの一貫した極値方向であることが保証されます。 
3. Dm を Oy 軸方向を定義するものとして扱います。 すべてのベクトルが半円に収まる場合、そのセットの極値ベクトルはその半円の境界上にあるため、この選択は安全です。 
4. Dm に対する垂直ベクトルとして Ox を構築します。 Dm = (a, b) の場合、Ox = (b, -a) となります。 ドット積がゼロであるため、これにより直交性が保証されます。 
5. (Dm × Ox) < 0 になるように Ox の符号を固定することで方向の一貫性を確保します。これにより、一貫した時計回りの方向が選択され、境界のどちら側が正の x とみなされるかが曖昧になります。 
6. すべてのベクトル Di が (Di · Ox) ≥ 0 を満たすことを確認します。等しい場合は、(Di · Dm) > 0 であることを確認し、境界ベクトルが後方や平坦ではなく、厳密に正の Oy 方向を指すようにします。 
7. いずれかのベクトルがこれらの条件に違反する場合、有効な座標系は存在しません。 

正当性は、有効な根拠が存在する場合、すべてのベクトルが半円内にあるという事実に依存します。 このアルゴリズムは、その半円の 1 つの端点を Dm として再構築し、それに合わせて直交する軸系を構築します。 すべてのベクトルは、Ox に垂直な線の同じ側になければなりません。 そうしないと、元の半円の仮定に違反します。 外積スキャンにより、Dm が極端な境界方向であることが保証されるため、有効な構成が失われることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    # build difference vectors
    d = []
    for i in range(n - 1):
        x1, y1 = pts[i]
        x2, y2 = pts[i + 1]
        d.append((x2 - x1, y2 - y1))

    # pick extreme vector using cross product ordering
    dx, dy = d[0]
    for x, y in d[1:]:
        if dx * y - dy * x > 0:
            dx, dy = x, y

    # Oy = Dm, Ox = perpendicular
    ox_x, ox_y = dy, -dx
    oy_x, oy_y = dx, dy

    # check validity
    for x, y in d:
        dot = x * ox_x + y * ox_y
        if dot < 0:
            print("No solution")
            return
        if dot == 0:
            if x * oy_x + y * oy_y <= 0:
                print("No solution")
                return

    print("Yes")

if __name__ == "__main__":
    solve()
```問題は連続する点間の方向についての推論に帰着するため、この実装では最初に差分ベクトルが構築されます。 極値ベクトルの選択では、外積を使用した線形スキャンが使用されます。これは、角度順序で境界方向を維持する標準的な方法です。 

垂直ベクトルは、座標を交換し、1 つの成分を否定することによって構築され、直交性を確保します。 最後の検証ステップでは、両方の制約 (Ox 上の非負の投影と、境界上にあるときの Oy に沿った厳密な正の投影) を直接チェックします。 

等しい場合には注意が必要です。 境界線 (内積ゼロ) 上に正確に存在するベクトルは、Oy に沿って正の射影を持たなければなりません。そうでないと、必要な厳密な順序付けと矛盾します。 

## 実用的な例

 主に増加する動きを形成する点の単純な構成を考えてみましょう。 

入力ポイント:

 (0,0)、(1,0)、(2,1)

 ベクトルを取得します。 

(1,0)、(1,1)

 極端な選択を追跡します。 

| ステップ | 現在のDM | 次のベクトル | 外積 | 更新 |
 | --- | --- | --- | --- | --- |
 | 1 | (1,0) | (1,1) | 1 | はい |
 | 2 | (1,1) | 終わり | - | - |

 最終的な Dm = (1,1) であるため、Oy は (1,1)、Ox は (1,-1) になります。 

投影をチェックすると、両方のベクトルが正しい側にあることが確認されます。 

ここで、ベクトルがすでに整列している場合を考えてみましょう。 

入力:

 (0,0)、(2,0)、(4,0)

 ベクトル:

 (2,0)、(2,0)

 | ステップ | 現在のDM | 次のベクトル | 外積 | 更新 |
 | --- | --- | --- | --- | --- |
 | 1 | (2,0) | (2,0) | 0 | いいえ |
 | 2 | (2,0) | 終わり | - | - |

 ここで、Ox は (0,-2) になり、両方のベクトルが境界方向に正確に位置します。 2 番目の条件は、Oy に沿った厳密な肯定性を強制します。これは、両方のベクトルが同一で前方を向いているため当てはまります。

 ## 特殊なケース

 重要なケースは、ベクトルが半円を超える場合です。 たとえば、1 つのベクトルが右を指し、別のベクトルが左上を指し、もう 1 つが左下を指す場合、Ox を選択すると、少なくとも 1 つのベクトルが負の半平面に配置されます。 単一の極値 Dm は検証中にすべてのベクトルに対して非負の内積を生成できないため、アルゴリズムはこれを間接的に検出します。 

もう 1 つのエッジ ケースは、複数のベクトルが選択した境界ベクトルと正確に同一線上にある場合です。 その場合、いくつかのベクトルの内積はゼロになり、正確さは Oy への射影を使用した二次チェックに完全に依存します。 このアルゴリズムは、境界条件が満たされた場合に Oy に沿った厳密な正の値を明示的に要求することでこれを処理し、後向きの共線ベクトルの縮退的な受け入れを防ぎます。
