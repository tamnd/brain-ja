 ## 解決策
 ## 問題の理解

 特定の整数の配列のすべての部分配列にわたる「美しさ」の累積的な尺度を計算するように求められます。 部分配列の美しさは、範囲の長さから 1 を引いた値に等しい秒数で要素の連続範囲を並べ替える操作を使用して部分配列を並べ替えるのに必要な最小合計時間として定義されます。 具体的には、部分配列がすでにソートされている場合、その美しさはゼロです。 2 つの要素が逆の順序にある​​場合、可能な操作は 1 秒以内にそれらを並べ替えるだけなので、その美しさは 1 つです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは、配列と配列自体の長さを提供します。 すべてのテスト ケースの長さの合計は 5000 で制限されます。これは十分に小さい制限であるため、O(n²) アルゴリズムでも 1 秒未満で実行される可能性がありますが、O(n³) のものは遅すぎます。 すべての要素は個別であるため、重複を処理する必要がなく、範囲ソートのロジックが簡素化されます。 

長さ 1 のサブ配列では、重要なエッジ ケースが発生します。 単一の要素は自明にソートされるため、その美しさはゼロです。 長さ 2 の部分配列の場合、要素が昇順の場合は美しさは 0、要素が逆の場合は 1 になります。 完全な並べ替えをシミュレートしようとしたり、すべての範囲が均等に寄与すると仮定したりする不用意なアプローチは、これらの単純なケースでは誤った結果を生成します。 

## アプローチ

 ブルートフォースアプローチは簡単です。 サブ配列ごとに、可能な範囲の並べ替えをすべて試して、その美しさを計算することができます。 長さ k の部分配列の場合、可能な範囲演算は O(k²) 個あり、O(k) 個の部分配列では、最悪の場合、合計の複雑さは O(n⁴) になります。 これは、n = 5000 の場合でも明らかに非現実的です。 

重要な観察は、サブ配列の美しさはその最小要素と最大要素の位置によって決まるということです。 各操作は連続するサブ配列をソートできるため、ソートにかかる最小時間は、正確にサブ配列の長さから、増加する最長の連続シーケンスの長さを引いたものになります。 言い換えれば、美しさは、マージする必要がある「順序が乱れた」隣接するペアの数に対応します。 この小さなバージョンでは、より単純な貪欲なアプローチを使用できます。つまり、最大の要素から開始して最小の要素に向かって範囲をマージし、これまでに確認されたすべての数値を含む最大インデックス範囲を追跡します。 現在の範囲の長さがその範囲内の個別の数値の数と一致する場合、その部分配列は最小限の時間で完全にソート可能であると見なされます。 

話は自然につながります。総当たり法はすべての可能性を試すため機能しますが、サブ配列と演算の数が急速に増加するために失敗します。 美しさは要素の正確な順序ではなく、要素の範囲のみに依存することを観察すると、サブ配列の開始位置を反復処理し、最小値と最大値を追跡しながら終了位置を拡張することで、O(n²) で計算することができます。 これにより、完全なシミュレーションの組み合わせ爆発が回避されます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n⁴) | お(1) | 遅すぎる |
 | 貪欲なスパンベース | O(n²) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`total_beauty`ゼロに。 これにより、すべてのサブ配列の合計が累積されます。 
2. 可能なすべての開始インデックスを反復処理します。`i`0 から n-1 までの部分配列。 各反復では、次から始まるサブ配列が考慮されます。`i`。 
3. 開始インデックスごとに`i`、2つの変数を初期化します`min_val`そして`max_val`値と一緒に`a[i]`。 これらは、現在の部分配列内の最小要素と最大要素を追跡します。 
4. 終了インデックスを反復してサブ配列を拡張します。`j`から`i`n-1へ。 新しい要素ごとに`a[j]`、 アップデート`min_val`そして`max_val`それを含めること。 
5. 現在の部分配列の長さを次のように計算します。`length = j - i + 1`。 スパンを次のように計算します。`span = max_val - min_val + 1`。 
6. もし`span`等しい`length`、部分配列には連続した個別の整数が含まれており、その美しさは次のとおりです。`length - 1`。 それ以外の場合は、前の美しさと同じです (部分配列の長さが 1 の場合は 0)。 この部分配列の美しさを`total_beauty`。 
7. から始まるすべてのサブ配列を処理した後、`i`、次の開始インデックスに進みます。 
8. すべての部分配列が考慮された後、出力します。`total_beauty`。 

なぜ機能するのか: 不変条件は、`i`に`j`、`min_val`そして`max_val`最小要素と最大要素を正確に追跡します。 スパン チェックは、数値が連続している場合にのみ、単一の範囲操作でサブ配列をソートできることを保証します。 要素は個別であるため、これは各サブ配列の最小ソート時間を完全に特徴づけます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total_beauty = 0
        
        for i in range(n):
            min_val = a[i]
            max_val = a[i]
            for j in range(i, n):
                min_val = min(min_val, a[j])
                max_val = max(max_val, a[j])
                length = j - i + 1
                span = max_val - min_val + 1
                if span == length:
                    total_beauty += length - 1
        print(total_beauty)

if __name__ == "__main__":
    solve()
```外側のループはサブ配列の先頭を選択し、内側のループはサブ配列を右に拡張します。 更新中`min_val`そして`max_val`段階的に、毎回最初から再計算することを避けます。 ビューティー計算は、現在のサブ配列が連続する整数シーケンスを形成する場合にのみトリガーされ、ソートに必要な最小限の時間を確実にカウントします。
