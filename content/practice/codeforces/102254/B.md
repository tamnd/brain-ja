 ## 解決策
 ## 問題の理解

 文字列で表される 2 つの川岸があります`a`そして`b`。 位置`i`最初のバンクは、によって指名された分隊のために予約されています。`a[i]`、および位置`j`2 番目のバンクは、によって指名された分隊のために予約されています。`b[j]`。 ブリッジでポジションを接続できる`i`そして`j`2 つの文字が等しい場合のみ。 

橋は渡ってはいけません。 一つの橋が繋がれば`(i1, j1)`そしてもう一つが繋がる`(i2, j2)`次に、第 1 バンクのポジションを注文した後、次のようになります。`i1 < i2`、また、`j1 < j2`。 逆の順序の 2 つの橋が幾何学的に交差します。 タスクは、この順序を維持しながら、選択できる同じ文字のペアの数を最大化することです。 元の制約では、両方の文字列の長さが最大 1000 であることが許可されています。 

この順序付け条件が問題全体の鍵となります。 選択された位置のシーケンス`a`および対応するシーケンス`b`は 2 つのサブシーケンスを形成し、選択されたすべてのペアは同じ文字を持ちます。 言い換えれば、ブリッジは 2 つの弦の共通のサブシーケンスを形成します。 したがって、答えは最長共通部分列 (LCS) の長さになります。 

1000 という制限は、サブセットを列挙したり、可能なブリッジのコレクションをすべて試行したりするアルゴリズムを除外するには十分な大きさですが、二次動的プログラムには十分小さいです。 アン`O(nm)`アルゴリズムは、両方の文字列の長さが 1000 の場合に最大 100 万回の状態遷移を実行します。これは、指定された制限内では快適です。 次のような指数アルゴリズム`O(2^n)`にはすでに不可能です`n = 1000`。 

直感的な実装がうまくいかないケースがいくつかあります。 たとえば、文字列にまったく異なる文字が含まれている場合、`a = "a"`そして`b = "b"`、答えは`0`。 実際の位置を考慮せずに一般的な文字をカウントする不用意な実装でも、一致が報告される可能性があります。 

繰り返される文字にも注意が必要です。 のために`a = "aa"`そして`b = "aa"`、答えは`2`両方のペアを交差せずに接続できるためです。 等しい文字を 1 つだけ使用できるかのように扱うと、誤って返される`1`。 

両方の文字列に多くの文字が含まれる場合でも、順序は重要です。 のために`a = "abca"`そして`b = "acba"`、答えは`3`、共通部分列を使用して`"aca"`。 最初のものと一致する貪欲なアルゴリズム`a`、その後すぐに最初に利用可能なものを取得します`b`、のみを取得します`2`そしてより良い選択を見逃してしまいます。 

## アプローチ

 最も直接的な総当たりアプローチは、ポジションのすべてのサブセットを考慮することです。`a`。 各サブセットは、次の 1 つのサブシーケンスを定義します。`a`、そのサブシーケンスが次の場所で発生するかどうかを確認できます。`b`秩序を保ちながら。 すべての共通サブシーケンスの中で、最大のものを保持します。 これは正しいです。なぜなら、非交差橋のすべての合法的なセットは 1 つの共通のサブシーケンスに正確に対応するからです。 

がある`2^n`のサブセット`n`-文字列。 1 つのサブシーケンスをチェックする場合`b`かかります`O(m)`最悪の場合の作業は`O(m * 2^n)`。 と`n = m = 1000`、それまでです`1000 * 2^1000`キャラクターレベルの操作は限界をはるかに超えています。 

ブルートフォースアプローチは、法的に順序付けられたすべての選択を明示的に調査するため機能します。 選択可能な数が膨大になると失敗します。 より高速な解決策を明らかにする観察は、多くの異なる部分選択がまったく同じ将来の可能性を持っているということです。 2 つの文字列のプレフィックスを使用して形成できるブリッジの数がわかれば、その値を生成した正確なブリッジを覚える必要はありません。 

定義する`dp[i][j]`最初の橋のみを使用して建設できる非交差橋の最大数として`i`の位置`a`そして最初の`j`の位置`b`。 これらのプレフィックスの最後の位置を考慮してください。 

もし`a[i - 1] == b[j - 1]`、これら 2 つの位置を接続すると、次のようになります。`dp[i - 1][j - 1] + 1`。 これらのポジションのいずれかを使用しないことを選択することもできます。`dp[i - 1][j]`または`dp[i][j - 1]`。 したがって、`dp[i][j] = max(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1] + 1)`文字が一致したとき。 

それらが異なる場合、最後の 2 つの位置を直接接続することはできないため、そのうちの 1 つを除外する必要があります。`dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])`。 

これは標準的な LCS の繰り返しですが、ここではその幾何学的な意味が特に役立ちます。一致する文字を選択すると新しい橋が作成されますが、より小さいプレフィックスに移動すると、川岸の 1 つの位置が未使用のままになることになります。 

すべての状態は前の行と現在の行にのみ依存するため、メモリを削減できます。`O(nm)`に`O(m)`。

 ## アルゴリズムのチュートリアル

 1. 2 つの文字列を読み取り、その長さを次のようにします。`n`そして`m`。 各文字列の位置は、対応する川岸に沿った順序をすでに示しています。 
2.長さの DP 行を作成します`m + 1`、最初はゼロで埋められます。`dp[j]`これまでに処理された最初の文字列の部分に対する最良の答えを表し、最初の`j`2番目の文字列の位置。 
3. の文字を加工する`a`左から右へ。 新しい文字ごとに、最初の値がゼロである新しい行を作成します。`b`橋を含めることはできません。 
4. ポジションごとに`j`で`b`、現在の文字を比較します`a[i - 1]`と`b[j - 1]`。 それらが等しい場合、これら 2 つの位置を接続することは正当であり、前の 2 つのプレフィックスの最適なソリューションにブリッジを追加できます。 候補値は`dp[j - 1] + 1`。 
5. 文字が一致するかどうかに関係なく、どちらかのバンクから現在位置をスキップすることも考慮します。 これらの選択により、前の行の値が得られます`dp[j]`および現在の行の左の値`new_dp[j - 1]`。 
6. これらの候補の最大値を`new_dp[j]`、現在の位置を終了した後、古い行を新しい行に置き換えます。`a`。 
7. すべての文字が処理された後の最後の DP 値は、構築できる非交差ブリッジの最大数になります。 戻る`dp[m]`。 

### なぜ効果があるのか

 不変条件は、最初の処理後の`i`の登場人物`a`、`dp[j]`は、これらを使用する非交差橋の最大数です。`i`登場人物と最初の`j`の登場人物`b`。 すべての法的解決策は、最後の 2 つのポジションのうち 1 つを未使用のままにするか、書簡が合意した場合にそれらを最後のブリッジとして使用します。 再帰化では 3 つの可能性すべてが考慮されるため、最適な解決策を破棄することはできません。 すべての遷移では両方のバンクで増加するポジションが維持されるため、DP によって構築されるすべての値は合法的な非交差ブリッジ セットに対応します。 最終的に、2 つの完全な文字列の状態は、まさに望ましい最大値になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a, b = input().split()

    # Keep the DP dimension small.
    if len(b) > len(a):
        a, b = b, a

    m = len(b)
    dp = [0] * (m + 1)

    for ca in a:
        new_dp = [0] * (m + 1)

        for j in range(1, m + 1):
            if ca == b[j - 1]:
                new_dp[j] = dp[j - 1] + 1
            else:
                new_dp[j] = max(dp[j], new_dp[j - 1])

            # Even when the characters match, skipping either position
            # may be better than using this particular matching pair.
            if dp[j] > new_dp[j]:
                new_dp[j] = dp[j]
            if new_dp[j - 1] > new_dp[j]:
                new_dp[j] = new_dp[j - 1]

        dp = new_dp

    print(dp[m])

if __name__ == "__main__":
    solve()
```先頭のオプションの交換により、`b`短い文字列。 反復は 2 つの文字列で対称であるため、答えは変わりません。 各 DP 行のサイズが減少するだけであり、したがってメモリ使用量も減少します。`dp[j]`は前の行の値ですが、`new_dp[j - 1]`現在の行のすぐ左の値です。 文字が一致すると、`dp[j - 1] + 1`新しい橋にかかることを表します。 現在の 2 文字の一致が最適な LCS の一部であるとは限らないため、コードは依然として位置をスキップする両方の方法と比較します。 

最初の代入後の明示的なチェックは、単一のネストされたオブジェクトを記述するよりも若干冗長になります。`max`、しかし、それらは 3 つの可能な遷移を可視化します。 また、一致するケースが盲目的に使用するというよくある間違いも回避します。`dp[j - 1] + 1`たとえ別の選択をすると結果が長くなります。 

Python では整数オーバーフローの問題はありません。 答えは、短い文字列の長さ (最大 1000) を超えることはできません。`m + 1`インデックス付けにより DP にクリーンなゼロ列が与えられるため、`1`を通して`m`文字に直接対応する`b[0]`を通して`b[m - 1]`。

import sys
import io

def solution(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    try:
        sys.stdin = io.StringIO(inp)
        sys.stdout = io.StringIO()

        a, b = sys.stdin.readline().split()

        if len(b) > len(a):
            a, b = b, a

        m = len(b)
        dp = [0] * (m + 1)

        for ca in a:
            new_dp = [0] * (m + 1)

            for j in range(1, m + 1):
                if ca == b[j - 1]:
                    new_dp[j] = dp[j - 1] + 1
                else:
                    new_dp[j] = max(dp[j], new_dp[j - 1])

                if dp[j] > new_dp[j]:
                    new_dp[j] = dp[j]
                if new_dp[j - 1] > new_dp[j]:
                    new_dp[j] = new_dp[j - 1]

            dp = new_dp

        print(dp[m])
        return sys.stdout.getvalue().strip()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout
