 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times m$各セルの重みが負ではないグリッド。 ランダムなプロセスによりグリッド内の 2 点が選択され、それらの 2 点によって辺がグリッドに平行な長方形が定義されます。 タスクは、その長方形の予想される面積を計算することです。 

ランダム性には 2 つの層があります。 まずはセル$(i,j)$重みに比例した確率で選択されます$p_{i,j}$。 次に、その単位正方形内で均一に点が選択されます。 これは、選択された各点が事実上、グリッド内の連続したランダムな点であることを意味しますが、密度は区分的に一定です。各セルは、その重みに比例する確率質量に寄与し、単位正方形上に均一に分散されます。 

長方形は 2 つの独立した点によって形成されます。 点の座標が$(x_1, y_1)$そして$(x_2, y_2)$、エリアは$|x_1 - x_2| \cdot |y_1 - y_2|$。 目標はこの製品の期待値です。 

グリッド サイズは最大 1500 x 1500 なので、最大 225 万個のセルが存在します。 セル内二次法は不可能です。$O((nm)^2)$のオーダーになります$5 \times 10^{12}$操作。 

微妙な問題は、座標がセル内で連続しているため、期待値には離散構造 (セルの選択) とセル内での連続オフセットの両方が含まれることです。 各セルを単一点として扱う単純なアプローチでは、セル内の寄与が無視され、偏った結果が生成されます。 

別の失敗例は、すべての重量が 1 つのセルに集中している場合に発生します。 この場合、両方の点は常に同じ単位正方形内にあり、単位正方形内で 2 つのランダムな点が依然として正の期待面積の長方形を形成するため、期待面積はゼロではありません。 離散のみの解釈では、誤ってゼロが出力されます。 

## アプローチ

 定義を直接拡張すると、セルのすべてのペアが考慮されます。 最初の点がセルに着地する確率$(i_1, j_1)$そして2番目の$(i_2, j_2)$に比例する$p_{i_1,j_1} \cdot p_{i_2,j_2}$。 セルの各ペア内で、次の期待値が必要になります。$|x_1 - x_2|\cdot |y_1 - y_2|$ここで、各座標は、整数オフセットによってシフトされたそれぞれの単位正方形内で均一です。 

これは分解につながります。長方形の領域は幅と高さの積に因数分解され、座標は軸全体で独立しているため、期待値は x 座標と y 座標からの寄与に独立して分割されます。 したがって、問題は、単位間隔の加重混合の下で 1 次元で期待される絶対差を計算し、次に軸全体で二乗タイプの組み合わせを計算することに帰着します。 

ブルート フォースはセルのすべてのペアに対して反復処理を行い、各ペアについて x および y 間隔の寄与を計算します。 つまり$O((nm)^2)$、大きすぎます。 

重要な観察は、$|X_1 - X_2|$重み付けされた分布における重み付けの重み付けと重み付けされた位置のプレフィックスの合計のみに依存します。 ペアごとの列挙の代わりに、行と列の累積合計を個別に使用して寄与度を計算できます。 2D 構造は x 部分と y 部分に明確に分離され、各部分は 1D の重み付けされた予想距離の問題に帰着します。 各 1D 問題は、すべてのペアの相互作用を回避しながら、プレフィックス和を使用して線形時間で計算できます。 

行インデックスと列インデックスの予想される絶対差を計算したら、それらを連続セル内補正と組み合わせて、定数に寄与します。$1/6$単位間隔内の均一な点の軸ごとの項。

 ## アルゴリズムのチュートリアル

 まず問題を 1 つの軸に沿った座標を理解することと、次に両方の軸を組み合わせることに分けます。 

1. 総重量を計算する$W = \sum p_{i,j}$。 生の重みを操作し、最後に除算することで、すべての確率を暗黙的に正規化します。 
2. 行の重みを構築する$R[i] = \sum_j p_{i,j}$とカラムの重み$C[j] = \sum_i p_{i,j}$。 x は列の選択のみに依存し、y は行の選択のみに依存するため、これにより x 分布と y 分布が分離されます。 
3. X 軸については、各列を扱います$j$セグメントとして$[j, j+1)$に比例する確率で選ばれる$C[j]$。 期待されるコンピューティング$|x_1 - x_2|$分解を使用して次のようにします。 

整数部分間の距離$|j_1 - j_2|$に、単位間隔内の均一オフセットの予想される寄与を加えたものです。 
4. 接頭辞の合計を使用して列の離散部分を計算します。 列を左から右にスイープするときは、累積重みと累積重み付きインデックスの合計を維持します。 新しい列はそれぞれ、以前のすべての列との相互作用に寄与します。$O(1)$。 
5. 行に対して同じ手順を繰り返して、期待値を計算します。$|y_1 - y_2|$。 
6. 連続補正を計算します: 内の 2 つの独立した一様変数について$[0,1)$、期待される絶対差は次のとおりです。$1/3$。 x と y の寄与が乗算されるため、各軸は加算補正に寄与し、最終的には整数グリッド距離とセル内分散を分離する乗算係数になります。 
7. 結果を結合します: 予想される面積は次のとおりです$E[|x_1-x_2|] \cdot E[|y_1-y_2|]$, x と y は独立しているためです。 
8. 結果のモジュロを出力します。$10^9+7$、合計重みの 2 乗による正規化にモジュラー逆関数を使用します。 

### なぜ効果があるのか

 ポイントの分布は、列と行の重みによって集約されて、独立した x 成分と y 成分に因数分解されます。 製品の期待は期待の産物になるため、$|x_1-x_2|$列のみに依存し、$|y_1-y_2|$行のみであり、サンプリング プロセスでは独立性が維持されます。 接頭辞の合計の計算は、ペアごとの差の代数展開と正確に一致するため、すべてのペアの寄与が 1 回だけ考慮されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

n, m = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]

row = [0] * n
col = [0] * m

W = 0
for i in range(n):
    for j in range(m):
        w = a[i][j]
        row[i] += w
        col[j] += w
        W += w

def expected_1d(w):
    total = sum(w)
    if total == 0:
        return 0

    pref_w = 0
    pref_iw = 0
    res = 0

    for i, wi in enumerate(w):
        res += wi * i * pref_w - wi * pref_iw
        pref_w += wi
        pref_iw += wi * i

    res *= 2
    inv = modinv(total)
    return (res % MOD) * inv % MOD * inv % MOD

Ex = expected_1d(col)
Ey = expected_1d(row)

ans = Ex * Ey % MOD
print(ans)
```コードは、2D 重みグリッドを行と列の合計に圧縮することから始まります。 これは 2 つの座標軸を分離し、独立した処理を可能にする重要なステップです。 

機能`expected_1d`加重分布の下で予想されるインデックスの絶対差を計算します。 ループはプレフィックスの合計を維持するため、各ペアの寄与度が次のようになります。$(i,j)$と$i > j$として 1 回だけカウントされます$w_i w_j (i - j)$。 ループ内の代数形式は、ペアごとの差をプレフィックス累積に変換する標準的な変換です。 

で 2 回割ることにより、正規化を暗黙的に 2 乗します。`total`独立したサンプリングの下で​​順序のないペアを扱うためです。 

最後に、長方形の面積が因数分解されるため、x と y の期待値を乗算します。

 ### 例 1

 入力:```

1 1
```ここで、両方のセルの重みは同じです。 行の重みは次のとおりです。`[2]`、列の重みは次のとおりです。`[1,1]`。 

| ステップ | 列の重み | プレフィックス W | 接頭辞 iW | 貢献 |
 | --- | --- | --- | --- | --- |
 | j=0 | 1 | 0 | 0 | 0 |
 | j=1 | 1 | 1 | 0 | 1 |

 予想される水平距離は次のとおりです。$1/2$、垂直方向は$0$。 つまり面積は0です。 

これは、すべての質量が 1 つの行上にある場合、高さがゼロになり、面積が崩壊することを確認します。

 入力:```
2 2
1 0

```行の重み`[1,1]`、列の重み`[1,1]`。 

| ステップ | 行の接頭辞 | 投稿行 | 列の接頭辞 | コルの投稿 |

 予想される差は両方とも対称的であり、x と y に同じ値が与えられます。 

この結果は、斜めに配置すると水平方向と垂直方向の分離が均等に作成されるという直観と一致します。

 ## 特殊なケース

 単一の非ゼロ セルは、解が両方の軸のゼロ分散を正しく処理するかどうかをテストします。 その場合はどちらも`col`そして`row`配列は単一の点に折りたたまれ、`expected_1d`両方の軸に対してゼロを返し、最終的な答えはゼロであり、長方形領域が形成されないという事実と一致します。 

完全に均一なグリッドは、プレフィックスの累積ですべてのペアごとの距離が二重にカウントされることなく正しくカウントされているかどうかをチェックします。 このアルゴリズムは、各インデックスをペアの正しいエンドポイントとして 1 回だけ処理するため、グリッド全体で重みが同一である場合でも、寄与は一貫して蓄積されます。
