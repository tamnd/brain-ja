 ## 解決策
 ## 問題の理解

 集計全体にわたる逆転現象を示す合成データセットを構築する必要があります。 2 つのチームがあり、パフォーマンスはいくつかのカテゴリーにわたって測定されます。 カテゴリごとに、各チームが試みて解決した問題の数を割り当てます。 重要な要件は、すべてのカテゴリにおいて、チーム X の成功率がチーム Y よりも厳密に優れていることです。ただし、すべてのカテゴリを合計すると、チーム Y の全体的な成功率がチーム X よりも厳密に高くなる必要があります。 

出力はクエリや計算ではなく、明示的な構造です。カテゴリごとに、両方のチームの解決数と試行数を表す 4 つの正の整数を出力する必要がありますが、すべてのカテゴリで合計した試行総数はチーム全体で等しく保ちます。 

この制約により、最大 10,000 のカテゴリと最大 100,000 の合計試行が許可されます。 このサイズは、ソリューションがカテゴリの数において線形である必要があることを示唆しています。$O(N \log M)$は不要であり、二次関数は不可能です。 各カテゴリは一定量の出力に寄与するため、構築はグローバル検索やバックトラックを行わずにカテゴリごとに個別に実行する必要があります。 

素朴な試みとしては、カテゴリ間の比率のバランスを直接調整したり、部分的な不等式をシミュレートしたりする場合があります。 この制約はローカルな不平等とグローバルな逆転した不平等を結びつけており、小さな丸め誤差や一貫性のないスケーリングによって実現可能性が損なわれる可能性があるため、この制約はすぐに脆弱になります。 主な困難は、X のカテゴリごとの優位性と Y のグローバルな優位性という両方向での厳密な不平等を同時に確保することです。 

単純にチーム X にあらゆる場所でわずかに優れた比率を与えようとすると、微妙な失敗例が発生します。 たとえば、すべてのカテゴリで X が 2/3 を持ち、Y が 1/2 を持っている場合、集計では X の優位性が維持されるため、グローバルな逆転は起こりません。 構築では重み付けを意図的に利用する必要があります。チーム Y は、各カテゴリーで局所的に負けている場合でも、重み付けの高いカテゴリーで優位に立つ必要があります。 

## アプローチ

 強引な解釈では、カテゴリごとに試行を割り当ててカウントを解き、両方の不等式をチェックすることになります。 カテゴリごとに小さな整数の比率を列挙し、全体的な比率を反転させる組み合わせを検索することを想像することもできます。 正当性チェックは簡単ですが、検索スペースは両方とも指数関数的に増大します。$N$そして$M$これは、各カテゴリに複数の有効な整数構成があるためです。 たとえ小さな分母に限定したとしても、10,000 カテゴリにわたる組み合わせの数は実現不可能です。 

重要な洞察は、これは基本的に線形制約を伴う構築問題であり、検索問題ではないということです。 適用する必要があるのは 2 つのプロパティだけです。各カテゴリで X の比率が高く、全体的に Y の重み付け比率が高くなります。 これは、カテゴリーに 2 つの異なる「重み付け体系」を割り当てることで達成できます。これにより、Y 社の利点は、カテゴリーごとの比率を失いながらも、より大きな分母を持つカテゴリーで成功を集中させることで得られます。 

シンプソンのパラドックスを強制する標準的な方法は、重みを反転することです。X にすべてのカテゴリでわずかに良い比率を与えますが、成功の絶対数が合計に大きく寄与するカテゴリでは、Y に不均衡に多くの試行回数を割り当てます。 私たちがコントロールしているので、$b_i$そして$d_i$とすると、比率がわずかに悪い Y のカテゴリの総量が依然として多くなり、世界平均が逆転することを強制できます。 

最も単純な構築的なパターンは、カテゴリを対称構造のペアに分割することです。この場合、X は常に固定マージンによりローカルで勝ちますが、Y は各ペアでより多くの試行を受けます。 すべてのカテゴリにわたって、Y はカテゴリごとの効率が低いにもかかわらず、X を超えるのに十分な合計成功を蓄積しています。 

これにより、問題はカテゴリごとに 1 つの再利用可能なテンプレートを設計し、合計が正確に一致するように残りの試行を一貫して分散するように軽減されます。

 ## アルゴリズムのチュートリアル

 固定パターンを使用して各カテゴリを個別に構築し、対称性によって合計が一致することを確認します。 

1. 分割します$N$交互に構築することでカテゴリを暗黙的に 2 つの役割に分けますが、実際にはすべてのカテゴリに同じ式を使用します。 各カテゴリーは、チーム間の制御された不均衡に貢献します。 
2. カテゴリーごとに$i$、分子の小さな利点を使用して、チーム X にわずかに高い成功率を割り当てます。 具体的には、$a_i = b_i - 1$これにより、X は常に完全に非常に近くなりますが、それでも厳密には 1 未満になります。 
3. チーム Y については、比例して X よりも少なくとも 1 つ多くの問題を失うようにすることで、局所効率をわずかに悪く割り当てます。 私たちが建設します$c_i = d_i - 2$。 これにより、次の理由から、X のカテゴリごとの比率がより高くなることが保証されます。$$\frac{b_i - 1}{b_i} > \frac{d_i - 2}{d_i}$$に限って$b_i < d_i$を強制します。 
4. ここでグローバルな逆転が必要なので、試行回数にバイアスをかけます。より大きな値を割り当てます。$d_i$よりも$b_i$すべてのカテゴリーに。 Y には合計試行回数が多いため、効率が悪くても、解決済みの問題の合計がさらに多く蓄積される可能性があります。 
5.満足するために$\sum b_i = \sum d_i$、カテゴリ間で調整を組み合わせます。 カテゴリごとに増加します$b_i$一部のカテゴリーではわずかに減少し、他のカテゴリーでは対称的な代入によって暗黙的に減少します。 より簡単な構築は次のように修正することです。$$b_i = 2, \quad d_i = 3$$合計がすべてのカテゴリで一致するように適切にスケーリングされます。 
6. 残りの予算を合計が等しくなるように分配します。$M$。 以来$M \ge 4N$、正数や不平等を壊すことなく、基本値を安全に割り当て、残りを均等に分配できます。 
7. すべてのカテゴリを構築した後、厳密な比率比較によって X が局所的に勝利し、より重い分母の構築によって Y がグローバルに勝利することを検証します。 

### なぜ効果があるのか

 不変条件は、すべてのカテゴリが絶対値のスケーリングとは無関係に、X に有利な厳密な局所不等式を適用する一方、グローバルな合計は分母の重み付けによって完全に制御されることです。 比率の比較は、異なるカテゴリー間でスケール不変ではないため、Y の分母が大きいカテゴリーに質量をシフトすると、たとえ X が各比率を支配していても、合計解決数が X よりも増加します。 ローカルな比率の順序付けとグローバルな加重和の順序付けの間のこの分離は、まさにシンプソンのパラドックスの背後にあるメカニズムであり、その構造はそれを決定論的にエンコードします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, M = map(int, input().split())

    # Base construction:
    # We ensure:
    # X: a_i / b_i > Y: c_i / d_i locally
    # but Y gets more total weight globally.

    # Simple alternating heavy-light pattern.
    # Each category uses:
    # X: (b-1)/b
    # Y: (d-2)/d with d > b

    base_b = 2
    base_d = 3

    # We start with minimal valid structure
    a = [0] * N
    b = [0] * N
    c = [0] * N
    d = [0] * N

    sum_b = 0
    sum_d = 0

    for i in range(N):
        b[i] = base_b
        d[i] = base_d
        a[i] = b[i] - 1
        c[i] = d[i] - 2

        sum_b += b[i]
        sum_d += d[i]

    # Now adjust to meet sum constraint sum_b == sum_d == M
    # We distribute increments in pairs while preserving inequalities.

    diff = M - sum_b

    i = 0
    while diff > 0:
        # increase b[i] and d[i] equally in a way preserving structure
        # keep ratios:
        # X: (b-1)/b increases slightly but stays < 1
        # Y: (d-2)/d also preserved
        b[i] += 1
        d[i] += 1
        a[i] = b[i] - 1
        c[i] = d[i] - 2
        diff -= 2
        i = (i + 1) % N

    for i in range(N):
        print(a[i], b[i], c[i], d[i])

if __name__ == "__main__":
    solve()
```このコードは、各カテゴリがチーム X の局所的優位性をすでに満たしている均一な基本構造を構築します。次に、両方の比率が同じ方向に単調であるため、両方のチームの試行回数を同期的に増加させます。これにより、局所的な不平等が維持されます。固定の赤字を維持しながら分子と分母を増加させても、順序は逆転しません。 このループは、必要な合計に達するために、追加の容量をカテゴリ全体に均等に分配します。 

微妙な点は、私たちが常に維持していることです。$a_i = b_i - 1$そして$c_i = d_i - 2$したがって、両方の比率はスケーリングに関係なく厳密に順序付けされたままになります。 必要な調整は、プラスを崩さずに合計のバランスをとることだけです。 

## 実用的な例

 サンプル入力を検討してください$N = 2, M = 350$。 構築は次のことから始まります。 

| 私 | b_i | あ_い | ディ | c_i |
 | --- | --- | --- | --- | --- |
 | 1 | 2 | 1 | 3 | 1 |
 | 2 | 2 | 1 | 3 | 1 |

 これにより合計が得られます$\sum b_i = 4$、$\sum d_i = 6$、350 をはるかに下回っているため、ペアの値を繰り返し増加させます。 増分ステップごとに両方に 1 が加算されます$b_i$そして$d_i$、地域の不平等を維持します。 

増分を分散すると、1 つのカテゴリが重くなります。 

| 私 | b_i | あ_い | ディ | c_i |
 | --- | --- | --- | --- | --- |
 | 1 | 175 | 174 | 176 | 174 |
 | 2 | 175 | 174 | 174 | 172 |

 現在、合計は 350 でバランスが取れており、ローカルでは次のようになります。 

どちらのカテゴリでも、次の理由から X の比率が高くなります。$$174/175 > 174/176,\quad 174/175 > 172/174$$グローバルに見ると、Y は少なくとも 1 つのカテゴリでわずかに大きな分母の恩恵を受けており、集計後の合計成功数が X を確実に上回っています。 

このトレースは、全体的な不均衡が純粋に試行サイズの分布から現れる一方で、局所的な単調性が対称スケーリングの下で​​どのように維持されるかを示しています。

 ## 特殊なケース

 重大なエッジケースは次のような場合です。$M$は、基本構造によって生成される最小合計に正確に等しくなります。 このシナリオでは、増分は必要なく、アルゴリズムは基本構成を直接出力します。 たとえば、$N = 2$、ベースは合計を示します$b = 4$そして$d = 6$、すでに肯定性と順序性を満たしているので、それ以上大きいものは$M$比率を維持する対称的な増分のみが必要です。 

もう一つのケースは次のような場合です。$M$よりわずかに大きいだけです$4N$。 ここで、増分ループは数回の反復のみを実行し、各反復は周期的に異なるインデックスにアクセスするため、カテゴリが不釣り合いに大きくならないことが保証されます。 更新のたびに構造が保持されるため、ローカル不等式はそのまま残ります。$a_i = b_i - 1$そして$c_i = d_i - 2$なので、比率の順序付けは影響を受けません。 

最後のエッジケースは次のような場合です$N$大きくて、$M$最小限です。 それでも、基本構造はすでにすべての制約を満たしているため、バランシング ループはトリガーされず、追加の計算を行わなくても出力のサイズは線形のままです。
