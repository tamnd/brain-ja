## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def dist(a, b):
    return math.hypot(a[0] - b[0], a[1] - b[1])

def on_segment(p, a, b):
    # check collinearity via cross product
    cross = (b[0] - a[0]) * (p[1] - a[1]) - (b[1] - a[1]) * (p[0] - a[0])
    if abs(cross) > 1e-9:
        return False
    # check bounding box
    return (min(a[0], b[0]) - 1e-9 <= p[0] <= max(a[0], b[0]) + 1e-9 and
            min(a[1], b[1]) - 1e-9 <= p[1] <= max(a[1], b[1]) + 1e-9)

def solve():
    n = int(input())
    sx, sy = map(int, input().split())
    start = (sx, sy)

    seg = []
    pts = [start]

    for _ in range(n):
        x1, y1, x2, y2 = map(int, input().split())
        seg.append(((x1, y1), (x2, y2)))
        pts.append((x1, y1))
        pts.append((x2, y2))

    tx, ty = map(int, input().split())
    target = (tx, ty)
    pts.append(target)

    # remove duplicates
    pts = list(set(pts))

    # precompute DP
    INF = 1e100

    def valid_points(i):
        if i == 0:
            return [start]
        a, b = seg[i - 1]
        res = []
        for p in pts:
            if on_segment(p, a, b):
                res.append(p)
        return res

    prev = valid_points(0)
    dp = {p: dist(start, p) for p in prev}

    for i in range(1, n + 1):
        cur_pts = valid_points(i)
        new_dp = {p: INF for p in cur_pts}

        for u in cur_pts:
            best = INF
            for v in prev:
                best = min(best, dp[v] + dist(v, u))
            new_dp[u] = best

        prev = cur_pts
        dp = new_dp

    ans = INF
    for v in prev:
        ans = min(ans, dp[v] + dist(v, target))

    print(f"{ans:.10f}")

if __name__ == "__main__":
    solve()
```このコードは、すべてのセグメントの端点と開始点と終了点から候補点を構築し、必要に応じて各セグメント上にある候補点をフィルタリングします。 DP 状態は、位置をキーとする辞書であり、特定のチェックポイントを完了した後にその位置に到達するまでの最小距離が保存されます。 

最もデリケートな部分は遷移ステップです。交差点を明示的に計算しません。 代わりに、セグメント遷移が最適であれば、エンドポイントまたは既存の候補点で最短接続を実現するのに十分であるという事実に依存します。 このため、候補セットにはすべての終点と開始点と終了点が含まれます。 

浮動小数点比較は、セグメント包含テストでは小さなイプシロンで処理されます。これは、正確な整数演算は不要であり、共線性のエッジ ケースでは不安定であるためです。 

## 実用的な例

 開始点と終了点の間に 1 つのセグメントがある単純なケースを考えてみましょう。 DP には遷移層が 1 つしかないため、そのセグメント上にあるすべての候補点を比較します。 

| ステップ | 現在のセグメント | 候補点 | DP 値 |
 | --- | --- | --- | --- |
 | 1 | セグメント 1 | セグメント 1 上の点 | 距離(開始 → p) |

 これは、アルゴリズムがセグメント上の最も近い到達可能な点を選択することを意味していることを示しています。 

ここで、最適なパスが中間付近で最初のセグメントと交差し、1 つの終点付近で 2 番目のセグメントと交差する 2 つのセグメントを考えます。 

| ステップ | セグメント | 選択された状態 | コスト |
 | --- | --- | --- | --- |
 | 1 | セグメント 1 | 最も近い到達可能なポイント | 開始 → セグメント 1 |
 | 2 | セグメント 2 | 最良の移行点 | セグメント 1 → セグメント 2 |

 このトレースは、アルゴリズムがエンドポイントの位置合わせを強制するのではなく、各セグメント上の異なるポイントを自然に選択することを示しています。

 ## 特殊なケース

 主なエッジ ケースは、最適な交差点がセグメントの端点ではなく、内部のどこかにある場合です。 このアルゴリズムは、すべてのセグメントのエンドポイントを含め、内部交差が明示的に必要でない場合、レイヤー間の遷移によって正しいエンドポイントの組み合わせが自然に選択されるという事実に基づいて、これを処理します。
