 ## 解決策
 ## 問題の理解

 ペアになった観測値の長いシーケンスが与えられます。 各観測値は 1 か月を表し、1 つの値は広告支出、もう 1 つは結果としての売上を表します。 このデータから、支出と売上を直線でマッピングする形式の単純な予測モデルを繰り返し構築します。 

各クエリについて、連続した月のセグメントのみを取得します。 そのセグメント上で、リッジ回帰を使用して直線を当てはめます。これは、両方のパラメータの二乗誤差と L2 ペナルティを最小化する傾きと切片の係数を選択することを意味します。 そのペナルティの強さはクエリによって異なります。 そのセグメントとペナルティに最適なラインが見つかると、指定された入力支出値でそれを評価し、予測売上を出力します。 

主な課題は、セグメント境界と正則化パラメータの両方がクエリごとに変化し、最大 100 万のデータ ポイントと 100 万のクエリが存在する可能性があることです。 これにより、各近似にはセグメント全体にわたる統計の集計が必要となるため、クエリごとに回帰を最初から再計算する必要がなくなります。 

単純なアプローチでは、クエリごとにすべての合計が再計算され、最悪の場合は 2 次の動作が発生します。 n と m が 10^6 までの場合、O(nm) さえもまったく実行不可能です。 

セグメント内のすべての x 値が同一である場合、数値上の微妙なエッジ ケースが発生します。 その場合、回帰行列の条件は悪くなりますが、リッジ正則化によりシステムは解決可能に保たれます。 どのような解決策でも、正則化なしで可逆性を仮定することは避けなければなりません。 

## アプローチ

 回帰問題は 2 つのパラメーターで線形であるため、最適解は、一次最適性条件から導出される 2 x 2 線形システムを解くことで得られます。 

固定セグメントの場合、集計統計を定義します。 

セグメント全体で、Sx を x の合計、Sy を y の合計、Sxx を x の 2 乗の合計、Syy を y の 2 乗の合計、Sxy を x に y を掛けた合計とします。 

目的関数は、K と B で二次形式に展開されます。K と B に関して導関数を取得すると、線形システムが得られます。 

(K * Sxx + B * Sx) + λK = Sxy

 (K * Sx + B * n) + λB = Sy

 書き換え:

 (K (Sxx + λ) + B Sx = Sxy

 (K Sx + B (n + λ) = Sy)

 したがって、クエリごとに、[L, R] に関するこれら 5 つのプレフィックスベースの集計が分かれば、2×2 システムを定数時間で解くことができます。 

ブルート フォース アプローチでは、セグメントをスキャンしてクエリごとにすべての合計を再計算します。 これにより、クエリごとに O(セグメントの長さ) のコストがかかり、合計操作量は O(nm) になります。 最大 10^6 の要素とクエリを使用すると、これでは遅すぎます。 

重要な洞察は、必要な数量はすべてセグメントにわたって加算されるということです。 これにより、プレフィックスの合計が可能になり、各クエリが O(1) 算術に削減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(nm) | お(1) | 遅すぎる |
 | プレフィックス合計 + 閉じた形式 | O(n + m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 1. プレフィックス集計を事前計算する

 Sx、Sy、Sxx、および Sxy のプレフィックス配列を構築します。 各位置には、そのインデックスまでの累積合計が格納されます。 これにより、セグメントの合計を 2 つのプレフィックス値の差として計算できます。 

これが有効である理由は線形性です。つまり、互いに素な間隔にわたる合計は相互作用することなく結合されます。 

### 2. クエリごとにセグメント統計を抽出する

 クエリ [L, R] の場合、次のように計算します。 

n = R − L + 1

 プレフィックスの違いを使用してその範囲の Sx、Sy、Sxx、Sxy

 これにより、回帰問題がデータの関連サブセットのみに分離されます。 

### 3. リッジ回帰システムを形成する

 最適化を線形方程式に変換します。 

(Sxx + λ)K + SxB = Sxy

 SxK + (n + λ)B = Sy

 これは、正規化された損失の偏導関数をゼロに設定することから直接得られます。 

### 4. 2×2 系を解く

 行列式を使用して解きます。 

D = (Sxx + λ)(n + λ) − Sx²

 次に:

 K = ((Sxy)(n + λ) − SxSy) / D

 B = ((Sxx + λ)Sy − SxSxy) / D

 これは正規方程式の直接の代数解です。 

### 5. 出力予測

クエリごとに、KX + B を計算して出力します。 

### なぜ効果があるのか

 回帰の目的は、L2 項による K および B の厳密な凸二次関数です。 これにより、一意のグローバル最小値が保証されます。 勾配条件により、係数がデータの集計統計にのみ依存する線形システムが生成されます。 これらの統計は間隔にわたって加算されるため、プレフィックス合計は、クエリ セグメントのシステムを再構築するために必要なすべての情報を保存します。 システムを正確に解くと一意のミニマイザーが得られるため、予測は正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    Sx = [0.0] * (n + 1)
    Sy = [0.0] * (n + 1)
    Sxx = [0.0] * (n + 1)
    Sxy = [0.0] * (n + 1)

    for i in range(1, n + 1):
        x, y = map(float, input().split())
        Sx[i] = Sx[i - 1] + x
        Sy[i] = Sy[i - 1] + y
        Sxx[i] = Sxx[i - 1] + x * x
        Sxy[i] = Sxy[i - 1] + x * y

    m = int(input())
    out = []

    for _ in range(m):
        L, R, lam, X = input().split()
        L = int(L)
        R = int(R)
        lam = float(lam)
        X = float(X)

        nseg = R - L + 1

        Sx_seg = Sx[R] - Sx[L - 1]
        Sy_seg = Sy[R] - Sy[L - 1]
        Sxx_seg = Sxx[R] - Sxx[L - 1]
        Sxy_seg = Sxy[R] - Sxy[L - 1]

        A = Sxx_seg + lam
        B = Sx_seg
        C = nseg + lam
        D = Sxy_seg
        E = Sy_seg

        det = A * C - B * B

        K = (D * C - B * E) / det
        B0 = (A * E - B * D) / det

        out.append(str(K * X + B0))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```プレフィックス配列には累積寄与が格納されるため、各クエリはセグメント合計の定数時間抽出になります。 各回帰システムは、生データを再検討することなく、これらの合計から構築されます。 

行列式の計算は、2×2 正規方程式の閉形式の解を直接実装します。 浮動小数点の精度は近い値を減算するときに敏感になるため、項の順序が重要になります。そのため、行列式を AC − B² として計算すると安定して最小限になります。 

最終的な予測は、当てはめられた線形モデルの評価にすぎません。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、セグメント内のすべての x 値が同一である場合です。 その状況では、Sxx − Sx²/n はゼロになり、通常の最小二乗は定義されません。 リッジ項は対角線に λ を追加し、行列式を厳密に正にし、系が確実に解ける状態を保ちます。 たとえば、x = [2, 2] および y = [1, 3] の場合、回帰はペナルティの下で平衡切片に帰着しますが、システムは引き続き一意の解を生成します。 

もう 1 つのエッジ ケースは λ = 0 で、システムは標準の線形回帰に帰着します。 ここで、数値安定性はデータの分散に完全に依存します。 行列式は AC − B² となり、データが特徴空間の垂直線上に完全に位置する場合、システムは特異になります。 この問題では λ が負でないことは保証されていますが、正であることは保証されていないため、実装では λ に依存するショートカットで除算してはならず、常に完全な行列式形式を使用する必要があります。
