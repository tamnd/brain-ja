 ## 解決策
 ## 問題の理解

 北、東、南、西の 4 つのフラップに対応する 4 つの調整可能なパラメーターを備えた簡素化されたフライト コントローラーを制御しています。 各リクエストは、ピッチ、ロール、ヨーという 3 つの望ましい物理的効果を与えます。 これらの効果はフラップ設定の線形結合であるため、システムは小さな線形方程式系によって完全に記述されます。 

この関係は、ピッチは東と西の差のみに依存し、ロールは北と南の差のみに依存し、ヨーは 4 つのフラップ値すべての合計に依存するということです。 したがって、各リクエストは基本的に、3 つの線形結合がターゲット ベクトルと一致する 4 つの実数を選択するように求めています。 

変数は 4 つありますが、制約は 3 つだけであるため、常に少なくとも 1 つの自由度が存在します。 その自由は、客観的な意味では自由ではありません。すべての有効な解決策の中で、最大の絶対フラップ値ができるだけ小さいものを選択する必要があります。 これにより、タスクが線形解空間にわたる制約付きの最適化問題に変わります。 

各クエリは独立しているため、それぞれに対して有効な 4 倍を出力する必要があります。 

入力の境界の大きさは小さく、すべてのターゲットは原点を中心とする辺の長さ 2 の立方体内にあります。 クエリの数は最大 10^4 と多いため、クエリごとに定数時間の式が必要です。 反復検索やクエリごとの最適化を伴う方法では、時間がかかりすぎます。 

素朴なアプローチは、1 つの変数を自由変数として選択し、探索によって最大絶対値を最小化することによって、線形システムを直接解くことです。 これは失敗します。最適な選択は 4 つの変数すべてのバランスを同時にとることに依存し、自由パラメーターを強引に離散化すると精度の問題と時間のオーバーヘッドが発生するためです。 

すべてのターゲットがゼロの場合、微妙なエッジ ケースが発生します。 すべてゼロのような対称的な代入は機能しますが、多くの単純なパラメータ化では、自由変数の恣意的な選択により依然として不要な非ゼロ値が生成され、最小最大制約に違反する可能性があります。 

## アプローチ

 制約が線形システムを定義するという観察から始めます。 

私たちが欲しいのは

 ピッチ p = e − w

 ロール r = n − s

 ヨー y = n + e + s + w

 最初の 2 つの方程式を並べ替えると、次の構造がすぐに得られます。 

n と s はロールとヨーにのみ表示され、e と w はピッチとヨーにのみ表示されます。 これは、変数を 2 つの独立したペアにグループ化することを示唆しています。 

ロールから、n と s の差の制約を取得します。 ピッチから、e と w の間の差制約が得られます。 これは、対称形式を使用して両方のペアをパラメータ化できることを意味します。 

n = a + t

 s = a − t

 e = b + u

 w = b − u

 これにより、ロール = 2t およびピッチ = 2u が自動的に満たされるため、t = r/2 および u = p/2 となります。 今度はヨーだけが残ります。 

y = (a + t) + (b + u) + (a − t) + (b − u) = 2a + 2b

 したがって、ヨー拘束は a + b = y/2 になります。 

ここで、最適化の問題が明らかになります。以下の中で最大の大きさを最小化しながら、合計が y/2 になる a と b を選択します。 

|a±t| および |b ± u|。 

これは古典的なバランスの問題です。 重要な観察は対称性です。各ペアについて、最大絶対値を最小化する最良の方法は、必要な差を尊重しながら、ペアをできるだけゼロ付近に集中させることです。 この構造は、ヨーへの寄与のバランスをとる方法で両方のペアが個別に中心に配置されている場合に最適化を強制します。 

a = b = y/4 を定義し、2 つの対称ペア間でヨーを均等に分配します。 この選択により、2 つのグループ間の不均衡が最小限に抑えられ、両方のペアのベースライン オフセットが確実に同じになります。 その場合、解決策は次のようになります。 

n = y/4 + r/2

 s = y/4 − r/2

 e = y/4 + p/2

 w = y/4 − p/2

 この構造はすべての制約を正確に満たし、ヨーを均一に分散します。これが、1 つのペアの最大絶対値が不必要に増加することを避ける唯一の方法です。

強引な代替方法は、自由パラメータ a を選択し、4 つの変数すべてを表現し、a の区分線形関数として最大絶対値を最小化することです。 この関数には絶対値の変化からのブレークポイントがあるため、凸関数での場合分け分析または三項探索が必要になりますが、対称性が認識されれば不要になります。

 ## アルゴリズムのチュートリアル

 1. 希望のピッチ p、ロール r、ヨー y からなるクエリを読み取ります。 目標は、大きさを小さく保ちながら、これらに正確に一致するフラップ値を構築することです。 
2. システムを 2 つの独立した差分方程式に分割します。 差分変数を t = r/2 および u = p/2 として設定します。 n − s = 2t および e − w = 2u であるため、これはロールとピッチを直接満たします。 
3. 各ペアを対称中心と偏差として表します: n = a + t、s = a − t、および e = b + u、w = b − u。 これにより、a と b に関係なく、ロールとピッチの正確さが保証されます。 
4. ヨー方程式に代入します。 差は相殺され、y = 2a + 2b が残ります。 これにより、ヨー制御が単一の線形制約 a + b = y/2 に縮小されます。 
5. a = b = y/4 を選択して、ヨーを均等に分配します。 これにより、2 つのペア間の非対称性がなくなり、一方のペアが他方のペアよりも多くのオフセットを強いられることがなくなります。 
6. ステップ 2 と 5 で導出された式を使用して最終的なフラップ値を計算し、出力します。 

### なぜ効果があるのか

 この構築では、a と b に分割された 1 つの自由度を使用して、すべての有効な解をパラメータ化します。 有効な解はすべて a + b = y/2 を満たす必要があるため、すべての解は (a, b) 空間内の直線上にあります。 フラップの絶対値の最大値は、残りの 1 つの自由度で凸となる a と b の線形式によって決まります。 対称的な選択 a = b が、どちらかのペアが上方に偏るのを避ける唯一の点であり、偏差があるとヨーの割り当てが不均一にシフトし、少なくとも 1 つのペアの大きさが増加します。 これにより、生成されるソリューションが、最大絶対フラップ値を最小化するという点で全体的に最適であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    q = int(input())
    out = []
    for _ in range(q):
        p, r, y = map(float, input().split())
        n = y / 4.0 + r / 2.0
        s = y / 4.0 - r / 2.0
        e = y / 4.0 + p / 2.0
        w = y / 4.0 - p / 2.0
        out.append(f"{n:.10f} {e:.10f} {s:.10f} {w:.10f}")
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```このコードは、派生した閉じた形式のソリューションを直接適用します。 各クエリは一定時間内に独立して処理されます。 解決策には入力の線形結合のみが含まれるため、書式設定では必要な絶対誤差範囲内に収まるように十分な精度が使用されます。 

唯一の微妙な実装の詳細は、一貫したスケーリングを確保することです。ピッチとロールは対称偏差として割り当てられる前に半分にされますが、ヨーは 4 つの変数すべてに適用される y/4 の共有オフセットに均等に分割されます。 

## 実用的な例

 クエリ p = 1、r = 1、y = 0 について考えてみましょう。 

t = 0.5、u = 0.5、および a = b = 0 を計算します。 

| ステップ | n | e | s | w |
 | --- | --- | --- | --- | --- |
 | t、u | を計算します。 - | - | - | - |
 | 数式を適用する | 0.5 | 0.5 | -0.5 | -0.5 |

 ピッチは e − w = 1 になり、ロールは n − s = 1 になり、すべての寄与が相殺されるためヨーは 0 になります。 この構造は、ヨーがゼロの場合、システムが 2 つの独立した対称ペアに減少することを示しています。 

ここで、p = 0、r = 0、y = 1 について考えてみましょう。 

t = 0、u = 0、a = b = 0.25 が得られます。 

| ステップ | n | e | s | w |
 | --- | --- | --- | --- | --- |
 | オフセットを計算する | 0.25 | 0.25 | 0.25 | 0.25 |
 | 数式を適用する | 0.25 | 0.25 | 0.25 | 0.25 |

 ここでは、すべての差が消えるため、ピッチとロールはゼロのままです。 合計が 1 であるため、ヨーは 1 に等しくなります。これは、純粋なヨーによってすべての変数が均一に移動することを強制していることを示しています。

 ## 特殊なケース

 すべての入力がゼロの場合、式は n = e = s = w = 0 にきれいに崩壊します。ヨーがすべての変数にわたって均等に分割され、ピッチとロールの寄与が消えるため、隠れたオフセットは導入されません。 

ピッチのみが非ゼロ、ヨーがゼロ、ロールがゼロの場合、構造は e と w のペアを分離します。 解は e = p/2 および w = −p/2 になりますが、n と s は等しいままで、ゼロロールが維持されます。 

ヨーのみがゼロ以外の場合、4 つの変数すべてが同じ値 y/4 に集約されます。 これは最も敏感なケースです。非対称性があるとすぐに最大絶対値が不必要に増加しますが、対称分布によりそれが防止されます。 

p と r で符号が異なる場合、ピッチは 1 つのペアにのみ影響し、もう 1 つのペアには影響を与えるため、独立した対称ペアに分離することで相互干渉がなくなります。
