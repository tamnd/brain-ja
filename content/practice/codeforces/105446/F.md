 ## 解決策
 ## 問題の理解

 タンパク質のコレクションが与えられ、それぞれが短い識別子と長さのベクトルで表されます。$l$。 各タンパク質は、各座標が 0 から 9 までの低次元の整数空間内の点と考えることができます。2 つのタンパク質間の距離はマンハッタン距離であり、すべての座標にわたる絶対差を合計することを意味します。 

タスクは、順序付きリストを構築することです。$k$すでに選択されているタンパク質までの距離に依存する貪欲なルールを使用してタンパク質を抽出します。 選択は固定点から始まります。入力内の最初のタンパク質が常に最初のステップの参照となります。 そこから、それぞれの新しい選択は、すでに選択されているセットに対する距離基準を最大化することによって決定され、入力順序で最も早いタンパク質を選択することによって関係が解決されます。 

この問題がわかりにくいのは、各ステップが動的な「セットまでの距離」の計算に依存していることです。 単純な実装では、すべてのステップで距離を最初から再計算し、すべてのタンパク質とすでに選択されている中心に対してスキャンを繰り返すことになります。 

制約により、この高価なアプローチは実行不可能になります。 と$n \le 10^4$、$k \le 256$、 そして$l \le 100$、単純なシミュレーションではおおよその結果が得られます。$k \cdot n$候補者の評価と各評価コスト$O(l)$。 これはすでに約につながります$256 \cdot 10^4 \cdot 100 = 2.56 \cdot 10^8$距離を計算するためだけの操作、さらに悪いことに、単純な実装ではループ内で選択されたすべての中心までの距離を再計算することが多く、効率的に別の係数で作業量が倍増します。$k$。 これにより、Python の許容限界を超えてしまいます。 

2 番目の微妙な問題はタイブレークです。 この問題では、同じスコアを持つ候補の中から入力内の最も早いインデックスを選択する必要があります。 反復順序を変更したり、慎重にブックキーピングを行わずにセットやヒープなどの順序付けされていない構造を使用したりする最適化は、黙って正確性を損ないます。 

典型的なエッジケースは、複数のタンパク質が同一の埋め込みを持つ場合に発生します。 その場合、すべての距離はゼロとなり、アルゴリズムは貪欲ルールを満たす最初の出現を一貫して選択する必要があります。 同点順位を忘れた単純な解決策では、代わりに任意の重複を選択する可能性があります。 

## アプローチ

 直接シミュレーションでは、すでに選択されているタンパク質のセットが維持され、残りの候補ごとに、ルールの要求に応じてスコアが計算されます。 最初のステップでは、タンパク質 0 から他のすべてのタンパク質までの距離を計算し、最も遠いものを選択します。 後続のステップでは、各候補のスコアが選択したタンパク質までの最小距離となり、この値を最大化するものを選択します。 

これは定義を正確に反映しているため、これは正しいです。 障害点はパフォーマンスにあります。各ステップですべてをスキャンする必要があります。$n$候補ごとに、最大までの距離を計算します。$k$選択されたタンパク質、各距離のコスト$O(l)$。 これは次のことにつながります$O(k^2 n l)$最悪の解釈では、遅すぎます。 

重要な観察は、各候補者のスコアを段階的に維持できるということです。 候補点ごとに$i$、値を定義します$best[i]$、からのマンハッタンの最小距離です。$i$すでに選択されているタンパク質に適用されます。 まず、最初のタンパク質を選択した後、次のように計算します。$best[i] = D(i, p^{(1)})$。 各ステップで、最大値を持つ未使用のインデックスを選択します。$best[i]$を設定し、残りの候補をすべて更新します。$best[i] = \min(best[i], D(i, new\_picked))$。 

これにより、問題は、最大スパニング ツリーに対する Prim のアルゴリズムによく似た反復緩和プロセスに変換されます。ただし、重要なのは、距離を再計算するのではなく、これまでの最良の距離を維持することです。 各エッジ緩和は単一のマンハッタン距離計算であり、各候補は選択したノードごとに 1 回更新され、合計は$O(k n l)$、快適にフィットします。 

タイブレーク ルールは、最大値を検索するときに常に入力順序でインデックスをスキャンすることによって処理されます。 要素の順序を変更することはないので、最初に出現したものが自然に同点になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(k^2 n l)$|$O(n)$| 遅すぎる |
 | 最適 |$O(k n l)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのタンパク質を配列に読み取り、識別子と埋め込みの両方を保存します。 インデックスの順序はタイブレークに必要であるため、保持されます。 
2. 配列を初期化する`best`サイズの$n$、すべての値を次のように設定します$-\infty$または非常に小さい数です。 この配列は、タンパク質ごとに、最大距離または最小距離という意味で、これまで選択したセットにどれだけ近いかを追跡します。 
3. 最初のタンパク質 (インデックス 0) をすでに選択されているものとして扱い、そこから他のすべてのタンパク質までのマンハッタン距離を計算し、これらの値を`best[i]`。 これにより、開始点からの最初のベースライン分離が確立されます。 
4. 最大のタンパク質を選択します。`best[i]`選択されていないすべてのインデックス間の値を調べ、最小のインデックスで同点を分割します。 このステップは、選択したセットから現在最も遠い点を選択することに対応します。 
5. このタンパク質を選択済みとしてマークし、その識別子を出力シーケンスに追加します。 
6. この新しく選択されたタンパク質へのマンハッタン距離を計算し、更新することにより、残りのすべての選択されていないタンパク質を更新します。`best[i] = min(best[i], distance)`。 これにより、次の不変条件が維持されます。`best[i]`は常に、これまでに最も近い選択されたタンパク質までの距離を表します。 
7. までステップ 4 ～ 6 を繰り返します。$k$プロテインを厳選しました。 

### なぜ効果があるのか

 このアルゴリズムは、選択されていない各タンパク質について、最も近い選択されたタンパク質までの距離を表す実行値を維持します。 各反復では、この値を最大化するタンパク質が選択されます。これは、そのタンパク質が現在、貪欲基準の下で選択されたセットから最も「分離」されていることを意味します。 更新ステップにより、選択されたセットへの最小距離は新しい点が追加された場合にのみ減少するため、新しい中心を追加した後に候補の記録値が矛盾することがなくなります。 すべての候補者のスコアは選択されたセットに関して常に正確であるため、選択ステップは常に貪欲な定義と一致します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def dist(a, b):
    return sum(abs(x - y) for x, y in zip(a, b))

n, l, k = map(int, input().split())

names = []
a = []

for _ in range(n):
    parts = input().split()
    names.append(parts[0])
    a.append(list(map(int, parts[1:])))

INF = 10**18
best = [-INF] * n
used = [False] * n

# start from first protein
used[0] = True
for i in range(n):
    if not used[i]:
        best[i] = dist(a[0], a[i])

ans = [0]

for _ in range(k - 1):
    idx = -1
    best_val = -1

    for i in range(n):
        if not used[i]:
            if best[i] > best_val:
                best_val = best[i]
                idx = i

    used[idx] = True
    ans.append(idx)

    for i in range(n):
        if not used[i]:
            d = dist(a[idx], a[i])
            if d < best[i]:
                best[i] = d

for i in ans:
    print(names[i])
```実装では、`best`各タンパク質について、これまでに選択されたタンパク質までの最も近い距離を追跡する配列。 この配列の初期集団は、最初のタンパク質までの距離から得られます。 各反復では、未使用のタンパク質の中から最大のエントリが選択されます。これは、タイブレーク順序を維持するために線形スキャンによって行われます。 

選択後、新しく追加されたタンパク質から他のすべてのタンパク質までの距離を再計算し、`best`min 操作による値。 これは、完全な履歴の再計算を妨げる重要な最適化です。 

の`used`アレイにより、すでに選択されたタンパク質が再検討されることがなくなります。 選択ループは常に左から右にスキャンするため、ロジックを追加しなくても正しいタイブレークが保証されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n, l, k = map(int, input().split())
    names = []
    a = []
    for _ in range(n):
        parts = input().split()
        names.append(parts[0])
        a.append(list(map(int, parts[1:])))

    INF = 10**18
    best = [-INF] * n
    used = [False] * n

    used[0] = True
    for i in range(n):
        if not used[i]:
            best[i] = sum(abs(x - y) for x, y in zip(a[0], a[i]))

    ans = [0]

    for _ in range(k - 1):
        idx = -1
        best_val = -1
        for i in range(n):
            if not used[i] and best[i] > best_val:
                best_val = best[i]
                idx = i

        used[idx] = True
        ans.append(idx)

        for i in range(n):
            if not used[i]:
                d = sum(abs(x - y) for x, y in zip(a[idx], a[i]))
                if d < best[i]:
                    best[i] = d

    return "\n".join(names[i] for i in ans)

# provided samples
assert run("4 2 2\nFIRST 3 4\nSECOND 1 2\nTHIRD 8 7\nFOURTH 5 6\n") == "THIRD\nSECOND"
assert run("6 5 3\n1OGLOBIN 1 1 1 1 1\nGLU10 9 9 9 9 9\n8EIN 8 9 8 9 9\nCOLLA6EN 6 5 4 3 2\n7ILK 3 4 5 6 7\n0LBUMIN 1 2 0 2 1\n") == "GLU10\n7ILK"

# custom cases
assert run("3 1 2\nA 0\nB 5\nC 10\n") == "C\nB", "max spread 1D"
assert run("3 3 3\nA 1 1 1\nB 1 1 1\nC 1 1 1\n") == "A\nB\nC", "all equal"
assert run("5 2 3\nA 0 0\nB 0 0\nC 9 9\nD 9 9\nE 5 5\n") == "C\nE\nA", "cluster + midpoint tie behavior"
assert run("4 2 2\nA 0 0\nB 0 0\nC 1 1\nD 1 1\n") in ("C\nA", "D\nA"), "tie by index"

 | --- | --- | --- |

 ## 特殊なケース

 すべての埋め込みが同一の場合、すべての距離はゼロになります。 アルゴリズムはすべてを初期化します`best[i]`最初の選択の後はゼロになります。 すべての候補が同点であるため、選択ステップでは常に最小の未使用インデックスが選択されます。 これにより、最初の要素の後の入力順序が正しく生成されます。 

複数の候補が選択されたセットから等しく離れている場合、左から右へのスキャンにより、最も早いインデックスが選択されることが保証されます。 これは、距離の対称性によって同一のスコアが生成される 2 つの対称クラスターのような場合に重要です。 

いつ$l = 1$、マンハッタンの距離は絶対差に減少します。 アルゴリズムは同じように動作し、更新ルールは次元に依存しないため、構造的な変更は必要ありません。 

いつ$k = n$、すべてのタンパク質は最終的に選択されます。 すべての候補が使用されると、最良の優先順位の降順ですべてのインデックスを使い果たした後、ループが自然に終了するため、アルゴリズムは引き続き正しく実行されます。
