 ## アルゴリズムのチュートリアル

 辞書の各単語をパターンとして扱い、出現するすべての単語を列挙したいと考えています。`s`、しかし、私たちは反転した単語に基づいて構築されたトライを使用して効率的にそれを行います。 

1. すべての辞書の単語からトライを作成しますが、それらを逆にして保存します。 各終端ノードには単語の値が格納されます。 これにより、後ろ向きに歩くことで、特定の位置で終わる単語を検出できるようになります。`s`。 
2. ポジションごとに`i`で`s`、トライ遷移に従って、最大語長まで逆方向に歩きます。 ターミナルノードに到達するたびに、一致を記録します。`(l, i, v)`どこ`l`一致した単語の開始位置です。 
3. DP アレイを維持する`dp[i]`、 どこ`dp[i]`プレフィックスの合計スコアです`1..i`。 初期化する`dp[0] = 1`。 
4. 位置を左から右に処理します。 位置で`i`、から始めます`dp[i] = dp[i-1]`で終わらない抽出を表します。`i`。 
5. 試合ごとに`(l, i, v)`で終わる`i`、この単語を抽出の最後に選択されたセグメントとして取得するという貢献を追加します。 その貢献とは、`dp[l-1] * v`なぜなら、以前はすべて`l`任意の有効な抽出を指定して、この間隔を追加します。 
6. そのような貢献をすべて合計すると、`dp[i]`。 
7. すべてを返す`dp[i]`モジュロ`998244353`。 

この合計が機能する理由は、右端のエンドポイントで見たときに、すべての抽出に最後に選択された一意の間隔があるためです。 抽出を最後の間隔でグループ化すると、二重カウントが回避され、前のセグメントと後のセグメント間の独立性が保証されます。 

### なぜ効果があるのか

 すべての有効な抽出は、重複しない間隔のセットに対応します。 選択した間隔を正しいエンドポイントで順序付けすると、最後の間隔が一意に分解を決定します。つまり、完全に存在する前のすべてのものが決まります。`1..l-1`。 固定された最後の間隔を持つすべての構成の寄与`(l, i)`まさに`dp[l-1] * v`、 以来`v`はその区間を選択する重みであり、`dp[l-1]`以前の有効な抽出をすべてカウントします。 すべての選択肢を合計し、空の抽出を含めると、重複や省略のないすべての有効なサブセットの完全な分割が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

class Node:
    __slots__ = ("next", "val")
    def __init__(self):
        self.next = {}
        self.val = 0

def insert(root, word, val):
    node = root
    for ch in word:
        if ch not in node.next:
            node.next[ch] = Node()
        node = node.next[ch]
    node.val += val

def solve():
    s = input().strip()
    n = int(input())
    
    root = Node()
    max_len = 0
    
    words = []
    for _ in range(n):
        t, v = input().split()
        v = int(v)
        words.append((t, v))
        max_len = max(max_len, len(t))
        insert(root, t[::-1], v)
    
    m = len(s)
    dp = [0] * (m + 1)
    dp[0] = 1
    
    for i in range(1, m + 1):
        node = root
        dp[i] = dp[i - 1]
        
        j = i
        step = 0
        
        while j > 0 and step < max_len:
            c = s[j - 1]
            if c not in node.next:
                break
            node = node.next[c]
            j -= 1
            step += 1
            
            if node.val:
                dp[i] = (dp[i] + dp[j] * node.val) % MOD
    
    print(*dp[1:])

if __name__ == "__main__":
    solve()

 辞書に一致しない文字列の場合、DP は一定のままである必要があります。`1`空の抽出のみが存在するため、すべてのプレフィックスに対して。 トライ終端ノードに到達しないため、アルゴリズムはこれを処理します。`dp[i] = dp[i-1]`みんなのために`i`。
