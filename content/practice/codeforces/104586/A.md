 ## 解決策
 ## 問題の理解

 すべてのベリーはもともと同じ瓶に詰められており、どの瓶にも同じ数のベリーが入っていたと言われています。 各瓶には 1 種類のベリーのみが含まれています。 選別中に混乱が生じた後、すべてのベリーが 1 つの山にまとめられ、その山で見つかったブラックカラントのベリーの総数がわかりました。 

カシスが入った瓶の中にはカシスとアカスグリがあったが、梱包時に誤って同じ種類として扱ってしまった。 元の構造について私たちが知っていることは、すべての瓶の一部が、`p`、カラント（黒と赤の両方）が含まれていました。 残りの瓶には他のベリーが含まれていましたが、合計数に寄与することを除いて、最終的な計算には関係ありません。 

重要な点は、すべての瓶の容量が同じであるため、「瓶の割合」はそのまま「ベリー全体の割合」に変換されるということです。 

課題は、カシスの数がわかっているとして、すべてのカラントの果実のどの部分がカシスであるかを判断することです。`n`、瓶の割合からスグリの果実の合計数を推測できます。`p`。 

入力サイズが小さいため、解は定数時間である必要があります。 瓶やベリーのシミュレーションを伴うアプローチは必要ありません。 唯一の微妙な点は、均等サイズ制約を使用して瓶の一部をベリーの一部に正しく変換することです。 

エッジケースは次の場合に発生します。`n = 0`、ここで黒スグリは存在せず、答えは正確にゼロでなければなりません。`p`。 もう 1 つの例外的なケースは次のような場合です。`p = 1`つまり、すべての瓶はスグリの瓶であるため、山にあるすべてのベリーはスグリであり、答えは次のようになります。`n / total_currants`これにより、分割の問題が発生せずにきれいに単純化されるはずです。 

素朴な間違いは治療することです`p`等しいサイズの瓶の仮定を考慮せずに直接スグリの果実の割合として計算するか、総ベリー数が瓶の構造によって暗黙的に固定されるという事実を無視します。 

## アプローチ

 ブルートフォース解釈では、jar の数を再構築しようとします。 各瓶に次のものが含まれていると仮定すると、`k`ベリー、可能性のあるものを列挙してみるかもしれません`k`、次にベリー全体を瓶に分割し、次にスグリの瓶を分数に応じて割り当てます。`p`、最後にカシスと赤スグリを配布しました。 これはすぐに決定不足になり、計算上無意味になります。`(k, number of jars)`ペアは制約を満たします。 

重要な観察は、実際に知る必要はないということです。`k`または瓶の数。 すべての瓶は同じサイズなので、瓶の比率とベリーの比率は同じです。 これにより、全体の構造が 1 つの比例関係に崩壊します。つまり、すべての果実のうちスグリの果実の割合は正確に次のようになります。`p`。 ベリーの合計数は 100 万に固定されているため、スグリのベリーの合計数は次のように直接計算できます。`p * 1e6`。 

スグリの総量が分かれば、答えは単純な比率、つまり総スグリに対する黒スグリの比率になります。

 ## アルゴリズムのチュートリアル

 1.読む`n`そして`p`。 この時点で`n`はブラックカラントの果実の数であり、`p`スグリの瓶に属するすべてのベリーの割合です。 
2. スグリの瓶の割合をスグリの実の総数に変換します。 すべての瓶には同じ数のベリーが含まれているため、この割合はベリーに均等に適用されます。 ベリーの合計数は、`1,000,000`、したがって、スグリの果実の合計は次のようになります。`p * 1,000,000`。 
3. 目的の比率を次のように計算します。`n / (p * 1,000,000)`。 これは、ブラックカラントをすべてのカラントと直接比較します。 
4. 必要な誤差範囲を満たすのに十分な精度を備えた浮動小数点数として値を出力します。 

### なぜ効果があるのか

 すべての瓶のサイズは同じなので、瓶からベリーへのマッピングは線形です。 瓶のサブセットは、定数係数でスケールされたベリーの同じサブセットに対応します。 したがって、カラントの瓶の割合は、カラントの果実の割合と等しくなります。 これにより、スグリの総数は以下によって完全に決定されます。`p`そして既知の総ベリー数、ブラックカラントを分離するための単一の部門のみが残ります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, p = input().split()
    n = int(n)
    p = float(p)

    total = p * 1_000_000.0
    if total == 0:
        print(0.0)
        return

    ans = n / total
    print(ans)

if __name__ == "__main__":
    solve()
```実装は派生した式に直接に従います。 唯一必要な注意は、次の浮動小数点変換です。`p`、小数点以下 6 桁まで指定されるためです。 の乗算`1e6`精度を維持するには、浮動小数点で実行する必要があります。 

警備員`if total == 0`縮退したケースを処理します。`p = 0`、つまり、スグリの実がまったく存在しないことを意味します。 その状況では、`n`もゼロでなければならず、除算を実行せずに答えはゼロとして定義されます。
