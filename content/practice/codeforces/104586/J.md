 ## 解決策
 ## 問題の理解

 直線上に配置された一連の垂直柱が与えられ、それぞれが X 軸上の位置と高さによって定義されます。 2 つの異なる投稿を選択できます。1 つは「落下」投稿、もう 1 つは「ターゲット」投稿とします。 落下するポストは、その頂点がターゲットのポストの頂点に接触するように回転し、地面と直角三角形を形成します。 

幾何学的には、この三角形の底辺は、選択した 2 つの位置間の水平距離であり、ターゲットの上部が三角形の上頂点を定義するため、垂直成分はターゲット ポストの高さによって決まります。 落下するポストは、その点に到達するのに十分な高さが必要なコネクタとしてのみ機能しますが、構成が有効になると、独立して三角形の高さに寄与することはありません。 

目標は、この直角三角形の面積を最大化する個別のインデックスの順序付きペアを選択することです。 正の領域を生成する有効な構成が存在しない場合は、-1 -1 が出力されます。 

この制約では、最大 10^9 の座標で最大 100,000 件の投稿が許可されます。 これにより、すべてのペアを明示的に考慮するソリューションは即座に除外されます。これは、最悪の場合、10^10 のオーダーの演算が必要になるためです。 O(n log n) または O(n) に近いものが必要です。 

このタイプの問題の微妙な問題は、落下ポストの方向は実現可能性の観点からのみ重要であり、最終的な面積の公式では重要ではないことです。 多くの誤った解決策は、誤って問題を対称として扱ったり、順序付けの制約を無視したりするため、最適な構成が最初に正しい「ターゲット」ポストを選択することに依存する場合に誤った回答を導きます。 

もう 1 つの失敗モードは、X 座標によるソート後、最良のペアが常に隣接するポストによって形成されると仮定することから生じます。 たとえば、次のことを考えてみましょう。 

入力:```
3
0 100
1 1
10 1
```貪欲な隣接アプローチでは、(0,1) または (1,10) を試行する可能性がありますが、最適な構造は、極端な距離と十分な高さの制約を組み合わせることによって異なりますが、隣接ではこれを捕捉できません。 

最後に、もう 1 つの落とし穴は、特定の投稿に対する最適なパートナーが、ローカルの近傍ではなく、フィルターされたセット間のグローバルな極値に依存するということを無視していることです。 

## アプローチ

 ブルート フォース ソリューションでは、順序付けされたすべてのポストのペアが試行されます。 各ペアについて、一方を落下ポストとして、もう一方をサポートとして使用して、暗示される三角形の面積を計算します。 すべての構成を直接チェックするため、これは簡単かつ正確です。 ただし、n(n−1) 個のペアをチェックする必要があり、各チェックは O(1) であるため、O(n^2) 時間がかかり、n = 100,000 の場合には実現不可能です。 

重要な観察は、固定された「ターゲット」ポストの場合、そのエリアはその高さと可能な限り最適なパートナーまでの距離のみに依存するということです。 ターゲットポストを b に固定すると、最良の落下ポスト a は常に |x_a − x_b| を最大化するものになります。 ただし、a が b に到達するのに十分な高さであるという実現可能性条件は満たしています。 

これは、視点を逆転することを示唆しています。ペアを列挙する代わりに、高さの降順に投稿を処理します。 投稿を処理するとき、以前に処理された投稿はすべて、少なくとも同じ高さがあるため、現在の投稿の落下投稿の有効な候補となります。 これらの候補のうち、距離を最大化するには最小と最大の X 座標のみが必要です。 

これにより、問題は、極端な X 値に高速にアクセスして点の動的なセットを維持することに軽減されます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 遅すぎる |
 | ソート + 極値によるスイープ | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 1. 投稿を高さの降順に並べ替えます

 まず、すべての投稿を並べ替えて、常に背の高い投稿を最初に処理するようにします。 これにより、投稿を検討するときに、以前に処理されたすべての投稿が少なくとも同じ高さになることが保証されます。 

この順序は実行可能性を保証するため、非常に重要です。以前の投稿は、現在の投稿に対する後続の投稿として機能する可能性があります。 

### 2. X 座標の動的なセットを維持する

 以前に処理されたすべての投稿の x 座標を保存する構造を維持します。 このセットからは、x の最小値と最大値を追跡するだけで済みます。 

これら 2 つの極端な値は、新しい点までの水平距離を最大化するため、十分です。 

### 3. 各投稿を現在のターゲットとして処理します

 ソート順に並べられた各投稿について、それを潜在的なターゲットとして扱います。 すでにポストを処理している場合は、i から現在の極値までの可能な限り最適な距離を計算します。 

距離 = max(|x_i − min_x|, |x_i − max_x|) を評価します。 

次に、領域候補 = h_i × 距離を計算します。 

これは、i を支柱として使用し、それを最も遠くにある有効な落下支柱と組み合わせることに対応します。 

### 4. ベストアンサーを更新する

 これまでに見つかった最大領域を追跡し、対応する順序付けされたインデックスのペアを保存します。 

### 5. 現在の投稿を構造に挿入します

 i を処理した後、その x 座標を構造に挿入して、将来の (短い) 投稿で使用できるようにします。 

### なぜ効果があるのか

 どのステップでも、以前に処理されたすべてのポストは現在の高さ以上であるため、それらは有効な落下ポストとなります。 ターゲット ポストごとに、距離は x 内で線形であり、極値で最大化されるため、最適な落下ポストは現在の x 範囲の両端のいずれかに存在する必要があります。 これにより、内側の点は極点よりも大きな水平距離を生成できないため、より大きな領域を生成できる候補を見逃すことがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = []
    for i in range(n):
        x, h = map(int, input().split())
        pts.append((h, x, i + 1))
    
    pts.sort(reverse=True)

    min_x = None
    max_x = None

    best_area = 0
    best_pair = (-1, -1)

    for h, x, idx in pts:
        if min_x is not None:
            d1 = abs(x - min_x)
            d2 = abs(x - max_x)
            if d1 >= d2:
                area = h * d1
                if area > best_area:
                    best_area = area
                    best_pair = (idx, pts_map_min[min_x])
            else:
                area = h * d2
                if area > best_area:
                    best_area = area
                    best_pair = (idx, pts_map_max[max_x])

        if min_x is None:
            min_x = max_x = x
            pts_map_min = {x: idx}
            pts_map_max = {x: idx}
        else:
            if x < min_x:
                min_x = x
                pts_map_min[x] = idx
            if x > max_x:
                max_x = x
                pts_map_max[x] = idx

    if best_area == 0:
        print(-1, -1)
    else:
        print(*best_pair)

if __name__ == "__main__":
    solve()
```実装はスイープのアイデアに直接準拠しています。 配列は高さによって並べ替えられるため、以前に確認された点と組み合わせるときに実現可能性が保証されます。 

対応するインデックスを取得するためのマッピングとともに、処理されたポイント間の最小値と最大値の x を維持します。 距離を最大化できるのは両極値のみであるため、新しい各ポイントが両極値と比較されます。 

実装上の微妙な問題は、両方の極値をその元のインデックスとともに追跡する必要があることです。 複数の点が時間の経過とともに同じ極値 x を共有する場合、有効なインデックスを参照していることを確認する必要があります。 ここでの辞書はその目的に役立ちますが、より単純な実装では min と max の両方の (x, idx) ペアを明示的に格納できます。 

best_area == 0 のチェックは、有効なペアが存在しない場合、つまり少なくとも 2 つの互換性のあるポイントが存在しなかった場合を処理します。

 ## 特殊なケース

 2 つの点を含む最小の入力は常に唯一の可能なペアを生成し、アルゴリズムは最初の点を挿入し、すぐにそれに対して 2 番目の点を評価することによってそれを処理します。 スイープにより、必要なときに正確に最初の点が候補セットの一部になることが保証されます。 

すべての点の高さが同じである場合、すべての点がターゲットとして同等に有効になります。 このアルゴリズムは、維持された最小および最大の x 値を使用して正しく検出される、最大水平距離を持つペアを選択することになります。 

点が x 内にクラスター化されているが、1 つの点が遠くにある場合、極端な追跡により、処理されたセットの一部になるときに遠い点が常に選択されるようになり、局所的なクラスター化が答えを支配するのを防ぎます。
