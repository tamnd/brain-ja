 ## 解決策
 ## 問題の理解

 私たちには洞窟の木が与えられています。 各洞窟にはいくつかのボールが含まれています。 キャラクターは固定された洞窟からスタートし、木の中を葉に向かって歩きますが、すべての分岐点で次の未訪問の端を一様にランダムに選択します。 彼は既に使用したエッジを決して戻ることはありません。そのため、彼の歩行は常に開始ノードからあるリーフまでの単純なパスになります。 

すべての洞窟は、ウォークが洞窟を通過する場合にそのボール数に影響します。 このタスクは、指定された開始ノードから開始するときに収集されるボールの予想総数を計算することです。 

入力サイズは最大 1 万ノードであるため、パスを明示的に列挙したり、ランダム ウォークをシミュレートしたりするソリューションは不可能です。 ツリー内のパスを完全に列挙すると、分岐の度合いとともに指数関数的に増加するため、唯一の実行可能な方向は、期待値をローカルで計算し、ツリー上の動的プログラミングを通じてそれらを結合することです。 

開始ノードがすでにリーフである場合、微妙なエッジ ケースが発生します。 この場合、ウォークは決して移動しないため、答えはそのノードの値だけになります。 もう 1 つの特殊なケースは、ツリーがパスに縮退する場合です。この場合、ランダム性が完全になくなり、期待値が決定的になるため、健全性チェックに役立ちます。 

## アプローチ

 ブルート フォース解釈では、開始ノードから考えられるすべてのルートからリーフへのパスを明示的にシミュレートします。 次数 d の各ノードで、ウォークは同様に可能性の高い d 個の継続に分割されます。 サイズ 10000 のツリーであっても、ルートからリーフへの個別のパスの数は指数関数的に増加する可能性があるため、このアプローチはすぐに失敗します。 

重要な観察は、プロセスがノードを決して再訪問しないツリー上のランダム ウォークであるため、子サブツリーにステップを踏み込むと、将来の期待はそのサブツリーのみに依存し、グラフの残りの部分には依存しないということです。 これにより、関数 E[v] を、ノード v から開始して元の親から離れていくにつれて収集されるボールの予想数として定義できます。 

ノード v では、親を除くすべての近隣ノードが次のステップとして選択される可能性が等しくなります。 隣接する u に移動すると、E[u] に従って u のサブツリー内のすべてを収集します。 したがって、E[v] は、v の値にすべての子 u の E[u] の平均を加えた値になります。 これは標準ツリー DP ですが、次数マイナス 1 による正規化が行われています。 

これをきれいに計算するために、開始ノードでツリーをルート化し、期待値をボトムアップで計算する DFS を実行します。

 | --- | --- | --- | --- |
 | パスに対するブルート フォース | O(exp(n)) | O(n) | 遅すぎる |
 | 期待を込めたツリーDP | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 開始ノード s でツリーをルートします。 ウォークは常に親から遠ざかるため、各ノードについて、遷移確率を計算するときにその親を禁止されたものとして扱います。 

各ノード v について、親からノードに入ったときに v から収集されるボールの予想数を計算します。 

1. ツリーの隣接リストを作成します。 

これにより、隣接するノードへの一定時間のアクセスが可能になります。これは、遷移が次数に依存するため必要です。 
2. 開始ノードから DFS を実行し、親を渡します。 

遷移ルール​​によって元のエッジが除外されるため、親が必要になります。 
3. 各ノード v について、親を除くすべての近隣ノードを収集します。 

これらは有効な次のステップです。 そのような近傍が存在しない場合、v は根のある意味での葉です。 
4. v が葉の場合、dp[v] = a[v] を設定します。 

散歩はここで止まるので、期待はまさに地元の価値です。 
5. それ以外の場合は、dp[v] = a[v] とすべての有効な近傍 u にわたる dp[u] の平均を計算します。 

各近傍は確率 1 / 度 (親を除く v) で選択されるため、期待値は線形になります。

dp[v] = a[v] + sum(dp[u]) / k。 
6. 開始ノードで計算された値 dp[s] を返します。 

dp[u] は dp[v] で使用される前に完全に決定されるため、再帰によって期待値が葉から上に自然に伝播されます。 

### なぜ効果があるのか

 任意のノード v で、ウォークがその親から v に到達すると、将来のパスは v とそのサブツリーのみに依存するマルコフ過程になります。 各出力エッジは残りのエッジの中から均一に選択されるため、将来のゲインの期待値は正確に子の期待値の平均になります。 期待値の線形性により、独立したサブツリーからの寄与を合計し、選択肢を平均することで、正しい全体的な期待値が生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(200000)

n, s = map(int, input().split())
a = list(map(float, input().split()))

g = [[] for _ in range(n)]
for _ in range(n - 1):
    x, y = map(int, input().split())
    x -= 1
    y -= 1
    g[x].append(y)
    g[y].append(x)

dp = [0.0] * n

def dfs(v, p):
    children = []
    for to in g[v]:
        if to != p:
            dfs(to, v)
            children.append(to)

    if not children:
        dp[v] = a[v]
        return dp[v]

    total = 0.0
    for to in children:
        total += dp[to]

    dp[v] = a[v] + total / len(children)
    return dp[v]

print(dfs(s - 1, -1))
```このソリューションは、隣接形式でツリーを構築し、開始ノードから DFS を実行します。 再帰により dp 値がボトムアップで計算されます。 各ノードは、非バックトラック ルールを適用するために親エッジを除き、その子からの結果のみを集約します。 

唯一のデリケートな部分は、完全な次数ではなく、有効な出力エッジの数を使用して確率の正規化が確実に行われるようにすることです。 これが、DFS 中に子が明示的にフィルターされる理由です。 

## 実用的な例

 ### 例 1

 入力:```
4 4
0 2 0 0
1 2
2 3
3 4
```これはチェーンであるため、エンドポイントを除くすべてのノードには、DFS 内にルート 4 の子が 1 つだけあります。 

| ノード | 子どもたち | dp値の計算 |
 | --- | --- | --- |
 | 1 | なし | 0 |
 | 2 | 1 | 2 + 0 = 2 |
 | 3 | 2 | 0 + 2 = 2 |
 | 4 | 3 | 0 + 2 = 2 |

 すべてのパスは決定的であり、常にノード 2 を通過するため、ノード 4 での期待値は 2 です。 

### 例 2

 入力:```
6 6
0 1 2 2 0 0
1 3
3 5
5 4
5 6
2 4
```ノード 6 からは隣接ノードが 1 つだけ存在するため、最初はウォークが決定的になります。 

| ノード | 子どもたち | DP |
 | --- | --- | --- |
 | 1 | なし | 0 |
 | 2 | なし | 1 |
 | 3 | 5 | 2 + dp[5] |
 | 4 | 5 | 2 + dp[5] |
 | 5 | 4,6 | 0 + (dp[4] + dp[6]) / 2 |
 | 6 | 5 | 0 + dp[5] |

 ボトムアップで解くと、dp[5] = 2、dp[4] = 4、dp[3] = 6、dp[6] = 2.5 が得られます。 

この表は、分岐によって平均化がどのように導入されるか、リーフ チェーンによって決定論的な寄与が上方に伝播されるかを示しています。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math

    n, s = map(int, input().split())
    a = list(map(float, input().split()))

    g = [[] for _ in range(n)]
    for _ in range(n - 1):
        x, y = map(int, input().split())
        g[x-1].append(y-1)
        g[y-1].append(x-1)

    dp = [0.0] * n

    sys.setrecursionlimit(200000)

    def dfs(v, p):
        child = []
        for to in g[v]:
            if to != p:
                dfs(to, v)
                child.append(to)
        if not child:
            dp[v] = a[v]
            return dp[v]
        dp[v] = a[v] + sum(dp[c] for c in child) / len(child)
        return dp[v]

    return str(dfs(s-1, -1))

 ## 特殊なケース

 リーフ開始ノードは基本ケースによって直接処理されます。 子がないため、DFS は dp[v] = a[v] を割り当てます。これは、動きが発生しないという事実と一致します。 

高次ノードは、すべての子を平均することによって処理されます。 親を明示的に除外するため、確率を歪める可能性がある後方移動を誤って含めることはありません。 

線形チェーンは決定論的なウォークに帰着します。 各ノードには子が 1 つだけあるため、平均化は希釈なしの直接伝播に縮退し、単一のパスに沿った強制移動の意図された動作と一致します。
