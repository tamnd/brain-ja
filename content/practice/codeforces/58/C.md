 ## 解決策
 ## 問題の理解

 の行が与えられています`n`それぞれの木には一定の高さがあります。私たちの仕事は、その列が「美しい」シーケンスを形成するように、その高さの一部を調整することです。 シーケンスは、中心を中心に対称で、端から離れるごとに正確に 1 ずつ増加する場合に美しくなります。 具体的には、最初と最後のツリーは同じ高さである必要があり、2 番目と最後から 2 番目のツリーは同じ高さで最初のツリーより 1 つ高い必要があります。 ツリーの高さは任意の正の整数に変更できますが、変更するたびにコストがかかるため、変更の数は最小限に抑えたいと考えています。 出力は、調整が必要なツリーの最小数です。 

入力サイズは最大 100,000 本の木まで可能で、それぞれの高さも最大 100,000 まで可能です。 2 秒の制限時間では、二次関数のアルゴリズムが使用されます。`n`遅すぎるでしょう。 線形またはほぼ線形にスケールするソリューションが必要です。`n`。 

明らかではないエッジケースは、すでにほぼ美しいものの、途中でわずかにずれているシーケンスで発生します。 例えば、`[2, 2, 2]`中央のツリーのみを調整する必要があるため、最小の変更は 1 になります。 もう一つの厄介なケースは、`[1, 3, 3, 1]`。 段階的な差異を考慮せずに対称性のみをチェックする単純なアプローチでは、すでに美しいと誤って結論付けることになります。 対称性と正確な増分パターンの両方を考慮する必要があります。 

## アプローチ

 ブルートフォース手法では、最初のツリーの開始高さをすべて試し、そこから美しいシーケンスを構築しようとします。 開始高さの候補ごとに、必要な変更の数を数えて、最小値を選択します。 このアプローチは正しいですが、非効率的です。 最初の木を最大 100,000 までのすべての可能な高さで変化させ、各高さですべての高さをスキャンするとします。`n`ツリーの場合、最悪の場合の操作数は次のとおりです。`n * max(a_i)`それは大きすぎます`n = 10^5`。 

重要な観察は、各ツリーとその対称的な対応するツリーとの間の違いが予測可能であるということです。 高さを定義すると、`i`美しいシーケンスの - 番目の木`h + i - 1`（前半）それを後半に反映すると、問題は、増分距離を調整するときに最も頻繁に発生する有効な開始高さを見つけることになります。 形式的には、前半の各高さから最初の端からの距離を引き、後半の最後の端からミラーリングされた距離を引くと、得られる数値は完全な順序ですべて同じになるはずです。 これらの「調整された高さ」の中で最も一般的な数値を数えることで、どの開始高さが変化を最小限に抑えるかを知ることができます。 そのときの変更数は、`n`最も一般的な調整値の頻度を引いた値。 

これにより、問題は周波数カウンターを使用した線形スキャンに変換されます。`O(n)`時間と`O(n)`空間。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * max(a_i)) | お(1) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各木の「距離調整後の高さ」を計算します。 ツリー用`i`(0-インデックス付き) 前半では、そのインデックスを減算します`i`から`a[i]`。 ツリー用`i`後半は差し引きます`(n - 1 - i)`から`a[i]`。 これにより、その木が理想的なシーケンスの一部である場合にシーケンスを美しくする効果的な開始高さが得られます。 
2. 辞書またはハッシュ マップを使用して、調整された各高さの頻度を数えます。 それぞれの固有の調整された高さは開始高さの候補を表し、その頻度はすでにその候補と一致している木の数を示します。 
3. 最大周波数を見つけます。 この頻度は、変更が最も少ない候補の開始高さに対応します。 
4. 変更の最小数は次のとおりです。`n`最も頻繁に調整される高さに一致しないすべての木を変更する必要があるため、この最大頻度を差し引いた値になります。 

機能する理由: 最も近いエッジからの距離に応じて高さを調整することで、すべての木を美しいシーケンスの開始高さを表す「共通のベースライン」に正規化します。 このベースラインにすでに位置合わせされているツリーの数を最大化すると、変更の数が直接最小限に抑えられます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import defaultdict

n = int(input())
a = list(map(int, input().split()))

counter = defaultdict(int)

for i in range(n):
    if i <= (n - 1 - i):
        key = a[i] - i
    else:
        key = a[i] - (n - 1 - i)
    counter[key] += 1

max_freq = max(counter.values())
print(n - max_freq)
```大量の入力を処理するために高速 I/O を使用します。 距離調整により、各木の高さが美しい順序で有効な開始高さに正規化されます。 辞書を使用すると、頻度を効率的に数えることができます。 最後に、から最大周波数を引きます。`n`最小限の変更を加えます。 微妙な点には、配列の辺に応じてどの距離を減算するかを正しく識別すること、インデックスが 0 ベースとして処理されることを確認することが含まれます。

## テストケース```python
import sys, io
def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import defaultdict
    n = int(input())
    a = list(map(int, input().split()))
    counter = defaultdict(int)
    for i in range(n):
        key = a[i] - i if i <= n-1-i else a[i] - (n-1-i)
        counter[key] += 1
    return str(n - max(counter.values()))

# provided sample
assert run("3\n2 2 2\n") == "1", "sample 1"

# custom cases
assert run("1\n5\n") == "0", "single tree"
assert run("5\n1 2 3 2 1\n") == "0", "already beautiful"
assert run("4\n1 2 2 1\n") == "0", "even length, already beautiful"
assert run("5\n1 3 3 3 1\n") == "2", "middle tree adjustment"
assert run("6\n1 2 2 3 2 1\n") == "3", "complex pattern"
