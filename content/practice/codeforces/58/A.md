 ## 解決策
 ## 問題の理解

 この問題は、小文字の文字列を入力した Vasya が効果的に「こんにちは」と言うことができたかどうかを問うものです。 目的は、入力された文字列が正確に「hello」であるかどうかをチェックすることではなく、いくつかの文字 (おそらくゼロ) を削除してシーケンスを生成できるかどうかを確認することです。`h`、`e`、`l`、`l`、`o`順番に。 

入力は、1 ～ 100 の間の長さの単一の文字列です。出力は、そこから単語「hello」を抽出できる場合は「YES」、そうでない場合は「NO」のいずれかです。 

制約は非常に緩和されています。 と`n ≤ 100`制限時間は 1 秒で、すべてのサブシーケンスを調べる単純な解決策でも理論的には機能しますが、問題の本質は実際には文字列をスキャンしてターゲット シーケンスを探すことです。 単純なアプローチを騙す可能性のあるエッジ ケースには、文字が存在するものの順序が正しくない文字列が含まれます。`hlelo`、「hello」のすべての文字が含まれていますが、順序は保持されません。 もう 1 つのエッジ ケースは、最小限の入力です。`h`、明確に「NO」が出力されるはずです。 

## アプローチ

 ブルートフォース手法では、入力文字列のすべてのサブシーケンスを試して、それが「hello」に一致するかどうかを確認します。 ある長さの文字列の場合`n`、 がある`2^n`サブシーケンスは、`n = 100`、大まかに生産`10^30`小切手。 明らかに、このアプローチは原理的には正しいですが、実用的ではありません。 

重要な洞察は、すべてのサブシーケンスを明示的に考慮する必要はないということです。 文字列をスキャンする際に、「hello」の各文字を順番に一致させることができるかどうかだけを気にします。 これは貪欲なスキャンを示唆しています: インデックスを保持します`j`ターゲット単語「こんにちは」の場合。 入力文字列を走査する`s`左から右へ。 文字が一致するたびに`hello[j]`、増分`j`。 もし`j`"hello" (5) の長さに達すると、単語の検索に成功しました。 これは文字列の長さが線形であり、問​​題の逐次要件を直接エンコードします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | お(1) | 遅すぎる |
 | 貪欲なスキャン | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.初期化`target = "hello"`そしてインデックス`j = 0`現在探している「hello」の文字を追跡します。 
2. 各文字を反復処理します。`c`入力文字列内で`s`。 
3. もし`c`等しい`target[j]`、増分`j`。 これにより、一致させる必要がある次の文字に移動します。 他の文字は順序を乱すことができないため、自動的にスキップされます。 
4. 文字列をスキャンした後、次のことを確認します。`j`5 に等しい。一致する場合は「YES」を出力し、そうでない場合は「NO」を出力する。 

なぜ機能するのか: 貪欲なアプローチは、次の不変条件に依存します。`j`は常に、一致する必要がある「hello」の次の文字を指します。 文字が一致するたびに、インデックスが進みます。 間にある文字は、サブシーケンスの形成を妨げないため、無視されます。 これにより、次のことが保証されます。`j`5 に達すると、すべての文字が正しい順序で照合されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s = input().strip()
target = "hello"
j = 0

for c in s:
    if c == target[j]:
        j += 1
        if j == len(target):
            break

print("YES" if j == len(target) else "NO")
```コードは入力を読み取り、末尾の改行を削除します。 ポインタを維持します`j`「こんにちは」を通じて進捗状況を追跡します。 繰り返していくうちに`s`、増分します`j`現在のターゲット文字に一致するたびに。 終わりに達したら`target`、効率を上げるために早めに停止します。 最後に、すべての文字が一致した場合は「YES」を出力し、そうでない場合は「NO」を出力します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    s = input().strip()
    target = "hello"
    j = 0
    for c in s:
        if c == target[j]:
            j += 1
            if j == len(target):
                break
    return "YES" if j == len(target) else "NO"

# Provided sample
assert run("ahhellllloou") == "YES", "sample 1"

# Custom cases
assert run("hlelo") == "NO", "letters out of order"
assert run("h") == "NO", "single letter"
assert run("helicopterlo") == "YES", "interleaved extra letters"
assert run("aaaaa") == "NO", "no relevant letters"
assert run("hhheeellllooo") == "YES", "duplicates before matches"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | ハレロ | いいえ | 順序の強制 |
 | h | いいえ | 最小限の入力処理 |
 | ヘリコプター はい | 無関係な文字をスキップします。 
| ああああ | いいえ | 対象文字がない |
 | はぁぁぁぁぁぁぁぁ | はい | 複数の連続した一致を処理 |

 ## 特殊なケース

 のために`s = "h"`、アルゴリズムは 1 回反復され、参照されます。`h`マッチ`target[0]`、増分`j = 1`。 これ以上のキャラクターはいないのですが、`j < 5`したがって、出力は`NO`。 のために`s = "hhheeellllooo"`、アルゴリズムは増加します`j`次に必要な文字が一致する場合にのみ、重複をスキップします。 やっぱりキャラクターは、`j = 5`、正しく出力されています`YES`。 これらにより、貪欲スキャンが不十分な入力と反復的な入力の両方を正しく処理することが確認できます。
