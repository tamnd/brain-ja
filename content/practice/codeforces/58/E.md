 ## 解決策
 ## 問題の理解

 次の形式の単純な算術式を表す文字列が与えられます。`a+b=c`、 どこ`a`、`b`、 そして`c`は整数です。 Vasya 氏は、いくつかの数字を書き留めるのを忘れた可能性があると主張しています。つまり、左側と右側の数字は実数の部分列である可能性があります。 私たちの目標は「真の」数値を再構築することです`x`、`y`、 そして`z`となることによって`x+y=z`を確保しながら、`a`、`b`、 そして`c`～の部分列として現れる`x`、`y`、 そして`z`、 それぞれ。 の合計桁数も必要です。`x+y=z`最小限であること。 

問題の境界は絶対値が小さい (`1 ≤ a, b, c ≤ 10^6`)、これは、数百万のすべての可能な整数を反復する解は実行可能ですが、より指数関数的な複雑さを持つ解は失敗することを意味します。 これはまた、主な課題は計算速度ではなく、桁の配置とサブシーケンスの慎重な処理であることを示唆しています。 

明らかではないエッジ ケースには、最小長のソリューションで最上位桁の数値を拡張する必要があるシナリオが含まれます。 たとえば、入力が次の場合、`2+4=5`、最小限の解決策`21+4=25`に数字を追加するので機能します`a`そして`c`左側では、全長を不必要に長くすることなく正しい合計が得られます。 単に既存の数字を照合するか、ゼロを埋め込むだけという単純なアプローチでは、次のようなエラーが発生するため失敗する可能性があります。`2+4=5`、これは算術的に無効です。 

もう 1 つの注意が必要なエッジ ケースは、キャリーが桁間で伝播する場合です。 例えば、`1+9=1`なることができる`11+9=20`、合計を満たすために予期しない位置に数字が大きくなる場合があることを示しています。 

## アプローチ

 ブルートフォースアプローチでは、数字を挿入するあらゆる方法を試みます。`a`、`b`、 そして`c`有効な数字を形成するには`x`、`y`、 そして`z`そして、次のことを確認します`x+y=z`。 考えられる各数字の挿入を長さのシーケンスとして表すと`L`まで`10^6`、候補者の数は組み合わせ的に爆発的に増加します。 10^7 までの数値だけを試したとしても、すべての組み合わせを反復処理すると、`x`そして`y`最大 10^14 のチェックが必要になりますが、これは明らかに実行不可能です。 

重要な洞察は、この問題が、2 つの数値を最下位から最上位まで 1 桁ずつ加算する一方で、各桁シーケンスに対応する元の桁がサブシーケンスとして含まれていることを確認する動的計画問題に帰着できるということです。 数字を逆に考えることで、キャリーを自然に伝播させ、ポジションを追跡することができます。`a`、`b`、 そして`c`それは一致する必要があります。 DP 状態は、元の 3 つの数値の位置とキャリーを表し、遷移は次の桁の選択に対応します。`x`そして`y`形成と一致する`z`および一致するサブシーケンス。 これにより、必要な場合にのみ番号を拡張するため、検索スペースが大幅に削減され、最小の全長が保証されます。

 ## アルゴリズムのチュートリアル

 1. 入力を文字列に解析します。`a`、`b`、 そして`c`。 これらを逆にすると、最下位から最上位への桁ごとの加算が簡略化されます。 
2. DP テーブルを初期化します。`dp[i][j][k][carry]`は`True`ポジションに到達することが可能であれば`i`で`a`、`j`で`b`、 そして`k`で`c`与えられたキャリーで。 DP は、解を再構築するために選択された数字も保存します。 
3. すべての状態を反復処理する`(i, j, k, carry)`それは到達可能です。 それぞれについて、次の可能な数字をすべて試してください`d1`そして`d2`のために`x`そして`y`。 コンピューティング`d1 + d2 + carry = dsum`。 次の桁は`z`は`dsum % 10`、そして次のキャリーは`dsum // 10`。 
4. 次のことを確認します。`i < len(a)`それから`d1`マッチ`a[i]`(または余分な桁を許可するためにマッチングをスキップします)、同様に`b`そして`c`。 有効な遷移のみが DP テーブルに追加されます。 
5. テーブルを埋めた後、次のすべての桁を消費する到達可能な状態を見つけます。`a`、`b`、 そして`c`キャリーゼロ付き。 保存された数字の選択肢を使用してバックトラックして再構築する`x`、`y`、 そして`z`。 
6. 再構成された文字列を反転して最終的な解を取得します。ゼロ自体を除いて先頭にゼロがないことを確認します。 

機能する理由: DP は、すべてのステップで、選択された数字シーケンスが元の数値をサブシーケンスとして拡張し、加算特性を満たすことを強制します。 最下位桁からの加算をシミュレートし、キャリーを追跡することにより、アルゴリズムは最終的な数値の合計が正確であることを保証します。 DP はサブシーケンスの一致または伝播の伝達に必要な場合にのみ数値を拡張するため、最小の長さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

a, rest = input().strip().split('+')
b, c = rest.split('=')
a = a[::-1]
b = b[::-1]
c = c[::-1]

from functools import lru_cache

@lru_cache(None)
def dfs(i, j, k, carry):
    if i == len(a) and j == len(b) and k == len(c) and carry == 0:
        return "", "", ""
    for d1 in range(10):
        if i < len(a) and int(a[i]) != d1:
            continue
        for d2 in range(10):
            if j < len(b) and int(b[j]) != d2:
                continue
            s = d1 + d2 + carry
            d3 = s % 10
            nc = s // 10
            if k < len(c) and int(c[k]) != d3:
                continue
            res = dfs(i + (d1 == int(a[i]) if i < len(a) else 0),
                      j + (d2 == int(b[j]) if j < len(b) else 0),
                      k + (d3 == int(c[k]) if k < len(c) else 0),
                      nc)
            if res is not None:
                x, y, z = res
                return str(d1) + x, str(d2) + y, str(d3) + z
    return None

x, y, z = dfs(0, 0, 0, 0)
print(x[::-1] + '+' + y[::-1] + '=' + z[::-1])
```このソリューションでは、再帰的メモ化を使用して、有効な数字の配置を調べます。 サブシーケンス制約とキャリーの伝播を考慮して、数値ごとに 0 から 9 までのすべての桁を反復処理します。 微妙な選択には、ポジションが範囲内にある場合にのみ数字の一致をチェックすることや、ポジションを慎重に進めることが含まれます。`a`、`b`、`c`数字が元の部分列と一致する場合のみ。
