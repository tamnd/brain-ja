 ## 解決策
 ## 問題の理解

 公園は巨大なグリッドになっており、左下隅から開始して右上隅に到達する必要があります。 動きは明示的に制限されませんが、幾何学的に唯一重要なのは、すべての「危険ゾーン」を回避する開始から出口までの連続した経路が存在するかどうかです。 

各ファミリー メンバーは円形の領域を定義します。 コーギーがこれらの円のいずれかに入ると、すぐに捕らえられます。 コーギーは敵対的に行動すると想定されており、すべての円を避ける出口への道を見つけようとすることを意味します。 私たちの仕事は、これらの円形の領域が集合的に脱出を不可能にするような家族のサブセットを選択することです。 

したがって、本当の質問は次のとおりです。開始点から出口までのすべてのパスが少なくとも 1 つの円によってブロックされるようにするには、どのファミリー メンバーをアクティブ化すべきでしょうか?

 これは連続的な幾何学的接続問題ですが、円の数が少ないため、重要なのはこれをグラフ分離タスクに変換することです。 

制約は意図した構造を示します。 グリッド サイズは 10^9 までなので、平面をセルに離散化することは不可能です。 ただし、円の数は最大でも 1000 であるため、円と境界の間の交差および隣接性を推論することは可能です。 これは、グリッド上の点ではなく、幾何学的オブジェクト上のグラフを強く示唆しています。 

微妙な失敗例は、円が実際にパスをブロックせずに境界に「接触」しているだけである場合に発生します。 たとえば、境界線に接する円は、2 つの遮断領域を完全に接続しない限り、必ずしも交差点を遮断するとは限りません。 同様に、ブロックはエリア カバレッジではなく接続性に関するものであるため、「最大半径の円」の貪欲なサブセットを選択すると失敗する可能性があります。 

## アプローチ

 強引な解釈では、ファミリー メンバーのすべてのサブセットを試し、選択した円の和集合が (0, 0) から (N, M) までのすべてのパスをブロックするかどうかを確認します。 各サブセットについて、そのサブセット内のすべての円を回避する開始から終了までのパスが存在するかどうかを判断する必要があります。 これは、ディスクの結合の補数における接続性をチェックすることと同等であり、幾何学的領域推論または平面のきめ細かいサンプリングが必要になります。 空間を離散化したとしても、グリッドが大きすぎるため、単一のサブセットをチェックするだけでもコストが高くなります。 2^K 個のサブセットでは、これは完全に不可能です。 

重要な洞察は、視点を反転することです。 自由空間内の経路について考える代わりに、円と境界によって形成される障壁について考えます。 開始から終了までのパスは、円が正方形の 2 つの角を隔てる連続したブロック構造を形成していない場合にのみ存在します。 

これは、幾何学的オブジェクト間のグラフ接続問題としてモデル化できます。 各円はノードとして見ることができます。 2 つのノードの円が重なり合うか接触する場合、重なり合う円は連続したブロック領域を形成するため、接続されています。 さらに、正方形の境界に接触または交差する円は、仮想境界ノードに接続されます。 重要な観察は、境界接続を介して開始コーナーと出口コーナーを分離する接続された構造がある場合、正確に脱出は不可能であるということです。 

正方形から円までの 4 つの辺の間の接続性を追跡するグラフを作成します。 問題は、ブロック的な意味で左下の境界領域を右上の境界領域に接続する連結成分が存在するかどうかを判断することに帰着する。 次に、アクティブ化によってそのようなブロック コンポーネントが作成される最小数の円が必要になります。 K が小さいため、最小数を優先して、union-find または BFS ベースの状態拡張を使用して、最大 1000 ノードのグラフにわたる最短の選択問題としてこれを組み立てることができます。

各円のアクティブ化をコスト 1 の包含として扱い、オーバーラップを介して接続を伝播することにより、開始と分離の境界領域を接続する最小のサブセットを効果的に検索します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース サブセット | O(2^K · K · ジオメトリチェック) | O(K) | 遅すぎる |
 | グラフ + 最短アクティベーション / BFS オーバーステート | O(K^2 α(K)) | O(K^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 接続性にとって重要なのは重複と境界の相互作用のみであるため、各ファミリー メンバーをグラフ内のノードとして扱います。 これにより、連続ジオメトリの問題が離散的な相互作用に還元されます。 
2. 円のペアごとに、それらが交差しているか接触しているかを確認します。 中心間の距離が半径の合計以下の場合は、それらをエッジで接続します。 これは、2 つのキャッチされた領域が 1 つの連続したバリアを形成することをモデル化しています。 
3. 正方形の 4 つの辺を表す 4 つの仮想境界ノードを導入します。 各円について、各境界辺と交差するかどうかを確認します。 存在する場合は、円ノードをその境界ノードに接続します。 
4. 開始コーナー (0, 0) は左と下の境界に関連付けられ、終了コーナー (N, M) は上と右の境界に関連付けられます。 これら 2 つの境界グループが円コンポーネントを介して接続されると、エスケープはブロックされます。 
5. 次に、「開始境界グループ」を「終了境界グループ」にリンクする連結成分が存在するように選択する必要がある円の最小数が必要になります。 
6. BFS またはダイクストラのような検索を実行します。ここで、状態は円のサブセットを通って境界グループに到達することを表し、遷移は新しい円のアクティブ化とオーバーラップによる接続のマージに対応します。 各アクティベーションのコストは 1 です。 
7. 答えは、パスが開始境界グループと終了境界グループを接続する最小コストです。 そのような接続が不可能な場合は、-1 を返します。 

### なぜ効果があるのか

 重要な不変条件は、実行可能なブロッキング構成が、必要な境界領域にわたる円重なりグラフ内の連結成分に正確に対応することです。 サークルをアクティブにするたびに、既存のブロック コンポーネントを拡張するか、2 つのコンポーネントをマージします。 このグラフの接続性は、ブロックされた領域の幾何学的到達可能性を正確に反映しているため、有効な分離セットは接続されたサブグラフに対応し、BFS オーバー アクティベーション カウントでは、そのようなすべてのサブグラフのサイズが増加しながら探索されます。 これにより、2 つの境界グループを初めて接続するときに、最小数の円が使用されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def intersects(a, b):
    x1, y1, r1 = a
    x2, y2, r2 = b
    dx = x1 - x2
    dy = y1 - y2
    return dx*dx + dy*dy <= (r1 + r2) * (r1 + r2)

def touches_left(c):   return c[0] - c[2] <= 0
def touches_right(c, N): return c[0] + c[2] >= N
def touches_bottom(c): return c[1] - c[2] <= 0
def touches_top(c, M): return c[1] + c[2] >= M

def solve():
    N, M, K = map(int, input().split())
    circles = [tuple(map(int, input().split())) for _ in range(K)]

    adj = [[] for _ in range(K + 4)]
    LEFT, RIGHT, BOTTOM, TOP = K, K+1, K+2, K+3

    for i in range(K):
        x, y, r = circles[i]
        if touches_left(circles[i]):
            adj[i].append(LEFT)
            adj[LEFT].append(i)
        if touches_right(circles[i], N):
            adj[i].append(RIGHT)
            adj[RIGHT].append(i)
        if touches_bottom(circles[i]):
            adj[i].append(BOTTOM)
            adj[BOTTOM].append(i)
        if touches_top(circles[i], M):
            adj[i].append(TOP)
            adj[TOP].append(i)

    for i in range(K):
        for j in range(i + 1, K):
            if intersects(circles[i], circles[j]):
                adj[i].append(j)
                adj[j].append(i)

    start_nodes = [LEFT, BOTTOM]
    target_nodes = [RIGHT, TOP]

    dist = [[10**9] * (K + 4) for _ in range(K + 4)]
    dq = deque()

    for s in start_nodes:
        dist[s][s] = 0
        dq.append((s, s))

    while dq:
        u, root = dq.popleft()
        if u in target_nodes and dist[root][u] == dist[root][root]:
            return dist[root][u]

        for v in adj[u]:
            cost = dist[root][u] + (1 if v < K else 0)
            if cost < dist[root][v]:
                dist[root][v] = cost
                dq.append((v, root))

    return -1

def main():
    print(solve())

if __name__ == "__main__":
    main()
```コードはまず円間のオーバーラップ グラフを構築し、各円をそれが接触する境界ノードに接続します。 次に、BFS のようなプロセスは、境界関連のノードから開始して接続を伝播しようとします。 アイデアは、境界コンポーネントを接続するために必要な円の数を蓄積することです。 

コスト ロジックでは、円ノードにステップインするときに単位コストを割り当てますが、境界ノードは無料です。 これは、円を「使用されるブロッカー」として選択し、それらの接続された構造を通じて伝播することをモデル化します。 

状態がターゲット境界側に到達すると、検索は終了します。これは、開始領域と終了領域の間に完全なブロッキング チェーンが形成されたことを意味します。

 ### サンプル 1

 左と下の境界から開始して、円の接続を通じて右または上の境界に到達しようとします。

 このプロセスは、連続したブロックチェーンを形成するには 3 つの円が必要であることを示しています。 

これは、部分的なカバレッジでは不十分であり、接続されたバリアのみが重要であることを裏付けています。

| ステップ | 現在のノード | コスト | 新しい移行 |

 これは、1 つの円が完全な分離構造にまたがるという縮退のケースを示しています。

 ## 特殊なケース

 主なエッジ ケースは、円が境界を超えずに境界に正確に接触する場合です。 たとえば、(0, 5) を中心とし半径 5 の円は左側の境界に触れますが、必ずしも垂直方向の通行を妨げるわけではありません。 アルゴリズムは、円が実際に境界線と交差する場合にのみ、これを境界接続として扱います。接線は依然として幾何学的接触を意味するため、これは正しいことです。 

もう 1 つのエッジ ケースは、円がチェーン内で重なっているが、個々には境界に触れていない場合です。 たとえば、グリッドを横切る斜めの廊下を形成する一連の重なり合う円は、依然として重要です。これは、重なりの接続によりブロック領域の伝播が可能になるためです。 グラフ構築では、境界接触に関係なく、すべての交差するペアを接続することで、これを正しく処理します。 

最後のエッジ ケースは、単一の大きな円が (0,0) 付近から (N,M) に向かって広がっているものの、両方の境界に明示的に到達していない場合に発生します。 交差ルールにより、そのような円が幾何学的に接触するすべての境界に確実に接続され、ブロック力の過小評価が防止されます。
