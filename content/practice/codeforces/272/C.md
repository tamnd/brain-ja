 ## 解決策
 ## 問題の理解

 問題は次のような階段を提示します。`n`ステップ。各ステップは、減少しない配列で指定された特定の高さを持ちます。`a`。 ディマは箱を階段に垂直に投げます。 各ボックスには幅があります`w`そして高さ`h`、最初の部分をカバーします`w`階段。 ボックスは、そのボックスがカバーする最も高い階段の最上部、またはそれらの階段の 1 つにすでに着地しているボックスの最上部に着地します。 必要な出力は、投げられた順序での各ボックスについて、着地後のボックスの底の高さです。 

重要な制約は次のとおりです。`n`そして`m`それぞれ最大 100,000、高さは最大 10 億まで可能です。 これは、すべての階段をすべてのボックスごとに検査するアプローチを意味します。`O(n*m)`操作が遅すぎる可能性があります。 各ボックスの階段の繰り返しスキャンを減らす必要があります。 考慮すべきエッジケースとしては、複数のボックスが同じ最初の階段に着地する場合、ボックスに幅がある場合などがあります。`1`、または階段の高さが等しい場合。 

単純な実装では、最初の部分がループする可能性があります。`w`各ボックスの階段を作成し、現在の最大高さを計算し、ボックスの高さを追加して、高さを更新します。 これは論理的には正しいですが、次の場合には実行不可能になります。`n`そして`m`大きいです。 もう 1 つの微妙な点は、累積を正しく処理することです。ボックスが積み重なるにつれて、高さを動的に追跡する必要があります。 

## アプローチ

 ブルート フォース ソリューションは、単純に最初のコードをループします。`w`各ボックスの階段を作成し、既存の最大の高さを見つけて印刷し、影響を受ける階段を次のように増分します。`h`。 これは、ボックスが常に階段または前のボックスの最大値に着地するため機能しますが、複雑さは次のとおりです。`O(n*m)`最悪の場合。 と`n`そして`m`10^5 までは 10^10 の操作が必要になる可能性があり、これでは遅すぎます。 

重要な洞察は、すべての階段の高さを個別に追跡する必要がないということです。 最初に到達した最も高い点だけが必要です`w`ボックスが着地するたびに階段が上がります。 これまでカバーした階段の中で最も高い頂上を反映する単一の「現在の最大高さ」変数を維持できます。 ボックスが落下すると、その底は現在の最大値で着地し、その後ボックスの高さだけ最大値を増やします。 これにより、複雑さが軽減されます。`O(m)`なぜなら、ボックスごとにすべての階段を反復処理する必要がなくなったからです。 

これが機能する理由は、すべての階段の高さが減少しないためです。 最初のカバー`w`階段には常に階段が含まれます`w`、少なくともその前の階段と同じ高さです。 これまでにボックスが到達した高さのグローバル最大値を維持することで、すべての階段を個別に追跡することなく、新しいボックスの最も高い接地面を正確にシミュレートします。

 ## アルゴリズムのチュートリアル

 1. 階段の数を読み取る`n`そして配列`a`最初の階段の高さ。 
2. 変数を初期化する`current_max`ゼロに。 これにより、以前に着陸したすべてのボックスの中で最も高い点が追跡されます。 
3. 箱の数を読み取ります`m`。 
4. 各ボックスの幅を読み取ります。`w`と高さ`h`。 
5. 着陸高さを最大値として計算します。`current_max`と高さ`w`- 番目の階段 (ボックスがカバーする最も高い階段)。 これにより、ボックスが正しいベースに着地することが保証されます。 
6. 着陸高さを印刷します。 
7. インクリメント`current_max`箱の高さによって`h`このボックスが着地した後の新しい最大高さを反映します。 
8. すべてのボックスに対して繰り返します。 

なぜ効果があるのか​​: 各ステップで、`current_max`は常に、次のボックスで覆われている階段の中で、任意の構造物 (階段または以前に着陸したボックス) の最も高い最上部を表します。 下り階段ではないので、階段`w`階段1から最大までを保証`w`。 ボックスの高さを追加すると、不変条件を維持しながら、後続のボックスの最高点が更新されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))
m = int(input())

current_max = 0
for _ in range(m):
    w, h = map(int, input().split())
    # stair index is 0-based
    landing_height = max(current_max, a[w-1])
    print(landing_height)
    current_max = landing_height + h
```このコードでは、`current_max`最初の点の中で最も高い点を追跡します`w`各ボックスの後に階段があります。 アクセスする`a[w-1]`Python の配列は 0 から始まるためです。 着陸高さを出力した後、更新します`current_max`後続のボックスの上部を考慮してボックスの高さを追加します。 この実装により、階段を繰り返しスキャンすることが回避され、各ボックスが正しく着地することが保証されます。
