 ## 問題の理解

 サイズのセットの空ではないすべてのサブセットの組み合わせの合計を評価するように求められます。$N$。 すべてのサブセットは、そのサイズのみに依存するコストに寄与します。$x$要素、そのコストは$x^k$。 最終的な答えは、空のものを除くすべての可能なサブセットにわたるこれらのコストの合計です。 

問題を読み取るためのより便利な方法は、個々のサブセットのことを忘れて、サブセットのサイズの観点から考えることです。 各整数について$x$、まさにあります$\binom{N}{x}$サイズのサブセット$x$、そしてそれぞれが貢献します$x^k$。 したがって、答えはサブセット サイズの加重合計になります。 

制約$N \le 10^9$サブセット、または最大のすべてのサブセット サイズを反復するアプローチは直ちに除外されます。$N$。 まで繰り返しても$N$不可能です。 唯一実行可能なループは、以下に依存するものです。$k$、 以来$k \le 5000$。 これは、最終的な式を多項式恒等式に変換する必要があることを強く示唆しています。$O(k)$または$O(k^2)$仕事は残っています。 

素朴な推論における最も脆弱な間違いは、計算しようとすることです$\sum \binom{N}{x} x^k$成長を制御せずに二項恒等式を直接使用します。 もう 1 つのよくある失敗は、権限を拡大することです。$x$そして、変換が大規模にわたって正確さを維持することを保証せずに、それらを独立して処理します。$N$。 たとえば、次のような階乗項を直接計算しようとすると、$N!$それは不可能ですので$N$大きすぎます。 

2 番目の微妙なエッジ ケースは、空ではないサブセットのみが含まれるという誤解です。 空のサブセットにはサイズがあります$0$、そしてそれ以来$0^k = 0$のために$k \ge 1$、合計には影響しません。 ただし、ID を誤って書き換えて、次のものが含まれる場合、$x=0$注意せずに使用すると、中間ステップで不正確な一定の調整が行われる可能性があります。 

## アプローチ

 ブルートフォースアプローチではサブセットサイズを列挙します$x$から$1$に$N$、計算する$\binom{N}{x}$、蓄積します$\binom{N}{x} x^k$。 二項係数が効率的に計算されたとしても、最大で反復処理が行われます。$10^9$不可能です。 複雑さは基本的に線形です$N$、すでに制限時間を数桁超えています。 

重要な観察は、この式には次のことが含まれるということです。$x^k$、次数の固定多項式$x$。 形式の合計$\sum \binom{N}{x} f(x)$どこ$f(x)$多項式は、スターリング数と下降階乗を使用して書き換えることができます。 これにより、依存関係が変換されます。$x^k$二項和が大幅に単純化される基底に変換します。 

私たちは、あらゆるべき乗が第 2 種スターリング数を使用して記述できるという恒等式を使用します。$$x^k = \sum_{j=0}^{k} S(k, j)\,(x)_j$$どこ$(x)_j = x(x-1)\cdots(x-j+1)$は下降階乗です。 

これを元の合計に代入すると、合計を交換できます。 重要な単純化は次のとおりです。$$\sum_{x} \binom{N}{x}(x)_j = (N)_j 2^{N-j}$$サブセットを選択してから注文するため、$j$区別された要素は選択に対応します$j$からの要素$N$そして残りをそのままにしておきます$N-j$要素は自由に変化します。 

これにより、問題はスターリング数の計算に軽減されます。$k$、階乗に似た長さの積$k$、およびべき乗剰余演算。

 ## アルゴリズムのチュートリアル

 この問題を、二項係数ときれいに相互作用する多項式基底の合計に書き直します。 

1. 第 2 種スターリング数を計算する$S(k, j)$みんなのために$0 \le j \le k$。 これは再帰を使用して行われます$S(n, j) = j \cdot S(n-1, j) + S(n-1, j-1)$。 このステップでは、通常のべき乗を二項構造と一致する降下階乗形式に変換します。 
2. それぞれについて$j$、下降階乗を計算します$(N)_j = N \cdot (N-1) \cdots (N-j+1)$モジュロ$10^9+7$。 これは選択と注文を表します$j$からの要素$N$-要素の宇宙。 
3. コンピューティング$2^{N-j}$モジュロ$10^9+7$。 指数が大きいので、剰余を減らします$10^9+6$係数が素数であるため、フェルマーの定理を使用します。 
4. それぞれについて$j$、寄与を計算します$S(k,j) \cdot (N)_j \cdot 2^{N-j}$、それを答えに追加します。 
5. 和の剰余を返します$10^9+7$。 

なぜこれが機能するのかは、基盤の構造的な変化に関係しています。 機能$x^k$は下降階乗に基づいて書き換えられ、二項和はこの基底では単純な乗算となる線形演算子として機能します。 各学期$(x)_j$事実上「選択」する$j$サイズの宇宙からの要素$N$、残りの要素は、$2^{N-j}$要素。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MOD_EXP = MOD - 1

def mod_pow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve():
    N, k = map(int, input().split())

    if k == 0:
        # only x^0 = 1, but problem guarantees k>=1 in constraints
        return 0

    # Stirling numbers S[n][j]
    S = [[0] * (k + 1) for _ in range(k + 1)]
    S[0][0] = 1

    for i in range(1, k + 1):
        for j in range(1, i + 1):
            S[i][j] = (S[i - 1][j - 1] + j * S[i - 1][j]) % MOD

    ans = 0

    falling = 1
    for j in range(0, k + 1):
        if j > 0:
            falling = falling * (N - (j - 1)) % MOD

        if S[k][j] == 0:
            continue

        exp = (N - j) % MOD_EXP
        pw = mod_pow(2, exp)

        ans = (ans + S[k][j] * falling % MOD * pw) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```実装は派生を直接反映します。 Stirling DP は基底変更係数を構築します。 下降階乗は再計算を避けるために段階的に累積されます。 指数の削減が不可欠である理由は、$N$できる$10^9$、累乗はサイクル長内に収まる必要があります$MOD-1$。 

実装の微妙な点は、下降階乗の乗算の順序です。 常に現在のものを使用する必要があります$N-(j-1)$、オーバーフローを回避し、複雑さを線形に保つために、最初から再計算されません。$k$。

 ## 特殊なケース

 のために$N = 1$、空ではないサブセットが 1 つだけ存在します。 アルゴリズムは 1 つに縮小されます。$j = 0$そして$j = 1$チェックしますが、それだけです$j=1$より高いスターリング値が消えるため寄与します。 下降階乗は正しく 1 と評価され、べき乗は次のようになります。$2^0$、正しいものを生成します$1^k$。
