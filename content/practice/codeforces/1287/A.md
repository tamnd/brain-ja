 ## 解決策

 ## 問題の理解

 生徒の独立した行がいくつか与えられており、各行は 2 文字だけを含む文字列で記述されています。 1 人のキャラクターはすでに怒っている生徒を表し、もう 1 人のキャラクターは落ち着いている生徒を表します。 行は単一の線に配置され、時間は離散的なステップで変化します。 あらゆる段階で、現在怒っている生徒はそれぞれ、目の前の生徒に怒りを広めようとします。 その瞬間に隣人がまだ冷静であれば、彼らは怒ります。 

重要な点は、このプロセスが波状に繰り返されるということです。 生徒が怒ると、すぐに怒りを広める次のステップに参加し始めます。 課題は、プロセス全体を無制限にシミュレートすることではなく、生徒が冷静から怒りに移行する最後の瞬間を判断することです。 

制約は非常に小さく、各行の生徒数は最大 100 人、テスト ケースの数は最大 100 です。 これは、2 次またはわずか 3 次の挙動であっても容易に制限内に収まるため、最悪の場合でも時間や位置を超えた直接シミュレーションがすでに実行可能であることを意味します。 ただし、プロセスは十分に構造化されているため、テスト ケースごとに 1 回のリニア スキャンに減らすことができます。 

いくつかの微妙なケースについては、覚えておく価値があります。 怒る生徒がまったくいない場合は何も変わらず、答えはゼロになります。 すべての生徒がすでに怒っている場合、やはり時間 0 以降は何も起こりません。 怒っている生徒たちが穏やかなブロックで隔てられている場合、さらに興味深い状況が現れます。 たとえば、次のようなパターンで`A P P A`、右端の怒っている学生は左に広がり、左の怒っている学生は右に広がり、中央の領域は両側から感染します。 一方向のみに注目する単純なアプローチでは、その収束効果を見逃してしまいます。 

## アプローチ

 プロセスについて考える簡単な方法は、分ごとにシミュレーションすることです。 各ステップで文字列をスキャンし、現在の設定に基づいて怒るべきすべての生徒にマークを付けます。 変化がなくなるまで繰り返します。 これは定義に正確に従っているため、正しいです。つまり、毎分、現在怒っている生徒だけが近隣の生徒に影響を与えるのです。 

このシミュレーションの問題は、終わり近くで怒っている生徒 1 人を除いて弦が完全に落ち着いているときに顕著になります。 最悪の場合、一方の端にいる 1 人の怒っている生徒がもう一方の端に到達するまでに O(n) 歩かかり、各ステップで文字列全体がスキャンされます。 これにより、テスト ケースあたり O(n²) になります。 生徒が 100 人いる場合、これでも許容できますが、不必要なオーバーヘッドが発生し、概念的には拡張できません。 

重要な観察は、怒りが恣意的に伝播するものではないということです。 各ポジションは、方向に応じて、その左側または右側ですでに怒っている最も近い生徒からどのくらい離れているかのみを考慮します。 時間の変化をシミュレートする代わりに、すべての冷静な生徒について、彼らが怒涛の波に達するまでにどれくらいの時間がかかるかを計算することができます。 答えは単にこれらの到着時間の最大値です。 

これにより、問題は、両方向で最も近い最初の「A」までの距離を見つけることに軽減されます。 これらの距離を計算するには、左から右への 1 回のパスと、右から左への 1 回のパスで十分であり、最後のアクティブ化時間は、元々穏やかだったすべてのポジションの中で最大になります。

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理し、怒りがどのくらいの速さであらゆる立場に伝わるかを計算します。 

1. 文字列を数値配列に変換します。怒っている生徒は時間 0 ソースとしてマークされ、穏やかな生徒は最初は不明です。 これにより、状態ではなく距離の観点から推論できるようになります。 
2. 左から右にスイープし、怒っている生徒が最後に目撃された位置を追跡します。 穏やかな生徒に出会ったとき、最後に怒った生徒から何歩離れているかを計算できます。 これにより、左側からの到着時刻の候補が得られます。 
3. 右から左にスイープし、同じロジックを繰り返します。 今回は、右側で最も近い怒っている学生を追跡し、右側からの到着時刻の候補を生成します。 
4. 各位置について、実際に怒る時間は、左側と右側の到着時間の最小値です。 これは、より速い波がいつ状態を変えるかを決定するという事実を反映しています。 
5. 最終的な答えは、変化が起こる最後の瞬間を尋ねられるため、最初は落ち着いていたすべての生徒のポジションごとの時間の最大値です。 

中心的な考え方は、どの方向からでもできる限り早い波がすべての生徒に届くということです。 到着時刻がローカルで判明すると、グローバルな答えは、そのような到着が最も遅い時間だけになります。 

不変条件は、各スイープの後、すべての位置が片側からの可能な限り最良の影響時間を認識しており、両方のスイープを組み合わせることで、考えられるすべての伝播パスを捕捉するということです。 怒りは単位時間当たり隣接する位置にのみ広がるため、影響の経路はいずれも最初の「A」から始まる必要があり、その最短経路はこの 1 次元レイアウトでは常に直線に沿っています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()

        INF = 10**9
        left = [INF] * n
        right = [INF] * n

        last = -1
        for i in range(n):
            if s[i] == 'A':
                last = i
                left[i] = 0
            elif last != -1:
                left[i] = i - last

        last = -1
        for i in range(n - 1, -1, -1):
            if s[i] == 'A':
                last = i
                right[i] = 0
            elif last != -1:
                right[i] = last - i

        ans = 0
        for i in range(n):
            if s[i] == 'P':
                t_arrive = min(left[i], right[i])
                ans = max(ans, t_arrive)

        print(ans)

if __name__ == "__main__":
    solve()
```この実装では、2 つの補助配列を使用して、各側から最も近い最初の怒っている生徒までの距離を保存します。 左から右へのパスは、怒りが左から各ポジションにどれだけ早く到達するかを示し、右から左へのパスは反対方向に対しても同じことを行います。 少なくとも 1 つの「A」がすでに表示されている場合にのみ距離を更新します。それ以外の場合はまだソースが存在しないためです。 

最後のループは、すでに怒っている生徒を無視します。生徒は時間 0 から開始され、最後のアクティブ化の瞬間には寄与しないからです。 落ち着いた生徒の場合、最も早い到着時間を計算し、すべてのポジションの最大値を追跡します。

 ## 特殊なケース

 のような文字列の場合`PPPPP`、最初の怒りの原因はありません。 どちらのスイープでもすべての距離は無限大のままであり、状態変化がまったく起こらないため、最終的な答えはゼロのままです。 

のような文字列の場合`AAAA`、すべての学生は時間ゼロの時点ですでにアクティブです。 初期状態以降は遷移が発生しないため、新たに感染した生徒の最大アクティブ化時間もゼロになります。 

のような構成の場合`PPAPP`、単一の中央ソースが対称的な拡張を生成します。 左スイープと右スイープはどちらも、隣接する位置の距離 1 と左端の位置の距離 2 を正しく計算し、新しくアクティブ化された生徒の最大値は 1 で、シングルステップの伝播ルールと一致します。
