 ## 解決策
 ## 問題の理解

 2 つの配列が与えられています。`a`そして`b`、両方の長さ`n`。 これらの配列から、次の有向グラフを構築するように求められます。`n`頂点。 頂点からエッジがある`u`頂点へ`v`（のために`u != v`) 違いがある場合`a[u] - a[v]`以上です`b[u] - b[v]`。 このグラフを構築した後、すべての「強い頂点」を識別したいと考えます。 頂点からグラフ内の他のすべての頂点への有向パスが存在する場合、その頂点は強力です。 

入力は複数のテスト ケースで構成され、その合計は`n`すべてのテスト ケースの数は最大 200,000 です。 この境界から、頂点のすべてのペアを明示的に調べる単純なアプローチでは次のことがすぐにわかります。`O(n^2)`テストケースあたりの時間が遅すぎます。 と`n`最大 2·10^5、おおよその解が必要です。`O(n log n)`または`O(n)`テストケースあたりの時間。 

注意すべきエッジケースは、すべての頂点が相互に到達可能な場合です。たとえば、次のような場合です。`a`そして`b`どちらも増加シーケンスです。 この場合、どの頂点も強いです。 1 つの頂点が著しく高い場合、別の微妙な状況が発生します。`a[i]`に対して`b[i]`他人と比較して。 それが支配し、唯一の強力な頂点になる可能性があります。 例えば、`a = [1, 2, 3]`そして`b = [1, 1, 1]`最後の頂点のみを強度として生成します。 

## アプローチ

 ブルートフォースアプローチでは、すべてのペアに対して反復処理が行われます。`(u, v)`そして有向エッジを明示的に構築します。 その後、BFS または DFS を使用して各頂点から到達可能性チェックを実行できます。 これは問題ステートメントの直後にあるため正しいですが、次のことが必要です。`O(n^2)`テスト ケースごとの操作数は、最悪の場合 4·10^10 に達する可能性があります。 これでは遅すぎます。 

重要な観察は、エッジ条件を再定式化することです。 不平等`a[u] - a[v] >= b[u] - b[v]`次のように書き換えることができます`(a[u] - b[u]) >= (a[v] - b[v])`。 示す`c[i] = a[i] - b[i]`。 次に、からのエッジ`u`に`v`いつでも存在します`c[u] >= c[v]`。 これにより、構造が明らかになります: より高い頂点を持つ`c[i]`より低い頂点に到達できる`c[i]`。 したがって、最も強い頂点は、最大値を持つ頂点です。`c[i]`価値。 これらの頂点は、それ以下のすべての頂点に到達できます。`c[i]`、および小さい頂点`c[i]`それより大きい頂点には到達できません`c[i]`。 この洞察により、問題は最大値の計算に分解されます。`c[i]`そしてどのインデックスがそれを達成するかを特定します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n^2) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースごとに配列を読み取ります。`a`そして`b`。 
2. 補助配列を計算する`c`どこ`c[i] = a[i] - b[i]`。 
3. 最大値を求める`max_c`で`c`。 
4. すべてのインデックスを特定する`i`どこ`c[i] == max_c`。 これらのインデックスは強い頂点に対応します。 
5. 強い頂点の数とそのインデックスのリストを昇順で出力します。 

これが機能するのは、次の条件があるためです。`c[u] >= c[v]`頂点が最大値であることを保証します。`c`他のすべてに到達できます。 小さい頂点`c`それより大きい頂点には到達できません`c`以来`c[u] < c[v]`不等式に失敗するので、強くなることはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    c = [a[i] - b[i] for i in range(n)]
    max_c = max(c)
    
    strong = [i + 1 for i in range(n) if c[i] == max_c]
    print(len(strong))
    print(*strong)
```このソリューションは、まずテスト ケースの数を読み取ります。 テストケースごとに配列を読み取ります。`a`そして`b`そして計算します`c[i] = a[i] - b[i]`。 の最大値`c`どの頂点が強いかを決定します。 この最大値を達成する頂点の 1 から始まるインデックスを保存し、結果を出力します。 実装は複数のテスト ケースを正しく処理し、順序を保持します。 

## 実用的な例

 **サンプル 1**

 入力配列:`a = [3, 1, 2, 4]`

`b = [4, 3, 2, 1]`コンピューティング`c = a - b = [-1, -2, 0, 3]`。 

最大`c`は`3`、インデックスでのみ達成されます`4`。

 | 1 | 3 | 4 | -1 |
 | 2 | 1 | 3 | -2 |
 | 3 | 2 | 2 | 0 |
 | 4 | 4 | 1 | 3 |

 強力な頂点:`[4]`。 

**サンプル 2**

 入力配列:`a = [1, 2, 4, 1, 2]`

`b = [5, 2, 3, 3, 1]`コンピューティング`c = [-4, 0, 1, -2, 1]`。 

最大`c`は`1`、インデックスで達成`3`そして`5`。 

| 私 | a[i] | b[i] | c[i] |
 | --- | --- | --- | --- |
 | 1 | 1 | 5 | -4 |
 | 2 | 2 | 2 | 0 |
 | 3 | 4 | 3 | 1 |
 | 4 | 1 | 3 | -2 |
 | 5 | 2 | 1 | 1 |

 強力な頂点:`[3, 5]`。
