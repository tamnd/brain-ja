 ## 解決策
 ## 問題の理解

 整数の配列が与えられ、各グループの合計が同じパリティ (両方とも偶数、または両方とも奇数) を持つように、それを 2 つの空でないグループに分割できるかどうかを決定する必要があります。 各グループには少なくとも 1 つの要素が含まれている必要があります。 入力は複数のテスト ケースで構成され、それぞれの長さが 2 ～ 50 の配列と 1 ～ 50 の範囲の要素を持ちます。 

出力は各テスト ケースの単純な「YES」または「NO」で、そのような色付けが可能かどうかを示します。 配列の長さが小さい (最大 50) ため、大規模な最適化は必要ありませんが、n が指数関数的になるすべてのパーティションの総当たり列挙は避ける必要があります。 

すべての数値が同じパリティである場合、明らかではないエッジケースが発生します。 たとえば、配列`[2,4]`は偶数しかありません。 2 つのグループに分割すると、常に両方の合計が偶数になり、パリティ条件が満たされます。 対照的に、配列`[1,2]`には奇数と偶数が 1 つずつあるため、分割すると異なるパリティの合計が生成され、答えは「NO」になります。 通常、少なくとも 1 つの奇数要素と 1 つの偶数要素を含む配列の方が柔軟性が高くなります。 

## アプローチ

 ブルート フォース ソリューションでは、配列の可能なすべての分割を 2 つの空でないグループに分けて試行し、合計のパリティをチェックします。 n 個の要素があると、$2^n - 2$空でない分割の可能性。 n=50 の場合、これはおよそ$10^{15}$、1秒では実現不可能です。 

重要な洞察は、パリティの動作を観察することで得られます。 2 を法とする和は、奇数の数のみに依存します。 配列に少なくとも 1 つの奇数要素と少なくとも 1 つの偶数要素が含まれている場合、両方のグループの合計が同じパリティになるようにそれらを分割することが常に可能です。 すべての要素が偶数の場合、空でない分割は偶数の合計を生成し、条件を満たします。 すべての要素が奇数の場合、合計は奇数であり、空ではない 2 つのグループに分割すると、1 つの奇数の合計と 1 つの奇数の合計から奇数を引いた奇数 (偶数) が生成されるため、パリティは異なり、「NO」が正しいです。 

したがって、問題は奇数要素と偶数要素をカウントすることに帰着します。 配列に奇数要素と偶数要素の両方が含まれている場合、またはすべての要素が偶数である場合、答えは「YES」です。 すべての要素が奇数で、n > 1 の場合、答えは「いいえ」です。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、配列の長さ n と配列 a を読み取ります。 
2. 奇数要素と偶数要素のカウンタを初期化します。 
3. a の各要素を繰り返します。 奇数の場合は、奇数カウンタをインクリメントします。 それ以外の場合は、偶数カウンタをインクリメントします。 
4. 条件を確認します。奇数カウントと偶数カウントの両方が少なくとも 1 であれば、「YES」を出力します。 
5. すべての要素が偶数の場合、「YES」を出力します。 
6. すべての要素が奇数で、n > 1 の場合、「NO」を出力します。 

これが機能する理由: 合計のパリティは、各グループ内の要素のパリティにのみ依存します。 各パリティの少なくとも 1 つの要素があると、必要に応じて合計のバランスをとることができます。 偶数のみの配列は常に同じパリティの合計を生成しますが、奇数のみの配列は空ではない 2 つのグループに分割すると常に等しくないパリティの合計を生成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    odd = sum(1 for x in a if x % 2)
    even = n - odd
    if odd and even:
        print("YES")
    elif even == n:
        print("YES")
    else:
        print("NO")
```このコードは奇数と偶数をカウントし、アルゴリズムで概説されている条件を適用します。 使用する`sum(1 for x in a if x % 2)`手動による反復を回避し、コードを簡潔に保ちます。 境界ケースは自然に処理されます。すべての偶数要素を持つ配列は「YES」を返し、すべての奇数要素を持つ配列は「NO」を返します。

 ## 特殊なケース

 のために`[1,3]`、どちらの数値も奇数です。 カウントすると、奇数 = 2、偶数 = 0 となります。 条件`odd and even`は誤りです、`even == n`は false なので、正しく "NO" が出力されます。 のために`[2,4]`、奇数=0、偶数=2。`even == n`true であるため、出力は「YES」になります。 奇数と偶数が混在する配列。次のようになります。`[1,2,3]`、 満足する`odd and even`したがって、出力は「YES」になります。 このアルゴリズムは、特別な場合の分岐を行わずに、すべての境界状況を自動的に処理します。
