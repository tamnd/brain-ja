 ## 解決策
 ## 問題の理解

 同じ色の 3 つの区間が「三重重複パターン」を形成しないように、数直線上の区間の集合に色を付けるように求められます。 より具体的には、ある時点で各ペアが重なり合う同じ色の区間が 3 つ存在し、1 番目が 2 番目と交差し、2 番目が 3 番目と交差し、1 番目が 2 番目を介して 3 番目と間接的に交差するチェーンが形成されている場合、そのカラーリングは無効になります。 各間隔には開いた終点または閉じた終点があり、それが終点で重複が発生するかどうかに影響します。 目標は、そのような無効な 3 つの重なりを回避するために必要な最小限の色の数を見つけることです。 

入力により、範囲内の座標を含む最大 1000 の間隔が得られます。$[-10^5, 10^5]$。 これは十分小さいので、$O(n^2)$あるいは、もう少し悪いアプローチも可能です。 この問題は、どの区間も別の区間に完全に含まれないことを保証します。つまり、すべての区間には、他の区間にはない少なくとも 1 つの点があります。 この制限により、自動トリプルオーバーラップを引き起こす同一間隔などの一部の特殊なケースが排除されます。 

明らかではないエッジ ケースには、エンドポイントで接触する間隔が含まれます。 例えば、$[1,2)$そして$(2,3]$1 つ目は 2 を除外し、2 つ目は 2 を除外するので重複しませんが、$[1,2]$そして$[2,3]$別の特殊なケースは、間隔の小さな集合です。 区間が 2 つしかない場合、トリプルは存在できないため、答えは常に 1 になります。 単一点の間隔。たとえば、$[5,5]$、オーバーラップを正しく判断するには、慎重な取り扱いも必要です。 

## アプローチ

 ブルートフォースアプローチでは、間隔の可能なすべての色付けを試し、同じ色のトリプルが無効な重複を形成しているかどうかを確認します。 このアプローチは理論的には正しいですが、次のような場合にはまったく実行できません。$n = 1000$色の数が飛躍的に増えるからです。 固定されたカラーリングについてすべてのトリプルをチェックすることさえ$O(n^3)$、それは約です$10^9$最悪の場合の運用。 

より高速なソリューションのための重要な洞察は、間隔構造そのものから得られます。 同じ色の 3 つの間隔が三重の重なりを形成することを避けるだけで済みます。 この問題は、よく知られた組み合わせの事実に帰着します。開始点または終了点で間隔を並べ替える場合、任意の点で重複する間隔の最大数によって、必要な色の数が決まります。 言い換えれば、3 つ以上の間隔に点が含まれていない場合は、1 色で十分です。 点がちょうど 3 つの間隔に含まれる場合、少なくとも 2 つの色が必要です。 間隔が別の間隔に完全に含まれないという制限により、任意の点での最大重複が最大 2 であることが保証されます。したがって、常に 1 色または 2 色のいずれかを使用して、きれいな色付けを行うことができます。 ある間隔が他の 2 つの間隔と重複しているかどうかを確認するだけで済みます。 その場合は 2 色が必要です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n) | 遅すぎる |
 | 最適 (最大オーバーラップチェック) | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力間隔を解析し、終点を開始終点と閉終点を考慮した数値表現に変換します。 各間隔をペアとして表現します`(start, end)`オーバーラップを正しく区別するために、オープンエンドポイントのイプシロンをわずかに調整します。 
2. 間隔を開始座標で並べ替えます。 これにより、どの間隔も終了前に開始する間隔のみを重複させることができるため、単一パスで重複する間隔を確認することが容易になります。 
3. カウンタを初期化する`max_overlap`ゼロと掃引線構造 (たとえば、現在アクティブな間隔の終点の配列)。 
4. ソートされた間隔を繰り返します。 間隔ごとに、現在の間隔の開始前に終了する間隔をアクティブ セットから削除します。 アクティブ セットのサイズは、この時点で現在の間隔と重複する間隔の数を表します。 
5.アップデート`max_overlap`現在の値とアクティブ セットのサイズ + 1 (現在の間隔を含む) の間の最大値。 
6. すべての間隔を処理した後、最小色の数を決定します。`max_overlap <= 2`、1色で十分です。 それ以外の場合、ある点が 2 つの間隔に含まれており、その点に 3 番目の間隔を追加するには 2 番目の色が必要になるため、2 つの色が必要になります。 

不変条件とは、`max_overlap`任意の点で、任意の座標で交差する間隔の最大数をカウントします。 問題の制約により、`max_overlap`「完全な封じ込めなし」ルールに違反しない限り 2 色を超えることはできないため、1 つまたは 2 つの色で十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def parse_interval(s):
    left_inclusive = s[0] == '['
    right_inclusive = s[-1] == ']'
    s = s[1:-1]  # strip brackets
    l, r = map(int, s.split(','))
    # adjust open intervals slightly to handle overlap checks
    if not left_inclusive:
        l += 0.1
    if not right_inclusive:
        r -= 0.1
    return (l, r)

n = int(input())
intervals = [parse_interval(input().strip()) for _ in range(n)]

# Sort by start point
intervals.sort()
active = []
max_overlap = 0

for l, r in intervals:
    # Remove intervals that end before current start
    active = [end for end in active if end > l]
    active.append(r)
    max_overlap = max(max_overlap, len(active))

# Minimum colors required is 1 if max_overlap <=2, else 2
print(1 if max_overlap <= 2 else 2)
```このソリューションでは、最初に間隔表記を数値範囲に変換し、開いた端点と閉じた端点を慎重に処理します。 最大オーバーラップを計算するために、アクティブな間隔の動的なリストを維持します。 イプシロンを使用すると、開いた端と閉じた端が正しく処理され、誤ったオーバーラップ カウントが防止されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    def parse_interval(s):
        left_inclusive = s[0] == '['
        right_inclusive = s[-1] == ']'
        s = s[1:-1]
        l, r = map(int, s.split(','))
        if not left_inclusive: l += 0.1
        if not right_inclusive: r -= 0.1
        return (l, r)
    intervals = [parse_interval(input().strip()) for _ in range(n)]
    intervals.sort()
    active = []
    max_overlap = 0
    for l, r in intervals:
        active = [end for end in active if end > l]
        active.append(r)
        max_overlap = max(max_overlap, len(active))
    return str(1 if max_overlap <= 2 else 2)

# Provided sample
assert run("2\n[1,2)\n(3,4]\n") == "1"

# Minimum-size input
assert run("1\n[0,0]\n") == "1"

# Intervals with max overlap 2
assert run("3\n[1,2]\n[1,3]\n[2,3]\n") == "1"

# Intervals requiring 2 colors
assert run("3\n[1,2]\n[1,3]\n[1.5,2.5]\n") == "2"

# All intervals same point
assert run("3\n[5,5]\n[5,5]\n[5,5]\n") == "2"
