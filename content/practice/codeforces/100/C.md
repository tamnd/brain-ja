 ## 解決策
 ## 問題の理解

 このタスクは一見すると簡単に見えます。2 つの整数を読み取り、その合計を出力します。 問題は制約の中に隠されています。 各数値には最大 500 桁の 10 進数を含めることができ、これは多くの言語の標準的な 32 ビットまたは 64 ビット整数の範囲よりもはるかに大きくなります。 

2 つの正の整数が与えられ、それぞれが先行ゼロなしで独自の行に書き込まれます。 先頭のゼロも含めずに、それらの正確な 10 進数の合計を出力する必要があります。 

重要な制約は数値のサイズです。 500 桁の値は、次のような通常の整数型には適合しません。`int`または`long long`C++で。 固定サイズの算術演算を使用した直接の数値加算は、すぐにオーバーフローします。 

このような小さい入力サイズに対しては、制限時間は非常に寛大です。 数字を 1 つずつ処理するアルゴリズムでさえ、実際には小さなものです。 Since each number has at most 500 digits, an`O(n)`解決策はどこで`n`桁数は十分すぎるほどです。 

主なエッジケースはキャリー伝播から生じます。 

次の入力を考えてみましょう。```
999
1
```正しい出力は次のとおりです。```
1000
```不注意に桁ごとに実装すると、すべてのポジションを処理した後に最後のキャリーを追加するのを忘れる可能性があります。 

もう 1 つの微妙なケースは、長さが異なることです。```
12345
9
```正しい出力は次のとおりです。```
12354
```短い数値が正しく埋め込まれていない場合、インデックスが範囲外になったり、桁がずれたりする可能性があります。 

可能な最小の入力もあります。```
1
1
```正しい出力は次のとおりです。```
2
```これにより、桁が 1 つだけで複雑なキャリー ロジックがない場合に実装が機能するかどうかがチェックされます。 

Python では、組み込み整数はすでに任意精度をサポートしているため、問題全体は数値を読み取り、その合計を出力することに帰着します。 それでも、なぜこれが重要なのかを理解することが、問題の中心的な考え方です。 

## アプローチ

 ブルートフォース手法は、手動による大きな整数の加算です。 両方の数値を文字列として保存し、右から左に処理し、対応する数字を追加し、キャリーを追跡し、結果を 1 桁ずつ構築することができます。 

これは、10 進数の加算がローカルであるため機能します。 各位置は、現在の 2 桁と前の位置からのキャリーのみに依存します。 各数値は最大でも 500 桁なので、合計の演算数は数百回の加算とモジュロ演算だけです。 

ブルートフォース手法はすでに十分に高速です。 その複雑さは桁数に線形であり、ここでは桁数は非常に小さいです。 

Python のより便利なアプローチは、Python の任意精度の整数に依存することです。 Python の整数は、非常に大きな値を保持できるように自動的に拡張されるため、文字列を整数に直接変換し、加算して、結果を出力できます。 

多くのプログラミング言語では 500 桁の数値をネイティブに表現できないため、手動による方法が存在します。 Python ではその制限が取り除かれ、問題が 1 行の算術演算に変わります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 手動による桁ごとの加算 | O(n) | O(n) | 承認済み |
 | Python の任意精度の整数 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力から最初の整数を文字列として読み取ります。 
2. 入力から 2 番目の整数を文字列として読み取ります。 
3. 両方の文字列を Python 整数に変換します。 Python は任意の大きな数値を自動的に処理するため、カスタムの大きな整数ロジックは必要ありません。 
4. 2 つの整数を加算します。 
5. 結果の合計を出力します。 

なぜ効果があるのか:

 Python の整数は、内部で任意精度の演算を使用して実装されています。 固定サイズのマシンワードに値を格納する代わりに、Python は非常に大きな整数を表すのに十分なメモリを動的に割り当てます。 このため、2 つの 500 桁の数値を加算すると、オーバーフローすることなく数学的に正しい結果が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

a = int(input().strip())
b = int(input().strip())

print(a + b)
```プログラムは、高速入力を使用して開始します。`sys.stdin.readline`、競技プログラミングでは標準です。 

の`strip()`を呼び出すと、末尾の改行文字が削除されます。 それらがなければ、`int()`Pythonでも動作しますが、`strip()`解析を明示的かつクリーンに保ちます。 

重要な詳細は、Python の組み込み関数の使用です。`int`タイプ。 多くの言語の固定幅の整数型とは異なり、Python の整数は必要に応じて自動的に増加します。 これにより、500 桁の数値であっても、オーバーフローが完全に回避されます。 

決勝戦`print(a + b)`合計の正確な 10 進表現を直接出力します。 Python は、先頭のゼロなしで整数を自動的にフォーマットします。

## 複雑さの分析

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    a = int(input().strip())
    b = int(input().strip())

    print(a + b)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided sample
assert run("2\n3\n") == "5\n", "sample 1"

# minimum values
assert run("1\n1\n") == "2\n", "minimum values"

# carry propagation
assert run("999\n1\n") == "1000\n", "final carry"

# different lengths
assert run("12345\n9\n") == "12354\n", "different digit counts"

# very large numbers
assert run(
    "999999999999999999999999999999\n"
    "1\n"
) == "1000000000000000000000000000000\n", "large integer handling"
```| テスト入力 | 期待される出力 | 検証内容 |

 |`999 1`|`1000`| すべての桁にわたって伝播を行う |

 | 30 桁の大きな値に 1 を加えた値 | 31 桁の大きな結果 | 任意精度の演算 |
