 ## 解決策
 ## 問題の理解

 並んでいます`n`ランプ、それぞれ最初はオンまたはオフです。 各ランプには 1 から 1 までの番号が付いています。`n`。 私たちも持っています`n`キーには同じ番号が付けられています。 キーを押す`i`数が次の値で割り切れるすべてのランプを切り替えます。`i`。 一連の操作の後、`k`キーを押すと、各ランプの最終的なオン/オフ状態が必要になります。 

入力により得られるのは、`n`、最初のランプは言葉として状態を示し、その後`k`、次に押されたキーのシーケンス。 出力は、すべてのランプの最終状態を同じワード形式で記述したものです。 

と`n`最大 10^5 および`k`最大 10^4 の場合、キーを押すたびにすべてのランプを反復する単純なソリューションでは最大 10^9 の操作が必要となり、1 秒の制限時間には遅すぎます。 これにより、O(n*k) 個のブルートフォース ソリューションが除外されます。 

エッジケースには、同じキーを複数回押すことが含まれますが、偶数回押すと事実上キャンセルされます。 たとえば、ランプ 2 が「オフ」で開始し、キー 2 を 2 回押すと、ランプは再び「オフ」になります。 もう 1 つのエッジ ケースは、キー 1 を押すことです。これにより、特に次の場合にすべてのランプが切り替わります。`n`1か2くらい小さいです。 

## アプローチ

 ブルートフォース ソリューションでは、押された各キーを反復処理し、そのキーで割り切れるすべてのランプを切り替えます。 これは原理的には機能しますが、各キーがタッチする可能性があるため、最大の入力では失敗します。`n`ランプの点灯時間は O(n*k) になります。 

最適なソリューションを実現するための重要な洞察は、切り替えが可換であり、剰余 2 であるということです。キーを押すたびにすぐに切り替えるのではなく、まず各キーが押された回数を数えることができます。 ランプ用`x`、その最終状態は、分割するキーの押下パリティのみに依存します。`x`。 言い換えれば、各キーが押された回数を事前に計算し、ランプごとに 2 を法とする約数のカウントを合計して、ランプが切り替わるかどうかを判断できます。 

これを効率的に実装するために、キーごとにふるいのようなアプローチを使用します。`i`奇数回押された場合は、すべての倍数を切り替えます。`i`。 1 + 1/2 + 1/3 + ... + 1/n の倍数の合計はランプあたり O(log n) であるため、これは O(n log n) 時間で実行されます。 これは、n が 10^5 までの場合に実現可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n*k) | O(n) | 遅すぎる |
 | 最適 | O(n log n + k) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`n`初期ランプ状態をリストにまとめます`lamps`。 「オン」を 1 に変換し、「オフ」を 0 に変換して、演算の切り替えを簡素化します。 
2.読む`k`押されたキーのシーケンスをリストに追加します`pressed`。 
3. 配列を作成する`count`サイズの`n+1`ゼロに初期化されます。 押されたキーごとに`i`、増分`count[i]`。 これは、各キーが押された回数をカウントします。 
4. 各キーについて`i`1から`n`、どうかを確認してください`count[i]`奇数です。 偶数の場合は押してもキャンセルされるため、効果はありません。 
5. もし`count[i]`奇数の場合、すべての倍数を反復します`i`(i、2i、3i、…最大 n)。 倍数ごとに`x`、トグル`lamps[x-1]`使用して`lamps[x-1] ^= 1`。 
6.変換`lamps`「on」または「off」文字列に戻り、結果を出力します。 

ここで不変なのは、押下回数が奇数のキーのランプのみを切り替え、各ランプは位置を分割する番号のキーごとに 1 回だけ切り替わることです。 これにより正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
lamps = input().split()
lamps = [1 if state == "on" else 0 for state in lamps]

k = int(input())
pressed = list(map(int, input().split()))

count = [0] * (n + 1)
for key in pressed:
    count[key] += 1

for i in range(1, n + 1):
    if count[i] % 2 == 1:
        for j in range(i, n + 1, i):
            lamps[j - 1] ^= 1

print(" ".join("on" if x else "off" for x in lamps))
```最初にランプの状態を読み取って整数に変換し、XOR を使用して切り替えを簡素化します。 キーの押下をカウントすると、偶数のカウントでトグルが繰り返されることがなくなります。 以下の場合にのみ反復する`count[i]`奇数であるため、不要な作業が軽減されます。 使用する`j - 1`切り替え時にゼロベースのインデックスが正しく作成されるようにします。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n log n + k) | キーの押下をカウントするのは O(k)、奇数のキーの倍数を切り替えるのは O(n log n) |
 | スペース | O(n) | ランプの状態とキーの数を保存します。 

n = 10^5 および k = 10^4 の場合、アルゴリズムは 1 秒の時間制限と 256 MB のメモリ制限内に簡単に収まります。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    lamps = input().split()
    lamps = [1 if state == "on" else 0 for state in lamps]
    k = int(input())
    pressed = list(map(int, input().split()))
    count = [0] * (n + 1)
    for key in pressed:
        count[key] += 1
    for i in range(1, n + 1):
        if count[i] % 2 == 1:
            for j in range(i, n + 1, i):
                lamps[j - 1] ^= 1
    return " ".join("on" if x else "off" for x in lamps)

# Provided sample
assert run("2\noff off\n2\n1 2\n") == "on off", "sample 1"

# Minimum input
assert run("1\noff\n1\n1\n") == "on", "single lamp"

# Multiple presses cancel
assert run("3\non off on\n4\n2 2 2 2\n") == "on off on", "even multiple presses"

# Maximum-size input, all keys pressed once
assert run("5\noff off off off off\n5\n1 2 3 4 5\n") == "on on on off on", "all keys once"

# Key 1 toggles all
assert run("4\noff off off off\n1\n1\n") == "on on on on", "key 1 toggles all"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | "1\nオフ\n1\n1\n" | 「オン」 | 最小入力 |
 | "3\n オフ オン\n4\n2 2 2 2\n" | "オンオフオン" | 複数回押してもキャンセル |
 | "5\nオフ オフ オフ オフ\n5\n1 2 3 4 5\n" | "オン オン オフ オン" | 複数のキーと n > k |
 | "4\nオフ オフ オフ\n1\n1\n" | "オンオンオンオン" | キー 1 ですべてを切り替えます |

 ## 特殊なケース

 同じキーが複数回押された場合、パリティのみが問題になります。 たとえば、次のように入力します。```
3
off off off
3
2 2 2
```count[2] = 3、これは奇数です。 アルゴリズムは 2 の倍数 (ランプ 2) を 1 回切り替え、最終的なランプはオフ、オン、オフになります。 このアルゴリズムは偶数カウントのキーを正しく無視し、キャンセルを自動的に処理します。 単一のランプの場合、キー 1 を押すとランプが正しく切り替わります。 最大 n の場合、アルゴリズムはふるいのような複数の切り替えアプローチを使用して効率的にスケーリングします。
