 ## 解決策
 ## 問題の理解

 10 × 10 の戦艦ボードが数枚与えられました。 各セルは空であるか、船の一部が占有しています。 タスクは、占有されているすべてのセルが有効なフリート構成に属しているかどうかを確認することです。 

有効な戦艦艦隊には、長さ 4 の船が 1 隻、長さ 3 の船が 2 隻、長さ 2 の船が 3 隻、長さ 1 の船が 4 隻含まれます。すべての船は、水平または垂直の直線セグメントでなければなりません。 船は重なり合ったり、曲がったり、斜めであっても互いに接触したりすることはできません。 

ボードは小さく、セル数はわずか 100 個です。 最大 10 枚のボードであっても、合計で最大 1000 セルしか処理されません。 これにより、パフォーマンスが主な課題として除外されます。 難しいのは、すべての幾何学的条件を正しく検証することだけです。 

最も危険な間違いは、無効な船の形状を受け入れたり、斜めの隣接性チェックを忘れたりすることによって発生します。 

このボードの断片を考えてみましょう。```
**00000000
*000000000
0000000000
```占有された 3 つのセルは L 字型を形成します。 接続されたコンポーネントのみをカウントする不注意な DFS では、サイズ 3 のコンポーネントが表示され、それを長さ 3 の有効な船として誤って分類する可能性があります。船は真っすぐでなければならないため、正解は NO です。 

もう 1 つのよくある落とし穴は、斜めに接触することです。```
*000000000
0*00000000
0000000000
```これらは 2 隻の単細胞船が斜めに接触しています。 戦艦のルールではこれが禁止されているため、ボードは無効です。 4 方向の隣接性のみをチェックするソリューションでは、これが見逃されます。 

3 番目の微妙なケースは、船が統合された場合です。```
***0000000
00*0000000
0000000000
```垂直セルは水平船に直角に接触し、曲がったコンポーネントを作成します。 理事会は直ちに拒否されなければなりません。 

最後のクラスのバグは船舶の数を数えることによって発生します。 すべての接続コンポーネントが直線である場合でも、フリートの構成は必要な数と正確に一致する必要があります。 たとえば、長さ 4 の船が 2 隻あり、長さ 3 の船がない場合は無効です。 

## アプローチ

 ブルートフォースのアイデアは単純です。 考えられるすべての船の配置を個別に特定し、一致する船をボードから削除することを試みることができます。 ボードは 10 × 10 しかないため、かなり不器用な列挙でも高速に実行されます。 

単純な戦略の 1 つは、ボードを繰り返しスキャンして水平または垂直のセグメントを探し、それらを船としてマークし、残りのセルも有効な船を形成することを期待することです。 問題は曖昧さです。 奇形な形状が誤って複数の合法的な船に分解される可能性があります。 たとえば、L 字型は、コンポーネント自体が無効であっても、長さ 2 の船と単一セルの船として解釈される可能性があります。 

ボードについては、グラフの問題として考えるのが正しい方法です。 占有されているすべてのセルは、4 方向の隣接関係にある 1 つの接続コンポーネントにのみ属します。 船舶は直交することができないため、接続された各コンポーネントは 1 つの船舶に正確に対応する必要があります。 

この観察により、すべてが単純化されます。 

1. 未訪問の占有セルごとに DFS または BFS を実行します。 
2. 連結成分全体を抽出します。 
3. すべてのセルが 1 つの行または 1 つの列にあることを確認します。 
4. セルが連続したセグメントを形成していることを確認します。 
5. セルが他の船と斜めに接触していないことを確認します。 
6. 船の長さを数えます。 

ボードには 100 セルしかないため、ボード全体の DFS は実質的に一定時間になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(1003) | O(100) | 受け入れられたが気まずい |
 | 最適 | O(100) | O(100) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 10 × 10 ボードをグリッドに読み取ります。 
2. 占有されている各セルが 1 回だけ処理されるように、訪問済みの配列を維持します。 
3. ボードのすべてのセルを繰り返し実行します。 
4. 未訪問の場合`'*'`セルが見つかった場合は、そこから DFS または BFS を開始し、4 方向の移動のみを使用して接続コンポーネント全体を収集します。 

船は水平または垂直にしか接続しないため、4 方向を使用するのが正しいです。 斜めのセルは決して同じ船に属してはなりません。 
5. コンポーネント内のすべてのセルについて、斜めに隣接する 4 つすべてのセルをチェックします。 

斜めの隣に次のものがある場合、`'*'`、船は斜めに接触することができないため、ボードは即座に無効になります。 
6. コンポーネントを収集したら、その形状を検証します。 

コンポーネントのサイズが 1 の場合、それは自動的に有効な単一セルシップになります。 

それ以外の場合は、次のいずれかです。 

- すべてのセルが同じ行を共有する必要があります。または
 - すべてのセルが同じ列を共有する必要があります。 

どちらの条件も当てはまらない場合、船は曲がり、ボードは無効になります。 
7. 導通を確認します。 

水平船の場合、列インデックスを並べ替えて、それらが連続した整数を形成していることを確認します。 

垂直船の場合、行インデックスを並べ替えて、それらが連続した整数を形成していることを確認します。 

これにより、次のような切断された形状が防止されます。```
*0*
```8. 船の長さを記録します。 
9. すべてのコンポーネントを処理した後、正確なフリート構成を確認します。 

- サイズ 4 の船 1 隻、
 - サイズ 3 の船 2 隻、
 - サイズ 2 の船 3 隻、
 - サイズ 1 の船 4 隻。 
10. すべてのチェックが成功した場合は YES を出力し、そうでない場合は NO を出力します。 

### なぜ効果があるのか

 占有されているすべてのセルは、4 方向の隣接関係にある 1 つの接続コンポーネントにのみ属します。 船舶は重なり合ったり、直交したりすることができないため、各コンポーネントは 1 つの船舶を表す必要があります。 

このアルゴリズムは、合法的な船舶のすべての必要な特性を検証します。 

- 斜めのチェックにより船との接触を防ぎます。 
- 行/列の位置合わせにより曲がりを防止します。 
- 連続性チェックによりギャップを防ぎます。 
- フリートカウントにより、必要な船舶在庫を正確に把握できます。 

すべてのコンポーネントが独立してチェックされ、占有されているすべてのセルが 1 回だけ処理されるため、無効な構成は検出を逃れることはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

DIRS = [(-1, 0), (1, 0), (0, -1), (0, 1)]
DIAG = [(-1, -1), (-1, 1), (1, -1), (1, 1)]

def solve_board(grid):
    visited = [[False] * 10 for _ in range(10)]
    counts = [0] * 5

    def inside(r, c):
        return 0 <= r < 10 and 0 <= c < 10

    def dfs(sr, sc):
        stack = [(sr, sc)]
        visited[sr][sc] = True
        cells = []

        while stack:
            r, c = stack.pop()
            cells.append((r, c))

            for dr, dc in DIRS:
                nr, nc = r + dr, c + dc

                if inside(nr, nc) and not visited[nr][nc] and grid[nr][nc] == '*':
                    visited[nr][nc] = True
                    stack.append((nr, nc))

        return cells

    for r in range(10):
        for c in range(10):
            if grid[r][c] == '*' and not visited[r][c]:
                cells = dfs(r, c)

                # diagonal touching check
                for x, y in cells:
                    for dx, dy in DIAG:
                        nx, ny = x + dx, y + dy

                        if inside(nx, ny) and grid[nx][ny] == '*':
                            return False

                size = len(cells)

                if size > 4:
                    return False

                rows = set(x for x, _ in cells)
                cols = set(y for _, y in cells)

                if len(rows) != 1 and len(cols) != 1:
                    return False

                if len(rows) == 1:
                    vals = sorted(y for _, y in cells)
                else:
                    vals = sorted(x for x, _ in cells)

                for i in range(1, len(vals)):
                    if vals[i] != vals[i - 1] + 1:
                        return False

                counts[size] += 1

    return counts[1] == 4 and counts[2] == 3 and counts[3] == 2 and counts[4] == 1

def main():
    t = int(input())
    ans = []

    for _ in range(t):
        grid = []

        while len(grid) < 10:
            line = input().strip()

            if line:
                grid.append(line)

        ans.append("YES" if solve_board(grid) else "NO")

    print("\n".join(ans))

if __name__ == "__main__":
    main()
```このソリューションでは検証を独立したチェックに分割するため、デバッグがはるかに簡単になります。 

DFS は、一度に 1 つの接続コンポーネントを収集します。 私たちは 4 方向にしか移動しないため、斜めに接触している船は別個のコンポーネントのままであり、これがまさに私たちが望んでいることです。 

対角検証はコンポーネント抽出後に意図的に実行されます。 この時点で、どのセルが現在の船に属しているかはすでにわかっているため、任意の対角線が`'*'`他の船に属している必要があり、直ちに規則に違反します。 

行セットと列セットのチェックは、中核となる形状検証です。 両方のセットのサイズが 1 より大きい場合、コンポーネントは曲がります。 これはすべての L 字型と T 字型をキャッチします。 

導通チェックは微妙ですが必要です。 次のようなコンポーネント:```
*0*
```有効な 4 方向接続では表示できませんが、連続性をチェックすることでロジックが堅牢かつ自己完結型になります。 

最終的な艦隊数の検証により、戦艦の正確な在庫が保証されます。 たとえ完璧な形状の船であっても、カウントが公式ルールと一致しない場合は拒否されます。
