 ## 解決策
 ## 問題の理解

 タスクは長さの順列を構築することです\(n > 1\)元の位置を占める要素が存在しないようにします。 つまり、順列の場合、\(p\)サイズの\(n\)、私たちはそれを要求します\(p_i \ne i\)すべてのインデックスに対して\(i\)。 各テスト ケースは単一の整数で構成されます\(n\)、出力は次のシーケンスになるはずです。\(n\)指定された条件を満たす有効な順列を形成する整数。 

制約は控えめです。\(n\)最大 100 まで指定でき、最大 100 のテスト ケースが存在します。 これは、線形時間解法も可能ではあるものの、 \(O(n^2)\) のアプローチでも十分高速であることを意味します。 主なエッジケースは次のような場合に発生します。\(n\)具体的には最小限です\(n = 2\)ここで、考えられる混乱は 1 つだけです。それは 2 つの数値を交換することです。 大型の場合\(n\)、有効な順列が複数あるため、解決策は建設的であり、検索や最適化を必要としません。 

単純に数値をランダム化する単純なアプローチでは、一部の数値が誤って元の位置に配置される可能性があり、それを検証するには各順列をチェックする必要があるため、失敗する可能性があります。 問題が単純であるため、これは不必要に複雑になります。 

## アプローチ

 ブルートフォースアプローチは、長さのすべての順列を生成することです。\(n\)それぞれをテストして、元の位置に要素がないことを確認します。 それは正しいのですが、このアプローチは複雑さ \(O(n!)\) において階乗的であり、次のような場合でも実行不可能になります。\(n = 10\)。 

重要な観察は、すべての要素を 1 位置ずつ単純に巡回シフトすると、すべての要素に対して有効な置換が生成されるということです。\(n > 1\)。 具体的には、最初の要素を 2 番目の位置に、2 番目を 3 番目に、...そして最後の要素を最初の位置に配置すると、要素が元の位置に残らないことが保証されます。 これは線形時間の建設的なアプローチであり、すべての制約を効率的に満たします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 |---|---|---|---|
 | ブルート フォース (すべての順列) | お(ん!) | O(n) | 遅すぎる |
 | 循環シフト | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取り、\(t\)。 
2. 各テスト ケースについて:
 1. 整数を読み取る\(n\)、順列の長さ。 
2. 1 から 1 までの整数のリストを生成します。\(n\)。 
3. 巡回シフトを実行して順列を構築します。最初の要素を最後に移動し、他のすべての要素を 1 つ左にシフトします。 
4. 結果の順列をスペースで区切られた文字列として出力します。 

機能する理由: すべての要素を 1 つ左に移動し、最初の要素を最後に移動することで、各数値が\(i\)位置から移動する\(i\)\((i-1 \mod n) + 1\) を配置します。 これにより、どの要素も元の位置に残らないことが保証され、すべての問題要件が満たされます。\(n > 1\)。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        perm = list(range(1, n + 1))
        # cyclic shift: first element moves to the end
        perm = perm[1:] + perm[:1]
        print(' '.join(map(str, perm)))

if __name__ == "__main__":
    solve()
```ソリューションは、最初にテスト ケースの数を読み取り、各テスト ケースを反復処理します。 1 から 1 までの範囲を構成します\(n\)そしてすぐに巡回シフトを適用します。これは、有効な狂いを生成する最も簡単な方法です。 印刷はスペースで区切られた文字列として実行され、正しい形式が保証されます。 の使用`sys.stdin.readline`最大数のテスト ケースに対する高速な入力処理が保証されます。

 ## 特殊なケース

 最小限の\(n = 2\)場合`[1,2]`になる`[2,1]`サイクリックシフトで。 最大の\(n = 100\)この場合も同じ原理が使用されます。 最初の要素は最後に移動し、他の要素はすべて左に移動します。これにより、要素が元の位置に残ることはなくなります。 奇数、偶数、および最大サイズの入力はすべて同じ線形シフト ロジックに従い、正確であることが確認されます。
