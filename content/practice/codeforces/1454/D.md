 ## 問題の理解

 単一の整数が与えられます$n$これらの整数は任意の因数ではありませんが、割り算の連鎖によって制約されます。つまり、次の各数字は前の数字で割り切れる必要があります。 同時に、シーケンス内のすべての数値を掛け合わせると、元の値を回復する必要があります。$n$。 すべての有効なシーケンスの中で、可能な最大長のシーケンスが必要です。 

これについて考えるのに役立つ方法は、ある基数から始まる乗法連鎖を構築しているということです。$a_1$、次のすべての要素は、構造を削除することなく、さらに素因数を追加することによってそれを拡張します。 各要素が次の要素を分割するため、シーケンスは要素を「蓄積」することによってのみ成長できます。 

制約の値は大きく、最大で$10^{10}$テストごとに、最大 5000 のテストが可能です。 これは、繰り返し因数分解や貪欲な構築に依存するソリューションは、理想的には数値ごとに効率的である必要があることを強く示唆しています。$O(\sqrt{n})$あるいは償却したほうがよいでしょう。 

これを恣意的な因子分割として扱おうとすることから、素朴な誤解が生じることがよくあります。 たとえば、$n = 12$、次のようなシーケンスを試すかもしれません$2, 3, 2$または$2, 6$、しかし、割り切れる条件により、多くの再配置がブロックされます。 もう 1 つの微妙な失敗は、素数への分割が順序として常に最適であると仮定していることです。 これは、各ステップが単に乗算するだけではなく、次のステップを除算する必要があるという要件を無視しています。$n$。 

本当のエッジケースは次のようなときに起こります。$n$などの主要なパワーです。$2^{10}$。 ここでの最適な答えは、恣意的な分割ではなく、非常に構造化された倍加チェーンです。 貪欲な「最小の因数を繰り返し取得する」アプローチでは、すべてのステップで割り算が有効であることを注意深く確認する必要があります。そうしないと、早期に分割され、最大長を逃してしまいます。 

## アプローチ

 ブルートフォース戦略では、すべての有効なシーケンスを構築しようとします。 の任意の約数から始めることができます。$n$次に、総積制約と割り算連鎖を維持するより大きな倍数を選択して、シーケンスを再帰的に拡張します。 これは基本的に、各状態が部分シーケンスであり、次の状態が有効な拡張を選択するツリーを探索します。 

すべての可能性を列挙しているので正しさは単純ですが、分岐要素が大きいです。 中程度の場合でも$n$、約数の数が大きくなる可能性があり、各拡張では割り算と残りの因数の実現可能性をチェックする必要があります。 最悪の場合、素因数の数が指数関数的に増加します。 

重要な観察は、可分性条件により非常に厳格な構造が強制されるということです。$a_i$前の値に整数を乗算して取得する必要があります。 その整数は除算する必要があります$n / a_i$、長さを最大化するために、有効な間に各乗算をできるだけ小さくしたいと考えています。 

これはすぐに貪欲なアプローチを示唆します:$n$を素数に変換し、可能な限り各ステップで素因数を取得してチェーンを構築します。 可能な限り長いチェーンは、単一の素因数を 1 つずつ繰り返し剥がすことに対応します。各ステップは少なくとも 1 つの素因数を乗算することによってのみ増加し、因数をできるだけ遅く分割することでステップ数が最大化されるためです。 

最適な構造は次のようになります。素因数分解を計算します。$n = \prod p_i^{e_i}$。 最大長は、多重度でカウントされた素因数の総数からグループ化に関連するものを差し引いたものですが、より直接的には、各ステップで利用可能な最小の構造を再利用しながら、素数を段階的に乗算するチェーンを構築します。 

より明確な解釈は、次のとおりです。可能であれば、各ステップで正確に 1 つの素因数が追加されるチェーンが必要です。 これにより、最小の約数 (多くの場合素数) から開始してシーケンスを構築し、制御された順序で素数を繰り返し乗算することになります。

 ## アルゴリズムのチュートリアル

 私たちは素因数分解に依存し、それらの因数から最長の有効な乗法連鎖を構築します。 

1.因数分解$n$素数に。 多重度によってチェーンを何回拡張できるかが直接決まるため、各素数をその指数とともに保存します。 
2. すべての素因数をリストに集め、指数に従って各素因数を繰り返します。 これにより、構築内にすべて出現する必要があるアトミックな「構築ステップ」の複数セットが得られます。 
3. 素数リストをソートします。 ソートは正確さのために厳密に必要なわけではありませんが、これにより決定論的な構築が保証され、チェーンの長さの最大化と一致する最小の拡張を最初に一貫して選択するのに役立ちます。 
4. 1 から始まるシーケンスを暗黙的に構築しますが、すべて$a_i > 1$、最初の素数を次のように取得することから始めます。$a_1$。 
5. 前の値に次の未使用の素因数を繰り返し乗算します。 各乗算により、シーケンス内の次の要素が生成されます。 
6. すべての素因数が 1 回だけ使用されたら停止します。 結果として得られるシーケンスの長さは、素因数の数と等しくなります。 

この微妙なステップにより、各素因数を 1 つずつ安全に使用できるようになります。 それぞれ$a_i$分割する$a_{i+1}$なぜなら、整数を掛けているだけで、残りの積はまだ完成しているからです。$n$。 この構造により、要素がスキップされたり、誤って再利用されたりすることがなくなります。 

### なぜ効果があるのか

 すべてのステップで、現在の値は次の素数マルチセットのサブセットの積です。$n$。 次の要素に移動することは、そのマルチセットから素因数を 1 つだけ追加することに対応します。 乗算は素因数分解の指数を増加させるだけで、減少させることはないため、これにより割り算が保証されます。 すべての素数は最終的に消費されるため、利用可能なすべての素因数を個別のステップとして使用することでチェーンの長さが最大化されます。各ステップで少なくとも 1 つの素因数を導入する必要があるため、有効なシーケンスはこれを超えることはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def factorize(n):
    factors = []
    p = 2
    while p * p <= n:
        while n % p == 0:
            factors.append(p)
            n //= p
        p += 1
    if n > 1:
        factors.append(n)
    return factors

t = int(input())
for _ in range(t):
    n = int(input())
    primes = factorize(n)
    primes.sort()

    # build chain
    res = []
    cur = 1
    for p in primes:
        cur *= p
        res.append(cur)

    print(len(res))
    print(*res)
```因数分解ループは素数を抽出します。$O(\sqrt{n})$、制約と合計の制限を考慮すると、これで十分です$n$。 ソートされたリストにより一貫した順序が確保されますが、素数をどのような順序で乗算しても有効なチェーンが生成されます。 

構築は暗黙の値 1 から始まりますが、この問題ではすべての要素が 1 より大きい必要があるため、最初の乗算ですぐに有効な値が生成されます。$a_1$。 後続の各値は、追加の整数を乗算して形成されるため、前の値で割り切れることが保証されます。 

よくある実装ミスは、積を段階的に蓄積することを忘れ、代わりに最初から再計算することです。これにより、不要なオーバーヘッドや精度の問題が発生する可能性があります。 もう 1 つの微妙な問題は、$\sqrt{n}$、ループの後に追加する必要があります。

 ## 特殊なケース

 次のような主要な入力$n = 13$単一要素のシーケンスを生成します。 このアルゴリズムでは因数分解が行われ、小さい約数は検出されないため、因数リストには 13 のみが含まれます。構築ステップでは中間乗算は生成されず、出力には最大長 1 が正しく反映されます。 

のようなプライムパワーの場合$n = 8$、因数分解すると、$[2,2,2]$。 アルゴリズムが構築される$2 \rightarrow 4 \rightarrow 8$、各ステップに次の素因数が乗算されます。 各値は厳密に同じマルチセットのプレフィックス積であるため、割り算条件はすべてのステップで当てはまります。 

次のような混合コンポジットの場合$n = 360$、すべての要素が 1 つずつ消費されます。 異なる順序が存在する場合でも、乗算は可換であり、prefix-product プロパティによってすべての遷移で割り切れることが保証されるため、素数乗算の順序は有効性を維持します。
