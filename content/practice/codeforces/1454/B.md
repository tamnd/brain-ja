 ## 解決策
 ## 問題の理解

 簡易型の「ユニーク入札オークション」で落札者を決定していただきます。 各参加者は数字を選択し、他の誰も選ばなかった、そのようなすべての固有の数字の中で最も小さい数字を選んだ参加者が勝者となります。 一意の数値がない場合、結果は -1 になります。 入力では複数のテスト ケースが提供され、それぞれに参加者の数と選択された番号が含まれており、ケースごとに勝利参加者の 1 から始まるインデックスを返す必要があります。 

制約は重要です。 各参加者の数は最大で`n`、最大で`2·10^5`すべてのテスト ケースの参加者。 これにより、数値のすべてのペアを比較するソリューションが除外されます (`O(n^2)`）、最悪の場合、それが必要になる可能性があるため、`4·10^10`これは 1 秒で実行できる処理をはるかに超えています。 理想的には、テスト ケースごとに線形または線形に近いソリューションが必要です。`O(n)`。 

明らかではないエッジ ケースには、すべての数値が重複している、参加者が 1 人だけ存在する、または最小の数値が繰り返されるが、わずかに大きい数値が一意であるなどの状況が含まれます。 たとえば、入力の場合`[1,1,2]`、勝者は選択した参加者です`2`、 ない`1`、 なぜなら`1`はユニークではありません。 同様に、すべての数値が`[1,1,2,2]`、勝者はいません。 一意性をチェックせずに最小値だけを探す単純なアプローチは失敗するため、これらは微妙です。 

## アプローチ

 ブルートフォース手法は簡単です。各数値について、その出現回数を数え、すべての数値をスキャンして、ちょうど 1 回出現する最小の数値を見つけます。 カウントは、ネストされたループまたは繰り返しスキャンで実行できます。 これは問題定義を明示的に実装しているため、正しく機能します。 しかし、それは遅すぎます。 各数値の頻度を数える`O(n)`各テストケースのスキャン結果は`O(n^2)`テストケースごとに、これは上限として受け入れられません。`n`。 

重要な洞察は、最初のスキャン時の位置ではなく、各数値の頻度のみが必要であるということです。 辞書を使用して、数値をその出現数にマッピングできます。 頻度マップを取得したら、一度だけ出現する数値をフィルターし、その中から最小値を選択できます。 次に、元のリストを 1 回通過することで、勝者の 1 から始まるインデックスが特定されます。 このアプローチは線形です。1 つのパスでカウント マップを構築し、1 つのパスでインデックスを見つけます。`O(n)`テストケースごとに。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | お(1) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 空の辞書を初期化して、各数値の出現回数をカウントします。 
2. 参加者の番号を反復処理して、辞書内の各番号のカウントを増やします。 これにより、各数値が何回出現するかの頻度マップが作成されます。 
3. カウントが正確に 1 であるすべての数値を識別します。 そのような数値がない場合は、このテスト ケースに対してすぐに -1 を返します。 
4. これらの一意の数値の中から最小の数値を見つけます。 これが当選番号です。 
5. 元の数字のリストを繰り返し、最初に出現した当選数字のインデックスを見つけます。 当選番号は一意であるため、そのような事態は 1 回だけ発生します。 
6. 1 から始まるインデックスを調整してインデックスを出力します。 

これが機能する理由: 辞書により正確な頻度カウントが保証され、最小限の一意の数値をスキャンすることで問題のルールに従っていることが保証されます。 その後、その数値のインデックスをスキャンするため、値を参加者に正しくマップし直すことができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        count = {}
        for num in a:
            count[num] = count.get(num, 0) + 1
        # collect unique numbers
        unique_numbers = [num for num, freq in count.items() if freq == 1]
        if not unique_numbers:
            print(-1)
            continue
        winner_value = min(unique_numbers)
        # find 1-based index
        for i, num in enumerate(a):
            if num == winner_value:
                print(i + 1)
                break

if __name__ == "__main__":
    main()
```コードは最初にテスト ケースの数を読み取ります。 ケースごとに、参加者の数とその番号が読み取られます。 の`count`辞書には各数値の頻度が格納されます。 リスト内包表記では、一意の数値が除外されます。 一意の数値がない場合は、-1 を出力します。 それ以外の場合は、最小の一意の番号を見つけて、元の配列をスキャンして参加者のインデックスを見つけます。 の使用`enumerate`ループ インデックスに 1 を追加することで、1 から始まるインデックス付けが簡単になります。

## 特殊なケース

 入力に参加者が 1 人だけ含まれている場合、たとえば、`[1]`の場合、アルゴリズムは 1 つの出現を正しくカウントし、それを一意であると認識し、インデックス 1 を返します。すべて等しい配列の場合、たとえば、`[5,5,5,5,5]`、周波数マップにはカウント 1 の値がなく、出力 -1 がトリガーされます。 最小の一意の番号が配列の最後にある場合、たとえば、`[2,3,3,2,1]`、アルゴリズムは正しく識別します`1`を勝者として選択し、そのインデックスを見つけます。 これらのエッジ ケースは、アルゴリズムが境界、単一要素、重複、配列の位置を正しく処理していることを確認します。
