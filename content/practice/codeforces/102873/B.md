 ## 解決策
 ## 問題の理解

 ニンジンが並んでいて、それぞれのニンジンにはサイズがあります。 2 匹のウサギがこの列の反対側の端から始まります。 ウサギが内側に進み続けることができるのは、次に到達するニンジンが、直前に食べたニンジンと少なくとも同じ大きさである場合のみです。 2 匹のウサギは動きの順序を選択できるため、目標は、2 匹のウサギが続行できなくなる前に、どれだけ多くの異なるニンジンを食べられるかを最大化することです。 この問題では、その最大数が求められます。 

最初のウサギは、配列の最長の非減少プレフィックスのみに依存します。 最初の数本のニンジンが`1 2 2 5`、あらゆる動きが許可されているため、すべてを食べることができます。 2 番目のウサギは、反対側から見て対称条件を持っています。右から左に見た場合、食べた順序は減少していなければなりません。つまり、左から右に見た場合、残りの接尾語は増加していなければなりません。 

制約`n <= 2 * 10^5`ウサギの動きのあらゆる可能な順序をシミュレートすることを除外します。 多くの動きの組み合わせを試みるアプローチは、簡単に二次関数またはそれより悪いものになる可能性があります。`4 * 10^10`操作は限界をはるかに超えます。 リニアスキャンは配列全体を一定の回数だけ処理するため、リニアスキャンが必要です。 

トリッキーなケースは、2 匹のウサギの到達可能なセグメントが接触または重なっている場合です。 よくある間違いは、2 匹のウサギを別々に数えて、誤って同じニンジンを 2 回数えることです。 例えば：```
Input
5
2 2 2 2 2
```正しい出力は次のとおりです。```
5
```どちらのウサギもすべてのニンジンに到達できますが、中央のニンジンは 2 回数えられません。 答えは、カバーできる個別のニンジンの数です。 

もう 1 つの境界ケースは、1 羽のウサギがすぐに止まる場合です。 例えば：```
Input
4
5 1 1 1
```正しい出力は次のとおりです。```
4
```次のニンジンは小さいため、左のウサギは最初のニンジンだけを食べます。 正しいウサギはサフィックス全体を食べることができます`1 1 1`。 両方のウサギが常に 1 本以上のニンジンを提供すると仮定した解決策は、ここでは失敗します。 

最後のケースは、到達可能な部分が減少するジャンプによって分離されている場合です。```
Input
5
1 3 2 3 1
```正しい出力は次のとおりです。```
4
```左のウサギは最初の 2 つのニンジンに到達し、右のウサギは最後の 2 つのニンジンに到達します。 真ん中のニンジンはどちらのウサギも届きません。 

## アプローチ

 直接的なアプローチは、両方のウサギをシミュレートすることです。 左の終点から開始して、次のニンジンが条件を満たすまで繰り返し移動できます。 適切なエンドポイントからも同じことができます。 これにより、開始側が固定されるとウサギの経路が決定されるため、各ウサギが食べる可能性のあるすべてのニンジンが正確に識別されます。 

考えられる移動命令の完全なシミュレーションの問題は、ウサギ間の対話を意味のある選択肢がたくさんあるかのように扱うことです。 実際には、重要な情報は、各ウサギが到達できる最も遠い位置だけです。 左側のウサギは常に接頭辞を要求し、右側のウサギは常に接尾辞を要求します。 

問題を単純化する観察は、両方のウサギが同じニンジンを望んでいる場合にのみ、動きの順序が重要になるということです。 左のウサギに到達可能なプレフィックス内のすべてのニンジンを取得させ、右のウサギに到達可能なサフィックス内のすべてのニンジンを取得させることができます。 最大の答えは、これら 2 つの範囲を合わせたサイズになります。 

すべての移動命令の総当りシミュレーションには、あらゆる瞬間にどちらかのウサギが移動する可能性があるため、指数関数的に多くの可能性が生じます。 到達可能な間隔によってゲームが完全に記述されるため、多くの状態を追跡する必要さえありません。 最適なソリューションでは、2 回のスキャンで両方の境界を見つけ、それらを組み合わせます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 可能な移動選択肢の数は指数関数的に増加します。 O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 左側からスキャンして最後のインデックスを見つけます`left`それは最初のウサギの道に属します。 最初に食べるニンジンから始めます。 次のニンジンが現在のニンジン以上である間、移動を続けます。 最後のインデックスは、到達可能なプレフィックスの終わりです。 
2. 右側からスキャンして最初のインデックスを見つけます`right`それは二番目のウサギの道に属します。 最後に食べたニンジンから始めます。 ウサギの視点から次のニンジンが現在のニンジン以上である間に左に移動します。 配列の順序では、前の要素が現在の要素以上でなければならないことを意味します。 
3. 左のウサギはその間にニンジンをすべて食べることができます`[0, left]`、そして右のウサギはその間隔ですべてのニンジンを食べることができます`[right, n-1]`。 これらの間隔が重複する場合、重複は 1 回だけカウントされます。 
4. 2 つの区間の和集合のサイズを計算します。 もし`left < right`、間隔は別々であり、答えは次のとおりです。`(left + 1) + (n - right)`。 それ以外の場合は、重複してセクション全体をカバーします。`0`に`n - 1`、したがって、答えは次のとおりです`n`。 

機能する理由: 移動ルールにより、各ウサギの経路が固定されます。 左側のウサギは、それを妨げるニンジンを飛び越えることはできないため、食べるものはすべて 1 つの最大接頭辞の中に収まる必要があります。 同じ推論により、右のウサギに対して 1 つの最大の接尾辞が得られます。 最適なゲームでは、これら 2 つの地域のニンジンのみを使用でき、移動順序を適切に選択することで両方の地域を完全に消費できます。 それらの結合を数えると、食べられた個別のニンジンの最大数が正確にわかります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    left = 0
    while left + 1 < n and a[left + 1] >= a[left]:
        left += 1

    right = n - 1
    while right - 1 >= 0 and a[right - 1] >= a[right]:
        right -= 1

    if left < right:
        ans = left + 1 + (n - right)
    else:
        ans = n

    print(ans)

if __name__ == "__main__":
    solve()
```最初のループでは、左のウサギの正確な停止点を見つけます。 比較には、`a[left + 1] >= a[left]`ウサギは左から右に移動しており、次のニンジンが少なくとも前のニンジンと同じ大きさである必要があるからです。 

2 番目のループは似ていますが、逆方向に実行されます。 条件は`a[right - 1] >= a[right]`なぜなら、ウサギはより小さなインデックスに向かって移動しているからです。 これはウサギの移動方向に食べる順番が減らないと言っているのと同じです。 

最終的な計算では、ウサギ間の相互作用のみが処理されます。 もし`left < right`、ウサギの到達可能な部分はバラバラです。 そうしないと、パスが交わるか交差し、一緒に 2 つの端点間のすべてのニンジンをカバーすることができます。 

この実装では、入力配列のほかにいくつかの整変数のみを使用します。 Python の整数には、これらの値に対するオーバーフローの問題はなく、演算の数は線形です。

 | 答え | | | 4 |

 どちらのウサギも列全体を覆うことができ、結合を数えるとニンジンが 4 つ得られます。

 ## 特殊なケース

 すべて等しい場合:```
5
2 2 2 2 2
```左側のスキャンがインデックスに到達します`4`あらゆる動きが許されるからです。 正しいスキャンがインデックスに到達しました`0`同じ理由で。 間隔が重なるため、アルゴリズムは次の値を返します。`n = 5`両方の長さを加算して無効な答えを生成するのではなく、

 早期停止の場合:```
4
5 1 1 1
```左側のスキャンはインデックスに残ります`0`なぜなら`1`よりも小さいです`5`。 右側のスキャンはインデックスに移動します`1`なぜなら`1 1 1`右から左へ有効です。 間隔`[0,0]`そして`[1,3]`別々なので、答えは`1 + 3 = 4`。 

重複する場合:```
5
1 2 3 4 5
```左のウサギがインデックスに到達`4`、右のウサギがインデックスに到達します`0`。 2 つの範囲は完全に重複しているため、アルゴリズムは次の値を返します。`5`。 両方の範囲を個別にカウントすると、誤って返されます。`10`。 

分離された場合:```
5
1 3 2 3 1
```左側のスキャンはインデックスで停止します`1`、右のスキャンはインデックスで停止します`3`。 二匹のウサギは位置を食べることができます`0,1,3,4`、正しい答えを与える`4`。 アルゴリズムにはインデックスは含まれません`2`なぜなら、どちらの単調パスも、それをブロックする水滴を横切ることができないからです。
