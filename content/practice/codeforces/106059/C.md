 ## 解決策
 ## 問題の理解

 平面内に 3 つのラベル付き点が与えられ、各点は繰り返し移動できます。 1 回の移動で点の 1 つが選択され、それが平面内の任意の場所に再配置されますが、厳密な幾何学的制約が適用されます。つまり、セグメントによって移動された点で他の 2 点に対して形成される角度は、移動前とまったく同じままでなければなりませんが、他の 2 点はその操作中に固定されたままになります。 

目的は、これらの動きをシミュレートすることではなく、そのような制約された動きのシーケンスの後、各点が対応するターゲット座標に正確に到達できるかどうかを判断することです。 

制約は局所的ですが、本質的には幾何学的です。 点を移動するとき$X$ポイントを守りながら$A$そして$B$修正されました、角度を強制しています$AXB$変わらないままでいること。 これは線形制約ではなく、直線に沿った代数運動ではなく、円形の幾何学を即座に示唆します。 

入力は、最初の三角形とターゲット三角形という 3 つのラベル付き点の 2 つの構成で構成されます。 許可された移動を使用して、初期構成をターゲット構成に変換できるかどうかを判断する必要があります。 

座標の範囲が狭いため、何もシミュレートすることは明らかに期待されていません。 唯一の意味のある解決策は、システムの幾何学的不変量を特定することです。 

よくある失敗モードは、各点が独立して動くと考えることです。 それは真実ではありません。 1 つの点の移動は他の 2 つの点に依存するため、システムはグローバルに制約されます。 

もう 1 つの落とし穴は、三角形の距離または角度がグローバルに保存されると仮定していることです。 そうではありません。 移動中に保持される角度は一度に 1 つだけであり、移動が異なると辺の長さが大幅に変化する可能性があります。 

## アプローチ

 ブルートフォース解釈では、状態を連続した 3 つの点としてモデル化し、幾何学的遷移を使用して到達可能なすべての構成を探索しようとします。 点は連続曲線 (角度制約によって定義される円弧) 上のどこにでも移動できるため、各状態は無限に多くの次の位置に分岐します。 これにより、組み合わせ的にも数値的にも直接検索が不可能になります。 

重要な観察は、見かけ上の自由にもかかわらず、各動きは非常に強力なグローバル不変条件を保持しているということです。 

2点を直すと$A$そして$B$そして3番目の点を移動します$C$角度を保ちながら$ACB$、すべての有効な位置のセット$C$は正確にどのセグメントからの点のセットです$AB$同じ角度から見ています。 その軌跡は通過する円です$A$、$B$、および元の位置$C$。 それで$C$三角形の外接円から出られない$ABC$。 

ここで重要なステップは、これがプロセス全体にわたって持続することを認識することです。 点を繰り返し移動した後でも、3 つの点は常に初期構成によって決定された同じ固有の円上に残ります。 1 つの点が移動すると、すでにその円上にある他の 2 つの点によって拘束されるため、有効な軌跡は同じ円に戻ります。 

最初の点が同一線上にある場合、「円」は限定的な場合には線になるため、同じ推論は線に縮退します。 

したがって、システム全体は、1 つの固定された幾何学的オブジェクト (最初に決定された円または線のいずれか) を離れることなく進化します。 

これにより問題が大幅に軽減されます。 一連の動きについて推論する代わりに、ターゲット構成が開始構成と同じ最初の円 (または直線) 上にあるかどうかを確認するだけで済みます。

 ## アルゴリズムのチュートリアル

 最初の 3 点によって定義された幾何学オブジェクトを抽出し、ターゲットの 3 点が同じオブジェクト上にあることを確認したいと考えています。 

1. 最初の 3 つのポイントを読む$A$、$B$、 そして$C$。 

これらは、一意の円 (同一線上にない場合) または線 (同一線上にある場合) を定義します。 区別は、三角形の符号付き領域かどうかをチェックすることによって決定されます。$ABC$はゼロです。 
2. 外積を使用して初期点の共線性を決定します。$$(B-A) \times (C-A)$$この値がゼロの場合、点は直線上にあります。 
3. 点が同一線上にある場合は、次のように 2 つの点を使用して線の方向を暗黙的に保存します。$A$そして$B$。 不変オブジェクトはこの行です。 
4. それ以外の場合は、次の外接円を計算します。$A$、$B$、 そして$C$。 この円はプロセス全体で固定されます。 
5. 目標点を読み取る$A'$、$B'$、 そして$C'$。 
6. 初期構成が同一線上にある場合は、すべてのターゲット ポイントが同じ線方向で同一線上にあることを確認します。 これは、各点が次の直線方程式を満たすことを確認することによって行われます。$A$そして$B$。 
7. 初期構成が同一線上にない場合は、次の式から外接円の中心と半径を計算します。$A$、$B$、 そして$C$、それぞれを確認します。$A'$、$B'$、 そして$C'$中心までの二乗距離が等しいことを確認することにより、その円上に位置します。 
8. すべてのチェックに合格した場合は「Yes」を出力し、合格しなかった場合は「No」を出力します。 

### なぜ効果があるのか

 不変条件は、すべての有効な動きはその時点で 3 つの点によって定義される一意の円 (または線) を保持するということです。 すべての中間構成は依然として同じ幾何学的制約を満たしているため、システムは最初の円または線から逃れることはできません。 逆に、不変構造を維持しながら各頂点を許容軌跡に沿って再配置できるため、その円 (または線) 上の任意の点に一連の移動で到達できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

def on_line(x, y, x1, y1, x2, y2):
    return cross(x2 - x1, y2 - y1, x - x1, y - y1) == 0

def solve():
    x1, y1, x2, y2, x3, y3 = map(int, input().split())
    a1, b1, a2, b2, a3, b3 = map(int, input().split())

    # check collinearity of initial points
    col = cross(x2 - x1, y2 - y1, x3 - x1, y3 - y1) == 0

    if col:
        ok = (
            on_line(a1, b1, x1, y1, x2, y2) and
            on_line(a2, b2, x1, y1, x2, y2) and
            on_line(a3, b3, x1, y1, x2, y2)
        )
        print("Yes" if ok else "No")
        return

    # circumcircle via perpendicular bisector formula (determinant form)
    xA, yA = x1, y1
    xB, yB = x2, y2
    xC, yC = x3, y3

    d = 2 * (xA*(yB - yC) + xB*(yC - yA) + xC*(yA - yB))

    cx = ((xA*xA + yA*yA)*(yB - yC) +
          (xB*xB + yB*yB)*(yC - yA) +
          (xC*xC + yC*yC)*(yA - yB)) / d

    cy = ((xA*xA + yA*yA)*(xC - xB) +
          (xB*xB + yB*yB)*(xA - xC) +
          (xC*xC + yC*yC)*(xB - xA)) / d

    def on_circle(x, y):
        return abs((x - cx) * (x - cx) + (y - cy) * (y - cy) -
                   (xA - cx) * (xA - cx) - (yA - cy) * (yA - cy))) < 1e-9

    ok = on_circle(a1, b1) and on_circle(a2, b2) and on_circle(a3, b3)
    print("Yes" if ok else "No")

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()
```解決策は、共線的なケースと非共線的なケースを分離することから始まります。これは、それらがそれぞれ直線と円に対応するためです。 ラインの場合、すべてのターゲット ポイントが最初のセグメントで定義された同じ線形方程式を満たすことを確認するだけで済みます。 

円形の場合、垂直二等分線から導出された標準の行列式を使用して外心を計算します。 中心が判明したら、すべての有効な点からその中心までの二乗距離が同じになる必要があります。 この条件は、不変円のメンバーシップを完全に特徴づけます。 

## 実用的な例

 初期点が直角三角形を形成する例を考えてみましょう。 計算された不変量は、3 つの点すべてを通過する円です。 三角形の形状が円に沿って連続的に変形する場合でも、有効な動きはすべてこの円上にすべての点を保持します。 ターゲット構成もこの円上にある場合、答えは到達可能性と一致します。 

ここで、初期点が直線上にある共線的な場合を考えてみましょう。 不変式はその線に縮退し、一連の移動によって非共線的な構成が生成されることはありません。 同一線上にないターゲット セットは直ちに失敗します。 

共線的な場合の痕跡:

 | ステップ | チェック | 結果 |
 | --- | --- | --- |
 | イニシャル | 点は同一線上にあります | 行不変式が修正されました |
 | ターゲット | すべての点が同じ線上にあります | はい |

 これは、アルゴリズムが動きを厳密な幾何学的制約に制限していることを示しています。

 ## 特殊なケース

 重要なエッジ ケースは、3 つの初期点が同一線上にある場合です。 このような状況では、単純な外接円の公式はゼロによる除算によって破綻し、正しい不変式は円ではなく直線になります。 このアルゴリズムは、ゼロクロス積を明示的に検出し、線形チェックに切り替えることでこれを処理します。 

もう 1 つの微妙なケースは、ターゲット構成は同一線上にあるが、初期構成は同一直線上にない場合です。 2 つのターゲット ポイントが元の円上にある場合でも、不変条件は 3 つのポイントすべてにわたって同時にグローバルであるため、円から外れた 1 つのポイントによって変換が直ちに無効になります。
