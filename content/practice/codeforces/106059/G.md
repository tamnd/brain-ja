 ## 解決策
 ## 問題の理解

 最大 100 個の頂点を持つ接続された 2 部グラフが与えられ、各頂点には正の重みが与えられます。 タスクは、エッジに任意に方向を割り当てるだけではなく、特定のコスト関数ができるだけ小さくなるようにすべてのエッジの方向を設定することです。 

グラフの方向を設定すると、一部の頂点には外向きのエッジがなくなります。 これらの頂点は特別なセットを形成し、すべての頂点からそれらの頂点までの最短の有向距離を測定します。 頂点がそのようなシンク頂点に到達できない場合、その距離は非常に長いものとして扱われます。 最終的なコストはこれらの距離の加重合計であり、シンク セットから遠い場合、より重い頂点の寄与が大きくなります。 

したがって、実際の決定は、重みの高い頂点が、方向付けされた観点から、出力次数が 0 の少なくとも 1 つの頂点に近づくようにエッジをどのように配向するかということです。 

制約は十分小さいので、$n \le 100$、ただし、エッジの数は二次になる可能性があります。 これにより、各エッジが状態空間を 2 倍にするため、方向の列挙に依存するものは直ちに排除されます。 頂点またはエッジのサブセットに対する動的プログラミングでも指数関数的になります。 

微妙な点は、距離の定義は、無向距離ではなく、シンク頂点への有向到達可能性に依存することです。 最初にシンクのセットを選択し、次にエッジを内側に「押し込む」という単純なアプローチは、簡単に失敗する可能性があります。シンクの選択を誤ると、一部の頂点が到達不能になり、大きなペナルティが課される可能性があるためです。 

たとえば、パス 1-2-3-4 で、エッジ 1→2→3→4 の方向を誤った場合、頂点 1 はシンクですが、頂点 4 はそこに到達できないため、その距離が無限になり、コストが大きく影響します。 通常、正しい方向を指定すると、すべての頂点が何らかのシンクに向かう方向のパスを持つように、到達可能性のバランスが取れます。 

別の失敗ケースは、サイクルを含む 2 部グラフに表示されます。 1-2-3-4-1 の 4 サイクルでは、一方向のすべてのエッジを選択すると、窪みがまったく作成されず、すべての距離が無限になります。 有効な解決策では、少なくとも 1 つの頂点の出次数が 0 であることを保証する必要があります。 

これらの観察は、最適解の構造には高度な制約があり、任意の方向性はほとんど常に悪いものであることを示唆しています。 

## アプローチ

 ブルート フォース手法では、すべてのエッジの可能な方向をすべて試し、結果のシンク セットを計算し、各頂点の有向グラフで BFS または最短パスを実行し、コストを評価します。 これは定義に直接従うため、原則として正しいです。 ただし、各エッジには 2 つの方向があるため、$2^m$方向性、さらには$m = 100$、これはまったく不可能です。 

重要な洞察は、頂点からシンクまでの距離が短いことが何を意味するかを再解釈することから得られます。 頂点にシンクへの方向のあるパスがある場合、そのパスに沿ってエッジは常にシンク層に向かって移動する必要があります。 これは、エッジが主に高い「レベル」頂点から低い頂点に向かうようにグラフを階層化する必要があることを示唆しています。 

グラフは 2 部構成であるため、非常に強力な構造的制約を利用できます。1 つのパーティションを「フローのソース」として扱い、もう 1 つを「フローのシンク」として扱い、2 つのパーティション全体で一貫してエッジの向きを設定できます。 二分割を修正すると、エッジは一方の側からもう一方の側に移動する必要があるため、各エッジの向きは、有向の意味でどちらの側が「高い」かを選択することに対応します。 

次に、コスト関数が何をしているかを考えてみましょう。 頂点が寄与する$w_i$最も近いシンクまでの距離の倍になります。 これはまさに、出次数が 0 の終端頂点のセットに向かう重み付けされた最短経路の目的です。 最適な構造は、逆の最短パス ツリーのように動作することがわかります。つまり、すべての頂点に、選択したルートのような構造への方向のあるパスが必要であり、重い頂点はその構造に近づく必要があります。 

これは削減につながります。任意の方向について考える代わりに、すべての頂点に最も近いシンクまでの距離に等しいレベルが割り当てられ、すべてのエッジが高いレベルから低いレベルに移動する必要がある有向構造を構築します。 これにより、非循環性が確保され、シンクが正確にレベル 0 頂点であることが保証されます。 

残りの問題は、どの頂点がシンクであるかを選択し、レベルの加重合計を最小限に抑えながらすべてのエッジがレベルを下げるようにエッジをどのように向けるかということになります。 これは、二部構造上の最短パス スタイルの伝播として扱うことで解決できます。最適な構成とは、重み付けされた距離を最小化する一貫した方向割り当てを選択することに相当します。これは、最良のシンク候補から BFS のような階層化を計算し、それに応じてエッジの方向を設定することに帰着します。 

なぜなら$n$が小さい場合は、二分割パリティによって引き起こされる 2 つの可能なグローバル方向を明示的に試し、結果として得られるコストを計算して、最良のものを維持できます。

 ## アルゴリズムのチュートリアル

 この解決策は、2 つのパーティションを修正し、一方を「偶数レベル」、もう一方を「奇数レベル」として扱い、一貫した方向性を評価することに依存しています。 

1. まず、BFS を使用してグラフの 2 分割を計算します。 各頂点には、すべてのエッジが反対の色を接続するように、2 つの色のいずれかが割り当てられます。 この構造は問題によって保証されています。 
2. 方向について考えられる 2 つのグローバルな解釈を考えます。エッジが主にカラー 0 からカラー 1 に向かうか、またはカラー 1 からカラー 0 に向かうかのどちらかです。両方を評価します。 
3. 方向を固定的に選択する場合、選択した「ソース側」からもう一方の側に向かってすべてのエッジを向けることによって、有向グラフを構築します。 これにより、すべての頂点に、選択と一致する、明確に定義された出力エッジのセットが確実に含まれるようになります。 
4. この向きの下で出ていくエッジがない頂点としてシンク頂点を特定します。 これらはまさに、インシデント構造によって強制される外向きエッジを持たない「ターゲット側」の頂点です。 
5. すべてのシンクから開始してエッジの逆方向にマルチソース BFS を実行します。 この BFS は、すべての頂点から任意のシンクまでの最小有向距離を計算します。 
6. 重みと計算された距離のすべての頂点の合計としてコストを計算します。 
7. 反対方向の選択を繰り返し、最小コストの構成を選択します。 
8. 最小コストと、それを達成した対応するエッジ方向の両方を出力します。 

### なぜ効果があるのか

 2 部グラフでは、すべてのエッジが 2 つのパーティション間で交差する必要があります。つまり、無限の距離を回避する有効な方向戦略は、パーティションの境界を横切る方向を一貫して選択する必要があります。 ローカル方向が混在すると、シンクが到達不能になる有向サイクルまたは孤立したコンポーネントが作成されます。 

一貫した方向が固定されると、シンクへの最短パスは、二分化によって引き起こされる有向非循環構造における標準の最短パスになります。 シンクからの BFS はすべての距離を正しく計算します。これは、選択した方向に応じてすべてのエッジが暗黙のレベルを厳密に減少または増加させ、代替のより短い有向ルートが出現するのを防ぐためです。 

コストはこれらの距離によって完全に決定されるため、両方のグローバル方向を評価することで、構造的に有効なすべての構成の中から最適な割り当てが見つかることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

n, m = map(int, input().split())
w = list(map(int, input().split()))

adj = [[] for _ in range(n)]
edges = []

for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append((v, len(edges)))
    adj[v].append((u, len(edges)))
    edges.append((u, v))

# bipartite coloring
color = [-1] * n
q = deque([0])
color[0] = 0
while q:
    u = q.popleft()
    for v, _ in adj[u]:
        if color[v] == -1:
            color[v] = color[u] ^ 1
            q.append(v)

def solve(forward_color):
    # orient edges from forward_color -> other
    outdeg = [0] * n
    orient = []

    for i, (u, v) in enumerate(edges):
        if color[u] == forward_color and color[v] != forward_color:
            orient.append((u, v))
            outdeg[u] += 1
        else:
            orient.append((v, u))
            outdeg[v] += 1

    sinks = [i for i in range(n) if outdeg[i] == 0]

    # reverse graph BFS for distances
    radj = [[] for _ in range(n)]
    for u, v in orient:
        radj[v].append(u)

    dist = [10**9] * n
    dq = deque()

    for s in sinks:
        dist[s] = 0
        dq.append(s)

    while dq:
        u = dq.popleft()
        for v in radj[u]:
            if dist[v] > dist[u] + 1:
                dist[v] = dist[u] + 1
                dq.append(v)

    cost = sum(dist[i] * w[i] for i in range(n))
    return cost, orient

c1, o1 = solve(0)
c2, o2 = solve(1)

if c1 <= c2:
    print(c1)
    for u, v in o1:
        print(u + 1, v + 1)
else:
    print(c2)
    for u, v in o2:
        print(u + 1, v + 1)
```コードは、グラフを読み取り、エッジを明示的に保存することから始まり、後で曖昧さなくエッジの方向を設定できるようになります。 2 部カラーリングは BFS を使用して計算されます。接続によりすべての頂点に到達することが保証されるため、安全です。 

の`solve`関数は、2 分割の一方の側を主方向ソースとして固定します。 その選択に基づいて各エッジの方向を一貫して設定し、出次数を計算してシンクを決定します。 次に、逆隣接リストを使用して、すべてのシンクからマルチソース BFS を実行し、最短の有向距離を計算します。 

最後に、両方のグローバル方向が評価され、最適な方向が対応する有向エッジとともに印刷されます。

 ## 特殊なケース

 重要なエッジ ケースは、2 分割の 1 つの辺に 1 つの頂点が含まれる場合です。 星型構造では、その頂点は方向に応じてユニバーサル シンクまたはユニバーサル ソースになります。 BFS カラーリングでは引き続き有効なパーティションが割り当てられ、方向を反転するとシンクの選択が一貫して反転されるため、アルゴリズムはこれを自然に処理します。 

もう 1 つのケースは、すべての重みが 1 つのエンドポイントに集中する長いパスです。 そのエンドポイントが 1 つの方向のシンクに近くない場合、その寄与が大きくなり、別の方向が最適になります。 距離はパスに沿って直線的に伝播するため、BFS ベースの距離計算ではこの非対称性が正確に反映されます。 

最後のケースは、多くの頂点が同一の構造を持つ密な二部グラフです。 ここでは、複数のシンク セットが等しいコストで存在し、両方の方向が同点になる可能性があります。 このアルゴリズムは、両方のグローバル方向を明示的に評価し、一意性に依存せずに最適な方向を選択するため、正確さを維持します。
