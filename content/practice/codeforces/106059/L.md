 ## 解決策
 ## 問題の理解

 この問題は基本的に、川岸に沿って並んだランタンの列を処理するように求めています。各ランタンはオンまたはオフになっています。 入力により長さ n のシーケンスが得られ、各位置にはランタンが消灯していることを意味する 0 または光っていることを意味する 1 が含まれます。 タスクは、現在点灯しているランタンの数を判断することです。これは、シーケンス内で 1 に等しい値がいくつあるかを数えるのと同じです。 

この声明はフェスティバルの設定でこれを組み立てていますが、生の価値観以上に位置、隣接性、構造については何も重要ではありません。 シーケンスは独立しており、各要素は他の要素と相互作用することなく答えに貢献します。 

n が 2 × 10^5 までの制約は、配列を線形時間でスキャンすることが期待されることを示しています。 同じ要素を繰り返し処理したり、配列に対してネストされたループを使用したりするアプローチは、遅すぎます。 二次解では、最悪の場合、約 4 × 10^10 の演算が必要となり、これは制限時間を大幅に超えます。 これは、単一パスの蓄積が正しい方向であることを直ちに示唆しています。 

ここでのエッジケースは主に入力の書式設定と境界サイズに関するものです。 n = 1 の場合、単純にその 1 つの値を返します。 すべての値が 0 の場合、答えは 0 です。すべての値が 1 の場合、答えは n です。 実装で発生する可能性のある微妙な問題は、2 行目が常にきれいにフォーマットされているか、スペースで区切られた正確に n 個の整数が含まれていると想定しているにもかかわらず、入力が高速な解析を必要とする大きな行にまたがる可能性があることを忘れていることです。 

## アプローチ

 この問題を解決する簡単な方法は、ランタンの状態のリストを直接反復処理し、1 に等しいものがいくつあるかを数える方法です。これは、各ランタンが独立して最終合計に寄与するため機能します。 範囲クエリや位置間の依存関係がないため、並べ替え、プレフィックス構造、またはいかなる形式の前処理も必要ありません。 

この強引な解釈は、依然として各ランタンを個別にチェックし、点灯時にカウンタをインクリメントするものと表現されるかもしれません。 それはすでに構造的に最適です。 この問題では 1 つのグローバル カウントのみが要求されるため、クエリ位置ごとにプレフィックスの合計を再計算するなど、カウントを繰り返し再計算する試みは不要です。 

重要な観察は、入力の構造がすでに最小限であるということです。 変換は必要なく、集計のみが必要です。 これにより、各 1 は正確に 1 単位だけ答えに寄与し、各 0 は何も寄与しないため、問題はバイナリ配列の合計を計算することになります。

 ## アルゴリズムのチュートリアル

 点灯しているランタンの累計を維持しながら、シーケンスを 1 回スキャンします。 

1. ランタンの数 n を読み取ります。 これにより、処理する値の数が決まり、シーケンスを消費した直後に停止することが保証されます。 
2. カウンタをゼロに初期化します。 このカウンターは、これまでに点灯したランタンの数を表します。 
3. 入力シーケンス内の n 個の値のそれぞれを反復処理します。 各値は 1 つのランタンの状態を表します。 
4. 各値について、それが 1 に等しいかどうかを確認します。1 に等しい場合は、カウンタを 1 つ増やします。 0の場合は何もしません。 このステップが機能するのは、各ランタンが独立して貢献し、点灯しているランタンのみが最終的なカウントに影響するためです。 
5. すべての値を処理した後、カウンターを出力します。 この時点で、入力シーケンスで点灯したランタンの総数が含まれます。 

### なぜ効果があるのか

このアルゴリズムは、最初の k 要素を処理した後、カウンターがそれらの k 要素内の 1 の数に等しいという不変条件を維持します。 プレフィックス内の点灯しているランタンの実際の数を変更する唯一の方法は、現在の要素が 1 の場合にそれを含めることであるため、各ステップではこの不変条件が維持されます。すべての要素は 1 回だけ処理され、1 の場合にのみ 1 回だけ寄与するため、最終的なカウンターはシーケンス全体の点灯しているランタンの合計数と等しくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    arr = list(map(int, input().split()))
    
    cnt = 0
    for x in arr:
        cnt += x
    
    print(cnt)

if __name__ == "__main__":
    solve()
```このソリューションは、サイズ n を読み取り、2 行目全体を整数リストに解析します。 値は 0 または 1 のみなので、それらを直接合計することは、点灯している提灯を数えるのと同じであり、コンパクトで効率的です。 

よくある落とし穴は、特に n が大きい場合に、入力行を削除するか正しく分割することを忘れることです。 使用する`sys.stdin.readline`高速な読み取りを保証します。 もう 1 つの微妙な点は、値が小さく、Python ではオーバーフローの危険がないため、ここでは整数の合計が安全であるということです。

 ## 特殊なケース

 n = 1、値 0 の場合、アルゴリズムはカウンターを 0 に初期化し、単一の要素を読み取り、それが 1 ではないことを検出し、0 を出力します。これは、点灯しているランタンがないため、予想される動作と直接一致します。 

n = 1、値 1 の場合、カウンターは 0 から開始し、1 回インクリメントされて 1 を出力します。これにより、最小ではない入力サイズでの正確性が確認されます。 

n = 5 や [0, 0, 0, 0, 0] など、すべてがゼロの場合、反復ごとにカウンターは変更されないため、最終結果は 0 のままとなり、ランタンが点灯していないことと一致します。 

n = 5 や [1, 1, 1, 1, 1] など、すべて 1 の場合、反復ごとにカウンターがインクリメントされるため、正確に n が蓄積されます。 これは、高密度の入力に対して特別な処理を必要とせずに、アルゴリズムが線形にスケールすることを示しています。
