 ## アルゴリズムのチュートリアル

 文字列の間隔にわたって DP 状態を定義します。 させて$dp[l][r]$部分文字列を分割する有効な方法の数を表します$s[l..r]$誘導されたラベル配列が回文であるセグメントに分割されます。 

1. 空の間隔の基本ケースを初期化します。 もし$l > r$、部分文字列は完全に消費されており、これまでのすべての選択が有効な対称構造を形成しているため、これはちょうど 1 つの有効な構造に対応します。 
2. インターバルごとに$[l, r]$、部分文字列全体を 1 つのセグメントとして取得する場合を考えてみましょう。 これにより、長さ 1 のシーケンスが生成されますが、これは自明のことながら回文です。 これにより、間隔ごとに 1 つの有効な方法が提供されます。 
3. それ以外の場合は、少なくとも 2 つのセグメントを形成します。 から始まる左側のセグメントを選択します$l$長さのある$a$、およびで終わる右セグメント$r$長さのある$b$。 これらを削除した後、残る問題は次のとおりです。$dp[l+a][r-b]$。 
4. これら 2 つのセグメントが同じ外層で有効であるためには、同じラベルを生成する必要があります。 セグメントのラベルは、それが次のプレフィックスと等しいかどうかをチェックして計算します。$t$同じ長さの。 この条件は、次の部分文字列間の事前計算された一致を使用して定数時間で評価できます。$s$と接頭辞$t$。 
5. セグメント長の有効なペアごとに$(a, b)$、両方のセグメントが区間内に留まり、それらのラベルが一致する場合、次のように追加します。$dp[l+a][r-b]$の答えに$dp[l][r]$。 
6. 必要なときにすべての小さな部分問題がすでにわかっているように、間隔の長さの増加順に状態を計算します。 

これが機能する理由は、有効なパーティションには明確に定義された最初と最後のセグメントが必要であるという事実から来ています。 これら 2 つのセグメントは、回文性を維持するために同じラベルを共有する必要があります。 それらが修正されると、その内部のすべてが独立し、同じ問題のより小さなインスタンスを形成します。 すべての有効なパーティションは、そのような外部選択の 1 つのシーケンスに正確に対応するため、DP は重複することなく各構造を正確に 1 回列挙します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_match(s, t):
    n = len(s)
    m = len(t)
    good = [[False] * (n + 1) for _ in range(n)]

    for i in range(n):
        cur = 0
        for l in range(1, n - i + 1):
            if l <= m and s[i + l - 1] == t[l - 1]:
                good[i][l] = True
            else:
                good[i][l] = False
    return good

def solve():
    MOD = 998244353
    n, m = map(int, input().split())
    s = input().strip()
    t = input().strip()

    good = build_match(s, t)

    dp = [[0] * n for _ in range(n)]

    for length in range(1, n + 1):
        for l in range(0, n - length + 1):
            r = l + length - 1

            dp[l][r] = 1

            if l == r:
                continue

            for a in range(1, length + 1):
                if l + a - 1 > r:
                    break

                # left segment [l, l+a-1]
                for b in range(1, length + 1):
                    if r - b + 1 < l + a:
                        break

                    # check labels
                    left_good = good[l][a] if a <= m else False
                    right_good = good[r - b + 1][b] if b <= m else False

                    if left_good != right_good:
                        continue

                    dp[l][r] = (dp[l][r] + dp[l + a][r - b]) % MOD

    print(dp[0][n - 1])

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()

比較`left_good != right_good`両方の外側セグメントが同じビットを生成するように強制します。これは、その層での回文対称性に必要です。
