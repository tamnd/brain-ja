 ## 解決策
 ## 問題の理解

 一定の長さの文字列を構築しています$n$正確に 7 つの記号からなる固定アルファベットを使用します。$a$に$g$。 文字列内のすべての位置はこのアルファベットとは独立して選択されますが、結果として得られるすべての文字列が許可されるわけではありません。 この制限は、一連の禁止されたルールに基づいて行われます。 各ルールには文字の小さなサブセットがリストされており、いずれかのルールのすべての文字が文字列内のどこかに少なくとも 1 回含まれている場合、文字列は無効になります。 

したがって、それぞれのルールは隣接性や順序に関するものではなく、存在に関するものです。 のようなルール$\{b, c, d\}$少なくとも 1 つを含む文字列を禁止します$b$、少なくとも 1 つ$c$、少なくとも 1 つ$d$、どこに表示されるかに関係なく。 

タスクは、有効な長さの数を数えることです。$n$文字列はこれらの制約の下で存在します (モジュロ)$10^9 + 7$。 重要な難点は、$n$と同じ大きさにすることができます$10^9$したがって、位置を反復処理したり、文字列を明示的に構築したりすることはできません。 制約の構造は、純粋な組み合わせカウントに圧縮する必要があります。 

アルファベットのサイズは 7 で一定であり、これが構造上の最も重要なヒントです。 どのような解決策でも、最終的には文字列内の位置ではなく、これら 7 文字のサブセットを検討する必要があります。 

文字列をシミュレートまたは列挙し、文字列ごとの制約をチェックしようとすると、単純な障害モードが表示されます。 たとえ$n=50$、文字列の数は$7^{50}$、これは大きすぎます。 もう 1 つの微妙な間違いは、ルールを独立して扱い、重複を処理せずにルールごとに無効なカウントを減算することです。これにより、文字列が同時に複数のルールに違反した場合に二重カウントが発生します。 

## アプローチ

 ブルートフォースのアイデアは単純です。すべてを生成します。$7^n$文字列を検索し、ルール内のすべての文字が含まれているかどうかを確認して、すべての禁止されたルールに対してそれぞれをテストします。 これは正しいですが、すべての文字列を保存したり反復したりすることさえ不可能であるため、直ちに実行不可能です。$n$小さな値を超えて。 

もう少し良い試みは、ルールごとに、そのすべての文字を含む文字列の数を計算し、合計から減算することです。$7^n$。 ただし、ルールが重なり合うため、これはうまくいきません。 単一の文字列が複数のルールに違反する可能性があり、ルールのすべてのサブセットにわたる包含と除外は複雑で非効率的になります。$m < 27$指数サブセットはまだ許可されていますが、実際の構造はルール内にあるのではなく、文字サブセット内にあります。 

重要な変化は、ルールの観点から考えるのをやめ、代わりに文字列の中にどの文字が現れるのかという観点から考えることです。 任意の文字列がサブセットに対応します$S \subseteq \{a,\dots,g\}$少なくとも 1 回出現する文字。 このサブセットが修正されると、それを実現する文字列の数は次の要素のみに依存します。$n$、アレンジメントではありません。 

文字列が次の文字を正確に使用している場合、$S$、各位置は次から選択されます$S$、しかし、のすべての要素$S$少なくとも 1 回は出現する必要があります。 これは、サブセットに対する古典的な包含と除外です。$S$ただし、完全なスターリング数は直接必要ありません。$|S|\le 7$。 

2 番目の重要な観察は、ルールは包含にのみ依存するということです。ルールはサブセットを禁止します。$T$選択したアルファベットのサブセットの場合$S$満足する$T \subseteq S$。 したがって、可能なそれぞれについて$S$、禁止されたルールのサブセットが含まれているかどうかだけを知る必要があります。 

アルファベットのサイズは 7 なので、すべてのサブセットを 7 ビット マスクとして表すことができます。 各ルールはマスクと候補アルファベットです$S$禁止マスクがサブマスクとして含まれていない場合に有効です。 

有効な値を修正したら、$S$、正確にそれらの文字にわたる文字列の数は次のとおりです。$$f(S) = \sum_{k=0}^{|S|} (-1)^k \binom{|S|-k}{\cdot} (|S|-k)^n$$しかし、より明確に言えば、使用されている文字のセットが正確に一致する文字列の標準的な数です。$S$、のサブセットに対する包含-除外を介して計算されます。$S$:$$f(S) = \sum_{T \subseteq S} (-1)^{|S|-|T|} |T|^n$$ここで問題は、7 文字のすべてのサブセットを反復処理し、ルールに違反しないものをフィルタリングして合計することになります。$f(S)$。 

なぜなら$2^7 = 128$、これはべき乗を事前計算しても完全に管理可能です$k^n$のために$k \in [0,7]$。

 ## アルゴリズムのチュートリアル

 文字をエンコードします$a$に$g$0 から 6 までのビットとして表されるため、すべてのサブセットは整数マスクになります。$[0, 127]$。 

1. すべてのルールを読み取り、各ルールをビットマスクに変換します。$R_i$。 これにより、ビット操作を使用して封じ込めを迅速にテストできます。 ルールがセットに違反しています$S$まさにいつ$(R_i \& S) = R_i$。 
2. 事前計算能力$p[k] = k^n \bmod (10^9+7)$のために$k = 0$に$7$。 これは、サイズのアルファベットにわたる文字列の数をキャプチャします。$k$制限なしで。 これが機能するのは、文字のサブセットを固定すると、各位置が独立してその中から選択されるためです。 
3. すべてのサブセットを反復処理します。$S$の$\{0,\dots,6\}$。 各サブセットは、候補文字列で許可される文字のセットを表します。 
4. サブセットごとに$S$、すべてのルールに対して有効性をチェックします。 ルールマスクが存在する場合$R$そのような$R \subseteq S$の場合、禁止条件に違反するため、このサブセットをスキップします。 
5. もし$S$が有効な場合、そのサブマスクに対する包含/除外を使用してその寄与を計算します。 

から始める$res = 0$、次に各サブネットマスクについて$T \subseteq S$、加算または減算$p[|T|]$のパリティに応じて$|S|-|T|$。 これにより、次の文字を正確に使用する文字列のみがカウントされるようになります。$S$。 
6. すべての有効なサブセットにわたる寄与を合計する$S$、モジュロを取る$10^9+7$。 

### なぜ効果があるのか

 すべての文字列はサブセットに一意に対応します$S$その中に出てくる文字のこと。 アルゴリズムは、すべての文字列をこのサブセットごとに分割します。 包含/除外式により、各文字列は、より小さなサブセットではなく、その正確な使用文字セットに対応する用語内で 1 回だけカウントされることが保証されます。 ルールのフィルタリングにより、使用されている文字に禁止されたサブセットが完全に含まれていないことが保証されるため、最終的な合計に無効な文字列が含まれることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def popcount(x):
    return bin(x).count("1")

n, m = map(int, input().split())

rules = []
for _ in range(m):
    parts = input().split()
    k = int(parts[0])
    mask = 0
    for c in parts[1:]:
        mask |= 1 << (ord(c) - ord('a'))
    rules.append(mask)

# precompute k^n
powk = [1] * 8
for k in range(1, 8):
    powk[k] = pow(k, n, MOD)

# precompute all subsets of 7 bits
ALL = 7

ans = 0

for S in range(1 << ALL):
    ok = True
    for r in rules:
        if (r & S) == r:
            ok = False
            break
    if not ok:
        continue

    sub = S
    res = 0
    while True:
        bits = popcount(sub)
        sign = 1 if ((popcount(S) - bits) % 2 == 0) else -1
        res = (res + sign * powk[bits]) % MOD

        if sub == 0:
            break
        sub = (sub - 1) & S

    ans = (ans + res) % MOD

print(ans % MOD)
```コードは、各禁止ルールをビットマスクにエンコードすることから始まり、ビット単位の演算を使用した定数時間のサブセット チェックを可能にします。 配列`powk`店$k^n$これは、文字のサブセットを固定した後、すべての位置が独立してそれらの文字の中から選択されるため、有効です。 

外側のループは、文字の可能なすべてのサブセットを列挙します。 各サブセットはすべてのルールに対してテストされ、禁止されたパターンが完全に含まれている場合は拒否されます。 内側のサブマスク ループは、サブセットに対して包含/除外を実装し、使用されている文字のセットが正確に一致する文字列を確実にカウントします。$S$、適切なサブセットではありません。 

交互の符号は、から削除される文字の数のパリティによって決まります。$S$、サブセットに対する標準の包含-除外原則に一致します。

## テストケース```python
import sys, io

MOD = 10**9 + 7

def solve(inp):
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n, m = map(int, input().split())

    rules = []
    for _ in range(m):
        parts = input().split()
        k = int(parts[0])
        mask = 0
        for c in parts[1:]:
            mask |= 1 << (ord(c) - ord('a'))
        rules.append(mask)

    powk = [1] * 8
    for k in range(1, 8):
        powk[k] = pow(k, n, MOD)

    ans = 0
    for S in range(1 << 7):
        ok = True
        for r in rules:
            if (r & S) == r:
                ok = False
                break
        if not ok:
            continue

        sub = S
        res = 0
        while True:
            bits = bin(sub).count("1")
            sign = 1 if ((bin(S).count("1") - bits) % 2 == 0) else -1
            res = (res + sign * powk[bits]) % MOD

            if sub == 0:
                break
            sub = (sub - 1) & S

        ans = (ans + res) % MOD

    return ans % MOD

 ## 特殊なケース

 微妙なケースの 1 つは、ルールがまったくない場合です。 この場合、文字のすべてのサブセットが有効になり、アルゴリズムはすべてのサブセットの包含と除外を合計することになり、正確に折りたたまれます。$7^n$。 サブセットがフィルターで除外されないため、コードはこれを自然に処理します。 

もう 1 つのケースは、ルールに 7 文字すべてが含まれる場合です。 任意のサブセット$S$空ではない場合は直ちに違反し、空のサブセットのみが残ります。 のために$n > 0$、空のサブセットはゼロに寄与します。$0^n = 0$、したがって、答えはゼロになります。空でない文字列はすべてルールに違反するため、これは正しいです。 

最後の興味深いケースは、次のような重複ルールです。$\{a,b\}$そして$\{b,c\}$。 のようなサブセット$\{a,b,c\}$は両方に違反しますが、妥当性チェックはルールごとの減算ではなく単純な存在テストであるため、拒否されるのは 1 回だけです。
