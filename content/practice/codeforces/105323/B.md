 ## アルゴリズムのチュートリアル

 この条件をモジュール位置の一貫性チェックに再定式化します。 

1. の各値について$T$、最初に出現したインデックスを記録します。 これにより、その値の基準位置が定義されます。 これが役立つ理由は、有効な埋め込みでは、各値がピリオド付きで定期的に表示されるためです。$m$したがって、すべてのオカレンスは固定開始オフセットを基準にして位置合わせする必要があります。 
2. 同じ値がその後出現するたびに、最初の出現と比較したインデックスの差を計算します。 この差が割り切れない場合は、$m$の場合、同じ数値が順列ブロック内の異なる位置に出現することになり、各ブロックに各値が 1 回だけ含まれるという事実に矛盾するため、埋め込みは不可能です。 
3. すべての値がこの合同条件を満たしている場合、シーケンスには一貫した開始オフセット モジュロを割り当てることができます。$m$。 これにより、ブロック内の一意性を侵害することなく、各値のすべての出現を何らかのブロックに配置できるようになります。 
4. スキャン中に矛盾が見つからなかった場合は「YES」を返し、そうでない場合は「NO」を返します。

 それぞれの値$x$無限シーケンスの中で$S$ある長さのブロックごとに 1 回だけ出現します$m$。 これは、次のような現象が発生することを意味します。$x$共通の差を持つ等差数列を形成する$m$。 の有効な埋め込み$T$すべての出現箇所を整列させる必要があります$x$の倍数異なる位置に$m$。 たとえ 1 対の出現でもこの間隔に違反する場合、ブロック構造は厳格でグローバルであるため、ブロック境界を移動してもそれらを調整することはできません。

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    T = list(map(int, input().split()))
    
    first_pos = {}
    
    for i, x in enumerate(T):
        if x not in first_pos:
            first_pos[x] = i
        else:
            if (i - first_pos[x]) % m != 0:
                print("NO")
                return
    
    print("YES")

if __name__ == "__main__":
    solve()
```この解決策は、各値の最初の出現インデックスを保存し、その後のすべての出現がモジュロを遵守するように強制することに依存しています。$m$制約。 各要素が 1 回処理され、辞書検索によって値のグループ化が効率的に処理されるため、ロジックは線形です。
