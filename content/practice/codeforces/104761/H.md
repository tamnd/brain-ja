 ## 問題の理解

 指定された数のコマンドのバイナリ コードブックを設計するように求められます。$K$。 各コマンドは、一定の長さのバイナリ文字列です。$Len$を割り当てなければなりません$K$独特の文字列。 

これらの文字列は任意のものではありません。 これらは 2 つの構造上の制約を満たさなければなりません。 まず、すべての文字列には同じ数の 1 が含まれている必要があります。 次に、選択したすべての文字列の任意のビット位置を調べ、その位置に 1 がある文字列がいくつあるかを数えると、これらのカウントは位置全体でほぼ均一であり、最大 1 の違いがある必要があります。 

考えられるすべての有効な構造の中で、可能な限り最小の均一な長さが必要です。$Len$有効なセットを出力する必要があります。$K$それを達成する文字列。 

主な問題点は、制約が 2 つの異なる方法で文字列を結合していることです。 1 つの制約は文字列ごと (固定ハミング重み) であり、もう 1 つは位置ごと (バランスのとれた列合計) です。 これにより、非常に対称的な構造が強制されます。本質的に、固定された行の合計とほぼ等しい列の合計を持つ、非常に規則的な出現行列を構築することになります。 

制約は十分小さいので余裕があります$Len \le 100$、 しかし$K$まで可能です$10^4$したがって、すべてのバイナリ文字列の列挙や組み合わせ検索に依存する構築は避けなければなりません。 

単純なアプローチでは、指定された長さのすべての文字列を生成し、行と列の両方の制約のバランスがとれたサブセットを選択しようとします。 これはすぐに失敗します。$Len = 20$、候補者の数は$2^{20}$、大きすぎます。 

より微妙な障害モードは、位置ごとに貪欲に割り当てようとすることから発生します。 たとえば、各行に固定の重みを強制しながら各位置を個別に埋めようとすると、一意性や均一な行の重みを損なわずに局所的に修正できない衝突や不均衡な列数が簡単に発生する可能性があります。 

中心的な課題は、構造が検索ではなく直接構築できるほど対称的であることを認識することです。

 ## アルゴリズムのチュートリアル

 1.最小の偶数を見つけます$Len$少なくとも存在するように$K$長さのバイナリ文字列$Len$同じ数の 1 で。 安心してご利用いただけます$Len = 2, 4, 6, \dots$それまで$\binom{Len}{Len/2} \ge K$中間層は利用可能な一定の重みの文字列を最大化するためです。 これにより、実現可能性と最小限性の両方が保証されます。 
2. 重りを固定する$R = Len / 2$。 この選択により、列数のバランスを取るために必要なビット位置全体の対称性が最大化されます。 
3. すべての長さの文字列の中から辞書編集順にバイナリ文字列を生成します。$Len$まさに$R$もの。 各文字列は選択に対応します$R$範囲外のポジション$Len$、辞書編集的な生成により、重複のない決定的なカバレッジが保証されます。 
4. 最初のものを取る$K$生成された文字列。 これにより、すべての文字列が構造上区別できるようになります。 
5. 出力$Len$そして選択された文字列。 

これが機能する理由は対称性に基づいています。 全部のセット$R$-ones 文字列はビット位置の順列の下で不変であるため、すべての座標は完全なセット内でまったく同じ数の文字列に表示されます。 最初を取る$K$対称的な順序付けの文字列は、ほぼ均一性を維持します。完全に対称的なマルチセットから要素を削除すると、各文字列が正確に寄与するため、列数は最大で 1 つ変更されます。$R$全体に分散されているもの$Len$完全なセットでは出現が均等に分散されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from math import comb

def generate(K):
    for Len in range(2, 101, 2):
        R = Len // 2
        if comb(Len, R) >= K:
            return Len, R

def next_combination(x):
    c = x & -x
    r = x + c
    return (((r ^ x) >> 2) // c) | r

def solve():
    T = int(input())
    for _ in range(T):
        K = int(input())
        Len, R = generate(K)

        mask = (1 << R) - 1
        res = []

        for _ in range(K):
            s = format(mask, f"0{Len}b")
            res.append(s)
            mask = next_combination(mask)

        print(Len)
        print(" ".join(res))

if __name__ == "__main__":
    solve()
```構築は、中間の二項層が十分に大きい最小の偶数長を選択することから始まります。 これにより、選択できることが保証されます$K$異なる一定の重みを持つ文字列。 

ビットマスク方式は、1 の位置の組み合わせをエンコードします。 正確な各整数マスク$R$設定されたビットは 1 つの有効なコマンドに対応します。 の`next_combination`関数は、同じ数の設定ビットを使用して次の辞書編集マスクを生成し、異なる文字列を効率的に列挙できるようにします。$O(K)$時間。 

バイナリ形式の手順では、先頭のゼロを保持して各マスクを固定長の文字列に変換します。文字列の長さは均一でなければならないため、これは不可欠です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import comb

    def next_combination(x):
        c = x & -x
        r = x + c
        return (((r ^ x) >> 2) // c) | r

    def solve():
        T = int(input())
        for _ in range(T):
            K = int(input())
            for Len in range(2, 101, 2):
                R = Len // 2
                if comb(Len, R) >= K:
                    mask = (1 << R) - 1
                    print(Len)
                    out = []
                    for _ in range(K):
                        out.append(format(mask, f"0{Len}b"))
                        mask = next_combination(mask)
                    print(" ".join(out))
                    break

    old_stdout = sys.stdout
    sys.stdout = io.StringIO()
    solve()
    out = sys.stdout.getvalue()
    sys.stdout = old_stdout
    return out.strip()

# provided sample
assert run("3\n1\n2\n3\n") != ""

# K = 1 minimal
assert run("1\n1\n") == "2\n01"

# small multiple test
assert run("1\n2\n") != ""

# larger K boundary
assert run("1\n5\n") != ""
