 ## 問題の理解

 原点までの距離が正確に一致する第 1 象限内のすべての格子点を見つけるように求められます。$D\sqrt{2}$。 距離を二乗すると平方根が削除されるため、実際には負でない整数のペアをすべて検索します。$(x, y)$そのような$$x^2 + y^2 = 2D^2.$$その中で、以下のものだけを出力します。$x \le y$、最終的なリストは昇順に並べ替える必要があります。$x$。 

制約$D \le 10^6$は、右辺の定数が次のように大きくなり得ることを意味します。$2 \cdot 10^{12}$。 すべてのペアを試す素朴なアプローチ$(x, y)$まで$2D$約必要になる$4 \cdot 10^{12}$チェックしますが、これは完全に不可能です。 全部チェックしても$x$値だけで約$2 \cdot 10^6$反復。これは境界線にありますが、各反復が定数時間であれば Python で管理可能です。 

さらに重要な微妙な点は、有効な解決策が非常に希薄であることです。 固定の場合$D$、方程式は半径の円上の格子点を記述します。$\sqrt{2}D$、そのような円には通常、整数点がほとんどありません。 このまばらさこそが、$O(D)$または、わずかに優れた列挙も許容されます。 

すべてをループする単純な実装$x$、計算します$y^2 = 2D^2 - x^2$、完全な平方であるかどうかをチェックすることで、すでに意図した解決策に近づいていますが、大きなオーバーヘッドを付けて実装したり、不注意に浮動小数点平方根を繰り返したりすると、パフォーマンスの問題が発生する危険があります。 

## アプローチ

 この問題を解決する直接的な方法は、1 つの座標を修正することです。$x$、対応するを計算します$y$方程式から$y^2 = 2D^2 - x^2$。 結果が完全な正方形の場合、そのペアを受け入れます。 

これが機能するのは、すべての有効な解が方程式を正確に満たす必要があるためです。$x$解決策を見逃さないことを保証します。 ただし、このブルート フォース スキャンは最大で実行されます。$2D$反復し、各反復で平方根と検証を実行します。 と$D = 10^6$、これは約 200 万回の反復であり、許容範囲内ですが、慎重に実装しないと Python では依然として遅くなる可能性があります。 

ガウス整数を使用して方程式を書き直すと、より構造的な観察が得られます。 アイデンティティ$$x^2 + y^2 = 2D^2$$次のように因数分解できます$$(x + iy)(x - iy) = 2D^2.$$以来$2 = (1+i)(1-i)$、次の形式でソリューションを書き直すことができます。$$x + iy = (1+i)(u + iv),$$に拡張されます$$x = u - v,\quad y = u + v.$$back を代入すると、$$x^2 + y^2 = 2(u^2 + v^2),$$したがって、問題を整数のペアを見つけることに縮小します$(u, v)$そのような$$u^2 + v^2 = D^2.$$この変換は、元の制約を標準的な問題 (半径円上の格子点を見つける) に変えるので便利です。$D$。 それぞれのペア$(u, v)$解決策を直接生成します$(x, y)$、非負性を強制する以上のフィルタリングは必要ありません。 

あとは解決策を列挙するだけです。$u^2 + v^2 = D^2$、すべてをスキャンするよりも大幅にまばらです。$(x, y)$ペア。

 ## アルゴリズムのチュートリアル

 1. 方程式を修正する$u^2 + v^2 = D^2$、半径の円上のすべての格子点を表します$D$。 すべての有効な整数のペアを列挙します$(u, v)$と$u, v \ge 0$。 
2. 反復する$u$から$0$に$D$。 値ごとに計算します$v^2 = D^2 - u^2$。 これにより、方程式と一致する候補のみを考慮することが保証されます。 
3. かどうかを確認します。$v^2$は完全な正方形です。 そうでない場合は、これを破棄します$u$。 そうであれば計算してください$v = \sqrt{v^2}$そしてそれが整数であることを確認します。 
4. 有効なペアごとに$(u, v)$、変換を使用して元の問題の解決策を構築します。$$x = u - v,\quad y = u + v.$$これにより保証されます$x^2 + y^2 = 2D^2$。 
5. 解決策のみを保管してください。$x \ge 0$。 この条件は次と同等です$u \ge v$したがって、無効なケースを暗黙的にフィルタリングします。 
6. それぞれの有効な値を保存します$(x, y)$ペアにして結果を並べ替える$x$列挙順なので出力前$u$ソートを厳密に保証するものではありません$x$。 

### なぜ効果があるのか

 重要な不変条件は、すべての表現が$u^2 + v^2 = D^2$正確に 1 つの有効な構造に対応します$x = u - v, y = u + v$満足のいく$x^2 + y^2 = 2D^2$。 変換は可逆的です。どのような解決策でも可能です。$(x, y)$にマッピングし直すことができます$(u, v)$経由$u = (x + y)/2$、$v = (y - x)/2$、これは整数でなければなりません。$x + y$そして$y - x$パリティを共有します。 この全単射により、解が見逃されたり、無効な解が導入されたりすることがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def solve():
    D = int(input())
    D2 = D * D
    res = []

    for u in range(D + 1):
        v2 = D2 - u * u
        if v2 < 0:
            continue
        v = int(math.isqrt(v2))
        if v * v != v2:
            continue

        x = u - v
        y = u + v

        if x < 0:
            continue

        res.append((x, y))

    res.sort()
    print(len(res))
    for x, y in res:
        print(x, y)

if __name__ == "__main__":
    solve()

条件`x < 0`変換後に必要な象限制限を強制し、対称解の正規の半分のみを保持することを暗黙的に保証します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import isqrt

    D = int(sys.stdin.readline())
    D2 = D * D
    res = []

    for u in range(D + 1):
        v2 = D2 - u * u
        if v2 < 0:
            continue
        v = isqrt(v2)
        if v * v != v2:
            continue
        x = u - v
        y = u + v
        if x >= 0:
            res.append((x, y))

    res.sort()
    out = [str(len(res))]
    out += [f"{x} {y}" for x, y in res]
    return "\n".join(out)

 ## 特殊なケース

 主なエッジケースは次のような場合です$u < v$、負の値が生成されます$x = u - v$。 たとえば、$u = 0, v = D$、私たちは得ます$x = -D$、許可された領域外にあります。 アルゴリズムはこれらのケースを明示的にフィルタリングするため、変換後にポイントが第 1 象限にのみ保持されることが保証されます。 

もう 1 つのエッジケースは次のような場合です$v = 0$に対応します。$u = D$。 これによりポイントが生成されます$(x, y) = (D, D)$これは常に有効であり、最小限の保証されたソリューションを形成します。
