 ## 解決策
 ## 問題の理解

 私たちは、未知のマス目にビショップが配置される 8 × 8 ボード上の隠れたチェス問題を操作しています。 その位置はわかりませんが、任意のマスをクエリして、隠れた位置からそのマスに到達するために必要なビショップの最小移動回数に関するフィードバックを受け取ることができます。 正方形に到達できない場合、応答は -1 になります。 

各クエリは、頂点が正方形であり、辺が同じ対角線上にある正方形を接続するグラフ内の距離を示します。 ビショップは対角線に沿って移動するため、到達可能性は正方形の色によって決まります。2 つの正方形は、行と列のパリティを共有する場合にのみ到達可能です。 

私たちのタスクは、最大 10 個のクエリを使用して正確な隠れた正方形を特定し、それを出力することです。 

制約は非常に小さく、ボードには 64 の可能な状態しかありません。 これにより、漸近的な懸念は即座に排除されます。 この課題は純粋に情報提供のためのものであり、ビショップの移動制約を尊重しながら検索空間を効率的に分割するクエリを設計する必要があることを意味します。 

素朴なアプローチは、すべての正方形までの距離がゼロかどうかを尋ねることによってテストすることです。 これには最大 64 個のクエリが必要となり、制限に違反します。 フィードバックは座標ベースではなくグラフ距離ベースであるため、行と列のバイナリ検索もここでは意味がありません。 

微妙な問題は、到達不能なクエリが -1 を返すことです。 これにより、ボードが 2 つの切り離されたカラー クラスに分割されます。 これを無視すると、誤って不可能な正方形を候補として扱ってしまう可能性があります。 

## アプローチ

 重要な観察は、ビショップの距離メトリックが、慎重に選択された少数のクエリでその位置を一意に決定するのに十分な構造をエンコードしていることです。 

8 x 8 ボードでは、すべての正方形をカラー パリティによって分類できます。 黒のマスからスタートしたビショップは決して白のマスに到達することはできません。 これは、特定のマスに対して -1 を返す単一のクエリの後に、ボードのちょうど半分が直ちに除外されることを意味します。 さらに重要なのは、正方形に到達できる場合、距離は 0、1、または 2 のいずれかになります。これは、同じ色の 2 つの正方形が同じ対角線上にあるか (距離 1)、中間の対角線の交差点 (距離 2) を 1 つだけ経由して接続できるためです。 

したがって、各クエリは単なる距離プローブではなく、大まかな分類ツールでもあります。 

結果が 0 の場合は、隠れた四角形がすぐに識別されます。 

結果が 1 の場合、隠された正方形が、クエリされた正方形を通過する 2 つの対角線の 1 つにあることがわかります。 

結果が 2 の場合、隠れた正方形は同じ色ですが、対角線を共有していないことがわかります。 

結果が -1 の場合、反対色のすべての正方形が削除されます。 

これにより、クエリごとに候補セットを大幅に縮小する戦略が可能になります。 まず、クエリを使用してカラー パリティを決定します。 次に、慎重に選択した対角線の交点を使用して、正方形の位置を特定します。 

きれいな構造は、最初に固定正方形 (A1 など) をクエリすることです。 これにより、ビショップの色に応じてボードが到達可能な半分と到達不可能な半分に分割されます。 次に、少数の候補で対角線が交差するように選択されたさらに 2 つの正方形をクエリし、1 つの正方形だけが残るまで徐々に絞り込みます。 各クエリによって候補セットがおよそ 2 ～ 4 分の 1 に削減されるため、10 クエリ以内に答えを決定的に分離できます。 

ブルート フォースでは、距離 0 が表示されるまですべての正方形を試し、それぞれをクエリします。 これは正しいですが、クエリ制限を超えています。 最適化されたアプローチでは、ビショップ移動の構造を活用して、クエリごとに大きな正方形のセットを排除します。

 ## アルゴリズムのチュートリアル

可能なビショップポジションのセットを徐々に縮小するクエリを設計します。 

1. 固定正方形 (A1 など) をクエリし、応答を読み取ります。 

答えが -1 の場合、ビショップの色が異なることがわかります。 負でない場合、そのカラー クラスは A1 と一致することがわかります。 
2. 色の制約と一致するすべての正方形のリストを維持します。 最初は、これは 32 マス (A1 と同じ色) または 32 マス (反対の色) のいずれかです。 
3. D4 などの対角構造に基づいて残りの候補を分割する正方形をクエリします。 

応答が 0 の場合、作業は完了です。 1 の場合、ビショップは D4 を通る 2 つの対角線の 1 つに位置します。 2 の場合、同じ色上にありますが、対角線から外れています。 
4. 応答によって暗示される制約を使用して候補セットを交差させます。 

これにより、各対角線が最大 8 つの正方形をカバーするため、可能な正方形の数が大幅に減少します。 
5. 残りの対角グループを二等分する慎重に選択した正方形で繰り返します。 効果的な決定論的戦略の 1 つは、A1、H1、A8、H8、D4、E5、D5、E4 などの独立した対角パーティションをカバーするプローブ正方形の固定シーケンスを循環させることです。 
6. 各クエリの後、クエリの正方形からの事前計算された距離が応答と一致するすべての正方形をフィルタリングすることにより、候補セットを更新します。 
7. 候補が 1 つだけ残った場合、それを隠しビショップ位置として出力します。 

重要なアイデアは、各クエリが「隠れた正方形はビショップ グラフのこの頂点から距離 K である」という形式の制約を追加し、いくつかのそのような制約の交差によってこの小さなグラフの頂点を一意に決定するということです。 

### なぜ効果があるのか

 8 x 8 ボード上のビショップの動きのグラフは高度に構造化されており、各色コンポーネント内の直径は最大 2 です。 各クエリは、候補セットを最大 3 つの意味のあるクラス (到達不能、同じ対角線 (距離 1)、または同じ色だが異なる対角線 (距離 2)) に分割します。 複数の独立した対角制約が適用されると、グラフの対称性が非常に低くなるため、少数のそのようなパーティションを交差させると、単一の頂点が一意に識別されます。 維持される不変条件は、隠れた正方形が常に現在の候補セットに含まれており、各クエリは真の位置を決して削除することなくセットのサイズを厳密に縮小することです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

coords = [(c, r) for r in range(1, 9) for c in "ABCDEFGH"]

def dist(a, b):
    # bishop distance
    x1, y1 = a
    x2, y2 = b
    if (x1 + y1) % 2 != (x2 + y2) % 2:
        return -1
    if a == b:
        return 0
    if abs(x1 - x2) == abs(y1 - y2):
        return 1
    return 2

def query(cell):
    print(f"? {cell[0]}{cell[1]}", flush=True)
    return int(input().strip())

def main():
    candidates = coords[:]

    # fixed query sequence designed to split diagonals
    probes = [(1, 1), (8, 8), (1, 8), (8, 1), (4, 4), (5, 5), (4, 5), (5, 4)]

    for p in probes:
        if len(candidates) == 1:
            break
        res = query(p)
        new_candidates = []
        for c in candidates:
            if dist(p, c) == res:
                new_candidates.append(c)
        candidates = new_candidates

        if len(candidates) == 1:
            break

    ans = candidates[0]
    print(f"! {ans[0]}{ans[1]}", flush=True)

if __name__ == "__main__":
    main()
```このソリューションは、考えられるすべての正方形のリストを維持し、各対話型応答の後にそれをフィルター処理します。 距離関数はビショップの移動ルールを正確にエンコードし、裁判官の回答の一貫したシミュレーションを可能にします。 各クエリは、観測された距離と互換性のある正方形のみを維持することによって、候補セットを絞り込みます。 

プローブ配列は、異なる対角線ファミリーと交差するように選択されます。 コーナーは長い対角線を分離しますが、D4 や E5 のような中心点は両対角線方向を横切るため、曖昧さはすぐに解消されます。 

クエリのたびに出力をフラッシュするように注意する必要があります。そうしないと、インタラクターが応答しなくなります。

 ## 特殊なケース

 A1 などのコーナー配置は、多くのクエリが対角線の配置に応じて 0 または 1 をすぐに返すため、最も単純なシナリオです。 距離制約によるフィルタリングには最初からの真の位置が含まれており、すべてのプローブがそれを保存または確認するため、アルゴリズムは依然としてそれを均一に扱います。 

H8 のような長い対角線上の正方形も同様に動作しますが、コーナー プローブに対する応答は対称性が異なります。 初期のクエリによって候補が不均等に削減された場合でも、すべての対角距離関係に同時に一致する正方形が他にないため、制約の交差部分は依然として H8 を一意に保存します。 

D4 のような中央の正方形は、複数の対角線上にあり、より多くの距離 1 の応答を生成するため、最も有益なケースです。 対角の等式を満たさないすべての候補が一貫して削除され、最後の正方形が残るまで有効な交差だけが残るため、フィルタリング ステップはこれを正しく処理します。
