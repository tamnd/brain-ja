 ## 問題の理解

 私たちに与えられた一行は、$n$石であり、各石は次のいずれかを使用してペイントする必要があります。$c$利用可能な色。 唯一の制限は、同じ色の連続についてです。同じ長さのブロックを持つことは許可されていません。$k$すべての石が同じ色を共有する場合はそれ以上。 言い換えれば、色が連続して現れる場合、その縞の長さは常に厳密に以下でなければなりません。$k$。 

タスクは、各テスト ケースに存在する有効なカラーリングの数を数え、指定された素数を法とした結果を出力することです。$p$。 テスト ケースの数は膨大になる可能性があり、各テスト ケースには非常に多くの処理が含まれる場合があります。$n$そして$c$したがって、色を明示的に列挙することを避ける方法が必要です。 

この制約により、ブルート フォースはすでに完全に排除されています。 中程度の場合でも$n$、シーケンスの総数は$c^n$、そしてそれは実行可能な計算を超えて大きくなります。 の存在$n$まで$10^6$テスト ケースごとに線形または線形に近いアプローチを強制します。 追加の制約$k \ge 2$これは、制限が局所的であり、連続した構造のみに依存することを示唆しており、これは通常、動的計画法または組み合わせ再発を示します。 

微妙なエッジケースが現れるのは、$k > n$。 その状況では、長さの連続がないため、制約は事実上無関係になります。$k$長さの範囲内に存在できる$n$順序。 答えは単純に次のようになります。$c^n$。 もう一つのエッジケースは、$k = 2$、隣接する 2 つの石が同じ色であることを禁止し、問題を古典的な「隣接する等しいものがない」という答え付きの計算問題に変えます。$c \cdot (c-1)^{n-1}$。 一般的なソリューションはすべて、これらの特殊なケースに正しく機能しなければなりません。 

## アプローチ

 素朴な試みは、シーケンスを左から右に構築し、すべての有効な割り当てを再帰的にカウントすることです。 それぞれのポジションで、私たちはすべてを試します$c$色、および禁止された長さの連続を作成する場合にのみ選択を拒否します。$k$。 これを強制するには、州は最後の色の現在のランレングスを記憶する必要があります。 これにより、位置と現在のストリークの長さのような DP 状態が得られ、同じ色を継続するか切り替えるかによって遷移が変わります。 

この定式化は正しいですが、直接実装するとすぐに大きくなりすぎます。 ランレングスは最大で$k-1$したがって、状態空間は次のようになります。$O(nk)$。 と$n$まで$10^6$、そのような DP を保存したり反復したりすることさえ不可能です。 

重要な簡素化は、正確な色の追跡をやめ、代わりにランの構造のみを追跡することです。 重要な点は、制約ではランが長さに達するかどうかだけが考慮されるということです。$k$、ランがどの色であるかについてではありません。 これは、すべての色が対称であることを意味し、必要な長さのランからシーケンスを構成できる方法が何通りあるかを数えるだけで済みます。$1$に$k-1$、各実行では、前の実行とは異なる色が選択されます。 

ランの観点から考えると、各シーケンスはブロックの連結です。 各ブロックには長さがあります$1$に$k-1$。 最初のブロックは任意の色にできるため、要素に影響します。$c$。 後続のすべてのブロックは、前のブロックとは異なる色を選択する必要があり、これが要因となります。$c-1$、その長さを独立して選択します。

 ## アルゴリズムのチュートリアル

 私たちは定義します$f[i]$最初の有効な色の数として$i$石。 

プレフィックス合計配列も維持します$pref[i] = f[0] + f[1] + \dots + f[i]$、モジュロ計算$p$、高速範囲合計を可能にします。 

再帰は、長さの色分けの最後のブロックを考慮することで生じます。$i$。 最後のブロックに長さがあると仮定します。$t$、 どこ$1 \le t < k$。 それから前回の$i-t$位置は有効なシーケンスを形成し、最後のブロックはプレフィックスの最後のブロックとは異なる色の選択に影響します。 

1.初期化$f[0] = 1$、空のシーケンスを表します。 
2. ポジションごとに$i$から$1$に$n$で終わるすべてのシーケンスを計算したいとします。$i$。 
3. もし$i < k$、まだ制限がないため、すべての拡張機能が有効です。 計算できる$f[i] = c \cdot (c-1)^{i-1}$直接または再発を通じて。 
4. 一般向け$i \ge k$、最後のブロックの長さで分割します$t$、からの範囲$1$に$k-1$。 それぞれについて$t$、プレフィックスが寄与します$f[i-t]$を乗算します$c-1$最後のブロックの色は前のブロックとは異なる必要があるためです。 
5. ウィンドウ全体のこの合計は、プレフィックス合計を使用して効率的に計算されます。$$f[i] = (c-1) \cdot (f[i-1] + f[i-2] + \dots + f[i-k+1])$$6. プレフィックスの合計を維持します。$f[i]$一定時間で計算できる。 

最終的な答えは、$f[n]$。 

これが機能する理由は、長さの有効なカラーリングがすべて$i$は、最後の実行が開始される位置によって一意に決定されます。 その開始点は最後の範囲内にある必要があります$k-1$そうしないと、実行が制約に違反します。 開始位置の各選択は、有効なプレフィックスと新しいランへの 1 つの分解に正確に対応し、そのような分解はすべて互いに素です。 これにより、解空間の完全な分割が得られ、これはまさにスライディング ウィンドウの合計がキャプチャするものとなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, c, k, p = map(int, input().split())

        if k > n:
            # no restriction applies
            res = pow(c, n, p)
            print(res)
            continue

        # f[i] = number of valid arrays of length i
        f = [0] * (n + 1)
        pref = [0] * (n + 1)

        f[0] = 1
        pref[0] = 1

        for i in range(1, n + 1):
            # window sum f[i-1] ... f[i-k+1]
            left = i - 1
            right = i - k

            total = pref[left]
            if right >= 0:
                total = (total - pref[right] + p) % p

            f[i] = total * (c - 1) % p
            pref[i] = (pref[i - 1] + f[i]) % p

        print(f[n])

if __name__ == "__main__":
    solve()
```この実装では、シーケンス カウントの DP 配列と、定数時間の範囲合計を可能にするプレフィックス合計配列が維持されます。 トランジションは、最後の実行の長さが最大でなければならないという考えを直接エンコードします。$k-1$したがって、有効な以前のカット位置のみを合計します。 の乗算$c-1$前回の実行の色とは異なる色の選択を反映します。 

実装の微妙な詳細は、ウィンドウ合計を計算するときのモジュラー減算の処理です。 プレフィックスの合計は減算できるため、追加する必要があります。$p$負の値を避けるためにモジュロを取る前に。 

特別な場合$k > n$再帰は無制限の色付けに退化するため、高速累乗を使用して個別に処理されます。

 ## 特殊なケース

 いつ$k > n$、DP ウィンドウ条件は決してアクティブになりません。 たとえば、$n=5, k=10$そうでない場合、ループは空の範囲を計算します。 アルゴリズムは明示的に次のように切り替わります。$c^n$したがって、未定義のプレフィックスの減算を回避し、すべてのカラーリングが有効であるという事実と一致します。 

いつ$k=2$、ウィンドウ サイズは 1 になるため、各状態は にのみ依存します。$f[i-1]$。 再発は正しく折りたたまれます$f[i] = (c-1) f[i-1]$、そして実装は特別な処理をしなくても自然に指数関数的な動作を生成します。 

いつ$c=1$、可能なシーケンスは一定の色のみです。 もし$k \le n$、これは制約に違反し、因数が次のとおりであるため、DP は正しくゼロを生成します。$c-1$ゼロになり、すべてが強制されます$f[i]$のために$i \ge 2$消えること。
