 ## 解決策
 ## 問題の理解

 フィールドはグリッドであり、一部のセルは利用可能な草のセルであり、残りはブロックされた岩です。 サリーは一定距離を垂直にジャンプできますが、`kv`、または水平方向に、`kh`ただし、ジャンプが許可されるのは、そのジャンプが横切るすべてのセルが草である場合のみです。 完全な動きは常に 2 つのこのようなジャンプで構成されます。 

タスクは、異なる草細胞の順序ペアを数えることです`(a, b)`どこから始まるか`a`、サリーは最終的に到達することができます`b`1 つ以上の完全な動作を実行した後。 その答えは、フィールドのオープン性と呼ばれます。 

入力には、グリッドの寸法、2 つのジャンプ長、およびグリッド自体が含まれます。 簡単なバージョンには落石がないため、初期開口度を計算するだけで済みます。 

グリッドには最大で次のものを含めることができます`n * m = 200000`細胞。 それでも`n`そして`m`個々のセルの数は大きくなる可能性がありますが、セルの総数は線形または線形に近いアルゴリズムには十分に小さいです。 すべての草セルのペアを試すソリューションには、最大で次の時間が必要になります。`O((nm)^2)`限界をはるかに超えた仕事。 各セルと可能なジャンプを一定の回数だけ処理する必要があります。 

難しいのは、サリーの動きが 1 回のジャンプではなく 2 回のジャンプで構成されていることです。 単一の有効なジャンプによって接続されたセルは、移動が完了した後は自動的に到達できなくなります。 グラフを単純に解釈すると、ジャンプ数の同等性を見逃してしまう可能性があります。 

単一の行を考えてみましょう。```
1 3 5
```と`kh = 2`そしてすべての細胞は草です。 1 回のジャンプで端から端まで移動できますが、完全に移動するには 2 回のジャンプが必要です。 1 つのジャンプの同じ接続コンポーネント内のすべてのセルを到達可能としてカウントする不用意な解決策には、奇数のジャンプを必要とするペアが含まれることになります。 ここでの正解はペアのゼロです`(1,3)`2 つのジャンプ シーケンスが存在しない場合。 

コンポーネントが 2 部構成である場合、別の特殊なケースが発生します。 2 つのパーティション間ですべての有効なジャンプの色が変わるグリッドの場合、反対側のセルには奇数のジャンプを使用しないと到達できません。 

例：```
Input
2 2 1 1
**
**
0

Output
4
```1 つのジャンプ グラフは正方形です。 反対側のコーナーには 2 回のジャンプが必要ですが、隣接するセルには 1 回のジャンプが必要です。 有効な順序ペアは、同じチェス盤の色のセル間の 4 つのペアのみです。 コンポーネント全体をカウントすると、誤って出力される`12`。 

最後のケースは、奇数サイクルを含むコンポーネントです。 奇数サイクルが存在すると、任意の 2 つの頂点間に偶数と奇数の両方の長さのパスを作成できるため、そのコンポーネント内のすべての異なるペアが有効になります。 

## アプローチ

 直接的なアプローチは、有効な単一ジャンプのグラフを構築することです。 各草のセルは頂点であり、サリーが 1 回のジャンプで 2 つのセル間を移動できる場合、エッジは 2 つのセルを接続します。 次に、すべての頂点からグラフのトラバーサルを実行し、偶数のエッジの後にどの頂点に到達できるかを数えることができます。 完全な動きはこのグラフのちょうど 2 つのエッジであるため、これは正しいです。 

ただし、すべてのセルから走査を行うと遅すぎます。 200,000 セルの場合、最悪の場合、約`200000 * 200000`操作。 

重要な点は、個別の到達可能性クエリが必要ないということです。 必要なのは、接続されたコンポーネントの構造と、各コンポーネント内のパスが両方のパリティを持つことができるかどうかだけです。 

1 ジャンプ グラフの連結成分には 2 つのケースがあります。 コンポーネントが 2 部構成の場合、すべてのエッジの色が変わるため、すべての偶数の長さのパスは同じカラー クラス内に留まります。 セルは、その同じ色の他のセルに正確に到達できます。 コンポーネントが 2 部構成でない場合は、パスのパリティを変更できる奇数サイクルが存在します。 すべての頂点は他のすべての頂点に到達できます。 

残りの作業は、連結成分を見つけ、二部性を確認し、2 つのカラー クラスをカウントすることです。 有効なジャンプをスキャンしている間、パリティ追跡を備えた素集合共用体が 3 つのタスクすべてを処理します。 

有効なジャンプ グラフ自体は、岩全体のプレフィックス合計を使用して線形時間で生成できます。 ジャンプは、開始点と目的地の間のセル内の岩の数が 0 の場合に有効です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |

 | ブルートフォース | O((nm)^2) | O(nm) | 遅すぎる |
 | 最適 | O(nm) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グリッドのすべての長方形内の岩石セルの数を格納するプレフィックス合計配列を構築します。 これにより、一定時間内にジャンプ パスに岩が含まれているかどうかを確認できます。 
2. パリティ素集合和集合構造を作成します。 すべての草セルは、最初は独自のコンポーネントです。 保存されたパリティは、ノードがコンポーネント ルートと同じ色を持つか反対の色を持つかを表します。 
3. すべての草のセルをスキャンします。 長さの下方向のジャンプに挑戦してください`kv`そして右方向への長さのジャンプ`kh`。 すべての有効なジャンプは元に戻すことができるため、これら 2 つの方向のみをチェックするだけで十分です。 宛先が存在し、パスが空いている場合は、パリティ DSU の 2 つのセル間にエッジを追加します。 
4. すべてのエッジを処理した後、すべての草セルを再度スキャンし、その DSU ルートとそのルートに対するパリティを見つけます。 すべてのコンポーネントについて、各パリティ クラスに属するセルの数を数えます。 
5. 各コンポーネントについて、その寄与を回答に追加します。 コンポーネントが 2 部構成でない場合は、順序付けられた異なるセルのペアがすべて機能し、次のようになります。`size * (size - 1)`。 二部構成の場合、等しいパリティを持つセルのみが相互に到達でき、次のようになります。`cnt0 * (cnt0 - 1) + cnt1 * (cnt1 - 1)`。 

なぜ効果があるのか:

 DSU は、単一ジャンプ グラフの接続コンポーネントを正確に保存します。 パリティ情報は、2 つのカラーリングの試行をシミュレートします。 すでに同じ色を持つ 2 つの頂点をエッジが接続した場合、そのコンポーネントには奇数のサイクルが含まれており、2 部構成ではありません。 2 部コンポーネントでは、ジャンプごとに色が反転するため、偶数のジャンプは同じ色の側に戻ります。 サリーの完全な動きには 2 つのジャンプが含まれているため、同じパリティ頂点のみに到達できます。 非 2 部コンポーネントでは、奇数サイクルによりパリティ制限がなくなり、頂点間のパス長が偶数と奇数の両方が許可されます。 この数式は、両方のセルが同じであるペアを除外しながら、すべての有効な順序付きペアを正確にカウントします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n
        self.par = [0] * n
        self.bad = [False] * n

    def find(self, x):
        if self.parent[x] != x:
            p = self.parent[x]
            self.parent[x] = self.find(p)
            self.par[x] ^= self.par[p]
        return self.parent[x]

    def union(self, a, b):
        ra = self.find(a)
        rb = self.find(b)
        xa = self.par[a]
        xb = self.par[b]

        if ra == rb:
            if xa == xb:
                self.bad[ra] = True
            return

        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
            xa, xb = xb, xa

        self.parent[rb] = ra
        self.par[rb] = xa ^ xb ^ 1
        self.size[ra] += self.size[rb]
        self.bad[ra] |= self.bad[rb]

def solve():
    n, m, kv, kh = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    pref = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(n):
        row = 0
        for j in range(m):
            row += 1 if grid[i][j] == '@' else 0
            pref[i + 1][j + 1] = pref[i][j + 1] + row

    def has_rock(r1, c1, r2, c2):
        return (
            pref[r2 + 1][c2 + 1]
            - pref[r1][c2 + 1]
            - pref[r2 + 1][c1]
            + pref[r1][c1]
        ) > 0

    total = n * m
    dsu = DSU(total)

    def idx(r, c):
        return r * m + c

    for i in range(n):
        for j in range(m):
            if grid[i][j] != '*':
                continue

            if i + kv < n and not has_rock(i + 1, j, i + kv, j):
                dsu.union(idx(i, j), idx(i + kv, j))

            if j + kh < m and not has_rock(i, j + 1, i, j + kh):
                dsu.union(idx(i, j), idx(i, j + kh))

    cnt = {}
    for i in range(n):
        for j in range(m):
            if grid[i][j] == '*':
                x = idx(i, j)
                r = dsu.find(x)
                c = dsu.par[x]
                if r not in cnt:
                    cnt[r] = [0, 0]
                cnt[r][c] += 1

    ans = 0
    for r, colors in cnt.items():
        a, b = colors
        if dsu.bad[r]:
            ans += (a + b) * (a + b - 1)
        else:
            ans += a * (a - 1) + b * (b - 1)

    print(ans)

if __name__ == "__main__":
    solve()
```プレフィックス合計構造は、すべてのジャンプ検証を定数時間の四角形クエリに変換します。 下方向へのジャンプについてクエリされた四角形は、サリーの 1 つ下のセルから始まり、草を残さなければならないセルと一致する目的地で終わります。 

DSU は、接続情報とカラーリング情報の両方を保存します。 2 つのコンポーネントがマージされる場合、新しいエッジが反対の色を接続するように、ルート間のパリティが選択されます。 エッジが現在の色と矛盾する場合、コンポーネントは非二部としてマークされます。 

最後の計数フェーズではグラフ検索は実行されません。 パリティ カウントには、到達可能な順序ペアの数を計算するために必要なすべての情報がすでに含まれています。 乗算には Python 整数が使用されるため、答えが 32 ビット値を超える可能性がある場合でも、オーバーフローの問題は発生しません。

 ## 特殊なケース

 1 つのジャンプ グラフでは接続されているように見えるコンポーネントでも、完全な動作には偶数のジャンプが必要となるため、到達可能性が制限される可能性があります。 完全な 2 by 2 草の例は、これを示しています。 DSU は 1 つのコンポーネントを作成しますが、カラーリングによりそれがサイズ 2 の 2 つのグループに分割されます。`2 * 1 + 2 * 1 = 4`考えられる 12 個のペアをすべて数えるのではなく、有効な順序付きペアを数えます。 

奇数サイクルのコンポーネントではパリティ制限が解除されます。 2×3のフルグラスグリッドで`kv = 1`そして`kh = 1`、単一のジャンプ グラフには奇数の長さのサイクルが含まれています。 DSU は色の矛盾を検出し、コンポーネントを非 2 部構成としてマークし、すべてのコンポーネントをカウントします。`6 * 5 = 30`すべてのセルが接続されている場合は順序ペア。 実装では、このルールが自動的に適用されます。 

単一の孤立した草セルのコンポーネント サイズは 1 です。 別の宛先セルがないため、数式ではゼロが生成され、自己到達可能性のケースは正しく除外されます。 DSU は、この状況に対して特別な処理を行う必要はありません。 

四角形チェックは、境界近くのジャンプも正しく処理します。 ジャンプは、宛先セルがグリッド内にある場合にのみ考慮され、プレフィックス合計クエリには交差するすべてのセルが 1 回だけ含まれ、岩の周囲で 1 つずつエラーが発生するのを防ぎます。
