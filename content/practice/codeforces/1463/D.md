 ## 問題の理解

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのペアを生成しようとします。$2n$数値を入力し、それぞれについてすべての選択肢を試してください。$x$最小値を取得するペア。 これは原理的には正しいですが、次の点が含まれます。$(2n)! / (2^n n!)$ペアリングと$2^n$最小値の選択により、たとえ小規模であっても計算上不可能になります$n$。 

重要な点は、すべての組み合わせを個別に考慮する必要はないということです。 シーケンス$b$は厳密に増加しており、最小/最大の選択を満たすために貪欲に数値をペアにすることができます。 すべての組み合わせを構築するのではなく、カウントの観点から問題を検討してください。 の最小の数字$b$あるペアの最小値には最大値を割り当て、他のペアの最大値には最大値を割り当てる必要があります。 この構造により、2 ポインター手法で次の値の数をカウントできるようになります。$x$制約を満たします。 

具体的には、問題をすべての値を見つけるものとして扱うことができます。$x$最小になるように$x$の数字$b$最小値および最大値として配置できます。$n-x$残りの数値と競合することなく、最大値として数値を入力します。$[1, 2n]$。 最初と最後からスキャンすることで、利用可能な要素の数を維持し、有効な範囲を決定します。$x$効率的に。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$そしてソートされたシーケンス$b$。 
3. 利用可能な番号を追跡するための 2 つのポインタを初期化します。1 つは小さい番号から始まります。$1$そしてもう一つは最高位から$2n$。 
4. 有効な最小値を計算します$x$で示される`x_min`。 の最初から始める$b$、それぞれについて$b_i$より小さい数値が十分にあるかどうかを確認してください。$b_i$最低限それとペアリングします。 最小値にできない数値に達するまでカウンターをインクリメントします。 これにより、必要な最小値の最小数が決まります。 
5. 有効な最大値を計算します$x`, denoted `x_max`. Start from the end of $b$, and for each $b_i$ from largest to smallest, check if there are enough numbers larger than $b_i$ を最大としてペアリングします。 最大値に達しないまでカウンターをデクリメントします。 これにより、可能な最小値の最大数が得られます。 
6. 有効枚数$x$価値観は`x_max - x_min + 1`もし`x_max >= x_min`、それ以外の場合はゼロ。 
7. テスト ケースのこのカウントを出力します。 

機能する理由: 問題を最小値と最大値を個別にチェックすることと、数値の合計数を考慮することに分割することで、すべての$x$計算された間隔で達成できます。 2 ポインター スキャンにより、各候補の番号が$b$セットの補完部分に有効な対応物があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        b = list(map(int, input().split()))
        b.sort()
        # compute x_min
        x_min = 0
        small_available = 0
        for bi in b:
            if bi > small_available:
                x_min += 1
                small_available += 1
        # compute x_max
        x_max = n
        large_available = 2 * n + 1
        for bi in reversed(b):
            if bi < large_available:
                x_max -= 1
                large_available -= 1
        print(x_max - x_min + 1)

if __name__ == "__main__":
    solve()
```最初のループオーバー`b`それより小さい数値と組み合わせることができる最小選択の最小数を決定します。 最後から 2 番目のループは、可能な最小選択の最大数を計算し、残りの数が最大値を形成できることを保証します。 オフバイワンエラーは初期化によって回避されます`small_available`そして`large_available`実際に使用された数値を注意深く追跡してください。
