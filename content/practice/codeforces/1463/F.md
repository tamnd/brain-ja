 ## アルゴリズムのチュートリアル

 1. 数字であることを確認します$i$数字でのみブロックできる$i - x$そして$i - y$。 これにより、全体ではなく、以前の値の小さなウィンドウのみを追跡できます。$n$。 
2. 長さの DP 配列を初期化します。$L = x + y$。 各エントリー$dp[i]$番号で終わる最大の正しいセットサイズを保存します$i$このウィンドウ内で。 
3. すべてを反復処理します$2^L$このウィンドウの可能なサブセット。 各サブセットについて、次の点で異なる 2 つの数値がないことを確認します。$x$または$y$。 有効なサブセット内の要素の最大数を記録します。 これにより、最適なローカル パターンが得られます。 
4. パターンが何回完全に当てはまるかを計算します。$n$:$k = n // L$。 最適なパターンのサイズに次の値を掛けます。$k$。 
5. 残った数字を処理する$r = n \% L$長さのより小さいインスタンスを解決することによって$r$同じDPで。 これを合計サイズに加えます。 
6. 合計サイズを正しいセットの最大サイズとして返します。 

なぜ機能するのか: 連続する任意のセット内での最適なセット$L = x + y$競合は距離のあるところでのみ発生するため、数値は以前のブロックと将来のブロックから独立しています。$x$そして$y$、両方とも未満$L$。 パターンを繰り返すことで、ブロック間で新たな競合が発生しないことが保証され、残りを個別に処理することで、次の値を超えないことが保証されます。$n$。 このタイリング引数は、解が最大であることを証明します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_correct_set(n, x, y):
    L = x + y
    best = 0
    # precompute all valid patterns in a block of size L
    for mask in range(1 << L):
        valid = True
        positions = [i for i in range(L) if mask & (1 << i)]
        for i in range(len(positions)):
            for j in range(i):
                if positions[i] - positions[j] == x or positions[i] - positions[j] == y:
                    valid = False
                    break
            if not valid:
                break
        if valid:
            best = max(best, len(positions))
    full_blocks = n // L
    remainder = n % L
    # handle remainder separately
    best_rem = 0
    for mask in range(1 << remainder):
        valid = True
        positions = [i for i in range(remainder) if mask & (1 << i)]
        for i in range(len(positions)):
            for j in range(i):
                if positions[i] - positions[j] == x or positions[i] - positions[j] == y:
                    valid = False
                    break
            if not valid:
                break
        if valid:
            best_rem = max(best_rem, len(positions))
    return full_blocks * best + best_rem

n, x, y = map(int, input().split())
print(max_correct_set(n, x, y))
```このソリューションでは、まず、次の長さのウィンドウ内で最適なローカル サブセットを見つけます。$x + y$ビットマスクを使用してすべての可能なサブセットを列挙することによって。 考慮する必要があるのは小さなサブセットのみです。$x, y \le 22$。 次に、このパターンを全範囲にわたってタイル表示します。$n$そして残りを明示的に処理します。 位置をまたがるネストされたループにより、距離の競合が発生しません。$x$または$y$。 フルブロックと残りのブロックを慎重に分割することで、off-by-one エラーが回避されます。
