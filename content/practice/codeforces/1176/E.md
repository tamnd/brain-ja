 ## 解決策
 ## 問題の理解

 各クエリに対して無向接続グラフが与えられ、選択しなかったすべての頂点が少なくとも 1 つの選択された近傍を持つように頂点のサブセットを選択する必要があります。 言い換えれば、選択されていない頂点はすべて、隣接する選択された頂点によって「覆われ」なければなりません。 追加の制限は、選択した頂点の数がすべての頂点の半分を超えてはいけないということです。 

したがって、タスクは基本的に、グラフを支配する頂点セットを構築することですが、保証されたサイズ境界は最大で Floor(n/2) です。 何も最小化する必要はなく、カバレッジ条件とサイズ制約の両方を満たす有効なセットを生成するだけで済みます。 

制約は大きく、クエリに対するすべての n と m の合計は最大 2⋅10^5 であり、最大 2⋅10^5 のクエリが存在する可能性があります。 これにより、クエリごとに線形または線形に近いソリューションが強制され、全体の複雑さは約 O(n + m) になります。 ペアごとのチェック、サブセットの列挙、または頂点ごとのグラフ走査の繰り返しを伴うものはどれも遅すぎます。 

パスのようなまばらなグラフでは、微妙なエッジ ケースが発生します。 構造を持たずに任意の頂点を貪欲に選択しようとすると、誤って多くの頂点を選択しすぎたり、カバレッジを保証できなかったりする可能性があります。 たとえば、パス 1-2-3-4-5 では、{2,4} を選択すると機能しますが、間違って始まる 2 番目の頂点ごとに常に選択するような単純な戦略では、トラバース順序によっては境界でオーバーシュートしたり、カバレッジを見逃したりする可能性があります。 

もう 1 つの特殊なケースは、クリークのような密集したグラフです。 完全なグラフでは、任意の 1 つの頂点が他のすべての頂点をカバーするため、1 つの頂点を選択するだけで十分です。 単純な交互戦略では、不必要に多くの頂点を選択する可能性がありますが、それでも有効です。 

主な困難は、支配を保証しながら常に n/2 以内に収まる構造を確保することです。 

## アプローチ

 強引なアイデアは、頂点のすべてのサブセットを試し、それらがグラフを支配するかどうかを確認し、最大でもサイズが n/2 のサブセットを追跡することです。 候補セットごとにカバレッジを検証するには、すべてのエッジまたは隣接リストをスキャンする必要があり、すでに O(n + m) のコストがかかります。 2^n 個のサブセットがあるため、これは完全に実行不可能です。 

カバレッジを確保しながら、本質的に回答サイズを制限する構造が必要です。 重要な観察は、BFS または DFS パリティ カラーリングを使用してグラフを 2 色にすると、すべてのエッジが同じパリティ ノードまたは異なるパリティ ノードに接続しますが、BFS ツリーの深さに基づいて頂点を 2 つのグループに分割できることです。 グラフは接続されているため、グラフが 2 部構成でない場合でも、BFS レベルにより自然な 2 部構成のような構造が得られます。 

次に、BFS レベルのパリティ (偶数の深さと奇数の深さ) によって頂点をグループ化することを検討します。 BFS ツリーの用語では、すべてのエッジは深さが最大 ​​1 だけ異なるノードを接続しますが、一般にグラフ エッジは任意のレベルを接続できます。 ただし、私たちが活用する重要な特性はより単純です。すべてのエッジにはエンドポイントがあり、少なくとも 1 つのエンドポイントは偶数または奇数のレベル セットに属します。 したがって、1 つのパリティ セットから選択されなかったすべての頂点は、(BFS ツリー エッジまたはグラフ エッジを介して) 他のパリティ セットの一部の頂点に隣接し、より小さいセットを選択したときにカバレッジが保証されます。 

これを確認するより確実な方法は、任意のノードでグラフをルートし、距離のパリティによって色を付けることです。 すべてのエッジは、同じパリティまたは反対パリティのいずれかを接続します。 エッジが同じパリティに接続している場合、直接的には役に立ちませんが、BFS ツリー内ですべての頂点が反対側のパリティに接続する親子関係を持っているため、カバレッジはグローバルに確保されます。 したがって、2 つのパリティ セットのうち小さい方を選択すると、選択されていないすべての頂点が、選択されたセット内に少なくとも 1 つの隣接頂点を持つことが保証されます。 

2 つのセットが頂点を分割するため、そのうちの 1 つのセットのサイズは最大でも n/2 となり、制約は直ちに満たされます。 

これにより、問題は 1 つの BFS とパリティ数に減ります。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n · (n + m)) | O(n) | 遅すぎる |
 | BFS パリティ パーティション | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 任意の頂点 (通常は 1) でグラフのルートを設定し、BFS 距離を計算します。 

1. ノード 1 から BFS を実行し、各ノードの距離パリティを記録します。 

ルートからの距離が偶数であるか奇数であるかに応じて、各ノードに 0 または 1 を割り当てます。 これにより、2 つの候補グループが作成されます。 
2. パリティに基づいてノードを 2 つのリストに収集します。 

1 つのリストにはすべての偶数距離のノードが含まれ、もう 1 つのリストにはすべての奇数距離のノードが含まれます。 
3. 2 つのリストのサイズを比較します。 

これらにはすべてのノードが含まれるため、少なくとも 1 つのリストのサイズは最大で Floor(n/2) になります。 そのリストを選択します。 
4. 選択したリストを回答として出力します。 

これで十分な理由は、BFS レイヤ化がルートからの到達可能性構造を保証し、すべてのノードにパス交互のパリティ ステップがあることを保証する方法にあります。これは、1 つのパリティ クラスを削除しても、少なくとも 1 つの選択された頂点に隣接するすべてのノードが残ることを意味します。 

### なぜ効果があるのか

 すべての頂点は、2 つのパリティ クラスのいずれかに正確に属します。 選択されたセットはこれら 2 つのクラスのうち小さい方であるため、選択されていない頂点はもう一方のクラスに属します。 BFS ツリーでは、ルートを除くすべてのノードに反対のパリティを持つ親があります。つまり、選択されていないすべてのノードには反対のパリティ クラスの隣接ノードが少なくとも 1 つあります。 クラス全体を 1 つ選択するため、選択されていないすべてのノードには、選択されたセット内に隣接ノードがあることが保証されます。 常に小さいパーティションを選択するため、サイズ境界は保持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        g[u].append(v)
        g[v].append(u)

    dist = [-1] * (n + 1)
    q = deque([1])
    dist[1] = 0

    while q:
        u = q.popleft()
        for v in g[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)

    even = []
    odd = []

    for i in range(1, n + 1):
        if dist[i] % 2 == 0:
            even.append(i)
        else:
            odd.append(i)

    if len(even) <= len(odd):
        ans = even
    else:
        ans = odd

    print(len(ans))
    print(*ans)
```BFS はノード 1 からの最短距離を計算します。接続によってすべてのノードが到達可能であることが保証されるため、これで十分です。 パリティ分割は 2 つのリストに保存されます。 最後に、サイズ制約を確保するために小さいリストを選択します。 

よくある間違いは、任意の色付けが機能すると仮定することです。 BFS は、グラフ全体で一貫したパリティ割り当てを保証します。 もう 1 つの微妙な点は、パリティ構築によって構造的にカバレッジが保証されるため、カバレッジを明示的に検証する必要がないことです。

## テストケース```python
import sys, io

def solve():
    import sys
    input = sys.stdin.readline
    from collections import deque

    t = int(input())
    out = []
    for _ in range(t):
        n, m = map(int, input().split())
        g = [[] for _ in range(n + 1)]
        for _ in range(m):
            u, v = map(int, input().split())
            g[u].append(v)
            g[v].append(u)

        dist = [-1] * (n + 1)
        q = deque([1])
        dist[1] = 0

        while q:
            u = q.popleft()
            for v in g[u]:
                if dist[v] == -1:
                    dist[v] = dist[u] + 1
                    q.append(v)

        even = []
        odd = []
        for i in range(1, n + 1):
            if dist[i] % 2 == 0:
                even.append(i)
            else:
                odd.append(i)

        ans = even if len(even) <= len(odd) else odd
        out.append(str(len(ans)))
        out.append(" ".join(map(str, ans)))

    return "\n".join(out)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    return solve()

 ## 特殊なケース

 単一頂点中心のスターでは、BFS 深度により、距離 0 に 1 つの中心が生成され、他のすべての中心が距離 1 に生成されます。アルゴリズムは、すべてのリーフを正しくカバーする、中心となる小さいパリティ クラスを選択します。 

長いパスでは、BFS はチェーンに沿って正確に距離を交互に変更するため、パリティ クラスは均等またはほぼ均等に分割されます。 小さいクラスを選択しても、近隣ノードを介してすべての内部ノードがカバーされます。 

完全なグラフでは、BFS はルートを除くすべてのノードに距離 1 を割り当てます。 偶数セットは単一のノードになり、すべての頂点がそれに隣接しているため、すでに他のすべてのノードを支配します。
