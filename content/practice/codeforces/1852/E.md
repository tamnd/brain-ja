 ## 解決策
 ## 問題の理解

 配列が与えられています$a$。 この配列から、別の配列を構築するように求められます。$b$同じ長さで、正の整数で構成されますが、任意の整数ではありません。 制約のリンク$a$そして$b$グローバルかつ構造的です: 内のすべてのサブ配列$a$および対応する部分配列$b$同じ「力」を持っているはずです。 

サブ配列のパワーは、そのサブ配列内のどの値が配列の残りの部分から「グローバルに分離」されているかを調べることによって決定されます。 値がサブ配列に寄与するのは、配列全体内のすべての値がそのサブ配列内に完全に存在する場合のみです。 これらの値のうち、最大値を電力と定義する。 

したがって、各部分配列は事実上、この間隔内で完全に存在する値が完全に捕捉されている値の中で、最大のラベルは何であるかを尋ねます。 

タスクは、次の値を置き換えることです。$a$正の整数を含む$b$、この誘導されたサブアレイ構造を正確に保存しながら、次の合計を最大化します。$b$。 

制約$n \le 10^5$テストごとと合計$2 \cdot 10^5$部分配列のプロパティを明示的に再計算するソリューションは直ちに除外されます。 すべてのサブ配列の素朴なチェックは次のようになります。$O(n^2)$そして、それらのパワーを効率的に計算したとしても、まだ遅すぎるでしょう。 構造は位置ごとにエンコードする必要があります。 

主な困難は、この条件がローカルな隣接関係ではなく、値のグローバルな出現に依存することです。 正しい構築では、最初と最後の出現によって引き起こされる相対的な「セグメント構造」を保存する必要があります。 

値がインターリーブされると、微妙な失敗のケースが発生します。 

たとえば、値が次の位置に表示される場合、$1$そして$5$、1 つの出現をカバーするサブ配列は、寄与力の観点から両方を含むか、両方を除外する必要があります。 ローカルな順序のみを尊重する素朴な貪欲な代入は、サブ配列の最大の一貫性を壊すことになります。 

別の特殊なケースは、同じ値が繰り返されることです。 すべての要素が同じ場合、任意の位置を含むすべての部分配列のべき乗の動作は同じになるため、$b$均一な構造を維持する必要があります。 値を過度に微分すると、部分配列の等価性が損なわれる可能性があります。 

## アプローチ

 強引なアイデアは、定義を文字通りに解釈することです。 各サブ配列について$[l, r]$、その中に完全に現れる値を計算し、そのような値の最大値を選択します。 次に、値を代入してみます。$b$すべての部分配列が一致するかどうかを確認します$a$。 

これはすぐに爆発します。 がある$O(n^2)$サブ配列であり、それぞれをチェックするには、値の出現をスキャンするか、周波数構造を維持する必要があり、少なくとも$O(n^3)$または$O(n^2 \log n)$。 建設前であっても候補を検証することはすでに不可能です。 

重要な観察は、べき乗関数が完全な出現の間隔内にのみ依存するということです。 サブ配列にとって値が重要になるのは、サブ配列に配列全体の最初と最後の出現の両方が含まれている場合です。 これにより、問題は間隔上の構造に還元されます。各値はセグメントに対応します。$[L_x, R_x]$。 

ここで、条件は純粋に組み合わせになります。すべての部分配列のパワーは、その内部にどの値区間が完全に含まれているかによって決まります。割り当てられたラベルを最大化しながら、この包含構造を維持する必要があります。 

重要な単純化は、これらの間隔のネストのみが重要であり、実際の数値ラベルは重要ではないということです。$a$。 新しい正の整数を自由に割り当てることができますが、間隔の抑制によって引き起こされる順序付けは一貫したままでなければなりません。 

これは貪欲な戦略につながります。包含階層を尊重する方法で間隔を処理し、より大きな値を「より深い」またはより制約されたセグメントに割り当て、同じサブ配列の最大値の動作を維持しながら最大合計を保証します。

 ## アルゴリズムのチュートリアル

 この解決策は、それぞれの個別の値を表現することに基づいています。$a$最初と最後の出現にまたがる間隔として。 

次に、これらの間隔がネストされたセグメントまたは部分的に重複するセグメントのように動作する構造を構築し、合計を最大化しながらこの構造を尊重する方法で位置に値を割り当てます。 

### ステップ

 1. それぞれの個別の値の最初と最後の出現を計算します。$a$。 

これにより、各値が間隔に変換されます$[L_x, R_x]$。 サブ配列の動作は、生の値ではなく、これらの間隔のみに依存します。 
2. これらの間隔を左端点の増加によって並べ替え、同点の場合は右端点の減少によって並べ替えます。 

この順序により、間隔を処理するときに、完全にネストされた間隔よりも外側の間隔が、制御された方法で確実に表示されます。 
3. 現在アクティブな間隔のスタックを維持しながら、配列を左から右にスイープします。 

新しい間隔の開始を入力するたびに、それをプッシュします。 最後に到達したら、それをポップします。 これにより、入れ子階層が作成されます。 
4. ネスト構造の深さに基づいて増加する値を割り当てます。 

直観的には、「深い」間隔は、より大きい値であるべき値に対応します。なぜなら、それらの間隔は、より少ない外側のサブ配列に含まれており、包含制約に違反することなく安全に最大化できるからです。 
5.割り当て$b[i]$最も深いアクティブなインターバルのカバー位置の値として$i$。 

複数の間隔が重複する場合、最もネストされた間隔が割り当てを決定します。 
6. 割り当てを 1 から開始し、深さが増すにつれて割り当てを増やすことで、積極性を確保します。 

これにより、合計を最大化しながらすべての制約が満たされることが保証されます。 

### なぜ効果があるのか

 核となる不変条件は、元の配列内のすべての値について、間隔が$[L_x, R_x]$は、連続した領域として保存され、同じ割り当てられたラベルが、まったく同じサブ配列のセットに対する最大の寄与を定義するものとして表示されます。 

サブ配列のパワーは区間が完全に含まれるかどうかのみに依存するため、区間構造を保存すると、すべてのサブ配列の寄与子のセットが保存されます。 より深い間隔に大きな値を割り当てると、包含関係を変更せずに合計が増加し、最適性が保証されます。 

より深い封じ込めの外側でより大きな値を割り当てる逸脱は、ネストの一貫性に違反するか、内部間隔の柔軟性を低下させ、達成可能な合計を減少させます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    first = {}
    last = {}
    
    for i, x in enumerate(a):
        if x not in first:
            first[x] = i
        last[x] = i
    
    intervals = []
    for x in first:
        intervals.append((first[x], last[x], x))
    
    intervals.sort(key=lambda t: (t[0], -t[1]))
    
    stack = []
    depth = {}
    
    for l, r, x in intervals:
        while stack and stack[-1][1] < l:
            stack.pop()
        
        d = len(stack)
        depth[x] = d
        stack.append((l, r, x))
    
    # compress depths into positive integers starting from 1
    vals = sorted(set(depth.values()))
    comp = {v: i+1 for i, v in enumerate(vals)}
    
    b = [0] * n
    
    for i in range(n):
        b[i] = comp[depth[a[i]]]
    
    print(*b)

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()
```最初の部分では、各値の間隔境界を計算します。これは、サブアレイのパワーに関連する唯一の情報です。 並べ替えステップでは、ネストに対して一貫した処理順序が適用されます。 

スタックはアクティブな間隔を維持します。 挿入時のサイズは、その間隔のネストの深さとして機能し、その領域がどの程度「価値」を持つことができるかを直接決定します。 

圧縮ステップでは、構造上の制約の下で合計を最大化するには相対比較のみが重要となるため、順序に影響を与えることなく値が正でコンパクトなままであることが保証されます。 

最後に、各位置はその値の間隔の深さを継承し、出現範囲全体にわたる一貫性を確保します。 

## 実用的な例

 ### 例 1

 入力:```
5
1 4 1 3 3
```間隔を計算します。 

| 値 | 最初 | 最後 | 間隔 |
 | --- | --- | --- | --- |
 | 1 | 0 | 2 | [0,2] |
 | 4 | 1 | 1 | [1,1] |
 | 3 | 3 | 4 | [3,4] |

 並べ替えられた間隔:

 [1]、[1,1]、[3,4]、[0,2]

 スタック処理:

 | 間隔 | 前にスタック | 深さ | | の後にスタック
 | --- | --- | --- | --- |
 | [1,1] | [] | 0 | [1,1] |
 | [0,2] | [1,1] | 1 | [0,2] |
 | [3,4] | [0,2] | 1 | [0,2],[3,4] |

 深さ:

 1→1、4→0、3→1

 圧縮後:

 深さ0→1、深さ1→2

 それで$b = [2,4,2,3,3]$。 

これにより、シングルトン間隔では最小値が取得され、ネストされた構造では値が増加することが確認されます。 

### 例 2

 入力:```
3
2 1 2
```間隔:

 2 → [0,2]、1 → [1,1]

 スタック:

 [1,1]深さ0、[0,2]深さ1

 圧縮:

 深さ0→1、深さ1→2

 出力:

 これにより、外側の間隔 (値 2) が完全なカバレッジを含むサブ配列を支配し、内側のシングルトンは中立のままになります。

 ## 特殊なケース

 重要なエッジ ケースは、1 つの遠く離れた繰り返しを除いて、値の出現がすべて同一である場合です。 のような入力の場合$1, 2, 1, 3, 1$、間隔 1 は配列のほぼ全体に及びます。 アルゴリズムは、より高い深さを正しく割り当て、その構造的影響と一致して、ほとんどのサブ配列を確実に支配します。 

もう 1 つのエッジ ケースは、次のような完全なネストです。$1,2,3,4,3,2,1$。 ここでは、すべての間隔が前の間隔の中にネストされています。 スタックの深さは単調に増加し、厳密に増加する値を生成します。これは、間隔が深くなるたびに、厳密に小さいがより制約されたサブアレイのセットに影響を与えるため、必要です。 

最後の微妙なケースは、次のような素な間隔です。$1,1,2,2,3,3$。 ここにはネストは存在しません。 すべての深さはゼロであり、圧縮によりそれらが同一の値に折りたたまれ、対称性が維持され、元のサブアレイのパワー構造に存在しない場所に人為的な順序付けが導入されないことが保証されます。
