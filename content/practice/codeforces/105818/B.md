 ## 解決策
 ## 問題の理解

 各家はグリッドの位置にあります$(r,c)$。 

に設置された塔$(R,C)$満足のいくすべての家をカバーします$$C \le c$$そして$$r+c \le R+C.$$その塔のコストは単純に$R$、その行。 

あらゆる人にとって$k$から$1$に$n$、すべての住宅をカバーするのに必要な最小の総コストを、最大でも次の値を使用して計算する必要があります。$k$塔。 

最初の課題は、タワーのカバレージの形状を理解することです。 この条件は次の 2 つの量のみに依存します。$$x=c,\qquad y=r+c.$$これらの座標では、パラメータを備えたタワーが$$X=C,\qquad Y=R+C$$家を正確に覆う$$x \ge X,\qquad y \le Y.$$したがって、タワーは、軸に沿った支配領域に対応します。$(x,y)$飛行機。 

入力サイズが到達しました$2\cdot10^5$したがって、ハウス間のペアごとの比較や、すべての間隔にわたる動的計画法を含む解決策は、直ちに不可能になります。 周りに何かが必要です$O(n\log n)$。 

微妙な点は、他の家がカバーされると、一部の家が自動的にカバーされることです。 

考慮する：```
(1,1)
(2,2)
```変換された座標は次のとおりです。```
(1,2)
(2,4)
```2番目の家をカバーすることは、1番目の家をカバーすることを意味するものではありません。 でも、もし持っていたら```
(1,2)
(1,1)
```になる```
(2,3)
(1,2)
```それからカバーします$(1,2)$自動的にカバーします$(2,3)$。 このような支配的なポイントを削除せずにすべての家を維持する解決策は、問題の重要な構造を見逃してしまいます。 

追加のタワーを追加しても解決しない場合には、別の特殊なケースが発生します。 

例：```
3
3 5
1 3
2 3
```答えは```
5 5 5
```すべての有用なカット位置にはすでに負でない寄与があるため、より多くのタワーを使用してもコストは削減されません。 常に正確に使用するソリューション$k$タワーは誤ってより小さい値を生成します。 

## アプローチ

 最も直接的なアイデアから始めましょう。 

家を列ごとに並べ替えるとします$c$。 すべてのパーティションをグループに分けて試し、各グループをカバーする最も安価なタワーを計算し、動的プログラミング ソリューションを一定の間隔で実行できます。 

集合住宅の場合、最も安価なカバータワーは満足できるものでなければなりません$$C \le \min c,
\qquad
R+C \ge \max(r+c).$$より大きな値を選択するとコストが増加するだけなので、グループの最適なコストは次のようになります。$$\max(r+c)-\min(c).$$この観察により、間隔コストの計算が容易になります。 

問題は、パーティション DP がオーバーしていることです。$n\le 2\cdot10^5$絶望的だ。 平$O(n^2)$間隔処理が制限をはるかに超えています。 

重要な観察は、支配から来ています。 

させて$$x_i=c_i,\qquad y_i=r_i+c_i.$$並べ替え$x$。 

ポイントが後で表示され、$$y_{\text{later}}\le y_{\text{earlier}},$$そうすれば、前のポイントをカバーすると、後のポイントも自動的にカバーされます。 後の点は答えに影響を与えないため、破棄できます。 

すべての支配的な点を削除した後、残りの点は次の条件を満たします。$$x_1<x_2<\cdots<x_m,$$

$$y_1<y_2<\cdots<y_m.$$現在、生き残っているすべてのポイントは、厳密に増加する階段の上にあります。 

連続したブロックに対して$[l,r]$、そのコストは$$y_r-x_l,$$なぜなら$y_r$は最大です$y$そして$x_l$最低です$x$。 

残りのすべてのポイントを 1 つのタワーでカバーするとします。 費用は$$y_m-x_1.$$ポジション間をカットすると$i$そして$i+1$、合計コストは次のように変化します$$(y_i-x_{i+1}).$$それが重要な単純化です。 

すべてのカットが独立して貢献します。 

複数のカット位置を選択した場合、総コストは次のようになります。$$(y_m-x_1)
+
\sum (y_i-x_{i+1}).$$したがって、問題は次のようになります。 

最大でも選択してください$k-1$～から値を切り取る$$d_i=y_i-x_{i+1}$$合計を最小化します。 

最良の選択は、単純に最小のカット値です。 

一度すべて$d_i$既知である場合は、それらを並べ替え、プレフィックスの合計を作成し、すべての応答を返します。$k$これらのプレフィックスの合計から。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース インターバル DP |$O(n^2)$それより悪い |$O(n^2)$| 遅すぎる |
 | 支配力削減 + ソート削減 |$O(n\log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての家をポイントに変える$$(x,y)=(c,r+c).$$1. すべてのポイントを次の基準で並べ替えます$x$上昇。 
2. 支配的な点を削除します。 

最大サイズを維持しながら、左から右にスキャンします。$y$これまで見られた。 次の場合にのみポイントを保持してください$y$以前のすべてよりも厳密に大きいです$y$。 

このステップの後、両方の座標は厳密に増加します。 
3. 残りの点を$(x_1,y_1),\dots,(x_m,y_m)$。 

1 つのタワーですべてをカバーする場合のコストは、$$base=y_m-x_1.$$1. すべての隣接するペアについて、次の計算を行います。$$d_i=y_i-x_{i+1}.$$それぞれ$d_i$そこにカットを配置することによって発生する追加コストを表します。 

1. すべて並べ替える$d_i$。 
2. プレフィックス合計を構築する$$pref[0]=0,
\qquad
pref[i]=d_1+\cdots+d_i.$$1. しましょう$$best[i]=\min(best[i-1],pref[i]).$$これは、最大でも使用して達成可能な最小の合計を保存します。$i$カット。 

1. あらゆる人にとって$k$から$1$に$n$:

 使用可能なカット数は上限を超えません$m-1$、それでは$$t=\min(k-1,m-1).$$答えは$$base+best[t].$$### なぜ効果があるのか

 支配されたポイントを削除した後、残りのすべてのポイントが重要です。 有効な解決策はどれも、この増加シーケンスを連続したブロックに分割することを引き起こします。 

ブロックのコスト$[l,r]$まさに$y_r-x_l$。 すべてのブロックを合計すると、すべての内部境界が独立して寄与します。$y_i-x_{i+1}$。 異なるカット間に相互作用は残りません。 

各カットが独立して寄与するため、次の制限のある最適なソリューションが得られます。$k-1$カットは、最小のカット値を選択することによって取得されます。 カット値が正の場合、問題により使用できるカット値が以下になるため、単純にそのカット値を採用しません。$k$塔。 

これは、アルゴリズムによって生成された値と正確に一致します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

pts = []
for _ in range(n):
    r, c = map(int, input().split())
    pts.append((c, r + c))

pts.sort()

x = []
y = []

mx = -1
for cx, cy in pts:
    if cy > mx:
        x.append(cx)
        y.append(cy)
        mx = cy

m = len(x)

base = y[-1] - x[0]

cuts = []
for i in range(m - 1):
    cuts.append(y[i] - x[i + 1])

cuts.sort()

pref = [0]
for v in cuts:
    pref.append(pref[-1] + v)

best = [0] * len(pref)
best[0] = 0
for i in range(1, len(pref)):
    best[i] = min(best[i - 1], pref[i])

ans = []
for k in range(1, n + 1):
    t = min(k - 1, m - 1)
    ans.append(str(base + best[t]))

print(" ".join(ans))
```最初のセクションでは、各家を変換された座標に変換します。$(c,r+c)$。 

支配性除去スキャンは、最も重要な実装の詳細です。 ポイントは次の場合にのみ保持されます。$y$値は以前のすべてを超えます$y$。 支配的なポイントがカバーされるたびに、破棄されたポイントがカバーされることが保証されます。 

圧縮後、階段プロパティは自動的に保持されます。 カットのコストは隣接する生き残ったポイントにのみ依存するため、すべての値を計算します。$y_i-x_{i+1}$、それらを並べ替えて、プレフィックスの合計を作成します。 

配列`best`問題では **最大で** が求められるため、これが必要です$k$塔。 次のカット値が正の場合、それを取ると答えが増加します。`best[i]`最大でも長さのすべてのプレフィックスの最小のプレフィックス合計を格納します`i`これは、より少ないタワーを使用する自由を正確にモデル化しています。 

すべての算術演算は 64 ビット符号付き整数に快適に収まりますが、Python 整数はそれを自動的に処理します。

import io

    n = int(input())

        pts.append((c, r + c))

        if cy > mx:
            x.append(cx)
            y.append(cy)

    base = y[-1] - x[0]

        cuts.append(y[i] - x[i + 1])

    cuts.sort()

        pref.append(pref[-1] + v)

    best = [0] * len(pref)
    for i in range(1, len(pref)):

    for k in range(1, n + 1):
        t = min(k - 1, m - 1)
        ans.append(str(base + best[t]))

    return " ".join(ans)
