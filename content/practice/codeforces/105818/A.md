 ## 問題の理解

 うちには池があります`N`スイレンの葉の列。 各行には、左右の 2 つの可能な着陸位置が含まれています。 いつでも、列のちょうど片側が水上にあり、使用できます。 2 匹のカエルが最初の列の前からスタートし、両方とも池を横切る必要があります。 

カエルは常に前に進みます。 現在利用可能なスイレンのパッ​​ドに着地することで列に入り、その列を離れると、使用されたパッドが沈み、同じ列の他のパッドが上昇します。 一度に 1 匹のカエルだけがパッドを占有できるため、カエルは順番に列を通過する必要があります。 カエルが右のパッドに着地するたびに、合計スコアが 1 つ増加します。 

入力により、行数と各行の初期状態が得られます。 出力では、両方のカエルが取得できる最大合計スコアが求められます。 

主な制約は、`N`は十分に小さいので多くの解を通過させることができますが、本当の目標は構造に注目することです。 たとえ`N`がはるかに大きかった場合、入力自体には次のものが含まれるため、線形時間に近い解を探す必要があります。`N`情報の断片。 2 匹のカエルの考えられるすべての順序をシミュレートすると、不必要な状態が作成され、指数関数的に増加します。 

難しいのは、カエルが異なる順序を選択できることです。 不用意な解決策では、現在の行に基づいてどのカエルを最初に実行するかを貪欲に選択しようとする可能性がありますが、1 つの行に対して選択された順序は、2 番目のカエルのその行の状態に影響を与えます。 重要な観察は、最終的なスコアへの寄与に関して、すべての行が独立しているということです。 

たとえば、1 行の場合:```
1
L
```最初のカエルは左側のパッドに着地しますが、ポイントは得られません。 パッドが反転し、2 番目のカエルが右側のパッドに着地して 1 ポイントを獲得します。 答えは次のとおりです。```
1
```最初に右向きのパッドのみをカウントするソリューションでは、次の出力が出力されます。`0`、それは間違いです。 

もう 1 つのエッジ ケースは、すべての行が利用可能な適切なパッドから始まる場合です。```
3
RRR
```最初のカエルがすべての列でポイントを獲得します。 各ジャンプの後、2 番目のカエルは左パッドを取得しますが、ポイントはありません。 答えはまだ次のとおりです。```
3
```両方のカエルが何らかの方法で連続して最初の位置を取ることを回避する必要があると仮定する解決策は、スコアを改善できると誤って考える可能性があります。 

## アプローチ

 自然な強引なアプローチは、2 匹のカエルが動きを交互にできるすべての可能な方法を試すことです。 どの列でもどちらかのカエルが最初に到達する可能性があるため、多くの順序が考えられます。 注文ごとに、行をシミュレートし、ポイントをカウントできます。 これは正しいです。重要なのはどのカエルが各列に最初に到着するかだけであるためです。 

問題は、これが必要以上に探索してしまうことです。 各行で誰が最初に行くかについては 2 つの選択肢があるため、可能な順序の数は最大です。`2^N`。 のために`N`その周り`100`、これはもうあります`10^30`対処できない可能性。 

重要な観察は、各行が常に正確に 1 つのポイントを与えるということです。 現在、行の左側のパッドが使用可能であると仮定します。 最初に入ったカエルは左パッドを取得し、スコアは 0 です。 離れると、左側のパッドが水中に入り、右側のパッドが使用可能になるため、2 番目のカエルが 1 ポイントを獲得します。 右のパッドが使用可能になり始めると、最初のカエルは 1 ポイントを獲得し、2 番目のカエルは 0 ポイントを獲得します。 どちらの場合も、その行の合計寄与度はちょうど 1 です。 

両方のカエルはすべての行を横切らなければならないため、初期構成や選択した順序に関係なく、すべての行が 1 ポイントを与えます。 問題全体は、行を数えるということに帰着します。

 ## アルゴリズムのチュートリアル

 1. 行数を読み取ります。 各行は正確に 1 つのポイントに寄与するため、答えに必要な情報は行が何行存在するかだけです。 
2. 各行の左または右の構成は無視します。 ある行を訪問する最初のカエルと同じ行を訪問する 2 番目のカエルは常に 2 つのパッドをそれらの間で分割するため、その行からの合計スコアは固定されます。 
3. 出力`N`、行数。 

なぜ効果があるのか:

 各列ごとに、カエルごとに 1 回ずつ、正確に 2 回の着陸が発生します。 1 回目の着地は現在のフローティング パッドを使用し、2 回目の着地は最初のカエルが去った後にフローティングになったパッドを使用します。 2 匹のカエルは一緒に列内の両方のパッドを 1 回訪問し、それらのパッドの 1 つが正しいパッドになります。 したがって、行ごとに正確に 1 つのポイントが追加されます。 この固定拠出金を全体に加算すると、`N`rows は可能な最大スコアを与えます。

アルゴリズムは文字列にインデックスを作成しないため、境界の問題はありません。 この実装では文字列の保存も回避され、メモリ使用量が一定に保たれます。 入力サイズは Python の機能に比べて小さいため、高速 I/O で十分です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)

    n = int(sys.stdin.readline())
    sys.stdin.readline()
    ans = str(n)

    sys.stdin = old
    return ans

# provided sample style
assert run("1\nR\n") == "1", "single row"

# custom cases
assert run("5\nLLLLL\n") == "5", "all left pads"
assert run("4\nRRRR\n") == "4", "all right pads"
assert run("3\nLRL\n") == "3", "mixed rows"
assert run("100\n" + "L" * 100 + "\n") == "100", "large input size"
```| テスト入力 | 期待される出力 | 検証内容 |

 ## 特殊なケース

 で始まる単一行の場合`L`、最初のカエルは左のパッドに到達しますが、何も得られません。 離れた後、左側のパッドが沈み、右側のパッドが使用可能になるため、2 番目のフロッグが 1 点を獲得します。 アルゴリズムの出力`1`、実際の最大値と一致します。 

すべてで始まる行の場合`R`、最初のカエルが各行のポイントを受け取ります。 2 番目のカエルは、右側のパッドがすでに沈んでいるため、これらの列からポイントを受け取りません。 アルゴリズムは、合計スコアと一致する行数を出力します。 

次のような交互の行の場合`LRL`、カエルは誰が最初に到着したかに応じて、異なる列でポイントを受け取ることがあります。 各行が常に正確に 1 ポイントを与えるため、合計は変わりません。そのため、答えは依然として行数になります。
