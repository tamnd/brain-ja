 ## アルゴリズムのチュートリアル

 中間変数を使用してプロセスを書き換えます$k_i = (A_i - 1)/x$。 それから：$$A_i = xk_i + 1, \quad A_{i+1} = (x-1)k_i$$これから、次の逆の関係を導き出すことができます。$$k_{i+1} = \frac{(x-1)k_i - 1}{x}$$これは次の場合にのみ有効です$(x-1)k_i \equiv 1 \pmod x$。 

今構築します$k_m$最初に逆方向に伝播します。 

1. 最後の子の選択$k_m$最後の操作が有効になるようにします。 これには必要です$k_m \ge 1$そしてそれ$(x-1)k_{m-1} - 1$で割り切れます$x$逆にすると、強制的に満たすのが最も簡単です$k_m \equiv x-1 \pmod x$。 そのような最小値は次のとおりです。$k_m = x-1$。 
2. コンピューティング$A_m = xk_m + 1 = x(x-1) + 1$。 これにより、最後の子が有効な番号を受け取り、必要な分割を実行できるようになります。 
3.子供から後ろに下がる$i+1$子供に$i$以下を強制することによって：$$k_{i+1} = x - 2 + (x-1)t$$どこ$t$次のステップのモジュール制約が有効なままになるように選択されます。 私たちは常に最小のものを選択します$t$不変条件を維持するもの$k_i \equiv x-1 \pmod x$。 
4. この逆方向展開を繰り返す$m-1$回。 各ステップで有効な値が生成されます。$k_i$したがって、有効な$A_i$、割り算を壊すことなく。 
5.到達後$k_1$、出力$n = A_1 = xk_1 + 1$。 

### なぜ効果があるのか

 構築全体は、単一の不変条件を維持することに基づいています。$k_i$そのように選ばれる$(x-1)k_i \equiv 1 \pmod x$これにより、次の逆のステップで整数値が生成されることが保証されます。 すべての段階でこの合同を強制することにより、すべての除算が確実に行われます。$x$順方向のプロセスは正確であり、すべての子は有効な整数のリンゴを受け取ります。 各逆方向ステップは同じ剰余クラスを満たす値を明示的に構築するため、どのステップも必要な割り算条件に違反することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    m, x = map(int, input().split())

    if x == 2:
        # special linear chain
        # k_m must be odd, minimal is 1
        A = 3  # works for all m
        # propagate backward: A_i = 2*A_{i+1} + 1
        for _ in range(m - 1):
            A = 2 * A + 1
        print(A)
        return

    # general case x >= 3
    # work with k values
    k = x - 1  # minimal valid choice for last step

    # build backwards
    for _ in range(m - 1):
        # enforce next valid k in reverse construction
        # k_new = x - 2 + (x - 1) * t, choose minimal t = x - 1
        k = (x - 2) + (x - 1) * (x - 1) + (x - 1) * k

    n = x * k + 1
    print(n)

if __name__ == "__main__":
    solve()
