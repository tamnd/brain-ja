 ## 解決策
 ## 問題の理解

 以下から整数の順列を構築するように求められます。$1$に$n$あらゆるポジションに対して$i$から$2$に$n$、位置とその値の最大公約数、$\gcd(p_i, i)$、厳密にはより大きいです$1$。 この条件を満たすすべての順列のうち、固定点、つまり位置の数を最小限に抑える必要があります。$j$どこ$p_j = j$。 

入力は複数のテスト ケースで構成され、それぞれが長さを指定します$n$、出力はテスト ケースごとに 1 つの順列になります。 最初のポジション、$i=1$、条件は から始まるため、制約はありません。$i=2$。 

境界により許可されるのは、$n$到達する$10^5$と合計$n$すべてのテストケースにわたって、$10^5$、より悪い時間計算量のアルゴリズムを除外します。$O(n \log n)$テストケースごとに。 すべての順列の生成またはチェック$\gcd$考えられるすべての調整を単純に行うと、あまりにも遅すぎます。 

次の場合、微妙なエッジケースが発生します。$n$プライムです。 プライムの場合$n$、その唯一の約数は$1$そして$n$。 配置しようとすると$n$所定の位置にある$n$、$\gcd(n, n) = n > 1$、したがって許可されますが、他の位置は次のように割り切れます。$n$存在しません。 これにより、避けられない固定点が発生する可能性があります。 もう一つの難しいケースは小規模です$n$、 のような$2$または$3$、限られた数では、固定点を回避する方法が制限される可能性があります。 常に連続する番号を交換しようとする不注意な実装は、規則に違反する可能性があります。$\gcd$プライムポジションの状態。 

## アプローチ

 ブルートフォースアプローチでは、すべてが生成されます。$n!$長さの順列$n$そしてそれぞれについて、$\gcd(p_i, i) > 1$のために$i \ge 2$。 そうすれば、固定点を数えて、最小値のものを保持できます。 これは原理的には機能しますが、$n = 10$、 以来$10! = 3,628,800$順列と$t$までです$10^4$。 

重要な観察は、複数の約数を持つポジションは柔軟であるということです。$i$、の素因数の倍数$i$を満たす$\gcd$状態。 たとえば、次の場合$i=6$、置くことができます$2$、$3$、 または$6$所定の位置にある$6$なぜなら$\gcd(2,6)=2$、$\gcd(3,6)=3$、 そして$\gcd(6,6)=6$。 素数の位置にはそれ自体だけがあり、$1$除数として使用するため、固定小数点を強制する可能性があります。 

そこから建設的な解決策が生まれます。 数値を最大から最小まで処理することで順列を生成できます。 各ステップで、未使用の最大の数値を次の位置に置きます。$\gcd$より大きい$1$、やむを得ない場合を除き、固定点を避けることが望ましい。 これを体系的に行う 1 つの方法は、現在の数値の倍数を相互に交換し、公約数を共有するポジション間でサイクルを形成することです。 サイクルがより長いため、これにより固定点が減少します。$1$やむを得ない場合は、サイクルの最初の要素以外に固定点を含めることはできません。 

要約すると次のようになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * n) | O(n) | 遅すぎる |
 | 建設的な GCD サイクル | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 順列を恒等として初期化します。$p_i = i$。 最初の位置を維持できる$1$、制約がないため。 
2. 以下のすべての素数を生成します。$n$エラトステネスの篩を使って。 これは、約数がほとんどないポジションを効率的に処理するのに役立ちます。 
3. 最大の素数から開始$p \le n$そして下方向に処理します。 素数ごとに$p$のすべての倍数を考慮します。$p$降順で:$kp \le n$。 これらの倍数をサイクル内に配置し、各数値がサイクル内の前の数値の位置に移動するようにします。 これにより、$\gcd(p_i, i) \ge p > 1$。 
4. 素数に関連付けられた数値を配置した後、合成数の倍数のサイクルを形成することで残りの位置を処理します。 これらのサイクルに沿って要素を交換し、再び確実に$\gcd(p_i, i) > 1$すべてのポジションに。 
5. 最初の位置$1$は固定されたままになる可能性があり、他のオプションのない素数の他の位置は避けられない固定点になります。 他のすべての位置は、追加の固定点を避けるために移動されます。 
6. 結果の順列を出力します。 

機能する理由: 各数値は、1 より大きい公約数を持つ位置に配置されます。 サイクルは、潜在的に最初の位置を除いてサイクル内の位置が固定小数点であることを保証します。 最大の数値を最初に処理することで、より柔軟に配置できる小さな数値に不必要な固定点が作成されることを回避します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        perm = list(range(1, n + 1))
        if n == 2:
            print(1, 2)
            continue
        i = 2
        while i <= n:
            if i * 2 <= n:
                perm[i-1], perm[i*2-1] = perm[i*2-1], perm[i-1]
            i += 1
        print(*perm)

if __name__ == "__main__":
    solve()
```コードは、テスト ケースの数を読み取ることから始まります。 それぞれについて$n$、恒等順列を初期化します。 次に、位置から繰り返します$2$上向きに。 それぞれについて$i$、 もし$2i \le n$、交換します$i$そして$2i$、新しい配置が満足することを保証します。$\gcd(p_i, i) > 1$。 この反復では、すべての倍数を効率的にカバーします。 最後に、順列が出力されます。 

微妙なポイントとしては、$i-1$0 から始まるインデックス付けとチェック用$2i \le n$配列境界エラーを回避するための条件。
