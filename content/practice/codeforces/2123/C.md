 ## 解決策
 ## 問題の理解

 個別の整数の配列と一連の操作が与えられます。プレフィックスをその最小値に置き換えるか、サフィックスをその最大値に置き換えることができます。 目的は、配列内の各要素について、これらの一連の操作を使用して、配列をその要素のみを含む単一要素の配列に縮小できるかどうかを判断することです。 出力はバイナリ文字列です。`1`可能であることを示しており、`0`さもないと。 

入力は、配列が個別の整数を持ち、テスト ケースごとに最大 200,000 要素まで大きくできることを保証し、複数のテスト ケースの合計は最大 200,000 要素になります。 可能なシーケンスの数は配列サイズに応じて指数関数的に増加するため、これにより、すべての操作シーケンスの総当りシミュレーションが排除されます。 したがって、私たちのアルゴリズムは、テスト ケースごとに線形時間で答えを計算する必要があります。 

この問題の難しい部分は、どの要素に到達できるかを理解することにあります。 要素が配列内のどこかにあれば、その要素に到達できると思われがちですが、操作には制約があります。プレフィックスの置換は常に左側の最小の要素に向かって移動し、サフィックスの置換は右側の最大の要素に向かって移動します。 たとえば、配列では`[3, 1, 4, 2]`、要素`3`どの操作もプルされるため、単独に縮小することはできません。`1`前へ、または`4`後ろ向きで、決して孤立しない`3`。 

## アプローチ

 素朴なアプローチは、各要素の接頭辞と接尾辞の操作の考えられるすべてのシーケンスをシミュレートし、配列がその要素に折りたたまれるかどうかを確認することです。 これは操作が決定論的であるため機能しますが、シーケンスの数は指数関数的に増加します (`O(2^n)`）、これは不可能です`n = 2*10^5`。 

重要な観察は、配列の一部のプレフィックスで最小である要素、または一部のサフィックスで最大である要素のみが最終位置まで存続できる可能性があるということです。 具体的には、実行最小値を追跡しながら配列を左から右にスキャンし、実行最大値を追跡しながら右から左にスキャンすると、どの要素が最終的な単一要素配列として表示されるかをすぐに判断できます。 最初の要素が存続するには常に配列全体の最小値に還元可能でなければならず、最後の要素は最大値に還元可能でなければなりません。 最小値から最大値へ厳密に増加するシーケンス上にない要素は、操作によって小さい要素が左にプッシュされるか、大きい要素が右にプッシュされるため、分離できません。 

この観察により、問題はアレイの両端からの単一パスに縮小され、線形時間の解決策が得られます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、配列を読み取ります。`a`そしてその長さを決定します`n`。 長さのバイナリ文字列を初期化します`n`ゼロで埋められています。 
2. 2 つの配列を維持します。`prefix_min`そして`suffix_max`。`prefix_min[i]`最小限のものを格納します`a[0..i]`、 そして`suffix_max[i]`最大値を格納します`a[i..n-1]`。 
3. 埋める`prefix_min`配列を左から右にスキャンします。 各インデックスで`i`、 セット`prefix_min[i]`として`min(prefix_min[i-1], a[i])`。 これにより、前面に伝播する可能性のある最小の要素が追跡されます。 
4. 埋める`suffix_max`配列を右から左にスキャンします。 各インデックスで`i`、 セット`suffix_max[i]`として`max(suffix_max[i+1], a[i])`。 これは、背面に伝播する可能性のある最大の要素を追跡します。 
5. 各インデックスを反復処理します。`i`配列の。 要素`a[i]`次の場合にのみ分離できます`prefix_min[i]`または`suffix_max[i]`。 バイナリ文字列内の対応する位置を次のように設定します。`1`この条件が成立すれば。 
6. 結果のバイナリ文字列を出力します。 

機能する理由: 長さ 1 の最終配列は、小さい要素を左に、または大きい要素を右に継続的にプッシュするシーケンスから取得されなければなりません。 プレフィックスの最小値とサフィックスの最大値を維持することにより、各位置でそのようなシーケンスで生き残ることができる唯一の要素を特定します。 これにより、最終的な単一要素配列となる要素のセットが正確にキャプチャされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        prefix_min = [0] * n
        suffix_max = [0] * n
        
        prefix_min[0] = a[0]
        for i in range(1, n):
            prefix_min[i] = min(prefix_min[i-1], a[i])
        
        suffix_max[-1] = a[-1]
        for i in range(n-2, -1, -1):
            suffix_max[i] = max(suffix_max[i+1], a[i])
        
        result = ['0'] * n
        for i in range(n):
            if a[i] == prefix_min[i] or a[i] == suffix_max[i]:
                result[i] = '1'
        print(''.join(result))

solve()
```The first section reads input and sets up storage for prefix minimums and suffix maximums. 2 つの線形スキャンによってこれらの配列が計算されます。 最後のループでは、プレフィックスの最小値またはサフィックスの最大値に基づいて、現在の要素が最終配列まで存続できるかどうかを確認することにより、バイナリ文字列を構築します。 Off-by-one errors are avoided by careful initialization of the first and last elements of`prefix_min`そして`suffix_max`。 このソリューションは時間と空間の両方で線形であり、最大の制約を効率的に処理します。
