 ## 解決策

 ## 問題の理解

 正の整数の隠れたトリプルのペアごとの最大値を表すと考えられる 3 つの数値が与えられます。 具体的には未知の値が存在する$a$、$b$、 そして$c$、提供された 3 つの数値は各ペアの最大値に対応します。1 つは$\max(a,b)$、もう一つは$\max(a,c)$、そして最後は$\max(b,c)$。 タスクは、そのようなトリプルが存在できるかどうかを判断し、存在できる場合は 1 つの有効なソリューションを構築することです。 

重要な問題は、どの入力値がどのペアに対応するかが分からないことです。 代入の任意の並べ替えが許可されており、有効な構造を 1 つ出力するか、不可能性を報告するだけで済みます。 

制約により、最大で次のことが許可されます。$2 \cdot 10^4$テスト ケース、最大値$10^9$。 これにより、総当たりの代入やテスト ケースごとの候補トリプルの列挙を試みるアプローチは即座に除外されます。 考えられるすべての割り当てをチェックしても、$x, y, z$ペアごとの最大値までのサイズは些細なものですが、可能性のあるものを検索しようとすると、$a, b, c$値の範囲が大きすぎるため、体系的に調査することは不可能です。 

値のうち 2 つが 3 番目の値より小さいが等しくない場合、微妙なエッジ ケースが発生します。 例えば、$x = 10$、$y = 30$、$z = 20$一見一貫性があるように見えますが、割り当てることは不可能です$a, b, c$1 つのペアごとの最大値は 10 で、もう 1 つは 30 になります。これは、最大値が比較の基礎となる三角形の共有エンドポイントに対応する場合、ペアごとの最大値の少なくとも 2 つに現れる必要があるためです。 この種の矛盾を検出する必要があります。 

## アプローチ

 総当り的な考え方は推測しようとするでしょう$a, b, c$そして、それらのペアごとの最大値が指定された値と一致するかどうかを確認します。 可能な代入を反復することを想像することができます。$a, b, c$最大入力値までの範囲ですべての制約をチェックします。 検証は 3 つの最大値を計算して比較するという単純なものであるため、これは概念的に機能します。 ただし、検索空間は値の範囲内で立方体であり、制約の下ではまったく不可能です。 

重要な観察は、問題の構造により、指定された 3 つの数値間に非常に厳密な関係が強制されるということです。 それぞれの$x, y, z$はペアの最大値であるため、ペア間の全体的な最大値は$x, y, z$ペアごとの最大値の少なくとも 2 つに現れる値に対応する必要があります。 なぜなら、その中で最大のものは、$a, b, c$は、その要素に関係する両方のペアごとの最大値に含まれている必要があります。 

させて$M = \max(x, y, z)$。 For a solution to exist, at least two of the numbers must equal$M$。 この条件が満たされない場合、最大値はペアごとの最大値の中で 1 回だけ表示されることになります。これは、3 つの要素にわたるペアごとの最大値の構造に矛盾します。 

条件が合えば施工は簡単になります。 仮定する$x = y = M$。 それから設定できます$a = M$、$b = z$、 そして$c = z$または、一致する値に応じて並べ替えます。 より明確な構造は、繰り返される最大値を 2 つのペアごとの最大値に割り当て、3 番目の変数を残りの値と一致するのに十分な大きさに設定することです。 これにより、最大の要素を含む最大値が再現されるため、一貫性が保証されます。$M$、残りのペアは 3 番目の値を生成します。

 ## アルゴリズムのチュートリアル

 各テスト ケースを 3 つの値の単純な整合性チェックに集約します。 

1. コンピューティング$M = \max(x, y, z)$。 これは、すべてのペアごとの最大値の中で最大の要素の唯一の候補を表します。 
2. 何個あるか数えます$x, y, z$に等しい$M$。 このカウントが 2 未満の場合は、「NO」を出力します。 その理由は、単一のグローバル最大値を 2 つの異なるペアごとの最大値に分散させることができないためです。 
3. 条件が満たされる場合、有効なトリプルを構築します。 繰り返される最大値を次の 2 つの値として割り当てます。$(a, b, c)$、3 番目に指定された数値を残りの変数として配置します。 一貫した構築は次のとおりです。$a = M$、$b = M$、 そして$c = \min(x, y, z)$。 次に、最大値がラベルではなく値のみに依存するという事実に基づいて、暗黙的に順序を調整します。 
4. 「YES」と構築されたトリプルを出力します。 

### なぜ効果があるのか

 有効な構成では、次の中で最大の要素が$a, b, c$ペアごとの最大値のうちちょうど 2 つに出現する必要があります。 これは、最大値が、それが参加するどのペアよりも優先されるためです。$x, y, z$、最大値を少なくとも 2 回繰り返す必要があります。 逆に、これを 2 回繰り返す場合、これら 2 つの最大値を最大の要素を含むペアに割り当てることができ、残りの値は 2 つの小さな要素によって形成されるペアに対応します。 これにより、3 つの方程式がすべて同時に満たされることが保証されます。 

## Python ソリューション```python

for _ in range(t):
    x, y, z = map(int, input().split())
    
    m = max(x, y, z)
    cnt = (x == m) + (y == m) + (z == m)
    
    if cnt < 2:
        print("NO")
        continue
    
    # construct
    a = b = m
    c = min(x, y, z)

どのような順序でも建設が機能します。$a, b, c$出力では許可されます。 これにより、入力とペアの ID の間の正確なマッピングの必要がなくなります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        x, y, z = map(int, input().split())
        m = max(x, y, z)
        cnt = (x == m) + (y == m) + (z == m)
        if cnt < 2:
            out.append("NO")
        else:
            out.append("YES")
            out.append(f"{m} {m} {min(x,y,z)}")
    return "\n".join(out) + "\n"

 ## 特殊なケース

 3 つの値がすべて等しい場合、次のようになります。$100, 100, 100$の場合、アルゴリズムは最大値の 2 つの出現を正確に識別し、すべての値が同一である自明なトリプルを構築します。 すべてのペアが同じ結果を生成するため、最大条件が成立します。 

最大値が 1 回だけ出現する場合$50, 49, 49$の場合、アルゴリズムはそのケースを拒否します。 単一の最大値を 2 つの異なるペアごとの最大値に割り当てようとすると、その値が指定された最大値間で重複しない限り、同時に 2 つの異なるペアの最大値として機能できないため、失敗します。 

2 つの値が最大値に等しく、3 番目の値が非常に小さい場合、次のようになります。$1, 1000000000, 1000000000$、繰り返される最大値がペアごとの構造の両方の主要な要素として機能し、小さい値が残りのペアで共有される最小要素になるため、この構造は依然として機能します。
