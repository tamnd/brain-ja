 ## 解決策
 ## 問題の理解

 シャッフルされた整数のリストが与えられます。各整数は 2 つの未知の正の整数のうちの 1 つの約数を表しており、これを次のように呼びます。`x`そして`y`。 両方を割る数値の場合`x`そして`y`、リストに 2 回表示されます。 私たちの仕事は、任意のペアを再構築することです`(x, y)`それによってこのリストが作成された可能性があります。 

入力サイズ`n`は 128 まであり、それぞれの数値は最大 10,000 です。 これは十分に小さいため、パフォーマンスを心配することなく、すべての数値を直接操作し、並べ替え、最大公約数を計算できます。 

微妙な点は、約数が特定の方法で繰り返されることです。リスト内の最大の数値は次のいずれかでなければなりません。`x`または`y`。 単純なアプローチでは、出力の 1 つとして最大の数値を選択し、その約数をリストから削除しようとする可能性がありますが、数値が複数回出現する場合は注意が必要です。 たとえば、リスト`[1, 2, 2, 4]`に対応する`x = 4`そして`y = 2`。 数を考慮せずにすべての約数を誤って削除した場合、次のようなものを選択する可能性があります。`x = 4`そして`y = 4`、これは無効です。 

2 つの数値が多くの約数を共有する場合、別の特殊なケースが発生します。 例えば、`[1, 2, 2, 4, 4]`に対応する`x = 4`そして`y = 4`。 アルゴリズムは、重複を誤って途中で破棄することなく、繰り返される約数を処理する必要があります。 

## アプローチ

 ブルートフォース手法では、リストからすべての数値のペアを生成し、それらの結合された約数が指定されたリストと一致するかどうかを確認します。 各候補ペアの約数の生成は O(sqrt(max number)) であるため、n=128 で最大 10^4 の数値の場合、これは潜在的に約 128² * 100 ≈ 160 万回の演算となり、これは機能する可能性がありますが、不要です。 ブルート フォースでは、重複を慎重に記録する必要もあります。 

重要な点は、リスト内の最大の数値は次のいずれかでなければならないということです。`x`または`y`。 この数値を次のように修正すると、`x`、他の番号`y`約数を除いた後に残ったすべての数値の最大公約数を取ることで推定できます。`x`。 これが機能するのは、リストが有効なリストに対応することが保証されているためです。`(x, y)`。 

したがって、最適なアプローチは貪欲で建設的なものになります。 リストを降順に並べ替え、最大の番号を次のように選択します。`x`。 次に、リストを反復処理し、各数値について、それが次の約数であるかどうかを確認します。`x`。 もしそうであれば、それを削除してカウントをデクリメントします。なぜなら、その約数は次のユーザーによって「使用」されているはずだからです。`x`。 最後に、残りの最大数 (または残りの数の GCD) は次のようになります。`y`。 

この方法は、最大 128 個の数値に対して反復処理を行い、割り算チェックと GCD 計算を実行するだけであるため、効率的に機能します。 並べ替えにより、公約数の多重度を考慮して、最大の数値が最初に処理されるようになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²√M) | O(n) | n が小さい場合は動作しますが、上限の場合は遅くなります。 
| 最適 | O(n²) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. リスト内の各数値の出現を数えます。 これにより、構築時にどの約数が「使用」されたかを追跡できるようになります。`x`そして`y`。 
2. リストを降順に並べ替えます。 最大の数値は未知の整数のいずれかである必要があるため、それを次のように選択します。`x`。 
3. 数値のマルチセットまたはカウンターを初期化します。 降順の各数値について、割り切れるかどうかを確認します`x`。 存在する場合、そのカウントをデクリメントし、次の商のカウントもデクリメントします。`x`存在する場合は、この数値で除算されます。 これは、次の要因によるすべての約数を削除することをシミュレートします。`x`。 
4. すべての約数を削除した後、`x`、マルチセット内の最大の残りの数は次のとおりです。`y`。 これが機能するのは、両方を割る任意の数があるためです。`x`そして`y`2 回表示され、処理時に 1 回デクリメントされます。`x`。 
5. 出力`x`そして`y`。 順序は関係ありません。 任意の有効なペアで十分です。 

機能する理由: 最大値から最小値まで数値を処理し、進むにつれて約数の数を減らすことにより、共有約数の多重度が確実に尊重されます。 最大の数値は元の数値の 1 つである必要があるため、最初にそれを選択すると、少なくとも 1 つの正しい数値が保証されます。 残りのすべての番号は、構造上 2 番目の番号と互換性があります。 

## Python ソリューション```python
import sys
import collections
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

counter = collections.Counter(a)
a.sort(reverse=True)

x = a[0]  # largest number is one of the integers
counter[x] -= 1

# Remove divisors contributed by x
for num in a:
    if counter[num] > 0 and x % num == 0:
        counter[num] -= 1

# Remaining numbers with count > 0 are divisors of y
y = max(num for num, cnt in counter.items() if cnt > 0)

print(x, y)
```このコードでは、`Counter`多重度を追跡し、リストを降順に並べ替え、次の要因による約数を削除します。`x`、残りの最大の数値を次のように選択します。`y`。 数値が使用可能な場合にのみカウントをデクリメントするように注意が払われ、繰り返される約数が正しく処理されます。

## テストケース```python
import sys, io
import collections

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    counter = collections.Counter(a)
    a.sort(reverse=True)
    x = a[0]
    counter[x] -= 1
    for num in a:
        if counter[num] > 0 and x % num == 0:
            counter[num] -= 1
    y = max(num for num, cnt in counter.items() if cnt > 0)
    return f"{x} {y}"

# Provided sample
assert run("10\n10 2 8 1 2 4 1 20 4 5\n") == "20 8", "sample 1"

# Custom cases
assert run("4\n1 1 2 2\n") == "2 2", "all equal"
assert run("2\n1 2\n") == "2 1", "minimum input"
assert run("6\n1 2 3 1 3 6\n") == "6 3", "common divisors"
assert run("8\n1 2 4 2 1 4 8 8\n") == "8 4", "duplicates with multiple copies"
```| テスト入力 | 期待される出力 | 検証内容 |

| 2 1 2 | 2 1 | 最小サイズの入力 |

## 特殊なケース

 両方の数値が同じ場合、たとえば、`[1, 2, 2, 4, 4]`の場合、アルゴリズムは最大の数値 4 を次のように選択します。`x`、各約数のコピーを 1 つ削除し、残った最大の数は次のようになります。
