 ## 問題の理解

 長方形の掲示板と向きが固定された長方形のポスター 2 枚があります。 アレックスはいつも自分のポスターを最初に置きます。 アレックスにはボブのポスターに応じて 2 つの異なる目標があるため、問題は単に両方のポスターが適合するかどうかではありません。 

最初の計画では、アレックスは、ボブがポスターを重ならずに配置できる位置を残す方法でポスターを配置したいと考えています。 2 番目の計画では、アレックスはボブのあらゆる位置がポスターに重なるようにポスターを配置し、ボブがポスターを配置できないようにしたいと考えています。 

入力によりボードの高さと幅が与えられ、その後に Alex のポスターと Bob のポスターの寸法が続きます。 出力には、プランごとに 1 つずつ、合計 2 つの回答が含まれます。 

寸法は最大 150 で小さく見えますが、ジオメトリは連続しているため、考えられるすべての位置を直接シミュレーションする必要はありません。 重要な部分は、軸が揃った 2 つの長方形の構造特性を見つけることです。 すべての配置ペアを試すソリューションでは、最悪の場合、およそ 20,000 × 20,000 のチェックが実行されますが、これは不必要です。 一定時間の幾何学的観測が必要です。 

いくつかのケースでは、誤って処理されやすいものがあります。 アレックスのポスター自体が適合しない場合、どちらの計画も機能しません。 例えば：```
20 30
21 10
20 30
```出力は次のとおりです。```
No
No
```ボブのポスターが適合しているにもかかわらず、アレックスはプロセスを開始できません。 

もう 1 つの罠は、2 つのポスターが個別に適合するということは、それらが共存できることを意味すると仮定していることです。 例えば：```
50 100
30 20
30 20
```最初の答えは`Yes`2 つのポスターを縦または横に並べて配置できるためです。 2番目の答えは、`No`なぜなら、ボードのポスターの周囲に十分なスペースが残っている場合、アレックスはボブを完全にブロックできないからです。 

接触するエッジも重要です。 長方形は境界線を共有できるため、隙間が完全にゼロであっても障害にはなりません。 

## アプローチ

 ブルートフォース手法では、アレックスのポスターの可能な位置をすべて列挙し、次にボブのポスターの可能な位置をすべてチェックします。 各ポスターのポジションの最大数は約 20,000 であるため、約 4 億件の比較が作成されます。 このアプローチは問題を直接モデル化しているため正しいですが、四角形の構造は無視されています。 

プラン A の場合、重要な観察は、軸に沿って重なり合わない 2 つの長方形の間に常に分離の水平線または垂直線があることです。 分離が水平の場合、2 つのポスターは高さを個別に消費し、幅は互いに適合する必要があります。 分離が垂直の場合は、その逆が起こります。 これにより、問題は 2 つの簡単なチェックに減ります。 

プラン B では、アレックスはポスターの周囲の最大の空き領域を最小限に抑えたいと考えています。 ポスターを端に向かって移動しても反対側の利用可能なスペースが増えるだけであるため、最適な位置はボードの中央です。 アレックスが中心になると、ボブはアレックスの上/下、またはアレックスの左/右のいずれかにのみ適合します。 残りのストリップが十分な大きさであるかどうかを確認するだけで済みます。 

ブルート フォースは、可能な配置をすべて探索するため機能しますが、同じ幾何学的な推論を何千回も繰り返すため失敗します。 線の分離と最適な中央配置に関する観察により、すべてが定数時間演算に還元されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((HW)^2) | お(1) | 遅すぎる |
 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. アレックスのポスターが掲示板内に収まるかどうかを確認します。 高さまたは幅のいずれかが対応する基板寸法を超えている場合、両方の答えは次のようになります。`No`、アレックスはポスターを配置できないためです。 
2. プラン A では、ポスターを水平方向に分離できるかどうかをテストします。 これには、両方のポスターが垂直方向に収まり、横に並べたときに幅が収まる必要があります。`ha <= H`、`hb <= H`、 そして`wa + wb <= W`。 

垂直方向の分離の場合もテストします。`wa <= W`、`wb <= W`、 そして`ha + hb <= H`。 

どちらかのケースがうまくいけば、ボブに居場所が与えられるでしょう。 
3. プラン B では、アレックスがポスターをボードの中央に置いたと想像してください。 残りの高さは`H - ha`、残りの幅は`W - wa`。 上部または下部の可能な最大のギャップは残りの高さの半分、左右の最大のギャップは残りの幅の半分です。 
4. ボブがこれらの残りのストリップの 1 つに収まるかどうかを確認します。 ボブは次のいずれかの場合に成功できます。`hb <= (H - ha) / 2`そして`wb <= W`または：`wb <= (W - wa) / 2`そして`hb <= H`。 

どちらも不可能な場合、アレックスはボブをブロックすることに成功します。 

これが機能する理由は、Alex の長方形を避ける長方形は完全にその片側にある必要があるためです。 アレックスを水平方向と垂直方向に同時に通過することはできません。 アレックスをセンタリングすると、4 つのサイドのギャップすべてが同時に最小化されるため、ボブがそこに収まらない場合は、他の配置でギャップを小さくすることはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    H, W = map(int, input().split())
    ha, wa = map(int, input().split())
    hb, wb = map(int, input().split())

    if ha > H or wa > W:
        print("No")
        print("No")
        return

    plan_a = False

    if ha <= H and hb <= H and wa + wb <= W:
        plan_a = True

    if wa <= W and wb <= W and ha + hb <= H:
        plan_a = True

    plan_b = True

    if hb <= (H - ha) / 2 and wb <= W:
        plan_b = False

    if wb <= (W - wa) / 2 and hb <= H:
        plan_b = False

    print("Yes" if plan_a else "No")
    print("Yes" if plan_b else "No")

if __name__ == "__main__":
    solve()
```最初の部分では、どちらの計画もアレックスが自分のポスターを設置する必要があるため、不可能なケースは即座に拒否されます。 プラン A の計算は、分割線の引数に直接続きます。 2 つの方向は、重なり合わない 2 つの長方形のあらゆる可能な配置をカバーします。 

プラン B では、浮動小数点除算を意図的に使用します。 整数除算を使用すると、次のような値が誤って丸められます。`(H - ha) / 2`下向きに。 比較は整数のポスター サイズに対してのみ行われるため、これらの小さな値については通常の Python 浮動小数点精度で十分です。

## テストケース```python
import sys
import io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    data = sys.stdin.readline
    H, W = map(int, data().split())
    ha, wa = map(int, data().split())
    hb, wb = map(int, data().split())

    if ha > H or wa > W:
        ans = "No\nNo"
    else:
        a = (ha <= H and hb <= H and wa + wb <= W) or \
            (wa <= W and wb <= W and ha + hb <= H)

        b = not ((hb <= (H - ha) / 2 and wb <= W) or
                 (wb <= (W - wa) / 2 and hb <= H))

        ans = ("Yes" if a else "No") + "\n" + ("Yes" if b else "No")

    sys.stdin = old
    return ans

assert run("""20 30
15 10
10 20
""") == "Yes\nYes"

assert run("""20 30
21 10
20 30
""") == "No\nNo"

assert run("""50 100
30 20
30 20
""") == "Yes\nNo"

assert run("""10 10
10 10
10 10
""") == "Yes\nNo"

assert run("""100 100
10 10
90 90
""") == "No\nYes"

 ## 特殊なケース

 アレックスのポスターがボードと完全に一致すると、残りのスペースはゼロになります。 のために：```
10 10
10 10
10 10
```別の取り決めがある場合にのみ 2 人のポスターが接触できるため、プラン A の条件は成功しますが、ここではボブの余地がないため、2 番目の答えは次のようになります。`No`。 残りのギャップは両方ともゼロであるため、アルゴリズムはこれを処理します。 

ボブのポスターが残りのストリップの 1 つに正確に収まった場合、アレックスはプラン B に失敗します。たとえば、残りの垂直方向のギャップが正確に十分に大きい場合、比較では次のようになります。`<=`, なぜなら、アレックスのポスターに触れることが許可されているからです。 

ボードに十分なスペースがあるが、ポスターを必要な方向に並べて配置できない場合でも、プラン A を戻さなければなりません。`No`。 分割線のチェックは可能な両方の方向をカバーするため、無効な対角配置が誤って受け入れられることはありません。
