 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times n$完全にゼロで始まる正方行列。 上端に沿って、$n$大砲、各列の上に 1 つずつ、左端に沿って$n$大砲、各列の左側に 1 つずつ。 各大砲は、別の 1 またはマトリックスの端に当たるまで、右方向 (列大砲) または下方向 (列大砲) に「1」を直線で発射します。 1 が停止すると、そのセルに永久に留まります。 

課題は、0 と 1 の特定の最終構成がこれらの大砲からの一連の射撃によって生成されたかどうかを判断することです。 入力は一連のテスト ケースであり、それぞれのテスト ケースは次のサイズで構成されます。$n$そして$n \times n$構成が可能であれば出力は「YES」、それ以外の場合は「NO」になります。 

制約$1 \le n \le 50$すべてのテスト ケースにわたるセルの合計$\le 10^5$と提案する$O(n^2)$マトリックスごとのアプローチは許容されます。 自明ではないケースとは、1 が他の 1 がその経路を妨げない場合、エッジを越えて移動し続ける位置にある場合です。 たとえば、右下隅に 1 があるのは常に問題ありませんが、位置が 1 であるのは問題ありません。$(1,1)$2x2 マトリックスで最初の行または列に 1 がないことは不可能です。なぜなら、そこでショットを早期に止めることはできないからです。 この「近隣者によるブロック」ルールを考慮しない単純な実装では、そのような構成が誤って受け入れられてしまいます。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのショットシーケンスをシミュレートし、それが最終的なマトリックスと一致するかどうかを確認しようとします。 各大砲は複数回発射することができ、$2n$大砲。 すべてのシーケンスを試すことは本質的に組み合わせ的なものであり、たとえ$n=10$。 

重要な洞察は、逆算して作業することです。 マトリックスの 1 は、下端か右端にあるか、そのすぐ右か下に 1 がある必要があります。 1 がこの特性を満たさない場合、一連の大砲の射撃によって衝突ルールに違反せずに 1 を配置することはできません。 この観察により、各セルを独立してチェックできるようになります。$O(n^2)$時間: 最後の行または列にないそれぞれの 1 について、下または右のセルも 1 であることを確認します。これは、1 が行列の境界に到達するか、別の 1 に到達するかのどちらかに停止するという重要な制約を捉えています。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | k ショットの O((2n)^k) | O(n^2) | 遅すぎる |
 | 最適 | O(n^2) | O(1) おまけ | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースを反復処理し、サイズを読み取ります。$n$そしてマトリックス。 
2. 各セルについて$(i, j)$マトリックスに 1 が含まれているかどうかを確認します。 
3. セルに 1 が含まれており、それが最後の行または最後の列に**ない**場合は、そのショットをブロックする可能性のある 2 つのセルを確認します。$(i+1, j)$（下）と$(i, j+1)$（右）。 
4. 下のセルと右のセルが両方とも 0 の場合、設定は不可能です。 すぐにこのテスト ケースに「いいえ」のマークを付けて、次のテスト ケースに進みます。 
5. すべての 1 がチェックに合格した場合、設定は可能であるため、テスト ケースを「YES」としてマークします。 
6. すべてのテスト ケースの結果を出力します。 

機能する理由: 構造上、境界線以外の位置にある 1 がそこで停止できるようにするには、真下またはすぐ右にブロッカーがなければなりません。 この不変条件により、すべての 1 が大砲の射撃から発生し、適切に停止したことが保証されます。 いずれかの 1 がこの特性に違反する場合、一連のショットでそれを生成することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
results = []

for _ in range(t):
    n = int(input())
    grid = [input().strip() for _ in range(n)]
    possible = True
    for i in range(n):
        for j in range(n):
            if grid[i][j] == '1':
                if i < n - 1 and j < n - 1:
                    if grid[i+1][j] != '1' and grid[i][j+1] != '1':
                        possible = False
                        break
        if not possible:
            break
    results.append("YES" if possible else "NO")

print("\n".join(results))
```このソリューションは各セルに対して反復されます。 ネストされたループは、最後の行または最後の列にないセルのみをチェックします。 早めに休憩を取ることで、違反が見つかった場合の不必要なチェックを回避できます。 グリッドは文字列のリストとして保存され、インデックス付けと比較が簡単になります。`'1'`。

 ## 特殊なケース

 単一セル行列の場合、任意の 1 は最後の行と列の両方にあるため、常に有効です。 

1 が (0,0) と (1,1) にあるが、(0,1) と (1,0) が 0 である 2x2 行列の場合、アルゴリズムは、(0,0) の 1 にはそれを阻止するブロッカーがないことを識別し、NO を生成します。 

完全に 1 で満たされた行列の場合、すべての 1 が右または下に隣接するか、境界上にあるため、YES が生成されます。 

このアルゴリズムは、追加の条件ロジックなしでこれらすべてのシナリオを自然に処理し、正確さを確認します。
