 すべての有効な解決策は約数の選択に対応します$i$の$n$と$i \le k$。 このアルゴリズムは、次のすべての約数を列挙します。$n$, したがって、実行可能な選択を見逃すことはありません。 候補ごとに、必要なパッケージの正確な数が計算されます。 目的は最小限にすることなので、$n / i$、最大化する$i$制約の下で$i \mid n$そして$i \le k$、最良の候補は列挙された約数の中にあることが保証されます。 これにより、非除数や上記の値をスキャンする必要がなく、正確性が保証されます。$\sqrt{n}$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())

        if k >= n:
            print(1)
            continue

        ans = n

        r = int(math.isqrt(n))
        for d in range(1, r + 1):
            if n % d == 0:
                if d <= k:
                    ans = min(ans, n // d)
                other = n // d
                if other <= k:
                    ans = min(ans, n // other)

        print(ans)

if __name__ == "__main__":
    solve()
