 ## 解決策
 ## 問題の理解

 いくつかのセルが占有されているとしてマークされ、4 方向に移動するとすべての占有セルが 1 つの接続された領域を形成するグリッドが与えられます。 このタスクは、各層に独立して配置された小さなレゴ ブロックを使用して、占有されているすべてのセルを 2 回 (上層で 1 回、下層で 1 回) 覆うことです。 

各レイヤーは占有セルの完全なタイル化です。 レイヤー内のタイルは、単一のセル、隣接する 2 つのセルを覆うドミノ、または直角を形成する 3 つのセルを覆う L 字型のトリオミノの 3 つの形状のいずれかである必要があります。 空のセルは両方のレイヤーで空のままにする必要があります。 

追加の制約はグローバルです。各ブリックをノードとして扱う場合、2 つのブリックは少なくとも 1 つのグリッド セル上で重なっていても、異なるレイヤーに属している場合は必ず接続されます。 言い換えれば、すべてのセルは、最上層でそれを覆うレンガと最下層でそれを覆うレンガの間にエッジを作成します。 最後の要件は、両方の層にわたるすべてのレンガがこれらのエッジの下で単一の接続されたコンポーネントを形成する必要があることです。 

グリッド サイズは最大 1000 x 1000 なので、セルの総数は最大 100 万個になります。 したがって、どのソリューションも、占有セル数において線形または線形に近い時間で実行する必要があります。 グリッド次元で二次的なものは直ちに不可能になります。 

単純なアプローチでは、両方のレイヤーのすべてのタイルを同時に検索しようとします。 タイルの配置という大きな分岐要素を無視しても、接続条件によって両方の層が結合され、状態空間のセル数が事実上指数関数的に増加します。 

各レイヤーを個別にタイル化しようとすると、より微妙な障害モードが表示されます。 独立したタイリングはローカル妥当性を満たしますが、2 部構成の「ブリック オーバーラップ グラフ」のグローバルな接続性は保証されず、多くの切断されたコンポーネントに簡単に分割される可能性があります。 

この失敗の小さな例は、2 x 2 の完全なグリッドです。 両方のレイヤーが 2 つの水平ドミノを使用してタイル化されている場合、各セルはその列内でのみ 1 対のレンガを接続し、2 つの切断されたコンポーネントを生成します。 

## アプローチ

 主な問題は、接続がレイヤー内ではなく、共有セルを介してレイヤー間で行われることです。 これは、懸念を分離することを示唆しています。一方の層は構造を保証する必要があり、もう一方の層はその構造全体の接続を保証する必要があります。 

強引なアイデアは、両方のレイヤーのタイリングを列挙し、接続をチェックすることです。 有効なペアは線形時間で検証できるため、これは概念的に機能しますが、グリッドのタイリングの数は、小さなグリッドであっても指数関数的に増加します。 これは、小さな入力を超えるとすぐに失敗します。 

重要な観察は、構造を保持するために両方の層が必要ないということです。 1 つの層がすべてのセルを「接着」する慎重に設計された分解を形成するだけで十分であり、もう 1 つの層は非常に単純なものでもかまいません。 

非常に非対称な構造を選択しています。 最下層では、各ブリックがグリッド隣接グラフ内の小さな接続されたセルのグループをカバーする接続されたタイルを構築します。 これらのレンガは、構造全体を接続するバックボーンとして機能します。 

最上層では、簡単なことを行います。占有されているすべてのセルは、それぞれ独自の 1 x 1 レンガです。 これにより最上層が最大限に断片化されますが、最上層と最下層の間の接続は最下層がセルをグループ化する方法によって完全に制御されるため、これは実際に便利です。 

これで、接続条件がより単純なステートメントになりました。 各下層レンガは、それが重なっているすべてのシングルトン上層レンガを接続します。 したがって、下層のレンガが集合的にグリッド上に接続された構造を形成すると、すべての上層のレンガがそれらを介して接続されるようになります。

したがって、問題は、グリッド内の共有エッジによって引き起こされるこれらのタイルの隣接グラフが接続されるように、許容される形状を使用して接続されたグリッドのタイリングを構築することに帰着します。 グリッド領域自体は接続されているため、スパニング ツリーを構築し、それを使用して最大 3 つのサイズの小さな接続された部分への分解をガイドできます。 

ここでL字型が重要になります。 2 つの子を持つツリー ノードは、両方の子を含めて 1 つの L 字型レンガにグループ化でき、1 つのレンガでツリーの複数の枝を接続できます。 これにより、カバレッジを壊すことなく、スパニング ツリーを接続されたブロックに圧縮することができます。

 ## アルゴリズムのチュートリアル

 値 1 を持つセルのセットのみを処理し、それらを 4 方向に隣接するセルの間にエッジがあるグラフの頂点として扱います。 

1. まず、深さ優先検索を使用して領域のスパニング ツリーを構築します。 これが可能になるのは、領域が接続されており、循環のない隣接関係を捉える構造が得られるからです。 
2. すべてのセルに独自のブリック ID を割り当てて最上層を構築します。 この層には内部構造はありませんが、すべてのセルが潜在的な接続ポイントになります。 
3. 次に、スパニング ツリーを使用して最下層を構築します。 目標は、ツリーの頂点をグループに分割することであり、各グループはツリー内に接続されたサブグラフを誘導し、最大サイズが 3 になります。 
4. ポストオーダー方式でツリーを処理します。 各ノードについて、「ペアになっていない」ままになっている子サブツリーの数を調べます。 子サブツリーは、まだブリックに配置されていない場合、ノードを上向きに提供します。 
5. ノードにペアになっていない子が少なくとも 2 つある場合は、現在のノードをそれらの子のうちの 2 つでグループ化し、これら 3 つの頂点を覆う L 字型のレンガを形成します。 これは、ツリー内で各子が親に隣接しているため、3 つのセルすべてがグリッド内で接続されているため有効です。 
6. ペアになっていない子が 1 つだけ存在する場合、それを現在のノードとペアにしてドミノ ブリックを作成します。 繰り返しますが、これはツリーの隣接性により有効です。 
7. ペアになっていない子がない場合、ノードは最下層のシングルトン ブリックになります。 
8. この最下層のパーティションにより、すべてのセルが 1 回だけカバーされ、すべてのレンガは常に 1 つのノード、ツリー内のエッジ、または両方に隣接する 2 つの子を持つ親のいずれかで構成されるため、許可された形状の 1 つとなります。 
9. 最後に、両方のレイヤーのすべてのレンガに一意の ID を割り当て、2 つのグリッドを出力します。 

### なぜ効果があるのか

 スパニング ツリーは、形成するすべてのグループがグリッドに隣接するセルで構成されることを保証します。 ポストオーダー構造により、すべてのノードが 1 つのグループに確実に含まれるようになります。これは、ノードはグループ化中に親によって消費されるか、グループ化が不可能な場合にはシングルトンとして残るためです。 

接続性については、層全体のブリックによって形成された 2 部グラフの構造を観察してください。 すべての最下層ブリックは、そのセルに対応するすべての上層シングルトン ブリックと接触します。 最下層のブリックはスパニング ツリーの共有セルを介して接続されているため、これらの重複によりすべてのブリックにまたがる接続のチェーンが生じます。 その結果、ブリックのサブセットが分離されることはありません。分離すると、スパニング ツリーの接続性や、少なくとも 1 つのブリック内で親子構造を常に無傷に保つグループ化ルールと矛盾するためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n, m = map(int, input().split())
g = [list(input().strip()) for _ in range(n)]

idx = [[-1]*m for _ in range(n)]
cells = []
for i in range(n):
    for j in range(m):
        if g[i][j] == '1':
            idx[i][j] = len(cells)
            cells.append((i, j))

N = len(cells)
adj = [[] for _ in range(N)]

dirs = [(1,0),(-1,0),(0,1),(0,-1)]
for i, (x, y) in enumerate(cells):
    for dx, dy in dirs:
        nx, ny = x + dx, y + dy
        if 0 <= nx < n and 0 <= ny < m and idx[nx][ny] != -1:
            adj[i].append(idx[nx][ny])

parent = [-1]*N
tree = [[] for _ in range(N)]
visited = [False]*N

def dfs(u):
    visited[u] = True
    for v in adj[u]:
        if not visited[v]:
            parent[v] = u
            tree[u].append(v)
            dfs(v)

dfs(0)

top_id = [[0]*m for _ in range(n)]
bid = 1
for i in range(n):
    for j in range(m):
        if g[i][j] == '1':
            top_id[i][j] = bid
            bid += 1

bot_id = [[0]*m for _ in range(n)]
bid2 = 1

def build(u):
    global bid2
    leftovers = []
    for v in tree[u]:
        build(v)
        leftovers.append(v)

    i, j = cells[u]

    while len(leftovers) >= 2:
        a = leftovers.pop()
        b = leftovers.pop()
        ua, va = cells[a]
        ub, vb = cells[b]
        bot_id[i][j] = bot_id[ua][va] = bot_id[ub][vb] = bid2
        bid2 += 1

    if len(leftovers) == 1:
        v = leftovers.pop()
        uv, vv = cells[v]
        bot_id[i][j] = bot_id[uv][vv] = bid2
        bid2 += 1

    if bot_id[i][j] == 0:
        bot_id[i][j] = bid2
        bid2 += 1

build(0)

for row in top_id:
    print(*row)
for row in bot_id:
    print(*row)
```この実装では、まず占有領域の隣接グラフを構築し、次に DFS ツリーを抽出します。 最上層は各セルに一意の識別子を割り当て、すべてのセルをシングルトン ブリックにします。 

最下層の構築はツリー全体にわたって再帰的です。 各ノードは子から結果を収集し、可能な限り親とともに 2 つの子を L 字型のレンガにグループ化します。 子供が 1 人だけ残ると、ドミノが形成されます。 それ以外の場合、ノードはシングルトン ブリックになります。 すべての割り当てはグリッド上で直接行われるため、出力は O(nm) のままです。 

ツリーのエッジは有効なグリッド隣接関係に対応するため、DFS ツリー内で接続されているノードのみを結合するように注意する必要があります。 

## 実用的な例

 単純な 1 行 3 行の 1 を考えてみましょう。 

| ステップ | ノード | 残り物 | アクション | レンガが形成されました |
 | --- | --- | --- | --- | --- |
 | 0 | 真ん中 | [左、右] | 2人の子供を連れて | L 字型 (親 + 子 2 人) |

 最下層は、走査順序に応じて 1 つの L 字型またはトライセル構造を形成しますが、最上層は 3 つのシングルトンのままです。 これにより、1 つの下部レンガがすべての上部レンガに接続されていることが確認されます。 

次に、T 字型の領域を考えてみましょう。 

| ステップ | ノード | 残り物 | アクション | レンガが形成されました |
 | --- | --- | --- | --- | --- |
 | 0 | 中央 | [上、左、右] | グループ 2 人の子供 | L字型 |
 | 1 | 中央 | [右] | 親チェーンとのペア | ドミノ |
 | 2 | 葉 | [] | シングルトン | 1x1 |

 これは、L 字型を使用して分岐がどのように吸収され、子サブツリーが切断されないようにするかを示しています。

 ## 特殊なケース

 単一セル領域は、両方の層でシングルトン ブリックをすぐに割り当てることによって処理されるため、接続は自明のことです。 

DFS ツリーではセルの細い線には分岐がないため、アルゴリズムは L 字型を必要とせずにドミノまたはシングルトンのみを生成します。 

高度に分岐した領域は、L 字型のグループ化ステップによって処理されます。これにより、親が 2 つの子を 1 つのブリックに吸収できるようになり、ツリーが切断されたコンポーネントに断片化するのを防ぐことができます。
