 ## 解決策
 ## 問題の理解

 私たちには一連の日数が与えられています。 毎日、負でない実数を選択します$r_i$、カロリー摂取量として解釈されますが、一定の間隔で横になるように制限されます$[L, R]$。 いくつかの日はすでに固定されています:$k$位置、値$r_i$あらかじめ決められており、変更することはできません。 

これに加えて、別のシーケンスがあります$c_i$、自由に選択できるものではありません。 線形反復を使用して、前日から決定論的に進化します。$$c_i = p \cdot c_{i-1} + (1 - p)\cdot r_{i-1}.$$それでそれぞれ$c_i$以前の代謝状態と以前の摂取量を重み付けしてブレンドしたものです。 

目的はグローバルです: 未修正のものをすべて選択します$r_i$値は、すべての日の合計が$c_i - r_i$最大化されます。 

重要な問題は、以下に関するすべての決定が、$r_i$すべての未来に影響を与える$c_j$因子による反復伝播による値$p$。 したがって、問題は局所的に分離できません。 

制約が意味するのは、$n$まで可能です$2 \cdot 10^5$テスト スイートごとに、最大で$10^4$テストケース。 これにより、さまざまな割り当てをシミュレートしようとしたり、すべての状態に対して動的プログラミングを実行しようとしたりするソリューションは即座に除外されます。 二次関数または偶数関数$O(n \log n)$テスト ケースごとの値は、すべてのテストにわたって慎重に償却される場合にのみ許容されます。 

微妙な特殊なケースは、固定日が連続性を壊すことで発生します。 この問題を単にポジションに対する貪欲さとして扱おうとすると失敗します。$i$固定制約によって分離されたセグメントを含む、その後のすべてのコントリビューションに影響します。 

たとえば、次の場合$p$が 1 に近い場合、早期の決定は遠くまで伝わります。 もし$p$小さいので、近隣の近隣のみが問題になります。 いつも選ぶ素朴な地元の貪欲者$R$または$L$即時ゲインに依存すると、この長距離効果が無視され、固定位置と自由位置が交互になるような場合には失敗します。 

## アプローチ

 再発を無視すると、目的は些細なものに見えます: 最大化$\sum (c_i - r_i)$それぞれを押すことを意味します$r_i$符号に応じて 1 つの境界まで。 しかし、再発はすべてを結びつけます。 

ブルートフォース解釈では、未修正のすべての可能な割り当てが試行されます。$r_i$。 各無料日には連続範囲があるため、$[L, R]$、いくつかの候補に離散化した場合でも、指数関数的な組み合わせが得られます。 休日ごとに 2 つの選択肢だけを考慮したとしても、状態空間は次のようになります。$2^{n-k}$、それは不可能です。 

重要な観察は、再発が線形であるということです。 毎$r_j$多くの未来に貢献します$c_i$しかし、その影響は倍増します。$p$。 これは、最終的な目標をすべての関数の一次関数として書き換えることができることを意味します。$r_i$:$$\sum_{i=1}^n (c_i - r_i) = \sum_{i=1}^n w_i r_i + \text{constant},$$いくつかの係数について$w_i$のみに依存するもの$p$そしてポジション構造。 

この削減が認識されると、問題は古典的な制約付き線形最適化になります。$r_i$ボックス制約を除いて独立しています$[L, R]$、それぞれが独立して目的に貢献します。 したがって、それぞれの$r_i$どちらかにプッシュする必要があります$L$または$R$、固定制約を尊重しながら、その係数の符号に応じて。 

残りのタスクは、これらの係数を効率的に計算することです。 直接展開すると、それぞれが次のようになります。$r_j$すべてに貢献します$c_i$のために$i > j$重さで$(1-p)p^{i-j-1}(1-p)$スタイルの幾何学的な減衰。 すべての接尾辞を合計すると等比級数が得られるため、各位置は次の条件のみに依存する閉形式の係数を持ちます。$p$そして$n-j$。 これは、サフィックス伝播トリックを使用して線形時間で計算できます。 

固定位置は単に選択をオーバーライドし、定数として扱われます。

 ## アルゴリズムのチュートリアル

 それぞれの貢献度を書き直します$r_i$最終目標へ。 

### ステップ 1: 再発の影響を拡大する

 拡大します$c_i$繰り返し：$$c_i = p^{i-1}c_0 + \sum_{j=1}^{i-1} (1-p)p^{i-j-1} r_j.$$これはすべてを示します$r_j$すべての未来に影響を与える$c_i$。 

### ステップ 2: スワップ合計

 目標を書き換えます。$$\sum_{i=1}^n c_i - \sum_{i=1}^n r_i.$$最初の項はすべてのペアの二重和になります$(j, i)$と$j < i$、さらにからの初期貢献$c_0$。 すべての用語をグループ化して並べ替える$r_j$、位置ごとに係数を生成します。 

### ステップ 3: 寄与の重みを計算する

 固定の場合$j$、その合計貢献度は次のとおりです。$$r_j \cdot (1-p)\sum_{i=j+1}^n p^{i-j-1} = r_j \cdot (1-p)\frac{1-p^{n-j}}{1-p} = r_j (1 - p^{n-j}).$$次に直接を引きます$-r_j$用語を与えると:$$w_j = (1 - p^{n-j}) - 1 = -p^{n-j}.$$だから、すべての$r_j$係数に線形的に寄与する$-p^{n-j}$、固定定数は次から得られます。$c_0$。 

### ステップ 4: 制約を処理する

 それぞれ未修正$r_j$で選ばれます$[L, R]$。 目標は直線的であるため、$r_j$、最適な選択は次のとおりです。 

もし$w_j \ge 0$、 選ぶ$R$、それ以外の場合は選択してください$L$。 

### ステップ 5: 最終的な回答を蓄積する

 次のべき乗を事前計算します$p$再計算と寄与の合計を避けるために後ろから。 

### なぜ効果があるのか

 システム全体はすべて直線的です$r_i$。 反復によって、異なる決定変数間に非線形相互作用が生じることはありません。 幾何学的減衰を介して時間の経過とともに重みを再分配するだけです。 独立した線形項の合計として書き換えられると、実行可能領域は区間の積になります。 区間の積にわたる線形目標は常に各区間の境界で独立して最適化されるため、各変数の決定は局所的に最適であり、全体的に一貫しています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, k = map(int, input().split())
        r0, c0, p, L, R = map(float, input().split())

        fixed = {}
        for _ in range(k):
            pos, val = input().split()
            pos = int(pos)
            val = float(val)
            fixed[pos] = val

        # suffix powers of p
        powp = [1.0] * (n + 2)
        for i in range(n, 0, -1):
            powp[i] = powp[i + 1] * p

        ans = 0.0

        # contribution from initial c0
        ans += c0 * powp[1]

        for i in range(1, n + 1):
            coeff = -powp[i]

            if i in fixed:
                ans += coeff * fixed[i]
            else:
                if coeff >= 0:
                    ans += coeff * R
                else:
                    ans += coeff * L

        print(f"{ans:.10f}")

if __name__ == "__main__":
    solve()
```実装では次のべき乗を計算します。$p$後ろからだから$p^{n-i}$で利用可能です$O(1)$。 各位置は独立して処理されます。 固定値は境界の選択をオーバーライドしますが、自由変数は線形寄与を最大化するエンドポイントにプッシュされます。 

微妙な点は浮動小数点精度です。すべての係数は次の幾何乗であるためです。$p$、値はすぐに減衰しますが、維持するには倍精度の累積が必要です。$10^{-6}$正確さ。

 ## 特殊なケース

 エッジケースの 1 つは、すべての位置が固定されている場合です。 その状況では、アルゴリズムは境界の置換を決して試行してはなりません。 固定オーバーライド パスが意思決定を完全にバイパスするため、係数ロジックは引き続き機能し、結果は線形形式の直接評価になります。 

別のエッジケースが発生するのは次の場合です。$p$は 1 に非常に近いです。$p^{n-i}$ゆっくりと減衰し、初期の位置は依然として全体に大きな影響を与えます。 このアルゴリズムは、級数を切り捨てたり近似したりするのではなく、浮動小数点累乗を直接使用するため、これを変更せずに処理します。 

最後のケースは次のような場合です。$p$とても小さいです。 すると、最後の係数を除くすべての係数がゼロに近くなり、最後の日数だけが問題になります。 実装では依然として各項が評価されますが、数値的な寄与は自然に最後に集中し、再帰の分析動作と一致します。
