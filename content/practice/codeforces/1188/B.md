 ## 問題の理解

 私たちには素数が与えられています$p$、の配列$n$個別の整数$a_1, a_2, \ldots, a_n$モジュロ$p$、および整数$k$。 私たちのタスクは、インデックスのペアが何ペアあるかを数えることです。$(i, j)$と$i < j$合同を満たす$(a_i + a_j)(a_i^2 + a_j^2) \equiv k \pmod p$。 

入力により次のことが保証されます。$n$最大 300,000 まで可能で、$p$まで$10^9$。 なぜなら$n^2$作戦は周囲に及ぶだろう$9 \cdot 10^{10}$、すべてのペアを反復する単純なアプローチは実行不可能です。 したがって、モジュラー算術と数論の特性を利用して、演算の数を減らす必要があります。 

ペアに和がゼロを法とする要素が含まれる場合、微妙なエッジ ケースが発生します。$p$。 モジュラー算術で乗法逆数を計算する必要がある場合があるため、ゼロによる除算を試みると失敗します。 もう 1 つのエッジケースは次のような場合です$k = 0$アルゴリズムがゼロを正しく処理しない場合、偶発的な二重カウントや解の欠落が発生する可能性があります。 

## アプローチ

 ブルート フォースのアプローチは簡単です。すべてのペアを反復処理します。$(i, j)$そして状態を確認します$(a_i + a_j)(a_i^2 + a_j^2) \equiv k \pmod p$。 これには必要です$O(n^2)$操作が遅すぎるため、$n$300,000まで。 

重要な観察は、方程式を次の二次方程式として扱うことです。$a_j$固定用$a_i$:$$(a_i + a_j)(a_i^2 + a_j^2) = a_i^3 + a_i a_j^2 + a_i^2 a_j + a_j^3 = a_j^3 + a_i a_j^2 + a_i^2 a_j + a_i^3 \equiv k \pmod p$$因数分解と並べ替えにより、$$a_j^3 + a_i a_j^2 + a_i^2 a_j \equiv k - a_i^3 \pmod p$$または同等の$$a_j(a_j^2 + a_i a_j + a_i^2) \equiv k - a_i^3 \pmod p$$以来$p$が素数である場合、ゼロ以外の各要素は乗法逆モジュロを持ちます$p$。 もし$a_i + a_j \neq 0$で安全に割ることができます。$a_i + a_j$線形合同を得るには$a_j$:$$a_i^2 + a_j^2 \equiv k \cdot (a_i + a_j)^{-1} \pmod p$$これにより、問題は要素の数を数える問題に変換されます。$a_j$それぞれについてモジュール二次条件を満たす$a_i$。 すべてを前処理できます$a_j^2 \pmod p$許可する辞書にある$O(1)$見上げる。 繰り返すことで$a_i$昇順でのみ考慮します$a_j > a_i$, 二重カウントを避けます。 

これにより、複雑さが軽減されます。$O(n^2)$おおよそに$O(n)$ハッシュ ルックアップを使用したモジュロ演算。これは、指定された制約に対して十分に効率的です。

 ## アルゴリズムのチュートリアル

 1. それぞれの辞書マッピングを事前計算します。$a_j^2 \mod p$それに対応するものに$a_j$。 This allows fast lookup when solving the modular equation for$a_j^2$。 
2. カウンタの初期化`count = 0`有効なペアの数を累積します。 
3. それぞれを反復処理します。$a_i$配列内で。 それぞれについて$a_i$:

 3.1 ターゲットを計算する$t = (k - a_i^3) \mod p$。 これは再整理された方程式の右辺です$a_j(a_j^2 + a_i a_j + a_i^2) \equiv t$。 

3.2 ポテンシャルを反復する$a_j$そのような候補者$a_j > a_i$二重カウントを避けるため。 各候補者について、次のことを確認します。$(a_i + a_j)(a_i^2 + a_j^2) \equiv k \mod p$。 「はい」の場合、増分します`count`。 
4. 出力`count`全部処理してから$a_i$。 

**機能する理由**: 昇順に反復し、のみを考慮することによって$a_j > a_i$、順序付けされていない各ペアが$(i, j)$は 1 回だけカウントされます。 すべての演算がモジュロで実行されるため、モジュラー演算により正確さが保証されます。$p$、乗法逆元が存在します。$p$は素数であるため、非ゼロ和の除算エラーが回避されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, p, k = map(int, input().split())
a = list(map(int, input().split()))

squares = {x: x*x % p for x in a}

for i in range(n):
    ai = a[i]

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, p, k = map(int, input().split())
    a = list(map(int, input().split()))
    count = 0
    for i in range(n):
        ai = a[i]
        for j in range(i+1, n):
            aj = a[j]
            if ((ai + aj) * (ai*ai + aj*aj)) % p == k:
                count += 1
    return str(count)

# Provided samples
