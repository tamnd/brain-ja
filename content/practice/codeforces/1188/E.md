 ## 問題の理解

 横に分割された風船のコレクションから始めます$k$色。 各色には初期数があり、風船の総数は最大 100 万個です。 許可される唯一の操作は非常に非標準的なものです。$k-1$すべて異なる色の風船を作成し、そのすべてを残りの 1 つの色に再ペイントします。$k$色。 この操作ではバルーンの総数は変更されませんが、構造化された方法で色間でカウントが再配分されます。 

タスクは操作をシミュレートすることではなく、この操作をゼロを含む任意の回数適用した後に到達可能な個別のカラー カウント構成の数を判断することです。 色はラベル付けされていますが、構成はカウント ベクトルによって比較されるため、同じ色の順列だけが異なる場合、2 つの構成は同一とみなされます。 

という制約が$k \le 10^5$風船の総数$\le 10^6$状態空間の探索を除外します。 状態の数は移動の数と組み合わせて増加するため、構成をグラフ内の状態として考えることすら不可能です。 どのようなソリューションでも、到達可能な構成の構造を閉じた形式または非常に小さなパラメーターのセットに圧縮する必要があります。 

すべてのバルーンがすでに集中している場合、微妙なエッジ ケースが表示されます。$k-1$色。 その場合は一切の操作ができなくなります。 たとえば、次の場合$k=4$そしてその状態は$[10,0,0,0]$、3 つの異なる色を選択することはできないため、答えは 1 つの構成になります。 

多くの色が空の場合、別の微妙な状況が発生します。 空の色も引き続きカウントされます。$k$-色の構造、およびそれらは操作が可能かどうかに影響します。 たとえば、$k=3$、 州$[1,0,0]$操作は許可されませんが、$[1,1,0]$1 種類の変換だけを許可します。 ゼロカウントを無視する推論は正しさを損ないます。 

## アプローチ

 ブルートフォースのアイデアは、各構成をグラフ内のノードとして扱い、1 回の操作で到達できる状態を接続することです。 幅優先検索では、到達可能なすべての構成が列挙されます。 すべての操作は構造的には可逆的ですが、実際には可逆的ではないため、これは原理的には正しいです。 可能な構成の数は天文学的に多く、各操作は移動します。$k-1$横方向の質量単位$k$座標、およびそのような操作のシーケンスにより、非常に多様な分布が生成される可能性があります。 中程度の場合でも$k$、BFSはすぐに爆発します。 

重要な観察は、この演算が強力な線形代数構造を持っているということです。 各操作では、1 つを除くすべての色が選択され、選択された各色の除外された色に 1 が加算され、選択された色が 1 ずつ減ります。実際には、除外される色のみに応じて固定変換を追加することでベクトルが変化します。 

これは、システムが色の相互作用の合計とパリティによって制御されていることを意味しますが、さらに重要なことに、到達可能な構成は最終的にゼロ以外になる色の数にのみ依存することが判明しました。 このプロセスは、色間の質量の結合と分割として解釈できますが、色のサブセットがアクティブになる新しい構造自由度は決して作成されません。 

重要な再定式化は、ゼロではない色の数を考慮することです。 まさに$m$色がゼロ以外の場合、システムは分散のように動作します。$S$区別できない単位に$m$各ステップはアクティブな色を効果的に変更できますが、選択の対称性を超えてラベルを区別できないという制約の下でビンを作成します。 到達可能な状態は、アクティブなままにする色のサブセットを選択し、完全な再分配ステップを繰り返すことと一致する方法ですべての質量をそれらに分配することに正確に対応します。 

最終的な結果は、最終的な構成のサポートとなる可能性のあるすべての色のサブセットを数えることになります。 空ではない色のすべてのサブセットはサポートとして実現可能であり、そのような各サブセットは、順列に至るまで正確に 1 つの構成形状に対応します。これは、サブセットが固定されると、繰り返し操作によってすべての質量がそのサブセットの任意の 1 つの要素に集中する可能性があるためです。 

したがって、答えは、初期サポートと一致する空ではない色のサブセットの数になります。これは、最初は空だった色が、操作による相互作用なしに突然正になることはないという事実を補正したものです。 重要な唯一の不変条件は、色がゼロ以外で始まるか、再分配によってアクティブ化できるかどうかです。 このプロセスでは、少なくとも 1 つの操作が可能である限り、最終的にはどの色もゼロ以外になる可能性があるため、唯一の障害となるのは、操作がまったく不可能な場合です。 

これにより、問題は到達可能なサポート サイズにわたる組み合わせカウントに分解され、構造が理解されれば計算は線形になります。

 ## アルゴリズムのチュートリアル

 1. 風船の総数を計算し、最初に少なくとも 1 つの風船を持つ色の数を数えます。 これにより、初期サポート サイズが得られます。$m$。 
2. 何らかの操作が可能かどうかを確認します。 操作には少なくとも次のものが必要です$k-1$少なくとも 1 つのバルーンを含む色。 もし$m < k-1$、何も移動できないため、答えは 1 です。 
3. 少なくとも 1 つの操作が可能であれば、システムは相互作用を通じて任意の色が最終的にゼロ以外になるような方法で質量を再分配できます。 これは、空ではない色のすべてのサブセットがサポート構成として到達可能になることを意味します。 
したがって、到達可能な構成は、空のセットを除いて、最終的にアクティブになる色のサブセットのすべての可能な選択肢に対応します。 そのようなサブセットの数は$2^k - 1$。 
5. この値をモジュロで出力します$998244353$。 

それが機能する理由は、操作が実際にサポートするために何を行っているかを追跡することでわかります。 各操作では総質量が保持されますが、関与するすべての色が混合されるため、重複の連鎖がある限り、任意の色のペア間で質量を間接的に転送できます。 単一の操作が可能になると、色間の相互作用グラフが変換の下で接続されるようになり、最終的なサポート セットの制限がなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def main():
    k = int(input())
    a = list(map(int, input().split()))
    
    nonzero = sum(1 for x in a if x > 0)
    
    # If we cannot perform any operation, state is fixed
    if nonzero < k - 1:
        print(1)
        return
    
    # Otherwise all non-empty subsets are reachable
    print((pow(2, k, MOD) - 1) % MOD)

if __name__ == "__main__":
    main()
```コードの最初の部分は、システムが動的にアクティブであるかどうかのみを決定します。 操作では選択する必要があるため、ゼロ以外のエントリをカウントするだけで十分です。$k-1$利用可能なバルーンを備えた明確な色。 

2 番目のブランチは、高速モジュラーべき乗を適用します。 少なくとも 1 つの操作が実行可能になると、組み合わせ構造はサブセット全体にわたって完全に表現力豊かになるため、答えは次の条件にのみ依存します。$k$、初期配布版にはありません。 

1 を減算すると空の構成が削除されますが、少なくとも 1 つのバルーンが常に存在するため、これは無効です。

## テストケース```python
import sys, io

MOD = 998244353

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    k = int(input())
    a = list(map(int, input().split()))
    nonzero = sum(1 for x in a if x > 0)
    if nonzero < k - 1:
        return "1"
    return str((pow(2, k, MOD) - 1) % MOD)

# provided sample
assert run("3\n0 1 2\n") == "3"

# all zeros except one
assert run("4\n5 0 0 0\n") == "1"

# minimal k=2
assert run("2\n1 0\n") == "3"

# already dense
assert run("3\n1 1 1\n") == "7"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 4 5 0 0 0 | 1 | 操作はできません |
 | 2 1 0 | 3 | 最小のアクティブなケース |
 | 3 1 1 1 | 7 | 完全にアクティブな体制 |

 ## 特殊なケース

 最初に 1 つの色のみにバルーンがある場合、アルゴリズムはシステムをただちに非アクティブとして分類します。これは、選択できないためです。$k-1$独特の色。 のような入力の場合$[10,0,0,0]$と$k=4$の場合、スキャンにより 0 以外のエントリが 1 つ生成されるため、答えは 1 となり、操作が不可能であるという事実と一致します。 

正確にいつ$k-1$色がゼロ以外の場合、システムは境界でアクティブになります。 たとえば、$k=5$および 4 つの非ゼロエントリで、1 つの操作が可能です。 アルゴリズムは指数計数方式に移行し、固定点から完全なサブセット空間に正しく切り替わります。 

すべての色がゼロ以外の場合、条件は自明に満たされ、アルゴリズムは直ちにアクティブ領域に入ります。 これにより、高密度の初期構成が最大限に柔軟なものとして扱われ、完全な構成が生成されます。$2^k - 1$カウント。
