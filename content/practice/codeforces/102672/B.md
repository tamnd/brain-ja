 ## 問題の理解

 私たちは持っています`n`ダンサーは整数座標に配置されます。 複数のダンサーが同じ座標を共有する場合があります。 ダンス中、各ダンサーは独立して 1 つのユニットを左右に同じ確率で動かします。 

すべての動きの後に占有された位置の複数セットが以前とまったく同じであれば、ダンスは成功です。 ダンサーの初期配置を選択することができ、ダンスが成功する確率を最大化する必要があります。 出力は、この最大確率の底 2 の対数です。 

の値`n`これにより、シミュレーション、ダンサーの数に対する動的プログラミング、または可能な配置の数に依存するアプローチが即座に除外されます。 解決策は、答えを直接公式に帰着させる数学的パターンを見つけることから導き出される必要があります。 

最初の隠れた制約はパリティから来ます。 すべてのダンサーは、2 つの整数座標間のちょうど 1 つのギャップを横切って移動します。 最終的な構成が最初の構成と一致するには、すべてのギャップで両方向に同じ数のダンサーが交差する必要があります。 つまり、ダンサーの総数はバランス クロッシングの総数の 2 倍でなければなりません。 その結果、奇数のダンサーが仕事をすることはできません。 

たとえば、1 人のダンサーの場合:```
1
```答えは`0`なぜなら、唯一のダンサーは元の座標から離れなければならないからです。 

偶数の例:```
4
```最適な確率は`1/8`したがって、出力は次のようになります。```
-3
```よくある間違いは、すべてのダンサーを 2 つの隣接する座標のみに配置することです。 4 人のダンサーの場合、両側に 2 人ずつ配置すると、有効な交差パターンは 1 つだけになります。`1/16`。 より良い配置では、カウント付きの 3 つの座標を使用します。`1,2,1`、中央のペアは 2 つの異なる方法で交換でき、確率が得られます。`2/16`。 

## アプローチ

 強引なアプローチでは、ダンサーのさまざまな配置を試し、構成を変更しないで考えられる動きの選択肢をすべて数えます。 問題は、可能な座標の選択肢が無限にあり、たとえ狭い間隔に制限したとしても、移動結果の数は`2^n`。 のために`n = 40000`、単一の配置を確認することさえ不可能です。 

有益な観察は、個々のダンサーについて考えるのをやめ、代わりにギャップについて考えることです。 2 つの隣接する占有座標間にギャップがあると仮定します。`x`ダンサーが左から右へ渡ります。 ダンスを成功させるには、正確に`x`ダンサーたちは同じ隙間を右から左へ渡ります。 したがって、すべてのギャップはバランスのとれた数の交差に関連付けられます。 

連続するギャップを通過する回数を次のようにします。```
g1, g2, ..., gk
```ダンサーの総数は正確に次のとおりです。```
2 * (g1 + g2 + ... + gk)
```なぜなら、交差点ごとに両側から 1 人のダンサーが参加するからです。 

ギャップの固定シーケンスの場合、有効な動作の選択肢の数は、各ダンサーのグループが方向を選択できる方法の数によって決まります。 2つの隙間の間の位置`a`そして`b`、 がある`a + b`ダンサー、そして私たちはどちらかを選ばなければなりません`a`そのうちの左に行きます。 これは次のことに貢献します。```
C(a + b, a)
```方法。 

残りの問題は、これらの二項係数の積を最大化するためにギャップ サイズを選択する方法です。 クロスカウントを小さなギャップに分割すると常に役立ちます。 最大の貢献は、すべてのギャップにサイズを持たせることによってもたらされます`1`。 

あれば`n / 2`合計の交差数とすべてのギャップのサイズが 1 の場合、配置は次のようになります。```
1, 2, 2, ..., 2, 1
```両端はそれぞれ 1 つの可能な選択肢に寄与し、すべての中間位置は次のように寄与します。```
C(2,1) = 2
```がある`n / 2 - 1`中間の位置なので、成功した動きの割り当ての数は次のようになります。```
2^(n/2 - 1)
```可能なダンスの総数は次のとおりです。```
2^n
```したがって、最大確率は次のようになります。```
2^(n/2 - 1) / 2^n = 2^(-n/2 - 1)
```したがって、答えは単純に次のようになります。```
-n/2 - 1
```均等に`n`。

 ## アルゴリズムのチュートリアル

 1. ダンサーの人数を読み取る`n`。 必要な情報はパリティだけです`n`なぜなら、最適な確率はダンサーの数をバランスの取れた交差に分割できるかどうかによってのみ決まるからです。 
2. もし`n`奇数です、出力`0`。 ダンスを成功させるには、すべてのダンサーが同じギャップを反対方向に横切るダンサーとペアになる必要がありますが、奇数のダンサーではこれは不可能です。 
3. もし`n`偶数、出力`-n/2 - 1`。 これは、あらゆる場所で単位サイズのギャップを使用することによって得られる確率の対数です。 

なぜ効果があるのか:

 成功したダンスはすべて、あらゆるギャップをバランスよく横断することに対応しています。 交差点の総数は固定されています。`n/2`。 これらの交差点をより多くのギャップに分割すると、独立した選択肢の数が増えます。 可能な限り最良の分割は、すべてのギャップに交差が 1 つだけ含まれるようにすることです。 これにより、可能な最大数の有効な動作割り当てが作成されます。`2^(n/2-1)`。 ずっと`2^n`方向の選択は同様の確率であり、確率は正確に`2^(-n/2-1)`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    if n % 2:
        print(0)
    else:
        print(-n // 2 - 1)

solve()
```この実装では、ダンサーの数が偶数であるかどうかのみをチェックします。 最適な確率はパリティとサイズによって完全に決定されるため、位置を保存したり、動きをシミュレートしたりする必要はありません。`n`。 

表現`-n // 2 - 1`Python の整数除算は偶数に対して正確であるため、機能します。`n`。 浮動小数点計算が必要ないため、対数出力の精度の問題が回避されます。

import sys
import io

def solve_io(inp: str) -> str:
    old_stdin = sys.stdin

 ## 特殊なケース

 のために`n = 1`、バランスをとることはできません。 唯一のダンサーが別の座標に移動する必要があるため、確率はゼロとなり、アルゴリズムは次のように出力します。`0`。 

次のような奇数の値の場合:```
5
```単純な数式では、依然として対数値を計算しようとする可能性があります。 交差の議論は、ダンスを成功させるにはすべての交差がペアになる必要がある、つまりダンサーの総数が偶数でなければならないため、これが起こり得ないことを示しています。 アルゴリズムはこれを即座に検出し、出力します。`0`。 

最小偶数の場合:```
2
```式は次のようになります。```
-2 / 2 - 1 = -2
```それは確率に相当します`1/4`。 隣り合った 2 人のダンサーは位置を交換する必要があり、4 つの可能な動きの選択肢のうち 1 つが成功します。 

次のような大規模な入力の場合:```
40000
```このソリューションは、配置を構築したり、可能性を列挙したりするものではありません。 以下を直接計算します。```
-20000 - 1 = -20001
```したがって、オーバーフローやパフォーマンスの問題はありません。
