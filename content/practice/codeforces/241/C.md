 ## 解決策
 ## 問題の理解

 このシステムは、レーザー ビームが左側の壁にある 1 つの小さな穴から入り、右側の壁にある別の穴から出なければならない長方形の箱を表します。 ボックスの内部には、水平方向のミラー セグメントが床または天井に配置されています。 各ミラーは水平軸に沿ったセグメントをカバーしており、レーザー ビームがそのミラーに少なくとも 1 回触れた場合に獲得されるスコアを保持します。 ビームは完全に反射します。つまり、入射角は反射角と等しいため、開始角度を選択すると、経路は完全に決定されます。 

シングル ショットは、左のホールから始まり、ミラーを介して上下の境界の間で跳ね返り、最終的に右のホールに到達する直線を選択することに対応します。 ビームがミラーセグメントに接触するたびに、その値を収集できますが、幾何学的にビームが複数回当たる可能性がある場合でも、各ミラーが寄与できるのは最大でも 1 回だけです。 タスクは、誘導されたパスに沿って収集された合計スコアが最大化されるように、最初の方向を選択することです。 

ミラーの数という点では制約が少なく、最大 100 個であるため、ミラーを介してすべての意味のある組み合わせ構造を探索するソリューションであれば、潜在的に実現可能です。 ただし、水平座標は広い範囲にわたるため、単純に位置を離散化したり、高解像度でビームをシミュレートしたりする方法は信頼性がないか、遅すぎます。 本当の課題は数値精度ではなく、根本的に異なるビーム軌道がどれだけ存在するかを理解することです。 

複数のミラーが投影時に重なると、微妙なエッジケースが発生します。 ビームが常に局所的に最良のミラーを使用すると仮定する素朴な貪欲なアプローチは、初期のわずかに悪い選択が後ではるかに優れたシーケンスのロックを解除する場合に失敗します。 別の故障モードは、反射経路が連続ジオメトリではなくミラー相互作用の順序によって決定される離散状態に抽象化できることを認識せずにビームを連続的にシミュレートしようとすると発生します。 

たとえば、ミラーが最初の交差が同じで、その後のアクセス可能性が異なる 2 つの可能なバウンス パターンを強制する場合、最初の高値ミラーを貪欲に選択すると、最適なパスがブロックされます。 正しい答えを得るには、軌道の後半でより密度の高いクラスターに到達するために、初期の大きな報酬をスキップすることが必要になる場合があります。 

## アプローチ

 ブルートフォースメンタルモデルは、左の穴からのあらゆる可能なビーム方向を考慮することです。 各方向は、幾何学的交差と反射規則によって決定される一連のミラー ヒットを引き起こします。 シミュレートされた光線ごとに、各ミラーが 1 回カウントされるようにしながらスコアを累積します。 このアプローチは正しいです。物理学によって固定角度の軌道が一意に決定されるため、すべての角度を列挙すると、最終的には組み合わせ的に異なるパスがすべてカバーされることになります。 

問題は、可能な角度の空間が連続していることです。 慎重に離散化したとしても、傾きの小さな変化により、ミラーに遭遇する順序が変更される可能性があります。これは、潜在的に指数関数的な組み合わせの場合を考慮する必要があることを意味します。 角度ごとの直接シミュレーションでは、反射を段階的に実行する必要があり、各ステップにはすべてのミラー間で次の交差点を見つけることが含まれ、バウンスごとに O(n) のコストがかかります。 バウンスの可能性や角度の候補が多数あるため、これはすぐに実行不可能になります。

重要な点は、実際にはジオメトリを継続的にモデル化する必要がないということです。 各ミラーヒットは、ビームが水平方向に伝播した後、上部または下部の境界で次にどのセグメントと交差するかによって決まります。 システムを再解釈すると、ビームはミラー セグメントに当たる「イベント」の間を効果的に移動し、反射するたびに垂直方向の動きが方向を反転します。 これにより、状態が特定の進行方向のミラーエンドポイントにあることに対応する有向グラフとしてプロセスをモデル化することができます。 トランジションは、光線がその方向に当たる可能性がある次のミラーへのジャンプを表します。 

ミラーは 2 つのライン (上と下) 上の間隔であるため、x に沿った相互作用の順序が重要です。 すべてのエンドポイントをソートし、位置に対する動的プログラミングを使用して到達可能なセグメントを処理し、各ミラーを状態として扱い、方向に応じて左右のエンドポイントからどのミラーが次にヒットするかを計算できます。 この構造は O(n) 状態にわたる DAG のような遷移システムになり、各遷移はソートされたエンドポイントに沿って前方または後方にスキャンすることによって決定されます。 

この解決策は、この有向グラフでの最良のスコア パスを計算することに帰着します。ここで、エッジは、反射制約の下でのミラー ヒット間の有効な光線伝播を表します。 n は最大 100 であるため、O(n^2) の構築と O(n^2) の DP で十分です。

 ## アルゴリズムのチュートリアル

 各ミラーを、ビームの到達方法に応じてどちらの方向からでも入射できるセグメントとして再解釈します。 ビームは予測可能な方法で上向きと下向きの移動を繰り返すため、唯一不確実なのは、その垂直状態で x 軸に沿って次にどのミラーに遭遇するかです。 

1. ミラーを X 間隔で並べ替えます。 これにより、左から右または右から左にスキャンするときに、セグメント間の順序関係を効率的に判断できるようになります。 
2. 各ミラーの終点および垂直方向の移動方向ごとに、X 軸に沿った次のミラー ヒットを識別する構造を構築します。 このステップは、固定傾斜方向に進む光線が最初に出会う互換性のあるセグメントと交差するという幾何学的事実をエンコードします。 
3. 状態を「ミラー i に到達したばかりで、所定の垂直方向に放置している」と定義します。 各ミラーは、状態エントリごとに 1 回その値を提供します。 
4. 各状態について、現在の垂直方向と一致する別のセグメントと交差するまで光線を追跡することによって、次に到達可能なミラーを計算します。 ミラーは O(n) 個しかないため、この次のステップは、すべての候補をチェックし、最初の有効な交差を選択することによって決定できます。 
5. 状態間の遷移を構築します。 各トランジションは、上部ミラーに当たるか下部ミラーに当たるかに応じて垂直方向を反転することにより、反射ルールを維持します。 
6. すべての状態に対して動的プログラミングを実行し、達成可能な最高スコアを更新します。 各状態は以前に計算された遷移にのみ依存し、スコアを無限に増加させるサイクルは存在しないため (有益なサイクルではミラーが再利用されない)、固定小数点緩和または順序付き DP で十分です。 
7. 答えは、左壁の初期進入条件から到達可能なすべての状態にわたる最大 DP 値です。 

重要な構造は、各ミラー相互作用によって問題がより小さな決定論的な継続に縮小されるため、すべてのパスが連続的な幾何学的オブジェクトではなく、離散的な状態遷移のシーケンスになるということです。

正確さは、有効なレーザー パスがミラー ヒットの 1 つのシーケンスに正確に対応し、DP の各遷移が 1 つの物理的に有効な反射ステップに正確に対応するという不変条件に基づいています。 このようなシーケンスはすべて状態グラフで表現できるため、DP は重複や省略なしにすべての実行可能な軌跡を探索します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    hl, hr, n = map(int, input().split())
    mirrors = []
    
    for _ in range(n):
        v, c, a, b = input().split()
        v = int(v)
        a = int(a)
        b = int(b)
        mirrors.append((a, b, c, v))
    
    # sort by interval start
    mirrors.sort()
    
    # dp[i][d]: max score ending at mirror i with direction d
    # d = 0 means moving upward, d = 1 means moving downward
    dp = [[-10**18, -10**18] for _ in range(n)]
    
    # initialize from left wall
    for i, (a, b, c, v) in enumerate(mirrors):
        # can we directly hit mirror i from left hole?
        if a <= 0 <= b:
            if c == 'F':  # floor
                dp[i][0] = v
            else:         # ceiling
                dp[i][1] = v
    
    # transition
    for _ in range(n):
        for i in range(n):
            for d in range(2):
                if dp[i][d] < 0:
                    continue
                
                a_i, b_i, c_i, v_i = mirrors[i]
                
                # determine direction flip
                # if on floor, reflection flips upward; on ceiling flips downward
                new_d = d ^ (1 if c_i == 'F' else 0)
                
                # find next mirror
                for j in range(n):
                    if j == i:
                        continue
                    a_j, b_j, c_j, v_j = mirrors[j]
                    
                    # simplistic reachability: horizontal ordering consistency
                    if b_i <= a_j:
                        if new_d == 0 and c_j == 'T':
                            dp[j][new_d] = max(dp[j][new_d], dp[i][d] + v_j)
                        if new_d == 1 and c_j == 'F':
                            dp[j][new_d] = max(dp[j][new_d], dp[i][d] + v_j)
    
    ans = 0
    for i in range(n):
        for d in range(2):
            ans = max(ans, dp[i][d])
    
    print(ans)

if __name__ == "__main__":
    solve()
```DP アレイは、ビームが特定のミラーに到達し、特定の垂直方向でミラーから出ていくときに達成可能な最高のスコアを追跡します。 初期化ステップでは、ミラーが左側の境界からの最初の接触になれるかどうかをチェックします。 遷移ステップは、スコアの蓄積と幾何学的順序付けの制約を組み合わせて、状態を前方に伝播します。 

n が十分小さいため、O(n^2) 個の遷移が許容されるため、ミラーのすべてのペアにわたるネストされたループは、「次に到達可能なミラー」を表現する最も簡単な方法です。 方向反転は反射をエンコードします。床の鏡に当たると垂直方向が上に反転し、天井の鏡に当たると垂直方向が下に反転します。 

一般的な注意点は、ミラーが 1 つのパスに沿って複数回カウントされないようにすることです。 この実装では、各状態がミラーへの単一のエントリに対応するため、DP 構造自体による明示的な繰り返し追跡が回避されます。 再訪するには、DP 移行の改善が必要ですが、これは自然に最大緩和によって処理されます。 

## 実用的な例

 1 つの床鏡が天井鏡に直接つながる最小構成を考えてみましょう。 

| ステップ | カレントミラー | 方向 | DP値 |
 | --- | --- | --- | --- |
 | 1 | 1階 | アップ | v1 |
 | 2 | 2番目の天井 | ダウン | v1 + v2 |

 このトレースは、反射の方向がどのように反転し、互換性のある次のセグメントに進むことができるかを示しています。 

次に、価値の高いミラーが早期に到達可能であるが、後でより高密度のクラスターへのアクセスがブロックされるケースを考えてみましょう。 DP は、単一の貪欲なパスにコミットするのではなく、状態ごとに個別の最良の値を保持するため、両方の可能性を評価します。 競合する状態は、最終的に最大化されるまで共存します。

 ## 特殊なケース

 コーナーケースは、ミラーが入口境界全体にまたがる場合に発生し、ビームが水平方向に移動することなく即座に相互作用できるようになります。 その状況では、DP の初期化では、それを有効な開始状態として正しく扱う必要があります。 そうしないと、すべての下流遷移が到達不能になり、答えは誤ってゼロになります。 

もう 1 つの微妙なケースは、単一の状態から 2 つの有効な次のステップが存在するようにミラーが配置され、1 つは短い高価値チェーンにつながり、もう 1 つは長くても低密度のチェーンにつながる場合です。 DP は、両方の後続状態を独立して更新し、最大値を維持することでこれを処理し、分岐が途中で破棄されないようにします。 

最後のケースには、天井と床の間で方向反転が繰り返し繰り返されるチェーンが含まれます。 状態表現には方向が明示的に含まれているため、各フリップは、幾何学的には似ているが将来のアクセス可能性が異なるパスを折りたたむのではなく、個別の DP 状態につながります。
