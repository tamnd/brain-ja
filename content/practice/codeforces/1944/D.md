 ## 解決策
 ## 問題の理解

 英小文字の文字列とクエリのセットが与えられ、それぞれが文字列の連続した部分文字列を指定します。 各クエリについて、すべての長さの合計を計算するように求められます。$k$同じ長さの部分文字列が少なくとも 1 つ存在する$k$それは回文ではありません。 言い換えれば、各部分文字列について、対称性を破るすべての非自明なセグメントの長さの合計が必要になります。 

入力制約は大きく、文字列の長さとクエリの数はそれぞれ次の制限に達します。$2 \cdot 10^5$、テスト ケース全体のすべての文字列の長さとクエリ数の合計も超えることはできません。$2 \cdot 10^5$。 したがって、あらゆる長さのすべての部分文字列を検査する素朴な解決策は不可能です。これは、部分文字列の数が文字列の長さに応じて二次関数的に増加し、最悪の場合が生じるためです。$O(n^3)$解決策は実現不可能です$n \sim 10^5$。 

たとえば、部分文字列が一様である場合、明白ではないエッジ ケースが発生します。`aaa`または`bbbb`。 このような場合、すべての部分文字列は回文であるため、合計はゼロになります。 別のエッジケースは、次のように部分文字列が文字を交互に配置するときに発生します。`ababab`。 この場合、長さ 2 以上の部分文字列のみが非回文である可能性があり、長さを二重にカウントしないように注意する必要があります。非回文セグメントがある場合、すべての長さは多くても 1 回だけカウントされます。 最小の部分文字列の長さ 2 が、対称性を破る最初の候補です。 

## アプローチ

 ブルート フォース アプローチでは、各クエリ部分文字列のすべての部分文字列が検査されます。 それぞれの長さごとに$k$2 から部分文字列の長さまでのサイズのウィンドウをスライドさせます。$k$回文かどうかを確認します。 これは正しく動作しますが、検査が必要です$O(n^2)$クエリごとの部分文字列。 と$q$まで$2 \cdot 10^5$そして$n$まで$2 \cdot 10^5$、これはまったく不可能です。 

重要な洞察は、あらゆる長さのすべての部分文字列を検査する必要はないということです。 非回文であるためには、少なくとも 2 の長さの部分文字列には、異なる連続する文字のペアが 1 つだけ必要です。 部分文字列内のすべての隣接するペアが同一の場合、すべての部分文字列は回文になります。 それ以外の場合、部分文字列は、潜在的に完全な回文の場合を除き、2 からその長さまでのすべての長さで非回文になります。 したがって、問題を、部分文字列に連続する文字が異なる場所が少なくとも 1 か所含まれているかどうかを見つけることに帰着できます。 存在する場合、その部分文字列は直ちに 2-good となり、非回文ペアをいつでも拡張してより長い非回文部分文字列を形成できるため、拡張により、すべてのより大きな長さは自動的に良好になります。 

したがって、クエリごとに、部分文字列がすべて同一であるかどうかと、部分文字列の長さという 2 つの条件だけをチェックする必要があります。 すべてが同一であれば、答えはゼロになります。 それ以外の場合、答えは 2 から部分文字列の長さまでの整数の合計になります。 合計の計算には等差級数の公式を使用します$2 + 3 + \dots + L = \frac{L(L+1)}{2} - 1$、これはクエリごとの定数時間です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^2)$クエリごと |$O(1)$| 遅すぎる |
 | 最適 |$O(n+q)$テストケースごと |$O(1)$クエリごと | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 テスト ケースごとに、次の内容を読んでください。$n$そして$q$、その後に文字列が続きます。 
2. クエリごとに、部分文字列の境界を読み取ります。$l$そして$r$。 ゼロベースのインデックス付けに調整します。 
3. 部分文字列を抽出します。 部分文字列内のすべての文字が同一かどうかを確認します。 これは、各文字を最初の文字と比較するか、少なくとも 1 つの異なる隣接文字の存在を確認することによって効率的に行うことができます。 
4. すべての文字が同一の場合、0 を出力します。これは、すべての長さに対して完全に回文である部分文字列に対応します。 
5. それ以外の場合は、次の式を使用して、2 から部分文字列の長さまでのすべての長さの合計を計算します。$\frac{L(L+1)}{2} - 1$そしてそれを出力します。 

これが機能するのは、非回文にならない可能性がある唯一の部分文字列が完全に均一な部分文字列であるためです。 隣接する異なる文字が存在すると、長さ 2 の非回文部分文字列が保証され、これはいつでもより長い長さに拡張できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, q = map(int, input().split())
    s = input().strip()
    for _ in range(q):
        l, r = map(int, input().split())
        l -= 1
        r -= 1
        substring = s[l:r+1]
        # check if all characters are the same
        all_same = True
        for i in range(1, len(substring)):
            if substring[i] != substring[i-1]:
                all_same = False
                break
        if all_same:
            print(0)
        else:
            L = r - l + 1
            print(L * (L + 1) // 2 - 1)
```重要な選択は、多様性を検出するために部分文字列を 1 回だけ反復することと、明示的なループを避けるために算術合計の公式を使用することです。 Off-by-1 エラーは、インデックスをゼロベースに調整し、部分文字列の長さを慎重に計算することで回避されます。 

## 実用的な例

 ### 例 1

 入力部分文字列:`aaab`(クエリ 1、位置 1 ～ 4)

 | 私 | 部分文字列[i] | 部分文字列[i-1]と比較 | すべて同じ |

 | 1 | | | 本当 |
 | 2 | | | 本当 |
 | 3 | b | | 偽 |

 部分文字列には異なる文字が含まれているため、L = 4、sum = 4*5/2 - 1 = 9 となります。正解です。 

### 例 2

 入力部分文字列:`aaa`(クエリ 2、位置 1 ～ 3)

 | 私 | 部分文字列[i] | 部分文字列[i-1]と比較 | すべて同じ |

 | 1 | | | 本当 |
 | 2 | | | 本当 |

 すべての文字が同一 → 0 を出力します。 

これは、アルゴリズムが完全に回文的な部分文字列と非回文的な部分文字列を正しく区別していることを示しています。
