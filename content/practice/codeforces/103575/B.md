 ## 解決策

 アルファベットをこうしましょう${x_1 < x_2 < \cdots < x_t}$多重度あり$n_1,\ldots,n_t$そして$\sum_{i=1}^t n_i = n$。 アルゴリズム L は、この順序付けされたアルファベットに関して厳密な辞書編集順で順列を生成します。 順列のランク$a_1 \ldots a_n$したがって、 は、辞書編集的に小さい、個別のマルチセット順列の数です。 

プレフィックスを修正する$a_1 \ldots a_{i-1}$。 位置で$i$、残りの利用可能な多重度が次のようになると仮定します。$m_1,\ldots,m_t$合計で$m = n-i+1$。 シンボルの場合$x_k$の位置に置かれます$i$、完了数は多項係数です$$\frac{(m-1)!}{m_1!\cdots (m_k-1)!\cdots m_t!}.$$以上をまとめると$x_k < a_i$地位の貢献を与える$i$ランクに。 これはまさに、繰り返しシンボルに適用された標準の多項レーマー コードです。 

次に順列を考えてみましょう$$314159265.$$基礎となる順序付けされたシンボルは次のとおりです。$$1 < 2 < 3 < 4 < 5 < 6 < 9,$$多重度あり$$n_1 = 2,\quad n_5 = 2,\quad n_2 = n_3 = n_4 = n_6 = n_9 = 1.$$ランクは段階的に計算されます。 

で$a_1 = 3$、より小さい記号$3$は$1$そして$2$。 

もし$1$が最初に配置され、残りの多重度がカウントを与えます$$\frac{8!}{2!\,1!\,1!\,2!\,1!\,1!} = \frac{40320}{2} = 20160.$$もし$2$が最初に配置されると、同じ分母が発生し、別の分母が得られます。$20160$。 したがって、最初の位置が貢献します$40320$。 

固定後$3$、残りのマルチセットは$$\{1^2,2,4,5^2,6,9\}.$$で$a_2 = 1$より小さい記号はありません$1$、つまり貢献度は$0$。 

で$a_3 = 4$、残りのシンボルは以下より小さい$4$は$1$そして$2$。 

もし$1$が配置され、残りのマルチセットにはサイズがあります$6$複製されたものだけを使用して$5$、与える$$\frac{6!}{2!} = 360.$$もし$2$が配置されると、同じ値が発生するため、貢献度は$720$。 

で$a_4 = 1$、寄与分は発生しません。 

加工後$a_5 = 5$、残りのマルチセットは${2,6,9}$追加の1つと一緒に$5$すでに考慮されており、シンボルよりも小さい$5$は$1$そして$2$。 

もし$1$が配置され、残りの 3 つのシンボルは区別され、貢献します。$3! = 6$。 

もし$2$が置かれると同じ値が発生し、貢献が得られます$12$、したがって合計$48$。 

で$a_6 = 9$、より小さい記号$9$残りのマルチセットの中で${2,5,6,9}$は$2$、$5$、 そして$6$。 

それぞれの選択により 3 つの異なるシンボルが残り、貢献します。$3! = 6$、したがって合計$18$。 

で$a_7 = 2$、これより小さい使用可能なシンボルは寄与しません。 

で$a_8 = 6$、使用可能な唯一の小さいシンボルは$5$、そしてそれを配置すると単一の補完が残り、貢献します$1$。 

で$a_9 = 5$、それ以上の貢献は発生しません。 

すべての貢献を合計すると、$$40320 + 720 + 48 + 18 + 1 = 41107.$$のランク$314159265$したがって、アルゴリズム L の下では、$$\boxed{41107}.$$
