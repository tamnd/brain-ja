 ## 解決策
 ## 問題の理解

 2 つの文字列が与えられています。`s`長さの`n`そして`t`長さの`m`、そして、次の部分列を見つける必要があります。`s`それは正確に一致します`t`。 このサブシーケンスは、各文字が`t`に順番に登場します`s`。 課題は、単にサブシーケンスを見つけることではなく、連続するインデックス間の最大ギャップが最大化されているサブシーケンスを選択することです。 そのギャップはシーケンスの_width_として定義されます。 

入力では、そのようなサブシーケンスが少なくとも 1 つ存在することが保証されるため、空の場合を処理する必要はありません。 出力は単一の整数で、考えられるすべての美しいシーケンスの中で最大幅です。 

制約は重要です。 両方`n`そして`m`最大 200,000 までになる可能性があります。 ポジションのすべての組み合わせを試す単純なアプローチでは、およそ次のような複雑さになります。$O(\binom{n}{m})$、これは天文学的に大きく、実行不可能です。 これは、線形時間または線形算術時間に近い解が必要であることを示しています。$O(n \log n)$。 エッジケースには、すべての文字が同じであるシーケンスが含まれます。`t`～の最初と最後に起こる`s`、またはいつ`t`とほぼ同じです`s`。 たとえば、不注意な解決策では、常に最初に出現する各文字が選択される可能性があります。`t`後の位置では広いスペースを逃してしまいます。 

## アプローチ

 ブルートフォースアプローチでは、インデックスのすべてのシーケンスが列挙されます。`s`その一致`t`。 シーケンスごとに幅を計算し、最大値を追跡します。 これは原理的には正しいですが、その複雑さは大まかに言うと組み合わせによるものです。$O(n^m)$、これは明らかに不可能です`n = 2 \cdot 10^5`そして`m = 10^5`。 

重要な洞察は、最大幅は 2 つのシーケンスのみを考慮することによって決定できるということです。1 つは、各文字の _左端_ の出現を貪欲に選択する場合です。`t`もう 1 つは、_右端_ のオカレンスを選択した場合です。 させて`left[i]`内の最も古いインデックスを示します`s`それは一致することができます`t[i]`秩序を保ちながら、`right[i]`の最新のインデックスを示します`s`それは一致することができます`t[i]`。 最大幅は常に 1 つの値の間に発生します。`left[i]`そして対応する`right[i+1]`これは有効なシーケンスを形成しながら最大のギャップを与えるためです。 これにより、問題はこれら 2 つのアレイにわたる線形スキャンに帰着します。これは次の場合に実行可能です。$O(n)$時間。

 ## アルゴリズムのチュートリアル

 1. 2 つの配列を初期化します。`left`そして`right`、両方の長さ`m`。`left[i]`最も古いインデックスを保存します`s`それは一致します`t[i]`順番に、そして`right[i]`一致する最新のインデックスを保存します`t[i]`逆の順序で。 
2. 埋める`left`繰り返して`s`左から右へ。 ポインタを維持する`j`の中へ`t`。 いつ`s[i] == t[j]`、割り当てます`left[j] = i`そして増加します`j`。 反復の後、`left`美しいシーケンスを形成する最も古いインデックスが含まれています。 
3. 埋める`right`繰り返して`s`右から左へ。 ポインタを維持する`j`から始まる`m-1`そして後退する。 いつ`s[i] == t[j]`、割り当てます`right[j] = i`そして減少します`j`。 反復の後、`right`美しいシーケンスを形成する最新のインデックスが含まれています。 
4. 反復して最大幅を計算します。`i`から`0`に`m-2`。 それぞれについて`i`、計算します`right[i+1] - left[i]`そして最大値を追跡します。 

これが機能する理由は、最大のギャップは、可能な限り最も早く発生したいくつかの組み合わせによって常に実現されるためです。`t[i]`最近発生する可能性のある`t[i+1]`。 他の組み合わせはギャップを減らすか、順序制約に違反します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
s = input().strip()
t = input().strip()

left = [0] * m
right = [0] * m

# Compute left array
j = 0
for i in range(n):
    if s[i] == t[j]:
        left[j] = i
        j += 1
        if j == m:
            break

# Compute right array
j = m - 1
for i in range(n-1, -1, -1):
    if s[i] == t[j]:
        right[j] = i
        j -= 1
        if j < 0:
            break

# Find maximum width
max_width = 0
for i in range(m - 1):
    max_width = max(max_width, right[i+1] - left[i])

print(max_width)
```左側の配列には可能な限り最も早い位置が格納され、シーケンスが有効であることが保証されます。 適切な配列には最新の可能な位置が保存され、ギャップが最大化されます。 最大幅を計算するループでは、連続するペアのみが慎重に考慮されます。`left[i]`そして`right[i+1]`の順序を尊重します。`t`。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    s = input().strip()
    t = input().strip()
    
    left = [0] * m
    right = [0] * m
    
    j = 0
    for i in range(n):
        if s[i] == t[j]:
            left[j] = i
            j += 1
            if j == m:
                break
    
    j = m - 1
    for i in range(n-1, -1, -1):
        if s[i] == t[j]:
            right[j] = i
            j -= 1
            if j < 0:
                break
    
    max_width = 0
    for i in range(m-1):
        max_width = max(max_width, right[i+1] - left[i])
    
    return str(max_width)

# provided samples
assert run("5 3\nabbbc\nabc\n") == "3", "sample 1"
assert run("2 1\naa\na\n") == "1", "sample 2"

# custom cases
assert run("7 2\nabacaba\naa\n") == "6", "widest possible gap"
assert run("5 2\naaaaa\naa\n") == "4", "all same letters"
assert run("10 5\nabcdefghij\nacegi\n") == "2", "maximum width in spaced letters"
assert run("2 2\nab\nab\n") == "1", "minimum size input"

 ## 特殊なケース

 すべての文字が同一である文字列の場合、次のようになります。`s = "aaaaa"`そして`t = "aa"`、左の配列が最初の 2 つの位置を取得します。`left = [0, 1]`、右の配列が最後の 2 つの位置を取得します。`right = [3, 4]`。 最大幅の計算では次のことを考慮します。`right[1]-left[0] = 4-0 = 4`、最適な美しいシーケンスを正確に識別します。
