 ## 解決策
 ## 問題の理解

 私たちに与えられたデッキは、`n`1 から 1 までの番号が付けられた個別のカード`n`、下から上に配置されます。 タスクは、可能な限り最高の「順序」を持つ新しいデッキを構築することです。この順序は、カードの価値の加重合計として計算され、上位のカードがより多く貢献します。 許可される唯一の操作は、元のデッキの一番上から一定枚数のカードを繰り返し取り出し、それらを新しいデッキの一番上に置くことです。 私たちの目標は、デッキの順序を最大化する一連の操作を見つけることです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースはデッキのサイズを提供します`n`カードの値は下から上に表示されます。 出力は、最大の順序を生成する、新しく形成されたデッキの下から上へのカードのシーケンスです。 

制約により許可されるのは、`n`まで`10^5`テストケースごととすべての合計`n`テストケース全体で最大`10^5`。 1 秒の時間制限では、テスト ケースごとに O(n) を超える複雑さのアルゴリズムは遅すぎる危険性があります。 したがって、すべての可能なサブデックを繰り返し反復する解決策は非現実的です。 

最大のカードがすでに底部近くにある場合、微妙なエッジケースが発生します。 一度に常に 1 枚のカードだけを取得するという単純な戦略も機能しますが、並べ替えのためのより大きな機会を逃す可能性があります。 たとえば、デッキ内で`[1, 5, 2, 4, 3]`, カードを 1 枚ずつ移動すると、一番上の`5`が遅れる可能性があり、デッキの順序が減ります。 正しいアプローチでは、現在残っている最大のカードを含む、上から最大の連続するカードのブロックを特定し、それが新しいデッキの最初に配置されるようにする必要があります。 

## アプローチ

 ブルートフォース手法では、可能なすべての一連の動きを試行します。`k`、結果として得られる新しいデッキを再帰的に計算し、最大の次数を選択します。 シーケンスの数は指数関数的に増加するため、これは明らかに実行不可能です。`n`。 毎回一番上のカードを移動させるという欲張ったアプローチを試みたとしても、残っている最大のカードが元のデッキの一番上にない場合は失敗します。 

重要な洞察は、残っている最大のカードが新しいデッキのできるだけ上位に表示されるときに順序が最大になるということです。 したがって、元のデッキの一番上からスキャンして、次に大きい未使用のカードを常に探します。 それを見つけたら、その上にあるすべてのカード (それ自体を含む) を取り出し、新しいデッキに順番に置きます。 これにより、最大の値が最初に配置され、連続する小さな値が元の相対順序のままになり、可能な限り最大の加重合計が維持されます。

 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適な貪欲さ | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 テスト ケースごとに、次の内容を読んでください。`n`そしてデッキを下から上へ。 操作は上から定義されるため、デッキを反転して上から下に作業します。 
2. 空のリストを初期化する`result`新しいデッキとポインター用`i`元のデッキの一番上から始めます。 
3. その間`i`デッキの範囲内にあります:

 ａ． 位置を見つける`j`残りの最大のカードから始まる`i`デッキの端まで。 

b. から連続したセグメントを取得します`i`に`j`(包括的) それを新しいデッキに順番に追加します。 

c. 動く`i`に`j + 1`。 
4. すべてのカードが処理されたら、リバースします。`result`出力は下から上の順序に戻ります。 

機能する理由: すべてのステップで、残っている最大のカードができるだけ早く新しいデッキに移動されるようにします。 現在の一番上からこのカードまでの連続セグメントを取得することにより、小さいカードの相対的な順序が維持されます。 この貪欲な選択により、最終的な加重合計に対する最大値の寄与が最大化され、配置されていない最大のカードが常に最初に配置されるという不変条件により、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        deck = list(map(int, input().split()))
        deck.reverse()  # work from top to bottom
        result = []
        i = 0
        while i < n:
            # find the next largest remaining card
            max_card = max(deck[i:])
            j = i
            while deck[j] != max_card:
                j += 1
            # append all cards from i to j to result
            result.extend(deck[i:j+1])
            i = j + 1
        # convert back to bottom-to-top
        print(' '.join(map(str, result[::-1])))

if __name__ == "__main__":
    solve()
```コードは、上から下の操作を簡素化するために入力デッキを反転することから始まります。 内側のループは残っている最大のカードを見つけ、現在のインデックスからこのカードまでのセグメントが新しいデッキに順番に移動されます。 最後に結果を反転すると、正しい下から上の順序が復元されます。 1 枚のカードやすでに降下しているデッキなどの特殊なケースは、この手順で自然に処理されます。
