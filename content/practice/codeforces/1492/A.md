 ## 解決策
 ## 問題の理解

 3 人の水泳選手が、それぞれ一定の周期でプールを泳いで戻ってくることを繰り返しています。 最初に泳ぐ人は`a`往復にかかる時間は 2 分、2 分目は`b`分、そして3番目`c`分。 プールに到着します`p`スタートから数分後、目標は、少なくとも 1 人の水泳選手が再びプールの左側に到達するまで何分待たなければならないかを決定することです。 

入力により、複数の独立したテスト ケースが得られます。 それぞれに 4 つの整数が与えられます`p`、`a`、`b`、 そして`c`。 これらの値はそれぞれ 10^18 まで大きくなる可能性があり、各水泳者の戻り時間を反復する総当りシミュレーションは実行不可能であることを意味します。 これらの大きな数値を直接処理する方法が必要です。 

明らかではないエッジケースは、水泳選手が左側にいるのとまったく同じ瞬間に到着した場合、または待機時間が水泳選手の時間よりも長い場合に発生します。 たとえば、次の場合`p = 10`そして`a = 2, b = 5, c = 10`、ちょうど 3 人目の選手がいるときに到着するので、待ち時間は`0`。 等価性を考慮せずに将来の倍数のみをチェックする不用意なソリューションでは、肯定的な待機が誤って報告されてしまいます。 

## アプローチ

 強引なアプローチでは、各水泳選手の現時点までのすべての復帰時間を生成することになります。`p`それ以降、前方にスキャンして、最初以上の時間を見つけます。`p`。 これは原理的には正しいですが、すぐに実用的ではなくなります。`p`10^18 とピリオドを指定できます`a, b, c`非常に大きくなる場合もあります。 数百万または数十億のステップを繰り返すのは遅すぎます。 

重要な観察は、各水泳選手の復帰タイムがゼロから始まり、その周期に等しいステップを持つ等差数列を形成していることです。 少なくとも次の戻り時間を見つけるには`p`、反復する代わりに数学的に計算できます。 生理のある水泳選手へ`x`、次の返却時間`p`の最小倍数です`x`以上`p`。 もし`p`で割り切れます`x`、次のリターンは`p`自体。 それ以外の場合は、`(p // x + 1) * x`。 各水泳選手の次の戻り時間がわかったら、待ち時間は最小限になります。`(next_return_time - p)`3人の水泳選手全員にわたって。 

これにより、問題は潜在的に膨大なシーケンスを反復処理することから、水泳者ごとの定数時間の算術計算に軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(p / 分(a, b, c)) | お(1) | 遅すぎる |
 | 算術計算 | テスト ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、整数を読み取ります。`p`、`a`、`b`、 そして`c`。 
3. 水泳期間ごとに`x`で`[a, b, c]`、次にスイマーが左側にいる時刻を計算します。`p`。 もし`p`で割り切れます`x`、次回は`p`。 それ以外の場合は計算します`next_time = ((p // x) + 1) * x`。 
4. 各水泳者の待ち時間を次のように計算します。`next_time - p`。 
5. テスト ケースの答えは、3 人の水泳選手の最小待機時間です。 
6. 各テスト ケースの結果を出力します。 

機能する理由: 算術演算により、各水泳選手の周期の最小値以上の最初の倍数が見つかることが保証されます。`p`。 引き算`p`正確な待ち時間がわかります。 すべての水泳選手の最小値を取ることで、最も早く到着する選手を確実に見つけることができます。 10^18 までの整数の算術演算がサポートされているため、近似は必要ありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def next_arrival(p, x):
    if p % x == 0:
        return p
    return ((p // x) + 1) * x

t = int(input())
for _ in range(t):
    p, a, b, c = map(int, input().split())
    wait_times = [next_arrival(p, a) - p,
                  next_arrival(p, b) - p,
                  next_arrival(p, c) - p]
    print(min(wait_times))
```機能`next_arrival`次の倍数の計算をきれいに処理し、次の場合の off-by-one エラーを回避します。`p`水泳選手の周期で正確に割り切れます。 メインループは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`すべての計算を整数演算で実行し、非常に大きな値の正確性を保証します。

 ## 特殊なケース

 水泳選手が左側にいるときにちょうど到着した場合、`p % x == 0`待ち時間がゼロになるようにします。 たとえば、入力の場合`p=10`そして`a=2`、`b=5`、`c=10`、3 番目の水泳選手の計算は次のようになります。`next_time = 10`、 そして`next_time - p = 0`。 すべてのスイマーの最小値が正しく出力される`0`。 

すべての期間が より大きい場合`p`、 のような`p=5`そして`a=b=c=10`、計算により次の結果が得られます`next_time = 10`待ち時間は`5`、最初の泳者が戻るまで待たなければならないことを正しく反映しています。 

この方法は、水泳選手の期間に対する到着時間のすべての組み合わせを一貫して処理します。
