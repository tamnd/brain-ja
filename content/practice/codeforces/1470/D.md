 ## 解決策
 ## 問題の理解

 頂点が家を表し、エッジが地下通路を表す無向グラフが与えられます。 教師を配置する頂点のサブセットを選択する必要があります。 

選択が完了すると、端点が両方とも選択されていないすべてのエッジが削除されます。 1 つおきのエッジは残ります。 したがって、少なくとも 1 つのエンドポイントが教師をホストしていれば、エッジは存続します。 

この枝刈りの後、残りのグラフでは、生き残ったエッジのみを使用して頂点のすべてのペア間の移動を許可する必要があります。 さらに、選択した 2 つの頂点をエッジで接続することはできません。これは、選択した頂点が独立したセットを形成することを意味します。 

したがって、タスクは、独立したセットであるが、選択されていないセット内のすべてのエッジを削除してもグラフが切断されないという意味で、グラフを「カバー」している頂点のセットを見つけることです。 

条件を解釈する別の方法は、頂点を教師と非教師の 2 つのグループに分割することです。 教師を隣接させることはできないため、教師セットは独立しています。 すべてのエッジには、教師セット内に少なくとも 1 つのエンドポイントがなければなりません。そうでないと、エンドポイントが消えてしまいます。 残りのグラフは接続されたままにする必要があります。 

これにより、疎性と接続性の間に緊張が生じます。接続構造を維持するのに十分な強度を持つ一種の頂点カバーでもある独立したセットが必要です。 

制約は大きく、すべてのテスト ケースにわたって最大 3⋅10^5 の頂点とエッジです。 これにより、二次構築や頂点ごとのグローバル検索の繰り返しが排除されます。 基本的にテスト ケースごとに線形または線形演算が必要であり、おそらくグラフの走査または貪欲な色付けが必要です。 

グラフが 2 部構成でない場合、微妙な問題が発生します。 二分化を試みると、奇妙なサイクルが矛盾を強いる衝突が生じます。 もう 1 つの失敗ケースは、孤立した頂点またはコンポーネントが一貫して処理されない場合です。特に、グラフに複数のコンポーネントがあるが、接続要件が元のグラフではなく、削除後の残りのグラフに適用される場合です。 

単純なアプローチでは、すべてのサブセットを試すか、構造ガイドなしで貪欲に頂点を選択しようとします。 独立性とグローバル接続が非ローカルな方法で相互作用するため、これはすぐに失敗します。 

## アプローチ

 直接的な総当たり戦略では、頂点の各サブセットを潜在的な教師配置として考慮し、両方の条件を検証します。選択された 2 つの頂点がエッジを共有しておらず、選択されていないセット内のエッジを削除した後の結果のグラフは接続されたままです。 このようなサブセットは 2^n 個あり、1 つをチェックするだけでもグラフの走査が必要となり、指数関数的な時間が発生します。これは n = 20 の場合でも不可能です。 

重要な観察は、エッジ除去後の接続性に関する条件が二部構造に強く結びついているということです。 グラフを 2 色にすると、すべてのエッジが反対の色に接続されます。 1 つの色のクラスを教師として選択した場合、2 人の教師が自動的に隣接することはありません。 さらに、すべてのエッジには選択したセット内の端点が 1 つだけあるため、エッジがまったく消えることはありません。つまり、グラフは完全にそのまま残り、以前とまったく同じように接続されます。 

これにより、すぐに十分条件が得られます。グラフが 2 部構成の場合、2 つのカラー クラスのいずれかを選択できます。 

残りの問題は、解決策が存在するために二者構成も必要かどうかです。 奇数のサイクルがある場合、有効な教師セットは接続性を維持しながら、すべてのエッジの両方の端点を選択されていないセット内に配置することを回避する必要があり、これにより 2 色塗りと同等の矛盾が生じます。 実際、有効な構築が二分割を引き起こすことを示すことができます。これは、隣接する 2 つの頂点が両方とも選択されていない場合、それらのエッジが削除され、削除を繰り返すと、独立性を侵害することなく修復できない形で接続が切断される可能性があるためです。

したがって、問題は接続コンポーネントごとに二部性をチェックし、カラーリングの片側を選択することに帰着します。 コンポーネントが 2 部構成でない場合、有効な選択は存在しません。 

どのカラー クラスを出力するかを自由に選択できます。 どちら側でも機能しますが、サイズを最大化するために大きい方を選択します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース サブセット | O(2^n · n) | O(n) | 遅すぎる |
 | BFS/DFS 2 部カラーリング | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力エッジからグラフの隣接リストを作成します。 この表現により、線形時間トラバースが可能になります。 
2. 配列を初期化する`color`すべての頂点が -1 で、未訪問を意味します。 
3. 1 から n までの各頂点について、色付けされていない場合は、そこから BFS (または DFS) を開始し、カラー 0 を割り当てます。 
4. 走査中、すべてのエッジ (u、v) に対して、色が付いていなければ v に u の反対の色を割り当てます。 v がすでに色付けされており、u と同じ色である場合、グラフは 2 部構成ではないため、有効な解は存在しないとすぐに結論付けられます。 
5. 各接続コンポーネントから 1 つのカラー クラスのすべての頂点を収集します。 各コンポーネントは独立して 2 部構成であるため、コンポーネントごとにどちらかの側を自由に選択できます。 
6. 各コンポーネントについて、カラー 0 とカラー 1 の頂点の数を比較し、答えのサイズを最大化するために大きい方の側を選択します。 
7. 「YES」に続いて、選択した頂点の数とそれらの頂点のリストを出力します。 

これが機能する重要な理由は、各接続コンポーネント内で、単一の色を選択した場合、二重パーティションによって選択した頂点間に内部エッジがないことが保証され、すべてのエッジが常にパーティションを越えて接続されるため、接続性が維持されるためです。 

### なぜ効果があるのか

 BFS カラーリングでは、すべてのエッジがそれらの間で交差するように、各接続コンポーネントを 2 つのセットに分割します。 有効なソリューションでは、エッジの両方の端点の選択を回避する必要があります。これにより、選択されたセットが独立することになります。 隣接関係の制約を破ることなく最大限の柔軟性を確保する唯一の方法は、2 つのパーティションを調整することです。 奇数のサイクルが存在する場合、一貫した 2 色の割り当ては存在せず、教師を選択しようとする試みは必然的に独立性、またはエッジの削除によるグラフの切断を防ぐ構造要件のいずれかに違反することになります。 

したがって、二者構成であることが実現可能性にとって必要かつ十分である。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        g = [[] for _ in range(n + 1)]
        for _ in range(m):
            u, v = map(int, input().split())
            g[u].append(v)
            g[v].append(u)

        color = [-1] * (n + 1)
        ok = True
        ans = []

        for i in range(1, n + 1):
            if color[i] != -1:
                continue
            q = deque([i])
            color[i] = 0
            comp = [[], []]

            while q:
                u = q.popleft()
                comp[color[u]].append(u)
                for v in g[u]:
                    if color[v] == -1:
                        color[v] = color[u] ^ 1
                        q.append(v)
                    elif color[v] == color[u]:
                        ok = False

            if not ok:
                break

            if len(comp[0]) >= len(comp[1]):
                ans.extend(comp[0])
            else:
                ans.extend(comp[1])

        if not ok:
            print("NO")
        else:
            print("YES")
            print(len(ans))
            print(*ans)

if __name__ == "__main__":
    solve()
```実装は、コンポーネントごとの標準的な BFS 2 部カラーリングに従います。 隣接リストはテスト ケースごとに 1 回作成されます。 の`color`配列はコンポーネント間で保持されます。これは、テスト内のコンポーネント間で配列をリセットする必要がないため重要です。 

微妙な点は、BFS 中に二部性をローカルでのみチェックすることです。 競合が見つかった場合は、早期に停止します。 もう 1 つの詳細は、コンポーネントごとに頂点を収集することです。`comp[0]`そして`comp[1]`これにより、コンポーネント全体を調べた後で最適な選択が可能になります。 

また、最初はグラフが接続されていない可能性があるため、接続されていないコンポーネントがすべて処理されるように注意深く確認します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque

    def solve():
        t = int(input())
        out = []
        for _ in range(t):
            n, m = map(int, input().split())
            g = [[] for _ in range(n + 1)]
            for _ in range(m):
                u, v = map(int, input().split())
                g[u].append(v)
                g[v].append(u)

            color = [-1] * (n + 1)
            ok = True
            ans = []

            for i in range(1, n + 1):
                if color[i] != -1:
                    continue
                q = deque([i])
                color[i] = 0
                comp = [[], []]

                while q:
                    u = q.popleft()
                    comp[color[u]].append(u)
                    for v in g[u]:
                        if color[v] == -1:
                            color[v] = color[u] ^ 1
                            q.append(v)
                        elif color[v] == color[u]:
                            ok = False

                if not ok:
                    break

                if len(comp[0]) >= len(comp[1]):
                    ans.extend(comp[0])
                else:
                    ans.extend(comp[1])

            if not ok:
                out.append("NO")
            else:
                out.append("YES")
                out.append(str(len(ans)))
                out.append(" ".join(map(str, ans)))

        return "\n".join(out)

    return solve()

 ## 特殊なケース

 クリティカルなエッジ ケースは、奇数サイクルを含むグラフです。 エッジ (1,2)、(2,3)、(3,1) を持つ三角形を考えます。 BFS は交互の色を割り当てようとしますが、最終的には異なるパスを通じてノード 1 にカラー 0 とカラー 1 の両方を強制的に割り当てます。 アルゴリズムは、同じ色ですでに色付けされている近隣を訪問するときにこの競合を検出し、正しく NO を出力します。 

もう 1 つのエッジ ケースは、頂点が孤立した接続されていないグラフです。 孤立した各頂点は、制約のないサイズ 1 のコンポーネントを形成します。 BFS はそれにカラー 0 を割り当て、応答に含めます。これは、隣接関係の制約に違反していないため有効です。 

最後の微妙なケースは、それぞれが 2 部構成であるが、一貫性のない側を選択すると、回答サイズが小さくなる可能性がある複数のコンポーネントです。 アルゴリズムは、コンポーネントごとに大きいカラー クラスを個別に選択することでこれを処理し、有効性に影響を与えることなく最大限の構築を保証します。
