 ## 解決策
 ## 問題の理解

 整数の配列が与えられます。 次の場合に 2 つの値を隣接するものとして定義します。$$\frac{\operatorname{lcm}(x,y)}{\gcd(x,y)}$$は完全な正方形です。 

配列の各要素は、毎秒、現在隣接しているすべての要素の積で置き換えられます。 私たちが気にする量は配列の美しさであり、すべての位置の中で最大の隣接数です。 

各クエリ値について$w$、私たちは正確にその後の美しさを報告しなければなりません$w$秒。 

最初の課題は、隣接性を理解することです。 2 番目の課題は、繰り返される変換が配列にどのような影響を与えるかを理解することです。 クエリでは、最大で任意の長い時間がかかります。$10^{18}$, したがって、直接シミュレーションは不可能です。 

すべてのテスト ケースにわたる配列要素の合計数は最大で$3 \cdot 10^5$、クエリの合計数にも同じ限界が当てはまります。 これにより、二次関数は即座に除外されます。$n$。 アン$O(n^2)$隣接グラフには大まかに必要になります$9 \cdot 10^{10}$最悪の場合の比較。 線形に近いものが必要です。$O(n \log n)$テストケースごとに。 

値自体は最大でも$10^6$。 これは、ふるいを使用してすべての数値の素因数を前処理するのに十分な大きさです。 

よくある間違いは、正方形のないカーネルではなく、元の数値を使用して作業することです。 

考慮する：```
1
3
12 3 48
1
0
```両方$12$そして$48$に減らす$3$すべての二乗素因数を削除した後:$$12 = 2^2 \cdot 3 \rightarrow 3$$

$$48 = 2^4 \cdot 3 \rightarrow 3$$3 つの値はすべて同じ隣接クラスに属しているため、答えは 3 です。元の数値を別のものとして扱うと、誤って小さなグループが生成されます。 

もう 1 つの微妙なケースは、値 1 です。```
1
4

```すべての数値は、正方形のないカーネル 1 に減ります。最初の最大グループ サイズは 4 です。安定化後は 4 のままです。完全な正方形がカーネル 1 に崩壊することを忘れると、間違った答えが生成されます。 

最も重要なエッジケースは大規模なものに関するものです$w$。```
1

100
```の答えは、$w=0$の答えとは異なります$w>0$。 プロセスは 1 回の変換後に安定するため、すべての肯定的な時間は同じ答えを共有します。 時間をシミュレーションすると、この構造の単純化が失われます。 

## アプローチ

 ブルート フォース ソリューションでは、最初に隣接グラフを構築します。 すべてのペアについて$(i,j)$かどうかを計算します。$$\frac{\operatorname{lcm}(a_i,a_j)}{\gcd(a_i,a_j)}$$は完全な正方形です。 

これには必要です$O(n^2)$ペアチェック。 たとえ各チェックが一定時間だったとしても、$n=3\cdot10^5$これは完全に不可能になります。 

重要な観察は素因数分解から得られます。 

させて$$x=\prod p_i^{\alpha_i}, \qquad y=\prod p_i^{\beta_i}.$$以来$$\frac{\operatorname{lcm}(x,y)}{\gcd(x,y)} = \prod p_i^{|\alpha_i-\beta_i|},$$すべての指数の差が偶数である場合、結果は完全二乗になります。 

つまり、$$\alpha_i \equiv \beta_i \pmod 2$$すべての素数に対して。 

指数パリティのみが重要です。 

各数値について、指数が奇数である素数を正確に保持します。 彼らの製品はスクエアフリーカーネルと呼ばれています。 

例:$$12 = 2^2\cdot3 \rightarrow 3$$

$$18 = 2\cdot3^2 \rightarrow 2$$

$$72 = 2^3\cdot3^2 \rightarrow 2$$2 つの数値は、同じ正方形のないカーネルを持っている場合にのみ隣接します。 

これは、問題をカーネルの頻度のカウントに変換します。 

残りの問題は、アレイの繰り返しの進化です。 

カーネル クラスに次のものが含まれているとします。$k$要素。 そのクラス内のすべての要素は、まったく同じ値のセット、つまりクラスのすべてのメンバーを乗算します。 したがって、1 秒後には、クラスのすべての要素が同一になります。 

より詳細な分析により、1 つのステップの後、カーネルが 1 であるか、サイズが偶数であるすべてのクラスがカーネル 1 に崩壊することが示されています。奇数サイズのクラスとカーネルが 1 つではないクラスは区別されたままです。 

これは、公式ソリューションで使用される中心的な観察です。 

させて：

-`mx0`すべてのカーネルの中で最大の周波数になります。 
-`mx1`次の合計頻度になります。 

- カーネル 1、
 - 周波数が偶数である非 1 つのカーネル。 

その後、残りの奇数周波数の非 1 カーネルはすべて分離されたままになります。 

肯定的な時間の場合、答えは次のようになります。$$\max(mx1,\text{largest odd-frequency non-one class}).$$この値は伝統的に次のように呼ばれています。`mx_inf`。 

プロセスはすぐに安定するため、次のようになります。 

-$w=0$用途`mx0`。 
-$w>0$用途`mx_inf`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^2)$|$O(n^2)$| 遅すぎる |
 | 最適 |$O(n \log \log M + n)$ふるい前処理後 |$O(n)$| 承認済み |

 ここ$M=10^6$。 

## アルゴリズムのチュートリアル

 ### 前処理

 までのすべての整数の最小の素因数を計算します。$10^6$。 これにより、各配列値をすばやく因数分解できます。 

### テストケースごと

 1. すべての配列値について、その平方フリー カーネルを計算します。 

数値を因数分解し、指数が奇数の素数だけを保持します。 
2. すべてのカーネルの頻度をカウントします。 

させて`cnt[k]`カーネルの出現数になります`k`。 
3. コンピューティング`mx0`。 

これは単にすべてのカーネルの最大周波数です。 
4. 安定化された大きなグループを計算します。 

初期化する$$\text{good}=0.$$すべてのカーネルと周波数のペアについて:

 - カーネルが 1 の場合、その周波数を`good`。 
- それ以外の場合、周波数が偶数の場合は、その周波数を`good`。 

これらのグループは、1 ステップ後に kernel-1 コンポーネントにマージされます。 
5. 残りの最大の奇数周波数の非 1 クラスを計算します。 

させて$$\text{oddmax}$$周波数が奇数の 1 とは異なるカーネル間の最大周波数になります。 
6. 定義する$$mx\_inf=\max(\text{good},\text{oddmax}).$$これがあらゆるポジティブな時の答えです。 
7. 各クエリについて:

 - もし$w=0$、印刷`mx0`。 
- それ以外の場合は印刷します`mx_inf`。 

### なぜ効果があるのか

 隣接性は、素因数分解における指数パリティのみに依存します。 各数値を正方形のないカーネルで置き換えると、すべての隣接関係が維持されます。 

同じカーネルを持つすべての番号は完全なコンポーネントを形成し、異なるカーネルを持つ番号が隣接することはありません。 1 回の変換の後、コンポーネント内のすべての要素はまったく同じ値のセットを乗算するため、同一になります。 

均一なサイズのコンポーネントは完全二乗係数の寄与を生成し、カーネル 1 に集約されます。すでにカーネル 1 を持つコンポーネントもそこに属します。 奇数サイズの非 1 コンポーネントはカーネルを保持します。 この最初の変換後、パーティションは変更されなくなるため、プロセスは永久に安定します。 

したがって、時間 0 の美しさは元の最大のコンポーネント サイズですが、正の時間ごとの美しさは、この安定化後の最大のコンポーネント サイズになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXA = 10 ** 6

spf = list(range(MAXA + 1))
for i in range(2, int(MAXA ** 0.5) + 1):
    if spf[i] == i:
        for j in range(i * i, MAXA + 1, i):
            if spf[j] == j:
                spf[j] = i

def kernel(x):
    res = 1
    while x > 1:
        p = spf[x]
        cnt = 0
        while x % p == 0:
            x //= p
            cnt ^= 1
        if cnt:
            res *= p
    return res

t = int(input())

for _ in range(t):
    n = int(input())
    arr = list(map(int, input().split()))

    freq = {}

    for x in arr:
        k = kernel(x)
        freq[k] = freq.get(k, 0) + 1

    mx0 = max(freq.values())

    good = 0
    oddmax = 0

    for k, c in freq.items():
        if k == 1 or c % 2 == 0:
            good += c
        else:
            oddmax = max(oddmax, c)

    mx_inf = max(good, oddmax)

    q = int(input())

    for _ in range(q):
        w = int(input())
        if w == 0:
            print(mx0)
        else:
            print(mx_inf)
```ふるいは、すべての数値の最小の素因数を 1 回計算します。 すべての値が最大であるため、$10^6$、この前処理コストはすべてのテスト ケースで共有されます。 

の`kernel`関数は平方素数の寄与を削除します。 完全な指数を保存する代わりに、パリティを追跡します。 素数が奇数回出現するたびに、その素数はカーネルに寄与します。 

周波数マップは、隣接グラフ内の連結成分を表します。 同じカーネルを持つすべての番号は同じコンポーネントに属します。`mx0`元の配列を返します。 変数`good`そして`oddmax`安定した状態をエンコードします。 カーネル 1、偶数サイズのグループ、および奇数サイズの非 1 グループ間の区別は、上で証明された特性とまったく同じです。 

プロセスは 1 つのステップで安定するため、クエリの処理は非常に簡単です。 すべてのクエリ$w>0$同じ答えが返ってきます。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def run(inp: str) -> str:
    from collections import defaultdict

    data = io.StringIO(inp)
    input = data.readline

    MAXA = 10**6

    spf = list(range(MAXA + 1))
    for i in range(2, int(MAXA ** 0.5) + 1):
        if spf[i] == i:
            for j in range(i * i, MAXA + 1, i):
                if spf[j] == j:
                    spf[j] = i

    def kernel(x):
        r = 1
        while x > 1:
            p = spf[x]
            parity = 0
            while x % p == 0:
                x //= p
                parity ^= 1
            if parity:
                r *= p
        return r

    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        arr = list(map(int, input().split()))

        freq = defaultdict(int)
        for x in arr:
            freq[kernel(x)] += 1

        mx0 = max(freq.values())

        good = 0
        oddmax = 0

        for k, c in freq.items():
            if k == 1 or c % 2 == 0:
                good += c
            else:
                oddmax = max(oddmax, c)

        mx_inf = max(good, oddmax)

        q = int(input())
        for _ in range(q):
            w = int(input())
            out.append(str(mx0 if w == 0 else mx_inf))

    return "\n".join(out) + "\n"
