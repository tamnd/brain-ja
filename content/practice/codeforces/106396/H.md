 ## 解決策
 ## 問題の理解

 この問題では、指定された開始ノードを持つ重み付きグラフが得られます。 エッジに沿って移動することが許可されており、任意の 2 つのノード間の移動コストは、元のグラフの最短経路距離によって定義されます。 目標は、単一のターゲットへの最短パスを見つけることだけではなく、指定されたソースから出発して総移動コストを最小限に抑えながらすべてのノードを訪問することです。 

したがって、概念的には、最初にグラフを、任意の 2 つのノード間の距離が元のグラフの最短経路距離となる完全な計量空間に変換します。 この変換後、ノード間の遷移がこれらの事前計算された最短パス距離によって重み付けされる、すべてのノードにわたる訪問問題を解決します。 

出力は、指定されたノードから開始され、最終的にすべてのノードを少なくとも 1 回カバーするウォークの最小可能総コストです。 これは基本的に状態空間探索問題であり、どのノードがすでに訪問されているか、また現在どこにいるかによって状態が定義されます。 

この制約は次のことを強く示唆しています。$n$は小さく、おそらく多くても 15 または 16 です。これは、ノードのサブセットを考慮するソリューションでは次のことが必要になるためです。$2^n$州、そしてそれを超えたあらゆるもの$n = 20$指数関数的な増加により実行不可能になります。 で$n = 15$、$2^n$は約 32,000 ですが、慎重に移行すれば管理可能です。 

コストは訪問履歴に依存するため、元のグラフ上の単純な最短経路では不十分です。 常に最も近い未訪問のノードに移動する典型的な貪欲なアプローチは、局所的に最適な選択が全体的に最適ではないツアーにつながる可能性があるため、失敗する可能性があります。 

微妙なエッジ ケースは、ノード間の最短パスが直接エッジと大きく異なる場合に発生します。 すべてのペアの最短経路を事前に計算しないと、状態間の移動コストが過小評価または過大評価され、不正確な DP 遷移が発生する可能性があります。 

## アプローチ

 強引なアイデアは、訪問ノードの考えられるすべての順序をシミュレートすることです。 ソースから開始して残りのノードのすべての順列を試行し、最短パス距離を使用して各次数の合計コストを計算します。 これは、考えられるすべてのツアーを検討するため、正しいですが、次のことが必要です。$n!$順列、さらには$n = 12$、これはすでに大きくなりすぎています。 

重要な洞察は、現在のノードと訪問したノードのセットを超えた正確なシーケンス構造を気にする必要がないということです。 すべてのノードのペア間の最短パス距離を事前に計算すると、グラフは固定エッジ コストを持つ完全な重み付きグラフになります。 次に問題は、各状態が訪問ノードのサブセットと現在位置によって定義される状態グラフ内の最短パスになります。 

これは自然に、ビットマスク動的プログラミングのアプローチにつながります。 各状態はどのノードが訪問されたかをエンコードし、遷移はまだマスクに含まれていない新しいノードへの移動に対応します。 移行のコストは、事前に計算された最短パス距離です。 

まず、Floyd-Warshall を使用してすべてのペアの最短経路を計算します。$n$小さいです。 次に、サブセットに対して DP を実行し、すべてのノードが含まれるまで訪問セットを徐々に拡張します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース順列 |$O(n!)$|$O(n)$| 遅すぎる |
 | ビットマスク DP + APSP |$O(n^2 2^n)$|$O(n 2^n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 この問題は 2 つの概念的なフェーズで解決されます。最初にグラフを最短経路距離に圧縮し、次にサブセットに対して動的プログラミングを実行します。 

1. まず、Floyd-Warshall を使用してすべてのペアの最短経路を計算します。 元のグラフには直接エッジよりも安価な間接ルートが含まれている可能性があるため、この手順が必要です。 このステップの後、ノードの各ペアが固定の最小移動コストを持つ完全に接続されたグラフとして扱うことができます。 
2. DP 状態を定義します`dp[mask][u]`、 どこ`mask`訪問したノードのセットを表し、`u`は現在のノードです。 この状態には、ノードに到達するための最小コストが格納されます。`u`のノードを正確に訪問しました`mask`。 今後の決定は、訪問した内容と現在どこにいるかのみに依存するため、このエンコードで十分です。 
3. 訪問した開始ノードのみを設定して DP を初期化します。`dp[1 << s][s] = 0`。 これは、移動コストなしで開始状態にあることを表します。 
4. マスク サイズの昇順でノードのすべてのサブセットを繰り返します。 州ごとに`(mask, i)`到達可能であるため、すべてのノードへのパスを拡張してみます。`j`まだマスクに入っていない。 新しい状態を更新します`dp[mask | (1 << j)][j]`コストを使って`dp[mask][i] + dist[i][j]`。 
5. 遷移は、次に訪問するノードの選択を効果的にシミュレートしますが、事前に完全な順列を修正する必要はありません。 代わりに、すべての可能性を段階的に構築し、各状態の最適なコストのみを維持します。 
6. すべての状態を処理した後、答えはすべての状態の最小値になります。`dp[full_mask][i]`、すべてのノードを訪問した後の最終ノードは任意のノードになる可能性があるためです。 

### なぜ効果があるのか

 各 DP 状態は、訪問したノードと現在位置のみを特徴とする独自に定義された部分ツアーを表します。 完全なツアーはすべてそのような状態に分解でき、エッジの重みがすでにノード間の最短の移動コストを表しているため、すべての遷移が正確さを維持します。 すべてのサブセットとすべての終了ノードを系統的に探索するため、有効なツアーが失われることはなく、DP は各状態に対して最小限のコストのみが保持されることを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, s = map(int, input().split())
    s -= 1

    INF = 10**18
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0

    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        dist[u][v] = min(dist[u][v], w)
        dist[v][u] = min(dist[v][u], w)

    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    K = 1 << n
    dp = [[INF] * n for _ in range(K)]

    dp[1 << s][s] = 0

    for mask in range(K):
        for i in range(n):
            if not (mask & (1 << i)):
                continue
            cur = dp[mask][i]
            if cur == INF:
                continue
            for j in range(n):
                if mask & (1 << j):
                    continue
                nmask = mask | (1 << j)
                new_cost = cur + dist[i][j]
                if new_cost < dp[nmask][j]:
                    dp[nmask][j] = new_cost

    full = K - 1
    ans = min(dp[full][i] for i in range(n))
    print(ans)

if __name__ == "__main__":
    solve()
```Floyd-Warshall ブロッ​​クは、すべてのペアごとの距離が最小であることを保証します。これは、DP 遷移が任意の 2 つのノード間の最適な移動コストに直接アクセスすることを前提としているため、非常に重要です。 この前処理がないと、DP は間接パスを過小評価します。 

ビットマスク DP はすべてのサブセットに対して反復されます。 内部ループは、遷移を許可する前に、ノードが現在のサブセット内にあるかどうかを注意深くチェックします。 更新ステップでは状態ごとのコストを最小限に抑え、冗長パスが早期に破棄されるようにします。 

すべての終了ノードに対する最終的な削減は、ツアーが開始位置に戻ったり、固定ノードで終了したりする必要がないという事実を反映しています。 

## 実用的な例

 ### 例 1

 入力:```
3 3 1
1 2 1
2 3 1
1 3 10
```フロイド-ウォーシャルの後、最短パスは次のようになります。 

| 私 | j | 距離 |
 | --- | --- | --- |
 | 1 | 2 | 1 |
 | 2 | 3 | 1 |
 | 1 | 3 | 2 |

 DP の進行:

 | マスク | 終了ノード | コスト |
 | --- | --- | --- |
 | 001 | 1 | 0 |
 | 011 | 2 | 1 |
 | 111 | 3 | 2 |

 最終的な答えは 2 です。 

これは、DP の前に間接エッジが最短パスにどのように置き換えられるかを示しています。 

### 例 2

 入力:```
4 4 1

3 4 5
1 4 20
```最短パスはチェーン構造を圧縮します。 

| ペア | 距離 |
 | --- | --- |
 | 1-2 | 5 |
 | 2-3 | 5 |
 | 3-4 | 5 |
 | 1-4 | 15 |

 DPはコスト15で1→2→3→4のパスを構築します。 

これは、直接エッジが存在する場合でも、DP が最適なサブパスのチェーンを正しく優先することを確認します。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 |$O(n^3 + n^2 2^n)$| フロイド-ウォーシャルとサブセット DP 遷移 |
 | スペース |$O(n 2^n)$| サブセットとエンドポイントにわたる DP テーブル |

 このソリューションは小規模向けに設計されています$n$、指数関数的な DP が実現可能です。 3 次前処理は状態空間爆発に比べて無視できる程度であり、組み合わせた複雑さはビットマスク DP 問題の一般的な制約に適合します。

    for i in range(n):

## 特殊なケース

 すべてのノードがすでに最適なエッジに直接接続されているグラフの場合、フロイド-ウォーシャル ステップは距離を変更しません。 トランジションは直接エッジに従うだけなので、DP は依然として正しく動作します。 

非常に高価な直接エッジが存在するが、より安価なマルチホップ パスが存在するグラフ (重いショートカット エッジを持つ三角形など) の場合、前処理により、DP が高価なエッジを決して使用しないことが保証されます。 

いつ$n = 1$、ビットマスク DP は単一の状態に減少し、移動が必要ないため、すぐにゼロを返します。 

開始ノードがすでにマスク内の唯一のノードである場合、DP の初期化はすでに完全な状態に対応しており、アルゴリズムが遷移に入らずに些細なケースを処理していることが確認されます。
