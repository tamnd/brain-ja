 ## 解決策
 ## 問題の理解

 Fedya にはマテリアルのコレクションがあり、それぞれのマテリアルはその強さを示す正の整数で表されます。 彼は2つの素材を組み合わせて武器を作ることができ、その武器の強さは右から並んだ2つの数字の対応する桁の差の絶対値の合計になります。 数値の長さが異なる場合、短い数値の先頭にゼロが埋め込まれます。 たとえば、53 と 57 を組み合わせると武器の強度は 4 になります。これは、10 の位が同じで、単位の桁が 4 異なるためです。 

入力により、複数のテスト ケースで利用可能な材料強度の範囲が得られます。 各範囲は、非常に大きな可能性がある 2 つの整数で与えられます。$L$そして$R$、最大 100 桁まで入力できます。 目標は、その範囲内の任意の材料のペアから得られる武器の最大強度を計算することです。 出力はテスト ケースごとに 1 つの整数です。 

数値が最大 100 桁までであるという制約により、範囲内のすべての数値を列挙するソリューションは直ちに除外されます。 すべてのペアを比較するという単純なアプローチでも、大まかに次のことが必要になります。$(R-L+1)^2$操作は実行不可能です。$L$そして$R$大きいです。 このため、数値全体ではなく個々の桁について推論する必要があります。 

エッジケースには以下のような場合が含まれます：$L = R$この場合、考えられる唯一の武器は 2 つの同じ数字を使用し、答えは 0 です。別の厄介な状況は、射程が異なる長さの数字にまたがる場合に発生します。$L = 88$そして$R = 1914$ここで、先頭のゼロを使用して数字を正しく配置することが重要です。 

## アプローチ

 ブルートフォースアプローチでは、次の範囲にあるすべての数値を生成しようとします。$L$そして$R$そして、考えられるすべてのペアの最大絶対桁差の合計を計算します。 これは正しいのですが、異常に遅いです。 最大 100 桁の数値の場合、すべての数値を 1 回反復することさえ不可能です。 

重要な洞察は、桁ごとの絶対差の合計を最大化するには、各位置で独立して、一方の数値の桁をできるだけ小さくし、もう一方の数値をできるだけ大きくする必要があるということです。 1 桁の場合、最大の差は 0 と 9 を選択することによって達成されます。したがって、問題は範囲内にある 2 つの数字を決定することになります。$L$に$R$桁ごとの差が桁ごとの最大値にできるだけ近くなるように桁を配置します。 数値の長さが異なる場合があるため、欠落している桁をゼロとして扱い、短い数値を左側に効果的に埋め込むことができます。 

戦略は、次の各桁を操作して得られた数値を調べることです。$L$そして$R$個別に。 実際には、候補となる番号はいくつかしかありません。$L$自体、$R$それ自体、および数字を 0 または 9 に置き換え、残りの数字を最小限に調整して得られる数値$[L,R]$。 このような候補数値のすべてのペアを比較すると、最適な解が保証されます。これは、これらの候補以外の数値は、一部の位置の桁の差が減少するだけで、他の箇所では桁の差が増加しないためです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((R-L+1)^2 × 桁数) | お(1) | 広い範囲には遅すぎる |
 | 最適 | O(桁 × 桁 × 候補^2) | O(候補者) | 効率的で制約内で動作します |

 ## アルゴリズムのチュートリアル

 1.読む$L$そして$R$非常に大きな数値を処理するための文字列として使用します。 各数値の長さを決定し、短い数値の先頭にゼロを埋め込んで長さを一致させます。 
2. 変数を初期化する`max_strength`0 に設定すると、見つかった最高の武器強度が保存されます。 
3. 元の値を考慮して、範囲の両端の候補番号を生成します。$L$そして$R$の各桁を変更して形成される数字$L$～9または各桁$R$数値を範囲内に保ちながら 0 にします。 これにより、特定の桁で一方の数値が最大化され、もう一方の数値が最小化されるケースを確実にカバーできます。 
4. 候補番号のすべてのペアについて、対応する数字の差の絶対値を合計することによって武器の強さを計算します。 数値の長さが異なる場合は、前と同様に先頭にゼロを使用して整列させます。 
5.アップデート`max_strength`計算された強度が現在の最大値を超えるたびに。 
6. すべての候補ペアをチェックしたら、出力します。`max_strength`現在のテストケースの場合。 

このアルゴリズムが機能するのは、すべての桁位置で、合計への最大寄与が範囲内で許容される最大の絶対差であるためです。 候補番号により、範囲内で極端な桁が許容されるすべての位置が考慮されるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_digit_diff(L: str, R: str) -> int:
    max_strength = 0
    lenL, lenR = len(L), len(R)
    max_len = max(lenL, lenR)
    L_pad = L.zfill(max_len)
    R_pad = R.zfill(max_len)
    
    # Candidate numbers: original L and R
    candidates = [L_pad, R_pad]
    
    # Generate variants of L by changing a digit to 9
    for i in range(max_len):
        if L_pad[i] != '9':
            candidate = L_pad[:i] + '9' + L_pad[i+1:]
            if L_pad <= candidate <= R_pad:
                candidates.append(candidate)
    
    # Generate variants of R by changing a digit to 0
    for i in range(max_len):
        if R_pad[i] != '0':
            candidate = R_pad[:i] + '0' + R_pad[i+1:]
            if L_pad <= candidate <= R_pad:
                candidates.append(candidate)
    
    # Compare all pairs
    for x in candidates:
        for y in candidates:
            strength = sum(abs(int(a)-int(b)) for a,b in zip(x,y))
            max_strength = max(max_strength, strength)
    
    return max_strength

t = int(input())
for _ in range(t):
    L, R = input().split()
    print(max_digit_diff(L, R))
```このソリューションは、数値を文字列として読み取り、任意の長さを処理し、桁を揃えるために短い数値を埋め込み、桁を極端に変更することで候補数値を効率的に生成します。 すべての候補ペアは桁ごとに比較され、潜在的な最大値が見落とされないようにします。

 最大強度は 28 で、桁ごとの差を最大にして 0088 と 1914 を組み合わせることによって得られます。 アルゴリズムは短い数値を正しく埋め込み、先頭のゼロを考慮します。
