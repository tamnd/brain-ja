 ## 解決策
 ## 問題の理解

 私たちはグリッドに取り組んでいます$(1,1)$に$(N,M)$、移動は右または上の移動のみに制限されます。 これは、すべての有効なパスが単調であることを意味します。両方の座標はパスに沿って厳密に増加します。 

その上で、私たちに与えられているのは、$K$パスによってすべて訪問される必要がある特別なセル。 パスは、角で開始および終了するだけでなく、必要なすべてのセルを通過する場合にのみ有効です。 

主な難点は、必要なポイントがオーダーされていないことです。 単調なパスは両方の座標で別の必要な点の「前」にある点を訪れることができないため、それらの中には矛盾を強制するものもあります。 たとえば、必要なポイントが 1 つある場合、$(2,5)$そしてもう一つは$(3,4)$、両方の次元で一貫した順序でどちらも他方を支配しないため、単調なパスは両方を訪問することはできません。 

制約は大きい: まで$10^5$テストケース、合計$K$すべてのテストでも$10^5$、グリッドの寸法は最大$10^5$。 これにより、テストごとのすべてが除外されます$O(K^2)$またはグリッド上の DP。 ソリューションは各テストを大まかに処理する必要があります$O(K \log K)$またはそれ以上です。 

重要なエッジ ケースは、必要なポイントが単調な順序付けと一致しない場合に発生します。 例えば：```
1
3 3 2
2 3
3 2
```有効なパスが存在しないため、$(2,3)$そして$(3,2)$単調な順序で訪れることはできません。 実現可能性をチェックせずに独立したパス セグメントを乗算する単純な計算では、誤って肯定的な答えが生成されます。 

重複したポイントが存在する場合、別の失敗ケースが発生します。 このステートメントでは座標の繰り返しが許可されていますが、それらを個別に扱うと、重複排除されていない限りパスが二重にカウントされる可能性があります。 

## アプローチ

 制約がなければ、自然なアイデアとして、訪問のすべての順列を試してみます。$K$必要なポイントを順番に並べていきます。 順序ごとに、それが単調であるかどうか (両方の座標によってソートされている) を確認し、連続する点間の各セグメントの二項係数を乗算します。 これは正しいです。なぜなら、2 つの固定点の間にあるからです。$(x_1,y_1)$そして$(x_2,y_2)$、単調パスの数は$\binom{(x_2-x_1)+(y_2-y_1)}{x_2-x_1}$。 

問題は、$K!$順列は不可能です$K$まで$10^5$。 有効な順序に制限しても、ポイントが部分的に順序付けされている最悪の場合には役に立ちません。 

重要な観察は、有効なパスは両方の座標の昇順で必要な点を同時に訪問する必要があるということです。 これは、必要なすべてのポイントを次の基準で並べ替えることができることを意味します。$x$、そして 2 つの点が同じである場合$x$、 による$y$。 After sorting, we only need to check feasibility: the$y$-座標も減少しない必要があります。 この条件が満たされない場合、答えはゼロになります。 

順序付けが完了すると、問題は独立した部分問題の単純な積になります。ソートされたチェーン内の連続する点間のパスを数え、それらを掛け合わせるというものです。

 ## アルゴリズムのチュートリアル

 問題を単調なセグメントのシーケンスに還元します。 

### ステップ

 1. 必要なポイントをすべて収集し、開始ポイントを追加します$(1,1)$とエンドポイント$(N,M)$。 

これらは、パスの完全な強制チェーンを定義します。 
2. すべてのポイントを昇順に並べ替えます$x$、そしてもし$x$増加すると等しい$y$。 

これは、可能であれば、すべての右/上方向のパスがこの順序でポイントを訪問する必要があるという事実を反映しています。 
3. ソートされたリストをスキャンし、次のことを確認して実現可能性をチェックします。$y$- 座標は減少しません。 

減少が発生した場合は、両方の要件を満たす単調パスはないため、0 を返します。 
4. 連続する点のペアごとに$(x_i,y_i)$そして$(x_{i+1},y_{i+1})$、それらの間の単調パスの数を計算します。$$\binom{(x_{i+1}-x_i)+(y_{i+1}-y_i)}{x_{i+1}-x_i}$$5. すべてのセグメント数を剰余で乗算します。$998244353$。 

パスが必要なポイントに到達すると、残りの選択肢は次のセグメントにのみ依存するため、各セグメントは独立しています。 
6. 最終成果物を出力します。 

### なぜ効果があるのか

 単調なパスは、両方の座標と一致する全体的な順序を課します。 並べ替えにより、必要なポイントを訪問する唯一の可能な候補順序が強制されます。 実現可能性チェックにより、この順序が両方の次元で一貫していることが確認されます。 固定されると、すべてのセグメントは独立した格子パス問題になり、独立性は、ばらばらの座標間隔での選択が相互作用しないという事実から生じます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def comb(n, k):
    if k < 0 or k > n:
        return 0
    k = min(k, n - k)
    res = 1
    for i in range(1, k + 1):
        res = res * (n - k + i) // i
    return res % MOD

def solve():
    T = int(input())
    for _ in range(T):
        N, M, K = map(int, input().split())
        pts = [(1, 1)]
        for _ in range(K):
            x, y = map(int, input().split())
            pts.append((x, y))
        pts.append((N, M))

        pts.sort()

        ok = True
        for i in range(len(pts) - 1):
            if pts[i][1] > pts[i + 1][1]:
                ok = False
                break

        if not ok:
            print(0)
            continue

        ans = 1
        for i in range(len(pts) - 1):
            x1, y1 = pts[i]
            x2, y2 = pts[i + 1]
            dx = x2 - x1
            dy = y2 - y1
            if dx < 0 or dy < 0:
                ok = False
                break
            ways = comb(dx + dy, dx)
            ans = ans * ways % MOD

        print(ans)

if __name__ == "__main__":
    solve()
```このソリューションでは、最初にエンドポイントを挿入して、すべての制約がセグメント遷移になるようにします。 ソートにより、単調な動きと一致する唯一の可能な訪問順序が強制されます。 ソートだけではパスが存在することが保証されないため、実現可能性チェックが必要です。 の$y$-シーケンスも単調でなければなりません。 

組み合わせ関数は、合計の移動の中から正しい移動の位置を選択することを表す二項係数を使用して、格子パス数を直接計算します。

 ## 特殊なケース

 必要なポイントがモノトーン発注に対応していない場合は、$x$の減少を明らかにする$y$、すぐに答え 0 を強制します。たとえば$(2,5)$そして$(3,4)$降順でソートされたシーケンスを生成します$y$、アルゴリズムは乗算の前に停止し、不可能な制約を正しく拒否します。 

いつ$K=0$、端点のみが残り、解は単一の二項係数に帰着します。$\binom{N+M-2}{N-1}$、同一セグメントの商品構成で自然に処理されます。 

複数の点が一致する場合、並べ替えによってそれらの点が隣接した状態に保たれ、長さ 0 のセグメントが乗法同一性に寄与し、特殊なケースを使用せずに正確さが維持されます。
