 ## アルゴリズムのチュートリアル

 解決策は、固有のルールに従ってツリーを分解することに基づいています。$a$-$b$パス。 

1.長さを固定する$k$間のパスの$a$そして$b$、つまりパスには$k$エッジと$k+1$頂点。 

考え方としては、すべての有効なツリーがそのようなパスを 1 つだけ提供するため、この値によってツリーを分類できるということです。 
2. パス上の中間頂点を選択します。 

選択します$k-1$残りの頂点から$n-2$頂点を使用して内部パス ノードを形成します。 これらのノードの順序はパス構造を決定するため重要です。 
3. これらの選択した頂点をパスに配置する方法が何通りあるかを数えます。$a$に$b$。 

セットを選択すると、次のようになります。$(k-1)!$パスに沿って順序を付ける方法。 
4. に重みを割り当てます。$k$パス上のエッジの合計が正確に一致するようにする$m$。 

の作曲数です。$m$の中へ$k$正の部分は次のように与えられます。$$\binom{m-1}{k-1}$$私たちが置くから$k-1$間の区切り文字$m-1$ギャップ。 
5. 残りをすべて取り付けます$n-(k+1)$頂点は、根の生えた木のいずれかからぶら下がっています。$k+1$パスノード。 

パス以外の各頂点は、パス上またはそのサブツリー構造内の親を選択します。これは、パス ノードをルートとするラベル付きフォレストをカウントすることになります。 これは次の要因に影響します。$$(k+1) \cdot n^{n-k-2}$$ケイリーの公式の標準的な一般化を介して。 
6. 有効なすべての合計$k$、 から$1$に$\min(n-1, m)$、すべての貢献を乗算します。 

### なぜ効果があるのか

 すべての有効なツリーには一意のツリーがあります$a$-$b$パス上にないすべての頂点は、パス上のノードをルートとする 1 つのサブツリーに属します。 これにより、完全なツリーと、パス構造、そのパス上の重み割り当て、およびフォレスト接続構造で構成されるタプルとの間に全単射が作成されます。 パス長が固定されると、これらの選択肢は独立するため、それらの数を乗算しても、過剰にカウントされたり、構成が欠落したりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def build_fact(n):
    fact = [1] * (n + 1)
    invfact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD
    invfact[n] = modinv(fact[n])
    for i in range(n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD
    return fact, invfact

n, m, a, b = map(int, input().split())

maxv = max(n, m)
fact, invfact = build_fact(maxv)

def C(n, k):
    if k < 0 or k > n:
        return 0
    return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD

ans = 0

for k in range(1, min(n - 1, m) + 1):
    paths = C(n - 2, k - 1) * fact[k - 1] % MOD
    weights = C(m - 1, k - 1)
    attach = pow(n, n - k - 2, MOD) * (k + 1) % MOD
    ans = (ans + paths * weights % MOD * attach) % MOD

print(ans)
```このコードは階乗を事前計算して、パスの頂点の選択とパスに沿った重みの分散の両方について高速な二項係数クエリをサポートします。 ループオーバー$k$は、上の可能なエッジの数に直接対応します。$a$-$b$パス。 

用語`C(n - 2, k - 1)`中間頂点を選択し、`fact[k - 1]`道に沿って彼らに命令します。 二項式`C(m - 1, k - 1)`重みの構成をエンコードします。 最終学期`pow(n, n - k - 2)`残りの頂点をラベル付きツリー形式で接続することで得られます。`(k + 1)`パス構造上のルート接続点を選択します。 

よくある実装の落とし穴は、パス ノードに両方のエンドポイントが含まれていることを忘れることです。$a$そして$b$、だからそれだけ$k-1$内部頂点は次から選択されます$n-2$。 もう 1 つは、アタッチメント項の指数の処理を誤っていることです。これは、両方のパス ノードを減算し、ツリー次数を正しく考慮する必要があります。

 ## 特殊なケース

 重要なエッジケースの 1 つは、$n=2$。 ツリーにはエッジが 1 つだけあるため、可能な構造は、$a$そして$b$。 ループオーバーのため、アルゴリズムはこれを自然に処理します。$k$のみ許可します$k=1$、重量寄与は次のようになります。$C(m-1,0)=1$一方、余分な頂点がないため、アタッチメント項は正しく減少します。 

もう一つの微妙なケースは次のような場合です。$m$小さいです。 もし$m < k$、 それから$C(m-1, k-1)=0$したがって、無効なパス長は何も寄与しません。 これにより、パスが長すぎて必要な距離を達成できない場合の構成の過剰カウントが防止されます。 

3 番目のケースは次の場合です。$n$大きいですが$m$小さいです。 すべてが大きいため、公式はまだ機能します$k$重み合成項により消滅し、短いパスのみを残し、無関係な状態に対する不必要な計算を回避します。
