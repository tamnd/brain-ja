 ## 解決策
 ## 問題の理解

 この問題では、複数のクエリに対して特別な整数のリストを生成するように求められます。 整数を含む特定のクエリの場合`x`、`p`、 そして`k`を見つける必要があります。`k`-番目の整数が次より大きい`x`それは互いに素である`p`。 共素とは、数値の最大公約数 (gcd) を意味し、`p`は 1 です。たとえば、次の場合`x = 7`そして`p = 22`、7 より大きく、22 と互いに素な数は、9、13、15、17 などになります。 クエリが必要とするのは、`k`このシーケンスの - 番目の番号。 

この制約により最大 30,000 個のクエリが可能になり、各クエリには最大 1,000,000 個の数値が含まれます。 上記の各整数をチェックする素朴なアプローチ`x`クエリごとに潜在的に数百万もの数値の gcd を 1 つずつ計算する必要がありますが、これでは遅すぎます。 と`t`30,000 に達する数字`10^6`、大まかに対数のオーダー、または素因数の数を線形にスケールする方法が必要です。`p`。 

微妙なエッジケースが発生する場合`p`には小さな素因数がたくさんあります。 たとえば、次の場合`p = 6`、2 または 3 の倍数の数値はスキップする必要があります。 単純なアプローチでは、次の素因数で割り切れる数を誤って数えてしまう可能性があります。`p`。 同様に、`x`と互いに素な数のすぐ下にある可能性があります`p`そのため、カウントまたはインデックス作成時に 1 つずつずれたエラーが発生すると、間違った数値が返される可能性があります。 たとえば、`x = 5`、`p = 6`、 そして`k = 1`、正解は6ではなく7です。 

## アプローチ

 ブルートフォース手法は簡単です。`x + 1`、各数値を順番に確認し、互いに素であるものがいくつあるかを数えます。`p`。 カウントに達したら`k`、その数字が答えです。 これが機能するのは、シーケンスの定義を直接シミュレートするためです。 問題は最悪のケースです。`p`は 2 のように小さく、数値の約半分は互いに素であるため、最大で反復する必要があるかもしれません。`10^6`クエリごとの数値。 と`t`30,000 に達する可能性があります`3 * 10^10`明らかに実行不可能な操作です。 

重要な観察は、共素性は次の素因数によって決定されるということです。`p`。 素因数分解がわかっていれば、`p`、包含-除外を使用して、ある値以下の数値がいくつあるかを数えることができます。`y`と互いに素である`p`。 これにより、問題を検索として扱うことができます。最小の数値を見つけることができます。`y`より大きい`x`まさに存在するように`k`間の数字`x`そして`y`と互いに素である`p`。 これにより、高速カウント機能と組み合わせた二分探索により問題が軽減されます。 包含-排他によるカウントは、最大で任意の数の異なる素因数の数が計算されるため、効率的です。`10^6`は最大 7 です (2 * 3 * 5 * 7 * 11 * 13 * 17 > 10^6 であるため)。 

ブルートフォースアプローチと最適アプローチは次のように比較できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | クエリあたり O(k * log p) | お(1) | k が大きいか p が小さい場合は遅すぎます |
 | 包含-除外 + 二分探索 | クエリごとに O(2^m * log(range))、m = #p の素因数 | O(m) | 効率的で受け入れられる |

 ## アルゴリズムのチュートリアル

 1. 以下のすべての素数を事前計算します。`10^6`エラトステネスのふるいを使って。 これにより、任意の因数分解が可能になります`p`効率的に。 
2. クエリごとに`(x, p, k)`、 要素`p`それぞれの異なる素因数に分けられます。 因子の数`m`小さいです。 
3. 関数を定義する`count_coprime(y)`整数がいくつあるかを数えます ≤`y`と互いに素である`p`。 包含-排他を使用して、次の素因数のすべてのサブセットを反復処理します。`p`。 各サブセットについて、素数の積を計算し、フロア除算を減算または加算します。`y // product`サブセットサイズのパリティに従って。 
4. 最小の整数を求める二分探索を実行します。`y`そのような`count_coprime(y) - count_coprime(x) == k`。 初期化する`low = x + 1`そして`high`として`x + k * p`(これは上限です。最悪の場合、すべての`p`数値には少なくとも 1 つの互いに素な数が含まれます)。 
5. 戻る`y`として`k`シーケンス内の - 番目の番号。 

これが機能するのは、包含/除外カウントによって互いに素な整数の正確な数が得られるためです。`p`限界まで。 二分探索は正確な数値を効率的に見つけます。`k`等素数は後に現れます`x`。 不変条件は、検索の各ステップで、真の答えが検索間隔内にとどまることです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def sieve(n):
    spf = list(range(n + 1))
    for i in range(2, int(n**0.5) + 1):
        if spf[i] == i:
            for j in range(i*i, n+1, i):
                if spf[j] == j:
                    spf[j] = i
    return spf

def factorize(n, spf):
    primes = set()
    while n > 1:
        primes.add(spf[n])
        n //= spf[n]
    return list(primes)

def count_coprime(y, primes):
    from itertools import combinations
    res = y
    m = len(primes)
    for sz in range(1, m+1):
        for comb in combinations(primes, sz):
            prod = 1
            for c in comb:
                prod *= c
            if sz % 2 == 1:
                res -= y // prod
            else:
                res += y // prod
    return res

def solve():
    spf = sieve(10**6)
    t = int(input())
    for _ in range(t):
        x, p, k = map(int, input().split())
        primes = factorize(p, spf)
        low = x + 1
        high = x + k * p
        while low < high:
            mid = (low + high) // 2
            if count_coprime(mid, primes) - count_coprime(x, primes) >= k:
                high = mid
            else:
                low = mid + 1
        print(low)

solve()
```ふるいは因数分解に使用されます`p`効率的に。 の`count_coprime`関数は、素因数に包含/除外を適用して、互いに素な整数の正確な数を決定します。`p`任意の値まで。 二分探索により、`k`- より大きい共素数`x`。 検索の上限を次のように安全に設定するように注意してください。`x + k * p`オーバーシュートを避けるため。
