 ## 解決策
 ## 問題の理解

 カエルは数直線上の位置 0 から開始し、一定のパターンで左右にジャンプを繰り返します。 最初のジャンプで右に移動します。`a`、2 番目のジャンプで左に移動します。`b`、そしてこの交互は続く`k`総ジャンプ数。 各クエリは異なる値を返します。`a`、`b`、 そして`k`そして、それらのジャンプを正確に実行した後、カエルの最終的な位置を決定する必要があります。 

ここで重要なのは、動きが完全に決定的であり、2 つのジャンプのサイクルで周期的であるということです。 1 サイクルはサイズの右移動で構成されます`a`続いてサイズを左に移動します`b`。 カエルの位置は単純な交互の合計として変化しますが、ジャンプの数は 10^9 にもなる可能性があるため、各ステップを明示的にシミュレートすることは不可能です。 

この制約は、ジャンプごとのシミュレーションが直ちに実行不可能であることを意味します。 最大 1000 個のクエリとクエリあたり最大 10^9 ステップの場合、O(k) アプローチでは最悪の場合最大 10^12 の操作が必要になりますが、これは制限をはるかに超えています。 プロセスをクエリごとの一定時間に圧縮する必要があります。 

次の場合、微妙なエッジケースが発生します。`k`最後の部分サイクルの動作が異なるため、奇数または偶数になります。 たとえば、次の場合`a = 5`、`b = 2`、 そして`k = 3`、シーケンスは次のとおりです`+5, -2, +5`、結果は 8 になります。`k = 4`、最後のステップは次のようになります`-2`、バランスを変更します。 残り物を処理せずに完全なペアを想定するソリューションは失敗します。 

もう 1 つのよくある落とし穴は、完全なペアを超えた対称性またはキャンセルを想定することです。 いつ`a`等しい`b`、完全なサイクルはキャンセルされますが、不完全なサイクルでは依然としてゼロ以外の値が生成されます。 たとえば、`a = b = 1`そして`k = 999999999`の場合、結果は 0 ではなく 1 になります。 

## アプローチ

 直接シミュレーションでは、現在の位置が維持され、交互に追加されます。`a`そして引き算`b`ジャンプごとに。 これは定義に正確に従っているため、簡単で正しいです。 ただし、ジャンプごとに 1 つの算術演算を実行するため、大きな`k`が遅くなりすぎます。 

重要な観察は、ジャンプが繰り返しのペアで行われるということです。 2 回のジャンプごとに、正味変位に寄与します。`a - b`。 プロセスを完全なペアにグループ化する場合、2 つのジャンプの完全なサイクルが何回存在するか、および最後に余分な 1 つのジャンプがあるかどうかを計算するだけで済みます。 

もし`k`が偶数であれば、カエル​​は正確に完了します`k/2`全サイクル、それぞれが貢献`a - b`。 もし`k`奇妙です、あります`(k-1)/2`全サイクルと最後の右ジャンプ 1 回`+a`。 

これにより、問題は線形シミュレーションからパリティに基づく単純な算術演算に軽減されます。

 ## アルゴリズムのチュートリアル

 各クエリについて:

 1.読む`a`、`b`、 そして`k`。 これらは、固定の交互動作パターンと実行するステップの数を定義します。 
2. 次を使用して、ジャンプの完全なペアがいくつ存在するかを計算します。`k // 2`。 各ペアは次のもので構成されます。`+a`移動に続いて`-b`動く。 
3. 完全なペアの数に次の値を掛けます。`(a - b)`すべての完全なサイクルの合計寄与度を取得します。 これが機能するのは、各完全なサイクルが前方ジャンプと後方ジャンプの差に等しい正味変位を返すためです。 
4. もし`k`奇数です、もう 1 つ追加してください`+a`不完全な最後のステップのために。 これが必要なのは、シーケンスが常に前方ジャンプで始まり、奇数長のシーケンスが前方移動で終了するためです。 
5. 結果の位置を出力します。 

### なぜ効果があるのか

 このシーケンスは期間 2 では厳密に周期的であり、各期間は固定純変化量に寄与します。`a - b`。 完璧なペアリングから唯一逸脱するのは、次の場合です。`k`これは奇妙で、最後のステップは常に前方ジャンプです。 このプロセスは線形かつ加算的であるため、素のペアと可能な残りのペアに分割すると、正確な合計変位が保存されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
out = []

for _ in range(t):
    a, b, k = map(int, input().split())
    
    pairs = k // 2
    res = pairs * (a - b)
    
    if k % 2 == 1:
        res += a
    
    out.append(str(res))

print("\n".join(out))
```このソリューションは、各クエリを個別に処理します。 重要な計算は整数の除算です`k // 2`、完全な (a, -b) サイクルをカウントします。 乗算`(a - b)`これらすべてのサイクルを 1 つの算術式にまとめます。 

条件付き`if k % 2 == 1`次の場合に、残りの 1 つの前方ジャンプを処理します。`k`奇数です。 最初のジャンプは常に前方に進むため、残ったステップが減算されることはありません。 

すべての算術演算は Python 整数で行われ、オーバーフローの問題なく最大 10^9 * 10^9 までの大きな値を自然にサポートします。

 ## 特殊なケース

 いつ`k = 1`、アルゴリズムセット`pairs = 0`そして追加します`+a`。 入力用`a = 7, b = 3, k = 1`の場合、最初の前方ジャンプのみが発生するため、結果は 7 となり、定義と一致します。 

いつ`a = b`、すべての完全なペアはゼロに寄与します。 のために`a = b = 10, k = 5`、私たちは得ます`pairs = 2`、つまり寄与は 0 となり、残った奇数ステップが追加されます。`+10`単純なキャンセルの仮定では、誤って 0 が返されます。 

いつ`k`は偶数であり、残り物は存在せず、結果は完全に次の条件に依存します。`(a - b)`。 のために`a = 5, b = 2, k = 4`、私たちは得ます`2 * 3 = 6`、明示的なシーケンスと一致する`5 - 2 + 5 - 2`。
