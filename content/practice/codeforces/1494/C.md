 ## 解決策
 ## 問題の理解

 一次元の無限数直線に沿った特別な位置に配置されたボックスの数を最大化することが求められます。 位置 0 から開始し、左または右に移動して、移動方向にボックスを押します。 ボックスは押した方向にのみ前進し、引いたり迂回したりすることはできません。 すべてのボックスは個別の整数位置を占め、すべての特別な位置も個別です。 一部のボックスは、最初は特別な位置にある場合があります。 

入力により複数のテスト ケースが提供されます。 各テスト ケースでは、ボックスの位置と特別な位置が並べ替えられた順序で提供されます。 出力はテスト ケースごとに 1 つの数値、つまり特別な位置に配置されるボックスの最大数です。 

制約は重要です。単一のテスト ケース内のボックスまたは特別な位置は最大 200,000 個で、位置の範囲は最大 ±10^9 であり、すべてのテスト ケースの合計が 200,000 を超えません。 これにより、最悪の場合、4×10^10 の演算に達する可能性がある O(n・m) の複雑さのアルゴリズムが除外されます。 n と m において線形に近い複雑さ、または線形演算の複雑さを持つアルゴリズムが必要です。 

考慮すべきエッジケースには、ボックスと特別な位置がすべてゼロの片側にあること、位置が非常に離れていること、ボックスを押すと他の人が特別な位置を通過することになる状況などが含まれます。 すべての動きをシミュレートしたり、ボックスと特別な位置の間のすべての組み合わせを試したりするという単純なアプローチでは、パフォーマンスと正確性の両方で失敗します。 たとえば、1 のボックスは 6 までプッシュできますが、5 のボックスは 7 までしか到達できない場合、最も近いボックスを最も近い特別な位置に盲目的にペアリングすると、一致を最大化できません。 

## アプローチ

 ブルートフォースアプローチでは、開始点から可能なすべてのプッシュシーケンスをシミュレートし、どのボックスがどの特別な位置に到達するかをチェックしようとします。 ボックスごとに、左右に移動したり、ボックスのチェーンを押したり、特別な位置が埋まったときにマークを付けたりすることができます。 この方法は原理的には正しいですが、移動数は n との組み合わせで増加するため、テスト ケースごとに O(2^n) 回、または少なくとも O(n·m) 回の操作が必要になります。これは、n、m が 2×10^5 までの場合はまったく実行不可能です。 

重要な洞察は、問題を数直線の負の側と正の側に分離することで得られます。 移動とプッシュはゼロを挟んで独立しています。左側のボックスは右側の特別な位置に到達するのに役立ちませんし、その逆も同様です。 それぞれの側内で、問題はマッチングの問題に帰着します。つまり、ボックスが既に存在する方向の特別な位置に到達できるボックスの数を最大化したいと考えます。 すべての位置がソートされているため、各ボックスの到達可能な特別な位置のセットは連続しています。 2 ポインターまたは二分探索手法を使用して、最も近い特別な位置に到達できるボックスの数を効率的にカウントできます。 

具体的には、片側については、同じ符号を持つボックスと特別な位置のみに焦点を当てます。 次に、特別な位置のプレフィックスごとに、それらに到達するために必要なボックスの最小数を決定します。 初期の重なりを素早く検索するためのセットと、すでに特別な位置にあるボックスのサフィックス数を使用して、片側あたり O(n + m) 時間で一致できる最適なボックスの数を計算します。 左と右の結果を組み合わせると、テスト ケースの答えが得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n・m) | O(n + m) | 遅すぎる |
 | 2 ポインター / プレフィックス マッチング | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 問題を 2 つの独立した部分、つまり負の値を持つボックスと特別な位置、および正の値を持つボックスと特別な位置に分割します。 押してもボックスは一方向にのみ移動するため、これは有効です。 どのボックスも一方の側からもう一方の側までゼロを横切ることはできません。 
2. ネガティブ リストを反転して、ゼロからの距離の増加シーケンスとして処理します。 これによりロジックが簡素化され、両側を対称的に処理できるようになります。 
3. 各側に対して、定数時間ルックアップ用の特別な位置のセットを作成します。 すでに特別な位置にあるボックスを数えて、ベースラインの一致数を形成します。 
4. 残りのボックスと特別な位置については、ボックスの末尾を到達可能な特別な位置に揃える問題として扱います。 特別な位置を逆に反復し、それに到達できる最も近いボックスへのポインターを維持します。 
5. 各特別な位置について、それがすでに占有されているかどうかを確認します。 そうでない場合は、二分探索または 2 ポインター手法を使用して、特別な位置の連続ブロックに到達できる最大の連続ブロックのボックスを決定します。 それに応じて最大一致数を更新します。 
6. 両側の結果を合計して、特別な位置を占めることができるボックスの合計最大数を取得します。 

**機能する理由:** このアルゴリズムは、各ボックスがその側面の位置が増加する方向にのみ移動できるという不変条件を維持します。 最も遠い特別な位置から逆方向に作業することで、物理的に押し込むことができない特別な位置にボックスが到達したとみなされることがないことを保証します。 すでに占有されているポジションと到達可能なポジションを組み合わせることで、二重カウントがなくなり、合計が最大化されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from bisect import bisect_right

def max_boxes(boxes, specials):
    boxes_set = set(boxes)
    specials_set = set(specials)
    
    # Count boxes already on special positions
    initial = len(boxes_set & specials_set)
    
    # Filter positions not already matched
    boxes = [x for x in boxes if x not in specials_set]
    specials = [x for x in specials if x not in boxes_set]
    
    if not boxes or not specials:
        return initial
    
    # Precompute suffix counts of specials
    specials_suffix = [0]*len(specials)
    specials_set_tmp = set(specials)
    for i in range(len(specials)-1, -1, -1):
        specials_suffix[i] = 1 + (specials_suffix[i+1] if i+1 < len(specials) else 0)
    
    res = 0
    j = len(boxes)-1
    for i in range(len(specials)-1, -1, -1):
        while j >= 0 and boxes[j] > specials[i]:
            j -= 1
        reachable = len([b for b in boxes[:j+1] if b + (len(boxes) - (j+1)) >= specials[i]])
        res = max(res, reachable + specials_suffix[i])
    
    return initial + res

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        # Split into negative and positive sides
        a_neg = [-x for x in a if x < 0][::-1]
        a_pos = [x for x in a if x > 0]
        b_neg = [-x for x in b if x < 0][::-1]
        b_pos = [x for x in b if x > 0]
        
        ans = max_boxes(a_neg, b_neg) + max_boxes(a_pos, b_pos)
        print(ans)

if __name__ == "__main__":
    solve()
```この解決策では、まず負の位置と正の位置を分離して、それぞれの側を独立して処理します。 すでに特別な位置にあるボックスをカウントし、一致する位置をフィルターし、到達可能なブロックを計算します。 負の位置を反転すると、対称的な処理が可能になります。 2 ポインター スキャンとサフィックス カウントを組み合わせることで、二重にカウントしたり、到達可能なボックスをスキップしたりすることなく、すべての最大一致が確実にカウントされます。
