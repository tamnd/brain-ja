 ## 解決策
 ## 問題の理解

 ジャンクションと道路のある都市を表す有向グラフが与えられます。 ウルパルはジャンクション _a_ から出発し、バスを使用してジャンクション _b_ に到達したいと考えています。 各バスは会社によって管理されており、開始ジャンクション _s_i_ から目的地 _t_i_ までの最短経路を毎秒ランダムに選択します。 ウルパルは、同じ時間に同じジャンクションにいる場合にのみバスに乗ることができ、一度乗車したバス会社しか知りません。 目標は、最悪の場合にジャンクション _b_ に到達することを保証するためにウルパルが利用しなければならないバスの最小数、またはそれが不可能な場合は -1 を見つけることです。 

制約は控えめで、ジャンクション数は最大 100 個、バス数は 100 個までです。 これにより、3 次または 2 次の複雑さを持つアルゴリズムを使用できるようになります。 すべての道路の長さは等しいため、ダイクストラのアルゴリズムではなく単純な幅優先探索 (BFS) によって最短パスを測定できます。 考えられるすべてのランダムなバス パスをシミュレートする単純なアプローチでは、各バスが多くの最短パスを通過する可能性があるため、組み合わせが爆発的に増加します。 

明らかではないエッジケースには、バス会社が始点から終点までの経路を持たない状況が含まれます。 たとえば、グラフにジャンクション 1 → 2 および 2 → 3 があり、バスが 3 → 1 に移動する場合、ウルパルはそのバスに乗車できません。 もう 1 つの微妙なケースは、複数のバスが部分的に重複する場合に発生します。ソリューションでは、パスだけでなく、最悪の場合のバスのシーケンスも考慮する必要があります。 

## アプローチ

 強引なアプローチは、考えられるすべてのバス シーケンスとパスの組み合わせを列挙し、Urpal がそれぞれの目的地に到達できるかどうかを確認することです。 これは原理的には正しいですが、各バスには潜在的に多くのパスがあり、シーケンスが指数関数的に増加するため、計算上実行不可能です。 最悪の場合、100 個のバスとそれぞれ複数の最短パスがある場合、2^100 を超えるシーケンスを試行することになりますが、これは明らかに不可能です。 

重要な洞察は、これをジャンクションのグラフ上の動的計画問題としてモデル化することです。 すべてのランダムな選択をシミュレートする代わりに、最悪の場合に目的地に到着するために必要なバスの最小数をジャンクションごとに計算できます。 このために、BFS を使用してすべてのペア間の最短パスを事前計算します。 次に、ジャンクションごとに、どのバスがウルパルをジャンクション _b_ に近づけることができるかを追跡します。 バス会社がジャンクションを通過する最短経路を持っている場合、バスが降車できる場所に基づいて、そのジャンクションの「必要なバス」を更新できます。 これらの値を宛先から逆方向に伝播することで、最悪のシナリオを確実に考慮することができます。 

ブルート フォースと最適なアプローチの違いは、シーケンスをシミュレートする代わりに、最短パスの構造を使用して到達可能性について決定論的に推論することです。 最悪の場合の最小バスは、ウルパルが保証されたパスに沿って取らなければならない最長のバス チェーンに対応します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k^パス * n) | O(n*k) | 遅すぎる |
 | 最適 | O(k*n^2 + n^3) | O(n^2 + k*n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての道路の重みが等しいため、BFS を使用してすべてのジャンクションから他のすべてのジャンクションまでの最短距離を計算します。 これを 2D 配列に格納します`dist[u][v]`。 これにより、バスの経路が最短経路であるかどうかを確認し、その経路に沿って到達可能なジャンクションを計算できます。 
2. DP 配列を初期化する`dp[u]`ジャンクション _u_ からジャンクション _b_ に到達するために必要なバスの最小数を表します。 セット`dp[b] = 0`なぜなら目的地にはバスが必要ないからです。 
3. 各バス会社ごと`i`1 から k までの最短パスに沿ってウルパルをドロップできるジャンクションのセットを計算します。`s_i`に`t_i`。 ジャンクション`v`バスでアクセス可能です`i`もし`dist[s_i][v] + dist[v][t_i] == dist[s_i][t_i]`。 これにより、最短パスのみを考慮することが保証されます。 
4. これらの到達可能なセットを使用して DP 値を逆方向に伝播します。 各ジャンクションごとに`u`、通過するすべてのバスを考慮します。`u`。 アップデート`dp[u]`として`1 + max(dp[v] for v reachable from u by this bus)`。 の`max`最悪のシナリオを説明します。バスの数の観点から、必要な最も遠い場所でバスが彼を降ろす可能性があると想定します。 
5. DP 値が変化しなくなるまでステップ 4 を繰り返します。 収束後であれば、`dp[a]`が無限である場合は、-1 を出力します。 それ以外の場合は、印刷します`dp[a]`。 
6. このアルゴリズムでは、常に各バスの最悪のドロップ位置を選択し、安定するまで反復し、ミニマックス動的プログラミングを効果的に実行するため、正確性が保証されます。 

## Python ソリューション```python
import sys
from collections import deque
input = sys.stdin.readline

def bfs(n, graph, start):
    dist = [float('inf')] * (n + 1)
    dist[start] = 0
    queue = deque([start])
    while queue:
        u = queue.popleft()
        for v in graph[u]:
            if dist[v] == float('inf'):
                dist[v] = dist[u] + 1
                queue.append(v)
    return dist

def main():
    n, m, a, b = map(int, input().split())
    graph = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        graph[u].append(v)
    
    k = int(input())
    buses = []
    for _ in range(k):
        s, t = map(int, input().split())
        buses.append((s, t))
    
    # shortest distances from all nodes
    dist = [bfs(n, graph, u) for u in range(n + 1)]
    
    INF = 10**9
    dp = [INF] * (n + 1)
    dp[b] = 0
    
    changed = True
    while changed:
        changed = False
        for u in range(1, n + 1):
            if u == b:
                continue
            best = dp[u]
            for s, t in buses:
                if dist[s][t] == float('inf') or dist[s][u] == float('inf') or dist[u][t] == float('inf'):
                    continue
                if dist[s][u] + dist[u][t] == dist[s][t]:
                    worst = 0
                    for v in range(1, n + 1):
                        if dist[s][v] + dist[v][t] == dist[s][t]:
                            worst = max(worst, dp[v])
                    best = min(best, 1 + worst)
            if best != dp[u]:
                dp[u] = best
                changed = True
    
    print(-1 if dp[a] >= INF else dp[a])

if __name__ == "__main__":
    main()
```BFS は最短距離を事前計算して、ジャンクションが各バスの最短パス上にあるかどうかを確認します。 DP 配列は、必要な最小限のバスを表します。 を使用して、安定するまで最悪の場合の値を伝播します。`max`最悪の場合の落下場所に対処するため、`min`最悪のシナリオでのバスの最小数を見つけます。 到達不能なバスなどのエッジケースは、次のコマンドを使用してバスを無視することで処理されます。`inf`距離。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n^3 + k*n^2) | 各ノードからの BFS は、n ノード O(n^3) の場合、O(n + m) ≈ O(n^2) です。 DP 伝播は、n ノードの k バス上で繰り返し反復されますが、O(n) ラウンドで安定します。 |
 | スペース | O(n^2 + k*n) | 距離行列 n^2、グラフ、バス O(k*n)。 |

 n ≤ 100 および k ≤ 100 の場合、これは 2 秒未満で快適に実行されます。
