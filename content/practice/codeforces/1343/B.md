 ## 解決策
 ## 問題の理解

 長さの配列を構築するように求められます$n$ここで、前半は個別の偶数の正の整数で構成され、後半は個別の奇数の正の整数で構成され、2 つの半分の合計は等しいです。 入力は複数の独立したテスト ケースを与え、それぞれが偶数の整数を指定します。$n$。 有効な配列が存在しない場合、出力は「NO」になります。$n$、または「YES」の後に 1 つの有効な配列が続きます。 

以来$n$と同じ大きさにすることができます$2 \cdot 10^5$と合計$n$すべてのテスト ケースが同じ値に制限されているため、次の値を目指す必要があります。$O(n)$またはテストケースごとのより良いソリューション。 二次的な複雑さを伴うアプローチや、広い範囲を繰り返し反復するアプローチは、制限時間を超過する可能性があります。 

注意すべき特殊なケースは次のような場合です$n$とても小さいです、みたいな$n = 2$。 この場合、前半が偶数１つ、後半が奇数１つとなります。 合計が一致する必要があります。 のために$n = 2$、最も単純な偶数は 2 で、最も単純な奇数は 1 であり、その合計が一致しないため、解は存在しません。 もう一つの微妙な点は、$n/2$奇数です。 この場合、最初の合計のバランスを取ろうとします。$n/2$偶数の和$n/2$異なる正の整数を使用した奇数は不可能であることが判明しました。 

## アプローチ

 ブルートフォース手法では、次のすべての組み合わせが試行されます。$n/2$偶数と$n/2$奇数の場合は、合計が一致するかどうかを確認します。 これは正しいですが、組み合わせの数が指数関数的に増加するため、計算上実行不可能です。 合計が一致するまで単純なシーケンスを繰り返すだけでも遅すぎます。$n = 10^5$。 

重要な洞察は、最初の値の合計が$n/2$連続する偶数は常に次の数で割り切れます。$n/2$、最初の合計$n/2$連続する奇数も次のように割り切れます。$n/2$。 もし$n/2$が偶数である場合、最初の式を取ることで簡単な解を構築できます。$n/2$丁数$2,4,6,\dots$そして最初の$n/2 - 1$奇数$1,3,5,\dots$そして最後の奇数を調整して合計のバランスをとります。 もし$n/2$が奇数の場合、この調整では前の奇数とは異なる正の整数を生成できないため、解決策は存在しません。 

これは、線形構成アルゴリズムに直接つながります。前半を連続する偶数として生成し、後半の最後を除くすべてを連続する奇数として生成し、合計のバランスを取るために必要な最後の奇数を計算します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((n/2)! * (n/2)!) | O(n) | 遅すぎる |
 | 建設的 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$。 もし$n/2$が奇数である場合は、合計のバランスをとることが不可能であるため、「NO」と出力します。 
3. それ以外の場合は、空の配列を初期化します。 させて$half = n/2$。 
4. 最初の文字列を追加します$half$丁数$2,4,6,\dots,2*half$配列に。 これにより、前半で明確な正の偶数が保証されます。 
5. 最初の文字列を追加します$half-1$奇数$1,3,5,\dots,2*(half-1)-1$配列に。 
6. 最後の奇数を、偶数の合計と最初の数の合計の差として計算します。$half-1$奇数。 それを配列に追加します。 これにより、両方の半分の合計が等しいことが保証されます。 
7. 「YES」に続いて、構築された配列を出力します。 

機能する理由: 構造上、前半には明確な偶数が含まれ、後半には明確な奇数が含まれます。 前半の合計は$half*(half+1)$2 を 2 で割る? 実際には、より注意深く、最初の合計$half$偶数は$half*(half+1)$。 最初の合計$half-1$奇数は$(half-1)^2$。 最後の奇数は、$half*(half+1) - (half-1)^2 = 3*half -1$、これは正の値であり、前の奇数よりも大きいことが保証されています。 これにより、合計が一致し、すべての数値が異なることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    half = n // 2
    if half % 2 != 0:
        print("NO")
        continue
    
    even_part = [2 * i for i in range(1, half + 1)]
    odd_part = [2 * i - 1 for i in range(1, half)]
    last_odd = sum(even_part) - sum(odd_part)
    odd_part.append(last_odd)
    
    print("YES")
    print(*even_part, *odd_part)
```コードはまず、次のような不可能なケースを処理します。$n/2$奇数です。「NO」と表示されます。 他のすべてのケースでは、2 つの半分が効率的に構築されます。 Python のアンパック演算子の使用`*`配列を 1 行に出力します。 すべての算術は範囲内で安全です。$n\le 2\cdot 10^5$生成された最大数は以下に残ります$10^9$。

        print("YES")
        print(*even_part, *odd_part)
    return output.getvalue().strip()
