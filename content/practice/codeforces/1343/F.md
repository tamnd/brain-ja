 ## 解決策
 ## 問題の理解

 私たちには、1 から n までの未知の数の順列が与えられています。 直接見る代わりに、n−1 個の情報を受け取ります。各部分は順列から取得されたマルチセット セグメントです。 各セグメントは元々、隠れた順列内の連続した区間から取得されたものですが、私たちに与えられる前に、その区間内の値が昇順にソートされて渡されました。 

したがって、各入力行はもはやサブ配列ではなく、未知のサブ配列のソートされたスナップショットです。 どの間隔でどのスナップショットが生成されたかは通知されず、セグメントはシャッフルされます。 

タスクは、これらすべてのソートされた間隔スナップショットを生成した可能性のある順列を再構築することです。 

主要な構造上の制約は、すべてのセグメントが何らかの区間 [l, r] に対応し、2 から n までのすべての r にわたって、各 r でちょうど 1 つの区間が終了するということです。 これにより、個々のセグメントが位置情報を失ったとしても、非常に厳格なグローバル構造が保証されます。 

制約は小さく、テスト全体の合計 n は最大 200 です。これにより、重度の漸近最適化の必要性がすぐになくなります。 O(n²) または O(n² log n) 程度の解決策で十分ですが、本当の課題は速度ではなく、順序のない間隔データから位置構造を復元することです。 

単純な解釈の間違いは、各セグメントを間隔とは独立した単なる設定された制約であるかのように扱うことです。 たとえば、周波数または最小値のみに基づいて値を貪欲に割り当てようとすると、同じ値が多くの重複する間隔に関与し、その正確な位置を決定するローカルなものが何もないため、失敗します。 

もう 1 つの一般的な障害モードは、セグメント内の最小値または最大値によって順列のエンドポイントが決定されると想定することです。 ソートでは値の構造ではなく位置情報が破壊されるため、これは真実ではありません。 

正しい解決策は、セグメント全体で繰り返される共起構造から値間の隣接制約を抽出し、それらの制約と一致する一意のハミルトニアン パスとして順列を再構築することに依存しています。 

## アプローチ

 ブルートフォース手法では、各セグメントを可能な区間 [l, r] に割り当て、すべてのセグメントと一致する順列が存在するかどうかをチェックします。 これはすぐに実行不可能になります。なぜなら、中程度の n の場合でも、セグメントを間隔に一致させる方法の数はサイズの階乗であり、各割り当てには完全な順列再構成に対する検証が必要だからです。 

重要な観察は、どのセグメントがどの r に対応するかを実際に知る必要がないということです。 代わりに、各セグメントは、最終的な並べ替えで互いに隣り合って現れる必要がある要素間の隣接情報を暗黙的にエンコードします。 セグメントが並べ替えられている場合でも、元の間隔での隣接性は痕跡を残します。つまり、狭いセグメントにわたって頻繁に一緒に出現する要素は、順列で隣接する傾向があります。 

構造上の画期的な点は、各セグメントを隠れた順列の連続する要素に対するクリーク制約として解釈することです。 2 つの値が常に最小スパンのセグメントに同時に表示される場合、それらは基本的な順序で隣接している必要があります。 これらの隣接エッジが回復されると、順列はグラフの問題になります。つまり、すべてのノードに 1 回だけアクセスするパスを探します。 

これにより、タスクが値 1..n の無向グラフの構築とハミルトニアン パスの回復に減ります。 制約により、このグラフが正確にパスであることが保証されるため、再構成は方向まで決定的になります。

## アルゴリズムのチュートリアル

 1. すべてのセグメントを、ソートされた値のリストとして扱います。 各セグメントについて、その並べ替えられたリスト内の連続する要素のすべてのペアを考慮し、それらを無向エッジで接続します。 

直感的には、並べ替えられた順序で隣接する値は、置換の同じローカル領域に属することが多く、重複する間隔によって引き起こされる最終的な順序構造では隣接して表示されるはずです。 
2. これらのエッジを使用して頂点 1..n に無向グラフを構築し、重複をマージします。 

このグラフは一貫性の制約を捉えています。つまり、有効な順列は、すべてのセグメントによって引き起こされるすべての隣接関係を尊重する必要があります。 
3. 結果として得られるグラフは単純なパスを形成する必要があることに注意してください。 したがって、すべてのノードの次数は最大 2 であり、ちょうど 2 つのノードの次数は 1 になります。 
4. 任意のエンドポイント ノード (次数 1) から開始し、常に次の未訪問の近傍に移動してグラフをウォークスルーします。 

パス グラフには 2 つの可能なハミルトニアン トラバーサル (順方向または逆方向) があるため、この走査は置換順序を一意に再構築します。 
5. この走査から得られたシーケンスを出力します。 

### なぜ効果があるのか

 各セグメントは、隠れた順列の連続する間隔に対応します。 このような間隔内では、値の順序が近い値は、それらを含むすべての間隔を考慮した場合、隣接する位置に繰り返し現れる傾向があります。 この繰り返しの共起により、構築されたグラフ内でそれらが強制的に接続されます。 元の順列は全順序であるため、隣接グラフは区間の一貫性と矛盾せずに分岐できず、単一のパスに崩壊します。 再構成ステップでは、この強制された線形構造を読み取るだけです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        adj = [[] for _ in range(n + 1)]

        for _ in range(n - 1):
            tmp = list(map(int, input().split()))
            k = tmp[0]
            arr = tmp[1:]

            for i in range(k - 1):
                a, b = arr[i], arr[i + 1]
                adj[a].append(b)
                adj[b].append(a)

        # find endpoint
        start = 1
        for i in range(1, n + 1):
            if len(adj[i]) == 1:
                start = i
                break

        # traverse path
        res = []
        visited = [False] * (n + 1)

        prev = -1
        cur = start

        while True:
            res.append(cur)
            visited[cur] = True
            nxt = -1
            for v in adj[cur]:
                if v != prev:
                    nxt = v
                    break
            if nxt == -1:
                break
            prev, cur = cur, nxt

        print(*res)

if __name__ == "__main__":
    solve()
```このコードは、並べ替えられた各セグメントをスキャンし、連続する値を接続することによって隣接リストを構築します。 これは、セグメント内の順序付けが使用される唯一の場所です。 それ以外はすべてグラフ構造に依存します。 

トラバーサルでは単純な親ポインターを使用して、後戻りを回避します。 グラフはパスであることが保証されているため、トラバーサル中に各ノードには最大でも 1 つの前方隣接ノードがあり、ウォークは決定的になります。 

実装の微妙な詳細は、有効な開始ノードの選択です。 パスの端点はまさに 1 つの近傍を持つノードであるため、次数 1 のノードはすべて有効です。 最初のそのようなノードを選択するだけで十分です。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        adj = [[] for _ in range(n + 1)]

            arr = tmp[1:]
            for i in range(k - 1):
                a, b = arr[i], arr[i + 1]
                adj[a].append(b)
                adj[b].append(a)

                    nxt = v
                    break
            if nxt == -1:
                break
            prev, cur = cur, nxt

        out.append(" ".join(map(str, res)))

    return "\n".join(out)

 ## 特殊なケース

 例外的なケースは、順列がトラバース方向と比較して完全に逆になっている場合に発生します。 構築されたグラフは方向をエンコードせず、隣接性のみをエンコードするため、いずれかのエンドポイントから開始すると、有効な逆順列が生成されます。 この問題では任意の有効な答えが許容されるため、両方を受け入れます。 

もう 1 つのエッジ ケースは、複数のセグメントに同一の隣接情報が含まれる場合です。 グラフの構築により重複したエッジが追加される可能性がありますが、トラバーサルはエッジの多重度ではなく接続性にのみ依存するため、これは正確さに影響しません。
