 ## 解決策
 ## 問題の理解

 正と負の両方の整数のシーケンスが与えられ、要素の符号が厳密に交互になるサブシーケンスを構築する必要があります。 可能な最大長に達するすべての部分列の中で、最大の合計を持つ部分列を見つけるように求められます。 各テスト ケースの出力はその合計です。 

各テスト ケースでは、シーケンス自体が後に続く要素の数が提供されます。 制約は重要です。テスト ケースにわたるすべてのシーケンスの長さの合計は 200,000 を超えないため、ソリューションはテスト ケースごとに線形時間で実行する必要があります。 考えられるすべてのサブシーケンスをチェックするなどの 2 次解は実行不可能です。 

連続する要素が同じ符号を持つ場合、微妙なエッジケースが発生します。 たとえば、入力が次の場合`[1, 2, 3, -1, -2]`、最大交互サブシーケンスは、負に切り替える前に最大の正を選択し、次に再び切り替える前に最大の負を選択します。 すべての要素を単に交互に配置しても、合計を最大化することはできません。 別の厄介なケースは、すべての要素が同じ符号である場合に発生します。`[-1, -2, -3]`、最長の交互部分列の長さは 1 であり、正解は最大の要素です。`-1`。 

## アプローチ

 ブルートフォース手法では、考えられるすべてのサブシーケンスを生成し、どの符号が交互に現れるかを確認し、長さが最も大きいものを選択し、合計が最大のものを選択します。 これは正しいですが、完全に非現実的です。サブシーケンスの生成には O(2^n) が必要で、n は最大 2 × 10^5 になります。 

効率的な解決策を可能にする重要な観察は、同じ符号を持つ連続した数値セグメント内では、常に最大の数値のみが必要であるということです。 より小さい数を含めると、交互のサブシーケンスの長さを延長することなく合計が減少します。 したがって、シーケンスは同じ符号を持つ連続した数字の「ブロック」に圧縮でき、ブロックごとに最大の要素が選択されます。 圧縮したら、これらの最大要素を交互に合計するだけで最適なソリューションが得られます。 

したがって、最適なアプローチは、シーケンスを反復処理し、現在の符号ブロックの最大値を維持し、符号の変化が発生するたびにそれを合計に加算することにより、線形時間で機能します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.初期化`sum_total`ゼロに。 これにより、選択した交互のサブシーケンスの合計が保存されます。 
2.セット`current_max`シーケンスの最初の要素に。 これにより、現在の符号ブロック内の最大の要素が追跡されます。 
3. 2 番目の要素からのシーケンスを繰り返します。 各要素について:

 1. 符号が一致する場合`current_max`、 アップデート`current_max`2 つのうち大きい方に。 これにより、現在の符号ブロック内に最大の数値のみが保持されることが保証されます。 
2. 符号が異なる場合は追加します。`current_max`に`sum_total`そしてセット`current_max`この新しい要素に追加して、新しい記号ブロックを開始します。 
4. 反復の後、最後のものを追加します。`current_max`に`sum_total`。 これは最後のブロックを処理します。 
5. 印刷`sum_total`。 

なぜ機能するのか: 不変条件は、どの時点でも、`current_max`現在の連続符号ブロックの最大要素を保持します。 交互のサブシーケンスでは各要素の符号を切り替える必要があるため、各ブロックで最大のものを選択すると、サブシーケンスの長さを減らすことなく合計が最大になります。 これにより、結果が最大長の交互サブシーケンスの最大合計となることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    sum_total = 0
    current_max = a[0]
    
    for i in range(1, n):
        if (a[i] > 0) == (current_max > 0):
            current_max = max(current_max, a[i])
        else:
            sum_total += current_max
            current_max = a[i]
    
    sum_total += current_max
    print(sum_total)
```各部分はアルゴリズムから直接続きます。`current_max`現在の符号ブロックの最大値を保持します。 比較`(a[i] > 0) == (current_max > 0)`現在の要素が前のブロックと同じ符号を持つかどうかをチェックします。 追加`current_max`最後に、最後のブロックが確実に考慮されるようにします。 これにより、off-by-one エラーが回避され、完全に正または負のシーケンスに対して機能します。
