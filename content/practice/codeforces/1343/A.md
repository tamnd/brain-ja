 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$。 目標は表現を見つけることです$n = x(2^k - 1)$。 
2. 可能な値を反復処理します。$k$から始まる$k = 2$問題が明示的に禁止しているため$k = 1$。 
3. それぞれについて$k$、乗数を計算します$m = 2^k - 1$。 
4. もし$m > n$、大きなチェックをやめてください$k$なぜなら、将来の乗数はすべて増加するだけだからです。 
5. もし$n \mod m = 0$、計算する$x = n / m$そしてすぐに出力します。 

この貪欲な停止が機能する理由は、幾何学的な要因が超過すると、$n$、分割できなくなります。

 すべての有効な構成は、形式の因数分解に対応します。$n = x(2^k - 1)$。 このアルゴリズムは、2 番目の要素のすべての可能な値を体系的に列挙します。$2^k - 1$以内に収まるかもしれない$n$。 これらの値は厳密に増加しているため、$k$が存在する場合、正しいものが存在することが保証されます。 見つかったら、除算により一意の対応する値を回復します。$x$。

 ## 特殊なケース

 主なエッジケースは次のような場合です$n$それ自体が形である$2^k - 1$。 例えば、$n = 7$。 アルゴリズムは次から始まります$k = 2$、小切手$3$、に移動します$7$、すぐに割り切れることがわかり、生成されます。$x = 1$。 これは、1 から始まる完全な幾何学的シーケンスに対応します。 

もう一つのケースは次のような場合です。$n$小さな乗数では割り切れませんが、後で割り切れるようになります$k$、 のような$n = 28$。 ループがスキップします$k = 2$以来$28 \bmod 3 \neq 0$、次に成功します$k = 3$乗算器付き$7$、降伏$x = 4$。 このアルゴリズムは早期にコミットしないため、後の有効な分解を見逃すことはありません。
