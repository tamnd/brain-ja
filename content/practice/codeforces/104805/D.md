 ## 解決策
 ## 問題の理解

 単一の整数が与えられます$n$そして、ある辺の長さの正方形の絵画を構築できるかどうかを判断する必要があります。$k$、 どこ$k \le n$、「絵画」の非常に特殊な解釈の下で。 

絵は単なる細胞の均一なグリッドではありません。 代わりに、次の要素の分解を表す必要があります。$k \times k$正方形を軸に沿った小さな正方形に分割し、それぞれが重なりや隙間なくキャンバスを完全にカバーします。 これらの小さな正方形のそれぞれに、4 つの色のいずれかが割り当てられます。 最終的に表示される出力は、次のサイズのグリッドです。$k \times k$ここで、すべての単位セルは、それが属する小さな正方形の色を継承します。 

隣接性には追加の制約があります。2 つの色の付いた領域が側面全体に沿って接触している場合、それらの領域は異なる色でなければなりません。 角だけ触っても問題ありません。 

したがって、タスクは基本的に有効な値を選択することです。$k$のタイリングを構築します$k \times k$グリッドを正方形に分割し、エッジを共有する 2 つの正方形が異なる色になるように、それらの正方形を 4 色で色付けします。 そのような構造が存在しない場合は、次のように出力します。$-1$。 

制約$n \le 1000$パーティションや幾何学的構造に対する大量の検索を伴うソリューションは遅すぎることを示唆しています。 すべての正方形の分割を列挙する強引な試みは爆発的に増加します。これは、グリッドの可能な正方形タイリングの数が面積とともに超多項式に増加するためです。 

サンプルには、より微妙な制約が隠されています。 いつ$n = 1$、解決策は自明のことです。 いつ$n = 2$または$n = 3$、解決策は存在しません。 これはすぐに、すべてがそうではないことを示唆しています。$n$着色力に関係なく、有効な幾何学的分解も可能になります。 

重要な構造上の制限は、全体が完全に一致している場合にのみ構築が可能であるということです。$k \times k$グリッドは単位正方形への分割として解釈できます。つまり、$n = k^2$。 他の不均等な正方形への分解では、厄介な残りの領域や互換性のない境界構造が強制的に作成されます。 

単純な間違いは、正方形をいつでも任意の数の小さな正方形にタイリングできると仮定することです。 たとえば、次のように分解しようとするかもしれません。$3 \times 3$グリッドを 3 つの正方形に分割しますが、どのような試みも必然的に長方形の断片が残るか、各断片自体が正方形であるという要件に違反します。 

もう 1 つのよくある落とし穴は、一度グリッドが与えられたら常に 4 色で十分であると仮定して、色のみに焦点を当てることです。 これは固定グリッドの場合には当てはまりますが、本当の難しさは、グリッドの分解自体が特定のグリッドに対して可能かどうかにあります。$n$。 

## アプローチ

 ブルートフォースアプローチでは、可能なすべてのタイリングを生成しようとします。$k \times k$正確にグリッドを入れる$n$それぞれの小さな正方形$k \le n$を選択し、有効なカラーリングが存在するかどうかをテストします。 中程度の場合でも$k$、正方形の各配置が分岐する形で将来の配置を制限するため、正方形タイリングの数は膨大になります。 これにより、ジオメトリとパーティション構造の両方で指数関数的な検索スペースが得られます。 

重要な観察は、幾何学的条件が最初に見えたよりもはるかに厳しいということです。 一般に、正方形を任意の数の小さな正方形に分解することはできません。 実際、領域を正確にカバーする、重なり合わない軸に沿った正方形に限定すると、$k \times k$領域において、常に機能する最も単純かつ唯一の均一な構造は、単位を次のように分解することです。$k^2$細胞。 

一貫して有効な唯一の構造が完全なユニット グリッドであることを受け入れると、問題は次の選択に集約されます。$k$そのような$n = k^2$。 その後、残りのタスクは純粋にグリッド上のグラフの色付けの問題になり、4 色すべてを使用する繰り返し 2x2 パターンを使用して解決できます。 

したがって、問題全体は、次のことを確認することに帰着します。$n$は完全な正方形です。 そうでない場合、有効な構造は存在しません。 そうであれば、設定します$k = \sqrt{n}$固定の周期パターンを使用してグリッドに色を付けます。

 ## アルゴリズムのチュートリアル

 ### アルゴリズムのチュートリアル

 1. コンピューティング$k = \lfloor \sqrt{n} \rfloor$かどうかを確認してください$k \cdot k = n$。 そうでない場合は、一貫した正方形のタイリングを形成する方法がないため、すぐに出力します。$-1$。 非正方形の領域は均一な領域に分解できないため、拒否が早期に発生します。$k \times k$残りのジオメトリを導入せずに正方形のブロックのグリッドを作成します。 
2. キャンバスのサイズを次のように設定します。$k \times k$。 この時点で、各セルを個別の正方形領域として解釈します。 
3. グリッド全体で繰り返される 2x2 パターンを使用して色を割り当てます。 座標のセルの場合$(i, j)$、ペアをマッピングします$(i \bmod 2, j \bmod 2)$4色のうちの1色に$\{Y, O, P, L\}$。 これにより、水平または垂直に隣接する 2 つのセルの色が異なることが保証されます。 
4. 出力$k$続いて構築されたグリッド。 

### なぜ効果があるのか

 正しさは 2 つの構造的特性に基づいています。 まず、建設は次の場合にのみ進行します。$n$は完全な正方形です。つまり、グリッドは均一なものとして解釈できます。$k \times k$分解。 There is no need for higher-level square partitioning because each unit cell already forms a valid square region.

 第 2 に、カラーリング機能により、隣接するセル間のすべてのエッジが 2x2 期間にわたって 2D チェッカーボード内の 2 つの異なるパリティ ペアを接続することが保証されます。 Since every horizontal or vertical move flips at least one coordinate parity, adjacent cells always receive distinct colors. This satisfies the constraint for all touching regions.

 ## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input().strip())

k = int(n ** 0.5)
if k * k != n:
    print(-1)
    sys.exit()

colors = ['Y', 'O', 'P', 'L']

# 2x2 periodic assignment
mapping = {
    (0, 0): 'Y',
    (0, 1): 'O',
    (1, 0): 'P',
    (1, 1): 'L'
}

print(k)
for i in range(k):
    row = []
    for j in range(k):
        row.append(mapping[(i % 2, j % 2)])
    print(''.join(row))
```このソリューションでは、まず入力が完全な正方形を形成しているかどうかを検証します。 このステップは、一貫した正方形のタイルに対応できないサイズのグリッドを構築しようとするのを防ぐため、非常に重要です。 

次に、決定論的な周期パターンを使用してグリッドが塗りつぶされます。 2x2 マッピングの選択は重要です。これは、隣接制約が両方向で満たされることを保証しながら 4 つの異なる色を保証する最小のパターンであるためです。 

微妙な点は、整数の平方根を慎重に扱う必要があることです。 浮動小数点 sqrt を検証せずに直接使用すると、精度の問題が発生する可能性があるため、整数チェック$k \cdot k = n$が必要です。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math

    n = int(input().strip())

    k = int(n ** 0.5)
    if k * k != n:
        return "-1"

    mapping = {
        (0, 0): 'Y',
        (0, 1): 'O',
        (1, 0): 'P',
        (1, 1): 'L'

    out = [str(k)]

        row = []
        for j in range(k):
            row.append(mapping[(i % 2, j % 2)])
        out.append(''.join(row))
    return "\n".join(out)

 ## 特殊なケース

 のために$n = 1$、アルゴリズムは正しく識別します$k = 1$単一の色のセルを出力します。 隣接性の制約がないため、どの色の割り当ても有効で、固定マッピングでも正しい結果が得られます。 

次のような非正方形の値の場合$n = 2$または$n = 3$の場合、アルゴリズムはすぐに拒否します。 グリッドを構築しようとすると、非整数の辺の長さを暗黙的に仮定することになり、正方形のキャンバス パーティションの幾何学的解釈が崩れます。 

より大きな完全正方形の場合は、$n = 100$、構造はセルの数に応じて直線的に拡大します。 定期的なカラーリング パターンにより、ローカル パリティ チェックを超えたグローバルな調整を必要とせずに、隣接関係の分離が保証され続けます。
