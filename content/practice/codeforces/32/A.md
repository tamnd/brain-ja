 ## 解決策
 ## 問題の理解

 私たちは、分遣隊の何組の兵士が偵察部隊を構成できるかを数える任務を負っています。 ユニットは正確に 2 人の兵士で構成され、彼らの身長の差が所定のしきい値 _d_ を超えることはできません。 入力により、兵士の総数 _n_、許容される最大身長差 _d_、および兵士の身長のリストが得られます。 出力は、|height[i] − height[j]| のような有効な順序ペア (i, j) の数を表す単一の整数です。 ≤ d. ここでは順序付きペアが重要であるため、(i, j) は (j, i) とは異なります。 

制約は中程度です。n は最大 1000、高さは 10^9 まで可能です。 n が小さいため、O(n²) アプローチが実際には実現可能ですが、最適化することができます。 重要な点は、高さ自体が非常に大きくなる可能性があるため、高さによるインデックス付けに直接依存するアルゴリズム (周波数配列など) は実用的ではないということです。 

考慮すべきエッジケースには、すべての兵士の身長が同じである場合や、差 d が非常に小さい場合などがあります。 たとえば、n = 3、d = 0、および高さ = [5, 5, 6] の場合、同じ身長の兵士のペアのみが有効です。 不用意に実装すると、ペアの順序が過小評価されたり、考慮されなかったりする可能性があります。 

## アプローチ

 最も単純なアプローチは総当たりです。考えられるすべての兵士のペア (i、j) を反復処理し、身長差が最大でも d であるかどうかを確認します。 これが機能するのは、問題の要件を直接実装しているためです。 合計の操作数は n * (n − 1) で、n = 1000 の場合、約 100 万回になります。これは 2 秒の制限時間内では許容されますが、エレガントではありません。 

仕分けをすることで効率化が図れます。 身長の配列を降順でない順に並べ替えると、問題は簡単になります。各兵士について、身長差が d を超えるまで後続の兵士をチェックするだけで済みます。 ソートのコストは O(n log n) で、その後の各兵士の線形スキャンは合計で O(n) であるため、O(n log n) のソリューションが得られます。 重要な洞察は、ソートによって内側のループでの早期終了が可能になるということです。差が d を超えると、高さが増加しているため、残りの兵士もすべて制限を超えることがわかります。 

比較表は次のことを明確にしています。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | n ≤ 1000 の場合は許容可能 |
 | 並べ替え + 2 つのポインター | O(n log n) | お(1) | 最適かつ明確 |

 ## アルゴリズムのチュートリアル

 1. n、d、および兵士の身長のリストを読み取ります。 不要なオーバーヘッドを避けるために高速入力を使用します。 
2. 高さを昇順に並べ替えます。 これにより、任意の兵士 i について、後続のすべての兵士の身長がそれより高いか同じになることが保証されます。 
3. 有効な順序ペアの数を追跡するには、カウンターを 0 に初期化します。 
4. 0 から n − 1 までの各兵士 i について、兵士 j > i のチェックを開始します。 height[j] − height[i] ≤ d である限り、カウンターをインクリメントします。 height[j] − height[i] > d の場合、それ以上の j は条件を満たすことができないため、内側のループを直ちに中断します。 
5. すべての兵士をスキャンした後、カウンターを出力します。 

機能する理由: 並べ替えにより、ペアが許容身長差を超えると、同じ最初の兵士を持つその後のすべてのペアもその差を超えることが保証されます。 ループ構造により、外側のループがすべてのソルジャーに対して反復されるため、すべてのペアを 1 回だけチェックし、暗黙的に両方向をカウントします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, d = map(int, input().split())
heights = list(map(int, input().split()))
heights.sort()

count = 0

for i in range(n):
    for j in range(i + 1, n):
        if heights[j] - heights[i] <= d:
            count += 1
        else:
            break

# Each valid pair can be ordered in two ways
print(count * 2)
```コードはまず兵士の身長を並べ替えます。 ネストされたループは、すべての有効なペアを昇順に検査します。 各ペア (i, j) は (i, j) と (j, i) の両方の順序で現れる可能性があるため、最終的なカウントに 2 を掛けます。 境界条件は暗黙的に処理されます。内側のループは i + 1 で開始され、自己ペアを防止し、高さの差が d を超えるとすぐに中断されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n log n) | ソートが優先され、ブレークにより内側のループはすべての i に対して最大で n 回実行されます。 |
 | スペース | お(1) | その場で仕分けし、カウンターのみを保管。 |

 n ≤ 1000 の場合、ソートとリニア スキャンは簡単です。 メモリ使用量は 256 MB をはるかに下回っています。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, d = map(int, input().split())
    heights = list(map(int, input().split()))
    heights.sort()
    count = 0
    for i in range(n):
        for j in range(i + 1, n):
            if heights[j] - heights[i] <= d:
                count += 1
            else:
                break
    return str(count * 2)

# Provided sample
assert run("5 10\n10 20 50 60 65\n") == "6", "sample 1"

# Minimum-size input
assert run("1 5\n10\n") == "0", "minimum size"

# Maximum-size, all equal
assert run("1000 0\n" + " ".join(["42"]*1000) + "\n") == str(1000*999), "all equal"

# Small d, some differences exceed
assert run("4 1\n1 2 4 5\n") == "4", "small d with gaps"

# Ordered heights
assert run("3 2\n1 3 5\n") == "2", "ordered with step 2"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 5\n10 | 0 | 最小 n はペアを形成できません |
 | 1000 0\n42… | 999000 | 最大 n、すべて等しい値 |
 | 4 1\n1 2 4 5 | 4 | いくつかのギャップが大きすぎてペアリングできません |
 | 3 2\n1 3 5 | 2 | ちょうど限界の身長差 |

 ## 特殊なケース

 すべての兵士の身長が同じである場合 (たとえば、高さ = [7,7,7,7] および d = 0)、すべてのペアが有効です。 私たちのアルゴリズムは、i < j のペアを 6 としてカウントし、2 を掛けると 12 となり、両方の順序を正しくカウントします。 d が 0 のように非常に小さい場合、同じ身長の兵士のみがペアになります。 内側のループの Break ステートメントにより、差が d を超えた場合の不必要なチェックが回避されます。 n = 1 の場合、外側のループは 1 回実行されますが、内側のループは実行されないため、アルゴリズムは正しい 0 を出力します。 

このメソッドは、並べ替えと早期終了ロジックにより、すべてのエッジ ケースを正しく処理します。
