 ## 解決策
 ## 問題の理解

 私たちには次のシーケンスが与えられています`n`自然数、ここで`n`は少なくとも 3、最大 100 であり、各数値は最大 100 です。これらの数値のうち、1 つを除くすべての数値は同じパリティ (偶数または奇数) を共有し、正確に 1 つの数値が異なります。 私たちのタスクは、1 から数えて、シーケンス内でこの「奇数 1 出力」の番号の位置を特定することです。 

問題の規模は小さい。 と`n`100 に制限されているため、効率を気にせずに各数値を直接検査するアルゴリズムを使用できます。 主な困難は、生の計算ではなく、どの数値がパリティのパターンを破るかを正確に特定することにあります。 

最初のいくつかの数値が多数決のパリティを明確に確立しない場合、微妙なエッジ ケースが発生します。 たとえば、シーケンスが次の場合、`3 2 7`、最初の 2 つの数値を見ただけでは、すぐに過半数が同等であると結論付けることはできません。本当に異なる 1 つの数値を確実に選択するには、注意深く検査する必要があります。 

## アプローチ

 最も簡単なアプローチは総当たりです。数値ごとに、偶数の数と奇数の数を数え、大多数とは異なるパリティを持つ数値を選択します。 この方法が機能するのは、正確に 1 つの数値が異なることが保証されているためです。 のために`n`最大 100 の場合、必要な操作はせいぜい数百回ですが、最新のプロセッサではそれは些細なことなので、パフォーマンスは問題になりません。 

よりクリーンな解決策を可能にする重要な洞察は、多数派パリティを決定するためにシーケンス全体を調べる必要がないということです。 最初の 3 つの数字を見れば十分です。 これらの数値のうち少なくとも 2 つが同じパリティを共有する場合、そのパリティが過半数となります。 多数派パリティがわかったら、シーケンスを 1 回スキャンして、異なる数値を見つけることができます。 これにより、不必要なチェックが減り、ロジックが単純かつ堅牢になります。

 ## アルゴリズムのチュートリアル

 1. 要素数を読み取る`n`そして数字の並び。 インデックスを作成するには、リスト内の数値が必要です。 
2. 各モジュロ 2 を取得して、最初の 3 つの数値のパリティを計算します。これら 3 つのパリティは、少なくとも 2 つが一致する必要があるため、シーケンス内の多数派パリティを決定します。 
3. 多数派パリティを特定します。 最初の 3 つの数値のうち 2 つ以上が偶数の場合、過半数は偶数です。 それ以外の場合、大多数は奇数です。 
4. 一連の数値全体を繰り返します。 数値ごとにそのパリティを計算し、それを過半数のパリティと比較します。 
5. パリティが過半数と一致しない数値が見つかるとすぐに、その位置 (1 から始まるインデックス) を出力して終了します。 これは、異なるパリティを持つ一意の番号であることが保証されます。 

これが機能する理由: 不変条件は、1 つの数値だけが残りの数値と異なるということです。 最初の 3 つの数値から多数決パリティを決定することで、シーケンスの残りの部分をスキャンすることで、曖昧さなく外れ値を正確に特定できることが保証されます。 入力保証により 1 つの異なるパリティが保証されるため、誤検知の危険はありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
nums = list(map(int, input().split()))

# determine majority parity from the first three numbers
first_three = nums[:3]
parities = [x % 2 for x in first_three]
majority_parity = 0 if parities.count(0) > 1 else 1

# find the index of the number with different parity
for i, num in enumerate(nums):
    if num % 2 != majority_parity:
        print(i + 1)
        break
```コードはまず最初の 3 つの要素をスライスして、多数決パリティを確立します。 ゼロを数える`parities`いくつが偶数であるかをチェックします。 次に、ループは多数決パリティに違反する数値を直接検索します。 インデックスに 1 を追加して、0 ベースの Python インデックス作成から問題で必要な 1 ベースのインデックス作成に変換します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    n = int(input())
    nums = list(map(int, input().split()))
    first_three = nums[:3]
    parities = [x % 2 for x in first_three]
    majority_parity = 0 if parities.count(0) > 1 else 1
    for i, num in enumerate(nums):
        if num % 2 != majority_parity:
            print(i + 1)
            break
    return output.getvalue().strip()

# provided samples
assert run("5\n2 4 7 8 10\n") == "3", "sample 1"

# custom cases
assert run("3\n2 3 4\n") == "2", "edge: middle number differs"
assert run("3\n1 2 3\n") == "2", "edge: middle number differs, smallest n"
assert run("5\n1 1 1 1 2\n") == "5", "outlier at end"
assert run("4\n2 2 1 2\n") == "3", "outlier in the middle"
assert run("100\n" + " ".join(["2"]*99 + ["3"]) + "\n") == "100", "maximum size input"

 ## 特殊なケース

 外れ値が最初の要素の場合、たとえば、`3 2 4 6`、最初の 3 つのパリティは次のとおりです。`[1, 0, 0]`、過半数が偶数、反復により最初の要素が異なることが判明し、出力`1`。 

外れ値が最後の場合、反復は最後まで継続され、正しく出力されます。`n`。 

外れ値が中央にある場合、たとえば、`1 1 2 1`、多数決パリティは最初の 3 つの数値から正しく決定され、シーケンスをスキャンすると 3 番目の要素が異なることがわかります。 

これらすべてのエッジケースは、最初の 3 つの要素を使用して多数決パリティを決定するだけで十分であり、スキャン ループは常に多数決に違反する 1 つの数値を特定することを確認します。 

これにより、問題を深く理解し、同様のパリティベースの異常値問題について解を導き出したい競技プログラマーに適した、完全かつ慎重な編集が完成しました。
