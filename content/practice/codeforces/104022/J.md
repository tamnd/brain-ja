 ## 解決策
 ## 問題の理解

 私たちには、未知の m × m グリッドに配置された正方形のジグソー ピースの完全なセットが与えられます。 各ピースは 1 から m² までの一意の番号で識別され、各ピースに対して、他のどのピースがその北、南、西、東に直接位置するかを示す 4 つのポインタが与えられます。 値 -1 は、その方向でピースがパズルの境界上にあることを意味します。 

隠された構造は完全なグリッドです。すべてのピースには、長方形のタイルと一致する最大 4 つの隣接要素があり、全体の構成は単一の一貫した m x m の配置を形成します。 タスクは、グリッド レイアウトを再構築すること、つまり、すべての部分の位置を回復し、最終的な行列を行ごとに印刷することです。 

m は 103 まで大きくできるため、制約では最大 10⁶ 個の個数が許可されます。 重い定数を含む O(n log n) であっても許容されますが、繰り返しのグラフ検索や配置のバックトラッキングなどはタイムアウトやメモリ不足の危険性があるため、どのようなソリューションもピースの数に対して線形時間で実行する必要があります。 

素朴な考え方における微妙な問題は、隣接ポインターが循環または不一致を形成する可能性があると想定することです。 そうではありません。 各部分は一貫したグリッド内の正確に 1 つのセルに属しているため、隣接構造は直交方向のリンク リストのように動作する 4 つの有向グラフを定義します。 

もう 1 つの一般的な失敗ケースは、コーナーであることを保証せずに、任意のノードから再構築を開始しようとすることです。 コーナー以外を選択すると、グリッドの原点を決定できず、座標が誤ってシフトする可能性があります。 

たとえば、中央のタイル A から開始するとします。-1 まで北に歩くのは問題ありませんが、西方向にも整列しないと、A を (0, 0) として扱い、真のグリッド原点が他の場所にあることに気づかずに負のインデックスが生成される可能性があります。 正しい出力は、左上隅が任意の開始点ではなく真の境界セルになるように位置合わせする必要があります。 

2 番目のエッジ ケースは、m = 1 の縮退グリッドです。この場合、単一のピースは 4 つの方向すべてが −1 であり、トラバースせずに直接出力する必要があります。 

## アプローチ

 強引な解釈では、各部分をグラフ内のノードとして扱い、配置されていないノードを繰り返し選択し、すべての位置が固定されるまで制約を拡張することで、座標を割り当てようとします。 配置制約をシミュレートすることもできます。タイルを選択し、それに座標を割り当て、隣接制約を繰り返し伝播し、毎回一貫性をチェックします。 

各隣接制約が相対位置を固定するため、これは概念的に機能します。 ただし、単純な実装では、配置されていない隣接ノードを繰り返し検索したり、一致する隣接関係を見つけるためにすべてのノードをスキャンしたりして、O(n²) の動作が発生する可能性があります。 n が 10⁶ までの場合、これは不可能です。 

重要な観察は、グラフ構造がすでに完全に方向付けられており、一貫性があるということです。 すべてのタイルは隣接するタイルを直接ポイントしているため、検索やマッチングは必要ありません。 有効な原点を選択し、単一の走査を実行して座標を割り当てるだけです。 

重要な洞察は、境界構造が独自の座標系を定義するということです。 北に隣接しないタイルは最初の行に属し、その中で西に隣接しないタイルは左上隅になければなりません。 このアンカーが見つかると、東および南のポインターに従って、他のすべてのタイルが一意に決定されます。 これにより、問題は線形トラバースと座標割り当ての問題に変換されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 繰り返しの検索によるブルート フォースの伝播 | O(n²) | O(n) | 遅すぎる |
 | アンカー + BFS/DFS 座標再構築 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

隣接ポインタを、各ノードが近隣ノードを認識している有向グリッド グラフとして扱います。 目標は、一貫した整数グリッド内の各ノードに座標を割り当て、それらを 1 から始まる行列に正規化することです。 

1. すべてのタイルをスキャンし、北隣も西隣も持たない固有のタイルを見つけます。 これはグリッドの左上隅です。 保証により、それが存在し、一意であることが保証されます。 このステップでは、後続のすべての配置が一貫するように座標原点を確立します。 
2. タイル ID からその (x, y) 座標へのマッピングを作成します。 キューを初期化して隅のタイル座標 (0, 0) を割り当て、それをキューにプッシュします。 これにより、暗黙的なグリッド エッジに対する BFS のような走査が開始されます。 
3. キューが空でない間に、座標 (x, y) のタイル u をポップします。 その 4 つの方向のそれぞれについて、近隣が存在し (-1 ではない)、座標がまだ割り当てられていない場合は、それに相対座標を割り当てます。北は (x − 1, y)、南は (x + 1, y)、西は (x, y − 1)、東は (x, y + 1) を与えます。 新しく割り当てられた各タイルをキューにプッシュします。 このステップは、隣接ポインターが正確な幾何学的なオフセットをエンコードしているため機能します。 
4. 走査後、割り当てられたすべての座標にわたって最小の x と y を計算します。 これにより、最終出力空間で左上が (0, 0) になるように正規化できます。 
5. min_x と min_y を減算してすべての座標をシフトし、各タイル ID をサイズ m × m の 2D 配列の最終位置に配置します。 
6. グリッドを行ごとに出力します。 

正確性は、すべてのタイルが隣接ポインターを介して左上から到達可能であるという事実に依存するため、BFS はグリッド全体を 1 回だけカバーします。 

### なぜ効果があるのか

 隣接構造は、接続されたグリッド グラフの Z² への一貫した埋め込みを定義します。 各エッジは、4 つの方向のうちの 1 つの固定単位ベクトルに対応します。 グリッドは単純に接続されており、各ノードには有効な配置が 1 つだけあるため、1 つのノードが固定されると、他のすべてのノードの位置は有向エッジに従うことによって一意に決定されます。 BFS により、これらの制約が競合することなく確実に伝達され、一意性により、どのタイルにも 2 つの異なる座標が割り当てられないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    m = int(input())
    n = m * m

    nxt = [None] * (n + 1)

    # store adjacency
    north = [0] * (n + 1)
    south = [0] * (n + 1)
    west = [0] * (n + 1)
    east = [0] * (n + 1)

    has_parent = [False] * (n + 1)

    for i in range(1, n + 1):
        a, b, c, d = map(int, input().split())
        north[i], south[i], west[i], east[i] = a, b, c, d
        if a != -1:
            has_parent[a] = True
        if c != -1:
            has_parent[c] = True

    start = -1
    for i in range(1, n + 1):
        if not has_parent[i] and north[i] == -1 and west[i] == -1:
            start = i
            break

    pos = {}
    pos[start] = (0, 0)
    q = deque([start])

    while q:
        u = q.popleft()
        x, y = pos[u]

        v = north[u]
        if v != -1 and v not in pos:
            pos[v] = (x - 1, y)
            q.append(v)

        v = south[u]
        if v != -1 and v not in pos:
            pos[v] = (x + 1, y)
            q.append(v)

        v = west[u]
        if v != -1 and v not in pos:
            pos[v] = (x, y - 1)
            q.append(v)

        v = east[u]
        if v != -1 and v not in pos:
            pos[v] = (x, y + 1)
            q.append(v)

    minx = min(x for x, y in pos.values())
    miny = min(y for x, y in pos.values())

    grid = [[0] * m for _ in range(m)]
    for k, (x, y) in pos.items():
        grid[x - minx][y - miny] = k

    for row in grid:
        print(*row)

if __name__ == "__main__":
    solve()
```実装は、すべての隣接情報を読み取り、どのノードが近隣ノードとして参照されているかを追跡することから始まります。 これにより、真の左上隅には入力参照がなく、明示的に北と西の隣接が存在しないため、境界候補の検出が可能になります。 

BFS セクションは、幾何学的伝播の直接エンコードです。 各割り当てでは固定オフセットが使用されるため、曖昧さや後戻りの必要性が回避されます。 辞書`pos`各タイルが 1 回だけ割り当てられるようにします。 

BFS 座標は任意の原点 (0, 0) から始まり、最終的なグリッド インデックスに対応しない可能性があるため、正規化が必要です。 シフトにより、すべてが有効な m × m 行列に整列されます。 

微妙な点は、「親なし」の検出だけに依存しているわけではないということです。 また、境界タイルではなく真の左上隅を確実に選択するために、北と西を -1 にする必要があります。

 ## 特殊なケース

 単一タイルの場合は、すぐに座標 (0, 0) を割り当て、隣接するタイルが存在しないため、トラバースなしで 1×1 グリッドを出力します。 

長い水平ストリップにより、垂直方向の移動を必要とせずに西から東への伝播が確実に機能します。 BFS は座標を増分的に割り当て、正規化により順序の一貫性が維持されます。 

境界が豊富な完全なグリッドは、開始タイルの正確な識別をテストします。 真の左上のみが「北隣接なし」と「西隣接なし」の両方を満たし、他の境界セル間で原点が誤って選択されないようにします。
