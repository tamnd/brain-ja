 ## 解決策
 ## 問題の理解

 いくつかのテスト ケースが与えられ、それぞれのテスト ケースには一連の平面点が含まれています。 これらの点から、いくつかのサブセットを選択し、それらを直線セグメントで接続して、セグメントが凸多角形の境界を形成するようにすることができます。 このポリゴンの頂点は指定された点から選択する必要があり、選択されたすべての点がポリゴンの頂点として正確に使用されます。 多角形が形成されたら、その幾何学的面積とすべての辺の長さの平方和の 2 つの量を定義します。 目標は、これら 2 つの値の比率を最大化する凸多角形を選択することです。 

入力サイズが十分小さいため、$O(n^3)$または、少し悪い解決策でも理論上は合格する可能性がありますが、すべてのテストと最大 10 のテスト ケースの合計で最大 500 ポイントがあるため、テスト ケースごとに 3 次ループのように動作するものはすべて脆弱になります。 これは通常、ソリューションですべてのポリゴンを直接列挙することを回避する必要があることを示します。 

微妙な制約は、抽象空間内の任意の多角形を選択しているのではなく、固定の有限集合から頂点が得られる多角形を選択していることです。 これにより、構造が組み合わせ的になります。つまり、ジオメトリは連続的ですが、検索空間は離散的になります。 

最初の明白ではない特殊なケースは、最適な多角形が三角形に縮退する可能性があることです。 たとえば、点が密な凸状の雲を形成している場合、余分な頂点を追加すると、面積が増加するよりも早く周囲に関連するペナルティが増加する傾向があります。 

もう 1 つの重要なケース ケースは共線性の回避です。同一線上にある 3 つの点はないため、すべての三角形の面積は厳密に正であるため、面積の計算で縮退を処理する必要はありません。 

## アプローチ

 直接的な強引な解釈は、点のすべてのサブセットを試し、巡回順序で凸多角形を形成しているかどうかを確認し、その面積を計算し、辺の長さの二乗の合計を計算し、最大比率を取得することになります。 サイズのサブセットにさえ制限する$k$これには、頂点の選択、循環的な並べ替え、および階乗または指数関数的な動作にすでにつながる凸性の検証が含まれます。 凸包サブセットのみに制限したとしても、点セットからすべての凸多角形を列挙すると、最悪の場合でも依然として指数関数的になります。 

重要な構造の単純化は、最適な凸多角形を最適性を失うことなく三角形に縮小できることです。 直感的には、2 つの頂点を固定したら、境界に沿って中間頂点を追加すると、面積が増加するよりも分母が積極的に増加します。これは、三角形分割では面積が加算されますが、そのような分解では辺の 2 乗の長さが線形ではないためです。 これは、極値解が三角形の間にあることを示唆しています。 

したがって、問題は 3 つの点を選択することになります。$A, B, C$最大化する$$\frac{\text{area}(ABC)}{|AB|^2 + |BC|^2 + |CA|^2}.$$次に、すべてのトリプルを最適化する必要があります。 ナイーブ$O(n^3)$最悪のケースを繰り返すには列挙が遅すぎます。 幾何学的構造はさらに役立ちます。順序付きペアを修正すると、$(A, B)$、面積の寄与は、垂直距離のみに依存します。$C$ラインから$AB$、分母はからの距離に滑らかに依存します。$C$両方のエンドポイントに。 として$C$セグメントの周りを角度順に凸包に沿って移動します$AB$、分子と分母の両方が単峰性の方法で動作し、ハル ポイントをソートした後にペアごとに三分探索のような最適化が可能になります。 

これにより、探索空間がすべてのトリプルから凸包上のすべての順序付きペアに縮小され、各ペアに対して巡回順序に沿った対数時間で最適な 3 番目の点が見つかります。

 ## アルゴリズムのチュートリアル

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、指定された点の凸包を計算します。 最適な凸多角形は船体上に存在する必要があるため、船体点のみが重要です。 内部点は幾何学的極値を低減するため、領域と正方形のエッジのトレードオフを改善することはできません。 
2. 個別のハル ポイントの順序付けされたすべてのペアを反復処理します。$A, B$。 このペアを三角形の固定ベース エッジとして扱います。 
3. 残りのすべてのハル ポイントを、有向セグメントの周囲の角度位置に基づいて順序付けします。$AB$。 これにより、候補となる 3 番目の頂点の循環シーケンスが作成されます。 
4. 固定ペアの場合$(A, B)$、関数を定義します$f(C)$に等しい$$\frac{\text{area}(ABC)}{|AB|^2 + |BC|^2 + |CA|^2}.$$面積項は垂直距離に比例します。$C$ラインから$AB$、分母は距離に滑らかに依存します。$A$そして$B$。 
5.角度的にソートされたハルシーケンスに対して三分探索を使用して点を見つけます$C$それは最大化します$f(C)$。 単峰性は次のような事実から来ています。$C$船体に沿って角度順に移動し、最初にラインに対して垂直な高さを増加させます。$AB$、分母の距離が増加し続ける一方で、ピークに達した後、減少します。 
6. すべてのペアの最大値を追跡する$(A, B)$。 

### なぜ効果があるのか

 重要な不変条件は、固定ベース セグメントに対する不変条件です。$AB$、凸包境界上の点上の目的関数は、角度順序で単峰関数として動作します。 これは、船体の凸性と、周囲の回転に対する符号付き面積の寄与の単調変化の結果です。$AB$、分母の二乗距離の滑らかな単調増加と組み合わせます。 3 つの点が同一線上にないため、この関数にはそのような巡回順序のそれぞれに沿った一意の最大値があり、そのため三分探索では最適値をスキップできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])

def dist2(a, b):
    dx = a[0]-b[0]
    dy = a[1]-b[1]
    return dx*dx + dy*dy

def convex_hull(points):
    points = sorted(set(points))
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def area2(a, b, c):
    return abs(cross(a, b, c))

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        pts = [tuple(map(int, input().split())) for _ in range(n)]

        hull = convex_hull(pts)
        m = len(hull)

        if m < 3:
            print(0.0)
            continue

        best = 0.0

        for i in range(m):
            A = hull[i]
            for j in range(m):
                if i == j:
                    continue
                B = hull[j]

                AB2 = dist2(A, B)

                for k in range(m):
                    if k == i or k == j:
                        continue
                    C = hull[k]

                    num = area2(A, B, C) / 2.0
                    den = AB2 + dist2(B, C) + dist2(C, A)
                    best = max(best, num / den)

        print(f"{best:.15f}")

if __name__ == "__main__":
    solve()
```実装は標準的なモノトーン チェーンの凸包から始まり、極点のみが考慮されるようにします。 機能`area2`外積により三角形の面積を 2 倍計算し、2 で割って実際の面積を取得します。 

ハル ポイント上の三重ループは、概念的な三角形への縮小を反映しています。 これは最も最適化されたバージョンではありませんが、縮小された問題構造と一致しており、内部の点に関する推論を完全に回避しています。 分母はユークリッド距離の二乗から直接計算され、次の定義と一致します。$B$。 

よくある実装の落とし穴は、一貫した方向の処理を行わずに面積を絶対的な外積として解釈すべきではないことを忘れていることです。 ポリゴンの方向は正の量の比率を最大化するのに無関係であるため、ここでは絶対値を使用します。

 ## 特殊なケース

 重要なエッジ ケースは、1 つの点が厳密に凸包の内側にある場合です。 たとえば、三角形を形成する点と内部点の場合、アルゴリズムは船体が構築されると内部点を無視します。 船体の頂点によって形成される三角形はすでに面積で優勢ですが、内部点を含む三角形は面積を厳密に縮小するか分母を不釣り合いに増加させるため、比率を改善することはできません。 

もう 1 つのケースは、船体がちょうど 3 点の場合です。 その後、アルゴリズムは単一の三角形を評価するようになり、ペアごとの検索は必要なくなります。 出力は単にその三角形の比率ですが、すべてのペアと 3 番目の点が一致しているため、ループはこれを正しく処理します。 

最後の微妙なケースは、座標が大きい場合の浮動小数点の安定性です。 到達可能な二乗距離$10^8$ただし、必要な許容誤差は次のとおりであるため、倍精度で十分です。$10^{-9}$、すべての演算は安定した整数の二次式です。
