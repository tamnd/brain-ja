 ## 問題の理解

 凸多角形の頂点に配置された一連のピンの周囲に張られた文字列で囲まれた領域を計算するように求められ、その後、全周を制限したままわずかに拡張させられます。 正式には、頂点を持つ凸多角形の場合$(x_i, y_i)$と長さの文字列$l$、凸包の外周を超えずに多角形に追加できるすべての点の面積が必要です。$l$。 

入力は頂点の数を提供します$n$そして文字列の長さ$l$、反時計回りの順に多角形の座標が続きます。 多角形は厳密に凸面であり、すべての内角が より小さいことを意味します。$180^\circ$。 文字列の長さ$l$ポリゴンの元の外周を超えるため、結果として得られる「ファイバー形状」は、一定のマージンだけ外側に膨張したポリゴンになります。 

とすれば$n$まで可能です$10^4$そして$l$まで$8 \cdot 10^5$、密なグリッド内のすべてのポイントを検査したり、新しいポイントの多くの潜在的な配置を個別に反復したりするアルゴリズムは、遅すぎます。 に対して線形または線形演算時間で機能するソリューションが必要です。$n$。 

単純に文字列の周りを動く鉛筆をシミュレートしようとする単純な実装は、浮動小数点の不正確さと構成の組み合わせ爆発により失敗します。 もう 1 つの微妙なエッジ ケースは、文字列がポリゴンの周囲よりわずかに長い場合に発生します。 不注意なアプローチでは、全方向に均一な膨張を想定する可能性があり、角付近の領域を過大評価または過小評価する可能性があります。 たとえば、頂点を持つ三角形$(0,0),(1,0),(0,1)$また、周囲よりわずかに長い文字列は、単純な均一な拡張ではなく、丸い角を生成します。 

## アプローチ

 ブルートフォースアプローチは、多角形の周囲のすべての潜在的な点に鉛筆を配置することをシミュレートし、鉛筆を追加することで凸包の周囲が範囲内に保たれるかどうかを確認することです。$l$。 原理的には正しいですが、これには膨大な数の候補点をチェックする必要があり、簡単に超えます。$10^{10}$大きなポリゴンの操作が必要になるため、まったく実用的ではありません。 

重要な洞察は凸形状から得られます。 凸多角形をわずかに膨張させると、結果として得られる領域は、元の多角形と、多角形の周囲に沿って分布する余分な文字列の長さに対応する半径をもつ円弧によって形成される各頂点の一連の丸い角で構成されます。 数学的には、繊維の形状は、多角形と半径の円のミンコフスキー和として見ることができます。$r = \frac{l - \text{perimeter}}{2\pi}$。 これは、文字列を多角形の周囲で外側に均一に引き伸ばすと、境界に沿ったすべての点に循環バッファが効果的に追加されるためです。 

この洞察を考慮すると、最適なアルゴリズムは元の多角形の面積を計算し、文字列の長さから余分な半径を計算してから、角の周りの円形のキャップの面積を追加します。 結果として得られる形状の面積は、ポリゴンの面積とバッファーの面積を加算したものになります。$\text{Area} = A_\text{polygon} + r \cdot \text{perimeter} + \pi r^2$。 この式は、凸多角形を均一なオフセットで膨張させるための古典的な幾何学的結果から直接得られます。

 ## アルゴリズムのチュートリアル

 1.周囲を計算する$P$指定された凸多角形の。 連続する頂点間のユークリッド距離を合計します。 これにより、元の多角形をしっかりとラップするために必要な文字列の合計の長さが得られます。 
2. 面積を計算する$A$靴紐式を使ったオリジナルの凸多角形。 これが必要になるのは、ファイバーの形状によって元のポリゴンの外側に領域が追加されるためですが、元のポリゴンの寄与は維持する必要があります。 
3. 多角形を超える余分な文字列の長さを計算します。$l - P$。 これは、外側に拡張するために使用できる文字列の量です。 
4. 半径を決定する$r$余分な長さをポリゴンの周囲に沿って均等に分配することにより、丸みを帯びた角を補正します。$r = \frac{l - P}{2\pi}$。 による除算$2\pi$半径が完全な円弧であるという事実から来ています。$r$周囲を追加します$2\pi r$。 
5. 繊維形状の面積を次のように計算します。$A_\text{fiber} = A + r \cdot P + \pi r^2$。 用語$r \cdot P$多角形のエッジに沿った長方形のストリップの領域に対応し、$\pi r^2$角の円形キャップの面積に相当します。 
6. 条件を満たすのに十分な精度で領域を出力します。$10^{-6}$エラー要件。 

機能する理由: 不変条件は、ファイバーの形状が凸状であること、および均一なバッファーを追加すると周囲の拡張状態が維持されることです。 ミンコフスキー総和は、ストリングの長さを超えることなくファイバー形状のすべての点に到達できることを保証し、計算された面積公式は線形エッジの膨張とコーナーの丸みの両方を正確に考慮します。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def main():
    n, l = map(int, input().split())
    vertices = [tuple(map(int, input().split())) for _ in range(n)]
    
    # Compute perimeter
    P = 0.0
    for i in range(n):
        x1, y1 = vertices[i]
        x2, y2 = vertices[(i+1) % n]
        P += math.hypot(x2 - x1, y2 - y1)
    
    # Compute polygon area using shoelace formula
    A = 0.0
    for i in range(n):
        x1, y1 = vertices[i]
        x2, y2 = vertices[(i+1) % n]
        A += (x1 * y2 - x2 * y1)
    A = abs(A) / 2.0
    
    # Extra radius
    r = (l - P) / (2 * math.pi)
    
    # Total area
    fiber_area = A + P * r + math.pi * r * r
    print(fiber_area)

if __name__ == "__main__":
    main()
```最初のループは、ユークリッド距離を使用して周長を正確に計算します。 靴紐の式は、反時計回りの頂点のポリゴン領域を正確に処理します。 の計算$r$追加の文字列が正しく分散されることを保証し、最終的な面積式は線形寄与と円形寄与を組み合わせます。 微妙な点は、周囲長と面積の計算では、幾何学問題で重大な切り捨てエラーを避けるために浮動小数点演算を使用する必要があることです。
