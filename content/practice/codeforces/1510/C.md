 ## 解決策
 ## 問題の理解

 この問題により、サボテン グラフが得られます。これは、各エッジが最大 1 つの単純なサイクルに属する、接続された無向グラフです。 サボテンは、いくつかのサイクルを許容しますが、サイクルが重複することは決してない木と考えることができます。 入力は、これらのサボテンを少し変わった方法で表します。つまり、すべてのエッジを明示的にリストする代わりに、パスを与え、パス内の連続する頂点の各ペアがエッジを定義します。 各エッジはすべてのパスにわたって 1 回だけ現れるため、グラフの再構築は簡単です。 

目的はサボテンを「強化」すること。 強いサボテンとは、サボテンの特性を侵害することなくエッジを追加できないサボテンのことです。 強力なサボテンに到達するために必要な追加エッジの最小セットを計算し、これらのエッジを明示的に出力するように求められます。 

制約により、頂点とエッジの数は最大で次のとおりであることがわかります。$10^5$、各パスの長さは最大 1000 頂点にすることができます。 これにより、およそよりも複雑なアルゴリズムは除外されます。$O(n + m)$すべてのエッジまたは頂点にわたるネストされたループでは数十億の操作が発生する可能性があるため、テスト ケースごとに異なります。 この問題では複数のテスト ケースも許可されるため、合計作業量はそれらのテスト ケース全体で直線的にスケールする必要があります。 

サボテンがすでにサイクルのない木である場合、微妙なエッジケースが 1 つ発生します。 単純なアプローチでは、任意の葉を接続しようとして、誤って重複するサイクルが作成され、サボテンの特性に違反する可能性があります。 たとえば、3 つの頂点 1-2-3 のパスを考えてみましょう。 強いサボテンには 1 つのサイクル (エッジ 1 ～ 3 を追加するなど) が必要ですが、それを超えて追加のエッジを追加しようとすることは禁止されています。 もう 1 つのエッジ ケースは、サボテンにすべての頂点を接続する単一のサイクルが含まれている場合です。 追加のエッジを追加することはできません。 サイクルとパスを均一に処理することが重要です。 

## アプローチ

 ブルートフォース手法では、頂点のすべてのペアを試し、サボテンのプロパティに違反しない場合はエッジを追加します。 サボテンのプロパティをチェックするには、複数のサイクルに属しているエッジがないことを確認する必要があり、これにはグラフ全体を走査する必要がある場合があります。 最悪の場合、このアプローチは次のようになります。$O(n^2)$さらに悪いことに、潜在的なエッジごとにグラフを探索する必要がある可能性があります。 これは明らかに不可能です$n = 10^5$。 

最適なアプローチはサボテンの構造に依存します。 すべてのサボテンは、単一のエッジまたは単純なサイクルのいずれかであるブロックに分解できます。 各サイクルを「ブロック グラフ」のノードとして扱うことができます。ノードはサイクルとブリッジ (サイクル内にないエッジ) であり、リーフは複数のサイクルに属さない頂点です。 強力なサボテンでは、すべてのサイクルとすべてのブリッジが「飽和」している必要があります。重複するサイクルを作成せずに、ブロック内またはブロックの葉の間に隣接しない 2 つの頂点を接続するエッジを追加することはできません。 サボテンでは、強力なサボテンに到達するための最小エッジ数は、ブロック グラフの葉の数の半分の上限であることがわかります。 これは、リーフをペアにして接続して新しいサイクルを形成し、グラフを徐々に飽和させることができるためです。 

重要な洞察は、サボテンのブロック グラフ自体が木であるということです。 このブロック ツリーの葉は、接続された場合に新しいサイクルを作成できる頂点を表します。 これらのリーフを効率的にペアリングすると、必要な最小限の数の新しいエッジが得られます。 これにより、ブロック ツリー内の葉を見つけてそれらを一致させるという問題が軽減されます。これは、$O(n)$時間。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n + m) | 遅すぎる |
 | 最適 | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力を読み取り、パスからグラフを再構築します。 パスごとに、連続する頂点の間にエッジを追加します。 
2. 親追跡による標準の DFS アプローチを使用してサイクルを特定します。 バック エッジが見つかったら、サイクルを形成する頂点を記録します。 サボテンのプロパティにより、各エッジは最大 1 つのサイクルに属します。 
3. ブロックグラフを構築します。 各ブロックは、サイクル、またはサイクルの一部ではない単一のエッジのいずれかです。 共有頂点を介してブロックを接続します。 
4. ブロック グラフ内の葉の数を数えます。 リーフは、別のブロックへの接続が 1 つだけあるブロックです。 各リーフ ブロックから代表的な頂点を 1 つ収集します。 
5. 葉を組み合わせます。 リーフの数が奇数の場合、1 つの頂点が一致しないままになる場合があります。 各ペアに対して、2 つの代表的な頂点を接続するエッジを追加します。 これらのエッジは新しいサイクルを作成し、グラフを飽和させます。 
6. 新しいエッジの数とエッジ自体を出力します。 

機能する理由: 不変条件は、ブロック ツリー内の葉がサボテンのプロパティに違反することなく接続できる頂点に対応するということです。 リーフをペアリングすると、追加の各エッジが既存のサイクルと重複することなく新しいサイクルに寄与するようになります。 すべての葉がペアになると、それ以上エッジを追加することはできなくなり、強力なサボテンが完成します。 この構造により、ペアになっていないリーフには追加のエッジが必要になるため、エッジの数が最小限に抑えられます。そのため、貪欲にペアリングすると最小数が達成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

def main():
    while True:
        n, m = map(int, input().split())
        if n == 0 and m == 0:
            break
        
        adj = [[] for _ in range(n)]
        edges = set()
        
        for _ in range(m):
            path = list(map(int, input().split()))
            s = path[0]
            verts = path[1:]
            for i in range(s-1):
                u, v = verts[i]-1, verts[i+1]-1
                if (u, v) not in edges and (v, u) not in edges:
                    adj[u].append(v)
                    adj[v].append(u)
                    edges.add((u, v))
        
        visited = [False] * n
        parent = [-1] * n
        depth = [0] * n
        blocks = []

        def dfs(u):
            visited[u] = True
            for v in adj[u]:
                if v == parent[u]:
                    continue
                if visited[v]:
                    if depth[v] < depth[u]:
                        # found a back edge u-v, extract cycle
                        cycle = set()
                        x = u
                        while x != v:
                            cycle.add(x)
                            x = parent[x]
                        cycle.add(v)
                        blocks.append(cycle)
                else:
                    parent[v] = u
                    depth[v] = depth[u] + 1
                    dfs(v)
        
        for i in range(n):
            if not visited[i]:
                dfs(i)
        
        # Build block graph
        block_adj = [[] for _ in range(len(blocks))]
        vert_to_block = {}
        for idx, block in enumerate(blocks):
            for v in block:
                vert_to_block[v] = idx
        
        deg = [0]*len(blocks)
        for idx, block in enumerate(blocks):
            neighbors = set()
            for v in block:
                for u in adj[v]:
                    if u in vert_to_block and vert_to_block[u] != idx:
                        neighbors.add(vert_to_block[u])
            deg[idx] = len(neighbors)
        
        leaves = []
        for idx, d in enumerate(deg):
            if d == 1:
                leaves.append(next(iter(blocks[idx])))
        
        # Pair leaves
        added_edges = []
        for i in range(0, len(leaves)-1, 2):
            added_edges.append((leaves[i]+1, leaves[i+1]+1))
        if len(leaves) % 2 == 1:
            added_edges.append((leaves[-1]+1, leaves[-1]+1))  # singleton remains
        
        print(len(added_edges))
        for u, v in added_edges:
            print(u, v)

if __name__ == "__main__":
    main()
```最初のセクションでは、エッジの重複を防ぎながら、隣接リストを使用してグラフを再構築します。 DFS はサイクルを識別し、ブロックとして収集します。 次に、頂点をブロックにマッピングすることによって、ブロック グラフが暗黙的に構築されます。 リーフは、ブロック隣接内でどのブロックが次数 1 を持つかを確認することによって収集されます。 葉を組み合わせることで、強力なサボテンに到達するための最小限のエッジのセットが得られます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + m) | DFS は各頂点とエッジを 1 回訪問し、サイクル検出は線形で、リーフのペアリングは線形です。 |
 | スペース | O(n + m) | 隣接リスト、訪問済み配列、ブロック ストレージ、および一時変数はすべて線形に拡張されます。 |

 これは 3 秒の制限時間内に収まります$n, m \le 10^5$。
