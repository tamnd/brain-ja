 ## 解決策
 ## 問題の理解

 タスクは、長さの正の整数配列を構築することです。`n`すべての隣接するペア間のローカル ルールを満たします。 ポジションごとに`i`、の値`i`残りを正確に残さなければなりません`1`次の値で割ったとき。 すべての有効な配列の中で、辞書編集的に最小の配列が必要です。つまり、2 つの配列が異なる最初の位置には、選択した配列内の小さい方の値が含まれている必要があります。 

入力には複数のテスト ケースが含まれています。 各テスト ケースでは、配列の必要な長さのみが提供されます。 出力は、その長さに対して構築されたシーケンスです。 制約により、最大で次のことが許可されます。`10^5`テスト ケースとすべてのテスト ケースの合計の長さは最大でも`5 * 10^5`したがって、要素ごとに線形時間を超えるアルゴリズムは不要になります。 たとえば、すべての位置に対して多くの可能な値を試すなどの 2 次アプローチでは、すぐに使用可能な演算を超えてしまいます。 

重要なエッジケースは、小さな約数を使用したモジュロの異常な動作から生じます。 

のために`n = 1`、隣接するペアがないため、任意の正の整数が機能します。 最小の選択肢は次のとおりです。```
Input:
1

Output:
1
```最初の要素を制約する 2 番目の要素がないため、常に減少チェーンを構築しようとする不用意な解決策はここで失敗します。 

より大きな配列の場合、最後の値を次のようにすることはできません。`1`。 最初の位置以降の要素が`1`、前の要素は次の条件を満たす必要があります。`x mod 1 = 1`、これは不可能です。なぜなら、すべての整数の剰余があるからです。`1`は`0`。 例えば：```
Input:
3
```有効な答えは次のとおりです。```
1 3 2
```なぜなら`1 mod 3`チェックされていない、そして`3 mod 2 = 1`。 

すべての要素を個別に最小化しようとする誤ったアプローチでは、次で終わる接尾辞が選択される可能性があります。`1`ただし、そのサフィックスを有効な配列に拡張することはできません。 

## アプローチ

 直接的な強引なアイデアは、可能な限り最小の最初の要素を検索し、次に可能な限り最小の 2 番目の要素を検索し、残りの位置をまだ埋めることができるかどうかを確認しながら続行することです。 辞書編集上の順序は左から右に決定されるため、これは論理的に正しいです。 ただし、候補値の範囲は狭くなく、可能性を探るとすぐに費用がかかります。 までの長さ`5 * 10^5`、ささやかな分岐検索さえ不可能です。 

有用な観察は、モジュロ条件自体を観察することで得られます。 最初の位置以降のすべての位置について、次の値を指定することはできません。`1`、つまり、からのすべての要素`a2`それ以降は少なくとも`2`。 両方の数字が入っている場合`x mod y = 1`少なくとも`2`、 それから`x`より大きくなければなりません`y`なぜなら、より大きな数値で除算した後、より小さな数値はゼロ以外の余りを持つことができないからです。 

これは接尾辞を意味します`a2, a3, ..., an`常に厳密に減少していなければなりません。 最後に可能な最小値は次のとおりです。`2`、 なぜなら`1`は禁止されています。 一度`an = 2`が固定されている場合、以前の有効な最小値は次のとおりです。`3`、 それから`4`、 等々。 

最初の要素は特別です。 次のモジュロ規則を満たす必要があるだけであるため、2 番目の要素より大きい必要はありません。`a2`。 可能な最小の最初の値は次のとおりです。`1`、 そして`1 mod anything greater than 1`いつもです`1`。 したがって、最適な構築は以下から始まります。`1`そして、からの減少シーケンスを配置します`n`まで`2`。 

最終的な配列は次のとおりです。```
1, n, n-1, ..., 2
```この構造では、可能な限り最小のプレフィックスと可能な限り最小の有効なサフィックスが直接与えられます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |

 | 最適 | O(n) | 出力ストレージの O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.長さを読み取ります`n`必要な配列の。 

構築はサイズのみに依存するため、追加の検索や前処理は必要ありません。 
2.置く`1`最初の要素として。 

これは可能な最小の正の整数です。 次の要素は少なくとも`2`、条件`1 mod a2 = 1`自動的に満たされます。 
3. 以下のすべての数字を追加します。`n`まで`2`。 

これにより、厳密に減少するサフィックスが作成されます。 このサフィックス内のすべての隣接するペアの形式は次のとおりです。`x`に続く`x - 1`。 以来`x mod (x - 1) = 1`、すべての遷移が有効です。 
4. 構築されたシーケンスを出力します。 

なぜ効果があるのか:

 2 番目の要素から始まるサフィックスは厳密に減少する必要があるため、その最小値は正確に次のようになります。`n, n-1, ..., 2`。 ある位置の値が小さいと、強制的に複製されるか、使用する必要があります。`1`、接尾辞に含めることはできません。 最初の値は独立して次のように減らすことができます。`1`有効な配列は、これより小さい正の整数で始めることはできません。 したがって、構築は辞書編集的に最小限になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        cur = [1]
        for x in range(n, 1, -1):
            cur.append(x)
        ans.append(" ".join(map(str, cur)))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```コードは最初にすべてのテスト ケースを読み取り、各回答を個別に構築します。 リストは次から始まります`1`最初の位置はシーケンスの残りの部分とは異なる役割を持っているためです。 

ループは次の値を追加します。`n`まで`2`。 まさにあります`n - 1`繰り返しが行われるため、生成されたシーケンスは必要な長さになります。 降順では、最終要素に到達する前にループが正確に停止するため、最終要素の前後での 1 つずつの間違いも回避できます。`1`、接尾辞に含めることはできません。 

Python の整数では、生成される最大の値は`5 * 10^5`。

```この構造により、以前の値がモジュロを満たす必要があるという無効な状況が回避されます。`1`。 

より大きな例としては、次のようになります。```
Input:
6
```アルゴリズムにより次のものが生成されます。```
1 6 5 4 3 2
