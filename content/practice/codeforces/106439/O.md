 ## 解決策
 ## 問題の理解

 正の整数の配列が与えられます。 スプリットポジションでは左パートと右パートに分かれます。 配列要素を 1 つだけ変更した後で 2 つの部分の最大公約数を等しくできる場合、分割は良好であると見なされます。 変更された要素は配列内のどこにあってもよく、決定は可能な分割ごとに個別に行われます。 

すべての分割について、GCD の最終値を見つけることが質問ではありません。 知る必要があるのは、分割の一方の側を変更し、もう一方の側を変更しないことで共通の値に到達できるかどうかだけです。 

配列の長さは次のとおりです$2 \cdot 10^5$すべてのテストケースにわたって。 これにより、両面をスキャンしてすべての分割をチェックする必要がなくなります。これにはコストがかかります。$O(n^2)$。 線形または$O(n \log n)$。 値自体は次のように大きくできます。$10^9$したがって、割り算と GCD に基づく演算は効率的でなければなりません。 

難しいケースは、1 つの変更が許可されているという事実から生じます。 現在の GCD が異なる場合の分割は、自動的に悪いわけではありません。 例えば：```
Input:
1
2
6 10

Output:
1
```分割されるのは 2 つの数値の間だけです。 左側の GCD は 6、右側の GCD は 10 です。最初の要素を 6 から 10 に変更すると、両側の GCD が 10 になり、良好な分割になります。 現在のプレフィックスとサフィックス GCD を比較するだけのソリューションでは、誤って拒否されてしまいます。 

もう 1 つのエッジ ケースは、多くの要素を含むサイドで、1 つの要素だけがターゲット GCD を妨げる場合です。```
Input:
1
3
6 10 15

Output:
2
```最初の分割では、左側は GCD 6、右側は GCD 5 になります。6 を 5 に変更すると、両方の側が GCD 5 になります。2 番目の分割では、左側は GCD 2、右側は GCD 15 になり、15 を 2 に変更すると機能します。 重要な観察は、1 つを除くすべての要素がすでに目的の GCD をサポートしている場合、側面を修復できるということです。 

## アプローチ

 直接的なアプローチでは、すべての分割を試し、1 つの変更で 2 つの GCD を等しくできるかどうかを計算します。 分割の場合、現在の GCD を計算し、各要素を一度削除して、変更後にどのような GCD が可能になるかを確認できます。 これは正しいです。1 つの要素を変更することは、他のすべての要素が最終的な GCD ですでに割り切れる必要があると判断することと同じだからです。 ただし、分割ごとにこれを行うには、配列の大部分を繰り返しスキャンする必要があります。 最悪の場合はこうなります$O(n^2)$が遅すぎます。 

重要な観察は、セグメントが何らかの目標値で割り切れるようになるということです。$g$1 つの要素を変更した後、おそらく 1 つを除くすべての要素が既に次の要素で割り切れる必要があります。$g$。 いつでも次の値に置き換えることができるため、変更された要素の正確な新しい値を知る必要はありません。$g$。 

したがって、左 GCD での分割の場合$L$と右GCD$R$、可能性は3つだけです。 次の場合、分割はすでに有効です$L = R$。 それ以外の場合は、左側の 1 つの要素を変更して、その GCD が次のようになります。$R$、または、右側の 1 つの要素を変更して、その GCD が次のようになります。$L$。 これらのチェックは、範囲に指定された値で割り切れない数値が 1 つだけ含まれているかどうかを尋ねることに帰着します。 

これらの割り算のクエリにすばやく答えるために、すべてのノードがその区間の GCD を格納するセグメント ツリーを構築します。 ノードの GCD がターゲット値で割り切れる場合、間隔全体が有効であり、スキップできます。 それ以外の場合は、条件に違反するいくつかの要素が見つかるまで下降します。 2 つの不正な要素が見つかるとすぐに停止するため、すべてのクエリが高速になります。

 | ブルートフォース | O(n²) | お(1) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのプレフィックスとすべてのサフィックスの GCD を計算します。 位置のプレフィックス値$i$分割の左側の現在の GCD を返します。$i$、接尾辞の値は右側の現在の GCD を示します。 
2. すべての間隔の GCD を格納するセグメント ツリーを構築します。 ツリーを使用すると、範囲に特定のターゲットで割り切れない要素が複数含まれているかどうかをすばやく見つけることができます。 
3. すべての分割位置について、左側の GCD を次のようにします。$L$そして正しい GCD は$R$。 
4. もし$L = R$、変更する必要がないため、この分割はすぐにカウントされます。 
5. それ以外の場合は、左側の部分を GCD に変更できるかどうかを確認します。$R$。 これは、左側の部分に次の要素で割り切れない要素が 1 つだけある場合に当てはまります。$R$。 
6. それが失敗した場合は、正しい部分を GCD に変更できるかどうかを確認します$L$。 右側も同じ状態です。 
7. いずれかの変更チェックが成功した場合、分割をカウントします。 

アルゴリズムの背後にある不変条件は、セグメントが GCD を持つように変換できることです。$g$そのセグメント内の最大でも 1 つの要素が次の要素で割り切れない場合に、1 回の変更を加えるだけで済みます。$g$。 すべての変更されていない要素はすでに最終的な GCD に寄与する必要があり、1 つの変更された要素には、必要な GCD を完成させる任意の値を割り当てることができます。 セグメント ツリーは、すべての要素を訪問することなく、この条件をチェックします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build(node, left, right, arr, tree):
    if left == right:
        tree[node] = arr[left]
        return
    mid = (left + right) // 2
    build(node * 2, left, mid, arr, tree)
    build(node * 2 + 1, mid + 1, right, arr, tree)
    tree[node] = gcd(tree[node * 2], tree[node * 2 + 1])

def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

def count_bad(node, left, right, ql, qr, target, tree):
    if qr < left or right < ql:
        return 0
    if ql <= left and right <= qr and tree[node] % target == 0:
        return 0
    if left == right:
        return 1
    mid = (left + right) // 2
    result = count_bad(node * 2, left, mid, ql, qr, target, tree)
    if result > 1:
        return result
    result += count_bad(node * 2 + 1, mid + 1, right, ql, qr, target, tree)
    return result

def solve_case(arr):
    n = len(arr)

    pref = [0] * n
    suff = [0] * n

    for i in range(n):
        pref[i] = gcd(pref[i - 1], arr[i]) if i else arr[i]

    for i in range(n - 1, -1, -1):
        suff[i] = gcd(suff[i + 1], arr[i]) if i + 1 < n else arr[i]

    tree = [0] * (4 * n)
    build(1, 0, n - 1, arr, tree)

    ans = 0

    for i in range(n - 1):
        left_g = pref[i]
        right_g = suff[i + 1]

        if left_g == right_g:
            ans += 1
            continue

        if count_bad(1, 0, n - 1, 0, i, right_g, tree) <= 1:
            ans += 1
            continue

        if count_bad(1, 0, n - 1, i + 1, n - 1, left_g, tree) <= 1:
            ans += 1

    return ans

def main():
    t = int(input())
    ans = []
    for _ in range(t):
        n = int(input())
        arr = list(map(int, input().split()))
        ans.append(str(solve_case(arr)))
    print("\n".join(ans))

if __name__ == "__main__":
    main()
```プレフィックス配列とサフィックス配列には、各分割の反対側の自然なターゲットとして使用される GCD 値が格納されます。 2 つの値がすでに一致している場合、答えはすぐに得られます。 

セグメント ツリーには区間 GCD が格納されます。 クエリ中に、格納されている GCD がターゲットで割り切れる場合、その区間内のすべての要素もターゲットで割り切れる必要があるため、ノード全体が破棄される可能性があります。 ノードを破棄できない場合、割り算条件を破る要素が見つかるまで検索が下方向に続行されます。 

アルゴリズムはカウントが 0、1、または少なくとも 2 であるかどうかのみを知る必要があるため、クエリは 2 つの不良要素が見つかった後に停止します。 これにより、不必要なトラバースが回避され、複雑さが制限内に保たれます。

## テストケース```python
import sys, io

def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

def solve_case(arr):
    n = len(arr)
    pref = [0] * n
    suff = [0] * n

    for i in range(n):
        pref[i] = gcd(pref[i - 1], arr[i]) if i else arr[i]

    for i in range(n - 1, -1, -1):
        suff[i] = gcd(suff[i + 1], arr[i]) if i + 1 < n else arr[i]

    tree = [0] * (4 * n)

    def build(node, l, r):
        if l == r:
            tree[node] = arr[l]
        else:
            m = (l + r) // 2
            build(node * 2, l, m)
            build(node * 2 + 1, m + 1, r)
            tree[node] = gcd(tree[node * 2], tree[node * 2 + 1])

    def bad(node, l, r, ql, qr, x):
        if qr < l or r < ql:
            return 0
        if ql <= l and r <= qr and tree[node] % x == 0:
            return 0
        if l == r:
            return 1
        m = (l + r) // 2
        res = bad(node * 2, l, m, ql, qr, x)
        if res > 1:
            return res
        return res + bad(node * 2 + 1, m + 1, r, ql, qr, x)

    build(1, 0, n - 1)

    ans = 0
    for i in range(n - 1):
        a, b = pref[i], suff[i + 1]
        if a == b or bad(1, 0, n - 1, 0, i, b) <= 1 or bad(1, 0, n - 1, i + 1, n - 1, a) <= 1:
            ans += 1
    return ans

def run(inp: str) -> str:
    data = list(map(int, inp.split()))
    t = data[0]
    idx = 1
    out = []
    for _ in range(t):
        n = data[idx]
        idx += 1
        arr = data[idx:idx+n]
        idx += n
        out.append(str(solve_case(arr)))
    return "\n".join(out)
