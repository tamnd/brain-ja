 ## 問題の理解

 私たちは、3 つの辺の長さが直接与えられるのではなく、それらの間の 3 つの比率によって制約される三角形を扱っています。 具体的には辺の長さ$AB$、$BC$、 そして$CA$3 つの比例関係を満たす必要があります。つまり、1 つの辺が固定されると、他の 2 つの辺も一定の比率に強制されます。 

したがって、入力は柔軟な三角形を記述しません。 厳密な「スケーリングまでの形状」を記述します。 すべての有効な三角形は、存在する場合、単一の基礎となる比例三角形を拡大縮小したものにすぎません。 

2 番目の要件は、三角形が非縮退でなければならないということです。つまり、正の面積を持つように厳密な三角形不等式を満たさなければなりません。 最後の要件は周囲長に関するものです。この三角形のすべての有効なスケール バージョンの中で、周囲長を整数にすることが可能かどうかを判断し、可能であれば、そのような最小の整数の周囲長を見つける必要があります。 

6 つの数字に対する制約は小さいですが、ここではそれが重要ではありません。 重要な観察点は、問題の構造により、すべてのジオメトリが 1 つの一貫性チェックとスケーリングの問題に分割されるため、どのような解決策も一定時間内に実行する必要があるということです。 

微妙な失敗例は、比率間の一貫性を無視した場合に発生します。 たとえば、比率が矛盾するスケーリングを暗示している場合（強制など）$AB > BC$強制しながらも$BC > AB$の場合、三角形はまったく存在しません。 もう 1 つの失敗例は、正の比率に対して三角形が常に存在すると仮定することですが、これは、暗黙の比例辺が三角形の不等式に違反する可能性があるため、誤りです。 

## アプローチ

 ブルートフォースの観点は、一方の側に値を割り当てることができると想像することから始まります。$AB = x$、次に、指定された比率を使用して他の 2 つの辺を導出します。 から$AB/BC = a/b$、間の関係が得られます。$AB$そして$BC$。 から$BC/CA = c/d$、別のペアをリンクし、から$CA/AB = e/f$、サイクルを閉じます。 単純なアプローチでは、次の任意の値を試します。$x$、結果の三角形を計算し、妥当性をテストしてから、どのスケーリングによって周囲が整数になるかを確認します。 

このアプローチの問題は、すべての実スケーリングにわたって継続的な検索が必要になることです。 スケーリングには制限がないため、総当り攻撃は無意味になり、候補は無限に多くなります。 

重要な観察は、比率が単一の乗算係数まで三角形の形状を完全に決定するということです。 比率が一貫していることを確認すると、すべての有効な三角形は、辺の比率の固定された 3 つの 1 つのスケーリングされたコピーにすぎません。 これにより、問題は、その比例トリプルが有効な三角形を形成するかどうかを確認し、スケーリングの下で​​周囲がどのような値を取ることができるかを理解することになります。 

その点に到達すると、「整数の周囲」制約は組み合わせ的なものではなくなり、固定有理和のスケーリングに関する純粋な数理論の問題になります。

 ## アルゴリズムのチュートリアル

 ### ステップ 1: 比率を代数制約に変換する

 治療します$AB = x$、$BC = y$、$CA = z$。 それぞれの比率は、これらの変数を結び付ける方程式になります。 これにより、幾何学の問題が比例制約のシステムに変わります。 

### ステップ 2: 比率が一貫しているかどうかを確認する

 3 つの比率方程式を組み合わせます。 サイクル全体でそれらを乗算すると、キャンセルが強制されます。$$\frac{AB}{BC} \cdot \frac{BC}{CA} \cdot \frac{CA}{AB} = 1$$したがって、入力は以下を満たす必要があります。$$\frac{a}{b} \cdot \frac{c}{d} \cdot \frac{e}{f} = 1$$これは次と同等です。$$ace = bdf$$これが失敗すると、システムは矛盾したスケーリングを強制するため、どの三角形もすべての制約を同時に満たすことができなくなります。 

### ステップ 3: 側面の比率を回復する

 一貫性が保たれると仮定して、すべての側面を単一のパラメータで表現します。$t$。 たとえば、$CA = t$。 それから：$$BC = \frac{c}{d} t, \quad AB = \frac{a}{b} \cdot \frac{c}{d} t$$つまり、三角形はスケーリングまで完全に決定されます。 

### ステップ 4: 三角形の有効性を確認する

 比例形式で厳密な三角形不等式をテストします。 不等式が成立しない場合、スケーリングではすべての比較が保持されるため、スケーリングでは問題を修正できません。 

### ステップ 5: 整数の境界条件を処理する

 周長は次のようになります。$$P = AB + BC + CA = t \cdot S$$どこ$S$は、比率によって決定される固定の正の有理数です。 

以来$t$は自由な正の実数パラメータです。これを選択して作成できます。$P$必要な正の実数値。 特に選択できるのは、$t = 1/S$、これにより周囲が正確に作成されます$1$。 三角形の不等式が満たされる場合、このスケーリングは有効なままになります。 

したがって、有効な三角形が存在する場合、最小の整数の周囲長は単純に次のようになります。$1$。 

### なぜ効果があるのか

 構造全体が単一方向のベクトルに崩壊します。$\mathbb{R}^3$横の比率を表します。 比率は、スケーリングに至るまでその方向を一意に修正します。 三角形の有効性は、大きさではなく、その方向のみに依存します。 妥当性が成立すると、スケーリングの自由により、任意の正の周囲値に到達できるため、整数制約は存在を超える制限を課すことはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def ok(a, b, c, d, e, f):
    # consistency of ratios: a/b * c/d * e/f = 1
    return a * c * e == b * d * f

def valid(x, y, z):
    return x + y > z and x + z > y and y + z > x

def solve():
    a = int(input())
    b = int(input())
    c = int(input())
    d = int(input())
    e = int(input())
    f = int(input())

    if not ok(a, b, c, d, e, f):
        print(-1)
        return

    # construct proportional sides
    # CA = 1
    z = 1
    y = c / d
    x = (a / b) * y

    if not valid(x, y, z):
        print(-1)
        return

    print(1)

if __name__ == "__main__":
    solve()
```コードは最初に巡回一貫性条件を強制します。これは、3 つの比率で実際の三角形を同時に記述することができる唯一の方法です。 次に、任意の正規化を使用して代表的な三角形を再構築します。$CA = 1$, since only proportions matter.

 三角不等式チェックは、これらの正規化された値に対して直接実行されます。 スケーリングは不等号の方向に影響を与えないため、一度確認すれば十分です。 

最終的に、出力は次のとおりです$1$なぜなら、有効な比例三角形は、周囲が正確に 1 つの整数値を持つようにスケーリングできるからです。

 ## 特殊なケース

 最も重要なエッジケースは、比率が個別には有効であるが、全体的には一貫性がない場合です。 その状況では、製品の状態は直ちに失敗し、アルゴリズムはジオメトリの再構築を試行せずに拒否します。 

もう 1 つのエッジ ケースは、比率が縮退三角形を定義する場合です。 サイクルの一貫性が保たれている場合でも、導出された比率は厳密な不平等ではなく等式を満たし、面積がゼロになる可能性があります。 アルゴリズムは、三角不等式のステップでこれらのケースを正しく拒否します。 

最後のエッジケースは、比率が極端に歪んでおり、一方が優勢になる場合です。 正規化ステップは、相対比較を正確に保持し、三角形の有効性が大きさではなく純粋に比例によって決定されるため、引き続き機能します。
