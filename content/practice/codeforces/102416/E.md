 ## 解決策
 ## 問題の理解

 3 次元空間には最大 100 個の球状の保護領域があります。 宇宙船 (i) には中心 ((x_i,y_i,z_i)) と半径 (r_i) があります。 元の球体が重ならないいくつかの宇宙船を選択する必要があります。 正確に 1 点をタッチすることは許可されます。 

宇宙船を選択すると、その責任は半径 (r_i) から半径 (3r_i) に拡大します。 展開された球は重なる場合があります。 要件は、すべての元の球の結合が、選択された宇宙船に属する拡張された球の結合に含まれなければならないことです。 

出力では、有効なサブセットを 1 つだけ指定する必要があります。 サブセットは最小限である必要はないため、動作が保証されている構造を見つけることに集中できます。 

2 つの球 (i) と (j) は、次の場合に正確に素になります。 

[
 d(i,j) \ge r_i+r_j,
 ]

 どこで

 [
 d(i,j)^2=(x_i-x_j)^2+(y_i-y_j)^2+(z_i-z_j)^2。 
]

 距離の二乗を使用すると平方根が回避され、すべての計算が整数に保たれます。 

制約 (n\le100) は (O(n^2)) の作業に十分小さいので、球のすべてのペアを比較できることを意味します。 (O(n^3)) 解もここでは数値的に小さくなりますが、それを使用する理由はありません。 すべてのサブセットにわたる指数探索は完全に不可能です。幾何学的チェックを行う前であっても、(2^{100}) は約 (1.27\cdot10^{30}) です。 

誤って処理されやすい境界ケースが 2 つあります。 まず、接触する球体の共存が許可されます。 例えば、```
2
0 0 0 1
2 0 0 1
```の中心は正確に 2 単位離れているため、球は接触しますが重なりません。 両方を選択でき、有効な出力は次のとおりです。```
2
1 2
```を使用した小切手`distance <= r1 + r2`このペアは誤って拒否されてしまいます。 

2 番目の境界はカバレッジに関するものです。 選択した球と交差するために球がスキップされたとします。 選択した球の半径は、少なくともスキップされた球の半径と同じである必要があります。 2 つの球が交差する場合、スキップされた球のすべての点は、選択した中心から最大 (r_i+r_j) の距離にあります。 (r_i\le r_j) であるため、これは最大でも (2r_j) であり、新しい半径 (3r_j) よりも小さくなります。 球を任意の順序で選択する不注意な実装では、重要な半径の比較が失われ、選択されたはるかに小さな球で大きな球をカバーできない可能性があります。 

例えば、```
2
0 0 0 10
10 0 0 1
```半径 10 の球を選択する必要があります。 小さな球が最初に選択され、元の球が交差するという理由だけで大きな球がスキップされた場合、拡張された半径 3 の球は大きな球をカバーしません。 半径を小さくして処理すると、この状況を防ぐことができます。 

## アプローチ

 最も直接的な強引なアプローチは、宇宙船のすべてのサブセットを試すことです。 サブセットごとに、選択した球のすべてのペアの重なりをチェックし、元のすべての球が拡張された球で覆われているかどうかをチェックできます。 (O(n^2)) の検証手順を使用した場合でも、(O(2^n n^2)) のコストがかかります。 (n=100) では、サブセット数だけで約 (1.27\cdot10^{30}) となるため、このアプローチは制限をはるかに超えています。 

有益な観察は、正しいサブセットを検索する必要がないということです。 半径を小さくして球を並べ替え、すでに保持されているすべての球から切り離されている球を貪欲に保持します。 

ばらばらな部分はすぐに発生します。 元の球が選択した球と交差していないことを確認した後でのみ、球を追加します。 

興味深いのはカバレッジです。 アルゴリズムが選択しない球 (A) を考えてみましょう。 (A) を考慮した時点で、以前に選択した球 (B) が (A) と交差する必要があります。 リストは半径の小さい順にソートされているため、

 [
 r_A\le r_B。 
]

 (A) 内の任意の点 (P) を取得します。 (B) の中心からの距離は最大で

 [
 |P-C_B|\le |P-C_A|+|C_A-C_B|
 \le r_A+(r_A+r_B)。 
]

 その式は最大でも (2r_A+r_B) ですが、(r_A\le r_B) であるため、最大でも (3r_B) になります。 したがって、(A) のすべての点は、(B) を中心とする半径 (3r_B) の球の内側にあります。 

実際には、もう少し緩いがより単純な境界を使用できます。 

[
 |P-C_B|\le r_A+r_A+r_B\le3r_B。 
]

 したがって、スキップされたすべての球は、以前に選択された球の 3 倍に拡張された球によって完全に覆われます。 

ブルート フォースは、両方の条件を満たすサブセットを明示的に検索するため機能しますが、サブセットが指数関数的に多いため失敗します。 半径が 3 倍になると、より大きな球が、交差するすべての小さな球を自動的にカバーするという観察により、検索は単純な貪欲な構築に変わります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(2^n n^2)) | (O(n)) | 遅すぎる |
 | 半径を小さくして欲張りに | (O(n^2+n\log n)) | (O(n)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 出力では入力のインデックスを使用する必要があるため、すべての宇宙船を読み取り、元のインデックスを保持します。 
2. 半径を小さくして宇宙船を並べ替えます。 2 つの半径が等しい場合、それらの間のどの順序も有効です。 
3. 選択した宇宙船の空のセットから始めます。 ソートされたリストを最大半径から最小半径に処理します。 
4. 現在の宇宙船 (i) について、すでに選択されているすべての宇宙船 (j) と比較します。 中心距離の二乗を計算する

 [
 d^2=(x_i-x_j)^2+(y_i-y_j)^2+(z_i-z_j)^2。 
]

 現在の球体は次の場合にのみ選択できます。 

[
 d^2\ge(r_i+r_j)^2
 ]

 選択されたすべての (j) について。 接触する球は互いに素であるとみなされるため、平等が許可されます。 

1. 現在の球体が選択したすべての球体から離れている場合は、それを答えに追加します。 それ以外の場合はスキップしてください。 
2. すべての球の処理が完了したら、選択したインデックスを印刷します。 アルゴリズムは常に有効な答えを生成するため、`NO`ブランチは決して必要ありません。 

### なぜ効果があるのか

 これまでに処理されたすべての球が選択されているか、選択された球の 3 倍に拡張された球によって完全に覆われているという不変条件を維持します。 

選択された球体は、それ自体の拡張された球体に元の球体が含まれるため、明らかに不変条件を満たします。 球をスキップすると、以前に選択した球 (j) と交差し、ソート順は (r_i\le r_j) になります。 スキップされた球内の任意の点 (P) について、

 [
 |P-C_j|
 \le |P-C_i|+|C_i-C_j|
 \le r_i+(r_i+r_j)
 =2r_i+r_j
 \le3r_j.
 ]

 したがって、スキップされた球全体は (j) の拡張された球によって覆われます。 同時に、球体は、以前に選択されたすべての球体と互いに素である場合にのみ選択されるため、選択されたすべての元の領域はペアごとに素なままになります。 両方の必須プロパティはすべての反復後に保持され、その結果、最終的な答えにも保持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    ships = []

    for i in range(1, n + 1):
        x, y, z, r = map(int, input().split())
        ships.append((r, x, y, z, i))

    # Larger spheres must be considered first.
    ships.sort(reverse=True)

    selected = []

    for r, x, y, z, idx in ships:
        can_take = True

        for sr, sx, sy, sz, sidx in selected:
            dx = x - sx
            dy = y - sy
            dz = z - sz

            dist2 = dx * dx + dy * dy + dz * dz
            radius_sum = r + sr

            # Touching is allowed, so equality is also disjoint.
            if dist2 < radius_sum * radius_sum:
                can_take = False
                break

        if can_take:
            selected.append((r, x, y, z, idx))

    print(len(selected))
    print(*[idx for _, _, _, _, idx in selected])

if __name__ == "__main__":
    solve()
```入力は元のインデックスと一緒に保存されるため、ソートによって宇宙船のアイデンティティが失われることはありません。 タプルは半径で始まり、次のことが可能になります。`sort(reverse=True)`より大きな半径を最初に処理します。 

すべての候補について、内側のループはそれを選択された球のみと比較します。 距離の二乗は半径の二乗和と比較されるため、浮動小数点演算は行われません。 これは、2 つの球が正確に接触する境界の場合を正確に処理する必要があるため、特に便利です。 

比較には、`<`それよりも`<=`。 もし

 [
 d^2=(r_i+r_j)^2、
 ]

 球体は接触しており、一緒に選択することが明示的に許可されています。 距離が厳密に小さい場合のみ、それらの内部が重なり合うことを意味します。 

Python の整数には任意の精度があるため、オーバーフローの問題はありません。 固定幅整数言語であっても、座標の差は最大 (10^4) であり、距離の二乗は (10^8) 程度になりますが、半径の二乗和も安全に小さくなります。 

アルゴリズムは決して印刷しない`NO`。 上記の証明は、球が 1 つだけある場合も含めて、半径が減少する構築によって常に有効なサブセットが得られることを示しています。

## テストケース

 以下のテスト ハーネスは、1 つの特定の有効なサブセットを必要とするのではなく、実際の幾何学的条件をチェックします。 これが必要なのは、この問題では有効な答えが許容されるため、正しい貪欲なタイブレークの選択が異なると、異なるインデックス セットが生成される可能性があるためです。```python
import sys
import io

def solve_data(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        n = int(sys.stdin.readline())
        ships = []

        for i in range(1, n + 1):
            x, y, z, r = map(int, sys.stdin.readline().split())
            ships.append((r, x, y, z, i))

        ships.sort(reverse=True)

        selected = []

        for r, x, y, z, idx in ships:
            ok = True

            for sr, sx, sy, sz, sidx in selected:
                dx = x - sx
                dy = y - sy
                dz = z - sz

                dist2 = dx * dx + dy * dy + dz * dz
                rr = r + sr

                if dist2 < rr * rr:
                    ok = False
                    break

            if ok:
                selected.append((r, x, y, z, idx))

        print(len(selected))
        print(*[idx for _, _, _, _, idx in selected])

        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

def validate(inp: str, out: str) -> bool:
    lines = out.strip().splitlines()
    if not lines:
        return False

    n = int(inp.splitlines()[0])
    data = [tuple(map(int, line.split())) for line in inp.splitlines()[1:]]

    k = int(lines[0])
    ids = list(map(int, lines[1].split())) if len(lines) > 1 else []

    if k != len(ids):
        return False
    if not (1 <= k <= n):
        return False
    if len(set(ids)) != k:
        return False
    if any(i < 1 or i > n for i in ids):
        return False

    selected = [data[i - 1] for i in ids]

    # Check that selected original spheres are pairwise disjoint.
    for i in range(k):
        x1, y1, z1, r1 = selected[i]
        for j in range(i + 1, k):
            x2, y2, z2, r2 = selected[j]

            dx = x1 - x2
            dy = y1 - y2
            dz = z1 - z2

            dist2 = dx * dx + dy * dy + dz * dz
            rr = r1 + r2

            if dist2 < rr * rr:
                return False

    # Check that every original sphere is covered by the union
    # of the expanded selected spheres.
    for x, y, z, r in data:
        covered = False

        for sx, sy, sz, sr in selected:
            dx = x - sx
            dy = y - sy
            dz = z - sz

            center_dist2 = dx * dx + dy * dy + dz * dz

            # The farthest point of the original sphere is
            # center distance + r, so coverage requires
            # center distance <= 3*sr - r.
            reach = 3 * sr - r

            if reach >= 0 and center_dist2 <= reach * reach:
                covered = True
                break

        if not covered:
            return False

    return True

def run(inp: str) -> str:
    out = solve_data(inp)
    assert validate(inp, out), f"Invalid output:\n{out}"
    return out

# Provided sample.
run("""4
1 0 0 1
2 0 0 1
7 0 0 1
10 0 0 3
""")

# Minimum-size input.
run("""1
5 5 5 7
""")

# Two spheres that only touch. Both may be selected.
run("""2
0 0 0 1
2 0 0 1
""")

# One large sphere intersects a smaller sphere.
# The larger one must be processed first so the smaller one is skipped safely.
run("""2
0 0 0 10
10 0 0 1
""")

# All spheres have identical centers.
# Only one original sphere can be selected, and its 3r expansion
# covers every identical sphere.
run("""4
100 100 100 2
100 100 100 2
100 100 100 2
100 100 100 2
""")

# Larger boundary-style case with 100 spheres.
# All are identical, so exactly one is needed.
large_case = "100\n" + "\n".join(
    f"{i} 0 0 1" for i in range(100)
)
run(large_case)

 ## 特殊なケース

 最初の境界ケースは正確な接線です。 のために```
2
0 0 0 1
2 0 0 1
```中心距離の二乗は (4) であり、半径の二乗和も (4) です。 重なる条件は、`dist2 < radius_sum * radius_sum`, したがって、球は一緒に受け入れられます。 それらの元の領域は接触するだけですが、問題ではこれが明示的に許可されています。 アルゴリズムは両方のインデックスを出力します。 

2 番目のエッジ ケースは、より大きな球と交差するより小さな球です。 のために```
2
0 0 0 10
10 0 0 1
```半径 10 の球が最初に処理され、選択されます。 中心距離 (10) が (11) より小さいため、半径 1 の球は拒否されます。 カバレッジを確認するために、小さな球の大きな中心からの最も遠い点は距離 (11) にあり、選択した球の半径は拡大されています (30)。 したがって、小さな球全体が覆われます。 

3 番目のエッジ ケースは、まったく同じ中心を持つ複数の球です。```
4
100 100 100 2
100 100 100 2
100 100 100 2
100 100 100 2
```最初の球が選択されます。 それ以降の球体は中心距離が 0、結合半径が 4 であるため、選択した球体と交差し、スキップされます。 選択した球は半径 6 に拡張されます。中心が同じであるため、元の半径 2 の 4 つの球がすべて含まれます。 これは、元の保護領域が多数存在する場合でも、アルゴリズムが安全に単一の宇宙船を返せる理由も示しています。 

4 番目のエッジ ケースは、接触する球体の長いチェーンです。 例えば、```
3
0 0 0 1
2 0 0 1
4 0 0 1
```隣接する球は接触しており、1 番目と 3 番目の球はつながっていないため、3 つの球すべてを選択できます。 厳密な重複テストでは、3 つすべてが選択されます。 実装が接線を交差として扱う場合、中央の球が誤って破棄され、構造が不必要に変更される可能性があります。 

最後のエッジケースは最大入力サイズ (n=100) です。 このアルゴリズムは依然として (O(n^2)) 個の幾何比較のみを実行します。 再帰、グラフ構築、浮動小数点ジオメトリ、またはサブセット列挙は必要ないため、最大ケースは問題なく制限内に収まります。
