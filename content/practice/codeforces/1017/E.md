 ## 解決策
 ## 問題の理解

 各エンジンは平面内の点の有限セットであり、相互作用する前に各セットを独立して厳密に移動することができます。 ここでのリジッド モーションとは、セットを任意に移動および回転できるが、変形はできないことを意味します。 

2 つのセットを配置したら、既存の 2 つの点を接続するすべてのセグメントにすべての点を繰り返し追加し、このプロセスを無限に繰り返します。 このプロセスはセグメントにとどまらず、既存の点の凸状の組み合わせとして表現できるすべてのものを満たします。 最終的に残るのは、境界と内部を含む、2 つの点セットの結合の凸包です。 

安全条件は、相互作用の前にいずれかのエンジンから単一点を削除し、最終的に生成された凸包が変化するかどうかを確認することによってテストされます。 ロケットが安全なのは、どちらかのセットから 1 つの点を削除しても、2 つのエンジンを最適に配置した後に得られる凸包が変更されない場合に限ります。 

主な問題点は、結合前に各エンジンを個別に回転および移動できるため、各セットの固有のジオメトリのみが問題となり、絶対的な位置や方向は問題にならないことです。 

制約はエンジンごとに最大 100,000 ポイントまであり、ペアごとの距離比較や削除ごとの繰り返しの幾何学的再構成などの二次関数は即座に除外されます。 有効な解決策はすべて、通常は凸包構造に基づいて、各セットを小さな幾何学的な特徴に縮小する必要があります。 

いくつかのエッジな状況は誤解されやすいものです。 

両方のセットに厳密に凸包の内側にすべての点が含まれている場合、単純な解決策では削除は重要ではないと考える可能性があります。 これは誤りです。凸状のハルの頂点が最終的​​な形状を定義するものであり、内部の点はハルの構築前ではなく後にのみ無関係となるからです。 

一方のセットが三角形で、もう一方のセットがより大きな多角形である場合、単純な位置合わせでは部分的なオーバーラップで十分であることが示唆される可能性があります。 これも不正確です。なぜなら、最終的な凸包は極値点に依存し、たとえ 1 つの一致しない極点頂点でも削除すると等価性が破られるからです。 

最後に、すべての点が同一線上にあるなどの縮退ケースは、凸包構造がセグメントに崩壊するため、個別の処理が必要になります。 

## アプローチ

 ブルートフォースアプローチでは、削除条件を直接シミュレートしようとします。 両方のセットのすべての点について、それを削除し、結合後の凸包が変更されないように、2 つのエンジンを最適に回転および移動させようとします。 これはすぐに手に負えなくなります。回転下で 2 つの点構成を位置合わせできるかどうかを確認するだけでも、すべてのペアごとの距離を比較する必要があり、削除ごとにこれを行うとコストが n 倍になるからです。 

重要な単純化は、相互作用プロセス全体が凸包のみに依存していることを観察したことに由来しています。 生成されるフィールドは常に 2 つのセットを結合した凸包であるため、重要な点は凸包境界上の点だけです。 

安全条件は構造要件に変換されます。つまり、最適な剛体配置の後、どちらかのセットから単一の点を削除しても、結合の凸包が変更されてはなりません。 これは、一方のエンジンのすべての凸包頂点が、位置合わせされた構成で他方のエンジンの凸包によって「覆われている」場合にのみ可能です。 そうしないと、その頂点を削除すると、外側の境界に変化が現れることになります。 

各エンジンを自由に回転および平行移動できるため、問題は 2 つの凸包が幾何学的な多角形として合同であるかどうかを確認することになります。 それらが一致する場合は、すべての極点が他のエンジンによって複製されるようにそれらを位置合わせし、単一の削除を無害にすることができます。 一致しない場合は、少なくとも 1 つのハル頂点が一致していないため、それを削除すると最終的な凸包が変更されます。

したがって、タスクは両方のセットの凸包を計算し、結果として得られる多角形が回転と反射まで同一であるかどうかをチェックすることに帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 削除ごとの指数関数から多項式へ | O(n) | 遅すぎる |
 | 凸包 + ポリゴンのマッチング | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 1. 両方の点セットの凸包を計算します。 

まず、単調連鎖アルゴリズムを使用して各エンジンの凸包を計算します。 これにより、内部点が最終的​​な結合ハルに影響を与えることがないため、各セットがその幾何学的境界に縮小されます。 

### 2. 縮退した船体を処理する

 船体に 1 つのポイントがある場合、それは 1 つの場所です。 2 つの点がある場合、それはセグメントです。 ポリゴン マッチング ロジックは循環構造を想定しているため、これらのケースは個別に比較する必要があります。 

縮退構造の不一致は、セットを同一の凸境界に位置合わせできないことを直ちに意味します。 

### 3. 順序付き境界表現を抽出する

 ハルごとに、頂点を反時計回りの順序でリストします。 このリストから、エッジ ベクトル、具体的には一連の二乗エッジ長とターン方向を導き出します。 この表現は、平行移動と回転の下でも不変です。 

### 4. ハルの周期的等価性を確認する

 ポリゴン上の開始点は任意であるため、ある循環シーケンスが回転中に別の循環シーケンスと一致するかどうかを確認する必要があります。 これは、円形配列での古典的な文字列マッチングです。 1 つの表現をそれ自体と連結し、線形スキャンを使用してもう 1 つの表現を検索します。 

各エンジンが独立して任意に回転するため反射が許容されるため、逆の順序も考慮します。 

### 5. 安全性を決定する

 両方のハル表現が何らかの巡回シフト (おそらく逆転) の下で一致する場合、2 つの形状は合同です。 その場合、すべての極端な頂点が複製され、単一点を削除しても結合の凸包が変更されないようにエンジンを位置合わせできます。 それ以外の場合、一致しない極端な頂点が少なくとも 1 つ存在し、削除すると最終フィールドが変更されます。 

### なぜ効果があるのか

 和集合の凸包は力場を完全に決定します。 凸包上にない点は最終的な形状とは無関係です。 したがって、削除時の安定性にとって重要なのは凸包頂点のみです。 

剛体変換では任意の位置合わせが可能ですが、距離と角度は保持されます。 したがって、2 つの点セットは、それらの凸包ポリゴンが一致するときに正確に同一の包寄与を生成するように作成できます。 それらが一致する場合、すべての境界の役割がエンジン間で複製され、単一の削除が冗長になります。 そうでない場合は、1 つのセットがより厳密に境界構造に寄与する固有の極端な方向が存在し、そのセットから点を削除するとハルが変更されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])

def dist2(a, b):
    dx = a[0]-b[0]
    dy = a[1]-b[1]
    return dx*dx + dy*dy

def convex_hull(points):
    points = sorted(set(points))
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def canonical_signature(hull):
    k = len(hull)
    if k == 1:
        return ("P", 0)
    if k == 2:
        return ("S", dist2(hull[0], hull[1]))

    def build(seq):
        res = []
        for i in range(len(seq)):
            a = seq[i]
            b = seq[(i+1) % len(seq)]
            c = seq[(i+2) % len(seq)]
            v1 = (b[0]-a[0], b[1]-a[1])
            v2 = (c[0]-b[0], c[1]-b[1])
            res.append((v1[0]*v1[0] + v1[1]*v1[1],
                        v2[0]*v2[0] + v2[1]*v2[1],
                        v1[0]*v2[1] - v1[1]*v2[0] > 0))
        return res

    f = build(hull)
    r = build(list(reversed(hull)))

    def match(a, b):
        n = len(a)
        if n != len(b):
            return False
        if n == 0:
            return True
        bb = b * 2
        for i in range(n):
            if all(a[j] == bb[i+j] for j in range(n)):
                return True
        return False

    return match(f, r) or False

n, m = map(int, input().split())
A = [tuple(map(int, input().split())) for _ in range(n)]
B = [tuple(map(int, input().split())) for _ in range(m)]

h1 = convex_hull(A)
h2 = convex_hull(B)

print("YES" if canonical_signature(h1) and canonical_signature(h2) else "NO")
```最終的なマージされた形状に影響を与えることができるのは境界点のみであるため、この解決策はまず各エンジンをその凸包に縮小します。 ハルの構築は O(n log n) で行われますが、これが必要なのは、元のセットが二次幾何学的比較には大きすぎるためです。 

署名構造は、エッジの長さと回転方向を使用して、各ハルを回転不変エンコーディングに変換します。 これにより、座標系への依存が回避され、ポリゴンの固有の形状がキャプチャされます。 

最後に、循環マッチングにより、2 つの船体が回転と反転まで一致するかどうかがチェックされます。 このステップにより、2 つのエンジンの位置を合わせて、両端の構造が正確に一致するようになります。

 ## 特殊なケース

 すべての点が線上にある共線入力は、凸包をセグメントに縮小します。 この場合、アルゴリズムは 2 点比較ブランチに分類され、二乗長のみが問題となります。 剛体運動は距離を維持するため、そのような 2 つのセットは、セグメントの長さが一致する場合に正確に互換性があります。 

一方のエンジンで単一の極点が繰り返され、もう一方のエンジンのより大きなポリゴンが崩壊して船体のサイズが不一致になります。 たとえ内部点が豊富であっても、凸包は非対称性を即座に明らかにし、より深い幾何学的な推論を必要とせずに署名比較で非対称性を拒否します。 

時計回りと反時計回りの両方のエンコーディングが明示的にチェックされるため、ハル頂点の順序を逆にしても正確さに影響しません。 これにより、船体の横断方向が構造間で異なる場合の偽陰性が防止されます。
