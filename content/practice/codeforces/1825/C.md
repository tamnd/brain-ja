 ## 解決策
 ## 問題の理解

 私たちは1から1までの番号が付けられた座席の列を与えられています。$m$そして$n$ショーにやってくる人々。 各人には好みの座席タイプがあります。つまり、左端の座席のすぐ左側に座りたい、右端の座席のすぐ右に座りたい、または特定の番号の座席に座りたい、ということです。 席が埋まったり、端に達したりして、希望どおりに座れない場合、その人は退席します。 目標は、人々が入場する順序を選択できる場合に、正常に座ることができる最大人数を決定することです。 

入力により人数が提供されます$n$そして総座席数は$m$、その後に配列が続きます$x$長さの$n$。 それぞれ$x_i$は座席の好みを示します。$-1$左隣接ルールの場合、$-2$右隣接ルールの場合は正の整数、特定の座席の場合は正の整数。 出力はテスト ケースごとに 1 つの整数、つまり座席を占有することができる最大人数です。 

制約を考慮すると、$n$そして$m$まで$10^5$すべてのテスト ケースの合計の上限も次のとおりです。$10^5$を超えるあらゆる解決策$O(n \log n)$テストケースごとにタイムアウトの危険がある可能性があります。 入場する人々のすべての順列を単純にシミュレーションするのは階乗時間であり、非現実的です。 エッジケースには、全員が同じ座席を希望するシナリオ、全員が左右の隣接する座席を希望するシナリオ、または貪欲な選択のバランスが必要な組み合わせが含まれます。 

小さな例で落とし穴を明らかにします。$n=3, m=5$と$x = [5, 5, 5]$, 全員が同じ席を対象としているため、座れるのは1人だけです。 すべての座席が空で、人々が左右どちらかのタイプの場合、最適な戦略は、欲張りに左から右、または右から左に座席を埋めるのではなく、両端からバランスよく座席を埋めることです。 

## アプローチ

 ブルートフォースソリューションでは、人々のすべての順列を試み、着席をシミュレートし、正常に着席した人の数を記録します。 これは正しいですが、順列の数が次のとおりであるため、実行できません。$n!$よりも早く成長します$10^{400,000}$のために$n \sim 10^5$。 

重要な洞察は、特定の席の人々は順序とは無関係に、個別の席を占有する必要があるということです。 左右隣の人の場合、着席できる最大人数は着席の左右の空席によって異なります。 特定の席の人を割り当てた後、さらに何人の左隣と右隣を競合せずに配置できるかを計算できます。 したがって、最適な順序は決定的です。つまり、特定の座席に座っているすべての人々を最初に着席させ、次に空いている左端の席の左隣と、空いている右端の右隣の座席を埋めます。 

効率的に実装するために、特定の座席番号を並べ替えて重複を排除し、最も左側の占有座席の左側と最も右側の占有座席の右側の空席を​​計算します。 結果は、個別の特定の座席の数に、残りの座席に収まる左隣と右隣の残りの最小人数を加えたものになります。

 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 左隣の人数のカウンタを初期化する`left_count`、右隣の人`right_count`、特定の座席番号をセットに収集します`specific_seats`。 
2. 重複を削除します`specific_seats`セットに変換して並べ替えると、両端の空のスペースが簡単に計算されます。 
3. 左端の特定の座席の左側にある空席の数を計算します。`left_empty = leftmost - 1`、そして一番右の特定の席の右側には、`right_empty = m - rightmost`。 
4. 着席できる左隣りの最大人数は、最小人数です。`left_count`そして`left_empty`。 同様に、右隣の最大人数は`min(right_count, right_empty)`。 
5. 残りの中央セクション (左端と右端の特定の座席の間) について、空席の数を計算します。`middle_empty = m - len(specific_seats) - max_left - max_right`。 この数値はゼロまたは正です。 
6. 合計最大着席数は`len(specific_seats) + max_left + max_right`、中央に空きスペースが残っている場合は、追加で左隣または右隣の人を重複せずに中央に 1 人収容できる場合は、さらに 1 人追加する可能性があります。 
7. 各テスト ケースの合計を出力します。 

機能する理由: 特定の座席に最初に着席させることで、絶対的な制約を修正します。 左隣の人も右隣の人も、衝突することなく端に隣接する席にのみ座ることができます。 空のスペースを並べ替えてカウントすることで、決して数えすぎないことが保証され、すべての制約が尊重され、全体的な最大値が生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_seated(n, m, x):
    left_count = x.count(-1)
    right_count = x.count(-2)
    specific_seats = sorted(set([xi for xi in x if xi > 0]))
    
    if not specific_seats:
        return min(n, m)
    
    left_empty = specific_seats[0] - 1
    right_empty = m - specific_seats[-1]
    
    max_left = min(left_count, left_empty)
    max_right = min(right_count, right_empty)
    
    middle_empty = m - len(specific_seats) - max_left - max_right
    total = len(specific_seats) + max_left + max_right
    # If there is a leftover left/right person that can fit in the middle
    if middle_empty > 0:
        total += 1
    return min(total, n, m)

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    x = list(map(int, input().split()))
    print(max_seated(n, m, x))
```このソリューションでは、まず左隣と右隣の人数をカウントし、次に固有の特定座席リクエストを抽出します。 並べ替えは、左右の拡張子の境界を決定するために不可欠です。 計算中`middle_empty`占領された境界の間に残った座席を説明します。 の`min(total, n, m)`総人数や総座席数を決して超過しないようにします。
