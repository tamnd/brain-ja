 ## 解決策
 ## 問題の理解

 のセットをご用意しております。$n$ツリー構造で接続された島。 つまり、任意の 2 つの島は 1 つのパスで接続されており、$n-1$エッジ。 LuoTianyiは会いたいです$k$それぞれが別の島に住む友人たち。 すべての島への合計距離を最小化する予想される島の数を計算するように求められます。$k$友達。 これらの島は良い島と呼ばれます。 出力はモジュロで計算する必要があります$10^9+7$分数の剰余逆乗算を表す整数として表現されます。 

制約は厳しいです:$n$到達できる$2 \cdot 10^5$、複雑なアルゴリズムは除外されます。$O(n^2)$以上。 すべてを列挙するアプローチ$k$- 島の要素サブセット。$O(\binom{n}{k})$、明らかに実行不可能です。 線形または線形に近いアプローチが必要です。$n$、おそらくツリーのプロパティまたは組み合わせ推論を使用します。 

考慮すべきエッジケースには、単一ノードなどの非常に小さなツリーが含まれます。$k=1$、フレンドの分布状況に応じて最適な島が変わる可能性があるチェーン。 不注意なアプローチでは、すべてのサブセットに対して単純に距離を計算しようとする可能性があり、時間とメモリの両方が爆発的に増加します。 

## アプローチ

 ブルートフォースアプローチは、すべてを列挙することです。$\binom{n}{k}$置き方$k$別々の島にいる友達。 配置ごとに、すべての島からこれらの友人までの距離の合計を計算し、最小合計に達する島を数えます。 これは問題定義を直接実装しているため機能しますが、複雑さは次のとおりです。$O(\binom{n}{k} \cdot n)$、これは大きすぎます。$n$は$2 \cdot 10^5$。 中程度の場合でも$k$、このアプローチは実行不可能です。 

重要な洞察は、すべての場所までの距離の合計が$k$友人は各エッジの寄与という観点から表すことができます。 ツリーでは、隣接するノード間の距離の合計の差は、それらが分離するサブツリーのサイズによって決まります。 任意のノードでツリーをルート化すると、ノードのサブセットまでの距離の合計は、各サブツリーに含まれる友人の数のみに依存します。 期待の線形性を使用すると、すべての配置を列挙することなく、良好なアイランドの期待数を計算できます。 具体的には、エッジごとに、エッジを横切ることで距離の合計が増加する確率を計算できます。 組み合わせ関数を使用すると、問題は次のように簡略化されます。$O(n)$事前に計算された階乗を使用した DFS ベースの計算により、高速な組み合わせが可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * C(n,k)) | O(n) | 遅すぎる |
 | DFS と組み合わせによる期待値 | O(n + k \log MOD) | O(n + k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 階乗および逆階乗モジュロを事前計算する$10^9+7$まで$n$。 これにより、組み合わせを計算できるようになります$C(n,k)$大規模向けに効率的に$n$そして$k$モジュラー演算を使用します。 
2. ノードでツリーを任意にルート化します$1$。 DFS を実行して各サブツリーのサイズを計算します。 させて`sz[u]`をルートとするサブツリー内のノードの数を示します。`u`。 
3. 親を接続する各エッジについて`u`そして子供`v`、ツリーは事実上 2 つの部分に分割されます。 すべてを配置する方法の数を計算します$k$完全に一方の側の友人。 これは$C(sz[v], k) + C(n - sz[v], k)$。 補数は、このエッジが距離の合計に寄与する構成の数を示します。 
4. 各ノードについて、期待される良好なアイランドの数は次のとおりです。$1$あるエッジが交差することで、他のエッジと比較してその距離の合計が増加する確率を引いたもの。 事前に計算されたエッジ確率を使用して、各ノードの寄与を合計します。 
5. 最終的な期待値のモジュロを計算します。$10^9+7$分数のモジュラー逆算を使用します。 

機能する理由: 距離合計に対するエッジの寄与をサブツリー サイズによって分離できるため、期待値の線形性により各エッジを独立して扱うことができます。 これにより、すべてのサブセットの列挙が回避され、友人の各配置の可能性が等しく、各エッジがそのエンドポイント間の距離合計の差に決定論的に寄与するため、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD-2, MOD)

def prepare_factorials(n):
    fac = [1]*(n+1)
    ifac = [1]*(n+1)
    for i in range(1, n+1):
        fac[i] = fac[i-1]*i % MOD
    ifac[n] = modinv(fac[n])
    for i in range(n-1, -1, -1):
        ifac[i] = ifac[i+1]*(i+1) % MOD
    return fac, ifac

def comb(n, k, fac, ifac):
    if k < 0 or k > n:
        return 0
    return fac[n]*ifac[k]%MOD*ifac[n-k]%MOD

n, k = map(int, input().split())
edges = [[] for _ in range(n)]
for _ in range(n-1):
    u, v = map(int, input().split())
    edges[u-1].append(v-1)
    edges[v-1].append(u-1)

fac, ifac = prepare_factorials(n)

sz = [0]*n
def dfs(u, p):
    sz[u] = 1
    for v in edges[u]:
        if v == p:
            continue
        dfs(v, u)
        sz[u] += sz[v]
dfs(0, -1)

total_ways = comb(n, k, fac, ifac)
res = 0
for u in range(n):
    bad = 0
    for v in edges[u]:
        s = sz[v] if sz[v] < sz[u] else n - sz[u]
        bad += comb(s, k, fac, ifac)
    good = (total_ways - bad) % MOD
    res = (res + good) % MOD

res = res * modinv(total_ways) % MOD
print(res)
```このソリューションは、高速な組み合わせ計算のために階乗と逆階乗を事前計算することから始まります。 次に、DFS を使用してサブツリーのサイズを計算します。 各エッジが評価されて、ツリーがどのように分割されるか、エッジ全体の距離の合計が増加するように友人を何通りに配置できるかが確認されます。 最後に、モジュラー演算を使用して、良好なアイランドの予想される数が計算されます。
