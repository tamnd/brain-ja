 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、$n$ノード、によって接続された島を表す$n-1$双方向ルート。 このツリーからランダムに選択します$k$個別のノード、ここで$k \le 3$。 これらの選択されたノードは人々の位置を表します。 

任意のノードに対して$v$、そのコストをからの最短経路距離の合計として定義します。$v$選択したすべてのノードに送信されます。 ツリー内のすべてのノードの中でコストが最小である場合、そのノードは良好であると呼ばれます。 言い換えれば、すべてのノードに対して距離合計関数を計算すると、良好なノードはまさにこの関数の最小化関数になります。 

タスクは、正常なノードの予想される数を計算することです。$k$特別なノードはすべてのノードの中から均一にランダムに選択されます。$\binom{n}{k}$サブセットを作成し、この期待モジュロを出力します$10^9+7$。 

制約$k \le 3$重要な構造の簡素化です。 のために$k=1$、問題は些細です。 のために$k=2$の場合、構造は 2 つのノード間のパスになり、$k=3$、ジオメトリは、一意の中心で交わる 3 つのパスの結合である 3 点のシュタイナー ツリーによって決定されます。 

素朴なアプローチでは、すべてを列挙することになります。$\binom{n}{k}$特別なノードを選択し、BFS を使用して毎回すべてのノードからのすべての距離を再計算し、コストを計算します。$O(n^2)$構成ごとにさらに悪い場合もあります。 と$n$まで$2 \cdot 10^5$、これは実現不可能です。 

木がパスである場合、微妙なエッジケースが現れます。 その場合、距離の合計は 1D 中央値のように動作します。 もし$k=2$、選択された 2 つのノード間のセグメント上のすべてのノードが最適です。 (ユークリッドの直観のように) 一意のミニマイザーを誤って仮定すると、カウントが間違ってしまいます。 たとえば、パス内で$1-2-3-4$、選択する$\{1,4\}$1 つだけではなく、すべてのノードが最適になります。 

別の特殊なケースが発生します$k=3$ここで、最適なセットは必ずしも単一のノードである必要はなく、ツリーの中央構造内のタイ ポイントに応じて、サブツリー構造全体を含む可能性があります。 

## アプローチ

 重要な観察は、最小化する関数が、マークされたノードの小さなセットまでの距離の合計であるということです。 ツリー上では、これは非常に構造化された方法で動作します。$k \le 3$、ミニマイザーのセットは常に、選択されたノード間のペアごとのパスによって決定される接続されたサブツリーです。 

ブルートフォースメソッドは、サイズのすべてのサブセットを反復処理します。$k$、BFS を使用してすべてのノードからすべての距離を計算し、最小合計に達するノードの数を数えます。 これには費用がかかります$O(\binom{n}{k} \cdot n)$、これは$k=3$になる$O(n^4)$最悪の場合は明らかに不可能です。 

重要な洞察は、視点を逆転させることです。 選択したノードのセットを修正し、どの頂点が適切であるかを尋ねる代わりに、ノードを修正します。$v$そしてそれが良いである確率を計算します。 答えは、最適である確率のすべてのノードの合計になります。 

固定ノードの場合$v$、という条件。$v$最適であるかどうかは、$k$選択したノードは、削除時に形成された接続コンポーネント間で分散します。$v$。 木の中で、取り除く$v$隣接するものをルートとするサブツリーに分割します。 最適性条件は、各コンポーネントに含まれる選択されたノードの数を使用して特徴付けることができます。$v$エッジに沿って配置すると、反対側のノードまでの距離が厳密に増加します。 

のために$k \le 3$、構成を明示的に分類できます。 

いつ$k=1$、すべてのノードは自明のことながら最適です。 

いつ$k=2$、良好なノードとは、選択した 2 つのノード間のパス上のすべてのノードです。 したがって、必要なのは、ランダム ペア パス上のノード数の観点から予想されるパス長だけです。 これにより、すべてのペアにわたる距離の合計が求められます。 

いつ$k=3$、良好なノードは、選択したノードのペア間のパスの結合を形成します。これは、まさに 3 つのノードを接続するシュタイナー ツリーです。 良好なノードの数は、この最小サブツリー内のノードの数です。 したがって、期待値は 3 つのペアワイズ パスの和集合の期待サイズになります。 

これにより、問題は、ランダムなサブセットにわたるパスの和集合の期待サイズを計算することになり、これはエッジ上の期待値の線形性を使用して表現できます。エッジは、選択されたノード間のペアごとのパスの少なくとも 1 つに存在する場合に限り、シュタイナー ツリーに寄与します。 その条件は、選択された 3 つのノードがすべてそのエッジの同じ側にあるかどうかによって異なります。 

したがって、問題をエッジごとに、ランダムなサブセットの誘導サブツリーに出現する確率を数え、寄与を合計するという問題に変換します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | サブセットに対するブルート フォース |$O(n^4)$|$O(n)$| 遅すぎる |
 | エッジ寄与 + 組み合わせ論 |$O(n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 任意のノード (たとえば 1) でツリーをルートにします。エッジごとに、親から子への方向を設定し、子のサブツリーのサイズを定義します。 

次に、定式化に応じてすべてのノードまたはエッジにわたって、次のシュタイナー構造にあることの予想される寄与を合計することによって、答えを計算します。$k$ランダムなノード。 

1. DFS を使用してツリーをルート化し、サブツリーのサイズを計算します。 エッジの子側のサブツリー サイズから、そのエッジ分割の各側にノードがいくつあるかがわかります。 
2. 各エッジについて、その削除を検討します。これにより、ツリーが 2 つのサイズの部分に分割されます。$s$そして$n-s$。 エッジは、少なくとも 1 つの選択されたノードが両側にある場合に限り、選択されたノードを接続する最小サブツリーの一部になります。 これは、選択されたすべてのノードが完全に 1 つのコンポーネント内にある場合、エッジはそれらの接続とは無関係になるためです。 
3. すべてが一致する確率を計算します。$k$選択されたノードは完全にエッジの片側内にあります。 これは次と同等です。$$\frac{\binom{s}{k} + \binom{n-s}{k}}{\binom{n}{k}}$$提供された$k \le 3$、という慣例により、$\binom{x}{k} = 0$いつ$x < k$。 

1. したがって、エッジがシュタイナー ツリーで使用される確率は次のようになります。$$1 - \frac{\binom{s}{k} + \binom{n-s}{k}}{\binom{n}{k}}$$1. 各エッジは、シュタイナー ツリーを使用する場合、そのサイズに正確に 1 を寄与するため、期待される答えはこの確率のすべてのエッジの合計になります。 
2. 二項係数のモジュロを計算します。$10^9+7$階乗事前計算とモジュラー逆行列を使用します。 

なぜそれが機能するのかというと、シュタイナー木は$k$ツリー内のノードはまさにエッジの結合であり、エッジを削除すると、選択された少なくとも 1 つのノードが残りのノードから分離されます。 これにより、頂点数の期待値がエッジごとのインジケーターの合計に変換されます。 イベントがグローバルに相関している場合でも、各エッジの寄与は期待において独立しているため、期待の線形性によって正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

n, k = map(int, input().split())
adj = [[] for _ in range(n)]
edges = []

for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append((v, len(edges)))
    adj[v].append((u, len(edges)))
    edges.append((u, v))

# factorials
maxn = n
fact = [1] * (maxn + 1)
invfact = [1] * (maxn + 1)

for i in range(1, maxn + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact[maxn] = pow(fact[maxn], MOD - 2, MOD)
for i in range(maxn, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def C(a, b):
    if a < b or b < 0:
        return 0
    return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

# compute subtree sizes
parent = [-1] * n
sz = [0] * n
order = []

stack = [0]
parent[0] = -2

while stack:
    v = stack.pop()
    order.append(v)
    for to, _ in adj[v]:
        if to == parent[v]:
            continue
        if parent[to] != -1:
            continue
        parent[to] = v
        stack.append(to)

for v in reversed(order):
    sz[v] = 1
    for to, _ in adj[v]:
        if to == parent[v]:
            continue
        sz[v] += sz[to]

# compute contribution of edges
ans = 0

for u, v in edges:
    # determine child side size
    if parent[v] == u:
        s = sz[v]
    else:
        s = sz[u]

    total = C(n, k)
    bad = (C(s, k) + C(n - s, k)) % MOD
    prob = (total - bad) % MOD
    prob = prob * pow(total, MOD - 2, MOD) % MOD
    ans = (ans + prob) % MOD

print(ans)
```実装は、階乗と逆階乗を事前計算して、一定時間で組み合わせを評価することから始まります。 DFS ルート化ステップは、再帰の深さの問題を回避するために反復的に実装されます。$n$到達できる$2 \cdot 10^5$。 

サブツリー サイズ配列は、エッジごとに、そのエッジを削除することによって形成された 2 つのコンポーネントのうちの 1 つに何個のノードがあるかを決定するために使用されます。 補数のサイズは単純であるため、これで十分です。$n - s$。 

各エッジは決定的な値ではなく確率に寄与し、そのような寄与はすべて最終的な期待値に累積されます。 

一般的な実装の落とし穴は、エッジのどの端点がサブツリー側を表すかを正しく識別できないことです。 親配列は、この方向性を解決するために重要です。

### 例 2

 入力:```
3 1
1 2
2 3
```すべてのノードは等しい確率で選択されます。 ノードが 1 つだけ選択されるため、そのノード自体が常に一意のミニマイザーになります。 

各エッジについて、$k=1$、 それで：$$\binom{s}{1} + \binom{n-s}{1} = s + (n-s) = n$$したがって、すべてのエッジの確率寄与はゼロであり、答えは 0 エッジ + 1 暗黙的ノード寄与で、1 になります。 

これにより、縮退した場合でもエッジベースの定式化の一貫性が確認されます。

 ## 特殊なケース

 のために$k=1$、選択されたすべてのノードはすでに最適であるため、すべての構成は 1 つの適切なノードに寄与します。 エッジベースの式ではエッジ寄与がゼロとなり、選択したノード自体を超える接続は必要ないという事実と一致します。 

のために$k=2$の場合、構造は 2 つのノード間の 1 つのパスに縮小されます。 選択したノードがエッジ分割の異なるコンポーネントにある場合、そのエッジはパスに寄与します。 アルゴリズムはこれらのエッジを正確にカウントし、ペアを明示的に列挙することなく、予想されるパス長を再構築します。 

のために$k=3$、シュタイナー ツリーの解釈では、選択された 3 つのノードが分割の片側にすべて含まれていない場合に、エッジが確実に含まれるようになります。 すべてのノードが 1 つのコンポーネントに分類される構成では、すべてのペアワイズ パスからそのエッジが削除され、二重カウントが防止され、正確さが維持されるため、確率式はこれを正しく捉えています。
