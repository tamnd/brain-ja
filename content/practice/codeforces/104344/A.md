 ## 解決策
 ## 問題の理解

 正確に分配できるか問われる$K$間のキャンディー$N$2 つの制約の下にある子供たち。 すべての子供は少なくとも受け取らなければなりません$L$子供はそれ以上のキャンディーを受け取ることはできません$R$キャンディー。 すべてのキャンディーを使用しながら、すべての子供を同時に満足させる整数の割り当てが存在するかどうかを判断する必要があります。 

これは基本的に、制限された割り当てに関する実現可能性の問題です。 各子は変数に貢献します$x_i$そのような$L \le x_i \le R$、およびすべての合計$x_i$等しい必要があります$K$。 問題は次のとおりです。$K$は、これらの有界変数によって形成される合計の達成可能な範囲内に収まります。 

制約は十分小さいので、$O(N)$または$O(1)$計算は簡単です。 価値観$N \le 10^3$、$K \le 10^6$、 そして$R \le 10^5$つまり、分布をシミュレートしたり、割り当てを検索したりすることは期待されていません。 代わりに、合計の厳密な下限と上限を導き出すことに重点を置く必要があります。 

可能な最小合計がすでに超えている場合、微妙なエッジケースが発生します。$K$、または可能な最大合計が依然として より小さい場合$K$。 もう 1 つのエッジケースは次のような場合です$L = R$、これはすべての子供にまったく同じ数のキャンディーを受け取ることを強制し、問題を厳密な割り算チェックに変えます。 たとえば、次の場合$N = 3$、$L = R = 3$の場合、可能な合計は次のとおりです。$9$。 どれでも$K \neq 9$すぐに失敗しなければなりません。 

もう一つのコーナーケースは、$L = 0$, これにより、一部の子供たちは何も受け取ることができなくなりますが、それでも上限により合計が制限されます。 その場合、実現可能性は完全に次のとおりであるかどうかに依存します。$K \le N \cdot R$。 

## アプローチ

 強引な解釈では、子ごとにキャンディーを割り当てようとします。 それぞれの子供について、次の範囲内のすべての値を試すことができます。$L$そして$R$、すべてのキャンディーがなくなるまで残りのキャンディーを再帰的に分配します。$N$子には値が割り当てられます。 これにより、およその分岐係数が生成されます。$R - L + 1$子ども一人当たり、$(R-L+1)^N$可能な構成。 境界が小さい場合でも、これは不可能です。$N$到達できる$10^3$、列挙が天文学的に大きくなります。 

重要な観察は、個々の分布は気にせず、合計が存在するかどうかだけを気にするということです。 各子は固定間隔内で独立して貢献するため、すべての可能な合計のセットは、達成可能な最小の合計から達成可能な最大の合計までの連続範囲を形成します。 

すべての子供が受け取るときに最小額が発生します$L$、与える$N \cdot L$。 最大合計額は、すべての子供が受け取るときに発生します。$R$、与える$N \cdot R$。 各子を整数ステップで個別に調整できるため、これら 2 つの極端な値の間のすべての整数値が達成可能です。 したがって、問題は次のことを確認することになります。$K$狭間にある$[N \cdot L, N \cdot R]$。

 ## アルゴリズムのチュートリアル

 1. キャンディーの最小合計を次のように計算します。$N \cdot L$。 これは、すべての子供が最低許容額を受け取る場合を表しており、有効な分配はこの値を下回ることはできません。 
2. キャンディーの最大合計を次のように計算します。$N \cdot R$。 これは、すべての子供が最大許容額を受け取る場合を表しており、有効な分配はこの値を超えることはできません。 
3. かどうかを確認します。$K$この間隔内にあります。 もし$N \cdot L \le K \le N \cdot R$の場合、有効な分布が存在します。 それ以外の場合は、そうではありません。 
4. 出力`'S'`可能であれば出力、そうでなければ出力`'N'`。 

ステップ 3 の背後にある理由は、各子の貢献は同じ範囲内で個別に増減できるため、合計がギャップに断片化されないということです。 代わりに、達成可能な整数の連続した範囲を形成します。 

### なぜ効果があるのか

 重要な不変条件は、子のサブセットを処理した後、達成可能な合計が連続した間隔を形成するということです。 当初、子がゼロの場合、達成可能な合計は次のとおりです。$0$。 子を 1 つ追加すると、値を追加することで達成可能な合計が拡張されます。$[L, R]$、間隔をシフトして結合しますが、ギャップを作成することはありません。 これを繰り返すと$N$回は連続性を維持するため、合計の最終セットは正確に次のすべての整数になります。$N \cdot L$そして$N \cdot R$。 したがって、この間隔でメンバーシップを確認することは必要かつ十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, K, L, R = map(int, input().split())
    
    min_sum = N * L
    max_sum = N * R
    
    if min_sum <= K <= max_sum:
        print('S')
    else:
        print('N')

if __name__ == "__main__":
    solve()
```実装は導出された境界に直接に従います。 必要な計算は 2 つの乗算と比較だけです。 Python の任意精度の整数を使用すると、中間値が次の値に達した場合でもオーバーフローの問題を回避できます。$10^8$以上。 

数学的条件を明確に反映するために、決定ロジックは最後に配置されます。 追加のデータ構造やループは必要ありません。

 ## 特殊なケース

 重要なエッジケースの 1 つは次のような場合です。$L = R$、すべての子供に同じ数のキャンディーを強制的に受け取ります。 入力の場合:```
3 9 3 3
```アルゴリズムが計算します$min\_sum = 9$そして$max\_sum = 9$。 以来$K = 9$、条件は正確に当てはまり、出力は次のようになります。`'S'`。 9 からの逸脱は、間隔が 1 つの点に崩壊するため、直ちに失敗します。 

もう 1 つのエッジケースは次のような場合です$L = 0$、柔軟な配布が可能になります。```
5 7 0 3
```ここ$min\_sum = 0$、$max\_sum = 15$。 7 はこの間隔内にあるため、アルゴリズムは正しく出力します。`'S'`。 重要な点は、個々の子がゼロを受け取ることができるとしても、上限は依然として合計最大値によってのみ実現可能性を制限するということです。 

3 番目のエッジケースは次のような場合です。$K$非常に大きいですが、整数演算の範囲内にあります。```
1000 1000000 0 1000
```可能な最大合計は正確に次のとおりです$1{,}000{,}000$、したがって、答えは次のとおりです`'S'`。 Python の整数は自然にスケーリングされるため、アルゴリズムはオーバーフローや特殊なケースを使用せずにこれを処理します。
