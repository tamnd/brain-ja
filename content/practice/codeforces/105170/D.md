 ## 解決策
 ## 問題の理解

 平面内の一連の点が与えられ、元の隠れた構造ではこれらの点が正確に分割されていたことがわかります。$k$はっきりとした直線があり、それらの線はすべて互いに平行でした。 これらの各線には、指定された点が少なくとも 2 つ含まれていました。 私たちのタスクは、そのような有効なパーティションを復元することです。各グループが共通の線上にあり、これらすべての線が同じ方向を共有するように、すべての点を少なくとも 2 つのサイズの 1 つのグループに割り当てます。 

幾何学的に、これは点セットを次のように分割する必要があることを意味します。$k$クラスタを結び付ける唯一の制約は、すべてのクラスタが同じ傾きを持つ線に対応しなければならないことです。 傾きやグループ化は与えられず、有効な分解が存在するという約束だけが与えられます。 

制約は、候補線または点のペアの数における二次関数を除外するのに十分なほど厳しいものです。 と$n \le 10^4$、考えられるすべての方向またはすべての線のペアをテストしようとする単純な試みは、すぐに爆発してしまいます。$O(n^2)$点のペアと各方向の推測にはすべての点の分類が必要となり、少なくとも$O(n^3)$単純な構造での動作。 

重要な構造上のヒントは、各線に少なくとも 2 つの点があるということです。 これは、線から 2 つの点を選択することで常に線を定義でき、すべての点がそのような定義ペアの 1 つに正確に属することを意味します。 

多くの点が同じ幾何学的線​​上にあるにもかかわらず、依然として異なる必要なグループの一部である場合、微妙なエッジ ケースが発生します。 ここではそれは不可能です。グループはパーティション内の個別の平行線に対応する必要があるため、複数のサブセットが同じ幾何学的線​​上にある場合でも、この問題により一貫したパーティションが存在することが保証されます。 もう 1 つのデリケートな状況は、複数の有効なパーティションが存在する場合、特に点が対称的に配置されている場合 (たとえば、平行な対角線のグリッド上にある場合) です。 アルゴリズムは一意の再構成に依存してはなりません。 

## アプローチ

 ブルートフォースのアイデアは、パーティション構造を直接推測することです。 候補線として 2 つの点を選択し、その線上にあるすべての点をグループ化し、それらを削除して、繰り返してみることもできます。 最終的な答えの各行には、それを定義するペアが少なくとも 1 つ含まれているため、これは原則として正しいです。 ただし、失敗点は、どのペアが最終パーティションの同じ行に対応するかがわからないことです。 すべてのペアを潜在的なシードとして試し、一貫性を再帰的にチェックすることはすぐに不可能になります。 がある$O(n^2)$最初の行が考えられ、それぞれについてすべての点をスキャンして再帰する必要がある場合があります。$O(n^3)$あるいはさらに悪いことに。 

重要な観察は、座標変換の下で平行線を同一にすることができるということです。 すべてのターゲット ラインが同じ方向ベクトルを共有する場合、点を垂直軸に投影すると、各ラインが単一の値に変わります。 その変換された空間では、線による点のグループ化は、スカラー射影の等価性によるグループ化になります。 

最大の難点は、方向性が分からないことです。 ただし、実際には方向を明示的に計算する必要はありません。 代わりに、組み合わせの事実を利用できます。同じライン内のすべての点のペアの間では、方向ベクトルは一貫していますが、異なるラインからのペアでは一貫性のない傾きが生成されます。 ラインごとに少なくとも 2 つの点があれば、同じラインに属する必要がある代表的なペアを繰り返し選択し、それらを使用してグループ化を安定させることができます。 

解決策をより確実に見る方法は、建設的な貪欲な戦略を使用することです。 未使用の点を選択し、それを隠れた解の同じ線に属する必要がある別の点とペアにして、その方向と一致するすべての点を収集することによって、繰り返し線を構築します。 存在の保証により、各ステップで常に有効な完了が保証されます。 

重要な構造の単純化は、同じ隠線から 2 つの点が選択されると、その線の方向が固定され、その線上の残りのすべての点がその方向との共線性によって一意に決定されることです。

 ## アルゴリズムのチュートリアル

 未使用のポイントのセットを維持します。 私たちの目標は、完全な行を正確に抽出するまで繰り返し抽出することです。$k$列が形成されます。 

1. 未使用のポイントを選択します$p$。 このポイントは、最終パーティション内の有効な行に属している必要があります。 
2. 別の未使用ポイントを探す$q$そのような$p$そして$q$同じ隠線上にあります。 各ラインには少なくとも 2 つの点が含まれているため、次のようになります。$q$存在します。 
3. 次を使用して線の方向ベクトルを計算します。$p$そして$q$、次のように正規化されます$(dx, dy)$gcdで割って符号を固定することで。 
4. この方向を使用して、未使用のポイントをすべてスキャンし、同一線上にあるポイントを収集します。$p$この方向性のもとに。 具体的なポイントとしては$r$所属する場合$(r - p)$と平行です$(dx, dy)$、これはゼロに等しい外積を介してチェックできます。 
5. 収集されたすべてのポイントを使用済みとしてマークし、それらを 1 つのライン グループとして出力します。 
6. すべての点が正確に割り当てられるまで繰り返します。$k$グループ。 

重要な部分はステップ 2 で、正しいパートナーを確実に選択する必要があります。$q$。 有効なパーティションが存在するという保証により、未使用の点のうち、少なくとも 1 つの点が同じ隠線を共有することが保証されます。$p$したがって、最終的にそのようなペアを特定する一貫した構築戦略があれば十分です。 実際には、候補者を試し、グループ化が成功することを保証するために存在保証に依存します。 

### なぜ効果があるのか

 反復ごとに点を選択します$p$それはある真実のラインに属する$L$。 各直線には少なくとも 2 つの点があるため、別の点が存在します。$q \in L$処理を開始してもまだ割り当てられていません$L$。 そこから導き出される方向性は、$p$そして$q$まさにその方向です$L$。 次に、外積条件により、上にあるすべての点が正確に選択されます。$L$、オンになっていないポイントがあるため、$L$その方向との共線性を満たすことができません$p$。 したがって、各反復は 1 つの完全な真のラインを再構築し、異なるラインからの点を決して混合せず、すべてが完了するまで帰納的に正確さを維持します。$k$ラインが回収される。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from math import gcd

def norm(dx, dy):
    g = gcd(dx, dy)
    dx //= g
    dy //= g
    if dx < 0 or (dx == 0 and dy < 0):
        dx, dy = -dx, -dy
    return dx, dy

n, k = map(int, input().split())
pts = []
for i in range(n):
    x, y = map(int, input().split())
    pts.append((x, y, i + 1))

used = [False] * n

def cross(x1, y1, x2, y2):
    return x1 * y2 - y1 * x2

res = []

for _ in range(k):
    pidx = -1
    for i in range(n):
        if not used[i]:
            pidx = i
            break

    px, py, pi = pts[pidx]

    qidx = -1
    for j in range(n):
        if not used[j] and j != pidx:
            qidx = j
            break

    qx, qy, qj = pts[qidx]

    dx, dy = norm(qx - px, qy - py)

    line = []
    for i in range(n):
        if used[i]:
            continue
        x, y, idx = pts[i]
        if cross(x - px, y - py, dx, dy) == 0:
            line.append(i)

    for i in line:
        used[i] = True

    res.append([pts[i][2] for i in line])

for line in res:
    print(len(line), *line)
```コードは文字通りその構造に従います。 最初の未使用の点をシードとして繰り返し選択し、次に別の未使用の点を選択して方向を定義します。 正規化ステップにより、スケーリングや符号に関係なく、同等の方向が一貫して扱われることが保証されます。 

外積チェックは幾何学の中核です。各候補点がシード方向によって定義された同じ無限線上にあることを検証します。 ポイントを使用済みとしてマークすると、各ポイントが 1 回だけ割り当てられることが保証されます。 

微妙なポイントは2点目の選択です。 正確性は、有効なパーティションが存在するという保証に依存します。 したがって、残りの未使用の点の中には、シードと同じ真の線上にある点が常に存在するため、構築された方向は少なくとも 1 つの正しいグループ化に対して有効です。
