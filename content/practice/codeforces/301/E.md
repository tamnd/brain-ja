 ## 解決策
 ## 問題の理解

 3 つの整数が与えられます。 配列の長さは次を超えることはできません`n`、すべての値は次の範囲内にある必要があります。`1`そして`m`、特別な隣接ルールを満たす個別の周期的配置の数は、次の範囲内である必要があります。`1`そして`k`。 

隣接ルールは「適切な」配列を定義します。 適切な配列では、隣接するすべてのペアが正確に異なります。`1`、最後の要素と最初の要素によって形成されるペアを含みます。 したがって、配列は、すべてのステップが 1 つずつ上昇または下降するサイクルを形成します。 

適切な配列を直接カウントするように求められるわけではありません。 代わりに、非減少配列を考慮します。`b`。 その要素を任意に並べ替えることができます。 すべての順列の中に次のものがある場合、`1`そして`k`明確な良好な循環配列、その後`b`偉いと言われます。 素晴らしい非減少配列がいくつあるかを数えなければなりません。 

主な難点は、入力配列はソートされているものの、プロパティは考えられるすべての再配置に依存することです。 どの数値の複数セットが有効なサイクルを形成できるか、またそれらが生成する個別のサイクルの数を正確に理解する必要があります。 

制約は、多項式動的計画法を可能にするのに十分小さいですが、順列に対するブルートフォースには大きすぎます。 以来`n`、`m`、 そして`k`せいぜい全部です`100`、周りの解決策`O(n^3)`または`O(n^4)`許容されます。 指数関数的なものは何でも`n`不可能です。 

問題の最も危険な部分は、適切な配列が実際にどのようなものかを理解することです。 単純な実装では、マルチセットのすべての順列を生成し、循環条件をチェックしようとする場合があります。 長さに関しても`10`、それはすでに大きくなりすぎています。 

構造を完全に変えるいくつかのエッジケースがあります。 

考慮する：```
1 1 1
```単一要素サイクルには次のことが必要です`|a1 - a1| = 1`、それは不可能です。 したがって、答えは次のとおりです`0`。 

もう 1 つの微妙なケースは、異なる値を含むマルチセットです。`1`。 

例えば：```
n = 3, m = 3
multiset = {1, 3}
```すべての隣接するペアは正確に異なる必要があるため、順列は機能しません。`1`。 カウントのみをチェックする不注意な実装では、誤って受け入れられる可能性があります。 

最も重要な構造上のエッジケースはパリティです。 

マルチセットを取り上げます。```
{1, 1, 2, 2}
```次のように整理できます。```
1 2 1 2
```これは良いですね。 

しかし：```
{1,1,1,2,2}
```最終的には 2 つの等しい値が隣接する必要があるため、循環的な交互シーケンスを形成することはできません。 

これは中心的な観察につながります。すべての良好なサイクルは 2 つの連続する値の間で交互に起こり、両方の値は同じ回数出現する必要があります。 

この特性を理解すると、問題は完全に変わります。 

## アプローチ

 ブルートフォースアプローチは概念的には単純です。 すべての非減少配列を生成します`b`、そのマルチセットのすべての個別の順列を生成し、どの順列が巡回隣接条件を満たすかを確認し、有効なサイクルがいくつ存在するかをカウントします。 

1 つの順列をチェックするのは簡単です。 私たちは次のことのみを検証します。```
|a[i] - a[(i+1)%r]| = 1
```あらゆるポジションに。 

問題は順列の数です。 長さに関しても`100`、明確な再配置の数は天文学的です。 それらを列挙する機会はありません。 

次のステップは、優れた循環配列の構造を研究することです。 

値を仮定します`x`良いサイクルのどこかに現れます。 すべての隣人`x`その場合はどちらかでなければなりません`x-1`または`x+1`。 サイクルが閉じているため、すべての値は連続した整数の接続されたチェーンに属している必要があります。 

次に、3 つの異なる値が表示されるとします。```
x, x+1, x+2
```値`x`にのみ接続できます`x+1`、 そして`x+2`にのみ接続できます`x+1`。 最終的には、2 つの等しい値が隣接することになり、ルールに違反します。 

可能な構造は、正確に 2 つの連続する値だけです。 

したがって、すべての良いサイクルは次のものだけで構成されます。```
x and x+1
```さらに、サイクルは交互に行われる必要があります。```
x, x+1, x, x+1, ...
```これは、両方の値が同じ回数出現することを直ちに意味します。 

それぞれの値が表示される場合`t`倍すると、サイクルの長さは`2t`。 

このようなマルチセットは、適切な循環配列をいくつ生成しますか?

 開始位置が固定されると、サイクル全体が交互に強制されます。 正確に 2 つの可能性があります。```
x, x+1, x, x+1, ...
x+1, x, x+1, x, ...
```長さがゼロでない限り、これら 2 つは別個のものです。 

したがって、すべての有効なマルチセットは正確に生成します`2`良い配列。 

つまり、「1 ～ k 個の適切な配列の間」という条件は非常に単純になります。 

もし`k = 1`、答えはいつも`0`。 

もし`k >= 2`、すべての有効なマルチセットが寄与します。 

ここで、問題は、マルチセットに等しい正の頻度を持つ 2 つの連続する値が含まれる非減少配列をカウントすることに帰着します。 

値を仮定する`x`表示されます`t`時代と価値`x+1`表示されます`t`回。 

ソートされた配列は一意に次のようになります。```
x x x ... x (t times)
x+1 x+1 ... x+1 (t times)
```だからどのペアも`(x, t)`正確に 1 つの優れた配列を定義します。 

構造を縮小すると、制約は些細なものになります。

 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | 指数 | 遅すぎる |
 | 最適 | O(nm) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`n`、`m`、 そして`k`。 
2. もし`k < 2`、印刷`0`。 

有効な良いサイクルは常に正確な結果をもたらします`2`2 つの交互の開始点に対応する個別の配列。 したがって、マルチセットでは適切な配列を 1 つだけ生成することはできません。 

1. 可能なすべての小さい値を反復処理します。`x`。 

より大きな値は次のようになります。`x+1`、 それで`x`からの範囲`1`に`m-1`。 

1. 考えられるすべての頻度で反復します。`t`。 

全長はこうなります`2t`したがって、次のものが必要です。```
2t <= n
```1. 各ペアを数えます`(x, t)`一度。 

ソートされた配列は一意に決定されます。```
[x repeated t times, x+1 repeated t times]
```2 つの異なるペアが同じ配列を生成することはありません。 

1. カウントモジュロを出力します。`1e9+7`。 

ここでの数字は小さいですが、私たちは依然としてこの声明に従っています。 

### なぜ効果があるのか

 循環良好配列は、隣接するすべての差が等しいことを満たさなければなりません。`1`。 これにより、すべての要素が隣接する値にのみ接続されるようになります。 3 つ以上の異なる値が出現すると、最終的にはサイクル内のどこかで 2 つの等しい値が隣接するようになります。 したがって、連続する値は 2 つだけ存在する可能性があります。 

値を使用するサイクルの場合`x`そして`x+1`、すべてのポジションを交互に配置する必要があります。 これは、周波数が等しい場合にのみ可能です。 

マルチセットが固定されると、どの値が交互を開始するかに応じて、正確に 2 つの循環配列が存在します。 したがって、すべての有効なマルチセットは次の場合に寄与します。`k >= 2`。 

このアルゴリズムは、そのようなマルチセットをすべて正確に列挙し、欠落したり二重にカウントしたりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, m, k = map(int, input().split())

    if k < 2:
        print(0)
        return

    ans = 0

    for x in range(1, m):
        t = 1
        while 2 * t <= n:
            ans += 1
            t += 1

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```処理される最初の条件は、`k < 2`。 すべての有効なマルチセットは、常に 2 つの適切な循環配列を生成し、1 つではないため、答えはすぐにゼロになります。 

外側のループは小さい値を選択します`x`。 2 番目の値は次のようにする必要があるため、`x+1`、 がある`m-1`選択肢。 

内側のループは共通の周波数を選択します`t`。 全長は次のとおりです`2t`、したがって、満足する値のみを許可します`2t <= n`。 

各ペア`(x, t)`ソートされた配列を 1 つだけ定義します。 配列は非減少であるため、あいまいさはありません。```
x x ... x x+1 x+1 ... x+1
```答えはせいぜい約`5000`, ただし、ステートメントと一致させるためにモジュロは引き続き適用されます。

 ## 特殊なケース

 次のことを考慮してください。```
1 5 100
```長さ 1 の巡回配列には次のものが必要です。```
|a1 - a1| = 1
```それは不可能です。 

肯定的なものがないため、アルゴリズムはこれを自然に処理します。`t`満足のいく：```
2t <= 1
```したがってカウントはゼロのままです。 

ここで次のことを考えてみましょう。```
4 3 1
```マルチセット`{1,1,2,2}`有効なサイクルを形成します。```
1 2 1 2
2 1 2 1
```まさに2つあります。 

以来`k = 1`、このマルチセットは対象外です。 アルゴリズムは、次の条件によってすべての構成を即座に拒否します。```python
if k < 2:
    print(0)
```最後に次のことを考慮してください。```
6 4 100
```考えられるペアは次のとおりです。```
(1,1), (1,2), (1,3)
(2,1), (2,2), (2,3)
(3,1), (3,2), (3,3)
```アルゴリズムはこれら 9 つのケースを正確にカウントします。 

例えば：```
(2,3)
```以下に対応します:```
[2,2,2,3,3,3]
```これにより、正確に 2 つの循環良好配列が形成されます。```
2 3 2 3 2 3
3 2 3 2 3 2
```他の順列は条件を満たしません。
