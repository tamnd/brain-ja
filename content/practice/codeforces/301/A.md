 ## 解決策
 ## 問題の理解

 長さ (2・n - 1) の配列が与えられます。 Yaroslav は、正確に _n_ 個の要素を選択し、それぞれに -1 を乗算する操作を何度でも実行できます。 私たちのタスクは、この操作を最適に適用して達成可能な最大合計を決定することです。 入力は、単一の整数 _n_ とそれに続く配列要素で構成されます。 出力は単一の整数、つまり最大合計です。 

_n_ は最大 100 までなので、配列には最大 199 個の要素を含めることができます。 各要素の境界は ±1000 です。 このサイズは、O(n log n) または O(n²) の複雑さのアルゴリズムを許可するのに十分小さいですが、すべての可能な操作をブルートフォースで実行することは不可能です。 199 個の要素があるため、そのうち _n_ 個を選択すると C(199,100) 個の可能性があり、これは天文学的に大きくなります。 

すべての数値が負であるか、負の数値と正の数値が混在している場合、エッジ ケースが発生します。 たとえば、配列が [-1, -2, -3] で n=2 の場合、単純なアプローチでは正の数値のみを反転しようとする可能性がありますが、ここでは合計を最大化するために反転する負の数のサブセットを慎重に選択する必要があります。 同様に、奇数の負の数が存在する場合、演算のパリティが結果に影響します。_n_ 個の要素を繰り返し反転すると、すべての要素を効果的に反転できますが、負の符号が奇数の場合、最小の絶対値によって避けられない損失が決まります。 

## アプローチ

 ブルートフォース手法では、サイズ _n_ のすべてのサブセットを列挙し、それらの符号を反転し、合計が増加しなくなるまですべての一連の操作をチェックします。 これが機能するのは、最終的にはすべての可能な標識構成に到達できるからです。 ただし、要素数が 199 で n=100 の場合、サブセットの数は天文学的な数になるため、このアプローチは実行不可能になります。 

重要な洞察は、_n_ 要素を任意の回数反転することは、偶数回反転した後、符号が元の値に戻ることを除いて、すべての要素を複数回反転できることと同等であるということです。 配列の長さは 2・n - 1 (奇数) なので、フリップでは完全にペアにできない要素が必ず存在します。 これは、可能であればすべての数値を正にすることで最適な合計が得られることを意味しますが、合計の反転数が奇数になった場合、最小絶対値要素は負の符号を保持する必要がある可能性があります。 

したがって、最適なアプローチは、すべての要素の絶対値の合計を計算し、演算パリティによって負の符号が強制的に奇数個ある場合は、避けられない負の部分を考慮して最小の絶対値の 2 倍を減算することです。 最小絶対値を見つけるために並べ替えまたはスキャンすると、複雑さは O(n) または O(n log n) になります。

 ## アルゴリズムのチュートリアル

 1. _n_ と長さ (2・n - 1) の配列を読み取ります。 
2. すべての要素を絶対値に変換します。 これは、要素を反転すると常に正になる可能性があるため、絶対値のみを考慮すると合計が最大化されるためです。 
3. 元の配列内の負の要素の数を数えます。 これは、強制反転の合計数が最終的な配列で奇数の負数をもたらすかどうかを判断するのに役立ちます。 
4. すべての絶対値の合計を計算します。 これにより、すべての数値が正であると仮定して合計が得られます。 
5. 配列内の最小の絶対値を特定します。 負の要素の数が奇数の場合、1 つの要素を事実上負のままにしなければなりません。 この最小絶対値を合計から 2 倍引いて計算します。 
6. 最終的な合計を出力します。

機能する理由: 絶対値を取得することで、任意の要素を反転する機能をシミュレートします。 配列の長さが奇数であるため、_n_ 個の要素を正確に反転する一連の操作では、すべての負の値を完全にペアにすることはできません。 符号反転に関しては、最大 1 つの要素が「ペアになっていない」ままにすることができます。 最小の絶対値は、必要に応じて負の値を持ち、合計の損失を最小限に抑える必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

neg_count = sum(1 for x in a if x < 0)
abs_a = [abs(x) for x in a]
total = sum(abs_a)
min_abs = min(abs_a)

# if number of negative elements is odd, subtract twice the smallest abs value
if neg_count % 2 == 1:
    total -= 2 * min_abs

print(total)
```コードはまず負の数をカウントし、反転後に避けられない負の数のパリティを決定します。 絶対値のリストは、すべての符号が正である場合の潜在的な合計を示します。 奇数の負が残っている場合は、最小の絶対値を使用して合計が調整され、達成可能な最大の合計が保証されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    neg_count = sum(1 for x in a if x < 0)
    abs_a = [abs(x) for x in a]
    total = sum(abs_a)
    min_abs = min(abs_a)
    if neg_count % 2 == 1:
        total -= 2 * min_abs
    return str(total)

# Provided samples
assert run("2\n50 50 50\n") == "150", "sample 1"
assert run("2\n-1 2 3\n") == "4", "sample 2"

# Custom cases
assert run("2\n-1 -2 -3\n") == "4", "all negative"
assert run("3\n1 -1 1 1 1\n") == "5", "single negative"
assert run("2\n-5 5 5\n") == "15", "negative largest element"
assert run("5\n1 1 1 1 1 1 1 1 1\n") == "9", "all equal positives"
