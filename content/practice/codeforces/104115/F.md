 ## 問題の理解

 の列があります$n$1 から 1 までの番号が付けられたチェスト$n$。 ちょうど片方の胸$k$宝物が含まれていますが、他のものはすべて空です。 海賊は宝箱を開け始めますが、宝がどこにあるのかまだ発見していません。 

彼は開始する前に 2 つの固定戦略のいずれかを実行します。1 から始めて上に向かって左から右に宝箱を開けるか、1 から始めて右から左に開けます。$n$そして下に向かって移動します。 宝物の入った箱を開けるとすぐに立ち止まります。 

宝物が実際にその位置にあると仮定して、最悪の場合に彼が開ける宝箱の数を計算するように求められます。$k$ただし、海賊は必要な開口部の最大数を最小限に抑えるために、2 つの方向のうち良い方を事前に選択します。 

制約$n \le 10^9$アレイ全体のシミュレーションや反復スキャンは除外されます。 線形スキャンであっても、すべての解は定時間である必要があります。$n$不可能です。 

宝物が一方の端に近づくと、微妙なエッジの状況が発生します。 たとえば、次の場合$n = 5, k = 4$、左からのスキャンには 4 つの開口部が必要ですが、右からのスキャンには 2 つの開口部がかかります (5 → 4)。 常に左から右を想定する単純なアプローチでは、両方向を比較せずに誤って 4 を返します。 正しい答えは、最も近いエンドポイントへの近さによって異なります。 

もう 1 つのエッジケースは次のような場合です$k = 1$または$k = n$。 どちらの場合も、一方の方向では 1 ステップで宝物がすぐに見つかりますが、もう一方の方向では時間がかかります。$n$ステップ。 最小値を取得する代わりに距離を平均したり組み合わせたりするソリューションは、ここでは失敗します。 

## アプローチ

 直接シミュレーションでは、海賊のプロセスを文字通り追跡しようとします。 方向を決めたら、到達するまでに何個の宝箱が開けられるかを数えます。$k$。 左から、まさにこれです$k$。 右から、これです$n - k + 1$。 このアプローチはプロセス定義を正確に反映するため正しいですが、入力サイズは巨大ですがテストごとの計算は些細なものであるため、大きな制約の下では意味がありません。 

重要な観察は、可能な単調走査は 2 つだけであり、それぞれが純粋に位置に基づいて決定論的なコストを生成するということです。$k$。 問題は、2 つの直線距離、つまり左側の境界からの距離と右側の境界からの距離のうち、小さい方を選択することになります。 検索プロセスには分岐やランダム性がないため、中間構造は重要ではありません。 

したがって、最適な解決策は、単純に両方のコストを計算し、最小値を取ることです。

 ## アルゴリズムのチュートリアル

 1. 海賊が左から始めた場合に開けられる宝箱の数を計算します。 これはまさに$k$、彼は 1、2、... を開くので、$k$。 
2. 海賊が右から始めた場合に開けられる宝箱の数を計算します。 これは$n - k + 1$、彼が開いて以来$n, n-1, ..., k$。 
3. これら 2 つの値を比較し、小さい方を選択します。海賊は、$k$。 

### なぜ効果があるのか

 各戦略は、スキップのない決定的な単調な走査です。 コストはインデックスに到達するまでに必要なステップ数にのみ依存します。$k$固定エンドポイントから。 どちらの走査も線形で独立しているため、最適な選択は常にそれぞれの距離の最小値になります。 ステップ間には相互作用がないため、これら 2 つの固定オプションを改善する適応戦略はありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    left = k
    right = n - k + 1
    print(min(left, right))

if __name__ == "__main__":
    solve()
```コードは 2 つの整数を読み取り、考えられる 2 つの検索コストを直接計算します。 左側のコストは、位置を 1 から 1 まで数えることに対応します。$k$、一方、適切なコストは、から逆算したものに対応します。$n$。 最終的な答えは、2 つのうちの最小値です。 

唯一の微妙な点は、右側の距離には位置自体が含まれることを覚えておくことです。$+1$。 これがないと、カウントは常に 1 ずつずれてしまいます。$k$まさに終点にいます。

 ## 特殊なケース

 いつ$k = 1$、左の戦略では 1 ステップで宝物がすぐに見つかりますが、右の戦略では時間がかかります。$n$ステップ。 アルゴリズムは計算します$left = 1$、$right = n$、正しく 1 を返します。
