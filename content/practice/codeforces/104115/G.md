 ## 解決策
 ## 問題の理解

 整数係数を持つ二次方程式が与えられます。$a, b, c$、それらはすべてゼロではありません。 これら 3 つの係数のサブセットを新しい非ゼロ整数に置き換えることができます。 修正後、方程式は実根が繰り返される 2 次式になる必要があります。これは、その判別式が正確に 0 でなければならないことを意味します。 

反復実根の判別条件は次のとおりです。$b^2 - 4ac = 0$、これは以下と同等です$b^2 = 4ac$。 タスクは、元のトリプルから変更する係数の数を最小限に抑えることです。 

出力は有効なトリプルです$(a', b', c')$変更の数を最小限に抑えながら、すべてがゼロ以外の整数であり、二次方程式が二重根を持つように、指定された範囲内で調整します。 

制約の大きさは小さく、各係数は以下によって制限されます。$10^4$、ただし出力は最大まで上昇する可能性があります$10^9$。 これは、広い範囲を検索するのではなく、新しい係数を自由に構築できることを強く示唆しています。 条件の構造$b^2 = 4ac$は代数的で離散的であるため、解決策は大規模な領域にわたる最適化ではなくケース分析に依存します。 

微妙な問題は、最小の答えが複数存在する可能性があることです。 この問題に必要なのは一意性ではなく、正確さと最小限の変更だけです。 

エッジケースは、一部の係数がすでに判別条件を満たしている場合に発生します。 たとえば、次の場合$a, b, c$すでに満足しています$b^2 = 4ac$、同じトリプルを出力し、何も変更しない必要があります。 もう 1 つのエッジ ケースは、係数変更が 1 つだけで十分であるにもかかわらず、不用意に構築すると係数がゼロになったり、整数制約に違反したりする可能性がある場合です。 

## アプローチ

 ブルートフォース解釈では、係数のサブセットを変更するあらゆる方法が試行されます。 各サブセットについて、範囲内で可能なすべての整数置換を試し、次のことを確認します。$b^2 = 4ac$。 たとえ置換を合理的な範囲に制限したとしても、検索空間には原則として制限がなく、さらには$[-10^9, 10^9]$これは不可能になります。 2 つの係数のすべての置換を試行すると、大きな領域にわたって 2 次またはさらに悪い検索が行われることになります。 

重要な観察は、固定されている係数と置換されている係数の数のみを考慮しているということです。 係数が 3 つしかないため、答えは 0、1、2、または 3 回の変更のみになります。 各シナリオで判別条件を達成できるかどうかを明示的に確認できます。 

変更がゼロの場合はすでに満たされています$b^2 = 4ac$、終わりました。 

1 つの変更で十分な場合は、他の 2 つの係数を固定したまま、1 つの係数だけを調整しようとします。 それぞれのケースは単純なディオファントス方程式を解くことに帰着します。 

- 修正$a, c$、 調整する$b$:$b' = \pm 2\sqrt{ac}$- 修理$a, b$、 調整する$c$:$c' = b^2 / (4a)$割り切れてゼロでない場合
 - 修正$b, c$、 調整する$a$:$a' = b^2 / (4c)$割り切れてゼロでない場合

 これらのどれも機能しない場合は、2 つの変更に進みます。 2 つの係数を置き換えると、次を満たす整数が存在することを確認するだけで済みます。$b'^2 = 4a'c'$。 このようなトリプルは、次のように自由に構築できます。$a' = 1$、$c' = 1$、$b' = \pm 2$。 これは常に条件を満たし、ゼロ以外の制約を尊重します。 

この構造により、問題は少数の一定数の代数チェックに分解されます。

 ## アルゴリズムのチュートリアル

 1. 元の係数がすでに満たされているかどうかを確認します$b^2 = 4ac$。 「はい」の場合は、変更せずに出力します。 これは変更がゼロに相当し、最適です。 
2. 変更だけを試してみる$a$保ちながら$b$そして$c$修理済み。 コンピューティング$a' = b^2 / (4c)$。 これは次の場合にのみ機能します$b^2$で割り切れます$4c$の場合、結果はゼロ以外になり、すべての制約が尊重されます。 有効な場合、このトリプルを出力します。 
3. 変更だけを試してみる$c$保ちながら$a$そして$b$修理済み。 コンピューティング$c' = b^2 / (4a)$同じ割り算と非ゼロチェックの下で。 
4. 変更だけを試してみる$b$保ちながら$a$そして$c$修理済み。 必要です$b'^2 = 4ac$、 それで$4ac$完全な正方形でなければなりません。 その場合は設定してください$b' = \pm \sqrt{4ac}$。 いずれかの符号 (通常は正) を選択します。 
5. 単一変更オプションがどれも機能しない場合は、2 つの変更を含む有効な二次方程式を作成します。 正規構造とは、$a' = 1$、$b' = 2$、$c' = 1$、を満たす$b'^2 = 4a'c'$その通り。 

これが機能する理由は、すべての有効な答えが判別条件を満たさなければならず、固定係数の数が方程式の形式を厳密に制限するという事実から来ています。 最大 1 つの係数が解放されている場合、方程式は線形の割り算制約または二乗条件になります。 それさえも失敗した場合は、2 つの係数を解放することで方程式の完全な制御が保証され、固定の正規解が常に存在します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

a, b, c = map(int, input().split())

def ok(a, b, c):
    return b * b == 4 * a * c

if ok(a, b, c):
    print(a, b, c)
    sys.exit()

# try change a
if (b * b) % (4 * c) == 0:
    a2 = (b * b) // (4 * c)
    if a2 != 0:
        print(a2, b, c)
        sys.exit()

# try change c
if (b * b) % (4 * a) == 0:
    c2 = (b * b) // (4 * a)
    if c2 != 0:
        print(a, b, c2)
        sys.exit()

# try change b
val = 4 * a * c
if val > 0:
    import math
    r = int(math.isqrt(val))
    if r * r == val:
        print(a, r, c)
        sys.exit()

# fallback: change two coefficients
print(1, 2, 1)
```コードはまず、変化がゼロであることに対応して、判別条件がすでに成立しているかどうかを直接チェックします。 後続の各ブロックは、欠落している変数を代数的に解くことによって、正確に 1 つの変更を試行します。 小数値は無効であるため、割り算チェックにより整数係数のみが生成されることが保証されます。 

の平方根ステップ$b$は唯一の自明ではない計算であり、$4ac$代入前の完全平方です$b$。 フォールバックは、二重根を持つ保証された有効な二次方程式です。 

微妙な点は、係数がゼロにならないようにすることです。 これは、入力がゼロ以外の場合でも理論的には除算でゼロが生成される可能性があるため、新しい値を計算するときに明示的にチェックされます。

## テストケース```python
import sys, io
import math

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    a, b, c = map(int, input().split())

    def ok(a, b, c):
        return b * b == 4 * a * c

    if ok(a, b, c):
        return f"{a} {b} {c}"

    if (b * b) % (4 * c) == 0:
        a2 = (b * b) // (4 * c)
        if a2 != 0:
            return f"{a2} {b} {c}"

    if (b * b) % (4 * a) == 0:
        c2 = (b * b) // (4 * a)
        if c2 != 0:
            return f"{a} {b} {c2}"

    val = 4 * a * c
    if val > 0:
        r = int(math.isqrt(val))
        if r * r == val:
            return f"{a} {r} {c}"

    return "1 2 1"

def run(inp: str) -> str:
    return solve(inp)

# provided samples
assert run("1 2 3") == "1 2 1"
assert run("1197 -144 3325") == "1197 3990 3325"
assert run("-3 6 -3") == "-3 6 -3"
assert run("-2 5 3") in ["-2 -20 -50", "-2 5 3"]

# custom cases
assert run("1 1 1") == "1 2 1"
assert run("2 4 2") == "2 4 2"
assert run("3 6 3") == "3 6 3"
assert run("5 10 20") in ["5 10 5", "5 10 20"]

 ## 特殊なケース

 1 つのエッジ ケースは、入力など、判別式がすでに 0 である場合に発生します。$(-3, 6, -3)$。 アルゴリズムは即座に検出します$b^2 = 4ac$同じトリプルを返し、不必要な変更を避けます。 

もう 1 つのエッジ ケースは、係数変更が 1 つだけ可能であるが、整数の慎重な処理が必要な場合です。 たとえば、固定するとき、$a$そして$b$、コンピューティング$c' = b^2 / (4a)$整数以外の結果が生成される場合があります。 割り算チェックは無効な割り当てを防止し、アルゴリズムに他のケースを強制的に試行させます。 

さらに特殊なケースは次のような場合です。$4ac$は正ですが完全な正方形ではありません。 この状況では調整のみ$b$整数の平方根が存在しないため、これは不可能です。 アルゴリズムはこの分岐を正しくスキップし、2 つの変更によるフォールバックに依存します。 

最後にフォールバック構築$a' = 1, b' = 2, c' = 1$係数ゼロを常に回避し、判別条件を常に満たすため、すべての単一変更の試行が失敗した場合でも完全性が保証されます。
