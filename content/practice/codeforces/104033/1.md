 ## 問題の理解

 ## アルゴリズムのチュートリアル

 到達可能性の条件をエンドポイントからの距離の観点から書き換えます。 

1. 後のカエルの距離を表す$t$秒を任意の整数で表す$[2t, 3t]$。 これは、すべての手が 2 または 3 を追加するという事実から来ており、最小値はすべて 2 で、最大値はすべて 3 です。 
2. 後のバッタ距離を表現します$t$秒を任意の整数で表す$[t, 2t]$、各移動は右側から 1 または 2 を減算するため、左方向への合計移動はその範囲内にあることを意味します。 
3. 会議を開催するには、分割ポイントを選択します$a$カエルが届くように$a$そしてバッタが届く$N-1-a$。 これにより、問題が発見に変わります$a$両方の制約が同時に成立するようにします。 
4. 不等式に変換します。$a \in [2t, 3t]$そして$N-1-a \in [t, 2t]$。 この 2 番目の不等式は次のようになります。$a \in [N-1-2t, N-1-t]$。 
5. 存在条件は区間の交点$[2t, 3t]$そして$[N-1-2t, N-1-t]$。 重なっていれば集合時間は可能です$t$。 
6. 最小のものを見つける$t$交差点が空ではない場合。 不等式を解く：$2t \le N-1-t$そして$N-1-2t \le 3t$、限界まで減少します$t$。 

結果として得られる最小値$t$はこれらの不等式から直接得られます。 

### なぜ効果があるのか

 決まった時間にいつでも$t$、オプション間でステップ サイズがちょうど 1 異なるため、両方の歩行者の到達可能な位置は連続した間隔を形成します。 これにより、組み合わせ分岐が削除され、到達可能性が数直線上の凸集合に変わります。 会合は、線形変換の下で 2 つの凸領域が交差することに相当します。$a + b = N-1$。 どちらのセットもインターバルが残っているため、$t$、実行可能性のチェックにより、間隔の重複が軽減され、個々のパスを検査する必要がなく正確さが維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N = int(input())
    target = N - 1

    lo, hi = 0, 10**18

    def ok(t):
        frog_L, frog_R = 2 * t, 3 * t
        grass_L, grass_R = t, 2 * t

        # need exists a such that:
        # a in frog interval AND target - a in grass interval
        L = max(frog_L, target - grass_R)
        R = min(frog_R, target - grass_L)
        return L <= R

    ans = -1
    l, r = 0, N

    while l <= r:
        mid = (l + r) // 2
        if ok(mid):
            ans = mid
            r = mid - 1
        else:
            l = mid + 1

    print(ans)

if __name__ == "__main__":
    solve()
