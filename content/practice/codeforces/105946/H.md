 ## 解決策
 ## 問題の理解

 次のような接続された単純な無向グラフが与えられます。$n$地区と$m$既存の道路。 第 1 地区はすべての市民にとっての出発点です。 各地区$u$もっている$c_u$すべての労働者は第 1 地区から職場まで移動します。$u$そして最短経路に沿って 1 に戻ります。 

グラフは重み付けされていないため、移動距離はエッジ内の通常の最短経路長になります。 1 日あたりの交通量の合計は、すべての地区の合計に、その地区の従業員数に 1 からその地区までの距離の 2 倍を乗じたものに比例します。 したがって、関心のある量は最短距離のベクトルによって完全に決定されます。$d(1,u)$。 

これまで接続されていなかった地区の任意のペアの間にエッジを追加することができます。 目標は、できるだけ多くの新しいエッジを追加し、これらすべての追加の後、地区 1 からのすべての最短距離が変更されないことを保証することです。これにより、総トラフィックも変更されません。 

制約スケール$n, m \le 2 \cdot 10^5$仮想エッジを挿入するたびに最短パスを再計算するアプローチは直ちに除外されます。 追加を明示的にシミュレートしたり、BFS を繰り返し実行したりするソリューションは、遅すぎます。 したがって、問題は、どのエッジを追加しても「安全」であるかの構造的特徴付けを求めることです。 

BFS ツリー内で遠く離れたノードを自由に接続できると仮定すると、微妙な失敗例が発生します。 たとえば、1 に非常に近いノードを遠くのノードに接続すると、以前は長いパスを介してのみ到達していたグラフの部分までの距離が意図せず短くなってしまう可能性があります。 追加された 1 つのエッジでも改善が複数のレイヤーに伝播する可能性があるため、エンドポイントのみをチェックするだけでは不十分です。 

## アプローチ

 重要な観察は、目的がノード 1 からの最短距離のみに依存するということです。エッジを追加しても、エッジが減少した場合にのみ答えに影響を与えることができます。$d(1,u)$少なくとも 1 つのノードに対して$u$。 そこで私たちが実際に尋ねているのは、ソースからの最短パス距離を減らすことなく追加できるエッジはどれかということです。 

強引な解釈は簡単です。 あらゆる可能性のある欠けているエッジに対して$(u,v)$を追加し、ノード 1 から BFS を再計算して、距離が減少するかどうかを確認することを想像します。 これには費用がかかります$O(n)$BFSごとに、$O(n^2)$候補エッジ、これにつながる$O(n^3)$最悪の場合の動作は限界をはるかに超えています。 

重要な構造的洞察は、元のグラフのノード 1 から BFS 階層化を確認することです。 させて$dist[u] = d(1,u)$。 1 からの最短パスは非減少レイヤーを通過する必要があり、エッジごとに最大 1 ずつ増加します。 

新しいエッジを追加すると$(u,v)$、1 からあるノードまで新しく作成された短いパスは、2 つの既知のレイヤー間のショートカットとしてそのエッジを通過する必要があります。 距離を短縮するには、新しいエッジが元の最短ルートよりも厳密に短いルートをノードまで作成する必要があります。 これは、新しいエッジが 2 つのノードを接続し、その相互作用により、以前はより多くの手順が必要だったレイヤー間のショートカットが作成される場合にのみ発生します。 

安全な特性評価は単純な構造に崩れることがわかります。同じ BFS 距離にあるノードは 1 からの最短パスに関して対称的に動作し、同じ距離レイヤーのノード間にエッジを追加しても、異なるレイヤーのノードへの短いルートは作成されません。 クロスレイヤー接続は、何らかのパスのレベルを「スキップ」する方法を即座に作成し、グラフのより深い部分の距離を短縮する可能性があります。 

これにより、最短距離を変更せずに自由に追加できる唯一のエッジは、各 BFS レベル内のエッジであるという事実が生じます。 距離パーティションを修正すると、安全な接続の観点から各レベルが独立したセットになるため、各レベルをクリークに完成させることができます。 

したがって、答えは次のとおりです。各距離レイヤー内の欠落しているエッジをすべて数えます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^3)$|$O(n)$| 遅すぎる |
 | BFS 階層化 + 層内エッジのカウント |$O(n + m)$|$O(n + m)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. ノード 1 から BFS を実行して計算します$dist[u]$すべてのノードに対して。 これにより、トラフィックを定義する正確な最短パス構造が捕捉されます。 
2. 距離値に基づいてノードをグループ化します。 各グループは BFS レイヤーに対応し、同じグループ内のすべてのノードは現在、合計トラフィック表現に独立して寄与しています。 
3. 各レイヤーのサイズを計算します。$k$。 レイヤー内では、ノード 1 からの距離に影響を与えることなく、任意のノードのペアを接続できる可能性があります。 
4. 各層について、その層のノード間にすでに存在するエッジの数を数えます。 これらのエッジを再度追加することはできません。 
5. レイヤー内の追加の安全なエッジの数は、完全なグラフ内の欠落しているエッジの数です。$k$ノード、つまり$k(k-1)/2$既存の層内エッジを差し引いたもの。 
6. この値をすべてのレイヤーで合計して、最終的な答えを取得します。 

### なぜ効果があるのか

 ノード 1 からの距離によって、すべての最短パスが BFS 順序を尊重する厳格な階層化が定義されます。 異なるレイヤーを接続する新しいエッジは、ダウンストリームの最短パスの計算において中間レイヤーをバイパスできる代替ルートを導入します。 これでは距離を縮めることしかできません。 

単一レイヤー内に完全に留まるエッジは、最短パス距離を短縮できません。そのようなエッジを使用するルートは依然としてノード 1 に対して同じ距離レベル内に留まり、したがって、より深いレイヤーのノードへの厳密に短いパスを作成できないためです。 これにより、各レイヤーが独立した「安全な領域」になり、欠落したエッジを自由に追加できるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

n, m = map(int, input().split())
c = list(map(int, input().split()))

g = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append(v)
    g[v].append(u)

dist = [-1] * n
dist[0] = 0
q = deque([0])

while q:
    u = q.popleft()
    for v in g[u]:
        if dist[v] == -1:
            dist[v] = dist[u] + 1
            q.append(v)

level_size = {}
for i in range(n):
    level_size[dist[i]] = level_size.get(dist[i], 0) + 1

# count existing edges inside each level
existing = {}
for u in range(n):
    for v in g[u]:
        if dist[u] == dist[v]:
            if u < v:
                existing[dist[u]] = existing.get(dist[u], 0) + 1

ans = 0
for d, sz in level_size.items():
    total = sz * (sz - 1) // 2
    used = existing.get(d, 0)
    ans += total - used

print(ans)
```BFS はノード 1 からの正確な距離パーティションを計算します。これは、追加されたエッジがトラフィックに影響を与えるかどうかに関して重要な唯一の構造です。 辞書`level_size`各距離レイヤーに存在するノードの数を保存します。`existing`二重にカウントされないように、各レイヤー内にすでに存在するエッジの数をカウントします。 

最終的な合計では、各レイヤーが完全なグラフに変換され、そのレイヤーにすでに存在するエッジが差し引かれます。これは、安全に追加できる追加エッジの数に直接対応します。 

## 実用的な例

 ノード 1 の BFS がノードを距離レイヤーに割り当てるサンプル グラフ構造を考えてみましょう。 次のようなレイヤーを取得するとします。 

レイヤ 0: {1}

 レイヤ 1: {2、3、4}

 レイヤ 2: {5}

 レイヤー全体のエッジ分布を追跡します。 

| ステップ | アクション | レイヤーサイズ | 層内エッジ | 貢献 |
 | --- | --- | --- | --- | --- |
 | 1 | ノード 1 からの BFS | {0:1、1:3、2:1} | グラフから計算 | 初期化 |
 | 2 | レイヤー0 | 1 | 0 | 0 |
 | 3 | レイヤ 1 | 3 | カウントされる既存のエッジ |$3\cdot2/2 - E_1$|
 | 4 | レイヤー2 | 1 | 0 | 0 |

 これは、複数のノードを持つレイヤーのみが寄与し、欠落している内部エッジのみがカウントされることを示しています。 

ここで、小さな構築例を考えてみましょう。 

入力グラフ:

 1 は 2 と 3 に接続され、2 は 4 に接続されます。 

BFS レイヤー:

 レイヤ 0: {1}

 レイヤ 1: {2, 3}

 レイヤ 2: {4}

 | ステップ | アクション | レイヤーサイズ | 結果 |
 | --- | --- | --- | --- |
 | BFS | 距離を計算する | {0:1,1:2,2:1} | 固定パーティション |
 | レイヤー 1 エッジ | 2 と 3 の間には何も存在しません | 追加可能 = 1 | |
 | 最終回 | 合計 | 1 | 1 つの安全なエッジ |

 これは、アルゴリズムがより深い接続パターンではなく、層構造のみに依存していることを示しています。

import sys, io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    from collections import deque

    n, m = map(int, sys.stdin.readline().split())
    c = list(map(int, sys.stdin.readline().split()))

    g = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    dist = [-1] * n
    dist[0] = 0
    q = deque([0])
    while q:
        u = q.popleft()
        for v in g[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)

    level_size = {}
    for i in range(n):
        level_size[dist[i]] = level_size.get(dist[i], 0) + 1

    existing = {}
    for u in range(n):
        for v in g[u]:
            if dist[u] == dist[v] and u < v:

    ans = 0
    for d, sz in level_size.items():
        ans += sz * (sz - 1) // 2 - existing.get(d, 0)

    return str(ans)

 ## 特殊なケース

 重要なエッジ ケースは、すべてのノードがルートの後の単一の BFS レイヤーにある場合です。 この状況では、すべてのノードの距離は 1 であるため、すべての新しいエッジは等しい距離のノード間に存在します。 このアルゴリズムは、グラフ全体で欠落しているエッジをすべて正確にカウントします。つまり、すでに最小距離である 1 を超えてノードへのより短い代替パスが出現できないため、距離を変更せずにすべてのペアを接続できます。 

もう 1 つの重要な状況は、根が 1 のツリーのような形をしたグラフです。すべてのノードは、層内ペアのない個別の層または厳密に構造化された層に存在します。 このアルゴリズムはゼロを生成します。これは、ツリーに追加されたエッジが必ずルートからの距離を減らすショートカットを作成するという事実と一致します。 

最後に、複数のノードがレイヤーを共有しているが、ダウンストリーム接続が異なるグラフを考えてみましょう。 内部構造が異なっていても、アルゴリズムはレイヤー全体を均一に扱います。 これは、潜在的なショートカットにはレイヤーを横断する必要があるため、安全です。これは距離分割によってすでに除外されています。
