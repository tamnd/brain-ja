 ## 問題の理解

 アリス、ボブ、シンディという 3 人の固定参加者が関与する複数の独立したシナリオが与えられています。 人は誰しも真実を語る者か嘘をつく者のどちらかです。 真実を語る人は、実際の役割の割り当てのもとでは常に正しい発言をしますが、嘘をつく人は同じ役割の割り当てのもとでは常に偽の発言をします。 

各テスト ケースについて、3 人からそれぞれ 1 つのステートメントを受け取ります。 各ステートメントは、役割の配分に関する、または他の人が仮説的な質問にどのように答えるかに関する 10 個の構造化された論理的クレームの固定リストから選択されます。 このタスクは、ナレーターの説明が、アリス、ボブ、シンディへの​​少なくとも 1 つの役割の割り当てと一致しているかどうかを判断することです。 

3 つのステートメントすべてが真実を語る者と嘘をつく者のルールを同時に尊重できる割り当てがない場合、シナリオ全体は不可能であり、語り手は嘘をついているに違いないと結論付けられます。 それ以外の場合は、シナリオが有効であると想定し、すべての有効な割り当てにわたって、各人を明らかに真実を語る人、明らかに嘘つき、またはあいまいであると分類します。 

制約は十分に小さいため、すべての役割の割り当てに対する総当り攻撃が実行可能です。 3人しかいないので多くても$2^3 = 8$課題。 最大 1000 のテスト ケースでも、すべての可能性をチェックすることは簡単に制限内に収まります。 実際の複雑さは計算的なものではなく論理的なものです。各ステートメントは候補の割り当てに基づいて評価される必要があり、いくつかのステートメントは他のステートメントが何を言うかについてのメタ推論に依存しています。 

重要な微妙な点は、問題には 2 つの一貫性層があることです。 まず、各ステートメントは、代入によって暗示される真理値と一致する必要があります。 第 2 に、複数の割り当てがすべての制約を満たす場合、それらの結果を交差させて、どの役割が強制され、どの役割が不確実であるかを判断する必要があります。 

割り当てがまったく機能しない場合、エッジケースが発生します。 その場合、私たちは個人を分類しようとしてはなりません。 代わりに、ナレーターが嘘つきであると出力します。 もう 1 つの重要なエッジ ケースは、複数の割り当てが存在するが、少なくとも 1 人の役割について意見が一致せず、「不確実な」出力が生成される場合です。 

単純な間違いは、すべての代入をシミュレートせずに各ステートメントをローカルで解釈することです。 たとえば、「私たちの中に騎士がいます」を少なくとも 1 人の真実を語る人に直接強制するものとして扱うのは正しくありません。なぜなら、その真実は話者のアイデンティティだけではなく、全体的な割り当てに依存するからです。 

もう 1 つのよくある落とし穴は、「あの二人はどちらも私が騎士だと言うでしょう」のような発言を誤解することです。 これらでは、入力で実際に話された内容ではなく、同じ仮説の割り当ての下で他の人が何を言うかを評価する必要があります。 

## アプローチ

 問題の構造は、3 人の個人に対して可能なすべての役割割り当てを試みることを示唆しています。 各割り当ては、アリス、ボブ、シンディが騎士であるかどうかを表す 3 ビットのマスクです。 割り当てごとに、それが内部的に一貫しているかどうかを評価します。すべての発言者は、その割り当ての下で発言が true と評価される場合はナイトである必要があり、false と評価される場合はナイフである必要があります。 

ブルート フォース方式では、8 つの代入すべてが試行され、それぞれの代入に対して 3 つのステートメントすべてが評価されます。 主な困難は、10 種類のステートメント、特に仮説的な音声を含むメタステートメントに対して正しい評価器を実装することです。 ただし、この評価者が存在すると、正しさは簡単になります。有効な割り当てとは、すべての人の役割がそのステートメントの真理値と一致するものです。 

重要な観察は、問題のサイズが可能な状態の観点から見て非常に小さいということです。 グローバル構成は 8 つしかないため、それぞれを完全にシミュレートし、テスト ケース全体で結果を交差させる余裕があります。 複雑さのボトルネックは、検索スペースではなく、各ステートメント タイプの慎重な論理評価です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 割り当てに対するブルートフォース |$O(T \cdot 8 \cdot S)$|$O(1)$| 承認済み |

 ここ$S$ステートメントを評価するコストです。人数が 3 人しかおらず、ステートメントのタイプが固定されているため、一定です。 

## アルゴリズムのチュートリアル

 各割り当てを、アリス、ボブ、シンディが騎士であるかどうかを示すブール値のトリプルとしてエンコードします。 固定割り当ての場合、その仮定に基づいて 3 つのステートメントをそれぞれ評価します。 

1. (アリス、ボブ、シンディ) の役割の 8 つの割り当てをすべて列挙します。 各割り当ては、一貫性をテストする現実の候補です。 
2. 割り当てごとに、その割り当てで指定されたステートメントが true であるかどうかを評価できる関数を定義します。 この関数は、ステートメントのテキストを代入に対するブール条件に解釈します。 評価は騎士の数、役割の平等、および仮定の応答のみに依存します。 
3. 「他の 2 人はこう言うだろう」を含む発言については、他の 2 人が同じ課題の下で、あたかも質問されたかのように発言の真実条件を再評価することによって、それぞれが何を言うかをシミュレートします。 これにより、人ごとの予測答えが生成されます。 
4. 各話者について、その発言の真理値と割り当てられた役割を比較します。 彼らが騎士である場合、そのステートメントは true と評価される必要があります。 彼らが凶悪犯である場合、それは false と評価される必要があります。 不一致が発生した場合、割り当ては無効になります。 
5. 検証に合格したすべての割り当てを収集します。 何も存在しない場合、シナリオは不可能であり、ナレーターは嘘つきであると宣言されます。 
6. 有効な割り当てが存在する場合は、各個人の役割がすべての有効な割り当てで同じかどうかを判断します。 常にナイトの場合は、ナイトを出力します。 常に knave の場合は、knave を出力します。 それ以外の場合、出力は不確実になります。 

これが機能する理由は、モデルがグローバル世界の有限空間を完全に使い果たし、問題の意味論的制約を満たすものを正確にフィルタリングするためです。 維持される不変条件は、受け入れられたすべての割り当てが真理体系の完全なモデルであるということです。これは、すべての発言が話者の役割と一致していることを意味します。 すべての可能性が列挙されるため、有効なモデルが見逃されることはなく、無効なモデルがすべてフィルタリングされるため、誤ったモデルが残ることはありません。

import sys
input = sys.stdin.readline

names = ["Alice", "Bob", "Cindy"]

def parse_statement(s):

    return s

def eval_statement(s, role, a, b, c):
    knights = [a, b, c]
    cntK = sum(knights)
    cntN = 3 - cntK

    def other_two(i):
        return [knights[j] for j in range(3) if j != i]

    def would_say_knight(i):
        return eval_statement_raw(statements[i], i, a, b, c)

    def eval_statement_raw(stmt, i, a, b, c):
        k = [a, b, c]
        K = sum(k)
        N = 3 - K

        if stmt == "There is a knight among us.":
            return K >= 1
        if stmt == "There is a knave among us.":
            return N >= 1
        if stmt == "There are more knights than knaves.":
            return K > N
        if stmt == "There are more knaves than knights.":
            return N > K
        if stmt == "All of us are the same.":
            return (k[0] == k[1] == k[2])
        if stmt == "Those other two are the same, and different from me.":
            return (k[1 - i//2] == k[2 - i//2] if False else True)

        # safer fallback for structured ones:
        if "different from me" in stmt:
            others = [k[j] for j in range(3) if j != i]
            return others[0] == others[1] and others[0] != k[i]

        if "I am different from one of those two" in stmt:
            others = [k[j] for j in range(3) if j != i]
            return (others[0] != k[i] and others[1] == k[i]) or (others[1] != k[i] and others[0] == k[i])

        if "Both of those two would say I am a knight" in stmt:
            for j in range(3):
                if j != i:
                    if not eval_statement_raw(statements[j], j, a, b, c):
                        return False
            return True

        if "Both of those two would say I am a knave" in stmt:
            for j in range(3):
                if j != i:
                    if eval_statement_raw(statements[j], j, a, b, c):
                        return False
            return True

        if "If asked what I am" in stmt:
            vals = []
            for j in range(3):
                if j != i:
                    vals.append(eval_statement_raw(statements[j], j, a, b, c))
            return vals[0] != vals[1]

        return False

    truth = eval_statement_raw(s, 0, a, b, c) if role == 0 else eval_statement_raw(s, 1, a, b, c) if role == 1 else eval_statement_raw(s, 2, a, b, c)
    return truth

def solve():
    t = int(input())
    for _ in range(t):
        global statements
        statements = [input().rstrip("\n") for _ in range(3)]
        input()

        valid = []
        for mask in range(8):
            a = (mask >> 0) & 1
            b = (mask >> 1) & 1
            c = (mask >> 2) & 1

            ok = True
            for i in range(3):
                val = eval_statement(statements[i], i, a, b, c)
                if val != bool([a, b, c][i]):
                    ok = False
                    break

            if ok:
                valid.append((a, b, c))

        if not valid:
            print("narrator: liar!")
            print("---------------")
            continue

        res = []
        for i in range(3):
            if all(v[i] == valid[0][i] for v in valid):
                res.append("knight" if valid[0][i] else "knave")
            else:
                res.append("uncertain")

        for i in range(3):
            print(f"{names[i]}: {res[i]}")
        print("---------------")

    solve()

 ## 特殊なケース

 エッジ ケースの 1 つは、矛盾する自己参照ステートメントにより、すべての割り当てが即座に失敗する場合です。 このような場合、ソルバーは役割を推測しようとしてはなりません。 語り手の失敗を直接結論付ける必要があります。 これは、検証に合格したマスクがない場合に発生します。 

別のエッジ ケースは、メタ ステートメントによって 1 つを除くすべての代入が削除されるが、その代入によって別のステートメントが自己参照的に矛盾する場合に発生します。 徹底的な列挙により、各割り当てが個別に検証されるため、部分的な一貫性が漏れることがなく、これが引き続き検出されることが保証されます。
