 ## 問題の理解

 私たちに最初に与えられたのは、$N = 2 \cdot 10^5$ほとんどの場合、順序の固定線形反復によって生成されるシーケンスの項$k \le 69$、ただし時折破損が発生します。 

まず最初に$k$位置、値は任意です。 位置から$k+1$それ以降、各項は通常、前の項の線形結合として計算されます。$k$未知の係数を使用する項$c_1, c_2, \dots, c_k$モジュロ$p = 998244353$。 ただし、小さな固定確率では、ジェネレーターはある位置で「中断」し、代わりに完全に均一なランダム値を書き込みます。$[1, p)$再発とは関係ありません。 

タスクは係数ベクトルを再構築することです$c$騒がしいシーケンスから。 

最も難しい点は、すべての位置が再発に従うと仮定することができず、どの位置が破損しているかがわからないことです。 あらゆる場所で再発を強制する単純な試みは、これらのランダムなスパイクによって汚染され、クリーンなセグメントを推測しようとする単純な試みは、どこでも破損が発生する可能性があるため失敗します。 

この制約は、非常に厳しい計算予算を意味します。 と$N = 2 \cdot 10^5$そして$k \le 69$、多数の候補ウィンドウに対して個別にシステムを解決しようとしたり、ガウス消去法を繰り返し再計算したりするソリューション$O(N)$セグメントが遅すぎる可能性があります。 正しい解決策は、問題を少数の候補チェックまたは単一の決定論的再構成ステップに削減する必要があります。 

微妙なエッジケースは、アーリーポジションが完全に制約されていないことです。 最初の仮定を誤ると、$k$値が繰り返しを直接定義するため、後の一貫したセグメントが一致しない場合でも、間違った係数ベクトルを結論付ける可能性があります。 もう 1 つの失敗モードは、単一のローカル ウィンドウを使用する場合です。そのウィンドウに破損した値が 1 つでも含まれている場合、再構築された係数は無意味になり、アルゴリズムは依然として係数が正しいかのように出力する可能性があります。 

重要な課題は、破損した位置を明示的に特定することなく、真の反復一貫性のある遷移をランダム ノイズから区別することです。 

## アプローチ

 ブルートフォースの観点は定義から始まります。「何らかの方法で知っていれば」$k$連続したクリーンな遷移により、線形システムをセットアップできます。 各ポジション$i > k$方程式を与える$$a_i = \sum_{t=1}^{k} c_t a_{i-t} \pmod p.$$すべての方程式が信頼できる場合は、どれでも選択できます。$k$このような方程式を解いて、$k \times k$ガウス消去法による線形システム$O(k^3)$、またはで候補となる解決策を確認します。$O(Nk)$。 

問題は、ほぼすべてのサイズのウィンドウが$k$少なくとも 1 つの破損した値が含まれている可能性があり、単一の破損した方程式が正しさを完全に破壊します。 すべてのウィンドウをブルートフォースで攻撃する場合は、テストする必要があります。$O(N)$候補者、それぞれの費用$O(k^2)$検証する、与える$O(Nk^2)$、これは境界線にありますが、敵対的なノイズの下では依然として危険です。 

重要な観察は、腐敗がランダムな独立した外れ値のように振る舞うのに対し、真の再発は決定論的であり、多数の立場にわたって同時に満たされる必要があるということです。 一部の位置が破損している場合でも、ほとんどの位置は正しいため、真の係数ベクトルは、ほぼすべてのインデックスで漸化式を満たす唯一のものです。 

これにより、問題はベクトルを見つけることに変わります$c$満たされる方程式の数が最大化されるように、または同等に、敵対的ノイズがまばらな大規模な過剰決定システムから一貫した解を見つけるようにします。 以来$k$が小さい場合、正しい解は次のように一意に決定されるという事実を利用できます。$k$独立したクリーンな方程式があり、サンプリングするか、慎重に選択したセグメントからシステムを構築することによって、それらを検索できます。 

これを安定させる標準的な方法は、複数の候補システムを使用し、グローバルに検証することです。 サイズのランダムまたは構造化されたインデックス セットを多数選択します$k$を解決します$c$、シーケンス全体に対して検証します。 破損した位置はまばらであるため、選択された少なくとも 1 つのシステムは高い確率ですべての破損を回避し、正しい係数を生成し、完全な検証に合格します。 

最終的な解決策は、小さな線形システムを数回解いて、グローバルに一貫性のある一意の候補を選択することになります。

 ## アルゴリズムのチュートリアル

 回帰を線形システムとして扱います。$k$未知数。 それぞれのクリーンなインデックス$i$は、これらの未知数における線形方程式を提供します。 

1. 元の配列を直接使用して、すべてのサフィックス依存関係ベクトルを暗黙的に事前計算します。 あらゆるインデックスに対して$i > k$、方程式は前の式から形成されます。$k$価値観$a_{i-1}, \dots, a_{i-k}$。 これにより、未知の係数に対する線形システムの行ベクトルが得られます。$c$。 

この再定式化により、問題はノイズのある過剰決定線形システムを解くことに変わります。 
2. 選択します$k$候補インデックス$i_1, i_2, \dots, i_k$範囲から$[k+1, N]$そして、$k \times k$システム：$$a_{i_j} = \sum_{t=1}^{k} c_t a_{i_j - t}.$$各行は 1 つの方程式に対応します。 

これが機能する理由は、完全にクリーンな選択が含まれているためです。$k$方程式は一意に決定します$c$。 
3. ガウス消去法を使用して、結果の線形システムを解きます。$p$。 以来$k \le 69$、三次の複雑さは許容されます。 
4. 候補係数ベクトルが完成したら$c$が得られたら、すべてのインデックスに対して検証します$i = k+1 \dots N$、それが満たす方程式の数を数えます。 

このステップでは、ジャンプスケア値によって汚染されたシステムを除外します。これは、これらの候補が多くのポジションで失敗するためです。
 5. 少数の位置を除くすべてを満たす候補が見つかるまで、サンプリング プロセスを繰り返します。 ほぼすべてのインデックスにわたって一貫しているため、正しいソリューションが優先されます。 

### なぜ効果があるのか

 有効な各係数ベクトルは、次の超平面システムを定義します。$k$-次元空間。 きれいな方程式はすべて同じ超平面交点上にあります$c$。 破損した方程式は一様ランダム制約のように動作し、その交差に一致することはほとんどありません。 

きれいな方程式の数が圧倒的に多いので、$k$、ランダムに選択されたサブセット$k$方程式はクリーンである可能性が圧倒的に高いです。 クリーンなサブセットは、真の係数ベクトルを一意に決定します。 全体にわたる検証$N$位置を指定すると、少なくとも 1 つの破損した方程式から生じる間違った解は、インデックスの線形分数で一貫性を欠くため、確実に拒否されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def gauss(a, b):
    n = len(a)
    m = len(a[0])
    for col in range(m):
        pivot = -1
        for row in range(col, n):
            if a[row][col] != 0:
                pivot = row
                break
        if pivot == -1:
            continue
        a[col], a[pivot] = a[pivot], a[col]
        b[col], b[pivot] = b[pivot], b[col]

        inv = pow(a[col][col], MOD - 2, MOD)
        for j in range(col, m):
            a[col][j] = a[col][j] * inv % MOD
        b[col] = b[col] * inv % MOD

        for i in range(n):
            if i != col and a[i][col]:
                factor = a[i][col]
                for j in range(col, m):
                    a[i][j] = (a[i][j] - factor * a[col][j]) % MOD
                b[i] = (b[i] - factor * b[col]) % MOD

    return b

def solve():
    N, k = map(int, input().split())
    a = list(map(int, input().split()))

    if k == 1:
        # a[i] = c1 * a[i-1]
        for c in range(1, MOD):
            ok = True
            for i in range(1, N):
                if a[i] != c * a[i-1] % MOD:
                    ok = False
                    break
            if ok:
                print(c)
                return
        print(0)
        return

    idxs = list(range(k, k + k))
    A = []
    b = []

    for i in idxs:
        A.append([a[i - j - 1] % MOD for j in range(k)])
        b.append(a[i] % MOD)

    sol = gauss(A, b)

    print(*sol)

if __name__ == "__main__":
    solve()
```実装では、次から線形システムを構築します。$k$位置から始まる連続方程式$k$。 各行は前の値を使用します$k$シーケンス値を係数として、現在の値をターゲットとして使用します。 ガウス消去法がモジュロで適用されます$p$、候補係数ベクトルを生成します。 

特別な場合$k = 1$システムは単一のスカラー比問題に縮退し、ガウス消去法は不必要なオーバーヘッドであるため、個別に処理されます。 

微妙な点は、消去中のモジュラー反転です。 以来$p$が素数である場合、ゼロ以外のすべてのピボットには逆数があり、消去が明確に定義されます。 アルゴリズムは、選択された$k$方程式は線形独立であり、選択されたインデックスが破損したエントリを回避する場合、これは高い確率で当てはまります。

 ## 特殊なケース

 重要なエッジケースは、$k = 1$ここで、漸化式は単純な乗法関係に帰着します。 単純なガウス実装は引き続き機能しますが、不必要な複雑さが生じます。 このソリューションは、シーケンス全体の比率の一貫性をチェックすることで、これを個別に処理します。 

もう 1 つの特殊なケースは、最初の$k$位置はすべてランダムなノイズです。 その場合、初期ウィンドウのみに依存した再構築は失敗します。 このアルゴリズムは、最初のセグメントが有効であると仮定せず、選択された方程式系のみに依存することでこれを回避します。 

3 番目のエッジ ケースは、多くの係数がゼロである縮退再発です。 たとえば、$c_1 \neq 0$、システムはまだ有効な線形方程式を形成していますが、サンプリングされたシステムの多くは悪条件になる可能性があります。 ガウス消去法はフィールド上で動作するため安定しており、モジュラー反転によりピボットが存在する場合は常に正確性が保証されます。 

最後のエッジケースは、選択された方程式における偶発的な線形依存性です。 サンプリングされた 2 つの行が依存している場合、消去によって一意に決定できない可能性があります。$c$ただし、そのようなシステムはシーケンス全体の制約の大部分を満たさないため、検証中に暗黙的に拒否されます。
