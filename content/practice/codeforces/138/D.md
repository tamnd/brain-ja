 ## 解決策
 ## 問題の理解

 すべてのセルに 3 つのシンボルのいずれかが含まれる長方形のボードがあります。 移動すると、アクティブなセルが選択され、そのセルを通過する対角線に沿ったセルが無効になります。 

正確な対角線はシンボルによって異なります。 

マークされたセル`L`2つの対角線を一定数で攻撃する`i + j`。 マークされたセル`R`2つの対角線を一定数で攻撃する`i - j`。 マークされたセル`X`両方の種類を攻撃します。 

攻撃はすでに非アクティブなセルに到達すると停止するため、非アクティブなセルは対角線を独立したセグメントに分割します。 

ゲームは公平であり、両方のプレーヤーが最適にプレーします。 先発プレイヤーが勝利する戦略を持っているかどうかを判断する必要があります。 

基板の寸法は最大でも`20 × 20`, したがって、最大でも`400`細胞。 これは、セルのサブセットに対する状態空間検索には大きすぎます。`2^400`状態を探索することは不可能です。 

寸法の限界が小さいことは、何か構造的なものを示唆しています。 動きは対角線にのみ影響するため、ボードは実際には個々のセルではなく、対角線間の相互作用によって支配されます。 

微妙な点は、攻撃が対角線全体を永久に消費するとは限らないことです。 一部のセルが非アクティブになると、以降の移動はそれらの非アクティブなセルで停止します。これは、対角線がいくつかの小さな独立したゲームに分割される可能性があることを意味します。 

例えば：```
3 3
XXX
XXX
XXX
```中央のセルを再生した後、対角線は切断された領域に分割されます。 すべての対角線を完全に削除されたものとして扱う単純な実装では、間違った Grundy 値が生成されます。 

もう 1 つの簡単な間違いは、すべての動きが 1 つのジオメトリ オブジェクトにのみ影響を与えると仮定することです。 アン`X`セルは両方の対角方向に同時にタッチするため、ゲームを 4 つの独立したサブゲームに分割できるクロスカットのように動作します。 

考慮する：```
1 1
X
```唯一の移動では単一のセルが削除され、移動は残りません。 正しい答えは、`WIN`。 

空の領域や mex 計算を誤って処理する不注意な実装により、誤った値が返される可能性があります。`LOSE`。 

もう 1 つの危険なエッジ ケースは、切断されたパリティ クラスから発生します。 偶数のセル`(i + j)`決して奇数の細胞と相互作用しないでください`(i + j)`対角線の移動によりパリティが維持されるためです。 この分解を忘れると、DP 状態は必要以上に大きくなります。 

例：```
2 2
RL
LR
```ゲームは 2 つの独立したコンポーネントに分割され、それぞれに Grundy 値が含まれます`1`、つまり、xor は`0`そして答えは`LOSE`。 

## アプローチ

 ブルートフォースのアイデアは単純です。 アクティブなセルと非アクティブなセルによってボードの状態を表し、すべての正当な手を再帰的に試し、標準的な公平なゲームの再帰を使用して勝敗の状態を計算します。 

これが機能するのは、ゲームが有限かつ決定的であるためです。 すべての移動により、アクティブなセルの数が厳密に減少します。 

問題は州の数です。 あ`20 × 20`ボードには`400`セルなので、考えられるすべてのサブセットを保存する場合でも、`2^400`州。 それは天文学的に手の届かないところにあります。 

重要な観察は、移動が対角線を介してのみ相互作用するということです。 

対角線上に 2 つのファミリーがあります。 

等しいセル`i + j`同じに属している`/`対角線。 

等しいセル`i - j`同じに属している`\`対角線。 

すべての動きは、これらの対角線上の間隔を切ります。 セルが非アクティブになると、攻撃はそこで永久に停止するため、残りのアクティブなセルは小さな独立した領域に分割されます。 

この構造はまさにスプレイグ・グランディ理論が好むものです。 ある手がゲームを独立したサブゲームに分解する場合、グランディ数はサブゲームの xor になります。 

2 番目の主要な観察はパリティです。 

移動は常に、固定パリティを持つセル内に留まります。`i + j`。 偶数パリティ セルと奇数パリティ セルは決して相互作用しないため、ゲーム全体がすぐに 2 つの独立したゲームに分割されます。 

1 つのパリティ クラス内では、対角線が格子状の座標系を形成します。 インデックスを付けることができます`/`1 つの座標による対角線と`\`別の対角線。 この変換された空間では、すべてのサブゲームが長方形になります。 

次に、移動により長方形内の点が選択され、それが最大 4 つの小さな長方形に分割されます。 

これにより、問題はメモ化された長方形 Grundy DP に変わります。

 ## アルゴリズムのチュートリアル

 1. ボードをパリティによって 2 つのゲームに分割します。`(i + j)`。 

対角移動ではパリティが維持されるため、異なるパリティ クラスのセルが相互に影響を与えることはありません。 
2. 1 つのパリティ クラスの場合、すべてのセルを対角座標にマッピングします。 

させて：`a = (i + j) / 2`

`b = (i - j + m - 1) / 2`1 つのパリティに制限すると、これらは整数になります。 
3. DP 状態を定義する`grundy(u, d, l, r)`。 

これは長方形の領域を表します。`u ≤ a ≤ d`

`l ≤ b ≤ r`4. 長方形内のすべてのセルを列挙します。 

セルが現在のパリティ クラスの外側またはボードの外側にある場合は、そのセルをスキップします。 
5. そのセルを動かしてみます。 

移動タイプによって、長方形がどのように分割されるかが決まります。 

のために`L`セルに沿ってカットします`a`座標。 

のために`R`セルに沿ってカットします`b`座標。 

のために`X`セルでは、両方の座標に沿って切り取ります。 
6. 結果として得られる部分長方形の xor を計算します。 

独立した地域は独立した公平なゲームに対応するため、それらの Grundy 値は XOR でまとめられます。 
7. 到達可能なすべての Grundy 値を収集し、mex を計算します。 

その mex が現在の長方形のグランディ数になります。 
8. 計算されたすべての状態をメモ化します。 

同じ四角形が何度も再帰的に現れます。 
9. 2 つのパリティ ゲームの xor を計算します。 

xor がゼロ以外の場合、最初のプレーヤーが勝ちます。 そうしないと、最初のプレイヤーが負けます。 

### なぜ効果があるのか

 不変条件は、すべての DP 状態が、対角座標の長方形の内側にあるまだアクティブなすべてのセルを表し、外側のすべてのセルがすでにブロックされていることです。 

動きをプレイするたびに、攻撃光線は非アクティブなセルまたは境界で停止します。 長方形の境界はすでにブロッカーとして機能しているため、この移動により、長方形がより小さな独立した長方形に分割されます。 

Sprague-Grundy 理論では、素和集合のグランディ数は構成要素であるグランディ数の xor に等しいと述べています。 すべての手がまさにそのような分解を生成するため、再帰公式は実際のゲームと一致します。 

メモ化により、すべての状態が固有の正しい Grundy 値を受け取ることが保証され、最後の XOR によって勝者が正しく決定されます。 

## Python ソリューション```python
import sys
from functools import lru_cache

input = sys.stdin.readline

n, m = map(int, input().split())
g = [input().strip() for _ in range(n)]

# map parity-separated coordinates
cells = {}

for i in range(n):
    for j in range(m):
        p = (i + j) & 1
        a = (i + j) // 2
        b = (i - j + m - 1) // 2
        cells[(p, a, b)] = g[i][j]

MAXA = (n + m) // 2 + 2
MAXB = (n + m) // 2 + 2

@lru_cache(None)
def solve(parity, u, d, l, r):
    if u > d or l > r:
        return 0

    s = set()

    for a in range(u, d + 1):
        for b in range(l, r + 1):
            key = (parity, a, b)

            if key not in cells:
                continue

            typ = cells[key]

            if typ == 'L':
                val = (
                    solve(parity, u, a - 1, l, r) ^
                    solve(parity, a + 1, d, l, r)
                )

            elif typ == 'R':
                val = (
                    solve(parity, u, d, l, b - 1) ^
                    solve(parity, u, d, b + 1, r)
                )

            else:
                val = (
                    solve(parity, u, a - 1, l, b - 1) ^
                    solve(parity, u, a - 1, b + 1, r) ^
                    solve(parity, a + 1, d, l, b - 1) ^
                    solve(parity, a + 1, d, b + 1, r)
                )

            s.add(val)

    mex = 0
    while mex in s:
        mex += 1

    return mex

ans = (
    solve(0, 0, MAXA, 0, MAXB) ^
    solve(1, 0, MAXA, 0, MAXB)
)

print("WIN" if ans else "LOSE")
```最初のセクションでは、すべてのボード セルを対角座標に変換します。 これが中心となる幾何学的変換です。 パリティによって分離された後、到達可能なすべてのセルは、変換されたシステム内の整数座標に配置されます。 

再帰的 DP は、対角空間内の長方形領域を表します。 空の長方形はすぐに Grundy 値を返します`0`。 

トランジション ロジックは、各動きの幾何学的効果を反映します。 

アン`L`move は、変換された座標から 1 本の水平線を削除し、長方形を上部と下部の部分に分割します。 

アン`R`move は垂直線を 1 本削除します。 

アン`X`move は両方を同時に削除し、4 つの独立した象限を作成します。 

最もエラーが発生しやすい部分は、座標マッピングです。 表現:```
b = (i - j + m - 1) // 2
```負の対角インデックスを非負の空間にシフトします。 

もう 1 つの微妙な詳細は、存在しない座標をスキップすることです。 すべてではありません`(a, b)`ペアは有効なボード セルに対応するため、実際のセルのみを`cells`。 

メモ化は必須です。 キャッシュがなければ、再帰的な爆発は非常に大規模になります。

import sys, io
from functools import lru_cache

def run(inp: str) -> str:

    input = sys.stdin.readline

    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    cells = {}

    for i in range(n):
        for j in range(m):
            p = (i + j) & 1
            a = (i + j) // 2
            b = (i - j + m - 1) // 2
            cells[(p, a, b)] = g[i][j]

    MAXA = (n + m) // 2 + 2
    MAXB = (n + m) // 2 + 2

    @lru_cache(None)
    def solve(parity, u, d, l, r):
        if u > d or l > r:
            return 0

        s = set()

        for a in range(u, d + 1):
            for b in range(l, r + 1):
                key = (parity, a, b)

                if key not in cells:
                    continue

                typ = cells[key]

                if typ == 'L':
                    val = (
                        solve(parity, u, a - 1, l, r) ^
                        solve(parity, a + 1, d, l, r)
                    )

                elif typ == 'R':
                    val = (
                        solve(parity, u, d, l, b - 1) ^
                        solve(parity, u, d, b + 1, r)
                    )

                else:
                    val = (
                        solve(parity, u, a - 1, l, b - 1) ^
                        solve(parity, u, a - 1, b + 1, r) ^
                        solve(parity, a + 1, d, l, b - 1) ^
                        solve(parity, a + 1, d, b + 1, r)
                    )

                s.add(val)

        mex = 0
        while mex in s:
            mex += 1

        return mex

    ans = (
        solve(0, 0, MAXA, 0, MAXB) ^
        solve(1, 0, MAXA, 0, MAXB)
    )

    return ("WIN" if ans else "LOSE") + "\n"

assert run("2 2\nRL\nLR\n") == "LOSE\n", "sample 1"

# minimum board
assert run("1 1\nX\n") == "WIN\n", "single move"

# all same values
assert run("2 2\nXX\nXX\n") == "WIN\n", "all X"

# parity cancellation
assert run("1 2\nLR\n") == "LOSE\n", "two independent piles"

 ## 特殊なケース

 可能な限り最小の基板を考えてみましょう。```
1 1
X
```変換されたゲームには、セルが 1 つだけ含まれます。 これを再生すると、リージョンが 4 つの空の長方形に分割されます。 すべての空の長方形にはグランディがいます`0`、したがって、移動は価値に達します`0`。 メキシコの`{0}`は`1`, したがって、開始プレイヤーが勝ちます。 

ここでパリティ分離を調べます。```
2 2
RL
LR
```偶数パリティのセルは、奇数パリティのセルと相互作用することはありません。 このアルゴリズムは各パリティを独立して解決し、答えを XOR します。 

各コンポーネントにはグランディがあります`1`、与える：```
1 xor 1 = 0
```したがって、正しい答えは`LOSE`。 

最後に、分割が頻繁に行われるケースを考えてみましょう。```
3 3
XXX
XXX
XXX
```中央のセルを再生すると、両斜め方向がカットされます。 再帰的 DP は 4 つの独立した部分四角形を作成します。 アルゴリズムはこれを自然に処理します。`X`4 つの象限状態を明示的に XOR します。 

対角線をグローバルに削除するだけの単純な実装では、これらの新しく分離された領域が見逃され、不正確なグランディ数が計算されます。
