 ## 解決策
 ## 問題の理解

 ヴァレラは数字で始まります$x$そして実行します$k$それに対するランダムな操作。 各ステップで、彼は確率で偏ったコインを投げます。$p/100$の場合は現在の数値を 2 倍にし、そうでない場合は 1 ずつ増分します。 結局$k$ステップごとに、最終的な数値が 2 で何回割れるかを数えます。 そのカウント、$s$、出力です。 この問題は次の期待値を求めます。$s$すべてのランダムなステップの後、これは加重平均を意味します$s$可能性のあるすべての操作シーケンスを確率に従って実行します。 

入力数値は次のように制限されます。$x$まで可能です$10^9$、$k$200まで、そして$p$0 から 100 まで。すべての総当たりシミュレーション$2^k$シーケンスは不可能なので、$k=200$生み出すだろう$2^{200}$実行可能な計算を大幅に超えたシーケンス。 これは、動的プログラミングまたは状態圧縮アプローチを示唆しています。 エッジケースには以下が含まれます$p=0$または$p=100$、決定的なシーケンスと奇数対偶数を生成します。$x$値は 2 で割り切れる値に直ちに影響します。 

単純なアプローチではシミュレートされる可能性があります$a$直接的には可能ですが、大きな数値を 2 倍にすると、標準の配列や 64 ビット整数の範囲をはるかに超える値がすぐに生成されます。 どのような解決策も、2 を除算する指数を考慮して推論する必要があります。$a$オーバーフローを避けるため、絶対値ではなく。 

## アプローチ

 ブルートフォースアプローチは簡単です。すべてを生成します。$2^k$2 倍または増分シーケンスの結果を計算します。$a$、その後、末尾のゼロを数えます。 各シーケンスには確率の重みがあります。 これは理論的には正しいのですが、$2^k$シーケンスは実行不可能です$k=200$- だいたい$10^{60}$可能性。 ブルート フォースは問題ステートメントの直後に続くため機能しますが、シーケンスの数が指数関数的に増加するため失敗します。 

重要な観察は、末尾のゼロの最終的な数は、現在の末尾のゼロの数と、2 倍にするか増分するかという 2 つのことだけに依存するということです。 2 倍すると、数値が偶数の場合は後続のゼロが 1 ずつ増加し、数値が奇数の場合はゼロのままになります。 数値をインクリメントすると、予測可能な方法で末尾のゼロに影響します。数値が奇数の場合は 1 (末尾のゼロ) になり、偶数の場合は 1 を追加すると指数パターンが減少します。 これにより、動的プログラミング状態を定義できるようになります。$dp[step][zeros]$その後の確率として`step`数値が正確に持つ演算`zeros`末尾のゼロ。 各ステップは前のステップと 2 つの操作のみに依存するため、確率を反復的に伝播できます。 

この観察により、指数関数的問題が管理可能な DP 問題に変換されます。`k`最大 200、末尾のゼロの最大数は次のサイズによって制限されます。$x \cdot 2^k$、32 ビット表現の指数では最大 229 です。 確率分数または浮動小数点数を慎重に使用すると、期待値が得られます。

 ## アルゴリズムのチュートリアル

 1. 末尾のゼロの初期数を計算します。$x$。 これは 2 の指数です$x$。 電話してください`tz0`。 もし$x$は奇数です、これはゼロです。 
2. DP 配列を定義する`dp[step][tz]`その後に起こる確率を表す`step`操作、番号は`tz`末尾のゼロ。 初期化する`dp[0][tz0] = 1.0`。 
3. 反復する`step`1から`k`。 考えられる末尾のゼロのカウントごとに`tz`前のステップで、次の操作の効果を計算します。 

- 倍増 (`*2`) は、末尾のゼロの数を 1 つ増やします。 それで追加します`dp[step-1][tz] * (p/100)`に`dp[step][tz+1]`。 
- 増加 (`+1`) 1 を追加することが末尾のゼロにどのような影響を与えるかを理解する必要があります。 もし`tz`がゼロ (奇数) の場合、インクリメントすると末尾のゼロが生成されます。 もし`tz >= 1`、1 を追加すると、末尾の 0 が 0 になります。 それで追加します`dp[step-1][tz] * (1 - p/100)`に`dp[step][0]`。 
4.完了後`k`ステップごとに、末尾のゼロの期待値を全体の合計として計算します。`tz`:`expected = sum(tz * dp[k][tz] for tz in dp[k])`。 
5. 十分な精度で期待値を出力します。 

正確さを保証する不変式は次のとおりです。`dp[step][tz]`後続ゼロの正確な確率分布を常に保持します。`step`操作。 確率を使用してすべての可能性を正しく伝播するため、最終的な期待値が正しいことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

x, k, p = map(int, input().split())
p /= 100.0

# compute initial trailing zeros
def trailing_zeros(n):
    tz = 0
    while n % 2 == 0:
        n //= 2
        tz += 1
    return tz

tz0 = trailing_zeros(x)

# maximum trailing zeros cannot exceed tz0 + k
max_tz = tz0 + k

dp = [0.0] * (max_tz + 2)
dp[tz0] = 1.0

for step in range(1, k + 1):
    next_dp = [0.0] * (max_tz + 2)
    for tz in range(max_tz + 1):
        prob = dp[tz]
        if prob == 0:
            continue
        # doubling
        next_dp[tz + 1] += prob * p
        # incrementing
        next_dp[0] += prob * (1 - p)
    dp = next_dp

expected = sum(tz * prob for tz, prob in enumerate(dp))
print(f"{expected:.12f}")
```このコードは、まず最初の末尾のゼロを計算します。 次に、末尾のゼロでインデックス付けされた確率の DP 配列を設定します。 各ステップで、2 倍演算と増分演算の後に新しい分布を計算し、最後に予想される末尾のゼロの数を計算します。
