 ## 解決策

 ## 問題の理解

 各テスト ケースには 2 つの長方形が与えられますが、その方向は固定されていません。 各長方形は 2 つの辺の長さによってのみ記述され、どちらの値も幅または高さを表すことができます。 課題は、これら 2 つの長方形が、垂直方向または水平方向に一度切断され、正確にこれら 2 つの部分が生成された単一の正方形から生じた可能性があるかどうかを判断することです。 

より具体的に言い換えると、正方形の辺に合わせて 1 つの直線カットを使用して 2 つの小さな長方形にスライスした後、得られた長方形のペアを (それぞれを独立して回転させることによって) 指定された寸法に一致するように再配置できるような正方形が存在するかどうかを判断しようとしています。 

制約範囲は非常に小さく、各辺の長さは最大 100 で、最大 10^4 のテスト ケースがあります。 これは、定数時間またはテストごとの O(1) 推論で十分であり、単純な条件チェックでも十分以上の速度であることをすぐに示唆しています。 状態空間は小さく、いくつかの幾何学的制約によって完全に特徴付けられるため、検索やシミュレーションを伴うものは何も必要ありません。 

主な微妙さは、方向の曖昧さと、正方形のカットが非常に構造化された出力を生成するという事実から来ています。 単純な間違いは、両方の部分の一貫性を強制せずに、各長方形から独立して辺の長さを推測することによって正方形を再構築しようとすることです。 

誤った推論を打ち破ることが多いいくつかの特殊なケース:

 両方の長方形が 2 × 3 と 3 × 1 である場合、単純なアプローチでは、配置制約をチェックせずに誤って辺 5 または 4 の正方形を形成しようとする可能性がありますが、これらの形状では単一の直線カットで一貫して正方形をタイリングすることができません。 

2 x 2 や 2 x 2 など、両方の長方形が同一の場合、向きに応じて一方向に並んでいる場合に限り、常に辺 2+2=4 の正方形を形成します。 

一方の長方形が 3 × 3 で、もう一方の長方形が 1 × 3 の場合、辺の長さが共有されているため有望に見えるかもしれませんが、切断によって一貫した完全な辺の長さが得られない限り、正方形を形成することはできません。 

## アプローチ

 1 本の直線で正方形を切り取ると、非常に特殊な構造が生まれます。 可能性は 2 つだけです。垂直方向の切断か水平方向の切断です。 

辺が S の正方形を想像すると、垂直に切断すると、S × x および S × (S − x) の寸法の 2 つの長方形が生成されます。 両方の長方形は同じ高さ S を共有する必要があります。同様に、水平方向のカットでは x x S および (S − x) x S が生成されます。これは、両方の長方形が同じ幅 S を共有することを意味します。 

この観察により、問題は、同じ高さを共有し、その幅の合計が共通の S になるように、または同じ幅を共有し、その高さの合計が S になるように、2 つの長方形に向きを割り当てることができるかどうかを確認することに帰着します。 

強引な解釈では、両方の長方形の可能な方向をすべて試してから、それぞれの構成から正方形の辺を推測しようとします。 各長方形には 2 つの向きがあるため、合計で 4 つの組み合わせしかなく、それぞれについて有効な正方形のパーティションを形成するかどうかをテストできます。 これはすでに継続的な作業であるため、総当たり攻撃は事実上最適化されています。 

重要な洞察は、正方形を再構築するのではなく、整合性を検証するだけでよいということです。両方の長方形を水平に積み重ねて正方形を形成する (同じ高さ) か、垂直に積み重ねた (同じ幅) かのいずれかです。 

ブルートフォースが「失敗」するのは、構造がすでに暗黙的に S を制約している一方で、S を明示的に構築するという観点から考えることによって推論が過度に複雑になるという意味においてのみです。

 ## アルゴリズムのチュートリアル

考えられる両方のカット方向をチェックすることで、2 つの長方形が正方形を形成できるかどうかをテストします。 

### 1. 表現を正規化する

 各長方形について、(幅、高さ) の両方の割り当てを試行することで、両方の方向を暗黙的に考慮します。 入力順序は任意であるため、これが必要です。 

### 2. 垂直カット条件を試す

 両方の長方形が同じ高さを共有すると仮定します。 この仮定の下で、それらの高さを等しくできるかどうか、および組み合わせた幅が正方形の辺となる同じ値に等しいかどうかを確認します。 

長方形 1 が (w1, h1) で、長方形 2 が (w2, h2) である場合、次のようにテストします。 

h1 == h2 の場合、候補正方形の辺は h1 となり、w1 + w2 == h1 を確認します。 

また、両方の長方形の向きを入れ替えてみます。 

### 3. 水平カット条件を試す

 ここでは、両方の長方形が同じ幅を共有していると仮定します。 w1 == w2 かどうか、および h1 + h2 がその共有幅に等しいかどうかをテストします。 

もう一度、すべての方向の交換を確認します。 

### 4. 結果を返す

 いずれかの構成がいずれかの条件を満たす場合、有効な正方形の構成が存在すると結論付けられます。 

### なぜ効果があるのか

 単一の直線カットにより、正方形が軸に沿って正確に 2 つの長方形に分割され、これらの長方形は 1 つの次元に沿って完全に整列する必要があります。 これにより、一方の次元が両方の部分にわたって一定のままになる一方、もう一方の次元は加算的に分割されて正方形の辺が形成されます。 長方形の方向は柔軟であるため、すべての回転を列挙することで、有効な位置合わせを見逃すことがなくなります。 他の幾何学的構成では、正方形から 1 つのカットで正確に 2 つの長方形を作成することはできないため、これら 2 つの条件は必要かつ十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def ok(a, b, c, d):
    # (a,b) and (c,d)
    # try vertical cut: same height
    if b == d and a + c == b:
        return True
    # try horizontal cut: same width
    if a == c and b + d == a:
        return True
    return False

t = int(input())
for _ in range(t):
    a1, b1 = map(int, input().split())
    a2, b2 = map(int, input().split())

    # try all orientations
    if (
        ok(a1, b1, a2, b2) or
        ok(a1, b1, b2, a2) or
        ok(b1, a1, a2, b2) or
        ok(b1, a1, b2, a2)
    ):
        print("YES")
    else:
        print("NO")
```コア機能`ok`は、2 つの構造の可能性をエンコードします。両方の長方形が同じ高さを共有し、その幅の合計がその高さに一致する (正方形の垂直カット)、または両方の長方形が同じ幅を共有し、その高さの合計がその幅に一致する (水平カット) のいずれかです。 入力では向きが指定されていないため、外側のループは単純にすべての回転を列挙します。 

唯一の微妙な実装の詳細は、4 つの方向の組み合わせがすべてテストされるようにすることです。 スワップが 1 つでも欠けていると、有効な構成が誤って拒否されます。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    def ok(a, b, c, d):
        if b == d and a + c == b:
            return True
        if a == c and b + d == a:
            return True
        return False

    t = int(input())
    out = []
    for _ in range(t):
        a1, b1 = map(int, input().split())
        a2, b2 = map(int, input().split())

        if (
            ok(a1, b1, a2, b2) or
            ok(a1, b1, b2, a2) or
            ok(b1, a1, a2, b2) or
            ok(b1, a1, b2, a2)
        ):
            out.append("YES")
        else:
            out.append("NO")

    return "\n".join(out)

 ## 特殊なケース

 重要なエッジケースは、両方の長方形が同一である場合です。 たとえば、入力 (2,2) と (2,2) は、垂直または水平の分割によって 4 × 4 の正方形を形成できるため、YES を返す必要があります。 アルゴリズムは両方の方向をチェックし、一方の次元が一致し、もう一方の次元が正しく合計されていることを検出します。 

もう 1 つのエッジ ケースは、長方形が一辺を共有しているにもかかわらず、正しく合計できない場合です。 (3,3) と (1,3) の場合、アルゴリズムは両方の方向をテストします。 1 つの構成では高さが一致していても、幅の合計が一貫した正方形の辺にならないため、すべてのチェックが失敗し、出力は正しく NO になります。 

最後の特殊なケースは、向きが不可欠な場合です。 (2,3) と (3,1) の場合、単純なチェックでは有効な構成 (2,3) と (1,3) が見逃される可能性があります。 徹底的な方向の列挙により、このケースが正しく処理され、YES が生成されることが保証されます。
