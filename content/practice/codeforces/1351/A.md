 ## 解決策
 ## 問題の理解

 このタスクでは、整数のペアを追加するように求められます。 各テスト ケースは 2 つの整数で構成されており、ペアごとにそれらの合計を計算する必要があります。 入力は最初にペアが何個あるかを示し、その後、後続の各行にペアが含まれます。 出力は、各ペアに対応する合計のシーケンス (1 行に 1 つ) です。 

制約は単純ですが、注目に値します。 各整数は -1000 ～ 1000 の範囲にあるため、Python では整数のオーバーフローは問題になりません。 テスト ケースの数は 10,000 に達する場合があります。これは、Python は 10,000 の単純な操作を 1 秒以内に快適に処理できるため、すべてのテスト ケースを 1 回繰り返すソリューションは十分に効率的であることを意味します。 負の数では合計が 0 または負になる可能性があるため、解では入力が厳密に正であると仮定してはなりません。 

明らかでないエッジ ケースには、一方または両方の数値がゼロであるペア、合計が正から負へ、またはその逆にゼロと交差するペア、および両方の数値が境界 (-1000 または 1000) にあるペアが含まれます。 たとえば、次のペア`-1000 1000`出力する必要があります`0`。 マイナスを無視した不用意な実装は、間違った符号を生成する可能性があります。 

## アプローチ

 ブルートフォース手法では、各行を読み取り、2 つの整数を解析し、それらの合計を計算し、結果をすぐに出力します。 これが機能するのは、2 つの整数の合計が O(1) 演算であり、Python では 10,000 を超えるテスト ケースを反復するのが効率的であるためです。 入力を順番に読み取って処理することには、隠れた複雑さはありません。 

すべてのテスト ケースを処理して合計を計算する必要があるため、これ以上に最適な漸近アプローチはありません。 唯一の改善点は、高速化のためにバッチ入力読み取りを使用することです。`sys.stdin.readline`これにより、Python の遅いデフォルト入力が回避されます。 この小さな最適化により、入力サイズが最大であっても、制限時間内でプログラムが快適に実行されることが保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(t) | お(1) | 承認済み |
 | 最適 | O(t) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 これにより、処理する必要があるペアの数がわかります。 
2. 反復する`t`回。 各反復では次のようになります。 

1. 2 つの整数を含む行を読み取ります。`a`そして`b`。 
2. 行を整数に変換します。 入力が文字列であるため、変換が必要です。 
3. 合計を計算します`a + b`。 
4. 合計をすぐに出力します。 
3. すべてのテスト ケースに対して繰り返します。 

重要な不変条件は、反復ごとに、`a`そして`b`制約内で有効な整数です。 それらを合計すると正しい答えが得られ、印刷では出力順序が即座に維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    print(a + b)
```最初の行はテスト ケースの数を読み取ります。 ループは正確に実行されます`t`各ペアを読み取り、整数に変換し、合計し、出力します。 使用する`sys.stdin.readline`大規模なテスト ファイルに対する遅い入力操作を回避します。`map(int, input().split())`負の場合でも両方の値が正しく解析されるようにします。 ループ内で印刷すると、追加のストレージを必要とせずに順序が維持されます。

## 複雑さの分析

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        a, b = map(int, input().split())
        print(a + b)
    return output.getvalue().strip()

# provided sample
assert run("4\n1 5\n314 15\n-99 99\n123 987") == "6\n329\n0\n1110", "sample 1"

# minimum inputs
assert run("1\n0 0") == "0", "minimum input"

# maximum inputs
assert run("2\n1000 1000\n-1000 -1000") == "2000\n-2000", "maximum absolute values"

# mixed signs
assert run("3\n-500 500\n-200 100\n0 -1") == "0\n-100\n-1", "mixed signs"

# single test case
assert run("1\n123 456") == "579", "single case"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 0 0 | 0 | 最小値 |
 | 2 1000 1000 \n -1000 -1000 | 2000\n-2000 | 最大絶対値 |
 | 3 -500 500 \n -200 100 \n 0 -1 | 0\n-100\n-1 | 混合符号とゼロの処理 |
 | 1 123 456 | 579 | 単一のテスト ケースの正確性 |

 ## 特殊なケース

 ペア用`-1000 1000`、アルゴリズムは次のように読み取ります`a=-1000`、`b=1000`、計算します`a+b=0`、およびプリント`0`。 各読み取り数値が範囲内にあるという不変条件により、オーバーフローがないことが保証されます。 合計は符号に関係なく正しく処理され、入力の極値におけるアルゴリズムの堅牢性が実証されています。 同様に、`0 0`、合計は`0`、最小限の入力に対する正しい動作を確認します。
