 ## 解決策
 ## 問題の理解

 樹木上の車の有効な駐車スケジュールを数えるように求められます。 ツリーの各頂点には最終的に 1 台の車がホストされます。 車はある時点でルートに入り、割り当てられた頂点までの固有のパスに沿って瞬時に移動し、そこに駐車し、後で同じパスに沿って戻ります。 車が頂点を占有している間は、他の車はその頂点を通過できません。 2 台の車両が同じ頂点を同時に占有または通過しようとしない場合、スケジュールは有効です。 

入力は複数のテスト ケースで構成され、それぞれが頂点の数を指定します。`n`そしてたくさんの葉っぱ`k`（根元は除く）。 1 つのツリーを考慮するだけでなく、これらのパラメータを持つラベル付きツリーすべての有効なスケジュールの数を合計するように求められます。 入場時間と退場時間のシーケンスは、一緒になって次の順列を形成する必要があります。`1..2n`そして満足する`l_i < r_i`各車ごとに。 

制約は重要です。`n`まで可能です`2*10^5`、そしてそれがあるかもしれません`10^4`テストケース、ただしすべての合計`n`テストケース全体の境界は次のとおりです`2*10^5`。 これは、すべてのツリーまたはすべてのシーケンスを明示的に列挙できないことを意味します。 おおよそよりも複雑なソリューション`O(n)`テストケースごとにタイムアウトになります。 エッジケースには以下が含まれます`n=2`(最小サイズ) と`k=n-1`(スター ツリー)、駐車の順列の数が高度に制限されています。 

単純なシミュレーションは、すべてを生成しようとするため失敗します。`n!`ラベル付きの木と各木のすべて`(2n)!/(2^n)`候補者`(l,r)`シーケンス、これは不可能です。 さらに、パスに沿って頂点をブロックする車の影響を数え間違えることは、特に単純なチェーンや星形ではない木の場合、微妙な誤差の原因となります。 

## アプローチ

 ブルートフォースアプローチでは、まずラベル付きのツリーをすべて列挙します。`n`頂点と`k`葉、それぞれの木について考えられるすべてを列挙します`(l,r)`シーケンスをチェックし、それぞれの有効性をチェックし、カウントを合計します。 これは原理的には正しいですが、ラベル付きの木の数だけでは次のようになります。`n^{n-2}`(ケイリーの公式)、超指数関数的に成長するため、ブルートフォースアプローチは完全に手に負えなくなります。`n=10`。 

重要な洞察は、樹木駐車スケジュールの構造を理解することから得られます。 内部頂点 (非リーフ、非ルート) は、その子孫のリーフへのパスに沿ってのみアクセスできます。 したがって、葉の数が分かれば、`k`、パスに沿った多重度を推測できます。 問題は、指定された数の葉を持つラベル付きツリーを数えることと、そのインターリーブ数を計算することに帰着します。`l_i`そして`r_i`ツリー構造を尊重したシーケンス。 組み合わせ恒等式と階乗操作を使用すると、これは本質的に次の式に帰着します。```
#count = C(n-2, k-1) * factorial(k) * factorial(2n-k-1)
```これにより、どの頂点がリーフであるかの選択、自動車の時間のリーフへの割り当て、および内部頂点の寄与がキャプチャされます。 All calculations are done modulo`998244353`。 階乗および逆階乗の事前計算により、組み合わせと積を効率的に計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * n!) | O(n) | 遅すぎる |
 | 階乗を使用した組み合わせ式 | O(n + t) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 階乗を事前計算します。`2*max_n`およびその逆モジュラー。 これにより、モジュロの組み合わせと順列の高速計算が可能になります。`998244353`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして`k`。 ラベル付きの木の数を次のように計算します。`n`頂点と`k`Cayley の公式と葉を選択するための公式を使用して葉を抽出します。 
3. 有効枚数`(l,r)`特定のツリーのシーケンスは、パス制約を尊重しながら葉と内部頂点に時間を割り当てる方法をカウントすることによって計算されます。 これは次のように導出できます。`factorial(k) * factorial(2n-k-1)`。 
4. ツリー構造の数とそのツリーの有効なシーケンスの数を乗算し、剰余を減らします。`998244353`、結果を出力します。 
5. すべてのテスト ケースに対して繰り返します。 

正確性が不変であるということは、内部頂点をルートとする各サブツリーが合計カウントに乗算的に寄与するということです。これは、互いに素なサブツリー内の自動車のスケジュールが干渉せず、Cayley の式は、指定された数の葉を持つラベル付きの木を正確にカウントするためです。 時間の順序により複数の車両が同時に経路を占有しないことが保証されるため、組み合わせシーケンス カウントは暗黙的にブロッキング ルールを尊重します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAXN = 400000

# Precompute factorials and inverse factorials
fact = [1] * (MAXN + 1)
invfact = [1] * (MAXN + 1)
for i in range(1, MAXN + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAXN] = pow(fact[MAXN], MOD - 2, MOD)
for i in range(MAXN, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def comb(n, k):
    if k < 0 or k > n:
        return 0
    return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD

def solve_case(n, k):
    # number of trees with k leaves: C(n-2, k-1) * n^(n-2-(k-1))
    trees = comb(n-2, k-1) * pow(n, n-1-k, MOD) % MOD
    # number of valid sequences for a given tree
    sequences = fact[k] * fact[2*n - 1 - k] % MOD
    return trees * sequences % MOD

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    print(solve_case(n, k))
```階乗および逆階乗の事前計算により、組み合わせを O(1) で計算できるようになります。 べき乗と階乗の剰余を慎重に計算します`998244353`オーバーフローを避けるため。 この式は、問題を 2 つの独立した組み合わせカウント (指定された葉を持つ木と有効な駐車シーケンス) に分割し、それらを乗算します。
