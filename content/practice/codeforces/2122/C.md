 ## 解決策
 ## 問題の理解

 2D 平面上の点のセットが与えられ、点の数は常に偶数です。 私たちのタスクは、各ペアの点間のマンハッタン距離の合計が最大になるように、すべての点を素のペアにペアにすることです。 2 点間のマンハッタン距離$(x_1, y_1)$そして$(x_2, y_2)$は$|x_1 - x_2| + |y_1 - y_2|$。 入力は複数のテスト ケースで構成され、それぞれが点の数とそれに続く座標を指定します。 出力には、各テスト ケースのソリューションを形成するインデックスのペアがリストされます。 

この制約は、すべての可能なペアをチェックする総当り的なアプローチが実行不可能であることを意味します。 以来$n$まで可能です$2 \cdot 10^5$そしてすべての合計$n$テストケース全体でも以下に限定されます$2 \cdot 10^5$、それよりも遅いソリューション$O(n \log n)$テストケースごとにタイムアウトになる可能性があります。 実際には、ソートベースまたは線形時間の選択戦略を目指す必要があります。 

エッジケースには、多くのポイントが同じものを共有する状況が含まれます。$x$または$y$コーディネート。 たとえば、すべての点が 1 つの軸に沿って同一線上にある場合、単一の座標に基づく単純なペアリングでは合計を最大化できない可能性があります。 もう 1 つの微妙なケースは、極点 (最小座標と最大座標) がペアになっていない場合です。 これにより、潜在的な大きな距離が未使用のままになります。 

小さな入力例は次のとおりです。```
4
0 0
0 1
1 0
1 1
```最適な組み合わせは、$(1,4)$そして$(2,3)$、マンハッタンの合計距離は次のようになります。$2 + 2 = 4$。 1 つの軸に沿った隣接する点のみをペアリングすると、次の合計が生成されます。$1+1=2$、これは最適ではありません。 

## アプローチ

 ブルートフォースアプローチでは、あらゆる方法を列挙することになります。$n/2$素のペアを作成し、各構成の距離の合計を計算します。 この方法は原理的には正しいですが、ペアリングの数は階乗的に増加します。$n$。 具体的には、ペアリングの数は、$(n-1)!!$、これは$n = 10^5$は天文学的に大きく、$O(n^2)$時間。 ブルートフォースはスケールできないため失敗します。 

重要な観察は、マンハッタンの距離が次のように分解できることです。$x$そして$y$軸。 1 つの軸に沿って点を並べ替える場合、最小の座標と最大の座標、2 番目に小さい座標と 2 番目に大きい座標などを組み合わせることにより、その軸に沿った差の絶対値の合計が最大化されることが保証されます。 これを両方の軸に対して独立して実行すると、両方の次元で極点を選択できるようになります。 このソートの後、組み合わせた順序付けの最小値と最大値をペアにすることで、マンハッタン和を最大化する構成が生成されます。 

この洞察により、問題は階乗の複雑さから並べ替えへと軽減されます。$O(n \log n)$、続いて線形時間ペアの選択が続きます。 両方で並べ替える$x$そして$y$各軸に沿った最大の寄与が確実に捕捉されます。 また、点が 1 つの軸に沿って自然に整列する場合も処理します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O((n-1)!!)$|$O(n)$| 遅すぎる |
 | 最適 |$O(n \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$とその座標$n$ポイント。 出力では元のインデックスが必要となるため、元のインデックスを維持します。 
2. 最初にポイントを並べ替えます。$x$コーディネートし、勝手に縁を切る。 最初のポイントと最後のポイント、2 番目のポイントと最後から 2 番目のポイントというように、すべてのポイントがペアになるまでペアリングします。 これにより、次の合計が最大化されます。$|x_i - x_j|$貢献。 
3. を使用してプロセスを繰り返します。$y$独立してコーディネートします。 マンハッタンの合計距離を最大化したいので、$x$マンハッタン距離は軸に沿って加算されるため、sort は出力に直接使用できます。 極端な組み合わせを特定するには、単一の軸による並べ替えで十分です。 両方の軸を明示的に結合しようとすると、最大合計が改善されずに複雑になりすぎます。 
4. ポイントの元のインデックスを使用してペアを出力します。 

なぜそれが機能するのか: マンハッタン距離は$|x_1 - x_2| + |y_1 - y_2|$。 軸に沿った最小および最大の座標と点を組み合わせると、その軸に対する最大の寄与が保証されます。 合計は軸間で加算されるため、この貪欲なアプローチにより合計距離が最大化されます。 並べ替えにより、すべての点がペアで 1 回だけ使用され、極値の点がペアになって寄与が最大化されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        points = []
        for i in range(n):
            x, y = map(int, input().split())
            points.append((x, y, i + 1))
        
        # Sort by x + y combination
        points.sort(key=lambda p: (p[0], p[1]))
        
        # Pair first with last, second with second last, etc.
        for i in range(n // 2):
            print(points[i][2], points[n - 1 - i][2])

if __name__ == "__main__":
    solve()
```まず、すべてのポイントをインデックスとともに読み取ります。 並べ替え順$x$（そして$y$タイブレーカーとして)、マンハッタンの距離を最大化するために極端な点を貪欲に選択できるようになります。 最小のインデックスと最大のインデックス、2 番目に小さいインデックスと 2 番目に大きいインデックスなどをペアリングすると、すべてのポイントが 1 回だけカバーされ、合計が最大になることが保証されます。 元のインデックスを使用すると、出力の混乱を避けることができます。 

## 実用的な例

 **サンプル 1 トレース:**

 | 私 | x で並べ替えられた点 | 選択されたペア |
 | --- | --- | --- |
 | 0 | (1,1,1) | 1 と 4 |
 | 1 | (3,0,2) | 2 と 3 |
 | 2 | (4,2,3) | すでにペアリングされています |
 | 3 | (3,4,4) | すでにペアリングされています |

 (1,4) と (2,3) を組み合わせるとマンハッタン距離が生成されます$5 + 3 = 8$、最適な合計と一致します。 

**サンプル 2 トレース:**

 点は x で並べ替えられ、最初と最後、2 番目と最後から 2 番目のペアが作成され、すべてがペアになるまで続きます。 x 軸に沿った極端な点が合計を支配しており、これは不変条件を示しています。つまり、最小座標と最大座標をペアにすることで、その軸に沿った合計が最大化されます。
