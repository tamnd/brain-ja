 ## 問題の理解

 単一の整数が与えられます$n$、そして最大の整数を決定したいのです$x$特定の幾何学的または組み合わせ的な構築が可能です。 重要な制約により、問題全体が次のような単純な不等式に還元されます。$x$そして$n$: 構築は正確に実行可能です$x^2 \le 2n$。 言い換えれば、最大の整数を見つけようとしています。$x$その二乗が指定された入力の 2 倍を超えないもの。 

この問題は、各ユニットがどこにリソースを割り当てるかであると考えることができます。$n$2 つの基本スロットと有効なサイズ構成を提供します。$x$消費する$x^2$これらのスロットの。 タスクはプッシュすることです$x$予算内で可能な限り大きくする$2n$。 

入力はこの 1 つの整数だけです$n$。 出力は 1 つの整数であり、実現可能な最大値です。$x$。 

解は純粋に算術的なものであるため、次の制約があります。$n$mainly determine whether we must worry about overflow or floating-point precision. 一般的な Codeforce の境界の場合、$n$まで到達できます$10^{18}$Python では直接の整数乗算と平方根演算は依然として安全ですが、C++ では 64 ビット算術演算に注意する必要があります。 

微妙なエッジケースが現れるのは、$n = 0$。 それから$2n = 0$したがって、唯一有効なのは$x$は 0 です。もう 1 つの境界は次の場合です。$n = 1$、 どこ$2n = 2$、やはり答えは 1 です。$1^2 = 1 \le 2$しかし$2^2 = 4$大きすぎます。 これらの事例は、答えが単純なものではないことを裏付けています。$\lfloor \sqrt{n} \rfloor$、しかし代わりに依存します$2n$。 

単純な間違いは、2 の因数を忘れて計算してしまうことです。$\lfloor \sqrt{n} \rfloor$、すべての答えを過小評価します$n > 0$。 

## アプローチ

 強引なアイデアは、可能な値をすべて試してみることです。$x$0から始めて不等式になるまで増やします$x^2 \le 2n$失敗します。 候補者ごとに$x$、計算します$x^2$そしてそれを比較してください$2n$。 考えられるすべての答えに対して実現可能性を明示的にテストするため、これは正しく機能しますが、パフォーマンスが低下する可能性があります。$O(\sqrt{n})$それ以来の反復$x$おおよそまで成長することができます$\sqrt{2n}$。 多くの場合、これはすでに許容されていますが、不平等の構造が非常に直接的である場合には、依然として不必要な作業です。 

重要な観察点は、次の条件です。$x^2 \le 2n$単調な境界を定義します。 一度値が$x$が無効である場合、それより大きな値もすべて無効です。 これにより、問題は、平方が次の範囲で囲まれる最大の整数を見つけることに変わります。$2n$、これはまさに次の整数の平方根です。$2n$。 反復する代わりに、平方根演算を使用してこれを直接計算してフロアを設定するか、精度の問題を回避するために整数演算に依存することができます。 

したがって、問題はコンピューティングに帰着します$\lfloor \sqrt{2n} \rfloor$。

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る$n$入力から。 問題全体はこの 1 つの値のみに依存するため、追加の解析や前処理は必要ありません。 
2. コンピューティング$m = 2n$。 これにより、元の状態がきれいな形に変わります。$x^2 \le m$、比較する量を分離します。 
3. の整数の平方根を計算します。$m$、これは最大の整数です$x$そのような$x \cdot x \le m$。 これは実現可能性の境界に直接対応します。 
4. この値を最終的な答えとして出力します。 

### なぜ効果があるのか

 不平等$x^2 \le 2n$有効な整数の単調セットを定義します。$x$が機能する場合は、より小さな値もすべて機能します。$x$失敗すると、それより大きな値はすべて失敗します。 これにより、解が正確にこの単調述語の境界点であることが保証されます。 整数平方根関数はその境界を正確に検出し、有効な値がスキップされたり、無効な値が含まれたりしないようにします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def main():
    n = int(input().strip())
    m = 2 * n
    ans = math.isqrt(m)
    print(ans)

if __name__ == "__main__":
    main()
```実装はアルゴリズムをほぼそのまま反映しています。 2 の乗算は、変換された制約を反映するために最初に実行されます。 それから`math.isqrt`の大きな値で発生する可能性のある精度エラーを回避するために、浮動小数点平方根の代わりに使用されます。$n$。 この関数は整数の平方根を安全に計算します。$O(1)$Python での償却時間。 

よくある実装上の間違いは、`int(math.sqrt(m))`直接。 浮動小数点の丸めは多くの場合機能しますが、場合によっては次のような結果が生じることがあります。$x - 1$倍精度の限界に近い完全な正方形の場合。 使用する`isqrt`これを完全に回避します。

 ## 特殊なケース

 のために$n = 0$、計算します$m = 0$、したがって、答えは次のとおりです$\lfloor \sqrt{0} \rfloor = 0$。 アルゴリズムはこれを自然に処理します。`isqrt(0)`特別な分岐を行わずに 0 を返します。

非常に大きい場合$n$、 のような$10^{18}$、$m$64 ビット範囲内に留まります ($2 \cdot 10^{18}$)、Python の任意精度整数はそれを安全に処理します。 の計算`isqrt`安定した状態を保ち、浮動小数点エラーを完全に回避するため、境界での精度の低下は発生しません。
