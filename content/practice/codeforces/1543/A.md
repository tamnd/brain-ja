 ## 問題の理解

 2 つの非負の整数が与えられ、それらをロックステップで移動できます。すべての操作で両方の値がまったく同じ量だけ変更され、両方とも 1 ずつ増加するか、両方とも 1 ずつ減少します (ゼロを下回らない限り)。 

私たちが気にするスコアは、一連の動きの後の 2 つの数値の最大公約数です。 このスコアを最大化したいと考えており、可能な限り最大の GCD を達成するすべての方法の中で、必要な手数を最小限に抑えたいと考えています。 

重要な観察は、すべての動きで 2 つの数値の差が維持されるということです。 定義すると$d = a - b$、その後、両方の操作が維持されます$a - b$変わらない。 これは、プロセス全体がフォームのポイントに制限されることを意味します。$(x, x - d)$または$(x + d, x)$注文に応じて。 

制約は次のとおりです$10^{18}$したがって、到達可能なすべての状態を試す解決策は不可能です。 周囲の値の範囲をスキャンしても$a$そして$b$到達可能な値は両方向の無限の線にまたがるため、これは実現不可能です。 

微妙なエッジケースが現れるのは、$a = b$。 その場合、両方の数値を増やすと平等が保たれ、GCD が値そのものと等しくなるため、際限なく増加する可能性があります。 これは無限の興奮につながり、それを検出する必要があります。 

1 つの値がゼロの場合、別の特殊なケースが発生します。 以来$gcd(x, 0) = x$、両方の値を減らすことは不可能かもしれませんが、両方を増やすことは、負の制約でブロックされない限り、任意の大きな等しい値に到達することを可能にします。 ただし、最適な推論は依然として不変差に依存します。 

単純な間違いは、複数の関係に向けて値を個別に調整できると想定することです。 差を変更することはできないため、ターゲットのペアは固定線形関係を満たさなければなりません。 

## アプローチ

 強引なアイデアは、到達可能なすべての状態をシミュレートすることです。$(a, b)$BFS または DFS によって、両方の値を一緒に ±1 ずつ更新します。 状態グラフは両方向の無限の線であるため、これはすぐに無限になります。 ヒューリスティックに境界を制限したとしても、GCD は近さではなく可分性に依存するため、最適な GCD は遠く離れた場所で発生する可能性があります。 

重要な構造的洞察は次のとおりです。$d = |a - b|$決して変わりません。 到達可能なペアは次のように記述できます。$$(a', b') = (x, x - d)$$ある整数に対して$x$(注文したと仮定して)。 

選びたい$x$次のような:$$\gcd(x, x - d)$$最大化されます。 

ID の使用:$$\gcd(x, x - d) = \gcd(x, d)$$問題は選択に帰着する$x$可能な最大の約数を固定数と共有するように直線上に配置します。$d$、開始点からの距離を最小限に抑えながら。 

可能な最大 GCD は単純に次のようになります。$d$可能であればそれ自体を実行しますが、整数ステップに一致する値にのみ到達できるという制約を設けて実現可能性を確保する必要があります。$a$そして$b$。 

重要な構造上の結果は、達成可能な最良の GCD は次のとおりであるということです。$g = |a - b|$シフトによって 1 つの数値を複数の構造に整列させることができる場合。 それ以外の場合、いつ$a = b$、答えは無限です。 

これにより、タスクは、差分アラインメントと最も近い有効な構成までの距離に基づく単純な数論的計算に減らされます。

 ## アルゴリズムのチュートリアル

 1. もし$a = b$、すぐに無限の興奮を返します。 

その理由は、操作を何度行っても両方の数値が常に等しく、インクリメント操作を繰り返すと GCD が際限なく増大するためです。 
2. コンピューティング$d = |a - b|$。 

この差は、許可されたすべての操作の下で不変であるため、到達可能なすべての状態は固定された算術直線上にあります。 
3. もし$d = 0$、すでに処理済みなので、次の前提で進めてください。$d > 0$。 
4. 達成可能な最良の GCD を次のように計算します。$g = d$。 

これはアイデンティティから来ています$\gcd(x, x - d) = \gcd(x, d)$、つまり、GCD は常に次の約数になります。$d$、そして私たちは整列することができます$x$この除数を最大化するには、$d$自体。 
5. いずれかの数値が次の値で割り切れる構成に到達するために必要な最小移動数を決定します。$d$。 

移動するたびに両方の数値が 1 ずつシフトされるため、事実上、ペアを整数ラインに沿ってシフトすることになります。 距離を最小限に抑えるために、最も近い複数のアライメントを選択します。 
6. 距離を計算する$a$は最も近い倍数からのものです$d$、そのシフトを移動数として使用します。 

### なぜ効果があるのか

 不変条件は、その違いです$a - b$決して変わりません。 これにより、到達可能なすべての状態が単一の 1 次元格子に制限されます。 この格子では、GCD は 1 つの変数と固定定数の関数に単純化されます。$d$。 達成可能なすべての GCD は次の約数であるため、$d$、最大値は、1 つの座標が次の倍数になるように状態を調整することによって達成されます。$d$。 各操作により格子点全体が正確に 1 単位だけシフトされるため、最小の移動カウントが続き、最も近い有効なアライメントに到達することが最適になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a, b = map(int, input().split())

        if a == b:
            print(0, 0)
            continue

        d = abs(a - b)

        # shift to nearest multiple alignment
        r = a % d
        move = min(r, d - r)

        print(d, move)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず等しい場合をチェックします。これが、無制限の増加につながる唯一のシナリオです。 その後はすべて不変差に依存します$d$。 残りの部分$a$モジュロ$d$私たちが一致からどれだけ離れているかを示します$a$の倍数に$d$、両方の数値をシフトすると、到達可能なラインに沿って移動しながら実現可能性が維持されます。 

のみを使用するという選択$a \% d$両方の数値をシフトすると両方に対称的な影響があり、整列条件は固定差に対する可算性のみに依存するため、 は有効です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        a, b = map(int, input().split())
        if a == b:
            out.append("0 0")
        else:
            d = abs(a - b)
            r = a % d
            out.append(f"{d} {min(r, d - r)}")

 ## 特殊なケース

 いつ$a = b$、アルゴリズムはすぐに戻ります$0, 0$。 たとえば、入力$4, 4$は等価性を生成し、増分を繰り返すと GCD が無制限に増加するため、早期の終了によりこれが正しく捕捉されます。 

1 つの値がゼロの場合、次のようになります。$0, 5$、差は 5 であり、剰余ロジックが引き続き適用されます。 計算により、有効なシフト距離はゼロになります。これは、GCD を最大化するために移動する必要がないことを意味します。 

すでに値が近い場合、次のようになります。$7, 3$、差は 4 で、7 モジュロ 4 の余りは 3 です。アルゴリズムは、最小シフトを正しく選択して、4 で割り切れる構成に到達します。 

値が非常に大きいが 1 だけ異なる場合、差は 1 であり、すべての構成の GCD は 1 になります。改善は不可能であるため、剰余ロジックではゼロ手しか生成されません。
