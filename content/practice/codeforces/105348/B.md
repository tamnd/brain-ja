 ## 問題の理解

 整数の順序ペアが何組あるかを数えるように求められます$(x, y)$与えられた数字から形成することができます$n$、ビットごとに適用される 2 つのバイナリ制約の下で。 

最初の制約は、ペアの XOR を修正します。$x$そして$y$、それらの XOR は、のバイナリ表現を再現する必要があります。$n$。 2 番目の制約は、ビット単位の AND を修正しますが、シフトされます。$x$そして$y$に等しくありません$n$、しかし代わりに等しい$2n$、つまり$n$バイナリ位置を 1 つ左にシフトします。 

各テスト ケースの出力は、有効なペアの数です。$(x, y)$両方の制約を同時に満たします。 順序が重要なので、$(x, y)$そして$(y, x)$異なる場合は別々にカウントされます。 

制約により許可されるのは、$n$まで$10^{15}$これは、数値ごとに最大 60 ビットを処理していることを意味します。 各ビットを独立して処理するか、テスト ケースごとに小さな線形スキャンで処理するソリューションで十分ですが、値を列挙しようとするものはすべて、$x$または$y$ビット数が増えると指数関数的に増加するため、直接実行することはすぐには不可能です。 

2 つの制約間の相互作用を考えると、微妙な問題が生じます。 通常、XOR と AND は独立したビットごとの動作を記述しますが、ここでは AND が XOR に対して 1 位置シフトされます。 これにより、隣接するビット間に結合が生じます。$n$これは、単純なビットごとの分解では見落としがちです。 

ある特殊なケースでは、これが特に顕著になります。 もし$n = 1$の場合、シフトにより の 2 番目のビットを含む制約が強制されます。$x$そして$y$たとえXORが最下位ビットにしか触れなかったとしても。 シフトを考慮せずに各ビットを独立して処理するソリューションでは、誤ったカウントが生成されたり、無効なペアが過剰にカウントされたりするのはこのためです。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての値を試します。$x$そして$y$～によって暗示されるある制限まで$n$。 以来$x \oplus y = n$、両方の数値がほぼ同じビット長以内に収まる必要があります。$n$したがって、からのすべての値を反復しようとする可能性があります。$0$に$2^{60}$。 両方の条件をチェックして有効なペアに制限しても、依然として次のオーダーの実行不可能な検索スペースが発生します。$2^{120}$候補ペア。 

重要な簡素化は、XOR と AND の間の関係を書き直すことで実現します。 任意の 2 つの整数について、恒等式は$$x + y = (x \oplus y) + 2(x \& y)$$常に保持されます。 制約を代入すると次のようになります。$$x + y = n + 2 \cdot (2n) = 5n$$したがって、合計は固定されます。 ただし、実際の構造は単に合計を固定するよりも強力です。XOR 制約と AND 制約を組み合わせて、AND 条件内のシフトを除き、各ビットを独立して決定します。 

シフトされた AND はそのビットを意味します$i$の$x \& y$ビットに等しい$i$の$2n$、ビットです$i-1$の$n$。 これにより、隣接するビット間に依存関係が生じます。$n$、問題を隣接ビットに対するローカル整合性チェックに変えます。 

ビットごとにすべてを表現すると、各位置で可能な割り当てはわずか数個だけになります。$(x_i, y_i)$、矛盾が現れない限り、解全体は独立したビット寄与の積になります。

 ## アルゴリズムのチュートリアル

 バイナリで作業し、シフトされた AND によって導入された相互作用を注意深く追跡しながら、各ビット位置を個別に処理します。 

1. 2 つのビットマスクを書き込みます。1 つは$A = n$は XOR 制約を表し、もう 1 つは$B = 2n$、AND制約を表します。 両方を少しずつ解釈していきます。 
2. その部分を観察します$i$の$B$ビットに等しい$i-1$の$n$の最下位ビットという慣例により、$B$はゼロです。 ここで隣接制約が生まれます。 
3. 各ビット位置について$i$、ペアを考えてみましょう$(x_i, y_i)$。 これら 2 ビットは次の条件を満たす必要があります。 

-$x_i \oplus y_i = A_i$-$x_i \& y_i = B_i$4. 考えられる 4 つのビット ペアを列挙します。 

-$00 \rightarrow (A=0, B=0)$-$01 \rightarrow (A=1, B=0)$-$10 \rightarrow (A=1, B=0)$-$11 \rightarrow (A=0, B=1)$この表は、各制約ペアが 0、1、または 2 つの有効な構成にマップされることを示しています。 
5. これをカウントルールに変換します。 

- もし$A_i = 1$そして$B_i = 1$、設定は不可能です。 
- もし$B_i = 0$そして$A_i = 1$、選択肢は2つあります。 
- それ以外の場合、選択肢は 1 つだけです。 
6. 複数の選択肢を得る唯一の方法は、$A_i = 1$そして$B_i = 0$、これは の 1 ビットに対応します。$n$前のビットは 0 です。 
7. すべてのビットを合計すると、答えは次のようになります。$2^{k}$、 どこ$k$は位置の数です。$n$直前に別の 1 ビットが存在しない 1 ビットがあります。 
8. いずれかのポジションが$A_i = 1$そして$B_i = 1$、構造は完全に壊れており、答えはゼロです。 

### なぜ効果があるのか

 各ビット位置は、次のものだけを含むローカル制約システムのように動作します。$x_i$、$y_i$、およびその隣接ビット$n$シフトされた AND を介して。 隣接するものが表示されないことを確認したら、$n$、すべての制約はビット間で独立するため、有効な割り当ての総数はビットごとの選択の積になります。 隣接するビットを越えた依存関係は存在しないため、グローバル結合によってローカルで一貫した割り当てが無効になることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        
        # invalid if n has consecutive 1s
        if n & (n << 1):
            print(0)
            continue
        
        # count valid "free-choice" bits
        ans = 1
        while n:
            if n & 1:
                ans <<= 1
            n >>= 1
        
        print(ans)

if __name__ == "__main__":
    solve()
```実装では、最初に主要な構造条件がチェックされます。$n$が両方とも 1 の場合、シフトされた AND 制約により矛盾が生じるため、答えはすぐに 0 になります。 

設定が有効な場合、すべての 1 ビットが$n$は、次の位置に対応するため、答えの係数 2 に寄与します。$(x_i, y_i)$2 つの異なる方法で選択できます。 ループは、バイナリ表現をスキャンすることによって、これらの寄与を単純にカウントします。 

シフトする$n$必要なのはそのビットのみであるため、ループ内での破壊的操作は安全です。 隣接性が検証されれば、位置情報は必要ありません。 

## 実用的な例

 検討してください$n = 5$、そのバイナリ形式は次のとおりです$101$。 

| ちょっと | n_i (A_i) | n_{i-1} (B_i) | 貢献 |
 | --- | --- | --- | --- |
 | 0 | 1 | 0 | 2 |
 | 1 | 0 | 1 | 1 |
 | 2 | 1 | 0 | 2 |

 合計は$2 \times 1 \times 2 = 4$。 これは、孤立した 1 ビットのみがどのように乗算的に寄与するかを示しています。 

ここで考えてみましょう$n = 3$、バイナリ$11$。 

| ちょっと | n_i (A_i) | n_{i-1} (B_i) | 有効性 |
 | --- | --- | --- | --- |
 | 0 | 1 | 0 | わかりました |
 | 1 | 1 | 1 | 無効 |

 2 番目の行は制約に違反しています。$n_i$シフトされた 1 インチと一致します$B_i$、その位置では XOR と AND が互換性がなくなります。 これにより、答えは強制的にゼロになります。 

2 番目のケースは、隣接関係が存在する理由を示しています。$n$実現可能性を完全に決定します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque
    it = sys.stdin.read().strip().split()
    
    t = int(it[0])
    idx = 1
    out = []
    
    for _ in range(t):
        n = int(it[idx]); idx += 1
        
        if n & (n << 1):
            out.append("0")
        else:
            ans = 1
            while n:
                if n & 1:
                    ans <<= 1
                n >>= 1
            out.append(str(ans))
    
    return "\n".join(out)

 ## 特殊なケース

 いつ$n = 0$、1 ビットや隣接制約はありません。 このアルゴリズムは空の積を生成し、これは正しく 1 と評価されます。唯一の有効なペアは次のとおりです。$(0,0)$、構造に一致します。 

いつ$n$連続する 1 が含まれます。例:$n = 3$、条件$n \& (n \ll 1) \neq 0$すぐにトリガーされます。 これは、ビットが入っている状況を正確に捉えています。$n$XOR とシフト AND の両方が同じ位置で互換性のない値を要求するように強制します。 

いつ$n$は 2 の累乗であり、すべての 1 ビットが分離されるため、それぞれが独立して 2 の係数に寄与し、2 に等しいきれいな指数結果が得られます。
