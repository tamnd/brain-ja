 ## 解決策
 ## 問題の理解

 ツリーが与えられ、ノードごとに、そのノードをパス上のどこかに強制的に配置した場合にパスがどのくらい「大きく」なるかを測定したいと考えています。 

より正確には、ノードを修正します`i`。 考えられるすべてのノードのペアを調べます`(u, v)`ツリー内で、`u`に`v`通り抜ける`i`。 そのようなすべてのペアの中で、間の最大の距離を取得します。`u`そして`v`ここで、距離はパス上のエッジの数です。 その最大値がノードの答えになります`i`。 

したがって、各ノードについて、ツリー全体の偏心率を求めるのではなく、ノードを通過するように制約されている最適な直径のようなパスを求めます。 

入力サイズが大きい: 最大 1000 個のテスト ケースがあり、すべてのテストにわたるノードの合計数は最大で 1000 個です。`10^5`。 これにより、ノードごとに 2 次、さらにはテスト ケースごとに 2 次の解が即座に除外されます。 すべてのペアの距離を再計算したり、各ノードから BFS を繰り返し実行しようとすると失敗します。 テスト ケースごとに線形または線形に近いソリューションが必要です。 

単純な落とし穴は、各ノードの答えが木の直径だけであると仮定することです。 ノードが直径パス上にない場合、これは false になります。 たとえば、ノード 1 を中心とする星のような形のツリーでは直径は 2 ですが、リーフ ノードの場合は直径が 2 になります。`i`、それを通過する最適なパスはリーフから中心へ、そして別のリーフであり、これはまだ 2 であるため、一致します。 ただし、より歪んだツリーでは、直径の端点から遠く離れたノードの直径は厳密に小さく制限されます。 

もう 1 つのよくある間違いは、ノードごとにツリー全体の最も遠いノードを計算し、その距離を 2 回使用しようとすることです。 これは、最適パスの 2 つのエンドポイントが通過するため失敗します。`i`の異なるブランチに存在する必要があります`i`、ルート化された意味で両方が同じサブツリー方向にあるわけではありません。 

小さな失敗例:

 入力:```
1
4
1 2
2 3
3 4
```期待される出力:```
3 2 2 3
```単純な「どこでもグローバル直径」アプローチではすべて 3 が出力されますが、ノード 2 または 3 は反対側の両端を使用してそれらを通る長さ 3 のパスを実現できません。 

## アプローチ

 ブルートフォースのアイデアは単純です。 各ノードについて`i`、すべてのペアを検討してください`(u, v)`、それらの間のパスが通過するかどうかを確認します`i`、最大距離を計算します。 ツリー内で、`i`の間の道にあります`u`そして`v`LCA ロジックを使用するか、距離をチェックすることで実行できますが、そのチェックを最適化したとしても、すべてのペアを列挙するのは困難です。`O(N^2)`ノードごとに、`O(N^3)`全体的に最悪の解釈です。 より慎重な各ノードからの BFS アプローチでも依然としてコストがかかります`O(N^2)`テスト ケースごとに、大きすぎます`10^5`合計ノード数。 

重要な観察点は、ノードを修正することです。`i`次の場合に、ツリーを複数の接続されたコンポーネントに分割します。`i`が削除されます。 通過する有効なパス`i`これらのコンポーネントのいずれかで始まり、別のコンポーネントで終わる必要があります。 したがって、ノードについては`i`、それを通る最適なパスは、`i`を上っていく`i`唯一の橋として。 

これにより、各隣接サブツリーについて問題が理解できるようになります。`i`、サブツリーから離れるときにそのサブツリー内で到達可能な最も遠いノードは何ですか`i`。 隣接する方向ごとに、下向きの最大距離がわかっている場合、`i`、次の答えは`i`は 2 つの異なる方向の最適な合計になります。 

これは本質的に「再ルートを伴うツリー DP」の問題です。 最初に下向きの深さを計算し、次に上向きの寄与を伝播して、各ノードがそのサブツリーだけでなく、全方向からの最適な値を認識できるようにします。 

最終的に、各ノードのすべての隣接方向の中で 2 つの最良の深さが得られ、制限された直径はそれらの合計になります。

 | 再ルートを伴うツリー DP | テスト ケースあたり O(N) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 通常はノード 1 でツリーを任意にルートし、2 つの DP 状態を計算します。ノードからサブツリーへの最適な下向きパスと、親側からの再ルートされた最適な寄与です。 

1. ノード 1 でツリーをルートし、DFS を実行して計算します。`down[u]`、からの最大距離`u`そのサブツリーにダウンします。 それぞれの子どもたちにとって`v`、`down[u] = max(down[u], down[v] + 1)`。 これにより、各子サブツリーに完全に含まれる最適なチェーンがキャプチャされます。 
2. 同じ DFS または 2 番目のパス中に、各ノードの 2 つの最大値も追跡します。`(down[child] + 1)`すべての子供たちの上に。 これらは、次から始まる最適な 2 つの下向きブランチを表します。`u`。 
3. ここで、再ルート DFS を実行して、`up[u]`からの最適な距離`u`親を通って上向きに、ツリーに含まれていない部分へ`u`のサブツリー。 親から子に移動するときは、その子のサブツリーを除いて寄与度を再計算する必要があります。そのため、上位 2 つの子の寄与度が必要になります。 
4. 各ノードについて`u`、答えは、`u`。 これらのブランチは両方の子から派生します (`down`) とその親側 (経由)`up`）。 すべての枝の長さの候補を小さなリストに集め、最大の 2 つの値の合計を取得します。 
5. この合計をノードごとに出力します。 

最大値だけではなく上位 2 つの寄与を維持する理由は、ノードを通る最適なパスが 2 つの異なるブランチを使用する必要があるためです。 パスがノードで分岐する必要があるため、同じサブツリーを 2 回使用することは不可能です。 

### なぜ効果があるのか

 どのノードでも`u`、削除`u`ツリーを隣接コンポーネントごとに 1 つずつ、素のコンポーネントに分解します。 通過する有効なパス`u`2 つの異なるコンポーネントを選択し、それぞれの内部で可能な限り長いチェーンを使用する必要があります。 民進党はこう述べている`down`そして`up`各コンポーネントで利用可能な最大チェーン長を正確にエンコードします。 すべてのコンポーネントの最良の寄与が 1 回だけ個別に取得されるため、2 つの最大の寄与を組み合わせると最適なペアが得られます。 どのパスもこれを超えることはできません。`u`は、厳密に 2 つの異なる隣接コンポーネントを選択するように制約されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        g = [[] for _ in range(n + 1)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            g[u].append(v)
            g[v].append(u)

        parent = [0] * (n + 1)
        order = []
        
        stack = [1]
        parent[1] = -1
        
        while stack:
            u = stack.pop()
            order.append(u)
            for v in g[u]:
                if v == parent[u]:
                    continue
                parent[v] = u
                stack.append(v)

        down = [0] * (n + 1)

        for u in reversed(order):
            best1 = 0
            best2 = 0
            for v in g[u]:
                if v == parent[u]:
                    continue
                val = down[v] + 1
                if val > best1:
                    best2 = best1
                    best1 = val
                elif val > best2:
                    best2 = val
            down[u] = best1

        up = [0] * (n + 1)
        ans = [0] * (n + 1)

        children = [[] for _ in range(n + 1)]
        for v in range(2, n + 1):
            children[parent[v]].append(v)

        stack = [1]
        up[1] = 0

        while stack:
            u = stack.pop()

            best1 = best2 = -1
            best_child = [-1] * (len(g[u]) + 1)

            for v in g[u]:
                if v == parent[u]:
                    continue
                val = down[v] + 1
                if val > best1:
                    best2 = best1
                    best1 = val
                elif val > best2:
                    best2 = val

            for v in g[u]:
                if v == parent[u]:
                    continue
                use = best1
                if down[v] + 1 == best1:
                    use = best2
                up[v] = max(up[u] + 1, use + 1 if use != -1 else 0)
                stack.append(v)

            candidates = []
            candidates.append(up[u])
            for v in g[u]:
                if v == parent[u]:
                    continue
                candidates.append(down[v] + 1)

            candidates.sort(reverse=True)
            ans[u] = candidates[0] + (candidates[1] if len(candidates) > 1 else 0)

        print(*ans[1:])

if __name__ == "__main__":
    solve()
```ソリューションは、ツリー上の 2 つのパスで構成されています。 最初のパスではサブツリーの深さを計算します (`down`) 逆の DFS 順序を使用します。 2 番目のパスは上向きの寄与を伝播します (`up`) 子に情報を渡すときに、事前に計算された上位 2 つの子の値を使用して、その子自身のサブツリーの寄与を確実に除外します。 

各ノードにおける最終的な答えは、そのノードで利用可能なすべての方向性分岐の長さを収集することによって形成されます。これには、親側の寄与とすべての子側の寄与が含まれます。 上位 2 つの値を並べ替えまたは選択すると、互いに素な方向の最適なペアが得られます。 

微妙な点は、計算時に「除外された子」ロジックが正しいことを確認することです。`up[v]`。 2 番目に優れた子コントリビューションを維持しないと、誤って同じサブツリーを再利用してしまい、正確さが損なわれてしまいます。

 ## 特殊なケース

 単一ノード ツリーは最も単純な境界です。 アルゴリズムが初期化されます`down[1]=0`子供がいないため、候補リストには次の内容のみが含まれます。`up[1]=0`、答え 0 が生成されます。これは、自明なノード以外にパスが存在しないという事実と一致します。 

星型ツリーは、複数の同一のブランチが正しく処理されるかどうかをチェックします。 各葉は中心までの枝の長さ 1 に寄与し、最良の 2 つは常に 1 と 1 となり、中心の直径が 2 に制限され、葉にも 2 が与えられます。 再ルート パスにより、リーフが上向きのパスとして中心の寄与を正しく継承することが保証されます。 

チェーンが長いと、深さの伝播が両方向に確実に行われます。 各内部ノードは上向きの長いブランチと下向きの長いブランチを 1 つずつ認識し、アルゴリズムは同じ側からの寄与を混合することなく一貫してそれらを選択します。
