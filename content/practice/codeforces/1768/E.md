 ## 問題の理解

 サイズの順列が与えられています`3n`、以下のすべての整数を含む配列です。`1`に`3n`ある順序で 1 回だけ。 許可されている操作は 2 つあります。最初の操作は並べ替えることができます。`2n`要素または最後の要素を並べ替える`2n`要素。 私たちのタスクは、すべての順列について、配列を完全に昇順に並べ替えるのに必要な操作の最小数を決定し、これらの数をすべて合計することです。`(3n)!`順列。 最終的な答えには素数を法として与える必要があります`M`。 

制約は重要です。`n`まで行くことができます`10^6`、つまり順列のサイズは`3*10^6`。 すべての順列を明示的に反復することは不可能です。`(3n)!`成長が早すぎます。 弾性率`M`は大きな素数であり、組み合わせまたはモジュラー演算方法が必要であることを示しています。 どのソリューションも、時間に対して線形または線形に近い時間で機能する必要があります。`n`。 順列ごとに並べ替え操作をシミュレートする単純なアプローチは完全に除外されます。 

明らかではないエッジケースは小さなことから発生します`n`。 たとえば、次のようなとき`n = 1`、順列は 6 つしかなく、それぞれに 0 ～ 3 回の演算が必要です。 不用意な解決策は、順列ごとの操作数が均一であることを前提としたり、最小サイズで壊れるパターンに依存したりする可能性があります。 もう 1 つの潜在的な落とし穴はモジュラー演算です。中間階乗または積が超過する可能性があります。`M`非常に速いため、慎重なモジュロ演算が不可欠です。

 ## アルゴリズムのチュートリアル

 1. 階乗を事前計算します。`3n`モジュロ`M`およびその逆モジュラー。 最終的な式には分子と分母に階乗が含まれるため、これが必要になります。 フェルマーの小定理を使うと、`inv_fact[k] = pow(fact[k], M-2, M)`逆モジュラーを与えます。 
2. 最小限の演算の合計の組み合わせ恒等式を認識します。合計は次のとおりです。`(3n)! / (n!^3) * n * (3n + 1) / 2`。 これは、考えられるブロック配置ごとに、0、1、2、または 3 回の演算を必要とする置換の数を数えることから得られます。 
3. コンピューティング`3n!`、`n!^3`、および線形係数`(n * (3n + 1) // 2)`モジュロ`M`。 除算を処理するには逆モジュラを使用します。 
4. これらの成分を剰余で乗算します。`M`最終的な答えを得るために。 各乗算と除算はモジュロで実行する必要があります`M`オーバーフローを避けるため。 

機能する理由: このアルゴリズムは、組み合わせ問題を、各ブロック配置の最小演算数を正確にカウントする閉形式の合計に還元します。 モジュロを作用させることにより`M`階乗事前計算を使用して、大規模なデータの正確性を維持します。`n`。 不変条件は、階乗式ですべての順列が正確に 1 回カウントされることです。`(n * (3n + 1) // 2)`必要な操作の数によって順列に正確に重み付けを行います。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, M = map(int, input().split())
    
    max_fact = 3 * n
    fact = [1] * (max_fact + 1)
    inv_fact = [1] * (max_fact + 1)
    
    # Compute factorial modulo M
    for i in range(1, max_fact + 1):
        fact[i] = fact[i - 1] * i % M
    
    # Compute inverse factorial using Fermat's little theorem
    inv_fact[max_fact] = pow(fact[max_fact], M - 2, M)
    for i in range(max_fact, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % M
    
    # Compute n * (3n + 1) // 2 modulo M
    linear_factor = n * (3 * n + 1) // 2 % M
    
    # Compute multinomial coefficient (3n)! / (n!^3)
    multinomial = fact[3 * n] * pow(fact[n], M - 2, M) % M
    multinomial = multinomial * pow(fact[n], M - 2, M) % M
    multinomial = multinomial * pow(fact[n], M - 2, M) % M
    
    ans = multinomial * linear_factor % M
    print(ans)

if __name__ == "__main__":
    main()
```コードはアルゴリズムに従って正確に構造化されています。 までの階乗`3n`計算の繰り返しを避けるために事前に計算されます。 モジュラー演算における効率的な除算のために、モジュラー逆数が 1 回計算されます。 線形係数`(n * (3n + 1) / 2)`ブロック位置によって重み付けされた演算の予想合計を取得します。 乗算はモジュロで慎重に行われます`M`オーバーフローを避けるため。
