 ## 解決策
 ## 問題の理解

 各スティックの長さが整数であるスティックのコレクションが与えられます。 長方形のフレームには、2 つの等しいペアとして配置された 4 本のスティックが必要です。 フレームが正方形の場合、4 本のスティックはすべて同じ長さでなければなりません。 

タスクは、スティックを切ったり組み合わせたりせずに、できるだけ多くのフレームを構築することです。 別のフレームに貢献できない場合は、一部のスティックを未使用のままにする場合があります。 

重要な観察は、すべてのフレームが同じ長さの 2 つのペアを正確に消費するということです。 4 回出現する長さは、それ自体で 1 つの正方形のフレームを作成することも、2 つの別個のペアを異なる長方形に提供することもできます。 

制約は非常に小さいです。 スティックの数は最大でも 100 個で、スティックの長さも最大でも 100 です。非効率的な解決策でもここでは問題なく通過できますが、問題は主に正しいカウント ロジックを認識することです。 

よくある間違いは、4 つの等しいスティックが常に正確に 1 つのフレームを形成し、他の場所では役に立たないと考えることです。 次の入力を考えてみましょう。```
6
5 5 5 5 2 2
```正しい答えは次のとおりです。```
1
```長さ 5 のペアが 2 つ、長さ 2 のペアが 1 つ、合計 3 つのペアがあります。各フレームには 2 つのペアが必要なので、作成できるフレームは 1 つだけです。 

多くの異なる長さがそれぞれ 1 つのペアのみに寄与する場合、別の微妙なケースが発生します。```
8
1 1 2 2 3 3 4 4
```正しい答えは次のとおりです。```
2
```全体で 4 ペアあるので、2 つのフレームを構築できます。 最初に四角形を貪欲に構築しようとする不用意な実装もここでは機能しますが、ペアの合計数のみが重要であるため、より複雑な貪欲な構築は不要です。 

最小のエッジケースは次のとおりです。```
1
7
```正しい答えは次のとおりです。```
0
```一本の棒では一対も形成できません。 

## アプローチ

 問題を強引に考える方法は、残ったスティックの中から 2 つのペアを探して削除し、1 フレームを数えるということを繰り返します。 入力サイズが小さいため、スティックをソートしてペア抽出を直接シミュレートすることもできます。 

たとえば、並べ替えた後、隣接する等しい値をスキャンしてペアを収集し、収集された 2 つのペアごとに 1 つのフレームを形成できます。 これはすでに問題の実際の構造を示唆しています。 

フレームは同じ長さのペアのみに依存するため、ブルート フォース パースペクティブが機能します。 それ以上は実際の寸法は関係ありません。 これを理解すると、問題ははるかに簡単になります。 

スティックの長さが表示されたとします。`cnt`回。 それなら貢献するよ`cnt // 2`使えるペア。 すべてのフレームはちょうど 2 つのペアを消費します。 したがって、ペアの合計数が`P`、答えは簡単です。```
P // 2
```これにより、明示的なフレーム構築が回避されます。 

解決策を明らかにする観察は、ペアの同一性は重要ではないということです。 長さ 2 のペアと長さ 5 のペアは、すでに有効な長方形を形成しています。 同じ長さの 4 本のスティックは単純に 2 つのペアを提供します。 全体の問題は、全体でいくつのペアが存在するかを数えることに帰着します。

 ## アルゴリズムのチュートリアル

 1. スティックの本数とスティックの長さを読み取ります。 
2. 各スティックの長さが何回現れるかを数えます。 

スティックの長さは最大でも 100 であるため、小さな周波数配列または辞書を使用できます。 
3. 個別の長さごとに、それが寄与するペアの数を計算します。 

長さが出る場合`cnt`何度も貢献します`cnt // 2`各ペアには 2 本の等しいスティックが必要なので、ペアになります。 
4. 寄与されたすべてのペアを合計して、という名前の変数に入れます。`pairs`。 
5. コンピューティング`pairs // 2`。 

各フレームはちょうど 2 つのペアを消費するため、ペアの合計数を 2 で割ると、フレームの最大数が得られます。 
6. 結果を印刷します。 

### なぜ効果があるのか

 すべての有効なフレームには、正確に 2 つの等スティック ペアが必要です。 2 つのペアがなければフレームを構築することはできず、どの 2 つのペアでも常に長方形を形成できます。 

表示される長さに対して`cnt`回以上の使用`cnt // 2`各ペアは2本のスティックを消費するため、ペアは不可能です。 すべての長さを合計すると、入力から取得できるペアの最大数が得られます。 

各フレームはスティックの長さに関係なく 2 つのペアを消費するため、フレームの最大数は正確にペアの合計数を 2 で割った値になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

freq = [0] * 101

for x in a:
    freq[x] += 1

pairs = 0

for cnt in freq:
    pairs += cnt // 2

print(pairs // 2)
```解決策は、各スティックの長さの発生を数えることから始まります。 スティックの最大長は 100 のみであるため、固定サイズの配列は辞書よりも単純で高速です。 

変数`pairs`使用可能な等スティック ペアの総数を保存します。 周波数ごとに`cnt`、整数を 2 で割ると、抽出できる素のペアの数が得られます。 

最終的な答えは、`pairs // 2`because every frame consumes two pairs.

 One subtle point is that we never explicitly construct rectangles or squares. それは意図的なものです。 The proof shows that pair count alone completely determines the answer.

 Another detail is that integer division naturally handles leftover sticks. For example, if a length appears 5 times, then`5 // 2 = 2`、つまり 1 本のスティックが未使用のままになります。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    freq = [0] * 101

    for x in a:
        freq[x] += 1

    pairs = 0

    for cnt in freq:
        pairs += cnt // 2

    print(pairs // 2)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.strip()

# provided sample
assert run("5\n2 4 3 2 3\n") == "1", "sample 1"

# minimum input
assert run("1\n7\n") == "0", "single stick"

# all equal

# many distinct pairs
assert run("8\n1 1 2 2 3 3 4 4\n") == "2", "four pairs total"

# maximum useful grouping

 ## 特殊なケース

 1 つのスティックの長さが何度も現れる場合を考えてみましょう。```
8
5 5 5 5 5 5 5 5
```長さ 5 の頻度は 8 なので、寄与します。`8 // 2 = 4`ペア。 すべてのフレームには 2 つのペアが必要なので、答えは次のようになります。`4 // 2 = 2`。 

アルゴリズムは、これらを 2 つの正方形のフレームまたは同等の配置として正しく処理します。 特別な正方形の処理は必要ありません。 

次に、残ったスティックについて考えてみましょう。```
7
1 1 1 2 2 2 3
```周波数は次のとおりです。```
1 -> 3
2 -> 3
3 -> 1
```ペア数は次のようになります。```
1 -> 1 pair
2 -> 1 pair
3 -> 0 pairs
```ペアの合計は 2 なので、答えは 1 フレームです。 

整数の除算では不完全なペアが破棄されるため、長さ 1 と 2 の余分なスティックは自動的に無視されます。 

最後に、さまざまな長さを考えてみましょう。```
8
1 1 2 2 3 3 4 4
```各長さはちょうど 1 つのペアに寄与し、合計 4 つのペアになります。 アルゴリズムの出力`4 // 2 = 2`。 

これは、解の中心不変条件を裏付けています。つまり、ペアの総数のみが重要であり、ペアの長さは関係ありません。
