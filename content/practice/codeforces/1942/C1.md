 ## 解決策
 ## 問題の理解

 次のような正多角形が与えられます。$n$ケーキを表す頂点。 いくつかの頂点は、対角線を描くための潜在的な終点として Bessie によってすでに選択されています。 各対角線は選択した 2 つの頂点を接続します。目標は、これらの選択した頂点間で交差しない対角線によって形成される三角形の数を最大化することです。 この簡単なバージョンでは、追加の頂点を選択することはできません($y = 0$)、したがって、Bessie が選択した頂点のみを操作する必要があります。 

入力には複数のテスト ケースがリストされます。 テストケースごとに、次のものが与えられます。$n$- 頂点の総数、$x$- Bessie が選択した頂点の数、および$x$頂点インデックス。 各テスト ケースについて、選択した頂点のみを使用して形成できる三角形の最大数を出力します。 

この制約により、単純な三角測量アルゴリズムは大規模なシステムでは実用的ではなくなります。$n$。 頂点の総数$n$まで行くことができます$10^9$、ただし選択された頂点の数$x$はるかに小さく、最大で$2 \cdot 10^5$すべてのテストケースにわたって。 これは、選択した頂点のみに計算を集中する必要があり、ポリゴンの合計サイズは循環順序の処理を除いてほとんど無視できることを示しています。 

選択した頂点がまばらであるかグループ化されている場合、明白ではないエッジ ケースが発生します。 たとえば、次の場合$n=8$そしてベッシーは頂点を選択します$1$そして$3$、選択した頂点を周期的に接続するエッジに沿って可能な最小限の三角形以外に三角形を形成する方法はありません。 すべての頂点を順番に三角形化しようとする単純なアプローチでは、頂点が選択されていないか、三角形の数え間違いが原因で失敗します。 

## アプローチ

 ブルートフォースアプローチは、選択した頂点間の可能なすべての対角線を列挙し、可能なすべての非交差セットを試みることです。 これは原理的には正しいですが、まったく実行不可能です。$x$頂点、対角線の数は$O(x^2)$、対角線のすべての組み合わせをテストすると、指数関数的に増加します。 これが不可能になるのは、$x$それは数千でさえ、まったく不合理です$x = 2 \cdot 10^5$。 

重要な洞察は、選択した頂点の相対的な位置のみが重要であるということです。 選択した頂点を時計回りの順序でリストし、それらを多角形を形成するものとして扱う場合、それらの頂点間で描画できる交差しない三角形の最大数は、それらの頂点によって形成される凸多角形内の三角形の最大数に等しくなります。 凸多角形$k$頂点を正確に三角形化することができます$k-2$三角形。 これは最適な数です。$k$頂点はそれ以上のものを生成できません$k-2$重ならない三角形。 

したがって、最適なアプローチは、選択した頂点の数をカウントすることです。$x$各テストケースと出力について$x-2$、三角形の最大数を表します。 頂点の数は十分であるため、頂点を並べ替えたり、明示的に対角線を作成したりする必要はありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^x) | O(x^2) | 遅すぎる |
 | 最適 | テスト ケースごとに O(1) | 入力の場合は O(x) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$、$x$、$y$。 このバージョンでは、$y=0$したがって、アルゴリズムには影響しません。 
3. を読んでください。$x$選択された頂点インデックス。 これらは別個のものですが、その正確な値は無関係です。 彼らの数だけ$x$重要です。 
4. 三角形の最大数を次のように計算します。$x-2$。 これは、凸多角形が$k$頂点は正確に分割できます$k-2$重なり合わない三角形。 
5. 結果を出力します。 

これが機能する理由: 不変条件は、どの頂点が選択されても、それらの中で交差しない三角形の最大数は、常に選択した頂点の数から 2 を引いたものになるということです。 この特性は、選択した頂点を接続する対角線を追加すると、多角形がより小さな凸形状に細分化され、凸多角形の三角形分割が次のように行われるため当てはまります。$k$頂点は正確に生成します$k-2$三角形。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, x, y = map(int, input().split())
    chosen_vertices = list(map(int, input().split()))
    print(x - 2)
```このコードは、高速入力を使用して複数のテスト ケースを効率的に読み取ります。 頂点を解析しますが、アルゴリズムはカウントのみに依存するため、頂点を個別に使用しません。$x$。 式$x-2$正しい三角形の数を直接与えます。 微妙な点は、$x \ge 2$なぜなら$x-2$負でない値である必要があります。 制約は保証します$x \ge 2$。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    t = int(input())
    res = []
    for _ in range(t):
        n, x, y = map(int, input().split())
        chosen_vertices = list(map(int, input().split()))
        res.append(str(x - 2))
    return "\n".join(res)
