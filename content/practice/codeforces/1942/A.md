 ## 解決策
 ## 問題の理解

 長さの配列を構築する必要があります`n`まさにそのようなこと`k`巡回シフトは非降順でソートされます。 

巡回シフトは、配列の新しい開始点としてある位置を選択し、残りの要素をラップします。 たとえば、`[1, 2, 3]`は`[1, 2, 3]`、`[2, 3, 1]`、 そして`[3, 1, 2]`。 

テストケースごとに、次のものが与えられます。`n`そして`k`。 ソートされた巡回シフトの数が正確に一致する有効な配列を出力する必要があります。`k`、または出力`-1`そのような配列が存在しない場合。 

制約は非常に小さいです。 すべての合計`n`値は最大でも`1000`したがって、配列のすべてのシフトをチェックするだけでもコストがかかりません。 課題は効率ではなく、必要な数のソートされたシフトを正確に生成する構造を発見することです。 

主な困難は、ソートされた循環シフトがどのように動作するかを理解することにあります。 単純な試みでは、カウントが最大になるまで個々の値を調整しようとする可能性があります。`k`、しかし、循環シフトの構造は、見た目よりもはるかに厳格です。 

重要なエッジケースの 1 つは、`k = n`。 

例えば：```
n = 4, k = 4
```配列`[1, 1, 1, 1]`すべての巡回シフトが同一であり、したがってソートされているため、機能します。 

もう 1 つの重要なエッジケースは、`1 < k < n`。 

例えば：```
n = 3, k = 2
```有効な配列が存在しません。 不注意なアプローチでは、直接構築しようとする可能性がありますが、循環シフトの基本的な特性により、これは不可能になります。 

最後のエッジケースは、`k = 1`。 

例えば：```
n = 5, k = 1
```有効な答えが存在します。 ソートされた回転が 1 つだけ含まれる配列が必要です。 この構築では、追加の並べ替えられたシフトが誤って作成されることを避ける必要があります。 

## アプローチ

 ブルートフォースの観点は、パターンを発見するのに役立ちます。 

いくつかの候補配列を生成するとします。 すべてをチェックすることで、ソートされた循環シフトをカウントできます。`n`回転ごとに、その要素が減少していないかどうかを検証します。 これには必要です`O(n^2)`候補配列ごとに動作します。 

問題は、ブルートフォースでは、ソートされたシフトの必要な数を正確に含む配列を構築する方法がわからないことです。 探索空間は膨大です。 

重要な観察は、循環シフトがいつソートされるかを研究することから得られます。 

完全に定数ではない配列を考えてみましょう。 ローテーションがソートされている場合、そのソートされたローテーションでは、シーケンスが最大値から最小値に戻る場所が 1 か所だけ存在します。 そのラップポイントは、ソートされた回転の開始位置を一意に決定します。 

その結果、非定数配列にはソートされた巡回シフトが最大 1 つだけ含まれる可能性があります。 

例えば：```
[2, 3, 4, 1]
```から始まる回転のみ`1`並べ替えられています:```
[1, 2, 3, 4]
```他のすべての回転には減少が含まれます。 

複数のソートされた回転を取得する唯一の方法は、すべての要素を等しくすることです。 その場合、すべての回転は同一であるため、すべての回転が同じになります。`n`ローテーションがソートされます。 

これにより、考えられるすべての答えがすぐに特徴づけられます。 

もし`k = n`、すべての値が等しい配列を出力します。 

もし`k = 1`、ソートされた回転が 1 つだけ含まれる非定数配列を出力します。 

もし`1 < k < n`、答えは不可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 候補者あたり O(n²) | O(n) | 建設ではありません |
 | 最適 | O(n) | O(1) おまけ | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`n`そして`k`。 
2. もし`k = n`、出力`n`等しい数。 

すべての循環シフトは同一であるため、すべて`n`シフトが並び替えられます。 
3. もし`k = 1`、出力:```
1 2 3 ... n
```この配列は厳密に増加しているため、元の形式はソートされています。 
4. 1 つおきの循環シフトが最初の要素の後のどこかで始まり、次の要素にラップアラウンドすることを観察します。`1`最後に。 

大きい値が小さい値の前に表示されるため、これらのシフトを並べ替えることはできません。 
5. もし`1 < k < n`、出力`-1`。 

非定数配列には複数のソートされた回転を含めることはできませんが、定数配列には正確にソートされた回転を含めることができます。`n`。 

### なぜ効果があるのか

 ソートされた巡回シフトの可能なカウントは 2 つだけです。 

すべての要素が等しい場合、すべての回転は同一であり、`n`ローテーションがソートされます。 

それ以外の場合は、ソートされたローテーションを検討してください。 循環配列には、シーケンスが大きい値から小さい値に折り返される固有の場所が必要です。 その位置の直後から開始すると、唯一可能なソートされた回転が生成されます。 したがって、非定数配列には、ソートされた巡回シフトを最大 1 つだけ含めることができます。 

これは、達成可能な値を意味します。`k`まさに`1`そして`n`。 この構造は、それらの場合には有効な配列を出力し、その他の場合には不可能であることを正確に報告します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, k = map(int, input().split())

    if k == n:
        print(*([1] * n))
    elif k == 1:
        print(*range(1, n + 1))
    else:
        print(-1)
```最初の分岐は、すべての巡回シフトをソートする必要があるケースを処理します。 すべての要素を等しくすると、すべての回転が同一になることが保証されます。 

2 番目のブランチは、ソートされたシフトが 1 つだけ必要な場合を処理します。 厳密に増加する配列には、すでに 1 つのソートされた回転、つまりそれ自体が含まれています。 その他の回転では、ラップアラウンドして、大きい数値が小さい数値の前に配置されます。 

最後の分岐は、残りのすべての値をカバーします。`k`。 上記の証明は、どの配列もそのようなカウントを実現できないことを示しています。 

数学的特徴付けによって答えが完全に決まるため、実装は短くなります。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n, k = map(int, input().split())

        if k == n:
            ans.append(" ".join(["1"] * n))
        elif k == 1:
            ans.append(" ".join(map(str, range(1, n + 1))))
        else:
            ans.append("-1")

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue().strip()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return out

# provided sample
assert run("3\n2 2\n3 1\n3 2\n") == "1 1\n1 2 3\n-1"

# minimum size
assert run("1\n1 1\n") == "1"

# impossible middle value
assert run("1\n5 3\n") == "-1"

# all rotations sorted
assert run("1\n4 4\n") == "1 1 1 1"

# exactly one sorted rotation
assert run("1\n5 1\n") == "1 2 3 4 5"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1 1`|`1`| 可能な最小のインスタンス |
 |`5 3`|`-1`| あり得ないケース`1 < k < n`|
 |`4 4`|`1 1 1 1`| すべての回転をソートする必要があります。 
|`5 1`|`1 2 3 4 5`| ソートされたローテーションを 1 つだけ |
