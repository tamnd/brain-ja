 ## 解決策
 ## 問題の理解

 デッキには4種類のカードが入っています。 ドロー 0 カードは手札からプレイ可能なカードを 1 枚消費し、何も返しません。 1 ドローのカードがそれ自体と置き換わります。 ドロー 2 カードはカードを 1 枚消費し、新しいカードを 2 枚与えるため、将来のドローパワーが 1 増加します。 特別なカードも 5 枚あり、行き詰まる前にすべてを引くことが目標です。 

最初に、ベッシーは上位 5 枚のカードを引きます。 その後、彼女は現在手札にあるドローカードを繰り返しプレイすることができます。 カードは 1 回しかプレイできません。 ある時点でプレイ可能なドローカードがなくなった場合、プロセスは終了します。 

ドロー 0、ドロー 1、ドロー 2 のカードのカウントが与えられます。 デッキは均一にランダムにシャッフルされます。 最終的に 5 枚の特別なカードがすべて引き出される確率を計算し、その確率の剰余を出力する必要があります。`998244353`。 

制約が十分に大きいため、状態空間シミュレーションは不可能です。 それぞれの`a`、`b`、 そして`c`到達できる`2 · 10^5`、まであるかもしれません`10^4`テストケース。 デッキの順列の数に比例する複雑さのアルゴリズムは明らかに不可能ですが、二次 DP さえも超えます。`a`そして`c`限界を超えてしまうだろう。 全部の合計なので、`a`、`b`、 そして`c`テストケース全体でそれぞれ最大`2 · 10^5`、`O(a + c)`テストケースごとのソリューションは実現可能です。 

見落としやすいケースがいくつかあります。 

考慮する`a = b = c = 0`。 デッキには5枚のスペシャルカードのみが含まれています。 ベッシーは開始時にすぐに 5 枚すべてのカードを引くので、答えは正確に次のようになります。`1`。 

考慮する`a = 1, b = 0, c = 0`。 デッキには 1 枚のドロー 0 カードと 5 枚のスペシャル カードが含まれています。 ベッシーは最初の 5 枚のカードを引き、追加のカードを獲得することはできません。 最初の 5 つの位置にドロー 0 のカードが出現し、特別なカードを 6 番目の位置に押し込まない限り、彼女は勝ちます。確率は一定ではありません。`1`、特別ではないカードが 1 枚しかないにもかかわらず。 

もう 1 つの微妙な点は、ドロー 1 カードによってベッシーがアクセスできる今後のカードの数が変わらないことです。 不注意な解決策では、それらを DP 状態に含めようとする可能性があり、必要以上に大きな問題が発生します。 実際には、それらは停止条件とはまったく無関係です。 

## アプローチ

 ブルートフォースソリューションでは、すべてのデッキの順序を列挙し、ゲームをシミュレートし、勝利につながるシャッフルの数をカウントします。 

シミュレーション自体は簡単です。 現在の手札を維持し、利用可能なドロー カードを繰り返しプレイし、カードがなくなったら停止します。 5 枚の特別なカードがすべて見えた場合、シャッフルは成功です。 

問題はシャッフルの回数です。 デッキサイズは約`6 · 10^5`テストケース全体の合計。 たとえ小さな入力であっても、順列の数は階乗的に増加します。 このアプローチはすぐに不可能になります。 

重要な観察は、ドロー 1 カードはリソース バランスにまったく寄与しないということです。 プレイするとカードを 1 枚消費し、カードを 1 枚だけ引きます。 彼らは決して助けたり傷つけたりすることはありません。 

次にバランスを定義します。 

- バランスから始めましょう`5`, 最初の5枚のカードは無料で引けるので。 
- ドロー 2 カードが貢献します`+1`。 
- ドロー 0 カードが貢献する`-1`。 
- スペシャルカードも貢献`-1`, 描かれたスロットを 1 つ占有しますが、プレイできないためです。 

ベッシーが上から下にカードを公開すると、残高から、あと何枚のカードを公開できるかがわかります。 

プロセスは、残高がゼロになる最初のプレフィックスで正確に停止します。`0`。 

これにより、ゲームは格子パス問題に変わります。 

ドロー 1 カードは完全に無視します。 残りのカードの中には、

 - ドロー-2 になります`+1`- ドロー-0 になります`-1`-特別になります`-1`高所からスタートします`5`。 

勝利デッキとは、残高が最初に達する前に 5 枚のスペシャル カードがすべて出現するデッキです。`0`。 

最初のヒットがあったとします。`0`正確に使用した後に発生します`p`カードを2枚引く。 この場合、停止プレフィックスには次のものが含まれている必要があります。 

-`p`カードを2枚引く
 -`p + 5`ネガティブカード

 5つのスペシャルをすべてご覧になっている必要があるので、`p + 5`ネガは次のもので構成されます。 

- 5 つのスペシャルすべて
 - まさに`p`ドロー0カード

 デッキの残りの部分は任意です。 

残りのタスクは投票経路の集計になります。 シーケンスの数が必要です`p`アップステップと`p + 5`高さから始まるダウンステップ`5`そして殴る`0`初めてプレフィックスの最後に。 

古典的なベルトラン投票/反射原理の結果は次のようになります。$$F_p = \frac{5}{2p+5}\binom{2p+5}{p}.$$このような道を選択した後、次のいずれかを選択します。`p+5`負の位置には 5 つのスペシャルが含まれ、残りのサフィックスを配置します。 

これは直接合計につながります`p`。

 ## アルゴリズムのチュートリアル

 1. ドロー 1 カードをすべて無視します。 

彼らは決してバランスを変えることはありません。 それらを削除すると、到達可能性に影響するすべてのカードの相対的な順序が保持されます。 
2.初めて残高に達したら`0`正確に使う`p`カードを2枚引く。 

バランスからスタートするので`5`、到達`0`の正味変更が必要です`-5`。 したがって、停止プレフィックスには正確に次のものが含まれます`p+5`ネガティブなカード。 
3. 停止する前に、5 枚の特別カードをすべて強制的に表示させます。 

その中で、`p+5`停止プレフィックスの負の位置で、どの 5 つにスペシャルが含まれるかを選択します。 

カウントは$$\binom{p+5}{5}.$$4. 有効なバランス パスをカウントします。 

停止プレフィックスには次のものが含まれます`p`前向きな一歩と`p+5`ネガティブなステップ。 

残高は最後のステップまでプラスのままでなければなりません。 

投票定理により、$$F_p=\frac{5}{2p+5}\binom{2p+5}{p}.$$5. 残りのカードを並べます。 

停止プレフィックスが修正された後、サフィックスには次のものが含まれます。 

-`a-p`ドロー0カード
 -`c-p`カードを2枚引く

 サフィックスの配置数は$$\binom{a+c-2p}{a-p}.$$6. すべての実現可能な値を合計します。`p`。 

必要なので`p`ドロー0カードと`p`ドロー - 停止プレフィックス内にカードを 2 枚、$$0 \le p \le \min(a,c).$$7. ゼロ以外のカード シーケンスの総数で割ります。 

ドロー 1 カードを無視すると、シーケンスの総数は次のようになります。$$\frac{(a+c+5)!}{a!\,c!\,5!}.$$8. 式を単純化し、それを剰余として評価します。`998244353`。 

### なぜ効果があるのか

 すべてのゲーム状態はバランスによって完全に決定されます。 ドロー 2 は将来の到達可能性を 1 増加させますが、ドロー 0 とスペシャル カードの両方はそれを 1 減少させます。 ゲームは、残高がゼロになる最初のプレフィックスで正確に終了します。 

固定停止点の場合、停止プレフィックスには、5 枚の特別なカードによって生じる 5 枚の余分な不足分を除き、同数のドロー 0 カードとドロー 2 カードが含まれていなければなりません。 投票定理では、残高が以前にゼロに達しないプレフィックスを正確にカウントします。 ネガティブ ステップの中でスペシャル カードの位置を選択すると、停止する前にすべてのスペシャルが確実に引き出されます。 すべての勝利デッキは、次の 1 つの値に正確に対応します。`p`、そしてカウントされたすべての構成が有効な勝利デッキを生成します。 したがって、合計ではすべての勝利デッキが 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

MAXN = 400005

fac = [1] * (MAXN + 1)
for i in range(1, MAXN + 1):
    fac[i] = fac[i - 1] * i % MOD

invfac = [1] * (MAXN + 1)
invfac[MAXN] = pow(fac[MAXN], MOD - 2, MOD)
for i in range(MAXN, 0, -1):
    invfac[i - 1] = invfac[i] * i % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fac[n] * invfac[r] % MOD * invfac[n - r] % MOD

def solve():
    t = int(input())

    for _ in range(t):
        a, b, c = map(int, input().split())

        total_inv = pow(
            fac[a + c + 5] * invfac[a] % MOD * invfac[c] % MOD * fac[5] % MOD,
            MOD - 2,
            MOD
        )

        good = 0

        for p in range(min(a, c) + 1):
            ballot = 5 * pow(2 * p + 5, MOD - 2, MOD) % MOD
            ballot = ballot * C(2 * p + 5, p) % MOD

            specials = C(p + 5, 5)
            suffix = C(a + c - 2 * p, a - p)

            good = (good + ballot * specials % MOD * suffix) % MOD

        ans = good * total_inv % MOD
        print(ans)

solve()
```実装はカウント引数の後に直接続きます。 

階乗テーブルは定数時間の二項係数をサポートします。 以来`a + c + 5`決して超えない`400005`1 つのグローバル事前計算で十分です。 

変数`ballot`店舗$$\frac{5}{2p+5}\binom{2p+5}{p},$$計算されたモジュロ`MOD`。 除算は逆モジュラーで実行されます。`specials`どのマイナスの位置が特別なカードに対応するかを選択します。`suffix`停止プレフィックスの後に残ったカードを配置します。 

数量`good`勝利した非ゼロカードシーケンスをカウントします。 非ゼロのカード シーケンスの総数は次のとおりです。$$\frac{(a+c+5)!}{a!\,c!\,5!},$$したがって、最後にその逆モジュラーを乗算します。 

よくある間違いは、ドロー 1 のカードをカウンティングに残そうとすることです。 これらは残高に影響を与えることはありません。そのため、これを行うと組み合わせが複雑になるだけであり、通常は数えすぎにつながります。

        if r < 0 or r > n:
