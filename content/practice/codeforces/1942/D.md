 ## 解決策
 ## 問題の理解

 私たちは、エルシーが 1D キャンバスに描いた絵を評価するのを手伝ってほしいと頼まれました。`n`細胞。 各セルはペイントすることも空のままにすることもでき、ペイントの美しさは 2D 配列によって決まります。`a`。 具体的には、ペイントされたセルの最大の連続ブロックごとに、`[l,r]`、美容への貢献は`a[l][r]`、全体的な美しさは、そのようなブロックすべての合計です。 目標は、`k`すべての中で可能な限り最大の美しさの値`2^n`可能な絵。 

入力は複数のテスト ケースで構成されます。 それぞれについて、`n`最大 1000 まで可能であり、`k`最大 5000 です。`a[i][j]`負の値を指定すると、特定の間隔がペイントされた場合に美しさの値が減少します。 以来`2^n`指数関数的に増加するため、すべての絵画を単純に列挙することは不可能です。 のために`n = 20`、`2^20`すでに100万を超えています。 したがって、直接的な総当たりアプローチは、大規模な場合には不可能です。`n`。 

エッジ ケースは、すべてのセルが負またはゼロの場合に発生します。 たとえば、次の場合`n = 1`そして`a[1][1] = -5`、ペイントが 2 つあります: セルをペイントすると結果が得られます。`-5`空のままにすると、次の結果が得られます`0`。 ペイントされた間隔のみを考慮する単純なアプローチでは、空のペイント シナリオが誤って無視される可能性があります。 

もう 1 つの微妙な点は、間隔が重なることです。 最大の連続間隔のみが問題となるため、寄与分を二重にカウントすることはできません。 たとえば、絵を描くこと`[1,2,3]`3 つの別々の単一セルが得られるため、`a[1,1] + a[2,2] + a[3,3]`、絵を描きながら`[1,2,3]`1 つのブロックが生成するため`a[1,3]`。 最大の美しさを見つけるには、間隔を組み合わせるか、間隔を離すかを選択することが重要です。 

## アプローチ

 ブルートフォースアプローチは簡単です。すべてを生成します。`2^n`セルのサブセット、それぞれの最大の連続ブロックを計算し、それらの合計を計算します。`a[l][r]`値を設定し、結果を収集します。 これは正しいですが、非現実的です。`n = 1000`、操作数`2^1000`天文学的に大きいです。 

実行可能な解決策に関する重要な観察は、問題が一定の間隔で動的プログラミングを使用して解決できるということです。 させて`dp[l][r]`その区間で得られる最大の美しさを表現します`[l,r]`。 美しさは最大限にペイントされたブロックに対して加算されるため、間隔ごとに`[l,r]`ブロック全体をペイントすることも、左右の要素を組み合わせて中間点で分割することもできます。 

すべてを計算する代わりに`2^n`明示的にペイントを行うと、間隔ごとに次のことを維持できます。`k`可能な限り最大の美しさ。 これにより、左右の間隔を効率的にマージできます。 2 つのソートされた美しさのリスト (左と右の部分間隔から) を結合する場合、必要なのは上部のみです。`k`合計。最小ヒープのサイズを使用して計算できます。`k`。 これにより、指数関数的な複雑さが管理可能な多項式に軽減されます。`n^2 * k * log k`操作は実行可能です`n`1000までと`k`5000まで。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n) | O(2^n) | 遅すぎる |
 | インターバルの DP + Top-k マージ | O(n^2 * k * log k) | O(n^2 * k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力の読み取り`n`そして`k`、配列を保存します`a`完全に`n x n`マトリックス形式。 入力は上三角のみを提供するため、必要に応じて下三角を入力します（ただし、必要なのは`i <= j`エントリ）。 
2. DP テーブルの初期化`dp[l][r]`すべての間隔で`[l,r]`。 それぞれ`dp[l][r]`上位のソートされたリストを保存します`k`その間に達成できる美しさ。 最初に、各単一セル間隔を設定します`dp[i][i] = [0, a[i][i]]`なぜなら、ペイントすることも空のままにすることもできるからです。 
3. 2 から 2 までの間隔の長さにわたって反復します。`n`。 インターバルごとに`[l,r]`、考えられるすべての分割点を考慮します`m`どこ`l <= m < r`。 上部を結合します`k`からの美しさ`dp[l][m]`そして`dp[m+1][r]`。 また、間隔全体を 1 つのブロックとしてペイントすることも検討してください。`a[l][r]`。 上部だけを残しておく`k`合併後の美しさ。 
4.充填後`dp[1][n]`、上部を出力します`k`に保存されている美しさ`dp[1][n]`降順で。 
5. すべてのテスト ケースに対して繰り返します。 

なぜ効果があるのか​​: 各ステップで、`dp[l][r]`上部が含まれています`k`インターバルの美しさ`[l,r]`。 分割と単一ブロック オプションの両方を考慮することで、すべてを列挙することなく、すべての構成が確実に考慮されるようになります。`2^n`絵画。 最小ヒープにより、最上位のみが保持されることが保証されます`k`、問題の要件と一致します。 

## Python ソリューション```python
import sys, heapq
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = [[0]*n for _ in range(n)]
        for i in range(n):
            row = list(map(int, input().split()))
            for j in range(len(row)):
                a[i][i+j] = row[j]

        dp = [[[] for _ in range(n)] for _ in range(n)]

        for i in range(n):
            dp[i][i] = [0, a[i][i]] if a[i][i] != 0 else [0]

        for length in range(2, n+1):
            for l in range(n-length+1):
                r = l+length-1
                candidates = [a[l][r]]
                for m in range(l, r):
                    for x in dp[l][m]:
                        for y in dp[m+1][r]:
                            candidates.append(x+y)
                dp[l][r] = heapq.nlargest(k, candidates)

        print(" ".join(map(str, dp[0][n-1][:k])))

if __name__ == "__main__":
    solve()
```このコードは、上三角入力の読み取りを慎重に処理し、間隔の長さによって DP テーブルを繰り返し埋め、サブ間隔の美しさをマージします。 の`heapq.nlargest`効率的にトップを維持できるようにする`k`メモリの爆発を防ぎます。 単一セル間隔では、セルを空のままにし、寄与がゼロであると正しく考慮されます。
