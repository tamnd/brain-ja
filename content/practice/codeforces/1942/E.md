 ## 問題の理解

 2 人の農家の牛がライン上に交互に表示されなければなりません。 最初の牛の順序を選択すると、順序全体が固定されます。 

どちらか`J N J N ... J N`または`N J N J ... N J`。 

実際の位置は固定されていません。 牛の間や壁の近くに空の独房がある場合があります。 

移動は、1 つの農家の牛の一部を選択し、すべての牛を同じ方向に 1 歩移動します。 移動は、牛が壁にぶつからず、占領された位置に着地しない場合にのみ合法です。 

各農家のラインの長さと牛の頭数が与えられます。 すべての有効な配置の中で、最適なプレイとジョンが最初に動くと仮定して、ファーマー ジョンが勝っているのはいくつあるかを数えなければなりません。 

制約は、解決策が組み合わせでなければならないことを示す主な手がかりです。 ラインの長さは到達可能です$10^6$ただし、テスト ファイル全体の長さの合計も最大です。$10^6$。 これにより、個々のゲームの状態を分析する試みは即座に排除されます。 有効な配置の数は指数関数的に増加するため、すべての構成を保存することさえ不可能になります。 

唯一実行可能な方向性は、勝ちポジションと負けポジションの簡単な特徴を見つけて、それを組み合わせ論でカウントすることです。 

いくつかの特殊なケースは見落とされがちです。 

たとえば:

2 1
```有効な構成は次のとおりです。```
JN
NJ
```どちらの構成でも牛は動けないため、ジョンはすぐに負けます。 正しい答えは次のとおりです。```
0
```「ボードがいっぱいでない限り、最初のプレイヤーが勝つ」と仮定する単純なアプローチは失敗します。 

もう 1 つの重要なケースは次のとおりです。

```ジョンが勝ったのは最後の 2 つだけです。 正しい答えは次のとおりです。```

```空のセルが存在するだけでは十分ではありません。 それらの配置は重要です。 

最後の微妙な点は、ゲームの説明では距離を伸ばす移動が許可されているため、一見すると無限のプレイが可能であるように見えます。 ゲーム理論の重要な観察は、最適なプレイは特定のギャップの同等性によって完全に決定されるということです。 その構造が発見されると、カウントが管理可能になります。 

## アプローチ

 ブルート フォース ソリューションでは、すべての有効な構成が生成され、ゲーム グラフが構築され、初期状態が勝利しているかどうかが判断されます。 

固定の交互順序の場合、構成は基本的に次の配置になります。$2n$中の牛$l$ポジション。 がある$$\binom{l}{2n}$$このような配置には、2 つの交互の順序が考えられます。 中程度の値であっても、この数は膨大です。 

たとえば、次のようなとき$l=60$そして$n=20$、$$\binom{60}{40}$$すでに数え切れないほどのものです。 

ゲームは有限状態であるため、総当たりアプローチは概念的には機能しますが、実際の制約に達するずっと前に役に立たなくなります。 

画期的な発見は、つがいの牛の間の隙間に注目することから始まります。 

シーケンスがジョンの牛から始まると仮定します。$$a_1 < b_1 < a_2 < b_2 < \cdots < a_n < b_n.$$定義する$$g_i = b_i - a_i - 1.$$それで$g_i$間の空のセルの数です。$i$-th John 牛と対応する Nhoj 牛。 

これらのギャップがゲームを完全に捉えます。 

移動により、ゼロ以外のギャップが正確に変更されます$+1$または$-1$。 重要な事実は、ギャップの同等性が勝者を決定するということです。 

ポジションが負けているのは、次の場合に限ります。$g_i$は均等です。 

少なくとも 1 つのギャップが奇数である場合、ジョンはすべてのギャップが偶数になる状態に移行できます。 すべてのギャップがすでに均等である場合、法的な動きをするたびに奇数のギャップが生じます。 

ゲームがこの同等基準に達したら、残りは純粋にカウントするだけです。 

すべての有効な構成をカウントし、ギャップがすべて均等である構成を減算します。

 ## アルゴリズムのチュートリアル

 ### 1. 交互の順序を 1 つ修正します

 シーケンスがジョンの牛から始まると仮定します。$$a_1 < b_1 < a_2 < b_2 < \cdots < a_n < b_n.$$逆の順序はまったく同じ数の構成に寄与するため、1 つの順序を数えて、最後に 2 を掛けることができます。 

### 2. 重要なギャップを定義する

 各ペアごとに、$$g_i = b_i - a_i - 1.$$これらはゲームを左右するギャップです。 

残りの空のセグメントも定義します。$$x_0=a_1-1,$$

$$x_i=a_{i+1}-b_i-1 \quad (1\le i<n),$$

$$x_n=l-b_n.$$全て$x_i$そして$g_i$は非負です。 

牛自身が占有しているので、$2n$細胞、$$\sum x_i + \sum g_i = l-2n.$$させて$$m=l-2n.$$### 3. 負けているポジションの特徴を明らかにする

 構成が失われるのは、次の場合です。$g_i$は均等です。 

書く$$g_i=2h_i.$$それから$$\sum x_i + 2\sum h_i = m.$$### 4. 失われた構成を数える

 しましょう$$s=\sum h_i.$$それから$$\sum x_i = m-2s.$$の$h_i$は非負であり、$n$彼らのうち。 

星とバーによって、$$\#(h_1,\dots,h_n) = \binom{s+n-1}{n-1}.$$の$x_i$は非負であり、$n+1$彼らのうち。 

再び星と棒によって、$$\#(x_0,\dots,x_n) = \binom{m-2s+n}{n}.$$固定の場合$s$したがって、失われた構成の数は次のようになります。$$\binom{s+n-1}{n-1} \binom{m-2s+n}{n}.$$考えられるすべてのことを合計すると$s$、$$L = \sum_{s=0}^{\lfloor m/2\rfloor} \binom{s+n-1}{n-1} \binom{m-2s+n}{n}.$$### 5. すべての構成を数える

 1回のご注文につき交互に配布いたします$m$間の空のセル$$(n+1)+n = 2n+1$$非負の変数。 

星とバーが与えるもの$$\binom{m+2n}{2n} = \binom{l}{2n}.$$### 6. 答えを計算する

 1回のご注文につき、$$\text{winning} = \binom{l}{2n}-L.$$2 つの対称的な交互の順序があるため、$$\text{answer} = 2\left(\binom{l}{2n}-L\right).$$すべての算術はモジュロで実行されます$998244353$。 

### なぜ効果があるのか

 ゲーム全体をギャップベクトルで表現可能$(g_1,\dots,g_n)$。 

移動すると、選択した正のギャップが 1 単位ずつ変更されるため、変更されたギャップごとにパリティが反転されます。 

すべてのギャップが偶数である場合、すべての合法的な動きにより、少なくとも 1 つの奇数のギャップが作成されます。 このようなポジションは、別のオールイーブンのポジションに移動することはできません。 

一部のギャップが奇数の場合、すべての奇数ギャップは正になります。 すべての奇数ギャップを 1 ずつ減らすことは正当であり、すべてのギャップが偶数になる状態が生成されます。 

したがって、すべての非偶数ポジションはすべて偶数ポジションへの移動を持ち、すべてのすべて偶数ポジションは非偶数ポジションへのみ移動します。 これは、負けポジションと勝ちポジションの定義と正確に一致します。 

すべての有効な配置が変数に一意に対応するため、カウント部分は正しいです。$x_i$そして$g_i$、および星と棒は、結果として得られる方程式の非負の解をすべてカウントします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

MAXL = 10**6 + 5

fact = [1] * MAXL
for i in range(1, MAXL):
    fact[i] = fact[i - 1] * i % MOD

inv_fact = [1] * MAXL
inv_fact[-1] = pow(fact[-1], MOD - 2, MOD)

for i in range(MAXL - 1, 0, -1):
    inv_fact[i - 1] = inv_fact[i] * i % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

t = int(input())

for _ in range(t):
    l, n = map(int, input().split())

    m = l - 2 * n

    losing = 0

    for s in range(m // 2 + 1):
        ways_h = C(s + n - 1, n - 1)
        ways_x = C(m - 2 * s + n, n)
        losing = (losing + ways_h * ways_x) % MOD

    total_one_order = C(l, 2 * n)

    ans = (total_one_order - losing) % MOD
    ans = (2 * ans) % MOD

    print(ans)
```階乗配列と逆階乗配列は、最大で 1 回事前計算されます。$10^6$、問題で必要なすべての二項係数をカバーします。 

機能`C(n, r)`組み合わせを一定時間で評価します。 

テストケースの場合は、`m = l - 2n`空のセルの数です。 ループオーバー`s`負けポジションの公式を直接実装します。$$\sum \binom{s+n-1}{n-1} \binom{m-2s+n}{n}.$$最初の組み合わせはハーフギャップの分布をカウントします。$h_i$。 2 番目は、残りの空のセルの分布をカウントします。$x_i$。 

答えは、1 つの交互オーダーのすべての構成から損失構成を減算し、2 人の可能な開始ファーマーについて 2 を乗算することによって得られます。 

最も一般的な実装上の間違いは、次のものがあることを忘れることです。$n+1$変数$x_i$、 ない$n$。 間違った星と棒の公式を使用すると、すべてのカウントが 1 ずつずれてしまい、小規模なテストであっても不正確な答えが生成されます。 

もう 1 つの簡単な間違いは、最後の 2 の乗算を忘れることです。 上記のカウントは、シーケンスがジョンの牛から始まることを前提としています。 逆の交互の順序は同額を寄与するため、含める必要があります。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

MOD = 998244353

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())

    tests = []
    max_l = 0

    for _ in range(t):
        l, n = map(int, input().split())
        tests.append((l, n))
        max_l = max(max_l, l)

    fact = [1] * (max_l + 5)
    for i in range(1, max_l + 5):
        fact[i] = fact[i - 1] * i % MOD

    inv_fact = [1] * (max_l + 5)
    inv_fact[-1] = pow(fact[-1], MOD - 2, MOD)

    for i in range(max_l + 4, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % MOD

    def C(n, r):
        if r < 0 or r > n:
            return 0
        return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

    out = []

    for l, n in tests:
        m = l - 2 * n

        losing = 0
        for s in range(m // 2 + 1):
            losing += C(s + n - 1, n - 1) * C(m - 2 * s + n, n)
            losing %= MOD

        ans = (C(l, 2 * n) - losing) % MOD
        ans = ans * 2 % MOD

        out.append(str(ans))

    return "\n".join(out) + "\n"

 ## 特殊なケース

 次のことを考慮してください。```
1
2 1
```我々は持っています$m=0$。 唯一可能なギャップ値は次のとおりです。$g_1=0$、これは偶数です。 アルゴリズムは以下を計算します。$$L=1, \qquad \binom{2}{2}=1.$$したがって、答えは次のようになります。$$2(1-1)=0.$$どちらのプレイヤーも移動できないため、これはゲーム自体と一致します。 

次に、次のことを考えてみましょう。```
1
4 2
```牛は 4 つのセルすべてを占有します。 また$m=0$したがって、すべてのギャップは強制的にゼロになり、したがって均等になります。 

アルゴリズムは、すべての構成を損失としてカウントします。$$L=\binom{4}{4}=1$$1つの交互の注文に対して。 

減算後、勝ちポジションの数はゼロになります。 これは、交互の順序だけが勝利のチャンスを生み出すと想定するというよくある間違いを捉えています。 

最後に、次のことを考慮してください。```
1
3 1
```ここ$m=1$。 唯一負けている州は、$g_1=0$。 任意の状態$g_1=1$妙な差をつけて勝っている。 

合計すると次のものが正しく生成されます。$$L=2,$$一方、構成の総数は$$2\binom{3}{2}=6.$$したがって：$$6-4=2$$サンプルと正確に一致する、優勝した構成が残ります。
