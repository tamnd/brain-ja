 ## 解決策
 ## 問題の理解

 厳密に凸多角形が与えられています$P$反時計回りの順序で頂点のリストとして平面内に表示されます。 各頂点は整数の座標を持ち、同一線上にある 3 つの頂点はありません。 から$P$、新しいポリゴンを定義します$T$すべてのベクトルの集合として$\overrightarrow{AB}$どこ$A$そして$B$の点です$P$。 幾何学的には、$T$のすべての平行移動によって形成される多角形です。$P$原点が含まれているもの。 タスクは、次のことを判断することです。$P$そして$T$幾何学的意味では似ています。スケーリングと回転までは同じ形状です。 

入力すると$n$、頂点の数、その後に続く$n$コーディネートペア。 次の場合、出力は「YES」になるはずです。$P$そして$T$類似している場合は「NO」、それ以外の場合は「NO」です。 

与えられた$n$到達できる$10^5$座標は最大まで上がります$10^9$、アルゴリズムは大まかに実行する必要があります$O(n)$または$O(n \log n)$時間。 すべての点のペアにわたるネストされたループを使用するアプローチ ($O(n^2)$）は直ちに除外されます。 

非常に小さなポリゴンや非常に非対称な形状では、微妙なエッジ ケースが発生します。 たとえば、頂点を持つ三角形$(0,0),(2,0),(1,3)$を生成します$T$それは辺の比率が異なる六角形です。 エッジまたは境界ボックスのみを調べる単純なアプローチでは、類似性を誤って主張する可能性があります。 正しくチェックするには、辺の長さだけでなく、点間の相対ベクトルも考慮する必要があります。 

## アプローチ

 強引な構築方法$T$すべての頂点のペアを反復処理することです$(A,B)$で$P$そしてベクトルを保存します$\overrightarrow{AB}$の頂点として$T$。 次に、結果のベクトルを反時計回りに並べ替えて、次と比較します。$P$類似性のために。 これは$O(n^2)$そしてすぐには実用的ではない$n=10^5$、それは周りで実行されるので、$10^{10}$操作。 

重要な洞察は次のとおりです$T$実際には次のミンコフスキー和です$P$そして$-P$(反射して得られる多角形$P$原点を通して）。 凸多角形のミンコフスキー和は、エッジの方向を保持し、2 倍の頂点を持つ多角形を作成します。 厳密に凸状の多角形の場合、既知の結果は次のとおりです。$P$そして$T$以下の場合にのみ類似することができます$P$中心対称です。 より具体的には、$T$の反対側のエッジの中点に頂点があります。$P$したがって、条件は、前半のすべてのエッジ ベクトルについてそれをチェックすることになります。$P$の場合、反対側の半分には平行で等しい長さのエッジ ベクトルが存在します。 

これは、次のエッジ ベクトルのシーケンスを比較することで問題を解決できることを意味します。$P$反対側のエッジを合計して形成されたシーケンスをすべて含めます$O(n)$時間。

 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. のエッジ ベクトルを計算します。$P$順番に。 頂点の場合$v_0, v_1, ..., v_{n-1}$、エッジベクトル$e_i = v_{i+1} - v_i$モジュロ$n$。 各ベクトルはエッジの方向と長さの両方をエンコードします。 
2. かどうかを確認します。$n$は均等です。 もし$n$奇妙です、$P$中心対称にはなり得ないので、$P$そして$T$似ているはずがない。 「いいえ」を出力します。 
3. 偶数の場合$n$、エッジを半分に分割します。 各エッジをペアリングする$e_i$と$e_{i + n/2}$。 次の場合、各ペアの合計はゼロ ベクトルでなければなりません。$P$中心対称です。 これは、ミンコフスキー和対称条件を直接エンコードします。 
4. 反復処理する$i$0から$n/2 - 1$。 もし$e_i + e_{i+n/2} \neq (0,0)$誰にとっても$i$、「NO」を出力します。 それ以外の場合は「YES」を出力します。 

**これが機能する理由:** 凸多角形の場合、$T = P + (-P)$。 2 つのポリゴンは、一方がもう一方のスケールおよび回転されたコピーである場合、類似しています。 凸用$P$、これは次の場合にのみ発生します。$P$中心対称であるため、$T$反射によって形状を効果的に 2 倍にします。 上記のようにエッジ ベクトルのペアをチェックすることで、明示的に構築することなく中心対称性を検証します。$T$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
vertices = [tuple(map(int, input().split())) for _ in range(n)]

if n % 2 == 1:
    print("NO")
    sys.exit(0)

edges = []
for i in range(n):
    x1, y1 = vertices[i]
    x2, y2 = vertices[(i+1)%n]
    edges.append((x2-x1, y2-y1))

half = n // 2
for i in range(half):
    ex, ey = edges[i]
    ex_op, ey_op = edges[i+half]
    if ex + ex_op != 0 or ey + ey_op != 0:
        print("NO")
        sys.exit(0)

print("YES")
```このソリューションはポリゴンの頂点を読み取り、奇数のサイズのポリゴンを即座に拒否します。 エッジ ベクトルはモジュロ順に計算されます$n$ラップアラウンドを処理します。 各エッジは反対側のエッジとペアになります。 いずれかのペア チェックに失敗すると、「NO」が返されます。 最後の「YES」は、すべてのペアが中心対称性を満たしている場合にのみ発生します。
