 ## 解決策
 ## 問題の理解

 最大 50 までの長さの正の整数の配列が与えられます。サブセット サイズごとに$k$2から$n$、均一にランダムに選択された、そのサイズのすべての部分列を調べます。 選択したサブシーケンスごとに$c$、その平均値を計算し、その平均よりも厳密に大きい要素がいくつあるかを測定します。 その割合は、サブシーケンスの「成功率」と呼ばれます。 タスクは、それぞれについて計算することです。$k$、サイズのすべての部分列にわたるこの成功率の期待値$k$。 

したがって、出力は一連の期待値であり、各期待値ごとに 1 つずつ出力されます。$k$、それぞれがすべてを引き継ぎます$\binom{n}{k}$サブセット。 

という点では制約は小さい$n$、指数関数的なものは即座に除外されます。$n$サブセットごとに追加係数を掛けます。 ただし、本当の困難は列挙ではなく、選択されたすべての要素を非線形方法で結合するサブセット平均への依存性です。 サブセットごとの平均を明示的に再計算するソリューションはすでに高価であり、追加の条件が必要です。$c_i > f(c)$各サブセット内でグローバル比較を導入します。 

すべての要素が等しい場合、微妙なエッジケースが発生します。 この場合、すべてのサブセットの平均値はすべての要素に等しいため、厳密に平均より大きい要素はなく、答えは常に 0 になります。厳密な不等式が平均値を中心に対称的に動作することを前提とする推論では、この退化ケースを維持する必要があります。そうしないと、誤ってゼロ以外の期待値が導入される可能性があります。 

もう 1 つのデリケートなケースは、分布が偏っている場合です。 たとえば、配列が次の場合、$[1, 1, 1, 100]$、100 を含むサブセットは平均を大きく上方に偏らせます。これにより、個々の値だけでなくサブセット全体の構成に応じて、どの要素が平均以上としてカウントされるかが変わります。 

## アプローチ

 直接的なアプローチは、サイズのすべてのサブセットを列挙することです。$k$、その平均を計算し、それを超える要素の数を数えます。 各サブセットの平均を計算すると、$O(k)$、平均を超える要素をカウントすることは別のことです$O(k)$。 繰り返します$\binom{n}{k}$サブセットの合計コストは次のとおりです。$\sum_k \binom{n}{k} k$となり、$O(n 2^n)$総計で。 と$n = 50$、これはまったく不可能です。 

主要な障害は、次の条件です。$c_i > \frac{1}{k}\sum c$はグローバル不等式です。要素がカウントされるかどうかは、選択されたサブセット全体の合計によって決まります。 これは、サブセットについての直接的な推論から、すべてのサブセットにわたる個々の要素の寄与についての推論への移行を示唆しています。 

中心的な観察は要素を修正することです$a_i$サイズのサブセットがいくつあるかを尋ねます$k$この要素は「平均以上」の数に影響しますか? 各要素について、その期待される寄与を計算できれば、期待の線形性により、寄与を合計し、適切に除算することができます。 固定要素がサブセット平均よりも大きい確率を分析することが困難になります。 

条件を書き換える$a_i > \frac{S}{k}$として$k a_i > S$、 どこ$S$は選択されたサブセットの合計です。 含めることを条件とするなら$a_i$、 残り$k-1$要素は他の要素のサブセットを形成します$n-1$要素。 次に、不等式は選択された値の合計に対する制約になります。$k-1$要素。 これにより、問題はサイズのサブセットをカウントすることに軽減されます。$k-1$その合計が次によって決定されるしきい値を下回っている$a_i$。 

これにより、問題は部分集合の合計に関するナップサック型の計数問題に変換されますが、$n \le 50$、値が小さいという事実を利用できます ($\le n$）。 これにより、サブセットのサイズと合計に対する擬似多項式動的プログラミングが可能になります。 

最終的な構造は次のようになります。$k$、すべてを集計することで、不等式を満たす要素の予想数を計算します。$i$、各寄与は、合計しきい値によって制限されるサブセット数の比率です。 サイズと合計によってサブセット数を事前計算すると、すべての答えが得られます。

 | 最適 |$O(n^3 \cdot \text{sum})$(または最適化された組み合わせ) |$O(n \cdot \text{sum})$| 承認済み |

 ## アルゴリズムのチュートリアル

 配列を次のように表します$a$、選択したサブセットの合計をキーの隠し変数とします。 

1. 二項係数を事前計算します$C[n][k]$。 これが必要なのは、すべての期待値が均一に選択されたサブセットの平均であるためです。 
2. 動的プログラミングテーブルを構築します$dp[t][s][c]$、選択する方法の数として解釈されます$t$合計が正確になるような配列プレフィックス (またはすべての要素) の要素$s$、 そして$c$特定の要素が含まれるかどうかをエンコードします。 実際には、包括フラグをグローバルに追跡するのではなく、各要素の寄与を個別に分離することでこれを簡素化します。 
3. 各固定要素について$a_i$、それを一時的に削除し、残りの部分集合の合計数を計算します。$n-1$要素。 私たちは定義します$ways[t][s]$サイズのサブセットの数として$t$合計付き$s$。 
4. 固定の場合$k$、 もし$a_i$はサブセットに含まれているため、選択する必要があります$k-1$合計が以下となる他の要素$S'$。 条件$a_i > \frac{a_i + S'}{k}$単純化すると$k a_i > a_i + S'$したがって、$S' < (k-1)a_i$。 
5. したがって、それぞれについて$i$、サイズが平均を超える要素の数に対する予想される寄与 -$k$サブセットは次のとおりです。$$\frac{\sum_{t=0}^{(k-1)a_i - 1} ways[k-1][t]}{\binom{n}{k}}$$6. この貢献をすべて合計します$i$の期待値を取得するには$g(c)$それぞれに$k$。 
7. すべての計算はモジュロで実行されます$998244353$、二項係数による正規化にモジュラー逆関数を使用します。 

### なぜ効果があるのか

 正確性は、サブセット平均を上回る各要素の指標変数に適用される期待値の線形性に依存します。 各要素の指標は、その要素が含まれることを条件にすると、その要素を除いたサブセットの合計にのみ依存します。 これにより、平均とサブセット構成の間の循環依存性が除去されます。 DP は、サイズと合計によってグループ化された残りの要素のすべてのサブセットを正しく列挙し、不等式は合計に対する単純な接頭辞条件に帰着します。 すべてのサブセットは含まれる要素ごとに 1 回だけカウントされ、正規化は全体にわたって均一であるため、$\binom{n}{k}$サブセットの場合、期待は正確です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    max_sum = n * n

    C = [[0] * (n + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        C[i][0] = 1
        for j in range(1, i + 1):
            C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % MOD

    ans = [0] * (n + 1)

    for k in range(2, n + 1):
        ways = [[0] * (max_sum + 1) for _ in range(k)]
        ways[0][0] = 1

        for val in a:
            for t in range(k - 2, -1, -1):
                for s in range(max_sum - val + 1):
                    if ways[t][s]:
                        ways[t + 1][s + val] = (ways[t + 1][s + val] + ways[t][s]) % MOD

        total = 0

        for i in range(n):
            ai = a[i]
            limit = (k - 1) * ai - 1
            if limit < 0:
                continue

            max_t = k - 1
            if max_t == 0:
                continue

            cnt = 0
            for s in range(min(limit, max_sum) + 1):
                cnt += ways[k - 1][s]
            cnt %= MOD

            total = (total + cnt * modinv(C[n][k])) % MOD

        ans[k] = total

    print(*ans[2:n + 1])

if __name__ == "__main__":
    solve()
```DP は、サイズとすべての要素の合計によってサブセット数を構築します。 サブセット サイズに対する逆ループにより、各要素がサブセット構築ごとに最大 1 回使用されることが保証されます。 それぞれについて$k$、サイズのサブセットを分離します$k-1$次に、次から導出されたしきい値条件をテストします。$k a_i > a_i + S'$。 すべてのサブセットの可能性が等しいため、二項係数正規化が最後に適用されます。 

実装上の微妙な問題は、合計の限界です。 値は最大でも$n$、サブセットの最大合計は次のとおりです。$O(n^2)$, したがって、DP グリッドは安全です。 もう 1 つの問題は、モジュラー反転が繰り返されることです。 二項係数の逆関数を事前に計算するとオーバーヘッドが削減されますが、これらの制約の下では厳密に必要というわけではありません。 

## 実用的な例

 小さな入力を検討してください$a = [1, 2, 3]$。 のために$k = 2$、すべてのサブセットは$[1,2], [1,3], [2,3]$。 

| サブセット | 意味 | 要素 > 意味 | g(c) |
 | --- | --- | --- | --- |
 | [1,2] | 1.5 | 1 | 1/2 |
 | [1,3] | 2 | 1 | 1/2 |
 | [2,3] | 2.5 | 1 | 1/2 |

 平均は$1/2$。 対称性が現れるのは、各ペアが常にその平均を上回る要素が 1 つだけ存在するためです。 

のために$k = 3$、サブセットのみが$[1,2,3]$、平均は 2 で、平均を上回るのは 3 だけなので、結果は次のようになります。$1/3$。 

ここで考えてみましょう$a = [1,1,100]$。 

のために$k = 2$、サブセットは$[1,1], [1,100], [1,100]$立場によっては。 

| サブセット | 意味 | 平均を上回る数 |
 | --- | --- | --- |
 | [1,1] | 1 | 0 |
 | [1,100] | 50.5 | 1 |
 | [1,100] | 50.5 | 1 |

 平均は$2/3$。 これは、大きな値がどのようにサブセット平均を支配し、それらが出現するサブセットのみに影響を与えるかを示しています。

 ## 特殊なケース

 すべての値が同一である配列の場合、すべてのサブセットの平均はすべての要素と等しくなります。 不平等$c_i > f(c)$決して満たされない。 アルゴリズムの DP は引き続きサブセットを正しくカウントしますが、しきい値条件がすべての要素で負になるため、すべての寄与はゼロとなり、期待される結果と一致します。 

次のような非常に偏ったケースの場合、$[1, 1, 1, 100]$、100 を含むサブセットは平均を大幅にシフトします。 DP はこれらのサブセットをより高い合計バケットに正しく含めます。また、不等フィルターは、残りの合計が導出されたしきい値を下回っている構成のみをカウントします。 これにより、100 が計算された平均を真に超えるサブセットでのみ寄与することが保証され、極度の不均衡下でも正確さが維持されます。
