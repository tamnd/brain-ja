 ## 解決策
 ## 問題の理解

 置きたい`n`平面の整数格子点上のチップ。 チップのコストは`(x, y)`は原点からのマンハッタン距離、`|x| + |y|`。 配置全体のコストは、配置されたすべてのチップの中で最大のチップ コストになります。 

チップは 1 つの幾何学的制限を満たす必要があります。つまり、チップのすべてのペアが次の値を超える必要があります。`1`ユークリッド距離で離れた単位。 

タスクは、正確に配置できる最小の最大コストを見つけることです。`n`チップス。 

入力には最大で次のものが含まれます`10^4`テストケースとそれぞれの`n`と同じ大きさにすることができます`10^18`。 このような巨大な値は、明示的にポイントを構築したり、最大まで反復したりするアプローチを即座に除外します。`n`。 たとえ`O(√n)`アルゴリズムは最大の入力に対して遅すぎる可能性があります。 周りに何かが必要です`O(log n)`テストケースごとに。 

主な課題は、与えられたコスト制限内に格子点がいくつ収まるかを理解することです。 

微妙なエッジケースは、`n = 1`。 

入力：```
1
1
```出力：```
0
```原点にチップを 1 つ配置できるので、答えは次のようになります。`0`。 最小コストが少なくとも`1`失敗するだろう。 

もう 1 つの重要な境界線は、次の場合です。`n`まさに完全な正方形です。 

入力：```
1
9
```出力：```
3
```答えはそうではありません`2`、コスト制限があるため、`2`のみが含まれます`3² = 9`有効なポジションは？ この観察が実際には解決策全体です。 数え方の公式を 1 つ間違えると、完全平方付近で不正確な答えが生じます。 

バグの最後の原因は、次の値を処理することです。`10^18`。 

入力：```
1
1000000000000000000
```答えは`1000000000`。 浮動小数点平方根を使用する実装では、この範囲付近で精度エラーが発生する危険があります。 整数演算の方が安全です。 

## アプローチ

 ブルートフォースの考え方は、許容される最大コストを固定することから始まります。`k`を満たす格子点の数を数えます`|x| + |y| ≤ k`。 セットは原点の周りにダイヤモンドを形成します。 

距離制限を考慮しないと、そのダイヤモンド内の格子点の数は次のようになります。$$1 + 2k(k+1).$$次に、増加を試みることができます`k`十分なポイントが存在するまで。 

問題は、距離制限によってすべてが変わってしまうということだ。 次のような 2 つの隣接する格子点`(0,0)`そして`(1,0)`まさに距離です`1`別に、それは禁止されています。 ダイヤモンドのすべてのポイントを使用することはできません。 

重要な観察は、整数グリッドでは距離条件が非常に単純になるということです。 座標は整数であるため、2 つの異なる格子点が最大の距離を持つ唯一の方法です。`1`は、水平方向または垂直方向に正確に 1 単位だけ異なるかどうかです。 

これは、パリティが 1 つだけのポイントを選択することを示唆しています。 すべての格子点を考慮します。`x + y`は均等です。 このような 2 つの点は、偶数値だけ異なります。`x + y`したがって、それらは水平方向または垂直方向に隣接することはできません。 それらのユークリッド距離は常に次よりも大きくなります。`1`。 

さあ、ダイヤモンドを見てください`|x| + |y| ≤ k`。 その格子点の中で、まさに$$(k+1)^2$$偶数パリティを持っています。 

さらに良いことに、これは最適です。 水平方向と垂直方向の隣接によって形成される格子グラフは 2 部構成であり、パリティによって分割されます。 このグラフでは、許容されるすべてのセットが独立したセットであり、1 つのパリティ クラスがすでに可能な最大サイズに達しています。 

コスト制限があるので`k`、正確に配置できます`(k+1)^2`チップス。 

問題は最小のものを見つけることに縮小されました。`k`そのような$$(k+1)^2 \ge n.$$以来`n`と同じ大きさにすることができます`10^{18}`、これは二分探索で解決できます。

 | ブルートフォース | O(k²) 以上 | お(1) | 遅すぎる |
 | 最適 | O(log n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 候補コスト制限の場合`k`、配置できるチップの数を計算します。$$(k+1)^2$$これは、ダイヤモンド内の 1 つのパリティのすべての格子点を取得することで得られます。 
2. より大きなものを観察します`k`常に少なくとも、より小さいチップと同数のチップを許可します`k`。 

機能`(k+1)^2`は単調であるため、二分探索が適用できます。 
3. 最小の二分探索`k`次のような:$$(k+1)^2 \ge n$$4.初期化`low = 0`そして`high = 10^9`。 

以来`n ≤ 10^{18}`を超えることはありません。`10^9 - 1`。 
5. 検索中に、`mid = (low + high) // 2`。 
6. もし`(mid + 1)^2 ≥ n`、設定で左半分を残します。`high = mid`。 

これはつまり`mid`すでに十分ですが、より小さな有効な答えがある可能性があります。 
7. それ以外の場合は設定します`low = mid + 1`。 

これはつまり`mid`十分なチップを収容できません。 
8. いつ`low == high`、その値を出力します。 

### なぜ効果があるのか

 コスト制限ごとに`k`、内部の格子点の最大の有効なセット`|x| + |y| ≤ k`サイズがあります`(k+1)^2`。 1 つのパリティ クラスでこのサイズが達成されますが、ダイヤモンド内の格子隣接グラフが 2 部構成であり、大きい方の側に正確に含まれるため、これより大きな独立セットは存在しません。`(k+1)^2`頂点。 

したがって、コスト制限`k`その場合にのみ実現可能です`(k+1)^2 ≥ n`。 二分探索で実行可能な最小値を見つける`k`、これはまさに最小限のコストです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())

    lo, hi = 0, 10**9

    while lo < hi:
        mid = (lo + hi) // 2

        if (mid + 1) * (mid + 1) >= n:
            hi = mid
        else:
            lo = mid + 1

    print(lo)
```解決策は単調述語を中心に展開します$$(k+1)^2 \ge n.$$固定の場合`k`、これは、ダイヤモンドの半径が`k`十分な有効なチップ位置を含めることができます。 

二分探索では、答えが常に内部にあるという不変条件が維持されます。`[lo, hi]`。 いつでも`mid`が実現可能であれば、最小コストが必要なため、左側の検索を続けます。 いつでも`mid`は実行不可能であり、それより小さな値もすべて実行不可能なので、右に進みます。 

すべての算術は整数を使用して実行されます。 これにより、浮動小数点平方根を使用するときに発生する可能性のある精度の問題が回避されます。`10^18`。 

上限`10^9`十分なので$$(10^9)^2 = 10^{18}.$$したがって、答えはより大きくなります`10^9`決して必要ありません。

# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())

        lo, hi = 0, 10**9

        while lo < hi:
            mid = (lo + hi) // 2

            if (mid + 1) * (mid + 1) >= n:
                hi = mid
            else:
                lo = mid + 1

        ans.append(str(lo))

    print("\n".join(ans))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out

    solve()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return out.getvalue()

 ## 特殊なケース

 最小の入力を考えてみましょう。```
1
1
```検索では次のことがチェックされます。`(k+1)^2 ≥ 1`。 すでに`k = 0`、条件が成り立つのは、`1² = 1`。 アルゴリズムは戻ります`0`にチップを置くことに対応します。`(0,0)`。 

次に、完全な正方形について考えてみましょう。```
1
9
```アルゴリズムは最小のものを検索します`k`と`(k+1)^2 ≥ 9`。 のために`k = 1`、私たちは得ます`4`、不十分です。 のために`k = 2`、私たちは得ます`9`、これで十分です。 答えは`2`。 これは、平等が実現可能なものとして扱われなければならないことを裏付けています。 

最後に、次のことを考慮してください。```
1
10
```のために`k = 2`、まだ残っているのは`9`利用可能なポジション。 次の値は次の値を与えます`(3+1)^2 = 16`、作る`k = 3`答え。 これは、間違った二分探索条件を検出する古典的なオフバイワンのケースです。 

最大範囲の場合:```
1
1000000000000000000
```条件はこうなります`(k+1)^2 ≥ 10^18`。 有効な最小値は次のとおりです。`k = 999999999`、 以来`(10^9)^2 = 10^18`。 整数演算はこれを安全に処理し、浮動小数点の丸めの問題を回避します。
