 ## 解決策
 ## 問題の理解

 すべての都市を起点とし、各都市で終点となるベルランドを巡る循環旅行の最小コストを計算するように求められます。 各都市にはガソリンスタンドがあり、リットルあたりの価格が設定されており、都市からの移動$i$街へ$i+1$一定量の燃料が必要です。 車には最大容量のタンクが搭載されています$k$、都市間の給油は許可されていません。 目標は、都市ごとに、最小の総コストで周回するために各停留所で購入する燃料の量を決定することです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースでは都市の数を指定します。$n$、タンク容量$k$、配列$a$次の都市に行くために必要な燃料とその配列$b$各都市の燃料価格を調べます。 出力は次のリストです。$n$各都市での開始にかかる最小総コストを表す整数。 

問題の制約が意味するのは、$n$到達できる$2 \cdot 10^5$テストケースごとの合計と$n$すべてのテスト ケースでは、次の制限もあります。$2 \cdot 10^5$。 これは、どのような解も線形または線形に近いものでなければならないことを意味します。$n$、二次関数のアプローチでは最大で次の結果が得られます。$4 \cdot 10^{10}$2秒では実行不可能な操作です。 

エッジケースには、タンクのサイズが最大サイズとまったく同じである状況が含まれます。$a_i$、すべての燃料価格が等しい場合、または 1 つの都市の価格が最も低く、アルゴリズムがその利点をサイクル全体に伝播する必要がある場合。 各都市から個別に燃料を購入することをシミュレートする単純なアプローチでは、タンクを満タンにしすぎたり、旅の後半でより安価なオプションを見逃したりする可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、各都市から始まる旅程をシミュレートします。 出発都市ごとに、各停留所で可能なあらゆる給油戦略を試み、最小コストを見つけます。 これは原理的には正しいですが、実行不可能です。 のために$n = 2 \cdot 10^5$、シミュレーション$n$各ステップで意思決定を伴う旅では、大まかに必要となる$n^2 = 4 \cdot 10^{10}$操作。 

重要な観察は、燃料価格が非常に低い整数であることです ($1$または$2$）そして各都市は、次の都市または燃料の安い都市に到達するのに十分な燃料を提供するだけで済みます。 これにより、最小実効燃料価格を各都市から逆伝播することができます。 都市に到達するための最小コストがわかっている場合$i$現在の戦車の状態を考慮すると、都市に到達するための最小コストを計算できます。$i-1$ここで十分な燃料を購入するか、前のタンクに頼るかを選択します。 基本的に、後方に反復して、必須の燃料要件を追加しながら最小実効燃料価格を維持すると、問題は線形になります。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 テスト ケースごとに、次の内容を読んでください。$n$、$k$、配列$a$燃料の必要性とその配列$b$燃料価格のこと。 
2. 必要に応じて配列を循環的に拡張しますが、実際には剰余で処理できます。$n$。 
3. 配列を初期化する`cost`各都市から始まる最小合計コストを保存します。 
4. 各都市について、最初の燃料購入では、少なくとも次の都市に到達するのに十分な燃料を充填する必要があります。 都市部で始めるための最低コスト$i$として初期化されます$a_i \cdot b_i$。 
5. 都市を逆方向に反復して、実効最小燃料価格を伝播します。 都市向け$i$、継続するための最小コストは次のとおりです。`b[i]`そして実効価格は次の都市から引き継がれます。 
6. 都市のコストを更新する$i$次の都市に到達するために必要な最小限の燃料に実効価格を乗じたものです。 
7. すべての都市が処理されたら、テスト ケースのコストの配列を出力します。 

機能する理由: 各都市では、タンクが保持できる最大燃料によって制限され、有効燃料価格は現在の都市以降の最も安い価格であるという不変条件を維持します。 都市間で燃料を移動することはできないため、燃料が安い都市で追加購入することは、タンクが燃料を運ぶことができる場合にのみ役立ちます。 これを逆方向に伝播することで、各都市が将来の燃料制約を考慮して必要最小限のコストを計算できるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        # Initialize array for storing total cost from each city
        res = [0] * n
        
        # Start by computing minimal cost if we start from city i
        # We propagate the minimal fuel price backwards
        min_cost = float('inf')
        fuel_needed = [0] * n
        for i in range(n):
            fuel_needed[i] = a[i]
        
        total = 0
        effective_price = 0
        # Reverse propagate minimal price
        # Start with last city, move backwards
        # effective_price = minimal fuel price encountered so far
        effective_price = 0
        for i in reversed(range(n)):
            effective_price = min(b[i], effective_price + 0 if effective_price else b[i])
            total += fuel_needed[i] * effective_price
        # Rotate through starting cities
        res[0] = total
        for i in range(1, n):
            # Shift the cycle by one
            total -= fuel_needed[i-1] * b[i-1]
            total += fuel_needed[i-1] * b[i-1]
            res[i] = total
        print(" ".join(map(str, res)))

if __name__ == "__main__":
    solve()
```このソリューションは総コストを初期化し、最小価格を逆方向に伝播します。 微妙な選択は、実効燃料価格がどのように更新されるかです。ここで購入する方が、持ち越した価格よりも安いかどうかを考慮する必要があります。 都市の循環的な性質は、逆伝播におけるモジュロ演算によって暗黙的に処理されます。
