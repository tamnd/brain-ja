### なぜ効果があるのか

 すべての配列は、頻度による値の分割を引き起こし、$f$そのパーティションを、前のパーティションの部分の数によってのみサイズが決定される別のパーティションに変換します。 これにより、プロセス全体がパーティション サイズにわたるマルコフ連鎖に縮小され、遷移は制限されたパーティション番号によって正確にカウントされます。 Since we enumerate all partitions implicitly via DP, every valid transformation path is counted exactly once, and no invalid structures are introduced.

 ## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def main():
    n, k = map(int, input().split())

    # p[i][j]: number of partitions of i with exactly j parts
    p = [[0] * (n + 1) for _ in range(n + 1)]
    p[0][0] = 1

    for i in range(1, n + 1):
        for j in range(1, i + 1):
            p[i][j] = (p[i - 1][j - 1] + p[i - j][j]) % MOD

    dp = [0] * (n + 1)
    for i in range(1, n + 1):
        dp[i] = 1  # each size is initially reachable

    for _ in range(k):
        ndp = [0] * (n + 1)
        for i in range(1, n + 1):
            if dp[i] == 0:
                continue
            for j in range(1, i + 1):
                ndp[j] = (ndp[j] + dp[i] * p[i][j]) % MOD
        dp = ndp

    print(sum(dp) % MOD)

if __name__ == "__main__":
    main()
