 ## 解決策
 ## 問題の理解

 有向マルチグラフが与えられています`n`宇宙。 時間の経過とともにエッジ (ポータルと呼ばれます) が 1 つずつ現れ、それぞれのポータルが方向付けされます。 

新しいエッジが追加されるたびに、2 つの値を維持する必要があります。 

最初の値は、有効な 2 ステップの移動ルートを形成するポータルの順序付けされたペアの数をカウントします。 言い換えれば、私たちはある宇宙から行くためのあらゆる方法を検討しています`a`別の宇宙へ`c`正確に 2 つの有向エッジを使用する`a → b → c`。 エッジのすべての個別の選択は異なる方法としてカウントされるため、平行なエッジは複数回寄与します。 

2 番目の値は、将来を見据えた質問をします。 現在のエッジを処理した後、次の 1 分以内にエッジをちょうど 1 つ追加することを想像してください。 次のエッジのすべての可能な選択肢の中で、2 ステップ ルートの数を可能な限り増やすことが必要です。 

入力サイズは最大です`n, t ≤ 10^5`したがって、挿入のたびに長さ 2 のすべてのパスを最初から再計算しようとするソリューションでは、すべてのエッジにわたって繰り返し再計算する必要があります。 まで`10^5`エッジが存在する場合、ステップごとに再計算すると、おおよそ次のようになります。`O(t * m)`あまりにも大きすぎる動作です。 

重要なエッジ ケースは、エッジが自己ループと重複を形成する可能性があることです。 たとえば、繰り返し追加すると、`1 → 1`の場合、すべてのループが多くのパスのプレフィックスとサフィックスの両方として参加するため、2 ステップ パスの数は急速に増加します。 多重性を持たずに単純な隣接関係のみを追跡する単純なアプローチは、次のような入力では失敗します。```
1 3
1 1
1 1
1 1
```新しい自己ループごとに同じノードで受信構造と出力構造の両方が増加し、2 ステップの組み合わせが増幅されるため、正しい出力は二次関数的に増加します。 

## アプローチ

 直接的なアプローチは、挿入のたびに長さ 2 のパスの数を再計算することです。 後`i`エッジについては、すべてのエッジのペアを反復処理し、最初のエッジの終わりが 2 番目のエッジの始まりと一致するかどうかを確認します。 つまり`O(m^2)`最悪の場合、ステップごとに次のようになります。`O(t^3)`エッジが蓄積すると全体的に完全に実行不可能になります。 

代わりに、各ノードの寄与を分離する方法でカウント問題を書き直すことができます。 すべての有効な 2 ステップ パス`a → b → c`中間ノードによって一意に決定されます`b`。 固定の場合`b`、ウェイの数は、入力エッジの数です。`b`からの発信エッジの数を乗算します。`b`。 これにより、グローバルなペアリングの問題がノードごとの結果に変換されます。 

この観察により、更新はローカルになります。 新しいエッジのとき`u → v`が追加された場合、変更されるのは 2 つのノードのみです。`u`1 つの出力エッジを獲得し、`v`入力エッジを 1 つ獲得します。 他のすべてのノードは影響を受けないため、`u`そして`v`調整が必要です。 

これにより、問題の 2 番目の部分も明らかになります。 単一の新しいエッジを挿入することによって作成される 2 ステップ パスの追加数を最大化したい場合`x → y`、私たちが気にするのは、そのエッジが全体の合計をどれだけ増加させるかだけです。 その増加は次のものにのみ依存します`x`そして`y`したがって、独立した最大値に対する最良の選択の問題にきれいに分離されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース再計算 | 1 ステップあたり O(m²) | O(m) | 遅すぎる |
 | 次数追跡不変式 | ステップごとに O(1) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 2 つの配列を維持します。`in[v]`そして`out[v]`、現在各ユニバースに出入りするポータルの数を追跡します。 また、すべての長さ 2 のパスを表すグローバル合計も維持します。 

1. すべて初期化する`in`そして`out`値をゼロに設定し、答えを設定します`S = 0`。 この時点では、2 段階のパスは存在しません。 
2. 新しいエッジごとに`u → v`, まず、このエッジが 2 ステップ パスの数をどのように変化させるかを計算します。 新しい 2 ステップ パスは、次のいずれかを使用します。`u`2 番目のエッジの開始点として使用するか、`v`最初のエッジの端点として。 
3.増加`S`による`in[u] + out[v]`。 用語`in[u]`に到達するためのあらゆる方法を数えます`u`そしてすぐに新しいエッジを使用します。`out[v]`から行くすべての道を数えます`v`新しいエッジ経由で到着した後。 これらは互いに素な寄与であるため、直線的に加算されます。 
4. 度を更新します: 増分`out[u]`そして`in[v]`。 
5. 可能な限り最良の次のエッジを追跡します。 エッジの追加によるゲイン`x → y`将来的には`in[x] + out[y]`。 最良の選択は最大化にきれいに分割されます`in[x]`そして最大化すること`out[y]`独立して。 したがって、私たちは維持します`max_in`そして`max_out`すべてのノードにわたって。 
6. 各エッジを処理した後、出力します`(S, max_in + max_out)`。 

### なぜ効果があるのか

 長さ 2 のすべての歩行は、その中間ノードによって一意に決定されます。 これは、グローバル構造が次の形式の独立した寄与に分解されることを意味します。`in[b] * out[b]`。 各更新では 1 つの着信カウントと 1 つの発信カウントのみが変更されるため、合計の変化は影響を受ける 2 つのノードによって完全にキャプチャされます。 1 回の更新中に他のノードのイン次数またはアウト次数が変化しないため、隠れたノード間の相互作用は存在しません。 

2 番目の値の場合、1 つのエッジの追加によるゲインはエンドポイントのみに依存します。 以来`in[x]`そして`out[y]`は独立した選択であるため、最適なエッジは、最大の入力次数を持つノードをソースとして選択し、最大出力次数を持つノードをターゲットとして選択することによって形成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, t = map(int, input().split())
    in_deg = [0] * (n + 1)
    out_deg = [0] * (n + 1)

    S = 0
    max_in = 0
    max_out = 0

    for _ in range(t):
        u, v = map(int, input().split())

        S += in_deg[u] + out_deg[v]

        out_deg[u] += 1
        in_deg[v] += 1

        if in_deg[v] > max_in:
            max_in = in_deg[v]
        if out_deg[u] > max_out:
            max_out = out_deg[u]

        print(S, max_in + max_out)

if __name__ == "__main__":
    solve()
```この実装の核心は、次数カウントへの影響を超えてエッジを明示的に保存することは決してないという観察です。 へのアップデート`S`増分式は前の状態に依存するため、度を変更する前に行う必要があります。 この順序により、それ自体の寄与内の新しいエッジを誤ってカウントすることが回避されます。 

メンテナンス`max_in`そして`max_out`毎回すべてのノードをスキャンすることを段階的に回避します。 各更新はエンドポイントのみに影響するため、追跡最大値は一定時間になります。

| スペース | O(n) | 2 つの配列には、すべてのノードの入次数と出力次数が格納されます。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    
    n, t = map(int, sys.stdin.readline().split())
    in_deg = [0] * (n + 1)
    out_deg = [0] * (n + 1)

    S = 0
    max_in = 0
    max_out = 0

        S += in_deg[u] + out_deg[v]

        max_out = max(max_out, out_deg[u])

 ## 特殊なケース

 自己ループは、同じノードの受信カウントと送信カウントの両方を同時に変更するため、最も注意が必要なケースです。 のような入力の場合`1 → 1`、更新が増えます`in[1]`そして`out[1]`一緒に、次の計算を意味します`S += in[1] + out[1]`新たに増加した構造がすでに反映されています。 

たとえば:

 入力:```
1 2
1 1
1 1
```最初のエッジの後、`in[1]=1`、`out[1]=1`、 それで`S=0`。 2 番目のエッジの後で計算します`S += 1 + 1 = 2`、与える`S=2`。 これは、長さ 2 のウォークが 2 つ存在するという事実と一致します。つまり、最初のループのいずれかの出現を最初のステップとして選択し、いずれかを 2 番目のステップとして選択します。 

これにより、更新と蓄積の順序が正しく、両方のエンドポイントが同一である場合でも過剰カウントが発生しないことが確認されます。
