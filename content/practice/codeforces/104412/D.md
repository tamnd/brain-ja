 ## 解決策
 ## 問題の理解

 2 つの整数配列が与えられます。 最初の配列 (パターン配列と呼びます) には長さがあります。$M$。 2 番目の配列 (ソース配列と呼びます) には長さがあります。$N$。 同じ定数値をセグメントのすべての要素に追加することによって、ソース配列の連続するセグメントが何個パターン配列に変換できるかを数えたいと考えています。 

言い換えれば、次のセグメント$N$マッチ$M$値の形状が同一の場合、垂直方向のシフトまで。 絶対値は重要ではなく、ある位置から次の位置へ値がどのように変化するかのみが重要です。 

重要な制約は、どちらの配列も非常に大きくなり得るということです。$10^6$要素。 これにより、次のすべての部分配列間の二次比較が除外されます。$N$そして$M$、大まかなチェックが必要になるため$N \cdot M$最悪の場合の要素（それをはるかに超えています）$10^6$操作。 

素朴なアプローチでは、あらゆる長さを比較してしまいます。$M$の部分配列$N$直接反対する$M$、ただし、1回の比較でもコストがかかります$O(M)$、につながる$O(NM)$全体としては、$10^{12}$最悪の場合の運用。 

すべての要素が次の場合に微妙なエッジケースが発生します。$M$は同一です。 その状況では、すべての有効な一致には、選択された部分配列が必要です。$N$も同じ値で構成されますが、シフトされたバージョンでも一致する可能性があります。 相対的な差異ではなく生の値を誤って比較すると、同一形状のケースが見逃されてしまいます。 例えば、$M = [1,1,1]$そしてサブアレイ$[5,5,5]$一致する必要がありますが、直接比較は失敗します。 

もう 1 つの例外的なケースは次のような場合です。$M$長さがある$1$。 のすべての単一要素部分配列$N$単一の数値に一致するように任意の値をシフトできるため、これは有効です。 答えは単純です$N$、メソッドが常に差異が存在することを前提としている場合、これは見落とされがちです。 

## アプローチ

 中心的な観察は、「一定のシフトまで等しい」では絶対値が削除され、相対的な構造のみが残るということです。 連続した要素を差し引くと、一定のシフトは完全に消えます。 

任意の配列に対して$A$、その差分表現を定義します。$$D_A[i] = A[i+1] - A[i]$$2 つの配列は、それらの差配列が同一である場合に限り、シフト等価です。 これにより、問題はパターン マッチング タスクに変換されます。つまり、値のマッチングではなく、一連の差異のマッチングが行われます。 

ブルートフォースソリューションは、次のすべての部分配列を反復処理します。$N$長さの$M$、その差分シーケンスを計算し、それを次のものと比較します。$M$。 それぞれの比較にかかる費用$O(M)$、そして、あります$O(N)$候補があるため、全体の複雑さは次のようになります。$O(NM)$。 両方のアレイが到達すると、これでは遅すぎます。$10^6$。 

問題が 2 つのシーケンスの一致に縮小されると、標準的な部分文字列検索の問題になります。つまり、ある配列の中に別の配列が出現する回数をカウントする必要があります。 これは、ローリング ハッシュまたはプレフィックス関数 (KMP) を使用して線形時間で解決できます。 構造は重要です。大きなテキスト内の固定パターンを照合しており、アルファベットは任意の整数であるため、ハッシュ化は自然に適合します。 

両方の配列を差分形式に変換した後、テキスト差分配列内でパターン差分配列の出現を検索します。 各一致は、元の配列内の 1 つの有効な部分配列に対応します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(NM)$|$O(1)$番外編 | 遅すぎる |
 | 差分 + KMP/ハッシュ |$O(N)$|$O(N)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. もし$M = 1$、 戻る$N$。 単一要素のサブ配列は単一の値に一致するようにシフトできるため、すべての位置が有効になります。 
2. の差分配列を構築します。$M$、各エントリは$m[i+1] - m[i]$。 これは、絶対値とは独立してその構造をエンコードします。 このステップにより、パターンのサイズが次のように縮小されます。$M-1$。 
3. の差分配列を構築します。$N$、同様に計算します$n[i+1] - n[i]$。 これにより、問題は、あるシーケンスの中に別のシーケンスが出現することを見つけることに変わります。 
4. もし$M > N$、 戻る$0$。 長いパターンは短いシーケンスには適合しません。 
5. KMP などの線形時間パターン マッチング アルゴリズムを使用して、テキスト差分配列内にパターン差分配列が出現する回数をカウントします。 各一致は、元の配列内の有効な開始インデックスに対応します。 
6. 見つかった一致の数を返します。 

### なぜ効果があるのか

 一定のシフトはすべての要素に均等に影響を与えるため、隣接する差分を取得すると相殺されます。 これは、定数のみが異なる 2 つの配列が同一の差分配列を生成することを意味します。 逆に、2 つの配列が同一の差分配列を持つ場合、固定の開始値から再構成すると同じ相対構造が得られるため、それらの値は定数オフセットだけ異なっていなければなりません。 したがって、差分配列のマッチングは、元の類似性条件とまったく同じになります。 差分空間内のすべての有効な部分配列の一致は、元の配列内の有効なシフトされた一致と 1 対 1 で対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_diff(arr):
    return [arr[i+1] - arr[i] for i in range(len(arr) - 1)]

def kmp_prefix(p):
    pi = [0] * len(p)
    j = 0
    for i in range(1, len(p)):
        while j > 0 and p[i] != p[j]:
            j = pi[j - 1]
        if p[i] == p[j]:
            j += 1
            pi[i] = j
    return pi

def kmp_count(text, pat):
    if not pat:
        return len(text) + 1

    pi = kmp_prefix(pat)
    j = 0
    count = 0

    for i in range(len(text)):
        while j > 0 and text[i] != pat[j]:
            j = pi[j - 1]
        if text[i] == pat[j]:
            j += 1
        if j == len(pat):
            count += 1
            j = pi[j - 1]

    return count

def solve():
    M, N = map(int, input().split())
    m = list(map(int, input().split()))
    n = list(map(int, input().split()))

    if M == 1:
        print(N)
        return

    if M > N:
        print(0)
        return

    dm = build_diff(m)
    dn = build_diff(n)

    print(kmp_count(dn, dm))

if __name__ == "__main__":
    solve()
```この解決策は、パターンの長さがテキストより 1 以上である縮退ケースを処理することから始まります。 変換ステップでは差分配列を計算し、マッチング問題を長さ以上の 1 つに縮小します。$M-1$そして$N-1$。 

KMP ルーチンは、パターンの発生を線形時間で効率的にカウントするために使用されます。 プレフィックス配列は、不一致が発生した場合にどこまで安全にフォールバックできるかをエンコードし、すでに検証された構造の再検査を防ぎます。 マッチング ループは、完全なパターンが一致するたびにカウンターをインクリメントし、最長の有効な境界線から続行します。 

微妙な点は、前処理後に生の配列をまったく比較しないことです。 すべての正しさは、差分配列が変換時に等価性を保持するという事実に完全に依存します。

 ## 特殊なケース

 場合について$M = 1$、アルゴリズムは直接返します$N$。 これは、差分配列が空になり、すべての位置が空のパターンに自明に一致するという事実と一致します。 たとえば、入力$M=[7]$、$N=[1,2,3]$すべての単一要素部分配列は 7 にシフトできるため、3 つの一致が生成されます。 

次のような均一配列の場合$M=[5,5,5]$そして$N=[1,1,1,1]$、差分配列は完全にゼロです。 KMP プロセスは、ゼロ テキスト全体でゼロ パターンを繰り返し照合し、$N-M+1$有効な一致。 これにより、差分後に値情報が完全に消失するケースをアルゴリズムが正しく処理していることが確認されます。 

次のような一致しない構造の場合$M=[1,2,3]$そして$N=[10,20,30]$、差分配列は次のように異なります。$[1,1]$対$[10,10]$したがって、部分文字列の一致は発生せず、予想どおりゼロが生成されます。
