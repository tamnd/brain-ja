 ## 問題の理解

 正の整数が与えられます$n$。 分割方法を検討します$n$2 つの自然数（正の整数を意味し、ペアとして記述されます）に変換します。$(a, b)$そのような$a + b = n$。 他のペアにも同じことが当てはまります$(c, d)$と$c + d = n$。 両方のペアが順序制約を満たす必要があり、4 倍に興味があります。$(a, b, c, d)$そのような$a + b = n$、$c + d = n$、4 つの数字はパターン内で厳密に増加しています。$a < c < d < b$。 

したがって、幾何学的には、同じ数の 2 つの分解を選択することになります。$n$、最初の分割が 2 番目の分割よりも「左にシフト」されるように、両方の合計が同じ合計になるようにエンドポイントをインターリーブします。 

入力サイズは最大です$10^9$したがって、考えられるすべての分解を試したり、すべての 4 倍数を反復したりする解決策は、直ちに不可能になります。 可能なすべてのことを繰り返しても$a$からの値$1$に$n$はすでに遅すぎるでしょう。 これは、答えが列挙ではなく構造的な数え方の議論に依存していることを強く示唆しています。 

微妙なエッジケースが現れるのは、$n$小さいです。 たとえば、次の場合$n = 3$、有効な分解は 1 つだけです$(1,2)$したがって、2 つの異なるペアを選択することはまったく不可能であり、答えはゼロでなければなりません。 4 つすべての変数間に厳密な不等式を適用することを忘れたメソッドでは、一部の変数が一致する縮退構成が誤ってカウントされる可能性があります。 

もう 1 つの潜在的な落とし穴は、二重カウントです。 以来$(a,b)$そして$(b,a)$暗黙的に自然な順序付け制約があるため、有効なペアとして許可されません。$a < b$、順序付けされた分解は一度だけ考慮するようにする必要があります。 

## アプローチ

 ブルートフォースアプローチは、すべてのペアを列挙することです。$(a,b)$そのような$a+b=n$、これは約を与えます$n-1$有効な分割。 次に、そのようなペアを 2 つ選択し、すべての 4 回転をチェックします。$(a,b,c,d)$かどうかを確認する$a < c < d < b$。 これはおおよそ次のことにつながります$O(n^2)$候補ペアの比較、各チェックは定数時間であるため、全体的な複雑さは次のとおりです。$O(n^2)$。 のために$n = 10^9$、これはまったく不可能です。 

重要な観察は、すべての有効な 4 つ組は、同じ線分の 2 つの有効な分割を選択することによって完全に決定されるということです。$1 \dots n-1$。 それぞれの分割$(a,b)$パーティションポイントに対応します$a$、 以来$b = n-a$。 したがって、4 つの独立変数の観点から考える代わりに、問題を 2 つの分割点の選択に縮小します。$a$そして$c$、そしてどのような制約があるかを確認します$a < c < d < b$に翻訳します。 

置き換える$b = n-a$そして$d = n-c$、不等式は次のようになります$a < c < n-c < n-a$。 

一番右の不等式$n-c < n-a$単純化すると$a < c$、これはすでに存在しているため冗長です。 残りの自明ではない条件は、$c < n-c$、つまり$c < \frac{n}{2}$、そしてまた$n-c < n-a$、これは再び次のように減少します$a < c$。 

したがって、構造は整数のペアを数えるように崩壊します。$a < c$両方とも$a$そして$c$中点の「左側」にあることによって制約されます。$n$、さらに両方の分割が有効であることを考慮します。 

これにより、問題は、次のように決定される特定のプレフィックス範囲から 2 つの異なる整数を選択できる方法が何通りあるかを数えることになります。$n$となり、答えは線形セグメント上の単純な組み合わせの数になります。 

これにより、問題は二次列挙から直接の組み合わせ公式に変換されます。

 ## アルゴリズムのチュートリアル

 1. 有効な各ペアを書き換えます$(a,b)$単一の変数を使用する$a$、 以来$b = n-a$。 これにより、問題は整数の処理に縮小されます。$a$範囲内で$1 \le a \le n-1$。 
2. 2 番目のペアを次のように表現します。$(c, n-c)$。 これで、2 つの異なる値を選択することによって 4 つ組全体が決定されます。$a$そして$c$。 
3. 制約を変換する$a < c < d < b$だけを含む不平等に$a$そして$c$。 置き換える$d = n-c$そして$b = n-a$、私たちは得ます$a < c < n-c < n-a$。 
4. 不等式を単純化します。 条件$n-c < n-a$に減少します$a < c$、これはすでに必須です。 自明でない制約は次のようになります。$c < n-c$、これは以下と同等です$2c < n$。 これは有効な範囲を制限します$c$。 
5. 有効なものをすべて特定する$c$。 これらは整数です$c$そのような$1 \le c \le \left\lfloor \frac{n-1}{2} \right\rfloor$。 
6. 有効なそれぞれについて$c$、有効な数を数えてください$a$と一緒に存在する$1 \le a < c$。 これは単純に、$c-1$。 
7. 有効なすべての合計$c$、三角和を生成します$\sum_{c=1}^{m} (c-1)$、 どこ$m = \left\lfloor \frac{n-1}{2} \right\rfloor$。 これは次のように評価されます$\frac{m(m-1)}{2}$。 

### なぜ効果があるのか

 すべての有効なクアドルプルは、インデックスの順序付きペアに一意に対応します。$(a,c)$と$a < c$, ここで、どちらも分解の有効な最初の成分を表します。$n$。 不等式の連鎖により、両方の点が有効な分解範囲の下半分に収まるようになり、置換後に他の隠れた制約は残りません。 各クアドルプルはそのような順序ペアに 1 つだけマッピングされ、またその逆も同様であるため、これらのペアを数えることで有効な構成の正確な数が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    m = (n - 1) // 2
    if m <= 1:
        print(0)
        return
    
    print(m * (m - 1) // 2)

if __name__ == "__main__":
    solve()
```コードは、問題を変数の有効な位置のカウントに変換することから始まります。$c$、厳密にその下にある必要があります$n/2$。 This is captured by$m = \lfloor (n-1)/2 \rfloor$、2 番目の分割点に存在する有効な選択肢がいくつあるかを表します。 

そのような点が 2 つ未満しか存在しない場合、順序付きペアは存在しません。$(a,c)$形成できるので、答えはゼロです。 それ以外の場合、増加するペアの数が標準の組み合わせ数になります。$C(m,2)$、として実装されます$m(m-1)/2$。 

重要な実装の詳細は、Python のフロア除算が数学的導出と一致しているため、整数除算が正しく使用されるようにすることです。

 ## 特殊なケース

 のために$n = 2$、分解は 1 つだけです$(1,1)$しかし、これは 2 つの異なるペアを形成するための厳密な不等式要件に違反します。 アルゴリズムは計算します$m = \lfloor (2-1)/2 \rfloor = 0$、すぐにゼロを返し、有効な 4 倍数が存在できないという事実と一致します。 

のために$n = 3$、唯一の分割は$(1,2)$したがって、2 つの異なる有効な分割を選択することは不可能です。 アルゴリズムは再び次の結果をもたらします$m = 1$、そしてそれ以来$m(m-1)/2 = 0$、出力は正しいです。 

大型用$n$、 のような$10^9$の場合、アルゴリズムは列挙を試みません。 直接計算します$m = 499999999$単一の算術式を返し、有効な構成をすべて正確に表現しながら、時間制限の問題のリスクを回避します。
