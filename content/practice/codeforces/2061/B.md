 ## 解決策
 ## 問題の理解

 複数のスティックの長さのセットが与えられているので、ゼロ以外の面積の二等辺台形を形成できるスティックを 4 本正確に選択する必要があります。 棒は凸四角形の 4 つの辺の長さになり、幾何学的条件が満たされる限り、有効な台形構成に再配置することができます。 

二等辺台形には平行な対辺が 1 対あり、平行でない 2 つの辺は等しいです。 長方形と正方形は、対辺の両方のペアが平行であるという縮退対称の場合としてこの定義を満たすため、含まれます。 

組み合わせの観点から、4 つの数字を選択し、そのうちの 2 つが等しい「脚」を形成し、残りの 2 つが 2 つの塩基を形成するようにそれらを配置できるかどうかを尋ねます。 唯一の構造上の制約は、脚が等しくなければならないことですが、ベースは任意の正の長さであり、形状が非縮退であるため、2 つのベースが面積ゼロの構成に折りたたまれないという追加の要件があります。 

入力サイズは大きく、すべてのテスト ケースで最大 200,000 個のスティックがあります。 これにより、テスト ケースごとに 2 次関数以上に成長するため、すべての 4 倍関数、さらにはすべてのペアのペアを試行するアプローチは直ちに除外されます。 有効なソリューションは、合計入力サイズが実質的に線形またはほぼ線形である必要があります。 

有効な構成が複数存在する可能性があり、出力する必要があるのは 1 つだけであるという事実から、微妙な問題が発生します。 これは、実現可能性を超えてジオメトリを最適化していないことを示唆しています。 マルチセット内の構造のみを検出しています。 

切り分ける価値のあるエッジケースの 1 つは、すべてのスティックが異なる場合です。 その状況では、等しい脚のペアを形成することはできないため、答えは直ちに不可能になります。 もう 1 つは、重複が多数あるものの、すべてが 1 つの値に集中している場合です。たとえば、`1 1 1 1`、ここで長方形のような構成を形成できます。 多重度を正確に追跡せずに「少なくとも 2 つの等しいペア」をチェックするだけの単純なアプローチでは、有効な取り決めを構築できない可能性があります。 

## アプローチ

 ブルートフォース戦略では、すべての 4 つのスティックを試して、有効な等脚台形を形成できるかどうかをテストします。 4 つのインデックスを選択するたびに、すべての順列をチェックするか、2 つの等しい辺を脚として割り当て、残りを基底として割り当てることができるかどうかを直接推論します。 これには次のような費用がかかります$O(n^4)$最悪の場合、それはたとえ$n = 10^5$、それは暗示するので、$10^{20}$操作。 

わずかに改良されたブルート フォースでは、最初に脚のペアを修正し、次に残りの要素の中から追加の 2 つの側面を検索する可能性があります。 これにより、検索が減少します。$O(n^3)$または$O(n^2)$、ただし、制約の下では依然として失敗します。 

重要な構造上の観察は、有効な台形には脚として機能する一対の等しい辺が必要であるということです。 このようなペアを識別すると、残りの 2 辺が自動的に底辺を形成し、この問題設定では正の長さが底辺として機能するため、それ以上の幾何学的制約をチェックする必要はありません (長方形が明示的に許可されており、追加のメートル制約が課されていないため)。 

これにより、問題は少なくとも 2 回出現する値を見つけるだけになります。 そのような値が見つかったら、それを脚として使用します。 次に、ベースとして機能する残りの 2 本の棒が必要になります。 唯一の微妙な点は、同じ出現を誤って再利用しないようにすることですが、これは周波数や位置を追跡すれば自然に処理されます。 

構築の信頼性を高めるために、配列をソートすると重複の検出が簡素化され、残りの 2 つの要素も効率的に選択できるようになります。

 | --- | --- | --- | --- |
 | 4回転以上のブルートフォース |$O(n^4)$|$O(1)$| 遅すぎる |
 | 周波数 + 貪欲な構築 |$O(n \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 この問題を、繰り返される値の検出と、さらに 2 つの別個の要素の選択に変換します。 

1. スティックの長さの配列を並べ替えます。 

グループを並べ替えると同じ値が得られるため、決定論を好む場合は、ハッシュベースの構造ではなく単一のリニアスキャンで重複の検出が行われます。 
2. ソートされた配列をスキャンして、少なくとも 2 回出現する最初の値を見つけます。 

連続して等しい要素に遭遇した場合、その値を等しいレッグの候補としてマークします。 
3. この重複値の 2 つの出現を潜在的なベースとしての考慮から削除します。 

この2本の棒が台形の足になります。 
4. 残りのスティックから、任意の 2 つの値を選択します。 

サイズが 4 以上のマルチセットから要素を 2 つだけ削除しただけなので、有効な重複が見つかった場合は常に少なくとも 2 つの要素が残ります。 
5. 選択した 4 つの値を出力します。 

値が 2 回以上出現しない場合は、すぐに出力します。`-1`。 

### なぜ効果があるのか

 二等辺台形には、脚として機能する等しい長さの辺が 1 組必要です。 したがって、どのような解法にも必要な条件は、重複した長さが存在することです。 このようなペアが選択されると、残りの 2 辺はこの問題設定では制約されません。これは、有効な台形 (特殊な場合として長方形を含む) を形成しながら、正の長さが底辺として機能するためです。 これにより、問題は完全に周波数検出に限定されます。 常に配列から実際の出現を選択するため、幾何学的再構成を必要とせずに妥当性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        a.sort()
        
        pair_val = -1
        i = 0
        while i < n - 1:
            if a[i] == a[i + 1]:
                pair_val = a[i]
                break
            i += 1
        
        if pair_val == -1:
            print(-1)
            continue
        
        used = 0
        res = []
        
        # take two equal legs
        cnt = 0
        for x in a:
            if x == pair_val and cnt < 2:
                cnt += 1
                continue
            res.append(x)
        
        # pick any two remaining as bases
        if len(res) < 2:
            print(-1)
            continue
        
        print(pair_val, pair_val, res[0], res[1])

if __name__ == "__main__":
    solve()
```この実装では、まず重複が隣接していることを確認するためにソートが行われ、有効なレッグ ペアの検出が簡単になります。 見つかったら、残りのプールを構築するときに、その値のちょうど 2 つの出現を明示的にスキップします。 これにより、同じスティックを誤って再利用することがなくなります。 

微妙な点は、ジオメトリから必要以上の構造を想定しないようにすることです。 対称条件が満たされれば、問題定義によりあらゆる構成が暗黙的に許可されるため、三角形不等式や角度制約を強制しようとすることはありません。 

## 実用的な例

 成功したケースと不可能なケースの 2 つのケースを追跡します。

 これは、複数の重複が存在するケースを示しています。 最初の有効なペアを選択するだけです。

 ## 特殊なケース

 重要なエッジ ケースは、重複が 2 つあるものの、ベースを形成するのに十分な要素が残っていない場合です。 例えば`2 2 2 2`脚として 2 つを選択した後、ベースとして 2 つが残るため、これはまだ機能します。 削除は正確であり、複数の値にわたって貪欲ではないため、アルゴリズムはこれを自然に処理し、偶発的な枯渇を確実に防ぎます。
