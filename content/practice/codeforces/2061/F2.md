 ## 解決策
 ## 問題の理解

 バイナリ文字列が与えられます`s`0 と 1、およびターゲット文字列で構成される`t`0、1、またはワイルドカード文字を含めることができる同じ長さ`?`。 許可される操作は、同じ文字の 2 つの **隣接するブロック**を選択することです。`s`そしてそれらを交換します。 ブロックは、同じ文字の最大の連続シーケンスです。 私たちの目標は変革することです`s`一致する文字列に変換`t`すべての位置で`t`ではありません`?`最小数のスワップを使用します。 それが不可能な場合は、-1 を返す必要があります。 

この制約により、最大 10^4 のテスト ケースと、最大 4×10^5 のすべての文字列の合計長が許可されます。 これは、どのソリューションも各文字をおよそ 1 回か 2 回処理する必要があり、ブロックのすべての置換を試みたり、各交換を明示的にシミュレートしたりするアプローチを除外する必要があることを意味します。 

明らかではないエッジケースは次のような理由から発生します。`?`の文字`t`複数のキャラクターが存在する状況`s`が要求するものよりも`t`。 たとえば、次の場合`s = "0101"`そして`t = "1010"`, ブロック隣接ルールを破らずに 2 つの連続する 1 の後ろに 0 を移動することはできないため、これは不可能です。 同様に、`t`ワイルドカードのみが含まれます。`s`操作がゼロの場合は自明に有効です。 これらの不均衡やスワップの不可逆性を考慮しない不注意な実装は、誤った答えを生み出すことになります。 

## アプローチ

 ブルートフォースアプローチは、すべてのブロックを繰り返し識別することです。`s`、すべての有効な隣接ブロックの交換を試み、結果の文字列が次の値に近づくかどうかを確認します。`t`。 各スワップは検索ツリー内のノードと見なすことができ、BFS または DFS を試行してスワップの最小数を見つけることができます。 これは原理的には正しいですが、ブロックの数は次のとおりです。`n`最悪の場合、スワップ シーケンスの数が指数関数的に増加します。 と`n`最大 10^5 および複数のテスト ケースの場合、このアプローチは実行できません。 

最適なソリューションを実現するための重要な洞察は、移動する必要がある正確な文字を 0 と 1 のカウントに抽象化することです。 隣接するブロックを交換すると、同じタイプのブロックの相対的な順序が維持されるため、問題は、「1」文字を通過するために「0」文字が何個必要か、またはその逆に「0」文字が何個必要かをカウントすることになります。 言い換えれば、次の間の**不均衡**を計算できます。`s`そして`t`左から右にスキャンするたびに、文字が`s`の対応する固定文字とは異なります`t`、そのタイプの「追加」のカウンターをインクリメントします。 スワップの最小数は、相互に交差する必要がある、誤って配置された 0 と 1 のカウント間の絶対差の合計になります。 ワイルドカードの使用`t`キャラクタをその位置に拘束しないため、無視できます。 これにより、問題は 1 回の線形スキャン (テスト ケースごとに O(n)) に減ります。

 ## アルゴリズムのチュートリアル

 1. 入力文字列を解析する`s`そして`t`。 2つのカウンタを初期化する`excess0`そして`excess1`これらは、0 と 1 の数を追跡します。`s`～に対して場違いである`t`。 
2. 文字列を左から右に繰り返します。 For each position`i`、 もし`t[i]`です`?`、どの文字でも使用できるため、スキップしてください。 もし`s[i]`マッチ`t[i]`、 続く。 それ以外の場合は、`s[i]`は`0`しかし`t[i]`は`1`、増分`excess0`。 もし`s[i]`は`1`しかし`t[i]`は`0`、増分`excess1`。 これは、正しい位置に到達するために最終的に他の文字をまたぐ必要がある、間違って配置された文字を表します。 
3. 文字列をスキャンした後、間違って配置された 0 と 1 の合計数に互換性があるかどうかを確認します。 0の合計数が`s`は 0 の数より小さいです`t`(ワイルドカードを無視)、一致することは不可能です`t`、-1を返します。 
4. 必要なスワップの最小数は、次の最大数です。`excess0`そして`excess1`。 これが機能するのは、各スワップで 0 と 1 の間の 1 つの交差を修正できるためであり、一部のキャラクターは複数のステップを移動する必要がある場合がありますが、最大数を数えることで必要なすべての移動がカバーされます。 
5. 結果を出力します。 

維持される不変条件は、各スキャンの後、`excess0`は、ターゲット位置に到達するためにいくつかの 1 を通過する必要があるすべての 0 を表し、その逆も同様です。 隣接するブロックを交換すると、一度に 1 つの交差が効率的に解決され、これらのカウントの最大値が必要なスワップの最小数になることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def min_swaps(s, t):
    excess0 = 0
    excess1 = 0
    for i in range(len(s)):
        if t[i] == '?':
            continue
        if s[i] == t[i]:
            continue
        if s[i] == '0' and t[i] == '1':
            excess0 += 1
        elif s[i] == '1' and t[i] == '0':
            excess1 += 1
    # Check if total counts allow a valid transformation
    if s.count('0') < t.count('0'):
        return -1
    return max(excess0, excess1)

def main():
    t = int(input())
    results = []
    for _ in range(t):
        s = input().strip()
        tstr = input().strip()
        results.append(str(min_swaps(s, tstr)))
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```機能`min_swaps`まず、間違った文字の数を数えます。 次に、0 の数が正しいかどうかを確認します。`s`満足するには十分です`t`、無視`?`。 そうでない場合、変換は不可能です。 それ以外の場合、誤って配置された 0 と 1 の最大数により、必要な最小限のスワップが得られます。 main 関数は、高速 I/O を使用して複数のテスト ケースを効率的に処理します。
