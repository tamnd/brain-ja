 ## 解決策
 ## 問題の理解

 1 台に 2 つのチップがあります$n \times m$グリッド。 各ターンで、最初のプレイヤーは、接着されていないチップを 4 つの隣接するグリッド内で 1 マスずつ正確に 1 つ移動します。 その後、2 番目のプレイヤーは、現在空になっている 1 つの正方形を永久に接着します。 

チップは接着された正方形の上に移動することができます。 そうなった瞬間、そのチップは永久に固着してしまいます。 2 つのチップが同じマスを占めると、最初のプレーヤーがすぐに勝ちます。 両方のチップが出会う前に移動できなくなった場合、2 番目のプレーヤーの勝ちです。 

基板の寸法は次のように大きくできます。$100 \times 100$、しかし、それは誤解を招くことが判明しました。 勝利条件は、セルの総数ではなく、2 つのチップの相対的な変位のみに依存します。 接着剤の配置は時間の経過とともに蓄積されるため、ゲーム全体の状態空間は膨大になり、ゲーム ツリー全体をモデル化する試みは絶望的になります。 

単純な実装では、接着されたすべてのセルを表現し、ミニマックス検索を実行しようとする可能性があります。 上でも$10 \times 10$ボードはすでにあります$100$最初の動きで接着可能な位置を特定し、その後$99$次の動きなど。 分岐因子はすぐに爆発します。 

難しいのは、ボードのサイズ自体はほとんど関係ないということです。 2 つのチップが非常に離れていると、2 番目のプレーヤーにバリアを構築し、両方のチップを強制的にトラップさせるのに十分な時間が与えられます。 通常、近くにある 2 つのチップは接着剤が決定的になる前に接触します。 

簡単な間違いの 1 つは、マンハッタンの距離だけを見てしまうことです。 例えば：```
10 10 1 1 5 5
```ここでの変位は$(4,4)$。 マンハッタンの距離はたったの$8$ですが、正解は`Second`。 距離のみに基づいた戦略では、最初のプレイヤーの勝利を誤って予測することになります。 

別の微妙なケースは次のとおりです。```
10 10 1 1 4 5
```変位は$(3,4)$。 これは、近くの多くのポジションが勝っているにもかかわらず、最初のプレーヤーにとっては負ける構成でもあります。 

最後のトラップは、内部のすべての位置が$5 \times 5$近所が勝ってます。 ペア$(3,4)$そして$(4,4)$は特別な例外です。 

## アプローチ

 ブルートフォースのアイデアは単純です。 ボード全体を表し、どのセルが接着されているかを追跡し、最初のプレーヤーのすべての正当な動きと 2 番目のプレーヤーのすべての接着配置を生成してから、ミニマックスを実行します。 

これは完全なゲーム ツリーを探索するため、正しいです。 問題は、到達可能な位置の数が天文学的に増加することです。 ほんの数回のターンだけで、すでに何百万もの異なる接着剤の構成が存在します。 この制限内では、検索ベースのソリューションは存続できません。 

重要な観察は、最適なプレイは 2 つのチップの相対位置にのみ依存するということです。 ゲームを分析すると、驚くほど少数の負け構成が見つかることがわかります。 

させて$$dx = |x_1 - x_2|,\qquad dy = |y_1 - y_2|$$そしてそれらを並べ替えて、$dx \le dy$。 

完全な解決策は次のとおりです。 

もし$dy > 4$、2番目のプレイヤーが勝ちます。 

もし$(dx,dy) = (4,4)$、2番目のプレイヤーが勝ちます。 

もし$(dx,dy) = (3,4)$、2番目のプレイヤーが勝ちます。 

他のすべてのポジションは先手のプレイヤーが勝ちます。 この特徴付けは、問題の意図された解決策でした。 

このパターンがわかれば、ゲームは少数の整数比較に減ります。

 ## アルゴリズムのチュートリアル

 1. ボードの寸法と 2 つのチップの座標を読み取ります。 
2. 絶対座標の差を計算します。$$dx = |x_1 - x_2|$$

$$dy = |y_1 - y_2|$$相対的な変位のみが重要です。 
3. 次のように値を並べ替えます。$dx \le dy$。 

これにより、対称的な位置を同様に扱うことができます。 
4. もし$dy > 4$、出力`"Second"`。 

一方向に 4 マス以上離れた位置は、最初のプレイヤーの負けとなります。 
5. もし$(dx,dy) = (4,4)$、出力`"Second"`。 
6. もし$(dx,dy) = (3,4)$、出力`"Second"`。 
7. 残りのすべてのケースで、出力します。`"First"`。 

### なぜ効果があるのか

 ゲームには、チップ間の相対変位の観点から完全な分類があります。 そのように正規化した後、$dx \le dy$、外側のすべての位置$5 \times 5$2 番目のプレーヤーは、チップが出会う前に常に十分な接着セルを作成できるため、近隣は最初のプレーヤーが負けます。 この付近では、徹底的なゲーム分析により、負けた構成は 2 つだけ残ります。$(3,4)$そして$(4,4)$。 他の正規化されたディスプレイスメントはすべて、最初のプレーヤーに強制的な戦略を許可します。 

このアルゴリズムはまさにこの特徴付けを実装しているため、その答えはすべての正当な入力に対して正しいものになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, x1, y1, x2, y2 = map(int, input().split())

    dx = abs(x1 - x2)
    dy = abs(y1 - y2)

    if dx > dy:
        dx, dy = dy, dx

    if dy > 4:
        print("Second")
    elif (dx, dy) == (4, 4):
        print("Second")
    elif (dx, dy) == (3, 4):
        print("Second")
    else:
        print("First")

if __name__ == "__main__":
    solve()
```最初のセクションでは、チップ間の相対変位を計算します。 このステップの後は、実際の座標やボードの寸法さえも問題になりません。 

スワップにより、次のような同等のポジションが保証されます。$(1,4)$そして$(4,1)$は同じペアで表されます。 この正規化を忘れると、対称位置が誤って分類されてしまいます。 

残りのロジックは、勝ち位置の特徴付けを直接実装します。 チェックの順序は重要ではありませんが、テストは`dy > 4`まず構造を少し明確にします。 

すべての値が最大値であるため、オーバーフローの問題は発生しません。$100$。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    n, m, x1, y1, x2, y2 = map(int, input().split())

    dx = abs(x1 - x2)
    dy = abs(y1 - y2)

    if dx > dy:
        dx, dy = dy, dx

    if dy > 4 or (dx, dy) == (4, 4) or (dx, dy) == (3, 4):
        print("Second")
    else:
        print("First")

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue().strip()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided samples

 ## 特殊なケース

 次のことを考慮してください。```
10 10 1 1 5 5
```取得します$dx = 4$、$dy = 4$。 アルゴリズムは明示的なレベルに達します$(4,4)$チェックと出力`Second`。 「最大 4 の差があるすべてのポジションが勝つ」というルールのみに基づいた解決策は、ここでは失敗します。 

ここで次のことを考えてみましょう。```
10 10 1 1 4 5
```正規化された変位は、$(3,4)$。 これも例外的な負け状態です。 専用のチェックが正しく返されます`Second`。 

ついに：```
100 100 1 1 1 6
```正規化された変位は、$(0,5)$。 以来$dy > 4$、アルゴリズムはすぐに出力します`Second`。 これは、長距離ルールがすべての小さなローカル パターンよりも優先されることを確認します。 答えは実際の基板寸法を考慮せずに決定されます。
