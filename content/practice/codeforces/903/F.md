 ## 解決策
 ## 問題の理解

 アスタリスクまたはドットで埋められた 4 行 x _n_ 列の行列が与えられます。 アスタリスクはクリアする必要があるタイルを表します。 許可される操作は、サイズ 1×1 から 4×4 までの正方部分行列を選択し、その中のすべてのアスタリスクをドットに置き換えることです。 各部分行列には、そのサイズに応じた固定コストがあります。 私たちの仕事は、すべてのアスタリスクをクリアするための最小総コストを決定することです。 

入力は、列の数、サイズ 1×1 ～ 4×4 の 4 つのコスト、および行列の 4 つの行を提供します。 出力は、最小コインコストを表す単一の整数です。 

_n_ が最大 1000 であることを考えると、考えられるすべての部分行列を単純に検査するアルゴリズムは遅すぎます。 正方部分行列の総数は O(n × 16) に増加し、4×4 の正方形では管理できるように見えますが、部分行列の最適なセットのすべての組み合わせを試みると、指数関数的な複雑さに遭遇します。 したがって、列を効率的に処理しながら、少数の固定行数 (4) を活用するには、動的プログラミングまたはビットマスク ベースのアプローチが必要です。 

エッジ ケースには、1 つの列に複数のアスタリスクが含まれる状況が含まれますが、4×4 または 3×3 の正方形は、小さな部分行列を個別にクリアするよりもコストがかかる可能性があります。 もう 1 つの微妙なシナリオは、大きな正方形の重なりが最小限であり、慎重なコスト選択が重要になる場合です。 たとえば、最初の列がすべてアスタリスクで残りが空の場合、列 1 ～ 4 をカバーする 4×4 の正方形は 1×1 を 4 回クリアするよりもコストがかかる可能性があるため、アルゴリズムはすべての可能性を考慮する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、すべてのアスタリスクをクリアするために正方形のすべての組み合わせを列挙し、それぞれの合計コストを計算し、最小のものを選択しようとします。 これはすべての可能性を評価するため正しいですが、その複雑さは _n_ において指数関数的であり、実行不可能です。 

重要な点は、行数が 4 に固定されていることです。これは、各列を 4 ビットの数値としてエンコードすることを示唆しています。各ビットは、この列の行にアスタリスクが含まれるかどうかを表します。 このエンコーディングを使用すると、最大 4 列のセグメントを 4 ビット整数のタプルとして表すことができます。 これにより、1×1 ～ 4×4 の正方形で連続する 1 ～ 4 列をクリアするすべての方法を事前計算し、それらをクリアするための最小コストを計算することができます。 

その後、列に沿って動的プログラミングを使用できます。 させて`dp[i]`最初のクリアにかかる最小コストであること`i`列。 計算するには`dp[i]`では、最後の 1 ～ 4 列を調べ、列セグメントごとに事前に計算されたコストを使用して、それらを正方形で最適に覆うために考えられるすべての方法を試します。 これにより、列ごとに 16 個の 4 ビット マスクが可能なため、小さな定数係数を使用して、問題が _n_ の指数関数から線形に軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(4n)) | お(1) | 遅すぎる |
 | ビットマスク付きの DP | O(n × 2^4 × 2^4 × 4) ≈ O(n) | O(2^4 × 4) ≈ O(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 4x_n_ 行列の各列を 4 ビット整数に変換します。ここで、各ビットはその行内のアスタリスクの存在を表します。 たとえば、一番上の行は最上位ビットです。 
2. 幅 1 ～ 4 の列の任意の組み合わせをクリアするための最小コストを事前計算します。セグメントごとに、そのセグメント内のすべてのアスタリスクをカバーする 1×1 ～ 4×4 の正方形のすべての可能な配置を生成し、最小コストを保存します。 行数が 4 であるため、列ごとの一意のマスクの総数は 16 であり、最大 4 列のセグメントから管理可能な数の組み合わせが得られます。 
3. 動的プログラミング配列を初期化する`dp`サイズの`n+1`どこ`dp[i]`最初のクリアに必要な最小限のコストを格納します`i`列。 セット`dp[0] = 0`ゼロ列のクリアには費用がかからないためです。 
4. 1 から _n_ までの列を繰り返します。 ポジションごとに`i`、最後の 1 ～ 4 列をセグメントとして取得することを検討してください。 そのセグメントをクリアするために事前に計算された最小コストを取得し、更新します`dp[i]`として`dp[i] = min(dp[i], dp[i-k] + cost_segment)`、 どこ`k`セグメント幅 (1 ～ 4) です。 
5. すべての列を処理した後、`dp[n]`マトリックス全体をクリアするための最小限のコストが含まれています。 

機能する理由: 各 DP 状態は、アスタリスクを最適にクリアできるすべての方法をカバーしながら、最大 4 列の可能な最後のセグメントをすべて考慮します。 各状態はより小さな部分問題に基づいて構築され、すべてのオプションが評価されるため、アルゴリズムは最小の総コストを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))
rows = [input().strip() for _ in range(4)]

# convert each column into a 4-bit mask
col_masks = []
for j in range(n):
    mask = 0
    for i in range(4):
        if rows[i][j] == '*':
            mask |= 1 << i
    col_masks.append(mask)

# Precompute cost to clear a segment of up to 4 columns
from functools import lru_cache

# minimal cost to clear a 4x4 submatrix with given masks
@lru_cache(None)
def min_cost(segment):
    length = len(segment)
    if length == 0:
        return 0
    res = float('inf')
    for k in range(1, min(4, length)+1):  # width of square horizontally
        for top in range(4 - k + 1):  # vertical position of square
            new_segment = list(segment)
            for dx in range(k):
                for dy in range(k):
                    if dx < length:
                        new_segment[dx] &= ~(1 << (top + dy))
            cost = a[k-1] + min_cost(tuple(new_segment[k:]))
            res = min(res, cost)
    # also consider clearing single columns individually
    for i in range(length):
        if segment[i]:
            cost = a[0] + min_cost(tuple(segment[:i] + (0,) + segment[i+1:]))
            res = min(res, cost)
    return res

dp = [0] + [float('inf')] * n
for i in range(1, n+1):
    for k in range(1, min(4, i)+1):
        segment = tuple(col_masks[i-k:i])
        dp[i] = min(dp[i], dp[i-k] + min_cost(segment))

print(dp[n])
```このソリューションは、まず列をビットマスクにエンコードし、次に最大 4 列のセグメントをクリアするための最小コストを再帰的に計算します。 列に対する DP により、すべてのパーティションが効率的に考慮されます。 ビット操作とメモ化を注意深く使用することで、最適な配置を見逃すことなく、重なり合うすべての正方形を処理します。 正方形のサイズより短いセグメントなどの境界条件は、制限することで正しく処理されます。`k`。
