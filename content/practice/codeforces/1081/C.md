 ## 解決策
 ## 問題の理解

 私たちは線を描いています$n$レンガ、各レンガは次のいずれかを選択します$m$利用可能な色。 塗装が完了したら、前のレンガと比べて色が変わった位置を観察します。 正式には、左から右にスキャンしてインデックスの数を数えます。$i \ge 2$満足する$a_i \ne a_{i-1}$。 そのカウントは正確である必要があります$k$。 

タスクは、シーケンス全体の完全な色が正確に何回生成されるかを数えることです。$k$そのような「変化点」を計算し、結果をモジュロで返します。$998244353$。 

構造を解釈する便利な方法は、配列が同じ色の連続したブロックに分割されていると考えることです。 変化点があるたびに、新しいブロックが始まります。 それで、もしあれば$k$色が前の色と異なる位置の場合、配列は正確に構成されます$k+1$モノクロセグメント。 

制約$n, m \le 2000$と提案する$O(n^2)$または$O(n^2 m)$動的プログラミングのアプローチはもっともらしいですが、すべての色で指数関数的なものは直ちに実行不可能です。$m^n$、中程度の人でも成長が速すぎます$n$。 

微妙なエッジケースが現れるのは、$k = 0$。 この状況では、すべてのレンガが同じ色を共有する必要があり、正確に結果が得られます。$m$有効な構成。 もう一つの境界ケースは、$k = n-1$、隣接するすべてのペアが異なるため、色の厳密な変更が強制され、遷移が大幅に制限されますが、色に応じて複数の選択肢が可能になります。$m$。 

単純な間違いは、それぞれを扱うことです。$k$独立して位置を変更できますが、制約はグローバルです。一度色を選択すると、その後の選択は前の色に依存するため、独立性の仮定は崩れます。 

## アプローチ

 ブルートフォースソリューションでは、すべてが列挙されます。$m^n$色を塗って正確に何個あるか数えます$k$トランジション。 これは概念的には簡単です。すべての配列を生成し、その配列の変更をカウントします。$O(n)$、全体的に複雑になります$O(n m^n)$。 これはすぐに失敗します。$m=2, n=2000$天文学的に大きいです。 

重要な観察は、構造がセグメントを継続するか新しいセグメントを開始するかによってのみ依存するということです。 完全な着色履歴を追跡する必要はなく、前のレンガの色と、これまでに発生した遷移の数だけを追跡する必要があります。 これにより、当然のことながら、ポジションに対する動的プログラミングが行われます。 

させて$dp[i][j]$最初に色を付ける方法の数になります$i$まさにそのようなレンガ$j$移行が発生しました。 レンガを置くとき$i$では、前の色と一致させるか (新しいトランジションなし)、別の色を選択します (新しいトランジションが 1 つあります)。 重要な点は、「異なる色」の場合には、$m-1$以前の色が何であったかに関係なく選択できるため、実際の色の値への依存を解消できます。 

これにより、問題はフルカラー状態の追跡から遷移数の追跡のみに軽減されます。

 | ブルートフォース |$O(m^n \cdot n)$|$O(n)$| 遅すぎる |
 | DP オーバートランジション |$O(nk)$|$O(nk)$| 承認済み |

 ## アルゴリズムのチュートリアル

 DP テーブルを定義します。$dp[i][j]$最初の色を付ける方法の数を表します$i$正確にレンガ$j$トランジション。 

1. 最初のブリックの基本ケースを初期化します。 がある$m$色を付ける方法があり、トランジションが発生していないため、$dp[1][0] = m$。 有効なカラーリングはすべて、何らかの色の選択から始まる必要があります。 
2. ポジションごとに$i$から$2$に$n$、すべての有効な構成を次から拡張することを検討します。$i-1$。 
3. レンガを割り当てる場合$i$レンガと同じ色$i-1$の場合、トランジションの数は変わりません。 カウントされるすべての構成について$dp[i-1][j]$、トランジション数を増やさずに拡張する方法が 1 つだけあり、これが貢献します。$dp[i-1][j]$に$dp[i][j]$。 
4. レンガを割り当てる場合$i$レンガとは違う色$i-1$、次にトランジション数を 1 増やします。前の色は固定されているため、正確に$m-1$新しい色の有効な選択肢。 これは貢献します$(m-1) \cdot dp[i-1][j-1]$に$dp[i][j]$。 
5. 以下の状態までのすべての状態を計算します。$dp[n][k]$、これが最終的な答えです。 

再発は次のとおりです。$$dp[i][j] = dp[i-1][j] + (m-1)\cdot dp[i-1][j-1]$$無効なインデックスは慎重に処理してください。 

### なぜ効果があるのか

 部分的なカラーリングは、将来の拡張目的のために、すでに発生した遷移の数と最後の色が何であるかという 2 つの情報によって完全に特徴付けられるため、DP 状態で十分です。 すべての色は対称であり、異なる色に切り替えると常に正確な結果が得られるため、最後の色の依存関係は遷移式ではなくなります。$m-1$選択肢。 この対称性により、最後のすべての色を集計しても情報が失われず、構成が二重にカウントされなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

n, m, k = map(int, input().split())

# dp[j] = ways for current prefix with j transitions
dp = [0] * (k + 1)

# base: first brick, 0 transitions, m choices
dp[0] = m

for i in range(2, n + 1):
    ndp = [0] * (k + 1)
    for j in range(0, k + 1):
        # same color transition count unchanged
        ndp[j] = (ndp[j] + dp[j]) % MOD

        # different color increases transitions
        if j + 1 <= k:
            ndp[j + 1] = (ndp[j + 1] + dp[j] * (m - 1)) % MOD

    dp = ndp

print(dp[k])
```各レイヤーは前のレイヤーのみに依存するため、実装では DP が 1 次元に圧縮されます。 重要な点は、両方の遷移が以前の同じ状態から適用されるため、インプレースで更新してはいけないということです。そうしないと、同じ反復内で将来の状態が汚染されてしまいます。 

基本の初期化`dp[0] = m`最初のレンガがその色を自由に選択するという事実を捉えています。 後続のすべてのステップは、実際の色の識別を追跡する必要なく、これに基づいて構築されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    MOD = 998244353
    n, m, k = map(int, input().split())

    dp = [0] * (k + 1)
    dp[0] = m

    for i in range(2, n + 1):
        ndp = [0] * (k + 1)
        for j in range(k + 1):
            ndp[j] = (ndp[j] + dp[j]) % MOD
            if j + 1 <= k:
                ndp[j + 1] = (ndp[j + 1] + dp[j] * (m - 1)) % MOD
        dp = ndp

    return str(dp[k])

# provided samples
assert run("3 3 0") == "3"

# custom cases
assert run("1 5 0") == "5", "single brick all colors"
assert run("2 2 1") == "2", "must differ once"
assert run("4 1 0") == "1", "only one color available"
assert run("4 3 3") == "6", "maximum transitions"

 ## 特殊なケース

 のために$n=1$、可能な遷移はないため、答えは常に次のようになります。$m$いつ$k=0$そして$0$さもないと。 位置をめぐるループは実行されず、基本状態は変更されないため、DP はこれを暗黙的に処理します。 

のために$m=1$、すべてのレンガは同じ色でなければなりません。 有効な構成は遷移がゼロの場合のみです。 DP用語で言えば、$m-1 = 0$, したがって、トランジションを作成するすべてのパスが消え、唯一残ります。$dp[n][0] = 1$、それは正しいです。 

のために$k = n-1$、隣接するすべてのペアは異なっていなければなりません。 DP は、各ステップが次のように乗算されるチェーンを強制します。$m-1$、 その結果$m \cdot (m-1)^{n-1}$これは、最初の色を自由に選択し、常に前の色を避けるという組み合わせの解釈と一致します。
