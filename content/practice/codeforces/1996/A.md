 ## 問題の理解

 農場には鶏と牛だけがいて、農夫のジョンは合計で鶏と牛を数えています。`n`足。 鶏はそれぞれ 2 本の脚を提供し、牛はそれぞれ 4 つの脚を提供します。 この質問では、足の総数と一致する動物の最小数を尋ねます。 基本的には配布しています`n`動物の合計を最小限に抑えながら、脚を 2 つと 4 つのグループに分けます。 

入力は複数のテスト ケースです。 各テスト ケースは単一の偶数整数です`n`カウントされた脚の合計を表します。 出力はテスト ケースごとに 1 つの整数です。つまり、正確に生成できる動物の最小数です。`n`足。 

制約は小さいです。`n`2000年までは`t`は 1000 までです。`n`が有限である、線形演算を含む任意の解`n`テスト ケースごと (O(n)) は 1 秒以内に快適に実行されます。 私たちも知っています`n`は常に偶数であるため、一部の特殊なケースが簡素化されます。奇数の脚の合計を処理する必要はありません。 

エッジケースが発生するのは次のような場合です`n`とても小さいです、みたいな`2`。 その場合、技術的には合計すると動物の組み合わせが複数あるとしても、唯一の可能性は 1 羽のニワトリです。`n`大きな例では脚。 もう 1 つの微妙な点は、牛の数を最大化すると最小の動物数が発生することです。これは、各牛が 1 頭あたりより多くの脚を提供し、総数が減少するためです。 不注意なアプローチでは、最初にすべての脚をニワトリに分割しようとし、多くの動物が生成される可能性があります。 

## アプローチ

 ブルートフォースアプローチは、0 から 0 までのすべての可能な牛の数を反復処理することです。`n//4`、ニワトリの残りの足を計算し、最小の動物の合計を追跡します。 これは、実行可能なすべての組み合わせを列挙しているため、正しいです。 操作の数は次のように比例します。`n//4`テストケースごとに。 と`n`2000 年までは、これはテスト ケースごとに約 500 回の反復であり、制約を考慮すると許容範囲ですが、解は数学的に表現できるため不要です。 

重要な洞察は、動物の数を最小限に抑えることは牛の数を最大限に増やすことと同じであるということです。 各牛に 4 本の足があり、各鶏に 2 本の足がある場合、まず、上限を超えない範囲でできるだけ多くの牛を割り当てます。`n`。 残りの脚はニワトリに割り当てられます。 代数的に言うと、`n`が偶数である場合、動物の最小数は`n // 4`牛プラス`(n % 4) / 2`鶏。 以来`n`均等です、`(n % 4)`は 0 または 2 なので、除算では常に整数が得られます。 これにより、問題がテスト ケースごとの単純な算術計算に変換されます。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、脚の合計数を読み取ります。`n`。 以来`n`が均等であることが保証されているので、分数を気にせずに安全に 2 または 4 で割ることができます。 
2. 牛の最大頭数を次のように計算します。`n // 4`。 牛は1頭あたり4本の足を使用するため、可能な限り多くの牛を使用すると、残りの頭数が減ります。 
3. 残りの脚を次のように計算します。`n % 4`。 なぜなら`n`は偶数です。これは 0 または 2 のいずれかです。 
4. 残りの脚はニワトリに割り当てられます。 鶏には足が2本あるので、鶏の数は`(n % 4) // 2`。 
5. 牛と鶏の数を加算して、動物の最小数を求めます。 
6. 各テスト ケースの結果を出力します。 

これが機能する理由: 不変条件は、4 本足の動物の最大数が常に最小の動物の総数を生み出すということです。 牛の数が減れば、同じ足の総量を満たすためにより多くの鶏が必要となり、動物の総数は増加します。 なぜなら`n`が偶数である場合、牛を割り当てた後に残った脚は常に 2 で割り切れるため、鶏の計算は正確になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    cows = n // 4
    chickens = (n % 4) // 2
    print(cows + chickens)
```このコードでは、`n // 4`牛の最大頭数を決定し、`(n % 4) // 2`残りの鶏を決定します。 モジュロと整数の除算はすべて偶数を処理するため、ループや条件は必要ありません。`n`。 使用する`sys.stdin.readline`複数のテスト ケースの高速入力を保証します。

 ## 特殊なケース

 最小の入力 n=2 の場合、アルゴリズムは次のように計算します。`0`牛と`1`鶏、正しく 1 匹の動物が得られます。 n=6 など、4 で割り切れないが偶数の n については、牛 1 匹と鶏 1 匹を割り当てます。これは鶏 3 匹より動物が少なく、牛を最大化すると動物の総数が減ることがわかります。 n=2000 のような大きな n の場合、整数の除算とモジュロ演算は正確かつ高速なままです。 このアルゴリズムは、特別なケースを使用せずに、許可された範囲内のすべての偶数 n を処理します。
