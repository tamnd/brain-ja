 ## 解決策
 ## 問題の理解

 2 つの配列に対する一連の操作でスコアを最大化するように求められます。 各配列には長さがあります$n$。 配列$a$各要素の現在の「値」を表し、配列$b$使用後にその要素がどれだけ劣化するかを表します。 1 回の操作でインデックスを選択します$i$、 追加$a_i$私たちのスコアに合わせて減算します$a_i$による$b_i$、それを非負に保ちます。 まさに$k$合計スコアを最大化するための操作。 

制約は重要です。$n$到達できる$2 \cdot 10^5$、 そして$k$まで可能です$10^9$。 各操作を個別にシミュレートする単純なソリューションは、何十億もの操作が必要になる可能性があるため、明らかに実行不可能です。 このため、多くの操作を 1 つずつ実行するのではなく、一度に飛び越える方法を見つける必要があります。 

エッジケースが発生するのは次の場合です$b_i \ge a_i$ある要素については、その要素は最大 1 回しか貢献できないためです。 同様に、$k$に比べて非常に大きい$n$、同じ要素に繰り返し操作を適用する必要があり、減衰パターンが重要です。 たとえば、次のように考えてみましょう$a = [1, 1]$、$b = [2, 3]$、$k = 3$。 最大スコアは$2$、 ない$3$これは、最初の操作後に両方の要素がゼロに達するためです。 減衰を追跡しない単純な貪欲なアプローチは過大評価になります。 

## アプローチ

 ブルートフォース手法は簡単です。$k$操作では、配列をスキャンして現在の最大値を持つ要素を見つけ、それをスコアに追加して、その要素を更新します。 これは正しいですが、次のことが必要です$O(n \cdot k)$時間。 と$n \le 2 \cdot 10^5$そして$k \le 10^9$、これは意味するかもしれません$10^{14}$これは許容範囲をはるかに超えています。 

重要な観察は、各要素が次のように直線的に減衰することです。$m$要素の用途$i$、その値は$\max(0, a_i - m \cdot b_i)$。 この線形構造により、各要素を使用する価値のある最大回数を計算できます。 具体的には、要素を初めて使用するときに、$a_i$。 次回も貢献します$a_i - b_i$、 それから$a_i - 2b_i$、など、ゼロになるまで続きます。 このシーケンスは算術演算であるため、各減分を繰り返すのではなく、すぐに合計することができます。 

操作を効率的に選択する賢い方法は、次の寄与が現在最大である要素を繰り返し選択することです。 毎回配列をスキャンすることを避けるために、要素を次の基準で並べ替えることができます。$a_i$そして$b_i$貢献度の高い要素を最初に処理し、非常に大規模な要素を処理できるようにする方法$k$、各要素がプラスに寄与する回数を計算することで、各要素を選択する回数をバッチ処理できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n・k) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を読み取る$a$そして$b$、および操作の数$k$。 それぞれペアリングする$a_i$それに対応するもの$b_i$。 
2. ペアを並べ替えます$b_i$減衰が遅い要素を最初に処理するか、他のヒューリスティックによって初期寄与が高く減衰が小さいことを優先します。 
3. 各要素について、ゼロに達するまでに使用できる最大回数を計算します。つまり、$m_i = \min(k, \lceil a_i / b_i \rceil)$もし$b_i > 0$、 さもないと$m_i = k$もし$b_i = 0$。 
4. この要素からの寄与の算術シーケンスの合計を加算します。$\text{sum}_i = m_i \cdot a_i - b_i \cdot \frac{m_i (m_i - 1)}{2}$。 
5. 減算$m_i$残りの操作から$k$。 もし$k = 0$、早めにやめてください。 
6. 貢献度を合計して合計スコアにします。 

機能する理由: 線形減衰により、各要素は厳密に減少するステップで寄与します。 各要素の正の寄与の合計を計算することで、各操作をシミュレートすることなく合計寄与を取得します。 並べ替えにより、全体的に最も寄与する要素が最初に処理されるようになり、各ステップで次に大きな寄与が選択されるため、全体的に最適なスコアが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        items = list(zip(a, b))
        # Sort by initial value descending to greedily pick highest first
        items.sort(reverse=True, key=lambda x: x[0])
        total = 0
        remaining_ops = k
        for val, dec in items:
            if remaining_ops == 0:
                break
            if dec == 0:
                total += val * remaining_ops
                remaining_ops = 0
                break
            max_use = min(remaining_ops, (val + dec - 1) // dec)
            total += max_use * val - dec * max_use * (max_use - 1) // 2
            remaining_ops -= max_use
        print(total)

if __name__ == "__main__":
    solve()
```解決策の最初のペア$a$そして$b$そして並べ替え$a_i$初期値が高いことを優先します。 ゼロによる除算を避けるために、ゼロ減衰を個別に処理します。 等差級数の公式は、繰り返しの寄与を効率的に合計します。 全部使ったら早めにやめる$k$操作。
