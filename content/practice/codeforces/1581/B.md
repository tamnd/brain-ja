 ## 解決策
 ## 問題の理解

 与えられたノード数で単純な接続された無向グラフを構築できるかどうかを判断するように求められます。`n`そしてエッジ`m`グラフの直径が厳密に以下になるように`k-1`。 グラフの直径は、2 つのノード間の最大距離であり、距離はそれらを接続するパス上のエッジの最小数として測定されます。 自己ループや複数のエッジは許可されません。 

入力は複数のテスト ケースで構成されます。 各テスト ケースでは次の値を指定します。`n`、`m`、 そして`k`。 それぞれについて、これらの条件を満たすグラフを構築できる場合は「YES」、不可能な場合は「NO」を出力する必要があります。 

制約を考慮すると、`n`そして`m`まで可能です$10^9$まであります$10^5$テストケース。 これは、グラフを明示的に構築したり、スケールに応じた操作を実行したりできないことを意味します。`n`または`m`。 代わりに、ノード、エッジ、必要な直径の数に基づいて何が可能かを数学的に推論する必要があります。 

エッジケースが発生するのは次の場合です`n`とても小さいです。 もし`n = 1`、唯一の有効なグラフにはエッジがなく直径 0 があり、次の値を満たす可能性があります。`k`。 もし`k = 1`、必要な直径は 0 未満であり、これは不可能です。 いつ`m = 0`の場合、グラフは切断されます。`n > 1`。 このような状況では、単純にカウントすると不正確な結果が生じる可能性があります。 

## アプローチ

 ブルートフォースアプローチは、グラフを明示的に構築し、その直径をチェックしようとすることです。 小型用`n`、考えられるすべてのエッジの組み合わせを試して、直径を測定することができます。 これは小さな入力では機能しますが、完全に失敗します。`n`そして`m`の命令で$10^9$なぜなら、隣接リストを構築するだけでも膨大な時間とスペースが必要になるからです。 

重要な洞察は、接続されたグラフ内のエッジの最小数と最大数は次のとおりであるということです。`n`ノードは既知です。 接続されたグラフには少なくとも`n-1`エッジ。 ループまたは複数のエッジを持たないエッジの最大数は次のとおりです。$\frac{n(n-1)}{2}$。 

直径の制約により、可能性はさらに制限されます。 厳密に小さい直径`k-1`は次のように解釈できます。 

- もし`k = 1`、直径は 0 でなければなりません。これは次の場合にのみ可能です。`n = 1`。 
- もし`k = 2`、直径は 1 未満である必要があります。つまり 0 です。これもまた必要です。`n = 1`。 
- のために`k >= 3`、接続されたグラフの直径は 1 から 1 までの間です。`n-1`。 星グラフの直径は 2、チェーンの直径は`n-1`。 

これで、完全に数学的に推論できるようになりました。グラフは接続されている必要があります (`m >= n-1`)、エッジの数は完全なグラフ (`m <= n(n-1)/2`）、 そして`k`～に追加の制限を課す`n`。 これらの条件は、各テスト ケースに O(1) 時間で答えるのに十分です。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`、`m`、`k`。 
3. 些細な不可能性を最初に処理します。`n = 1`、グラフの直径は 0 です。これは、次の場合に直径制約を満たします。`k > 1`そして`m = 0`。 そうでなければ不可能です。 
4. もし`n = 2`、グラフには 0 または 1 つのエッジがあります。 エッジがある場合は直径が 1、エッジがない場合は 0 になります。 これが満たされているかどうかを確認してください`k-1`。 
5. のために`n >= 3`, the graph must be connected. それで`m >= n-1`。 もし`m < n-1`、「NO」を出力します。 
6. 可能なエッジの最大数は次のとおりです。$\frac{n(n-1)}{2}$。 もし`m > n(n-1)/2`、「NO」を出力します。 
7. 直径要件は次によって異なります。`k`。 星形グラフ`n >= 3`直径は 2 です。したがって、次のようになります。`k = 1`、それは不可能です。 もし`k = 2`、直径 1 を持つことができるのは完全なグラフだけです。`m`等しい必要があります`n(n-1)/2`。 さもないと、`k >= 3`限り常に達成可能です`n >= 3`そして`m`は有効な範囲内です。 
8. すべての条件を満たしている場合は、「YES」を出力します。 それ以外の場合は「NO」を出力します。 

機能する理由: このアルゴリズムは、接続されたグラフの数学的特性と標準構造 (チェーン、スター、完全) の既知の直径に依存しています。 各チェックは不可能制約に直接対応します。 カウントと境界について推論するだけなので、実際のグラフ構築は必要ありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        if n == 1:
            print("YES" if m == 0 and k > 1 else "NO")
            continue
        if n == 2:
            if m > 1 or m < 1:
                print("NO")
            else:
                print("YES" if k > 1 else "NO")
            continue
        min_edges = n - 1
        max_edges = n * (n - 1) // 2
        if m < min_edges or m > max_edges or k == 1:
            print("NO")
        elif k == 2:
            print("YES" if m == max_edges else "NO")
        else:
            print("YES")

if __name__ == "__main__":
    main()
```このソリューションでは、まず、エッジ数と直径の要件が特殊な場合の最小のグラフを処理します。 次に、接続されたグラフの最小エッジと最大エッジを計算し、スターおよび完全なグラフ構造に基づいて直径ロジックを直接適用します。 これにより、テスト ケースごとに O(1) が保証されます。

 ## 特殊なケース

 のために`n = 1, m = 0, k = 2`の場合、アルゴリズムは YES を返します。 小切手`n == 1`この特殊なケースは、一般的な公式に依存せずに確実に処理されます。
