 ## 解決策
 ## 問題の理解

 この本は連続した章に分かれています。 各章は連続した範囲のページを占め、すべてのページは 1 つの章にのみ属します。 

Nastya はすでにページを読みました`1`を通して`k - 1`。 ページ`k`それは彼女がまだ読んでいない最初のページです。 完全に完了していない章が何章あるかを判断する必要があります。 

章は 2 つの状況で未完了としてカウントされます。 Nastya がまったく開始していないか、その中のどこかで停止して最後のページに到達していないかのどちらかです。 

章の範囲は順番に示されており、重複しません。 章は連続して本をカバーしているため、ページが含まれる章を見つけたら、`k`、それ以降の各章は未完成です。 それより前の章はすでにすべて読まれています。 

制約は非常に小さいです。 チャプタは最大 100 個あるため、すべてのチャプタをざっとざっと見てみるだけでも十分に高速です。 高度なデータ構造や検索テクニックは必要ありません。 

微妙なケースが発生する場合`k`まさに章の最初のページです。 

例：```
3
1 3
4 7
8 10
4
```ページ`4`第二章に属します。 第一章は読み終えましたが、第二章はまだ始まっていません。 答えは`2`、 ない`1`。 

もう 1 つの見落としやすいケースは次のような場合です。`k`章の最後のページです。```
3
1 3
4 7
8 10
7
```ページの第 2 章はまだ未完成です。`7`まだ読まれていません。 答えは`2`。 

不用意な解決策は、最後のページに到達するとその章が完了したことを意味すると考えるかもしれませんが、ページは`k`それ自体は読まれていません。 

可能な限り最小の入力にも注意が必要です。```
1
1 1
1
```唯一の章にページが含まれています`1`、未読です。 正しい答えは、`1`。 

## アプローチ

 強引な解釈は、ページごとに読むことをシミュレートすることです。 どのページが読まれたかを判断し、各章を調べて、その章のすべてのページが読まれたかどうかを確認できます。 各章には最大 100 ページが含まれ、章の数も最大 100 であるため、最大で約 10,000 ページのチェックが必要になります。 このような制約の下では、それさえも受け入れられるでしょう。 

問題の構造により、もっと単純なことが可能になります。 

最後のページが厳密に次のページよりも小さい場合、章は完全に読み取られています。`k`。 ページを含む範囲の章に遭遇した瞬間`k`、または終了ページが少なくとも`k`、その章は未完成です。 ナスティアが到達できなかったため、以降の各章も未完成です。 

これは、間隔にページが含まれる最初の章を見つけるだけでよいことを意味します。`k`。 その章に索引がある場合`i`(ゼロベースのインデックスを使用)、その後、次のすべての章`i`を通して`n - 1`は未完了であり、次のような答えが返されます。`n - i`。 

1 回のリニア スキャンで十分です。

 ## アルゴリズムのチュートリアル

 1. 章数を読む`n`。 
2. すべてのチャプター間隔を保存する`(l, r)`。 
3. ページ番号を読みます`k`、これは最初の未読ページです。 
4. 章を左から右にスキャンします。 
5. 章ごとに、次のことを確認します。`k`ページ範囲内にあるということは、`l ≤ k ≤ r`。 
6. そのような章が見つかるとすぐに、残りの章の数を出力します。`n - current_index`。 
7. 以降の章もすべて未完了であるため、すぐに中止してください。 

### なぜ効果があるのか

 章は、連続した重複しないページ範囲を形成します。 ページ以来`k`最初の未読ページ、その前のすべてのページです`k`はすでに読まれています。 

前に終了する章`k`完全に終わっています。 ユニークな章には、`k`ページが未完成であるため、`k`それ自体は読まれていません。 ナスティアがそれらのページに到達しなかったため、それ以降の各章も未完成です。 

したがって、答えは正確に、を含む章から始まる章の数になります。`k`本の最後まで。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

chapters = []
for _ in range(n):
    l, r = map(int, input().split())
    chapters.append((l, r))

k = int(input())

for i, (l, r) in enumerate(chapters):
    if l <= k <= r:
        print(n - i)
        break
```最初の部分はチャプタ範囲を読み取って保存します。 

読んだ後`k`、ソリューションは線形スキャンを実行します。 間隔は連続していて重複しないため、ちょうど 1 つの章にページが含まれます。`k`。 

そのチャプタがその位置で見つかった場合`i`、答えは`n - i`。 これは、現在のチャプタとその後のすべてのチャプタをカウントします。 

最も一般的な実装ミスは、ページ周りの off-by-one エラーです。`k`。 そのページを思い出してください`k`まだ**読まれていません**。 を含む章`k`たとえまだ未完成だとしても、`k`たまたまその章の最後のページです。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    n = int(input())

    chapters = []
    for _ in range(n):
        l, r = map(int, input().split())
        chapters.append((l, r))

    k = int(input())

    for i, (l, r) in enumerate(chapters):
        if l <= k <= r:
            return str(n - i) + "\n"
