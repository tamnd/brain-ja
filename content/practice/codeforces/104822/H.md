 ## 解決策
 ## 問題の理解

 大きなグリッドが与えられています。$n$行と$m$各セルには 0 または 1 が含まれている必要があります。連続するブロック内にどの行にもどの列にも 3 つの同一の値が含まれていない場合、グリッドは有効であるとみなされます。 言い換えれば、水平方向または垂直方向のパターンを見ることは禁止されています。$000$または$111$マトリックスのどこにでも。 

タスクはグリッドを構築することではなく、この制約の下でグリッドを有効に保ちながら配置できる 1 の最大数を決定することです。 

制約は非常に大きく、両方の次元が最大です。$10^9$そして最大まで$10^5$テストケース。 これにより、グリッドを明示的に構築またはシミュレートするアプローチは即座に除外されます。 テストケースごとの線形時間も$n$または$m$不可能です。 解決策は、構造的推論から導き出される直接的な公式でなければなりません。 

素朴な直観では、行を個別に扱い、3 つの連続する行を避けながら各行の行を最大化しようとするでしょう。 ただし、列を考慮すると、これはすぐに矛盾します。 各行で有効なパターンでも、行全体で不注意に繰り返されると、列内で中断される可能性があります。 

各行を次のようなものとして貪欲に構築しようとすると、よくある失敗例が発生します。$110110...$。 各行は有効ですが、同一の行を積み重ねると同一の値で埋められた列が作成され、垂直方向に長いランが生成され、直ちにルールに違反します。 これは、水平制約と垂直制約が密接に結合していることを示しています。 

もう 1 つの微妙な落とし穴は、市松模様のような交互パターンが最適であると想定していることです。 有効ではありますが、達成されるのは密度だけです$1/2$、長さ 2 のランの許容値を最大限に活用しません。 

## アプローチ

 私たちは一次元の視点から始めます。 単一行では、制約により、連続する 3 つの等しいビットが禁止されます。 このルールに基づいて値を最大化する最良の方法は、パターンを繰り返すことです。$110$。 これにより、3 のブロックごとに 2 つの 1 が実現されます。これは最適です。なぜなら、長さ 3 のウィンドウに 3 つの 1 を配置しようとする試みは禁止されており、ゼロを 1 に置き換えると、禁止されたトリプルが作成される危険がただちにあるからです。 

同じロジックが列にも適用されます。 ただし、垂直方向の一貫性により長い定数列が作成されるため、すべての行にわたって最適な行を独立して繰り返すだけでは失敗します。 

重要な観察は、制約が完全にローカルであるということです。つまり、長さ 3 のランのみが問題となります。 これは、両方向で同時に有効な周期的構造を使用することを示唆しています。 禁止パターンも長さ 3 であるため、試行すべき自然な周期は 3 です。 

拠点を構築します$3 \times 3$すべての行と列で同時に最適な密度を達成するブロック:

 行0: 110

 行 1: 101

 行 2: 011

 各行は次の循環シフトです。$110$。 このパターンを水平方向に拡張すると、行内に 3 つ等しくない条件が保存されます。 垂直方向に、各列は次の循環シフトになります。$110$、$101$、 または$011$, そのため、列も 3 つの同一の値が連続することを避けます。 

この構造では、9 セルごとに正確に 6 個の 1 が実現されます。これは、密度が高いことを示唆しています。$2/3$。 この周期構造によりグリッドがタイル状に並べられているため、任意の領域に同じ密度が広がります。$n \times m$境界に無効なトリプルを導入することなくグリッドを作成します。 

最後のステップは、この密度を超える建築物は存在できないことを認識することです。 有効な配置では、行または列内の 3 つの連続するセルの各ブロックに最大 2 つのセルを含めることができます。 このグローバルな制限により、達成可能な密度の上限が決まります。$2/3$、そして周期的な構造はそれと完全に一致します。

 ## アルゴリズムのチュートリアル

 最適な周期パターンの構造から直接答えを導き出します。 

1. すべての有効な行または列に、連続する 3 つの等しい値を含めることはできないことに注意してください。 これは、長さが 3 の任意のウィンドウで、セルを最大化しようとすると、最大で 2 つのセルが 1 になる可能性があることを直ちに意味します。 これにより、ハード密度の上限は次のようになります。$2/3$。 
2. 長さ 3 のパターンを繰り返すだけで、1 次元の制約を満たすのに十分であることを認識します。 パターン$110$単一行に最適です。 
3. 3 周期グリッドを構築して、このアイデアを 2 次元に拡張します。 3 つの行テンプレートを循環シフトとして定義します。$110$:$110$、$101$、 そして$011$。 
4. これら 3 つのテンプレートの繰り返しサイクルで行を割り当てます。 これにより、垂直スライスもこれらと同じ安全なパターンを繰り返すことが保証され、列が禁止されたトリプルを形成するのを防ぎます。 
5. この構造内の 1 の数を数えます。 すべてのブロック$3 \times 3$ちょうど 6 個のものが含まれているため、密度は一貫しています。$2/3$。 したがって、どのような場合でも、$n \times m$、1 の合計数は$\left\lfloor \frac{2nm}{3} \right\rfloor$、この構造では常に正確です。 

### なぜ効果があるのか

 正しさは、任意の行または列内の長さ 3 のすべての連続セグメントがマルチセットの回転であるという不変条件から得られます。$\{1,1,0\}$。 これにより、どのセグメントも次のような状態にならないことが保証されます。$000$または$111$。 両方の次元は同じ循環構造から構築されているため、このプロパティは行または列内でローカルに保持されるだけでなく、グローバルに保持されます。 

また、この構造では、どこでも 3 つのセルごとに 2 つの 1 というローカルな上限が飽和するため、何らかの方向の制約に直ちに違反しない限り、追加の 1 を挿入することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        print((2 * n * m) // 3)

if __name__ == "__main__":
    solve()
```実装では、派生した式が直接適用されます。 Python では任意精度の整数を使用できるため、最大の値であっても乗算は安全です。$10^9$。 整数を 3 で割ると、前に確立した構造限界の下で達成可能な 1 の正確な最大数が得られます。 

重要な単純化は、幾何学的な組み合わせ構造全体が 1 つの不変条件に帰着することです。整列した 3 つのセルの各グループは、最大 2 つのセルに寄与でき、この境界は厳密です。

 ## 特殊なケース

 のために$3 \times 3$グリッドの場合、アルゴリズムは 6 を返します。この構築により、グリッドが繰り返しパターンで正確に埋められます。$110 / 101 / 011$、すべての行と列は、3 つの同一の連続値を回避します。 すべてのローカル ウィンドウがすでに飽和しているため、7 番目のウィンドウを配置しようとすると、行または列のいずれかにトリプルが強制的に配置されます。 

のために$1 \times m$または$n \times 1$グリッドでも、式は引き続き適用されます。 たとえば、$1 \times 9$グリッドの場合、結果は 6 です。これは最適な 1D 配置と一致します。$110110110$, ここで、3 つのブロックにはそれぞれ 2 つのブロックが含まれます。 グリッドが縮退していても、同じ局所制約が構造を支配するため、式は変更せずに有効なままになります。
