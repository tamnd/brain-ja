 ## 解決策
 ## 問題の理解

 整数のシーケンスが与えられ、何かを行う前に、個々の要素の符号を何度でも反転することができます。 最終的な符号を選択​​した後、すべてのサブ配列を調べ、その中に現れる個別の値の数を計算し、その量をすべてのサブ配列で合計します。 

重要な相互作用は、符号を変更しても大きさは変わりませんが、等価関係が変化するということです。 2 つの等しい絶対値は等しくする (同じ符号) ことも、異なるにする (反対の符号) こともできますが、反転しても何も起こらないため、ゼロは固定されます。 

目標は、すべての要素に符号を割り当てて、すべての部分配列にわたる個別のカウントの合計ができるだけ大きくなるようにすることです。 

制約$n \le 3 \cdot 10^5$すべてのサブ配列を明示的に検査するソリューションは除外されます。 ナイーブ$O(n^2)$サブ配列の列挙がすでに大きすぎて、$O(n^2 \log n)$または、個別のカウントを繰り返し再計算するものは不可能です。 実行可能な解決策では、値または位置の寄与に関する線形または線形に近い集計に問題を削減する必要があります。 

微妙な問題は、「価値観を変える」ということは純粋にローカルなものではないということです。 たとえば、値の 1 つの出現を反転すると、その位置を含むすべての部分配列に影響し、同じ絶対値の他の出現とも相互作用します。 グローバル構造を考慮せずに要素ごとに貪欲に決定すると、寄与のカウントを簡単に間違える可能性があります。 

もう 1 つのエッジ状況は、すべての値がゼロの場合です。 ゼロを 2 つの異なる符号付き値に分割することはできないため、すべての部分配列には常に 1 つの異なる要素が含まれます。 ゼロを分割可能な値のように誤って扱うソリューションでは、オーバーカウントが発生します。 

## アプローチ

 直接的なアプローチでは、すべての部分配列を列挙し、それぞれの個別の要素を計算し、すべての符号の割り当てを試みます。 符号の選択を無視しても、サブ配列ごとに個別のカウントを維持すると、おおよその結果が得られます。$O(n^2)$州。 各要素には 2 つの状態があるため、符号の最適化を追加すると指数関数的になります。 

重要な構造の簡素化は、目的を書き直すことで実現します。 最初に部分配列を合計する代わりに、視点を逆転させて値を合計します。 各値がサブ配列内に少なくとも 1 回出現する場合、その値はサブ配列に寄与します。 したがって、固定最終値の合計寄与度は、$x$少なくとも 1 つの出現と交差する部分配列の数です。$x$。 合計の答えは、すべての個別の符号付き値に対するそのようなカバレッジ寄与の合計になります。 

これで、サイン反転の役割がより明確になります。 あらゆる絶対値$v$複数の位置セットを生成します。 符号を割り当てた後、これらの位置は 2 つの独立したグループに分割されます。$+v$そして$-v$、これらは 2 つの異なる値のように動作します。 各グループは、個別のカウントの合計に独立して寄与します。 

したがって、各絶対値について、それが存在するかどうかを選択するのではなく、その出現を 2 つのラベル付きセットに分割する方法を選択します。 各セットはサブ配列全体にわたるカバレッジの寄与を誘発するため、これらのカバレッジの合計を最大化するパーティションを選択したいと考えています。 

位置の固定セットの場合、その寄与は連続する出現間のギャップのみに依存します。 オカレンスが位置にある場合$p_1 < p_2 < \dots < p_k$の場合、すべての出現を回避するサブ配列は、ギャップに完全に含まれるサブ配列になります。 これにより、ギャップの長さに二次的に依存するコストが発生するため、クラスタリングの発生により寄与が大幅に増加します。 

したがって、問題は、両方のサブシーケンスの内部広がりが最小限になるように、各出現リストを 2 つのサブシーケンスに分割することに帰着します。 最適な構造は、2 つのグループ間でソートされた順序でオカレンスを交互に配置することで実現され、ギャップ分布のバランスがとれます。 

これにより、値ごとに 2 つの誘導シーケンスからの寄与を計算するという問題が軽減されます。

 ## アルゴリズムのチュートリアル

 1. インデックスを絶対値でグループ化します。 各グループには、特定の大きさが現れるすべての位置が含まれます。 
2. ポジションの各グループを昇順に並べ替えます。 これにより、ギャップを推論するために必要な構造が修正されます。 
3. ソート順に位置を交互にして各グループを 2 つのサブシーケンスに分割し、最初のサブシーケンスをグループ A に送信し、2 番目のサブシーケンスをグループ B に送信します。 これにより、両方のサブシーケンスが可能な限り均等に分散されるようになります。 
4. サブシーケンスごとに、そのサブシーケンスの少なくとも 1 つの要素を含むサブ配列の数として、答えへの寄与を計算します。 これはギャップ分解を使用して行われます。連続する出現間のギャップのサイズがわかっている場合は、サブ配列の総数からギャップに完全に含まれるサブ配列の数を差し引きます。 
5. すべての値の両方の部分列からの寄与を加算し、分割して固定値として動作することができないため、ゼロも個別に含めます。 

これが機能する理由は、各符号付き値を「色」として見ることにあります。 サブ配列がその位置の少なくとも 1 つと交差する場合、各色はサブ配列に寄与します。 オカレンスを 2 つの色に分割すると、クラスタリングが減少し、その色を完全に欠落するサブ配列の数が減るため、有益です。 交互に割り当てると、両方の色の内部ギャップの最大値と合計が最小化され、適用範囲が最大化されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    pos = {}
    zeros = 0
    
    for i, x in enumerate(a):
        if x == 0:
            zeros += 1
            continue
        v = abs(x)
        pos.setdefault(v, []).append(i)
    
    total_subarrays = n * (n + 1) // 2
    ans = 0
    
    def contribution(positions):
        if not positions:
            return 0
        k = len(positions)
        
        # compute complement: subarrays that avoid all positions
        bad = 0
        
        # left boundary
        bad += positions[0] * (positions[0] + 1) // 2
        
        # middle gaps
        for i in range(1, k):
            gap = positions[i] - positions[i - 1] - 1
            bad += gap * (gap + 1) // 2
        
        # right boundary
        bad += (n - positions[-1] - 1) * (n - positions[-1]) // 2
        
        return total_subarrays - bad
    
    for v, ps in pos.items():
        ps.sort()
        
        group1 = []
        group2 = []
        
        for i, p in enumerate(ps):
            if i % 2 == 0:
                group1.append(p)
            else:
                group2.append(p)
        
        ans += contribution(group1)
        ans += contribution(group2)
    
    # zeros contribute 1 per subarray since they are identical and unavoidable
    ans += zeros * (n * (n + 1) // 2)
    
    print(ans)

if __name__ == "__main__":
    solve()
```反転によって等価性が得られるか破壊されるかは大きさだけで決まるため、コードは最初に絶対値によって位置を集計します。 各グループは、最適な符号の割り当てをシミュレートするために、2 つの交互のサブシーケンスに分割されます。 

の`contribution`関数は標準の補数トリックを実装します。少なくとも 1 つの出現を含むサブ配列を数える代わりに、すべてのサブ配列をカウントし、その位置を完全に回避するサブ配列を減算します。 それらの「悪い」部分配列はまさに、出現間のギャップまたは極値の外側に完全に存在するものであり、そのような各間隔は三角数に寄与します。 

ゼロは分割できない固定値として動作するため、個別に処理され、ゼロを含むすべての部分配列は依然として 1 つの別個の要素としてカウントされます。 

## 実用的な例

 ### サンプル 1

 入力:```
4
1 1 0 -1
```絶対値 1 を位置 [0、1、3] にグループ化し、ゼロを位置 [2] にグループ化します。 

[0, 1, 3] を 2 つのグループに分割します。 

グループ A: [0, 3]

 グループB: [1]

 | ステップ | グループAのポジション | グループBのポジション | 投稿A | 投稿B |
 | --- | --- | --- | --- | --- |
 | 1 | [0, 3] | [] | ギャップを介して計算される | 0 |
 | 2 | [] | [1] | 0 | ギャップを介して計算される |

 グループ A は大きな中間領域を持つギャップ構造を持ち、グループ B はシングルトンです。 それらを組み合わせた寄与により、多くのサブ配列に個別に寄与する両方の発生が考慮され、カバレッジが最大化されます。 位置 2 にゼロを追加すると、それを含むすべてのサブ配列が 1 つの異なる要素ずつ増加します。 

トレースは、分割によって 1 の両方の出現が単一のクラスター化された値として動作するのを防ぎ、多くのサブ配列で個別のカバレッジが減少することを示しています。 

### サンプル 2

 入力:```
3
0 0 0
```ここにはゼロ以外の値はありません。 すべてのサブ配列は完全にゼロで構成されているため、各サブ配列は 1 つの異なる値を持ちます。 

| サブアレイ | 個別のカウント |
 | --- | --- |
 | [0] | 1 |
 | [0,0] | 1 |
 | [0,0,0] | 1 |

 6 つのサブ配列すべてを合計すると 6 が得られ、ゼロはいかなる変換からも恩恵を受けず、一定のベースラインとして機能することが確認されます。

 ## 特殊なケース

 重要なエッジケースは、すべての要素がゼロの場合です。 このアルゴリズムは、ゼロを正しく個別に扱い、各部分配列に 1 つの異なる要素の寄与を割り当てます。これは、符号の変更によって等価性が変更されないという事実と一致します。 

もう 1 つのケースは、ゼロ以外の等しい絶対値の完全に一様な配列です。 分割ステップにより、出現が 2 つのグループに確実に分割され、それらが 1 つの高度にクラスター化された値に崩壊するのを防ぎます。 これにより、特に長い配列の場合、クラスタリングによって個別のカウントが大幅に減少する可能性があるため、サブ配列のカバレッジが過少にカウントされることが回避されます。 

最後の微妙なケースは、発生がまばらで不規則な場合です。 交互分割は、単一グループ内に大きな連続ブロックを構築することを回避し、ギャップ寄与のバランスを保ち、単一グループがサブ配列の除外を支配するのを防ぐため、引き続き機能します。
