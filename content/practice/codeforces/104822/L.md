 ## 解決策
 ## 問題の理解

 強い構造的制約の下で、部分的に既知の配列から 1 から n までの数値の完全な並べ替えを何回完了できるかを数えるよう求められます。 

制約は、プレフィックス ルールによって有効な置換を定義します。 左から右へ順列をスキャンすると、すべての位置が、これまでに確認されたすべての要素の中での新しいグローバル最小値、またはこれまでに確認されたすべての要素の中での新しいグローバル最大値のいずれかでなければなりません。 プレフィックスの最小値を厳密に拡張していないか、プレフィックスの最大値を拡張していない要素は、順列を無効にします。 

部分的に満たされた配列が与えられます。 いくつかのポジションは固定されていますが、残りは不明です。 タスクは、最終的な順列がこの接頭辞の最小-最大特性を満たすように、欠損値を残りの未使用の数値で埋めることができる方法が何通りあるかを数えるということです。 

重要な制限は、既知の値が明確であることが保証されているため、固定位置間の競合を解決する必要がないことです。 未知の位置はスロットを形成し、そこに残りの番号をプレフィックス構造と一貫して配置する必要があります。 

制約は大きく、テスト全体の合計 n は最大 2⋅10^5 です。 これにより、順列を列挙したり、位置ごとに独立して値を割り当てようとしたりするアプローチは即座に除外されます。 テストごとに二次関数であっても遅すぎます。 ソリューションは、各テストを線形または線形に近い時間で効果的に処理する必要があります。 

いくつかの特殊なケースで構造が明らかになります。 

すべての値が欠落している場合、たとえば n = 4 ですべて 0 の場合、答えは 4 ではありません。 ただし、2^(n-1) です。ルールに従うすべての置換は、各ステップで次の極値が最小側を拡張するか最大側を拡張するかを選択することに対応するためです。 

固定値によって不可能な接頭辞パターンが強制される場合 (有効な補完において接頭辞の最小値または接頭辞の最大値に一致しない中間要素など)、答えはゼロになります。 たとえば、順序付けの制約に違反する形で、すでに強制されている極端な値の間に厳密に存在する値を修正した場合、どの補完でもそれを修復することはできません。 

固定値がすでに極値プロセスと矛盾を形成している場合、たとえば、より小さい既知の値の後に表示されるべき値を強制的に配置するのが早すぎる場合、欠落している位置に関係なく、構成は無効になります。 

## アプローチ

 ブルートフォースアプローチは、残りの数値のすべての順列を生成し、左から右にスキャンして各候補をテストし、各プレフィックス要素がそのプレフィックスの最小値または最大値であるかどうかをチェックすることです。 これは定義を直接強制するため概念的には機能しますが、階乗的に多くの順列を生成し、それぞれを線形時間でチェックする必要があり、最悪の場合、およそ O(n! · n) 回の演算が必要になり、これは n = 20 の場合でも実行不可能です。 

重要な観察は、プレフィックス ルールにより、許容される残りの値の現在の間隔 [L, R] を繰り返し拡張することによって順列が強制的に構築されることです。 すべてのステップで、次に選択される要素は L または R のいずれかである必要があります。これにより、置換が左または右の選択肢のシーケンスに変わりますが、残りの未使用の数値を基準にしたものにすぎません。 

この間隔プロセスの見方を受け入れると、並べ替えはまったく任意ではなくなります。 これは、各新しい要素が現在のプレフィックスの新しい最小値または新しい最大値のいずれかになる挿入順序を選択することと同じです。 これは古典的な「極値を拡張して順列を構築する」構造であり、有効性は固定要素の相対位置と、区間の両側に強制的に挿入される未使用の値の数にのみ依存します。

部分的な情報の場合、主な問題点は、一部の値がすでに位置に固定されていることです。 これらの固定値は、順列をセグメントに分割します。 各セグメント内で、左拡張側と右拡張側に配置される要素の数を効果的に選択していますが、セグメント間の一貫性は値のグローバルな順序によって制限されます。 

解決策は、固定アンカーを尊重しながら、これらの拡張する極値スロットに未知の数値を割り当てることができる有効な方法をいくつ追跡できるかを追跡することになります。 これは、間隔にわたる組み合わせ計数問題となり、残りの未使用数の実行可能な範囲をスキャンして維持することによって、テストごとに線形時間で解くことができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! · n) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 未使用値の動的間隔の観点から順列構造を解釈します。 最初は、1 から n までのすべての数値が使用可能であり、[1, n] の範囲を形成します。 配置された各要素はプレフィックスの新しい最小値または新しい最大値になり、それに応じて使用可能な間隔が縮小します。 

すでに配置したものを考慮して、残りの数値の有効な割り当てと矛盾しない最小値と最大値を維持しながら、配列を左から右に処理します。 

1. 順列のどこにもまだ割り当てられていない最小値と最大値を表す 2 つのポインタ L = 1 および R = n を初期化します。 
2. 左から右に位置をスキャンします。 各位置 i について、固定値が存在するか、位置が不明であるかを確認します。 
3. 値が固定されている場合は、現在の間隔との一貫性を検証する必要があります。 有効な構造では次の要素が現在の極値の 1 つになるように強制されるため、値は L または R のいずれかに等しくなければなりません。 L の場合、L を消費してインクリメントします。 R の場合、R を消費して減分します。 どちらにも一致しない場合、有効な構造は存在しません。 
4. 位置が不明な場合は、間隔のどちらかの終点を自由に選択できます。 ただし、選択肢の数は、L と R が別個であるかどうかによって異なります。 L が R と等しい場合、選択肢は 1 つだけになります。 それ以外の場合は、選択肢が 2 つあり、答えに 2 を掛けます。選択肢を考慮すると、構築の継続と一致する方法で間隔が縮小します。 
5. すべての位置が処理されるまで続行します。 累積積モジュロ 10^9+7 は、有効な完了数です。 

正確さは、すべてのプレフィックスで、未使用の番号のセットが連続した間隔を形成しているという事実に基づいています。 prefix-min-max 条件では、内部値がそのプレフィックスの最小プロパティまたは最大プロパティのいずれかに違反するため、次の要素がこの間隔のエンドポイントの 1 つになるように強制されます。 固定値は特定のステップでどのエンドポイントが選択されるかを強制するだけですが、自由位置は 2 つのエンドポイント間の二分決定に正確に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        used = [False] * (n + 1)
        for x in a:
            if x != 0:
                used[x] = True

        L, R = 1, n
        ans = 1
        ok = True

        for x in a:
            if x == 0:
                if L == R:
                    ans = ans * 1 % MOD
                else:
                    ans = ans * 2 % MOD
                L += 1
                R -= 1
            else:
                if x == L:
                    L += 1
                elif x == R:
                    R -= 1
                else:
                    ok = False
                    break

        print(ans if ok else 0)

if __name__ == "__main__":
    solve()
```この実装では、利用可能な値の縮小間隔を直接シミュレートします。 配列`used`コア ロジックに厳密に必要なわけではありませんが、意図した順列構造を反映していますが、実際の実現可能性チェックはエンドポイントのマッチングを通じて行われます。 

変数`L`そして`R`残りの未使用の値を表します。 数字を配置するたびに、この間隔が短くなります。 位置が固定されている場合は、端点の 1 つと一致する必要があります。そうしないと、構築がすぐに中断されます。 

自由な位置の場合、左端と右端の二者択一を想定します。 ここで乗算係数 2 が登場します。 L が R に等しいエッジ ケースでは、この分岐が削除され、中立係数 1 が寄与します。

 ## 特殊なケース

 固定値がまだグローバル範囲内にあるにもかかわらず、現在のエンドポイントにない場合、微妙な障害が発生します。 たとえば、L = 2 および R = 5 で値 3 が見つかった場合、その値は置換ではグローバルに有効ですが、このプレフィックス プロセスでは無効になります。 3 はどちらのエンドポイントでもないため、アルゴリズムは正しくそれを即座に拒否します。 

もう 1 つのケースは、間隔が単一の値に崩壊する場合です。 If L equals R, there is no branching. 空きポジションはその 1 つの残りの値を消費する必要があり、答えはそれ以上増加しません。 L == R の場合、乗算係数は 1 であるため、アルゴリズムはこれを自然に処理します。 

最後に、固定値が遅れて表示されるが、以前の自由な選択と矛盾して早期の間隔縮小を強制する場合、構築はただちに失敗します。 これは、すべての固定値が縮小間隔の現在の境界と一致する必要があり、逸脱があるとバックトラックすることなくプロセスが中断されるため、捕捉されます。
