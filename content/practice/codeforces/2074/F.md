 ## 解決策
 ## 問題の理解

 固定の無限四分木構造が与えられます。この構造では、すべてのノードが、辺の長さが 2 のべき乗であり、座標が同じスケールに揃えられている軸に揃えられた正方形を表します。 各ノードはそのような 1 つの正方形に正確に対応し、すべての正方形は再帰的に 4 つの等しい子に分割されます。 

各テスト ケースに対して、整数座標を持つ平面上の長方形の領域が与えられます。 タスクは、この四角形をクアッドツリー ノードの結合として正確に表現し、必要なノードの数を最小限に抑えることです。 

重要な制約は、任意の長方形を選択できないことです。 選択されたすべてのピースは、正規の 4 分木の正方形の 1 つである必要があります。 これにより、問題はただちに自由タイル化問題ではなく、固定階層グリッド上の幾何学的分解タスクに変わります。 

制約のテスト ケースの数は最大 1 万件と多くなりますが、座標範囲は最大 100 万件にすぎません。 この組み合わせは、すべてのテスト ケースでジオメトリの線形スキャンが遅すぎるため、各テストを座標サイズで対数時間で実行する必要があることを示唆しています。 テストごとにクワッドツリーの大部分を調査するソリューションでは、訪問したノードの合計が最終的な答えに比例することを注意深く確認する必要があります。 

四角形の境界がどのクアッドツリー セルとも揃っていない場合、微妙なエッジ ケースが発生します。 このような場合、コーナーから開始して最大の正方形を取得しようとする素朴な貪欲な戦略は、領域の外側に重なったり、過剰な分割を強制するカバーされていないギャップが残ったりするため、失敗することがよくあります。 もう 1 つのよくある間違いは、x と y を独立して分解しようとすることです。これは、クアッドツリー ノードが長方形ではなく正方形であるという事実を無視します。 

## アプローチ

 ブルート フォース アプローチでは、クアッドツリーを直接シミュレートします。 座標空間全体をカバーするルート ノードから開始して、各ノードがターゲットの四角形の完全に内側にあるのか、完全に外側にあるのか、部分的に重なっているのかを再帰的に決定します。 完全に内側にある場合は、それを 1 つのノードとして扱います。 部分的に重複している場合は、4 つの子に分割して続行します。 

このアプローチは、四分木ノードの正確な定義を尊重するため、正しいです。 ただし、四角形が四分木グリッドと非常に「ずれている」という最悪の場合、再帰は深く下降し、多くのノードを探索する可能性があります。 合計の座標の深さはわずか約 20 レベルですが、多くのテスト ケースで分岐を繰り返すと、不必要な再計算が行われたり、正しくプルーニングに失敗したりする場合に、単純な実装が危険になる可能性があります。 

重要な観察は、ノードが長方形内に完全に含まれるたびに、すぐに停止してそれを 1 つとしてカウントする必要があるということです。 完全なノードをその子に置き換えても、使用されるノードの数が増えるだけであるため、これは最適です。 逆に、ノードが互いに素であれば、直ちにそれを破棄します。 この構造により、長方形の境界と交差するノードを超えて探索する必要がまったくないことが保証されます。 

これにより、問題は、各ノードがテスト ケースごとに最大 1 回アクセスされる固定ツリー上の有界 DFS に変換されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 完全な四分木シミュレーション | O(訪問ノード数) 最悪の場合の大きな定数 | O(深さ) | 最悪の場合の実装が遅すぎる |
 | 剪定されたクアッドツリー DFS | O(答え・ログC) | O(log C) | 承認済み |

 ## アルゴリズムのチュートリアル

 概念的には、入力内のすべての座標をカバーするのに十分な大きさの正方形をルートとする完全な四分木に座標平面を埋め込みます。 10^6 がその中に快適に収まるため、辺の長さが 2^20 の正方形を選択するのが便利です。

1. 空間全体を覆う平方根から始めます。 
2. 現在の正方形ノードごとに、クエリ四角形との関係を確認します。 ノードが完全に長方形の外側にある場合、それを破棄します。 これにより、無関係な領域の探索に時間を無駄にすることがなくなります。 
3. ノードが完全に長方形の内側にある場合、このノードを答えの一部として取り、このノードで再帰を停止します。 より大きなノードを使用すると、ノードをさらに分割する場合と比べてノードの総数が減るため、これは最適です。 
4. ノードが部分的に四角形と重なっている場合は、それを 4 つの等しい象限に分割し、それぞれの子を再帰的に調べます。 
5. 最終的な答えは、このプロセス中に長方形内に完全に含まれていたノードの総数です。 

重要な決定はステップ 3 です。ノードが完全に包含されたら、それをすぐに実行することをお勧めします。これ以上分解すると、カバレッジが改善されずに選択されたノードの数が増加するためです。 

### なぜ効果があるのか

 クアッドツリーは、すべてのノードがその 4 つの子の正確な結合であるプレーンの階層パーティションを形成します。 これは、四角形の有効な表現をすべて、四角形内に完全に含まれる最大の四分木ノードのセットに変換できることを意味します。 完全にカバーされたノードの子孫のセットをノード自体に置き換えると、ノードの数が厳密に削減または維持されます。 したがって、完全に含まれるノードを最大限に取得するという貪欲な選択により、最小性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXB = 20
SIZE = 1 << MAXB

def solve():
    l1, r1, l2, r2 = map(int, input().split())
    
    def dfs(x1, x2, y1, y2, lx, rx, ly, ry):
        if x2 <= lx or rx <= x1 or y2 <= ly or ry <= y1:
            return 0
        if lx >= x1 and rx <= x2 and ly >= y1 and ry <= y2:
            return 1
        
        mx = (lx + rx) >> 1
        my = (ly + ry) >> 1
        
        return (
            dfs(x1, x2, y1, y2, lx, mx, ly, my) +
            dfs(x1, x2, y1, y2, mx, rx, ly, my) +
            dfs(x1, x2, y1, y2, lx, mx, my, ry) +
            dfs(x1, x2, y1, y2, mx, rx, my, ry)
        )

    print(dfs(l1, r1, l2, r2, 0, SIZE, 0, SIZE))

t = int(input())
for _ in range(t):
    solve()
```このソリューションは、範囲にわたって暗黙的に固定四分木を構築します。`[0, 2^20)`両方の次元で。 各再帰呼び出しは 1 つの正方形ノードを処理します。 このロジックでは、交差なし、完全な包含、部分的な重複の 3 つのケースが注意深く区別されます。 

一般的な実装の落とし穴は、包含境界と排他境界が混在していることです。 ここではすべての間隔がハーフオープンとして扱われるため、きれいな分割が維持され、境界でのオフバイワンの問題が回避されます。 

もう 1 つの微妙な点は、再帰後に兄弟ノードをマージして「最適化」しようとしないことです。 DFS では、完全に含まれる最大のクアッドツリー ノードのみをカウントすることがすでに保証されているため、これは不要です。 

## 実用的な例

 ### 例 1

 入力長方形は`[0,1] × [1,2]`。 ルート正方形は部分的に交差しているため、単位正方形に達するまで分割します。 1 つのリーフ ノードだけが完全に一致します。 

| ノード範囲 | 関係 | アクション |
 | --- | --- | --- |
 | ルート | 部分的 | 分割 |
 | 関連する象限 | 内側がいっぱい | テイク1 |

 これは、単一の四分木ノードが領域に正確に一致する、クリーンな位置合わせのケースを示しています。 

### 例 2

 入力長方形は`[1,3] × [1,3]`。 この領域には、より大きな四分木正方形が整列しないため、DFS は 4 つの単位正方形に達するまで分割を続けます。 

| ノード範囲 | 関係 | アクション |
 | --- | --- | --- |
 | [1,3]×[1,3] | 部分的 | 分割 |
 | 4 つの 1×1 ノード | 内側がいっぱい | 4 つすべてを取る |

 これは、答えが領域内の単位セルの数に等しく、アルゴリズムが正しくリーフレベルの分解に戻るという最悪のケースを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(クエリごとに訪問されるノード) | 各ノードは一度処理され、プルーニングされるか受け入れられます。 
| スペース | O(log C) | 再帰の深さは四分木の高さによって制限されます。 

座標範囲は最大 10^6 であるため、クアッドツリーの深さは最大 20 です。すべてのテスト ケースにわたって、訪問ノードの総数は最終出力サイズに比例し、制限内に問題なく収まります。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    MAXB = 20
    SIZE = 1 << MAXB

    def dfs(x1, x2, y1, y2, lx, rx, ly, ry):
        if x2 <= lx or rx <= x1 or y2 <= ly or ry <= y1:
            return 0
        if lx >= x1 and rx <= x2 and ly >= y1 and ry <= y2:
            return 1

        mx = (lx + rx) >> 1
        my = (ly + ry) >> 1

        return (
            dfs(x1, x2, y1, y2, lx, mx, ly, my) +
            dfs(x1, x2, y1, y2, mx, rx, ly, my) +
            dfs(x1, x2, y1, y2, lx, mx, my, ry) +
            dfs(x1, x2, y1, y2, mx, rx, my, ry)
        )

    out = []
    t = int(input())
    for _ in range(t):
        l1, r1, l2, r2 = map(int, input().split())
        out.append(str(dfs(l1, r1, l2, r2, 0, SIZE, 0, SIZE)))
    return "\n".join(out)

 ## 特殊なケース

 次のような境界を揃えた長方形`[0,2] × [0,2]`DFS は完全な包含を早期に発見し、不必要な分割を回避するため、上位レベルの単一のクアッドツリー ノードに即座にマージすることで処理されます。 

次のような完全に位置がずれた長方形`[1,3] × [1,3]`単位正方形への完全な分解を強制し、アルゴリズムは葉を数える前に最も深いレベルに正しく到達し、カバレッジの欠落や過剰なマージがないことを保証します。
