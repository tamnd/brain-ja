 ## 解決策
 ## 問題の理解

 与えられた整数を見つけるように求められます`x ≥ 2`、別の整数`y`3つの数字になるように`x`、`y`、 そして`x XOR y`非縮退三角形は三角不等式によって定義されます。 番号`y`厳密に以下でなければなりません`x`。 入力は複数のテスト ケースで構成され、それぞれが単一の整数を提供します`x`、出力は有効な値を提供する必要があります。`y`または`-1`そうでない場合`y`存在します。 

制約`x ≤ 10^9`すべてをブルートフォースチェックすることを意味します。`y < x`遅すぎるので、`x`10億近くになる可能性があります。 したがって、O(x) 解は実現不可能です。 候補を計算するアプローチが必要です`y`テストケースごとに定数時間または対数時間で。 

の値が小さい場合、微妙なエッジケースが発生します。`x`、特に 2 の累乗。 例えば、`x = 2`だけを許可します`y = 1`、しかしその後`x XOR y = 3`、および三角形の辺`1, 2, 3`三角不等式は失敗します。`1 + 2`より大きくない`3`。 同様に、`x`という形です`2^k - 1`、特定のビット パターンにより、有効な三角形の構築が妨げられます。 小さなことを試すだけの素朴なアプローチ`y`逐次実行はこれを見逃して失敗するか、遅すぎるかのどちらかです。 

## アプローチ

 ブルートフォースアプローチは簡単です。`y`から`1`に`x-1`、計算する`z = x XOR y`三角不等式を確認してください`x + y > z`、`x + z > y`、 そして`y + z > x`。 もしあれば`y`これらを満たしている場合は出力します。 これは小規模な場合に機能します`x`ただし、最大で`10^9`大規模な反復`x`、制限時間の 2 秒をはるかに超えています。 

最適なアプローチは、バイナリの XOR に関する重要な観察に基づいています。 もし`x`最上位の設定ビットが位置にあります`k`、次に選択します`y`その最上位ビットは より 1 つ小さいものになります。`k`それを保証します`y < x`そして`x XOR y < x + y`。 簡単な候補としては、`y`に`2^(k-1)`、つまり、厳密に小さい 2 の最大累乗`x`。 これにより保証されます`y < x`そして通常、三角形不等式が成り立つことを保証します。 

アプローチは次のとおりです。 の最高設定ビットを計算します。`x`、構築する`y`以下の対応する 2 のべき乗として`x`、計算する`z = x XOR y`、三角不等式を検証します。 満足していれば出力する`y`。 それ以外の場合は出力`-1`。 これにより、各テスト ケースの操作数が一定に減ります。

 | 最適 | O(log x) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数の読み取り`x`入力から。 
2. 最上位ビット位置を計算します。`k`の`x`。 これは次を使用して実行できます`x.bit_length() - 1`。 
3. 候補を作成する`y`として`1 << (k - 1)`。 これにより、`y < x`そして`y`可能な最大の単一ビットのみが設定されています。 
4. コンピューティング`z = x XOR y`。 
5. 三角不等式を確認する`x + y > z`、`x + z > y`、`y + z > x`。 
6. すべての不等式が満たされる場合、出力します。`y`。 それ以外の場合は、印刷します`-1`。 
7. すべてのテスト ケースに対して繰り返します。 

この方法が機能するのは、XOR が異なるビットを反転するためです。 選択することで`y`以下の 2 のべき乗として`x`、`x XOR y`厳密に小さい数値を生成します`x + y`しかし、それよりも大きい`|x - y|`、正の整数の三角不等式を満たします。 正確さは選択にかかっています`y`のビットパターンを尊重する構造化された方法で`x`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x = int(input())
        if x == 2:
            print(-1)
            continue
        k = x.bit_length() - 1
        y = 1 << (k - 1)
        z = x ^ y
        if y + z > x and x + z > y and x + y > z:
            print(y)
        else:
            print(-1)
```このソリューションはエッジケースに慎重に対処します`x = 2`三角形が存在できない場所。 大型の場合`x`、候補を構築します`y`印刷前に三角不等式を検証します。

 ## 特殊なケース

 のために`x = 2`、唯一の候補`y = 1`生成する`z = 3`、三角不等式に違反します。`x + y > z`。 アルゴリズムは明示的にチェックします`x == 2`そして出力`-1`。 

のために`x`2 の累乗であるなど、`x = 1024`、候補者`y = 512`不等式を満たす：`512 + 512 > 1024 `、 しかし`x + y > z`そして`y + z > x`まだ保持しています。 このアルゴリズムには、すべての不等式を検証するチェックが含まれており、無効な三角形が返されないことが保証されます。
