 ## 解決策
 ## 問題の理解

 次のような正多角形が与えられます。$n$頂点。各頂点には正の整数のラベルが付けられます。 目標は、多角形内に重ならない三角形を描画して、頂点の数値の積の合計を最大化することです。 各三角形はその頂点積をスコアに寄与し、三角形が正の領域を共有することは許可されません。 

入力は複数のテスト ケースで構成され、それぞれが次の方法でポリゴンを記述します。$n$および整数の配列$a_1, \dots, a_n$。 出力は、各ポリゴンの達成可能な最大スコアです。 

主な制約は次のとおりです。$3 \le n \le 400$と合計$n^3$すべてのテスト ケースで最大でも$400^3$。 これは、$O(n^3)$解決策は受け入れられますが、さらに悪いことは次のとおりです。$O(n^4)$、遅すぎるでしょう。 エッジ ケースには、すべての数値が等しいポリゴン、または小さな三角形を組み合わせると全体の積和が減少するため、最適な解決策として複数の小さな三角形ではなく 1 つの三角形を選択することが含まれるポリゴンが含まれます。 たとえば、[2,1,3,4] というラベルの付いた四角形では、頂点 1,3,4 を持つ三角形を選択すると 24 が得られますが、より小さな三角形を組み合わせると得られる数は少なくなる可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、重複しない三角形の可能なすべてのセットが考慮されます。 のために$n$頂点、三角形の数は$O(n^3)$、重複をチェックするとさらに複雑になります。 これは正しいですが、すべての組み合わせを検証すると階乗的に増加し、実行可能な計算をはるかに超えてしまうため、非効率的です。$n = 400$。 

観察によると、多角形は規則的で凸状であるため、慎重に選択した場合、エッジを共有しない三角形は重なりません。 これは、サブポリゴンとその達成可能な最大スコアを再帰的に考慮する、「行列チェーン乗算」または「ポリゴン三角形分割」に似た動的プログラミング アプローチを示唆しています。 具体的には、頂点を持つ三角形を選択すると、$i, j, k$サブポリゴン内$[i, j, k]$、残りのポリゴンを独立したサブポリゴンに分割し、それらを個別に解決できます。 これにより、重複する三角形が描画されることがなくなります。 

したがって、問題を DP を使用してすべてのサブポリゴンの積の最大合計を計算することに縮小します。 させて`dp[l][r]`頂点からのポリゴン セグメントに対して達成可能な最大スコアになります。$l$に$r$時計回りの順番で。 再帰は次のとおりです。```
dp[l][r] = max(dp[l][k] + dp[k][r] + a[l]*a[k]*a[r]) for l<k<r
```この繰り返しでは、端点を持つ三角形を選択することを考慮しています。`l`そして`r`およびいくつかの中間頂点`k`。 すべてのセグメントと長さを反復処理すると、DP テーブルが埋められます。$O(n^3)$、制約を考慮すると、これは実現可能です。

 ## アルゴリズムのチュートリアル

 1. アレイを拡張する`a`ポリゴンの円形性をそれ自体に連結することで簡単に処理できます。 これにより、ポリゴンを囲むセグメントの線形インデックス作成が可能になります。 
2. 2D DP 配列を初期化する`dp[l][r]`ゼロを使​​用すると、`l`そして`r`は拡張配列内のセグメントのインデックスです。 
3. セグメント長を 3 から 3 まで繰り返します。$n$三角形には少なくとも 3 つの頂点が必要なためです。 
4. セグメントごとに`[l, r]`指定された長さの場合、すべての中間頂点を考慮します`k`そのような`l < k < r`。 
5. 三角形を描画するためのスコアを計算します`(l, k, r)`左右のサブセグメントの最大スコアを加算します (`dp[l][k]`そして`dp[k][r]`）。 
6.アップデート`dp[l][r]`あらゆる可能性の中から得られる最大値で`k`。 
7. DP テーブルに記入すると、答えは最大値になります。`dp[l][l+n-1]`すべての開始インデックスに対して`l`0から`n-1`、ポリゴンのすべての回転を確実に考慮します。 

機能する理由: DP 不変条件により、次のことが保証されます。`dp[l][r]`セグメントの最適解を常に保存します`[l, r]`。 互いに素なサブセグメントで選択された三角形は重なり合わず、すべての中間頂点をチェックすることによって`k`、あらゆる可能な三角形分割が考慮されることを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        # duplicate array for circularity
        a = a * 2
        dp = [[0] * (2*n) for _ in range(2*n)]
        
        for length in range(3, n+1):
            for l in range(0, 2*n - length + 1):
                r = l + length - 1
                for k in range(l+1, r):
                    dp[l][r] = max(dp[l][r], dp[l][k] + dp[k][r] + a[l]*a[k]*a[r])
        
        ans = 0
        for start in range(n):
            ans = max(ans, dp[start][start+n-1])
        print(ans)
```コードはまず配列を複製します。`a`円形のセグメントを処理するには、すべてのセグメントの長さについて DP テーブルを埋めます。 ネストされたループは、中央の頂点を選択して各セグメントの最大積和を計算します。`k`。 最後に、ポリゴンのすべての回転バージョンの中から最大スコアを選択します。
