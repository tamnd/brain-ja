 ## 解決策
 ## 問題の理解

 平面内に 4 つの固定点が与えられます。 それらの座標は常に軸と一致しています。1 つは負の X 軸上にあります。$(-l, 0)$、1 つは正の x 軸上にあります。$(r, 0)$、負の y 軸上の 1 つ$(0, -d)$、および 1 つは正の y 軸上にあります。$(0, u)$。 各テスト ケースにおける唯一の自由は 4 つの距離です$l, r, d, u$。 

課題は、これら 4 つの点をある順序で接続したときに、ある正方形の頂点として機能できるかどうかを判断することです。 ポイントを移動することはできません。 自己交差のない正方形を形成する有効な順序が存在するかどうかを判断することしかできません。 

テスト ケースごとの制約は非常に小さく、各値は 1 ～ 10 ですが、最大で 10 までの制約が存在します。$10^4$テストケース。 これにより、ケースごとに一定時間のチェックが行われるようになります。 順列が 24 個しかないため、点順序の順列を試みるアプローチは理論的にはまだ許容されますが、多くのテスト ケースにわたって幾何学的チェックを繰り返し実行すると、直接的なブルート フォースが必要以上にクリーンでなくなります。 

微妙な特殊ケースは、これらの点が任意ではないという事実から生じます。 これらは常に軸上にあるため、ジオメトリは大きく制限されます。 素朴な直観では、「4 つの距離がすべて等しい場合、それは常に正方形である」と思われるかもしれませんが、エッジを交差させることなく点が実際に正方形の順序で接続できることも確認しない限り、それだけでは十分ではありません。 

たとえば、次の場合$l = r = d = u = 2$明らかに、原点を中心に回転した正方形を形成できます。 ただし、一方の辺が大きい場合は、次のようにします。$l = 1, r = 2, d = 3, u = 4$、ポイントは各方向に異なる方法で引き伸ばされ、それらを接続する剛直な正方形は存在しません。 

隠れた重要な要件は対称性です。原点を中心とし、辺が対角線に平行な正方形の場合、4 方向すべてに均等に拡張する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、指定された 4 つの点のすべての順列を考慮し、有効な正方形を形成する順序があるかどうかを確認しようとします。 順列ごとに、4 つの辺の長さを計算して等しいことを検証し、対角線が一致し、形状が自己交差していないことも確認します。 テスト ケースごとに 24 個の順列があるため、$10^4$テストケース、これにより約$2.4 \times 10^5$これはすでに問題ありませんが、順列ごとの幾何学的検証は、このような制約のある構成では不要なオーバーヘッドです。 

重要な点は、4 つの点がすでに軸上に固定されており、それらの点から形成される正方形は原点を中心とする必要があるということです。 これは、これらの軸に揃えられた極値を使用する正方形では、反対側の点が両方の軸を横切って対称的に配置されるためです。 

原点を中心とする正方形の場合、頂点は次の位置にある必要があります。$(\pm a, 0)$そして$(0, \pm a)$45 度回転した後、またはこの特定の構成で位置合わせした後。 この問題では、点は厳密に軸に揃えられているため、可能な正方形は原点からの 4 つの距離がすべて等しいものだけです。 つまり、$l = r = d = u$。 

したがって、問題全体は単一の等価性チェックに帰着します。

 ## アルゴリズムのチュートリアル

 各テスト ケースを個別に処理し、4 つの値を直接比較します。 

1.読む$l, r, d, u$。 これらは、各点が軸に沿って原点からどれだけ離れているかを表します。 これにより、ジオメトリが完全に決定されます。 
2. 4 つの値がすべて等しいかどうかを確認します。 この条件は、原点を中心とする正方形に必要な 4 方向すべての完全な対称性を強制します。 
3. 等しい場合は「Yes」を出力し、等しくない場合は「No」を出力します。 

### なぜ効果があるのか

 正方形には、すべての頂点が中心から等距離にあります。 この構成では、すべての点がいずれかの軸上にあるため、考えられる中心は原点のみです。 形状が正方形であるためには、4 つの頂点すべてが垂直方向に沿って中心から等しい半径に位置する必要があります。 指定された構造はこれらの方向を軸自体に固定するため、等しい辺の長さと直角を維持する唯一の方法は、原点からの 4 つの距離すべてが正確に一致することです。 不均衡があると、エッジが不均等になるか、正方形の制約を満たすことができない歪んだ四角形が作成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    l, r, d, u = map(int, input().split())
    if l == r == d == u:
        print("Yes")
    else:
        print("No")
```解決策は、対称条件を直接実装することです。 連鎖等価性チェックでは、4 つの方向がすべて同一であることが保証され、これが唯一の有効な構成です。 

入力はすでに完全な空間制約をエンコードしているため、追加のデータ構造や幾何学的計算は必要ありません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(sys.stdin.readline())
    out = []
    for _ in range(t):
        l, r, d, u = map(int, sys.stdin.readline().split())
        out.append("Yes" if l == r == d == u else "No")
    return "\n".join(out)

# provided samples
assert run("2\n2 2 2 2\n1 2 3 4\n") == "Yes\nNo"

# custom cases
assert run("1\n1 1 1 1\n") == "Yes"
assert run("1\n1 1 1 2\n") == "No"
assert run("1\n10 10 10 9\n") == "No"
assert run("1\n2 3 2 3\n") == "No"

 ## 特殊なケース

 エッジ ケースの 1 つは、3 つの値が等しく、1 つの値がわずかに異なる場合です。$l = r = d = 5, u = 4$。 等価性チェックはすぐに失敗するため、アルゴリズムは正しく「いいえ」を出力します。 幾何学的に、これは 1 つの軸を引き伸ばし、回転対称性を破壊します。 

もう 1 つのケースは、2 つの反対方向が異なるが、もう一方のペアが一致する場合です。$l = r = 7, d = u = 3$。 両方の軸が独立して対称であっても、辺の長さが向きに応じて異なるため、軸間の不一致により正方形が妨げられます。 

最後に、次のような完全に等しい場合、$l = r = d = u = 1$、チェックに合格し、構成は完全に中央に配置された正方形に対応します。
