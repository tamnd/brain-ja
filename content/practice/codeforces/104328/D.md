## アルゴリズムのチュートリアル

 1. 因数分解$p_i$そしてその約数をすべて列挙します。 このステップでは、すべての候補のセットを構築します$x$価値観。 これを行う理由は、有効な$x$サポート パス内の少なくとも 1 つのノードを分割する必要があるため、この除数セットに含める必要があります。 
2. 各約数について$x$、ノードのリストを維持します。$p_i \bmod x = 0$。 これにより、ツリー ノードがこの候補に対してアクティブと非アクティブに分割されます。 
3.固定の場合$x$、重みを割り当てる$+1$アクティブなノードと$-1$非アクティブなノードに。 目標は、ツリー内の合計が最大になる単純なパスを見つけることです。 この最大合計が正の場合、アクティブなノードがそのパス上の大部分を占めています。 
4. DFS DP を使用して、ツリー内の最大パス合計を計算します。 各ノードについて、その子からの最適な下向き寄与を計算し、2 つの子の寄与を組み合わせて、ノードを通過する最適なパスを形成します。 これは標準的な「ノードの重みを含むツリーの直径」の計算です。 
5. 約数がある場合$x$正の最適パス合計が得られる場合は、すぐに YES を返します。 それ以外の場合は、すべての候補を調べた後、NO を返します。

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

from collections import defaultdict

def factorize(x):
    res = {}
    d = 2
    while d * d <= x:
        while x % d == 0:
            res[d] = res.get(d, 0) + 1
            x //= d
        d += 1
    if x > 1:
        res[x] = res.get(x, 0) + 1
    return res

def all_divisors_from_factorization(factors):
    divisors = [1]
    for p, cnt in factors.items():
        cur = []
        mul = 1
        for _ in range(cnt):
            mul *= p
            for d in divisors:
                cur.append(d * mul)
        divisors.extend(cur)
    return divisors

def solve():
    n = int(input())
    p = list(map(int, input().split()))
    
    g = [[] for _ in range(n)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    divisors_map = defaultdict(list)

    for i, val in enumerate(p):
        fac = factorize(val)
        divs = all_divisors_from_factorization(fac)
        for d in divs:
            divisors_map[d].append(i)

    # try each candidate divisor
    for x, nodes in divisors_map.items():
        active = [False] * n
        for v in nodes:
            active[v] = True

        # tree DP for max path sum
        best = 0

        def dfs(u, parent):
            nonlocal best
            best_down = 1 if active[u] else -1

            first = 0
            second = 0

            for v in g[u]:
                if v == parent:
                    continue
                child = dfs(v, u)
                best_down = max(best_down, (1 if active[u] else -1) + child)

                # track top two contributions
                if child > first:
                    second = first
                    first = child
                elif child > second:
                    second = child

            best = max(best, (1 if active[u] else -1) + first + second)
            return best_down

        dfs(0, -1)

        if best > 0:
            print("YES")
            return

    print("NO")

if __name__ == "__main__":
    solve()
```このソリューションはツリーを構築し、各候補約数に対して「アクティブ化」された頂点のセットを構築します。 DFS は、ノードから始まる最適な下向きパスと、その 2 つの最良の子の寄与を使用してノードを通過する最適なパスという 2 つの量を同時に計算します。 重量の変換$+1$そして$-1$これは、多数決条件を標準の最大パス合計の問題に変えるものです。 

実装の微妙な詳細の 1 つは、除数ごとの DFS のリセットと再計算です。 これは最悪の場合コストが高くなりますが、すべての値にわたる意味のある約数の数は因数分解の構造によって制限されるため、許容できます。 もう 1 つの微妙な点は、DP はルートに基づいた答えではなくグローバルな最適パスを計算するため、ルートの選択は重要ではないことです。

 ## 特殊なケース

 主なエッジケースは次のような場合です$x$多くのノードをアクティブ化しますが、それらはブランチ間で分割されます。 たとえば、葉だけがアクティブな星では、葉の間のパスは非アクティブな中心を通過する必要があり、多数派が減少するため、長いパスは生成されません。 

ツリー DP は非アクティブなノードの負の重みを明示的に考慮しているため、アルゴリズムはこれを正しく処理します。 このような星では、中心を通る最適な経路の合計は制限されます。たとえ 2 つの葉が +1 であっても、中心は -1 に寄与し、活性化が十分に密でない限り、結果として得られる経路の合計は 0 を超えることはできません。
