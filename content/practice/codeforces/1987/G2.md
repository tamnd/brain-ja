 ## 解決策
 ## 問題の理解

 1 から 1 までの整数の順列が与えられます。$n$および長さの命令の文字列$n$ここで、各命令は L、R、または ? のいずれかです。 順列の各位置は、左 (L) または右 (R) の最も近い大きい番号に接続できます。 どちらかの方向を選択できます。 目標は、これらのルールに従って接続された無向グラフを構築し、そのようなグラフの可能な最大直径を見つけること、または接続されたグラフを形成できない場合は -1 を出力することです。 

重要な課題は、順列と命令によってエッジがどのように決定されるか、そして ? での選択がどのように行われるかにあります。 位置は接続に影響します。 ? について考えられるすべての選択肢を試す素朴なアプローチ。 は実行不可能であるため$n$組み合わせの数は 400,000 に達する可能性があり、指数関数的に増加します。 また、合計は、$n$すべてのテスト ケースの数も 400,000 に達する可能性があるため、どのアルゴリズムもほぼ線形である必要があります。$n$7秒の制限時間内に収まるように。 

慎重な処理が必要なエッジ ケースには、切断されたコンポーネントを作成する完全に固定された方向、最大数がエンドポイントにあるシーケンス、および ? の長いストレッチが含まれます。 複数の設定が存在する文字。 たとえば、$p=[1,2]$そして$s='LR'$の場合、L が左を指し、R が右を指すため、2 つのノードを接続する方法はなく、孤立したままになります。 正しい出力は -1 です。 

## アプローチ

 ブルートフォース手法では、? の選択肢のすべての組み合わせに対してグラフが構築されます。 各構成について、すべての頂点から BFS を実行するか、ツリーに対して 2 パス BFS を使用することによって、グラフの直径を計算します。 これはグラフが常にツリーであるため機能します (各ノードは正確に 1 つのエッジを追加します) が、構成の数が少ないために失敗します。$2^k$どこ$k$の数は？ 最大文字数まで可能$n$。 すべての構成を評価するには、次のような操作が必要になります。$O(2^n \cdot n)$これは明らかに遅すぎます。$n\sim 4 \cdot 10^5$。 

重要な洞察は、順列によって定義されたエッジが **単調チェーンの森**を作成し、各ノードが最も近いより大きな隣接ノードに接続するということです。 各ノードは、L または R で定義された親を指します。これらのエッジの構造は、順列に基づいて構築された **デカルト ツリー**に対応します。最大の要素がルートとなり、同じルールが左と右の部分配列に再帰的に適用されます。 デカルト ツリーを使用すると、接続性と距離を効率的に推論できます。最大可能直径は、ルートの左右のサブツリーの高さの合計であり、? の選択によって潜在的に調整されます。 ポジション。 

?の処理としては、「木の深さを最大にするエッジを選択できる」という扱いになります。 これにより、問題は **デカルト ツリー上の分割統治**に還元され、各サブツリーで、エッジが左右に自由に移動できるときに取得できる最大の高さを計算します。 ツリーが完全に構築されている場合は接続が保証されますが、命令によって一部のノードが上位ノードに接続できない方法でエッジを強制すると、コンポーネントの切断が発生します。 このようなケースを検出するには、固定された L および R 方向を考慮して、サブツリーが孤立したままであるかどうかを確認する必要があります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n) | O(n) | 遅すぎる |
 | デカルト ツリー + DP | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各インデックスの事前計算$i$左に最も近い大きい隣のもの$l_i$そして正しい$r_i$モノトーンのスタックを使って。 各要素のプッシュとポップは最大 1 回であるため、このステップは線形時間で実行されます。 
2. L を強制接続として扱います。$l_i$と R への強制接続として$r_i$。 ? については、両方の選択肢を許可し、効果的に、より深い深さを与える方の親に子をアタッチさせます。 
3. 順列からデカルト ツリーを構築します。現在の部分配列の最大の要素がルートであり、左と右のサブツリーを再帰的に構築します。 これにより、有効なグラフの基礎となる接続が得られます。 
4. DP 関数を定義する`dfs(node)`ルートとなるサブツリーの高さを返します。`node`そしてそのサブツリーで達成可能な最大直径。 葉の場合、高さは 1、直径は 0 です。 
5. DP では、? が付いたノードについて、左右のサブツリー間の最大高さを取得して、潜在的な直径を計算します。 ローカル直径は、そのノードの下にある 2 つの最も高いサブツリーの合計に 1 (ノード自体の場合) を加えたものです。 最大直径を上方向に伝播します。 
6. 固定された L/R エッジに従ってサブツリーを接続できない場合は、すぐに -1 を返します。 それ以外の場合、DP がルートで完了した後、計算された直径を返します。 

機能する理由: デカルト ツリーは、各ノードが最も近い、より大きな隣接ノードに正しく接続されることを保証します。 ? の高さを最大化するエッジを再帰的に選択することで、木の直径を最大化する構成をシミュレートします。 各ノードは 1 つのエッジにのみ寄与し、すべてのノードがツリーに含まれるため、有効な構成では接続不変条件が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        s = input().strip()

        # nearest greater to left
        l = [i for i in range(n)]
        stack = []
        for i in range(n):
            while stack and p[stack[-1]] < p[i]:
                stack.pop()
            l[i] = stack[-1] if stack else i
            stack.append(i)

        # nearest greater to right
        r = [i for i in range(n)]
        stack = []
        for i in range(n-1, -1, -1):
            while stack and p[stack[-1]] < p[i]:
                stack.pop()
            r[i] = stack[-1] if stack else i
            stack.append(i)

        children = [[] for _ in range(n)]
        root_candidates = set(range(n))
        parent = [-1]*n
        ok = True

        for i in range(n):
            if s[i] == 'L':
                if l[i] == i:
                    ok = False
                    break
                parent[i] = l[i]
            elif s[i] == 'R':
                if r[i] == i:
                    ok = False
                    break
                parent[i] = r[i]

        if not ok:
            print(-1)
            continue

        for i in range(n):
            if parent[i] != -1:
                children[parent[i]].append(i)
                root_candidates.discard(i)

        # attach remaining ? nodes optimally
        for i in range(n):
            if s[i] == '?':
                if l[i] != i and r[i] != i:
                    if len(children[l[i]]) < len(children[r[i]]):
                        parent[i] = r[i]
                    else:
                        parent[i] = l[i]
                    children[parent[i]].append(i)
                    root_candidates.discard(i)
                elif l[i] != i:
                    parent[i] = l[i]
                    children[parent[i]].append(i)
                    root_candidates.discard(i)
                elif r[i] != i:
                    parent[i] = r[i]
                    children[parent[i]].append(i)
                    root_candidates.discard(i)
                else:
                    ok = False
                    break

        if not ok or len(root_candidates) != 1:
            print(-1)
            continue

        root = root_candidates.pop()

        def dfs(u):
            h1 = h2 = 0
            diameter = 0
            for v in children[u]:
                d, h = dfs(v)
                diameter = max(diameter, d)
                if h > h1:
                    h2 = h1
                    h1 = h
                elif h > h2:
                    h2 = h
            return max(diameter, h1 + h2), h1 + 1

        ans, _ = dfs(root)
        print(ans)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず単調スタックを使用して最も近い、より大きな近傍を計算します。 次に、固定された L エッジと R エッジに従って暫定的な親リストを構築し、不可能な構成を即座に拒否します。 残り ？ ノードは高さを最大化するために貪欲に接続されます。 DFS は、1 回の事後探索で最大直径を効率的に計算します。
