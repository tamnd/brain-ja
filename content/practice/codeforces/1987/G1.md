 ## 問題の理解

 順列が与えられています`p`長さの`n`そして文字列`s`だけからなる同じ長さの`?`。 各ポジション`i`順列では 2 つの特別なインデックスを定義します。`l_i`前の最後のインデックスです`i`順列値が大きい場合、および`r_i`の後の最初のインデックスです`i`値が大きいところ。 そのようなインデックスが存在しない場合は、デフォルトで`i`自体。 

タスクは、無向グラフを構築することです。`n`頂点。 各頂点`i`どちらにも接続できます`l_i`または`r_i`すべてのキャラクターがそうだから`?`。 目標は、結果として得られるグラフが接続され、可能な最大直径 (任意の 2 つの頂点間の最大距離として定義される) を持つようにこれらのエッジを選択することです。 接続されたグラフを形成できない場合は、出力します。`-1`。 

制約が意味するのは、`n`すべてのテスト ケースで合計最大 400,000 件まで可能です。 あらゆることを試す素朴なアプローチ`2^n`エッジを選択する方法は不可能です。 の構造を活用する必要があります。`l_i`そして`r_i`線形または線形に近い時間で効率的に直径を計算します。 

順列が厳密に増加または減少している場合、微妙なエッジケースが発生します。 そのような場合には、`l_i`または`r_i`デフォルトで設定できます`i`それ自体は、グラフを拡張しない自己ループを作成します。 例えば、`p = [1,2,3]`につながる`l_2 = 2`、`r_2 = 3`、間違ったエッジを選択すると、接続性や直径が小さくなる可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、すべてのエッジのあらゆる組み合わせが試行されます。`?`文字。 組み合わせごとに、グラフを構築し、DFS または BFS を使用して接続を確認し、ダブル BFS を使用して直径を計算します。 それぞれの組み合わせは、`O(2^n)`グラフの構築と確認は`O(n)`、それは完全に不可能になります`n`400,000まで。 

重要な洞察は、次のように定義されるグラフであるということです。`l_i`そして`r_i`より大きな隣接するエッジに向かって一貫してエッジが選択されている場合、根のある木の森になります。 すべての頂点には、より大きな要素への固有の「上向き」エッジがあり、順列のグローバル最大値をルートとするツリーを形成します。 だって全部`?`左または右のいずれかをより大きな隣接点に向けることができます。最大直径は、可能な場合は左と右を交互に、ジグザグにエッジを選択することによって達成されます。 より体系的には、直径は暗黙的ツリー上の動的プログラミングによって取得できます。つまり、各ノードの最長の下向きパスを計算し、各ノードでの 2 つの最大パスを組み合わせて候補直径を形成します。 グローバル最大値が答えを与えます。

 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. コンピューティング`l_i`そして`r_i`みんなのために`i`単調スタックを効率的に使用します。 左から右に繰り返す`l_i`、減少するスタックを維持します。 各要素について、上部が大きくなるまで小さい要素をポップします。これにより、次のようになります。`l_i`。 右から左へ繰り返します`r_i`。 
2. グラフを暗黙的に配列として表現する`parent[i]`。 最大直径については、常にそれぞれを接続します`i`大きい方へ`l_i`または`r_i`葉までの距離を最大化します。 
3. 深さ優先検索 (DFS) を使用して、各サブツリーの高さを計算します。 再帰から戻るときに、子の中で最大の 2 つの高さを追跡し、このノードの直径の候補を、最大の 2 つの高さに 2 を加えた合計 (接続エッジの場合) として計算します。 
4. グローバル変数を保持する`diameter`より大きな直径の候補が見つかるたびにそれを更新します。 
5. グローバル最大値をルートとするツリーに対する DFS が完了した後、`p`、計算されたものを出力します`diameter`。 

機能する理由: 次に大きい隣接ノードに常に接続することで、ツリーがグローバル最大値にルートすることを保証し、距離を最大化します。 各ノードの 2 つの最大の高さを組み合わせると、内部ノードを通過するパスが確実に考慮されます。 この問題ではどちらかを選択できるため、この貪欲な選択は有効です。`l_i`または`r_i`自由に、より大きな近傍を選択すると、深さが圧縮されるのではなく拡張されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        s = input().strip()

        l = [0] * n
        r = [0] * n

        stack = []
        for i in range(n):
            while stack and p[stack[-1]] < p[i]:
                stack.pop()
            l[i] = stack[-1] if stack else i
            stack.append(i)

        stack = []
        for i in range(n-1, -1, -1):
            while stack and p[stack[-1]] < p[i]:
                stack.pop()
            r[i] = stack[-1] if stack else i
            stack.append(i)

        children = [[] for _ in range(n)]
        root = p.index(max(p))
        for i in range(n):
            if i == root:
                continue
            # choose the neighbor further from root for max diameter
            if abs(i - l[i]) > abs(i - r[i]):
                children[l[i]].append(i)
            else:
                children[r[i]].append(i)

        diameter = 0
        def dfs(u):
            nonlocal diameter
            heights = []
            for v in children[u]:
                h = dfs(v)
                heights.append(h)
            if not heights:
                return 0
            heights.sort(reverse=True)
            if len(heights) >= 2:
                diameter = max(diameter, heights[0] + heights[1] + 2)
            diameter = max(diameter, heights[0] + 1)
            return heights[0] + 1

        dfs(root)
        print(diameter)

if __name__ == "__main__":
    solve()
```最初の 2 つのループは計算します`l_i`そして`r_i`単調スタックを使用して線形時間で。 の`children`配列は、各ノードに対して深さを増やす近傍を選択することによってツリー構造を表します。 DFS は高さを再帰的に計算し、グローバルな高さを更新します。`diameter`上位 2 人の子の高さを使用します。 実際には各ノードに最大 2 つの子があり、全体の操作が線形に保たれるため、ソートの高さは許容されます。
