 ## 解決策
 ## 問題の理解

 この問題への入力は意図的に有益ではありません。入力は常に同じ固定文字列であり、意味のある形で答えに影響を与えることはありません。 タスクは、入力に対する計算ではなくステートメントによって暗黙的に定義された単一の事前定義された文字列を出力することです。 

入力が存在するとしても、唯一の合理的な解釈は、それが赤いニシンであるということです。 実際の問題は、ステートメントで指定された語句に関して「欠落文字」という考えから導出できる文字列を要求することです。 

自然な解釈では、英語の小文字のアルファベットを見て、大文字と小文字を無視し、スペースを無視して、指定されたフレーズ「BAD問題」に現れるすべての文字を削除します。 残りの文字はアルファベット順に出力されます。 

入力行が 1 つだけで変動がないため、制約は事実上自明です。 これは、時間的プレッシャーの下でアルゴリズム的アプローチのどちらかを選択する必要がないことを意味します。 重要なのは、「欠落文字」が何を指すのかを正しく解釈し、大文字と小文字の区別と順序に一貫性を持たせることだけです。 

ここでの主な微妙なエッジケースは、文字の正規化の処理です。 大文字と小文字を一貫して処理しないと、「B」と「b」のような文字が異なるものであると誤ってみなされる可能性があります。 たとえば、大文字と小文字の区別を誤って保持すると、アルファベットが完全に存在しないのに完全に存在すると信じてしまう可能性があり、またその逆も同様です。 もう 1 つの特殊なケースは、処理中に誤ってスペース文字を含めることです。これは完全に無視する必要があります。 

## アプローチ

 ブルートフォースメンタルモデルは、フレーズから開始して、完全なアルファベット文字列から繰り返し文字を削除することです。 具体的には、「a」から「z」までのすべての文字を含むセットを初期化し、入力文字列の文字を反復処理して、小文字に変換した後に各アルファベットを削除します。 最終的にセットに残ったものが答えになります。 

これが機能するのは、メンバーシップの設定と削除が平均して一定の時間であるため、入力が長くても瞬時に終了するためです。 より素朴な変形は、アルファベットの各文字について、入力文字列全体をスキャンして、それが表示されるかどうかをチェックすることです。 このアプローチでは 26 回のフル スキャンが実行されます。これはここではまだ簡単ではありませんが、同じデータに対して冗長で繰り返されるスキャンの非効率性を示しています。 

重要な構造上の観察は、入力がテスト ケース間で変化せず、少数の固定文字セットのみが含まれていることです。 これにより、この問題はアルファベットの補集合を計算することと等価になります。

 ## アルゴリズムのチュートリアル

 1. 「a」から「z」までのすべての小文字の英字を含むセットを作成します。 これは、可能な出力文字の全世界を表します。 
2. 入力文字列を読み取ります。 
3. 文字列内の各文字を繰り返し処理します。 文字が文字の場合は、それを小文字に変換し、残りの候補のセットから削除します。 これにより、入力に存在しない文字のみを追跡することが保証されます。 
4. すべての文字を処理した後、セットには入力に出現しなかった文字が正確に含まれます。 
5. 残りの文字をアルファベット順に並べ替え、最終的な出力文字列に連結します。 

この問題では辞書編集的に順序付けされた決定的な結果が期待される一方で、セットでは意味のある順序付けが保持されないため、順序付けのステップが必要です。 

### なぜ効果があるのか

すべてのステップで、残りの文字のセットは、入力内でまだ観察されていない文字を正確に表します。 文字を見つけたときにのみ削除するので、残すべき文字を誤って削除することはありません。 同様に、入力に出現するすべての文字が少なくとも 1 回削除されます。 すべての文字を処理した後、セットは入力内の文字を正確に補ったものになります。これはまさに「欠落文字」を指します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()

    full = set("abcdefghijklmnopqrstuvwxyz")

    for c in s:
        if c.isalpha():
            full.discard(c.lower())

    print("".join(sorted(full)))

if __name__ == "__main__":
    solve()
```このソリューションでは、完全なアルファベットをセットとして初期化し、入力に出現する文字を削除します。 の使用`discard`文字がすでに存在しない場合のエラーを回避します。これは大文字と小文字の正規化によって発生する可能性があります。 最後に並べ替えることで、辞書編集上の順序が保証されます。
