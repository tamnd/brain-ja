 ## 解決策
 ## 問題の理解

 私たちには、固定されたエスカレーター構造と、身長が既知の人々のセットが与えられています。 ヴラドも身長あるし。 エスカレーターには等間隔の階段があり、各階段の高さは一定値ずつ増加します。 問題は物理的な動きではなく、二人の人間を 2 つの異なるステップに配置して、二人の間の垂直距離が身長差と正確に一致するかどうかです。 

入力内の各人物について、段差制約と高さ差制約の両方が完全に一致するように、Vlad とその人物のステップのペアが存在するかどうかを個別に決定する必要があります。 そのような配置が存在する場合、その人をカウントします。 

重要な観察は、各ステップで正確に高さが増加するため、段差は常に固定値の倍数であるということです。`k`。 これにより、問題はすぐに、指定された高さの差が次のように表現できるかどうかを確認するようになります。`d * k`ある整数に対して`d`エスカレーターの範囲内に収まります。 

制約は小さく、テスト ケースは最大 1000 件、テスト ケースごとに最大 50 人です。 これにより、テスト ケースごとのソリューションは O(n) で十分であり、1 人あたりの単純な算術チェックでも十分であることが保証されます。 

一般的なエッジケースは、高さの差がゼロである場合、または高低差が次の値で割り切れない場合に発生します。`k`。 もう 1 つの微妙なケースは、たとえ割り切れる場合であっても、必要なステップ差が利用可能なステップ数を超える場合です。 両方の条件を同時に適用する必要があります。 

単純な間違いは、各人についてすべてのステップのペアをシミュレートしようとすることです。これは不必要であり、絶対的な位置ではなく差だけが重要であるという事実を見落とす危険があります。 

## アプローチ

 ブルートフォースソリューションでは、Vlad とすべての人のすべてのステップを試し、段差と高さの違いが有効に調整されているかどうかを確認します。 人ごとに、これをすべて繰り返す必要があります`m * m`ステップ ペア、テスト ケースごとに O(n m^2) になります。 制約の下では技術的にはまだ小さいですが、概念的には非効率であり、問​​題の構造を曖昧にします。 

重要な単純化は、重要なのはヴラドと他の人の絶対的な身長差だけであると認識することです。 この違いが解決されれば、あとはエスカレーターの形状を使ってそれを実現できるかどうかが唯一の問題です。 各ステップが正確に貢献するため、`k`身長差、その差が で割り切れるかどうかを確認しています。`k`暗黙のステップ距離が範囲内に収まるかどうか`[1, m-1]`。 

これにより、問題が個人ごとの直接的な算術条件に縮小され、すべての組み合わせ推論が排除されます。

 | ブルートフォース | O(n m^2) | お(1) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ヴラドと各人物の絶対身長差を計算します。 これは、エスカレーターの階段を使用して説明する必要がある合計の垂直ギャップを表します。 
2. この差が次の式で割り切れるかどうかを確認します。`k`。 そうでない場合は、各ステップが正確に寄与するため、一連のステップ動作が高さのギャップと正確に一致することはありません。`k`単位。 
3. 割り切れる場合は、必要なステップ距離を次のように計算します。`diff // k`。 
4. このステップ距離が厳密に 1 と 2 の間にあることを確認します。`m - 1`。 2 つの異なるステップが必要であるため、ゼロは無効であり、エスカレーターの範囲を超えることはできません。 
5. 両方の条件を満たすすべての人を数えます。 

### なぜ効果があるのか

 エスカレーターは、有効な高さの差が正確に次の整数倍である離散線形メトリックを誘導します。`k`。 有効な会話は、インデックスの差が高さの差を で割った商に一致する 2 つの異なるステップを選択することに相当します。`k`。 ステップは 1 から 1 までの範囲にあるため、`m`、達成可能な最大インデックス差は次のとおりです。`m - 1`。 これにより、すべての有効な構成が完全に特徴付けられるため、可分性と境界をチェックするだけで必要かつ十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m, k, H = map(int, input().split())
    h = list(map(int, input().split()))
    
    ans = 0
    
    for x in h:
        diff = abs(x - H)
        
        if diff == 0:
            continue
        
        if diff % k != 0:
            continue
        
        d = diff // k
        
        if 1 <= d <= m - 1:
            ans += 1
    
    print(ans)
```入力を読み取った後、各人物を反復処理して、Vlad との絶対身長差を計算します。 2 つの異なるステップが必要となるため、差がゼロのケースはすぐに破棄されます。 次に、次のように割り算条件を強制します。`k`、エスカレーターのステップ サイズが高さのギャップを表現できるようにします。 最後に、暗黙のステップ距離がエスカレーターの範囲内に収まることを確認します。 有効な各人が答えをインクリメントします。 

すべての構造がこれらの算術制約によって捕捉されるため、実装は意図的に最小限に抑えられています。

import sys, io

    sys.stdin = io.StringIO(inp)
    import sys as _sys
    input = _sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n, m, k, H = map(int, input().split())
        h = list(map(int, input().split()))

        for x in h:
            diff = abs(x - H)
            if diff == 0:
                continue
            if diff % k == 0 and 1 <= diff // k <= m - 1:
                ans += 1
        out.append(str(ans))
    return "\n".join(out)

 ## 特殊なケース

 すべての高さがヴラドの高さと等しい場合、すべての差はゼロとなり、問題には 2 つの異なるステップが必要となり、自己マッチングが無効になるため、何もカウントされません。 

いつ`k`はすべての身長差に比べて大きいため、ほとんどの差は可算性チェックに失敗し、生の差が近いように見えても有効な会話はゼロになります。 

いつ`m = 1`、異なるステップのペアは存在しないため、ステップ距離の制約を満たすことができないため、高さの値に関係なく、答えは常に 0 になります。
