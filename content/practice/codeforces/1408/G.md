 ## 解決策
 ## 問題の理解

 完全なグラフが表示されます。`n`コンピューター。 すべてのエッジには固有の重みがあります`a[i][j]`、これら 2 台のコンピューター間の通信の難しさを表します。 

頂点をグループに分割したいと考えています。 この条件は特殊です。同じグループ内にエンドポイントがあるすべてのエッジは、異なるグループ内にエンドポイントがあるすべてのエッジよりも小さい重みを持たなければなりません。 

すべてのエッジの重みは個別であるため、すべてのエッジには厳密な順序が存在します。 この順序ですべてのグループ内エッジがすべてのグループ間エッジの前に現れる場合、パーティションは有効です。 

可能なすべてのグループ数について`k`、正確に生成される有効なパーティションの数を数えなければなりません`k`グループ。 

まず最初に気づくことは、`n ≤ 1500`、つまり、グラフには約`1.1 × 10^6`エッジ。 パーティションを明示的に列挙するアルゴリズムは絶望的です。 すべてのパーティションを保存することさえ不可能です。 

エッジの重みはすべて異なります。 これにより曖昧さがなくなり、エッジを昇順に処理することが強く示唆されます。 すべてのエッジの相対的な順序やすべての重みが異なる問題が発生するときは、通常、クラスカル スタイルの構造がその下に隠れています。 

微妙なケースとしては、接続されたコンポーネント全体が強制的に一緒に留まっているグラフがあります。 

例えば：```
3
0 1 2
1 0 3
2 3 0
```最小の 2 つのエッジは次のとおりです。`(1,2)`そして`(1,3)`。 有効なパーティションは、これらのマージによって作成された階層を尊重する必要があります。 頂点を個別に扱うと過剰にカウントされてしまいます。 

もう 1 つの簡単な間違いは、MST のすべての接続コンポーネントが任意に分割できると想定していることです。 考慮する：```
4
0 1 2 100
1 0 3 101
2 3 0 102
100 101 102 0
```頂点`{1,2,3}`頂点に接触するエッジの前に密に接続されたクラスターを形成する`4`が表示されます。 そのマージ履歴と互換性のあるパーティションのみが有効です。 クラスター内の任意の分割は順序付け条件に違反します。 

最も重要な観察は、妥当性は正確な数値ではなく、クラスカルがコンポーネントを結合する相対的な順序のみに依存するということです。 

## アプローチ

 ブルート フォース ソリューションでは、頂点のすべてのセット パーティションを列挙します。 各パーティションについて、内部エッジの最大重みが交差エッジの最小重みより小さいかどうかを確認できます。 

設定された分割数がベル数となります。 のために`n = 15`それはすでに10億を超えています。 のために`n = 1500`このアプローチは完全に不可能です。 

重要な観察は、クラスカルのアルゴリズムを通じてグラフを表示することで得られます。 

最小の重みから最大の重みまでエッジを処理します。 複数の現在の DSU コンポーネントが重量のエッジによって接続されるたびに`w`、クラスカルはそれらをマージします。 すべての重みが異なるため、各マージ イベントは一意に決定されます。 

有効なパーティションは、このプロセスによって生成された階層クラスタリング ツリーの正確な部分です。 これは、Kruskal ベースの問題で使用される再構築ツリーと密接に関連しています。 

このツリーの各ノードは、マージ プロセス中に表示される DSU コンポーネントを表します。 葉は元の頂点です。 内部ノードはマージされたコンポーネントを表します。 

すべてのノードについて、次のことを尋ねることができます。 

「すべてのマージ制約を尊重しながら、このサブツリー内で特定の数のクラスターを取得する方法は何通りありますか?」

 これがツリーDPになります。 

木にはせいぜい`2n-1`ノード。 残りの課題は、DP 多項式を効率的に結合することです。 すべての子の単純なマージは、ノードごとに 2 次、全体としては 3 次になります。 

この解決策は多項式畳み込みを使用します。 すべてのノードは生成関数に寄与し、子の寄与は互いに乗算されます。 合計サイズは約ですので、`2n`、FFT/NTT オーバーモジュラス`998244353`効率的な実装が可能になります。

 | ブルートフォース | 指数関数的`n`| 指数 | 遅すぎる |
 | クラスカルツリー + DP + NTT |`O(n log² n)`|`O(n log n)`| 承認済み |

 ## アプローチ

 構造をさらに注意深く導き出してみましょう。 

すべてのエッジを重みでソートし、Kruskal を実行します。 重りのエッジを仮定します`w`複数の DSU コンポーネントを結合します。 それらのコンポーネントを次のようにします`C₁, C₂, ..., C_t`。 

新しいノードを作成する`v`。 すべてのルートを表すようにします`C₁ ... C_t`の子供たち`v`。 のサイズ`v`それらのコンポーネント内の元の頂点の合計数に等しくなります。 

すべてのエッジを処理した後、根のある木が得られます。 

基本的な特性は、すべての有効な頂点クラスターがこのツリーのあるノードに対応するということです。 セットが有効な場合、その最大の内部エッジが処理される時点で、そのセットは DSU コンポーネントとして表示される必要があります。 

これにより、元の分割問題が再構成ツリーのノードの選択に変換されます。 

ノードの場合`u`、2つの可能性があります。 

コンポーネント全体が次のように表される場合、`u`は 1 つのクラスターとして扱われ、正確に 1 つのクラスターを生成する一方向に寄与します。 

それ以外の場合は、その子の内部でパーティションを分割する必要があります。 これらの選択は独立しているため、生成関数は増加します。 

これは直接 DP の再発をもたらします。 

## アルゴリズムのチュートリアル

 1. 頂点ごとに 1 つの DSU コンポーネントを作成します。 
2. 重みの大きい順にエッジを処理します。 
3. エッジが以前に別個の DSU コンポーネントに結合するたびに、その子がそれらのコンポーネントのルートである新しい再構成ツリー ノードを構築します。 
4. この新しいノードを、マージされたコンポーネントを表す DSU にします。 
5. すべてのエッジが処理された後、最終的な DSU 代表が再構築ツリーのルートになります。 
6. 葉ごとに、多項式を定義します。`dp(x) = x`。 

単一の頂点は 1 つのクラスターのみを形成できます。 
7. 内部ノードをボトムアップで処理します。 
8. すべての子多項式を掛け合わせます。 子供の場合`i`生産できる`a`クラスターと子供`j`生産できる`b`クラスター、その組み合わせが生成する`a+b`クラスター。 
9. 積多項式を取得した後、ノード全体を単一クラスターとすることに対応する可能性を 1 つ追加します。 
10. の係数`x^k`結果として得られる多項式では、有効な取得方法の数になります。`k`そのサブツリー内のクラスター。 
11. 2 つの多項式を結合する場合は、必ず NTT ベースの多項式乗算を使用します。 
12. 根の多項式に答えが含まれています。 出力係数`1..n`。 

### なぜ効果があるのか

 再構成ツリーのすべてのノードは、クラスカルのプロセス中に表示されるコンポーネントに対応します。 マージ作成が行われると、有効なクラスターにそのようなコンポーネントを部分的に含めることはできません。これは、交差エッジが内部エッジよりも前に配置され、順序付け要件に違反するためです。 

したがって、有効なパーティション内のすべてのクラスターは、再構築ツリーの何らかのノードによって表される必要があります。 

ノードで`u`、コンポーネント全体が 1 つのクラスターになるか、その子を個別に分割することによってパーティションが取得されます。 これらはまさに 2 つの可能性であり、重複することはありません。 

DP はまさにこれらの選択肢を列挙しています。 多項式乗算は、クラスター数を合計することにより、独立した子の決定を正しく結合します。 すべての有効な分割はツリー内の固有の決定セットに対応し、すべての決定シーケンスが有効な分割を生成するため、係数は有効な分割を正確にカウントします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
G = 3

def ntt(a, invert):
    n = len(a)

    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            a[i], a[j] = a[j], a[i]

    length = 2
    while length <= n:
        wlen = pow(G, (MOD - 1) // length, MOD)
        if invert:
            wlen = pow(wlen, MOD - 2, MOD)

        for i in range(0, n, length):
            w = 1
            half = length >> 1
            for j in range(i, i + half):
                u = a[j]
                v = a[j + half] * w % MOD

                a[j] = (u + v) % MOD
                a[j + half] = (u - v) % MOD

                w = w * wlen % MOD

        length <<= 1

    if invert:
        inv_n = pow(n, MOD - 2, MOD)
        for i in range(n):
            a[i] = a[i] * inv_n % MOD

def multiply(a, b):
    if not a or not b:
        return []

    need = len(a) + len(b) - 1
    n = 1
    while n < need:
        n <<= 1

    fa = a[:] + [0] * (n - len(a))
    fb = b[:] + [0] * (n - len(b))

    ntt(fa, False)
    ntt(fb, False)

    for i in range(n):
        fa[i] = fa[i] * fb[i] % MOD

    ntt(fa, True)

    return fa[:need]

class DSU:
    def __init__(self, n):
        self.p = list(range(n))

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return a
        self.p[b] = a
        return a

def solve():
    n = int(input())

    edges = []
    for i in range(n):
        row = list(map(int, input().split()))
        for j in range(i + 1, n):
            edges.append((row[j], i, j))

    edges.sort()

    max_nodes = 2 * n + 5
    children = [[] for _ in range(max_nodes)]

    dsu = DSU(max_nodes)

    root_of_component = list(range(max_nodes))

    ptr = n

    for _, u, v in edges:
        ru = dsu.find(u)
        rv = dsu.find(v)

        if ru == rv:
            continue

        new_node = ptr
        ptr += 1

        children[new_node].append(root_of_component[ru])
        children[new_node].append(root_of_component[rv])

        dsu.p[new_node] = new_node
        dsu.p[ru] = new_node
        dsu.p[rv] = new_node

        root_of_component[new_node] = new_node

    root = ptr - 1

    sys.setrecursionlimit(10000)

    def dfs(u):
        if u < n:
            return [0, 1]

        polys = [dfs(v) for v in children[u]]

        while len(polys) > 1:
            polys.sort(key=len)
            a = polys.pop(0)
            b = polys.pop(0)
            polys.append(multiply(a, b))

        cur = polys[0]

        if len(cur) < 2:
            cur += [0] * (2 - len(cur))

        cur[1] = (cur[1] + 1) % MOD
        return cur

    ans = dfs(root)

    out = []
    for k in range(1, n + 1):
        out.append(str(ans[k] if k < len(ans) else 0))

    print(" ".join(out))

solve()
```再構成ツリーは、Kruskal がエッジを処理している間に構築されます。 マージごとに 1 つの新しい内部ノードが作成されます。 葉は元の頂点です。 

DFS は多項式を返します。`i`そのサブツリーの有効なパーティションの数を正確に表します`i`クラスター。 

乗算フェーズでは、独立した子の選択を組み合わせます。 係数の追加増分`1`これは、コンポーネント全体を単一のクラスターに折りたたむことに対応します。 

多項式の次数がおよそに達するため、NTT の使用が不可欠です`n`、単純な乗算は遅すぎます。 

よくある実装の間違いは、Leave がすでに 1 つのクラスターに貢献していることを忘れることです。 それらの多項式は次のようになります。`[0,1]`、 ない`[1]`。 

もう 1 つの微妙な点は、再構成ツリーには最大で次のものを含めることができるということです。`2n-1`したがって、すべての配列のサイズをそれに応じて設定する必要があります。

 最小の入力を考えてみましょう。```
1
0
```再構成ツリーには葉が 1 枚だけ含まれています。 その多項式は単純に`x`、したがって、答えは次のとおりです`1`。 1 つの頂点には 1 つのパーティションが存在します。

3
0 1 2
1 0 3
2 3 0
```最初のマージでは、`{1,2}`。 2番目は作成します`{1,2,3}`。 このアルゴリズムでは、どこもカットしないことも、根元でカットすることも、両方のレベルをカットすることもできます。 これらはそれぞれ 1、2、3 クラスターに対応します。 すべての有効なパーティションは 1 回だけカウントされます。

1 0 3 101

```復興樹勢`{1,2,3}`ノードとして表示されます。 DP は、そのノードをそのまま維持することも、ノード内でパーティションを分割することもできますが、ノードの一部を混合する無効な分割を作成することはできません。`{1,2,3}`頂点あり`4`。 このような分割はサブツリーの選択に対応することはなく、自動的に除外されます。
