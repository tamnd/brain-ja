 ## 解決策
 ## 問題の理解

 私たちには、2D グリッド上に配置された一連の強盗と、それぞれ固定位置を持つ一連のサーチライトが与えられます。 強盗は制限された方法で移動します。1 回の移動で、すべての強盗は X 座標を 1 増やすか、Y 座標を 1 増やすかのいずれかになります。 サーチライトから強盗が見える場合、構成は安全ではありません。可視性とは、強盗の座標がサーチライトの座標以下であることを意味します。 目標は、サーチライトで強盗が見えない構成への最小移動回数を決定することです。 

入力範囲は中程度です: 最大 2000 人の強盗と 2000 個のサーチライト、最大の座標$10^6$。 これにより、あらゆる可能な動きの単純なシミュレーションが除外されます。$10^6$強盗とサーチライトごとに反復処理が行われ、その結果、何兆回もの操作が行われます。 代わりに、構造化された動きと可視性の制約を活用して最小限の動きを効率的に計算するアプローチが必要です。 

すべての強盗が最初にすべてのサーチライトの範囲外にいる場合、微妙なエッジケースが発生します。 たとえば、強盗が (5,5) にいて、最も近いサーチライトが (2,3) にある場合、移動は必要ありません。 ある最大値を超えるまで常に座標をインクリメントする不注意な実装では、移動数が過剰にカウントされてしまいます。 もう 1 つのエッジ ケースは、複数のサーチライトがカバー範囲内で重なっている場合です。 安全性を確保するために、アルゴリズムは最悪の場合の適用範囲を考慮する必要があります。 

## アプローチ

 ブルートフォース手法は概念的には単純です。あらゆる可能な一連の動きをシミュレートし、そのたびに強盗が安全かどうかを確認します。 それぞれの動きには 2 つのオプションがあり、$2^k$のシーケンス$k$動きます。 座標が次の高さになる可能性があることを考慮すると、$10^6$、これでは遅すぎます。 

より構造化されたアプローチは、各サーチライトを個別に回避するために必要な最小シフトの観点から考えることです。 単一の強盗と単一のサーチライトの場合、強盗はサーチライトの x 座標または y 座標を超えなければなりません。 させて$dx = \max(0, c_j - a_i + 1)$そして$dy = \max(0, d_j - b_i + 1)$。 少なくとも私たちが行動すれば、強盗は安全です$dx$右に移動するか、$dy$上に移動します。 問題は、すべての移動がステップごとに一方向でなければならないことを考慮して、すべての強盗とすべてのサーチライトにわたるこれらの個別の要件を組み合わせて、グローバルな最小移動数を見つけることに帰着します。 

重要な洞察は、一方向への移動数を列挙し、その数が与えられた場合に必要な最小の移動数を計算できることです。 形式的には、各強盗とサーチライトのペアの x 距離を事前計算できます。$dx$と y 距離$dy$。 次に、右の動きの回数を繰り返すことができます$rx$0から最大まで$dx$対応する上への移動の最小数を計算します$ry$必須。 合計移動量は、$rx + ry$。 このようなすべての組み合わせで最小値を取ることにより、全体的な最小値の動きを見つけます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(最大座標)) | お(1) | 遅すぎる |
 | 最適 | O(n*m + max_dx) | O(n*m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 空のリストを初期化して、各強盗とサーチライトのペアの x 距離と y 距離を保存します。 強盗ごとに$i$そしてサーチライト$j$、計算する$dx = \max(0, c_j - a_i + 1)$そして$dy = \max(0, d_j - b_i + 1)$。 追加$(dx, dy)$リストに。 これにより、サーチライトから逃れるための最小限の右と上への移動が捕捉されます。 
2. ペアのリストを次の基準で並べ替えます。$dx$昇順で。 並べ替えることにより、右の移動の数を増やすことで、必要な上への移動がどのように減少するかを効率的に検討できます。 
3. 配列を初期化する$max\_dy\_suffix$最大値を保存する$dy$すべてのペアに対して$dx \ge k$。 この事前計算により、特定の右移動カウントに対して一定時間内で必要な上移動をクエリできます。 
4. 右に移動できる回数を繰り返します。$rx$0から最大まで$dx$すべてのペアの中で。 それぞれについて$rx$、事前計算されたものを使用します$max\_dy\_suffix$最大値を見つけるために$dy$すべてのペアに対して、$dx > rx$。 この選択に必要な合計手数は次のとおりです。$rx + max\_dy\_suffix[rx]$。 
5. すべての最小合計移動数を追跡する$rx$。 この最小値を出力します。 

機能する理由: それぞれの強盗とサーチライトのペアは、危険な位置を長方形に配置します。 このアルゴリズムは、すべての長方形を残すために必要な x 軸と y 軸に沿った最小のシフトを計算します。 右と上の間で実行可能なすべての動きの分割を考慮し、反対方向に必要な最大の動きを取ることで、すべての強盗がすべてのサーチライトの範囲外に移動することを保証します。 事前計算により、最悪の場合のペアを見逃すことなく、必要な y 移動を効率的に選択できるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
robbers = [tuple(map(int, input().split())) for _ in range(n)]
lights = [tuple(map(int, input().split())) for _ in range(m)]

pairs = []
for a, b in robbers:
    for c, d in lights:
        dx = max(0, c - a + 1)
        dy = max(0, d - b + 1)
        pairs.append((dx, dy))

pairs.sort()
max_dx = max(dx for dx, dy in pairs) if pairs else 0
max_dy_suffix = [0]*(max_dx + 2)
for dx, dy in reversed(pairs):
    max_dy_suffix[dx] = max(max_dy_suffix[dx], dy)
for i in range(max_dx, -1, -1):
    max_dy_suffix[i] = max(max_dy_suffix[i], max_dy_suffix[i+1])

ans = float('inf')
for rx in range(max_dx + 1):
    total = rx + max_dy_suffix[rx]
    ans = min(ans, total)
print(ans)
```コードはまず、各ロバーライト ペアに必要なすべての dx および dy シフトを計算します。 ペアをソートすると、rx を繰り返すときに、残りのペアに必要な最大 dy を効率的に決定できるようになります。 サフィックス配列を使用すると、最悪の場合の dy を定数時間で検索できます。 これにより、重複するサーチライトの照射範囲を回避するために必要な移動を過少カウントすることがなくなります。
