 ## 解決策
 ## 問題の理解

 サイズの配列に対して一連の操作を構築するように求められます。$n$それは次のように始まります$[1, 2, \dots, n]$。 各操作で 2 つの位置を選択します$x$そして$y$そして両方を置き換えます$a_x$そして$a_y$任意の関数によって返された値を使用$f(a_x, a_y)$。 重要な制約は、すべての演算の後、配列には最大 2 つの異なる数値が含まれるべきであり、演算はどの関数に対しても機能する必要があるということです。$f$。 入力はただ$n$、そして操作のシーケンスを出力する必要があります。 

重要な観察点は、関数が$f$は任意で未知であるため、その特定の動作に依存することはできません。 つまり、値ではなくインデックスのみに基づいて一連の操作を設計する必要があります。 操作によってマージされた 2 つの位置は、その値が何であるかに関係なく、その後常に同じ値を保持します。 これは、最終的な配列で最大 2 つの異なる値を保証するためにインデックスをグループ化する戦略を示唆しています。 

制約$1 \le n \le 15000$そして限界$5 \cdot 10^5$操作は、次のような解決策を示します。$O(n)$操作は許容されます。 すべてのインデックスのペアを試したり、実行したりする単純な試み$O(n^2)$操作が制限を超えてしまいます。 

微妙なエッジケースが発生する場合$n = 1$。 配列にはすでに 1 つの数値が含まれているため、操作は必要ありません。 もう一つのケースは次のような場合です。$n = 2$; 両方の位置を接続する 1 回の操作で十分です。 常に発生する不用意なアプローチ$n-1$大規模な場合、操作は操作制限を超える可能性があります$n$。 

## アプローチ

 ブルートフォースアプローチでは、すべての要素を他のすべての要素とペアにして、両方を次の要素に置き換えようとします。$f(a_i, a_j)$。 これは、すべてのペア操作がローカルで個別の値の数を減らすため機能しますが、それには次のことが必要です。$O(n^2)$実行不可能な操作$n = 15000$。 

最適なアプローチは分割統治に依存します。 配列を再帰的に 2 つの半分に分割し、各半分のすべての要素を 1 つの代表にマージしてから、2 つの半分をマージすることができます。 具体的には、各グループの代表的なインデックスを選択し、他のすべてのインデックスをそれに接続します。 すべてのグループを処理すると、最終的に 2 つの代表が得られるため、配列全体には最大 2 つの異なる数値が含まれます。 

これが機能するのは、各操作で接続されたインデックスが同じ値を共有することが保証され、再帰構造により 2 つのグループのみが残ることが保証されるためです。 私たちは決して超えることはありません$n - 1$半分内でグループ化するための操作に加えて、2 つの半分を接続する最大 1 つの操作により、上限が与えられます。$n-1$オペレーション、これははるかに下にあります$5 \cdot 10^5$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 分割統治 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. もし$n = 1$、出力$0$操作。 配列はすでに 2 つの異なる数値の制約を満たしています。 
2. 配列を 2 つの半分に分割します。 各半分の最初の要素を代表として選択します。 
3. 各半分について、その半分の 1 つおきのインデックスを代表に接続します。 これにより、これらの操作の後、半分のすべての要素が同じ値を共有するようになります。 
4. 両サイドの代表 2 人を結びます。 この操作の後、配列全体には最大でも 2 つの異なる値が含まれます。各半分に 1 つずつ、それらの代表によってマージされます。 
5. ステップ 3 と 4 で生成されたすべてのインデックスのペアを出力します。 

機能する理由: 半分内の各マージ操作の後、その半分のすべての要素は、$f$。 半分の代表が結合されると、2 つの半分はそれぞれ 1 つの値を保持します。 これ以上の操作は必要ないため、最終的な配列には最大 2 つの値が含まれます。 各操作は機能から独立しています$f$、問題の要件を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
if n == 1:
    print(0)
    sys.exit(0)

ops = []

# choose first element as representative
rep = 1
for i in range(2, n + 1):
    ops.append((rep, i))

print(len(ops))
for x, y in ops:
    print(x, y)
```コードはエッジケースを処理します$n = 1$明示的に。 のために$n > 1$では、インデックス 1 を代表として選択し、他のすべてのインデックスをそれにマージします。 これにより、最大 2 つの異なる値が保証されますが、この構成では、単一の代表値を使用しているため、実際にはすべての値が等しくなります。 2 番目の代表者を選択する必要はありませんが、より構造化された分割統治が必要な場合は、このアプローチを再帰的に拡張できます。 使用する`sys.stdin.readline`高速入力が保証され、出力形式は必要な 1 から始まるインデックスと一致します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline
    n = int(input())
    if n == 1:
        return "0"
    ops = []
    rep = 1
    for i in range(2, n + 1):
        ops.append((rep, i))
    res = [str(len(ops))] + [f"{x} {y}" for x, y in ops]
    return "\n".join(res)

# provided samples
assert run("3\n") == "2\n1 2\n1 3", "sample 1"

# custom cases
assert run("1\n") == "0", "minimum size"
assert run("2\n") == "1\n1 2", "two elements"
assert run("5\n") == "4\n1 2\n1 3\n1 4\n1 5", "five elements"
assert run("15000\n").startswith("14999\n"), "large n"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 | 0 | 最小の配列を処理します |
 | 2 | 1ペア | 2 つの要素を正しくマージします。 
| 5 | 4ペア | 複数の要素を単一の値にマージします。

 ## 特殊なケース

 のために$n = 1$、操作は必要ありません。 アルゴリズムの出力`0`、それは正しいです。 のために$n = 2$、インデックス 1 と 2 を結合すると 1 つの操作が生成されます。 大型用$n$15000 などの場合、アルゴリズムは 14999 の演算を生成しますが、これは許容される 500000 を大幅に下回ります。すべての要素が 1 つの代表にマージされ、条件を自明に満たすため、出力では常に最大 2 つの異なる値が保証されます。
