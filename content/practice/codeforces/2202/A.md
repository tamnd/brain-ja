 ## 解決策
 ## 問題の理解

 問題は、原点から始まる 2D 整数グリッド上で一連の動きを構築することです。`(0,0)`そして目標地点で終了`(x,y)`。 各移動は 3 つの特定のタイプのいずれかである必要があります。つまり、2 つのユニットを右に移動し 1 つのユニットを上に移動する、垂直方向の変更なしで 3 つのユニットを右に移動する、または 4 つのユニットを右に移動し 1 つのユニットを下に移動する必要があります。 課題は、これらの動きだけを使用してターゲットに到達することが可能かどうかを判断することです。 

入力は複数のテスト ケースで構成され、それぞれにターゲットが指定されます。`(x,y)`。 制約により許可されるのは、`x`と同じくらい大きくなる`10^9`そして`y`間`-10^8`そして`10^8`。 これは、手の数が次のオーダーになる可能性があるため、考えられるすべての動きのシーケンスを列挙する総当り的な試みは実行不可能であることを意味します。`10^9 / 2`最悪の場合、これは 1 秒の制限時間には大きすぎます。 

明らかではないエッジ ケースには、X 軸から遠く離れた点や正確な垂直調整が必要な点が含まれます。 たとえば、到達する`(4,1)`増加する動きだけなので不可能です`x`4も減ります`y`1 ずつ増加し、許可された動きの組み合わせではネットを生成できません`(4,1)`から`(0,0)`。 同様に、大きな x 値と極端な y 値の場合は、垂直方向の増分と減分が正しくバランスが取れているかどうかを慎重にチェックする必要があります。 

## アプローチ

 単純なアプローチでは、再帰的または BFS を使用して、次から始まるすべての一連の動きをシミュレートしようとします。`(0,0)`到達するまで 3 つの移動タイプをそれぞれ試してみます。`(x,y)`。 これはすべての可能性を徹底的に探索するため、原理的には正しいですが、状態の数はおよそ`x/2`ディメンションごとに最小値であり、次のように指数関数的に増加する可能性があります`x`、それは完全に非実用的になります`x`と同じくらい大きい`10^9`。 

重要な洞察は、手の代数を考慮することで得られます。 させて`a`、`b`、 そして`c`タイプの移動数を示します`(2,1)`、`(3,0)`、 そして`(4,-1)`それぞれ。 したがって、合計の x 座標は次のようになります。`2a + 3b + 4c = x`合計の y 座標は`a - c = y`。 これにより、問題は、非負の整数の 2 つの線形ディオファントス方程式の単純な系を解くことに帰着します。 観察結果は、`b`によって決定されます`b = x - 2a - 4c`そして`y = a - c`与える`a = y + c`。 これを x 方程式に代入すると、次のようになります。`b = x - 2(y + c) - 4c = x - 2y - 6c`。 非否定性を満たすためには、次のことが必要です。`b >= 0`そして`c >= 0`そして`a = y + c >= 0`。 これらの不等式が整数に対して成立する場合`c >= max(0, -y)`であれば、解決策は存在します。 

これにより、問題は次のことを確認するだけになります。`x - 2y`を考慮した後、6 の倍数として表すことができます。`c`。 さらに単純化することができます。`c`満たさなければなりません`0 <= c <= (x - 2y)/6`(整数の除算) と`c >= max(0, -y)`。 そのような場合`c`存在すれば、そのポイントに到達できます。

 ## アルゴリズムのチュートリアル

 1. 与えられた条件に対して`(x,y)`, まず単純な境界を確認します。 目標に到達できない場合は、`y`未満です`-x//4`以上`x//2`。 これは、下向きの移動では x の 4 単位ごとに y が 1 減少し、上向きの移動では x の 2 単位ごとに 1 ずつ増加し、x が与えられた場合に y の最大範囲が得られることを観察した結果から得られます。 
2. コンピューティング`c_min = max(0, -y)`。 これは下向きの最小数です`(4,-1)`負の数の上向き移動を避けるために必要な移動。`a = y + c`負ではない必要があります。 
3. コンピューティング`c_max = (x - 2*y)//6`。 これは次のように置き換えることから来ます`a = y + c`x 方程式に代入し、可能な最大値を求めます。`c`それはまだ許される`b`マイナスでないこと。 
4. もし`c_min <= c_max`、有効な`c`存在します。これは、対応する非負の整数を意味します。`a = y + c`そして`b = x - 2a - 4c`can be constructed. そうしないと、ポイントに到達できません。 
5. Output`YES`到達可能であれば、そして`NO`さもないと。 

機能する理由: このアルゴリズムは問題を、非負の整数制約を持つ線形ディオファントス方程式系の実現可能性をチェックすることに縮小します。 丁寧にバウンディングすることで`c`そして導き出す`a`そして`b`これにより、報告された「YES」は実際に到達可能なシーケンスに対応し、「NO」は不可能に対応することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can_reach(x, y):
    c_min = max(0, -y)
    c_max = (x - 2 * y) // 6
    if c_min <= c_max:
        return "YES"
    return "NO"

t = int(input())
for _ in range(t):
    x, y = map(int, input().split())
    print(can_reach(x, y))
```このソリューションは、説明した実現可能性チェックを直接実装します。 整数演算を使用して浮動小数点の問題を回避し、複数のテスト ケースを効率的に処理します。 の`max(0, -y)`負の移動数を決して選択しないようにし、整数の除算によって自動的に上限が下限に設定されます。`c`。
