 ## 解決策
 ## 問題の理解

 問題は、3 つの競合する母集団に関する確率的プロセスです。 決められた数のじゃんけん、紙から始めます。 時間の経過とともに、残りのすべての個体から個体のペアが均一にランダムに選択されます。 選択した 2 つのタイプが異なる場合は、じゃんけんのルールに従って、一方が排除されます。つまり、じゃんけんははさみに勝ち、はさみは紙に勝ち、紙はじゃんけんに勝ちます。 ペアが同じタイプの場合は何も起こりません。 

このプロセスは、1 つの種だけが残るまで続きます。 タスクは、3 つの種のそれぞれについて、その種がプロセス全体の唯一の生存者となる確率を計算することです。 

入力は、じゃんけん、紙の初期数を表す 3 つの整数だけです。 出力は、最終的な生存確率をこの順序で与える 3 つの実数です。 

重要な制約は、各カウントが最大 100 であることです。これにより、指数関数的な状態爆発が排除されます。 およそ 100 の 3 乗のサイズの状態空間は約 100 万個の構成に相当し、これは動的プログラミングのアプローチではほぼ実現可能です。 考えられるすべての相互作用シーケンスを列挙することを伴うものはすべて、考えられるイベント シーケンスの数が母集団の総サイズに応じて階乗的に増加するため、すぐに大きすぎます。 

素朴な考えは、モンテカルロを使用してランダムなプロセスを何度もシミュレートすることです。 これでは収束が遅くなり、特に確率が非常に小さいか非常に近い場合には、時間制限内で必要な精度を保証できません。 

もう 1 つのよくある落とし穴は、プロセスを独立したペアごとの消去法としてモデル化しようとすることです。 たとえば、ハサミが紙を除去することを考慮せずに、岩が独立してある程度の割合でハサミを除去すると仮定すると、ダイナミクスが歪みます。 相互作用は周期的であり、結合しているため、部分モデルは対称性を破り、不正確な確率を与えます。 

いずれかの種がゼロから始まる場合、微妙なエッジケースが現れます。 たとえば、最初にハサミがゼロである場合、じゃんけんは還元された 2 種の系で依然として直接相互作用しており、答えはこれら 2 つのタイプ間の決定論的な吸収に還元されるはずです。 3 つの種すべてが常に存在することを前提とした解決策は、これらの境界を誤って処理することになります。 

## アプローチ

 ブルートフォースの観点では、考えられるすべての状態と遷移にわたる確率プロセス全体をシミュレートします。 各状態はトリプル (r、s、p) によって定義され、その状態からの次のイベントは、すべてのペアの中から任意の個人のペアを均一に選択することに依存します。 合計 n 個の個体がある状態からは、O(n^2) 個の可能なペアがあり、各ペアは遷移を生成するか、何も実行しません。 これを完全な確率ツリーに拡張すると、分岐の数が指数関数的に増加します。 状態をメモ化したとしても、分岐要素は可能な相互作用の数に関連付けられたままであるため、イベントのシーケンスをすべて直接列挙することは不可能です。 

重要な観察は、プロセスが状態数に関してメモリを持たないということです。 (r, s, p) を固定すると、将来のすべての進化は歴史ではなく、これらのカウントのみに依存します。 これにより、その状態から岩石が最終的に勝つ確率を表す確率関数 f(r, s, p) を定義することができます。 他の 2 種についても同様です。 次のステップは、まさに次の相互作用を条件付けて、より小さな状態に関して f(r, s, p) を表現することです。

特定の状態から、選択される次のペアは、個別の個体のすべてのペアの中から一様にランダムになります。 次のイベントによって r が 1 減る確率は、じゃんけんのペアの数に比例します。これは、じゃんけんとじゃんけんの場合も同様です。 これは、すべての自明でない相互作用によって正確に 1 人の個体が除去されるため、厳密に総人口サイズが小さい州間での直接反復が生成されます。 これにより、総人口が減少するため、クリーンな動的プログラミングの順序付けが行われます。 

ブルートフォースはシーケンスを推論しようとするため失敗しますが、正しい定式化ではすべてのランダム性が状態間の局所的な遷移確率に圧縮されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべてのイベントシーケンスの完全なシミュレーション | 指数 | お(1) | 遅すぎる |
 | 状態 (r、s、p) に対する DP | O(n3) | O(n3) | 承認済み |

 ## アルゴリズムのチュートリアル

 probR[r][s][p]、probS[r][s][p]、probP[r][s][p] の 3 つの DP テーブルを定義します。各エントリは、その状態から開始して、じゃんけん、はさみ、または紙がそれぞれ最終的に生き残る確率を表します。 

1. 1 つの種だけが残る基本ケースを除き、すべての DP 値をゼロに初期化します。 r > 0 かつ s = p = 0 の場合、probR[r][0][0] = 1 になります。他の 2 つの種についても同様です。 これは、種が 1 つだけ存在する場合、結果はすでに決定されていることをコード化しています。 
2. すべての州を反復して総人口サイズを増加させます。 この順序付けにより、状態 (r、s、p) を計算するときに、より小さい状態へのすべての遷移がすでに既知であることが保証されます。 
3. 状態 (r、s、p) について、異なる種間で考えられる相互作用ペアの総数を計算します。 r・sじゃんけんペア、s・pじゃんけんペア、p・rじゃんけんペアがあります。 これらの合計により、状態が実際に変化する頻度が決まります。 
4. 次にどのインタラクションが発生するかに基づいて確率質量を分配します。 岩がハサミに出会った場合、ハサミは外され、(r, s−1, p) に進みます。 ハサミが紙に出会ったら、(r, s, p−1) に進みます。 紙が石と出会うと、(r−1, s, p) に進みます。 各遷移は、すべての有効な相互作用ペア間の相対確率によって重み付けされます。 
5. これらの遷移確率を使用して寄与を DP テーブルに蓄積し、現在の状態からより小さな状態に確率の塊を効果的に押し込みます。 
6. 初期構成 (r、s、p) に達するまで、すべての状態に対してこれを繰り返します。その値が最終的な答えになります。 

この順序付けが機能する理由は、すべての有効な遷移が r + s + p を厳密に 1 だけ減らすためです。 これにより、総人口でソートした場合に DP グラフが非循環であることが保証されます。 したがって、繰り返しは明確に定義されており、すでに計算されていない状態にループバックすることはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAX = 105

r0, s0, p0 = map(int, input().split())

probR = [[[0.0] * MAX for _ in range(MAX)] for _ in range(MAX)]
probS = [[[0.0] * MAX for _ in range(MAX)] for _ in range(MAX)]
probP = [[[0.0] * MAX for _ in range(MAX)] for _ in range(MAX)]

for i in range(MAX):
    probR[i][0][0] = 1.0
    probS[0][i][0] = 1.0
    probP[0][0][i] = 1.0

for r in range(MAX):
    for s in range(MAX):
        for p in range(MAX):
            if r + s + p <= 1:
                continue

            total = r * s + s * p + p * r
            if total == 0:
                continue

            if r > 0 and s > 0:
                probR[r][s][p] += probR[r][s-1][p] * (r * s / total)
                probS[r][s][p] += probS[r][s-1][p] * (r * s / total)
                probP[r][s][p] += probP[r][s-1][p] * (r * s / total)

            if s > 0 and p > 0:
                probR[r][s][p] += probR[r][s][p-1] * (s * p / total)
                probS[r][s][p] += probS[r][s][p-1] * (s * p / total)
                probP[r][s][p] += probP[r][s][p-1] * (s * p / total)

            if p > 0 and r > 0:
                probR[r][s][p] += probR[r-1][s][p] * (p * r / total)
                probS[r][s][p] += probS[r-1][s][p] * (p * r / total)
                probP[r][s][p] += probP[r-1][s][p] * (p * r / total)

print(f"{probR[r0][s0][p0]:.12f} {probS[r0][s0][p0]:.12f} {probP[r0][s0][p0]:.12f}")
```この実装は、次のインタラクションの条件付けから得られる繰り返しを直接エンコードします。 各用語は、3 つの可能な異種遭遇の 1 つに対応します。 実装でよくある間違いは、遷移では計算済みのより小さい状態を使用する必要があることを忘れることです。 r + s + p を増加させて反復すると、この特性が自然に保持されます。 

状態空間が小さく、確率が制限されたままであるため、ここでは浮動小数点累積は安全です。 倍精度を使用すれば、必要な 1e-9 精度を十分に満たすことができます。 

## 実用的な例

 インプットを考慮する`2 2 2`。 

| 状態 (r,s,p) | 移行のアイデア | 貢献行動 |
 | --- | --- | --- |
 | (2,2,2) | 3 つのインタラクションすべてが可能 | 対称性により均等に分割されます。 
| (2,1,2) | 減少したはさみの状態 | 非対称性を伝播する |
 | (1,2,2) | 対称対応物 | 以前のケースを反映します |

 このトレースは、すべての遷移には種の役割を交換するミラーリングされた対応物があるため、初期状態での対称性が等しい確率につながることを示しています。 

ここで考えてみましょう`2 1 2`。 

| 状態 (r,s,p) | 支配的な相互作用 | 効果 |
 | --- | --- | --- |
 | (2,1,2) | ペーパーロック頻繁 | 石がより頻繁に除去される |
 | (2,0,2) | ジャンケンのみ | 2 種のサイクルに縮小 |
 | (1,1,2) | 弱い存在感のはさみ | ハサミはめったに生き残れません。 

これは、初期数の不均衡が、直接の捕食者を支配する種に向かって移行の流れをどのように偏らせるかを示しています。 

## 複雑さの分析

| スペース | O(n3) | すべての州にわたる 3 つの DP アレイ |

def run(inp: str) -> str:

    import math

    r0, s0, p0 = map(int, sys.stdin.readline().split())

    probS = [[[0.0] * MAX for _ in range(MAX)] for _ in range(MAX)]
    probP = [[[0.0] * MAX for _ in range(MAX)] for _ in range(MAX)]

    for i in range(MAX):
        probR[i][0][0] = 1.0
        probS[0][i][0] = 1.0
        probP[0][0][i] = 1.0

    for r in range(MAX):
        for s in range(MAX):
            for p in range(MAX):
                if r + s + p <= 1:
                    continue
                total = r * s + s * p + p * r
                if total == 0:
                    continue

                if r > 0 and s > 0:
                    probR[r][s][p] += probR[r][s-1][p] * (r*s/total)
                    probS[r][s][p] += probS[r][s-1][p] * (r*s/total)

                if s > 0 and p > 0:
                    probR[r][s][p] += probR[r][s][p-1] * (s*p/total)
                    probS[r][s][p] += probS[r][s][p-1] * (s*p/total)
                    probP[r][s][p] += probP[r][s][p-1] * (s*p/total)

                if p > 0 and r > 0:
                    probR[r][s][p] += probR[r-1][s][p] * (p*r/total)
                    probS[r][s][p] += probS[r-1][s][p] * (p*r/total)
                    probP[r][s][p] += probP[r-1][s][p] * (p*r/total)

    return f"{probR[r0][s0][p0]:.12f} {probS[r0][s0][p0]:.12f} {probP[r0][s0][p0]:.12f}"

 ## 特殊なケース

 場合について`1 0 0`、アルゴリズムはすぐに岩だけが存在する基本条件に達します。 DP テーブルは probR[1][0][0] を 1 に初期化し、合計インタラクション数がゼロであるため、遷移は適用されません。 出力は正しく 1 0 0 を返します。 

のために`2 0 2`、ジャンケンのみが相互作用します。 この移行により、システムは紙と石の相互作用のみが重要となる 2 次元のチェーンに縮小されます。 DP は自然にはさみの次元をゼロに縮小し、有効な遷移を通じて確率を伝播し、最終的にはどちらの側が最初に相手を排除するかに応じて決定的な勝者の分布を解決します。
