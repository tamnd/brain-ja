 ## 問題の理解

 爆弾が爆発するまでの時間を最大限に短縮することが求められます。 爆弾にはタイマーが付いている`b`最初は 1 秒ごとに 1 ずつ減少します。 あなたが持っている`n`それぞれのツールでタイマーを増やすことができます。`x_i`使用する場合、ただしタイマーは最大値を超えることはできません`a`。 各ツールは 1 回だけ使用でき、タイマーが減少する前であればいつでも使用できます。 目標は、ツールを最適に使用した場合に爆弾がゼロになるまでの最長合計時間を決定することです。 

入力は複数のテスト ケースで構成されます。 テスト ケースごとに、次のものが与えられます。`a`、`b`、 そして`n`、 に続く`n`ツールの値を表す整数。 各テスト ケースの出力は単一の整数、つまり爆弾が持続する最大秒数です。 

制約により許可される`b`そして`a`まで$10^9$、しかしツールの数`n`最大でも 100 です。`n`が小さい場合、ツールを複数回反復するアルゴリズムが実現可能です。 ただし、大きな境界は、`a`そして`b`これは、非常に大きなタイマーを単純に 1 秒ごとにシミュレートすることはできないことを示しています。$10^9$繰り返し。 

ツール効果の合計が最大タイマーを超える可能性がある場合、微妙なエッジケースが発生します。`a`。 たとえば、次の場合`a = 5`、`b = 1`、ツールの値は`[3, 4]`、常に最大のツールを追加する単純な貪欲なアプローチは、タイマーを超えて増加させようとする可能性があります。`a`、効果はありません。 したがって、アルゴリズムは次の上限を尊重する必要があります。`a`工具の無駄を避けるため。 

別のエッジ ケースは、すべてのツールの値がタイマーに比べて非常に小さい場合に発生します。 例えば、`a = 10`、`b = 10`、およびツール`[1, 1, 1]`。 最初にツールを使用しても上記のタイマーは増加しません`a`したがって、同じ秒間に複数のツールを使用するのは冗長です。 

## アプローチ

 ブルート フォース手法では、毎秒シミュレートし、各ステップで、未使用のツールのすべての可能なサブセットを試行してタイマーに追加し、その後 1 ずつ減らします。これにより正確性が保証されますが、指数関数的になります。`n`あるから$2^n$ツールのサブセット。 と`n`100 までの場合、このアプローチは実行できません。 

重要な観察点は、現在のタイマーが以下になった後は、ツールを使用する順序は重要ではないということです。`a`。 遅延を最大化するには、どの瞬間でも、タイマーをできるだけ増加させたいと考えています。`a`できるだけ。 したがって、最初に最大のツールを使用するのが最適です。 これにより、問題は単純な貪欲アルゴリズムに変換されます。つまり、ツールを降順に並べ替え、毎秒、タイマーを満たすために必要な数のツールを使用します。`a`。 各ツールは最大 1 回使用されます。 タイマーが満杯になるか、道具がなくなると、爆弾は 1 秒ごとに 1 ずつカウントダウンします。 

これにより、問題はソートされたツールに対する線形スキャンに変換されます。 タイマーが経過している間に、1 秒ごとに次に大きなツールを追加します`a`、タイマーを 1 減らします。工具がなくなり、タイマーがゼロになるまで続けます。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、最大タイマーを読み取ります。`a`、初期タイマー`b`、ツールの数`n`、および一連のツール`x`。 
2. ツールを降順に並べ替えます。 これにより、利用可能な最大のツールが最初に適用されてタイマーが最大化されます。 
3. 現在のタイマーを初期化する`c`として`b`そしてカウンター`seconds`0として。 
4. ソートされたツールを繰り返し、各ツールを`c`を超えずに`a`。 ツールを使用した後は、タイマーが 1 秒ごとに 1 ずつ減少するため、すぐに合計秒数を 1 増やします。 
5. すべてのツールが適用されるか、タイマーが経過した後`a`どのツールもそれ以上増加できないように、残りのタイマー値を`seconds`。 これは、ツールをさらに使用せずにタイマーがゼロに達するまでに必要な秒数を表します。 
6. 出力`seconds`このテストケースでは。 

機能する理由: 利用可能な最大のツールを常に適用することで、毎秒のタイマーを最大化します。 タイマーを超えることはできないので、`a`、後で小さなツールを使用しても、最大タイマーを超えて増やすことはできません。`a`。 したがって、貪欲な選択は全体的に最適です。 タイマーが到達したら`a`または、ツールが残っていない、より良い構成が存在しない、残りのカウントダウンは単に`c`秒。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, n = map(int, input().split())
    x = list(map(int, input().split()))
    x.sort(reverse=True)
    c = b
    seconds = 0
    for tool in x:
        if c >= a:
            break
        c = min(c + tool, a)
        seconds += 1
    seconds += c
    print(seconds)
```このソリューションでは、まずツールを降順で並べ替えます。 各ツールでは、現在のタイマーが最大値を下回っている場合、そのツールが使用され、タイマーが更新され、タイマーの減少分が 1 秒カウントされます。 タイマーを増やすツールがなくなると、残りのカウントダウンが合計秒数に追加されます。 ソートにより、より大きなツールが最初に適用されるようになります。これは、上限があるためタイマーを効率的に埋めるために必要です。`a`。
