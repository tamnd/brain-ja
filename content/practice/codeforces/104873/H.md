 ## 問題の理解

 一定量のゴールドを複数人で分割するよう求められます。$n$受信者、各受信者$i$最大許容シェアが宣言されている$a_i$。 入手可能なゴールドの合計は、$s$、そして厳密にはすべての請求の合計よりも小さい場合があるため、誰もが希望するものを受け取ることができるわけではありません。 

ねじれは、分割が任意ではないということです。 特定の 2 人ルールとグローバルに一致している必要があります。 誰か二人組を連れて行くと$i, j$そしてそれらを組み合わせた割り当てだけを想像してください$c_i + c_j$、次に個別の株式$c_i, c_j$これら 2 つの請求とその合計金額に固定の「公平な分割」機能を適用したかのように正確に動作する必要があります。 この関数は連続的で、合計金額が単調で、分類された請求のみに依存します。$a_i \le a_j$。 

したがって、問題は上限を満たして合計すると次のようになることだけではありません。$s$。 それはグローバルベクトルを見つけることです$c$そのすべてのペアごとの射影は、非常に具体的なローカル ルールと一致します。 

制約$n \le 5000$そして$a_i \le 5000$ことを示します$O(n^2)$または$O(n^2 \log n)$このアプローチはもっともらしいですが、ペアのペアにわたる三次関数はすべてそうではありません。 同一の値を集約するか、ペアワイズ ルールの構造を利用するソリューションを期待する必要があります。 

微妙なエッジケースが現れるのは、$a_i$等しいです。 次に、対称性はすべてを強制します$c_i$等しくない場合は、一部のペアが公平性ルールに違反することになります。 別のエッジケースが発生するのは次の場合です。$s = 0$これにより、すべての出力が強制的にゼロになります。 最後に、いつ$s = \sum a_i$、すべての制約が飽和状態になり、それぞれの制約が飽和状態になります。$c_i = a_i$。 

すべてのペア制約を独立して満たそうとする単純なアプローチは、ペアごとの一貫性が独立していないため失敗します。 たとえば、固定する$c_1, c_2$方法を制限します$c_1, c_3$動作し、それによって制限がかかる$c_2, c_3$、グローバルカップリングを形成します。 

## アプローチ

重要な観察は、ペアごとのルールは 2 つのクレームに対する順序と飽和のみに依存するということです。 これは、各人が根底にある均一なお金の分配の「上限」のように行動することを意味します。より多くのお金が割り当てられると、各人の限界利益は減少し、すべての限界行動はクリッピングまで同一です。$a_i$。 

この構造は、ウォーターフィリングまたはパラメトリック割り当てプロセスの特徴です。 ペアの制約を直接解決する代わりに、限界割り当てを決定するグローバル パラメーターを導入し、それぞれの$c_i$キャップの長さから導き出されます$a_i$そのパラメータの下でアクティブになります。 

このように解釈すると、問題は、割り当てられた質量の合計を次の値に等しくする単一のパラメータを見つけることになります。$s$。

 ## アルゴリズムのチュートリアル

 私たちは、公平な分割ルールは、各通貨ごとにクリップされる均一な限界分配を意味すると解釈します。$a_i$。 これにより、単一の単調パラメータが得られます。$x$、「ベースライン割り当てレベル」を表します。 

### ステップ

 1. 値を並べ替える$a_i$減少しない順序で。 限界構造は各キャップがいつアクティブになるかに依存するため、ソートが必要です。 
2. 世界レベルが上がると想像してください$x$。 各人は、次のように直線的に増加する割り当てを受けます。$x$、ただし上限まで$a_i$。 これは人の効果的な貢献を意味します$i$は$\min(a_i, x)$ペアごとのルールから導出された変換された座標系で。 

これが機能する理由は、2 人の公平性条件により、1 人が飽和するまで同一の限界共有が強制されるためです。 
3. ソート済みのプレフィックス寄与を計算する$a_i$。 固定の場合$x$、割り当てられたゴールドの合計は次のように計算できます。 

の合計$\min(a_i, x)$、これは区分的に線形です$x$。 
4. ユニークなものを見つける$x$合計が等しくなるように$s$。 関数は単調なので二分探索ができます。$x$。 
5. 1回$x$見つかったので割り当てる$c_i = \min(a_i, x)$順序を維持しながら、元の解釈に調整し直されます。 
6. 結果を出力します$c_i$元の順序で。 

### なぜ効果があるのか

 2 人ルールでは、どのペア間の限界利益も、その主張に対する残りの能力のみに依存することが強制されます。 これにより、すべての割り当てが、共通の増加する割り当てプロファイルの切り捨てとして表現可能になります。 何らかの逸脱があると、一方の人が初期に不釣り合いに多くの辺縁質量を受け取るペアが作成され、必要なペアごとの再構成特性に違反します。 したがって、すべての有効な解はこの単一パラメータ ファミリに基づいており、正しいパラメータを検索すると総和制約が厳密に適用されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    s = float(input())

    idx = list(range(n))
    a_sorted = sorted((val, i) for i, val in enumerate(a))

    def total(x):
        res = 0.0
        for val, _ in a_sorted:
            if val < x:
                res += val
            else:
                res += x
        return res

    lo, hi = 0.0, max(a)

    for _ in range(60):
        mid = (lo + hi) / 2
        if total(mid) < s:
            lo = mid
        else:
            hi = mid

    x = hi

    res = [0.0] * n
    for val, i in a_sorted:
        res[i] = min(val, x)

    # adjust to match exact sum (tiny floating drift)
    diff = s - sum(res)
    res[0] += diff

    print("\n".join(f"{v:.12f}" for v in res))

if __name__ == "__main__":
    solve()
```実装では、グローバルしきい値に対して二分検索が実行されます。$x$。 機能`total(x)`クリップされた寄与の合計を評価します。これは、以下では単調です。$x$安定した検索が可能です。 

並べ替えは構造を保持するためにのみ使用されます。 この簡略化された形式では各項が独立しているため、元のインデックスにマッピングし直すだけで済みます。 

最後の補正ステップでは、残留誤差を 1 つの座標に押し込むことで浮動小数点ドリフトを調整します。 必要な許容誤差が許容されるため、これは安全です。$10^{-9}$絶対誤差であり、合計は保存されます。

 ## 特殊なケース

 いつ$s = 0$、二分探索はすぐに次のように収束します。$x = 0$、すべてゼロが生成されます。 アルゴリズムはこれを処理します。`total(x)`はゼロです$x = 0$したがって、割り当てはトリガーされません。 

いつ$s = \sum a_i$、検索がプッシュされます$x$全てを超えて$a_i$、だからすべての`min(a_i, x)`等しい$a_i$。 出力は入力配列とまったく同じになります。 

いつすべて$a_i$が等しい、たとえばすべてが 5 である、関数`total(x)`として成長します$n \cdot \min(x, 5)$。 二分探索で見つかるのは、$x = s/n$、すべての出力は同一であり、自動的に対称性が維持されます。 

これらのケースは、アルゴリズムが特別なケースなしで境界領域を越えて一貫して動作することを確認します。
