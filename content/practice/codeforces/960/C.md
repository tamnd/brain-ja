 ## アルゴリズムのチュートリアル

 ブロックの連結として配列を構築します。 

1. まず、次のように表現します。$X$形式の項の合計として$2^k - 1$。 最大のものを繰り返し取得します$k$そのような$2^k - 1 \le X$、それを減算して続行します。 この貪欲な選択が機能する理由は、$2^k - 1$指数関数的に増加し、対数のブロック数が確保されます。 
2. 選択したそれぞれについて$k$、サイズのブロックを作成します$k$ここで、すべての要素は同一です。 このブロックはまさに​​貢献します$2^k - 1$内部の空でないすべてのサブシーケンスには同一の要素があり、範囲がゼロであるため、有効なサブシーケンスとなります。 
3. ブロック間の相互作用を防ぐために、後のブロックのすべての要素が少なくとも$d$以前のブロックのすべての要素よりも大きくなります。 これにより、2 つの異なるブロックの要素を含むサブシーケンスが少なくとも最大値から最小値を引いたものになることが保証されます。$d$、したがって無効です。 
4. 値の増加に応じて任意の順序で連結されたすべてのブロックを出力し、分離が維持されるようにします。 
5. 基本値を任意に割り当てます。通常は 1 から始まり、少なくとも 1 ずつ増加します。$d$ブロックごとに。 

### なぜ効果があるのか

 ブロック内のサブシーケンスは常に有効であり、強制された値のギャップによりブロック間のサブシーケンスは常に無効であるため、各ブロックは独立して寄与します。 ブロックは組み合わせ的に相互作用しないため、有効なサブシーケンスの総数は、各ブロックからの寄与の正確な合計となります。 貪欲な分解により合計が一致することが保証されます$X$この構造により、余分なサブシーケンスが誤ってカウントされることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    X, d = map(int, input().split())
    
    blocks = []
    
    # decompose X into (2^k - 1)
    for k in range(60, 0, -1):
        val = (1 << k) - 1
        while X >= val:
            X -= val
            blocks.append(k)
    
    if X != 0:
        print(-1)
        return
    
    res = []
    base = 1
    
    for k in blocks:
        for _ in range(k):
            res.append(base)
        base += d
    
    print(len(res))
    print(*res)

if __name__ == "__main__":
    solve()
