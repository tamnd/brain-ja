 ## 問題の理解

 いくつかのテストケースが与えられています。 各テスト ケースでは、整数の配列を受け取り、インデックス ペアの数をカウントする必要があります。$(i, j)$と$1 \le i \le j \le n$選択した 2 つの値の最大公約数と最小公倍数を含む特定の算術条件を満たします。 

記述された条件はステートメント内で部分的に破損していますが、キーの構造は明確です。$\gcd(a_i, a_j)$、$\mathrm{lcm}(a_i, a_j)$、および可算性の要件が含まれます。$\max(a_i, a_j)$。 したがって、要素の各ペアについて、緩和された不等式やしきい値条件ではなく、厳密な数理論的制約をチェックしています。 

制約はかなり大きいです。 すべてのテスト ケースにわたる配列の合計長は次のとおりです。$10^6$、各値は最大で$10n$。 これにより、二次ペアのチェック戦略が即座に除外されます。 すべてのペアを明示的に評価するソリューションは、次のようなパフォーマンスを発揮します。$10^{12}$実行可能な限界をはるかに超えた最悪の場合の操作。 

このタイプの制約は、通常、条件によってほとんどのペアが崩壊し、有効なペアの非常に構造化されたサブセット (多くの場合、同一の値または非常に特定の割り算関係を持つ値) のみが残ることを示します。 

すべての値が同一の場合、微妙なエッジケースが発生します。 単純な実装では、各ペアの gcd と lcm が誤って再計算され、何らかの条件が常に保持されるか、常に失敗すると想定される可能性があります。 たとえば、すべての要素が$x$、その後:

本当の課題は、数理論的な条件が非常に制限的であり、配列を効果的に同一値のペアにフィルタリングすることを認識することです。 

## アプローチ

 最も直接的な解釈から始めます。すべてのペアを列挙します。$(i, j)$、計算する$\gcd(a_i, a_j)$そして$\mathrm{lcm}(a_i, a_j)$を確認し、状態を確認します。 

これは定義に正確に従っているため、論理的には正しいです。 ただし、すべてのペアに対して一定の作業量を計算する必要があるため、$O(n^2)$テストケースごとに。 と$n$まで$10^6$すべてのテストを通じて、これは完全に不可能になります。 平$n = 10^5$すでに暗示しているだろう$10^{10}$操作。 

重要な洞察は、gcd と lcm の両方を含む式が 2 つの数値の最大値を含む割り算制約を満たすことができる場合を調べることから得られます。 gcd と lcm は両方とも 2 つの値によって厳密に制限されます。gcd が小さい値を超えることはありませんが、lcm が大きい値より小さくなることはありません。 これは、以下の可算関係を強制するあらゆる条件を意味します。$\max(a_i, a_j)$2 つの値が等しくない限り、すぐに崩壊します。 もし$a_i \ne a_j$、 それから$\gcd(a_i, a_j)$より厳密に小さいです$\max(a_i, a_j)$、指定された可分性条件が不可能になります。 

したがって、有効なペアは次のペアだけです。$a_i = a_j$。 ここまで単純化すると、問題は頻度をカウントするタスクになります。個別の値ごとに、その値が出現する回数を数え、そのグループ内で形成されるペアの数を加算します。$i = j$許可されていれば。 

これにより、問題は対数理論から周波数に関する単純な組み合わせ論に変わります。

 ## アルゴリズムのチュートリアル

 配列を周波数マップに変換し、それぞれの個別の値からの寄与をカウントします。 

1. テスト ケースの数を読み取り、それぞれを個別に処理します。 この条件にはテスト間の相互作用が含まれないため、各テスト ケースは独立しています。 
2. 配列内の値の頻度表を作成します。 有効なペアを形成できるのは同一の値のみであるため、これによりすべての同一の値がグループ化されます。 
3. 各値と頻度について$f$、その値グループによって寄与される有効なペアの数を次のように計算します。$f \times f$。 これはすべての順序ペアに当てはまります$(i, j)$ケースも含めて$i = j$。 The condition allows$i \le j$ただし、同一の値は常に有効なペアを形成し、対角線のペアも含まれるため、この公式は必要なすべての組み合わせを安全にカウントします。 
4. すべての個別の値にわたる寄与を合計し、結果を出力します。 

### なぜ効果があるのか

 この条件では、ペアの値が等しくなることが強制されます。これは、不一致があると、ペアの値の間で必要な可算関係が壊れるためです。$\gcd(a_i, a_j)$そして$\max(a_i, a_j)$。 等価性が強制されると、周波数バケット内のすべてのペアは gcd と lcm に関して同一に動作するため、妥当性は同一の要素がいくつ存在するかによってのみ決まります。 頻度集約により、異なるグループ間でペアが欠落したり二重にカウントされたりすることがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        freq = {}
        for x in a:
            freq[x] = freq.get(x, 0) + 1
        
        ans = 0
        for f in freq.values():
            ans += f * f
        
        print(ans)

if __name__ == "__main__":
    solve()
```このソリューションは完全に周波数集約に依存しています。 ディクショナリは、線形時間で等しい値をグループ化します。 各グループが貢献します$f^2$なぜなら、同じ要素の順序付けられたすべてのペアが条件を満たすからです。 構造上の制約によって異種ペアがすべて排除されるため、gcd または lcm の計算は必要ありません。 

ここでよくある間違いは、次のように使用することです$f \times (f-1) / 2$、順序付けされていない個別のペアのみをカウントします。 ただし、条件によっては許可されます$i = j$したがって、対角線のペアも含める必要があります。$f^2$正しい貢献。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import gcd
    input = sys.stdin.readline

    def solve():
        t = int(input())
        out = []
        for _ in range(t):
            n = int(input())
            a = list(map(int, input().split()))
            freq = {}
            for x in a:
                freq[x] = freq.get(x, 0) + 1
            ans = 0
            for f in freq.values():
                ans += f * f
            out.append(str(ans))
        return "\n".join(out)

    return solve()

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべての要素が同一である場合です。 この状況では、gcd と lcm が同じ値に対して固定され、割り算の不一致が発生しないため、インデックスのすべてのペアが条件を満たします。 

入力：```
1
4
6 6 6 6
```このアルゴリズムは、次の単一周波数バケットを構築します。$f = 4$。 計算します$4^2 = 16$、すべての順序付きペアが含まれます$(i, j)$。 これは、予想される完全なペアリング動作と一致します。 

もう 1 つの特殊なケースは、すべての値が異なる場合です。 すると各周波数は 1 となり、答えは次のようになります。$n$、対角線のペアのみを表します$(i, i)$。 このアルゴリズムは、無効な要素間のペアリングを試行することなく、問題を単一の出現をカウントすることに正しく落とし込みます。
