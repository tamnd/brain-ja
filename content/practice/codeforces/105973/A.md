 ## 解決策
 ## 問題の理解

 各エッジが正の整数の重みを持つ無向グラフが与えられます。 タスクは、すべてのエッジに対して 2 つのエンドポイント値の大きい方がエッジの重みと正確に等しくなるように、すべての頂点に値を割り当てることです。 

言い換えれば、すべてのエッジには厳密な制約が課せられます。エッジが重み w で u と v を接続する場合、2 つの頂点の 1 つは値 w を保持し、もう 1 つは w を超えない値を保持する必要があり、実際、2 つの頂点の最大値は正確に w でなければなりません。 したがって、少なくとも 1 つのエンドポイントがエッジの重みを「実現」する必要があり、他のエンドポイントはそれを超えることはできません。 

出力は、すべての制約を満たす 1 ～ 10^9 の範囲の頂点への整数の割り当て、またはそのような割り当てが存在しないという宣言です。 

制約は大きく、すべてのテスト ケースにわたって最大 3·10^5 の頂点とエッジがあります。 これにより、テスト ケースごとに二次関数または二次関数に近いものは除外されます。 テスト ケースごとに線形または線形に近い構造が期待されます。 

複数のエッジが同じ頂点に矛盾する要件を強制する場合、微妙な問題が発生します。 たとえば、ある頂点が 1 つのエッジによって 5 に等しくされ、別のエッジによって 7 に等しくされる場合、解決策は存在しません。 別の問題は、「最大値がエッジの重みに等しい」条件によって一貫性のない伝播が強制されるサイクルで、特にグラフにサイクルの周りで重みが減少するエッジが含まれている場合に発生します。 グローバルな一貫性を持たないエッジごとの単純な貪欲な割り当ては簡単に壊れます。 

## アプローチ

 各エッジの条件は、より高いエンドポイント値がエッジの重みと等しくなければならないという制約として読み取ることができます。 これは、エッジの重みがローカルのどこかで実現される必要がある上限のように動作することを直ちに示唆しています。 

強引なアイデアは、各頂点値を不明なものとして扱い、値を繰り返し割り当てようとすることです。 バックトラッキングまたは制約の伝播を試みることもできます。つまり、頂点を選択し、1 つのインシデント エッジと一致する値を割り当て、隣接するエッジに沿って制約を伝播します。 すべてのエッジが 2 つの変数を制約するため、これは概念的に機能しますが、最悪の場合、グラフには制約が密になります。 各割り当ては多くのエッジをカスケードすることができ、バックトラッキングにより割り当ての指数関数的な組み合わせを再検討することができます。 最大 3·10^5 のエッジでは、これは完全に不可能になります。 

重要な観察は、すべてのエッジが最大値を含む非常に局所的な条件を強制していることです。 エッジの重みが w の場合、少なくとも 1 つの端点が正確に w である必要があり、どちらの端点も w を超えることはできません。 これは、大きな制約が最初に固定され、小さな制約がその周囲に適応するように、重みの降順でエッジを処理することを示唆しています。 

これは建設的な観点につながります。つまり、頂点に値を割り当てることを決定したときに、後でその値を増やす必要がないように、大きな重みから小さな重みまで貪欲に値を割り当てようとします。 問題は、等しいまたは減少する重みの接続された制約全体で割り当ての一貫性を確保することになります。 

主な構造的洞察は、頂点が同じ最大関連ウェイト領域のエッジによって引き起こされる 2 つの異なる値を取る必要がある場合にのみ競合が発生するということです。 重みによってグループ化されたエッジを処理し、各グループ内で一貫して値を割り当てるようにすると、その構築は、同じ重みしきい値のエッジの下で接続されたコンポーネントを維持することになります。 

エッジを重みの降順で効果的に処理し、重み w のエッジが表示されるたびに、そのエンドポイントが値 w と互換性があることを確認する必要があります。 どちらのエンドポイントもまだ w に固定されていない場合は、一方のエンドポイントを自由に選択して w に設定し、もう一方のエンドポイントを最大でも w に保つことができます。 将来の矛盾を避けるために、どの頂点が同じ最終値を共有することを強制されるかを追跡する、素のセット構造を使用して制約をマージします。

これにより、問題は重み層全体にわたる和集合検索の一貫性チェックに変わります。

 ## アルゴリズムのチュートリアル

 より高い制約がより低い制約を優先するように、重みの降順でエッジを処理します。 

1. すべてのエッジを重みの小さい順に並べ替えます。 これにより、エッジを処理するときに、後のステップで、以前の決定と矛盾する可能性のある、より大きな重みを伴うより厳格な要件が導入されることがなくなります。 
2. 頂点上で互いに素な集合結合構造を維持し、最終的に同じ値が割り当てられる必要がある頂点のグループを表します。 直感的には、2 つの頂点が重なり合う制約によって同じ「最大実現の役割」を強制される場合、それらは同じコンポーネントに属することになります。 
3. すべての頂点値を未割り当てとして初期化します。 
4. 等しい重み w でグループ化されたエッジを反復処理します。 各エッジ (u、v、w) について、DSU 内の u と v の代表をチェックします。 
5. 両方の代表値がすでに割り当てられており、これらの値が max(au, av) が w になることが不可能になるほど w と異なる場合、矛盾を検出し、不可能を返します。 実際には、唯一安全な矛盾は、両方の成分が厳密に w よりも大きい値にすでに固定されている場合です。これは、エッジの最大値が許容値よりも大きくなるからです。 
6. 一方または両方のコンポーネントが割り当てられていない場合は、少なくとも 1 つのエンドポイントのコンポーネントに値 w が割り当てられるようにします。 代表者を 1 人選び、まだ割り当てられていない場合は割り当てます。 両方が割り当てられていない場合は、通常は 1 人の代表者に任意に割り当てます。 
7. 割り当て後、2 つの頂点を結合します。これは、エッジが同じウェイト レイヤの下に拘束されていることを意味しているためです。 
8. すべてのエッジが処理されるまで続行します。 残りの未割り当てのコンポーネントには、[1, 10^9] の任意の値 (たとえば、1) を割り当てることができます。 

結合の背後にある理由は、重み w のエッジが処理されると、両方のエンドポイントが w 以下のエッジによって制約されるため、今後はそれらを同じ制約領域の一部として扱う必要があるということです。 

### なぜ効果があるのか

 不変条件は、厳密に w より大きい重みを持つすべてのエッジを処理した後、DSU 内のすべての連結コンポーネントが、最終値がすべてのより高い重みの制約とすでに一致している頂点に対応することです。 重み w を処理するとき、重み w のすべてのエッジに正確に w が割り当てられた少なくとも 1 つのエンドポイント コンポーネントがあり、処理されている現在のエッジの重みより大きい値がコンポーネントに割り当てられることはありません。 下方向に移動するため、コンポーネントが値を取得すると、それを増やす必要はなく、将来のエッジは同じ値かそれより小さい値のみを強制できます。 これにより矛盾が防止され、すべてのエッジが必要な最大値を正確に達成できるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        edges = []
        for _ in range(m):
            u, v, w = map(int, input().split())
            u -= 1
            v -= 1
            edges.append((w, u, v))

        edges.sort(reverse=True)

        parent = list(range(n))
        size = [1] * n
        val = [0] * n

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a, b):
            ra, rb = find(a), find(b)
            if ra == rb:
                return
            if size[ra] < size[rb]:
                ra, rb = rb, ra
            parent[rb] = ra
            size[ra] += size[rb]
            if val[ra] == 0:
                val[ra] = val[rb]
            rb_val = val[rb]
            if rb_val != 0:
                if val[ra] == 0:
                    val[ra] = rb_val

        ok = True

        for w, u, v in edges:
            ru, rv = find(u), find(v)

            vu, vv = val[ru], val[rv]

            if vu > w or vv > w:
                ok = False
                break

            if vu == 0 and vv == 0:
                val[ru] = w
            elif vu == 0:
                val[ru] = w
            elif vv == 0:
                val[rv] = w

            union(ru, rv)

        if not ok:
            print(-1)
            continue

        ans = []
        for i in range(n):
            r = find(i)
            if val[r] == 0:
                val[r] = 1
            ans.append(str(val[r]))

        print(" ".join(ans))

if __name__ == "__main__":
    solve()
```このソリューションでは、まずエッジを並べ替えて、より高い重みが早期に適用されるようにします。これが、後の矛盾を防ぐ中心的なメカニズムです。 DSU は、処理されたエッジを通じて結合される頂点をグループ化し、各コンポーネントは、そのコンポーネント内の最終的な頂点の割り当てを表す単一の代表値を保持します。 

結合操作は、マージされたコンポーネント間ですでに固定されている値を伝播するように慎重に設計されています。 一方の側にすでに値がある場合、その値は保持され、コンポーネントに重みが強制されると、その決定はマージを通じて保持されます。 

エッジ処理中に、両方のコンポーネントがすでに現在のエッジの重みを超えている場合、そのエッジの最大値を w まで下げることができないため、構成は無効になります。 それ以外の場合、少なくとも 1 つの辺が値 w を取ることを強制され、エッジ制約が満たされることが保証されます。 

最後に、エッジによって強制されていないコンポーネントには可能な限り最小の値 1 が割り当てられます。これは、より大きな値を必要とする最大制約に影響を与えないため安全です。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、重みの高いエッジがコンポーネント値を早期に強制し、その後の重みの小さいエッジと競合する場合に発生します。 重みが 5 と 2 のチェーン 1-2-3 のようなグラフでは、最初のエッジに 5 を早めに割り当てるのは正しいですが、伝播によってコンポーネント全体に 5 が誤って適用されると、2 番目のエッジは不可能になります。 降順処理により、5 エッジが最初に解決され、互換性のある下位の割り当てのみがその後に導入されるため、後で割り当てを増やしたり矛盾させたりする必要がなくなります。 

もう 1 つのエッジ ケースは、複数のエッジが同じ重みを共有し、接続されたコンポーネントを形成する場合です。 この状況では、接続コンポーネントごとに少なくとも 1 つの頂点にその重みを割り当てる必要がありますが、すべてを一度に明示的に割り当てる必要はありません。 DSU マージにより、コンポーネント内の 1 つの頂点が w に設定されると、有効な構成を誤って上書きする可能性のある複数の冗長な割り当てを強制することなく、残りの頂点が一貫性を継承します。
