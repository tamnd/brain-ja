 ## 解決策
 ## 問題の理解

 いくつかのテストケースが与えられています。 各テスト ケースには項目のリストがあり、各項目は整数値を持ちます。 タスクは、各グループ内で項目のすべてのペアが「互換性」を持つように項目を 2 つの空でないグループに分割することです。つまり、それらの値が共通の素因数を共有しないことを意味します。 同様に、各グループ内では、2 つの異なる要素を素数で分割することはできません。 

出力は、各インデックス付きアイテムを 2 つの隠れ場所の 1 つに割り当てる有効な方法の数です。両方の隠れ場所は空ではなく、有効性は各グループ内で独立してチェックされます。 少なくとも 1 つのインデックスが異なるグループに配置されている場合、2 つの割り当ては異なります。 

制約は大きく、すべてのテスト ケースにわたる項目の合計数は最大 5 × 10^5、値は最大 5 × 10^6 です。 これにより、数値のペアを比較したり、すべてのペアの gcd をチェックしたりするアプローチは即座に除外されます。 テスト ケースごとの O(n²) 推論でも、遅すぎます。 許容可能なソリューションはすべて、中心的な要件として高速因数分解を備え、総入力サイズが線形または線形に近いものである必要があります。 

多くの数値が共通の素因数を共有する場合、微妙なエッジの状況が現れます。 たとえば、3 つの数値がすべて 2 で割り切れる場合、それらのうちの 2 つを同じグループにすることはできません。 グループが 2 つしかない場合、相反する 3 つのアイテムをルールに違反せずに配置することは不可能になるため、答えはゼロになる必要があります。 別の失敗例は、相互作用構造が値 6、10、15 などの奇数サイクルを形成し、共有素数がそれらを三角形で接続する場合に発生します。 単一の素数が 3 回出現しない場合でも、誘導された制約により有効な分割は依然として不可能になります。 

## アプローチ

 直接の試みでは、すべての 2^n 割り当てを試行し、各グループをスキャンしてペアごとの gcd 条件を検証することで妥当性をチェックします。 これは定義を直接適用するため概念的には機能しますが、指数関数的な数の構成が検査され、各チェックはグループ サイズが線形または二次になります。 無効な部分割り当てを削除しても指数関数的な最悪のケースは変わらないため、このアプローチは n が 5 × 10^5 までの場合はすぐに失敗します。 

重要な観察は、制約が完全に素因数によって駆動されるということです。 2 つの数値が素因数を共有する場合、それらを同じグループに入れることはできません。 これは問題をグラフの観点に変換します。各インデックスはノードであり、値が素因数を共有する場合、2 つのノードを接続します。 有効な分割は、このグラフの正確な 2 色分けであり、色は 2 つの隠れ家に対応します。 

このように再定式化すると、構造がさらに単純化されます。 それぞれの素数は、それで割り切れるすべての数の間でクリークを引き起こします。 素数が 3 つ以上の数字に現れると、すぐに制約の三角形が作成され、二分割が不可能になります。 すべての素数が最大 2 回出現する場合、誘導されたすべてのクリークは単一のエッジに縮退し、グラフはペアごとの制約の集合になります。 

このグラフを作成した後、タスクはそれが 2 部構成であるかどうかを確認し、有効な色の数を数えることになります。 コンポーネント内の 1 つのノードが割り当てられると、残りのノードが強制的に割り当てられるため、各接続コンポーネントは係数 2 に寄与しますが、そのコンポーネントの初期色を選択することはできます。 最終的な答えは 2^(連結成分の数) ですが、両方のグループが空ではない必要があるため、エッジがまったくない場合は修正されます。

 ## アルゴリズムのチュートリアル

まず、5 × 10^6 までのすべての整数の最小の素因数を前処理して、各数値をすばやく因数分解できるようにします。 これにより、試行除算の繰り返しが回避され、すべての入力にわたる素因数の数において合計因数分解が線形に保たれます。 

各テスト ケースについて、すべての値を因数分解し、どのインデックスに各素数が含まれているかを記録します。 これを行う際に、3 つ以上のインデックスに素数が出現した場合、それらのインデックスには 3 つの異なる色が必要ですが、グループが 2 つしか存在しないため、答えはゼロであるとすぐに結論付けることができます。 

次に制約グラフを構築します。 すべての素数について、そのリスト内のすべてのインデックスを接続します。 リストのサイズが最大 2 であることはすでに確認されているため、インデックスのペア間には単純なエッジのみが生成されます。 

次に、すべてのインデックスに対してグラフの走査を実行します。 接続された各コンポーネントは、BFS または DFS を使用して、交互の色を割り当てながら探索されます。 同じ色の 2 つのノードを接続するエッジが見つかった場合、グラフは 2 部ではなく、答えはゼロになります。 

コンポーネントを走査しながら、接続されているコンポーネントがいくつ存在するかを数えます。 これには、サイズ 1 のコンポーネントである孤立したノードが含まれます。 

走査後、有効な色の数を計算します。 グラフに少なくとも 1 つのエッジがある場合、すべてのコンポーネントに少なくとも 1 つの強制交互が含まれるため、両方の色が最終的な割り当て空間に表示されます。 答えは 2^(成分数) です。 エッジがまったくない場合、すべてのノードが 1 つのグループに属する 2 つのケースを除いて、すべての割り当ては有効であるため、答えは 2^n − 2 になります。 

### なぜ効果があるのか

 この構造により、「素数を共有する 2 つの数は一緒にならない」というすべての制約がエッジになります。 有効な割り当てはすべてのエッジを尊重する必要があるため、適切な 2 色でなければなりません。 逆に、適切な 2 色分けでは、各共有素数が同じ色の配置を防ぐエッジを作成するため、グループ内で素数が 2 回出現しないことが自動的に保証されます。 エッジがコンポーネントと交差しないため、接続されたコンポーネントは独立しているため、各コンポーネントを独立して反転することができ、コンポーネントごとに 2 つの選択肢が生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAXA = 5_000_000

spf = list(range(MAXA + 1))
for i in range(2, int(MAXA ** 0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, MAXA + 1, step):
            if spf[j] == j:
                spf[j] = i

def factorize(x):
    primes = []
    while x > 1:
        p = spf[x]
        primes.append(p)
        while x % p == 0:
            x //= p
    return primes

def pow2(k):
    return pow(2, k, MOD)

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    prime_to_nodes = {}
    edges = []
    ok = True

    for i, val in enumerate(a):
        ps = factorize(val)
        seen = set()
        for p in ps:
            if p in seen:
                continue
            seen.add(p)
            if p not in prime_to_nodes:
                prime_to_nodes[p] = i
            else:
                j = prime_to_nodes[p]
                edges.append((i, j))
            if len(prime_to_nodes.get(p, [])) > 2:
                ok = False

    # check "3 occurrences" properly
    freq = {}
    for i, val in enumerate(a):
        for p in set(factorize(val)):
            freq[p] = freq.get(p, 0) + 1
            if freq[p] > 2:
                ok = False

    if not ok:
        print(0)
        continue

    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * n
    comps = 0
    edges_exist = False

    for i in range(n):
        if not adj[i]:
            continue
        edges_exist = True

    from collections import deque

    for i in range(n):
        if color[i] != -1:
            continue
        comps += 1
        color[i] = 0
        dq = deque([i])

        while dq:
            u = dq.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    dq.append(v)
                elif color[v] == color[u]:
                    ok = False

    if not ok:
        print(0)
        continue

    if not edges_exist:
        ans = pow2(n) - 2
    else:
        ans = pow2(comps)

    print(ans % MOD)
```解決策は、各数値を効率的に分解できるように最小の素因数ふるいを構築することから始まります。 これが必要なのは、前処理なしで最大 5 × 10^6 までの素因数分解を繰り返すと、すべてのテスト ケースで時間がかかりすぎるためです。 

各数値は因数分解され、異なる素数のセットに変換されます。 各素数について、それを共有するインデックスを接続し、すべての非互換性をエンコードするエッジを生成します。 次に、グラフが 2 部構成であることを確認するために、同時に接続成分をカウントします。 

素数が 3 回出現しない場合でも、異なる素数の組み合わせが奇数サイクルを形成する可能性があるため、2 部チェックは不可欠です。 BFS のカラーリング ステップは、そのような矛盾を即座に検出します。 

最後に、グラフにエッジがまったくない場合には特別な補正を加えて、接続成分に基づいて答えが計算されます。

 ## 特殊なケース

 重大なエッジケースは、3 つの数字に素数が出現する場合です。 たとえば、値 2、4、8 はすべて素数 2 を共有します。因子の収集中、素数 2 の頻度は 3 になり、相互に接続されている 3 つのノードを競合せずに 2 つのグループに配置できないため、すぐに拒否がトリガーされます。 

もう 1 つのエッジ ケースは、すべての数値がペアごとに互いに素である場合など、エッジがまったく存在しない場合です。 この場合、すべての割り当ては有効ですが、両方のグループが空ではないという要件により、正確に 2 つの構成が削除されます。 アルゴリズムは、隣接関係が存在するかどうかをチェックすることでこれを検出し、補正 2^n − 2 を適用します。 

最後の微妙なケースは、複数のコンポーネントを含む接続されていないグラフです。 各コンポーネントは、独自のカラーリング制約を個別に適用します。 BFS トラバーサルにより、各コンポーネントが 1 つの自由なバイナリ選択肢に寄与することが保証され、カウント コンポーネントは二重カウントや孤立したノードの欠落を起こすことなく、この独立性を正確に把握します。
