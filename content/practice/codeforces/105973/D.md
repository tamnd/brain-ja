 ## 問題の理解

 2 つの配列が与えられ、2 種類の演算を使用して各配列を変換できます。循環シフトと、プレフィックスを同じ長さのサフィックスと交換する特殊なスワップ演算です。 目的は、ある配列を別の配列に直接変換することではなく、許可されたスワップ操作を任意の数適用した後、最初の配列と 2 番目の配列の回転のペアを何組同一にできるかをカウントすることです。 

ここでの回転とは、配列を取得し、それをある位置で切り取り、プレフィックスを最後に移動することを意味します。 したがって、生の配列を操作する代わりに、両方の配列のすべての循環表現を効果的に操作することになります。 回転の選択ごとに、`a`と回転`b`、スワップ操作を使用して一方を他方に変換できるかどうかを尋ね、そのようなペアが何個存在するかを数えます。 

スワップ操作自体には非常に制約があります。`ℓ`配列の長さの半分までを変更し、最初の部分を交換します`ℓ`最後の要素`ℓ`要素。 これにより、任意の順列は許可されませんが、配列の強力な不変構造を保持する構造化された並べ替えが可能になります。 

制約は大きく、すべてのテスト ケースの合計の長さは最大 3⋅10^5 です。 これにより、回転のすべてのペアを明示的に試行するソリューション (テスト ケースごとにすでに O(n^2) になる)、および配列間の変換をシミュレートするソリューションは直ちに除外されます。 テストごとに線形または線形演算に近いものが必要です。 

素朴な隠れトラップは、スワップ操作が回転クラス内のすべての置換を生成できると想定しています。 それは真実ではありません。 たとえば、n = 6 の場合、長さ 1 または 2 のプレフィックスとサフィックスを交換しても、任意の要素を自由に移動することはできません。 セグメントの構造的な反転を作成するだけです。 単純なアプローチでは、等価性がローテーション下の単なる複数集合の等価性であると誤って想定される可能性がありますが、順序制約が残っているため失敗します。 

もう 1 つの微妙なエッジ ケースは、配列に繰り返し値が含まれる場合です。 2 つの回転は、マルチセット推論では似ているように見えますが、周波数だけでなく構造が重要であるため、許可された操作では同等ではありません。 

## アプローチ

 ブルートフォースの観点から始めます。 の各回転ごとに`a`そして各回転`b`、一方をもう一方に変換できるかどうかを判断しようとします。 それぞれ n 回の回転があるため、これは n^2 個のペアになります。 各ペアについて、スワップ プロセスをシミュレートすることは簡単ではありません。 配列の状態に対する単純な BFS であっても、本質的には階乗的であり、すぐには実行不可能になります。 

O(n) のスワップ操作で 2 つの配列間の等価性をテストする高速な方法があると楽観的に仮定したとしても、全体のコストはテスト ケースごとに O(n^3) になりますが、これは制約の下では不可能です。 

重要な点は、スワップ操作によって恣意的な再配置が行われないことです。 代わりに、深い構造が保存されます。つまり、対称ブロックの交換が可能になります。これは、ミラーリングと循環シフトの下でアレイがどのように動作するかによって、到達可能な構成が決定されることを意味します。 回転が含まれると、問題は、鏡映のような操作によって生成された対称グループの下で循環文字列を比較することになります。 

このタイプの構造は通常、許可された操作で反転をシミュレートできるかどうかに応じて、一方の回転された配列がもう一方の回転と一致するか、またはその逆の回転と一致するかどうかをチェックするように折りたたまれます。 この問題では、接頭辞と接尾辞の交換により、恒等配置とその鏡映形式の両方に到達できる群が正確に生成されます。これは、同値類が円形配列上の二面対称に対応することを意味します。 

したがって、すべての変換をチェックする代わりに、条件を標準形式に縮小します。つまり、基礎となる循環シーケンスが反射に一致する場合、2 つの回転は同等となります。 これにより、一方の配列の 2 倍バージョンともう一方の配列の両方の方向の間の一致をカウントする作業が軽減されます。これは、Z 関数やローリング ハッシュなどの文字列一致手法を使用して実行できます。 

次に、回転ごとにカウントします。`a`、何回転するか`b`この等価性の下でそれを照合します。 これは、2 倍の配列に対する循環パターン マッチングの問題になります。

 ## アルゴリズムのチュートリアル

 この問題を、回転と反射の両方を許可する等価性の下で循環シーケンスを比較することに変換します。 

### 1. 両方の配列を複製します。 

私たちは構築します`A = a + a`そして`B = b + b`。 これにより、各配列のすべての回転を、長さの連続した部分配列として表すことができます。`n`。 

これが有効である理由は、すべての巡回シフトが 2 倍化された配列内のウィンドウに正確に対応するためです。 

### 2. 正規一致ルールを定義する

 有効な変換の等価性は、ある巡回シーケンスが別の巡回シーケンスに直接一致するか、逆方向に一致するかによってのみ依存することがわかります。 

したがって、すべての回転ウィンドウに対して、`a`、次のものと比較する必要があります。 

- すべての回転`b`- すべての逆回転`b`逆回転を処理するために、次もビルドします。`b_rev`そしてそれを2倍にします。 

### 3. パターン マッチング構造を構築する

 長さ n の各ウィンドウをパターンとして扱い、ハッシュまたは文字列マッチング メカニズムを使用します。`B`そして`B_rev`。 

各ウィンドウを個別に比較する代わりに、次の長さ n の部分文字列をすべて前処理します。`B`そして`B_rev`ローリング ハッシュをキーとするハッシュ マップに変換します。

### 4. のローテーションごとに一致をカウントします。 

すべての開始位置を反復します`i`で`A`から`0`に`n-1`、のハッシュを計算します`A[i:i+n]`、そして次を追加します。 

- 一致するウィンドウの数`B`- 一致するウィンドウの数`B_rev`これにより、各回転の寄与が得られます。`a`。 

### 5. 寄付金の合計

### なぜ効果があるのか

 スワップ操作により、構成とその反射を区別しない、円形アレイ上に対称グループが生成されます。 配列を 2 倍にして回転が正規化されると、到達可能なすべての構成が直接循環アライメントまたはミラーリングされた循環アライメントのいずれかに対応します。 アルゴリズムはこれらの等価一致を正確にカウントし、他の構成には到達できないため、カウントされたすべてのペアは有効であり、すべての有効なペアは 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = (1 << 61) - 1
BASE = 91138233

def build_hash(arr):
    n = len(arr)
    h = [0] * (n + 1)
    p = [1] * (n + 1)
    for i in range(n):
        h[i+1] = (h[i] * BASE + arr[i] + 1) % MOD
        p[i+1] = (p[i] * BASE) % MOD
    return h, p

def get_hash(h, p, l, r):
    return (h[r] - h[l] * p[r - l]) % MOD

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    A = a + a
    B = b + b
    Br = b[::-1]
    Br = Br + Br

    hB, pB = build_hash(B)
    hBr, pBr = build_hash(Br)

    freq = {}

    for i in range(n):
        val = get_hash(hB, pB, i, i + n)
        freq[val] = freq.get(val, 0) + 1

    freq_r = {}
    for i in range(n):
        val = get_hash(hBr, pBr, i, i + n)
        freq_r[val] = freq_r.get(val, 0) + 1

    hA, pA = build_hash(A)

    ans = 0
    for i in range(n):
        val = get_hash(hA, pA, i, i + n)
        ans += freq.get(val, 0)
        ans += freq_r.get(val, 0)

    print(ans)

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()
```このソリューションでは、2 倍の配列に対するローリング ハッシュを使用して、すべての回転を連続セグメントとして表します。 のために`b`、長さのセグメントの数を事前に計算します。`n`各ハッシュは通常形式と逆形式の両方で対応します。 次に、各回転ごとに、`a`、そのハッシュを計算し、一致を蓄積します。 

微妙な実装の詳細は、値をシフトすることによる整数配列の一貫性のあるハッシュです。`+1`、乗算時にゼロ衝突が発生しないようにします。 もう 1 つの重要な点は、フォームの大きな MOD を使用することです。`2^61 - 1`演算を高速に保ちながら衝突の可能性を減らすスタイルの算術演算。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    MOD = (1 << 61) - 1
    BASE = 91138233

    def build(arr):
        h = [0]
        p = [1]
        for x in arr:
            h.append((h[-1] * BASE + x + 1) % MOD)
            p.append((p[-1] * BASE) % MOD)
        return h, p

    def get(h, p, l, r):
        return (h[r] - h[l] * p[r-l]) % MOD

    def solve():
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        A = a + a
        B = b + b
        Br = b[::-1] + b[::-1]

        hB, pB = build(B)
        hBr, pBr = build(Br)
        hA, pA = build(A)

        freq = {}
        freq_r = {}

        for i in range(n):
            freq[get(hB, pB, i, i+n)] = freq.get(get(hB, pB, i, i+n), 0) + 1
            freq_r[get(hBr, pBr, i, i+n)] = freq_r.get(get(hBr, pBr, i, i+n), 0) + 1

        ans = 0
        for i in range(n):
            hval = get(hA, pA, i, i+n)
            ans += freq.get(hval, 0)
            ans += freq_r.get(hval, 0)

        return str(ans)

    t = int(input())
    out = []
    for _ in range(t):
        out.append(solve())
    return "\n".join(out)

 ## 特殊なケース

 次のような繰り返し要素を含む最小限の配列`[1,1,1,1]`すべての回転が同じ表現に折りたたまれるようにします。 この場合、回転するたびに、`a`のすべての回転に一致します`b`なので、答えは n² になります。 すべてのウィンドウのハッシュが含まれるため、アルゴリズムがこれを処理します。`B`同一なので、`freq`そのハッシュの n を累積し、n 回転のそれぞれを累積します。`a`n に寄与し、n² を生成します。 

2 番目のエッジ ケースは、配列が相互に逆巡回シフトである場合です。たとえば、`a = [1,2,3,4]`、`b = [4,3,2,1]`。 ここでは、逆マッチングのみが寄与します。 アルゴリズムはこれを正しく捕捉します。`freq_r`は反転した double 配列から構築されるため、`a`の 1 回転に正確に一致します`b`逆ハッシュテーブルを介して。 

最後のエッジケースは次のような場合です`n = 1`、両方の配列が単一の要素で構成されます。 2 倍の表現は繰り返される単一の値に縮退し、両方の周波数マップに正確に 1 つのエントリが含まれるため、答えは 1 となり、単一の有効な回転ペアに一致します。
