 ## 解決策
 ## 問題の理解

 各検出は同じ辺の長さの正方形です`S`。 その位置は左下隅によって決まります`(x, y)`、そして明確な信頼スコアを持っています。 NMS は、これらの検出を最高スコアから最低スコアの順に処理します。 検出がまだ抑制されていない場合、検出が選択されます。 選択すると、和集合に対する交差が指定されたしきい値よりも厳密に大きい、よりスコアの低い検出がすべて抑制されます。 タスクは、このプロセスを生き残ったすべての検出のインデックスを、元のインデックスで並べ替えて出力することです。 

公式の制約により、`n`到達する`10^5`、 と`S`まで`10^7`、しきい値は小数点以下 3 桁の正確な値です。 現在の Codeforces ステートメントでは、15 秒の時間制限と 256 MB のメモリ制限が与えられています。 アン`O(n^2)`実装で実行できるのは約`10^10`ペアチェックのタイミング`n = 10^5`, これは、比較的寛大な時間制限を考慮しても、妥当な範囲をはるかに超えています。 選択したボックスごとの比較の数を定数で制限する必要があります。 

2 つの等しい正方形について、`dx = |x1 - x2|`そして`dy = |y1 - y2|`。 

それらの交差点には幅があります`max(0, S - dx)`と高さ`max(0, S - dy)`。 交差点エリアが`A`、結合領域は`2S^2 - A`したがって、IoU は次のようになります。`A / (2S^2 - A)`。 

浮動小数点を使用してこれを評価すべきではありません。 しきい値が`p / 1000`、 それから`A / (2S^2 - A) > p / 1000`と全く同じです`(1000 + p) A > 2000 p S^2`。 

この不等式のすべての量は整数です。 

いくつかのエッジケースでは、不注意な実装が静かに破壊される可能性があります。 まず、比較結果が厳密にしきい値を超えています。 例えば、```
1
2 3 0.500
0 0 0.9
0 1 0.8
```交差点エリアは、`3 * 2 = 6`、組合は`18 - 6 = 12`、IoU は正確に`0.500`。 正しい出力は次のとおりです```
Case #1: 2
1 2
```使用する`>= threshold`ボックス 2 が誤って抑制されてしまいます。 

2 番目のエッジ ケースは、オーバーラップがゼロです。 例えば、```
1
2 4 0.300
0 0 0.9
4 0 0.8
```正方形は境界でのみ接触するため、交差面積はゼロです。 両方の検出を選択する必要があります。```
Case #1: 2
1 2
```距離のみから推論する不注意な実装では、接触している正方形を誤って重複しているものとして扱う可能性があります。 

3 番目のエッジケースは同一のボックスです。 例えば、```
1
3 1 0.700
0 0 0.5
0 0 0.7
0 0 0.9
```最高スコアのボックスが最初に選択され、他の両方のボックスとの IoU は次のようになります。`1`、厳密にはより大きいです`0.700`。 答えは、```
Case #1: 1
3
```個別スコア保証により、どの同一ボックスが生き残るかが正確にわかります。 

最後に、選択した検出結果は、スコア順ではなくインデックスの昇順で出力する必要があります。 ボックス 2 が抑制されている間にボックス 3 と 1 が存続する場合、出力は次のようになります。`1 3`たとえボックス 3 の方がスコアが大きいかもしれません。 公式サンプルはこの順序を示しています。 

## アプローチ

 直接的な解決策は文字通り NMS に従います。 すべてのボックスをスコアの降順に並べ替え、現在抑制されていないボックスを維持します。 次のボックスが選択されたら、それを残りのすべてのボックスと比較し、IoU がしきい値を超えるボックスを抑制します。 これはまさに NMS プロセスの定義であるため、これは正しいです。 

問題は比較の回数です。 最悪の場合、どのボックスも他のボックスを抑制しないため、最初に選択されたボックスが大まかにチェックされます。`n`ボックス、2 番目は大まかにチェックします`n - 1`、 等々。 合計は約`n(n - 1)/2`、おおよそに達します`5 * 10^9`の比較`n = 10^5`。 これは、ソート、ハッシュ テーブル操作、ジオメトリ計算を考慮する前に、すでに大きすぎます。 

重要な観察は、すべての正方形がまったく同じサイズであるということです。 固定された選択された正方形の場合、別の正方形の左下隅が選択された隅に十分に近い場合にのみ、別の正方形はしきい値を超える IoU を持つことができます。 で`(x, y)`平面では、競合する可能性のある位置のセットは、選択した点の周囲の境界領域になります。 

この幾何学的局所性をグリッドに変えることができます。 セルサイズを選択してください`C`そのため、同じセル内の任意の 2 ポイントの IoU がしきい値よりも厳密に大きいことが保証されます。 その後、各セルから最大 1 つのボックスを選択できます。 また、2 つの競合するボックスは、座標の違いが最大 2 であるセル内に存在する必要があることも示すことができます。 したがって、選択したボックスを処理するときは、`5 x 5`その細胞を取り囲む細胞。 

セル サイズは、おおよそではなく正確に選択されます。 閾値を次のようにします`p / 1000`そして定義します`q = 2p / (1000 + p)`。 

2 つのボックスの交差面積がしきい値よりも大きい場合、そのボックスの IoU はしきい値よりも大きくなります。`qS^2`。 

2 つの左下隅が辺の同じセル内にあると仮定します。`C`。 両者の座標の差は最大でも`C - 1`なので、それらの交差面積は少なくとも`(S - C + 1)^2`。 

最大の整数を選択します`C`満足のいく`(1000 + p)(S - C + 1)^2 > 2000pS^2`。 

したがって、同じセル内のボックスのすべてのペアが競合します。 これが中心密度限界です。 

ここで、実際に矛盾する 2 つのボックスについて考えてみましょう。 以来`(S - dx)(S - dy) > qS^2`、

 両方の係数は個別に次の値より大きくなければなりません`sqrt(q) S`。 したがって、`dx < S(1 - sqrt(q))`そして同様に`dy`。 

選択したセル サイズは少なくとも`S(1 - sqrt(q))`したがって、競合するペアの違いは、どちらの座標でも 1 セル幅の 2 倍未満です。 したがって、それらのグリッド座標は最大 2 だけ異なる可能性があります。 の`5 x 5`近傍には、可能なすべての抑制可能なボックスが含まれています。 

グリッドは、抑制されたボックスを物理的に削除する必要はありません。 ボックスは 1 つのセルに属し、そのセル内のすべてのボックスは互いに競合するため、セルには選択されたボックスを 1 つだけ含めることができます。 したがって、保存されている特定のボックスは、最大 25 個の隣接セルから選択されたボックスによってのみ検査できます。 各ボックスは、全体として一定数の比較のみに参加します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 公式コンテストの資料でも同じ幾何学的なアイデアが説明されています。つまり、同じサイズの正方形は固定された近傍内でのみ競合し、すべてのボックスをチェックする代わりにグリッドベースの検索が可能になります。 

## アルゴリズムのチュートリアル

 1. しきい値を整数として解析する`p`代表する`p / 1000`。 すべてのスコアをスケールされた整数として解析します`10^6`。 これにより、並べ替え時や IoU が厳密にしきい値を超えているかどうかを判断する際の浮動小数点比較が回避されます。 
2. ボックス インデックスをスコアの降順に並べ替えます。 すべてのスコアは個別であるため、これにより、NMS がボックスを考慮する順序が正確に決まります。 
3. グリッドセルの最大辺の長さを計算します。`C`満足のいく`(1000 + p)(S - C + 1)^2 > 2000pS^2`。 

左辺は次のように減少します`C`増えるので、`C`二分探索で見つけることができます。 厳密な不平等は意図的なものです。 厳密に一致します`IoU > threshold`ルール。 
4. すべてのボックスを、キーをキーとした辞書に挿入します。`(x // C, y // C)`。 辞書には、各空間セルに属するインデックスが格納されます。 
5. ボックスをスコアの降順に処理します。 ボックスがすでに抑制されている場合は、スキップします。 それ以外の場合は、それを選択し、処理済みとしてマークします。 
6. 選択したボックスについて、次のオフセットを持つすべてのグリッド セルを検査します。`-2`を通して`2`両方の座標で。 IoU がしきい値を超える可能性のあるすべてのボックスは、これら 25 個のセルのいずれかに存在する必要があります。 
7. まだ抑制されていないすべての候補について、正確な交差領域を計算してテストします。`(1000 + p) * intersection > 2000 * p * S^2`。 

不等式が成り立つ場合、その候補を抑制済みとしてマークします。 
8. 選択したすべてのインデックスを保存し、印刷する前にそれらのインデックスを徐々に並べ替えます。 NMS プロセス自体はスコア順に並べられますが、必要な出力はインデックス順に並べられます。 

### なぜ効果があるのか

 不変条件は、スコア順にボックスを処理する前に、NMS の規定どおりに、以前のすべてのボックスが選択または抑制されるということです。 現在のボックスがすでに非表示になっている場合は、決して選択しないでください。 それ以外の場合は、以前に選択したボックスが抑制されていないため、残りのボックスの中で正確に最高スコアとなるため、選択する必要があります。 

ボックスが選択されている場合、抑制できる可能性のあるすべてのスコアの低いボックスは検査対象のボックス内にあります。`5 x 5`近所。 セル サイズの構築により、すべての同じセルのペアが競合することが保証されますが、オーバーラップの不等式により、すべての競合するペアが最大 2 の距離にあるセルに制限されます。 次に、正確な整数 IoU テストは、IoU が厳密にしきい値よりも大きい候補を正確に抑制します。 したがって、すべての NMS 決定は正しく行われ、最終的に選択されたセットはまさに必要なものとなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def parse_scaled(s, digits):
    if '.' in s:
        a, b = s.split('.')
    else:
        a, b = s, ''
    b = (b + '0' * digits)[:digits]
    return int(a) * (10 ** digits) + int(b)

def solve():
    t = int(input())
    output = []

    for case_id in range(1, t + 1):
        n, S, threshold = input().split()
        n = int(n)
        S = int(S)

        # threshold is exact to three decimal places.
        p = parse_scaled(threshold, 3)

        boxes = []
        order = []

        for i in range(n):
            x, y, score = input().split()
            x = int(x)
            y = int(y)
            score = parse_scaled(score, 6)
            boxes.append((x, y))
            order.append((score, i))

        order.sort(reverse=True)

        # We need the largest integer C such that
        #
        # (1000 + p) * (S - C + 1)^2 > 2000 * p * S^2
        #
        # Then any two boxes in one cell necessarily have IoU > threshold.
        target = 2000 * p * S * S
        coefficient = 1000 + p

        def good(c):
            overlap = S - c + 1
            return coefficient * overlap * overlap > target

        lo, hi = 1, S
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if good(mid):
                lo = mid
            else:
                hi = mid - 1

        cell_size = lo

        grid = {}
        for _, idx in order:
            x, y = boxes[idx]
            key = (x // cell_size, y // cell_size)
            grid.setdefault(key, []).append(idx)

        suppressed = bytearray(n)
        selected = []

        for _, idx in order:
            if suppressed[idx]:
                continue

            suppressed[idx] = 1
            selected.append(idx + 1)

            x1, y1 = boxes[idx]
            gx = x1 // cell_size
            gy = y1 // cell_size

            for ox in range(-2, 3):
                for oy in range(-2, 3):
                    candidates = grid.get((gx + ox, gy + oy))
                    if candidates is None:
                        continue

                    for j in candidates:
                        if suppressed[j]:
                            continue

                        x2, y2 = boxes[j]

                        ix = S - abs(x1 - x2)
                        if ix <= 0:
                            continue

                        iy = S - abs(y1 - y2)
                        if iy <= 0:
                            continue

                        area = ix * iy

                        if coefficient * area > target:
                            suppressed[j] = 1

        selected.sort()

        output.append(f"Case #{case_id}: {len(selected)}")
        output.append(" ".join(map(str, selected)))

    sys.stdout.write("\n".join(output))

if __name__ == "__main__":
    solve()
```入力解析では、しきい値とスコアが意図的に整数として保持されます。 次のようなしきい値`0.500`になる`500`、次のようなスコアが表示される一方で、`0.900000`になる`900000`。 入力では正確な 10 進数値が保証されるため、この表現では順序が維持され、丸め誤差が回避されます。 

二分探索により、最大の安全なセル サイズが見つかります。 候補セルサイズについて`C`、そのセル内の 2 つのボックス間の可能な最小の交差は、2 つの座標が異なる場合に発生します。`C - 1`。 結果として得られる交差点は、`(S - C + 1)^2`、それで、`good`predicate は、最悪のケースでもしきい値を厳密に上回る IoU があるかどうかを直接チェックします。 

の`grid`ディクショナリは、各空間セルをそのセル内のすべての元のボックス インデックスにマップします。 抑制されたエントリは削除されずに保持されます。 これにより、実装がシンプルに保たれ、複雑さの限界が破壊されることはありません。 どのセルからも最大で 1 つのボックスが生き残ることができるため、保存されたボックスは、セルが距離 2 以内にある一定数の選択されたボックスからのみ検出されます。 

の`suppressed`bytearray は、すでに選択されているボックスと NMS によって削除されたボックスの両方を記録します。 パイソンの`bytearray`Python のブール値のリストよりも大幅に小さい`10^5`エントリ。 

交差の計算には次のものを使用します。`ix = S - abs(x1 - x2)`と同様の表現`iy`。 正でない値は、正の領域の交差がないことを意味するため、IoU はゼロとなり、候補は抑制できません。 最後の比較では整数演算が使用され、厳密な不等式が正確に保持されます。 

Python の整数には任意の精度があるため、次のような積が得られます。`S^2`そして`2000 * p * S^2`オーバーフローしないでください。 固定幅の整数を使用する言語では、これらの境界には 64 ビット整数で十分です。

            suppressed[idx] = 1
            selected.append(idx + 1)

            x1, y1 = boxes[idx]
            gx = x1 // cell_size
            gy = y1 // cell_size

            for ox in range(-2, 3):
                for oy in range(-2, 3):
                    candidates = grid.get((gx + ox, gy + oy))
                    if candidates is None:
                        continue

                    for j in candidates:
                        if suppressed[j]:
                            continue

                        x2, y2 = boxes[j]

                        ix = S - abs(x1 - x2)
                        if ix <= 0:
                            continue

                        iy = S - abs(y1 - y2)
                        if iy <= 0:
                            continue

                        area = ix * iy

                        if coefficient * area > target:
                            suppressed[j] = 1

        selected.sort()

        output.append(f"Case #{case_id}: {len(selected)}")
        output.append(" ".join(map(str, selected)))

    return "\n".join(output)

    return solution(inp)
