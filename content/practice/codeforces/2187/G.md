 ## 解決策
 ## 問題の理解

 順列を再構築するように求められます$q$長さの$n$一連の配列から派生したデカルト ツリーの特別なエンコーディングから。 各アレイ$p_i$前の配列を取得して生成されます$p_{i-1}$そしてその最小要素を増分します$n$、すべての番号が区別できるようにします。 アレイごとに$p_i$これは、任意のノードの親がより大きな値を持ち、左右のサブツリーが元の配列インデックスを尊重するという特性を持つバイナリ ツリーです。 

The input does not give the arrays directly; instead, it gives a binary matrix$s$サイズの$n \times n$。 マトリックスは、すべての配列にわたるすべての親子関係をエンコードします。$p_i$。 具体的には、$s_{i,j} = 1$、それは次のことを示します$i$かつてはの子供だった$j$デカルト ツリーの 1 つで。 私たちの仕事は、あらゆる順列を再構築することです$q$その派生シーケンスが指定された行列を生成します。 

制約は中程度です。$n$最大 3000 まで可能で、合計は$n^2$テストケース全体では$9 \cdot 10^6$。 これは除外します$O(n^3)$解決策だが許可する$O(n^2)$アルゴリズム、特に行列を反復処理して簡単な簿記を行うアルゴリズム。 

明らかではないエッジケースには次のようなものがあります。 

1. **単一スワップ ルート**: 2 要素の置換は次のいずれかになります。$[1,2]$または$[2,1]$、両方とも異なるデカルト ツリーを生成します。 不注意なコードは、固定された順序を想定している可能性があります。 
2. **最小要素位置**:$p_i$最小値を増分すると、各デカルト ツリーの実際のルートが変化する可能性があります。 ルートが常に最初または最後の要素であると想定するアルゴリズムは失敗します。 
3. **切り離された影響**: 一部の要素は親にも子にもならないため、相対的な順序は柔軟なままになります。 アルゴリズムは、行列を満たしながらこれらを柔軟に処理する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、すべてをシミュレートしようとします。$p_i$候補順列からの配列$q$そして、結果の親セットを入力行列と比較します。$s$。 デカルト ツリーの各シミュレーションには、$O(n)$モノトーンスタックアプローチを使用するため、すべての人にとって$p_i$これは$O(n^2)$候補者ごとに。 全部試してみる$n!$順列は明らかに不可能です。 

重要な観察は次のとおりです$s$どの要素がどの親の子として出現するかをエンコードします。 要素の場合$i$決して子供ではありません（行$i$で$s$すべてゼロである)、それは次の最小要素である必要があります。$q$配列のシーケンスでは常に最小値が昇格されるためです。 最小限の要素を選択したら、それを繰り返し削除して問題を軽減できます。 これにより、「決して子ではない」という制約を尊重して、残りの数値の中から最小の要素を繰り返し選択するという問題が軽減されます。 

これにより、貪欲なアルゴリズムが提供されます。つまり、その行が含まれる要素を繰り返し選択します。$s$残りの候補にはすべてゼロが含まれます。 次に小さい番号を割り当て、考慮から削除し、更新します$s$それに応じて。 これは$O(n^2)$、制限内に快適に収まります。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$そして$n \times n$マトリックス$s$。 まだ値が割り当てられていない残りのインデックスのセットを維持します。$q$。 
2. 空の順列配列を初期化する$q$。 私たちが満たします$q$小さい数字から$1$まで$n$。 
3. 未割り当てのインデックスがある間、残りのすべてのインデックスをスキャンします。 インデックスごとに$i$、その行が$s$残りの列はすべてゼロです。 「はい」の場合、$i$は、現在の最小値の有効な候補です。 
4. 現在の最小値を$i$、 取り除く$i$残りのセットから値を増やし、次の反復に割り当てる値を増分します。 
5. すべてのインデックスが割り当てられるまで繰り返します。 戻る$q$。 

**機能する理由:** すべてのステップで、残りの要素の中から子ではなかった要素を選択しています。 の定義によれば、$p_i$構築とその最小限の要素であるデカルト ツリー$q$どの作品にも子供として登場することはありません$p_i$, したがって、この貪欲な選択は常に有効です。 この不変式を繰り返すことにより、再構成された順列が、エンコードされたすべての親子関係を確実に満たします。$s$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = [list(map(int, input().strip())) for _ in range(n)]
        remaining = set(range(n))
        q = [0] * n
        current = 1
        while remaining:
            for i in remaining:
                if all(s[i][j] == 0 or j not in remaining for j in remaining):
                    q[i] = current
                    current += 1
                    remaining.remove(i)
                    break
        print(' '.join(map(str, q)))

solve()
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 それは、`remaining`まだ割り当てられていないインデックスを追跡するように設定します。 各ステップで、セットをスキャンして、残りの列にゼロが含まれる行の要素を見つけ、それに現在の最小番号を割り当て、セットを更新します。 の`break`これにより、反復ごとに 1 つの要素のみが割り当てられるようになります。 

微妙な点には正確なチェックが含まれます`j not in remaining`すでに割り当てられているインデックスに対応する列を無視します。 これがないと、アルゴリズムは次のような小さなケースで失敗します。`n=2`。
