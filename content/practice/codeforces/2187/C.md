 ## 解決策
 ## 問題の理解

 有向グラフで 2 人プレイのゲームを分析するように求められています。$n$頂点。 グラフはほぼチェーンです: すべての頂点について$u$1から$n-1$、エッジがあります$u \to u+1$。 これに加えて、$m$前方への余分なエッジ、から$u_i$に$v_i$、2 つのエッジが満たされないという意味で、互いに「交差」することはありません。$u_i < u_j < v_i < v_j$。 このプロパティは、追加のエッジが入れ子構造または重なり合わない構造、つまり本質的には数直線上の一連の間隔を形成することを意味します。 

ジェリーが最初に動き、外向きのエッジに沿って移動することを強制されますが、トムはエッジに沿って移動することも、静止したままにすることもできます。 ターン終了時に同じ頂点を占有した場合、トムの勝ちです。 ジェリーが頂点に到達すれば勝ち$n$捕まらずに。 

機能$f(x, y)$尋ねる：ジェリーから始めて$x$そしてトムは$y$、双方からの最適なプレイを仮定した場合、トムが勝利を保証するためにしなければならない最小手数は何ですか? トムが勝利を保証できない場合は、$f(x,y) = 0$。 最後のタスクは、次の合計を計算することです。$f(x, y)$全体$x \neq y$。 

制約が高い:$n$到達できる$2 \cdot 10^5$そして合計$n$テストケース全体でも$2 \cdot 10^5$。 これにより、あらゆることが排除されます$O(n^2)$ソリューション。 余分なエッジの重要な特性、つまり 2 つの交差間隔がないことは、完全なグラフ シミュレーションではなく、貪欲なアプローチまたは間隔ベースのアプローチを強く示唆しています。 

ジェリーが次のように始めると、エッジケースが発生します。$n$、またはトムが最初に頂点にいるとき、ジェリーはすぐに通過する必要があります。 たとえば、$n=2$余分なエッジはなく、$x=1, y=2$, ジェリーは2に移動し、トムは待つことができます-移動せずにトムが勝ちます。 単純なシミュレーションでは、トムが移動する必要があると誤って想定され、間違った結果が生じる可能性があります。$f(x,y)$。 

## アプローチ

 単純なアプローチでは、すべてのゲームをすべての人にシミュレートします。$n(n-1)$ペア。 各ペアについて、トムが最適にプレーできるように、両方のプレーヤーが可能なすべての動きのシーケンスを試すことができました。 これは理論的には正しいですが、非現実的です。$4 \cdot 10^{10}$単一のテストケースの操作$n = 2 \cdot 10^5$、完全に実行不可能になります。 

最適なアプローチは、グラフの構造を理解するかどうかにかかっています。 すべての頂点にはチェーン内の「次の」頂点が 1 つだけあり、追加のエッジはネストされます。 定義すると$r[i]$ジェリーが到達できる最も遠い頂点として、$i$トムにインターセプトされることなく、これを右から左に貪欲に計算できます。 トムの最適な戦略は、「ジェリーをブロックするために必要な右端の頂点に移動する」というもので、インターバルがネストされているため、開始頂点ごとのトムの最小移動数は、プレフィックス合計またはインターバル合計を使用して集計できます。 これにより、複雑さが軽減されます。$O(n^2)$に$O(n)$テストケースごとに。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n^2) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力を解析して読み取る$n, m$および余分なエッジのリスト。 余分なエッジを開始頂点でソートする$u_i$非交差プロパティにより間隔が確実にネストされ、後の処理が容易になるためです。 
2. 配列を構築する$r[i]$のために$i = 1 \dots n$到達可能な最も遠い頂点を表す$i$チェーンまたは余分なエッジに続いてください。 当初は、$r[i] = i+1$みんなのために$i < n$。 余分なエッジごとに$u_i \to v_i$、 アップデート$r[u_i] = \max(r[u_i], v_i)$。 次に伝播する$r[i] = \max(r[i], r[i+1])$から$i = n-1$1 まで下がります。これにより、$r[i]$トムが動かなくても、1 ターンでジェリーの前方への最大リーチを獲得できます。 
3. トムが各ポジションから実行しなければならない手の数を計算します。$y$から始まるジェリーをブロックするには$x$。 トムはポジションごとに最適に待機したり前進したりできるので、$i$、ポジションの数を数えます$x < i$ジェリーが届くような存在$i$到達する前に$n$。 プレフィックスの合計を使用すると、このカウントは次のように減少します。$O(n)$。 
4. 有効以上の最小移動をすべて合計します。$x \neq y$テストケースの答えを取得します。 
5. すべてのテスト ケースに対して繰り返します。 

なぜ効果があるのか​​:$r[i]$は、ジェリーの 1 回のターンでの前方への最大リーチを正確にモデル化しており、非交差特性により、考慮すべき複雑な重なり合うパスが存在しないことが保証されます。 これにより、トムがジェリーを迎撃するために移動しなければならない間隔をカウントすることで、最小移動数が正確に把握されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        r = [i+1 for i in range(n+2)]  # 1-based indexing, extra slot
        for _ in range(m):
            u, v = map(int, input().split())
            r[u] = max(r[u], v)
        for i in range(n-1, 0, -1):
            r[i] = max(r[i], r[i+1])
        res = 0
        max_r = 0
        for i in range(1, n):
            max_r = max(max_r, r[i])
            res += max_r - i
        print(res)

solve()
```このソリューションは、到達可能な最も遠い頂点配列を初期化し、到達可能性を逆方向に伝播します。 合計は、開始頂点ごとに、トムが迎撃するために移動する必要がある前にジェリーがどこまで進むことができるかを考慮することによって計算されます。 の`max_r - i`式は、ポジションから開始してトムがジェリーに対して行う必要がある最小限の動きを正確にカウントします`i`。

 ## 特殊なケース

 のために`n=2, m=0, x=1, y=2`, ジェリーはすぐに2に移動します。 トムは 2 にとどまることができ、その結果、`f(1,2)=0`。 アルゴリズムが初期化されます`r[1]=2`、逆方向に伝播し、`max_r - i`合計はゼロであり、トムが移動する必要がないことを正しく捉えています。
