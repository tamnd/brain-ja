 ## 解決策
 ## 問題の理解

 整数の配列が与えられ、最大の整数を決定するように求められます。$k$少なくとも差が 2 つ以上ある 2 つの要素を交換することで、配列を降順以外で並べ替えることができます。$k$。 形式的には、インデックスのペアに対して$i < j$、交換できます$a_i$そして$a_j$もし$|a_i - a_j| \ge k$。 私たちの目標は最大化することです$k$これらのスワップを使用して配列を完全にソートできるようにしながらも。 

入力は複数のテスト ケースで構成され、それぞれの長さは$n$まで$2 \cdot 10^5$および最大の配列値$10^9$。 合計から$n$すべてのテストケースで次を超えない$2 \cdot 10^5$、テスト ケースごとに、ほぼ線形または線形演算のアルゴリズムが必要です。 二次アプローチは、最大で次の時間が必要となるため、妥当な時間内に実行することはできません。$10^{10}$最悪の場合の運用。 

配列がすでにソートされている場合、微妙なエッジケースが発生します。 たとえば、配列が`[1,2,3]`、スワップは必要ありませんが、問題は最大のスワップを要求します。$k$。 この場合、負ではない任意の$k$技術的には許可されていますが、最大の意味があるのは$k$は操作が必要ないという意味で未定義であるため、答えは次のようになります。`-1`。 もう 1 つの注意が必要なケースは、すべての要素が等しい場合です。`[5,5,5]`; 繰り返しますが、スワップは必要なく、出力は次のようにする必要があります。`-1`。 Arrays with only two elements are simpler, but the algorithm must still correctly identify whether a swap is needed to sort them.

 ## アプローチ

 ブルートフォースアプローチはあらゆる可能性を試みます$k$値を設定し、それぞれのスワップをシミュレートしようとします。 それぞれについて$k$、配列を繰り返しスキャンし、少なくとも差があるペアを交換します。$k$交換ができなくなるまで。 このアプローチは原理的には正しいですが、遅すぎます。$10^9$可能$k$値と各シミュレーションが取り得る値$O(n^2)$、これは計算上不可能です。 

重要な洞察は、最大の子豚が$k$は、ソートされた配列内で順序が乱れている要素の位置によってのみ決定されます。 させて`b`のソートされたバージョンになる`a`。 要素を考慮する$a_i$そして$b_i$同じインデックスにあります。 もし$a_i \neq b_i$、その要素は移動する必要があります。 の最大値$k$必要なすべてのスワップを許可する値は、移動する必要がある元の要素とソートされた配列内のターゲットとの間の最大の差になります。 具体的には、$k \le \max(a) - \min(a)$間違って配置された要素の中に。 これにより、問題は配列全体の 1 回のパスに短縮されます。つまり、間違って配置された要素の最小値と最大値を特定し、それらの差を計算します。 要素が間違って配置されていない場合、配列はすでにソートされており、答えは次のようになります。`-1`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2 * max(a)) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、配列を読み取ります。`a`ソートされたコピーを作成します`b`。 
2.初期化`min_misplaced`に`inf`そして`max_misplaced`に`-inf`。 
3. インデックスを反復処理する`i`0から`n-1`。 各インデックスについて、`a[i] != b[i]`、 アップデート`min_misplaced`そして`max_misplaced`と`a[i]`。 
4. 反復後、次のことを確認します。`min_misplaced`残る`inf`。 そうである場合、配列はすでにソートされており、出力は次のようになります。`-1`。 
5. それ以外の場合、最大のピギー整数`k`は`max_misplaced - min_misplaced`。 
6. 結果を出力します。 

機能する理由: 並べ替えられた位置にない要素は移動する必要があります。 許可される最大値$k$スワップは、以下の違い以上の場合にのみ許可されるため、誤って配置された要素の中で最大の要素と最小の要素の差を超えることはできません。$k$。 選択することで$k$この違いとして、必要なすべてのスワップが許可されることを保証します。$k$必要なスワップをブロックします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    b = sorted(a)
    
    min_misplaced = float('inf')
    max_misplaced = float('-inf')
    
    for i in range(n):
        if a[i] != b[i]:
            min_misplaced = min(min_misplaced, a[i])
            max_misplaced = max(max_misplaced, a[i])
    
    if min_misplaced == float('inf'):
        print(-1)
    else:
        print(max_misplaced - min_misplaced)
```コードはまず入力を効率的に読み取ります。 誤って配置された要素の極値を追跡するために 2 つの変数を維持します。 配列を反復処理すると、移動する必要がある要素のみが結果に影響を与えます。 使用する`float('inf')`そして`float('-inf')`最初に間違って配置された要素の特殊なケースを回避します。 並べ替えというのは、`O(n log n)`、スキャンは`O(n)`。 このソリューションは、単一パスで複数のテスト ケースを処理します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = sorted(a)
        min_misplaced = float('inf')
        max_misplaced = float('-inf')
        for i in range(n):
            if a[i] != b[i]:
                min_misplaced = min(min_misplaced, a[i])
                max_misplaced = max(max_misplaced, a[i])
        if min_misplaced == float('inf'):
            output.append('-1')
        else:
            output.append(str(max_misplaced - min_misplaced))
    return "\n".join(output)
