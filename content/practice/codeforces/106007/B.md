 ## 問題の理解

 長さの配列が与えられます$n$。 手術を繰り返し行う$m$そしてそのたびに、紙に書かれた増加する数列に数字を 1 つ追加します。 

各操作には 3 つのランダムなレイヤーがあります。 まず、配列をランダムにシャッフルします。これにより、配列のすべての置換の可能性が等しくなります。 次に、ランダムな整数を選択します$k$から一律に$1$に$n$。 最後に、ランダムなインデックスを選択します$i$から一律に$1$に$k$、そして現在の位置にある要素を追加します$i$シャッフルされた配列内。 

これを行った後$m$回、長さのシーケンスを取得します$m$。 タスクは、この最終シーケンスが減少しない確率を計算し、それを剰余として出力することです。$998244353$。 

制約により許可されるのは、$n, m \le 10^6$これにより、プロセスを明示的にシミュレートするソリューションは除外されます。 単一の操作を単純に処理する場合でも、すべての操作について推論する必要があります。$n$位置を決め、これを繰り返す$m$プロセスを閉じた形式の確率モデルに圧縮する必要があることをすでに示唆しています。 偶数の解決策$O(nm)$という行動は直ちに不可能です。$10^{12}$操作。 

多段階のランダム性により、微妙なエッジ ケースが発生します。 プロセスがシャッフルされた配列内の位置に複雑に依存している、または操作間の相関関係が重要であると誤って仮定する人もいるかもしれません。 たとえば、$n=2, m=2, a=[1,2]$、複数の操作にわたる描画間の依存関係を誤ってシミュレートすることが簡単に起こります。 正しい解釈は、配列を毎回再シャッフルするため、各操作は独立しているということです。 

もう 1 つの潜在的な間違いは、配列から要素を一律に選択するものとして選択を扱うことです。 それはすぐには明らかではありません。$k$-制限があり、分布は慎重に導き出す必要があります。 

## アプローチ

重要な洞察は、シャッフルされた配列内の特定の位置が選択される確率を分析すると、複雑なサンプリング プロセスが大幅に簡素化されるということです。 ポジションを固定したら$j$、すべての有効な値を合計することにより、このポジションが 1 回の操作で選択される確率を計算します。$k$。 これにより、位置に依存した重みが生成されますが、均一なシャッフルの平均化後に驚くべきことが起こります。すべての配列要素は、その位置に関係なく、同じように選択される可能性が高くなります。 複雑な手順全体が、配列要素の複数セットからの均一なサンプリングに集約されます。

 ## アルゴリズムのチュートリアル

 しましょう$p_v$単一の操作で値が出力される確率を示します。$v$。 シャッフルの対称性と位置の平均化から、次のようになります。$p_v = \frac{\text{cnt}[v]}{n}$。 

ここでシーケンスをモデル化します$X_1, X_2, \dots, X_m$、ここでそれぞれ$X_t$配布とは独立して描画されます$p$。 次の確率が欲しいのです$X_1 \le X_2 \le \cdots \le X_m$。 

このイベントを構造化するために DP 解釈を定義します。 

1. 定義する$f[t][v]$その後の確率として$t$ステップ、シーケンスは減少せず、正確に値で終了します。$v$。 これにより、最後の要素が固定されているすべての有効なプレフィックスがキャプチャされます。 
2. トランジションの場合、値を追加する場合$v$ステップで$t$、前の値は最大でも$v$。 したがって、以前のすべての状態を合計します。$$f[t][v] = p_v \cdot \sum_{u \le v} f[t-1][u]$$要因$p_v$独立したサンプリングから得られたもの$v$ステップで$t$。 
3. プレフィックスの蓄積を定義します。$$g[t][v] = \sum_{u \le v} f[t][u]$$これにより、トランジションをコンパクトな形式で書き直すことができます。 
4. 繰り返しを置き換えます。$$g[t][v] = g[t-1][v] + f[t][v] = g[t-1][v] + p_v \cdot g[t-1][v]$$これは次のように単純化されます。$$g[t][v] = g[t-1][v]\cdot (1 + p_v)$$5.以来$g[0][v] = 1$繰り返し適用すると、次のようになります。$$g[m][v] = (1 + p_v)^m$$6.回復する$f[m][v]$プレフィックスの違いから:$$f[m][v] = p_v \cdot (1 + p_v)^{m-1}$$7. 最終的な答えは、考えられるすべての最後の値の合計です。$$\sum_v p_v \cdot (1 + p_v)^{m-1}$$構造上の重要な点は、最後の要素を条件付けすると、プレフィックスの累積によって値間の依存関係がすべて削除されるということです。 

### なぜ効果があるのか

 プロセス全体は、値に対する固定分布からの独立したサンプリングに帰着します。 非減少条件は順序を制約するだけであり、DP は最後に選択された値を追跡することによってその制約を強制します。 プレフィックス構造により、すべてのステップで、ある値以下で終わるすべての有効な履歴が 1 つの状態に集約されることが保証されます。 これにより、遷移はローカルな乗算のみに依存するようになります。$1 + p_v$、システムを値間で分離可能にします。 分離可能性が現れると、それぞれの値は独立して進化し、閉じた形式に直接つながります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

n, m = map(int, input().split())
a = list(map(int, input().split()))

cnt = [0] * (n + 1)
for x in a:
    cnt[x] += 1

inv_n = modpow(n, MOD - 2)

ans = 0
for v in range(1, n + 1):
    if cnt[v] == 0:
        continue
    p = cnt[v] * inv_n % MOD
    term = p * modpow((1 + p) % MOD, m - 1) % MOD
    ans = (ans + term) % MOD

print(ans)
```この実装は、派生した式を直接反映します。 We first compute the frequency-based probability$p_v$値ごとに。 モジュラーの逆$n$確率がモジュロで表現されるため、これが使用されます。$998244353$。 

各項は次のように計算されます。$p_v (1 + p_v)^{m-1}$。 べき乗は値ごとの計算を支配しますが、対数であるため、全体的な複雑さは大規模な場合でも効率的です。$n$。 

よくある落とし穴は、指数が次のものにのみ適用されることを忘れることです。$m-1$、 ない$m$。 これは、最初の要素のみが寄与するという事実から来ています。$p_v$、後続のステップでは乗算係数が累積されます。

import sys, io

MOD = 998244353

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    def modpow(a, e):
        res = 1
        while e:
            if e & 1:
                res = res * a % MOD
            a = a * a % MOD
            e >>= 1
        return res

    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    cnt = [0] * (n + 1)
    for x in a:
        cnt[x] += 1

    inv_n = modpow(n, MOD - 2)

        if cnt[v] == 0:
            continue
        p = cnt[v] * inv_n % MOD

    return str(ans)

 ## 特殊なケース

 次のような最小限の配列$n=1$あらゆる操作が決定的になります。 式は次のようになります。$p_1 = 1$したがって、最終的な確率は、次の条件に関係なく常に 1 になります。$m$これは、すべてのシーケンスが一定であるため、減少しないという事実と一致します。 

次のような均一な配列では$a = [x, x, x, \dots]$、 我々は持っています$p_x = 1$、したがって、すべての項は次のようになります$1 \cdot 2^{m-1}$ただし、可能なシーケンスは定数のみであるため、モジュロ演算は 1 に解決されます。 アルゴリズムは、合計を単一の有効な結果に正しく折りたたみます。 

次のような混合配列では、$a = [1, 2, 3]$、各値は、周波数から導出される確率を通じて独立して寄与します。 DP はプレフィックス制約を超えて値を混合せず、閉じた形式により値間の干渉が残らないことが保証され、導出された分布の独立構造と一致します。
