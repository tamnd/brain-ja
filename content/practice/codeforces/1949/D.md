 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、$n$ゲーム シナリオ。プレーヤーはそれぞれのシナリオを 1 回だけプレイする必要があります。 2 つの異なるシナリオの間で$i$そして$j$、ゲームには面白い (F) または怖い (S) かの切り替えビデオがあります。 このトランジションは対称的です。つまり、ビデオが$i$に$j$からと同じです$j$に$i$。 ゲームデザイナーはすでに最大でも次のことを指定しています$\lfloor n/2 \rfloor$これらの遷移のうち、残りは不明です。 

課題は、プレイヤーがどの順序でシナリオをプレイしても、次のような状況に遭遇しないように、残りのトランジションを割り当てることです。$\lceil 3n/4 \rceil$同じタイプの連続した遷移。 入力は、部分的に満たされた計画を表す行列です。`F`、`S`、`?`、 そして`.`対角線用。 出力は、制約に従って完全に埋められた対称行列である必要があります。 

小さな上限は$n$($n \le 24$) および遷移の対称的な性質は、建設的な解決策が可能であることを示唆しています。 すべての順列を考慮する単純なアプローチでは、複雑さは階乗になります ($n!$）、これはたとえ$n=24$。 代わりに、入力するメソッドが必要です。`?`すべての順列をシミュレートせずに制約を保証する遷移。 

次の場合には、明らかではないエッジケースが発生します。$n$たとえば小さいです$n=2$または$n=3$。 ここでの制約は、$\lceil 3n/4 \rceil$遷移の総数よりも大きくなる可能性があります。 型のバランスを貪欲に取ろうとする不注意なアルゴリズムは複雑になりすぎたり、解決策を生成できなかったりする可能性がありますが、実際には、固定されたエントリを尊重する限り、どの補完も機能します。 

## アプローチ

 ブルートフォースアプローチはシンプルです: すべてを試してください$2^{k}$未知の遷移を埋める可能な方法 (`?`）、 どこ$k$未知の数です。 塗りつぶされた各行列について、すべてをチェックします。$n!$シーケンスに次の値を超えるものが存在しないことを保証するための順列$\lceil 3n/4 \rceil$連続した F または S 遷移。 このアプローチはあらゆる可能性を徹底的に検討するので正しいですが、$2^{k} \cdot n!$天文学的に大きい$n>10$。 

重要な観察点は、最大連続制限が$\lceil 3n/4 \rceil$単一シナリオからの遷移数の半分よりも常に大きくなります。 これは、すべての未知数を一貫して 1 つの型に割り当てると (たとえば、すべての未知数が`F`)、制約はすべての置換に対して満たされます。 基本的に、入力がすでに連続制限に違反していない限り、パスは連続制限を超えることはできませんが、この問題ではそのようなことが起こらないことが保証されています。 これにより、問題は階乗複雑さの探索から直接的な建設的充填に変換されます。 

したがって、最適なアプローチは、単純にすべてを置き換えることです。`?`固定タイプのエントリ (例:`F`) 対称構造をそのまま維持しながら。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^k * n!) | O(n^2) | 遅すぎる |
 | 建設的な塗りつぶし | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. シナリオの数を読む$n$そして$n \times n$マトリックス。 エントリはそのままにしておきます。 
2. 行列は対称であるため、行列の上三角形 (対角部分を除く) を繰り返します。 それぞれについて`?`エントリ、割り当て`F`。 
3. 対称性を維持するために、割り当てられた値を対称位置にコピーします。 
4. 出発`.`対角線上のエントリは変更されません。 
5. 完成したマトリックスを印刷します。 

機能する理由: 正確性を保証する特性は、連続制限があることです。$\lceil 3n/4 \rceil$は常に、遷移グラフ内のノードの最大次数以上です。 すべての未知数を同じタイプで埋めることにより、任意の順列における可能な最大の連続シーケンスがこのしきい値を超えることはできません。 すでに指定されているトランジションは次の数より少ないです$n/2$, したがって、違反を強制することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
matrix = [list(input().strip()) for _ in range(n)]

for i in range(n):
    for j in range(i + 1, n):
        if matrix[i][j] == '?':
            matrix[i][j] = 'F'
            matrix[j][i] = 'F'

for row in matrix:
    print(''.join(row))
```このコードは行列を読み取り、上の三角形の未知数を次のように埋めます。`F`、対称性を保つためにそれらをミラーリングし、結果を出力します。 上の三角形を使用すると、冗長なチェックが回避されます。 斜めのエントリは残ります`.`。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    matrix = [list(input().strip()) for _ in range(n)]
    for i in range(n):
        for j in range(i + 1, n):
            if matrix[i][j] == '?':
                matrix[i][j] = 'F'
                matrix[j][i] = 'F'
    return '\n'.join(''.join(row) for row in matrix)

# provided sample
assert run("5\n.?F??\n?.???\nF?.S?\n??S.?\n????.\n") == ".FFFF\nF.FFF\nFF.SF\nFFS.F\nFFFF.", "sample 1"

# small n
assert run("3\n.??\n?.?\n??.\n") == ".FF\nF.F\nFF.", "small 3"

# n=2, one fixed
assert run("2\n.F\nF.\n") == ".F\nF.", "n=2, fixed F"

# n=4, all unknown
assert run("4\n.???\n? .??\n???.\n???\n") == ".FFF\nF.FF\nFFF.\nFFF.", "n=4 all unknown"

# n=24, max size, all unknown (just check length)
output = run("24\n" + "\n".join(["?"*24 for _ in range(24)]) + "\n")
assert len(output.splitlines()) == 24, "max n lines"

 | 3 つのシナリオはすべて未知 | 対称行列 | 小規模かつ最先端のケース |
 | 2 つのシナリオ、1 つは修正済み | 対角 + 固定を尊重 | 最小 n の正しさ |
