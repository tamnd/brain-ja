 ## 解決策
 ## 問題の理解

 プロセスは次の単一セルから始まります。`(0, 0)`。 

細胞が分裂するたびに`(x, y)`、その細胞は消えて生成します`(x + 1, y)`そして`(x, y + 1)`。 分割は、現在どちらの子供も存在しない場合にのみ合法です。 

有限の禁止座標セットが与えられています。 問題は、最終的な生物体にそれらの禁止された細胞がまったく含まれないように、何らかの一連の分裂を実行できるかどうかです。 

この問題が欺瞞的である第一の理由は、プロセス中に同じ座標が複数回出現する可能性があることです。 セルを作成し、分割し、後でもう一方の親から再作成し、再度分割することができます。 The sample itself contains such a situation with`(1, 1)`。 

入力サイズが大きいです。 すべてのテスト ケースにわたって、最大で次のことが考えられます。`10^6`禁断の細胞。 生物をシミュレートしたり、状態を検索したり、無限のグリッドを探索したりするソリューションは、直ちに不可能になります。 線形に近いものが必要です。`O(n log n)`禁止されたセルの数。 

よくある間違った考えは、すべての禁止されたセルを独立して扱うことです。 

考慮する：```
4
0 0
1 0
0 1
1 1
```正しい答えは、`YES`。 

すべての禁止されたセルは分割することができ、レクリエーション間の相互作用によってそれが可能になります。 

もう 1 つの簡単な罠は、すべての有限の禁止領域を囲むことができると仮定することです。 

考慮する：```
16
0 0
0 1
0 2
0 3
1 0
...
3 3
```正しい答えは、`NO`。 

たとえ禁止されたセットが有限であっても、繰り返しのレクリエーションによって生じる組み合わせ圧力により、何らかの禁止されたセルが残されることになります。 

重要な問題は、禁止されたセルを何回再作成する必要があるかを理解することです。 

## アプローチ

 強引なアプローチでは、生物を直接モデル化しようとします。 

状態とは、現在存在するセルのセットです。 私たちは各州のあらゆる法的部門を試し、禁断の生物を探します。 

これはルールに正確に従っているため、原則として正しいです。 問題は、到達可能な状態の数が爆発的に増加することです。 少数の分裂の後でも、すでに膨大な数の異なる生物が存在します。 座標が到達すると`10^9`、状態空間探索は完全に絶望的です。 

この画期的な進歩は、現在の生物体を無視し、代わりに禁止されている各細胞を何回処理する必要があるかをカウントすることによってもたらされます。 

禁じられた細胞は最終的な生物では決して生き残れないと主張するとします。 

その細胞が出現するたびに、最終的には分裂する必要があります。 

させて`cnt(x, y)`禁止されたセルの回数を示します`(x, y)`分割を余儀なくされる。 

セルは 2 つの親からのみ作成できます。```
(x - 1, y)
(x, y - 1)
```したがって、すべての出現`(x, y)`それらの親の一人の分割から来ています。 

これにより、すぐにパスカル三角形の再帰が得られます。 

もし`(x, y)`が禁止されている場合は、すべての出現を前方に転送する必要があるため、次のようになります。```
cnt(x, y)
=
cnt(x - 1, y)
+
cnt(x, y - 1)
```根`(0, 0)`1回の初期出現に貢献します。 

ここで重要な観察が行われます。 

禁止されたセルは、最大 2 回必要であれば安全に削除できます。 

禁止されたセルが 3 回以上強制的に出現すると、レクリエーションを吸収できなくなります。 その時点から、プロセスは必然的に永久に伝播し、すべての禁止されたセルを回避することが不可能になることを意味します。 

したがって、2 を超えると正確な数は必要なくなります。 私たちはそれが 3 に達するかどうかだけを気にします。 

これにより、問題全体が、すべての値の上限が 1 に制限された、禁止されたセル上のパス カウント DP に帰着します。`3`。

 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | 指数 | 遅すぎる |
 | 最適 |`O(n log n)`|`O(n)`| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての禁止されたセルをハッシュ テーブルに保存します。 
2. 禁止されたセルを増加順に並べ替えます。`x + y`。 

これにより、処理時に次のことが保証されます。`(x, y)`、潜在的な親は両方ともすでに処理されています。 
3. しましょう`dp[(x, y)]`禁止されたセルの強制出現回数は次のとおりです。`3`。 
4. のために`(0, 0)`、値で開始します`1`なぜなら、生物には最初からまさにその細胞が含まれているからです。 
5. 禁止されたセルごとに`(x, y)`:

 Compute```
dp(x, y)
=
base
+
dp(x - 1, y)
+
dp(x, y - 1)
```どこ`base = 1`のためだけに`(0, 0)`。 

行方不明の両親が寄付する`0`。 
6. 値を計算した後、次の値に上限を設定します。`3`。 

区別できるのは次のとおりであるため、これより大きな値は必要ありません。```
0, 1, 2, >=3
```重要です。 
7. 禁止されているセルが到達した場合`3`、出力`NO`。 
8. それ以外の場合は出力`YES`。 

### なぜ効果があるのか`dp(x, y)`禁止されたセルを何回数えるか`(x, y)`禁止されたセルをすべて削除しようとすると、強制的に再作成されます。 

すべてのレクリエーションは 2 人の親のうちの 1 人から行われなければならないため、カウントはパスカルの三角形とまったく同じ反復に従います。 

価値観`0`、`1`、 そして`2`管理可能です。 禁止されたセルは、左の親、下の親、または両方から 1 回ずつ再作成できます。 

強制カウントに達すると`3`、プロセスが吸収できる以上に必要なレクリエーションが存在します。 その時点で、圧力は無限に伝播し、すべての禁止された細胞を回避する最終的な生物を得ることが不可能になります。 

したがって、すべての禁止セルが最大でも強制カウントを持っている場合に限り、禁止セットは回避可能です。`2`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    ans = []

    for _ in range(t):
        n = int(input())

        cells = []
        forbidden = set()

        for _ in range(n):
            x, y = map(int, input().split())
            cells.append((x, y))
            forbidden.add((x, y))

        cells.sort(key=lambda p: (p[0] + p[1], p[0]))

        dp = {}
        ok = True

        for x, y in cells:
            cur = 1 if (x, y) == (0, 0) else 0

            cur += dp.get((x - 1, y), 0)
            cur += dp.get((x, y - 1), 0)

            if cur > 3:
                cur = 3

            dp[(x, y)] = cur

            if cur >= 3:
                ok = False
                break

        ans.append("YES" if ok else "NO")

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```この実装では、禁止されたセルの DP 値のみが保存されます。 禁止されていない親の寄与はゼロです。これは、禁止されたセルのみがレクリエーションの転送を強制されるためです。 

並べ替え順`x + y`両親は常に前の対角線上に位置するため、これで十分です。 2 番目の並べ替え基準`x`順序を決定的にするためにのみ使用されます。 

値の上限は次のとおりです`3`すぐに。 これにより、大きな整数が回避され、DP が純粋に論理的に保たれます。 アルゴリズムは、カウントが次のとおりであるかどうかのみを知る必要があります。`0`、`1`、`2`、または少なくとも`3`。 

細胞が到達した瞬間`3`、答えはすでに決まっています。 そのテストケースの処理を早期に停止できます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

 | 時間 |`O(n log n)`| 禁止されたセルの並べ替えが優勢 |
 | スペース |`O(n)`| DP 値のハッシュ テーブル |
