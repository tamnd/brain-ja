 ## 解決策
 ## 問題の理解

 ツリーの各頂点には、最初はちょうど 1 つのアリが含まれています。 

動きはエッジを選択する$(u,v)$そして現在集まっているすべてのアリに命令します$u$に移動する$v$。 アリは、目的地に少なくとも発信元と同じ数のアリがすでに含まれている場合にのみ従います。 移動が発生した場合、グループは$u$が消え、そのアリが追加される$v$。 

問題は、最終的にすべてを集める有効な一連の動きが存在するかどうかです。$n$アリを単一の頂点にまとめます。 

入力は最大のツリーです。$200\,000$頂点。 二次関数または偶数$O(n \sqrt n)$この規模では解決策はすでに危険です。 おそらくソートによる対数係数を使用した、線形時間に近いものが必要です。 

難しいのは、実現可能性はサブツリーのサイズだけによって決まるわけではないということです。 マージの順序は重要です。 ノードは、複数の隣接するコンポーネントが最小のものから最大のものまで処理される場合にはそれらを吸収できる可能性がありますが、大きなコンポーネントをあまりにも早く吸収する必要がある場合には失敗します。 

よくある間違いは、コンポーネントの最終的なサイズだけを見てしまうことです。 考慮する：```
1 - 2 - 3 - 4
```すべてを頂点 2 に集めようとすると、右側のコンポーネントのサイズは 2 になります。頂点 2 は 1 匹のアリだけから始まるため、そのコンポーネントをすぐには吸収できません。 正しい戦略は、最初に頂点 1 を吸収し、頂点 2 のカウントを 2 に増やしてから、サイズ 2 のコンポーネントを吸収することです。 マージ順序を無視したソリューションでは、間違った答えが得られます。 

もう 1 つの微妙なケースはスターです。```
    2
    |
3 - 1 - 4
```答えは`YES`。 すべてのリーフのサイズが 1 であるため、頂点 1 は各リーフを 1 つずつ吸収できます。「中心は既にすべての隣接コンポーネントと少なくとも同じ大きさでなければならない」などの単純なルールでは、このケースは誤って拒否されます。 

最小の入力もチェックする価値があります。```
1
```答えは`YES`、すべてのアリがすでに集まっているためです。 

## アプローチ

 強引なアイデアは、すべての頂点をミーティング ポイントとして試し、可能なすべてのマージ順序を明示的にシミュレートすることです。 固定ルートの場合、隣接するすべてのコンポーネントは内部で収集された後にのみマージできるため、多くの可能な順序を検討する必要があります。 州の数は指数関数的に増加し、ずっと前に完全に実行不可能になります。$n=200000$。 

重要な観察は、コンポーネントが接続頂点に正常に集まった後は、そのサイズという 1 つの数字だけが問題になるということです。 

頂点がサイズのある隣接するコンポーネントを吸収したいと仮定します。$$s_1,s_2,\dots,s_k.$$頂点は 1 匹のアリから始まります。 コンポーネントを昇順で処理すると、その順序は常に最適になります。 より小さな成分を早期に吸収することが唯一の助けになります。 

並べ替えた後、サイズを次のようにします$$s_1 \le s_2 \le \dots \le s_k.$$すべての吸収の前に現在のアリの数が十分に大きい場合、マージは成功します。 

処理前の現在の金額の場合$s_i$は$$1 + \sum_{j<i} s_j,$$それなら必要です$$s_i \le 1 + \sum_{j<i} s_j.$$この条件は、頂点が隣接するすべてのコンポーネントを収集できるかどうかを完全に特徴づけます。 

すべての有向エッジを表示します$u \to v$。 エッジを取り外します。 入っている側$u$コンポーネントです。 有向 DP 状態を定義します。 

コンポーネント全体が次の場所に集まることができる場合、その状態は有効です。$u$。 

の有効性$u \to v$に接続されている隣接コンポーネントの有効性とサイズのみに依存します。$u$を含む側を除く$v$。 

これにより、問題はツリー上の DP の再ルートに変わります。 

残りの課題は、除外される可能性のあるすべての近傍についてソートされたサイズ条件を効率的にチェックすることです。 すべてのエッジを直接再計算すると、二次計算になります。 重要な最適化は、ソートされたリストからいずれか 1 つの近傍を削除した場合の影響を頂点ごとに事前計算することです。

 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | 指数 | 遅すぎる |
 | 最適なリルート DP |$O(n \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 ### コンポーネントのサイズの事前計算

 すべての有向エッジについて、エッジを削除した後のその側のコンポーネントのサイズが必要です。 

頂点 1 でツリーをルートします。 

子供のために$v$の$u$、コンポーネントのサイズ$v \to u$単純に`sub[v]`。 

反対方向の場合$u \to v$、サイズは`n - sub[v]`。 

### サイズからマージの実現可能性を計算する

 ソートされたシーケンスの場合$$b_1 \le b_2 \le \dots \le b_m,$$定義する$$d_i = b_i - \sum_{j<i} b_j.$$マージ条件は次と同等です$$\max_i d_i \le 1.$$これは、各吸収の前にアリの現在の量が十分に多いことが必要なことから直接得られます。 

### 隣接する 1 つを効率的に削除する

 頂点の場合、隣接するコンポーネントのサイズを並べ替えます。 

位置の要素を削除すると$k$、その後のすべてのプレフィックス合計は ずつ減少します$b_k$。 

以降のインデックスの場合$k$、$$d_i' = d_i + b_k.$$オリジナルのプレフィックスとサフィックスの最大値を使用する$d_i$で計算できます$O(1)$特定の近傍を除外した後もマージ条件が有効なままであるかどうか。 

### ボトムアップ DP

 1. ツリーを頂点 1 にルートし、サブツリーのサイズを計算します。 
2. 頂点ごとに、すべてのインシデントコンポーネントのサイズをソートし、事前計算します。 

1. すべての近傍をマージできるかどうか。 
2. 特定のものを除くすべての近傍をマージできるかどうか。 
3. 逆の DFS 順序で頂点を処理します。 
4. しましょう`down[u]`指示された状態の有効性を示す$u \to parent(u)$。 
5.`down[u]`次の場合に true です。 

1. すべての子状態`down[child]`それは本当です。 
2. 親側を除いたサイズ条件を満たします。 

### トップダウンの DP

 1. しましょう`up[u]`の有効性を示します$parent(u) \to u$。 
2. 頂点をルートから下にトラバースします。 
3. 各頂点について、無効な受信有向状態の数を数えます。 
4. 次の場合に頂点を最終集合点にすることができます。 

1. 入力されるすべての状態が有効です。 
2. 隣接するすべてのコンポーネントを使用したサイズ条件は有効です。 
5. 計算するには`up[child]`、その子の受信状態を無効なカウントから除外し、その子の除外に事前計算されたサイズ条件の結果を使用します。 

### なぜ効果があるのか

 すべての有向エッジ状態について、DP は次のステートメントを正確に表します。 

「エッジのこちら側のコンポーネント全体がエンドポイントに集まる可能性があります。」

 コンポーネントは、その頂点にアタッチされているすべての隣接コンポーネントが最初に独自の接続ポイントに集まることができる場合にのみ、頂点に集まることができます。 それはまさに、受信 DP 状態がエンコードするものです。 

隣接するコンポーネントが利用可能になった後は、そのサイズだけが問題になります。 ソートされたサイズの条件は、頂点がそれらをすべて吸収するために必要かつ十分です。 

ボトムアップ パスでは、ルートに向けられたすべての状態が計算されます。 トップダウン パスは、不足している親側の情報を提供します。 両方のパスの後、すべての有向エッジ状態が正しく評価されます。 

頂点は、すべてのインシデント コンポーネントがそこに集まり、すべてを吸収できる場合にこそ、有効な集合点となります。 アルゴリズムはその状態を正確にチェックします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    adj = [[] for _ in range(n + 1)]

    for _ in range(n - 1):
        u, v = map(int, input().split())
        adj[u].append(v)
        adj[v].append(u)

    if n == 1:
        print("YES")
        return

    parent = [0] * (n + 1)
    parent[1] = -1

    order = [1]
    for u in order:
        for v in adj[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            order.append(v)

    sub = [1] * (n + 1)
    for u in reversed(order[1:]):
        sub[parent[u]] += sub[u]

    good_all = [False] * (n + 1)
    good_excl = [dict() for _ in range(n + 1)]

    for u in range(1, n + 1):
        items = []

        for v in adj[u]:
            if parent[v] == u:
                sz = sub[v]
            else:
                sz = n - sub[u]
            items.append((sz, v))

        m = len(items)

        if m == 0:
            good_all[u] = True
            continue

        items.sort()

        b = [x for x, _ in items]

        d = [0] * m
        pref = 0
        for i in range(m):
            d[i] = b[i] - pref
            pref += b[i]

        pref_max = [0] * m
        suff_max = [0] * m

        pref_max[0] = d[0]
        for i in range(1, m):
            pref_max[i] = max(pref_max[i - 1], d[i])

        suff_max[m - 1] = d[m - 1]
        for i in range(m - 2, -1, -1):
            suff_max[i] = max(suff_max[i + 1], d[i])

        good_all[u] = pref_max[-1] <= 1

        for i, (_, v) in enumerate(items):
            left = pref_max[i - 1] if i > 0 else 0
            right = suff_max[i + 1] + b[i] if i + 1 < m else 0
            need = max(left, right)
            good_excl[u][v] = (need <= 1)

    down = [True] * (n + 1)

    for u in reversed(order[1:]):
        ok = True

        for v in adj[u]:
            if parent[v] == u and not down[v]:
                ok = False
                break

        down[u] = ok and good_excl[u][parent[u]]

    up = [True] * (n + 1)

    answer = False

    for u in order:
        invalid = 0

        if parent[u] != -1 and not up[u]:
            invalid += 1

        for v in adj[u]:
            if parent[v] == u and not down[v]:
                invalid += 1

        if invalid == 0 and good_all[u]:
            answer = True

        for v in adj[u]:
            if parent[v] == u:
                invalid_excluding_v = invalid - (0 if down[v] else 1)
                up[v] = (invalid_excluding_v == 0 and good_excl[u][v])

    print("YES" if answer else "NO")

solve()
```最初の DFS は、親関係とサブツリーのサイズを計算します。 これらのサイズによって、すべての有向エッジ コンポーネントのサイズが決まります。 

次のステージでは、各頂点を個別に処理します。 隣接するコンポーネントのサイズを並べ替えた後、$d_i$配列を作成し、完全な近傍セットとすべての除外される近傍の両方に対してマージ条件を事前計算します。 

の`down`DP はルートに向かって有向状態を評価します。 状態は、必要なすべての子状態が有効であり、サイズ条件が成立する場合にのみ有効です。 

の`up`DP は親側から不足している情報を提供します。 すべての子について有効性を最初から再計算するのではなく、事前に計算された除外結果と無効な受信状態の数を使用します。 

この実装では再帰は決して使用されないため、ツリーでの再帰の深さの問題が回避されます。$200000$頂点。

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 |$O(n \log n)$| 各頂点は、入射成分のサイズを 1 回ソートします。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    n = int(input())
    adj = [[] for _ in range(n + 1)]

    for _ in range(n - 1):
        u, v = map(int, input().split())
        adj[u].append(v)
        adj[v].append(u)

    if n == 1:
        return "YES\n"

    parent = [0] * (n + 1)
    parent[1] = -1

    order = [1]
    for u in order:
        for v in adj[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            order.append(v)

    sub = [1] * (n + 1)
    for u in reversed(order[1:]):
        sub[parent[u]] += sub[u]

    good_all = [False] * (n + 1)
    good_excl = [dict() for _ in range(n + 1)]

    for u in range(1, n + 1):
        items = []

        for v in adj[u]:
            if parent[v] == u:
                sz = sub[v]
            else:
                sz = len(parent) - 1 - sub[u]
            items.append((sz, v))

        m = len(items)

        if m == 0:
            good_all[u] = True
            continue

        items.sort()

        b = [x for x, _ in items]

        d = []
        pref = 0
        for s in b:
            d.append(s - pref)
            pref += s

        pm = [0] * m
        sm = [0] * m

        pm[0] = d[0]
        for i in range(1, m):
            pm[i] = max(pm[i - 1], d[i])

        sm[-1] = d[-1]
        for i in range(m - 2, -1, -1):
            sm[i] = max(sm[i + 1], d[i])

        good_all[u] = pm[-1] <= 1

        for i, (_, v) in enumerate(items):
            left = pm[i - 1] if i else 0
            right = sm[i + 1] + b[i] if i + 1 < m else 0
            good_excl[u][v] = max(left, right) <= 1

    down = [True] * (n + 1)

    for u in reversed(order[1:]):
        ok = True
        for v in adj[u]:
            if parent[v] == u and not down[v]:
                ok = False
        down[u] = ok and good_excl[u][parent[u]]

    up = [True] * (n + 1)

    ans = False

    for u in order:
        invalid = 0

        if parent[u] != -1 and not up[u]:
            invalid += 1

        for v in adj[u]:
            if parent[v] == u and not down[v]:
                invalid += 1

        if invalid == 0 and good_all[u]:
            ans = True

        for v in adj[u]:
            if parent[v] == u:
                invalid_ex = invalid - (0 if down[v] else 1)
                up[v] = invalid_ex == 0 and good_excl[u][v]

    return ("YES\n" if ans else "NO\n")
