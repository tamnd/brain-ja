 ## 解決策
 ## 問題の理解

 この問題は線形シーケンスを定義します$f_n$2 つの初期値を持つ$x = f_1$そして$y = f_2$、6 項ごとに繰り返される繰り返し:$f_{n} = f_{n-1} - f_{n-2}$。 これにより、事実上、次のサイクルのシーケンスが作成されます。 

-$f_1 = x$-$f_2 = y$-$f_3 = y - x$-$f_4 = -x$-$f_5 = -y$-$f_6 = x - y$-$f_7 = f_1 = x$- などを 6 タームごとに繰り返します。 

入力は整数を提供します$x$、$y$、 そして$n$、そして計算するように求められます$f_n$モジュロ$10^9 + 7$。 

制約は次のことを示します$x$そして$y$非常に大きくなる可能性があります（最大$\pm 10^9$）、 そして$n$到達できる$2 \times 10^9$。 これは、シーケンスを 1 から 2 まで繰り返し計算することを意味します。$n$何十億もの操作が必要になる可能性があるため、実行不可能です。 したがって、6 項の繰り返しパターンを利用した直接式が必要です。 

微妙な特殊なケースとして、負の数が関係します。 結果をモジュロで返さなければならないため、$10^9 + 7$、負の結果は、対応する正の係数に適切に変換する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、1 から 2 までを繰り返します。$n$再発を利用して$f_n = f_{n-1} - f_{n-2}$各項を計算します。 このアプローチは論理的には正しいですが、大規模な企業にとっては現実的ではありません。$n$、 なぜなら$n$最大 20 億になる可能性があり、数十億の算術演算が行われます。 

重要な洞察は、シーケンスの 6 項の周期的な動作を認識することです。 サイクルが特定されたら、$f_n$剰余を使用して直接計算できます$n \mod 6$。 これにより、次の問題が軽減されます。$O(n)$定数への演算$O(1)$検索と算術。

 ## アルゴリズムのチュートリアル

 1. まず、初期値に基づいて 6 期サイクルを計算します。$x$そして$y$。 順序は$[x, y, y - x, -x, -y, x - y]$。 
2. コンピューティング$n \mod 6$サイクル内の位置を決定します。 シーケンスのインデックスは 1 であるため、1 を減算してインデックスを調整します。$index = (n-1) \mod 6$。 
3. このインデックスに対応するサイクルから値を取得します。 
4. 結果を範囲に変換します$[0, 10^9 + 6]$モジュロ演算を使用します。 数値が負の場合は加算します$10^9 + 7$モジュロを取る前に。 
5. 最終値を返します。 

機能する理由: 数列の反復により、連続する 6 項ごとに正確に繰り返されるため、計算$n \mod 6$サイズの大小に関係なく、正しい用語を提供します$n$は。 負の値をモジュロで処理すると、出力が問題の制約を満たすことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

x, y = map(int, input().split())
n = int(input())

seq = [x, y, y - x, -x, -y, x - y]
result = seq[(n - 1) % 6] % MOD
print(result if result >= 0 else result + MOD)
```このコードはまず、次の入力値を読み取ります。$x$、$y$、 そして$n$。 6期サイクル`seq`が構築され、適切な用語にアクセスできます。`(n - 1) % 6`1 から始まるインデックスを考慮するため。 モジュロ演算により、結果が正しい範囲内に収まることが保証され、負の値が処理されます。 

## 実用的な例

 入力の場合:```
2 3
3
```シーケンスを計算します。`[2, 3, 1, -2, -3, -1]`。 第 3 項 (0 からインデックス: 2) は、`1`。 ここではモジュロ演算は自明なので、出力は次のようになります。`1`。 

入力の場合:```
2 3
8
```サイクル内のインデックス:`(8 - 1) % 6 = 1`。 数列の第 2 項は、`3`。 出力モジュロ$10^9 + 7$は`3`。 

For input with negative result:```
2 3
5
```索引：`(5 - 1) % 6 = 4`。 5期は`-3`。 モジュロ変換:`-3 % (10^9 + 7) = 1000000004`。

## 特殊なケース

 特殊なケースの 1 つは負の数を含みます。 例えば、$x = 2$、$y = 3$、$n = 5$。 第5期は、`-3`。 調整せずに単純なモジュロを使用すると、元に戻る可能性があります`-3`ですが、正しい出力は次のとおりです。`1000000004`。 私たちの実装では追加します$MOD$結果が負の場合、これを正しく処理します。 

もう 1 つのエッジケースは次のような場合です$n$非常に大きいです、例えば$n = 2 \times 10^9$。 反復的に計算することは不可能です。 モジュロを使用したサイクルベースのルックアップを使用すると、一定時間に短縮されます。 

3 番目のエッジケースは次のような場合です。$n = 1$または$n = 2$。 これらは初期値に直接対応します$x$そして$y$。 モジュロインデックス作成`(n-1) % 6`off-by-one エラーなしで、最初または 2 番目の要素を正しく返します。
