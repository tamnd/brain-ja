 ## 解決策
 ## 問題の理解

 平面内の直線の集合が与えられ、それぞれは次の形式の方程式で記述されます。$y = a_i x + b_i$。 このタスクは、順序のない個別の線のペアが正確に 1 点で交差する数を数えることです。 

幾何学的には、2 本の線は平行でなくても交差します。 傾きと切片の形式の線の場合、平行度は傾きが等しいとき、つまり次のときに発生します。$a_i = a_j$。 この問題では、明らかにもう 1 つの詳細が追加されます。2 つの直線が同一である場合、つまり傾きと切片の両方が一致する場合、それらは交差するペアとみなされるべきではありません。 

したがって、出力は基本的にペアの数になります。$(i, j)$と$i < j$線が平行でなく、同一でもありません。 

制約は次のとおりです。$n \le 5 \cdot 10^3$。 これは十分小さいので、$O(n^2)$アプローチは受け入れられます。 負荷の高い計算で各ペアをチェックしたり、入れ子になったループ内でソートを使用したりするなど、2 次式よりも悪い試みはタイムアウトになる危険性があります。 線形または$n \log n$このアプローチは厳密には必要ではありませんが、クリーンな組み合わせ計数ソリューションが期待されています。 

同一の行が複数存在する場合、微妙なケースが発生します。 たとえば、入力に次のものが含まれているとします。```
1 1
1 1
1 1
```3 つの線はすべて正確に重なっています。 単純に「平行でないペア」を数えると 3 つのペアすべてが数えられることになりますが、それらのどれも交差していると見なすべきではありません。 同一行は除外されるので正解は0です。 

もう 1 つのエッジ ケースは、多くのラインが同じ傾きを共有しているが、切片が異なる場合です。```
2 0
2 1
2 2
```これらはすべて平行ですが別個であるため、交差するペアはなく、答えは 0 になります。 

## アプローチ

 問題を解決する最も直接的な方法は、すべての線のペアを検討し、それらが交差するかどうかを確認することです。 2行$y = a_i x + b_i$そして$y = a_j x + b_j$その場合にのみ交差する$a_i \ne a_j$。 傾きが等しい場合、それらが同一でない限り、傾きが一致することはなく、いずれにせよ、同一の線は明示的に除外されます。 

これにより、すべてのペアを反復処理するという単純な総当たりソリューションが得られます。$(i, j)$、どうかを確認してください$a_i \ne a_j$、そしてそれらを数えます。 平面内の非平行な線の各ペアは 1 回だけ交差するため、これは正しいです。 

ただし、このアプローチのパフォーマンスは、$\frac{n(n-1)}{2}$これは、最悪の場合で約 1,250 万回の操作になります。$n = 5000$。 これはすでに境界線に達していますが、最小限に抑えれば Python ではまだ許容されます。 それでも、ペアごとのチェックから除外されるペアの数をカウントすることに移行することで、さらに単純化できます。 

交差するペアを直接カウントする代わりに、すべてのペアをカウントし、交差しないペアを差し引きます。 交差しないペアは、まさに等しい傾きを持つ線のペアです。 スロープ値が表示された場合$k$回であれば貢献します$\frac{k(k-1)}{2}$交差しないペア。 残る唯一の問題は同一のラインですが、同一のラインはすでに傾斜グループ内に含まれており、すべての等しい傾斜のペアを減算すると、この問題定義に必要な平行と重複の両方の寄与が正しく除去されます。これは、いずれにせよ重複が交差に寄与することはないためです。 

したがって、問題は、傾きによってラインをグループ化し、各グループ内の組み合わせを合計することに帰着します。 

## アルゴリズムのチュートリアル

 1. すべてのラインを読み取り、傾きごとにグループ化します。$a_i$、各坂が何回出現するかを保存します。 切片は線が交差するかどうかには影響しないため、カウントのみが必要です。 
2. 次を使用して、すべての行間の順序のないペアの合計数を計算します。$\frac{n(n-1)}{2}$。 これは、平行な線がない場合に考えられる交差の最大数を表します。 
3. サイズのある各斜面グループについて$k$、交差できないペアの数を計算します。これは、$\frac{k(k-1)}{2}$。 これを合計から引きます。 
4. 結果の値を出力します。 

ステップ 3 が有効である理由は、傾きが等しい線のペアは決して交差しないため、完全なペアのセットからすべての無効なペアを正確に削除しているためです。 

### なぜ効果があるのか

 すべての線のペアは、傾きが異なるか、または傾きが等しいという 2 つのカテゴリのいずれかに正確に分類されます。 傾きが異なる場合、線は 1 回だけ交差します。 傾きが等しい場合、直線は平行であり、切片に関係なく、同一直線の縮退の場合も含めて交差することはありません。 したがって、すべてのペアを数えて同じ傾きのペアを減算すると、交差するペアが正確に分離されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from collections import defaultdict

def solve():
    n = int(input())
    cnt = defaultdict(int)

    for _ in range(n):
        a, b = map(int, input().split())
        cnt[a] += 1

    total = n * (n - 1) // 2
    bad = 0

    for k in cnt.values():
        bad += k * (k - 1) // 2

    print(total - bad)

if __name__ == "__main__":
    solve()
```コードは傾きだけで線をグループ化します。切片は交差点の存在に影響を与えないため、これで十分です。 ペアの合計数が一度計算され、その後、各勾配グループが補正項に寄与して、平行なすべてのペアを削除します。 

よくある間違いは、すべてのペアを明示的にチェックしようとすることですが、これは不必要です。 もう 1 つの間違いは、同一の直線と平行な直線を別々に扱うことですが、当然両方とも同じ傾斜グループ内で処理されます。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import defaultdict

    n = int(sys.stdin.readline())
    cnt = defaultdict(int)

    for _ in range(n):
        a, b = map(int, sys.stdin.readline().split())
        cnt[a] += 1

    total = n * (n - 1) // 2
    bad = 0
    for k in cnt.values():
        bad += k * (k - 1) // 2

    return str(total - bad)

 ## 特殊なケース

 次のような単一行の場合:```
1
10 20
```傾斜マップには、カウント 1 のエントリが 1 つだけ含まれています。ペアの合計数は 0 で、減算は行われないため、結果は正しく 0 になります。 

完全に同一の行の場合:```
3
1 1
1 1
1 1
```勾配グループは {1:3} です。 ペアの合計は 3 で、グループ内の不良ペアも 3 で、最終的な答えは 0 になります。これにより、重複する線が交差しているとカウントされることが正しく回避されます。 

多くの平行だが別個の線の場合:```
4
2 0
2 1
2 2
2 3
```勾配グループは {2:4} です。 合計のペアは 6、悪いペアは 6、最終的な答えは 0 で、平行線間に交差が存在しないことを正しく反映しています。
