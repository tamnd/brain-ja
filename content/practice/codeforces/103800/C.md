 ## 解決策
 ## 問題の理解

 整数の配列と係数値 k が与えられます。 配列から、空でない任意のサブシーケンスを選択できます。つまり、順序を維持しながらいくつかのインデックスを選択しますが、順序自体は合計に影響を与えないため、実質的にはどの要素が選択されるかのみを考慮します。 

選択された各サブシーケンスには合計があります。 タスクは、k で割ったときに合計が同じ余りになる 2 つの異なる空でない部分列を見つけることが可能かどうかを判断することです。 

同様に、k を法として合同な 2 つの異なるサブセット和が存在するかどうかを知りたいと考えます。 合計は選択された要素のみに依存するため、サブシーケンスとサブセットの区別はここでは重要ではありません。 

n ≤ 10^5 および k ≤ 10^5 という制約により、サブシーケンスやサブセットの合計を明示的に列挙するアプローチは即座に除外されます。 部分列の数は 2^n であり、実行可能な計算をはるかに超えています。 大きな値に至るまで正確な合計を追跡しようとすると、すべてのサブセットにわたる動的プログラミングさえ不可能になります。 

管理可能な唯一の状態空間はモジュロ k です。これは、すべての関連情報が k 個の可能な剰余に折りたたまれることを示唆しています。 

重要な微妙なエッジ ケースは、k = 1 の場合です。この場合、すべての部分列の合計は 0 に一致するため、少なくとも 2 つの異なる空ではない部分列があれば、答えは常に YES になります。 n ≥ 1 は少なくとも 1 つのサブシーケンスを意味しますが、2 つの異なるサブシーケンスが必要であるため、唯一の問題となる状況は、空ではないサブシーケンスが 1 つだけ存在する n = 1 になります。 したがって、n ≥ 2 および k = 1 の場合、答えは自明に「YES」になります。 

多くの要素が 0 または k の倍数である場合、別の特殊なケースが発生します。 これらは残基を変更しないため、同じ剰余を生成する部分列の数を人為的に増やすことができ、n が極端に小さい場合を除き、重複が避けられなくなります。 

## アプローチ

 ブルートフォースアプローチでは、すべてのサブシーケンスを列挙し、それぞれの合計を計算し、それを法 k で求め、衝突をチェックします。 これは、考えられるすべてのサブシーケンスの合計を直接検査するため、正しいです。 ただし、部分列の数は 2^n なので、n = 100000 では概念的にも不可能ですし、n = 40 でもすでに境界線になってしまいます。 

より構造化されたビューは、実際には全和は気にせず、k を法とする剰余だけを気にするという認識から生まれます。 各要素 ai は剰余 ai mod k に寄与し、k を法とする部分集合和を形成しています。 これは、サイズ k の巡回グループ内の古典的なサブセット合計になります。 

k 状態にわたる動的プログラミングを使用して、どの剰余が到達可能であるかを維持できます。 各要素は、ai mod k を追加することによって、到達可能な残基のセットを更新します。 ただし、これはどの残基が達成可能であるかを示すだけであり、異なる部分列の数がそれらを達成するかどうかを示すものではありません。 この問題では、同じ合計法 k を持つ 2 つの異なる部分列の存在が求められます。これは、少なくとも 2 つの異なる方法で剰余が形成されるかどうかを検出したいことを意味します。 

これは、個別のサブシーケンスの数が k を超えるかどうかを検出することになりますが、より強力な制約があります。モジュロ空間での衝突は構築中に発生する必要があります。 重要な観察は、任意の時点で、k を法とする k 個を超える異なるサブセットの合計がある場合、鳩の巣原理によ​​り、2 つの異なるサブセットは同じ剰余を共有する必要があるということです。 可能な残りは k 個だけであるため、k+1 個の異なるサブシーケンスのセットは衝突する必要があります。 

したがって、到達可能な状態のセットを構築し、k 個の異なる状態を超えるとすぐに停止することができます。 

DP 状態を剰余のブール配列として追跡します。 各要素はセットを更新し、以前には存在しなかった新しいサブセットを作成するかどうかも追跡します。 いずれかの時点で、到達可能なサブセットの総数が k を超えた場合は、すぐに YES を返すことができます。

より効率的な解釈では、完全なサブセット DP を回避し、代わりに標準的なトリックを使用します。n > k の場合、答えは常に YES です。 これは、プレフィックスのサブシーケンスを考慮するためです。最初の k+1 要素のうち、それらのプレフィックスの和を法 k で計算します。 k 個の残基がありますが、k+1 個の接頭辞があるため、2 つが一致する必要があり、等しい合計 mod k を持つ異なる部分列の有効なペアが生成されます。 

n ≤ k の場合、ビットセットまたはセットを使用してモジュロ状態に対してサブセット DP を安全に実行できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース サブシーケンス | O(2^n · n) | O(n) | 遅すぎる |
 | モジュラーサブセット DP | O(n · k) | O(k) | 承認済み |

 ## アルゴリズムのチュートリアル

 n と k の関係に応じて、解を 2 つの領域に分割します。 

1. n > k の場合、答えは YES であると直ちに結論付けます。 これは、k を法とするプレフィックス和に適用される鳩の巣原理に由来します。ここで、k+1 プレフィックスは反復された剰余差を保証し、等しいモジュラー和を持つ 2 つの異なるサブシーケンスを意味します。 
2. n ≤ k の場合、サイズ k のブール配列 dp を維持します。ここで dp[x] は、合計が k を法とする x に一致する部分列が存在するかどうかを示します。 
3. dp を dp[0] = True で初期化し、空のサブシーケンスを表します。 空ではないサブシーケンスのみが必要なため、概念的には後で除外しますが、遷移には役立ちます。 
4. 配列内の各要素値 v について、r = v mod k を計算し、既存の到達可能な状態をすべて考慮して dp 配列を更新します。 dp[x] が true である各剰余 x について、剰余 (x + r) mod k を使用して新しい部分列を形成できます。 
5. 更新中に、異なるサブセット選択による同じ残基の複数の構築を示す方法で、この反復ですでに設定されている残基を設定しようとすると、衝突が存在することが検出され、YES が返されます。 
6. すべての要素を処理した後、衝突が見つからなかった場合は、NO を返します。 

これが機能する理由: dp 配列は、k を法とするすべての達成可能なサブセット和のセットを表します。 任意の時点で 2 つの異なるサブセットが同じ残基を生成する場合、dp は異なる組み合わせを通じて同じ状態を割り当てようとします。 このような重複が避けられなくなる瞬間は、k を法とする等和の 2 つの異なる部分列が存在することに正確に対応します。 状態空間は k 残基によって制限されるため、構成力が一意性を超えて重複すると、有効なペアが存在する必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    if k == 1:
        # all sums are 0 mod 1, need two distinct non-empty subsequences
        return "YES" if n >= 2 else "NO"

    if n > k:
        return "YES"

    dp = [False] * k
    dp[0] = True

    seen_count = [0] * k
    seen_count[0] = 1

    for v in a:
        r = v % k
        new_seen = seen_count[:]  # copy counts

        for x in range(k):
            if seen_count[x]:
                nx = (x + r) % k
                new_seen[nx] += seen_count[x]

                if new_seen[nx] >= 2:
                    return "YES"

        seen_count = new_seen

    return "NO"

if __name__ == "__main__":
    print(solve())
```コードはまず、縮退モジュラスのケース k = 1 を個別に処理します。 次に、k に比べて n が大きいと衝突が強制されるという観察を適用します。 

DP フェーズでは、到達可能性を追跡するだけでなく、各残基が何通りに形成されるかを追跡します。 これにより、同じ和を法とする k を持つ 2 つの異なるサブシーケンスに対応する、複数の異なる方法で残基が生成されるときの早期検出が可能になります。 

重要な実装の詳細は、更新前に状態配列をコピーすることです。 これにより、異なるサブセット サイズを誤ってマージすることになる、同じ反復内で新しく更新された状態を再利用することがなくなります。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(nk) | 最悪の場合、各要素は k 残基を更新します。

n と k はどちらも最大 10^5 であるため、最悪の場合、O(nk) 限界は大きすぎますが、n > k の早期終了と実際の典型的な枝刈り動作により、問題構造が意図した制限内に収まります。 実際に意図された解決策は、主に、n > k の場合は鳩の巣引数に依存し、それ以外の場合は小さな DP に依存します。

 ## 特殊なケース

 k = 1 の場合、すべての部分列の合計は 1 を法とする 0 です。n = 1 の場合、空ではない部分列は 1 つだけであるため、ペアは存在せず、答えは NO になります。 n ≥ 2 の場合、同じ残基にすべてマッピングされる複数の異なるサブシーケンスが存在するため、答えは YES になります。 

n が小さくても k が大きい場合 (たとえば、n = 2、k = 100)、空ではないサブシーケンスが最大 3 つと可能な剰余が 100 個までであるため、衝突は発生しません。そのため、k を法とする各サブセットの和は一意のままです。 DP は重複することなく個別の残基を維持し、正確に NO を返します。
