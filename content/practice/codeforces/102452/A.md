 ## 解決策
 ## 問題の理解

 内部が決して重ならない、軸に沿って整列した長方形のコレクションがあります。 長方形はエッジに沿って、または点で接触する場合があるため、最終的な図形は 1 つの接続された形状、複数の切断された形状、または穴のある形状になる可能性があります。 

すべてのテスト ケースで、図全体がリフレクションによって変更されないすべての線を見つけなければなりません。 各行は次のように出力する必要があります

 [
 ax+by=c、
 ]

 3 つの係数は最大公約数 (1) を持ちます。 複数の軸が存在する場合は、それらの正規化された係数トリプルを辞書編集上の降順で出力する必要があります。これは、辞書編集上で最大の連結された答えが得られるためです。 公式の制限は (2) 秒と (512) MB で、すべてのテスト ケースの合計で最大 (10^5) 個の四角形が含まれます。 

座標範囲が広いということは、グリッドを構築したり、個々の単位セルを検査したりすべきではないという手がかりになります。 座標は (10^8) 程度になる可能性がありますが、(10^5) 個の長方形も存在する可能性があるため、座標の大きさに比例するものは不可能です。 (10^5) 個の長方形と 2 秒の制限を使用すると、(O(n^2)) 個の幾何学的比較では、定数係数を考慮する前に、約 (10^{10}) 個のペア チェックが実行されます。 各四角形が一定の作業のみに寄与し、テスト ケース全体がおおよそ (O(n\log n)) 以上で処理される表現が必要です。 

最初の微妙なケースは、長方形が接触する可能性があることです。 例えば、```
1
2
0 0 2 1
1 1 2 2
```L字型の図形を形成します。 点 ((1,1)) は、最初の長方形の角ではありませんが、和集合の角になります。 1 つの長方形の角だけを個別に保存する方法では、このような境界の曲がりを見逃す可能性があります。 正しい答えは対称性がないことであり、以下の解決策はすべての長方形の角のパリティを通じて接触点を処理します。 

もう 1 つの微妙なケースは、中心が半整数の座標を持つ長方形です。 のために```
1
1
0 0 1 1
```4 つの対称軸は```
4
2 0 1 1 1 1 1 -1 0 0 2 1
```縦軸は (x=\frac12) なので、その基本的な整数方程式は浮動小数点演算で書かれた (x=1/2) ではなく (2x=1) になります。 2 倍の座標を使用すると、あらゆる小数計算が回避されます。 

3 番目のケースは、エッジ全体に沿って接触するいくつかの長方形です。 例えば、```
1
2
0 0 1 1
1 0 2 1
```は単なる (2\times1) 長方形です。 その答えは、```
2
1 0 1 0 2 1
```すべての四角形の境界を最終境界の一部として扱う不注意な実装では、共有エッジが境界セグメントとして誤って認識されてしまいます。 

最後に、図には複数の対称性があり、要求された順序が重要になります。 上記の単位正方形の場合、正規化されたトリプルは ((2,0,1))、((1,1,1))、((1,-1,0))、および ((0,2,1)) です。 辞書編集上の降順に並べ替えることは、単なる表示方法の選択ではなく、必要な出力の一部です。 

## アプローチ

 直接的な幾何学的なアプローチでは、最初にすべての長方形のすべての境界セグメントが構築されます。 元のセグメントは最大で (4n) 個あります。 考えられる対称軸ごとに、すべての境界セグメントを他のすべてのセグメントと比較し、反射が一方から他方にマッピングされているかどうかを確認できます。 これは正しいです。ポリゴンの境界はそのセグメントによって完全に決定されますが、(O(n)) 個のセグメントと (O(n)) 個の他のセグメントを比較すると (O(n^2)) のコストがかかります。 (n=10^5) の場合、このようなチェックが 1 つだけでも約 (1.6\times10^{11}) 個のセグメント比較に達する可能性があり、制限時間を大幅に超えます。 

重要な観察は、対称軸の方向が非常に制限されていることです。 図形のすべての境界セグメントは水平または垂直です。 対称軸を横切る反射では、水平または垂直セグメントを別の水平または垂直セグメントにマッピングする必要があります。 縦軸や横軸には明らかにこの性質があります。 斜めの軸の場合、水平方向と垂直方向を交換できる唯一の方法は (45^\circ) であり、傾き (1) と (-1) を持つ 2 つの対角方向が得​​られます。 したがって、軸には最大で 4 つの方向が考えられます。 

各候補の位置も境界ボックスによって強制されます。 反射では、図全体の最小 (x) 座標と最大 (x) 座標が保存されるため、垂直対称軸はこれら 2 つの座標の中点である必要があります。 同じ引数で水平軸を固定します。 対角対称では境界ボックスも維持する必要があるため、境界ボックスの中心を通過する必要があります。 したがって、候補行は 4 つだけです。 

候補者が本当に図全体を保存しているかどうかをテストするコンパクトな方法がまだ必要です。 有益な観察は、長方形とコーナーのパリティです。 すべての点で、(2) を法として、そこに長方形の角がいくつあるかを数えます。 奇数パリティを持つ点はまさに境界の転換点です。 いくつかの長方形が接触すると、それらの境界からの寄与が共有部分に沿ってペアで相殺され、境界が方向を変える場所で正確にパリティが維持されます。 これは、公式コンテスト ソリューションの境界議論で使用されているのと同じパリティのアイデアです。 

すべての奇数パリティ コーナーが判明すると、軸のテストがセット メンバーシップの問題になります。 候補軸を横切るすべての奇数コーナーを反射し、反射された点が別の奇数コーナーであることを要求します。 すべての奇数コーナーにパートナーがある場合、連続する転換点によってそれらの間の軸に沿った境界セグメントが決定されるため、境界全体が保存されます。 逆に、本物の対称性はすべての境界ターンを別の境界ターンにマッピングする必要があるため、このテストに誤って合格することはできません。 

実装の詳細がもう 1 つあります。 他のことをする前に、すべての座標を 2 倍にします。 元の境界ボックスに 2 倍の極値 (X_{\min},X_{\max},Y_{\min},Y_{\max}) がある場合、次のように定義します。 

[
 d_x=X_{\min}+X_{\max}、\qquad d_y=Y_{\min}+Y_{\max}。 
]

 これらは中心座標の 2 倍です。 この場合、鏡映式には整数の加算と減算のみが含まれます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(n^2)) | (O(n)) | 遅すぎる |
 | 最適 | (O(n)) が期待されます | (O(n)) | 承認済み |

 ハッシュセットの実装には (O(n)) 時間がかかります。 バランスツリー実装では、公式社説で述べられている (O(n\log n)) 限界が与えられます。 

## アルゴリズムのチュートリアル

1. すべての長方形を読み取り、4 つの座標すべてに (2) を掛けます。 二重化された 4 つのコーナーをパリティ セットに挿入します。 角がすでに存在する場合は、それを削除します。 それ以外の場合は挿入します。 同時に、最小値と最大値の 2 倍の (x) 座標と (y) 座標を維持します。 

2 つの長方形は境界部分を共有できるため、パリティ演算が重要になります。 共有貢献は 2 回発生してキャンセルされますが、真の境界ターンは奇数の頻度で発生します。 
2. コンピューティング

 [
 d_x=X_{\min}+X_{\max}、\qquad d_y=Y_{\min}+Y_{\max}。 
]

 境界ボックスの実際の中心は ((d_x/2,d_y/2)) です。 (d_x,d_y) を整数として維持すると、すべての反射が整数のままになります。 
3. 水平候補をテストします。 水平方向の中心を横切る 2 倍の点 ((x,y)) の反射は次のようになります。 

[
 (x,,2d_y-y)。 
]

 (d_y) はすでに中心の 2 倍を表しているため、2 倍の座標系での正しい式は次のようになります。 

[
 (x,,2d_y-y)。 
]

 元の座標での候補線は(2y=d_y)です。 
4. 垂直候補をテストします。 反射というのは

 [
 (2d_x-x,,y),
 ]

 対応する行は (2x=d_x) です。 
5. 傾斜を使用して対角線をテストします (1)。 方向 ((1,1)) で境界ボックスの中心を通るラインを横切る反射により、中心の座標が交換されます。 

[
 (x,y)\マップスト
 (d_x+(y-d_y),,d_y+(x-d_x))。 
]

 元の座標での方程式は次のとおりです。 

[
 2x-2y=d_x-d_y。 
]
 6. 傾き (-1) を使用して対角線をテストします。 反省は、

 [
 (x,y)\マップスト
 (d_x-(y-d_y),,d_y-(x-d_x)),
 ]

 に対応する

 [
 2x+2y=d_x+d_y。 
]
 7. 候補ごとに、パリティ セット内のすべての点を反復処理します。 反射点が存在しない場合は、その候補を拒否します。 それ以外の場合は、チェックを続けてください。 候補は、すべての奇数境界ターンに対応する反映されたターンがある場合にのみ受け入れられます。 

境界上の任意の点をチェックする必要はありません。 2 つの連続するターンの間の境界は、水平または垂直の直線セグメントであり、反射によって端点が反射されたセグメントの端点にマップされます。 したがって、すべてのターンを一致させるだけで、境界全体を一致させるのに十分です。 
8. 受け入れられた各行をプリミティブ整数係数に変換します。 3 つの係数すべてを最大公約数で割ります。 次に、最初の非ゼロ係数が負の場合は、トリプル全体に (-1) を乗算します。 これにより、幾何学的な線ごとに 1 つの正規表現が得られます。 
9. 結果のトリプルを辞書編集上の降順に並べ替えて出力します。 すべてのトリプルには正確に 3 つのエントリがあるため、トリプルの辞書編集上の降順は、連結された出力が辞書編集上最大になるために必要な順序とまったく同じです。 

### なぜ効果があるのか

 不変条件は、パリティ セットに結合の境界の転換点が正確に含まれていることです。 鏡映対称は境界ターンを境界ターンにマッピングする必要があるため、すべての真の対称は点反射テストに合格します。 逆に、すべての境界ターンが 4 つの可能な反射の 1 つで別の境界ターンにマップされる場合、連続するターンの各ペア間の軸が整列したセグメントは、対応する境界セグメントにマップされます。 したがって、完全な境界が保存されます。 反射は境界領域を境界領域にマップするため、境界を保存すると図形自体が保存されます。 

軸に揃えられた長方形の境界には水平セグメントと垂直セグメントのみが含まれるため、4 つの候補方向は網羅的です。 これらの方向を維持する反射は、水平または垂直のいずれか、または水平と垂直を交換して、傾き (1) と (-1) を与えます。 それらの位置は境界ボックスによって強制されます。 したがって、可能な対称性は省略されません。 

## Python ソリューション```python
import sys
from math import gcd

input = sys.stdin.readline

def primitive(a, b, c):
    g = gcd(abs(a), gcd(abs(b), abs(c)))
    a //= g
    b //= g
    c //= g

    if a < 0 or (a == 0 and b < 0):
        a = -a
        b = -b
        c = -c

    return (a, b, c)

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())

        corners = set()

        min_x = 10**30
        max_x = -10**30
        min_y = 10**30
        max_y = -10**30

        for _ in range(n):
            x1, y1, x2, y2 = map(int, input().split())

            x1 *= 2
            y1 *= 2
            x2 *= 2
            y2 *= 2

            for p in ((x1, y1), (x1, y2), (x2, y1), (x2, y2)):
                if p in corners:
                    corners.remove(p)
                else:
                    corners.add(p)

            min_x = min(min_x, x1)
            max_x = max(max_x, x2)
            min_y = min(min_y, y1)
            max_y = max(max_y, y2)

        dx = min_x + max_x
        dy = min_y + max_y

        ok = [True, True, True, True]

        for x, y in corners:
            if ok[0]:
                p = (x, 2 * dy - y)
                if p not in corners:
                    ok[0] = False

            if ok[1]:
                p = (2 * dx - x, y)
                if p not in corners:
                    ok[1] = False

            if ok[2]:
                p = (dx + y - dy, dy + x - dx)
                if p not in corners:
                    ok[2] = False

            if ok[3]:
                p = (dx - y + dy, dy - x + dx)
                if p not in corners:
                    ok[3] = False

            if not any(ok):
                break

        ans = []

        if ok[0]:
            ans.append(primitive(0, 2, dy))

        if ok[1]:
            ans.append(primitive(2, 0, dx))

        if ok[2]:
            ans.append(primitive(2, -2, dx - dy))

        if ok[3]:
            ans.append(primitive(2, 2, dx + dy))

        ans.sort(reverse=True)

        out.append(str(len(ans)))
        out.append(" ".join(str(v) for triple in ans for v in triple))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```の`corners`set は奇数の出現のみを保存します。 四角形の角ごとにメンバーシップの切り替えはまさに XOR 演算となるため、2 回出現する点は消え、奇数回出現する点は残ります。 

境界値は、座標を 2 倍にした後も維持されます。 これが、候補方程式を整数のトリプルとして直接構築できる理由です。 たとえば、実際の縦軸が (x=3.5) の場合、`dx`は (7) であり、候補は (2x=7) です。 

4 つの反射公式は 2 倍の座標で直接記述されます。 水平候補の場合、高さの 2 倍の点`y`反射高さあり`2 * dy - y`。 他の 3 つの式は、同じ中心座標変換に従います。 

の`ok`配列を使用すると、すでに反証された候補者がハッシュ検索の実行をやめることができます。 これは小さな定数係数の最適化ですが、生き残った各候補がすべての境界ターンをチェックするため便利です。 

の`primitive`関数はまず、完全な 3 つの数値 gcd で除算します。 符号規則では最初の非ゼロ係数が使用されるため、(x-y=0) や (-x+y=0) などの式は 1 つの表現を受け取ります。 Python の整数では、固定幅の実装で発生するオーバーフローの問題も回避されますが、ここでの値は 64 ビットの範囲内に収まります。 

決勝戦`reverse=True`並べ替えは意図的です。 この問題では、辞書編集上最大の平坦化シーケンスが求められるため、最大の係数トリプルが最初に来て、次に最大の係数トリプルが来る、という順番になります。

| ステップ | キーの状態 | 結果 |

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | (O(n)) が期待されます | 四角形ごとに 4 つの角が処理され、奇数の角ごとに最大 4 つのハッシュ ルックアップが実行されます。 
| スペース | (O(n)) | 最大 (4n) 個のコーナー位置が保存されます。 

すべてのテスト ケースにわたる四角形の合計数は最大 (10^5) であるため、予想されるハッシュ演算の合計数も (10^5) で線形になります。 座標の大きさに依存する構造はありません。座標は (10^8) 程度になる可能性があるため、これは重要です。 したがって、このアプローチは公式の 2 秒、512 MB 制限に適合します。

        return a, b, c

    for _ in range(t):
        n = int(next(it))
        corners = set()

        min_x = 10**30
        max_x = -10**30
        min_y = 10**30
        max_y = -10**30

        for _ in range(n):
            x1 = int(next(it))
            y1 = int(next(it))
            x2 = int(next(it))
            y2 = int(next(it))

            x1 *= 2
            y1 *= 2
            x2 *= 2
            y2 *= 2

            for p in ((x1, y1), (x1, y2), (x2, y1), (x2, y2)):
                if p in corners:
                    corners.remove(p)
                else:
                    corners.add(p)

            min_x = min(min_x, x1)
            max_x = max(max_x, x2)
            min_y = min(min_y, y1)
            max_y = max(max_y, y2)

        dx = min_x + max_x
        dy = min_y + max_y

        ok = [True] * 4

        for x, y in corners:
            if ok[0] and (x, 2 * dy - y) not in corners:
                ok[0] = False

            if ok[1] and (2 * dx - x, y) not in corners:
                ok[1] = False

            if ok[2] and (dx + y - dy, dy + x - dx) not in corners:
                ok[2] = False

            if ok[3] and (dx - y + dy, dy - x + dx) not in corners:
                ok[3] = False

        ans = []

        if ok[0]:
            ans.append(primitive(0, 2, dy))
        if ok[1]:
            ans.append(primitive(2, 0, dx))
        if ok[2]:
            ans.append(primitive(2, -2, dx - dy))
        if ok[3]:
            ans.append(primitive(2, 2, dx + dy))

        ans.sort(reverse=True)

        out.append(str(len(ans)))
        out.append(" ".join(str(v) for a in ans for v in a))

    return "\n".join(out) + "\n"

 ## 特殊なケース

 ### 単一の長方形

 のために```
1
1
0 0 2 1
```境界ボックスの中心は ((1,\frac12)) です。 水平方向の反射では長方形が維持され (2y=1)、垂直方向の反射では (x=1) が得られます。 長方形が正方形ではないため、対角線の候補は失敗します。 正規化と辞書編集後の出力は次のようになります。```
2
1 0 1 0 2 1
```このアルゴリズムは、すべての四角形に 4 つの対称性があるとは決して想定しません。 

### エッジに沿って接触する長方形

 のために```
1
2
0 0 1 1
1 0 2 1
```2 つの長方形はセグメント (x=1,0\le y\le1) を共有します。 共有セグメントの各エンドポイントは長方形の角として 2 回出現するため、パリティ セットから削除されます。 共有セグメント自体は外部境界の一部ではありません。 残りの境界は正確に (2\times1) 長方形の境界であるため、残る 2 つの軸は (x=1) と (y=\frac12) になります。 

これが、すべての入力四角形の境界を個別に扱うことが間違っている理由ですが、コーナー パリティにより内部寄与が自然に除去されます。 

### 一点で接触する長方形

 のために```
1
2
-1 -1 0 0
0 0 1 1
```共通点 ((0,0)) は両方の長方形によって提供され、パリティ セットからは消えます。 残りの境界ターンは、共通点を通る両方の対角線の周りで対称です。 受け入れられる 2 行は次のとおりです。 

[
 x+y=0
 ]

 そして

 [
 x-y=0。 
]

 プリミティブ トリプルは ((1,1,0)) と ((1,-1,0)) で、最初のトリプルが辞書編集的に大きいため、最初に出力されます。 

### 半整数の対称中心

 のために```
1
1
0 0 1 1
```中心は ((\frac12,\frac12)) です。 座標を 2 倍にすると、`dx = 1`そして`dy = 1`, そのため、縦軸は (2x=1) として直接表され、横軸は (2y=1) として表されます。 浮動小数点の中点は計算されません。 

これは、反射公式が整数軸位置と半整数軸位置の両方で均一に機能する理由でもあります。 

### 大きな負の係数

 検討してください```
1
1
-100000007 100000006 -100000006 100000007
```縦軸は

 [
 x=-100000006.5、
 ]

 したがって、その原始方程式は

 [
 2x=-200000013。 
]

 正規化ルーチンは、盲目的に定数を正にすることを強制してはなりません。 符号規則は最初の非ゼロ係数に基づいており、これにより表現が一意に保たれ、次のような結果が得られます。`(2, 0, -200000013)`。 

### 対称性がない

 最初の公式サンプルには、4 つの可能な反射のいずれも境界を維持しないように配置された 2 つの長方形が含まれています。 アルゴリズムは依然として同じ境界ボックスから 4 つの候補すべてを計算し、不足している反射ターンを見つけた後にそれぞれを拒否します。 結果は単純に```
0
```外側の境界には必然的にターンが含まれるため、空のパリティ セット テストは有効な空でない Figure の特別なケースではありません。 したがって、アルゴリズムはすべての入力に対して同じリフレクション テストを使用できます。 

### 複数の接続コンポーネント

 長方形は 1 つの連結コンポーネントを形成する必要はありません。 パリティ セットには、すべてのコンポーネントの境界ターンが含まれているだけです。 対称性はすべてのコンポーネントを正しく反映する必要があるため、完全なパリティ セットをチェックすると、追加の接続コンポーネント ロジックを必要とせずに、切断された図も同時に処理されます。 

### 複数の対称軸

 正方形の和集合は、4 つの候補テストすべてに合格できます。 アルゴリズムはそれらすべてを個別に記録し、個別に正規化してから並べ替えます。 候補の生成順序は幾何学的であるのに対し、必要な出力順序は辞書編集的であるため、この分離が必要です。
