 ## 問題の理解

 私たちは、それぞれが特定の数の生き物を含む複数の種族から軍隊を編成するように求められます。 同じ種族の各クリーチャーペアは、異なる分隊に配置されている場合、固定量を貢献します。`b`軍隊の強さに。 一方、最初の分隊を超えて分隊が追加されるたびに、総戦力は次のように減少します。`x`。 私たちの任務は、軍隊の強さを最大化するためにクリーチャーを分隊に分割する方法を決定することです。 

入力は複数のテスト ケースで構成されます。 各テストケースについて、レースの数がわかっています。`n`、ペアボーナス`b`、チームペナルティ`x`、および配列`c`種族ごとのクリーチャーの数を与える。 各ケースの最大陸軍戦力を表す単一の整数を出力する必要があります。 

制約は次のことを示唆しています`n`最大 200,000 に達する可能性がありますが、すべての合計`c_i`すべてのテスト ケースが 200,000 を超えないこと。 これは、クリーチャーの総数については線形演算を行うことができるが、二次関数については何でも許容できることを意味します。`c_i`遅すぎます。 したがって、クリーチャーを個別に分隊に分割するためにあらゆる方法を試みる強引なアプローチは拡張できません。 明らかではないエッジケースには、クリーチャーが 1 匹だけのレースや、複数の分隊に分かれると高い攻撃力により全体的な戦力が低下するケースが含まれます。`x`。 たとえば、次の場合`b = 1`そして`x = 10`、2 つのクリーチャーの種族であっても別々の分隊に分割することは、それらを一緒に維持するよりも悪く、追加の強さはゼロという正解が得られます。 

## アプローチ

 ブルートフォースソリューションでは、考えられる分隊の数をすべて列挙し、クリーチャーを分隊に割り当てるあらゆる方法を試し、結果として生じるペアの貢献と複数の分隊からのペナルティを計算し、最大値を選択します。 とのレースに向けて`c_i`生物を分割する方法の数は指数関数的に増加するため、このアプローチは、中程度の値であってもすぐに実行不可能になります。`c_i`。 最悪の場合、演算回数は 2 × 10^5 × 2 × 10^5 を超え、1 秒以内には不可能です。 

重要な洞察は、各レースを独立して検討し、レースからの貢献は完全に分隊の数によって決まることを理解することです。 のために`k`分隊、とのレース`c_i`生き物が貢献する`b * (sum_{j=1}^{k} (number of creatures in squad j choose 2))`。 ボーナスを最大化するには、バランスを取ることで平方和が最小化されるため、同じ種族のクリーチャーを分隊間でできるだけ均等に分配する必要があります。 この観察により、問題は 1 つの変数、つまり分隊の数の関数に帰着します。`k`。 軍隊の総戦力は、分隊間の貢献からペナルティを差し引いた全レースの合計となります。`(k - 1) * x`。 関数は単峰性です`k`増えているので`k`最初はペアの寄与が増加しますが、最終的にはペナルティが支配的になります。 これにより、三項検索を使用できるようになります。`k`または、単に可能性のあるものを反復処理するだけです`k`最大値以降の効率的な値`k`レースはせいぜい`c_i`。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 テスト ケースごとに、次の内容を読んでください。`n`、`b`、`x`、および配列`c`。 
2. 並べ替え`c`必要に応じて降順で並べてください。ただし、厳密に必要なわけではありません。 
3. 特定の分隊の合計数の場合`k`、各種族からの貢献度を計算します。 とのレースに向けて`c_i`生き物、できるだけ均等に分割します。`k`分隊。 させて`q = c_i // k`そして`r = c_i % k`。 それから`r`分隊が持っている`q+1`生き物たちと`k-r`分隊が持っている`q`生き物たち。 チーム間のペアの数は`(q+1)*q/2 * r + q*(q-1)/2 * (k-r)`。 乗算する`b`貢献を得るために。 
4. すべてのレースからの貢献度を合計し、チームペナルティを差し引きます。`(k-1) * x`軍隊の総合力を得るために。 
5. の値を求めます。`k`それは軍隊の総力を最大化します。 この関数は単峰性であるため、1 から最大まで反復できます。`c_i`レース間で検索したり、速度を上げるために三項検索を使用したりできます。 制約が与えられた場合、考えられるすべての単純なループ`k`効率的に動作します。 
6. テストケースの最大陸軍戦力を出力します。 

機能する理由: 分隊全体にクリーチャーを均等に分配することで、各種族の貢献が最大化されます。 ペナルティは直線的です`k`。 反復または検索することによって`k`、関数は単峰性であるため、グローバル最大値を確実に見つけることができます。 不均衡な分割を組み合わせても結果を改善することはできません。不均衡があるとペアの寄与の合計が減少するためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_strength(n, b, x, c):
    max_c = max(c)
    best = 0
    for k in range(1, max_c + 1):
        total = 0
        for ci in c:
            if ci < k:
                continue
            q, r = divmod(ci, k)
            total += b * (r * q * (q + 1) // 2 + (k - r) * q * (q - 1) // 2)
        total -= (k - 1) * x
        best = max(best, total)
    return best

t = int(input())
for _ in range(t):
    n, b, x = map(int, input().split())
    c = list(map(int, input().split()))
    print(max_strength(n, b, x, c))
```機能`max_strength`アルゴリズムを実装します。 内側のループは、各種族の生き物を可能な限り均等に分散します。`k`分隊。 整数の除算と剰余を処理するために整数を使用し、分隊がスキップされたり二重にカウントされたりしないようにします。 の引き算`(k-1) * x`チームのペナルティを正しくモデル化します。 まで繰り返します`max_c`最大のレースよりも多くの分隊を使用しても追加のペアは得られないため、これで十分です。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(合計 c_i * max_c) | 外側のループはレース全体で最大 max(c_i) まで実行され、内側のループはすべてのレースの貢献度を合計し、合計は 2e5 | で制限されます。 
| スペース | O(n) | テスト ケースごとに配列 c のみを格納します。 

と`sum c_i ≤ 2 × 10^5`そして`max_c ≤ 2 × 10^5`、これは 1 秒未満であれば許容されます。
