 ## 解決策
 ## 問題の理解

 辺のある長方形が与えられます$a$そして$b$そして、この長方形を辺の 1 つに平行な線に沿って切断して、整数の寸法を持つ 2 つの小さな長方形にし、これら 2 つの部分を使用して元の長方形とは**形状が異なる** 長方形を形成できるかどうかを尋ねます。$a \times b$矩形。 互いに回転する長方形 (例:$6 \times 4$そして$4 \times 6$) は同一とみなされます。 

入力は複数のテスト ケースを提供します。 各テスト ケースは 2 つの整数で構成されます$a$そして$b$長方形の寸法を表します。 出力は、別の四角形を形成できる場合は「はい」、そうでない場合は「いいえ」と答える必要があります。 

制約は大きいです:$a$そして$b$まで可能です$10^9$、最大で$10^4$テストケース。 これにより、可能なすべてのカットを列挙したり、可能なすべての長方形の形成をシミュレートしようとするアプローチは除外されます。 **テスト ケースごとに一定時間**で答えを計算するソリューションが必要です。 

最小の非自明な長方形は、微妙なエッジケースを強調表示します。 あ$1 \times 1$長方形はまったくカットできないので、答えは「いいえ」です。 あ$2 \times 1$長方形は切り取ることしかできません$1 \times 1$再組み立て可能な長方形$1 \times 2$、回転後の元と同じであるため、答えも「いいえ」になります。 サイズの長方形$2 \times 2$以上の場合、通常、新しい長方形を作成できるカットが可能になります。 

## アプローチ

 ブルートフォース手法では、可能な限りの水平方向および垂直方向のカットを試み、結果として得られる長方形を生成し、別の長方形を形成できるかどうかを確認します。 各カットで 2 つの長方形が生成され、水平および垂直の両方のスタッキング構成でそれらを組み合わせることができます。 寸法が大きい場合、これはすぐに実行不可能になります。1 つの長方形でも寸法が近いためです。$10^9$作成するだろう$10^9$可能性と$10^4$テストケースを 1 秒で実行することは不可能です。 

重要な観察は、幾何学的かつ組み合わせ的なものです。 元とは異なる新たな長方形を形成するには、元の長方形の少なくとも一辺が 2 以上である必要があります。両方の辺が 1 の場合は、カットできません。 少なくとも 1 つの辺が 2 以上であれば、いつでもその辺に沿ってカットを行うことができ、2 つの長方形が生成され、それを異なる比率の長方形に再配置できます。 具体的には、次のような長方形$a \ge 2$または$b \ge 2$少なくとも 1 つの寸法が 1 の 2 つの部分に切断でき、これらの部分を積み重ねて、切断部分の合計を辺とする新しい長方形を形成できます。 唯一の例外は、次の長方形です。$2 \times 1$または$1 \times 2$、大きい辺に沿って切断すると 2 つの形状が作成されるため、新しい形状を作成することはできません。$1 \times 1$同じ長方形に再構築される正方形。 

したがって、問題は単純な条件チェックに帰着します。つまり、長方形が小さすぎて新しい形状を作成できないのは、次のいずれかの場合です。$1 \times 1$または$2 \times 1$（または$1 \times 2$)、それ以外の場合は「はい」。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$a$そして$b$。 
3. スワップ$a$そして$b$必要に応じてそのように$a \le b$。 これにより、小さい辺と大きい辺についての推論が簡素化されます。 
4. 次のことを確認します。$a = 1$そして$b = 1$。 true の場合、「No」を出力します。$1 \times 1$長方形はカットできません。 
5.次のことを確認します$a = 1$そして$b = 2$。 true の場合、「No」を出力します。$1 \times 2$長方形は、切り取って再配置した後にのみ同じ長方形を作成できます。 
6. それ以外の場合は、新しい長方形を生成できるカットが存在するため、「Yes」を出力します。 
7. すべてのテスト ケースに対して繰り返します。 

これが機能する理由: 不変条件は、意味のあるカットが可能かどうかは長方形の最小辺によって決まるということです。 最小辺が 2 以上の場合、水平または垂直のカットにより 2 つの部分が作成され、それらを再結合して新しい長方形を作成できます。 唯一の例外は、最小サイズの長方形です。$1 \times 1$そして$1 \times 2$、明示的に処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    if a > b:
        a, b = b, a
    if a == 1 and b <= 2:
        print("No")
    else:
        print("Yes")
```コードは、次を使用してすべてのテスト ケースを効率的に読み取ります。`sys.stdin.readline`。 スワッピングにより、常に小さい方から最初に処理されるため、エッジケースのチェックが簡素化されます。 条件`a == 1 and b <= 2`新しい形状を生成できない最小限の長方形をキャプチャします。 他のすべての長方形は、カット可能な幾何学的条件を自動的に満たします。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    
    t = int(input())
    for _ in range(t):
        a, b = map(int, input().split())
        if a > b:
            a, b = b, a

            print("No")
        else:
            print("Yes")
    
    return output.getvalue().strip()

 ## 特殊なケース

 のために$1 \times 1$長方形である場合、アルゴリズムはそれを正しく識別します`a==1 and b<=2`true の場合、「No」を出力します。 のために$1 \times 2$、同じ条件では「いいえ」がトリガーされます。 次のような長方形の場合$2 \times 3$以上の場合、条件は false となり、アルゴリズムは「Yes」を出力し、カットによって新しい長方形が生成される一般的なケースを捉えます。 スワップステップにより、小さい側が常に内側にあることが保証されます。`a`したがって、エッジ状態のチェックは均一であり、最小限のケースを見逃すことはありません。
