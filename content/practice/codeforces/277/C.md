 ## 問題の理解

 紙の内部のすべてのグリッド線は、格子点によって単位セグメントに分割されます。 グリッド線に沿って切断すると、ナイフが触れたすべての単位セグメントがすでに切断されたものとしてマークされます。 

重要な観察は、紙の形状が決して変わらないということです。 ピースは移動されず、将来のカットでは、グリッド線の単位セグメントが以前にすでにタッチされているかどうかのみが考慮されます。 ゲームの状態は、単にまだカットされていない単位グリッド セグメントのセットです。 

内部の 1 本の垂直グリッド線を考えてみましょう。 含まれています`m`単位セグメント。 既存のカットは、そのライン上の一部の区間をすでにカットされているものとしてマークします。 残りの切断されていない単位セグメントは、いくつかのばらばらの連続したランを形成します。 同じ説明がすべての内部の水平グリッド線に当てはまります。 

移動では 1 つのグリッド ラインを選択し、その上で連続した間隔を切ります。 カットされていない長さのランの内側`s`、そのような動きは、連続したブロックを削除し、多くても 2 つの小さな未カットのランを残します。 

寸法は次のように大きくできます。`10^9`, そのため、グリッド自体を保存することはできません。 既存のカット数は`10^5`、つまり、`O(k)`グリッド線は何も触れられていない状態とは異なる場合があります。 受け入れられている解決策は、カットの説明だけから機能する必要があります。 

よくある間違いは、各入力カットを独立したゲーム コンポーネントとして扱うことです。 重複するカットは最初にマージする必要があります。 

例えば：```
3 3 2
1 0 1 2
1 1 1 3
```両方のカットが同じ垂直線上にあり、重なっています。 彼らの組合は全行程をカバーしています。 マージ後、そのラインにはカットされていないセグメントはまったく含まれません。 

もう 1 つの簡単な間違いは、最大のノーカット ラン数ではなく、個々のユニット セグメントをカウントすることです。 

例：```
3 3 1
1 1 1 2
```縦の線`x = 1`カットされていない長さのランがある`1`そして`1`、単一の長さのランではありません`2`。 Sprague-Grundy 値はラン分解に依存します。 

最後の微妙なケースは、巨大な次元から生じます。 仮定する`n = 10^9`、`m = 10^9`、 そして`k = 0`。 何十億もの手つかずの行が存在します。 ソリューションでは、それらの寄与を反復するのではなく、数学的に集計する必要があります。 

## アプローチ

 強引な見方では、すべての最大限のノーカット ランをゲームのコンポーネントと見なします。 長いランの場合`s`、移動すると、隣接するブロックが削除され、2 つの小さなランが残ります。 すべての長さの Sprague-Grundy 値を計算し、全体の位置を評価できます。 

長さは次のように大きくなる可能性があるため、これはすぐに失敗します。`10^9`。 Grundy 値を最大長まで保存することさえ不可能です。 

重要な観察は、1 回の実行でゲームが予想外に単純な Grundy 関数を持っているということです。 

させて`G(s)`カットされていない長さのランのグランディ値になります。`s`。 

動きは長さを選ぶ`l`そして`r`残っている左右の部分については、`l + r < s`。 したがって、$$G(s)=\operatorname{mex}\{G(l)\oplus G(r)\}.$$帰納的に次のように仮定します`G(t) = t`すべての短い長さに対応します。 それから$$G(s)=\operatorname{mex}\{l\oplus r \mid l+r<s\}.$$からのすべての値`0`に`s-1`そのセットに出現しますが、値はありません`≥ s`現れることがあります。 したがって$$G(s)=s.$$したがって、すべてのノーカット実行は、サイズがその長さに等しい Nim ヒープとまったく同じように動作します。 

これでゲーム全体がニムのポジションになります。 グランディの合計値は、すべての内部グリッド ライン上のすべての最大ノーカット ランの長さの単純な XOR です。 

のみ`O(k)`グリッド線はカットの影響を受けます。 垂直線が 1 つおきに 1 つのサイズが追加されます`m`、1 つおきの水平線が 1 つのヒープのサイズに寄与します`n`。 同じ値を偶数回 XOR 演算すると相殺されるため、パリティを使用して未処理の行を集約できます。 

残りの作業は次のとおりです。 

1. 影響を受けるすべての行の間隔をマージします。 
2. 補体内の最大のアンカットランを計算します。 
3. それらの長さを XOR します。 
4. 標準的な Nim の勝利の手を適用します。
