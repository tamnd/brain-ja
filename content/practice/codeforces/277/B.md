 ## アルゴリズムのチュートリアル

 1. 凸面を構築する`m`-ゴン。 最も簡単な選択は、線に沿って点を配置することです`y = x`整数の増分で、厳密に凸状の位置にあることを保証します。 これらの点にラベルを付けます`P0, P1, ..., P_{m-1}`。 これらの点の凸包は正確なサイズになります`m`。 
2. 必要な内部点の数を決定します。`k = n - m`。 これらの点は厳密にポリゴンの内側に存在する必要があります。 
3. 場所`k`ポリゴンのベースからわずかにオフセットしたラインに沿った内部ポイント。たとえば、`y = 0`と`x`2 つの頂点間で互い違いに配置された座標。 これにより、それらが凸包内にあることが保証され、共線性が回避されます。 
4. すべての座標を出力します`n`ポイント。 

これが機能する理由: 点セットの凸包は、最も外側の点によって定義されます。 余分なものを入れることで、`k`点は厳密に内側にあるため、新しい凸多角形の頂点になることはできないため、最大の凸サブセットは正確に元のままになります。`m`ポイント。 内部の点をずらして配置することで、3 つの点が同一線上にないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

if m < 3 or m > n or n > 2 * m:
    print(-1)
    sys.exit()

points = []

# Step 1: Construct convex m-gon along y = x
for i in range(m):
    points.append((i * 2, i * 2))

# Step 2: Place interior points, staggered along y = 0
for i in range(n - m):
    points.append((i * 2 + 1, 0))

for x, y in points:
    print(x, y)
```各部分はアルゴリズムのステップに対応します。 外側の凸多角形は座標を使用します`(0,0), (2,2), ..., (2*(m-1), 2*(m-1))`、これは厳密に増加する勾配を保証します。 インテリアのポイント使い`y = 0`そして千鳥足で`x`座標`(1,3,5,...)`、そのため、ポリゴンのエッジと同一線上に置くことはできません。 座標を 2 で乗算すると、内部ポイントを重複せずに配置できる余地が残ります。

 ## 特殊なケース

 のために`n = m`の場合、アルゴリズムは凸多角形のみを構築します。 例えば、`n = 5, m = 5`ポイントが得られます`(0,0),(2,2),(4,4),(6,6),(8,8)`。 内部点がないため、凸性は正確に`m`。 

のために`n = 2*m`、アルゴリズムは次のように配置します`m`内部ポイントは、多角形内の線に沿ったものです。 内部点は厳密に内側にあり、互い違いに配置され、ポリゴン エッジと同一直線上にないため、新しい凸頂点は作成されません。 のために`n = 6, m = 3`、ポイント`(0,0),(2,2),(4,4)`三角形を形成し、`(1,0),(3,0),(5,0)`内側に横たわって、凸性を 3 に保ちます。 

他のすべてのケース`m ≤ n ≤ 2*m`も同様に扱われます。 同一線上にある 3 つの点はなく、内部点は厳密に多角形の内側にあり、凸包のサイズは正確に維持されます。`m`。
