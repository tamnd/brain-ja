 ## 解決策
 ## 問題の理解

 BerCorp のすべての従業員が、共有言語を通じて直接、または一連の翻訳者を介して間接的に他のすべての従業員と確実にコミュニケーションできるようにすることが求められています。 各従業員は最初は 0 個以上の公用語を知っている可能性がありますが、追加の言語を学習するために従業員 1 人あたり 1 言語あたり 1 の費用を支払うことができます。 目標は、この方法ですべての従業員を接続するために必要な総コストを最小限に抑えることです。 

入力から、`n`従業員と`m`言語。 各従業員のリストには、彼らが知っている言語が含まれています。 出力は単一の整数です。これは、すべての従業員が相互に連絡できるようにするための有料レッスンの最小数です。 言語を知らない従業員は最初は接続が切断され、通信ネットワークに参加するには常に少なくとも 1 回のレッスンが必要になります。 

制約は中程度です。両方とも`n`そして`m`は最大でも 100 なので、`O(n*m)`操作は実行可能です。 ただし、誰がどの言語を学習するかについてすべての組み合わせを試すという単純な力技は指数関数的であり、不可能です。 エッジ ケースには、従業員全員が言語をまったく知らないことが含まれます。この場合、各従業員は孤立しており、最小コストは従業員の数に等しいか、またはすべての従業員がすでに言語連鎖を知っているためコストはゼロになります。 もう 1 つの微妙なエッジ ケースは、複数の切断されたグループが存在する場合です。 各グループの 1 人に 1 つの言語を教えるだけで、効率的にグループを結び付けることができます。 

## アプローチ

 ブルートフォースアプローチでは、何も知らない従業員に対して可能なすべての言語割り当てセットを列挙し、その結果として得られる接続性を計算し、最小コストを選択します。 これは原理的には正しいですが、明らかに実行不可能です。`n=100`確認が必要だろう`m^n`組み合わせ。 

重要な洞察は、これが接続の問題であるということです。 従業員をグラフ内のノードとして扱い、言語を共有している 2 人の従業員を接続すると、問題はこの従業員言語グラフ内の接続コンポーネントをカウントすることになります。 同じコンポーネント内の従業員はすでに通信できるため、異なるコンポーネントを接続する場合にのみコストが発生します。 マージするには`k`コンポーネントは少なくとも必要です`k-1`新しいつながり。 それぞれの接続は、あるコンポーネントの従業員に別のコンポーネントの言語を教えることで実現できます。 

さらに微妙な点は、言語を知らない従業員がいないという特殊なケースを処理することです。 その場合、各従業員は最初は孤立したコンポーネントです。 既存の言語の重複に依存できないため、各従業員に少なくとも 1 つの言語を教える必要があり、その結果、`n`。 

最適なアプローチでは、素集合結合 (DSU) 構造を使用します。 私たちは言語を繰り返し検討し、その言語を知っているすべての従業員を結合します。 最後に、個別の DSU セットの数が、最初に切断されたグループの数を示します。 少なくとも 1 人の従業員が言語を知っている場合、必要な最小レッスンはグループ数から 1 を引いたものになります。 従業員がどの言語も知らない場合、最低限のレッスンは以下となります`n`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(m^n) | O(n*m) | 遅すぎる |
 | DSU / 接続コンポーネント | O(n*m + n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 次のコマンドを使用して DSU を初期化します。`n`各従業員に 1 つの要素。 各従業員は自分のセットから開始します。 これは、最初は各従業員が孤立する可能性があるという考えをモデル化しています。 
2. ブール値フラグを追跡する`any_language_known`言語を知っている従業員が少なくとも 1 人いるかどうかを検出します。 
3. 各従業員と既知の言語のリストを繰り返し処理します。 言語ごとに、その言語を理解している従業員のリストを維持します。 これは、言語から従業員への逆マッピングです。 
4. 各言語について、2 人以上の従業員がそれを知っている場合は、DSU で全員を結合します。 このステップでは、すでに共有言語を介してコミュニケーションできる従業員を単一のコンポーネントに統合します。 
5. DSU 内の各従業員のルートを調べて、個別の接続コンポーネントの数を数えます。 もし`any_language_known`が True の場合、最小レッスン数は`components - 1`。 従業員がどの言語も知らない場合、最小レッスン数は次のとおりです。`n`。 

機能する理由: DSU は、言語を共有する従業員を統合する際に、接続されたコンポーネントを正しく維持します。 組合の操作により、2 人の従業員が接続されると、その後のすべての組合が接続を維持することが保証されます。 コンポーネントの最終的な数をカウントすると、すべてのグループをマージするために必要な追加の接続 (レッスン) の数が直接得られ、最小コストが得られます。 ゼロ言語のエッジ ケースは、結合が発生しないため、個別に処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px != py:
            self.parent[py] = px

def main():
    n, m = map(int, input().split())
    dsu = DSU(n)
    lang_to_employees = [[] for _ in range(m)]
    any_language_known = False
    
    for i in range(n):
        data = list(map(int, input().split()))
        k = data[0]
        if k > 0:
            any_language_known = True
        for lang in data[1:]:
            lang_to_employees[lang - 1].append(i)
    
    for employees in lang_to_employees:
        for i in range(1, len(employees)):
            dsu.union(employees[0], employees[i])
    
    roots = set(dsu.find(i) for i in range(n))
    if any_language_known:
        print(len(roots) - 1)
    else:
        print(n)

if __name__ == "__main__":
    main()
```このコードは従業員用の DSU を作成し、言語から従業員へのマッピングを使用して、言語を共有するすべての従業員を効率的に統合します。 旗`any_language_known`初期知識がゼロというエッジケースを処理します。 結合コンポーネントの数から 1 を減算します。`k`グループに必要なもの`k-1`新しいレッスン。

 すべての従業員が一連の言語を共有し、DSU は全員を 1 つのセットに統合します。`roots = {0}`。 少なくとも 1 つの言語が知られているため、コストは次のようになります。`1-1=0`。

これらのトレースは、アルゴリズムが標準ケースと特殊ケースの両方を正しく処理していることを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n*m) | 各従業員の言語は 1 回処理され、DSU の結合/検索ではパス圧縮によりほぼ一定の償却時間がかかります。 |
 | スペース | O(n + m) | DSU は O(n) を使用し、言語から従業員へのマッピングは O(m + 合計言語) ≤ O(n*m) を使用します。 |

 制約を考慮すると`n,m ≤ 100`、最悪の場合の操作数は 10,000 未満で、2 秒以内、256 MB 以内です。
