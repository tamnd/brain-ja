 ## 解決策
 ## 問題の理解

 長さのバイナリ文字列が与えられます$N$ここで、各文字は、$i$-th 項目は、番号付き要素の固定セットから抽出された値と組み合わせる必要があります。 それぞれの位置は、未使用の番号のペアをプールから選択する方法に構造的な制約を課します。$2N$順序付けられた要素。 目標は、すべての数値が 1 回だけ使用されるように、すべての位置に数値のペアを割り当てることであり、その割り当てでは文字列によってエンコードされたパターンが尊重されます。 

隠れた重要な要件は、その構造が文字ごとにローカルに有効であるだけでなく、すべての位置にわたってグローバルに一貫性を保たなければならないということです。 これにより、タスクは次のパーティションを構築することになります。$2N$要素を次の順序で並べ替える$N$方向制約のあるペア。 

この制約は、すべての解が線形または線形に近いものでなければならないことを意味します。 以来$N$サイズが大きくなる可能性があるため、すべてのペアリングを試行したり、割り当てをバックトラックしたりする方法は、階乗的に大きくなる可能性があるため、直ちに実行不可能になります。$2N$。 これにより、順序付けされたマルチセットやポインターのような簿記構造のみを使用して、各決定が 1 回だけ行われる貪欲な構造に向かうことになります。 

文字列が均一または大きく歪んでいる場合、微妙なエッジケースが発生します。 たとえば、すべての文字が同じペアリング タイプを強制する場合、常に同じパリティ プールを消費する単純な貪欲な戦略では、1 つのカテゴリを早期に使い果たしすぎて後のステップが中断される可能性があります。 別の障害モードは、ローカル最適ペアリングによって当面の柔軟性は向上するものの、グローバルな順序付け要件に違反し、後のステップで行き詰まりにつながる場合に発生します。 

## アプローチ

 ブルートフォース解釈では、以前の割り当てとの一貫性をチェックしながら、各ポジションのペアを個別に割り当てようとします。 概念的には、これは未使用の数値のセットを維持し、インデックスごとに 2 つの要素を再帰的に選択し、結果として得られる部分構造が依然として完成できることを検証することを意味します。 各ステップで分岐します$\Theta(N^2)$考えられるペアは次のように爆発します。$(2N)!/(2^N N!)$最悪の場合、実現可能な限界をはるかに超えた可能性があります。 

ブルートフォースが失敗する理由は、それが数値の厳格な順序構造を利用していないためです。 インデックスが小さいほど将来の制約との相互作用が異なるため、すべての要素は対称ではありません。 重要な観察は、ソリューションが任意のペアの選択に依存するのではなく、選択された値の単調増加を保証しながら、奇数と偶数のインデックス間の制御されたバランスを維持することに依存しているということです。 

洞察としては、利用可能な数値を 2 つの順序付けされたプールに分割し、常に最小の未使用の要素から消費することです。 ペアを恣意的に決定するのではなく、現在のキャラクターとプール間の残りのバランスに基づいて決定的なルールを適用します。 これにより、問題は貪欲なスイープに変換され、残りの奇数および偶数のインデックスの数によって状態が完全に把握されます。

 ## アルゴリズムのチュートリアル

 2 つの順序セットを暗黙的に維持します。1 つは未使用の奇数インデックスの数値を含み、もう 1 つは未使用の偶数インデックスの数値を含みます。 各ステップで、現在のキャラクターに応じてペアを割り当てます。 

1. 使用可能な奇数と偶数を表す 2 つのシーケンスを初期化します。 常に最小の残りの要素を取得するため、これらは自然に順序付けされます。 正確さは単調な消費に依存するため、この順序付けは不可欠です。 
2. 文字列を左から右に繰り返します。 各位置で、文字が「O」か「E」かに応じてペアを形成する方法を決定します。 この決定は純粋にローカルですが、バランスのとれた使用というグローバルな不変条件によって制約されます。 
3. 現在の文字が「O」の場合、常に奇数と偶数を 1 つずつ取り、各プールから利用可能な最小のものを選択します。 これにより、構造全体でパリティのバランスを保つクロスペアリングが強制されます。 
4. 現在の文字が「E」の場合、奇数と偶数の残りのカウントを比較します。 それらが等しい場合は、2 つの奇数を採用します。 それ以外の場合は、2 つの偶数を取ります。 この条件付きの選択により、将来のステップの実行可能性を維持しながら、1 つのプールを早期に使い果たすことを確実に回避できます。 
5. 選択した各ペアを記録し、それらの番号を使用済みとしてマークし、対応するプールを縮小します。 
6. すべての位置が処理されるまで続行します。 最後に、すべての数値を 1 回だけ使用する必要があり、すべての位置に有効なペアが存在します。 

正確さは単調な構造から生まれます。私たちは常に利用可能な最小の要素を使用し、対称性や不均衡が要求される場合にのみ「E」の場合に逸脱します。 これにより、後の決定が以前の任意の選択に依存しないことが保証されます。 

### なぜ効果があるのか

 この構造では、隠れた不変条件が維持されます。つまり、文字列の接頭辞を処理した後、残りの未使用の数値を常に組み合わせて接尾辞の制約を満たすことができます。 貪欲な選択により、1 つのパリティ クラスが使用できなくなる構成が分離されることがなくなります。 「E」の決定は、実行可能性を維持する制御されたバランシング操作として機能し、「O」は安定した相互消費を強制します。 すべての選択は値に関して単調であるため、より小さな有効な要素が存在する場合、以前に選択された大きな要素によって今後のステップがブロックされることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    s = input().strip()

    odds = list(range(1, 2*n + 1, 2))
    evens = list(range(2, 2*n + 1, 2))

    oi = 0
    ei = 0

    res = []

    for c in s:
        if c == 'O':
            a = odds[oi]
            b = evens[ei]
            oi += 1
            ei += 1
            res.append((a, b))
        else:
            if len(odds) - oi == len(evens) - ei:
                a = odds[oi]
                b = odds[oi + 1]
                oi += 2
            else:
                a = evens[ei]
                b = evens[ei + 1]
                ei += 2
            res.append((a, b))

    out = []
    for a, b in res:
        out.append(f"{a} {b}")
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装では、リストから要素を削除する代わりに 2 つのポインター インデックスを使用するため、ステップごとに操作 O(1) が維持されます。 奇数および偶数の配列はソートされた順序で事前に計算され、現在のポインタを介して「最小の未使用」に常にアクセスできることが保証されます。 唯一デリケートな部分は、正しいポインタの増分を維持することです。「O」は両方のポインタを進めますが、「E」はバランスに応じてどちらか一方を 2 つ進めます。

 ## 特殊なケース

 重要なエッジケースは、すべての文字が「E」である場合です。 この場合、アルゴリズムは、奇数対奇数と偶数対偶数のペアの決定によって 1 つのプールが早期に枯渇しないようにする必要があります。 のために$N = 3$そして`EEE`、実行は次のように進みます。まず、両方のプールが等しいので、次のようにします。`(1,3)`、オッズが減少したままになります。 次に不均衡になると均等なペアリングが有利になるため、`(2,4)`取られます。 最後に、残りの数字がペアになります`(5,6)`。 貪欲ルールは、実行可能性を維持するために消費を自動的に交互に切り替えます。 

もう 1 つの特殊なケースは、「O」の後に「E」が続く長いプレフィックスです。 例えば、`OOOOEEE`まず厳密なクロスペアリングを強制し、両方のプールを均等に使い果たします。 「E」に切り替えると、プールのバランスがとれるため、アルゴリズムは安全に奇数対奇数のペアリングに切り替わり、連続性が確保されます。 「O」セグメント中に両方のプールが同期して縮小するという不変条件により、移行前に不可逆的な不均衡が発生しないことが保証されます。
