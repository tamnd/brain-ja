 ## 問題の理解

 私たちは次のようなラインで取り組んでいます$n$細胞。 空の状態から始めて実行します$n-1$塗装作業。 稼働中$i$、線の連続したセグメントを選択し、そのセグメント内のすべてのセルを色で再描画します。$i$、以前にペイントしたものを上書きします。 すべての操作の後、各セルは最終的に 1 つの色を持ち、これらの色が配列を形成します。$c_1, c_2, \dots, c_n$。 

3 つの条件が同時に満たされる場合、カラーリングは有効であるとみなされます。 まず、これらのシーケンスによって達成できる必要があります。$n-1$セグメント再描画操作。 第 2 に、すべてのセルは最終的に色付けされる必要があります。つまり、ペイントされていないセルは存在しません。 第三に、以下のすべての色$1$に$n-1$最終配列に少なくとも 1 回出現する必要があります。 

タスクは、これらのルールに従って最終的にいくつのカラー配列を生成できるかをカウントすることです。 

制約$n \le 3 \cdot 10^5$演算または色付けに対する指数列挙または階乗列挙を即座に除外します。 平$O(n^2)$が大きすぎるため、解は線形または対数でなければなりません。 区間演算によって定義された構造化された組み合わせオブジェクトをカウントしているため、当然のことながら、答えは直接的なシミュレーションではなく、既知の反復または標準的な組み合わせファミリーに依存することが予想されます。 

小さなサイズでは、微妙なエッジケースがすでに現れています。 のために$n=2$、セルの配置は 1 つだけです。両方のセルに色が付きます。$1$。 操作が 1 つしかないため、2 番目の構造を導入しようとしても失敗します。 のために$n=3$、複数の異なるカラーリングが存在し、重複する再描画間隔間の相互作用は重要になります。 各色を間隔として独立して扱う単純なアプローチは、後の操作によって非ローカルな方法で以前の構造が上書きされるため、失敗します。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての選択肢を列挙しようとします。$n-1$セグメントを作成し、ペイント プロセスをシミュレートし、結果として得られる最終的なカラーリングを記録します。 それぞれの操作には、$O(n^2)$セグメントの選択肢が多数あるため、操作シーケンスの総数は次のようになります。$(n^2)^{n}$、非常に小さい場合でも完全に実行不可能です。$n$。 同等の最終状態を枝刈りしても役に立ちません。異なる操作シーケンスが、非常に非注入的な方法で同じ最終的なカラーリングに崩壊する可能性があるからです。 

重要な観察は、最終的なカラーリングは、再ペイント操作の正確な順序によってではなく、カラー間の優勢構造によって決定されるということです。 各色$i$は、各位置に最後に適用された時刻に対応し、これにより階層が生じます。セグメントが重なっている場合は、より高いインデックスの色が、より低いインデックスの色を上書きします。 

この階層は、ラインの再帰的な細分化として解釈できます。 セグメントがより高い色でペイントされるたびに、より低い色の領域がサブセグメントに分割されます。 これにより、区間のツリー状の分解が生成されます。$[1, n]$ここで、各色は連続セグメントを所有するノードに対応し、上位の色によって分割される場合があります。 

この構造は、セグメントのバイナリ分解をネストされた間隔に構築するのと同等であることがわかります。 有効な各色分けは、区間の完全な分解ツリーに対応します。$n$原子細胞を使用して$n-1$分割操作。 各分割が区間を 2 つの独立した部分問題に分割するため、このような構造の数はカタロニア語タイプの反復によって決まります。 

したがって、カウントは間隔サイズ全体にわたって標準的なカタロニア語 DP まで減少します。

 ## アルゴリズムのチュートリアル

 私たちは定義します$dp[k]$ある長さのセグメントの有効な色の数として$k$。 最終的な答えは、$dp[n]$。 

1. 長さの有効な色分けが可能であるという観察から始めます。$k$セグメントの最上位構造を定義する「ルート」カラー操作を選択して作成する必要があります。 このルート操作は、セグメント全体の分解に影響を与える最高の色に対応します。 
2. ルート操作が修正されると、セグメントが選択されます。$[l, r]$完全にペイントされるということ。 上位レベルの構造は存在しないため、このセグメントは区間の最初の分割として機能します。 
3. このセグメントは、後の操作によって左右の部分に分割され、独立して展開されます。 ルートセグメントがプレフィックスとサフィックスをカバーする場合、中間構造は外部構造とは独立して決定されます。 
4. したがって、分割ポイントの選択$i$問題をサイズの異なる 2 つの部分問題に分割します$i$そして$k-1-i$、ルートの構造を除く区間の左側と右側の部分に対応します。 
5. 考えられるすべての分割点を合計します。$$dp[k] = \sum_{i=0}^{k-1} dp[i] \cdot dp[k-1-i]$$これはまさに、インデックスによってシフトされたカタルーニャ語の回帰です。 
6. 基本ケースは次のとおりです。$dp[0] = 1$、空のセグメントを表します。 

### なぜ効果があるのか

 すべての有効なカラーリングは、セグメントの一意の階層的分解を引き起こします。最上位の構造分割は、ラインを、支配関係の点で相互作用しない 2 つの独立した部分に分離します。 後の操作では、すでに作成されたセグメント内でのみ調整が行われ、セグメントがマージされることはないため、分割境界を越える依存関係はありません。 これにより、部分問題の独立性が保証され、すべての色が繰り返しによって正確に 1 回カウントされることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def main():
    n = int(input().strip())
    
    dp = [0] * (n + 1)
    dp[0] = 1
    
    for k in range(1, n + 1):
        val = 0
        for i in range(k):
            val += dp[i] * dp[k - 1 - i]
        dp[k] = val % MOD
    
    print(dp[n])

if __name__ == "__main__":
    main()
```実装はカタロニア語スタイルの畳み込みに直接準拠しています。 外側のループはセグメント サイズを固定し、内側のループは左右の部分問題を決定する分割点を列挙します。 オーバーフローを防ぐために、各ステップでモジュロが適用されます。 

最もデリケートな点はインデックス付けです。再帰処理では次のようなものを使用します。$k-1$ルート構造は残りの構造を分割する前にセグメンテーションの 1 単位を消費するためです。
