 ## 問題の理解

 三角形の 2 つの固定辺の長さが与えられています。$a$そして$b$そして、3番目の辺がどのような整数値になるかを理解したいと考えています。$c$3 つのセグメントが正の面積を持つ有効な三角形を形成するように取ることができます。 

三角形が縮退していない場合、三角形はまさに正の面積を持ちます。これは、すべての三角形不等式が厳密であることを意味します。 したがって、3 番目の辺は 2 つの条件を同時に満たさなければなりません。それは、他の 2 つの辺に適合するのに十分な長さでなければならず、また、三角形が直線に崩れないように十分な長さでなければなりません。 

具体的にはサイドに関しては$a$、$b$、 そして$c$、有効性には次のものが必要です。$a + b > c$、$a + c > b$、 そして$b + c > a$。 

タスクは最小および最大の整数を見つけることです$c$これらの条件を満たすもの。 

制約は次のとおりです$10^6$これは、どのソリューションもテスト ケースごとに一定時間で実行する必要があることを意味します。 可能なすべての値を反復するソリューション$c$最悪の場合、辺の合計までが遅すぎる可能性があります。 制約の構造は、列挙ではなく直接的な代数的特徴付けを示唆しています。 

よくある微妙な失敗のケースは、一方の側がもう一方の側に比べて非常に大きい場合です。 たとえば、次の場合$a = 1$そして$b = 10$の場合、多くの単純な実装では、$c$間$1$そして$11$は機能しますが、不等式の厳密さと三角形の条件によって課される下限を忘れています。$c > |a - b|$。 

## アプローチ

 ブルートフォースアプローチでは、すべての整数が試行されます$c$1から$a + b - 1$かどうかを確認します$a, b, c$有効な三角形を形成します。 各チェックは定数時間であるため、複雑さは次のようになります。$O(a + b)$、最悪の場合は約$2 \cdot 10^6$。 これは一部の環境では問題なく動作する可能性がありますが、特にループ内のロジックは単純化できる不等式を検証しているだけであるため、不要かつ脆弱です。 

重要な観察は、三角形の妥当性制約が狭い間隔に崩壊することです。$c$。 三角不等式から:$c < a + b$、$c > a - b$、$c > b - a$。 

最後の 2 つを組み合わせると、$c > |a - b|$。 以来$c$が整数の場合、これは次のようになります$c \ge |a - b| + 1$。 同様に、厳密な上限は次のようになります。$c \le a + b - 1$。 

したがって、有効な範囲は連続する整数セグメントです。$$|a - b| + 1 \le c \le a + b - 1$$これにより、問題は検索ではなく、単に間隔のエンドポイントを計算することになります。

 ## アルゴリズムのチュートリアル

 三角形不等式から直接 3 番目の辺の有効範囲を計算します。 

1. 下限を計算します。$c$として$|a - b| + 1$。 これにより、三角形が縮退せず、両方を満たすことが保証されます。$a + c > b$そして$b + c > a$。 絶対差は、2 つの下位制約のうち強い方を捕捉します。 
2. の上限を計算します。$c$として$a + b - 1$。 これにより、エリアの厳密なポジティブ性が確保されます。$c < a + b$。 
3. 2 つの値を答えとして出力します。 

### なぜ効果があるのか

 三角不等式システムは、実行可能な値の凸集合を定義します。$c$。 すべての制約は線形であるため、$c$、それらの交差点は単一の連続区間です。 下限は、$c$両方の差より大きい$a - b$そして$b - a$、一方、上限は合計制約から得られます。 整数値が必要であるため、連続間隔は、厳密な不等式によりエンドポイントが ±1 調整された整数セグメントに変換されます。 ギャップや不連続な領域は存在しないため、エンドポイントはソリューション セットを完全に記述します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

a = int(input())
b = int(input())

low = abs(a - b) + 1
high = a + b - 1

print(low, high)
```このソリューションは 2 つの整数を読み取り、有効な間隔を直接計算します。 唯一の微妙な点は、厳密な不等式を尊重することです。上限は 1 減り、下限は絶対差を超えて増加します。 平等だと縮退した三角形が生成されるため、両方の調整が必要です。 

ループは必要なく、追加のデータ構造も必要ありません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    input = _sys.stdin.readline

    a = int(input())
    b = int(input())

    low = abs(a - b) + 1
    high = a + b - 1

    return f"{low} {high}"

# provided sample
assert run("6\n14\n") == "9 19"

# equal sides
assert run("5\n5\n") == "1 9"

# minimal case
assert run("1\n1\n") == "1 1"

# highly unbalanced
assert run("1\n10\n") == "10 10"

# large values
assert run("1000000\n999999\n") == "2 1999998"

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、指定された 2 つの辺が等しい場合です。 例えば、$a = b = 5$。 アルゴリズムは計算します$low = |5 - 5| + 1 = 1$そして$high = 9$。 これにより、1 から 9 までのすべての有効な三角形の 3 番目の辺が正しく許可されます。重要な点は、下限がゼロに崩壊しないことです。 厳密な不等式により、少なくとも 1 が強制されます。 

もう 1 つの特殊なケースは、一方の側がもう一方の側よりもはるかに大きい場合です。$a = 1$、$b = 10$。 計算の結果は、$low = 10$、$high = 10$、有効な三角形が 1 つだけ存在することを意味します。 不等式を追跡すると、次のことが確認されます。$c$より大きくなければなりません$9$未満$11$、残すのみ$10$。 

最後に、両方の値が大きくて近い場合、間隔は広くなります。 のために$a = 10^6$、$b = 10^6$、1 からほぼまでのほぼ完全な範囲が得られます。$2 \cdot 10^6$、制約が差分ではなく和条件によって支配されていることを示しています。
