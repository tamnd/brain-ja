 ## 問題の理解

 非常に大きな長方形のグリッドが与えられました。`n`行と`m`列。 一部の細胞は石によってブロックされていますが、残りの細胞はすべて解放されています。 タスクは、`2 × 2`正方形は、正方形の 4 つのセルすべてがグリッド内にあり、どのセルにも石が含まれていないように存在します。 

の配置`2 × 2`正方形は左上のセルによって完全に決定されます。 左上隅が`(i, j)`、次に正方形のカバー`(i, j)`、`(i, j+1)`、`(i+1, j)`、`(i+1, j+1)`。 したがって、有効な配置は範囲内の左上隅に正確に対応します。`1 ≤ i ≤ n-1`そして`1 ≤ j ≤ m-1`カバーされた 4 つのセルがすべてフリーになるようにします。 

グリッド サイズに対する制約は非常に大きく、`n`そして`m`最大10億まで。 これにより、グリッド上で反復するアプローチは不可能になります。 ブロックされたセルの数は最大 200,000 ですが、これは直接反復処理できるほど小さいです。 この不均衡が構造上の中心的なヒントです。解決策は、グリッドの寸法ではなく、ブロックされたセルのみに依存する必要があります。 

素朴な試みでは、すべてを列挙することになるでしょう`(n-1)(m-1)`可能`2 × 2`配置を確認し、それぞれが有効かどうかを確認します。 グリッドには最大で次のものを含めることができるため、これは実行不可能です。`10^18`候補ポジション。 

2 番目の素朴なアイデアは、ブロックされた各セルを反復処理し、影響を受けるすべてのセルをマークすることです。`2 × 2`正方形。 これは正解に近いですが、複数の石が同じマスを無効にする可能性があるため、重複を適切に処理する必要があるため注意が必要です。 

一般的に誤った解決策を破るエッジケースには、石のないグリッド、石が境界上にあるグリッド (より少ないマスに影響を与える)、および複数の石が同じ無効に寄与するケースが含まれます。`2 × 2`地域。 たとえば、2 つの石が同じ中にある場合、`2 × 2`領域にある場合でも、その正方形は無効として 1 回だけカウントされる必要があります。 

## アプローチ

 直接カウントするアプローチは、すべての有効な配置がオブジェクトの左上隅に対応するという観察から始まります。`2 × 2`ブロック。 石がなければ、答えは簡単です。`(n - 1) × (m - 1)`。 

石を導入すると、これらの配置の一部が削除されるだけです。 4 つのマスのうち少なくとも 1 つに石が含まれている場合、その配置は無効になります。 すべての配置をチェックするのではなく、視点を逆転させます。考えられるすべての配置から開始して、ブロックされている配置を差し引きます。 

重要な点は、二重カウントを避けることです。 各石は、石の左上隅の可能性のある最大 4 つの角に影響を与えます。`2 × 2`それを含む正方形。 このような影響を受ける位置をすべて集めて無効な配置として扱うと、複数の石が同じマスに影響を与えるときに自然に重複が発生します。 これは、セットを使用して無効な左上隅をすべて保存することを提案します。 

最終的な答えは、配置の合計数から、すべての石から収集された個別の無効な配置の数を引いたものになります。

 ## アルゴリズムのチュートリアル

 1. 可能な総数を計算します。`2 × 2`空のグリッドへの配置`(n - 1) × (m - 1)`。 これは、正方形を配置できる可能性のあるすべての左上隅を表します。 
2. すべての左上隅を保存するセットを維持します。`2 × 2`少なくとも 1 つの石があるために無効になっているマス。 
3. にある各石について`(x, y)`、どちらかを決定します`2 × 2`属することができる正方形。 石は、左上隅が次のいずれかの正方形に配置できます。`(x, y)`、`(x-1, y)`、`(x, y-1)`、`(x-1, y-1)`ただし、それらの座標が有効な左上隅の境界内にある場合に限ります。 
4. 各候補の左上隅`(i, j)`、どうかを確認してください`1 ≤ i ≤ n-1`そして`1 ≤ j ≤ m-1`。 有効な場合は挿入します`(i, j)`無効なプレースメントのセットに追加されます。 
5. すべての石を処理した後、配置の合計数から無効なセットのサイズを減算します。 

これが機能する理由は、すべての無効な`2 × 2`正方形には少なくとも 1 つの石が含まれている必要があるため、その石を処理するときに発見する必要があります。 逆に、セットでは重複が排除されるため、含まれる石の数に関係なく、すべての正方形はセットに最大 1 回追加されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())
    
    total = (n - 1) * (m - 1)
    
    bad = set()
    
    for _ in range(k):
        x, y = map(int, input().split())
        
        # possible top-left corners of 2x2 blocks containing (x, y)
        candidates = [
            (x, y),
            (x - 1, y),
            (x, y - 1),
            (x - 1, y - 1)
        ]
        
        for i, j in candidates:
            if 1 <= i <= n - 1 and 1 <= j <= m - 1:
                bad.add((i, j))
    
    print(total - len(bad))

if __name__ == "__main__":
    solve()
```この解決策は、最初に完全な数を計算してから、無効な構成を削除することに依存しています。 候補生成ステップは重要な部分です。各石は一定数の潜在的な配置にのみ影響を与えるため、全体の作業は直線的です。`k`。 このセットにより、複数の石からの影響が重なり合って、過剰な減算が発生することがなくなります。

 ## 特殊なケース

 石のないグリッドは次の式で直接処理されます。`(n - 1) × (m - 1)`無効な正方形のセットは空のままであるためです。 このアルゴリズムでは挿入候補が生成されないため、減算では何も行われません。 

境界線上にある石のようなもの`(1, m)`有効な左上隅が境界内に留まっている場合にのみ、有効な左上隅に寄与します。 候補生成では、次のような無効な座標が自然に除外されます。`(0, m)`または`(1, m)`いつ`m`左上隅の制限を超えています。 

複数の石が同じ中にある場合`2 × 2`リージョン内で、それらはすべて同じ左上隅をセットに挿入しようとします。 このセットでは、この正方形が無効なセット内で 1 回だけカウントされることが保証され、過剰な減算が防止されます。 

完全にブロックされた`2 × 2`領域内のすべての石が同じ左上の候補を生成し、正方形が無効なセットに 1 回だけ含まれることが保証されるため、領域は正しく処理されます。
