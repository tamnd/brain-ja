 ## 解決策
 ## 問題の理解

 数字と疑問符で構成される文字列が与えられます。 それぞれの疑問符は未知の数字を表しており、疑問符を数字に置き換えることで形成できるすべての正の整数をカウントし、結果の数値の先頭にゼロがないようにしたいと考えています。 入力はそのような複数の文字列で構成され、それぞれが個別のテスト ケースを表し、文字列ごとに一致する正の整数の合計数を出力する必要があります。 

主要な制約は、文字列の長さが最大 ​​5 文字であることです。つまり、完全に疑問符で構成される文字列の可能性の総数は最大 5 文字です。$10^5 = 100,000$。 これは十分に小さいため、単純な乗算ベースの組み合わせアプローチでも制限時間内で快適に実行できます。 

明らかではないエッジ ケースは、先頭のゼロと 1 桁の文字列から生じます。 たとえば、テンプレート`0`ゼロは正ではないため、正の整数には一致しません。 のようなテンプレート`?5`有効ですが、`05`先行ゼロは禁止されているため、そうではありません。 もう 1 つの微妙な点は、次のような 1 文字の疑問符です。`?`、数字を一致させることができます`1`を通して`9`、有効な数値は 10 ではなく 9 になります。 

## アプローチ

 ブルートフォースアプローチは、疑問符の可能なすべての置換を生成し、各候補文字列を整数に変換し、それらの整数のうち、先頭にゼロがない正の整数がいくつあるかを数えるというものです。 これが機能するのは、最大長が 5 で、最悪の場合の候補が最大 100,000 個になるためです。`?????`。 単一のテンプレートの場合、すべての置換をループしてチェックすることもできますが、これにはネストされたループまたは再帰が必要となり、面倒です。 

最適なアプローチを自明にする重要な観察は、各テンプレートの有効な整数の数が単純な組み合わせ論によって直接計算できることです。 各疑問符は 10 個の可能性を表します。ただし、疑問符の場合、最初の文字をゼロにすることはできません。 したがって、各位置の可能性の数を増やすことができます。最初の文字が疑問符の場合、9 つのオプションがあります (`1-9`)、それ以外の場合は 1 のみ。残りの位置については、疑問符は 10 個のオプションを表し、桁は固定されています。 この乗算により、合計カウントがすぐに得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(10^長さ) | お(1) | 動作しますが、不要です |
 | 最適 | テスト ケースごとの O(長さ) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 これは、計算を繰り返す回数を制御します。 
2. テンプレート文字列ごとに`s`、最初の文字を確認してください。 疑問符の場合は、次のいずれかの数字を指定できます。`1`に`9`。 数字の場合`0`の場合、文字列は正の整数を表すことができないため、答えはゼロになります。 
3. カウンタを 1 に初期化します。これにより、可能性の数が累積されます。 
4. カウンタに最初の文字のオプションの数を掛けます。 疑問符の場合は 9 を掛けます。 ゼロ以外の数字の場合は 1 を掛けます。 
5. 文字列内の残りの文字ごとに、疑問符の場合は、カウンタに 10 (桁数) を掛けます。`0`に`9`)、それ以外の場合は固定なので 1 を掛けます。 
6. すべての文字を処理した後、カウンタを出力します。 これにより、テンプレートに一致する正の整数の数が得られます。 

機能する理由: このアルゴリズムは、カウンタが、処理された位置を置き換えることによって生成された有効な整数の総数と常に等しいという不変条件を維持します。 各乗算ステップでは、その位置の独立した選択肢の数が正確に計算され、最初の文字チェックにより、先頭にゼロが含まれる数値が決して含まれないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    s = input().strip()
    if s[0] == '0':
        print(0)
        continue
    count = 1
    for i, c in enumerate(s):
        if c == '?':
            if i == 0:
                count *= 9
            else:
                count *= 10
    print(count)
```コードは、次を使用してすべてのテスト ケースを効率的に読み取ります。`sys.stdin.readline`。 最初の文字チェックにより、ゼロで始まる無効な数値がカウントされるのを防ぎます。 すべての文字について、疑問符の場合は、正しい数の可能性が乗算されます。 このアプローチでは、ネストされたループと再帰が回避され、文字列の長さ (最大 5) に関して線形時間で実行されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    t = int(input())
    res = []
    for _ in range(t):
        s = input().strip()
        if s[0] == '0':
            res.append("0")
            continue
        count = 1
        for i, c in enumerate(s):
            if c == '?':
                count *= 9 if i == 0 else 10
        res.append(str(count))
    return "\n".join(res)

 ## 特殊なケース

 テンプレート`0`ゼロは正ではないため、すぐに最初の文字チェックがトリガーされ、0 が返されます。 のために`?`単一文字のテンプレートとして、乗算では 10 ではなく 9 つのオプション (1 ～ 9) がカウントされ、ゼロが正しく回避されます。 のようなテンプレート`03`または`0?`早期に発見され、次のようなテンプレート`?0?`最初の文字に 9 を掛け、残りの各疑問符に 10 を掛けて、90 を生成します。`?0`または900`?0?`、先行ゼロのルールを尊重します。 このアルゴリズムは、すべての 1 桁および複数桁のエッジ ケースを一貫して処理します。
