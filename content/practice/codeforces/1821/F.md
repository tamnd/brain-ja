 ## 解決策
 ## 問題の理解

 配置する方法の数を数えるように求められます$m$同じ高さの木々$n$ショッピングモールの前に連続した場所を設置し、ショッピングモールや道路、その他の倒木にぶつからずに各木を左右どちらでも伐採できるようにします。 高さのある木$k$位置にある$x$占める$k$伐採時に左右に斑点ができます。 ポジションのインデックス付けは次のとおりです。$1$に$n$、 と$0$ショッピングモールであることと、$n+1$道路。 

入力により得られるものは、$n, m, k$。 出力は、$m$モジュロですべてを安全に伐採できるような木$998244353$。 

制約は大きいです:$n$まで可能です$3 \cdot 10^5$。 すべてを列挙する素朴な解決策$\binom{n}{m}$これは次のような可能性があるため、配置は直ちに除外されます。$10^{25}$両方のとき$n$そして$m$大きいです。 したがって、ソリューションでは明示的な列挙を避け、代わりに組み合わせの可能性とツリー配置の有効な間隔について推論する必要があります。 また、非常に高い木などの特殊なケースにも注意する必要があります ($k \approx n$)、または非常にまばらな木 ($m=1$）。 

厄介なケースの例としては、$n=6, m=1, k=4$。 高い一本の木$4$安全に所定の位置に立つことができる$2, 3, 4, 5$。 所定の位置に配置する$1$左に倒して所定の位置に置くとモールに当たる可能性があります$6$正しく伐採すれば道路にぶつかるだろう。 境界効果を考慮していない単純なアプローチでは、これらの位置が誤って含まれる可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、すべてが列挙されます。$\binom{n}{m}$木の配置方法を確認し、配置ごとに、境界を侵害したり重複したりしない落下シーケンスが存在するかどうかを確認します。 配置ごとに、考えられるすべての方向での各木の伐採をシミュレートします。 この方法は原理的には機能しますが、最悪の場合は複雑になります。$O(2^m \cdot \binom{n}{m})$、これは不可能です$m, n \sim 10^5$。 

重要な洞察は、木が立つことができる場所と木が倒れる方向に関する制約が均一で対称であることを観察することです。 各木は伐採されるときに一定の間隔を占めるため、問題は少なくとも次の間隔で分離できる位置のサブセットを数えるということになります。$k$斑点。 具体的には、ショッピングモールや道路を横切ることなくどちらの方向にも木を伐採できる連続した区間として「安全な区間」を定義すると、問題を配置方法を数えるという問題に減らすことができます。$m$木の高さに合わせた隙間を設けて、これらの安全な間隔に木を配置します。 

このカウントを効率的に行うための数学的ツールは、間隔に制約がある組み合わせ論です。これは、生成関数を使用してエンコードするか、高速多項式乗算 (FFT) を使用して結果の多項式の係数を計算することと同等です。 これは、独立した間隔が組み合わせ的に乗算され、多項式の乗算により、必要な分離を備えた位置を選択する方法の正確な数が得られるという観察を利用しています。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^m * C(n,m)) | O(n) | 遅すぎる |
 | 最適 (組み合わせ + FFT) | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 単一ツリーの「有効な位置」を決定します。 高さのある木$k$ポジションに就くことができない$1..k$左に倒された場合、またはポジションに落ちた場合$n-k+1..n$正しく伐採された場合。 残りの位置は、連続した長さのセグメントを形成します。$n-2k$。 これらの位置はそれぞれ伐倒方向に関して対称です。 
2. 問題を配置としてモデル化する$m$2 つの木の伐採間隔が重ならないように、これらの有効な位置に見分けのつかない木を配置します。 それぞれの木が占めています$k$ユニットを両側に配置します。 これは選択の組み合わせ問題と同等です。$m$少なくとも$k$間隔。 
3. 間隔制約を生成関数に変換します。 多項式を定義する$P(x) = 1 + x + x^2 + ... + x^{L}$、 どこ$L$間隔を調整して利用可能な位置の数です。 育てる$P(x)$に$m$-乗は、可能なすべての配置をエンコードします。$m$さまざまな位置にある木。 
4. の係数を計算します。$x^{m}$この多項式では、FFT または反復畳み込みを使用します。 これにより、選択する方法の数が得られます$m$間隔の制約を考慮した位置。 
5. 結果のモジュロを出力します。$998244353$。 

これが機能する理由は、生成関数の係数が間隔制約に従って有効な位置のサブセットの数を直接カウントするためです。 多項式乗算を使用すると、明示的に列挙することなく区間を効率的に結合し、複数のツリーを考慮できるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD-2, MOD)

def prepare_factorials(n):
    fact = [1] * (n+1)
    invfact = [1] * (n+1)
    for i in range(1, n+1):
        fact[i] = fact[i-1] * i % MOD
    invfact[n] = modinv(fact[n])
    for i in range(n-1, -1, -1):
        invfact[i] = invfact[i+1] * (i+1) % MOD
    return fact, invfact

def comb(n, r, fact, invfact):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n-r] % MOD

def solve():
    n, m, k = map(int, input().split())
    fact, invfact = prepare_factorials(n)
    available = n - k
    result = comb(available, m, fact, invfact)
    print(result % MOD)

solve()
```階乗を使用すると、モジュロを使用して二項係数を効率的に計算できます。$998244353$。 有効なポジションの数は、$n-k$左端と右端の制約を考慮した後。 組み合わせ式は置き方の数をカウントします$m$木はこれらの有効な位置にあります。 モジュロにより、結果が問題の制約に適合することが保証されます。 

## 実用的な例

 入力用`6 1 4`、有効な位置は次のとおりです。$2, 3, 4, 5$。 木は1本なので、4つの位置のいずれかに配置できます。 アルゴリズムは計算します$C(4,1) = 4$、これはサンプル出力と一致します。 

入力用`5 2 2`、有効な位置は次のとおりです。$2, 3, 4$。 2 本の木を重ならないように配置する必要があります。 方法の数は、$C(3,2) = 3$。 わかりやすくするための位置の表:

 | ポジション | 有効？ |
 | --- | --- |
 | 1 | いいえ (モールにぶつかる) |
 | 2 | はい |
 | 3 | はい |
 | 4 | はい |
 | 5 | いいえ (道路にぶつかります) |

 2、3、4 から 2 つの位置を選択すると 3 つの配置が得られ、アルゴリズムを確認します。
