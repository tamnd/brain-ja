 ## 解決策
 ## 問題の理解

 指定された長さ _m_ の 2 つの整数を、それらの桁の合計が正確に _s_ になるように構築するように求められます。 これらの整数の 1 つは辞書順で可能な限り最小、もう 1 つは可能な限り最大でなければなりません。 数値がちょうど 0 の場合 (_m = 1_ および _s = 0_ の場合にのみ発生します) を除き、整数の先頭にゼロを付けることはできません。 

入力値には厳密な制限が課せられます。_m_ は 100 まで、_s_ は 900 までです。これは、長さ _m_ のすべての数値を単純に列挙することは完全に不可能であることを意味します。$10^m$候補者たち。 代わりに、完全な列挙ではなく、桁レベルの推論に依存する必要があります。 

エッジ ケースは主に、合計 _s_ が小さすぎるか大きすぎて _m_ 桁の数値を形成できない場合に発生します。 たとえば、_m = 3_ および _s = 28_ の場合、3 桁の最大合計は 27 (9 が 3 つ) であるため、どの数値もこれを満たすことができません。 同様に、ゼロの合計は 1 桁の数値でのみ達成可能です。 これらの制約を検証せずに数字を割り当てようとする不用意な実装は、先頭にゼロの付いた無効な数値を生成するか、サイレントに失敗します。 

## アプローチ

 ブルートフォース手法では、すべての _m_ 桁の数値を試し、その桁を合計し、_s_ と比較します。 これは正しいですが、最大 0 までの反復が必要となるため、大きな _m_ では明らかに不可能です。$10^{100}$この数字は、どのコンピューターの能力も天文学的に超えています。 

重要な洞察は、各桁が独立して合計に寄与し、先頭にゼロがないようにしながら、より小さい桁をより重要な位置に割り当てることで最小の数値を取得できるということです。 逆に、最初に大きな桁を割り当てると、最大の数値が得られます。 この貪欲なアプローチが機能するのは、合計の制約が各桁にわたって線形であり、長さの制約により、先頭のゼロを避けるために最初の桁を個別に考慮する必要があるためです。 

最小の数値の場合、数値を左から右に最小の有効な桁で埋め、残りの位置の合計が剰余になるようにします。 最大の数値の場合、左から右に有効な最大の数字を入力します。これは対称ですが、先頭の大きな数字に対する制限がないため、より単純になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(10^m) | お(1) | 遅すぎる |
 | 貪欲な数字の割り当て | O(m) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. _s = 0_ かどうかを確認します。 _m = 1_ の場合、最小値も最大値も 0 になります。それ以外の場合は不可能なので、-1 -1 を返します。 
2. _s > 9 × m_ かどうかを確認します。 true の場合、sum _s_ で _m_ 桁の数値を作成することは不可能なので、-1 -1 を返します。 
3. 最大の数値を見つけるには、各 _m_ 位置を左から右に繰り返します。 各位置に、9 と残りの合計の最小値である可能な最大の桁を割り当てます。 残りの合計からその桁を引きます。 
4. 最小の数値を見つけるには、位置を左から右に繰り返しますが、先頭にゼロがないことを確認する必要があります。 これには、残りの桁を合計して残りの合計を得ることができる、各桁の最小値を知る必要があります。 具体的には、_i_ の位置にある数字は少なくとも`max(0, remaining_sum - 9*(m-i-1))`。 最初の数字は 1 以上である必要があります。 
5. すべての数字を入力したら、それらを文字列に結合し、最小値と最大値を出力します。 

機能する理由: 各ステップで、残りの桁で有効な数値を構築できる極値 (最小または最大) を選択します。 これにより、最終的な数値が辞書編集上最小または最大であることが保証されます。 不変条件は、各桁を配置した後、残りの合計を残りの位置に分配できることです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

m, s = map(int, input().split())

if s == 0:
    if m == 1:
        print("0 0")
    else:
        print("-1 -1")
elif s > 9 * m:
    print("-1 -1")
else:
    # Largest number
    remaining = s
    largest = []
    for i in range(m):
        d = min(9, remaining)
        largest.append(str(d))
        remaining -= d
    # Smallest number
    remaining = s
    smallest = []
    for i in range(m):
        # Ensure first digit is at least 1
        if i == 0:
            d = max(1, remaining - 9*(m-i-1))
        else:
            d = max(0, remaining - 9*(m-i-1))
        smallest.append(str(d))
        remaining -= d

    print("".join(smallest), "".join(largest))
```コードは、自明のゼロおよび不可能なケースを処理することから始まります。 最大の数値を構築するのは簡単です。合計がなくなるまで、可能な限り最大の桁を割り当てます。 最小の数については、注意深く計算すると、`max(1, remaining - 9*(m-i-1))`残りの数字が残りの数字に合計されるようにし、先頭のゼロや無効な割り当てを防ぎます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    m, s = map(int, input().split())
    if s == 0:
        return "0 0" if m == 1 else "-1 -1"
    if s > 9 * m:
        return "-1 -1"
    remaining = s
    largest = []
    for i in range(m):
        d = min(9, remaining)
        largest.append(str(d))
        remaining -= d
    remaining = s
    smallest = []
    for i in range(m):
        d = max(1, remaining - 9*(m-i-1)) if i == 0 else max(0, remaining - 9*(m-i-1))
        smallest.append(str(d))
        remaining -= d
    return "".join(smallest) + " " + "".join(largest)

# Provided samples
assert run("2 15\n") == "69 96", "sample 1"
# Custom cases
assert run("1 0\n") == "0 0", "minimum single-digit zero"
assert run("2 0\n") == "-1 -1", "two-digit zero impossible"
assert run("3 27\n") == "999 999", "maximum sum for length 3"
assert run("3 2\n") == "101 200", "smallest number requires leading 1"
assert run("5 23\n") == "14999 99500", "intermediate sum case"

 | 1 0 | 0 0 | 1 桁のゼロは許可されます |
 | 2 0 | -1 -1 | 複数桁のゼロは不可能 |
 | 3 27 | 999 999 | 最大合計のエッジ ケース |

 ## 特殊なケース

 入力用`m = 1, s = 0`、アルゴリズムはすぐに戻ります`0 0`、唯一の有効なゼロを正しく処理します。 

入力用`m = 2, s = 0`、先頭のゼロを避けるために最初の桁は少なくとも 1 である必要がありますが、合計はゼロになります。 アルゴリズムはこの不可能性を検出し、出力します。`-1 -1`。 

のために`m = 3, s = 2`、最小の数値の計算により、最初の桁が次のようになります。`max(1, 2 - 9*2) = 1`、残りの合計 1 が次の 2 つに分配されます。
