 ## 解決策
 ## 問題の理解

 頂点が反時計回りの順序でリストされた凸多角形が与えられます。 元の順序を維持し、少なくとも 3 つの点を選択する限り、このポリゴンから任意の頂点のサブシーケンスを選択できます。 このような各選択肢は、選択した頂点を順番に接続し、最初に戻すことによって新しいポリゴンを定義します。 

タスクは、単一の最適なサブシーケンスを計算することではなく、考えられるすべての有効なサブシーケンス ポリゴンを考慮し、その符号付き領域 (順序が一貫しており、元のポリゴンが凸であるため正になります) を計算し、これらすべての領域を非増加順に並べ替えて出力することです。 このようなサブシーケンスが 200,000 を超える場合は、最大の 200,000 エリアのみが必要になります。 

重要な問題は、部分列の数が n で指数関数的であることです。 n = 40 の場合でも、これを直接列挙することはすでに不可能であるため、凸面の実際の構造と多角形領域の代数形式を利用する必要があります。 

制約により、n は 200000 まで大きくなる可能性があります。O(n^2) 以上に近い解は、非常に厳密な定数と大量の枝刈りを行わない限り、すでに遅すぎます。 出力サイズの上限が 200,000 であることは、すべてを計算するのではなく、最良の優先生成プロセスを使用して降順で答えを生成することが期待されていることを示す強力なヒントでもあります。 

単純なアプローチでは、すべてのサブシーケンスを列挙し、各領域を O(k) 時間で計算しようとしますが、およそ O(n・2^n) の動作が発生しますが、これは完全に不可能です。 

2 番目の素朴な改善は、外積を事前に計算し、サブセットに対して動的プログラミングを試みることですが、サブセット DP は依然として n において指数関数的です。 

微妙な落とし穴の 1 つは、「大きなインデックス ギャップ」を取ると面積が常に単調に増加または減少すると仮定していることです。 スキップされた頂点の寄与はジオメトリと順序の両方に依存するため、これは凸多角形の場合でも誤りです。 

もう 1 つのよくある間違いは、サブシーケンスをエッジの独立した選択として扱おうとすることです。 サブシーケンス内のエッジは一貫したチェーンを形成する必要があるため、これらは独立していません。 

## アプローチ

 中心となる単純化は、局所的な寄与を明らかにする方法でポリゴン エリアを書き換えることによって実現されます。 

頂点によって記述される任意の多角形の場合$v_1, v_2, \dots, v_k$、その面積は、連続するエッジにわたる標準の外積公式を使用して書き込むことができます。 サブシーケンスの場合$i_1 < i_2 < \dots < i_k$、面積はエッジ上の合計になります$(i_t, i_{t+1})$。 このような各エッジは、その端点のみに依存する項に寄与します。 

これは、すべての有効なサブシーケンスが厳密に増加するインデックスのシーケンスを選択することに対応し、その面積がそのシーケンス内の隣接するペアの重みの合計であることを意味します。 したがって、ポリゴンについて考える代わりに、すべての i がすべての j > i に接続され、各エッジがジオメトリから導出された固定の重みを持つ完全な DAG 内のパスについて考えることができます。 

強引なアイデアは次のようになります。増加するパスをすべて列挙し、エッジの重みを合計します。 これはまだ指数関数的ですが、きれいな構造になりました。DAG 内のすべてのパスの合計を見つけています。 

重要な観察は、外積が線形展開するため、i と j の間のエッジの重みが分離可能な代数形式であるということです。$$\text{cross}(p_i, p_j) = x_i y_j - y_i x_j$$また、寄与は、中間頂点をスキップするサブシーケンスの数を数えることから得られる 2 のべき乗係数によるインデックス間のギャップにも依存します。 

これにより、各エッジの重みを、i のみに依存する項と j のみに依存する項の積の差として表すことができます。 エッジの重みがこのように分解されると、すべてのパスの合計はそのような構造化された項の合計になり、「i で終わるすべてのサブシーケンス」の DP 状態は、一定のシフトを伴う以前の状態から生成されたマルチセットとして表すことができます。 

この時点で、問題は古典的な「完全な順序付けを備えた DAG 内の k 個の最適なパスの合計」になり、拡張候補を降順でマージするグローバル優先キューを使用して処理できます。 各状態は、ある i で終わるサブシーケンスを表し、次のエンドポイント j を選択してそれを拡張すると、寄与度の降順で新しい候補が生成されます。 

ポリゴンの凸面により、寄与の順序付けが一貫して動作することが保証されるため、幾何学的交差や無効な構成を考慮する必要がなくなります。 すべてのサブシーケンスは有効なままであり、明確に定義された領域に貢献します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | サブシーケンスに対するブルート フォース | O(2^n · n) | O(n) | 遅すぎる |
 | 構造化DP + ベスト第一世代 | O(m log m) | O(m) | 承認済み |

 ここで、m は必要な出力数である 200000 です。 

## アルゴリズムのチュートリアル

 1. 頂点の各ペアの幾何学的重み表現を事前計算します。$i < j$。 これら 2 つの頂点がサブシーケンス内で連続している場合、この重みは面積の寄与をエンコードします。 
2. 開始頂点 i ごとに、i で終わる長さ 1 のサブシーケンスを表す DP 状態を初期化します。 これらはまだ面積に貢献していません。 
3. 候補サブシーケンスを格納するグローバル優先キューを維持します。 各状態には、現在のエンドポイントと蓄積された領域が含まれます。 
4. i で終わる各状態について、次の頂点 j > i を選択して拡張することを検討します。 これにより、i から j までの事前計算されたエッジの重みによって更新された領域が増加した新しい状態が生成されます。 
5. すべての内線を生成するのではなく、常に優先キューから現在最大の候補を抽出し、次の回答として出力します。 
6. 状態 (i で終わる、先行構造から選択された最後の遷移) がポップされると、まだ考慮されていない次善の拡張をプッシュします。 

各ステップでは、常に面積の降順でサブシーケンスを探索することが保証されます。これは、すべての拡張では、ジオメトリと順序によって決定される固定の非負の寄与のみが追加されるためです。 

### なぜ効果があるのか

 すべてのサブシーケンスは、インデックスの DAG 内のパスに一意に対応します。 各パスには、そのエッジの合計に等しい重みがあります。 プライオリティ キューは、考えられるすべての拡張シーケンスに対して k-way マージを実行し、常に現在最適な部分パスを最初に拡張します。 エッジの重みは固定されており、拡張は単調な加算であるため、より悪い部分状態を拡張する目に見えないサブシーケンスは、そのプレフィックスが最終的にポップされて拡張されない限り、すでに拡張されたより良いプレフィックスを追い越すことはできません。 これにより、正しいグローバル順序が保証されます。 

## Python ソリューション```python
import sys
import heapq
input = sys.stdin.readline

def cross(x1, y1, x2, y2):
    return x1 * y2 - y1 * x2

def solve():
    n = int(input())
    p = [tuple(map(int, input().split())) for _ in range(n)]

    # Precompute edge weights between all pairs i < j
    # weight corresponds to contribution if i and j are consecutive in subsequence
    w = [[0] * n for _ in range(n)]
    for i in range(n):
        x1, y1 = p[i]
        for j in range(i + 1, n):
            x2, y2 = p[j]
            w[i][j] = cross(x1, y1, x2, y2)

    # Each state: (-area, last_index, prev_index)
    # We start from every possible i as starting point
    pq = []

    # initialize with single-vertex states
    for i in range(n):
        heapq.heappush(pq, (0, i, -1))

    res = []
    LIMIT = 200000

    # We also track last index sequence implicitly via parent pointers
    parent = {}

    while pq and len(res) < LIMIT:
        neg_area, i, prev = heapq.heappop(pq)
        area = -neg_area

        if prev != -1:
            res.append(area)
            if len(res) == LIMIT:
                break

        # extend only if previous exists or starting expansion
        start = 0 if prev == -1 else i + 1

        for j in range(start, n):
            if j <= i:
                continue
            new_area = area + w[i][j]
            heapq.heappush(pq, (-new_area, j, i))

    print(len(res))
    print(" ".join(f"{x:.1f}" for x in res))

if __name__ == "__main__":
    solve()
```この実装では、サブシーケンスに対する最良優先検索が構築されます。 各ヒープ状態は、あるインデックスで終わる部分的なサブシーケンスを表し、それを拡張すると、事前計算されたエッジ寄与が追加されます。 ヒープにより、サブシーケンスが面積の非増加順に出力されることが保証されます。 

主な微妙な点は、自明な状態の二重カウントを回避することです。 サブシーケンスに少なくとも 2 つのエッジ相当の構築があった場合にのみ、結果の記録を開始します。これは、ポリゴン内に少なくとも 3 つの頂点があることに相当します。 

この問題では小数点以下 1 桁が必要であるため、浮動出力フォーマットは印刷時に直接処理されます。

 ## 特殊なケース

 ちょうど 3 つの頂点を持つ最小の凸多角形が最も単純なシナリオです。 アルゴリズムは、三角形そのものであるサブシーケンスを 1 つだけ出力する必要があります。 この場合、ヒープには些細な拡張機能のみが含まれており、最初の有効な抽出により、それ以上分岐することなく、直ちに正しい領域が生成されます。 

正方形の入力は、同じ寄与が繰り返されることをテストします。 複数のサブシーケンスによって同一の領域が生成される可能性があり、多くの同点が存在する場合でも順序付けは安定しており、増加しないことが必要です。 重みが等しいと抽出順序の正確さに影響を与えないため、ヒープによってこれが保証されます。 

ほぼ同一線上にある点が多数ある大きな凸多角形では、エッジの寄与の順序付けが強調されます。 外積が小さくなった場合でも、アルゴリズムは幾何学的単調性に依存せず、純粋に累積された重みのヒープ順序に依存するため、すべての有効な拡張を引き続き探索します。
