 ## 解決策
 ## 問題の理解

 2 つの制約に従って、整数の配列を青または赤に色付けする方法の数を数えるように求められます。 1 つ目は辞書編集上の制約です。青色の要素をサブシーケンスとして抽出し、赤色の要素を別のサブシーケンスとして抽出する場合、青色のシーケンスは辞書編集順で赤色のシーケンスよりも厳密に小さくなければなりません。 2 つ目はローカル バランス制約です。連続する部分配列では、指定された値の青色の要素の数が、その値の赤色の要素の数と 2 以上異なることはできません。 

入力は最大で次の配列で構成されます。$2 \cdot 10^5$それぞれ同じ範囲の整数。 出力は有効な色のモジュロ数です。$998,244,353$。 以来$n$が大きいため、可能なすべての色付けを明示的に試行するアルゴリズムは実行不可能です。$2^n$可能性。 これにより、ブルートフォース列挙が即座に排除されます。 

数値が配列内に複数回出現する場合、明らかではないエッジ ケースが発生します。 たとえば、次のようなシーケンス`[1, 1, 2]`制約されている: 両方の場合`1`は青、どれも赤、これら 2 つを含む部分配列`1`sはアンバランスです。 同様に、配列が非降順でソートされている場合、同じ値の赤色の要素の後に出現する青色の要素は辞書編集上の順序に違反するため、辞書編集上の制約によって色分けが大幅に制限されます。 

辞書編集的な順序とローカルバランスの組み合わせは、有効な色分けが構造化されていることを意味します。繰り返される値は任意に分割できず、各値の最初の出現が割り当てを支配する傾向があります。 サブ配列のバランスを無視した単純な実装では、カラーリングが過剰にカウントされてしまいます。 

## アプローチ

 ブルートフォースアプローチは、すべてを生成することです。$2^n$色付け、青と赤のサブシーケンスの辞書編集順を確認し、すべてをスキャンします。$O(n^2)$アンバランスな部分配列。 これにより、$O(n^2 \cdot 2^n)$実現可能性をはるかに超えた仕事$n=2\cdot10^5$。 

重要な洞察は、ローカル バランス制約により、各値が非常に制約された方法で分割されることを観察することです。 具体的には、有効な色分けにおいて、各個別の値について、その値の出現を青と赤のブロックに分割し、サブ配列に 1 つの色が他の色よりも 2 つ以上余分に出現しないようにする必要があります。 これは、値のすべての出現を完全に青または完全に赤の連続セグメントに分割できること、および辞書編集順序により、値が最初に青で出現してから赤で出現することが保証されることを意味します。 

これは当然、素セットまたは区間マージのアプローチを示唆しています。 同じ値の出現をグループ化し、不均衡が発生する可能性のある重複する範囲をリンクすることにより、色を個別に選択できる独立したセグメントを識別できます。 有効な色の合計数は、各セグメントの選択肢の積になります。辞書編集上の制約により、配列全体のオプションは最大 3 つに減ります。

 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^2 \cdot 2^n)$|$O(n)$| 遅すぎる |
 | 最適 (間隔マージと独立したセグメントのカウント) |$O(n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. **各値の最初と最後の位置を特定します。** 配列内の個別の整数ごとに、その最初と最後の出現のインデックスを格納します。 これにより、その値のすべての出現を含む最小間隔が提供されます。 
2. **重複する間隔をマージします。** 最初に出現した順に間隔を移動します。 間隔が現在の実行間隔と重複する場合は、それを含むように実行間隔を延長します。 マージされた各間隔は、まとめて考慮する必要があるセグメントを表します。これは、その間隔内に不均衡があると制約がセグメント全体に伝播するためです。 
3. **独立したセグメントをカウントします。** マージされた各区間は、バランスと辞書編集上の条件を満たしながら 3 つの方法で色付けできます。つまり、すべて青、すべて赤、または辞書編集上の順序と一致する最小限の許容パターンでの分割です。 すべての間隔のカウントをモジュロで乗算します。$998,244,353$。 
4. **合計数を返します。** ステップ 3 の積により、配列の有効な色の数が得られます。 

正確さは 2 つの不変式に依存します。 まず、間隔のマージにより、不均衡を形成する可能性のある 2 つの位置が同じセグメントに含まれることが保証されます。 第 2 に、色の順序を決定する際に各値の最初の出現のみを考慮することで、辞書編集上の制約が自然に適用されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 998244353

def main():
    n = int(input())
    a = list(map(int, input().split()))
    
    first = {}
    last = {}
    for i, x in enumerate(a):
        if x not in first:
            first[x] = i
        last[x] = i
    
    intervals = sorted([(first[x], last[x]) for x in first])
    
    total = 1
    l, r = -1, -1
    for start, end in intervals:
        if start > r:
            l, r = start, end
            total = total * 3 % MOD
        else:
            r = max(r, end)
    
    print(total)

if __name__ == "__main__":
    main()
```コードの各セクションはアルゴリズムのステップを反映しています。 まず最初と最後のインデックスを記録し、次に間隔を並べ替えて順番に処理します。 重複する間隔は動的にマージされ、それぞれの独立したセグメントは合計カウントを 3 倍します。境界条件は初期化によって処理されます。`l`そして`r`に`-1`そのため、最初の間隔で常に乗算がトリガーされます。

 最終合計: 3

5
1 2 3 4 5
```すべての間隔は互いに素です: (0,0)、(1,1)、(2,2)、(3,3)、(4,4)。 それぞれに 3 を掛けると、$3^5 = 243$モジュロ$998244353$。

 ## 特殊なケース

 単一要素の配列`[42]`結果は単一の間隔 (0,0) になります。 コードはこの間隔に対して 3 を乗算して 3 を生成します。これは、単一の要素を青、赤に色付けしたり、最小限の分割を満たしたりできるため、正しい値です。 

すべて等しい値を持つ配列`[1,1,1]`は単一の間隔 (0,2) として扱われます。 3 を掛けると 3 つの有効な色が得られ、バランスを維持するために許可される青/赤のパターンがすべて考慮されます。 

値が交互に繰り返される配列`[1,2,1,2,1,2]`1 には間隔 (0,4)、2 には (1,5) の間隔があります。
