 ## 解決策
 ## 問題の理解

 私たちは総当たりのサッカートーナメントを開催しています$n$チーム。 各チームのペアは 1 試合だけプレーします。 

各チームの効率は次のように定義されます。$$\text{goals scored} - \text{goals conceded}$$トーナメント終了後、すべてのチームの効率が計算されます。 1 つのチームの効率が失われ、残りのチームの効率が与えられます。$n-1$チーム。 タスクは、不足している効率を判断することです。 

制約は非常に小さいです。 テスト ケースは最大 500 個あり、テスト ケースごとに最大 100 チームが存在します。 たとえ$O(n^2)$ここでの解決策は簡単です。 本当の課題は、欠損値を一意に決定する数学的特性を認識することです。 

よくある間違いは、試合結果を再構築する必要があると考えることです。 この声明は、私たちを試合のモデル化に誘惑する可能性のあるトーナメントの 1 つを提供しています。 欠落している効率はグローバル不変式から直接導出できるため、これは不要です。 

簡単な例を考えてみましょう。```
n = 2
known efficiencies = [5]
```一致するのは 1 つだけです。 1 つのチームに効率性がある場合$+5$、もう一方は効率が必要です$-5$。 答えは次のとおりです。```
-5
```もう 1 つの見落としやすいケースは、効率がマイナスの場合です。```
n = 3
known efficiencies = [-3, -7]
```正しい答えは次のとおりです。```
10
```絶対値を採用したり、効率が負ではないと仮定したりする不注意な実装は失敗します。 

3 番目のエッジケースは、既知の効率がすべてゼロである場合です。```
n = 4
known efficiencies = [0, 0, 0]
```欠けている効率も次のようになります。```
0
```ソリューションで使用される不変式は依然として完全に保持されます。 

## アプローチ

 強引な考え方は、トーナメントを再構築しようとすることから始まります。 すべての効率は多くの試合に依存するため、指定された値を満たすスコアを推測して、不足しているチームの効率を導き出すことを試みる場合があります。 

このアプローチはすぐに実用的ではなくなります。 総当りトーナメントには次の内容が含まれます$$\frac{n(n-1)}{2}$$各試合には多くのスコアの組み合わせが考えられます。 開催可能なトーナメントを検索する必要はまったくありません。 

重要な観察は、効率がどのように形成されるかを観察することから得られます。 

任意の試合で、チーム A が得点したとします。$x$ゴールとチームBのスコア$y$目標。 

チーム A は次のことに貢献します。$$x-y$$その効率に。 

チーム B は次のことに貢献します。$$y-x$$その効率に。 

これらの貢献を追加すると、次のようになります。$$(x-y)+(y-x)=0$$すべての試合は、すべてのチームの効率の合計に寄与しません。 トーナメントは単なる試合の集合体であるため、全チームの合計効率もゼロでなければなりません。 

効率が次の場合:$$e_1,e_2,\dots,e_n$$それから$$e_1+e_2+\cdots+e_n=0$$私たちは与えられています$n-1$彼らのうち。 それらの合計が$S$の場合、不足している効率は次のようになります。$$-S$$これにより、問題全体が指定された数値の合計に集約されます。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. 各テスト ケースについて、次の内容を読んでください。$n$。 
3. を読んでください。$n-1$既知の効率。 
4. それらの合計を計算します$S$。 
5. 出力$-S$。 

ステップ 5 が機能する理由は、トーナメント内のすべてのチームの効率の合計が常にゼロになるためです。 欠損値は、既知の値の合計を正確にキャンセルする必要があります。 

### なぜ効果があるのか

 すべての試合は、参加する 2 チームに相反する価値をもたらします。 どちらかのチームが勝った場合$x-y$、その他の利益$y-x$。 グローバル効率の合計に対するその一致の寄与の合計はゼロです。 

すべての試合の貢献度はゼロであるため、トーナメント全体が終了した後のすべてのチームの効率の合計もゼロになります。 不足している効率を次のようにします。$m$。 既知の効率の合計が$S$、 それから：$$S + m = 0$$これは次のことを意味します:$$m = -S$$アルゴリズムはこの値を正確に計算するため、常に正しい値になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(-sum(a))
```実装は数学的観察に直接従います。 

変数`a`を保管します$n-1$既知の効率。 それらの合計は Python の組み込み関数で計算されます。`sum()`関数。 すべてのチームの合計効率はゼロに等しくなる必要があるため、不足している効率は単純にその合計のマイナスになります。 

難しい境界条件はありません。 負の値、正の値、ゼロはすべて自然に処理されます。 Python では整数オーバーフローは問題になりません。また、固定幅言語であっても、指定された制約の下では値は非常に小さいままです。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        ans.append(str(-sum(a)))

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:

    sys.stdout = io.StringIO()

    out = sys.stdout.getvalue()

    sys.stdout = backup_stdout
