 ## 解決策
 ## 問題の理解

 価値を選択します$a_{n+1}$間$0$そして$m$。 その後、以前のすべての位置は次のように一意に決定されます。$$a_i = a_{i+1} \bmod i$$のために$i=n,n-1,\dots,1$。 

配列全体は単一の開始値から生成されます。 ～の選択肢がいくつあるか数えなければなりません$a_{n+1}$正確に生産する$k$すべての中で異なる数字$n+1$ポジション。 

制約は、プロセスをシミュレートできないことを直ちに示唆します。 両方$n$そして$m$到達できる$10^9$、まであります$2\cdot10^4$テストケース。 の値を反復するソリューション$a_{n+1}$、またはすべてのポジションを通してでも$1\ldots n$、無理です。 

主な課題は、モジュロ演算の繰り返しによって生成されるシーケンスの構造を理解することです。 

いくつかの特殊なケースは見落とされがちです。 

考慮する$n=2,m=0,k=1$。 唯一可能な選択肢は、$a_3=0$。 生成された配列は$[0,0,0]$、したがって、答えは次のとおりです$1$。 を仮定する式はどれも$m\ge1$ここで失敗するでしょう。 

考慮する$n=4,m=6,k=3$。 有効な選択肢は次のとおりです$5$そして$6$、答えを与える$2$。 個別の値の数は次の要素のみに依存するという単純な推測$a_{n+1}$大きいか小さいだけでは不十分です。 

考慮する$n=265,m=265,k=265$。 答えは$0$。 しかないので、$266$ポジション、取得$265$個別の値はすでに非常に制限されています。 のどの値を正確に理解するか$k$達成可能かどうかが問題の核心です。 

## アプローチ

 ブルートフォースソリューションでは、考えられるすべての値が試行されます。$x=a_{n+1}$から$0$に$m$。 それぞれについて、次のように生成します。$$a_n=x\bmod n,\quad a_{n-1}=a_n\bmod(n-1),\dots$$個別の値をカウントします。 

これは定義に直接従っているため、正しいです。 残念ながら、それには、$O(mn)$仕事。 両方のパラメータが到達すると、$10^9$、これはまったく不可能です。 

このブレークスルーは、繰り返されるモジュロ演算が実際に何を行うかを調べることから生まれます。 

させて$x=a_{n+1}$。 

もし$x<n$、 それから$$a_n=x\bmod n=x.$$以来$x<n$、より小さい数値でモジュロを適用すると、値が維持されるか、値が減少します。 シーケンス内に現れるすべての値は最大でも$x$。 

もし$x\ge n$、 それから$$a_n=x\bmod n.$$シーケンスの残りの部分全体は、次のもののみに依存します。$r=x\bmod n$。 

さらに重要なのは、ポジションの後に$n$、すべての値は最大でも$n-1$。 

個別の値がいくつ出現するかを理解しましょう。 

もし$x=0$、すべての要素は次のようになります$0$。 正確に 1 つの異なる値を取得します。 

もし$1\le x<n$、その後、シーケンスは値から始まります$x$、そして係数に達するたびに$x$、$$x\bmod x = 0.$$その時点より前の値はそのままです$x$。 その時点以降はそのままです$0$。 

したがって、配列には 2 つの異なる値が含まれています。$x$そして$0$。 

もし$x\ge n$、 書く$$r=x\bmod n.$$値$x$それ自体が位置に表示されます$n+1$、それ以前の位置はすべて のみに依存します。$r$。 

もし$r=0$、次に位置$1\ldots n$すべてです$0$。 個別の値は次のとおりです。$\{0,x\}$、正確に 2 つの異なる値が得られます。 

もし$1\le r<n$、次に位置$1\ldots n$のみを含む$r$そして$0$、位置を維持しながら$n+1$含まれています$x$よりも大きい$n$そして両方とは異なります。 したがって、正確に 3 つの異なる値が得られます。$$\{x,r,0\}.$$これは問題を完全に特徴づけています。 

個別の値の可能な数は次のとおりです。 

のために$k=1$、 のみ$x=0$。 

のために$k=2$、 どちらか$x\in[1,n-1]$または$x$はの正の倍数です$n$。 

のために$k=3$、$x\ge n$そして$x\bmod n\neq0$。 

のために$k\ge4$、答えはいつも$0$。 

この構造が分かれば、数えることは簡単な算術になります。

 ## アルゴリズムのチュートリアル

 1. もし$k=1$、唯一の有効な選択肢は$x=0$。 戻る$1$なぜなら$0$常に許可されます。 
2. もし$k\ge4$、 戻る$0$。 シーケンスには 3 つを超える異なる値を含めることはできません。 
3. もし$k=2$、値の 2 つのグループを数えます。 

まず、すべて$x$そのような$1\le x<n$。 それぞれが正確な値を生成します$\{x,0\}$。 

第二に、すべての正の倍数$n$を超えない$m$。 これらが生み出すのは、$\{x,0\}$同じように。 

カウントは$$\min(m,n-1)+\left\lfloor\frac{m}{n}\right\rfloor.$$4. もし$k=3$、すべての値をカウントします$x\ge n$非ゼロ剰余モジュロあり$n$。 

がある$$m-n+1$$区間内の整数$[n,m]$いつ$m\ge n$。 

その中で、$$\left\lfloor\frac{m}{n}\right\rfloor$$の倍数です$n$。 

それらの付与を削除すると、$$(m-n+1)-\left\lfloor\frac{m}{n}\right\rfloor.$$もし$m<n$、答えは$0$。 

### なぜ効果があるのか

 重要な不変条件は、計算後の$a_n=x\bmod n$、後続のすべての値はその剰余のみに依存し、それを超えることはありません。$n-1$。 

いつ$x<n$、値$x$係数が決まるまで変化せずに存続します$x$が適用され、その時点で$0$。 3 番目の値は表示されません。 

いつ$x\ge n$、値$x$それ自体は位置にのみ表示されます$n+1$。 残りの位置は、から生成されたシーケンスとまったく同じように動作します。$r=x\bmod n$のみを含めることができます。$r$そして$0$。 したがって、配列全体には、次の場合に 2 つの異なる値のいずれかが含まれます。$r=0$、または 3 つの異なる値の場合$r\neq0$。 

Since every possible$x$これらのケースのいずれかに該当する場合、カウント式は正確です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n, m, k = map(int, input().split())

        if k == 1:
            ans.append("1")

        elif k == 2:
            res = min(m, n - 1) + m // n
            ans.append(str(res))

        elif k == 3:
            if m < n:
                ans.append("0")
            else:
                res = (m - n + 1) - (m // n)
                ans.append(str(res))

        else:
            ans.append("0")

    sys.stdout.write("\n".join(ans))

solve()
```最初のブランチは一意の値を処理します$x=0$、これが単一の個別の数値を取得する唯一の方法です。 

2 番目のブランチは、正確に 2 つの異なる値を生成する 2 つのクラスをカウントします。 使用する`min(m, n - 1)`間隔が次の場合を正しく処理します。$[1,n-1]$許容範囲を超えて広がる$[0,m]$。 

3 番目のブランチは、次の数を数えます。$[n,m]$の倍数を引きます$n$。 小切手`m < n`間隔が空の場合に負の結果が生成されることを回避します。 

すべての算術演算は 64 ビット整数に快適に適合します。 Python の整数には制限がないため、特別な注意は必要ありません。
