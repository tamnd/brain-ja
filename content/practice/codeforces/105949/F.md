 ## 解決策
 ## 問題の理解

 すべての位置が 0 または 1 になるはずのバイナリ シーケンスが与えられていますが、一部の位置は現在不明です。 未知の位置は 0 または 1 で自由に埋めることができます。すべての未知の位置を埋めた後、反転の数を評価します。反転はインデックスのペアです。$i < j$の値が$i$は 1 であり、次の値は$j$課題は、この反転数ができるだけ大きくなるように、すべての未知の位置の置換を選択することです。 

入力は複数の独立したテスト ケースで構成されており、すべてのテスト ケースの合計の長さが十分に大きいため、二次戦略は直ちに不可能になります。 テスト ケースごとに線形または線形演算のアプローチが必要であり、位置ごとの定数係数のオーバーヘッドさえも重要です。 

重要な問題は、未知の位置がグローバルに相互作用することです。1 を早めに配置すると、後のすべてのゼロによる反転が増加しますが、0 を早めに配置すると、以前の位置によって形成される反転が減少します。 すべての割り当てを試すという単純な考えは指数関数的であり、1 つの位置での決定が左側と右側の両方への寄与に影響を与えるため、貪欲なローカル決定でさえ明らかに安全ではありません。 

すべての位置が不明な場合、微妙なエッジケースが発生します。 たとえば、入力の場合`???`、すべてを 1 で埋めると反転はゼロになりますが、次のように埋めると`111`もゼロになりますが、`110`1 つの反転が得られます。 これは、方向性の寄与を追跡せずに、1 つのタイプをグローバルに最大化するだけでは不十分であることを示しています。 

もう 1 つのエッジ ケースは、次のような固定制約を交互に使用することです。`1?0?1?0`、局所的な直観は交互の充填を示唆することができますが、最適な解決策は未知の分割からの寄与の全体的な蓄積に依存します。 

## アプローチ

 ブルートフォースアプローチはすべてを試みます$2^k$の割り当て$k$未知の位置、完成した各配列の反転数を計算し、最大値を選択します。 これは、可能なすべての完了を直接評価するため正しいですが、実行不能になるとすぐに実行できなくなります。$k$指数関数的な増加により、約 25 を超えると増加します。 以来$n$まで可能です$10^6$、このアプローチは単一のテスト ケースに対しても使用できません。 

さまざまなタイプのペアの寄与を分離すると、問題の構造はより単純になります。 すべての反転は、1 が 0 の前に現れるペアです。完全な割り当てについて考える代わりに、各位置が未来または過去の要素にどのように寄与するかを考えることができます。 重要な観察は、選択された 1 の寄与はその右側にあるゼロの数のみに依存し、選択された 0 の寄与はその左側にある 1 の数にのみ依存するということです。 未知の位置では方向を選択できますが、一度選択されると、その寄与は固定ビットのように動作します。 

これは、両側に存在する固定またはすでに決定された 0 と 1 の数のカウントを維持しながら、未知数の処理方法を決定する線形スキャン戦略を示唆しています。 最適な戦略は、グローバル構造を考慮して、ポジションごとに、それを 0 として扱うか 1 として扱うことが、最終的な反転合計に対してより大きな限界寄与をもたらすかを決定することになります。 これは、既知の 0 と 1 が左右にいくつあるかを事前計算し、増分ゲインの最大化に基づいて未知の位置を決定することで取得できます。

 ## アルゴリズムのチュートリアル

 推論を固定ビットと未知のビットからの寄与に分割しました。 

1. まず、固定 1 と固定 0 のプレフィックス数を計算します。 これにより、すべての位置で、左側に保証された 1 がいくつ存在し、右側に保証された 0 がいくつ存在するかを知ることができます。 これらの値は、未知の決定とは無関係に、固定ビットのみからのベースライン反転寄与を定義します。 
2. アレイをスキャンし、未知の位置を決定点として扱います。 未知の位置で$i$、これを 1 に設定すると、その後に現れるすべてのゼロによる反転が寄与します。 これを 0 に設定すると、その前にあるすべての値との反転が寄与します。 これら 2 つの効果は相補的であり、ローカルな近隣ではなくグローバルな分布に依存します。 
3. 未知の位置を評価するために、固定ゼロのサフィックス カウントと固定 1 のプレフィックス カウントを事前計算します。 This gives us immediate formulas for both choices: choosing 1 yields gain equal to remaining zeros on the right, and choosing 0 yields gain equal to existing ones on the left.
 4. 未知の位置ごとに、より大きな寄与を与える割り当てを選択します。 選択したゲインを答えに累積します。 
5. 元の位置の固定 1 と固定 0 によって厳密に形成されたベースライン反転カウントを加算します。これは、固定 1 に遭遇したときにまだ先にある固定ゼロの数をカウントすることによって、左から右への 1 回のパスで計算できます。 

重要な点は、寄与を左依存部分と右依存部分に分割すると、未知の位置が互いに干渉しないということです。 

### なぜ効果があるのか

 すべての反転は、位置のペアによって一意に決定されます。 このような各ペアは、最終カウントに 1 回だけ寄与します。 両方のポジションが固定されると、貢献度も固定されます。 一方または両方の位置が不明な場合、寄与はそれらの未知の位置をどのように割り当てるかによって完全に決定されます。 それぞれの未知の位置は、それを横切るペアに単調に影響するだけであるため、その最良の選択は、各側の反対の値の合計数にのみ依存します。 これにより、異なる未知の位置間の結合が排除され、独立した貪欲な決定が全体的に最適化されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()

        # prefix counts of fixed 1s
        pref1 = [0] * (n + 1)
        for i in range(n):
            pref1[i + 1] = pref1[i] + (1 if s[i] == '1' else 0)

        # suffix counts of fixed 0s
        suf0 = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            suf0[i] = suf0[i + 1] + (1 if s[i] == '0' else 0)

        base = 0
        ones = 0
        for i in range(n):
            if s[i] == '1':
                ones += 1
            elif s[i] == '0':
                base += ones

        ans = base

        for i in range(n):
            if s[i] == '?':
                gain_if_1 = suf0[i]
                gain_if_0 = pref1[i]
                ans += max(gain_if_1, gain_if_0)

        print(ans)

if __name__ == "__main__":
    solve()
```この解決策は、固定プレフィックスのカウントを構築することから始まり、どの位置でもその左側に確認済みのプレフィックスがいくつあるかを即座に知ることができるようになります。 固定ゼロのサフィックス配列は、右側で対称的な役割を果たします。 基本反転カウントは、左から右にスイープし、固定ゼロに遭遇したときにすでに見つかった固定反転の数をカウントすることによって計算されます。これは、固定構造とのみ相互作用する未知数の決定によって影響されないすべての強制反転を直接カウントします。 

次に、それぞれの未知の位置が独立して評価されます。 これを 1 として割り当てると、このアカウンティングでは他の未知数がまだコミットされていないため、右側に固定ゼロを持つ反転のみが作成されます。 これを 0 として割り当てると、左側に固定された反転のみが作成されます。 すべての位置でこれら 2 つの寄与の最大値を取ると、最適なローカル寄与が得られ、それらを合計すると、最適なグローバル寄与が得られます。 

微妙な点は、未知間の相互作用が評価における対称性によって暗黙的に処理されることです。各未知は固定構造のみを考慮しますが、すべての未知は一貫して扱われるため、未知のペアは選択された割り当てと一致する方向に 1 回だけ寄与します。

これらの例は、アルゴリズムがローカルなバランスではなく、境界を越えた寄与を最大化する方向に自然に意思決定を進めることを示しています。

 ## 特殊なケース

 のような入力の場合`????`、アルゴリズムはゼロの初期構造から完全にプレフィックス 1 とサフィックス 0 を計算するため、各位置は 1 に設定されることによる利点が減少します。最初の位置は 3、次に 2、次に 1 に寄与し、すべて 1 の完全にソートされた割り当てと一致します。 

のために`11001`、未知数は存在しないため、サフィックス配列とプレフィックス配列は基本計算以外には無関係です。 スイープは固定反転のみを正しくカウントし、3 を生成します。 

のために`1?0?1?`、それぞれの未知は、左の 1 と右の 0 を独立して比較します。 中間の未知数は位置に応じて非対称に影響を受け、貪欲な選択により、それぞれが二重にカウントされることなく、可能な限り最高の交差寄与を正確に提供することが保証されます。
