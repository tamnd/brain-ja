 ## 解決策
 ## 問題の理解

 この問題は、文字列で表される、それぞれ赤、緑、青の色の石の列を記述します。`s`文字「R」、「G」、および「B」。 リスのリスは最初の石から開始し、2 番目の文字列で指定された一連の色ベースの命令を実行します。`t`。 各指示は色に対応しています。リスが現在いる石が指示の色と一致する場合、リスは石を 1 つ進めます。 そうでなければ、彼女はその場に留まったままです。 すべての命令を実行した後、Liss の最終的な位置を計算するように求められます。位置には 1 から始まる番号が付けられます。 

文字列はそれぞれ最大 50 文字と短いため、時間制限を気にせずに命令を直接シミュレーションできます。 各命令は 1 回の比較と、該当する場合はインクリメントのみを必要とします。 50 個の命令と 50 個の石を使用すると、最大でも 50 回の操作が行われますが、これは 2 秒の制限時間内では無視できる程度です。 

複数の指示が現在の石の色と一致しない場合、微妙なエッジケースが発生します。 たとえば、次の場合`s = "RGB"`そして`t = "GGG"`, Liss は石 1 から決して移動しません。もう 1 つの潜在的な落とし穴は、1 から始まるインデックスを適切に処理することです。 単純にゼロベースの配列を処理すると、off-by-1 エラーが発生する可能性があります。 

## アプローチ

 ブルートフォースアプローチはリスの動きを直接シミュレートします。 変数から始めます`pos = 0`最初の石の場合 (内部計算ではゼロベース)。 各命令について、次のことを確認します。`s[pos]`指示と一致します。 そうであれば、インクリメントします`pos`。 これによりルールが正しくモデル化され、実装が簡単になります。 比較の数は次の長さに等しい`t`, そのため、最悪の場合でも 50 回の操作を実行しますが、これは許容範囲内です。 

入力サイズが非常に小さいため、より複雑なアルゴリズムは必要ありません。 重要な洞察は、これが純粋なシミュレーションの問題であるということです。 事前計算、データ構造、貪欲な戦略はパフォーマンスを向上させません。 最適なソリューションは総当たりシミュレーションと同じですが、1 から始まる出力を慎重に処理する必要があります。

 | --- | --- | --- | --- |
 | ブルートフォース / シミュレーション | O( | t | ) |
 | 最適化された | O( | t | ) |

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`pos = 0`Liss の現在の石のインデックス (ゼロベース) を表します。 この選択により、Python での文字列のインデックス作成が簡素化されます。 
2. 各文字を反復処理します。`instruction`文字列の中で`t`。 各文字は色の指示を表します。 
3. それぞれについて`instruction`、どうかを確認してください`s[pos]`それと一致します。 これは、指示が石の色と一致する場合にのみリスが移動するというルールをモデル化しています。 
4. 一致するものがあれば、インクリメントします。`pos`1つずつ。 それ以外の場合は、何もせずに次の指示に進みます。 
5. すべての命令を処理した後、出力します。`pos + 1`ゼロベースの位置から 1 ベースの位置に変換します。 

機能する理由: アルゴリズムは、次の不変条件を維持します。`pos`常にリスの現在の石のインデックスを表します。 各命令は順番に適用され、許可された場合にのみ動作が発生します。 命令を順番に繰り返すため、動きがスキップされたり、間違って繰り返されたりすることはありません。 最終的な出力は、内部の 0 から始まるインデックス付けから問題の 1 から始まる番号付けに正しく変換されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s = input().strip()
t = input().strip()

pos = 0  # zero-based index

for instruction in t:
    if s[pos] == instruction:
        pos += 1

print(pos + 1)
```このソリューションでは、まず両方の文字列を読み取って削除し、末尾の改行を削除します。 の`pos`変数は、0 から開始して現在の位置を追跡します。for ループは各命令を反復し、単一の等価性チェックとオプションのインクリメントを実行します。 最後に、結果は 1 から始まるインデックスとして出力されます。 一致する命令でのみインクリメントするように注意して、off-by-one エラーを回避します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    s = input().strip()
    t = input().strip()
    pos = 0
    for instruction in t:
        if s[pos] == instruction:
            pos += 1
    return str(pos + 1)
