 ## 解決策
 ## 問題の理解

 Polycarpus には一定数のキャンディーとたくさんの友達がいます。 彼は、すべての友人が正の数のキャンディーを受け取り、最も多くのキャンディーを受け取る友人と最も少ないキャンディーを受け取る友人の差ができるだけ小さくなるように、すべてのキャンディーを友人に分配したいと考えています。 入力により、キャンディーの総数という 2 つの整数が得られます。`n`そして友達の数`m`。 出力は次のシーケンスになるはずです。`m`合計すると次の正の整数`n`、最大の整数と最小の整数の差は最小限に抑える必要があります。 

制約を考慮すると、`n`そして`m`これは、単純な分散戦略が効率的に実行できるほど十分に小さいため、複雑なアルゴリズムのパフォーマンスを心配する必要はありません。 主な課題は、ディストリビューション自体について推論することです。 

重要なエッジケースは次のような場合です`n`で割り切れない`m`。 たとえば、Polycarpus に 10 個のキャンディーと 3 人の友人がいる場合、単純なアプローチでは、各友人にキャンディーを与えようとする可能性があります。`n // m = 3`キャンディーが 1 個残ることになります。 正しいアプローチは、配分のバランスをとるために、何人かの友達に追加のキャンディーを与えることです。`[4, 3, 3]`。 もう 1 つのエッジケースは次のような場合です`n`等しい`m`; 各友達は単にキャンディーを 1 つずつ受け取ります。 剰余を正しく処理しない不注意な解決策は、次のような入力に対して失敗します。`n % m != 0`。 

## アプローチ

 ブルートフォースアプローチは、あらゆる可能な分布を試してみることです。`n`間のキャンディー`m`友達と最大値と最小値の差を確認してください。 これにより最適な解が見つかることが保証されていますが、組み合わせの数は指数関数的に増加します。`n`そして`m`。 具体的には、パーティションの数は、`n`の中へ`m`正の整数は組み合わせであり、簡単に数千を超える可能性がありますが、問題の構造が単純であるため、これは不要です。 

これを最適化するための重要な洞察は、最も公平な分布は常にほぼ均一な分布であるということです。 すべての友達はどちらかを受け取る必要があります`floor(n / m)`または`ceil(n / m)`キャンディー。 させて`q = n // m`友達ごとのキャンディーの基本数になります。`r = n % m`残りになります。 その通り`r`友達が手に入れるべき`q + 1`キャンディーと残り`m - r`友達がもらう`q`キャンディー。 これにより、最大の差が 1 であることが保証されます。これは最小であり、すべての値が等しい場合には改善できません。`n % m != 0`、合計額に達しないでしょう`n`。

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`そして`m`入力から。 これらはキャンディーの総数と友達の数を表します。 
2. コンピューティング`q = n // m`各友達が受け取るべきキャンディーの基本数として。 これにより、誰もが少なくとも同じ最低額を受け取ることができます。 
3. コンピューティング`r = n % m`まだ配布する必要がある残りのキャンディーとして。 最大の差を最小限に抑えるために、これらの追加のキャンディーは友達ごとに 1 つずつ与えられます。 
4. サイズリストの作成`m`最初はどこで`r`要素は`q + 1`そして残りの`m - r`要素は`q`。 これはまさにそれを保証します`r`友達は追加のキャンディーを 1 つ受け取り、分配のバランスが取れます。 
5. リストをスペースで区切られた整数として出力します。 

なぜ機能するのか: 不変条件は、各友人が少なくとも受け取ることです。`q`キャンディー、そしてまさに`r`友達はもう 1 つのキャンディーを受け取ります。 すべての値の合計は、`q*(m-r) + (q+1)*r = n`、正確性を保証します。 最大値と最小値の差は最大でも 1 ですが、残りを分配するには友達に追加のキャンディーをもらう必要があるため、これは最小限です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
q, r = divmod(n, m)
result = [q + 1] * r + [q] * (m - r)
print(' '.join(map(str, result)))
```コードはまず、次を使用して商と余りを計算します。`divmod`これは、個別の除算とモジュロ演算よりもクリーンです。 リストは、以下を繰り返すことによって構築されます。`q + 1`その通り`r`回と`q`その通り`m - r`回。 使用する`join`整数を文字列に変換し、必要な形式で出力します。 残りを慎重に処理することでオフバイワンエラーが回避されます。`r`そして、すべての友達が正の整数を受け取るようにします。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    q, r = divmod(n, m)
    result = [q + 1] * r + [q] * (m - r)
    return ' '.join(map(str, result))

# provided samples
assert run("12 3\n") == "4 4 4", "sample 1"
assert run("10 3\n") == "4 3 3", "remainder distribution"

# custom cases
assert run("1 1\n") == "1", "minimum input"
assert run("100 1\n") == "100", "single friend, all candies"
assert run("100 100\n") == "1 "*100[:-1], "each friend gets one candy"
assert run("7 3\n") == "3 2 2", "small uneven distribution"
assert run("15 4\n") == "4 4 4 3", "uneven with remainder less than half"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 1 | 1 | 最小入力 |
 | 100 1 | 100 | 一人の友人がキャンディーをすべて手に入れる |
 | 100 100 | 1 1 ... 1 | 友達は最大限、配布は最小限 |
 | 7 3 | 3 2 2 | 剰余分布の正確性 |
 | 15 4 | 4 4 4 3 | 剰余 < m/2 の場合の剰余分布 |

 ## 特殊なケース

 いつ`n`等しい`m`、 のような`5 5`、各友達はちょうど 1 つのキャンディーを受け取ります。 アルゴリズムは計算します`q = 1`そして`r = 0`。 結果リストは`[1, 1, 1, 1, 1]`。 いつ`n`よりわずかに大きい`m`、 のような`7 3`、計算します`q = 2`そして`r = 1`。 最初`r`友人が受け取ります`q + 1 = 3`キャンディー、残りの2人が受け取ります`2`それぞれキャンディー。 これにより、最大差が正確に 1 になることが保証され、これを減らすことはできません。 このアルゴリズムは、追加の条件なしで両方のケースを適切に処理します。
