 ## 解決策
 ## 問題の理解

 n 個の場所と m 個の片道道路の有向グラフが与えられます。 どの道路を移動してもちょうど 1 分かかります。 トラベラーは常にノード 1 から開始し、通常の単一ソースの最短パスとは少し異なる質問をされます。すべてのノード i について、ノード 1 から i に到達するのに必要な最小時間が必要ですが、グラフは追加のテレポート エッジで拡張されます。 

各ノードは整数値 ai を持ちます。 指定された有向エッジの他に、追加のルールがあります。 ai と aj のビットごとの AND が aj に等しい場合、ノード i から 1 分以内にノード j に即座に「テレポート」できます。 言い換えれば、aj に設定されるすべてのビットは ai にも設定される必要があるため、aj は ai のビット単位のサブセットになります。 

したがって、各ノードはビット関係に応じて他の多くのノードに接続する可能性があるため、グラフは暗黙的に m エッジよりも大きくなります。 タスクは、この展開されたグラフ内のノード 1 からすべてのノードまでの最短距離を計算することです。 

制約は大きく、最大 200,000 ノードと 300,000 エッジ、最大 2^20 の値です。 すべてのテレポート エッジを明示的に構築するソリューションでは、最悪の場合の 2 次数のエッジが作成され、すぐに失敗します。 暗黙的な遷移を介したマルチソース BFS であっても、すべてのノードの繰り返しスキャンを避けるために慎重に構造化する必要があります。 

明示的なエッジに対する単純なダイクストラは、m 個の道路には問題ありませんが、テレポート条件により実際の困難が生じます。各 i について可能なすべての j をチェックすると、密なビット構成では約 O(n^2) の動作が発生します。 

すべての ai が同一である場合、特にすべてが 0 である場合、微妙なエッジ ケースが発生します。 その場合、すべてのノードは他のすべてのノードにテレポートできます。つまり、ノード 1 からの距離は最大 1 ステップに縮小します。テレポート エッジを完全に無視する単純な最短パスの実装では、ビット構造を通じて完全に接続されている場合でも、到達不能なノードが誤って返されてしまいます。 

もう 1 つのエッジ ケースは、ノード 1 に設定されているビットが非常に少ない場合です。 この場合、ビットマスクが a1 のサブセットであるノードにのみ到達できますが、これは非常に制限される可能性があります。 道路だけを通って到達できることを前提としたソリューションでは、多くのテレポート専用パスを見逃すことになります。 

## アプローチ

 ブルートフォースのアイデアは単純で、テレポート エッジを明示的なエッジとして扱います。 すべてのペア (i, j) について、ai & aj = aj であるかどうかを確認し、そうであればエッジ i → j を追加します。 次に、ノード 1 から BFS またはダイクストラを実行します。すべてのエッジの重みが等しいため、これは正しいです。 問題はエッジを構築するコストです。すべてのペアをチェックするには O(n^2) ビットの演算が必要ですが、2 × 10^5 ではまったく実行不可能であり、10^10 の比較を超えます。 

重要な観察は、テレポートのエッジが純粋にビットの包含によって決定されるということです。 固定ノード i の場合、aj が ai のサブマスクとなるすべてのノード j が必要です。 これは古典的な「ビットマスクのサブセット」関係であり、視点を逆転することを示唆しています。つまり、各 i からエッジを拡張する代わりに、マスクによってノードを編成し、サブセットに対してビット DP を使用します。 

ただし、個別のマスクの数は多くなります (2^20) が、SOS-DP スタイルの伝播を使用すれば管理可能です。 秘訣は、すべてのビットマスクについて、値がそのマスクと等しいノードまでの最適な距離を計算し、これらの値をサブセット関係全体に効率的に伝播することです。 

これを元のグラフ上の最短パスと組み合わせます。 まず標準的な BFS/ダイクストラを使用して m 個のエッジにわたる距離を計算しますが、そのプロセス中にサブセット関係に沿った高速遷移も必要になります。 テレポート エッジを明示的に追加する代わりに、マスクに到達すると、SOS DP 伝播を使用して、すべての状態にわたって合計 O(20 · 2^20) ですべてのサブセット マスクを緩和できる構造を維持します。 

したがって、ソリューションはハイブリッドになります。明示的なエッジ上の最短パスと、テレポート クロージャをシミュレートするためのビットマスク伝播です。

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべてのペアのエッジ) | O(n^2 + m) | O(n^2) | 遅すぎる |
 | 最適 (グラフ + SOS DP 伝播) | O((n + m) log n + 20・2^20) | O(n + 2^20) | 承認済み |

 ## アルゴリズムのチュートリアル

 遷移が 2 つのソース (指定されたエッジとビットサブセットテレポーテーション) から発生する最短距離が必要です。 

1. m 個の明示的なエッジのみを使用して、ノード 1 から標準最短パス (重みが 1 であるため BFS) を実行します。 これにより、道路移動のみを考慮した初期距離 d[i] が得られます。 これにより、テレポートなしで多くのパスをすでにキャプチャするベースラインが形成されます。 
2. 配列 best[mask] を作成します。ここで、mask は 20 ビット値で、+inf に初期化されます。 各ノード i について、best[ai] = min(best[ai], d[i]) を更新します。 これにより、既知の最良の距離を維持しながら、すべてのノードがビットマスク空間に圧縮されます。 
3. ここで、サブセット関係全体に情報を伝播します。マスク x の適切な距離がわかっていれば、y が x のサブマスクであるようなすべてのマスク y を改善できます。これは、マスク x を持つノードは、マスクが x のサブセットである任意のノードにテレポートできるためです。 
4. ビットマスク上で SOS DP を実行します。 0 ～ 19 の各ビット k および各マスク x について、ビット k が x に設定されている場合、best[x] を使用して best[x ^ (1 << k)] を緩和しようとします。 これにより、情報が大きなマスクから小さなマスクに伝播されます。 
5. DP が終了した後、best[mask] は、道路の移動とテレポート チェーンの両方を考慮した、値がまさにそのマスクであるノードに到達するための最小距離を表します。 
6. 同じ値を持つすべてのノードが同じテレポート構造を共有するため、ノード i の答えを best[ai] として割り当てます。 

重要な点は、テレポーテーション自体を連鎖させることができることです。 マスク x を持つノードに到達したら、任意のサブマスクに移動し、そこから同様に続行できます。 SOS DP クロージャは、この到達可能性ラティス全体を 1 つのパスでキャプチャします。 

### なぜ効果があるのか

 このアルゴリズムは、エッジがスーパーセットからサブセットにのみ移行するビットマスク ラティスにノードを圧縮します。 すべてのテレポート移動は、可能な 1 ビットのセットを厳密に減らすか、サブセット構造との一貫性を保ちます。 SOS DP は、到達可能なスーパーセット マスクが、テレポート ルールに正確に一致する、到達可能なすべてのサブセットに最適な距離を伝播することを保証します。 すべてのテレポート エッジの重みは等しいため、最短パスは 2^20 エッジにわたる明示的なグラフ走査を必要とせずに、この単調伝播を尊重します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

INF = 10**18

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    g = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)

    # BFS on original graph
    dist = [INF] * n
    dist[0] = 0
    q = deque([0])

    while q:
        u = q.popleft()
        for v in g[u]:
            if dist[v] > dist[u] + 1:
                dist[v] = dist[u] + 1
                q.append(v)

    MAXB = 20
    N = 1 << MAXB
    best = [INF] * N

    for i in range(n):
        best[a[i]] = min(best[a[i]], dist[i])

    # SOS DP: propagate from supersets to subsets
    for b in range(MAXB):
        for mask in range(N):
            if mask & (1 << b):
                if best[mask] < best[mask ^ (1 << b)]:
                    best[mask ^ (1 << b)] = best[mask]

    res = []
    for i in range(n):
        res.append(str(best[a[i]]) if best[a[i]] < INF else "-1")

    print("\n".join(res))

if __name__ == "__main__":
    solve()
```BFS フェーズでは、唯一の明示的なエッジである実際の道路のみを使用して最短距離を計算します。 配列圧縮ステップはノード距離をビットマスク空間にマッピングするため、テレポート動作はグラフ構造とは独立して処理できます。 

SOS DP ループは核となる変換です。 これは、マスクから 1 ビットを削除して得られたすべてのマスクに値を繰り返しプッシュします。これは、ノードがそのビット表現が含まれる任意のノードに到達できるという規則に一致します。 

すべてのテレポート動作はすでにその DP クロージャでエンコードされているため、最後に、各ノードは best[ai] からその応答を読み取ります。 

## 実用的な例

 ノードがサブセットテレポーテーションを可能にする値を持つ小さなグラフを考えてみましょう。 ノード 1 が道路でノード 2 に到達でき、ノード 2 にはノード 3 へのテレポートを可能にするマスクがあるとします。 

| ステップ | ノード | 距離 | 最高のアップデート |
 | --- | --- | --- | --- |
 | 初期化 | 1 | 0 | 最高[a1]=0 |
 | BFS | 2 | 1 | 最高[a2]=1 |
 | BFS | 3 | INF | 変更なし |

 BFS の後は、道路の到達可能性のみがわかります。 

SOS DP の後、a2 が a3 のスーパーセットの場合、best[a3] は 1 になります。 

これは、インターリーブではなく最短パスの計算後にテレポーテーションがどのように適用されるかを示しています。 

2 番目の例は、すべてのノードが同一のマスクを共有する場合です。 次に、best[mask] がそのマスクを持つすべてのノード間の最小 BFS 距離になり、サブセット関係が何も変わらないため、DP はそれ以上何もしません。 これにより、テレポーテーションによって新しい構造が追加されない場合、アルゴリズムが正しく縮退することが確認されます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + m + 20・2^20) | m エッジ上の BFS とビットマスク上の SOS DP |
 | スペース | O(n + 2^20) | 隣接リストとマスク DP 配列 |

 この制約により、約 10^8 の軽量操作が可能になり、20・2^20 はおよそ 2,000 万回の更新に相当し、制限内に問題なく収まります。

 ## 特殊なケース

 すべてのノードが同じマスクを持つ場合、すべてのノードはテレポート ルールを通じて相互に到達可能になります。 そのような状況でも、BFS は道路構造に応じて複数の距離を生成する可能性がありますが、DP ステップはすべてをそれらの距離の中で最小値に縮小します。これはテレポート ショートカットの存在と一致します。 

ノード 1 にマスク 0 がある場合、0 にはそれ自体以外にスーパーセットがないため、そこからのテレポート エッジは存在しません。 best[0] は値がゼロのノードのみをキャプチャするため、アルゴリズムは BFS のみの距離に正しくフォールバックします。 

ノードが BFS では到達できないが、スーパーセット マスクに到達した後にテレポート チェーン経由で到達できる場合でも、BFS の結果から最適なノードが初期化され、サブセットの伝播によって下方に拡張されるため、ノードは引き続きキャプチャされ、マスク構造を通じて間接的な到達可能性を回復できるようになります。
