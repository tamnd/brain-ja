## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input().strip())
    
    limit = int(n ** 0.5) + 1
    
    # sieve primes up to sqrt(n)
    is_prime = [True] * (limit + 1)
    primes = []
    for i in range(2, limit + 1):
        if is_prime[i]:
            primes.append(i)
            for j in range(i * i, limit + 1, i):
                is_prime[j] = False

    ans = 0

    def dfs(idx, cur, omega):
        nonlocal ans
        if cur > n:
            return
        
        # include current
        if cur > 1:
            ans = (ans + (n // cur) * pow(2, omega, MOD)) % MOD
        
        for i in range(idx, len(primes)):
            p = primes[i]
            if cur * p > n:
                break
            dfs(i + 1, cur * p, omega + 1)

    dfs(0, 1, 0)
    
    print(ans % MOD)

if __name__ == "__main__":
    solve()
```ふるいは、平方自由数を構築するために必要な素数集合を構築します。 DFS は、各平方フリー積を正確に 1 回列挙し、素数セットが繰り返されないようにします。 各州が貢献$2^{\omega(k)}$の倍数で重み付けされる$k$までのプレフィックスに嘘をつきます$n$。 

条件`cur * p > n`探索空間を早期にプルーニングし、制限を超える因子を構築しないようにします。 DFS インデックスの単調性により、各素数は分岐ごとに最大 1 回使用され、正方形のない構造が維持されます。 

貢献度は次の場合にのみ追加されます。`cur > 1`、 以来$k = 1$は空の素数集合に対応し、この分解では意味のある要素を表しません。

def brute(n):
