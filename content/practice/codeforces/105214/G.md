 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、$n$各ノードに自由に小文字を割り当てることができます。 ラベル付け後、ツリー内のすべての単純なパスは一連の文字となり、そのエンドポイント間の一意のパスに沿って読み取られます。 

短いパターンワードも与えられます$w$長さは最大でも 3 です。 タスクは、連結されたラベルが正確に一致する有向単純パスの数が一致するようにノード ラベルを選択することです。$w$できるだけ大きいです。 有向パスとは、順序付けられたノードのペアを選択することを意味します$(u, v)$からのユニークなシンプルなパスに沿って文字を読みます。$u$に$v$。 

基礎となるグラフはツリーであるため、ノードの各ペアは正確に 1 つの単純なパスを定義するため、唯一の自由はノードに文字を割り当てる方法だけになります。 

制約$n \le 3 \cdot 10^5$割り当てごとまたはパスごとの貢献を明示的に評価しようとするソリューションは直ちに除外されます。 すべてのパスを数えることさえ、単純な意味ではすでに二次関数であるため、有効な解決策は問題を次数やエッジなどのツリーの局所的な構造特性に帰着させる必要があります。 

いくつかのエッジの状況が重要です。 

もし$w$長さが 1 の場合、単一ノードは自明なパスであるため、すべての単一ノードが独立して有効なパスに寄与します。 

もし$w$長さが 2 の場合、順序付けされた文字のペアに一致する有向エッジをカウントします。 

もし$w$長さが 3 なので、長さ 2 のパスを数えます$u \to v \to x$したがって、中間ノードを中心とするパスのみが問題となります。 

単純なアプローチでは、文字を割り当ててから、すべてのパスをチェックして寄与を再計算しようとしますが、単一の割り当てを評価するだけでも必要なため、失敗します。$\Theta(n^2)$木の中の小道。 

## アプローチ

 主な困難は、固定されたラベル付けのパスをカウントするのではなく、カウントを最大化するラベル付けを選択することです。 語長は最大でも 3 であるため、有効なパスの構造は非常に局所的になり、各ケースはノードまたはエッジでの単純な組み合わせ最適化に崩壊します。 

ブルートフォース手法では、すべてのノードに文字を割り当ててから、一致するパスをカウントしようとします。 たとえ、関連する文字に限定したとしても、$w$、割り当ての数は指数関数的です$n$、これは絶望的です。 

構造上の観察によると、長さ 3 以下の有効なパスはすべて、一定サイズの近傍によって完全に決定されます。 

長さ 1 の場合、ノード自体のみが問題になります。 

長さ 2 の場合、エッジのみが問題になります。 

長さ 3 の場合、中心ノードとその入射エッジのみが問題になります。 

これにより、ツリーが独立したノード、独立したエッジ、またはノードの周りの独立したローカル スター構造のいずれかに折りたたまれます。 

その独立性こそが、$O(n)$解決。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数関数 /$O(n^2)$割り当てごとのカウント |$O(n)$| 遅すぎる |
 | 最適 |$O(n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 単語の長さに基づいて問題を処理します$w$。 

### ケース 1:$|w| = 1$1. すべてのノードには 1 つの文字でラベルを付けることができます$w[0]$。 
2. すべてのノードは、長さ 1 の有効なパスを個別に形成します。 

答えは単純です$n$これは、各ノードが 1 つの有効な有向パスに寄与するためです。 

### ケース 2:$|w| = 2$1. 単語は 2 文字です。$w = ab$。 
2. 有効なパスは、有向隣接ペアに正確に対応します。$(u, v)$そのような$u$ラベルが貼られている$a$そして$v$ラベルが貼られている$b$。 
3. 各無向エッジは、エンドポイントの割り当て方法に応じて、最大 1 つの有効な有向パスに寄与します。 

ここで、各エッジが最大 1 つの有効な方向に寄与できることに注目してください。可能であれば、すべてのエッジがそのような方向の一致を 1 つだけ寄与するようにしたいと考えています。 ツリーは 2 部構成であるため、ノードを 2 つのセットに色分けし、一方の側を割り当てることができます。$a$、もう一方$b$。 その後、すべてのエッジが反対側の文字を接続するため、すべてのエッジが 1 つの有効な有向パスに寄与します。 

したがって、最大値は$n - 1$、文字の任意の 2 分割割り当てによって達成されます。$a$そして$b$。 

### ケース 3:$|w| = 3$1. 言葉には形がある$w = abc$。 
2. 有効なパスは 3 つのノードです$u \to v \to x$、 どこ$v$は中間ノードです。 
3. これにより、$v$手紙を運ぶ$b$、 その間$u$そして$x$の隣人でなければなりません$v$ラベルが貼られた$a$そして$c$順番に。 

ノードを修正する$v$割り当てられた手紙$b$。 いくつかの近隣にラベルを付けます$a$そしていくつかはラベルが貼られています$c$。 すべての有効なパスの中心は次のとおりです$v$どれかを選択することで形成されます$a$-隣人と1人$c$-隣人なので、$v$は$$(\#a\text{-neighbors of }v) \cdot (\#c\text{-neighbors of }v).$$次に、各ノードの隣接ノードの数を選択します。$a$、$b$、 または$c$この合計を最大化します。 

重要な簡略化は、ラベルが付けられたノードのみがラベル付けされていることです。$b$したがって、どのノードがパスの中心として機能するかを効果的に決定しています。 複数選択する場合$b$-node では、すべてのノードがグローバルに固定ラベルを持っているため、近隣の割り当てが干渉します。 この結合により、単一の最適な中心の周りにすべての構造を集中させる場合と比較して、多中心のソリューションは最適化されません。 

そこで、単一のノードを選択してみます$v$ユニークなものとして$b$すべてのコントリビューションを生成する - ラベル付きノード。 その後、他のすべてのノードが次の間で分割されます。$a$そして$c$、およびそれに付随するエッジのみ$v$案件。 

させて$d = \deg(v)$。 隣接するものを次のように分割します。$x$ラベルが貼られた$a$そして$d-x$ラベルが貼られた$c$。 貢献度は、$$x(d-x),$$これは、分割が可能な限りバランスが取れているときに最大化され、$$\left\lfloor \frac{d^2}{4} \right\rfloor.$$すべてのノードにわたってそのような最良の値を採用します。 

## なぜ機能するのか

 長さ 3 の有効なすべてのパスには一意の中心ノードがあるため、パスをカウントすることは、中心にわたる独立した寄与を合計することと同じです。 センターとして選択されなかったノードは寄与せず、責任を複数のセンターに分割すると、グローバルなラベルの競合が発生し、達成可能な隣接パーティションが減少します。 すべての寄与を最良次数ノードに集中させると、その隣接関係を 2 つのグループに最適に分割でき、順序付けされた隣接ペアの数が最大化されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    w = input().strip()

    if len(w) == 1:
        print(n)
        return

    edges = []
    deg = [0] * (n + 1)

    for _ in range(n - 1):
        u, v = map(int, input().split())
        deg[u] += 1
        deg[v] += 1

    if len(w) == 2:
        print(n - 1)
        return

    ans = 0
    for i in range(1, n + 1):
        d = deg[i]
        ans = max(ans, (d * d) // 4)

    print(ans)

if __name__ == "__main__":
    solve()
```この実装は 3 つの構造的なケースを直接反映しています。 最終的な式はローカル次数情報のみに依存するため、エッジ リストは次数を計算するためにのみ使用されます。 

唯一の微妙な点は、長さが 3 の場合です。$(d^2)//4$最適な分割を正しく実装します$x(d-x)$すべてのパーティションを明示的に試す必要はありません。

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n = int(input())
    w = input().strip()

 ## 特殊なケース

 のために$|w| = 1$、アルゴリズムはすべてのノードに同じ文字を割り当てます。 次のような単一ノード入力`1`唯一のノードが有効な長さ 1 のパスを形成するため、1 つの有効なパスが正しく生成されます。 

のために$|w| = 2$、長いチェーンなどのパスでも正確に結果が得られます。$n-1$なぜなら、すべてのエッジは二部割り当てによって交差させることができるからです。 このアルゴリズムは、ツリーが 2 部構成であるという事実を暗黙的に使用するため、エッジの競合は発生しません。 

のために$|w| = 3$、次数のノードを考えます$d$。 アルゴリズムはそれを一意の中心として割り当て、近隣を最適に分割します。 スターグラフで次のように入力します`5 abc`エッジの中心が 1 の場合、計算では明示的に次のように評価されます。$d=4$、与える$4$、形成可能な順序付けされた隣接ペアの数に一致します。 

これらのケースは、すべての寄与がローカル構造によって捕捉され、ノード間の相互作用が見逃されないことを確認します。
