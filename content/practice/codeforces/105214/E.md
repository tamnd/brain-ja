 ## 問題の理解

 私たちは 2 つの層の組み合わせ論を扱っています。 まず、テキスト文字列があります$S$長さの$n$アルファベット以上の大きさ$k$、 どこ$k$非常に大きくなる可能性があり、最大で$10^9$, したがって、文字は具体的な文字ではなく、抽象的なラベルとして考える必要があります。 次に、パターン文字列を考慮します。$P$長さの$m$, ただし、文字が 2 回以上出現しないパターンのみが許可されます。

タスクは、これを 1 つのペアについて評価することではなく、合計することです。$F(S, P)$考えられるすべての文字列にわたって$S$長さの$n$およびすべての有効なパターン$P$長さの$m$、モジュロ$10^9+7$。 

制約構造はすでにソリューションを形成しています。 アルファベットのサイズは最大です$10^9$文字の反復やシンボルに対する頻度表の構築に依存するアプローチは直ちに除外されます。 実際の構造は、実際のキャラクターのアイデンティティからではなく、立場間の平等性がどのように動作するかによって決まる必要があります。

重要なエッジケースは、「美しい」パターンの定義から生じます。 各文字は最大 2 回出現するため、パターンには多くの繰り返し記号を含めることができますが、繰り返しの深さは非常に限られています。 たとえば、次のようなパターン$aab bcc$有効ですが、$aaa$そうではありません。 単純なアプローチでは、パターンを任意の文字列として誤って扱い、構造上の制限を無視する可能性があり、これにより大幅にカウントが過剰になる可能性があります。

## アプローチ

 ブルートフォースのアイデアは、すべての可能な文字列を反復処理することです。$S$、次にすべての有効なパターンにわたって$P$、各ペアについて計算します$F(S,P)$貪欲スキャンを使用します。 ペアを修正しても、計算$F(S,P)$は$O(n)$したがって、これはすぐに次のようなものになります$O(k^n \cdot \text{validPatterns} \cdot n)$、概念的にも不可能です。 

以下のことを観察すると、少し単純化できます。$F(S,P)$～の発生のみに依存する$P$内部$S$、つまり固定用$P$全体にわたって予想される発生を数えてみることもできます$S$。 これは視点を変えることを示唆しています。文字列を列挙する代わりに、パターン出現構造をどのように埋め込むことができるかを数えます。$S$。 

重要な構造的洞察は、次の制約から得られます。$P$。 すべての文字は最大 2 回出現するため、どのパターンでもその位置に対するパーティション構造が誘導されます。各シンボルは、シングルトンの位置、または同じでなければならない位置のペアを定義します。$S$。 これは、有効なすべてのことを意味します$P$のセットパーティションに対応します$\{1,\dots,m\}$ここで、各ブロックのサイズは 1 または 2 です。 

今、再解釈してみます$F(S,P)$。 それぞれの発生$P$で$S$長さの窓です$m$ここで、等価制約は次の制約と一致します。$P$。 重複しない発生を最大化することは、可能な限り多くの互いに素なウィンドウを選択することになり、これは開始位置の数を数えるのと同じです。$i$そのような$S[i..i+m-1]$マッチ$P$、それから欲張ったパッキングを取ります。 すべてのウィンドウの長さが等しいため、Greedy が最適です。 

したがって、固定ペアの場合$(S,P)$、$F(S,P)$は単に次の出現回数です。$P$で$S$重複しない出現、つまり位置での出現を取得する場合$i_1 < i_2 < \dots$と$i_{t+1} \ge i_t + m$。

これにより、問題は、長さの重み付けされたタイリングをカウントすることに縮小されます。$n$サイズのブロックごとの配列$m$ここで、各ブロックは、そのブロック構造と互換性のある有効なパターンの数に等しい重みを持ちます。 

重要な単純化は、パターンとブロックの互換性は、実際のシンボルではなく、内部的に適用される等価対の数のみに依存するということです。 アルファベットのサイズが大きいため、各等価クラスは単に新しい記号の選択に対応するため、各パーティションは次の係数に寄与します。$k^{\#\text{distinct classes}}$。 各クラスのサイズは 1 または 2 であるため、クラスの数は$m - (\text{number of pairs})$。

 ## アルゴリズムのチュートリアル

 計算を 2 つの独立した層で書き直します。パターンの重みの計算と、文字列の長さ全体にわたる DP の配置です。 

まず、有効な長さのパターンがいくつあるかを事前計算します。$m$まさに持っています$t$等しい文字のペア。 選択する$t$ペアとは選択することを意味します$2t$範囲外のポジション$m$次に、それらをペアにして、各接続コンポーネントにアルファベットの記号を割り当てます。 各ペアは個別のシンボルの数を 1 つ減らすため、次のようなパターンになります。$t$ペアで使用する$m - t$明確なシンボル。 

そこで係数を計算します$W[t]$、まさに美しいパターンの数$t$ペアとして$$W[t] = \binom{m}{2t} \cdot (2t-1)!! \cdot k^{m-t}$$どこ$(2t-1)!!$のペアをカウントします$2t$選ばれたポジション。 

第二に、私たちは解釈します$F(S,P)$全体的に集計された$S$長さ全体にわたるタイリングプロセスとして$n$。 のコピーを配置するたびに、$P$、消費します$m$連続ポジション。 配置が重複しないため、効果的にいくつかのブロックを選択することになります。$x$、そのような$xm \le n$。 

各ブロックは独立して制約に寄与します。$S$, したがって、貢献度の合計は次の合計になります。$x$ここで、各配置はパターンの重みからの寄与を乗算します。 

これにより、次のような DP が得られます。$dp[i]$プレフィックス長の合計寄与度です$i$、遷移は次のとおりです。$$dp[i] = dp[i-1] \cdot k + dp[i-m] \cdot C$$ここで、最初の項は自由な文字を追加し、2 番目の項は合計パターンの重みに寄与する新しい強制パターン ブロックを開始します。$C = \sum_t W[t]$。 

最後に、ブロックを配置できる最大の方法の数によって重み付けされたすべての有効なエンドポイントを合計します。$n$。 

アルゴリズムは、パターン列挙から導出された事前計算された定数を使用した線形 DP になります。 

## なぜ機能するのか

 正しさは、独立性を 2 つの軸に沿って分離することで得られます。 まず、アルファベット サイズが大きいため、構造が固定されると、パターン内の等価制約が独立したシンボル割り当てとして動作することが保証されます。 2 番目に、重複しない出現により、文字列がサイズの独立したブロックに分割されます。$m$または単一の文字。 これにより、線形 DP 状態遷移を除いて、異なるパターン配置間の相互作用が排除されます。 したがって、すべての構成が固有のセグメント化を引き起こすため、DP はすべての有効な構成を 1 回だけカウントします。$S$自由な位置とパターンに合わせたセグメントに分割します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mod_pow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve():
    n, m, k = map(int, input().split())

    # factorials for pairing counts
    fact = [1] * (m + 1)
    invfact = [1] * (m + 1)
    for i in range(1, m + 1):
        fact[i] = fact[i - 1] * i % MOD
    invfact[m] = mod_pow(fact[m], MOD - 2)
    for i in range(m, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    def nC(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

    # count matchings on 2t elements: (2t-1)!!
    max_pairs = m // 2
    double_fact = [0] * (max_pairs + 1)
    double_fact[0] = 1
    for t in range(1, max_pairs + 1):
        double_fact[t] = double_fact[t - 1] * (2 * t - 1) % MOD

    total = 0
    for t in range(max_pairs + 1):
        ways_pairs = nC(m, 2 * t) * double_fact[t] % MOD
        contrib = ways_pairs * mod_pow(k, m - t) % MOD
        total = (total + contrib) % MOD

    # DP over string length: choose placements of blocks of size m
    dp = [0] * (n + 1)
    dp[0] = 1

    for i in range(1, n + 1):
        dp[i] = dp[i - 1] * k % MOD
        if i >= m:
            dp[i] = (dp[i] + dp[i - m] * total) % MOD

    print(dp[n] % MOD)

def main():
    solve()

if __name__ == "__main__":
    main()
```階乗事前計算は、パターン内の位置を選択してペアにする方法が何通りあるかを数えるためにのみ使用されます。 二重階乗ループは、選択したペアの位置での完全一致の数を構築します。これは、まさに「最大 2 回出現」という制約の下で繰り返される文字を配置できる方法の数です。 

次に、DP は文字列の構築をステップバイステップのプロセスとして解釈します。つまり、単一の制約のない文字を配置して、$k$または、次のサイズの完全なパターン ブロックを固定します。$m$、すべての有効なパターンの事前計算された合計重みに寄与します。 

両方の遷移が同じ状態を更新し、互いに素な構造の選択を反映する必要があるため、遷移の順序には注意が必要です。

 ## 特殊なケース

 いつ$k = 1$、すべての文字列$S$は同一であるため、DP はパターン配置の純粋なカウントに集約されます。 アルゴリズムはこれを処理します。$k^{m-t}$項は 1 になり、パターンの構造的な数だけが残ります。 

いつ$m = 1$、すべてのパターンは自明に有効であり、すべての出現は独立しています。 DP は繰り返し乗算することで減少します。$k$これは、すべての位置が有効な一致であるという事実と一致します。 

いつ$m = 2$、ペアリング構造は最小限であり、計算は等しい文字パターンと異なる文字パターンを区別することに減ります。 アルゴリズムには両方が正しく含まれています$k^2$そして$k$これら 2 つのケースに正確に対応する貢献。
