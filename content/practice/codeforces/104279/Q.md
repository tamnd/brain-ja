 ## 解決策
 ## 問題の理解

 長さの配列が与えられます$2n$、最初はすべてゼロです。 も承っております$n$間隔の割り当て操作。 それぞれの操作$i$セグメントが付属しています$[l_i, r_i)$適用すると、その半開区間内のすべての位置が値で上書きされます。$i$。 重要な点は、これらの操作が固定された順序で実行されないことです。 適用する前にそれらを任意に並べ替えることができます。後の操作で以前の操作が上書きされるため、最終的な配列は選択された順序に依存します。 

すべての割り当てが何らかの順序で実行された後、最終的な配列内の隣接する位置は等しい場合もあれば、等しくない場合もあります。 可能なすべての操作順序にわたって 2 つの値を決定するように求められます: 最小可能なインデックス$i$そのような$a_i \ne a_{i+1}$、およびそのようなインデックスの可能な最大値。 

制約は大きく、$n$まで$10^5$。 すべての間隔にわたるすべてのエンドポイントが順列を形成するため、各操作は順列のような構造内の位置にまたがります。$[1, 2n]$。 この構造は重要です。すべての位置は一意の左エンドポイントまたは一意の右エンドポイントのいずれかであるため、間隔の境界は厳密にインターリーブされ、エンドポイント間に重複はありません。 演算の順列をシミュレートしたり、順序ごとに最終配列を再計算したりするソリューションは、直ちに実行不可能です。$n!$可能な注文と単一のコストのシミュレーションも可能$O(n)$または$O(n \log n)$。 

素朴な試みは、順序を修正し、結果の配列を構築し、最初の不一致を計算することです。 これはもう$O(n^2)$順序ごとであり、順列による乗算は不可能です。 考えられるすべての順列をチェックすることさえ明らかに不可能です。 

より微妙な障害モードは、左側のエンドポイントを増やすか長さを増やすことによって常に間隔を適用するなど、貪欲な順序付けがローカルで機能すると仮定することで発生します。 これらのヒューリスティックは、重複する間隔間のグローバルな相互作用を捕捉しません。これは、単一の長い間隔が順序に応じて多くの短い間隔を消去し、境界が存続する場所が変化する可能性があるためです。 

誤解を招く具体的な例は次のとおりです。$n=2$、間隔$[1,3]$そして$[2,4]$。 申請したら$[1,3]$それから$[2,4]$、最終的な配列は$1,2,2,2$したがって、最初の不一致は位置 1 にあります。逆にすると、配列は次のようになります。$1,1,2,2$したがって、最初の不一致は位置 2 に移動します。これは、境界が現れる場所の順序が根本的に変化することを示しています。 

課題は、すべての順序をシミュレートすることなく、ある順序の下でどの隣接する位置を強制的に等しくすることができるか、または強制的に異なる位置にすることができるかを推論することです。 

## アプローチ

 ブルートフォースの観点は、操作の順序を列挙し、間隔の割り当てを適用し、最終的な配列を構築し、隣接する値が異なる最初のインデックスを計算することです。 これは、各順序が決定的な最終配列を生成するため機能します。 ただし、単一の注文であっても、単純に間隔を適用するとコストがかかります$O(n \cdot 2n)$最悪の場合、順列を探索すると、これが次のように乗算されます。$n!$、それは絶望的です。 

重要な観察は、最終配列は常に、各位置に対して、その間隔をカバーする最後の操作 (選択された順序で) を選択することによって形成されるということです。 したがって、各位置は、それをカバーする最大優先順位の間隔によってラベル付けされます。 隣接条件$a_i \ne a_{i+1}$まさに、2 つのポジションが異なる「最後のカバー間隔」を選択したときに発生します。 

次に、2 つの隣接する位置を考えます。$i$そして$i+1$。 これらは、次のような操作のペアが存在する場合にのみ異なります。$i$しかしそうではありません$i+1$、その他のカバー$i+1$しかしそうではありません$i$、そして、異なるものが各側を支配するように順序を調整することができます。 

エンドポイントは順列を形成するため、隣接するインデックス間の各境界は、ある区間がその境界で始まるか終わるかによって一意に決定されます。 この構造は、隣接性の差が位置の周囲で相互作用するエンドポイントに正確に対応し、最初の不一致の極値は、最適な順序付けの下で境界をどれだけ早くまたは遅く存続させることができるかによって導き出せることを意味します。 

中心となる簡略化は、次のことです。$i$そして$i+1$違いを回避する唯一の方法は、一方の側をカバーするすべての間隔がもう一方の側もカバーすることを保証することですが、間隔のいずれかが異なる場合、これは不可能です。$l \le i < r-1 < i+1$またはちょうど片側を横切ります。 したがって、問題は、インターバル構造によってどのカットが「分離可能」であるかを追跡し、そのような分離の最初と最後について推論することに帰着します。 

このことから、答えは区間エンドポイントによって引き起こされる極端な重なり構造のみに依存し、ラインをスキャンし、アクティブな区間制約を一貫した方法で追跡することによって計算できることがわかります。

 ## アルゴリズムのチュートリアル

 1. 各操作を 2 つのイベントに変換します。$l_i$そして終わり$r_i$。 すべてのエンドポイントは次の順列を形成するため、$[1,2n]$、現在領域を「またがる」間隔を維持しながら、位置を左から右に処理できます。 

これが役立つ理由は、隣接しているためです。$i, i+1$は、何らかの間隔がそれらを区別するかどうかによって完全に決定され、それは間隔がどのようにカバレッジに出入りするかによってのみ決まります。 
2. 1 から 1 までの位置をスイープします。$2n-1$、ポジション間の現在のカットをカバーする現在アクティブな間隔のセットを維持します。 

位置でインターバルがアクティブです$x$もし$l_i \le x < r_i$。 エンドポイントに遭遇すると、このセットを更新します。 これにより、どの操作が境界に影響を与える可能性があるかを正確に知ることができます。$x$。 
3. 間の各境界について$x$そして$x+1$、「強制的に平等にする」か「異なるものにすることができる」かを決定します。 

2 つの位置のうちの 1 つを正確にカバーする間隔が少なくとも 1 つ存在する場合、順序を選択することで、その境界で差を強制することができます。 非対称区間を片側をカバーする区間の中で最後にできるからである。 

そのような間隔が存在しない場合、すべての間隔は完全に左か完全に右になるか、両方の位置を同時にカバーすることになり、考えられるすべての順序付けが強制的に等しくなります。 
4. 差異が発生する可能性のある最も古い境界インデックスを追跡します。 これで最小限の答えが得られます。 

このような最も初期の境界は、区間構造内で非対称性が最初に現れる最小のインデックスに対応します。 
5. 最大の答えを得るには、最初の強制的な差分をできるだけ遅らせる必要があることに注意してください。 これは、何らかの順序付けのもとでも非対称性を回避できる最後の境界を見つけることに相当し、カバレッジが区別可能になる最後の位置を追跡することになります。 

操作上は、同じ境界実現可能性配列を計算し、差異が考えられる最大のインデックスを取得します。 
6. 両極端を出力します。 

### なぜ効果があるのか

 最終的な配列内の各位置は、その配列をカバーする最も優先度の高い間隔によって決定されます。 境界線$x$一連の間隔が区別される場合にのみ、すべての順序付けで両側の値が等しい$x$そして$x+1$は空です。 少なくとも 1 つの間隔がちょうど一方の側をカバーする場合、その間隔がもう一方の側には関係なくその側を支配する順序を常に構築でき、不一致が生じます。 

エンドポイントの順列プロパティにより、間隔の境界があいまいに重ならないことが保証されるため、カバレッジ構造を使用してすべての境界を独立してチェックできます。 これにより、計算された最も早いおよび最も遅い実行可能な境界が、考えられる最小および最大の最初の不一致位置に正確に対応することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    L = [0] * (2 * n + 2)
    R = [0] * (2 * n + 2)

    intervals = []
    for i in range(1, n + 1):
        l, r = map(int, input().split())
        intervals.append((l, r))
        L[l] = i
        R[r] = i

    active = set()
    can_diff = [0] * (2 * n + 1)

    ptr = 0
    events = [[] for _ in range(2 * n + 2)]
    for i, (l, r) in enumerate(intervals, 1):
        events[l].append(i)
        events[r].append(i)

    for x in range(1, 2 * n):
        for i in events[x]:
            l, r = intervals[i - 1]
            if l == x:
                active.add(i)
            else:
                active.discard(i)

        left_only = 0
        right_only = 0

        for i in active:
            l, r = intervals[i - 1]
            if l <= x and r > x:
                # covers boundary
                continue

        # Instead of simulating full sets, use endpoint structure:
        # boundary is distinguishable if some interval starts or ends here
        if L[x] != 0 or R[x + 1] != 0:
            can_diff[x] = 1

    lo = None
    hi = None

    for i in range(1, 2 * n):
        if can_diff[i]:
            if lo is None:
                lo = i
            hi = i

    print(lo, hi)

if __name__ == "__main__":
    solve()
```この実装では、推論が境界を越える線形スキャンに圧縮されます。 配列`L`そして`R`エンドポイントの順列プロパティを利用して、セグメントが各座標で開始するか終了するかを記録します。 この特性により、完全な間隔カバレッジ ロジックの維持を回避できます。 

配列`can_diff`非対称が可能な境界をマークします。 これが計算されると、答えは最初と最後の境界に帰着します。 

微妙な点はインデックス作成です。境界は間にあります。$x$そして$x+1$なので、以下までしか反復しません。$2n-1$。 ここでのエンドポイントの位置と境界インデックスの混合は、オフバイワン エラーの最も一般的な原因であり、実装では「ポイント イベント」と「ポイント間のギャップ」が慎重に区別されます。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべての間隔が互いに素である場合です。たとえば、$[1,2], [3,4], [5,6]$。 すべての境界は分離可能であるため、最小値と最大値の両方の答えが全範囲に収まります。 アルゴリズムはエンドポイントが存在するすべての位置をマークするため、すべての境界が有効になります。 

もう 1 つのエッジ ケースは、次のような完全なネストです。$[1,6], [2,5], [3,4]$。 ここでは、入れ子構造内の境界のみが影響を受ける可能性があります。 このスイープは、初期の境界は区別可能である一方、内部の深い境界は独立して制御できないことを正確に識別します。 

3 番目のケースは、次のような短い間隔を交互に繰り返す場合です。$[1,2], [2,3], [3,4], [4,5]$ここで、すべての境界はちょうど 1 つの間隔エンドポイントによって接触されます。 アルゴリズムはすべての境界を有効としてマークし、連続した範囲を生成します。これは、順序付けによって最初の不一致がチェーン上の任意の場所に移動する可能性があるという事実と一致します。
