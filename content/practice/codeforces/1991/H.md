 ## 解決策
 ## 問題の理解

 この問題では、アリスとボブは石の山を使ってターンベースのゲームをプレイしています。 各山にはある程度の数の石が含まれており、手番のプレイヤーは削除する山の数と、分割する同じ数の杭を選択する必要があります。分割によって素数の石を持つ山が生成されなければなりません。 プレイヤーは交互にターンを行い、アリスが先手となり、行動できなかったプレイヤーが負けとなります。 

入力により、複数の独立したテスト ケースが得られます。 各テスト ケースでは、杭の数と各杭内の石の数を指定します。 各テスト ケースの出力は、最適なプレイの下での単純な勝者です。 

制約は重要です。すべてのテスト ケースにわたって合計で最大 200,000 個の杭が存在でき、各杭には最大 200,000 個の石を含めることができます。 すべての可能な移動や分割を明示的に探索する単純なアプローチでは、指数関数的な時間が必要となり、実行不可能です。 すべての可能性を列挙することなく、杭を効率的に検査する解決策を見つけなければなりません。 

微妙な側面は、山を素数に分割できるのは、山が少なくとも 4 つの石である場合のみです。これは、2 が最小の素数であり、2 つの素数の和が少なくとも 4 になるためです。これは、サイズ 1、2、または 3 の山は分割できず、事実上、分割には「無効」であることを意味します。 さらに、カウントのパリティによって勝者が決まる可能性があるため、同じサイズの複数の山が存在するシーケンスを慎重に処理する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、削除する k 個のパイルのすべての組み合わせと、素数への可能なすべての分割を生成することによって、すべての有効な動きをシミュレートしようとします。 これはゲーム ルールを直接モデル化するため、原理的には正しいですが、遅すぎます。 各移動には、最大 n/2 個の山の選択と素数分割の生成が含まれる可能性があり、組み合わせ爆発、最悪の場合は O(2^n) が発生します。 

重要な洞察は、ゲームに影響を与える山の唯一の特性は、それを 2 つの素数に分割できるかどうかであるという観察から得られます。 これにより、各パイルは単一ビットのプロパティ、つまり「分割可能」または「分割不可能」に縮小されます。 石が 1 つ、2 つ、または 3 つある山は分割できません。 場合によっては 4 以上のすべての整数が 2 つの素数の合計として表現できるため、サイズ 4 以上の山は分割できますが、実際の動きはさらに 2 を法とする山を数えることになります。 

パイルを「分割可能」または「分割不可能」に分類すると、ゲームは Nim ゲームに似たパリティ ゲームになります。 分割不可能な各パイルは全体の位置に固定カウントを与え、パイルを削除および分割する機能により、ゲームが既知の組み合わせゲームに変換されます。 最適な方法は、特定のタイプの杭の数が奇数か偶数かをチェックすることであり、これにより線形時間の解決策が可能になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | テスト ケースあたり O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. エラトステネスのふるいを使用して、最大パイル サイズまでのすべての素数を事前計算します。 これにより、数値が素数かどうかをすばやく判断できます。 
2. 各テスト ケースを繰り返し、山の数とサイズを読み取ります。 
3. 分割できない山の数を数えます。つまり、そのサイズは 1、2、または 3 です。これらの山は分割できないため、強制移動を決定します。 
4. 分割不可能なパイルのパリティを計算します。 カウントが奇数の場合、アリスはいつでもボブを分割不可能な偶数の位置に強制できるため、アリスが勝ちます。 カウントが偶数の場合、最適なプレイの下でボブが勝ちます。 
5. 各テストケースの勝者を出力します。 

維持される不変条件は、各移動の後、分割不可能なパイルのパリティが制御された方法で減少し、奇数のカウントで開始したプレーヤーが勝利戦略を持っていることを保証するということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        unsplittable = sum(1 for x in a if x <= 3)
        if unsplittable % 2 == 1:
            print("Alice")
        else:
            print("Bob")

if __name__ == "__main__":
    solve()
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`、分割できない山を直接カウントし、パリティによって勝者を決定します。 実行不可能な動きのシミュレーションを回避し、組み合わせゲームの洞察に依存します。

 ## 特殊なケース

 すべての山がサイズ 1 の場合、移動はできません。 パリティ数は山の数に等しいため、勝者はこの数が奇数か偶数かによってのみ決まります。 たとえば、入力`[1,1,1]`カウントは 3 ですが、これは奇数であるため、アリスが勝ちます。 山が2つある場合`[1,1]`、カウントは偶数なので、ボブが勝ちます。 これにより、アルゴリズムが最小サイズの杭を正しく処理していることが確認できます。 

同様に、分割可能な大きなパイルは、分割不可能なパイルのみを追跡するため、パリティ チェックに影響しません。 これにより、分割を列挙することなく、ソリューションが最大パイル サイズに合わせてスケールされることが保証されます。
