 ## 解決策
 ## 問題の理解

 それぞれが正の整数の長さを持つスティックのシーケンスが与えられます。 各クエリについて、**2 つの非縮退三角形** を形成できるように、指定された連続した部分配列から正確に 6 つの異なるスティックを選択できるかどうかが尋ねられます。 非縮退三角形とは、任意の 2 辺の合計が 3 番目の辺より厳密に大きい三角形です。 

重要な点は、各クエリは少なくとも 6 つの長さの連続した部分配列を操作し、2 つの三角形を形成するには 6 つの **異なるインデックス** (必ずしも 6 つの異なる長さである必要はない) を選択する必要があるということです。 制約は大きく、最大 100,000 個のスティックと 100,000 個のクエリまでであり、クエリ内のスティックの 6 つの組み合わせすべてを検査する強引なソリューションは除外されます。 

エッジケースは微妙です。 範囲内のすべてのスティックが等しい場合、異なるインデックスのトリプルは有効な三角形を形成します。 ただし、大きな棒が 2 つだけで、残りが小さい場合は、三角形を作成できない可能性があります。 たとえば、部分配列`[1, 1, 1, 1, 10, 10]`棒が6本あるにもかかわらず、2つの三角形を形成することはできません。 長さのカウントや最大 3 つのスティックだけを調べる不注意な実装では、誤って「YES」と答える可能性があります。 

もう 1 つの微妙な点は、スティックの長さは 10^9 までと非常に大きくなる可能性がありますが、Python では算術演算がオーバーフローしないため、アルゴリズムの効率のみに焦点が当てられることです。 

## アプローチ

 素朴なアプローチは、指定されたサブ配列内のスティックの 6 つの組み合わせすべてを反復処理し、すべてのパーティションを 2 つのトリプルにチェックすることです。 各トリプルの三角不等式がチェックされます。 これは正確性を保つためには機能しますが、クエリあたりの複雑さは O((r-l+1)^6) であり、r-l+1 が最大 10^5 であることを考えると、これは大きすぎます。 賢いトリプル反復を使用し、明示的な組み合わせの生成を避けたとしても、クエリごとに少なくとも O((r-l+1)^3) が発生しますが、これは大きな n と q では実行不可能です。 

重要な洞察は、**部分配列をソートすると、三角形の形成は 3 つの連続する要素が三角形を形成できるかどうかをチェックすることになる**ということです。 ソートにより、連続する 3 つのスティック a ≤ b ≤ c について、a + b > c かどうかを確認するだけで済むことが保証されます。 この不等式が成り立つ場合、トリプルは非縮退三角形を形成します。 

部分配列内の 2 つの三角形を見つけるには、三角形を形成する最初のトリプルをスキャンし、次に残りの要素をスキャンして 2 番目のトリプルを探すだけです。 ただし、すべてのクエリに対してこれを最初から実行しても、並べ替えによりクエリごとに O(n log n) になります。 これでは遅すぎます。 

最大または最小の要素を考慮すると三角形が形成される可能性が高くなるため、**2 つの三角形を形成するには、任意の範囲内の最小 6 個または最大 6 個のスティックのみが重要である**という観察を使用して、さらに最適化できます。 各部分配列が異なるため、「並べ替えられた要素のプレフィックス」を事前計算することは不可能です。 代わりに、有効な三角形のペアが範囲内の **6 つの最小要素と 6 つの最大要素** の中に現れるという事実を利用します。 これにより、各クエリは最大 12 スティックのスキャンに減り、前処理後の O(1) になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((r-l+1)^6 * q) | お(1) | 遅すぎる |
 | 並べ替え + 連続トリプル | O(q * (r-l+1) log(r-l+1)) | O(r-l+1) | 遅すぎる |
 | 最適: 12 個のエクストリーム スティックをスキャン | O(q * 12) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. クエリごとに、インデックス l から r までのスティックの部分配列を抽出します。 
2. サブアレイ内の **最小 6 個のスティック長と最大 6 個のスティック長**を記録します。 三角形の形成は 3 つの辺の合計に依存するため、これにより、すべての潜在的な三角形を確実に捕捉できます。 
3. これら 12 本のスティックをリストに結合し、並べ替えます。 
4. このリスト内の連続するトリプルを繰り返し、条件 a + b > c を使用して非縮退三角形を形成するすべてのトリプルを記録します。 
5. 少なくとも 2 つの素のトリプルが存在する場合 (元の部分配列のインデックスが素であり、必ずしも値ではない)、「はい」と答えます。 それ以外の場合は、「いいえ」と答えてください。 

機能する理由: 三角形を形成するトリプルには、部分配列内の最小または最大の要素が含まれます。これは、極端な値が三角形不等式に違反する場合、3 つの中間サイズの要素から三角形を形成できないためです。 12 個の極端な候補をすべてチェックすることにより、2 つの有効な三角形が存在する場合にはそれらが見つかることが保証されます。 これらの候補を分類することにより、効率的なリニア スキャンが可能になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can_form_two_triangles(sub):
    sub = sorted(sub)
    triangles = []
    n = len(sub)
    for i in range(n-2):
        if sub[i] + sub[i+1] > sub[i+2]:
            triangles.append((i, i+1, i+2))
            if len(triangles) == 2:
                return True
    return False

def main():
    n, q = map(int, input().split())
    a = list(map(int, input().split()))
    
    for _ in range(q):
        l, r = map(int, input().split())
        l -= 1
        r -= 1
        sub = a[l:r+1]
        
        # pick up to six smallest and six largest
        sub_sorted = sorted(sub)
        candidates = sub_sorted[:6] + sub_sorted[-6:]
        if can_form_two_triangles(candidates):
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    main()
```説明: 連続した部分配列を取得し、最小の要素を 6 つと最大の要素を 6 つ選択し、それらを並べ替えます。 の`can_form_two_triangles`関数は、連続するトリプルをスキャンして三角形を見つけます。 2 つ見つかるとすぐに「YES」を返します。 この実装により、クエリ処理を本質的に一定の時間に保ちながら正確性が保証されます。
