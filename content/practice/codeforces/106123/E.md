 ## 解決策
 ## 問題の理解

 各値が皿上のチキンスターの数を表す配列があります。 

何かが破壊される前に、コールは位置を 1 つだけ選択し、その値を次のように置き換えることができます。`0`。 その後、バーニーは長さの連続した部分配列を選択します。`k`そしてそのセグメント内のすべてのプレートを破壊します。 バーニーはできるだけ多くのチキンスターを破壊したいと考えていますが、コールはバーニーの最善の選択をできるだけ弱くしたいと考えています。 

課題は、両方のプレイヤーが最適に行動したときにバーニーが破壊するチキンスターの最終的な数を決定することです。 

配列サイズは次の範囲に達します`10^5`これにより、すべての長さを再計算するソリューションは即座に除外されます。`k`コールのすべての可能な選択後の部分配列の合計。 アン`O(n^2)`アルゴリズムは次のように実行します`10^10`最悪の場合、限界をはるかに超えて動作する可能性があります。 

微妙な部分は、コールが 1 つのポジションを変更するだけですが、そのポジションがさまざまな長さに影響を与えるということです。`k`窓。 単純な実装では、候補位置ごとにウィンドウを 1 つずつ更新することが多く、時間がかかりすぎます。 

インプットを考慮する```
5 3
3 5 7 4 7
```長さ 3 のウィンドウの合計は次のとおりです。```
[15, 16, 18]
```Cole が値を削除した場合`7`位置で`3`、ウィンドウの合計は次のようになります。```
[8, 9, 11]
```そしてバーニーは破壊する`11`。 

不注意なアプローチでは、現在最大のウィンドウだけを見て、それを弱めようとする可能性があります。 これでは十分ではありません。1 つのウィンドウを弱めた後、別のウィンドウが新しい最大値になる可能性があるからです。 

次の場合には、別のエッジケースが発生します。`k = n`。```
4 4
1 10 4 8
```可能なウィンドウは 1 つだけです。 コールは最大値を削除する必要があります。`10`、与える```
1 + 0 + 4 + 8 = 13
```そして答えは`13`。 

どのようなソリューションでも、一部のウィンドウはコールの選択によって影響を受け、他のウィンドウは変更されないという事実を正しく処理する必要があります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 あらゆる長さを計算します -`k`ウィンドウ合計。 続いてポジションごとに`i`、そのふりをしてください`a[i]`ゼロになると、以下を含むすべてのウィンドウが更新されます。`i`、結果として得られる最大のウィンドウ合計を見つけ、すべての選択肢に対して最良の答えを保持します。`i`。 

これはゲームを直接シミュレートしているため、これは正しいです。 問題はコストです。 ポジションが属する可能性があるのは、`O(k)`窓があり、`n`ポジション。 最悪の場合こうなります`O(nk)`、つまり`O(n^2)`いつ`k`大きいです。 

重要な観察は、変化しているということです。`a[i]`位置を含むウィンドウにのみ影響します。`i`。 

させて`S[j]`の合計になります`j`- 番目の長さ -`k`ウィンドウ。 

設定後`a[i] = 0`:```
windows containing i:  S[j] - a[i]
other windows:         S[j]
```固定位置の場合`i`, バーニーの最良の選択は、次の中で最大のものです。```
1. The largest unaffected window.
2. The largest affected window after subtracting a[i].
```したがって、効率的に 2 つの値が必要になります。 

影響を受けない最大のウィンドウは、ウィンドウの合計に対するプレフィックスとサフィックスの最大配列を使用して取得できます。 

影響を受ける最大のウィンドウは次のとおりです。```
max_window_sum_in_containing_range - a[i]
```これは、ウィンドウ合計配列の範囲最大クエリになります。 

ウィンドウ合計は決して変化しないため、それらを 1 回前処理して、すべての範囲最大クエリに答えることができます。`O(1)`スパーステーブルを使用します。 

これにより、問題全体が次のように簡略化されます`O(n log n)`前処理と`O(n)`評価。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(nk) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n log n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての長さを計算します。`k`スライディング ウィンドウを使用したウィンドウ合計。 

ウィンドウの数を次のようにします`W = n - k + 1`。 
2. ウィンドウ合計に対してプレフィックス最大配列を構築します。`pref[j]`ウィンドウ間の最大のウィンドウ合計を保存します`1..j`。 
3. ウィンドウ合計に対してサフィックス最大配列を構築します。`suff[j]`ウィンドウ間の最大のウィンドウ合計を保存します`j..W`。 
4. ウィンドウ合計に対する範囲最大クエリ用のスパース テーブルを構築します。 

これにより、任意の間隔内の最大ウィンドウ合計を取得できます。`O(1)`時間。 
5. ポジションごとに`i`、どのウィンドウにそれが含まれているかを判断します。 

で始まるウィンドウ`j`位置が含まれています`i`まさに次のとき:```
j ≤ i ≤ j + k - 1
```したがって、次のようになります。```
L = max(1, i - k + 1)
R = min(i, W)
```6. 影響を受けない最大のウィンドウを計算します。 

影響を受けない窓はすべて外側にあります`[L, R]`。 

接頭辞と接尾辞の最大値を使用する:```
outside = max(
    pref[L - 1] if L > 1,
    suff[R + 1] if R < W
)
```7. 影響を受ける最大のウィンドウを計算します。 

内部の最大ウィンドウ合計をクエリします。`[L, R]`そして引きます`a[i]`。```
inside = max_window_in_[L,R] - a[i]
```8. コールが選択した後のバーニーの達成可能な最高の破壊`i`は```
max(outside, inside)
```9. すべての位置の最小値を取得します。`i`。 

### なぜ効果があるのか

 固定位置の場合`i`、すべてのウィンドウは 2 つのグループのうちの 1 つに正確に属します。 

含まれる窓`i`まさに負ける`a[i]`それらの合計から。 含まれていないウィンドウ`i`変わらないまま。 

Barney は結果として得られる最大のウィンドウを選択するため、その位置の答えは、影響を受けていない最適なウィンドウと影響を受けている最適なウィンドウの間の最大値となります。 アルゴリズムは両方の量を正確に計算します。 

ありとあらゆるポジションがあるので、`i`が調べられ、コールはそのような値が最小となるポジションを選択します。最終的な答えはまさにゲームの最小値になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
a = list(map(int, input().split()))

w = n - k + 1

# window sums
S = [0] * w
cur = sum(a[:k])
S[0] = cur

for i in range(k, n):
    cur += a[i] - a[i - k]
    S[i - k + 1] = cur

# prefix max
pref = [0] * w
pref[0] = S[0]
for i in range(1, w):
    pref[i] = max(pref[i - 1], S[i])

# suffix max
suff = [0] * w
suff[-1] = S[-1]
for i in range(w - 2, -1, -1):
    suff[i] = max(suff[i + 1], S[i])

# sparse table for RMQ max
lg = [0] * (w + 1)
for i in range(2, w + 1):
    lg[i] = lg[i // 2] + 1

K = lg[w] + 1
st = [S[:]]

j = 1
while (1 << j) <= w:
    prev = st[j - 1]
    length = w - (1 << j) + 1
    row = [0] * length
    half = 1 << (j - 1)

    for i in range(length):
        row[i] = max(prev[i], prev[i + half])

    st.append(row)
    j += 1

def range_max(l, r):
    length = r - l + 1
    p = lg[length]
    return max(st[p][l], st[p][r - (1 << p) + 1])

INF = 10**30
answer = INF

for idx in range(n):
    L = max(0, idx - k + 1)
    R = min(idx, w - 1)

    outside = 0

    if L > 0:
        outside = max(outside, pref[L - 1])

    if R + 1 < w:
        outside = max(outside, suff[R + 1])

    inside = range_max(L, R) - a[idx]

    answer = min(answer, max(outside, inside))

print(answer)
```最初のセクションでは、すべての長さを計算します。`k`標準のスライディング ウィンドウを使用して、線形時間でウィンドウの合計を計算します。 

プレフィックス配列とサフィックス配列を使用すると、配列を再度スキャンすることなく、任意の間隔の外側で最大のウィンドウを取得できます。 

スパース テーブルには、ウィンドウ合計配列の範囲の最大値が格納されます。 配列は決して変更されないため、スパース テーブルが理想的です。`O(1)`前処理後の最大クエリ数。 

見落としがちな実装の詳細の 1 つは、位置とウィンドウ インデックス間の変換です。 このコードでは 0 から始まるインデックスが使用されているため、包含ウィンドウの間隔は次のようになります。```
L = max(0, idx - k + 1)
R = min(idx, w - 1)
```もう 1 つの微妙な点は、すべてのウィンドウに選択した位置が含まれる場合です。 その場合、影響を受けないウィンドウは存在しません。 変数`outside`残る`0`これは、すべての配列値が正であり、すべての実数ウィンドウの合計が負ではないため、正しいです。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    w = n - k + 1

    S = [0] * w
    cur = sum(a[:k])
    S[0] = cur

    for i in range(k, n):
        cur += a[i] - a[i - k]
        S[i - k + 1] = cur

    pref = [0] * w
    pref[0] = S[0]
    for i in range(1, w):
        pref[i] = max(pref[i - 1], S[i])

    suff = [0] * w
    suff[-1] = S[-1]
    for i in range(w - 2, -1, -1):
        suff[i] = max(suff[i + 1], S[i])

    lg = [0] * (w + 1)
    for i in range(2, w + 1):
        lg[i] = lg[i // 2] + 1

    K = lg[w] + 1
    st = [S[:]]

    j = 1
    while (1 << j) <= w:
        prev = st[j - 1]
        length = w - (1 << j) + 1
        row = [0] * length
        half = 1 << (j - 1)

        for i in range(length):
            row[i] = max(prev[i], prev[i + half])

        st.append(row)
        j += 1

    def rmq(l, r):
        length = r - l + 1
        p = lg[length]
        return max(st[p][l], st[p][r - (1 << p) + 1])

    ans = 10**30

    for idx in range(n):
        L = max(0, idx - k + 1)
        R = min(idx, w - 1)

        outside = 0

        if L > 0:
            outside = max(outside, pref[L - 1])

        if R + 1 < w:
            outside = max(outside, suff[R + 1])

        inside = rmq(L, R) - a[idx]

        ans = min(ans, max(outside, inside))

    return str(ans) + "\n"

 ## 特殊なケース

 次のことを考慮してください。```
1 1
5
```プレートと窓は 1 つだけです。 コールはそのプレートをゼロに設定します。 唯一のウィンドウ合計がゼロになるため、バーニーはゼロのチキンスターを破壊します。 アルゴリズムは、次と等しい 1 つのウィンドウ合計を計算します。`5`、次に唯一の位置を評価して次の値を取得します。`5 - 5 = 0`。 

考慮する：```
4 4
1 10 4 8
```ウィンドウは 1 つしかないため、すべてのウィンドウにはすべての位置が含まれます。 ポジションについて`2`、影響を受けるウィンドウの最大値は`23 - 10 = 13`影響を受けないウィンドウはありません。 アルゴリズムは正しく終了します`outside = 0`そして戻ってきます`13`。 

考慮する：```
3 2
1 100 1
```ウィンドウの合計は次のとおりです。`[101, 101]`。 中央の値を削除すると、両方のウィンドウに同時に影響し、次のようになります。`[1, 1]`。 このアルゴリズムは、含まれるウィンドウの間隔がすべてのウィンドウをカバーしていることを特定し、以下を計算します。```
inside = 101 - 100 = 1
outside = 0
```正しい答えを与えること`1`。 

これらのケースでは、影響を受けるウィンドウの間隔の計算、影響を受けずに欠落しているウィンドウの処理、およびミニマックス ロジックがすべて正しく動作することが検証されます。
