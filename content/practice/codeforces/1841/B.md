 ## 解決策
 ## 問題の理解

 空の配列から始めて、数値を 1 つずつ受け取ります。 

受信値ごとに`x`、現在の配列に追加することで配列が「美しい」状態に保たれるかどうかを判断する必要があります。 存在する場合は、それを永続的に追加します。 それ以外の場合は無視します。 各クエリの後に出力します`1`値が追加された場合と`0`拒否された場合。 

美しい配列は非常に特殊な構造を持っています。 降順でない順序でソートされるように配列を回転できる必要があります。 これを別の言い方で言えば、配列はソートされたシーケンスであり、1 つの位置で切り取られて折り返された可能性があります。 

例えば：`[1,2,3,4,5]`すでにソートされているので美しいです。`[3,7,7,9,2,3]`前の位置で回転するので綺麗です`2`与える`[2,3,3,7,7,9]`。`[5,2,2,1]`回転しないとソートされたシーケンスが生成されないため、美しくありません。 

すべてのテスト ケースにわたるクエリの合計数は最大で`2 · 10^5`。 挿入のたびに配列全体を再スキャンするソリューションでは、大まかに次のことが必要になります。$$O(q^2)$$最悪の場合の操作は、約に達する可能性があります`4 · 10^10`操作。 それは限界をはるかに超えています。 

各クエリを一定時間または対数時間で処理するソリューションが必要です。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

考慮する：```
1
5
1 2 3 0 2
```受け入れられる配列は次のようになります`[1,2,3,0]`。 回転ポイントが表示された後、追加`2`2 番目のセグメントはまだ減少しておらず、`2 ≤ 1`は誤りです。 ローカルな順序のみをチェックする不注意な実装では、無効な値が受け入れられてしまいます。 

もう 1 つの注意が必要なケースは次のとおりです。```
1
4
5 1 2 6
```受付後`5`そして`1`、配列は`[5,1]`、これにはすでに固有のドロップが含まれています。 追加中`6`ローテーションされたソート順序が壊れるため、拒否する必要があります。 最後に受け入れられた要素だけを見ると、それが誤って許可されてしまいます。 

重複も重要です:```
1
5
1 1 1 1 1
```すべての値を受け入れる必要があります。 非厳密比較ではなく厳密比較を行うと、有効な挿入が拒否されます。 

## アプローチ

 ブルート フォース ソリューションは、定義に直接従います。 

各クエリの後に、新しい値を一時的に追加し、結果の配列が美しいかどうかをテストします。 これを行うには、考えられるすべての回転を検索し、回転された配列がソートされているかどうかを確認します。 長さの配列の場合`k`、これには費用がかかります`O(k²)`時間。 すべての回転をチェックインするわずかに改良されたバージョンでも`O(k)`まだつながる`O(q²)`すべてのクエリの後にテストが繰り返されるため、総作業量が増加します。 

重要な観察は、美しい配列には次数が減少する位置が最大でも 1 つしか含まれないということです。 

回転ソート配列の場合:```
3 7 7 9 2 3
```ちょうど 1 つのドロップがあります:```
9 -> 2
```下落前のすべては減少せず、下落後のすべても減少しません。 

アレイを構築する際に必要なのは、そのドロップがすでに出現したかどうかだけを知ることです。 

最初に受け入れられる値を次のようにします`first`。 

ドロップが現れる前は、配列は単純に減少していません。 少なくとも最後に受け入れられた値と同じ大きさの任意の値を追加できます。 

最後に受け入れられた値より小さい値が表示された場合は、一意の回転ポイントを作成しようとしています。 これは、新しい値が以下の場合にのみ許可されます。`first`。 そうしないと、回転によって配列がソートされる可能性があります。 

下落が存在した後は、将来の値はすべて次の 2 つの条件を満たす必要があります。 

2 番目のセグメントは減少しないようにする必要があるため、少なくとも現在の最後の値でなければなりません。 

2 番目のセグメントの範囲内に収まる必要があるため、次のセグメントを超えることはできません。`first`。 

これらの条件は、すべての有効な挿入を特徴付けるのに十分です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(q²) | O(q) | 遅すぎる |
 | 最適 | O(q) | O(q) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 受け入れられる空の配列から始めます。 
2. 最初のクエリを無条件に受け入れます。 単一要素の配列は常に美しいです。 
3. 最初に受け入れられた値を次のように保存します。`first`。 
4. ブール値を維持する`wrapped`。`wrapped = False`回転点がまだ表示されていないことを意味します。`wrapped = True`ユニークなドロップがすでに作成されていることを意味します。 
5. 新しい値ごとに`x`、現在最後に受け入れられた値を調べます。 
6. もし`wrapped`は`False`：

もし`x >= last`、受け入れてください。 配列は減少しないままです。 

それ以外の場合は、回転ポイントを作成しようとしています。 以下の場合にのみ受け入れます`x <= first`。 受け入れられた場合は設定します`wrapped = True`。 
7. もし`wrapped`は`True`：

受け入れる`x`両方の条件が当てはまる場合のみ:`x >= last`

`x <= first`最初の条件は、2 番目のセグメントの非降順順序を保持します。 2 番目の条件では、回転ポイント以降のすべての要素が最初のセグメントの先頭より大きくならないようにします。 
8. 出力`1`受け入れられた値と`0`拒否された値の場合。 

### なぜ効果があるのか

 不変条件は、受け入れられる配列が常に 1 つのソートされたセグメント、または 1 つのドロップで区切られた 2 つのソートされたセグメントのいずれかで構成されることです。 

いつ`wrapped`は`False`、アレイはまだそのドロップを使用していません。 ソートされたセグメントを継続することも、最初の要素以下の値を挿入して一意のドロップを作成することもできます。 

いつ`wrapped`は`True`、ドロップはすでに存在します。 future 要素はすべて 2 番目のセグメントに属します。 少なくともそのセグメント内の前の要素と同じ大きさ、最大でも配列の最初の要素と同じ大きさでなければなりません。 そうしないと、回転ソート順序付けが不可能になります。 

受け入れられた挿入はすべてこの不変条件を維持し、拒否された挿入はすべてこれに違反します。 美しい配列とは、そのようなドロップが 1 つ以下で、対応する境界制約が存在する配列であるため、アルゴリズムは正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        q = int(input())
        xs = list(map(int, input().split()))

        ans = []

        arr = []
        wrapped = False
        first = None

        for x in xs:
            if not arr:
                arr.append(x)
                first = x
                ans.append('1')
                continue

            last = arr[-1]

            ok = False

            if not wrapped:
                if x >= last:
                    ok = True
                elif x <= first:
                    ok = True
                    wrapped = True
            else:
                if last <= x <= first:
                    ok = True

            if ok:
                arr.append(x)
                ans.append('1')
            else:
                ans.append('0')

        print(''.join(ans))

if __name__ == "__main__":
    solve()
```最初に受け入れられた値が永続的な基準点になります`first`。 その後のすべての決定は、受信した値、現在最後に受け入れられた値、および`first`。 

変数`wrapped`固有の減少がすでに使用されているかどうかを記録します。 使用する前は、配列は通常の非減少シーケンスのように動作します。 一度使用すると、将来の値はすべてその間隔内に収まる必要があります`[last, first]`。 

微妙な詳細は、`wrapped`ドロップを作成する値が実際に受け入れられた場合にのみ変更されます。 拒否された値は状態に影響を与えてはなりません。 

もう 1 つの詳細は、非厳密な比較の使用です。 ターゲットの次数は厳密に増加するのではなく、減少しないため、等しい値が許可されます。

 ## 特殊なケース

 次のことを考慮してください。```
1
4
5 1 2 6
```アルゴリズムは受け入れます`5`、その後、受け入れます`1`なぜなら`1 <= first`。 これにより、回転ポイントが作成され、`wrapped = True`。 

値`2`満足する`1 <= 2 <= 5`, したがって、受け入れられます。 

値`6`違反する`6 <= first`, したがって拒否されます。 

出力は次のとおりです。```
1110
```ラップが発生すると、回転されたソート配列には最初のセグメントより大きな要素を含めることができないため、これは正確に正しいです。 

ここで重複について考えてみましょう。```
1
5
1 1 1 1 1
```すべての挿入は非減少条件を満たします。 ラップは必要ありません。 

出力は次のとおりです。```
11111
```厳密な比較を使用すると、等しい値が誤って拒否されます。 

最後に次のことを考慮してください。```
1
5
3 4 5 1 0
```受付後`1`、ラップはすでに存在します。 

最終的な値`0`現在最後に受け入れられた値より小さいです`1`, したがって、2番目のドロップが作成されます。 アルゴリズムはそれを拒否します。`0 >= last`は誤りです。 

出力は次のようになります。```
11110
```これは中心的な不変条件を示しています。つまり、美しい配列には減少が 1 つしか含まれていない可能性があります。 この減少が使用されると、それ以降のすべての値は 2 番目にソートされたセグメント内に留まる必要があります。
