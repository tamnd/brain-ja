 ## 解決策
 ## 問題の理解

 連結された 2 つの整数、つまり元の評価を表す数字の文字列が与えられます。`a`そして評価も上がった`b`、しかしそれらの間に明確な分離はありません。 私たちのタスクは、この文字列を 2 つの数値に分割し、どちらも厳密に正であり、どちらも先行ゼロを持たないようにすることです。`b`厳密には次より大きいです`a`。 複数の分割がこれらの条件を満たす場合は、任意の分割を返すことができます。 有効な分割が存在しない場合は、戻り値が返されます。`-1`。 

各テスト ケースの入力サイズは小さく、文字列の長さは 2 ～ 8 です。最大 10,000 のテスト ケースが存在する可能性があります。 各文字列は最大 8 文字であるため、単一の文字列に対して最大 7 つの分割位置が存在するため、考えられるすべての分割を検査するアプローチは実行可能です。 主な課題は、先頭のゼロ、等しい数値を処理し、強制することです。`b > a`正しく。 たとえば、入力が与えられたとすると、`200200`、不注意に実装すると、次のように分割される可能性があります。`200`そして`200`、これは失敗します。`b`厳密には以下より大きくありません`a`。 同様に分割すると、`1001`として`10`そして`01`は無効です。`01`先頭にゼロが付きます。 

## アプローチ

 ブルートフォースアプローチは簡単です。 各文字列について、可能な限りすべての場所を試して、空ではない 2 つの部分に分割します。 両方の部分を整数に変換し、条件を満たしているかどうかを確認します。どちらも先頭にゼロがなく、どちらもゼロより大きく、`b > a`。 文字列の長さは最大 8 であるため、テスト ケースごとに最大 7 つのチェックが必要になります。 10,000 のテスト ケースでは、最大 70,000 のチェックが生成されますが、これは実際には許容範囲です。 ブルートフォースアプローチは、考えられるすべての有効な分割が検査されることが保証されているため機能します。 

観測により作業が簡素化されます: 文字列に長さがあるかどうか`n`、中央に近い分割を試みると、結果が小さくなることがよくあります`a`そしてさらに大きい`b`、これにより、`b > a`可能性が高くなります。 ただし、正確性を確保するために、特に数字が繰り返されたり増加したりする文字列の場合、有効な分割はどの位置でも発生する可能性があるため、最悪の場合でもすべての分割をチェックする必要があります。 

このコンテキストでの最適なアプローチは、やはり早期停止を伴う総当り攻撃です。つまり、すべての分割位置を左から右に反復処理し、最初の有効な分割を返します。 入力の制約により操作の数はわずかなままであり、これにより不必要な複雑さなしに正確さが保証されます。

 | ブルートフォース / 早期停止 | O(n * t)、n ≤ 8、t ≤ 10^4 | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. テスト ケースごとに、連結された文字列を読み取ります。`s`。 
3. 可能な分割位置を反復処理します。`i`1から`len(s)-1`。 分割は分割します`s`の中へ`a_str = s[:i]`そして`b_str = s[i:]`。 
4. 先頭のゼロをチェックします。`a_str`または`b_str`から始まる`'0'`、この分割はスキップしてください。 
5.変換`a_str`そして`b_str`整数に`a`そして`b`。 
6. 両方の数値が厳密に正であるかどうかを確認します (`a > 0`そして`b > 0`）そしてもし`b > a`。 その場合は印刷してください`a`そして`b`そしてこの文字列の処理を停止します。 
7. すべての位置を確認した後、有効な分割が見つからない場合は、印刷します。`-1`。 

機能する理由: このアルゴリズムは、文字列を 2 つの数値に分割する可能なすべての方法をチェックします。 先行ゼロを伴う分割を明示的に拒否し、強制することにより、`b > a`、すべての出力が問題の制約を満たすことを保証します。 早期停止により、有効な分割が見つかるとすぐに効率的に結果が生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    s = input().strip()
    n = len(s)
    found = False
    for i in range(1, n):
        a_str, b_str = s[:i], s[i:]
        if a_str[0] == '0' or b_str[0] == '0':
            continue
        a, b = int(a_str), int(b_str)
        if b > a:
            print(a, b)
            found = True
            break
    if not found:
        print(-1)
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 すべての分割ポイントを反復処理し、各分割候補をチェックします。 不必要な整数変換を避けるために、先頭のゼロが最初にフィルタリングされます。 早期に停止することで、余分な作業をせずに最初の有効な分割を返すことができます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()
    t = int(input())
    for _ in range(t):
        s = input().strip()
        n = len(s)
        found = False
        for i in range(1, n):
            a_str, b_str = s[:i], s[i:]
            if a_str[0] == '0' or b_str[0] == '0':
                continue
            a, b = int(a_str), int(b_str)
            if b > a:
                print(a, b)
                found = True
                break
        if not found:
            print(-1)
    return sys.stdout.getvalue().strip()
