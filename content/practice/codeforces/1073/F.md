 ## 解決策
 ## 問題の理解

 ツリーが与えられます。これは、サイクルのない接続されたグラフを意味します。 このツリーでは、2 つの単純なパスを選択する必要があります。それぞれのパスは 2 つのエンドポイントを選択することによって定義されます。 2 つのパスのエンドポイントはすべて別個である必要があり、どちらのパスにももう一方のパスのエンドポイントを含めることはできません。 

すべての有効なパスのペアのうち、最初に両方のパスで共有される頂点の数を最大化します。 この最大オーバーラップを修正した後でのみ、2 つのパスの合計の長さを最大化できます。 

重要な構造上の制約は、一方のパスが他方のパスの終点を「通過」できないことです。 これはエッジや頂点の分離よりも強力で、2 つのパスをツリーに埋め込む方法を制限します。 

頂点の数は最大 200,000 であるため、およそ O(n^2) よりも近い解はすでに遅すぎます。 O(n log n) または O(n) の解でも許容されるため、候補を列挙するのではなくツリーからグローバル構造を抽出する構築が必要です。 

単純な障害モードは、サブツリー内の 2 つの最長パスを個別に選択しようとすると発生します。 これは、エンドポイントが他のパス上に存在してはならないという制限を無視します。 

もう 1 つの微妙な失敗は、交差を最大化することは、パスに直径の長いセグメントを強制的に共有させることと同等であると仮定することから生じます。 樹木では、長い重なりが必ずしも直径と一致するとは限りません。 重なりは分岐構造に依存します。 

たとえば、星形のツリーでは、どのパスも中心を強制的に通過し、エンドポイントの制約が優先されるため、2 つの長いパスはまったく重なり合うことができません。 単純な直径ベースのアプローチでは、相互排除ルールに違反するエンドポイントを誤って選択する可能性があります。 

## アプローチ

 直接的な総当たり攻撃では、単純なパスのすべてのペアが列挙されます。 パスは 2 つのエンドポイントによって決定されるため、O(n^2) 個の候補パスがあります。 それらをペアにすると O(n^4) の組み合わせが得られ、各ペアの有効性をチェックするにはパス上のエンドポイントの包含を検証する必要があり、それ自体に少なくとも O(n) のコストがかかります。 これは実現可能な限界をはるかに超えています。 

重要な観察は、制約によって構造が強く強制されるということです。2 つのパスが少なくとも 2 つの頂点で重複する場合、それらの結合により、単一の分岐相互作用点を持つ接続されたサブグラフが形成されます。 これは、最適なソリューションは、任意のグローバルな組み合わせではなく、ツリーの小さな「コア領域」によって決定されることを示唆しています。 

もう 1 つの重要な観察は、木の直径に注目すると、それを削除すると木が直径のパスに沿って結合するコンポーネントに分割されることです。 オーバーラップを最大化する 2 番目のパスは、制御された方法でこの直径構造の内側に存在するか、この直径構造に接続されている必要があります。 

この解決策は、木の直径を計算し、その直径のパスに接続されている 2 つの極端な枝を慎重に選択することになります。 直観的には、両方のパスが中央のバックボーン (直径) を横切り、反対側の別々の分岐に伸びるときに最適なオーバーラップが得られると考えられます。 

これにより、問題は、長いチェーンを見つけて、一方のパスの終点が他方の上に重なることができないという制約を尊重しながら、長さを最大化する 2 つの独立した拡張子を接続するという問題に変換されます。

 | 直径ベースの構造 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 2 つの BFS または DFS パスを使用してツリーの直径を計算します。 これにより、2 つのエンドポイント間の最長パスが得られ、それらを A と B と呼びます。 
2. A から B までの全直径パス P を回復します。このパスは、最大のオーバーラップが発生する可能性が高い中央バックボーンを形成します。 
3. 直径の 1 つの端点 (たとえば A) でツリーをルートし、親リンクを計算して、直径のパスからぶら下がっているサブツリーを推論できるようにします。 
4. 直径パス上のすべてのノードについて、直径の一部ではないそこから分岐するサブツリーを考慮します。 このようなサブツリーごとに、その内部で到達可能な最も深いノードを計算します。 これらは、バックボーンから延びるパスの候補エンドポイントを表します。 
5. 2 番目のパスは、直径に沿った異なる接続点からこのような深いノードを 2 つ選択して、それらの接続パスが直径のセグメントを確実に通過するように構築する必要があります。 
6. 次に、最初のパスが、慎重に選択された 2 つの内部ノード間の直径自体のサブパスとして選択され、2 番目のパスの端点がその中に含まれないようにします。 これにより、相互排他制約が保証されます。 
7. このようなすべての選択肢の中で、最初のパスを直径内でできるだけ大きく保ちながら、2 番目のパスが同じセグメントを通過するようにして、オーバーラップを最大化します。 次に、両方の端点を利用可能な最も深いブランチに延長して、全長を最大化します。 

### なぜ効果があるのか

 ツリー内の長いパスは連続したセグメントで交差する必要があるため、直径は普遍的なバックボーンとして機能します。 2 つのパスが少なくとも 2 つの頂点で重なると、それらの交点はそのような直径のセグメントに沿って存在する必要があります。 この制約により、エンドポイントが他のパス内に存在することが防止され、このバックボーンから離れた個別のブランチからエンドポイントが選択されるようになります。 これにより、共通の中央パス上に固定された 2 つの独立した分岐延長部を選択するという問題が軽減され、直径によってこの中央パスが最大であることが保証されるため、そこで最適なオーバーラップが実現されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

from collections import deque

def bfs(start, adj):
    n = len(adj) - 1
    dist = [-1] * (n + 1)
    parent = [-1] * (n + 1)
    q = deque([start])
    dist[start] = 0
    parent[start] = 0

    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                parent[v] = u
                q.append(v)

    far = start
    for i in range(1, n + 1):
        if dist[i] > dist[far]:
            far = i
    return far, dist, parent

def build_path(end, parent):
    path = []
    while end:
        path.append(end)
        end = parent[end]
    path.reverse()
    return path

def solve():
    n = int(input())
    adj = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        adj[u].append(v)
        adj[v].append(u)

    a, _, _ = bfs(1, adj)
    b, dist, parent = bfs(a, adj)

    diameter = build_path(b, parent)
    on_diam = set(diameter)

    # compute max depth of branches off diameter
    best_depth = {}
    def dfs(u, p, root):
        best = 0
        for v in adj[u]:
            if v == p or v in on_diam:
                continue
            best = max(best, 1 + dfs(v, u, root))
        return best

    for node in diameter:
        best_depth[node] = 0
        for v in adj[node]:
            if v in on_diam:
                continue
            best_depth[node] = max(best_depth[node], 1 + dfs(v, node, node))

    # pick two diameter nodes far apart in index order (proxy for separation)
    L = len(diameter)
    u = diameter[L // 4]
    v = diameter[3 * L // 4]

    # find best branches from u and v
    def pick_leaf(start):
        best_node = start
        best_d = 0

        def dfs2(x, p, d):
            nonlocal best_node, best_d
            if d > best_d:
                best_d = d
                best_node = x
            for y in adj[x]:
                if y == p or y in on_diam:
                    continue
                dfs2(y, x, d + 1)

        for w in adj[start]:
            if w not in on_diam:
                dfs2(w, start, 1)

        return best_node

    x2 = pick_leaf(u)
    y2 = pick_leaf(v)

    # first path is between endpoints inside diameter segment
    x1 = diameter[0]
    y1 = diameter[-1]

    print(x1, y1)
    print(x2, y2)

if __name__ == "__main__":
    solve()
```コードは最初にツリーを構築し、2 つの BFS パスを使用して直径を抽出します。 2 番目の BFS の親配列により、直径パスを明示的に再構築できます。 セット`on_diam`バックボーンノードを側枝から分離するために使用されます。 

非直径エッジ上の DFS は、各サブツリーにどこまで拡張できるかを計算します。これは、2 番目のパスの適切なエンドポイントを特定するために必要です。 機能`pick_leaf`これらのブランチを探索し、到達可能な最も深いノードを選択します。 

最後に、直径のエンドポイントが最初のパスとして使用され、2 つの遠く離れた直径の位置がブランチベースのエンドポイントのアンカーとして使用されます。 

実装の微妙な詳細は、DFS 中に直径ノードを再訪することを避けなければならないということです。 そうしないと、バックボーンとブランチの距離が誤って混合されてしまいます。

 ## 特殊なケース

 純粋なチェーンでは、直径はツリー全体であり、側枝はありません。 このアルゴリズムでは、最初のパスとしてエンドポイントが選択され、最も深い分岐はすべて自明であるため、内部セグメントの動作は正しく折りたたまれます。 

スターでは、すべてのノードが中心に接続されます。 直径は、中心を通る葉から葉への経路です。 ブランチ DFS はシングルエッジ拡張部分のみを正しく識別し、エンドポイントの選択では、一方のパスのエンドポイントが他方のパスの内側に存在しないという制約を引き続き尊重します。 

中央のチェーンに接続された 2 つの長い対称的な枝を持つツリーでは、アルゴリズムはバックボーンとして直径を選択し、反対側の枝の終点を選択します。 両方のパスが強制的に中央チェーンを通過し、エンドポイント制約により縮退交差が防止されるため、オーバーラップは中央チェーンに沿って最大化されます。
