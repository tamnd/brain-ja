 ## 解決策
 ## 問題の理解

 ちょうど 2 行のグリッドが与えられ、$n$列。 一部のセルにはすでにカラー ラベルが含まれていますが、残りは空です。 すべてのセルに色が付けられ、事前に色付けされたセルは変更されないように、空のセルに色を割り当てる必要があります。 

グリッドが完成したら、同じ色のセルによって形成された連結コンポーネントを調べます。ここで、隣接性は 4 つの基本方向のエッジを共有することによって定義されます。 目標は、すべての色にわたってこのような単色の接続コンポーネントの数を最小限に抑える完成品をデザインすることです。 

重要な自由は、範囲内の任意の色を選択できることです。$[1, 2n]$、各色を一度だけ、またはまったく使用する必要はありません。 唯一の厳しい制約は、事前に色付けされたセルとの一貫性です。 

グリッドがあるので、$2n$セルの合計と最大$2n$利用可能なカラー ラベルの場合、問題は基本的に、隣接関係によって引き起こされる強力な接続制約がある非常に小さな構造全体にラベルをどのように配布するかということです。 

と$n \le 10^5$、すべてのカラーリングを明示的に試したり、グリッド構成に対してステートフル検索を実行したりするソリューションは不可能です。 平$O(n^2)$動作がすでに大きすぎるため、解は線形または線形に近いものでなければなりません。通常、$O(n)$または$O(n \log n)$。 

同じ色がすでに複数の場所で固定されている場合、微妙なエッジケースが発生します。 これらの配置がグリッド内で切り離されている場合、間にある他の固定色と競合する可能性なしに、単純に単一の連続領域を割り当てることはできません。 たとえば、次のような行について考えてみましょう。```
1 0 2 0 1
```ここでは色 1 が両端に表示されます。 すべての色 1 を接続しようとすると、異なる固定色が必要なセルを通過する必要があります。 セルごとに独立して色を割り当てる単純な貪欲な塗りつぶしでは、接続性の前提が崩れ、コンポーネント数が増加します。 

もう 1 つのエッジ ケースは、グリッドの単純な走査順序において、固定色によって「分割」が強制される場合です。 最も最適な構築はグリッドをパス状の構造に変えることに依存しているため、これは重要です。 

## アプローチ

 強引なアイデアは、各空のセルを変数として扱い、接続されたコンポーネントを動的に追跡しながら色の割り当てを試みることです。 各割り当てについて、グリッド セル上で結合検索構造を維持し、色ごとの個別の連結成分の数を計算します。 ただし、各共用体検索の更新は$O(\alpha(n))$、割り当ての数は空のセルの数で指数関数的に増加するため、これは小さなセルを超えると完全に実行不可能になります。$n$。 

重要な観察は、$2 \times n$グリッドは、最初の行で左から右、次に 2 行目で右から左という蛇のような順序ですべてのセルを 1 回だけ訪れる単一のパスに線形化できます。 このようなトラバーサルでは、シーケンス内の隣接するインデックス間のローカルな遷移となる垂直エッジを除き、グリッド内の隣接関係はパス内の隣接関係としてほとんど保存されます。 

この削減は、問題を線上の間隔に関する推論に変えるため、強力です。 色は、そのすべての出現がこの走査の 1 つの連続したセグメントに出現する場合にのみ、連結コンポーネントを形成します。 色が複数の分離されたセグメントに表示される場合、各セグメントは個別の連結成分になります。 

したがって、この問題は、固定位置を尊重しながら、すべての色がヘビのトラバースに沿って最大 1 つの連続ブロックを誘導するように色を割り当てることと同等になります。 

ブルート フォースはセルごとにローカルに推論するため失敗しますが、正しい構造はグローバルです。色はグリッドの特定のハミルトニアン パスの連続性を考慮する必要があります。 この視点を採用すると、構築は貪欲かつ直線的になります。

 ## アルゴリズムのチュートリアル

 まず、$2 \times n$グリッドを長さの線形シーケンスに変換する$2n$。 ヘビ トラバーサルを使用します。最初の行は左から右へ、次に 2 行目は右から左へです。 この順序付けにより、カラー ブロック内の接続に影響を与えない無害な境界効果を除き、グリッド内のすべての隣接関係がシーケンス内でローカルになることが保証されます。 

次に、固定セルを尊重しながら、このシーケンスに沿って最終的な色付けを構築します。 

### ステップ

 1. 全員のスネーク秩序を構築する$2n$セル、その座標を保存します。 これにより、各グリッド位置に線形インデックスが与えられます。 この順序付けが使用されるのは、パス構造内のグリッド接続が維持され、接続されたコンポーネントが連続したセグメントに対応するようになるためです。 
2. 配列を初期化する`ans`最後のグリッドとポインターの場合`i = 0`ヘビのシーケンスを超えて。 
3. 変数を維持する`current_color`連続したセグメントを現在塗りつぶしている色を表します。 最初は空です。 
4. ヘビ シーケンスを左から右に移動します。 各位置で:

 セルに事前に色が付けられている場合は、その色を割り当てる必要があります。 もし`current_color`が空の場合は、その色で新しいセグメントを開始します。 もし`current_color`が異なる場合は、前のセグメントを閉じて、この強制境界で新しいセグメントを開始する必要があることを意味します。 これにより、セグメント内で 2 つの色が混合することがなくなります。 
5. セルが事前に色付けされていない場合、`current_color`が空の場合は、新しい未使用の色を選択します$[1, 2n]$。 これにより、新しいセグメントが作成されます。 
6. 現在のセルに`current_color`。 
7. 次の強制的な色変更またはシーケンスの終了まで続行します。 

このプロセスでは、ヘビのトラバースを最大のセグメントに分割し、それぞれに単一の色を割り当てます。 事前に色付けされたセルは強制セグメント アンカーとして機能し、入力に対する正確性を保証します。 

### なぜ効果があるのか

 この構造により、すべての色が、横断中に同じ色の別の出現によって中断されることがない、互いに素なセグメントの結合を占めることが保証されます。 グリッド内の隣接関係はスネーク シーケンス内の隣接関係または隣接に近い関係にマップされるため、各連続セグメントはグリッド内の接続された領域に対応します。 したがって、各セグメントは、その色の連結成分を 1 つだけ提供します。 一貫性のために必要な場合を除き、色の強制的な出現を複数のセグメントに分割することは決してないため、不必要な断片化が回避され、接続されたコンポーネントの数が直接最小限に抑えられます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a1 = list(map(int, input().split()))
    a2 = list(map(int, input().split()))

    # build snake order
    cells = []
    for j in range(n):
        cells.append((0, j))
    for j in range(n - 1, -1, -1):
        cells.append((1, j))

    grid = [[0] * n for _ in range(2)]
    for j in range(n):
        grid[0][j] = a1[j]
        grid[1][j] = a2[j]

    used = [False] * (2 * n + 1)

    # mark used colors
    for i in range(2):
        for j in range(n):
            if grid[i][j] != 0:
                used[grid[i][j]] = True

    ans = [[0] * n for _ in range(2)]
    current_color = 0

    def new_color():
        for c in range(1, 2 * n + 1):
            if not used[c]:
                used[c] = True
                return c
        return 1

    for idx, (r, c) in enumerate(cells):
        fixed = grid[r][c]

        if fixed != 0:
            if current_color == 0:
                current_color = fixed
            elif current_color != fixed:
                current_color = fixed

        if current_color == 0:
            current_color = new_color()

        ans[r][c] = current_color

    for i in range(2):
        print(*ans[i])

if __name__ == "__main__":
    solve()
```この実装では、最初にスネーク トラバーサルを構築し、次に強制値を尊重しながら貪欲に色を割り当てます。 重要な点は、現在のセグメントとは異なる固定色が見つかったら、すぐにセグメントを切り替えるということです。 これにより、事前に色付けされたセルに間違った値が割り当てられることがなくなります。 

の`new_color`この関数は、新しいセグメントを開始するときに常に未使用のラベルを選択することを保証します。 あるので$2n$色と$2n$セルの場合、利用可能なラベルが不足することはありません。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、スネーク トラバースで固定色が遠く離れて表示される場合です。 例えば：```
1 0 0
0 0 1
```ヘビの順序では、これらの発生はいくつかの細胞によって区切られています。 アルゴリズムはセグメントを最初から開始します`1`、強制的に切り替えられるまで続行し、2 番目の切り替えが行われたときに再起動します。`1`に遭遇します。 これにより 2 つのセグメントが生成されますが、中間割り当てによって固定セルが上書きされたり、不連続な配置が強制されたりするため、これは避けられません。 

もう 1 つのケースは、グリッド全体が空の場合です。 このアルゴリズムは、選択した単一の色で 1 つの長いセグメントを作成するだけで、連結成分が 1 つだけ生成されます。分離を強制する制約がないため、これが最適です。 

最後の微妙なケースは、多くの事前に色付けされたセルが頻繁に強制切り替えを引き起こす場合です。 このアルゴリズムは、すべての強制値をセグメント境界として扱うことでこれを処理し、無効な上書きが発生しないようにしながら、可能な限りセグメントを最大に保ち、制約の下でコンポーネントの数を最小限に保ちます。
