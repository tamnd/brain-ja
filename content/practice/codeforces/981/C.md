 ## 解決策
 ## 問題の理解

 無向ツリーが与えられているので、そのすべてのエッジを単純なパスのコレクションに分割して、すべてのエッジが正確に 1 つのパスに属するようにする必要があります。 追加の要件はグローバルかつ制限的です。これらのパスのいずれかを 2 つ選択する場合、それらは少なくとも 1 つの共通の頂点を共有する必要があります。 

したがって、単に木を恣意的に分解しているわけではありません。 すべてのエッジを 1 回だけカバーしながら、パスのセットに非常に強力な交差構造を強制しています。 

入力は最大 100,000 頂点のツリーであるため、どの解も本質的に線形または線形に近いものでなければなりません。 パスを列挙したり、分解をテストしたり、接続を繰り返し再計算しようとするものはすべて生き残れません。$O(n \log n)$重い定数を使用する場合は、すでに境界線に達しています。 

最初の微妙な問題は、「ツリー内のペアごとに交差するパス」が実際に構造的に何を強制するのかを理解することです。 一般的なグラフでは、ペアごとの交差はグローバルな交差点を意味しません。 ただし、ツリーでは、パスはより厳密に動作します。 単純なパスのすべてのペアが交差する場合、それらはすべて少なくとも 1 つの共通の頂点を共有する必要があります。 それが当てはまらない場合は、異なるサブツリーで分岐する 2 つのパスを選択し、それらの重なりを避けてペアごとの交差と矛盾する 3 番目のパスを構築することができます。 

したがって、私たちが構築しようとしている実際の構造は、すべてのパスが単一の頂点を通過する分解であり、それが普遍的な交差点として機能します。 

木がパスである場合、微妙なエッジケースが現れます。 この場合、唯一の有効な分解は、すべてのエッジをカバーする単一のパスになります。 誤って小さなセグメントに分割しようとすると、反対側の 2 つのセグメントが交差しなくなるため、すべてを 1 つの部分に保たない限り、答えは無効になります。 

もう 1 つの障害モードは、単一ノードを中心にしない分岐構造を持つツリーです。 たとえば、各枝が長い次数 3 の頂点では、単一の交差頂点を強制的に作成しようとする試みが失敗する可能性があります。これは、分解では枝を複数のチェーンに分割する必要があり、エッジの非連結性を考慮しながらすべてを単一の共有頂点を通過させることはできないためです。 

したがって、タスクは、そのような「ユニバーサルセンター」が存在するかどうかを判断し、存在する場合は有効なパーティションを明示的に構築することです。 

## アプローチ

 ブルートフォースアプローチでは、エッジを単純なパスに分割する可能なすべての方法を列挙し、交差状態をチェックしようとします。 パーティションの組み合わせの爆発を無視したとしても、すべてのエッジがパスの開始位置と終了位置を決定できる可能性があるため、ツリーをパスに分割する方法の数はエッジの数で指数関数的に増加します。 のために$n = 10^5$、これはまったく不可能です。 

重要な簡素化は交差制約によって実現されます。 すべてのパスが共通の頂点を共有する必要があることを認識すると、$c$、問題はその頂点の周囲で局所的になります。 すべての有効なパスは通過するように制約されます$c$これは、すべてのパスが、次の位置で結合された 2 つのルートからノードへのセグメントで構成されていることを意味します。$c$、または縮退形式では、で始まる単一のセグメント$c$。 

これにより、問題は、この特別な頂点にルートしたときにツリーがどのように見えるかを理解することに変わります。$c$。 各エッジは、次の位置で始まる 1 つのパスに正確に割り当てられます。$c$そして木の中へ降りていきます。 パスは分岐できないので、以下の構造となります。$c$切り離されたチェーンのように動作する必要があります。 サブツリーに分岐ノードが含まれている場合、$c$、エッジの非連結性に違反せずに分岐を単一の単純なパスに収容することはできないということです。 

したがって、問題は頂点を見つけることに帰着します$c$削除後のツリーのすべての接続コンポーネントが$c$は単純なパスグラフです。 このような頂点が見つかると、各コンポーネントをチェーンとしてたどって、次から始まる 1 つのパスに変えることができます。$c$。

 ## アルゴリズムのチュートリアル

 適切な中心頂点を検索し、その周囲のツリーを分解することでソリューションを構築します。 

1. すべての頂点を反復処理し、それぞれを中心候補とみなします。 頂点を有効にするには、削除後のすべての接続コンポーネントに分岐が含まれていてはなりません。つまり、そのコンポーネント内のノードは元のツリーで 2 より大きい次数を持つことができません。 
2. 選択した候補頂点の場合$c$、一時的にそれを無視し、各近隣のサブツリーを検査します。 各サブツリー内で、すべてのノードがそのサブツリー構造内に留まるインシデント エッジを最大 2 つ持つことを保証します。 これにより、各サブツリーが分岐構造ではなくチェーンであることが保証されます。 
3. 有効なセンターになると$c$が見つかったら、ツリーをルートします。$c$そして道を作り始めます。 隣接するサブツリーに入るたびに、リーフまたは分岐境界に到達するまで一意のチェーンを外側にたどり、途中でノードを収集します。 
4. このような各走査により、次から始まる 1 つの単純なパスが生成されます。$c$そして外に向かって伸びています。 サブツリーはチェーンであるため、このウォークは決定的であり、そのコンポーネント内のすべてのエッジを 1 回だけカバーします。 
5. そのようなパスをすべて出力します。 すべてのエッジは正確に 1 つのサブツリー チェーンに属しているため、エッジの共通性は保たれ、すべてのパスには次のものが含まれます。$c$、必要なペアごとの交差が保証されます。 

重要な不変条件は、有効な中心を選択した後、$c$、のすべての接続コンポーネント$G - c$パスグラフです。 これにより、これらのコンポーネントの各エッジが、次から始まる正確に 1 つの線形チェーンに属することが保証されます。$c$したがって、分岐によってパスの再利用や分割が強制されることはありません。 すべてのパスには次のものが含まれるため、$c$、任意の 2 つのパスは少なくとも次の時点で交差します。$c$、大域条件を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

n = int(input())
g = [[] for _ in range(n)]

for _ in range(n - 1):
    a, b = map(int, input().split())
    a -= 1
    b -= 1
    g[a].append(b)
    g[b].append(a)

deg = [len(g[i]) for i in range(n)]

# find candidate center: node such that all nodes except it have deg <= 2
center = -1
for v in range(n):
    ok = True
    for u in range(n):
        if u != v and deg[u] > 2:
            ok = False
            break
    if ok:
        center = v
        break

if center == -1:
    print("No")
    sys.exit()

visited = [False] * n
visited[center] = True

paths = []

def dfs(u, path):
    visited[u] = True
    path.append(u)
    nxt = -1
    for v in g[u]:
        if not visited[v]:
            nxt = v
            break
    if nxt == -1:
        paths.append(path)
        return
    dfs(nxt, path)

for v in g[center]:
    if not visited[v]:
        dfs(v, [center])

print("Yes")
print(len(paths))
for p in paths:
    print(p[0] + 1, p[-1] + 1)
```この実装では、まず次数を計算し、グローバル交差点として機能する頂点を検索します。 ここで強制される条件は、他の頂点が 2 より大きい次数を持たないことです。これにより、中心を削除した後に形成されるすべてのサブツリーが単純なチェーンになることが保証されます。 

中心を固定した後、未訪問の各隣接サブツリーは、固有の利用可能な方向を前方にたどる深さ優先ウォークでトラバースされます。 内部ノードにはサブツリー内の未使用のエッジが最大 2 つあるため、この走査は分岐することがなく、単一のクリーンなパスが生成されます。 各パスはそのエンドポイントによって記録されるため、出力には十分です。 

微妙な点は、DFS を常に中心から開始し、すぐに各サブツリーに拡張することです。 これにより、構築されたすべてのパスに中心頂点が含まれることが保証されます。これが交差条件が成立する構造的な理由です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    from collections import deque

    n = int(_sys.stdin.readline())
    g = [[] for _ in range(n)]
    deg = [0]*n
    for _ in range(n-1):
        a,b = map(int,_sys.stdin.readline().split())
        a-=1; b-=1
        g[a].append(b)
        g[b].append(a)
        deg[a]+=1; deg[b]+=1

    center = -1
    for v in range(n):
        ok = True
        for u in range(n):
            if u != v and deg[u] > 2:
                ok = False
                break
        if ok:
            center = v
            break

    if center == -1:
        return "No\n"

    vis = [False]*n
    vis[center]=True
    paths=[]

    sys.setrecursionlimit(10**7)

    def dfs(u, path):
        vis[u]=True
        path.append(u)
        for v in g[u]:
            if not vis[v]:
                dfs(v, path)
                return
        paths.append(path)

    for v in g[center]:
        if not vis[v]:
            dfs(v,[center])

    out = ["Yes", str(len(paths))]
    for p in paths:
        out.append(f"{p[0]+1} {p[-1]+1}")
    return "\n".join(out)+"\n"

 ## 特殊なケース

 パス形状のツリーは、アルゴリズムが過剰な分割を回避するかどうかをテストします。 このような場合、エンドポイントを除くすべてのノードは次数 2 を持つため、有効な中心はどれでも機能します。 DFS は、構造全体をカバーする正確に 1 つのパスを生成します。パスが 1 つしかないため、出力は有効なままであり、交差条件は自明に当てはまります。 

星形のツリーは、中心の選択がハブを正しく識別しているかどうかをチェックします。 すべての葉の次数が 1 であるため、中心のみが次数が高くなります。 中心からの各 DFS は直ちに終了し、シングルエッジ パスが生成され、そのすべてが中心頂点を共有し、条件を満たします。 

選択した中心から離れた単一の分岐ノードを持つ混合ツリーは失敗を示します。 次数条件は、分岐ノードが「他のすべてのノードが次数 ≤ 2 である」という要件に違反するため、これを除外し、アルゴリズムが無効な分解を試行するのではなく、正しく「いいえ」を出力するようにします。
