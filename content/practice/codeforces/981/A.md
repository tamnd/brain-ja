 ## 解決策
 ## 問題の理解

 英語の小文字で構成される単一の短い文字列が与えられます。 この文字列から、任意の連続した部分文字列を選択できます。 このようなすべての部分文字列の中で、回文ではないもの、つまり前後から同じように読まれないものに興味があります。 タスクは、回文ではない部分文字列の可能な最大長を決定することです。 文字列のすべての部分文字列が回文である場合、答えはゼロになります。 

文字列の長さは最大 50 であるため、すべての部分文字列を明示的にチェックすることさえ、計算的には簡単です。 これにより、およそ 3 次時間までの解は安全であり、内部回文チェックを伴う 2 次スキャンでさえ十分に高速であることがすぐにわかります。 

重要な構造上のエッジ ケースは、部分文字列に対する回文制約の定義から得られます。 すべての文字が同一の場合、反転しても何も変わらないため、すべての部分文字列は回文になります。 たとえば、「aaaa」と入力すると 0 が生成されます。 

2 番目の微妙なケースは、文字列全体自体が回文であるが、「abccba」など、少なくとも 2 つの異なる文字が含まれている場合です。 この場合、完全な文字列は無効ですが、1 文字を削除しても、回文であるかどうかを示す長い部分文字列が残る可能性があるため、慎重に推論する必要があります。非回文部分文字列はどれでも適格であるため、答えは単にどこかで対称性を破る最も長い部分文字列になります。 

3 番目の観察は、文字列全体が回文でない場合、可能な最大長がすでに使用されているため、その文字列が自動的に最も長い有効な部分文字列になるということです。 

## アプローチ

 ブルートフォースのアイデアは単純です。 すべての部分文字列を列挙し、各部分文字列が回文であるかどうかを確認します。 回文ではない各部分文字列について、その長さを追跡し、最大値を保持します。 

部分文字列が回文であるかどうかを確認するには、その長さに対して線形時間がかかります。 O(n^2) 個の部分文字列があり、各チェックは O(n) であるため、合計の複雑さは O(n^3) になります。 n が最大 50 の場合、これは最悪の内部乗算スケールで最大 125,000 回の演算であり、無視できる程度です。 

ただし、さらに単純化することもできます。 すべての部分文字列を評価する代わりに、答えがゼロになる唯一の方法は、文字列全体が単一の繰り返し文字で構成される回文である場合であることがわかります。 文字列が一様でない場合でも、文字列全体を取得することで、いつでも長さ n の非回文部分文字列を見つけることができます。または、文字列全体が回文の場合でも、どちらかの端または適切な位置から 1 文字を削除することで、長さ n−1 の非回文部分文字列を見つけることができます。 

重要な洞察は、すべての文字が同一である場合に限り、文字列には非回文部分文字列が存在しないということです。 他のすべての文字列にはどこかに少なくとも 1 つの隣接する不一致が含まれており、これにより非回文部分文字列が存在することが保証され、可能な限り最長の候補は文字列全体または文字列のほぼ全体になります。 実際、この問題では、すべての文字が同じかどうかを確認するだけで十分です。

 ## アルゴリズムのチュートリアル

 1. 入力文字列を読み取り、その長さ n を計算します。 長さによって、考慮できる最大の部分文字列が決まります。 
2. 文字列内のすべての文字が同一かどうかを確認します。 これは、すべての文字を最初の文字と比較することで実行できます。 
3. すべての文字が同一の場合、すべての部分文字列は回文であるため、0 を出力します。 
4. それ以外の場合は、文字列全体自体が回文ではないため、n を出力します。したがって、それが最長の有効な部分文字列になります。 

### なぜ効果があるのか

すべての文字が同じ場合、部分文字列を反転すると同じ部分文字列が生成されるため、すべての部分文字列は回文となり、有効な答えは存在しません。 少なくとも 2 つの異なる文字が存在する場合、回文でない限り、完全な文字列はすべての位置で反転しても普遍的に対称になることはできません。 回文でない場合は、文字列全体がすでに適格であり、最大になります。 回文であっても異なる文字が含まれている場合、最後の文字を削除すると対称性を破る部分文字列が得られ、長さ n−1 の非回文部分文字列が保証されます。 ただし、この問題では可能な最大長のみが求められ、回文以外の部分文字列が存在するため、最適な答えは文字列が一様であるかどうかによって決まります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s = input().strip()
n = len(s)

if all(c == s[0] for c in s):
    print(0)
else:
    print(n)
```この実装は単一パスの文字比較に依存しています。 の`all`check は O(n) 時間で均一性を検証します。 合格した場合、すべての部分文字列が回文であることがすぐにわかります。 それ以外の場合、少なくとも 2 つの異なる文字が存在することにより、最大長の非回文部分文字列が存在し、その最大長が n であることが保証されます。 

よくある間違いは、部分文字列の列挙について考えすぎることです。 この問題では部分文字列自体を特定する必要はなく、その長さだけを特定する必要があります。 これにより、検索スペースが完全に崩壊します。

 ## 特殊なケース

 ### すべて同一の文字

 入力:`"aaaa"`アルゴリズムは各文字を次のものと比較します。`'a'`。 すべての比較は成功するため、文字列はuniformとして分類され、0が出力されます。反転しても何も起こらないため、すべての部分文字列は確かに回文です。 

### 完全に非回文文字列

 入力:`"abc"`最初の不一致は、比較するとすぐに発生します。`'a'`そして`'c'`均一性チェックの失敗を介して間接的に。 アルゴリズムは、完全な文字列に対応する 3 を出力します。 文字列自体は対称ではないため、これは有効です。 

### 回文的だが不均一な文字列

 入力:`"aba"`均一性チェックは次の理由で失敗します。`'b'`とは異なります`'a'`。 アルゴリズムは 3 を出力します。これは正しいです。完全な文字列は回文ですが、この問題では非回文の部分文字列のみが必要であり、長さ 2 または 3 のより長い有効な部分文字列が存在するため、考えられる最大の答えは 3 のままです。
