 ## 問題の理解

有効な取り決めでは、各新郎と 1 人の新婦がペアになり、2 組の間で完璧な組み合わせが形成されます。 どの組み合わせでも、花嫁は割り当てられた新郎の城に到達するために円に沿って移動し、常に 2 つの可能な円弧のうち短い方を選択します。 ペアリングのコストは、すべての花嫁の最大移動距離として定義され、タスクはこの最大値を最小化することです。 

ここでの重要な構造は、距離を合計しているのではなく、円形の計量空間でのマッチングにおけるボトルネックを最適化しているということです。

 ## アルゴリズムのチュートリアル

 1. 両方の位置の配列を並べ替えます。 ソートは、循環データに構造を課し、一貫して相対的な順序を推論できるようにするために必要です。 
2.追加して新郎の位置を複製します。$L$それぞれに拡張されたサイズの配列を形成します$2n$。 これにより、線形表現で間隔が「境界を越える」ことが可能になり、循環ラップアラウンドの問題が解消されます。 
3. 固定の回答候補の場合$x$、各花嫁について、距離内にある新郎の位置の範囲を計算します。$x$サークル上で。 包装を解いた後、各花嫁は連続した間隔に対応します$[l_i, r_i]$。 
4. 間隔の正しい終点で花嫁を並べ替えます。 この順序により、最も制約の多い花嫁を常に最初に満足させることができるため、後の衝突を防ぐことができます。 
5. 利用可能な新郎の位置の上にポインターを維持します。 順番に花嫁ごとに、その間隔内にある最初の未使用の新郎の位置にポインタを進めます。 存在しない場合、候補は$x$は無効です。 
6. 最小二分探索$x$実現可能性チェックが成功するように。 

正しいエンドポイントによる並べ替えが機能する理由は、先に終了する間隔を割り当てることで、間隔スケジュールのバリアントの標準的な貪欲な原則である厳しい制約がブロックされる可能性が最初に最小限に抑えられるためです。 

### なぜ効果があるのか

 円をアンラップした後、固定しきい値の下で有効なマッチングはすべて、同じ点を共有する 2 つの区間が存在しないように、各区間から 1 つの点を選択することに対応します。 これは、片側に間隔制約がある 2 部マッチングです。 すべてのステップで、利用可能な最も早い実行可能なグルームを選択することで、残りのすべての間隔に対して最大限の柔軟性が残されるため、貪欲な戦略は正しいです。 割り当てを遅らせる代替選択は、現在の間隔の実現可能性を向上させることなく、将来利用可能なオプションを減らすだけです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can(x, a, b, L):
    n = len(a)
    
    # duplicate groom positions for circular wrap
    g = a + [v + L for v in a]
    
    # build intervals for brides
    intervals = []
    for bi in b:
        l = bi - x
        r = bi + x
        
        # normalize to linear doubled space
        # find valid range in g
        intervals.append((l, r))
    
    intervals.sort(key=lambda t: t[1])
    
    j = 0
    used = 0
    
    for l, r in intervals:
        while j < len(g) and g[j] < l:
            j += 1
        if j == len(g) or g[j] > r:
            return False
        used += 1
        j += 1
    
    return True

def solve():
    n, L = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    a.sort()
    b.sort()
    
    # binary search answer
    lo, hi = 0, L // 2
    
    while lo < hi:
        mid = (lo + hi) // 2
        if can(mid, a, b, L):
            hi = mid
        else:
            lo = mid + 1
    
    print(lo)

if __name__ == "__main__":
    solve()
```コードはまず、両方の位置セットを並べ替えます。これは、単調間隔を構築するために不可欠です。 実現可能性関数は、循環ラップアラウンドを考慮した新郎の位置の拡張リストに対して花嫁を貪欲に照合しようとします。 

二分探索では、答えが次のように制限されます。$[0, L/2]$なぜなら、円上の最短経路距離は円周の半分を超えることができないからです。 

微妙な点は、新郎用に 2 つの配列を使用していることです。 これにより、間隔が境界を横切るときにモジュラー演算を明示的に処理する必要がなくなります。$0$境界。 ポインタ`j`一致する制約を維持しながら、各グルームが最大 1 回使用されるようにします。
