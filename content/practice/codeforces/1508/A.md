 ## 解決策
 ## 問題の理解

 3 つの異なるビット文字列が与えられ、それぞれの長さが異なります。$2n$、そして最大で次の長さの新しいビット文字列を構築する必要があります$3n$これら 3 つの文字列のうち少なくとも 2 つがサブシーケンスとして含まれています。 サブシーケンス条件を使用すると、指定された文字列の 1 つに一致する文字を新しい文字列から削除できるため、正確な配置を保持する必要はなく、順序のみを保持する必要があります。 私たちのタスクは基本的に、長さの制限を超えずに 2 つのビット文字列を 1 つのビット文字列にマージすることです。 

入力は複数のテスト ケースを提供し、それぞれに独自の値が含まれます。$n$そして3つのビット列。 すべての合計$n$すべてのテスト ケースで最大でも$10^5$、これは、次の線形複雑さを持つソリューションが存在することを示唆しています。$n$テストケースごとに許容されます。 テスト ケースごとに 2 次複雑度を持つソリューションは遅すぎます。$2n \approx 2 \cdot 10^5$単一のテストケースでは、次のような結果になる可能性があります$10^{10}$操作。 

微妙な点は、3 つの文字列が区別されることは保証されていますが、0 と 1 の分布については保証がないということです。 単純に 3 つの文字列すべてを一度にマージしようとすると、長さの制限を超える可能性があります。 たとえば、3 つの文字列すべてを盲目的にインターリーブしようとすると、次の長さの文字列が生成される可能性があります。$6n$、これは無効です。 もう 1 つの注意が必要なシナリオは、2 つの文字列が 1 つの文字 (たとえば、ほとんどが 0) に大きく偏っていて、3 番目の文字列がほとんど他の文字である場合です。 効率的にマージするには、互換性のある過半数を持つ 2 つの文字列を選択する必要があります。 

## アプローチ

 ブルートフォースアプローチは、2 つの文字列の考えられるすべての部分シーケンスを考慮し、各文字を手動で位置合わせしてそれらをマージしようとすることです。 これにより、考えられるすべての配置がチェックされるため正確性が保証されますが、文字列の長さに応じて操作数が指数関数的に増加するため、これは実行不可能です。$n \le 10^5$。 

重要な洞察は、2 つの文字列が過半数の文字を共有する場合、両方とも少なくとも$n$ゼロ - それらを効率的にマージできます。 指定された各文字列には長さがあります$2n$, したがって、鳩の巣原理によ​​り、そのうちの少なくとも 2 つは多数派の性格を共有します。 同じ過半数文字を持つ 2 つの文字列を選択したら、2 ポインター手法を使用してそれらをマージできます。 両方の文字列をスキャンし、多数の文字が見つかった場合は常にそれを出力します。 他の文字については、順序を維持したまま少数の文字を挟むことができます。 これにより、両方の文字列がサブシーケンスとして表示され、マージされた文字列が次の値を超えることがないことが保証されます。$3n$長さ的には。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、3 つの文字列それぞれの 0 の数を数えます。 文字列に少なくとも$n$ゼロの場合、その大部分の文字は 0 です。 それ以外の場合、過半数は 1 です。 
2. 同じ多数文字を共有する任意の 2 つの文字列を選択します。 鳩の穴の原理により、少なくとも 2 つの文字列は同じ多数文字を持つことになるため、このステップは常に可能です。 
3. これら 2 つの文字列の先頭にある 2 つのポインタと空の結果文字列を初期化します。 順序を維持しながら文字ごとに結合していきます。 
4. どちらのポインタも文字列の末尾に到達していない間に、次のようにします。 

- 両方のポインターの文字が多数派文字と等しい場合、それを結果に追加し、両方のポインターを進めます。 
- 文字が異なる場合は、ポインタが指す文字列から非多数決文字を追加し、そのポインタを進めます。 これにより、サブシーケンスに必要な文字を見逃すことがなくなります。 
5. 一方の文字列が完全に結合されたら、もう一方の文字列の残りの文字を追加します。 過半数文字の合計数は少なくとも$n$文字列ごとに、最終的にマージされた文字列の長さが超えることはありません$3n$。 
6. 結合された文字列を出力します。 この文字列には、選択した両方の文字列がサブシーケンスとして含まれており、長さの制約を満たしています。 

マージ全体を通じて不変なのは、選択した両方の文字列のすべての文字が結果に順番に表示されることです。 過半数の文字に基づいてマージし、相対的な順序を維持するため、両方の文字列はマージされた文字列のサブシーケンスのままになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = input().strip()
        b = input().strip()
        c = input().strip()
        strings = [a, b, c]

        # Determine majority character (0 or 1) for each string
        majorities = []
        for s in strings:
            if s.count('0') >= n:
                majorities.append('0')
            else:
                majorities.append('1')

        # Pick two strings with same majority
        if majorities[0] == majorities[1]:
            s1, s2, ch = strings[0], strings[1], majorities[0]
        elif majorities[0] == majorities[2]:
            s1, s2, ch = strings[0], strings[2], majorities[0]
        else:
            s1, s2, ch = strings[1], strings[2], majorities[1]

        # Merge s1 and s2 based on majority character
        i = j = 0
        res = []
        while i < 2*n and j < 2*n:
            if s1[i] == s2[j]:
                res.append(s1[i])
                i += 1
                j += 1
            elif s1[i] == ch:
                res.append(s1[i])
                i += 1
            else:
                res.append(s2[j])
                j += 1
        # Append remaining characters
        res.extend(s1[i:])
        res.extend(s2[j:])
        print(''.join(res))

solve()
```コードはまず、各文字列内でどの文字が多数を占めているかを判断し、この多数を共有する 2 つの文字列を選択します。 次に、2 ポインターのマージ戦略を使用して、順序を維持しながら文字を追加し、選択された両方の文字列をサブシーケンスとして含む文字列を構築します。 残りの文字を最後に追加することで、文字が失われないことが保証され、2 ポインター戦略により、マージされた文字列の長さが次の範囲内に収まることが保証されます。$3n$。
