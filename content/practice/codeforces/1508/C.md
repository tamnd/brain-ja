 ## 解決策
 ## 問題の理解

 完全な無向グラフを使用していますが、固定重みが付いているのは一部のエッジのみです。 欠落しているすべてのエッジには、必要な非負の整数の重みを割り当てることができます。 欠落している重みをすべて割り当てた後は、2 つの条件が同時に成立する必要があります。 まず、グラフ全体のすべてのエッジの重みのビット単位の XOR を計算すると、結果はゼロになる必要があります。 第 2 に、そのようなすべての有効な割り当ての中で、最小スパニング ツリーの可能な最小の重みが必要です。 

重要な問題は、固定重みに対して MST を最適化するだけではないことです。 グラフの大部分を再形成することができますが、XOR 制約によりすべてのエッジがグローバルに結合されます。 1 つのエッジの重みを変更すると、別の場所で強制的に補償変更が行われます。 

入力サイズにより、これは微妙になります。 最大 200,000 個のノードと 200,000 個の固定エッジでは、Θ(n²) 個のエッジがあるため、完全なグラフを構築したり、概念的に処理したりすることは明らかに不可能です。 どのような解決策も、ほぼすべてのエッジを無視し、与えられたエッジと私たちが推論した少数の人工的なエッジによって引き起こされる制約された構造でのみ機能する必要があります。 

XOR 制約を無視したり、欠落しているエッジをゼロとして扱ったりすると、微妙な障害モードが発生します。 たとえば、指定されたすべてのエッジがすでにサイクルを形成している場合、MST が固定されていると誤って仮定する可能性があります。 ただし、XOR 制約により、重みの高いエッジを間接的に挿入する必要が生じ、MST コストが増加する可能性があります。 

もう 1 つのエッジ ケースは、指定されたエッジがまったくない場合です。 その後、すべてのエッジを自由に割り当てることができますが、それでも合計 XOR がゼロであり、MST が最小化されていることを確認する必要があります。 単純な解決策ではすべて 0 を割り当てる可能性がありますが、これは無効です。パリティが機能する場合にのみ XOR が 0 のままになり、MST は簡単なものになる可能性がありますが、構築によっては制約が依然として重要になります。 

最後に、特に危険なケースは、指定されたエッジがすでにゼロ以外の XOR を強制している場合です。 次に、追加のエッジを 1 つ使用してそれを「修正」する必要があり、この修正がどこに着地するかを選択することが最適化の問題全体になります。 

## アプローチ

 XOR 制約を無視すると、完全なグラフに対する MST 問題の構造は自明です。最小スパニング ツリーは、すべてのエッジをソートすることによって単純に決定されます。 しかし、ここではグラフは完全にはわかっておらず、さらに重要なのは、欠落している重みを選択できることです。 

強引なアイデアは、欠落しているエッジの可能なすべての割り当てを検討することです。 各割り当ては完全な重み付きグラフを定義し、その MST を計算して XOR の妥当性をチェックできます。 これは正しいですが、すぐには不可能です。 重みを小さな値に制限したとしても、欠落エッジの数は Θ(n²) であるため、割り当ての数は Θ(n²) で指数関数的になります。 これは計算限界をはるかに超えて失敗します。 

重要な点は、実際には完全なグラフは必要ないということです。 自由に割り当て可能なエッジを持つ完全なグラフの MST では、エッジの小さなサブセットのみが問題になります。MST は常に小さな重みを持つエッジを優先し、明示的に使用したい場合を除いて、ほぼすべてのエッジを自由に極端に大きくすることができます。 

これは重要な言い換えにつながります。 指定されたエッジによって形成される構造のみを考慮します。 与えられたエッジによって接続されたすべてのノードがグラフを形成していると考えてください。 この固定部分にわたる最小スパン フォレストを計算できます。 欠落している接続は、XOR 制約を尊重する必要がある場合を除き、人為的に安価なエッジを追加することで処理できます。 

ここからが主な構造的洞察です。 与えられたすべてのエッジを取得し、それらの XOR を計算するとします。これを X と呼びます。X がすでに 0 の場合、XOR の補正エッジは必要ありません。欠落しているエッジをすべて非常に大きく割り当てることができるため、MST に影響を与えることはありません。 答えは、単純に、特定のグラフ コンポーネントの MST に最小限の接続を加えたものです。

X がゼロ以外の場合、重みが XOR 調整を伴う有効な補正エッジを 1 つだけ導入する必要があります。 すべてのエッジの XOR がゼロになる必要があるため、そのエッジは重み X を持つ必要があります。 唯一の自由は、MST への影響を最小限に抑えるために、この補正エッジをどこに配置するかです。 

欠落したエッジはどこにでも作成できるため、任意の 2 つのノードを接続する重み X を持つ 1 つの追加エッジを追加することを想像できます。 最適な戦略は、コストが向上するかどうかに応じて、このエッジが MST に入るか、安全に回避されるようにすることです。 これにより、問題は、指定されたエッジと重み X の 1 つの余分な候補エッジで構成されるグラフの MST を計算することになります。 

残りの微妙な点は、他のすべての欠けているエッジも制御することです。 これらを非常に大きな値に設定して、MST に入らないようにすることができます。 これにより、MST 構造が指定されたエッジと、場合によっては 1 つの補正エッジのみに依存することが保証されます。 

したがって、問題は次のようになります。指定された m 個のエッジと、指定されたすべての重みの XOR に等しい重みを持つ追加のエッジを 1 つ持つグラフに対して MST を計算します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数関数 | 指数関数 | 遅すぎる |
 | 最適 | O(m log n) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 指定されたエッジをすべて読み取り、それらの重みの XOR を計算します。 この値は、合計 XOR をゼロにするために必要な補正を表します。 
2. 指定されたエッジのみで構成されるグラフを構築します。 接続に必要な場合を除き、欠落エッジは無限に大きく無関係なものとして扱われる可能性があるため、欠落エッジを明示的に構築しません。 
3. 任意の 2 つのノード (便宜上、ノード 1 と 2、または任意の固定ペアを選択できます) の間に、計算された XOR 値と等しい重みを持つ人工エッジを 1 つ追加します。 このエッジは、グローバル XOR 制約を満たす唯一の方法を表します。 
4. この拡張されたエッジ セットに対して Kruskal のアルゴリズムを実行します。 エッジを重みでソートし、DSU を使用して最小スパニング ツリーを構築します。 
5. 結果として得られる MST 重みが答えです。 

ステップ 3 の背後にある主な理由は、XOR 制約によって重み付けシステム内の 1 つの「調整単位」が強制されるということです。 この調整は、重みが XOR の不一致をエンコードする単一のエッジとしてモデル化できます。 

### なぜ効果があるのか

 すべての欠落エッジには任意の大きな値を割り当てることができるため、接続に絶対に必要な場合を除き、MST に表示されることはありません。 これは、MST が指定されたエッジと単一の補正エッジによって完全に決定されることを意味します。 有効な重みの割り当ては補正効果の何らかの配置に対応しますが、MST コストの観点から見ると、そのような配置はすべて、XOR 値 X を運ぶ最も安価なエッジ構造を選択することと同等です。クラスカルのアルゴリズムは、この補正エッジを含めることが役立つ場合は、それが最適な方法で使用されることを保証します。 それ以外の場合はスキップされ、正確性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.r[a] < self.r[b]:
            a, b = b, a
        self.p[b] = a
        if self.r[a] == self.r[b]:
            self.r[a] += 1
        return True

n, m = map(int, input().split())
edges = []
xor_all = 0

for _ in range(m):
    u, v, w = map(int, input().split())
    u -= 1
    v -= 1
    edges.append((w, u, v))
    xor_all ^= w

if xor_all != 0:
    edges.append((xor_all, 0, 1))

edges.sort()

dsu = DSU(n)
ans = 0

for w, u, v in edges:
    if dsu.union(u, v):
        ans += w

print(ans)
```この実装では、XOR の累算が MST の構築から分離されます。 DSU は接続を維持しますが、Kruskal は最小のエッジを貪欲に追加します。 人工エッジは必要な場合にのみ導入され、MST の選択によって自然に寄与するかどうかが決定されるため、その配置は重要ではありません。 

微妙な点は、欠落しているエッジをすべて明示的にモデル化していないことです。 それらの暗黙の役割は「無限に大きなウェイト エッジ」であるため、クラスカルの順序付けでは決して必要ありません。 

## 実用的な例

 ### 例 1

 入力:```
4 4
2 1 14
1 4 14
3 2 15
4 3 8
```ここではすべてのエッジがすでに指定されています。 

XOR を計算します。 

| ステップ | エッジ | これまでの XOR |
 | --- | --- | --- |
 | 1 | 14 | 14 |
 | 2 | 14 | 0 |
 | 3 | 15 | 15 |
 | 4 | 8 | 7 |

 したがって、XOR は 7 であり、重み 7 の補正エッジを追加する必要があることを意味します。 

ここで、Kruskal を 5 つのエッジ上で実行します。 

エッジを 7、8、14、14、15 に並べ替えます。 

循環を避けながらエッジを順番に選択します。 

| エッジ | 撮影 | DSU の状態変化 |
 | --- | --- | --- |
 | 7 | はい | 0-1を接続します |
 | 8 | はい | コンポーネントを接続する |
 | 14 | はい | 残りのコンポーネントをマージします |
 | 14 | いいえ | サイクル |
 | 15 | いいえ | サイクル |

 MST の合計の重みは 7 + 8 + 14 = 29 になりますが、MST に必要なエッジは 3 つだけなので、最終的に選択されたエッジのコストは最適構造と同様に 15 になります。 

これは、補正エッジが既存の構造を支配するのではなく、どのように競合するかを示しています。 

### 例 2

 入力:```
3 0
```エッジが指定されていないため、XOR は 0 です。補正エッジは追加しません。 

MST は、欠落しているエッジの中から可能な限り最小のエッジを暗黙的に選択することによって完全に形成されます。 エッジを自由に割り当てることができるため、重みがゼロのエッジを持つツリーを効果的に作成できます。 

| ステップ | アクション | コスト |
 | --- | --- | --- |
 | 1 | 固定エッジなし | 0 |
 | 2 | 修正は必要ありません | 0 |

 答えは0です。 

これは、制約が存在しない場合、解は重みゼロのスパニング ツリーに崩壊することを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(m log m) | エッジのソートが優勢で、DSU の動作はほぼ一定です。 
| スペース | O(n + m) | DSU アレイと格納されたエッジ |

 この制約では最大 200,000 のエッジが許可されるため、並べ替えと DSU 操作は容易に制限内に収まります。 このソリューションは、完全なグラフの n² 構造への依存を回避します。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    class DSU:
        def __init__(self, n):
            self.p = list(range(n))
            self.r = [0]*n
        def find(self, x):
            while self.p[x] != x:
                self.p[x] = self.p[self.p[x]]
                x = self.p[x]
            return x
        def union(self, a, b):
            a = self.find(a)
            b = self.find(b)
            if a == b:
                return False
            if self.r[a] < self.r[b]:
                a, b = b, a
            self.p[b] = a
            if self.r[a] == self.r[b]:
                self.r[a] += 1
            return True

    n, m = map(int, input().split())
    edges = []
    x = 0
    for _ in range(m):
        u,v,w = map(int, input().split())
        u-=1; v-=1
        edges.append((w,u,v))
        x ^= w

    if x:
        edges.append((x,0,1))

    edges.sort()
    dsu = DSU(n)
    ans = 0
    for w,u,v in edges:
        if dsu.union(u,v):
            ans += w
    return str(ans)

 ## 特殊なケース

 指定されたエッジがない場合でも、アルゴリズムは重み 0 の有効な MST を生成します。これは、暗黙的な完全グラフにより、XOR を自明に満たしながら重み 0 のスパニング ツリーを構築できるためです。 これは、不必要な補正エッジを強制していないことをテストします。 

指定されたエッジの XOR がすでにゼロである場合、補正エッジを追加することは有害です。 このアルゴリズムは、必要な場合にのみ挿入することでこれを回避し、MST が歪まないようにします。 

与えられたエッジがすでにサイクルを形成している場合、Kruskal は冗長なエッジを自然に破棄します。 XOR 補正エッジはこれらのサイクルと公平に競合し、総コストが削減される場合にのみ参加します。これにより、高価な強制構造が誤って含まれることが防止されます。
