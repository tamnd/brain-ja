 ## 解決策
 ## 問題の理解

 N 次元ユークリッド空間内のいくつかの点が与えられます。 重要な条件は、指定された点のすべてのペアが正確に 1 単位離れていることです。そのため、これらの点は、すべての相互距離が同一である完全に規則的な幾何学的構造をすでに形成しています。 

タスクは、同じプロパティを維持しながら、できるだけ多くの新しいポイントを追加して、この構成を拡張することです。元のポイントと新しく追加されたポイントの間のすべてのポイントのペアは、依然として正確に距離 1 離れている必要があります。 追加可能な点の最大数を決定した後、入力と同じ座標系でそれらの新しい点の座標も出力する必要があります。 

幾何学的に、これは、すべてのペアごとの距離が等しい場合に、N 次元空間内の点のセットがどのくらい大きくなるのか、そして部分的に与えられたそのような構成を可能な限り最大の構成に完成させる方法を尋ねています。 

この制約では、最大 100 個のテスト ケースと最大 100 個のディメンションが許可されます。各テストには多くの点を含めることができますが、指定されたすべての点はすでに相互に等距離にあるため、非常に剛性の高い構造を形成します。 この剛性が中心的な手がかりです。N 次元で可能な最大構成サイズは本質的に 1 つだけであり、すべての有効な解決策は、同じ基礎となる形状の剛体変換でなければなりません。 

素朴なアイデアは、既存のすべての点に距離制約を適用する二次方程式を解くことによって追加の点を構築してみることです。 ただし、単一の点を追加する場合でも、N 個の変数で M 個の二次方程式を満たす必要があり、これを繰り返し行うとすぐに数値的に不安定になり、組み合わせが複雑になります。 さらに悪いことに、グローバル構造を認識しないと、新しいポイントのさまざまな選択が相互作用し、以前の選択が無効になる可能性があります。 

主なエッジケースは、M がすでに最大可能サイズに等しい場合です。 たとえば、N = 2 の場合、相互の距離 1 にある点は最大 3 つです。M = 3 の場合、点を追加できません。 セットを常に拡張できると仮定する不注意な解決策は、ユークリッド幾何学では不可能な 4 番目の点を誤って構築しようとします。 

## アプローチ

 強引な戦略では、1つずつポイントを追加しようとします。 候補点ごとに、既存のすべての点までの距離 1 を適用する連立方程式を解き、有効な解が存在するかどうかを確認します。 見つかった場合は、それを追加して繰り返します。 問題は、各ステップで M 個の制約を持つ N 個の変数の非線形システムを解く必要があり、可能性の数が爆発的に増加することです。 解空間は連続領域ではなく単一の剛体構成であるため、離散化またはランダム検索を試みても失敗します。 

重要な構造的観察は、すべてのペアが距離 1 にある一連の点が正則シンプレックスを形成しているということです。 N 次元空間では、このような構成の最大可能サイズは N + 1 ポイントです。 これは古典的な幾何学的事実です。空間が完全に飽和するまで、新しい点ごとに独立した次元が追加されます。 

最終的な答えに正確に N + 1 個の点が含まれている必要があることがわかると、問題は完了の 1 つになります。つまり、正単体の M 個の頂点が与えられ、同じ埋め込みで不足している N + 1 − M 個の頂点を再構築する必要があります。 

通常のシンプレックスは、回転と平行移動までは固定です。 これは、有効な正準単体を再構築し、剛体変換を使用して指定された点と位置合わせすると、残りの頂点が一意に決定されることを意味します。

 | --- | --- | --- | --- |

 | シンプレックス認識 + 厳密な位置合わせ | テストごとに O(N3) | O(N²) | 承認済み |

 ## アルゴリズムのチュートリアル

 私たちは、すべての有効な構成が K = N + 1 頂点を持つ標準的な正単体に合同であるという事実に依存しています。

1. まず、K = N + 1 を計算します。最終構成には正確に K 個の点が含まれている必要があるため、追加する点の数は K − M です。 
2. N 次元で正準単体を構築します。 これは、すべてのペアごとの距離が 1 である K 点 u1、u2、...、u_K の固定セットです。これは参照形状として機能します。 
3. 与えられた点も通常の単体サブセットであるため、M 個の与えられた点を最初の M 個の正準頂点に任意に関連付けます。 
4. 正準点 u1 ... u_M を指定された点 x1 ... x_M にマッピングする剛体変換 (回転と平行移動) を計算します。 平行移動は重心を揃えることによって決定され、回転は中心点セットから抽出された正規直交基底を使用して決定されます。 
5. すべての正準頂点 u₁ ... u_K に同じ変換を適用します。 これにより、元の座標系で完全な単体の座標が生成されます。 
6. 新たに追加した点であるインデックス M + 1 ～ K に対応する頂点のみを出力します。 

中心的な計算ステップは、単体によって広がる部分空間の正規直交基底を構築することです。 正規基底とターゲット基底の両方が構築されると、基底ベクトルを照合することによって回転行列が取得されます。 

### なぜ効果があるのか

 すべてのペアごとの距離が等しい N + 1 点のセットは、剛体幾何学オブジェクトを形成します。 このようなシンプレックスの 2 つの実現は、ユークリッド等長性によってのみ異なります。 正準シンプレックスと入力点の両方が同じ距離制約を満たすため、一方を他方にマッピングする固有の剛体変換が存在します。 M ≥ 1 の頂点からこの変換を決定することにより (実際には、単体部分空間の向きを固定するには M ≥ 2 で十分です)、残りのすべての頂点が一貫して配置され、すべてのペアごとの距離が維持されることが保証されます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def norm(a):
    return math.sqrt(dot(a, a))

def sub(a, b):
    return [x - y for x, y in zip(a, b)]

def add(a, b):
    return [x + y for x, y in zip(a, b)]

def mul(a, t):
    return [x * t for x in a]

def gram_schmidt(vectors):
    basis = []
    for v in vectors:
        w = v[:]
        for b in basis:
            proj = dot(w, b)
            w = sub(w, mul(b, proj))
        n = norm(w)
        if n > 1e-12:
            basis.append(mul(w, 1.0 / n))
    return basis

def build_simplex(n):
    k = n + 1
    # start in R^k, project to sum=0 hyperplane, then take first n coords basis implicitly
    v = []
    for i in range(k):
        vec = [0.0] * k
        vec[i] = 1.0
        avg = 1.0 / k
        vec = [x - avg for x in vec]
        v.append(vec[:n])
    return v

def solve_case(n, m, pts):
    k = n + 1
    if m == k:
        return []

    u = build_simplex(n)

    base_x = pts[0]
    X = [sub(p, base_x) for p in pts]

    U = [sub(u[i], u[0]) for i in range(m)]

    Bx = gram_schmidt(X[1:])
    Bu = gram_schmidt(U[1:])

    if len(Bx) < len(Bu):
        Bu = Bu[:len(Bx)]

    rot = Bu

    def apply(v):
        res = [0.0] * n
        for i in range(len(rot)):
            coeff = dot(v, Bu[i])
            for j in range(n):
                res[j] += coeff * Bx[i][j]
        return res

    ans = []
    for i in range(m, k):
        v = sub(u[i], u[0])
        v2 = apply(v)
        ans.append(add(v2, base_x))

    return ans

def main():
    t = int(input())
    for tc in range(1, t + 1):
        n, m = map(int, input().split())
        pts = [list(map(float, input().split())) for _ in range(m)]

        res = solve_case(n, m, pts)

        print(f"Case #{tc}: {len(res)}")
        for r in res:
            print(" ".join(f"{x:.10f}" for x in r))

if __name__ == "__main__":
    main()
```解決策は、最終的な構造には正確に N + 1 個の点が含まれている必要があることを認識することから始まります。 機能`build_simplex`標準基底ベクトルを中心超平面に投影し、等しいペアごとの距離を生成することにより、N 次元の正準単体を構築します。 

次に、最初の点が原点になるようにすべてを変換することで、この正準単体を入力と位置合わせします。 グラム・シュミット プロセスは、正準点と入力点の差の両方から正規直交方向を抽出し、単体部分空間に互換性のある基底を与えます。 

残りの頂点は正準座標系で表現され、計算された基底対応関係を使用して入力座標系に変換され、最後に逆変換されます。 

微妙な点は、数値直交位置合わせが浮動小数点誤差の影響を受けやすいことです。 グラム・シュミットステップは安定している必要があり、ノルムが非常に小さいベクトルは破棄する必要があります。

 ## 特殊なケース

 エッジ ケースの 1 つは、M が N + 1 に等しい場合です。この状況では、点はすでに完全な正単体を形成しており、正しい出力には追加の点が含まれていない必要があります。 シンプレックスをやみくもに「完成」させるような構築の試みは、重複した頂点や矛盾した頂点を生成することになります。 

もう 1 つの微妙なケースは、M = 1 の場合です。単一点の場合、シンプレックスの向きはまったく制約されないため、アルゴリズムは点間の違いから導出される根拠に依存することを避ける必要があります。 正準シンプレックスは依然として存在しますが、アライメントは縮退し、あらゆる直交変換は有効です。 実装では、一貫性はあるものの任意の方向を事実上デフォルト設定することでこれを処理します。
