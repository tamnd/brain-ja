 ## 解決策
 ## 問題の理解

 同じ数の犬とケージを備えたシステムが与えられ、どちらも 0 から N − 1 までのラベルが付けられます。各犬は独立して一様にランダムにケージを選択し、各ケージには最大 1 匹の犬を収容できます。つまり、最終的な構成はケージ全体で犬がランダムに並べられたものになります。 

結果の完全な分布については尋ねられず、最終的に自分たちと同じ指数のケージに入れられない犬の予想数だけが尋ねられます。 言い換えれば、それぞれの犬 i について、その犬が檻 i に入れられることを避けているかどうかを考慮し、そのような犬の予想される数が必要です。 

入力は複数のテスト ケースで構成され、それぞれのテスト ケースで値 N が与えられ、それぞれに対して「不一致」の犬の予想数が出力されます。 

この制約により、テスト ケースは 10^5 まで、N は 10^5 まで許可されるため、テスト ケースごとのシミュレーションや階乗ベースの推論は不可能になります。 ソリューションでは、最小限の前処理または式の直接評価を行った後、各クエリ時間を O(1) に短縮する必要があります。 

微妙なエッジ ケースは N = 1 です。単一の犬とケージの場合、犬は常に正しいケージ内にあるため、答えは正確に 0 でなければなりません。複数の要素にわたる対称性を誤って仮定し、この基本ケースを忘れた導出は、より大きな N に対して正しいように見える式を生成する可能性がありますが、ここでは失敗します。 

もう 1 つの概念的な落とし穴は、プロセスを犬ごとに独立した選択として扱うことです。 これは、各犬が間違っている確率は 1 − 1/N であることを示唆しますが、ケージの一意性は強制されません。 幸いなことに、グローバル割り当てが独立した描画ではなく順列である場合でも、期待値の線形性により、この単純化は有効なままになります。 

## アプローチ

 ブルートフォースの視点は、犬をケージに割り当てる可能性のあるすべての有効な割り当てを想像することから始まります。 各割り当てはサイズ N の順列であり、各順列について、permutation[i] ≠ i を満たすインデックス i の数を数えます。 次に、この値をすべての N! で平均します。 順列。 

これは正しいですが、まったく実行不可能です。 Nを列挙する！ 10 なので、N = 10 の場合でも構成は不可能です。 はすでに 360 万であり、N = 20 の場合、それは天文学的に大きくなります。 

重要な観察は、実際には順列の結合構造が必要ないということです。 必要なのは、個々のインデックスの予想される寄与のみです。 犬 i がケージ i にいない場合は 1、そうでない場合は 0 となる標識変数 Xi を定義します。 答えはすべての Xi の合計の期待値です。 

期待値の直線性により、ポジション間の依存関係を考慮することなく、個々の指標の期待値を合計することができます。 固定された犬 i の場合、対称性は、一様にランダムな順列において、犬 i がどの檻にも等しく出現する可能性があることを意味するため、犬 i が自分の檻に着地する確率は正確に 1/N です。 したがって、不一致となる確率は 1 − 1/N = (N − 1)/N となります。 

N 匹の犬すべてを合計すると、N · (N − 1)/N = N − 1 となります。これにより、問題全体が定数時間の公式に分解されます。

 ## アルゴリズムのチュートリアル

 ## アルゴリズムのチュートリアル

 1. 現在のテスト ケースの N を読み取ります。 
2. N = 1 の特殊なケースを処理し、唯一のドッグが正しい必要があるため、すぐに 0 を出力します。 
3. N ≥ 2 の場合、導出された式 N − 1 を使用して、予想される不一致の数を計算します。 
4. 結果を十分な精度で浮動小数点形式で出力します。 

計算の背後にある推論ステップは、順列がそれらをグローバルに結合しているにもかかわらず、各位置が期待値に独立して寄与しているということです。 インジケーターの分解により、実際の独立性に依存しないことが保証されます。 

### なぜ効果があるのか

犬 i が檻 i に入っていないかどうかを示す指標を Xi とします。 ランダムな並べ替えでは、各犬が正しい位置に固定される確率は 1/N であるため、E[Xi] = (N − 1)/N となります。 期待値の合計は E[ΣXi] = ΣE[Xi] = N · (N − 1)/N です。 これにより、順列を列挙したりシミュレーションしたりすることなく、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for i in range(1, t + 1):
        n = int(input())
        if n == 1:
            out.append(f"Case #{i}: 0.0000000000")
        else:
            ans = n - 1
            out.append(f"Case #{i}: {ans:.10f}")
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装では、派生した閉じた形式の式が直接適用されます。 唯一の分岐は N = 1 であり、書式設定要件の下で正確さを維持し、些細なケースでの不必要な浮動小数点演算を回避します。 小数点以下 10 桁の書式設定は、期待値の問題に対する典型的な Codeforces 出力許容誤差と一致します。

| ステップ | N | 犬ごとの不一致確率 | 予想合計 |

 ## 特殊なケース

 N = 1 の場合、アルゴリズムは明示的に 0 を返します。式 N − 1 も 0 を返しますが、分岐により書式設定ロジックのあいまいさが回避されます。 

たとえば、N = 1 と入力します。 

| ステップ | 値 |
 | --- | --- |
 | Nを読む | 1 |

 これにより、可能な最小の構成が期待引数と一貫して動作することが確認されます。 

N = 2 や N = 3 などの大きな N の場合、計算は置換構造に依存せずに直接 N − 1 に減少します。 期待によって犬間のすべての相互作用がすでに抽象化されているため、アルゴリズムは割り当てをシミュレートする必要はありません。
