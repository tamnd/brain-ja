 ## 解決策
 ## 問題の理解

 配列`a`は明示的に与えられていません。 これは短い配列の無限に見える繰り返しです`b`、以降は切り捨てられます`n`要素。 もし`b = [b0, b1, ..., b(m-1)]`、次に、のすべてのブロック`m`の連続要素`a`の別のコピーです`b`。 

空ではない連続セグメントが必要です。`a`正確にその合計は`k`。 このようなすべてのセグメントの中で、最も短いセグメントが必要です。また、複数のセグメントが同じ長さの場合は、左の端点が最小のセグメントが必要です。 

アーカイブされたステートメントには小さな矛盾があります。答えは次のとおりです。`1 <= l <= r <= n`、一方、配列は 0 からインデックス付けされていると宣言されており、公式サンプルでは次のように出力されます。`0 3`。 意図した出力は 0 から始まる包括的なエンドポイントであるため、以下の実装はサンプルに従って出力します。`l`そして`r`と`0 <= l <= r < n`。 

重要な制約は、`n <= 10^9`、一方、`m <= 10^5`通常の配列処理制限によって制限されます。 建設中`a`明示的に 10 億の要素が必要になる可能性がありますが、これはすでにメモリ制限に対して大きすぎます。 最悪の場合、O(n) スキャンでもコストがかかりすぎます。 の合計`m`すべてのテストケース全体で最大でも`3 * 10^5`したがって、テスト ケースごとに O(m log m) アルゴリズムが実用的です。 

の値`b`は負の値になる可能性があるため、スライディング ウィンドウなどのテクニックは適用されません。 要素の符号に関係なく、セグメント合計は 2 つの接頭辞合計の差として表現できるため、接頭辞合計は自然な表現です。 プレフィックスの合計もおおよそに達する可能性があります`10^14`、 そして`k`到達できる`10^18`, そのため、32 ビット演算では不十分です。 Python 整数はこれらの値を直接処理します。 

最初のエッジ ケースは空のセグメントです。 例えば、```
1
1 3 0
5
```には合計がゼロの空でないセグメントがないため、答えは次のようになります。`-1`。 同じプレフィックス位置を 2 回使用できるプレフィックスサムの実装では、誤って長さ 0 のセグメントが報告される可能性があります。 

2 番目の特殊なケースは、膨大な回数の繰り返しにわたる答えです。 のために```
1
1 1000000000 1000000000
1
```考えられる唯一の答えは配列全体です。`0 999999999`。 1 つまたは数個のコピーのみを検査するソリューション`b`見つかりません。 

3 番目のエッジ ケースは、次の完全なコピーが 1 つある場合に発生します。`b`和はゼロです。 のために```
1
2 2 0
1 -1
```答えは`0 1`。 1 つのコピー内の適切なサブ配列に限定された検索では、この全期間セグメントが失われます。 

4 番目のエッジ ケースは、合計が負になります。 サンプル自体には次の内容が含まれています`b = [1, 1, -3]`、その合計は`-1`、そして答えは`0 3`。 完全な期間の数が通常の正の除算で得られると仮定した導出では、期間の合計が負の場合、間違った方向を選択する可能性があります。 

## アプローチ

 直接的なアプローチでは、完全な配列が構築されます。`a`、そのプレフィックスの合計を計算し、その差が次の 2 つのプレフィックス位置を探します。`k`。 ハッシュ マップを使用すると、O(n) 時間と O(n) メモリが必要になりますが、これはすでに不可能です。`n`は`10^9`。 エンドポイントのすべてのペアを列挙することはさらに悪いことです。 がある`n(n+1)/2`空ではないセグメント、つまり`5 * 10^17`セグメントの場合`n = 10^9`。 

この強引なアイデアは、問題の本当の構造を明らかにするため、今でも役に立ちます。 すべてのセグメントは 2 つのプレフィックス位置によって決定されます。これらを直接検査できない唯一の理由は、繰り返されるコピーが多すぎることです。`b`。 

させて`S`～の完全なコピー 1 つの合計である`b`。 1 つのコピー内のプレフィックス合計を次のように定義します。`p[0] = 0`そして、のために`1 <= i < m`、`p[i] = b[0] + b[1] + ... + b[i-1]`。 

インデックス付きのプレフィックス位置`q * m + r`、 どこ`0 <= r < m`、価値があります`P(q * m + r) = q * S + p[r]`。 

これがキー圧縮です。 それでも`q`最大 10 億の場合、すべてのプレフィックス合計の非周期部分は 1 つだけです`m`価値観。 

右プレフィックス位置の候補を検討する`y = q*m+r`。 一致する左プレフィックス位置が次であると仮定します。`x = (q-h)*m+s`。 

それから`P[y] - P[x] = h*S + p[r] - p[s]`。 

のために`S != 0`、必要な数の完全な期間が強制されます。`h = (k + p[s] - p[r]) / S`。 

プレフィックス位置間の距離は次のとおりです。`y-x = h*m + r-s`。 

固定右剰余の場合`r`、この式を最小化するということは、可能な限り最小のものを見つけることを意味します`h`、そして可能な限り最大の`s`。 

可分性条件により、別の有用な観察が得られます。 必要です`p[s] ≡ p[r] - k (mod |S|)`。 

したがって、各剰余モジュロに対して`|S|`、その残基に属するすべての接頭辞の合計をソートされた順序で保持できます。 もし`S > 0`、増加しています`p[s]`増加する`h`したがって、最小のものが必要です`p[s]`に対応するしきい値を超える`h >= 1`。 もし`S < 0`、方向が逆になるため、最大のものが必要です`p[s]`対応するしきい値を下回っています。 

ケース`h = 0`は特別です。 この場合、両方のプレフィックス位置が同じコピー内にあるため、次のようにする必要があります。`s < r`。 残基を左から右にスキャンしながら、必要なプレフィックス値の直前の出現を見つけることができます。 

もし`S = 0`、完全なコピーはプレフィックスの合計には何も寄与しません。 目的の条件は単純になります`p[s] = p[r] - k`。 

同じコピー内で再度必要になります`s < r`。 そのような位置が存在しない場合は、前のコピーから同じプレフィックス値を使用できます。 それは長さのセグメントを与えます`m+r-s`ただし、その右端がまだ実際の配列内にある場合に限ります。 

すべての有効なセグメントがプレフィックスの合計のペアに対応するため、ブルート フォースが機能します。 プレフィックスの位置が多すぎるため、失敗します。 すべての接頭辞の位置が次の形式であるという観察`q*S + p[r]`巨大なものを排除しましょう`q`寸法を決定し、残りを解決します`m`ソートと二分探索による残余ケース。

 ## アルゴリズムのチュートリアル

 1. 合計を計算する`S`1 部の`b`およびプレフィックス値`p[0], ..., p[m-1]`。 これらは、巨大な配列のすべてのプレフィックス位置を表すのに十分です。 
2. もし`S = 0`、問題を個別に処理してください。 残基ごとに`r`、必要な以前のプレフィックス値は次のとおりです。`p[r] - k`。 以前に発生した最新の出来事を検索する`r`最初のコピー内のセグメントを取得します。 それが存在しない場合は、最新のものを任意の場所で使用し、前のコピーに配置します。 後者の候補はプレフィックス位置で終了します`m+r`, という場合にのみ使用可能です。`m+r <= n`。 
3. もし`S != 0`、ペアごとにグループ化します`(p[s] mod |S|, p[s], s)`その剰余モジュロによって`|S|`、完全なコレクションを残基ごとに並べ替え、次にプレフィックス値ごとに並べ替えます。 これにより、可能な限り最良のものを見つけることができます`p[s]`二分探索を使用してすべての正しい残基に対して。 
4. 可能なすべての正しい残余を処理する`r`から`0`を通して`m-1`。 まず探すのは`p[s] = p[r] - k`ポジション間で`s < r`。 これは、`h = 0`場合。 その長さは`r-s`、有効な最大値`s`常にこれの最有力候補です`r`。 
5. のために`h >= 1`、を満たすプレフィックス値のみ`p[s] ≡ p[r] - k (mod |S|)`働くことができます。 もし`S > 0`、を満たす最初のプレフィックス値を見つけます。`p[s] >= p[r] - k + S`。 

もし`S < 0`、満足する最後のプレフィックス値を見つけます。`p[s] <= p[r] - k + S`。 

これらの不平等はまさに条件です`h >= 1`、可能な限り最も近いプレフィックス値を選択すると、最小値が得られます。`h`。 
6. 1回`p[s]`選択されている場合、計算します`h = (k + p[s] - p[r]) / S`。 

この構造候補の最も早い出現は、次の選択によって取得されます。`q = h`。 次に、左側の接頭辞の位置は単純に次のようになります。`s`、正しい接頭辞の位置は次のとおりです。`h*m+r`。 候補は次の場合にのみ使用できます。`h*m+r <= n`。 
7. プレフィックスの位置を配列のエンドポイントに変換します。 プレフィックスペア`(x,y)`包含的な配列セグメントを表します`[x, y-1]`。 まず候補を長さで比較します`y-x`、次に左側のエンドポイントによって`x`。 
8. 候補が見つからなかった場合は、印刷します。`-1`。 それ以外の場合は、最適な 0 ベースの包括的なエンドポイントを出力します。 

### なぜ効果があるのか

 空ではないすべてのサブ配列は 2 つのプレフィックス位置に一意に対応します`x < y`、合計付き`P[y]-P[x] = k`。 のために`S != 0`、2つの位置を次のように書きます`(q-h)m+s`そして`qm+r`正確な方程式を与えます`h*S+p[r]-p[s]=k`。 したがって、すべての有効なセグメントがアルゴリズムによって考慮された候補の中に表示されます。 

のために`h=0`、条件`s<r`これは、両方のプレフィックス位置が同じコピー内にあるという条件とまったく同じです。 のために`h>=1`、左のプレフィックスは自動的に右のプレフィックスの前に配置され、合同プラスしきい値の検索では、次の可能な値が正確に考慮されます。`s`ポジティブな結果をもたらす`h`。 固定の場合`r`、長さは`h*m+r-s`、つまり最小の`h`そして次に最大の`s`最も短い候補を与えます。 選択する`q=h`可能な限り小さい左端点で同じ長さを生成します。 の`S=0`ブランチは、同じコピーと前のコピーという 2 つの可能な構造ケースのみを考慮します。 したがって、考えられるすべての最適なセグメントが考慮され、最終的な比較で必要な答えが正確に選択されます。 

## Python ソリューション```python
import sys
from bisect import bisect_left, bisect_right

input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        m, n, k = map(int, input().split())
        b = list(map(int, input().split()))

        p = [0] * m
        cur = 0
        for i in range(m - 1):
            cur += b[i]
            p[i + 1] = cur

        S = sum(b)

        best_len = None
        best_l = None
        best_r = None

        def update(x, y):
            nonlocal best_len, best_l, best_r

            length = y - x
            l = x
            r = y - 1

            if best_len is None or (length, l) < (best_len, best_l):
                best_len = length
                best_l = l
                best_r = r

        if S == 0:
            last_all = {}
            for i, value in enumerate(p):
                last_all[value] = i

            last_before = {}

            for r in range(m):
                target = p[r] - k

                # h = 0, so the left prefix must be before r.
                s = last_before.get(target)
                if s is not None:
                    update(s, r)

                # Use the same prefix value in the previous copy.
                s = last_all.get(target)
                if s is not None:
                    y = m + r
                    if y <= n:
                        update(s, y)

                last_before[p[r]] = r

        else:
            D = abs(S)

            # Each item is (p[s] mod D, p[s], s).
            data = [(p[i] % D, p[i], i) for i in range(m)]
            data.sort()

            # For every residue, store the half-open interval in data.
            bounds = {}
            start = 0
            while start < m:
                key = data[start][0]
                end = start + 1
                while end < m and data[end][0] == key:
                    end += 1
                bounds[key] = (start, end)
                start = end

            last_before = {}

            for r in range(m):
                pr = p[r]
                target = pr - k

                # h = 0.
                s = last_before.get(target)
                if s is not None:
                    update(s, r)

                key = target % D
                interval = bounds.get(key)

                if interval is not None:
                    lo, hi = interval

                    if S > 0:
                        # h >= 1 means:
                        # k + p[s] - p[r] >= S
                        threshold = pr - k + S

                        idx = bisect_left(
                            data,
                            (key, threshold, -1),
                            lo,
                            hi
                        )

                        if idx < hi:
                            pval = data[idx][1]

                            # For the same pval, take the largest s,
                            # because that minimizes h*m + r - s.
                            j = bisect_right(
                                data,
                                (key, pval, m),
                                lo,
                                hi
                            ) - 1

                            s = data[j][2]
                            h = (k + pval - pr) // S
                            y = h * m + r

                            if h >= 1 and y <= n:
                                update(s, y)

                    else:
                        # h >= 1 means:
                        # k + p[s] - p[r] <= S
                        threshold = pr - k + S

                        idx = bisect_right(
                            data,
                            (key, threshold, m),
                            lo,
                            hi
                        ) - 1

                        if idx >= lo:
                            pval = data[idx][1]
                            s = data[idx][2]
                            h = (k + pval - pr) // S
                            y = h * m + r

                            if h >= 1 and y <= n:
                                update(s, y)

                last_before[pr] = r

        if best_len is None:
            out.append("-1")
        else:
            out.append(f"{best_l} {best_r}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```プレフィックス構築ストアのみ`m`価値観。`p[i]`位置の前の合計です`i`最初のコピー内にあるため、後のすべてのコピーのプレフィックス位置は、実体化する代わりに代数的に再構築できます。 

の`S == 0`ブランチは 2 つの辞書を使用します。`last_before`には、現在の残基より厳密に前の位置のみが含まれているため、誤って空のセグメントが構築されることが防止されます。`last_all`一致するプレフィックスが以前のコピーから取得されなければならない場合に、最新のオカレンスを提供します。 

のために`S != 0`、`data`で並べ替えられています`p[s] mod |S|`初め。 同じ剰余クラスのプレフィックス値は、まさに必要な方程式に参加できる値です。 二分探索は、次の符号によって課される方向を実装します。`S`。 タプルには次のものも含まれます`s`したがって、等しいプレフィックス値をインデックス順に並べることができ、最新のインデックスを直接選択できます。 

の計算`h`剰余条件は、次のように割り切れることが保証された後にのみ実行されます。`S`。 Python の任意精度の整数は、次のような大規模な積を安全に処理します。`n`、`m`、およびプレフィックスの合計。 

コードは内部でプレフィックス位置を使用するため、候補`(x,y)`包含的な配列間隔になります`[x,y-1]`。 これがサンプルの理由でもあります。`0 3`最初のテストケース用に生成されます。

    for _ in range(t):
        m, n, k = map(int, input().split())
        b = list(map(int, input().split()))

        p = [0] * m
        cur = 0
        for i in range(m - 1):
            cur += b[i]
            p[i + 1] = cur

        S = sum(b)

        best = None

        def update(x, y):
            nonlocal best
            cand = (y - x, x, y - 1)
            if best is None or cand[:2] < best[:2]:
                best = cand

        if S == 0:
            last_all = {}
            for i, value in enumerate(p):
                last_all[value] = i

            last_before = {}

            for r in range(m):
                target = p[r] - k

                s = last_before.get(target)
                if s is not None:
                    update(s, r)

                s = last_all.get(target)
                if s is not None:
                    y = m + r
                    if y <= n:
                        update(s, y)

                last_before[p[r]] = r

        else:
            D = abs(S)
            data = [(p[i] % D, p[i], i) for i in range(m)]
            data.sort()

            bounds = {}
            start = 0
            while start < m:
                key = data[start][0]
                end = start + 1
                while end < m and data[end][0] == key:
                    end += 1
                bounds[key] = (start, end)
                start = end

            last_before = {}

            for r in range(m):
                pr = p[r]
                target = pr - k

                s = last_before.get(target)
                if s is not None:
                    update(s, r)

                key = target % D
                interval = bounds.get(key)

                if interval is not None:
                    lo, hi = interval

                    if S > 0:
                        threshold = pr - k + S
                        idx = bisect_left(
                            data, (key, threshold, -1), lo, hi
                        )

                        if idx < hi:
                            pval = data[idx][1]
                            j = bisect_right(
                                data, (key, pval, m), lo, hi
                            ) - 1
                            s = data[j][2]
                            h = (k + pval - pr) // S
                            y = h * m + r

                            if y <= n:
                                update(s, y)

                    else:
                        threshold = pr - k + S
                        idx = bisect_right(
                            data, (key, threshold, m), lo, hi
                        ) - 1

                        if idx >= lo:
                            pval = data[idx][1]
                            s = data[idx][2]
                            h = (k + pval - pr) // S
                            y = h * m + r

                            if y <= n:
                                update(s, y)

                last_before[pr] = r

        out.append("-1" if best is None else f"{best[1]} {best[2]}")

    sys.stdin = old_stdin
    return "\n".join(out)

 ## 特殊なケース

 空のセグメントの問題は、次のようにすることで処理されます。`last_before`現在のプレフィックス位置とは別のものです。 のために```
1
1 3 0
5
```唯一のプレフィックス値は`0`ただし、最初で唯一の残基を処理する場合には、それより前のプレフィックス位置はありません。 以来`S=5`、和ゼロに対する正周期の解もありません。 アルゴリズムは出力します`-1`プレフィックスとそれ自体を長さゼロのセグメントと混同するのではなく。 

膨大な繰り返しのケースを構築せずに処理します`a`。 のために```
1
1 1000000000 1000000000
1
```我々は持っています`S=1`そして`p[0]=0`。 方程式は次のようになります。`h=1000000000`。 正しい接頭辞の位置は次のとおりです。`h*m+r = 1000000000`、まさにその通りです`n`、左側のプレフィックス位置はゼロです。 したがって、答えは次のとおりです`0 999999999`。 の値`h`巨大になる可能性がありますが、それは単なる整数の計算にすぎません。 

ゼロピリオドのケースでは、除算が行われるため、別の分岐が使用されます。`S`無意味でしょう。 のために```
1
2 2 0
1 -1
```我々は持っています`S=0`そして`p=[0,1]`。 で`r=0`、ターゲットのプレフィックス値はゼロであり、同じ値が次の場所でも発生します。`s=0`。 それ以前は無い`s`したがって、アルゴリズムはその出現箇所を前のコピーに配置します。 正しいプレフィックス位置は次のようになります。`m+r=2`、配列セグメントを与える`[0,1]`。 その合計は`1 + (-1) = 0`、結果は次のようになります`0 1`。 

負の期間合計は、二分探索の方向を変更します。 サンプルの最初のテストでは、`S=-1`そして`p=[0,1,2]`。 で`r=1`、必要な陽性期間の候補者は`s=0`、与える`h = (0 + 0 - 1) / (-1) = 1`。 

正しい接頭辞の位置は次のとおりです。`1*3+1=4`したがって、セグメントは次のようになります。`[0,3]`。 その値は次のとおりです。`1,1,-3,1`、その合計はゼロです。 アルゴリズムは、正の場合に有効な方向を使用するのではなく、負の合計しきい値を下回る最大のプレフィックス値を検索することによって、この候補を見つけます。`S`。 

インデックス作成の問題は、プレフィックス エンドポイントを正しく変換することで処理されます。 プレフィックスペアが`(x,y)`、選択された配列要素は正確にインデックスです`x`を通して`y-1`。 したがって、コードは出力されます`x`そして`y-1`これは、ステートメント内に表示される数値範囲が矛盾している場合でも、公式サンプルの 0 から始まる出力規則と一致します。
