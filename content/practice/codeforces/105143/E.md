## アプローチ

構造の単純化は 2 つのアイデアを分離することで実現します。 まず、感染者セットの時間$t$常に距離内のノードで構成される接続されたサブツリーです$t$から$r$。 第 2 に、どのツリーでも、固定セットの最適な中心はその直径によって完全に決まります。最小半径は直径の半分 (切り上げ) に等しくなります。 したがって、あらゆる可能性について推論するのではなく、$r_0$必要なのはボールの直径だけです$B(r,t)$。 

次の観察は、次のノードが存在することです。$B(r,t)$まさに最大の深さのものです$t$根を張った木の中で$r$。 直径は常に境界層の 2 つのノード間、つまり正確な深さのノード間で得られます。$t$。 したがって、問題の幾何学は、各深度でノードがどのように配置されるかを理解することに帰着します。$t$最下位の共通祖先を通じてつながります。 

固定の場合$t$、深さのあるすべてのノードを正確に考慮します$t$。 これらのノードのペアの LCA として表示される最も浅いノードが直径構造を決定します。 このノードを呼び出すと$x_t$、次に直径$B(r,t)$は$2(t - \text{depth}(x_t))$、可能な最小半径は次のとおりです。$t - \text{depth}(x_t)$。

 ## アルゴリズムのチュートリアル

 私たちは木を次の場所に根付けます$r$そして距離を計算します$dist[v]$から$r$すべてのノードに。 これによりレベルが定義され、各レベルは$t$は、まさにその時点でフェイクニュースが到達したノードのセットです$t$。 

レベルごとに$t$、からの距離が次のノードの仮想ツリーを構築します。$r$等しい$t$。 これは、これらのノードを DFS 順序でソートし、連続するノード間に LCA を挿入することによって行われます。 重要な特性は、仮想ツリーが元のツリー内でこれらのノードがどのように接続されているかを正確にキャプチャすることです。 

この仮想ツリー内で、深さが最小のノードを見つけます。 このノードはまさに$x_t$、境界ノードのペアを接続する最も浅い LCA。 感染者を特定したら、感染セットの有効半径を次のように計算します。$t - depth[x_t]$。 

これから、与えられた条件に対する条件を導き出します。$k$。 反駁は感染セットをカバーすることができます$t$もし、そしてその場合に限り$$t - depth[x_t] \le k(t - t_0).$$並べ替えるとしきい値が与えられます$k$:$$k \ge \frac{t - depth[x_t]}{t - t_0}.$$上限を取得して、これを整数の要件に変換します。 

今では毎回$t$間隔制約に影響を与える: すべて$k$このしきい値以上であれば、時間を達成できます$t$。 

時間を昇順に処理し、配列を維持します`ans[k]`無限大に初期化されます。 それぞれについて$t$、すべてのサフィックスの更新を実行します。$k \ge k_{\min}(t)$、設定`ans[k] = min(ans[k], t)`。 これは、遅延伝播または同様の構造で範囲 chmin をサポートするセグメント ツリーを使用して実装できます。 

最後に出力します`ans[1..n]`。 

### なぜ効果があるのか

 全体の正しさは 2 つの不変条件に依存します。 まず、固定の場合$t$、最適な反駁センターは、直径によって完全に特徴付けられます。$B(r,t)$、深さのノードの中で最も浅い LCA によって決定されます。$t$。 これにより、任意の中心を考慮する必要がなくなります。 

2番目に、毎回$t$に対して単調制約を独立して生成します。$k$、増えているので$k$カバー要件を緩和するだけです。 したがって、すべての有効な時間がサフィックス間隔に寄与します。$k$-space を使用し、各有効時間の最小値を取得します。$k$可能な限り最も早い時刻が得られます。 異なるもの間の相互作用はありません$t$実現可能性は純粋に存在するものであるため、価値観が失われています。$r_0$固定ごとに$t$。

for _ in range(n - 1):

    u -= 1
    v -= 1

    g[v].append(u)

    order.append(x)

        if y == parent[x]:

        parent[y] = x
        depth[y] = depth[x] + 1
        st.append(y)

timer = 0

parent2[r] = r

stack = [(r, 0)]
parent2[r] = r
vis = [0] * n
order2 = []
while stack:
    x, i = stack.pop()
    if i == 0:
        vis[x] = 1
        tin[x] = len(order2)
        order2.append(x)
    if i < len(g[x]):
        y = g[x][i]
        stack.append((x, i + 1))
        if y != parent2[x]:
            parent2[y] = x
            depth[y] = depth[x] + 1
            stack.append((y, 0))
    else:

# binary lifting LCA
LOG = 20
up = [[-1] * n for _ in range(LOG)]
for i in range(n):
    up[0][i] = parent[i]

for j in range(1, LOG):
    for i in range(n):
        up[j][i] = up[j - 1][up[j - 1][i]]

def lca(a, b):
    if depth[a] < depth[b]:
        a, b = b, a
    diff = depth[a] - depth[b]
    for i in range(LOG):
        if diff >> i & 1:
            a = up[i][a]
    if a == b:
        return a
    for i in range(LOG - 1, -1, -1):
        if up[i][a] != up[i][b]:
            a = up[i][a]
            b = up[i][b]
    return up[0][a]

# group nodes by depth
maxd = max(depth)
levels = [[] for _ in range(maxd + 1)]
for i in range(n):
    levels[depth[i]].append(i)

# compute answer array
ans = [10**18] * (n + 1)

# virtual tree helpers
def build_virtual(nodes):
    nodes = sorted(nodes, key=lambda x: tin[x])
    st = []

    def add(x):
        if not st:
            st.append(x)
            return
        w = lca(x, st[-1])
        while len(st) >= 2 and depth[st[-2]] >= depth[w]:
            st.pop()
        if st[-1] != w:
            st.append(w)
        st.append(x)

    # minimal depth node in virtual tree
