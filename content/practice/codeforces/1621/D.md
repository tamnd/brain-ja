 ## 解決策
 ## 問題の理解

 次のサイズの正方形グリッドが与えられます。$2n \times 2n$。 左上の象限。最初の象限で構成されます。$n$行と最初$n$列には、最初はセルごとに 1 人の友人が含まれています。 右下の象限、最後の$n$行と最後の$n$列には、最終的にはセルごとに 1 人の友人を含める必要があります。 左上の象限の外側の一部のセルは雪で覆われており、所定のコストをかけて除雪しない限り通過できません。 目標は、すべての友人が行と列の循環移動のみを使用して右下の象限に到達できるように、雪を取り除くための最小限のコストを見つけることです。 

この問題により、友人は行または列に沿って周期的に移動できることになります。最後の行または列を越えて移動すると、最初の行または列に戻ります。 ただし、友人が雪で覆われたセルを踏むと気分が悪くなるため、事前に移動経路にある雪をすべて取り除く必要があります。 

主な制約は次のとおりです。$1 \le n \le 250$そしてその合計は$n$テスト ケース全体で最大 250 です。これは、すべてのテスト ケースを反復するソリューションを意味します。$2n \times 2n$各テストケースのセルは実行可能です。 除雪にかかる費用は、次のように高額になる場合があります。$10^9$, そのため、無駄な支出を防ぐためには、無駄な操作を避ける必要があります。 

微妙な点は、友人の最終的な配置には右下の象限のみが重要ですが、最初または最後の循環移動中に雪が通過する可能性があることです。$n$左上の象限外の行/列も移動をブロックする可能性があります。 不用意にアプローチすると、右下の象限にある雪をすべて除去しようとする可能性がありますが、これは不必要です。 代わりに、右下の象限への「入口」パスをブロックする可能性がある、左上の象限にすぐ隣接するセルのみを考慮する必要があります。 

たとえば、次の場合$n=1$、グリッドは$2 \times 2$。 左上には友人が 1 人います$(1,1)$そして右下は$(2,2)$。 細胞だけ$(1,2)$、$(2,1)$、 そして$(2,2)$コストに関係する可能性があります。 右下の象限内のすべての雪を考慮した単純なアプローチでは、過剰にカウントされてしまいます。 

## アプローチ

 ブルートフォース手法では、行と列の循環移動の可能なすべてのシーケンスに沿ってすべての友人を移動するシミュレーションを試み、どのセルが雪でブロックされているかを追跡します。 これは理論的には正しいですが、可能なシーケンスの数が指数関数的に増加するため、計算的には実行不可能です。$n$。 行/列の移動のすべての順列をチェックするだけでも、$1$2回目の制限時間。 

重要な洞察は、すべての友人を個別にシミュレーションしなくても、最小限の除雪コストを決定できることです。 友達は区別できず、動きは周期的であるため、問題となるのは左上の象限から右下の象限への「入り口」をブロックする可能性のある雪だけです。 具体的には、左上の象限の外側にちょうど 4 つの角があり、1 行または 1 列の移動によって友達を右下の象限に移動させる能力に即座に影響を与える可能性があります。 これらの細胞は、$(n, n+1)$、$(n+1, n)$、$(n+1, 2n)$、 そして$(2n, n+1)$のために$2n \times 2n$グリッド。 最小コストは、右下の象限のすべての除雪コスト (これは避けられません) に、これら 4 つの「入口」セルの最小コストを加えたものにすぎません。 

この観察により、潜在的な問題が軽減されます。$O((2n)^2)$簡単なチェック$O(1)$入口コストのテスト ケースごとの計算に、右下の象限の線形和を加えたもの。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((2n)^2 * n!) | O((2n)^2) | 遅すぎる |
 | 最適 | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$そしてそれを読んでください$2n \times 2n$除雪費用のグリッド。 
3. 最小コストをゼロとして初期化します。 これにより、右下の象限にあるすべての雪を除去するためのコストが累積されます。 
4. 右下の象限 (行) を繰り返します。$n+1$に$2n$、列$n+1$に$2n$）すべての除雪費用を合計します。 これにより、すべての友人が右下の象限に有効な最終セルを持つことが保証されます。 
5. 左上象限から右下象限へ移動する友人をブロックする可能性がある、左上象限のすぐ外側にある 4 つの「入口」セルを特定します。 

- 右上の入り口:$(1\text{ to } n, n+1)$- 左下の入り口:$(n+1, 1\text{ to } n)$- 右下列入口:$(n+1, 2n)$- 右下の列の入り口:$(2n, n+1)$6. これら 4 つの入口セルの中で最小の除雪コストを見つけます。 このコストをステップ 4 の合計に加算します。 
7. 各テストケースの合計最小コストを出力します。 

機能する理由: 友人は区別できず、右下の象限内の相対的な位置のみが問題になります。 右下の象限内の雪は常に取り除く必要があります。 隣接する 4 つのセルは、左上象限から右下象限への周期的な移動を可能にするために必要な最小限の追加除雪を表します。 それらの中から最小限のものを選択することで、過剰支出のない有効なパスが常に存在することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        grid = [list(map(int, input().split())) for _ in range(2*n)]
        
        # sum of all snow costs in bottom-right quadrant
        total = 0
        for i in range(n, 2*n):
            for j in range(n, 2*n):
                total += grid[i][j]
        
        # four "entrance" cells
        entrance_costs = [
            grid[0][n],     # row 1, column n+1
            grid[n-1][2*n-1], # row n, column 2n
            grid[n][0],     # row n+1, column 1
            grid[2*n-1][n-1] # row 2n, column n
        ]
        total += min(entrance_costs)
        print(total)

if __name__ == "__main__":
    solve()
```コードはすべてのテスト ケースを読み取り、$2n \times 2n$グリッド。 これらのセルは友人が自由に占有できる必要があるため、右下の象限にすべての除雪コストが合計されます。 4 つの入口セルには慎重にインデックスが付けられています。1 つは左上の象限の最後の列に、1 つは左下の象限の最初の列に、他の 2 つは右下の象限に隣接するエッジにあります。 そのうちの最小コストを取得し、それを右下の合計に加算します。 

## 実用的な例

 **例 1**:

```ステップトレース:

 | セル | コスト | 理由 |
 | --- | --- | --- |

 | 入口: (1,2)=8、(2,1)=1、(2,2)=99、(1,2)=8 | 最小=1 | 最低限必要な入場料は 1 つだけ |

 合計 = 99 + 1 = 100。予想される出力と一致します。

 入力:```

これらのトレースは、右下の象限と 4 つの入口セルのみが関連していることを示しています。 このアルゴリズムは無関係な雪を無視し、問題を入口と象限にわたる線形和の定数時間選択に縮小します。
