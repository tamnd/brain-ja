 ## 問題の理解

 2進数を構築するように求められます`a`別の 2 進数が与えられる`b`同じ長さの`n`導出された数値が`d`最大化されます。 入手までのプロセス`d`は二段です。 まず、計算します`c`の桁ごとの合計として`a`そして`b`持ち運ばずに。 これは、次の各桁を意味します。`c`単純に`a[i] + b[i]`次に、連続して繰り返される数字を削除します。`c`取得するため`d`。 たとえば、次の場合`c = 1220`、繰り返される連続した数字を削除して取得します`d = 120`。 

私たちの目標は選択することです`a`最大化する`d`整数として。 実際には、これは一連の数字が必要であることを意味します。`c`折りたたまれる不必要な繰り返しを作成せずに、可能な最大の値を交互に使用します。`d`。 

制約は次のことを示します`n`到達できる`10^5`テスト ケースは最大 1000 個まで存在できます。`n`すべてのケースで ≤ 10^5。 これにより、考えられるすべての解決策が除外されます。`a`価値観があるので、`2^n`可能性。 テスト ケースごとに線形時間で動作するアルゴリズムが必要です。 エッジ ケースには、非常に短い文字列 (長さ 1)、完全に 0 または 1 で構成される文字列、および連続した文字列が含まれます。`b[i]`値が等しいかどうかに影響する可能性があります。`d`数字を折りたたむ。 

長さのすべての 2 進数を試す単純なアプローチ`n`すぐに失敗します。 たとえば、次の場合`b = 111`そして`n = 3`、ブルートフォースは考慮します`a`で`000`に`111`。 これは指数関数的で非現実的です。 もう一つの微妙なケースは次のような場合です。`b`0 と 1 が交互に表示されます。 選択する`a`繰り返しを考慮しないと、結果が小さくなる可能性があります`d`可能な限り。 

## アプローチ

 ブルートフォースソリューションでは、すべてのバイナリ文字列が生成されます。`a`長さの`n`、計算する`c = a + b`(数字ごとに)、連続する繰り返しを減らして取得します。`d`、最後に比較します`d`値を整数として扱います。 複雑さは O(2^n × n) であり、10^5 はおろか、n = 20 であっても明らかに実行不可能です。 これは理論的には正しいですが、実際には役に立ちません。 

重要な観察は次のとおりです`d`の桁が最大になるとき`c`可能な限り、値を交互に切り替えてください。 以来`c[i] = a[i] + b[i]`そして`b[i]`固定されており、`a[i]`0 または 1 のいずれかになります。決定するだけで済みます。`a[i]`連続する等しい数字を避けるため`c`。 具体的には、前の桁が`c`と同じです`b[i] + 1`、選ぶことはできません`a[i] = 1`なぜなら`c[i]`繰り返すだろう。 そうでなければ、貪欲に選んでしまう`a[i] = 1`作る`c[i]`できるだけ大きく。 それが繰り返される場合、私たちは選択します`a[i] = 0`。 

この観察により、次のような単純な貪欲アルゴリズムが可能になります。`a`一回の通過で`b`。 貪欲な選択は常に安全です。`c`連続した繰り返しを折りたたむため、即時の繰り返しを避けながら各桁を個別に最大化することで、最大値が保証されます。`d`。

 | 貪欲に最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.初期化`prev`-1 に設定すると、前の桁が保存されます。`c`構築されたシーケンス内で。 構築を開始する`a`空の文字列として。 
2. インデックスごとに`i`0 から n-1 まで、考慮してください`b[i]`。 次の場合に合計を計算します。`a[i] = 1`（それで`c_i = b[i] + 1`) と等しいかどうかを確認します`prev`。 そうでない場合は、選択してください`a[i] = 1`、 セット`c_i = b[i] + 1`、更新します`prev`に`c_i`。 
3.設定する場合`a[i] = 1`前のことを繰り返すでしょう`c`数字、選択してください`a[i] = 0`その代わり。 それから`c_i = b[i] + 0 = b[i]`、更新します`prev`に`c_i`。 
4. 選択したものを追加します`a[i]`文字列に`a`。 
5.最後まで繰り返します`b`。 出力`a`。 

機能する理由: 各ステップで、可能な最大の数字を選択します。`c`前のことを繰り返さずに`c`価値。 連続する同桁を折りたたむと繰り返しが減るだけなので、どの選択肢も改善できません。`d`この貪欲な決断を超えて。 これにより、すべてのステップが局所的に最大の寄与を生成するという不変条件が維持されます。`d`崩壊を引き起こすことなく。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    b = input().strip()
    a = []
    prev = -1  # previous digit of c
    
    for ch in b:
        bi = int(ch)
        if bi + 1 != prev:
            a.append('1')
            prev = bi + 1
        else:
            a.append('0')
            prev = bi

    print("".join(a))
```ソリューションは複数のテスト ケースを読み取り、テスト ケースの各文字を反復処理します。`b`。 鍵となるのはメンテナンスです`prev`の最後の桁として`c`。 私たちは選択しようとします`a[i] = 1`最大化する`c[i]`。 それが繰り返される場合、私たちは選択します`a[i] = 0`。 これにより、線形時間実行が保証され、折りたたみルールが尊重されます。
