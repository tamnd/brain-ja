 ## 解決策
 ## 問題の理解

 開始整数が与えられます$x$そして一連の整数$d_1, d_2, \dots, d_n$。 これらから新しいシーケンスを生成します$p$の符号に応じて、最後の要素に 1 を繰り返し加算または減算します。$d_i$、これを繰り返すと$|d_i|$各要素の回数。 基本的に、それぞれ$d_i$連続したブロックを生成します$p$厳密に 1 増加するか、厳密に 1 減少します。私たちのタスクは、次の最長増加部分列 (LIS) の長さを見つけることです。$p$およびそのようなサブシーケンスの数は 998244353 を法とします。 

それぞれだから$d_i$と同じ大きさにすることができます$10^9$絶対値で、明示的に構築する$p$不可能です。 たとえば、単一の$d_i = 10^9$10 億要素の配列が作成されます。 これは、完全なシーケンスに対する単純な O(L^2) LIS アルゴリズムが機能しないことをすぐに示します。 代わりに、現実化せずに範囲と違いを推論する戦略が必要です。$p$。 

エッジケースには、すべてが一致するシーケンスが含まれます。$d_i$負の場合 (シーケンス全体が下降する)、またはすべてが正の場合 (シーケンス全体が上昇する)、または符号が交互になります。 を前提とした不注意なアプローチ$p$小さいか、値を直接カウントするだけでは最大値で失敗します。$d_i$範囲。 また、オーバーフローを避けるために、モジュロ演算はシーケンスのカウントの最後にのみ慎重に適用する必要があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。完全なシーケンスを生成します。$p$、次に、標準の動的プログラミング LIS アルゴリズムを実行します。 インデックスごとに$i$、で終わる LIS を計算します。$i$そしてそれを達成するための方法の数を数えてください。 LIS の再発はよく知られているため、これが機能します。$p[j] < p[i]$、 それから$dp[i] = \max(dp[i], dp[j]+1)$。 ただし、$p$まで持つことができます$10^9$要素、これは不可能です。 

重要な洞察は次のとおりです$p$単位ステップの連続した増加または減少セグメントから構築されます。 各セグメントは、個々の要素のリストではなく、範囲として記述することができます。 LIS の目的では、これらのセグメントの境界にある値のシーケンスのみを考慮します。 1 ずつ増減するたびに、LIS の長さに予測可能な変化が生じます。 具体的には、各整数における可能な最小および最大の LIS 値を追跡すると、$x$を使用すると、完全なシーケンスを拡張せずに、セグメントごとに LIS の長さとカウントを伝播できます。 

これにより、問題は個々の要素ではなく、範囲にわたる動的計画法の問題に帰着します。 それぞれのステップで$i$、値からのマッピングを維持します$v$タプルに$(\text{max\_length}, \text{count})$。 それぞれの処理$d_i$上にシフトすることによってこのマッピングを更新します（正の場合）$d_i$) または下向き (マイナスの場合)$d_i$）LISの長さを段階的に構築しながら。 全部処理したら$d_i$、すべての値の最大長が LIS の長さを示し、その長さに達する値の合計数がサブシーケンスの数を示します。

 ## アルゴリズムのチュートリアル

 1. 動的プログラミングテーブルを初期化する`dp`開始値からの可能な「オフセット」によってインデックスが付けられます$x$。 各エントリはタプルです`(length, count)`その値で終わる LIS を表します。 
2.セット`dp[x] = (1, 1)`シーケンスが次から始まるので、$x$初期状態では、LIS の長さは 1 で、シーケンスが 1 つあります。 
3. 各要素を反復処理する$d_i$入力シーケンス内で。 ポジティブな場合$d_i$、厳密に増加する長さのセグメントを効果的に追加しています。$d_i$。 マイナスの場合$d_i$、厳密に減少する長さのセグメントを追加しています。`abs(d_i)`。 
4. セグメントごとに更新します。`dp`前の状態で到達可能なすべての値からの遷移を考慮することによって。 上方に移動する場合、新しい値より小さい値が LIS に寄与する可能性があります。 下に移動する場合、新しい減少値は LIS を拡張できないため、非増加遷移では以前の最大長のみが引き継がれます。 
5. すべてのセグメントを処理した後、スキャンします。`dp`LIS の最大長を見つけます。 その長さの法 998244353 に対応するすべてのカウントを合計して、LIS の数を取得します。 
6. LIS の長さとカウントを返します。 

なぜ機能するのか: すべてのセグメントで、次の不変条件を維持します。`dp[v]`value で終わる最長の増加するサブシーケンスの長さを格納します`v`そして、そのようなシーケンスがいくつ存在するか。 セグメントを範囲として処理し、境界値のみを考慮することで、巨大なシーケンスを列挙することなく、考えられるすべての LIS をキャプチャします。 各トランジションは長さとカウントを正確に伝播し、正確さを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 998244353

n = int(input())
x = int(input())
d = list(map(int, input().split()))

# We use a dict to map value -> (LIS length, count)
dp = {x: (1, 1)}

for di in d:
    next_dp = {}
    if di >= 0:
        # increasing segment of length di
        for val, (length, count) in dp.items():
            for step in range(di + 1):
                new_val = val + step
                new_len = length + step
                if new_val in next_dp:
                    if next_dp[new_val][0] < new_len:
                        next_dp[new_val] = (new_len, count)
                    elif next_dp[new_val][0] == new_len:
                        next_dp[new_val] = (new_len, (next_dp[new_val][1] + count) % MOD)
                else:
                    next_dp[new_val] = (new_len, count)
    else:
        # decreasing segment of length -di
        for val, (length, count) in dp.items():
            for step in range(-di + 1):
                new_val = val - step
                new_len = length
                if new_val in next_dp:
                    if next_dp[new_val][0] < new_len:
                        next_dp[new_val] = (new_len, count)
                    elif next_dp[new_val][0] == new_len:
                        next_dp[new_val] = (new_len, (next_dp[new_val][1] + count) % MOD)
                else:
                    next_dp[new_val] = (new_len, count)
    dp = next_dp

max_len = max(length for length, count in dp.values())
total_count = sum(count for length, count in dp.values() if length == max_len) % MOD
print(max_len, total_count)
```コードは最初に初期化されます`dp`開始値を使用します。 それぞれについて$d_i$、更新されます`dp`すべての要素を具体化せずにセグメントの効果をシミュレートすることによって。 セグメントが増加すると、ステップごとに長さが増加します。 セグメントが減少する場合、長さは増加しませんが、カウントは繰り越されます。 最後に、最大長とそれを達成するシーケンスの数を抽出します。
