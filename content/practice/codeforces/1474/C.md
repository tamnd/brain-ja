 ## 問題の理解

 の配列が与えられます`2n`正の整数であり、合計が現在の数値に等しいペアを繰り返し選択して、すべての要素を削除することが目標です。`x`。 最初は、任意の正の整数を選択できます。`x`配列内の 2 つの数値の合計に等しい。 ペアを削除した後`(a, b)`合計は誰の`x`、`x`2 つの数値のうち大きい方に更新され、このプロセスが繰り返されます`n`配列が空になるまで繰り返します。 タスクは、そのような一連の操作が存在するかどうかを判断し、存在する場合は最初の操作を提供することです。`x`削除されたペアのシーケンス。 

制約により許可されるのは、`n`まで`1000`および最大の配列値`10^6`、すべての合計で`n`以下のテストケース全体で`1000`。 これにより、合計操作が 1 秒の制限時間内で管理可能なままとなるため、テスト ケースごとに O(n²) のアプローチを検討することが可能になります。 

配列に繰り返し要素が含まれている場合、または最大の要素が他のすべての要素よりもはるかに大きい場合、明らかではないエッジ ケースが発生します。 たとえば、`a = [1, 1, 2, 4]`、ペアリングしたくなる`4`と`2`しかし、その後すべての数字を削除するための有効なシーケンスは存在しません。 単純なアプローチでは、最大の要素が最初にペアになる可能性があると誤って仮定し、間違った答えが生成される可能性があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。可能な限りすべての初期値を試してください。`x`配列内の最大の要素とその他の要素の合計として。 候補者ごとに`x`をシミュレートしようとします。`n`現在の値と合計するペアを常に選択することにより、貪欲に削除操作を実行します。`x`。 いずれかのステップでそのようなペアが存在しない場合、候補は`x`失敗します。 これは正解です。この問題では、固定の初期値に対して 1 つの削除シーケンスしか許可されていません。`x`また、有効なシーケンスでは、合計制約に従ってペアを削除する必要があります。 

ブルート フォースは、最大の要素を反復処理することで実装できます。`max_a`それを他の要素と組み合わせて最初の要素を形成します`x`。 次に、必要なペアの存在を効率的にチェックするためにマルチセット (Python ではカウンター) を維持することで削除をシミュレートします。 ソートされた構造で要素の削除を注意深く管理する場合、このアプローチの時間計算量は O(n² log n) になります。 

私たちのアプローチを最適化するための重要な洞察は、最終的に何らかの操作で最大値として現れる必要があるため、最初の削除には常に最大値が含まれている必要があるということです。 したがって、最大の要素と他の要素のペアによって形成される初期合計のみを考慮する必要があります。 そうなると候補者が減ります`x`に`2n - 1`考えられるペアのすべての合計の代わりに、このアルゴリズムを実用的なものにします。`n`まで`1000`。

 ## アルゴリズムのチュートリアル

 1. 配列を非降順でソートします。 これにより、最大の要素が確実に最後に配置され、ペアリング ロジックが簡素化されます。 
2. 各要素について`a[i]`最後を除いて、考慮してください`x = a[i] + a[-1]`候補の初期合計として。 
3. すべての配列要素を使用してマルチセットまたはカウンターを初期化します。 セット`current_x = x`。 
4. 繰り返します`n`回:

 ａ． 残っている最大の要素を選択します`y`マルチセットで。 

b. コンピューティング`z = current_x - y`。 どうかを確認してください`z`マルチセットに存在します (選択しないように注意してください)`y`2回なら`y == z`その数は 1 です)。 

c. もし`z`存在する場合は両方を削除します`y`そして`z`マルチセットからペアを記録します`(y, z)`。 

d. アップデート`current_x = max(y, z)`。 

e. もし`z`存在しません。中断して次の候補の頭文字を試してください`x`。 
5. すべて削除できたら`2n`要素、YES、初期値を出力`x`、およびペアのシーケンス。 それ以外の場合は、NO を出力します。 

機能する理由: すべての操作で配列が縮小され更新されるため、最大の要素は最初の操作に参加する必要があります。`x`最大削除要素まで。 最大の要素を他の要素とペアにすることで、すべての潜在的な有効な開始点が考慮されるようになります。 マルチセットは、選択された各ペアが実際に存在することを保証し、更新します`x`問題のルールに従って正しさを保ちます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import Counter

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()
        success = False

        for i in range(2 * n - 1):
            x = a[i] + a[-1]
            counter = Counter(a)
            res = []
            current_x = x
            counter[a[-1]] -= 1
            if counter[a[-1]] == 0:
                del counter[a[-1]]
            counter[a[i]] -= 1
            if counter[a[i]] == 0:
                del counter[a[i]]
            res.append((a[i], a[-1]))
            current_x = max(a[i], a[-1])

            for _ in range(n - 1):
                if not counter:
                    break
                y = max(counter)
                z = current_x - y
                if z not in counter:
                    break
                res.append((y, z))
                counter[y] -= 1
                if counter[y] == 0:
                    del counter[y]
                counter[z] -= 1
                if counter[z] == 0:
                    del counter[z]
                current_x = max(y, z)
            if not counter:
                print("YES")
                print(x)
                for p in res:
                    print(p[0], p[1])
                success = True
                break
        if not success:
            print("NO")

if __name__ == "__main__":
    solve()
```コードは配列を並べ替えることから始まり、最大の要素を除くすべての要素を反復して初期合計を形成します。 の`Counter`残りの要素のマルチセットを追跡するために使用されます。 各反復中に、使用可能な最大の要素が、現在の要素と一致するために必要な補数とペアになります。`x`。 ペアが記録され、すべての要素が削除されるか、ペアが見つからなくなるまでプロセスが続行されます。 慎重な取り扱い`Counter`同一の番号が複数存在する場合に正確性を保証します。
