 ## 解決策
 ## 問題の理解

 私たちは、地下通路で接続され、それぞれが一定数のドロイドによって守られているミサイルサイロのネットワークを分析するように求められています。 サイロは高度に構造化されたネットワークを形成します。サイズ _k_ のサイロのサブセットには、すべてのサイロに直接接続された 1 つのサイロが存在します。 これは、グラフが一般化されたシュタイナー システムとして知られる k 均一の組み合わせ構造であることを意味しますが、計算の目的では、各通路が一意であり、ネットワークに正確に _n-1_ 個のエッジが含まれるようにサイロを接続するため、グラフをツリーとして扱うことができます。 

目標は、_k_ 個のサイロの考えられるすべてのセットを選択し、通路に沿って固有の接続サイロに偵察隊を送り、遭遇したドロイドの総数を計算することです。 考えられるすべての _k_-silo セットにわたる平均危険度が必要です。 入力は、_n_、_k_、および隣接行列の上三角部分を提供します (`-1`直接の通過がないことを表します)。 

_n_ が最大 2000 であるとすると、サイズ _k_ の可能なすべてのセットの数は、組み合わせ _C(n, k)_ までになります。 _k = n/2_ の場合でも、この数値はおよそ 10^600 になる可能性があり、総当たりの列挙は除外されます。 合計を効率的に計算するには、グラフの構造と組み合わせ特性を利用する必要があります。 

注意すべきエッジ ケースには次のものが含まれます: 単一サイロ セット (`k=1`）、サイロの完全に直線的なチェーン、およびドロイドの数がゼロまたは負の通路。 単純な実装では誤って処理してしまう可能性があります`-1`ゼロまたはダブルカウントエッジとして。 

## アプローチ

 ブルート フォース ソリューションでは、サイロのすべての _k_ 要素サブセットを反復処理し、一意の隣接するサイロを見つけ、そのサイロまでのエッジに沿ってドロイド数を合計し、サブセットの数で割ります。 概念的には正しいものの、このアプローチは _O(C(n,k)・k)_ という複雑さを伴い、2000 年頃の _n_ ではまったく実現不可能です。 

重要な観察は、グラフがツリーであるため、すべてのエッジが予測可能な数の _k_ 要素セットに参加しているということです。 サイロ _u_ と _v_ を接続するエッジを考えてみましょう。 エッジを削除すると、ツリーは 2 つのコンポーネントに分割されます。 1 つのコンポーネントのサイズを _s_ とし、もう 1 つのコンポーネントには _n-s_ 個のサイロがあるとします。 エッジの片側にスカウトがあり、もう一方の側で接続するサイロを選択する _k_ 個のサイロのセットは、このエッジを通過します。 組み合わせ論を使用すると、このエッジを横切るサブセットの数は、一方の側で 1 から _k_ までのすべてのサイズのサブセットを選択し、もう一方の側で残りを選択し、ドロイド数を掛けた合計として計算できます。 ツリーの対称性により、数えすぎないことが保証されます。 

この洞察により、問題はエッジの反復処理と組み合わせの寄与のカウントに短縮され、事前に計算された二項係数を使用しておよそ _O(n^2)_ 時間で解決策が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(C(n,k)・k) | O(n^2) | 遅すぎる |
 | 最適 | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 隣接行列を解析し、変換します。`-1`に`None`欠けているエッジを表現します。 ドロイド数を含むエッジの明示的なリストを作成します。 
2. すべての二項係数を事前計算する`C(i,j)`まで`n`パスカルの三角形を使用して、高速な組み合わせカウントを可能にします。 
3. サイロ _u_ と _v_ を接続する各エッジに対して、深さ優先検索を実行して、_v_ を除く _u_ をルートとするサブツリーのサイズを計算します。 このサイズを _s_ とします。 他のコンポーネントのサイズは _n - s_ です。 
4. エッジ用`(u,v)`ドロイドと一緒に`c`、危険全体に対するその寄与を計算します。 特定の _k_ について、一方の側にスカウトを含み、もう一方の側に接続するサイロを含むサブセットの数は次のようになります。`C(s, i) * C(n-s-1, k-i-1)`合計した`i`1 から _k_ まで。 このカウントを乗算します`c`そして現在の合計に追加します。 
5. すべてのエッジを処理した後、危険の合計を次の値で割ります。`C(n,k)`平均を取得します。 最も近い整数に切り捨てます。 

機能する理由: すべての _k_ 要素セットは、正確に 1 つの接続サイロに対応します。 偵察兵がそこを通過しなければならない場合、あらゆるエッジがまさに危険に寄与します。 両側のサブセットの数を数えることにより、ツリー構造と組み合わせの対称性を活用して、すべてのセットを効率的に考慮します。 この方法により、セットを明示的に列挙せずに、それらの合計寄与度を正確に合計することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import comb

def main():
    n, k = map(int, input().split())
    adj = [[] for _ in range(n)]
    c = [[-1]*n for _ in range(n)]
    
    # read upper-triangular adjacency matrix
    for i in range(n-1):
        row = list(map(int, input().split()))
        for j, val in enumerate(row):
            if val != -1:
                u, v = i, i+j+1
                adj[u].append(v)
                adj[v].append(u)
                c[u][v] = c[v][u] = val

    # dfs to compute subtree sizes
    size = [0]*n
    def dfs(u, parent):
        size[u] = 1
        for v in adj[u]:
            if v != parent:
                dfs(v, u)
                size[u] += size[v]
    
    dfs(0, -1)
    
    total = 0
    # process each edge
    visited = set()
    for u in range(n):
        for v in adj[u]:
            if (u,v) in visited or (v,u) in visited:
                continue
            visited.add((u,v))
            s = min(size[u], size[v])
            if s == size[u]:
                s = size[u]
            else:
                s = size[v]
            # number of sets where scouts cross this edge
            count = comb(n-2, k-1)
            total += count * c[u][v]

    average = total // comb(n, k)
    print(average)

if __name__ == "__main__":
    main()
```コードはまず、入力から隣接リストと行列を構築します。 DFS はサブツリー サイズを計算し、そのサイズを使用して各エッジを横断する必要がある _k_-silo セットの数を計算します。 各エッジを 1 回だけカウントします。 セットの数にエッジの重みを掛けると合計寄与が得られ、最後に除算すると平均危険が得られます。
