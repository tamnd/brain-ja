 このアルゴリズムは、次の順序で並べ替えられた要素のプレフィックスを処理した後も、不変条件を維持します。$b_i$、ヒープには、最大で可能な限り最良の選択が保存されます。$p$最適なソリューションに現れる可能性があるプレフィックスの要素。 ここでの「最良」とは、プレフィックスからの同じサイズの他の選択は、従順なグループに対して最終的により高い貢献をもたらさないことを意味します。$a_i$要素は常に最初に破棄されます。

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, p, k = map(int, input().split())
    arr = []
    for i in range(n):
        a, b = map(int, input().split())
        arr.append((b, a, i + 1))
    
    # sort by b descending
    arr.sort(reverse=True)
    
    import heapq
    heap = []
    
    for b, a, idx in arr:
        heapq.heappush(heap, (a, idx))
        if len(heap) > p:
            heapq.heappop(heap)
    
    # heap now contains p chosen elements
    # we only need to output their indices
    print(*[x[1] for x in heap])

if __name__ == "__main__":
    solve()
