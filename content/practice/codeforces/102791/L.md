 ## 解決策
 ## 問題の理解

 有向非巡回グラフがあります。 すべてのエッジは、より大きな値が割り当てられた頂点から、より小さな値が割り当てられた頂点へと進みます。 エッジが発生する場合`x`に`y`、その貢献度は`w * (a[x] - a[y])`。 タスクは、すべてのエッジの差が正となり、重み付けされた合計寄与が可能な限り小さくなるように、頂点に整数値を割り当てることです。 

グラフには最大 18 個の頂点があります。 この小さな値が主な手がかりとなります。 指数関数的なソリューション`n`機能しますが、値の可能なすべての代入を試みるようなことはできません。代入の数がはるかに速く増加するためです。`2^n`。 

最初の有用な変換は、目的を書き直すことです。 

すべての頂点について、その値の係数を収集します。 頂点は、出力エッジを通じてプラスに寄与し、入力エッジを通じてマイナスに寄与します。```
sum(w * (a[x] - a[y])) = sum(c[v] * a[v])
```どこ`c[v]`は、出力エッジの合計重みから入力エッジの合計重みを引いたものです。 

制約はすべてのエッジに対して順序付け制約になります。`x -> y`、`a[x] > a[y]`。 

微妙な点は、すべてのオブジェクトに同じ定数を追加することです。`a[v]`係数の合計はゼロになるため、何も変わりません。 最小割り当て値がゼロになるように、ソリューション全体をシフトできます。 

値を超える必要はありません`n - 1`。 値の 2 つの連続するレイヤーが空の場合、エッジ制約を破ることなく、上位レイヤーのすべての頂点を 1 つ減らすことができ、答えが改善されます。 したがって、最適解は常に次の値を使用して表現できます。`n`層。 

最も起こりやすい間違いは、最長のパス長のみを使用して値を割り当てることです。 これは不等式を満たしますが、加重合計を最小化できない可能性があります。 例えば：```
3 3
1 2 100
2 3 1
1 3 1
```最長パスの割り当てにより値が得られます`2 1 0`ただし、最初のエッジのウェイトが大きいということは、そのエッジのギャップを減らすことがより重要であることを意味します。 最適な階層化は、係数によるすべてのエッジの重みに依存します。 

## アプローチ

 強引なアイデアは、可能な値の割り当てをすべて試してみることです。 すべての頂点には最大で次のものを含めることができるため、`n`可能なレイヤー、これには大まかに必要です`n^n`割り当てはすでに大きすぎます`n = 18`。 

有益な観察は、ソリューションが実際には頂点をレイヤーに分割したものであるということです。 上位レイヤーの頂点ほど大きな値になります。 少なくともどの頂点に値があるかがわかっている場合`k`、そのセットには、その頂点のすべての先行要素が含まれている必要があります。 言い換えれば、すべてのレイヤー境界は、入力エッジの下で閉じられた頂点のサブセットに対応します。 

問題は、レイヤー番号を掛けた係数の合計を最小限に抑えながら、有効なレイヤーを選択することになります。 しかないので、`2^18`サブセットの場合は、サブセット動的プログラミングを使用できます。 

便利な実装では、レイヤーを 1 つずつ処理します。 サブセットの場合`S`、頂点に正確に値を割り当てた後、最小コストを保存します。`S`。 次のレイヤーを作成するには、次の値を受け取ることができる残りの頂点の有効なサブセットを選択します。 すべての遷移を単純に列挙すると、`O(3^n)`、高すぎます。 

代わりに、トポロジ順に頂点を選択するサブセット DP を使用してレイヤーを構築します。 現在のレイヤーの頂点を検討する場合、その頂点が指すすべての頂点がすでに下位レイヤーに配置されている場合にのみ、その頂点をそこに配置できます。 これにより、サブセット列挙が削除され、`O(n^2 2^n)`解決。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^n) | O(n) | 遅すぎる |
 | 層サブセット DP | O(n^2 2^n) | O(n 2^n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. コンピューティング`c[v]`頂点ごとに。 エッジの重みをソース係数に追加し、それを宛先係数から減算します。 元のエッジ目標は最小化と同等になりました。`sum(c[v] * a[v])`。 
2. グラフを位相的に並べ替えます。 この順序により、既にその下に存在する頂点のみをチェックすることで、頂点がレイヤーに結合できるかどうかを判断できます。 
3. サブセットに対して動的プログラミングを実行します。 ステートは、いくつかの頂点を処理し、そのうちのどれがすでに完了した下位層に属するかを決定した後、最良のコストを保存します。 
4. トポロジ順に並んだすべての頂点について、2 つの選択肢を試してください。 現在のレイヤーの頂点をスキップするか、すべての出力近傍がすでに下位レイヤーのサブセットにある場合は、頂点を現在のレイヤーに配置します。 
5. レイヤーに頂点を配置する場合`k`、 追加`c[v] * k`現在のコストに。 選択したレイヤーを再構築できるように、親情報を保存します。 
6. 選択したレイヤーを親ポインターから復元し、すべての頂点に割り当てられた値を出力します。 

これが機能する理由: すべての有効な割り当ては、等しい値のレイヤーを定義します。 DP は、より小さい値を持つすべての頂点が固定された後にのみ頂点がレイヤーに入ることができるため、これらの可能なレイヤー構造を正確に考慮します。 すべてのトランジションでは、そのレイヤーに配置された頂点の寄与が正確に追加されます。 すべての有効な割り当ては 1 つの DP パスに対応し、すべての DP パスは有効な割り当てに対応するため、最小の DP 値がまさに最適です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    coef = [0] * n
    out = [0] * n

    for _ in range(m):
        x, y, w = map(int, input().split())
        x -= 1
        y -= 1
        coef[x] += w
        coef[y] -= w
        out[x] |= 1 << y

    order = []
    indeg = [0] * n
    for i in range(n):
        for j in range(n):
            if (out[i] >> j) & 1:
                indeg[j] += 1

    q = [i for i in range(n) if indeg[i] == 0]
    while q:
        v = q.pop()
        order.append(v)
        for u in range(n):
            if (out[v] >> u) & 1:
                indeg[u] -= 1
                if indeg[u] == 0:
                    q.append(u)

    N = 1 << n
    INF = 10**30

    dp = [INF] * N
    dp[0] = 0
    parent = [(-1, -1)] * N

    for layer in range(n):
        ndp = dp[:]
        npar = parent[:]

        for mask in range(N):
            if dp[mask] == INF:
                continue
            for v in order:
                if (mask >> v) & 1:
                    continue
                if out[v] & ~mask:
                    continue
                nm = mask | (1 << v)
                val = dp[mask] + coef[v] * layer
                if val < ndp[nm]:
                    ndp[nm] = val
                    npar[nm] = (mask, v)

        dp = ndp
        parent = npar

    ans = [0] * n
    mask = N - 1
    layer = n - 1

    while mask:
        pm, v = parent[mask]
        if pm == -1:
            break
        ans[v] = layer
        mask = pm
        if mask == 0:
            break

    print(*ans)

if __name__ == "__main__":
    solve()
```係数の計算では、エッジ変数が完全に削除されます。 トポロジカルな順序付けは、レイヤーの頂点が選択されたときに、必要な下位の頂点がすべてすでに考慮されていることを保証するためにのみ使用されます。 

サブセット DP はビットマスクを使用します。`n`移行条件はわずか 18 です。`out[v] & ~mask == 0`のすべての発信隣人を意味します`v`すでに下位層の中にあります。 これはまさにその要件です`a[v]`それらすべてより大きくなければなりません。 

再構築は、保存された親を逆方向に進みます。 選択された各トランジションは、レイヤーに入る 1 つの頂点を記録するため、現在のレイヤー番号をその頂点に割り当てると、最適な割り当てが再構築されます。 

## 実用的な例

 最初のサンプルの場合:```
3 2
2 1 4
1 3 2
```係数は次のとおりです。 

| 頂点 | 係数 |
 | --- | --- |
 | 1 | -2 |
 | 2 | 4 |
 | 3 | -2 |

 有効な最適な階層化は次のとおりです。 

| 頂点 | 割り当てられた値 |
 | --- | --- |
 | 2 | 2 |
 | 1 | 1 |
 | 3 | 0 |

 頂点 2 の正の係数が大きいため、頂点 2 を高くすることは避けられませんが、頂点 1 と 3 は低くしておいたほうが安価です。 

3 番目のサンプルの場合:```
5 5
1 2 1
2 3 1
3 4 1
1 5 1
5 4 10
```最適なレイヤーは次のとおりです。 

| 頂点 | 割り当てられた値 |
 | --- | --- |
 | 1 | 4 |
 | 2 | 3 |
 | 3 | 2 |
 | 4 | 1 |
 | 5 | 2 |

 DP は頂点 5 の値を増やすことを好みます。`5 -> 4`最も大きな重量を持っています。 

## 複雑さの分析

 ## 特殊なケース

 エッジのないグラフには順序制限がありません。 すべての頂点の係数は 0 であるため、すべての頂点は値 0 を受け取ることができます。 DP は空のサブセットから開始され、同じレイヤー内のすべての頂点で終了することができます。 

切断されたコンポーネントは独立して処理されます。 2 つの頂点グループの間にエッジがない場合、それらの相対的な垂直位置は実現可能性に影響を与えず、係数変換は重要な唯一のもの、つまり客観的な値を正確に取得します。 

非常に大きなウェイトで接続されている頂点を不必要に分離しないでください。 DP はレイヤーの数だけを最適化するのではなく、重み付けされた係数の合計を最適化するため、高価なエッジは選択された配置に影響を与えます。 

複数の頂点は、エッジが間違った方向に接続していない限り、同じ値を共有できます。 サブセット遷移により、互換性のある頂点のセットが 1 つのレイヤーを占有することができます。これが、このソリューションが単純に最長パスの深さを割り当てるよりも優れている主な理由です。
