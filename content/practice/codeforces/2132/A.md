 ## 解決策
 ## 問題の理解

 文字列から始めます`a`。 別の文字列`b`には、出現順に 1 つずつ挿入する必要がある文字が含まれています。 

あらゆるポジションについて`i`で`b`、対応する文字`c[i]`誰がその文字を挿入したかを教えてくれます。 もし`c[i] = 'V'`、ヴラドインサート`b[i]`現在の文字列の先頭にあります。 もし`c[i] = 'D'`、ディマインサート`b[i]`最後に。 

すべての文字を処理した後、`b`、最後の文字列を出力する必要があります。 

制約は非常に小さいです。 両方`a`そして`b`長さは最大 10 で、テスト ケースの数は最大 1000 です。 すべての操作の後に文字列を物理的に変更する直接シミュレーションでも、テスト ケースごとに実行される文字操作は数十文字のみです。 ここでは効率は問題になりません。 このタスクは純粋に、説明されているプロセスを正しく実装することに関するものです。 

間違いの主な原因は、広告掲載オーダーの処理です。 

考慮する：```
a = "x"
b = "ab"
c = "VV"
```操作は次のとおりです。```
x
ax
bax
```答えは次のとおりです。```
bax
```不注意な解決策では、Vlad に割り当てられたすべての文字を収集し、それらを元の順序で先頭に追加して、次のような結果が生じる可能性があります。`"abx"`、これは間違いです。 すべての新しい Vlad キャラクターは、既存のすべてのキャラクターの前に配置されます。 

もう 1 つの簡単な間違いは、すべての Vlad 操作を最初に処理し、すべての Dima 操作を後で処理することです。 

例：```
a = "ot"
b = "ad"
c = "DV"
```正しいプロセス:```
ot
ota
dota
```答え：```
dota
```時系列順を尊重するのではなく、人ごとに操作をグループ化すると、異なる結果が得られるでしょう。 

## アプローチ

 最も直接的なアイデアは、ステートメントの説明を正確にシミュレートすることです。 

現在の文字列を維持します。 ポジションごとに`i`、 もし`c[i]`は`'V'`、置きます`b[i]`正面にあります。 それ以外の場合は後ろに配置します。 

文字列は小さいため、挿入するたびに新しい文字列を作成してもまったく問題ありません。 可能な限り長い文字列の長さは最大です`n + m ≤ 20`, したがって、各挿入には最大 20 キャラクターのコピーがかかります。 

最悪の場合、長さ 20 の文字列に対してそれぞれ最大 10 回の挿入が実行されます。これは、テスト ケースあたりわずか数百文字の操作にすぎません。 

もう少し明確な観察があります。 ヴラドが挿入した文字は常に左側に蓄積され、ディマが挿入した文字は常に右側に蓄積されます。 

ヴラドが先頭に文字を挿入すると、最新のヴラドの文字が一番左になります。 つまり、ヴラドの登場人物は、`b`。 

Dima が最後に文字を挿入しても、その順序は変わりません。 

したがって、次のものを構築できます。```
left  = all b[i] where c[i] = 'V'
right = all b[i] where c[i] = 'D'
```そして、最終的な答えは次のようになります。```
reverse(left) + a + right
```どちらの方法でも受け付けられます。 2 番目の方法では、文字列の繰り返しの変更を回避し、答えを直接構築します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O(m(n+m)) | O(n+m) | 承認済み |
 | 最適な構造 | O(n+m) | O(n+m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.文字列を読む`a`、`b`、 そして`c`。 
2. 2 つの空の文字列 (またはリスト) を作成します。`left`そして`right`。 
3. のすべての位置をスキャンします。`b`。 
4. もし`c[i]`は`'V'`、追加`b[i]`に`left`。 

現時点ではキャラクターのみを記録します。 最終的な位置は後で決定されます。 
5. もし`c[i]`は`'D'`、追加`b[i]`に`right`。 

Dima の文字はそれぞれ最後に追加されるため、元の順序が維持されます。 
6. リバース`left`。 

Vlad は先頭に繰り返し挿入するため、処理された最後の Vlad 文字が最終文字列の左端の文字になります。 
7. 出力:```
reverse(left) + a + right
```### なぜ効果があるのか

 すべての Vlad 操作では、現在の文字列全体の前に文字が挿入されます。 Vlad が文字を受け取ったとします。```
x1, x2, x3
```その順番で。 

それらの効果は次のとおりです。```
x1 + ...
x2 + x1 + ...
x3 + x2 + x1 + ...
```つまり、ヴラドの登場人物は逆の順序で登場します。 

Dima の操作は常に末尾に追加されます。```
... + y1
... + y1 + y2
... + y1 + y2 + y3
```したがって、ディマのキャラクターは元の順序で表示されます。 

キャラクターを片側から動かすことはできません`a`もう一方へ。 最終的な構造は正確に次のようになります。```
(reversed Vlad characters) + a + (Dima characters)
```それはまさにアルゴリズムが構築するものです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    a = input().strip()

    m = int(input())
    b = input().strip()
    c = input().strip()

    left = []
    right = []

    for ch, who in zip(b, c):
        if who == 'V':
            left.append(ch)
        else:
            right.append(ch)

    ans = ''.join(reversed(left)) + a + ''.join(right)
    print(ans)
```このソリューションでは、文字を挿入する人に応じて文字が分割されます。 

ヴラドに割り当てられたキャラクターは、`left`。 に表示されるのと同じ順序で収集されます。`b`ただし、新しい Vlad の挿入はすべて先頭で行われるため、最終的な順序は逆にする必要があります。 

Dima に割り当てられた文字は次の場所に格納されます。`right`。 最後に追加すると時系列が保持されるため、順序は変わりません。 

最後に、答えは 3 つの部分から組み立てられます。反転された Vlad セグメント、元の文字列です。`a`、および Dima セグメント。 

リストと`''.join()`これは Python の標準的な方法であり、不必要な中間文字列の作成を回避します。 

## 実用的な例

 ### 例 1

 入力:```

```| ステップ | キャラクター | オーナー | 左 | 右 |

 | 開始 | - | - | "" | "" |

reverse("d") + "ot" + "a"
= "dota"
```出力：```
dota
```この例は、操作の順序が重要であることを示しています。 Dima が最初に動作し、次に Vlad が現在の文字列全体の前に挿入します。 

### 例 2

 入力:```

```| ステップ | キャラクター | オーナー | 左 | 右 |

 | 4 | n | D | "アブ" | 「オン」 |

reverse("ab") + "biz" + "on"

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + m) | 文字列を 1 回スキャンし、最大で 1 回の反転`m`キャラクター |
 | スペース | O(n + m) | 答えと一時的な文字リストの保管場所 |

 以来`n`そして`m`どちらも最大でも 10 なので、実行時間はわずかです。 1,000 のテスト ケースにわたっても、合計作業量は制限に比べて無視できる程度です。

import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline
    t = int(input())
    out = []

        n = int(input())
        a = input().strip()

        m = int(input())
        b = input().strip()

            if who == "V":
                left.append(ch)
            else:
                right.append(ch)

        out.append("".join(reversed(left)) + a + "".join(right))

    return "\n".join(out)
