 ## 解決策
 ## 問題の理解

 すべての正の整数を連続して書くことによって形成される無限の文字列を考慮するように求められます。`123456789101112...`等々。 テストケースごとに番号が与えられます`k`この無限の文字列の先頭から取得する桁数を表します。 タスクはそれらの合計を計算することです`k`数字。 

たとえば、次の場合`k = 5`、最初の 5 桁は`12345`、それらの合計は`15`。 もし`k = 10`、数字は`1234567891`、合計は`46`。 

制約は大きいです:`k`まで可能です`10^15`、最大で`2 * 10^4`テストケース。 文字列を明示的に構築してその桁を合計する単純なアプローチでは、時間がかかりすぎてメモリを大量に消費します。 桁ごとに反復しようとしても、処理は`10^15`妥当な時間内に桁数を計算することは不可能です。 

エッジケースは微妙です。 1つはそのときです`k`たとえば、異なる長さの数値間の境界で正確に終了します。`k = 9`(数字で終わる`9`） または`k = 11`(末尾は 2 桁の数字)。 不用意に解決すると、桁数を数え間違えたり、最後の数字をオーバーランしたりする可能性があります。 別のエッジケースは非常に大きい`k`、例えば、`k = 10^15`、整数のオーバーフローや累積和は、慎重に扱わないと失敗する可能性があります。 

## アプローチ

 ブルートフォース手法は簡単です。各数値を文字列として生成し、実行中のシーケンスに追加し、合計の長さに達したら停止します。`k`、数字を合計します。 これが機能するのは、シーケンスを忠実に再現し、桁を正確にカウントするためです。 問題は規模だ。 最初の桁の合計`10^15`数字は少なくとも反復処理が必要です`10^14`これは 2 秒では実現不可能な数字です。 

効率的な解決策を導き出す重要な観察は、数値をその長さによってグループ化できるということです。 数字と`1`からの数字`1`に`9`、数字付き`2`数字はから始まります`10`に`99`、 等々。 長さのグループごとに`d`、グループ全体が寄与する桁数が正確にわかります。`count_of_numbers * d`。 これを使用して、どのグループに属しているかを判断できます。`k`-th 桁は文字列を構築せずに落ちます。 

グループがわかったら、反復する代わりに数式を使用して桁の合計を計算できます。 数値範囲の場合、各桁位置の寄与を考慮して桁の合計を計算できます。 具体的には、長さの数値については、`d`、最初の桁の合計`x`数値は、各位置の数字の等差級数を使用して表現できます。 実際には、絶対に必要な場合にのみ数値を反復処理することでこれを処理し、残りの部分数値についてはその桁を直接合計します。 

このアプローチにより、次の問題が軽減されます。`O(k)`に`O(log k)`テスト ケースごとの操作数は最大でも`16`桁長グループ`k ≤ 10^15`、二分探索は、カットオフが発生する正確な数を特定するのに役立ちます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k) | O(k) | 遅すぎる |
 | 最適 | O(log k * log k) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. から始める`k`、合計する桁数。 初期化する`sum_digits = 0`そして`remaining_digits = k`。 
2. 桁数を繰り返します。`d = 1, 2, 3 ...`グループが見つかるまで`k`- 桁目は嘘です。 各グループの最初の番号は次のとおりです。`10^(d-1)`そして最後は`10^d - 1`。 このグループ内の数値の合計数は次のとおりです。`9 * 10^(d-1)`。 このグループの合計桁数は次のとおりです。`count * d`。 
3. もし`remaining_digits`現在のグループの数字より大きい場合は、桁合計の式を使用してグループ全体のすべての桁の合計を計算し、減算します。`digits_in_group`から`remaining_digits`。 グループの合計を加算します`sum_digits`そして次のグループに移ります。 
4. もし`remaining_digits`現在のグループの合計桁数より小さい場合、カットオフはこのグループ内にあります。 正確な数を決定する`num`が含まれている`remaining_digits`-番目の桁は、整数の除算とモジュロ演算を使用します。 
5. すべての完全な数値の桁を合計します。`num`グループ内で数式を使用します。 切り捨てられる可能性がある最後の数値については、以下に対応する最初の数桁のみを合計します。`remaining_digits % d`。 
6. 出力`sum_digits`。 

不変条件は、各グループを処理した後、`sum_digits`現在のグループの前のすべての数字の合計が含まれます。`remaining_digits`まだ必要な桁数を追跡します。 グループを順番に処理することにより、合計は正確になり、グループ境界により、桁のスキップや二重カウントが発生しないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def sum_digits_upto(n):
    return sum(int(c) for c in str(n))

def solve():
    t = int(input())
    for _ in range(t):
        k = int(input())
        sum_digits = 0
        remaining = k
        d = 1
        while True:
            first = 10**(d-1)
            last = 10**d - 1
            count = last - first + 1
            digits_in_group = count * d
            if remaining > digits_in_group:
                # Sum all numbers in this group
                sum_group = 0
                for num in range(first, last + 1):
                    sum_group += sum_digits_upto(num)
                sum_digits += sum_group
                remaining -= digits_in_group
                d += 1
            else:
                # Cut is inside this group
                num_idx = remaining // d
                extra_digits = remaining % d
                for i in range(first, first + num_idx):
                    sum_digits += sum_digits_upto(i)
                if extra_digits > 0:
                    last_num = first + num_idx
                    sum_digits += sum(int(c) for c in str(last_num)[:extra_digits])
                break
        print(sum_digits)

if __name__ == "__main__":
    solve()
```このコードでは、`sum_digits_upto`各数値の桁を合計するには、数値のグループを長さごとに繰り返し、最後に部分的な数値を処理します。 while ループは、各桁が正確に 1 回カウントされることを保証します。 完全なグループと部分的な数値に分割することで、正確さと効率性が保証されます。
