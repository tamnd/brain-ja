 ## 解決策
 ## 問題の理解

 私たちにはバレリーナの長方形のグリッドが与えられ、それぞれが小文字の英語の文字で表される 26 の可能な動きのうちの 1 つを実行します。 概念的には、各行は文字列であり、グリッド全体は文字列の配列です。 振付師はグリッドを 180 度回転させ、最終的な構成を最初の構成と一致させたいと考えています。 現在の配置でこれが不可能な場合は、任意の動きを持つ新しいバレリーナを追加して、可能になるまでグリッドを拡大する可能性があります。 タスクは、各テスト ケースに必要な追加バレリーナの最小数を計算することです。 

制約に関しては、最大で次のものがあります。$10^5$テスト ケース、およびすべてのテストにわたるバレリーナの総数は最大で$10^6$。 これにより、強制的に$O(n \cdot m)$テスト ケースごとにソリューションを実行しますが、これより遅いものは制限時間内に収まりません。 個々の行と列はそれぞれ次のように大きくできます。$10^6$したがって、グリッドの可能な限りの拡張やバレリーナの順列を試みる解決策は避けなければなりません。 

微妙なエッジ ケースには、独自のミラーである単一行または単一列のグリッドや、一部の対称ペアがすでに一致しているが他のペアが一致していないグリッドが含まれます。 たとえば、文字を含む 2x2 グリッドは次のようになります。```
a b
b c
```ここで対称ペア`(0,0)-(1,1)`そして`(0,1)-(1,0)`は`(a,c)`そして`(b,b)`。 単純なアルゴリズムは単にカウントするだけかもしれません`b,b`大丈夫ですので無視してください`a,c`不一致は、不正確な最小加算値につながります。 

## アプローチ

 強引なアプローチでは、グリッドが 180 度回転して対称になるまで、考えられるすべての行と列を追加してみます。 それは正しいのですが、欠落している各位置は複数の方法で埋められる可能性があるため、大規模なグリッドでは指数関数的な数の操作が必要になる可能性があります。 たとえ単一のテストケースであっても、$n$そして$m$が 500 である場合、これには最大で$2^{250000}$実現不可能な可能性。 

最適なアプローチを明らかにする重要な観察は、180 度の回転対称により、グリッドの中心を横切るセルのペアリングの問題が軽減されるということです。 位置にあるすべてのセル`(i,j)`のセルと一致する必要があります`(n-1-i, m-1-j)`グリッドが自己対称になるようにします。 すでに一致しているセルは無視できます。 各不一致は、より大きな対称の長方形を作成するために新しいバレリーナが必要か、またはペアの数が特定の行または列に沿って均等である場合に解決できるペアを表します。 必要なのは、一致しないペアが何個あるかを数え、それらをペアにするために必要な追加の行または列の最小数を決定することだけです。これは、次の計算と同じです。`(total_pairs - matching_pairs)`すべての対称位置に対応します。 各セルを 1 回だけ反復するため、このアプローチはバレリーナの数において線形です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(n*m)) | O(n*m) | 遅すぎる |
 | 対称性の計数 (最適) | O(n*m) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 各テスト ケースの寸法を読み取ります。`n`そして`m`。 
2. を読んでください。`n`グリッドの行を文字列のリストとして保存します。 
3. 追加のバレリーナのカウンターを 0 に初期化します。 
4. グリッドの「左上の象限」、つまりセルのみを考慮して、グリッドを反復処理します。`(i,j)`どこ`i < (n+1)//2`そして`j < (m+1)//2`。 これにより、対称ペアを二重にカウントしないことが保証されます。 
5. 各セルについて`(i,j)`、対称ペアを識別します`(n-1-i, m-1-j)`。 
6. これらの位置のキャラクターが異なる場合、最終的には一致する追加のバレリーナが必要になります。 それらが同じである場合、アクションは必要ありません。 
7. 奇数の寸法のグリッドの場合は、中央の行または列を個別に処理します。 これらのセルは自身をミラーリングするため、ペアになっていないセルごとにバレリーナを 1 人追加することで不一致を解決できます。 
8. すべての対称ペアにわたって必要な追加のバレリーナを合計します。 
9. テスト ケースの合計数を出力します。 

機能する理由: 各対称ペアを 1 回だけ考慮し、不一致を数えることで、必要な最小限の数の新しいバレリーナを確実に追加できます。 この計算における不一致の数を正確に使用して、180 度の回転に一致するように、元のグリッドから任意の対称構成を拡張できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def min_ballerinas_needed(n, m, grid):
    extra = 0
    for i in range((n + 1) // 2):
        for j in range((m + 1) // 2):
            x, y = i, j
            sx, sy = n - 1 - i, m - 1 - j
            chars = [grid[x][y]]
            if sx != x or sy != y:
                chars.append(grid[sx][sy])
            # Count frequency of each char
            freq = {}
            for c in chars:
                freq[c] = freq.get(c, 0) + 1
            # Max frequency is the number we can keep; rest need new ballerinas
            extra += len(chars) - max(freq.values())
    return extra

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]
    print(min_ballerinas_needed(n, m, grid))
```各ペアは 1 回だけチェックされ、頻度辞書により、既存の文字と一致しない文字の追加のみがカウントされます。 奇数の場合`n`または`m`、中央の行または列は、それら自体をミラーリングするときに自動的に処理されます。
