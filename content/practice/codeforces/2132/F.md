 ## 解決策
 ## 問題の理解

 カモミールバレーを表す接続された無向グラフを分析するように求められています。ノードは家、エッジはそれらの間の車線です。 Rada は、どの車線が家 1 から家 n までの **すべての最短経路** の一部であることが保証されているかを知りたいと考えています。 彼女は数日ごとに特定の家にいるため、これらの「いつも使用される」レーンのうち最も近いレーンを報告する必要があります。 

家から車線までの距離は、その車線のいずれかの端点までの最小距離として定義されます。 各クエリのタスクは、Rada が立っている家に最も近い必須の車線のインデックスを返すか、必須の車線がない場合は -1 を返すことです。 

この制約は、すべてのレーンとクエリの 1 から n までのすべてのパスをチェックする総当りアプローチでは遅すぎることを意味します。 n と m が最大 2 · 10^5、最大 10^4 のテスト ケースの場合、アルゴリズムは基本的に **テスト ケースごとのグラフのサイズで線形時間** (およそ O(n + m + q)) で実行する必要があります。 

1 から n までの最短パスが複数ある場合、微妙なエッジ ケースが発生します。 そのシナリオでは、一部の車線がすべての最短パスに属していない可能性があります。 たとえば、1 が 2 と 3 に接続され、両方とも n に接続されている場合、1-2-n も 1-3-n も保証されないため、答えは -1 になります。 もう 1 つの特殊なケースは、グラフがツリーである場合です。 ここでは、1 から n までの一意のパス上のすべてのエッジが使用されることが保証されています。 

## アプローチ

 ブルート フォース アプローチでは、BFS を使用して 1 から n までのすべての最短パスを計算し、各エッジがすべてのパスに出現するかどうかを確認します。 これにはすべてのパスを生成する必要がありますが、これは n で指数関数的なため、実行不可能です。 中間のアイデアは、1 および n から他のすべてのノードまでの距離を計算することです。 エッジ u-v は、**1 から n までの最短パス上にあり**、**すべての最短パスにそれが含まれている必要がある**場合に保証されます。これは、距離 d1[u] + 1 + dn[v] の合計が 1 から n までの距離と等しく、d1[v] + 1 + dn[u] の場合も同様の場合に発生します。 重み付けされていないグラフでは対称性により、最短経路上にあるエッジが識別されますが、より強力な特性が必要です。つまり、エッジは**必須**でなければなりません。つまり、それがそのステップで最短経路に沿って進む唯一の方法です。 

重要な洞察は、1 からの BFS と n からの BFS を使用して距離を計算することです。 1 からの距離が **厳密に増加**し、n までの距離が**厳密に減少**しているノードを接続する場合、エッジは必須です。 このプロパティにより、最小距離を維持する代替ルートがないため、すべての最短パスがエッジを通過する必要があります。 必須レーンが判明すると、クエリへの回答は、クエリ ノードから任意の必須レーンまでの最小距離を見つけることになります。これは、BFS を使用するか、すべての必須レーン エンドポイントから開始するマルチソース BFS を使用して距離を事前計算することによって実行できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべてのパス) | O(2^n) | O(n + m) | 遅すぎる |
 | BFS ベースの必須エッジ + マルチソース BFS | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、グラフを読み取り、隣接リストを作成します。 
2. ノード 1 から BFS を実行して計算します`d1[i]`、1 からすべてのノードまでの最短距離。 
3. ノード n から BFS を実行して計算します`dn[i]`、n からすべてのノードまでの最短距離。 
4. 各エッジ u-v をチェックして、必須のレーンを特定します。 もし`d1[u] + 1 + dn[v] == d1[n]`**そして**`d1[v] + 1 + dn[u] == d1[n]`そして`d1[u] < d1[v]`(n に向かって確実に進むために)、このエッジを必須としてマークします。 
5. 必須レーンのエンドポイントであるすべてのノードを収集します。 これらすべてのノードから BFS を同時に初期化し、各ノードが最も近いレーン インデックスを保存します。 
6. 各クエリ ハウスについて、最も近い必須レーンのインデックスを報告します。 必須レーンが存在しない場合は、-1 を出力します。 

機能する理由: BFS は、すべてのノードまでの最小距離を正しく計算し、距離を 1 から厳密に増加させ、距離を n まで厳密に減少させる特性により、最短パスでエッジがバイパスされないことを保証します。 BFS は常に距離の昇順にノードを探索するため、マルチソース BFS は最も近い必須レーン インデックスを正しく伝播します。 

## Python ソリューション```python
import sys
from collections import deque
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        adj = [[] for _ in range(n)]
        edges = []
        for i in range(m):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            adj[u].append((v, i + 1))
            adj[v].append((u, i + 1))
            edges.append((u, v))
        
        def bfs(start):
            dist = [n+1] * n
            dist[start] = 0
            dq = deque([start])
            while dq:
                u = dq.popleft()
                for v, _ in adj[u]:
                    if dist[v] == n+1:
                        dist[v] = dist[u] + 1
                        dq.append(v)
            return dist
        
        d1 = bfs(0)
        dn = bfs(n-1)
        dist_1_n = d1[n-1]
        
        mandatory_edges = []
        for idx, (u, v) in enumerate(edges):
            if d1[u] + 1 + dn[v] == dist_1_n and d1[u] < d1[v]:
                mandatory_edges.append((u, v, idx+1))
            elif d1[v] + 1 + dn[u] == dist_1_n and d1[v] < d1[u]:
                mandatory_edges.append((v, u, idx+1))
        
        if not mandatory_edges:
            q = int(input())
            print(" ".join(["-1"] * q))
            for _ in range(q):
                input()
            continue
        
        nearest_edge = [0] * n
        dist_to_edge = [n+1] * n
        dq = deque()
        for u, v, idx in mandatory_edges:
            for node in (u, v):
                if dist_to_edge[node] > 0:
                    dist_to_edge[node] = 0
                    nearest_edge[node] = idx
                    dq.append(node)
        
        while dq:
            u = dq.popleft()
            for v, ei in adj[u]:
                if dist_to_edge[v] > dist_to_edge[u] + 1:
                    dist_to_edge[v] = dist_to_edge[u] + 1
                    nearest_edge[v] = nearest_edge[u]
                    dq.append(v)
                elif dist_to_edge[v] == dist_to_edge[u] + 1:
                    nearest_edge[v] = min(nearest_edge[v], nearest_edge[u])
        
        q = int(input())
        res = []
        for _ in range(q):
            c = int(input()) - 1
            res.append(str(nearest_edge[c]))
        print(" ".join(res))

if __name__ == "__main__":
    solve()
```このソリューションでは、まずノード 1 と n からの距離を計算します。 必須のエッジは、エッジが最短パスに沿って進む唯一の方法であることを確認することによって選択されます。 マルチソース BFS は、最も近い必須レーン インデックスを効率的に伝播します。 出力に 1 から始まるレーン インデックスを使用する場合は注意が必要です。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | テスト ケースごとに O(n + m + q) | BFS は O(n + m) で実行され、必須エッジ チェックは O(m) で実行され、マルチソース BFS は O(n + m) で実行され、クエリに応答します O(q) |
 | スペース | O(n + m) | グラフの隣接関係リスト、距離配列、および BFS キュー |

 すべてのテスト ケースにわたる n、m、q の合計 ≤ 2 · 10^5 を考慮すると、アルゴリズムは 512 MB のメモリで 3 秒の制限に快適に収まります。
