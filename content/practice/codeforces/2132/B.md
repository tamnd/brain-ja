 ## アルゴリズムのチュートリアル

 すべての有効な構造は次の条件を満たします$n = x(1 + 10^k)$ある整数に対して$k \ge 1$。 逆に、どれでも、$k$誰のために$1 + 10^k$分割する$n$候補者を導き出す$x$有効な$y = x \cdot 10^k$。 アルゴリズムは可能なすべてを列挙します$k$そして、それぞれについて、可能なものを 1 つだけ拒否するか再構築します。$x$。 すべての有効な表現がそのような 1 つに正確に対応するため、有効な解決策を見逃すことはできません。$k$、割り算により元の方程式が厳密に強制されるため、無効な解を追加することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        res = []

        pow10 = 10
        k = 1

        while pow10 < n:
            d = pow10 + 1
            if n % d == 0:
                x = n // d
                res.append(x)
            pow10 *= 10
            k += 1

        if not res:
            print(0)
        else:
            res.sort()
            print(len(res))
            print(*res)

if __name__ == "__main__":
    solve()

ループは次の場合に停止します。$10^k \ge n$なぜならその点を超えると$1 + 10^k$すでに超えています$n$、割り切れなくなります。 

最後に並べ替えると、サイズが大きくても出力順序が正しいことが保証されます。$k$必ずしも小さいものに対応するとは限りません$x$。

 ## 特殊なケース

 重要なエッジケースの 1 つは次のような場合です。$n$はちょうど 10 の累乗か、それに近い値です。 例えば、$n = 1000000000000000000$。 アルゴリズムは反復されます$k$、しかし、すべて$10^k + 1$どちらかが超える$n$または分割しません。 ループは早期に停止し、候補は生成されず、正しく 0 が出力されます。
