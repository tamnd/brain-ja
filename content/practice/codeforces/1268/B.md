 ## 解決策
 ## 問題の理解

 ヤング図は、列の高さが非増加配列によって与えられるヒストグラムとして表示できます。$a_1,a_2,\dots,a_n$。 ヒストグラム内のすべての単位正方形は最大 1 つのドミノでカバーされ、各ドミノは垂直方向または水平方向に 2 つの隣接するセルを正確に占有します。 

タスクは、図内に重複せずにできるだけ多くのドミノを配置することです。 

形状をグリッド セルのセットとして考えると便利です。 カラム$i$細胞が含まれています$(i,1),(i,2),\dots,(i,a_i)$。 高さは増加しないため、各行は左端から始まる連続したセグメントを形成します。 

制約は大きいです。 まであるかもしれません$300\,000$列の高さはそれぞれ次のように大きくすることもできます。$300\,000$。 図の総面積はおよそ次の範囲に達します。$9 \times 10^{10}$したがって、セルを明示的に構築したり、図全体を反復したりするアルゴリズムは不可能です。 たとえ$O(n^2)$アルゴリズムには次のようなものが必要です$9 \times 10^{10}$最悪の場合の運用。 線形または線形に近いものが必要です$n$。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

単一の列を考えてみましょう。```
1
3
```この図には 3 つのセルが含まれています。 垂直ドミノは 1 つしか配置できないため、答えは次のようになります。```
1
```すべてのセルのペアが常に一致すると仮定したソリューションでは、誤った値が返されます。$\lfloor 3/2 \rfloor = 1$ここでは幸運に恵まれましたが、その推論は一般化できません。 

奇数の高さの 2 つの列を考えてみましょう。```
2
1 1
```答えは次のとおりです。```
1
```垂直方向の配置はありませんが、1 つの水平ドミノが唯一の列をカバーします。 垂直ペアのみをカウントするアプローチでは、0 が返されます。 

もう 1 つの興味深いケースは次のとおりです。```
2
3 3
```エリアは6なので、最大3つのドミノが可能です。 実際、6 つのセルすべてをタイル状に並べることができ、答え 3 が得られます。あらゆる場所で垂直ドミノを貪欲に使用する素朴なローカル戦略では、垂直ドミノは 2 つだけ配置され、一致しないセルが 2 つ残ります。 

主な困難は、奇数の高さの列が水平方向の配置を通じてどのように相互作用するかを理解することです。 

## アプローチ

 総当り的な観点は、すべてのセルをグリッド グラフの頂点とみなして、隣接するセルを接続することです。 すべてのドミノが 2 つの隣接するセルをカバーするため、グラフ内で最大の一致を見つけることが問題になります。 

この定式化は正しいです。 マッチングは、重複しないドミノのセットに正確に対応します。 残念ながら、グラフにはセルごとに 1 つの頂点が含まれています。 面積はこれくらい大きくてもよいので、$9 \times 10^{10}$、グラフを構築することは完全に不可能です。 

ヤング図の構造は、任意のグリッドよりもはるかに多くの情報を提供します。 まず、各列内にできるだけ多くの垂直ドミノを配置しましょう。 

高さのある柱$a_i$貢献する$\lfloor a_i/2 \rfloor$垂直ドミノ。 もし$a_i$が均一であれば、列全体がカバーされます。 もし$a_i$これは奇数であり、ちょうど 1 つのセルがカバーされていないままになります。 

唯一の問題は、これらの残った細胞はどうなるのかということです。 

奇数列の場合、カバーされていないセルは奇数行または偶数行のいずれかで選択できます。 たとえば、高さ 5 の列を垂直方向に並べて、行 1 をカバーしない、行 3 をカバーしない、または行 5 をカバーしないままにすることができます。 すべてのカバーされていないポジションは同じパリティを持ちます。 

次に、隣接する 2 つの奇数列を見てください。 残ったセルが同じ行に配置されると、1 つの水平ドミノが形成されます。 図は左寄せであるため、両方の列に存在する行は、それらの間のすべての列にも存在します。 したがって、奇数列の連続ブロックは、その残りを一度に 2 つずつペアにすることができます。 

重要なのはパリティだけです。 

させて$$S = \sum_i \left\lfloor \frac{a_i}{2} \right\rfloor$$垂直ドミノの数になります。 

各奇数列は 1 つの残りのセルに寄与します。 同じインデックスパリティを持つ連続した奇数列は、それらの残りをペアにすることができます。 単純なスキャンでは、奇数列ごとに 1 つの追加のドミノが作成されることがわかります。 

結果として得られる答えは、$$S + \sum \left\lfloor \frac{k}{2} \right\rfloor$$どこ$k$最大連続セグメント内の奇数列の数です。 

さらに単純な実装では、現在一致しない奇数列の数を維持します。

 ## アルゴリズムのチュートリアル

 1.初期化`answer = 0`。 
2.初期化`pending = 0`。 

ここ`pending`現在の連続セグメント内でまだペアになっていない奇数列の数を格納します。 
3. 列を左から右に処理します。 
4.追加`a[i] // 2`答えに。 

これは、列内に配置できるすべての垂直ドミノをカウントします。 
5. もし`a[i]`奇数です、増分します`pending`。 

奇数列は 1 つの残りのセルに影響します。 
6. もし`a[i]`偶数である場合は追加します`pending // 2`答えに戻ってリセットする`pending = 0`。 

偶数列はセグメントを分割します。 水平方向のペアは、奇数列の現在の最大ブロック内で完了する必要があります。 
7. すべての列を処理した後、次の値を追加します。`pending // 2`答えに。 

これは、奇数列の最後のブロックを処理します。 
8. 答えを出力します。 

### なぜ効果があるのか

 可能なすべての垂直ドミノを取得した後、すべての偶数高さの列が完全にカバーされ、すべての奇数高さの列がちょうど 1 つの残りのセルに寄与します。 これらの残りのセルは、追加のドミノに参加できる唯一のセルです。 

奇数列の最大連続セグメント内では、各列の残りのセルをセグメント内のすべての列が共有する行に配置できます。 残ったものをすべて 1 つの水平ドミノに結合できます。 を含むセグメント$k$奇数列は正確に結果を返します$\lfloor k/2 \rfloor$追加のドミノ。 

異なるセグメントは偶数列で区切られます。 このような列には残りのセルが含まれないため、水平方向のドミノは境界を越えることができません。 セグメントの寄与は独立しています。 

このアルゴリズムは、すべての垂直ドミノをカウントし、各奇数セグメントから取得できる最適な水平ペアの最大数を正確に追加します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    ans = 0
    pending = 0

    for x in a:
        ans += x // 2

        if x & 1:
            pending += 1
        else:
            ans += pending // 2
            pending = 0

    ans += pending // 2
    print(ans)

solve()
```最初の貢献は垂直配置によるものです。 すべての列が独立して貢献します`x // 2`ドミノ。 

変数`pending`奇数列の現在の最大ブロックのサイズを追跡します。 偶数列が現れるとそのブロックは終了するので、すぐに追加します。`pending // 2`水平ドミノを並べてカウンターをリセットします。 

配列が奇数列で終了する可能性があるため、ループ後の最後の加算が必要です。 この手順を忘れることが最も一般的なバグです。 

答えは図の領域のおよそ半分に達する可能性があり、32 ビット整数の制限を超える可能性があります。 Python の整数はこれを自動的に処理します。

 ## 特殊なケース

 可能な限り最小の図を考えてみましょう。```
1
1
```アルゴリズムは追加します`1 // 2 = 0`垂直ドミノ。 列が奇数なので、`pending = 1`。 スキャン後に追加されます`1 // 2 = 0`。 答えは 0 です。単一のセルではドミノを形成できないため、これは正解です。 

単一の奇数列を考えてみましょう。```
1
3
```アルゴリズムは追加します`3 // 2 = 1`垂直ドミノ。 残りのセルが 1 つ残るので、`pending = 1`。 最終的な貢献度は、`1 // 2 = 0`。 答えは 1 となり、これが最適です。 

偶数列で区切られた 2 つの奇数列を考えてみましょう。```
3
3 2 3
```中央の列を処理すると、アルゴリズムは最初の奇数セグメントを強制的に閉じます。 偶数列は残りを提供しないため、最初の残りのセルを最後のセルとペアにすることはできません。 計算は次のとおりです。```
vertical = 1 + 1 + 1 = 3
extra = 0 + 0 = 0
answer = 3
```これにより、セグメント境界を越えた無効な水平ペアリングが正しく防止されます。 

長い奇数セグメントを考えてみましょう。```
5
1 1 1 1 1
```垂直ドミノはありません。 セグメントには 5 つの奇数列が含まれているため、アルゴリズムは次の値を追加します。`5 // 2 = 2`水平ドミノ。 1 つのセルは覆われていないままです。 答えは 2 で、可能な最大のタイリングに一致します。
