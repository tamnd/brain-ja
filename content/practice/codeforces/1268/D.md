 ## 解決策

 ## 問題の理解

 頂点のすべてのペアの間に有向エッジが 1 つだけ存在する、完全な有向グラフが得られます。 これはトーナメントです。 構造は隣接行列によって完全に記述されるため、ペアごとにエッジがどの方向を向いているかがわかります。 

1 回の操作で頂点を選択し、それに付随するすべてのエッジを反転します。 すべての入力エッジは出力になり、すべての出力エッジは入力になります。 このような一連の操作により、新しいトーナメントが生成されます。 計算には操作の順序が重要ですが、最終的な効果に関しては、各頂点は奇数回反転されるか、まったく反転されません。 

タスクは、最小数の操作を使用してトーナメントを強接続の有向グラフに変換できるかどうかを判断することです。変換できる場合は、最短の操作シーケンスの数 (998244353 を法とする) でこれを達成できるかどうかを数えます。 

強く接続されたトーナメントとは、すべての頂点から他のすべての頂点への方向のあるパスがあることを意味します。 トーナメントでは、強力な接続の失敗は、パーツ間のすべてのエッジが一方向のみを指し、複数のコンポーネントを含む凝縮構造を生成する、自明ではない頂点の分割の存在に対応します。 

制約では最大 2000 個の頂点が許可されるため、立方体に近い、またはそれより劣る解は合格する可能性が低くなります。 すべての操作シーケンスをシミュレートしたり、頂点のすべてのサブセットをチェックしたりする単純なアプローチは、すぐには実行不可能です。なぜなら、可能なサブセットは 2^n 個あり、n! 個あるからです。 サブセットごとのシーケンス。 

トーナメントがすでに強く結びついている場合、微妙な特殊なケースが発生します。 その場合、ゼロ操作が最適であり、有効なシーケンスは 1 つだけ、つまり何もしないことだけです。 もう 1 つのエッジ ケースは、トーナメントが強く接続されていないが、単一の頂点を反転した後に強く接続される場合です。 有効な頂点の構造は非対称になる可能性があります。頂点を反転すると、そのすべての入射エッジが同時に変更され、非ローカルな方法でグローバルな到達可能性が壊れたり修正されたりする可能性があります。 

## アプローチ

 ブルート フォース ビューポイントは、各操作が頂点の選択に対応し、同じ頂点に対する繰り返し操作がペアでキャンセルされることに気づくことから始まります。 これは、最終状態は各頂点が選択された回数のパリティによってのみ決定されることを意味します。 したがって、シーケンスの代わりに、頂点のサブセットという観点から考えることができます。 

各サブセット S について、それらの頂点を 1 回正確に反転することによって結果のトーナメントを計算し、それが強く接続されているかどうかを確認できます。 最小の答えは、強力な接続を実現する最小サイズのサブセットであり、ウェイの数は、サブセット サイズの階乗と最適なサブセットの数の積である、それらの選択を実現するシーケンスの数です。 

ただし、固定サブセットの強力な接続を確認するにはすでに O(n²) のコストがかかり、サブセットは 2ⁿ と大きすぎます。 

重要な構造的洞察は、この問題が劇的に崩壊するということです。答えは 1 より大きくなることはありません。元のトーナメントがすでに強く接続されているか、または強く接続されるのに十分な反転をもつ単一の頂点が存在します。 複数の頂点の反転は、トーナメントで既にカバーされている単一の反転を超える根本的に新しい到達可能性パターンを作成しない一連のローカル反転として解釈できるため、最適性を高めることなく、より大きな反転のセットを減らすことができます。 

これにより、タスクが 2 つのチェックに減ります。最初のトーナメントが強く接続されているかどうか、そうでない場合は、反転した場合にどの単一の頂点が強く接続されるかです。 数は、そのような頂点がいくつ存在するかによって決まります。

 ## アルゴリズムのチュートリアル

 私たちは問題を、元のグラフと単一の頂点を反転することによって得られたグラフの強い接続性を評価することに集約します。 

### 1. 元のトーナメントが強く関連しているかどうかを確認する

 1 つの頂点から BFS または DFS を使用して標準の到達可能性テストを実行します。 すべての頂点が到達可能で、後方にも到達できる場合 (トーナメントでは SCC または逆到達可能性を介して確認できます)、グラフはすでに強く接続されています。 

これが当てはまる場合、答えはただちに一方向で操作がゼロになります。 

### 2. 1 つの頂点を反転した効果を特徴付ける

 頂点 v を反転すると、v に付随するすべてのエッジが反転します。v と異なる u、w のペアについては、それらの相対方向は変わりません。 v に接触するエッジのみが影響を受けます。 

これは、v を反転した後の到達可能性構造の唯一の変更は、v で開始または終了するパスに関係するローカルな変更だけであることを意味します。他のすべての構造的関係は同一のままです。 

したがって、v ごとに SCC を最初から再計算するのではなく、v が到達可能性パターンによって引き起こされる凝縮構造の分離点になるときに、v を反転した後の強力な接続が失敗することが観察されます。 

### 3. 各頂点を効率的にテストする

 BFS/DFS を使用して到達可能性情報を一度計算します。 次に、各頂点 v について、それを反転することで、以前に強力な接続をブロックしていたすべてのグローバル方向性制約が削除されるかどうかを判断します。 

具体的には、元のグラフ内のすべてのノードからの到達可能性を維持します。 これを使用して、v が元の凝縮のすべてのパーティションにわたって両方向を接続できる位置にあるかどうかを確認します。 これは、v が到達可能性階層内のグローバル ソースまたはシンクではないことを検証することになります。 

それぞれの有効な v は 1 つの最適解に寄与します。 

### 4. 答えを計算する

 機能する頂点がなく、グラフがまだ強く接続されていない場合は、-1 を出力します。 

それ以外の場合、最小操作は、すでに強く接続されている場合は 0、それ以外の場合は 1 です。ウェイの数は有効な頂点の数であり、それぞれが単一操作シーケンスに対応します。 

### なぜ効果があるのか

 重要な不変条件は、トーナメントでは、到達可能性の構造がグローバル順序制約によって完全に決定され、頂点を反転すると、他の頂点間に新たなペア間の非対称性が導入されることなく、そのインシデント エッジが反転されるだけであるということです。 これは、強力な接続に対するグローバルな障害を解消することに成功すると、複数の頂点フリップ構成を実質的に 1 つの重要な頂点フリップに減らすことができることを意味します。 したがって、最適解は最大でも 1 のサイズに折りたたまれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def kosaraju_scc(n, g, gr):
    sys.setrecursionlimit(10**7)
    vis = [False] * n
    order = []

    def dfs(v):
        vis[v] = True
        for to in g[v]:
            if not vis[to]:
                dfs(to)
        order.append(v)

    def dfs2(v):
        comp.append(v)
        vis[v] = True
        for to in gr[v]:
            if not vis[to]:
                dfs2(to)

    for i in range(n):
        if not vis[i]:
            dfs(i)

    vis = [False] * n
    comps = []

    for v in reversed(order):
        if not vis[v]:
            comp = []
            dfs2(v)
            comps.append(comp)

    return comps

def build_graph(mat, n):
    g = [[] for _ in range(n)]
    gr = [[] for _ in range(n)]
    for i in range(n):
        for j in range(n):
            if i == j:
                continue
            if mat[i][j] == '1':
                g[i].append(j)
                gr[j].append(i)
    return g, gr

def strong_connected(n, g, gr):
    comps = kosaraju_scc(n, g, gr)
    return len(comps) == 1

def main():
    n = int(input())
    mat = [input().strip() for _ in range(n)]

    g, gr = build_graph(mat, n)

    if strong_connected(n, g, gr):
        print(0, 1)
        return

    def flip_graph(v):
        fg = [[] for _ in range(n)]
        fgr = [[] for _ in range(n)]
        for i in range(n):
            for j in range(n):
                if i == j:
                    continue
                if i == v or j == v:
                    # flip edge
                    if mat[i][j] == '1':
                        # was i->j becomes j->i
                        fgr[i].append(j)
                        fg[j].append(i)
                    else:
                        fg[i].append(j)
                        fgr[j].append(i)
                else:
                    if mat[i][j] == '1':
                        fg[i].append(j)
                        fgr[j].append(i)
        return fg, fgr

    ans = 0
    for v in range(n):
        fg, fgr = flip_graph(v)
        if strong_connected(n, fg, fgr):
            ans += 1

    if ans == 0:
        print(-1)
    else:
        print(1, ans)

if __name__ == "__main__":
    main()
```実装では、最初に元のトーナメントの隣接リストを構築し、SCC 分解を使用してすでに強く接続されているかどうかを確認します。 そうである場合、ゼロの操作を返します。 

それ以外の場合は、すべての頂点を反復処理し、その頂点を反転することで得られるトーナメントを構築します。 このようなグラフごとに SCC を再計算して、強力な接続をテストします。 これは概念的には O(n³) ですが、隣接リストの単純さと早期拒否により、最適化された Python では厳密な仮定の下でのみ n が 2000 まで許容される境界線となります。

 ## 特殊なケース

 主なエッジケースは、トーナメントがすでに強く結びついている場合です。 たとえば、3 サイクル入力は、すべてのペア間の両方向の到達可能性を直ちに満たします。 このアルゴリズムは単一の SCC を検出し、一方向でゼロの操作を出力します。 

もう 1 つのエッジ ケースは、複数の頂点が有効な単一反転ソリューションである場合です。 推移的トーナメントでは、さまざまな内部頂点を反転するとすべてサイクルが生成され、アルゴリズムは反転によって強力な接続が復元された各頂点を正確にカウントします。 

最後のエッジケースは、単一の頂点では十分ではない場合です。 このような場合、トーナメント構造には、エッジの 1 つを反転しても破ることができない厳格なグローバル順序が含まれており、アルゴリズムは正しく -1 を出力します。
