 ## 解決策
 ## 問題の理解

 幅のあるL字型の廊下をご用意しております。`a`そして`b`2つの枝にあります。 固定長の長方形の棺`l`コーナーを通って移動する必要があります。 棺は平面内で自由にスライドしたり回転したりできますが、床から離れることはできないため、すべての中間位置は廊下の内側に留まらなければなりません。 

タスクは可能な最大の幅を計算することです`w`というサイズの長方形`l × w`ターンを通過できる。 

これは単純な軸合わせフィッティングの問題ではありません。 長い長方形は、角の周りを移動しながら回転することによって通過する可能性があります。 全体の難しさは、棺が廊下の壁にかろうじて接触する重要な方向を見つけることにあります。 

入力制限は数値的に小さく、最大で`10^4`、ただし、ジオメトリは連続的です。 探索できる有限の状態空間はありません。 粗い離散化ですべての角度を試すことは危険です。なぜなら、答えを得るには`1e-7`精度。 ソリューションは浮動小数点ジオメトリで動作し、確実に収束する必要があります。 

隠された主な問題は、棺によっては幅が非常に狭くても通過できないことです。 例えば：```
1 1 100
```長さの長方形`100`どんなに薄くしてもユニットの角で曲げることはできません。 正しい出力は次のとおりです。```
My poor head =(
```かどうかをチェックするだけの単純な実装`w ≤ min(a,b)`このケースを誤って受け入れることになります。 

廊下の幅が等しく、棺が短い場合には、別の微妙なケースが発生します。```
2 2 1
```答えは`1`、 ない`2`。 ステートメントでは次のことが保証されているため、棺の幅はそれ自体の長さを超えることはできません。`l ≥ w`。 この制限を忘れると、無効な回答が生成されます。 

より幾何学的なエッジケースは、正確な実現可能性の境界付近で発生します。 考慮する：```
1 2 2.5
```棺は非常に狭い幅しか通過できません。 比較が慎重に行われない場合、このしきい値付近で数値が不安定になると、誤検知が容易に発生します。 

## アプローチ

 ブルートフォースのアイデアは単純です。 候補の幅を固定する`w`、その後、多くの回転角度を試します`θ`。 角度ごとに、回転した長方形が角を曲がるときに 2 つの廊下の分岐の内側に同時に収まるかどうかを計算します。 

固定角度のジオメトリは管理しやすいです。 長方形を回転させると、`θ`、水平方向と垂直方向への投影によって、各ブランチで占めるスペースが決まります。 すべての幾何学的制約を満たす角度が存在する場合、棺は合格します。 

ブルートフォースの問題は精度です。 100 万の角度をスキャンし、幅を 60 回反復して二分探索するとします。 それはすでに大まかになります`6 × 10^7`幾何学的評価。 さらに悪いことに、最適な角度はサンプル値の間にある可能性があるため、角度の離散化は基本的に信頼できません。 

重要な観察は、固定幅の場合、必要なスペースを表す量は有効な角度間隔にわたって滑らかで単峰性であるということです。 これにより、三項検索が適用できるようになります。 

この問題の背後にある古典的な幾何学的事実は次のとおりです。長方形が直角の角を通って回転するとき、4 つの制限壁すべてに同時に接触すると、臨界状態が発生します。 斜めに`θ`、必要な長さの寄与は次のとおりです。$$\frac{a-w\cos\theta}{\sin\theta} + \frac{b-w\sin\theta}{\cos\theta}$$すべての有効な角度にわたるこの式の最小値が少なくとも`l`、その後、棺は通過できます。 

したがって、完全な解決策は次のようになります。 

1. 二分探索で答えを求める`w`。 
2. 各候補幅について、必要な長さの式を最小にする角度を三項探索します。 
3. 達成可能な最小必要長が少なくとも以下であるかどうかを確認します。`l`。 

ブルート フォースはすべての角度を明示的にスキャンします。 最適化されたソリューションは、滑らかさと凸状性を利用して、代わりに継続的に検索します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(B・A) | お(1) | 遅すぎて数値的に信頼性が低い |
 | 最適 | O(B・T) | お(1) | 承認済み |

 ここ、`B`は二分探索の反復回数であり、`T`三項検索の反復回数です。 

## アルゴリズムのチュートリアル

 1. まず自明な上限を処理します。 棺の幅は回廊の幅や棺自体の長さを超えることはできないため、答えは最大でも`min(a, b, l)`。 
2. 候補幅の実現可能性チェックを定義する`w`。 
3. 角度固定の場合`θ`、長方形が重要な壁に接触している間に収まる棺の最大の長さを計算します。$$f(\theta)= \frac{a-w\cos\theta}{\sin\theta} + \frac{b-w\sin\theta}{\cos\theta}$$この式は、長方形を 2 つのコリドー ブランチに分解することで得られます。 

1. 角度を制限する`(0, π/2)`。 この範囲外では、ジオメトリは対称か無効になります。 
2. 三項検索を使用します。`θ`最大化する`f(θ)`。 

ジオメトリが 1 つの制限壁構成から別の制限壁構成にスムーズに移行するため、この関数は単峰性です。 最適な回転方向は 1 つだけあります。 

1. 達成可能な最良の値が`f(θ)`少なくとも`l`、次に幅`w`実現可能です。 
2.幅の二分探索`w`。 ある幅が実現可能であれば、幅を大きくすることは難しくなり、決して容易ではないため、実現可能性は単調です。 
3. 十分な反復の後、二分探索の下限を出力します。 
4. 結果の幅が実質的にゼロの場合は、次のように出力します。`"My poor head =("`。 

### なぜ効果があるのか

 幅が固定されている場合、コーナーを通るあらゆる可能な動きは、ある回転角度に対応します。 制限構成は、まさに長方形がコリドーの境界にしっかりと接触するときです。 派生式は、その角度で通過できる長方形の最大長を計算します。 

三分探索では、この達成可能な長さを最大化する角度が見つかります。 最適な角度でも長さに対応できない場合`l`の場合、モーションは存在しません。 1 つの角度が機能すれば、棺はコーナーを通過し続けることができます。 

幅を増やしても利用可能な空き領域が縮小するだけなので、二分探索は正しいです。 一度不可能な幅になると、それ以上の幅も不可能になります。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    a, b, l = map(float, input().split())

    def best_length(w):
        lo = 1e-12
        hi = math.pi / 2 - 1e-12

        for _ in range(100):
            m1 = lo + (hi - lo) / 3
            m2 = hi - (hi - lo) / 3

            f1 = (
                (a - w * math.cos(m1)) / math.sin(m1)
                + (b - w * math.sin(m1)) / math.cos(m1)
            )

            f2 = (
                (a - w * math.cos(m2)) / math.sin(m2)
                + (b - w * math.sin(m2)) / math.cos(m2)
            )

            if f1 < f2:
                lo = m1
            else:
                hi = m2

        theta = (lo + hi) / 2

        return (
            (a - w * math.cos(theta)) / math.sin(theta)
            + (b - w * math.sin(theta)) / math.cos(theta)
        )

    def can(w):
        return best_length(w) + 1e-10 >= l

    lo = 0.0
    hi = min(a, b, l)

    for _ in range(100):
        mid = (lo + hi) / 2

        if can(mid):
            lo = mid
        else:
            hi = mid

    if lo < 1e-8:
        print("My poor head =(")
    else:
        print("{:.10f}".format(lo))

solve()
```外部二分探索では、実現可能な最大幅が計算されます。 検索間隔はゼロから始まり、廊下の幅と棺の長さのうちの最小の物理的制限で終了します。 

内部三分探索により、回転角度全体が最適化されます。 使用する`0`または`π/2`直接実行するとゼロ除算が発生するため、実装では境界からの小さなオフセットが使用されます。 

最適化される関数は、接触壁構成から導出される幾何学的表現です。 値が大きいほど、廊下がその幅と角度でより長い棺を収容できることを意味します。 

三項検索内の比較は簡単に逆戻りできます。 実現可能な最大の長さを生み出す角度が必要なので、検索では関数値が大きい側が維持されます。 

イプシロン`can()`正確な境界付近での精度の低下を回避します。 これがないと、浮動小数点の丸めにより、実行可能な幅が誤って拒否される可能性があります。 

最終チェック`1e-8`ステートメントで要求される特殊な不可能なケースを処理します。
