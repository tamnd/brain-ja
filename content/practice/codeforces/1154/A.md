 ## 解決策
 ## 問題の理解

 未知の正の整数の 3 つのペアごとの合計を表す 4 つの数値が与えられます。$a$、$b$、$c$そして 3 つの数値すべての合計。 これら 4 つの数字に順序はありません。 私たちのタスクは、元の 3 つの整数を再構築することです。$a$、$b$、$c$これらの合計から。 

入力により、解決策が存在することが保証され、実現可能性を検証する必要がないため、タスクが簡素化されます。 ボード上の各数字は少なくとも 2、最大で 2 つです。$10^9$これは、入力サイズが小さい (数値が 4 つだけ) ものの、潜在的に非常に大きな整数を扱っていることを意味します。 数値が 4 つしかないため、時間計算量が一定または線形の任意のアルゴリズムが受け入れられます。 

考慮すべきエッジ ケースには、次のような状況が含まれます。$a$、$b$、 そして$c$等しいです。 たとえば、次の場合$a = b = c = 1$、ボード上の 4 つの数字は次のようになります。$2, 2, 2, 3$。 すべての合計が異なるものであると仮定する単純なアプローチは、ここでは失敗する可能性があります。 もう 1 つのケースは、2 つの数値が等しい場合です。$a = b = 2, c = 3$、合計を生成します$4, 5, 5, 7$。 3 つの数値すべての合計を認識し、それをペアごとの合計から分離することが重要です。 

## アプローチ

 ブルートフォースアプローチでは、4 つの数値の役割への割り当てをすべてチェックしようとします。$a+b$、$a+c$、$b+c$、 そして$a+b+c$。 あるのは$4! = 24$順列は小さいため、純粋な総当たり攻撃が機能します。 順列ごとに、小さな線形方程式系を解き、すべての結果が正の整数であるかどうかを確認できます。 このアプローチは数値が 4 つしかないため機能しますが、必要以上に複雑で直感的ではありません。 

重要な観察は、3 つの数値すべての合計が$a+b+c$は 3 つの正の整数がすべて含まれるため、常に 4 つの中で最大の数になります。 最大の数を特定したら、$a+b+c$、残りの 3 つの数値はペアごとの合計でなければなりません。 最大の数を次のように表します$S = a+b+c$他の数字は次のようになります$x, y, z$。 その後、元の数値を直接解くことができます。 

-$a = S - (b+c) = S - x$-$b = S - (a+c) = S - y$-$c = S - (a+b) = S - z$これは順序に関係なく機能します。$x, y, z$すべてのペアごとの合計を表します。 このアルゴリズムは、ソート、最大値の特定、および単純な減算に集約されます。 これはシンプルかつ直接的であり、不必要な列挙を避けます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(24) = O(1) | お(1) | 動作するが不要 |
 | 最適 | O(4 log 4) = O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 4 つの整数をリストに読み取ります。 これにより、任意の順序で提供された合計が取得されます。 
2. リストを昇順に並べ替えます。 並べ替えると、最大の数値を簡単に特定できるようになります。$a+b+c$3 つの整数がすべて正であるためです。 
3. ソートされたリストの最後の番号を次のようにします。$S = a+b+c$。 ソートされたリストの最初の 3 つの数値を次のようにします。$x, y, z$。 これらはペアごとの合計に対応しますが、どれがどれであるかを知る必要はありません。 
4. から各ペアの合計を減算して、元の数値を計算します。$S$:

 -$a = S - x$-$b = S - y$-$c = S - z$これらの計算が機能する理由は、$S - x$1 つを除くすべての整数を含む合計を削除し、残りの整数を残します。 
5. 印刷$a$、$b$、 そして$c$任意の順序で。 

機能する理由: 私たちが特定する並べ替えの保証$a+b+c$最大の数として。 3 つすべての合計から残りの各数値を減算すると、個々の整数が分離されます。 正の整数による解が保証されているため、曖昧さはなく、演算により元の数値が正しく再構築されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

nums = list(map(int, input().split()))
nums.sort()
S = nums[3]
a = S - nums[0]
b = S - nums[1]
c = S - nums[2]
print(a, b, c)
```このソリューションは入力を効率的に読み取り、4 つの数値を並べ替え、合計として最大のものを特定し、減算を使用して個々の数値を再構築します。 並べ替えにより、一貫した識別が保証されます$a+b+c$どの合計に 3 つの数値がすべて含まれているかを手動で確認する必要はありません。 この問題では出力で任意の順序が許可されるため、減算順序は柔軟です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    nums = list(map(int, input().split()))
    nums.sort()
    S = nums[3]
    a = S - nums[0]
    b = S - nums[1]
    c = S - nums[2]
    return f"{a} {b} {c}"

# Provided sample
assert run("3 6 5 4\n") in ["3 2 1", "2 3 1", "1 2 3"], "sample 1"

# Custom cases
assert run("2 2 2 3\n") == "1 1 1", "all equal case"
assert run("4 5 5 7\n") in ["3 2 2", "2 3 2", "2 2 3"], "two equal numbers"
assert run("10 11 15 21\n") in ["11 6 10", "10 11 6", "6 10 11"], "general case"
assert run("1000000000 1000000000 1000000000 3000000000\n") == "1000000000 1000000000 1000000000", "max values"
```| テスト入力 | 期待される出力 | 検証内容 |

 | 2 2 2 3 | 1 1 1 | すべて等しい数値 |
 | 4 5 5 7 | 3 2 2 | 2 つの等しい数 |
