 ## 解決策
 ## 問題の理解

 Polycarp さんは毎週の食事スケジュールが厳格な猫を飼っています。 猫は月曜日、木曜日、日曜日に魚の餌を食べます。 火曜日と土曜日はウサギのシチュー。 水曜日と金曜日にはチキンステークスがあります。 Polycarp は旅行に行きたいと考えており、食料の種類ごとに一定数の食料を詰め込みます。`a`魚にとって、`b`ウサギ用と、`c`鶏肉用。 目標は、猫が可能な限り連続してどのような種類の餌も切らさずに食べることができるような旅行の開始日を選択することです。 

入力は、利用可能な配給量を表す 3 つの整数で構成されます。 出力は単一の整数、つまり最適な曜日から開始して猫に餌を与えることができる最大日数です。 

境界は非常に大きく、最大で`7*10^8`食べ物の種類ごとに。 これは、どのソリューションでも、場合によっては数億日にわたって毎日個別にシミュレーションすることを回避する必要があることを示しています。 代わりに、週ごとのパターンを活用して、個別の日ではなく、まとまった単位で推論する必要があります。 

単純なアプローチは、ある種類の食品が他の種類よりも早くなくなったり、開始日によって消費順序が変わったりするような特殊なケースでは失敗する可能性があります。 たとえば、猫がウサギのシチューを 1 回しか食べず、火曜日から始めた場合、ウサギのシチューはすぐになくなり、水曜日から始めた場合とは異なる結果になります。 別の特殊なケースは、ある種類の食品が豊富にあるのに、別の種類の食品がほとんどない場合に発生します。 週ごとのパターンを無視した不用意なアプローチは、日数を過大評価する可能性があります。 

## アプローチ

 強引なアプローチは簡単です。考えられる平日から始めて猫の毎日の摂取量をシミュレートし、餌が何日続くかを数えます。 これは正しいですが、次の場合は遅すぎます。`a`、`b`、`c`反復回数が数億回に達する可能性があるため、この値は大きくなります。 

重要な観察は、猫の食事が毎週繰り返されるということです。 丸一週間で、猫は魚を 3 回、ウサギを 2 回、鶏肉を 2 回食べます。 これにより、丸一週間を一度に減算することができます。 具体的には、猫が生存できる最大週数は、次の最小値によって制限されます。`a//3`、`b//2`、 そして`c//2`。 完全な週の最大数が削除されると、残りの配給量のみを最大 7 日間、週の開始日ごとに 1 つずつシミュレートする必要があります。 これにより、問題は潜在的に 7 億回の反復から管理可能な一定のシミュレーションに減ります。 

最適な解決策は、丸 1 週間の整数除算と残りの小さなスライド シミュレーションを組み合わせたものです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(a + b + c) | お(1) | 遅すぎる |
 | 最適 | お(7) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 週の摂取量を決定します。猫は週に 3 匹の魚、2 匹のウサギ、2 匹の鶏肉を食べます。 猫が丸々生存できる最大週数を計算します。`full_weeks = min(a//3, b//2, c//2)`。 これらの配給量を差し引きます。`a -= 3*full_weeks`、`b -= 2*full_weeks`、`c -= 2*full_weeks`。 
2. 週ごとの食品の​​順序を表す配列を作成します。`[fish, rabbit, chicken, fish, chicken, rabbit, fish]`日曜日から土曜日までの日に対応します。 
3. 可能な開始日ごとに`i`0 から 6 まで、残りの配給量を使用して 1 日ごとの消費量をシミュレートします。 猫がその日に必要な餌を食べられない場合、シミュレーションを停止します。 この開始日に食べた連続日数を追跡します。 
4.追加`7 * full_weeks`シミュレーションから得られた連続日数の最大値まで。 これは、猫が食べ物を切らさずに食べることができる合計最大日数を示します。 

**効果がある理由**: 不変条件は、週ごとのパターンが固定されており、すべての種類の食品が既知の量で消費されるため、常に丸一週間を差し引くことができるということです。 これより長いシーケンスは 1 週間をラップし、さらに丸 1 週間かけて処理できるため、残りのシミュレーションは 7 日間だけをカバーする必要があります。 これにより、可能な限り連続した日数が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

food_order = [0, 1, 2, 0, 2, 1, 0]  # 0: fish, 1: rabbit, 2: chicken

def main():
    a, b, c = map(int, input().split())
    
    # full weeks
    full_weeks = min(a // 3, b // 2, c // 2)
    a -= 3 * full_weeks
    b -= 2 * full_weeks
    c -= 2 * full_weeks

    max_days = 0
    for start in range(7):
        x, y, z = a, b, c
        days = 0
        idx = start
        while True:
            food_type = food_order[idx % 7]
            if food_type == 0 and x > 0:
                x -= 1
            elif food_type == 1 and y > 0:
                y -= 1
            elif food_type == 2 and z > 0:
                z -= 1
            else:
                break
            days += 1
            idx += 1
        max_days = max(max_days, days)
    
    print(max_days + 7 * full_weeks)

if __name__ == "__main__":
    main()
```コードはまず、猫に餌を与えることができる完全な週数を計算し、それらの配給量を差し引きます。 次に、各開始日を最大 7 日間シミュレートして、さらに何日カバーできるかを確認します。 突然変異を避けるために、各シミュレーションの残りの配給量をコピーするには細心の注意が必要です。 モジュロ 7 を使用すると、週を正しく折り返します。

 ## 特殊なケース

 いずれかの食品タイプに最初の配給量がゼロの場合、その食品が必要な日にシミュレーションはすぐに停止します。 例えば、`a=0, b=2, c=2`:

 - 日曜日開始: 初日は魚が必要ですが、`a=0`、シミュレーションは 0 で停止します。 
- 水曜日から開始: 鶏が食べられ、次にウサギが食べられ、魚はこれらの日以降にのみ必要になります。 連続する最大日数は 2 で、これは出力と一致します。 

このアルゴリズムはすべての開始日を処理し、無効な消費が発生しないことを保証し、極端な場合でも正確さを確認します。
