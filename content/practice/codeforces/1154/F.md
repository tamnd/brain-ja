 ## 解決策
 ## 問題の理解

 とのお店があります`n`シャベルにはそれぞれ特定の価格が付いています。 ミーシャは正確に購入したいと考えています`k`シャベル、おそらく複数購入。 おもしろいのは、その店が特別セールを提供しているということです。`x_j`一度の購入でシャベルを`y_j`それらのシャベルの中で最も安いものは無料です。 各オファーは何度でも使用できますが、1 回の購入に適用できるオファーは 1 つだけです。 目標は、ミーシャが支払う総額を最小限に抑えることです。 

制約の観点から見ると、`n`そして`m`200,000 まで大きくなる可能性がありますが、`k`これは非常に重要です。一方、`O(n*k)`または`O(n^2)`すべてのシャベルに直接アルゴリズムを適用することで、`k`必要以上に高価なシャベルを購入することは決して最適ではないため、最も安価なシャベルを購入する必要があります。 これにより、有効な問題サイズが次のように縮小されます。`k`シャベルは、動的プログラミングのアプローチを可能にするのに十分小さい。 

エッジケースには、すべてのオファーでミーシャが望むよりも多くのシャベルを購入する必要があるシナリオ、またはオファーで無料のシャベルがゼロであるシナリオが含まれます。 単純なアプローチでは、安価なシャベルが残っているときに高価なシャベルを購入することが決して最適ではないことを考慮せずに、リスト全体を並べ替えてオファーを適用しようとする可能性があり、総コストが膨らむ可能性があります。 

## アプローチ

 ブルートフォース ソリューションでは、シャベルのサブセットを選択し、考えられるすべてのオファーを適用し、各構成のコストを追跡するためのすべての方法を列挙します。 これには、`2^k`シャベルのサブセット。`k = 20`。 ブルートフォースはあらゆる組み合わせを考慮するため、原理的には正しいですが、指数関数的に遅くなります。 

重要な洞察は、シャベルの順序は価格によってのみ重要であるということです。 価格の上昇順にシャベルを分類すると、最適な購入には残りの最も安価なシャベルが使用されます。 分類したら、問題を 1 次元の動的計画問題としてモデル化できます。`dp[i]`最初の購入にかかる最低コストを表します`i`最安のシャベル。 それぞれについて`i`、最後に購入したサイズを決定できます`j`正確にオファーがあるかどうかを確認してください`j`シャベル。 ある場合は、最も高価なもののみを支払います`j - y_j`シャベル。 有効なすべてを反復処理することにより、`j`、更新します`dp[i]`最小コストを求めます。 

これにより、潜在的な組み合わせの問題が次のような問題に縮小されます。`O(k * m)`DP、これは実現可能です。`k ≤ 2000`そして`m ≤ 2e5`。 価格を並べ替えると追加されます`O(n log n)`、しかし必要なのは`k`最も安い、私たちはそれらを選択することができます`O(n + k log k)`部分ソートあり。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^k * m) | O(k) | 遅すぎる |
 | 最適なDP | O(k * m) + O(n log n) | O(k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. まず、すべてのシャベルの価格を昇順に並べ替えます。 のみ`k`これ以上高価なシャベルを購入してもコストは最小限に抑えられないため、最も安価なシャベルが適切です。 
2. オファーを前処理します。 複数のオファーが同じである可能性があるため、`x_j`でも違う`y_j`、購入サイズごとに`x`、最大値を保持します`y`オファーの中には。 これにより、特定の購入サイズに対して、常に可能な限り最高の割引が得られるようになります。 
3. DP 配列を初期化する`dp`サイズの`k+1`、 どこ`dp[i]`最初の購入にかかる最低コストを表します`i`シャベル。 セット`dp[0] = 0`ゼロのシャベルを購入しても費用はかからないからです。 
4. 反復処理する`i`1から`k`。 それぞれについて`i`、考えられるすべての購入サイズを考慮してください`j`1から`i`。 それぞれについて`j`、最後の購入にかかる実効コストを計算します。`j`シャベル。 サイズのオファーがある場合`j`のコストを差し引きます。`y`このブロックで最も安いシャベル。常に最初に表示されます。`y`このうち`j`仕分けによるシャベル。 アップデート`dp[i]`現在の値の最小値として、および`dp[i-j] + cost_of_last_j`。 
5. DP アレイを埋めた後、`dp[k]`正確に購入するための最小総コストを保持します`k`シャベル。 

これは、ソートされた順序が不変であるため機能します。つまり、常に最も安い残りのシャベルを選択するため、この順序に従わない購入の組み合わせは最適化できません。 動的プログラミングにより、最初のパーティションを分割するためのあらゆる方法が考慮されます。`i`有益なオファーを利用して、有効な購入を検討します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, m, k = map(int, input().split())
    prices = list(map(int, input().split()))
    prices.sort()
    prices = prices[:k]

    offer = [0] * (k + 1)
    for _ in range(m):
        x, y = map(int, input().split())
        if x <= k:
            offer[x] = max(offer[x], y)

    prefix_sum = [0] * (k + 1)
    for i in range(k):
        prefix_sum[i+1] = prefix_sum[i] + prices[i]

    INF = 10**18
    dp = [INF] * (k + 1)
    dp[0] = 0

    for i in range(1, k + 1):
        for j in range(1, i + 1):
            free = offer[j]
            cost = prefix_sum[i] - prefix_sum[i - j + free]
            dp[i] = min(dp[i], dp[i - j] + cost)

    print(dp[k])

if __name__ == "__main__":
    main()
```このソリューションでは、接頭語の合計により、シャベルのコストの連続ブロックを効率的に計算できます。 配列`offer`購入サイズごとに最高の割引を保存します。 すべてのパーティション サイズをループします`j`のために`i`シャベルを作成し、対応するオファーを適用して最小コストを動的に計算します。
