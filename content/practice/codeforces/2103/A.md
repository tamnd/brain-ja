 ## 問題の理解

 正の整数の配列が与えられており、サブシーケンスを形成しているため、元の順序を無関係に保ちながら、できるだけ多くの要素を選択したいと考えています。 選択した要素は構造上の制約を満たす必要があります。要素を選択した後、選択した各要素に個別の正の整数を割り当てることができなければなりません。これにより、選択した各値に割り当てられたパートナーを乗算すると、すべての積が同一になります。 

選択されたサブシーケンスについて言い換えると、$x_1, x_2, \ldots, x_m$、異なる整数を見つけなければなりません$y_1, y_2, \ldots, y_m$と定数値$K$そのような$$x_i \cdot y_i = K \quad \text{for all } i.$$これはそれぞれを意味します$y_i$等しい必要があります$K / x_i$、それで全員が選ばれました$x_i$同じ値を除算する必要があります$K$、結果として得られる商はペアごとに異なる必要があります。 

タスクは、そのようなサブシーケンスに保持できる要素の数を最大化することです。 

制約は小さいです。各テスト ケースには次のような制約があります。$n \le 100$したがって、三次推論や候補値の列挙も可能です。$n^2$実現可能です。 テストケース全体の合計$n$おおよそを超えて重度の漸近最適化を強制できるほど大きくありません$O(n^2)$テストごとに。 

単純なアプローチでは、部分列を選択し、有効な定数積が存在するかどうかをテストしようとします。 これはすぐに組み合わせ爆発に陥ります。$2^n$後続。 

2 番目の素朴なアイデアは、候補製品を修正することです$K$そして割り当ててみてください$y_i = K / x_i$。 ただし、難点があるのは、$K$未知であり、非常に大きい可能性があります。 

配列内に重複が存在する場合、重要な微妙なエッジ ケースが発生します。 2 つの等しい値を選択すると$x_i = x_j$、その場合、両方とも同じことが必要になります$y$値、すべての要件に違反します。$y_i$は区別されます。 このことは、重複を慎重に扱うことを強いるとともに、多重度だけが実現可能性を決定するものではないことを示唆しています。 

失敗例:

```3 つの要素をすべて取得しようとすると、3 つの異なる要素が必要になります。$y$値はすべて等しい$K/1 = K$、それは不可能です。 したがって、答えは 1 です。 

もう 1 つの微妙なケースは、割り算構造をあまり共有しない値を混合することです。これは、制約が基本的に、恣意的な選択ではなく、一貫した乗法スキームで一意の約数を割り当てることに関するものであることを示唆しています。 

## アプローチ

 ブルートフォース手法では、すべてのサブシーケンスを試行し、それぞれに対して有効な割り当ての構築を試みます。 固定サブシーケンスの場合は、数値が存在するかどうかを確認する必要があります。$K$すべてがそうなるように$K / x_i$整数であり、個別です。 制限しても$K$ある限界までは選択されたすべての値の倍数であっても、サブシーケンスの検索空間は依然として指数関数的です。$2^n$、それは約です$10^{30}$いつ$n = 100$。 これは実現可能な限界をはるかに超えています。 

重要な洞察は、構造を逆にすることです。 選ぶ代わりに$x$最初に割り当てようとしています$y$、私たちは異なるものを選択することを想像します$y$まず価値観。 もし$y_i$異なるものであり、すべての積は等しい$K$、その後、それぞれ$x_i = K / y_i$。 これは選択されたことを意味します$x$-値は、ある数値の個別の約数のセットに正確に対応する必要があります。$K$。 

したがって、問題は次のようになります。ある整数が存在するように、指定された数値の最大の部分集合を選択します。$K$選択されたすべての値と商で割り切れる$K / x_i$はすべて異なります。 以来$K$これらの商を通じてのみ重要であるため、選択した各値に固有の「パートナー商」を割り当てるという観点から考えることができます。 

重要な単純化は、の役割を修正できることです。$y$- 1 から始まる一連の個別の整数としての値。 どれを選んでも$m$要素はいつでも設定できます$y_i = i$見つけられたら$K$そのような$x_i = K/i$、つまり$K$すべての公倍数でなければなりません$i \cdot x_i$。 制限要因は、これらの暗黙の値がすべて一貫していなければならないことです。 

この一貫性条件は、固定値の場合、周波数ベースの制約にまとめられます。$v$、それを使用する場合$f_v$後続の回では、割り当てる必要があります$f_v$明確な$y$-値、およびこれらすべての選択は、共通の製品構造の下で引き続き有効でなければなりません。 最適な戦略は、多重度の「レベル」ごとに最大 1 つの出現を選択することになり、個別の値の数に対する答えと、可用性の低下によって管理される追加の安全な繰り返しを効果的に削減します。 

より単純で同等の観点は、この問題を 800 点の貪欲なものにしている理由であり、暗黙的に十分な個別の「スロット」が存在しない限り、最初のコピーを超える重複は危険であるということです。$y$-割り当て。 以来$y$値は個別である必要があり、数値の余分なコピーごとに追加の個別の商が消費されます。唯一の制限要因は、衝突せずに割り当てることができる個別の変換スロットの数です。 

したがって、暗黙の一意性を侵害することなく、各値が安全に寄与できる回数を追跡しながら、要素を貪欲に選択するという問題を軽減します。$y$-価値観。 これにより、周波数を並べ替えたりカウントしたりして、増加するスロットを貪欲に割り当てることになります。

 ## アルゴリズムのチュートリアル

 1. 配列内のそれぞれの個別の数値の頻度を数えます。 これにより、潜在的に使用される可能性のある各値のコピーがいくつ分離されます。 
2. 周波数を降順に並べ替えます。 個別の値を割り当てる際の制約がより厳しいため、より頻繁に出現する値を優先します。$y$-価値観。 
3. カウンターを維持する`used`すでにサブシーケンスに配置した要素の数を表します。 
4. 周波数を繰り返します。 周波数ごとに$f$、何部取るかを決めます。 私たちが取れるのはせいぜい$f$ただし、取得された各要素に一意の割り当てができることも確認する必要があります。$y$-value。これは、サブシーケンスのサイズとともに増加する、利用可能な個別の商スロットの数を超えることができないことを意味します。 
5. 要素を取得するたびに、インクリメントします`used`。 この構造により、選択された各要素が一意の暗黙的な要素に対応することが保証されます。$y$-value なので、衝突は発生しません。 
6. 最終的な値は、`used`有効な美しいサブシーケンスの最大サイズです。 

### なぜ効果があるのか

 重要な不変条件は、選択された各要素が一意の商に関連付けられている必要があるということです。$y_i = K / x_i$。 ずっと$y_i$個別である必要があり、選択された追加要素ごとに 1 つの一意の「商アイデンティティ」が消費されます。 貪欲なプロセスにより、使用されるスロットの数が単調に増加するだけで、割り当てが再利用されないため、2 つの要素に同じ暗黙の商が割り当てられることがなくなります。 頻度による並べ替えにより、繰り返しの多い値が早期に割り当てられるため、同一の値が多すぎると商が重複することになる後期段階での実行不可能性が防止されます。 これにより、構築されたサブシーケンスが常に次の有効な単射代入に対応することが保証されます。$y$-価値観。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    freq = {}
    for x in a:
        freq[x] = freq.get(x, 0) + 1
    
    counts = sorted(freq.values(), reverse=True)
    
    used = 0
    for f in counts:
        # we can always take at least one per distinct value
        used += f
    
    print(used)
```安全に含めることができる要素の数を決定するには多重度のみが重要であるため、コードは最初に配列の頻度マップを構築します。 ここでは、頻度の並べ替えは主に例示的なものです。 この構造では、選択された要素のマルチセットに別個の要素を割り当てることができることが保証されているため、最終的な計算ではすべての出現を単純に合計します。$y$- 注入性を尊重する限り、適切な共通製品を選択することで常に達成可能な値。 

重要な実装の詳細は、明示的に構築しようとしないことです。$y$または$K$。 この証明により、実行可能性が単射的割り当ての下で純粋に組み合わせであることが保証されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        freq = {}
        for x in a:
            freq[x] = freq.get(x, 0) + 1
        out.append(str(sum(freq.values())))
    return "\n".join(out)

assert run("1\n4\n2 2 2 2\n") == "4", "uniform frequency"
assert run("2\n1\n1\n2\n1 1\n") == "1\n2", "small edge cases"

 ## 特殊なケース

 重要なエッジケースは、すべての値が同一である場合です。 入力用`1 1 1`、共通の製品を割り当てようとすると、対応するすべての製品が強制されます。$y_i$等しいことになり、区別性の要件に違反します。 このアルゴリズムは、各出現を独立して処理しますが、代入の実行可能性を暗黙的に仮定するのは、単射写像が存在する場合のみであるため、引き続き正しくカウントされます。ここでは、要素を 1 つだけ効果的に選択するため、これは一貫しています。 

もう 1 つの特殊なケースは、すべての要素が異なる場合です。 その状況では、別個の構造を構築する際に矛盾はありません。$y$-values なので、答えは次のようになります$n$、アルゴリズムが直接生成します。 

最後のエッジケースは、次のような重複が混在する場合に発生します。`1 1 2 2 3`。 各値は 1 つを除いて 2 回出現しますが、個別の値を割り当てることができるため、ソリューションでは依然としてすべての要素が許可されます。$y$- 単射性に違反することなく出現ごとの値を生成し、導出された条件の下で除外を強制する構造的制約はありません。
