 ## 解決策
 ## 問題の理解

 私たちは、単純な置換暗号によって暗号化されたメッセージを解読するように求められます。 元のメッセージの各文字は固定文字に置き換えられるため、マッピングは 1 対 1 になります。異なる文字は異なる文字にマッピングされ、同じ文字は常に同じ文字にマッピングされます。 マリア・イワノフナは暗号文を持っており、試験の正しい答えを知っていますが、サーシャの実際の答えは知りません。 目標は、サーシャの解読された答えが正しい答えと一致する位置の数を最大化する方法で、暗号化された文字から考えられる答えへのマッピングを選択することです。 

入力はメッセージの長さで構成されます$N$(最大 200 万) と可能な回答の数$K$(最大 52)、長さの暗号文文字列$N$、および長さの正解の文字列$N$。 出力は 2 つあります。達成できる正解の最大数と、ある長さの文字列です。$K$暗号文字 (「a」で始まる) から応答文字へのマッピングを指定します。 

大きな制限は、$N$マッピングのすべての順列を反復する単純なアプローチは除外されます。$K!$工場で成長するため、たとえ小規模であっても実行不可能です$K$。 また、線形または線形に近い処理を保証する必要もあります。$N$余分なオーバーヘッドを発生させることなくすべての文字を処理します。 エッジケースには、複数の暗号文字が同じ答えにマップされるシナリオ、または特定の文字が 1 回しか出現しないシナリオが含まれます。 不用意に貪欲なアプローチを行うと、誤って同じ答えに複数の暗号文字が割り当てられる可能性があり、これは無効です。 たとえば、暗号が「aa」で正解が「ab」の場合、両方の「a」を「b」に単純に貪欲に割り当てると、1 対 1 のマッピング ルールに違反します。 

## アプローチ

 ブルートフォース手法では、暗号文字から応答文字へのマッピングのすべての順列を試み、デコードされたメッセージが正解と一致する位置の数を数え、最大値を取得します。 このアプローチは、考えられるすべてのマッピングを徹底的にチェックするため正しいですが、その複雑さは次のとおりです。$O(K! \cdot N)$、これは偶数にとっても天文学的に大きいです$K=10$。 これは明らかに実行不可能です$N$200万まで。 

重要な観察は、この問題が最大重みの 2 部マッチング問題に帰着できるということです。 暗号文字は一方のノードとして、応答文字はもう一方のノードとして考えてください。 暗号文字ごとに$c$そして返事の手紙$a$、暗号文が存在する位置の数を計算できます。$c$そして正しい答えは$a$。 この数はマッピングの「重み」として機能します。$c$に$a$。 次に、問題は、これらの重みの合計を最大化する、暗号文字と答えの 1 対 1 の割り当てを見つけることになります。 これは 2 部グラフでの古典的な最大重みマッチングであり、ハンガリーのアルゴリズムを使用して効率的に解決できます。 以来$K \le 52$、$O(K^3)$マッチングの解決策は許容されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(K! \cdot N)$|$O(K^2)$| 遅すぎる |
 | 最大重みの 2 部マッチング |$O(K^3 + N)$|$O(K^2)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2D 配列を初期化する`weight[c][a]`すべての暗号文字について`c`(0 ～ K-1) およびすべての回答文字`a`(0 ～ K-1)。 この配列には、メッセージ内の暗号文が含まれる位置の数が格納されます。`c`そして正解`a`。 すべてのポジションをループします`i`0 から N-1 までおよび増分`weight[c][a]`どこ`c`のインデックスです`cipher[i]`そして`a`のインデックスです`answer[i]`。 
2. アレイを処理する`weight`ノードの一方のセットが暗号文字を表し、もう一方のセットが回答文字を表す二部グラフとして、エッジの重みは上記で計算されたカウントによって与えられます。 
3. ハンガリーのアルゴリズム (Kuhn-Munkres) を適用して、この KxK 2 部グラフで完全に一致する最大重みを見つけます。 これにより、一致の総数を最大化する暗号文字から答えへのマッピングが得られます。 
4. 合計して一致の総数を計算します。`weight[c][a]`割り当てられたすべてのペアにわたって`(c, a)`マッチングから。 
5. 各暗号文字に対応する応答文字を順番に配置して、暗号マッピング文字列を構築します。 この文字列は出力の 2 行目です。 

**機能する理由:** アルゴリズムの各ステップで、重み配列は、暗号文字を解答文字にマッピングすることによって得られた正解の数を正確にカウントします。 ハンガリーのアルゴリズムは、選択された重みの合計が 1 対 1 の割り当てで最大になることを保証します。 マッピングは完全 (1 対 1) で重みの合計が最大化されるため、アルゴリズムは可能な最大数の正解を生成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    N, K = map(int, input().split())
    cipher = input().strip()
    correct = input().strip()

    # Initialize weight matrix
    weight = [[0] * K for _ in range(K)]
    
    def idx(ch):
        if 'a' <= ch <= 'z':
            return ord(ch) - ord('a')
        return ord(ch) - ord('A') + 26

    for c_char, a_char in zip(cipher, correct):
        c = idx(c_char)
        a = idx(a_char)
        weight[c][a] += 1

    # Hungarian Algorithm for maximum weight matching
    u = [0] * (K+1)
    v = [0] * (K+1)
    p = [0] * (K+1)
    way = [0] * (K+1)

    for i in range(1, K+1):
        p[0] = i
        minv = [float('inf')] * (K+1)
        used = [False] * (K+1)
        j0 = 0
        while True:
            used[j0] = True
            i0 = p[j0]
            delta = float('inf')
            j1 = 0
            for j in range(1, K+1):
                if not used[j]:
                    cur = -(weight[i0-1][j-1]) - u[i0] - v[j]
                    if cur < minv[j]:
                        minv[j] = cur
                        way[j] = j0
                    if minv[j] < delta:
                        delta = minv[j]
                        j1 = j
            for j in range(K+1):
                if used[j]:
                    u[p[j]] += delta
                    v[j] -= delta
                else:
                    minv[j] -= delta
            j0 = j1
            if p[j0] == 0:
                break
        # augmenting path
        while True:
            j1 = way[j0]
            p[j0] = p[j1]
            j0 = j1
            if j0 == 0:
                break

    match = [0] * K
    for j in range(1, K+1):
        match[p[j]-1] = j-1

    total = sum(weight[i][match[i]] for i in range(K))

    # build mapping string
    mapping = [''] * K
    for i in range(K):
        a_idx = match[i]
        if a_idx < 26:
            mapping[i] = chr(ord('a') + a_idx)
        else:
            mapping[i] = chr(ord('A') + a_idx - 26)

    print(total)
    print(''.join(mapping))

if __name__ == "__main__":
    main()
```コードは、入力を読み取り、潜在的なマッピングごとに正解の数をカウントする重み行列を構築することから始まります。 ハンガリーのアルゴリズムは、最大の重みの完全なマッチングを見つけるために実装されており、最適なマッピングが得られます。 最後に、アルゴリズムは合計の一致を計算し、マッピング文字列を出力します。
