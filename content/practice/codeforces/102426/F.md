 ## 問題の理解

 すべての単位正方形を、底部が高さにある垂直な柱として考えてください。`h[i][j]`そしてその水平面積は正確に`1`。 一般的な水平水面が選択され、柱はその底がその水面より下にある場合にのみ水を供給します。 

重要なのは水の量です。 水面に高さがある場合`x`、次に底部の高さのあるセル`h`含まれています`max(x - h, 0)`水の単位。 それぞれの細胞には面積があるので、`1 dm²`、この高さはリットル単位の体積でもあります。 

例は、必要な答えがこの水位であることを示しています`x`、共通基準底部から上向きに測定。 最初のサンプルでは、​​表面を高さに配置します`3`底部が同じ高さの6つのセルのそれぞれに1単位の水を与える`2`、合計ボリュームは`6`。 2 番目のサンプルでは、​​高さの表面`6`深みを与える`5, 4, 3, 2, 1`高さのある 5 つのセルの上`1, 2, 3, 4, 5`、その合計は`15`。 

マトリックスには最大でも次のものが含まれます`1000 × 1000 = 10^6`細胞。 行列全体を読み取るには、セル数の線形時間がすでに必要であるため、適切なソリューションは次のようになります。`O(nm)`。 どの身長もせいぜいなので、`100`、可能な水位の範囲も非常に狭いです。 別の要素を費やす方法`nm`あらゆる可能なレベルで最大約`10^8`セル操作は、1 秒の制限の下では不必要にコストがかかります。 

ボリュームは次のように大きくできます`10^9`したがって、実装では少なくともその値を保持できる整数型を使用する必要があります。 Python の整数には任意の精度があるため、オーバーフローは問題になりません。 

直接実装を騙す可能性のある境界ケースがいくつかあります。 考慮する```
1 1 1
1
```唯一の列に底部の高さがあります`1`、したがって水面は高さに達する必要があります`2`1リットル入るように。 正しい答えは、`2`。 を使用する不注意な実装`x - h`サーフェスが底部より上にあるかどうかを考慮せずに実行すると、より低い候補レベルにマイナスの寄与が生じる可能性があります。 

もう一つの便利なケースは、```
1 3 3
1 1 1
```高所で`2`、各列には 1 リットルが含まれるため、答えは次のようになります。`2`。 1 つの代表的な高さだけではなく、3 つの等しい列がすべて寄与する必要があります。 

最後に考えてみましょう```
2 2 4
1 3
1 3
```高所で`2`、底部のある 2 つの列`1`それぞれに 1 リットルが入り、底のあるカラムには`3`水を含まない。 合計はまさに`2`、だから高さ`2`十分ではありません。 高所で`3`、下の 2 つの列にはそれぞれ 2 リットルが含まれ、他の 2 つの列にはゼロが含まれています。`4`。 正しい答えは、`3`。 これは、表面が最大値に達するとすべてのセルが水没したかのように扱う、または底が正確に表面にある柱を数えるというよくある間違いを捕らえます。 

## アプローチ

 最も直接的な解決策は、考えられるすべての水位を試してみることです。 候補身長については`x`、すべてのセルをスキャンして追加します`max(x - h[i][j], 0)`ボリュームに。 結果の体積が等しい場合`v`、その答えが見つかりました。 

固定水位における物理体積は、すべての柱内の水高さの合計に正確に一致するため、この強引な方法は正しいです。 この問題では、整数の答えが存在することが保証されており、高さは最大でも`100`、そのため、テストする候補レベルの数は少数です。 

問題はスキャンの繰り返しです。 100 万個のセルと最大約 100 個の候補レベルがある場合、最悪のケースは次のとおりです。`10^8`セルの評価。 各評価では減算、比較、加算が実行されますが、これは 1 秒のコンテスト制限には多すぎます。 

有益な観察は、高さの範囲が狭いということです。 実際には、セルを読んだ後にすべてのセルを個別に思い出す必要はありません。 各底部の高さを持つセルの数を数えることができます。 

させて`cnt[h]`底部が高さになっているセルの数になります`h`。 水位で`x`、すべてのセルに`h < x`貢献する`x - h`、一方、セルは`h >= x`貢献度はゼロ。 したがって、ボリュームは```
volume(x) = Σ cnt[h] * (x - h), for h < x
```あるのは`100`可能な値`h`したがって、周波数配列を構築した後、レベルごとに一定時間で考えられるすべての水位を評価できます。 解決策全体には次の時間がかかります`O(nm + H)`、 どこ`H = 100`。 

同じ考え方を理解するさらに一般的な方法は、ボリューム関数が単調であることを観察することです。 水面を上げても体積は決して減りません。 ただし、この問題では高さの制限が非常に小さいため、可能なレベルをスキャンする方が二分探索や並べ替えを実装するよりも簡単です。

 ## アルゴリズムのチュートリアル

 1. 配列を作成する`cnt`どこ`cnt[h]`底部の高さを持つセルの数を格納します`h`。 最大の高さは`100`、つまりサイズの配列`101`で十分です。 
2. すべての行列値を読み取ります`h`そして増加します`cnt[h]`。 同じ底部の高さを持つセルは、考えられるすべての水位に対して同じように動作するため、各高さの頻度のみが必要です。 
3. 以下の水位を試してください。`1`を通して`101`。 候補者レベルの場合`x`、すべての高さによって寄与される体積を計算します。`h < x`として`cnt[h] * (x - h)`。 ハイツ`h >= x`底が水面か水面より上にあるため、寄与はゼロです。 
4. 計算された体積が等しくなると同時に`v`、出力`x`。 この問題により、有効な整数の水位が存在することが保証されるため、検索によって整数の水位が見つかります。 
5. 最初の一致レベルの後で停止します。 ボリューム関数は減少しません。`x`が増加し、必要な量に対応する物理的な水位は、問題の保証の下では固有になります。 

### なぜ効果があるのか

 任意の固定水位に対して`x`、底部が高さにあるセル`h`正確に含まれています`x - h`水の単位`h < x`それ以外の場合は水を使用しません。 同じグループ内のすべてのセルはまったく同じ寄与を持つため、セルを底部の高さでグループ化しても、この計算は変わりません。 したがって、計算された合計は正確に水位の総水量となります。`x`。 

このアルゴリズムは、必要なボリュームを含むことができるすべての整数レベルをチェックします。 このステートメントは整数の答えとオーバーフローがないことを保証しているため、計算された量が正確に一致するレベルは`v`見つけて返さなければなりません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, v = map(int, input().split())

    # h is at most 100.
    cnt = [0] * 101

    for _ in range(n):
        for h in map(int, input().split()):
            cnt[h] += 1

    # Try every possible integer water level.
    # Level 101 is enough because the maximum bottom height is 100.
    for x in range(1, 102):
        volume = 0

        for h in range(1, x):
            volume += cnt[h] * (x - h)

        if volume == v:
            print(x)
            return

if __name__ == "__main__":
    solve()
```実装の最初の部分では、行列を読み取りながら周波数配列を構築します。 これにより、最大 100 万個の個別の高さを保存する必要がなくなり、メモリの使用量が非常に少なくなります。 

2 番目の部分では、候補となる水位を列挙します。 レベルとしては`x`、ループは意図的に次の位置で停止します。`x - 1`, なぜなら、次のセルがあるからです。`h == x`底が水面にぴったりあるため、水分はゼロです。 それを含めると追加されます`cnt[x] * 0`したがって、どちらの境界も数学的には安全ですが、`range(1, x)`状態をダイレクトに表現します。 

上限は`101`。 すべての底面の高さは最大でも`100`、上の表面`100`すべての柱が水没した後に残る唯一の可能性です。 この問題では、答えが存在し、浴槽があふれないことが保証されているため、この範囲で十分です。 

Python の任意精度の整数を使用すると、中間積が大きい場合でも体積計算を安全に行うことができます。 固定幅の整数を使用する言語では、64 ビット整数が適切な型になります。

    for _ in range(n):

            cnt[h] += 1

        volume = 0
