 ## 問題の理解

 2 つの等差数列が与えられています。$B$そして$C$。 進行状況$C$未知の数列に共通するすべての数字が含まれています$A$そして$B$。 私たちの目標は、有限の等差数列の数を数えることです。$A$この性質を満たすものが存在する可能性があります。 進歩$A$は、最初の項、共通の差異、および項の数によって一意に定義されます。 これら 3 つの値のいずれかが異なる場合、2 つの進行は異なるものとみなされます。 

入力により提供されるのは、$B$そして$C$標準の等差数列形式: 最初の項、公差、および項の数。 これらから、次のすべての要素を再構成できます。$B$そして$C$必要に応じて。 出力は可能な進行の数でなければなりません$A$モジュロ$10^9 + 7$、 または$-1$無限にたくさん存在するとしたら。 

制約が厳しい:$B$そして$C$まで持つことができます$10^9$条項。 これにより、完全なシーケンスのブルートフォース生成が不可能になります。 代わりに、解決策は算術推論と数論に依存する必要があります。 エッジケースが発生するのは次の場合です$C$と一致していません$B$、または$A$無限に超えて広がることができる$C$まだマッチングしながら$C \cap B = C$。 たとえば、次の場合$B = [2, 7, 12, 17, 22]$そして$C = [7, 12, 17, 22]$、無限に多くの$A$の算術ステップを後方または前方に拡張することで可能になります。$r$の期間の違いを分割するもの$C$。 

## アプローチ

 素朴なアプローチは、考えられるすべての最初の項を反復処理することです。$a$と違い$d$のために$A$シーケンスが交差するかどうかを確認します$B$まさに生産するために$C$。 これは原理的には正しいですが、差異を最大まで反復しても実行不可能です。$10^9$までの長さ$10^9$天文学的な数の操作が発生します。 

重要な観察は、$A$と一致する必要があります$C$、の最初の項を意味します$A$という形です$c - k \cdot r$ある整数に対して$k \ge 0$。 同様に、共通の違いは、$A$～の共通の違いを割らなければなりません$C$なぜなら$C$の続きです$A$。 もし$d$の違いは$A$そして$r$の違いは$C$、 それから$r \% d = 0$。 

さらに、$A$以下に該当する新しい用語を導入することはできません$B$しかし入っていない$C$。 もしそうなるなら、$A \cap B$を超える追加の要素が含まれる可能性があります$C$、これは無効です。 これは、無限に多くの解のケースを検出する方法です。$A$外に拡張できる$C$交点を破らなければ、解の数は無限になります。 

この推論の後、解決策は次のすべての約数を反復することになります。$r$、共通の違いの潜在的な候補です$d$の$A$。 それぞれについて$d$、許容される開始点の数を数えます$A$カバーする$C$余計な要素を含まずに、$B$外$C$。

 ## アルゴリズムのチュートリアル

 1.次のことを確認します$C$完全に内側にある$B$最初と最後の条件を確認することで、$C$に対して$B$そしてそれ$r$で割り切れます$q$。 いずれかの用語があれば、$C$外にある$B$、0を返します。 
2. 共通の違いがある場合$q$の$B$が 0 の場合$B$同一の要素が繰り返し含まれています。$C$すべて同一である必要があります$B$、それ以外の場合は 0 を返します。$C$同じです、無限にたくさんあります$A$(-1 を返します)。 
3. すべての正の約数を計算します。$r$、これらが考えられる唯一の違いであるため、$d$のために$A$と一致するもの$C$。 
4. 各約数について$d$、延長するかどうかを確認します$A$一歩前か後$C$からの数字を追加します$B$外$C$。 「はい」の場合は、これをスキップしてください$d$。 それ以外の場合は、シーケンスの数を計算します。$A$使用して$d$それはまさにカバーします$C$そしてそれ以上何もない$B$。 カウントは、最初の項が開始される前に開始できる方法の数に比例します。$C$の倍数で$d$。 
5. 有効なすべての合計$d$そしてモジュロを取る$10^9+7$。 

機能する理由: このアルゴリズムはシーケンスの算術特性を利用します。 約数に限定すると、$r$、私たちは保証します$A$含むことができる$C$続編として。 前方拡張/後方拡張チェックにより、無関係な項が交差部分に入らないことが保証され、無限解が正しく処理されます。 各約数は、正確に 1 つの構造を説明します。$A$重複することなくすべての有効なシーケンスをカウントするようにします。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline
MOD = 10**9 + 7

def divisors(n):
    res = set()
    for i in range(1, int(n**0.5)+1):
        if n % i == 0:
            res.add(i)
            res.add(n//i)
    return res

def solve():
    t = int(input())
    for _ in range(t):
        b, q, y = map(int, input().split())
        c, r, z = map(int, input().split())
        
        last_b = b + (y-1)*q
        last_c = c + (z-1)*r

        # Check C inside B
        if (c < b) or (last_c > last_b) or ((c-b)%q != 0) or ((last_c - b)%q != 0):
            print(0)
            continue

        # Infinite solutions check
        inf = False
        if q == 0:
            if r != 0 or y != z or b != c:
                print(0)
                continue
            else:
                print(-1)
                continue

        ans = 0
        for d in divisors(r):
            # Check for extraneous B elements
            ok = True
            if (c - d >= b) and ((c - d - b) % q == 0):
                ok = False
            if (last_c + d <= last_b) and ((last_c + d - b) % q == 0):
                ok = False
            if ok:
                ans = (ans + pow(r//d, 2, MOD)) % MOD
        print(ans)

solve()
