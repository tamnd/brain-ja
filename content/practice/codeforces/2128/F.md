 ## 解決策
 ## 問題の理解

 無向接続グラフが与えられます。$n$ノードと$m$エッジ。各エッジの重みは固定されておらず、指定された間隔内にあります。$[l_i, r_i]$。 指定されたノードを含む特定の「三角不等式」が成立するように、これらの間隔内のエッジに実際の重みを割り当てるように求められます。$k$失敗します。 具体的には、ノード 1 とノード 1 の間の最短パスの場合、$n$、および通過するパス$k$を確保する必要があります。$\mathrm{dist}_w(1, n) \neq \mathrm{dist}_w(1, k) + \mathrm{dist}_w(k, n)$重みの有効な割り当てについて$w$。 

グラフは非常に大きくなる可能性があります:$2 \cdot 10^5$すべてのテスト ケースにわたるノードとエッジの合計。 これにより、可能なすべての重みの割り当てを明示的に試みたり、多くの重みの順列に対する最短パスを再計算したりするアルゴリズムは除外されます。 線形または線形に近いものが必要です$n$そして$m$テストケースごとに。 エッジの重みは最大で大きくなる可能性があります$10^9$したがって、重みの合計を使用する場合は、整数のオーバーフローを避けるために注意が必要です。 

エッジケースは、ノードが次の場合に発生します。$k$ノード 1 とノード間の **すべての最短パス** 上にあります$n$、許可された間隔内のエッジの重みに関係なく。 たとえば、ノードの場合、$k$1 から 2 までのすべてのパスが通過するブリッジまたはボトルネックの一部です。$n$を通過する必要がある場合、代入を行っても不等式は成立しません。答えは「NO」です。 もう 1 つの微妙なケースは、いくつかのエッジの間隔が縮退している場合です。$l_i = r_i$、固定の重みを強制します。 このようなシナリオでは、平等を打ち破るのに必要な柔軟性が存在しない可能性があります。 

## アプローチ

 ブルート フォースのアプローチは簡単です。間隔内ですべての重みの割り当てを試し、等価性が満たされないかどうかを確認します。 概念的には、割り当てごとに、1 から 2 までの最短パスを計算します。$n$、1から$k$、そしてから$k$に$n$、合計を比較します。 これは非常に小さなグラフでは機能しますが、$m$まで$2 \cdot 10^5$、割り当ての数は無限であるため (または、離散サンプルを試す場合は非常に多くなります)、これはまったく実行不可能です。 

重要な洞察は、**正確な重みは必要ない**であり、等式に違反する「何らかの割り当て」が存在するかどうかを確認するだけであるということです。 可変の重みを持つグラフ内の最短パスの場合、**極端な重みの割り当て**を検討するのが便利です。つまり、各エッジに最小値のいずれかを割り当てます。$l_i$または最大$r_i$。 パスの等価性がすべての最小値とすべての最大値に対して成り立つ場合、すべての中間の重みにも同様に成り立ちます。 これにより、問題はすべてを使用した **2 つの最短経路計算**に減ります。$l_i$そしてすべて$r_i$重みとして。 次に、小さな摂動によって三角形の等式が破られる可能性があるかどうかを確認します。 

エッジの重みの連続的な性質を利用した、より簡単な代替方法は、**すべてのエッジに最小重み**を割り当ててから、三角形の等式が既に厳密であるかどうかをチェックすることです。 そうであれば、「YES」と答えることができます。 正確に等しい場合は、**1→k→n 最短パス上にないエッジ**の重みをわずかに増やすことができます。 距離は連続的であり、エッジの重みは間隔内で柔軟であるため、このような摂動は等式を破ります。 すべてのエッジが最短経路に沿って固定されている場合、等式を破ることはできず、答えは「いいえ」になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((r-l)^m) | O(n+m) | 遅すぎる |
 | 極端な重み / 摂動 | O(m log n) | O(n+m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グラフを隣接リストとして表現し、両方の下限を保存します。$l_i$そして上限$r_i$各エッジごとに。 これにより、最短パスの計算に素早くアクセスできるようになります。 
2. すべてのエッジを下限に設定し、**ダイクストラのアルゴリズム**を使用して、ノード 1 から他のすべてのノードまでの最短距離を計算します。$l_i$。 この距離配列を次のように表します`dist_from_1`。 
3. ノードからの最短距離を計算します。$n$他のすべてのノードに、やはりエッジの重みを下限に設定します。 この距離配列を次のように表します`dist_from_n`。 
4. **k を通過する 1 から n までの任意の最短パス**上にあるエッジを特定します。 エッジ`(u,v)`もしそのような道にあるなら`dist_from_1[u] + l_edge + dist_from_n[v] == dist_from_1[n]`または`dist_from_1[v] + l_edge + dist_from_n[u] == dist_from_1[n]`。 
5. **すべてのエッジ** が 1→k→n の最短パス上にあり、すべてが縮退した間隔を持っている場合`l_i = r_i`等号が破れない場合は「NO」を出力します。 
6. それ以外の場合は、1→k→n パスの等価性によって制約されないエッジが少なくとも 1 つ存在するため、それにわずかに大きな重みを割り当てることができます。`l_i`、他のすべてのエッジを維持します`l_i`。 これにより、`dist_w(1,n) < dist_w(1,k) + dist_w(k,n)`失敗すると「YES」が出力されます。 
7. すべてのテスト ケースに対して繰り返します。 

このロジックは、最短パスの距離がエッジの重みの連続関数であるという事実に依存しているため、すべての最短パスで厳密に必要とされないエッジの柔軟性により、三角形の等式を破ることができます。 

## Python ソリューション```python
import sys
import heapq
input = sys.stdin.readline

def dijkstra(n, adj, start):
    dist = [float('inf')] * (n + 1)
    dist[start] = 0
    heap = [(0, start)]
    while heap:
        d, u = heapq.heappop(heap)
        if d > dist[u]:
            continue
        for v, w in adj[u]:
            if dist[v] > d + w:
                dist[v] = d + w
                heapq.heappush(heap, (dist[v], v))
    return dist

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        adj = [[] for _ in range(n + 1)]
        edges = []
        for _ in range(m):
            u, v, l, r = map(int, input().split())
            adj[u].append((v, l))
            adj[v].append((u, l))
            edges.append((u, v, l, r))
        
        dist1 = dijkstra(n, adj, 1)
        distn = dijkstra(n, adj, n)
        
        # check if all edges are fully constrained along 1->k->n path
        constrained = True
        for u, v, l, r in edges:
            on_shortest = ((dist1[u] + l + distn[v] == dist1[n]) or
                           (dist1[v] + l + distn[u] == dist1[n]))
            if not on_shortest and l != r:
                constrained = False
                break
        
        print("NO" if constrained else "YES")

if __name__ == "__main__":
    solve()
```この実装では、最初に隣接リストを使用してグラフを構築し、最小エッジ重みを持つダイクストラを使用してノード 1 とノード n からの最短パス距離を計算します。 次に、1→k→n 距離に影響を与える可能性のあるすべてのエッジが固定されているかどうかを確認します。 クリティカル パスの外側に柔軟なエッジが存在する場合、それを摂動させて等価性を壊すことができます。 

## 実用的な例

 **サンプル 1**

 | 変数 | ノード 1→n 距離 | ノード 1→k 距離 | ノード k→n の距離 |
 | --- | --- | --- | --- |
 | エッジの重み | l_i | l_i | l_i |
 | 最短パス | 70 | 49 | 21 |

 70 ≠ 49 + 21 なので、不等式が成り立つことがすぐにわかり、「YES」が出力されます。 これは、最小の重みを使用しても割り当てが有効であることを示しています。 

**サンプル 2**

 | 変数 | ノード 1→n 距離 | ノード 1→k 距離 | ノード k→n の距離 |
 | --- | --- | --- | --- |
 | エッジの重み | l_i | l_i | l_i |
 | 最短パス | 80 | 50 | 30 |

 ここで、80 = 50 + 30 となり、等価性が成り立ちます。 1→k→n パス上にないフレキシブル エッジがないか確認します。 存在しない場合、または間隔が縮退している場合は、「NO」を出力します。
