 ## 解決策
 ## 問題の理解

 食堂は 2 つの「ベース スープ」から始まります。これは 2 つの純粋な材料と考えることができます。1 つは π タト スープ、もう 1 つはτ マト スープです。 レシピは日々確実に進化します。 1日目はスープ全体がπタト、2日目はスープ全体がτマトになります。 3 日目以降、前の 2 つのスープを同じ割合で混合して、新しいスープを作ります。 

これは、n 番目のスープは常に最初の 2 つのスープの混合物であり、各ステップでは新しいものを導入することなく前の混合物をブレンドするだけであることを意味します。 課題は、最終混合物のどの部分が元の π-タト スープに由来し、どの部分が n 日後の τ-マト スープに由来するかを決定することです。 

入力サイズは 10^18 に達するため、毎日をシミュレートするアプローチは直ちに実行できなくなります。 線形シミュレーションには最大 10^18 の操作が必要ですが、これは時間制限をはるかに超えています。 対数因数法でも許容されますが、O(log n) より悪いものは失敗します。 

n の値が小さい場合、微妙なエッジケースが現れます。 n が 1 または 2 の場合、答えは自明のことながら純粋な成分です。 これらの基本ケースを処理せずに、n = 3 から始まる漸化式を盲目的に適用するソリューションを使用すると、シーケンスが誤ってシフトしたり、未定義の値が生成されたりする可能性があります。 

## アプローチ

 ブルートフォース解釈は簡単です。 私たちは、π-tato と τ-mato がどのくらい存在するかを表す 1 組の値を毎日維持します。 1 日目は (1, 0) から始まり、2 日目は (0, 1) になります。 翌日毎日、前の 2 つのペアの平均を計算します。 これは問題定義に直接従っており、構造的には正しいです。 

問題は規模だ。 n 日目までの計算には、それまでのすべての日数を繰り返す必要があるため、複雑さは O(n) になります。 n が 10^18 までの場合、このアプローチは完全に実行不可能です。 

重要な観察は、両方のコンポーネントが同じ反復のもとで独立して進化するということです。 π-tato 分数のみを追跡すると、f(1) = 1 および f(2) = 0 で、漸化式 f(n) = (f(n−1) + f(n−2)) / 2 を満たします。τ-mato 分数は単純に 1 − f(n) ですが、対称的に計算することもできます。 

これは係数が一定の線形反復です。 このような反復は、行列のべき乗を使用して解決できます。 (f(n−1), f(n−2)) から (f(n), f(n−1)) への遷移を行列乗算としてエンコードします。 この行列を (n−2) 乗すると、O(log n) 時間での n 日目の状態が得られます。 

2 による除算では分数が導入されますが、浮動小数点で 1/2 を乗算するものとして扱うことも、同等に遷移行列に組み込むこともできます。 必要な精度は 10^{-6} であるため、浮動小数点行列のべき乗で十分です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n) | お(1) | 遅すぎる |
 | 行列のべき乗 | O(log n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 私たちは問題を、スケーリングを伴うフィボナッチのような漸化式の計算に落とし込みます。 

1. f(n) を n 日目の π タトスープの割合として定義します。 この構造から、f(1) = 1 および f(2) = 0 となります。これにより、すべてが発展する 2 つの基本状態が確立されます。 
2. n ≥ 3 の場合、f(n) = (f(n−1) + f(n−2)) / 2 であることに注目してください。これは、前の 2 つの混合の平均から直接得られます。 
3. 漸化式を線形変換として書き直します。 

(f(n), f(n−1)) = (1/2 * (f(n−1) + f(n−2)), f(n−1))。 
4. これを行列の乗算として表現します。 

[f(n), f(n−1)]^T = A * [f(n−1), f(n−2)]^T,

ここで、A = [[1/2, 1/2], [1, 0]]。 この表現により、累乗による繰り返し適用が可能になります。 
5. A^(n−2) を計算します。 これにより、初期ベクトル [f(2), f(1)] = [0, 1] が [f(n), f(n−1)] に変換されます。 
6. 2 乗による高速累乗を実行します。 各乗算では 2 つの遷移状態が結合され、反復の正確性が維持されます。 
7. 結果のベクトルから f(n) を抽出します。 混合物の合計は常に 1 になるため、τ-mato 分数は 1 − f(n) となります。 

### なぜ効果があるのか

 重要な不変条件は、各状態ベクトルが反復の最後の 2 つの値を完全にエンコードしていることです。 遷移行列は反復ステップを正確に再現するため、行列を乗算すると、浮動小数点精度を超える近似誤差を生じることなくシーケンスが 1 日進みます。 行列の乗算は結合的であるため、二乗を繰り返すと、対数時間で n−2 回の連続変換が正しくシミュレートされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def mat_mul(a, b):
    return [
        [
            a[0][0]*b[0][0] + a[0][1]*b[1][0],
            a[0][0]*b[0][1] + a[0][1]*b[1][1],
        ],
        [
            a[1][0]*b[0][0] + a[1][1]*b[1][0],
            a[1][0]*b[0][1] + a[1][1]*b[1][1],
        ],
    ]

def mat_pow(m, e):
    res = [[1.0, 0.0], [0.0, 1.0]]
    base = m
    while e > 0:
        if e & 1:
            res = mat_mul(res, base)
        base = mat_mul(base, base)
        e >>= 1
    return res

n = int(input())

if n == 1:
    print("100.0 0.0")
elif n == 2:
    print("0.0 100.0")
else:
    A = [
        [0.5, 0.5],
        [1.0, 0.0],
    ]
    M = mat_pow(A, n - 2)
    f_n = M[0][1]
    print(f"{f_n * 100:.10f} {(1 - f_n) * 100:.10f}")
```コードは、反復から直接遷移行列を構築します。 乗算関数は、サイズが一定であるため効率が維持されるため、最適化を行わずに標準の 2×2 行列乗算を実装します。 

二乗による累乗は、乗算の数を n から log n に減らします。 単位行列は累積を初期化し、結合されるまで部分的な結果が中立のままになるようにします。 

行列の定式化では前の 2 つの状態へのアクセスが想定されているため、基本ケース n = 1 および n = 2 は明示的に処理されます。 

浮動小数点演算が直接使用されます。 深さは最大でも log2(10^18) ≈ 60 回の乗算であるため、累積誤差は許容範囲内に収まります。 

## 実用的な例

 n = 1 と n = 2 から始まる漸化式を考えます。 

### 例 1: n = 3

 | 日 | f(n−2) | f(n−1) | f(n) の計算 |
 | --- | --- | --- | --- |
 | 1 | - | - | 1.0 |
 | 2 | - | - | 0.0 |
 | 3 | 1.0 | 0.0 | (1.0 + 0.0)/2 = 0.5 |

 n = 3 の場合、結果は 50% π-tato と 50% τ-mato になります。 これは、最初の混合ステップで 2 つのベース スープが直接平均されることを示しています。 

### 例 2: n = 4

 | 日 | f(n−2) | f(n−1) | f(n) の計算 |
 | --- | --- | --- | --- |
 | 2 | - | - | 0.0 |
 | 3 | 1.0 | 0.0 | 0.5 |
 | 4 | 0.0 | 0.5 | (0.5 + 0.0)/2 = 0.25 |

 4 日目には、π-tato 比率が 25% に低下し、平均化を繰り返すと元の寄与が急速に減衰することが確認されました。 

これらの例は、漸化式が各ステップで 1/2 ずつスケールされた平滑化されたフィボナッチ数列のように動作することを確認します。

 ## 特殊なケース

 n = 1 の場合、前の 2 つの状態が存在すると仮定しているため、行列定式化は適用できません。 このアルゴリズムは行列のべき乗を明示的にバイパスし、(100, 0) を返し、純粋な π タト スープとしての 1 日目の定義と一致します。 

n = 2 の場合も同じ問題が発生し、出力は (0, 100) に固定されます。 再帰を盲目的に適用しようとすると、未定義の以前の状態の混合が誤って計算されてしまいます。 

10^18 などの大きな n の場合、直接シミュレーションでは時間とメモリの両方がオーバーフローしますが、行列のべき乗により計算が約 60 の二乗ステップに削減されます。 各ステップは定数サイズの行列のみを操作するため、浮動小数点演算でも結果は安定したままになります。
