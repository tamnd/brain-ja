## Python ソリューション```python
import sys
import random
import math

input = sys.stdin.readline

def query(t: int) -> int:
    print(f"? {t}")
    sys.stdout.flush()
    return int(input().strip())

def main():
    # We pick increasing large timestamps
    # to avoid any ordering issues and to diversify coefficients.
    
    Q = 41
    MAXT = 10**18 - 1

    # generate strictly increasing queries
    # using a simple decreasing offset from MAXT
    ts = []
    step = 10**16

    cur = 0
    for i in range(Q):
        cur = cur + step
        if cur > MAXT:
            cur = MAXT - (Q - i - 1)
        ts.append(cur)

    g = 0

    for t in ts:
        x = query(t)
        diff = t - x
        g = math.gcd(g, diff)

    print(f"! {g}")
    sys.stdout.flush()

if __name__ == "__main__":
    main()
```このソリューションは、相互作用の結果に対して演算のみを実行します。 クエリ時間ごとに、返された位置を減算して、未知の長さの倍数を取得します。 gcd アキュムレータは、そのような制約をすべて 1 つの候補値にマージします。 

唯一の微妙な部分は、クエリ時間が厳密に増加していることを確認することです。 単調増加シーケンスを構築しますが、これも許容範囲内に留まります。$10^{18}$。

 ## 特殊なケース

 もし$L = 1$、すべてのクエリは 0 を返すため、それぞれ$d_i = t_i$。 選択されたすべてのクエリ時間にわたる gcd は 1 になり、サイクル長がすぐに正しく識別されます。
