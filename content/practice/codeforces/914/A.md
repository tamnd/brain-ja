 ## 解決策
 ## 問題の理解

 整数の配列が与えられているので、**完全な正方形**ではない最大の要素を見つける必要があります。 完全二乗とは、整数の 2 乗として表現できる数値です。 入力は、数値 _n_、配列のサイズ、その後に続く配列要素で構成されます。 出力は単一の整数、つまり完全な正方形ではない配列内の最大の要素です。 

制約は控えめです。_n_ は最大 1000、要素の範囲は -10^6 から 10^6 までです。 負の数値は完全な平方になることはあり得ないため、それらが候補であることがすぐにわかります。 _n_ の上限は、パフォーマンスの問題なく線形時間で各数値を個別にチェックできることを意味します。 数値の範囲により、整数演算で平方根を安全に計算することもできます。 

配列に大きな完全な正方形と小さな非正方形の数値が混在している場合、エッジ ケースが発生します。 たとえば、入力`5\n1 4 9 16 2`最大の非正方形は 2 だけです。 正方形をチェックせずに単純に最大の数値を選択する単純なアプローチでは 16 が返されますが、これは正しくありません。 負の数とゼロには注意が必要です。ゼロは完全な平方ですが、負の数は決して完全な平方ではありません。 

## アプローチ

 ブルートフォースアプローチは簡単です。 配列の各要素を反復処理し、それが完全な正方形であるかどうかを確認します。 そうでない場合は、これまでに確認された最大値を追跡します。 数値が完全な二乗であるかどうかを確認するには、整数の平方根を取得し、それを二乗して元の数値と等しいかどうかを確認します。 要素は最大 1000 個あり、それぞれが定数時間の平方根チェックを必要とするため、合計演算数は約 1000 であり、無視できる程度です。 したがって、総当たり攻撃は実際には許容されますが、大規模な配列では非効率になる可能性があります。 

重要な洞察は、配列をソートしたり、追加のデータ構造を保存したりする必要がないということです。 単一の直線パスで十分です。 各要素について、次の式を使用して整数の平方根を計算します。`math.isqrt`関数を使用して二乗し、元の数値と比較します。 等しくない場合、その数値は完全な平方ではないため、現在の最大値と比較します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n) | お(1) | 承認済み |
 | 最適 | O(n) | お(1) | 承認済み |

 この問題では、最適なアプローチと総当たり法は事実上同じであるため、非正方形を正しく識別することに重点が置かれています。 

## アルゴリズムのチュートリアル

 1. 変数を初期化する`best`負の無限大まで。 これにより、これまでに見つかった最大の非正方形が保存されます。 
2. 各要素を反復処理する`x`配列の。 
3. もし`x`が負の場合、完全な正方形にはなりません。 と比較してください`best`そして更新します`best`もし`x`の方が大きいです。 
4. もし`x`負ではない、計算する`y = int(sqrt(x))`を使用して`math.isqrt(x)`。 どうかを確認してください`y * y == x`。 そうでない場合は、`x`は完全な正方形ではありません。 
5. もし`x`は完全な正方形ではありません。と比較してください`best`そして更新します`best`もし`x`の方が大きいです。 
6. すべての要素を処理した後、出力します`best`。 

**機能する理由:** 各ステップで、次の不変条件が維持されます。`best`これまでに確認された完全な正方形ではない最大の数です。 すべての要素を調べて完全な正方形を正確に識別するため、最終的な値は`best`は最大の非正方形であることが保証されます。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

best = -float('inf')
for x in a:
    if x < 0:
        best = max(best, x)
    else:
        y = math.isqrt(x)
        if y * y != x:
            best = max(best, x)

print(best)
```このソリューションはまず、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 初期化する`best`負の数を正しく処理するには、負の無限大に設定します。 各要素について、負の数値が自動的に候補になります。 浮動小数点の不正確さを避けるために、整数の平方根を使用して非負の数値が完全な平方であるかどうかがテストされます。 ついに、`best`最大の非正方形が含まれます。

## テストケース```python
import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    best = -float('inf')
    for x in a:
        if x < 0:
            best = max(best, x)
        else:
            y = math.isqrt(x)
            if y * y != x:
                best = max(best, x)
    return str(best)

# provided samples
assert run("2\n4 2\n") == "2", "sample 1"

# custom cases
assert run("5\n1 4 9 16 2\n") == "2", "all squares except one"
assert run("3\n-1 0 1\n") == "-1", "negative numbers handled"
assert run("4\n2 3 5 7\n") == "7", "all non-squares"
assert run("1\n0\n") == "-inf", "single element, square zero"  # would never happen due to guarantee
assert run("6\n-100 -36 0 1 2 3\n") == "3", "mixed negative and positive"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`5\n1 4 9 16 2`| 2 | 複数の完全な正方形を正しく無視します。 
|`3\n-1 0 1`| -1 | 負の数を正しく処理します。 
|`4\n2 3 5 7`| 7 | すべての非正方形の中から選択された最大の非正方形 |
 |`6\n-100 -36 0 1 2 3`| 3 | 負数、ゼロ、平方の混合 |

 ## 特殊なケース

 入力用`-1 0 1`、`best`負の無限大から始まります。`-1`はマイナスなので、`best`-1になります。`0`は完全な正方形であり、スキップされます。`1`は完全な正方形であり、スキップされます。 出力は -1 ですが、これは正しいです。 このアルゴリズムは、負数やゼロを誤って分類することはありません。 

入力用`2 3 5 7`, すべての数字は非正方形です。 アルゴリズムのアップデート`best`これにより、正方形のないシーケンスが自然に処理されることが確認されます。 

これにより、ソリューションがすべてのエッジ シナリオにわたって最大の非正方形を正しく識別していることが確認されます。
