 ## 解決策
 ## 問題の理解

 コナンと阿笠が順番に山からカードを取り除くゲームがあります。 各カードには正の整数が書かれています。 プレイヤーがカードを選択すると、そのカードが削除されるだけでなく、厳密に小さい番号のカードもすべて削除されます。 カードがなくなってプレイヤーが行動できなくなった場合、ゲームは終了し、そのプレイヤーは負けます。 いつもコナンが先に動きます。 課題は、両方が最適にプレーした場合にどちらが勝つかを決定することです。 

入力はカードの数を示します`n`そしてそれらのカード上の整数のリスト。 出力は、最初のプレイヤーが勝利を強制できる場合は「Conan」、2 番目のプレイヤーが勝利できる場合は「Agasa」のいずれかになります。 制約により許可されるのは、`n`最大 100,000、カード価値も最大 100,000。 これは、カードに対して二次時間で反復したり、すべての可能な動きをシミュレートしたりするソリューションは、遅すぎる可能性が高いことを意味します。 線形または線形算術による解決策が必要です。 

多くのカードが同じ番号を持つ場合、エッジケースが発生します。 たとえば、すべてのカードが同一で偶数の場合、コナンは 1 回のターンですべてのカードを削除することはできません。 任意のカードを選択すると、その値のカードのみが削除されます。 その後、Agasa はすべてのカードがなくなるまで動きをミラーリングできます。 のような小さな入力`2\n5 5`は「Agasa」を出力するはずですが、最大のカードが常に勝つと仮定する不用意なアプローチでは、誤って「Conan」が返されます。 同様に、1 枚のカードがユニークで他のカードよりも大きい場合、コナンはそれを受け取ってすぐに勝つことができます。`3\n4 5 7`ここで、7 を選択するとすべてのカードが削除されます。 

## アプローチ

 ブルートフォースアプローチでは、考えられるあらゆる一連の動きをシミュレートします。 コナンのターンでは、各カードを試し、選択したカードとすべての小さいカードを取り除き、対戦相手の最適な動きを再帰的に計算します。 これは正しいですが、指数関数的に変化します`n`それぞれのカードの選択が複数の再帰的分岐につながる可能性があるためです。 メモ化しても、残りのカードの各サブセットが個別の状態であるため、状態空間は巨大になり、`n = 10^5`。 

重要な観察は、重要な唯一の要素は、**各カード番号の頻度のパリティ**であるということです。 それぞれの動きで小さい数字がすべて削除されるため、ゲームは事実上、固有の値ごとに何枚のカードが存在するかを数えることになります。 **奇数カウント**の数字が存在する場合、コナンはいつでもそのうちの 1 つを取得して偶数カウントを残すか、阿笠を負けの立場に追い込むことから始めることができます。 逆に、すべてのカウントが偶数の場合、阿笠はコナンの動きを反映することができ、最終的にはコナンのターンにカードがなくなってしまいます。 これにより、問題は単純な周波数チェックに減ります。

 ## アルゴリズムのチュートリアル

 1.入力されたカード枚数を読み取ります`n`そしてカードの値のリスト。 
2. 辞書や辞書を使用して、各カードの値の頻度を数えます。`Counter`。 
3. 周波数値を繰り返し処理します。 
4. 周波数が奇数の場合は、「Conan」と出力して停止します。 その理由は、カウントが奇数であるため、コナンが最初のアドバンテージを強制できるということです。 阿笠がどんな動きをしても、コナンは同等性を維持するために対応できる。 
5. すべての周波数が偶数の場合は、「Agasa」と出力します。 この場合、阿笠の手番で最後のカードが取られるまで、コナンのあらゆる行動が阿笠によって反映される可能性があります。 
6.終了。 

機能する理由: 不変条件は、どのターンでも、残りの最小数の頻度が偶数である場合、現在のプレイヤーは決定的なアドバンテージを得ることができないということです。 パリティによって、誰が勝利をもたらすことができるかが決まります。 奇数カウントを確認することで、どの選手が流れをコントロールできるかを即座に判断します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import Counter

n = int(input())
cards = list(map(int, input().split()))
freq = Counter(cards)

for count in freq.values():
    if count % 2 == 1:
        print("Conan")
        break
else:
    print("Agasa")
```コードはカードの数とカードの値を効率的に読み取ります。 の`Counter`各固有のカードが出現する回数をカウントします。 このループは奇数のカウントをチェックするため、コナンの勝利が保証されます。 の`else`ループ上では、ブレークが発生しない場合、つまりすべてのカウントが偶数である場合にのみトリガーされます。

## テストケース```python
import sys, io
from collections import Counter

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    cards = list(map(int, input().split()))
    freq = Counter(cards)
    for count in freq.values():
        if count % 2 == 1:
            return "Conan"
    return "Agasa"

# Provided samples
assert run("3\n4 5 7\n") == "Conan", "sample 1"
assert run("4\n2 2 3 3\n") == "Agasa", "sample 2"

# Custom cases
assert run("1\n5\n") == "Conan", "single card"
assert run("2\n5 5\n") == "Agasa", "two identical cards"
assert run("5\n1 1 2 2 2\n") == "Conan", "mixed parity counts"
assert run("6\n1 1 2 2 3 3\n") == "Agasa", "all even counts"
assert run("7\n7 7 7 8 8 8 9\n") == "Conan", "complex parity mix"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1\n5 | コナン | シングルカード、最初のプレイヤーが勝ち |
 | 2\n5 5 | 阿笠 | 同じカードの偶数カウント |
 | 5\n1 1 2 2 2 | コナン | 混合パリティ数 |
 | 6\n1 1 2 2 3 3 | 阿笠 | すべて偶数とみなします |
 | 7\n7 7 7 8 8 8 9 | コナン | 複数の数値の中の奇数の数 |

 ## 特殊なケース

 シングルカードの場合`1\n5`、周波数は`{5:1}`、これは奇妙です。 アルゴリズムは予想どおり「Conan」を出力します。 同じカードが 2 枚ある場合`2\n5 5`、周波数は`{5:2}`、 平。 ループでは奇数のカウントが見つからないため、「Agasa」が出力されます。 次のような混合カウントの場合`5\n1 1 2 2 2`、周波数は`{1:2, 2:3}`。 最初の奇数 (2:3) は「コナン」をトリガーし、アルゴリズムが勝利戦略を正しく検出していることを示しています。 この実装では、大きな入力とパリティ ロジックが一貫して正しく処理されます。
