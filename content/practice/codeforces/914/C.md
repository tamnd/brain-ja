## アプローチ

 ブルートフォースソリューションは概念的には簡単です。 すべての整数に対して`x`から`1`に`n`に達するまで、ポップカウントで繰り返し置き換えます。`1`、必要なステップ数をカウントし、そのカウントが等しいかどうかを確認します。`k`。 

Popcount は大量の数値を非常に迅速に折りたたむため、操作チェーンは短くなります。 以下の数字については`2^1000`、最大でも 1 つのアプリケーションが値を生成します`1000`、その後、値は小さくなります。 問題はチェーンの長さではなく、開始値の数です。 いつ`n`それ自体はそれに近いかもしれない`2^1000`、すべての候補を繰り返すことは絶望的です。 

重要な観察は、最初の操作後の将来の動作は、元の数値の設定ビット数のみに依存するということです。 

数字を考えてみましょう`x`正確に含まれています`s`バイナリ表現のもの。 

1 回の操作の後:```
x → s
```その時点からのプロセスは完全に決定されます。`s`。 

定義する：```
f(v) = minimum operations needed to reduce v to 1
```通常の整数の場合`v`。 

もし`x`もっている`s`ビットを設定し、`x > 1`、 それから：```
f(x) = 1 + f(s)
```したがって、膨大な数について推論する代わりに、それらに含まれるセット ビットの数を知るだけで済みます。 バイナリ長は最大 1000 なので、設定ビット数も最大 1000 になります。 

これにより、問題が 2 つの別々の部分に変換されます。 

まず、事前計算します`f(s)`みんなのために`s ≤ 1000`。 

次に、考えられるすべてのセットビット数について`s`、数字をいくつ数えますか`x ≤ n`正確に含む`s`もの。 これは、バイナリ文字列に対する古典的な組み合わせの数字 DP 問題です。 

答えに寄与する数値は、設定されたビット数と正確に一致します。`s`を満たす:```
1 + f(s) = k
```特別な取り扱いを除いて、`x = 1`。

## アルゴリズムのチュートリアル

### なぜ効果があるのか

 すべての正の整数に対して`x > 1`、最初の操作で送信されます`popcount(x)`。 After that moment, the future sequence depends only on that popcount value. もし`x`含まれています`s`1 の場合、操作の合計数は次となります。`1 + steps[s]`。 

アルゴリズムは、可能なすべての値を列挙します。`s`それはまさに`k`操作。 そういったそれぞれに対して`s`、桁 DP カウント手順はすべての数値をカウントします。`≤ n`まさに`s`ビットを 1 回だけ設定します。 組み合わせ遷移は、構築された数値が より小さくなる最初の位置に対応します。`n`。 

すべての有効な数値には一意のセット ビット カウントがあり、カウントされたすべての数値は必要な演算回数を満たしているため、最終的な合計は正確に望ましい答えになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10 ** 9 + 7

n = input().strip()
k = int(input())

L = len(n)

if k == 0:
    print(1)
    sys.exit()

# steps[i] = operations needed for i -> 1
steps = [0] * (L + 1)
steps[1] = 0

for i in range(2, L + 1):
    steps[i] = steps[i.bit_count()] + 1

# binomial coefficients
C = [[0] * (L + 1) for _ in range(L + 1)]
for i in range(L + 1):
    C[i][0] = C[i][i] = 1
    for j in range(1, i):
        C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % MOD

def count_with_ones(target):
    used = 0
    res = 0

    for i, ch in enumerate(n):
        if ch == '1':
            rem = L - i - 1
            need = target - used

            if 0 <= need <= rem:
                res = (res + C[rem][need]) % MOD

            used += 1

    if used == target:
        res = (res + 1) % MOD

    return res

ans = 0

for ones in range(1, L + 1):
    if 1 + steps[ones] == k:
        ans = (ans + count_with_ones(ones)) % MOD

if k == 1:
    ans = (ans - 1) % MOD

print(ans % MOD)
```の`steps`配列には、最大 1000 までの小さい整数に必要な演算の数が格納されます。これが機能するのは、1 回の Popcount 演算の後、関連するすべての数値が最大でも次のビット長になるためです。`n`。 

二項テーブルはカウントフェーズをサポートします。 スキャンで問題が発生した場合`1`噛み込む`n`、より小さい桁を選択できます`0`そして、残りの必要なものを残りのポジションに自由に分配します。 このような分布の数はまさに二項係数です。 

機能`count_with_ones(target)`桁DPカウントを実行します。 状態を DP テーブルに保存するのではなく、バイナリの上限に対して標準の組み合わせカウント トリックを使用します。 

の減算`k = 1`実装の中で最もデリケートな部分です。 ビットが 1 つ設定されている数値が条件を満たします`1 + steps[1] = 1`、しかしその数は`1`すでに等しいため、それ自体はそのカテゴリに属すべきではありません`1`何らかの操作の前に。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    MOD = 10 ** 9 + 7

    n = input().strip()
    k = int(input())

    L = len(n)

    if k == 0:
        print(1)
        return

    steps = [0] * (L + 1)
    for i in range(2, L + 1):
        steps[i] = steps[i.bit_count()] + 1

    C = [[0] * (L + 1) for _ in range(L + 1)]
    for i in range(L + 1):
        C[i][0] = C[i][i] = 1
        for j in range(1, i):
            C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % MOD

    def count(target):
        used = 0
        res = 0

        for i, ch in enumerate(n):
            if ch == '1':
                rem = L - i - 1
                need = target - used

                if 0 <= need <= rem:
                    res += C[rem][need]

                used += 1

        if used == target:
            res += 1

        return res % MOD

    ans = 0
    for s in range(1, L + 1):
        if 1 + steps[s] == k:
            ans += count(s)

    if k == 1:
        ans -= 1

    print(ans % MOD)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue().strip()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided sample
assert run("110\n2\n") == "3", "sample 1"

# minimum value
assert run("1\n0\n") == "1", "only number 1"

# number 1 is not special for k=1
assert run("1\n1\n") == "0", "special handling of 1"

# boundary where only 2 qualifies
assert run("10\n1\n") == "1", "remove number 1"

# numbers <= 3 needing exactly one operation: only 2
assert run("11\n1\n") == "1", "small boundary"
