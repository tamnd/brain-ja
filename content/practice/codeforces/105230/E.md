 ## 解決策
 ## 問題の理解

 単一の整数が与えられます$n$そして、それを 1 より大きい整数の積として表現したいと考えています。ひねりを加えると、考えられるすべての因数分解の中で、単純化や項の最小数を目的として最適化しているのではなく、その逆、つまり積に現れる因数の数を最大化したいということです。 

たとえ無限長の表現が可能であっても 1 を使用することは明示的に禁止されているため、各因数は少なくとも 2 でなければなりません。 出力は、降順でない整数のシーケンスであり、その積は以下に等しくなります。$n$, and among all valid decompositions, we choose the one with the maximum number of terms.

 制約$2 \le n \le 10^5$因数分解するメソッドを使用できるほど十分に小さい$n$おおよそで$O(\sqrt{n})$、あるいは$O(n)$precomputation ideas. What we cannot afford is enumerating all factorizations or doing exponential recursion over partitions of factors, since the number of multiplicative decompositions grows very quickly even for moderate values.

 主なエッジケースは次のような場合です$n$プライムです。 In that situation, no non-trivial factorization exists, so the only valid representation is the number itself.

 Another subtle case appears when multiple factorization paths exist but differ in depth. 例えば、$12$次のように書くことができます$3 \times 4$または$2 \times 6$ただし、すべての因数が素数になるまで分割を続ける分解のみが最大長に達します。 常に最小の約数を最初に取るような単純な貪欲な選択では、それを適切に正当化しない限り、最適なグローバル因数カウントが自動的に保証されません。 

## アプローチ

 ブルートフォースアプローチは、可能なすべての分割を再帰的に試みることです。$n$の中へ$a \times b$、次に両方の因数分解を続けます$a$そして$b$、最大数の項で分解を追跡します。 これは、乗算パーティションの完全な状態空間を探索するため、正しいです。 ただし、中程度の場合でも、$n$、これは不可能になります。 多くの数には数十の約数があり、それぞれの分岐がさらなる分岐につながり、指数関数的な爆発を引き起こします。 高度に合成された数値などの最悪の場合、再帰ツリーは非常に大きくなります。 

重要な観察は、任意の因数が求められるのではなく、項の数を最大化する分解が求められるということです。 因数の数を最大化するには、数値をできるだけ分割する必要があり、合成数をより小さな因数に分割すると、常に因数の合計数が増加または維持されます。 これは、最適な戦略は分解することであることを示唆しています。$n$素数は乗算における分割できない最小の構成要素であるため、完全に素因数に変換されます。 

素因数分解に達すると、それ以上の分割は不可能になるため、すべての合成が完全に分解されたときに因数の数が最大になります。 これにより、問題は標準的な素因数分解に変換され、その後、結果として得られる素数が非降順で並べ替えられます。これは、素数を除数の昇順に収集すれば、すでに自然に満たされます。

 ## アルゴリズムのチュートリアル

 1. 数字から始めます$n$そして、可能な限り小さい約数から始めてすべての要素を抽出しようとします$2$。 より小さな数で分割すると、より大きな複合分割を使用するよりも積極的に因数の総数が増加するため、小さな約数から始めます。 
2. 各整数について$d$2から$\sqrt{n}$、分割を繰り返します$n$による$d$割り切れるうちに。 分割するたびに記録します$d$一つの要因として。 これにより、すべての出現箇所を完全に抽出することができます。$d$次に進む前に。 
3. 約数が割り切れなくなったら$n$、増分$d$そして続けます。 これにより、どの合成因子もその平方根を超えない素約数を持つ必要があるため、すべての合成構造が最終的に素成分に分解されることが保証されます。 
4. ループ終了後、残りの値が$n$1 より大きい場合、素数でなければなりません。 それを最終要素として追加します。 
5. 収集されたすべての因子を文字「x」で結合して順番に出力します。 除数を昇順に繰り返すため、順序は当然非降順になります。 

### なぜ効果があるのか

 中核となる特性は、複合因数分解を項の数を減らさずに素因数に洗練できることです。因数がすでに素数でない限り、実際には項の数を厳密に増加させます。 あらゆる要因$a \times b$と$a, b > 1$は 1 つの項ではなく 2 つの項に寄与するため、複合を繰り返し分割すると常にカウントが向上または維持されます。 したがって、最大長分解はまさに次の素因数分解です。$n$、および他のグループ化では、より多くの要素を生成することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    res = []
    
    d = 2
    while d * d <= n:
        while n % d == 0:
            res.append(d)
            n //= d
        d += 1
    
    if n > 1:
        res.append(n)
    
    print("x".join(map(str, res)))

if __name__ == "__main__":
    solve()
```この実装は、因子抽出プロセスを直接反映しています。 外側のループは可能な除数を進めますが、内側のループは現在の除数のすべての出現を削除し、多重度が完全にキャプチャされることを保証します。 最終チェックでは、除算後に大きな素数が残る場合を処理します。これは、試行除算では標準です。 

主要な実装の詳細は次のとおりです。$d \times d \le n$停止条件として、$n$分割時に縮みます。 これにより、現在の削減値を超える不必要な反復が回避されます。

 ## 特殊なケース

 次のようなプライム入力の場合$n = 13$の場合、アルゴリズムは約数 2 と 3 を試行しますが、何も見つからず、唯一の因数として 13 を直接追加します。 トレースでは分割が発生していないことが示されているため、出力は単一要素のリストのままです。 

2 の累乗の場合は次のようになります$n = 16$、2 による除算の繰り返しは、値が 1 になるまで継続され、2 が 4 回発生します。除算ごとに因数の数が厳密に増加し、最適性の条件が直接示されます。 

次のような混合複合材料の場合$n = 30$の場合、アルゴリズムは 2、次に 3、次に 5 を昇順に抽出します。 それぞれが素数であるため、それ以上の分割は不可能であり、次のような代替グループ化も可能です。$6 \times 5$または$3 \times 10$生成される因数の合計は少なくなり、完全な因数分解が必要な理由が裏付けられます。
