 ## 解決策
 ## 問題の理解

 次元を持つ 0 と 1 のグリッドが与えられます。`n`による`m`。 各セルはオフ (`0`) または (`1`）。 私たちの目標は、特定の操作を使用してすべての 1 を 0 に変えることです。 この操作により、1 つのセルから任意の 3 つのセルを選択できます。`2 x 2`値を二乗して反転します。1 は 0 になり、0 は 1 になります。 出力には、テーブル全体がゼロになる一連の操作が記述されている必要があります。 各操作は、`2 x 2`サブグリッド。 操作の数を最小限に抑える必要はありません。 目標を達成するシーケンスはすべて有効です。 

制約により、テーブルが大きすぎないことが保証されます。`n`そして`m`それぞれせいぜい`100`、すべてのテスト ケースにわたるセルの合計数は次を超えません。`20000`。 これにより、`O(n m)`アプローチは実現可能です。 操作自体もテーブルのサイズに制限されるため、最大で`n m`移動は許容されます。 

明らかではないエッジケースは、テーブルが隅に集中している小さなテーブルまたは構成で発生します。 たとえば、`2 x 2`完全に 1 であるテーブルでは、各操作で 3 つのセルのみが反転されるため、複数の操作が必要になります。 セルのパリティを考慮せずにセルを反転するだけの単純なアプローチ`2 x 2`ブロックが 1 つだけ残る可能性があります。 もう 1 つの注意が必要な状況は、テーブルの端に 1 がある場合です。不注意に行方向または列方向に反復すると、右下隅のセルを見逃す可能性があります。 

## アプローチ

 ブルートフォース手法では、グリッドを反復処理して、それぞれをチェックします。`2 x 2`すべてのセルが 0 になるまで、正方形にして一度に 3 つずつ反転します。 これが機能するのは、各操作によって 1 の数が減り、`2 x 2`正方形は最大 4 回の手で解決できます。 単純な実装の問題は、操作の順序です。 慎重に記録を行わずに最初に行を処理し、次に列を処理すると、0 が 1 に戻され、サイクルが発生し、以上の処理が必要になる可能性があります。`n m`動きます。 最悪の場合のカウントでは、各セルが複数の操作に関与している可能性があることが示されていますが、合計は線形のままです。`n m`。 

重要な洞察は、右下隅からテーブルを処理して逆方向に作業することも、テーブルの最後の 2 行と最後の 2 列に焦点を当てることもできるということです。 どれでも`2 x 2`サブグリッドは、1 つ、2 つ、または 3 つを反転する操作を適用することで独立して解決できます。 問題を解決に導くことで`2 x 2`ブロックを個別に配置すると、体系的にグリッドをクリアできます。 このアプローチでは、すべての操作で現在のブロック内の 1 の数が減り、ブロックの外に新しい 1 が作成されないことが保証されます。

 ## アルゴリズムのチュートリアル

 1. 入力テーブルを可変の整数の 2D 配列に変換します。 これにより、1 と 0 を簡単に反転できます。 
2. 最後の行を除くすべての行を反復処理し、最後の行を除くすべての列を処理します。 それぞれについて`2 x 2`によって形成されたブロック`(i, j), (i, j+1), (i+1, j), (i+1, j+1)`、そのブロック内のすべての 1 の位置を記録します。 
3. ブロック内に 1 があり、少なくとも 3 つある場合は反転する 3 つを選択するか、1 と 0 を選択して 3 つのセットを形成します。 反転操作を適用して記録します。 ブロックにゼロのみが含まれるまで繰り返します。 これによりすべてが削減されます`2 x 2`ブロックごとに最大 4 つの操作を使用してブロックをゼロにします。 
4. 最終行と最終列を別々に処理します。 右下を処理する`2 x 2`最後のブロックとして正方形。 同じテクニックを使用して、残りのものをすべて削除します。 これにより、境界にある場合でも、セルが手つかずのまま残されることはありません。 
5. すべての操作をリストに蓄積し、合計数と操作自体を出力します。 各操作では、1 から始まるインデックスを使用して 3 つのセル座標がリストされます。 

このアプローチが機能するのは、各ブロックの処理後、そのブロック内のすべてのセルがゼロになるという不変条件があるためです。 ブロックは、以前にクリアされたセルに未解決のブロックを残さずに処理されるため、操作によって以前の作業が取り消されることはありません。 決勝戦の扱い`2 x 2`ブロックは、境界セルが正しくクリアされることを個別に保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        grid = [list(map(int, list(input().strip()))) for _ in range(n)]
        ops = []

        def apply(cells):
            ops.append([x+1 for xy in cells for x in xy])
            for x, y in cells:
                grid[x][y] ^= 1

        for i in range(n - 1):
            for j in range(m - 1):
                while sum([grid[i][j], grid[i][j+1], grid[i+1][j], grid[i+1][j+1]]) > 0:
                    ones = [(i,j), (i,j+1), (i+1,j), (i+1,j+1)]
                    ones = [cell for cell in ones if grid[cell[0]][cell[1]] == 1]
                    zeros = [(i,j), (i,j+1), (i+1,j), (i+1,j+1)]
                    zeros = [cell for cell in zeros if grid[cell[0]][cell[1]] == 0]
                    if len(ones) >= 3:
                        apply(ones[:3])
                    else:
                        apply(ones + zeros[:3-len(ones)])

        print(len(ops))
        for op in ops:
            print(' '.join(map(str, op)))

if __name__ == "__main__":
    solve()
```コードは、テスト ケースの数を読み取り、各テーブルを 2D 整数配列に変換することから始まります。 の`apply`関数は 3 つのセルに対して反転操作を実行し、グリッドを更新します。 ネストされたループはすべてを処理します`2 x 2`最初は右下のブロックを除くブロックを処理し、while ループによって 1 の構成が確実に解決されます。 最後の print ステートメントは、操作の数とその詳細を出力します。
