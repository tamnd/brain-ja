 ## 解決策
 ## 問題の理解

 各ストリップは位置の列として見ることができ、各位置にはチップが保持されます。 チップはストリップの右端のセルから始まり、移動がストリップ内に留まり、固定色の遷移ルール​​で許可されている限り、プレイヤーはターンごとにちょうど 1 つのチップを交互に移動し、1、2、または 3 位置左に押します。 

ゲームの状態は、すべてのストリップにわたるすべてのチップの位置によって完全に決定され、ターン構造は通常のプレイであり、動けない人が負けになります。 これにより、結果が Sprague-Grundy 値によって決定される公平な組み合わせゲームのクラスに問題が直ちに発生します。ただし、ここでの動きはセルの色に依存するため均一ではなく、色は部分的に不明であり、ボブによって敵対的に選択される点が異なります。 

実際のひねりは、ボブがゲーム内で手を動かしていないことです。 彼は、アリスがどのようにプレイするかに関係なく、結果のゲームが常に 2 番目のプレーヤー (ボブ) に勝つように、部分的に色の付いたボードの完成を選択しています。 したがって、空のセルへのフルカラーの割り当てによって、開始位置全体が最初のプレイヤーにとって負けの位置になる回数を数えています。 

直接読み取ると、2 方向の指数構造が示唆されます。各ストリップの長さは最大 10^9 で、ストリップの数は最大 1000 です。 m 個のセルのみが事前に色付けされています。 これは、ほとんどの構造が暗黙的であり、事前に色付けされたセルの周囲のローカル制約のみが重要であることを意味します。 全長にわたってセルごとに個別に推論する解決策は不可能です。 

局所的に考えると微妙な故障モードが現れます。 各ストリップは独立して処理できると思われるかもしれませんが、移動ではすべてのストリップの中から任意のチップを選択するため、ゲームはストリップを結合します。 したがって、完全な状態は独立したヒープのようなゲームの合計であり、各ストリップの Grundy 値に対して XOR ベースの推論が必要であることを意味します。 

もう 1 つの微妙な問題は、遠く離れた未知の領域の色が重要ではないと仮定することです。 実際には、各ストリップは遷移によってのみ決定される周期構造を持つ長いパスのように動作するため、未知の領域は乗法的自由度に寄与しますが、それは安定した動的動作を通じてのみです。 

## アプローチ

 この強引なアイデアは、色を付けていないすべてのセルに色を割り当て、完全なゲーム グラフの状態を計算し、各ストリップ位置の Grundy 値を評価してから、すべてのストリップの XOR が 0 であるかどうかを確認することです。 これは概念的には正しいですが、各ストリップの長さは最大 10^9 であり、単一のストリップでもすべてのセルにわたって線形 DP が必要となり、最大 10^12 の演算が必要になるため、完全に実行不可能です。 

重要な観察は、移動が 1、2、または 3 の減算に制限されていることです。これにより、各ストリップが有限状態反復になり、位置 i のグランディ値が i-1、i-2、および i-3 にのみ依存し、現在のセルの色と許可された遷移にのみ依存します。 カラーアルファベットのサイズは 3 のみであるため、各位置の動作は小さなステートマシンによって決定されます。 

ここで重要な構造的洞察が得られます。セルの色を固定すると、そのセルからの遷移も固定されます。 したがって、各セルは、グランディ伝播がどのように逆方向に動作するかについてのローカル制約に寄与します。 m 個のセルのみが事前に色付けされているため、各ストリップの残りの部分は同一の「未知の」セルの長いセグメントになります。 これらのセグメントは DP の意味で周期的に動作します。十分なステップの後、反復は小さな状態空間にわたる線形変換に安定します。 

したがって、位置を推論する代わりに、各ストリップを既知のセル間のセグメントに圧縮します。 各セグメントは、色付けされていないセルの長い連続であり、その寄与は、各カラー構成の最後の 3 つの DP 値を追跡する定サイズ状態に対する行列の累乗を使用して計算できます。

各ストリップが右境界から左境界への伝達関数に還元されると、問題全体は独立したセグメントの寄与の積になります。 残りのタスクは、未知のセルの色がゼロのグローバル XOR を引き起こす回数をカウントすることになります。これはストリップ上の DP を介して処理され、各ストリップは XOR 状態に対する多項式に寄与します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 |---|---|---|---|
 | 完全なゲームシミュレーション | O(3^{セルの総数}) | O(セルの合計) | 遅すぎる |
 | セグメント DP + 状態圧縮 | O(m · 3^k) | O(3^k) | 承認済み |

 ここで、k は 3 ステップの移動によって引き起こされる境界状態の数であり、一定です。 

## アルゴリズムのチュートリアル

 まず、各ストリップを、グランディ値がセルの色のみに依存する線形公平ゲームとして再解釈します。 ボブはすべての未知のセルの色を選択するため、各ストリップには多くの可能な誘導グランディ値が含まれており、XOR ゼロを生成するグローバル割り当ての数を数えなければなりません。 

以下の手順で進めていきます。 

1. 事前に色付けされたセルで切断して、各ストリップをセグメントに分割します。 各セグメントは、固定色のセル、または長い無色の間隔のいずれかです。 

2. セグメントごとに、可能な色構成ごとに、そのセグメントの最後の 3 つの位置のグランディ寄与を追跡する DP 状態を定義します。 3 つのステップを追跡する理由は、すべての動きは最大 3 つのポジションまでしか戻らないため、それを超えるものは将来のトランジションに影響を及ぼさないためです。 

3. 固定カラーセグメントの場合、カラーに対する 3 ステップの DP 再帰を使用して、その伝達関数を直接計算します。 3 つの色と 3 つの動きしかないため、これはセグメントごとの定数時間の計算です。 

4. 長さ L の色付けされていないセグメントの場合、遷移演算子の累乗を使用してその効果を計算します。 グランディ寄与がどのように逆方向に伝播するかを表す 3 色、3 状態のオートマトンを構築し、高速累乗を使用してそれを L 乗します。 これにより、L の反復処理が回避されます。 

5. 各ストリップについて、初期境界状態から最終的なグランディ寄与までのマッピングを取得します。 これを XOR 値に対する小さな関数として解釈します。 

6. ストリップ上で DP を実行します。 dp[x] が、Grundy 値の XOR が x になるように、処理されたストリップに色を割り当てる方法の数を表すものとします。 各ストリップについて、dp をストリップの寄与分布と畳み込みます。 

7. 最後に、答えは dp[0] です。XOR 0 は最初のプレーヤーの負け位置に対応し、ボブが勝つことを意味します。 

### なぜ効果があるのか

 正しさは 2 つの不変条件に基づいています。 まず、各ストリップは独立した公平なゲームであるため、グローバル ゲーム値はストリップ Grundy 値の XOR になります。 第 2 に、すべてのストリップはセグメントに分解でき、その内部構造は最後の 3 つの位置によって決定される境界状態を通じてのみゲームに影響します。 これにより、各セグメントが有限状態空間上の決定論的変換になります。 すべてのインタラクションはローカルで深さが制限されているため、グローバルなゲーム価値はこれらのセグメント変換の構成にのみ依存し、色を数えることが有限状態遷移の構成を数えることになります。 

どのステップも最後の 3 つの位置を超えて依存関係を導入したり、XOR の独立性を壊すような方法でストリップを混合したりすることはないため、ストリップ上の DP は正確なままになります。

 ## 特殊なケース

 デリケートなケースの 1 つは、すべての内部セルが色付けされていないが、両端が固定されているストリップです。 このような構成では、DP 状態は両方の境界で固定され、セグメントは自由オートマトンではなく制約付きオートマトンになります。 アルゴリズムは、両方のエンドポイントで分割し、中央を長い遷移セグメントとして扱うことでこれを処理します。 遷移行列の累乗により、長さに関係なく正確さが保証されます。 

別のケースは、セルの色が行列 f の下でのすべての送信移動を禁止する場合です。 これにより、局所的に強制的な負けポジションが作成されますが、状態遷移では単にその構成にゼロ寄与を割り当て、無効な状態を伝播するのではなく分布から削除するため、DP は壊れません。
