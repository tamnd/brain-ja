 ## 解決策
 ## 問題の理解

 マトリックスは任意ではありません。 各行には非表示の値があり、各列には非表示の値があり、表示されるすべてのセルはこれら 2 つの値の最小公倍数です。 一部のセルが欠落しています。タスクは、選択したすべての値の積をできるだけ小さくしながら、表示されているすべてのセルを作成できる行と列の値を選択することです。 

この積は、すべての行と列の値にわたる素数指数の合計を最小化することと同じです。 これは、数の掛け算を素数ごとに独立して表示できるためです。 たとえば、素数が 1 つの行の値の指数 3 に寄与する場合、それは別の値を同じ指数だけ増加させるのとまったく同じ係数に寄与します。 LCM の指数は 2 つの数値の最大の指数であるため、LCM 条件は素数によっても独立して機能します。 

ディメンションは最大 500 で、すべてのテストの行と列の合計数はそれぞれ 500 によって制限されます。 これにより、行と列の値のすべての可能な割り当てをチェックすることに近いことが除外されます。 非表示の値には制限がないため、可能な数値を検索することはできません。 解決策では、LCM と素因数の構造を使用する必要があります。 

セルが欠落していると、見逃しやすい状況が生じます。 ゼロセルにのみ表示される行または列には制限がなく、何も寄与しません。 たとえば、入力の場合```
2 2
0 0
0 0
```答えは`1`なぜなら、すべての非表示の値は 1 として選択できるからです。行列の値からすべての行と列を初期化する不用意なアプローチは、ここでは失敗します。 

もう 1 つの注意が必要なケースは、単一の行または列から値を取得しても最小値が常に見つかるとは限らないことです。 例えば：```
1 2
6 10
```最小値は`30`、 ない`60`。 行の値は次のとおりです。`1`2 つの列の値は次のようになります。`6`そして`10`、製品を与える`60`ただし、より良い選択は行値です。`2`、列`3`そして`5`、製品と同じ LCM を与える`30`。 解決策は、目に見える数値をコピーするのではなく、素数指数について推論する必要があります。 

## アプローチ

 直接的なアプローチでは、非表示の行配列と列配列を再構築しようとします。 目に見えるすべてのセルが言うので、`lcm(row[i], col[j]) = b[i][j]`、行列値のさまざまな約数を試して、最小の積を維持することができます。 すべての有効な答えはこれらの方程式を満たさなければならないため、これは正しいです。 

問題は可能性の数です。 までの値`10^8`多くの約数を含めることができ、最大 500 個の行値と 500 個の列値があります。 組み合わせを試すことはすぐに不可能になります。 ポジションごとに少数の候補者だけを考慮するだけでも、広大な州空間にわたる探索につながる可能性があります。 

有益な観察は、解決中に完全な値が必要ないということです。 1 つの素数を個別に考えてみましょう。 この素数の指数を並べます`i`なれ`r[i]`、列内`j`なれ`c[j]`。 指数のある既知のセル`x`条件を与えます:```
max(r[i], c[j]) = x
```頂点の場合、その頂点が持つことができる最大の指数は、すべての隣接する既知のセルの中で最小の指数です。 行が指数を持つセルに接している場合`2`、`5`、 そして`3`の場合、その指数は超えることはできません`2`。 これより大きな値を指定すると、最初のセルが不可能になります。 

次に、すべての行と列にこの最大許容指数を割り当てます。 元の行列は有効であることが保証されているため、すべての既知のセルには、最大許容指数が正確にセル指数であるエンドポイントが少なくとも 1 つあります。 どちらのエンドポイントにもその指数がなかった場合、どちらも小さくなり、LCM は必要な値に到達できなくなります。 

これにより、可能な限り最小の割り当てが得られます。 許容される最大指数を超えて頂点を増やすことは不可能であり、頂点を減らすと、それに依存するセルが壊れてしまいます。 これを素数ごとに個別に適用すると、最小積が得られます。

 | 最適 | O(nm log A) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての非ゼロ行列エントリを因数分解します。 各素数について、既知のすべてのセルに表示される指数を保存します。 行列内で実際に発生する素数のみを考慮します。 

すべての値が最大で以下であるため、異なる素因数の数は少なくなります。`10^8`。 

1. 各素数について、すべての行と列に対して可能な最小の指数の配列を作成します。 すべての行と列を大きな値で初期化し、すべての既知のセルを指数で処理します`e`。 行と列の上限を更新します。`e`。 

これにより、各頂点が受け取ることができる最大の指数が計算されます。 

1. この素数の行と列の寄与を答えに追加します。 行に最終指数がある場合`x`、答えを乗算します`p^x`。 すべての列に対して同じことを行います。 

素数は独立しているため、製品は素数ごとに構築できます。 

1. 既知のセルがない行と列を無視します。 上限は未設定のままで、可能な最小値は 1 です。 

これが機能する理由: すべての素数について、隠れ行列は最大 2 つの指数にのみ依存します。 すべての頂点には、その入射エッジからの上限があります。 有効な解では、これより大きな指数を割り当てることはできません。 すべての頂点に最大許容指数を割り当てると、すべてのエッジが満たされます。元の行列には有効な割り当てがあることが保証されているため、各エッジには、必要な指数に到達できる少なくとも 1 つのエンドポイントがあります。 割り当てを小さくすると、エッジで必要な指数が減少します。 したがって、構築された割り当てはまさに最小のものになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def factorize(x):
    res = []
    d = 2
    while d * d <= x:
        if x % d == 0:
            cnt = 0
            while x % d == 0:
                x //= d
                cnt += 1
            res.append((d, cnt))
        d += 1 if d == 2 else 2
    if x > 1:
        res.append((x, 1))
    return res

def solve_case(n, m, a):
    factors = [[[] for _ in range(m)] for _ in range(n)]
    primes = set()

    for i in range(n):
        for j in range(m):
            if a[i][j]:
                f = factorize(a[i][j])
                factors[i][j] = f
                for p, _ in f:
                    primes.add(p)

    ans = 1

    for p in primes:
        row = [-1] * n
        col = [-1] * m

        for i in range(n):
            for j in range(m):
                if a[i][j]:
                    exp = 0
                    for q, e in factors[i][j]:
                        if q == p:
                            exp = e
                            break
                    if row[i] == -1 or exp < row[i]:
                        row[i] = exp
                    if col[j] == -1 or exp < col[j]:
                        col[j] = exp

        for x in row:
            if x > 0:
                ans = ans * pow(p, x, MOD) % MOD

        for x in col:
            if x > 0:
                ans = ans * pow(p, x, MOD) % MOD

    return ans

def main():
    t = int(input())
    out = []

    for _ in range(t):
        n, m = map(int, input().split())
        a = [list(map(int, input().split())) for _ in range(n)]
        out.append(str(solve_case(n, m, a)))

    print("\n".join(out))

if __name__ == "__main__":
    main()
```因数分解ステージでは、すべての非ゼロ セルの素指数が保存されます。 それらを保存すると、異なる素数を処理するときに同じ値を繰り返し因数分解することが回避されます。 

メインループは一度に 1 つの素数を処理します。 の`row`そして`col`配列は、その素数の最小の上限を表します。 すべてのエンドポイントはセルの指数を超えてはいけないため、表示されているすべてのセルはこれらの境界を減らすことしかできません。 

よくある間違いは、初期値としてゼロを使用することです。 ゼロは実数の指数であるため、すべての行または列に寄与がないことが誤って強制されてしまいます。 コードでは、`-1`これは、頂点に既知の入射セルがないことを意味します。 

すべての素数べき乗の積は非常に大きくなる可能性があるため、最後の乗算ではべき乗剰余を使用します。

 ここ`A`は行列の最大値であり、`P`出現する個別の素数の数です。 までの値`10^8`問題の制約によって制限される行列の合計次元、これは快適に適合します。 

## テストケース```python
import sys, io

MOD = 998244353

def factorize(x):
    res = []
    d = 2
    while d * d <= x:
        if x % d == 0:
            c = 0
            while x % d == 0:
                x //= d
                c += 1
            res.append((d, c))
        d += 1 if d == 2 else 2
    if x > 1:
        res.append((x, 1))
    return res

def solve(inp):
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n, m = map(int, input().split())
        a = [list(map(int, input().split())) for _ in range(n)]
        factors = [[[] for _ in range(m)] for _ in range(n)]
        primes = set()

        for i in range(n):
            for j in range(m):
                if a[i][j]:
                    factors[i][j] = factorize(a[i][j])
                    for p, _ in factors[i][j]:
                        primes.add(p)

        cur = 1
        for p in primes:
            row = [-1] * n
            col = [-1] * m
            for i in range(n):
                for j in range(m):
                    if a[i][j]:
                        e = 0
                        for q, v in factors[i][j]:
                            if q == p:
                                e = v
                                break
                        row[i] = e if row[i] == -1 else min(row[i], e)
                        col[j] = e if col[j] == -1 else min(col[j], e)
            for x in row + col:
                if x > 0:
                    cur = cur * pow(p, x, MOD) % MOD
        ans.append(str(cur))

    return "\n".join(ans)

 ## 特殊なケース

 すべてゼロの行列の場合:```
2 2
0 0
0 0
```すべての行と列にはインシデント制約はありません。 このアルゴリズムでは素数指数が割り当てられないため、すべての隠れた値は 1 のままです。積は次のようになります。`1`。 

スパース行列の場合:```
2 3
0 6 0
0 0 10
```素因数は独立して処理されます。 素数 2 の場合、最初の既知の値によりその行または列に指数 1 が強制され、値 10 からの素数 5 と素数 3 にも同じことが起こります。最小の積は、必要な指数を可能な限り 1 回だけ割り当てることによって取得されます。 

値が等しい場合:```
2 2
6 6
6 6
```すべてのエッジには素数 2 と 3 の指数が必要です。行と列の境界は同じ値になりますが、アルゴリズムは合計の寄与が最小のものを選択します。`36`表示されているすべてのセルを一緒に乗算する代わりに。
