 ## 解決策
 ## 問題の理解

 整数配列で表されるタイルの行があります。`b`。 同じ非負の値を追加します`x`すべてのタイルに。 この操作の後、左側の合計が右側の合計と等しくなるように、行を 2 つのタイル間の任意の位置で分割可能にする必要があります。 タスクは可能な限り最小のものを見つけることです`x`、または の値がないことを報告する`x`このような分割を可能にすることができます。 

ポジション後に分割したとします`i`、 どこ`1 <= i < n`。 元のプレフィックスの合計を次のようにします。`P`、合計を次のようにします`S`。 追加後`x`すべての要素に対して、左側がゲインします`i*x`そして右側が利益を得る`(n-i)*x`。 条件は次のようになります。`P + i*x = (S - P) + (n-i)*x`配列の長さは次のとおりです`2 * 10^5`すべてのテスト ケースの合計。 これにより、考えられる多くの値を試すことができなくなります。`x`、答えは次のように大きくなる可能性があるため、`10^18`。 ソリューションでは、各要素を一定の回数だけ検査する必要があり、期待されるターゲットは次のとおりです。`O(n)`テストケースごとに。 

主なエッジ ケースは、分割位置と係数から得られます。`x`。 

ちょうど真ん中の分割部分は、`2*i-n = 0`。 この状況で変化するのは、`x`双方に均等に影響を与えるため、不均衡を修正することはできません。 例えば：```
Input:
1
2
1 2
```唯一の分割には合計が残っています`1+x`そして正しい合計`2+x`。 それらの違いは次のとおりです`1`永遠に、だから答えは`-1`。 で割る不注意な実装`2*i-n`ゼロを処理しないとここで失敗します。 

もう 1 つのエッジ ケースは、配列がすでに分離可能である場合です。 例えば：```
Input:
1
3
1 2 3
```2 番目の要素の後の分割により、`1+2 = 3`、 それで`x = 0`はすでに有効です。 他の正の値も機能する場合でも、最小の答えはゼロのままでなければなりません。 

3 番目のケースは、有効な分割に大幅な調整が必要な場合です。 例えば：```
Input:
1
5
1 2 3 4 5
```3 つの要素の後に分割すると、次のようになります。`6 + 3x = 9 + 2x`それで`x = 3`。 の小さい値のみをチェックする`x`この答えを見逃してしまうでしょう。 

## アプローチ

 直接的な総当たりのアイデアは、可能なすべての分割とすべての可能な値を試すことです。`x`解決策が見つかるまで。 分割部分はプレフィックス合計で簡単に処理できますが、`x`小さな数に制限されません。 最悪の場合、有効な答えが到達する可能性があるため、可能な値をテストすることが不可能になります。`10^18`。 

等価条件を再整理すると、有益な観察が得られます。 スプリット位置を固定する場合`i`:`P + i*x = S - P + (n-i)*x`すべての項を移動すると、次のようになります。`(2*i-n)*x = S - 2P`各分割位置は、未知数を 1 つ含む線形方程式を与えます。 探す必要はありません`x`; その分割に対して可能な唯一の値を計算できます。 

もし`2*i-n`がゼロの場合、分割はすべての場合に機能します。`x`または何もなし。 唯一役に立つのは次のような場合です。`S - 2P`もゼロなので、`x = 0`。 

それ以外の場合、候補値は次のとおりです。`x = (S - 2P) / (2*i-n)`それが整数で負でない場合にのみ受け入れられます。 すべての分割をチェックし、最小の有効な候補を維持すると、答えが得られます。 

分割条件が単純であるため総当り攻撃は機能しますが、可能性のある調整が小さくないため失敗します。 代数変換により検索が完全に削除され、問題が線形スキャンに変わります。

 ## アルゴリズムのチュートリアル

 1. 合計を計算する`S`元の配列の。 すべての分割でプレフィックスを残りのサフィックスと比較するため、この値が必要です。 
2. 可能な分割位置をスキャンします。`1`に`n-1`現在のプレフィックス合計を維持しながら`P`。 それぞれの位置は、最終的な配列が分離される可能性のある 1 つの場所を表します。 
3. 現在の分割について、次のように計算します。`left = 2*P - S`そして`right = 2*i - n`。 この分割の方程式は次のとおりです。`left + right*x = 0`、これは唯一の可能な値を与えます`x`。 
4. もし`right`がゼロの場合は、個別に処理します。 分割は次の場合には変更されません`x`変化するため、次の場合にのみ機能します。`left`もゼロです。 その場合、答えの候補はゼロになります。 
5. もし`right`ゼロではない、かどうかを確認してください`-left`で割り切れます`right`。 割り切れない場合、この分割では次の整数値を生成できません。`x`。 割り切れる場合は、候補を計算し、それが負でない場合にのみ保持します。 
6. 見つかった最小の候補を返します。 有効な候補を生成する分割がなかった場合は、戻り値を返します。`-1`。 

これが機能する理由: 考えられるすべての分割において、等式条件は次の線形方程式になります。`x`。 分割には、有効な整数解がない場合、有効な値が 1 つある場合、または両側がすでに等しく、係数が次の場合はすべての値が含まれる可能性があります。`x`はゼロです。 このアルゴリズムは、考えられるすべての分割を調べ、方程式を満たすことができる値を正確に考慮するため、有効な答えが見逃されることはなく、無効な答えが受け入れられることもありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    b = list(map(int, input().split()))

    total = sum(b)
    prefix = 0
    ans = None

    for i in range(1, n):
        prefix += b[i - 1]

        a = 2 * prefix - total
        c = 2 * i - n

        if c == 0:
            if a == 0:
                candidate = 0
            else:
                continue
        else:
            value = -a
            if value % c != 0:
                continue
            candidate = value // c

            if candidate < 0:
                continue

        if ans is None or candidate < ans:
            ans = candidate

    print(-1 if ans is None else ans)

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```すべての分割ではプレフィックスとそのプレフィックスの補数が比較されるため、ソリューションでは最初に合計が格納されます。 スキャン中に、`prefix`は現在の分割前の合計であるため、式は`2 * prefix - total`は、双方の元の違いを表します。 

変数`c`の係数です`x`。 ゼロの場合、除算は不可能であり、コードは特殊なケースを直接チェックします。 これにより、ゼロ除算エラーが回避され、中間分割が正しく処理されます。 

非ゼロの場合`c`、コードは整数の除算を実行する前に割り算をチェックします。 Python の整数除算では非整数の答えが暗黙的に切り捨てられ、無効な結果が作成される可能性があるため、これは重要です。 最終的な比較では、最小の有効な非負の値が保持されます。

import io

def solution(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    def solve():
        n = int(input())
        b = list(map(int, input().split()))

        total = sum(b)
        prefix = 0
        ans = None

        for i in range(1, n):
            prefix += b[i - 1]
            a = 2 * prefix - total
            c = 2 * i - n

            if c == 0:
                if a == 0:
                    candidate = 0
                else:
                    continue
            else:
                value = -a
                if value % c != 0:
                    continue
                candidate = value // c
                if candidate < 0:
                    continue

            if ans is None or candidate < ans:
                ans = candidate

        return "-1" if ans is None else str(ans)

    t = int(input())
    out = []
    for _ in range(t):
        out.append(solve())

    sys.stdin = old_stdin
    return "\n".join(out)
