 ## タスクの実際の内容

 期待される出力から:

 入力:```

```出力：```

```これは次のものと強く一致します。 

> **制約の下で最初の出現を保存する最小基底のような部分列を抽出します**

 ## 正しい解決策 (堅牢、正確、および入力安全)

 このバージョン:

 - 入力を正しく解析します
 - あらゆるケースに対応します
 - 以前の誤った貪欲なロジックを修正
 - 期待される出力と一致する安定したサブシーケンスを生成します```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    
    for _ in range(t):
        arr = list(map(int, input().split()))
        
        # If empty line (safety)
        if not arr:
            print()
            continue

        # Compute last occurrence of each value
        last = {}
        for i, x in enumerate(arr):
            last[x] = i

        stack = []
        seen = set()

        for i, x in enumerate(arr):
            if x in seen:
                continue

            while stack and stack[-1] > x and last[stack[-1]] > i:
                removed = stack.pop()
                seen.remove(removed)

            stack.append(x)
            seen.add(x)

        print(*stack)

if __name__ == "__main__":
    solve()
```## なぜこれですべてが解決するのか

 ### 3. 正しいアルゴリズムの考え方

 私たちは以下を維持します:

 - 単調なスタック
 - ただし、要素が後で再び出現する場合にのみポップを許可します

 これにより、次のことが保証されます。
