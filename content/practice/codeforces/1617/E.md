 ## 解決策
 ## 問題の理解

 私たちには、負でない整数で表される個別のタイプを持つチョコレートの箱が与えられます。 アイシーは、少なくとも 1 組のチョコレートを同じ種類にしたいと考えていますが、交換する前に、たとえばインデックスで 2 つのチョコレートを選択します。$x$そして$y$。 その後、祖父母は一連のチョコレート交換を行います。$x$毎回 2 の累乗を選択するだけです$2^k$少なくとも同じ大きさ$a_x$そして交換$a_x$と$2^k - a_x$。 このシーケンスは次の時点まで続きます。$a_x = a_y$。 

私たちの仕事はペアを見つけることです$(x, y)$必要な交換回数が最小限になるように、$a_x = a_y$最大化されます。 また、交換の最小数を報告する必要があります。$m$。 

制約というのは、$n$最大 200,000 までの可能性があり、$a_i \le 10^9$。 大きいため、$n$、すべてのシーケンスのブルートフォース探索ですべてのペアを考慮するアルゴリズムは実行不可能です。 すべてのペアのすべての変換をシミュレートする素朴なアプローチは、簡単に達成できます。$O(n^2 \cdot \text{sequence length})$、これは 4 秒の許容範囲をはるかに超えています。 

考慮すべきエッジケースには、非常に小さな配列 (n = 2)、ゼロに近い値、または 2 のべき乗が含まれます。 たとえば、次の場合$a = [0, 1]$、それらを等しくするための最短のシーケンスは自明ではありません。$0$にしか行けない$1$経由$2^1 - 0 = 2$それから$2^1 - 2 = 0$、などというサイクルが形成されます。 不注意に実装すると、複数のパスまたはサイクルを考慮できない可能性があります。 

## アプローチ

 ブルートフォースアプローチは、概念的には単純です: 各ペアのチョコレートに対して$(x, y)$、BFS または DFS を実行して、変換に必要な最小限の交換数を見つけることができます。$a_x$の中へ$a_y$。 それぞれの変換で複数の新しい状態 (すべての状態) が生成される可能性があるため、$2^k - a_x$)、状態空間は非常に大きくなる可能性があります。$O(\log_2(10^9)) = 30$ステップごとの変換により、指数関数的な成長が得られます。 と$n = 2 \cdot 10^5$、これは実現不可能です。 

重要な洞察は、変換の構造を観察することで得られます。 各交換の形式は次のとおりです。$a := 2^k - a$これは、ノードが数値でありエッジが接続されている暗黙的なグラフ上の BFS を彷彿とさせます。$a$に$2^k - a$。 重要なことは、$2^k$は常に 2 の累乗であり、任意の数であるため、変換シーケンスには制限があります。$a < 2^k$ゼロまたは別の 2 のべき乗区間に近い値に変換します。 

チョコレートの種類ごとに事前計算できます$a_i$、一連の交換を通じて到達可能なすべての番号と、それぞれに到達するための最小ステップ数。 これができたら、問題を逆転できます。すべてのペアの変換をシミュレートする代わりに、数値をキーとしたハッシュ マップに各チョコレートの到達可能な値をすべて保存し、ステップと元のインデックスのリストにマップします。 次に、複数のチョコレートから到達できる各数値について、最小交換回数を最大化するペアを確認できます。 これにより、検索スペースが減少します。$O(n^2)$本質的には、到達可能な数値によって形成されるグラフのサイズになります。これは、変換によって数値がゼロと 2 の累乗に向かって急速に縮小されるため、管理可能です。

 ## アルゴリズムのチュートリアル

 1. まず、すべてのチョコレートに対して反復処理を行います。$a_i$から到達可能なすべての番号を生成します$a_i$一連のやりとりを経て。 それぞれのステップが変化する$x$の中へ$2^k - x$みんなのために$2^k \ge x$。 これらの数値を、その数値に到達するために必要な歩数とと​​もに保存します。 辞書マッピング番号 → (インデックス、ステップ) のリストを使用します。 
2. 数字ごとに$v$辞書に複数の起源を持つチョコレートが表示されている場合、各起源のチョコレートが到達するまでに必要な最小ステップ数を計算します。$v$。 
3. 同じ数字になったすべてのチョコレートのペアの中から、そのペアを見つけます。$(i, j)$最小限のステップを最大化します。 これはアイシーの選択に対応しています。彼女は、祖父母がペアを平等にするためにできるだけ時間がかかることを望んでいます。 
4. ペアを返却します$(x, y)$(1 ベースのインデックス付け) とステップ数$m$それらの間の最小限のシーケンス。 複数の答えが存在する可能性があります。 どれでも受け入れられます。 

機能する理由: 各チョコレートの到達可能な数値が 1 回だけ事前計算され、任意の値に到達するための最小限のステップがキャプチャされます。 複数の起源を持つ数値を反復することにより、すべてのチョコレートのペアの中で最大の最小シーケンスが見つかることを保証します。 変換は 2 のべき乗の制限により決定的かつ有限であるため、BFS 探索は終了し、正しいステップ数が生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import defaultdict, deque

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    # Stores reachable number -> list of (index, steps)
    reach = defaultdict(list)
    
    for idx, val in enumerate(a):
        seen = {}
        q = deque()
        q.append((val, 0))
        while q:
            x, steps = q.popleft()
            if x in seen:
                continue
            seen[x] = steps
            reach[x].append((idx, steps))
            # Generate next states
            k = 0
            while (1 << k) < x * 2:
                nxt = (1 << k) - x
                if nxt >= 0 and nxt not in seen:
                    q.append((nxt, steps + 1))
                k += 1
    
    # Find pair maximizing minimal steps
    best = (-1, -1, -1)
    for v, lst in reach.items():
        if len(lst) < 2:
            continue
        lst.sort(key=lambda x: -x[1])  # sort descending by steps
        first, second = lst[0], lst[1]
        steps = min(first[1], second[1])
        if steps > best[2]:
            best = (first[0] + 1, second[0] + 1, steps)
    
    print(f"{best[0]} {best[1]} {best[2]}")

if __name__ == "__main__":
    solve()
```BFS は、特定のチョコレートから各数値に到達するまでの最小ステップ数を記録することを保証します。 辞書を使用すると、再計算が回避され、到達可能な数値を高速に検索できます。 到達可能なリストをステップ降順で並べ替えることで、最小ステップ数を最大化するペアが選択されることが保証されます。
