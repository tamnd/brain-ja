 ## 解決策
 ## 問題の理解

 文字列が与えられています`S`任意の小文字と文字列`T`それは常に次の順列です`"abc"`。 タスクは、文字を並べ替えることです。`S`新しい文字列に`S'`これは、次のことを保証しながら辞書編集上可能な最小値です。`T`サブシーケンスとしては表示されません。 関係する文字列は小さく、`S`最大100文字と`T`長さは常に 3 ですが、テスト ケースの数は最大 1000 になる可能性があるため、ソリューションは多くの短い文字列に対して効率的である必要があります。 

文字列の辞書編集上最小の順列は、通常、その文字を昇順に並べ替えることによって取得されます。 複雑さは回避する必要があることから生じます`T`続編として。 単純な並べ替えでは、誤って次のような結果が生成される可能性があります。`T`もし`S`少なくとも 1 つ含まれています`'a'`、 1つ`'b'`、そして1つ`'c'`。 たとえば、次の場合`S = "abacaba"`そして`T = "abc"`、並べ替え`S`与える`"aaaabbc"`、これには以下が含まれます`"abc"`サブシーケンスなので無効です。 

この制約により、パフォーマンスを気にせずに文字列を直接操作できるようになります。`100 * 1000 = 100,000`Python では操作は簡単です。 エッジ ケースには、次のすべてを含まない文字列が含まれます。`'a'`、`'b'`、`'c'`(この場合、任意の並べ替えが有効です) および文字列`T`は`"acb"`(禁止順はアルファベット順とは異なります)。 常にアルファベット順にソートする不注意な実装では、禁止されたサブシーケンスを破ることができない可能性があります。 

## アプローチ

 ブルートフォースアプローチは、次のすべての順列を生成することです。`S`、禁止されたサブシーケンスをそれぞれチェックし、辞書編集的に最小の有効な文字列を選択します。 これは原理的には機能しますが、長さは指数関数的になります。`S`（100まで！）なので、それは不可能です。 

重要な洞察は次のとおりです`T`のみが含まれます`'a'`、`'b'`、 そして`'c'`したがって、ソートされた文字列が誤って形成される唯一の方法です。`T`は、これら 3 つの文字がそれぞれ少なくとも 1 つ含まれているかどうかを示します。 を除くすべての文字を並べ替える`'a'`、`'b'`、`'c'`常に安全です。 特別な処理が必要なだけです`'a'`、`'b'`、 そして`'c'`。 

問題は次のように単純化されます。`'a'`、`'b'`、`'c'`、アウトプットしましょうか？`"abc"`注文するか、`"acb"`形成を避けるため`T`? もし`T`は`"abc"`、切り替えます`'b'`そして`'c'`に`"acb"`後続を中断します。 その他の順列については、`'abc'`（のように`"acb"`、`"bac"`)、単に次のように並べ替えます`"abc"`すでに安全です。 これにより、すべてのテスト ケースが正しく効率的に処理されます。

 ## アルゴリズムのチュートリアル

 1. すべての文字の出現を数えます。`S`周波数配列を使用するか、`collections.Counter`。 これは、後でソートされた文字列を効率的に再構築するのに役立ちます。 
2. もし`T`まさに`"abc"`そして`S`少なくとも 1 つ含まれています`'a'`、 1つ`'b'`、そして1つ`'c'`、再注文させていただきます。`'a'`、`'b'`、`'c'`としてブロック`"acb"`形成を防ぐために`"abc"`続編として。 その他については`T`、並べ替えることができます`'a'`、`'b'`、`'c'`普通に。 
3. 文字を反復処理して出力文字列を構築します。`'a'`に`'z'`:

 - キャラクターの場合`'a'`、`'b'`、 または`'c'`そして`T`は`"abc"`、出力`'a'`まず、それから`'c'`、 それから`'b'`。 
- 他のすべての文字については、その数に従って辞書順に追加します。 
4. すべての文字の連結を次のように返します。`S'`。 

なぜ機能するのか: 順序を変更するだけで`'a'`、`'b'`、`'c'`いつ`T`は`"abc"`、私たちはそれを保証します`T`サブシーケンスとして出現することはできません。 他のすべての文字を並べ替えると、辞書編集上の最小限度が維持されます。 不変条件は、`'a'`、`'b'`、`'c'`ブロックの場合、ブロックには含まれていない文字のみが含まれるため、順序は禁止されたサブシーケンスには影響しません。`T`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        S = input().strip()
        T = input().strip()
        freq = [0] * 26
        for ch in S:
            freq[ord(ch) - ord('a')] += 1

        result = []
        if T == "abc" and freq[0] and freq[1] and freq[2]:
            # output 'a's
            result.append('a' * freq[0])
            # output 'c's
            result.append('c' * freq[2])
            # output 'b's
            result.append('b' * freq[1])
        else:
            result.append('a' * freq[0])
            result.append('b' * freq[1])
            result.append('c' * freq[2])
        # append the rest in lex order
        for i in range(3, 26):
            result.append(chr(i + ord('a')) * freq[i])
        print(''.join(result))

if __name__ == "__main__":
    solve()
```このソリューションでは、まず各文字をカウントします。 禁止された部分シーケンスが`"abc"`を交換します。`'b'`そして`'c'`ブロックして形成を防ぎます。 他のすべての文字は標準のアルファベット順に出力されます。 境界エラーは、以下のカウントをチェックすることで回避されます。`'a'`、`'b'`、`'c'`スワップを適用する前はゼロ以外です。 他のすべての文字は、自然に辞書編集上の順序を維持します。

## 特殊なケース

 のために`S = "abc"`そして`T = "abc"`、アルゴリズムは禁止されたサブシーケンス パターンを検出し、出力します。`"acb"`、スワップが正しく機能することを確認します。 のために`S`欠けている`'a'`、`'b'`、 または`'c'`の場合、アルゴリズムはスワップを適用せず、辞書編集上の最小性が確実に保持されます。 のために`S`外側に文字が入っている`'a'`-`'c'`、これらはソートされた順序で追加されるため、禁止されたサブシーケンスが誤って形成されることはありません。
