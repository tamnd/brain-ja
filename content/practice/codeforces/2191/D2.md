 ## 問題の理解

 文字列が与えられています`s`長さの括弧`n`。 タスクは、次の空でない部分列をすべて考慮することです。`s`そしてそれぞれの「スコア」を計算します。 スコアは次のように定義されます。サブシーケンスが正規の括弧シーケンスでない場合、そのスコアは 0 です。正規の括弧シーケンスの場合は、辞書編集のような比較に従って、現在のシーケンスよりも「優れている」最長の正規括弧のサブシーケンスが検索されます。`(`クロージングよりも良いです`)`。 サブシーケンスのスコアは、この最良のサブシーケンスの長さになります。 最後に、これらすべてのスコアの合計を 998244353 で割った値が必要になります。 

制約は小さく、すべての制約が合計されます。`n`すべてのテスト ケースの総操作数は最大でも 100 です。これは、最悪の場合でも操作の合計数は 2 秒の制限でも許容できるため、およそ O(n^3) かそれよりわずかに高いアルゴリズムを許容できることを意味します。 

シーケンスに 1 種類の括弧しか含まれていない場合、明らかではないエッジ ケースが発生します。 例えば、`s = "("`または`s = "))))"`。 ここでのすべてのサブシーケンスは不完全または不均衡であるため、正しいスコアは 0 です。不注意な実装では、「より良い」サブシーケンスを構築しようとして、単一のサブシーケンスを誤って仮定する可能性があります。`(`有効なペアを形成できます。 

もう 1 つの注意が必要なシナリオは、シーケンスが完全に規則的である場合です。`s = "()()"`。 ここでは、すべてのサブシーケンスをチェックし、サブシーケンス自体よりも辞書編集的に優れている最長のものを正確に特定する必要があります。 この微妙な点には、長さだけでなく、位置とカウントを注意深く記録する必要があります。 

## アプローチ

 ブルートフォース手法では、次の 2^n 個の空でない部分列をすべて列挙します。`s`。 各サブシーケンスについて、それが通常の括弧シーケンスであるかどうかを確認し、すべてのサブシーケンスを再度列挙して、最も長い「より良い」サブシーケンスを見つけます。 これは原理的には正しいですが、実際には 2^100 個の部分列を生成できないため、n ≥ 20 の場合は完全に実行不可能です。 

重要な観察は、スコアが左括弧と右括弧の数とそれらの相対位置にのみ依存するということです。 サブシーケンスを生成する代わりに、動的プログラミングを使用して、特定のバランスでサブシーケンスを構築する方法の数を追跡できます。 DP 状態を定義する`dp[i][j]`最初の値を使用したサブシーケンスの数として`i`現在バランスが取れているキャラクター`j`(数`(`マイナスの数`)`これまでのところ）。 次に、次の括弧を含めるかスキップすることで、これを更新できます。 右括弧に遭遇した場合、プラスの残高で終わるサブシーケンスがスコアに寄与する可能性があります。 

最適なアプローチでは、問題をプレフィックスの合計と残高に関する DP に落とし込み、すべてのサブシーケンスの寄与を明示的に列挙することなく効率的にカウントします。 また、各州が寄与する合計スコアを保存するための並列配列も維持します。 次に、有効な状態を合計し、最後に残高がゼロになることによって合計が計算されます。

 ## アルゴリズムのチュートリアル

 1. DP アレイを初期化する`dp[i][j]`どこ`i`範囲は 0 ～ n であり、`j`0からnまで。 ここ`dp[i][j]`最初のサブシーケンスの数を表します`i`バランスのとれたキャラクター`j`。 初期化もする`score[i][j]`これらのサブシーケンスのスコアの合計を保存します。 
2.ベースケースを設定する`dp[0][0] = 1`空のサブシーケンスの残高がゼロであるためです。`score[0][0] = 0`。 
3. 文字列を左から右に繰り返します。 キャラクターごとに`s[i]`そして可能なバランスごとに`j`0からnまで:

 - もし`s[i]`は`(`、スキップすることもできます（そのままにしておきます）`dp[i+1][j] += dp[i][j]`そして`score[i+1][j] += score[i][j]`) またはそれを含めます (残高を増やす:`dp[i+1][j+1] += dp[i][j]`そして`score[i+1][j+1] += score[i][j]`）。 
- もし`s[i]`は`)`、次の場合にのみスキップまたは含めることができます。`j > 0`（開いた以上に閉じることはできません）。 含めると残高が減ります`j-1`、一致するペアを追加するとサブシーケンスが拡張されるため、スコアは 2 増加します。 それで`dp[i+1][j-1] += dp[i][j]`そして`score[i+1][j-1] += score[i][j] + 2*dp[i][j]`。 
4. すべての文字を処理した後の答えは、次の合計になります。`score[n][0]`モジュロ 998244353。最終バランスが 0 のサブシーケンスのみが、有効な通常の括弧シーケンスです。 
5. テスト ケースごとに繰り返します。 

重要な不変条件は次のとおりです`dp[i][j]`そして`score[i][j]`最初のを使用してすべてのサブシーケンスを正しく説明します`i`バランスのとれたキャラクター`j`。 各括弧を慎重に含めるかスキップし、閉じ括弧がペアを形成する場合にのみスコアを更新することで、すべての有効なサブシーケンスが合計に適切な量を寄与することが保証されます。

    print(score[n][0] % MOD)
