 ## 解決策
 ## 問題の理解

 部分的に満たされたサイズの順列が与えられています$n$、配列として表現される$a$ここで、ゼロは未知の位置を示します。 タスクは、完全な順列の数をカウントすることです。$p$と一致する$a$シーケンスを構築するときのように$f(p)$、すべての連続するトリプルの中央値を取ることによって定義されます。$p$のすべての要素$f(p)$は区別されます。 

言い換えれば、あらゆるものに対して、$i$から$1$に$n-2$の中央値を計算します。$(p_i, p_{i+1}, p_{i+2})$。 結果は新しい長さのシーケンスになります。$n-2$、この順序で数字を 2 回出現させることはできません。 入力により、最初と最後の位置がどこかに埋められることが保証されます。$1$そして$n$、これは最小値と最大値です。 

制約は次のようなものです$n$まで行くことができます$2 \cdot 10^5$、最大で$10^4$テストケースと合計$n$すべてのテストで以下を超えない$2 \cdot 10^5$。 これにより、二次関数となる解は除外されます。$n$。 おおよそ線形または線形演算のアルゴリズムが必要です。$n$テストケースごとに。 

大きな数字または小さな数字がトリプルの中央の位置を占めることを強制される場合、微妙なエッジケースが発生します。 たとえば、シーケンスに次のようなものがある場合、$1$そして$n$いくつかの未知の部分によって分離されている場合、特定の配置のみが中央値を明確に保つことができます。 ゼロを任意に埋めてから一意性をチェックする単純なアプローチは、時間の点でも正確さの点でも失敗します。 

## アプローチ

 ブルートフォースアプローチは、以下と一致するすべての順列を生成することです。$a$、計算する$f(p)$それぞれについて、明確な中央値を持つものがいくつあるかを数えます。 のために$n \sim 10^5$、があるのでこれは不可能です$n!$たとえ多くの位置が固定されていたとしても、順列は可能です。 各順列の中央値を直接計算すると、さらに次の乗算係数が追加されます。$n$、これを実行不可能にします。 

重要な洞察は、完全な順列を列挙するのではなく、数値の相対的な順序を推論することです。 トリプル内の各中央値は、ソート順で中央の要素です。 すべての中央値を区別するには、現在の中央値のすぐ隣のものだけが次の中央値に影響を与えるという事実を利用できます。 これにより、問題は、各ステップで利用可能な最大の数値を追跡し、中央値での衝突を避ける方法で貪欲に数値を割り当てるという組み合わせの配置に帰着します。 

事実上、中央値の一意性を維持するために厳格なローカル順序を維持しながら、未知の位置を残りの番号で埋める必要があるスロットとして扱うことができます。 1 と の位置$n$極値を修正し、残りの数値を埋める方法の数は、既知の要素間の間隔を考慮し、中央値を繰り返さない有効な挿入の数を数えることによって計算できます。

 ## アルゴリズムのチュートリアル

 1. すべての固定数字の位置を特定します。$a$、1とを含む$n$。 これらの位置により境界が作成され、中央値の重複を避けるために未知の数値の順序が固定数値を尊重する必要があります。 
2. 連続する固定番号間の間隔ごとに、未知のスロットの数と、これらのスロットに割り当てることができる番号の範囲を決定します。 固定位置に出現しない数字のみを使用できます。 
3. 各間隔を左から右に処理します。 固定数の後の最初の未知のスロットの場合、最初のトリプルの中央値は固定数によってすでに決定されています。 次の中央値は、一意性が保証される順序で次に大きな利用可能な数値を選択することに依存します。 これは、階乗を使用して各区間の選択肢を乗算することになります。 
4. モジュラー演算を使用して階乗と積のモジュロを計算する$998\,244\,353$。 階乗を事前計算する$n$有効にする$O(1)$間隔ごとに計算します。 
5. すべての間隔のカウントを乗算して、以下と一致する順列の合計数を取得します。$a$そして明確な中央値を持っています。 

機能する理由: 問題を固定数によって決定される間隔に分割することで、局所的な順序付けで中央値の一意性が確実に維持されます。 境界が固定されると各間隔は独立するため、カウントを乗算することが有効になります。 不変条件は、数値が素のセットから選択されるため、前の間隔で割り当てられた中央値が現在の間隔の中央値と競合しないことです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 998244353

# Precompute factorials up to 2*10^5
N = 2 * 10**5 + 10
fact = [1] * N
for i in range(1, N):
    fact[i] = fact[i-1] * i % MOD

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # collect fixed positions
        fixed = []
        for i, val in enumerate(a):
            if val != 0:
                fixed.append((i, val))
        
        fixed.sort()
        
        # intervals between fixed numbers
        result = 1
        for i in range(1, len(fixed)):
            lpos, lval = fixed[i-1]
            rpos, rval = fixed[i]
            length = rpos - lpos - 1
            available = rval - lval - 1
            if available < length:
                result = 0
                break
            # number of ways to choose positions in interval
            result = result * fact[available] % MOD
            result = result * pow(fact[available - length], MOD-2, MOD) % MOD
        print(result)
        
solve()
```最初のセクションでは階乗を事前計算して、高速な組み合わせカウントを可能にします。 次に、テスト ケースごとに、ゼロ以外の要素の位置と値を抽出し、並べ替えます。 連続する固定数値に対するループは、数値を挿入する必要がある間隔を処理します。 不明なスロットを埋めるのに十分な数があるかどうかを確認します。 そうでない場合、カウントはゼロです。 それ以外の場合は、階乗と除算の逆モジュラーを使用して方法の数を計算します。 印刷`result`gives the total number of valid permutations.
