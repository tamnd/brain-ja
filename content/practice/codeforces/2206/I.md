 ## 解決策
 ## 問題の理解

 各位置に上限があり、各要素が次の要素を除算する必要がある場合に、整数のシーケンスを構築できる方法が何通りあるかを数えています。 

より具体的に言うと、位置的には`i`私たちは値を選択します`b_i`それを超えることはできません`a_i`。 選択したら、次の値`b_{i+1}`の倍数でなければなりません`b_i`。 したがって、シーケンスは、値が常に所定の上限によって制限されながら、割り算の意味で増加するチェーンです。 

出力は、そのような有効なチェーンの総数です。 

制約は大きいです:`n`は最大 200000 であり、それぞれ`a_i`これにより、位置ごとに値を列挙したり、状態ごとにすべての約数を単純にスキャンして遷移を構築したりするアプローチは即座に除外されます。 たとえ`O(n sqrt A)`最悪の場合、1 ステップあたりの処理は数十億回のオペレーションになるため、遅すぎます。 

この構造は隠れた困難も暗示しています。制約はローカルですが、状態空間はグローバルです。 のすべての可能な値を追跡する単純な DP`b_i`値の範囲全体にわたって算術構造を利用しない限り、倍数への移行は爆発してしまいます。 

いくつかの特殊なケースでは、よくある間違いが明らかになります。 

もしすべてなら`a_i = 1`の場合、唯一の有効なシーケンスはすべて 1 であるため、答えは 1 になります。乗算分岐を誤って仮定するメソッドはすべてオーバーカウントになります。 

もし`a = [1, 2, 3, 4]`の場合、3 のような値は、境界内の倍数がほとんどないため、長いチェーンには寄与しません。 単純な「すべての約数が均等に伝播する」アプローチはここで破綻します。 

もう 1 つの微妙なケースは、`a_i`大きいが分散している: たとえば`a = [200000, 1, 200000, 1, ...]`。 小さな値が現れると、将来の状態が大きく制限されるため、答えはすぐに崩れます。 

## アプローチ

 強引なアイデアは単純明快です。 ポジションごとに、可能なすべての値を試します。`b_i`から`1`に`a_i`、前の要素との可算性を確保します。 これにより DP が定義されます。`dp[i][x]`value で終了する方法の数をカウントします`x`位置で`i`。 

からの移行`i`に`i+1`、それぞれについて`x`その寄与をすべての倍数に伝播します`y`そのような`y % x == 0`そして`y <= a_{i+1}`。 これは、割り算の制約と正確に一致するため、正しいです。 

ただし、コストは壊滅的です。 最悪の場合、すべてが`a_i = 200000`、各州`x`おおよそに貢献をプッシュします`200000 / x`値を計算し、これを合計すると`x`レイヤーごとに高調波系列を与えます。 それはもうそのくらいです`O(M log M)`ポジションごとに、`O(n M log M)`全体として、限界をはるかに超えています。 

重要な観察は、視点を逆転させることです。 「x がどこに行くのか」という観点から考えるのではなく、「x に何が貢献するのか」という観点から考えます。 値`x`位置で`i`の約数からのみ得られます`x`位置で`i-1`。 これにより、遷移が倍数から除数に切り替わり、より構造化されます。 

ここで問題は次のようになります。`x`、すべての有効な約数からの寄与を合計したい`d`の`x`。 約数の数は平均して小さいため、200000 までのすべての数値の約数を事前計算して再利用できます。 

残りの課題は、制約の下で有効な状態を維持することです。`b_i ≤ a_i`。 これは、値に対するカウントを追跡し、ある位置から次の位置に移動するときに寄与をクリアすることで処理できます。 

これにより、除数集約による値の頻度に対する DP が得られます。

 ## アルゴリズムのチュートリアル

 1. までのすべての整数の約数のリストを事前計算します。`max(a_i)`。 

これにより、任意の値のすべての有効な先行データに高速にアクセスできます。 
2. DP アレイを維持する`dp[x]`value で終わる有効なシーケンスの数を表す`x`現在の位置で。 
3.初期化`dp[x] = 1`みんなのために`1 ≤ x ≤ a_1`、境界内の開始値は有効で独立しているためです。 
4. 次のポジションごとに`i`:

 新しい配列を構築する`ndp`ゼロに初期化されます。 
5. 各値について`x`から`1`に`max(a_i)`:

 あらゆる約数について`d`の`x`、 追加`dp[d]`の中へ`ndp[x]`。 

これにより、前の値が現在の値を除算する必要があります。 
6. すべての遷移を計算した後、制約を適用します。`b_i ≤ a_i`すべてをゼロにすることで`ndp[x]`どこ`x > a_i`。 
7. 交換`dp`と`ndp`そして続けます。 
8. すべての位置を処理した後、次のすべての値を合計します。`dp`答えを得るために。 

重要な微妙な点は、割り算が整数に対する半順序を定義し、DP は基本的に、現在の最大許容値で枝刈りしながら、このポセットに沿って上向きに重みを伝播していることです。 

### なぜ効果があるのか

 それぞれのステップで`i`、`dp[x]`値に到達する有効な方法の数を正確に数えます`x`位置までのすべての制約の下で`i`。 トランジションにより、次で終了するシーケンスが確実に実行されます。`x`ステップで`i`ステップの約数から来ている必要があります`i-1`、まさにその条件です`b_{i-1} | b_i`。 枝刈りステップでは、`b_i ≤ a_i`したがって、無効な状態は残りません。 すべての有効なシーケンスにはこれらの遷移を通る固有のパスがあるため、過剰カウントや省略は発生しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    maxA = max(a)

    # precompute divisors
    divisors = [[] for _ in range(maxA + 1)]
    for i in range(1, maxA + 1):
        for j in range(i, maxA + 1, i):
            divisors[j].append(i)

    dp = [0] * (maxA + 1)

    # initialize
    for x in range(1, a[0] + 1):
        dp[x] = 1

    # DP over positions
    for i in range(1, n):
        ndp = [0] * (maxA + 1)
        limit = a[i]

        for x in range(1, limit + 1):
            total = 0
            for d in divisors[x]:
                total += dp[d]
            ndp[x] = total % MOD

        dp = ndp

    print(sum(dp) % MOD)

if __name__ == "__main__":
    solve()
```この実装では約数を 1 回事前計算しますが、ステップごとに再計算するとすぐに時間制限を超えてしまうため、これは非常に重要です。 DP 配列には、最大制約までのすべての値のカウントが保存されます。 

各位置で、現在の値で許可される値の遷移のみを計算します。`a[i]`。 これにより、無効な状態が伝播することがなくなります。 

最終的な合計は、考えられるすべての終了値を集計します。 

## 実用的な例

 ### 例 1

 入力:```
2
2 4
```私たちは追跡します`dp[x]`各ステップの後に。 

| ステップ | dp 状態 |
 | --- | --- |
 | 初期化 | [0,1,1,0,0] |
 | i=2 | 値 ≤ 4 への遷移を計算する |

 遷移の計算:

 | × | 約数(x) | DP への貢献 | ndp[x] |
 | --- | --- | --- | --- |
 | 1 | [1] | 1 | 1 |
 | 2 | [1,2] | 2 | 2 |
 | 3 | [1] | 1 | 1 |
 | 4 | [1,2,4?] しかし、4 は無効な初期 dp(4)=0 | 2 | 2 |

 最終的な dp 合計 = 1 + 2 + 1 + 2 = 6。 

これにより、3 のような値は、チェーンを強く拡張しない場合でも、依然として独立した選択肢として後の位置に現れる可能性があるため、有効なままであることが確認されます。

 入力:```
3
1 2 2
```| ステップ | dp 状態 |
 | --- | --- |
 | 初期化 | [0,1,0,0] |

 ## 特殊なケース

 次のような完全に制約されたシーケンス`a = [1,1,1,...]`すべての DP 状態を単一の値に集約します。 初期化セットのみであるため、アルゴリズムはこれを処理します。`dp[1] = 1`1 の約数は 1 だけであるため、すべての遷移でそれが維持されます。 

次のようなスパース制約シーケンス`a = [200000, 1, 200000]`DP を位置 2 で強制的に状態 1 のみに折りたたんでから、再展開します。 すべての値に除数 1 が含まれているため、除数ベースの遷移は依然として機能し、すべての有効なシーケンスが再び拡張される前に一貫した基本状態を通過することが保証されます。 

小さな数値が多く含まれるケースでは、すべての数値にわたる約数の合計が高調波動作によって制限され、爆発的に増加しないため、除数リストの効率性が維持されます。
