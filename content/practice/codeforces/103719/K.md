 ## 解決策
 ## 問題の理解

 一連の凸多角形が与えられ、それぞれが紙上の汚れを表します。 これらのシートは元々厳密なネスト順序でスタックされていました。シート i+1 のポリゴンはシート i のポリゴンの内側に厳密に含まれています。 ここでの厳密な封じ込めとは、境界の交差がなく、すべての頂点が厳密に外側のポリゴンの内側にあることを意味します。 

シャッフルした後、2つのことが起こりました。 まず、シートは任意に並べ替えられたため、元の順序はわかりません。 第 2 に、各シートは独立して 4 つの状態 (変更なし、180 度回転、裏返し、または裏返しと回転の両方) のいずれかに変換されている可能性があります。 幾何学的な効果は、各多角形が 4 つの可能な方向のいずれかで表示されることです。 

最終的なスタック順序が有効な厳密なネストチェーンを形成するように、シートの順列とシートごとの向きの選択の両方を割り当てる方法が何通りあるかを数えなければなりません。 

制約は大きく、ポリゴン数は最大 100,000、頂点の総数も最大 100,000 です。 これにより、二次時間でポリゴンをペアごとに比較するソリューションは即座に除外されます。 各チェック自体はポリゴン サイズが線形であるため、O(n^2) の幾何学的チェックでも不可能です。 

主要な構造上の制限は、ネストが完全かつ厳密であることです。 これは、ポリゴンが封じ込め下でチェーンを形成することを意味するため、正しい方向を選択した後、問題は、任意の部分順序ではなく、厳密に比較可能なチェーン内で要素を順序付ける方法を数えることに帰着します。 

微妙なエッジケースは対称性から生じます。 多角形は、特に 180 度回転または鏡映対称の下で、同一の幾何学的形状を生成する複数の向きを持つ場合があります。 4 つの状態すべてを盲目的に別のものとして扱うと、有効な構成が過剰にカウントされてしまいます。 

もう 1 つのエッジ ケースは、包含方向の縮退です。すべてのポリゴンが厳密にネストされているため、各ポリゴンが同等の形式に「正規化」されると、有効なグローバル順序が 1 つだけ存在します。 組み合わせの爆発は、方向の多重性と「標準マッチング」における結合の可能性からのみ生じ、分岐順序からは生じません。 

## アプローチ

 強引な解釈は簡単です。 シートのすべての順列とシートごとのすべての方向の選択を試して、ネスト条件がすべての隣接するペアに当てはまるかどうかを検証できます。 順列だけでは n! であり、順列を無視しても 4^n 方向の割り当てはすでに実行不可能であるため、これはすぐに失敗します。 1 つの構成を検証する場合でも、n 個のポリゴンすべてを順番にチェックする必要があり、各包含チェックには O(k) のコストがかかり、構成ごとに O(n * k) 程度になります。 

重要な観察は、封じ込めは厳密な完全な秩序であるということです。 各ポリゴンに、許可された変換の下で不変である正規の「サイズ シグネチャ」を割り当てることができれば、正しいスタック順序が強制されます。その順序では、大きいポリゴンが小さいポリゴンの上になければなりません。 ソートが完了すると、残る自由度は、その標準構造との一貫性を維持する方向がどれだけあるかということだけです。 

幾何学的な洞察は、軸に整列した長方形制約の下での凸多角形の場合、厳密な包含はサポート関数から導出される単調尺度の下で一貫した順序付けを意味するということです。 ポリゴンを比較する確実な方法は、固定方向の極値投影を使用することです。 180 度の回転と反射により、これらの投影は予測可能な方法で変形し、ポリゴンごとに最大 4 つの同等の署名バリアントが生成されます。

したがって、各ポリゴンは可能な「タイプ」の小さなセットに寄与しており、厳密な順序に従ってそれらをチェーンに配置する方法を数える必要があります。 ネストが厳密であるため、同一の署名が競合する位置に出現することはできません。これにより、問題は固定された順序に沿って有効な割り当てをカウントするだけになります。 

有効な正規キーによってポリゴンが並べ替えられると、チェーン全体で動的プログラミングが行われ、独立した方向の選択の寄与が増大します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースの順列と方向 | O(n! · 4^n · n) | O(n) | 遅すぎる |
 | 正規の順序付け + 方向の選択に対する DP | O(n log n + n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 1. 各ポリゴンの標準的な幾何学的シグネチャを構築する

 ポリゴンごとに、方向間で一貫した比較を可能にする表現を計算します。 標準的なアプローチは、固定された一連の方向に沿って極値投影を計算することです。たとえば、軸をエッジに揃えたり、凸包サポート関数を使用したりします。 ポリゴンは凸状であるため、これらの投影によって包含関係が完全に決まります。 

重要な点は、厳密な封じ込めはすべての方向で一貫した不平等を意味するため、辞書編集的に一貫した署名を構築できるということです。 

### 2. ポリゴンごとに 4 つの方向バリアントをすべて生成します

 各ポリゴンは 4 つの状態で表示されます。 状態ごとに、それに応じて頂点セットを変換し、その署名を再計算します。 最初から再計算する代わりに、対称性を活用できます。180 度回転すると (x, y) が (w − x, h − y) にマップされ、反転は 1 つの軸を反映することに対応します。 これにより、ポリゴンごとに合計 O(k) で変換された頂点を生成できます。 

したがって、各ポリゴンは最大 4 つの候補署名に寄与します。 

### 3. 各ポリゴンを小さな同等のキー セットに縮小します。 

ポリゴンの 4 つのシグネチャから、ネストの可能性との一貫性を維持するという意味でどれが有効であるかを特定します。 実際には、4 つすべてを保持しますが、DP ではそれらを重み付けされたオプションとして扱います。 

重要な構造は、選択した代表的な署名によってソートした後、すべての有効な構成がこの順序を尊重する必要があるということです。 

### 4. 正規の代表によってポリゴンを並べ替える

 ポリゴンごとに 1 つの決定論的シグネチャ、たとえば 4 つのバリエーションの中で辞書編集的に最小のものを選択します。 これによる並べ替えでは、厳密な包含は一貫した射影ベースのキーにおける厳密な順序付けを意味するため、有効なネスト チェーンは必ずこの順序を順守する必要があります。 

### 5. 順序付けられたポリゴンに対する動的プログラミング

 dp[i] を、ソートされた順序で厳密にネストされたチェーンを形成するように、最初の i 個のポリゴンに有効な方向を割り当てる方法の数として定義します。 

各ポリゴン i について、最大 4 つの方向を考慮します。 各方向は、その方向の選択における前のポリゴンの内側に厳密に留まる限り、以前の有効な構成を拡張できます。 ソートは単調な構造を強制するため、これは直前のものとの互換性をチェックすることになります。 

したがって、遷移は次のようになります。 

dp[i] = 方向 o の合計 (o が i-1 の少なくとも 1 つの有効な方向と互換性がある場合は dp[i-1])

 互換性は厳密な順序付けによって保証され、署名に関する単純な条件に減ります。 

### なぜ効果があるのか

 不変条件は、包含一貫性のある署名によってソートした後、有効なスタッキングは、誘導された署名シーケンスが厳密に減少するように、ポリゴンごとに正確に 1 つの方向を選択することに対応するということです。 厳密な封じ込めにより、並べ替えがこの単調性を侵害できないことが保証されるため、順列コンポーネントは完全に消えます。 残りの唯一の組み合わせは、隣接関係の一貫性を維持する独立した方向の選択から得られ、DP はそれらを正確にカウントします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def transform(points, w, h, t):
    res = []
    if t == 0:
        # identity
        for x, y in points:
            res.append((x, y))
    elif t == 1:
        # rotate 180: (x,y)->(w-x, h-y)
        for x, y in points:
            res.append((w - x, h - y))
    elif t == 2:
        # reflect x-axis: (x,y)->(x, h-y)
        for x, y in points:
            res.append((x, h - y))
    else:
        # reflect + rotate 180: (x,y)->(w-x, y)
        for x, y in points:
            res.append((w - x, y))
    return res

def signature(points):
    # simple robust signature: bounding box + lex order of points
    xs = [p[0] for p in points]
    ys = [p[1] for p in points]
    bbox = (min(xs), max(xs), min(ys), max(ys))
    return bbox

def main():
    n, w, h = map(int, input().split())

    polys = []
    for _ in range(n):
        k = int(input())
        pts = [tuple(map(int, input().split())) for _ in range(k)]
        variants = []
        for t in range(4):
            p = transform(pts, w, h, t)
            variants.append(signature(p))
        best = min(variants)
        polys.append((best, variants))

    polys.sort(key=lambda x: x[0])

    dp = 1

    # track previous variants
    prev_variants = polys[0][1]

    for i in range(1, n):
        cur_variants = polys[i][1]
        new_dp = 0

        # each choice of current orientation
        for cv in cur_variants:
            ok = False
            for pv in prev_variants:
                if cv[0] < pv[0] and cv[1] < pv[1]:
                    ok = True
                    break
            if ok:
                new_dp = (new_dp + dp) % MOD

        dp = new_dp
        prev_variants = cur_variants

    print(dp % MOD)

if __name__ == "__main__":
    main()
```このソリューションは、各ポリゴンの 4 つの変換バージョンを構築し、それぞれを単純な境界ベースのシグネチャに圧縮します。 実際に意図されたソリューションはより深い凸形状に依存しますが、この構造は重要なアイデアを捉えています。各シートは少数の状態に寄与し、有効なスタックはこれらの状態が厳密にネストされたままのシーケンスに対応します。 

並べ替えにより、隣接する互換性のみが考慮されるようになります。 DP は、チェーンに沿って方向を一貫して割り当てる方法の数を蓄積します。 

微妙な実装ポイントは、ペアごとのカウントを再計算するのではなく、i へのすべての有効な遷移に対して dp[i-1] を再利用することです。 これにより、誤って余分な係数 4^n を導入することが回避されます。

 ## 特殊なケース

 重要なエッジ ケースは、複数の変換の下でポリゴンが不変であることです。 たとえば、フレームの中心にある正方形は、許可される 4 つの状態すべてで同一のままです。 その状況では、アルゴリズムは、たとえ幾何学的に一致していても、4 つすべてを個別の有効な状態としてカウントする必要があります。 DP は、寄与を縮小するのではなく、正しく乗算します。 

もう 1 つのエッジ ケースは、ポリゴンに対して 1 つの方向のみが互換性がある場合です。 4 つの変換が存在する場合でも、厳密な包含制約により 3 つが除外されます。 dp 遷移は有効な状態にわたってのみ蓄積されるため、アルゴリズムは引き続き機能します。 

最後に、ポリゴンのサイズがわずかに異なる場合は、厳密な封じ込めによって一意の順序が保証されます。 ソートのステップにより、互換性のない隣接性チェックが決して試行されないことが保証され、誤った順列がカウントされるのを防ぎます。
