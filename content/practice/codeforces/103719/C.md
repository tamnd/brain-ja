 ## 解決策
 ## 問題の理解

 長さ n の配列が与えられ、インデックスの増加シーケンスを選択することによって定義されたサブシーケンスを調べます。 選択したサブシーケンスごとに、値のマルチセットを取得し、その中に現れない最小の非負の整数である mex を計算します。 サブシーケンスは、選択されたすべての要素がこの mex 値から最大 1 の距離内にある場合にのみ有効であるとみなされます。 

タスクは、この条件を満たす空ではないサブシーケンスの数を数え、すべての可能なインデックス選択を引き継ぎ、998244353 を法とする答えを返すことです。 

n が 100000 までの制約により、O(n²) またはサブシーケンスの組み合わせ列挙が不可能になります。 O(n log n) のソリューションであっても、サブシーケンスごとの推論を避ける必要があります。 この構造は、mex が有効なセットに現れることができる整数を強く制限するため、mex が固定されると、値の条件によって検索空間が大幅に崩壊することを示唆しています。 

微妙な点は、この条件が 2 つのことを結合していることです。1 つは mex に近い値のメンバーシップ、もう 1 つは mex 自体の定義であり、どの値が存在するか存在しないかによって決まります。 このフィードバック ループは、素朴な推論が通常破綻する場所です。 

よくある落とし穴は、値がいくつかの候補 mex の周囲の狭い範囲に制限されると、どのサブセットでも機能すると想定してしまうことです。 これは、すべての小さい値が少なくとも 1 回出現する必要があるという mex 要件を無視します。 

別の失敗モードは、同じサブシーケンスが複数の mex 値に対応できないことを確認せずに、異なる mex 値からの寄与を混合することです。 ここで、mex は構造を一意に決定するため、正しく特徴付けられれば素のカウントは安全です。 

## アプローチ

 この強引なアイデアは、すべてのサブシーケンスを列挙し、それぞれの mex を計算することです。 これによりすでに 2^n 個の候補が得られ、サブセットごとの mex の計算コストは​​最大 O(n) となり、実行不可能な指数関数的爆発につながります。 

重要な観察は、有効なサブシーケンスの mex 値を大きくすることはできないということです。 この制約により、サブシーケンス内のすべての要素が {M-1, M, M+1} 内に収まるようになります。 同時に、mex M は、0 から M-1 までのすべての整数が存在し、M が存在しないことを必要とします。 これら 2 つの条件は非常に制限的です。 

M が 2 以上の場合、0 が出現する必要があるという要件は、0 を含まない許容値セット {M-1, M+1} と競合します。これにより、0 と 1 を除くすべての mex 値が即座に削除されます。 

この崩壊により、問題は 2 つの独立した計数問題 (mex 0 の部分列のカウントと mex 1 の部分列のカウント) に縮小されます。 

mex 0 の場合、0 は存在しない必要があり、距離条件によりすべての要素が {0,1} 内に存在する必要があり、サブシーケンスは 1 のみで構成されます。 

mex 1 の場合、0 は少なくとも 1 回出現する必要があり、1 は存在しない必要があり、値は {0,2} に存在する必要があります。 これは、2 つの独立したカテゴリにわたる標準的な組み合わせ数になります。

 | Mex 分解 (0 と 1 のみ) | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 まず配列の要素を値で分類しますが、重要なのは値 0、1、2 だけです。 この範囲外の値は、条件 |a[i] − M| に違反するため、有効なサブシーケンスに属することはできません。 可能な両方の mex 値について ≤ 1。 

### 1. 周波数を数える

 c0、c1、c2 を値 0、1、2 の出現数として計算します。 

### 2. mex 0 で部分列を数える

 0 が存在せず、1 が存在する場合、サブシーケンスは mex 0 になります (そうでない場合、mex は 0 になります)。ただし、距離制約により、すべての要素が {0,1} 内に存在することが強制されます。 これらを組み合わせると、0は現れず、1だけが残ります。 空でない 1 のサブセットはすべて有効です。

したがって、そのような部分列の数は 2^{c1} − 1 となります。 

### 3. mex 1 で部分列を数える

 mex 1 の場合、0 は少なくとも 1 回出現し、1 は存在しなければなりません。 距離制約では、{0,2} の値のみが許可されます。 したがって、すべての c0 + c2 位置から任意の部分列を選択しますが、0 を含まない部分列は除外する必要があります。 

これらの要素のサブシーケンスの合計は 2^{c0+c2} で、0 のないサブシーケンスは 2^{c2} です。 したがって、寄与率は 2^{c0+c2} − 2^{c2} となります。 

### 4. 寄付金の合計

 最終的な答えは、2 つの独立したケースの合計です。 

### なぜ効果があるのか

 mex が固定されると、許容される値の範囲はその周囲の厳密な間隔になり、mex 定義によりすべての小さい値の存在が強制されます。 これにより、実行可能な mex 値は 2 つだけ残ります。 各有効なサブシーケンスはその mex を一意に決定するため、mex による分割により素のセットが作成され、二重カウントが回避されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

n = int(input())
a = list(map(int, input().split()))

c0 = c1 = c2 = 0
for x in a:
    if x == 0:
        c0 += 1
    elif x == 1:
        c1 += 1
    elif x == 2:
        c2 += 1

# mex = 0: non-empty subsets of ones
ans0 = (modpow(2, c1) - 1) % MOD

# mex = 1: subsets of {0,2} with at least one 0
ans1 = (modpow(2, c0 + c2) - modpow(2, c2)) % MOD

print((ans0 + ans1) % MOD)
```コードはまず、配列を 3 つの関連する周波数カウンターに圧縮します。 それ以外はすべて純粋な組み合わせ論です。 べき乗剰余演算は、必要な係数の下でサブセット数を効率的に計算するために使用されます。 

減算ステップでは空または無効なケースの除外が処理されるため、各項は導出されたカウント式と直接一致します。 

## 実用的な例

 ### 例 1

 入力を考慮してください。```
n = 4
a = [0, 2, 3, 2]
```c0 = 1、c1 = 0、c2 = 2を計算します。 

mex 0 の場合、1 のみで構成される部分列を数えますが、1 がないため、ans0 = 0 になります。 

mex 1 の場合、{0,2,2} を処理します。 部分列の合計: 2^3 = 8。0 のないものは {2,2} のみを使用し、2^2 = 4 となります。つまり、ans1 = 4。 

最終的な答えは 4 です。 

これは、有効なサブシーケンスとは、少なくとも 1 つの 0 と 2 のサブセットを正確に含むものであるという事実と一致します。 

### 例 2```
n = 3
a = [1, 1, 1]
```ここで、c1 = 3、c0 = c2 = 0です。 

mex 0 の場合、1 の空でないすべてのサブセットが有効であり、2^3 − 1 = 7 となります。 

mex 1 の場合、ゼロは存在しないため、有効なサブシーケンスは存在しません。 

最終的な答えは 7 です。 

これは、ソリューションがケース間の相互作用なしに寄与を明確に分離していることを示しています。

 ## 特殊なケース

 配列に値 1 のみが含まれている場合、許可範囲に違反する要素はなく、0 が存在しないため mex は自動的に 0 になるため、mex 0 式は空ではないすべてのサブセットを正しくカウントします。 

0 が存在しない場合、{0,2} のすべての候補サブセットが 0 を含むという要件を満たすことができないため、mex 1 の寄与はゼロになり、減算 2^{c0+c2} − 2^{c2} は正しくゼロになります。 

2 より大きい値が出現した場合、これらの値はすべての有効なサブシーケンスから暗黙的に除外されます。これは、これを含めると、考えられる両方の mex 値の距離制約に違反するため、それらは何も寄与せず、カウント削減で安全に消えます。
