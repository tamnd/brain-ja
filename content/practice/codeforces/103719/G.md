 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times m$このグリッドでは、各セルが最終的に壁としてマークされるか、空のままになります。 グリッドが直接与えられる代わりに、対角線の 2 つの族に対するパリティ制約が与えられます。 

1 つのファミリーは右上がりの対角線で構成され、もう 1 つのファミリーは右下に向かう対角線で構成されます。 各ファミリーの各対角線は一連のセルをカバーしており、そのような対角線ごとに、その上の壁の数が偶数でなければならないか奇数でなければならないかがわかります。 タスクは、これらのパリティ制約をすべて満たすグリッド内の壁位置のセットを構築するか、構築が存在しないことを報告することです。 

入力構造からの重要な観察は、すべてのセルが各ファミリーのちょうど 1 つの対角線に寄与しているということです。 したがって、各セルは正確に 2 つのパリティ方程式に参加します。 これは、次の線形制約のシステムを直ちに示唆します。$\mathbb{F}_2$ここで、各セルは壁であるかどうかを示すバイナリ変数です。 

制約は大規模なシステムを意味します。$n + m - 1$各対角ファミリの方程式なので、$2(n+m)$合計の制約は最大ですが、$nm$変数。 以来$n, m$と同じ大きさにすることができます$10^5$、グリッドのサイズは次のとおりです。$10^{10}$したがって、すべてのセルを個別に明示的に考慮する解決策は不可能です。 

単純な解釈では、各セルを大規模な線形システムの変数として扱い、ガウス消去法によって解決しようとします。 これは、変数の数と、構造が非常にまばらであるにもかかわらず実現するには大きすぎるため、実行不可能です。 

制約が一貫していない場合、より微妙なエッジ ケースが発生します。 たとえば、両方の対角システムが個別には一貫しているように見えても、一緒になると単一のセルで矛盾が生じる場合、対角ファミリごとに不注意に独立して構築すると失敗します。 のような小さなインスタンス$n = m = 2$これはすでに明らかになっている可能性があります。慎重に選択した 1 つの不一致を除いてすべてのパリティをゼロに設定すると、各ファミリだけでは局所的には問題ないように見えても、システムが満足できなくなります。 

課題は、各セルがちょうど 2 つの対角線によって制約されるという事実を利用し、グローバル システムをローカルな整合性伝播の問題に変えることです。 

## アプローチ

 2 番目の対角ファミリーをしばらく無視すると、最初のファミリーだけは簡単です。パリティを満たすために各対角の最後のセルを除く任意の値を選択して、対角に沿ってセルを貪欲に割り当てることができます。 独立した 2 番目の家族にも同じことが当てはまります。 問題は、2 つの割り当てがすべてのセルで同時に一致する必要があることです。 

ブルート フォース ビューでは、すべてのセルをバイナリ変数として扱い、次のシステムを構築します。$2(n+m)$方程式。 これをガウス消去法で解く$nm$変数を使用するには、妥当な複雑さをはるかに超えた、実行不可能な数のエントリの保存と処理が必要になります。 

重要な構造的洞察は、各セルがちょうど 1 つの直上対角線と 1 つの右下対角線の交差点に位置するということです。 これは、セルの値が 2 つの独立したパリティ累積によって同時に決定されることを意味し、一貫性とは、誘導された両方の値が一致することを保証することになります。 

各対角制約を、その対角に沿ったプレフィックス XOR 条件として再解釈できます。 一貫した順序で対角線を処理すると、値を貪欲に割り当て、セルが 2 つの矛盾する要件を受け取ったときに矛盾を即座に検出できます。 これにより、問題は大域線形システムから、各ノード (セル) が制約空間で次数 2 を持つグラフ状の伝播に縮小されます。 

方程式をグローバルに解く代わりに、対角端の端点から値を伝播し、1 つのファミリーから誘導されたセル値を計算し、もう 1 つのファミリーに対して検証します。 両方の誘導された割り当てがどこでも一致する場合にのみ、構築は成功します。

 ## アルゴリズムのチュートリアル

 両方向の対角線にインデックスを付けます。 直立対角線の場合、各対角線が定数に対応していることがわかります。$i - j$。 右下の対角線の場合、それぞれは定数に対応します$i + j$。 

両方の対角ファミリでパリティ伝播を使用して一貫した割り当てを構築します。 

### ステップ

 1. 右上対角制約のみを使用して、すべてのセルに値を割り当てます。 それぞれの直角対角線について、そのセルを順番に走査し、累積 XOR が必要なパリティと一致するように値を割り当てます。 これにより、暫定的なグリッドが作成されます。 
2. この暫定グリッドから右下の対角パリティが何になるかを独立して計算します。 右下の対角ごとに、割り当てられたすべてのセルの XOR を実行し、必要なパリティと比較します。 
3. 右下の制約がすべて満たされている場合は、値 1 を持つすべてのセルを壁として出力します。 いずれかの対角線が失敗すると、システムに一貫性がなく、-1 が出力されます。 

重要な部分は、最初に 1 つのファミリだけを使用してグリッドを修正できる理由です。 その理由は、直立対角線がすべてのセルを分割するため、内部矛盾がなくなるまで完全な割り当てを定義するためです。 完全な割り当てが存在すると、2 番目のファミリーがグローバルな一貫性の検証ステップになります。 

### なぜ効果があるのか

 各対角制約はその対角上のすべてのセルの XOR を固定するため、各セルは直立対角割り当てプロセスによって一意に決定されます。 走査順序を選択し、対角線ごとに最後のセルを除くすべてのセルを固定することにより、すべての対角線制約が正確に満たされることが保証されます。 これにより、明確に定義されたバイナリ グリッドが生成されます。 

2 番目の対角線ファミリーは一貫性フィルターとして機能します。 有効な解が存在する場合、最初の族の一貫した完了によって引き起こされる構築は、2 番目の族も満たさなければなりません。これは、両方が同じ線形システムを記述するためです。$\mathbb{F}_2$。 2 番目のファミリーに矛盾が現れる場合、それはシステムにグローバルな解決策がないことを意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    # build grid via up-right diagonals (i-j constant)
    # diagonals indexed by d = i - j + (m-1)
    diag = [[] for _ in range(n + m - 1)]

    for i in range(n):
        for j in range(m):
            diag[i - j + (m - 1)].append((i, j))

    grid = [[0] * m for _ in range(n)]

    # satisfy first diagonal family
    for d in range(n + m - 1):
        cells = diag[d]
        xr = 0
        for idx, (i, j) in enumerate(cells):
            if idx + 1 == len(cells):
                grid[i][j] = xr ^ a[d]
            else:
                grid[i][j] = 0
                xr ^= grid[i][j]

    # verify second family
    diag2 = [[] for _ in range(n + m - 1)]
    for i in range(n):
        for j in range(m):
            diag2[i + j].append((i, j))

    for d in range(n + m - 1):
        xr = 0
        for i, j in diag2[d]:
            xr ^= grid[i][j]
        if xr != b[d]:
            print(-1)
            return

    cells = []
    for i in range(n):
        for j in range(m):
            if grid[i][j]:
                cells.append((i + 1, j + 1))

    print(len(cells))
    for r, c in cells:
        print(r, c)

if __name__ == "__main__":
    main()
```実装では、直立対角を明示的に構築し、各対角がパリティ制約を満たすように値を割り当てます。 各対角線の最後のセルは、必要なパリティと一致させるために必要な XOR をすべて吸収します。 

この施工後、グリッドを固定します。 次に、すべての右下の対角線を再計算し、それらが指定されたパリティ制約に一致するかどうかを確認します。 不一致が見つかった場合、関数はすぐに -1 を返します。 

主な微妙な点は、建設中に両方の家族を同時に満足させようとしていないことです。 それには、結合システムを解決する必要があります。 代わりに、1 つのファミリーが候補グリッドを完全に決定し、2 番目のファミリーが決定論的な検証ステップになるという事実を利用します。

| 対角線 | 処理された細胞 | 最後の前の XOR | 最後に割り当てられました | 最終的な XOR |

 グリッドを構築した後、右下の対角線を確認します。 各対角 XOR は必要な値と一致するため、解が受け入れられます。 出力には、1 が割り当てられたすべてのセルがリストされます。

| 対角線 | 細胞 | XOR |
 | --- | --- | --- |

これは、1 つの対角ファミリを満たすことがグローバルな実現可能性を保証しないことを示しています。

 ## 特殊なケース

 対角線に含まれるセルが 1 つだけの場合、重大なエッジ ケースが発生します。 その場合、アルゴリズムはそのセルを必要なパリティ値として直接割り当てます。 単一要素の対角線には自由度が存在せず、不一致があると直ちに不一致が発生するため、これは安全です。 

もう 1 つのケースは、一方のファミリーが完全にゼロであるのに、もう一方のファミリーはそうでない場合です。 この構築では依然として完全なグリッドが生成されますが、2 つのファミリに互換性がない場合、検証は失敗します。 これは、最初のファミリーが実現可能性をグローバルに制約するものではなく、解の同値クラスを代表する候補を定義するだけであることを強調しています。 

最後のエッジケースは、対角線が非常に長い長さと非常に短い長さが交互になる場合に発生します。 各対角線が独立して処理され、対角線を横切るバックトラッキングが必要ないため、貪欲な割り当ては安定したままになります。
