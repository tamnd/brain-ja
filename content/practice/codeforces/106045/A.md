 ## 解決策
 ## 問題の理解

 パックマンが 1 つのセルから開始し、食品セルに到達したいグリッドがあります。 壁が動きを妨げ、吸血鬼が他の房を占拠します。 パックマンは、できるだけ失点を少なくしながら食料に到達するルートを選択したいと考えています。 食べ物を食べると常に 500 ポイントが与えられますが、パックマンに会うことができるすべての吸血鬼はスコアを 10 ずつ減らします。 

重要な詳細は、パックマンが毎ターン最初に動き、吸血鬼が彼の後に動くということです。 吸血鬼はその場にとどまることも選択できるため、吸血鬼が同じ移動数以下で到達できるセルにパックマンが到達するとすぐに、吸血鬼はパックマンに噛みつく可能性があります。 

入力には複数のグリッドが含まれています。 各グリッドには、パックマン、食べ物、壁、吸血鬼の位置を含む完全なマップが表示されます。 各グリッドの出力は、Pacman が保証できる最大スコアです。 

すべてのテスト ケースにわたるセルの合計数は最大 10^6 です。 これにより、多くの可能なパスを探索するものはすべて除外されます。 ソリューションはグリッドのサイズが線形に近い必要があり、BFS スタイルの処理を指します。 

難しいのは、ターンをシミュレートする必要がないことを理解することです。 単純なシミュレーションでは、さまざまなパックマンのパスを試してから吸血鬼に追いかけさせますが、可能なパスの数は指数関数的に増加します。 

よくある間違いは、最短経路の長さだけを見て、近くにいるすべての吸血鬼がパックマンを捕まえると仮定することです。 例えば：```
1
3 3
P..
.V.
..F
```パックマンから食料までの最短距離は4。吸血鬼はまさに最短ルート上にいます。 正しい答えは次のとおりです。```
490
```吸血鬼はパックマンを捕まえるので、スコアは 500 - 10 です。 

もう一つの間違いは、吸血鬼からパックマンまでの距離だけを確認していることです。 例えば：```
1
3 3
P..
...
.VF
```吸血鬼はスタート地点に近づいていますが、食料への最短経路には到達していません。 正しい出力は次のとおりです。```
500
```吸血鬼は最初から近くにいる必要はありません。 重要なのは、パックマンが食料に到達する前にパックマンを迎撃できるかどうかだけです。 

## アプローチ

 ブルートフォースアプローチは、パックマンから食べ物までの可能なルートを生成することです。 すべてのルートについて、吸血鬼をシミュレートし、何人が噛みつくことができたかを数えることができます。 これはゲーム ルールに直接従うため正しいですが、グリッド内のルートの数は膨大になる可能性があります。 オープン グリッドでは、可能なパスの数が指数関数的に増加するため、小さな基板であってもこれは不可能になります。 

重要な観察は、パスが長くてもパックマンを助けることはできないということです。 ルートに迂回路またはループが含まれている場合、それを削除すると、パックマンは後のすべてのセルに早く到達します。 早く到着しても、吸血鬼が彼を捕まえるのが難しくなるだけです。 したがって、最適な戦略は常にパックマンから食べ物までの最短経路を使用します。 

ここで必要なのは、どの吸血鬼が最短経路をたどることができるかを知ることだけです。 パックマンから食料までの最短距離を D とします。セル V にいる吸血鬼は、パックマンと食料の間の最短経路上にあればパックマンを捕まえることができます。 その条件は次のとおりです。 

dist(P, V) + dist(V, F) = D

 等式が成り立つ場合、パックマンは吸血鬼が到達するのとまったく同時にその吸血鬼の独房に到達できるため、吸血鬼は噛みつくことができます。 合計が D より大きい場合、吸血鬼は最短経路上にいないため、合流点が考えられると、合計経路が最短経路よりも長くなりますが、このようなことは起こり得ません。 

したがって、問題は 2 つの BFS トラバーサルになります。 パックマンからの 1 つの BFS は、パックマンからすべてのセルまでの距離を示します。 食物からの別の BFS により、すべての細胞から食物までの距離がわかります。 次に、最短経路条件を満たす吸血鬼を単純に数えます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | O(nm) | 遅すぎる |
 | 最適 | O(nm) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. Pacman から BFS を実行します。 すべての歩行可能なセルに到達するために必要な最小移動数を保存します。 
2. 食品から開始して別の BFS を実行します。 すべての歩行可能なセルから食料までの必要最小限の移動数を保存します。 
3. パックマンから食べ物までの距離を D とします。 これは、パックマンが通る最短ルートの長さです。 
4. すべての吸血鬼セルについて、パックマンからの距離と食べ物までの距離を加えた距離が D に等しいかどうかを確認します。D に等しい場合、この吸血鬼はすべての最適なルートで避けられず、パックマンに噛みつきます。 
5. スコア 500 から開始し、避けられない吸血鬼ごとに 10 を減算します。 

効果がある理由: 吸血鬼は、パックマンが到着するまでに吸血鬼が到達できるセルを訪問した場合にのみ噛みつきます。 これが最短ルートで起こった場合、吸血鬼はその最短ルート上に横たわる必要があります。 逆に、吸血鬼が最短ルート上にある場合、パックマンは吸血鬼とまったく同じ移動数でそのセルに到達するため、吸血鬼はそこに留まって噛みつくことができます。 それらの吸血鬼を正確に数えることにより、咬傷の数を最小限に抑えることができます。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

def bfs(start, grid, n, m):
    dist = [[-1] * m for _ in range(n)]
    q = deque([start])
    dist[start[0]][start[1]] = 0

    while q:
        x, y = q.popleft()
        nd = dist[x][y] + 1

        if x > 0 and grid[x - 1][y] != '#' and dist[x - 1][y] == -1:
            dist[x - 1][y] = nd
            q.append((x - 1, y))
        if x + 1 < n and grid[x + 1][y] != '#' and dist[x + 1][y] == -1:
            dist[x + 1][y] = nd
            q.append((x + 1, y))
        if y > 0 and grid[x][y - 1] != '#' and dist[x][y - 1] == -1:
            dist[x][y - 1] = nd
            q.append((x, y - 1))
        if y + 1 < m and grid[x][y + 1] != '#' and dist[x][y + 1] == -1:
            dist[x][y + 1] = nd
            q.append((x, y + 1))

    return dist

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n, m = map(int, input().split())
        grid = []
        pac = None
        food = None
        vampires = []

        for i in range(n):
            row = input().strip()
            grid.append(row)
            for j, c in enumerate(row):
                if c == 'P':
                    pac = (i, j)
                elif c == 'F':
                    food = (i, j)
                elif c == 'V':
                    vampires.append((i, j))

        from_pac = bfs(pac, grid, n, m)
        from_food = bfs(food, grid, n, m)

        shortest = from_pac[food[0]][food[1]]
        bad = 0

        for x, y in vampires:
            if from_pac[x][y] + from_food[x][y] == shortest:
                bad += 1

        ans.append(str(500 - 10 * bad))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```最初の BFS は、パックマンが各セルに到達するために移動する必要がある距離を計算します。 2 番目の BFS は食物側から同じことを行い、任意の位置の後の残りの距離を示します。 

等価性チェックはソリューションの中核です。 セルは、始点からセルまでの距離とセルから終点までの距離を足したものが全体的な最短距離に等しい場合に、最短パスに属します。 これを吸血鬼の位置に直接適用します。 

すべての移動には等しいコストがかかるため、実装では BFS キューが使用されます。 距離配列は次のように初期化されます。`-1`、壁や到達不能なセルも自然に処理します。 パックマンの最短ルート上のセルへの到着時間は開始点からの BFS 距離とまったく同じであるため、1 つずつずれることはありません。 

## 実用的な例

 このグリッドの場合:```
1
3 3
P..
.V.
..F
```BFS 距離は次のようになります。 

| セル | パックマンより | 食べ物へ | 合計 |
 | --- | --- | --- | --- |
 | V | 2 | 2 | 4 |
 | ふ | 4 | 0 | 4 |

 最短ルートの長さは4です。吸血鬼は条件を満たしているのでカウントされます。 

スコアは次のようになります。 

| 変数 | 値 |
 | --- | --- |
 | 最短距離 | 4 |
 | 危険な吸血鬼 | 1 |
 | 最終スコア | 490 |

 このグリッドの場合:```
1
3 3
P..
...
.VF
```吸血鬼は最短ルートを歩いていません。 

| 変数 | 値 |
 | --- | --- |
 | 最短距離 | 4 |
 | パックマンからの吸血鬼の距離 | 3 |
 | 吸血鬼の食べ物までの距離 | 1 |
 | 合計 | 4 |

 この場合、吸血鬼は実際には最短経路上にあるため、それがカウントされ、答えは 490 になります。このトレースは、開始距離の確認だけでは十分ではない理由を示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(nm) | 2 回の BFS トラバーサルと 1 回のグリッドのスキャン |
 | スペース | O(nm) | 2 つの距離グリッドが保存されます。 

すべてのテストにわたるセルの合計数は 10^6 で制限されるため、線形処理は時間とメモリの制限内に無理なく収まります。 

## テストケース```python
import sys, io
from collections import deque

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    def bfs(start, grid, n, m):
        dist = [[-1] * m for _ in range(n)]
        q = deque([start])
        dist[start[0]][start[1]] = 0
        while q:
            x, y = q.popleft()
            for dx, dy in ((1,0),(-1,0),(0,1),(0,-1)):
                nx, ny = x + dx, y + dy
                if 0 <= nx < n and 0 <= ny < m and grid[nx][ny] != '#' and dist[nx][ny] == -1:
                    dist[nx][ny] = dist[x][y] + 1
                    q.append((nx, ny))
        return dist

    t = int(input())
    out = []

    for _ in range(t):
        n, m = map(int, input().split())
        grid = []
        for i in range(n):
            grid.append(input().strip())

        for i in range(n):
            for j in range(m):
                if grid[i][j] == 'P':
                    p = (i, j)
                elif grid[i][j] == 'F':
                    f = (i, j)

        a = bfs(p, grid, n, m)
        b = bfs(f, grid, n, m)

        d = a[f[0]][f[1]]
        cnt = 0

        for i in range(n):
            for j in range(m):
                if grid[i][j] == 'V' and a[i][j] + b[i][j] == d:
                    cnt += 1

        out.append(str(500 - 10 * cnt))

    return "\n".join(out)

 ## 特殊なケース

 パックマンの開始位置に吸血鬼があることは有効な入力では不可能ですが、パックマンのすぐ隣に吸血鬼があると誤解を招く可能性があります。 このアルゴリズムは初期距離のみを比較しません。 両方の BFS 距離配列を使用して、吸血鬼が最短経路上にあるかどうかを確認します。 

壁があるとパックマンがグリッド内でより長く見えるルートに移動する可能性がありますが、実際のグラフの最短パスにはすでに壁が考慮されています。 ヴァンパイアは、計算された 2 つの距離が最短ルートの長さと正確に一致する場合にのみカウントされるため、ブロックされたパスによって誤検知が発生することはありません。 

吸血鬼が多数いる場合、個別にシミュレートすることはありません。 すべての吸血鬼は、同じ 2 つの距離マップを使用して個別にテストされます。 これにより、吸血鬼の動きの組み合わせを検討するという不可能な作業が回避されます。
