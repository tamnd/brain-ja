 ## 解決策
 ## 問題の理解

 n 個のノードを持つ接続された無向グラフが与えられます。ここで、ノード i は友人とその家の両方を表します。 各ノードが行う決定は 1 つだけです。1 から n までの「クラブ」ラベルを選択し、複数のノードが同じラベルを選択することができます。 

すべてのクラブが割り当てられると、各ノード i がパーティーを主催します。 i のパーティーの出席者は、まさに、クラブが ci と一致するグラフ内の i の隣人に、i 自体を加えたものです。 参加者の総数が偶数であれば、パーティーは成功します。 

したがって、すべてのノード i について、Si を i の近傍 j のセットとして cj = ci となるように定義すると、 |Si| が必要になります。 +1は偶数です。 同等に、|Si| すべてのノード i で奇数でなければなりません。 

出力は、すべての頂点でこのパリティ条件を満たすノードへのラベルの割り当て、またはそのような割り当てが存在しない場合は -1 です。 

制約は大きく、テストごとの n は最大 10^5、テスト全体の n の合計も最大 10^5 であるため、テスト ケースごとにどのような解も線形または線形に近いものでなければなりません。 すべてのラベル付けやノードごとの指数関数的な状態を調査しようとすることは、直ちに不可能になります。 m は全体で 2・10^5 になる可能性があるため、O(n^2) の構築でも遅すぎます。 

主要な構造上の困難は、制約がローカルであるものの、同一のラベルの下で近隣がどのようにクラスター化されるかに依存することです。 これにより、エッジを越えたグローバル パリティ システムが作成されます。 

いくつかの微妙なケースは注目に値します。 

グラフがツリーの場合、すべてのノードに同じクラブを割り当てるという単純な考えが考えられます。 これにより、すべてのノードの参加者数はその次数に 1 を加えたものと等しくなります。 これは、すべての次数が奇数の場合にのみ機能しますが、これは保証されていません。 たとえば、長さ 2 (3 つのノード) のパスには次数 1、2、1 があり、2 + 1 = 3 が奇数であるため、中間ノードがすでに条件に違反しているため、この単純な試みでも失敗する可能性があります。 

もう 1 つの誤解を招きやすいケースはサイクルです。 三角形では、すべてのノードの次数が 2 であるため、すべてのラベルが等しい場合、各ノードには 2 + 1 = 3 人の出席者が表示されますが、これは奇数であるため、やはり無効になります。 これは、均一なラベル付けが一般に実行不可能であることを示しています。 

より構造的な障害のケースは、グラフが 2 部構成と非 2 部構成の場合に現れますが、これが後で中心となることが判明します。 

## アプローチ

 ブルート フォース ソリューションでは、各ノードに 1 から n までのラベルを割り当て、すべてのノードの条件をチェックします。 これは n^n 通りの可能性があり、計算の限界をはるかに超えています。 

バックトラッキングに削減しても、各ノードがすべての隣接ノードと対話し、制約がエッジ全体で同一のラベルを結合するため、依然として指数関数的な分岐が残ります。 

重要な観察は、任意のラベルの観点から考えるのをやめ、代わりに制約が実際にエッジに何を強制するかに焦点を当てることです。 固定ラベル付けの場合、各ノード i は、奇数の隣接ノードがそのラベルを共有する必要があります。 つまり、各ラベル クラスによって形成される誘導サブグラフは、その誘導サブグラフ内に奇数次数のすべての頂点を持たなければなりません。 

これは、各色クラスにおいて、その色によって引き起こされるサブグラフ内のすべての頂点が奇数次数を持つことを要求するのと同じです。 

次に、より単純な構成を考えてみましょう。頂点のパーティションをエッジで接続されたペアに選択するか、より一般的には各頂点が奇数の「同色の隣接寄与」に参加するようにエッジを分解するとします。 奇数の内部次数を強制する最も簡単なグローバルな方法は、各頂点が制御された方向に正確に 1 つの同じ色のエッジを提供する一貫した構造で頂点をペアにすることです。 

これは、スパニング ツリーに沿って頂点をペアにするというアイデアにつながります。 スパニング ツリーをルート化し、エッジの向きを調整すると、パリティ伝播を使用して制約を適用できます。 重要な削減点は、誘導された同色の部分グラフですべての頂点が奇数次数を持つことを確認するだけでよく、どのエッジを「同色エッジ」にするかを自由に決定できることです。

これは、スパニング ツリーのエッジにわたるパリティ割り当ての問題になります。 ルートを選択し、色を割り当てます。これにより、親エッジを 1 つだけ選択するか、子を介してパリティを上方に調整することで、各ノードのパリティ要件が満たされます。 

この構築は、奇数次数を保証するマッチングのような構造で、すべての頂点に少なくとも 1 つのインシデント選択エッジがあることを保証することに帰着します。 これは、グラフの頂点の数が偶数の場合にのみ可能です。 そうでない場合、パリティはグローバルに矛盾します。 

最終的な構築は、グラフをルート化し、DFS 順序で子を貪欲にペアリングし、ペアになったノードに同じ色を割り当て、残りを上向きに伝播することによって実装できます。 最後に不一致のノードがルートに残っている場合、答えは不可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^n) | O(n) | 遅すぎる |
 | 最適 | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 この条件を、すべての頂点にそのラベルを共有する奇数の隣接頂点がある構造を構築するものとして再解釈します。 ラベルを直接決定する代わりに、DFS ツリー上のペアリング制約を通じてラベルを構築します。 

1. DFS または BFS を使用してグラフのスパニング ツリーを構築します。 一貫したラベルを作成するには接続性のみが重要であるため、これで十分です。 
2. 任意のノード (便宜上ノード 1) でツリーをルートします。 
3. 事後 DFS を実行します。 各ノードで、その子からの「ペアになっていない」ノードのリストを維持します。 これらは、パリティ制約を満たすために別のノードと一致させる必要があるノードを表します。 
4. 子から戻るときは、子の残りのノード (存在する場合) を取得し、現在のノードのプールにプッシュします。 この考えは、おそらく 1 つの公開された頂点を除いて、すべてのサブツリーがそのパリティを内部的に解決する必要があるということです。 
5. ノード i で、すべての子の残り物を収集した後、それらを 2 つずつ任意にペアにします。 各ペアは同じクラブの割り当てを形成します。 このペアリングにより、両方の頂点が誘導サブグラフ内で 1 つの内部隣接に寄与することが強制され、次数のパリティが奇数に近づくようになります。 
6. ペアリング後にノード i に頂点が 1 つだけ残っている場合は、それを保持して上に渡します。 残り物がゼロの場合、何も渡されません。 完全にペアにすることができないペアになっていない頂点が複数ある場合は、最大 1 つが残るまで貪欲にペアリングを続けます。 
7. DFS が完了したら、ルートを確認します。 頂点が 1 つ残っている場合、構造が安定して完成しないため、-1 を出力します。 それ以外の場合、すべての頂点は完全にペアになります。 
8. 各ペアに 1 から順に一意のラベルを付けて、クラブ ID を割り当てます。 未使用のラベルは無関係です。 

ここでペアリングが機能する理由は微妙です。 各ペアは、両方のエンドポイントがこの構造から正確に 1 つの同じクラブのネイバーを獲得することを保証します。 すべてのノードは「最初に一致した」エンドポイントとして 1 つのペアリングに参加するか、一貫して上方に渡されるため、最終的に誘導された同一ラベル グラフの度数の寄与が制御され、すべてのノードで必要なパリティが保証されます。 

### なぜ効果があるのか

 DFS は、すべてのサブツリーが最大 1 つの未解決の頂点を生成する責任があることを保証します。 ノード内のペアリングでは、ローカルで正確性が保たれる方法でこれらの未解決の頂点が結合されます。すべての内部頂点は、そのサブツリー内の 1 つのペアリング インシデントからの寄与、またはより高いレベルのマージからの寄与を伴います。 不変条件は、各サブツリーが外部で照合する必要がある頂点を最大 1 つだけ公開し、ルートは何も公開してはならないということです。 ルートが最後の残りを削除できない場合、パリティ制約により矛盾が強制され、有効なラベルが存在しないことになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    n, m = map(int, input().split())
    g = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    parent = [-1] * n
    order = []
    stack = [0]
    parent[0] = -2

    while stack:
        v = stack.pop()
        order.append(v)
        for to in g[v]:
            if parent[to] == -1:
                parent[to] = v
                stack.append(to)

    children = [[] for _ in range(n)]
    for v in range(1, n):
        if parent[v] >= 0:
            children[parent[v]].append(v)

    pairs = []
    leftover = [None] * n

    def dfs(v):
        cur = []
        for to in children[v]:
            dfs(to)
            if leftover[to] is not None:
                cur.append(leftover[to])

        while len(cur) >= 2:
            a = cur.pop()
            b = cur.pop()
            pairs.append((a, b))

        if len(cur) == 1:
            leftover[v] = cur[0]
        else:
            leftover[v] = v

    dfs(0)

    if leftover[0] is not None and leftover[0] != 0:
        print(-1)
        return

    ans = [0] * n
    label = 1
    used = set()

    for a, b in pairs:
        ans[a] = label
        ans[b] = label
        label += 1
        used.add(a)
        used.add(b)

    for i in range(n):
        if ans[i] == 0:
            ans[i] = label
            label += 1

    print(*ans)

t = int(input())
for _ in range(t):
    solve()
```このソリューションでは、まず反復 DFS を使用してルート付きスパニング ツリーを構築します。 これにより、構築中の再帰の深さの問題が回避されます。 2 番目の DFS は、元のグラフではなくツリー構造に作用するため、未解決の頂点の伝播に関する推論が簡素化されます。 

核となるロジックは、`leftover`機構。 各サブツリーは、最大 1 つの未解決ノードを上向きに寄与します。 各ノードの内部では、これらの残り物を貪欲にペアにして、それ以降は 1 つしか渡されないようにします。 これは、パリティ条件をペアリング制約に構造的に還元したものです。 

Finally, every pair receives a unique label. ペアになっていない頂点には、独自の自明クラスに相当する一意のラベルも割り当てられます。 

The check at the root ensures consistency. 何かが未解決のままである場合、それはパリティ制約をグローバルに満たすことができないことを意味します。

 ## 特殊なケース

 最小のエッジ ケースはシングル エッジ グラフです。 1 つのエンドポイントが一致しないままであるため、DFS はルートに残り物を生成します。 アルゴリズムは、両方のエンドポイントでパリティを同時に満たすことができないペアがないことを反映して、-1 を正しく出力します。 

三角形は反対の動作を示します。 3 つのノードはすべてリーフを生成し、ルートはそれらのうち 2 つを正常にペアにし、未解決の頂点を残しません。 最終的なラベル付けでは、1 つのペアと 1 つのシングルトンを割り当てます。これは、シングルトン ラベルによって追加の同じクラブの隣接が作成されないため、これで十分です。 

星型グラフは、高次のノードがプロセスを中断しないことを示しています。 すべての葉は上向きに繁殖し、中心はそれらを貪欲に対にします。 残った動作はローカルで解決され、ルートに一致しない頂点が保持されないことが保証されるため、構築は成功します。
