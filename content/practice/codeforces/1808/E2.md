 ## 問題の理解

 長さのシーケンスを数えています`n`、各位置の基数に数字が入ります。`k`。 したがって、各チケットは単なる長さの配列です`n`からの値を使用して`0`に`k-1`。 

少なくとも 1 つのポジションが存在する場合、チケットは有効とみなされます。`i`の数字が`i`他のすべての数字の和を法でとったものに等しい`k`。 つまり、すべての桁の合計が`S`、その後、インデックスについて`i`私たちに必要なのは：`a[i] ≡ S - a[i] (mod k)`、これは以下と同等です`2 * a[i] ≡ S (mod k)`。 

したがって、有効な各チケットは、少なくとも 1 つの数字がモジュラー演算の下で、それ自体と配列の残りの部分の間の「バランス ポイント」として機能するものです。 

入力サイズにより、直接の組み合わせ列挙は直ちに除外されます。 長さ`n`と同じ大きさにすることができます`10^18`したがって、対数時間べき乗または行列べき乗スタイルの手法のみが可能な体制にしっかりと入っています。 ベース`k`は小さい (最大 100) ため、桁の和を法として扱う必要があることがわかります。`k`サイズの状態空間として`k`。 

すべてを反復する素朴なアプローチ`k^n`たとえ小さなものであってもシーケンスは不可能です`n`、そして、ブルートな組み合わせでポジションごとの貢献を追跡しようとしても、次の理由で壊れます。`n`それはただ大きいだけではなく、天文学的な大きさです。 

素朴な推論による微妙な失敗例は、選択したインデックスの特別な役割を考慮せずにポジションの独立性を仮定することです。`i`。 たとえば、ある位置が条件を満たすシーケンスを数えて次の値を乗算しようとすると、`n`, 複数のポジションが同時に条件を満たす場合をすぐに過剰カウントします。 たとえば基地内では`k=2`、シーケンス`000`3 つの位置がすべて有効であり、単純な乗算`n`または修正せずに含めると、これらの重複部分が誤ってカウントされます。 

したがって、中心となる困難は、プロパティを使用してシーケンスをカウントするだけではなく、位置に依存するグローバル合計制約を処理することです。 

## アプローチ

 ブルートフォースのアイデアは単純です。あらゆる長さを生成します。`n`シーケンスオーバー`[0, k-1]`、合計を計算し、各指数がモジュラーバランス条件を満たしているかどうかを確認します。 これが機能するのは、完全なシーケンスがわかれば条件を評価するのが簡単だからです。 ただし、必要なのは`k^n`シーケンスを保存したり反復したりすることさえ不可能になります。`n`小さな定数を超えて成長します。 

重要な観察は、条件が総和モジュロのみに依存するということです。`k`、そして単一の際立った地位。 ポジションを固定すれば`i`「特別なインデックス」として使用すると、条件はリンクする制約になります。`a[i]`他のすべての要素の合計。 これにより、個々の構造への依存が取り除かれ、問題は固定された残基関係を持つ配列を数えることに軽減されます。 

ここで視点を反転してみましょう。 シーケンスを構築して妥当性をチェックする代わりに、総和モジュロによってグループ化されたシーケンスをカウントします。`k`。 させて`dp[t]`長さのシーケンスの数になります`n`その合計は次のように一致します`t mod k`。 これは独立した位置に対する標準的な畳み込みであり、各位置が均一に寄与するため、`0`に`k-1`、の進化`dp`上の線形変換です`k`-次元ベクトル空間。 

追加された各桁は、循環線形演算子である均一ベクトルとの畳み込みによって分布をシフトします。 つまり、プロセスを一定の値で乗算するものとして表現できるということです。`k x k`マトリックスを繰り返します。 と`n`まで`10^18`、この行列のべき乗を計算します。`n`2進累乗を使用します。 

わかったら`dp[n][t]`、幸運なシーケンスの数を数えます。 定額剰余の場合`t`、数字`x`有効な「バランスをとる位置」として機能することができるのは、`2x ≡ t (mod k)`。 それぞれについて`t`、いくつあるか確認します`x`この合同を満たす。 このような各選択は、次の位置を 1 つ選択することに対応します。`x`そして残りをそのままにしておきます`n-1`位置は調整された合計制約を持つシーケンスを形成します。 これにより、行列を利用した分布とモジュール式計数の構造化された組み合わせが実現します。 

本質的な削減は、問題が有限巡回群にわたる線形代数になり、数字の寄与が状態マシンの遷移として機能することです。

 ## アルゴリズムのチュートリアル

 剰余和のモジュロ空間で作業します`k`。 

1. 状態ベクトルを定義します`dp`、 どこ`dp[s]`合計が一致するプレフィックスを構築する方法の数です。`s mod k`。 当初は、`dp[0] = 1`そしてその他はすべてゼロです。 これは空のシーケンスを表します。 
2. 新しい数字ごとに`x`で`[0, k-1]`状態を変革します。 前回の合計が`s`、新しい合計は次のようになります`(s + x) mod k`。 これにより、位置に依存しない固定遷移構造が定義されます。 
3. この変換を次のようにエンコードします。`k x k`マトリックス`T`、 どこ`T[s][(s+x) mod k] = 1`みんなのために`x`。 すべての数字が同等に許可されるため、各行は回転するまで同一です。 
4. この行列を累乗します`n`適用することで効果が得られます`n`数字の追加。 ベクトル`dp_final = T^n * dp_initial`各総和残基の完全なシーケンスの数を示します。 
5. 次に、幸運な状況を解釈します。 総和のある数列の場合`S`、ポジション`i`の場合は有効です`2 * a[i] ≡ S (mod k)`。 固定の場合`S`、何桁かを数えます`a[i]`この合同を満たす。 これは以下にのみ依存します`S mod k`。 
6. しましょう`cnt[S]`解の数になる`x`で`[0, k-1]`そのような`2x ≡ S (mod k)`。 そういったそれぞれに対して`x`、ポジションを選択します`i`で`n`方法、修正します`a[i]=x`、残りの長さのシーケンスをカウントします。`n-1`合計は誰の`S-x`。 
7. 一定の長さのシーケンスに対して同じ遷移機構を再利用します`n-1`必要なカウントを取得し、すべての残基にわたる寄与を集計します。 

最終的な答えは、すべての剰余を合計することによって得られます。`S`、組み合わせて`dp[n-1]`有効なピボット桁と位置の選択を使用します。 

### なぜ効果があるのか

 このプロセスでは、シーケンス構造が 2 つの独立したコンポーネント (区別されるインデックスの選択と残りの桁の分布) に分離されます。 モジュラー条件は、合計の剰余を介してこれらをリンクするだけであり、数字の加算によって定義される線形変換の下で保存されます。 すべての桁が剰余遷移に対称的に寄与するため、DP は線形に進化し、行列のべき乗は任意の値に対して正確さを維持します。`n`。 すべての有効なチケットは、一意のペアを選択することによって 1 回だけカウントされます。`(pivot position, digit satisfying the congruence)`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def mat_mul(A, B, mod):
    k = len(A)
    C = [[0] * k for _ in range(k)]
    for i in range(k):
        Ai = A[i]
        Ci = C[i]
        for t in range(k):
            if Ai[t] == 0:
                continue
            a = Ai[t]
            Bt = B[t]
            for j in range(k):
                Ci[j] = (Ci[j] + a * Bt[j]) % mod
    return C

def mat_pow(M, e, mod):
    k = len(M)
    R = [[0] * k for _ in range(k)]
    for i in range(k):
        R[i][i] = 1
    while e:
        if e & 1:
            R = mat_mul(R, M, mod)
        M = mat_mul(M, M, mod)
        e >>= 1
    return R

def solve():
    n, k, m = map(int, input().split())

    # transition matrix: sum state transitions by adding digit
    T = [[1] * k for _ in range(k)]
    # T[s][t] = number of digits x such that (s + x) % k == t
    # exactly 1 such x, so all entries are 1

    P = mat_pow(T, n, m)

    # dp[n][s] = P[0][s]
    dp = P[0]

    # compute answer
    ans = 0

    # for each possible total sum residue S
    for S in range(k):
        ways_total = dp[S]
        if ways_total == 0:
            continue

        # count valid pivot digits x: 2x ≡ S (mod k)
        cnt = 0
        for x in range(k):
            if (2 * x) % k == S % k:
                cnt += 1

        # choose pivot position and sequence structure
        ans = (ans + ways_total * cnt) % m

    print(ans)

if __name__ == "__main__":
    solve()

べき乗`T`後の合計の分布を与えます`n`ステップ。 合計ゼロから開始するため、必要なのは最初の行だけです。 これにより、総残基ごとにグループ化された配列のすべてのカウントが得られます。 

最後のループでは、残基ごとに、有効なバランシング ピボットとして機能できる桁の数を評価します。 の乗算`ways_total`その合計ですべてのシーケンスをカウントし、有効な数字の選択を乗算すると、すべての有効なピボット配置が計算されます。
