 ## 解決策
 ## 問題の理解

 各プレイヤーは次の内容のカードを受け取ります。`m`整数。 すべてのプレーヤーのペアについて、ゲームで獲得した金額は、カード上の対応する位置間の絶対差の合計です。 

プレイヤーの場合`i`カードの価値がある`c[i][1...m]`そしてプレイヤー`j`カードの価値がある`c[j][1...m]`、彼らの貢献は次のとおりです。$$\sum_{k=1}^{m} |c[i][k] - c[j][k]|$$順序付けされていないすべてのプレーヤーのペアにわたる合計貢献度が必要です。 

直接的な解釈は、カードのすべてのペアとカード内のすべての位置を比較することを示唆しています。 と`n`選手たちと`m`カードごとの値、すべてを調べる必要がある`n(n-1)/2`ペアも全部も`m`各ペアの列。 

重要な制約は、すべてのテスト ケースにわたる行列エントリの合計数です。$$\sum (n \cdot m) \le 3 \cdot 10^5$$これは、周囲のアルゴリズムにとって十分小さいです`O(nm log n)`、しかし大きすぎます`O(n^2 m)`いつ`n`大きいです。 たとえば、次の場合`n = 3 \cdot 10^5`そして`m = 1`、その後、`O(n^2)`アプローチには大まかに必要になります$9 \times 10^{10}$操作。 

隠された構造は、絶対差の和が列で分離できることです。 各列は、最終的な答えに独立して貢献します。 

いくつかの特殊なケースでは、簡単に間違いが発生する可能性があります。 

考慮する：```
2 1
5
5
```ペアは 1 つだけあり、その寄与は`|5-5| = 0`。 並べ替え後に値が厳密に増加することを前提とする数式では、誤って正の値が加算されてしまいます。 

考慮する：```
3 1
1
10
100
```答えは次のとおりです。```
|1-10| + |1-100| + |10-100|
= 9 + 99 + 90
= 198
```ソート後に隣接する差異のみを確認する不注意な実装は、次のような結果を招く可能性があります。`9 + 90 = 99`, これは必要な合計の半分にすぎません。 

考慮する：```
1 4
7 8 9 10
```プレーヤーのペアはまったくありません。 答えは次のとおりです。`0`。 ペアの公式を考慮せずに盲目的に適用するソリューション`n = 1`ガベージ値が生成される可能性があります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 プレーヤーのペアごとに、カードの座標を座標ごとに比較し、絶対的な差の合計を計算し、それを答えに加えます。 

これは賞金の定義と直接一致するため機能します。 問題は実行時間です。$$O(n^2 m)$$もし`n = 3 \cdot 10^5`そして`m = 1`、これは完全に不可能になります。 

重要な観察は、各列からの寄与が独立していることです。 

単一の列に焦点を当て、その列からすべての値を収集するとします。$$x_1, x_2, \dots, x_n$$このコラムの合計貢献度は次のとおりです。$$\sum_{i<j} |x_i - x_j|$$これは古典的な表現です。 並べ替え後:$$x_1 \le x_2 \le \cdots \le x_n$$絶対値が消えます。$$|x_j-x_i| = x_j-x_i \quad (j>i)$$ここで、並べ替えられた各値が正および負の頻度で現れることを考えてみましょう。 

ポジションについて`i`:$$x_i$$より大きな要素として正確に表示されます`i`倍、そして小さい要素として正確に`n-1-i`(0 ベースのインデックスを使用)。 

その正味係数は次のようになります。$$i - (n-1-i)$$同じ合計を計算する別の方法は、プレフィックス合計を使用することです。 ソートされた配列をスキャンしながら、各値について`x[i]`、以前のすべての値はすでにわかっています。 

前の要素に対するその貢献度は次のとおりです。$$i \cdot x[i] - \text{prefix}$$どこ`prefix`以前のすべての値の合計です。 

これにより、並べ替え後に列全体の寄与を線形時間で計算できるようになります。 

すべての列が独立して処理されるため、複雑さは次のようになります。$$O(m \cdot n \log n)$$制約に簡単に適合します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²m) | お(1) | 遅すぎる |
 | 最適 | O(m・n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのカードを表すマトリックスを読み取ります。 
2. 各列について、その列を収集します。`n`値を配列に入れます。 
3. Sort the column values.

 ソート後、すべてのペアの寄与は絶対値ではなく単純な減算になります。 
4.初期化`prefix = 0`。 
5. ソートされた列を左から右にスキャンします。 

現在の値については`x[i]`、以前の値はすべてそれより小さいか等しい。 
6.追加$$i \cdot x[i] - prefix$$答えに。 

これは次の合計と等しくなります。$$x[i]-x[0],\ x[i]-x[1],\ \dots,\ x[i]-x[i-1]$$それはまさに の貢献です`x[i]`以前のすべての要素が含まれています。 
7. アップデート$$prefix += x[i]$$将来の要素でもそれを使用できるようになります。 
8. すべての列に対して繰り返します。 
9. 蓄積された回答を出力します。 

### なぜ効果があるのか

 列をソートした後、すべてのペア`(i,j)`と`i < j`貢献する`x[j] - x[i]`。 加工時`x[j]`、数量$$j \cdot x[j] - \text{prefix}$$正確に追加します$$(x[j]-x[0]) + (x[j]-x[1]) + \cdots + (x[j]-x[j-1])$$これは、位置で終わるすべてのペアの合計寄与度です。`j`。 

すべての順序なしペアは 1 回だけ、つまり、より大きな並べ替えられたエンドポイントが処理されるときに現れます。 どのペアも省略されず、どのペアも 2 回カウントされません。 すべてのポジションとすべての列のこの値を合計すると、必要な合計賞金が正確に得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, m = map(int, input().split())

    a = [list(map(int, input().split())) for _ in range(n)]

    ans = 0

    for col in range(m):
        vals = [a[row][col] for row in range(n)]
        vals.sort()

        prefix = 0

        for i, x in enumerate(vals):
            ans += i * x - prefix
            prefix += x

    print(ans)
```マトリックスは 1 回だけ読み取られます。 各列について、その値を抽出して並べ替え、実行中のプレフィックス合計を使用してペアごとの差の合計を計算します。 

表現:```
ans += i * x - prefix
```がクリティカルラインです。 インデックス時`i`、まさにあります`i`以前の要素。 彼らの貢献総額は、`x`は：```
(x - v1) + (x - v2) + ... + (x - vi)
```これは次のように単純化されます。```
i * x - (v1 + v2 + ... + vi)
```その合計は次のように保存されます`prefix`。 

Python の整数は大きな値を自動的に処理するため、オーバーフローのリスクはありません。 C++ などの言語では、64 ビット整数が必要になります。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())
    out = []

    for _ in range(t):
        n, m = map(int, input().split())
        a = [list(map(int, input().split())) for _ in range(n)]

        ans = 0

        for col in range(m):
            vals = [a[row][col] for row in range(n)]
            vals.sort()

            pref = 0
            for i, x in enumerate(vals):
                ans += i * x - pref
                pref += x

        out.append(str(ans))

    sys.stdout.write("\n".join(out))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    res = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return res
