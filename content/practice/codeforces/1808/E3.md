 ## 問題の理解

 チケットは一連のものです`n`底の数字`k`、したがって、すべての位置には次の値が含まれます。`0`に`k - 1`。 

合計桁の和を法にしてみましょう`k`なれ$$S = a_1 + a_2 + \dots + a_n \pmod k.$$残りのすべての桁のモジュロの合計に等しい桁が存在する場合、チケットは幸運です。`k`。 

選択した数字が`a_i`の状態になります。$$a_i \equiv S - a_i \pmod k,$$これは以下と同等です$$2a_i \equiv S \pmod k.$$つまり、固定チケットの場合、幸運は合計額のみに依存します`S`そして、ある数字が合同の解であるかどうかについて$$2x \equiv S \pmod k.$$制約は問題の性質を完全に変えます。 長さ`n`と同じ大きさにすることができます$10^{18}$, そのため、位置を 1 つずつ処理するアルゴリズムは不可能です。 平$O(n)$遅すぎます。 ベース`k`せいぜい`2000`、これは、への依存性を示唆しています。`k`手頃な価格ですが、依存性があります`n`対数でなければなりません。 

最初のトラップは、合同の場合です。$2x \equiv S\pmod k$解決策がありません。 たとえば、`k = 4`そして`S = 1`、満足する数字がありません`2x ≡ 1 (mod 4)`。 合計額が奇数のチケットは自動的に不運になります。 

2番目の罠は、`k`が偶数である場合、合同式には 2 つの解が存在します。 たとえば、`k = 6`そして`S = 2`、$$2x \equiv 2 \pmod 6$$解決策がある`x = 1`そして`x = 4`。 一意の禁止数字を想定したカウント引数は、警告なしにオーバーカウントします。 

3 番目の罠は、次のような巨大な値です。`n`。 などの表現`(k - 1)^n`モジュロで計算する必要があります`m`高速累乗を使用します。 

## アプローチ

 ブルートフォースソリューションでは、すべてが生成されます。$k^n$チケット、合計の剰余を計算します`k`、いくつかの位置が満たされているかどうかを確認します$2a_i \equiv S$。 これは定義を直接実装しているので正しいですが、すぐに役に立たなくなります。 たとえ`k = 10`そして`n = 20`、 がある$10^{20}$チケット。 

重要な観察は、条件が総和モジュロのみに依存するということです。`k`。 固定剰余の場合`S`、セットを定義します$$U_S = \{x \in \mathbb Z_k : 2x \equiv S \pmod k\}.$$すべての数字が回避された場合、チケットは不吉です`U_S`、 どこ`S`チケットの合計金額です。 

これにより、問題は循環群の計数問題に変わります。$\mathbb Z_k$。 「合計が等しい」と表現すると、`S`" 文字の合計では、`n`すべての寄与は固有値として現れるため、無害になります。`n`-乗。 

驚くべきことは、フーリエ拡張の後、ほとんどすべての文字の寄与が消えるということです。 最終的な答えは、次の累乗のみを含む閉じた式に崩壊します。`k`、`k - 1`、`k - 2`、および単一の gcd。

 ## アルゴリズムのチュートリアル

 ### 奇数`k`いつ`k`奇妙です、`2`可逆モジュロです`k`。 

残留物ごとに`S`、方程式$$2x \equiv S \pmod k$$解決策は 1 つだけあり、それを呼び出します`cS`、 どこ`c = 2^{-1} (mod k)`。 

合計金額のアンラッキーチケット`S`桁が決して等しくないシーケンスです`cS`。 

フーリエ反転の使用$\mathbb Z_k$、アンラッキーチケットの枚数と合計`S`は$$A_S = \frac1k \sum_r \chi_r(-S) \left( k\delta_{r,0} - \chi_r(cS) \right)^n .$$すべての剰余の合計`S`、満足したキャラクターを除いてすべてのキャラクターが消えます$$(n-2)r \equiv 0 \pmod k.$$もし$$d = \gcd(n-2,k),$$まさにあります`d`そのような文字のうちの 1 つは些細な文字です。 

簡略化した後、$$F=(k-1)^n + (d-1)(-1)^n,$$どこ`F`アンラッキーチケットの枚数です。 

必要な答えは、$$k^n - F.$$＃＃＃ 平`k`させて$$K=\frac{k}{2}.$$もし`S`奇数です、合同です$2x \equiv S\pmod k$には解決策がないため、合計金額が奇数のチケットはすべて不運です。 

和が固定剰余であるシーケンスの数は以下に等しい$k^{n-1}$したがって、奇数の合計はすべて寄与します。$$\frac{k}{2}\cdot k^{n-1} = \frac{k^n}{2}.$$ここで偶数和を考えてみましょう。`S = 2y`。 

合同式には正確に 2 つの解があります。$$y,\qquad y+K.$$フーリエ計算を繰り返すと、偶数文字だけが生き残ります。 させて$$d=\gcd(n-2,K).$$すべての偶数和の合計寄与率は次のようになります。$$\frac{(k-2)^n + (d-1)(-2)^n}{2}.$$奇数和部分と偶数和部分を組み合わせると、$$F = \frac{k^n}{2} + \frac{(k-2)^n + (d-1)(-2)^n}{2}.$$もう一度言いますが、答えは、$$k^n - F.$$### なぜ効果があるのか

 フーリエ変換は巡回群の計数問題を対角化します$\mathbb Z_k$。 固定総和剰余の場合`S`、制限「すべての桁が次の解セットを回避する」$2x \equiv S$" は文字の合計の積になります。その文字の合計を`n`選択のための -乗の計算`n`独立した数字。 

すべての可能な剰余を合計した後`S`、文字の直交性により、ほぼすべての周波数がキャンセルされます。 生き残った周波数は、次のような単純な合同を満たすものです。`n - 2`、gcd 用語の登場について説明します。 すべてのアンラッキー チケットは 1 回カウントされ、すべてのラッキー チケットは除外されるため、チケットの総数から引くと正しい答えが得られます。 

## Python ソリューション```python
import sys
from math import gcd

input = sys.stdin.readline

n, k, m = map(int, input().split())

total = pow(k, n, m)

if k % 2 == 1:
    d = gcd(n - 2, k)

    unlucky = pow(k - 1, n, m)

    term = (d - 1) % m
    if n % 2:
        term = (-term) % m

    unlucky = (unlucky + term) % m

else:
    K = k // 2
    d = gcd(n - 2, K)

    inv2 = pow(2, m - 2, m)

    part1 = total

    part2 = pow(k - 2, n, m)

    extra = (d - 1) % m
    extra = extra * pow(2, n, m) % m
    if n % 2:
        extra = (-extra) % m

    unlucky = (part1 + part2 + extra) % m
    unlucky = unlucky * inv2 % m

answer = (total - unlucky) % m
print(answer)
```計算は上記で導出された式に従います。 

奇数の場合`k`、自明でない唯一の量は$$d=\gcd(n-2,k).$$用語$(-1)^n$の場合は否定することで処理されます`n`奇数です。 

偶数の場合`k`、2 による除算はモジュロで実行する必要があります。`m`。 以来`m`は素数であり、より大きいことが保証されます`2`、モジュラー逆関数`2`存在し、次のように計算されます$$2^{m-2}\pmod m.$$表現$(-2)^n$として実装されます$2^n$のパリティによって決定される符号とともに`n`。 

すべてのべき乗は、Python の組み込みモジュラーべき乗を使用します。$O(\log n)$。

import sys, io
from math import gcd

def solve():
    input = sys.stdin.readline
    n, k, m = map(int, input().split())

    total = pow(k, n, m)

    if k % 2:
        d = gcd(n - 2, k)

        unlucky = pow(k - 1, n, m)

        term = (d - 1) % m
        if n % 2:
            term = (-term) % m

        unlucky = (unlucky + term) % m
    else:
        K = k // 2
        d = gcd(n - 2, K)

        inv2 = pow(2, m - 2, m)

        part2 = pow(k - 2, n, m)

        extra = (d - 1) % m
        extra = extra * pow(2, n, m) % m
        if n % 2:
            extra = (-extra) % m

        unlucky = (total + part2 + extra) % m
        unlucky = unlucky * inv2 % m

    print((total - unlucky) % m)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out

    solve()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.getvalue().strip()

 ## 特殊なケース

 ### ベース`k = 1`入力：```
1000000000000000000 1 1000000007
```1桁の値しかありませんが、`0`、チケットは1枚だけです。 その合計額は、`0`、すべての位置が満たされます$$2\cdot 0 \equiv 0.$$奇妙なのは-`k`式は与えます$$d=\gcd(n-2,1)=1,$$

$$F=(1-1)^n+0=0,$$だから答えは`1`。 

### 合計値が奇数の場合`k`均等です

 入力:```
3 4 1000000007
```合計金額が以下のチケット`1`または`3`モジュロ`4`決して幸運にはなれないので、$$2x \equiv 1 \pmod 4$$そして$$2x \equiv 3 \pmod 4$$解決策がありません。 

この式は、項内のすべての奇数和シーケンスを明示的にカウントします。$$\frac{k^n}{2}.$$実装には特別なことは何も必要ありません。 

### 同じ合計に有効な 2 桁

 入力:```
3 6 1000000007
```合計金額について`2`、合同$$2x \equiv 2 \pmod 6$$解決策がある`1`そして`4`。 

1 桁だけを禁止するという単純な導出は間違っています。 偶数-`k`数式は両方の数字を正しく削除します。`(k - 2)^n`の代わりに表示されます`(k - 1)^n`。 

### 事件`n = 2`入力：```
2 5 1000000007
```ここ$$d=\gcd(0,5)=5.$$これは、考えられる最大の gcd 寄与であり、まさに多くのフーリエ周波数が生き残る状況です。 この式は特別な処理を行わなくても有効なままです。`gcd(0, x) = x`はすでに正しく定義されています。
