 ## 解決策
 ## 問題の理解

 2 つの移動オブジェクトが 2D 平面上に与えられ、それぞれが剛体三角形として表されます。 各三角形は時間ゼロの 3 つの固定頂点によって記述され、三角形全体が等速度ベクトルで平行移動します。 形状は回転したり変形したりせず、時間の経過とともに直線的に移動するだけです。 

タスクは、これら 2 つの移動する三角形がある時点で重なっているかどうかを判断し、重なっている場合は、それらが最初に接触または交差する最も早い時間を計算することです。 それらが決して交差しない場合は、-1 を出力する必要があります。 

この問題を考えるのに役立つ方法は、各三角形が時空で連続した 3D オブジェクトになるということです。時間 t では、各点が直線的に移動するため、三角形はプリズムを一掃します。 これら 2 つのプリズムがあるタイム スライス t ≥ 0 で交差すると、衝突が発生します。 

座標に対する制約は大きいですが、慎重に処理すればすべての幾何学的計算を浮動小数点または正確な算術を使用して実行できるほど十分に小さいです。 重要な課題は入力のサイズではなく、時間の連続的な性質であり、これによりブルート フォースのタイム ステップが防止されます。 

単純な離散化では多くの時点をチェックしようとしますが、速度が大きくなり、交差が非常に正確な分数時間で発生する可能性があるため、そのアプローチは根本的に間違っています。 

三角形が 1 点またはエッジに沿って正確に接触している場合、微妙なエッジ ケースが発生します。 たとえば、時間 t = 0.5 でちょうど 1 つの頂点で接触した場合でも、それは衝突としてカウントされます。 もう 1 つのエッジ ケースは、三角形の投影が一定の時間間隔で重なっているにもかかわらず、三角形が平行に移動し、決して交差しない場合です。 

最も重要な構造上の問題は、交差条件が時間的に単調ではないことです。 相対運動に応じて、2 つの三角形が切り離されてから交差し、その後再び切り離されることがあります。 これにより、より深い推論なしに、時間通りに単純な二分探索が排除されます。 

## アプローチ

 この強引なアイデアは、時間を継続的にまたは非常に小さなステップでシミュレートし、サンプリングされた各瞬間に三角形が交差するかどうかを確認することです。 時間 t ごとに、両方の三角形を平行移動し、ポリゴン交差テストを実行します。これには一定の時間がかかります。 ただし、10^6 の時間サンプルのみを考慮した場合でも、正確な衝突の瞬間を簡単に見逃してしまう可能性があります。これは、直線交差方程式によって決定される非合理的な時間または高精度の有理時間で発生する可能性があるためです。 これにより、離散化が遅すぎて不正確になります。 

重要な洞察は、絶対運動から相対運動に視点を変えることです。 両方の三角形を動かすのではなく、一方の三角形を固定し、もう一方の三角形を相対速度差で動かします。 ここで問題は、固定された三角形は移動する三角形と交差するかということです。 

これにより、問題は凸多角形間の古典的な連続衝突検出問題に帰着します。 三角形は凸であるため、分離軸定理を使用できます。 2 つの凸多角形の場合、それらは分離軸がない場合にのみ交差し、各軸の制約は時間における線形不等式になります。 

潜在的な各分離方向は、いずれかの三角形からのエッジ法線によって定義されます。 固定方向の場合、両方の三角形のその軸への投影は、時間の経過とともに直線的に移動する間隔になります。 その軸上の交差は、a + bt ≤ c + dt の形式の単純な不等式になります。 各軸はオーバーラップの可能性がある時間間隔に寄与し、全体の衝突間隔はそのようなすべての間隔の交点になります。 

したがって、問題は、エッジ法線によって引き起こされるすべての有効な時間間隔を計算し、それらと交差し、交差部分での最小の非負の時間を取得することに帰着します。

 ## アルゴリズムのチュートリアル

 まず問題を相対運動に変換します。 三角形 A が速度 vA で、三角形 B が速度 vB である場合、A を固定し、B を速度 v = vB − vA で移動します。 これは衝突イベントの相対的なジオメトリを変更するものではなく、説明を簡素化するだけです。 

次に、分離軸の候補を検討します。 凸多角形の場合、分離軸はいずれかの多角形のエッジに対して垂直でなければなりません。 どちらの形状も三角形であるため、エッジは合計 6 つしかなく、したがって 6 つの候補方向が存在します。 

各軸について、両方の三角形をその軸に投影します。 三角投影は、端点が時間の線形関数である区間です。 具体的には、各頂点は線形関数 x(t) = x0 + v · t に寄与するため、投影された間隔の各終点も時間的に線形になります。 

次に、軸ごとに、2 つの投影された間隔が重なる時間間隔を計算します。 これは一対の線形不等式となり、有効な t の単一区間に解決されます。 

このようなすべての間隔をすべての軸上で交差させます。 設定された最終的な実行可能時間は、実線上の最大 6 つの間隔の交差点です。 t ≥ 0 で交差点が空の場合、衝突は発生しません。 それ以外の場合、交差点内の最小の t が答えになります。 

### なぜ効果があるのか

 凸多角形の場合、交差しないことは分離軸が存在することに相当します。 動きは線形であるため、固定軸上の投影ギャップは時間の経過とともに線形に変化します。 したがって、その軸上のオーバーラップの条件は、時間に関する線形の実現可能性制約になります。 衝突ではすべての軸が同時にオーバーラップする必要があるため、これらの制約を交差させると、設定された衝突時間が正確に取得されます。 すべての軸の制約を満たさずに交差を引き起こす他の幾何学的構成はありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def dot(ax, ay, bx, by):
    return ax * bx + ay * by

def proj_interval(poly, vx, vy):
    mn = float('inf')
    mx = -float('inf')
    for x, y in poly:
        val = x * vx + y * vy
        mn = min(mn, val)
        mx = max(mx, val)
    return mn, mx

def get_axes(poly1, poly2):
    axes = []
    polys = [poly1, poly2]
    for poly in polys:
        for i in range(3):
            x1, y1 = poly[i]
            x2, y2 = poly[(i + 1) % 3]
            dx, dy = x2 - x1, y2 - y1
            axes.append((-dy, dx))
    return axes

def solve():
    p1 = [tuple(map(int, input().split())) for _ in range(3)]
    v1 = tuple(map(int, input().split()))
    p2 = [tuple(map(int, input().split())) for _ in range(3)]
    v2 = tuple(map(int, input().split()))

    vx = v2[0] - v1[0]
    vy = v2[1] - v1[1]

    axes = get_axes(p1, p2)

    lo = 0.0
    hi = float('inf')

    for ax, ay in axes:
        mn1, mx1 = proj_interval(p1, ax, ay)

        shifted = []
        for x, y in p2:
            shifted.append((x, y))

        mn2, mx2 = proj_interval(shifted, ax, ay)

        # projection of p2 moves linearly: shift both endpoints by t*(vx,vy)
        vproj = vx * ax + vy * ay

        if vproj == 0:
            if mx2 < mn1 or mx1 < mn2:
                print(-1)
                return
            continue

        # solve overlap: mn2 + t*vproj <= mx1 and mx2 + t*vproj >= mn1
        t1 = (mn1 - mx2) / vproj
        t2 = (mx1 - mn2) / vproj

        if t1 > t2:
            t1, t2 = t2, t1

        lo = max(lo, t1)
        hi = min(hi, t2)

        if lo > hi:
            print(-1)
            return

    if hi < 0:
        print(-1)
        return

    lo = max(lo, 0.0)
    print(lo)

if __name__ == "__main__":
    solve()
```この解決策は、2 番目の三角形を相対運動システムに変換することから始まります。したがって、重要な速度ベクトルは 1 つだけです。 以降のすべての計算は静的参照に対する単一オブジェクトの線形移動に依存するため、これは不可欠です。 

これらの方向のみが分離超平面を定義できるため、各軸は三角形のエッジから導出されます。 射影ステップは、2D 凸交差問題を 1D 間隔オーバーラップ問題に還元します。 

各軸の重要な操作は、間隔の重複を時間の線形不等式に変換することです。 変数`vproj`投影された間隔がその軸に沿って移動する速度です。 ゼロの場合、相対位置は決して変更されないため、時間ゼロですでに間隔が重なっているかどうかだけをチェックします。 

それ以外の場合は、移動間隔が固定間隔と交差する時間範囲を計算します。 これらの境界は交差によってすべての軸にわたってマージされ、空の交差は衝突が存在しないことを直ちに証明します。 

微妙な点は、除算時に正しい順序を維持することです。`vproj`、その符号は不等式の方向を反転するためです。 スワッピング`t1`そして`t2`常に間隔として扱うようにします。

これは、三角形が最初に頂点に接触したときに正確に衝突がどのように検出されるかを示しています。

 ## 特殊なケース

 重要なエッジ ケースは、軸上の投影速度がゼロの場合です。 この状況では、間隔の相対的な順序は時間の経過とともに変化しません。 アルゴリズムは、時間 0 でのみ重複をチェックすることにより、これを正しく処理します。 最初にそれらがばらばらであれば、将来それを修正することはできません。 

衝突がちょうど t = 0 で発生した場合、別のエッジ ケースが発生します。アルゴリズムは最終的な答えを次のようにクランプします。`lo = max(lo, 0.0)`すぐに交差点を見逃さないようにします。 

最後のエッジケースは、2 つの三角形が 1 点で接触する場合です。 投影空間では、これは少なくとも 1 つの軸間隔の境界が等しいことに対応します。 区間の計算には不等式が含まれるため、このような場合は有効なゼロ幅交差区間が生成され、その時点で衝突として正しく報告されます。
