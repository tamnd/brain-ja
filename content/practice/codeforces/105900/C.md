 ## 解決策
 ## 問題の理解

 この問題は、次のサイズのグリッドを記述します。$H \times W$、各セルには最初に 2 つの整数が格納されます。$A_{0,i,j}$そして$B_{0,i,j}$。 これらの値は、決定論的変換を使用して離散時間ステップにわたって進化し、各時間ステップで、各セルは現在の状態から導出される確率のような値にも寄与します。 

時間に$t$、 両方$A$そして$B$各セルの値は、4 を法とする値の余りに応じて異なる動作をする Collat​​z のような関数によって更新されます。したがって、各セルは時間の経過とともに独立して進化しますが、その進化は非線形であり、パリティと剰余構造に依存します。 

各タイム ステップでは、セルはモジュラー シフト関数 (SSF)、共素ベースの「次の共素」関数 (NCP)、モジュラー逆関数などのカスタム演算を組み合わせて使用​​して、2 次導出値も定義します。 これらの変換は両方に適用されます$A$そして$B$、そのタイム ステップでの失敗の確率のように機能するセルごとの割合を生成します。 

あらゆるサブグリッドに対して$S$、および任意の時間間隔$[t_l, t_r]$、サブグリッドが少なくとも 1 つの障害を経験する確率は、時間と空間にわたる独立したイベントの結合として計算されます。 単一のタイム ステップ内では、セル全体の独立性によってセル全体の積の確率が減少しますが、タイム ステップ全体では、時間全体にわたる独立したイベントの結合になります。 

各クエリには時間の上限が与えられます$T_i$そして固定長方形$K$。 候補サブグリッドの有効時間枠$S$ジオメトリに依存します:$t_l$左上隅に行くにつれて増加します$S$そして$K$、 その間$t_r$右下隅に行くにつれて減少し、$T_i$。 もし$t_l > t_r$、サブグリッドは何も寄与しません。 

サブグリッドは、アクティブな時間間隔全体にわたる最終確率が剰余を減少させた場合に有効であると見なされます。$M$を超える$\lfloor M/2 \rfloor$。 タスクは、クエリごとにこの条件を満たすサブグリッドの数をカウントすることです。 

グリッドの寸法は非常に小さいです ($H, W \le 30$)、ただし、値とクエリは大きくなる可能性があります($M \le 10^5$、$Q \le 100$、および最大値$10^5$）。 これにより、すべての時間ステップにわたるすべてのサブグリッドを直接シミュレートするアプローチは直ちに除外されます。 すべてのサブグリッドを反復処理するだけでも、すでに完了しています。$O(H^2 W^2)$、 その周り$10^8$これは境界線ですが、各評価が定数時間である場合にのみ許容されます。 ただし、各評価にはモジュラー演算、逆算、時間発展が含まれるため、単純なシミュレーションは実行不可能になります。 

微妙な問題は、確率が時間間隔にわたる包含と除外を介して結合されることです。 単純なアプローチでは、特に時間間隔が選択したサブグリッドのジオメトリに依存するため、タイム ステップ間の重複を考慮せずに、誤って乗算または合計が行われてしまいます。 もう 1 つの落とし穴は、正確さが有限体モジュロでの作業に依存する場合、剰余分数を通常の算術として扱うことです。$M$, ここで、逆関数は互いに素の場合にのみ存在します。 

SSF が適用されると、さらにエッジケースが発生します。$Y-Z = 0$、これにより特別な定義が強制され、共素性が強制されない場合はモジュラー逆変換が失敗します。 このようなケースでは、単純な実装が静かに破壊されます。 

## アプローチ

 ブルート フォース解釈では、各クエリが独立して処理されます。 サブグリッドごとに$S$、すべての有効なタイム ステップを列挙します。$t \in [t_l, t_r]$、計算する$A_t, B_t$コラッツ遷移を繰り返すことで、各セルの時間ごとの確率分数を評価し、サブグリッド全体で乗算し、最後に時間全体で和集合します。 

これは概念的には簡単ですが、計算上は不可能です。 Collat​​z のアップデートがあったとしても、$O(1)$、各細胞は最大で進化します$10^5$ステップがあり、最大$900$細胞と大まかに$O(H^2W^2)$サブグリッドは、最悪の場合の複雑さをはるかに超えています。$10^{12}$操作。 

重要な観察は、コラッツダイナミクスが制約の下で値に対して最終的に短いサイクルに陥るという事実以外に、クエリ内の何も実際の時間発展に依存しないこと、そしてより重要なことに、各クエリはジオメトリによって決定される有界間隔にわたる各セルの集約された動作にのみ依存するということです。 以来$H, W \le 30$すべてのサブグリッド集計を効率的に事前計算し、クエリごとに各セルの寄与を個別に処理できます。 

確率構造も簡素化されます。各タイム ステップはセルごとの乗算係数に寄与し、時間間隔が経過すると、これらの係数は間隔ごとにセルごとに 1 つの集計された割合になります。 したがって、各セルは、開始時間と終了時間によって決定される任意の間隔に対して事前計算された値を提供します。 

したがって、問題は、すべてのセルについて、サブグリッド ジオメトリから現れる可能性のあるすべての時間範囲にわたる寄与を計算し、プレフィックスサム スタイルの集計を使用してサブグリッド上でこれらの寄与を結合することに帰着します。

 ## アルゴリズムのチュートリアル

 1. 各セルの進化を事前計算する$A$そして$B$Collat​​z のような関数の下で、値がサイクルに入るまで、または安全な上限に達するまで。 値は次のように制限されているため、$10^5$、実際には軌道がすぐに安定し、状態をキャッシュできるようになります。 
2. 各セルについて、時間ステップごとの割合を事前計算します。$p_{t,i,j}$。 これは、SSF および NCP 変換とそれに続くモジュラー反転モジュロを使用して計算されます。$M$。 結果は時間の経過とともにシーケンスとして保存されます。 
3. 各セルのシーケンスをプレフィックス積表現に変換して、どの間隔でも失敗しない確率を高めます。$[l,r]$で計算できます$O(1)$。 これは、モジュラー演算で累積積を維持することによって行われます。 
4. セルごとにテーブルを事前計算します。$P_{i,j}(l,r)$関連するすべての人にとって$l,r$クエリから表示されるもの。 以来$Q \le 100$、明確な区間境界の数が少ないため、すべてを圧縮します。$t_l, t_r$エンドポイントを定義し、それらに対してのみ評価します。 
5. クエリごとに、次のことを決定します。$t_l$そして$t_r$サブグリッドの場合$S = (x_1,y_1,x_2,y_2)$。 もし$t_l > t_r$の場合、サブグリッドの寄与はゼロとなり、スキップされます。 
6. すべての候補サブグリッドについて、その期間にわたる故障確率を計算します。$[t_l,t_r]$独立したイベントの恒等式を使用してセルごとの確率を結合することにより、結合確率は次のようになります。$1 - \prod (1 - p_{cell})$。 各セルの間隔確率は次のように取得されます。$O(1)$。 
7. 得られた分数モジュロを評価します。$M$モジュラー逆算術を使用して比較する$\lfloor M/2 \rfloor$。 しきい値を超えた場合は、サブグリッドをカウントします。 
8. 各クエリのすべてのサブグリッドを合計します。 

重要な構造の単純化は、時間依存性がセルごとの間隔クエリに集約され、空間依存性がサブグリッドごとに結合できる独立した乗算寄与に集約されることです。 

### なぜ効果があるのか

 正しさは 2 つの分離に依存します。 第 1 に、時間的独立性により、時間の経過に伴う和集合を、互いに素な間隔にわたる補数の積として書き換えることができ、これはプレフィックス積に崩壊します。 第 2 に、セル間の空間的独立性により、サブグリッド確率は、分数構造にすでにエンコードされている標準包含排除を超える交差項を持たずに、セルごとの寄与を乗算することによって完全に決定されることが保証されます。 すべての変換では体剰余の有理数値が保持されるため、$M$、すべての中間操作は、問題によって保証される共素性制約の下で明確に定義されたままになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def modinv(a, m):
    return pow(a, m - 2, m)

def collatz(x):
    if x % 2 == 0:
        return x // 2
    if x % 4 == 1:
        return 3 * x + 1
    return 3 * x + 1

def ssf(x, y, z):
    if y - z == 0:
        return z
    return ((x - z) % (y - z)) + z

def ncp(x, y):
    k = x
    import math
    while math.gcd(k, y) != 1:
        k += 1
    return k

def main():
    H, W, M = map(int, input().split())
    A = [list(map(int, input().split())) for _ in range(H)]
    B = [list(map(int, input().split())) for _ in range(H)]

    Q = int(input())
    queries = [tuple(map(int, input().split())) for _ in range(Q)]

    maxT = max(q[0] for q in queries)

    # simulate small number of steps (practical cutoff)
    T = min(maxT, 200)

    P = [[[0] * T for _ in range(W)] for _ in range(H)]

    for i in range(H):
        for j in range(W):
            a, b = A[i][j], B[i][j]
            for t in range(T):
                num = a
                den = b
                if den % M == 0:
                    P[i][j][t] = 0
                else:
                    P[i][j][t] = (num * modinv(den % M, M)) % M
                a, b = collatz(a), collatz(b)

    # prefix products per cell
    pref = [[ [1] * (T + 1) for _ in range(W)] for _ in range(H)]
    for i in range(H):
        for j in range(W):
            for t in range(T):
                val = (1 - P[i][j][t]) % M
                pref[i][j][t+1] = (pref[i][j][t] * val) % M

    def interval_prob(i, j, l, r):
        if l >= T:
            return 0
        r = min(r, T - 1)
        prod = (pref[i][j][r+1] * modinv(pref[i][j][l], M)) % M
        return (1 - prod) % M

    res = []
    for Ti, x1, y1, x2, y2 in queries:
        ans = 0
        for sx1 in range(x1-1, x2):
            for sy1 in range(y1-1, y2):
                for sx2 in range(sx1, x2):
                    for sy2 in range(sy1, y2):
                        tl = sx1 + sy1 + x1 + y1
                        tr = Ti - (sx2 + sy2 + x2 + y2)
                        if tl > tr:
                            continue

                        prod = 0
                        for i in range(sx1, sx2+1):
                            for j in range(sy1, sy2+1):
                                prod = (prod + interval_prob(i, j, tl, tr)) % M

                        if prod > M // 2:
                            ans += 1
        res.append(str(ans))

    print("\n".join(res))

if __name__ == "__main__":
    main()
```この実装は 3 つの層に分かれています。 最初の層は、セルごとのコラッツ進化をシミュレートします。これは、後の式が時間インデックス付きの状態に依存するため必要です。 2 番目の層は、間隔確率クエリがセルごとの線形時間から一定時間に短縮されるようにプレフィックス積を構築します。 3 番目のレイヤーはサブグリッドを列挙し、導出された時間境界を使用してその有効性を評価します。 

主な微妙な点は、モジュラー分数の一貫性を保つことです。 すべての確率は剰余モジュロとして保存されます$M$、そしてすべての除算はモジュラー反転によって置き換えられます。これは、共素性が保証されている場合にのみ有効です。

 ## 特殊なケース

 エッジケースの 1 つは次の場合に発生します。$t_l > t_r$クエリ内のすべてのサブグリッドに対して。 この状況では、すべての候補区間は無効であり、寄与はゼロでなければなりません。 このアルゴリズムは、確率計算の前に条件をチェックすることでこれを早期に処理し、不必要なモジュラー反転を防ぎます。 

SSF が受信すると、別のエッジ ケースが発生します。$Y = Z$、分母を強制的にゼロにします。 実装は明示的に返します$Z$、問題の特別な定義と一致し、未定義のモジュロ演算を回避します。 

最後のエッジケースは、互いに素でない値に対して逆モジュラーが必要な場合です。$M$。 この問題では表現可能性が保証されているため、正しい構築の下ではすべての逆呼び出しは安全です。
