 ## 解決策
 ## 問題の理解

 単一の整数が与えられます$N$、長板橋の前に配置された曹操軍の兵士の数を表します。 物語では、張飛の咆哮がパニックを引き起こし、兵士たちが逃亡する様子が描かれています。 ただし、特定の例外があります。夏厚傑将軍は別の影響を受けており、「怖がって逃げた」人々の数には含まれないと明示されています。 

したがって、課題は、恐怖を感じたグループの一員としてカウントされない 1 人を除外した後、実際に何人の兵士が逃げたかを判断することになります。 

物語はかなり様式化されていますが、基礎となる構造は純粋に算術です。 入力サイズは最大です$10^6$これにより、複雑な動作を持つ個々の兵士に対するシミュレーションを伴うものは即座に除外されますが、ここではインタラクションやシーケンスを追跡していないため、それさえも不要です。 定数時間の計算で十分です。 

微妙なエッジケースが現れるのは、$N = 1$。 このとき、カウントから除外された人物だけが存在する場合、怯えて逃げた兵士の数はゼロになります。 単純な減算では、負の値を生成せずにこれをきれいに処理する必要があります。 

## アプローチ

 ブルートフォース解釈では、各兵士を明示的にシミュレートし、咆哮によって逃走するかどうかをマークし、Xia Houjie を除外してカウントを調整します。 これには概念的に、すべてを反復処理することが含まれます。$N$エンティティと兵士ごとのステータス フラグの維持。 これはすでに線形であり、簡単に通過しますが、$N \le 10^6$、個々の状態遷移は実際には位置や相互作用に依存しないため、これは不要です。 

重要な観察は、この物語では、最終的なカウントに含めるべきではない 1 人の例外的な個人が定義されているということです。 つまり、答えは単純に兵士の総数から除外された1人を引いたものになります。 それ以上の構造、順序、条件は結果に影響を与えません。 

したがって、この問題は定数時間の算術計算に集約されます。

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る$N$、橋の前にいる兵士の総数を表します。 これは、除外が適用される前の全母集団です。 
2. 最終的な「怖がった」数に含まれていない個人が 1 人だけであることを特定します。 このステートメントはこの例外を明示的に定義しているため、その人は結果にカウントされません。 
3. 結果を次のように計算します。$N - 1$。 これにより、除外された個人が合計から直接削除されます。 
4. もし$N = 1$、同じ式が引き続き適用され、当然 0 が得られます。これは、怖がってカウントされる兵士がいないことを正しく表します。 

### なぜ効果があるのか

 重要な不変条件は、1 人を除くすべての兵士が最終的な逃亡者数に寄与するということです。 この問題では、除外が 1 つだけ保証され、他のフィルター条件は保証されないため、最終的な答えは常に、合計サイズからその 1 つの除外されたエンティティを引いたものになります。 兵士間に依存関係はなく、条件付きの行動や人口の動的な変化もないため、減算はすべての入力に対して有効なままです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n = int(input().strip())
    print(max(0, n - 1))

if __name__ == "__main__":
    main()
```実装は意図的に最小限に抑えられています。 引き算$n - 1$ステートメントで説明されている除外をエンコードします。 の`max(0, ...)`ガードは次の場合に正確性を保証します$n = 1$、縮退した場合の負の出力を防ぎます。 

このソリューションでは、一定時間の入力処理を使用し、単一の整数を超えるものを格納することを回避します。
