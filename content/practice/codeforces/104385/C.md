 ## 問題の理解

 私たちはいくつかの石の山を与えられました。 2 人のプレイヤーが交代で、各ターンにプレイヤーが 1 つの山を正確に選択し、そこからいくつかの石を取り除きます。 問題は、削除される数値が固定整数の累乗でなければならないことです。$p$、したがって、許可される動きは次のとおりです$1, p, p^2, p^3, \dots$、選択した値がパイル サイズを超えない限り。 有効な手を打つことができないプレイヤーは負けます。これは、すべての山が空の場合に起こります。 

タスクは、両方のプレーヤーが最適にプレイしたと仮定して、最初のプレーヤーが強制的に勝利するかどうかを判断することです。 

制約は大きく、最大で$3 \cdot 10^5$パイル、および両方のパイル サイズと$p$と同じ大きさにすることができます$10^{18}$。 これにより、動きをシミュレートしたり、考えられるすべての状態にわたってパイルごとの DP を構築したりするアプローチは即座に除外されます。 どのようなソリューションでも、各パイルを個別に処理し、各パイルを小さな表現に縮小する必要があります。 

次の場合、微妙なエッジケースが発生します。$p = 1$。 その場合、すべての動きでちょうど 1 つの石が削除されるため、各パイルは標準の Nim ヒープのように動作し、すべての動きでヒープが 1 ずつ減ります。これにより、ゲームは単純なパリティ問題に分解されますが、それでも次の累乗を生成しようとする単純な実装です。$p$無限ループに陥る可能性があるため、$p^k = 1$みんなのために$k$。 

もう 1 つの重要なエッジ ケースは、パイルが非常に大きく、$p$も大きいです。 その場合、それを超えたほとんどの権限は、$p^1$すぐにパイル サイズを超えるため、関連する移動サイズはわずかです。 制限なしにグローバルにすべてのべき乗を事前計算するソリューション$10^{18}$リスクがオーバーフローしたり、不要な作業が発生したりする可能性があります。 

## アプローチ

 このゲームを直接的に考えると、各移動が固定移動セットの値だけ 1 つのパイルを減らす、マルチパイルの公平なゲームとして考えることができます。 これはスプラーグ・グランディ理論を示唆しています。 パイルサイズごとに$a$、到達可能なすべての状態を考慮して、その Grundy 値を計算できます。$a - p^k$そしてメキシコを摂取します。

重要な観察点は、ゲームの動作が次の条件に応じて大きく異なるということです。$p = 1$または$p \ge 2$。 

いつ$p \ge 2$、一連の動きは$1, p, p^2, \dots$。 これらはまばらであり、指数関数的に増加します。 これによりベースが作成されます。$p$構造体: すべての整数$a$塩基で分解できる$p$、各移動は重みを付けて 1 桁の位置を減算することに対応します。$p^k$。 これにより、ゲームは、Grundy 値が基数の数字の XOR である Nim ヒープと同等になります。$p$しかし、重要なのは、各移動が 1 つの山にのみ影響するため、キャリーは山をまたいで複雑に相互作用しないことです。 

それは、$p \ge 2$、山のグランディ値は単にその底の合計のパリティです。$p$数字。 これにより、各パイルが単一ビット (合計が偶数か奇数か) に減らされます。 この削減が行われると、ゲーム全体がこれらのビットに対する標準の Nim になります。

 ## アルゴリズムのチュートリアル

 各パイルを個別に処理し、単一の XOR 寄与に変換します。 

1. もし$p = 1$、各移動がちょうど 1 つの石を削除することがわかります。 サイズの山$a$チェーンのように動作し、最適なプレイは次の条件にのみ依存します。$a$奇数か偶数です。 したがって、各山を次のように縮小します$a \bmod 2$。 これが機能するのは、すべての手が残りの石のパリティを反転させるためです。 
2. もし$p \ge 2$、各パイルサイズを分解します$a$基地内で$p$。 を取得して繰り返し数字を抽出します$a \bmod p$で割る$p$。 
3. 取得した各桁について、その値のモジュロ 2 をその山の実行中のパリティ カウンタに累積します。 これは、すべての累乗の合計寄与度が次のとおりであるかどうかを表します。$p$この山の中にあるのは奇数か偶数です。 
4. このパリティが奇数の場合、パイルは 1 を与え、それ以外の場合は 0 を与えます。 
5. すべてのパイル寄与を XOR します。 最終的な XOR がゼロ以外の場合、最初のプレーヤーが勝ちます。 

桁パリティが重要な理由は、各移動がちょうど 1 乗を取り除くためです。$p$、これらの動きは基底の各桁の位置に独立して作用します。$p$。 このような減算ゲームのグランディ値は、この指数関数的な移動セットでは等価になるため、選択可能な寄与の合計数が奇数であるかどうかのみが最終状態に影響します。 

### なぜ効果があるのか

 各パイルは事実上、次の累乗に対応する独立したコンポーネントの合計です。$p$。 すべての動きでそのようなコンポーネントが 1 つだけ削除され、その構造により、数えきれないほどの異なる大きさの間の相互作用が保証されません。 これにより、各パイルは、表現可能なコンポーネントのパリティのみが重要となるトークンの山と同等になります。 これらのパリティの XOR により、標準の Nim 結果条件が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def pile_value(a, p):
    if p == 1:
        return a % 2

    parity = 0
    while a > 0:
        parity ^= (a % p) % 2
        a //= p
    return parity

def solve():
    n, p = map(int, input().split())
    arr = list(map(int, input().split()))

    x = 0
    for a in arr:
        x ^= pile_value(a, p)

    print("GOOD" if x != 0 else "BAD")

if __name__ == "__main__":
    solve()

微妙な点は、次のべき乗を決して事前計算しないことです。$p$、オーバーフローを完全に回避します。 ループが実行されます$O(\log_p a)$、以下では安全です$10^{18}$。
