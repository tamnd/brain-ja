 ## 解決策
 ## 問題の理解

 同じ長さの 2 つの文字列が与えられ、同期操作を繰り返し実行できます。長さを選択します。`len`, choose any substring of that length in the first string, reverse it, and independently choose any substring of the same length in the second string and reverse it as well. 選択した位置は一致している必要はありません。 

The goal is not to directly transform one string into the other, but to determine whether there exists a sequence of such paired reversals that makes the two strings identical at the end.

 The key observation is that each operation preserves a strong global structure: both strings are being modified by reversals of equal-sized segments, but their relative multiset of characters never changes in a way that depends on position matching. それぞれの動きは各文字列内の文字を独立して並べ替えますが、常に両方の文字列の「強さ」がグローバルに反映される方法で行われます。 

制約の観点から見ると、すべてのテスト ケースの合計の長さは最大でも`2 · 10^5`。 これにより、操作をシミュレートしたり順列の構成を探索しようとするソリューションは除外されます。 任意の部分文字列の反転についての推論でも、階乗の複雑さに直接つながります。 解決策は、問題をテスト ケースごとの単純な構造不変チェックに分解する必要があります。理想的には線形または線形演算です。`n`。 

単純なアプローチでは、反転によって各文字列に順列がどのように生成されるかをシミュレートし、共通の構成が存在するかどうかを確認しようとします。 しかし、任意の反転の下で単一の文字列の到達可能な状態空間を決定することさえ、すでに完全な置換生成と同等であるため、そのアプローチは実行不可能になります。 

2 つの文字列が同じ複数の文字セットを持っているが、配置が異なる場合、微妙なエッジ ケースが 1 つ発生します。 例えば：```
s = "ab"
t = "ba"
```単純なマルチセットベースのチェックでは「YES」と表示されますが、同期の制約によっては、より複雑な場合に許可された操作を通じてそれらを調整できるとは限りません。 実際の条件は単なる文字数よりも厳密ですが、それでも単純なパリティベースの不変式にきれいに削減されます。 

文字列の位置が 1 か所だけ異なる場合、別の特殊なケースが発生します。```
s = "abcde"
t = "abXde"
```たとえ不一致が 1 つだけ存在するとしても、同期反転のグローバル制約はローカル修正が独立していないことを意味するため、実現可能性はローカル修正能力ではなくグローバル パリティ構造に依存します。 

## アプローチ

 ブルートフォース解釈では、それぞれの動きを 2 つの部分文字列を独立して選択し、それらを反転するものとして扱います。 単一の長さの文字列の場合`n`、部分文字列の任意の反転により、すべての置換が生成されます。 したがって、両方の文字列を個別に考慮すると、それぞれの文字の任意の順列に到達することができます。 

ただし、問題は同期です。各移動により、両方の文字列に同じ長さの反転が適用されます。 これにより、変換シーケンスが結合され、個別に扱うことができなくなります。 すべての反転ペアを総当り検索すると、おおよその結果が得られます。`O(n^3)`移動ごとの選択肢が増え、移動シーケンスが指数関数的に増加しますが、これは完全に不可能です。 

重要な洞察は、到達可能な順列という観点から考えるのをやめ、代わりに両方の文字列にわたって保持される不変式に焦点を当てることです。 各操作では、両方の文字列を一緒に考慮するときに、文字位置の相対的なパリティ構造が保存されます。 より具体的には、この操作により、グローバル パリティ制約の下で位置を一致させる機能を維持する方法でのみ文字を再配置できるようになります。 

これにより、すべての同期反転後に存続する唯一の不変式を尊重しながら、文字を再配置することで 2 つの文字列を同一にできるかどうかをチェックするという問題に問題が軽減されます。不一致の位置のパリティは、単純な実現可能性の制約を超える障害にはなりません。 

変換システムを単純化した後、問題は単純な条件に集約されます。必要なのは、2 つの文字列に同じ複数の文字セットが含まれていること、および許可された操作の対称性から導出されるパリティ実現可能性条件を満たしていることを検証することだけです。 これは最終的には、周波数をカウントした後の一定時間のチェックに帰着します。

 ## アルゴリズムのチュートリアル

 ### 重要なアイデアの再定式化

 この操作を同期された並べ替えプロセスとして再解釈します。 各文字列は任意に並べ替えることができますが、同期により、位置全体でパリティ ベースの制約が保持されるように変換が強制されます。 

### ステップ

 1. 両方の文字列内の各文字の頻度をカウントします。 

最初に必要な条件は、反転によって文字が作成または破壊されないため、両方の文字列に同一の文字のマルチセットが含まれている必要があることです。 
2. 度数分布が異なる場合は、直ちに「NO」を返します。 

一連の逆転によって、異なるキャラクターの一覧を調整することはできません。 
3. パリティベースの実現可能性チェックを計算します。 

同期反転により、文字が位置間で再配分される方法のパリティが維持されることがわかります。 これは、有効な変換が存在する場合、文字列間の不一致構造が対称再配置と互換性がある必要があることを意味します。 
4. 文字が異なる位置の数が偶数であるかどうかを確認します。 

それぞれの同期された反転により、不一致がペアで効果的に移動され、不一致の等価性が維持されます。 したがって、奇数の位置の不一致は解決できません。 
5. マルチセットの等価性とパリティ条件の両方が成立する場合は、「YES」を返します。 それ以外の場合は「NO」を返します。 

### なぜ効果があるのか

 不変条件は、すべての操作で両方の文字列に同じ長さの反転が適用されることです。つまり、文字は常に対称ブロック内で移動されます。 これは、文字列間の不一致は個別に解決することはできず、バランスの取れた交換でのみ解決できることを意味します。 結果として、唯一の障害は、これらの対称変換を通じて不一致の位置をペアにして削除できるかどうかです。 文字数が一致すると、実現可能性は純粋に不一致構造が完全なペアリングを許可するかどうかに依存します。これはパリティ条件に帰着します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    q = int(input())
    for _ in range(q):
        n = int(input())
        s = input().strip()
        t = input().strip()

        if sorted(s) != sorted(t):
            print("NO")
            continue

        diff = 0
        for i in range(n):
            if s[i] != t[i]:
                diff += 1

        if diff % 2 == 0:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```この解決策は、並べ替えを使用して両方の文字列に同じ複数の文字セットが含まれていることを確認することから始まります。反転では文字数が正確に保持されるため、これで十分です。 これが失敗した場合、文字列を整列させる一連の操作は実行できません。 

次に、位置に関する不一致をカウントします。 同期された各操作は不一致をペアで効果的に移動するため、許可された操作のどのシーケンスでも奇数の不一致を解決できません。 

最後に、同一のマルチセットと不一致パリティの両方の条件を組み合わせます。 

実装は簡単ですが、重要な微妙な点は、パリティ チェックなしではマルチセットの等価性だけでは十分ではないということです。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    q = int(sys.stdin.readline())
    out = []
    for _ in range(q):
        n = int(sys.stdin.readline())
        s = sys.stdin.readline().strip()
        t = sys.stdin.readline().strip()

        if sorted(s) != sorted(t):
            out.append("NO")
            continue

        diff = sum(1 for i in range(n) if s[i] != t[i])
        out.append("YES" if diff % 2 == 0 else "NO")

    return "\n".join(out)
