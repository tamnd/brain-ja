 ## 解決策
 ## 問題の理解

 この問題では、各頂点が正の整数値を持つ有向グラフが得られます。 マーシャはコインを任意の頂点に置き、グラフの端に沿って正確に移動させることができます。$k-1$回。 コインが頂点を訪れるたびに、頂点の番号がノートに記録されます。 タスクは、これらの後にノートブックに表示される最大の数値を最小化することです。$k$初期位置を含むコインの配置。 作るのが無理なら$k-1$グラフが小さすぎるか切断されているために移動する場合、出力は次のようになります。$-1$。 

入力制約は大きく、最大で$2 \cdot 10^5$頂点とエッジ、そして$k$まで高くすることができます$10^{18}$。 これにより、可能なすべての移動またはストアのシーケンスを明示的にシミュレートするアルゴリズムは除外されます。$k$要素。 また、頂点値の大きな数値や、非常にまばらなグラフや接続されていないグラフを処理する必要もあります。 

エッジケースは微妙です。 グラフにサイクルが含まれている場合、Masha は頂点を無限に繰り返すことができます。$k$サイクルが最初から到達可能である限りは関係ありません。 グラフが非巡回で、最長パスのパスが以下の場合、$k$頂点の場合、出力は次のようになります$-1$。 小さなグラフ、または最小の頂点が分離されているグラフにも、局所的にのみ検索するか、すべての頂点が到達可能であると想定する単純なアルゴリズムの罠が存在します。 

たとえば、3 つの頂点とエッジを持つグラフを考えてみましょう。$1 \to 2$そして$2 \to 3$、 そして$k = 5$。 最長のパスには頂点が 3 つしかないため、マーシャがどのように動いても、5 つの数字を記録することはできません。 正しい出力は次のとおりです$-1$。 サイクルや無制限の移動を想定した不注意なアプローチでは、誤って既存の頂点を複数回使用しようとします。 

## アプローチ

 ブルートフォースアプローチは、すべての頂点を開始点として試し、長さのすべてのパスを探索することです。$k$。 各パスに沿って最大値を追跡し、その中から最小値を選択できます。 これは原理的には正しいですが、扱いが困難です。パスの数はグラフ サイズに応じて指数関数的に増加します。$k$までです$10^{18}$。 中程度の場合でも深さが制限された DFS$k$不可能です。 

重要な洞察は、シーケンスに沿って記録された最大数が、訪問した頂点の最大値であることを認識することです。 閾値を推測すると$x$、長さのシーケンスが存在するかどうかを確認できます$k$最大でも値を持つ頂点のみを訪問します$x$。 これにより、問題は、値を持つ頂点によって形成されるサブグラフ内の到達可能性の問題に帰着します。$\le x$。 このサブグラフの強く接続されたコンポーネントにサイクルがある場合、移動を無限に繰り返して任意の要素に到達することができます。$k$。 グラフが非巡回の場合、サブグラフ内の最長パスは少なくとも$k$。 このプロパティを使用すると、候補の最大値を二分探索して、実現可能な最小値を効率的に見つけることができます。$x$。 

ブルートフォース検索はすべてのパスを明示的に試みますが、次の時点で失敗します。$n = 2 \cdot 10^5$。 最適な解決策は、DFS と組み合わせた値の二分探索に問題を還元して、サイクルを検出したり、しきい値付きサブグラフ内の最長パスを計算したりするものです。 これにより、複雑さはおおよそ次のようになります。$O((n+m) \log n)$、それは実現可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^k) | O(k) | 遅すぎる |
 | 二分探索 + DFS | O((n+m) log(max a_i)) | O(n+m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての一意の頂点値を収集し、並べ替えます。 これらは、シーケンスに沿った最小最大値の唯一の候補です。 
2.チェック機能の実装`can(x)`長さのシーケンスが存在する場合に True を返します$k$値を持つ頂点のみを訪問します$\le x$。 頂点のみを含むサブグラフを構築します。`a[i] <= x`そしてそれらの間のエッジ。 
3. で`can(x)`、再帰スタックを備えた DFS を使用して、サブグラフ内に循環があるかどうかを検出します。 サイクルがある場合、シーケンスは無限に拡張できます。 この場合は True を返します。 
4. サイクルが存在しない場合は、メモ化を伴う DFS を使用してサブグラフ内の最長パスの長さを計算します。 最長のパスに少なくとも$k$頂点の場合は True を返します。 それ以外の場合は False を返します。 
5. ソートされた一意の頂点値に対する二分探索。 候補者ごとに`x`、 使用`can(x)`それが可能かどうかを判断するためです。 検索を絞り続けて、実現可能な最小の最大値を見つけます。 
6. 候補者がチェックに合格しない場合 (すべてのサブグラフがサポートに失敗する)$k$移動)、戻ります$-1$。 

不変条件は、常に有効な頂点値の中から検索し、値が候補しきい値を超えないサブグラフのみを考慮することです。 DFS はサイクルを正確に識別し、到達可能性を過小評価しないことを保証します。 メモ化された最長パス計算により、非巡回サブグラフでの正しい評価が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**6)

def solve():
    n, m, k = map(int, input().split())
    a = list(map(int, input().split()))
    edges = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        edges[u-1].append(v-1)

    unique_vals = sorted(set(a))

    def can(x):
        subgraph = [[] for _ in range(n)]
        for u in range(n):
            if a[u] <= x:
                for v in edges[u]:
                    if a[v] <= x:
                        subgraph[u].append(v)

        visited = [0]*n
        dp = [0]*n

        def dfs(u):
            visited[u] = 1
            max_len = 1
            for v in subgraph[u]:
                if visited[v] == 0:
                    ret = dfs(v)
                    max_len = max(max_len, 1 + ret)
                elif visited[v] == 1:
                    return k  # cycle detected
                else:
                    max_len = max(max_len, 1 + dp[v])
            visited[u] = 2
            dp[u] = max_len
            return dp[u]

        max_path = 0
        for i in range(n):
            if a[i] <= x and visited[i] == 0:
                length = dfs(i)
                if length >= k:
                    return True
                max_path = max(max_path, length)
        return max_path >= k

    left, right = 0, len(unique_vals)-1
    ans = -1
    while left <= right:
        mid = (left + right)//2
        if can(unique_vals[mid]):
            ans = unique_vals[mid]
            right = mid - 1
        else:
            left = mid + 1
    print(ans)

solve()
```この解決策では、最初に各候補最大値のサブグラフを設定します。 DFS は、サイクル検出と最長パス計算の両方に使用されます。 の`visited`配列は、未訪問ノード、訪問ノード、処理済みノードを区別してサイクルを検出します。 二分検索は一意の値のみを反復処理するため、不必要な繰り返しチェックが回避されます。
