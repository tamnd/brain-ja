 ## 解決策
 ## 問題の理解

 上で一連の操作をシミュレートするように求められます。$n \times n$ルークが関与するチェス盤。 各ルークはその行と列全体を攻撃します。 クエリでは、ルークを配置するか、ルークを削除するか、または指定された長方形領域内のすべてのセルが少なくとも 1 つのルークによって攻撃されているかどうかを確認することが求められます。 サブ四角形が攻撃によって完全に覆われている場合、出力は「Yes」、そうでない場合は「No」です。 

ボードのサイズは最大です。$10^5 \times 10^5$、最大で$2 \cdot 10^5$クエリ。 ルークの配置ごとに各セルを明示的にマークしたり、四角形内のすべてのセルをチェックしたりする単純なアプローチでは、最大で$10^{10}$これは、一般的な競技プログラミングの制限時間内ではまったく実行不可能です。 これにより、クエリごとの複雑さがおおよそ次のようなソリューションを検討する必要があります。$O(\log n)$または$O(1)$。 

厄介なエッジ ケースには、1 行または 1 列のみにわたる四角形が含まれます。 両方の次元が 1 より大きいと仮定する不注意な実装では、実際には単一のルークが行または列全体を攻撃しているときに、四角形がカバーされていないと誤って報告する可能性があります。 もう 1 つの微妙な点は、ルークの配置と除去が重なっていることです。 同じ行または列に複数のルークを配置するには、その行または列を単に「攻撃された」または「攻撃されていない」として扱うのではなく、除去後に残っているルークの数を数える必要があります。 

## アプローチ

 ブルートフォース手法では、すべてのセルの状態が保存されます。 配置の場合、対応する行と列のすべてのセルが攻撃済みとしてマークされます。 削除の場合、それらのセルのマークが解除されます。 クエリでは、四角形内のすべてのセルがチェックされます。 これは小規模な場合に機能します$n$、しかし、$n = 10^5$、マーキング$n$配置またはチェックごとのセル$n^2$クエリごとのセルのリード$O(nq)$または$O(n^2 q)$操作。 と$q \sim 2 \cdot 10^5$、解決策が遅すぎます。 

重要な観察は、セルがその行または列に少なくとも 1 つのルークがある場合にのみ攻撃されるということです。 行または列のどこにルークがあるかを正確に知る必要はありません。 各行と列に少なくとも 1 つのルークがあるかどうかだけを知る必要があります。 したがって、個々のセルを追跡する代わりに、行または列ごとに現在その行または列に何人のルークがいるかを表すカウンターを維持できます。 ルークを配置すると、対応する行カウンターと列カウンターがインクリメントされます。 ルークを削除すると、ルークが減ります。 範囲内のすべての行のカウントがゼロ以外の場合、または範囲内のすべての列のカウントがゼロ以外の場合、四角形は完全にカバーされます。 

行と列の範囲にゼロがあるかどうかを効率的にチェックするには、ゼロ以外のカウンターを使用して行と列のセットまたはマップを維持し、最小インデックスと最大インデックスを比較します。 別のアプローチは、攻撃された行/列のブール配列に対してプレフィックスの合計を使用することです。$O(1)$更新後のクエリ$O(1)$ルークあたり。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2 * q) | O(n^2) | 遅すぎる |
 | 行/列カウンター | O(q) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つの配列を初期化する`row_count`そして`col_count`長さの$n+1$ゼロに。 これらは、各行と列に現在配置されているルークの数を保存します。 
2. 2つのセットを初期化する`rows_with_rook`そして`cols_with_rook`現在少なくとも 1 つのルークが含まれている行と列を追跡します。 
3. 各クエリについて:

 - タイプ 1 の場合 (ルークを置く)$x, y$)、増分`row_count[x]`そして`col_count[y]`。 カウントが1になったら追加します$x$に`rows_with_rook`そして$y$に`cols_with_rook`。 
- タイプ 2 の場合 (ルークを取り除く)$x, y$)、デクリメント`row_count[x]`そして`col_count[y]`。 カウントが0になったら削除$x$から`rows_with_rook`そして$y$から`cols_with_rook`。 
- タイプ 3 (四角形をチェック) の場合、四角形の最小および最大の行と列を抽出します。 長方形内に少なくとも 1 つのルークがある行の数が長方形内の行の数と等しい場合、または列についても同様の場合、長方形は完全に攻撃されます。 同様に、四角形内に対応するセットにない行または列が存在するかどうかを確認します。 存在しない場合は「Yes」を出力し、存在しない場合は「No」を出力します。 
4. タイプ 3 のすべてのクエリに対する回答を出力します。 

機能する理由: 行カウンターと列カウンターは、カウンターがゼロ以外の場合に限り、行または列が攻撃されるという不変条件を取得します。 これらのセットを使用すると、特定の四角形内のすべての行またはすべての列が攻撃されているかどうかを効率的に判断できます。 すべての行またはすべての列に少なくとも 1 つのルークがあり、ルーク攻撃の定義と一致する場合、長方形は完全に覆われます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, q = map(int, input().split())
row_count = [0] * (n + 1)
col_count = [0] * (n + 1)
rows_with_rook = set()
cols_with_rook = set()

for _ in range(q):
    query = list(map(int, input().split()))
    if query[0] == 1:
        x, y = query[1], query[2]
        row_count[x] += 1
        col_count[y] += 1
        rows_with_rook.add(x)
        cols_with_rook.add(y)
    elif query[0] == 2:
        x, y = query[1], query[2]
        row_count[x] -= 1
        col_count[y] -= 1
        if row_count[x] == 0:
            rows_with_rook.discard(x)
        if col_count[y] == 0:
            cols_with_rook.discard(y)
    else:
        x1, y1, x2, y2 = query[1], query[2], query[3], query[4]
        all_rows = all(row_count[i] > 0 for i in range(x1, x2 + 1))
        all_cols = all(col_count[j] > 0 for j in range(y1, y2 + 1))
        print("Yes" if all_rows or all_cols else "No")
```コードは各行と列のカウンターを維持し、セットを更新してどれが非ゼロであるかを認識します。 タイプ 3 のクエリは、四角形の範囲を反復してカバレッジを確認します。 範囲の長さが 1 である可能性があるため、エッジ ケースが処理されます。セットを使用すると、次のことが可能になります。`discard`存在を確認せずに、KeyErrors を防ぎます。
