 ## 解決策
 ## 問題の理解

 車輪の合計数を考慮して、フリートが何台のバスを使用できるかを決定するように求められます。 各バスには、4 輪の 2 軸バスと 6 輪の 3 軸バスの 2 つのタイプがあります。 入力は多数のテスト ケースで構成され、それぞれがホイールの合計数を指定します。出力は、このホイールの合計に合計できるバスの最小数と最大数でなければなりません。 どのバスの組み合わせもその合計を生成できない場合、出力は次のようになります。`-1`。 

制約は算術演算には寛大ですが、単純な列挙には制限が厳しくなります。 車輪の数`n`これは、バスのすべての組み合わせを列挙しようとするソリューションが実行不可能であることを意味します。 最大 1,000 のテスト ケースで 1 秒の制限時間は、テスト ケースごとに O(1) または O(log n) のソリューションが必要であることを意味します。 エッジケースには、次のような小さな合計が含まれます。`1`、`2`、 または`3`、4 輪および 6 輪のバスでは形成不可能であり、非常に大きな合計は、オーバーフローすることなく正確な整数演算を使用して処理する必要があります。 

素朴なアプローチは、合計が奇数であるか、4 と 6 の合計に割り切れない場合に失敗する可能性があります。 例えば、4+4=8でも超えてしまい、6+4=10でも超えてしまいますので、7輪は成り立ちません。 などの小さな入力`4`または`6`アルゴリズムでは、単一のバスのみが可能であること、つまり最小値と最大値を同時に検出する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、車輪の合計が以下になる 2 軸バスと 3 軸バスのすべての組み合わせを試します`n`。 それぞれについて`a`で`[0, n//4]`、それはかどうかをチェックします`n - 4*a`は 6 で割り切れます。すべての有効なパーティションを考慮するのでこれは正しいですが、テスト ケースごとに最大 n/4 の反復が必要です。 のために`n = 10^18`、これはまったく不可能です。 

重要な洞察は、単純な整数演算から得られます。 させて`x`は 2 軸バスの台数、`y`3軸バスの台数。 次に、線形ディオファントス方程式が得られます。`4*x + 6*y = n`。 両辺を2で割ると、`2*x + 3*y = n/2`。 を解決できるようになりました`x`そして`y`負でない整数として。 バスの最小数は最大化したときに発生します。`y`, 3軸バスはバス1台あたりの車輪の数が多いためです。 これは次のことにつながります`y = floor(n/6)`もし`n`が 2 で割り切れる場合、`x`残りのホイールを 4 で割った値です。バスの最大数は、最大化したときに発生します。`x`、につながる`x = floor(n/4)`そして`y`adjusted accordingly. もし`n`が奇数であるか、2 で割った余りが 2 で割り切れない場合、解は存在しません。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n) | お(1) | 遅すぎる |
 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 各テスト ケースについて、合計ホイール数を読み取ります。`n`。 
2. 次のことを確認します。`n`4 未満である場合、出力`-1`バスの組み合わせが 4 つ未満の車輪を持つことはできないからです。 
3. できるだけ多くの 3 軸バスを使用して、バスの最小数を計算します。 セット`min_buses = ceil(n/6)`それぞれの 3 軸バスが 6 つの車輪に寄与するためです。 もし`n`は 2 で割り切れるので、整数演算で十分です。 
4. できるだけ多くの 2 軸バスを使用して、バスの最大数を計算します。 セット`max_buses = n // 4`それぞれの 2 軸バスが 4 つの車輪に寄与するためです。 
5.次のことを確認します`n`は 2 で割り切れます。割り切れない場合は、出力します`-1`4 と 6 は両方とも偶数なので、奇数の合計は不可能だからです。 それ以外の場合は、印刷します`min_buses`そして`max_buses`。 

正しさは、4 輪バスと 6 輪バスのすべての有効な組み合わせの合計が偶数にならなければならないという不変条件に依存します。 3 軸バスの数を最大化すると総バス数が最小になり、2 軸バスを最大化すると総バス数が最大になります。 下限と上限の算術演算により、実行可能な整数解を見逃さないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    if n < 4 or n % 2 != 0:
        print(-1)
        continue
    min_buses = (n + 5) // 6  # ceil(n / 6)
    max_buses = n // 4         # floor(n / 4)
    print(min_buses, max_buses)
```コードは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 小さすぎる合計や奇数の合計はすぐに除外されます。 3 軸バスで十分な車輪が確実にカバーされるように、バスの最小数は天井分割を使用します。 バスの最大台数は、2 軸バスを最大化するためにフロア分割を使用します。 どちらの除算も、Python では非常に大きな整数を正しく処理できます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    t = int(input())
    for _ in range(t):
        n = int(input())
        if n < 4 or n % 2 != 0:
            print(-1)
            continue
        min_buses = (n + 5) // 6
        max_buses = n // 4
        print(min_buses, max_buses)
    return out.getvalue().strip()

 ## 特殊なケース

 いつ`n`4 より小さい場合、アルゴリズムはすぐに戻ります`-1`。 奇数の場合は次のようになります`7`、`5`、 または`1`、アルゴリズムは戻ります`-1`4と6の合計が奇数になることはないからです。 2 の倍数の場合ですが、4 や 6 の倍数ではありません。たとえば、`10`の場合、アルゴリズムは剰余を適切に分配することで最小値と最大値を正しく計算します。 非常に大きな数値の場合、Python はオーバーフローすることなく整数演算を処理し、次のような場合でも正確さを保証します。`n`10^18に近づきます。
