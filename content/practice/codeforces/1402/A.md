 ## 解決策
 ## 問題の理解

 私たちに与えられたフェンスは、$N$長方形のセクションを並べて配置します。 各セクション$i$幅があります$w_i$そして高さ$h_i$。 私たちのタスクは、これらのセクションの上に完全に形成できる軸に沿った長方形をすべて数えることです。 長方形は、その辺がフェンスの辺と平行になるようにフェンス上に配置する必要があり、セクションの上に浮いたり、セクションを越えて広がったりせず、その座標は整数である必要があります。 

入力サイズは非常に大きくなる場合があります。$N$まで可能です$10^5$、個々の高さと幅は最大です。$10^9$。 これにより、考えられるすべての四角形を明示的に考慮するソリューションは除外されます。これは、可能性のある四角形の数は、おおよそ合計幅の 2 乗に応じて増加し、この幅を簡単に超える可能性があるためです。$10^{14}$。 したがって、フェンスの構造を活用する数学的または組み合わせ的なアプローチを探す必要があります。 

微妙なエッジ ケースは、連続するセクションの高さが異なる場合です。 素朴なアプローチでは、すべてのセクションが複数の幅にまたがる長方形を形成するのに十分な高さがあると想定するかもしれませんが、1 つのセクションが短い場合、フェンスの境界を侵さずに長方形をその上に拡張することはできません。 たとえば、高さが [1, 2] で幅が [1, 2] の場合、両方のセクションにまたがる一部の長方形は、短い方の高さ 1 に制限されます。不注意なアプローチでは、これらを過剰にカウントする可能性があります。 

もう 1 つのエッジ ケースは、非常に高いセクションや幅の広いセクションです。この場合、単純なネストされたループ内の四角形の合計がオーバーフローしたり、遅すぎたりします。 アルゴリズムは大きな数値を効率的に処理する必要があるため、数式ベースの計数方法とモジュラー演算が推奨されます。 

## アプローチ

 ブルート フォース アプローチの説明は簡単です。セクション全体の左右の境界によって定義されるすべての可能な長方形を考慮し、そのスパン内の最小の高さまで可能なすべての高さに対して反復処理を行います。 各長方形を数えます。 これは正しいですが、操作の数は次の値に比例します。$O(\text{total width}^2 \cdot \text{min height})$。 と$N = 10^5$幅/高さは最大$10^9$、これはまったく不可能です。 

重要な洞察は、明示的な列挙ではなく組み合わせ論を使用してセクションごとに四角形をカウントすることです。 幅の単一セクションの場合$w$そして高さ$h$、中に収まる長方形の数は$\frac{w(w+1)}{2} \cdot \frac{h(h+1)}{2}$。 幅係数は連続するサブ幅をカウントし、高さ係数は連続するサブ高さをカウントします。 この式は 1 セクションを一定時間で処理します。 

複数のセクションを処理するには、連続したセクションにまたがる長方形を考慮する必要があります。 このような長方形の幅は、複数の値を合計することができます。$w_i$、ただし、高さはスパン内の最小高さによって制限されます。 単調スタック手法を使用して、セクションごとに、より短いセクションに遭遇するまで左方向に伸びる幅の合計を計算できます。 これにより、問題は線形時間に短縮されます。各セクションは、その幅、高さ、およびスタックによって決定される「スパン」に基づいて、特定の数の長方形を提供します。 このアプローチは、高さの制約は左方向に拡張する場合にのみ減少するという事実を利用します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O((\sum w_i)^2 \cdot \max h_i)$| お(1) | 遅すぎる |
 | 最適 |$O(N)$| O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 次の式を使用して、各セクション内の長方形の合計を個別に計算します。$\frac{w_i(w_i+1)}{2} \cdot \frac{h_i(h_i+1)}{2}$。 これにより、単一セクション内の長方形全体がカウントされ、合計にすぐに反映されます。 
2. 複数のセクションにまたがる長方形の場合、セクションの高さの増加しないシーケンスを表すインデックスのスタックを維持します。 セクションごとに$i$、最上部の高さが以下になるまでスタックからポップします。$h_i$。 これにより、左側に最も近い小さい高さが検索され、これにより、その幅の最大幅が決まります。$h_i$制限高さまで伸ばすことができます。 
3. スタックによって決定されるスパンの幅の合計を計算します。 この合計は、高さの長方形が構成される連続する幅の単位の数を表します。$h_i$延長することができます。 乗算する$h_i$そして、それらの幅で可能なサブ四角形の数によって決まります (連続する整数の合計式)。 
4. 現在のインデックスをプッシュします$i$スタックに追加して続行します。 すべてのセクションが処理されるまで繰り返します。 各ステップで、合計四角形数のモジュロを更新します。$10^9+7$。 
5. 合計モジュロを出力します$10^9+7$。 

ここで不変なのは、各セクションで、現在の高さが最小の高さである左側の最大の連続スパンをスタックが正しく識別することです。 これにより、すべての四角形を正確に 1 回カウントし、スパン内のセクションの高さを超える無効な四角形が含まれないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def count_rectangles(N, heights, widths):
    total = 0
    # rectangles inside individual sections
    for h, w in zip(heights, widths):
        total += (h * (h + 1) // 2) * (w * (w + 1) // 2)
        total %= MOD
    
    # rectangles spanning multiple sections
    stack = []
    sum_widths = [0] * N
    for i in range(N):
        while stack and heights[stack[-1]] > heights[i]:
            stack.pop()
        if stack:
            prev = stack[-1]
            span = sum_widths[prev] + widths[i]
        else:
            span = widths[i]
        sum_widths[i] = span
        total += heights[i] * (heights[i] + 1) // 2 * (span * (span + 1) // 2 - widths[i] * (widths[i] + 1) // 2)
        total %= MOD
        stack.append(i)
    
    return total % MOD

def main():
    N = int(input())
    h = list(map(int, input().split()))
    w = list(map(int, input().split()))
    print(count_rectangles(N, h, w))

if __name__ == "__main__":
    main()
```コードの各部分はアルゴリズムのステップを直接反映します。 まず個々のセクション長方形を計算し、次に単調スタックを管理して複数セクションの長方形を効率的に処理します。 事前に計算されたスパン合計を使用すると、再計算が回避され、線形時間が保証されます。 モジュラー演算により、オーバーフローが発生しません。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(N) | 各セクションはスタックから最大 1 回プッシュおよびポップされ、幅の合計が段階的に計算されます。 |
 | スペース | O(N) | stack および sum_widths 配列には、それぞれ最大 N 個のエントリが保存されます。 |

 N を最大で指定すると、$10^5$N での線形演算により、アルゴリズムは 1 秒以内とメモリ制限内で快適に実行されます。
