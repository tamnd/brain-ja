 ## 解決策
 ## 問題の理解

 私たちは、講堂での一連の講義をスケジュールする任務を負っています。各講義では共有マーカーが使用されます。 各講師には個人的な許容範囲があり、一定回数使用されたマーカーの使用を拒否し、代わりに新しいマーカーを要求します。 私たちの目標は、講師が要求した場合にのみマーカーを交換しながら、実際に使用される個別のマーカーの数を最大化する講義順序を選択することです。 

入力は複数の独立したテスト ケースを提供します。 ケースごとに、講義の数と、各講師の許容範囲を表す整数の配列が与えられます。 出力は、マーカーの使用を最大化する講師インデックスの順序です。 制約は中程度です。テスト ケースは最大 100 件、それぞれのテスト ケースには最大 500 件のレクチャーが含まれます。つまり、操作の総数は、時間の複雑さが次の程度のソリューションに問題なく適合する必要があります。$O(n \log n)$または$O(n^2)$テストケースごとに。 

エッジ ケースは、複数の講師が同じ許容値を持つ場合、またはすべての講師の許容しきい値が非常に低い、または非常に高い場合に発生します。 たとえば、すべての講師の許容値が 1 の場合、最初の講義以降のすべての講義でマーカーの置換が強制されます。 不注意なアルゴリズムが許容値の相対的なサイズを無視すると、使用するマーカーの数を不必要に減らす順序で講師をスケジュールする可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、講師の考えられるすべての順列を考慮し、順列ごとに講義シーケンスをシミュレートし、使用されたマーカーの数を数えます。 この方法は正しいですが、順列の数が階乗的に増加するため実行不可能です。$n!$、これは実用的ではありません$n = 10$。 

重要な洞察は、相対許容値に焦点を当てることです。 マーカーを交換する必要があるのは、現在の講義の許容範囲がマーカーがすでに使用されている回数を超えた場合のみです。 使用されるマーカーの数を最大化するには、許容値が最も低い講師を早く来てもらいます。講師の交代が早くなるからです。 現在のマーカーの寿命を延ばすために、より高い許容値を持つ講師を後でスケジュールすることができます。 

これは、講師を許容値の昇順に並べ替えることで実現されます。 これにより、必要に応じてマーカーを交換し、すぐに拒否されるマーカーについての講義を無駄にすることがなくなります。 順序を構築するためにソートされたリストを 1 回通過するだけで済むため、このアプローチは効率的でシンプルです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | 許容範囲による貪欲な並べ替え | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. 各テスト ケースについて、講義の数と合格値の配列を読み取ります。 
3. 元の位置を維持できるように、各講師のインデックスと許容値を組み合わせます。 
4. このペアのリストを許容値の昇順で並べ替えます。 
5. ソートされたインデックスを講義順として抽出します。 
6. 現在のテスト ケースの結果の順序を出力します。 

効果がある理由: 常に、受け入れ閾値が小さい講師を最初に配置することで、各マーカーが交換が必要になる前に最大使用回数に達することが保証されます。 この貪欲なアプローチにより、使用されるマーカーの数が最大化されることが保証されます。これは、いかなる逸脱（耐性の高い講師を早期に配置すること）によってもマーカーの使用量を増やすことができないためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        # pair index with value
        indexed = [(a[i], i + 1) for i in range(n)]
        # sort by acceptance value ascending
        indexed.sort()
        # extract order
        order = [idx for _, idx in indexed]
        print(' '.join(map(str, order)))

if __name__ == "__main__":
    solve()
```元の番号付けを維持するために、各講師の許容値と 1 から始まるインデックスを組み合わせます。 並べ替えにより、可能な限り効率的にマーカーの置換をトリガーできるようになります。 ソートしてインデックスを抽出すると、希望する講義順序が得られます。 使用する`sys.stdin.readline`特に複数のテスト ケースの場合、高速な入力処理が保証されます。

 ## 特殊なケース

 すべての講師の受け入れ値が同じであれば、どの順序でも機能します。 公差による並べ替えでは Python の安定した並べ替えの相対順序が維持されるため、アルゴリズムはこれを正しく処理します。 単一の講師の場合、アルゴリズムはその講師を正しく出力します。 すでに昇順または降順の許容値でソートされているシーケンスの場合、アルゴリズムは順序を適切に維持または逆転し、不必要な置換を行わずに最大のマーカーが使用されるようにします。
