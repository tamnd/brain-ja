 ## 問題の理解

 2 つの整数が与えられます。`k`そして`l`。 タスクは、次のことを判断することです。`l`の正確な累乗として書くことができます`k`。 

言い換えれば、負でない整数が存在するかどうかを確認する必要があります。`n`次のような:$l = k^n$そのような場合`n`存在する場合は印刷します`"YES"`また、数値の重要性も出力します。これは正確に`n - 1`声明の用語では。 例えば、`k^1`～の出現はゼロです`"la"`、`k^2`オカレンスが 1 つある、など。 

制約は十分に小さいため、高度な数学や対数は必要ありません。 どちらの数値も 32 ビットの符号付き整数内に収まるため、乗算や除算を繰り返すことは完全に可能です。 以来、`k`指数関数的に増加する、超過するまでのステップ数`l`せいぜい31歳くらいのとき`k >= 2`。 

主な危険は、指数カウントを正しく処理することです。 ステートメントは重要度の数をカウントするため、不注意に実装すると間違った重要度の値が簡単に出力される可能性があります。`"la"`指数そのものではなく言葉です。 

次の例を考えてみましょう。 

入力:```
5
25
```ここ：$25 = 5^2$指数は`2`、しかし重要なのは`1`、 なぜなら`"petricium la petricium"`1つ含まれています`"la"`。 

別の微妙なエッジケースが現れるのは、`l`で割り切れない`k`プロセス中。 

入力：```
3
10
```累乗を続ける単純なループでは、オーバーシュートが発生したり、浮動小数点対数を使用したりして、精度の問題が発生する可能性があります。 正しい答えは、`"NO"`の整数乗がないので、`3`等しい`10`。 

もう 1 つの重要なケースは次のような場合です。`l = k`。 

入力：```
7
7
```これは以下に対応します。$7 = 7^1$答えは次のようになります。```
YES
0
```重要性が重要だから`"la"`言葉、そして第一乗には何もありません。 

## アプローチ

 ブルートフォースのアイデアは単純です。 から開始`1`を繰り返し乗算します。`k`、最終的に到達するかどうかを確認します`l`。 

例えば：```
1 -> k -> k^2 -> k^3 -> ...
```これが機能するのは、シーケンス内のすべての有効な数値が昇順に生成されるためです。 現在値を超えた瞬間`l`、私たちは知っています`l`不可能です。 

このアプローチは、指定された制約に対してすでに十分に高速ですが、この問題をさらに明確に考える方法があります。 力を上向きに構築する代わりに、力を減らすことができます。`l`下向きに。 

もし`l`本当に力です`k`で割ります。`k`繰り返し、最終的には到達する必要があります`1`。 

例えば：$125 \to 25 \to 5 \to 1$分割が成功するたびに、次の要素が 1 つ取り除かれます。`k`。 いつか`l`で割り切れない`k`、その場合、表現は不可能です。 

この除算ベースの方法は、オーバーフローの危険がなく、自然に指数カウントが得られるため、より簡単です。

 ## アルゴリズムのチュートリアル

 1. 整数の読み取り`k`そして`l`。 
2. カウンタの初期化`cnt = 0`。 このカウンターは、正常に除算した回数を追跡します。`k`。 
3. その間`l`で割り切れます`k`、 分ける`l`による`k`そして増加します`cnt`。 

各除算は次のべき乗を 1 つ取り除きます。`k`番号から。 
4. ループが終了したら、`l == 1`。 

もし私たちが到達したなら`1`の場合、元の数値は正確に次のべき乗になります。`k`。 
5. もし`l == 1`、印刷`"YES"`そして印刷する`cnt - 1`。 

指数そのものは、`cnt`、しかし問題は次の数を求めます。`"la"`単語が 1 つ減ります。 
6. それ以外の場合は、印刷します`"NO"`。 

### なぜ効果があるのか

 このアルゴリズムは、各反復後に、 の現在の値が変化するという不変条件を維持します。`l`元の数値を次の値で割った値に等しい`k^cnt`。 

元の数値が本当に次の場合:$l = k^n$それから正確にその後`n`私たちが取得しなければならない部門`1`。 

ある時点で分割が不可能な場合は、`l % k != 0`の場合、少なくとも 1 つの素因数が属していません。`k`、したがって、数値は純粋な累乗にはなりません。`k`。 

ループはちょうど 1 つの要素を削除するため、`k`反復ごとに、`cnt`が指数となり、`cnt - 1`必要な重要度になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    k = int(input())
    l = int(input())

    cnt = 0

    while l % k == 0:
        l //= k
        cnt += 1

    if l == 1:
        print("YES")
        print(cnt - 1)
    else:
        print("NO")

solve()
```このソリューションは、次の要因を繰り返し除去します。`k`から`l`。 

ループ条件が重要な詳細です。```
while l % k == 0:
```割り算が正確な場合にのみ割り算を行います。 これにより、整数除算が黙って情報を破棄する無効な状態が防止されます。 

変数`cnt`除算が成功した回数を格納します。 元の番号が`k^n`、その後、ループが正確に実行されます`n`回。 

最後の減算:```
cnt - 1
```見逃しやすいです。 この問題では指数自体は求められません。 の数を尋ねます`"la"`フレーズ表現における接続子。 

除算では値が減少するだけであるため、オーバーフローの問題は発生しません。`l`。
