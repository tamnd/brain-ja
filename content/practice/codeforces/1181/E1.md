 ## 解決策
 ## 問題の理解

 私たちは与えられています`n`2D 平面上の城。それぞれが整数の座標を持つ軸に揃えられた長方形で表されます。 それぞれの城は元々は領土が長方形だった国に属していました。 この物語では、各国の連合が長方形を形成すれば合併でき、最終的にはすべての国が 1 つに合併できると主張しています。 ただし、城はそのまま残り、交差しません。 私たちの仕事は、城の位置を説明できる初期の国の領土セットが少なくとも 1 セット存在するかどうかを判断することです。これは、すべての合併が長方形の特性を尊重する方法で行われた可能性があることを意味します。 

入力により城の座標は得られますが、領土は得られません。 初期テリトリーの一貫したセットが存在する場合、出力は「YES」、それ以外の場合は「NO」でなければなりません。 

制約`1 ≤ n ≤ 1000`までのコーディネート`10^9`考えられるすべてのマージを単純にシミュレートすることはできないことを意味します。 四角形のあらゆる組み合わせを試すブルートフォースアプローチでは、次のような時間がかかります。`O(2^n)`完全に不可能な時間です`n = 1000`。 明らかではないエッジ ケースには、複数のマージが同時に発生する必要がある行または列に沿って並んでいる城が含まれます。 たとえば、4 つの城が形成されている場合、`2x2`正方形の場合、一番上の行だけを最初にマージするか、左の列だけを最初にマージすると、それ以上のマージがブロックされる可能性があり、不注意なマージ順序のシミュレーションによって誤って「NO」と判定される可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、各城の初期領土を推測し、考えられるすべての合併シーケンスをチェックしようとします。 のために`n`城、あります`n!`注文を統合します。 各マージでは、境界四角形を計算し、重複をチェックする必要があり、次のような操作が必要になります。`O(n! * n)`最悪の場合。 これは明らかに実行不可能です。 

重要な洞察は、問題が、各グループ自体が長方形を形成できるように、城のグループを 1 本の水平線または垂直線に沿って 2 つのグループに分割できるかどうかを再帰的にチェックすることに帰着するということです。 この観察により、すべてのマージを明示的に列挙する必要がなくなります。 長方形の完全性を崩さずに城を分割できるように、すべての有効な城のグループには垂直線または水平線が必要です。 有効な分割が見つかったら、同じロジックをサブグループに再帰的に適用します。 この分割統治アプローチは、分割するたびに再帰呼び出し内の城の数が減り、最大でも城の数が減るため、効率的に機能します。`n-1`分割が必要です。 

長方形は長方形の形状を維持する方法でのみマージできるため、ブルートフォースは機能しますが、サイズが大きい場合は失敗します。`n`組み合わせ爆発によるもの。 軸に沿った分割に関する観察により、問題を境界ボックスを再帰的にチェックするという問題に減らすことができます。これは次のように実行できます。`O(n^2)`可能性のあるパーティションラインを注意深くスキャンすることで時間を短縮します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | 再帰的分割 | O(n^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 現在のグループ内のすべての城の外接する長方形を計算します。 この長方形をまたがるようにしてください`xmin`に`xmax`そして`ymin`に`ymax`。 
2. グループに城が 1 つしかない場合、それは自明に有効です。`True`。 
3. 垂直方向の分割を確認します。 城を左の X 座標で並べ替えます。 左から右にスキャンして、これまでに確認された城の右端の X 座標を追跡します。 ある時点で、この右端の座標が次の城の左の x 座標と等しい場合、ここを左と右のサブグループに分割します。 
4. 垂直分割が見つかった場合は、両方のサブグループを再帰的にチェックします。 両方とも戻ってきたら`True`、現在のグループは有効です。 
5. 垂直方向の分割が機能しない場合は、y 座標に対して同じ手法を使用して水平方向の分割を試みます。 
6. 水平分割も機能しない場合は、戻ります。`False`現在のグループの場合。 
7. 最初に、城の完全なリストに対してこの再帰的チェックを呼び出します。 戻ってきたら`True`、「YES」を出力します。 それ以外の場合は、「NO」を出力します。 

機能する理由: 有効な城のグループはそれぞれ、最終的に 1 つの長方形にマージできる必要があります。 再帰的分割により、すべてのステップで、長方形の結合を形成できる城のみがグループ化されることが保証されます。 軸に合わせた分割が存在しない場合、マージの有効なシーケンスは不可能になり、正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(2000)

def can_form(castles):
    if len(castles) == 1:
        return True

    # Attempt vertical split
    castles.sort(key=lambda x: x[0])
    rightmost = castles[0][2]
    for i in range(1, len(castles)):
        if rightmost == castles[i][0]:
            if can_form(castles[:i]) and can_form(castles[i:]):
                return True
        rightmost = max(rightmost, castles[i][2])

    # Attempt horizontal split
    castles.sort(key=lambda x: x[1])
    topmost = castles[0][3]
    for i in range(1, len(castles)):
        if topmost == castles[i][1]:
            if can_form(castles[:i]) and can_form(castles[i:]):
                return True
        topmost = max(topmost, castles[i][3])

    return False

n = int(input())
castles = [tuple(map(int, input().split())) for _ in range(n)]

print("YES" if can_form(castles) else "NO")
```このソリューションは、まず入力を読み取り、城の四角形を保存します。 再帰関数`can_form`有効な垂直分割と水平分割をすべて試行します。 x または y で並べ替えると、ギャップを残さない分割が確実に見つかります。 右端/上端の座標を使用すると、長方形が完全に揃っている場所でのみ分割されることが保証され、重複や部分的なマージが回避されます。 安全に処理するために再帰制限が増加しました`n = 1000`。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n^2) | 再帰試行の各レベルは、ソートされた座標に沿って分割されます。 ソートには O(n log n) かかりますが、部分的なソートは合計 O(n^2) | で再利用できます。 
| スペース | O(n) | 再帰スタックの深さは最大 n、さらに分割用の一時リスト |

 与えられた`n ≤ 1000`, O(n^2) 操作 (~1e6) は 4 秒以内であれば安全であり、メモリ使用量は 512 MB をはるかに下回ります。
