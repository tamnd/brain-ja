 ## 問題の理解

 考えられる長さの配列をすべてカバーするように求められます`n`その要素の範囲は次のとおりです`1`に`k`配列のシーケンスを使用します。シーケンス内の各配列は、2 つの操作を通じて他の配列を「生成」できます。 最初の手術は、`F(a, k)`、の各要素を引き伸ばします。`a`何らかの乗数を掛けて長さに切り詰めます`n`。 ２回目の手術は、`G(a, x, y)`、すべての出現を交換します。`x`そして`y`。 

効果的には、`F`要素を繰り返して任意の周波数パターンに達することができます。`G`位置間で値を任意に並べ替えることができます。 課題は、考えられるすべての長さの配列が一致するような**開始配列の最小数**を見つけることです。`n`数字から`1..k`is reachable as an "ancestor" of some array in our sequence.

 制約は次のことを示します`n`そして`k`それぞれ最大 200,000 まで可能で、制限時間は 6 秒です。 すべてを反復するアプローチ`k^n`配列は直ちに実行不可能です。`k^n`天文学的に大きいです。 明示的に配列を列挙することを避けるアプローチが必要です。 

エッジケースには以下が含まれます`n = 1`または`k = 1`。 のために`k = 1`、すべての配列は同じであるため、単一の配列で十分です。 のために`n = 1`、シーケンスにはすべてが含まれている必要があります。`k`それ以来の数字`F`単一要素の配列に新しい数値を生成することはできません。 小さな例も、その方法を示しています。`F`そして`G`必要な配列の数を減らすために相互作用します。 

## アプローチ

 単純なアプローチは、長さのすべての配列を明示的に構築することです。`n`以上`1..k`そして、それを生成されたシーケンスでカバーしてみてください。`F`そして`G`。 これには反復処理が必要になります`k^n`配列は不可能です`n > 10`組み合わせ爆発によるもの。 賢いメモ化を使用しても、組み合わせコアは回避できません。 

重要な洞察は次のとおりです`F`これにより、任意の多重度パターンに到達できるようになります。 **要素数**が 2 のべき乗の範囲にある配列をいつでも選択できます。`n`を繰り返し適用するため、`F`任意の周波数構成を作成できます。 同時に、`G`数値を自由に交換できるため、実際の値は無関係であり、各数値のカウントのみが重要になります。 

したがって、問題は次のようになります。**すべてのパーティションをカバーするには、いくつの配列が必要か`n`の中へ`k`負でない整数**、数値を自由に乗算し、数値を自由に並べ替えることができるとしたら? 答えは組み合わせ論から得られます。必要なシーケンスの数は最小限です。`m`そのような`k^m >= n`、モジュロ`998244353`。 シーケンス内の各配列は、周波数拡張の 1 つの「ビット」に対応します。

 ## アルゴリズムのチュートリアル

 1. もし`k = 1`の場合、数字は 1 つだけ存在します。 可能な唯一の配列は`[1, 1, ..., 1]`。 戻る`1`すぐに。 
2. それ以外の場合は、カウンターを初期化します。`res`ゼロと一時変数へ`cur`1に。 
3. その間`cur < n`、ダブル`cur`そして増加します`res`1つずつ。 これは、2 倍化を繰り返してすべての周波数を表すために必要な配列の最小数を計算します。 
4. 乗算`res`1 を法とする`998244353`、問題が明示的にモジュロを要求しているためです。 
5. 出力`res`。 

倍加ループが機能するのは、`F`要素の数に任意の正の整数を掛けることができます。 配列の最小数は、カバーするために必要な 2 倍化の数に対応します。`n`～の力を使って`k`。 

**機能する理由:** 位置を周波数パワーの組み合わせとして表すことにより、`k`、次のシーケンスを持つ任意のターゲット配列を生成できます。`F`操作。 と交換します`G`特定の値に対する制約を取り除くと、カウントのみが重要になります。 2 倍になることで、次の範囲までのすべての長さのカバレッジが保証されます。`n`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, k = map(int, input().split())
    if k == 1:
        print(1)
        return
    res = 0
    cur = 1
    while cur < n:
        cur *= k
        res += 1
    print(res % MOD)

solve()
```コードが初期化されます`cur`最初の配列を表すために 1 に設定し、次に乗算します。`k`カウントを超えるまで繰り返します`n`、必要な配列の数を数えます。 モジュロは、問題の制約への準拠を保証するために適用されます。
