 ## アルゴリズムのチュートリアル

 問題をカウントの観点から再構成します。 それぞれの$m$サンプリングされた要素は独立してセット内に存在します$[1,k]$確率的に$k/n$、そして$[k+1,n]$さもないと。 させて$X_m$サンプリングされた要素の数になります$\le k$。

4. それぞれについて$m$から$1$に$n$、DP を更新します。

### なぜ効果があるのか

 DP は、サンプリングされた要素の数が以下に該当するかどうかの完全な分布をエンコードします。$k$。 内部では相対的な順序があるため、$[1,k]$重要ではありません。カウントのみが影響するかどうかに影響します。$d$- 番目に小さいものが次を超える$k$。 漸化式は独立したベルヌーイ試行と正確に一致するため、DP はすべてのステップで真の二項分布を保存します。 切り捨て$d-1$これを超える状態はクエリのイベントに寄与しないため、これは有効です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

n, d, k = map(int, input().split())

inv_n = modinv(n)
p = k * inv_n % MOD
q = (n - k) * inv_n % MOD

dp = [0] * (d + 1)
dp[0] = 1

res = []

for m in range(1, n + 1):
    ndp = [0] * (d + 1)

    for x in range(d):
        if dp[x] == 0:
            continue
        ndp[x] = (ndp[x] + dp[x] * q) % MOD
        if x + 1 <= d:
            ndp[x + 1] = (ndp[x + 1] + dp[x] * p) % MOD

    dp = ndp

    if m >= d:
        res.append(sum(dp[:d]) % MOD)

print("\n".join(map(str, res)))
```この実装では、各層がサンプル サイズの増加に対応するローリング DP が維持されます。 移行では、分布を損なう可能性のある古い確率と新しい確率の混合を避けるために、慎重に新しい配列を使用します。 

での境界処理$x + 1 = d$それを超えた状態は安全なので、$d-1$最終的な確率には関係ありません。 このしきい値を超える値が必要になることを明示的に避けます。
