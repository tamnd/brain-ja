 ## アルゴリズムのチュートリアル

 各ビットを個別に切り替えるメリットを事前に計算し、カーディナリティ制約の下で最適なビットのサブセットを選択します。 

1. ビット位置ごとに$j$0から$m-1$、配列をスキャンしてその寄与を計算します。 要素ごとに$a_i$、計算します$b = a_i \oplus (1 << j)$かどうかを確認してください$b > a_i$。 そうであれば、ゲインは$b - a_i$。 これを蓄積していきます$gain[j]$。 このステップでは、このビットが使用可能になった場合に合計がどの程度改善されるかを測定します。$x$。 
2. すべてのゲインが計算されたら、各ビットを値を持つ項目として扱います。$gain[j]$。 せいぜい使えるので$k$合計ビット数、最大で選択したい$k$合計ゲインが最大のビット。 
3. ゲインを減少させることによってビット位置を並べ替えますが、2 つのビットが同じゲインを持つ場合は、小さいインデックスが最初に優先されます。 この順序付けにより、複数の解が同じ合計を生成する場合に、可能な限り最小の解が構築されることが保証されます。$x$。 
4.初期化する$x = 0$。 ソートされたビットを反復処理し、ビットごとに$j$、 もし$gain[j] > 0$そしてまだ割り当てが残っています$k$、ビットを設定します$j$で$x$、デクリメント$k$、続けます。 非正のゲインを持つビットは合計を改善しないため、決して選択されません。 
5. 最後にアウトプット$x$。 

重要な隠れたステップは、各ビットの効果が最終合計の改善という観点から独立して評価できることを認識することです。これは、最大演算によって改善のみが維持されることが保証され、固定ビットでの XOR は他のビットに依存しないためです。$x$そのビットが要素に役立つかどうかを評価するとき。 

### なぜ効果があるのか

 各ビットは、以下に含める候補として考慮された場合、合計に対する独立した非負の限界ゲインに寄与します。$x$。 この変換により、要素ごとに、単一ビットの反転による改善が、元の値と反転された値を比較することによって完全に決定されるようになります。$x$ゲインの単純な加算を超えて互いに打ち消したり増幅したりしないでください。 これにより、グローバルな目的は、サイズ制約の下で独立した重みの最大合計を持つビットのサブセットを選択することと同等になり、最適な重み付けされたビットを貪欲に取得することで最適性が維持され、ビット位置によるタイブレークにより最小の重みが保証されます。$x$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    gain = [0] * m
    
    for j in range(m):
        bit = 1 << j
        g = 0
        for x in a:
            y = x ^ bit
            if y > x:
                g += (y - x)
        gain[j] = g
    
    bits = list(range(m))
    bits.sort(key=lambda j: (-gain[j], j))
    
    x = 0
    used = 0
    
    for j in bits:
        if used == k:
            break
        if gain[j] > 0:
            x |= (1 << j)
            used += 1
    
    print(x)

if __name__ == "__main__":
    solve()
```このソリューションでは、各ビットを含めることに決めた場合に、それがどの程度役立つかをまず計算します$x$。 ビットと配列要素に対する入れ子になったループがコアの計算であり、コストがかかります。$O(nm)$。 

ゲインを計算した後、常に高い利益が最初に優先されるようにビットを並べ替え、同じ利益の場合は低いビット インデックスを優先します。 この問題では可能な限り最小限のものが必要なため、この順序は不可欠です。$x$これは、ゲインが同点の場合、より小さいビット位置が優先されることを意味します。 

次に、以下までを貪欲に選択します。$k$正のゲインを持つビット。 選択された各ビットは最終マスクに直接挿入されます。

 ## 特殊なケース

 エッジケースの 1 つは次のような場合です$k = 0$。 アルゴリズムはすべてのゲインを計算しますが、ビットは選択しません。$x = 0$。 入力用`5 3 0 / 7 7 7`、選択ステップではゼロビットが強制され、出力は 0 のままであるため、すべてのゲイン計算は無関係です。 

別のエッジ ケースは、すべてのゲインが正でない場合に発生します。 たとえば、すべての場合、$a_i$はそのビット構造においてすでに最大であるため、任意のビットを反転しても値が減少するだけです。 この場合、ゲイン配列にはゼロのみが含まれており、ソートによってすべてのビットが配置されますが、選択条件は`gain[j] > 0`いかなる挿入も阻止し、$x = 0$これは正しいです。反転すると合計が減少するか改善されないからです。 

最後の微妙なケースはタイブレークです。 ビット位置全体にわたる値の対称分布など、2 つのビットが同一のゲインを生成する場合、ソートにより小さいビット インデックスが最初に選択されるようになります。 これにより、下位ビットの数値への寄与が小さくなるため、等和解の中で結果として得られる 2 進数が最小になることが保証されます。$x$可能な場合は常に推奨されます。
