 ## 問題の理解

 このタスクでは 3 つの小文字の英単語が与えられます。 イライザは、3 つの単語がすべて異なっていて、そのフレーズに 1 つまたは 2 つの特別な単語が含まれている場合、そのフレーズを魔法だとみなします。`see`、`believe`、 そして`repeat`, ただし、3つすべてが同時にではありません。 与えられた 3 つの単語がこれらのルールを満たしているかどうかを判断して出力する必要があります。`YES`または`NO`。 

入力サイズは意図的に小さくなっています。文字列はちょうど 3 つあり、各文字列の長さは最大でも 15 です。これは、3 つの魔法の単語との直接比較でも十分に高速であることを意味します。 高度なデータ構造や最適化は必要ありません。 すべての単語をチェックし、一定量の作業を実行するソリューションは事実上瞬時に実行されます。 

主な困難はパフォーマンスではなく、条件を正しく解釈することです。 このフレーズには 3 つの異なる単語が必要であるため、重複した単語が魔法の単語であっても、重複した入力単語は拒否する必要があります。 同時に、3 つの入力のうちのマジック ワードの数は、少なくとも 1 つ、多くても 2 つでなければなりません。 

次の入力を考えてみましょう。```
see
see
cat
```正しい出力は次のとおりです。```
NO
```出現する魔法の言葉の数を数えるだけの不注意な解決策は、`see`2 回間違えてそのフレーズを受け入れてしまいます。 単語自体が明確でなければなりません。 

別のエッジケースは次のとおりです。```
see
believe
repeat
```正しい出力は次のとおりです。```
NO
```3 つの特別な単語はすべて存在しますが、ルールでは 3 つすべてを使用することを明示的に禁止しています。 

最後のケースは次のとおりです。```
see
cat
dog
```正しい出力は次のとおりです。```
YES
```必要な魔法の言葉のうち 1 つだけが表示され、それが許可されます。 

## アプローチ

 簡単なアプローチは、3 つの入力単語と 3 つの特別な単語を比較し、そのうちのいくつが魔法のセットに属するかを数えることです。 また、単語を相互に比較して、3 つすべてが異なることを確認します。 単語が 3 つしかないため、総当たりアプローチではすべての条件を直接試すことができます。 

ここでは、ブルート フォース バージョンがすでに最適な実用的なソリューションとなっています。 この作業を操作の観点から説明すると、各単語の長さは最大 15 であるため、一定数の文字列比較、最大でも数十文字のチェックのみが行われます。可能なチェックに対して徹底的なアプローチを行ったとしても、実行される原始的な操作はわずか数百個だけです。 

重要な観察は、問題には隠れた検索スペースがないということです。 私たちはフレーズを構築したり、単語の組み合わせを調べたりしているわけではありません。 入力によってフレーズ全体がすでに得られているため、答えは 2 つの特性、つまり 3 つの単語の一意性と単語の中の魔法の単語の数によって決まります。

 ## アルゴリズムのチュートリアル

 1. 3 つのワードを配列に読み取ります。 それらをまとめておくと、魔法のセットの一意性とメンバーシップの両方を簡単に確認できます。 
2. 3 つの単語がペアごとに異なるかどうかを確認します。 2 つの位置に同じ単語が含まれている場合、そのフレーズは魔法ではありえないため、答えは次のようになります。`NO`。 
3. 3 つの単語のうち、次のいずれかに等しいものがいくつあるか数えます。`see`、`believe`、 または`repeat`。 この数は、フレーズ内で使用されている魔法の単語の数を表します。 
4. カウントがちょうど 1 またはちょうど 2 の場合、出力します。`YES`。 それ以外の場合は出力`NO`。 

これが機能する理由は、元のルールをこれら 2 つのチェックに完全に削減できるためです。 最初のチェックでは、フレーズに 3 つの異なる単語が含まれていることを強制します。 2 番目のチェックでは、特殊な単語の数が許容範囲内であることが強制されます。 

機能する理由: アルゴリズムは、魔法のフレーズを定義するすべてのルールをチェックします。 受け入れられた場合、単語は異なり、特殊な単語の数は 0 または 3 ではないため、すべての要件が満たされます。 拒否された場合は、少なくとも 1 つのルールに違反していることになり、そのフレーズは魔法ではないことを意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    words = [input().strip() for _ in range(3)]

    if len(set(words)) != 3:
        print("NO")
        return

    magic = {"see", "believe", "repeat"}
    count = sum(1 for word in words if word in magic)

    if 1 <= count <= 2:
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```問題では常に 3 つの単語が提供されるため、入力は正確に 3 つの別々の行として読み取られます。 の`set`変換により重複が削除されるため、そのサイズを 3 と比較することで、すべての単語が一意であるかどうかが直接確認されます。 

ここではメンバーシップのチェックが自然な操作であるため、魔法の言葉はセットに保存されます。 次に、プログラムは 3 つの入力のうちのいくつがそのセットに属するかを数えます。 

最後の条件では、1 または 2 のカウントのみが受け入れられます。 範囲チェックを使用すると、魔法の単語が 0 つも誤って受け入れられたり、3 つの魔法の単語がすべて出現するという禁止されたケースを回避したりできます。 

入力サイズに応じたインデックス操作やループがないため、境界の問題はありません。 格納される整数は 0 から 3 までのカウントだけであるため、整数のオーバーフローも不可能です。

## テストケース```python
import sys
import io

def solution(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    words = [sys.stdin.readline().strip() for _ in range(3)]

    if len(set(words)) != 3:
        ans = "NO"
    else:
        magic = {"see", "believe", "repeat"}
        count = sum(1 for word in words if word in magic)
        ans = "YES" if 1 <= count <= 2 else "NO"

    sys.stdin = old_stdin
    return ans + "\n"

assert solution("see\ncat\ndog\n") == "YES\n", "one magical word"
assert solution("see\nbelieve\nrepeat\n") == "NO\n", "all magical words"
assert solution("see\nsee\ncat\n") == "NO\n", "duplicate words"
assert solution("hello\nworld\ncat\n") == "NO\n", "no magical words"
assert solution("repeat\nabc\nbelieve\n") == "YES\n", "two magical words"
assert solution("a\nb\nc\n") == "NO\n", "minimum length ordinary words"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`see, cat, dog`|`YES`| 許可される最小マジックワード数 |
 |`see, believe, repeat`|`NO`| 3つの魔法の言葉がすべて詰まった禁断の事件 |
 |`see, see, cat`|`NO`| 重複単語の検出 |
 |`hello, world, cat`|`NO`| 魔法の言葉が出てこない場合の拒否 |
 |`repeat, abc, believe`|`YES`| 2 つの魔法の言葉で受け入れ |
 |`a, b, c`|`NO`| 短い一般単語の扱い |

 ## 特殊なケース

 重複する単語の場合、入力```
see

cat
```すぐに拒否されます。 単語セットのサイズは 3 ではなく 2 であるため、アルゴリズムはマジック ワード数チェックに到達しません。 これにより、重複したマジックワードが有効なフレーズと間違われるのを防ぎます。 

3 つの魔法の言葉がすべて存在する場合:```
see
believe
repeat
```単語が異なるため、一意性条件は成功します。 魔法のカウントは 3 になり、魔法の言葉は 1 つまたは 2 つしか許可されないため、最終条件で拒否されます。 

魔法の単語を 1 つだけ含むフレーズの場合:```
see
apple
tree
```一意性条件は成功し、マジカル カウントは 1 になります。 魔法の言葉は 1 つで十分なので、アルゴリズムはそれを受け入れます。 

魔法の言葉を含まないフレーズの場合:```
apple
tree
stone
```一意性条件は成功しますが、カウントはゼロです。 すべての有効なフレーズには 3 つの特殊な単語のうち少なくとも 1 つが含まれている必要があるため、アルゴリズムはこれを拒否します。
