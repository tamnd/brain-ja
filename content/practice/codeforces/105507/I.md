 ## 問題の理解

 高層ビルでは、アパートメントに 1 階から順に 1 から連続して番号が付けられ、各階に同じ数のアパートメントが含まれていると説明されています。 床にある場合`k`アパートメントの場合、1 階にはアパートメントが含まれます`1`を通して`k`、2階には以下が含まれます`k+1`を通して`2k`、 等々。 

各テスト ケースには 2 つの数値が与えられます。`f`、特定のアパートがあると想定されるフロア、および`r`、アパート番号。 タスクは、次の値を決定することです。`k`(フロアごとのアパート数) によりこれが可能になり、そのようなすべての有効な値の中から、可能な最小値と最大値を見つけます。`k`。 そうでない場合`k`存在する場合、両方の答えは`-1`。 

制約`r ≤ 10^9`有効な解決策はすべて、可能なすべての反復を回避する必要があることを意味します。`k`価値観。 までのリニアスキャン`r`最大 1000 個のテスト ケースがあり、それぞれに最大 10^9 のチェックが必要になる可能性があるため、最悪の場合は非常に遅くなります。 

重要な構造的観察は、固定された`k`、アパートの床`r`は整数の除算で求められます。`(r - 1) // k + 1`。 これにより、問題はシミュレーションではなく、不等式に関する推論に変わります。 

次の場合、微妙なエッジケースが発生します。`f`有効なフロア インデックスの最大可能値よりも大きい`k`。 たとえば、次の場合`f = 5`そして`r = 3`とすると、アパート 3 は、均一な間仕切りでは 5 階にある可能性はありません。 フロアのインデックス付けを考慮せずに割り算のみをチェックするアプローチは、ここでは失敗します。 

下限境界は包含的な整数範囲に依存するため、不等式の厳密性を慎重に処理せずに境界を推測しようとすると、別の失敗モードが発生します。 

## アプローチ

 フロアごとのアパートの候補数を固定すると`k`、アパートの床を直接計算できます`r`使用して`(r - 1) // k + 1`それが等しいかどうかを確認してください`f`。 このブルートフォースアプローチはすべてを試みます`k`1から`r`、考えられるすべての構成をチェックするため、正確性が保証されます。 ただし、これは次のことにつながります`O(r)`テスト ケースごとの作業量が大きすぎる場合`r`到達できる`10^9`。 

The structure of the floor function provides a sharper characterization. そのアパートの条件`r`床に横たわる`f`これは、サイズの累積範囲を要求することと同等です。`k`場所`r`の中で`f`- 番目のセグメント。 これは、制約を与える一対の不等式に変換されます。`k`散在した離散値ではなく、連続的な間隔に変換します。 

具体的には、フロア境界は次のことを意味します。```
(f - 1) * k < r ≤ f * k
```これから、次の境界を導き出すことができます。`k`:```
k ≥ ceil(r / f)
k ≤ floor((r - 1) / (f - 1))   (when f > 1)
```したがって、検索の代わりに、有効な間隔を計算します。`k`直接。 間隔が空の場合、解は存在しません。 それ以外の場合は、有効な最小値と最大値`k`は単にこの間隔の終点です。

 ## アルゴリズムのチュートリアル

 1. 特殊なケースに対処する`f = 1`。 この状況ではアパート`r`は 1 階にあり、1 から 2 までのすべてのアパートメントを意味します。`k`含む`r`。 これにより、`k ≥ r`、1階は少なくとも最大までカバーする必要があるため、`r`。 この場合は上限がないため、最大値は無制限となり、次のように表されます。`-1`。 
2. のために`f > 1`、床の状態を次の不等式に変換します。`r`サイズがブロック内に収まる必要があります`k`。 
3. 条件を書き換える`(f - 1)k < r ≤ fk`の制約に`k`。 上限は、`f`-階は後ではありません`r`、下限により次のことが保証されます。`r`前の階には落ちません。 
4. 整数上限除算を使用して下限を計算します。`k_min = (r + f - 1) // f`。 これにより、`f * k`少なくとも`r`。 
5. 上限を次のように計算します。`k_max = (r - 1) // (f - 1)`。 これにより、`(f - 1) * k < r`。 
6. もし`k_min > k_max`、有効なパーティションが存在しないため、出力`-1 -1`。 それ以外の場合は、間隔のエンドポイントを出力します。 

これが機能する理由は、アパートの番号付けを、番号直線を等しい長さのセグメントに分割するものとして考えることから来ます。 それぞれ`k`整数をブロックにタイリングすることを定義します。フロア番号は単に、次のものを含むブロックのインデックスです。`r`。 不等式はブロックとなる条件を正確に捉えています。`f`含まれています`r`、そして両方の制約が単調であるため、`k`、単一の連続間隔を定義します。 どれでも`k`この間隔の外では、どちらかが移動します`r`上層階または下層階に移動できるため、有効なソリューションが見逃されたり追加されたりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    f, r = map(int, input().split())

    if f == 1:
        # r must be on first floor, so k >= r
        print(r, -1)
        continue

    # lower bound: fk >= r
    k_min = (r + f - 1) // f

    # upper bound: (f-1)k < r  => k <= (r-1)/(f-1)
    k_max = (r - 1) // (f - 1)

    if k_min > k_max:
        print(-1, -1)
    else:
        print(k_min, k_max)
```特別な場合`f = 1`上限の式でゼロによる除算を回避し、1 階が常にアパート 1 から始まり、アパートに応じて無限に広がるという事実を捉えます。`k`。 天井分割`(r + f - 1) // f`最小限のことを強制します`k`そのような`r`床を越えて押し出されない`f`。 フロア区分`(r - 1) // (f - 1)`それを保証します`r`サイズでセグメント化するときに、下層階にはまだ含まれていません`k`。 

条件付き比較では、導出された実行可能間隔が空かどうかを直接チェックします。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        f, r = map(int, input().split())
        if f == 1:
            out.append(f"{r} -1")
            continue
        k_min = (r + f - 1) // f
        k_max = (r - 1) // (f - 1)
        if k_min > k_max:
            out.append("-1 -1")
        else:
            out.append(f"{k_min} {k_max}")
    return "\n".join(out)

 ## 特殊なケース

 いつ`f = 1`、アルゴリズムは直接出力します`k_min = r`。 入力用`f = 1, r = 1`、結果は`1 -1`、アパート 1 は常に 1 階にあるため、`k ≥ 1`。 計算では、一般式を完全にバイパスすることにより、ゼロによる除算が回避されます。
