 ## 解決策
 ## 問題の理解

 私たちは試験会場で 1 列の座席を与えられ、長さの文字列として表されます。$n$。 各ポジションは学生によって占められているか、空席になっています。 私たちの仕事は、一部の学生を現在の席から空席に移動させて、学生を再編成することです。 

再配置後、3 つのプロパティを持つ構成を取得する必要があります。つまり、左端の席に学生が 1 人含まれている必要があり、右端の席にも学生が 1 人含まれている必要があり、連続する学生間の距離が列全体で一定になるようにすべての学生が配置されている必要があります。 言い換えれば、占有位置だけを見ると、それらは等差数列を形成するはずです。 

生徒を現在占有されている座席から移動させ、空いた座席に配置することは許可されています。 解決策にかかるコストは、移動する生徒の数です。 目標は、このコストを最小限に抑えるか、有効な最終構成を形成できないと判断することです。 

制約$n \le 200000$シートのすべてのサブセット、またはエンドポイントとギャップのすべてのペアを 2 次またはそれ以上の複雑さで単純な方法で列挙しようとするソリューションは直ちに除外されます。 少なくとも線形または線形に近い戦略が必要で、これには現在占有されている位置をソートし、等差数列を効率的に推論することが含まれる可能性が高くなります。 

生徒の数が少ない場合、または生徒の位置がすでに有効な進行を形成している場合、微妙な特殊なケースが発生します。 もう 1 つの注意が必要なケースは、選択した端点のペアによって暗示される間隔が非整数の中間位置を生成する場合、または範囲外になる場合に発生します。 すべての中間配置を検証せずにエンドポイントのみをチェックする単純なアプローチでは、無効な構成が誤って受け入れられます。 逆に、ステップ サイズは最大で変化する可能性があるため、すべてのステップ サイズに対する単純な総当たりはタイムアウトになります。$n$、それぞれについて、すべての位置をスキャンします。 

## アプローチ

 最終的な配置は 3 つの値によって完全に決定されるという観察から始めます。$a$、ステップ$d$、生徒数$k$。 直したら$a$そして$d$の場合、必要な位置は次のとおりです。$a, a+d, a+2d, \dots$。 すべての生徒はこれらの位置に正確に配置され、全員がセグメント内に位置する必要があります。$[1, n]$。 

ブルートフォースアプローチでは、可能なエンドポイントとして生徒のすべてのペアを試し、暗黙のステップサイズを計算し、結果の等差数列上にすでに何人の生徒が嘘をついているかを検証します。 と$k$学生の皆さん、これは次のことにつながります$O(k^3)$単純に行われた場合は最悪の場合、少なくとも$O(k^2)$各ペアを注意深くチェックすると。 以来$k$できる$O(n)$が鈍くなるにもほどがあります。 

重要な構造的洞察は、最終的な構成が、境界のあるセグメント内の等差数列であるということです。 考えられるすべての手順を試す代わりに、視点を逆転させます。変更しない生徒の数を修正し、その数を最大化しようとします。 そのときの答えは、$k - \text{best preserved count}$。 

現在の学生の位置を並べ替えると、その一部のサブセットに一致する有効な等差数列は、その最初の項と差によって定義されます。 開始位置とステップを固定することはできますが、ステップを明示的に列挙するのではなく、有効な進行は少なくとも 2 人の既存の生徒と一致する必要があることがわかります。 したがって、ステップは、最終的に保持されたセット内の生徒のペアによって決定されます。 

これは、インデックスのペアを試すことを示唆しています$(i, j)$、それらを最終進行の連続する要素として解釈します。 次に、ステップは次のように強制されます$d = (pos[j] - pos[i])$そして、これらの位置に既に横たわっている既存の生徒の数を数えて、この進行が配列の境界内で前方と後方の両方にどこまで伸びるかを確認します。 

すべてのペアの一致数を最大化します。 残りの生徒は移動する必要があります。 どの進行にも少なくとも 2 人の生徒を一貫して含めることができない場合、問題は 1 人の生徒または不可能な構成が存在するかどうかを確認することにまで発展します。 

重要な最適化は、各候補の進行に対して行全体をスキャンしないことです。 代わりに、2 ポインタまたはハッシュ セットのメンバーシップ チェックを使用して、候補者ごとに線形時間で算術シーケンス上にある元の学生の位置の数を数えます。$O(k^2)$慎重に最適化され、高速なメンバーシップ チェックに依存している場合には、許容可能なソリューションです。

 ## アルゴリズムのチュートリアル

 まず、占有座席のすべてのインデックスをソートされたリストに抽出します。 このリストを$p$、そしてさせてください$k$その長さになります。 

1. もし$k \le 1$の場合、占有されていて自明でない等差数列を持つ両方のエンドポイントを満たすことができないため、すぐに -1 を返します。 これにより、劣化したケースが早期に除去されます。 
2. メンバーシップを定期的にチェックするために、すべての占有ポジションをセットに保存します。 候補の進行が既存の生徒に当てはまるかどうかを頻繁にテストするため、これは不可欠です。 
3. インデックスのすべてのペアを反復処理します。$i < j$リストの中で$p$。 各ペアについて、それらを目的の最終進行における連続したポイントとして扱うため、ステップは次のように固定されます。$d = p[j] - p[i]$。 私たちも検討します$p[i]$進歩の潜在的な開始点として。 
4. 各候補者について$(start, d)$、次の限り、進行を後方に延長します。$start - d$範囲内に留まります。 これにより、最終的な配置で左端の座席が占有されているという要件が確実に尊重されます。 
5. 左端の有効な開始を修正した後、範囲内の進行のすべての位置を生成します。$[1, n]$そして、元の占有セットにこれらの位置がいくつ存在するかを数えます。 この数は、移動する必要のない生徒の数を表します。 
6. すべての候補者の進行にわたって、保存されている生徒の最大数を追跡します。 
7. 答えは次のとおりです。$k - \text{max preserved}$最適な進行状況に含まれていない生徒はすべて移動する必要があるためです。 

### なぜ効果があるのか

 有効な最終配置は、その最初の位置とステップ サイズによって一意に決定されます。 少なくとも 2 人の元の生徒が含まれている場合、それらの 2 人は同じ等差数列を定義します。 したがって、すべての有効な解はペアの列挙で表されます。 このような誘発された進行をすべてチェックすることで、最適な構成が考慮されていることを保証します。 元のセットとの交差をカウントすることで、何人の生徒が滞在できるかを確実に測定し、これを最大化すると最小移動数が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    s = input().strip()

    pos = []
    for i, ch in enumerate(s, 1):
        if ch == 'S':
            pos.append(i)

    k = len(pos)
    if k <= 1:
        print(-1)
        return

    occ = set(pos)
    ans_keep = 1

    for i in range(k):
        for j in range(i + 1, k):
            d = pos[j] - pos[i]

            start = pos[i]
            while start - d >= 1:
                start -= d

            cnt = 0
            x = start
            while x <= n:
                if x in occ:
                    cnt += 1
                x += d

            if cnt > ans_keep:
                ans_keep = cnt

    print(k - ans_keep)

if __name__ == "__main__":
    solve()
```インデックスを直接操作する方が、生の文字列を推論するよりもはるかに簡単であるため、実装はすべての生徒の位置を収集することから始まります。 セット`occ`候補の等差数列が既存の生徒と一致するかどうかを評価するときに、定数時間チェックが可能になります。 

ペアの二重ループでは、可能なステップ サイズをすべて列挙します。 各ペアについて、開始点を後方にシフトすることで進行を正規化し、セグメント内の最も左の可能な要素を常に考慮します。 これにより、最初に選択した生徒を超えた有効な設定を見逃すことがなくなります。 

内側のループは進行を構築し、元の生徒の位置との重複をカウントします。 これは、正確さが慎重なステップに依存する唯一の場所です。 後方拡張をスキップすると、有効な位置合わせが過小評価されます。

 ## 特殊なケース

 重大なエッジケースは、生徒全員がすでに完全な等差数列を形成している場合に発生します。 たとえば、入力`SFSFSF`ポジションを生み出す$[1,3,5]$。 アルゴリズムでは、ステップ 2 を与えるペア (1,3) が考慮され、後方への拡張は何も行われません。 その後、3 つの一致すべてがカウントされ、移動は 0 になります。 これにより、有効な構成が不必要な再配置なしで正確に保持されることが確認されます。 

もう 1 つのケースは、生徒が集まっているものの、等間隔ではない場合です。`SSSFFFFF`。 ポジション$[1,2,3]$最初にステップ 1 を提案します。これにより、すべての座席にわたる完全な進行が生成されます。 アルゴリズムはこれを検出し、構造的な変更が必要ないため、再びゼロ手を返します。 

失敗が起こりやすいシナリオは、次のようなまばらで孤立した生徒です。`SFFFFFS`。 ポジション$[1,7]$有効な進行を 1 つだけ定義します。 アルゴリズムはステップ 6 を構築し、1 まで逆方向に拡張してから、これら 2 つのポイントのみをカウントし、中間の仮想配置を強制的に移動しますが、追加の処理は必要ありません。 これにより、アルゴリズムが中間の席を元の生徒が占有する必要があると誤って想定することがなくなります。
