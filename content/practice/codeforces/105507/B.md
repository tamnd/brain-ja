 ## 問題の理解

 私たちはフットボールチームの独立したシーズンを数回与えられます。 シーズンごとに、勝った試合数と負けた試合数がわかり、すべての試合の合計得点数と失点数もわかります。 引き分けは存在しないため、すべての試合は厳密に勝ちか負けのどちらかになります。 

有効なシーズンの説明とは、すべての試合に正確にスコアラインを割り当てることができることを意味します。`a`試合は勝利であり、`b`試合は負け、全試合で得点したゴールの合計は等しい`x`、失点の合計は以下に等しい`y`。 勝利はその試合での得点数が失点よりも厳密に多いことを意味し、負けは厳密に失点数が少ないことを意味します。 

試合スコアラインのすべての有効な再構築の中で、1 つの試合で得点されるゴールの可能な最大数が必要です。 再建が不可能な場合、答えは次のとおりです。`-1`。 

制約は次のとおりです`10^9`値ごとに最大`1000`テストケース。 これにより、試合をシミュレートしたり、ゴールを明示的に配分したりする試みは即座に排除されます。 どのソリューションも、テスト ケースごとに一定時間で機能する必要があります。 

一般的な失敗例は、集計統計が有効な一致結果に対応できない場合に発生します。 たとえば、チームが 3 試合で負けたが、合計で 2 ゴールしか失点しなかった場合、少なくとも 1 つの負けで少なくとも 1 ゴールを許す必要があるため、厳密に負けている 3 試合にゴールを分散することは不可能になります。 同様に、合計勝利数は存在するが、合計得点数が少なすぎて 1 試合でも勝利を裏付けることができない場合、実現可能性は直ちに破綻します。 

もう 1 つの微妙な失敗は、合計は実行可能だが、個々の試合構造により最大ゴール数に制限がかかる場合です。 たとえ総ゴール数が多かったとしても、勝利により最小得点差構造が強制され、1 つの試合がどれほど極端になるかを制限します。 

## アプローチ

 強引な解釈は分割しようとするでしょう`x`にゴールを決めた`a + b`バケツに入れて同様に配布します`y`失点を確認してから、各バケットを勝ちまたは負けとしてラベル付けできるかどうかを確認します。 整数分割だけを試したとしても、分布の数は組み合わせになります。`a + b`、一度不可能にする`a + b`数十にも達します。 

重要な観察は、正確な分布は決して必要ではなく、実現可能性の制約と極端な構造のみが必要であるということです。 勝利するたびに失点よりも得点が少なくとも 1 つ多くなり、負けるたびに失点よりも少なくとも 1 つ多くなります。 これにより、下限構造が作成されます。勝利すると、最小の寄与が強制されます。`x - y`、そして損失は反対方向に赤字の一部を消費します。 

実現可能性は、基本の最小スコアラインを割り当てて合計を一致させることができるかどうかを確認することによって決まります。 実現可能性が確保されると、1 つの試合でのスコアを最大化することが再分配の問題になります。つまり、他のすべての試合を必要最小限の構成に保ちながら、1 つの試合にできるだけ多くのゴールを押し込みます。 

最適な解決策は、他のすべての試合に最小限の有効な構成を割り当てた後、1 つの試合にどれだけの「フリー」ゴールを集中させることができるかを特定することに帰着します。

 ## アルゴリズムのチュートリアル

 試合ごとに必要な最小限の構造という観点から推論します。 

1. すべての試合に、その結​​果と一致する最小限のスコアラインを与えることから始めます。 勝利は少なくとも貢献する`(1, 0)`そして損失は少なくとも寄与する`(0, 1)`。 これはすでに消費しています`a`得点したゴールと`b`失点。 
2. このベースライン後の残りの柔軟な目標を計算します。 

余った得点数は`x - a`、余った失点は`y - b`。 
3. どちらかの剰余がマイナスの場合は入力できません。 これは、最も弱い有効なシーズンであっても、勝利ごとに少なくとも 1 ゴールを獲得し、敗北ごとに少なくとも 1 ゴールを失点する必要があるためです。 
4. ここでは、各勝利が厳密に勝ち、各損失が厳密に負けである限り、勝敗条件を破ることなく試合に追加できる「追加ゴール」として余剰を解釈します。 
5. 1 つの試合のスコアを最大化するために、これらの追加得点をできるだけ多く 1 つの試合に集中させたいと考えています。 ただし、厳密な不平等条件を維持している限り、試合は結果を変えることなく追加のゴールを吸収することしかできません。 
6. 勝利ではすでに得点 > 失点が許可されているため、最大得点の試合の最適な候補は勝利です。 勝利を維持したまま、勝利を収めた一試合に追加のゴールを押し込むことができます。 
7. 同様に、負けた場合に得点を増やすと勝ちに転じる危険があるため、負けるとどれだけ得点できるかが制限されます。 
8. したがって、最適な構造では、他の試合を有効に保つのに十分な構造を確保した後、すべての余剰得点能力を 1 つの勝利試合に配置します。 1 回の試合での最大スコアは次のようになります。 

ベースラインの勝利構造と追加の得点すべてを加え、他の試合で少なくとも最小限の妥当性を維持する必要性によって調整されます。 
9. 勝利がない場合 (`a = 0`) の場合、すべての試合は負けであり、試合の最大得点は、その試合を支配できる失点の数によって制限されます。 その場合、得点は負けを維持するスコアを超えることはできません。 
10. 対称的推論は次の場合に適用されます。`b = 0`。 

最後の式は、実現可能性をチェックして次のことを行うことを単純化します。`max(0, x - b)`勝利が存在する場合、対称的な処理により、損失が制約を破らないようにします。 

### なぜ効果があるのか

 この構築は、すべての有効なシーズンを、各勝利が次のようなベースライン構成に還元できるという不変条件に依存しています。`(1, 0)`そしてそれぞれの損失は`(0, 1)`、その後、残りのすべての目標は「無料余剰」になります。 試合間の余剰の再分配では合計が維持され、唯一の制約は試合ごとの厳密な不平等を維持することです。 1 つの一致のみが最大化されるため、他のすべての一致は最小の有効な構成に固定され、実現可能性を侵害することなくすべての余剰を吸収する単一の自由度が残されます。 

これにより、最初はグローバルな分割問題のように見えた問題が、固定の下限構造の下での局所的な最大化の問題に変わります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    
    for _ in range(t):
        a, b, x, y = map(int, input().split())

        # minimal feasible baseline
        if x < a or y < b:
            out.append("-1")
            continue

        # remaining flexible goals
        sx = x - a
        sy = y - b

        # if no wins, all matches are losses
        if a == 0:
            # every match must be loss: score < concede
            # best match: concentrate all scores into one loss match
            # max score is limited by total structure
            out.append(str(sx))
            continue

        # if no losses, all matches are wins
        if b == 0:
            out.append(str(sx + a))
            continue

        # general case: at least one win and one loss
        # we maximize one winning match
        ans = sx + 1
        out.append(str(ans))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```実装は、各勝ちと負けがそれぞれ少なくとも 1 単位の得点と失点を消費するという基本要件を強制することから始まります。 この実現可能性チェックに合格したら、残りの「無料」目標を分離します。 

勝利がない場合、すべての試合は強制的に負けとなるため、1 つの試合を最大限に活用するということは、負けた試合を負けたままにしつつ、得点できるすべてのゴールを 1 つの負けた試合に集中させることになります。 損失がない場合、すべての試合は勝利となるため、すべての余剰スコアとベースラインの勝利構造が 1 つの試合に累積されます。 

混合ケースの場合、重要な単純化は、他の場所で少なくとも 1 つの勝利構造をそのまま維持しながら余剰スコアを吸収するには 1 つの試合だけが必要であり、これにより残りの余剰で線形式が得られます。

 ## 特殊なケース

 勝ちがない場合は、すべての試合が負けになる必要があります。 このアルゴリズムは、得点されたゴールが 1 つの負け試合に集中するという問題に直接帰着します。これは、合計失点数が負けを維持するのに十分なままである限り許可されます。 負けるには厳密に得点よりも多くの失点が必要なだけであるため、実現可能条件は`x >= a`そして`y >= b`有効な配布がすでに保証されています。 

負けがなければ、すべての試合は勝ちです。 各勝利には、失点よりも少なくとも 1 つの得点が必要なだけであるため、制約に違反することなく、余剰得点は 1 つの試合に自由に蓄積されます。 式`sx + a`各勝利が少なくとも 1 つの基準得点に貢献していることを反映しています。 

混合の場合、アルゴリズムは、集中した余剰をホストするために少なくとも 1 つの勝ち試合が存在すると仮定します。 余剰を負け試合に集中させようとすると、厳密な不平等により実現可能性が制限されてしまいます。 この構造により、少なくとも 1 つの勝利がそのまま残され、最大化ステップの正確性が維持されます。
