 ## 解決策
 ## 問題の理解

 まず、ますます複雑になる問題の範囲から始めます。 セットの不均衡は、並べ替え後の 2 つの隣接する要素間の最大の差として定義されます。 

追加の問題は最大 1 つまで挿入できます。 新しい問題は複雑でなければなりません`d_i + f_j`ここで、モデル配列から 1 つの値を選択し、関数配列から 1 つの値を選択します。 

タスクは、このような値を 1 つだけ挿入した後、最終的な不均衡を最小限に抑えることです。 

元の配列はすでにソートされているため、非常に便利です。 不均衡は隣接するギャップにのみ依存するため、問題全体は実際には最大のギャップを制御することにあります。 

この制約により、考えられるすべての挿入に対してブルートフォースが即座に排除されます。 すべてのテストケースにわたって、`m`そして`k`それぞれの合計は`2 * 10^5`, なので、周りにあるかもしれません。`4 * 10^10`可能なペア`(d_i, f_j)`。 すべての合計を明示的に生成するアルゴリズムは不可能です。 

配列`a`それ自体ははるかに小さく、全体のサイズは`10^5`したがって、ギャップを中心とした解決策が期待できるはずです。`a`、生成されたすべての値に関するものではありません。 

見落としやすいエッジケースがいくつかあります。 

最大のギャップが複数回出現するとします。```
a = [1, 5, 9]
gaps = [4, 4]
```たとえ 1 つのギャップを 2 つの小さな部分に完全に分割したとしても、もう 1 つのギャップのサイズは`4`まだ存在します。 答えは決して下に行くことはできません`4`。 選択した 1 つのギャップのみを最適化する不注意な実装では、誤った値が返されます。`2`。 

もう 1 つの注意が必要な状況は、最大のギャップ内に挿入することが不可能な場合です。```
a = [1, 10]
d = [100]
f = [100]
```構築可能な唯一の値は、`200`、ギャップの外側にあります`[1, 10]`。 それを追加しても元のギャップは何も変わらないため、答えは残ります。`9`。 

最適な生成値を選択する際には、微妙な境界の問題もあります。 最大のギャップがある場合、`[L, R]`の場合、理想的な挿入値は中間点付近になります。`(L + R) / 2`。 ただし、最も近い達成可能な合計は、この中間点をわずかに下回るか、わずかに上回る可能性があります。 片側だけをチェックすると最適なものを見逃す可能性があります。 

例：```
L = 10, R = 20
possible sums = {14, 16}
```使用する`14`最大のギャップを与える`6`、 その間`16`最大のギャップを与える`6`同じように。 多くの場合、厳密には一方の側の方が優れているため、ターゲットの周囲の両方の近隣を注意深くチェックする必要があります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 すべてのペアについて`(d_i, f_j)`、値を構築します`x = d_i + f_j`。 それをソートされた配列に挿入し、新しい最大隣接ギャップを計算し、最小の答えを保持します。 

これが機能するのは、不均衡の定義が最終的な並べ替え順序のみに依存するためです。 挿入された値が固定されると、結果は確定的になります。 

問題は規模だ。 最悪の場合、次のことを調べます。```
m * k = 2 * 10^5 * 2 * 10^5 = 4 * 10^10
```可能な値。 ギャップを再計算する前でさえ、これはすでに制限時間をはるかに超えています。 

重要な点は、数値を挿入しても 1 つのギャップにのみ影響するということです。 

挿入された値が次の範囲にあると仮定します。`a[i]`そして`a[i+1]`。 隣接する他のすべての差は変更されません。 ギャップだけ```
a[i+1] - a[i]
```に置き換えられます```
x - a[i]
and
a[i+1] - x
```これにより、視点がすぐに変わります。 すべてのポジションについて考えるのではなく、既存の最大ギャップのみを考慮します。 

なぜ？ なぜなら、他のすべてのギャップはすでに存在しており、その中に挿入しない限り変化しないからです。 現在の最大ギャップが`mx`挿入後も、すべての未処理のギャップは依然として残ります。 

ここで 2 つのケースを考えてみましょう。 

最大のギャップが少なくとも 2 回出現する場合、1 つのコピーは常にそのまま残ります。 答えはすでに決まっています`mx`。 

それ以外の場合は、固有の最大ギャップが存在します。 このギャップを分割するとグローバル最大値が減少する可能性があるため、挿入によってのみ答えが改善されます。 

一意の最大ギャップが次の間であると仮定します。`L`そして`R`。 

値を挿入すると`x`この間隔内で、そこに寄与する新たな最大ギャップは次のようになります。```
max(x - L, R - x)
```この式は次の場合に最小化されます。`x`できるだけ中間点に近い位置にあります。 

したがって、問題は次のようになります。 

構築可能な値を見つける`d_i + f_j`最も近い`(L + R) / 2`。 

ここで、並べ替えと二分探索が登場します。 

配列をソートします`f`。 あらゆる人にとって`d_i`、私たちが望むのは：```
d_i + f_j ≈ midpoint
```つまり:```
f_j ≈ midpoint - d_i
```ソート済みのバイナリ検索を使用する`f`、最も近い候補を効率的にテストできます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(mk + nk) | お(1) | 遅すぎる |
 | 最適 | O(n + m log k + k log k) | O(1) おまけ | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列内のすべての隣接するギャップを計算します。`a`。 
2. 最大のギャップを見つける`mx`そして2番目に大きいギャップ`second`。 

最大のギャップを分割した後でも、他のすべてのギャップは変化しないままであるため、2 番目に大きなギャップが重要になります。 

1. 何回数えるか`mx`が表示されます。 

少なくとも 2 回表示された場合は、すぐに戻ります`mx`。 

1 つの発生を減らしたとしても、別の同一のギャップは変化せずに残ります。 

1. 固有の最大ギャップを次の間とする`L = a[pos]`そして`R = a[pos + 1]`。 

この間隔内に挿入するだけで答えが改善されます。 

1. 配列のソート`f`。 

その中を二分探索してみます。 

1. あらゆる値について`d_i`、ターゲットを計算します。```
target = (L + R) / 2 - d_i
```私たちは価値が欲しいのです`f_j`そのような`d_i + f_j`ギャップの中点にできる限り近づけます。 

1. 二分探索を使用します。`f`より小さくない最初の値を見つけるには`target`。 

この位置と前の位置の両方を確認してください。 

最も近い達成可能な合計は、中点のどちらかの側にある可能性があります。 

1. すべての候補の合計について`x = d_i + f_j`:

 1. 次の場合は無視します。`x`厳密には内側ではありません`(L, R)`。 
2. 挿入後の最大ギャップを計算します。```
new_max = max(
    second,
    x - L,
    R - x
)
```1. すべての候補に対する回答を最小限に抑えます。 
2. ギャップ内に有効な挿入が存在しない場合、答えは残ります。`mx`。 

### なぜ効果があるのか

 すべての挿入は、隣接する 1 つの間隔にのみ影響します。 他のすべてのギャップは永久に変更されません。 

最大ギャップが複数回発生する場合、別の同一のギャップがまだ残っているため、1 つのコピーを変更してもグローバル最大値を減らすことはできません。 

最大ギャップが一意である場合、唯一有効なアクションはそのギャップを分割することです。 その外側に挿入すると、最大のギャップはそのまま残ります。 

一定間隔内`[L, R]`、結果として生じる最大のローカル ギャップは次のようになります。```
max(x - L, R - x)
```この量は次の場合に最小化されます。`x`は中間点に最も近いです。 すべての構成可能な値には形式があるため、`d_i + f_j`、最も近いバイナリ検索`f_j`それぞれに`d_i`すべての最適な候補を調べます。 

アルゴリズムは、潜在的に最適な挿入をすべてチェックし、結果として生じる不均衡を正確に計算するため、検出された最小値は正確になります。 

## Python ソリューション```python
import sys
from bisect import bisect_left

input = sys.stdin.readline

def solve():
    t = int(input())
    
    for _ in range(t):
        n, m, k = map(int, input().split())
        
        a = list(map(int, input().split()))
        d = list(map(int, input().split()))
        f = list(map(int, input().split()))
        
        gaps = []
        mx = -1
        pos = -1
        
        for i in range(n - 1):
            g = a[i + 1] - a[i]
            gaps.append(g)
            
            if g > mx:
                mx = g
                pos = i
        
        cnt = gaps.count(mx)
        
        if cnt >= 2:
            print(mx)
            continue
        
        second = 0
        for g in gaps:
            if g != mx:
                second = max(second, g)
        
        L = a[pos]
        R = a[pos + 1]
        
        f.sort()
        
        ans = mx
        mid = (L + R) / 2
        
        for dv in d:
            target = mid - dv
            
            idx = bisect_left(f, target)
            
            for j in [idx - 1, idx]:
                if 0 <= j < k:
                    x = dv + f[j]
                    
                    if L < x < R:
                        cur = max(second, x - L, R - x)
                        ans = min(ans, cur)
        
        print(ans)

solve()
```最初のセクションでは、隣接するすべてのギャップを計算し、最大のものを特定します。 後で正確な間隔の境界が必要になるため、それが発生する位置も保存します。 

最大ギャップが繰り返された場合は、早期に復帰することが不可欠です。 これがなければ、アルゴリズムは決して答えを改善できない挿入を検索することに時間を浪費することになります。 

変数`second`影響を受けていない最大のギャップを保存します。 一意の最大ギャップを分割した後、この値は自動的に最終的な答えの一部になります。 

二分探索セクションは最適化の中核です。 それぞれについて`d_i`で理想的なマッチング値を導き出します。`f`。 以来`f`並べ替えられて、`bisect_left`最も近いより大きな候補を与えます。 前のインデックスはさらに近い可能性があるため、両方をチェックする必要があります。 

厳密な条件:```
L < x < R
```重要です。 もし`x`等しい`L`または`R`、実際には分割は起こらず、元のギャップは変化しません。 

Python 整数は任意の精度をサポートしているため、ここではすべての値を安全に処理できます。 固定幅整数を使用する言語では、`L + R`64 ビット演算を使用する必要があります。

 ## 特殊なケース

 最大ギャップが繰り返される場合を考えてみましょう。```
a = [1, 5, 9]
```ギャップは`[4, 4]`。 

挿入しても`3`間`1`そして`5`、ギャップは次のようになります。```
2, 2, 4
```アンバランスは相変わらず`4`。 

アルゴリズムは、最大ギャップが複数回出現したことを検出し、すぐに戻ります。`4`。 これにより、コピーを 1 つだけ削減しようとする誤った試みが回避されます。 

ここで、不可能な挿入を考えてみましょう。```
a = [1, 100]
d = [200]
f = [300]
```構築可能な唯一の値は、`500`、外にあります`(1, 100)`。 

アルゴリズムは以下をチェックします。```
if L < x < R
```そしてこの候補者を拒否します。 有効な分割が存在しないため、答えは元のギャップと同じままになります。`99`。 

最後に、境界に敏感な中点の場合を考えてみましょう。```
a = [10, 20]
d = [5]
f = [4, 6]
```可能な挿入は次のとおりです`9`そして`11`。 

中間点は`15`。 

二分探索では、ターゲットの周囲の両方の隣接位置をチェックします。 有効な挿入`11`隙間ができる`1`そして`9`、答えを与える`9`。 

下位近傍のみまたは上位近傍のみをチェックすると、同様の状況で最適な候補を見逃してしまう可能性があります。
