 ## 解決策
 ## 問題の理解

 この問題では、地下鉄システムを無向グラフとして記述します。各頂点は駅であり、各辺は 2 つの駅間の直接接続を表します。 すべてのエッジには、そのエッジが属する地下鉄路線を表す色が付けられています。 同じ色のすべてのエッジが接続されたサブグラフを形成します。つまり、その線に沿って駅間を中断することなく移動できます。 タスクは、ルートが出発駅から移動するために通過する必要がある地下鉄路線の最小数を決定することです。`b`目的地の駅まで`e`。 

入力は複数のテスト ケースを提供し、それぞれが最大 200,000 個の頂点と 200,000 個のエッジを持つグラフを定義し、すべてのテスト ケースにわたる頂点とエッジの合計数もこれらの範囲内に収まります。 このような制限と 2 秒の実行時間では、テスト ケースあたりの時間計算量が O(n + m) よりも悪いソリューションは遅すぎる可能性があります。 具体的には、エッジや色をまたがるネストされたループは、実行可能な操作数をすぐに超えてしまいます。 

明らかではないエッジ ケースには、開始駅と終了駅が同じ場合、グラフに線が 1 本しかない場合、または単純な貪欲トラバーサルでは見逃す可能性がある方法で最短パスが複数の色にまたがる場合が含まれます。 たとえば、頂点 1-2-3 が 1 つの色で、3-4-5 が別の色で、1 から 5 に移動するグラフでは、ラインを 1 回切り替える必要があり、色を無視する不注意な BFS ではカウントを誤る可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、からのすべてのパスを列挙する可能性があります。`b`に`e`、各パスに沿って使用される線の色のセットを追跡し、使用する色が最も少ないパスを選択します。 これは原理的には正しいですが、パスの数はステーションの数に応じて指数関数的に増加するため、このアプローチは完全に非現実的になります。`n`そして`m`2・10^5まで。 パスを単純なパスに制限したとしても、組み合わせの爆発は避けられません。 

重要な洞察は、切り替える回線の最小数は通過するステーションの総数には関係せず、異なる色で接続されたコンポーネント間の遷移にのみ関係するという認識から得られます。 各色はステーションの接続されたコンポーネントを定義します。 これらのコンポーネントを新しい「メタグラフ」のノードとして扱う場合、つまりステーションをあるステーションから別のステーションに接続するエッジが存在する場合に 2 つのコンポーネントが接続される場合、問題はこのメタグラフ内で最短パスを見つけることになります。 これはまさにエッジの重み 0 と 1 の BFS 問題です。同じ色に沿って移動すると重み 0 (ラインの変更なし) になり、色の切り替えでは重み 1 (ラインの変更) が発生します。 0-1 BFS を使用してこれを効率的に計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(パス) | O(n) | 遅すぎる |
 | 0-1 BFS / コンポーネント グラフ | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、グラフの端を読み取り、色ごとにグループ化します。 同じ色のエッジは接続されたサブグラフを形成するため、BFS の目的では各色のサブグラフを単一のコンポーネントとして扱います。 
2. 各色の内部の各接続コンポーネントに一意の識別子を割り当てます。 これは、同じ色のエッジに制限された DFS または BFS を使用して実行できます。 各ステーションは、色ごとに 1 つのコンポーネントに正確に属します。 
3. 各ノードがステーションであり、元のグラフで直接接続されている異なる色のステーション間にエッジが存在するメタグラフを構築します。 エッジにコストを付けて注釈を付けます。色が変わらない場合は 0、ラインを切り替える場合は 1。 これにより、0 ～ 1 BFS の加重グラフが生成されます。 
4. 出発局から始まるBFSのデキューを初期化します。`b`使用コストは 0 回線です。 同じ色に沿って隣接するものを両端キューの前面 (重み 0) にプッシュし、色の変更を必要とする隣接するものを後ろにプッシュします (重み 1)。 
5. 目的局までBFSを継続します。`e`に達します。 この時点での料金は、地下鉄の最低利用路線数を表します。 もし`b`等しい`e`、すぐに 0 を返します。 
6. 各テストケースの結果を出力します。 

機能する理由: このアルゴリズムは、BFS デキューには、到達するために必要な回線スイッチの最小数で順序付けされた次のステーションが常に含まれるという不変条件を維持します。 グラフには負ではないエッジ コスト (0 または 1) があり、BFS はコストの増加順にノードを処理するため、最初に目的地に到達したときに最小限の行数が得られます。 0-1 BFS は、ライン切り替えを増やす前にゼロコストの移動を探索することで最適性を保証します。 

## Python ソリューション```python
import sys
from collections import defaultdict, deque
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        edges = defaultdict(list)
        color_edges = defaultdict(list)
        for _ in range(m):
            u, v, c = map(int, input().split())
            edges[u].append((v, c))
            edges[v].append((u, c))
            color_edges[c].append((u, v))
        b, e = map(int, input().split())
        if b == e:
            print(0)
            continue

        # component mapping per color
        color_comp = {}
        for c, pairs in color_edges.items():
            visited = set()
            comp_id = 0
            adj = defaultdict(list)
            for u, v in pairs:
                adj[u].append(v)
                adj[v].append(u)
            for u in adj:
                if u not in visited:
                    stack = [u]
                    while stack:
                        node = stack.pop()
                        if node in visited:
                            continue
                        visited.add(node)
                        color_comp[(node, c)] = comp_id
                        for nei in adj[node]:
                            if nei not in visited:
                                stack.append(nei)
                    comp_id += 1

        # BFS 0-1
        dq = deque()
        dist = {}
        for v, c in edges[b]:
            dist[(v, c)] = 1
            dq.append((v, c))
        dist[(b, 0)] = 0
        dq.appendleft((b, 0))

        while dq:
            node, curr_c = dq.popleft()
            d = dist[(node, curr_c)]
            for nei, c in edges[node]:
                cost = 0 if c == curr_c or curr_c == 0 else 1
                if (nei, c) not in dist or dist[(nei, c)] > d + cost:
                    dist[(nei, c)] = d + cost
                    if cost == 0:
                        dq.appendleft((nei, c))
                    else:
                        dq.append((nei, c))
        ans = min([dist[(e, c)] for v, c in edges[e] if (e, c) in dist] + [dist.get((e, 0), float('inf'))])
        print(ans)
        
solve()
```このソリューションでは、まずステーションと色の両方で隣接リストを作成します。 DFS は、接続されているステーションの各セットにカラーごとに一意のコンポーネント ID を割り当てます。 次に、0-1 BFS はデキューを使用してライン スイッチを処理し、同じ色の移動を前に押してスイッチを後ろに押します。 以下を使用して距離を追跡します`(station, color)`現在の行に基づいて状態を区別するためのペア。 

実装の微妙な選択には初期化が含まれます`dist[(b, 0)] = 0`任意の回線への最初の移動を回線切り替えとしてカウントできるようにし、色の変更を処理するために BFS 内の近隣を注意深くチェックします。 Python は 1 から始まるステーション インデックスを入力から直接使用するため、off-by-one エラーは回避されます。
