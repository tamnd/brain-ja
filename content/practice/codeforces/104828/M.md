 ## アルゴリズムのチュートリアル

 すべての制約を不等式に再定式化します。$x$、それぞれは以下に応じた間隔として表されます。$len$。 

1. 4 つの制約から始めます。$x \in [a,b]$、$x+len \in [a,b]$、$x+len \in [c,d]$、$x+2len \in [c,d]$。 
2. それぞれを境界に変換します。$x$。 これにより、次の 4 つの間隔が生成されます。$[a,b]$、$[a-len, b-len]$、$[c-len, d-len]$、$[c-2len, d-2len]$。 
3.固定の場合$len$、これらすべての間隔の交差を計算します。 これは、すべての下限の最大値とすべての上限の最小値を取得することによって行われます。 
4. 構成は、最大下限が最小上限以下である場合にのみ実行可能です。 
5. 実現可能条件は単調である$len$: ある場合$len$機能するため、より小さい値でも機能します。 これにより、有効な最大値を検索できるようになります。$len$実数直線上で二分探索を使用します。 
6. 二分探索を実行します。$len \in [0, 10000]$。 各中間値について、区間交差条件を使用して実現可能性を確認します。 
7. 収束後、結果の最大値を出力します。$len$小数点第2位に四捨五入。 

### なぜ効果があるのか

 実現可能条件は、次の一連の線形不等式によって定義されます。$len$。 それぞれの不等式が制限する$x$端点が次のように線形にシフトする区間に$len$が増加します。 として$len$成長する、すべて実現可能$x$- 範囲は単調に縮小またはシフトします。つまり、交差点が空になると、それより大きなすべての交差点は空のままになります。$len$。 これにより単調性が保証され、二分探索が正当化されます。 正しいことは、有効な構成はすべてこれらの間隔の空でない交差に対応する必要があり、そのような交差はすべて導出された境界によって完全にキャプチャされるという事実からわかります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def ok(l, a, b, c, d):
    low = max(a, a - l, c - l, c - 2*l)
    high = min(b, b - l, d - l, d - 2*l)
    return low <= high

a, b, c, d = map(float, input().split())

lo, hi = 0.0, 10000.0

for _ in range(80):
    mid = (lo + hi) / 2
    if ok(mid, a, b, c, d):
        lo = mid
    else:
        hi = mid

print(f"{lo:.2f}")
```実装は、アルゴリズムで導出された実現可能性条件を直接エンコードします。 機能`ok`指定された候補の長さが、すべての可能な位置の空でない交差を許可するかどうかを計算します。$x$。 各境界は、次のように書き換えられた 4 つの制約の 1 つに正確に対応します。$x$。 二分探索は固定反復回数で実行されます。これは、入力スケールを考慮した場合、倍精度の安定性を確保するには十分です。 

重要な実装の詳細は、すべてを浮動小数点に保ち、実現可能性チェック中に整数の丸めを回避することです。 出力には小数点以下 2 桁しか必要ないため、80 回の反復で達成される約 1e-6 の精度は十分以上です。

 ## 特殊なケース

 重要なエッジケースは、入力など、すべてのエンドポイントが一致する場合です。`0 0 0 0`。 実現可能性チェックは次のようになります。$low = max(0, 0, 0, 0) = 0$、$high = min(0, 0, 0, 0) = 0$、

 それでさえ$len = 0$有効です。 二分検索ではゼロが拒否されないため、アルゴリズムは正しく 0.00 を返します。 

もう 1 つのケースは、次のような 2 番目の間隔が非常に広い場合です。`0 1 0 10000`。 ここでは、最初の区間の制約が完全に支配的です。 のために$len = 1$、次のようになります。$low = max(0, -1, 0, -2) = 0$、$high = min(1, 0, 10000, 9999) = 0$、

 したがって、境界では引き続き実行可能です。 わずかに大きい値は実現可能性を損なうため、アルゴリズムは 1.00 に収束します。 

最後の構造的なエッジ ケースは、元の間隔ではなく、シフトされた境界の緊密な交差によって最適値が達成される場合に現れます。 すべての制約が対称的に含まれているため、定式化ではすでにこれが考慮されています。`max(low)`そして`min(high)`計算により、境界条件の欠落がないことが保証されます。
