 ## 解決策

 ## 問題の理解

 位置 1 から右に向かって、直線上に配置された一連の砂の柱を構築しています。 各位置は非負の整数の高さを保持し、その高さはそこに配置される砂パックの数を表します。 すべての砂パックは分割できないため、各ユニットは正確に 1 つの位置の高さに寄与します。 

構成は 3 つの構造規則を満たす必要があります。 まず、最初の位置の高さは、フェンス制約に基づく所定の制限 H を超えることはできません。 次に、隣接する柱の高さの差は最大 1 でなければなりません。これにより、全体の形状が急激に変化することなく徐々に変化することになります。 第三に、n 個の砂パックはすべて正確に使用する必要があります。これは、すべての高さの合計が固定されることを意味します。 

正の高さを持つ位置のみが「使用済みスポット」としてカウントされるため、後続のゼロは重要ではありませんが、最後の非ゼロ位置より前のすべてが重要です。 目標は、滑らかさの制約と総和の制約を尊重しながら、使用される位置の数が最小限になるように砂を配置することです。 

制約は非常に大きく、n と H は最大 10^18 です。 これにより、シーケンスを明示的に構築またはシミュレートするアプローチは即座に除外されます。 どのような解法も、位置に対する反復ではなく構造に関する閉じた形式の推論に依存し、テスト ケースごとに対数時間または定数時間で機能する必要があります。 

H が n に比べて非常に大きい場合、微妙なエッジ ケースが発生します。 その場合、最良の形状は単に n、n-1、...、1 のような下り階段となり、答えは小さくなります。 一方、H が小さい場合、早期に高さを「キャップ」し、高さ 1 の平らな領域でシーケンスを拡張することを余儀なくされます。左から右に構築しようとする単純な貪欲シミュレーションは、傾き制約の下で固定数の位置に合計がどのくらい詰められるかを正しく考慮していないため、失敗することがよくあります。 

たとえば、n = 5 および H = 2 の場合、貪欲なアプローチでは 2、1、1、1 を配置しようとする可能性があります。これは 3 つの位置で有効かつ最適です。 しかし、誤って 1、2、1 などの低い値から開始しようとすると、キャパシティについてグローバルに推論しないため、ポジションを過剰に使用したり、実現可能性を誤って計算したりする可能性があります。 

## アプローチ

 直接総当り戦略では、長さ k が増加するすべての有効なシーケンスを構築し、隣接差分制約と初期限界を尊重しながらそれらの合計が n に達するかどうかをチェックしようとします。 各 k について、ルール |hi − hi+1| に基づいて高さを分配することで、達成可能な合計を最大化することを試みることができます。 ≤ 1 および h1 ≤ H。ただし、単一の k を評価する場合でも、最大 k 個の位置をシミュレートする必要があり、k 自体は n と同じくらい大きくなり、最大 10^18 になります。 これにより、総当たり攻撃は完全に不可能になります。 

重要な観察は、固定長 k の場合、考えられる最適な構成は任意ではないということです。 制約の下で合計を最大化するには、常に可能な限り高い値から開始し、1 に達するまでステップごとに 1 ずつ減少させる必要があります。その時点以降は、残りの位置でシーケンスを 1 でフラットに保つことができます。これは、再び増加すると、早期に最大の累積を維持するために必要な単調ドロップ構造に違反するためです。 

これにより、問題は容量の問題に集約されます。各 k について、達成可能な最大合計を計算できます。 この値を O(1) で計算できれば、この最大合計が少なくとも n になるように最小の k を二分探索できます。 この k がわかれば、高さを下げても差の制約に違反することがないため、値を下方に調整して n に正確に一致させることができます。

 ## アルゴリズムのチュートリアル

1. 占有位置 k の候補数を固定し、制約の下で配置できる砂の最大合計を計算します。 考え方は、k 個の位置が n 個の砂パックすべてを保持するのに十分であるかどうかを確認することです。 
2. 長さ k の最も高い有効な形状を構築します。 位置 1 の高さ H から開始し、高さ 1 に達するまでステップごとに 1 ずつ減少します。これにより、最大 H の長さの降順プレフィックスが得られます。 
3. k が H 以下の場合、シーケンスは厳密に減少するセグメントになります: H、H−1、...、H−k+1。 合計は部分等差数列であり、床にぶつからない最大のパッキングを表します。 
4. k が H より大きい場合、シーケンスはまず H から 1 まで下降し、H 位置を消費します。 その後、|hi − hi+1| を壊すことなく、残りの位置はすべて高さ 1 を持つことができます。 ≤ 1 制約。 これにより、容量が直線的に拡張されるプラトーが生じます。 
5. 適切な閉じた形式を使用して、この k の達成可能な合計を計算します。 位置を追加しても達成可能な最大合計を減らすことができないため、これにより k の単調関数が得られます。 
6. 計算された最大合計が少なくとも n になるように、最小の k を二分探索します。 これにより、すべての砂に対応しながら、必要以上に多くのポジションを使用することがなくなります。 
7. k を見つけた後、シーケンスを構築し、合計がちょうど n になるまで右側から貪欲に高さを減らします。 値を下げても隣接する差が 1 を超えて増加することはないため、右から減らすと有効性が維持されます。 

### なぜ効果があるのか

 重要な特性は、任意の固定長 k について、合計を最大化する最適な配置が、平らな尾部が続くキャップ付きの下り階段として独自に構造化されることです。 この形状から逸脱すると、初期の大きな値が減少するか、不必要な傾きの変化が生じて合計が減少します。 この達成可能な最大合計は k で単調であるため、二分探索により実行可能な最小の長さが正しく特定され、有効性を損なうことなく過剰な容量を削除できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_sum(k, H):
    if k <= H:
        # H + (H-1) + ... + (H-k+1)
        return k * (2 * H - k + 1) // 2
    else:
        # full descending to 1, then flat 1s
        return H * (H + 1) // 2 + (k - H)

def solve():
    n, H = map(int, input().split())

    lo, hi = 1, n
    ans = n

    while lo <= hi:
        mid = (lo + hi) // 2
        if max_sum(mid, H) >= n:
            ans = mid
            hi = mid - 1
        else:
            lo = mid + 1

    # construct initial maximal shape
    k = ans
    res = []

    cur = H
    remaining = k
    while remaining > 0 and cur > 0:
        res.append(cur)
        cur -= 1
        remaining -= 1

    if remaining > 0:
        res.extend([1] * remaining)

    # adjust down to exactly n
    total = sum(res)
    i = len(res) - 1
    while total > n:
        dec = min(res[i], total - n)
        res[i] -= dec
        total -= dec
        i -= 1

    # trim trailing zeros
    while res and res[-1] == 0:
        res.pop()

    print(len(res))

if __name__ == "__main__":
    solve()
```二分探索により、最適に充填されたプロファイルの下ですべての砂塊をサポートできる最小限の数の位置が分離されます。 構築ステップでは、その容量を達成する極限形状に従い、最終調整では、隣接制約に違反しない最右端からの高さを安全に下げることで、正確な均等性を確保します。 

## 実用的な例

 サンプル入力 n = 5、H = 2 を考えてみましょう。関数 max_sum は次のように動作します。 

| k | シーケンスの形式 | max_sum(k) |
 | --- | --- | --- |
 | 1 | [2] | 2 |
 | 2 | [2,1] | 3 |
 | 3 | [2,1,1] | 4 |
 | 4 | [2,1,1,1] | 5 |

 二分探索により、容量が 5 に達する最初の長さとして k = 4 が特定されます。構築されたシーケンスは [2,1,1,1] で、すでに合計が 5 になり、4 つの位置を占めます。 

このトレースは、構造が高さ 1 に到達すると、平坦な構造で拡張すると容量が線形に増加することを示しています。これが、k > H の後に関数が区分的に線形になる理由です。 

As another example, take n = 10, H = 3.

 For k = 3, max_sum is 3 + 2 + 1 = 6.

 For k = 4, max_sum is 6 + 1 = 7.

 For k = 7, max_sum is 6 + 4 = 10.

 したがって、答えは 7 になり、[3,2,1,1,1,1,1] に対応します。 これは、H での転移点と、その後の成長がプラトーによってどのように支配されるかを裏付けています。

 ## 特殊なケース

 Hがn以上の場合、最適構造は平坦領域に到達しません。 シーケンスは純粋な下り階段になり、答えは k(k+1)/2 ≥ n となる最小の k に崩壊します。 容量関数の k ≤ H 分岐は二分探索全体を通じてアクティブなままであるため、アルゴリズムはこれを自動的に処理します。 

H が非常に小さい場合、特に H = 1 の場合、構造は 1 のフラットなシーケンスに縮退します。 この場合、max_sum(k) = k となるため、二分探索はすぐに k = n を返します。 構築ステップでは、隣接制約を自明に満たす均一な 1 の配列が生成されます。 

n が H(H+1)/2 よりわずかに大きい場合、解はプラトー領域に入ります。 二分探索により H のすぐ上の k が特定され、構築されたシーケンスは完全な三角形になり、その後に短い平らな尾部が続きます。 これは最も敏感な遷移点であり、正確かどうかは、max_sum の 2 つの式領域間の正確な分離に依存します。
