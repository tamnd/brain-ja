 ## 解決策
 ## 問題の理解

 配置します$2n$円形のゴンドラ。 各ゴンドラには次のいずれかを割り当てる必要があります。$k$色。 色を付けた後、2 つの制約付きでゴンドラをペアで接続しようとします。すべてのゴンドラが同じ色の他の 1 つのゴンドラと正確に一致すること、およびこれらのペアを表す描画セグメントが平面で見たときに交差してはいけないことです。 

色を尊重し、交差を避けるような完璧な組み合わせを選択する方法が少なくとも 1 つ存在する場合、その色付けは有効であるとみなされます。 課題は、何色の色を数えるかです。$2n$位置はこの存在条件を満たしており、円の回転は同じ色とみなされますが、反射は異なるものとみなされます。 

制約は次のとおりです$n, k \le 3 \cdot 10^6$これにより、円構造を反復したり、マッチングをシミュレートしようとしたりするソリューションが即座に除外されます。 多項式時間であっても、ペアリングを明示的に構築するアプローチ$n$、遅すぎます。 唯一実行可能な方向は、式または組み合わせ値の線形時間事前計算です。 

微妙な点は、有効性が存在的なものであるということです。ペアリングを構築する必要はなく、カラーリングと一致する少なくとも 1 つの非交差完全一致が存在することを確認するだけで済みます。 これにより、一般的な故障モードである固定一致を想定して過大カウントが容易になります。 

たとえば、最初に非交差マッチングを選択し、その後自由に色を割り当てると誤って仮定した場合、$k^n \cdot C_n$着色、ここで$C_n$カタルーニャ語の数字です。 多くのカラーリングでは複数の互換性のあるマッチングが許可されますが、一部のカラーリングではまったく互換性が認められないため、これは誤りです。 

もう 1 つの落とし穴は、回転の等価性を無視することです。 固定開始点上の単純な線形 DP は、相互に回転する構成を暗黙的にオーバーカウントします。 

## アプローチ

 自然な出発点は、円上で交差しない完全な一致という観点から考えることです。 一瞬色を忘れても、有効な組み合わせの構造はカタロニア語で正確に数えられます。$C_n$。 これは、「ペアリングの形状」を「色の割り当て」から分離しようとすることを示唆しています。 

最初の強引な解釈は次のようになります。$2n$位置を確認し、色ごとに有効な非交差ペアリングが存在するかどうかを確認します。 たとえ 1 つのカラーリングに対して高速チェッカーがあったとしても、カラーリングの数は$k^{2n}$、それは完全に不可能です。 

2 番目の素朴なアイデアは、プロセスを逆にすることです。交差しない一致 (カタロニア語の多数) をすべて列挙し、各一致と互換性のある色の数を数えます。 マッチングが修正された場合、各エッジはその 2 つの端点に同じ色を強制的に共有するため、各エッジは次の係数に寄与することになります。$k$、につながる$k^n \cdot C_n$。 問題は、これにより、複数の有効な一致が認められるカラーリングが過大にカウントされること、そしてさらに重要なことに、存在条件が固定一致に結び付けられていないことです。 カラーリングは、特定のカラーリングと一致する場合ではなく、少なくとも 1 つの非交差マッチングを許容する場合に有効です。 

重要な構造的観察は、有効な一致が存在すると、円の間隔に再帰的な制約が課されるということです。 頂点を修正すると、そのパートナーは円を 2 つの独立した部分問題に分割します。 色の制約は、各ペアの端点の色が一致するという要件によってのみ、これらの部分問題を結合します。 

これにより、区間分解にわたる DP が得られますが、相互作用は劇的に単純化されます。最終的に重要なのは、円をスイープするときにアクティブな色の「開いた成分」がいくつあるかです。 新しいペアを導入するたびに、既存のカラー構造を継続するか、別のカラーで新しい構造を開始します。 これにより、問題は次の一次元の再発に帰着します。$n$ここで、トランジションは、色を再利用するか、新しい色を導入するかによってのみ決まります。 

結果として得られる反復は、標準的な組み合わせ構造と一致します。つまり、1 つの識別されたルート ペアを選択し、後続のすべてのペアが既存のカラー クラスに接続されるか、新しいカラー クラスを開始します。 これにより、それぞれの乗算構造が生成されます。$n-1$残りのペアは次の係数に寄与します$k-1$、最初のペアは次の係数に寄与します。$k$。 The Catalan structure appears implicitly in the background as the count of valid nesting patterns, but it cancels out under the existential condition.

 したがって、最終的な式は単純な閉じた形式になります。$$k \cdot (k-1)^{n-1}$$追加の組み合わせスケーリングが回転とネスト制約の構造によって吸収され、直接的な$O(n)$計算。

 ## アルゴリズムのチュートリアル

 ## アルゴリズムのチュートリアル

 1. 円上に基準点を固定して回転対称を一時的に破ります。 これにより、すべての有効な構成を一意にローテーションして戻すことができるため、カウントを変更せずに構造を線形に推論することができます。 
2. 有効なペアは、円を独立した間隔に再帰的に分割する必要があることに注意してください。 最初に選択された各ペアは、残りの頂点を、同じルールの下で独立して動作する 2 つの互いに素な円弧に分割します。 この再帰的分解が中心となる構造的制約です。 
3. 各ペアを、正確に 2 つのエンドポイントにまたがる「カラー クラス」に属していると解釈します。 エンドポイントが色を共有するという制約は、各ペアが色の伝播の最小単位であることを意味します。 
4. 暗黙の構築順序でペアを処理します。各新しいペアは、既存のカラー系統を継続するか、新しいカラー系統を導入します。 重要な事実は、色が切り離されて使用されると、後で強制的に交差させずに結合することはできないということです。 
5. 選択肢を順番に数えます。$n$ペア。 最初のペアには、$k$色の選択。 後続のすべてのペアは正確に$k-1$競合する構造と同じ色を選択すると、交差構成が強制され、非交差の実現可能性を維持する拡張部分のみが残るため、効果的な選択肢となります。 
6. 全体の貢献度を倍増する$n$最終的なカウントを取得するためのペア$k \cdot (k-1)^{n-1}$、モジュロ計算$998244353$。 

### なぜ効果があるのか

 分解により、すべての有効な構成が一連のペア作成決定に一意に対応することが保証されます。 非交差制約により厳密な入れ子構造が適用され、切り離された円弧間で色がどのように伝播するかが曖昧になるのを防ぎます。 各ステップは残りの自由度を一律に減少させるため、ローカルな選択の積は、過剰にカウントすることなくグローバルなカウントと等しくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = (res * a) % MOD
        a = (a * a) % MOD
        e >>= 1
    return res

def solve():
    n, k = map(int, input().split())
    if n == 0:
        print(1)
        return
    if k == 0:
        print(0)
        return
    ans = k * modpow(k - 1, n - 1) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```この実装はべき乗剰余演算のみに依存します。 反復は直接計算されるため、DP や組み合わせテーブルは必要ありません。 唯一デリケートな部分は指数の処理です$n-1$、次の場合には慎重に扱う必要があります。$n = 1$、式は正しく次のようになります。$k$。
