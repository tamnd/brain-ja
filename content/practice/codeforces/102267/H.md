 ## 解決策
 ## 問題の理解

 頂点 (V) を持ち、すべての辺が長さ (S) を持つ正多角形があります。 多角形は正則であるため、そのすべての頂点は多角形の中心を中心とする 1 つの円上にあります。 タスクは、その円の面積を計算することです。 

重要な量は外周半径 (R)、つまり多角形の中心から頂点までの距離です。 (R) がわかれば、要求された領域は次のようになります。 

[
 A=\pi R^2。 
】

 頂点の数は (3\le V\le359) を満たすため、線形または二次アルゴリズムでも実際には十分に小さいでしょう。 辺の長さは (10^9) まで大きくなるため、中間値は (10^{18}) 程度になります。 Python の整数はそのような値を安全に処理し、答えには数値精度が必要なため、最終的な計算には浮動小数点三角関数が使用されます。 

興味深いのは、入力のサイズではなく、ジオメトリを認識することです。 正多角形は、その中心とすべての頂点を結ぶことによって、(V) 個の同一の二等辺三角形に分割できます。 各三角形には 2 つの辺 (R) があり、その底辺は多角形の辺 (S) です。 中心の角度は (2\pi/V) です。 

不注意なジオメトリによって、黙って間違った答えが生成されるケースがいくつかあります。 たとえば、入力の場合`3 2`、多角形は正三角形です。 その外周半径は (2/\sqrt3) であるため、円の面積は (4\pi/3)、つまり約 (4.188790205) となります。 (S/(2\sin(\pi/V))) の代わりに (S/\sin(\pi/V)) を使用すると、半径が 2 倍になり、面積が 4 倍大きくなりすぎます。 

もう 1 つのよくある間違いは、ラジアンを期待する三角関数で度を使用することです。 のために`8 2`、関連する角度は (22.5) ではなく (\pi/8) です。`sin`。 正解はおよそ`21.452136491`。 

上限 (V=359) は、非常に大きなポリゴンを特別に処理する必要がないことも意味します。 (\sin(\pi/V)) は、許可されたすべての (V) に対して正であるため、式は許可された範囲全体で数値的に適切に動作します。 

## アプローチ

 直接的な幾何学的実装では、円の周囲に (V) 頂点を明示的に構築し、その座標を計算してから、半径を回復したり、辺の長さを検証したりすることができます。 正多角形は外周半径と角度間隔によって完全に決定されるため、このアプローチは正しいです。 すべての頂点を保存すると、(O(V)) 個の作業量と (O(V)) 個のメモリが必要になります。 最大値 (V=359) では、頂点の数は 359 個だけであるため、このアプローチは、指定された制約の下で十分に高速になります。 

より複雑な総当たりアプローチでは、数値的に半径を検索できます。 すべての候補半径について、対応する辺の長さ (2R\sin(\pi/V)) を計算し、半径が十分に正確になるまで二分探索を使用できます。 たとえば、60 回の反復では、約 (60) 回の三角関数評価が必要になります。または、一定の角度が事前に計算されている場合は (60) 回の評価が必要です。 これでも余裕で限界内です。 

そのため、多くの Codeforce の問題とは異なり、制約によって実際に総当たりの構築が遅くなりすぎることはありません。 最適な解決策は、タイムアウトになるアルゴリズムを救済するのではなく、不必要な計算を削除することから得られます。 正多角形の構造によって半径の正確な式が得られるため、頂点を作成したり数値検索を実行したりする必要はありません。 

中心と隣接する 2 つの頂点によって形成される (V) 三角形の 1 つを考えてみましょう。 2 つの等しい辺の長さは (R)、底辺の長さは (S)、中心の頂点の角度は (2\pi/V) です。 その三角形を真ん中で分割すると、斜辺 (R)、反対側 (S/2)、および角度 (\pi/V) を持つ直角三角形が作成されます。 したがって、

 [
 \sin\left(\frac{\pi}{V}\right)=\frac{S/2}{R}。 
】

 並べ替えると

 [
 R=\frac{S}{2\sin(\pi/V)}。 
】

 これを円面積の式に代入すると、

 [
 A=\pi\left(\frac{S}{2\sin(\pi/V)}\right)^2。 
】

 したがって、問題全体は 1 つの正弦評価といくつかの算術演算に削減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ポリゴンを明示的に構築する | (O(V)) | (O(V)) | 受け入れられますが、不要です |
 | 数値半径検索 | (O(K)) | (O(1)) | 受け入れられますが、不要です |
 | 幾何学式 | (O(1)) | (O(1)) | 承認済み |

 ここで (K) は数値検索で使用される反復回数です。 数式ベースの解決策は、標準の浮動小数点三角関数の精度まで正確であり、収束パラメータがないため、推奨されます。 

## アルゴリズムのチュートリアル

 1. 多角形の頂点の数 (V) と共通の辺の長さ (S) を読み取ります。 
2. 半角を計算します。 

[
 \theta=\frac{\pi}{V}。 
】

 それぞれの中心角は (2\pi/V) であり、対応する二等辺三角形の 1 つを半分に分割すると、角度 (\pi/V) が得られます。 

1. 次を使用して外周半径を計算します。 

[
 R=\frac{S}{2\sin\theta}。 
】

 得られる直角三角形の半辺 (S/2) は反対側 (\theta) であり、(R) はその斜辺です。 

1. 外接円の面積を次のように計算します。 

[
 A=\pi R^2。 
】

 1. 結果を浮動小数点数として出力します。 パイソンの`float`(10^{-6}) 許容差が必要とする精度よりも大幅に高い精度が得られます。 

なぜ効果があるのか

 導出の背後にある不変条件は、隣接する頂点のすべてのペアと多角形の中心が同じ二等辺三角形を形成するということです。 その中心角は正確に (2\pi/V) であり、それを半分にすると、反対側が多角形の辺のちょうど半分になる直角三角形が生成されます。 したがって、正弦関係により、すべての頂点に対して同じ半径が決定されます。 

[
 S/2=R\sin(\pi/V)。 
】

 したがって、計算された (R) は、多角形の中心からすべての頂点までの実際の距離であり、正確には外接円の半径です。 その半径を二乗して (\pi) を掛けると、必要な面積が得られます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

v, s = map(int, input().split())

angle = math.pi / v
radius = s / (2.0 * math.sin(angle))
area = math.pi * radius * radius

print("{:.10f}".format(area))
```問題には単一のポリゴンが含まれているため、入力は 1 回読み取られます。`math.pi / v`1 つの中心角の半分を計算します。これは、直角三角形の導出に必要な角度です。 

分母は`2.0 * math.sin(angle)`。 因数 2 は、直角三角形がポリゴンの辺の半分 (S/2) を含むという事実から来ています。 この要素を省略すると、この問題の最も直接的な式の誤りとなります。 

半径は (\pi) を乗算する前に 2 乗され、(A=\pi R^2) と完全に一致します。 計算は浮動小数点値を使用して実行され、整数の中間値が使用される場合には Python の整数も自動的に増加するため、ここでは Python は整数オーバーフローの影響を受けません。 

小数点以下 10 桁を出力することは、必要な (10^{-6}) 絶対誤差または相対誤差よりも快適に正確です。

import sys
import io
import math

def solve():
    input = sys.stdin.readline
    v, s = map(int, input().split())

    angle = math.pi / v
    radius = s / (2.0 * math.sin(angle))
    area = math.pi * radius * radius

    print("{:.10f}".format(area))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        solve()
        return sys.stdout.getvalue().strip()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

def assert_close(inp: str, expected: float, message: str):
    actual = float(run(inp))
    assert abs(actual - expected) <= 1e-6 * max(1.0, abs(expected)), message

# Provided sample
assert_close(
    "8 2\n",
    21.452136491,
    "sample 1"
)

# Minimum number of vertices
assert_close(
    "3 2\n",
    4.1887902047863905,
    "minimum vertices"
)

# A square with side 2 has circumradius sqrt(2)
assert_close(
    "4 2\n",
    2.0 * math.pi,
    "square"
)

# Maximum number of vertices and maximum side length
v = 359
s = 10**9
expected = math.pi * (s / (2.0 * math.sin(math.pi / v))) ** 2
assert_close(
    f"{v} {s}\n",
    expected,
    "maximum constraints"
)

# Smallest side length
assert_close(
    "3 1\n",
    math.pi / 3.0,
    "minimum side length"
)

print("All tests passed.")
