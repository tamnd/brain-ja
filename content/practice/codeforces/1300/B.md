 ## 解決策

 ## 問題の理解

 サイズの配列が与えられます$2n$、生徒のスキルレベルを表します。 このタスクは、これらの学生を 2 つのグループに分割し、各グループに奇数の学生が含まれ、すべての学生が 1 つのグループに割り当てられるようにすることです。 

どのグループについても、そのグループを分類した後のメンバーの中央値としてその「クラスの強さ」を定義します。 両方のグループのサイズが奇数である必要があるため、各中央値は単一の中間要素として明確に定義されます。 

目標は、中央値間の絶対差ができるだけ小さくなるように、配列を 2 つの奇数サイズのグループに分割することです。 

制約により、最大で次のことが許可されます。$10^5$合計のテスト ケースの合計$n$までも$10^5$。 これは、次のことを強く示唆しています。$O(n \log n)$ソートが主要な許可操作であり、テスト ケースごとの 2 次関数はすぐにタイムアウトになるため、テスト ケースごとにそれ以上の解決策が必要です。 

すべてのパーティションを試す素朴なアプローチ$2n$パーティションの数が指数関数的に増加するため、要素を 2 つの奇数グループに分割することは不可能です。 有効な奇数分割に制限しても、組み合わせ爆発が生じます。 

貪欲な直観が微妙に失敗するケースは、配列を並べ替えられた順序で連続する 2 つの半分に分割することが常に機能すると仮定することです。 たとえば、値が並べ替えられている場合でも、中点分割を選択すると、中央値が元の配列内の絶対位置ではなく、各グループ内のパリティ位置のみに依存することが無視されます。 

## アプローチ

 ブルートフォースソリューションでは、すべての分割方法を列挙します。$2n$要素を奇数サイズの 2 つのグループに分割します。 For each split, we would sort both groups and compute their medians. このようなパーティションの数は次のとおりです。$\binom{2n}{n}$、小さいものでも天文学的な大きさです。$n$、完全に実行不可能になります。 

重要な観察は、中央値は同一性ではなく順序に依存するため、要素の相対的な順序のみが重要であるということです。 配列を並べ替えたら、2 つの中央値を選択し、それらの周囲に有効な奇数サイズのグループを構築できることを確認します。 

最初のグループの中央値が位置にあることを修正すると、$i$の場合、その要素は奇数長のサブセットの中央として選択する必要があります。 2番目のグループについても同様です。 この構造により、両方の中央値が並べ替えられた配列内の要素に対応することが強制され、最適な解決策は、並べ替えられた順序でできるだけ近い、ただしパリティ制約のある 2 つの中央値を選択することによって得られます。 

重要な改良点は、並べ替え後、奇数サイズのグループを形成するのに十分な要素が両側に存在する位置から有効な中央値を取得する必要があることです。 最適な答えは、次の 2 つの要素を取ることによって達成されることがわかります。$n$ソートされた配列内でバラバラになります。 

これは、位置で中央値の候補を選択するときに機能するためです。$i$とグループを形成できることを確認する必要があります。$i$周囲の要素を使用して中央値として計算され、残りの要素が自動的に別の奇数グループを形成します。 2 番目の中央値は構造的に互換性のある位置から取得する必要があり、最良のペアリングは分割を中心に対称になります。 

したがって、ソート後はペアを比較するだけで済みます。$(a[i], a[i+n])$すべて有効な$i$、最小の差をとります。

 ## アルゴリズムのチュートリアル

 1. の配列をソートします。$2n$要素。 これにより、中央値が固定位置に対応する構造が得られます。 
2. 2 つの奇数サイズのグループへの有効な分割は、2 つのグループの中央値として機能する 2 つの「中心」要素を選択することに対応することに注目してください。 
3. すべての有効な開始位置を反復します。$i$から$0$に$n-1$、ペアリング$a[i]$と$a[i+n]$。 その理由は、これらのペアが、中央配置で重複することなく配列を 2 つの奇数サイズのグループに分割する構造的に一貫した唯一の方法を表すということです。 
4. 各ペアについて、絶対差を計算します。$|a[i] - a[i+n]|$。 
5. すべてのペアにわたるそのような最小の差を追跡し、それを出力します。 

正確に区切られたペアのみを考慮する理由$n$位置は、サイズのソートされた配列内の位置です$2n$、2 つの奇数サイズのセットへの有効な 2 分割では、一方の中央値を下半分に、もう一方を上半分に配置する必要があり、実行可能な中央値配置間の境界は正確にこのオフセットにあります。 

### なぜ効果があるのか

 配列がソートされると、中央値は奇数サイズのサブセットの中心にできる位置に対応します。 下半分の中央値を選択すると、残りの要素も奇数サイズのグループを形成する必要があるため、他の中央値が強制的に上半分に配置されます。 ペアリング距離$n$これにより、各中央値がそれぞれのサブセットの中央の要素となるように、両方のグループのバランスが保たれることが保証されます。 すべての有効な構成はそのようなペアにマッピングされるため、これらのペアの最小値が最適です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()
        
        ans = float('inf')
        for i in range(n):
            ans = min(ans, abs(a[i] - a[i + n]))
        
        print(ans)

if __name__ == "__main__":
    solve()
```解決策は、中央値の関係が組み合わせではなく位置になるように配列を並べ替えることから始まります。 次にループは、$n$構造的に有効な中央値ペア。 各ペアは、両方のグループが奇数のサイズになる、実行可能なパーティションに対応します。 

一般的な実装の落とし穴は、反復処理が最大までしか行われないことです。$2n$または半分のインデックスを間違って混合します。 正しい不変条件は、要素を常に正確に比較することです。$n$ソート順に並べてあります。

 ## 特殊なケース

 すべての要素が同一である場合、微妙な特殊なケースが発生します。 このアルゴリズムはソート後も対称位置をペアにしますが、すべての差はゼロであり、これはどのパーティションでも等しい中央​​値が得られるという事実と一致します。 

最小限のケースの場合$n = 1$、配列にはちょうど 2 つの要素があります。 並べ替えでは 2 つの位置が生成され、それらの間でのみ比較が行われ、可能な唯一のパーティションが正しく反映されます。 

クラスター間に大きなギャップがある場合、最適なペアリングは常に、ソート後の最も近いクロスハーフアライメントから得られます。 アルゴリズムはすべての有効な値を評価するため、これを自然に捕捉します。$i, i+n$ペアを作成し、その中で最小のものを選択し、偏ったパーティションを見逃さないようにします。
