 ## 解決策
 ## 問題の理解

 整数の配列が与えられており、要素の合計がゼロであってはならず、要素の積がゼロであってはいけないという 2 つのプロパティを同時に true にしたいと考えています。 許可される唯一の操作は、単一要素を 1 ずつインクリメントすることです。 タスクは、両方の特性を満たすこのようなインクリメント操作の最小数を見つけることです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは配列のサイズから始まり、その後に配列要素が続きます。 境界は小さく、配列ごとに要素が最大 100 個、各要素が -100 ～ 100 の間で、テスト ケースが最大 1000 個です。 これは、$O(n)$テストケースごとのソリューションは十分に高速です。 

配列にゼロが含まれる場合、エッジ ケースが発生します。 配列内のゼロは積をゼロにし、ゼロごとに少なくとも 1 つの増分で固定する必要があります。 すべてのゼロを修正した後に配列の合計がゼロになる場合、別の微妙なケースが発生します。 たとえば、[0, -1, 1] のような配列には、和がゼロ、積がゼロになります。 0 を 1 に増やすと、積は 0 以外になりますが、合計は 1 になるため、両方の条件が満たされます。 一般に、ゼロを処理した後は、合計自体がゼロかどうかを確認する必要があります。これは、ゼロを増分しても合計が自動的に修正されない可能性があるためです。 

## アプローチ

 ブルートフォースアプローチでは、すべてのゼロの増分を個別にシミュレートし、追加の増分のすべての組み合わせをテストして合計を修正します。 これは正しいですが、問題は数学的に推論できるため、不要です。 と$n \le 100$値が制限されている場合、操作数は少ないように見えますが、すべての合計調整をシミュレートするには指数関数的な作業が必要になる可能性がありますが、利用可能なより単純な洞察を考慮すると、これは正当化されません。 

重要な洞察は、2 つの制約を分離することです。 積を修正するには、配列内のゼロをインクリメントする必要があります。 させて`zeros`ゼロの数になります。 少なくとも必要です`zeros`操作。 すべてのゼロをインクリメントした後、結果の配列の合計を計算できます。 この合計がゼロの場合、合計をゼロから解除するには、どこかに 1 つの追加の増分が必要です。 合計がすでにゼロ以外の場合、それ以上の操作は必要ありません。 これにより、解決策はゼロを数えて調整された合計を確認するだけになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O(2^n) | O(n) | 遅すぎる |
 | ゼロを数える + 合計を調整する | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. カウンタを初期化する`steps`ゼロに。 これにより、必要な合計増分が追跡されます。 
2. 配列内のゼロの数を数えます。 各ゼロは、積をゼロ以外にするために 1 つの増分を必要とするため、このカウントを`steps`。 
3. すべてのゼロを 1 ずつ増分したと仮定して、配列の合計を計算します。 させて`sum_after`この金額になります。 
4. もし`sum_after`ゼロ、増分`steps`1つずつ。 これは、製品の修正によって合計がゼロになった状況を説明します。 
5. 印刷`steps`このテストケースの結果として。 

機能する理由: 非ゼロの積を達成するには、すべてのゼロをインクリメントする必要があり、アルゴリズムによってそれが保証されます。 ゼロが処理されると、合計がゼロのままになる唯一の方法は、ゼロ以外の要素が完全に打ち消される場合です。 どこかにもう 1 つの増分を追加すると、これが破られ、合計と積の両方がゼロ以外になることが保証されます。 アルゴリズムは、必要な最小増分数を正確にカウントします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    zeros = a.count(0)
    steps = zeros
    
    sum_after = sum(a) + zeros
    if sum_after == 0:
        steps += 1
    
    print(steps)
```最初のセクションでは、テスト ケースの数を読み取り、それらをループします。 到着ごとに
