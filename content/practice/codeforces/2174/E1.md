 ## 問題の理解

 隠された数字を推測するように求められます`x`間`1`そして`c`選択した基数の桁の合計についてクエリを実行します。 各クエリはベースを指定します`b`（間`2`そして`c`) の桁の合計を返します。`x`その基地内、または`-1`もし`x`よりも小さいです`b`。 厳しい制限があります`k = 4`番号ごとのクエリ数、および番号自体が非常に大きくなる可能性があり、最大`4 × 10^18`。 まであります`10^4`連続して推測する数字。 

すべての数値を試すという単純なアプローチ`1`に`c`それは不可能でしょう、なぜなら`c`は膨大であり、各数値を桁の合計と照合するには、許可されている操作をはるかに超える時間がかかります。 さらに、インタラクターは非適応的です。つまり、各数値は固定されており、以前のクエリから独立しているため、フィードバック ループを気にせずにクエリを計画できます。 

厄介な点は、クエリが返す可能性があることです。`-1`底が隠れた数値より大きい場合。 これは、数値が選択した基数よりも小さいことがすぐに識別されるため、特殊なケースです。 たとえば、次の場合`x = 3`そしてベースをクエリします`5`、インタラクターが戻ります`-1`。 処理しない実装`-1`正しく実行すると、結果が数値の合計として誤って解釈される可能性があります。 

もう一つの微妙な点は、`c`。 総当りの列挙に頼ることはできず、非常に大きな数値を単純に操作しようとすると整数オーバーフローが発生する可能性があります。 この問題は本質的に、いくつかのモジュール制約から数値を再構成することに関するものです。 

## アプローチ

 ブルートフォースアプローチでは、より小さなベースを順番にクエリし、リバースエンジニアリングを試みます。`x`応答に適合するすべての数値をシミュレートすることによって。 これは原理的には正しいです。桁の合計によって特定の基数の数値を一意に識別できるからですが、これは実行不可能です。 各クエリは次の形式の情報を提供します。`sum_digits(x, b) ≡ x mod (b-1)`、底の数字の合計なので、`b`は剰余数に一致します`b-1`。 たった 4 つのクエリを使用して、このモジュール構造を活用する方法が必要です。 

重要な観察は、どんな数値に対しても`x`、`x % (b-1)`の桁の合計に等しい`x`基地内で`b`。 これは、数値と桁の合計の古典的な特性です。 したがって、各クエリにより効果的に次のことが得られます。`x modulo (b-1)`。 ペアごとの差が互いに素である 4 つの塩基を選択すると、中国剰余定理を適用して一意に再構成できます。`x`の積を法とする`(b-1)`それらの基地のために。 これらのベースを慎重に選択すると、製品は`c`したがって、回復します`x`その通り。 

最適なアプローチは、2 の累乗マイナス 1 が互いに素であるため、4 つの大きく異なる 2 のべき乗を選択することです。 例えば、`b1 = 2^1`、`b2 = 2^2`、`b3 = 2^4`、`b4 = 2^8`与える`b1-1 = 1`、`b2-1 = 3`、`b3-1 = 15`、`b4-1 = 255`。 これらの係数は互いに素であり、その積は以下よりもはるかに大きくなります。`c`。 各クエリについて、剰余モジュロを計算します。`b_i-1`桁の合計を使用して再構築します`x`中国の剰余定理を使用します。

 ## アルゴリズムのチュートリアル

 1. 次のような 4 つの基底を事前計算します。`(b_i - 1)`は互いに素であり、その積は次を超えます`c`。 たとえば、次のように使用します。`b = 2, 3, 4, 5`またはその他の小さな 2 の累乗を上にシフトします。 
2. 推測する数値ごとに、4 つの塩基のそれぞれを使用してインタラクターにクエリを実行します。 数字の合計である応答を読み取るか、`-1`もし`x < b`。 もし`-1`起こる、私たちは知っています`x`はそのベースより小さいので調整します。 
3. 各桁の合計を剰余に変換します。`remainder_i = sum_digits_i mod (b_i - 1)`。 これは有効です。`x ≡ sum_digits(x, b_i) (mod b_i - 1)`。 
4. 中国剰余定理を使用して再構築する`x`の積を法とする`(b_i - 1)`。 商品が超過しているため、`c`、これは一意に決定されます`x`。 
5. 出力`! x`推測を送信し、検証応答を読みます。 
6. 各番号について繰り返します`t`。 

機能する理由: 各クエリには制約が与えられます`x ≡ sum_digits(x, b_i) mod (b_i-1)`。 以来`(b_i-1)`はペアごとに互いに素であり、その積は次を超えます`c`、CRT は、次の分野で独自のソリューションを保証します。`[1, c]`。 桁の合計を剰余として使用することは、重要な数学的特性です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def chinese_remainder_theorem(remainders, moduli):
    x = 0
    M = 1
    for m in moduli:
        M *= m
    for r, m in zip(remainders, moduli):
        Mi = M // m
        # compute inverse of Mi mod m
        inv = pow(Mi, -1, m)
        x += r * Mi * inv
    return x % M

t, k, c = map(int, input().split())

# choose bases so that b-1 are coprime
bases = [2, 3, 4, 5]
moduli = [b - 1 for b in bases]

for _ in range(t):
    remainders = []
    for b in bases:
        print("?", b)
        sys.stdout.flush()
        res = int(input())
        if res == -1:
            remainders.append(0)
        else:
            remainders.append(res % (b - 1))
    x = chinese_remainder_theorem(remainders, moduli)
    print("!", x)
    sys.stdout.flush()
    r = int(input())
    if r == 0:
        sys.exit()
```ソリューションはまず次のような塩基を選択します。`b-1`は互いに素である。 各クエリは桁の合計を生成し、それがモジュラー剰余に変換されます。 の`chinese_remainder_theorem`関数が再構築する`x`一意に推測し、その推測を提出します。 エッジケースなど`-1`応答は剰余を次のように設定することで処理されます。`0`、底よりも小さい数値はそれ自体を法として合同であるため機能します。`b-1`。
