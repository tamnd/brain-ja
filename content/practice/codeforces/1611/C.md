 ## 問題の理解

入力は複数のテスト ケースで構成されます。 各テストケースにはサイズがあります`n`そして結果の配列`a`。 以来`n`まで可能です`2 * 10^5`そしてすべての合計`n`テスト ケース全体が同じ数で制限される場合、テスト ケースごとに効率的な線形アルゴリズムが必要です。 すべての順列を試行したり、各ステップですべての可能な選択肢をシミュレートしたりするなど、二次的な複雑さを持つアルゴリズムは遅すぎます。 

考慮すべきエッジケースには、次のようなシーケンスが含まれます。`n=1`、配列が厳密に増加または減少しているシーケンス、および有効な順列に対応できないシーケンス。 例えば、`a = [1, 3, 5, 4, 2]`相対的な順序が記述されたルールと一致しないため、これは不可能です。 

## アプローチ

重要な洞察は、以下から逆算して考えることです。`a`。 プロセスを順にシミュレートする代わりに、次のように再構築できます。`p`生成のあらゆる段階でそれを観察することによって、`a`、残りのシーケンスの次に小さい番号は、いずれかの端から来る必要があります。 これにより分割が可能になります`a`のセグメントに対応する連続したチャンクに分割`p`。 各チャンクは、選択された左端の最小値から次の最小値まで減少し、直接追加できるブロックを形成します。`p`。 これらのブロックを効率的に識別することで、有効な順列を線形時間で再構築できます。

 ## アルゴリズムのチュートリアル

 1. の最初の要素から開始します。`a`現在の最小値よりも小さい数値が見つかるまで、要素が厳密に減少している連続セグメントを識別します。 このような各セグメントは、元の順列のブロックに対応します。`p`。 
2. セグメントごとに、再構成された順列を表すリストに順番に追加します。 これが機能するのは、元のプロセスでは、ブロック内の最小の数値が最初に削除され、その後、ブロックの残りの部分が左から右、または右から左の順に削除されるためです。 
3. これまでに確認された最大の数値を追跡して、次のセグメントの境界を決定します。 セグメントに既に追加されている番号が含まれている場合、再構成は不可能なので、出力します。`-1`。 
4. すべての要素が表示されるまでこのプロセスを続けます。`a`消費される。 識別されたすべてのブロックを連結すると、有効なブロックが形成されます。`p`。 
5. 再構成された順列を出力するか、`-1`いずれかのステップで再構築が失敗した場合。 

ここで不変なのは、各ステップで、セグメント内で処理する要素が、元のプロセスの最後から連続して削除された要素とまったく同じであるということです。 常に最大の減少セグメントを取得することにより、どちらかの端から最小の要素を常に削除するというルールが尊重されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        seen = [False] * (n + 1)
        result = []
        i = 0
        while i < n:
            block = []
            current = a[i]
            if seen[current]:
                result = [-1]
                break
            j = i
            while j < n and not seen[a[j]]:
                block.append(a[j])
                seen[a[j]] = True
                j += 1
            result.extend(block)
            i = j
        if result[0] == -1:
            print(-1)
        else:
            print(' '.join(map(str, result)))

if __name__ == "__main__":
    solve()
```このコードでは、ブール配列を維持します。`seen`再構成時に数字が 2 回出現しないようにするためです。 を繰り返します`a`、減少するセグメントを`block`、見たとおりに数字をマークし、拡張します`result`これらのブロックを使って。 すでに表示されている数値に遭遇した場合、それは矛盾を示しており、次の値を返します。`-1`。

 ## 特殊なケース

 もし`n=1`、配列`a`数値が 1 つだけ含まれており、`p`でなければなりません`[1]`。 アルゴリズムは、長さ 1 のブロックを作成することでこれを正しく処理します。 もし`a`厳密に増加または減少している場合、アルゴリズムはすべての要素をカバーする単一のブロックを形成します。 再構成で要素が繰り返される場合、または非減少セグメントが最小除去プロパティに違反する場合、アルゴリズムは次の出力を行います。`-1`。 例えば、`a = [1, 3, 2]`有効です。`a = [2,1,3]`最小限の要素なので無効です`1`削除されるべきときにどちらの端にもありません。
