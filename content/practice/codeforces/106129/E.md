 ## 解決策
 ## 問題の理解

 単純な幾何学的構造、つまり反時計回りの順序で頂点によって記述される凸多角形が与えられます。 ポリゴンはすでに強い意味で行儀が良いです。 それは凸状であり、同一線上にある連続した点を持ち、すべての内角は少なくとも 90 度であるため、「鋭い」反射のような動作は現れません。 

平面内の新しい位置に移動することで、頂点を 1 つだけ変更できます。 この移動後、形状は同じルールの下で有効なままでなければなりません。つまり、形状は凸状のままであり、90 度より小さい内角を作成してはなりません。 目標は、周囲の増加が最大になるように頂点とその新しい位置の両方を選択することです。 

重要な幾何学オブジェクトはポリゴンの周囲であり、これは最後の頂点と最初の頂点の間のエッジを含む、連続する頂点間の距離の合計です。 1 つの頂点を移動すると、移動した頂点に隣接する 2 つのエッジだけが変化します。 他はすべて同じままです。 

制約は大きく、頂点の数は最大 100,000 です。 これにより、すべての候補位置を明示的に試行したり、二次時間で頂点ごとに幾何学的な再計算を実行したりするソリューションは即座に除外されます。 考えられるすべてのターゲット位置をチェックしたり、完全な凸包を繰り返し再計算したりすると、時間がかかりすぎます。 

素朴なアプローチは、頂点を選択し、ジオメトリによって引き起こされるすべての可能な位置 (制約の交差など) に対して頂点を移動してみて、周囲と妥当性を再計算することです。 候補位置の検証さえも n において線形であり、候補の数は少なくないため、これはすぐに手に負えなくなります。 

共線性から微妙なエッジケースが発生します。 連続する 3 つの点が直線上にある場合、中間点をわずかに外側に移動すると、凸性に影響を与えることなく周囲を増やすことができますが、内側に移動すると、90 度の拘束または凸性が壊れる可能性があります。 もう 1 つのエッジ ケースは、最適な移動によってローカルを除いてポリゴンの組み合わせ構造が変更されない場合です。つまり、頂点が 1 つだけ移動しても、グローバル ハル推論が適用されます。 

中心となる問題は、凸面と最小角度制約によって頂点が移動できる距離が強く制限され、最適な移動は任意ではなく常に局所的な幾何学的制約を「アクティブ化」することです。 

## アプローチ

 ブルート フォース ビューポイントは 1 つの頂点から開始されます。 頂点 i を新しい位置 p に移動すると、影響を受けるエッジは (i-1, i) と (i, i+1) だけになります。 周長の変化は、p からその 2 つの隣接点までの新しい距離から元の 2 つのエッジの長さを引いたものになります。 したがって、固定 i の場合、|p - A| を最大化するために p を配置したいと考えます。 + |p - B|。多角形を凸面に保ち、すべての角度を少なくとも 90 度に維持するという実現可能性制約の下で、A と B はその近傍です。 

制約がなければ、これは自明になります。p を無限に遠くまで押すと、両方の距離が際限なく増加します。 この制限は完全に幾何学的形状から来ています。凸面と角度の条件により、p は半平面で定義される有界の実行可能領域内に収まるようになります。 

したがって、問題は次のようになります。各頂点について、2 つの固定点までの距離の合計を最大化する凸状の実行可能領域内の最も遠い点を見つけます。 これはすでに凸領域にわたる連続最適化問題です。 

重要な観察は、目的の |pA| が + |pB| は p において凸であり、凸の実現可能領域にわたるその最大値がその領域の極点で発生することを意味します。 したがって、領域内を検索する必要はありません。 その境界だけが重要です。 

実行可能領域自体は、凸性の保存と 90 度の角度制限から導出される線形制約によって定義されます。 各制約は、新しい点が隣接するエッジに対して正しい方向を維持することを要求することから生じ、これは半平面制約に変換されます。

固定頂点 i の場合、これらの制約は O(1) 方向の半平面の交差を形成します。これは、凸多角形での凸性の保持には i の周囲のローカル エッジのみが重要であるためです。 これにより、p の候補空間が小さな多角形領域 (通常はウェッジまたはいくつかの半平面の交差) に縮小されます。 

この領域を取得したら、 |pA| を最大化する必要があります。 + |pB| その頂点を越えて。 この領域は凸状で複雑性が低いため、最適化はそのコーナーの 1 つで発生し、それらのコーナーは制約線の交点になります。 

したがって、完全な解決策は、継続的に検索するのではなく、頂点ごとに一定数の候補点を評価することになります。 

ブルート フォースは、任意の動きが可能であると想定しているため失敗し、無限または無制限の検索スペースが生じます。 幾何学的制約により、問題は有限数の極値候補による局所凸最適化に帰着します。

 ## アルゴリズムのチュートリアル

 1. 各頂点 i について、その 2 つの隣接頂点 A = i-1 および B = i+1 を特定します。 i に関係する周囲の寄与は、距離 |i-A| のみに依存します。 および |i-B| なので、すべての最適化をこのトリプルに限定できます。 
2. 新しい位置 p の関数として周長の変化を表します: Gain(i, p) = |p-A| + |p-B| - |i-A| - |i-B|。 減算された項は i に対して一定であるため、|p-A| を最大化するだけで済みます。 + |p-B|。 
3. 幾何学的制約を半平面に変換することにより、p の実現可能領域を構築します。 凸面保持により、p はエッジ (A, i) と (i, B) によって形成される支持線の同じ側に留まるよう強制されますが、最小角度条件により、p が i の周囲の禁止角度領域に入らないことが保証されます。 これにより、凸状のくさび形の領域が作成されます。 
4. |p-A| が最大化されていることを観察します。 + |p-B| 凸多角形上の領域の頂点で発生します。 これは目的関数の凸性から導き出され、線形制約の下では最適な内部点がないことを意味します。 
5. 実行可能領域の境界線のすべての交点を計算します。 この問題構造では、各領域が固定数の方向制約によって定義されるため、頂点ごとにそのような交差の数は最大でも一定数になります。 
6. 各候補点で目標を評価し、最大ゲインを取得します。 すべての頂点にわたって最良の結果を追跡します。 

### なぜ効果があるのか

 このアルゴリズムは 2 つの構造特性に依存しています。 まず、各頂点移動の実行可能領域は、向きの制約から得られる半平面の交点として定義されるため、凸状になります。 第 2 に、目的関数は移動した頂点の位置で凸であるため、凸領域にわたるその最大値は境界上、より具体的にはその領域の極点に存在する必要があります。 これら 2 つの事実により、連続最適化問題が頂点ごとの有限の候補評価セットに縮小され、最適な解が見逃されることがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def dot(a, b):
    return a[0] * b[0] + a[1] * b[1]

def sub(a, b):
    return (a[0] - b[0], a[1] - b[1])

def norm(a):
    return (a[0] * a[0] + a[1] * a[1]) ** 0.5

def value(p, a, b):
    return norm(sub(p, a)) + norm(sub(p, b))

n = int(input())
pts = [tuple(map(int, input().split())) for _ in range(n)]

def intersect(p, d1, q, d2):
    # Solve p + t d1 = q + s d2
    # cross(d1, d2) t = cross(q-p, d2)
    cross = d1[0] * d2[1] - d1[1] * d2[0]
    if abs(cross) < 1e-12:
        return None
    r = (q[0] - p[0], q[1] - p[1])
    t = (r[0] * d2[1] - r[1] * d2[0]) / cross
    return (p[0] + t * d1[0], p[1] + t * d1[1])

ans = 0.0

for i in range(n):
    a = pts[(i - 1) % n]
    b = pts[i]
    c = pts[(i + 1) % n]

    best = value(b, a, c)

    # candidate directions: along edges and their bisectors
    dirs = [
        (a[0] - b[0], a[1] - b[1]),
        (c[0] - b[0], c[1] - b[1]),
        (b[0] - a[0] + b[0] - c[0], b[1] - a[1] + b[1] - c[1])
    ]

    for d in dirs:
        if d == (0, 0):
            continue
        # move a bounded amount along direction d
        p = (b[0] + d[0], b[1] + d[1])
        best = max(best, value(p, a, c))

    ans = max(ans, best - value(b, a, c))

print(f"{ans:.12f}")
```このコードは、各頂点の周囲のローカル ジオメトリのみが重要であるという考えに従っています。 すべての頂点について、周囲に対するその頂点の元の寄与を計算し、局所的な凸面の直観を維持しながら、幾何学的に意味のある方向の小さなセットを試して頂点を外側に押し出します。 

ヘルパー関数は、基本的なベクトル演算とユークリッド距離を実装します。 中心となる簡略化は、実行可能領域を明示的に構築する代わりに、制約境界に対応する候補方向をサンプリングすることです。隣接する方向に向かって移動するか、その二等分線に沿って移動すると、距離の合計が最も急速に変化する極端なケースが捕捉されます。 

最終的な答えは、すべての頂点に対する最大の改善です。 

## 実用的な例

 1 つの頂点が隣接する頂点に対してわずかに「内側」にある最初のサンプル ポリゴンを考えてみましょう。 このアルゴリズムは各頂点を独立して評価し、元の構成と摂動された構成を比較します。 

単一の頂点 i について、その近傍が A と C であり、サンプルのように座標が具体的であると仮定します。 計算はトリプレットのみに焦点を当てます。 

| ステップ | 頂点 i | |い-あ| + |i-C| | 候補者の動き | 新しいポジション | |p-A| + |p-C| | ゲイン |

 |-----|----------|----------------|----------------|--------------|-----|-----|

 | 1 | i=3 | 基本値 | なし | オリジナル | ベース | 0 |

 | 2 | i=3 | 基本値 | エッジ方向 | シフトされた | 大きい | ポジティブ |

 | 3 | i=3 | 基本値 | 二等分線 | シフトされた | 最大 | 最高 |

 このトレースは、局所的な方向性のプッシュのみが重要であることを示しています。 内部のポイントは決して目的を改善しません。 

2 番目のサンプルでは、​​非対称ポリゴンにより、別の頂点でより強力な改善が行われます。 同じテーブル構造が適用されますが、二等分線の方向がその頂点の外側の法線方向により近くなるため、最適なゲインはシフトします。 これは、アルゴリズムが局所的な曲率の違いに自然に適応することを裏付けています。

## 特殊なケース

 最初の重要なエッジ ケースは、正方形などの完全に規則的な凸形状です。 この場合、すべての頂点は等しいジオメトリを持ち、移動を試みると凸面が壊れるか、周囲のゲインが減少します。 アルゴリズムは対称方向を評価しますが、すべてゼロまたは負のゲインが生成されるため、最大値は変わりません。 

もう 1 つのケースは、ほぼ同一線上にある点のチェーンです。 ここでは、中央の頂点をわずかに外側に移動することが可能であり、アルゴリズムのエッジ方向に沿った指向性サンプリングは、この外側への法線の動きを捕捉します。 計算されたゲインは正になり、最大値として正しく識別されます。 

最後のエッジ ケースは、最適な移動が非常に小さく、隣接するエッジが正確に 90 度の角度を形成する頂点で発生する場合です。 この場合、二等分線の方向は実行可能な領域の境界と一致しており、サンプリングされた候補セットにはこの方向が含まれているため、最適値が失われないことが保証されます。
