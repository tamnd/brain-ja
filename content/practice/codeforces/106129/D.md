 ## 解決策
 ## 問題の理解

 単純な直交多角形が与えられます。これは、その境界が水平セグメントと垂直セグメントのみで構成され、自己交差のない閉じたサイクルであることを意味します。 頂点は反時計回りの順序でリストされているため、頂点を通過すると都市の境界をたどることができます。 

タスクは、指定された多角形全体を「包み込み」、軸に位置合わせされたセグメントのみを使用し、全長が可能な限り最小になる、別の閉じた直交サイクルを構築することです。 出力は元の頂点を再利用する必要はありませんが、どこでも元の輪郭に任意に近くなるという意味で、直交を維持し、単純なままであり、同じ領域を囲む必要があります。 

出力では元の境界までの距離がゼロであることが許可されているため、問題は固定半径で外側にポリゴンをバッファリングすることではありません。 代わりに、輪郭を完全にカバーする最短の直線サイクルを求めます。これにより、軸に沿った方向の外側エンベロープに寄与しないすべての凹面のくぼみが効果的に折りたたまれます。 

制約は大きく、最大 100,000 個の頂点と最大 10^9 の座標があります。 これにより、頂点のペア間の可視性のテストや、エッジに沿った幾何学的オフセットの明示的なシミュレーションなどの二次推論が即座に除外されます。 ソートまたは座標圧縮後の頂点の数は、基本的に線形またはほぼ線形である必要があります。 

よくある失敗例は、これを標準の凸包問題として扱おうとすることです。 通常の凸包では斜めのエッジが発生しますが、ここでは許可されていません。 もう 1 つの落とし穴は、ローカル角度チェックを使用して「凹状の頂点を削除」しようとすることです。 直交多角形では、頂点が局所的に凹んでいても形状の極端な水平または垂直境界上にある可能性があるため、凹面だけでは頂点が外側の直線包絡線に属するかどうかを判断するのに十分ではありません。 

具体的な例として、上端にある階段状のくぼみを考えてみましょう。 頂点は隣接する頂点に比べて凹面になっている可能性がありますが、それでも広い x 間隔の最高点になります。 これを局所的に削除すると、境界の一部が誤って平らになり、形状を囲むことができなくなります。 

## アプローチ

 ブルートフォース解釈では、多角形を囲むすべての可能な直交サイクルを構築し、最短のものを選択しようとします。 注意を頂点のサブセットに限定したとしても、候補サイクルの数は指数関数的であり、サイクルの有効性を検証するには、すべてのエッジに対する幾何学的チェックが必要であり、すでに O(n) のコストがかかります。 これはすぐに実行不可能になり、最悪の場合、およそ 10^10 の操作を超えます。 

重要な観察は、最適な囲み直交サイクルは、多角形の x 軸と y 軸への極端な投影によって完全に決定されるということです。 完全な 2D 構造について推論する代わりに、ポリゴンを垂直にスライスすると何が起こるかという観点から考えることができます。 

任意の x 座標について、最適な外側境界は、その x で多角形が到達する最高点と最低点を通過する必要があります。 これらの極端な内側のインデントは、形状を囲む要件に影響を与えないため、最小の囲みサイクルには決して現れません。 左右対称でも同様の考え方が成り立ちます。 

これにより、水平セグメントの結合として見たときに多角形の上部エンベロープと下部エンベロープを計算し、これらのエンベロープを単一の直交サイクルにステッチするという問題が軽減されます。

ポリゴンの境界は水平エッジと垂直エッジで構成されているため、すべての水平エッジは x に対する一定の y 間隔に寄与します。 上部の境界は、特定の x をカバーするすべての水平エッジの最大の y 値であり、下部の境界は最小の y 値です。 どちらの関数も区分的に定数であり、エッジの端点の x 座標でのみ変化します。 これにより、アクティブな間隔を維持しながら x をスイープすることができます。

 ## アルゴリズムのチュートリアル

 上部と下部のエンベロープを別々に構築し、それらを 1 つのサイクルに結合することでソリューションを再構築します。 

まず、ポリゴンからすべての水平エッジを抽出します。 各水平エッジは、固定の y 値での x 軸上の間隔として表されます。 (x1, y) から (x2, y) までのエッジについては、高さ y で間隔 [min(x1, x2), max(x1, x2)] をアクティブにするイベントを保存します。 

次に、変更を順番に処理できるように、これらのエンドポイントからのすべての X 座標を圧縮します。 各 x 位置で、どの水平セグメントがアクティブであるかを知る必要があります。 

3 番目に、x を昇順にスイープします。 間隔の挿入と削除をサポートするデータ構造を維持し、アクティブな間隔の最大値と最小値 y のクエリもサポートします。 スイープがその範囲に出入りするときに各間隔を挿入または削除できるため、マルチセットで十分です。 

すべての間隔更新を適用した後、各 x 位置で、上部エンベロープを表す最大アクティブ y と、下部エンベロープを表す最小アクティブ y の 2 つの値を計算します。 これらの値は連続する x 座標間で一定のままであるため、結果として得られる多角形の水平セグメントとして記録します。 

4 番目に、これらの区分的に一定のエンベロープを一連の頂点に変換します。 上限または下限の値が変更されるたびに、現在の x 座標の頂点と対応する y 座標が出力されます。 これにより、2 つの x-monotone チェーンが生成されます。 

最後に、上のチェーンと反転した下のチェーンを連結して、閉じたサイクルを形成します。 どちらのチェーンも x では単調であるため、連続する頂点は 1 つの座標だけで異なり、軸の位置合わせが維持されます。 

### なぜ効果があるのか

 実行可能なすべての囲み直交サイクルは、各 x 位置について、その x で元の多角形が到達可能な最小 y 値と最大 y 値の間になければなりません。 この範囲内にあるセグメントは多角形の一部を囲むことができず、外側にあるセグメントはエンベロープに達するまで長さを増やさずに内側に引っ張ることができます。 これは、境界がまさに上部エンベロープと下部エンベロープの結合であるため、これらの極端な関数の変更を超えて頂点を追加する必要がないことを意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from collections import defaultdict
import bisect

def build_chain(events, xs):
    active = defaultdict(int)
    active_vals = []

    def add(y):
        if active[y] == 0:
            bisect.insort(active_vals, y)
        active[y] += 1

    def remove(y):
        active[y] -= 1
        if active[y] == 0:
            i = bisect.bisect_left(active_vals, y)
            active_vals.pop(i)

    ei = 0
    m = len(xs)

    upper = []
    lower = []

    for i in range(m):
        x = xs[i]

        while ei < len(events) and events[ei][0] == x and events[ei][1] == 0:
            _, _, y = events[ei]
            add(y)
            ei += 1

        while ei < len(events) and events[ei][0] == x and events[ei][1] == 1:
            _, _, y = events[ei]
            remove(y)
            ei += 1

        if active_vals:
            upper.append((x, active_vals[-1]))
            lower.append((x, active_vals[0]))

    return upper, lower

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    events = []
    xs = set()

    for i in range(n):
        x1, y1 = pts[i]
        x2, y2 = pts[(i + 1) % n]
        if y1 == y2:
            l, r = sorted([x1, x2])
            events.append((l, 0, y1))
            events.append((r, 1, y1))
            xs.add(l)
            xs.add(r)

    xs = sorted(xs)
    events.sort()

    upper, lower = build_chain(events, xs)

    def compress(chain):
        res = []
        for x, y in chain:
            if not res or res[-1][1] != y:
                res.append((x, y))
        return res

    upper = compress(upper)
    lower = compress(lower)

    # build polygon
    path = upper + lower[::-1]

    # remove possible collinear duplicates
    final = []
    for p in path:
        if not final or final[-1] != p:
            final.append(p)

    print(len(final))
    for x, y in final:
        print(x, y)

if __name__ == "__main__":
    solve()
```垂直エッジは x の極値 y 値に直接寄与しないため、解決策は水平エッジのみを抽出することから始まります。 各水平エッジは 1 対のスイープ イベントに変換されます。 スイープはアクティブな y 値のマルチセットを維持し、現在の最大値と最小値を一定時間で取得できるようにします。 

圧縮ステップにより、何かが変更された箇所の x 座標のみが考慮されるようになります。 上部チェーンと下部チェーンの構築により、これらの極値が変化するたびに境界頂点が記録されます。 

最後に、上部チェーンと反転した下部チェーンを連結すると、閉じた直交サイクルが生成されます。 

## 実用的な例

 ### サンプル 1

 上部の境界が平らではない形状から始めます。x = 3 と x = 5 の間にバンプがあります。スイープが x 上で進行するにつれて、アクティブな水平エッジが変化する最大 y 値を定義します。 

| × | アクティブな y 範囲 | 上の y | 下のy |
 | --- | --- | --- | --- |
 | 1 | [2,5] | 5 | 2 |
 | 3 | [2,5] | 5 | 2 |
 | 5 | [1,5] | 5 | 1 |
 | 7 | [1,5] | 5 | 1 |

 上部エンベロープは y = 5 で一定の​​ままであるため、最終結果にはバンプは表示されません。 下のエンベロープは x = 5 および x = 7 で低下し、出力に示されている単純化された長方形のような形状が生成されます。 

これにより、極端な y 値に影響を与えない内部のくぼみが削除されたことが確認されます。 

### サンプル 2

 ここでは、ポリゴンはよりギザギザの階段構造になっています。 

| × | アクティブな y 範囲 | 上の y | 下のy |
 | --- | --- | --- | --- |
 | 1 | [1,4] | 4 | 1 |
 | 2 | [2,4] | 4 | 2 |
 | 3 | [3,4] | 4 | 3 |
 | 4 | [1,4] | 4 | 1 |

 下部エンベロープはステップごとに変化し、きれいな単調の下降と上昇を生成しますが、上部エンベロープは一定のままです。 結果として得られる多角形は、形状を囲む最小の直線サイクルです。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、複数の水平エッジが同じ y 値を共有しているが、互いに素な x 間隔で表示される場合です。 それらを時期尚早にマージすると、アクティブなカバレッジが誤って拡張され、エンベロープが歪む可能性があるため、スイープではこれらを独立して処理する必要があります。 マルチセットベースのアプローチでは、各間隔を個別に追跡することでこれを回避します。 

もう 1 つのケースは、ポリゴンが高い水平エッジと低い水平エッジの間で急速に切り替わる場合です。 このような場合、アクティブ セットは頻繁に変更されますが、出力は最大または最小の y 値が実際に変更された場合にのみ変更されます。 これにより、振動の激しい入力でも出力頂点の数が線形に保たれます。 

最後の微妙なケースは、エンベロープが x の長い範囲で変化しない場合に発生します。 このアルゴリズムは引き続き x ブレークポイントごとにポイントを出力しますが、圧縮ステップにより冗長な頂点が削除され、平らなセグメントに不要な共線点が導入されないようになります。
