 ## 解決策
 ## 問題の理解

 次の形式の二次方程式を解くように求められます。$Ax^2 + Bx + C = 0$、 どこ$A$、$B$、 そして$C$範囲内の整数です$[-10^5, 10^5]$。 目標は、方程式の実根をすべて見つけて数え、昇順で高精度に出力することです。 方程式に無限に多くの解がある場合、次のように出力する必要があります。$-1$。 解決策がない場合は印刷します$0$。 

入力係数にはゼロを含めることができるため、微妙な点が生じます。 たとえば、次の場合$A = 0$、方程式は線形になります ($Bx + C = 0$)、両方の場合$A = 0$そして$B = 0$、方程式には解がありません (もし$C \neq 0$) または無限に多くの解 (場合$C = 0$）。 

制約は十分に小さいため、単純な算術以外のアルゴリズムの効率について心配する必要はありません。 平方根の計算と条件チェックの実行は、許容時間内に十分収まります。 課題はすべてのケースを正しく処理し、数値の精度を維持することにあります。 

明らかではないエッジケースには、次のシナリオが含まれます。 もし$A = 0$そして$B = 0$、その場合、解決策は完全に依存します$C$。 例えば、$0x^2 + 0x + 5 = 0$根はありませんが、$0x^2 + 0x + 0 = 0$無限に多くの根を持っています。 もう 1 つの微妙な点は、判別式が 0 の場合に発生し、ルートが 1 つだけ生成され、出力で重複してはなりません。 負の判別式は実際の根を生成しません。 浮動小数点精度を正しく処理して、出力されるルートの小数点以下が少なくとも 5 桁になるようにすることも必要です。 

## アプローチ

 素朴なアプローチは、可能な値をすべて試してみることです。$x$範囲内で、満たしているかどうかを確認する$Ax^2 + Bx + C = 0$ある程度の精度まで。 縮退したケースを正しく処理すれば、二次方程式はあらゆる二次方程式に対して正確な解析解を与えるため、この強引な方法は不要です。 列挙する$x$長い間隔にわたって実行すると、無制限の数の操作が必要となり、高精度で確実にルートを識別することはできません。 

最適なアプローチは標準的な代数に依存します。 のために$A \neq 0$、判別式を計算します$D = B^2 - 4AC$。 もし$D > 0$、によって与えられる 2 つの異なる根があります。$(-B - \sqrt{D}) / (2A)$そして$(-B + \sqrt{D}) / (2A)$。 もし$D = 0$、ルートは 1 つです$-B / (2A)$。 もし$D < 0$、本当の根はありません。 線形の場合 ($A = 0$そして$B \neq 0$)、ルートは 1 つだけです$-C / B$。 両方の場合$A$そして$B$が 0 の場合、解は、次のいずれかに応じて、ゼロ ルートまたは無限に多くのルートになります。$C$はゼロです。 

重要な洞察は、線形と二次の場合を別々に扱い、二次方程式の判別式を使用することです。 条件を慎重に順序付けすることで、ゼロで除算したり、負の数の平方根を求めたりすることがなくなります。 ルートが見つかったら、それらをソートすることで昇順が保証されます。

 ## アルゴリズムのチュートリアル

 1. 整数の読み取り$A$、$B$、 そして$C$。 これらの係数は方程式を定義します$Ax^2 + Bx + C = 0$。 
2. 次のことを確認します。$A = 0$。 そうである場合、方程式は二次ではなく線形になります。 
3. もし$A = 0$そして$B = 0$、 チェック$C$。 もし$C = 0$、印刷$-1$無限に多くのソリューションを実現します。 それ以外の場合は、印刷します$0$解決策がないからです。 
4. もし$A = 0$しかし$B \neq 0$、単一ルートを計算します$-C / B$、印刷$1$、次に小数点以下 5 桁以上のルート。 
5. もし$A \neq 0$、判別式を計算します$D = B^2 - 4AC$。 
6. もし$D < 0$、実際のルートはないので、印刷します$0$。 
7. もし$D = 0$、単一ルートを計算します$-B / (2A)$そして印刷する$1$続いてルート。 
8. もし$D > 0$、2つの根を計算します$(-B - \sqrt{D}) / (2A)$そして$(-B + \sqrt{D}) / (2A)$。 印刷する$2$次にルートが昇順で続きます。 

機能する理由: 各ケースは相互に排他的であり、網羅的です。 線形の場合は、ゼロによる除算を避けるために個別に処理されます。 判別分析を備えた二次公式により、ルートの正確なカウントと計算が保証され、2 つのルートをソートすることで昇順が保証されます。 ゼロ/非ゼロ係数のすべての組み合わせが考慮されるため、欠落しているエッジ ケースはありません。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

A, B, C = map(int, input().split())

if A == 0:
    if B == 0:
        if C == 0:
            print(-1)
        else:
            print(0)
    else:
        x = -C / B
        print(1)
        print(f"{x:.10f}")
else:
    D = B * B - 4 * A * C
    if D < 0:
        print(0)
    elif D == 0:
        x = -B / (2 * A)
        print(1)
        print(f"{x:.10f}")
    else:
        sqrt_D = math.sqrt(D)
        x1 = (-B - sqrt_D) / (2 * A)
        x2 = (-B + sqrt_D) / (2 * A)
        x1, x2 = sorted([x1, x2])
        print(2)
        print(f"{x1:.10f}")
        print(f"{x2:.10f}")
```コードは、ゼロ除算を回避するために線形と二次の場合を分離し、無限根を正しく処理します。 私たちが使用するのは`math.sqrt`正の判別式のみを対象とし、2 つ存在する場合はルートをソートして昇順を保証します。 で印刷する`.10f`問題の要件に対して十分な精度が得られます。
