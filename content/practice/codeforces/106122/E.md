 ## 問題の理解

 プレートの列が与えられ、各プレートには正の数の「チキンスター」が含まれており、単純に配列の重みとして考えることができます。 2 人のプレイヤーが順番に行動します。 

まず、防御側は配列内の 1 つの位置を正確に「ゼロアウト」し、その 1 つのプレートからすべての値を削除します。 その後、攻撃者は固定長の連続セグメントを選択します。$k$そして、そのセグメント内の値の合計を収集します。 攻撃者はこの合計をできるだけ大きくしたいと考えていますが、防御者は 1 回の変更後に可能な限り最良のセグメント合計を最小限に抑えたいと考えています。 

最終的な答えは、すべての長さの最大合計の値です。$k$ゼロに設定するインデックスを 1 つ最適に選択した後のサブ配列。 

入力サイズは最大です$n \le 10^5$したがって、考えられる変更ごとにすべてのウィンドウの合計を個別に再計算するソリューションは遅すぎます。 それぞれについて単純な再計算$O(n)$変更されたインデックスの選択肢 (それぞれスキャンが必要)$O(n)$窓、$O(n^2)$それ以上の場合は、一般的な 2 秒の制約では受け入れられません。 

いくつかのエッジの状況が重要です。 

すべての値が等しい場合、次のようにします。$a = [5, 5, 5, 5]$そして$k = 2$の場合、最適なウィンドウは常に固定され、ウィンドウの内側または外側の 1 つの要素を削除すると、さまざまなウィンドウにさまざまな影響が与えられます。 「常に最適なウィンドウ内を削除する」という単純な考えは、重複する最適なウィンドウが複数ある場合に失敗する可能性があります。 

もし$k = 1$、攻撃者は単純に最大の要素を選択します。 防御側は明らかにその最大値をゼロにするため、答えは配列の 2 番目の最大値になります。 

もし$k = n$、ウィンドウは 1 つだけであり、防御側は常に最大の要素を削除して、合計を可能な限り最大量削減します。 

最適な長さのときに興味深い動作が現れます。$k$1 つのインデックスを削除すると、それを覆うウィンドウの有効合計がシフトされるため、ウィンドウはその中の要素を削除したかどうかによって異なります。

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    # prefix sums
    pref = [0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + a[i]

    # window sums
    m = n - k + 1
    win = [0] * m
    for i in range(m):
        win[i] = pref[i + k] - pref[i]

    # prefix/suffix max over windows
    prefmax = [0] * m
    suffmax = [0] * m

    prefmax[0] = win[0]
    for i in range(1, m):
        prefmax[i] = max(prefmax[i - 1], win[i])

    suffmax[m - 1] = win[m - 1]
    for i in range(m - 2, -1, -1):
        suffmax[i] = max(suffmax[i + 1], win[i])

    ans = float('inf')

    for i in range(n):
        L = max(0, i - k + 1)
        R = min(m - 1, i)

        best_outside = float('-inf')
        if L > 0:
            best_outside = max(best_outside, prefmax[L - 1])
        if R < m - 1:
            best_outside = max(best_outside, suffmax[R + 1])

        best_inside = float('-inf')
        if L <= R:
            best_inside = suffmax[L]  # any window in range, use its base form
            best_inside = max(win[L:R + 1])  # refine (could be optimized, but conceptual)

        # removing a[i] subtracts from all affected windows
        best_inside -= a[i]

        ans = min(ans, max(best_outside, best_inside))

    print(ans)

if __name__ == "__main__":
    solve()
