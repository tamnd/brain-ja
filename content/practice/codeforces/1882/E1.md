 ## 解決策
 ## 問題の理解

 2 つの順列が与えられ、1 つはサイズです$n$そしてサイズの一つ$m$、これは 1 から 1 までのすべての整数を含む単なる配列です。$n$そして1から$m$ある順序で。 目標は、特定の操作を使用して、両方の順列を並べ替えられた形式に同時に変換することです。 この操作により、各順列のインデックスを選択し、そのインデックスで順列を分割し、ピボット要素を中心に左右の部分を交換することができます。 この操作は必要なだけ、最大 10,000 回適用できます。 

入力は順列のサイズを提供します。$n$そして$m$、および初期順列自体。 出力は次のいずれかです$-1$両方の順列を同時にソートすることが不可能な場合、またはソートされた配列を実現する操作のリスト。 

主な課題は、分割と交換操作を両方の置換に同時に適用するという制約です。 すべての操作が両方の配列に影響するため、各順列を個別に並べ替える単純なアプローチは機能しない可能性があります。 の境界$n, m \le 2500$ということを暗示します$O(n^2)$または$O(m^2)$アプローチは実行可能ですが、大幅に悪化すると遅すぎます。 エッジケースには、すでにソートされた配列、逆にソートされた配列、または同時操作ルールを破らなければ整列できない順列が含まれます。 

たとえば、次の場合$p = [2, 1]$そして$q = [2, 1]$、ワンオペレーションで$i = j = 2$最後の要素を中心に左右の部分を交換し、ソートされた配列を直接生成します。 操作の結合を無視する不注意なアプローチでは、操作を誤って個別に並べ替えようとする可能性があり、2 つの配列が異なる位置でピボットを必要とする場合、失敗する可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのペアが試行されます。$(i, j)$配列がソートされるまでの操作。 これは、一連のピボット スワップを使用してすべての順列を並べ替えることができるため、機能します。 注意してすべてをチェックしないと、最悪の場合の操作の数は無制限になります。$i \times j$すべてのステップでの可能性が法外に遅くなる可能性があります($O(n m \cdot k)$のために$k$操作）。 

重要な洞察は、ピボット操作が可逆的で柔軟性が高いことを観察することで得られます。 要素の現在位置でピボットを使用して、残りの最大要素を正しい位置に繰り返し移動することで、任意の順列を並べ替えることができます。 したがって、要素を配置する場所に関しては両方の配列を独立して処理できますが、選択したピボットを一貫した方法で位置合わせする必要があります。 簡単なバージョンでは、両方の配列に正しく配置する必要がある次の要素を繰り返し選択するだけで十分です。一方の配列がすでに正しい位置に到達している場合は、単純なスワップでパディングする可能性があります。 

これにより、貪欲なアルゴリズムが可能になります。つまり、各順列のソートされていないプレフィックスの最後の要素をピボットとして選択し、交換を実行し、両方の配列がソートされるまで継続します。 一方の配列が他方の配列よりも先に正しい順序に達した場合、順序を変更せずに完成した配列で単純なスワップを使用し続けることができ、もう一方の配列が確実に進行するようにします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((n*m)^k) | O(n+m) | 遅すぎる |
 | 貪欲なピボットソート | O(n+m) の操作 | O(n+m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 空の操作リストを初期化します。 ポインタを保持する$i$そして$j$正しく配置したい現在の要素に$p$そして$q$、1から始まります。 
2. いずれかの状態で$p$または$q$ソートされていません:

 1. 以下に等しい要素の位置を見つけます。$i$で$p$。 もし$i > n$、有効なピボットを選択します (例:$p_n$）。 
2. 以下に等しい要素の位置を見つけます。$j$で$q$。 もし$j > m$、有効なピボットを選択します (例:$q_m$）。 
3. 追加$(pivot\_p, pivot\_q)$操作のリストへ。 
4. 両方の置換にピボット スワップを適用します。 これにより、選択した要素が最終位置に移動され、残りが部分的に並べ替えられます。 
5. インクリメント$i$そして$j$要素が正しい位置に到達すると。 
3. 操作のリストを返します。 

機能する理由: 各ピボット操作により、少なくとも 1 つの要素を正しい最終位置に配置できます。 順列には個別の整数が含まれるため、各要素は固有の正しい位置を持ちます。 アルゴリズムは各ステップで進歩し、すでにソートされた部分に対する簡単な操作によってソートされた順序が崩れることはなく、一定期間内での終了が保証されます。$n + m$操作数は 10,000 をはるかに下回っています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def pivot_sort(arr, target):
    pos = {v:i for i,v in enumerate(arr)}
    ops = []
    n = len(arr)
    for k in range(1, n+1):
        idx = pos[k]
        if idx == k-1:
            continue
        # perform pivot swap at idx
        left = arr[:idx]
        mid = arr[idx]
        right = arr[idx+1:]
        arr[:] = right + [mid] + left
        # update positions
        for i,v in enumerate(arr):
            pos[v] = i
        ops.append(idx+1)
    return ops

def main():
    n, m = map(int, input().split())
    p = list(map(int, input().split()))
    q = list(map(int, input().split()))
    
    ops_p = pivot_sort(p, n)
    ops_q = pivot_sort(q, m)
    
    k = max(len(ops_p), len(ops_q))
    result = []
    for i in range(k):
        op_p = ops_p[i] if i < len(ops_p) else 1
        op_q = ops_q[i] if i < len(ops_q) else 1
        result.append((op_p, op_q))
    
    print(len(result))
    for a, b in result:
        print(a, b)

if __name__ == "__main__":
    main()
```このソリューションは、効率的なピボット選択のための要素の位置のマップを構築します。 次に、配列ごとにピボット操作を個別に生成し、短いリストにダミー操作を埋め込むことでそれらを位置合わせします。 各ピボット後に位置を更新することで、1 つずつの間違いを回避し、正確さを保証します。
