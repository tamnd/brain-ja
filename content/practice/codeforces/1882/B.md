 ## 解決策
 ## 問題の理解

 いくつかの整数のセットが与えられます。 これらのセットの任意のサブセット (なしを含む) を選択し、選択したセットの和集合を取得できます。 この方法でセットを形成できれば、そのセットは「達成可能」です。 私たちの仕事は、元のすべてのセットの和集合と**等しくない**、達成可能な最大のセットを見つけることです。 出力は、そのようなセット内の要素の数である必要があります。 

各テスト ケースでは最大 50 のセットが得られ、各セットには 1 ～ 50 の範囲の整数が最大 50 個含まれます。制約が小さいため、セット要素に対するブルート フォース手法は実行可能ですが、セットの考えられるすべてのサブセットに対してブルート フォースを実行するのは限界です。$2^n$可能性、それは終わった$10^{15}$いつ$n = 50$。 したがって、すべてのサブセットを明示的にテストするのではなく、より賢明で建設的なアプローチが必要です。 

明らかではないエッジケースには、すべてのセットがシングルトンであるか、セットが 1 つしかない状況が含まれます。 たとえば、セットが 1 つしかない場合、$\{1,2,3\}$、完全結合に等しくない唯一の達成可能なセットは空のセットであり、出力は 0 になります。もう 1 つの微妙な点は、いずれかのセットを削除しても完全結合が得られるような方法でセットが重複している場合です。 その場合、最大の非完全結合は、1 つを除くすべてのセットの結合を取得することによって取得されます。 

## アプローチ

 ブルートフォースアプローチは、指定されたセットのすべてのサブセットを反復処理し、それらの和集合を計算し、すべてのセットの和集合に一致しない最大の和集合のサイズを追跡することです。 これは結合演算が結合的で単調であるため原理的には機能しますが、サブセットの数は指数関数的に増加します ($2^n$）、これは大きすぎます$n = 50$。 

より効率的な解決策を明らかにする重要な観察は、完全和集合ではない達成可能な最大の集合は、**1 つを除く**すべての集合の和集合をとることで常に取得できるということです。 他のセットに含まれていない要素を含むセットを削除すると、結果の結合ではそれらの要素が失われ、最大の非完全結合が得られます。 すべてのセットが残りのセットの和集合のサブセットである場合、任意のセットを削除しても完全な和集合が得られ、答えは和集合のサイズから 1 つの要素を引いた値、またはセットが 1 つしか存在しない場合は 0 になります。 

これにより、問題は各セットを反復処理し、他のすべてのセットの和集合を計算し、これらの和集合の最大サイズを取得することになります。 の代わりに$2^n$オペレーション、私たちはただ行うだけです$n$それぞれの結合は最大 50 個の要素にわたっています。 セットを 1 ～ 50 の数値のビットマスクとして表すと、結合演算とサイズの計算が簡素化されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * k) | O(k) | 遅すぎる |
 | 最適 (1 セットを除く) | O(n * k) | O(k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 テスト ケースごとに、次の内容を読んでください。$n$、セット数。 
2. 各セットを読み取り、Python として保存します。`set`または 50 ビット整数ビットマスクとして。 ビットマスクは、union が単一のビットごとの OR 演算になるため便利です。 
3. すべての結合を計算します$n$セット。 これに電話してください`full_union`。 
4. 変数を初期化する`best`これは、以下の値よりも小さい、達成可能なセットの最大サイズを追跡します。`full_union`。 
5. セットごとに$S_i$:

 - を除くすべてのセットの和集合を計算します。$S_i$。 ビットマスクを使用すると、次のようになります。`union_except_i = full_union & ~S_i`。 Python セットを使用すると、`union_except_i = full_union - S_i`要素のみの場合$S_i$または`union_except_i = set().union(*[S[j] for j != i])`。 
- 要素の数を数えます`union_except_i`そして更新します`best`もっと大きい場合。 
6. すべてのセットを確認したら、印刷します`best`テストケース用。 

機能する理由: 完全な結合と等しくない取得可能なセットは、結合から少なくとも 1 つの要素を省略する必要があります。 セット全体を 1 つ削除するだけで、考えられるすべての省略をカバーするには十分です。これは、含めるセットの数が少ないと、より大きな結合を作成できないためです。`full_union`。 したがって、各セットを反復して除外すると、達成可能な最大サイズが以下に見つかることが保証されます。`full_union`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        sets = []
        for _ in range(n):
            data = list(map(int, input().split()))
            sets.append(set(data[1:]))
        
        full_union = set()
        for s in sets:
            full_union |= s
        
        best = 0
        for i in range(n):
            union_except_i = full_union - sets[i]
            best = max(best, len(union_except_i))
        
        print(best)

solve()
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`各セットを Python セットとして保存します。 すべてのセットの結合を計算します。`|=`演算子を使用して反復し、各セットを順番に除外します。 セット減算を使用すると、現在のセットに固有の要素のみが削除されます。これはまさに、達成可能な最大の非完全結合を見つけるメカニズムです。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(t * n * k) | テストケースごとに、次のように計算します。`full_union`(O(n_k)) を繰り返し、各セット (O(n_k)) を除外します。 k ≤ 50 および n ≤ 50 であるため、テスト ケースごとの合計操作数 ≤ 2500。 |
 | スペース | O(n * k) | それぞれサイズ k のセットを最大 n セット保存します。 ビットマスク表現はスペースを削減しますが、これらの制約には必要ありません。 |

 これは、2 秒の時間制限と 256 MB のメモリ制限内に問題なく収まります。
