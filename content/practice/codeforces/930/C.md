 ## 解決策
 ## 問題の理解

 1 から m までの直線上の整数セグメントのコレクションが与えられます。 各セグメントは、エンドポイントを含む、その内部のすべての整数点にカバレッジを提供します。 すべての整数位置 x について、それをカバーするセグメントの数を計算できます。 この値を cnt(x) と呼びます。 

サーシャはいくつかの選択された位置 x について質問することができ、それぞれについて cnt(x) を受け取ります。 ただし、セグメントが合計で何個存在するかは知らされていません。 Teodor は、すべてのセグメントでカバーされる点はなく、セグメントの総数に等しい cnt(x) を持つ x は存在しないことを意味すると主張しています。 サーシャは当初この主張を信用しておらず、要点を尋ねて証拠を集めようとします。 

重要な点は、Sasha がセグメント セットを再構築する必要がないことです。 彼は、受け取った回答がテオドールが嘘をついているに違いないという結論を強制するのか、あるいは、ある点がすべてのセグメントでカバーされる、すべての回答と一致する別の有効なセグメント構成が存在する可能性がまだあるのかどうかを判断するだけで済みます。 

すべての cnt(x) 値を受け取った後でも、サーシャがテオドールが嘘をついていると確信できないような、サーシャがクエリできる個別のポイントの最大数を計算するように求められます。 

n、m が 100000 までの制約は、どの解もおおよそ O(m log m) または O(m) でなければならないことを意味します。 最悪の場合、m^2 は 10^10 の演算になるため、すべてのポイントのペアのチェックやクエリごとのカバレッジの再計算を伴うものは遅すぎます。 

単純な解釈では、観察された数と一致するさまざまなセグメント構成をシミュレートしようとしますが、cnt(x) 値だけではグローバル構造を一意に決定できないため、それはすぐに困難になります。 

デリケートなエッジ ケースの 1 つは、すべてのポイントが同じ範囲にある場合です。 たとえば、すべての cnt(x) が 1 に等しい場合、セグメントの総数は不明であるため、存在するセグメントの数に関係なく、すべての点を観察しても矛盾は生じません。 これはまさに最初のサンプルの状況であり、すべての位置が対称です。 

もう 1 つの重要なエッジ ケースは、厳密に最高のカバレッジを持つ単一のポジションがあり、他のすべてのポジションが小さい場合です。 このような構成では、その固有のピークがクエリから省略された場合に不一致を推定するために悪用できる情報となり、場合によっては答えが制限されることになります。 

## アプローチ

 ブルートフォースアプローチでは、クエリされたポイントのすべての可能なサブセットを検討し、サブセットごとに、観測された cnt 値がすべてのセグメントにポイントが存在しないという仮定と矛盾するかどうかを判断しようとします。 各サブセットについて、代替世界に完全な交点を許容しながら、すべての観測値と一致する仮想的な数のセグメントと配置が存在するかどうかを推論する必要があります。 考えられるクエリ セットは 2^m 個あり、単一のセットをチェックするだけでもセグメントの重複のグローバルな一貫性について推論する必要があるため、ポイントの数はすぐに指数関数的に増加します。 

重要な観察は、サーシャの知識が基本的に、クエリされたポイント間で観察される最大カバレッジ値に制限されていることです。 n がわからないため、値がセグメントの総数に等しいかどうかを直接確認することはできません。 重要な唯一の構造情報は、回線全体にわたって世界最大のカバレッジを達成する独自の位置があるかどうかです。

最大カバレッジ値が少なくとも 2 回出現する場合、最も多くカバーされているという点で一意に区別される単一のポイントはありません。 その場合、点のサブセットを削除または欠落しても、サーシャは矛盾を強制するような独自の有益な位置を分離することができません。 ただし、最大値がちょうど 1 つの位置で達成される場合、その点は特別になります。それは、回答と一致する別の説明における普遍交差におそらく対応できる唯一の候補です。 この非対称性により、安全なクエリの数が 1 つ減少します。 

これにより、問題全体が回線全体のカバレッジを計算し、最大値の多重度をチェックすることに集約されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース サブセット | O(2^m・m) | O(m) | 遅すぎる |
 | プレフィックス合計 + 最大頻度チェック | O(n + m) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ゼロに初期化されたサイズ m + 2 の配列 diff を構築します。 各セグメント [l, r] について、diff[l] をインクリメントし、diff[r + 1] をデクリメントします。 これは、カバーされたすべてのポイントを明示的にマークするのではなく、カバレッジの変更をエンコードします。 
2. 位置 1 ～ m にわたるプレフィックス合計を使用して、diff を実際のカバレッジ配列 cnt に変換します。 各位置 x での cnt(x) は、x までの差分値の累計です。 これにより、線形時間で各ポイントをカバーするセグメントの数が再構築されます。 
3. cnt アレイをスキャンして、最大カバレッジ値 mx を決定します。 
4. この最大値 mx に達する位置の数を数えます。 
5. このカウントが少なくとも 2 であれば、m を出力します。これは、矛盾を証明するのに十分な構造を与えることなく、すべての位置をクエリできることを意味します。 
6. 最大値が 1 回だけ発生する場合は、m − 1 を出力します。これは、一意に識別されるカバレッジ ピークが明らかになるのを避けるために 1 つの位置を効果的に除外する必要があるためです。 

### なぜ効果があるのか

 cnt アレイは、Sasha がクエリから受け取ったすべての情報を完全にキャプチャします。 そこから推測できる唯一のグローバル構造は、その最大値の形状です。 最大カバレッジが複数の位置で共有される場合、単一のクエリ ポイントは構造的に区別されないため、クエリのサブセットは一意に決定的な証人を分離できません。 最大値が 1 つだけ存在する場合、その点は、グローバルな実現可能性に影響を与えることなく、代替の一貫した構成で値を「置き換える」ことができない唯一の場所です。そのため、最大安全クエリ セットはその曖昧さを失わないようにする必要があります。 これにより、決定は完全に最大の多重度まで減少します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
diff = [0] * (m + 3)

for _ in range(n):
    l, r = map(int, input().split())
    diff[l] += 1
    diff[r + 1] -= 1

cnt = [0] * (m + 1)
cur = 0
mx = 0

for i in range(1, m + 1):
    cur += diff[i]
    cnt[i] = cur
    if cur > mx:
        mx = cur

freq = 0
for i in range(1, m + 1):
    if cnt[i] == mx:
        freq += 1

print(m if freq >= 2 else m - 1)
```この実装では、差分配列を使用して、各セグメント内のすべてのカバーされたポイントを明示的にマークすることを回避します。 直接マーキングは最悪の場合 O(nm) まで劣化するため、これは不可欠です。 

プレフィックスの蓄積により、単一パスで正確なカバレッジが再構築されます。 cnt の計算中、余分なスキャンを避けるために最大値が同時に追跡されますが、明確さと正確さのためにその頻度をカウントするために 2 番目のパスが引き続き使用されます。 

最終的な決定は、最大カバレッジ値が一意であるかどうかのみによって決まります。

The constraints allow up to 100000 segments and positions, so a linear scan solution is comfortably within limits.

 ## 特殊なケース

 範囲全体をカバーする単一セグメントなど、すべてのセグメントが同一の場合は、一定のカバレッジ配列が生成されます。 アルゴリズムは、すべての位置が同じ最大値に達することを発見することでこれを処理し、完全な答え m を導き出します。これは、一意に情報を提供する位置がないという事実と一致します。 

[1,1] のような単一の点セグメントの場合も、自明に共有される単一の最大値が生成され、やはり m が得られます。 部分クエリから構造を区別できないため、サーシャは決定的な情報を取得できません。 

1 つの位置が他の位置よりも多くカバーされる構成では、固有の最大値が得られます。 その状況では、アルゴリズムは、区別性の崩壊を避けるために 1 つの位置を除外する必要があることを反映して m − 1 を出力し、プレフィックス合計の構築により、cnt の 1 回のスキャンを通じてその固有のピークが正しく識別されます。
