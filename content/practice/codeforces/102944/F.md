 ## 解決策
 ## 問題の理解

 正の整数の小さなコレクションが与えられます。 このコレクションから、空ではない可能なすべてのサブセットを考慮し、そのサブセット内の数値の最大公約数を計算します。 この gcd がちょうど 1 に等しい場合、サブセットは「有効」であると見なされます。タスクは、そのような有効なサブセットがいくつ存在するかをカウントすることです。 

入力サイズは小さく、最大でも 100 個の数値ですが、各数値は 10^9 まで大きくなる可能性があります。 サイズ制約が重要な信号です。2^100 は大きすぎるため、すべてのサブセットを列挙することは原理的に可能ですが、100 は数値、特に約数から導出される値に対する圧縮または包含除外による指数関数法を可能にするのに十分小さいためです。 

素朴な解釈では、すべてのサブセットを反復処理して gcd を直接計算しようとします。 これはすでに核となる問題を示唆しています。サブセット空間は指数関数的ですが、gcd 操作には悪用できる構造があります。 

すべての数値が 1 より大きい共通因数を共有する場合、微妙なエッジ ケースが発生します。たとえば、すべての数値が偶数の場合、すべてのサブセットの gcd が少なくとも 2 であるため、答えは 0 でなければなりません。gcd の折りたたみ動作を適切に強制しないアプローチでは、実際には 1 に到達しないサブセットが誤ってカウントされます。 

もう 1 つの特殊なケースは、配列に 1 に等しい単一の要素が含まれている場合に発生します。唯一のサブセットは {1} であり、その gcd は 1 であるため、答えは 1 になります。これは、どのメソッドでも満たさなければならない最小限の健全性チェックです。 

## アプローチ

 ブルートフォースのアイデアは単純です。 配列の空でないすべてのサブセットを反復し、その要素を折りたたんで gcd を計算し、結果が 1 に等しい場合は答えをインクリメントします。これは、問題の定義に直接従うため、正しいです。 

ただし、サブセットの数は 2^N です。 N = 100 の場合、これは約 10^30 のサブセットとなり、計算限界をはるかに超えます。 たとえ gcd の計算が高速であっても、サブセットの数が膨大であるため、このアプローチは不可能です。 

重要な観察は、gcd 構造が部分集合ではなく除数とうまく相互作用するということです。 構築後に gcd 値によってサブセットをグループ化する代わりに、視点を逆にします。値 d を固定し、d で割り切れるすべての要素を持つサブセットがいくつあるかを数えます。 このようなサブセットの gcd は d で割り切れます。過剰カウントを注意深く考慮すると、gcd が d に正確に等しいサブセットの正確な数を回復できます。 これは、除数に対する標準的な包含/除外のアイデアですが、ここでは N が小さく、値が大きいため、特に明確になります。 

各整数 d について、d で割り切れる配列要素の数を数えることによって進めます。 k 個の要素が d で割り切れる場合、d の倍数のみで構成される空ではないサブセットが 2^k - 1 個存在します。 f(d) がこのカウントを表すものとします。 ただし、f(d) は、gcd が d の倍数であって、厳密に d に等しくないすべてのサブセットをカウントします。 次に、除数に対して降順ふるいを使用して d の倍数の寄与を減算し、gcd が正確に d であるサブセットの正確な数を生成します。 

最後に、d = 1 に対応する値を合計します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(N · 2^N) | お(1) | 遅すぎる |
 | 除数 DP + 包含-除外 | O(N √A + D log D) | O(D) | 承認済み |

 ここで、D は入力値に現れる個別の約数の数です。各数値の約数のみを生成するため、この数は小さくなります。 

## アルゴリズムのチュートリアル

 サブセットの列挙を完全に避け、代わりに除数クラスごとにカウントします。

1. 配列内の各数値について、その約数をすべて列挙します。 除数 d ごとに、周波数カウンタ cnt[d] を 1 ずつ増やします。このステップでは、除数から、その除数で割り切れる配列要素の数へのマッピングを構築します。 これが機能する理由は、要素がすべて d で割り切れるサブセットは、これらの cnt[d] 要素からのみ形成されるためです。 
2. cnt に現れるすべての約数 d について、それらの要素から形成される空でないサブセットの数を計算します。これは f(d) = 2^{cnt[d]} - 1 です。これは、要素がすべて d の倍数であるすべてのサブセットを表します。つまり、それらの gcd が少なくとも d であることを意味します。 
3. すべての約数を降順に並べ替えます。 倍数からの過剰カウントを削除したいと考えています。 サブセットの gcd が d の大きい倍数に正確に等しい場合、それは誤って f(d) に含まれているため、それらの寄与を差し引きます。 
4. 除数を降順に処理します。 最初に f(d) に設定された配列 g[d] を維持します。 各 d について、すべての倍数 m = 2d、3d、... を繰り返し、g[d] から g[m] を減算します。 これにより、処理後、g[d] が gcd が正確に d であるサブセットを表すことが保証されます。 
5. 最終的な答えは g[1] です。 

### なぜ効果があるのか

 空ではない各サブセットには一意の gcd 値があります。 任意の固定 d について、f(d) は、gcd が d の倍数であるすべてのサブセットをカウントします。 これらのサブセットは、すべて d の倍数である正確な gcd 値によって分割されます。 減算ステップは事実上、除数格子に対するメビウス反転であり、各サブセットがその真の gcd 値に 1 回だけ割り当てられることが保証されます。 除数の関係は半順序を形成するため、大きいものから小さいものへの処理により、減算時に、より大きな寄与がすべてすでに確定していることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def get_divisors(x):
    divs = []
    i = 1
    while i * i <= x:
        if x % i == 0:
            divs.append(i)
            if i * i != x:
                divs.append(x // i)
        i += 1
    return divs

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = (res * a) % MOD
        a = (a * a) % MOD
        e >>= 1
    return res

n = int(input())
a = list(map(int, input().split()))

cnt = {}
for x in a:
    for d in get_divisors(x):
        cnt[d] = cnt.get(d, 0) + 1

vals = sorted(cnt.keys(), reverse=True)

f = {}
g = {}

for d in vals:
    c = cnt[d]
    f[d] = (modpow(2, c) - 1) % MOD
    g[d] = f[d]

for d in vals:
    for m in vals:
        if m > d and m % d == 0:
            g[d] = (g[d] - g[m]) % MOD

print(g.get(1, 0) % MOD)
```解決策は、除数周波数を構築することから始まります。 各数値について、その約数を O(√aᵢ) で列挙します。これは、10^9 までの aᵢ に十分です。 これは、生の入力値に直接触れる唯一のステップです。 

次に、各除数の数について 2^k - 1 を計算します。 これは、その約数で割り切れる数値のみで構成されるすべてのサブセットを表します。 k は最大 100 になる可能性があるため、べき乗剰余演算が必要です。 

最後に、より大きな gcd 値の寄与を差し引くことで過剰カウントを修正します。 これらの制約の下では、実際にはすべての数値にわたる個別の約数の数が少ないままであるため、約数に対するネストされたループは許容されます。 

## 実用的な例

 ### 例 1

 入力:```
3
2 3 5
```すべての数値は素数であり、個別であるため、gcd 1 ではシングルトンのサブセットのみが問題になります。 

| ステップ | CNT | f(d) | g(d) |
 | --- | --- | --- | --- |
 | d=5 | 1 | 1 | 1 |
 | d=3 | 1 | 1 | 1 |
 | d=2 | 1 | 1 | 1 |
 | d=1 | 3 | 7 | 4 |

 最終的な値 g(1) = 4 は、gcd が 1 でないものを除くすべてのサブセットに対応します。有効なサブセットは、空のセットと gcd が 1 より大きいサブセットを除くすべてです。 

このトレースは、すべての数値が対で互いに素である場合でも、包含-排他によって gcd クラスがどのように分離されるかを示しています。 

### 例 2

 入力:```
3
2 4 8
```すべての数値は 2 の累乗であるため、サブセットが gcd 1 を持つことはできません。 

| ステップ | CNT | f(d) | g(d) |
 | --- | --- | --- | --- |
 | d=8 | 1 | 1 | 1 |
 | d=4 | 2 | 3 | 2 |
 | d=2 | 3 | 7 | 4 |
 | d=1 | 3 | 7 | 0 |

 ここでは、すべてのサブセットが 2 の累乗の gcd クラスの下でカウントされ、d = 1 ですべてがキャンセルされ、gcd 1 に達するサブセットがないことが確認されます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(N √A + D²) | 除数の列挙と除数の倍数の補正 |
 | スペース | O(D) | 除数カウントと DP テーブルのストレージ |

 N ≤ 100 という制約により、約数の列挙は簡単に保たれ、各数値が最大約 100 個の約数に寄与するため、D は管理可能なままになります。 これにより、ソリューションが制限内に快適に収まるようになります。

MOD = 10**9 + 7

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math

    def get_divisors(x):
        divs = []
        i = 1
        while i * i <= x:
            if x % i == 0:
                divs.append(i)
                if i * i != x:
                    divs.append(x // i)
            i += 1
        return divs

    def modpow(a, e):
        res = 1
        while e:
            if e & 1:
                res = (res * a) % MOD
            a = (a * a) % MOD
            e >>= 1
        return res

    n = int(input())
    a = list(map(int, input().split()))

    cnt = {}
    for x in a:
        for d in get_divisors(x):
            cnt[d] = cnt.get(d, 0) + 1

    vals = sorted(cnt.keys(), reverse=True)

    f = {}
    g = {}

    for d in vals:
        f[d] = (modpow(2, cnt[d]) - 1) % MOD
        g[d] = f[d]

                g[d] = (g[d] - g[m]) % MOD

# single element 1

# all same even number

## 特殊なケース

 すべての値が 1 より大きい公約数を共有する場合、すべてのサブセットの gcd は少なくともその約数になります。 入力用`2 2 2`、除数カウントは f(2)=7 および f(1)=7 を生成しますが、減算により d=1 での寄与がすべて除去され、有効なサブセットはゼロのままになります。 このアルゴリズムは、1 に到達する前に、すべてをより高い gcd クラスに正しく折りたたみます。 

配列に 1 に等しい要素が 1 つ含まれている場合、cnt[1]=1 および f(1)=1 となります。 それより減算できるより大きな約数は存在しないため、直接 g(1)=1 となります。 除数の列挙には自然にすべての数値に 1 が含まれるため、アルゴリズムは特別なケースを使用せずにこれを処理します。
