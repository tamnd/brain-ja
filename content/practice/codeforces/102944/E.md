 ## 解決策
 ## 問題の理解

 最大 100 x 100 のサイズの長方形グリッドが与えられます。各セルは座席を表しており、すでに緑、青、または中立のままで塗られています。 緑と青は固定ですが、中立席は緑と青を自由に割り当てることができます。 

すべての中立席が割り当てられると、グリッドは 2 値の色になります。 2 つのセルが 1 つの辺を共有し、最終的な色が同じである場合、2 つのセルは同じ領域に属します。 タスクは、緑のセルによって形成される連結成分と青のセルによって形成される連結成分の合計数ができるだけ少なくなるように、すべてのニュートラル セルの色を選択することです。 

個々のカウントよりも、グリッドの構造の方が重要です。 特に、すでに色付けされている複数の領域の間にニュートラル セルが位置する場合、1 回の色変更の決定でコンポーネントが結合または分割される可能性があります。 

中立セルの数が最大 10 個であるという制約が、重要な構造上の制限です。 これがなければ、問題はグリッドのラベル付けに対するハードな最適化に似たものになるでしょう。 これにより、それらの少数のセルだけが不確実性をもたらすため、検索空間は管理可能な構成セットに崩壊します。 

素朴だが重要なエッジケースは、中立セルがブリッジとして機能するときに現れます。 

次の行を考えてみましょう。```
0 ? 0
```中央のセルを 0 に設定すると、両方の緑が 1 つのコンポーネントになります。 1 に設定すると、緑は分離されたままになります。 これは、各ニュートラル セルが接続に全体的な影響を与える可能性があることを示しています。 

複数の中立セルが相互作用する場合、より微妙な問題が発生します。 1 つの割り当てを変更すると、別のニュートラル セルが同じ色の領域を接続するか分離するかが変わる可能性があるため、独立して決定を行うことはできません。 

この制約は、ヒューリスティックなローカル選択はグローバルに失敗する可能性があるため、ソリューションは最大 10 個の不確実なセルのすべての構成を明示的に検討する必要があることを意味します。 

## アプローチ

 ニュートラル セルの制約を無視すると、問題はすべての 2D カラーリングにわたるグローバルな最適化となり、各セルの割り当てが非線形的に接続性に影響を与えます。 強引なアイデアは、各ニュートラル セルを緑または青に割り当て、フラッド フィルを使用して結果のグリッド内の接続コンポーネントの数を再計算することです。 

この総当り的な方法は、入力と一致する可能性のあるすべての最終状態を評価するため、正しいです。 問題は規模だ。 k 個の中立セルがある場合、構成の数は 2^k になります。 一般的な設定では、k は最大 10,000 になる可能性がありますが、これは不可能です。 

重要な観察は、k の境界が 10 であるということです。これによりすべてが変わります。 グリッド全体について推論する代わりに、これらの少数の不確実な位置に対する割り当てのみを列挙します。 すべての割り当てによってグリッドが完全に決定され、その後接続性が O(NM) で直接計算されます。 

したがって、問題は最大 1024 のサイズの状態空間を探索し、グリッド トラバーサルで各状態を独立して評価することに帰着します。 

ソリューションの構造は 2 レベルのプロセスになります。 外側のレベルには、ニュートラル セルのすべての色の割り当てが列挙されます。 内部レベルは、結果として得られるグリッド内の接続コンポーネントの数を計算します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべての割り当て + BFS) | O(2^k・N・M) | O(N・M) | 承認済み |
 | 最適 (k ≤ 10 の場合も同じ考え) | O(2^k・N・M) | O(N・M) | 承認済み |

 違いは、「最適な」ソリューションは、制約によって強引な攻撃が実行可能になることを単に認識していることです。 

## アルゴリズムのチュートリアル

 ニュートラル セルをインデックス付き変数として扱い、それらに対して可能なすべてのバイナリ割り当てを列挙します。 

1. まず、ニュートラルとしてマークされたすべてのセルの座標を収集します。 この問題における自由度はこれらのみです。 このステップでは、問題をグリッド決定問題から最大 10 個の変数にわたるビットマスク列挙問題に削減します。 
2. 0 から 2^k − 1 までのすべての整数を繰り返します。ここで、k はニュートラル セルの数です。 各整数は色の一意の割り当てを表し、ビット i によりニュートラル セル i が緑になるか青になるかが決まります。 
3. 各割り当てについて、元のグリッドをコピーし、現在のビットマスクに従ってニュートラル セルを置き換えることにより、最終的なグリッドを構築します。 このステップにより、接続性を曖昧さなく評価できるように完全な色付けが実現されます。 
4. グリッド上で標準のフラッド フィルまたは BFS を実行して、接続されているコンポーネントを緑と青で個別にカウントします。 未訪問のセルに遭遇するたびに、そのコンポーネント全体をマークする走査を開始します。 
5. この割り当てのコンポーネントの合計数を、緑と青のコンポーネントの合計として計算します。 すべての割り当ての最小値を追跡します。 
6. 見つかった最良の値を出力します。 

正確さは、各割り当てが独立しており、グリッド構造を完全に決定するため、それらを個別に評価しても相互作用効果が失われないという事実にかかっています。 

### なぜ効果があるのか

すべての有効な最終構成は、ニュートラル セル上の 1 つのビットマスクに正確に対応します。 アルゴリズムはそのようなビットマスクをすべて列挙するため、実行可能な解決策が見逃されることはありません。 構成ごとに、コンポーネント数が正確に計算されます。 接続性は完全に構築されたグリッド上で評価されるため、近似や部分的な推論は含まれません。 したがって、すべての構成にわたる最小値は全体的な最適値と一致します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from collections import deque

def count_components(grid, n, m):
    vis = [[False] * m for _ in range(n)]
    
    def bfs(i, j):
        q = deque()
        q.append((i, j))
        vis[i][j] = True
        color = grid[i][j]
        while q:
            x, y = q.popleft()
            for dx, dy in ((1,0), (-1,0), (0,1), (0,-1)):
                nx, ny = x + dx, y + dy
                if 0 <= nx < n and 0 <= ny < m:
                    if not vis[nx][ny] and grid[nx][ny] == color:
                        vis[nx][ny] = True
                        q.append((nx, ny))
    
    comps = 0
    for i in range(n):
        for j in range(m):
            if not vis[i][j]:
                bfs(i, j)
                comps += 1
    return comps

def solve():
    n, m = map(int, input().split())
    g = [list(input().strip()) for _ in range(n)]
    
    qs = []
    for i in range(n):
        for j in range(m):
            if g[i][j] == '?':
                qs.append((i, j))
    
    k = len(qs)
    ans = float('inf')
    
    for mask in range(1 << k):
        for idx, (i, j) in enumerate(qs):
            g[i][j] = '0' if (mask >> idx) & 1 == 0 else '1'
        
        ans = min(ans, count_components(g, n, m))
    
    print(ans)

if __name__ == "__main__":
    solve()
```解決策は、不確実な位置をすべて抽出することから始まります。 これらは、マスク内の各ビットが 1 つのセルに一貫して対応するように格納されます。 反復中に、効率を高めるためにグリッドがその場で一時的に変更され、繰り返しの割り当てが回避されます。 

BFS 機能は、標準的な 4 方向の塗りつぶしです。 未訪問のセルに遭遇するたびに、同じ色の接続領域全体を探索し、各コンポーネントが正確に 1 回カウントされるようにします。 

実装の微妙な詳細は、マスクごとにグリッドが繰り返し上書きされることです。 オリジナルの「?」以来 いずれにしても値は常に上書きされ、反復ごとにすべての「?」が再割り当てされます。 セルの場合、反復の間にグリッドを復元する必要はありません。 

## 実用的な例

 単純な 2 × 3 グリッドを考えてみましょう。```
? 0 ?
0 ? 1
```中立セルは 3 つあるため、8 つの割り当てを列挙します。 

| マスク | グリッドの解釈 | グリーンコンプ | ブルーコンプ | 合計 |
 | --- | --- | --- | --- | --- |
 | 000 | 全て ？ = 0 | 1 | 1 | 2 |
 | 001 | 最後 ？ = 1 | 2 | 1 | 3 |
 | 010 | 真ん中 ？ = 1 | 2 | 2 | 4 |
 | ... | ... | ... | ... | ... |

 既存の同じ色の領域を断片化するのではなく接続するためにニュートラル セルが選択された場合、最適な構成が表示されます。 

次に、単一行の場合を考えてみましょう。```
0 ? 0 1
```| マスク | 割り当て | コンポーネント |
 | --- | --- | --- |
 | 0 | 0 0 0 1 | 緑=1、青=1 合計=2 |
 | 1 | 0 1 0 1 | 緑=2、青=1 合計=3 |

 これは、ニュートラル セルを別の色に変えると、断片化が大幅に増加する可能性があることを示しています。 

トレースは、各ニュートラル セルが、隣接する同じ色の領域が結合するか分離したままになるかに直接影響を与えることを示しており、完全な列挙が正当化されます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(2^k・N・M) | 最大 1024 の割り当てごとに、フル グリッド BFS/DFS トラバーサルがトリガーされます。 
| スペース | O(N・M) | アレイおよびグリッド ストレージを訪問 |

 N、M が最大 100、k が最大 10 の場合、最悪の場合の操作数は約 1024 × 10000 であり、これは単純な BFS ロジックを使用した Python での 1 秒の実行の制限内に十分収まります。

## 特殊なケース

 重要なエッジ ケースは、ニュートラル セルが 2 つの同一領域の間に位置し、割り当てに応じてそれらを結合または分離できる場合です。 

入力：```
1 3
0?0
```中央のセルに 0 が割り当てられている場合、行全体が 1 つのコンポーネントになります。 1 を割り当てた場合、青で区切られた 2 つの緑のコンポーネントが存在します。 アルゴリズムは両方のマスクを評価し、グリッドを明示的に構築します。BFS はこれらの結果を正しく区別して、最小値が選択されるようにします。 

別のケースには、交互構造が含まれます。```
0?1
?0?
1?0
```ここでは、すべてのニュートラル セルが複数の潜在的なマージに参加します。 このアルゴリズムはすべての 2^k 構成を列挙し、BFS は毎回接続を最初から再計算し、ニュートラル セル間の相互依存関係が近似ではなく完全に考慮されることを保証します。
