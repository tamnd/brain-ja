 ## 解決策
 ## 問題の理解

 この問題は 2 つの電球を比較します。 普通の電球は安価に購入できますが、消費電力が高くなります。 省エネ電球は最初は高価ですが、時間ごとに消費するワット数は少なくなります。 省エネ電球に費やされる合計金額が通常の電球に費やされる合計金額を超えなくなるまでの最初の整数時間を見つける必要があります。 

入力では、通常の電球の購入価格、1 時間あたりの電力消費量、省エネ電球の購入価格、1 時間あたりの電力消費量、コペック単位のワット時あたりの電気料金の 5 つの値が別々の行に表示されます。 出力は、省エネ電球が高い初期コストを支払ったときの最小の整数時間数です。 

到達できる値は、$10^9$したがって、答えは 32 ビット整数よりもはるかに大きくなる可能性があります。 必要な時間数は前後する可能性があるため、時間の直接シミュレーションは不可能です。$10^{11}$またはそれ以上。 1 時間ごとにチェックするのではなく、算術演算を使用して一定の時間を計算する必要があります。 

エッジケースのほとんどは、電気料金ゼロと正確な分割に関連しています。 電気が無料であれば、より高価な電球は決して追いつきません。 例えば：```
10
100
20
50
0
```正しい出力は次のとおりです`-1`、両方の電球が元の購入価格を永久に維持するためです。 ゼロをチェックせずに、節約されたエネルギーコストで割るソリューションは失敗します。 

もう 1 つのケースは、整数時間で正確に節約が十分になる場合です。```
20
90
120
20
5
```購入価格の差は10000コペックです。 1 時間ごとに 350 コペックが節約されるため、最初の有効な時間は 29 になります。切り上げを行わずに整数の除算を使用した解では、誤って 28 が生成されます。 

3 番目のケースは、最初の 1 時間ですでに十分な場合です。```
0
100
1
0
1
```出力は`1`。 省エネ電球は最初は 1 コペック高くなりますが、1 時間あたり 100 コペック節約できるため、最初の 1 時間後には良くなります。 電球がまだ使用されていないため、誤ってゼロ時間を許可する実装は間違っています。 

## アプローチ

 簡単なアプローチは、経過時間をシミュレーションすることです。 1 時間ごとに両方の電球の合計コストを計算し、省エネ電球の価格が低くなった時点で停止します。 このアプローチはステートメントの条件を正確にチェックするため、正しいことを証明するのが簡単です。 ただし、膨大な回数の反復が必要になる場合があります。 近い価格で$10^9$、所要時間は前後する可能性があります$10^{11}$数時間かかるため、シミュレーションは不可能になります。 

重要な観察は、どちらのコストも時間の経過とともに直線的に増加するということです。 購入価格は固定されており、1時間ごとに電気料金が追加されるだけです。 2 つの増加する値を繰り返し比較する代わりに、その差を比較できます。 

省エネ電球は次のように遅れて起動します。$b-a$ルーブル。 1時間ごとに次のような利点が得られます$(x-y)p$消費ワットが少ないため、コペックです。 最初の差をコペイカに変換すると、単純な不等式が得られます。$$100(b-a) \leq h(x-y)p$$答えは最小の整数です$h$それを満足させます。 これは単なる天井分割です。

 ## アルゴリズムのチュートリアル

 1. 5 つの入力値を読み取り、完全にコペイカ単位で処理します。 電力の計算にはすでにコペックが使用されているため、電球の価格を変換することで浮動小数点エラーが防止されます。 
2. 省エネ電球の初期欠点を次のように計算します。`100 * (b - a)`。 これは、利益を得る前に節約しなければならない金額です。 
3. 1 時間ごとに得られる節約量を次のように計算します。`(x - y) * p`。 通常の電球はより多くのエネルギーを消費するため、この値は負ではありません。 
4. 1 時間当たりの節約量がゼロの場合、省エネ電球はその高い価格を取り戻すことはできません。 出力`-1`。 
5. それ以外の場合は、上限除算を使用して最小の整数時間カウントを計算します。$$\left\lceil \frac{\text{initial disadvantage}}{\text{hourly saving}} \right\rceil$$整数形式は`(need + save - 1) // save`。 

機能する理由: 2 つの電球のコストの差は、1 時間ごとにまったく同じ量だけ減少します。 最初は省エネ電球が一定量遅れています。 1 時間ごとに、その差の固定部分が削除されます。 蓄積された節約が最初の不利な点に達する最初の瞬間は、まさに省エネ電球がそれ以上高価でなくなる瞬間です。 天井除算は、これが発生する最初の整数時間を見つけます。 

## Python ソリューション```python
import sys

input = sys.stdin.readline

def solve():
    a = int(input())
    x = int(input())
    b = int(input())
    y = int(input())
    p = int(input())

    need = 100 * (b - a)
    save = (x - y) * p

    if save == 0:
        print(-1)
    else:
        print((need + save - 1) // save)

if __name__ == "__main__":
    solve()
```プログラムはまず、購入価格の差をルーブルからコペイカに変換します。 これにより、精度の低下が回避され、すべての計算が整数として維持されます。 

変数`save`省エネ電球が 1 時間後にどれだけ安くなるかを保存します。 一般電球の方が消費電力が高いため、この値が当初の価格差の回収に向けた進捗となります。 

ゼロチェックが必要なのは、ゼロによる天井除算が無効になるためであり、論理的には、電気自体に価格がない場合、電気料金が安いことが何の利点も生み出すことはありません。 

最後の式では、標準の整数上限除算式が使用されます。 追加`save - 1`before Division は、正確な除算を変更せずに、不正確な結果を上に移動します。
