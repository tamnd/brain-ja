## アプローチ

 直接的な解決策は、すべての整数を検査することです`x`から`1`を通して`r`かどうかをテストします`gcd(x, n) = 1`。 必要なセットの定義がまさにその gcd 条件であるため、これは正しいです。 ただし、`r = 10^9`、アルゴリズムは実行する可能性があります`10^9`gcd の計算。 Euclid のアルゴリズム自体は高速ですが、10 億回の反復は予定された時間予算をはるかに超えています。 

有益な観察は、`x`と互いに素である`n`の異なる素因数にのみ依存します`n`。 それらの素数が`p1, p2, ..., pk`。 整数は互いに素にならない`n`正確に、これらの素数の少なくとも 1 つで割り切れるときです。 

包含排他を使用して、少なくとも 1 つの禁止された素数で割り切れる整数を数えることができます。 異なる素因数の空でないサブセットごとに、次のようにします。`d`はそのサブセット内の素数の積になります。 サブセット内のすべての素数で割り切れる数は、正確に次の倍数です。`d`、あります。`r // d`彼らの中の`1`を通して`r`。 

奇数の素数を含むサブセットの場合、これらの倍数が加算されます。 偶数の素数を含むサブセットの場合、それらは減算されます。 もし`bad`は結果のカウントです。望ましい答えは次のとおりです。`r - bad`。 

残っている唯一のタスクは、次の異なる素因数を見つけることです。`n`。 試し割りは平方根までで十分です。`n <= 10^9`。 素因数のすべての出現を抽出した後、その素因数を 1 回だけ保持します。これは、包含と除外には別個の可算条件が必要であるためです。

## アルゴリズムのチュートリアル

 1.因数分解`n`約数を試すことで`2`を通して`sqrt(n)`。 約数のときはいつでも`p`現在の値を除算します`n`、 記録`p`何度も分割してください。 共素性にとって重要なのは素数の存在のみであるため、すべてのコピーを削除することが必要です。 
2. 試しに分割した後、残りの値が より大きい場合`1`、それを別の素因数として記録します。 残りの値が大きい`1`これより小さい未処理の因数を持つことはできないため、それ自体が素数でなければなりません。 
3. 異なる素因数のすべてのサブセットを列挙します。 サブセットの場合は、選択した素数を乗算して次の値を取得します。`d`。 選択したすべての素数で割り切れる整数は、正確に次の倍数になります。`d`、与える`r // d`このような整数。 
4.追加`r // d`サブセットに奇数の素数が含まれる場合は減算し、サブセットに偶数の素数が含まれる場合は減算します。 これは、可分性条件間の重複に対する包含/除外補正です。 
5. から非素数の整数を減算します。`r`。 残りの数は、正確に次の整数の数です。`[1, r]`誰の gcd と`n`等しい`1`。 

### なぜ効果があるのか

 しましょう`P`～の異なる素因数の集合であること`n`。 整数`x`と互いに素ではない`n`少なくとも 1 つの素数が含まれるとき、正確に`P`分割する`x`。 したがって、不要な整数は集合の和集合を形成します。`A_p = {x : p divides x}`のために`p`で`P`。 

これらの素数のサブセットと積について`d`、その交差部分には正確に の倍数が含まれます。`d`、そして、あります`r // d`までの整数`r`。 包含-除外では、サブセット サイズに応じて加算と減算を交互に行うことにより、結合を正確にカウントします。 その結果、`bad`は正確には、自明ではない約数を共有する整数の数です`n`、 そして`r - bad`互いに素な整数を正確に数えます。 

因数分解ステージでは、すべての素数が提供されます。`P`正確に 1 回だけ行われるため、包含/除外ステージは考えられるすべての共通の素約数を表し、無関係な条件は含まれません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, r = map(int, input().split())

    x = n
    primes = []

    p = 2
    while p * p <= x:
        if x % p == 0:
            primes.append(p)
            while x % p == 0:
                x //= p
        p += 1 if p == 2 else 2

    if x > 1:
        primes.append(x)

    k = len(primes)
    bad = 0

    for mask in range(1, 1 << k):
        product = 1
        bits = 0

        for i in range(k):
            if mask & (1 << i):
                product *= primes[i]
                bits += 1

        count = r // product

        if bits % 2 == 1:
            bad += count
        else:
            bad -= count

    print(r - bad)

if __name__ == "__main__":
    solve()
```コードは最初にコピーされます`n`の中へ`x`, なぜなら、試行除算は繰り返し因数分解される数を減らすからです。 リスト`primes`それぞれの異なる素因数が 1 回だけ含まれます。 

ループは次から始まります`p = 2`、その後、奇数の値のみをチェックします`2`。 これにより、素数にできない約数のテストも回避されます。 条件`p * p <= x`安全なので、`x`は複合因数分解を持ち、その因数の 1 つは最大でも平方根です。 ループが終了すると、残りの`x > 1`プライムでなければなりません。 

サブセット ループではビットマスクが使用されます。 少し`i`かどうかを決定します`primes[i]`現在のサブセットに属します。`product`は選択された素数の積になりますが、`bits`サブセットのサイズを記録し、包含/除外の符号を決定します。 

計算には整数除算が使用されます`r // product`、 ない`(r - 1) // product`、 なぜなら`r`それ自体は区間に属します。 Python の整数ではオーバーフローの懸念も解消されますが、ここでのすべての中間積は通常の 64 ビット整数に対しても十分小さいものです。 

のために`n = 1`、因子リストは空のままです。 サブセット ループには反復がないため、`bad = 0`そして答えは次のようになります`r`、まさにその通りです。

import io

def solve_data(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        n, r = map(int, sys.stdin.readline().split())

        x = n
        primes = []

        p = 2
        while p * p <= x:
            if x % p == 0:
                primes.append(p)
                while x % p == 0:
                    x //= p
            p += 1 if p == 2 else 2

        if x > 1:
            primes.append(x)

        k = len(primes)
        bad = 0

        for mask in range(1, 1 << k):
            product = 1
            bits = 0

                if mask & (1 << i):
                    product *= primes[i]
                    bits += 1

            count = r // product

            if bits & 1:
                bad += count
            else:
                bad -= count

        print(r - bad)

        return sys.stdout.getvalue().strip()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

 ## 特殊なケース

 のために`n = 1, r = 5`因数分解では空のリストが生成されます。`1`には素因数がありません。 包含/除外サブセットはないため、`bad`ゼロのままです。 最終的な計算は`5 - 0 = 5`、からのすべての数字を正しく数えます`1`に`5`。
