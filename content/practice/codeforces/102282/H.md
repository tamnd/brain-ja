 ## 解決策
 ## 問題の理解

 デカルト平面上に 2 つの円があります。 各円は、その中心の整数座標と正の整数の半径によって記述されます。 タスクは、両方の円に属する点の数を決定し、それらの点を十分な数値精度で出力することです。 2 つの異なる円には、0、1、または 2 つの共通点があります。 2 つの円が実際に同じ円である場合、円上のすべての点は共通であるため、必要な答えは次のようになります。`MANY`。 

座標と半径の境界は (10^3)​​ のみなので、入力自体は小さいです。 さらに重要なのは、幾何学的オブジェクトは 2 つだけであり、答えには最大でも 2 つの有限点が含まれるということです。 したがって、ソリューションでは、平面上で反復したり、数値的に交点を検索したりするのではなく、一定数の算術演算を使用する必要があります。 単純な (O(1)) 幾何学的導出であっても、1 秒の制限内に余裕で収まり、メモリの使用量は無視できます。 距離の 2 乗などの整数は最大でも (10^7) 程度であるため、Python の整数演算ではオーバーフローの心配はまったくありません。 

実装が交差式に直接ジャンプすると、いくつかのケースは誤って処理されやすくなります。 円の中心と半径が同じであれば、共通点は無数に存在します。 例えば、```
0 0 1
0 0 1
```生産しなければならない```
MANY
```中心間の距離で割ることに基づく式では、ここではゼロで割ることになります。 

中心が一致しても半径が異なる場合、円には共通点がありません。 例えば、```
0 0 1
0 0 2
```出力があります```
0
```中心が一致するかどうかのみをチェックする不注意な実装では、これを無限に多くの交差点として誤って分類する可能性があります。 

2 つの外接円には、正確に 1 つの交点があります。 例えば、```
0 0 1
2 0 1
```1点を生み出さなければなりません、`(1, 0)`。 2 つの異なるルートを期待する浮動小数点比較では、誤って同じ接点が 2 回出力される可能性があります。 

内部接線には、別の構成でも同じ問題があります。 のために```
0 0 3
1 0 2
```小さい円は大きい円と接触します。`(3, 0)`, ということで、答えはまた1点です。 

最後に、2 つの円は、完全に切り離されたままで、一方の中心を他方の円の内側に持つことができます。 例えば、```
0 0 5
1 0 1
```中心間の距離が半径の差より小さいため、交差はありません。 中心距離が半径の合計より小さいかどうかだけをチェックすると、これが誤って交差ケースとして扱われてしまいます。 

## アプローチ

 直接的な総当たりアプローチでは、両方の円を含む領域をスキャンし、候補点が両方の円の方程式を満たすかどうかをテストすることによって、共通点を検索しようとします。 交差座標は任意の実数であるため、グリッドベースの実装では、何らかの数値解像度を選択する必要があります。 (10^{-6}) 以内の座標を保証するには、(10^{-6}) の周囲に間隔を持つグリッドが必要です。 座標範囲は各方向に約 2000 単位に及ぶ可能性があり、各軸に沿った位置は約 (2\cdot10^9)、最悪の場合はグリッド ポイントは約 (4\cdot10^{18}) になります。 単一の点を一定時間でチェックすることさえ、このアプローチは完全に実行不可能になり、グリッド解像度を下げると、必要な精度が保証されなくなります。 

真の交点はまさに両方の円方程式を満たす点であるため、強引なアイデアは概念的には機能しますが、平面が連続的であり、必要な精度により網羅的なサンプリングが膨大になるため、失敗します。 有益な観察は、2 つの円方程式を代数的に組み合わせることができるということです。 それらを減算すると、二次項 (x^2+y^2) が削除され、直線が残ります。 すべての交点は根軸と呼ばれるこの線上になければなりません。 次に、最初の円をその線と交差させると、最大 2 つの点が直接得られます。 

座標を計算するさらにクリーンな方法があります。 中心を(C_1)と(C_2)とし、それらの間の距離を(d)とします。 2 つの中心を通る線には、共通の弦の中点が含まれます。 (C_1) からそのコードまでの距離が (a) である場合、ピタゴラスの定理は次のようになります。 

[
 a=\frac{r_1^2-r_2^2+d^2}{2d}。 
】

 共通の弦は中心を結ぶ線に対して垂直です。 (h) が弦の半分の長さである場合、

 [
 h^2=r_1^2-a^2。 
】

 (C_1) から弦への垂線の足は、(C_1) から (C_2) に向かって距離 (a) だけ移動することによって得られます。 次に、垂直単位ベクトルを使用して両方向に (h) だけ移動して、可能な 2 つの交点を取得します。 

これらの式を使用する前に、二乗距離を使用して構成を分類します。 これにより、不必要な平方根が回避され、入力値が整数であるため、すべての幾何学的比較が正確になります。

 | 最適 | (O(1)) | (O(1)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つの円の中心と半径を読み取ります。 コンピューティング`dx = x2 - x1`、`dy = y2 - y1`、および中心距離の二乗`d2 = dx*dx + dy*dy`。 保管`d2`すぐに平方根を取る代わりに、正確な整数比較を使用して、すべての縮退構成と非交差構成を分類できます。 
2. もし`d2 == 0`半径が等しい場合、円は一致します。 1 つの円のすべての点は他の円に属しているため、次のように出力します。`MANY`そしてやめてください。 
3. もし`d2 == 0`半径は異なりますが、円は同心円状ですが区別できます。 彼らは会うことができないので、印刷してください`0`そしてやめてください。 
4. 正方形を使用して中心距離を半径の合計および差と比較します。 (d > r_1+r_2) の場合、円は外側に分離されます。 (d < |r_1-r_2|) の場合、一方の円は厳密に他方の円の内側にあります。 どちらの状況でも交点はゼロになります。 
5. コンピューティング

 [
 d=\sqrt{d^2}
 】

 そして計算します

 [
 a=\frac{r_1^2-r_2^2+d^2}{2d}。 
】

 これは、中心を結ぶ線に沿った、最初の中心から共通弦までの距離です。 式は、2 つの交点に対する 2 つの直角三角形の関係を記述し、それらを減算することによって続きます。 

1. コンピューティング

 [
 h^2=r_1^2-a^2。 
】

 2 つの交差する円の場合、この値は負ではありません。 なぜなら`a`は浮動小数点演算で計算されるため、接線構成は次のような小さな負の値を生成する可能性があります。`-1e-12`正確なゼロの代わりに。 平方根を求める前に、そのような値をゼロにクランプします。 

1. 最初の中心から共通弦までの垂線の足を見つけます。 

[
 p_x=x_1+a\frac{dx}{d},\qquad
 p_y=y_1+a\frac{dy}{d}。 
】

 次に、中心線に垂直な単位ベクトルを構築します。 

[
 \left(-\frac{dy}{d},\frac{dx}{d}\right)。 
】

 このベクトルに (h) を乗算すると、弦の中点からいずれかの交点までの変位が得られます。 

1. (h=0) の場合、円は接しているため、可能な 2 つの点は一致します。 ワンポイントでプリントします。 それ以外の場合は両方を印刷します

 [
 (p_x-h\frac{dy}{d},\ p_y+h\frac{dx}{d})
 】

 そして

 [
 (p_x+h\frac{dy}{d},\ p_y-h\frac{dx}{d})。 
】

 順序は関係ありません。 

構築の背後にある不変条件は、生成されたすべての点が直角三角形の関係 (a^2+h^2=r_1^2) により最初の円上に位置し、選択された弦の位置が対応する半径方程式を満たすため、2 番目の円上にも位置するということです。 逆に、すべての共通点は共通の弦上に存在する必要があり、その位置は 2 つの円方程式によって一意に決定されます。 垂直構築では、最初の円上にある弦上のすべての点が検索されるため、すべての交差が正確に生成されます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    x1, y1, r1 = map(int, input().split())
    x2, y2, r2 = map(int, input().split())

    dx = x2 - x1
    dy = y2 - y1
    d2 = dx * dx + dy * dy

    # Coincident centers.
    if d2 == 0:
        if r1 == r2:
            print("MANY")
        else:
            print(0)
        return

    # Disjoint or one circle strictly inside the other.
    sum_r = r1 + r2
    diff_r = abs(r1 - r2)

    if d2 > sum_r * sum_r or d2 < diff_r * diff_r:
        print(0)
        return

    d = math.sqrt(d2)

    # Distance from the first center to the common chord.
    a = (r1 * r1 - r2 * r2 + d2) / (2.0 * d)

    # Half of the common chord length, squared.
    h2 = r1 * r1 - a * a

    # Floating-point roundoff can make a tangent case slightly negative.
    if h2 < 0.0:
        h2 = 0.0

    h = math.sqrt(h2)

    # Midpoint of the common chord.
    px = x1 + a * dx / d
    py = y1 + a * dy / d

    # Unit vector perpendicular to the line between centers.
    ux = -dy / d
    uy = dx / d

    # First intersection point.
    x_a = px + h * ux
    y_a = py + h * uy

    # Tangency: both mathematical constructions give the same point.
    if h == 0.0:
        print(1)
        print(f"{x_a:.10f} {y_a:.10f}")
        return

    # Two distinct intersection points.
    x_b = px - h * ux
    y_b = py - h * uy

    print(2)
    print(f"{x_a:.10f} {y_a:.10f}")
    print(f"{x_b:.10f} {y_b:.10f}")

if __name__ == "__main__":
    solve()
```最初の部分では、中心間のベクトルとその二乗長を計算します。 特別な場合`d2 == 0`の式は一般式の前に処理する必要があります。`a`中心距離で割ります。 

次の 2 つの比較では、整数の 2 乗を使用します。 条件`d2 > (r1 + r2)^2`円が半径の合計よりも離れていることを意味します。 条件`d2 < (r1 - r2)^2`これは、中心距離が絶対半径の差よりも小さいことを意味するため、一方の円が他方の円の内側に厳密に存在します。 どちらの比較における等価性も意図的に拒否されません。これは、等価性は接線を意味し、有効な交点が 1 つ得られるためです。 

構成に 1 つまたは 2 つの交差があることがわかった後、コードは次の計算を行います。`d`、 に続く`a`そして`h2`。 の表現`a`中心となる幾何学式です。 値`h2`共通の弦の長さが正であるか、単一の接点に折りたたまれているかを決定します。 

の`if h2 < 0.0`補正は浮動小数点の丸めのみを処理します。 本当に交差しない構成は、正確な整数比較を使用してすでに拒否されているため、ここでの小さな負の値は、接線付近の算術誤差からのみ発生する可能性があります。 

共通の弦の中点は、中心から中心の方向に沿って計算されます。 ベクトル`(-dy / d, dx / d)`はその方向に垂直で、長さは 1 なので、これを乗算します。`h`弦の中点からいずれかの交点までのオフセットを正確に示します。 

Python では整数オーバーフローの問題はありません。 固定幅の整数型を使用する言語では、指定された境界は符号付き 64 ビット整数を問題なく処理できるほど十分に小さいにもかかわらず、二乗式を使用可能な整数の範囲に対してチェックする必要があります。

## テストケース

 以下のテスト ハーネスは、2 つの交点の 1 つの正確な順序を必要とするのではなく、幾何学的回答を比較します。 スペシャルもチェックします`MANY`ケースと必要なポイント数。```python
import sys
import io
import math

input = sys.stdin.readline

def solve():
    x1, y1, r1 = map(int, input().split())
    x2, y2, r2 = map(int, input().split())

    dx = x2 - x1
    dy = y2 - y1
    d2 = dx * dx + dy * dy

    if d2 == 0:
        if r1 == r2:
            print("MANY")
        else:
            print(0)
        return

    sum_r = r1 + r2
    diff_r = abs(r1 - r2)

    if d2 > sum_r * sum_r or d2 < diff_r * diff_r:
        print(0)
        return

    d = math.sqrt(d2)
    a = (r1 * r1 - r2 * r2 + d2) / (2.0 * d)
    h2 = r1 * r1 - a * a

    if h2 < 0.0:
        h2 = 0.0

    h = math.sqrt(h2)

    px = x1 + a * dx / d
    py = y1 + a * dy / d

    ux = -dy / d
    uy = dx / d

    x_a = px + h * ux
    y_a = py + h * uy

    if h == 0.0:
        print(1)
        print(f"{x_a:.10f} {y_a:.10f}")
        return

    x_b = px - h * ux
    y_b = py - h * uy

    print(2)
    print(f"{x_a:.10f} {y_a:.10f}")
    print(f"{x_b:.10f} {y_b:.10f}")

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        solve()
        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

def parse_output(out: str):
    lines = out.strip().splitlines()

    if lines == ["MANY"]:
        return "MANY", []

    n = int(lines[0])
    points = []

    for line in lines[1:]:
        x, y = map(float, line.split())
        points.append((x, y))

    assert len(points) == n
    return n, points

def assert_points_on_circles(inp: str, out: str):
    data = list(map(int, inp.split()))
    x1, y1, r1, x2, y2, r2 = data

    result, points = parse_output(out)

    if result == "MANY":
        assert x1 == x2 and y1 == y2 and r1 == r2
        return

    for x, y in points:
        d1 = (x - x1) ** 2 + (y - y1) ** 2
        d2 = (x - x2) ** 2 + (y - y2) ** 2

        assert abs(d1 - r1 * r1) <= 1e-5 * max(1.0, r1 * r1)
        assert abs(d2 - r2 * r2) <= 1e-5 * max(1.0, r2 * r2)

300 0 200
"""

result, points = parse_output(out)
assert result == 2, "sample 1 count"
assert_points_on_circles(sample1, out)

# Provided sample 2.
sample2 = """\
0 0 1
0 2 1
"""
out = run(sample2)
result, points = parse_output(out)
assert result == 1, "sample 2 count"
assert_points_on_circles(sample2, out)
assert abs(points[0][0]) < 1e-9
assert abs(points[0][1] - 1.0) < 1e-9

# Custom case 1: coincident circles, the minimum radius.
case1 = """\

"""
assert run(case1).strip() == "MANY", "coincident circles"

# Custom case 2: concentric circles with different radii.
case2 = """\

"""

# Custom case 3: internal tangency.
case3 = """\

"""

 |`0 0 3`/`1 0 2`| ワンポイントで`(3, 0)`| 内部接線 |
 |`-1000 -1000 1000`/`1000 -1000 1000`| 2 つの交点 | 最大サイズの座標と半径 |

 ## 特殊なケース

 一致する円については、次のことを考慮してください。```
0 0 1
0 0 1
```中心距離の二乗はゼロであり、半径は等しい。 アルゴリズムはすぐに出力します`MANY`中心距離を除数として計算する前に。 ここで不変なのは、両方の方程式がまったく同じ点のセットを表すということです。 

半径が異なる同心円の場合、```
0 0 1
0 0 2
```中心距離の二乗は再びゼロですが、半径は異なります。 アルゴリズムは出力します`0`。 同じ中心を持つ 2 つの円は、半径が等しい場合にのみ点を共有できます。 

外部接線の場合、```
0 0 1
2 0 1
```中心距離の二乗は`4`、正確に等しい`(1 + 1)^2`。 素性条件は次を使用します。`>`それよりも`>=`したがって、このケースは交差計算まで存続します。 結果として得られる値は、`h2`ゼロであり、単一点を与えます`(1, 0)`。 

内部接線の場合、```
0 0 3
1 0 2
```中心距離は正確に`|3 - 2| = 1`。 ここでも、厳密な不等式によって構成が拒否されるわけではありません。 式は次のようになります`a = 3`そして`h2 = 0`、生産`(3, 0)`、小さい円が大きい円と接触する点。 

厳重な封じ込めのため、```
0 0 5
1 0 1
```中心距離は`1`、一方、半径の差は`4`。 (1^2 < 4^2) なので、アルゴリズムはすぐに出力します。`0`。 この分類には平方根や浮動小数点の計算は必要ありません。 

2 つの普通の交差点の場合、```
0 0 2
3 0 2
```中心距離は`3`、これは厳密に半径の差の間にあります。`0`そして半径の合計`4`。 アルゴリズムは構築段階に達し、以下を取得します。`a = 1.5`、そして肯定的な結果を得る`h2`, したがって、2 つの対称点が出力されます。 中心を結ぶ線の周りの対称性は、垂直単位ベクトルの使用から直接得られます。 

主な数値境界は接線です。 の正確な幾何学的値`h2`はゼロですが、浮動小数点評価では小さな負の数が生成される可能性があります。 クランピング`h2`ゼロにすると防止されます`math.sqrt`本当に有効な 2 つの交差のケースをすべて変更せずに、失敗することを防ぎます。
