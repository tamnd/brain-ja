 ## 解決策
 ## 問題の理解

 以下のみで構成されるバイナリ文字列が与えられます。`0`と`1`s. タスクは、それを次の「適切な」特性を満たす文字列に変換することです: すべての位置について`i`文字列内の、次の文字`i`最後から数えて対称な位置の文字とは異なっていなければなりません。つまり、`s[i] != s[n-i+1]`。 文字列は部分文字列を挿入することで変更できます。`"01"`どの位置でも同様の挿入を最大 300 回実行できます。 私たちの目標は、文字列を適切なものにすることが可能かどうかを判断し、可能であれば、これを達成する一連の挿入を提供することです。 

制約は中程度です。 各文字列の長さは最大 100 で、最大 100 個のテスト ケースを含めることができます。 これは、文字列を複数回繰り返す解決策は実行可能ですが、シーケンスの数は挿入の数とともに指数関数的に増加するため、考えられるすべての挿入シーケンスを総当たりで列挙することは実行不可能であることを意味します。 

明らかではないエッジ ケースは、次のようなすべて同じ文字である文字列です。`"000"`または`"111"`。 このような場合、中央を横切ってミラー化された部分文字列は常に等しい文字を持つため、適切な文字列を作成する方法はありません。 もう 1 つの注意が必要なケースは、一方の端に単純に挿入するだけで問題を解決できる文字列です。`"0011"`追加することで改善できます`"01"`対称性のバランスをとるために。 元の文字列をチェックするだけ、または最初に挿入することだけを考慮する不用意な実装は、これらの例では失敗します。 

## アプローチ

 ブルートフォースアプローチでは、あらゆる可能な位置への挿入が試行されます。`"01"`弦が良くなるまで繰り返します。 これは、解決策が存在する場合には機能することが保証されていますが、シーケンスの数が急速に増加するため、たとえ小さな文字列であってもすぐに実用的ではなくなります。 挿入するたびに 2 つの新しい位置が作成され、可能性が倍増します。 

重要な観察は、すべての文字が同一である場合、文字列を適切に作成することは不可能であるということです。 それ以外の場合は、単純な構成で問題を解決します。`"01"`文字列の最後まで 1 回。 理由は追加することです`"01"`最後の文字がその対称パートナーと異なることを保証し、このパターンは文字列全体の条件を満たすようにカスケードされます。 これは、両方を含む文字列が存在するため、機能します。`0`そして`1`この制御された方法でいつでも拡張でき、1 つまたは 2 つ以上の挿入を必要とせずに「良好な」条件を満たすことができます。 

したがって、問題はすべての文字が等しいかどうかをチェックすることになります。 もしそうなら、答えは次のとおりです。`-1`。 そうでない場合は追加できます`"01"`特定の位置に配置して適切な文字列を構築します。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. テスト ケースごとに、文字列を読み取ります。`s`。 
3. すべての文字が含まれているかどうかを確認します。`s`は同一です。 存在する場合は、出力します`-1`一連の挿入が条件を満たすことはできないためです。 
4. 文字列に両方が含まれている場合`0`そして`1`、出力`1`演算回数を計算し、インデックスを出力します。`n`挿入する位置としては`"01"`文字列の最後に。 これにより、弦が良好になることが保証されます。 
5. すべてのテスト ケースに対して繰り返します。 

ここでの不変条件は、両方を含む文字列であることです。`0`そして`1`追加することでいつでも改善できます`"01"`最後に。 追加中`"01"`最後の 2 文字が異なることが保証され、文字列にはすでに両方の文字が含まれているため、ミラーリングされた比較条件が文字列全体に適用されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        if s.count('0') == n or s.count('1') == n:
            print(-1)
        else:
            print(1)
            print(n)

solve()
```コードは最初にテスト ケースの数を読み取ります。 テスト ケースごとに、文字列が完全に 1 文字で構成されているかどうかがチェックされます。 そうであれば、印刷されます`-1`。 それ以外の場合は印刷されます`1`操作と挿入`"01"`最後に（位置`n`）。 の`.strip()`改行文字がカウントと位置の妨げにならないようにします。`n`最後に追加することに正しく対応します。

 ## 特殊なケース

 文字列の場合`"111"`すべて同一の文字がある場合、アルゴリズムがチェックします`s.count('1') == n`そして出力`-1`。 挿入しないとうまくいきません。 

文字列の場合`"001"`両方の文字が含まれている場合、アルゴリズムによって追加されます。`"01"`位置 3。結果の文字列`"00101"`ミラー化された各ペアが異なるため、条件は満たされます。`0 != 1`、`0 != 0`(真ん中は無視)、そして`1 != 0`。 挿入により、ミラー化されたペアが等しくないという不変条件が保証され、混合文字列に対して 1 回の挿入で十分であることがわかります。
