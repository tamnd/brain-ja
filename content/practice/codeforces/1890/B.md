 ## 解決策
 ## 問題の理解

 2 つのバイナリ文字列が与えられています。`s`そして`t`。 青山は変身したい`s`「適切な」文字列と呼ばれる、連続する 2 つの同じ文字が存在しない文字列に変換されます。 文字列を繰り返し挿入できます`t`どこでも`s`、最初または最後を含め、何度でも。 目標は、それが可能かどうかを判断することです。`s`これらの挿入を使用すると良いでしょう。 

入力には複数のテスト ケースがあり、最大 2000 のケースがあり、各文字列の長さは最大 50 です。`n`そして`m`が小さい場合は、テスト ケースごとに複雑さ O(n*m) のアルゴリズムが許容されます。 ただし、考えられるすべての挿入をシミュレートする単純なアプローチは、次の点で指数関数的です。`n`そして`m`が鈍くなるにもほどがあります。 

不注意な実装を騙す可能性のあるエッジ ケースとしては、すでに良好な文字列、`s`繰り返しの文字が含まれており、`t`均一であるか、またはどこで`t`交互に繰り返されますが、最初の繰り返しを修正することはできません。 たとえば、次の場合`s = "111"`そして`t = "00"`どこに挿入しても`t`、の繰り返し`1`先頭の s は解決できません。 逆に、もし`s = "1"`そして`t = "010"`、文字列はすでに良好であるため、操作はゼロで十分です。 

## アプローチ

 ブルートフォースメソッドは、`t`あらゆる可能な位置で`s`、考えられるすべての文字列を生成し、それぞれの文字列が「良い」プロパティであるかどうかを確認します。 これは正しいですが、挿入ごとに考慮すべき文字列の数が増えるため、実行不可能です。 と`n=50`そして`m=50`、可能性の数は指数関数的に増加し、明らかに制限時間を超えています。 

重要な洞察は、の最後の文字に焦点を当てることです。`s`そして最初の文字は`t`。 適切な文字列には交互の文字が必要であるため、連続する文字が等しい場合にのみ潜在的な問題が発生します。 すべての挿入をシミュレートする必要はありません。 かどうかを確認するだけで済みます。`t`連続する異なる文字のペアが少なくとも 1 つ含まれていると、繰り返しが中断される可能性があります。`s`。 もし`s`文字で終わる`c`そして`t`文字が含まれています`d != c`、挿入`t`最後に潜在的にできるのは`s`良い。 の最初の文字`t`の最後とは異なっていなければなりません`s`ジャンクションでの繰り返しを削除します。 残りの部分`t`良好さを維持するには交互に行う必要があるだけです。 もし`t`均一であり、次の中で繰り返される文字と同一です。`s`、それは仕方がありません。 

問題を 3 つのチェックに減らすことができます。`s`すでに良好な場合は、YES を返します。 それ以外の場合は、次のことを確認してください`t`は良好で、最後の文字が`s`最初のものとは異なります`t`。 この一定時間チェックは、テスト ケースごとに O(1) です。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースを繰り返し、読み取ります。`n`、`m`、`s`、 そして`t`。 
2. かどうかを確認します。`s`スキャンすることですでに問題なく動作しています`s[i] == s[i+1]`。 そのようなペアが存在しない場合は、「YES」を出力し、次のテスト ケースに進みます。 これにより、ゼロオペレーションのシナリオが処理されます。 
3. かどうかを確認します。`t`良いです。 スキャン`t`連続する等しい文字の場合。 もし`t`は良くありません。文字が繰り返されているため、「NO」を出力します。`t`修正できません`s`。 
4. もし`t`いいですね、最後の文字を調べてください`s`そして最初の文字は`t`。 異なる場合は、挿入します`t`最後 (または繰り返しの間の任意の場所) で繰り返しを中断できる場合は、「YES」と出力します。 それらが同じ場合は、挿入しても連続した繰り返しが解決されないため、「NO」を出力します。 
5. すべてのテスト ケースに対して繰り返します。 

機能する理由: このアルゴリズムは、適切な文字列は連続する文字の違いによってのみ定義されるという特性に基づいています。 繰り返されるセグメント`s`良いものを挿入することで修正できます`t`最初の文字が前の文字と異なる`s`。 以来`t`これは良いことですが、新たに連続した繰り返しが発生することはありません。 間の接続点のみをチェックする`s`そして`t`他のポジションは十分なので、`s`すでに良好であるか、繰り返し挿入することで修正できるかのいずれかです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_good(x):
    for i in range(len(x)-1):
        if x[i] == x[i+1]:
            return False
    return True

T = int(input())
for _ in range(T):
    n, m = map(int, input().split())
    s = input().strip()
    t = input().strip()
    
    if is_good(s):
        print("YES")
        continue
    
    if not is_good(t):
        print("NO")
        continue
    
    if s[-1] != t[0]:
        print("YES")
    else:
        print("NO")
```機能`is_good`文字列に連続する等しい文字があるかどうかをチェックします。 まず、次のような些細なケースを扱います。`s`もういいです。 そうでない場合は、`t`良くないものを挿入するので、それは良いです`t`改善できない`s`。 最後に、間の接合点を確認します。`s`そして`t`1 回の挿入で最後の繰り返しを解決できるかどうかを判断します。 複数の挿入を明示的に考慮する必要はありません。`t`交替を保持し、接合条件が満たされると繰り返し挿入する必要はありません。
