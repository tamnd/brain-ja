 ## 解決策
 ## 問題の理解

 とのミーティングを予定しています$N$スピーカー。 各スピーカーは同じ整数の分数で話し、連続するスピーカーのペアごとに固定の 1 分間の休憩があります。 したがって、会議の合計時間は 2 つの部分で構成されます。1 つは発言時間です。$N \cdot t$それぞれの話が続けば$t$分とアイドル時間、正確に$N-1$分の間には多くのギャップがあるため、$N$スピーチ。 

タスクは可能な最大の整数を選択することです$t \ge 1$合計時間が制限を超えないように$K$。 正式には、最大値が必要です$t$満足のいく$$N \cdot t + (N - 1) \le K.$$入力サイズは小さいです。$N \le 100$、$K \le 1000$。 これは、すべての可能な値に対する単純な線形スキャンでも、$t$まで$K$計算的には簡単です。 どれでも$O(K)$あるいは$O(NK)$アプローチは即座に実行されます。 この構造は純粋に算術演算であり、内部に組み合わせ論やグラフ走査は隠されていません。 

間違いを引き起こす可能性がある唯一の微妙な点は、休憩はスピーチごとにカウントされるのではなく、スピーチの間にカウントされることを忘れることです。 たとえば、次の場合$N = 1$、休憩はゼロであるため、式は次のようになります。$t \le K$、与える$t = K$。 常に減算する不注意な実装$N$の代わりに$N-1$誤って答えを減らしてしまいます。 

もう 1 つの潜在的なエッジ ケースは、スケジュールが制限を正確に満たす厳しい境界です。 たとえば、次の場合$N=3$、$K=10$、 そして$t=3$、合計時間は$3\cdot3 + 2 = 11$、すでに超えています$K$、したがって、正しい答えは次のようになります。$2$。 これは、不平等を厳密に強制する必要があることを強調しています。 

## アプローチ

 最も直接的なアイデアは、考えられるすべてのスピーチの長さを試してみることです。 から始めます$t=1$合計期間を超えるまで増加します$K$。 各チェックで計算されます$N \cdot t + (N-1)$。 以来$t$せいぜい周りにいる$K$、この総当り的なアプローチは、一定時間で最大 1000 回の反復を実行します。 これは制約を考慮するとすでに十分な速度です。 

不等式を書き出す瞬間$N \cdot t + (N-1) \le K$、問題が純粋に線形であることがわかります。 シミュレーションや検索は必要ありません。直接分離できます。$t$。 並べ替えると$$t \le \frac{K - (N - 1)}{N}.$$以来$t$整数でなければならず、有効な最大値が必要な場合は、単純にこの式の下限値を取得します。 これにより、反復が完全に排除されます。 

制約空間が小さいためブルートフォースは機能しますが、式が単調な関係を定義していることを認識すると、ブルートフォースは不要になります。$t$。 として$t$が増加すると、合計時間は直線的に増加するため、有効から無効に移行するしきい値は 1 つだけになります。 この単調性により、直接計算が可能になります。

 ## アルゴリズムのチュートリアル

 1. 整数の読み取り$N$そして$K$。 これらは、トークの数と最大許容合計時間を定義します。 
2. 必須の休憩時間を差し引きます。$(N-1)$から$K$。 これにより、実際に話すのにどれくらいの時間が使えるのかがわかります。 ブレークは固定され、独立しているため、このステップは非常に重要です。$t$。 
3. 残り時間を次のように割ります。$N$整数の除算を使用します。 これにより、制限を超えないようにして、発言可能な時間をすべての発言者に均等に配分します。 
4. 結果を、可能な最大整数音声長として出力します。 

## なぜ機能するのか

 合計期間は次の一次関数です。$t$、 具体的には$f(t) = N t + (N-1)$。 この機能は厳密に増加しています$t$, したがって、実行可能な値のセットは、次から始まる連続した間隔を形成します。$t=1$。 有効な最大のもの$t$したがって、関数が次の値を超える前の正確な最後の整数です。$K$。 コンピューティング$\lfloor (K-(N-1))/N \rfloor$境界点を直接特定し、最大性と実現可能性の両方を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

N = int(input().strip())
K = int(input().strip())

# total time: N*t + (N-1) <= K
# => N*t <= K - (N-1)
remaining = K - (N - 1)
ans = remaining // N

print(ans)
```実装では、導出された不等式を直接エンコードします。 の引き算$(N-1)$ブレークからすべての固定オーバーヘッドを削除し、整数の除算で実現可能な最大の整数に必要な下限演算を実行します。$t$。 

微妙な点は、答えが少なくとも 1 になるように明示的に固定することは決してないことです。問題はそれを保証します。$K \ge N$これにより、休憩を差し引いた後、講演者あたり少なくとも 1 分が常に実行可能になります。

 ## 特殊なケース

 のために$N=1$、休憩がないため、計算はきれいに減少します。$t = K$。 式は次のようになります$(K-0)/1 = K$、意図した動作と正確に一致します。 

休憩が時間予算の大半を占める場合:$N=100, K=100$、差し引いた残りの時間$99$だけです$1$を生成します。$t=0$という式で。 これは、厳密に算術的に解釈すると、この制約の下では話者ごとに 1 分を割り当てることさえ不可能であるという事実に対応します。 ただし、この問題は次のような方法で実現可能性を保証します。$K \ge N$したがって、そのような病的なケースは有効な入力の正確性に違反しません。 

厳密な等価性の場合、次のような場合$N=4, K=13$、私たちは得ます$t = (13-3)/4 = 2$。 逆に代入すると合計時間が得られます$4 \cdot 2 + 3 = 11$、たるみを残しながらも最大化します$t$。 あらゆる増加$t=3$すぐに制限を超えているため、境界が正しく処理されていることを確認できます。
