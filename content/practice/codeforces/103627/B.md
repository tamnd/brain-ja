 ## 問題の理解

 私たちは、$n \times n$各セルを埋めるか空のままにすることができるグリッド。 目標は、完全な「ビンゴ ライン」の形成を回避する空のセルのパターンを構築することです。ビンゴ ラインは、完全に空の行、完全に空の列、または完全に空の主対角線または反対角線に対応します (ここで使用される構築の解釈に応じて異なります)。 

ゲームのルールという観点から考えるのではなく、タスクを組み合わせ構築問題として言い換えた方が有益です。 できるだけ多くの空のセルを配置したいと考えています。$n \times n$行、列、または対角線が完全に空にならないようにしながら、グリッドを作成します。 すべての行と列には、少なくとも 1 つの塗りつぶされたセルが含まれている必要があります。 

単純なカウント引数により、配置できる空のセルの数の上限が決まります。 それぞれの$n$行には少なくとも 1 つの塗りつぶされたセルが含まれている必要があります。$n$塗りつぶされたセルの合計。 これは、空のセルの数が最大で$n^2 - n$。 重要な問題は、この限界が実際に達成できるかどうかです。 

この問題は純粋に建設的であり、次の要素のみに依存するため、制約は最小限です。$n$。 これは、通常の意味での漸近的なパフォーマンスには関心がなく、むしろ、次のすべての値に対して有効な構成を生成できるかどうかに関心があることを意味します。$n$そしてそれを明示的に構築する方法。 

唯一微妙なエッジケースは次のような場合です。$n = 2$。 その場合、行、列、対角線の構造が密になりすぎて、上限を達成することができなくなります。 簡単な手動チェックでは、2 つの空のセルを配置しようとすると、行全体または列全体が空になることがわかります。

## アプローチ

 ブルートフォース手法では、セルのすべてのサブセットを試し、行、列、または対角線が完全に空になるかどうかを確認します。 これには選択が含まれます$k$間の空のセル$n^2$位置、$k$ potentially close to $n^2$。 構成の数は指数関数的に増加します。$\binom{n^2}{k}$、それはたとえ小さくても実行不可能です$n$。 すべての可能性を直接テストするため、正確性は簡単ですが、非常に小さなグリッドを超えるとランタイムがすぐに爆発します。 

重要な構造上の観察は、「各行には少なくとも 1 つの塗りつぶされたセルが含まれている必要がある」という制約によって、すでに非常に厳密な形式が規定されているということです。 事後的に不適切な構成を回避することを考えるのではなく、行ごとに 1 つの塗りつぶされたセルが割り当てられ、残りが空になるパターンを構築できます。 これにより上限が自動的に保証されます$n^2 - n$。 

残りの困難は、列と対角線が誤って完全に空になったり、意図しないパターンを形成したりしないようにすることです。 単純な対角構造は、塗りつぶされたセルをシフトした対角線に沿って配置することで機能し、すべての行と列に正確に 1 つの塗りつぶされたセルが配置されます。 これはポジションを埋めることに対応します$(i, i)$またはそれのシフトバージョン。 

However, this naive diagonal pattern fails when diagonal constraints are considered more strictly, especially for even$n$、構造の配置に応じて、主対角線の 1 つが完全に空になる可能性があります。 The fix is to slightly break symmetry by swapping positions in the first and last row, which ensures that neither diagonal becomes fully uniform in emptiness.

 最後の例外は、$n = 2$、このような再配置は完全な行を回避しないため、個別に処理する必要があります。

 ## アルゴリズムのチュートリアル

 私たちは、$n \times n$グリッドを作成し、各行に 1 つの塗りつぶされたセルが表示されるように、どのセルが塗りつぶされ、どのセルが空であるかを明示的に決定します。 

1. 概念的に空のセルで満たされた空のグリッドから開始します。 目標は、すべての行と列にちょうど 1 つの塗りつぶされたセルが存在するように、塗りつぶされたセルの位置を決定することです。 これにより、空のセルの最大数が保証されます。 
2. のために$n = 2$は、上限に達する構成がないため、完全に空の行または列の形成を回避する唯一の有効な構成を直接出力します。 
3. のために$n \ge 3$、塗りつぶされたセルを対角パターンに沿って配置しますが、その行が配置されるようにずらして配置します。$i$列の入力されたセルを取得します$i$ほとんどの行で。 これにより、列の一意性が自動的に保証されます。 
4. 最初の行と最後の行の塗りつぶし位置を交換して、主要な対角構造が壊れるように変更します。 これにより、対称性のために対角線が誤って完全に空になるのを防ぎます。 
5. 塗りつぶされたセルを配置した後、残りのすべてのセルを空としてマークします。 各行には入力されたセルが 1 つだけ含まれているため、各行が寄与します。$n - 1$空のセル、合計を与える$n(n - 1) = n^2 - n$。 

### なぜ効果があるのか

 この構造では、必要以上に強力な不変条件が適用されます。つまり、各行には 1 つの塗りつぶされたセルが含まれ、各列にも 1 つの塗りつぶされたセルが含まれます。 これは、すべての行には埋められる位置が保証されているため、完全に空の行や列は存在できないことを意味します。 対角線の交換ステップは、すべての塗りつぶされたセルを 1 つの対角線に沿って整列させ、禁止された完全に空の対角線を誤って作成する可能性がある唯一の構造的対称性を除去します。 この対称性が崩れると、空のセルの最適な数を維持しながら、すべての行の制約が満たされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())

    if n == 2:
        print(-1)
        return

    grid = [['.' for _ in range(n)] for _ in range(n)]

    # place one filled cell per row in a shifted diagonal pattern
    for i in range(n):
        j = (i + 1) % n
        grid[i][j] = '#'

    # swap first and last row placements to break diagonal symmetry
    if n > 2:
        for j in range(n):
            grid[0][j], grid[n - 1][j] = grid[n - 1][j], grid[0][j]

    for row in grid:
        print(''.join(row))

if __name__ == "__main__":
    solve()
```グリッドは完全に空のセルで初期化されます。 ループ配置`#`巡回シフトを使用して行ごとに 1 つのセルが必ず 1 つだけ入力されるようにするため、列も 1 回だけ使用されます。 

最初の行と最後の行の間の入れ替えは、対称的な場合の対角線の位置合わせの問題を回避する重要な修正です。 これがないと、パターンは、意図した対角制約を満たさない完全に整列した対角に変質してしまいます。 

最後の印刷ステップでは、構築されたグリッドを行ごとに出力するだけです。

 ## 特殊なケース

 のために$n = 2$、アルゴリズムは直接出力します`-1`。 これは、対角線の制約に違反せずに、行ごとに塗りつぶされたセルを 1 つだけ配置することは不可能であることと一致します。 グリッドは対称性を破るには小さすぎるため、いかなる試みも禁止された線に崩壊します。 

のために$n = 1$、この構造は単一の塗りつぶされたセルを配置し、有効な自明なグリッドを生成します。 循環配置は引き続き機能し、スワップは必要ないため、アルゴリズムはこれを自然に処理します。 

偶数の場合$n$、最初の行と最後の行の入れ替えは必須です。 これがないと、パターンは完全な循環対角になり、主対角を横切る対称性により、意図しない完全に空の対角が生成される可能性があります。 スワップにより、その構造から少なくとも 1 つの逸脱が保証され、行と列の一意性を維持しながら位置合わせが解除されます。
