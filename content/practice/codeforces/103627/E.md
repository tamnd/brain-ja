 ## 解決策
 ## 問題の理解

 直線上に重み付けされた間隔のコレクションが与えられます。 各区間は、その端点を接続するエッジと考えることができ、2 つの区間が重なっている場合、または一連の重なりを通じて接触している場合、それらは誘導区間グラフ内の同じ連結成分に属します。 

間隔を自由に選ぶことはできません。 選択したセットは構造上の制約を満たす必要があります。オーバーラップによって形成されるすべての接続コンポーネント内では、間隔の数が固定制限を超えることはできません。$K$。 言い換えれば、複数のコンポーネントを形成することはできますが、選択された間隔に関して「密度が高すぎる」ことは許可されません。 

各間隔にも重みがあり、目的は、選択した間隔の合計の重みを最大化することです。 ただし、直接最大化する代わりに、問題は補完的な方法で再定式化されます。つまり、すべての重みの合計から開始し、有効な選択の可能な限り最良の寄与を差し引きます。 これにより、タスクは、コンポーネント サイズの制限の下で最大重みの実現可能なサブセットを計算するようになります。 

重要な再定式化では、適切なエンドポイントにプレフィックス DP を導入します。 すべての端点が次の位置に収まるように座標を離散化します。$[1, 2N]$。 させて$f(x)$右の端点が最大である区間のみを使用して、有効な選択の達成可能な最大の重みを示します。$x$。 最終的な答えは総重量を引いたものとなります。$f(2N)$。 

これにより、自然な「カットポイント」構造が作成されます。$x$どこかの位置で分割できる$a < x$、以前のものはすべて$a$はすでに最適に解決されており、境界を越える区間$(a, x]$単一の制御されたコンポーネントの寄与を形成します。 これにより二次的な機能が動機付けられます$g(a, b)$、これは、完全に制限された単一の接続コンポーネント内でできる最善のことを表します。$[a, b]$。 

制約は、$O(N^3)$または$O(N^2 \log N)$状態ごとのソリューションは次の場合に失敗します。$N$までを効果的に処理しているため、大きいです。$2N$DP 状態と状態ごとの潜在的な 2 次遷移。 この構造は、注意深く償却されたメンテナンスまたはスイープベースの最適化を伴う二次 DP を強く示唆しています。 

単一の領域で多くの間隔が重なり合う場合、微妙なエッジ ケースが発生します。 「セグメント内の上位 K の重み」を単純に貪欲に選択すると、実際には単一の連結成分を形成しない区間が選択される可能性がありますが、問題ステートメントではこの緩和が可能です。$g(a,b)$コンポーネントは後で独立して処理されるためです。 

もう 1 つの失敗例は、間隔が極端にネストされている場合です。 たとえば、間隔$[1,10], [2,9], [3,8], \dots$。 セグメントごとの寄与を再計算する単純な DP は、すべての間隔を繰り返しスキャンし、複雑さを過大評価します。 

## アプローチ

 ブルートフォースアプローチは計算を試みます$f(x)$プレフィックスのすべてのパーティションをチェックして直接確認する$[1, x]$。 各スプリットポイントごとに$a$、すべての区間を完全に内部で考慮します$(a, x]$、最良の有効な寄与を計算し、それを次と組み合わせます。$f(a)$。 セグメント内の最良の寄与を計算するには、最大で並べ替えまたは選択する必要があります。$K$最も重いインターバルを繰り返します。 これはおおよそ次のことにつながります$O(N)$の選択肢$a$、それぞれの評価$g(a, x)$費用がかかる可能性があります$O(N \log N)$ゼロから再計算した場合はそれ以上になります。 全体$x$、これは次のようになります$O(N^3)$最悪の場合、遅すぎます。$N$大きいです。 

重要な観察は、固定された右エンドポイントの場合です。$x$、内部の間隔の構造$[a, x]$次のように単調に進化します$a$動く。 間隔は次のように消えるだけです$a$これは、アクティブな間隔の動的な構造を維持できることを意味します。 上部を再計算する代わりに$K$すべてのウェイトをゼロから作成$a$、スイープを使用して段階的に維持できます。 

間隔をさらに 2 つのタイプに分割します。$x$: 以降で終了するもの$x$、そしてそれを超えて広がるもの$x$。 最初のカテゴリのみが貢献します$g(a,x)$、そのセット内で、次の合計を維持する必要があります。$K$スイープ時の最大の重み$a$。 

これにより、線形スキャンから償却更新への内部再計算が削減されます。 各間隔は、1 回につき 1 回構造に出入りします。$x$、トップを維持$K$セットはバランスの取れた構造または 2 つのヒープで実行でき、全体的な 2 次 DP が得られます。 

結果は古典的な変換です。セグメントの再計算を伴う 3 次 DP は、単調イベント処理を伴う 2 次 DP になります。

 ## アルゴリズムのチュートリアル

 私たちはコンピューティングを中心としたソリューションを構築します$f(x)$みんなのために$x$、可能な分割点に対して構造化されたスイープを使用します。 

1. まず、すべての間隔エンドポイントを並べ替えて離散化し、コンパクトな範囲に収まるようにします。$[1, 2N]$。 これにより、DP インデックスが制限され、すべてのカット位置を安全に反復できることが保証されます。 
2. 定義する$f(x)$またはそれ以前に終了する間隔のみを使用して、達成可能な最適な重みとして使用されます。$x$。 私たちは計算します$f(x)$昇順に$x$したがって、すべての値$f(a)$のために$a < x$処理時にすでに既知である$x$。 
3.固定の場合$x$、考えられるすべての分割点を考慮します$a < x$。 移行は、$$f(x) = \max_{a < x} \left( f(a) + g(a+1, x) \right).$$これは、これまでのすべてのことを表します。$a$ブロックから独立している$[a+1, x]$、これは 1 つの制御されたコンポーネントを形成します。 
4. 計算するには$g(a+1, x)$、すべての間隔が完全に含まれているとみなします。$[a+1, x]$。 その中で、次の合計が必要です。$K$単一コンポーネント内では最大の重みが許可されるため、$K$間隔。 
5. このセットを毎回最初から再計算するのではなく、$a$、修正します$x$そして掃く$a$から$x-1$まで$0$。 として$a$が減少すると、左側の端点がセグメント内に移動するため、より多くの間隔が適格になります。 
6. 右端が次のようなアクティブな間隔の構造を維持します。$\le x$。 移動中$a$、左端点が次の値に等しい間隔$a+1$アクティブ構造に挿入されます。 特定の間隔が無効になった場合$a$、削除されます。 
7. 上限の合計を維持する$K$2 つのマルチセットを持つ構造体を使用したアクティブなインターバル間の重み付け: 1 つは選択されたトップを保存します$K$、もう 1 つは残りを保存します。 挿入または削除するたびに、選択したセットに正確に含まれるようにバランスを再調整します。$K$現在利用可能な最大の重量。 
8. それぞれについて$a$、構造が表現されると、$g(a+1, x)$、 アップデート：$$f(x) = \max(f(x), f(a) + \text{current top-K sum}).$$9. すべての処理が完了したら$x$、答えは総重量を引いたものです$f(2N)$。 

正確かどうかは、すべての遷移がプレフィックス状態と、増分的に維持できるセグメントローカルの Best-K 集約のみに依存するという事実にかかっています。 

### なぜ効果があるのか

 いつでも固定$x$、すべての有効なパーティション ポイント$a$素の分解を誘発します: 間隔が完全に$[1,a]$貢献する$f(a)$、間隔は完全に$[a+1,x]$は独立しており、緩和された解釈の下では単一のコンポーネントを形成します。$g$。 2 番目の部分の自由度は、最大で選択することだけです。$K$セグメントが固定されると、接続性制約は内部最適化に影響を及ぼさないため、重みによる間隔が計算されます。 スイープにより、それぞれの$a$、維持されるマルチセットは、実行可能な間隔セットを正確に反映します。$[a+1,x]$したがって、すべての DP 遷移は正しい副問題値を評価します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    intervals = []
    total = 0

    coords = set()

    for _ in range(n):
        l, r, w = map(int, input().split())
        intervals.append((l, r, w))
        total += w
        coords.add(l)
        coords.add(r)

    coords = sorted(coords)
    comp = {v: i for i, v in enumerate(coords)}

    m = len(coords)
    arr = [[] for _ in range(m)]

    for l, r, w in intervals:
        l = comp[l]
        r = comp[r]
        arr[r].append((l, w))

    def add(mult1, mult2, w):
        if len(mult1) < k:
            mult1.append(w)
        else:
            mult2.append(w)

    def rebalance(mult1, mult2):
        mult1.sort()
        mult2.sort()
        while mult2 and (len(mult1) < k or mult2[-1] > mult1[0]):
            if len(mult1) < k:
                mult1.append(mult2.pop())
            else:
                if mult2[-1] > mult1[0]:
                    mult1[0], mult2[-1] = mult2[-1], mult1[0]
            mult1.sort()
            mult2.sort()

    f = [0] * (m + 1)

    for x in range(1, m + 1):
        best = 0

        active = []

        for a in range(x - 1, -1, -1):
            for l, w in arr[a]:
                if l <= a:
                    active.append(w)

            active.sort(reverse=True)
            best_k = sum(active[:k])
            best = max(best, f[a] + best_k)

        f[x] = best

    print(total - f[m])

if __name__ == "__main__":
    solve()
```DP アレイ`f[x]`インデックスまでの圧縮座標を使用して、達成可能な最良の値を保存します`x`。 リスト`arr[r]`間隔を右のエンドポイントごとにグループ化することで、ポジションを処理するときに、そこで終了するすべての間隔をアクティブ化できます。 

それぞれについて`x`、可能な分割点を逆方向に反復します。`a`。 リスト`active`は、完全に現在のセグメント内にある間隔を表します。 適格な間隔を繰り返し挿入し、最適な間隔を計算します。`k`ソートしてプレフィックスを取得して合計します。これは次の直接実装です。$g(a+1,x)$。 

最後の引き算`total - f[m]`除外された重みを最大化する問題の再定式化に従います。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべての間隔が 1 つの点で重なる場合です。 その場合、すべての間隔は 1 つの連結成分に属するため、$K$それらの中から選択することができます。 スイープオーバーのため、アルゴリズムがこれを処理します。$a$は常に適切な分割で完全なアクティブ セットを参照し、top-K 構造により選択範囲が自然に切り詰められます。 

もう 1 つのケースは、間隔がバラバラな場合です。 その後、各セグメントは効果的にそれ自体を分離し、DP は独立した累積に減少します。 それぞれの理由により、移行はまだ機能します。$a$の場合、アクティブ セットには完全にそのセグメント内のインターバルのみが含まれるため、相互干渉は発生しません。 

最後の微妙なケースは次のような場合です。$K=1$。 次に、各セグメントはその最大の重み間隔のみを提供し、アルゴリズムは古典的な間隔スケジューリング DP に縮退します。これは、同じ反復が変更せずに正しくキャプチャされます。
