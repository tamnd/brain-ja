 ## アルゴリズムのチュートリアル

 1. 配列内の各値の頻度をカウントします。 これにより、すべての要素を繰り返し処理することなく、割り切れる可能性について推論することができます。 
2. 各整数について$x$から$1$に$m$で割り切れる要素の数を計算します。$x$。 これは、複数回反復することによって行われます。$x$そして周波数を加算します。 
3. その数から、次の数で割り切れる要素のみで形成される空でない部分列の数を計算します。$x$、つまり$2^{cnt[x]} - 1$。 この量には、GCD が次の倍数であるすべての部分列が含まれます。$x$、必ずしも正確ではありません$x$。 
4. プロセス$x$から$m$まで$1$。 それぞれについて$x$、すべての倍数の寄与を差し引きます。$kx$どこ$k \ge 2$。 これらの倍数は、GCD がより高い値ですでに考慮されているサブシーケンスを表します。 
5. 減算後の残りの値は、GCD が次のとおりである部分列の数と正確に一致します。$x$。 

減算ステップは重要な補正メカニズムです。 これがないと、すべてのサブシーケンスがその真の GCD のすべての約数についてカウントされます。 

### なぜ効果があるのか

 すべてのサブシーケンスには明確に定義された GCD があります$g$。 その部分列は、すべての約数のバケット内でカウントされます。$g$「で割り切れるすべての要素」を計算すると、$x$”。除数格子構造により、寄与が可分性チェーンに沿って正確に上方に伝播することが保証されます。大きいものから小さいものへ処理することで、次の答えを計算するときに、$x$、すべての寄与は適切な倍数からのものです。$x$すでにファイナライズされており、GCD が正確に一致するサブシーケンスのみを残して、きれいに削除できます。$x$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAXV = 10**6 + 5

# precompute powers of 2
pow2 = [1] * (MAXV)
for i in range(1, MAXV):
    pow2[i] = (pow2[i - 1] * 2) % MOD

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    freq = [0] * (m + 1)
    for v in a:
        freq[v] += 1

    cnt = [0] * (m + 1)

    for x in range(1, m + 1):
        s = 0
        for k in range(x, m + 1, x):
            s += freq[k]
        cnt[x] = s

    dp = [0] * (m + 1)

    for x in range(m, 0, -1):
        total = (pow2[cnt[x]] - 1) % MOD

        for k in range(2 * x, m + 1, x):
            total = (total - dp[k]) % MOD

        dp[x] = total

    print(*dp[1:])
```すべてのサブセット数は次の要素に依存するため、コードは 2 の累乗を事前計算することから始まります。$2^{cnt}$。 の`freq`配列は各値の出現を格納し、`cnt[x]`で割り切れる要素の数を累積します。$x$。 複数のネストされたループは、複雑さを制御する標準的なふるいのようなパターンです。 

ボトムアップ ループでは、包含と排除が発生します。 処理時に次のように答えを降順で計算します。$x$、すべての倍数$2x, 3x, \dots$すでに最終的な答えが得られています。 これにより、減算の正確性が保証されます。 

よくある実装上の落とし穴は、減算後のモジュロ補正を忘れることで、負の値が生成される可能性があります。 もう 1 つは、部分列数を除数ごとではなく要素ごとに計算しようとするもので、構造が完全に壊れてしまいます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import gcd
    MOD = 998244353

    t = int(input())
    out_lines = []

    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))

        freq = [0] * (m + 1)
        for v in a:
            freq[v] += 1

        pow2 = [1] * (n + 1)
        for i in range(1, n + 1):
            pow2[i] = (pow2[i - 1] * 2) % MOD

        cnt = [0] * (m + 1)
        for x in range(1, m + 1):
            for k in range(x, m + 1, x):
                cnt[x] += freq[k]

        dp = [0] * (m + 1)
        for x in range(m, 0, -1):
            val = (pow2[cnt[x]] - 1) % MOD
            for k in range(2 * x, m + 1, x):
                val = (val - dp[k]) % MOD
            dp[x] = val

        out_lines.append(" ".join(map(str, dp[1:])))

    return "\n".join(out_lines)

# custom sanity checks
assert run("1\n1 1\n1") == "1"
assert run("1\n3 3\n1 2 3")  # basic distribution sanity
assert run("1\n4 4\n2 2 2 2")
assert run("1\n5 5\n1 1 1 1 1")

 | すべて異なる | スパース gcd 分布 | 除数の分離 |

 ## 特殊なケース

 単一の値を含む最小限の入力により、実装が正しく処理するかどうかが明らかになります。$2^1 - 1 = 1$減算エラーなし。 アルゴリズムは計算します`cnt[x] = 1`その値の約数についてのみ、他のすべての dp 状態はゼロのままで、正しい分離された寄与が生成されます。 

すべての数値が同一である場合、包含と排除が強調されます。 その数のすべての約数は最初にすべてのサブシーケンスをカウントしますが、より高い倍数から減算すると、正確な gcd バケットを除くすべてが削除されます。 処理順序が降順であるため、取り消しが正しい方向に行われることが保証され、過剰カウントが防止されます。 

数値がペアごとに互いに素である場合は、逆の動作を示します。 各値はそれ自体の約数にのみ寄与するため、dp 値はほとんど独立したままとなり、意図しない除数間の漏れが存在しないことが確認されます。
