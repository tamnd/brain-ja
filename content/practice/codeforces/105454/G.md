 ## 問題の理解

 私たちはリンゴのかごが 2 つ存在する状況に対処しています。 1 つのバスケットには既知の量が入っています$X$、2 番目には未知の正の数が含まれています$Y$、厳密には以下よりも小さい$X$。 したがって、リンゴの合計数は、$S = X + Y$、そして私たちは知っています$1 \le Y \le X-1$、つまり$X+1 \le S \le 2X-1$。 

兄弟のグループは、最初にすべてのリンゴを自分たちで均等に分割します。 その後、妹が加わり、すべてのリンゴが再び集まり、同じグループに妹も含まれるようになります。 重要な制約は、両方の分割が完全に均等であり、リンゴが残らないことです。 さらに、各兄弟が受け取るリンゴは、第 2 部門では第 1 部門よりもちょうど 1 つ少なくなります。 

課題は、リンゴの数を再構成することではなく、兄弟が何個存在できるかを決定することです。 制約に一致するすべての有効な構成の中で、兄弟の可能な最小数と最大数を出力する必要があります。 

制約$X \le 10^{18}$テスト ケースごとに、すべての解が最大でも対数時間または定数時間になるように強制します。 可能なすべての兄弟の数を反復するアプローチは、候補の数がおよそ$10^9$またはそれ以上。 

隠れた変数から微妙な問題が発生します$Y$。 素朴なアプローチでは、あらゆる可能性を試みる可能性があります$Y$次に、兄弟の数ごとに割り算条件を確認します。 これにより、すぐに 2 次またはそれより悪い検索空間が発生し、制約の下では機能できなくなります。 

2 番目のよくある落とし穴は、2 番目の除算に姉妹が含まれていることを忘れていることです。これにより、約数が変化します。$k$に$k+1$。 これを怠ると、不正確な線形方程式や矛盾した制約が発生します。 

## アプローチ

 兄弟の数を$k$。 最初の分割では、各兄弟が受け取ります。$\frac{S}{k}$、 どこ$S = X+Y$。 2 番目の分割には、$k+1$人々、だからそれぞれが受け取ります$\frac{S}{k+1}$。 声明では、その違いはちょうどリンゴ 1 個であると述べています。$$\frac{S}{k} - \frac{S}{k+1} = 1$$強引なアイデアは、次のすべての値を試してみることです。$k$、それぞれについて、有効なものをすべて試してください$Y$、両方の除算が整数であるかどうか、および差分条件が成立するかどうかを確認します。 以来$X$まで可能です$10^{18}$、$Y$大きくすることもできますし、$k$おおよその範囲まで可能です$\sqrt{X}$またはそれ以上。 これにより、実行不可能な検索スペースが生じます。 

重要な観察は、上記の方程式が構造を完全に崩壊させているということです。 違いを単純化すると、$$S \cdot \frac{1}{k(k+1)} = 1$$どちらが強制するのか$$S = k(k+1)$$したがって、リンゴの総数は完全に次のように決定されます。$k$。 これにより、$Y$全体的に。 以来$S = X + Y$、私たちは得ます$$Y = k(k+1) - X$$今の状態は$1 \le Y \le X-1$になる$$X+1 \le k(k+1) \le 2X-1$$したがって、問題はすべての整数を見つけることに帰着します$k$そのような$k(k+1)$一定の間隔で存在します。 これは単調二次関数なので、有効な$k$は連続セグメントを形成するため、必要なのは最小整数解と最大整数解だけです。

 ## アルゴリズムのチュートリアル

 条件を次のように書き換えます。$k$、次に 2 つの境界不等式を解きます。 

1. リンゴの合計数は次のように表されます。$S = k(k+1)$。 これは、2 つの均等な除算の差の条件を単純化することから直接得られます。 
2. 不明な 2 番目のバスケット サイズを次のように変換します。$Y = S - X = k(k+1) - X$。 これにより、未知の量と既知の量が結び付けられます$X$。 
3. 2 番目のバスケットの有効性を強制します。これは、少なくとも 1 個以下のリンゴが含まれている必要があるためです。$X$、私たちは得ます$1 \le k(k+1) - X \le X-1$。 
4. 純粋な制約に再配置します。$k$:$X+1 \le k(k+1) \le 2X-1$。 これにより、への依存がすべて削除されます。$Y$。 
5. 下限不等式を解く$k(k+1) \ge X+1$最小の整数を見つけることによって$k$二次値が閾値に達する。 
6. 上限不等式を解く$k(k+1) \le 2X-1$最大の整数を見つけることによって$k$閾値を超えないこと。 

結果は、有効な連続した間隔になります。$k$したがって、答えは単純にこの間隔の終点になります。 

### なぜ効果があるのか

 機能$f(k) = k(k+1)$正の整数の場合は厳密に増加します。 問題を境界に変換したら$f(k)$区間内では、すべての有効な解は 1 つの整数に正確に対応します。$k$、隙間はありません。 これにより、最初と最後の整数解を計算することで、考えられるすべての兄弟数を完全に特徴付けることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def floor_sqrt(x):
    r = int(x ** 0.5)
    while (r + 1) * (r + 1) <= x:
        r += 1
    while r * r > x:
        r -= 1
    return r

X = int(input())

# k(k+1) >= X+1
low = X + 1
high = 2 * X - 1

def min_k(low):
    # k^2 + k - low >= 0
    # k >= (-1 + sqrt(1 + 4*low)) / 2
    t = floor_sqrt(1 + 4 * low)
    return ( -1 + t + 1 ) // 2

def max_k(high):
    # k^2 + k - high <= 0
    # k <= (-1 + sqrt(1 + 4*high)) / 2
    t = floor_sqrt(1 + 4 * high)
    return ( -1 + t ) // 2

l = min_k(low)
r = max_k(high)

print(l, r)
```実装の中核は、2次不等式を整数の平方根計算に変換することです。 値が上がるので、$10^{18}$、浮動小数点の平方根は安全ではないため、制御された整数の平方根が使用されます。 

の`min_k`関数は最小の整数を計算します$k$下限を満たしていること。 二次方程式を使用し、切り上げに注意します。 の`max_k`関数は上限に対しても同じことを行いますが、下方に切り捨てられます。 

正確さは、整数安全な平方根計算を使用するかどうかにかかっています。 浮動小数点精度の小さな誤差でも、境界が 1 つずれて正確性が損なわれる可能性があります。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    def floor_sqrt(x):
        r = int(x ** 0.5)
        while (r + 1) * (r + 1) <= x:
            r += 1
        while r * r > x:
            r -= 1
        return r

    X = int(input())

    high = 2 * X - 1

        return ( -1 + t ) // 2

    l = min_k(low)
    r = max_k(high)
