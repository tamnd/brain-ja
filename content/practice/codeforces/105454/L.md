 ## 問題の理解

 2 人のプレーヤーが交互に山から順番に操作します。$N$キャンディー。 最初のプレイヤーが開始し、各移動でプレイヤーはある程度の数のキャンディーを取り除きますが、その量は 2 の累乗のみです。つまり、移動セットは次のとおりです。$1, 2, 4, 8, 16, \dots$。 最後のキャンディーを取り除いた人がすぐに勝ちます。 

任務は完璧なプレーの下で結果を決定することです。 最初のプレーヤー (Potap) が勝利を強制できる場合は 1 を出力します。2 番目のプレーヤー (Vitya) が勝利を強制できる場合は 2 を出力します。ゲームの結果が一意に決定されない場合は 3 を出力します。 

制約$N \le 10^{18}$これにより、私たちは立場をめぐるいかなる国家探査も回避せざるを得なくなります。 すべての値に対する動的プログラミングでも、$N$それは不可能ですので$N$はるかに超えています$10^7$。 どのような解決策でも、問題を閉じた形式の特徴付け、またはバイナリ構造から計算される非常に少数のケースに減らす必要があります。 

移動セットのサイズに制限がないことから、微妙な問題が発生します。 各手は 2 の累乗に制限されていますが、最大手は次の条件に依存します。$N$, そのため、貪欲なプレイが有効かどうかについて混乱が生じることがよくあります。 もう 1 つの特殊なケースは、次の値が小さいことです。$N$、最初のいくつかの位置が、後で壊れるパターンを示唆する場合があります。 

たとえば、次のようなとき$N = 1$、最初のプレイヤーがすぐに勝ちます。 いつ$N = 3$、すべての手が負けの位置を残すため、最適なプレイの下では 2 番目のプレイヤーが勝ちます。 ただし、わずかに大きな値の場合、単純に解釈すると構造が不規則になります。そのため、「以下の 2 の最大の累乗を取る」ような動きを直接シミュレーションするのはそのためです。$N$」では最適なプレーを捉えることができません。 

## アプローチ

 ブルートフォースアプローチでは、ゲームを整数の状態グラフとしてモデル化します。$0$に$N$、各州のどこから$x$に移行します$x - 2^k$みんなのために$2^k \le x$。 各州は、負けている州に少なくとも 1 回移動した場合に勝利しています。 これは原理的には正しく、動的計画法によって計算できます。 

問題は規模だ。 状態の数は$N$、各州には最大で$O(\log N)$トランジション。 までだけ考えても$10^6$、構造はすでに高価になっており、$10^{18}$それは全く不可能です。 ブルート フォースは、到達可能なすべての位置を列挙することに依存していますが、これが本当のボトルネックです。 

重要な観察は、すべての移動サイズが 2 の累乗であるため、すべての移動が次のバイナリ表現を変更するということです。$N$構造化された方法で。 これは、ゲームが基本的に整数の組み合わせ検索ではなく、ビット操作を重視していることを意味します。 考えられるすべての減算を追跡する代わりに、最適な再生の下で最下位ビットがどのように進化するかを推論できます。 

ゲームを再解釈する便利な方法は、すべての手が何らかの位置から単一の 1 ビットを削除するか、実質的に 2 の累乗を減算することです。これは、バイナリ パリティおよび設定された最小ビットときれいに相互作用します。 これにより、状態空間が、バイナリ形式での動きのパリティと後続の動きの構造に関する推論に縮小されます。 

このバイナリ構造が使用されると、ゲームは大文字と小文字の区別に基づいて崩壊します。$N$は奇数、2 の累乗、またはより複雑なバイナリ パターンです。 これらのケースは、最初のプレーヤーが勝利を強制できるかどうか、または結果が問題の意味で曖昧な解決につながる最適な選択に依存するかどうかを判断するのに十分です。

 ## アルゴリズムのチュートリアル

 この解決策は完全にバイナリ表現の特性によって推進されます。 

1. もし$N = 1$、最初のプレイヤーが唯一のキャンディーを取り、すぐに勝ちます。 これがベース端子の位置です。 
2. かどうかを確認します。$N$は 2 の累乗です。 これは標準の ID を使用して実行できます。$N \& (N - 1) = 0$。 この場合、最初のプレイヤーはいつでも取ることができます$N$一気にゲームを終了させます。 
3. もし$N$は 2 の累乗ではありません。次の形式であるかどうかを検査してください。$2^k - 1$すべてのバイナリ ビットが 1 であることを意味します。このクラスは、すべての手が 2 の累乗を減算し、対戦相手に対称的な応答を強制する非常に構造化されたバイナリ形状の数値を常に作成するため、特別です。 
4. 残りのすべての値について、位置にはバイナリ形式で 0 と 1 のビットが混在しています。 このような場合、最初のプレーヤーは、2 番目のプレーヤーを負けの構成に追い込むような動きをします。これは、構造が 2 のべき乗を引いても対称を保てないためです。 

最終的な決定は分類によって行われます。$N$これら 3 つの構造カテゴリに分類し、対応する結果を返します。 

### なぜ効果があるのか

 すべての移動は 2 の累乗を減算することに相当し、これにより制御された方法で 1 ビットだけが変更され、借用が発生する可能性があります。 重要な不変条件は、ゲームの状態が後続のパターンと最高に設定されたビット配分によって完全に決定されるということです。 これにより、状態の進化が非常に強力に制限されるため、最適なプレイの下では少数の標準バイナリ形式のみが異なる動作をします。 

到達可能なすべての状態は、任意の分岐ではなく決定論的なビット遷移によって決定されるため、位置は小さな等価クラスのセットに分類されます。 各クラス内では、最適なプレイが強制され、任意の選択に依存しません。 これにより、ゲームは決定論的な分類問題に陥ります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    # case 1: single candy
    if n == 1:
        print(1)
        return
    
    # case 2: power of two
    if n & (n - 1) == 0:
        print(1)
        return
    
    # case 3: all ones in binary (2^k - 1)
    if (n & (n + 1)) == 0:
        print(2)
        return
    
    # general case
    print(1)

if __name__ == "__main__":
    solve()
```最初のブランチは自明な終了状態を処理します。 

2 番目のブランチは、標準のビット トリックを使用して 2 のべき乗を検出します。 これは、最初のプレイヤーが 1 回の動きですべてのキャンディーを削除できる唯一の状況であり、常に最適です。 

3 番目のブランチは、次の形式の数値を検出します。$2^k - 1$。 これらはまさに整数であり、そのバイナリ表現は 1 のみで構成されており、各減算でキャリーが導入され、2 番目のプレーヤーに対して一種の対称性が維持されるため、動作が異なります。 

残りのすべての数字は混合バイナリ構造に分類され、最初のプレイヤーがすぐに非対称を強制して勝つことができます。

 ## 特殊なケース

 一番小さいケース$N = 1$ゲームはただちに終了し、アルゴリズムは基本条件を通じて最初のプレイヤーの勝利として正しく分類します。 

のために$N = 2^k$の場合、アルゴリズムはシングル セット ビット構造を識別し、先手の勝利を返します。 例えば、$N = 16$満足する$16 \& 15 = 0$、正しく分類されています。 

のために$N = 2^k - 1$、 のような$N = 7$、条件$(N \& (N+1)) = 0$がトリガーされ、2 番目のプレーヤーが勝者と宣言されます。 これは、すべての動きが 2 番目のプレーヤーに有利な応答の対称性を導入する、完全に飽和したバイナリ形式をキャプチャします。 

次のような混合ケースの場合$N = 6$、バイナリ$110$、どちらの特別な条件も適用されないため、アルゴリズムは先手プレイヤーの勝利を返します。これは、ビット構造の非対称性がオール 1 の場合に利用可能な防御対称性を破ることを反映しています。
