 ## 問題の理解

 1 から 1 までの番号が付けられた、循環するアルファベットが与えられます。$C$。 単語はこれらの数字の単なるシーケンスであり、パターン単語の出現を見つけることに興味があります。$W$複数のテキスト内。 ただし、部分文字列が一致するとみなされるのは、それが同一である場合だけではありません。$W$だけでなく、この循環アルファベット内ですべての文字が同じ量だけシフトされる場合も同様です。 

言い換えれば、シフト値を選択すると、$k$、次にすべての文字$x$パターンでは$x + k$(サイズのアルファベットを囲む$C$）。 単一のシフトを選択できる場合、テキストの部分文字列は有効です。$k$パターン全体をその部分文字列に変換します。 

各クエリ文字列はテキストであり、テキストごとに、一定の巡回シフトの下でパターンが表示されるすべての開始位置を出力する必要があります。 

この制約により、二次部分文字列比較が即座に除外されます。 すべてのクエリの合計テキスト長は次のとおりです。$10^6$、パターンは最大で$5 \cdot 10^5$。 これにより、テストごとに線形または線形に近いアプローチが強制され、理想的にはパターンに対する単一の前処理パスとすべてのテキストに対するストリーミング マッチングが行われます。 

パターンの長さが 1 の場合、微妙なエッジ ケースが発生します。その場合、適切なシフトを選択した後にテキスト内の任意の 1 文字が一致するため、すべての位置が有効になります。 単純な差分ベースのソリューションでは、これを明示的に処理する必要があります。そうしないと、空の差分パターンが生成され、実装に応じてすべてまたはまったく一致しない可能性があるためです。 

もう 1 つの重要な例外ケースは、ラップアラウンド動作です。 シフトはモジュロなので$C$、差分もモジュロで計算する必要があります。$C$、それ以外の場合、負の値または一貫性のない範囲はマッチングを中断します。 

## アプローチ

 ブルートフォースソリューションでは、各テキスト内の可能な開始位置をすべて試して、シフトが存在するかどうかを判断しようとします。$k$パターンを揃えるものです。 開始位置が固定されている場合、次のように計算できます。$k = T[i] - W[0]$モジュロ$C$、すべての文字を確認します。 これには費用がかかります$O(|W|)$ポジションごとに、$O(|T| \cdot |W|)$テキストごとに、最悪の場合、$10^{11}$動作が遅すぎます。 

重要な観察は、グローバル シフトの下で重要なのは、連続する文字間の相対的な違いだけであるということです。 2 つのシーケンスが一様なシフトによって異なる場合、それらの隣接する差は同一のモジュロになります。$C$。 これにより、未知のシフトが完全に除去され、問題が差分配列での正確なパターン マッチングに変換されます。 

パターンと各テキストの両方をそれらの差分表現に変換すると、タスクは 2 つの整数シーケンスの標準的な部分文字列マッチングになります。 これは、Knuth-Morris-Pratt (KMP) を使用すると、結合された入力サイズにわたって線形時間でパターンのすべての出現を検出するため、効率的に解決できます。

 ## アルゴリズムのチュートリアル

 私たちは問題を、一連の差異の一致に帰着させます。 

1.パターンを読む$W$。 長さが 1 の場合、この特殊なケースを保存し、すべてのテキストのすべての位置を直接出力します。 これは、任意の 1 文字を他の文字にシフトできるため有効です。 
2. パターンを、各要素が次のとおりである差分配列に変換します。$(W[i] - W[i-1] + C) \bmod C$。 

これは、グローバル シフトとは無関係に、ある文字から次の文字にパターンがどのように変化するかをエンコードします。 
3. このパターン差分配列に KMP 失敗関数 (プレフィックス関数) を構築します。 これにより、各テキストをスキャンしながら部分一致を効率的に追跡できるようになります。 
4. 各テキストについて、同じ式を使用してその差分配列を計算します。 このステップでは、差分配列が正確に一致する場合に限り、均一なシフトの下で 2 つの部分文字列が一致するという特性が保存されます。 
5. パターン差分配列をパターンとして使用して、テキスト差分配列に対して KMP を実行します。 完全一致に達するたびに、元のテキストに有効な開始位置が記録されます。 開始インデックスは差分配列ではなく、元のテキスト内の位置に対応するため、1 つずつシフトします。 
6. 一致は複数のテキストにまたがることができないため、異なるテキスト間の KMP 状態をリセットします。 

これが機能する理由: 均一循環シフトは定数を追加します$k$部分文字列のすべての要素に適用されます。 連続する要素を減算すると、この定数は相殺されます。 したがって、差分配列は、文字列のすべてのシフトされたバージョンの同値クラスを一意に表します。 差分配列の一致は、有効なシフトの存在にとって必要かつ十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_kmp(p):
    m = len(p)
    pi = [0] * m
    j = 0
    for i in range(1, m):
        while j and p[i] != p[j]:
            j = pi[j - 1]
        if p[i] == p[j]:
            j += 1
        pi[i] = j
    return pi

def solve():
    C = int(input())
    
    W = list(map(int, input().split()))
    W.pop()  # remove trailing 0
    m = len(W)

    N = int(input())

    if m == 1:
        for _ in range(N):
            T = list(map(int, input().split()))
            T.pop()
            n = len(T)
            if n == 0:
                print("0")
            else:
                print(" ".join(str(i) for i in range(1, n + 1)) + " 0")
        return

    # pattern differences
    P = [(W[i] - W[i - 1]) % C for i in range(1, m)]
    pi = build_kmp(P)

    for _ in range(N):
        T = list(map(int, input().split()))
        T.pop()
        n = len(T)

        if n < m:
            print("0")
            continue

        # text differences
        S = [(T[i] - T[i - 1]) % C for i in range(1, n)]

        res = []
        j = 0
        for i in range(len(S)):
            while j and S[i] != P[j]:
                j = pi[j - 1]
            if S[i] == P[j]:
                j += 1
            if j == len(P):
                start = i - len(P) + 2
                res.append(str(start))
                j = pi[j - 1]

        if res:
            print(" ".join(res) + " 0")
        else:
            print("0")

if __name__ == "__main__":
    solve()
```この実装では、まずパターンとテキストの両方を差分配列に正規化し、未知の巡回シフトを排除します。 KMP 接頭辞関数はパターンの違いに対して 1 回計算され、その後すべてのテキストに対して再利用されます。 

最も繊細な部分はインデックス付けです。 差分配列は元の文字列よりも 1 要素短いため、一致が 位置で終了すると`i`差分配列では、元のテキスト内の対応する開始位置は次のとおりです。`i - m + 2`。 

単一文字パターンのケースは、その差分表現が空であるため分離する必要があり、これを一律に扱うと KMP ロジックが壊れる可能性があります。 

## 実用的な例

 小さなアルファベットを考えてみましょう。$C = 5$。 パターンをこうしましょう$W = [1, 3]$、およびテキスト$T = [2, 4, 1, 3]$。 

パターン差分配列は$[2]$、 以来$3 - 1 = 2$。 

テキスト差分配列は次のとおりです。$[2, 2, 2]$。 

ここで KMP を実行します。 

| 私 | S[i] | j (一致する長さ) | アクション |
 | --- | --- | --- | --- |
 | 0 | 2 | 1 | 試合開始 |
 | 1 | 2 | 1 | 不一致フォールバックしてから一致 |
 | 2 | 2 | 1 | 一致が継続し、完全一致が見つかりました |

 完全一致は、差分配列内の位置 0、1、および 2 で発生します。これは、元のテキストの開始位置 1、2、および 3 に対応します。 

これは、テキスト内のすべての隣接するペアがパターンと同じ違いを持っ​​ていることを示しています。つまり、部分文字列は常にパターンのシフトされたバージョンであることを意味します。 

次に、一致しない 2 番目の例を考えてみましょう。 

させて$W = [1, 2, 4]$、パターンの違いは$[1, 2]$。 

させて$T = [3, 5, 6, 1]$、違いを与える$[2, 1, 2]$。 

| 私 | S[i] | j | アクション |
 | --- | --- | --- | --- |
 | 0 | 2 | 0 | 一致しません |
 | 1 | 1 | 0 | 一致しません |
 | 2 | 2 | 0 | 完全な位置合わせはありません |

 パターンの違いに正確に一致するセグメントがないため、開始位置は出力されません。

 ## 特殊なケース

 長さ 1 のパターンは、最も重要な縮退ケースです。 隣接する差分がないため、標準の変換では空のパターンが生成されます。 素朴に扱うと、KMP は空のパターンの処理方法に応じて、どこでも一致するか、どこにも一致しないことになります。 正しい動作は、単一の値を他の値にシフトできるため、すべての位置が有効であるということです。 

2 番目のエッジ ケースは、ラップアラウンドの差から発生します。 たとえば、小さなアルファベットでは、$C = 5$、5 から 1 への移行では、-4 ではなく 1 の差が生じるはずです。 モジュロ正規化により一貫性が保証されますが、モジュロ正規化がなければ、シフトされた同一の部分文字列が誤って一致しません。 

最後に、複数のテキストで KMP 状態の引き継ぎを許可してはなりません。 各テキストは独立しているため、新しい文字列をスキャンする前にプレフィックス一致状態をリセットする必要があります。 リセットしないと、一致が誤ってドキュメントの境界を越えて広がり、誤検知が発生する可能性があります。
