 ## 解決策
 ## 問題の理解

 長さ _n_ の文字列として表される 1 次元のマインスイーパ フィールドがあります。 各文字は、爆弾「*」、未知の「?」、または数字 0、1、または 2 にすることができます。数字は、そのセルに直接隣接する爆弾の数を示します。 私たちの課題は、「?」を埋める方法の数を数えるということです。 フィールドが有効になるように爆弾または数字を含むセル (モジュロ 10^9+7)。 

この制約は、_n_ が 10^6 までの大きさになる可能性があることを意味します。 制限時間が 2 秒の場合、単純な方法で爆弾の配置をすべて繰り返すソリューションでは、最悪の場合 2^n 回の操作が必要となり、天文学的に時間がかかります。 このため、動的計画法または線形時間アプローチを見つける必要があります。 

明らかではないエッジ ケースは、フィールドに「2??1」などの連続した数字がある場合です。 「？」を埋める迂闊なアプローチ。 隣接する番号を考慮せずに貪欲に実行すると、無効な構成が生成される可能性があります。 もう 1 つの注意が必要なケースは配列の境界にあり、先頭または末尾の数値に隣接する数値が 1 つしかありません (例: "2?*" または "?2")。 境界条件を無視すると、不可能な構成がカウントされる可能性があります。 

## アプローチ

 ブルートフォース手法では、「?」ごとに爆弾と数字のあらゆる組み合わせを試します。 _n_ 個の未知数の場合、それは 2^n 通りの可能性ですが、n = 10^6 の場合は明らかに不可能です。 すべての構成を生成できれば、各構成をマインスイーパのルールに照らしてチェックできるため、これは概念的に機能します。 しかし、n が 20 または 25 を超えると、妥当な時間内に終了することができなくなります。 

重要な観察は、各セルの値がそれ自体とそのすぐ隣のセルにのみ依存するということです。 このローカル依存関係は、動的プログラミングを使用できることを示唆しています。`dp[i][state]`最初の有効な構成の数を表します。`i`最後の 1 つまたは 2 つのセルの状態を考慮したセル。 現在のセルの数値は前後のセルを参照するため、前の 1 つまたは 2 つのセルに爆弾があるかどうかを追跡するだけで済みます。 この観測により、状態空間が指数関数から _n_ に依存しない小さな定数に減少し、線形時間の解が得られます。 

ブルートフォースは組み合わせ爆発により失敗しますが、DP アプローチは問題に固有の「ローカル制約」特性を利用します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 地方州とのDP | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力文字列を前処理し、数値を整数に変換し、「?」を保持します。 および「*」は特殊記号として使用されます。 これにより、DP 更新での均一な処理が保証されます。 
2. 動的プログラミング配列を定義する`dp[i][b]`、 どこ`i`は現在のセルのインデックスであり、`b`前のセル内の爆弾の数です (0 または 1)。`dp[i][b]`で終わるプレフィックスの有効な埋め込みの数をカウントします。`i`前回の爆弾の状態を考えると。 
3. DP を初期化します。インデックス 0 で、最初のセルが不明な「?」の場合は、爆弾と空の配置の両方を検討し、インデックス 0 および 1 の数値制約との一貫性をチェックします。最初のセルが爆弾「*」の場合は、初期化します。`dp[0][1] = 1`; 数値の場合は初期化します`dp[0][0] = 1`。 
4. 各セルを反復処理します。`i`1 から n-1 まで。 考えられる前の状態 (爆弾かどうか) ごとに、配置がセルの数の制約をすべて満たしている場合に限り、爆弾を配置するか空のままにしてみます。`i-1`。 アップデート`dp[i][new_b]`それに応じて。 
5. すべてのセルを処理した後の答えは、次の合計になります。`dp[n-1][0]`そして`dp[n-1][1]`、最後のセルが空または爆弾で終わるすべての有効な構成を表します。 10^9+7 を法とする和を求めます。 

このアルゴリズムが機能するのは、各ステップで有効なプレフィックスのみを繰り越すためです。 DP の不変条件は次のとおりです。`dp[i][b]`最初の構成をすべて正確にカウントします。`i+1`マインスイーパのルールを遵守するセル。 無効な構成は数の制約をチェックするときにすぐにフィルタリングされるため、無効な組み合わせが伝播することはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def count_configurations(s):
    n = len(s)
    s = list(s)
    
    dp0 = 0  # previous cell has no bomb
    dp1 = 0  # previous cell has bomb
    
    # Initialize first cell
    if s[0] == '*':
        dp1 = 1
    elif s[0] == '?':
        dp0 = 1
        dp1 = 1
    else:
        dp0 = 1
    
    for i in range(1, n):
        ndp0, ndp1 = 0, 0
        for prev_bomb, count in [(0, dp0), (1, dp1)]:
            if count == 0:
                continue
            for cur_bomb in [0, 1]:
                if s[i] == '*' and cur_bomb == 0:
                    continue
                if s[i] != '*' and cur_bomb == 1:
                    if s[i] != '?':
                        continue
                # Check number constraint on previous cell
                prev_val = s[i-1]
                bombs_around = prev_bomb + cur_bomb
                if prev_val != '?' and prev_val != '*':
                    if bombs_around != int(prev_val):
                        continue
                if cur_bomb:
                    ndp1 = (ndp1 + count) % MOD
                else:
                    ndp0 = (ndp0 + count) % MOD
        dp0, dp1 = ndp0, ndp1
    
    # Check the last cell's number constraint
    last_val = s[-1]
    result = 0
    if last_val == '*':
        result = dp1
    elif last_val == '?':
        result = (dp0 + dp1) % MOD
    else:
        result = dp0
    return result

s = input().strip()
print(count_configurations(s))
```このソリューションは、爆弾または空の最後のセルで終わる有効なシーケンスの数を明示的に追跡します。 微妙な部分は、次を使用して前のセルの数値制約をチェックすることです。`prev_bomb + cur_bomb`DPを更新する前に。 境界を慎重に処理することで、端の数値が正しく検証されるようになります。 

## 実用的な例

 **入力:**`?01???`| 私 | dp0 | dp1 | 説明 |
 | --- | --- | --- | --- |
 | 0 | 1 | 1 | 最初のセルは不明です: 爆弾または空の可能性があります |
 | 1 | 1 | 1 | 2 番目のセル '0': 前の爆弾 = 1 -> 無効、prev=0 のみ許可 |
 | 2 | 2 | 0 | 3 番目のセル '1': 以前の爆弾は 0 または 1 に一致し、カウントを更新します。 
| 3 | 2 | 2 | 4番目の「？」 -> 前に指定した場合、両方の配置が有効です |
 | 4 | 4 | 0 | 5番目の「？」 前の数値によって制約される |
 | 5 | 4 | 0 | 6番目の「？」 前の数値によって制約される |

 答え = 4。 

**入力:**`*2?1`トレースは、DP が隣接する配置と「2」を満たす配置のみを許可することを検証し、1 より大きい数値の正しい処理を示します。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | 各セルは最大 4 つのトランジション (前の爆弾/爆弾なし × 現在の爆弾/爆弾なし) で処理されます。 
| スペース | お(1) | 定数空間 | 反復ごとに 2 つの DP 状態のみが保存されます。 

n ≤ 10^6 の場合、O(n) 操作は 2 秒の制限内に十分収まります。 このソリューションでは少数の整数のみを使用するため、メモリは無視できます。
