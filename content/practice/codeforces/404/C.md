 ## 解決策
 ## 問題の理解

 各頂点が最大 _k_ 個のエッジを持つことができるという制約の下で、1 つの頂点からの最短距離のリストから無向接続グラフを再構築するように求められます。 入力は頂点の数を与えます`n`、最大次数`k`、および配列`d`長さの`n`どこ`d[i]`選択した開始頂点から頂点までの距離を表します`i`。 グラフは、距離と次数の制限と一致しており、自己ループや複数のエッジを含まない限り、どのような構造でも構いません。 

主な制約は次のとおりです。`n`最大 10^5 であり、各頂点には最大次数があります`k`。 これは、どのような解もほぼ線形であるか、O(n log n) でなければならないことを意味します。 考えられるすべてのエッジの組み合わせをチェックしようとするアルゴリズムでは O(n^2) の演算が必要ですが、これでは遅すぎます。 256 MB の制限内では、最大 10^5 のエッジを持つ 10^5 の頂点が許容されるため、隣接リストや同様の構造を保存するにはメモリが十分です。 

自明ではないエッジ ケースには、次のものが含まれます。開始点を除くすべての頂点の距離が 0 であるグラフ。これは自明です。 一部の距離値が欠落しており、構築が不可能なグラフ。 そして、次のような場合`k`同じ距離にある頂点を接続するには小さすぎるため、グラフが切断されてしまいます。 たとえば、次の場合`n = 3, k = 1`そして`d = [0, 1, 2]`の場合、距離 2 の頂点は複数の頂点に接続できず、次数を超えずに距離 1 に到達する他の選択肢がないため、有効なグラフを構築できません。 

## アプローチ

 ブルートフォース手法では、距離に基づいて貪欲に頂点を接続しようとします。各頂点について、すべての距離が満たされるまで、1 つ少ない距離で任意の頂点に接続しようとします。 これは原理的には正しいですが、遅いため、頂点ごとに最大で反復処理が行われる可能性があります。`n`これは、n = 10^5 では実行不可能な O(n^2) の複雑さを与えます。 

重要な洞察は、距離レベルを活用することです。 頂点は、開始点からの距離に基づいてグループ化できます。 距離のあるすべての頂点`d`離れたところにある頂点に接続する必要があります`d-1`。 レベル内では、頂点は相互に接続しません (距離に違反してショートカットが作成されるため)。 これにより、BFS のようなツリー構造をレベルごとに構築できます。 次数制約`k`各頂点がすでに使用しているエッジの数を追跡し、頂点がそれを超えていないことを確認することによって処理されます。`k`。 

ブルート フォースは考えられるすべての接続を考慮するため機能しますが、n が大きい場合は失敗します。 レベルベースの BFS アプローチが機能するのは、距離によって厳密な階層 (距離にある頂点) が課されるためです。`d`離れた頂点にのみ接続できます`d-1`（または`d+1`後ろ向きの場合)、これにより、距離に矛盾するサイクルが防止されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n^2) | 遅すぎる |
 | レベル BFS / 距離グループ化 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 距離 0 の頂点を特定します。これが開始頂点、つまり BFS ツリーのルートです。 距離が 0 以上の頂点がない場合は、入力が矛盾しているため -1 を出力します。 
2. すべての頂点を開始点からの距離に基づいてグループ化します。 辞書またはリストのリストを使用します。`level[d]`遠くにあるすべての頂点が含まれます`d`。 0 と最大距離の間のレベルが空の場合、ギャップは到達できない距離があることを意味するため、-1 を出力します。 
3. 各頂点の次数カウンターを 0 から初期化します。これにより、各頂点がすでに持っているエッジの数が追跡されます。 
4. 頂点をレベルごとに接続します。 距離の場合`d = 1`各頂点の max_ distance まで`v`レベルで`d`、親頂点を選択します`u`レベルから`d-1`学位容量が残っていること。 そのような親が存在しない場合、グラフは形成できず、-1 が出力されます。 
5. 接続ごとに、両方の頂点の次数カウンターをインクリメントします。 に達した場合は、子を親に割り当てるのを停止します。`k`。 
6. すべてのエッジを収集し、合計数と各エッジを出力します。 有効な親の割り当ては機能するため、複数のソリューションを使用できます。 

機能する理由: 離れたところにあるすべての頂点`d`遠く離れた頂点に接続することが保証されています`d-1`。 接続する前に容量をチェックするため、次数制限を超える頂点はありません。 エッジは連続したレベル間でのみ形成されるため、距離は維持されます。 BFS ツリーはすべての頂点にまたがるため、接続が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
d = list(map(int, input().split()))

from collections import defaultdict, deque

# Step 1: check for valid root
roots = [i for i, dist in enumerate(d) if dist == 0]
if len(roots) != 1:
    print(-1)
    sys.exit()

root = roots[0]

# Step 2: group by distance
levels = defaultdict(list)
max_dist = 0
for i, dist in enumerate(d):
    levels[dist].append(i)
    max_dist = max(max_dist, dist)

# Step 3: check for missing levels
for dist in range(max_dist + 1):
    if not levels[dist]:
        print(-1)
        sys.exit()

# Step 4: assign edges
edges = []
degree = [0] * n

for dist in range(1, max_dist + 1):
    parents = deque(levels[dist - 1])
    if not parents:
        print(-1)
        sys.exit()
    for v in levels[dist]:
        # find parent with free degree
        while parents and degree[parents[0]] >= k:
            parents.popleft()
        if not parents:
            print(-1)
            sys.exit()
        u = parents[0]
        edges.append((u + 1, v + 1))
        degree[u] += 1
        degree[v] += 1
        # keep parent in deque if it can take more
        if degree[u] >= k:
            parents.popleft()

print(len(edges))
for u, v in edges:
    print(u, v)
```このソリューションでは、最初にルートを見つけ、距離によって頂点をグループ化し、次にレベルごとにエッジを割り当てます。 の`degree`配列により、決して超過しないことが保証されます`k`頂点ごとの接続。 使用する`deque`親が容量に達したときに効率的にポップできるようになります。
