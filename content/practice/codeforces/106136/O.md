 ## 問題の理解

 私たちは、各ノードが整数の重みを持つツリーを扱っています。 個別のノードのペアごとに、それらの間の一意のパスを調べ、そのパスに沿ったすべてのノードの重みを収集します。 このコレクションから、パス上の最小重みとパス上のすべての重みの最大公約数という 2 つの値を計算します。 

ペアは、これら 2 つの量が一致する場合にのみ値を与えます。 パス上の最小値がパスの gcd と等しい場合、そのペアを有効と呼び、この共有数に等しい値を割り当てます。 タスクは、すべての有効なペアでこの値を合計し、一様にランダムなノードのペアで期待される値を返すことです。つまり、順序付けされていないペアの合計数で割ります。 

主な問題点は、両方の制約にグローバル パス プロパティが関係していることです。 最小値はパス上の最も弱いノードに依存しますが、gcd はパス上のすべてのノードの割り算に依存します。 ペアごとの単純なチェックでは、パス全体をスキャンする必要がありますが、ツリーの高さは線形であり、すべてのペアに対して実行すると速度が非常に遅くなります。 

この制約は、テスト ケースあたり最大 100,000 ノード、合計 300,000 ノードを意味するため、すべてのペアを明示的に検査したり、ペアごとのパス情報を再計算したりするソリューションは、直ちに実行不可能になります。 平$O(n^2)$推論は限界をはるかに超えており、さらには$O(n \log n)$ペアごとに崩壊に近づきます。 

最低限の条件だけに注目すると、微妙な失敗例が現れます。 たとえば、パスの最小値は 2 ですが、2 の倍数ではないノードが 1 つあるため、gcd は 1 になる場合があります。 もう 1 つの失敗例は、すべてのノードが強い割り算制約を尊重する場合にのみ gcd が最小値と一致する可能性があるため、gcd が等しいだけで十分であると仮定することです。

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    inv2 = (MOD + 1) // 2

    for _ in range(t):
        n = int(input())
        g = [[] for _ in range(n)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            g[u].append(v)
            g[v].append(u)

        a = list(map(int, input().split()))

        mx = max(a)
        pos = [[] for _ in range(mx + 1)]
        for i, x in enumerate(a):
            pos[x].append(i)

        parent = list(range(n))
        size = [0] * n
        active = [False] * n

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            x = find(x)
            y = find(y)
            if x == y:
                return
            if size[x] < size[y]:
                x, y = y, x
            parent[y] = x
            size[x] += size[y]

        def build(nodes):
            for i in nodes:
                parent[i] = i
                size[i] = 1
                active[i] = True
            for i in nodes:
                for j in g[i]:
                    if active[j]:
                        union(i, j)

            res = 0
            comp = {}
            for i in nodes:
                r = find(i)
                comp[r] = comp.get(r, 0) + 1
            for v in comp.values():
                res += v * (v - 1) // 2
            for i in nodes:
                active[i] = False
            return res

        total = 0

        for k in range(1, mx + 1):
            nodes = []
            for mul in range(k, mx + 1, k):
                nodes.extend(pos[mul])
            if len(nodes) < 2:
                continue

            all_pairs = build(nodes)

            bad_nodes = [u for u in nodes if a[u] != k]
            bad_pairs = build(bad_nodes) if bad_nodes else 0

            total += k * (all_pairs - bad_pairs)

        inv_n2 = pow(n * (n - 1) // 2, MOD - 2, MOD)
        print(total % MOD * inv_n2 % MOD)

if __name__ == "__main__":
    solve()

微妙な実装の詳細は、DSU 状態を次の手順に従ってリセットする必要があることです。$k$そうでない場合、異なる値のコンポーネントが干渉する可能性があります。 もう 1 つは、隣接性チェックが一時的なアクティブ化マーカーに依存しているため、エッジは現在のエッジの内側のみとみなされることです。$S_k$。
