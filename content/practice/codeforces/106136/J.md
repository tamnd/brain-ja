 ## 問題の理解

 すでに非常に厳密な構造を持った整数の初期マルチセットが与えられています。これは長さの等差数列です。$n$、から始まります$a_1$共通の違いがある$d$。 したがって、スターティングセットは完全に決定され、自動的にソートされます。 

次に、2 人のプレーヤーが交代で新しい正の整数をこのマルチセットに追加します。 各プレイヤーは正確に追加します$m$数値なので、最終的なマルチセットには以下が含まれます$n + 2m$要素。 

すべての挿入後、最終的なマルチセットを並べ替えて、連続する 2 つの要素が同じコンポーネントに属する連結コンポーネントに分割します (それらの差が最大であれば)。$k$。 同等に、各要素はグラフ内のノードであり、エッジは距離が最大で次のペアを接続します。$k$; 答えは、このグラフの連結成分の数です。 

どちらのプレイヤーも完全に敵対的です。最初のプレイヤーはコンポーネントの最終的な数を最大化しようとし、2 番目のプレイヤーはそれを最小化しようとします。 

制約は非常に小さく、すべてのパラメーターは最大 100 で、テスト ケースの数は最大 100 です。 これは、解法に大きな漸近線が必要ないことを意味します。 テストごとに 2 次または 3 次であっても、有限状態空間での展開または理由を明示的にシミュレートするアプローチであれば十分です。 

主な問題は、挿入によって接続がグローバルに変更される可能性があることです。 挿入された 1 つの値は、それ自体を新しいコンポーネントとして分離することも、距離内に到達した場合には複数の既存のコンポーネントをマージすることもできます。$k$異なるグループのポイントの数。 

最初の進行がすでに切断されている場合、微妙なエッジケースが表示されます。 たとえば、次の場合$d > k$の場合、すべての隣接するペアは最初に分離されるため、各要素は独自のコンポーネントとして開始されます。 挿入時に構造が「安定」しているという単純な仮定は誤りです。適切に配置された 1 つの挿入によって複数のコンポーネントが一度にマージされる可能性があるためです。 

もう一つの重要な事例は、$k = 0$。 この場合、接続性は同一の値のみをグループ化します。 新しい個別の値はすぐに新しいコンポーネントを作成し、重複のみがカウントの増加を回避できます。 多くの誤ったアプローチは、暗黙のうちに次のように仮定しています。$k > 0$。 

## アプローチ

 ゲームについて考える強引な方法は、考えられるすべての動きのシーケンスをシミュレートすることです。 各挿入後、隣接する差分を並べ替えてスキャンすることにより、連結成分を再計算します。 これは正しいですが、各プレイヤーは任意の正の整数を選択できるため、分岐要素が大きくなります。 選択肢を「興味深い」位置に限定したとしても、ゲーム ツリーは深みとともに指数関数的に成長します。$2m$、完全な検索が不可能になります。 

重要な観察は、接続性は内部の相対距離にのみ依存するということです。$k$。 これにより、状態はソートされた構造によって効果的に決定されますが、さらに重要なのは、コンポーネントの数を増やしたいプレイヤーが、他のすべてから遠く離れた値を配置することによって害を受けることがないことです。 このような移動により、常に新しい孤立したコンポーネントが作成されます。 

一方、相手は距離内にある数字を配置することによってのみコンポーネントの数を減らすことができます。$k$複数の既存のコンポーネントの要素を結合し、それらをマージします。 ただし、マージには構造的な制約があり、既存のコンポーネントがすでに数値行内で十分に近くにある必要があります。 

この問題では、プレーヤーはいつでも任意に大きいか小さい数値を導入できるため、最小化プレーヤーによって制御された方法で構造がマージ可能になるように「強制」されることはありません。 2 番目のプレーヤーがコンポーネントを削減しようとする試みは、最初のプレーヤーが離れた要素を挿入することで直ちにスプレッドを再度拡大し、既存のすべてのクラスターから確実に隔離されるようにすることで対抗できます。 

これは単純化につながります。最大化プレーヤーによる各移動は、事実上 1 つの新しい接続コンポーネントを保証しますが、最小化プレーヤーはコンポーネントを永久に削除することはできません。 したがって、ゲームの価値は先手が何回動くかによってのみ決まります。 

マディが先に動き、両方のプレイヤーが正確に行動するため、$m$動くとマディが得する$m$移動し、強制することができます$m$追加の分離コンポーネント。 初期構造は、それ自体のコンポーネントのベースライン数に寄与します。これは、初期進行が既に破られているかどうかによってのみ決まります。$k$。 

もし$d \le k$、初期配列は完全に接続されているため、1 つのコンポーネントから始まります。 もし$d > k$、すべての要素が分離されており、$n$コンポーネント。 

これにより、問題全体が、コンポーネントの初期数を計算してから追加することに縮小されます。$m$。

 ## アルゴリズムのチュートリアル

 1. 最初の等差数列内の連結成分の数を計算します。 これは、隣接する差分がしきい値内にあるかどうかにのみ依存します。$k$。 もし$d \le k$、すべての点が 1 つのコンポーネントに接続されます。 それ以外の場合、各点は単独で存在し、$n$コンポーネント。 
2. マディが常に正確に持っていることを観察してください。$m$移動し、挿入された各値が既存のすべてのポイントから十分離れた位置に配置されて、新しい独立したコンポーネントが形成されることを確認できます。 これにより、$m$コンポーネント。 
3. ローカルのマージ効果は後続の遠隔挿入によって構造的に元に戻される可能性があり、マージにはゲームによって強制されない既存の近接性が必要であるため、Baddy の動きによって総コンポーネント数を永続的に減らすことはできないことに注意してください。 
4. 2 つの効果を結合します。コンポーネントの最終的な数は、初期の数に加えた数になります。$m$。 

### なぜ効果があるのか

 不変条件は、マディが移動ごとに少なくとも 1 つの新しく作成された分離コンポーネントを常に維持できるということです。これは、マディが値を外部に配置できるためです。$k$- 既存のすべての要素の近傍。 接続性は距離のみに依存するため、そのようなポイントは明示的にマージされない限り独自のコンポーネント内に残ることが保証され、対戦相手は将来の配置を制限することなく永久に強制することはできません。 したがって、総コンポーネント数は次のように決定論的に増加します。$m$初期状態を超えています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, a1, d, m, k = map(int, input().split())

        if d <= k:
            initial = 1
        else:
            initial = n

        print(initial + m)

if __name__ == "__main__":
    solve()
```この実装では、問題が 2 つの独立した部分に分割されます。つまり、初期接続の計算と、ゲームの最終的な効果の適用です。 

唯一の微妙な点は、等差数列の正しい処理です。 すべてのギャップは等しいので、$d$、配列を構築する必要はありません。 構造は比較によって完全に決定されます$d$そして$k$。

 ## 特殊なケース

 いつ$k = 0$、接続性は等価性チェックに崩壊します。 最初の等差数列にはすでにすべての個別の値が含まれているため、次のように始まります。$n$コンポーネント。 各 Maddy 挿入では常に新しい値を選択できるため、コンポーネント数が増加し、最終的な値は次のようになります。$n + m$。 複製が唯一の中立的な操作であるため、バディの動きでは数を減らすことができません。 

いつ$d \le k$、最初の配列は単一の接続されたブロックです。 挿入が発生したとしても、Maddy は依然として遠く離れた値を導入し、新しい分離コンポーネントを即座に形成することができるため、システムは 1 から 2 に成長します。$1 + m$。 

いつ$d > k$、すべての初期要素が分離されます。 同じ推論が当てはまりますが、基本は$n$、最終的な答えは次のようになります$n + m$。
