 ## 解決策
 ## 問題の理解

 材料の鮮度値のリストと 2 つの固定レシピ係数が与えられます。 毎日、マディは未使用の材料を 2 つだけ選び、それらを 2 つのレシピに任意の順序で割り当てなければなりません。 選択した値が$a$そして$b$、レシピ係数は次のとおりです。$x$そして$y$、その日の貢献度は次のいずれかになります$ax + by$または$ay + bx$、材料をレシピに割り当てる方法に応じて異なります。 2 つの割り当てのうち、より良い方が常に採用されます。 

一日を通して、各材料は最大 1 回しか使用できませんが、マディが早期に停止して一部の材料が未使用のままになる場合があります。 目標は、毎日の貢献の合計が最大化されるように、形成するペアの数と、材料のペアと割り当ての方法を選択することです。 

制約は大きく、最大で$10^5$テストケースごとの成分と最大$3 \cdot 10^5$合計。 これにより、二次ペアリング戦略やすべてのマッチングを試行するアプローチが即座に除外されます。 平$O(n^2)$テスト ケースごとの推論は限界をはるかに超えているため、解決策は問題を並べ替えと線形または線形に近いスキャンに減らす必要があります。 

ここでは、いくつかのエッジ動作が重要です。 まず、ペアリングはオプションであるため、すべてのペアがマイナスの寄与を与える可能性があります。その場合、何も調理しないことを選択できるため、正解はゼロになります。 第二に、各ペア内の順序は柔軟であるため、問題は基本的に、固定された順序のペアではなく、ペア内で「役割」を割り当てる方法にあります。 第三に、係数$x$そして$y$ネガティブになる可能性があり、素朴な貪欲な直感が覆される可能性があります。 

たとえば、すべての成分が陽性であるが、両方とも陽性である場合、$x$そして$y$が負の場合、すべてのペアが合計を減らすため、ペアを選択しないと最適な答えはゼロになります。 要素を常にペアにする貪欲な戦略では、誤って否定的な結果が生成されます。 

## アプローチ

 この強引なアイデアは、組み合わせを選択し、材料を日にちに割り当てるあらゆる方法を試してみることです。 つまり、均等なサイズの要素のサブセットを選択し、それらをペアに分割し、各ペアに対して割り当てを決定することを意味します。$x$そして$y$。 サブセットを修正し、すべてのペアをカウントすることは、本質的にすでに指数関数的であり、それを超えています$n$これは超指数関数的に増加する要素です。 これは、非常に小さな入力を超えるとすぐに失敗します。 

重要な観察は、単一のペア内で、より適切な割り当てにより、より大きな成分の間のより大きな係数が常に与えられるということです。$x$そして$y$。 これにより、ペア内のあいまいさが完全に取り除かれます。各ペアは「より大きな要素の時間を取得する」ように動作します。$\max(x,y)$小さい要素時間に加えて$\min(x,y)$”。

 これにより、問題は要素の選択とグループ化に変わりますが、グループ化の構造ははるかに単純になり、各ペア内の大きい要素の識別のみが重要になります。 

書き換えられると、ペアの寄与は両方の要素からの固定ベースラインに加えて、より大きい要素に比例する追加ボーナスになります。 これにより、問題はいくつかの要素を選択し、それらを任意にペアにし、どの要素が「ペア最大値」になるかを選択することに変わります。 その後、構造はさらに崩壊します。サブセットが固定されると、最適なペアリングは、選択した最大値の合計を最大化することになります。これは、単にそのサブセット内の最大の要素を最大値とすることを意味します。 

これにより、問題は、それらをどのように組み合わせるかではなく、いくつの上位要素を取るかを選択することになります。

 ## アルゴリズムのチュートリアル

 まず係数を正規化して、一方が大きい方として扱われ、もう一方が小さい方として扱われるようにします。これは、各ペア内の割り当てによって常に大きい方の係数が大きい方の要素に揃えられるためです。 

1. 比較する$x$そして$y$、そしてさせてください$x_1 = \max(x,y)$、$x_2 = \min(x,y)$。 すべてのペアの寄与をこれら 2 つの値に関して書き換えます。 
2. どのペアでも$(a,b)$と$a \ge b$、最適な割り当てが貢献します$a \cdot x_1 + b \cdot x_2$。 これにより、ペア内の各ポジションの役割が分離されます。 
3. セットを考える$S$使用するために選択された要素の数。 使用する場合$2k$要素、それらが形成する$k$ペア。 合計貢献度は 2 つの部分に分割されます。使用されるすべての要素は、その値に次の値を乗算して貢献します。$x_2$、各ペアは次のボーナスに等しい追加ボーナスを提供します。$(x_1 - x_2)$そのペア内の大きい要素の倍になります。 
4. これは、目的が次の形式の関数を最大化することになることを意味します。 

合計 =$x_2 \cdot \sum S + (x_1 - x_2) \cdot \sum \text{(pair maxima)}$。 
5. 固定サブセットの場合$S$、最適なペアリングは、ペアの最大値の合計を最大化することです。 これは、各ペアがその最大値を 1 回だけ正確に提供するため、任意にペアにすることで実現されます。 したがって、最大値の合計は、最大の要素を選択することによって最大化されます。$S$最大値として。 
6. したがって、次の場合$|S| = 2k$、の最適な寄与$S$は次のようになります:$x_2 \cdot \sum S + (x_1 - x_2) \cdot \sum$最大の$k$の要素$S$。 
7. すべての要素を降順に並べ替えます。 固定の場合$k$、最適なサブセット$S$単に最初のものです$2k$選択した要素をより大きな未使用の要素に置き換えると、両方の合計項が改善されるだけであるためです。 
8. それぞれについて$k$、サイズの接頭辞からスコアを計算します$2k$: すべての合計$2k$要素とその上位の合計$k$その中で（最初のものは）$k$ソートされた配列内)。 
9. 全体の最大値を取る$k$、 含む$k=0$、これはペアを選択しないことを表します。 

### なぜ効果があるのか

 このアルゴリズムは単調交換特性に依存しています。 スコアの両方のコンポーネントの要素値が単調であるため、有効なソリューションは、目標を下げることなく、利用可能な最大の要素を使用するソリューションに変換できます。 ソートされた配列の接頭辞に制限されると、ペアリング構造は実現可能性に影響を与えなくなり、選択された要素の数のみが影響を及ぼします。 合計と「上半分の合計」への分解により、固定サイズのサブセット内で最適な内部配置が標準的になることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    out = []
    
    for _ in range(T):
        n, x, y = map(int, input().split())
        a = list(map(int, input().split()))
        
        x1 = max(x, y)
        x2 = min(x, y)
        delta = x1 - x2
        
        a.sort(reverse=True)
        
        pref = [0] * (n + 1)
        for i in range(n):
            pref[i + 1] = pref[i] + a[i]
        
        ans = 0
        
        for k in range(n // 2 + 1):
            total_sum = pref[2 * k]
            top_sum = pref[k]
            val = x2 * total_sum + delta * top_sum
            if val > ans:
                ans = val
        
        out.append(str(ans))
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この解決策は、常に大きい乗数と小さい乗数を区別できるように係数を正規化することから始まります。 配列を降順に並べ替えると、プレフィックスから最適な要素が選択されるようになります。 

プレフィックス合計配列を使用すると、プレフィックスの合計とその上半分の合計の両方を定数時間で計算できます。 可能なペア数ごとに$k$、最初の段階から得られる正確な最良の値を評価します。$2k$要素。 答えは、空の選択肢を含む、そのようなすべての構成の最大値です。 

実装には慎重に以下が含まれます$k=0$そのため、すべての組み合わせが有害であるケースは自然にゼロに解決されます。 

## 実用的な例

 小さな入力を考えてみましょう。$a = [5, 1, 4, 2]$、$x=3$、$y=1$。 

正規化します$x_1=3$、$x_2=1$なので、デルタは 2 です。 並べ替え後:$[5,4,2,1]$。 

| k | プレフィックス (2k) | 合計(2k) | 上位 k の合計 | 値 |
 | --- | --- | --- | --- | --- |
 | 0 | [] | 0 | 0 | 0 |
 | 1 | [5,4] | 9 | 5 | 1・9 + 2・5 = 19 |
 | 2 | [5,4,2,1] | 12 | 9 | 1・12 + 2・9 = 30 |

 最適な選択では、すべての要素が使用され、プレフィックス内で自然にペアになります。 

ここで負の係数を考えてみましょう。$a = [3,2,1]$、$x=-5$、$y=-2$。 

正規化後は、$x_1=-2$、$x_2=-5$、デルタは 3 です。並べ替えると次のようになります。$[3,2,1]$。 

| k | プレフィックス (2k) | 合計(2k) | 上位 k の合計 | 値 |
 | --- | --- | --- | --- | --- |
 | 0 | [] | 0 | 0 | 0 |
 | 1 | [3,2] | 5 | 3 | -5・5 + 3・3 = -16 |

 ここでの最良の答えは 0 で、まったく調理しないことに対応し、アルゴリズムはこれを正しく保持します。

 ## 特殊なケース

 すべての係数が負の寄与につながる場合でも、アルゴリズムは次のことを考慮します。$k=0$、値ゼロが生成されます。 これは、すべての負の成分や負の乗数などのケースを処理します。 

すべての材料が等しい場合、どの組み合わせも同等です。 プレフィックス戦略は依然として正しい数の要素を選択し、計算された値は形成されるペアの数にのみ依存します。 

いつ$n=2$、 のみ$k=0$そして$k=1$評価されます。 このアルゴリズムは、何もしないことと単一のペアを取得することを直接比較し、問題の定義と正確に一致します。
