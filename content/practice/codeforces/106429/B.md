 ## 解決策
 ## 問題の理解

 オレンジを表す整数ラベルのマルチセットが与えられています。 これらのラベルを並べ替えると、順序付けられたシーケンスが得られます。$b_1 \le b_2 \le \dots \le b_n$。 このシーケンスから、完全な重み付きグラフを構築します。$n$頂点、頂点間の重み$i$そして頂点$j$絶対的な違いは$|b_i - b_j|$。 

タスクは、このグラフ内の最大スパニング ツリーの重みを計算することです。つまり、正確に選択する必要があります。$n-1$選択したエッジの重みの合計を最大化しながら、すべての頂点を接続するエッジ。 

制約が大きいため、完全なグラフを構築することは不可能です。 素朴な解決策には次のことが必要です$O(n^2)$エッジにアクセスし、Kruskal または Prim を介して最大スパニング ツリーを試行しますが、これは次の場合にすぐに実行不可能になります。$n$到達する$10^5$。 このため、列挙ではなく構造について推論する必要があります。 

すべての値が等しい場合、微妙だが重要なエッジ ケースが発生します。 この状況では、すべてのエッジの重みが 0 になるため、答えも 0 になる必要があります。 少なくとも 1 つの正のエッジを想定する単純な実装は数値的には機能する可能性がありますが、多くの誤った貪欲な構築は、意味のある順序ギャップが存在すると想定しているため失敗します。 

次の場合には、別のエッジケースが発生します。$n = 2$。 グラフには単一のエッジがあるため、答えは単純です。$|b_2 - b_1|$。 派生式はすべて、この場合に正しく縮退する必要があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。次のようにして完全なグラフを構築します。$n(n-1)/2$エッジを取得し、最大スパニング ツリーの Kruskal アルゴリズムを実行します。 各エッジの重みは絶対差として計算され、エッジの並べ替えが実行時間を支配します。$O(n^2 \log n)$。 と$n = 10^5$、エッジさえも保存することが不可能であるため、これは時間的にもメモリ的にも不可能になります。 

重要な観察は、重み関数が$|b_i - b_j|$ソートされた配列内の位置のみに依存します。 並べ替えられたシーケンスでは、最大の差異は常にエンドポイントまたはエンドポイントの近くから生じます。 これは、クラスカルのプロセス中、重要なエッジは、現在接続されていないセグメントの両端を接続するエッジだけであることを意味します。 

概念的に Kruskal の実行を想像すると、エッジは最大の重みから最小の重みまで考慮されます。 可能な最大のエッジは次の間です$b_1$そして$b_n$。 これが選択されると、次の有用なエッジは常に新しい極値要素 (次に小さい、または次に大きい残りの要素) を既に接続されている極値の 1 つに接続します。 このプロセスでは、内部間の接続は常にエンドポイントを含むエッジによって支配されるため、内部間の接続を考慮する必要がなくなります。 

この構造により、問題をソートされた配列の線形スキャンに縮小し、各要素がエンドポイントからどれだけ離れているかに基づいて寄与を蓄積することができます。

 | 最適 (並べ替えられた構造的貪欲) |$O(n \log n)$|$O(1)$番外編 | 承認済み |

 ## アルゴリズムのチュートリアル

 この考え方は、全体的な最小値と最大値に対する個々の要素の寄与という観点から MST の重みを表現することです。 

1. 配列をソートする$b$。 すべての構造的推論はインデックスではなく値による順序付けに依存しているため、並べ替えは不可欠です。 
2. グローバル最小値を計算する$b_1$そして最大の$b_n$。 これら 2 つのエンドポイントは、スパニング構造のバックボーンを形成します。 
3. 基本寄与を追加する$b_n - b_1$答えに。 これは、両極端間の最初で最も強い接続に対応します。 
4. あらゆるインテリア要素について$b_i$どこ$2 \le i \le n-1$、各エンドポイントからの距離を計算します。 具体的に計算する$f(b_i) = \max(b_i - b_1, b_n - b_i)$。 これは取り付けにかかるコストを表します$b_i$最終的なツリー構造のさらに遠い端点まで。 
5. これらすべての貢献を合計して最終的な答えを求めます。 

これが機能する理由は、各内部要素が、両端の間の最初の接続を超えて、MST に 1 つのエッジだけを効果的に寄与しているためです。 Kruskal によって構築された MST は接続性を維持するより大きな利用可能なエッジを常に優先するため、最適な選択では常にエッジの重みを最大化するエンドポイントに接続されます。 

### なぜ効果があるのか

 ソートされたセットにわたる絶対差分の最大スパニング ツリーでは、このプロセスは、現在アクティブな区間をその境界から繰り返しマージすることと同じです。 最初のエッジは 2 つのグローバルな極値を接続します。 その後、残りのすべての頂点は、より大きな差が得られる端点に接続します。これは、端点以外の点間の接続は常に、少なくとも 1 つの端点への接続によって支配されるためです。 これにより、各内部要素が 1 つの可能な最大接続コストに正確に寄与する決定論的な構造が作成され、スパニング ツリーの制約に違反せずに合計を増加できる代替エッジ構成は存在しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    b = list(map(int, input().split()))
    b.sort()

    if n == 1:
        print(0)
        return

    mn = b[0]
    mx = b[-1]

    ans = mx - mn

    for i in range(1, n - 1):
        ans += max(b[i] - mn, mx - b[i])

    print(ans)

if __name__ == "__main__":
    solve()
```解決策は配列をソートすることから始まりますが、これが唯一の非線形ステップです。 ソート後、最小値と最大値を直接抽出します。 基本用語$mx - mn$エンドポイント間の必須接続に対応します。 

内部要素に対するループは、各要素の可能な限り最良のアタッチメント コストを計算します。 の使用`max(b[i] - mn, mx - b[i])`encodes the decision of whether the element connects more beneficially to the left endpoint or the right endpoint in the Kruskal-driven construction.

 微妙な実装の詳細が処理されます$n = 1$。 このガードがなければ、式は引き続き機能しますが、計算が正しく行われなくなります。$b_n - b_1$単一の要素で。 明示的にゼロを返すことで、曖昧さを回避できます。

 ## 特殊なケース

 のために$n = 1$の場合、スパニング ツリーに含めるエッジがないため、アルゴリズムはすぐに 0 を返します。 ループは完全にスキップされ、数式では無効なインデックス付けが試行されることはありません。 

のために$n = 2$、初期化により答えが設定されます$b_2 - b_1$、ループは空です。 これは、可能な唯一のスパニング ツリーと一致します。 

同じ値の場合、両方$mn$そして$mx$は等しいため、基本項はゼロとなり、すべての内部寄与はゼロに評価されます。 すべての要素について max 内の両方の項が 0 であるため、アルゴリズムは特別な分岐を行わなくても正しく 0 を生成します。
