 ## 解決策
 ## 問題の理解

 私たちは、ヘビが一定のセルのシーケンスを経時的に移動するプロセスをシミュレートしています。 各タイムステップで$t$、ヘビの頭は既知の細胞を占めています$c(t)$。 一部の細胞は時間の経過とともに繰り返す可能性があり、ヘビが後で同じ位置を再訪する可能性があることを意味します。 

ヘビは指定された時間に「リンゴを食べ」、食べるたびに体長が 1 つずつ増えます。 スコアへの寄与は時間と現在の長さの両方に依存します。直感的には、ヘビが長いほど各単位時間の寄与が大きくなるため、より大きなヘビでより長く滞在することが有益です。 

ただし、食事の時間は、$t$セルがリンゴの生成に有効な場合にのみ許可されます。これは、そのセルが time より前に最後にアクセスされた時期によって決まります。$t$。 同じセルに最近アクセスした場合、リンゴがその位置で有効であると見なされない制限ウィンドウが存在します。 

目標は、一連の食事時間とそれに対応する長さを選択して、時間までの合計スコアを最大化することです。$N$、さらに、ヘビが最後まで最終的な長さを維持する最後の継続フェーズが追加されます。 

制約の観点から見ると、この構造は、時間と長さの経過に伴う二次または二次に近い動的計画法ソリューションを強く示唆しています。 すべてのトリプル状態に対する 3 次アプローチは、一般的な制限に対して遅すぎます。$N \approx 5000$。 これにより、以前の状態に対する範囲クエリを使用して遷移が最適化される DP が実現します。 

一般的な障害のケースは、セルが繰り返されるときに発生します。 たとえば、次の場合$c(t) = c(t')$、次に食事の時間を選択します$t$同じセルの最近の使用を「無効にする」かどうかによって異なります。 この依存関係を無視する単純な DP は、不正な遷移を過大にカウントします。 

もう 1 つの微妙な問題は、最終延長期間です。 最後の食事の時間が$t$、私たちはまだからスコアを蓄積します$t+1$に$N$したがって、この接尾辞の寄与を忘れると、系統的に答えを過小評価することになります。 

## アプローチ

 問題をモデル化する最も直接的な方法は、DP 状態を定義することです。$dp[t][i]$、最後のリンゴがその時点で食べられた場合に達成可能な最高スコアを表します$t$食べた後のヘビの長さは$i$。 

状態に遷移するには$(t, i)$、これまでのすべての食事時間を試します$k < t$、以前の長さは$i-1$。 2つの食事イベントの間で、ヘビは長さを持っています$i-1$、したがって、間隔からの寄与は$[k, t]$時間とともに直線的に成長します。 これにより、次の形式の遷移が得られます。$$dp[t][i] = \max_k \left(dp[k][i-1] + (i-1)\cdot (t-k) + 1\right)$$という追加の制約があり、$k$現在のセルの最後の無効な出現箇所から十分に離れている必要があります。 

この直接的なアプローチでは、すべての有効性がチェックされます。$k$それぞれに$(t, i)$、3 つのネストされたループにつながります。 状態の数は$O(N^2)$、および各移行コスト$O(N)$、生産$O(N^3)$が遅すぎるときは、$N$適度に大きいです。 

重要な観察は、固定された$i$、遷移は次の線形形式に再配置できます。$t$および接頭辞に依存しない用語$k$:$$dp[t][i] = t\cdot(i-1) + 1 + \max_k \left(dp[k][i-1] - k\cdot(i-1)\right)$$これにより各レイヤーが変換されます$i$前の DP 層から派生した事前計算された配列に対する範囲最大クエリ問題に変換します。 残る唯一の複雑な問題は、妥当性制約です。$k \ge f(t) + i - 1$、これは状態ごとに左に移動する境界になります。 これは、RMQ 範囲を制限することで処理されます。 

DP 層が範囲クエリに縮小されると、セグメント ツリーまたはスパース テーブルを使用して各遷移に効率的に応答できるようになります。 これにより、全体的な複雑さが軽減されます。$O(N^2 \log N)$、 または$O(N^2)$線形時間RMQ構造を備えています。

 ## アルゴリズムのチュートリアル

 しましょう$c(t)$時のスネークヘッドの位置になります$t$。 毎回、最初に計算します$t$、前回同じセルが出現したとき、と示されます。$f(t)$。 これは、セル識別子のハッシュ マップを使用して実行できます。 

次に、ヘビの長さのレイヤーの上に DP を構築します。 

1. 事前計算$f(t)$いつでも$t$。 これは、各セルが以前にどのくらい最近アクセスされたかをキャプチャします。$t$、リンゴが時間にあるかどうかを決定します$t$法的には前職に依存することができる。 
2.ベースレイヤーを初期化する$dp[t][1]$みんなのために$t$。 これは、最初に食べたリンゴに対応し、事前の長さの寄与はありません。 最適化する前のセグメントがないため、移行は簡単です。 
3.長さごとに$i \ge 2$、補助配列を構築します$A[k] = dp[k][i-1] - k\cdot(i-1)$。 これにより、前の決定点のみに依存する遷移の部分が分離されます。$k$、現在時刻から区切ります$t$。 
4. 範囲最大構造を構築する$A[k]$。 これにより、以前の最適な食事時間をクエリすることができます$k$任意の有効な間隔で効率的に実行できます。 
5. 毎回$t$、以前の状態の有効な範囲を決定します。 左側の境界線は、$f(t) + i - 1$、以前から$k$同じセルへの繰り返しの訪問によって引き起こされる間隔の制約に違反する可能性があります。 
6. コンピューティング$$dp[t][i] = t\cdot(i-1) + 1 + \max_{k \in [L, t-1]} A[k]$$どこ$L = f(t) + i - 1$。 各状態は、線形再構成と組み合わせた単一の RMQ クエリによって満たされます。 

1. すべてのレイヤーを埋めた後、最後のセグメントを時間まで拡張して最終的な答えを計算します。$N$。 それぞれについて$(t, i)$、最終的な貢献度は$dp[t][i] + i\cdot(N-t)$。 

重要な不変条件は、処理後の層です。$i-1$、すべての値$dp[k][i-1]$はすでに time で終了するシーケンスの最適なスコアを表しています$k$長さのある$i-1$。 レイヤーを構築するとき$i$、残りのすべての構造はのみに依存するため、すべての候補遷移は 1 つの有効な前のエンドポイントを考慮し、最適性を維持します。$k$で捉えられた線形変換を通じて$A[k]$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class SegTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.size = 1
        while self.size < self.n:
            self.size *= 2
        self.seg = [-10**18] * (2 * self.size)
        for i in range(self.n):
            self.seg[self.size + i] = arr[i]
        for i in range(self.size - 1, 0, -1):
            self.seg[i] = max(self.seg[2 * i], self.seg[2 * i + 1])

    def query(self, l, r):
        if l > r:
            return -10**18
        l += self.size
        r += self.size
        res = -10**18
        while l <= r:
            if l % 2 == 1:
                res = max(res, self.seg[l])
                l += 1
            if r % 2 == 0:
                res = max(res, self.seg[r])
                r -= 1
            l //= 2
            r //= 2
        return res

def solve():
    N = int(input().strip())
    c = list(map(int, input().split()))

    last = {}
    f = [0] * N
    for i in range(N):
        if c[i] in last:
            f[i] = last[c[i]] + 1
        else:
            f[i] = 0
        last[c[i]] = i

    NEG = -10**18

    dp_prev = [NEG] * N
    dp_cur = [NEG] * N

    for i in range(N):
        dp_prev[i] = 1  # base: length 1

    for length in range(2, N + 1):
        arr = [dp_prev[k] - k * (length - 1) for k in range(N)]
        st = SegTree(arr)

        for t in range(N):
            L = f[t] + length - 1
            if L >= t:
                continue
            best = st.query(L, t - 1)
            if best <= NEG // 2:
                continue
            dp_cur[t] = t * (length - 1) + 1 + best

        dp_prev, dp_cur = dp_cur, [NEG] * N

    ans = 0
    for t in range(N):
        for length in range(1, N + 1):
            if dp_prev[t] > NEG // 2:
                ans = max(ans, dp_prev[t] + length * (N - t - 1))

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、DP をスネークの長さのレイヤーごとに分離します。 配列`arr`変換された前の DP 状態をエンコードして、各遷移が範囲最大クエリになるようにします。 セグメント ツリーは、すべての候補となる以前の食事時間をクエリごとの対数時間で評価するために使用されます。 

繰り返しでは、慎重なインデックス付けが使用されます。`length - 1`は前のヘビの長さを表し、項は`k * (length - 1)`食事イベント間の時間の線形寄与を調整します。 境界線`L = f[t] + length - 1`同じセルへの繰り返しの訪問による制限を強制します。 

最終的な回答には継続フェーズが含まれていますが、ここでは最後のイベント後の残り時間に基づくサフィックス寄与に単純化されています。 

## 実用的な例

 すべてのセルが異なるため、位置の繰り返しがない単純なケースを考えてみましょう。 それから$f(t) = 0$みんなのために$t$。 させて$N = 3$、シーケンスは次のとおりです$[1, 2, 3]$。 

### 例 1

 ベースレイヤーを計算します$dp[t][1] = 1$。 

| t | dp[t][1] |
 | --- | --- |
 | 0 | 1 |
 | 1 | 1 |
 | 2 | 1 |

 長さ 2 の場合、トランジションは次を使用します。$A[k] = 1 - k$。 

で$t=2$、 有効$k$は$0,1$。 

最高$A[k]$にあります$k=0$、与える$dp[2][2] = 2\cdot1 + 1 + 1 = 4$。 

これは、線形分解によって区間寄与が単純な最大クエリにどのように変換されるかを示しています。 

### 例 2

 次に、繰り返しを考えてみましょう。$c = [1, 2, 1, 3]$。 

で$t=2$、セル 1 が繰り返されるため、$f(2)=0$。 大型の場合$i$の場合、有効範囲は小さくなります。$f(t) + i - 1$が大きくなり、同じセルの最近の出現を再利用するような遷移が防止されます。 

これは、スネーク ボディ ジオメトリの明示的なシミュレーションを必要とせずに、コンストレイントが無効な DP 遷移を直接削除する方法を示しています。

 ## 特殊なケース

 1 つのエッジ ケースは、同じセルがすぐに繰り返されるときに発生します。 そのような状況では、$f(t) = t-1$したがって、ヘビの長さが小さい場合、有効な遷移範囲は崩れます。 左境界が存在するため、アルゴリズムはこれを正しく処理します。$L = f(t) + i - 1$すぐに超える$t-1$、DP 状態に到達不能になり、セグメント ツリー クエリはスキップされます。 

もう 1 つのエッジ ケースは、特定の有効な以前の状態が存在しない場合です。$(t, i)$。 実装では、DP テーブルを更新する前にクエリ結果を負の無限大センチネルと照合することでこれを保護し、無効な状態が偶発的に伝播することを防ぎます。 

最後のエッジケースは、最適なソリューションが 1 つの食事イベントのみを使用する場合です。 その場合、すべてのトランジションは無関係であり、ベースレイヤーは$dp[t][1]$支配する。 最終回答ロジックは、可能な限りすべての前回の結果を考慮するため、これらの状態を正しく評価します。$t$。
