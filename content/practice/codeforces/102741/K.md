 ## 解決策
 # 問題の理解

 この問題では、既存のすべての TNT ピースが即座に爆発することが保証されるように、新しく配置された 1 つの TNT ピースの揮発性を最小限にすることが求められます。 新しい TNT は、3 次元空間内の任意の実数値位置に配置できます。 既存の TNT の場合、`(xi, yi, zi)`ボラティリティ一定の場合`vi`、新しい TNT の必要なボラティリティは、その点からのマンハッタンの距離を で割ったものです。`vi`。 課題は、すべての TNT ピース間で必要な最大の揮発性を最小限に抑える配置位置を選択することです。 

入力には最大 20000 個の TNT ピースが含まれます。 各部分は、新しい TNT の可能な位置に関する制約に寄与します。 TNT ピースのペアに対する二次探索や座標に対するグリッド探索は、座標が 100 万に達する可能性があり、答えが実数になる可能性があるため、コストが高すぎます。 この入力サイズでは、アルゴリズムは線形に近いか、小さな対数係数の線形倍である必要があります。 

いくつかの特殊なケースは見落とされがちです。 TNT ピースが 1 つしかない場合、新しい TNT は正確に同じ位置に配置でき、答えはゼロになります。 

例えば：```
1
5 5 5 10
```正しい出力は次のとおりです。```
0.00000000
```答えが肯定的でなければならないと仮定する不注意な実装は、ここで失敗します。 

もう 1 つの微妙なケースは、最適な位置が既存の TNT 座標ではない場合です。 考慮する：```
4
0 0 0 1
1 2 0 1
3 4 0 1
2 1 0 1
```正しい出力は次のとおりです。```
3.50000000
```最適な点は既存の座標の間にあります。 整数の位置だけをチェックしたり、既存の TNT の位置だけをチェックしたりすると、答えが見つからなくなります。 

ボラティリティ定数も各ポイントの影響を変化させます。 例えば：```
3
1 0 0 1
2 1 1 4
3 2 3 2
```正しい出力は次のとおりです。```
2.33333333
```すべての TNT を同じ重みを持つものとして扱うと、重み付けされたバージョンではなく、通常の幾何中心の問題が誤って解決されてしまいます。 

## アプローチ

 直接的なアプローチは、候補ポジションを試し、それぞれのポジションで必要なボラティリティを計算することです。 問題は、位置が連続的であり、整数座標に限定されないことです。 たとえ何らかの方法ですべての興味深い座標を生成したとしても、考えられるすべての候補を比較することは非現実的になります。 検索空間には自然な小さな限界はありません。 

重要な観察は、問題を逆転させることです。 特定のボラティリティに対して TNT をどこに配置するかを尋ねる代わりに、選択したボラティリティが適切かどうかを尋ねます。`T`十分です。 

固定の場合`T`、すべての TNT ピースは、許可された位置の領域を定義します。 新しいTNTはマンハッタンの距離内になければなりません`T * vi`既存のすべての TNT から。 問題は、これらすべての地域が少なくとも 1 つの共通点を共有しているかどうかです。 

3 次元のマンハッタン距離には便利な変換があります。 どの点でも`(x, y, z)`では、次の 4 つの値を定義します。```
s1 = x + y + z
s2 = x + y - z
s3 = x - y + z
s4 = -x + y + z
```任意の 2 点のマンハッタン距離は、これらの 4 つの変換された座標間の最大絶対差に等しくなります。 これにより、元の 3 次元のひし形領域が 4 つの独立した間隔制約に変換されます。 

変換された値を持つ TNT の場合`s1, s2, s3, s4`、候補のボラティリティ`T`必要：```
|S1 - s1| <= T * vi
|S2 - s2| <= T * vi
|S3 - s3| <= T * vi
|S4 - s4| <= T * vi
```変換された 4 つの座標のそれぞれは、その間隔が重なるだけで済みます。 変換されたすべての座標ですべての間隔の交点が空でない場合、選択したボラティリティが機能します。 

答えは二分探索で見つかります`T`。 各実現可能性チェックではすべての TNT ピースを 1 回スキャンするため、完全なアルゴリズムは十分に高速です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(探索空間 × N) | お(1) | 遅すぎる |
 | 最適 | O(N log C) | O(N) | 承認済み |

 ここ`C`二分探索の対象となる数値範囲です。 固定の反復回数を使用すると、これは事実上一定となり、倍精度のチェックは約 70 回になります。 

## アルゴリズムのチュートリアル

 1. すべての TNT 位置を変換します`(x, y, z)`4 つの値に変換します。```
x + y + z
x + y - z
x - y + z
-x + y + z
```マンハッタン距離がこれら 4 つの座標間の最大の差になるため、変換が機能します。 

1. 二分探索で答えを求める`T`、新しく配置されたTNTのボラティリティ。 ゼロの下限と十分に大きな上限から始めます。 
2. 各二分探索中間点について`T`、このボラティリティが可能かどうかを確認してください。 変換されたすべての座標について、すべての可能な値の交差間隔を維持します。 
3. 揮発性のある TNT の場合`v`、その変換された座標`a`新しい変換された座標を内部のどこにでも置くことができます。```
[a - T*v, a + T*v]
```この間隔を現在のグローバル間隔と交差させます。 

1. 変換された 4 つの座標区間のいずれかが空になった場合、`T`仕事ができない。 さもないと、`T`実現可能です。 
2. 二分探索を十分に繰り返した後、必要な最小ボラティリティとして下限を出力します。 

なぜ効果があるのか:

 固定ボラティリティの場合`T`、すべての TNT ピースは、答えの可能な変換座標を個別に制限します。 変換ではマンハッタン距離が正確に保存されるため、4 つの間隔制約を満たすことは、元の 3 次元距離制約を満たすことと同じになります。 このアルゴリズムは、変換された 4 つの次元すべてが共通の有効な値を持つ場合に正確に実行可能な値を宣言します。これは、すべての TNT 要件を満たす実際の点が存在することを意味します。 次に、二分探索によって実行可能な最小値が見つかります。これは、実行可能性が単調であるためです。ボラティリティを増加しても、許可される領域を拡大することしかできません。 

## Python ソリューション```python
import sys

input = sys.stdin.readline

def solve():
    n = int(input())
    points = []

    for _ in range(n):
        x, y, z, v = map(int, input().split())
        points.append((
            x + y + z,
            x + y - z,
            x - y + z,
            -x + y + z,
            v
        ))

    def possible(t):
        low = [-10**30] * 4
        high = [10**30] * 4

        for a, b, c, d, v in points:
            vals = (a, b, c, d)
            radius = t * v

            for i in range(4):
                low[i] = max(low[i], vals[i] - radius)
                high[i] = min(high[i], vals[i] + radius)
                if low[i] > high[i]:
                    return False

        return True

    left = 0.0
    right = 3 * 10**6

    for _ in range(80):
        mid = (left + right) / 2
        if possible(mid):
            right = mid
        else:
            left = mid

    print("{:.10f}".format(right))

if __name__ == "__main__":
    solve()
```入力は 1 回読み取られ、座標変換の適用後にすべての TNT が保存されます。 変換された値を保持すると、バイナリ検索の反復ごとに同じ式を再計算する必要がなくなります。 

の`possible`関数は実現可能性テストを表します。 配列`low`そして`high`変換された各次元の許容間隔の現在の交差部分を保存します。 TNT を処理する場合、許可される間隔は次のように狭められます。`max`そして`min`。 下限エンドポイントが上限エンドポイントを超えると、どの配置も現在のボラティリティを満たすことができなくなります。 

答えが必ずしも整数であるとは限らないため、二分探索では浮動小数点値が使用されます。 必要な処理には 80 回の反復で十分です`1e-6`精度。 の上限`3 * 10^6`座標の違いはマンハッタン距離で最大 300 万であり、すべてのボラティリティ定数は少なくとも 1 であるため、安全です。

 ## 特殊なケース

 単一の TNT の場合:```
1
5 5 5 10
```二分探索では、ゼロが機能するかどうかがチェックされます。 唯一の TNT の変換された間隔はすべて 1 点に集約され、それらの交差は有効です。 アルゴリズムは、答えがゼロになるまで答えを減らし続けます。 

答えが既存の座標ではない場合:```
4
0 0 0 1
1 2 0 1
3 4 0 1
2 1 0 1
```実現可能性チェックでは、実際の場所を推測することはありません。 代わりに、変換された間隔が重複しているかどうかを検証します。 ボラティリティがあるとき`3.5`、変換されたすべての間隔は共通の値を共有し、元の TNT 位置の 1 つではないにもかかわらず、何らかの実際の点が存在することが証明されます。 

さまざまなボラティリティ定数の場合:```
3
1 0 0 1
2 1 1 4
3 2 3 2
```ボラティリティのあるTNT`4`同じ必要なボラティリティに対してはるかに長い距離を可能にします。 間隔の交差は、各チェック中に各半径に独自のボラティリティ定数を乗算することで自然にこれを考慮します。 アルゴリズムは等しい重みを想定しないため、結果の値は問題の重み付けされたジオメトリと一致します。
