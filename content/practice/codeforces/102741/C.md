 ## 解決策
 ## 問題の理解

 部屋は`N × M`正方形の床セルのグリッド。 イザベルは、グリッド全体を同一の L 字型タイルで置き換えたいと考えています。 各タイルは 4 つのセル (直線に並んだ 3 つのセルと、一端に追加された 1 つのセル) をカバーしており、タイルは回転できます。 タスクは、これらのタイルの配置によって、隙間や重なりなしで長方形全体をカバーできるかどうかを判断することです。 

タイルは常に 4 つのセルを正確にカバーするため、最初の制限は面積から生じます。 長方形の領域は 4 で割り切れる必要があります。 ただし、この条件だけでは十分ではありません。 L-テトロミノには、より強力なパリティ制限があります。有効な長方形はすべて 8 で割り切れる面積も必要ですが、各タイルが少なくとも 2 行と 2 列を占めるため、辺の長さが 1 の長方形はカバーできません。 

入力値は最大 1000 です。これは、配置をシミュレートするのではなく、数学的な観察に基づいて解決策を決定する必要があることを意味します。 最大 100 万個のセルを含むグリッドは、可能なタイル配置を検索するにはすでに大きすぎます。 バックトラッキング ソリューションは、多くの可能なタイル位置で分岐し、すぐに実行不可能になります。 

厄介なケースは、領域の分割が十分であるように見えても、ジオメトリが長方形を拒否するケースです。 

たとえば、寸法のある部屋`1 8`エリア8がありますが、答えは`NO`。 チェックのみの不注意な解決策`N*M % 8 == 0`1 行に L 字型タイルを含めることはできませんが、受け入れられます。 

別の例は`2 2`。 面積は4ですが、答えは`NO`。 この長方形は小さすぎて、L-テトロミノを 1 つも含めることができません。 

条件をクリアしたケースは、`2 4`。 面積は 8 で、どちらの次元も 1 より大きいため、答えは次のようになります。`YES`。 長方形を埋めるように 2 つの L 字型タイルを配置できます。 

## アプローチ

 直接的なアプローチは、床にタイルを 1 つずつ配置してみることです。 ブルート フォース検索では、覆われていないセルを選択し、そのセルを覆う L 字型タイルのあらゆる回転を試み、再帰的に続行できます。 これは、考えられるすべてのタイリングを調査するため、正しいです。 問題は、可能な配置の数が指数関数的に増加することです。 適度なサイズの長方形の場合でも、多くの異なるタイル順序が同じ最終配置を表すため、検索ツリーは巨大になります。 

有益な観察は、正確な配置を構築する必要がないということです。 長方形に有効なタイリングがあることを認識するだけで済みます。 L テトロミノは 4 つのセルをカバーしますが、列の色付け引数により、より強力な条件が与えられます。つまり、有効なタイリングでは常に偶数のタイルが使用されます。これは、合計面積が 8 で割り切れる必要があることを意味します。 これにより、多くの四角形が即座に削除されます。 

残りの問題は、この条件も十分であるかどうかです。 両方の寸法が 1 より大きく、面積が 8 で割り切れる場合、長方形はいつでも、並べて表示できる小さな長方形に分割できます。 一辺が偶数の場合、長方形は次のように分割できます。`2 × 4`このような各ブロックは 2 つの L-テトロミノで埋めることができます。 一方の辺が奇数の場合、面積条件によりもう一方の辺は 8 の倍数になり、長方形を次のように分割できます。`3 × 8`ブロックと`2 × 4`ブロック。 どちらのブロック タイプにも有効な L-テトロミノ タイリングがあります。 

問題全体は 2 つの条件をチェックすることに帰着します。それは、部屋の寸法が 1 に等しいものであってはならず、その面積が 8 で割り切れる必要があるということです。

 | ブルートフォース | 指数 | O(NM) | 遅すぎる |
 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つの部屋の寸法を読み取ります。`N`そして`M`。 
2. いずれかの次元が 1 に等しいかどうかを確認します。 存在する場合は出力します`NO`L-テトロミノは単一の行または列内に収まらないためです。 
3. コンピューティング`N * M`そしてそれが8で割り切れるかどうかを確認してください。 分割条件は、L-テトロミノの形状によって作成されるタイル数の制限を捉えます。 
4. 出力`YES`両方の条件が満たされた場合。 それ以外の場合は出力`NO`。 

機能する理由: 有効なタイリングはすべて面積制限と寸法制限を満たす必要があるため、どちらかの条件を満たさない四角形を拒否しても安全です。 両方の条件を満たすすべての長方形について、その長方形は、L-テトロミノによって個別にタイル化できる小さな領域に分解できます。 条件は必要条件と十分条件の両方であるため、アルゴリズムは常に正しい答えを返します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

if n == 1 or m == 1:
    print("NO")
elif (n * m) % 8 == 0:
    print("YES")
else:
    print("NO")
```コードは 2 次元を読み取り、アルゴリズムからの 2 つの数学的チェックを直ちに適用します。 最初の条件は、配置できない薄い部屋を処理します。 2 番目の条件はエリア制限を使用します。 

掛け算`n * m`Python では整数の精度は任意であるため安全ですが、最大領域は 100 万にすぎないため、固定幅の 32 ビット整数でも指定された制限には十分です。 

ループがないため、境界トラバーサルの問題やオフバイワンエラーは発生しません。 考えられる唯一の間違いは、次元 1 の場合を忘れて、面積がたまたま 8 で割り切れる長方形を受け入れることです。

## テストケース```python
import sys
import io

def solve(data: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(data)
    n, m = map(int, sys.stdin.readline().split())

    if n == 1 or m == 1:
        ans = "NO"
    elif (n * m) % 8 == 0:
        ans = "YES"
    else:
        ans = "NO"

    sys.stdin = old_stdin
    return ans

# provided samples
assert solve("6 4\n") == "YES", "sample 1"
assert solve("9 6\n") == "NO", "sample 2"

# custom cases
assert solve("1 8\n") == "NO", "single row cannot fit L tiles"
assert solve("2 4\n") == "YES", "small valid rectangle"
assert solve("2 2\n") == "NO", "area is not enough"
assert solve("1000 1000\n") == "YES", "maximum size case"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1 8`|`NO`| 一次元の部屋を拒否する |
 |`2 4`|`YES`| 最小の共通有効構造を確認します。 
|`2 2`|`NO`| 領域の可分性のみをチェックするソリューションをキャッチします。 
|`1000 1000`|`YES`| 大きな入力が一定時間内に処理されることを確認します。 

## 特殊なケース

 のために`1 8`、アルゴリズムは最初に 1 つの次元が 1 であることを確認し、すぐに返します。`NO`。 面積は 8 で割り切れますが、すべての L-テトロミノには 2 方向のスペースが必要なので、長方形をカバーすることはできません。 

のために`2 2`、面積はわずか4つです。 4 は 8 で割り切れないため、アルゴリズムはこれを拒否します。 各タイルが 4 つのセルをカバーするという事実のみに基づいた解決策は、このケースを誤って受け入れてしまいます。 

のために`2 4`の場合、アルゴリズムは両方の次元が 1 より大きく、面積が 8 であることをチェックします。 戻ります`YES`。 これは、2 つの L-テトロミノが長方形を正確にカバーする有効な基本構造です。 

のために`9 6`、アルゴリズムは寸法チェックを通過した後、面積チェックに到達します。 エリアは`54`、 そして`54 % 8`はゼロではないので返されます`NO`。 この長方形は幾何学的に十分な大きさですが、セルの数が有効な L タイル グループに分割できません。
