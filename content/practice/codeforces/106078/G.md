 ## 問題の理解

 ターゲット文字列があります`t`記録されたデータ文字列のリスト。 記録された文字列のサブセットを選択することはできますが、元の順序は変更できません。 選択した文字列が連結され、目標はターゲット文字列が部分文字列としてできるだけ多く表示されるようにすることです。 重複する出現はカウントされるため、ある位置で終了する一致は別の一致と文字を共有できます。 

入力は、短いターゲット パターンと最大 1000 のデータ ポイントで構成されます。 各データ ポイントは、長さが最大 ​​100 の文字列です。出力は、最適なサブセットを選択した後にターゲットが発生する最大回数です。 

ソリューションを形成する主な制約は、ターゲットの長さが短いことです。 ターゲットの長さは最大 20 ですが、データの総量は約 100,000 文字に達する可能性があります。 選択肢が指数関数的に多いため、文字列のすべてのサブセットを試す解決策は不可能です。 考えられるすべての連結境界をチェックするだけでもコストがかかりすぎます。 選択した文字列間で運ぶ情報を圧縮する必要があります。 

構築済みの連結のうち、将来の一致にとって重要となる唯一の部分は、将来発生する可能性のある接尾辞です。`t`。 たとえば、ターゲットが`abab`、テキストを読んだ後は、現在のサフィックスが`a`、`ab`、 または`aba`。 前の連結全体は無関係です。 

不用意に実装すると、重複する一致で失敗する可能性があります。 たとえば、ターゲットが`aaa`そして選んだテキストは`aaaa`、正しい出力は次のとおりです。`2`出現位置は 1 ～ 3 と 2 ～ 4 であるため、出現箇所を見つけた後に一致した文字を飛び越えるソリューションはカウントされるだけです。`1`。 

もう 1 つの注意が必要なケースは、選択した 2 つの文字列の間の境界をまたぐ場合です。 ターゲットを検討する`abc`とデータ文字列`ab`そして`c`。 両方の文字列を選択すると、連結が行われます。`abc`、したがって、答えは次のとおりです`1`。 各文字列内の出現を個別にカウントするメソッドでは、誤った出力が発生します。`0`。 

最後のエッジケースは、文字列を選択しないことです。 すべてのデータ文字列が役に立たない場合、答えは残らなければなりません`0`。 たとえば、ターゲットを使用すると、`xyz`と 1 つのデータ文字列`aaaa`、正しい出力は次のとおりです。`0`。 

## アプローチ

 直接的なアプローチは、データ ポイントの可能なすべてのサブセットを試してみることです。 サブセットごとに、選択した文字列を連結し、次の文字列の出現をカウントします。`t`。 すべての有効な最終ドキュメントは 1 つのサブセットに正確に対応するため、これは正しいです。 問題はサブセットの数です。`2^1000`、したがって、このアプローチは私たちが処理できる範囲をはるかに超えています。 

重要な観察は、将来は完全な連結に依存しないということです。 文字列を左から右に処理する場合、現在のテキストの接頭辞でもある最長の接尾辞を記述するオートマトンの状態だけが必要です。`t`。 これは、プレフィックス関数ベースの文字列マッチングで使用される状態情報と同じです。 

ターゲットの長さは最大 20 であるため、可能な状態の数は少数です。 すべてのデータ文字列について、考えられるそれぞれの状態から開始して追加した場合に何が起こるかを事前計算できます。 遷移により、新しい状態と、新しい状態が何回発生したかがわかります。`t`が作成されます。 

この場合、問題は単純な動的プログラミング プロセスになります。 データポイントをスキャンしている間、`dp[state]`処理された文字列を考慮し、そのオートマトン状態で終了した後に達成可能な一致の最大数を格納します。 新しい文字列ごとに、それをスキップするか、それを取得して事前計算された遷移を適用します。

 ## アルゴリズムのチュートリアル

 1. ターゲット文字列のプレフィックス関数ベースのオートマトンを構築します。 考えられるすべての状態について、文字を読み取った後の次の状態と、その文字がオカレンスを完了したかどうかを保存します。 状態は、ターゲットの何文字が現在読み取ったものの接尾辞に一致するかを表します。 
2. すべてのデータ文字列について、考えられるすべての状態から開始して、現在のテキストへの追加をシミュレートします。 結果の状態と作成されたオカレンスの数を保存します。 これが機能するのは、ターゲットが短いため、すべての遷移の事前計算が低コストであるためです。 
3. 状態を使用して動的プログラミング配列を初期化します。`0`価値がある`0`。 これは、空の選択された連結を表します。 
4. データ文字列を順番に処理します。 各文字列について、まず現在の DP 値をオプションとしてコピーし、この文字列をスキップします。 
5. 現在のオートマトンの状態ごとに、現在の文字列を取得してみます。 事前に計算された次の状態に移動し、この文字列によって生成された一致の数を加算します。 その状態に最適な値を維持します。 
6. すべての文字列が処理された後、最終的な接尾辞の状態は重要ではないため、答えはすべてのオートマトン状態の最大値になります。 

なぜ機能するのか: DP の不変条件は、最初の処理後の`i`データ文字列、`dp[s]`マッチャーを状態のままにする文字列のすべての選択肢の中で可能な最良の出現数です。`s`。 文字列をスキップすると、同じ状態とスコアが維持されますが、文字列を取得すると、文字列を追加した場合とまったく同じ効果が使用されます。 考えられるすべての選択肢は次の文字列を取得するかスキップするかのいずれかであるため、すべての有効な連結が考慮されます。 オートマトンの状態には、将来の拡張に必要な情報が正確に含まれているため、必要な情報が失われることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    target = input().strip()
    n = int(input())
    strings = [input().strip() for _ in range(n)]

    m = len(target)

    pi = [0] * m
    for i in range(1, m):
        j = pi[i - 1]
        while j > 0 and target[i] != target[j]:
            j = pi[j - 1]
        if target[i] == target[j]:
            j += 1
        pi[i] = j

    nxt = [[0] * 26 for _ in range(m)]
    add = [[0] * 26 for _ in range(m)]

    for state in range(m):
        for c in range(26):
            ch = chr(ord('a') + c)
            j = state
            while j > 0 and target[j] != ch:
                j = pi[j - 1]
            if target[j] == ch:
                j += 1
            if j == m:
                add[state][c] = 1
                j = pi[m - 1]
            nxt[state][c] = j

    transitions = []
    for s in strings:
        cur = []
        for start in range(m):
            state = start
            score = 0
            for ch in s:
                idx = ord(ch) - ord('a')
                score += add[state][idx]
                state = nxt[state][idx]
            cur.append((state, score))
        transitions.append(cur)

    dp = [-10**9] * m
    dp[0] = 0

    for trans in transitions:
        ndp = dp[:]
        for state in range(m):
            if dp[state] < 0:
                continue
            to, gain = trans[state]
            if dp[state] + gain > ndp[to]:
                ndp[to] = dp[state] + gain
        dp = ndp

    print(max(dp))

if __name__ == "__main__":
    solve()
```プレフィックス関数は、不一致の後に照合を継続するために必要な失敗リンクを構築します。 これにより、文字が適合しない場合にターゲット全体を再スキャンする必要がなくなります。 

の`nxt`そして`add`表はオートマトンを説明しています。`nxt[state][character]`は文字を読み取った後の接尾辞の状態です。`add[state][character]`その文字がオカレンスを完了するかどうかを示します。 出現が見つかると、状態はプレフィックスでもある最長の適切なサフィックスに戻ります。これにより、重複が可能になります。 

各データ文字列の遷移テーブルは 1 回計算されます。 シミュレーションではターゲットを繰り返し検索する代わりにオートマトンを使用するため、長いデータ文字列でも高速に処理されます。 

DP 更新では、文字列のスキップが可能なままでなければならないため、最初に現在の配列がコピーされます。 次に、すべての状態が文字列の取得を試み、結果の状態を更新します。 Python では整数オーバーフローの問題はありませんが、負の初期値は不可能な状態を表します。

## テストケース```python
import sys
import io

def solve(inp):
    old = sys.stdin
    sys.stdin = io.StringIO(inp)

    target = sys.stdin.readline().strip()
    n = int(sys.stdin.readline())
    strings = [sys.stdin.readline().strip() for _ in range(n)]

    m = len(target)

    pi = [0] * m
    for i in range(1, m):
        j = pi[i - 1]
        while j > 0 and target[i] != target[j]:
            j = pi[j - 1]
        if target[i] == target[j]:
            j += 1
        pi[i] = j

    nxt = [[0] * 26 for _ in range(m)]
    add = [[0] * 26 for _ in range(m)]

    for s in range(m):
        for c in range(26):
            ch = chr(97 + c)
            j = s
            while j > 0 and target[j] != ch:
                j = pi[j - 1]
            if target[j] == ch:
                j += 1
            if j == m:
                add[s][c] = 1
                j = pi[m - 1]
            nxt[s][c] = j

    dp = [0] + [-10**9] * (m - 1)

    for text in strings:
        trans = []
        for start in range(m):
            state = start
            score = 0
            for ch in text:
                x = ord(ch) - 97
                score += add[state][x]
                state = nxt[state][x]
            trans.append((state, score))

        ndp = dp[:]
        for i in range(m):
            if dp[i] >= 0:
                j, gain = trans[i]
                ndp[j] = max(ndp[j], dp[i] + gain)
        dp = ndp

    sys.stdin = old
    return str(max(dp)) + "\n"

 ## 特殊なケース

 ターゲット向け`aaa`そして文字列`aaaa`、オートマトンは次の状態で開始されます。`0`。 最初の 3 文字を読み取った後、1 つの出現を見つけて状態に戻ります。`2`、接尾辞を表します`aa`。 4 番目の文字を読み取ると、別のオカレンスが作成されます。 アルゴリズムの出力`2`一致後にサフィックスを破棄しないからです。 

ターゲット向け`abc`と文字列`ab`そして`c`、最初に選択された文字列はオートマトンの状態を残します。`2`、現在のサフィックスが`ab`。 When the second string begins with`c`、オートマトンはすぐにパターンを完成させ、スコアに 1 を追加します。 これは、選択された複数の文字列にまたがる一致を処理します。 

ターゲット向け`xyz`と文字列`aaaa`、すべてのトランジションは完了した一致から遠ざかります。 DP は、到達可能な最高のスコアを次のように維持します。`0`、これは有用なものを何も選択しないことを表します。 このアルゴリズムでは文字列の選択が強制されることはないため、不可能な要素が結果に影響することはありません。
