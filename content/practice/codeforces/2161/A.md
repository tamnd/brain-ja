 ## 解決策
 ## 問題の理解

 私たちは一連のコンテスト ラウンドをシミュレートしており、参加者は各評価ラウンドの前に評価を調整できる場合があります。 主な複雑な点は、ラウンドが参加者に評価されるかどうかは、固定しきい値と比較した現在の評価に依存し、評価ラウンドでは制限された範囲内で評価を変更できることです。 

各テスト ケースでは、初期レーティング、2 種類のラウンドを分けるしきい値、レーティング ラウンドの前にレーティングをどの程度調整できるかの最大ステップ サイズ、およびタイプ 1 またはタイプ 2 としてラベル付けされた一連のラウンドが与えられます。タイプ 1 ラウンドは常にレーティングされます。 タイプ 2 ラウンドは、現在のレーティングがしきい値を厳密に下回っている場合にのみレーティングされます。 それ以外の場合は未評価となり、評価は変更されません。 

ラウンドがレーティングされるとき、プレーヤーは現在のレーティングを中心とした対称的な間隔内で最終レーティングを選択できます。 これにより、評価が高すぎる場合に一部のステップが「フリーズ」されることを除いて、プロセスが数直線上を制御されたように感じられます。 

課題は、最終的に評価されるラウンド数を最大化することです。 

この制約は、テスト ケースあたりのラウンド数が最大 1000 であり、すべてのテストの合計が最大 30000 であることを示しています。これは、すべての状態およびすべてのラウンドにわたる 2 次または 2 次に近い動的計画法が許容されることをすぐに示唆していますが、ステップごとに 1000 状態を超える 3 次のものはすでに境界線にあります。 ステップごとに到達可能な評価の小さなセットまたは間隔のみを維持するソリューションが必要です。 

主な問題点は、レーティングには原則として制限がないことですが、タイプ 2 ラウンドではしきい値との関係のみが問題となることです。 これは、すべての評価を正確に追跡する必要はなく、しきい値を下回るか上回るかに影響を与える範囲または極端な可能性だけを追跡する必要があることを示唆しています。 

ローカルで貪欲な決定が行われると、微妙な失敗のケースが発生します。 たとえば、直ちにレーティングを可能な限り低くすると、将来のタイプ 2 ラウンドを有効にするのに役立つかもしれませんが、望ましくない状態変化を避けるためにしきい値を超えたままにしたい場合があるタイプ 1 ラウンドの柔軟性が低下する可能性があります。 相互作用は長期にわたるため、ローカルな決定は信頼できません。 

## アプローチ

 強引な解釈では、各ラウンドを、各評価ラウンド後に到達可能なすべての可能な評価値にわたる分岐として扱うことになります。 評価ラウンドの後、評価は現在の評価を中心とした 2D の長さのセグメント内の任意の整数になります。 到達可能なすべての評価を正確に追跡すると、すぐに状態爆発が発生します。各状態は O(D) 個の新しい状態に拡張され、n ステップを超えると、最悪の場合、n で指数関数的になります。 

ただし、問題の構造により、これはやりすぎになります。 レーティング間の唯一の意味のある違いは、レーティングが X を下回っているかどうかです。これにより、タイプ 2 ラウンドがアクティブかどうかが決まります。 X 未満の領域と X より上の領域内では、どれだけ到達できるか、必要なときにしきい値を超えることができるかどうかだけを気にします。 

重要な洞察は、到達可能なすべてのレーティングを追跡するのではなく、将来のレーティングラウンドを最大化する可能な限り最良の「効果的なポジション」を追跡するということです。 レーティングラウンドにいるとき、いつでもサイズ 2D の間隔内のどこにでもレーティングを移動できることがわかります。 これは、各評価ラウンドの後、可能な評価のセットが常に連続した間隔になることを意味します。 このプロパティは、潜在的に多くの点から単一の区間に状態空間を縮小します。

したがって、あらゆる段階で、これまでの定格ラウンドを最大化した後に達成可能な最小および最大の定格を維持します。 ラウンドごとに、ラウンドがレーティングされているかどうか、およびタイプ 2 がアクティブであるかスキップされているかに応じて、この間隔を更新します。 ラウンドが評価されると、間隔が両方向に D だけ拡張されます。 スキップした場合、間隔は変わりません。 また、タイプ 2 ラウンドは、現在のインターバルが X を下回って交差する場合にのみレーティングされるという事実も考慮する必要があります。これにより、ポイントを獲得するかどうか、およびトランジションを適用するかどうかが決まります。 

これにより、問題は、一定時間間隔の更新によるラウンドにわたる線形スキャンに軽減されます。

 ## アルゴリズムのチュートリアル

 これまでの最大評価ラウンド数に達した後、可能な評価の範囲を維持しながら、左から右にラウンドを処理します。 

1. 現在の到達可能な定格区間を初期定格 R0 の単一点として初期化します。 また、答えを0として初期化します。 
2. 各ラウンドを順番にスキャンします。 ラウンドごとに、タイプ 1 かタイプ 2 かを決定します。 
3. ラウンドがタイプ 1 の場合、常にレーティングされます。 答えを 1 ずつ増やします。次に、[L - D, R + D] に拡張して間隔を更新します。これは、評価ラウンドの後、以前に到達可能な値の D 以内の任意の評価を選択でき、すべての可能性を組み合わせると完全な拡張間隔が得られるためです。 このステップにより、将来のあらゆる可能性が確保されます。 
4. ラウンドがタイプ 2 の場合、最初にこのラウンドをレーティングできるかどうかを確認します。これは、現在のインターバル内に厳密に X より小さいレーティングが少なくとも 1 つ存在することを意味します。これは、インターバルの最小値が X より小さいかどうかを確認するのと同じです。 
5. タイプ 2 のラウンドが現在のインターバルで評価されている場合、答えを 1 増やします。次に、タイプ 1 の場合と同じ方法でインターバルを更新し、両側で D だけ拡張します。 
6. タイプ 2 ラウンドがレーティングされていない場合、レーティングはレーティングされていないラウンド中は凍結されたままであるため、間隔は変更しません。 
7. すべてのラウンドが処理されるまでこのプロセスを継続し、定格ラウンドの累積カウントを出力します。 

重要な考え方は、これまでの決定を最大限に活用した後、達成可能な評価の全範囲を常に維持するということです。 間隔はすでにすべての最適な可能性を表しているため、単一の軌道を選択する必要はありません。 

### なぜ効果があるのか

 正確性は、ラウンドの各プレフィックスを処理した後、区間 [L, R] が、その時点までの評価ラウンド数を最大化した後に達成できるすべての評価のセットを正確に表すという不変条件に基づいています。 

ラウンドが評価されると、前のインターバルのすべてのポイントは ±D 以内で独立して移動でき、結果として得られるすべてのインターバルの和集合は再び単一の連続インターバルになります。 ラウンドが評価されない場合、遷移は発生しないため、到達可能なセットは変更されません。 タイプ 2 のラウンドは、実行可能なレーティングが X 未満にあるかどうかによってのみ決定されるため、インターバルの最小値をチェックするだけで、ラウンドを最適な実行でレーティングできるかどうかを判断できます。 

後でさらに多くの評価ラウンドにつながる可能性がある到達可能な評価を破棄することはないため、最終的なカウントは最適になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        R0, X, D, n = map(int, input().split())
        s = input().strip()

        L = R0
        R = R0
        ans = 0

        for c in s:
            if c == '1':
                ans += 1
                L -= D
                R += D
            else:
                if L < X:
                    ans += 1
                    L -= D
                    R += D
                else:
                    pass

        print(ans)

if __name__ == "__main__":
    solve()
```実装は間隔の解釈に直接続きます。 変数 L と R は、定格ラウンドを最大化した後の可能な定格の全範囲を表します。 タイプ 1 ラウンドごとに、常に間隔を拡張し、回答をインクリメントします。 

タイプ 2 ラウンドの場合、条件は`L < X`最小可能評価がすでに X 以上である場合、間隔に到達可能なすべての状態が含まれていると仮定すると、どの実行パスも評価を十分に低くすることができないため、これで十分です。 ラウンドが評価されたとみなされると、同じ拡張ルールが再度適用されます。 

微妙な点は、格付けを特定の地域に「強制」しようとしていないことです。 この間隔は、すべての有効な選択肢を自動的にエンコードします。 これにより、後戻りやケースの分割が回避されます。

 ## 特殊なケース

 エッジケースの 1 つは、初期評価がすでにしきい値を下回っている場合です。 この状況では、最初のタイプ2ラウンドがすぐに対象となり、開始からインターバルが拡大し始めます。 アルゴリズムはこれを自然に処理します。`L < X`は初期化時に true であるため、特別なケースは必要ありません。 

もう 1 つのエッジ ケースは、評価が X をはるかに上回って開始され、D が小さい場合です。 このような場合、間隔が X を下回るまでに数回の評価ラウンドがかかる可能性があります。間隔全体にわたって評価を自由に選択できる場合にのみ、繰り返しの拡張により最終的に下限が下方にシフトするため、間隔表現により、この遷移が暗黙的に捕捉されることが保証されます。 

最後のエッジケースは、到達可能なすべての評価と比較して X が極端に大きい場合です。 その場合、タイプ 2 ラウンドはカウントされません。 区間が X より下で交差することはないため、アルゴリズムは正しく答えを変更しないままにします。
