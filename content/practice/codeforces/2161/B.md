 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times n$黒いセルがマークされたグリッド`#`と白いセルがマークされています`.`。 私たちの目標は、3 つの条件が同時に満たされるように、いくつかの白いセルを黒くペイントすることです。 まず、黒マスが少なくとも 1 つ存在する必要があります。 次に、すべての黒セルは、直交隣接関係にある単一の連結成分を形成する必要があります。黒セルのみを踏んで上下左右に移動することで、任意の黒セルから別の黒セルに移動できます。 第三に、行または列に 3 つの連続した黒セルを含めることはできません。 

入力には複数のテスト ケースが含まれており、それぞれに独自のグリッドがあります。 1 つのグリッドの最大サイズは 100 x 100 であり、$n$すべてのテスト ケースで 2000 を超えません。これは、各セルを数回繰り返すソリューションは許容されるが、二次関数はすべて許容されることを意味します。$n^2$1000 個のテスト ケースを繰り返すと、テスト ケースごとの処理が遅くなる可能性があります。 

単純なアプローチではつまずいてしまう可能性がある、微妙なエッジケースがいくつかあります。 たとえば、完全に黒のセルで埋められた 3x3 グリッドは、「3 つ連続しない」ルールに簡単に違反します。 もう 1 つの注意が必要なケースは、黒と白のセルの市松模様です。 ペイントすることでつながりを実現できるかもしれませんが、黒いセルを追加すると誤って 3 つ連続してしまう可能性があります。 サイズ 1 または 2 の小さなグリッドも、行数または列数によって隣接の可能性が制限されるため、特別な処理が必要です。 

## アプローチ

 ブルートフォース手法では、接続性と「3 連続なし」ルールを毎回チェックしながら、白セルの可能なすべてのサブセットを描画しようとします。 これは原理的には正しいですが、サブセットの数が指数関数的であるため実行不可能です。 のために$n \times n$グリッド付き$k$白血球、あります$2^k$可能性。 たとえ$n=10$、これは広すぎるため、徹底的に調査することはできません。 

重要な洞察は、2x2 の正方形に焦点を当てることです。 グリッドがどこかの場所で 3 行ルールに違反している場合、接続を切断したり新たな違反を作成したりすることなく、ローカルで修正することは不可能です。 2x2 の各正方形を検討すると、その正方形内のすべてのセルをペイントすると、3 連続しないという特性が維持されるか、または破壊されるかのどちらかであることがわかります。 したがって、解決できないパターンを検出するには、2x2 の正方形ごとに「一列に並んだ 3 つの黒いセル」をチェックするだけで十分です。 どの行または列にも 3 つの連続した黒セルが表示されないため、2x2 の正方形内の唯一の禁止パターンは、黒セルをもう 1 つ追加すると 1 行に 3 つになるように配置することです。 すべての 2x2 正方形がこの特性を満たしている場合、対角線に沿ってペイントすることで常に接続されたパスを構築でき、接続性が保証され、3 連続違反が回避されます。 

これにより、単純な O(n^2) の解決策が得られます。つまり、グリッド内のすべての 2x2 正方形を反復処理し、禁止されたパターンがないかチェックします。 存在しない場合は、「YES」を出力します。 それ以外の場合は、「NO」を出力します。 これは効率的であるため、$n^2$テスト ケースごとの反復回数に次の最大合計を乗算したもの$n^2$すべてのテスト ケースの数は約 2,000,000 で、2 秒以内に許容されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^{n^2}) | O(n^2) | 遅すぎる |
 | 2x2 の正方形チェック | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 テスト ケースごとに、次の内容を読んでください。$n$次に文字列のリストとしてのグリッド。 
2. すべての位置を反復処理します。$(i,j)$どこ$0 \le i < n-1$そして$0 \le j < n-1$。 これらは 2x2 の正方形の左上隅です。 
3. 次のように定義される 2x2 の正方形ごとに、$(i,j)$、4つの位置にある黒マスの数を数えます。$(i,j)$、$(i,j+1)$、$(i+1,j)$、$(i+1,j+1)$。 
4. 2x2 の正方形にちょうど 3 つの黒セルが含まれている場合、3 つの連続するセルを作成せずに黒セルを追加してすべての黒セルを接続することは不可能です。 このテスト ケースではすぐに「NO」を返します。 
5. 2x2 の正方形にちょうど 3 つの黒いセルが含まれていない場合は、「YES」を返します。 

機能する理由: ローカルで 3 行連続制約に違反するソリューションは、3 つの黒いセルからなる 2x2 の正方形として表示されます。 すべての正方形についてこのプロパティを検証することにより、解決できない構成をすべて捕捉します。 禁止パターンが存在しないことが確認できれば、連続する 3 つの黒セルを作成せずに、常に斜めまたは L 字型のパスに沿って接続された黒コンポーネントを構築できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        grid = [input().strip() for _ in range(n)]
        possible = True
        for i in range(n - 1):
            for j in range(n - 1):
                black_count = sum(
                    grid[i][j] == '#' +
                    grid[i][j+1] == '#' +
                    grid[i+1][j] == '#' +
                    grid[i+1][j+1] == '#'
                )
                if black_count == 3:
                    possible = False
                    break
            if not possible:
                break
        print("YES" if possible else "NO")

if __name__ == "__main__":
    solve()
```最初のセクションでは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 グリッド内のすべての 2x2 正方形を反復処理します。`black_count`4 つのブール式を合計します。 Pythonでは、`True`は 1、`False`は 0 で、黒セルの数を示します。 ちょうど 3 つのセルが黒の場合、テスト ケースは直ちに不可能としてマークされます。 次に、結果を出力します。 ネストされたループは、最大で反復するだけで境界条件を自動的に処理します。`n-1`。
