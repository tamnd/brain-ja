 ## 解決策
 ## 問題の理解

 ツリー内の頂点のすべてのサブセットにわたるグローバル合計を計算するように求められます。 入力は重み付けされていないツリーであり、`n`頂点。 このツリーから、任意の 2 つの頂点間の重みが元のツリー内のそれらの頂点間の距離に等しい完全なグラフを想像します。 次に、頂点のサブセットごとに、誘導されたサブグラフの最小スパニング ツリー (MST) を見つけ、すべてのサブセットにわたるこれらの MST の重みの合計が必要になります。 最終的な答えはモジュロで計算されます$10^9 + 7$。 

制約は次のことを教えてくれます$n$最大 5000 まで可能で、多くのテスト ケースが存在する可能性がありますが、合計は$n^2$すべてのテスト ケースの数は最大 2,500 万です。 これにより、頂点のすべてのサブセットを明示的に列挙するアルゴリズムは除外されます。$2^n$サブセットは、中程度の場合でも天文学的に大きくなります$n$。 また、$O(n^3)$テスト ケースごとの解決策は境界線に達するため、次のことを目指す必要があります。$O(n^2)$テストケースごとにそれ以上です。 

エッジ ケースは、ツリーの頂点が 1 つだけの場合に発生します。この場合、MST に含めるエッジがないため、合計はゼロになります。 同様に、直線であるツリーでは、MST エッジが強制されるサブセットが作成され、サブセットにエッジを含める方法とは関係なくエッジを扱うと、微妙なカウン​​ト エラーが発生する可能性があります。 

## アプローチ

 ブルートフォース手法では、頂点の各サブセットを考慮し、完全なグラフの誘導サブグラフ (重みは距離) を構築し、重みを合計して MST を計算します。 MST の計算はよく理解されているため、これは機能しますが、絶望的に遅いです。$2^n$サブセット。 たとえメモ化したとしても、急激な成長を許すことはできません。 

より高速なソリューションを実現するための重要な洞察は、完全なグラフではなくツリー構造自体を操作することです。 サブセットのすべての MST は、含まれるすべての頂点を接続する元のツリーのエッジのサブセットに対応します。 元のツリーの 1 つのエッジに注目すると、その重み (距離) は 1 です。エッジを一時的に削除すると、このエッジは、端点が異なる接続コンポーネント内にあるサブセットの MST 合計に正確に寄与します。 ノード間を接続するエッジの場合`u`そして`v`、 させて`a`のサブツリー内の頂点の数になります。`u`エッジを削除すると、`b = n - a`は、他のコンポーネントの頂点の数になります。 エッジは、両側の少なくとも 1 つの頂点を含むサブセットの MST に表示されます。 これらのサブセットを数えると、$(2^a - 1) * (2^b - 1)$各エッジにエッジの重みを乗算します。 これにより、問題は指数列挙から、単純な組み合わせカウントを使用したツリー エッジ上の単一パスに変換されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n^2) | O(n^2) | 遅すぎる |
 | 最適 | O(n^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、頂点の数を読み取ります。`n`そして木の端。 ツリーを表す隣接リストを作成します。 
2. を初期化します。`mod`変数へ$10^9 + 7$2 のべき乗モジュロを事前計算します`mod`まで`n`、必要になるため`2^k`サブツリーのサイズを頻繁に確認します。 これにより、各エッジの電力の再計算が回避されます。 
3. ツリー内の各エッジについて、それが削除されたものとみなします。 1 つのエンドポイントから深さ優先検索 (DFS) を実行してサイズを計算します。`a`エッジを越えずにそのエンドポイントから到達可能なサブツリーの。 サイズ`b`他のコンポーネントの`n - a`。 
4. 最終的な合計に対するこのエッジの寄与は積です。`(2^a - 1) * (2^b - 1)`。 これにエッジの重みを掛けます。この例では 1 です。 これをランニングサムモジュロに加算します`mod`。 
5. すべてのエッジに対してこれを繰り返します。 総和モジュロを出力します`mod`。 

機能する理由: エッジを削除すると、ツリーは正確に 2 つのコンポーネントに分割されます。 エッジは、サブセットに各コンポーネントの頂点が少なくとも 1 つ含まれている場合にのみ、サブセットの MST に表示されます。 各エッジに対してこの条件を満たすサブセットをカウントすると、各サブセットの MST は元のツリー内の頂点を接続するエッジによって一意に決定されるため、すべてのサブセット MST 重みが正確に 1 回カウントされることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10000)

mod = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        adj = [[] for _ in range(n)]
        edges = []
        for _ in range(n - 1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            adj[u].append(v)
            adj[v].append(u)
            edges.append((u, v))
        
        pow2 = [1] * (n + 1)
        for i in range(1, n + 1):
            pow2[i] = (pow2[i-1] * 2) % mod
        
        def dfs(u, parent):
            size = 1
            for v in adj[u]:
                if v != parent:
                    size += dfs(v, u)
            return size
        
        ans = 0
        for u, v in edges:
            # size of subtree if we remove edge u-v
            size_u = dfs(u, v)
            size_v = n - size_u
            contrib = ((pow2[size_u] - 1) * (pow2[size_v] - 1)) % mod
            ans = (ans + contrib) % mod
        print(ans)

solve()
```コードはまず、各テスト ケースの隣接リストを構築します。 2 の累乗モジュロを事前に計算します`mod`DFS での計算の繰り返しを避けるため。 各エッジについて、概念的にエッジを削除し、DFS を使用して 1 つのエンドポイントからサブツリー サイズを計算します。 エッジの寄与は次のようになります。`(2^size_u - 1) * (2^size_v - 1)`、それを和のモジュロに加算します。`10^9 + 7`。 使用する`sys.setrecursionlimit`これにより、DFS が深いツリーに対する Python の再帰制限に達しないことが保証されます。 

## 実用的な例

 3 つの頂点が 1-2-3 として接続されている最初のサンプルを考えてみましょう。 

| エッジ | サブツリーのサイズ (a,b) | 貢献 |
 | --- | --- | --- |
 | 1-2 | 1,2 | (2^1-1)_(2^2-1)=1_3=3 |
 | 2-3 | 1,2 | (2^1-1)_(2^2-1)=1_3=3 |

 合計は 6 で、予想される出力と一致します。 これは、小さなライン ツリーの場合、アルゴリズムがすべてのサブセットを正しくカウントしていることを示しています。 

単一のエッジ 2-1 を持つ木の場合 (n=2):

 | エッジ | サブツリーのサイズ | 貢献 |
 | --- | --- | --- |
 | 2-1 | 1,1 | (2^1-1)_(2^1-1)=1_1=1 |

 合計は 1 です。これは正しいです。これは、少なくとも 2 つの頂点を持つ空でない唯一のサブセットに両方の端点が含まれており、重み 1 の MST を形成しているためです。
