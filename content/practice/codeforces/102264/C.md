 ## 解決策
 ## 問題の理解

 部屋は下に境界がある半平面です。`y = 0`以上により`y = H`。 各ラダーは、ある整数の垂直セグメントです。`X`、高さから`A`高さまで`B`。 フリンはどこにでも水平方向に移動できますが、垂直方向の移動ははしごに乗っている間のみ可能です。 

ヘビも垂直セグメントですが、障害物です。 あるところのヘビ`x`それを横切る水平方向の動きをブロックします`x`2 つの端点間のすべての高さについて。 その端点は障害物に含まれるため、長さ 0 のヘビは 1 つの正確な高さをブロックできます。 ヘビのコストは垂直の長さです。 

タスクは、からの連続したルートが存在しないように、最小の全長を持つヘビを選択することです。`(0,0)`に`(0,H)`。 フリンがすでにヘビなしではその旅行をすることができない場合、答えは次のとおりです。`0`。 有限のヘビのコレクションが彼女を止められない場合、答えは次のとおりです。`-1`。 

はしごはせいぜい50個くらいですが、`H`100,000も可能です。 これにより、整数の高さおよびラダーごとに 1 つの状態を持つグラフは即座に除外されます。1 つのテスト ケースでも数百万の状態が作成される可能性があり、最大 150 のテスト ケースがあるからです。 有益な観察は、はしごの配置の構造が変化する高さははしごの終点だけであるということです。 多くてもあります`2N`このような高さがあるため、連続問題は次のように圧縮できます。`O(N)`関連するレベル。 

特に危険なエッジケースは、フリンがすでに閉じ込められている部屋です。 例えば、```
1
2 100
1 0 49
1 50 100
```与える```
Case #1: 0
```2つのはしごは同じです`x`座標は一致しますが、重なり合わないため、フリンは一方から他方へ垂直に移動できません。 ヘビを追加する必要はありません。 ヘビを配置する必要があると盲目的に仮定する解決策は、肯定的な答えを生み出します。 

もう 1 つの重要なケースは、可能な唯一のトランジションが床または天井を使用する場合です。 例えば、```
1
3 9
33 0 6
66 0 9
99 3 9
```与える```
Case #1: -1
```1 つ目と 2 つ目のはしごは床で重なり、2 つ目と 3 つ目は天井で重なり合います。 ヘビはどちらの境界にも触れることができないため、どちらの遷移もブロックできません。 長さゼロのオーバーラップまたはエンドポイントを通常の有限コストカットとして扱うソリューションは、誤って次の結果を返します。`0`。 

3 番目のエッジ ケースは、長さがゼロのスネークです。 例えば、```
1
2 5
1 0 2
2 2 5
```答えがあります`0`。 はしごは高さで交わる`2`、そしてちょうどそれらの間に配置された長さゼロのヘビ`y = 2`唯一の遷移をブロックします。 ヘビは 1 つのポイントのみを占有するため、コストはゼロです。 すべての有用なスネークが正の長さであることを必要とする実装では、このケースは見逃されます。 

## アプローチ

 最も直接的なアプローチは、すべての整数の高さを離散化することです。 あらゆる高さで、どのはしごが存在するか、どの水平遷移が可能かを記録し、結果として得られる状態グラフを検索できます。 問題はそれです`H`は 100,000 まで可能で、最大 50 個の各はしごがあらゆる高さと相互作用できます。 グラフ`O(NH)`1 つの部屋に州が 500 万州に達することもありますが、すべてのテスト ケースを考慮すると多すぎます。 

フリンの動きは水平方向と垂直方向の可能性のグラフとして見ることができるため、強引なアプローチは概念的には正しいです。 問題は、これらの高さのほとんどすべてが区別できないことです。 2 つの連続するはしごの終点間では何も変化しません。 ヘビはそこで継続的に移動できますが、その間隔内では新しい組み合わせの選択肢はありません。 

重要な観察は、問題を反対側から見ることです。 フリンが床側から天井側に移動するのを防ぐバリアを構築しようとしていると想像してください。 既存のはしごはそのような障壁にとって障害になります。 バリアは空の垂直ストリップを通って垂直に移動でき、その移動には使用されるヘビの長さの量とまったく同じコストがかかります。 はしごの終点では、バリアは追加コストなしで終点の周りを通過し、はしごの左側から右側に切り替えることができます。 これは問題を平面双対的に見たものです。 

はしごの終点のみが重要です。 2 つの連続する終点の高さの間では、はしごのセットは一定であるため、その間隔内で垂直に移動すると、単位高さあたりのコストは常に同じになります。 したがって、はしご間の垂直ギャップで構成されるすべてのペアに対してノードを作成できます。`x`座標と内部ラダー終点の高さ。 

1 つのギャップ内で、連続するエンドポイントの高さが、その差がコストとなるエッジに接続されます。 はしごの終点の周りを横切ると、その左右の 2 つのギャップがゼロコスト エッジですぐに接続されます。 ハイツ`0`そして`H`はスネーク エンドポイントとして使用できないため、有限バリア グラフから除外されます。 バリアが床または天井のはしごを横切らなければならない場合、その移行をブロックすることは不可能であり、まさにこれが状況を生み出します。`-1`。 

このグラフを作成する前に、まずフリンがヘビなしで天井に到達できるかどうかを確認します。 すべてのはしごを頂点として扱い、垂直間隔が交差するときに 2 つのはしごを接続します。 床に接触しているはしごは開始頂点であり、天井に接触しているはしごは終点頂点です。 目的地に到達できない場合、答えはすぐに得られます`0`。 目的地に到達可能な場合、考えられるすべてのバリアが境界を通過しない限り、最小バリア問題は有限です。 

結果として得られるグラフには、`O(N^2)`州。 次に、ダイクストラのアルゴリズムは、バリアの垂直方向の最小全長を見つけます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 整数高さのブルート フォース | O(NH + N²H) | O(NH) | 遅すぎる |
 | エンドポイント圧縮された最短パス | O(N² log N) | O(N²) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのラダーを読み取り、それぞれのラダーを分類します`X`コーディネート。 これらの座標は部屋を垂直方向のギャップに分割します。 ギャップとは、2 つの連続するはしごのすぐ間の領域です。`x`すべてのはしごの左側に 1 つ、右側に 1 つ余分なギャップがあります。 
2. ヘビのいない到達可能性を確認します。 ラダー上に区間重複グラフを作成します。 閉じた垂直間隔が交差する場合、2 つのはしごは隣接しています。 すべてのはしごから開始します`A = 0`、はしごがあるかどうかを確認してください。`B = H`到達可能です。 これは、ヘビが存在しないときにフリンが行うことができる動きを正確に捉えています。フリンは同じ高さで水平方向に、はしごに沿って垂直方向に移動できるからです。 
3. 天井梯子が届かない場合は、戻ります。`0`。 フリンはすでに旅を完了できないため、スナイダーは何も配置する必要はありません。 
4. 部屋の内側にあるすべてのはしごの終点を厳密に収集します。`A`そして`B`満足のいく`0 < y < H`、個別の値を並べ替えます。 これらは、組み合わせ構造が変化する唯一の高さです。 
5. ペアごとに 1 つのグラフ ノードを作成します`(gap, y)`どこ`y`内部エンドポイントの高さの 1 つです。 ノードは、バリアが現在その高さの垂直ギャップ内にあることを意味します`y`。 
6. すべてのギャップ内で、連続するエンドポイントの高さを接続します。 2つの高さがある場合、`y1 < y2`、エッジコストを与える`y2 - y1`。 これらの高さの間で障壁を移動するには、まさにその長さのヘビが必要です。 
7. すべてのはしごについて、その 2 つの端点を調べます。 内部エンドポイントで`y`、ノードを接続します`(left_gap, y)`と`(right_gap, y)`コストゼロのエッジを使用します。 バリアは、垂直方向の長さを費やすことなく、はしごの終点の周りを回ることができます。 エンドポイントが床または天井にある場合は、ヘビがこれらの境界に触れることを禁止されているため、そのような有限遷移を追加しないでください。 
8. 床に触れる梯子の上にあるすべての内部エンドポイントの高さからダイクストラを初期化します。 そのはしごの両側が存在する場合、その両側が有効な開始位置となります。 はしごに沿って移動するのにコストはかからないため、そのような状態はすべて距離 0 から始まります。 
9. 同様に、天井に届く梯子の上にあるすべての内部エンドポイントは、目的の状態です。 これらの状態の中で最小のダイクストラ距離が必要な答えになります。 
10. バリア グラフで到達可能な目的の状態がない場合、出力`-1`。 これは、可能な限り分離するには、ヘビが触れることを許可されていない床または天井を使用する必要があることを意味します。 

### なぜ効果があるのか

 不変条件は、すべてのグラフ パスが有効なバリアを表し、すべての有効な最小バリアは長さを増やさずにグラフ パスに変換できるということです。 ヘビの垂直部分は 1 つのギャップ内にあり、合計重量がその長さに等しい垂直グラフ エッジによって表されます。 バリアがはしごの一方の側からもう一方の側に変化するときは常に、端点を迂回する必要があります。これは、その端点でのゼロコスト遷移によって表されます。 はしごの終点間には構造的な変化がないため、折り返し点を終点に移動しても、必要な垂直方向の長さが増加することはありません。 初期状態と最終状態は、フリンが床から天井まで使用できるはしごに対応しています。 したがって、最短のグラフ パスは正確に最小合計スネーク長になります。 

## Python ソリューション```python
import sys
import heapq

input = sys.stdin.readline

INF = 10**30

def solve_case():
    n, H = map(int, input().split())
    ladders = [tuple(map(int, input().split())) for _ in range(n)]

    # First check whether Flynn can already reach the ceiling.
    start = [i for i, (_, a, _) in enumerate(ladders) if a == 0]
    target = [i for i, (_, _, b) in enumerate(ladders) if b == H]

    reachable = [False] * n
    stack = start[:]
    for i in start:
        reachable[i] = True

    while stack:
        u = stack.pop()
        _, au, bu = ladders[u]

        for v in range(n):
            if reachable[v] or v == u:
                continue

            _, av, bv = ladders[v]

            if max(au, av) <= min(bu, bv):
                reachable[v] = True
                stack.append(v)

    if not any(reachable[i] for i in target):
        return 0

    # Distinct x coordinates define vertical gaps.
    xs = sorted(set(x for x, _, _ in ladders))
    x_id = {x: i for i, x in enumerate(xs)}

    # Each ladder at x=xs[k] has gap k on its left and k+1 on its right.
    gap_count = len(xs) + 1

    # Only internal heights matter for finite snakes.
    ys = sorted({
        y
        for _, a, b in ladders
        for y in (a, b)
        if 0 < y < H
    })

    if not ys:
        # If there is a reachable floor-to-ceiling ladder chain but
        # there are no internal endpoints, every relevant ladder
        # touches a boundary. No finite snake can separate it.
        return -1

    y_id = {y: i for i, y in enumerate(ys)}
    k = len(ys)

    # Node (gap, y-index).
    total_nodes = gap_count * k

    def node(g, yi):
        return g * k + yi

    graph = [[] for _ in range(total_nodes)]

    def add_edge(u, v, w):
        graph[u].append((v, w))
        graph[v].append((u, w))

    # Vertical movement inside every empty gap.
    for g in range(gap_count):
        base = g * k
        for i in range(k - 1):
            w = ys[i + 1] - ys[i]
            add_edge(base + i, base + i + 1, w)

    # Crossing around ladder endpoints.
    for x, a, b in ladders:
        g = x_id[x]

        # Internal bottom endpoint.
        if 0 < a < H:
            yi = y_id[a]
            if g > 0:
                add_edge(node(g, yi), node(g - 1, yi), 0)
            if g + 1 < gap_count:
                add_edge(node(g, yi), node(g + 1, yi), 0)

        # Internal top endpoint.
        if 0 < b < H:
            yi = y_id[b]
            if g > 0:
                add_edge(node(g, yi), node(g - 1, yi), 0)
            if g + 1 < gap_count:
                add_edge(node(g, yi), node(g + 1, yi), 0)

    # We need only finite barrier paths that start on a floor ladder
    # and end on a ceiling ladder. Starting/ending at any internal
    # endpoint on such a ladder costs zero.
    dist = [INF] * total_nodes
    pq = []

    def seed_ladder(x, a, b):
        g = x_id[x]

        for yi, y in enumerate(ys):
            if a <= y <= b:
                if g > 0:
                    u = node(g, yi)
                    if dist[u] != 0:
                        dist[u] = 0
                        heapq.heappush(pq, (0, u))

                if g + 1 < gap_count:
                    u = node(g + 1, yi)
                    if dist[u] != 0:
                        dist[u] = 0
                        heapq.heappush(pq, (0, u))

    for x, a, b in ladders:
        if a == 0:
            seed_ladder(x, a, b)

    target_nodes = set()

    for x, a, b in ladders:
        if b == H:
            g = x_id[x]

            for yi, y in enumerate(ys):
                if a <= y <= b:
                    if g > 0:
                        target_nodes.add(node(g, yi))
                    if g + 1 < gap_count:
                        target_nodes.add(node(g + 1, yi))

    while pq:
        d, u = heapq.heappop(pq)

        if d != dist[u]:
            continue

        if u in target_nodes:
            return d

        for v, w in graph[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))

    return -1

def main():
    t = int(input())
    out = []

    for case_id in range(1, t + 1):
        ans = solve_case()
        out.append(f"Case #{case_id}: {ans}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```最初のグラフ検索は、最短パスの計算とは意図的に分離されています。 それは、そもそも有限の答えが必要かどうかという別の質問に答えます。 フリンははしごの終点で正確に水平に移動できるため、間隔オーバーラップ テストでは閉じた間隔が使用されます。 

2 番目のグラフは内部エンドポイントの高さのみを使用します。 これがメインの圧縮です。 最大でも存在する可能性があります`2N - 2`このような高さなので、せいぜい`N + 1`隙間しかない`O(N²)`州。 

垂直エッジは、連続する高さの差を使用します。 それらの合計は、対応するヘビの部分の長さと正確に一致します。 エンドポイントの高さは重複排除されているため、差がゼロになることはありません。 

ゼロコストの遷移はラダーのエンドポイントで作成されます。 境界例`y = 0`そして`y = H`意図的に排除されています。 ヘビはどちらの境界にも触れることができないため、境界の端点を通常のはしごの端点のように扱うと、不可能な分離が有限の分離に誤って変換されてしまいます。 

Python の整数には制限がないため、オーバーフローの問題はありません。`INF`可能な答えよりも大きいだけで十分です。`10**30`関連する最大全長をはるかに超えています。 

## 実用的な例

 ### サンプル 1

 部屋には 2 つのはしごがあります。```
L0: x = 0, [0, 3]
L1: x = 1, [1, 4]
```最初のはしごは床に到達し、2 番目のはしごは天井に到達するため、フリンはヘビなしでそれらの間を移動できます。 関連する内部の高さは次のとおりです。`1`そして`3`。 

| 状態 | アクション | コスト | 距離 |
 | --- | --- | --- | --- |
 | y=3 での L0 | 床はしごから始めます | 写真 床はしごから始めます 0 | 0 |
 | L0 と L1 の間のギャップ、y=3 | L0の上部を回る | 0 | 0 |
 | L0 と L1 の間のギャップ、y=1 | 垂直に移動 | 2 | 2 |
 | y=1 での L1 | L1の下を回る | 0 | 2 |

 パスには合計コストがあります`3 - 1 = 2`、したがって、答えは次のとおりです`2`。 

このトレースは、長さ 2 のヘビが機能する理由も示しています。 これは高さ 1 と高さ 3 の間のセグメントを占め、2 つのはしご間の水平方向の交差をすべてブロックします。 

### サンプル 2

 ２つのはしごは、```
L0: x = 1, [0, 49]
L1: x = 1, [50, 100]
```彼らも同じものを持っています`x`座標は一致しますが、垂直方向の間隔はバラバラです。 

| 現在のラダー | 候補者はしご | 交差点 | 結果 |
 | --- | --- | --- | --- |
 |`[0,49]`|`[50,100]`| 空 | エッジなし |
 |`[0,49]`| それ自体 |`[0,49]`| すでに代表されています |

 はしご重なり探索では、床はしごから天井はしごまでは到達できません。 スナイダーが何かを置く前にフリンは閉じ込められているので、答えは次のとおりです。`0`。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(N² log N) | O(N²) 個の圧縮状態とエッジがあり、その後にダイクストラ | が続きます。 
| スペース | O(N²) | 圧縮されたグラフには O(N²) 個のノードとエッジが含まれています。 

と`N <= 50`、圧縮されたグラフには、部屋ごとに数千の状態しか含まれていません。 の値`H`100,000 の場合でも、エッジの重みには影響しますが、状態の数には影響しません。 これが、ソリューションがすべてのテスト ケースに対して十分に小さいままである主な理由です。

## 特殊なケース

 フリンがすでに天井に到達できない部屋の場合、間隔オーバーラップ グラフはバリアの計算前にこれを検出します。 入力で```
1
2 100
1 0 49
1 50 100
```2 つのはしごには共通の高さがありません。 最初のラダーから開始された DFS は 2 番目のラダーに到達しないため、アルゴリズムはリターンします。`0`。 

境界のオーバーラップの場合、オーバーラップ自体は有限のバリアを作成するには十分ではありません。 で```
1
3 9
33 0 6
66 0 9
99 3 9
```最初の遷移は次の時点で可能です`y = 0`そして2回目は`y = 9`。 バリア グラフは、これらの境界の高さで有限のエンドポイント遷移を意図的に作成しません。 したがって、ダイクストラは有限分離を生成できず、`-1`。 

内部単一点遷移の場合、エンドポイントはグラフに含まれており、それを横切るコストはゼロです。 で```
1
2 5
1 0 2
2 2 5
```両方のはしごが使用可能です`y = 2`。 その高さでそれらの間に配置された長さゼロのヘビがトランジションをブロックします。 アルゴリズムは内部エンドポイントで両側をシードし、距離 0 を取得します。 

部屋全体にまたがるはしごの場合、有限のバリアを開始または終了できる内部終点はありません。 到達可能性チェックでは、床と天井が同じはしごで接続されていることがわかりますが、バリア グラフにはそれらを区切る有限のルートがありません。 正しい結果は`-1`。 

同じはしごが複数ある場合`x`、はしごは重なることができないため、各はしごは個別の垂直コンポーネントのままになります。 この構造は、単に 2 つの梯子を共有するという理由だけで、そのような 2 つの梯子を接続するものではありません。`x`座標。 それらは、元の移動ルールが要求するとおりに、共通の高さでの有効な水平移動によってのみ接続されます。
