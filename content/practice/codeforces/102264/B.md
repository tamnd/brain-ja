 ## 解決策
 ## 問題の理解

 一連の`A`そして`B`投票は学生証順に並べられます。 代表的なセットは、この文字列の連続した区間です。 安全な間隔を保つために、ベティは次の値を超えてはなりません。`K`エイミーに投票します。 同様に、`A`として`+1`そして`B`として`-1`、すべての連続する部分配列は少なくとも合計を持たなければなりません`-K`。 

代表的な間隔を選択する前に、いくつかの変更を行う可能性があります。`B`に投票する`A`投票。 生徒の変更`i`費用`2^i`, したがって、初期の学生は指数関数的に安くなります。 タスクは、実際のコストを最小限に抑えながら、すべての間隔が安全になるように投票を変更する学生のセットを選択することです。 その最小値を見つけた後にのみ、それを剰余として計算します`1,000,000,007`。 

位置で終わるプレフィックスの場合`i`、その残高を次の数とします。`A`投票数から投票数を引いた`B`投票。 プレフィックス残高が`P_0, P_1, ..., P_N`、次に間隔のバランス`[l, r]`は`P_r - P_{l-1}`。 この値が以下の場合にベティが勝ちます。`-K`したがって、必要な条件は次のとおりです。`P_r >= P_{l-1} - K`あらゆる人にとって`l <= r`。 左から右にスキャンしている間、これは、現在のプレフィックス残高がこれ以上低下することはないことを意味します。`K`これまでに見られた最大のプレフィックス残高を下回っています。 

の値`N`100万に達する可能性があります。 アン`O(N^2)`このメソッドは次の順序で検査します`10^12`最悪の場合の間隔は完全に不可能です。 アルゴリズムは各生徒を一定の回数処理する必要があります。`O(N)`ターゲット。 テストケースの数も多いため、Python では不要な対数係数や大きな補助構造が問題になります。 

もっともらしい実装を簡単に破ってしまう境界例がいくつかあります。 と`N = 1`、`K = 0`、 そして`V = B`、答えは`2`、唯一の代表セットは 1 人の生徒であり、そうでなければベティが勝つからです。 少なくとも 2 の長さの間隔のみをチェックする不注意な実装では、ゼロが返されます。 

と`N = 4`、`K = 0`、 そして`V = BAAB`、答えは`18`。 生徒 1 だけを反転すると長い間隔は安全になりますが、生徒 4 は依然としてベティのみの代表セットであるため、これも反転する必要があります。 プレフィックスのみのチェックでは、そのシングルトン間隔が通知なく見逃される可能性があります。 

と`N = 4`、`K = 1`、 そして`V = ABBA`、答えは`4`、 ない`8`。 悪い間隔は生徒 2 から 3 で、最も安いです`B`中には生徒 2 がいます。違反が検出された場合に常に現在の生徒を反転させる貪欲なルールでは、生徒 3 を反転させて料金を支払うことになります。`8`。 

最後に、いつ`K = N`、答えは常にゼロです。 空でない代表セットには、以下の値を超えるものはありません。`N`ベティに投票するため、ベティはエイミーを超えることはできません`K`。 厳密な不等式を間違った方向に使用する実装では、ここで誤って反転が実行される可能性があります。 

## アプローチ

 直接的なアプローチは、可能なすべての生徒セットを反転させてから、すべての連続する代表セットを検証することです。 がある`2^N`学生の考えられる選択肢、そして 1 つの選択肢をチェックするだけでも検討が必要です`O(N^2)`間隔。 非常に小規模な場合、これはすでに絶望的です`N`。 

より合理的なブルートフォースにより、反転される生徒の数が修正され、可能な限り安価な生徒が選択されます。 費用がかかるので、`2^i`、一定の生徒数の場合は、早めに利用したほうが常に安くなります`B`有権者。 その後、最初の`m` `B`有権者は十分です。 これにより、単調な実現可能性条件が与えられ、二分探索が可能になりますが、すべての実現可能性チェックでは文字列全体がスキャンされるため、次のようになります。`O(N log N)`時間。 

違反の構造により、より強力な線形ソリューションが得られます。 プレフィックスをスキャンしている間は、これまでに確認された最大の有効なプレフィックス バランスを維持します。 現在の残高が最大マイナス額以上であれば`K`、ここで終了するすべての間隔は安全です。 現在の残高が小さい場合、左端が最大プレフィックス残高に達する位置の直後にある不正な間隔が存在します。 

その位置が`p`。 この悪い間隔を修復するには、必ず問題を解決する必要があります。`B`どこかで`[p + 1, i]`。 厳密に学生指数に応じてコストが増加するため、最も安価な選択は反転されていない左端の選択になります。`B`その合間に。 まさにその生徒を反転させます。 

選択された位置は右に単調に移動します。 一回`B`は、現在の不良間隔が始まる前に存在しますが、将来の不良間隔は現在の不良間隔よりも早く開始されることはないため、後の違反には決して役に立ちません。 これにより、次の対象者を見つけるための単一の前方ポインタが得られます。`B`。 

微妙な点が 1 つあります。 反転学生`p`からのすべてのプレフィックスの有効バランスを変更します。`p`までに`2`、すでに処理されたプレフィックスを含みます。 最大プレフィックス バランスを正しく維持するために、元のプレフィックス合計に対して単調デキューを維持します。 フリップ時`p`が作成されると、元のプレフィックス合計の最大値が計算されます。`[p, i]`両端キューから取得でき、`2`フリップ回数の倍が加算されます。 この範囲の左端点は右にのみ移動するため、デキューは線形時間で維持できます。 

その結果、左から右への 1 回のスキャンで、生徒ごとに一定の償却作業が行われます。

 | フリップ セットと間隔を列挙する |`O(2^N N^2)`|`O(N)`| 遅すぎる |
 | 二分探索フリップ数 |`O(N log N)`|`O(N)`| 不必要に遅い |

 ## アルゴリズムのチュートリアル

 1. 毎回エンコードする`A`として`+1`そしてすべての`B`として`-1`、元のプレフィックス合計を維持します`P`。 学生の場合`i`からのすべての有効なプレフィックスが反転されました。`i`今後の利益`2`。 
2. メンテナンス`max_balance`そして`max_pos`、現在の学生よりも厳密に前のポジションと、その最大値が発生する最も早いポジション間の最大の有効プレフィックスバランスを表します。 最も早いポジションは、不良間隔が可能な限り広くなり、その結果、適格なポジションが最も安価になるため便利です。`B`。 
3. ポインタを維持する`next_b`最も早い時期に`B`まだ選択されていないもの。 ポインタは前方にのみ移動します。 その後に違反が始まった場合`max_pos`、 どれでも`B`前に`max_pos + 1`その違反は修復できないため、最初の位置に到達するまでポインタを進めます。`B`その境界上、またはその境界以降。 
4. 学生時代`i`、現在の実効残高を次のように計算します。`P + 2 * flips`、 どこ`flips`これまでに選ばれた生徒の数です。 これが少なくとも`max_balance - K`、現在のエンドポイントは新しい違反を作成しません。 必要に応じて最大値を更新します。 
5. 現在の残高が以下の場合`max_balance - K`、から始まる間隔`max_pos + 1`そして終わる`i`悪いです。 反転されていない最も古いものを選択します`B`この間隔で。 これは、新たに発見された違反を修復できる最も安価な生徒です。 
6. 選択した生徒の費用を答えのモジュロに加算します。`1,000,000,007`。 検索に使用されるポインタ`B`位置には対応する 2 のべき乗も含まれるため、すべてのべき乗の配列は必要ありません。 
7. ポジション選択後`p`、すべての元のプレフィックスの合計は、`p`を通して`i`増加する`2`効果的な順序で。 前に両端キューエントリを削除してください`p`、両端キューに残っている元のプレフィックス合計の最大値を取得し、追加します`2 * flips`、古い最大値と比較します。 新しい値が厳密に大きい場合は、更新します`max_balance`そして`max_pos`。 
8.すべて終わるまで続けます`N`学生は処理されました。 考えられるすべての代表的な間隔がその適切なエンドポイントを通じて考慮され、すべての違反は可能な限り安価な資格のある学生によって修復されています。 

### なぜ効果があるのか

 不変条件は、処理後の位置です。`i`、またはそれ以前に終了するすべての代表的な間隔`i`は安全であり、選択された生徒は、これまでに発生した違反に対する貪欲なプロセスによって行われた最も安価な選択です。 新しい違反が発生した場合、その左側のエンドポイントは最大プレフィックスバランスによって決定されます。 有効な解決策はすべて、`B`その区間の外で生徒を変更しても、その区間の投票差を変えることはできないためです。 対象となるすべての反転されていないものの中で`B`有権者にとって、左端のコストが最小になります。 これを選択することで、将来のソリューションのコストが高くなるわけではありません。改善できるのはその位置またはその位置より前で始まる間隔だけであり、その後の間隔は改善されるからです。`B`今後の違反に対しても利用可能です。 したがって、各貪欲な選択は最適なソリューションと互換性があり、すべてのエンドポイントを処理することで、すべての連続する代表セットに必要な保証が確立されます。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

MOD = 1_000_000_007

def solve():
    t = int(input())
    out = []

    for case in range(1, t + 1):
        n, k = map(int, input().split())
        s = input().strip()

        # Monotonic deque of (index, original_prefix_sum).
        # Values are decreasing, and equal values keep the earliest index.
        dq = deque([(0, 0)])

        prefix = 0
        flips = 0

        # Maximum effective prefix sum among processed prefixes.
        max_balance = 0
        max_pos = 0

        # Earliest B which has not been selected yet.
        next_b = 0

        # 2^next_b modulo MOD.
        next_b_cost = 1

        answer = 0

        for i, ch in enumerate(s, 1):
            if ch == 'A':
                prefix += 1
            else:
                prefix -= 1

            # Add current original prefix sum to the monotonic deque.
            while dq and dq[-1][1] < prefix:
                dq.pop()
            dq.append((i, prefix))

            current = prefix + 2 * flips

            if current < max_balance - k:
                # The bad interval starts at max_pos + 1.
                left = max_pos + 1

                # Move to the first unflipped B inside that interval.
                while next_b < left:
                    next_b += 1
                    next_b_cost = next_b_cost * 2 % MOD

                while next_b < i and s[next_b] != 'B':
                    next_b += 1
                    next_b_cost = next_b_cost * 2 % MOD

                # A violation cannot exist without an eligible B.
                # next_b is necessarily <= i and s[next_b] == 'B'.
                p = next_b

                answer = (answer + next_b_cost) % MOD
                flips += 1

                # After flipping p, all prefixes from p onward
                # gain 2. Remove prefixes before p from the range
                # whose maximum needs to be reconsidered.
                while dq and dq[0][0] < p:
                    dq.popleft()

                shifted_max = dq[0][1] + 2 * flips

                # Keep the earliest position on ties.
                if shifted_max > max_balance:
                    max_balance = shifted_max
                    max_pos = dq[0][0]

                # The selected B is no longer available.
                next_b += 1
                next_b_cost = next_b_cost * 2 % MOD

            else:
                if current > max_balance:
                    max_balance = current
                    max_pos = i

        out.append(f"Case #{case}: {answer}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```プレフィックスの合計`prefix`は常に元の投票文字列を参照します。 選択されたすべての生徒の効果は、次のように個別に表されます。`2 * flips`選択されたすべての生徒のインデックスが現在のスキャン位置以下であるためです。 

の`dq`元のプレフィックスの合計が降順で含まれます。 新しいプレフィックス合計が到着すると、後ろの小さい値が将来の範囲の最大値になることはあり得ませんが、大きい値は前に残るため、それらは破棄されます。 等しい値は破棄されず、最大値に達した最も早いインデックスが保持されます。 最大値を早めると可能な限り安くなるため、このタイの選択は重要です。`B`違反が発生したとき。 

の`next_b`ポインターは決して後方には移動しません。 最初に現在の不良間隔より前の位置をスキップし、次にスキップします。`A`最初の適格なポジションに達するまでポジションを獲得する`B`。 その生徒が選択されると、ポインターがその生徒を通過します。 すべての位置は、このポインタによって最大 1 回渡されます。 

コスト変数`next_b_cost`から始まります`2^0 = 1`。 ポインタがその位置から移動するたびに`x`に`x + 1`、コストは次のように乗算されます。`2`モジュロ`MOD`。 したがって、いつ`next_b`学生を指す`i`、`next_b_cost`まさに`2^i mod MOD`。 

違反に関する操作の順序は重要です。 新しく選択された学生が現在の学生である可能性があり、反転後にそのプレフィックスが新しい最大値に参加する必要があるため、違反をチェックする前に現在の元のプレフィックスが両端キューに挿入されます。 違反自体は、次のように表される、以前の有効なプレフィックスの最大値と比較してチェックされます。`max_balance`、現在のプレフィックスが通常の新しい最大値として受け入れられる前に。 

Python の整数はオーバーフローしませんが、すべてのコストは剰余で削減されます`MOD`すぐに。 プレフィックスバランス自体は次の範囲内に留まります。`-N`そして`N`なので、特別な処理は必要ありません。 

## 実用的な例

 ### サンプル 1

 のために`N = 4`、`K = 0`、 そして`V = BAAB`、元のプレフィックス残高は次のとおりです。`0, -1, 0, 1, 0`。 最初の生徒はすぐに不正な間隔を作成するため、生徒 1 が選択されます。 その後、二人のその後、`A`投票すると、生徒 4 が別の不良間隔を作成するため、生徒 4 が選択されます。

### サンプル 2

 のために`N = 4`、`K = 1`、 そして`V = BAAB`、 最初`B`ベティが 1 票だけリードしているため許可されます。 後者`B`閾値以下では無害であるため、生徒が転向することはありません。
