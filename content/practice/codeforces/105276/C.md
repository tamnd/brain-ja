 ## 解決策
 ## 問題の理解

 グリッドは、中央のセルの周囲にある同心円状の正方形のリングのセットとして考えることができます。 サイズが奇数であるため、中心は 1 つであり、他のすべてのセルは正確に 1 つのリングに属します。 リングは境界線から固定マンハッタン距離にあるすべてのセルで構成され、各リングは時計回りに移動するとサイクルを形成します。 

各リングは独立して回転できます。 1 回回転すると、そのサイクルに沿ってすべての文字が 1 位置ずつ移動し、どちらの方向に回転しても構いません。 すべてのリングの回転量を選択した後、新しいグリッド構成を取得します。 

目標は、2 つの完全なグリッドを一致させたり、構造をグローバルに保持したりすることではありません。 代わりに、最終グリッドの 2 つの主対角線のみを考慮します。 回転後は、両方の対角線上のすべての位置に同じ文字が含まれている必要があるため、「X」上のすべてのセルが等しくなければなりません。 

主な難点は、各対角セルが何らかのリングに属しており、リングを回転させると複数の対角位置が一度に変更されることです。 したがって、問題は、最小の総回転コストですべての対角セルが一貫した値に揃うように、リングごとにどれだけ回転させるかを選択することになります。 

制約により、$N \le 100$, したがって、グリッドには最大でも 10,000 個のセルがあります。 二次関数以上の解$N$安全です。 リングごとのすべての回転にわたる完全なシミュレーションは大きすぎます。$O(N)$ポジションがあり、$O(N)$リングなので、リングごとのシフトに対する単純な検索は次のようになります。$O(N^3)$繰り返し再計算されるとさらに悪化します。 

微妙なエッジケースが現れるのは、$N = 1$。 グリッドにはセルが 1 つだけあり、両方の対角線は同じ単一セルです。 回転しても何も変わらないため、答えは常に 0 です。 

もう 1 つの点は、各対角セルは 1 つのリング内にのみ表示されますが、1 つのリングが複数の対角セルに寄与する可能性があることです。 各セルを個別に誤って処理すると、同じリングに一貫性のないシフトが割り当てられ、不可能な構成が生成される可能性があります。 

## アプローチ

 強引なアイデアは、各リングを個別に扱い、そのリングに対して可能なすべての回転量を試すことです。 各候補のシフトについて、それを頭の中で適用し、2 つの対角線が均一になるかどうかを確認します。 長さのあるリングなので、$L$もっている$L$可能性のあるシフト、および大まかにあります$N/2$リングが鳴る、これはおおよその結果につながります$O(N^2)$リングごとの状態と$O(N^3)$チェックするのが遅すぎます。 

重要な観察は、リングの回転は、そのリング上のすべての位置に対して同時に循環アラインメントを選択することと同等であるということです。 リング内のすべての対角セルは、回転後のサイクルで同じ「ターゲット インデックス」に一致する必要があります。 したがって、グリッド セルの観点から考える代わりに、視点を各リングの循環文字列に切り替えます。 

各リングについて、それに属するすべての対角位置を考慮します。 このような位置ごとに制約が課せられます。リングが次のように回転すると、$k$の場合、その位置はリングのサイクル内の何らかのインデックスにマップされ、そのインデックスの文字は対角線のグローバル ターゲット文字と等しくなければなりません。 すべての対角セルは最終的に同一になる必要があるため、最終値として考えられる各文字を効果的にテストし、最小コストを個別に計算します。 

固定ターゲット キャラクタの場合、各リングは独立したコスト、つまりリング内のすべての対角位置がそのキャラクタを含むセルに着地するために必要な最小回転数に寄与します。 これは、そのリングのすべてのシフトを試し、最良のものを採用することで計算されます。 

これにより、問題は完全に切り離されます。リングは、最後に選択された文字を介する場合を除いて相互作用しません。

## アルゴリズムのチュートリアル

 1. 離れた位置にあるセルをペアにして、グリッドのすべてのリングを識別します。$k$国境から、のために$k = 0$に$(N-1)/2$。 各リングは時計回りの座標のリストとして保存されます。 

回転は単純なインデックス シフトになるため、この順序は重要です。 
2. リングごとに、そのサイクルに沿って文字のシーケンスを抽出します。 同時に、どのインデックスが対角セルに対応するかを記録します。 

このステップでは、目的にとって重要なグリッドの部分のみを分離します。 
3. 候補文字のセットを決定します。 最終的な値は、最適な配置で既存の対角文字から取得する必要があるため、通常、これらはいずれかの対角線上に現れるすべての文字です。 

他の文字は、すべての対角線上の出現を不一致に置き換える必要があるため、コストを削減できません。 
4. 各候補文字について、ゼロに初期化された合計コストを計算します。 
5. 各リングについて独立して、そのリング内のすべての対角位置が候補文字と一致するために必要な最小回転数を計算します。 

これを行うには、可能なすべての回転オフセットを試してください。$s$。 オフセットごとに、リング内のすべての対角位置を確認し、シフト後に候補文字にマップされるかどうかを確認します。 最適な有効オフセットは、その絶対シフト距離に影響します。 
6. 候補キャラクターのすべてのリングにわたる寄与を合計します。 
7. すべての候補文字の最小値を取得します。 

### なぜ効果があるのか

 各リングは環状構造であり、その状態は 1 つの回転オフセットによって完全に決定されます。 そのリング内の対角セルは、そのオフセットの決定論的な関数になります。 最後の要件では、すべてのリングにわたるすべての対角セルが 1 つの値に等しくなるように強制されるため、最初にその値を固定してから、リングを個別に最適化できます。 独立性は、個別のリングの回転が互いに影響を及ぼさないという事実から得られるため、総コストは、固定ターゲット キャラクターの下でのリングごとの最小位置合わせコストの合計になります。 この追加構造により、グローバル カップリングが失われないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    g = [input().strip() for _ in range(n)]

    rings = []
    mid = n // 2

    # build rings
    for layer in range(mid + 1):
        coords = []

        top, left = layer, layer
        bottom, right = n - 1 - layer, n - 1 - layer

        # single center
        if top == bottom:
            coords.append((top, left))
            rings.append(coords)
            continue

        # top row
        for j in range(left, right):
            coords.append((top, j))
        # right col
        for i in range(top, bottom):
            coords.append((i, right))
        # bottom row
        for j in range(right, left, -1):
            coords.append((bottom, j))
        # left col
        for i in range(bottom, top, -1):
            coords.append((i, left))

        rings.append(coords)

    # map diagonal cells to ring index + position
    diag_info = {}

    for idx, ring in enumerate(rings):
        L = len(ring)
        for pos, (i, j) in enumerate(ring):
            if i == j or i + j == n - 1:
                diag_info.setdefault(idx, []).append(pos)

    candidates = set()
    for i in range(n):
        candidates.add(g[i][i])
        candidates.add(g[i][n - 1 - i])

    def best_cost_for_ring(ring, diag_positions, target):
        L = len(ring)
        best = float('inf')

        for shift in range(L):
            ok = True
            for pos in diag_positions:
                i, j = ring[(pos + shift) % L]
                if g[i][j] != target:
                    ok = False
                    break
            if ok:
                best = min(best, min(shift, L - shift))

        return 0 if best == float('inf') else best

    ans = float('inf')

    for c in candidates:
        total = 0
        for idx, ring in enumerate(rings):
            if idx in diag_info:
                total += best_cost_for_ring(ring, diag_info[idx], c)
        ans = min(ans, total)

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、まず各リングが時計回りの順序で明示的に構築され、これにより回転がモジュラー インデックス シフトに変換されます。 対角線抽出ステップは、目的に影響を与えるインデックスのみに注目を制限するため、重要です。 

コスト関数は、各リングのすべての回転を試行します。 非対角セルは最終的な制約に影響しないため、正確性は対角位置のチェックのみに依存します。 の使用`min(shift, L - shift)`どちらの方向にも回転できることを考慮しています。 

候補文字ループにより、検索スペースが意味のあるターゲットに縮小され、無関係な文字に対する不必要な計算が回避されます。

 ## 特殊なケース

 のために$N = 1$、1 つのセルを含む 1 つのリングがあり、両方の対角線が同じ位置を指します。 このアルゴリズムは、長さ 1 の単一のリングを構築し、中心を対角位置として特定し、1 つのシフトのみを評価してコストをゼロにします。 

すべての対角文字がすでに等しいグリッドの場合、その値に等しいすべての候補文字は、すべてのリングでコストがゼロになります。 各リングの最良のシフトはゼロであり、合計はゼロのままであるため、アルゴリズムは正しくゼロを返します。 

両方の対角線が同じリングと複数回交差する大きなグリッドなど、リングに複数の対角線の位置が含まれる場合、アルゴリズムはシフトごとにそれらの位置をすべてチェックします。 シフトは、マップされたすべての位置が候補文字と一致する場合にのみ有効であり、一貫性のない部分的な位置合わせが防止されます。
