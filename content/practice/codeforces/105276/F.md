 ## 問題の理解

 出版される各論文は段階的に作成されます。 一部のペーパーは独立した文字列ですが、他のペーパーは以前のペーパーを取り出し、その末尾に追加の文字列を追加することによって形成されます。 これにより、すべてのペーパーがルートからノードまでのパスに対応するルート構造が作成され、ペーパーのコンテンツはそのパスに沿ったすべてのエッジ ラベルの連結になります。 

ターゲット文字列も与えられます$t$。 のすべての部分文字列に対して、$t$では、すべての論文を調べて、その正確な部分文字列が各論文内に何回出現するかを数えます。 すべての一致はグローバル合計に寄与します。タスクは、次のすべての部分文字列に対するこの合計寄与度を計算することです。$t$そしてすべての書類。 

難しさはスケールから来ています。 追加されたすべての文字列の合計の長さと、$t$到達できる$10^5$したがって、次の部分文字列を明示的に列挙するメソッドはすべて$t$または、すべての紙を部分文字列ごとに個別にスキャンすることは、実行可能な限界をはるかに超えています。 二次関数または偶数$O(n \log n)$文字列ごとのアプローチはすぐに壊れます。 

微妙な点は、寄与が個別の部分文字列ごとにのみ集計されるわけではないということです。 論文内の各部分文字列は、一致するすべての部分文字列に対して 1 回寄与します。$t$したがって、個別の値ではなく、一致する文字列のすべてのペアを効果的に合計します。 

単純な間違いは、次のすべての部分文字列を反復処理しようとすることです。$t$そしてあらゆる新聞でそれらを検索します。 効率的なパターン マッチングを行ったとしても、部分文字列の数は$t$は$O(|t|^2)$、そのアプローチはすでに不可能になっています。 

もう 1 つのよくある落とし穴は、文字列一致構造を使用して各論文を個別に処理しようとすることです。 論文ごとのパターン マッチングが線形であっても、部分文字列ごとに構築またはクエリを実行すると、依然として二次的な動作が発生します。

 ## アルゴリズムのチュートリアル

 1. 文字列の接尾辞オートマトンを構築する$t$。 すべての状態は、次の部分文字列のセットを表します。$t$、トランジションは文字による拡張をシミュレートします。 
2. オートマトン内の各状態の発生数を計算します。 これは、終端状態をマークし、サフィックス リンクに沿ってカウントを長さの降順に伝播することによって行われます。 この後、各状態は、その表現された部分文字列が何回出現するかを認識します。$t$。 
3. すべての状態について、サフィックスリンクの集計値を計算します。 州の場合$v$、この値を、それ自体の出現回数とそのサフィックス リンクの同じ値を加算したものとして定義します。 これにより、値は次の合計頻度を表します。$t$で表される文字列のすべての接尾辞のうち$v$。 
4. 紙の構造をツリーとして構築します。 各ノードは文字列フラグメントを保存します$u_i$、子は拡張機能を表します。 
5. 根から始めて木を横断します。 現在のルートからノードへのパスに沿って形成された文字列を表す現在のサフィックス オートマトンの状態を維持します。 
6. キャラクターがラベル付けしたエッジに沿って移動する場合$c$、オートマトン内の遷移。 遷移が存在しない場合は、有効な遷移が見つかるまでサフィックス リンクを介してフォールバックし、必要に応じて最終的に初期状態に到達します。 
7. トラバーサル中に処理されるすべての文字について、現在のオートマトンの状態の事前計算されたサフィックス集計値を答えに追加します。 

これが機能する理由は、いつでも現在のオートマトンの状態が、それまでに構築されたプレフィックス文字列全体を表すためです。 現在の位置で終わるすべての部分文字列は、この接頭辞の 1 つの接尾辞に正確に対応します。 これらのサフィックスは、正確に、現在の状態からサフィックス リンクをたどることによって到達可能な状態です。 したがって、集計されたサフィックスリンク値は、その頻度によって重み付けされたすべての部分文字列をカウントします。$t$。 すべての論文文字列のすべての位置でこれを合計すると、二重にカウントしたり省略したりすることなく、必要な引用数の合計が正確に累積されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class SAM:
    def __init__(self, n):
        self.next = [dict() for _ in range(2 * n)]
        self.link = [-1] * (2 * n)
        self.length = [0] * (2 * n)
        self.sz = 1
        self.last = 0

    def extend(self, c):
        p = self.last
        cur = self.sz
        self.sz += 1
        self.length[cur] = self.length[p] + 1

        while p != -1 and c not in self.next[p]:
            self.next[p][c] = cur
            p = self.link[p]

        if p == -1:
            self.link[cur] = 0
        else:
            q = self.next[p][c]
            if self.length[p] + 1 == self.length[q]:
                self.link[cur] = q
            else:
                clone = self.sz
                self.sz += 1
                self.length[clone] = self.length[p] + 1
                self.next[clone] = self.next[q].copy()
                self.link[clone] = self.link[q]

                while p != -1 and self.next[p].get(c) == q:
                    self.next[p][c] = clone
                    p = self.link[p]

                self.link[q] = self.link[cur] = clone

        self.last = cur

N = int(input())
parent = [0] * (N + 1)
edge = [""] * (N + 1)
tree = [[] for _ in range(N + 1)]

for i in range(1, N + 1):
    parts = input().split()
    j = int(parts[0])
    u = parts[1].strip()
    parent[i] = j
    edge[i] = u
    if j > 0:
        tree[j].append(i)

t = input().strip()

sam = SAM(len(t))
for ch in t:
    sam.extend(ch)

order = sorted(range(sam.sz), key=lambda x: sam.length[x], reverse=True)

cnt = [0] * sam.sz
for i in range(sam.sz):
    cnt[i] = 1 if i != 0 else 0

for v in order:
    if sam.link[v] != -1:
        cnt[sam.link[v]] += cnt[v]

agg = [0] * sam.sz
for v in range(sam.sz):
    agg[v] = cnt[v]
for v in order[::-1]:
    if sam.link[v] != -1:
        agg[v] += agg[sam.link[v]]

ans = 0

def dfs(u, state):
    global ans
    for ch in edge[u]:
        if state != -1 and ch in sam.next[state]:
            state = sam.next[state][ch]
        else:
            state = 0
        ans += agg[state]
    for v in tree[u]:
        dfs(v, state)

for i in range(1, N + 1):
    if parent[i] == 0:
        dfs(i, 0)

print(ans)
```サフィックスオートマトンは上に構築されます$t$、すべての部分文字列を状態として表すことができます。 の`cnt`配列はエンドポスのサイズを計算するので、各状態はその部分文字列が何回出現するかを知ることができます。$t$。 の`agg`配列はこれらの値をサフィックス リンクに沿って折り畳むので、各状態が特定の位置で終わるすべてのサフィックス部分文字列の頻度に即座に寄与できるようになります。 

ペーパーツリー上の DFS は、現在構築されている文字列のオートマトン状態を維持します。 文字が追加されるたびに、オートマトン内で遷移します。 遷移が存在しない場合は、初期状態に戻ります。 各ステップで追加される寄与は、現在の状態の合計値です。

 ## 特殊なケース

 親のない 1 つの論文では、オートマトンの状態伝播の初期化がテストされています。 DFS はルートから開始され、すべての文字は遷移を通じて直接処理されるため、サフィックス リンクのフォールバックがカウントを破壊することはありません。 

ペーパーの深いチェーンにより、オートマトンの状態が連続する連結を通じて正しく伝達されることが保証され、すべての中間プレフィックスが後の寄与に影響を与えます。 ここでは、ゼロへのフォールバックによる状態リセット ロジックが不可欠です。これは、遷移が失われた場合、古い状態を継続するのではなく、無効な部分一致を正しく破棄する必要があるためです。
