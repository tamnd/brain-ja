 ## 解決策
 ## 問題の理解

 2 つの別々のツリーが与えられます。1 つは最初のブロックの頂点に、もう 1 つは 2 番目のブロックの頂点にあります。 最初のツリーの 1 つの頂点を 2 番目のツリーの 1 つの頂点に接続し、構造全体を 1 つのツリーに変えることができます。 

このエッジを追加すると、頂点のすべてのペアに明確に定義された最短パス距離が設定されます。 すべてのペアの中には、結果として得られるツリー内で可能な最大距離 (直径) を実現するペアもあります。 タスクは、距離がこの直径に等しい頂点ペアの数ができるだけ大きくなるように接続エッジを選択し、その最大数を出力することです。 

重要な問題は、追加されたエッジによって 2 つの異なる方法で直径が変化する可能性があることです。 元の 2 つの直径のうち大きい方を維持することも、一方の木からもう一方の木へ向かうより長いパスを作成することもできます。 直径が変化すると、それを実現するペアのセットも変化するため、接続ポイントの選択は、直径の値とそれを実現するペアの数の両方に影響します。 

この制約は、両方のツリーが最大 100,000 個のノードを持つことができることを意味します。 すべてのペアの距離を再計算したり、頂点ペアを列挙したりするアプローチは不可能です。 平$O(n \log n)$または$O(n)$候補エッジごとの処理は、頂点のすべてのペアに対して単純に繰り返すと遅すぎます。 ツリーごとに線形時間の前処理を行ってから、最適な接続を評価する定数時間の方法が必要です。 

直径のみについて推論する場合、微妙な問題が発生します。直径の長さを知るだけでは十分ではありません。 また、それを達成するペアの数も数えなければなりません。それらのペアは、直径が各ツリーのどこに「固定されている」かによって異なります。 

素朴だが誤解を招きやすい考えは、2 つの直径の端点を接続することです。 エンドポイントはパスの長さを最大化しますが、極端な距離にあるノードの数を必ずしも最大化するわけではないため、これは失敗する可能性があります。これにより、マージ後に表示される直径ペアの数が制御されます。 

もう 1 つのよくある落とし穴は、直径を実現するすべてのペアが直径パスの端点の間にあると仮定することです。 ツリーでは、エンドポイントのペアだけでなく、多くの異なるノードのペアが同じ最大距離を達成できます。 

## アプローチ

 ブルートフォース戦略では、考えられるすべての頂点のペアを試します。$u \in T_1$、$v \in T_2$、それらを接続し、結果として得られるツリーの直径を再計算し、それを達成するペアの数を数えます。 直径を計算し、最も遠いペアをすべて最初から数えることは、$O(N)$候補者ごとに、$O(N_1 N_2)$エッジの選択。 これは次のことにつながります$O(N^3)$最悪の場合、全体としては実現可能な限界をはるかに超えています。 

重要な観察は、接続すると、$u$そして$v$、ノード間の任意のパス$T_1$とノード$T_2$その新しいエッジを通過しなければなりません。 したがって、すべてのツリー間の距離は、次の距離の合計に分解されます。$u$、エッジ 1 つ、エッジからの距離を加えたもの$v$。 

各ツリー内ですべての離心率を事前に計算できます。つまり、各ノードについて、そのツリー内の他のノードまでの最遠距離がわかります。 これにより、マージ後に長いパスを生成する候補となるノードを特定できます。 

結合されたツリーの直径は 3 つの値のみに依存します。$T_1$、の直径$T_2$、そして選択することによって形成される最良のクロスパス$u$そして$v$。 相互寄与は、それぞれのツリーからできるだけ遠く離れたノードを選択することによって最大化されます。これは、ブリッジを介したエンドポイント間の距離が増加するためです。 

最終的な直径がわかったら、それを達成するペアは 3 つの考えられるソースから得られます。$T_1$、内径のペア$T_2$、または、両方のエンドポイントが、選択した接続ポイントに対してそれぞれのツリーの最も極端な領域にあるクロス ペア。

 | ブルートフォース |$O(N_1^2 N_2 + N_2^2 N_1)$|$O(N)$| 遅すぎる |
 | 最適 |$O(N_1 + N_2)$|$O(N_1 + N_2)$| 承認済み |

 ## アルゴリズムのチュートリアル

 最初に各ツリーを個別に処理します。 

1. 2 回の BFS 実行を使用して、各木の直径の端点を計算します。 任意のノードから開始して最も遠いノードを見つけ、そこから再度開始して直径の終点を取得します。 これにより直径の長さが得られます$d_1$そして$d_2$。 
2. 各ツリーについて、偏心の値を計算します。 すべてのノードについて$x$、その離心率はからの最大距離です。$x$同じツリー内の他のノードに送信します。 これは、両方の直径の端点からの距離を取得し、その 2 つの最大値を取得することによって取得できます。 
3. しましょう$R_1$の最大偏心になります$T_1$、 そして$R_2$の最大偏心$T_2$。 これらは、各ツリーの最も「極端な」ノードを表します。 
4. 各ノードについて$u$、距離にあるノードの数を正確に計算します$\text{ecc}(u)$。 この値を呼び出します$cnt[u]$。 これは、BFS 中に距離に基づいてノードをグループ化することによって取得できます。 
5. 各ツリー内のアタッチメント ノードの候補を特定します。つまり、離心率が以下のノードです。$R_i$。 これらは、接続ポイントとして使用されるときにツリー間の距離を最大化するノードです。 
6. 可能な限り最良のクロス直径を次のようにします。$D_{cross} = R_1 + 1 + R_2$。 これと比較してください$d_1$そして$d_2$。 最終的な直径は$D = \max(d_1, d_2, D_{cross})$。 
7. もし$D = d_1$の場合、直径を達成するすべてのペアは内側のペアになります。$T_1$、さらに、ペアが到達する場合にのみクロスペアになる可能性があります。$d_1$、これには特別な等価性チェックが必要です。 同様に、$T_2$。 
8. もし$D = D_{cross}$の場合、クロスツリーペアのみが直径に到達できます。 最適な選択は、$u$で$T_1$そして$v$で$T_2$最大化する$cnt[u] \cdot cnt[v]$、偏心のあるノードに限定される$R_1$そして$R_2$。 

### なぜ効果があるのか

 最終的なツリー内の距離は、常に追加されたエッジによって分解されます。 1 つのツリー内に完全にあるパスは、そのツリーの元の直径を超えることはできません。 クロスツリー パスは、エンドポイントが選択した接続ノードからどれだけ離れているかによって完全に決定されます。 偏心はノードからの最悪の場合の距離を表すため、最大の偏心を持つノードを選択すると、可能な限り最大の交差直径が保証されます。 直径が固定されると、最も遠いレイヤーの端点のみが直径ペアを形成でき、それらは BFS 距離グループ化を通じて正確にカウントされます。

import sys

from collections import deque

def bfs(start, adj):
    n = len(adj) - 1
    dist = [-1] * (n + 1)
    dist[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    far = max(range(1, n + 1), key=lambda x: dist[x])
    return dist, far

def bfs_dist(start, adj):
    n = len(adj) - 1
    dist = [-1] * (n + 1)
    dist[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

    adj1 = [[] for _ in range(n1 + 1)]
    adj2 = [[] for _ in range(n2 + 1)]

    for _ in range(n1 - 1):

        adj1[u].append(v)
        adj1[v].append(u)

        u -= offset
        v -= offset
        adj2[u].append(v)
        adj2[v].append(u)

    d2, ecc2 = solve_tree(n2, adj2)

    R1 = max(ecc1)
    R2 = max(ecc2)

    D = max(d1, d2, Dcross)

    def count_diameter_pairs(n, adj):
        _, a = bfs(1, adj)
        dista = bfs_dist(a, adj)
        b = max(range(1, n + 1), key=lambda x: dista[x])
        distb = bfs_dist(b, adj)
        d = dista[b]

        for i in range(1, n + 1):

                if max(min(dista[i] + dista[j] - 2 * dista[a], 0), 0) == d:

        return 0, d

    cnt2, _ = count_diameter_pairs(n2, adj2)

        if ecc1[i] == R1:

唯一のデリケートな部分は、偏心が正しく計算されていることを確認することです。 両方の直径の端点からの距離を使用すると、最も遠いノードはすべて、それらの端点をルートとする極値 BFS ツリーの 1 つに存在する必要があるため、正確さが保証されます。 

## 実用的な例

 ### サンプル 1

 まず各木の直径を計算します。 各入力ツリーは星型構造であるため、ツリー内のすべてのリーフの離心率は 2 に等しいです。 したがって$R_1 = R_2 = 2$、クロス直径は次のようになります。$D_{cross} = 2 + 1 + 2 = 5$、内径を支配します。 

| ステップ |$R_1$|$R_2$|$D_{cross}$| ファイナルD |
 | --- | --- | --- | --- | --- |
 | 偏心を計算する | 2 | 2 | - | - |
 | 相互評価 | 2 | 2 | 5 | 5 |

 すべての直径ペアは、両方のツリーの極端なノード間を交差する必要があります。 各ツリーには 4 つの極端なノードがあるため、有効なペアの数は次のようになります。$4 \times 4 = 16$。 

このトレースは、交差直径が支配的である場合、答えは純粋に各ツリーで最大の離心率を達成するノードの数に依存することを示しています。 

### サンプル 2

 ここで、最初のツリーは長いパス状の構造を持っているため、その直径は十字オプションよりも大きくなります。 2 番目のツリーは小さいため、最終的な直径には影響しません。 

| ステップ |$d_1$|$d_2$|$D_{cross}$| ファイナルD |
 | --- | --- | --- | --- | --- |
 | 直径を計算する | 大きい | 小さい | 中間 |$d_1$|

 最初のツリーの内径ペアのみが答えに寄与します。 クロスペアは直径に達しないため、無視されます。 

これは、ツリーを接続しても直径を改善できない場合を示しており、最適な戦略は、支配的なツリー内の直径のペアを数えることになります。

 ## 特殊なケース

 重要なエッジケースは、両方のツリーの直径が同じで、クロス オプションを使用しても改善されない場合です。 このシナリオでは、任意のノードを接続してもどのペアが最適であるかは変わりません。内部ペアのみが寄与します。 

もう 1 つの微妙なケースは、多くのノードが最大の離心率を共有する場合です。 このようなツリーでは、異なる接続ポイントを選択すると、存在するクロスペアの数が大幅に変わる可能性があるため、偏心率を最大化するノードに注意を限定することが不可欠です。
