 ## 解決策
 ## 問題の理解

 のマルチセットが与えられています$2n$カードのすべての数字が$1$に$n$合計でちょうど 2 回登場します。 これらのカードは、あなたとネネの 2 人のプレイヤーに均等に分割されます。$n$カード。 私たちに与えられたのはあなたの手だけです。 Nene の手札は、各値の残りのコピーとして暗黙的に決定されます。 

ゲームは次のように進行します$2n$あなたから始めて、あなたとネネの間で交互に回転します。 各ターンは、現在の手札から 1 枚のカードを選択し、その値がすでにテーブルにすでに表示されている場合はオプションでポイントを獲得し、そのカードをテーブルに永久に置くことで構成されます。 

テーブルには、値が出現した回数ではなく、値が以前に出現したかどうかのみが記録されます。 したがって、各値は、特にその値が全体で 2 回目にプレイされるときに、プレーヤーごとに最大 1 つの得点機会に貢献します。 

Nene は 2 つのレベルの目標に基づいて最適にプレイします。まず自分自身のスコアを最大化し、そのような戦略の中で最終スコアを最小化します。 

タスクは、両方の初期ハンドを考慮して、自分自身に保証できる最大ポイント数を計算することです。 

制約$\sum n \le 2 \cdot 10^5$これは、すべてのソリューションがテスト ケースごとに線形に近い必要があることを意味します。 テスト ケースごとの二次関数はすべて失敗します。 これにより、すべての有効なゲームの展開をシミュレートしたり、両方のプレイヤーの戦略を完全なゲーム ツリーとしてモデル化しようとしたりすることが除外されます。 

微妙な点は、手の中の値の順序は重要ですが、それは周波数構造によってのみ重要であるということです。 単純な間違いは、「両方のコピーを持っていれば 1 ポイントを獲得できる」というように、それぞれの値が独立して何かに寄与すると仮定することです。 Nene は順序を制御して得点機会をブロックしたり遅らせたりできるため、これは間違いです。 

もう 1 つの障害モードは、相互作用の無視によって発生します。両方のコピーを保持する値は、自動的には安全ではありません。 たとえば、Nene があなたの前に 2 番目のコピーをプレイした場合、代わりに Nene がポイントを獲得できます。 

## アプローチ

 ブルートフォースアプローチでは、再帰またはゲーム状態を使用してゲームをシミュレートしようとします。 各ステップで、両方のプレイヤーがカードを選択し、ネネの選択は将来の結果によって決まります。 状態には、どのカードが両手に残っているか、どの値がテーブルに現れているかが含まれます。 これにより、最大で次のような膨大な分岐要素が作成されます。$n!$各プレイヤーの可能なオーダー。 メモ化を行ったとしても、状態空間にはカードとテーブル履歴のサブセットが含まれており、これは指数関数的であり、実現可能な限界をはるかに超えています。 

重要な単純化は、スコアリングに重要なのは各値の 2 回目の出現の相対的なタイミングだけであるという観察から得られます。 各値は、どちらかのプレイヤー、具体的には最初に 2 番目のコピーをプレイしたプレイヤーに最大 1 ポイントを貢献します。 

ここでプロセスを再解釈します: それぞれの値$x$には 2 つの出現があり、1 つはあなたの手に、もう 1 つは Nene の手に (または両方があなたの手に、または両方が彼女の手の中に) あります。 初めて値が再生されるときは何も起こりません。 2 回目は、あなたと Nene のどちらがプレイしたかに応じて、誰がポイントを獲得するかを決定します。 

したがって、各値は「2 つのトークンの競争」のように動作し、2 番目の動きがポイントの所有権を決定します。 

次に、両方のコピーを保持する値を考えてみましょう。 最終的には両方ともプレイすることが保証されているため、最初と 2 回目の出現の両方をコントロールできます。 これは、Nene がその値から得点することはありませんが、2 回目のプレイ前に Nene が少なくとも 1 枚のコピーをプレイした場合にのみポイントを獲得できることを意味します。 ただし、ネネは敵対的であるため、混乱を最大化するようにプレイをスケジュールできます。 

正しい観点は、保持しているコピーの数によって値を分類することです。 

- 0 部: あなたにとって無関係です。 
- 1 部: 争点となる値。 
- 2 コピー: Nene コントロール ダイナミクスの潜在的な強制ポイント。 

重要な観察は、最適なプレイは、ネネが自分のプレイを最適に使用する前に、強制的に 2 回目のプレイを実行できる、貪欲に一致する「機会」に帰着するということです。 

より具体的に再定式化すると、答えは手の中に一度だけ現れる値の数だけによって決まります。 これらは、Nene が 2 回目のアクティベーションを確実に確保できないように両方の発生を制御できる唯一の値です。 2 回出現する値は完全に制御できますが、依然としてタイミング制約の影響を受けるため、1 回出現する値は最適なスケジュールで干渉ポイントとして動作します。 

これは貪欲なペアリングのアイデアにつながります。つまり、Nene より先に 2 番目の出現を確実に再生できる値の数を最大化しようとします。 

最後の単純化は、答えは、誘発された順序付けで Nene を「上回る」ことを可能にする値の数に等しいということです。これは、最適なキャンセル効果後の 2 で割った値が、手札に 1 回だけ出現する値の数を数えることに帰着します。

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

1. 各値が手の中に何回現れるかを数えます。 各値は全体でちょうど 2 回出現するため、Nene のカウントは次のように暗黙的に推測できます。$2 - \text{your count}$。 これにより、問題はゲーム シミュレーションではなく周波数分析に変換されます。 
2. 保持しているコピーの数によって各値を分類します。 コピー数が 0、1、または 2 つであるかどうかのみを考慮します。 コピー数が 0 の値がスコアに直接寄与することはありません。 
3. コピーが 2 つある値は、コピーが 1 つある値とは異なる動作をすることを確認します。 両方のコピーを保持している場合、両方の配置をコントロールすることになりますが、スコアは最初のコピーがすでにテーブル上にあるかどうかによって決まるため、Nene の最適なプレイがスコアに影響する可能性があります。 
4. 一度に保持した値の数を追跡します。 これらは、Nene がタイミングの競合を強制できる可能性がある「柔軟な相互作用ポイント」です。 
5. 核となる貪欲な構造が現れます。単一のコピーを持つ各値は、ポイントを拒否するために 1 つの「相手の干渉スロット」を必要とすると考えることができます。 ネネは最適にプレイするため、ターンを使用してこれらの機会をできるだけ効率的にブロックします。 
6. これらの単一出現値を最適に組み合わせて、敵対的なスケジューリングの下で​​安全なスコアリングの機会の数を効果的に半分に減らします。 
7. 最終的な答えは、このキャンセル効果の後でも 2 回目の出現アドバンテージを強制できる値の数です。 

### なぜ効果があるのか

 ゲームは、2 番目の出現の順序を制御することになります。 各値は 2 回目の出現で正確に 1 つの潜在的なポイントに貢献し、その 2 回目の出現をより早く強制したプレーヤーが所有権を決定します。 両方のプレイヤーが最適に行動し、Nene は完璧な知識を持っているため、完全に制御していない値は共有リソースのように動作し、盗まれたり無力化されたりする可能性があります。 

不変なのは、各移動後に残る重要な情報は、どの値がテーブル上で 1 回だけ出現したか、およびどのプレイヤーが 2 回目の出現のトリガーに近づいているかということだけです。 貪欲なカウントにより、脆弱なシングルトンに対して Nene の最適なブロック能力を常に一致させ、避けられないスコアリングの機会のみを残します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        freq = [0] * (n + 1)
        for x in a:
            freq[x] += 1
        
        single = 0
        for i in range(1, n + 1):
            if freq[i] == 1:
                single += 1
        
        print(single // 2)

if __name__ == "__main__":
    solve()
```コードはまず、手の周波数配列を構築します。 値が範囲内にあるため、$1$に$n$、配列で十分であり、辞書よりも高速です。 抽出される重要な統計は、1 回だけ出現する値の数です。 

出力式`single // 2`これは、最適な敵対的スケジューリングの下で​​これらのシングルトン値をペアにすることで得られます。 整数の除算は、ネネがターンの 1 つを効果的に使用することで脆弱な値の各ペアを妨害することができ、保証された達成可能なポイントとしてそれらの半分だけを残すという事実を反映しています。 

よくある実装上の間違いは、ターンやテーブルの状態を追跡しようとすることです。 実際のゲームはシーケンスではなく周波数構造のみに依存するため、これは不必要であり、誤った貪欲なロジックにつながります。 

## 実用的な例

 周波数ベースの計算を追跡します。 

### 例 1

 入力ハンド:`[1, 1, 2, 3]`| 値 | 周波数 | タイプ |
 | --- | --- | --- |
 | 1 | 2 | ダブル |
 | 2 | 1 | シングル |
 | 3 | 1 | シングル |

 私たちは数えます`single = 2`、したがって、答えは`2 // 2 = 1`。 

これは、値 1 を完全に制御しても、複数のポイントが保証されるわけではないことを示しています。 インタラクション主導のシングルトン値のみが重要です。

 入力ハンド:`[7, 4, 1, 2, 8, 8, 5, 5]`| 値 | 周波数 | タイプ |
 | --- | --- | --- |
 | 7 | 1 | シングル |

 | 2 | 1 | シングル |
 | 8 | 2 | ダブル |
 | 5 | 2 | ダブル |

 ここ`single = 4`、したがって、答えは`2`。 

トレースは、最適な敵対的ペアの下で複数のシングルトン値がどのように崩壊し、保証されたスコアの機会を制限するかを示しています。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    
    input = sys.stdin.readline
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        freq = [0] * (n + 1)
        for x in a:
            freq[x] += 1
        single = sum(1 for i in range(1, n + 1) if freq[i] == 1)
        out.append(str(single // 2))
    return "\n".join(out)

 ## 特殊なケース

 いつ$n = 1$、全体で 2 回出現する値は 1 つだけであるため、手札にはちょうど 1 枚のコピーが含まれ、もう 1 枚の Nene が含まれています。 このアルゴリズムは、ハンド内のシングルトンを 0 個カウントし、ゼロを生成します。これは、2 番目にプレイした人が常にポイントを失うという事実と一致します。 

手の中のすべての値が個別である場合、すべての値はシングルトンになります。 アルゴリズムはそれらを貪欲に組み合わせ、それらの約半分を保証されたポイントとして生成します。 これは、Nene が常にあなたの試みを反映し、最適な順序付けによって機会の半分を盗むことができるという考えと一致します。 

すべての値が手札に 2 回出現する場合、ネネはそれらの値を 1 つも持ちません。 シングルトン数はゼロなので、答えはゼロです。 すべてのカードをコントロールしている場合でも、得点には 2 回目の出現タイミングが必要です。Nene は、プレイヤーに有利な早期出現を決して提供しないようにすることで、得点を完全に遅らせることができます。
