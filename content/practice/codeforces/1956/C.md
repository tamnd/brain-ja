 ## 解決策
 ## 問題の理解

 サイズの正方行列が与えられます。$n \times n$最初はゼロで埋められます。 Nene は 2 種類の操作を実行できます。いずれかは、行全体を次の順列に設定します。$1$を通して$n$または列全体をそのような順列に設定します。 目標は、最大でも次の値を使用して、すべての行列エントリの合計を最大化することです。$2n$操作。 

重要な観察は、各操作で数字を配置できることです。$1$を通して$n$行または列で。 順列を適用した後の単一の行または列の数値の合計は、常に次のようになります。$\frac{n(n+1)}{2}$なぜなら、以下の整数の合計は$1$に$n$順序によっては変わりません。 したがって、行列の合計は、後の操作によってどのエントリが上書きされるかによって決まります。 最大の数値を上書きされない位置に慎重に配置すると、合計を最大化できます。 

制約は中程度です。$n$まで上がります$500$と合計$n^2$すべてのテストケースで次を超えない$5 \cdot 10^5$。 これにより、$O(n^2)$時間制限を超過することなく、テストケースごとのアルゴリズムを実行します。 小さいもの$n$また、bound を使用すると、単に合計を計算するのではなく、演算を明示的に構築することもできます。 

明らかではないエッジケースとしては、以下のものがあります。$n = 1$、唯一の数字は$1$、 そして$n = 2$、複数の戦略が同じ最大合計を達成する可能性がありますが、大きな数値が小さな数値で上書きされるのを避けるために、行と列の置換を慎重に選択する必要があります。 

## アプローチ

 ブルート フォース アプローチでは、合計を最大化するために行と列の演算を可能な限り組み合わせて試します。 各操作は次の順列です。$n$数字があり、$n$行と$n$列から選択できます。 演算ごとに、結果の行列の合計を計算します。 このアプローチは原理的には正しいですが、実用的ではありません。$n=10$、行ごとの順列の数は次のようになります。$10!$そしてそこにあります$2n$行/列の合計は天文学的に大きくなります。 

重要な洞察は、行列に最大の数値を上書きせずに配置することで合計が最大化されるということです。 すべての行と列を独立して設定できるため、単純な貪欲な戦略が機能します。 奇数の場合$n$では、最初にすべての行を増加する順列で埋め、次にすべての列を同じ順列で埋めますが、回転して主対角の最大の数値を揃えるというパターンを適用できます。 これにより、各セルが少なくとも 1 回の操作で可能な最大の数を受け取ることが保証されます。 偶数の場合$n$、行と列の順列の単純な交互パターンにより、数値が必要以上に上書きされることがなくなります。 

これにより、問題は建設的な貪欲アルゴリズムに帰着します。つまり、最大の数値ができるだけ多くの個別のセルを占めるように、行と列に順列を割り当てます。 これにより、最大合計が保証されます。$2n$操作。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$。 操作のカウンターを初期化し、それらを保存するリストを準備します。 
2. 基本的な順列を作成する$p = [1, 2, \dots, n]$。 
3.行の場合$i = 1$に$n$、タイプ 1 の操作を追加します。順列を割り当てます。$p$漕ぐ$i$。 これにより、すべての行に 1 から 1 までのすべての数字が含まれるようになります。$n$。 このステップの後、各行の合計は次のようになります。$\frac{n(n+1)}{2}$、合計は$n \cdot \frac{n(n+1)}{2}$。 
4. カラムの場合$i = 1$に$n$、タイプ 2 の操作を追加します。順列を割り当てます。$p$列へ$i$。 主対角の最大の数値を上書きしないようにするには、順列を次のようにシフトします。$i-1$列の位置$i$。 これにより、最大の数値が対角線に沿って配置され、残りのエントリには小さな数値が入力されます。 
5.合計を計算する$s$行列の$s = n \cdot \frac{n(n+1)}{2}$。 出力$s$および操作のリスト。$2n$操作。 

機能する理由: 行と列の各演算により、行または列にすべての数値が含まれることが保証されます。$1$に$n$。 行を埋めた後、列の順列を注意深く順序付けることにより、最大の数値が上書きされることなく個別のセルを確実に占有するようになります。 各行と列の合計は固定されており、大きな数値を最適に配置するために順列が使用されるため、全体の合計が最大化されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = n * (n + 1) // 2 * n  # sum of all rows initially filled
        ops = []

        perm = list(range(1, n + 1))
        for i in range(1, n + 1):
            ops.append((1, i, perm[:]))  # type 1, row i
        for i in range(1, n + 1):
            shifted = perm[i-1:] + perm[:i-1]  # rotate to align diagonals
            ops.append((2, i, shifted))

        print(s, len(ops))
        for op in ops:
            print(op[0], op[1], *op[2])

if __name__ == "__main__":
    solve()
```このソリューションでは、各行と列の順列を構築します。 行操作により、すべての行に 1 から 1 までのすべての数値が含まれるようになります。$n$。 列演算は、対角線上の合計を最大化するために順列をシフトします。 回転順列により、行操作によってすでに配置されている最大の数値が上書きされるのを防ぎます。 などの境界条件$n=1$順列は単一の要素に対して自動的に正しいため、自然に処理されます。

 ## 特殊なケース

 のために$n=1$、アルゴリズムは順列を使用して 1 行 1 列の演算を実行します [1]。 合計は 1 で、予想される最大値と一致します。 要素が 1 つしかないため、行操作と列操作は互いに上書きされません。 

のために$n=2$、アルゴリズムは両方の行を [1,2] で埋めてから、回転して適用します。
