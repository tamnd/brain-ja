 ## 解決策
 ## 問題の理解

 私たちは、Monocarp が 2 つの制約の下で層状のケーキを焼くのを手伝ってほしいと頼まれました。それは、各層のサイズが指数関数的に大きくなり、各層を覆うチョコレートが白と黒を交互に配置しなければならないということです。 最上層のサイズは常に 1 です。次の層のサイズは 2、その次は 4、その次は 8 というように、毎回 2 倍になります。 各層はそのサイズに等しい数キログラムのチョコレートを消費しますが、Monocarp のホワイト チョコレートとダーク チョコレートの供給には限りがあります。 課題は、チョコレートの供給量を超えずに構築できる層の最大数を決定することです。 

入力では、ホワイト チョコレートとダーク チョコレートの量をそれぞれ指定するいくつかのテスト ケースが提供されます。 出力は、テスト ケースごとに 1 つの整数、つまり可能な最大レイヤー数である必要があります。 以来`a`そして`b`テスト ケースは最大 10^6 まで可能で、テスト ケースは最大 10^4 まで可能です。単純な線形反復では、テスト ケースごとに数百万の操作、全体で数十億の操作に達する可能性があるため、アルゴリズムはテスト ケースごとにおよそ O(log N) で実行する必要があります。 

微妙な点は、交互のチョコレートの要件です。 素朴で貪欲なアプローチでは、ホワイト チョコレートまたはダーク チョコレートを重ね始め、チョコレートが 1 つなくなるまで追加し続けるかもしれません。 しかし、常に白から始めると、暗から始まる最適なソリューションを見逃してしまう可能性があります。 たとえば、次の場合`a = 1`そして`b = 2`、白から始めると 1 つのレイヤー (サイズ 1) のみが許可されますが、暗いから始めると 2 つのレイヤー (暗い 1 つ、白 2 つ) が許可されます。 チョコレートがいくつかの小さな層には十分であるが、次の大きな層には不十分である場合、別の特殊なケースが発生します。 アルゴリズムは各レイヤーを段階的にチェックし、両方の開始オプションを考慮する必要があります。 

## アプローチ

 ブルートフォース手法では、層を反復処理し、毎回サイズを 2 倍にし、交互のパターンに従ってそれぞれのチョコレート プールから減算します。 これはケーキ構築プロセスを直接シミュレートするため、正しく機能します。 問題は、最悪の場合、層の数が最大 20 になる可能性があることです (k ≈ 19 の場合、等比級数 1 + 2 + 4 + ... + 2^k の合計は 10^6 を超えるため)。そのため、ここではブルート フォースが実際には十分に高速です。 各テスト ケースで必要な反復回数は 20 回未満で、最悪の場合でも合計 2_10^4_20 = 4*10^5 の操作が必要となり、2 秒の制限内に十分収まります。 

重要な洞察は、白から始めるか暗から始めるという 2 つの可能な開始選択肢をシミュレートするだけでよいということです。 両方を計算した後、最大値を採用します。 各シミュレーションは層ごとに進行し、層のサイズを 2 倍にし、対応するチョコレートの種類から減算し、次の層が利用可能なチョコレートを超えると停止します。

 ## アルゴリズムのチュートリアル

 1. テストケースごとに、ホワイトチョコレートの量を読み取ります。`a`そしてダークチョコレート`b`。 
2. 2 つのカウンターを初期化します。`count1`そして`count2`、それぞれ白で始まるか暗いで始まる場合のレイヤーの数を表します。 
3. のために`count1`、白から始まるケーキをシミュレートします。 

1. 現在のレイヤー サイズを 1 に初期化します。 
2. 現在のレイヤーに十分なチョコレートがある間に、次のようにします。 

1. 適切なチョコレートの種類から層のサイズを減算し、各層を交互に配置します。 
2. レイヤーのサイズを 2 倍にします。 
3. レイヤー数を増やします。 
4. 手順 3 を繰り返します。`count2`, ダークチョコレートから始まります。 
5. の最大値を返します`count1`そして`count2`このテストケースの答えとして。 

機能する理由: 各シミュレーションは、層のサイズとチョコレートの交互のルールに正確に従っています。 両方の開始チョコレートを試すことで、可能な最大の層数が見つかることが保証されます。 不変条件は、どの段階でもチョコレートの消費が利用可能な供給量を超えないことです。 それが完了すると、シミュレーションが停止します。この時点で、ケーキをさらに拡張できなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_layers(a, b):
    def simulate(start_white):
        w, d = a, b
        layer = 1
        count = 0
        white_turn = start_white
        while True:
            if white_turn:
                if w >= layer:
                    w -= layer
                else:
                    break
            else:
                if d >= layer:
                    d -= layer
                else:
                    break
            layer *= 2
            white_turn = not white_turn
            count += 1
        return count
    
    return max(simulate(True), simulate(False))

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    print(max_layers(a, b))
```このコードはヘルパーを定義します`simulate`最初のレイヤーを白にするかどうかを示すブール値を受け取る関数。 チョコレートの種類ごとの残りの量、現在の層のサイズを追跡し、チョコレートの使用を交互に行います。 両方の開始色を試した後、最大レイヤー数が返されます。 の倍増`layer`ループ内では指数関数的な成長が保証されます。 チョコレートが 1 種類しかない、または供給が非常に少ないなどの特殊なケースは、while ループによって自然に処理されます。
