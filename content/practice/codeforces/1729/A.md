 ## 解決策
 ## 問題の理解

 この状況は、1 階のヴラドに到達する可能性がある 2 台のエレベーターのどちらを使用するかの決定を表しています。 各エレベーターには異なる移動ルールがあり、目的は、ヴラドが呼び出しボタンを押した後、どのエレベーターが最も早く 1 階に戻るかを決定することです。 

最初のエレベーターは最初はどこかの階に停止しています`a`。 呼び出されると、すぐにフロア 1 に向かって移動を開始します。移動時間は純粋に現在位置と目的地の間の距離であるため、必要な時間は`|a - 1|`。 

2 番目のエレベーターは異なる動作をします。 床から始まります`b`そして現在フロアに向かって移動中です`c`。 ヴラドが呼び出しても、すぐに 1 階へ向かうのではなく、まず現在の移動を継続 (または終了) します。`c`、そして到達した後にのみ`c`フロア 1 に向かって移動し始めますか。これは、その合計時間がフロア 1 から移動するまでの時間であることを意味します。`b`に`c`、からの所要時間に加えて、`c`に`1`、つまり`|b - c| + |c - 1|`。 

タスクは、テスト ケースごとにこれら 2 つの到着時間を比較し、最初のエレベーターが速いか、2 番目のエレベーターが速いか、それとも同じ時間がかかるかを判断することです。 

制約により、最大で次のことが許可されます。`10^4`テスト ケース、下限値は最大`10^8`。 これにより、ステップごとの動きのシミュレーションが即座に除外されます。 O(t log n) であっても不必要なオーバーヘッドであり、フロアの差の大きさにより O(t * 距離) は不可能であるため、各テストは一定時間で処理される必要があります。 

1 台のエレベーターがすでに事実上 1 階にある場合、微妙なエッジ ケースが発生します。たとえば、次のような場合です。`a = 1`、最初のエレベーターの移動時間はゼロです。 同様に、`b = 1`、2 番目のエレベーターはまだ現在の移動を完了する必要があります。`c`したがって、フロア 1 から開始しても即時ではありません。開始位置だけで即時利用可能性が決まると仮定すると、この非対称性を誤解しやすくなります。 

## アプローチ

 強引な解釈では、各エレベーターの動きを時間ステップでシミュレートします。 最初のエレベーターの場合、これは簡単です。エレベーターから歩いてすぐです。`a`に`1`。 2 番目のエレベーターについては、その動きをシミュレートしてみるとよいでしょう。`c`まず、次に向かって`1`、段階的に位置を更新します。 

これは概念的には機能しますが、完全に実行不可能です。 フロア間の距離は最大で`10^8`そのため、単一のテスト ケースを段階的にシミュレートするだけでも、最大で 3 時間かかる可能性があります。`10^8`オペレーション、そして全体にわたって`10^4`テストケースでは、これは天文学的に大きくなります。 

重要な観察は、両方のエレベーターが一定の速度で移動し、距離以外の制約とは相互作用しないことです。 これにより、問題全体が合計パス長の計算に集約されます。 最初のエレベーターは、次の単一セグメントに寄与します。`a`に`1`。 2 番目のエレベーターは、固定の 2 セグメント パスに寄与します。`b`に`c`その後`c`に`1`。 距離として表現されると、比較は単純な算術チェックになります。 

もうプロセスを最適化しているのではなく、数直線上のジオメトリから導出された 2 つのスカラー値を比較しているだけです。

 | ブルートフォースシミュレーション | O(t · 最大距離) | お(1) | 遅すぎる |
 | 直接距離の計算 | O(t) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、3 つの整数を読み取ります。`a`、`b`、 そして`c`。 これらは、2 番目のエレベーターの開始位置と強制中間ターゲットを定義します。 
2. 最初のエレベーターの到着時間を次のように計算します。`t1 = abs(a - 1)`。 これは、フロア 1 への途切れのない移動を直接表しています。 
3. 2 番目のエレベーターの到着時間を次のように計算します。`t2 = abs(b - c) + abs(c - 1)`。 これは、最初に移動を完了しなければならないというルールをエンコードしています。`c`を選択し、1に進みます。 
4. 比較する`t1`そして`t2`。 もし`t1 < t2`、最初のエレベーターの方が厳密には速いので、出力`1`。 
5. もし`t2 < t1`、2 番目のエレベーターの方が厳密に速いため、出力`2`。 
6. 両方の時間が等しい場合、出力`3`どちらの選択肢も同等であるためです。 

比較の背後にある理由は、両方の式が確定的な移動下での合計移動時間を完全に把握しているためです。 これらの距離を超えると、隠れた状態、遅延、分岐パスはありません。 

### なぜ効果があるのか

 このシステムは、一定速度の 1 次元の数直線上の動きとしてモデル化できます。 呼び出しが行われると、各エレベーターの動作によって固定の経路長が定義されます。 移動時間は距離に比例し、エレベータ間の相互作用がないため、到着時間を最小化することは、経路の総長を最小化することと同じです。 このアルゴリズムは、近似やシミュレーションを行わずにこれらのパス長を正確に比較するため、正確です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c = map(int, input().split())

    t1 = abs(a - 1)
    t2 = abs(b - c) + abs(c - 1)

    if t1 < t2:
        print(1)
    elif t2 < t1:
        print(2)
    else:
        print(3)
```最初の計算`t1`最初のエレベーターから目的階までの直線距離をエンコードします。 2 番目の計算`t2`2 番目のエレベーターが最初に到達しなければならないという制約を明示的に尊重します`c`これが、1 からの 1 つの直接距離ではなく、2 つの絶対的な違いに分割される理由です。`b`に`1`。 

比較ロジックは、問題の決定ルールを直接変換したものです。 各ブランチは相互に排他的であり、集合的に網羅的であるため、テスト ケースごとに 1 つの有効な出力が保証されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque

    it = iter(inp.strip().split())
    t = int(next(it))
    out = []
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        t1 = abs(a - 1)
        t2 = abs(b - c) + abs(c - 1)
        if t1 < t2:
            out.append("1")
        elif t2 < t1:
            out.append("2")
        else:
            out.append("3")
    return "\n".join(out)

# provided samples
assert run("""3
1 2 3
3 1 2
3 2 1
""") == """1
3
2"""

# custom cases
assert run("""1
1 2 100
""") == "1"

assert run("""1
50 1 2
""") == "3"

assert run("""1
100 50 1
""") == "2"

 ## 特殊なケース

 いつ`a = 1`、最初のエレベーターはすでに目的階にあるため、コストはゼロです。 アルゴリズムは計算します`t1 = abs(1 - 1) = 0`したがって、ゼロ以外の 2 番目のエレベーター パスは正しく失われます。 

いつ`b = 1`、2 番目のエレベーターは最初に到達する必要があるため、依然としてコストが発生します。`c`。 たとえば、`a = 5, b = 1, c = 10`、私たちは得ます`t1 = 4`そして`t2 = 9 + 9 = 18`したがって、2 番目のエレベーターは 1 階から開始するにもかかわらず、最初のエレベーターが正しく選択されます。 

いつ`c = 1`、2 番目のエレベーターの 2 番目の区間はゼロになりますが、それでもコストは発生します。`b`に`1`。 例えば、`a = 10, b = 5, c = 1`与える`t1 = 9`、`t2 = 4 + 0 = 4`したがって、2 番目のエレベーターが勝ちます。その強制ルートは、到達直後に目的の階で実際に終了するためです。`c`。
