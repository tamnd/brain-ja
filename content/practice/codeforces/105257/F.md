 ## 解決策
 ## 問題の理解

 いくつかの独立したテスト ケースが与えられています。 それぞれに、さまざまなコード提出のスコアを表す整数のリストがあります。 プレーヤーはコードを 2 回提出する必要があり、最終スコアは合計や最大値ではなく、選択した 2 つの提出スコアのビットごとの AND になります。 同じ送信を 2 回選択することができます。つまり、インデックスをそれ自体とペアにすることができます。 

各テスト ケースのタスクは、gi と gj の値ができるだけ大きくなるように 2 つのインデックス i と j (おそらく等しい) を選択することです。 

入力サイズは大きく、すべてのテスト ケースにわたる合計数は最大 2×10^5 です。 これにより、すべてのペアを明示的にチェックする二次ペアリング戦略は除外されます。これは、最悪の場合、およそ 4×10^10 の演算が必要になるためです。 テスト ケースごとに線形時間以上で機能するソリューションが必要です。 

「同じコードを 2 回送信できる」というルールから、微妙なエッジ ケースが発生します。 この詳細を見落とすと、i ≠ j が必要であると誤って仮定し、2 つの異なる要素を見つけようとする可能性があります。 たとえば、配列が [7, 1] の場合、誤った解釈では答えが 7 & 1 = 1 であると示唆される可能性がありますが、正しい解釈では 7 を 2 回選択でき、7 & 7 = 7 となります。 

もう 1 つのエッジ ケースは、1 つの大きな値を除いてすべての数値がゼロである場合です。 ゼロとのペアはビットを破壊しますが、自己ペアでは元の値が保持されます。 

## アプローチ

 ブルートフォースのアイデアは簡単です。すべてのペア (i, j) を試し、gi と gj を計算し、最大値を追跡します。 これは問題の定義を直接評価するため、正しいです。 ただし、テスト ケースごとに n^2 個のペアをチェックする必要があり、n が合計 2×10^5 に達すると非常に遅くなります。 

重要な観察は、ビット単位の AND が同一の要素に関して単調に動作するということです。任意の数値 x について、それをそれ自体と組み合わせると x が得られますが、AND はビットをオフにすることしかできないため、これは常に少なくとも他の数値と組み合わせるのと同じくらい大きくなります。 

これにより、問題の構造が即座に変わります。 最適なペアを検索する代わりに、最良の結果が自己ペアから得られるかどうかを考慮するだけで済みます。 すべての要素は (i, i) を介して有効な候補であるため、答えは配列内の最大要素よりも小さくすることはできません。 一方、任意のペア (i, j) は、gi と gj の両方にビット単位で含まれる値を生成するため、個別にどちらかを超えることはできません。 これは、どのペアも最大要素自体を超えることはできないことを意味します。 

したがって、最適な戦略は、各テスト ケースで最大値を見つけることになります。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 遅すぎる |
 | 最適 (最大スキャン) | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 1. 各テスト ケースを個別に処理する

 各テスト ケースは分離されているため、数値のリストごとに答えを個別に計算します。 

### 2. 現在の最大値を維持しながら、すべての値をスキャンします。 

変数を保持します`best`0 に初期化されます。配列内の数値 x ごとに、次のように更新します。`best = max(best, x)`。 

これが機能するのは、すべての要素を 2 回選択することで有効な結果が得られるためです。そのため、答えは少なくとも最大の要素でなければなりません。 

### 3. 見つかった最大値を出力します

 すべての要素をスキャンした後、印刷します`best`そのテストケースの答えとして。 

### なぜ効果があるのか

 ビットごとの AND はビットのみをクリアするため、2 つのインデックス i および j について、値 gi & gj は gi を超えることはできず、gj を超えることもできません。 したがって、考えられるすべてのペアの結果は、配列内の最大要素によって上限が制限されます。 i = j を選択すると gi が達成されるため、最大要素は常に達成可能です。 これにより、答えがリスト内の最大値に正確に固定されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    arr = list(map(int, input().split()))
    print(max(arr))
```このソリューションは、各テスト ケースを読み取り、最大値を計算して出力するだけです。 重要な実装の詳細は、Python の組み込みを使用することです。`max`、これは線形時間で実行され、この問題のサイズに最適です。 追加の前処理は必要なく、ペアを明示的に考慮する必要もありません。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

 | 時間 | テスト ケースあたり O(n) | 最大値を計算する単一パス |

## テストケース```python
import sys, io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        arr = list(map(int, input().split()))
        out.append(str(max(arr)))
    return "\n".join(out)

# provided sample-like cases
assert solve("2\n3\n0 1 2\n4\n10 10 5 4\n") == "2\n10"

# minimum size, single element
assert solve("1\n1\n7\n") == "7"

# all equal values
assert solve("1\n5\n3 3 3 3 3\n") == "3"

# mixed values
assert solve("1\n4\n1 8 3 6\n") == "8"

# includes zeros
assert solve("1\n3\n0 0 0\n") == "0"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 単一要素 | それ自体 | セルフペア動作 |
 | すべて等しい | 同じ値 | 重複時の安定性 |
 | 混合値 | 最大選択 | スキャンの正確性 |
 | すべてゼロ | 0 | 正のビットがないエッジケース |
