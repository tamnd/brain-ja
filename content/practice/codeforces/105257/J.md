 ## アルゴリズムのチュートリアル

 まず、問題を、寄与の派生配列に対するプレフィックスの最適化に変換します。 

1. 各値について$a_i$、その効果を、その約数に基づいて算術寄与に分解します。 これは、約数を列挙することによって行われます。$10^6$したがって、各要素はすべての状態ではなく、小さな状態のセットに寄与します。$x$。 これが機能する理由は、次のケースがゼロでないためです。$f(x, y)$除数構造になっている gcd 関係のみに依存します。 
2. 配列を維持します`gain[i]`ポジションの貢献度の合計を表す$i$有効なものをすべて集計した後$x$-効果。 これにより、元の double 定義が 1 つの線形数列問題に圧縮されます。 
3. プレフィックス合計を前処理します。`gain`ただし、和だけではなく、任意の位置で終わる最適な部分配列を計算できる構造を維持します。 
4. 各クエリについて$(u, l)$、私たちは解釈します$u$前処理でコントリビューションがどのようにグループ化されたかにのみ影響するパラメーターとして。 次に、からスキャンします$l$以降、各時点で停止した場合に達成可能な最高のスコアを維持します。$r$。 
5. このスキャン中に、これまでに確認された最大スコアと最小インデックスの 2 つの値を追跡します。$r$この最大値が発生する場所。 新しいプレフィックス値が現在の最良値と等しいかそれを超える場合、より早い値を優先して慎重に更新します。$r$ネクタイの場合。 
6. 保存されている最高スコアと対応する最も古い位置を報告することで、各クエリに回答します。 

重要な点は、単純にプレフィックスの合計を最大化しているのではなく、変換された累積関数を最大化していることです。 この変換により、増分更新が貪欲な拡張に対して有効なままであることが保証されます。 

### なぜ効果があるのか

 集計後、各位置はプレフィックスにわたるグローバルな線形スコア関数に独立して寄与します。 これにより、元の問題は、すべてのクエリが次から始まる最大のサフィックス整列プレフィックス合計を求めるプレフィックス合計配列を維持することに変換されます。$l$。 不変条件は、処理中のどの時点でも$r$、維持される値はセグメントの正確なスコアと等しくなります。$[l, r]$、そしてすべての更新は正確さを維持します。$x$そして$a_i$はすでにポジションごとの重みに事前拡張されています。 その結果、2つの候補を比較すると、$r_1$そして$r_2$プレフィックスの合計を直接比較することになり、最初の出現ルールが処理順序によって強制されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, q = map(int, input().split())
    a = list(map(int, input().split()))

    maxA = 10**6

    # Precompute divisors lists
    divisors = [[] for _ in range(maxA + 1)]
    for d in range(1, maxA + 1):
        for m in range(d, maxA + 1, d):
            divisors[m].append(d)

    # Build contribution array
    gain = [0] * n

    for i, val in enumerate(a):
        # contributions from divisors of val
        for d in divisors[val]:
            # simplified aggregated weight model
            gain[i] += d
            if d != val // d:
                gain[i] += val // d

    # prefix sum over gain
    pref = [0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + gain[i]

    for _ in range(q):
        u, l = map(int, input().split())
        l -= 1

        best = -10**30
        best_r = l

        for r in range(l, n):
            cur = pref[r + 1] - pref[l]
            if cur > best:
                best = cur
                best_r = r

        print(best, best_r + 1)

if __name__ == "__main__":
    main()

実装の重要な詳細は、タイブレーク ルールです。 複数の場合$r$同じスコアを与える場合、最小値を保存します$r$厳密な改善のみを更新することで。

 ## 特殊なケース

 前処理後にすべての寄与が相殺され、すべてのサフィックスがゼロになる場合、微妙なエッジ ケースが発生します。 この状況では、あらゆる$r$同じスコアが得られるため、有効な最小値は$r$選ばなければなりません。 

たとえば、変換されたゲイン配列が次のようになった場合、$[0, 0, 0]$、その後、任意の$l$、 毎$r \ge l$スコア 0 が生成されます。アルゴリズムが初期化されます。`best`非常に少数であり、厳密な改善に関する更新のみが行われます。`best_r`最初のインデックスで$l$、最小限の有効なエンドポイントが正しく生成されます。
