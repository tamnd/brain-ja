 ## 解決策
 ## 問題の理解

 エッジが 10 進数でラベル付けされた有向グラフが与えられます。 頂点 1 から始めて、有向エッジに従って永遠に歩くことができます。 エッジ ラベルのシーケンスは、0 から 1 までの数値を 10 進展開したものになります。 

問題は、小数展開が無理な無限歩行が存在するかどうかです。 10 進展開は、その桁が **最終的に周期的でない**場合にまさに無理数になります。そのため、タスクはグラフが最終的に非周期的な数字列を生成できるかどうかを実際に問うことになります。 

グラフは大きいですが、すべてのテスト ケースにわたる頂点とエッジの合計数は最大でも$2 \cdot 10^5$。 同じグラフを繰り返し探索したり、グラフに比例した作業を実行したりするアルゴリズム。$N^2$または$M^2$はすぐに除外されます。 線形または線形に近いグラフ アルゴリズムが必要です。 

見落としがちな状況がいくつかあります。 

到達可能なサイクルがないと仮定します。```
1 -> 2 -> 3
```無限に歩くことはまったくありません。したがって、答えは次のとおりです。`No`。 異なるエッジラベルのみをチェックするソリューションでは、誤った答えが返されます。`Yes`。 

到達可能な部分が単一の有向サイクルであると仮定します。```
1 -> 2 (digit 1)
2 -> 3 (digit 2)
3 -> 1 (digit 3)
```無限の歩みが繰り返される`123123123...`したがって、すべての小数は有理数です。 正しい答えは、`No`。 

最も微妙なケースは、SCC に分岐が含まれているが、「サイクル内の同じ位置」からのすべての出力エッジが常に同じ桁を保持している場合です。 このような分岐により、訪問する頂点は変更されますが、生成される数字のシーケンスは決して変更されません。 グラフの構造だけを見るだけでは十分ではなく、エッジのラベルも重要です。 

## アプローチ

 強引なアイデアは、生成された数字シーケンスが最終的に周期的になるかどうかを確認しながら、ますます長い歩行を列挙することです。 これは原則として正しいです。なぜなら、非合理性とはまさに最終的な周期性が存在しないことだからです。 残念ながら、ウォークの数はウォークの長さに応じて指数関数的に増加するため、長さ 50 のウォークをすべて探索することさえすでに不可能です。 

重要な観察は、すべての無限のウォークが最終的に 1 つの強く接続されたコンポーネント内に留まるということです。 一度 SCC を離れると、二度と戻ることはできません。 これにより、到達可能な各 SCC を個別に分析できるようになります。 

1 つの SCC 内では、すべてのサイクル長に最大公約数があります。$g$。 古典的なグラフのプロパティは、すべての値の gcd を取得することで、この値を線形時間で計算できることを示しています。$$\text{depth}[u] + 1 - \text{depth}[v]$$あらゆる有向エッジにわたって$(u,v)$DFS ツリー内。 

計算後$g$、すべての頂点は自然に次のいずれかに属します。$g$DFS 深度モジュロに従った剰余クラス$g$。 すべてのエッジは常に残差から生じます$c$残留物に$c+1 \pmod g$。 

ここで重要な特徴付けが行われます。 同じ剰余クラスの頂点を離れるすべてのエッジが常に同じ数字を保持する場合、すべての無限ウォークは、その剰余クラスを訪問するたびにまったく同じ数字を出力する必要があります。 生成された 10 進数は、毎回強制的に繰り返されます。$g$したがって、すべての歩行は最終的には周期的になります。 

逆に、ある剰余クラスに異なる桁を持つ 2 つの出力エッジが含まれている場合、SCC 内に留まりながら、それらの間で繰り返し選択することができます。 これにより、最終的には周期的ではなくなる数字列を構築でき、無理数小数が得られます。 この特徴は公式分析で証明されています。 

アルゴリズム全体は、SCC 分解、DFS、gcd 計算、およびエッジ上の 1 回のパスのシーケンスになります。

 ## アルゴリズムのチュートリアル

 1. 頂点 1 から DFS または BFS を実行し、到達できない頂点をすべて無視します。 
2. 到達可能な部分グラフの強結合成分を計算します。 
3. 到達可能なすべての SCC を個別に処理します。 無限ウォークを含めることができない SCC、つまり自己ループのない単一頂点を無視します。 
4. SCC の任意の頂点をルートとして選択し、SCC 内に DFS ツリーを構築します。 すべての頂点のツリーの深さを記録します。 
5. gcd を計算します。$$g=\gcd(\text{depth}[u]+1-\text{depth}[v])$$SCC のすべてのエッジにわたって。 
6. すべての頂点に色を付けます。`depth % g`。 いつ`g = 0`、SCC には常に少なくとも 1 つのサイクルがあるため、これを 1 に置き換えます。 
7. すべての残差クラスについて、そのクラスのすべての頂点のすべての出向きエッジを調べます。 これらすべてのエッジには同じ数字が含まれている必要があります。 剰余クラスに 2 つの異なる数字が含まれている場合は、すぐに答えます`Yes`。 
8. 到達可能なすべての SCC が前の条件を満たしている場合、応答します。`No`。 

### なぜ効果があるのか

 すべての無限ウォークは最終的に 1 つの到達可能な SCC 内に残ります。 SCC 内では、すべてのサイクル長の gcd によって、すべての無限ウォークにおける位置の標準循環順序が決定されます。 同じ深さのモジュロを持つ頂点$g$その順序では常に同じ位置を占めます。 

すべての剰余クラスが常に同じ数字を出力する場合、位置の数字は$i$のみに依存する$i \bmod g$。 すべての無限ウォークは最終的には周期的になるため、すべての小数は有理数になります。 

1 つの剰余クラスが 2 つの異なる桁を出力できる場合、その剰余クラスを繰り返し再訪し、毎回どの桁を出力するかを独立して選択できます。 非最終的に周期的な 2 進数シーケンスに従って選択すると、非最終的に周期的な 10 進展開が生成されますが、これは非合理的です。 

## Python ソリューション```python
import sys
from math import gcd

input = sys.stdin.readline
sys.setrecursionlimit(1_000_000)

t = int(input())

for _ in range(t):
    n, m = map(int, input().split())

    g = [[] for _ in range(n)]
    rg = [[] for _ in range(n)]
    edges = []

    for _ in range(m):
        u, v, d = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append((v, d))
        rg[v].append(u)
        edges.append((u, v, d))

    # reachable
    vis = [False] * n
    stack = [0]
    vis[0] = True
    while stack:
        v = stack.pop()
        for to, _ in g[v]:
            if not vis[to]:
                vis[to] = True
                stack.append(to)

    order = []
    used = [False] * n

    def dfs1(v):
        used[v] = True
        for to, _ in g[v]:
            if vis[to] and not used[to]:
                dfs1(to)
        order.append(v)

    for i in range(n):
        if vis[i] and not used[i]:
            dfs1(i)

    comp = [-1] * n

    def dfs2(v, c):
        comp[v] = c
        comps[-1].append(v)
        for to in rg[v]:
            if vis[to] and comp[to] == -1:
                dfs2(to, c)

    comps = []
    cid = 0
    for v in reversed(order):
        if comp[v] == -1:
            comps.append([])
            dfs2(v, cid)
            cid += 1

    ok = False

    for idx, verts in enumerate(comps):
        if ok:
            break

        if len(verts) == 1:
            u = verts[0]
            self_loop = False
            for to, _ in g[u]:
                if to == u:
                    self_loop = True
            if not self_loop:
                continue

        depth = {}
        root = verts[0]

        def dfs(v):
            for to, _ in g[v]:
                if comp[to] != idx:
                    continue
                if to not in depth:
                    depth[to] = depth[v] + 1
                    dfs(to)

        depth[root] = 0
        dfs(root)

        cyc = 0
        for u in verts:
            for v, _ in g[u]:
                if comp[v] == idx:
                    cyc = gcd(cyc, abs(depth[u] + 1 - depth[v]))
        if cyc == 0:
            cyc = 1

        digit = {}
        for u in verts:
            c = depth[u] % cyc
            for v, d in g[u]:
                if comp[v] != idx:
                    continue
                if c in digit:
                    if digit[c] != d:
                        ok = True
                        break
                else:
                    digit[c] = d
            if ok:
                break

    print("Yes" if ok else "No")
```最初の部分では、有効なウォークがこれらの頂点に入ることができないため、到達できない頂点をすべて削除します。 

Kosaraju のアルゴリズムは、残りのグラフを SCC に分解します。 すべての無限ウォークは最終的に 1 つの SCC 内に留まるため、各コンポーネントを個別にチェックできます。 

関連するすべての SCC に対して、DFS は深さを割り当てます。 これらの深さは考えられるスパニング ツリーの 1 つにすぎませんが、gcd 計算により特定のツリーへの依存が除去されます。 値`depth[u] + 1 - depth[v]`ツリー以外の各エッジがサイクル長をどれだけ変化させるかを捕捉し、そのようなすべての値の gcd を取得すると、SCC 内のすべてのサイクル長の gcd が回復されます。 

最後に、頂点は次のようにグループ化されます。`depth % cyc`。 1 つの剰余クラスからのすべての出力エッジは、同じ数字を持たなければなりません。 2 つの異なる数字が表示された瞬間、私たちは不合理な経路を発見し、すぐに停止することができます。

 ## 特殊なケース

 到達可能なサイクルがないグラフを考えてみましょう。```
1 2
1 2 5
2 3 6
```到達可能なサブグラフにはサイクルを持つ SCC が含まれていないため、すべての SCC がスキップされます。 アルゴリズムは正しく印刷します`No`。 

単一の到達可能な有向サイクルを考えてみましょう。```
3 3
1 2 1
2 3 2
3 1 3
```gcd は 3 で、各剰余クラスは正確に 1 桁を出力し、競合は見つかりません。 出力は`No`。 

最後に考えてみましょう```
2 4
1 1 0
1 2 1
2 1 1
2 2 0
```グラフ全体が 1 つの SCC です。 gcd は 1 に等しいため、すべての頂点は同じ剰余クラスに属します。 この剰余には 0 と 1 の両方のラベルが付いた出力エッジがあるため、アルゴリズムはすぐにレポートします。`Yes`、最終的に非周期的な 2 進数シーケンスの存在と正確に一致します。
