 ## 解決策
 ## 問題の理解

 各節は 3 つの変数の積であり、すべての変数は次のいずれかです。`0`または`1`。 式全体は、すべての句の値の合計です。 この合計が奇数になるような変数の割り当てがあるかどうかを尋ねられます。 そのような割り当てが存在する場合は、有効な割り当ても 1 つ出力する必要があります。 

最終合計のパリティのみが重要であるため、すべての計算はモジュロで行われます。`2`。 加算は XOR になりますが、オペランドはすでにビットであるため、乗算は通常の乗算​​のままです。 したがって、式は次の多項式になります。`GF(2)`三次単項式のみで構成されます。 

すべてのテスト ケースにわたる変数と句の合計数は最大で`10^5`。 これにより、すべての割り当てを試すことが直ちに除外されます。`2^100000`全く実現不可能です。 変数の半分だけで指数関数的なアルゴリズムであっても、限界をはるかに超えています。 入力サイズが本質的に線形であるアルゴリズムが必要です。 

誤って対処しやすい状況がいくつかあります。 

同じ節が 2 回出現するとします。```
1
3 2
1 2 3
1 2 3
```正しい答えは、`NO`。 両方の句は常に同じ値に評価されるため、それらの寄与は次のいずれかになります。`0+0=0`または`1+1=2`、両方とも均等です。 一部の文節が次の条件を満たすかどうかだけをチェックするソリューション`1`間違って答えるだろう`YES`。 

句内で繰り返される変数にも注意が必要です。```
1
1 1
1 1 1
```句は等しい`x1³`、しかしそれ以来`x1`どちらかです`0`または`1`、これは単純に`x1`。 設定`x1=1`式が奇妙になるため、正しい答えは次のとおりです`YES`。 すべての節に 3 つの異なる変数が含まれていると仮定した引数は、ここでは失敗します。 

もう 1 つの微妙なケースは、すべての句に特定の変数が含まれる場合です。```
1
3 2
1 2 3
1 1 2
```設定`x1=0`式全体を即座に強制的にゼロにします。 アルゴリズムは、句の出現を数えるのではなく、代入について正しく推論する必要があります。 

## アプローチ

 ブルート フォース アプローチでは、すべての攻撃が試行されます。`2^n`課題。 割り当てごとにすべてを評価します`m`句を使用して、結果の合計が奇数かどうかをチェックします。 これは、考えられるすべての割り当てを明示的にテストするので正しいですが、最悪の場合の複雑さは次のとおりです。`O(m·2^n)`、にとっても絶望的です`n=40`、ましてや`100000`。 

重要な観察は、式を次の多項式として見ることから得られます。`GF(2)`。 

単項式が寄与する`1`その中に現れるすべての変数が等しい場合のみ`1`。 まだどこかに現れている最大のインデックス付き変数を繰り返し選択するとします。 その変数を含む残りのすべての単項式は、節のインデックスが次の条件を満たすため、その変数を最大の変数として持ちます。`a ≤ b ≤ c`。 

最大の変数が次のとおりであるすべての単項式をグループ化します。`xk`。 

彼らの貢献には次のような形があります。```
xk · P(previous variables)
```どこ`P`より小さいインデックスを持つ変数のみを含む多項式です。`k`。 

もし`P`いつかなれる`1`、私たちはただ選択するだけです`xk=1`そしてこのグループ全員が貢献できるようにする`1`。 もし`P`が常にゼロの場合、以下を含むすべての単項式が`xk`無関係なので破棄しても構いません。 

これにより、再帰的な削除プロセスが行われます。 すべての個別の単項式は 1 回だけ処理されます。 変数が残らなくなると、再帰は底に達します。 その時点で、多項式はまったく同じ 0 か、まったく同じ 1 になります。 

シンボリック多項式を明示的に操作する代わりに、単項式のリストを維持し、それらを最大の変数で再帰的に分割するだけで済みます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |`O(m·2^n)`|`O(n)`| 遅すぎる |
 | 最適 |`O(n+m)`|`O(n+m)`| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての文節を 3 つのインデックスで表します。 
2. 再帰関数を使用して、最大のインデックスから最小のインデックスに向かって変数を処理します。 
3. 現在の最大の変数について`xk`、すべての単項式を、最大の変数が次のとおりである単項式に分割します。`k`そして含まれていないもの`k`最大の変数として。 
4. 削除する`k`最初のグループのすべての単項式から。 次のような単項式`(2,5,5)`になる`(2,5)`最大の変数の出現を 1 つ削除した後。 すべてのコピーが消えると、結果は定数単項式になります。 
5. 縮小多項式が次のように評価できるかどうかを再帰的に判断します。`1`。 
6. 縮小された多項式が満足できる場合、次のように代入します。`xk=1`残りの単項式を続けます。 
7. それ以外の場合は割り当てます`xk=0`。 を含むすべての単項式`xk`が消えるので、2 番目のグループだけが残ります。 
8. すべての変数が処理されるまで続行します。 
9. 基本的な場合、多項式は定数項を含む場合に正確に満たされます。`1`。 

### なぜ効果があるのか

 現在の最大変数を含むすべての単項式は次の形式になります。`xk·M`、 どこ`M`小さい変数のみが含まれます。 もし`M`なることができる`1`、設定`xk=1`これらの換算された単項式によって表されるパリティを正確にアクティブにします。 もし`M`は常にゼロであり、割り当てはありません`xk`これらの単項式が寄与する可能性があるため、無視しても問題ありません。 再帰呼び出しごとに 1 つの変数が考慮から削除されるため、最終的にはすべての単項式は次のいずれかの定数になります。`1`または消えます。 これにより、各ステップで多項式のパリティが維持されるため、最終的な代入は、元の式が存在する場合は必ずそれを満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(1 << 25)

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n, m = map(int, input().split())

        poly = []
        for _ in range(m):
            poly.append(tuple(map(int, input().split())))

        assign = [0] * (n + 1)

        def dfs(var, terms):
            if var == 0:
                parity = 0
                for term in terms:
                    if len(term) == 0:
                        parity ^= 1
                return parity == 1

            with_var = []
            without_var = []

            for term in terms:
                if term and term[-1] == var:
                    with_var.append(term[:-1])
                else:
                    without_var.append(term)

            if dfs(var - 1, with_var):
                assign[var] = 1
                merged = without_var + with_var
                return dfs(var - 1, merged)

            assign[var] = 0
            return dfs(var - 1, without_var)

        if dfs(n, poly):
            out.append("YES")
            out.append(" ".join(map(str, assign[1:])))
        else:
            out.append("NO")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```再帰関数は、前述した消去プロセスに正確に従います。 各レベルは 1 つの変数を処理し、その変数で終わるかどうかに応じて単項式を分割し、必要に応じて 1 つの出現を削除します。 

すべての単項式をタプルとして表現すると、最大の変数を削除するだけで済むため便利です。`term[:-1]`。 インデックスはすでにソートされているため、最大の変数は常に最後の要素になります。 

基本ケースは特に注目に値します。 空のタプルのみが定数項を表します。 それらのパリティは、残りの多項式が 1 に等しいか 0 に等しいかを決定します。 

再帰の深さは最大でも`n`、したがって再帰制限はそれに応じて増加します。

 ## 特殊なケース

 重複した句の例を考えてみましょう。```
1
3 2
1 2 3
1 2 3
```両方の句は同一なので、以上です`GF(2)`それらは互いに打ち消し合います。 消去中、それらは定数レベルまでペアのままであり、そこでは 2 つの定数項もキャンセルされます。 アルゴリズムは正しく出力します`NO`。 

次に、反復変数を考えます。```
1
1 1
1 1 1
```再帰的削除により、変数のコピーが 1 つ削除されます。`1`単項式が定数項になるまで一度に。 この定数は 1 回だけ存在するため、基本ケースは成功を報告し、代入が生成されます。`x1=1`。 

最後に、1 つの変数によって強制的にゼロにされる句を考えてみましょう。```
1
3 1
1 2 3
```再帰チェックにより、最も高い変数をアクティブにすることが有益であると判断された場合、次の値が設定されます。`x3=1`。 それ以外の場合は設定されます`x3=0`、その条項を検討から直ちに削除します。 これは、バイナリ変数を乗算する代数的動作と正確に一致するため、すべての分岐が正確さを維持します。
