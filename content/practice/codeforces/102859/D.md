 ## 解決策
 ## 問題の理解

 円形の配置があります`N`料理。各料理は小文字で表されます。 サンプルは、円の周囲を時計回りまたは反時計回りに採取した連続した一連の料理です。 タスクは、サンプルとして現れる可能性のある異なる文字列の数を数えることです。 2 つのサンプルは、長さとすべての文字の位置が等しい場合にのみ等しいとみなされます。 

丸は、通常の部分文字列定義では不十分であることを意味します。 シーケンスは入力文字列の末尾から先頭に折り返すことができるため、時計回りの方向は次の部分文字列を取得することで表すことができます。`S + S`せいぜい長さで`N`。 反時計回りの方向は、反転した文字列に適用されるのと同じ考え方です。 

円の長さは最大です`50000`これにより、すべてのサンプルを明示的に生成することが除外されます。 長さの文字列`N`もっている`O(N^2)`可能な部分文字列があり、ここでは約 25 億の候補になります。 各候補者を一度チェックしただけでも、すでに一般的なコンテストの制限を超えてしまいます。 線形または線形に近い解決策が必要です。 

厄介なケースは、パターンの繰り返しや 2 つの方向の重なりによって発生します。 たとえば、単一の繰り返し文字の場合は次のようになります。```
Input
4
aaaa
```可能なサンプルは次のとおりです。`a`、`aa`、`aaa`、 そして`aaaa`、したがって、答えは次のようになります。```
4
```個別の文字列ではなく出現回数をカウントするソリューションでは、すべての開始位置で同じサンプルが作成されるため、カウントが過剰になります。 

もう 1 つの簡単な間違いは、2 つの方向が答えを共有していることを忘れることです。 のために：```
Input
3
aba
```時計回りのサンプルには次のものが含まれます`ab`そして`ba`、反時計回りのトラバーサルでも同じ文字列が生成されます。 両側を独立してカウントすると、重複がカウントされます。 正しい答えは次のとおりです。```
8
```フルセットは、`a`、`b`、`aa`、`ab`、`ba`、`aba`、`aab`、 そして`baa`。 

## アプローチ

 直接的なアプローチでは、すべての開始ディッシュを列挙し、一度に 1 文字ずつサンプルを拡張し、生成されたすべての文字列をセットに保存します。 がある`N`開始位置とそれまで`N`各位置の長さ、生成`O(N^2)`サンプル。 各サンプル自体には最大で次のものを含めることができるため、`N`文字を比較して保存すると、総当たり攻撃が可能になります。`O(N^3)`仕事。 ハッシュを使用しても、サンプルの 2 次数はすでに大きすぎて、`N = 50000`。 

問題の構造は、接尾辞オートマトンの使用を示唆しています。 接尾辞オートマトンは、文字列のすべての個別の部分文字列をコンパクトに格納します。 各状態は、同じ終了位置の動作を持つ部分文字列のグループを表し、表される文字列の数は、オートマトンに格納されている長さからカウントできます。 

円は通常の文字列に変換できます。 時計回りのサンプルはすべて次の部分文字列です。`S + S`その長さは最大でも`N`。 反時計回りのサンプルはすべて次の部分文字列です。`reverse(S) + reverse(S)`同じ長さ制限があります。 2 つのオートマトンを構築して回答を手動でマージする代わりに、二重化された両方の文字列を受け取る 1 つの一般化された接尾辞オートマトンを構築します。 これは、すべての有効なサンプルの結合を表します。 

唯一の追加の詳細は長さの制限です。 2 倍になった文字列には、完全な 1 ターンよりも長い部分文字列が含まれていますが、それらは有効なサンプルではありません。 状態の寄与をカウントするとき、すべての長さの上限は次のとおりです。`N`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(N2) から O(N3) | O(N²) | 遅すぎる |
 | 汎用接尾辞オートマトン | O(N) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 以下を挿入して、一般化された接尾辞オートマトンを構築します。`S + S`そして挿入します`reverse(S) + reverse(S)`。 2 番目の文字列を挿入する前に、ルートからやり直して、オートマトンが両方のソースの部分文字列の結合を表すようにします。 
2. オートマトンの状態ごとに、通常のサフィックス オートマトンの値を保存します`len`、これはその状態によって表される部分文字列の最大長です。 接尾辞のリンクは、次に小さい接尾辞グループを表す状態を指します。 
3. 各非ルート状態の寄与をカウントします。 通常、州は以下のすべての長さを提供します。`len[link[state]] + 1`に`len[state]`。 サンプルは 1 つの円を超えることはできないため、両方の長さをその最小値で置き換えます。`N`。 
4. すべての州の拠出金を追加します。 合計は、両方向の個別のサンプルの数です。 

機能する理由: サフィックス オートマトンは、すべての個別の部分文字列を状態に分割し、各状態が 1 つの連続した長さの範囲をカバーします。 接尾辞リンクは前の範囲の終わりを示すため、すべての個別の部分文字列は、状態とその接尾辞リンクの間の差に 1 回だけ表示されます。 一般化された構造により、表現される言語は両方向の結合となり、長さの制限により、円を複数回周回する必要がある文字列が正確に削除されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    s = input().strip()

    strings = [s + s, (s[::-1]) + (s[::-1])]

    nexts = [{}]
    link = [-1]
    length = [0]

    def extend(c, last):
        cur = len(nexts)
        nexts.append({})
        length.append(length[last] + 1)
        link.append(0)

        p = last
        while p != -1 and c not in nexts[p]:
            nexts[p][c] = cur
            p = link[p]

        if p == -1:
            link[cur] = 0
        else:
            q = nexts[p][c]
            if length[p] + 1 == length[q]:
                link[cur] = q
            else:
                clone = len(nexts)
                nexts.append(nexts[q].copy())
                length.append(length[p] + 1)
                link.append(link[q])

                while p != -1 and nexts[p].get(c) == q:
                    nexts[p][c] = clone
                    p = link[p]

                link[q] = clone
                link[cur] = clone

        return cur

    for text in strings:
        last = 0
        for c in text:
            last = extend(c, last)

    ans = 0
    for state in range(1, len(length)):
        high = min(length[state], n)
        low = min(length[link[state]], n)
        if high > low:
            ans += high - low

    print(ans)

if __name__ == "__main__":
    solve()
```オートマトンの構築は、標準の接尾辞オートマトン拡張です。 挿入された各文字は新しい状態を作成し、以前には存在しなかった遷移を修正します。 既存の遷移が、新しいサフィックスに対して長さの範囲が大きすぎる状態につながる場合、クローン作成が必要です。 

重要な実装の詳細はリセットです`last`をルートに戻してから、反転した二重文字列を挿入します。 このリセットがないと、オートマトンはあたかも 2 番目の文字列が最初の文字列を継続しているかのように動作し、境界を越える無効な部分文字列が発生することになります。 

最後のループでは、各状態の表現された長さの数を計算します。 ルートは空の文字列を表すため、スキップされます。 の`min`この操作では、円の長さの制限が適用され、テーブルの 1 周を超える長いサンプルのカウントが回避されます。 

## 実用的な例

 対象:```
3
aba
```挿入された 2 つの文字列は次のとおりです。`abaaba`そして`abaaba`逆も同じだから。 オートマトンには言語のコピーが 1 つだけ必要です。 

| 状態 | 長さ | サフィックスリンクの長さ | 貢献 |
 | --- | --- | --- | --- |
 |`a`グループ | 1 | 0 | 1 |
 |`ab`グループ | 2 | 1 | 1 |
 |`aba`グループ | 3 | 1 | 2 |
 | 繰り返されるグループ | ... | ... | 残りの個別の文字列 |

 合計は次のようになります`8`。 トレースは、複製された時計回りと反時計回りのサンプルが自動的にマージされることを示しています。 

のために：```
6
ondrej
```逆方向では、次のような文字列が追加されます。`rejo`そして`drejon`、時計回りの方向には からの文字列が含まれます。`ondrejondrej`。 

| ステージ | 挿入されたテキスト | 考慮される最大サンプル長 | 効果 |
 | --- | --- | --- | --- |
 | 最初の挿入 |`ondrejo...`| 6 | 時計回りにサンプルを追加します |
 | 2 番目の挿入 | 反転した二重化文字列 | 6 | 反時計回りにサンプルを追加します |
 | カウント | すべての州 | 6 | 和集合のみをカウントします |

 オートマトンは共有部分文字列を同じ状態に保つため、最終的なカウントは両方向の一意のサンプルの数になります。

 ## 特殊なケース

 文字が繰り返される場合:```
4
aaaa
```二重化された文字列は、`aaaaaaaa`。 オートマトンは同じパターンが多数出現しますが、それらは同じ状態に崩壊します。 州の貢献により長さが生み出される`1`、`2`、`3`、 そして`4`正しい答えを与えるだけです`4`。 

方向が重複する場合:```
3
aba
```逆の円は、オートマトンですでに表現されている共有言語を超える新しい一意の文字列を生成しません。 二重化された両方の文字列が同じ構造に挿入されるため、カウント式では同じサンプルに重複した状態が追加されません。 答えは残っている`8`。 

ラッピングが重要な場合:```
5
abcde
```のようなサンプル`dea`元の文字列では通常の部分文字列として見つけることはできませんが、内部に表示されます`abcdeabcde`。 2 倍化ステップにより、これらのラップされた部分文字列が作成され、長さの上限により、次のような無効なサンプルが防止されます。`abcdea`カウントされることから。 最終的な答えは、`25`。
