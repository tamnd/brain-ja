 ## 解決策
 ## 問題の理解

 復元したいシーケンスは、完全なグラフのオイラー ツアーです。 からの各番号`1`に`N`は頂点であり、2 つの異なる数字を並べて書くことは、これら 2 つの頂点を接続するエッジを横断することを意味します。 有効なシーケンスでは、2 つの異なる頂点間のすべての可能なエッジを 1 回だけ使用する必要があります。 

入力により、アップルパイが 1 つの連続した中間セクションをカバーした後の、そのようなシーケンスの目に見える部分が得られます。 左側は表示されたままのプレフィックス、右側は表示されたままのサフィックスです。 完全なシーケンスがすべてのエッジの有効な走査となるように、それらの間に挿入できる隠れた中間セクションが存在するかどうかを判断する必要があります。 

制限は、最大でも次のグラフを中心に設計されています。`N = 1000`頂点。 表示できる値の数は次のとおりです。`5 * 10^5`したがって、多くの可能なシーケンスを構築またはテストしようとするソリューションは不可能です。 入力量と可能なエッジの数の合計に関して、線形に近いアプローチが必要です。 完全なグラフには約`N^2 / 2`エッジ、`O(N^2)`解決策は受け入れられます。`N`たったの1000です。 

最初のエッジ ケースは、完全なシーケンス自体の存在から生じます。 たとえば、次のようになります。```
2
0
0
```答えは`Y`、唯一のエッジが頂点間にあるため`1`そして`2`、 それで`[1,2]`可能です。 可視シーケンスに少なくとも 1 つの要素が含まれている必要があると仮定する不用意な解決策は、このケースを拒否します。 

もう 1 つのエッジ ケースは、目に見える部分で繰り返されるエッジです。 のために：```
3
2 2 1
2 2 1
```答えは`N`。 ペア`{1,2}`は表示されているセクションに 2 回表示されるため、隠れた中間部分はシーケンスを修復できません。 頂点数のみをチェックし、すでに使用されているエッジを無視する実装は、それを誤って受け入れます。 

最後の注意が必要なケースは、エッジを繰り返さない頂点の繰り返しです。 のために：```
3
2 2 1
2 2 2
```答えは`N`。 表示されているセクションにはエッジが含まれています`{1,2}`そしてエッジ`{2,3}`が欠落していますが、サフィックスを使用する必要があります`{2,2}`、隣接する等しい数値は無効であるため、これは許可されたエッジですらない。 元の歩行を検証せずに度だけをチェックすると、これを見逃してしまいます。 

グラフの重要な観察点は、シーケンス全体がオイラー軌跡であるということです。 すでに左右に表示されているエッジを削除できます。 隠れた部分は残りのグラフのオイラー軌跡であればよく、両方が存在する場合は可視部分を接続します。 

## アプローチ

 直接的なアプローチは、欠けている中央を構築しようとすることです。 可能なエッジの総数は最大です。`499500`したがって、考えられるすべての開始点についてオイラー トレイルの構築をシミュレートしたり、隠れたセクションを遡ってみたりすることもできます。 エッジの可能な次数は膨大であるため、これは現実的ではありません。 可能性のあるトレイルのほんの一部をチェックするだけでも、すぐに利用可能な時間を超えてしまいます。 

視点を変えると効果的なのは、欠落しているシーケンスについて考えるのをやめ、代わりにまだ使用されていないエッジについて考えることです。 表示されているプレフィックスとサフィックスにより、一部のエッジがすでに修正されています。 これらのエッジが有効な場合は、完全なグラフから単純に削除できます。 問題は、残りのグラフに必要なエンドポイントを含むオイラー軌跡があるかどうかです。 

無向グラフでは、すべての非孤立頂点が 1 つの連結成分に属し、奇数次の頂点の数が 0 または 2 の場合に正確にオイラー軌跡が得られます。 奇数の頂点が 2 つある場合は、それらがトレイルの開始点と終了点である必要があります。 

元のグラフが完成しているため、どのエッジが表示されている部分によって消費されたかをブール行列に保存できます。 次に、残りのグラフで次数を計算し、接続性をチェックして、オイラー条件を検証します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 隠れエッジの数が指数関数的 | O(N^2) | 遅すぎる |
 | 最適 | O(P + Q + N^2) | O(N^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. シーケンスの 2 つの表示部分を読み取ります。 各パーツをトラバースし、隣接するすべてのペアを使用済みエッジとしてマークします。 隣接するペアに等しい値が含まれる場合、または同じ無向エッジが 2 回出現する場合、答えはすぐに得られます。`N`。 
2. 完全なグラフのマークされていないすべてのエッジを非表示部分として扱います。 この残りのグラフ内のすべての頂点の次数を計算します。 
3. 必要なオイラー トレイル エンドポイントを決定します。 両方の表示側が存在する場合、非表示セクションは左側の後で開始し、右側の前で終了する必要があります。 片側が欠落している場合は、欠落しているエンドポイントを自由に選択できます。 
4. 残りのグラフで次数が奇数の頂点を数えます。 両方の端点が固定されている場合は、奇数次の頂点と正確に一致する必要があります。 一方または両方のエンドポイントが空いている場合、許可される奇数次構成は通常のオイラー トレイル ルールに従います。 
5. 残りのエッジを持つすべての頂点が 1 つの連結コンポーネントに属していることを確認します。 切断された未使用のエッジを 1 つの非表示シーケンスですべてカバーすることはできません。 
6. すべての条件が合格すると、出力`Y`; それ以外の場合は出力`N`。 

機能する理由: 表示されるシーケンスは、完全なグラフから一連のエッジをすでに消費しています。 有効な補完では残りのエッジを正確に使用する必要があるため、隠れた部分は正確に残りのグラフのオイラー軌跡になります。 オイラーの軌跡定理は、そのような軌跡が存在するための必要十分条件を与えます。 エンドポイント要件もチェックされるため、受け入れられたすべてのケースには有効な完了があり、拒否されたすべてのケースは不可能です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    left = list(map(int, input().split()))
    p = left[0]
    left = left[1:]

    right = list(map(int, input().split()))
    q = right[0]
    right = right[1:]

    used = [[False] * n for _ in range(n)]
    bad = False

    def add_edges(arr):
        nonlocal bad
        for i in range(len(arr) - 1):
            a = arr[i] - 1
            b = arr[i + 1] - 1
            if a == b or used[a][b]:
                bad = True
            else:
                used[a][b] = True
                used[b][a] = True

    add_edges(left)
    add_edges(right)

    if bad:
        print("N")
        return

    deg = [0] * n
    graph = [[] for _ in range(n)]

    for i in range(n):
        for j in range(i + 1, n):
            if not used[i][j]:
                deg[i] += 1
                deg[j] += 1
                graph[i].append(j)
                graph[j].append(i)

    fixed_start = left[-1] - 1 if p else -1
    fixed_end = right[0] - 1 if q else -1

    odd = [i for i in range(n) if deg[i] % 2]

    if fixed_start != -1 and fixed_end != -1:
        if len(odd) == 0:
            if fixed_start != fixed_end:
                print("N")
                return
        elif len(odd) == 2:
            if set(odd) != {fixed_start, fixed_end}:
                print("N")
                return
        else:
            print("N")
            return
    elif fixed_start != -1:
        if len(odd) == 2:
            if fixed_start not in odd:
                print("N")
                return
        elif len(odd) != 0:
            print("N")
            return
    elif fixed_end != -1:
        if len(odd) == 2:
            if fixed_end not in odd:
                print("N")
                return
        elif len(odd) != 0:
            print("N")
            return
    else:
        if len(odd) not in (0, 2):
            print("N")
            return

    start = -1
    for i in range(n):
        if deg[i]:
            start = i
            break

    if start != -1:
        stack = [start]
        seen = [False] * n
        seen[start] = True
        while stack:
            v = stack.pop()
            for u in graph[v]:
                if not seen[u]:
                    seen[u] = True
                    stack.append(u)

        for i in range(n):
            if deg[i] and not seen[i]:
                print("N")
                return

    print("Y")

if __name__ == "__main__":
    solve()
```マトリックス`used`すでに表示されているエッジを正確に保存します。 頂点には次から番号が付けられているため、`1`の場合、実装は配列にアクセスする前にそれらを 0 から始まるインデックスに変換します。 

最初のトラバーサルでは、シーケンスの 2 つの既知の部分を検証します。 完全なグラフ内のエッジは異なる頂点を接続するだけであるため、隣接する等しい値は無効です。 すべてのエッジは 1 回だけ出現する必要があるため、同じ無向エッジを 2 回見ることも不可能です。 

残りの次数の計算は完全なグラフから開始され、未使用のエッジのみが効果的に保持されます。 次に、オイラー条件がこの残りのグラフに対してチェックされます。 プレフィックスまたはサフィックスが欠落しているということは、隠れたオイラー トレイルの一端が事前に決定されていないことを意味するため、エンドポイントの処理は分離されます。 

最後の深さ優先検索では、通過する必要のあるエッジが含まれていないため、孤立した頂点は無視されます。 残りのグラフに参加している頂点のみが同じ連結成分に属している必要があります。

 ## 特殊なケース

 アップルパイがシーケンス全体を覆う場合、表示されている部分は両方とも空になります。 このアルゴリズムは、完全なグラフ自体にオイラー軌跡があるかどうかを単純にチェックします。 のために`N=2`、残りのグラフには 2 つの奇数次の頂点とパスがあります。 奇数の場合`N`、すべての頂点は偶数次数を持つため、オイラー回路が存在します。 偶数の場合`N > 2`、奇数次の頂点が多すぎるため、答えは次のようになります。`N`。 

可視側に同じエッジが 2 回含まれる場合、アルゴリズムは最初のスキャン中に拒否します。 例えば：```
3
3 1 2 1
0
```エッジが含まれています`{1,2}`そして`{1,2}`また。 エッジ行列をマークすると、オイラー推論が実行される前にこれが捕捉されます。 

片側のみが表示されている場合、非表示のオイラー トレイルの欠落している終点は変化することが許可されます。 例えば：```
3
1 2
0
```頂点の後に始まる非表示セクションを残します`2`。 残りのエッジは次のように横断できます。`2 -> 1 -> 3 -> 2`、オイラー条件により適切なエンドポイントが許可されるため、アルゴリズムはそれを受け入れます。
