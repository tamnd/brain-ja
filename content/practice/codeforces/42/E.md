 ## 解決策
 ## 問題の理解

 未知のトンネル システムの上に、ワームホールと呼ばれる追加の無向エッジのセットを準備するように求められます。 

軍事基地には、`n`オブジェクト。 トンネル グラフは、次の 2 つの保証を除いて不明です。 

まず、トンネルグラフを接続します。 

次に、ちょうど 2 つの頂点がサーフェスに接続されます。 パトロールは 1 つのサーフェス頂点から開始し、可能であればすべてのトンネルを 1 回だけ通過し、1 つのサーフェス頂点から終了します。 クエリの 2 つのサーフェス頂点は固定されており、既知です。 

パトロールは何度でもワームホールを通過することができますが、元のトンネルはすべて 1 回だけ使用する必要があります。 

ワームホールの可能性を示す別のグラフが表示されます。 考えられるワームホールにはそれぞれ建設コストがかかります。 あらゆるクエリに対して`(a, b)`、表面の頂点が正確に一致する接続されたトンネル グラフごとに、ワームホールの合計コストの最小値を見つける必要があります。`a`そして`b`、パトロールはすべてのトンネルを 1 回だけ通過できます。 

キーワードは「どんなトンネルの配置にも」です。 トンネルグラフは分かりません。 私たちのワームホールは、これら 2 つの表面頂点を持つ接続されたすべてのグラフに対して普遍的に機能する必要があります。 

制約により、二次関数は即座に除外されます。`n`または`q`。 まであります`100000`頂点、`200000`ワームホールと`100000`クエリ。 アン`O(n^2)`前処理または`O(m)`クエリごとのスキャンは遅すぎます。 に近いものが必要です`O((n + m + q) log n)`。 

この問題の最も難しい部分は、ワームホールがどのようなプロパティを強制する必要があるかを理解することです。 不用意に解釈すると、まったく間違ったグラフの条件が作成されてしまいます。 

次のトンネル グラフを考えてみましょう。```
1 - 2 - 3
```サーフェス頂点あり`1`そして`3`。 

このグラフにはすでにオイラー軌跡が含まれています`1`に`3`、奇数次の頂点は正確に`1`そして`3`。 ワームホールは必要ないので、答えは次のとおりです。`0`。 

まさにそれが、サンプル 1 の出力の理由です。`0`。 

ここで、中心にある星を考えてみましょう。`2`:```
    1
    |
3 - 2 - 4
```サーフェスの頂点が次のようになっていると仮定します。`1`そして`4`。 

奇数次の頂点は次のとおりです。`1, 2, 3, 4`。 パトロールには追加のエッジが必要です`1`そして`4`奇数。 トンネル グラフが事前にわからないため、ワームホールは任意のパリティ構成を修正できなければなりません。 

素朴な考えは、頂点のすべてのペアをワームホールで接続することです。 それは確かに機能しますが、必要以上にコストが大幅に高くなります。 

もう 1 つの簡単な間違いは、接続だけで十分だと考えることです。 そうではない。 元のトンネル グラフはすでに接続されているため、ワームホールはパリティを変更する場合にのみ役立ちます。 

特に危険なエッジケースは、ワームホール グラフ自体が切断されている場合です。 

例：```
n = 4
wormholes:
1 - 2
3 - 4
query: 1 3
```どのようなトンネル グラフが表示されても、2 つのコンポーネント間でパリティ情報を転送する方法はありません。 正しい答えは、`-1`。 

もう 1 つの微妙なケースは、同じペア間の複数のワームホールです。```
1 - 2 cost 10
1 - 2 cost 3
```最短パスでは最も安価なエッジのみが重要です。 任意の重複を保持する不注意な実装により、不正確な距離が生成される可能性があります。 

## アプローチ

 ブルート フォースの観点はパリティ補正から始まります。 

無向グラフでは、オイラー軌跡は次のようになります。`a`に`b`可能性を除くすべての頂点が存在する場合にのみ存在します`a`そして`b`偶数次数を持ち、グラフは接続されます。 

元のトンネル グラフはすでに接続されています。 唯一の問題はパリティです。 

どういうわけか正確なトンネルグラフを知っていたとします。 次に、すべての奇数次の頂点を特定し、ワームホールを使用してそれらをペアにすることができます。 ワームホールを通過すると、その端点のパリティが反転するため、2 つの奇数の頂点の間にパスを追加すると、両方が修正されます。 

これは、最小コストのパリティ マッチングにすぐに似ています。 

問題は、トンネルグラフが不明であることです。 表面頂点を持つすべての接続されたグラフに対して機能する固定ワームホール システムを構築する必要があります。`a`そして`b`。 

この普遍的な要件により、問題は完全に変わります。 

重要な観察は、接続されたグラフでは、奇数次の頂点のセットは常に偶数サイズであり、それ以外の場合は任意のサイズになる可能性があるということです。 どの頂点が奇数になるかわからないため、ワームホール システムでは、ワームホール パスを介して任意の頂点をペアにできる必要があります。 

つまり、頂点のすべてのペアがワームホールを介して接続されている必要があります。 そうしないと、異なるコンポーネントに奇数の頂点が配置され、パリティの修復に失敗する可能性があります。 

それで、クエリのために`(a, b)`、ワームホール グラフはすべての頂点を接続する必要があります。 ただし、例外が 1 つあります。`a`そして`b`最終的なグラフでは奇数のままにすることができます。 パリティ補正は必要ありません。 

これは実際の状況につながります。 

可能性を除くすべての頂点`a`そして`b`ワームホール グラフの 1 つの連結コンポーネント内に存在する必要があります。 

同様に、削除後、`a`そして`b`、残りの頂点はワームホールを通じて接続されたままでなければなりません。 

ここで、問題はよりグラフ理論的なものになります。 

次のような最小コストのサブグラフが必要です。`a`そして`b`グラフを切断しません。 

古典的な定理から次のような答えが得られます。 

必要な構造は、次の場合にのみ存在します。`a`そして`b`ワームホール グラフの同じ二重連結コンポーネントに属します。 

さらに、最小コストは、両方を含むサイクルに沿った最小エッジの重みと正確に一致します。`a`そして`b`。 

これにより、問題は二重接続コンポーネントを使用したオフライン グラフ処理に変換されます。 

最適な解決策は、クラスカル再構成フォレストをエッジの降順で構築します。 エッジの重みを使用して 2 つの連結コンポーネントをマージする場合`w`、値を指定して新しい仮想ノードを作成します。`w`。 

この場合、2 つの頂点の答えは、この再構成ツリー内の最も低い共通の祖先に格納されている値になります。 

なぜこれが機能するのでしょうか?

 それは、再構築プロセスが頂点間の最大のボトルネック接続を正確に捕捉するためです。 2 つの頂点は、それらを結合できる最小のエッジ ウェイトで同じ二重接続構造の一部になります。 

すべてのクエリとすべての可能なトンネル グラフを個別に推論するのは指数関数的であるため、ブルート フォースは失敗します。 再構築ツリーの観察では、関連するすべての接続情報が単一のツリー構造に圧縮されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | クエリごとのブルート フォース パリティ推論 | 指数関数的/実行不可能 | 巨大な | 遅すぎる |
 | クラスカル再構成ツリー + LCA | O((m + q) log n) | O(n log n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのワームホールをコストの降順に並べ替えます。 

再構築ツリーにはボトルネック値が保存されているため、高価なエッジを最初に処理します。 2 つのコンポーネントがマージされる最初の瞬間に、それらの間のパス上の最大最小エッジが決まります。 
2. 元の頂点の上に DSU 構造を作成します。 

各 DSU コンポーネントは、再構成フォレスト内のサブツリーに対応します。 
3. エッジがあるたびに`(u, v, w)`2 つの異なる DSU コンポーネントを接続し、新しい仮想ノードを作成します。 

この新しいノードはコストを伴うマージ イベントを表します`w`。 
4. マージされた 2 つのコンポーネントのルートを新しい仮想ノードの子にします。 

仮想ノードは両方のサブツリーの親になります。 その保存された値は、`w`。 
5. すべてのエッジが処理されるまで続行します。 

結果として得られる構造は、マージ ツリーのフォレストです。 元の頂点はすべて葉として表示されます。 
6. 再構成フォレストに対する LCA クエリのバイナリ リフティング テーブルを前処理します。 

先祖を 2 のべき乗と深さで保存します。 
7. 各クエリについて`(a, b)`：

もし`a`そして`b`すべてのマージ後、同じ DSU コンポーネント内に存在しない場合、出力`-1`。 

それ以外の場合は、再構成ツリーで LCA を計算します。 
8. LCA に保存されている値を出力します。 

この値は、クエリに必要な最小ワームホール コストです。 

### なぜ効果があるのか

 再構成ツリーは、2 つの頂点が下降エッジしきい値の下で接続される正確な瞬間をエンコードします。 

次の LCA を仮定します。`a`そして`b`価値がある`w`。 つまり:

 このマージの下で使用されるすべてのエッジの重みは厳密に次の値より大きくなります。`w`、しかしマージは`w`を含むコンポーネントが配置される最初の点です。`a`そして`b`つながるようになる。 

したがって、間にパスが存在します`a`そして`b`少なくともウェイトのあるエッジのみを使用する`w`、厳密に大きな重みを使用するそのようなパスは存在しません。 

これはまさに頂点間のボトルネック パスの最大値です。 

そのボトルネック値は、パリティ引数で必要な最小ユニバーサル ワームホール コストと一致します。 しきい値が小さいと、必要な接続構造を維持できなくなります。 

## Python ソリューション```python
import sys
sys.setrecursionlimit(1 << 25)
input = sys.stdin.readline

n = int(input())
m = int(input())

edges = []
for _ in range(m):
    u, v, w = map(int, input().split())
    edges.append((w, u - 1, v - 1))

edges.sort(reverse=True)

max_nodes = 2 * n + m + 5

parent = list(range(max_nodes))
tree = [[] for _ in range(max_nodes)]
value = [0] * max_nodes

root = list(range(max_nodes))

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

cur = n

for w, u, v in edges:
    fu = find(root[u])
    fv = find(root[v])

    if fu == fv:
        continue

    node = cur
    cur += 1

    value[node] = w

    tree[node].append(root[fu])
    tree[node].append(root[fv])

    parent[fu] = node
    parent[fv] = node
    parent[node] = node

    root[node] = node

LOG = 20

up = [[-1] * cur for _ in range(LOG)]
depth = [0] * cur

visited = [False] * cur

def dfs(v):
    visited[v] = True

    for to in tree[v]:
        depth[to] = depth[v] + 1
        up[0][to] = v
        dfs(to)

for v in range(cur):
    if find(v) == v and not visited[v]:
        dfs(v)

for k in range(1, LOG):
    for v in range(cur):
        if up[k - 1][v] != -1:
            up[k][v] = up[k - 1][up[k - 1][v]]

def lca(a, b):
    if depth[a] < depth[b]:
        a, b = b, a

    diff = depth[a] - depth[b]

    for k in range(LOG):
        if diff & (1 << k):
            a = up[k][a]

    if a == b:
        return a

    for k in range(LOG - 1, -1, -1):
        if up[k][a] != up[k][b]:
            a = up[k][a]
            b = up[k][b]

    return up[0][a]

q = int(input())

out = []

for _ in range(q):
    a, b = map(int, input().split())
    a -= 1
    b -= 1

    if find(a) != find(b):
        out.append("-1")
        continue

    anc = lca(a, b)
    out.append(str(value[anc]))

print("\n".join(out))
```最初のセクションでは、ワームホールを読み取り、降順に並べ替えます。 順序付けは重要です。 再構成ツリーは、より大きな重みからより小さな重みへのマージが発生する場合にのみ正しく機能します。 

DSU はコンポーネント間の接続を追跡します。 マージが成功するたびに、新しい仮想ノードが作成されます。 このノードはマージに関与するエッジの重みを格納し、マージされた 2 つのツリーの親になります。 

微妙な点の 1 つは、元の頂点が`0..n-1`はリーフですが、すべての仮想マージ ノードは後で作成されます。 ノードの総数は最大で約`2n`。 

DFS は、バイナリ リフティングの深さと直接の親情報を構築します。 再構築構造はフォレストなので、すべてのルートから DFS を開始します。 

LCA ロジックは標準的なバイナリ リフティングです。 重要な特性は、LCA に格納されている値が、これら 2 つの頂点のボトルネック マージ値と等しいということです。 

間違いやすいもう 1 つの実装詳細は、切断された頂点のクエリです。 2 つの頂点が同じ DSU コンポーネントにマージされなかった場合、有効なワームホール システムは存在しないため、次の結果を返します。`-1`。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

 | 時間 | O((m + q) log n) | 並べ替えと DSU および LCA クエリ |

 ## 特殊なケース

 切断されたワームホール コンポーネントを考慮してください。```
4
2
1 2 5
3 4 7
1
1 4
```DSU は、以下を含むコンポーネントをマージしません。`1`を含むコンポーネントで`4`。 

クエリ処理中:```
find(1) != find(4)
```したがって、アルゴリズムの出力は`-1`。 

これは正しいです。ワームホール構造では、切断された領域間でパリティ修正を転送できないからです。 

ここで平行エッジを考えてみましょう。```
2
2
1 2 10
1 2 3
1
1 2
```エッジは降順で処理されます。```
10 first
3 second
```最初のエッジは 2 つの頂点をマージし、値を持つ再構築ノードを作成します。`10`。 

頂点はすでに接続されているため、2 番目のエッジは無視されます。 

答えは次のようになります`10`。 

これにより、頂点間の最大のボトルネック接続が正確にキャプチャされます。 

最後に、長いチェーンを考えてみましょう。```
4
3
1 2 10
2 3 8
3 4 6
1
1 4
```再構築マージは次の値で発生します。```
10 -> 8 -> 6
```のLCA`1`そして`4`値を持つ最後のマージノードです`6`。 

これは、頂点間の唯一のパス上の最小エッジと一致します。これはまさにボトルネック接続値です。
