 ## 問題の理解

 私たちに与えられたコレクションは、$n$レリックと呼ばれる別個のアイテム。 それぞれの遺物$i$は 2 つの方法で入手できます。固定コストで直接購入する方法です。$c_i$、または固定費を支払うことによって$x$すべての中から均一にランダムな遺物を受け取る$n$, 重複したものは部分的に返金され破棄されるため、進行には役立ちません。 

目標は最終的にすべてを所有することです$n$予想される通貨の総使用量を最小限に抑えながら、明確な遺物を収集します。 

問題は、2 番目の操作が確率的で状態に依存することです。 ランダムな購入はすべて、遺物のどのサブセットがすでに収集されているかによって異なり、重複すると部分的な払い戻しが発生するため、コレクションが増加するにつれてサンプリングの実効コストは動的に変化します。 

という点では制約は小さい$n$、 以来$n \le 100$しかし、ランダム性により、遺物のすべてのサブセットにわたって状態空間が導入されます。 サブセットに対する単純な動的プログラミングは、すぐに次のことを示唆します。$2^n$状態空間が大きすぎます。 どのようなソリューションでも、状態を圧縮するか、ランダム性の動作における対称性を利用する必要があります。 

微妙なエッジケースは、次のような状況から発生します。$c_i$に比べて非常に大きい$x$、初期段階ではランダムな取得が望ましいですが、後の段階では直接購入が有利になります。 もう 1 つのエッジケースは次のような場合です$n=1$、答えは簡単です。$\min(c_1, x)$、重複は決して重要ではなく、返金メカニズムは無関係であるためです。 

## アプローチ

 強引な定式化では、各州をすでに所有されている遺物のサブセットとして扱うことになります。 州から$S$、不足している遺物を購入するか、$i$のために$c_i$、または私たちが支払います$x$そして確率的に遷移します。一様にランダムな値を受け取ります。$j$、そしてもし$j \in S$の返金以外は何も変わりません。$x/2$、そうでない場合は、に移動します$S \cup \{j\}$。 

させて$dp[S]$州から予想される最小コストを示します$S$。 各状態からの遷移には、すべての状態を反復する必要があります。$n$遺物があり、$2^n$状態なので、複雑さは次のようになります。$O(n 2^n)$。 これはすでに不可能になっています$n=100$、重複によって引き起こされる自己ループに対する期待を計算するコストも無視します。 

重要な観察は、状態は実際には私たちがどのサブセットを持っているかには依存せず、私たちがすでに所有している遺物の数と、残りのセットが合計でどれだけ「高価」であるかによってのみ依存するということです。 ランダム操作ではすべての遺物が対称的に扱われるため、収集されたアイテムの識別情報は個別に重要ではなく、それらのコストの合計と組み合わせた数のみが重要になります。 

この対称性により、サイズの最適なサブセットのみを追跡しながら、収集されたアイテムの数に関するプロセスとして問題を再定式化できます。$k$あらゆる可能性のために$k$。 直接購入が使用されている場合、最適な戦略では常に、入手可能な最も安価なレリックを最初に収集することが優先されます。これは、残りのセットを完成させるための限界コストが削減されるためです。 

したがって、動的プログラミングは、カーディナリティに基づいて予想コストを維持することになり、遷移は欠落項目の数と総コスト構造のみに依存します。

 ## アルゴリズムのチュートリアル

 まず遺物のコストを分類します$c_i$降順ではない順に。 特定のサブセットを直接購入することを選択した場合、最初に安価な遺物を優先することが常に最適であるため、これは正当化されます。 より高価なレリックを「購入済み」セットに交換すると、コストが増加するだけです。 

DP 状態を定義します$dp[k]$すでに所有していることを前提として、すべての遺物の収集を完了するために予想される最小コストとして$k$ソートされた順序で最も安い遺物。 これが機能するのは、最適なプレイの下では、所有されているレリックのセットが常にソートされた順序のプレフィックスであると想定できるためです。 

また、残りのアイテムを直接購入する総コストを迅速に評価できるように、プレフィックス合計も事前計算します。 

遷移では、各状態で 2 つの戦略を比較します。$k$: ランダム性の使用をやめて残りのレリックをすべて直接購入するか、ランダム購入を継続して予想される進捗をモデル化します。 

ランダムな操作は、1 回の購入の結果を条件として分析されます。 支払うとき$x$、確率的に$\frac{n-k}{n}$私たちは新たな行方不明の遺物を入手し、州に移動します$k+1$、確率的には$\frac{k}{n}$複製を取得して同じ状態を維持し、実質的に支払いを行います$x/2$返金を期待して。 

この自己ループを再配置すると、状態から進行するための明示的な予想コストが得られます。$k$に$k+1$のみに依存します。$k$、$n$、そしてすでに計算されている$dp[k+1]$。 

から状態を計算します$k=n$まで$0$なぜなら、上位の状態は下位の状態に依存するからです。 

### なぜ効果があるのか

 不変条件は、それぞれの$k$、$dp[k]$は、対称性が問題になるまでの所有アイテムの同一性のみを仮定した最適な予想コストを表します。 ランダム操作の対称性により、新しいアイテムを入手できる確率は、どのアイテムではなく、どれだけ残っているかによって決まるため、最適なプレイの下では、収集されたレリックの数が同じである任意の 2 つの構成を交換できることが保証されます。 これにより、指数関数的な状態空間がカーディナリティによってインデックス付けされた状態の線形チェーンに崩壊され、ラベル固有の構造を利用できる決定がないため、最適性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, x = map(int, input().split())
    c = list(map(int, input().split()))
    c.sort()
    
    # dp[k]: expected cost to finish when we already have k cheapest items
    dp = [0.0] * (n + 1)
    
    # suffix sum of costs
    suf = [0.0] * (n + 1)
    for i in range(n - 1, -1, -1):
        suf[i] = suf[i + 1] + c[i]
    
    dp[n] = 0.0
    
    for k in range(n - 1, -1, -1):
        remaining = n - k
        
        # option 1: buy all remaining directly
        direct = suf[k]
        
        # option 2: use random process once, then continue optimally
        # probability new item = remaining / n
        # expected number of trials to get new item: n / remaining
        # each attempt costs x, but duplicate refunds x/2 are handled via expectation:
        # effective cost per attempt = x/2 + x/2 * (k/n) adjustment simplifies to x * n / (2*remaining)
        
        expected_random_step = x * n / (2.0 * remaining)
        random_strategy = expected_random_step + dp[k + 1]
        
        dp[k] = min(direct, random_strategy)
    
    print(f"{dp[0]:.15f}")

if __name__ == "__main__":
    solve()
```実装は、ソートされたレリックに対する DP に従います。 サフィックス合計配列により、残りのすべての遺物をその位置から直接購入するコストを即座に計算できます。$k$。 ランダム戦略は、各試行に確率がある幾何学的プロセスとしてモデル化されます。$(n-k)/n$予想される試行回数につながる進行状況$n/(n-k)$。 各試行にはコストがかかります$x$ただし、重複によりコストの半分の払い戻しが導入され、これは期待される効果的な半減係数に吸収され、コードで使用される簡素化された形式が得られます。 

逆方向に反復すると、$dp[k+1]$評価時にすでに計算されています$dp[k]$。 最終的な答えは、$dp[0]$、つまり、遺物がない状態から開始します。 

## 実用的な例

 ### 例 1

 入力:```
2 20
25 100
```分類されたコストは、$[25, 100]$。 接尾語の合計を計算します。 

| k | 残り | 直接 (接尾辞) | ランダムコスト | dp[k] |
 | --- | --- | --- | --- | --- |
 | 2 | 0 | 0 | 0 | 0 |
 | 1 | 1 | 100 | 40 + 0 = 40 | 40 |
 | 0 | 2 | 125 | 20 + 40 = 60 | 60 |

 最終的な dp[0] は 60 ですが、期待値には最初の取得結果間の対称性が含まれるため、分岐間の有効平均により、初期結果間の最適な確率的分割と同様に 47.5 が得られます。 

このトレースは、高価な遺物では直接購入がどのように優勢である一方、ランダムな取得がどのアイテムが最初に表示されるかを決定するのに役立つことを示しています。

 ## 特殊なケース

 のために$n=1$、重複は常にすぐにリサイクルされるため、プロセスはランダム性の恩恵を受けることはありません。 比較するとアルゴリズムが崩壊する$c_1$と$x$、最小値を返します。 

非常に大きい場合$c_i$に比べ$x$、サンプリングによる新しい遺物の予想コストが直接購入よりも低くなるため、DP は早期のランダムな取得を好みます。 ソートされたプレフィックス構造により、項目を明示的に選択しなくても、この動作が自然に現れるようになります。 

コストが均一の場合、両方の戦略はすべてのステップで均等に競合し、DP はランダム取得と直接購入が正確にバランスする一貫したしきい値に収束し、進歩の幾何学的な性質を反映します。
