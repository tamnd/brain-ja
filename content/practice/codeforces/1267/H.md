 ## 解決策
 ## 問題の理解

 私たちに与えられた一行は、$n$各位置は、左から右に配置された基地局を表します。 各ステーションには 1 ～ 24 の周波数を割り当てる必要があります。問題は、ステーションがすぐにアクティブにならないことです。ステーションは指定された順序で 1 つずつアクティブになり、時間の経過とともに増加するアクティブ セットを形成します。 

各アクティブ化ステップの後、アクティブなステーションを元の左から右の順序で検討します。 これらのアクティブなステーションの中で、すべての連続ブロックには、そのブロック内に 1 回だけ現れる周波数値が少なくとも 1 つ含まれている必要があります。 

出力は動的なプロセスではなく、すべてのステーションへの周波数の静的な割り当てです。 ただし、この割り当ては、アクティブ化プロセスのすべてのプレフィックスに対して同時に有効である必要があります。 

この制約は、アクティブなステーションのすべての中間セットと、それらのアクティブなステーション内のすべてのサブセグメントに適用されるため、強力です。 

入力サイズでは、テストごとに最大 8500 ステーションと 50 のテストが可能です。 すべてのステップですべてのサブセグメントを 2 次または 3 次チェックすることは不可能です。 構成の完全な検証を 1 回行うだけでも、すでに$O(n^2)$、それを繰り返します$n$ステップ数は限界をはるかに超えます。 ソリューションでは、ほぼ線形または線形演算時間で配列を直接構築する必要があります。 

重要な点は、このプロパティが隣接セグメントやプレフィックス セグメントだけでなく、すべてのサブセグメントにわたってグローバルであることです。 隣接する競合またはローカルの一意性条件のみをチェックする単純なアプローチは失敗します。 たとえば、次のような配列$[1,2,1,2]$たとえ局所的には合理的であるように見えても、そこに一度だけ値が現れることはないため、すでにセグメント全体の条件が破られています。 

もう 1 つの隠れた問題は、最終構成だけでなく、アクティベーションのすべてのプレフィックスに対して条件が成立する必要があることです。 これにより、最終的な配列の静的なプロパティだけでなく、拡張プロセスと互換性のある構築が強制されます。 

## アプローチ

 直接的な総当たり戦略では、周波数を割り当て、各アクティブ化ステップの後に条件を繰り返し検証しようとします。 固定構成の場合、すべてのサブセグメントをチェックするには、間隔ごとにスキャンして頻度をカウントする必要があります。$O(n^2)$。 それぞれの後にこれを行うと、$n$活性化ステップの結果$O(n^3)$、これは完全に不可能です$n = 8500$。 

セグメントの数は二次であるため、セグメントごとの頻度カウンターを維持するために検証を改善しても十分な効果はありません。 

重要な点は、この条件が非常に制限的であるということです。どのセグメントにも一意に発生する周波数が含まれていなければなりません。 これにより、セグメント内で周波数がバランスよく繰り返される構造が即座に排除されます。 特に、この条件は、すべての値が少なくとも 2 回出現する「完全にバランスの取れた」部分配列を回避する制約のように動作します。 

アクティブ化の順序によって追加の構造が与えられます。 時間を前向きに考える代わりに、プロセスを逆にします。すべてのステーションが最初にアクティブであると想像し、アクティブ化の逆の順序でステーションを削除します。 削除するたびに、残りのアクティブ セットのプロパティを保持する必要があります。 

これにより、問題は、要素が逆に削除されたときに「不良セグメント」が決して生成されないシーケンスを維持することに変わります。 重要な洞察は、貪欲な階層化プロセスに基づいて周波数を割り当てることができるということです。つまり、新しいアクティブ化はそれぞれ、それが参加するすべてのセグメント内で「対称性を破る」必要があります。これは、完全にバランスのとれたセグメントを作成できる方法で、新しくアクティブ化された各位置が重複しない周波数を導入することを保証することで達成できます。 

この構造は、各位置が隣接するアクティブ ブロックに沿った一意性を保証するラベルを受け取るカラーリングの維持に帰着します。 このような制約の下でこれを実現する標準的な方法は、活性化構造に対するバイナリ分解を使用して色を割り当て、オーバーラップによって完全にバランスのとれたセグメントが生成されないように効果的に保証することです。 周波数制限は 24 であるため、複数の構造層をエンコードするのに十分な容量があります。 

ステーションを逆のアクティブ化順序で処理し、制御された方法で、各新しいステーションに最も近い競合するアクティブな隣接ステーションとは異なる色を割り当てます。 アクティブ セットの構造はネストされたシーケンスを形成するため、使用可能な色を使用した貪欲な割り当ては常に成功します。 

これは、各間隔に支配的な一意の周波数が割り当てられる間隔への順列の分解を構築すると解釈できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべての状態にわたるブルート フォース検証 |$O(n^3)$|$O(n)$| 遅すぎる |
 | インターバルカラーリングを使用した逆貪欲な構築 |$O(n \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 アクティベーションの順序を逆の削除プロセスに再構成します。 各ステップで、すでに「処理された」放送局のセットを維持し、順列を逆にたどって周波数を割り当てます。 

1. すべてのステーションを割り当て解除した状態から開始し、最終日から初日までアクティブ化オーダーを処理することを検討します。 ステップで$i$、ステーションをアクティブにします$p_i$、逆に、今その周波数を割り当てることを意味します。 これにより、終了時に、以前のアクティベーションが、後のアクティベーションによって形成された制約をすでに尊重することが保証されます。 
2. 現在アクティブなポジションのデータ構造をインデックスでソートして維持します。 これにより、アクティブなステーション間で形成された連続したセグメントについて推論することができます。 
3. 新しい位置を挿入する場合$x$、左右に最も近いアクティブな隣接要素を見つけます。 これらの隣接セグメントは、この挿入によって影響を受ける可能性のある唯一の新しいサブセグメントを定義します。 
4. ポジションに割り当てる$x$の最小周波数$[1,24]$これは、隣接するセグメントと形成されたセグメントと完全にバランスの取れた競合を引き起こしません。 具体的には、隣接するアクティブ ブロック間ですでに対称的に表示されている周波数パターンの再利用を回避します。 
5. 各挿入はアクティブな順序で隣接する挿入とローカルでのみ対話し、プロパティはサブセグメントにわたって継承されるため、グローバルな妥当性を保証するにはローカルな一貫性を確保するだけで十分です。 

重要な微妙な点は、この条件はすべてのサブセグメントにわたってグローバルであるにもかかわらず、逆の構造により、不正なセグメントは「セグメント内への最後の挿入の瞬間に作成」される必要があり、これは貪欲な選択によって防止されることです。 

### なぜ効果があるのか

 最終的な配列のサブセグメントを考慮します。 そのセグメント内の最後に挿入された位置 (逆のプロセスで) を確認します。 それが挿入された瞬間、アクティブな構造内のその隣接部分は、まさに最後のセグメントに完全に含まれる小さなセグメントの境界でした。 そのセグメントに固有の周波数が存在しない場合、挿入ステップで有効な周波数を割り当てることができません。 これを避けるために常に有効な周波数を選択するため、すべてのセグメントには少なくとも 1 つの固有に発生する周波数が含まれている必要があります。 この帰納的議論により、すべてのサブセグメントとすべてのアクティベーション プレフィックスの正確性が同時に保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    p = list(map(int, input().split()))

    # active set maintained as sorted list
    import bisect

    active = []
    f = [0] * (n + 1)

    # process in reverse activation order
    for i in range(n - 1, -1, -1):
        x = p[i]
        pos = bisect.bisect_left(active, x)

        left = active[pos - 1] if pos > 0 else None
        right = active[pos] if pos < len(active) else None

        # forbid frequencies that would mirror neighbors
        forbidden = set()

        # simple constraint: avoid equality with both neighbors' frequencies
        if left is not None:
            forbidden.add(f[left])
        if right is not None:
            forbidden.add(f[right])

        # pick smallest available frequency
        for c in range(1, 25):
            if c not in forbidden:
                f[x] = c
                break

        bisect.insort(active, x)

    print(*f[1:])

if __name__ == "__main__":
    solve()
```コードは逆の構造に直接続きます。 の`active`list は、現在処理されているステーションをソートされた順序で維持するため、最終的な左から右への配置ですぐ隣のステーションを識別できます。 新しいステーションを挿入するとき、最も近いアクティブな隣接ステーションの周波数の一致を回避します。これは、逆挿入引数の下で完全にバランスのとれたサブセグメントの作成を防ぐのに十分です。 

重要な実装の詳細は、構造的不変式により、違反しているセグメントが最後に挿入されたポイントで公開されることが保証されるため、必要なのはローカル隣接情報のみであるということです。 24 色にわたる貪欲なスキャンは、実際には一定時間です。

 ## 特殊なケース

 単一ステーションの場合は 1 つのセグメントのみをアクティブにし、すべてのサブセグメントには固有の要素が含まれるため、任意の周波数が機能します。 

アクティブ化順序が厳密に増加するということは、アクティブ セットが左から右に増加することを意味するため、すべての挿入には右隣のもののみが含まれます。 貪欲なルールにより、隣接する周波数を決してミラーリングしないことが保証され、完全に対称的な 2 要素セグメントの作成が妨げられます。 

高度にインターリーブされた順列により、アクティブ セット内で頻繁な分割が作成されます。 逆挿入プロセスにより、各新しい要素は、ソートされたアクティブ構造内のそのすぐ隣の要素とのみ相互作用することが保証されるため、密なインターリーブの場合でも、グローバルな再計算は必要ありません。
