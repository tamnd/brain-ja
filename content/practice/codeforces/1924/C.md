 ## 解決策
 ## 問題の理解

 正方形のシートで同じ折りを繰り返します。 折り目ごとに現在の正方形を取得し、4 つの角をすべてその中心に向かって折り、辺の長さを で乗算した小さな正方形を生成します。$1/\sqrt2$。 

操作を行った後$N$何度も紙を広げてみると、すべての折り目は山折りか谷折りになります。 させて$M$すべての山折り目の合計の長さとなります。$V$すべての谷折り目の合計の長さ。 比率$M/V$常に次のように書くことができます$$A+B\sqrt2,$$どこ$A$そして$B$合理的です。 必要なのは係数だけです$B$、縮小モジュロ$999999893$。 

幾何学的プロセス自体はすぐに膨大なものになります。 後$N$折り畳む紙の層の数は$2^N$、 その間$N$と同じ大きさにすることができます$10^9$。 折り目、レイヤー、または個々の折り目のシミュレーションは完全に不可能です。 ソリューションは、プロセスの小さな代数的記述のみに依存し、テスト ケースごとに対数時間を使用する必要があります。 

微妙なエッジケースが現れる$N=1$。 最初の折り目以降はすべての折り目が谷になるため、$M=0$そして$M/V=0$。 の係数$\sqrt2$もです$0$、これはサンプル出力と一致します。 

もう 1 つのトラップは、浮動小数点数を操作しようとすることです。 最終的な答えは、次の正確な有理係数によって異なります。$\sqrt2$。 数値近似に基づくアプローチでは、端数を正確に復元するために必要な情報が失われます。 

## アプローチ

 強引なモデルでは、すべての折り目で作成されたすべての折り目を追跡し、それを山または谷に分類しようとします。 展開パターンが一意に決定されるため、これは概念的には正しいです。$M$そして$V$。 残念ながら、折り重ねるごとにレイヤーの数が 2 倍になるため、幾何学的な情報の量は指数関数的に増加します。 平$N=50$問題は許すが、すでに絶望的だろう$N=10^9$。 

重要な点は、折り目パターン自体は必要ないということです。 必要なのは山の全長と谷の長さの合計だけです。 

を考慮してください。$i$- 番目の折り目。 その折り目の前に、$2^{i-1}$層。 1 つのレイヤーに作成された折り目は長さを持ちます$$2\sqrt2\left(\frac1{\sqrt2}\right)^{i-1}.$$レイヤーの数を掛けると、折り時に作成される折り目の合計長さが求められます。$i$:$$T_i = 2^{i-1}\cdot 2\sqrt2\cdot \left(\frac1{\sqrt2}\right)^{i-1} = 2(\sqrt2)^i.$$2 番目の観察は重要です。 2 番目の折り目以降、新しく作成される山の長さと谷の長さは等しくなります。 公式社説はまさにこの紙の両面の対称性をほのめかしている。 

最初の折り目は特別です。 全長の谷折り目のみを作成します$2\sqrt2$。 その後の折り目は、折り目全体の長さの半分が山に、半分が谷に寄与します。 

したがって、$$M=\sum_{i=2}^{N}(\sqrt2)^i,$$そして$$V=2\sqrt2+\sum_{i=2}^{N}(\sqrt2)^i.$$残りのタスクは純粋に代数的なものです。 あらゆる量を次のように表します$$a+b\sqrt2.$$合計$$S=\sum_{i=2}^{N}(\sqrt2)^i$$このような数字です。 係数がわかったら$(a,b)$、の係数$\sqrt2$で$$\frac{S}{S+2\sqrt2}$$共役を使用して正確に抽出できます。 

以来$N$巨大なので計算してみます$(a,b)$行列のべき乗を使用した場合$O(\log N)$。

 ## アルゴリズムのチュートリアル

 1. しましょう$$S=\sum_{i=2}^{N}(\sqrt2)^i.$$代表する$S$として$a+b\sqrt2$。 
2. 乗算を次のように表します。$\sqrt2$ペアで$(a,b)$。$$(a+b\sqrt2)\sqrt2=(2b)+a\sqrt2.$$したがって$$(a,b)\mapsto(2b,a).$$3. 現在の電力と累積合計の両方を含む状態を構築します。$$[a,b,sa,sb].$$ここ$(a,b)$現在のパワーは$\sqrt2$、 そして$(sa,sb)$累計額です。 
4.$4\times4$最初に現在の電力を乗算する遷移行列$\sqrt2$、それを合計に加算します。 
5. を表す状態から開始します。$$(\sqrt2)^1,$$そしてトランジションを適用します$N-1$2進累乗を使用して倍します。 
6. 結果として$(sa,sb)$はまさに係数です$(a,b)$の$S$。 
7. しましょう$$D=S+2\sqrt2=a+(b+2)\sqrt2.$$それから$$\frac{S}{D} = \frac{(a+b\sqrt2)(a-(b+2)\sqrt2)}      {a^2-2(b+2)^2}.$$8. の係数$\sqrt2$この表現では$$B = \frac{-2a}      {a^2-2(b+2)^2}.$$9. この分数を法として評価します$999999893$モジュラーインバースを使用します。 

### なぜ効果があるのか

 幾何学的な部分がアイデンティティに還元される$$M=S,\qquad V=S+2\sqrt2,$$なぜなら、最初の折り目は谷だけをもたらすのに対し、後のすべての折り目は山と谷の長さが等しいからです。 行列遷移は、繰り返される乗算を正確に再現します。$\sqrt2$そして、その結果得られる累乗の累積なので、べき乗後のペアは$(a,b)$の正確な表現です$S$。 次の形式の数値の共役公式$a+b\sqrt2$の正確な係数を与えます$\sqrt2$で$M/V$。 すべてのステップは代数的に正確であるため、最終的なモジュラー値が必要な係数となります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 999999893

def mat_mul(A, B):
    n = len(A)
    m = len(B[0])
    k = len(B)

    C = [[0] * m for _ in range(n)]

    for i in range(n):
        for t in range(k):
            if A[i][t] == 0:
                continue
            v = A[i][t]
            for j in range(m):
                C[i][j] = (C[i][j] + v * B[t][j]) % MOD

    return C

def mat_pow(e):
    T = [
        [0, 2, 0, 0],
        [1, 0, 0, 0],
        [0, 2, 1, 0],
        [1, 0, 0, 1]
    ]

    R = [[1 if i == j else 0 for j in range(4)] for i in range(4)]

    while e:
        if e & 1:
            R = mat_mul(T, R)
        T = mat_mul(T, T)
        e >>= 1

    return R

def solve_case(n):
    if n == 1:
        return 0

    P = mat_pow(n - 1)

    init = [[0], [1], [0], [0]]
    res = mat_mul(P, init)

    a = res[2][0]
    b = res[3][0]

    den = (a * a - 2 * (b + 2) * (b + 2)) % MOD
    num = (-2 * a) % MOD

    return num * pow(den, MOD - 2, MOD) % MOD

t = int(input())
ans = []

for _ in range(t):
    n = int(input())
    ans.append(str(solve_case(n)))

print("\n".join(ans))
```状態ベクトルには、現在の累乗と次の両方が格納されます。$\sqrt2$そして累計額。 遷移行列はマップを実装します。$(a,b)\mapsto(2b,a)$、これはまさに乗算です$\sqrt2$。 

行列のべき乗$N-1$、から始めるので、$(\sqrt2)^1$までのすべての電力を生成する必要があります$(\sqrt2)^N$。 

すべての算術は、必要な素数を法として実行されます。 最終係数は整数係数の有理式なので$a$そして$b$、素数を法とする有限体でその式を評価すると、必要な値が正確に得られます。

import sys, io

MOD = 999999893

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    def mat_mul(A, B):
        n = len(A)
        m = len(B[0])
        k = len(B)
        C = [[0] * m for _ in range(n)

        ]
        for i in range(n):
            for t in range(k):
                if A[i][t] == 0:
                    continue
                for j in range(m):
                    C[i][j] = (C[i][j] + A[i][t] * B[t][j]) % MOD
        return C

    def mat_pow(e):
        T = [
            [0, 2, 0, 0],
            [1, 0, 0, 0],
            [0, 2, 1, 0],
            [1, 0, 0, 1]
        ]
        R = [[1 if i == j else 0 for j in range(4)] for i in range(4)]

        while e:
            if e & 1:
                R = mat_mul(T, R)
            T = mat_mul(T, T)
            e >>= 1

        return R

    def solve(n):
        if n == 1:
            return 0

        P = mat_pow(n - 1)
        res = mat_mul(P, [[0], [1], [0], [0]])

        a = res[2][0]
        b = res[3][0]

        den = (a * a - 2 * (b + 2) * (b + 2)) % MOD
        num = (-2 * a) % MOD

        return num * pow(den, MOD - 2, MOD) % MOD

    t = int(input())
    out = [str(solve(int(input()))) for _ in range(t)]
    return "\n".join(out) + "\n"
