 ## 解決策
 ## 問題の理解

 2 人には、日数の数直線上に「良い間隔」の周期的なパターンがあります。 各パターンは、繰り返しサイクル内の連続する日の固定セグメントで構成されます。 アリスの場合、すべてのブロックの長さ内で`t_a`からの日々`l_a`に`r_a`(包括的) は良好であり、同じブロック内のそのセグメント以外のすべては不良です。 同じ構造がパラメータ付きの Bob にも適用されます`l_b`、`r_b`、`t_b`。 

どちらのパターンも、良好なセグメントを周期の倍数だけシフトすることで無限に繰り返されます。 シフトされたセグメントのいずれかに該当する日は、人にとって良い日です。 

このタスクは、そのブロック内の毎日がアリスとボブの両方にとって同時に良いものとなるように、連続する日数のブロックの最大長を決定することです。 

主な問題点は、両方のパターンが周期的であるものの、周期が異なることです。そのため、交差構造は周期が明らかに短く周期的ではなく、周期値が 10^9 に達する可能性があるため、広範囲の日にわたる強引な位置合わせは不可能です。 

2 つの大きな整数の最小公倍数が 10^18 を超える可能性があり、構造が依然として列挙するには大きすぎるため、完全な最小公倍数期間にわたってパターンを明示的に構築またはシミュレートしようとする素朴なアプローチは、直ちに実行不可能です。 

残基のアライメントによって、ある区間が別の区間に完全に含まれる場合、微妙なエッジ ケースが発生します。 たとえば、アリスがいつも元気なら`[0, 4] mod 10`そしてボブは上手です`[2, 3] mod 10`、答えは 2 ですが、直感を誤って変更すると、期間の境界を越えてラップまたはマージする可能性がありますが、各期間が独立してリセットされるため、これは無効です。 

もう 1 つの注意が必要な状況は、最適なオーバーラップが一方の期間の境界を越えるが、もう一方の期間の境界を越えない場合に発生します。 たとえば、ボブは、あるサイクルの終わりと次のサイクルの開始時は良好である一方、アリスは継続的に良好である可能性があります。 交差部分は 2 つのモジュール ブロックにまたがっていても、絶対時間では依然として 1 つの連続したセグメントです。 

## アプローチ

 ブルートフォースの観点では、すべての開始日をチェックし、アリスとボブの両方が同時に適切な間隔にいる間に前方に拡張することです。 毎日のために`x`では、アリスの周期間隔とボブの周期間隔のメンバーシップを O(1) でテストし、条件が壊れるまで拡張します。 最悪の場合、答え自体が大きくなる可能性がありますが、より重要なのは、開始位置ごとに作業を繰り返すことになり、暗黙的な膨大な範囲の日数にわたって O(N^2) の動作が発生することになります。 

これは、構造が周期的に繰り返され、オーバーラップを最初から再計算すると、2 つのサイクル間の相対位相のみが重要であるという事実が無視されるため、失敗します。 重要な観察は、両方のパターンがシフトされた間隔の結合であり、それらの相互作用がそれぞれの周期を法とした位置にのみ依存するということです。 

時間をかけてスキャンする代わりに、2 つの周期的なパターンの相対的な位置関係を調べます。 アリスの周期の 1 日を決めて、それに対してボブの良好な間隔がどこに位置するかを判断します。 2 つの周期セグメント システム間のオーバーラップ パターンが周期的に繰り返されます。`t_a`なぜなら、アリスの構造はすでにその周期で周期的だからです。 したがって、アリスの 1 つのサイクルに注目を限定し、その内部の各点について、交差点が前方にどれくらい続くかを計算できます。 

アリスのサイクル内では、ボブの好調な日々が複数のシフトされたセグメントとして表示されます。 ボブの間隔をアリスの座標系にマッピングし、線形化されたセグメント内の間隔間の重複をチェックします。`[0, t_a - 1]`、ボブのセグメントのラップアラウンドの処理に注意します。 両方のセットが同等のモジュラー空間で表現されると、問題は円上の間隔間の最長の重複を見つけることになります。これはサイクルを複製することで線形化できます。 

次に、重なっているセグメントの端点をスイープし、連続する交差部分の最大長を計算します。

 ## アルゴリズムのチュートリアル

 アリスの構造はすでに長さのクリーンな周期分割であるため、アリスのサイクルに関連してすべてを正規化します。`t_a`。 

1. アリスの良好なセグメントを 1 サイクル内の単一の間隔に変換します。`[l_a, r_a]`。 これは、アリスが優れている 1 つの代表的な期間内のすべてのポイントを表します。 
2. ボブの良いセグメントをアリスのサイクルに合わせた形に拡張します。 各ボブ間隔`[l_b + k t_b, r_b + k t_b]`剰余モジュロに射影されます`t_a`。 無限に多くのシフトを列挙する代わりに、ボブモジュロのパターンのみが必要です。`t_a`、ボブの基本間隔を取得し、長さのスライディング ウィンドウとの重複を考慮することで生成できます。`t_a`。 
3. 内部で候補区間のセットを構築します。`[0, t_a)`アリスもボブも良いところです。 これは、アリスの単一の間隔を、1 サイクルで交差する可能性のあるすべてのシフトされたボブの間隔と交差させることによって行われます。 
4. ボブの間隔はサイクル境界を囲む可能性があるため、交差する間隔を分割します。`t_a - 1`2 つの直線セグメントに分割します。 これにより、問題は標準的な線間隔の交差問題に変換されます。 
5. すべての交差点間隔を開始点でソートし、それらをマージします。 マージ中に、マージされた単一セグメントの最大長を追跡します。 

答えは、マージされた間隔の最大長です。 

### なぜ効果があるのか

 アリスの楽しい日々は、同じセグメントが毎回繰り返されることで、整数線の完璧なタイルを形成します。`t_a`。 したがって、アリスの構造を通して見ると、グローバル交差パターンは同じ周期で繰り返される必要があります。 分析をアリスの 1 つの完全なサイクルに制限することで、相対的な重複の構成が失われることはありません。 

そのサイクル内で、ボブの貢献は、彼の周期的なセグメントが残差空間にどのように投影されるかによって完全に捉えられます。 考えられるすべての同時良好ストレッチは、この縮小されたドメイン内の交差セグメントに正確に対応します。 完全な投影の後にのみ間隔をマージするため、連続性が維持され、サイクル境界を越えて互いに素なオ​​ーバーラップが誤って接続されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_intervals(l, r, t, limit):
    res = []
    # generate occurrences that can intersect [0, limit)
    k = 0
    while l + k * t < limit:
        start = l + k * t
        end = r + k * t
        if start < limit and end >= 0:
            res.append((start, min(end, limit - 1)))
        k += 1
        if k > limit // max(1, t) + 5:
            break
    return res

def intersect(a1, a2, b1, b2):
    l = max(a1, b1)
    r = min(a2, b2)
    if l <= r:
        return (l, r)
    return None

def solve():
    l_a, r_a, t_a = map(int, input().split())
    l_b, r_b, t_b = map(int, input().split())

    # we work inside one cycle of Alice
    limit = t_a

    alice = [(l_a, r_a)]

    bob_intervals = build_intervals(l_b, r_b, t_b, limit + t_b)

    candidates = []
    for a1, a2 in alice:
        for b1, b2 in bob_intervals:
            inter = intersect(a1, a2, b1, b2)
            if inter:
                candidates.append(inter)

    if not candidates:
        print(0)
        return

    candidates.sort()
    merged = []
    cur_l, cur_r = candidates[0]

    best = 0
    for l, r in candidates[1:]:
        if l <= cur_r + 1:
            cur_r = max(cur_r, r)
        else:
            best = max(best, cur_r - cur_l + 1)
            cur_l, cur_r = l, r

    best = max(best, cur_r - cur_l + 1)
    print(best)

if __name__ == "__main__":
    solve()
```コードはまず問題を、次のサイズの境界付きウィンドウ内の交差に落とし込みます。`t_a`アリスのパターンは毎回正確に繰り返されるため、これで十分です。`t_a`。 次に、無限等差数列構造について抽象的に推論しようとするのではなく、このウィンドウと重なる可能性がある関連するボブ セグメントを生成します。 

各重複候補は直接区間交差によって計算されます。 次に、これらをマージして、両方が同時に良好な最大の連続セグメントを形成します。 最終的な答えは、そのような結合されたセグメントの中で最も長いものです。 

微妙な点は、ボブの間隔がウィンドウまで切り詰められていることです。`[0, t_a + t_b)`。 これにより、無限の列挙を回避しながら、アリスの最初のサイクルにラップできるすべてのシフトを確実にキャプチャできます。

 ## 特殊なケース

 エッジケースの 1 つは、ボブの周期が終わり近くに始まり、次の周期に切り替わる場合です。 たとえば、ボブ`[4, 1] mod 6`効果的に分割されます`[4,5]`そして`[0,1]`。 このアルゴリズムは、アリスのサイクルに投影されたときに両方の部分を自然にカバーするシフトされた間隔を生成することでこれを処理し、交差部分が見逃されないようにします。 

もう 1 つのエッジ ケースは、アリスの間隔がサイクル全体をカバーする場合です。`l_a = 0, r_a = t_a - 1`。 この場合、答えはボブのパターンの中で最も長く連続するブロックになります。 アリスがドメインを制限しなくなり、すべてのボブのオーバーラップが保存され、正しくマージされるため、交差ロジックは引き続き機能します。 

最後のエッジ ケースは、両方の期間が大きいがほぼ等しい場合に発生し、オーバーラップがサイクル間でゆっくりとドリフトする原因となります。 計算を単一のアリス サイクルに制限することで、ライン全体をシミュレートすることなく、遅いドリフト パターンでも完全に捕捉できるようになります。
