 ## 解決策
 ## 問題の理解

 2 つの配列が与えられています。`a`そして`b`。 それらから暗黙的な行列を構築します$$M_{i,j}=a_i b_j.$$マトリックスの美しさは、そのすべてのエントリの合計です。 

各クエリ値について`x`、行が存在するかどうかを判断する必要があります。`r`そしてコラム`c`行内のすべてのセルを設定した後、`r`列内のすべてのセル`c`ゼロにすると、その結果得られる美しさは正確になります`x`。 

操作は仮説です。 すべてのクエリは元の行列から始まります。 

最初の観察は、行列自体が構築するには大きすぎるということです。 どちらの次元にも到達できる`2·10^5`、したがって、行列には​​最大で次のものを含めることができます。`4·10^10`細胞。 マトリックスのエントリを個別に扱うような解決策は不可能です。 

クエリ数は`5·10^4`これは、大幅な前処理は許可されていますが、各クエリは、`O(nm)`。 

配列内の値は、その長さによって制限されます。 以来$$|a_i|\le n,\qquad |b_j|\le m,$$すべての行の合計と列の合計が管理可能な範囲内に収まります。 これが問題を解決可能にする重要な特性であることがわかります。 

いくつかの特殊なケースは見落とされがちです。 

考慮する```
n=1, m=1
a=[5]
b=[7]
```マトリックスには次のものだけが含まれます。`35`。 唯一の行と唯一の列を選択すると、そのセルは 2 回ではなく 1 回削除されます。 その結果得られる美しさは、`0`。 

不注意な包含除外式により、交差部分が 2 回減算される可能性があります。 

もう 1 つの重要なケースにはゼロが関係します。```
a=[0,1]
b=[2,3]
```マトリックスの全体的な美しさは、すでに 2 行目によって完全に決定されています。 一部の行削除値は同一になり、合計の一意性に依存する解決策は失敗します。 

負の値も同様に重要です。```
a=[-2,3]
b=[-1,2]
```どの行と列が削除されるかによって、ターゲットの美しさはプラスにもマイナスにもなります。 正の約数のみに注目すると、有効な回答を見逃してしまいます。 

## アプローチ

 直接総当りのソリューションにより、考えられるすべてのペアの結果として得られる美しさを計算します。`(r,c)`。 

がある`nm`選択肢。 ペアごとに美しさを再計算できます。`O(1)`事前に計算された行と列の合計を使用して、クエリと比較します。 

これにはすでに最大までの保存または生成が必要です$$2\cdot10^5 \times 2\cdot10^5 = 4\cdot10^{10}$$ペア、これは完全に不可能です。 

問題に隠された構造を見つけるには、次のようにします。$$A=\sum a_i,\qquad B=\sum b_j.$$本来の美しさは、$$S=A\cdot B.$$行を削除すると`r`、私たちは排除します$$a_r B.$$列を削除すると`c`、私たちは排除します$$b_c A.$$細胞`(r,c)`は両方の除去に属しているため、2 回減算され、1 回追加し直す必要があります。 

その結果得られる美しさは、$$S-a_rB-b_cA+a_rb_c.$$ここで次のことを考慮します。$$S-a_rB-b_cA+a_rb_c =(A-a_r)(B-b_c).$$このアイデンティティによって問題は完全に変わります。 

すべての行に対して定義します$$u=A-a_r.$$すべての列に対して定義します$$v=B-b_c.$$手術後の美しさはただそれだけです$$u\cdot v.$$クエリは次のようになります。 

存在しますか$$u\in U,\quad v\in V$$そのような$$u v = x ?$$どこ$$U=\{A-a_i\},\qquad V=\{B-b_j\}.$$ここで、行列の問題を因数分解の問題に縮小しました。 

重要な観察は、次のすべての値が`U`そして`V`狭い範囲にあります。 

以来$$|a_i|\le n,\qquad |A|\le n^2,$$毎`u`満足する$$|u|\le n^2+n.$$と`n≤2·10^5`、これはおおよそです`4·10^10`、大きく見えます。 ただし、クエリ値は次の条件を満たします。$$|x|\le 2\cdot10^5.$$クエリの約数のみが重要です。 任意の整数の約数の数。`200000`数百未満の小さいものです。 

お問い合わせの場合`x`、すべての約数を列挙します`d`の`|x|`。 

各約数のペアについて$$d,\ \frac{x}{d},$$1 つの要素が属するかどうかを確認する`U`そしてもう一方は`V`、兆候を考慮に入れます。 

これにより、すべてのクエリが除数検索に変わります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(qnm) | お(1) | 遅すぎる |
 | 最適 | O(n + m + q√X) | O(n + m) | 承認済み |

 ここ`X = 200000`。 

## アルゴリズムのチュートリアル

 1. 配列の読み取り`a`そして`b`。 
2. コンピューティング$$A=\sum a_i,\qquad B=\sum b_j.$$1. セットを構築する$$U=\{A-a_i\}.$$ハッシュ セットを使用すると、一定時間のメンバーシップ チェックが可能になります。 

1. セットを構築する$$V=\{B-b_j\}.$$1. 各クエリ値について`x`、の正の約数をすべて列挙します。`|x|`。 
2. すべての約数について`d`、 させて$$e=\frac{|x|}{d}.$$1. 積が次と等しいすべての符号の組み合わせを生成します。`x`。 

もし`x>0`、有効な因子ペアは次のとおりです。$$(d,e),\quad (-d,-e).$$もし`x<0`、有効な因子ペアは次のとおりです。$$(d,-e),\quad (-d,e).$$1. 各候補因子ペアについて`(p,q)`、どうかを確認してください$$p\in U$$そして$$q\in V.$$true の場合は、すぐに「YES」と答えてください。 

1. どの除数ペアも機能しない場合は、「いいえ」と答えます。 

### なぜ効果があるのか

 行を削除した後`r`そしてコラム`c`、結果として得られる美しさは次のとおりです$$(A-a_r)(B-b_c).$$達成可能なすべての美しさは、次の 1 つの価値の産物でなければなりません。`U`と 1 つの値`V`。 

逆に言うと、どのペアも$$u=A-a_r,\qquad v=B-b_c$$実際の行と列の選択に対応します。 

したがって、クエリは正確に次の場合に達成可能です。`x`次のように書くことができます$$x=u v$$と`u∈U`そして`v∈V`。 

このアルゴリズムは、考えられるすべての因数分解を正確にチェックします。`x`したがって、そのようなペアが存在する場合は YES を返します。 

## Python ソリューション```python
import sys
from math import isqrt

input = sys.stdin.readline

def solve():
    n, m, q = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    A = sum(a)
    B = sum(b)

    U = set(A - x for x in a)
    V = set(B - x for x in b)

    ans = []

    for _ in range(q):
        x = int(input())

        ok = False
        ax = abs(x)

        for d in range(1, isqrt(ax) + 1):
            if ax % d:
                continue

            e = ax // d

            if x > 0:
                candidates = (
                    (d, e),
                    (-d, -e),
                )
            else:
                candidates = (
                    (d, -e),
                    (-d, e),
                )

            for p, qv in candidates:
                if p in U and qv in V:
                    ok = True
                    break
                if e != d:
                    if qv in U and p in V:
                        ok = True
                        break

            if ok:
                break

        ans.append("YES" if ok else "NO")

    sys.stdout.write("\n".join(ans))

solve()
```前処理フェーズでは、合計を計算し、変換されたセットを構築します。`U`そして`V`。 

重要な実装の詳細は、行列を構築しないことです。 すべてのクエリは、除数の列挙とハッシュ検索を通じて完全に回答されます。 

除数のペアをチェックするときは、両方の次数を考慮する必要があります。`U`どちらかに該当する可能性があります`d`またはへ`e`。 

ネガティブターゲットには別の符号処理が必要です。 A common bug is checking only positive divisors and forgetting that both transformed sets may contain negative values.

 ## 特殊なケース

 を考えてみましょう`1 × 1`マトリックス：```
a=[5]
b=[7]
```単一のセルを削除する唯一の操作です。 その結果得られる美しさは、`0`。 式は次のようになります$$(A-a_1)(B-b_1)=0\cdot0=0,$$正確に一致します。 

ゼロを含む配列を考えてみましょう。```
a=[0,1]
b=[2,3]
```それから$$U=\{1,0\}.$$の目標`0`1 つの要素がゼロになる可能性があるため、これは達成可能です。 変換されたセットにはゼロが直接現れるため、因数分解のアプローチではこれを自然に処理できます。 

ネガティブなターゲットを検討してください。```
a=[-2,3]
b=[-1,2]
```変換されたセットには、正の値と負の値の両方が含まれます。 のようなターゲット`-3`反対の符号を持つ因子が必要です。 アルゴリズムはすべての符号の組み合わせを明示的にチェックするため、有効な解決策が見逃されることはありません。
