 ## 解決策
 ## 問題の理解

 各スパイダーは受信者を 1 人だけ選択します。 これは、すべての頂点の出次数が 1 つだけである有向グラフとして見ることができます。 最初は、すべてのクモが 1 つのぬいぐるみを所有しています。 

1 年の間に、現在ぬいぐるみを持っているすべてのクモは、その外縁に沿って 1 つのぬいぐるみを送ります。 すべての転送は同時に行われます。 ぬいぐるみを受け取った後、クモは最大でも 1 つしか飼うことができません。 複数のぬいぐるみが到着した場合、1 つが生き残り、残りは破棄されます。 

クモはぬいぐるみを持っているか持たないかのどちらかであるため、システムの状態は単なるバイナリ配列になります。 現在ぬいぐるみを所有している場合、頂点をアクティブにします。 1 年後、少なくとも 1 つのアクティブな先行者が頂点を指していれば、その頂点はアクティブになります。 

タスクは、状態が前年の状態と同一である最初の年を見つけることです。 

グラフの構造は非常に特殊です。 すべての頂点には出力エッジが 1 つだけあるため、接続されたすべてのコンポーネントは有向サイクルで構成され、有向ツリーがそのサイクルに供給されます。 この観察が問題全体の鍵となります。 

すべてのテスト ケースにわたる頂点の合計数は最大で$2 \cdot 10^5$。 何年も繰り返しシミュレーションするアルゴリズムは簡単に二次関数になる可能性があります。 解決策$O(n)$テストケースごとに必要です。 DFS、サイクル検出、距離計算などのグラフ走査は、十分に高速です。 

いくつかの特殊なケースは誤解されやすいものです。 

純粋なサイクルを考えてみましょう。```
1 -> 2 -> 3 -> 1
```すべての頂点には常に 1 つのぬいぐるみがあります。 状態は決して変わりません。 定義上、1 年目は安定しないため、答えは 2 になります。

3
2 3 1
```出力：```
2
```1 年目にすぐに安定性のチェックを開始するシミュレーションでは、誤って 1 が出力されます。 

ここで、サイクルに供給するチェーンを考えてみましょう。```
3 -> 2 -> 1 <-> 4
```最初はすべての頂点がアクティブになっています。 十分な年月が経過すると、サイクル頂点のみがアクティブのままになります。 安定化にかかる時間は、最も深い木の頂点がサイクルからどれだけ離れているかによって異なります。 

入力：```
1
4
4 1 2 1
```答えは周期の長さではありません。 これは、木の頂点からサイクルまでの最大距離によって決まります。 

もう 1 つのよくある間違いは、すべてのアクティブな頂点が永久に存続すると仮定することです。 入ってくるエッジのない葉は、一歩進むと消えてしまい、戻ることはできません。 

例えば：```
1
3

```状態は次のように進化します。```
111

```答えは 3 です。 

サイクルを分析するだけでツリーを無視するソリューションでは、この動作が見逃されます。 

## アプローチ

 最も直接的なアプローチはシミュレーションです。 

現在のアクティブ セットをバイナリ配列として表します。 毎年、アクティブな頂点ごとに 1 つのぬいぐるみを受信者に送信します。 少なくとも 1 つのぬいぐるみを受け取った場合、頂点を来年アクティブとしてマークします。 連続する状態を比較し、等しくなったら停止します。 

これはプロセス定義に正確に従っているため、これは正しいです。 

問題は、安定化には何年もかかる可能性があることです。 簡単なバージョンはすぐに安定するのでシミュレーションが魅力的に見えるかもしれませんが、グラフには長いチェーンが含まれる可能性があります。 最悪の場合は実施させていただく場合がございます$O(n)$それぞれの移行に必要な$O(n)$仕事、につながる$O(n^2)$操作。 

より良い成果を出すためには、プロセスが実際に何を行っているのかを理解する必要があります。 

させて$S_t$年のアクティブな頂点のセットになります$t$。 頂点が属する$S_{t+1}$少なくとも 1 つの先行者が属している場合$S_t$。 

最初はすべての頂点がアクティブになっています。 

頂点は存続します$k$長さの有向経路が存在する正確な年$k$その頂点で終わります。 関数グラフでは、十分に長いパスはすべて最終的にサイクルに達します。 サイクル上の頂点は常に存続します。 アクティビティがサイクルに向かって後退すると、それをさらに遠くに再生する方法がないため、ツリーの頂点は最終的に消滅します。 

すべてのツリー頂点が消滅した後、サイクル頂点のみがアクティブのままになります。 その時点から、状態は決して変わりません。 

これは、安定化の年が、サイクルに接続されている最も深いツリーによってのみ決定されることを意味します。 

頂点が遠くにあると仮定します$d$そのサイクルから、そのサイクルに到達するまで出力エッジをたどることによって測定されます。 このような頂点は年間を通じて存続します$d+1$そしてその後消える。 最後の変化は、最大距離の頂点が消えるときに発生します。 

最大距離が$D$、 それから：```
year 1 : initial state
year D+1 : deepest vertices still present
year D+2 : they disappear
year D+3 : state repeats
```答えは次のようになります。$$D + 2$$サイクルのみで構成されるグラフの場合、$D = 0$、答えを与える$2$、必要に応じて正確に。 

したがって、問題は、任意の頂点からそのコンポーネント内のサイクルまでの最大距離を見つけることに帰着します。

 ## アルゴリズムのチュートリアル

 1. 受信者の配列から関数グラフを構築します。 
2. すべての頂点の次数を計算します。 
3. 度数 0 の頂点に対してカーンのアルゴリズムを使用します。 

削除された頂点はすべて、すべてのサイクルの外側にあります。 度数 0 の頂点を繰り返し削除すると、サイクル頂点が正確に残ります。 
4. 残りのすべての頂点をサイクル頂点としてマークします。 

関数グラフでは、カーンのプロセスはすべてのツリー頂点を削除し、すべてのサイクル頂点を残します。 
5. すべてのサイクル頂点の距離をゼロに初期化します。 
6. 削除された頂点を逆カーン順序でトラバースします。 

頂点が距離がすでにわかっている後続頂点を指している場合、次のように設定します。$$dist[v] = dist[next[v]] + 1$$これにより、頂点からそのサイクルまでのエッジの数が計算されます。 
7. 最大距離を求める$D$すべての頂点の間で。 
8. 出力$D + 2$。 

グラフにサイクルのみが含まれている場合は、$D=0$、答え2を与えます。 

### なぜ効果があるのか

 カーンのアルゴリズムは、有向サイクルに属さない頂点を正確に削除します。 削除されたすべての頂点は最終的にサイクルに達し、逆の順序で削除を処理することで、頂点の後続距離がすでに計算されていることを保証します。 

計算された値$dist[v]$は、正確には、出力エッジをたどってサイクルに到達するために必要なステップ数です。 

離れたところにある頂点$d$年間を通して活動を続ける$d+1$、長さのパスが存在するため$d$その頂点からサイクルへ。 一年後$d+1$、アクティビティが到達できなくなります。 最終的な状態変化は、最大距離の頂点が消えるときに発生します。 もし$D$は最大距離であり、失踪は数年の間に起こります$D+1$そして$D+2$したがって、最初に繰り返される状態は年です。$D+2$。 

すべての頂点はサイクルに属しているか、サイクルへの一意のパスを持っているため、最大距離によって安定化時間が完全に決まります。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        r = [x - 1 for x in map(int, input().split())]

        indeg = [0] * n
        for v in r:
            indeg[v] += 1

        q = deque()
        for i in range(n):
            if indeg[i] == 0:
                q.append(i)

        order = []

        while q:
            v = q.popleft()
            order.append(v)

            to = r[v]
            indeg[to] -= 1
            if indeg[to] == 0:
                q.append(to)

        dist = [0] * n

        for v in reversed(order):
            dist[v] = dist[r[v]] + 1

        max_dist = max(dist)
        ans.append(str(max_dist + 2))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```入次数の計算により、カーンのアルゴリズムが準備されます。 カーンによって削除されたすべての頂点は、あるサイクルにつながるツリーに属します。 

配列`order`削除シーケンスを保存します。 逆に処理することは、実装の重要な詳細です。 頂点が逆方向に処理されると、後続頂点はすでにサイクルに近づいているため、その距離がわかります。 

サイクル頂点は決して表示されません`order`、したがって、それらの距離は当然ゼロのままです。 これにより、個々のサイクルに対する特別な処理が回避されます。 

最終的な答えは、`max_dist + 2`。 追加の 2 年は、問題の年の番号付けから得られます。 距離ゼロは、最初の交換後にすでに安定しているグラフに対応し、その答えは 0 または 1 ではなく 2 です。

 ## 特殊なケース

 可能な限り最小のグラフを考えてみましょう。```
1
2
2 1
```両方の頂点がサイクルを形成します。 カーンのアルゴリズムでは何も削除されないため、すべての距離はゼロのままになります。 最大距離はゼロであり、答えが生成されます$0+2=2$。 最初の交換後、状態は変化せず、2 年目は最初の安定した年になります。 

長いチェーンを考えてみましょう。```
1
5
2 1 2 3 4
```グラフにはサイクルが含まれています$1 \leftrightarrow 2$そしてチェーン$5 \to 4 \to 3 \to 2$。 

カーンは次の順序で頂点を削除します。```
5, 4, 3
```逆方向に処理すると次のようになります。```
dist[3] = 1
dist[4] = 2
dist[5] = 3
```最大距離は 3 なので、答えは 5 です。最も深い頂点がまさに安定化を制御します。 

最後に、複数のコンポーネントについて考えてみましょう。```
1
6
2 1 4 3 4 5
```次の 2 つのサイクルがあります。```
1 <-> 2
3 <-> 4
```そしてチェーン:```
6 -> 5 -> 4
```距離は次のとおりです。```
1,2,3,4 : 0
5 : 1

```最大距離は 2 なので、答えは 4 です。カーンのアルゴリズムと逆距離の計算は関数グラフ全体にわたってグローバルであるため、アルゴリズムは当然すべてのコンポーネントを同時に処理します。
