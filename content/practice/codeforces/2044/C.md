 ## 解決策
 ## 問題の理解

 私たちは、ちょうど 2 列の教室でサルを席に割り当てるように求められます。`m`それぞれの座席。 サルは 3 つのカテゴリに分類されます。`a`最前列にしか座らないサル、`b`2列目にしか座らないサル、そして`c`好みのない猿。 各座席に座れる猿は1匹だけです。 目標は、座っているサルの総数を最大化することです。 

入力により得られるのは、`t`テストケース。 各テスト ケースでは、列ごとの座席数を指定します。`m`そしてカウント`a`、`b`、`c`。 各テスト ケースの出力は単一の整数、つまり座ることができるサルの最大数です。 

制約を考慮すると、それぞれ`m`、`a`、`b`、 そして`c`と同じ大きさにすることができます$10^8$、最大まであります$10^4$テストケース。 これにより、すべての座席またはすべてのサルを個別に反復するソリューションは即座に除外されます。 テストケースごとに直接算術計算が必要です。 

明らかではないエッジケースとしては、列ごとのサルの数が座席数を超えている場合、または列ごとのサルの合計数が座席の総数より少ない場合があり、柔軟な座席の余地が残されています。`c`猿。 たとえば、次の場合`m = 3`、`a = 6`、`b = 1`、`c = 1`、最初の行には 3 つしか取れません。`a`猿、残りを残す`a`座っていないサル。 2列目は3席ですが1席のみ`b`猿と1`c`不用意なアプローチでは、サルの好みに反して列間でサルを「移動」させようとし、不正確な合計が得られる可能性があります。 

## アプローチ

 ブルートフォース手法では、列の優先順位と座席の空き状況を確認しながら、各サルを 1 匹ずつ座らせようとします。 これは原理的には正しいですが、サルの総数が次の値に達する可能性があるため、遅すぎます。$3 \cdot 10^8$そして、各猿を反復処理すると、非常に時間がかかります。 

重要な洞察は、これが純粋に算術問題であるということです。 各行には最大で次の値を保持できます`m`サルなので、列 1 に座っているサルの数は最小です。`a + c`そして`m`、行 2 では次の最小値になります。`b + remaining_c`そして`m`。 ただし、より単純で同等の計算は、各列にできるだけ多くの座席を個別に配置することです。列 1 には最大 2 人まで座席を配置できます。`m`サル、優先順位付け`a`まず、次に残り物`c`。 同じことが行 2 にも当てはまります。`c`サルは柔軟です。最大合計は`min(a + c, m) + min(b + c, m)`ただし、二重にカウントしないように注意する必要があります。`c`。 正しい公式は座ることです`a`まで`m`、`b`まで`m`、各行の残りの容量を使用します。`c`猿。 これにより、ソリューションはテスト ケースごとの単純な定数時間の計算に削減されます。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースの値を読み取ります。`m`、`a`、`b`、`c`。 
3. 配置後の最初の列で利用可能な座席の数を計算します。`a`猿:`space1 = max(0, m - a)`。 これは柔軟なサルに対応できる座席を表しています。 
4. 座席を配置した後、2 列目に利用可能な座席の数を計算します。`b`猿:`space2 = max(0, m - b)`。 
5. の数`c`座ることができるサルは、残りのスペースの合計によって制限されます。`c_used = min(c, space1 + space2)`。 
6. 座っている猿の総数は`min(a, m) + min(b, m) + c_used`。 これにより、列の容量を超えることがなくなり、すべてのサルの好みが尊重されます。 
7. 各テスト ケースの合計を出力します。 

機能する理由: 行固有の制約を尊重しながら、常に各行を最大容量まで埋めています。 フレキシブルなサルは、列固有のサルが着席した後、残りの席のみを埋めます。 これにより、設定に違反することなく、座っているサルの数を最大化することが保証されます。 すべての演算は算術演算であるため、最大の入力に対しても解は十分に高速です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    m, a, b, c = map(int, input().split())
    row1 = min(a, m)
    row2 = min(b, m)
    remaining_c = min(c, (m - row1) + (m - row2))
    print(row1 + row2 + remaining_c)
```コードは最初にテスト ケースの数を読み取ります。 各テストケースについて、列固有のサルを列の収容人数に制限することで、各列に座ることができるサルの数を計算します。 次に、柔軟なサルの数を計算します (`c`) は残りの座席に収まり、これらの数値を合計できます。 使用する`min`決してキャパシティを超えないようにします。 使用する`max(0, ...)`ここでは不要です。`min(c, ...)`残りのスペースがゼロの場合も当然処理されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        m, a, b, c = map(int, input().split())
        row1 = min(a, m)
        row2 = min(b, m)
        remaining_c = min(c, (m - row1) + (m - row2))
        output.append(str(row1 + row2 + remaining_c))
    return "\n".join(output)

## 特殊なケース

 もし`a`を超える`m`そして`b`が小さい場合、残りの柔軟なサルが 2 列目を埋めます。 のために`m = 3, a = 6, b = 1, c = 1`、row1 には 3 匹のサルが座っており、row2 には 1 匹のサルが座っており、row2 の残りの席には 1 匹のフレキシブル モンキーが座っています。 合計は`3 + 1 + 1 = 5`。 アルゴリズムは `row1 = min(6) を正しく計算します。
