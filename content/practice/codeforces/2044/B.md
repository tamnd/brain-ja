 ## 解決策
 ## 問題の理解

 文字のみからなる文字列が与えられます`p`、`q`、 そして`w`。 船はガラス窓の外からこの文字列を観察し、私たちに文字列を与えます`a`。 シップが店内に移動して同じ窓から覗くと、紐が見えます。`b`。 私たちの仕事は、何を決定するかです。`b`与えられたように見える`a`。 

重要な観察は、ウィンドウが特定の文字を効果的に反映していることです。 サンプルからわかることは、`p`そして`q`見る方向に応じて役割を交換します。`w`は変わらないままです。 例えば、`qwq`外で観察されると`pwp`内部。 したがって、次のような固定マッピングがあります。`p <-> q`、 そして`w -> w`。 

制約は小さく、各文字列の長さは最大 100 で、テスト ケースの数は最大 100 です。 これは、処理される文字の合計数が最大 10,000 文字であることを意味します。 文字列ごとの単純な線形スキャンは許容されます。 

明白でないエッジケースには、次のような文字列が含まれます。`w`またはすべての文字が同一である文字列。 例えば、`wwww`残るべきだ`wwww`なぜなら`w`それ自体にマップされます。 もう 1 つの特殊なケースは、次のような文字を交互に配置することです。`pqpq`そのため、すべての位置で一貫してマッピングを適用する必要があります。 

## アプローチ

 ブルートフォース手法は簡単で、文字列内の各文字に対して`a`、その値を確認し、ミラー マッピングに従って置き換えます。 これには、すべての文字を調べて単純な置換を実行する必要がありますが、最悪の場合でも合計操作数はわずか約 10,000 なので、これは機能します。 

最適なソリューションを実現するための重要な洞察は、複雑なデータ構造やアルゴリズムが必要ないことを認識することです。 マッピングは一定で小さい (`p`、`q`、`w`）。 辞書または直接の条件文を使用すると、各文字を O(1) 時間で翻訳できます。 文字列の長さは制限されており、テスト ケースの数は中程度であるため、この線形時間アプローチはすでに最適です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース / ダイレクト マッピング | 文字列ごとに O(n) | 文字列ごとに O(n) | 承認済み |

 マッピングを適用するにはすべての文字を検査する必要があるため、これより高速な漸近解はありません。 

## アルゴリズムのチュートリアル

 1. ミラーリングされた文字のマッピングを定義します。`p`になる`q`、`q`になる`p`、 そして`w`滞在します`w`。 
2. テストケースの数を読み取る`t`。 
3. テスト ケースごとに、入力文字列を読み取ります。`a`。 
4. 結果を保持するために空の文字列またはリストを初期化します。`b`。 
5. 各文字を反復処理します。`c`で`a`：

- もし`c`は`p`、追加`q`に`b`。 
- もし`c`は`q`、追加`p`に`b`。 
- もし`c`は`w`、追加`w`に`b`。 
6. すべての文字を処理した後、出力します`b`。 

機能する理由: マッピングは、例で観察された正確な動作を保持します。 各文字は独立して変換されるため、最終的な文字列は`b`まさにShipが店内で目にしたものです。 不変条件は、最初の処理後の`k`文字列の一部は、船の内部から見えるものに正しく対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# mapping function
mirror = {'p': 'q', 'q': 'p', 'w': 'w'}

t = int(input())
for _ in range(t):
    a = input().strip()
    b = ''.join(mirror[c] for c in a)
    print(b)
```このソリューションは、次を使用してすべての入力を効率的に読み取ります。`sys.stdin.readline`。 の`mirror`辞書は文字変換を 1 か所でエンコードし、間違いの可能性を減らします。 使用する`''.join()`ジェネレーターを使用すると、ループ内での不必要な文字列の連結が回避され、Python ではより効率的になります。

## テストケース```python
import sys, io

def run(inp: str) -> str:

    output = io.StringIO()

    t = int(input())
    for _ in range(t):
        a = input().strip()
        b = ''.join(mirror[c] for c in a)
        print(b)
    sys.stdout = sys.__stdout__
    return output.getvalue().strip()
