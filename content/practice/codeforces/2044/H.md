 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times n$正の整数の行列と複数のクエリ。それぞれが長方形の部分行列を指定します。 クエリごとに、部分行列を行優先の 1D 配列に平坦化し、平坦化された配列内の 1 から始まる位置を乗算した各要素の合計を計算する必要があります。 正式に言うと、$A$は平坦化された配列です。$\sum_{i=1}^{|A|} i \cdot A_i$。 

制約が重要です。 各マトリックスは最大で$2000 \times 2000$、すべての合計$n$すべてのテスト ケースの上限は 2000 であるため、事前計算が可能になります。 ただし、クエリの数は次のとおりです。$10^6$したがって、クエリごとに部分行列要素を反復処理するソリューションは非常に遅くなります。 素朴なアプローチは次のようにスケールします。$O(q \cdot n^2)$に到達する可能性があります$2 \cdot 10^9$操作は受け入れられません。 

エッジ ケースには、単一行または単一列の部分行列と、行列全体にまたがる部分行列が含まれます。 すべての行が前の行から継続するのではなく 1 からカウントを開始すると仮定した場合、実装が不注意であると、フラット化された配列内の 1 から始まるインデックスが誤って計算される可能性があります。 

## アプローチ

 ブルート フォース アプローチでは、各クエリを反復し、部分行列を手動で平坦化し、加重合計を計算します。 これは正しいですが、最大の制約に対して明らかに遅すぎます。 コストは部分行列の面積とクエリ数の積に比例します。$O(q \cdot n^2)$操作。 

重要な洞察は、合計が$\sum i \cdot A_i$行ごとに分解できます。 部分行列の各行は、重みが単純な等差数列を形成する合計に寄与します。 具体的には、行の最初の要素はその値にフラット化された配列内のその行の開始インデックスを乗じた値を与え、2 番目の要素はその値に 1 を加えた値を与えます、というようになります。 事前に計算された要素のプレフィックス合計と、各行内の列インデックスによって重み付けされたプレフィックス合計を使用して、各行の寄与を計算できます。$O(1)$。 すべての行を合計すると、クエリの答えが得られます。$O(n)$時間。 

すべてのテスト ケースの合計行数は 2000 で制限されており、各行の寄与は次のように計算できます。$O(1)$事前に計算された合計を使用するクエリごとに、このアプローチは、$10^6$クエリ。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(q * n^2) | O(n^2) | 遅すぎる |
 | 最適 (行ごとのプレフィックスの合計) | O(n^2 + q * n) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 行列の各行について、各列までの要素の累積和を格納するプレフィックス合計配列を事前計算します。 これにより、列の連続セグメントの合計を一定時間で取得できます。 
2. また、各行に対して、各要素に 1 から始まる列インデックスを乗算した重み付けされたプレフィックスの合計を事前計算します。 これにより、要素の合計とそのローカル列位置の積を迅速に計算できます。 
3. クエリごとに、部分行列内の行を反復処理します。 行用$r$、行の前のフラット化された順序の前の要素の数$r$は$(r - x_1) \cdot (y_2 - y_1 + 1)$。 これは、フラット化された配列内のこの行の 1 から始まるインデックスのオフセットです。 
4. 現在の行について、列内の要素の合計を計算します。$y_1$を通して$y_2$プレフィックスの合計を使用します。 合計に行オフセットを乗算して、前の行の寄与を考慮します。 オフセットを調整してこの行の重み付けされた要素の合計を加算します。 これにより、クエリの結果に対する行の合計寄与度がわかります。 
5. 部分行列内のすべての行からの寄与を合計し、出力に追加します。 

このアルゴリズムが機能するのは、平坦化された配列のインデックスが行と列の境界から完全に予測可能であるためです。 各行を個別に処理することで、完全な配列を構築しなくても、1 から始まる正しいインデックス付けが維持されます。 事前に計算されたプレフィックス合計により、各行の寄与を一定時間で計算できるため、全体的なクエリ計算の効率が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    results = []
    for _ in range(t):
        n, q = map(int, input().split())
        M = [list(map(int, input().split())) for _ in range(n)]
        
        prefix = []
        weighted_prefix = []
        for row in M:
            p = [0]
            wp = [0]
            for i, val in enumerate(row):
                p.append(p[-1] + val)
                wp.append(wp[-1] + val * (i + 1))
            prefix.append(p)
            weighted_prefix.append(wp)
        
        ans = []
        for _ in range(q):
            x1, y1, x2, y2 = map(int, input().split())
            x1 -= 1
            y1 -= 1
            y2 -= 1
            total = 0
            width = y2 - y1 + 1
            for r in range(x1, x2):
                row_offset = (r - x1) * width
                row_sum = prefix[r][y2 + 1] - prefix[r][y1]
                row_weighted_sum = weighted_prefix[r][y2 + 1] - weighted_prefix[r][y1]
                total += row_weighted_sum + row_sum * row_offset
            ans.append(str(total))
        results.append(" ".join(ans))
    print("\n".join(results))

if __name__ == "__main__":
    main()
```まずすべての入力を読み取り、各行のプレフィックスの合計を構築します。 プレフィックス配列を使用すると、任意の連続セグメントにわたる要素の合計を高速に計算できます。 重み付けされたプレフィックス配列により、ローカル列インデックスを乗算した要素の合計を高速に計算できます。 クエリごとに、各行の前にある要素の数を数えることによって、フラット化された配列のインデックスが決定されます。 次に、事前計算された配列を使用して各行の合計寄与を一定時間で計算し、明示的に平坦化された配列を構築しなくても、最終結果が正しいことを確認します。
