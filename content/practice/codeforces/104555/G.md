 ## 解決策
 ## 問題の理解

 各王国は 2D 平面上の点で表され、世界は最近接首都ルールによって分割されます。 無限平面内のすべての位置は、ユークリッド距離で厳密に最も近い首都に属します。 複数の首都から等距離にある点は境界線を形成しますが、それらは単一の王国の面積に寄与しません。 

質問は、領域全体を明示的に計算することに関するものではありません。 代わりに、どの首都がボロノイ セル内に無限の面積の領域を所有しているかを特定するだけで済みます。 幾何学的用語で言えば、どの点に境界のないボロノイ セルがあるかを見つけたいと考えています。 

制約が十分に大きいため、すべてのサイト間のペアごとの幾何学的比較を伴うアプローチは避けなければなりません。 ここでの自然構造は点の数が二次であるため、単純な幾何学的構成や明示的な距離サンプリングはすぐに制限を超えてしまいます。 

素朴な考え方の微妙な失敗例は、すべての点が平等に関与している、またはユークリッド距離で局所的に隣接する点が有界性を決定していると仮定することです。 たとえば、点に非常に近い隣接点があるにもかかわらず、凸包上にあるため、境界がない場合があります。 逆に、点の局所密度が比較的まばらでありながら、完全に囲まれている場合もあります。 

欠けている重要なアイデアは、有界ボロノイ セルは厳密に凸包の内側の点に対して正確に発生するのに対し、無限セルは凸包の頂点に正確に対応するということです。 

## アプローチ

 ブルートフォースの視点は定義から始まります。各首都について、そのボロノイ領域を想像し、それが無限に広がるかどうかを判断しようとします。 多くの方向の光線をシミュレートしたり、遠く離れた点をサンプリングして、どの首都が最も近くに残っているかを確認することができます。 境界のないセルは任意の距離に「到達」する必要があるため、これは概念的には正しいです。 ただし、単一の方向を確認する場合でも、他のすべての点との距離を比較する必要があり、方向を十分に密にサンプリングすると、実際にはコストが爆発的に O(N³) 程度かそれ以上になります。 

構造的な洞察は、点が一連の首都の凸包上にあるときに、境界のないボロノイ領域が正確に発生するということです。 点が凸包上にある場合、その点が極点のままである方向が存在します。つまり、その方向では他の点が支配的ではないため、そのボロノイ セルは無限に広がります。 点が厳密に凸包の内側にある場合、最終的にはあらゆる方向が無限の拡張をブロックする支配的な包頂点に遭遇するため、そのボロノイ領域は制限されます。 

これにより、問題は凸包を計算し、その上に表示されるすべての頂点を報告することになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース幾何チェック | 指数関数的またはそれ以上 | O(N) | 遅すぎる |
 | 凸包計算 | O(N log N) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 標準的な単調チェーン構造を使用して、凸包境界上のすべての点を見つけるタスクを簡素化します。

1. すべての点を x 座標で並べ替え、タイブレーカーとして y 座標で並べ替えます。 これにより、船体の構築に必要な決定的なスキャン順序が確立されます。 
2. 左から右にポイントをスキャンして、船体下部を構築します。 候補ハル頂点のスタックを維持します。 新しいポイントごとに、スタック内の最後の 2 ポイントと新しいポイントが左折以外の方向に曲がるかどうかを確認します。 存在する場合、中間点は凸包に属することができず、削除されます。 不変条件が復元されるまでこれを繰り返し、その後、新しい点を追加します。 
3. 同じ方法で上部船体を構築しますが、逆の順序でスキャンします。 これにより、対称性が確保され、凸形状の上部境界が捕捉されます。 
4. 重複するエンドポイントを削除するように注意しながら、両方のハルを結合します。 結果のセットには、凸包のすべての頂点が含まれます。 
5. ハルに表示されるすべてのポイントをインデックスの昇順で出力します。 

ステップ 2 で使用される幾何学的テストは方向 (外積) です。 非正の外積は、シーケンスが厳密に左折しないことを示します。これは、中点が凸状の境界上に存在できないことを意味します。 

## なぜ機能するのか

 他の点によって支配されない方向が存在する場合にのみ、点は無限のボロノイ領域を持ちます。 これは、凸包の頂点である場合にまさに発生します。 船体は、他のすべての点が片側に位置するように、その点でセットに接触する支持線があることを保証します。 その補助線は、ボロノイ領域が無限に広がる方向を定義します。 内部点にはそのような補助線を持つことはできないため、そのボロノイ領域は境界付けされます。 

したがって、凸包は必要なセットを正確に特徴付けます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def convex_hull(points):
    points = sorted(points)
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    hull = lower[:-1] + upper[:-1]
    return hull

def solve():
    n = int(input())
    pts = []
    for i in range(n):
        x, y = map(int, input().split())
        pts.append((x, y, i + 1))

    # sort by coordinates but keep index
    pts_sorted = sorted(pts, key=lambda p: (p[0], p[1]))

    def cross2(a, b, c):
        return (b[0]-a[0])*(c[1]-a[1]) - (b[1]-a[1])*(c[0]-a[0])

    lower = []
    for p in pts_sorted:
        while len(lower) >= 2 and cross2(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(pts_sorted):
        while len(upper) >= 2 and cross2(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    hull = lower[:-1] + upper[:-1]

    ans = sorted(set(p[2] for p in hull))
    print(*ans)

if __name__ == "__main__":
    solve()
```実装では元のインデックスが保持されるため、王国 ID を報告できます。 モノトーン チェーンは下部ハルと上部ハルに分割されており、凸性を維持するために外積テストを使用します。 点は厳密な凸境界条件に違反する場合にのみ削除され、同一線上にある境界点が一貫して処理されることが保証されます。 

微妙な点は、同一線上にある境界点が極端なエッジにある場合、それらをハルの一部として含めることです。 の`<= 0`この条件により、外側の端点は維持しながら、内側の同一線上の点は維持されなくなります。 

## 実用的な例

 小規模な構成を考えてみましょう。 

入力:```

```辞書順にポイントを並べ替えてハルを構築します。 方向に基づいてポイントが追加および削除されると、スタックは進化します。 各点はセットによって形成された形状の境界上にあるため、最終的なハルにはすべての点が含まれます。 

| ステップ | ポイントが追加されました | 船体下部の状態 |

このプロセスでは、極端な幾何学的位置を維持する点のみが両方のスキャンで生き残り、予想される出力と一致することがわかります。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(N log N) | ソートが優先され、ハル スキャンは線形です。 
| スペース | O(N) | ポイントとハルを保存する |

 制約では最大 100,000 点が許可されるため、O(N²) 個の幾何学的比較は実行できません。 モノトーンのチェーン凸包が最適で、制限内に快適にフィットします。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n = int(input())
    pts = []
    for i in range(n):
        x, y = map(int, input().split())
        pts.append((x, y, i + 1))

    pts.sort()
    def cross(a,b,c):
        return (b[0]-a[0])*(c[1]-a[1])-(b[1]-a[1])*(c[0]-a[0])

    lower=[]
    for p in pts:
        while len(lower)>=2 and cross(lower[-2],lower[-1],p)<=0:
            lower.pop()
        lower.append(p)

    upper=[]
    for p in reversed(pts):
        while len(upper)>=2 and cross(upper[-2],upper[-1],p)<=0:
            upper.pop()
        upper.append(p)

    hull = lower[:-1] + upper[:-1]
    return " ".join(map(str, sorted(set(p[2] for p in hull))))

 ## 特殊なケース

 重要なエッジ ケースは、すべての点が 1 つの直線上にある場合です。 その場合、すべての点は縮退した意味で凸包境界上にあり、アルゴリズムは依然としてすべての点を返さなければなりません。 モノトーン チェーンはこれを処理します。これは、方向チェックによって同一線上の点が一貫して折りたたまれ、結合されたときに完全なセットを再構成するエンドポイントが残るためです。 

もう 1 つのエッジ ケースは、多くの点が極端な X 座標または Y 座標を共有する場合です。 船体は依然として最も外側の構造のみを正確に識別する必要があり、上部船体と下部船体を連結する際の重複処理により、インデックスの重複や省略が確実に発生しません。
