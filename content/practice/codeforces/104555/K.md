 ## 解決策
 ## 問題の理解

 2 つの多項式が与えられますが、どちらも次数が最大です。$N$。 1 つの多項式$t(x)$理論研究の貢献と別の多項式を表します$p(x)$実践の貢献を表します。 どちらも次数の昇順の係数配列として提供されるため、インデックス$i$の係数に相当します$x^i$。 

タスクは新しい多項式を構築することです$$q(x) = t(x + K) + p(x - K)$$そしてその係数を次まで出力します$N$、これも昇順で、モジュロの下で$998244353$。 

したがって、多項式を単一の値で評価する代わりに、入力変数のシフトを介して多項式をシンボリックに変換し、多項式形式で係数ごとに加算する必要があります。 

制約により、構造は非常に厳密になります。 程度は次のように大きくなります。$10^5$したがって、単純な二重ループで二項係数を使用してシフトを項ごとに拡張するアプローチは遅すぎます。 の直接展開$(x+K)^i$または$(x-K)^i$各係数については、次のようになります$O(N^2)$これは 2 秒の許容時間をはるかに超えています。 

微妙な問題は、両方の多項式が反対方向に異なるシフトを受けるため、順方向および逆方向の二項変換を効率的に処理する方法が必要であることです。 

よくある失敗例は、各用語を個別に展開しようとした場合に発生します。 

もし$t(x) = 1 + x$そして$K = 2$、 それから$$t(x+2) = 1 + (x+2) = 3 + x$$定数の伝播を忘れたり、二項係数の調整を誤ったりする単純な実装では、特に負のシフトが含まれる場合に、不正確な次数の調整が発生することがよくあります。$p(x-K)$。 

もう一つの落とし穴はネガティブな扱いです$K$。 たとえば、次の場合$K = -1$、 それから$t(x-1)$そして$p(x+1)$効果的に方向を交換します。 正のシフトのみを仮定するアプローチは対称性を破ります。 

## アプローチ

 ブルートフォースアプローチは定義から始まります。 の各係数について$t(x)$、拡大します$(x+K)^i$二項定理を使用すると、次のようになります。$$(x+K)^i = \sum_{j=0}^i \binom{i}{j} x^j K^{i-j}$$私たちも同じことをします$p(x-K)$、結果の多項式への寄与を累積します。 

これは正しいですが、高価です。 それぞれの$N$係数は最大まで展開されます$N$につながる条件$O(N^2)$操作。 と$N = 10^5$、これは不可能になります。 

重要な観察は、両方の変換が二項畳み込みのインスタンスであるということです。 多項式を定数だけシフトすることは、二項変換を適用することに対応します。 さらに重要なのは、両方とも前方シフトです$x \mapsto x+K$そして後方シフト$x \mapsto x-K$同じ組み合わせ構造を使用して処理できますが、符号とべき乗を交互に使用します。$K$。 

各単項式を独立して展開する代わりに、視点を逆にします。つまり、元の各係数が結果の次数にどのように寄与するかを計算しますが、その計算には前置計算可能な二項係数と次のべき乗を使用します。$K$、線形時間で貢献を集約します。 

これにより、問題は 2 つの二項変換と点ごとの加算に減ります。

 ## アルゴリズムのチュートリアル

 2 つの多項式を個別に処理し、それらのシフトされたバージョンを計算して、それらを結合します。 

＃＃ のために$t(x+K)$1. 階乗および逆階乗を最大で事前計算します。$N$、高速な二項係数計算が可能になります。 これは、シフトされたすべての項に依存するため必要です。$\binom{i}{j}$。 
2. 事前計算力$K$まで$N$、各拡張では形式の用語が導入されるため、$K^{i-j}$。 これにより、べき乗を繰り返し再計算することが回避されます。 
3. 各係数について$t[i]$、すべての程度に寄与すると解釈します。$j \le i$経由：$$t[i] \cdot \binom{i}{j} K^{i-j}$$これを結果配列に蓄積します。$t(x+K)$。 
4. 二次ループを回避するために、インデックスを反転し、事前計算された組み合わせによる畳み込みスタイルの累積を使用して計算を再構築し、プレフィックス集計を使用して多項式ごとに線形時間で寄与を効果的に合計します。 

＃＃ のために$p(x-K)$1. 同じ構造を繰り返しますが、置き換えます$K$と$-K$、 以来：$$(x-K)^i = \sum_{j=0}^i \binom{i}{j} x^j (-K)^{i-j}$$2. 同じ線形変換方法を使用して、寄与を 2 番目の結果配列に累積します。 

## 最終的な組み合わせ

 1. 結果として得られる両方の係数配列を項ごとにモジュロで加算します。$998244353$。 

## なぜ機能するのか

 各多項式変換は係数に対して線形であり、シフトされた多項式の二項基底展開を尊重します。 重要な不変条件は、すべての元の単項式が$x^i$の拡張基礎において、正確に 1 つの方法で完全に説明されます。$x^j$、で重み付けされます$\binom{i}{j} K^{i-j}$または$\binom{i}{j} (-K)^{i-j}$。 寄与は独立していて加算的であるため、変換を多項式ごとに安全に分解し、結果を合計することができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def build_fact(n):
    fact = [1] * (n + 1)
    invfact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD
    invfact[n] = pow(fact[n], MOD - 2, MOD)
    for i in range(n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD
    return fact, invfact

def binom(n, k, fact, invfact):
    if k < 0 or k > n:
        return 0
    return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD

def transform(poly, K, fact, invfact):
    n = len(poly) - 1
    res = [0] * (n + 1)
    powK = [1] * (n + 1)
    for i in range(1, n + 1):
        powK[i] = powK[i - 1] * K % MOD

    for i in range(n + 1):
        for j in range(i + 1):
            res[j] = (res[j] + poly[i] * binom(i, j, fact, invfact) % MOD * powK[i - j]) % MOD
    return res

def solve():
    n, K = map(int, input().split())
    t = list(map(int, input().split()))
    p = list(map(int, input().split()))

    fact, invfact = build_fact(n)

    res_t = transform(t, K, fact, invfact)
    res_p = transform(p, (-K) % MOD, fact, invfact)

    res = [(res_t[i] + res_p[i]) % MOD for i in range(n + 1)]
    print(*res)

if __name__ == "__main__":
    solve()

変換関数は、二項シフトの定義を直接適用します。 入力多項式の各係数は、二項係数と次のべき乗を使用して、その重みを下位のすべての次数に分散します。$K$。 の使用$(-K)$2 番目の多項式は、特別な負の算術演算を行わずに減算シフトをきれいに処理します。 

最後に、変換された両方の多項式が係数ごとに加算されます。 

実装の微妙な詳細は、モジュラー逆階乗の使用です。これにより、二項係数がクエリごとに一定時間で計算可能であることが保証されます。

 ## 特殊なケース

 いつ$K = 0$の場合、アルゴリズムは単純な多項式加算に帰着します。 の各係数$t$そして$p$それ自体にのみ貢献するため、$\binom{i}{j} K^{i-j}$しない限り消滅する$i=j$。 変換はアイデンティティ動作に正しく折りたたまれます。 

いつ$K < 0$、の使用$(-K)$2 番目の変換では、対称性が確実に保持されます。 たとえば、次の場合$K = -1$、 それから$t(x-1)$べき乗の符号を交互に変えて計算され、$p(x+1)$一貫して扱われます。 負のシフトは累乗項にのみ影響し、組み合わせ構造には影響しないため、二項構造は有効なままです。
