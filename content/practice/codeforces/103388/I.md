 ## 解決策

 書く$N$バイナリ形式で$$N = (a_m a_{m-1}\dots a_0)_2 = \sum_{i=0}^m a_i 2^i.$$させて$\kappa_t N$最小の整数を表す$M \ge N$バイナリ展開に正確に含まれるもの$t$もの、つまり、$$M = \sum_{i \in S} 2^i \quad \text{for some } |S| = t.$$この定義は、次のことを意味します。$N$すでに正確に持っています$t$一つ、それでは$\kappa_t N = N$、 以来$N$数値の中で許容可能かつ最小である$\ge N$同じプロパティを持つ。 

仮定する$N$正確にはありません$t$もの。 させて$j$そのような最高の地位になる$M$そして$N$少しずつ違う$j$、 どこ$M = \kappa_t N$。 最小限にすることで、$M$、すべての上位ビットが一致します。$$a_i(M) = a_i(N) \quad \text{for } i > j,$$そしてその位置で$j$、の建設$M$力$a_j(M)=1$その間$a_j(N)=0$。 それ以外の場合は、より小さい許容数値$\ge N$最も高い 1 を以下に置くことで存在します。$j$、ミニマルさと相反します。 

残り全部$t-1$の$M$厳密に下の位置になければなりません$j$。 あらゆる選択肢の中で、$t-1$以下の位置$j$、可能な限り最小の値は、それらを利用可能な最も低い位置に配置することによって取得されます。$0,1,\dots,t-2$。 これにより下限が得られます$$M \le 2^j + (2^{t-1}-1).$$今比較してください$N$そして$M$。 以来$a_j(N)=0$すべての上位ビットが一致すると、その差は満たされます。$$M - N \le \bigl(2^j + (2^{t-1}-1)\bigr) - (2^j - 1),$$どこ$2^j - 1$は、下位ビットの可能な最大の寄与です。$N$所定の位置にキャリーを入れるという制約の下で$j$には必要です$M \ge N$。 これを単純化すると、$$M - N \le 2^{t-1}.$$この限界が達成されていることを示すには、次のようにします。$$N = 2^m - 1$$誰にとっても$m \ge t-1$。 それから$N$からなるバイナリ形式です$m$もの。 最小の整数$\ge N$まさに$t$位置に 1 を配置する必要があります$m$そして残りを配布します$t-1$最も低い地位にいる人たちに与える$$\kappa_t N = 2^m + (2^{t-1}-1).$$したがって、$$\kappa_t N - N = \bigl(2^m + (2^{t-1}-1)\bigr) - (2^m - 1) = 2^{t-1}.$$前の引数が次の値を与えるため、これより大きな値は不可能です。$\kappa_t N - N \le 2^{t-1}$みんなのために$N \ge 0$。 

これで証明は完了です。 ∎$$\boxed{2^{t-1}}$$
