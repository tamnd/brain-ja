 ## 解決策
 ## 問題の理解

 順列が与えられています`p`長さの`n`。 インデックス`i`その位置で初めて最大値に達した場合は、「醜い」と呼ばれます。 より正式には、`i`場合は醜いです`p[i]`の最大値に等しい`p[1..i]`。 Simons は、配列内の任意の 2 つの位置間で最大 1 回の交換を実行できます。 私たちのタスクは順列を出力することです`q`から得た`p`醜いインデックスの数が最小限に抑えられるように、最大​​ 1 回のスワップを使用します。 

入力は複数のテスト ケースで構成されます。 各テスト ケースが提供するのは、`n`そして配列`p`からの異なる整数の`1`に`n`。 出力は順列です`q`最小の醜さの基準を満たす各テスト ケースについて。 

制約が示すのは、`n`最大 500 まで可能で、`t`最大100まで。`n`小さくても、`O(n^2)`アルゴリズムは実現可能ですが、順列の特性と醜いインデックスの定義に基づいて線形時間解を見つけることができます。 

単純な実装では、考えられるすべてのスワップを試し、それぞれの醜いインデックスをカウントする可能性がありますが、これは不要です。 エッジケースには、最初の要素が最大であるすでに降順になっている置換、またはスワップなしでカウントが改善されるすでに最適な置換が含まれます。 例えば、`p = [3,1,2]`スワップすると醜さが増すため、すでに最小になっています。 

## アプローチ

 ブルートフォースアプローチは簡単です。テストケースごとに、すべてのペアを反復処理します。`(i,j)`と`i<j`、交換`p[i]`そして`p[j]`、醜いインデックスの数を数え、最小数で順列を追跡します。 各スワップに必要なのは`O(n)`醜さを数えるための総時間計算量は次のようになります。`O(n^3)`テストケースごとに。 と`n = 500`、これはテスト ケースごとにおよそ 1 億 2,500 万の操作であり、定数係数によってはかろうじて 1 秒に収まる可能性がありますが、明らかに最適ではありません。 

最適なアプローチは、インデックスの値が現在の最大値である場合にはインデックスが醜いという事実を利用します。 醜さを減らすために、最初の要素を最大にする必要があります。そうすることで、より小さい数値に達するまで、後続の要素が新しい最大値をトリガーしないようにすることができます。 シンプルな戦略は最大の要素を見つけることです`n`まだ存在しない場合は、配列の先頭に配置します。 最初の要素を最大要素と交換することで、これを 1 回の操作で実現できます。 最大値がすでに開始時にある場合は、スワップの必要はありません。 これにより、最初は醜いインデックスが 1 つだけ保証され、醜さが最小限に抑えられます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして順列`p`。 
3. 位置を特定する`max_idx`最大値の`n`配列内で。 
4. もし`max_idx`最初の位置ではないので交換します`p[0]`そして`p[max_idx]`。 これにより、最大値が最初に配置され、醜いインデックスが最小限に抑えられます。 
5. 結果の順列を出力します。 

機能する理由: 私たちが使用する特性は、実行最大値が最初に出現するインデックスは醜いということです。 最大の要素を最初の位置に配置することで、最初の醜いインデックスが位置 1 にあることが保証され、存在しないより大きな数値が現れるまで、他のインデックスは醜くなりません。 より小さい要素を含むスワップでは、最大の要素を最初に配置する以上に醜さを軽減できないため、この戦略は最適です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))
    max_val = n
    max_idx = p.index(max_val)
    if max_idx != 0:
        p[0], p[max_idx] = p[max_idx], p[0]
    print(" ".join(map(str, p)))
```解決策はまず、次の最大値の位置を見つけます。`p`。 最初の位置にない場合は、最初の要素と置き換えます。 スワップはテスト ケースごとに 1 回許可されるため安全です。 私たちが使用するのは`p.index(n)`それは`O(n)`、そしてスワップ自体は`O(1)`。 の`print`ステートメントは、各テスト ケースの順列を出力します。 配列を超える余分なスペースは使用されず、次のような境界条件は使用されません。`n=1`自然に処理されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        max_val = n
        max_idx = p.index(max_val)
        if max_idx != 0:
            p[0], p[max_idx] = p[max_idx], p[0]
        print(" ".join(map(str, p)))
    sys.stdout = sys.__stdout__
    return output.getvalue().strip()

 ## 特殊なケース

 のために`n = 1`、配列`[1]`要素は 1 つだけであり、最適であることは自明です。 アルゴリズムはそれを検出します`max_idx = 0`したがって、スワップは発生せず、出力は次のようになります。`[1]`。 

最大値がすでに最初にある配列の場合、次のようになります。`[3,2,1]`、アルゴリズムは順列を変更しないままにします。 他の要素を交換すると、醜いインデックスの数が増加します。 このアルゴリズムは、初期順列が最適であることを正確に識別し、不必要な操作を実行しません。 

最大値が最後の位置にある場合、たとえば、`[1,2,3,4]`、アルゴリズムが切り替わります`4`最初の位置に与えて、`[4,2,3,1]`。 醜いインデックスは位置 1 の 1 に最小化されますが、他のスワップでは、それより前の位置に複数の醜いインデックスが残ります。
