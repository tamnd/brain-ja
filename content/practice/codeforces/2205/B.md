 ## 解決策
 ## 問題の理解

 私たちは、シモンズが友達にケーキを分けるのを手伝ってほしいと頼まれました。 より正式には、指定された数の友人に対して$n$、最小の正の整数を見つける必要があります$k$そのような$k^n$で割り切れます$n$。 入力は複数のテスト ケースで構成され、それぞれが友人の数を指定します。 各ケースの出力は最小値です$k$割り切れる条件を満たすものです。 

制約により許可されるのは、$n$と同じくらい大きくなる$10^9$テスト ケースの数は最大 100 です。計算を試みる任意のアルゴリズム$k^n$すべての人に直接$k$まで$n$大きな数値のべき乗はコストが高く、最大で反復処理が行われるため、遅すぎます。$10^9$は非現実的です。 したがって、課題は、ブルートフォース権限なしで機能する方法を決定することです。 

素朴なアプローチでは次のことが起こります。$k=1,2,3,\dots$そしてテストするかどうか$k^n \mod n = 0$。 小型用$n$、これは機能しますが、$n\sim 10^9$、何十億回もの反復が必要になります。 また、$1^n$は常に 1 であり、次の場合に失敗します。$n>1$したがって、これは不注意な実装によくある落とし穴です。 

もう一つの微妙なケースは次のような場合です。$n$は素数または素数の累乗です。 例えば、$n=8$必要$k=2$なぜなら$2^3 = 8$分割する$2^8 = 256$。 構造を誤解している$n$多くの場合、過大評価につながります$k$。 

## アプローチ

 ブルートフォース手法は反復されます$k=1,2,3,\dots$そしてチェックするかどうか$n$分割する$k^n$。 各チェックにはべき乗剰余演算が含まれます。$O(\log n)$。 最悪の場合、$k$と同じ大きさにすることができます$n$、与える$O(n \log n)$。 のために$n \sim 10^9$、これは遅すぎます。 

重要な洞察は因数分解から得られます。 させて$n$素因数分解がある$n = p_1^{a_1} p_2^{a_2} \dots p_m^{a_m}$。 持つこと$k^n$で割り切れる$n$、各素数$p_i$に登場しなければなりません$k^n$少なくとも指数付き$a_i$。 言い換えれば、多重度は、$p_i$で$k$少なくとも$\lceil a_i / n \rceil = 1$なぜなら$a_i/n < 1$。 したがって、最小限の$k$の異なる素因数を乗算することで得られます。$n$。 

これにより、問題は次の素因数分解に還元されます。$n$これは、指定された制約に対して効率的です。$n \le 10^9$。 試行除算を使用して最大で因数分解できます$\sqrt{n}$、テスト ケースごとに最大約 31,622 回の反復が必要です。 異なる素数を乗算すると最小値が得られます$k$。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$。 
3. 素因数の空のリストを初期化します。 
4. 反復する$d$2から$\sqrt{n}$。 もし$d$分割する$n$、 追加$d$素因数のリストに。 それから分割します$n$による$d$割り切れなくなるまで繰り返します。 これにより、最高のパワーが引き出されます。$d$で$n$明確なプライムのみを記録します。 
5. ループ後の場合$n>1$、それ自体が素因数である場合は、リストに追加します。 
6. コンピューティング$k$すべての異なる素因数の積として。 
7. 印刷$k$。 

Why it works: Each prime factor of$n$に登場しなければなりません$k$、 さもないと$k^n$除算するのに十分な素数の倍数を供給できません$n$。 それぞれの異なる素数を 1 回だけ含めると、最小値が生成されます。$k$、より高いパワーを追加すると不必要に増加するため、$k$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def minimal_k(n):
    original_n = n
    k = 1
    for d in range(2, int(n**0.5)+1):
        if n % d == 0:
            k *= d
            while n % d == 0:
                n //= d
    if n > 1:
        k *= n
    return k

t = int(input())
for _ in range(t):
    n = int(input())
    print(minimal_k(n))
```ソリューションは関数を定義します`minimal_k`因数分解する$n$異なる素数の積を計算します。 外側のループはすべてのテスト ケースを読み取ります。 使用する`int(n**0.5)`試行除算が平方根までのみ行われるようにします。 内側のループが分割されます$n$因数で繰り返し乗算してすべての累乗を取り除き、重複した乗算を避けます。
