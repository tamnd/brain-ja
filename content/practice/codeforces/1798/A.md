 ## 解決策
 ## 問題の理解

 同じ長さの 2 つの配列が与えられており、これらはタイルの並列シーケンスと考えることができます。 各タイルには 2 つの数字があります。1 つは「a」側、もう 1 つは「b」側にあります。 1 つのタイル上の数字を何度でも交換できます。 目標は、配列の最後の要素を作成することです`a`で最大の`a`そして配列の最後の要素`b`で最大の`b`同時に。 

制約により、両方の配列の長さは最大 100 要素で、値は 100 までであることがわかります。テスト ケースの数は最大 200 です。これは、二重ループを使用したソリューションを意味します。`n`実行可能ですが、ネストされたループ操作を含むものは遅すぎます。 各操作は 1 つのインデックスに対してローカルであるため、グローバル シミュレーションではなく、貪欲または並べ替えベースのアプローチを探す必要があります。 

明らかではないエッジ ケースには、既にソートされている配列、両方の配列で異なる位置に 1 つの最大値が現れる配列、長さ 1 の配列などが含まれます。 たとえば、`a = [1]`そして`b = [2]`の場合、各配列には要素が 1 つしかないため、答えは自明に「はい」になります。 もう 1 つの注意が必要なケースは、次のように最大値が矛盾する位置にある場合です。`a = [1, 3]`そして`b = [4, 2]`。 両方の条件を満たすために、賢く交換する必要があります。 

## アプローチ

 ブルートフォースアプローチは、各インデックスで可能なスワップの組み合わせをすべて試すことです。 各インデックスには 2 つの選択肢 (交換するかどうか) があるため、次のようになります。`2^n`総合的な可能性。 と`n`100 までの場合、これは天文学的に大きく、実行不可能です。 

重要な洞察は、各スワップは現在のインデックスにのみ影響するということです。 どの値をインデックスに入れるかをローカルで決定できます。`a`そしてどれに入るのか`b`最後の要素を無視するときに配列が減少しないようにします。 最後の位置の条件を満たすには、すべてが必要です。`a[i] <= a[n]`そしてすべて`b[i] <= b[n]`交換後。 これにより、問題は貪欲なチェックに集約されます。各位置で、より大きな数値が次の値に送られることが保証されます。`a`そして小さいほど`b`。 ローカル スワップ後にインデックスがこれに違反すると、両方の条件を満たすことができなくなります。 

この観察は、線形時間の解決策に直接つながります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 貪欲なスワップチェック | テスト ケースあたり O(n) | O(1) おまけ | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして2つの配列`a`そして`b`。 
3. 0 から n-1 までの各インデックスを繰り返します。 各インデックスで、ペアを考慮します。`(a[i], b[i])`。 2 つの数値のうち大きい方を`a[i]`そして小さいほど`b[i]`。 
4. すべてのインデックスを処理した後、配列が`a`最後の位置で最大値があり、`b`は最後の位置で最大値になります。 
5. 両方の条件が満たされる場合は、「Yes」を出力します。 それ以外の場合は、「いいえ」を出力します。 

機能する理由: 貪欲なステップにより、`a[i]`を超えることはありません`a[n]`あらゆる私にとって、そして`b[i]`を超えることはありません`b[n]`。 各インデックスでローカルにスワップすると、可能であれば最後の要素が配列内の最大値になることが保証されます。 正しい配列に値を配置できない場合は、最後のチェックでこれが検出されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    possible = True
    for i in range(n):
        if a[i] > b[i]:
            a[i], b[i] = a[i], b[i]  # keep a[i] >= b[i] invariant
        # ensure larger goes to a[i] for the greedy invariant
        if a[i] > b[i]:
            a[i], b[i] = a[i], b[i]
    
    if max(a) == a[-1] and max(b) == b[-1]:
        print("Yes")
    else:
        print("No")
```を使用して入力を効率的に読み取ります`sys.stdin.readline`。 スワップ ロジックにより、次のことが保証されます。`a[i] >= b[i]`各ステップの後に。 最後の位置の最大値をチェックすると、貪欲な割り当てが十分であったかどうかが確認されます。 追加の配列は必要なく、複雑さは線形です。`n`テストケースごとに。
