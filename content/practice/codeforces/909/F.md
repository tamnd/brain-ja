 ## 解決策
 ## 問題の理解

 2 つの完全に異なる数値の順列を構築する必要があります`1...N`。 

最初の順列について`p`、あらゆるポジション`i`は別の値を受け取る必要があり、位置とその割り当て値のビット単位の AND は正確に 0 である必要があります。 

2 番目の置換の場合`q`、あらゆるポジション`i`再び異なる値を受け取る必要がありますが、ビット単位の AND は厳密に正でなければなりません。 

入力には整数が 1 つだけ含まれています`N`、 まで`10^5`。 これにより、順列に関する検索が即座に除外されます。 たとえ`O(N^2)`construction would be unnecessarily expensive. 線形時間で順列を満たす直接的な構築的なパターンが必要です。 

The first non-obvious edge case is odd`N`最初のタスクで。 すべての奇数インデックスはバイナリで終わります`1`。 入手するには`i & p[i] = 0`、奇数のインデックスに割り当てられる値は偶数である必要があります。 いつ`N`が奇数の場合、偶数よりも奇数の方が多いため、少なくとも 1 つの奇数インデックスは個別の偶数値を受け取ることができません。 例えば：```
N = 3
```指数`1`そして`3`は奇数ですが、偶数の値は 1 つだけ存在します。`2`。 解決策は存在しません。 

2 番目に重要なエッジケースは次のような場合です。`N`2 番目のタスクでは、 は 2 のべき乗です。 考慮する`N = 8`。 番号`8`最上位ビットのみが設定されています。 範囲内`1...8`、そのビットを共有する唯一の数値は`8`自体。 固定点は禁止されているため、位置`8`有効な値を割り当てることはできません。 同じ議論が 2 のすべての累乗に対して機能します。 

3 番目のトラップは、次の小さな値です。`N`。 いつでも`N`は 2 のべき乗ではないため、2 番目の順列はまだ存在しません。`N < 6`。 たとえば、徹底的なチェックにより次のことがわかります。`N = 5`どこでも正の AND を伴う有効な混乱はありません。 

## アプローチ

 ブルートフォースアプローチでは順列が生成され、すべての位置で必要な条件がテストされます。 

最初のタスクでは、すべてのペアが`(i, p[i])`満足する`i & p[i] = 0`。 2 番目のタスクでは、次のことを確認します。`i & q[i] > 0`。 

定義を直接検証するため、正確性がすぐにわかります。 問題は順列の数です。 たとえ`N = 15`、すでにあります`15! ≈ 1.3 × 10^12`候補者たち。 実際の制限は`10^5`, したがって、強引な攻撃は完全に不可能です。 

重要な観察は、ビット単位の AND 制約により、バイナリ構造によって数値が自然にグループ化されるということです。 

最初の順列では、次の形式のマスクで囲まれた間隔内の数値`2^k - 1`自然な補色を持っています。 もし```
x + y = 2^k - 1
```それからすべてのビット`1`で`x`は`0`で`y`、その逆も同様です。 したがって、`x & y = 0`。 

2 番目の順列では、同じ最上位の設定ビットを共有する数値は自動的に正の AND になります。 このようなブロック内で数値を循環的にローテーションすると、すべての位置が異なる値を受け取り、共通の最上位ビットによって正の AND が保証されます。

 | --- | --- | --- | --- |
 | ブルートフォース |`O(N!)`|`O(N)`| 遅すぎる |
 | 最適な構造 |`O(N)`|`O(N)`| 承認済み |

 ## アルゴリズムのチュートリアル

 ### 最初の順列 (`i & p[i] = 0`)

 1. もし`N`奇数です、出力`NO`。 
2. それ以外の場合は、`r = N`。 
3. フォームの最小マスクを見つけます`2^k - 1`そのような`mask >= r`。 
4. しましょう`l = mask - r`。 
5. あらゆる人にとって`x`で`[l, r]`、割り当てます```
p[x] = mask - x
```なぜなら`x`そして`mask - x`マスク内のビット単位の補数です。 
6. 残りのプレフィックスに対して再帰的に続行します。`[1, l-1]`。 

すべての間隔は独立してペアになっており、すべての数字は 1 回だけ表示されます。 

### 2 番目の置換 (`i & q[i] > 0`)

 1. もし`N < 6`または`N`は 2 のべき乗、出力`NO`。 
2. 最初の 7 つの数値には固定基底構造を使用します。```
q[1..7] = [3, 6, 2, 5, 1, 7, 4]
```3. ブロックごとに```
[2^k , min(N, 2^(k+1)-1)]
```と`2^k >= 8`、ブロックを 1 位置ずつ循環的にシフトします。 
4. ブロックが```
a, a+1, ..., b
```割り当てる```
a -> a+1
a+1 -> a+2
...
b -> a
```同じブロック内のすべての数値は最上位ビットを共有します`2^k`したがって、割り当てられたすべてのペアは正の AND を持ちます。 

### なぜ効果があるのか

 最初の順列では、すべての代入は次の形式になります。```
x <-> (mask - x)
```どこ`mask = 2^k - 1`はバイナリですべて 1 です。 2 つの数値は、これらの数値内の正確なビット単位の補数です。`k`ビットなので、それらの AND はゼロになります。 2 回補うと元の数値が返されるため、マッピングは完全なペアリング、つまり順列になります。 

2 番目の順列では、すべてのブロックは同じ最上位の設定ビットを持つ数値で構成されます。 周期的にシフトしても固定点が作成されることはありません。 割り当てられたすべてのペアの両方の数値にはその最上位ビットが含まれるため、それらの AND には少なくともそのビットが含まれ、厳密に正になります。 のベースブロック`1...7`厄介な小さな数値のみを処理します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_first(n):
    if n % 2:
        return None

    p = [0] * (n + 1)
    r = n

    while r > 0:
        mask = 1
        while mask - 1 < r:
            mask <<= 1
        mask -= 1

        l = mask - r
        for x in range(l, r + 1):
            p[x] = mask - x

        r = l - 1

    return p[1:]

def build_second(n):
    if n < 6 or (n & (n - 1)) == 0:
        return None

    q = [0] * (n + 1)

    base = [3, 6, 2, 5, 1, 7, 4]
    for i in range(1, min(n, 7) + 1):
        q[i] = base[i - 1]

    start = 8
    while start <= n:
        end = min(n, (start << 1) - 1)

        for x in range(start, end):
            q[x] = x + 1
        q[end] = start

        start <<= 1

    return q[1:]

def solve():
    n = int(input())

    p = build_first(n)
    if p is None:
        print("NO")
    else:
        print("YES")
        print(*p)

    q = build_second(n)
    if q is None:
        print("NO")
    else:
        print("YES")
        print(*q)

solve()
```最初の関数は、現在のサフィックスをカバーする最小のオール 1 マスクを繰り返し検索します。 そのサフィックス内のすべての数値は、マスク内のその補数とペアになります。 変数`r`各ステップの後、未処理のプレフィックスに縮小されます。 

2 番目の機能は、特別な取り決めから始まります。`1...7`。 その後、すべての 2 のべき乗ブロックが循環的に回転されます。 最後の要素はブロックの最初の要素に戻り、固定小数点を防ぎます。 

よくある実装上の間違いは、最初の構築で区間境界を誤って計算することです。 間隔は次のとおりです。`[mask - r, r]`、 ない`[mask - r + 1, r]`。 エンドポイントが 1 つ欠けていると、順列プロパティが壊れます。 

もう 1 つのよくある間違いは、ブロックを回転させようとすることです`[1]`2回目の施工中。 そのブロックのサイズは 1 であり、混乱を引き起こすことはできません。 特殊なベース構造により、この問題は完全に回避されます。

 ## 特殊なケース

 のために`N = 3`、奇数の位置が 2 つあり、偶数の値が 1 つしかないため、最初の構築は失敗します。 アルゴリズムは奇数を検出します`N`すぐに印刷します`NO`。 

のために`N = 8`、位置が原因​​で 2 番目の構築は失敗します。`8`別の番号共有ビットが必要になる`8`、しかしそのような番号は内部には存在しません`1...8`。 2 のべき乗チェックは、建設が始まる前にこのケースを検出します。 

のために`N = 5`、2回目の施工も不可能です。 アルゴリズムはすべてを拒否します`N < 6`、この小さな例外的な範囲を直接カバーします。 

これらはまさに、単純な構築パターンが無効な固定小数点またはゼロの AND 値を暗黙のうちに生成するケースです。
