 ## 解決策
 ## 問題の理解

 この問題では、次から整数を数えるよう求められます。`0`に`n`整数を次の値で割ったときに同じ余りが残る場合を含めます。`3`そしてによって`5`。 それぞれの数値を生成して条件をチェックする代わりに、そのような数値がいくつ存在するかを計算するだけで済みます。 入力は複数のテスト ケースで構成され、それぞれが 1 つの整数を持ちます。`n`、出力は、条件を満たす数値の数を表すテスト ケースごとの 1 つの整数です。 

の境界`n`まで行く`10^9`、まであるかもしれません`10^4`テストケース。 までのすべての数値を反復する単純なアプローチ`n`まで必要になります`10^9`テストケースごとの操作が遅すぎます。 そのため、すべての数値をシミュレートするのではなく、数式やパターンを見つける必要があります。 

明らかではないエッジケースが発生するのは次の場合です。`n`よりも小さいです`3`または`5`。 たとえば、`n = 0`、 のみ`0`条件を満たし、カウントが得られます。`1`。 別のエッジケースが発生するのは次の場合です。`n`の倍数のすぐ下にあります`15`有効な数値のパターンは毎回繰り返されるため、`15`数字。 不用意に実装すると、最後のブロックを正しく含めることができない可能性があります。 

## アプローチ

 ブルートフォースアプローチは次のように繰り返されます。`0`に`n`そして各整数をチェックします`i % 3 == i % 5`。 これは正しいですが、遅すぎます`n`まで`10^9`。 操作数は次の数に達する可能性があります`10^9 * 10^4`最悪の場合、それは不可能です。 

重要な観察点は、次のような条件です。`i % 3 == i % 5`定期的に発生します。 次の最小公倍数`3`そして`5`は`15`, したがって、このシーケンスは 15 個の数字ごとに繰り返されます。 15 個の数字の各ブロック内で、正確な数字`0, 1, 2, 15, ...`満足する`i % 3 == i % 5`。 最初のブロックを調べると、次のことがわかります。`0, 1, 2`それを満足させます。 したがって、どのような場合でも、`n`、15 の完全なブロックがいくつ収まるかを計算できます。`[0, n]`そして余分な数がいくつ残っているかを調べて、その残りの中で条件を満たす数を数えます。 

これにより、問題は単純な整数演算、つまり除算、剰余、乗算に縮小されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n) | お(1) | 遅すぎる |
 | ブロックカウント | テスト ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`。 
2. 完全な 15 桁のブロックがいくつ存在するかを計算します。`[0, n]`整数除算を使用する:`full_blocks = n // 15`。 
3. ブロック全体の外側の残りの数値を計算します。`remainder = n % 15`。 
4. 各完全なブロックが貢献します`3`有効な数値 (`0, 1, 2`ブロック内）。 乗算する`full_blocks * 3`。 
5. 剰余ブロックが寄与する`min(remainder + 1, 3)`どのブロックでも最初の 3 つの数値のみが条件を満たすため、有効な数値です。 
6. フルブロックからの寄与を合計し、残りを計算して答えを求めます。 
7. テスト ケースの結果を印刷します。 

**機能する理由:** 条件`i % 3 == i % 5`15 個の数字ごとに繰り返します。 15 桁の数字ブロック全体を数え、残りを慎重に処理することで、条件を満たすすべての数字を 1 回正確に数えることが保証されます。 これにより、正しいカウントを提供しながら、すべての数値の反復処理が回避されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        full_blocks = n // 15
        remainder = n % 15
        count = full_blocks * 3 + min(remainder + 1, 3)
        print(count)

if __name__ == "__main__":
    solve()
```コードは高速 I/O を使用してすべてのテスト ケースを効率的に読み取ります。 計算では、整数の除算とモジュロを使用して、完全な 15 桁のブロックと残りの数値を計算します。`min(remainder + 1, 3)`剰余ブロックで最大 3 つの数値のみをカウントするようにします。 これにより、次のような境界での間違いを回避できます。`n`15の倍数をわずかに下回ります。

 満足のいく数字`i % 3 == i % 5`は`0, 1, 2`。

 ## 特殊なケース

 のために`n = 0`、アルゴリズムは正しく返します`1`なぜなら、ただ`0 % 3 == 0 % 5`。 のために`n = 14`、14 の剰余ブロックは最初の 3 つの数値のみを正しくカウントします。 のために`n`15 の倍数 (例: 15) に等しい場合、この式は余りから 1 つの余分な数値を加算し、手動で数えることと一致して、正確に 4 つの数値を与えます。 パターンが 15 個の数値ごとに繰り返されるという不変条件により、すべてのエッジ ケースにわたる正確性が保証されます。
