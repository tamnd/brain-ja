 ## 解決策
 ## 問題の理解

 2 種類の要素のみから構築された配列を操作するように求められます。`1`そして`-1`。 各テスト ケースは、それぞれのテスト ケースの数を指定します。`x`ものと`y`マイナスのもの。 配列には、これらの要素を任意に並べたものを使用できます。 次に関数を定義します`f(a)`これは、すべてのサブ配列の合計が同じになるように配列を連続したサブ配列に分割する方法の数をカウントします。 私たちの目標は、最小化する配列を構築することです。`f(a)`そしてその最小値を法として計算します`676767677`。 

問題は微妙です。`1`と`-1`s は、存在する等和パーティションの数に直接影響します。 たとえば、同じ番号のブロックは、多くの場合、可能なパーティションの数を増やしますが、交互に配置されます。`1`そして`-1`それを減らすことができます。 モジュロは計算後にのみ関係します`f(a)`; モジュロを最小化しているのではなく、実際の`f(a)`。 

制約を考慮すると、テスト ケースごとの配列の合計長は次のとおりです。`4 * 10^5`ただし、すべてのテスト ケースを合計すると、要素の数は次のように制限されます。`2 * 10^5`両方にとって`x`そして`y`。 これにより、テスト ケースごとに効果的に線形なアルゴリズムが可能になります。 すべてのパーティションを明示的に試行するアプローチは指数関数的であり、完全に実行不可能です。 

次のいずれかの場合に、明白ではないエッジケースが発生します。`x`または`y`はゼロです。 たとえば、次の場合`x=0`そして`y=3`、配列は`[-1, -1, -1]`、 そして`f(a)`この同種の配列を等しい合計を持つ部分配列に分割する方法をカウントします。 配列が常に混合されていると仮定する単純なアプローチは失敗します。 

## アプローチ

 ブルートフォースアプローチでは、次のすべての順列を生成しようとします。`x`ものと`y`次に、順列ごとに、サブ配列に分割するすべての方法を試し、すべてのサブ配列の合計が等しいものだけをカウントします。 これは原理的には正しいですが、まったく現実的ではありません。 長さの単一の配列を生成する場合でも`4*10^5`階乗変換が多く、パーティションのカウントは指数関数的です。 明らかに、ブルート フォースは長さが 1 または 2 の配列に対してのみ機能します。 

重要な観察点は、最小限の`f(a)`これは、合計が等しい非自明な部分配列分割が不可能となるように配列が配置されている場合に達成されます。 これは、配列が交互に切り替わるときに発生します。`1`そして`-1`できるだけ均等に。 つまり、最小限に抑えるためには、`f(a)`をインターリーブする必要があります。`1`と`-1`s 重要なプレフィックスの合計が他のサブ配列とは異なり、単純な完全配列パーティションのみが残るようにします。 これにより、`f(a) = 1`いつ`x != y`そして`f(a) = 2`すべての要素が同じ場合。 

すべての数値が等しい場合、同じ要素の合計を持つ連続したチャンクへの分割は有効であり、値が増加します。`f(a)`に`length of array`プラス1。 それ以外の場合、インターリーブにより、可能なパーティションが大幅に制限されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((x+y)!) | O(x+y) | 遅すぎる |
 | 最適 (建設的な交互) | O(x+y) | O(x+y) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`x`そして`y`。 
3. もし`x == 0`または`y == 0`、すべての数字は同じです。 セット`f(a) = x + y`可能なすべてのパーティションが必要だが、最低限保証されるのは`2`長さが 1 以上の配列の場合。 配列を次のように構築します`x`続いてのもの`y`マイナスのもの。 
4. 両方の場合`x`そして`y`がゼロ以外の場合は、以下を交互に配置して配列を配置します。`1`そして`-1`できるだけ。 から始める`1`もし`x >= y`それ以外の場合は次から始めます`-1`。 
5. 配列の残りの部分に、残っているタイプの残りの要素を入力します。 
6. 両方の配列の場合`1`そして`-1`、`f(a)`になる`1`なぜなら、自明ではない等和部分配列の分割が存在しないからです。 
7. 最小限のものを印刷します`f(a)`モジュロ`676767677`そして構築された配列。 

なぜ効果があるのか​​: 交互に行うことで`1`と`-1`■ 接頭辞の合計は、エンドポイントを除いて配列内で決して繰り返されないため、複数の等和サブ配列の分割が防止されます。 これにより、`f(a)`最小限まで、つまり`1`。 同種配列の場合、削減する唯一の方法は`f(a)`は単純なパーティションです。配列全体を取得するか、各要素を個別に分割して、次のようにします。`f(a) = 2`。

def solve():
    t = int(input())
    for _ in range(t):

        if x == 0 or y == 0:
            # all identical numbers

            print(2)
            if x:

            else:

        else:

            res = []
            ones, negs = x, y

                    res.append(1)
                    ones -= 1

                        negs -= 1
                    else:

```このソリューションは、各テスト ケースを読み取り、配列が均一であるかどうかをチェックします。 同種の配列は次のように出力されます。`f(a)=2`そしてすべて同一の要素。 混合配列は交互に構築されます。`1`と`-1`複数のサブ配列の分割を防止し、`f(a)=1`。 変更後に残った要素を拡張すると、すべての要素が確実に含まれます。`x+y`要素。
