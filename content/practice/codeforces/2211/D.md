 ## 解決策
 ## 問題の理解

 隠し配列が与えられています`a`長さの`n`。 見る代わりに`a`直接、シーケンスが提供されます`b`各要素が`b_k`すべてのビット単位の AND の合計です。`k`-要素のサブシーケンス`a`、モジュロ`10^9 + 7`。 私たちのタスクは、有効な配列を再構築することです。`a`これらの合計を満たすもの。 

入力は複数のテスト ケースで構成されます。 各テスト ケースが提供するのは、`n`と対応するシーケンス`b`。 出力は次のシーケンスになるはずです。`n`それぞれ以下の非負の整数`2^29`、与えられたものを生成します`b`AND 配列を計算するとき。 

制約により許可されるのは、`n`まで`10^5`すべてのテストケースにわたって。 すべてのサブシーケンスを明示的に計算するには、最大で合計する必要があります。`2^n`サブセットですが、これは不可能です。 これにより、素朴なアプローチが排除され、組み合わせ論と組み合わせたビットごとの AND 演算の構造を活用する必要があります。 

明らかではないエッジ ケースには、すべてが一致するシーケンスが含まれます。`b_k`はゼロです。 単純なアプローチでは、方程式を直接解いたり、多くの可能性を反復しようとしたりしますが、正しい順序は単純です。`[0, 0, ..., 0]`。 もう 1 つのエッジケースは次のような場合です`b`は、特定の 2 のべき乗をもつパスカルの三角形のように対称パターンを形成します。これは、各ビットを独立して処理しない解法を誤解させる可能性があります。 

## アプローチ

 ブルートフォースアプローチは、考えられるすべてのシーケンスを試すことです`a`それらの AND 配列を計算し、次と比較します。`b`。 のために`n = 1000`、これには大まかな評価が含まれます`2^1000`サブセット、それは不可能です。 長さのすべてのサブセットを生成する場合でも`k`固定用`k`非常に急速に増大する組み合わせ合計が必要です。 

重要な点は、ビットごとの AND 演算をビットごとに分析できることです。 最終的な各ビット`b_k`は、選択されたすべての要素にそのビットが存在するサブセットによって提供されます。 させて`cnt_j`の要素の数になります`a`だれの`j`-th ビットは 1 です。`j`-番目のビット`b_k`まさにその数です`k`-これらの要素サブセット`cnt_j`要素、すなわち、`C(cnt_j, k)`。 私たちが解決できるのは、`cnt_j`ビットごとに独立して。 各ビットが何回出現するかがわかったら、そのビットを次の要素に割り当てることができます。`a`恣意的に、それぞれを保証します`a_i`下に留まる`2^29`。 

これにより、問題は管理可能な組み合わせの問題に縮小されます。`C(cnt_j, k)`モジュロシーケンス`10^9 + 7`のために`cnt_j`与えられたものから`b`。 以来`n`≤ 10^5 および`b_i < 10^9 + 7`、このアプローチは実現可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * 2^n) | O(n) | 遅すぎる |
 | ビットごとの組み合わせ論 | O(n * 30) | O(n * 30) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`そしてそのシーケンス`b`。 
2. リストの初期化`a`ゼロの。 
3. 0 ～ 28 の各ビット位置を処理します。ビットの場合`j`の要素数を計算する必要があります。`a`このビットを設定してください。 この数字を`cnt`。 
4. シーケンスを使用する`b`を解決するための組み合わせ推論`cnt`。 具体的には、それぞれについて、`b_k`、ビットさんの貢献`j`は`C(cnt, k) << j`。 コンピューティング`cnt`合計が超過するように`k`マッチ`b_k`モジュロ`10^9 + 7`。 ずっと`b_k`十分に小さいので、最大のものから始めて貪欲に実行できます。`k`。 
5. 1回`cnt`わかっている場合は、ビットを割り当てます`j`最初に`cnt`の要素`a`。 
6. 29 ビットすべてに対して繰り返します。 すべてのビットを処理した後、配列は`a`構造上、すべての AND 和を満たします。 
7. 配列を出力する`a`。 

**機能する理由:** AND 演算では各ビットは独立しています。 の数`k`-element 特定のビットセットを持つ要素のサブセットは、まさに`b_k`そのビットから。 解決されたカウントに従ってビットを割り当てることにより、すべての`b_k`値は正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    import sys
    from math import comb
    t = int(input())
    for _ in range(t):
        n = int(input())
        b = list(map(int, input().split()))
        a = [0] * n
        
        for bit in range(29):
            counts = [0] * (n + 1)
            for k in range(n):
                counts[k + 1] = (b[k] >> bit) & 1
            
            # find how many elements have this bit
            cnt = 0
            while comb(cnt, n) % MOD != counts[n]:
                cnt += 1
            
            for i in range(cnt):
                a[i] |= (1 << bit)
        print(*a)

if __name__ == "__main__":
    solve()
```コードは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 0 から 28 までのビットを繰り返します。ビットごとに、そのビットを設定する要素の数が決定されます。 次に、配列要素間でビットを分配します。 貪欲なアプローチが機能するのは、問題によって解決策が存在することが保証されるためです。
