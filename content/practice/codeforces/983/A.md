 ## 問題の理解

 有理数が与えられている$p/q$そして、baseで書かれたときにその表現が有限であるかどうかを判断するように求められました$b$。 有限表現とは、ある時点の後に展開が停止し、それ以上の桁が必要なくなることを意味します。$1/2 = 0.5$10進数で。 

各クエリは 3 つの整数を与えます: 分子$p$、分母$q$、およびベース$b$。 タスクは展開を計算することではなく、展開が終了するかどうかを決定することだけです。 

制約は大きく、最大で$10^5$最大のクエリと値$10^{18}$。 これにより、除算をシミュレートしたり、桁ごとに表現を構築したりするアプローチは除外されます。 分母と基数が十分に大きいため、中間状態では任意精度の算術演算が必要になり、場合によっては多くの反復が必要となるため、クエリごとに 1 つの長い除算を行うことさえ実現不可能です。 

微妙な点としては、$p$表現の有限性とは無関係です。 例えば、$6/12$そして$1/2$どのベースでも同じ終了動作をします。 したがって、問題は根本的に$q$そして$b$、についてではありません$p$。 

端的なケースは、分数がすでに整数である場合に発生します。 たとえば、次の場合$p = 12$そして$q = 3$、結果は$4$、ベースに関係なく常に終了します。 素朴なアプローチでは、素因数を不必要に分析しようとする可能性がありますが、このケースは直ちに有限として分類される必要があります。 

もう 1 つの特殊なケースは、基数が縮小された分母のすべての素因数を共有する場合に発生します。 例えば、$1/3$基数 3 は有限であるため、$3$ベースを分割します。 10 進数では無限です。$3$分けない$2 \cdot 5$。

 ## アルゴリズムのチュートリアル

 各クエリを個別に処理します。 

1. まず計算によって端数を減らします。$g = \gcd(p, q)$そして設定$q \leftarrow q/g$。 

このステップでは、すべての共通因子を削除して、既約分母のみを分析します。 以前に共有された要因は部分的に相殺されるため、終了に影響を与えることはできません。 
2. から削除します$q$基底にも存在するすべての素因数$b$。 

繰り返し計算していきます$g = \gcd(q, b)$。 もし$g > 1$、分けます$q \leftarrow q/g$。 

これが機能する理由は、$\gcd(q, b)$どちらの数値も因数分解しなくても、共有素数の積を正確に抽出します。 
3. まで前の手順を繰り返します。$\gcd(q, b) = 1$。 その時点で、残りの要素はありません$q$～の力で生み出すことができる$b$。 
4. 決勝戦の場合$q$1 に等しい場合、分母は基数によって完全に吸収され、表現は終了します。 それ以外の場合、少なくとも 1 つの素因数は、$q$と互換性がありません$b$、拡張は無限になります。 

### なぜ効果があるのか

 有理数には基数に終端展開があります$b$まさに、分母を減じて累乗を割ったとき、$b$。 この条件は、分母のすべての素因数が次の要素にも現れなければならないと言うのと同じです。$b$。 gcd 除去プロセスを繰り返すことで、体系的に除去されます。$q$すべての要素は以下と互換性があります$b$。 何かが生き残ったとしても、それは決して掛け算では導入できない素因数です。$b$これにより、ベース拡張の残りが決して消滅しないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def solve():
    n = int(input())
    for _ in range(n):
        p, q, b = map(int, input().split())

        g = math.gcd(p, q)
        q //= g

        # remove all factors of q that are in b
        while True:
            g = math.gcd(q, b)
            if g == 1:
                break
            while q % g == 0:
                q //= g

        if q == 1:
            print("Finite")
        else:
            print("Infinite")

if __name__ == "__main__":
    solve()
```最初のステップでは、分数を最小項に減らし、無関係な要素を持ち込まないようにします。$p$。 次にループは、gcd を使用して分母と底の間の重複を繰り返し抽出します。これは、次の場合でも効率的です。$10^{18}$-サイズの数字。 

内側の除算ループが必要なのは、次の理由からです。$\gcd(q, b)$要素が複数回出現する可能性があるため、要素を完全に削除する必要があります。$q$再計算する前に。 これにより、各反復が厳密に削減されることが保証されます。$q$、無限ループを防ぎます。
