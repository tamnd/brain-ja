 ## 解決策
 ## 問題の理解

 私たちには、陸地または水域の、陸地で始まり陸地で終わる一連の直線的な場所が与えられています。 最初の場所から開始し、最後の場所に到達する必要があります。 隣接する土地の場所に無料で移動することも、任意の土地から後の土地にジャンプするごとに 1 回、ジャンプした距離に等しいコインを支払うこともできます。 タスクは、最後の土地に到達するために必要な最小コインを計算することです。 

入力は複数のテスト ケースを提供します。 各テスト ケースは場所の数を示します$n$0 と 1 の連続は水と土地を表します。 出力はテスト ケースごとに 1 つの整数であり、最小コイン コストを表します。 

制約は小さいです。$n$は最大 100 であり、テスト ケースは最大 100 個まで存在できます。 これは任意のことを意味します$O(n^2)$アルゴリズムは実行可能であり、さらに単純です$O(n)$直線的なパスは非常に速くなります。 高性能のデータ構造や複雑なグラフ アルゴリズムについて心配する必要はありません。 

すべての中間位置が水である場合、明らかではないエッジケースが発生します。 たとえば、入力の場合`1 0 0 0 1`、ステップバイステップで移動することは不可能であるため、最適なジャンプは 4 コインを消費してすべての水にまたがる必要があります。 もう 1 つの微妙なケースは、連続した土地がある場合です。 入力用`1 1 1 1`、最初から最後の場所まで 2 コインで「ジャンプ」できても、隣接する移動はすべて無料であるため、最適な戦略はコインを支払わないことです。 最初の土地と最後の土地の間を常にジャンプする単純な実装では、コストがかかりすぎます。 

## アプローチ

 ブルートフォースアプローチは、自由な隣接移動と水上ジャンプの料金の両方を考慮して、最初の土地の場所から最後の場所までの可能なすべての経路をシミュレートすることです。 これを再帰的に実装して、到達可能なすべての位置を計算し、最小限のコストを保存することができます。 最悪の場合の複雑さは次のとおりです。$O(n^2)$各テスト ケースでは、各ランドが他のすべてのランドにジャンプする可能性があるため、$n$場所。 この問題のサイズでは実行可能ですが、単純なシーケンスでは再帰は不要であり、エラーが発生しやすくなります。 

重要な洞察は、コストが土地間の連続する水域の長さによって完全に決まるという観察から得られます。 隣接する土地間の移動にはコストはかかりません。連続する海域を飛び越える場合には、飛び移った場所の数と同じだけのコストがかかります。 したがって、自由な動きを無視して、コインジャンプを使用して渡らなければならない連続する水セグメントの長さを合計するだけで済みます。 これにより、問題は単純な線形スキャンに縮小されます。つまり、配列を反復処理し、1 の間の 0 を数え、これらのカウントを合計します。 複雑な分岐グラフや隣接グラフを考慮する必要はありません。

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`coins`ゼロに。 これにより、強制的な水上ジャンプの合計コストが累積されます。 
2. インデックスを初期化する`i`0で。`i < n`、 前進`i`土地タイルまで (`1`）が見つかりました。 このステップでは、最初に土地のシーケンスを処理します。 
3. 陸タイルに着いたら、連続する水タイルを数えながら前方にスキャンします (`0`) 次の土地タイルに到達するまで。 させて`gap`2 つの土地の間にある水タイルの数になります。 
4.追加`gap`に`coins`。 これは、そのセグメントを飛び越えるのに必要な最小限のコインを表します。 
5.インデックスを移動する`i`次の土地に移動し、最後のタイルに到達するまで手順 3 ～ 4 を繰り返します。 
6. 出力`coins`このテストケースの答えとして。 

これが機能する理由は、2 つの土地の間にある連続した水のセグメントを飛び越える必要があり、そのコストが正確に水タイルの数であるためです。 Free adjacent moves on land do not contribute to the cost, so ignoring them does not change the total. This invariant guarantees correctness: each zero is counted exactly once for the mandatory jump it belongs to.

 ## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    coins = 0
    i = 0
    while i < n:
        if a[i] == 1:
            j = i + 1
            while j < n and a[j] == 0:
                j += 1
            if j < n:
                coins += j - i - 1
            i = j
        else:
            i += 1
    print(coins)
```まずテスト ケースの数を読み取り、それぞれを反復処理します。 アレイごとに`a`、左から右にスキャンします。 土地タイルに到達するたびに、間にある水タイルだけを数えて次の土地までの距離を測定し、それを加算します。`coins`。 続行する前に、カウントされたセグメントを完全にスキップします。 最後の場所は保証された土地であるため、境界処理は暗黙的に行われます。

    output = io.StringIO()
    sys.stdout = output

        n = int(input())
        a = list(map(int, input().split()))
        coins = 0
        i = 0
        while i < n:

                j = i + 1
                while j < n and a[j] == 0:
                    j += 1
                if j < n:
                    coins += j - i - 1
                i = j
            else:
                i += 1
        print(coins)
    return output.getvalue().strip()

# Provided samples

 ## 特殊なケース

 入力用`1 0 0 0 1`、アルゴリズムセット`i=0`陸上で、発見する`j=4`次の土地で計算する`gap = 4-0-1 = 3`そしてコインに追加されます。 索引`i`配列の終わりの 4 に移動します。 出力 3 は正しいです。 

連続した土地の場合、`1 1 1 1`、最初の着陸`i=0`につながる`j=1`(次の土地)、`gap=0`コインが追加されました。 それから`i=1`、次の着陸地`j=2`、`gap=0`。 ついに`i=2`、次の着陸地`j=3`、`gap=0`。 合計コイン = 0、自由な動きは正しく無視されます。
