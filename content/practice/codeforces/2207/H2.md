 ## 解決策
 ## 問題の理解

 私たちは、Bowser が選択した隠れた関数をリバース エンジニアリングするように求められます。 関数はかかります`n`整数入力であり、完全にネストされたものから構築されます。`min`そして`max`操作、各入力は次からの順序で 1 回だけ表示されます。`x1`に`xn`。 私たちの目標は、Bowser が新しい入力ベクトルを与えたときに出力を正しく計算できるように、関数について十分に識別することです。 

この対話により、それぞれのベクトルであるクエリを送信できるようになります。`n`整数を返し、関数値を受け取ります。 すべてのテスト ケースにわたって最大 10,000 のクエリを作成できます。`n`それ自体は最大 200 であり、次の合計は`n`すべてのテスト ケースでも ≤ 200 です。この限界は、クエリを実行できる十分なクエリがあることを意味します。`O(n^2)`しかし、それ以上に悪化すると、制限を超える危険があります。 各テスト ケースは個別の関数として考えることができ、隠れた組み合わせに関係なく機能する戦略を決定する必要があります。`min`そして`max`。 

単純なエッジ ケースは、すべての入力が等しいか、厳密に増加/減少している場合です。 たとえば、関数が次のような場合`min(max(x1,x2), max(x3,x4))`、昇順のシーケンスを入力すると、慎重に選択したパターンと同じ結果が得られる可能性があり、不注意なアルゴリズムによって関数が誤って分類される可能性があります。 関数が以下を交互に実行するときに、別の微妙なシナリオが発生します。`min`そして`max`ネストされたペア。 入力ベクトルの極値のみを比較すると、単純で貪欲なアプローチが誤解を招く可能性があります。 

## アプローチ

 最も単純な総当り的な方法は、次のすべての順列を試すことです。`min`そして`max`すべてのサブセットにわたる操作。 個別の有効な min-max 式の数は、次のように指数関数的に増加するため、これは実現不可能です。`n`。 すべてのツリーを生成する場合でも、`n`葉と内部`min/max`ノードは組み合わせ的に爆発的になります。 

重要な洞察は、min-max 関数が各入力変数に関して単調であるということです。 を除くすべての値が 1 である入力ベクトルを考慮すると、`xi = 10^9`、隠し関数が使用するかどうかに応じて、出力は最小値のままになるか、最大値にジャンプします。`max`または`min`特定のサブツリーで。 「単位ベクトル」(1 つの大きな値、残りは最小値) と「全最大ベクトル」(1 つの最小値を除くすべての大きな値) を戦略的にクエリすることにより、変数の相対的な順序付けと分割を推定できます。 基本的に、これにより問題は分割統治戦略に帰着します。変数のセットを再帰的に分割し、トップレベルの操作が正しいかどうかを検出します。`min`または`max`、各ブランチで再帰します。 

これが機能するのは、すべての min-max 式が葉が変数、内部ノードが変数であるバイナリ ツリーとして表現できるためです。`min`または`max`。 By probing extreme values in a controlled way, we can reconstruct the tree without enumerating all expressions.

 ## アルゴリズムのチュートリアル

 1. 変数インデックスのリストを初期化する`[1, 2, ..., n]`。 これは、最小-最大サブツリーを識別する必要がある変数の現在のセットを表します。 
2. すべての変数を 1 に設定して関数をクエリします。これにより、グローバル最小の出力が得られます。`min_value`。 
3. すべての変数を 10^9 に設定して関数をクエリします。 これにより、グローバルで可能な最大出力が得られます。`max_value`。 
4. 現在のサブツリーの最上位の演算子を検出するには、変数を 2 つの半分に分割します。 一方を最大に設定し、もう一方を最小に設定して、各半分をクエリします。 出力を比較します`min_value`そして`max_value`。 出力が次のようにジャンプした場合`max_value`、トップレベルの操作は次のとおりです。`max`; 近くに残っていたら`min_value`、トップレベルの操作は次のとおりです。`min`。 
5. 同じ戦略を左半分と右半分に再帰的に適用し、最小-最大二分木を単一変数まで再構築します。 
6. ツリーが再構築されたら、任意の入力に対する関数を計算するための情報を保存します。 Bowser のクエリ中に、ツリーをトラバースします。保存されているクエリを適用します。`min`または`max`各内部ノードでその子ノードの値に変換されます。 

機能する理由: Min-max 関数は単調で構造化されているため、極端な値を調べると階層的な操作が効果的に明らかになります。 再帰的分割により、各内部ノードの操作が他のノードから独立して識別され、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def query(values):
    print("?", *values)
    sys.stdout.flush()
    res = int(input())
    if res == -1:
        exit()
    return res

def build_tree(vars_list):
    if len(vars_list) == 1:
        return vars_list[0]
    left = vars_list[:len(vars_list)//2]
    right = vars_list[len(vars_list)//2:]
    left_vals = [1 if i in left else 10**9 for i in vars_list]
    right_vals = [1 if i in right else 10**9 for i in vars_list]
    res_left = query(left_vals)
    res_right = query(right_vals)
    if res_left > res_right:
        op = 'max'
    else:
        op = 'min'
    return (op, build_tree(left), build_tree(right))

def eval_tree(tree, values):
    if isinstance(tree, int):
        return values[tree-1]
    op, left, right = tree
    lval = eval_tree(left, values)
    rval = eval_tree(right, values)
    return max(lval, rval) if op == 'max' else min(lval, rval)

t = int(input())
for _ in range(t):
    n = int(input())
    tree = build_tree(list(range(1, n+1)))
    print("!")
    sys.stdout.flush()
    while True:
        line = input()
        if line.strip() == '0':
            break
        x = list(map(int, line.strip().split()))
        print(eval_tree(tree, x))
        sys.stdout.flush()
```ソリューションには 3 つの主要な部分があります。`query`関数は対話を管理し、出力をフラッシュします。`build_tree`極値クエリを使用して min-max 式を再帰的に再構築します。`eval_tree`再構築されたツリーを使用して入力を評価します。 インタラクターのタイムアウトを避けるために、出力のたびにフラッシュが確実に発生するように注意が払われます。 再帰の基本ケースは単一の変数であり、自明にその値を返します。
