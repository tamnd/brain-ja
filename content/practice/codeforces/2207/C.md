 ## 解決策
 ## 問題の理解

 2D 画像を無視して各列に独立して注目すると、グリッドをより簡単に理解できます。 列内`i`、 がある`a_i`一番下に土のタイル、その上の高さまでのすべてのタイル`h`水です。 したがって、列内の水タイルの数は`i`は`h - a_i`。 

水タイル上に配置された排水管は、洪水埋め立て領域をアクティブにします。その開始タイルから、水は隣接する水タイルにのみ広がりますが、移動は左、右、下に制限されます。 上への移動は不可能であるため、すべての接続された水領域は非常に特殊な構造を持っています。開始水タイルを選択すると、到達可能な領域全体がまさに最大の水の「盆地」となり、その下は土によってブロックされません。 

排水管の重要な効果は、水柱が「あるレベルで接続されている」連続した水平セグメントの柱にすべての水を集めるということです。 高さの観点から考えると、各柱は水の垂直セグメントに寄与し、接続性は隣接する柱が重複する水の高さを持っているかどうかによって決まります。 

タスクは、このような排水管を最大 2 つ配置し、それぞれが 1 つの接続された水コンポーネントを選択し、収集される個別の水タイルの総数を最大化することです。 2 つの排水管が重なり合う水をカバーする場合、それらのタイルは 1 回だけカウントされます。 

この制約により、ドレイン位置のすべてのペアに対するブルートフォースが不可能になります。 各テストには合計で最大 2000 列を含めることができるため、テスト ソリューションごとに 2 次以下の場合は慎重に制御する必要があり、フラッド フィルを最初から再計算することを伴うものは遅すぎます。 

微妙な問題は、重複を過剰にカウントすることです。 重なり合う領域または入れ子になった領域に配置された 2 つの排水管は、広い水域を共有できます。 交差部分をモデル化せずに 2 つの最良の独立したセグメントを選択するだけの単純なアプローチでは、答えが過大評価されてしまいます。 

たとえば、すべての列に`a_i = 1`、どの列にもほぼ満水の水が入っています。 どのドレインも基本的にグリッド全体に到達するため、2 つのドレインを配置しても 1 つ以上の利点はありません。 「最良のセグメントを 2 つ取得する」という貪欲なアプローチでは、誤って 2 重にカウントされてしまいます。 

## アプローチ

 強引な方法では、考えられるすべての排水位置を試します。 排水位置は任意の水タイルですが、各位置が接続された水域を定義するため、代わりに任意の開始セルを選択し、その到達可能な水域をフラッドフィルによって計算することを考えることができます。 すべてのセルに対してこれを行うとすでに大きすぎます。`O(nh)`考えられる開始点、および各塗りつぶしにかかる時間`O(nh)`最悪の場合、明らかに実行不可能な結果が得られる`O(n^2 h^2)`行動。 

各柱の「最上部の水セル」のみに限定したとしても、各コンポーネントの形状はさまざまな高さによる水平方向の伝播に依存し、柱をグローバルに結合するという問題に依然として直面します。 

重要な構造的観察は、各排水管が本質的に柱の水平間隔の選択に対応しており、その間隔内での制限要因が排水管全体にわたる最小の「水高プロファイル」であるということです。 列で水の高さを定義すると`i`として`b_i = h - a_i`の場合、排水管から到達可能な接続領域は、有効水深が最小値によって支配されるセグメントのように動作します。`b_i`そのセグメントで。 これにより、問題は区間に関する推論と、和集合の重複を伴​​う 2 つの区間の結合に変わります。 

したがって、問題は、最大 2 つの区間を選択することになります。各区間の値は、区間内の最小の高さの関数によって決まり、和集合の寄与の合計を最大化します。 これは、単調なスタック構造と組み合わせた分割統治またはインターバルにわたる DP が効率的なソリューションを提供する古典的な設定です。 

すべての間隔に対して構造化された方法で最良のシングルドレイン寄与を計算し、重複部分を慎重に差し引きながら 2 つの間隔を結合します。 重なりの処理が最も大きな問題であり、プレフィックス/サフィックスの最適値と事前計算された間隔ゲインを使用して、互いに素なコントリビューションまたは適切にマージされたコントリビューションのみを結合することを保証することで解決されます。

 ## アルゴリズムのチュートリアル

 補完的なビューに切り替えます。各列が貢献します。`b_i = h - a_i`水の単位。 

1. 水位の高さを事前計算する`b_i`。 これにより、問題は、値が列ごとの水の容量を表す 1D 配列で完全に処理されるように変換されます。 
2. シングルドレインの最良の答えを計算します。 単一のドレインは、最大接続領域を効果的に捕捉します。これは、寄与がセグメント内の最小値とその幅の積によって決定されるセグメントを選択することに対応します。 これは、次のように定義されたヒストグラムの下で最適な長方形を見つけることと同じです。`b_i`。 
3. 単調スタックを使用して、位置ごとに最大のセグメントを計算します。`b_i`は最小限です。 それぞれについて`i`、値がそれ以上にとどまる左右の境界を決定します。`b_i`。 これにより、列の最大間隔が得られます。`i`水の高さを支配します。 
4. 以下を使用して、そのような間隔ごとに最適な長方形の値を計算します。`b_i * (r - l + 1)`。 最大値を追跡します。 これは 1 回のドレインでの最良の結果です。 
5. ここで、2 つの排水管が必要になります。 配列を左側と右側の部分に分割し、すべてのプレフィックスとサフィックスについて可能な限り最良の単一ドレインの答えを計算します。 させて`left_best[i]`列のみを使用して最良の回答にする`[1..i]`、 そして`right_best[i]`同様に`[i..n]`。 
6. 最適な 2 つのドレイン構成は、両方のドレインを完全に分離領域に配置するか、最適なソリューションでは、何らかの境界で効果的に分割する構造を使用します。 それで評価します`left_best[i] + right_best[i+1]`全体`i`。 
7. 最良の単一ドレインの答えとすべての分割の組み合わせの中の最大値を返します。 

### なぜ効果があるのか

 各ドレインは、変換された配列内の最大のヒストグラム四角形の選択に対応します。`b_i`。 2 つのドレインを備えた最適なソリューションは、結合が最適な 2 つの領域に分解できます。また、重複するタイルは 1 回カウントされるため、重複しても限界ゲインが減少するだけです。 したがって、最適な構成は、結果を低下させることなく常に 2 つの互いに素な寄与区間に再配置でき、境界で配列を分割し、プレフィックスとサフィックスの最適値を組み合わせることが正当化されます。 

単調スタックは、すべての最大の四角形が 1 回だけ考慮されることを保証し、シングル ドレイン計算の正確性を保証します。一方、プレフィックス サフィックス DP は、すべての有効な 2 ドレイン パーティションがカバーされることを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, h = map(int, input().split())
        a = list(map(int, input().split()))
        b = [h - x for x in a]

        # monotonic stack for largest rectangle histogram
        left = [0] * n
        right = [0] * n

        stack = []
        for i in range(n):
            while stack and b[stack[-1]] >= b[i]:
                stack.pop()
            left[i] = stack[-1] + 1 if stack else 0
            stack.append(i)

        stack = []
        for i in range(n - 1, -1, -1):
            while stack and b[stack[-1]] > b[i]:
                stack.pop()
            right[i] = stack[-1] - 1 if stack else n - 1
            stack.append(i)

        best_single = 0
        for i in range(n):
            area = b[i] * (right[i] - left[i] + 1)
            if area > best_single:
                best_single = area

        # prefix best
        pref = [0] * (n + 1)
        for i in range(1, n + 1):
            pref[i] = max(pref[i - 1], b[i - 1] * (i - left[i - 1] + 1) if i - 1 >= 0 else 0)

        # suffix best
        suf = [0] * (n + 2)
        for i in range(n - 1, -1, -1):
            suf[i] = max(suf[i + 1], b[i] * (right[i] - i + 1))

        ans = best_single
        for i in range(n + 1):
            ans = max(ans, pref[i] + suf[i])

        print(ans)

if __name__ == "__main__":
    solve()
```この実装では、まず高さを水の容量に変換し、次に単調スタックを使用して、各インデックスが限界最小値となる最大間隔を計算します。 プレフィックス配列とサフィックス配列は、すべての分割ポイントを効率的に列挙できるように構築されています。 最後のループでは、すべてのパーティション境界を試し、両側で最適なソリューションを組み合わせます。 

最もデリケートな部分は、スタックポップにおける厳密な不等式の選択です。 使用する`>=`左側のパスと`>`正しいパスでは、同じ高さでも一貫したハンドリングが保証され、各レックが確実に行われます。
