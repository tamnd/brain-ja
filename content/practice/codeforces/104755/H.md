 ## 解決策
 ## 問題の理解

 平面内の直線の集合が与えられます。 すべての行は、次の 3 つの特別な方向のいずれかであることが保証されます: フォームの水平線$y = c$、フォームの縦線$x = c$、およびフォームの斜線$x + y = c$。 すべての定数$c$は整数であり、すべての行は個別です。 

タスクは、三角形の各辺が完全に指定された線上の 1 つに位置するように、縮退していない三角形をいくつ形成できるかを数えることです。 有効な三角形は、3 本の直線のペアの交点が 3 つの異なる点を形成する 3 本の直線を選択することによって決定されます。これにより、これらの点は、3 本の直線すべてが 1 点で交わるか、または 3 本の直線のうち 2 つが平行になるような縮退した構成ではなく、適切な三角形を形成します。 

主要な構造上の制約は、エッジが指定された線上に正確に存在するように制限されていることです。つまり、すべての三角形は、各辺に 1 つずつ、3 本の線を選択することに対応し、これら 3 本の線が 3 つの異なる点でペアで交差するという要件があります。 

バウンド$n \le 3000$あらゆるものを即座に除外します$O(n^3)$トリプル行の列挙。 平$O(n^2)$境界線にありますが、各ペアが一定時間で処理される場合には実現可能です。 ライン ファミリの構造は、任意の交差についての推論を避け、代わりに 3 つの方向のみが存在するという事実を利用する必要があることを強く示唆しています。 

微妙な問題は、同時実行によって引き起こされる縮退です。 3 本の線が 1 点で交わる場合があります。これは、たとえば、水平線、垂直線、対角線が共通の交点を共有する場合に発生します。 もう 1 つの失敗例は、平行で三角形の辺のペアを形成できない、同じ方向の 2 本の線分を選択した場合です。 

たとえば、$y = 0$、$x = 0$、 そして$x + y = 0$、3 本の線はすべて原点で交わるので、有効な線が 3 本ありますが、それらは三角形を形成しません。 個別の頂点を強制せずにペアごとの交差のみをチェックする単純なカウント手法では、そのような構成を過剰にカウントすることになります。 

## アプローチ

 直接的なブルート フォース ソリューションでは、すべてのトリプル ラインを反復処理し、それらが有効な三角形を形成しているかどうかをテストします。 各トリプルについて、3 つのペアごとの交点を計算し、それらがすべて異なるかどうかを確認します。 どの三角形も 3 本の線から生じなければならないため、これは概念的には単純で正しいです。 

ただし、トリプルの数は、$\binom{n}{3}$、それは約です$4.5 \times 10^9$いつ$n = 3000$。 非常に高速な交差計算を行ったとしても、これは 0.25 秒の許容範囲をはるかに超えています。 

重要な観察は、ジオメトリが高度に構造化されていることです。 方向は 3 つしか存在しないため、三角形は正確に 1 本の水平線、1 本の垂直線、1 本の対角線で構成されなければなりません。 他の組み合わせは不可能です。2 本の平行線は交わることができないため、2 本の水平線、2 本の垂直線、または 2 本の対角線があっても、閉じた三角形の境界を形成することはできません。 

各種類の線を 1 つに制限すると、交点が完全に決まります。 水平線$y = h$、縦線$x = v$、および対角線$x + y = d$ペアごとに交差します:$(v, h)$、$(d - h, h)$、 そして$(v, d - v)$。 これら 3 つの線がすべて同じ点で交わらない限り、これら 3 つの点は三角形を形成します。これは、まさに次の場合に起こります。$h + v = d$。 この条件により、すべての交差点が単一点に崩壊し、縮退した三角形が生成されます。 

したがって、問題はトリプルを数えるということになります。$(H, V, D)$そのような$h + v \ne d$。 

1 本の水平線、1 本の垂直線、1 本の対角線のすべてのトリプルを数えて、次のような縮退ケースを差し引くことができます。$h + v = d$。 最初の部分は単純に$|H| \cdot |V| \cdot |D|$。 2 番目の部分は、ペアを反復処理することで計算できます。$(h, v)$値のある対角かどうかを確認します$h + v$存在します。 

これにより、問題は最大 3000 の値にわたる頻度をカウントするタスクに変わります。

 | トリプルに対するブルートフォース |$O(n^3)$|$O(1)$| 遅すぎる |
 | タイプ + ハッシュによるカウント |$O(n^2)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 入力線を水平線、垂直線、対角線の 3 つのグループに分けます。 また、定数時間でメンバーシップをテストできるように、対角定数の周波数配列またはハッシュ セットも維持します。 

1. すべての行を読み取り、水平定数をリストに保存します$H$、リスト内の垂直定数$V$、ブール配列またはセット内の対角定数をマークします$D$。 この前処理により、後で存在を迅速にチェックできるようになります。 
2. 各ファミリーから 1 つのラインを選択して形成されるトリプルの合計数を計算します。 これは$|H| \cdot |V| \cdot |D|$。 このようなトリプルはすべて、縮退を考慮する前の三角形の候補です。 
3. すべてのペアを反復処理します。$(h, v)$どこ$h \in H$そして$v \in V$。 各ペアについて計算します$s = h + v$。 もし$s$対角集合に存在し、次にトリプル$(h, v, s)$は退化しているため、除外する必要があります。 
4. 前に計算した合計積から、そのような縮退トリプルの数を引きます。 それぞれ有効$(h, v)$厳密に 1 つの禁止対角に寄与するため、オーバーカウントは発生しません。 
5. 最終的な補正後のカウントを出力します。 

重要な考え方は、縮退は完全な交差の計算を必要とする幾何学的特性ではなく、純粋に 3 つの直線パラメータを結び付ける代数的等式条件であるということです。 

### なぜ効果があるのか

 平行線は三角形の辺を形成できないため、有効な三角形はすべて、各方向の 1 本の線を使用する必要があります。 固定の水平方向が与えられると、$y = h$そして垂直$x = v$、交点は強制的に次のようになります。$(v, h)$、三角形を崩壊させるには、対角線がこの点を通過する必要があります。 それは次の場合にのみ起こります$h + v = d$。 このような各ペアは、正確に 1 つの対角定数を識別するため、これらのケースを減算すると、縮退した構成のみがすべて削除されます。 一致しないトリプルは 3 つの異なるペアごとの交差を生成するため、他の縮退は存在しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    H = []
    V = []
    D = [0] * 6005  # since c up to 3000, sums up to 6000

    hasD = set()

    for _ in range(n):
        d, c = input().split()
        c = int(c)
        if d == 'H':
            H.append(c)
        elif d == 'V':
            V.append(c)
        else:
            hasD.add(c)

    total = len(H) * len(V) * len(hasD)

    bad = 0
    for h in H:
        for v in V:
            if (h + v) in hasD:
                bad += 1

    print(total - bad)

if __name__ == "__main__":
    main()
```この実装は、カウントのアイデアを直接翻訳したものです。 3 つのリストに分割することで、互換性のない方向が混在することがなくなります。 対角セットを使用すると、トリプルが縮退するかどうかをテストするときに、定数時間のメンバーシップ チェックが可能になります。 

微妙な点は、それぞれ$(h, v)$ペアはちょうど 1 つの対角値に対応します$h+v$したがって、悪いケースのカウントは線形です。$|H| \cdot |V|$対角線を越えて検索する必要はありません。 

## 実用的な例

 小規模な構成を考えてみましょう。 

入力:```
H 0
V 0
D 0
D 1
```ここ$H = \{0\}$、$V = \{0\}$、$D = \{0,1\}$。 

| h | v | h+v | Dで| 悪い |
 | --- | --- | --- | --- | --- |
 | 0 | 0 | 0 | はい | 1 |

 トリプルの合計 =$1 \cdot 1 \cdot 2 = 2$。 悪い = 1。答え = 1。 

これは、対角線のみが$x+y=0$変性を引き起こします。 

ここで次のことを考えてみましょう。 

入力:```
H 1
H 2
V 3
D 10
```ここ$H = \{1,2\}$、$V = \{3\}$、$D = \{10\}$。 

トリプルの合計 =$2 \cdot 1 \cdot 1 = 2$。 

| h | v | h+v | Dで| 悪い |
 | --- | --- | --- | --- | --- |
 | 1 | 3 | 4 | いいえ | 0 |
 | 2 | 3 | 5 | いいえ | 0 |

 どの和にも一致する対角がないため、答えは 2 のままです。 

これらのトレースは、縮退が等価条件によって完全に捕捉されていることを確認します。$h+v=d$。

 ## 特殊なケース

 主なエッジケースは、水平線と垂直線のすべてのペアが対角線と一致する場合です。 たとえば、次の場合$H = \{0,1\}$、$V = \{0,1\}$、対角線にはすべての合計が含まれます$\{0,1,2\}$の場合、すべてのペアが縮退構成を生成します。 アルゴリズムは、ペアごとに 1 つだけ減算し、すべての三角形を削除することでこれを処理します。 

もう一つのケースは、対角線が存在しない場合です。 この場合、set チェックは常に失敗するため、減算は行われず、答えは単純です。$|H| \cdot |V| \cdot 0 = 0$これは、3 つの方向すべてがなければ三角形は形成できないことを正しく反映しています。 

最後のコーナーケースは、存在する方向が 3 つ未満の最小限の入力です。 積項はすでにゼロになっているため、アルゴリズムは特別な処理を行わなくても自然にゼロを返します。
