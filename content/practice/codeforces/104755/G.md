 ## アルゴリズムのチュートリアル

 1. すべてのサブセットのサブセット合計を事前計算します。$A$。 マスクごとに合計を計算します$S(\text{mask})$。 これが必要なのは、実現可能性はモジュロの半和条件が満たされるかどうかのみに依存するためです。$n$。 
2. DP テーブルを構築する`dp[mask][r]`サブセット合計到達可能性モジュロの場合$n$。 値`dp[mask][r] = true`署名された割り当てが存在することを意味します`mask`残留物を生成する$r$。 トランジションは各要素を次のいずれかとして追加します。$+a_i$または$-a_i$、剰余モジュロを更新$n$。 
3. サブセットをマークする`mask`可能な限り`dp[mask][0]`それは本当です。 これは、合計を次の倍数にする符号割り当ての存在を直接エンコードします。$n$。 
4. 最小限性を強制するには、基数の昇順でサブセットを処理します。 配列を維持する`good[mask]`サブセットに、より小さい実現可能なサブセットが含まれることがすでにわかっているかどうかを示します。 
5. サブセットが実行可能であるが、マークされていない場合`good`、それは最小限のソリューションとしてカウントされます。 次に、そのすべてのスーパーセットは暗黙的に最小であることが失格となるため、マークをすべてのスーパーセットに伝播します。 
6. 伝播はビットマスク上のサブセット DP を使用して効率的に実装され、未使用の要素を追加することでマスクを拡張します。 これにより、各マスクが必要な場合にのみ更新されるようになります。 
7. 最終的な答えは、より小さな実現可能なサブセットによって支配されない実現可能なマスクの数です。 

### なぜ効果があるのか

 包含下では実現可能性は単調です。要素を追加しても、有効な符号割り当ての存在が破壊されることはありません。これは、いつでも新しい要素に任意の符号を割り当て、内部でペアにすることでそれらを無視できるためです。 これにより、実行可能なサブセットのファミリーが上向きに閉じられます。 したがって、最小実現可能サブセットは、包含順序の下でまさにこの上向きに閉じられた族の最小要素です。 サイズを増やしながらサブセットを処理すると、サブセットが最初に実行可能として検出されたときに、既に処理されていない限り、その中に小さい実行可能なサブセットが存在しないことが保証されるため、スーパーセットにマークを付けることで、二重にカウントすることなく正確さが維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    N = 1 << m

    # dp[mask] = set of reachable residues using ± signs
    dp = [set() for _ in range(N)]
    dp[0].add(0)

    for mask in range(N):
        for i in range(m):
            if not (mask >> i) & 1:
                for r in dp[mask]:
                    dp[mask | (1 << i)].add((r + a[i]) % n)
                    dp[mask | (1 << i)].add((r - a[i]) % n)

    feasible = [False] * N
    for mask in range(N):
        if 0 in dp[mask]:
            feasible[mask] = True

    # minimality filtering
    good = [False] * N
    masks_by_size = sorted(range(N), key=lambda x: bin(x).count("1"))

    ans = 0
    for mask in masks_by_size:
        if not feasible[mask]:
            continue
        if good[mask]:
            continue
        ans += 1
        # mark all supersets
        for sup in range(N):
            if (sup | mask) == sup:
                good[sup] = True

    print(ans)

if __name__ == "__main__":
    solve()
```このソリューションは、ビットマスク DP を使用して、各サブセットの到達可能なすべての符号付き合計を構築します。 各遷移は、現在の要素のモジュロを加算または減算します。$n$。 サブセットは、残基 0 が到達可能な場合にのみ実行可能です。 

最小性は、サブセットをサイズの小さい順に処理することによって強制されます。 実行可能なサブセットがカウントされると、すべてのスーパーセットが無効化されるため、後でカウントすることはできません。 

主な微妙な点は、符号付きサブセットの合計が到達可能性の問題として解釈されることです。$\mathbb{Z}_n$これにより、符号の割り当てを明示的に列挙する代わりに動的プログラミングが可能になります。

 ## 特殊なケース

 重要なエッジ ケースは、単一の要素が 0 モジュロに等しい場合です。$n$。 その場合、それを含むシングルトン サブセットはすぐに実行可能になり、そのスーパーセットはすべて非最小になります。 そのサブセットの DP にはシングルトン レベルで残基 0 が含まれるため、アルゴリズムはこれを正しく処理します。
