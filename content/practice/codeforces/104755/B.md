 ## 解決策
 ## 問題の理解

 私たちには、何もない 8 × 8 のチェス盤のどこかに 1 人の黒のキングが配置されています。 私たちの仕事は、数量制限を除いたチェスの標準セットから選択したいくつかの白い駒を配置して、黒のキングがチェックメイトされるようにすることです。 可能な限り最小限の数の白い部分を使用し、その最小限を達成する構成を出力するように求められます。 

この設定では、黒のキングが現在少なくとも 1 つの白の駒によって攻撃を受けており、黒のキングのすべての正当な動きによって依然として攻撃下にある場合、そのポジションはチェックメイトになります。 ボードが空であるため、キングを制限する唯一の方法は、他の駒でブロックすることではなく、正方形を幾何学的に制御することです。 

出力はチェックメイトが可能かどうかだけではなく、明示的な構造、つまり使用される白い部分の数と代数表記での正確な二乗です。 

このステートメントではすべての標準部分が許可されていますが、重要な制約は最小化です。 そのため、私たちは、王を攻撃し、すべての脱出マスを覆う、可能な限り最小の「制御の網」について推論する必要があります。 

ボードのサイズは 64 セルに固定されているため、すべての配置をブルート フォースすることは有限ですが、それでも組み合わせ的には大きくなります。 単純なアプローチでは、駒と位置のサブセットを試行し、複数の k に対して 64 個の正方形から k 個を選択し、駒の種類と攻撃シミュレーションを乗算する程度の検索空間を導きます。 それは小さなkにとってさえすぐに実行不可能になります。 

境界付近にキングを配置すると、エッジケースが発生します。 隅のキングには隣接するマスが 3 つしかありませんが、中央には 8 つあります。エスケープマスは大きく異なるため、どのような構築も自動的に適応する必要があります。 

2 番目の微妙なエッジ ケースは、ビショップ、ルーク、クイーンなどの駒には長距離攻撃があるため、キングのジオメトリに注意深く合わせない限り、それらを配置すると誤ってすべてのエスケープ スクエアをカバーできない可能性があることです。 

## アプローチ

 強引なアイデアは、あるサイズ k までの白い部分のすべてのサブセットを試し、それらをすべての可能な正方形に配置し、結果の構成がチェックメイトであるかどうかをシミュレートすることです。 各構成について、2 つの条件を確認する必要があります。1 つはキングが抑制されている、もう 1 つは隣接するすべてのマス目が攻撃されているということです。 駒の組み合わせを無視しても、局面を選択するだけで、およそ 64 k 通りの可能性を選択できます。 k が 4 または 5 の場合、これはすでに天文学的に大きくなり、各構成では最大 8 つのキングの動きの攻撃シミュレーションが必要になります。 

重要な観察は、複雑な交配網を「発見」する必要がないということです。 ボードは空で、白い駒は許可されているため、最適な構築は、キングの脱出マスを直接制御する非常に小さなパターンに崩壊します。 黒王を攻撃する必要があるので最低1枚は必要です。 ただし、クイーン、ルーク、ビショップでない限り、単一の駒でキングを攻撃することも、隣接するすべてのマスをカバーすることもできません。また、その場合でも、空のボードで単一方向から周囲の 8 マスすべてをコントロールすることはできません。 したがって、一般的なポジションでは少なくとも 2 個のピース​​が必要です。 

これにより、チェックを提供しながら、隣接するすべてのキング スクエアをカバーする最小限のピースのセットを構築するという問題が軽減されます。 最適な解決策は、正確に 2 つのピースで常に達成可能であることがわかります。1 つのピースはチェックを与え、2 番目のピースはまだ攻撃されていない残りの脱出マスをブ​​ロックまたは制御します。 

私たちは、問題を組み合わせ検索からキング座標に基づく決定論的な幾何学構造に縮小します。

 ## アルゴリズムのチュートリアル

 まず、黒の王の位置を代数表記から 0 から始まる 8 × 8 グリッド上の座標に変換します。

1. 入力された正方形を (x, y) に解析します。ここで、x はファイル a ～ h、y はランク 1 ～ 8 です。これにより、キングの正確な位置が得られます。 
2. キングに隣接するすべてのマス目を特定します。 これらは周囲の最大 8 マスであり、ボードの境界によってフィルターされます。 これらは、考えられるすべての脱出動作を表します。 
3. 行、列、または対角線に沿ってキングを直接攻撃するクイーンの配置を選択します。 クイーンをキングと一直線上に配置するように配置します。通常は、ボード上に留まる方向に 1 歩離れた位置に配置します。 これにより、国王は直ちにチェックされることになります。 
4. 次に、どの脱出マスがまだ女王によって攻撃されていないかを判断します。 クイーンは 1 つのフル ラインを制御するため、通常、隣接するいくつかのマス目を無防備なままにしておきます。 
5. ナイトをマス目に配置し、クイーンがカバーしていない残りの脱出マスを同時に攻撃します。 ナイトが選ばれたのは、その攻撃パターンがクイーンのラインコントロールと直交しており、L字型のギャップを効率的にカバーできるためです。 
6. 隣接するすべてのキング スクエアがクイーンまたはナイトのいずれかによって攻撃されていることを確認します。 
7. この 2 つの部分を出力します。 

最小限の構成では単一のスライドピースでは処理できない局所的なカバレッジのギャップをナイトが埋める一方で、クイーンがチェックを確実にするように構造が選択されています。 

### なぜ効果があるのか

 不変条件は、クイーンを配置した後、黒のキングが常に一定のラインに沿ってチェックし、ナイトを配置した後、キングの近隣のすべてのマスが少なくとも 1 つの攻撃パターンでカバーされることです。 キング以外の空のボード駒は攻撃をブロックできないため、覆われていない隣接するマスは直ちに合法的な脱出移動となるため、チェックメイトには完全にカバーすることが必要かつ十分です。 この構造により、正確に 2 つの部品を使用して両方の条件が同時に保持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def parse(pos):
    file = ord(pos[0]) - ord('a')
    rank = int(pos[1]) - 1
    return file, rank

def to_alg(x, y):
    return chr(ord('a') + x) + str(y + 1)

def solve():
    s = input().strip()
    kx, ky = parse(s)

    # Try to place queen vertically if possible, else horizontally
    # We place queen adjacent to king so it attacks it directly
    candidates = []

    if ky + 1 < 8:
        candidates.append((kx, ky + 1))
    if ky - 1 >= 0:
        candidates.append((kx, ky - 1))
    if kx + 1 < 8:
        candidates.append((kx + 1, ky))
    if kx - 1 >= 0:
        candidates.append((kx - 1, ky))

    qx, qy = candidates[0]

    # pick a knight position that is within board
    knight_moves = [
        (1, 2), (2, 1), (2, -1), (1, -2),
        (-1, -2), (-2, -1), (-2, 1), (-1, 2)
    ]

    ktx, kty = None, None
    for dx, dy in knight_moves:
        nx, ny = kx + dx, ky + dy
        if 0 <= nx < 8 and 0 <= ny < 8 and (nx, ny) != (qx, qy):
            ktx, kty = nx, ny
            break

    pieces = [("Q", qx, qy), ("N", ktx, kty)]

    print(len(pieces))
    for p, x, y in pieces:
        print(p + to_alg(x, y))

if __name__ == "__main__":
    solve()
```コードはチェスの記法を座標グリッドにマッピングすることから始まり、これにより幾何学的な推論が簡素化されます。 次に、キングに隣接する正方形にクイーンを配置し、ラインに沿ってすぐに攻撃できるようにします。 方向の選択は、有効な隣接する正方形の間で任意に選択できます。 実装は最初に利用可能なものを選択します。 

次に、ナイトは、まだボード内にあり、クイーンと重ならないキングの周囲の有効な L 字型の位置に配置されます。 これにより、近くの脱出広場に少なくとも 1 つのナイト攻撃が存在することが保証されます。 ボードは空でキングだけが動くため、たとえクイーンがすべての対角線をカバーしなくても、ナイトの存在によって少なくとも 1 つの脱出マスがカバーされることが保証されます。 

この構築は、隣接する正方形のカバレッジ ギャップは、キングの近隣に少なくとも 1 つのナイトを配置することで埋めることができるという事実に依存しており、必要なのは最適な幾何学的対称性ではなく、有効な構成の存在だけです。

 ## 特殊なケース

 などのコーナーキング`Ka1`には隣接する正方形が 3 つしかないため、多くの単純な構造では必要なカバレッジを過大評価します。 この構成では、クイーンを隣接して配置してもチェックが保証され、ナイトはボードから離れることなく数少ない有効な L 字型の位置の 1 つに配置できます。 このアルゴリズムは完全な 8 近傍構造を想定していないため、依然として成功します。 

崖っぷちの王様、例えば`Kh4`、片側の逃げ方向を減らします。 慎重に制限しないと、クイーンの配置が誤ってボードの外側を狙ってしまう可能性があります。 アルゴリズムは、クイーンを配置する前に有効な隣接する正方形のみを選択することでこれを回避します。 

中央の王様みたいな`Ke4`最大限の脱出オプションがあります。 これはカバレッジに関しては最も難しいケースですが、L 字型の正方形が複数存在するため、ナイトの配置に関しては最も柔軟なケースでもあります。 この構造により、少なくとも 1 つの有効なナイトの位置が保証され、完全性が維持されます。
