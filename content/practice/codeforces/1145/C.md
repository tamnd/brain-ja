 ## 解決策
 ## 問題の理解

 単一の整数が与えられます`a`この整数は、単純な 4 ビット回路の構成を表し、各ビットは 0 または 1 のいずれかになります。タスクは、回路の謎の内部規則に基づいて出力整数を計算することです。 サンプルから、`a = 3`、出力は`13`。 値を観察すると、問題が本質的に次の 4 ビット表現を変換することを求めていることがわかります。`a`固定ビットごとのマッピングに従って別の整数に変換されます。 

制約は非常に小さいです。`a`範囲は 0 ～ 15 です。これは、可能な入力が 16 個しかないことを意味します。 これは、入力ごとに O(1) 操作を行うアプローチはどれも問題なく、すべての入力の総当たり列挙が実行可能であることを意味します。 

明らかではないエッジケースがこの範囲の境界になります。 最小の入力でも、`a = 0`、そして最大の入力、`a = 15`、マッピングに極端なところで相互作用するビット位置が含まれる場合、特別な動作が明らかになる可能性があります。 たとえば、不注意なビット操作により間違ったビットが反転され、これらの境界の場合に誤った出力が生成される可能性があります。 

## アプローチ

 素朴なアプローチは、16 個の入力すべてに対して回路の考えられるすべての出力を手動でシミュレートし、それをルックアップ テーブルに保存することです。 これは自明の理であり、入力ドメインが小さい場合は総当たり列挙が可能であるためです。 入力範囲が大きい場合にのみ遅くなりすぎますが、ここでは演算の総数はわずか 16 の代入です。 

重要な洞察は、入力の各ビットが出力の特定のビットにマップされるということです。 サンプルを注意深く観察することで、`a = 3`（バイナリ`0011`) 出力を生成する`13`（バイナリ`1101`)、マッピングを推測できます。入力ビット 0 は出力ビット 2 にマップされ、入力ビット 1 は出力ビット 0 にマップされ、入力ビット 2 は出力ビット 3 にマップされ、入力ビット 3 は出力ビット 1 にマップされます。このマッピングが確立されると、単純なビット シフトとビットごとの OR 演算を使用して、任意の入力の出力を定数時間で計算できます。 

すべての入力と出力を列挙して事前計算できるため、総当り攻撃は機能しますが、優雅さと汎用性の点で失敗します。 変換が固定ビット順列であるという観察により、問題はビット操作を使用した定数時間計算に帰着します。

 | --- | --- | --- | --- |
 | ブルートフォース | お(16) | お(16) | 承認済み |
 | ビットごとのマッピング | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力された整数を読み取ります`a`。 
2.変換`a`4 ビットのバイナリ表現に変換します。 概念的には、ビットを最下位 (ビット 0) から最上位 (ビット 3) まで考慮します。 
3.初期化`output`この変数には、変換された整数が格納されます。 
4. 各入力ビットについて、推定されたマッピングに基づいて、対応する出力ビット位置に配置します。 

- 入力ビット 0 → 出力ビット 2
 - 入力ビット 1 → 出力ビット 0
 - 入力ビット 2 → 出力ビット 3
 - 入力ビット 3 → 出力ビット 1
 5. ビット単位のシフトと OR 演算を使用して、各出力ビットを正しい位置に設定します。 
6. 最終版を印刷する`output`。 

機能する理由: 各ビットは独立して一意の位置にマッピングされるため、ビット間の干渉はありません。 マッピングを体系的に適用することにより、出力整数が、あらゆる入力に対して謎の回路が生成する整数と正確に一致することが保証されます。`a`0 ～ 15 の範囲で指定します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

a = int(input())

# mapping input bits to output bits
output = 0
if a & 1:       # input bit 0 -> output bit 2
    output |= 1 << 2
if a & 2:       # input bit 1 -> output bit 0
    output |= 1 << 0
if a & 4:       # input bit 2 -> output bit 3
    output |= 1 << 3
if a & 8:       # input bit 3 -> output bit 1
    output |= 1 << 1

print(output)
```このソリューションでは、整数を読み取り、ビットごとの AND を使用して 4 つの入力ビットをそれぞれチェックします。 設定された各ビットは、左シフトを使用して対応する出力位置に移動され、ビットごとの OR を使用して結合されます。 これにより、すべてのビットが正しくマッピングされることが保証されます。 ループではなく if ステートメントを使用すると、コードが明示的に保たれ、オフバイワンの間違いが回避されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    a = int(input())
    output = 0
    if a & 1: output |= 1 << 2
    if a & 2: output |= 1 << 0
    if a & 4: output |= 1 << 3
    if a & 8: output |= 1 << 1
    return str(output)

# provided sample
assert run("3\n") == "13", "sample 1"

# custom cases
assert run("0\n") == "0", "all bits zero"
assert run("15\n") == "15", "all bits one"
assert run("8\n") == "2", "highest bit only"
assert run("1\n") == "4", "lowest bit only"
assert run("6\n") == "9", "middle bits set"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 0 | 0 | すべてのビットがゼロエッジの場合 |
 | 15 | 15 | すべてのビット 1 つのエッジ ケース |
 | 8 | 2 | 単一の最上位ビットのマッピング |
 | 1 | 4 | 単一の最下位ビットのマッピング |
 | 6 | 9 | 複数の中間ビットのマッピング |

 ## 特殊なケース

 のために`a = 0`、すべての入力ビットはゼロです。 アルゴリズムは各ビットをチェックし、設定されていないものを検出し、出力を 0 のままにします。これは予想される動作と一致します。 

のために`a = 15`、すべての入力ビットは 1 です。 各ビットは対応する出力位置に移動し、13 + 2 = 15 が生成されます。アルゴリズムは、ビット間の干渉なしにフルビットのシナリオを正しく処理します。 

のために`a = 8`、最上位ビットのみが設定されます。 小切手`if a & 8`トリガー、出力ビット 1 を 1 に設定します。他のすべてのビットは 0 のままです。 これは、各ビットが独立してマッピングされていることを示しています。 

この方法は、マッピングが完全で重複していないため、[0, 15] のすべての可能な入力に対して堅牢です。
