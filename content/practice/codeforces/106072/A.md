 ## 解決策
 ## 問題の理解

 平面内に描かれた閉じたポリラインが与えられます。$z = 0$。 より簡単に言うと、次のようなものがあります。$n$XY 平面内の点はサイクルで接続されます。各点は次の点に接続され、最後の点は最初の点に戻ります。 これは、場合によっては自己交差する多角形ループのような、区分的線形閉曲線を定義します。 

各頂点は正確に固定されていません。 代わりに、与えられたすべてのポイント$(x_i, y_i)$実際には半径の円盤内のどこにでも配置できます$R_2$その座標を中心にします。 したがって、真のポリラインは、頂点ごとに独立して、これらの不確実性ディスク内で「小刻みに動く」ことができます。 

鳥は 3D で動きますが、その中心はこの不確実な平面ポリライン上にあるように制約されています。 鳥自体は半径の球体です$R_3$したがって、物理的に占有できる領域は、距離内のすべての点のセットになります。$R_3$ポリラインの中心の可能な任意の位置。 これは、各不確実性ディスクから 1 つの点を選択し、それらを順番に接続することによって形成されるすべての可能な曲線を幾何学的に太くしたものです。 

この到達可能な領域全体を$S$。 タスクは、凸包の体積を計算することです。$S$、 ない$S$自体。 

凸包のステップは非常に重要です。太った曲線のおそらく複雑な結合の代わりに、すべてを含む最小の凸状 3D ソリッドの体積が求められます。 

入力サイズにより、ほぼ線形または$O(n \log n)$テストごとのソリューション。 合計以来$n$すべてのテストケースにわたって$10^5$、ソートベースのジオメトリやテストごとの単一の凸包構築よりも悪いものは遅すぎます。 すべての頂点にわたる二次ジオメトリは除外されます。 

微妙なエッジケースが現れるのは、$n = 1$。 ポリラインは不確実性のある単一点に縮退するため、到達可能な領域は単なる半径の球になります。$R_2 + R_3$。 その凸包はそれ自体であるため、答えは単純な体積公式になります。 ポリゴンを想定した単純な解決策はここで失敗します。 

すべての点が同一線上または同一である場合には、別の特殊なケースが発生します。 2D ハルはセグメントまたは点に折りたたまれますが、半径により最終的な 3D ボリュームはまだゼロではありません。$R_3$、ゼロエリア押し出しとして扱ってはなりません。 

## アプローチ

 まず、凸性を無視した場合にジオメトリが実際に何をしているかを調べます。 それぞれの不確かな頂点は、平面内の円盤です。 円盤を線分で接続すると、2D で「太いリボン」が生成され、球の半径が追加されます。$R_3$リボン上に 3D チューブ状の構造を作成します。 考えられるすべての頂点の選択を結合すると、これがさらに大きくなります。 

直接的なアプローチでは、摂動される可能性のあるすべてのポリゴンを列挙しようとします。 各頂点には無限に多くの選択肢があり、離散化さえも指数関数的な爆発につながるため、これは不可能です。 

簡素化の鍵となるのは、操作の順序を逆にすることです。 考えられるすべての曲線を考えてからそれらを太くする代わりに、不確実性と半径の膨張の両方がミンコフスキー和であることがわかります。 到達可能なセット$S$は次のミンコフスキー和です:

 1. 平面内のすべての可能な中心曲線のセット。 
2. 半径の 3D ボール$R_3$。 

頂点の不確実性自体もミンコフスキー和です。各点は元のポリゴンの頂点に半径の 2D ディスクを加えたものです。$R_2$飛行機の中。 

したがって、全体の構造は次のようになります。 2D の元の多角形サイクルから開始し、それを半径によって平面内で膨張させます。$R_2$、半径で 3D に押し出します。$R_3$、次に凸包を取ります。 

ここで、幾何学的な洞察が得られます。ミンコフスキー和が元のオブジェクトの凸包ときれいに相互作用した後の凸包を取得します。 ミンコフスキー和の凸包は、凸包のミンコフスキー和です。 したがって、非凸多角形サイクルを扱う代わりに、それを 2D の凸包で置き換えることができます。 

したがって、問題は、2D で指定された点の凸包を計算し、その凸多角形を垂直方向の半径だけ太らせることによって得られる 3D 形状の体積を計算することに帰着します。$R_3$そして水平方向のインフレーション$R_2$。 

幾何学的には、結果は凸多角形の外殻を平面内に取り込み、次の方法で外側に膨らませるのと同等の凸ボディになります。$R_2$、そして半径のボールをスイープします$R_3$その周りを3Dで表示します。 これは、凸多角形とボールを組み合わせた古典的なミンコフスキーの和であり、「丸いプリズム」を生成します。 

面積のある凸多角形の場合$A$と周囲$P$、半径によるオフセットの体積$R_3$3D では次のようになります。$$V = A \cdot 2R_3 + P \cdot \pi R_3^2 + \frac{4}{3}\pi R_3^3$$これは、平面領域から押し出された 3D の凸状ボディのシュタイナー公式です。 

残る唯一の影響は平面不確実性です$R_2$、円盤との 2D ミンコフスキー和によって凸包ポリゴン自体を膨張させます。 これにより、面積と周囲長は次のように変換されます。$$A' = A + P R_2 + \pi R_2^2,\quad P' = P + 2\pi R_2$$これらを 3D Steiner 展開に代入すると、最終的な式が得られます。 

したがって、計算タスクは次のように削減されます。 

凸包を計算し、その面積と周長を計算して、閉じた形式の公式を適用します。 

ブルートフォースは、すべての摂動をシミュレートするか、完全な 3D 船体を直接構築しようとし、少なくともコストがかかります。$O(n^2)$幾何学的組み合わせによりさらに悪化する場合もあります。 凸包 + 解析ジオメトリにより、すべてが並べ替えと線形走査に集約されます。

 ## アルゴリズムのチュートリアル

 1. 単調連鎖を使用して、2D で指定された点の凸包を計算します。 内側の点は凸状ミンコフスキー展開に影響を与えることができないため、極端な頂点のみを保持します。 
2. 凸包をトラバースして、靴紐の公式を使用してその符号付き面積を計算し、最後に絶対値を取得します。 これにより、ベースポリゴンの領域が得られます$A$。 
3. 周囲長を計算する$P$最後から最初までのエッジを含む、連続する船体の頂点間のユークリッド距離を合計することによって。 
4. 平面内のポリゴンを次のように膨張させます。$R_2$ミンコフスキー ID の使用: 領域を更新$A_1 = A + P R_2 + \pi R_2^2$そして周囲まで$P_1 = P + 2\pi R_2$。 このステップでは、不確実な頂点を確定的な凸オフセット形状に置き換えます。 
5. 半径のボールをスイープすることで、膨張した平面領域を 3D ボディに変換します。$R_3$。 次を使用してボリュームを計算します$V = A_1 \cdot 2R_3 + P_1 \cdot \pi R_3^2 + \frac{4}{3}\pi R_3^3$。 

重要な推論ステップは、各変換が凸性を維持し、領域と周囲によって完全にキャプチャされるため、船体の境界を越える幾何学的詳細は問題にならないということです。 

### なぜ効果があるのか

 ミンコフスキー和は凸包を保持するため、凸包の縮小は有効です。つまり、元の多角形の内部点またはその摂動は常に、極端な頂点の包拡張に含まれます。 不確実性ディスクは境界を外側に均一に拡張するだけであり、そのような均一なオフセットは局所的な曲率にのみ依存します。ポリゴンの場合、局所的な曲率は、周囲長と面積によってグローバルにエンコードされたエッジの長さと頂点の角度に折りたたまれます。 領域が凸状になると、球面拡張後の体積は固有の尺度のみに依存します。$A$そして$P$、シュタイナーの公式で与えられる。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

PI = math.pi

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def dist(a, b):
    return math.hypot(a[0] - b[0], a[1] - b[1])

def convex_hull(points):
    points = sorted(set(points))
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def solve():
    T = int(input())
    for _ in range(T):
        n, R2, R3 = map(float, input().split())
        n = int(n)

        pts = [tuple(map(float, input().split())) for _ in range(n)]

        if n == 1:
            r = R2 + R3
            print(4.0 / 3.0 * PI * r * r * r)
            continue

        hull = convex_hull(pts)

        if len(hull) == 1:
            r = R2 + R3
            print(4.0 / 3.0 * PI * r * r * r)
            continue

        # area
        A = 0.0
        P = 0.0
        m = len(hull)

        for i in range(m):
            x1, y1 = hull[i]
            x2, y2 = hull[(i + 1) % m]
            A += x1 * y2 - x2 * y1
            P += dist((x1, y1), (x2, y2))

        A = abs(A) / 2.0

        # Minkowski with disk R2
        A1 = A + P * R2 + PI * R2 * R2
        P1 = P + 2 * PI * R2

        R = R3

        V = A1 * 2 * R + P1 * PI * R * R + (4.0 / 3.0) * PI * R * R * R

        print(V)

if __name__ == "__main__":
    solve()
```実装は標準のモノトーン チェーンの凸包から始まります。 並べ替えステップは、面積と周囲の両方の計算に必要な境界順序を定義するため、不可欠です。 外積テストにより、左回転のみを維持することが保証され、凸性が保証されます。 

面積の計算では、船体に対して靴ひも式を使用します。これは、浮動小数点を使用する場合の制約に対して数値的に十分安定しています。 外周は、連続する船体の頂点間のユークリッド距離から直接累積されます。 

ミンコフスキー展開は代数的に適用されます。 幾何学的な構築は必要ないため、エッジを明示的にオフセットすることによる数値の不安定性が回避されます。 

最終的な体積公式は、ボールによって厚くされた凸状ボディをシュタイナー展開で直接置き換えたものです。

 ## 特殊なケース

 すべての点が同一の場合、凸包は単一の頂点に折りたたまれます。 アルゴリズムは、面積と周長がゼロである特殊なケースの分岐に正しく入り、結果は半径の球になります。$R_2 + R_3$。 凸包ルーチンは単一の点を返し、エッジの反復は発生しないため、除算や無効な周囲の累積が防止されます。 

点が直線を形成すると、船体は 2 つの端点に減ります。 面積の計算ではゼロが得られますが、周囲長はセグメントの長さの 2 倍になります。 ミンコフスキー展開は、式を通じて有効なカプセルのような体積を生成し、コードは船体を 2 つの頂点を持つものとして正しく処理し、周長が 1 つのセグメントと閉包から計算されることを保証します。
