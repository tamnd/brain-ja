 ## 解決策
 ## 問題の理解

 1 から N までのラベルが付けられたノードを持つツリーが与えられますが、ツリー自体は失われます。 残るのは、そのツリー内で可能な最大距離にあるとして記憶されたノードのペアのリストです。これは、リストされた各ペアの距離がツリーの直径に等しいことを意味します。 

私たちのタスクは、直径エンドポイントのペアのセットが指定されたリストと正確に一致する、同じ N 個のラベル付きノード上にツリーが存在するかどうかを判断することです。 そのようなツリーが存在する場合、有効な例を 1 つ構築する必要があります。 そうでない場合は、それは不可能であると報告する必要があります。 

重要な問題は、距離から任意のエッジを再構築しているわけではないことです。 直径の端点の構造のみからツリーを再構築しています。 これにより、この問題は直接的なグラフ構築問題ではなく、構造的特徴付けタスクになります。 

この制約により、テスト ケース全体で合計最大 200,000 個のノードと 200,000 ペアが許可され、テスト ケースごとの入力サイズが基本的に線形になるソリューションが強制されます。 すべてのペアを明示的にチェックしたり、候補ツリーを単純にシミュレートしたりするなど、ノードの数を超える二次関数を実行すると、すぐに遅すぎます。 

記憶されたペアが一般的なグラフ構造を形成すると仮定すると、微妙な失敗例が現れます。 たとえば、入力ペアが (1,2)、(2,3)、(1,3) のような三角形を形成する場合、これが常に有効であると誤って仮定する可能性がありますが、そのような構造の多くは木の距離の剛体幾何学に違反するため、木の直径の端点から生じることはできません。 

別の失敗例は、複数のノードがどのペアにも記載されていない場合に発生します。 これらのノードは直径のエンドポイントではありませんが、最終ツリーには存在する必要があります。 これらを完全に無視する単純なアプローチでは、切断された構造や無効な構造が生成されます。 

## アプローチ

 強引な解釈では、N 個のノード上ですべての可能なツリーを試し、直径エンドポイントのペアのセットが指定されたセットと一致するかどうかを確認します。 たとえ 1 本の木の直径の端点を線形時間で計算できたとしても、ラベル付けされた木の数は N、具体的には N^(N−2) で指数関数的になるため、これは完全に不可能になります。 

重要な観察は、どのツリーでも、直径エンドポイントのペアに参加するノードのセットは非常に制限された構造を持っているということです。 これらのエンドポイントで可能な構成は 2 つだけです。 

すべての直径の端点が、一意の中心ノードの周りの単一の「レイヤー」に配置されます。この場合、端点のすべてのペアは半径の正確に 2 倍の距離にあり、その端点セット上に完全なグラフを形成します。 または、ツリーにはエッジで接続された 2 つの中心があり、直径の端点が 2 つのグループに分割され、すべての有効なペアがグループ間で交差し、完全な 2 部グラフが形成されます。 

これにより、問題は、指定されたペア セットが少なくとも 1 つのペアに現れるノード上でクリークまたは完全な 2 部グラフを形成するかどうかを識別し、残りのすべてのノードを 1 つまたは 2 つの中心としてアタッチすることに帰着します。

 | --- | --- | --- | --- |
 | 木の上でブルーフォース | 写真 指数 | O(N) | 遅すぎる |
 | 構造分類 (クリークまたは二部エンドポイント グラフ) | O(N + M) | O(N + M) | 承認済み |

 ## アルゴリズムのチュートリアル

 入力ペアをノード 1 から N にわたる無向グラフのエッジとして扱います。少なくとも 1 つのペアに表示されるノードのみが直径端点になり得るため、最初にアクティブなノードと非アクティブなノードを分離します。

1. 指定されたペアを使用してグラフを構築し、このグラフ内の各ノードの次数を計算します。 
2. P を次数が 0 より大きいノードのセットとする。 これらが直径エンドポイントの唯一の候補です。 
3. Z を次数 0 のノードのセットとする。 これらのノードは、再構築されたツリーの内部「中心」ノードになる必要があります。 Zの大きさがちょうど1か2でないと施工できません。 この制限は、どのツリーにも 1 つの中心または 2 つの隣接する中心があるという事実から来ています。 
4. Z のサイズが 1 の場合、そのノード c を呼び出します。 私たちは単一中心のケースにいます。 この場合、すべての直径の端点は c からの等しい最大深さに存在する必要があり、これにより端点のすべてのペアが有効になります。 したがって、P 上のペア グラフは完全なグラフでなければなりません。 これを検証するには、ペアの数が k・(k−1)/2 (k は |P|) に等しいことを確認します。 そうでない場合は拒否します。 
5. c を P のすべてのノードに接続してツリーを構築します。これにより、c を中心とする星が生成され、P のすべてのノードが同じ深さの葉になります。 
6. Z のサイズが 2 の場合、ノード c1 と c2 を呼び出します。 これは二重中心の場合で、c1 と c2 がエッジで接続されている必要があります。 
7. この場合、エンドポイント セット P は、すべての有効なペアが正確に A と B の間のクロス ペアになるように、2 つのグループ A と B に分割する必要があります。ペア グラフ上で BFS のような伝播を使用して、P 内のノードを 2 つのグループの 1 つに割り当てます。つまり、任意のノードを選択し、それを A に割り当て、すべてのペア (u、v) に対して反対側を強制します。 
8. 割り当て中に矛盾が生じた場合、その構造は二部構成ではないため、拒否します。 
9. 分割後、ペアの数が |A|・|B| に等しいことを確認して、完全性を検証します。 そうでない場合は、いくつかのクロスペアが欠落しているか、余分なペアが存在するため、拒否されます。 
10. c1 を A のすべてのノードに接続し、c2 を B のすべてのノードに接続し、c1 を c2 に接続してツリーを構築します。 

### なぜ効果があるのか

 ツリーでは、すべての直径の端点は、直径に等しい同じ離心値を共有します。 これにより、それらはツリーの中心の周囲の 1 つまたは 2 つの対称レイヤーに配置されます。 この構造上の制限は、エンドポイントに誘導されるグラフがクリーク (中央が 1 つの場合) または完全な 2 部グラフ (中央が 2 つの場合) のいずれかでなければならないことを意味します。 これら 2 つのパターンからの逸脱は、測地線の一意性を侵害することなく、ツリー内の最短パスによって実現することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        N, M = map(int, input().split())
        
        deg = [0] * (N + 1)
        edges = []
        
        for _ in range(M):
            u, v = map(int, input().split())
            edges.append((u, v))
            deg[u] += 1
            deg[v] += 1
        
        P = [i for i in range(1, N + 1) if deg[i] > 0]
        Z = [i for i in range(1, N + 1) if deg[i] == 0]
        
        k = len(P)
        
        if k == 0:
            print("NO")
            continue
        
        if len(Z) not in (1, 2):
            print("NO")
            continue
        
        if len(Z) == 1:
            c = Z[0]
            
            if M != k * (k - 1) // 2:
                print("NO")
                continue
            
            print("YES")
            for v in P:
                print(c, v)
            continue
        
        c1, c2 = Z
        
        adj = {v: set() for v in P}
        for u, v in edges:
            adj[u].add(v)
            adj[v].add(u)
        
        color = {}
        ok = True
        
        for v in P:
            if v not in color:
                stack = [v]
                color[v] = 0
                while stack:
                    x = stack.pop()
                    for y in adj[x]:
                        if y not in color:
                            color[y] = color[x] ^ 1
                            stack.append(y)
                        elif color[y] == color[x]:
                            ok = False
        
        if not ok:
            print("NO")
            continue
        
        A = [v for v in P if color[v] == 0]
        B = [v for v in P if color[v] == 1]
        
        if M != len(A) * len(B):
            print("NO")
            continue
        
        print("YES")
        print(c1, c2)
        for v in A:
            print(c1, v)
        for v in B:
            print(c2, v)

def main():
    solve()

if __name__ == "__main__":
    main()
```この実装では、まず、任意のペアに含まれるノードを孤立したノードから分離し、候補中心構造を即座に決定します。 単一中心の場合は、すべてのペアが存在する必要があることを強制することによって処理されますが、二中心の場合は、エンドポイント グラフに対して 2 部構造を強制し、エッジ数によって完全性を検証します。 

よくある落とし穴は、どのペアにも出現しないノードが最大 2 つに制限されていることを検証するのを忘れることです。 もう 1 つの微妙な問題は、接続されたコンポーネント間で 2 分割の一貫性が確保されていないことです。これにより、無効な再構築が発生します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque

    input = sys.stdin.readline

    def solve():
        T = int(input())
        out = []
        for _ in range(T):
            N, M = map(int, input().split())
            deg = [0]*(N+1)
            edges = []
            for _ in range(M):

            Z=[i for i in range(1,N+1) if deg[i]==0]
            k=len(P)

            if k==0 or len(Z) not in (1,2):
                out.append("NO")
                continue

            if len(Z)==1:
                c=Z[0]
                if M!=k*(k-1)//2:
                    out.append("NO")
                    continue
                out.append("YES")

                    out.append(f"{c} {v}")
                continue

            c1,c2=Z
            adj={v:set() for v in P}
            for u,v in edges:
                adj[u].add(v);adj[v].add(u)

            color={}
            ok=True
            for v in P:
                if v not in color:
                    stack=[v]
                    color[v]=0
                    while stack:
                        x=stack.pop()
                        for y in adj[x]:
                            if y not in color:
                                color[y]=color[x]^1
                                stack.append(y)
                            elif color[y]==color[x]:
                                ok=False

            for v in A:
                out.append(f"{c1} {v}")
            for v in B:
                out.append(f"{c2} {v}")

        return "\n".join(out)

    return solve()

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべてのノードが少なくとも 1 つのペアで表示され、潜在的な中心となるノードが残っていない場合です。 これにより、すべての有効なツリーには直径エンドポイントのペアに参加しない中心ノードが少なくとも 1 つ必要となるため、再構築は直ちに不可能になります。 Z が空の場合、アルゴリズムは構造的な仮定が行われる前に拒否します。 

もう 1 つのエッジ ケースは、ちょうど 2 つのノードがペア セットの外にある場合に発生します。 この状況では、エッジで接続された 2 つの中心になる必要があります。 エンドポイントの残りのグラフが完全に 2 部ではない場合、またはペアの数がパーティション サイズの積と一致しない場合、その構造はどのツリー ジオメトリにも対応できません。
