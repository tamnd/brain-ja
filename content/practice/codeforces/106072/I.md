 ## 解決策
 ## 問題の理解

 有向非巡回グラフの完全な構造は与えられていますが、エッジの重みは不明です。 重みについて何かを知る唯一の方法は、対話型のオラクルを使用することです。つまり、頂点のペアを選択します。$s, t$そしてスカラー$c$、オラクルは、からのすべての有向パスの合計を返します。$s$に$t$。 各パスは、グラフ内のすべてのエッジの重みに次の値を乗算した後のエッジの重みの積に寄与します。$c$。 

したがって、パスにエッジがある場合は、$e_1, e_2, \dots, e_k$オリジナルのウェイトで$w_1, w_2, \dots, w_k$、スケーリング後、パスが寄与します$(w_1 c)(w_2 c)\cdots(w_k c) = (w_1 w_2 \cdots w_k)c^k$。 オラクルはこれをすべてのパスにわたって合計します。 

クエリが完了すると、システムは値を明らかにします。$k$そして、頂点 1 から頂点まで同じパス合計を出力する必要があります。$n$スケーリング中$k$。 

最も重要な制約は、最大 999 個のクエリが許可されることです。$n \le 1000$そして$m \le 5000$。 これにより、個々のエッジの重みを再構築したり、パスを列挙しようとする戦略は除外されます。これは、多くの分岐パスを持つ DAG では、すべてのパスの 1 つのペアごとの計算でもすでに指数関数的になるためです。 

素朴な推論の微妙な失敗例は、小さな部分問題をクエリすることでエッジを分離できると考えることです。 たとえば、クエリを実行すると、$f(u, v, c)$直接エッジのみを期待する$u \to v$貢献するには、これは間違っています:

 もっと長い道もあれば$u \to x \to v$、次のような小さなグラフでも$u \to v$、$u \to x \to v$、

 クエリにはすでに寄与が混在しています。$$f(u,v,c) = w_{uv}c + (w_{ux}w_{xv})c^2.$$そのため、エッジの重みがすべての代替パスと絡み合い、ローカル抽出の信頼性が低くなります。 

主な問題点は、パスの寄与が乗算と合計を通じてグローバルに相互作用し、集計された値のみが観察されることです。 

## アプローチ

 ブルートフォースの観点では、すべてのエッジの重みを回復しようとします。 DAG 内であっても、各エッジは指数関数的に多くのパスに参加しているため、1 つの重みを分離するには、すべての代替ルートの寄与を差し引く必要があります。 各クエリはすべてのパスにわたってグローバルな多項式のような式を返すため、これはすぐに手に負えなくなります。 

重要な観察は、固定エンドポイントの場合です。$1$そして$n$、関数としての答え$c$任意ではありません。 すべてのパスは以下に比例する項に寄与します。$c^{\text{length}}$したがって、式全体は次の多項式になります。$c$:$$f(1,n,c) = \sum_{d \ge 1} a_d c^d,$$どこ$a_d$長さのすべてのパスの合計寄与度です$d$、それぞれは元のエッジの重みの積によって重み付けされます。 

から長さ 0 のパスがないため、定数項はありません。$1$に$n$いつ$1 \ne n$。 これにより、問題はせいぜい学位の再構築に変わります$n-1$定数項のない多項式。 この多項式がわかれば、最終的なクエリに答えることは単に次の点で評価するだけです。$c = k$。 

したがって、グラフを学習する代わりに、多項式を学習します。 

この多項式の値は、直接クエリすることで取得できます。$f(1,n,c)$選択された値に対して$c$、次に補間します。

 ## アルゴリズムのチュートリアル

 このソリューションは、サンプリングと多項式の再構築にすべてを削減します。 

1. オラクルにクエリを実行します。$f(1,n,c)$999 個の異なる値で$c$、 例えば$c = 1, 2, \dots, 999$。 各クエリは未知の多項式上の 1 つの点を返します。$P(c)$。 グラフの構造は、関数が適切に定義されていることを保証すること以外には無関係です。 
2. 各ペアを保存します$(c_i, y_i)$、 どこ$y_i = P(c_i)$。 これらは、定数項がゼロで最大 999 次の単一多項式の評価です。 
3. 多項式を再構築する$P(c)$モジュロ$998244353$999 ポイントにわたる補間を使用します。 直接$O(n^2)$このスケールではラグランジュ補間で十分です。 
4. 再構築後、値を読み取ります。$k$インタラクターから。 
5. 評価する$P(k)$再構成された表現を使用して結果を出力します。 

唯一の微妙な点は、補間が確実にモジュロで行われるようにすることです。$998244353$、すべての除算が逆モジュラーに置き換えられます。 

### なぜ効果があるのか

 固定されたすべてのクエリ$(1,n)$そして変数$c$長さによってグループ化されたすべてのパスの寄与を集計した係数を持つ多項式を生成します。 各パスはちょうど 1 つの単項式に寄与するため、$c^{\text{length}}$、関数全体は単項式の合計であるため、多項式になります。 

の異なる値$c$この同じ多項式の評価を与えます。 最大 999 次の多項式は、定数項がゼロであることがわかっている場合、999 個の個別の評価によって一意に決定されます。 これにより、内挿ステップで元の関数が正確に再構築されることが保証されるため、$k$必要な答えを返します。 

## Python ソリューション```python
import sys

input = sys.stdin.readline
MOD = 998244353

def inv(x):
    return pow(x, MOD - 2, MOD)

def lagrange(x, xs, ys):
    n = len(xs)

    pre = [1] * n
    suf = [1] * n

    for i in range(1, n):
        pre[i] = pre[i - 1] * (x - xs[i - 1]) % MOD
    for i in range(n - 2, -1, -1):
        suf[i] = suf[i + 1] * (x - xs[i + 1]) % MOD

    res = 0
    for i in range(n):
        num = pre[i] * suf[i] % MOD
        den = 1
        for j in range(n):
            if i != j:
                den = den * (xs[i] - xs[j]) % MOD
        res = (res + ys[i] * num % MOD * inv(den)) % MOD

    return res

def main():
    n, m = map(int, input().split())
    for _ in range(m):
        input()

    xs = []
    ys = []

    for c in range(1, n):
        print(f"? 1 {n} {c}")
        sys.stdout.flush()
        xs.append(c)
        ys.append(int(input()))

    print("!")
    sys.stdout.flush()

    k = int(input())
    print(lagrange(k, xs, ys))

if __name__ == "__main__":
    main()
```必要な情報はすべて対話型多項式に埋め込まれているため、プログラムはグラフのエッジを読み取った後は完全に無視します。$f(1,n,c)$。 

メインループのクエリ$c = 1$に$n-1$、正確に収集します$n-1$点。これは、多項式内の未知の係数の数と一致します (ゼロ定数項を除くすべての経路長の寄与)。 受け取り後$k$、ラグランジュ補間を使用して多項式を再構築し、それを評価します。 

内挿ルーチンは、プレフィックスとサフィックスの積を構築して、各点の分子を効率的に計算します。 分母は項ごとに直接計算され、べき乗剰余を使用して反転されます。 

## 実用的な例

 これは対話型なので、最小限の概念的な例を考えてみましょう。 

単一のエッジを持つ頂点が 2 つだけあると仮定します。$1 \to 2$体重の$w$。 それから：$$f(1,2,c) = wc.$$次のようにクエリします。 

| クエリ$c$| 戻り値 |
 | --- | --- |
 | 1 |$w$|
 | 2 |$2w$|
 | 3 |$3w$|

 これにより多項式が再構築されます$P(c) = wc$、で評価します$k$与える$wk$。 

もう少し複雑なケース:

 2 つのパスがあるとします。$1 \to 2 \to 3$重り付き$a, b$、および直接エッジ$1 \to 3$重さで$d$。 

それから：$$f(1,3,c) = dc + (ab)c^2.$$クエリ:

 | c | 値 |
 | --- | --- |
 | 1 |$d + ab$|
 | 2 |$2d + 4ab$|

 これらの評価から、補間によって線形成分と二次成分が分離され、完全な多項式構造が復元されます。 

これにより、このメソッドが直接寄与と複数ステップ寄与の両方を正しく捕捉していることが確認されます。

 ## 特殊なケース

 からのパスがない場合、縮退ケースが発生します。$1$に$n$。 その後、すべてのクエリは、次の条件に関係なくゼロを返します。$c$、ゼロ多項式を生成します。 内挿によりすべての係数がゼロとして再構築され、最終的な答えはどの係数でも正確にゼロになります。$k$。 

もう 1 つの特殊なケースは、すべてのパスの長さが同じである場合です。 この場合、多項式にはゼロ以外の係数が 1 つだけ含まれます。 たとえば、すべてのパスの長さが 3 の場合、すべてのクエリは次の倍数を返します。$c^3$、補間により、不安定になることなく単項多項式が自然に回復されます。 

最後のケースは次のような場合です。$n = 1$。 それから$f(1,1,c)$自明のことですが、すべてが 1 です$c$(空のパス) なので、多項式は定数です。 アルゴリズムは引き続き機能しますが、縮退補間のみが必要であり、最終的な答えは、$k$。
