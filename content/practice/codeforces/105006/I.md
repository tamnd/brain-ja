 ## 解決策
 ## 問題の理解

 私たちはコーギーのコレクションを与えられ、それぞれに 22 ビットの整数の性格値が割り当てられています。 これらのコーギーのサブセットを選択すると、そのサブセット内のすべてのペアは、性格のビットごとの AND に等しい「幸福度」をもたらします。 サブセットの幸福度の合計は、これらのペアごとの AND 値の合計です。 タスクは、コーギーのすべての可能なサブセットにわたってこの数量を合計することです。 

これを直接解釈する方法は、インデックスのすべてのペアが複数回、つまりペアの両方の要素を含むサブセットごとに 1 回ずつ寄与しているということです。 最初にサブセットについて考えるのではなく、すべてのサブセットにわたって固定ペアがどのくらいの頻度で出現するかを考える方が有益です。 

制約は大きく、最大 200,000 個の要素と最大 2²² の値があります。 これにより、各ペアが重い作業を必要とする場合、サブセットを反復したり、すべてのペアを直接反復したりするソリューションは即座に除外されます。 およそ 2×10^10 のサブセットがあり、すべてのサブセットにわたって 2×10^10 のペアも存在するため、サブセットの列挙は不可能です。 O(n²) でさえ、n = 2×10^5 にとっては大きすぎる境界線です。 

単純なアプローチでは、各サブセットの内部ペアの合計が計算され、指数関数的な時間が発生します。 すべてのペアを一度合計してから固定係数を乗算しても、サブセットの構造が無視され、失敗します。これは、組み合わせ論を注意深く考慮しない限り、各ペアがサブセット全体で均等にカウントされないためです。 

微妙な落とし穴は、多重性を追跡せずにサブセットにわたる線形性を仮定することです。 たとえば、値 [1, 2] の場合、ペア (1,2) は両方が選択された場合にのみ寄与します。これは、どちらかの要素を含むすべてのサブセットではなく、1 つのサブセットのみで発生します。 

## アプローチ

 重要なアイデアは、合計の順序を逆にすることです。 最初にサブセットを合計する代わりに、最初にペアを合計し、ペアごとにそれが含まれるサブセットの数を決定します。 

2 つのインデックス i < j を修正します。 ペア (i, j) は両方の要素を含むサブセットに正確に現れますが、残りの n − 2 要素は任意です。 したがって、各ペアは 2^(n−2) を乗じた AND 値に寄与します。 これにより、問題全体がコンピューティングに帰着します。 

すべてのペア (p_i & p_j) を合計し、2^(n−2) を掛けます。 

ここで問題は、すべてのペアのビット単位の AND の合計を計算することになります。 これは古典的なビット分解のトリックです。 各ビットは独立して処理できます。 各ビット b について、このビットが設定されている数値の数を数えます。 cnt[b] 要素にビット b が設定されている場合、cnt[b] はそのビットに寄与する 2 つのペアを選択し、そのような各ペアは AND 合計に 2^b 寄与します。 

したがって、ペアごとの AND 合計は次のようになります。 

b の合計: (cnt[b] * (cnt[b] − 1) / 2) * 2^b

 最後に 2^(n−2) を掛けます。 

これにより、問題はビット数のカウントに軽減されます。

 ## アルゴリズムのチュートリアル

 1. すべての値にわたって 0 ～ 21 の各ビットが何回出現するかを数えます。 AND は各ビットに対して独立して動作するため、これによりビットごとの寄与が分離されます。 
2. 各ビット b について、 cnt[b] * (cnt[b] − 1) // 2 を計算します。これにより、両方の数値にビット b が設定されている順序のないペアの数が得られます。 これが機能する理由は、ビットが両方のエンドポイントにビットがある場合にのみ AND に寄与するためです。 
3. 最終的な合計におけるそのビットの値を考慮して、各ペアのカウントに 2^b を乗算します。 
4. すべてのビットにわたるこれらの寄与を合計して、すべての順序なしペアにわたる p_i と p_j の合計を取得します。 
5. 各固定ペアは正確に 2^(n−2) 個のサブセットに現れるため、結果に 2^(n−2) を掛けます。 両方のエンドポイントを含むすべてのサブセットは、残りの要素を自由に選択できます。 
6. 結果のモジュロ 998244353 を返します。 

### なぜ効果があるのか

正確さは 2 つの独立した分解に基づいています。 まず、すべてのサブセットにわたる各ペアの寄与は均一であり、両方のエンドポイントを含むサブセットの数 (正確に 2^(n−2)) にのみ依存します。 第 2 に、ビットごとの AND はビット間で加算的であるため、各ビットの寄与を他のビットからの干渉なしに個別にカウントできます。 どちらの変換でも正確な合計寄与率が保持されるため、最終的な式は元の定義と一致します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

n = int(input())
a = list(map(int, input().split()))

B = 22
cnt = [0] * B

for x in a:
    for b in range(B):
        if x & (1 << b):
            cnt[b] += 1

pair_and_sum = 0
for b in range(B):
    c = cnt[b]
    pair_and_sum += (c * (c - 1) // 2) % MOD * ((1 << b) % MOD)
    pair_and_sum %= MOD

if n >= 2:
    pair_and_sum *= modpow(2, n - 2)
    pair_and_sum %= MOD
else:
    pair_and_sum = 0

print(pair_and_sum)
```この実装では、まずすべての情報がビット数に圧縮され、ペアの列挙が回避されます。 べき乗剰余演算により、サブセット多重度係数 2^(n-2) が効率的に計算されます。 モジュラー演算の繰り返しを避けるために、乗算はペアごとの合計が終わるまで延期されます。 

微妙な点の 1 つは、ペアが存在せず、結果がゼロになる必要がある n < 2 の処理です。 もう 1 つは、cnt[b] がリダクション前の Python 整数で安全に 2 を選択するため、すべての中間値をモジュロ 998244353 未満に保ちながら、組み合わせに整数演算を使用することです。
