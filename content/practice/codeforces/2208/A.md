 ## 解決策
 ## 問題の理解

 次のサイズの正方形グリッドが与えられます。$n \times n$各セルに特定の色のキャンディーが含まれるボードを表します。 キャンディーの色は整数で表され、異なる整数は異なる色を表します。 ボブは、どの行も列もすべて同じ色のキャンディーで埋まらないように、ボード上のキャンディーを再配置できるかどうかを知りたいと考えています。 

つまり、再配置後、すべての行と列に少なくとも 2 つの異なる色が含まれている必要があります。 入力は複数のテスト ケースを提供し、それぞれに独自のボードが含まれます。 そのような再配置がボードで可能である場合は「YES」、そうでない場合は「NO」と答える必要があります。 

制約は次のことを教えてくれます$n$最大 100 まで可能で、すべての合計$n$テスト ケース全体で 500 を超えません。これは、すべてのセルを反復するあらゆるソリューションが許容されることを意味します。$n^2$テスト ケースあたりのセル数は最大 10,000、すべてのテスト ケースにわたるセルの総数は最大 50,000 です。 

主なエッジケースは、1 つの色が複数表示される場合です。$n$回。 しかないので、$n$単一の色が複数の行または列に表示される場合、その行または列の位置$n$場合によっては、その色が完全に同じ色の行または列を形成することを防ぐことはできません。 たとえば、次の場合$n = 3$そしてボードは次のとおりです。```
1 1 1
2 3 2
3 2 3
```それから色を塗ります`1`3 回出現します。これは次と同じです。`n`。 並べ替えることはできますが、いずれかの色が 3 回以上出現する場合、単色の行または列を避けることはできません。 頻度をカウントせずに行または列のみをチェックする不注意な実装は、ここで失敗します。 

## アプローチ

 ブルートフォースアプローチでは、ボード上のキャンディーのすべての順列を試し、結果のボードが条件を満たすかどうかを確認しようとします。 のために$n \times n$理事会、これには次のことが含まれます$(n^2)!$順列。 これは明らかに不可能です$n = 5$。 再配置はすべての可能性をカバーするため、総当り攻撃は原理的には機能しますが、天文学的な数の順列のために失敗します。 

重要な洞察は、色の正確な位置は気にしておらず、色の数だけを気にしていることに気づくことから得られます。 いずれかの色がそれ以上発生する場合、再配置は不可能です。$n$回を超えて配置することはできないため、$n$単色の行や列を作成せずに、同じキャンディーを作成します。 逆に、すべての色が最大でも発生する場合、$n$場合によっては、単一色の行または列全体を避けるために、いつでも対角線のようなパターンで並べ替えることができます。 この観察により、問題は順列から各色の出現のカウントに軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((n^2)!) | O(n^2) | 遅すぎる |
 | 最適（周波数チェック） | テスト ケースごとに O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$そして、$n \times n$ボード。 
3. すべてのキャンディーカラーの周波数カウンタ (ディクショナリ) を作成します。 あらゆる細胞に$a_{i,j}$のカウントをインクリメントします。$a_{i,j}$。 
4. 数えた後、任意の色の最大頻度を確認します。 この周波数がそれよりも大きい場合、$n$、このテスト ケースでは「NO」を出力します。 それ以外の場合は、「YES」を出力します。 

これが機能する理由は、色の最大周波数が制限要因であるためです。 ボードをどのようにシャッフルしても、色が表示されない場合は、$n$場合によっては、少なくとも 1 つの行または列のすべての位置にその色が含まれている必要があります。 すべての周波数が最大でも$n$たとえば、各色を対角線に沿って配置し、残りの位置を慎重に埋めることによって、有効な再配置が常に存在します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import Counter

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        colors = []
        for _ in range(n):
            row = list(map(int, input().split()))
            colors.extend(row)
        count = Counter(colors)
        if max(count.values()) > n:
            print("NO")
        else:
            print("YES")

if __name__ == "__main__":
    solve()
```このソリューションは、すべての行をフラット リストに読み取ります。`colors`簡単にするために。`Counter`各キャンディーカラーの出現を効率的にカウントします。 小切手`max(count.values()) > n`上記で導出された条件を直接実装します。 使用する`sys.stdin.readline`複数のテスト ケースの高速入力を保証します。 行を正しく平坦化するには注意が必要です。 単純な合計演算では数値が誤って連結される可能性があります。

 ## 特殊なケース

 のために`n = 1`、ボードにはセルが 1 つだけあります。 どの行または列にも複数のキャンディーを含めることはできないため、色に関係なく、答えは常に「YES」です。 アルゴリズムはこれを処理します。`max(count.values()) = 1 <= n = 1`。 

のために`n = 100`単一の色が 101 回出現すると、アルゴリズムは正しく「NO」を出力します。`max(count.values()) = 101 > 100`。 再配置は行われず、大きな入力サイズを効率的に処理します。 

複数の色が正確に表示されるボードの場合`n`アルゴリズムは、制限を超える色がないことを認識するため、各回「YES」を出力します。 これは、注意深く並べ替えることで有効な基板が生成される可能性があるが、周波数制約によって保証されるケースを捉えています。
