### なぜ効果があるのか

 すべての有効な文字列`t`正確に使用します`n`に存在する文字セットからの異なる文字`s`。 サイズのサブセットになると`n`が固定されている場合、そのすべての順列が 2 番目の条件に対して有効な文字列を生成し、最初の条件は同じサブセットの一意の昇順に正確に寄与します。 この昇順順序はすでに順列の 1 つであるため、各サブセットの有効な文字列の合計数は正確に次のようになります。`n!`。 したがって、問題はサイズのサブセットを数えることに帰着します。`n`で利用可能なアルファベットから`s`、そしてサブセットごとの順列の数を掛けます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXA = 18

fact = [1] * (MAXA + 1)
for i in range(1, MAXA + 1):
    fact[i] = fact[i - 1] * i

def solve():
    s, n = input().split()
    n = int(n)

    used = [0] * 26
    k = 0
    for ch in s:
        if not used[ord(ch) - 97]:
            used[ord(ch) - 97] = 1
            k += 1

    if k < n:
        print(0)
        return

    # C(k, n)
    comb = 1
    for i in range(n):
        comb *= (k - i)
        comb //= (i + 1)

    print(comb * fact[n])

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()
```この解決策は、入力文字列を 26 文字にわたるブール型プレゼンス配列に圧縮することから始まりますが、関連するのは最初の 18 文字だけです。 カウント`k`使用可能な個別の文字がいくつ存在するかを追跡します。 

二項係数は、パスカルの三角形の事前計算を回避し、メモリを一定に保つために反復的に計算されます。 以来`n ≤ 18`、Python では整数の増加は安全であり、コストがかかることはありません。 

乗算`fact[n]`選択された各サブセットのすべての順列が考慮されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import factorial

    MAXA = 18
    fact = [1] * (MAXA + 1)
    for i in range(1, MAXA + 1):
        fact[i] = fact[i - 1] * i

    t = int(sys.stdin.readline())
    out = []
    for _ in range(t):
        s, n = sys.stdin.readline().split()
        n = int(n)

        used = [0] * 26
        k = 0
        for ch in s:
            if not used[ord(ch) - 97]:
                used[ord(ch) - 97] = 1
                k += 1

        if k < n:
            out.append("0")
            continue

        comb = 1
        for i in range(n):
            comb *= (k - i)
            comb //= (i + 1)

        out.append(str(comb * fact[n]))

    return "\n".join(out)

 ## 特殊なケース

 いつ`s`正確に含まれています`n`異なる文字の場合、計算は単一のサブセットに減ります。 アルゴリズムは正しく出力します`n!`, C(n, n) = 1 であり、すべての順列がカウントされるためです。 

いつ`s`多くの重複が含まれていますが、個別の文字はほとんど含まれていないため、実装では頻度が完全に正しく無視されます。 例えば、`s = "aaaaabbbb"`まったく同じように動作します`s = "ab"`、存在だけが重要なので。 

いつ`n = 1`、内のすべての個別の文字`s`は有効な文字列を形成し、式は C(k, 1) × 1 = k を返します。これは直接列挙と一致します。 

いつ`k < n`、早期終了により、不必要な組み合わせ計算が実行されなくなり、無効な状態での除算ステップが回避されます。
