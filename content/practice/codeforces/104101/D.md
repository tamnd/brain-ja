 ## 解決策
 ## 問題の理解

 平面内に角がある長方形の領域が与えられます。$(0,0)$、$(n,0)$、$(0,m)$、 そして$(n,m)$。 空の長方形と考えてください。 

次に配置します$q$この長方形内の軸に揃えられた線分。 各セグメントは長方形の 1 辺に取り付けられ、指定された長さだけ内側に伸びます。$a_i$。 可能な方向は 4 つあります。 タイプ 1 セグメントは、上部境界から始まります。$y=m$そして下に向かっていきます。 タイプ 2 セグメントは、下の境界から始まります。$y=0$そして上に上がっていきます。 タイプ 3 セグメントは、左側の境界から始まります。$x=0$そして右に進みます。 タイプ 4 セグメントは、右境界から始まります。$x=n$そして左に進みます。 

したがって、各セグメントは 1 つの軸に平行な直線のカットであり、境界線に固定されています。 すべてのセグメントを配置した後、これらのカットにより長方形が複数のサブ領域に分割されます。 タスクは、残っている最大の接続領域の面積を計算することです。 

制約は特定の点で厳しいです。$n, m$まで可能です$10^6$したがって、単位解像度でグリッドを離散化することはできません。 しかし、$q \le 2000$これは、構造が幾何学的シミュレーションではなく、各辺に沿ったセグメントの順序によってのみ支配されることを強く示唆しています。 この不均衡は、平面をシミュレートするのではなく、問題を方向ごとの 1D 推論に圧縮する必要があることを意味します。 

単純な間違いは、垂直カットと水平カットの間の交差は、すべての交点を明示的にスイープすることで処理できると想定することです。 これには、セグメントのすべてのペアをチェックする必要があります。$O(q^2)$境界線にあるものの、まだ管理可能な交差点。 ただし、領域がどのように形成されるかについての重要な構造の単純化がまだ抜けています。 

もう 1 つのよくある間違った考え方は、各セグメントを、サイズの長方形ごとに独立して面積を縮小するものとして扱うことです。$a_i \times$(反対側の境界までの距離)。 これは、セグメントが重なっている場合、または反対側からの複数のカットが出会って互いにブロックしている場合には失敗します。 

小さな失敗例は、重複したカットから発生します。 

入力:$n=10, m=10$2つのトップカット$x=5$そして$x=5$、両方の長さ$6$単純な減算では、除去された領域が 2 倍にカウントされる可能性がありますが、正しい構造では、2 番目のカットには最初のカットを超える追加の効果がないことが示されます。 

正しい解決策は、反対側からのカットがどのくらい貫通するか、そしてそれらが中央でどのように「交わる」かを推論する必要があります。 

## アプローチ

 ブルートフォース解釈は幾何学的シミュレーションです。長方形を表し、各セグメントを平面グラフのセグメントとして挿入し、すべての交点を計算し、エッジを分割し、フラッドフィルまたは平面細分割アルゴリズムを実行してすべての面領域を計算します。 これは概念的には簡単です。平面がポリゴンに分割されると、最大の面領域はまさに最大ポリゴン領域になります。 

ただし、このアプローチは組み合わせ的に爆発的になります。 新しい各セグメントは最大で交差できます。$O(q)$既存のセグメント、生産$O(q^2)$頂点。 平面グラフの構築と顔領域の計算は、特に 1 秒の制限の下では非常に遅く、複雑すぎます。 

重要な観察は、すべてのセグメントが軸に沿って位置合わせされ、境界に固定されていることです。 これは、それらが任意の交差を形成しないことを意味します。垂直セグメントは水平セグメントとのみ交差し、ジオメトリは x 軸と y 軸に沿った独立した拘束に分離可能です。 さらに重要なことは、側面からカットされるたびに、利用可能な空きスペースが単調に減少することです。 完全なサブディビジョンを追跡する代わりに、各座標線で各側がどの程度「内側に押し込まれる」かを追跡するだけで済みます。 

これにより、問題は、長方形内の任意の点について、各方向から来る最も近いブロック セグメントからどのくらい離れているかを理解することになります。 残りの最大領域は、対向するカット間に形成されるブロックされていない最大の長方形によって決まります。 

したがって、交差点をシミュレートする代わりに、各辺から有効カバレッジ間隔を計算し、自由な長方形の最大の幅と高さを導き出します。

 ## アルゴリズムのチュートリアル

 1. すべてのセグメントをタイプに基づいて、上、下、左、右の 4 つのグループに分けます。 各グループは、固定された座標線に沿って、境界から内側にカットがどの程度貫通するかを記述します。 同じ側​​のセグメントは重なりを除いて幾何学的に相互作用せず、垂直な側のセグメントは分離可能な交差ロジックを介する場合を除いて制約をマージしないため、この分離は有効です。 
2. 上部のセグメントについては、X 座標で並べ替え、各 X 位置での最大透過のみを保持します。 同じ x で重複するセグメントや重複するセグメントは、最も遠くまでは問題になりません。その位置では、より深いセグメントが短いセグメントを完全に支配するからです。 
3. 底部、左側、右側にも同じ圧縮を繰り返します。 このステップの後、各辺は、自由空間がその境界からどの程度縮小するかを定義する独立した「障害物」のセットとして表されます。 
4. 次に、長方形が 2 つの独立した方向に拘束されていると解釈します。 どの x 座標でも、使用可能な垂直高さは、垂直に交わる上部と下部のカットによって制限されます。 同様に、どの y 座標でも、使用できる水平幅は左右のカットによって制限されます。 
5. 最大の空の領域は、軸に沿って整列した長方形でなければなりません。その境界は、対辺からの連続した「有効カット端点」によって決定されます。 したがって、両方の次元に沿った有効浸透エンドポイント間の最大ギャップを計算します。 
6. 垂直寸法の場合、すべての有効なトップダウン カット エンドポイントとボトムアップ カット エンドポイントを収集し、並べ替えて、重複しないトップ カット エンドポイントとボトム カット エンドポイントの間の最大間隔を計算します。 
7. 左右のカットを使用して、水平寸法についても同じことを行います。 最終的な答えは、有効な垂直ギャップと水平ギャップの最大積です。 

### なぜ効果があるのか

 最終的なパーティション内のすべての領域は、左、右、上、下のカットの組み合わせによって境界付けられます。 すべてのセグメントは軸に揃えられ固定されているため、境界が曲がったり、非局所的なジオメトリに依存したりすることはありません。 これにより、サブディビジョン内のすべての面が元の長方形またはカット セグメントのいずれかに辺が揃う長方形になります。 したがって、そのような最大の面は、反対側からのカットの極端な貫通によってのみ決定される、x のブロックされていない最も広い間隔と y のブロックされていない最も高い間隔を選択することに対応する必要があります。 

追加のセグメントは新しい境界を導入するか、既存の自由間隔を短くするだけであるため、複数のセグメントを構成しても、最適に位置合わせされた反対側のギャップのペアよりも大きな領域を生成することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, q = map(int, input().split())

    top = []
    bottom = []
    left = []
    right = []

    for _ in range(q):
        a, t, x = map(int, input().split())
        if t == 1:
            top.append((x, a))
        elif t == 2:
            bottom.append((x, a))
        elif t == 3:
            left.append((x, a))
        else:
            right.append((x, a))

    # compress: keep max at each coordinate
    def compress(segs):
        mp = {}
        for pos, length in segs:
            if pos not in mp or mp[pos] < length:
                mp[pos] = length
        return list(mp.values())

    top_len = compress(top)
    bottom_len = compress(bottom)
    left_len = compress(left)
    right_len = compress(right)

    # If no cuts, full rectangle remains
    max_h = m
    max_w = n

    if top_len or bottom_len:
        top_max = max(top_len) if top_len else 0
        bottom_max = max(bottom_len) if bottom_len else 0
        max_h = m - min(top_max + bottom_max, m)

    if left_len or right_len:
        left_max = max(left_len) if left_len else 0
        right_max = max(right_len) if right_len else 0
        max_w = n - min(left_max + right_max, n)

    print(max_h * max_w)

if __name__ == "__main__":
    solve()
```各方向が 1 つの軸を独立して制限するため、コードはまず方向によってセグメントを分割します。 圧縮は、同じ座標での重複セグメントを避けるために使用されます。 ある位置で最も強いカットだけが重要です。 

垂直方向の計算では、上向きと下向きの最大の貫通により、長方形の高さでキャップされた重なり合いが組み合わされて、使用可能な高さが効果的に減少します。 同じロジックが水平方向にも当てはまります。 

最後に、実現可能な最大の高さと幅を乗算すると、残りの最大の長方形領域が得られます。

 ## 特殊なケース

 重要なエッジケースは、反対側からのカットが完全に重なるときに発生します。 次のことを考慮してください。 

入力:```
5 5 1
5 1 2
5 2 2
```x=2 では、1 つのセグメントは上から 5 だけ切り下げられ、もう 1 つのセグメントは下から 5 だけ切り上げられます。それらは完全に一致し、その線で垂直方向の通路がなくなります。 アルゴリズムは、貫通を合計し、全高でキャッピングすることでこれを処理し、その座標で使用可能な高さをゼロにします。 

もう 1 つのエッジ ケースは、複数のセグメントが同じ側の同じ座標に存在する場合です。```
10 10 3
3 1 5
7 1 5
2 1 5
```3 つはすべて x=5 でのトップ カットです。 最も長いカットの中に短いカットが完全に含まれているため、最も長いカットだけが問題となります。 圧縮では 7 のみが維持され、カウントしすぎを防ぎます。 

最後のケースは、1 つの軸上にセグメントが存在しない場合です。 水平方向のカットがまったくない場合は、全幅をそのまま使用できます。 このアルゴリズムは、幅と高さを完全な値に初期化し、少なくとも 1 つの方向が制約に寄与する場合にのみ幅と高さを減らし、空の入力が完全な長方形領域を正しく返すことを保証します。
