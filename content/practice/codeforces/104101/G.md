 ## 解決策
 ## 問題の理解

 行に配置されたノードの三角形構造が与えられます。 行 1 には 1 つのノードがあり、行 2 には 2 つのノードがあり、行 i には i つのノードがあります。 位置 (i, j) の各ノードは、(i + 1, j) と (i + 1, j + 1) の 2 つのノードに下向きに接続します。 これは本質的に、各ノードが下の行への影響のセグメントを表す三角形のバイナリ展開です。 

最初は、いくつかのノードが黒でマークされています。 他のすべてのノードは赤です。 さらに、赤いノードを黒に再描画することもできますが、最終的な構成はすべての位置で 2 つのクロージャー ルールを満たす必要があります。 まず、ノードが黒の場合、その子も両方とも黒でなければなりません。 次に、ノードの子が両方とも黒の場合、ノード自体も黒でなければなりません。 

これら 2 つのルールにより、最終的な黒のセットが下方向と上方向の両方で強制的に閉じられます。これは、最終的な黒のノードが両方向の伝播下で安定した構造を形成する必要があることを意味します。 タスクは、最終構成がこれらの制約を満たすように黒色のノードを最小限に追加し、最終構成で黒色のノードの数を報告することです。 

重要な制約は、n は 10^6 まで、k は 10^6 までであることです。 これは、ノードの総数が n(n+1)/2 であり、実行可能なメモリまたは時間の制限をはるかに超えているため、完全な三角形を明示的に反復するアプローチを除外します。 有効なソリューションでは、指定された黒いノードのみを処理し、高度に圧縮された表現でエフェクトを伝播する必要があります。 

単純な落とし穴は、各ノードを個別に扱い、安定するまでルールを繰り返し適用することです。 たとえば、底部近くの単一の黒いノードから開始した場合、単純な上向きおよび下向きの伝播によって繰り返し領域が拡大し、最悪の場合には Θ(n^2) ノードに接触する可能性があります。 

より微妙な失敗例は、黒いノードがまばらだが離れている場合に発生します。 ローカル伝播アプローチでは、重複が繰り返し再計算され、事実上同じセグメントを何度も再ウォークするため、最初の黒ノードの数ではなく、影響を受けるノードの数が二次関数的に動作する可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、クロージャプロセスを直接シミュレートします。 最初の黒いノードから始めて、ルールを繰り返し適用します。ノードが黒の場合は、その子をマークします。 子供が両方とも黒人の場合は、親にマークを付けます。 変化が起こらなくなるまで続けます。 これはクロージャ定義を直接エンコードしているため、これは正しいです。 

ただし、ルールを適用するたびにセットが大幅に拡張される可能性があり、最悪の場合、底部近くの単一の黒いノードによって三角形のほぼ全体が黒くなる可能性があります。 三角形には Θ(n^2) 個のノードがあるため、各ノードに一度触れることさえ不可能で、パスを繰り返すとさらに悪化します。 

重要な観察は、実際には完全な三角形を具体化する必要がないということです。 各ノード (i, j) は、最下行の概念的な 1D ラインの区間に対応し、閉包規則は区間の支配関係を正確に記述しています。 ノードは、その影響区間内に少なくとも 1 つの初期黒ノードが存在する場合に黒くなり、逆に、黒さは子区間を完全にカバーすることによってのみ上方に伝播します。 

これは重要な単純化につながります。2D 構造で作業する代わりに、各ノードを圧縮座標系の間隔 [j, j + (n - i)] として再解釈できます。 次に問題は、区間包含の下で最小閉集合を計算することになります。これは、最初の黒いノードから導出された制約をソートおよびマージすることで解決できます。 

最終的な構造は、クロージャに達するまで重複する影響範囲を繰り返しマージすることによって決定されます。 ノード状態をシミュレートする代わりに、「強制黒間隔」の最終セットを計算し、それらの寄与を合計します。

 ## アルゴリズムのチュートリアル

 各黒いノードを、グリッド内の点ではなく範囲構造に制約を課すものとして再解釈します。 

1. 初期の各黒ノード (x, y) を、影響を表す概念的な直線上の区間に変換します。 正確なマッピングは、ノードのすべての子孫が最下行の連続した範囲を形成するという観察から得られます。 この範囲は (x, y) によって完全に決定されます。 
2. このようなすべての間隔を左の端点で並べ替えます。 オーバーラップ構造によってクロージャーがマージされるか分離されたままになるかが決まるため、ソートが必要です。 
3. 間隔をスイープし、重複または隣接する間隔を単一のアクティブ領域にマージします。 2 つの間隔が重なる場合は、それらを接続する黒い伝播のチェーンが存在することを意味するため、それらは同じ最終クロージャに属している必要があります。 
4. マージされた各間隔について、最終的な答えに寄与するノードの数を計算します。 これは、間隔を行全体のノード数に変換し直すことによって行われます。これは、セグメント長の線形合計に対応します。 
5. すべてのマージされた間隔からの寄与を合計して、黒ノードの最終的な数を取得します。 

重要な設計上の選択は、三角形内のノードを明示的に列挙しないことです。 すべての操作は、最初の k ノードから派生した間隔エンドポイントで発生します。 

### なぜ効果があるのか

 クロージャ ルールはモノトーン システムを定義します。ノードが黒になると、そのインフルエンス コーン内のすべてのノードも黒でなければなりません。また、上向きクロージャにより、完全に黒になった子のペアが必ず親に強制されます。 これにより、影響区間の重複を通じて接続されるノードの同値クラスが作成されます。 このような各クラスは、変換された表現内の 1 つのマージされた区間に正確に対応します。 マージではオーバーラップの推移性が考慮されるため、アルゴリズムはクロージャ ルールに基づいて正確に最小固定点を構築します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    
    intervals = []
    
    for _ in range(k):
        x, y = map(int, input().split())
        # map (x, y) to influence interval on bottom row
        # bottom row index is n
        l = y
        r = y + (n - x)
        intervals.append((l, r))
    
    intervals.sort()
    
    merged = []
    for l, r in intervals:
        if not merged or merged[-1][1] < l:
            merged.append([l, r])
        else:
            merged[-1][1] = max(merged[-1][1], r)
    
    # compute contribution
    ans = 0
    for l, r in merged:
        length = r - l + 1
        ans += length * (length + 1) // 2
    
    print(ans)

if __name__ == "__main__":
    solve()
```実装の中核は区間変換です。 各ノード (x, y) は区間 [y, y + (n - x)] にマッピングされ、影響を受けるすべての下位行の位置を表します。 これにより、中間行への接触が完全に回避されます。 

並べ替えとマージにより、重なり合うインフルエンス領域が単一の強制黒コンポーネントに集約されます。 マージされた各間隔は行全体にわたる強制ノードの完全な階段に対応し、ノード数はレイヤーごとに線形に増加するため、最終的な合計には三角数の式が使用されます。 

微妙な点は、マージにおける厳密な不平等です。隣接関係により、共有境界ノードを介した上向きの閉鎖が依然として許可されるため、端点で接触する間隔はマージする必要があります。 

## 実用的な例

 n = 4 で、(2, 1) と (3, 2) に最初の黒いノードがある小さなケースを考えてみましょう。 

まず、それらを下の行の間隔にマッピングします。 

| ノード | 間隔 |
 | --- | --- |
 | (2,1) | [1、3] |
 | (3,2) | [2、3] |

 並べ替えた後、重複するため結合します。 

| ステップ | 現在の間隔 | マージ状態 |
 | --- | --- | --- |
 | 1 | [1、3] | [[1, 3]] |
 | 2 | [2、3] | [[1, 3]] |

 結合された区間は [1, 3] です。 貢献度は 3 × 4 / 2 = 6 なので、答えは 6 です。 

これは、別々の開始点の影響が最下層で重なったときに、それらの開始点がどのように単一のクロージャに崩壊するかを示しています。 

ここで、単一ノード (1, 1) を持つ n = 5 を考えてみましょう。 

| ノード | 間隔 |
 | --- | --- |
 | (1,1) | [1、5] |

 結合は必要ありません。 

| ステップ | 現在の間隔 | マージ状態 |
 | --- | --- | --- |
 | 1 | [1、5] | [[1, 5]] |

 寄与率は 5 × 6 / 2 = 15 となり、構造全体が黒くなります。 これにより、上からの完全な伝播が確認されます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(k log k) | k 間隔のソートが優先され、マージは線形です。 
| スペース | O(k) | 最初の黒ノードごとに 1 つの間隔を保存します。 

k は最大 10^6 であり、すべての演算は非常に小さな定数を使用する最悪の場合でも線形演算であるため、アルゴリズムは制約内に容易に適合します。 算術計算以外の n への依存はありません。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべてのノードが一番下の行にある場合です。これは、すべての入力に対して x = n を意味します。 各ノードは、長さ 1 の間隔にマップされます。アルゴリズムは、隣接しない限り、これらを独立したものとして扱います。 

たとえば、n = 5 ((5,1)、(5,2)、(5,3) となります。

 これらは [1,1]、[2,2]、[3,3] にマップされ、別々のままになり、答え 3 が生成されます。重複がないため、マージ ロジックは独立性を正しく維持します。 

もう 1 つのエッジ ケースは、上部に単一のノード (1,1) がある場合です。 これは [1,n] にマップされ、完全なマージが生成され、すべてのノードが強制的に黒になります。 間隔表現は、反復シミュレーションを行わずに、このグローバルな伝播を即座にキャプチャします。 

これらのケースは、極端なスパース性と完全な優位性の両方が区間マージを通じて均一に処理されることを確認します。
