 ## 解決策
 ## 問題の理解

 この問題はエイプリル フール コンテストから生まれました。 重要なトリックは、次のように表示されるシンボルです。`⊕`実際にはビットごとの XOR ではありません。 シンボルに付けられたリンクはパズルにつながり、その解決策によって次のことが明らかになります。`⊕`乗算として解釈する必要があります。 それが発見されると、その状態は次のようになります。$$(a_i a_j)(a_i^2 a_j^2)\equiv k \pmod p,$$これを単純化すると$$a_i^3 a_j^3 \equiv k \pmod p.$$したがって、素数を法とする一連の個別の数値が与えられます。$p$そして、その立方体が次のように乗算されるペアを数えなければなりません。$k$モジュロ$p$。 

配列サイズが次の値に達しました$3 \cdot 10^5$これにより、すべてのペアのチェックが即座に除外されます。 二次解はおおよそのパフォーマンスを発揮します$4.5 \cdot 10^{10}$最悪の場合、制限をはるかに超えたペアチェックが行われます。 線形に近いものが必要です。$O(n \log p)$。 

微妙なケースの 1 つは、$k=0$。 以来$p$プライム、製品です$a_i^3 a_j^3$ゼロモジュロです$p$2 つの数値のうち少なくとも 1 つがゼロである場合に限ります。 すべての配列値は個別であるため、ゼロは最大 1 回出現することができます。 

考慮する：```
3 5 0
0 1 2
```有効なペアは次のとおりです。$(0,1)$そして$(0,2)$, したがって、答えは2です。 

モジュラー逆数を盲目的に計算する不注意な実装は、ゼロには逆数がないため、ここで失敗します。 

もう 1 つの重要なケースは次のような場合です。$k \neq 0$しかし、一部の配列要素はゼロに等しい。```
3 5 1
0 1 2
```ゼロを含むペアは、その積が常にゼロを法として等しいため、方程式を満たすことができません。$p$。 このような要素は、ゼロ以外の値と一致する場合はスキップする必要があります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 すべてのペアについて$(i,j)$、計算する$$a_i^3 a_j^3 \bmod p$$そしてそれを比較してください$k$。 これは状態を直接確認するので正しいです。 残念ながら、$$\frac{n(n-1)}2$$ペア。 と$n=3\cdot10^5$、それは約です$4.5\cdot10^{10}$小切手。 

方程式の構造は、より良い方向性を示唆しています。 させて$$x_i = a_i^3 \bmod p.$$条件はこうなります$$x_i x_j \equiv k \pmod p.$$固定の場合$x_j\neq 0$、必要なパートナーは一意に決定されます。$$x_i \equiv k \cdot x_j^{-1} \pmod p.$$以来$p$が素数である場合、すべての非ゼロ剰余は逆数を持ちます。 これにより、問題がペアテストから頻度カウントに変換されます。 

配列を左から右に処理します。 現在の値については$x_j$、以前に出現したはずの剰余を計算します。 ハッシュ マップには、各立方体残基がすでに表示された回数が保存されます。 必要な残基の数は、位置で終わる有効なペアの数と正確に一致します。$j$。 

唯一の特別な状況は、$k=0$ここで、逆関数は使用できず、方程式の特徴は非常に単純です。

 ## アルゴリズムのチュートリアル

 1. 入力配列を読み取ります。 
2.ハンドル$k=0$別に。 

方程式は次のようになります$$a_i^3 a_j^3 \equiv 0 \pmod p.$$以来$p$が素数の場合、これはまさに 1 つの要素がゼロのときに発生します。 
3. ゼロが存在する場合、その要素に関係するすべてのペアが有効です。 

すべての配列値は個別であるため、ゼロは最大 1 つです。 答えは$n-1$。 
4. ゼロが存在しない場合、および$k=0$、有効なペアが存在しません。 
5. のために$k\neq0$、ハッシュマップを作成します`cnt`すでに処理された立方体残差の頻度を保存します。 
6. アレイを左から右にスキャンします。 
7. 値ゼロをスキップします。 

ゼロを含むペアはゼロ以外の積モジュロを生成できません$p$。 
8. コンピューティング$$x = a_i^3 \bmod p.$$9. 逆モジュラーを計算する$$x^{-1} \equiv x^{p-2} \pmod p$$フェルマーの定理を使って。 
10. 必要なパートナー残基は次のとおりです。$$need = k \cdot x^{-1} \bmod p.$$11.追加`cnt[need]`答えに。 

これまでに見られたすべての出来事`need`現在の要素と有効なペアを形成します。 
12. 現在の残基を挿入します`x`マップに。 
13. すべての要素を処理した後、累積された答えを出力します。 

### なぜ効果があるのか

 ゼロ以外の要素ごとに、その立方体剰余モジュロを保存します。$p$。 位置処理時$j$、マップには位置からの残基が正確に含まれています$i<j$。 

方程式$$x_i x_j \equiv k \pmod p$$と同等です$$x_i \equiv k x_j^{-1} \pmod p$$なぜなら$x_j\neq0$。 したがって、すべての有効な以前のパートナーは、残基の 1 つの出現に対応します。`need`、およびすべての発生`need`有効なペアが生成されます。 各ペアは、その右エンドポイントが処理されるときに 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, p, k = map(int, input().split())
    a = list(map(int, input().split()))

    if k == 0:
        if 0 in a:
            print(n - 1)
        else:
            print(0)
        return

    cnt = {}
    ans = 0

    for v in a:
        if v == 0:
            continue

        x = pow(v, 3, p)
        inv = pow(x, p - 2, p)
        need = (k * inv) % p

        ans += cnt.get(need, 0)
        cnt[x] = cnt.get(x, 0) + 1

    print(ans)

if __name__ == "__main__":
    main()
```最初のブロックは特殊なケースを処理します$k=0$。 すべての値は個別であるため、存在できるゼロは最大 1 つです。 存在する場合、他のすべての要素はそれと有効なペアを形成します。 

一般的な場合、マップには立方体剰余の頻度が格納されます。 表現`pow(v, 3, p)`計算する$v^3 \bmod p$オーバーフローなしで。 表現`pow(x, p - 2, p)`フェルマーの定理を使用して逆モジュラーを計算します。これは有効です。$p$プライムであり、$x\neq0$。 

順序が重要です。 現在の残基を挿入する前にマップをクエリします。 これは、次のものとのみペアになることを保証します$i<j$カウントされ、セルフペアリングが妨げられます。

 ## 特殊なケース

 次のことを考慮してください。```
3 5 0
0 1 2
```アルゴリズムはすぐに$k=0$支店。 ゼロが存在するので返す$n-1=2$。 有効なペアは次のとおりです。$(0,1)$そして$(0,2)$、数学的条件に正確に一致します。 

ここで次のことを考えてみましょう。```
3 5 0
1 2 3
```もう一度、$k=0$ブランチが使用されていますが、ゼロがありません。 1 つの因数がゼロでない限り、素数を法としてゼロになる積はありません。したがって、答えは次のようになります。`0`。 

ついに：```
3 5 1
0 1 2
```値 0 は処理中にスキップされます。 残りの残留物は通常どおりチェックされます。 ターゲット剰余方程式を満たすペアがないため、答えは次のようになります。`0`。 ゼロをスキップすると、未定義となるゼロの逆数を計算する試みが回避されます。
