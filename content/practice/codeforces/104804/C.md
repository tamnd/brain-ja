 ## 問題の理解

 私たちは、船員と呼ばれる一連のアイテムに対する非常に単純な獲得プロセスをシミュレートしています。 がある$n$合計およびそれぞれの利用可能な船員$k$ラウンドで、イゴールは残った船員からちょうど1人の船員を選びます。 各船員には、船員の世界的な順序におけるその位置によって純粋に決定される固定値があります。つまり、最初の船員が価値があります。$m$コイン、2番目の価値があります$m+1$、3番目は価値があります$m+2$、 等々。 

船員間の相互作用やランダム性がないため、重要なのは最初の船員の中でどのインデックスが選ばれるかだけです。$n$ポジションは最初の段階で選択されます$k$ピックします。 イゴールはラウンドごとに常に 1 人の船員を連れており、利用可能以外の制限はないため、このプロセスは最初の船員を取るのと同等です。$\min(n, k)$船員が順番に。 

出力は、これらのラウンド中に取得されたすべての船員の値の合計です。 

制約により、最大で$10^5$船員と$10^5$ラウンドします。 各セーラーを個別に反復するソリューションはすでに許容範囲の境界線にありますが、入れ子になったループや繰り返しの再計算を伴うものは、全体として厳密に線形である場合にのみ問題ありません。 算術構造を認識せずに選択を段階的にシミュレートしようとするアプローチは、不必要なオーバーヘッドを引き起こす危険性がありますが、それでも安全です。 本当の単純化は、選択された値が連続した等差数列を形成していることを認識することから生まれます。 

微妙なエッジケースが現れるのは、$k = 0$。 その場合、船員は採用されず、答えはゼロでなければなりません。 もう 1 つのエッジケースは次のような場合です$k > n$、ここでのみ$n$船員が存在するため、プロセスは事実上早期に停止し、$n$条件が貢献します。 常に合計する素朴な実装$k$用語は、存在しない船員が存在すると誤って仮定することになります。 

## アプローチ

 プロセスを直接シミュレートすると、船員を 1 人ずつ取得し、その値を蓄積します。 の値$i$- 番目に捕まった船員は$m + i - 1$、そして、その後のいずれかで停止します$k$ステップまたは疲れた後$n$船員たち。 この直接メソッドは、取得した船員ごとに一定量の作業を実行するため、$O(\min(n, k))$、これはすでに制限を十分に満たす速度です。 

ただし、その構造は任意ではなく、 から始まる連続した等差数列です。$m$違いあり$1$。 反復する代わりに、閉じた形式で合計を計算できます。 もし$t = \min(n, k)$の場合、シーケンスは次のようになります。$$m, m+1, m+2, \dots, m+t-1$$これは標準的な等差級数であり、その合計は次のように計算できます。$$t \cdot m + \frac{t(t-1)}{2}$$主な改善点は、反復をこの式の直接評価に置き換え、計算を一定時間に短縮することです。

 ## アルゴリズムのチュートリアル

 1. 整数の読み取り$n$、$k$、 そして$m$。 これらは、存在する船員の数、取得される船員の数、および最初の船員の開始値を定義します。 
2. 実際に何人の船員が捕らえられるかを決定します: set$t = \min(n, k)$。 これは、存在する以上の船員を受け入れることができないため、必要です。 
3. から始まる等差数列の合計を計算します。$m$長さのある$t$。 反復する代わりに、合計が等しい恒等式を使用します。$t \cdot m + \frac{t(t-1)}{2}$。 
4. 計算された合計を出力します。 

### なぜ効果があるのか

 あらゆる段階で$i$、付加価値はまさに$m + i$、連続する船員間で一貫して 1 ずつ増加します。 これにより、取得された値がギャップや並べ替えのない完全な等差数列を形成することが保証されます。 正確に最初のものを取るので、$t$船員は順番に配置されますが、順列や選択効果によって順序が変更されることはありません。 したがって、等差数列の合計公式は、プロセスの有効な実行の累積結果と正確に一致します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k, m = map(int, input().split())
    
    t = min(n, k)
    
    # sum of m + (m+1) + ... + (m+t-1)
    # = t*m + (0 + 1 + ... + t-1)
    # = t*m + t*(t-1)//2
    ans = t * m + t * (t - 1) // 2
    
    print(ans)

if __name__ == "__main__":
    solve()
```コードはまず入力値を読み取り、すぐに問題のサイズを次のように縮小します。$t = \min(n, k)$有効な選択のみを考慮するようにします。 次に、等差級数の公式を直接適用します。 減算のない公式では、浮動小数点演算が一切回避され、整数演算に完全に依存するため、Python の無制限の整数では安全です。 

よくある落とし穴はクランプを忘れることです$k$による$n$、これは船員がそれを超えていると誤って想定することになります。$n$存在する。 もう 1 つは、整数除算ではなく除算を使用して合計を実装することです。これにより、他の言語で浮動小数点エラーが発生する可能性があります。
