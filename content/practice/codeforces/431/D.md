 ## 問題の理解

 正の整数を見つける必要があります`n`間隔内にあるように`(n, 2n]`、 その通り`m`数字は正確に持っています`k`バイナリ表現のもの。 

この状態を別の言い方で表現すると次のようになります。 

もし`f(x)`内の整数の数を示します`[0, x]`そのバイナリ形式には正確に次のものが含まれます`k`ビットを設定してから、有効な整数の数を設定します。`(n, 2n]`等しい$f(2n)-f(n)=m$したがって、タスクは何かを見つけることになります`n ≤ 10^18`この方程式を満たすこと。 

この制約により、数値を 1 つずつチェックすることが完全に排除されます。 すべての数値を繰り返しても、`10^18`不可能です。 対数的な複雑さに近いものが必要です。 答えが存在することが保証されており、ターゲット式は以下に単調に依存するため、`n`、二分探索が自然な方向になります。 

難しいのは計算です`f(x)`効率的に。 単純な実装では、次のすべての数値を検査します。`0`に`x`セットビットをカウントします。これにはコストがかかります`O(x log x)`。 と`x`近く`10^18`、それは絶望的です。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

もし`k`で利用可能なビット数よりも大きいです`x`、の答え`f(x)`ゼロでなければなりません。 たとえば:

現在の数値自体が正確に次の値を持っている場合、別の微妙なケースが発生します。`k`ビットを設定します。 次のように仮定します。 

入力:```

## アプローチ

 ブルートフォースのアイデアは単純です。 候補者ごとに`n`のすべての数値を検査します。`(n, 2n]`、正確に何個持っているか数えてください`k`ビットを設定し、カウントが等しい場合に停止します`m`。 

これは、状態を直接確認できるため機能します。 問題は規模だ。 シングルでも`n`、間隔のサイズは`n`。 もし`n`周りにいる`10^18`、おおよそ必要になります`10^18`ポップカウント操作。 それは現実的な限界をはるかに超えています。 

次の改善点は、正確に数値のカウントのみが必要であることを観察することです。`k`ビットをある限界まで設定します。 定義する：$f(x)=\#\{0\le t\le x\mid \operatorname{popcount}(t)=k\}$次に、内部の有効な整数の数`(n, 2n]`は次のようになります:$f(2n)-f(n)$さて、問題は効率的な評価に帰着します。`f(x)`。 

ここでバイナリの組み合わせが役立ちます。 ビットを処理します`x`最も重要なものから最も重要でないものへ。 私たちが何かに遭遇するたびに、`1`ビット、私たちは配置することを選択するかもしれません`0`そこで、残りの必要なセットビットを下位の位置に自由に分配します。 そのような可能性の数は二項係数です。 

たとえば、まだ必要な場合は、`r`1つとそこにあります`p`残りのビット位置の場合、ウェイの数は次のようになります。$\binom{p}{r}$これは計算します`f(x)`約64ステップで。 

最後の観察は単調性です。 として`n`増える、量が増える`f(2n) - f(n)`決して減りません。 数字は区間に入るのみで、消えることはありません。 これにより二分探索が可能になります`n`。

 ## アルゴリズムのチュートリアル

 1. すべての二項係数を事前計算する`C[n][r]`のために`0 ≤ n, r ≤ 64`。 

必要なのは最大 64 ビットだけです。`10^18 < 2^60`64 を使用すると実装が簡単になります。 
2. 関数を実装する`count(x)`それは整数の個数を返します`[0, x]`正確に含む`k`ビットを設定します。 

この関数はビットを上位から下位にスキャンします。 
3. 変数を維持する`ones_used`、プレフィックス内ですでに固定されている設定ビットの数を表します。 
4. 現在のビットが`x`は`1`、このビットを作ることを検討しています`0`その代わり。 

次に、残りの下位位置には、正確に次のような配置を含めることができます。$k-ones\_used$もの。 

あれば`pos`残りの位置には、以下を追加します。$\binom{pos}{k-ones\_used}$5. その分岐を処理した後、引き続き実際のビットをたどります。`x`、このビットが残ることを意味します`1`。 

インクリメント`ones_used`。 
6. いつでも`ones_used > k`、継続が有効になることはないため、早めに停止してください。 
7. すべてのビットが処理されたら、次のコードを含めます。`x`正確に含まれている場合はそれ自体`k`ビットを設定します。 
8. 以下を定義します。$g(n)=count(2n)-count(n)$これは、次の整数の数に等しくなります。`(n, 2n]`まさに`k`ビットを設定します。 
9. 最小値の二分探索`n`次のような:$g(n)\ge m$10. 問題の存在が保証されているため、検索が終了すると、取得された`n`を満たす:$g(n)=m$### なぜ効果があるのか

 カウント関数は、以下のすべての数値を列挙します。`x`ビットを左から右に固定します。 いつでも`1`ビットが表示されます`x`、選択する`0`そこでは、より小さい数値のブロック全体が作成され、組み合わせ論は、必要な数のセット ビットが含まれるブロックの数を正確にカウントします。 

二分探索は正しいので、`g(n)`単調非減少です。 増加中`n`間隔を広げます`(n, 2n]`右の方へ。 新しい数値は条件を満たす可能性がありますが、以前にカウントされた数値が合計数を減らす形で消えることはありません。 答えが存在するため、標準の下限二分探索により有効な答えが見つかります。`n`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXB = 64

# Precompute combinations
C = [[0] * (MAXB + 1) for _ in range(MAXB + 1)]

for n in range(MAXB + 1):
    C[n][0] = 1
    C[n][n] = 1

for n in range(1, MAXB + 1):
    for r in range(1, n):
        C[n][r] = C[n - 1][r - 1] + C[n - 1][r]

def solve():
    m, k = map(int, input().split())

    def count_upto(x):
        if x < 0:
            return 0

        ans = 0
        ones_used = 0

        for pos in range(MAXB - 1, -1, -1):
            if (x >> pos) & 1:
                need = k - ones_used

                if 0 <= need <= pos:
                    ans += C[pos][need]

                ones_used += 1

                if ones_used > k:
                    break

        else:
            if ones_used == k:
                ans += 1

        return ans

    def g(n):
        return count_upto(2 * n) - count_upto(n)

    lo, hi = 1, 10**18

    while lo < hi:
        mid = (lo + hi) // 2

        if g(mid) >= m:
            hi = mid
        else:
            lo = mid + 1

    print(lo)

solve()
```最初のセクションでは、パスカルの三角形を使用して二項係数を事前計算します。 関連する最大ビット数は最大 64 であるため、このテーブルは非常に小さいです。 

コアロジックは内部にあります`count_upto(x)`。 この関数はビットを上位から下位に処理します。 何かに遭遇するたびに、`1`ビット、以下の配置によって形成されるすべての小さい数値をカウントします。`0`そこで、残りの必要な設定ビットを下位の位置に分配します。 

式:$C[pos][need]$これが digital-DP のアイデアの核心です。 がある`pos`利用可能な下位ビット位置があるため、正確に選択する必要があります`need`彼らのうちからなる`1`。 

の`else`に付属の`for`ループは微妙です。 Python では、ループが終了されなかった場合にのみ実行されます。`break`。 つまり、すべてのビットが正常に処理され、次のものが含まれる可能性があります。`x`ポップカウントが等しい場合はそれ自体`k`。 

二分探索では、`g(mid) >= m`。 これは、最初の有効な位置の下限検索です。 使用する`>`代わりに、完全一致をスキップします。 

すべての算術は Python 整数内に安全に収まります。
