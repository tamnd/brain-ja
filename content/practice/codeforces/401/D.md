 ## 解決策
 ## 問題の理解

 与えられた数値の桁を並べ替えることで形成できる整数の数を数えるように求められます。$n$、ゼロで始まらず、指定された係数で割り切れます。$m$。 入力$n$と同じ大きさにすることができます$10^{18}$、これは最大 18 桁を意味し、$m$出力は単に有効な数値のカウントです。 

課題は、すべての順列を単純に生成するのが現実的ではないという事実にあります。 18 桁の異なる数字であっても、$18! \approx 6.4 \times 10^{15}$順列は天文学的に大きい。 これにより、順列を明示的に列挙するソリューションは除外されます。 

エッジケースには、数字が繰り返される数値が含まれるため、個別の順列の数が減少する可能性があります。 先頭のゼロは無効であるため、ゼロ桁の数値には特別な注意が必要です。 たとえば、$n = 102$そして$m = 2$、順列$012$ゼロで始まるので無効ですが、$120$そして$210$有効です。 

もう 1 つの微妙な点は、割り算の処理です。 数値が多すぎるため、数値を生成した後に割り切れるかどうかを確認できません。 代わりに、数値を構築しながら剰余を増分的に計算する必要があります。 

## アプローチ

 ブルートフォース手法では、次の桁のすべての順列が生成されます。$n$、それらがゼロで始まらないことを確認し、次に次の方法で割り切れるかどうかを確認します。$m$。 これは桁数が非常に少ない数値に対して機能します。 と$d$桁数、これには最大で$d!$順列、それぞれ$O(d)$割り切れるかどうかを確認するため、$O(d! \cdot d)$。 のために$d = 18$、これは不可能です。 

重要な点は、順列を明示的に生成する必要がないということです。 それぞれの数字は数字を並べ替えたものであり、これまでにどの数字が使用されてきたかによって定義される状態空間が自然に示唆されます。 以来$d \le 18$、使用された数字を長さのビットマスクとしてエンコードできます。$d$。 残りの問題は、部分ビットマスクと現在の剰余モジュロが与えられた数値を完成させる方法の数を計算することです。$m$。 

ビットマスクと剰余を使用した動的プログラミングは、これを解決します。 させて`dp[mask][rem]`に対応する数字を使用して数字を形成する方法の数を表します`mask`残りが残るもの`rem`モジュロ`m`。 各ステップで、未使用の数字を次の位置に配置し、剰余演算を使用して剰余を更新し、マスクを更新します。 ゼロから始まる数を数えることを避けるために、最初の位置にいる場合は単純にゼロをスキップします。 重複する数字を二重にカウントせずに処理するために、残りのセットに 2 つの同一の数字がある場合、常に左端の未使用の数字が順序付けで最初に使用されるようにします。

 | ブルートフォース | O(d! * d) | O(d!) | d > 10 では遅すぎます |

 ## アルゴリズムのチュートリアル

 1.数値を変換する$n$数字のリストに変換して並べ替えます。 並べ替えにより、並べ替えを二重にカウントすることなく、繰り返される数字を一貫して処理できるようになります。 
2. DP テーブルの初期化`dp[mask][rem]`-1 を付けると、未計算の状態を示します。`mask`は整数です。$i$-th ビットは、$i$- 番目の桁が使用されています。`rem`剰余モジュロです`m`。 
3. 再帰関数を定義する`count(mask, rem)`これは、未使用の数字を使用して形成できる有効な数値の数を返します。`mask`、現在の剰余を考えると`rem`。 
4. 再帰で、すべての数字が使用されている場合 (`mask == (1 << d) - 1`）、どうかを確認してください`rem == 0`。 存在する場合は 1 を返し、そうでない場合は 0 を返します。これが基本的なケースです。 
5. それ以外の場合は、すべての桁位置を反復処理します。`i`。 すでに使用されている数字はスキップします (`mask & (1 << i)`)、または次の場合は先頭のゼロをスキップします`mask == 0`そしてその数字はゼロです。 同じ数字が二重にカウントされるのを避けるため、前の数字と同じで、前の数字が使用されていない場合は、その数字をスキップします (`digits[i] == digits[i-1]`そして`(mask & (1 << (i-1))) == 0`）。 
6. 有効な選択をするには、再帰的に呼び出します。`count(mask | (1 << i), (rem * 10 + digits[i]) % m)`そして結果を積み上げていきます。 
7. 結果を次の場所に保存します`dp[mask][rem]`そしてそれを返します。 

機能する理由: DP は、未使用の数字と剰余のすべての組み合わせが 1 回だけ考慮されることを保証します。 前の同一の数字が使用されていない場合に繰り返される数字をスキップすると、並べ替えの過剰カウントが防止されます。 先頭のゼロは明示的に避けられます。 剰余を段階的に構築することにより、次で割り切れる数値のみを考慮します。`m`最終チェックで完全な数値を作成する必要がなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10000)

def main():
    n, m = input().split()
    m = int(m)
    digits = sorted([int(c) for c in n])
    d = len(digits)
    dp = [[-1 for _ in range(m)] for _ in range(1 << d)]

    def count(mask, rem):
        if mask == (1 << d) - 1:
            return 1 if rem == 0 else 0
        if dp[mask][rem] != -1:
            return dp[mask][rem]
        total = 0
        for i in range(d):
            if mask & (1 << i):
                continue
            if i > 0 and digits[i] == digits[i-1] and not (mask & (1 << (i-1))):
                continue
            if mask == 0 and digits[i] == 0:
                continue
            total += count(mask | (1 << i), (rem * 10 + digits[i]) % m)
        dp[mask][rem] = total
        return total

    print(count(0, 0))

if __name__ == "__main__":
    main()
```最初のセクションでは、入力された数値を数字に変換し、並べ替えます。 DP テーブル`dp`は、数字のすべてのサブセットとすべての剰余に対して初期化されます。 再帰的`count`関数はアルゴリズムのウォークスルーを反映しています。 使用されている数字、先頭のゼロ、および繰り返しの数字をスキップするための条件により、正確さが保証されます。 有効なカウントを蓄積します`total`、メモ化して、最後に結果を出力します。
