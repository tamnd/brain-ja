 ## 解決策
 ## 問題の理解

 休憩を挟んで 2 つのフェーズに分かれたキノコ栽培コンテストが開催されます。 各参加者には 2 つの速度がありますが、問題は、参加者がそれらを使用する順序がわからないことです。 長さ _t1_ の最初の段階では、キノコは 1 つの速度で成長します。 休憩後、キノコの高さは _k_ パーセント縮小します。 次に、長さ _t2_ の第 2 段階では、キノコが第 2 の速度で成長します。 各参加者は、最終的なキノコの高さを最大化するために 2 つの速度の順序を選択します。 私たちのタスクは、すべての参加者の最終的な身長を計算し、身長の高いものから低いものへ並べて出力することです。 2 つのキノコの高さが等しい場合、インデックスが小さい参加者が最初になります。 

入力により、_n_、参加者数、期間 _t1_ と _t2_、および減少率 _k_ が得られます。 次に、各参加者の 2 つの速度 _a_i_ と _b_i_ が与えられます。 出力は、説明どおりに並べ替えられた、各参加者の最終的な最大身長を小数点以下 2 桁に四捨五入したものです。 

制約は小さく、_n_、_t1_、_t2_ はすべて最大 1000、速度は最大 1000 です。これは、O(n) または O(n log n) の計算を簡単に実行できることを意味します。 増加には整数演算ではない割合の削減が含まれるため、浮動小数点演算には注意が必要です。 

難しい可能性があるエッジ ケースには、2 つの速度が等しい参加者 (どちらの順序でも同じ結果が得られる場合)、または極端な _k_ 値 (100% 削減など) が含まれ、これにより最初のフェーズが完全に消去されます。 

## アプローチ

 ブルートフォース手法は簡単です。参加者ごとに、考えられる両方の速度の次数を試し、各次数の最終的なキノコの高さを計算し、最大値を取得します。 具体的には、比較する 2 つの高さは次のとおりです。```
h1 = a_i * t1 * (1 - k/100) + b_i * t2
h2 = b_i * t1 * (1 - k/100) + a_i * t2
```最大値`h1`そして`h2`その参加者にとって最適な高さです。 これが機能するのは、参加者の数が少なく、各計算が定数時間であるため、O(n) の解が得られます。 身長を計算した後、参加者を身長の降順で並べ替え、同点の場合はインデックスの昇順で並べ替えます。 

より高速でクリーンな実装を実現するための重要な洞察は、他の組み合わせを検討する必要がないということです。 参加者あたりの速度と順序は 2 つだけであるため、これ以上の最適化はできません。 その後の並べ替えは標準であり、結果テーブルで正しい順序が保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n log n) | O(n) | 承認済み |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ソートは O(n log n) であり、高さの線形 O(n) 計算よりも優先されます。 

## アルゴリズムのチュートリアル

 1. 参加者数を読む`n`、2つの期間`t1`そして`t2`、休憩の短縮`k`。 削減係数を小数として保存します`r = (100 - k)/100`計算を簡略化するため。 
2. 空のリストを初期化する`results`タプルを保存します`(participant_index, max_height)`。 
3. 各参加者を反復処理します。 2 つの速度を読み取る`a`そして`b`。 
4. 参加者が使用する場合は、最終的な高さを計算します。`a`まず、それから`b`:`h1 = a * t1 * r + b * t2`。 
5. 参加者が使用する場合は、最終的な高さを計算します。`b`まず、それから`a`:`h2 = b * t1 * r + a * t2`。 
6.テイク`max(h1, h2)`参加者の最適なキノコの高さとして。 
7. 追加`(participant_index, max_height)`に`results`。 
8. すべての参加者が処理されたら、並べ替えます。`results`まずは`-max_height`(降順) そして次によって`participant_index`(昇順) 関係を解決します。 
9. 各参加者のインデックスと身長を小数点第 2 位まで正確にフォーマットして出力します。 

機能する理由: 不変条件は、各参加者について、2 つの速度の可能な次数をすべて調査したということです。 最大高さは正しいことが保証されます。 その後並べ替えると、タイブレーク ルールを尊重して正しいランキングが保証されます。 組み合わせが見逃されることはなく、計算には競技ルールが正確に反映されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, t1, t2, k = map(int, input().split())
r = (100 - k) / 100  # reduction factor

results = []

for i in range(1, n + 1):
    a, b = map(int, input().split())
    h1 = a * t1 * r + b * t2
    h2 = b * t1 * r + a * t2
    max_height = max(h1, h2)
    results.append((i, max_height))

# sort by height descending, then index ascending
results.sort(key=lambda x: (-x[1], x[0]))

for idx, height in results:
    print(f"{idx} {height:.2f}")
```コードはアルゴリズムのステップに正確に従っています。 除算の繰り返しを避けるために、削減係数が事前に計算されます。 高さは、乗算後の精度を維持するために浮動小数点数として格納されます。`r`。 並べ替えでは、ラムダ関数を使用して、高さによる降順と参加者のインデックスによる昇順に並べ替えます。

## 複雑さの分析
