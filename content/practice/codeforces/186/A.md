 ## 解決策
 ## 問題の理解

 2 人のドワーフのゲノムを表す 2 つの文字列が与えられます。 目的は、これら 2 つのゲノムが非常に具体的な定義に基づいて同じ人種に属するかどうかを判断することです。つまり、最初のゲノム内の 2 つの文字を正確に交換することによって、最初のゲノムを 2 番目のゲノムに変換できます。 文字列の長さが異なる場合がありますが、その場合は自動的に互換性がなく、各文字列には小文字のラテン文字のみが含まれます。 文字列は異なることが保証されているため、単純な「すでに等しい」場合を考慮する必要はありません。 

この制約は、各文字列に最大 100,000 文字を含めることができることを示しています。 これは、可能なすべてのスワップを明示的に試すなど、文字列の長さが 2 次であるアプローチは、最悪の場合でも最大約 10^10 の操作を実行することになるため、2 秒の制限時間内では実行不可能であることを意味します。 線形または線形に近い時間ソリューションが必要です。 

一部の特殊なケースは微妙です。 たとえば、文字列の長さが異なる場合、答えは即座に「NO」になります。 文字が異なる 2 つの位置を除いて文字列が同じである場合、答えは「YES」になります。 3 つ以上の位置が異なる場合、1 つのペアを交換しても不一致を修正できないため、答えは「いいえ」です。 素朴なアプローチでは文字数だけを比較する可能性がありますが、「ab」と「ba」、または「aa」と「ab」のような文字列では失敗します。これは、単一のスワップ変換を許可せずに文字数が一致する可能性があるためです。 

## アプローチ

 ブルートフォース手法では、最初の文字列内の位置のすべてのペアをチェックして交換し、結果が 2 番目の文字列と等しいかどうかをテストします。 この方法は、文字通りすべての可能なスワップをテストするため、正しいです。 長さ n の文字列の場合、考慮すべきペアが O(n^2) あり、結果の文字列の比較には O(n) 時間がかかります。 これにより、最悪の場合、O(n^3) 回の演算が行われ、n = 10^5 にとっては遅すぎます。 

最適なアプローチは、文字列が異なる位置のみが関連していることを観察することから得られます。 文字列の正確に 2 つの位置が異なる場合は、最初の文字列内の 2 つの文字を交換すると 2 番目の文字列が得られるかどうかを確認できます。 それ以外の数の位置が異なる場合、1 回の交換で修正することは不可能です。 これにより、問題は両方の文字列を通る単一の線形スキャン、不一致のインデックスの記録、および定数時間チェックの実行に軽減されます。 これにより、O(n) の解が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 両方のゲノム文字列を読み取り、変数 s1 および s2 として保存します。 
2. 長さが異なるかどうかをすぐに確認します。 存在する場合は、「NO」を出力して終了します。これは、スワップでは異なる長さの文字列を調整できないためです。 
3. 空のリストを初期化する`diff`s1 と s2 が異なるインデックスを保持します。 
4. インデックスによって文字列を反復処理します。 各位置で文字が異なる場合は、インデックスを追加します。`diff`。 
5. After scanning, check the length of`diff`。 正確に 2 でない場合は、スワップが必要ないか、複数のスワップが必要になるため、「NO」と出力されます。 
6. もし`diff`正確に 2 つのインデックス i と j が含まれている場合、s1[i] と s1[j] を交換すると s1 が s2 と等しくなるかどうかを確認します。 具体的には、s1[i] == s2[j] および s1[j] == s2[i] を検証します。 
7. スワップ条件が満たされている場合は、「YES」を出力します。 それ以外の場合は、「NO」を出力します。 

文字列が異なる位置のみを修正できるという不変条件があるため、正確性が保証されます。 2 つのポジションを超える不一致は、1 回のスワップでは修正できません。 差異を記録し、スワップ状態を直接確認することで、有効なケースと無効なケースをすべて効率的に処理します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s1 = input().strip()
s2 = input().strip()

if len(s1) != len(s2):
    print("NO")
    sys.exit()

diff = []
for i in range(len(s1)):
    if s1[i] != s2[i]:
        diff.append(i)

if len(diff) != 2:
    print("NO")
else:
    i, j = diff
    if s1[i] == s2[j] and s1[j] == s2[i]:
        print("YES")
    else:
        print("NO")
```コードは高速 I/O 読み取りで始まり、改行文字がトリミングされます。 長さチェックにより、互換性のない文字列が即座にフィルタリングされます。 メインループは不一致インデックスを収集します。 正確に 2 つの違いが見つかった場合にのみ、一定時間のチェックであるスワップ検証が試行されます。 使用する`sys.exit()`長さチェックの後、明らかに互換性のない文字列に対する不必要な計算がさらに防止されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | 文字列を 1 回スキャンして差異を記録し、定数時間のスワップ チェックを実行します。 
| スペース | お(1) | リスト`diff`最大 2 つのインデックスを保存します。 n | を使用しても追加のメモリは増加しません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from contextlib import redirect_stdout
    out = io.StringIO()
    with redirect_stdout(out):
        s1 = input().strip()
        s2 = input().strip()
        if len(s1) != len(s2):
            print("NO")
            return
        diff = []
        for i in range(len(s1)):
            if s1[i] != s2[i]:
                diff.append(i)
        if len(diff) != 2:
            print("NO")
        else:
            i, j = diff
            if s1[i] == s2[j] and s1[j] == s2[i]:
                print("YES")
            else:
                print("NO")
    return out.getvalue().strip()

# Provided samples
assert run("ab\nba\n") == "YES", "sample 1"
assert run("aa\nab\n") == "NO", "sample 2"

# Custom cases
assert run("abcd\nabdc\n") == "YES", "swap middle letters"
assert run("abcd\nacbd\n") == "NO", "requires two swaps"
assert run("a\nb\n") == "NO", "single character mismatch"
assert run("abc\nabcd\n") == "NO", "different lengths"
assert run("abba\nbaba\n") == "NO", "two mismatches but swap doesn't match"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | abcd\nabdc | はい | 中間ポジションでのスワップを正しく識別します。 
| abcd\nacbd | いいえ | 複数のスワップが必要なケースを拒否します。 
| \nb | いいえ | | 異なる 1 文字の文字列を処理します。 
| abc\nabcd | いいえ | 長さが等しくない文字列を処理します。 
| アバ\nババ | いいえ | 2 つの不一致が存在しますが、スワップは一致しません |

 ## 特殊なケース

 長さが等しくない 2 つの文字列の場合、次のようになります。`abc`そして`abcd`の場合、アルゴリズムは長さの不一致を直ちに検出し、「NO」を出力します。 ちょうど 1 つの位置が異なる文字列の場合、次のように`aa`そして`ab`の場合、差分リストの長さは 1 であるため、「NO」が出力されます。 スワップが有効な 2 つの位置が異なる文字列の場合、次のようになります。`ab`そして`ba`の場合、アルゴリズムはスワップ インデックスを正しく識別し、「YES」を出力します。 3 つ以上の違いがある文字列、または交換に合わせて整列しない 2 つの違いがある文字列の場合、次のようになります。`abba`そして`baba`の場合、アルゴリズムは「NO」を出力します。 diff-length チェックと正確なスワップ条件により、各エッジ ケースが正しく処理されます。
