 ## 解決策
 ## 問題の理解

 小惑星は一辺の長さが 100 万の巨大な立方体グリッドであるため、セルを明示的に保存することは不可能です。 空のセルはトンネルによって削除されたセルのみです。 各トンネルは、3 つの軸のいずれかに平行な完全な直線です。 

トンネルは、固定された 2 つの座標によって説明できます。 たとえば、X 軸に沿ったトンネルは次のように識別されます。`(y, z)`、すべての`(x, y, z)`セルが空です。 このタスクは、指定された 2 つの空セルが空セルの同じ接続領域に属しているかどうかを答えることです。 

制約が重要な問題です。 トンネルは 300,000 個、クエリは 500,000 個存在する可能性があります。 キューブ上の BFS には最大で`10^18`細胞、それは不可能です。 すべての空のセルを含むグラフでも大きすぎます。 アルゴリズムはトンネル自体でのみ機能する必要があります。 

隠された構造は、小惑星の大きさに比べてトンネルの数が少ないことです。 トンネルがどのように相互に接続されているかを理解することだけが必要です。 

よくある間違いは、2 つのセルが同じトンネル上にあるかどうかだけを確認することです。 隣接する並列トンネルが接続されているため、これは失敗します。 もう 1 つの間違いは、異なる方向の交差点だけをチェックすることです。 1 単位離れた 2 つの平行なトンネルは決して交差しませんが、ホリネズミはトンネルの間を移動できます。 

## アプローチ

 ブルート フォース ソリューションでは、空のセルをすべて生成し、隣接するセルを接続し、接続されたコンポーネントを実行します。 小惑星には以下が含まれています`10^18`セルなので、グリッドを作成することさえ不可能です。 

より良い試みは、すべてのトンネルが頂点となるグラフを作成することです。 対応するトンネルが接触している場合、2 つの頂点は接続されます。 多くのトンネルが同じ座標面と交差する可能性があるため、直接実装してもまだ時間がかかりすぎます。 たとえば、同じ Z 座標にある数千の X トンネルと Y トンネルは、数百万のペアごとの交差を作成します。 

重要な点は、交差点を個別に表す必要がないということです。 複数のトンネルがすべて同じスライスを通過する場合、1 つの補助頂点がスライス全体を表すことができます。 すべてのトンネルをこの補助頂点に接続すると、まったく同じ接続が得られます。 

たとえば、同じ Z 座標を持つすべての X トンネルは、その Z 座標を持つすべての Y トンネルと交差します。 単一の「z スライス」ノードがそれらすべてを接続します。 

この圧縮後は、並列トンネル間のローカル隣接関係のみが残ります。 これはハッシュ マップで処理できます。各トンネルは 2 次元座標空間内の 4 つの可能な近傍をチェックするだけでよいからです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(10^18) | O(10^18) | 不可能 |
 | ペアごとの交差を持つトンネル グラフ | O(n²) | O(n²) | 遅すぎる |
 | 補助スライス ノードを備えた DSU | O(n + q) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての一意のトンネルを保存し、ID を割り当てます。 トンネルは、その方向と 2 つの固定座標によって保存されます。 
2. すべてのトンネルと追加の補助ノードを含む、素の集合結合構造を作成します。 補助ノードは、1 つの固定座標スライスを共有するすべてのトンネルを表します。 
3. 補助ノードを介して垂直トンネルを接続します。 Xトンネル`(y,z)`座標を表す補助ノードに接続されています`y`そしてコーディネート`z`なぜなら、これらはまさに垂直トンネルがそれに出会うことができるスライスだからです。 
4. 隣接するトンネルを並列に接続します。 すべてのトンネルについて、1 つの固定座標を 1 増やした同じ方向の別のトンネルが存在するかどうかを確認します。 存在する場合は、それらのコンポーネントをマージします。 
5. クエリごとに、開始セルを含むすべてのトンネルと終了セルを含むすべてのトンネルを検索します。 セルは空であることが保証されているため、各側に少なくとも 1 つのトンネルが存在します。 開始トンネルと終了トンネルの DSU 代表者が同じ場合、答えは次のようになります。`YES`。 

なぜ効果があるのか:

 空のセル間の移動はすべて、同じトンネル上に留まるか、隣接する平行なトンネル間を移動するか、または 2 つの垂直なトンネルの交差点で発生します。 DSU には、まさにこれら 3 種類の接続が含まれています。 補助ノードは、すべてのペアを明示的に作成せずに、考えられるすべての垂直交差を表します。 したがって、2 つのセルは、対応するトンネル頂点が同じ DSU コンポーネント内にあるときに、元の小惑星内で正確に接続されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    z = int(input())
    out = []

    for _ in range(z):
        n = int(input())

        xt = {}
        yt = {}
        zt = {}

        tunnels = []

        for _ in range(n):
            a, b, c = map(int, input().split())
            if c == -1:
                key = (a, b)
                if key not in zt:
                    zt[key] = len(tunnels)
                    tunnels.append((2, a, b))
            elif b == -1:
                key = (a, c)
                if key not in yt:
                    yt[key] = len(tunnels)
                    tunnels.append((1, a, c))
            else:
                key = (b, c)
                if key not in xt:
                    xt[key] = len(tunnels)
                    tunnels.append((0, b, c))

        parent = []
        size = []

        def add():
            parent.append(len(parent))
            size.append(1)
            return len(parent) - 1

        for _ in tunnels:
            add()

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a, b):
            a = find(a)
            b = find(b)
            if a == b:
                return
            if size[a] < size[b]:
                a, b = b, a
            parent[b] = a
            size[a] += size[b]

        aux = {}

        def get_aux(t, x):
            key = (t, x)
            if key not in aux:
                aux[key] = add()
            return aux[key]

        for i, (typ, a, b) in enumerate(tunnels):
            if typ == 0:
                union(i, get_aux(0, a))
                union(i, get_aux(1, b))
            elif typ == 1:
                union(i, get_aux(0, b))
                union(i, get_aux(2, a))
            else:
                union(i, get_aux(1, a))
                union(i, get_aux(2, b))

        for (a, b), i in xt.items():
            if (a + 1, b) in xt:
                union(i, xt[(a + 1, b)])
            if (a, b + 1) in xt:
                union(i, xt[(a, b + 1)])

        for (a, b), i in yt.items():
            if (a + 1, b) in yt:
                union(i, yt[(a + 1, b)])
            if (a, b + 1) in yt:
                union(i, yt[(a, b + 1)])

        for (a, b), i in zt.items():
            if (a + 1, b) in zt:
                union(i, zt[(a + 1, b)])
            if (a, b + 1) in zt:
                union(i, zt[(a, b + 1)])

        def get_lines(x, y, z):
            res = []
            if (y, z) in xt:
                res.append(xt[(y, z)])
            if (x, z) in yt:
                res.append(yt[(x, z)])
            if (x, y) in zt:
                res.append(zt[(x, y)])
            return res

        q = int(input())
        for _ in range(q):
            x1, y1, z1, x2, y2, z2 = map(int, input().split())
            a = get_lines(x1, y1, z1)
            b = get_lines(x2, y2, z2)

            ok = False
            for u in a:
                ru = find(u)
                for v in b:
                    if ru == find(v):
                        ok = True
                        break
                if ok:
                    break

            out.append("YES" if ok else "NO")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装では、トンネルと圧縮されたスライス グラフのみが保持されます。 座標値は辞書キーとしてのみ使用されるため、完全な整数のままにすることができます。 座標圧縮は必要ありません。 

微妙な部分は補助ノードの構築です。 トンネルは、それと交差するすべてのトンネルに接続されているわけではありません。 代わりに、座標スライス全体を表すノードに接続されます。 これにより、接続を維持しながら二次的な動作が回避されます。 

近隣チェックでは次の機能のみが使用されます。`+1`これは、圧縮された 2 次元トンネル レイアウト内のすべての無向隣接関係が 1 つのエンドポイントから検出されるためです。 負の方向をチェックすると作業が重複します。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + q) | 各トンネルは一定の辞書操作を実行し、各クエリは最大 3 つのトンネルを 3 つのトンネルに対してチェックします。 |
 | スペース | O(n) | DSU には、トンネル ノードと、トンネル座標ごとに最大でも一定数の補助ノードが含まれます。 |

 最大のケースには、数十万のトンネルとクエリが含まれます。 このアルゴリズムは 100 万×100 万×100 万の立方体には決して触れないため、制限内に問題なく収まります。
