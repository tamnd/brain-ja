 ## 解決策
 ## 問題の理解

 2 つの制約を同時に満たすように、2 種類のベーカリー製品を組み合わせて選択できるかどうかを判断するように求められます。 Vasилиса は N 人のゲストごとに 1 つの商品を購入する必要があるため、商品の合計数は N に固定されます。同時に、彼女は購入の合計費用がちょうど K ルーブルであることを要求するプロモーション クーポンを持っています。 

使用可能な製品タイプは 2 つだけです。1 つのタイプは品目あたり A ルーブルのコストで、もう 1 つのタイプは品目あたり B ルーブルのコストで、A と B は異なります。タスクは、x が A の価格の品目の数、y が B の価格の品目の数、x + y が N に等しく、合計コスト Ax + By が K に等しいような非負の整数 x と y が存在するかどうかを判断することです。そのようなペアが存在する場合は、有効なペアを出力する必要があります。 それ以外の場合は、-1 を出力します。 

この制約では、最大 10^9 の値が許可されるため、x または y のすべての可能な値を試行するソリューションは即座に除外されます。 N 個の可能性にわたる線形スキャンには、最悪の場合、最大 10^9 回の反復が必要になりますが、これは 1 秒の制限をはるかに超えています。 これにより、組み合わせ探索ではなく代数的解決が求められます。 

よくある落とし穴は、安いものをできるだけ多くとったり、高価なものをできるだけ多くとったりするなど、欲張った選択をしようとするときに起こります。 これらの戦略は失敗します。目標コスト K が正確に固定されており、正しい解決策には極端な構成ではなく正確なバランスが必要になる可能性があるためです。 もう 1 つの微妙な失敗例は、割り算をチェックせずに整数の除算が使用され、分数のカウントが黙って受け入れられる場合に発生します。 

## アプローチ

 ブルートフォース手法では、x の考えられるすべての値を 0 から N まで繰り返し、y を N から x を引いたものとして計算し、Ax + By が K に等しいかどうかを確認します。これは、有効なカウントのすべての組み合わせを明示的にテストするため、正しいです。 ただし、このアプローチでは N 回の反復が実行され、各反復には一定の作業が含まれます。 N が 10^9 までになると、これは計算上不可能になります。 

重要な観察は、問題が真に 2 次元ではないということです。 x を固定すると、y の値は N によってすぐに決定され、システムが単一の変数に縮小されます。 さらに重要なのは、コスト方程式が x において線形になることです。 これは、列挙ではなく代数を使用して x を直接解くことができることを意味します。 

x + y = N から、コスト方程式に y = N - x を代入します。 これにより、問題は x における単一の線形方程式に変換されます。 未知のものは 1 つだけなので、一定時間内にそれを分離できます。 残りのタスクは、計算された値が整数であり、有効な範囲内にあるかどうかを確認することです。

 ## アルゴリズムのチュートリアル

 x を A コスト項目の数、y を B コスト項目の数として表します。

1. 制約 x + y = N から開始し、y を N - x として表現します。 これにより、システムから 1 つの変数が削除され、すべてが 1 つの未知の x にまとめられます。 
2. y をコスト方程式 Ax + By = K に代入し、Ax + B(N - x) = K を取得します。このステップでは、問題を x のみの線形方程式に変換します。 
3. 方程式を展開して Ax + BN - Bx = K を取得し、x に関係する項をグループ化して x(A - B) + BN = K を取得します。これにより、x へのすべての依存関係が 1 つの係数に分離されます。 
4. x を解くために並べ替えます: x(A - B) = K - BN。 これは、x を 2 つの既知の量の比として表します。 
5. 分子 K - BN と分母 A - B を計算します。この時点で、x は (K - BN) / (A - B) に等しくなければなりません。 この値は、分子が分母で割り切れる場合にのみ有効です。 
6. 計算された x が整数であり、0 ≤ x ≤ N を満たすかどうかを確認します。満たす場合は、y を N - x として計算し、両方の値を出力します。 それ以外の場合は、有効な選択が存在しないと結論付けます。 

### なぜ効果があるのか

 この変換により、2 つの未知数における 2 つの線形方程式系が 1 つの変数における 1 つの線形方程式に縮小されます。 すべての制約は線形であり、非負以外に不等式はないため、実行可能なすべての解はこの導出式を正確に満たさなければなりません。 方程式には実数での一意の解があり、残る制限は整数と境界だけであるため、有効な解はすべて同じ値の x を生成する必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    K = int(input())
    N = int(input())
    A = int(input())
    B = int(input())

    numerator = K - B * N
    denom = A - B

    if denom == 0:
        print(-1)
        return

    if numerator % denom != 0:
        print(-1)
        return

    x = numerator // denom
    y = N - x

    if x < 0 or y < 0:
        print(-1)
        return

    print(x, y)

if __name__ == "__main__":
    solve()
```コードは代数導出を直接実装します。 最初のステップでは、x の式の再配置された分子と分母を計算します。 可分性チェックにより、分数解が受け入れられないことが保証されます。 境界チェックでは、両方のカウントが合計が N になる有効な非負の整数であることが強制されます。 

実装の微妙な詳細は、A - B の符号です。A と B はどちらの順序でも出現できるため、分母は負になる可能性がありますが、除算の前に割り算がチェックされている限り、Python の整数の除算は依然として正しく機能します。 

## 実用的な例

 ### 例 1

 入力:

 K = 11、N = 3、A = 5、B = 1

 次のように計算します。 

| ステップ | 式 | 値 |
 | --- | --- | --- |
 | 分子 | K-B・N | 11 - 3 = 8 |
 | 分母 | Ａ～Ｂ | 5 - 1 = 4 |
 | × | 8 / 4 | 2 |
 | y | N - x | 1 |

 x と y の両方が負ではなく、合計が N になるため、結果は有効です。これは、ソリューションが高価な品目と安価な品目のバランスをとり、正確な目標コストに一致させる方法を示しています。 

### 例 2

 入力:

 K = 2、N = 1、A = 3、B = 0

 | ステップ | 式 | 値 |
 | --- | --- | --- |
 | 分子 | 2 - 0・1 | 2 |
 | 分母 | 3 - 0 | 3 |

 ここで、2 は 3 で割り切れないため、整数 x は存在しません。 これは、このメソッドが列挙を試行することなく、不可能な分数解をどのように正しく拒否するかを示しています。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、A と B が非常に近いか入れ替わっている場合 (たとえば、A = 1 と B = 2) に発生します。この状況では、分母 A - B が負になり、不注意な取り扱いは符号ミスにつながる可能性があります。 このアルゴリズムは、除算の前に整数の割り算に厳密に依存することでこれを回避するため、符号は正確さに影響しません。 

別のケースは、K が最小の可能なコストより小さい場合、または N 個の項目が与えられた場合の最大の可能なコストより大きい場合に発生します。 たとえば、すべてのアイテムのコストが少なくとも 5 で、N が 3 の場合、15 未満の K は不可能です。 計算された分子が [0, N] の範囲外の x 値を生成するため、式は当然これらのケースを拒否します。 

3 番目のエッジ ケースは、線形方程式に実数の解があるにもかかわらず、整数の解が存在しない場合に発生します。 たとえば、計算された x が 2.5 に等しい場合、割り算チェックは失敗し、アルゴリズムは四捨五入や近似を試みることなく、不可能であることを正しく報告します。
