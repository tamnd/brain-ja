 ## アルゴリズムのチュートリアル

 1.セット`a`に等しい`c`。 これにより、次のことが保証されます`a`の倍数です`c`、 それで`lcm(a, c)`まさになる`a`。 また、`a xor c`はゼロになり、XOR 式の片側が削除されます。 
2. 表現するために必要なビット数を見つける`c`。 この量だけシフトすると、設定されたすべてのビットが移動します`c`既存の最上位ビットを超えているため、シフトされた値は次のビットと重複することはできません。`c`。 
3. 構築する`b`として`c`のビット長だけ左にシフト`c`。 これにより、`b`の倍数`c`、つまり`lcm(b, c) = b`。

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []
    for _ in range(t):
        c = int(input())
        shift = c.bit_length()
        a = c
        b = c << shift
        ans.append(f"{a} {b}")
    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```の異なる値の間に共有状態がないため、ソリューションは各テスト ケースを個別に読み取ります。`c`。

この構築では、ビット シフトによる 2 のべき乗の乗算のみを使用します。 値は安全に以下に保たれます`10^17`可能な限り最大なので`c`だけです`10^7`、約シフトします`24`ビットはおおよその値を与えます`1.6 * 10^14`。 

## 実用的な例

 のために`c = 1`:

 | ステップ | c | シフト | | b |

 ここ`a xor c = 0`そして`b xor c = 3`。 LCM 値は次のとおりです。`1`そして`2`、 しかし`b xor c`は`3`なぜなら、`b`そして`c`は異なります。 両側は`3`そして`3`施工ルールを考慮した上で。 

のために`c = 7`:

 | ステップ | c | シフト | | b |

XOR 側は次のとおりです。`7 xor 7 + 56 xor 7 = 0 + 63 = 63`LCM 側は次のとおりです。`lcm(7,7) + lcm(56,7) = 7 + 56 = 63`等価性が成り立ちます。

 ## 特殊なケース

 いつ`c = 1`、最初の数字は次のようになります`1`そして2番目の数字は`2`。 2 つの値には個別のビットがあります。 方程式は次のようになります`0 + 3 = 1 + 2`、したがって、建設はまだ機能します。 

いつ`c`が 2 の累乗である場合、シフトによって 2 番目のコピーが元のビットを超えて移動する必要があります。 のために`c = 8`、構造は与える`a = 8`そして`b = 128`。 数値は両方とも次の倍数です`8`、そしてそれらの設定ビットが異なるため、LCM 値は正確に数値そのものです。 

次のような大きな値の場合、`c = 10000000`、アルゴリズムは因数分解したりパターンを検索したりしません。 ビット長を計算してシフトするだけです。 元の制限が存在しないため、結果の値は許容範囲内に残ります。`c`十分小さいです。
