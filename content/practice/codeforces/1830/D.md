 ## 解決策
 ## 問題の理解

 各テスト ケースではツリーが与えられ、すべての頂点に 0 または 1 のラベルを割り当てる必要があります。ラベルが固定されると、頂点の各ペアがツリー内の一意の単純なパスを定義し、そのパスに沿ったラベルのシーケンスを調べます。 そのペアの寄与は、そのパス上に現れない最小の非負の整数によって決まります。このバイナリ設定では、パスに 0、1、または両方が含まれるか、どちらも含まれないかによってのみ決まります。 

両方の端点が同じ頂点である自明なペアを含む、頂点のすべてのペアにわたるこの寄与を合計しています。 目標は、この合計を最大化するバイナリ ラベリングを選択することです。 

入力サイズはすべてのテスト ケースで合計 20 万ノードに達するため、ソリューションは基本的にテストごとに線形または線形演算である必要があります。 頂点ペアの数だけでも O(n^2) であり、実現可能な限界をはるかに超えているため、ノードの数またはペアの数における二次関数の動作は直ちに不可能になります。 

素朴な試みでは、すべてのラベルを試したり、すべてのペアをチェックしてパスの内容を計算することによって固定ラベルを評価したりすることになりますが、単一のラベルの寄与を計算するだけでも、ペアの数によりすでに O(n^2) の作業が必要になります。 もう 1 つの一般的な落とし穴は、ツリー トラバーサルで各パスを独立して処理しようとすることです。これにより、重複するパス間で作業が静かに繰り返され、三次または三次に近い動作が発生します。 

本当の難しさは、寄与がローカル エッジに依存するのではなく、パスに沿ったラベルのグローバルな相互作用に依存することです。 ただし、ツリー構造はパスの動作を強く制限するため、きれいな単純化が可能になります。 

## アプローチ

 ブルート フォースのビューは単純です。すべてのノードに 0 または 1 を割り当て、すべてのノードのペアを反復処理し、それらの間のパスを抽出し、そのパスに 0 のみが含まれるか、1 のみが含まれるか、またはその両方が含まれるかを計算し、対応する値を加算します。 これは正しいですが、Θ(n^2) ペアを検査し、各ペアに対して少なくとも O(パスの長さ) を費やし、チェーン上で Θ(n^3) の最悪のケースを与えます。 パスの再計算を削除しても、依然として Θ(n^2) が残りますが、これは大きすぎます。 

重要な観察は、どのパスでも、値は端点が同じ色構造内にあるかどうか、またはパスが両方の色を横切るかどうかによってのみ依存するということです。 これは、個々のパスの観点から考えることを避け、代わりに、色付けによってツリーが単色の接続コンポーネントにどのように分割されるかを理解する必要があることを示唆しています。 

隣接する 2 つの頂点が同じ色を共有する場合、それらは同じコンポーネントに属し、そのコンポーネント内のすべてのペアはコンポーネントをまたぐペアとは異なる寄与をします。 重要な洞察は、ツリーでは、グラフの適切な 2 色からの逸脱により単色のエッジが作成され、コンポーネントがマージされ、他の部分で十分な補正が行われずにコンポーネント内の二次ペナルティが増加するということです。 これにより、最適な構造がツリーの適切な 2 部構成に向けて推進されます。 

ツリーの有効な 2 分割に制限すると、すべてのパスの構造が均一になります。異なる頂点間のすべてのパスは色を交互に切り替えます。つまり、パスには常に両方の色が含まれており、したがって常に非対角ペアの可能な最大値に寄与します。 残りの自由は、2 分割のどちらの側に 0 を割り当て、どちらの側に 1 を割り当てるかだけであり、これは単一頂点パスにのみ影響します。 

これにより、問題は大域的な組み合わせ最適化からツリーの 2 分割上の単純な計数問題に分解されます。

 | --- | --- | --- | --- |
 | すべてのラベルとペアに対するブルートフォース | O(2^n · n^2) | O(n) | 遅すぎる |
 | 最適な2分割構造 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

1. BFS または DFS を実行して、ツリーの 2 分割を計算します。 各ノードにはパリティ クラスが割り当てられ、2 つのセット A と B が形成されます。これは、すべてのツリーが 2 部構成であるため常に可能です。 
2. 1 つの部分をカラー 0 として割り当て、もう 1 つの部分をカラー 1 として割り当てます。選択肢は 2 つあります。A が 0 で B が 1、またはその逆です。 
3. そのような割り当てを 1 つ修正し、寄与を分析します。 2 つの異なるノードの場合、それらの間のパスには色が交互になるため、0 と 1 の両方が含まれ、パス値は強制的に 2 になります。これは、すべての非対角ペアが 2 になることを意味します。 
4. 対角ペアからの寄与を個別に計算します。 単一の頂点は、1 要素配列の mex に寄与します。頂点の色が 0 の場合は 1、色が 1 の場合は 0 になります。 
5. したがって、合計値は、個別の頂点の順序付けされていないすべてのペアの 2 に、0 で着色された頂点の数を加えた合計になります。 
6. 唯一の自由は、2 分割のどの側に 0 のラベルが付けられるかであるため、対角線の寄与を最大化するには、2 分割の大きい側を色 0 として選択します。 

### なぜ効果があるのか

 ツリーの 2 分割により、すべてのエッジが反対の色に接続されます。 2 つの異なる頂点間のパスは少なくとも 1 つのエッジを通過する必要があり、すべてのエッジで色が反転するため、パスには必然的に両方の色が含まれます。 これにより、すべての非対角ペアが可能な最大 mex 値 2 を達成するように強制されます。 

単色のエッジを導入する代替カラーリングでは、頂点がより大きな同色の連結コンポーネントにマージされます。 これにより、寄与が 2 を下回るサイズ k のコンポーネント内に Θ(k^2) ペアが作成されますが、改善されるのはせいぜい線形で多くの対角寄与だけです。 ツリーでは、この不均衡により常にそのような偏差が最適化されていないため、純粋な 2 分割により完全に混合されたパスの数が最大化されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        g = [[] for _ in range(n)]
        for _ in range(n - 1):
            a, b = map(int, input().split())
            a -= 1
            b -= 1
            g[a].append(b)
            g[b].append(a)

        color = [-1] * n
        q = deque([0])
        color[0] = 0

        cnt = [0, 0]

        while q:
            v = q.popleft()
            cnt[color[v]] += 1
            for to in g[v]:
                if color[to] == -1:
                    color[to] = color[v] ^ 1
                    q.append(to)

        a, b = cnt[0], cnt[1]

        # all non-diagonal pairs contribute 2
        ans = n * (n - 1)

        # diagonal contributions: nodes colored 0 contribute 1
        ans += max(a, b)

        print(ans)

if __name__ == "__main__":
    solve()
```BFS は、ツリーの有効な 2 つのパーティションを割り当て、2 つの部分のサイズをカウントします。 式`n * (n - 1)`順序のないペアに対する元の合計にそれぞれ 2 を与えるすべての順序付き非対角ペアを考慮します。 残っている自由度はどちらの側に 0 のラベルが付けられるかだけなので、より大きなパーティション サイズを追加します。 

微妙な点は、この問題では次のペアがカウントされることです。$u \le v$、順序のないペアと対角を意味します。 用語$n(n-1)$に正確に対応します$2$あらゆる面での貢献$\binom{n}{2}$異なるペア。 対角処理はゼロのカウントによってきれいに分離されます。 

## 実用的な例

 ### 例 1

 ツリー: パス内の 3 つのノード

 BFS の 2 分割後のサイズは 2 と 1 になります。 

| ステップ | サイズ | Bサイズ｜ 非対角寄与 | 対角寄与 | 合計 |
 | --- | --- | --- | --- | --- | --- |
 | BFS後 | 2 | 1 | 3 ペア × 2 = 6 | 最大(2,1)=2 | 8 |

 これは、すべてのパスに両方の色が含まれるため、個別のノードのすべてのペアが 2 に寄与することを示しています。 

### 例 2

 4 つのノードを持つスター ツリー

 2 分割では、センターのみとリーフが生成されます。 

| ステップ | サイズ | Bサイズ｜ 非対角寄与 | 対角寄与 | 合計 |
 | --- | --- | --- | --- | --- | --- |
 | BFS後 | 1 | 3 | 6ペア × 2 = 12 | 最大(1,3)=3 | 15 |

 これは、大きい側にカラー 0 を集中させると、他のすべてのペアに対する最大の寄与を維持しながら、対角ゲインのみが増加することが確認されます。

 ## 特殊なケース

 単一ノード ツリーは、対角規則を直接公開します。唯一のパスは、選択した色に応じて単一値の mex を提供し、アルゴリズムはそのノードに対して色 0 を正しく選択します。 

2 ノード ツリーにより、2 分割ロジックが最も単純なエッジを正しく処理できるようになります。 それらの間のパスは常に 2 を寄与します。最適な選択は、最良の対角寄与を得るために 1 つのエンドポイントにカラー 0 を割り当てることです。 

星型ツリーでは、2 つのパーティションのサイズのバランスが非常に不均衡になります。 このアルゴリズムは、大きいリーフ側に色 0 を割り当てます。これにより、+1 に寄与する頂点の数が最大化され、すべての交差ペアが値 2 に保たれ、二部引数によって暗示される最適な構造と一致します。
