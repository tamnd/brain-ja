 ## 解決策
 ## 問題の理解

 長さの配列を構築するように求められます$n$1 と -1 だけで構成されるインデックスのペアの数$i < j$要素が等しい場合 (両方 1 または両方 -1) は正確に$k$。 このペアの数は、配列の数と呼ばれます。$A$-特性。 各テスト ケースが提供するのは、$n$そして$k$、そしてそのような配列を生成するか、それが不可能であると宣言します。 

制約は小さいです。$n \le 100$そして$k \le \frac{(n-1)n}{2}$。 これは、大まかに実行されているソリューションを意味します$O(n^2)$テスト ケースごとに行うことは許容されますが、より構造化されたアプローチを使用すると、より良い結果を得ることができます。 重要な課題は組み合わせです。グループ内のペアの合計が正確に一致するように、1 と -1 をいくつ配置するかを選択することです。$k$。 

エッジケースが発生するのは次のような場合です$k$達成することは不可能です。 たとえば、$n = 3$そして$k = 2$、3 つの要素を 2 つのグループに分割することはできません。そのため、$\binom{c_1}{2} + \binom{c_2}{2} = 2$。 常に最初に 1 を貪欲に配置しようとする単純なアルゴリズムは失敗する可能性があるため、定型的な方法が必要です。 

もう一つの微妙な点は、$k = 0$。 この場合、どのペアも乗算して 1 にはなりません。これは、1 と -1 を交互に繰り返すことで実現されます。 

## アプローチ

 A brute-force approach would try all$2^n$可能な配列の場合は、$A$-それぞれの特性を調べて、最初に一致したものを返します$k$。 これは原理的には機能しますが、たとえ$n = 30$、 以来$2^{30}$およそ10億通りの組み合わせになります。 

重要な洞察は、次のことを観察することによって得られます。$A$-characteristic は、同一の要素内のペアをカウントします。 配置することが決まったら$x$残りの 1 つ$n-x$要素は -1 です。 すると、等しい要素のペアの合計は次のようになります。$\binom{x}{2} + \binom{n-x}{2}$。 これにより、問題は二次方程式を解くことに帰着します。$$\binom{x}{2} + \binom{n-x}{2} = k$$ある整数に対して$x$0から$n$。 一度$x$が見つかったら、最初の部分を埋めることができます$x$位置は 1、残りは -1 になります。 整数解が存在しない場合、答えは NO です。 これにより、すべての配列を試行することがなくなり、正確さが保証されます。$A$-特性は位置ではなくカウントのみに依存します。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. 各テスト ケースについて、次の内容を読んでください。$n$そして$k$。 解決策が見つかったかどうかを示すフラグを初期化します。 
3. 反復する$x$0から$n$、配列内の 1 の数を表します。 
4. を計算します。$A$-このパーティションの特性:$x \cdot (x-1)/2 + (n-x) \cdot (n-x-1)/2$。 
5. 等しい場合$k$、次のように配列を構築します$x$続いてのもの$n-x$マイナス 1 を付けて、解決策を見つかったとマークします。 ループを断ち切りましょう。 
6. そうでない場合$x$ループの後に見つかった場合は、NO を出力します。 それ以外の場合は、YES と配列を出力します。 

なぜ効果があるのか​​:$A$-characteristic は、1 と -1 の数によって完全に決定されます。 0 から 0 までのすべての可能なカウントを試してみます。$n$、解決策が存在する場合は、それを見つけることを保証します。 このアプローチでは、カウントの各組み合わせが一意のペアの合計に対応し、位置は重要ではないため、カウントしすぎたり、可能性を逃したりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        found = False
        for x in range(n + 1):
            a_char = x * (x - 1) // 2 + (n - x) * (n - x - 1) // 2
            if a_char == k:
                result = [1] * x + [-1] * (n - x)
                print("YES")
                print(" ".join(map(str, result)))
                found = True
                break
        if not found:
            print("NO")

if __name__ == "__main__":
    solve()
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 各テスト ケースについて、1 の潜在的なカウントをループします。 の`//`演算子は整数の除算を保証し、浮動小数点数の問題を防ぎます。 配列の構築ではリストの乗算と連結を使用します。これは簡単で、off-by-one エラーを回避します。 早期ブレークにより、テスト ケースごとに有効な配列が 1 つだけ出力されることが保証されます。

 ## 特殊なケース

 のために$k = 0$、アルゴリズムは試みます$x = 0$最初はすべて -1 となり、A 特性を持ちます。$\binom{0}{2} + \binom{n}{2} = \binom{n}{2}$。 これは 0 より大きい可能性が高いため、アルゴリズムは引き続き$x = n//2$、最終的には 0 を達成するために必要に応じて 1 と -1 を交互に繰り返します。$n = 2, k = 0$、トレース:

 - x = 0 → a_char = 1 → 高すぎる
 - x = 1 → a_char = 0 → 解`[1, -1]`これにより、アルゴリズムが最小配列とゼロ特性を正しく処理していることが確認されます。
