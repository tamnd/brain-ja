 ## アルゴリズムのチュートリアル

 私たちは木を次の場所に根付けます$t$すべてのエッジを遠方に向けられたものとして解釈します。$t$親子構造という意味では。 

1. すべての頂点の隣接リストと次数を計算します。 頂点からの各遷移では確率が隣接する頂点間で均等に分割されるため、次数が重要になります。 
2. ツリーを次の場所にルートします。$t$DFS または BFS を使用して親子関係を保存します。 これにより、次のような独自の方向性が得られます。$t$すべてのノードに対して。 
3. DP 値を定義する$f(v)$ウォークが頂点に入る予想回数として$v$吸収前に$t$。 初期化する$f(s)=1$なぜなら、プロセスは強制的な最初の「エントリ」としてそこから始まるからです。 
4. 距離の近いノードから順に処理します。$t$、葉から根に向かって。 ノードにいるとき$v \neq t$、ウォークが入るたびに$v$のいずれかを選択する必要があります。$deg(v)$隣接するものは一様に存在するため、期待されるフローは次から送信されます。$v$隣人に$u$は$f(v)/deg(v)$。 
5. 寄与分を伝播する: ルート化されたツリー内の子から親への関係ごとに、累積します。$f(parent) += f(child) / deg(child)$。 これは、子へのすべての訪問が最終的にその確率質量で親に寄与するという事実を反映しています。 
6. 伝播が完了すると、$f(v)$知られています。 期待されるカウンタ値$c(v)$等しい$f(v)$、入るたびに$v$、への移動$v$カウンタを 1 回だけインクリメントします。 
7. すべての算術モジュロを実行します$998244353$、乗算による除算を次数の逆モジュラーに置き換えます。 

正しさは不変式から得られます。$f(v)$～への予想される流入フローの合計を表します$v$各頂点は、その入射エッジ全体にその受信期待値全体を均一に分配します。 散歩は止まるところだけなので、$t$、流れ葉なし$t$、このシステムのシンクになります。 ツリー構造により、一度ルート化されると、この有向フローに循環依存性がなくなるため、リーフからルートへの伝播によってすべての値が一意に決定されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, s, t = map(int, input().split())
    g = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        g[u].append(v)
        g[v].append(u)

    if n == 1:
        print(1)
        return

    parent = [0] * (n + 1)
    order = []
    stack = [t]
    parent[t] = -1

    while stack:
        v = stack.pop()
        order.append(v)
        for to in g[v]:
            if to == parent[v]:
                continue
            if parent[to] == 0:
                parent[to] = v
                stack.append(to)

    deg = [0] * (n + 1)
    for i in range(1, n + 1):
        deg[i] = len(g[i])

    f = [0] * (n + 1)
    f[s] = 1

    for v in reversed(order):
        if v == t:
            continue
        inv_deg = modinv(deg[v])
        for to in g[v]:
            if parent[to] == v:
                continue
            # child to parent direction in rooted tree
            if parent[v] == to:
                f[to] = (f[to] + f[v] * inv_deg) % MOD

    for i in range(1, n + 1):
        print(f[i] % MOD, end=' ')
    print()

if __name__ == "__main__":
    solve()
```実装では、まずルート付きツリーを構築します。$t$。 走査順序により、子が親よりも前に処理されるため、コントリビューションを安全に上にプッシュできます。 各次数のモジュラー逆元は、予想されるフローを分配するときに計算され、確率的遷移ルール​​の除算に代わって計算されます。 

実装の微妙な点は、ツリーの既に処理された部分に無向な意味で誤って伝播しないようにすることです。 これは、親配列を使用してルート方向を強制することで処理されます。
