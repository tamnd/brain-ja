 ## 解決策
 ## 問題の理解

 バイナリ グリッドが与えられ、セルを 0 から 1 または 1 から 0 に反転することができます。目標は、辺の長さが偶数であるすべての正方部分行列に奇数の 1 が含まれるようにグリッドを変換することです。 

この条件は、すべての偶数サイズの正方形に適用されるため、グローバルに見えますが、重要な点は、これらの制約により、グリッド全体で値がどのように変化するかを強く制限していることです。 私たちは、単一の構成のプロパティをチェックすることを求められているのではなく、そのようなすべての制約を同時に真にするために必要な反転の最小数を見つけること、またはどの構成もそれらの制約を満たすことができないと判断することを求められています。 

グリッドには合計で最大 100 万個のセルを含めることができるため、すべての部分正方形を列挙しようとしたり、すべての制約を明示的にチェックしようとするアプローチは、すぐに失敗します。 最悪の場合、すべての正方形を反復処理することさえすでに 3 次行列であり、すべての O(n^2 m^2) 部分行列の観点から考えることさえ完全に不可能です。 

さらに微妙な問題は、制約が重なり合うことです。 単一のセルは多くの偶数マスに参加しており、素朴な貪欲な反転戦略により、1 つのマスを修正しながら他の多くのマスを壊すことができます。 これは、ローカル修正がきれいに構成されない種類の構造です。 

小さな例は、局所的な推論がなぜ危険であるかを示しています。 2×2 グリッドを考えてみましょう。```
1 0
0 1
```これはすでに条件を満たしています。唯一の偶数の正方形がグリッド全体であり、その中に偶数の 2 つの正方形が含まれているため、実際にはルールに違反します。 単一のセルを反転すると問題は修正されますが、どのセルを反転するかに応じて、より大きなグリッドでは効果の伝播方法が異なります。 これは、正方形を独立して扱うことができないことを示しています。 

正しい解決策は、個々の正方形を操作するのではなく、グリッド内の隠れた対称クラスを特定することから得られます。 

## アプローチ

 強引なアイデアは、考えられるすべての最終グリッドを試し、それぞれに必要なフリップの数を計算し、それが条件を満たすかどうかを確認することです。 すべての有効な構成をテストできるため、これは原理的には正しいですが、グリッドの数は 2^(nm) であり、たとえ小さなインスタンスであっても計算の制限をはるかに超えています。 

より構造化された強引な方法は、すべての偶数平方を列挙し、制約を段階的に適用することです。ただし、各配置は多くの重複する部分行列に影響を及ぼし、変更のたびに妥当性をチェックすると、最悪の場合でも少なくとも O(n^2 m^2) の作業が必要になります。 これは、制約 nm ≤ 10^6 の下では直ちに失敗します。 

重要な洞察は、この条件はあらゆるサイズのすべての偶数正方形について述べていますが、実際には最小の偶数正方形、つまり 2×2 ブロックによって完全に決定されるということです。 すべての 2×2 部分行列が奇数の 1 を持つという条件を満たすと、より大きな偶数正方形もすべて自動的に条件を満たします。 これにより、無限の制約ファミリーがローカル制約に折りたたまれます。 

ここで問題は、元のグリッドからの反転コストを最小限に抑えながら、すべての 2x2 ブロックが奇数パリティを持つようにグリッドに値を割り当てることです。 

構造上の画期的な点は、すべてのセルが (i mod 2, j mod 2) に基づく 4 つのパリティ クラスのいずれかに属することです。 2×2 ブロックには、各クラスのセルが 1 つだけ含まれます。 つまり、すべての制約には各クラスの代表者が 1 つだけ含まれるため、グリッド全体が各クラスの値を選択し、一貫性とコストを評価することになります。 

これら 4 つのクラス値へのすべての割り当てを試みますが、完全な 2×2 ブロックのパリティが奇数である割り当てのみが有効です。 これにより、評価する構成の一定数が得られ、それぞれについてグリッド全体にわたる不一致コストが計算されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | グリッド上のブルートフォース | O(2^(nm)) | O(nm) | 遅すぎる |
 | すべての四角形を直接チェックする | O(n^2m^2) | お(1) | 遅すぎる |
 | 4 クラスの列挙 | O(16・nm) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのセルを、座標のパリティに基づいて 4 つのグループに分割します: (i mod 2, j mod 2)。 これは、すべての偶数の正方形に各グループのまったく同じ数のセルが含まれるため、機能します。 
2. 有効なグリッドでは、同じグループ内のすべてのセルが一貫した値を取る必要があることに注意してください。 同じグループ内の 2 つのセルが異なる場合、十分に大きな偶数正方形内でセルを交換すると、制約の均一性に違反します。 
3. グリッドを、4 つのグループのそれぞれに割り当てられた値を表す 4 つのブール変数に縮小します。 
4. 任意の 2×2 ブロックからの制約を課します。 各 2x2 には各グループのセルが 1 つだけ含まれるため、4 つのグループ値の合計は奇数でなければなりません。 
5. これら 4 つの変数の 16 個の割り当てをすべて列挙しますが、パリティ制約が満たされるものだけを保持します。 このような割り当てはちょうど 8 つあります。 
6. 有効な割り当てごとに、グリッドを 1 回スキャンし、割り当てられたグループ値と異なるセルの数を合計することによってコストを計算します。 
7. すべての有効な割り当ての中での最小コストを返します。 

各グループを均一なものとして扱うことができる理由は、違反が発生すると、同じパリティ クラス内で位置を交換してもメンバーシップ数は変更されませんが、制約の一貫性が損なわれる偶数正方形内で矛盾が生じるためです。 

### なぜ効果があるのか

すべての偶数正方形は、4 つのパリティ クラスのそれぞれからの等しい数のセルで構成されているため、1 の合計数は、位置ではなく、各クラスに割り当てられている 1 の数によってのみ決まります。 したがって、この条件は、多くのスケールにわたる幾何学的制約から 4 つの変数に対する単一のパリティ制約に崩れます。 これら 4 つの値が固定されると、より大きな偶数正方形はパリティ動作が同一の 2×2 ブロックの和集合であるため、より大きな制約はすべて自動的に一貫性を保ちます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    # count ones in each parity class
    cnt = [[0, 0], [0, 0]]
    sz = [[0, 0], [0, 0]]

    for i in range(n):
        for j in range(m):
            ii = i % 2
            jj = j % 2
            sz[ii][jj] += 1
            if g[i][j] == '1':
                cnt[ii][jj] += 1

    best = 10**18

    # try all assignments of 4 variables: a00,a01,a10,a11
    for mask in range(16):
        a = [[0, 0], [0, 0]]
        for i in range(2):
            for j in range(2):
                a[i][j] = (mask >> (i * 2 + j)) & 1

        # check constraint: each 2x2 block has odd sum
        total = a[0][0] + a[0][1] + a[1][0] + a[1][1]
        if total % 2 == 0:
            continue

        cost = 0
        for i in range(2):
            for j in range(2):
                if a[i][j] == 1:
                    cost += sz[i][j] - cnt[i][j]
                else:
                    cost += cnt[i][j]
        best = min(best, cost)

    print(best if best < 10**18 else -1)

if __name__ == "__main__":
    solve()
```この実装では、まずグリッドを 4 つの集約されたバケットに圧縮し、正確な位置への依存を回避します。 各マスクは、これら 4 つのバケットへの値の 1 つの割り当て候補を表します。 パリティ チェックにより、2×2 制約が確実に尊重されます。 コスト計算では事前計算されたカウントが使用されるため、前処理後に各候補が O(1) で評価されます。 

微妙な点は、コストが割り当てごとにグリッドを再スキャンすることではなく、クラス頻度を使用して計算されることです。 これにより、nm を超える時間計算量における不必要な 16 倍が回避されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    cnt = [[0, 0], [0, 0]]
    sz = [[0, 0], [0, 0]]

    for i in range(n):
        for j in range(m):
            ii = i % 2
            jj = j % 2
            sz[ii][jj] += 1
            if g[i][j] == '1':
                cnt[ii][jj] += 1

    best = 10**18

    for mask in range(16):
        a = [[0, 0], [0, 0]]
        for i in range(2):
            for j in range(2):
                a[i][j] = (mask >> (i * 2 + j)) & 1

        if (a[0][0] + a[0][1] + a[1][0] + a[1][1]) % 2 == 0:
            continue

        cost = 0
        for i in range(2):
            for j in range(2):
                cost += (sz[i][j] - cnt[i][j]) if a[i][j] else cnt[i][j]

        best = min(best, cost)

    return str(best if best < 10**18 else -1)

 ## 特殊なケース

 1×1 グリッドには偶数の正方形が含まれないため、その値に関係なく常に有効です。 クラス集約が引き続き機能し、すべての割り当てが評価され、反転が必要ない場合には最小コストが正確にゼロになるため、アルゴリズムはこれを自然に処理します。 

2×2 グリッドには制約が 1 つだけ存在し、アルゴリズムは 4 つの変数のパリティ条件を介してそれを強制します。 各変数は正確に 1 つのセルに対応するため、コストの計算はすべての有効な構成を直接列挙することになり、自明ではない最小のケースでも正確さが保証されます。 

すべて 0 またはすべて 1 などの均一性の高いグリッドでは、アルゴリズムはいかなる構造も想定しません。 有効なパリティ割り当てをすべて評価し、最も近いパリティ割り当てを選択するだけで、単一パターンへのオーバーフィッティングが回避され、極端な場合でも堅牢性が保証されます。
