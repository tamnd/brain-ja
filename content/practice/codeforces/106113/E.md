 ## 解決策
 ## 問題の理解

 教師は文字を繰り返して「無限のアルファベット」を構築します`a`を通して`z`永遠に。 26 文字の各ブロックには、その前に出現した完全なアルファベット サイクルの数が接頭辞として付けられます。 

最初のいくつかの値は次のとおりです。`0a, 0b, ..., 0z, 1a, 1b, ..., 1z, 2a, ...`これらの位置に 1 から始まる番号を付けると、次のようになります。`0a`位置 1 にあり、`0b`位置 2、...、`0z`26 番目の位置で、`1a`27 番目など。 

シーケンス`s`数値シーケンスを取得することによって取得されます$$5,\ 8,\ 13,\ 20,\ 29,\dots$$そして、各数値を無限アルファベットのその位置に格納されている値に置き換えます。 このステートメントは、`s`:`0e, 0h, 0m, 0t, 1c, ...`タスクはその逆の操作です。 無限のアルファベットの 1 つの値が与えられた場合、その値がどの位置にあるかを決定します。`s`それは現れます。 表示されない場合は印刷してください`-1`。 

重要な観察は、表示されている値を変換することで得られます。`s`アルファベットの位置に戻ります。 

| 値 | アルファベットの位置 |
 | --- | --- |
 | 0e | 5 |
 | 0時間 | 8 |
 | 0m | 13 |
 | 0t | 20 |
 | 1c | 29 |

 違いは次のとおりです。$$3,\ 5,\ 7,\ 9,\dots$$連続する奇数です。 つまり、基礎となる数値シーケンスは次のとおりです。$$n^2 + 4$$のために$n = 1, 2, 3, \dots$。 

入力サイズが小さいです。 数値プレフィックスは次のように大きくできます。$10^8$、したがって、結果として得られるアルファベットの位置は最大でも約$2.6 \times 10^9$。 定数時間の算術ソリューションで十分です。 

よくある間違いは、アルファベットの位置が 1 から始まるインデックスであることを忘れることです。 

例えば：```
Input:
0a
```アルファベットの位置は 0 ではなく 1 です。$$1 - 4 = -3$$は完全な正方形ではありません。正しい答えは次のとおりです。```
-1
```もう 1 つの簡単な間違いは、浮動小数点の丸め後の平方根を受け入れることです。 

例えば：```
Input:
0d
```アルファベットの位置は 4 です。次のようになります。$$4 - 4 = 0$$これは平方根 0 を返します。シーケンスは次から始まります。$n=1$なので、位置 0 は存在しません。 正しい答えは次のとおりです。```
-1
```これはサンプルケースの 1 つです。 

## アプローチ

 ブルートフォースソリューションでは、シーケンスの値が生成されます。$$n^2 + 4$$各値を無限のアルファベット表現に変換し、入力と比較します。 これはシーケンスが明示的であるため機能します。 

問題は、どこまで生成するかを決定することです。 入力によって表されるアルファベットの位置は 20 億を超える場合があるため、対応するシーケンス インデックスは約 5 万になる可能性があります。 これはまだ大したことではありませんが、値の生成と変換は不要な作業です。 

入力を数値アルファベットの位置に変換し直すと、実際の構造が表示されます。 

入力が`pX`、 どこ`X`が文字の場合、そのアルファベットの位置は次のようになります。$$N = 26p + \text{letterIndex}(X)$$と`a = 1`、`b = 2`、...、`z = 26`。 

シーケンスには正確に数字が含まれています$$n^2 + 4.$$したがって、質問は次のようになります。$$n^2 + 4 = N$$または$$n^2 = N - 4.$$あとは、次のことを確認するだけです。$N-4$は正の完全平方です。 そうであれば、その平方根はまさにシーケンス内の位置になります。 それ以外の場合、値は表示されません。

 ## アルゴリズムのチュートリアル

 1. 入力文字列を読み取ります。 
2. 数字の接頭辞と最後の文字を区切ります。 
3. 文字をアルファベット内の位置に変換します。`a = 1`そして`z = 26`。 
4. 無限アルファベットの位置を計算します。$$N = 26 \cdot prefix + letterPosition$$これは、無限のアルファベットの構築から直接得られます。 

1. 以下を計算します。$$x = N - 4$$非表示の数値シーケンスのすべての要素は次の形式を持つためです。$n^2 + 4$。 

1. もし$x \le 0$、印刷`-1`。 

シーケンスは次から始まります$n=1$、 それで$n=0$は無効です。 

1. 整数の平方根を計算します。$r = \lfloor \sqrt{x} \rfloor$。 
2. もし$r^2 = x$、印刷$r$。 それ以外の場合は印刷します`-1`。 

### なぜ効果があるのか

 のすべての値`s`数値シーケンスから来ています$n^2 + 4$。 無限のアルファベットの文字列は、正確に 1 つのアルファベットの位置に対応します$N$。 文字列が表示されるのは、`s`その位置が満たされる場合にのみ$$N = n^2 + 4$$何らかの正の整数の場合$n$。 

並べ替えると$$n^2 = N - 4.$$正の整数$n$まさにそのときに存在します$N-4$は正の完全平方です。 その場合、一意の平方根がシーケンスの位置になります。 それ以外の答えはあり得ません。 

## Python ソリューション```python
import sys
from math import isqrt

input = sys.stdin.readline

s = input().strip()

letter = s[-1]
prefix = int(s[:-1])

pos = 26 * prefix + (ord(letter) - ord('a') + 1)

x = pos - 4

if x <= 0:
    print(-1)
else:
    r = isqrt(x)
    print(r if r * r == x else -1)
```最初の部分では、数字の接頭辞と最後の文字が抽出されます。 

アルファベットの位置への変換では、完成した各ブロックが 26 の位置に寄与するという事実を利用します。 文字は 1 ～ 26 の値を与えます。 

取得後`pos`、問題は次のことを確認することになります。`pos - 4`は正の完全平方です。 

使用する`math.isqrt`浮動小数点精度の問題を回避します。 浮動小数点の平方根では、完全な平方に近い非常に大きな値が誤って分類される可能性があります。 整数の平方根により正確な結果が得られ、最終チェックが行われます。`r * r == x`完全な正方形の状態を確認します。 

条件`x <= 0`重要です。 例えば、`0d`生成する`x = 0`、しかしシーケンスはから始まります$n=1$、したがって、答えは次のようになります。`-1`。

## テストケース```python
# helper: run solution on input string, return output string
import io
import sys
from math import isqrt

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    s = sys.stdin.readline().strip()

    letter = s[-1]
    prefix = int(s[:-1])

    pos = 26 * prefix + (ord(letter) - ord('a') + 1)

    x = pos - 4

    if x <= 0:
        return "-1\n"

    r = isqrt(x)
    return f"{r if r * r == x else -1}\n"

# provided samples
assert run("0e\n") == "1\n", "sample 1"
assert run("3z\n") == "10\n", "sample 2"
assert run("104d\n") == "52\n", "sample 3"
assert run("0d\n") == "-1\n", "sample 4"

# custom cases
assert run("0a\n") == "-1\n", "smallest alphabet value"
assert run("0h\n") == "2\n", "second sequence element"
assert run("1c\n") == "5\n", "crossing alphabet block boundary"
assert run("99999999z\n") == "-1\n", "large non-member"

 次のことを考慮してください。```

```アルファベットの位置は次のとおりです。$$1$$それから：$$1 - 4 = -3$$値が負であるため、正の整数はありません$n$満足のいく$n^2=-3$。 アルゴリズムはすぐに出力します`-1`。 

次に、次のことを考えてみましょう。```

```アルファベットの位置は次のとおりです。$$4$$それから：$$4 - 4 = 0$$平方根は 0 ですが、シーケンスは次から始まります。$n=1$。 アルゴリズムが拒否する`x <= 0`そして正しく出力されます:```

```最後に、次のことを考慮してください。```

```これにより、アルファベットの数値位置に変換し直すときに、ブロック番号と文字の寄与が正しく組み合わされていることを確認できます。
