 ## 解決策
 # 問題の理解

 この問題は映画のコレクションについて説明しています。 各映画には公開年、監督名、評価が付いています。 映画をいくつか選択し、時系列順に並べて、可能な限り最長の映画マラソンを構築する必要があります。 

有効なマラソンには 3 つの制限があります。 公開年を減らすことはできず、評価は次の映画に厳密に向上する必要があり、2 つの映画を連続して同じ監督が起用することはできません。 タスクは、そのようなシーケンスに表示できるムービーの最大数を見つけることです。 

入力では、映画の数と各映画のデータが続きます。 出力は、マラソンの有効な最長距離を表す単一の整数です。 

映画の数は最大 3000 です。可能なサブセットの数は指数関数的に増加するため、すべてのサブセットを試行するアルゴリズムは即座に除外されます。 二次遷移数を使用する動的計画法ソリューションが現実的であるのは、次の理由からです。$3000^2 = 9 \times 10^6$これはコンパイル言語としては十分小さいですが、Python では単純な操作で使用できます。 

難しい部分は、入力のサイズではなく、順序付けルールを正しく処理することです。 よくある間違いは、年だけを並べ替えて、それ以前のすべての映画が前作であると想定することです。 レーティングの条件が厳しいため、同じレーティング以下の映画ではマラソンを延長することはできません。 

次のような場合を考えてみましょう。```
3
2000 A 50
2001 A 60
2002 B 70
```正しい出力は次のとおりです。```
2
```迂闊な解決策は、年数が増えるから3本とも選択してしまうかもしれないが、最初の2本は同じ監督で連続出演なので御法度である。 

別の例:```
3
2000 A 50
2001 B 50
2002 C 60
```正しい出力は次のとおりです。```
2
```最初の 2 つの映画は評価が等しいため、連続することはできません。 評価を厳密に増加させるのではなく、減少しない評価を使用するソリューションでは、誤って 3 が返されます。 

最後の境界ケースは、どの映画も別の映画の後に続かない場合です。```
2
2000 A 90
2001 B 80
```正しい出力は次のとおりです。```
1
```それぞれの映画はすでに長さ 1 の有効なマラソンであるため、答えがゼロになることはありません。 

# アプローチ

 直接的なアプローチは、映画のあらゆる順序を試し、それが条件を満たすかどうかを確認することです。 これは正しいです。最終的には、考えられるすべてのマラソンが検討されることになるからです。 ただし、可能なサブセットの数だけでも、$2^N$、そして$N=3000$これは不可能です。 

より合理的な強引なアイデアは、映画を年ごとに並べ替え、動的プログラミングのトランジションを使用することです。 それでも、すべての選択肢に対する単純な再帰検索では、依然として多すぎる分岐が探索されます。これは、多くの異なる選択肢が同じ残りの状態につながるためです。 

重要な観察は、映画を時間ごとに分類した後、部分的なマラソンに関して必要な情報は最後に選択された映画だけであるということです。 最後の映画がわかれば、現在の年、評価、監督がわかり、これらはまさに別の映画を追加できるかどうかを決定するために必要な値です。 

させて`dp[i]`映画で終わる最長の有効なマラソンを表します`i`。 過去の映画ごとに`j`かどうかを確認します。`j`直前でもいい`i`。 の年であれば、`j`～の年を超えていない`i`、の評価`j`の評価よりも小さいです`i`、そして監督が違うと、`dp[i]`から更新できます`dp[j]`。 

並べ替えのステップにより、移行が簡単になります。 年ごとに並べ替えてから評価します。 ソート後、後任者は少なくとも同程度の年と、より大きな評価を持たなければならないため、リスト内ではすべての可能な前任者が後任者より前に表示されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^N)$|$O(N)$| 遅すぎる |
 | ソート後の動的プログラミング |$O(N^2)$|$O(N)$| 承認済み |

 # アルゴリズムのチュートリアル

 1. すべての映画を読み取り、それぞれを年、監督、評価を含むタプルとして保存します。 映画を最初に年、次に評価で並べ替えます。 

並べ替えられた順序により、有効な前のムービーが現在のムービーの前にのみ表示されるタイムラインが作成されます。 同じ年の中で格付けを順序付けることにより、同等またはそれ以下の格付けによって引き起こされる不可能な移行も防止できます。 

1. 配列を作成する`dp`どこ`dp[i]`すべての映画はそれ自体でマラソンを形成できるため、 は 1 から始まります。 

この初期化は、ムービーの前に他のムービーを配置できない場合を処理します。 

1. すべての映画について`i`、以前のすべてのムービーを検査します`j`。 

映画`j`で終了するマラソンを延長できます`j`その年が後でなければ`i`、その評価はより小さいです`i`の評価と監督が違います。 

1. 有効な遷移が存在する場合は、以下を更新します。$$dp[i] = \max(dp[i], dp[j] + 1)$$すでに終了しているベストマラソンの後に新しいムービーが追加されます。`j`。 

1. 答えは次の最大値です。`dp`。 

最も長いマラソンはどの映画でも終了する可能性があるため、並べ替え後に最後の要素を検査するだけでは済みません。 

## なぜ機能するのか

 動的計画法配列の不変式は次のとおりです。`dp[i]`常に最高のマラソンを保存しており、その最終ムービーはまさに映画です`i`。 

映画を考えるとき`i`、考えられるすべての以前の映画が以前のインデックスの中に表示されます。 以前のムービーが合法的に接続できる場合`i`、トランジションでは、そこで終了する最適なマラソンが考慮され、それが 1 つ延長されます。 考えられるすべての最後の先行処理がチェックされるため、次の時点で終了する有効なマラソンは存在しません。`i`見逃されています。 すべての結末の最大値を取得すると、全体的な最適値が得られます。 

# Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    movies = []

    for _ in range(n):
        y, director, p = input().split()
        movies.append((int(y), int(p), director))

    movies.sort()

    dp = [1] * n
    ans = 1

    for i in range(n):
        year_i, score_i, director_i = movies[i]

        for j in range(i):
            year_j, score_j, director_j = movies[j]

            if year_j <= year_i and score_j < score_i and director_j != director_i:
                dp[i] = max(dp[i], dp[j] + 1)

        ans = max(ans, dp[i])

    print(ans)

if __name__ == "__main__":
    solve()
```入力は、年とスコアの数値を含むタプルに変換されるため、直接比較されます。 等価性チェックのみが必要なため、ディレクターは文字列のままです。 

用途の分類`(year, score, director)`注文すること。 ディレクターは最後のタイブレーカーとしてのみ含まれており、トランジションでは 3 つのマラソン条件すべてが明示的にチェックされるため、正確さには影響しません。 

ネストされたループは、動的プログラミング遷移を実装します。 条件`score_j < score_i`評価を改善する必要があるため、厳格です。 監督に対する条件により、同じ監督による連続映画の製作は禁止されている。 

答えは最大 3000 であるため、特別な整数の処理は必要ありません。

# 複雑さの分析

 | 測定 | 複雑さ | 説明 |

# テストケース```python
import sys
import io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n = int(input())
    movies = []

    for _ in range(n):
        y, director, p = input().split()
        movies.append((int(y), int(p), director))

    movies.sort()

    dp = [1] * n
    ans = 1

    for i in range(n):
        yi, pi, di = movies[i]
        for j in range(i):
            yj, pj, dj = movies[j]
            if yj <= yi and pj < pi and dj != di:
                dp[i] = max(dp[i], dp[j] + 1)
        ans = max(ans, dp[i])

    return str(ans)
