 ## 解決策
 ## 問題の理解

 グラフ内のすべての位置が頂点として扱われる文字列があります。 2 つの位置間の部分文字列 (両端点を含む) が左から右、右から左に同​​じように読まれる場合、2 つの位置はエッジによって接続されます。 

タスクは、グラフ全体を明示的に構築することではありません。 1 つの文字列には 2 次数の回文部分文字列が含まれる可能性があるため、グラフには多くのエッジが存在する可能性があります。 すべての有効なエッジが追加された後、接続された位置グループの数のみが必要になります。 

文字列の長さを次のようにします`n`。 簡単なバージョンでは、`n`まで`10000`。 すべてのポジションのペアをチェックする直接的なアプローチには、`n^2`ペアを作成し、各部分文字列が回文であるかどうかを確認するには別のコストがかかります`O(n)`素朴にやれば。 それは`O(n^3)`アルゴリズム、それは`10^12`最大の入力に対する操作であり、許容される 2 秒の制限をはるかに超えています。 

有用なターゲットは、`O(n^2)`解決。 その周り`10^8`単純な演算は最適化された言語の上限に近いため、二次ループ内でのコストのかかる作業を避ける必要があります。 主な課題は、次のような問題が発生する可能性があることです。`O(n^2)`回文部分文字列、特に次のような文字列の場合`aaaaaaaaaa`したがって、すべての回文を保存するのは現実的ではありません。 

いくつかの特殊なケースでは、不注意な実装が失敗する可能性があります。 次のような 1 文字の文字列の場合`a`、エッジはないので、答えは次のようになります。`1`。 すべての文字がそれ自体を介して接続されていると想定するソリューションでは、誤って異なる値が返される可能性があります。 

のために`ab`、部分文字列であるため、どちらの位置も接続できません。`ab`は回文ではありません。 正しい答えは、`2`。 等しい長さの部分文字列または一致する個々の文字を接続とし​​て扱うソリューションでは、2 つの位置が誤ってマージされます。 

のために`abcacba`、文字列全体は回文ですが、中央の文字は他の位置に接続されていません。 正しい答えは、`4`。 よくある間違いは、回文内のすべての文字が同じコンポーネントに属しているが、エッジは回文の 2 つの端点を接続しているだけであると想定することです。 

## アプローチ

 簡単な方法は、考えられるすべての部分文字列を検査し、それが回文であるかどうかをテストし、回文である場合は、その 2 つの端点を素集合結合構造で結合することです。 すべてのグラフ エッジが正確に 1 つの結合演算であるため、正確性は即座にわかります。 問題はコストです。 がある`O(n^2)`部分文字列を検索し、文字を比較してそれぞれをチェックするには時間がかかります`O(n)`、与える`O(n^3)`時間。 

回文がどのように自然に生成されるかを観察することで、より良い方向性が生まれます。 すべての回文は、その中心を中心に展開することで見つけることができます。 奇数長の回文には中央の文字が 1 つありますが、偶数長の回文には中央のギャップがあります。 考えられるすべての中心から拡張すると、すべての回文が 1 回だけ表示されます。 

拡張中は、現在の 2 つのエンドポイントの間にエッジを追加するだけで済みます。 グラフを作成したり、回文そのものを保持したりする必要はありません。 全センターにわたる拡張数は次のとおりです。`O(n^2)`、展開が成功するたびに、ちょうど 1 つの結合演算が行われます。 

ブルートフォース手法は回文を最初から繰り返し検索するため失敗します。 中心拡張では、回文の対称性を直接使用して、その繰り返し作業を削除します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n) | 遅すぎる |
 | DSUによるセンター拡張 | O(n^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 文字列位置ごとに 1 つのセットを含む素セット共用体構造を作成します。 各セットは 1 つの可能な連結成分を表し、2 つのセットをマージすることはグラフ エッジの追加を表します。 
2. すべての位置を奇数長の回文の中心として扱います。 文字を合わせながら左右に拡大します。 展開が成功するたびに、現在の左位置と右位置を結合します。これは、それらの間の部分文字列が回文であるためです。 
3. 隣接する位置間のすべてのギャップを、均等な長さの回文の中心として扱います。 同様の方法で展開し、見つかったすべての回文の 2 つの端点を結合します。 
4. すべての拡張が終了した後に残っている DSU ルートの数を数えます。 残りの各ルートは、元のグラフの 1 つの連結成分に対応します。 

これが機能する理由は、考えられるすべての回文に中心が 1 つだけあるためです。 拡張プロセスではすべての有効なエッジが検出され、DSU はそれらのエッジによって作成された接続を正確に記録します。 接続されたコンポーネントは、どの頂点が互いに到達できるかによってのみ決まるため、エッジを任意の順序で追加しても、同じ最終的なパーティションが生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve(s):
    n = len(s)

    parent = list(range(n))
    size = [1] * n

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(a, b):
        ra = find(a)
        rb = find(b)
        if ra == rb:
            return
        if size[ra] < size[rb]:
            ra, rb = rb, ra
        parent[rb] = ra
        size[ra] += size[rb]

    for center in range(n):
        left = center
        right = center
        while left >= 0 and right < n and s[left] == s[right]:
            if left != right:
                union(left, right)
            left -= 1
            right += 1

    for center in range(n - 1):
        left = center
        right = center + 1
        while left >= 0 and right < n and s[left] == s[right]:
            union(left, right)
            left -= 1
            right += 1

    ans = 0
    for i in range(n):
        if find(i) == i:
            ans += 1
    return ans

def main():
    s = input().strip()
    print(solve(s))

if __name__ == "__main__":
    main()
```DSU 配列には、各コンポーネントの現在の代表値が格納されます。 パス圧縮`find`サイズによるユニオンはツリーを浅く保ちながら、繰り返しの接続チェックを高速に保ちます。 

奇数の中央ループは、両方のポインターが同じ文字にある状態で開始されます。 最初の展開は長さ 1 の回文を表しますが、両方の端点が同じ頂点であるため、有用なエッジは作成されません。 より長い展開では、必要なグラフ エッジがすぐに得られます。 

偶数の中央ループは 2 つの隣接する文字の間で始まります。 展開が成功すると必ず 2 つの異なるエンドポイントが与えられるため、常に結合が実行されます。 

DSU の親が結合後に自分自身を直接指すことが保証されていないため、最後のスキャンでは配列値ではなくルートがカウントされます。 電話をかける`find`カウントする前に、圧縮されているがまだ更新されていないパスによって引き起こされる間違いを回避します。 

## 実用的な例

 | 3 の奇数中心 | 2 | 4 | 2 と 4 をマージする |
 | 3 の奇数中心 | 1 | 5 | 1 と 5 をマージする |
 | 3 の奇数中心 | 0 | 6 | 0 と 6 をマージする |

 最終的なコンポーネントは次のとおりです。`{0,6}`、`{1,5}`、`{2,4}`、 そして`{3}`、答えを与える`4`。 

This trace shows that a large palindrome does not automatically merge every character inside it. エンドポイントのみが接続されます。 

のために`navarrolikestacocat`、重要な回文の接続は、回文領域の中心の周りの拡張から得られます。

この例は、アルゴリズムが特別な回文形状に依存しないことを示しています。 すべての回文は同じ中心展開ルールによって処理されます。

## テストケース```python
import sys
import io

def solve(s):
    n = len(s)
    parent = list(range(n))
    size = [1] * n

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(a, b):
        a = find(a)
        b = find(b)
        if a == b:
            return
        if size[a] < size[b]:
            a, b = b, a
        parent[b] = a
        size[a] += size[b]

    for c in range(n):
        l = r = c
        while l >= 0 and r < n and s[l] == s[r]:
            if l != r:
                union(l, r)
            l -= 1
            r += 1

    for c in range(n - 1):
        l, r = c, c + 1
        while l >= 0 and r < n and s[l] == s[r]:
            union(l, r)
            l -= 1
            r += 1

    return str(sum(find(i) == i for i in range(n)))

def run(inp: str) -> str:
    return solve(inp.strip()) + "\n"

assert run("abcacba") == "4\n", "sample 1"
assert run("navarrolikestacocat") == "14\n", "sample 2"

assert run("a") == "1\n", "single character"
assert run("ab") == "2\n", "no palindrome of length two"
assert run("aaaa") == "1\n", "all characters connected"
assert run("abcba") == "3\n", "nested palindrome boundaries"

 ## 特殊なケース

 のために`a`、アルゴリズムは 1 つの奇妙な展開を開始します。`left = right = 0`。 部分文字列は回文ですが、エンドポイントは同じインデックスであるため、結合は発生しません。 DSU は 1 つのコンポーネントを保持し、正しい答えを生成します`1`。 

のために`ab`、奇数の拡張では単一の文字のみが検索されます。 偶数展開は部分文字列をチェックします`ab`、2 つの文字が異なることを確認し、すぐに停止します。 結合は実行されず、2 つのコンポーネントが残ります。 

のために`abcacba`、インデックスの中心`3`を通じて拡大します`c`、`cac`、`bcacb`、 そして`abcacba`。 アルゴリズムの結合`(2,4)`、`(1,5)`、 そして`(0,6)`インデックスを残したまま`3`一人で。 これにより、グラフ定義と一致する 4 つのコンポーネントが得られます。 

のために`aaaa`、多くの回文が重なり合っています。 拡張により、隣接するペアとより大きなペアが検出され、最終的には DSU を介してすべてのインデックスが接続されます。 最終的なルート数は次のとおりです。`1`これは、DSU が重複エッジを無視するため、回文の発見が繰り返されても無害であることを示しています。
