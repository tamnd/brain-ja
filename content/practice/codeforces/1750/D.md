 ## 問題の理解

 配列を数えるように求められます$b$プレフィックスの最大公約数のシーケンスに一致するもの。 具体的にはポジションごとに$i$、最初の GCD$i$の要素$b$等しい必要があります$a_i$。 各要素$b_i$1 から までの整数でなければなりません$m$。 出力は、そのような配列の数を法にしたものです。$998{,}244{,}353$。 

入力は複数のテスト ケースで構成されます。 各テスト ケースには整数が含まれます$n$配列の長さと整数$m$最大許容値。 それから$n$整数$a_1, \dots, a_n$必要なプレフィックス GCD を指定します。 

制約が教えてくれる$n$まで可能です$2\cdot 10^5$そして$m$まで$10^9$。 合計から$n$テストケース全体の境界は次のとおりです$2\cdot 10^5$、ほぼ線形の解が必要です。$n$テストケースごとに。 考えられるすべての配列を列挙する単純なアプローチ$b$不可能だから$m^n$天文学的に大きいです。 すべての値を反復するソリューション$b_i$明らかに実行不可能です。 

シーケンスが次の場合に、明白ではないエッジケースが発生します。$a$割り切れるという意味では非増加ではありません。 たとえば、次の場合$a = [2,3]$、可能性はありません$b$なぜなら$\gcd(b_1) = 2$そして$\gcd(b_1,b_2) = 3$起こりません-3 は 2 を割りません。割り算のチェックを無視する不用意な解決策は、有効な値を誤って計算しようとします。$b_2$そしてゼロ以外のカウントを生成します。 

もう一つの微妙な点は、$a_i$等しい$a_{i-1}$。 その場合、$b_i$の倍数でなければなりません$a_i$ただし、前の GCD から追加の制約は発生しないため、カウントには次のすべての倍数が含まれます。$a_i$まで$m$GCD を保存します。 

## アプローチ

 ブルートフォースアプローチは、考えられるすべてのものを列挙することです。$b_1$で$[1,m]$、それぞれについて$b_1$あらゆる可能な$b_2$で$[1,m]$、など、各ステップでプレフィックス GCD を計算します。 これには時間がかかります$O(m^n)$、これは不可能です。$m$できる$10^9$そして$n$まで$2\cdot 10^5$。 

重要な観察は、プレフィックス GCD が強力な可分性制約を課すことです。 具体的には、それぞれ$b_i$の倍数でなければなりません$a_i$、GCD が低下するのは$a_{i-1}$に$a_i$、$b_i$満たさなければなりません$\gcd(b_i, a_{i-1}) = a_i$。 これは整数を数えるのと同じです$x$そのような$1 \le x \le \frac{m}{a_i}$そして$\gcd(x, \frac{a_{i-1}}{a_i}) = 1$。 ここで、次のようにして再スケーリングします。$a_i$問題を、指定された数と互いに素な整数を数えるというものに縮小します。 オイラー トーティエント関数の使用$\phi(k)$、最大の整数の数を計算できます。$t$と互いに素である$k$効率的に。 

この観察により、アレイ全体の線形スキャンが可能になります。$a$、コンピューティング$\phi(a_{i-1}/a_i)$各ステップに対して、$O(n \sqrt{a_{i-1}/a_i})$テスト ケース ソリューションごとに高速化されます。 もしあれば$a_i$分けない$a_{i-1}$、答えはすぐに0です。

3. 因数分解$k$その主な要因に。

6. 出力`ans`。 

なぜ機能するのか: 不変条件はステップです$i$、配列の数を維持します$b_1 \dots b_i$プレフィックス GCD 制約を満たすもの。 可分性により、GCD が次の値から低下することが保証されます。$a_{i-1}$に$a_i$、およびスケーリング$a_i$カウントを互いに素な整数に減らします。 包含-排他は、互いに素である整数を正確にカウントします。$k$、正確性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 998244353

def prime_factors(x):
    i = 2
    factors = set()
    while i * i <= x:
        if x % i == 0:
            factors.add(i)
            while x % i == 0:
                x //= i
        i += 1
    if x > 1:
        factors.add(x)
    return list(factors)

def count_coprime(n, primes):
    # Inclusion-Exclusion to count numbers <= n coprime with product of primes
    res = 0
    m = len(primes)
    for mask in range(1, 1 << m):
        prod = 1
        bits = 0
        for i in range(m):
            if mask & (1 << i):
                prod *= primes[i]
                bits += 1
        cnt = n // prod
        if bits % 2 == 1:
            res += cnt
        else:
            res -= cnt
    return n - res

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    if a[0] > m:
        print(0)
        continue
    ans = 1
    for i in range(1, n):
        if a[i-1] % a[i] != 0:
            ans = 0
            break
        k = a[i-1] // a[i]
        x_max = m // a[i]
        if k == 1:
            cnt = x_max
        else:
            primes = prime_factors(k)
            cnt = count_coprime(x_max, primes)
        ans = ans * cnt % MOD
    print(ans)
```の`prime_factors`この関数は、試行除算によって数値を効率的に因数分解します。`count_coprime`これらの素数に対して包含-排他を使用して、因数分解と互いに素である制限まで整数を数えます。 これらのカウントを乗算すると、各位置での選択の独立性が尊重され、正しい合計カウントのモジュロが保証されます。$998244353$。
