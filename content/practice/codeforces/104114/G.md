 ## 解決策
 ## 問題の理解

 すでに左から右にソートされた固定車軸位置の行が与えられており、これらの車軸に特定のギア半径のマルチセットを割り当てる必要があります。 

配置したら、隣接するギアのペアはすべて接している必要があります。 すべてのギアが同じ線上にあるため、隣接する 2 つの車軸が所定の位置にある場合、接線は厳密な幾何学的制約に変換されます。$x_i$そして$x_{i+1}$、割り当てられた半径は次のとおりです。$s_i$そして$s_{i+1}$の場合、中心間の距離は半径の合計と等しくなければなりません。 これにより、連続する割り当て間に決定的な関係が与えられます。隣接する各ペアは次の条件を満たす必要があります。$$s_i + s_{i+1} = x_{i+1} - x_i.$$したがって、タスクは半径を自由に割り当てることではありません。 隣接するすべてのペアが線形制約を満たすように、指定された半径を並べ替え、すべての半径が 1 回だけ使用されます。 

この制約により、私たちは線形または線形に近い解決策に向かうことになります。 まで$5 \cdot 10^5$すべての順列を試したり、すべての開始構成を試したり、単純にシミュレートしたりするソリューションは合格しません。 二次関数の何か$n$すでに遅すぎるし、$O(n \log n)$ソリューションでは、繰り返しの厳しいチェックを避ける必要があります。 

微妙な問題は、コンストレイントが剛体のチェーンを定義していることです。 最初のギアの半径を固定すると、他のすべての半径が伝播によって強制されます。 これにより、隠れた依存関係が作成されます。最初の選択の後にはローカルな自由度はなく、マルチセットに対するグローバルな整合性チェックのみが行われます。 

一般的な故障モードは、これが隣接する差分と半径の間の単なるマッチングの問題であると想定することで生じます。 たとえば、局所的に半径に対する差異の貪欲なペアリングを試みると、局所的な制約は満たすが、全体的には失敗するシーケンスが生成される可能性があります。 

もう 1 つの失敗モードは、一貫性をチェックせずにエンドポイントを任意に修正しようとすることです。 システムは最初の値によって完全に決定されるため、間違った選択をすると、見た目は有効でも不正確な完全なシーケンスが生成されます。 

## アプローチ

 ブルートフォースのアイデアは、指定されたマルチセットから最初の車軸の半径を任意に選択することから始まります。 一度$s_1$が選択されると、次のすべての半径が強制されます。$$s_{i+1} = (x_{i+1} - x_i) - s_i.$$これにより、線形時間で完全なシーケンスが一意に決定されます。 それを構築した後、それが入力半径の順列であるかどうかを検証します。 すべての有効な解は漸化式を満たす必要があるため、これは論理的には正しいです。 

しかし、あらゆる可能性を試してみると、$s_1$は高すぎます。 最悪の場合、私たちは次のことを試みます$O(n)$候補者、それぞれの費用$O(n)$再構成して検証し、$O(n^2)$仕事。 

重要な観察は、シーケンスは一度は任意ではないということです。$s_1$固定されています。 すべての値は次のアフィン関数です。$s_1$どちらかの係数を付けて$+1$または$-1$。 これは、シーケンス全体が以下に関して単調に動作することを意味します。$s_1$、しかし、異なる指数は反対方向に動きます。 その結果、構築されたシーケンスのソート順序が構造的に変化し、実現可能性は、この移動ソート リストが半径の固定ソート リストと一致できるかどうかという問題になります。 

すべての出発点を試す代わりに、$s_1$を連続パラメータとして使用し、結果として得られるマルチセットを正確に一致させる値が存在するかどうかを尋ねます。 これは 1 次元パラメータに関する実現可能性の問題となり、有効な間隔かどうかをチェックすることで解決できます。$s_1$存在します。 

候補者を確認できます$s_1$シーケンスを構築し、周波数構造を使用してマルチセットを比較することにより、線形時間で実行されます。 すべての候補をスキャンすることを避けるために、2 つの構築された値の順序が入れ替わる場合にのみ有効性が変化するという事実を利用します。これは予測可能な線形境界で発生します。 これにより、実現可能なものを探すことができます$s_1$対数または線形実行可能ガイド付きチェックを使用します (通常は、検証を伴う値領域での二分探索)。

 ## アルゴリズムのチュートリアル

 私たちは構造を再定式化して、$s_1$が固定されると、シーケンス全体が決定されます。 プレフィックスエッジの差を計算します$d_i = x_{i+1} - x_i$、そしてすべての半径を次の一次関数として表します。$s_1$。 

1. すべての距離を計算する$d_i = x_{i+1} - x_i$。 これらは、隣接するものの間で半径をどのように合計する必要があるかをエンコードします。 
2. 以下を使用してシーケンスを再帰的に表現します。$s_{i+1} = d_i - s_i$。 これは、それぞれの位置が次のいずれかであることを意味します。$+s_1$または$-s_1$距離にのみ依存する定数を加えます。 
3. すべてのインデックスの事前計算$i$ペア$(a_i, b_i)$そのような$s_i = a_i \cdot s_1 + b_i$、 どこ$a_i \in \{+1, -1\}$。 これは、繰り返しの中で置換が繰り返された結果として起こります。 
4. インデックスが 2 つの単調グループ (係数を持つグループ) に分割されることを観察します。$+1$として増加します$s_1$増加するものと係数のあるもの$-1$減少。 
5. 候補の実現可能性をテストするため$s_1$、すべてを構築します$s_i$増加するグループと減少するグループの間の 2 ポインターのマージを使用して、並べ替えられた半径のマルチセットと比較します。 不一致が発生した場合は、候補を破棄します。 
6. 十分に大きな整数範囲 (座標の差と半径和によって制限される) に対して二分探索を使用して、任意の値を見つけます。$s_1$これにより、有効なマルチセット一致が得られます。 
7. 有効になったら$s_1$が見つかった場合は、再帰を使用して完全なシーケンスを再構築し、出力します。 

なぜそれが機能するかは、システムの剛性に関係しています。 最初の値が固定されると、反復により一意のチェーンが強制されるため、解空間は 1 次元になります。 アフィン関数のソートされた構造により、2 つの線形式間の順序関係が入れ替わる場合にのみ実現可能性が変わります。これは有限のしきい値でのみ発生します。 これにより、組み合わせ代入問題が構造化された 1 パラメーター検索に変わります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build(x, s1):
    n = len(x)
    s = [0] * n
    s[0] = s1
    for i in range(n - 1):
        d = x[i + 1] - x[i]
        s[i + 1] = d - s[i]
    return s

def ok(x, r_sorted, s1):
    s = build(x, s1)
    s_sorted = sorted(s)
    return s_sorted == r_sorted

def solve():
    n = int(input())
    x = list(map(int, input().split()))
    r = list(map(int, input().split()))
    r_sorted = sorted(r)

    lo, hi = -10**18, 10**18
    ans = None

    for _ in range(60):
        mid = (lo + hi) // 2
        s = build(x, mid)
        s_sorted = sorted(s)

        if s_sorted <= r_sorted:
            lo = mid
        else:
            hi = mid

    for cand in [lo, hi]:
        s = build(x, cand)
        if sorted(s) == r_sorted:
            ans = s
            break

    print(*ans)

if __name__ == "__main__":
    solve()
```コードは反復構造を直接エンコードします。 の`build`関数は、選択された開始半径から強制伝播を実行します。 の`ok`順列のみが許可されるため、ロジックでは複数セットの比較の正確性が低下します。 

二分探索は最初の半径で使用されます。これは、実行可能性が、生成されたマルチセットが次の変更の下でどのようにシフトするかに関して単調に動作するためです。$s_1$。 検索が狭い間隔に絞り込まれたら、完全一致のみが有効となるため、エンドポイントを明示的にテストします。 

実装の微妙な詳細は、再構築が決定論的であり、再発と一貫性がなければならないということです。 後の値は以前のすべての値に依存するため、交互伝播で算術上の間違いが発生すると、直ちに実行可能性が損なわれます。 

## 実用的な例

 車軸の距離が固定されている小さなチェーンを考えて、一貫した割り当てを探します。 

### 例 1

 入力:```
n = 4
x = [1, 4, 10, 15]
r = [2, 3, 4, 5]
```距離を計算します。$$d = [3, 6, 5]$$候補者を試す$s_1 = 2$:

 | 私 | d[i-1] | s[i] の計算 | s[i] |
 | --- | --- | --- | --- |
 | 1 | - | 開始 | 2 |

 | 3 | 6 | 6 - 1 | 5 |
 | 4 | 5 | 5 - 5 | 0 |

 これは失敗します。$0$マルチセットには含まれていません。 

試しています$s_1 = 3$:

 | 私 | d[i-1] | s[i] の計算 | s[i] |

 | 1 | - | 開始 | 3 |
 | 2 | 3 | 3 - 3 | 0 |
 | 3 | 6 | 6 - 0 | 6 |
 | 4 | 5 | 5 - 6 | -1 |

 これも失敗し、チェーンが最初の選択に対してどれほど敏感であるかを示しています。 

これは、非常に具体的な開始値のみが有効なグローバル構成を生成することを示しています。 

### 例 2

 入力:```
n = 3

```距離:$$d = [5, 5]$$試す$s_1 = 1$:

 ## 特殊なケース

 初期の推測が間違っている場合に、繰り返しにより値がゼロまたは負になる場合、重大なエッジ ケースが発生します。 半径は厳密に正であるため、そのような失敗は候補を即座に無効にし、これは再構築中に検出されます。 

複数の有効な構成が存在する場合、別のエッジ ケースが発生します。 このアルゴリズムは一意性に依存しません。 実行可能なものだけを検索します$s_1$。 一旦見つかると、決定論的な伝播により完全に有効な配置が保証されます。 

最後の微妙なケースは、値が非常に大きい場合です。 すべての計算は入力座標と半径の線形結合であるため、中間の減算と加算の際のオーバーフローを避けるために 64 ビット整数を使用する必要があります。
