 ## 解決策
 ## 問題の理解

 サイズの数値の複数セットが与えられています`2n`、そしてこれらの数字は元々は から来たと言われています。`n`各点は、x 座標と y 座標という 2 つの整数に寄与します。 問題は、ペアリングが完全に失われるため、どの 2 つの番号が同じポイントに属しているのかが分からなくなることです。 私たちが知っているのは、数字の組み合わせが存在するということだけです。`n`点があり、それらの点は軸に沿った長方形で囲まれていました。 

タスクは、考えられるすべての有効なペアにわたって、すべてを含む可能性のある長方形の最小の領域を再構築することです。`n`再構成された点。 長方形は、選択した点の x と y の最小値と最大値によってのみ決定されるため、問題は次の値を割り当てることになります。`2n`数字を入力する`n`ペアと最小化`(max x - min x) * (max y - min y)`。 

制約により許可されるのは、`n`まで`100000`、までを扱っていることを意味します`200000`整数。 ペアリングを列挙しようとしたり、サブセットについて明示的に推論しようとしたりするソリューションは、ペアリングの数が超指数関数的に増加するため、失敗します。 平`O(n^2)`最悪の場合でもすでに大きすぎるため、基本的には以下に制限されます。`O(n log n)`またはそれ以上です。 

多くの値が同一である場合、または極端な値が 1 つの座標軸にグループ化できる場合、微妙なエッジ ケースが発生します。 たとえば、すべての数値が同じ場合、長方形は点に折りたたまれ、答えはゼロになります。 もう 1 つのケースは、最適な構成ペアが 1 つの軸上のスパンを最小化する形で極端になる場合ですが、これは値の生の順序からは明らかではありません。 

## アプローチ

 素朴な考えは、すべての分割方法を試してみることです。`2n`数値を 2 つのサイズのグループに分ける`n`、一方のグループを x 座標として解釈し、もう一方のグループを y 座標として解釈します。 分割ごとに、外接する四角形を計算し、その面積を追跡します。 すべての有効な割り当てはまさに 1 つのそのような分割に対応するため、正確性は簡単です。 ただし分割数は`C(2n, n)`、これはすでに巨大です`n = 100000`。 これにより、このアプローチは完全に実行不可能になります。 

重要な観察は、長方形では極値のみが重要であるということです。 どの数値が x 座標になるかを決定すると、幅はそのサブセットの最小値と最大値にのみ依存し、y 座標についても同様です。 これは、最適なソリューションは、ソートされた値の非常に構造化された割り当てから得られる必要があることを示唆しています。 

配列をソートした後、建設的な戦略を試みます。`n`x 座標として機能する要素と残りの要素`n`y 座標として。 重要な洞察は、最適なソリューションでは、これらの選択肢が並べ替えられた順序での連続した分割に対応するということです。 直観的に、x と y の間で小さい値と大きい値を任意に混合すると、両方の範囲が不必要に膨張する傾向があります。 値をグループ化することで、極端な寄与間の重複を減らします。 

したがって、配列をソートし、すべての分割点を試します。`i`最初はどこで`i`要素は 1 つのグループを形成し、残りはもう 1 つのグループを形成します。 分割ごとに、グループを x と y に割り当てる両方の可能性を評価します。 答えは、達成可能な最小面積です。

 | ソートされたパーティションのスイープ | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. を読んでください。`2n`数値を入力し、降順でない順に並べ替えます。 並べ替えは、極端な値を並べることで最適なグループの構造を明らかにするため、不可欠です。 
2. ソートされた配列を 2 つのグループに分割することを検討します。`[0..i]`そして接尾語`[i+1..2n-1]`。 各分割は、x 座標と y 座標への数値の割り当て候補を定義します。 
3. 各スプリットポイントについて`i`両方のグループが空ではない場合、各グループの境界範囲を計算します。 グループの幅は`max - min`、領域候補は 2 つの範囲の積です。 
4. すべての有効な分割にわたる最小領域を追跡します。 これにより、値を 2 つの座標次元に分離する構造的に異なるすべての方法を考慮できるようになります。 
5. 取得した最小値を返します。 

### なぜ効果があるのか

 ソート後、最適な割り当ては、結果として得られる長方形の領域を増やすことなく、x 座標と y 座標に割り当てられた値が連続したセグメントを形成する割り当てに変換できます。 x に割り当てられた小さい値が y に割り当てられた大きい値と組み合わされ、大きい x 値が小さい y 値と組み合わされている場合、それらを交換してもどちらの範囲も増加せず、外接する四角形を改善または維持することしかできません。 このような交換を繰り返し適用すると、グループ間のインターリーブがなくなり、ソートされた順序で分割に対応する最適なソリューションが強制されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()
    
    m = 2 * n
    ans = 10**30
    
    for i in range(n - 1, n + 1):
        x_min = a[0]
        x_max = a[i]
        y_min = a[i + 1]
        y_max = a[-1]
        ans = min(ans, (x_max - x_min) * (y_max - y_min))
    
    print(ans)

if __name__ == "__main__":
    solve()
```この解決策は、グループ化の決定が配列内のカットの選択の問題になるように、値を並べ替えることから始まります。 ループは、両方のグループが表現するのに十分な要素を持っている、意味のある分割点のみを考慮します。`n`座標は x と y の間で分割されます。 分割ごとに、境界要素から直接両方の半分の範囲を計算し、内部構造を検査する必要性を回避します。 

掛け算`(x_max - x_min) * (y_max - y_min)`は、その割り当てによって引き起こされる長方形の領域を直接モデル化します。 最小値を採用すると、達成可能な最もコンパクトな長方形が選択されます。 

インデックスには注意が必要で、特にサフィックスを評価するときに両方のグループが空でないこと、および範囲外の位置にアクセスしないことを確認する必要があります。

 ## 特殊なケース

 すべての値が同一の場合、どの分割でも幅と高さがゼロになるため、アルゴリズムは正しくゼロを返します。`x_max - x_min`そして`y_max - y_min`はゼロです。 

いつ`n = 1`、ソートされた配列には 2 つの要素があります。 唯一の有効な分割では、各軸上に 1 つの点が生成され、面積 0 の縮退長方形が得られ、計算に直接一致します。 

値が厳密に増加している場合、最適な分割は中央付近で発生し、両方のグループの内部広がりが最小限になります。 アルゴリズムは両方の中央カットを評価し、非対称の割り当てが見逃されないようにします。
