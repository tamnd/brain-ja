 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times m$各セルが異なる化学元素であるグリッド。 これらの細胞の一部はすでに研究室で利用可能です。 軸に沿った長方形の 3 つの角を形成する 3 つの要素から、科学者はいつでも 4 番目の角を合成できます。 この操作は無制限であり、新しく作成された要素はすぐにさらなる合成に参加できます。 

目標は、最初に所有していたセットと購入できるいくつかの要素から始めて、グリッド内のすべてのセルを最終的に作成することです。 購入する必要がある要素の数を最小限に抑え、長方形の完成操作を任意の回数適用した後でグリッド全体を取得できるようにしたいと考えています。 

制約は非常に偏っています。グリッドの両方の次元は 200,000 に達する可能性があるため、グリッドを明示的に構築することはできません。 最初に利用可能な要素の数は最大 200,000 であるため、すべての解は完全な行列をシミュレートするのではなく、既知の点と派生構造でのみ機能することになります。 

重要なエッジ ケースは、1 つの次元が 1 の場合に発生します。単一の行または列では長方形を形成できないため、合成はまったく不可能です。 たとえば、次の場合$n = 1, m = 5$、セルのみから始めます$(1,1)$、その場合は、1 つおきのセルを購入する必要があります。 「より多くのセルが最終的により多くのセルを生成する」と仮定する単純なアプローチでは、誤って行に沿って伝播しようとしますが、ルールでは厳密に 2 つの異なる行と列が必要です。 

もう 1 つの微妙なエッジ ケースは、初期ポイントがまばらであるものの、カスケード補完が可能な方法で位置合わせされている場合に発生します。 たとえば、完全な行と別の行にいくつかの散在点がある場合、構造全体のロックを安価に解除できますが、これは構造が幾何学的近接性ではなく行と列間の接続に依存していることをアルゴリズムが認識した場合に限られます。 

## アプローチ

 直接シミュレーションでは、4 つのポイントすべてを繰り返しスキャンし、欠けているコーナーを埋めようとします。 これは、既知のセルを含む行と列のすべてのペアを繰り返しチェックし、閉じるまで新しいセルを生成することと同じです。 ただし、グリッドを表現することすら大規模には不可能であり、潜在的な四角形演算の数は点の数で 3 次またはそれよりも劣るため、このアプローチは実行不可能になります。 

重要な観察は、長方形ルールが行の相互作用と列の相互作用によって完全に支配される閉包システムを作成するということです。 行を左側のノード、列を右側のノードと考えると、既知の各セルが 2 部グラフのエッジになります。 長方形の完了は 4 サイクルの完了に相当します: エッジがある場合$(r_1, c_1), (r_1, c_2), (r_2, c_1)$、推測できます$(r_2, c_2)$これは、コンポーネントが行セットと列セットの間で完全に密になるまで、この 2 部グラフの接続性が共有構造を通じて伝播することを正確に示しています。 

重要な簡略化は、この 2 部グラフの各接続コンポーネント内で、行と列のすべての接続コンポーネントに少なくとも 1 つのエッジが存在することを確認すると、閉包プロセスでそれらの間の二乗全体を埋めることができるということです。 そうすれば、接続されているすべてのコンポーネントが少なくとも 1 回は確実に「アクティブ化」されるようになり、コストが削減されます。 そうしないと、分離されたコンポーネントに到達できないままになります。 

最初の既知のセルは、この 2 部グラフ内のいくつかの連結コンポーネントをすでに形成しています。 コンポーネントにシードとして機能する初期エッジが含まれていない場合は、そのコンポーネント内で少なくとも 1 つのセルを購入する必要があります。 コンポーネント内で単一のセルが購入されると、長方形ルールが伝播して、そのコンポーネント内のすべての欠落しているエッジを埋めることができます。 

したがって、答えは、伝播を可能にする方法で最初のエッジによってまだ「覆われていない」行と列によって引き起こされる 2 部グラフ内の連結成分の数になります。 これにより、DSU 内のコンポーネントを行と列にわたってカウントすることになり、コンポーネントにすでにエッジがあるかどうかの追加チェックが行われます。

 ## アルゴリズムのチュートリアル

 1. すべての行インデックスとすべての列インデックスを 2 部グラフのノードとして扱います。 行と列が衝突しないように、互いに素なインデックス スペースを割り当てます。 これにより、行と列の区別を維持しながら構造を統一することができます。 
2. 最初に既知のセルごとに$(r, c)$、ノードを接続します$r$ノード付き$c$DSU ユニオン操作を使用します。 これは、これら 2 つのセットが既知の化学反応を通じて相互作用できるという事実をコード化しています。 
3. DSU 内の各接続コンポーネントに、最初に既知のエッジが少なくとも 1 つ含まれているかどうかを追跡します。 これを行うには、入力セルからのすべての結合のルートをマークします。 
4. すべての初期セルを処理した後、DSU 内で形成されたすべての個別のコンポーネントを反復処理します。 各コンポーネントは、既知のセルを通じて相互に到達可能な行と列の最大セットを表します。 
5. 各コンポーネントについて、少なくとも 1 つの初期セルが含まれている場合、内部で完全に伝播することができ、既存のものを超えて購入する必要はありません。 コンポーネントが DSU 構造内に存在するが、初期セルが含まれていない場合 (これは行ノードと列ノードが分離されているために発生する可能性があります)、それをアクティブ化するには少なくとも 1 つの要素を購入する必要があります。 
6. このような非アクティブなコンポーネントの数を合計します。 この合計が最小購入数です。 

中心的な考え方は、コンポーネントにシード エッジがあれば、そのコンポーネント内のすべての行と列のペアが到達可能になるまで、長方形の補完が繰り返し拡張できるということです。 DSU は、それらのコンポーネントを正確に検出することを保証します。 

### なぜ効果があるのか

 DSU は、行と列を共有セルによって引き起こされる等価クラスに分割します。 単一クラス内では、任意の 2 つの行と列が既知の四角形のチェーンを介して接続されます。 四角形操作は、この二部接続上の推移閉包を効果的に閉じます。つまり、コンポーネントが少なくとも 1 つの購入セルまたは初期セルによって「アクティブ化」されると、コンポーネント内の欠落しているエッジがすべて生成される可能性があります。 したがって、問題は、すべての接続コンポーネントに少なくとも 1 つのアクティブなエッジがあることを確認することになり、購入を最小限に抑えることは、アクティブ化せずにコンポーネントをカウントすることに相当します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return
        if self.r[ra] < self.r[rb]:
            ra, rb = rb, ra
        self.p[rb] = ra
        if self.r[ra] == self.r[rb]:
            self.r[ra] += 1

def solve():
    n, m, q = map(int, input().split())
    dsu = DSU(n + m)

    used = [False] * (n + m)

    def mark(x):
        used[dsu.find(x)] = True

    for _ in range(q):
        r, c = map(int, input().split())
        r -= 1
        c -= 1
        c += n
        dsu.union(r, c)
        mark(r)
        mark(c + n - n)

    for i in range(n + m):
        used[dsu.find(i)] = used[dsu.find(i)] or used[i]

    components = set()
    for i in range(n + m):
        components.add(dsu.find(i))

    ans = 0
    for root in components:
        if not used[root]:
            ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```DSU は、入力に表示されるすべての行ノードとすべての列ノードをマージし、四角形操作を通じて相互の到達可能性を表す接続コンポーネントを構築します。 の`used`配列は、コンポーネントが展開するために必要な初期エッジを少なくとも 1 つ持っているかどうかを追跡します。 最後のループでは、アクティベーションを行わずにコンポーネントをカウントし、必要な購入数を出力します。 

微妙な点は、採点は代表レベルで行わなければならないことです。 圧縮せずに生のインデックスのみをマークすると、`find`場合、後で DSU ユニオンを介してマージするコンポーネントを誤って分割してしまいます。

 入力:```

1 2
2 2

```各エッジを処理し、ノード上に DSU を構築します`{rows:1,2 | cols:3,4}`。 

| ステップ | エッジ | DSU のマージ | コンポーネント | アクティブなルート |
 | --- | --- | --- | --- | --- |
 | 1 | (1,2) | 1-(2+n) | 1 つのコンポーネント | マーク付き |
 | 2 | (2,2) | 2-(2+n) | 同じコンポーネント | マーク付き |
 | 3 | (2,1) | 2-(1+n) | 同じコンポーネント | マーク付き |

 すべてのノードは 1 つの接続コンポーネントで終わり、それがアクティブ化されます。 四角形演算により残りの欠落セルを埋めることができるため、答えは 0 です。 

これは、接続のサイクルが存在すると、クロージャが完全に伝播することを示しています。

 ## 特殊なケース

 縮退の場合は、初期セルがまったく存在しない場合です。 この状況では、すべての行と列のペアが分離され、何も合成できません。 このアルゴリズムは、すべてのノードをアクティブ化のない独自の DSU コンポーネントとして扱うため、すべてのコンポーネントをカウントし、$n + m$または、コンポーネントごとのアクティベーションの解釈に応じて、必要なすべての購入と同等です。 これは、すべての要素を購入する必要があるという事実と一致します。 

別の特殊なケースは、単一行または単一列のグリッドです。 四角形を形成できないため、DSU 結合が複数の行または列を意味のある形で接続することはありません。 各列は分離され、アルゴリズムは不足しているすべてのコンポーネントを購入が必要なものとして正確にカウントします。 

最後の微妙なケースは、入力が複数の DSU コンポーネントを形成するが、一部のコンポーネントに複数の初期エッジが含まれる場合です。 このアルゴリズムにより、コンポーネントがアクティブとマークされると、パス圧縮がマージされた後もアクティブのままになり、偶発的な再アクティブ化カウント エラーが防止されます。
