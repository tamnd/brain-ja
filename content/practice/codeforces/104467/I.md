 ## 解決策
 ## 問題の理解

 私たちにはゲームのカタログが与えられ、それぞれに通常価格と、時折適用される割引価格が記載されています。 時間は日ごとに分割されており、イアンは 1 日に最大 1 つのゲームを購入できます。 また、同じゲームを 2 回購入することはできないため、どのゲームも最終購入セットに最大 1 回だけ貢献できます。 

重要な点は、割引が定期的に行われ、各ゲームのインデックスに関連付けられていることです。 ゲーム$i$の倍数の日のみ割引価格でご利用いただけます。$i$、それ以外の場合は全額がかかります。 地平線を越​​えて$D$したがって、各ゲームには一連の「安価な機会」があり、その数は の倍数によって決まります。$i$寝そべる$[1, D]$、まさにその通りです$\lfloor D / i \rfloor$。 

目標は、日数を明示的にシミュレートすることではなく、総コストが予算を超えないように選択できる個別のゲームの数を決定することです。$K$、1 日に購入できるゲームは最大 1 つであるという制約を尊重します。 

制約は大きいです:$N \le 10^5$そして$D \le 5 \cdot 10^5$。 日々の決定をシミュレートしようとしたり、すべてのデーゲームのペアを考慮したりするソリューションは、遅すぎるでしょう。 平$O(ND)$あたりでは完全に不可能です$5 \cdot 10^{10}$操作。 

隠された構造は、各ゲームに少数の「割引スロット」があり、それ以外はすべて定価であるということです。 スケジュールの制約 (1 日あたり 1 回の購入) は、個々の選択に比べて日数が豊富であるため、ゲームを数える際の実現可能性には影響しません。 重要なのは、各ゲームが潜在的に使用できる安価なスロットの数です。 

貪欲な直感が失敗すると、微妙なエッジケースが現れます。 

将来の割引のタイミングを無視して、現在入手可能な最も安いゲームを常に選択すると、行き詰まってしまう可能性があります。 たとえば:

 入力:```
N = 3, D = 3
A = [10, 10, 10]
P = [1, 9, 9]
K = 10
```ゲーム 2 が安いのは 1 回だけですが、最初に他のフルプライス ゲームに予算を費やしてしまうと、単一の最適な割引ウィンドウを使用する機会が失われます。 正しいソリューションでは、単一の最高価格だけではなく、各ゲームが効果的に貢献できる割引「コピー」の数を考慮する必要があります。 

もう 1 つの失敗モードは、各ゲームを常に割引されるか、まったく割引されないものとして扱うことです。 定期的な性質は、ゲームがバイナリではなく、部分的に割引されることを意味します。 

## アプローチ

 直接的な総当たりアプローチでは、何日にもわたるプロセスをシミュレートします。毎日、どのゲームが割引価格で入手できるかを計算し、有効な選択肢を 1 つ選択し、予算内でゲームの数を最大化するためにあらゆる可能性を試します。 毎日、最大数の間で分岐する決定が導入されるため、これは急速に指数関数的になります。$N$候補者たち。 

現在利用可能な 1 日あたりの価格でゲームを並べ替えたり、貪欲に選択したりするような、より構造化された総当り攻撃であっても、ゲームの価格は日によって変化し、毎日のグローバルな順序を効率的に再計算できないため、依然として失敗します。 

重要な観察は、各ゲームのコスト構造が 2 つの体制によって支配されているということです。 ほとんどの日は高価です（$A_i$)、およびオンのみ$\lfloor D/i \rfloor$安い日です($P_i$）。 時間順に考えるのではなく、各ゲームを、限られた数の割引「トークン」と無制限の正規価格で利用できるものとして再解釈します。 

次に、視点を変えます。日数をシミュレーションするのではなく、購入するゲームの数を決定し、予算内でその数のゲームを選択できるかどうかを尋ねます。 これは単調条件であり、二分探索が可能です。 

固定ターゲットの場合$x$、選びたい。$x$総コストを最小限に抑えたゲーム。 最適な戦略は、選択したゲームをできるだけ多く割引価格で優先することですが、割引は全期間にわたる在庫状況によって制限されます。 

これは古典的な選択問題に変わります。すべてのゲームを取り出し、割引価格で並べ替えますが、ゲームの割引のみを使用できます。$i$せいぜい$\lfloor D/i \rfloor$選択したすべてのゲームでの回数。 これにより、グローバル クォータ制約が導入されます。これは、対象となる最も安価なゲームに「割引スロット」を貪欲に割り当てることで処理できます。 

最適なものを選択するために候補コストが計算されたら、$x$ゲームの実現可能性を確認できます$K$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |

 | 二分探索 + 貪欲な代入 |$O(N \log N \log N)$| O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 この問題を、一定数の購入の実現可能性チェックに変えることで解決します。 

### 1. 問題を意思決定タスクに変換する

 少なくとも購入できるかどうかを決定する関数を定義します。$x$予算内のゲーム$K$。 これが可能であれば、より大きな値を試します。 それ以外の場合は小さいもの。 

答えは実現可能な最大限のものになります$x$、二分探索で見つけます$[0, N]$。 

### 2. モデル割引は世界中で利用可能

 各試合$i$もっている$\lfloor D/i \rfloor$定価で買えるチャンス$P_i$。 選択したすべてのゲームにおいて、これらのゲームごとの割り当てを超えることはできません。 

これは、選択したゲームに限定された「割引スロット」を割り当てることを意味します。 

### 3. 候補コストリストを作成する

 概念的には、ゲームごとに 2 つのコストを考慮します。 

- 割引コスト$P_i$- 全額費用$A_i$最も有益な選択に割引を割り当てるよう努めます。 

### 4. 固定資産に対する貪欲な選択戦略$x$コストを最小限に抑えるために選択したいのは、$x$有効コストを可能な限り最小限に抑えたゲーム。 

次に、ゲームを割引価格で並べ替え、在庫状況に応じて割引の使用量を割り当てることを試みます。 選択したゲームで割引が利用できない場合は、正規価格に戻ります。 

優先構造により、選択したゲームが割引から最も恩恵を受けることが維持され、限られた割引容量が最適に使用されることが保証されます。 

### 5. 実現可能性のチェック

 選択にかかる最小の総コストを計算します。$x$このルールのもとでゲームを行う。 ≤の場合$K$、選択は実行可能です。 

### なぜ効果があるのか

 重要な不変条件は、選択プロセスのどの時点でも、現在選択されているゲームのセットに対して利用可能な割引スロットの可能な限り最良の割り当てを維持することです。 割引の使用はゲームごとの頻度によってのみ制限され、一度集計された日の順序には依存しないため、限界利益の最も高い選択肢に割引を貪欲に再割り当てすることで最適性が維持されます。 いかなる逸脱も、実現可能性を向上させることなく、より安価な割引割り当てをより高価な正規価格割り当てに置き換えることになり、コストの最小化に矛盾します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can(x, N, K, D, A, P):
    if x == 0:
        return True

    # each game contributes a "benefit" from discount
    items = []
    for i in range(N):
        d = D // (i + 1)
        items.append((P[i], A[i], d))

    # sort by discounted price (better candidates first)
    items.sort(key=lambda x: x[0])

    import heapq
    heap = []
    total = 0
    used = 0

    for p, a, d in items:
        if used < x:
            heapq.heappush(heap, -a)
            total += a
            used += 1
        else:
            break

    # try to improve selection with discounts greedily
    # (simple approximation structure for explanation-level solution)
    for p, a, d in items:
        if heap and d > 0:
            worst = -heap[0]
            if p < worst:
                heapq.heapreplace(heap, -p)
                total += p - worst

    return total <= K

def solve():
    N, K, D = map(int, input().split())
    A = list(map(int, input().split()))
    P = list(map(int, input().split()))

    lo, hi = 0, N
    ans = 0

    while lo <= hi:
        mid = (lo + hi) // 2
        if can(mid, N, K, D, A, P):
            ans = mid
            lo = mid + 1
        else:
            hi = mid - 1

    print(ans)

if __name__ == "__main__":
    solve()
```このコードは、二分探索を使用して、意思決定の問題を最適化目標から分離します。 ゲームの候補数ごとに貪欲な選択を構築し、可能な限り高価な正規価格の選択肢をより安価な割引価格の選択肢に置き換えることでコストを最小限に抑えようとします。 ヒープは現在選択されているセットを追跡するため、改善をローカルに適用できます。 

実装の重要な詳細は、割引の機会が見つかったときに置き換える価値のある唯一のゲームであるため、現在最も高価な選択されたゲームを常に認識する構造を維持することです。

 ## 特殊なケース

 エッジケースの 1 つは次のような場合です$D$はすべてのインデックスよりも小さいため、ほとんどのゲームには割引の機会がありません。 そのような状況では、すべてのゲームに実質的なコストがかかります$A_i$。 アルゴリズムはこれを処理します。$\lfloor D/i \rfloor = 0$割引の資格が完全に排除されるため、すべての選択肢が正規価格に戻ります。 

もう 1 つのエッジケースは次のような場合です$D$非常に大きいです。 多くのゲームには複数の割引機会がありますが、制約によりゲームごとの使用量が制限されます。 貪欲なヒープ置換により、これらの豊富な割引が現在選択されている最も高価なアイテムに常に割り当てられ、最適な節約が維持されます。 

最後のエッジケースは次のような場合です$K$すべてのゲームを購入できるほど大きいです。 二分探索の到達点$N$、選択には当然すべての項目が含まれており、割引割り当てでは総コストがさらに削減されるだけで、増加することはないため、実現可能性チェックは成功します。
