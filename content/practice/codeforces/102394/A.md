 ## 解決策
 ## 問題の理解

 (N) 個の立方体が列に並んでおり、各立方体はペイントされているか、そのままになっています。 タイプ 1 ルールでは、特定の間隔 ([L,R]) 内に少なくとも (K) 個のペイントされた立方体が必要です。 タイプ 2 ルールでは、その間隔の外側に少なくとも (K) 個のペイントされた立方体が必要です。 

目標は、明確に絵画を構築することではありません。 すべてのルールを満たす最小限の数のペイントされた立方体だけが必要です。 公式問題には (N\le 3000)、(M_1,M_2\le3000) があり、すべてのテスト ケースにわたるこれらの量の合計も最大 (3000) です。 元の問題には 1 秒の時間制限と 512 MB のメモリ制限があります。 

自然な表現は接頭辞の合計です。 (S_i) を位置 (1,\ldots,i) 間でペイントされた立方体の数とします。 次に、位置 (i) をペイントすることは、プレフィックスの合計を 0 または 1 ずつ増やすことに対応します。 

[
 0\le S_i-S_{i-1}\le1.
 ]

 タイプ 1 ルールの場合、([L,R]) にペイントされた数字は (S_R-S_{L-1}) であるため、ルールは次のようになります。 

[
 S_R-S_{L-1}\ge K.
 ]

 タイプ 2 ルールの場合、外側にペイントされた数字 ([L,R]) は次のようになります。 

[
 S_N-(S_R-S_{L-1})、
 ]

 したがって、ルールは次のようになります

 [
 S_N-(S_R-S_{L-1})\ge K.
 ]

 厄介な部分は (S_N) です。なぜなら、それ自体が最小化したい量だからです。 (S_N) が何らかの値 (X) に固定されると、すべての制約は 2 つのプレフィックス和のみを含む差分制約になります。 それが中心的な観察です。 

サイズ (N=3000) は、(N) 内の指数関数を除外します。 すべての絵画を列挙する場合でも、(2^{3000}) 個の候補が必要になります。 反対の極端な場合、(O(N^3)) メソッドには、最大の単一ケースですでに約 270 億の基本演算が含まれるため、目的のソリューションでは疎間隔構造を利用する必要があります。 受け入れられているアプローチでは、(O(\log N)) 個のエッジを持つ疎なグラフに基づいた (O(\log N)) 個の実行可能性チェックが使用されます。 

誤って対処しやすい特殊なケースがいくつかあります。 ルールがまったくない場合、何もペイントしないことは有効であるため、答えはゼロになります。 例えば、```
1
1 0 0
```答えがあります```
0
```少なくとも 1 つの立方体を常にペイントするような不用意な実装は、すぐに失敗します。 

ルールには (K=0) を指定できますが、これは絵画に実際の要件を課しません。 例えば、```
1
3 1 0
1 3 0
```答えがあります```
0
```この場合、接頭語と合計の不等式により等価性が認められる必要があります。 

境界 (L=1) と (R=N) も (S_0) または (S_N) に関係するため重要です。 例えば、```
1
1 1 0
1 1 1
```立方体 1 をペイントする必要があるため、答えは (1) になります。 接頭辞の位置 (S_0) を忘れると、間隔の式が扱いにくくなり、多くの場合、1 ずつずれたエラーが発生します。 

配列全体に対するタイプ 2 ルールは、もう 1 つの有用な境界ケースです。 その外部セットは空であるため、有効な要件は (K=0) のみです。 例えば、```
1
3 0 1
1 3 0
```答えは(0)です。 補数を別の通常の間隔として扱うのは正しくありません。 

## アプローチ

 ブルートフォースアプローチは簡単です。 (N) 個の立方体のすべてのサブセットを試し、ペイントされる立方体の数を数え、すべてのルールを確認します。 (2^N) 個のサブセットがあり、すべてのルールに対してサブセットを直接チェックするコスト (O(N+M_1+M_2)) があるため、最悪の場合の作業は次のようになります。 

[
 O\left(2^N(N+M_1+M_2)\right)。 
]

 (N=3000) の場合、大規模な場合、これはおよそ (6000\cdot2^{3000}) 個の基本チェックに相当し、これは完全に実行不可能です。 

可能性のあるすべての絵画が明示的に表現されているため、強引な方法が機能し、正確さには疑問の余地がありません。 問題は、興味深い構造が指数列挙によって隠されていることです。 

最初の有用な観察は、個々のペイントされた立方体の決定をプレフィックスの合計で置き換えることです。 (S_i) が判明すると、任意の間隔でペイントされた立方体の数は、2 つの接頭辞の合計の差にすぎません。 各立方体の二進数の性質も、単純な不等式によって捉えられます。 

[
 S_i-S_{i-1}\ge0
 ]

 そして

 [
 S_i-S_{i-1}\le1.
 ]

 ここで、ペイントされた立方体の最終的な数が (X=S_N) に固定されていると仮定します。 タイプ 1 ルールは次のようになります。 

[
 S_{L-1}-S_R\le-K.
 ]

 タイプ 2 ルールは次のようになります。 

[
 S_R-S_{L-1}\le X-K.
 ]

 合計数は次のように決まります。 

[
 S_N-S_0=X、
 ]

 これは 2 つの不等式で表すことができます

 [
 S_N-S_0\le X
 ]

 そして

 [
 S_0-S_N\le-X.
 ]

 結果として生じるすべての制約は標準形式になります

 [
 S_v\le S_u+w.
 ]

 このようなシステムは差分制約と呼ばれます。 それらは、重み (w) を持つ有向エッジ (u\to v) によって表すことができます。 実現可能なシステムには負のサイクルがありません。逆に、制約グラフに負のサイクルがない場合は、最短経路距離によって実現可能な割り当てが提供されます。 

これには 1 つの疑問が残ります。実現可能な最小の (X) をどのように見つけるかです。 実現可能性は単調です。 (X) 個のペイントされた立方体を含むペイントがすべてのルールを満たしている場合、さらに 1 つの未塗装の立方体をペイントします。 タイプ 1 の数は増加するだけです。 タイプ 2 ルールの場合、その間隔の外側にあるペイントされた立方体の数は、新しい立方体が間隔の内側にある場合は変化せず、新しい立方体が間隔の外側にある場合は増加します。 したがって、より多くの数の立方体をペイントすることも可能です。 

したがって、(0) から (N) までの二分探索 (X) を行うことができます。 各候補 (X) について、対応する差分制約グラフを構築し、SPFA を使用して負のサイクルが含まれているかどうかを確認します。 公式社説では、まさにこの二分探索と SPFA の定式化を示しており、(M) が制約の数を表す場合、複雑さは (O(NM\log N)) になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(2^N(N+M_1+M_2))) | (O(N+M_1+M_2)) | 遅すぎる |
 | 二分探索 + SPFA | (O(N(N+M_1+M_2)\log N)) 最悪の場合 | (O(N+M_1+M_2)) | 承認済み |

 SPFA 自体は、Bellman-Ford と同じ (O(VE)) 最悪の場合の限界を持っていますが、ここで生じるスパース グラフではキューベースの実装の方がはるかに高速です。 公式社説は、受け入れられた (O(NM\log N)) ソリューションに対する SPFA の実際的な枝刈りに明示的に依存しています。 

## アルゴリズムのチュートリアル

1. (S_i) を位置 (1) ～ (i) の間でペイントされた立方体の数として定義します。 値 (S_0) はゼロで、(S_N) はペイントされた立方体の数とまったく同じです。 
2. 回答候補 (X) を修正します。 一時的に (S_N=X) が必要になります。 これを行う理由は、(S_N) を含むすべてのルールが定数右側を持つ通常の差分制約になるためです。 
3. 2 つの制約を追加します
 [
 S_{i-1}-S_i\le0
 ]
 そして
 [
 S_i-S_{i-1}\le1
 ]
 すべての位置 (i) について。 これらは、各差 (S_i-S_{i-1}) を 0 または 1 のいずれかにし、ペイントされていない立方体またはペイントされた立方体と正確に一致するように強制します。 
4. すべてのタイプ 1 ルール ((L,R,K)) を次のように変換します。 
[
 S_{L-1}-S_R\le-K.
 ]
 これは、元の条件 (S_R-S_{L-1}\ge K) の項を並べ替えたものです。 
5. すべてのタイプ 2 ルール ((L,R,K)) を次のように変換します。 
[
 S_R-S_{L-1}\le X-K.
 ]
 (X-(S_R-S_{L-1})\ge K) から開始すると、区間内に描かれた数字は (X-K) を超えることができないことを示します。 
6. を追加して合計を強制的に (X) に等しくします。 
[
 S_N-S_0\le X
 ]
 そして
 [
 S_0-S_N\le-X.
 ]
 これらを組み合わせると、(S_N-S_0=X)、および (S_0=0) になります。 
7. すべての不等式 (S_v-S_u\le w) を重み (w) を持つ有向辺 (u\to v) に変換します。 パス緩和は、元の不等式とまったく同じ形式になります。 
[
 S_v\le S_u+w.
 ]
 8. SPFA を実行して負のサイクルを検索します。 プレフィックスサム エッジには (i-1) から (i) までの前方エッジが含まれるため、グラフには頂点 (0) から到達可能なすべての関連頂点が含まれます。 負のサイクルが存在する場合、候補(X)は不可能です。 負のサイクルが存在しない場合、差分制約系には解があるため、(X) は実行可能です。 
9. 実行可能な最小の (X) を二分探索します。 範囲 ([0,N]) から始めます。 すべての立方体をペイントすると、入力境界で許可されているすべてのルールが満たされるため、上部のエンドポイントは常に実現可能です。 中間点が実現可能な場合は、下半分を検索します。 それ以外の場合は上半分を検索します。 

### なぜ効果があるのか

 固定 (X) の場合、グラフは、(X) 個のペイントされた立方体を含む絵画の可能なプレフィックスの合計を正確に表します。 すべての有効なペイントはすべてのグラフの不等式を満たすため、負のサイクルを生み出すことはできません。 逆に、グラフに負のサイクルがない場合、最短パス距離はすべての差の制約を満たし、制約 (0\le S_i-S_{i-1}\le1) により、各プレフィックスの差は ({0,1}) の整数になります。 したがって、これらの違いは実際の絵画を説明します。 (S_N) に関係する 2 つの制約により、ペイントされた立方体の合計数が正確に (X) になるように強制されます。 (X) では実現可能性が単調であるため、二分探索では可能な限り最小の数が返されます。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    input = sys.stdin.readline
    t = int(input())
    answers = []

    for _ in range(t):
        n, m1, m2 = map(int, input().split())

        type1 = [tuple(map(int, input().split())) for _ in range(m1)]
        type2 = [tuple(map(int, input().split())) for _ in range(m2)]

        def feasible(x):
            g = [[] for _ in range(n + 1)]

            # 0 <= S[i] - S[i-1] <= 1
            for i in range(1, n + 1):
                g[i].append((i - 1, 0))
                g[i - 1].append((i, 1))

            # S[L-1] - S[R] <= -K
            for l, r, k in type1:
                g[r].append((l - 1, -k))

            # S[R] - S[L-1] <= X - K
            for l, r, k in type2:
                g[l - 1].append((r, x - k))

            # S[N] - S[0] <= X
            # S[0] - S[N] <= -X
            g[0].append((n, x))
            g[n].append((0, -x))

            # SPFA, starting from 0.
            # The chain edges make every vertex reachable from 0.
            vcnt = n + 1
            dist = [0] * vcnt
            in_queue = [False] * vcnt
            relax_count = [0] * vcnt

            q = deque([0])
            in_queue[0] = True
            relax_count[0] = 1

            while q:
                u = q.popleft()
                in_queue[u] = False
                du = dist[u]

                for v, w in g[u]:
                    nd = du + w
                    if nd < dist[v]:
                        dist[v] = nd

                        if not in_queue[v]:
                            q.append(v)
                            in_queue[v] = True
                            relax_count[v] += 1

                            if relax_count[v] >= vcnt:
                                return False

            return True

        lo, hi = 0, n

        while lo < hi:
            mid = (lo + hi) // 2
            if feasible(mid):
                hi = mid
            else:
                lo = mid + 1

        answers.append(str(lo))

    return "\n".join(answers)

if __name__ == "__main__":
    sys.stdout.write(solve())
```入力はケースバイケースで読み取られ、グラフのエッジが二分探索値 (X) に対して異なる依存関係を持つため、2 種類の制約は別々に保存されます。 

内部`feasible`の場合、グラフには (0) から (N) まで番号が付けられた (N+1) 個の頂点があり、(S_0,\ldots,S_N) に直接対応します。 各位置について、重み 0 のエッジ (i\to i-1) は (S_{i-1}\le S_i) を表し、重み 1 のエッジ (i-1\to i) は (S_i\le S_{i-1}+1) を表します。 これらは一緒にバイナリ増分を強制します。 

タイプ 1 エッジは、`g[r].append((l - 1, -k))`。 その緩和条件は (S_{L-1}\le S_R-K) であり、これはまさに区間に必要な下限です。 

タイプ 2 はタイプ 1 と比べてエッジが逆になっています。その重さは`x - k`なぜなら、(S_N=X) を固定すると、カウント外条件が (S_R\le S_{L-1}+X-K) に変換されるからです。 

最後の 2 つのエッジは両方とも必要です。 のみを使用する`0 -> n`のみを使用すると、(S_N\le X) が与えられます。`n -> 0`(S_N\ge X) が得られます。 それらを組み合わせると合計が正確に決まります。 

すべての頂点が到達可能であるとみなされる場合、SPFA 距離配列はすべて 0 で開始できますが、この実装は頂点 0 からのみ開始します。 前方プレフィックス エッジによってゼロからすべての頂点までのパスが与えられるため、これは安全です。 任意の頂点から到達可能な負のサイクルは、結果的にゼロからも到達可能です。 

緩和カウンタは、SPFA が無期限に継続する前に負のサイクルを検出します。 (V) 個の頂点を持ち、負のサイクルがないグラフでは、最短パスは、少なくとも (V) 個のエッジを含む繰り返し改善するパスを必要としません。 頂点がリラックスしている場合、それは負のサイクルを示していることがよくあります。 

Python の整数を使用すると、オーバーフローの問題がなくなります。 関係する最大値は (N) 程度にすぎませんが、累積された最短経路距離は負の値になる場合があります。 

二分探索では、`hi = n`すべて (N) 個の立方体をペイントすると、常にすべてのルールが満たされるためです。 入力境界は、タイプ 1 の要件が間隔の長さを超えることを要求しないこと、およびタイプ 2 の要件がその補数のサイズを超えることを要求しないことを保証します。 

## 実用的な例

 ### サンプル 1

 実際のサンプルには 1 つのテスト ケースが含まれています。```
1
3 1 1
1 2 1
2 2 1
```最初のルールでは、位置 1 と 2 の間に少なくとも 1 つのペイントされた立方体が必要です。2 番目のルールでは、位置 2 の外側に少なくとも 1 つのペイントされた立方体が必要であるため、位置 1 または位置 3 のいずれかをペイントする必要があります。 

二分探索は次のように動作します。 

|`lo`|`hi`|`mid`| 解釈候補 | 実現可能ですか？ |
 | --- | --- | --- | --- | --- |
 | 0 | 3 | 1 | 正確に 1 つの立方体をペイントする | はい |
 | 0 | 1 | 0 | 正確に 0 個の立方体をペイントする | いいえ |

 (X=1) の場合、立方体 1 のペイントは機能します。 立方体 1 が ([1,2]) 内にあるため、最初の規則を満たし、立方体 1 が ([2,2]) の外側にあるため、2 番目の規則を満たします。 したがって、答えは 1 です。公式ステートメントでは、これと同じサンプルと出力が示されています。 

### サンプル 2

 次の場合を考えてみましょう。```
1
5 1 1
2 4 2
2 4 1
```タイプ 1 ルールでは、位置 2 ～ 4 に少なくとも 2 つのペイントされた立方体が必要です。タイプ 2 ルールでは、位置 2 ～ 4 の外側に少なくとも 1 つのペイントされた立方体が必要であるため、位置 1 と 5 の少なくとも 1 つもペイントする必要があります。 

二分探索は次のとおりです。 

|`lo`|`hi`|`mid`| 解釈候補 | 実現可能ですか？ |
 | --- | --- | --- | --- | --- |
 | 0 | 5 | 2 | ちょうど 2 つのペイントされた立方体 | いいえ |

この例は、単に必要な最大間隔数を取得するだけでは十分ではない理由を示しています。 2 つのルール タイプは、ペイントされた立方体の総数を通じて相互作用します。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | (O(N(N+M_1+M_2)\log N)) 最悪の場合 | (O(\log N)) 個の実現可能性チェックがあり、各 SPFA チェックには、(V=O(N)) および (E=O(N+M_1+M_2)) による (O(VE)) 個の最悪の複雑度があります。 |
 | スペース | (O(N+M_1+M_2)) | グラフ、距離、キュー状態、制約配列はすべて線形サイズです。 |

 公式社説では、二分探索と SPFA アプローチの同じ (O(NM\log N)) 限界を示し、SPFA プルーニングがコンテストの制限に対して十分であると述べています。 すべてのテスト ケースの (N)、(M_1)、および (M_2) の合計はそれぞれ 3000 で制限されるため、合計入力はすべてのテスト ケースを独立したワーストケース インスタンスとして扱うよりも大幅に小さくなります。

 ## 特殊なケース

 ルールがない場合、グラフにはプレフィックス差制約と固定合計制約のみが含まれます。 のために```
1
1 0 0
```候補 (X=0) は (S_0=S_1=0) を生成するため、負の循環はなく、二分探索ではゼロが返されます。 このアルゴリズムは、少なくとも 1 つの立方体をペイントする必要があるとは決して想定しません。 

ルールが (K=0) を持つ場合、そのグラフ エッジの重みは 0 であり、プレフィックス構造によってすでに暗示されている制限を超える追加の制限は課されません。 のために```
1
3 1 0
1 3 0
```候補 (X=0) は実行可能であり、正解は 0 になります。 

タイプ 1 の要件を持つ単一のキューブの場合、```
1
1 1 0
1 1 1
```制約は (S_0-S_1\le-1) になりますが、バイナリ接頭辞制約は (S_1-S_0\le1) および (S_0-S_1\le0) になります。 可能な値は (S_1=1) のみであるため、答えは 1 です。 これは、(L-1=0) 境界を直接実行します。 

タイプ 2 の境界ケースの場合、```
1
4 0 1
1 1 2
```([1,1]) の外側は位置 2、3、および 4 で構成されます。ルールはそこに 2 つのペイントされた立方体を要求するため、2 つの立方体で十分であり、必要です。 グラフでは、ルールは (S_1-S_0\le X-2) となり、補数条件の正しい変換になります。 

最も微妙なケースは、間隔と補数の要件が反対方向に引っ張られる場合です。 で```
1
5 1 1
2 4 2
2 4 1
```2 つの立方体は位置 2 ～ 4 の内側にペイントする必要があり、もう 1 つのペイントされた立方体は外側にある必要があります。 したがって、最小値は 3 になります。 テスト (X=2) では一貫性のない差分制約システムが作成されるため、SPFA は負のサイクルを見つけます。 テスト (X=3) によりその矛盾が解消され、二分探索はそこで停止します。 

最後に、ある程度の (X) が実現可能であれば、より大きな (X) 値は常に安全です。 別のペイントされた立方体を追加しても、タイプ 1 の状態に悪影響を与えることはできません。その間隔数は増加するだけであるためです。 タイプ 2 の状態の場合、その外側のカウントは変更されないままであるか、増加します。 この単調性こそが、単なるヒューリスティックではなく二分探索を有効なものにしているのです。
