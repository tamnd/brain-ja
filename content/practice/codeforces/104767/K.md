 ## 解決策
 ## 問題の理解

 私たちは離散幾何学的設定で作業しています。 原点を中心とする球を想像してください。$D$-次元整数格子。 原点からのユークリッド距離が最大以下のすべての格子点$R$球の「内部または表面」とみなされます。 

このような整数点ごとに$(x_1, x_2, \dots, x_D)$、その寄与をその座標の絶対値の合計として計算します。$|x_1| + |x_2| + \cdots + |x_D|$。 タスクは、球内のすべての格子点にわたるこの寄与を合計することです。 

出力はこの総和モジュロです$10^9 + 7$。 

入力制限は見かけ上小さいですが、$D, R \le 50$、しかし、幾何学的オブジェクトは組み合わせ的に巨大です。 次のような控えめな値であっても、$D = 10, R = 20$、ボール内の整数点の数は天文学的に多くなります。 これにより、点の直接の列挙が即座に除外されます。 

素朴な試みでは、ハイパーキューブ内のすべての整数ベクトルを反復処理することになります。$[-R, R]^D$、それぞれが球内にあるかどうかを確認し、貢献度を蓄積します。 これはすでに生成されています$(2R+1)^D$候補者、最悪の場合は$101^{50}$、完全に不可能です。 

さらに微妙な落とし穴は、対称性の誤用から生じます。 正のオルタントのみでポイントをカウントし、次の値を乗算しようとすることもできます。$2^D$ただし、符号反転によって個別の点が生成されないため、座標がゼロの点の場合は失敗します。 座標に関する対称性を注意深く考慮していないソリューションでは、寄与が過大評価または過少評価されます。 

## アプローチ

 中心的な問題は、球面制約上で分離可能な関数を合計していることです。$\ell_2$-norm、関数自体は$\ell_1$-のように。 この構造はすべての座標で対称であり、符号が変化しても不変であるため、最初の単純化は非負の座標でのみ機能し、後で正しく乗算することです。 

ブルートフォース手法では、ボール内のすべての整数点を列挙し、それらの座標寄与を直接合計します。 これは文字通り定義に従っているため、概念的には単純で正しいものです。 ただし、そのコストは、格子点の数が増えるにつれて増加します。$D$-ボール、指数関数的に動作します$D$。 超立方体に限定しても、状態空間は次のようになります。$(2R+1)^D$、これは計算の限界をはるかに超えています。 

重要な構造的観察は、点を合計する代わりに、次元ごとに座標の寄与を合計するものとして問題を再解釈できることです。 その座標内で指定された絶対値を持つ有効な点の数を数えると、各座標は独立して寄与します。 これにより、問題は完全なベクトルの列挙から、制限された残りの半径を持つ低次元にいくつの部分ベクトルが存在するかを数えることに軽減されます。 

これにより、当然のことながら、次元と半径の 2 乗に関する動的プログラミングの定式化が行われます。 部分ベクトルを構築する方法の数と合計の量を追跡する状態を定義します。$\ell_1$貢献度が蓄積されました。 移行では、一度に 1 つの座標を追加し、その座標で可能なすべての整数値を反復処理し、構成の数と寄与の増加の両方を更新します。 

球面拘束は座標の二乗和に関するナップザックのような条件になりますが、目的は絶対値を線形に累積します。 なぜなら$D, R \le 50$、寸法と半径の二乗に対する DP$R^2$実現可能です。

 の三次因子$R$すべての座標値を反復処理し、二乗半径の遷移を分散することで得られます。 

## アルゴリズムのチュートリアル

 平方半径で作業します$S = R^2$。 させて$dp[d][s]$最初の 2 つの量を表します$d$次元: 総二乗ノルムを使用して整数座標を正確に選択する方法の数$s$、およびそのようなすべての構成にわたる絶対値の合計。 

私たちはカウントと貢献額の両方を一緒に維持します。 

1. DP をゼロ次元に初期化します。 二乗ノルムを持つ空のベクトルが 1 つだけあります$0$そして貢献$0$。 これにより、$dp[0][0] = (1, 0)$。 
2. 寸法を 1 つずつ処理します。 それぞれの次元で$i$、値を選択することで以前のすべての状態を拡張します$x \in [-R, R]$。 二乗ノルムは次のように増加します$x^2$、貢献度は によって増加します$|x|$既存の構成の数を掛けたものです。 
3. 前の状態ごとに二乗和を求める$s$、可能な限りすべてを繰り返します$x$。 もし$s + x^2 \le R^2$、新しい状態を更新します。 コンフィギュレーションの数は倍増しますが、コントリビューションには以前のコントリビューション コピーと追加されたコントリビューションの両方が蓄積されます。$|x|$コスト×構成数。 
4. すべての次元を処理した後、最大でも 2 乗ノルムを使用してすべての状態を合計します。$R^2$、寄付金の総額を集めます。 

なぜ遷移が正しいのかは、座標の独立性からわかります。 各拡張ステップでは、以前の部分ベクトルを固定されたものとして扱い、新しい次元のすべての有効な拡張を列挙し、二乗半径の加算を通じて球面制約を正確に保持します。 

### なぜ効果があるのか

 球内のすべての格子点は、一度に 1 つの座標を選択することによって一意に構築されます。 DP は、二乗ノルムによって点をグループ化し、同一の部分問題を集約します。 各座標の選択は独立しており、加法二乗制約を通じてのみ相互作用するため、状態は必要な情報をすべて完全に取得します。 貢献度の累積は座標全体にわたって線形であるため、拡張子全体に分散させることで二重にカウントすることなく正確さが保たれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    D, R = map(int, input().split())
    S = R * R

    # dp[s] = (count, sum_abs)
    dp = [(0, 0)] * (S + 1)
    dp[0] = (1, 0)

    for _ in range(D):
        ndp = [(0, 0) for _ in range(S + 1)]
        for s in range(S + 1):
            cnt, sm = dp[s]
            if cnt == 0:
                continue
            for x in range(-R, R + 1):
                ns = s + x * x
                if ns > S:
                    continue
                ncnt, nsm = ndp[ns]
                nc = cnt
                # update count
                ncnt = (ncnt + nc) % MOD
                # update sum: previous sums replicated + added abs(x) for each vector
                nsm = (nsm + sm + cnt * abs(x)) % MOD
                ndp[ns] = (ncnt, nsm)
        dp = ndp

    ans = 0
    for cnt, sm in dp:
        ans = (ans + sm) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、二乗半径にわたって DP 配列が維持されます。 次元ごとに、すべての座標値を試して新しい DP レイヤーを構築します。 重要な点は、以前の次元からの寄与が変更されずに引き継がれる一方、新しい座標が追加されるたびに、$|x|$前の状態でカウントされた構成ごとに 1 回。 

カウントは中程度の場合でも指数関数的に増加するため、オーバーフローを防ぐために更新のたびに係数が適用されます。$D$。

 ## 特殊なケース

 退化したケース$R = 0$原点だけを残します。 DP は、寄与がゼロである単一の空のベクトルで初期化され、すべての遷移が新しい状態を追加することはありません。$x \neq 0$は無効です。 最終的な答えはゼロのままで、唯一の点が何も貢献しないという事実と一致します。 

のために$D = 1$、DP は整数に対する単純な列挙に折りたたまれます。$[-R, R]$。 各状態は単一の座標値に直接対応し、半径の二乗次元は無関係になります。 このアルゴリズムは、対称区間にわたる絶対値の合計を正確に計算し、二重カウントなしで期待される算術構造と一致します。
