 ## 解決策
 ## 問題の理解

 私たちに与えられているのは$N$ラベル付きの点が円上に配置され、考えられるすべての文字列が 2 つの異なる点の間の直線セグメントとして描画されますが、一部の文字列セットのみが許可されます。 文字列は共有端点以外で交差してはなりません。そのため、描画されるグラフは点の凸状の位置に関して平面になります。 

すべてのペグには、それぞれ 1 つのインシデント文字列を持つ 2 つの特別なペグを除いて、正確に 2 つのインシデント文字列があります。 これにより、構造全体がすべてのペグを 1 回だけ訪れる単一の単純なパスになります。内部頂点の次数は 2、2 つの端点の次数は 1 であるため、分岐はできません。 

タスクは、このような交差しない完全なパスを何通り描画できるかを数えることです。$N$凸多角形上のラベル付き点。2 つの図面がまったく同じエッジのセットを使用している場合、2 つの図面は同一とみなされます。 

制約$N \le 1000$構造を明示的に列挙する試みは除外されます。 エッジの選択を検討したり、バックトラッキングを使用して段階的にグラフを構築しようとするソリューションは、組み合わせ的に爆発的に発生します。 実現可能な解決策は、問題を閉じた形式、または最悪の場合でも問題を解決する必要があります。$O(N)$または$O(N \log N)$モジュラー演算なので計算$10^9+7$が必要です。 

素朴な推論が微妙に失敗するケースは、頂点の順列が有効な非交差パスに対応すると仮定することです。 たとえば、$N=4$、シーケンス$1 \to 3 \to 2 \to 4$エッジがあるため無効です$(1,3)$そして$(2,4)$クロス。 この制約は幾何学的なものであり、純粋に組み合わせによるものではありません。 

もう 1 つのよくある間違いは、最初にエンドポイントを固定するか個別に選択する必要があると想定することです。 実際には、エンドポイントの選択と内部構造は分離できません。 それらを個別にカウントすると、大幅にオーバーカウントされます。 

## アプローチ

 ブルートフォース手法では、次のすべての順列を生成しようとします。$N$頂点を取得し、それぞれをパスとして解釈し、そのエッジが凸多角形上で交差しないセットを形成しているかどうかを確認します。 1 つの順列を検証するだけでもチェックが必要です$O(N)$エッジがあり、$N!$順列の結果、$O(N! \cdot N)$、これは実現可能性をはるかに超えています。$N=20$。 

重要な構造的観察は、有効な構成は単なるパスではなく、凸多角形上の交差しないハミルトニアン パスであるということです。 このようなオブジェクトには強力な再帰的分解があり、交差しないエッジはその分割を越えて接続できないため、1 つのエッジを選択すると多角形が 2 つの独立した部分問題に分割されます。 

これは二者択一構造につながります。 エッジがパスに固定されると、残りのすべての頂点は平面性を維持する方法で接続する必要があり、各ステップで構造が境界に沿って左右の領域に分割されます。 それぞれの内部決定は、進化するパスのどちら側に頂点が接続するかを選択することに対応しており、これらの選択は独立しています。 

この独立性により、問題は、サイクル上の開始位置の選択と組み合わせて、内部頂点に対するバイナリ割り当ての純粋なカウントに分解されます。 

結果として得られる閉じた形式は次のようになります。$N \cdot 2^{N-3}$。

 | --- | --- | --- | --- |
 | 順列に対するブルートフォース |$O(N! \cdot N)$|$O(N)$| 遅すぎる |
 | 組み合わせ構造 |$O(N)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 式を導き出して計算します$N \cdot 2^{N-3}$。 

1. サイクル上の基準点として機能する任意の頂点を固定します。 この構造は回転対称であるため、特別な幾何学的制約を持つ頂点はありません。 
2. 有効な構成はすべて単一のハミルトニアン パスであることを確認します。 エンドポイントが暗黙的に選択されると、残りの頂点は非交差の挿入順序に強制されます。 
3. パスの選択した終点で構築をルートします。 その終点から、パスは非交差制約を維持しながら未使用の頂点まで繰り返し延長して進みます。 各ステップで、未使用の頂点が境界上に連続した間隔を形成します。 
4. パスが内部頂点を通過するたびに、その頂点には、残りの未使用の近傍を接続できる 2 つの利用可能な辺があり、残りの間隔をどのように分割するかを決定する二分決定に対応します。 
5. まさにあります$N-3$このような独立した二者択一の決定。 これは、エンドポイントを修正した後、残りの$N-2$頂点が寄与する$N-3$形状によって強制されない内部取り付けステップ。 
6. それぞれの二者択一の選択は独立しており、次の係数が生成されます。$2^{N-3}$。 
7. 最後に、建設の開始位置は、次のいずれかの位置に固定できます。$N$頂点、乗算係数に寄与する$N$。 

最終的な答えは次のとおりです。$$\text{ans} = N \cdot 2^{N-3} \bmod (10^9+7)$$### なぜ効果があるのか

 非交差条件により、グラフは凸多角形の再帰的バイナリ分解のように動作します。 新しい内部頂点がパスに組み込まれるたびに、残りの未訪問の頂点が 2 つの互いに素な境界区間に分割されます。 これらの間隔が再び相互作用することはありません。そのため、その頂点での決定は、それまでのすべての選択から独立しています。 これにより、独立した二値決定の積が作成され、指数項が正確に説明され、サイクルの対称性が線形因子を説明します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modexp(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve():
    n = int(input().strip())
    if n <= 2:
        print(1)
        return
    ans = n * modexp(2, n - 3) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```この実装は、閉じた形式を直接翻訳したものです。 高速なべき乗計算$2^{n-3}$対数時間で。 の乗算$n$剰余が取られます$10^9+7$。 

コーナーケースは次の場所に表示されます。$N=2$、指数が負になります。 これは両方の頂点を接続する一意の単一エッジに対応するため、答えは 1 として個別に定義されます。

 ## 特殊なケース

 のために$N=2$、式$N \cdot 2^{N-3}$必要になるだろう$2^{-1}$、これは剰余算術では意味がありません。 この場合、可能な構成は 2 つのペグを接続する 1 本の紐だけなので、答えは 1 になります。 

のために$N=3$、すべての有効な構成は、単一のパス内の 3 つの頂点すべてを接続する必要があります。 式は次のようになります$3 \cdot 2^0 = 3$、エンドポイントの 3 つの可能な選択肢に対応し、それぞれが固有の非交差パスを生成します。
