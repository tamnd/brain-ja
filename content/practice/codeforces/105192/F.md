 ## 問題の理解

 2 つの開始整数と、シーケンスをどこまで拡張するかを記述する 3 番目のパラメーターが与えられます。 この範囲に沿った各インデックスから、足並みをそろえて移動する 2 つの数値を調べます。1 つは から始まります。`a`ステップごとに 1 ずつ増加し、もう 1 つは から始まります。`b`また、ステップごとに 1 ずつ増加します。 すべての位置について、その位置のペアの最大公約数を計算し、これらの値をすべて加算します。 

したがって、タスクは gcd 値の長い等差数列を評価することです。 

あらゆる人にとって`i`から`0`に`d`、計算する`gcd(a + i, b + i)`そしてそれらを合計します。 

この制約により、直接のシミュレーションが直ちに除外されます。 項の数は次のように大きくできます。`10^18`, したがって、それらの一部でも反復することは不可能です。 各 gcd 計算は安価ですが、評価の数がすべてを支配します。 これにより、シフト ペアに対して gcd がどのように動作するかの構造を理解する必要があります。 

2 つのシーケンスが同じかほぼ同じで始まる場合、微妙なエッジ ケースが発生します。 もし`a = b`、すると、すべての項は次のようになります`gcd(a+i, a+i) = a+i`、問題を単純な等差数列の和に変換します。 単純な gcd ベースのループも概念的には機能しますが、規模の観点から実行不可能です。 次の場合には、別のエッジケースが発生します。`|a-b| = 1`ここで、gcd は短いプレフィックスの後にすぐに 1 に崩壊しますが、その動作を検出するには、反復ではなく割り切れるパターンについての推論が必要です。 

## アプローチ

 直接総当たりアプローチで各インデックスを評価します`i`独立して。 それぞれについて`i`、計算します`gcd(a+i, b+i)`そしてそれを答えに追加します。 これは定義と正確に一致しており、仮定を使用していないため、これは正しいです。 

問題は規模だ。 と`d`まで`10^18`、すべてのインデックスに対する単一のループさえ不可能です。 gcd が対数であっても、反復回数が完全に支配的になります。 

重要な観察は、gcd 式を書き換えることから得られます。 させて`g = gcd(a, b)`、定義します`a = g * A`、`b = g * B`と`gcd(A, B) = 1`。 それから：`gcd(a+i, b+i) = gcd(gA + i, gB + i)`ここでは、標準の gcd ID を使用します。`gcd(x, y) = gcd(x, y - x)`それで：`gcd(a+i, b+i) = gcd(a+i, (b+i) - (a+i)) = gcd(a+i, b-a)`2 番目の引数は範囲全体にわたって定数になります。 これにより問題は合計に帰着します`gcd(a+i, D)`どこ`D = |b - a|`。 

これで構造がより明確になりました。 固定数に対して線形シーケンスの gcd を合計しています。 gcd 値は、方法によってのみ異なります。`a+i`の約数と一致します`D`。 これは、値が約数によって決定される周期構造で繰り返されることを意味します。`D`、インデックスをグループ化することで寄与を処理できます。`gcd(a+i, D)`同じです。 

標準的な方法は、次のすべての約数を反復処理することです。`D`、そして倍数に対して包含を使用します。 各約数について`g`の項の数を数えます。`[a, a+d]`で割り切れます`g`、次に、より大きな倍数で割り切れる値を減算して、正確な gcd 寄与を分離します。 これにより、問題はある期間にわたる除数のカウントに変わります。これは、次のように対数になります。`d`床割り算を使用した後。 

インデックスごとの計算から除数ごとの集計への移行により、ソリューションが実現可能になります。

 ## アルゴリズムのチュートリアル

 問題を固定差に帰着させます`D = |b - a|`そして一緒に働きます`gcd(a+i, D)`。 

1. コンピューティング`D = abs(b - a)`。 もし`D = 0`、すべての用語は単純に`a + i`、したがって、答えは次の等差数列の合計になります。`a`に`a + d`。 
2. すべての約数を因数分解するか列挙します。`D`。 すべての gcd 値はこれらの約数の 1 つである必要があります。`gcd(a+i, D)`常に分裂する`D`。 これにより、値スペースが最大で次のように制限されます。`O(√D)`要素。 
3. 各約数について`g`の`D`、間隔内の整数の数を数えます`[a, a+d]`で割り切れます`g`。 これはフロア分割を使用して計算されます。`cnt(g) = floor((a+d)/g) - floor((a-1)/g)`。 
4. ここで、gcd が正確に等しい位置の数が必要になります。`g`で割り切れるだけではありません`g`。 約数を降順に処理します。 それぞれについて`g`、既に倍数に割り当てられている寄与分を差し引きます。`g`。 これは除数格子上の標準包含です。 
5.追加`g * exact_count[g]`答えに。 
6. 結果のモジュロを返します`10^9 + 7`。 

### なぜ効果があるのか

 重要な不変条件は、すべての項が`gcd(a+i, D)`は、の約数によって完全に決定されます。`D`分ける`a+i`。 割り算条件は整数を除数の倍数にわたってきれいに分割するため、各インデックスは除数格子内のちょうど 1 つの gcd 値に寄与します。 約数を大きいものから小さいものまで処理し、倍数の寄与を差し引くことにより、各インデックスが両方の数値を除算する一意の最大の約数 (正確に gcd) に割り当てられるようにします。 これにより、二重カウントが防止され、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def count_multiples(l, r, g):
    return r // g - (l - 1) // g

def solve_case(a, b, d):
    if a == b:
        # sum of arithmetic progression
        n = d + 1
        last = a + d
        return ((a + last) * n // 2) % MOD

    D = abs(a - b)

    # enumerate divisors
    divisors = []
    i = 1
    while i * i <= D:
        if D % i == 0:
            divisors.append(i)
            if i * i != D:
                divisors.append(D // i)
        i += 1

    divisors.sort(reverse=True)

    cnt = {}
    for g in divisors:
        cnt[g] = count_multiples(a, a + d, g)

    res = 0
    for g in divisors:
        c = cnt[g]
        for multiple in divisors:
            if multiple > g and multiple % g == 0:
                c -= cnt[multiple]
        res = (res + g * c) % MOD

    return res

def main():
    t = int(input())
    for _ in range(t):
        a, b, d = map(int, input().split())
        print(solve_case(a, b, d))

if __name__ == "__main__":
    main()
```実装は特殊なケースを分離します`a == b`ここで、gcd は値自体に折りたたまれ、直接の算術合計になります。 これにより、不必要な除数ロジックが回避され、gcd の 2 番目の引数が消える唯一の状況が処理されます。 

一般的なケースでは、約数を列挙します。`|a-b|`、gcd 値がそのセット内に存在する必要があるためです。 ヘルパー関数`count_multiples`標準の下限演算を使用して、指定された約数で割り切れる区間内の項の数を計算します。 

ネストされたループは、除数ラティスに対して包含/除外を実行します。 すべてのより大きな倍数のカウントを減算して、各約数の正確な gcd 寄与を分離します。 この順序は重要です。 逆にすると寄付金が二重にカウントされてしまいます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import gcd

    MOD = 10**9 + 7

    def brute(a, b, d):
        return sum(gcd(a+i, b+i) for i in range(d+1)) % MOD

    # placeholder for actual solution call
    def solve():
        import sys
        input = sys.stdin.readline
        def count_multiples(l, r, g):
            return r // g - (l - 1) // g

        def solve_case(a, b, d):
            if a == b:
                n = d + 1
                last = a + d
                return ((a + last) * n // 2) % MOD

            D = abs(a - b)
            divisors = []
            i = 1
            while i * i <= D:
                if D % i == 0:
                    divisors.append(i)
                    if i * i != D:
                        divisors.append(D // i)
                i += 1

            divisors.sort(reverse=True)

            cnt = {g: count_multiples(a, a + d, g) for g in divisors}

            res = 0
            for g in divisors:
                c = cnt[g]
                for m in divisors:
                    if m > g and m % g == 0:
                        c -= cnt[m]
                res = (res + g * c) % MOD
            return res

        t = int(input())
        out = []
        for _ in range(t):
            a, b, d = map(int, input().split())
            out.append(str(solve_case(a, b, d)))
        return "\n".join(out)

    # samples
    assert run("2\n1 7 5\n2 8 8\n") == "15\n22"

    # edge: equal
    assert run("1\n5 5 3\n") == str(sum(5+i for i in range(4)) % MOD)

    # small random consistency
    assert run("1\n3 4 2\n") == str(brute(3,4,2))

    print("ok")

 ## 特殊なケース

 いつ`a = b`、すべての用語は次のように単純化されます。`gcd(x, x)`, したがって、シーケンスは直接等差数列になります。 このアルゴリズムは除数ロジックを明示的にバイパスし、等差級数の公式を使用して一定時間で合計を計算し、不必要な因数分解を回避し、オーバーフローやパフォーマンスの問題を防ぎます。 

いつ`|a-b| = 1`、唯一の約数は`1`したがって、すべての項が正確に寄与します`1`。 除数の列挙では単一の値が生成され、包含/除外によってその値は変更されず、合計が得られます。`d+1`。 これは、格子論理が自明ではない最小の除数構造で正しく崩壊することを確認します。 

いつ`a`とても大きくて、`d`も大きい、の個体値`a+i`明示的に列挙されることはありません。 このアルゴリズムはフロア分割数のみに依存するため、値が一般的な反復制限を超えた場合でも安定したままになります。
