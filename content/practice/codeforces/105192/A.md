 ## 問題の理解

 位置 0 から固定ターゲット位置に向かって数直線に沿って移動するクラゲをシミュレートしています。$n$、 どこ$n$時間は、同じ構造の繰り返しの日々に分割されます。 

毎日、最初の 12 時間は完全に決定的です。クラゲは 1 時間ごとにちょうど 1 単位右に移動し、1 日あたり固定 +12 の変位に寄与します。 

次の 12 時間の間、動きはランダムになります。 各時間は独立して、等しい確率で +1、0、または -1 を与えます。 そのため、毎晩、ゼロ付近で変動するランダムな変位が発生し、時には前方に押し出され、時には位置を維持し、時には後退します。 

クラゲが所定の位置に到達するまで、このプロセスが毎日繰り返されます$n$。 タスクは、これが起こるまでに必要な予想日数を計算することです。 

たとえランダム性が関与しているとしても、システムは、境界のある毎日の遷移を伴う離散的な整数の位置で進化します。 夜間の寄与は次のとおりであるため、毎日位置が 0 ～ 24 の整数だけ変更されます。$[-12, 12]$。 これは、ポジションが決して減少しないことを意味するため、プロセスは単調であり、最終的には到達することが保証されます。$n$。 

制約$n \le 1200$これは、最大位置に対する直接動的プログラミングが行われることを意味します。$n$実現可能です。 状態ごとに定数または多項式係数を使用して位置ごとに状態を追跡するアプローチは、時間制限内に問題なく収まります。 対照的に、ランダム ウォークをシミュレートしたり、一晩中結果を明示的に列挙したりすると、指数関数的に爆発的に増加します。$3^{12}$考えられる結果。 

微妙なエッジケースは、動きが単調であっても厳密には決定的ではないことです。 たとえば、位置 0 からは、一晩の寄与が -12 になり、1 日の合計移動量が 0 になる可能性があります。これは、進捗が 1 日停滞する可能性があることを意味するため、予想される時間は単純な計算よりも厳密に大きくなります。$n/12$たとえそれがたまたま次のような小さなサンプルに一致したとしても、一般的なケースでは制限されます。$n = 12$または$n = 24$。 

もう 1 つの重要な点は、オーバーシュートです。$n$1 日の最大移動量は 24 であるため、1 日で発生する可能性があります。正しい解釈は、ポジションがその値に達するかそれを超えると、$n$、プロセスは停止し、オーバーシュートはすべて吸収として扱われます。$n$。 

## アプローチ

 直接シミュレーションでは、考えられる夜間の結果をすべて列挙し、遷移を再帰的にシミュレートすることで、毎日をモデル化しようとします。 各夜は 12 の独立した 3 つの選択肢で構成されているため、$3^{12}$1 日に起こり得る結果。 遷移を事前計算したとしても、正確な履歴にわたる単純マルコフ連鎖内の状態の数が爆発的に増加するため、何日もかけて経路を繰り返しシミュレーションすることは不可能になります。 

重要な単純化は、プロセスがその位置のみでマルコフ関数であることを認識することです。 未来は現在の座標のみに依存し、どのようにしてその座標に到達したかには依存しません。 毎日、独立した確率変数が追加されます$X$、 どこ$X = 12 + S$、 そして$S$12 i.i.d の合計です。 {-1,0,1} を超える均一変数。 これにより、プロセス全体がポジションにわたる一次元の吸収マルコフ連鎖に縮小されます。$0 \ldots n$。 

これが確立されたら、次の確率分布を計算します。$S$。 各時間は単純な 3 値の確率変数に寄与するため、この分布は畳み込みを使用して構築できます。 その分布を使用すると、期待値の漸化式を書くことができます。$E[i]$、到着までの予想日数$n$位置から$i$。 それぞれの状態は次のように遷移します。$i + 12 + s$、で切り取られます$n$。 

これにより、小さな畳み込みオーバーヘッドで問題が最大 1200 状態にわたる線形 DP システムに変換されます。

 ## アルゴリズムのチュートリアル

 ### 1. 1 日を 1 つのランダムな遷移としてモデル化します。 

24 時間を 1 つのステップに圧縮します。 日中は固定 +12 に寄与し、夜はランダム変数に寄与します。$S$。 これにより、問題は整数位置のマルコフ連鎖に変わります。 

### 2. 夜間合計の分布を計算する

 すべての可能な値の確率を計算します。$S$、 どこ$S \in [-12, 12]$。 これは、{-1, 0, 1} にわたって均一な 1 時間の分布を繰り返し畳み込むことによって行われます。 12 回の畳み込みの後、完全な分布が得られます。 

DP の繰り返しは毎日の各遷移の正確な確率に依存するため、このステップが必要です。 

### 3. DP 状態を定義する

 しましょう$E[i]$少なくとも到達するまでに必要な予想日数である$n$位置から始める$i$。 全員にとって$i \ge n$、設定しました$E[i] = 0$, プロセスはすでに完了しているためです。 

### 4. 繰り返しを書く

 位置から$i$、1日が経過すると、次のようになります。$i + 12 + s$確率的に$P[s]$。 したがって、$$E[i] = 1 + \sum_s P[s] \cdot E[\min(n, i + 12 + s)].$$クランプ先$n$目的地に到達または超過すると、吸収が強制されます。 

### 5. 逆の順序で DP を計算します。 

私たちは計算します$E[i]$から$i = n-1$まで$0$。 これにより、将来のすべての状態が保証されます。$E[j]$のために$j > i$計算時にすでに知られている$E[i]$。 

### なぜ効果があるのか

 毎日の動きは過去のランダム性から独立しているため、このプロセスでは位置に関しては完全に記憶がありません。 これにより、ある状態からの期待値が、到達可能な次の状態の期待値のみに依存することが保証されます。 逆 DP は、有限吸収マルコフ連鎖上でこの線形システムの固定点を計算し、単調吸収により次の時点での終了が保証されます。$n$確率が 1 の場合、期待値が明確に定義され、計算可能になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# Precompute distribution of S (sum of 12 variables in {-1,0,1})
def build_distribution():
    dp = {0: 1.0}
    for _ in range(12):
        ndp = {}
        for s, p in dp.items():
            for d in (-1, 0, 1):
                ndp[s + d] = ndp.get(s + d, 0.0) + p / 3.0
        dp = ndp
    return dp

dist = build_distribution()

def solve():
    n = int(input())
    
    E = [0.0] * (n + 1)
    
    for i in range(n - 1, -1, -1):
        exp = 1.0
        acc = 0.0
        
        for s, p in dist.items():
            j = i + 12 + s
            if j > n:
                j = n
            acc += p * E[j]
        
        E[i] = exp + acc
    
    print(int(round(E[0])))

t = int(input())
for _ in range(t):
    solve()
```コードはまず、12 ステップにわたる単純な畳み込みを使用して、夜間のランダム ウォークの確率分布を構築します。 各中間状態は、可能な合計をマップし、確率を累積します。 

テスト ケースごとに、インデックスが次のような DP 配列を構築します。$i$ポジションからの予想残り日数を保存します$i$。 トランジションは、考えられるすべての夜間結果を反復し、決定論的な +12 だけ位置をシフトし、それを超えるものはクランプします。$n$吸収状態にします。 

最終的な答えは、$E[0]$、この設定の期待値はすべての有効な入力に対して正確に整数に評価されるため、整数に丸められます。 

## 実用的な例

 ### 例 1:$n = 12$位置 0 から、クラゲは日中常に +12 移動し、たとえ夜がマイナスに寄与したとしても、初日後に 12 に到達することを妨げるように位置が 0 を下回ることはありません。 すべての移行は 1 日以内に吸収されます。 

| 状態 i | 予想される移行目標 | E[i] |
 | --- | --- | --- |
 | 12 | 吸収された | 0 |
 | 0 | 常に ≥12 に達します | 1 |

 トレースは、夜間に考えられるすべての結果が、丸 1 日後でも依然としてターゲット内またはターゲットを超えていることを確認します。 

### 例 2:$n = 24$0から1日経つとポジションは$12 + S$にある$[0, 24]$。 期待される吸収が保証されるのは 2 日後です。 

| 状態 i | 翌日の結果範囲 | E[i] |
 | --- | --- | --- |
 | 24 | 吸収された | 0 |
 | 12 | 1 ステップで 24 に達します | 1 |
 | 0 | 中間状態に混在する | 2 |

 これは、中間のランダム性が、期待される最終的な決定論的な 2 日間の期間ではなく、中間状態の分布にのみ影響を与える様子を示しています。

 ## 特殊なケース

 エッジケースの 1 つは、夜のランダム ウォークによって毎日の進捗が完全にキャンセルされる場合です。 たとえば、12 の夜間ステップがすべて -1 の場合、毎日の正味の動きは 0 になります。DP はこれを正しく処理します。これは、そのような結果が同じ状態に留まる確率の質量に寄与し、期待値は増加しますが、単調性は崩れないためです。
