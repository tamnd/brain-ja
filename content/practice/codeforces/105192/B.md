 ## 解決策
 ## 問題の理解

 単一の多項式が与えられます$c(x)$、0 次から次数までの係数によって記述されます。$l$。 この多項式は、他の 2 つの多項式を乗算した結果であることが知られています$a(x)$そして$b(x)$, しかし、本来の要素は失われてしまいました。 タスクはそれらを一意に回復することではなく、多項式の任意のペアを構築することです。$a$そして$b$その畳み込みは指定された多項式を正確に返します$c$。 

出力形式では、再構築された両方の多項式の次数と係数を明示的に出力するように求められます。 最小次数、一意性、または乗算の正しさを超える構造的制約に対する要件はありません。 

制約は大きく、$l \le 10^5$これにより、多項式を有意義に因数分解したり、係数に関する連立方程式を解こうとするアプローチは即座に除外されます。 「実際の」因数分解を再構築しようとすると、畳み込み推論または代数分解が必要になりますが、これは必要以上に負荷がかかります。 重要な観察点は、正確さは製品のマッチングのみに依存するということです。$c$要素がどれだけ「興味深い」かではありません。 

最も危険なエッジ ケースは、両方の多項式が自明でない必要がある、または何らかのバランスの取れた分割が必要であると仮定することです。 たとえば、誤って係数を均等に分割したり次数を分配しようとしたりする可能性がありますが、この問題ではそのような制約は必要ありません。 

簡単なケースでこれを説明します。 

入力:```
2
6 5 1
```多項式は$c(x) = 6 + 5x + x^2$。 魅力的だが不要なアイデアは、次のことを検索することです。$(x+2)(x+3)$, しかし、それは必須ではありません。 有効な因数分解は機能します。 

正しい出力は次のようになります。```
2
6 5 1
0
1
```定数多項式を掛けるので、$1$すべてを保存します。 

## アプローチ

 単純な解釈では、畳み込みが指定された多項式と等しい 2 つの多項式を回復しなければならないということになります。 これを直接試みると、係数を求めることになります。$a_i, b_j$次のような:$$c_k = \sum_{i+j=k} a_i b_j$$これは非線形方程式系です。 中程度の場合でも$l$、各係数が多くのペアにわたる依存関係を導入するため、そのようなシステムを推測または解決しようとすると、組み合わせ論的に爆発することになります。 

より構造化された試みには、学位の修正が含まれる可能性があります$n$そして$m$、次に係数を繰り返し再構築しようとします。 ただし、各ステップは以前に選択された値に依存するため、すぐに不定になります。 有効な分解は無数にあり、原理的な方法で分解を探す必要はありません。 

単純化の鍵となるのは、問題には非自明な因数分解が必要ないことを認識することです。 有効なペアを自由に選択できます。 これは、定数多項式が 1 つの要素であることを即座に示唆します。 設定すると$b(x) = 1$、 それから：$$a(x) \cdot 1 = a(x)$$それで選択する$a(x) = c(x)$要件を正確に満たしています。 

これにより、タスク全体が入力多項式を 1 つの出力多項式にコピーし、定数多項式を出力するだけになります。$1$2番目として。

 ## アルゴリズムのチュートリアル

 畳み込みや代数的解決を実行せずに、有効な分解を直接構築します。 

## アルゴリズムのチュートリアル

 1. 学位を読む$l$との係数$c(x)$。 これらの係数は、次の係数として直接再利用されます。$a(x)$。 これは、乗法恒等多項式を使用する予定であるため機能します。$b(x)$。 
2.セット$a(x) = c(x)$。 係数を変更すると、補正調整が必要になるため、係数は変更しません。$b(x)$、これは不必要な複雑さです。 
3. 構築する$b(x) = 1$これは、1 に等しい単一の係数を持つ次数 0 の多項式です。これが選択されるのは、これが多項式乗算における乗法恒等式であるためです。 
4. の次数と係数を出力します。$a(x)$。 
5. 次数 0 を出力します。$b(x)$、その後に係数 1 が続きます。 

### なぜ効果があるのか

 定数多項式による多項式乗算$1$すべての係数を変更しないままにします。 との畳み込み以来$[1]$項を混合したりシフトしたりしないため、結果として得られる多項式は元の多項式とまったく同じになります。 これにより、構築されたペアが常に次を満たすことが保証されます。$a(x) \cdot b(x) = c(x)$、入力係数に関係なく。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    l = int(input().strip())
    c = list(map(int, input().split()))
    
    # a(x) = c(x)
    print(l)
    print(*c)
    
    # b(x) = 1
    print(0)
    print(1)

if __name__ == "__main__":
    main()
```コードの最初の部分は、多項式を直接読み取り、それを変更せずに次のように出力します。$a(x)$。 2 番目の部分では恒等多項式を構築します。$b(x)$。 入出力処理以外の計算は必要ないため、このソリューションは制約内に快適に適合します。 

微妙な点は、度の書式設定が定義と一致していることを確認することです。$l$に対応する$l+1$次数 0 は単一の係数に対応します。 これを混同することは、最も一般的な実装エラーです。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    l = int(input().strip())
    c = list(map(int, input().split()))

    out = []
    out.append(str(l))
    out.append(" ".join(map(str, c)))
    out.append("0")
    out.append("1")
    return "\n".join(out)

# provided sample
assert run("2\n6 5 1\n") == "2\n6 5 1\n0\n1"

# single constant polynomial
assert run("0\n7\n") == "0\n7\n0\n1"

# negative coefficients
assert run("1\n-3 4\n") == "1\n-3 4\n0\n1"

# larger case
assert run("3\n1 2 3 4\n") == "3\n1 2 3 4\n0\n1"
```| テスト入力 | 期待される出力 | 検証内容 |

 ## 特殊なケース

 定数多項式の場合$l = 0$構造的に異なる唯一の入力です。 入力の場合:```
0
5
```アルゴリズムセット$a(x) = [5]$そして$b(x) = [1]$。 定数と 1 の畳み込みは同じ定数のままであるため、出力は特別な分岐を必要とせずに有効です。 

係数値がどれほど大きくても不規則であっても、恒等多項式は値をコピーする以外の算術に依存することなく正確さを保証します。
