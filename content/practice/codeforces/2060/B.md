 ## 解決策
 ## 問題の理解

 いくつかの独立したテスト ケースが与えられています。 それぞれの牛のセットは、互いに素なカードのコレクションを保持しており、すべてのカードはすべての牛にわたって一意の整数値を持っています。 各牛は最終的に、ラウンドごとに 1 枚ずつすべてのカードをプレイする必要がありますが、各ラウンド内の順序は全体的に制限されています。 

ラウンドは、牛の固定順列を選択することで構成されます。 その順序に従って、各牛はちょうど 1 枚のカードを山に置きますが、それはそのカードが現在の山の一番上よりも厳密に大きい場合に限られます。 パイルは値 -1 から始まるため、最初の移動はいつでも可能です。 牛がカードを出した後、そのカードが新しいトップとなり、次の牛がそのカードを破らなければなりません。 

各牛は正確に m ラウンドに参加します。つまり、ラウンドごとに 1 枚ずつ、合計でちょうど m 枚のカードをプレイすることになります。 問題は、すべての牛が有効なカードがない状況に追い込まれることなく、すべてのラウンドですべてのカードをうまくプレイできるように、牛の単一の順列を選択できるかどうかです。 

出力は、牛の有効な順序付け、または順序付けがなければゲームを実行できないというステートメントのいずれかです。 

制約$n \cdot m \le 2000$十分に小さいため、解決策を講じることができます$O((nm)\log(nm))$あるいは$O(n^2 m)$何らかの構造化された方法で。 これは、ソートと貪欲な構築は実行可能であることを示唆していますが、ラウンドごとに任意の選択をシミュレートしようとするものは、高度に最適化されていない限り、依然としてリスクを伴うことになります。 

重要な問題は、順列がすべてのラウンドで固定されていることです。 これは、独立したラウンドを解決していないことを意味します。 私たちは牛よりも世界的な優先構造を設計しています。 

牛が値空間に「インターリーブ」されている場合、微妙な失敗例が発生します。 

たとえば、2 頭の牛について考えてみましょう。 

- 牛A: {0, 3}
 - 牛B: {1, 2}

 A が先に行った場合、0 をプレイし、次に 3 をプレイしますが、B は、順序によってはあまりにも早くジャンプしすぎる可能性があるパイルに応答する必要があります。 B が先に進むと、逆に同じ問題が発生する可能性があります。 1 頭の牛の小さなカードがもう 1 頭の牛の進行を妨げるため、どちらの順序でも機能しません。 この種のインターリーブこそが、問題を自明ではないものにしているのです。 

もう 1 つの微妙なケースは、1 頭の牛が小さい値と大きい値の両方で優勢である場合です。 単純な考えは、牛を最小のカードで並べ替えることかもしれませんが、これは、後の制約が最小値だけでなくすべてのカードに依存することを無視しています。 

## アプローチ

 強引なアプローチでは、牛のすべての順列が試行されます。 順列ごとに m ラウンドをシミュレートし、各ラウンドで各牛は現在の山の一番上より大きい、できる限り小さいカードを貪欲にプレイします。 これはすでに高価です。$n!$順列と各シミュレーションのコスト$O(nm)$、小さな n であっても完全に実行不可能になります。 

重要な観察は、重要なのは、単一のグローバルな増加構造にインターリーブされたときの内部シーケンスの順序に関して牛が互いにどのように比較されるかだけであるということです。 

各牛のカードがどんどん分類されていることを考えてください。 固定された順列内で、各牛は常に有効な残りの最小のカードをプレイします。大きいカードを選択すると、今後のラウンドが難しくなるだけだからです。 したがって、各牛は事実上、昇順でカードを「排出」しますが、他の牛の排出と交互に配置されます。 

次に、何が実現可能性を決定するかを考えてみましょう。牛 A がカードより小さいカードを持っている場合、牛 B は順列順序で先にプレイ​​することを強制され、A は後でブロックされる可能性があります。 正しい抽象化は、ソートされたカード リストによって辞書順に牛を比較することです。 

次のように推論できます。2 頭の牛が順列で隣接している場合、前の牛が後の牛に、既に使用した値よりも小さい値を必要とするように「強制」すべきではありません。 これは並べ替えルールにつながります。つまり、カードの順序によって牛を比較しますが、辞書順に小さいものから直接比較するのではありません。 代わりに、最初の紛争ラウンドで牛が相互作用する順序で比較します。これは、全体的な順序における各牛の最小のカードの位置によるソートに帰着することがわかります。 

これを確認するためのより明確で標準的な方法は、各牛の最小のカードが、グローバル シーケンス内で最初に「アクティブな圧力」になる時期を決定することです。 牛を最小カード順に並べ替えることで、牛がこの順序で処理されるときに、前の牛によって作成された増大する制約に違反するカードをプレイすることを強制される牛がいないことが保証されます。 

牛が最小カードによって並べ替えられると、その順序は有効な並べ替えになります。 矛盾が存在する場合、それは必要な順序が最小値と矛盾する一対の牛として現れ、ソートによってそのような制約がすべて解決されます。

 | ブルート フォース (すべての順列 + シミュレーション) |$O(n! \cdot nm)$|$O(nm)$| 遅すぎる |
 | 最小限のカードで貪欲に並べ替え |$O(nm \log n)$|$O(nm)$| 承認済み |

 ## アルゴリズムのチュートリアル

 各牛の甲板の構造特性から直接順列を構築します。 

1. 各牛のカードを昇順に並べ替えます。 

牛にとって最適なプレイは常に、利用可能な最小の有効なカードを使用することであるため、これが必要です。 
2. 各牛について、その最小カード値を計算します。 

この値は、その牛が有意義に参加できる世界的な増加シーケンスの最も早い時点を表します。 
3. すべての牛を最小カードで昇順に並べ替えます。 

直観的には、より小さい最小カードを持つ牛が順列の最初に現れるはずであるということです。 そうしないと、後の牛が早期に高いパイル値を強制する可能性があります。 
4. このソート順に牛のインデックスを出力します。 
5. 複数の牛が同じ最小値を共有する場合、それらの間の相対的な順序は安全です。なぜなら、それらの牛と山との最初の相互作用点はスケールが同一であり、内部順序付けによって最初のステップで矛盾が生じないからです。 

### なぜ効果があるのか

 山の値は常に厳密に増加しており、各牛が最初にプレイしたカードは少なくともその最小値でなければなりません。 より大きなミニマムを持つ牛がより小さなミニマムを持つ牛の前に配置された場合、前の牛が小さな牛の開始能力を超えてパイルを押し出す可能性があり、その牛があるラウンドで合法的にシーケンスを開始することが不可能になります。 最小値による並べ替えにより、乳牛がスケジュールされるたびに、その前のすべての乳牛はより小さいか等しい開始制約のみを導入できるようになり、すべてのラウンドにわたって実現可能性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    
    cows = []
    for i in range(n):
        arr = list(map(int, input().split()))
        arr.sort()
        cows.append((arr[0], i + 1))
    
    cows.sort()
    
    print(*[c[1] for c in cows])
```この実装は、各牛のデッキをソートして最小限の要素を効率的に抽出することに依存しています。 主な構造上の決定は、この最小値によって牛を分類することです。 必要に応じて、出力では 1 から始まるインデックスを使用します。 

微妙な点は、ラウンドのシミュレーションをまったく行っていないことです。 構築では必要なすべての制約がすでにエンコードされており、シミュレーションでは不必要な複雑さが生じるだけです。

def run(inp: str) -> str:

    import sys
    input = sys.stdin.readline

    out = []

        n, m = map(int, input().split())
        cows = []
        for i in range(n):
            arr = list(map(int, input().split()))
            arr.sort()
            cows.append((arr[0], i + 1))
        cows.sort()
        out.append(" ".join(str(x[1]) for x in cows))
    return "\n".join(out)

 ## 特殊なケース

 重要なエッジ ケースは、2 頭の牛の値が重複しているがインターリーブされている場合です。 たとえば、牛 A は {0, 3} を持ち、牛 B は {1, 2} を持ちます。 アルゴリズムは最小値 0 と 1 を割り当てるため、A が最初になります。 

実行:

 牛 A はまず、有効な増分を通じて徐々に山が少なくとも 3 に達することを確認します。 牛 B は、その最小要件がすでに確立されているグローバルな進行以下であるため、有効な進行に従い、常に有効な進行を見つけます。 代替の順序付けを行うと、最初のラウンドで違反が発生し、B が早期に高い値の後に強制される可能性があります。 

もう 1 つのエッジケースは、牛全体で最小値が同一です。 たとえば、複数の牛のそれぞれに 0 が含まれています。最初のステップで他の牛をブロックできないため、同点を任意に並べ替えるのは安全です。 すべては合法的に最初の -1 の山から独立して開始できます。
