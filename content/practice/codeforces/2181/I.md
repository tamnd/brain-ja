 ## 解決策
 ## 問題の理解

 デカルト平面上に 2 つの点セットがあります。谷に点在するポンプと、周囲の丘に配置された貯水池です。 各協同組合は、2 つのポイントを直線パイプで接続したいと考えています。目標は、これら 2 つのパイプ (1 つは 2 つのポンプを接続し、もう 1 つは 2 つの貯水池を接続) が交差することが可能かどうかを確認することです。 交差には、接触または重なり合うセグメントが含まれます。 

入力では複数の計画シナリオを指定します。 各シナリオでは、ポンプの数とその座標が提供され、その後に貯水池の数とその座標が続きます。 各シナリオの出力は、有効な交差するパイプのペアを表す 4 つのインデックス、またはそのような構成が存在しない場合は -1 です。 

主な制約は、シナリオごとのポンプと貯水池の数、およびシナリオの数です。 すべてのシナリオの合計ポイント数は次のように制限されているため、$2 \cdot 10^5$ポンプとリザーバーの両方について、リザーバーのすべてのペアに対してポンプのすべてのペアをチェックする単純なソリューションには、大まかに次の作業が含まれる可能性があります。$O(n^2 m^2)$最悪の場合の操作は完全に不可能です。 したがって、考えられるすべてのペアを列挙することを回避するアルゴリズムが必要です。 

エッジケースには、すべてのポンプまたはすべてのリザーバーが同一線上にある状況が含まれます。 たとえば、すべてのポンプが水平​​線上にあり、すべてのリザーバーがそれに平行な線上にある場合、交差することはできません。 最初の 2 つのポンプと最初の 2 つのリザーバーを、それらの相対位置を確認せずに選択する不注意なアプローチでは、誤った交差が報告される可能性があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。 各シナリオでは、ポンプのすべてのペアを反復し、次にリザーバのすべてのペアを反復して、2 つの線分が交差するかどうかを確認できます。 これにより正確性が保証されますが、時間計算量は次のようになります。$O(n^2 m^2)$シナリオごとに、これは実行不可能です$n, m \le 10^5$そして$t \le 10^5$。 

より高速なソリューションを実現する重要な観察は、同一直線上にないポンプのセットやリザーバーの非同一直線上にあるセットでは、接続セグメントが交差する 2 つのポンプと 2 つのリザーバーの選択肢が常に存在するということです。 これは、左端と右端のポンプ、および左端と右端のリザーバーを選択すると、4 つの接続セグメントのペアのいずれかが交差するか、セットが完全に分離され、その場合はすべての点が共通の軸に沿って同一線上にあるという幾何学的事実から来ています。 これにより、問題は単純な交差のチェックに集約されます。x 軸 (x が等しい場合は y 軸) に沿って各セットの極値点を選択し、1 つの交差テストを試みます。 

これは、すべてのペアをチェックする必要がないことを意味します。 各シナリオでは、ポンプとリザーバを x 座標で並べ替えて各セットの 2 つの極値点を見つけ、並べ替えられた各リストの最初と最後の点を選択します。 これら 4 つの点が交差するセグメントを形成する場合、有効な構成が得られます。 ポンプまたはリザーバーのセットが厳密に垂直 (すべての X 座標が等しい) または水平 (すべての Y 座標が等しい) である場合、他のセットが厳密に平行でなく分離されている場合にのみ交差が可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2m^2) | O(n + m) | 遅すぎる |
 | 極値点 | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. シナリオごとに、ポンプと貯水池の座標を読み取ります。 
2. X 座標を比較して、左端と右端のポンプを特定します。 同点の場合は、左端の y が最小で、右端の y が最大のポンプを選択します。 
3. 同様に、y 座標で区切られたタイを含む x 座標によって左端と右端のリザーバーを識別します。 
4. 左端のポンプを右端のポンプに接続し、左端のリザーバを右端のリザーバに接続してみます。 これらのセグメントが交差する場合は、それらのインデックスを出力します。 
5. 交差しない場合は、リザーバーのインデックスの 1 つを逆にして (左端のポンプを右端のポンプに、右端のリザーバーを左端のリザーバーに接続)、再度確認します。 
6. いずれかの構成で交差が見つかった場合は、対応するインデックスを報告します。 それ以外の場合は、-1 を出力します。 

機能する理由: 極値点を選択することで、交差が可能であれば、最も外側の点の間で交差が発生することが保証されます。 これは、軸に沿って厳密に分離されていないポンプのペアとリザーバのペアが、これらの極端な組み合わせのいずれかで交差するため機能します。 このアルゴリズムは、問題を組み合わせ列挙から少数の一定数の交差テストに削減します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def ccw(a, b, c):
    return (b[0]-a[0])*(c[1]-a[1]) - (b[1]-a[1])*(c[0]-a[0])

def intersect(p1, p2, q1, q2):
    d1 = ccw(p1, p2, q1)
    d2 = ccw(p1, p2, q2)
    d3 = ccw(q1, q2, p1)
    d4 = ccw(q1, q2, p2)
    if d1*d2 < 0 and d3*d4 < 0:
        return True
    if d1 == 0 and on_segment(p1, p2, q1):
        return True
    if d2 == 0 and on_segment(p1, p2, q2):
        return True
    if d3 == 0 and on_segment(q1, q2, p1):
        return True
    if d4 == 0 and on_segment(q1, q2, p2):
        return True
    return False

def on_segment(a, b, c):
    return min(a[0], b[0]) <= c[0] <= max(a[0], b[0]) and min(a[1], b[1]) <= c[1] <= max(a[1], b[1])

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        pumps = [tuple(map(int, input().split())) + (i+1,) for i in range(n)]
        m = int(input())
        reservoirs = [tuple(map(int, input().split())) + (i+1,) for i in range(m)]
        pumps.sort()
        reservoirs.sort()
        p1, p2 = pumps[0], pumps[-1]
        r1, r2 = reservoirs[0], reservoirs[-1]
        if intersect(p1, p2, r1, r2):
            print(p1[2], p2[2], r1[2], r2[2])
        elif intersect(p1, p2, r2, r1):
            print(p1[2], p2[2], r2[2], r1[2])
        else:
            print(-1)

if __name__ == "__main__":
    solve()
```このソリューションはすべてのポイントを読み取り、出力用にインデックスを追加し、各セットを x 座標で並べ替えます。 の`intersect`関数はすべての一般的な共線的なケースを処理しますが、`on_segment`接触または重なり合うセグメントを適切に検出します。 極値点により、交差点が存在する場合、これらの組み合わせで交差点が検出されることが保証されます。
