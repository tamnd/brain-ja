 ## 解決策
 ## 問題の理解

 各ラウンドでは、サイクル上のすべての位置で整数が選択されます。 数値が選択された後、サイクル上の隣接する各ペアを調べ、左のエンドポイントが右のエンドポイントよりも厳密に大きい場合は常に、両方のエンドポイントに 1 ポイントを与えます。 複数のラウンドにわたって、連続する頂点間のすべてのエッジが一定回数寄与し、そのような寄与ごとに 2 つのエンドポイントのスコアが増加します。 

最終データからは、各頂点で蓄積された合計スコアのみが得られます。 タスクは、正確にこれらの合計を生成する一連の有効なラウンドが存在するように、必要な最小ラウンド数を再構成することです。 

制約により強制的に$O(n)$または$O(n \log n)$テストケースごとのソリューション。 の合計$n$テスト全体にわたって$5 \cdot 10^5$, したがって、単一のテストで二次関数となる解は直ちに不可能になります。 平$O(n \log n)$非常にきれいな場合にのみ許容されます。 意図したソリューションはテスト ケースごとに線形です。 

単純なアプローチでは、ラウンドをシミュレートするか、貪欲にラウンドを構築しようとします。 有効なラウンドの空間は指数関数的であるため、これはすぐに失敗します。各ラウンドは値の順列の選択に対応し、したがってサイクル上で一貫した方向パターンを暗黙的に選択することになります。 明示的にラウンドを構築したり、エッジごとにラウンドを貪欲に割り当てたりしようとすると、グローバルな整合性チェックを行わずにカウントしすぎたり、実現可能性に違反したりすることになります。 

各エッジを個別に処理しようとすると、2 番目の微妙な落とし穴が発生します。 たとえば、4 サイクルで、あたかも各エッジをラウンドごとに任意にスケジュールできるかのように、寄与を独立して割り当てようとすると、すべてのエッジが同じラウンドで寄与を必要とする構成が生成される可能性があります。 そうなると、すべての比較がサイクル全体で厳密に下降することになりますが、これは不可能です。 

中心的な問題は、エッジが独立していないことです。すべてのラウンドはグローバルに一貫した順序付けに対応しており、そのラウンドですべてのエッジを同時に選択することは禁止されています。 

## アプローチ

 ブルートフォースビューは、「左が右より大きい」が成立するサイクルエッジのサブセットを選択するものとして各ラウンドを想像し、必要な各エッジ寄与をあるラウンドに割り当てることです。 ラウンドを 1 つずつ構築しようとすると、サイクルの有効な方向を繰り返し選択し、寄与分を差し引くことになります。 これは正しいですが、実現不可能です。考えられる方向の数は指数関数的であり、残りの需要をそれらの方向に分散する方法の決定は組み合わせによるものになるからです。 

重要な構造観察は、まずラウンドの観点から考えるのをやめ、代わりに各エッジが何回使用されるかを数えることです。 させて$c_i$エッジがどのラウンド数になるか$i \to i+1$得点に貢献する。 次に、各頂点スコアは次のようにきれいに分解されます。$$a_i = c_{i-1} + c_i.$$これにより、問題は非負の整数の割り当てを見つけることに変換されます。$c_i$サイクル上の線形システムを満たすエッジ上。 

一度そのようなシーケンスが$c$が修正された場合、ラウンドを各エッジの寄与をタイムスロットに分配するものとして再解釈します。 各ラウンドはエッジ上の 0/1 パターンの選択に対応します。1 はそのラウンドでエッジが使用されることを意味します。 唯一の制限は、有効なラウンドでは、すべてのエッジを同時に 1 に設定できないことです。これは、厳密な不等式のサイクルを意味するためです。 

したがって、問題は次のようになります: それぞれを分割する$c_i$の中へ$R$各層に少なくとも 1 つのゼロがあるようにします。 これは、各ラウンドで最大で次の値を使用すると言っているのと同じです。$n-1$エッジ、グローバル制約を与える$$\sum c_i \le R(n-1).$$固定された実行可能なものに対して$c$、必要な最小ラウンド数は$$R = \max\left(\max_i c_i,\ \left\lceil \frac{\sum c_i}{n-1} \right\rceil \right).$$残りの課題は、どれがどれかを理解することです。$c$割り当てが可能です。 から$a_i = c_{i-1} + c_i$、すべてを表現できます$c_i$単一の変数に関して言えば、$c_1 = x$。 これにより、すべての制約が線形になり、実行可能な間隔が与えられます。$x$。 両方なので$\max c_i$そして$\sum c_i$は区分的に線形です$x$、最適値は、この区間の境界点、または 1 つの制約が厳しくなる点で発生します。

 ## アルゴリズムのチュートリアル

 まず、頂点スコアをエッジ寄与に変換します。 

1.修正$c_1 = x$。 この 1 つの値が他のすべての値を決定します$c_i$再発を通じて$c_i = a_i - c_{i-1}$。 再発では兆候が交互に現れるため、それぞれ$c_i$の一次関数になります$x$。 
2. すべてを計算する$c_i$象徴的に$c_i = s_i \cdot x + b_i$、 どこ$s_i \in \{+1,-1\}$。 この分離により、システム内の唯一の自由度が分離されます。 
3. 実現可能性を徹底する$c_i \ge 0$みんなのために$i$。 各不等式は下限または上限のいずれかになります。$x$、単一の間隔を生成します$[L, R]$。 この間隔には、スコアのエッジ寄与への有効な分解がすべて含まれます。 
4. 有効な$x$、計算する$\max c_i$そして$\sum c_i$。 これらは区間にわたる線形または区分的線形関数であるため、連続的に評価するのではなく重要な点でのみ評価する必要があります。 
5. 各候補者に必要なラウンド数を計算します。$x$使用:$$R(x) = \max\left(\max_i c_i(x),\ \left\lceil \frac{\sum c_i(x)}{n-1} \right\rceil \right).$$6. 評価する$R(x)$実行可能な間隔のすべてのエンドポイントと、最大値が得られる追加ポイントで$c_i$優位性が変わります。 これらの候補の最小値が答えになります。 

### なぜ効果があるのか

 エッジ変数への変換により、頂点制約の循環依存性が除去され、解の 1 次元空間が明らかになります。 すべての有効な構造は、この区間内の 1 つの点に正確に対応します。 各ラウンドが最大で貢献できるため、ラウンドの丸め条件は厳しいです$n-1$その境界を達成するスケジュールは、各層を少なくとも 1 つの欠落エッジを持つ有効な巡回置換方向として構築することによって達成できます。 これにより、境界が必要かつ十分になるため、実行可能な範囲を最小限に抑えることができます。$c$元の問題を完全に解決します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(n, a):
    if n == 2:
        # a1 = c1 + c2, a2 = c1 + c2 => all equal, c1=c2=a1/2
        # each round uses at most 1 edge, so answer is c1+c2 = a1
        return a[0]

    # Build alternating representation:
    # c1 = x
    # c2 = a2 - x
    # c3 = a3 - a2 + x
    # c4 = a4 - a3 + a2 - x ...
    s = [0] * n
    b = [0] * n

    s[0] = 1
    b[0] = 0
    s[1] = -1
    b[1] = a[1]

    for i in range(2, n):
        s[i] = -s[i-1]
        b[i] = a[i] - b[i-1]

    # feasibility bounds for x
    L = -10**30
    R = 10**30

    for i in range(n):
        if s[i] == 1:
            L = max(L, -b[i])
        else:
            R = min(R, b[i])

    # candidate x values: endpoints
    candidates = [L, R]

    def evaluate(x):
        mx = 0
        total = 0
        for i in range(n):
            ci = s[i] * x + b[i]
            if ci < 0:
                return None
            mx = max(mx, ci)
            total += ci
        r1 = mx
        r2 = (total + n - 2) // (n - 1)
        return max(r1, r2)

    ans = 10**30
    for x in candidates:
        val = evaluate(x)
        if val is not None:
            ans = min(ans, val)

    return ans

def main():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        out.append(str(solve_case(n, a)))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```この解決策は、単一の自由パラメータに固定された線形反復としてエッジ寄与をエンコードすることから始まります。 これにより、サイクル依存性が除去され、検索スペースが有効な値の間隔に縮小されます。 そのパラメーターの実現可能性は、非負性から導出される線形境界を通じてチェックされます。 

有効なエッジ分解が固定されると、2 つの独立した制約を使用してラウンド数が計算されます。つまり、任意のエッジの最大負荷と、各ラウンドが最大で保持できるグローバル容量制約です。$n-1$エッジ。 

微妙な点は、実行可能な間隔の端点のみをチェックする必要があることです。 区間内では、最大エッジ負荷と合計合計は両方とも線形または区分的に線形に動作し、それらの組み合わせでは境界よりも厳密に優れた値を生成することはできません。 

## 実用的な例

 小さなサイクルを考えてみましょう。$n = 4$スコアは次のとおりです。 

| 私 | a[i] |
 | --- | --- |
 | 1 | 1 |
 | 2 | 2 |
 | 3 | 4 |
 | 4 | 3 |

 エッジ変数を次のように計算します。$x = c_1$。 

| 私 | c[i] 式 |
 | --- | --- |
 | 1 | × |
 | 2 | 2 - × |
 | 3 | 4 - 2 + x = x + 2 |
 | 4 | 3 - 4 + 2 - x = 1 - x |

 実現可能性には、すべての式が非負であることが必要です。$x \in [0,1]$。 

エンドポイントの評価:

 で$x = 0$:$c = [0,2,2,1]$、合計 = 5、最大 = 2、丸め = max(2, ceil(5/3)) = 2。 

で$x = 1$:$c = [1,1,3,0]$、合計 = 5、最大 = 3、丸め = 3。 

したがって、答えは 2 で、下限のエンドポイントで達成されます。 これは、最大エッジ負荷を最小限に抑えることが総和制約のバランスよりも優先される可能性があることを示しています。

 ## 特殊なケース

 いつ$n = 2$、サイクルはラウンドごとに 2 回使用される単一のエッジに縮退します。 再帰性は崩壊し、解決策は両方の頂点を同じエッジ数として直接解釈することになるため、答えは共有値をエッジ寄与構造で適切に除算したものに等しくなります。 

いつすべて$a_i$が等しい場合、交互の反復により、単一の実現可能な構成を中心とする対称的な間隔が生成されます。 不均衡があると、最大エッジ負荷または合計要件のいずれかが増加するため、最適値は完全にバランスの取れた割り当てになります。 

値が急激に切り替わる場合、実現可能範囲は狭くなり、非負性を強制した後も 1 つのエンドポイントのみが有効になります。 これは、境界評価が十分である理由を直接示しています。内部点がローカル エッジ制約に違反しているか、ボトルネック エッジの負荷が増加していることがわかります。
