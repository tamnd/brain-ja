 ## 解決策
 ## 問題の理解

 1 から非常に大きな番号までのフロア番号が付けられた超高層ビルがあり、数人の人々が異なるフロアでエレベーターを待っています。 各人には明確な開始フロアと明確な目的地のフロアがあり、2 つのフロアが重なることはありません。 エレベーターは1階から始まります。 現在のフロアから、待っている人の開始フロア、またはすでに入っている人の目的のフロアに直接移動できます。 乗降は瞬時に行われ、エレベーターは全員を一度に運ぶことができます。 

目標は、1 階から最後の人が目的地に到着するまでの総移動時間を最大化するようにエレベーターのルートを計画することです。 各移動には、現在のフロアと次のフロア間の絶対差に等しい時間が消費され、中間のフロアは無視されます。 

制約を考慮すると、`n`まで可能です`10^5`テストケースごと、およびすべての合計`n`テストケース全体で次を超えない`10^5`。 これにより、可能な順序の数が階乗的に増加するため、フロア シーケンスの素朴な総当りの並べ替えが即座に排除されます。`n`。 各テスト ケースには、最大でも線形または線形時間の解が必要です。 

エッジケースは微妙です。 そのようなケースの 1 つは、ユーザーの開始フロアが他のすべてのフロアよりもはるかに高い場合です。 「最も近いフロアを優先」に基づいて単純に貪欲に選択すると、最初のステップが最小限に抑えられ、意図せず合計時間が短縮される可能性があります。 同様に、出発階と目的地の階が離れている人が合計時間の大部分を占めるため、間の範囲は無視されます。`s_i`そして`f_i`最大値を過小評価する可能性があります。 

たとえば、次の入力を使用します。```
1
2
2 100
3 5
```素朴な最近接優先はうまくいくかもしれません`1->2->3->5->100`時間は 2+1+2+95=100 ですが、よりスマートなシーケンスです`1->3->5->2->100`2+2+3+98=105 となります。 時間を最大化するには、ロングジャンプを活用するかどうかにかかっています。 

## アプローチ

 強引なアプローチでは、出発階と目的地の訪問のすべての順列を試し、合計距離を計算します。 これが機能するのは、乗車と降車のルールを尊重する経路はすべて有効であり、合計時間は絶対的な差の合計にすぎないためです。 ただし、`n`まで`10^5`、 がある`(2n)!`シーケンスは計算上不可能です。 最も近い未訪問フロアの貪欲な戦略を使用してすべてのシーケンスを評価する場合でも、合計時間を増加させる長いジャンプを見逃す可能性があるため、最適とは言えません。 

重要な観察は、各人が総距離に一定の「スパン」を寄与しているということです。つまり、開始階からの移動です。`s_i`彼らの目的地へ`f_i`避けられない。 エレベーターの総移動量を最大化するには、これらのスパンをインターリーブして、できるだけ多くの大きなジャンプを作成する必要があります。 最大値で人々を並べ替える`s_i`そして`f_i`降順にすると、エレベーターが最初に最大のジャンプを行うようになります。 もう一つの同等の視点は、間隔を考慮することです。`[min(s_i,f_i), max(s_i,f_i)]`最も遠いエンドポイントから順に注文するため、エレベーターは早めに長距離を移動する必要があり、合計時間が最大になります。 

分類したら、エレベーターをシミュレートします。各ステップで、現在の位置 (待っている人の出発地点または乗客の目的地のいずれか) から最も遠い未訪問の階に移動します。 この貪欲な順序付けが機能するのは、最適解が常に最大のジャンプを最初に使用するためです。 早い段階で小さなジャンプをすると、後で達成できる総距離が短くなります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべての順列) | O((2n)!) | O(2n) | 遅すぎる |
 | 貪欲な間隔での注文 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テストケースの人数を読み取ります。`n`およびその出発階と目的地の階。 
2. 人ごとにタプルを定義します`(min(s_i, f_i), max(s_i, f_i))`。 これはそれらが占める間隔を表します。 
3. すべての間隔を最大エンドポイントで降順に並べ替えます。 最大値で並べ替えると、大きなジャンプが最初に考慮されるようになります。 
4. エレベーターを 1 階で初期化し、total_time を 0 に設定します。 
5. ソートされた間隔を繰り返します。 インターバルごとに、エレベーターがインターバルの最小値よりも低い場合はインターバルの開始位置に移動し、それ以外の場合は最も遠い端に直接移動します。 インクリメント`total_time`移動した距離によって。 
6. 開始したら、常に間隔のもう一方の端に移動します (`s_i`に`f_i`またはその逆)、絶対差を次のように加算します。`total_time`。 
7. 全員が配達されるまで続行します。 
8. 出力`total_time`。 

なぜ効果があるのか​​: すべての人のスパン`[s_i,f_i]`少なくとも貢献する`abs(s_i - f_i)`合計時間に。 最遠端でソートすると、エレベーターが早期に最大限のロングジャンプを確実に行うことができ、他のシーケンスではこれを延長することはできません。 搭乗制限に違反することなく、小さなジャンプを後で大きなジャンプに置き換えることはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        intervals = []
        for _ in range(n):
            s, f = map(int, input().split())
            intervals.append((min(s,f), max(s,f)))
        
        intervals.sort(key=lambda x: x[1], reverse=True)
        cur = 1
        total_time = 0
        for l, r in intervals:
            if cur <= l:
                total_time += r - cur
                cur = r
            elif cur >= r:
                total_time += cur - l
                cur = l
            else:
                # cur is between l and r
                total_time += max(r - cur, cur - l)
                cur = r if r - cur >= cur - l else l
        print(total_time)

if __name__ == "__main__":
    solve()
```各セクションはアルゴリズムのステップに対応します。 最大エンドポイントで間隔を並べ替えると、常に最長の潜在的なジャンプが最初に考慮されることが保証されます。 現在のエレベーター位置が 〜 の間の場合`l`そして`r`、最も遠いエンドポイントに移動すると、累積時間が最大になります。 エッジケースなど`cur < l`または`cur > r`単純な算術によって直接処理されます。
