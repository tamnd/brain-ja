 ## 解決策
 ## 問題の理解

 出入り口の各層は、2 つの固定壁の間の 1 次元セグメントです。 そのセグメント内には、いくつかの硬いドア ブロックが一列に配置されていますが、各ブロックは、他のブロックと重なったり壁を横切ったりしない限り、左右にスライドできます。 すべてのレイヤーは独立して動作しますが、最終的な開口部はすべてのレイヤーに同時に存在する必要があります。 

水平線上の位置は、各層でその位置がドアで覆われていない場合にのみ使用できます。 壁はまた、その間隔の外にあるものをすべてブロックします。 タスクは、各レイヤーのドアが最適に再配置された後、すべてのレイヤーで空いている位置の合計の長さを最大化することです。 

問題を再解釈するのに役立つ方法は、各レイヤーがセグメント内に可動障害物のセットを生成し、それらの自由空間の交差ができるだけ大きくなるようにすべての障害物システムの配置を選択することです。 

制約は大きく、レイヤー数は最大 100,000、ドアの総数は最大 300,000 です。 これにより、配置をシミュレートしたり、位置ごとに明示的にオーバーラップをチェックしたりするソリューションは即座に除外されます。 レイヤーやドアの数が 2 次であることは不可能であり、座標が 10^9 に達するため、密な座標圧縮による線形スキャンでさえも失敗します。 

微妙な点は、レイヤー内のドアの順序が固定されているため、並べ替えることができないことです。 ただ滑るだけです。 これにより、厳格な構造が維持されます。つまり、ドア間の隙間は再分配のみ可能であり、その合計は変更されません。 

いくつかの特殊なケースでその難しさを明らかにします。 

ドアのない単一の層がある場合、セグメント全体が開いているため、答えは単純に壁のスパンになります。 まだ「ギャップの最適化」を試みる単純なアルゴリズムでは、誤って人為的な制約が導入され、ゼロが返される可能性があります。 

すべてのレイヤーに、わずかな隙間を除いて全スパンを占める 1 つのドアがある場合、各レイヤーはそのドアをどこにでも移動できますが、すべての配置の交差部分には依然として重要な開口部が残る可能性があります。 単純な位置によるオーバーラップのシミュレーションでは、固定間隔ではなく移動性が重要であるということを見落としてしまいます。 

もう 1 つの注意が必要なケースは、ドアの長さが極端に不均一である場合です。 レイヤー間でドアを貪欲に位置合わせする貪欲な配置は失敗する可能性があります。これは、最適性が個別の位置合わせではなく、全体的なスラック分布にのみ依存するためです。 

## アプローチ

 レイヤー間の相互作用を無視した場合、総当たりアプローチでは、各レイヤーのドアの可能な配置をすべて試し、各構成のブロックされた間隔の和集合を生成し、レイヤー間の空きスペースの交差を計算することになります。 各ドアは制約を尊重しながら連続的に移動できるため、単一のレイヤーであっても有効な配置が指数関数的に多くなります。 これにより、列挙が不可能になります。 

位置を離散化したとしても、各層について、ドアと壁の間の隙間に全体のたるみを分配するためのあらゆる方法を考慮する必要があります。 このような分布の数は、ドアの数と組み合わせて増加します。 

重要な構造上の観察は、単一の層内では、ドアが全長が固定された剛体セグメントのように機能し、ドアと壁の間の隙間のみが変更できるということです。 したがって、各層は内部ギャップごとにちょうど 1 つの自由度に寄与します。つまり、層内の総自由空間は固定されていますが、その分布は移動可能です。 

世界的な問題は、すべての層に同時にどれだけの「未使用の柔軟性」が存在するかという問題になります。 絶対的な位置を考えるのではなく、各層を最適に配置したときに空き領域の重なりがどの程度保証されるかに焦点を当てます。

重要な変換は、各レイヤーを、最終的なグローバル開口部が存在できる場所に関する一連の制約を生成するものとして扱うことです。 レイヤーが最適に配置されると、可能な最大長の 1 つの連続した空きセグメントを除いて、すべてのドアを一緒に「押す」ことができます。 したがって、各層は事実上、避けられないブロッキング構造の 1 つの間隔に寄与しており、補完部分の重なりを最大化したいと考えています。 

これにより、問題は、これらの最適な構成を調整した後にどれだけの共通の空き領域が存続できるかを計算することになります。 この構造は、壁のスパンに対して各層に存在するドアの全長がどれだけあるかによってのみ決まることがわかります。 

最終的な解決策は、各層でできる最善の方法は、すべてのドアを 1 つの連続したブロックに集中させ、最大の空き間隔を 1 つだけ残すことであることを観察することによって得られます。 この区間の位置はスライド可能ですが、その長さはそのレイヤーのたるみとして固定されます。 このようなすべての可動間隔の交差部分が制限要因となり、これらの緩い間隔を揃えることによって最適なオーバーラップを計算します。

 | ブルートフォース | 指数 | 指数 | 遅すぎる |
 | 最適 | O(n + Σkᵢ) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各層について、ドアの全長を計算します。 これは、再配置に関係なく、そのレイヤー内で永続的に占有されるスペースの量を表します。 これは、後のすべての推論を駆動する不変量です。 
2. 壁のスパンとドアの全長の差として、レイヤーの壁の内側にある利用可能な空きスペースを計算します。 これは、ドアが最適に詰め込まれている場合にレイヤーが許容できる連続的な空きスペースの最大量です。 
3. 最適な配置では、すべてのドアを 1 つの連続したブロックに統合できることに注目してください。ドアを分離しても、使用可能な空きスペースは増加せず、柔軟性が低下するだけだからです。 これは、各レイヤーが壁の間隔内で固定サイズの単一の硬い障害物のように動作することを意味します。 
4. したがって、レイヤー内の残りの空きスペースは、前に計算したスラックに等しい長さの 1 つの連続した間隔になります。 その位置は、境界内にある限り、壁の間隔内のどこにでも移動できます。 
5. 最終的な答えは、すべてのレイヤーの可動自由セグメント内に同時に配置できる最大の間隔によって決まります。 これは、長さが固定されているが、境界のある範囲内の任意の位置にある間隔の最大の重複を見つけることと同じです。 
6. レイヤーをさらにシフトしても交差が減少するだけであるため、最適な位置合わせは、すべての自由間隔の左側の境界をできるだけ厳密に一致させることによって実現されます。 

### なぜ効果があるのか

 各層は 2 つの不変条件を保持します。つまり、占有される長さの合計は固定されており、すべての再配置は空のスペースのみを再配分します。 断片化された構成では可能な最大の連続空き領域が厳密に減少するため、単一の連続ブロックへの変換は有効です。 グローバル目標は実行可能な空き領域の交差のみに依存するため、各層を最良の場合の連続表現で置き換えることで、最適性に関連するすべての構成が保存されます。 したがって、最適に配置された最大自由間隔の交差により、真の最大可能な開口部が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    total_slack = 0
    max_wall_span = 0

    for _ in range(n):
        data = list(map(int, input().split()))
        k = data[0]
        x1, x2 = data[1], data[2]
        lengths = data[3:]

        occupied = sum(lengths)
        span = x2 - x1
        slack = span - occupied

        total_slack += slack
        max_wall_span = max(max_wall_span, span)

    # The answer is constrained by the largest layer span and total shared flexibility
    print(max(0, total_slack - (n - 1) * max_wall_span))

if __name__ == "__main__":
    solve()
```コードはまず、各層について、ドアの長さを考慮した後にどれだけの空きスペースが残っているかを集計します。 これは、そのレイヤー内で再分配できるスラックです。 すべてのスラック値を合計すると、システム全体で利用可能な「移動可能な空き領域」の合計が得られます。 

壁の最大スパンに関連する用語が表示されるのは、各レイヤーの自由セグメントは独立してスライドできますが、他のすべてのセグメントとオーバーラップする必要があるためです。そのため、最初のレイヤーを超えて追加レイヤーが存在するたびに、最大でもそのスパン制約によって使用可能な交差が効果的に減少します。 減算により、この調整コストがグローバルに集計されます。 

ここでよくある間違いは、個々のドアの位置を計算しようとすることです。 占有長の合計のみが重要であるため、これは不要です。 最大開口の実現可能性を変えることなく、ドアを単一のブロックに統合できることがわかった後、内部構造は消滅します。

 ## 特殊なケース

 ドアのないレイヤーは、ソリューションが人為的な制約を誤って強制しているかどうかを明らかにします。 その場合、スラックはフル スパンに等しいため、応答が減少することはありません。 ドア合計はゼロであるため、アルゴリズムはこれを自然に処理します。 

すべてのドアが小さなギャップを除いてセグメントのほぼ全体を占める場合、単純な配置戦略では、独立したギャップが完全に位置合わせできると仮定してオーバーラップを過大評価する傾向があります。 未使用スペースの合計のみが問題となるため、スラック公式はこれを適切に防止します。 

1 つのレイヤーが他のレイヤーと比較して非常に大きなスパンを持つ場合、単純な交差ロジックではそれが無視され、結果が過度に制約される可能性があります。 ここで、最大スパンによる減算により、支配層がすべての層にわたって達成可能なオーバーラップを正しく境界付けることが保証されます。
