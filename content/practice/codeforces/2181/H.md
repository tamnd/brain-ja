 ## 解決策
 ## 問題の理解

 寸法のある長方形のケーキが与えられます$w \times h \times d$。 目標は、この固体を正確に分割することです。$n$小さな長方形の部分で、すべて同じサイズです。 許可される操作は、ケーキの面に平行なカットのみです。 各次元は最初に等しい長さのセグメントに分割されます。これは、最終的な部分が通常の 3D グリッドから得られることを意味します。 

プロセスについて考えるのに役立つ方法は、各軸に沿って必要なスライスの数を選択することです。 幅を分割すると$a$等しい部分、高さ$b$部分と深さ$c$パーツごとにケーキが出来上がります$a \cdot b \cdot c$同一のブロック。 各カット数は単純にその次元に沿ったセグメントの数から 1 つ減りますが、問題は各軸に沿ったカット数を直接求めます。 

重要な制約は、各除算で整数長のセグメントを生成する必要があるため、選択したセグメント数ごとに対応する次元を正確に分割する必要があることです。 

入力サイズは最大です$10^9$これにより、約数を列挙したり、すべての因数の 3 倍を試行したりする試みが除外されます。$n$。 ループアップするソリューション$n$あるいは$10^6$最悪の場合、テスト ケースごとの処理はすでに遅すぎるため、直接の数理論的分解が必要です。 

次の場合、微妙なエッジケースが発生します。$n = 1$。 この場合、カットは必要ないので、答えは次のようになります。$0, 0, 0$。 もう 1 つの重要なケースは次のような場合です。$n$因数分解に埋め込むことができない素因数が含まれています。$w, h, d$、 たとえ$n$それ自体は小さいです。 たとえば、次の場合$w = h = d = 2$そして$n = 8$、私たちにできることは$2 \times 2 \times 2$、しかし、もし$n = 6$、割り算条件が正常に失敗しない限り、因子を次元に合わせて 3 つの有効な整数分割に分配する方法はありません。 

主な困難は組み合わせ論ではなく、因数分解を正しく一致させることです。$n$三次元で利用可能な可分性構造を備えています。 

## アプローチ

 素朴なアプローチでは、すべてのトリプルを試します。$(a, b, c)$そのような$a \cdot b \cdot c = n$。 各トリプルについて、次のことを確認します。$w$で割り切れます$a$、$h$による$b$、 そして$d$による$c$。 因数の数が 3 倍になるため、これはすでに問題になっています。$n$小さな定数によって制限されません。 最悪の場合、次のような$n = 10^9$、すべての除数のペアを反復処理するのは依然として遅すぎる可能性があり、大きな制約に対して反復処理を行うのは安全ではありません。 

より深い構造は、問題は完全に次の素因数の分布に関するものであるということです。$n$3 つのバケットに分割され、各バケットは 1 つのディメンションに対応します。 ただし、任意の係数を自由に割り当てることはできません。各カットは整数のセグメント サイズを尊重する必要があるため、各次元では分割できる回数に上限が課されます。 

したがって、要素の 3 倍の観点から考えるのではなく、$n$、視点を反転します。 各次元は、可能な最大数のセグメントに影響します。$w$分割する任意の数のパーツをサポートできます$w$、同様に$h$そして$d$。 約数を 3 つ選びたいと思います$a \mid w$、$b \mid h$、$c \mid d$そのような$a b c = n$。 

これにより、問題は約数の検索になりますが、各次元の約数を事前に計算し、それらを次の約数のペアと組み合わせることで、効率的に構造化できます。$n$。 以来$w, h, d \le 10^9$、各数値は最大で約$10^5$最悪の病理学的ケースでは約数が計算されますが、実際には、約数を反復するだけで済みます。$n$、によって制限されます$O(\sqrt{n})$。 

重要な観察は、分割方法を修正できるということです。$n$の中へ$a \cdot b \cdot c$, ただし、すべてのトリプルを列挙する代わりに、2 つの要素を修正して 3 番目の要素を導出します。 次に、各次元に対して割り切れるかどうかを確認するだけで済みます。 

これにより、問題は次の約数のペアを列挙することに縮小されます。$n$、これは効率的であり、3 次元に対する互換性をテストします。

 ## アルゴリズムのチュートリアル

 タスクを整数を見つけるものとして再解釈します$a, b, c$次のような:$a \cdot b \cdot c = n$、$w \bmod a = 0$、$h \bmod b = 0$、$d \bmod c = 0$。 

その後、セグメントをカットに変換します。 

1. すべての約数を列挙します$a$の$n$。 そういったそれぞれに対して$a$、計算する$n / a$、私たちはこれを呼んでいます$m$。 このステップが必要なのは、有効な最初の次元の分割では約数を消費する必要があるためです。$n$。 
2. 各約数について$b$の$m$、 定義する$c = m / b$。 これにより保証されます$a b c = n$3 番目のループは必要ありません。 
3. トリプルごとに$(a, b, c)$、どうかを確認してください$a$分割する$w$、$b$分割する$h$、 そして$c$分割する$d$。 これにより、各ディメンションを必要な数のセグメントに均等に分割できるようになります。 
4. 有効な場合は、リターンしてセグメント数をカット数に変換します。$a - 1, b - 1, c - 1$、 以来$k$セグメントには必要な$k - 1$カット。 
5. すべての除数のペアを使い果たした後に有効なトリプルが存在しない場合、出力$-1$。 

### なぜ効果があるのか

 すべての有効なパーティションは、各軸に沿って選択したセグメント数に正確に対応します。 カットは軸に沿って均一になるように制約されているため、各寸法は独立してその長さの約数を選択することになります。 製品の制約$a b c = n$セルの総数が必要な個数と一致することを確認します。 の約数ペアを列挙する$n$これにより、可能なすべての乗法分解を冗長性なく考慮することが保証され、次元の割り算をチェックすることで幾何学的実現可能性が強化されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def get_divisors(x):
    small = []
    large = []
    i = 1
    while i * i <= x:
        if x % i == 0:
            small.append(i)
            if i * i != x:
                large.append(x // i)
        i += 1
    return small + large[::-1]

w, h, d = map(int, input().split())
n = int(input())

# try all factorizations n = a * b * c
i = 1
while i * i <= n:
    if n % i == 0:
        j = n // i

        # a = i, bc = j
        k = 1
        while k * k <= j:
            if j % k == 0:
                a, b, c = i, k, j // k
                if w % a == 0 and h % b == 0 and d % c == 0:
                    print(a - 1, b - 1, c - 1)
                    sys.exit(0)
            k += 1
    i += 1

print(-1)
```このコードは、因子トリプルの制御された列挙を実行します。$n$。 外側のループは最初の次元係数を修正します$a$。 そのような選択ごとに、残りの製品が$n / a$2つの要素に分かれる$b$そして$c$。 これにより、すべてのトリプルに対する三次検索が回避されます。 

可分性チェックにより、各次元が等しいセグメントに分割できることが保証されます。 1 を引くと、セグメント数がカット数に変換されます。$k$部品は正確に必要です$k-1$カット。 

有効なトリプルで十分であり、問​​題ではすべての解を列挙する必要がないため、早期終了が使用されます。

 ## 特殊なケース

 一番小さいケース$w = h = d = 1, n = 1$単一のブロックを生成します。 アルゴリズムはすぐに見つけます$a = b = c = 1$、そして戻ります$0, 0, 0$、カットが必要ないという事実と一致します。 

いつ$n$は素数で 1 より大きい、など$n = 13$、可能な因数分解は次のとおりです。$13 \cdot 1 \cdot 1$。 アルゴリズムは各次元に素因数を割り当てようとしますが、いずれも割り当てられない場合は、$w, h, d$が 13 で割り切れる場合、すべてのチェックが失敗し、出力は正しくなります。$-1$。 

次のような 1 つの次元が非常に制限されている場合$w = 1$、アルゴリズムは効果的に強制します$a = 1$。 より大きな係数を割り当てようとする試みは、$w$可分性チェックに失敗し、無効な因数分解を早期に削除し、有効な割り当てのみを残します。$h$そして$d$。
