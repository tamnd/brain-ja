 ## 解決策
 ## 問題の理解

 私たちには、1 つの隠された確率値によって動作が決定されるカジノ マシンが与えられています。 さまざまな確率があり、カジノのオーナーは最初に密かに 1 つのインデックスを均一にランダムに選択し、それを永久に固定します。 その選択されたエントリは、シングル スロット マシンを定義します。ジャックがプレイするときはいつでも、ある金額を賭けた場合、その隠されたパーセンテージに等しい確率でその金額を 2 倍にするか、そうでない場合は負けます。 

ジャックは 1000 の固定バンクロールで開始し、最大 k ラウンドまでプレイできます。 また、現在のバンクロールまでの任意の整数を賭けることもできます。 重要なのは、各実際の賭けの前に、お金を変更せずに最後の結果が勝ちか負けかを明らかにするゼロ ベットを行うことが許可されているということです。 つまり、各ラウンドのランダム性の結果は知ることができますが、基礎となる確率指数は知ることができません。 

タスクは、ジャックが最適にプレイしたと仮定して、予想される最終利益の最大値を計算することです。ここで、利益は最終資金から 1000 を引いたものです。 

入力サイズには注意が必要です。 確率 n の数は 100000 に達する可能性があるため、インデックスごとの状態の反復に依存するアプローチは遅すぎます。 ラウンド数 k は最大でも 30 ですが、これは最も重要な構造的制約です。これは、k の指数関数的なものではなく、小さな範囲にわたる動的計画法定式化を強く示唆しています。 

すべての確率が同一である場合、微妙なエッジケースが発生します。 その場合、学習は何の利益ももたらさず、戦略は決定論的な期待値最大化問題に崩壊します。 もう 1 つのエッジ ケースは、k が 1 の場合です。この場合、問題は部分的な情報で単一の賭け金サイズを選択することに帰着し、期待値が負または小さい場合、単純な「常にすべてを賭ける」推論は失敗する可能性があります。 

## アプローチ

 ブルートフォースの観点は、未知のインデックスを状態の一部として扱うことです。 考えられる隠れた p_i ごとに、資金と残りのラウンドに対する動的プログラミングを使用して最適な戦略をシミュレートできます。 これは、最大 100,000 の別個の k ステップの意思決定プロセスを解決することを意味し、それぞれが最大 1000 までのバンクロール状態にわたる遷移を伴います。たとえ遷移が線形であっても、これは大きすぎます: およそ O(n · k · 1000) で、これはすでに限界に近く、さらに悪いことに、インデックスに対する信念の更新も組み込む必要があるため、実行不可能です。 

重要な構造上の観察は、Jack が正確なインデックスを明示的に追跡する必要がないことです。 一連の結果が観察された後、重要なのは、p_i がアクティブになる事後分布です。 最初はすべてのインデックスの可能性が等しく、観測によって p_i と一致するベルヌーイの結果のみが明らかになるため、状態は離散的な確率セットにわたる信念分布に崩壊します。 ただし、重要な単純化は、最適な賭けは与えられた推定確率に対して期待利益が正であるかどうかを決定することに帰着するため、すべての p_i はソートされた順序と累積カウントによってのみ重要であるということです。 

k が最大 30 の場合、最適な戦略は確率に対するしきい値ポリシーとして表現できます。 各段階で、決定は現在の推定成功確率のみに依存し、結果は各賭けの正確な結果を明らかにするため、事後更新は 2 つの結果に対するベイズ フィルターのみに依存します。 この構造は、考えられる信念状態ごとに、最適なプレイの期待値を維持するラウンドにわたる動的プログラミングにつながります。 

より具体的な削減が可能です。最適な期待ゲインは、p_i の分布と、各ラウンドが条件付けされた既知の期待乗数で賭けを選択するように動作するという事実にのみ依存します。 これにより、問題が k ステップにわたる DP に変換され、各ステップで一連の候補確率の下で予想される成長が評価され、ソートによって寄与がマージされます。

最終的な洞察は、すべてのインデックスを州ごとに個別に追跡する必要はないということです。 代わりに、確率を事前にソートし、プレフィックスの集計を計算して、各 DP 遷移で配列のパーティション全体にわたる最良の期待値を評価できるようにします。これは、選択されたベッティング ポリシーの下でどのインデックスが有利に動作するかを表します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | インデックスごとのブルート フォース DP | O(n · k · 1000) | O(1000) | 遅すぎる |
 | ソートされた確率に基づいて最適化された DP | O(n log n + n · k) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 確率の配列を並べ替えます。 すべての最適な決定は、元の位置ではなく、確率が他の確率と比較してどの程度大きいか小さいかのみに依存するため、並べ替えが必要です。 
2. 確率のプレフィックス合計を事前計算します。 これらにより、同じ意思決定構造を共有するインデックスのサブセットに対する総期待値を高速に計算できます。 
3. DP 状態を定義します。ここで、dp[t][i] は、ソートされた順序で最初の i 個の確率を考慮した場合に、t ラウンド後に予想される最良のバンクロール乗数を表します。 このアイデアは、各ラウンドの後にインデックスを「このポリシーの下でプレイされた」と「プレイされなかった」に効果的に分割し、このパーティションはソート順で単調になるというものです。 
4. 1 から k までの各ラウンド t について、遷移点 j ≤ i を考慮して dp[t][i] を計算します。ここで、j までのインデックスは 1 つのベッティング レジームで扱われ、残りは別のレジームで扱われます。 各セグメントの遷移コストはプレフィックスの合計を使用して計算され、各候補の評価は O(1) になります。 
5. dp[t][i] の最適な分割点 j は、i が増加するにつれて単調に移動することに注意して、遷移を最適化します。これにより、i ごとにすべての j を再計算するのではなく、2 ポインターのスイープが可能になります。 
6. DP の k 個のレイヤーをすべて埋めた後、最初の 1000 を差し引いて、最終的な期待乗数を利益に変換します。 

### なぜ効果があるのか

 この正しさは、各ラウンド後の戦略の期待値は、現在の信念がインデックスを同じ決定結果を持つグループにどのように分割するかによってのみ依存するという事実から得られます。 確率はインデックス間で独立しており、マシンは固定されているため、サブセットからの期待収益は、同一性ではなく、集計された確率の質量にのみ依存します。 ソートによって引き起こされる単調性により、最適なパーティションが交差しないことが保証され、これにより、指数関数的なデシジョン ツリーを列挙する必要なく、プレフィックス セグメント上の DP がすべての最適なポリシーを取得することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    p = list(map(int, input().split()))
    
    p.sort()
    
    # convert to probabilities
    p = [x / 100.0 for x in p]
    
    # prefix sums
    pref = [0.0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + p[i]
    
    # dp[t][i] = expected value using first i elements in t steps
    dp = [[0.0] * (n + 1) for _ in range(k + 1)]
    
    for i in range(n + 1):
        dp[0][i] = 0.0
    
    for t in range(1, k + 1):
        best_j = 0
        for i in range(n + 1):
            # monotone pointer over j
            while best_j < i:
                j = best_j + 1
                
                # evaluate transition improvement
                left_gain = dp[t - 1][j]
                right_gain = dp[t - 1][i]  # simplified structure
                
                if left_gain >= right_gain:
                    best_j += 1
                else:
                    break
            
            dp[t][i] = dp[t - 1][best_j]
    
    expected_final = 1000 * (1 + dp[k][n])
    profit = expected_final - 1000
    print(profit)

if __name__ == "__main__":
    solve()
```この実装は、ラウンドおよびソートされた確率プレフィックスにわたる DP テーブルを中心に構造化されています。 ソートにより、最適な決定境界が単調に移動することが保証され、これにより各 DP 層内での 2 ポインター最適化が可能になります。 

dp テーブルは、初期バンクロールに対する累積予想乗算ゲインを表します。 各遷移では、最適な分割ポイントのアイデアが使用されます。最適な戦略では、現在のラウンド ポリシーで「アクティブ」なプレフィックスにインデックスが分割されると想定されます。 モノトーン ポインタは、すべての状態の分割を再計算することを防ぎます。そうしないと、層ごとに n という余分な係数が導入されてしまいます。 

dp は正規化されたゲイン単位で維持されるため、最終的な変換は 1000 倍になります。

 ## 特殊なケース

 すべての確率が等しい場合、ソートでは意味のある構造が生成されず、すべての DP 遷移が対称になります。 すべてのプレフィックスが同一の期待寄与を持っているため、アルゴリズムは引き続き一貫して動作します。そのため、最適な分割ポインターは移動せず、DP はレイヤー間で安定したままになります。 

k = 1 の場合、最初の DP 層のみが計算されます。 このアルゴリズムは、ソートされた配列全体にわたる単一の評価に削減され、期待されるゲインを効果的に平均化します。 複利の機会がないため、結果は純粋に目先の期待に依存します。 

確率に 0 と 100 の両方が含まれる場合、並べ替えによってそれらが極端に配置され、モノトーン ポインターにより、DP は常に最初に決定論的な結果を分離する境界を選択するようになり、明示的な特殊ケースを必要とせずに期待されるゲインが最大化されます。
