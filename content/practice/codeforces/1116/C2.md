 ## 解決策
 ## 問題の理解

 与えられたビット列が周期的かどうかをチェックする量子オラクルを実装するように求められます。 実際的には、次の配列があると想像してください。$N$それぞれがビットを表す量子ビットと、個別の出力量子ビット。 目的は、ビット列に周期がある場合にのみ、出力量子ビットを反転することです。$P$と$1 \le P \le N - 1$、文字列が毎回繰り返されることを意味します$P$ポジション。 正式には、全員に対して$i$で$0$に$N-P-1$、位置のビット$i$位置のビットに等しい$i+P$。 

制約$2 \le N \le 7$十分に小さいため、考えられるすべての期間を試して徹底的にチェックする余裕があります。 演算は量子であるため、計算中に量子ビットを測定することはできません。 単一演算を使用してそれらを操作するだけであり、入力レジスタは変更されないままでなければなりません。 

ピリオドが文字列の長さを均等に分割しない場合、微妙なエッジ ケースが発生します。 For example, the string`01010`長さは 5 ですが、周期的です$P=2$。 約数をチェックするだけの単純なアプローチ$N$誤って非周期としてマークされてしまいます。 もう 1 つのエッジ ケースは、すべて同一のビットの文字列であり、技術的にはすべてのビットに対して周期的です。$P$1から$N-1$。 私たちの実装では、これらを正しく検出する必要があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。 考えられる各期間について$P$1から$N-1$、すべてのペアをチェックしてください$(x_i, x_{i+P})$そしてそれらが一致するかどうかを確認してください。 見つけたら$P$すべての比較が成立する場合、文字列は周期的です。 周期性の定義は明示的にペアワイズ等価シフトされるため、このアプローチは正しいです。$P$。 最悪の場合の複雑さは次のとおりです。$O(N^2)$できるから$N-1$期間以降$N-P$それぞれの比較。 と$N$最大でも 7 であれば、これは完全に実現可能です。 

最適化するための重要な洞察は、このような小さなものに対して、$N$、総当たりチェックは実際にはすでに最適です。 代わりに、入力レジスタを変更せずに測定を実行しないという量子固有の要件が実装をガイドします。 古典的なチェックを、候補期間に一致する必要がある量子ビットのペアごとに、可逆的な量子操作に変換します。$P$、それらを XOR して補助量子ビットにします。 一部のすべての XOR がある場合$P$が 0 の場合、文字列にはそのピリオドが含まれます。 最後に、すべての周期テストを 1 つの出力フリップに結合します。

 ## アルゴリズムのチュートリアル

 1. 候補期間ごとに$P$1から$N-1$、不一致を追跡するために補助量子ビットを初期化します。 
2. 各ビットを比較する$x_i$と$x_{i+P}$みんなのために$i$で$0$に$N-P-1$。 不一致ごとに、CNOT ゲートを使用して補助量子ビットを反転します。 付属品は終了します`1`不一致がある場合と、`0`期間が保たれていれば。 
3. 一定期間すべてのポジションを確認した後$P$、結果を出力量子ビットに XOR します。 アンシラリーが 0 の場合、出力量子ビットは反転されます。 それ以外の場合は、変更されないままになります。 
4. 可逆性を維持するために、各周期チェック後に補助量子ビットを 0 にリセットします。 これにより、入力レジスタが変更されず、操作が単一になることが保証されます。 
5. すべての期間に対して繰り返します$P$。 最後に、ビット列がある期間周期的である場合にのみ、出力量子ビットが反転されます。 

機能する理由: 各補助量子ビットは、候補期間が失敗したかどうかを追跡します。 XOR演算`success`(補助は 0) を出力に追加すると、少なくとも 1 つの周期が成功したときに出力が正確に反転することが保証されます。 すべての操作は可逆であるため (XOR と CNOT)、入力レジスタは変更されず、Oracle の制約を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_periodic(s):
    n = len(s)
    for p in range(1, n):
        match = True
        for i in range(n - p):
            if s[i] != s[i + p]:
                match = False
                break
        if match:
            return True
    return False

def main():
    t = int(input())
    for _ in range(t):
        s = input().strip()
        print("YES" if is_periodic(s) else "NO")

if __name__ == "__main__":
    main()
```説明:`is_periodic`この関数は、アルゴリズムのチュートリアルで説明されている古典的なチェックを実装します。 すべての候補期間にわたって反復され、関連するすべてのペアが検証されます。 初期の`break`不一致がある場合は効率が保証されます。 の`main`関数は複数のテスト ケースを読み取り、チェックを適用します。 使用する`.strip()`入力文字列の末尾の改行を処理します。

 ## 特殊なケース

 このアルゴリズムは、文字列の長さが均等に分割されていないピリオドを正しく処理します。 のために`01010`、チェックします$P=2$そして、関連するすべての比較の一致を見つけて、出力を反転します。 均一な文字列の場合`1111`、それは検出します$P=1$有効として出力を適切に設定します。 最小の入力は次のとおりです`01`または`00`ループオーバー期間は自然に次の時点で停止するため、正しく処理されます。$N-1 = 1$。 初期の`break`on 不一致により、不必要な比較が防止され、正確さが維持されます。
