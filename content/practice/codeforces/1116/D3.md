 ## 解決策
 ## 問題の理解

 以下から構成される量子レジスタに対してユニタリ演算を実装するように求められます。$N$量子ビット、ここで$2 \le N \le 5$。 ユニタリは次のように表されます。$2^N \times 2^N$行列であり、主対角と反対角にのみゼロ以外のエントリがなければなりません。 他のすべてのエントリはゼロでなければなりません。 行列のインデックスはリトルエンディアン順序付けを使用します。これは、インデックスの最下位ビットが配列内の最初の量子ビットに対応することを意味します。 

タスクは数値行列を出力することではなく、次のようなツールを介して検査したときに量子演算を構築することです。`DumpUnitary`、記述されたパターンに一致する行列を生成します。 複数の有効なユニタリーがパターンを満たすため、要件を満たす任意の構造が受け入れられます。 溶液中で測定を行うことはできません。 操作は純粋に単一である必要があります。 

とすれば$N$小さい (最大 5 量子ビット)、実装する必要がある最大の行列は次のサイズです$32 \times 32$。 これにより、スケーラビリティを気にせずにフルビット操作を推論できるようになります。 エッジケースは小規模な環境で発生します。$N$、 特に$N = 2$ここで、メインエントリと対角エントリが互いに競合したり上書きしたりしないようにする必要があります。 

たとえば、不注意な実装では、行列の対称性を考慮せずに量子ビットを交換しようとし、必要な対角位置および反対角位置の外側に非ゼロ要素が生成される可能性があります。 たとえば、$N = 3$の場合、すべての量子ビットに単純なビット反転を適用することはできません。これは、ゼロ以外の値が非対角位置に配置され、行列パターンに違反するためです。 

## アプローチ

 ブルートフォースアプローチは、完全な$2^N \times 2^N$すべての基底状態を反復し、行と列のインデックスが主または反対角に対応するかどうかを確認し、それに応じて非ゼロ要素を設定することにより、行列を手動で作成します。 これは実現可能ですが、$N \le 5$以来$32 \times 32 = 1024$要素が小さく、量子プログラミングでは扱いにくく直感的ではなく、量子ゲートの自然な構造を利用していません。 

重要な観察は、主対角要素は量子ビットを変更しないままにすることに対応し、反対角要素はすべての量子ビットを反転する (ビットごとに反転しない) ことに対応するということです。 量子用語では、主対角は恒等演算によって実装され、反対角はすべての量子ビットに X ゲートを適用することによって実装でき、ユニタリティを維持するために制御された位相演算と組み合わせる可能性があります。 賢いトリックは、すべての量子ビットに対してアダマール変換を使用して状態を混合し、条件付き Z 回転を適用して反対角パターンを生成することです。 

最適なアプローチでは、この洞察が使用されます。各量子ビットはアダマールを受けて重ね合わせが作成され、その後、特定のマルチ制御 X ゲートまたは位相反転が、主対角要素に影響を与えることなく反対角を実装します。 このようにして、ユニタリ全体が一連の基本ゲートで構築され、視覚化するとパターンが自然に現れます。

 ## アルゴリズムのチュートリアル

 1. すべての量子ビットにアダマール ゲートを適用します。 これにより、各計算基底状態が変換されます$|b\rangle$すべての基底状態を重ね合わせます。 アダマールは、後続の X ゲートまたは Z ゲートが複数のエントリに同時に影響を与えることができることを保証します。 
2. すべての量子ビットに X ゲートを適用します。 これにより状態が反転します$|b\rangle$そのビット単位の補数に$|\bar{b}\rangle$これはまさに主対角インデックスを反対角インデックスにマップするものです。 
3. 必要に応じて、ユニタリ性を維持し、重複する状態間の干渉を回避するために (正確な複素位相に必要な場合)、制御された Z ゲートまたは他の量子ビットによって制御される 1 つの量子ビットに複数量子ビットの位相回転を適用します。 実際には、この問題ではチェッカーはゼロ以外の複素数を受け入れるため、このステップをスキップできます。 
4. 結果の演算では、主対角 (恒等) と反対角 (全量子ビット X) の両方に非ゼロのエントリがあり、それ以外の場所にはゼロが含まれます。 すべてのインデックスは自動的にリトルエンディアンの規則に従って調整されます。 

機能する理由: アダマールに続いて X をすべての量子ビットに適用すると、主位置と反対角位置に正確にヒットする重ね合わせが生成されます。 他のすべての基底状態はゼロになるか、(相対位相に応じて) 破壊的に干渉するため、行列は必要なスパース パターンを持ちます。 この性質は量子ビットの置換の下では不変であり、すべての場合に当てはまります。$N \le 5$。 

## Python ソリューション

 この問題には Q# が必要なため、代わりに Q# ソリューションを提供しますが、完全を期すために、ロジックを Python のような疑似コードで説明します。```
# Pseudocode representation of Q# solution
from qsharp import qs

def Solve(qs):
    # Apply Hadamard to all qubits
    for q in qs:
        H(q)
    # Apply X to all qubits
    for q in qs:
        X(q)
```Q# に翻訳:```
namespace Solution {

    operation Solve(qs : Qubit[]) : Unit {

```各ループはアルゴリズムのステップに直接対応します。 アダマールは重ね合わせを作成し、X ゲートはすべての量子ビットを反転し、それらが一緒になって必要な対角行列エントリと反対角行列エントリを生成します。 

## 実用的な例

 ### 例 1: N = 2

 | ステップ | 量子ビットの状態 | 操作 |

 | ステップ | 量子ビットの状態 | 操作 |

 結果として得られる 8x8 行列には、必要に応じて主対角 (0,0...7,7) と反対角 (0,7...7,0) に X が含まれます。

 ## 特殊なケース

 N=2 の場合、H と X を適用すると、対角線と反対角線の両方が正しく埋められた 4x4 行列が得られます。 初期状態 |00>、|01>、|10>、|11> は次のように変換されます。 

- 両方に H: 各状態は 4 つの状態の重ね合わせになります。 
- 両方に X: 各ビットを反転し、|00> を |11> にマッピングします。 
- 非ゼロのエントリは、対角および反対角のインデックスに正確に表示され、無関係な非ゼロ要素は存在しません。 

N=5 の場合、同じ論理が自然に拡張されます。H と X を各量子ビットに適用すると、正しいスパース パターンを持つ 32x32 ユニタリが生成されます。 このアルゴリズムは、追加の考慮事項なしで最大サイズを処理します。
