 ## 解決策
 ## 問題の理解

 ビット文字列をエンコードする量子ビットの小さなレジスタと、出力アキュムレータとして機能する追加の単一量子ビットが与えられます。 課題は、ビット文字列のブール関数を計算する可逆変換を実装することです。入力レジスタ内の 1 の数が 3 で割り切れる場合に限り、出力量子ビットを反転する必要があります。重要な制約は、入力レジスタが変更されないこと、および演算がユニタリーでなければならないということです。つまり、可逆的でなければならず、測定や古典的な分岐に依存することはできません。 

より具体的には、基底状態をマッピングする量子オラクルを構築しています。$|x\rangle|y\rangle$に$|x\rangle|y \oplus f(x)\rangle$、 どこ$f(x)$ハミング重みのみに依存します$x$モジュロ 3。入力サイズは非常に小さく、最大でも 9 量子ビットです。これは、漸近的に最適化するのではなく、標準の量子ゲートを使用して直接可逆回路を構築することが期待されていることを示す強力なヒントです。 

この制約は、レジスタが小さいため、すべての量子ビットを含む制御された操作を自由に使用できることを意味します。 指数関数的または組み合わせの構築$2^N$状態も概念的には実現可能ですが、量子回路の観点からは、明示的な真理値表エンコードではなく、クリーンな可逆構造が依然として必要です。 

関数が 1 の位置ではなく 1 の数のみに依存するという事実から、微妙なエッジ ケースが発生します。 素朴な古典的な直観は、ビットを合計して割り切れる可能性をチェックすることを提案するかもしれませんが、量子コンピューティングでは、合計を破壊的に「計算して上書き」することはできません。 もう 1 つのよくある落とし穴は、禁止されている中間パリティ情報を測定しようとすることです。 最後に、関数は対称であるため、量子ビットを非対称に扱うソリューションでは可逆性を維持する必要があります。そうしないと、入力レジスタが変更されないという要件を破ることになります。 

## アプローチ

 これについて考える強引な方法は、すべてを列挙することです。$2^N$基底状態を計算し、それぞれのハミング重みを計算し、出力量子ビットを条件付きで反転します。 概念的には、すべての入力状態が独立しており、マッピングを明示的に定義できるため、これは機能します。 ただし、これは回路レベルの解決策ではなく、量子用語で言えば、構造化された方法で効率的に構築できない、指数関数的に大規模な制御された操作に相当します。 

重要な点は、個々のビット文字列を区別する必要がないということです。 ハミング重みのモジュロ 3 を追跡するだけで済みます。これにより、問題全体が、可逆的な方法で小さな 3 状態カウンターを維持することに集約されます。 各量子ビットはこのカウンターに 0 または 1 のいずれかを与え、モジュラー演算を使用してカウンターを増分更新できます。 

これにより、標準的な可逆構造が得られます。つまり、位相累積または制御された回転を使用して、現在の和モジュロ 3 の 2 量子ビットのアンシラなしのエンコーディングを維持します。または、より単純に、「和モジュロ 3 が 0 に等しい」という条件をエンコードする制御された演算を使用して、出力量子ビットへのパリティ寄与を直接計算します。 N は最大 9 であるため、サイズ mod 3 が 0 であるすべてのサブセットを列挙することにより、多重制御の Toffoli スタイルのロジックを使用して可逆分解を直接実装することもできます。 

ただし、最もきれいな構造は、関数を対称多項式形式に分解することで得られます。 ハミング重みが 3 で割り切れるという指標は、基本対称和の XOR に対するブール関数として表現でき、可逆回路内の制御されたマルチ量子ビット ゲートで実装できます。 この小さな N 領域では、単純にスクラッチ フェーズで合計を計算し、その合計のモジュロ 3 がゼロに等しいかどうかで出力反転を条件付け、その後は計算を行わずに入力量子ビットを復元できます。 

ブルート フォースと最適な構築の本質的な違いは、ブルート フォースは入力を直接推論するのに対し、最適なアプローチはコンパクトな統計量であるハミング重みモジュロ 3 に基づいて推論することです。

 ## アルゴリズムのチュートリアル

 制御された操作を使用して、ハミング重みモジュロ 3 を出力量子ビットの位相情報にエンコードする可逆計算を構築します。 

1. すべての入力量子ビットを全体を通して変更せずに、条件付きで出力量子ビットのみに作用することを確認して初期化します。 これは Oracle の定義で要求されているため、すべての操作は入力レジスタに関して可逆である必要があります。 
2. 各入力量子ビットについて$x_i$では、モジュール式の計数構造に貢献する制御された操作を適用します。 従来の合計を保存する代わりに、制御された位相反転に寄与をエンコードし、合計ハミング重みのモジュロ 3 の署名を蓄積します。 
3. ハミング重みモジュロ 3 のみに依存する関数は、単位根に対応する位相寄与を適用することによって実装できるというアイデンティティを使用します。 各量子ビットは、結合された位相がエンコードされるように位相回転に寄与します。$\omega^{\text{weight}(x)}$、 どこ$\omega = e^{2\pi i/3}$。 
4. この位相を蓄積した後、蓄積された位相が 3 で割り切れる重みに対応する場合にのみ出力を反転する制御された反射を使用して、位相インジケーターを出力量子ビットの計算可能なブール フラグに変換します。 
5. 最後に、すべての入力量子ビットが正確に元の状態に戻るように、補助位相エンコードを計算解除することで可逆性を確保します。 

### なぜ効果があるのか

 不変条件は、最初の k 量子ビットを処理した後、量子状態が 3 を法とするそれらの k 量子ビットのハミング重みにのみ依存する位相を累積しているということです。この不変条件が成り立つのは、各量子ビットが独立して乗算的に位相エンコードに寄与し、1 の立方根の乗算が指数の 3 を法とする加算に正確に対応するためです。 k = N の場合、位相は 1 の合計数が 0 を法とする 3 に一致するかどうかを完全にエンコードします。最終的な制御された操作は、この位相情報を出力量子ビットのフリップに単純に変換し、オラクルを完了します。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、入力レジスタがすべて 0 の場合です。 この場合、ハミング重みは 0 であり、3 で割り切れるため、出力は反転する必要があります。 オラクルは重ね合わせに対しても同様に動作する必要があります。これは、システムがすべてゼロと非ゼロの状態で均一な重ね合わせにある場合でも、変換は線形で一貫したままであることを意味します。 

もう 1 つのエッジ ケースは、ちょうど 3 量子ビットが 1 に設定される場合です。たとえば、9 量子ビット システムでは |111000000⟩ と入力します。 回路は、非アクティブな量子ビットからの干渉なしに、3 つのアクティブな量子ビットすべてからの寄与を正しく蓄積する必要があります。 各量子ビットがモジュロ 3 位相エンコードに独立して寄与するため、位置ではなくカウントのみが重要となるため、可逆的な構造によりこれが保証されます。 

最後の微妙なケースは、振幅が異なるハミング重みを持つ状態に対応する重ね合わせ入力です。 オラクルは、正しい位相条件付きフリップを各基底コンポーネントに独立して適用する必要があります。これは、古典的な分岐ロジックではなく純粋にユニタリ制御ゲートから演算を構築することによって保証されます。
