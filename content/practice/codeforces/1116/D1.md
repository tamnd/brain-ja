 ## 解決策
 ## 問題の理解

 の配列に対してユニタリ演算を実装するように求められます。$N$量子ビット、ここで$2 \le N \le 5$、演算を表す行列は非常に特殊なブロック対角構造を持つようになります。 具体的に言うと、$2^N \times 2^N$行列では、すべての非ゼロのエントリは主対角に沿って連続する 2×2 ブロックに現れ、これらのブロックの外側はすべてゼロになります。 マトリックスをチェス盤として想像すると、対角線上の 2×2 の正方形だけが埋められ、残りは空になります。 

行と列のインデックスはリトルエンディアンです。これは、最下位ビットが配列内の最初の量子ビットに対応することを意味します。 これは、各列がどの基底状態に対応するかを解釈するために重要です。 たとえば、最初の列は次のようになります。$|00...0\rangle$、2列目から$|10...0\rangle$、 等々。 出力は数値ではありません。 これは行列内のゼロ以外のエントリのパターンであり、チェッカーに対して検証されます。 

なぜなら$N$が小さい場合、行列のサイズは最大でも$32 \times 32$したがって、このパターンを明示的に埋めるソリューションは、計算上実行可能です。 ただし、主な課題は速度ではなく、測定を使用せずにこのブロック対角パターンを生成する量子演算を設計することです。 これは、2×2 ブロックを実現するために、一度に量子ビットのペアにのみ作用するユニタリー演算 (基本的に量子ゲートのシーケンス) を構築することを意味します。 

重要なエッジケースは次のような場合です$N=2$, ここで行列は$4 \times 4$。 ここで、不注意な実装により、存在しない量子ビットを操作しようとしたり、ブロックを形成するペアを誤って解釈したりする可能性があります。 正しい出力は、単一の 2×2 ブロックが対角線に沿って 2 回繰り返されたものです。 

## アプローチ

 ブルートフォースアプローチは、任意のユニタリーを構築しようとすることです。$N$量子ビットを取得し、行列が目的のブロック パターンと一致するまで調整します。 あらゆるユニタリは 1 量子ビットおよび 2 量子ビットのゲートのシーケンスに分解できるため、これは理論的には正しいです。 実際には、このアプローチは失敗します。2×2 ブロック構造を保証する体系的な方法がなく、可能なユニタリ行列の数が指数関数的に増加するためです。$N$。 

実用的な解決策を明らかにする洞察は、パターンに気づくことです。各 2×2 ブロックには、そのペアの最下位量子ビットのみを反転することが含まれます。 これは、制御された X (CNOT) ゲートまたは制御されたアダマール変換を使用して、基底状態のペアにのみ影響を与えるエンタングルメントを作成することを示唆しています。 具体的には、量子ビットを最下位から最上位まで反復処理し、最初の量子ビットにアダマール ゲートを適用し、次に上位量子ビットに条件を付けて制御された演算を適用すると、目的の 2×2 ブロック対角構造が生成されます。 以来$N$が小さい場合は、ネストされたループまたは一連の制御されたゲートですべてのブロックをカバーするのに十分です。

 ## アルゴリズムのチュートリアル

 1. 量子ビットの配列を準備する$qs$入力として。 配列の長さ$N$は 2 ～ 5 であることが保証されます。 
2. アダマール ゲートを最下位量子ビット (qs[0]) に適用します。 これにより重ね合わせが作成されます$(|0\rangle + |1\rangle)/\sqrt{2}$、最初の 2×2 ブロックの基礎を形成します。 
3. 後続の各量子ビットについて$i$1から$N-1$、量子ビットで制御される、controlled-X (CNOT) ゲートを適用します。$i$そして量子ビットをターゲットにする$i-1$。 これにより、2×2 ブロックが他のブロックに干渉することなく対角線に沿って繰り返されることが保証されます。 
4. 以下の場合は、制御された操作を階層的に繰り返します。$N>2$、行列内の各 2×2 ブロックが正しい基底状態のペアのみを結合するようにします。 制御構造により、ブロックが確実に分離されます。 
5. 結果として得られるユニタリは、自動的に正しいパターンを持ちます。つまり、対角線上に連続する 2×2 の非ゼロ ブロック、その他の場所にはゼロがあります。 測定は使用されません。 

それが機能する理由: 不変条件は、制御された各操作が意図した基底状態のペアにのみ影響を与えるということです。 アダマールは重ね合わせを導入し、制御された X 演算は各 2x2 ブロックが設定されるように反転パターンを伝播します。 ゲートの構造により、ブロックの外側に非対角要素が表示されることはありません。 

## Python ソリューション

 これは Q# の問題ですが、行列パターンをシミュレートする Python 表現を作成できます。 説明のために、2×2 ブロック対角パターンを生成します。```python
import sys
input = sys.stdin.readline

def block_diagonal_matrix(N):
    size = 2**N
    matrix = [['.' for _ in range(size)] for _ in range(size)]
    for i in range(0, size, 2):
        matrix[i][i] = 'X'
        matrix[i][i+1] = 'X'
        matrix[i+1][i] = 'X'
        matrix[i+1][i+1] = 'X'
    return matrix

def print_matrix(matrix):
    for row in matrix:
        print(''.join(row))

def main():
    N = int(input())
    matrix = block_diagonal_matrix(N)
    print_matrix(matrix)

if __name__ == "__main__":
    main()
```このコードは、対角に沿って 2×2 X ブロックで行列を埋めて出力します。 2 つずつ繰り返すステップにより、各ブロックが確実に分離されます。

 ## 特殊なケース

 許容される最小入力である N=2 の場合、行列には 4×4 要素しかありません。 アルゴリズムはステップ サイズ 2 で反復され、正確に 2 つの 2×2 ブロックを作成します。 インデックス作成エラーは発生せず、余分な要素が埋められることもありません。 最大入力である N=5 の場合、アルゴリズムは 32 行を 2 ステップで正しく反復し、16 ブロックを埋めます。 ステップ サイズにより、ブロックが重ならないことが保証され、対角以外の要素はすべてゼロのままになります。 どちらの極端な場合も、アルゴリズムが境界条件を正しく処理していることが確認されます。
