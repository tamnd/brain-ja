 ## 解決策
 ## 問題の理解

 量子操作を構築するように求められています$N$量子ビットの行列は、計算の基礎において非常に厳格なブロック構造を持っています。 完全なユニタリは、$2^N \times 2^N$行列なので、それを明示的に計算したり出力したりする必要はありません。 代わりに、結果として生じる変換が非ゼロおよびゼロのエントリの特定のパターンに一致する量子回路を設計する必要があります。 

行列は再帰的に定義されます。 それを 4 つの等しい象限に分割すると、右上と左下の象限は完全にゼロになります。 右下の象限は完全にゼロではありません。 左上の象限も同じ構造ですが、1 レベル小さいだけです。 最小スケールで$N=1$、左上のエントリはゼロ以外なので、再帰は終了します。 

これは、行列を洗練するにつれて、非ゼロ構造が対角ブロックに向かって徐々に集中することを意味しますが、それは非常に特殊なフラクタルのような方法でのみです。分割するたびに、左上と右下のブロックのみが生き残り、対角以外の象限は消滅します。 

基底の順序付けは標準バイナリ (リトル エンディアン) であるため、列は入力基底状態に対応し、行は出力振幅に対応します。 古典的な行列を直接操作しているわけではありません。 代わりに、ゼロ以外の値まで正確にこのスパース パターンを生成するユニタリ回路を実装する必要があります。 

制約は非常に小さく、$2 \le N \le 5$、したがって、次の指数構造は$2^N$まだ些細なことです。 ただし、私たちは量子ゲート空間で作業しているため、実際の制約は概念的なものです。つまり、構造化された構造を表現する必要があります。$2^N \times 2^N$ブルートフォース線形代数ではなく、テンソル積推論を使用した変換。 

単純な間違いは、行列をブロック対角演算子のようなものとして解釈し、値を直接割り当てたり、振幅をシミュレートしようとしたりすることです。 量子演算は任意の行列アセンブリではなくローカル ゲートから構築する必要があるため、これは失敗します。 

もう 1 つの微妙な落とし穴は、パターンが単純な辞書編集的な方法での基底順序付けに依存すると仮定していることです。 再帰は量子ビットの分割に合わせて調整されるため、正しい解釈では、構造はフラットなインデックス パーティションではなく、(リトル エンディアン規則による) インデックスの最上位量子ビットの条件付けに対応します。 

## アプローチ

 直接的な総当たりアプローチでは、明示的に構築しようとします。$2^N \times 2^N$パターンを満たす行列を抽出し、それをゲートに分解します。 分解問題を無視して構造の検証だけを考えたとしても、行列の構築には時間がかかります。$O(4^N)$この設定では、任意のマトリックスからの一般的な合成は実行できません。 

重要な観察は、マトリックス構造がまったく恣意的ではないということです。 それは、各再帰レベルでの単一の二項決定、つまりシステムが左上のブロックにあるか右下のブロックにあるかによって完全に決定されます。 これは、量子ビット状態によって駆動されるテンソル積分解を直ちに示唆します。 

最初の量子ビットが空間のどちらの半分にいるかを制御していると解釈すると、構造は 2 つの部分空間の制御された構成になります。$|1\rangle$、私たちは完全に密集したブロック内にいます。 そうなったとき$|0\rangle$、同じルールを残りの部分に再帰的に適用します。$N-1$量子ビット。 

これにより、問題は再帰セレクターのように動作するユニタリーの構築に変わります。 左上の象限は、最初の量子ビットが存在する部分空間に対応します。$0$そして、すべての下位量子ビットは同じパターンによって変換されます。 右下の象限は、最初の量子ビットが存在する部分空間に対応します。$1$、その部分空間内で完全な混合を許可します。 非対角の象限は、その間に遷移がないため消滅します。$0$-亜空間と$1$-反対方向の部分空間。 

したがって、この構築は、同じ操作を再帰的に構築することになります。$N-1$量子ビットを取得し、それを最も重要な量子ビットによって制御されるブロック対角拡張と組み合わせます。 これは当然、制御された操作を使用して実装されます。再帰は、下位量子ビットに同じ変換を適用し、次に制御量子ビットが 1 である部分空間に完全な混合を追加することによって実装されます。 

以来$N \le 5$、単純なループのような展開で再帰の深さを明示的に実装できます。

 ## アルゴリズムのチュートリアル

 最下位量子ビットから再帰的にユニタリーを構築します。 

1. 最後の量子ビット (または同等に、選択されたピボット量子ビット) を、行列を 2 つの半分に分けるコントロールとして扱います。 基底状態は順序付けの最上位ビット 1 つだけ異なるため、これはブロック構造と一致します。 
2. もし$N = 1$、行列表現に非ゼロのエントリを生成する単一の量子ビットに自明でないユニタリーを適用します。 アダマール ゲートはすべてのエントリがゼロ以外であることを保証するため、十分です。 
3. のために$N > 1$、最初に最後の操作に対して必要な操作を再帰的に構築します。$N-1$量子ビット。 これにより、左上の象限が必要に応じて同じ構造を確実に継承します。 
4. その後、建設を完全に延長します。$N$-制御量子ビットが存在する部分空間に制御混合を適用することによる量子ビットシステム$|1\rangle$。 これにより、ブロック分離を維持しながら、右下の象限が完全にゼロ以外になります。 
5. 混合する操作の導入は避けます。$|0\rangle$-制御されており、$|1\rangle$-制御された部分空間。非対角四分円がゼロのままであることが保証されます。 

この構築は深さ優先で適用され、より小さな有効なパターンを構築してから、より大きなヒルベルト空間に埋め込まれます。 

### なぜ効果があるのか

 すべての再帰レベルで、ヒルベルト空間は 1 量子ビットによって決定される 2 つの直交部分空間に分割されます。 このアルゴリズムにより、変換によってこれら 2 つの部分空間の間で振幅が非対角方向に移動することがないことが保証されます。 内部$|0\rangle$部分空間では、変換はまさに再帰的に定義された、構造を維持した小さな行列です。 内部$|1\rangle$部分空間では、変換は完全に密になるように選択され、そのブロック内のすべてのエントリがゼロ以外であることが保証されます。 

各レベルはこの分解を独立して尊重するため、完全な行列のクロネッカー構造は帰納的に保存されます。 これにより、最終的な行列が必要な再帰象限パターンに正確に一致することが保証されます。 

## Python ソリューション

 元の問題は Q# にありますが、ロジックを明確にするために、構造を Python のような再帰的分解で表現します。```python
import sys
input = sys.stdin.readline

def solve():
    N = int(input())
    # We do not explicitly build the matrix; instead we describe structure.
    # For demonstration purposes, we output a symbolic representation.
    # In actual Q# solution, this corresponds to recursive gate construction.

    def build(n):
        if n == 1:
            return [[1, 1],
                    [1, 1]]  # all nonzero base
        prev = build(n - 1)
        size = len(prev)
        res = [[0] * (2 * size) for _ in range(2 * size)]

        # top-left: recursive copy
        for i in range(size):
            for j in range(size):
                res[i][j] = prev[i][j]

        # bottom-right: fully nonzero block
        for i in range(size, 2 * size):
            for j in range(size, 2 * size):
                res[i][j] = 1

        return res

    mat = build(N)
    for row in mat:
        print(*row)

if __name__ == "__main__":
    solve()
```実際の Q# 実装では、この再帰行列は、同じ演算を下位量子ビットに再帰的に適用し、その後、最高位量子ビットに対して制御されたフルミキシング演算を使用して拡張することに対応します。 コードの重要なアイデアは、数値的な正確さではなく、構造的な分解です。再帰によって、すべてのレベルで同じ象限ルールが明示的に適用されます。 

左上の代入は、より小さいユニタリの保存に対応します。 右下の割り当ては、密な部分空間を埋めることに対応します。 他の場所にゼロを指定すると、ブロックの分離が強制されます。 

## 実用的な例

 検討してください$N = 2$。 再帰により、$4 \times 4$マトリックス。 

| ステップ | 左上 | 右下 |
 | --- | --- | --- |
 | ベース$N=1$|$\begin{bmatrix}1 & 1 \\ 1 & 1\end{bmatrix}$| - |
 | 建てる$N=2$| コピーベース | すべてのもの |

 これにより、以下が生成されます。```
1 1 0 0
1 1 0 0
0 0 1 1
0 0 1 1
```これは必要な構造と一致します。左上は基本パターンを繰り返し、右下は完全に密集しており、対角線上にないブロックはゼロです。 

ここで考えてみましょう$N = 3$。 

| ステップ | 左上の構造 | 右下の構造 |
 | --- | --- | --- |
 |$N=2$| 前の 4x4 パターン | - |
 |$N=3$| 4x4 を左上にコピー | 右下を埋める 4x4 |

 これにより、対角の象限のみがアクティブになり、左上のブロック内で再帰が継続する 8x8 行列が生成されます。 

これにより、各再帰レベルがパターンを独立して保存し、ブロック間の汚染が現れないことが確認されます。

 ## 特殊なケース

 ### N = 1 基本ケース

 のために$N=1$、行列は単一の非ゼロのエントリです。 アルゴリズムは明示的に完全にゼロ以外の値を返します。$2 \times 2$埋め込み時にベースを使用し、再帰が有効な開始点を持つことを保証します。 この構築ではそれ以上の分割は試行されないため、無効なブロック分解は発生しません。 

### 最大深さ N = 5

 で$N=5$、行列は$32 \times 32$。 各再帰レベルは行列のサイズを 2 倍にしますが、適用されるのは決定的なコピーと塗りつぶしのみです。 各レベルが独立してブロック分離を強制するため、構造は安定したままとなり、数値的不安定性や構造的ドリフトの蓄積は発生しません。 

### 非対角抑制

 よくある失敗モードは、左上と右下の部分空間の間で誤って遷移が発生することです。 再帰的な構築では、これらの部分空間を混合する操作が回避されるため、対角ブロックの外側のエントリは、キャンセルによってではなく、すべてのレベルでの構築によってゼロのままになります。
