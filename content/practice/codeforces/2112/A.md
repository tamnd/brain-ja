 ## 解決策
 ## 問題の理解

 この問題では、アリスとボブは、1 次元の直線上の 2 つの異なる点のいずれかに表示される賞品を目指して競争しています。 アリスはすでに出発点を選んでいます`a`。 ボブは整数の開始点を選択したいと考えています`b`それはアリスとは違うので、2 つの場所のどちらにいても、彼はアリスよりも早く賞品に到達することができます。`x`または`y`賞品が表示されます。 任意の 2 点間の距離は、単にそれらの座標の差の絶対値です。 

入力は複数のテスト ケースを与え、それぞれが指定します`a`、`x`、 そして`y`、1 から 100 までのすべての個別の整数。出力では、テスト ケースごとにそのような点が存在するかどうかを示す必要があります。`b`存在します。 賞品の場所に関係なく、ボブが確実にアリスに勝つことができる場合、答えは「YES」、そうでない場合は「NO」です。 

厳しい制限 (すべての数値 ≤ 100 および最大 1000 のテスト ケース) を考慮すると、テスト ケースごとに必要なステップは最大 100 であるため、実行可能な範囲内のすべての整数を反復するアルゴリズムは許容されます。 ただし、完全な総当たり列挙を行わなくても、問題を推論することは可能です。 

主なエッジケースは、賞品の場所がアリスの位置をまたぐ場合に発生します。たとえば、`a = 3, x = 1, y = 5`。 このような状況では、ボブが 1 つの賞でアリスに勝つポイントを選んだ場合、もう 1 つの賞では彼女に負ける可能性があります。 両方の距離をチェックせずに中間点または賞品の 1 つを選択する単純なアプローチでは、そのような保証された位置が存在しないときに誤って「YES」と主張する可能性があります。 

## アプローチ

 単純な総当たりアプローチは、可能なすべての整数をチェックすることです。`b`1 ～ 100 (除く)`a`) 両方の賞の位置について、`|b - x| < |a - x|`そして`|b - y| < |a - y|`所有。 これが機能するのは、ドメインが小さく、各テスト ケースで最大 99 個のチェックが必要であり、チェックごとに 2 つの絶対差があり、実際には無視できる程度です。 実行可能なすべての開始位置についてボブの勝利条件を明示的に検証するため、総当り攻撃は機能しますが、いくぶん洗練されていません。 

最適なソリューションを見つけるための重要な洞察は、整数`b`勝利を保証するものは厳密に次の間にある必要があります`a`そして「最も遠い」賞品の場所。 両方の賞品がアリスの同じ側にある場合 (たとえば、`a < x < y`)、ボブはアリスよりも遠い賞品を越えて、それに近い賞品をスタートすることができ、両方の賞品でアリスに勝つことが保証されます。 賞品がアリスの反対側にある場合 (`x < a < y`)、ボブがどこから始めても、アリスよりも 1 つの賞に近づきますが、もう 1 つの賞からは遠くなります。 したがって、保証された位置は、両方の賞品がアリスの同じ側にある場合にのみ存在します。 これにより、問題はポジションの比較に集約されます。次の場合にボブが勝ちます。`(x - a) * (y - a) > 0`。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 これにより、評価する必要がある別々のレースの数が決まります。 
2. 各テスト ケースについて、整数を読み取ります。`a`、`x`、 そして`y`。 これらは、アリスの開始位置と 2 つの賞品の位置を定義します。 
3.積を計算する`(x - a) * (y - a)`。 この製品は、アリスに対する賞品の相対的な位置をキャプチャします。 製品が正の場合、両方の賞品はアリスの同じ側にあります。 負の場合、それらは反対側にあります。 
4. 積が正の場合は「YES」を出力します。 ボブは、遠い方の賞品に最も近い位置を選択し、アリスに両方に勝つことを保証できます。 
5. それ以外の場合は、「NO」を出力します。 ボブがアリスより両方の賞に近づくことを保証する単一の整数の開始位置はありません。 

なぜ機能するのか: 不変条件は、次の符号であるということです。`(x - a) * (y - a)`幾何学的配置を完全にエンコードします。 肯定的とは、両方の賞品がアリスの左側または右側にあり、両方に早く到達するために単一の開始点が存在することを意味します。 ネガティブとは、それらがアリスにまたがっており、ボブが両方の賞に同時に近い位置を選択することが不可能であることを意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, x, y = map(int, input().split())
    if (x - a) * (y - a) > 0:
        print("YES")
    else:
        print("NO")
```コードは最初にテスト ケースの数を読み取ります。 各テスト ケースについて、アリスの開始点と 2 つの潜在的な賞の位置を表す 3 つの整数を解析します。 コアロジックは、製品を使用しているアリスに対して両方の賞品が同じ側にあるかどうかをチェックします。`(x - a) * (y - a)`。 Codeforces は「YES」/「NO」を受け入れるため、デフォルトでは出力は即時に行われ、大文字と小文字は区別されません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(sys.stdin.readline())
    for _ in range(t):
        a, x, y = map(int, sys.stdin.readline().split())
        if (x - a) * (y - a) > 0:
            output.append("YES")
        else:
            output.append("NO")
    return "\n".join(output)

# Provided samples
assert run("3\n1 3 4\n5 3 1\n3 1 5\n") == "YES\nYES\nNO", "sample 1"

# Custom cases
assert run("2\n2 3 4\n2 1 3\n") == "YES\nNO", "prizes on same side vs opposite side"
assert run("1\n50 51 52\n") == "YES", "consecutive numbers, all on one side"
assert run("1\n50 49 48\n") == "YES", "consecutive numbers on the other side"
assert run("1\n50 49 51\n") == "NO", "prizes straddle Alice"
assert run("1\n1 2 100\n") == "NO", "extreme values, straddling"
```| テスト入力 | 期待される出力 | 検証内容 |

 | 2 3 4 | はい | Both prizes on same side |
 | 2 1 3 | いいえ | Prizes on opposite sides |
 | 50 51 52 | はい | Sequential prizes to right |
 | 50 49 48 | はい | Sequential prizes to left |
 | 50 49 51 | いいえ | 賞品はアリスにまたがる |
 | 1 2 100 | いいえ | 大きなギャップ、またがる |

 ## 特殊なケース

 If Alice is between the two prizes, such as`a = 3, x = 1, y = 5`、製品`(x - a) * (y - a) = (-2) * 2 = -4`はマイナスです。 アルゴリズムは即座に「いいえ」を出力し、単一のポジションではアリスに両方の賞品を勝ち取ることができないことを正しく反映しています。 両方の賞品がアリスの右側にある場合 (`a = 1, x = 3, y = 4`)、積は正であり、アルゴリズムは「YES」を出力し、ボブが正しく選択できるようにします。`b = 4`勝利を保証するために。 これらのケースは、製品テストが跨ぎ賞品構成と単方向賞品構成の両方を確実に処理することを示しています。
