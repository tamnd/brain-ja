 ## 解決策
 ## 問題の理解

 無向ツリーを取得し、順序付けされた頂点ペアの数が次のとおりになるように各エッジに方向を割り当てるように求められます。$(u, v)$からの指示されたパスがある場所$u$に$v$正確に等しい$n$、頂点の数。 言い換えれば、エッジの方向を設定した後、良好なペアの合計数は頂点の数と等しくなる必要があるため、すべての頂点は平均して有向パスを介して他の 1 つの頂点に正確に到達する必要があります。 そのような方向が存在しない場合は、「NO」を返します。 それ以外の場合は、「YES」と有効なエッジ方向が出力されます。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは次のツリーを生成します。$n$ノードと$n-1$エッジ。 以来$n$まで到達できます$2 \cdot 10^5$まであります$10^4$テスト ケースでは、私たちのソリューションは各ツリーをそのサイズに対して線形時間で処理する必要があります。 考えられるすべてのエッジ方向を試したり、すべてのパスを列挙したりすると、遅すぎます。 

素朴なソリューションを壊す可能性のあるエッジケースには、次のような非常に小さなツリーが含まれます。$n=2$または、単一のノードが非常に高い次数を持つツリー。 たとえば、5 つの頂点を持つ星: すべてのエッジを中心から離れる方向に向けると、中心はすべての葉に到達し、4 つの適切なペアが生成されます。 それらを中心に向けると、各葉は中心に到達し、再び 4 つの良好なペアが生成されます。 どちらの向きも正確に 5 を生成しません。これは、次数が 2 を超えるノードでは正確に達成することが不可能になる可能性があることを示唆しています。$n$良いペア。 

## アプローチ

 ブルートフォースソリューションでは、すべてのデータを生成しようとします。$2^{n-1}$エッジの方向、それぞれについて良好なペアを数え、比較します。$n$。 これは明らかに実行不可能なので、$n$できる$2 \cdot 10^5$。 

重要な洞察は、正確に取得する唯一の方法は、$n$ツリー内の良好なペアとは、葉を除くすべての頂点の次数が最大 2 である場合です。ツリーでは、次数 3 以上のノードは常に追加のパスを生成します。高次数のノードから 1 つの葉への 1 つのパスはすでにカウントされていますが、他の葉に到達する方法は複数あり、頂点ごとに複数の良好なペアが生成されます。 したがって、正確に確率を得るには、ツリーはパス (またはチェーン) でなければなりません。$n$良いペア。 

木がパスでなければならないことがわかれば、方向は簡単です。 長さのあるパス$n-1$一貫して一方向に向けることができます。 最初を除く各ノードは次のノードに到達し、正確に$n-1$良いペア。 ただし、開始ノードから次のノードに到達するノードもカウントするため、合計は正確に次のようになります。$n$良いペア。 これは問題の要件と一致します。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$そして$n-1$エッジ、隣接リストを構築します。 
3. 各ノードの次数を確認します。 いずれかのノードの次数が 2 より大きい場合は、「NO」を出力し、次のテスト ケースに進みます。 次数 3 以上のノードを持つツリーは正確に生成できません$n$良いペア。 
4. すべてのノードの次数が最大 2 の場合、ツリーはパスです。 パスの一端として機能するリーフ (次数 1 のノード) を見つけます。 
5. このリーフから DFS または BFS を実行して、パスを順番に通過します。 トラバース中に、パスに沿って親から子への方向を示すエッジを記録します。 
6. 「YES」と向きのあるエッジを出力します。 

正確さは、ツリー パス内で、最後のノードを除く各ノードがパスに続く他の 1 つのノードに正確に到達できるという不変式によって保証されます。 分岐が存在しないため、良好なペアの数が次を超えることはできません。$n$、葉から葉への向きにより、正確に$n$良いペア。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        adj = [[] for _ in range(n+1)]
        edges = []
        for _ in range(n-1):
            u, v = map(int, input().split())
            adj[u].append(v)
            adj[v].append(u)
            edges.append((u, v))
        
        deg = [len(adj[i]) for i in range(n+1)]
        if max(deg) > 2:
            print("NO")
            continue
        
        # find a leaf
        start = next(i for i in range(1, n+1) if deg[i] == 1)
        
        directed = []
        visited = [False]*(n+1)
        
        def dfs(u, parent):
            visited[u] = True
            for v in adj[u]:
                if not visited[v]:
                    directed.append((u, v))
                    dfs(v, u)
        
        dfs(start, -1)
        print("YES")
        for u, v in directed:
            print(u, v)

if __name__ == "__main__":
    solve()
```このソリューションは、ツリーを読み取り、すべてのノードの次数をチェックして、非パス ツリーを迅速に削除します。 次に、リーフから DFS を実行して、パスに沿ってノードを順序付けし、エッジの方向を記録します。 シンプルな DFS を使用すると、ノードを再訪することなく一貫してエッジを方向付けることが保証され、パスは正確に保証されます。$n$良いペア。
