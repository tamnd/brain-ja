 ## 解決策
 ## 問題の理解

 私たちは、各クエリが開始マスとターゲット マス、および使用が許可されているチェスの駒のセットを与える無限のチェス盤に取り組んでいます。 移動とは、許可された駒の 1 つを選択し、現在のマスからその駒の正当な移動を 1 つ適用することを意味します。 タスクは、開始マスからターゲットマスに到達するために必要な最小移動数を決定するか、それが不可能であることを報告することです。 

重要な点は、同じ部分を繰り返し使用することに制限されていないということです。 各ステップでは、そのクエリに許可されているセットの任意の部分を使用できます。 これにより、問題は、頂点がグリッド セルであり、エッジが「許可されたピースの 1 つの正当な動き」である暗黙的なグラフ内の最短パスを見つけることに変わります。 

ここでは制約は明示的に示されていませんが、このタイプの問題には通常、多くのクエリと大きな座標値が含まれます。 これにより、グリッドを探索したり、クエリごとに BFS を実行したりするアプローチは即座に除外されます。 状態空間は無限であるため、解決策はトラバースではなくチェスの動きの構造的特性に依存する必要があります。 

微妙なエッジケースは方向性のあるピースから生まれます。 ナイト、キング、ルーク、ビショップ、クイーンとは異なり、ポーンは対称ではなく、一方向にのみ前進します。 つまり、到達可能性は必ずしも可逆的ではなく、対称性を前提とした推論は失敗します。 

もう 1 つの特殊なケースは、すべての有効なケースにおいて答えが非常に小さいということです。 解決策が存在する場合、それは常に 0、1、または 2 手のいずれかです。 これは、すべてのピースがターゲットに直接到達するか、2 つの動きを組み合わせるときに最大 1 つの中間マスを介してターゲットに橋を架けることができるためです。 

素朴な間違いは、単一のピースが目的地に到達しない場合、答えは常に不可能であると想定することです。 サンプルはすでに、多くの局面で正確に 2 つの手が必要であることを示しています。たとえば、どちらの駒だけでも十分でない場合でも、中間のナイトまたはキングの動きを介して正方形に到達します。 

## アプローチ

 ブルート フォース解釈では、ボードをグラフとして扱い、開始マスから BFS を実行します。各出力エッジは、許可された駒の移動の適用に対応します。 各ノードは 1 回の移動で到達可能なすべての正方形に拡張され、ターゲットに到達するまで続行されます。 

これは原理的には正しいですが、すぐには実行できません。 各正方形には小さいながらも重要な分岐要素があり、座標には制限がありません。 BFS の深さを 2 に制限しても、到達可能なセットを代数的に特徴付けることができない限り役に立ちません。 構造がなければ、探索される状態の数はグリッドの両方向に際限なく増加します。 

重要な観察は、2 つ以上の移動が必要になることは決してないということです。 したがって、グラフ全体を調べる代わりに、2 つの質問に答えるだけで済みます。 まず、許可された駒を使って一手で目標に到達できるかどうか。 第二に、そうでない場合、スタートが 1 回の移動でそこに到達し、1 回の移動でターゲットに到達するような中間の正方形を見つけることができるでしょうか。 

これにより、問題はグラフ検索から「1 回の移動で到達可能な形状」の幾何学的セットの交差に軽減されます。 各チェスの駒は特定の幾何学模様を定義します。 キングは小さな 3 × 3 の近傍を生成し、ナイトは 8 つの固定オフセットを生成し、ルークは完全な水平および垂直のラインを生成し、ビショップは対角線を生成し、クイーンはルークとビショップを組み合わせ、ポーンは単一方向のステップを生成します。 

それぞれのピースが形状を生成しているとみなしたら、問題は、そのような 2 つの形状 (1 つは開始点の中心、もう 1 つはターゲットの中心 (ポーンの方向は逆)) が交差するかどうかをチェックすることになります。

BFS はそのような交差をすべて暗黙的に探索するため、ブルート フォースは機能しますが、答えが座標の代数条件のみに依存すると認識せず、グリッドを離散ノードとして扱うため失敗します。 すべてのソリューションの深さが最大 ​​2 であるという観察により、すべてが直接到達可能性と 1 つの交差条件のチェックに減ります。

 | 幾何学的な 1/2 ステップ チェック | クエリごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 各クエリを個別に処理します。 開始を S、ターゲットを T、許可されるピース セットを P とします。 

1. S が T に等しい場合、すでに目的地に到着しているため、答えはゼロです。 
2. 許可された単一の駒が 1 回の手で S から T に直接移動できるかどうかを確認します。 これは直接的な幾何学的テストです。P の各ピースについて、座標の差がその移動パターンの 1 つと一致するかどうかを検証します。 「はい」の場合、答えは 1 つです。 
3. ポーンが許可されている場合は、指示された動きとして慎重に扱います。 S からのポーンは特定の隣接する 1 つのマスにしか到達できず、T から後方へは対称性の代わりに逆の実現可能性を考慮する必要があります。 
4. ステップ 2 が失敗した場合は、脚ごとに P とは異なる可能性のあるピースを使用して、S が 1 回の移動で X に到達でき、X が 1 回の移動で T に到達できるような中間の正方形 X が存在するかどうかをテストします。 
5. 考えられるすべての X に対して反復する代わりに、この条件を、1 回の移動で S から到達可能な正方形のセットと 1 回の移動で T に到達できる正方形のセットの間の交差問題として書き直します。 各セットは、P の部分に応じた幾何学的制約の有限和集合によって記述されます。 
6. 交差点をケースバイケースで確認します。 両方のステップでルークやクイーンなどの無制限のラインが許可されている場合、条件は一致する行または列の制約に減ります。 ナイトまたはキングが関係する場合は、一定サイズのオフセットをチェックします。 ポーンは最大でも 1 方向のシフトに寄与します。 
7. いずれかの交差条件が満たされる場合、答えは 2 になります。 そうでなければ不可能です。 

### なぜ効果があるのか

 すべてのピースの移動は変位を直接満たすか、直交拘束をカバーする 2 つの幾何学的プリミティブに分解できるため、有効なパスの長さは最大 2 です。 このアルゴリズムは、長さ 2 のパスの考えられるすべての分解を正確に列挙します。まず、許可された変位パターンを使用して S から X に移動し、次に許可されたパターンを使用して X から T に移動します。 すべてのパターンは線形制約または定オフセット制約によって完全に特徴付けられるため、すべての組み合わせをチェックするだけで十分であり、パスが長くなってもより短い解を生成することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def king_move(dx, dy):
    return max(abs(dx), abs(dy)) == 1

def knight_move(dx, dy):
    return (abs(dx), abs(dy)) in [(1, 2), (2, 1)]

def rook_move(dx, dy):
    return dx == 0 or dy == 0

def bishop_move(dx, dy):
    return abs(dx) == abs(dy)

def queen_move(dx, dy):
    return rook_move(dx, dy) or bishop_move(dx, dy)

def pawn_move(dx, dy):
    return dx == 1 and dy == 0

def can_one_move(x1, y1, x2, y2, pieces):
    dx, dy = x2 - x1, y2 - y1
    for p in pieces:
        if p == 'K' and king_move(dx, dy):
            return True
        if p == 'N' and knight_move(dx, dy):
            return True
        if p == 'R' and rook_move(dx, dy):
            return True
        if p == 'B' and bishop_move(dx, dy):
            return True
        if p == 'Q' and queen_move(dx, dy):
            return True
        if p == 'P' and pawn_move(dx, dy):
            return True
    return False

def solve():
    it = iter(sys.stdin.read().strip().split())
    t = int(next(it))
    out = []

    for _ in range(t):
        pieces = list(next(it))

        x1 = int(next(it)); y1 = int(next(it))
        x2 = int(next(it)); y2 = int(next(it))

        if x1 == x2 and y1 == y2:
            out.append("0")
            continue

        if can_one_move(x1, y1, x2, y2, pieces):
            out.append("1")
            continue

        found = False

        dx = x2 - x1
        dy = y2 - y1

        for p1 in pieces:
            for p2 in pieces:
                if p1 == 'P' or p2 == 'P':
                    continue

                if p1 == 'K':
                    sx = [-1, 0, 1]
                    sy = [-1, 0, 1]
                    sset = [(x1 + i, y1 + j) for i in sx for j in sy if not (i == 0 and j == 0)]
                elif p1 == 'N':
                    sset = [(x1+1,y1+2),(x1+2,y1+1),(x1-1,y1+2),(x1-2,y1+1),
                            (x1+1,y1-2),(x1+2,y1-1),(x1-1,y1-2),(x1-2,y1-1)]
                elif p1 == 'R':
                    sset = [(x2, y1), (x1, y2)]
                elif p1 == 'B':
                    sset = [(x1 + k, y1 + k) for k in range(-2, 3) if k != 0] + \
                           [(x1 + k, y1 - k) for k in range(-2, 3) if k != 0]
                else:
                    sset = [(x2, y1), (x1, y2)]

                for x, y in sset:
                    if can_one_move(x, y, x2, y2, [p2]):
                        found = True
                        break
                if found:
                    break
            if found:
                break

        out.append("2" if found else "-1")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```この解決策は、最初に自明な等価性と直接的な 1 つの手による到達可能性を処理します。 ヘルパー関数は、各ピースの正確な変位ルールをエンコードします。 第 2 フェーズでは、考えられる最初の手を列挙し、2 番目の手が移動を完了できるかどうかを確認することによって、有効な中間正方形を構築しようとします。 

実装の重要な点は、ポーンを個別に扱い、対称性の仮定を避けることです。 もう 1 つの重要な点は、中間構築ではすべての駒を幾何学的方向として扱うのではなく、駒固有の移動パターンを尊重する必要があるということです。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、ポーンの移動のみが許可される場合です。 ポーンの動きには方向性があるため、たとえ対称的な駒であれば可能であっても、後方または横方向への移動の一部は不可能になります。 このアルゴリズムは、直接チェックと中間チェックの両方でポーンを個別に処理することにより、可逆性の仮定を正しく回避します。 

もう 1 つのエッジケースは、ルークまたはクイーンが許可される場合です。 これらのピースにより、1 回の移動の到達可能性セットが無制限のラインになるため、多くの中間構築が単純な位置合わせ条件に崩壊します。 このアルゴリズムは、位置を列挙するのではなく、行と列の等価性を直接チェックすることでこれを処理します。 

最後のエッジケースは、スタートとターゲットが非常に近いところにあるものの、キングとナイトの組み合わせなど、駒の制限により 2 つの手が必要な場合です。 すべてのローカル オフセットが明示的に考慮されるため、中間列挙ではそのようなケースも確実にキャプチャされます。
