 ## 解決策
 ## 問題の理解

 まず、種類別にグループ化された箸のコレクションから始めます。 各タイプは既知の数の同一アイテムを提供します。 満杯のプールから、交換せずに正確に 2n 個の箸をランダムに選択します。 このランダムな抽選の後、選択した箸を n 組に再編成することができ、常に可能な限り最良の方法でそれらを組み合わせます。つまり、両方の箸が同じ種類である組の数を最大化します。 

選択したマルチセット内に型が x 回出現する場合、その型から、floor(x/2) 個の有効な一致ペアを形成できます。 すべてのタイプを合計すると、一致するペアの総数は sum Floor(x_i/2) になります。 常に合計 n 個のペアを形成するため、不一致ペアの数は n からこの値を引いた数になります。 タスクは、選択のランダム性に対するこの不一致数の期待値を計算することです。 

入力サイズが十分に大きいため、ランダムな選択をシミュレートするアプローチは不可能です。 その種類は50万にも及び、箸の総数も膨大です。 これにより、サイズ 2n のマルチセットまたは列挙サブセットに対する状態ベースの動的プログラミングが除外されます。 すべてのタイプが固定の合計サイズ制約を通じて結合されているため、タイプごとに独立して確率を計算する場合でも、慎重な組み合わせ構造が必要です。 

すべての箸が同じ種類の場合、微妙なエッジケースが表示されます。 この場合、すべての選択は構造において決定的であり、すべてのペアが常に一致するため、答えはゼロになります。 型間の独立性を前提とする単純な確率論的なアプローチでは、このような縮退したケースでは不一致の確率が誤って過大評価されてしまいます。 

もう 1 つのエッジな状況は、各タイプに 1 つの箸しかない場合です。 この場合、選択されたすべてのセットは完全に不一致となり、期待される答えは正確に n になります。 パリティを正しく処理せずに型ごとのペアの形成に依存するアプローチは、floor(x/2) が常に 0 であるため、ここでは失敗します。 

## アプローチ

 単純な観点は、ランダム プロセスをシミュレートすることです。マルチセットから 2n 個の要素を均等に選択し、タイプごとの数を計算し、形成できるペアの数を計算します。 これには、サイズ 2n のすべてのサブセットを反復処理する必要があり、そのカウントは C(s, 2n) ですが、中程度の s であっても大きすぎます。 この問題では正確なモジュラー期待値が求められるため、モンテカルロ近似であっても受け入れられません。 

主要な構造の単純化は、不一致のペアが各タイプ カウントのパリティ構造によって完全に決定されることを観察することによって得られます。 タイプ i の選択された項目の数を x_i と書くと、一致するペアの数は Floor(x_i/2) になります。 この式は、x_i/2 から x_i が奇数かどうかのみに依存する補正を引いたものとして書き直すことができます。 すべてのタイプを合計すると、線形部分が崩壊し、奇数の確率に依存する項だけが残ります。 

これにより、問題は、ペアの形成に関する推論から、超幾何分布の下でサンプル数が奇数である確率をタイプごとに計算することに変わります。 その確率は、サイズ 2n のサブセットにわたる純粋な組み合わせ計数式に変換でき、確率を完全に回避できます。 残りの困難は、すべてのサブセット サイズを反復することなく、すべてのタイプのパリティで重み付けされたサブセット数を効率的に計算することです。

 ## アルゴリズムのチュートリアル

 主なアイデアは、単純なグローバル用語とパリティ イベントの合計を分離する方法で不一致数を書き直すことです。

まず、一致するペアの観点から答えを表現します。 固定選択の場合、不一致はフロアのタイプ (x_i/2) の n から合計を引いたものに等しくなります。 次に、パリティ分解を使用して、floor(x_i/2) を書き直し、各カウントを偶数と奇数の寄与に分割します。 

代数的単純化の後、期待値の合計は、選択されたサブセット内で各タイプが奇数の数を持つ確率の合計に分解されます。 これにより、期待の問題が部分集合に対する純粋な計数の問題に変換されます。 

次に、両辺に部分集合 C(s, 2n) の総数を乗算することで確率を完全に消去します。 これにより、各確率が、特定のタイプが奇数回出現するサブセットの数に変換されます。 

この時点で、型 i ごとに、型 i から選択された要素の数が奇数になるように、サイズ 2n のサブセットをカウントする必要があります。 これは、タイプ i から j 個の要素を選択し、残りから 2n-j 個の要素を選択する間の畳み込みです。 

生成関数を使用してこれを効率的に計算します。 各型 i について、必要な符号付き合計は、(1-x)^{k_i}(1+x)^{s-k_i} の x^{2n} の係数として表すことができます。 ここから、標準の偶数-奇数分解恒等式を使用して奇数カウントの寄与を抽出し、最終的な答えをグローバル二項係数と符号付き係数項の組み合わせとして表現できるようにします。 

最後に、階乗と逆階乗を事前計算して二項係数を評価し、前処理された組み合わせ値を使用して残りの畳み込み項を評価します。 

最終結果は、すべてのタイプからの寄与を合計し、確率除去によって導入されたスケーリングを考慮してモジュラー逆関数を適用することによって組み立てられます。 

なぜそれが機能するのかというと、パリティの線形化と組み合わせた期待値の線形性によって決まります。 ペアリング構造は x_i mod 2 に関して書き換えられると消滅し、正確に 2n 個の要素を選択するというグローバル制約は完全に二項畳み込み恒等式を通じて処理されます。 この変換により、すべてのサブセットが正しいパリティの重みで正確に 1 回カウントされるため、構成が過剰にカウントされたり欠落したりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, m = map(int, input().split())
    k = list(map(int, input().split()))
    
    s = sum(k)
    N = s
    
    maxN = s
    fact = [1] * (maxN + 1)
    invfact = [1] * (maxN + 1)
    
    for i in range(1, maxN + 1):
        fact[i] = fact[i - 1] * i % MOD
    
    invfact[maxN] = pow(fact[maxN], MOD - 2, MOD)
    for i in range(maxN, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD
    
    def C(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD
    
    total = C(s, 2 * n)
    
    # compute signed sum B_i = sum (-1)^j C(k_i,j) C(s-k_i,2n-j)
    # using direct convolution (conceptual; optimized implementations use NTT)
    
    B_sum = 0
    
    for ki in k:
        # naive convolution over j is shown for clarity
        # in practice this needs optimization
        si = s - ki
        Bi = 0
        for j in range(0, ki + 1):
            if j > 2 * n:
                break
            val = C(ki, j) * C(si, 2 * n - j) % MOD
            if j % 2 == 0:
                Bi = (Bi + val) % MOD
            else:
                Bi = (Bi - val) % MOD
        
        B_sum = (B_sum + Bi) % MOD
    
    inv4 = modinv(4)
    ans = (m * total - B_sum) % MOD
    ans = ans * inv4 % MOD
    
    print(ans)

if __name__ == "__main__":
    solve()
```階乗前処理は、高速な二項係数評価をサポートします。これは、ソリューションが組み合わせを繰り返しクエリするため不可欠です。 中心となる計算は、各タイプの符号付き畳み込み Bi であり、そのタイプから選択された偶数と奇数の間のパリティの不均衡をエンコードします。 最終的な集計では、グローバル合計サブセット数と符号付き項の合計を組み合わせた派生式が適用されます。 

実際の実装では、内部畳み込みループを NTT ベースの畳み込みや組み合わせ変換などのより高速な事前計算戦略に置き換えることになります。これは、単純なループがここでは数学的構造を明確にするためにのみ存在しているためです。 

## 実用的な例

 ### 例 1

 入力:

 n = 3、m = 3、k = [2、2、2]

 ここでは s = 6 で、6 つの要素をすべて選択します。 すべてのタイプは、考えられるすべての選択において偶数の項目を提供するため、どのタイプも奇数の数の不均衡を引き起こすことはできません。 導出された値の表は次のとおりです。 

| 数量 | 値 |
 | --- | --- |
 | C(s, 2n) | 1 |
 | 各B_i | 1 |
 | 合計B_i | 3 |

 最終的な式は (3・1 − 3)/4 = 0 になります。これにより、すべてのペアが完全に一致することが確認され、不一致は常にゼロになります。 

### 例 2

 入力:

 n = 5、m = 3、k = [3、3、4]

 ここでは s = 10 で、すべての要素が選択されています。 貢献度は、各タイプが奇数のピックに貢献できる方法が何通りあるかによって異なります。 パリティの組み合わせが正確に分布すると、ゼロ以外の符号付き値 B_i が得られ、最終的な式でのキャンセルにより小さな正の期待値が生成されます。 

トレース構造は次のとおりです。 

| タイプ | k_i | 投稿B_i |
 | --- | --- | --- |
 | 1 | 3 | パリティ畳み込みによって計算 |
 | 2 | 3 | タイプ 1 と対称 |
 | 3 | 4 | 異なるパリティプロファイル |

 これらの寄与を合計し、最終的な式を適用すると、予想される不一致数が得られます。 

この例は、合計サイズが固定されている場合でも、多重度の違いがパリティの不均衡にどのように影響するかを示しています。

 ## 特殊なケース

 すべての箸が 1 つのタイプに属している場合、選択されたすべてのサブセットにはタイプ間のパリティの不均衡がありません。 畳み込み項は、符号付きの合計がサブセットの合計数と等しくなるように折りたたまれ、予想どおり不一致がゼロになります。 

すべての型のサイズが 1 の場合、2n 個の異なる型を選択するたびに、一致する可能性のあるペアは生成されません。 すべての x_i が常に 0 または 1 であり、floor(x_i/2) がすべての i に対して強制的に 0 になるため、パリティ式はこれを反映します。 最終的な期待値は正確に n となり、パリティ確率から導出された式と一致します。
