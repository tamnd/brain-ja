 ## 解決策
 ## 問題の理解

 学童を集めてグループを作り、各グループがタクシーで一緒に旅行したいと考えています。 各グループには 1 ～ 4 人の子供がおり、各タクシーには最大 4 人の子供を乗せることができます。 目標は、グループを複数のタクシーに分割できないことを考慮しながら、すべてのグループを輸送するために必要なタクシーの最小数を決定することです。ただし、合計サイズが 4 つを超えない場合、複数のグループで 1 台のタクシーを共有することができます。 

入力は、グループの数と、それに続く各グループのサイズで構成されます。 出力は、必要なタクシーの最小数を表す単一の整数です。 

主な制約は、グループは最大 100,000 個まで存在でき、時間制限は 3 秒であることです。 これは、グループの数に関して線形時間よりも悪いものは許容できないことを意味します。 可能な組み合わせの数はグループの数に応じて指数関数的に増加するため、グループ化のすべての組み合わせを試みる 2 次または単純なアプローチでは時間がかかりすぎます。 

考慮すべきエッジ ケースには、すべてのグループがサイズ 4 で、グループごとに 1 台のタクシーが強制されるシナリオと、すべてのグループがサイズ 1 で、4 台のタクシーに完璧に詰め込めるシナリオが含まれます。 もう 1 つの微妙なケースは、貪欲なパッキングが自明ではないようなグループ サイズの混在です。たとえば、3 人のグループと 2 人のグループは一緒に収まらないため、組み合わせる順序が重要になります。 

## アプローチ

 ブルートフォースアプローチでは、グループのすべての順列を試し、考えられるすべての順序でグループをタクシーに詰め込もうとします。 これはすべての構成を調査するので正しいですが、n が 100,000 までの場合は計算上不可能です。 たとえ各順列チェックが線形だったとしても、順列の階乗増加によりそれは不可能になります。 

重要な洞察は、グループには 4 つの可能なサイズしかないということです。 この限られた範囲により、周波数ベースのアプローチが可能になります。 各サイズのグループが何個あるかを数えて、それらを最適に組み合わせることができます。 4 人のサイズのグループは常に単独でタクシーを占有します。 サイズ 3 のグループは、利用可能な場合はサイズ 1 のグループと組み合わせることができます。 サイズ 2 のグループは、サイズ 2 の別のグループ、またはサイズ 1 の最大 2 つのグループと組み合わせることができます。 最後に、サイズ 1 の残りのグループを 4 つに組み合わせることができます。 問題の構造により、最初に最大のグループを処理し、残りのスペースを小さなグループで埋めるという貪欲な戦略が可能になります。 これにより、より大きなグループが制限要因となり、より小さなグループを使用して制約に違反することなくギャップを埋めることができるため、最小限のタクシーが保証されます。

 ## アルゴリズムのチュートリアル

1. 1 から 4 までの各サイズのグループがいくつあるかを数えます。これにより、貪欲な決定に使用できる小さな頻度表が得られます。 
2. サイズ 4 のグループごとに個別のタクシーが必要です。 タクシーカウンターは、サイズ 4 のグループの数だけ増加します。 
3. 可能であれば、サイズ 3 の各グループをサイズ 1 のグループと組み合わせます。 ペアごとに、タクシー カウンターをインクリメントし、それに応じてサイズ 1 のグループの数をデクリメントします。 サイズ 1 のグループが十分でない場合でも、サイズ 3 のグループが個別にタクシーを占有します。 
4. サイズ 2 のグループをペアにします。 サイズ 2 のグループの各ペアは、タクシーにぴったり収まります。 サイズ 2 の奇数グループが残っている場合は、サイズ 1 の最大 2 つのグループと組み合わせることができます。 タクシーカウンターを増やし、それに応じてサイズ 1 のグループを減らします。 サイズ 1 のグループが残っていない場合は、サイズ 2 の 1 つのグループが単独でタクシーを占有します。 
5. 最後に、残りのサイズ 1 グループを処理します。 1台あたり4台のタクシーを相乗りすることができます。 タクシーの台数を、残りのタクシーの数の上限を 4 で割って計算します。 
6. これらの手順で計算されたすべてのタクシーの合計により、必要なタクシーの最小数が得られます。 

これが機能する理由: 不変なのは、各ステップで残りの最大のグループでタクシーを最大限に満たし、その後、ギャップを埋めるためにより小さなグループを使用するということです。 グループ サイズは 1 ～ 4 に制限されているため、異なる組み合わせによってタクシーの総数が削減される構成はなく、この貪欲なアプローチが最適になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
sizes = list(map(int, input().split()))

count = [0] * 5  # index 0 unused
for s in sizes:
    count[s] += 1

taxis = 0

# size 4 groups
taxis += count[4]

# size 3 groups + size 1 groups
pair_3_1 = min(count[3], count[1])
taxis += pair_3_1
count[3] -= pair_3_1
count[1] -= pair_3_1

# remaining size 3 groups
taxis += count[3]

# size 2 groups
taxis += count[2] // 2
if count[2] % 2:
    taxis += 1
    count[1] -= min(2, count[1])

# size 1 groups
if count[1] > 0:
    taxis += (count[1] + 3) // 4  # ceil division

print(taxis)
```このコードは、各サイズのグループの周波数配列を初期化します。 4 人グループに必要なタクシーの台数を直接カウントし、3 台​​と 1 台を組み合わせてスペースの使用を最適化します。 残りの 3 個と 2 個は慎重に処理され、残ったものは最後にタクシーに積み込まれます。 天井分割は残りのものを効率的に処理し、最初のカウントを除くすべての操作は定数時間であるため、線形の時間計算量が得られます。
