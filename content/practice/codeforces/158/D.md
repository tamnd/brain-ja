 ## 問題の理解

 私たちは持っています`n`円周上に均等に配置された氷の彫刻。 それぞれの彫刻には価値があり、それは肯定的または否定的です。 いくつかの彫刻を削除することはできますが、残りの彫刻は正多角形を形成する必要があります。 

彫刻は移動できないため、残りの頂点は元の円に沿って等間隔に配置する必要があります。 つまり、このままにしておくと、`k`彫刻、それから`k`分けなければなりません`n`、保持された彫刻は、一定のステップ サイズで繰り返しジャンプすることによって取得されます。 

たとえば、次の場合`n = 12`4 つの彫刻を保持すると、連続して保持される彫刻間の間隔は次のようになります。`12 / 4 = 3`。 任意の位置から開始し、12 を法とする 3 を繰り返し加算すると、1 つの有効な多角形が生成されます。 

タスクは、少なくとも 3 つの彫刻を維持しながら、保持されている彫刻値の合計を最大化することです。 

制約は十分小さいため、多くの約数を試行できます。`n`、しかし二次関数には大きすぎます。`n`。 以来`n ≤ 20000`、`O(n^2)`このソリューションでは、最悪の場合、約 4 億回の操作が実行されますが、Python では遅すぎます。 解決策`O(n * d(n))`、 どこ`d(n)`は約数の数であり、簡単に適合します。 

この問題にはいくつかの間違いがありやすいです。 

よくある間違いの 1 つは、連続したセグメントのみをチェックすることです。 残りの彫刻は円上で隣接する必要はありません。 

考慮する：```
8
1 2 -3 4 -5 5 2 3
```最良の答えは、2 つおきの彫刻を維持することで得られます。```
2 + 4 + 5 + 3 = 14
```連続サブアレイのアプローチでは、この構造が完全に欠落します。 

もう 1 つの間違いは、残りのポリゴンには少なくとも 3 つの頂点が必要であることを忘れていることです。 

例：```
6
100 -1 100 -1 100 -1
```3つだけ残しておくと`100`s は有効であり、次のようになります。`300`。 2つの頂点を維持すると、次のようになります`200`, ただし2ゴンは不可です。 

循環ステップを処理するときに、さらに微妙なバグが発生します。 仮定する：```
5
1 2 3 4 5
```5 は素数であるため、唯一の有効なポリゴンはすべての彫刻を使用します。 ステップ サイズ 2 または 3 を使用しようとしても、これらのステップは 5 と互いに素であるため、すべての頂点を訪問することになります。正解は次のとおりです。`15`。 

不注意な実装では、そのようなサイクルを複数回カウントしたり、すべてのステップでより小さなポリゴンが作成されると誤って想定したりすることがあります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 彫刻のすべてのサブセットを試して、選択した位置が正多角形を形成しているかどうかを確認できます。 選択した連続する頂点間のギャップが円周上で等しい場合、サブセットは有効です。 

正多角形の定義は非常に厳密であるため、これは概念的に機能します。 残念ながら、`2^n`サブセット、`n = 30`、ましてや`20000`。 

より構造化されたブルート フォースでは、すべての有効なポリゴンが、円の周囲で固定サイズのジャンプを繰り返し実行することに対応していることが観察されます。 

ジャンプサイズが`d`。 ポジションから始める`s`、私たちは以下を訪問します：```
s, s+d, s+2d, ...
```モジュロ`n`。 

これがサイクルを形成します。 訪問した個別の頂点の数は次のようになります。```
n / gcd(n, d)
```多角形を有効にするには、少なくとも 3 つの頂点が必要です。 

これで、検索スペースが管理可能になります。 考えられるすべてのステップ サイズについて、すべての開始位置をシミュレートし、そのサイクルに沿って合計を計算できます。 

重要な観察は、同じステップ サイズによって生成されたサイクルが円を互いに素なグループに分割していることです。 もし`g = gcd(n, d)`、そうすると、まさにあります`g`異なるサイクル、それぞれの長さ`n / g`。 

任意の多角形の観点から考える代わりに、次の約数を考慮するだけで済みます。`n`。 

させて`k`保持される頂点の数になります。 それから`k`分けなければなりません`n`。 ステップ サイズは次のようになります。```
step = n / k
```あらゆる約数について`k ≥ 3`、すべての等差数列のモジュロの合計を計算します。`n`そのステップ サイズで最大値を維持します。 

数の約数の数は次のとおりです。`20000`が小さいため、総作業量はほぼ線形に留まります。

 ## アルゴリズムのチュートリアル

 1. 彫刻値の配列を読み取ります。 
2. 答えをすべての彫刻の合計として初期化します。 

これはすでにポリゴン全体を保持することに対応しており、常に許可されています。 

1. すべての約数を列挙します`k`の`n`そのような`k ≥ 3`。 

ここ、`k`残りの多角形の頂点の数を表します。 

1. 有効なそれぞれについて`k`、次を計算します。```
step = n / k
```繰り返し移動すると`step`、正確に訪問します`k`頂点に戻る前に、最初に戻ります。 

1. すべての開始位置について、`0`に`step - 1`、繰り返し加算することによって形成されるサイクルの合計を計算します。`step`。 

各開始位置により、この除数に対して 1 つの異なるポリゴン構成が生成されます。 

1. サイクル合計でグローバル最大値を更新します。 
2. 見つかった最良の値を出力します。 

### なぜ効果があるのか

 有効な残りの多角形は、元の円上に等間隔に配置された頂点で構成されている必要があります。 ポリゴンが`k`頂点の場合、連続して保持される頂点間の間隔は正確に一致する必要があります。`n / k`。 

任意の頂点から開始して、この間隔モジュロを繰り返し追加します`n`そのポリゴンの頂点を正確に生成します。 

逆に、この方法で生成されたすべてのサイクルは、すべてのギャップが等しいため、有効な正多角形を形成します。 

アルゴリズムは可能なすべての約数を列挙します`k`その間隔のすべての可能な開始位置が指定されているため、すべての有効なポリゴンが 1 回だけチェックされます。 各候補の正確な合計を計算し、最大値を維持するため、最終的な答えは最適になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    ans = sum(a)

    for k in range(3, n + 1):
        if n % k != 0:
            continue

        step = n // k

        for start in range(step):
            cur = 0
            pos = start

            for _ in range(k):
                cur += a[pos]
                pos += step

            ans = max(ans, cur)

    print(ans)

solve()
```この解決策は、有効なポリゴンの数学的構造に直接従うものです。 

外側のループは、可能なすべてのポリゴン サイズを反復します。`k`。 の約数のみ`n`等間隔の頂点が円を完全に囲む必要があるため、これらは有効です。 

固定の場合`k`、ジャンプサイズは`step = n // k`。 任意のインデックスから開始して繰り返し追加`step`1 つの候補ポリゴンの頂点を正確に訪問します。 

範囲`0 .. step-1`より大きなスタートでは同じサイクルが繰り返されるため、スタート位置には十分です。 これは重複作業を避けるための微妙な最適化です。 

最も内側のループ内で、正確に収集します`k`要素。 以来`k * step = n`、正確に終わったら開始位置に戻ります`k`ジャンプします。 

もう 1 つの詳細は、ここではモジュロ演算が不要であることです。 なぜなら`pos`増加します`step`その通り`k`回の場合、最大アクセスされたインデックスは次のとおりです。```
start + (k - 1) * step < n
```したがって、すべてのアクセスは範囲内に留まります。
