 ## 解決策
 ## 問題の理解

 長さの異なる整数のシーケンスを構築するように求められます。$n$最大要素と最小要素の差がすべての要素の合計の平方根に等しくなるようにします。 入力はテスト ケースの数を提供します$t$、各テスト ケースに対して単一の整数$n$。 出力は次の任意のシーケンスである必要があります。$n$指定された条件を満たす個別の整数。 

主な課題は、2 つの制約を同時に満たす数値を選択することです。つまり、合計は完全な 2 乗である必要があり、数値の範囲はその合計の平方根に等しくなければなりません。 整数も個別であり、次の範囲内にある必要があります。$1$そして$10^9$, これは十分な範囲です。 すべての合計$n$すべてのテスト ケースの上限は次のとおりです。$3 \cdot 10^5$したがって、効率を維持するには、アルゴリズムがテスト ケースごとにほぼ直線的な時間で実行される必要があります。 

エッジケースが発生するのは次の場合です$n = 2$。 ここで、条件は 2 つの数値に減ります。$a$そして$b$どこ$|a - b| = \sqrt{a+b}$。 たった 2 つの数値では、和と差は密接に結合しているため、次のような単純なペアを選択します。$1$そして$4$（範囲$3$、合計$5$) は機能しません。 和が完全二乗となるペアを見つける必要があります。 もう 1 つのエッジ シナリオは次のとおりです。$n$大きい、近い$3 \cdot 10^5$、可能性のあるシーケンスまたは合計を反復しようとするブルートフォースの試みは遅すぎます。 

## アプローチ

 ブルートフォースアプローチは、次のすべてのシーケンスを試すことです。$n$整数を調べて、合計が完全な二乗であり、差がその平方根に等しいかどうかを確認します。 これは原理的には正しいですが、シーケンスの数は階乗的に増加するため、まったく実用的ではありません。$n$、均等にする$n = 10$実現不可能。 のために$n$まで$3 \cdot 10^5$、ブルートフォースアプローチは完全に排除されます。 

重要な洞察は、1 つを除いてすべての要素が等しいシーケンスを選択することです。 これにより、合計と範囲を同時に制御できるようになります。 あるとします。$n-1$等しい数$x$そして1つの数字$y = x + d$。 すると範囲は$y - x = d$、合計は$(n-1)x + y = nx + d$。 合計の平方根に等しい範囲を設定すると、次のようになります。$d = \sqrt{nx + d}$。 これは単純な二次方程式に帰着します。$d$、これは直接解決できます。 小さいものを選ぶ$x$、 のような$1$、すべての数値が個別であり、許容範囲内であることを保証し、整数解が存在することを保証します。 

また、合計が完全二乗になるのに十分な大きさの 1 つの数値が後に続く連続する数値のシーケンスを構築することもできます。 たとえば、次のように選択します。$1,2,3,\dots,n-1$そして最後の数値を調整します。 このアプローチは柔軟であり、常に異なる整数を生成します。

 ## アルゴリズムのチュートリアル

 1. 基数を選択することから始めます$x$、 通常$1$、最初に$n-1$要素。 これにより、すべての要素が明確かつ小さくなり、整数のオーバーフローが回避されます。 
2. 最後の要素を次のようにします。$y = x + r$、 どこ$r$範囲です。 この場合、数列の合計は次のようになります。$(n-1)x + y = nx + r$。 必要です$r = \sqrt{nx + r}$。 
3.解決する$r = \sqrt{nx + r}$。 両辺を正方形にして取得します$r^2 = nx + r$、または同等の$r^2 - r - nx = 0$。 これは二次方程式です$r$、これは次の公式を使用して解決できます。$r = \frac{1 + \sqrt{1 + 4nx}}{2}$。 正の整数の根を選択します。 
4. もし$r$計算された値は整数ではありません。増分です$x$それまで$1 + 4nx$完全な正方形になります。 これは小規模な場合には常に成功します$x$なぜなら、シーケンスは解ける二次方程式を満たす必要があるだけだからです。 実際には、$x = 1$すべての人に役立つ$n \le 3\cdot 10^5$。 
5. シーケンスを次のように出力します。$[x, x, x, \dots, x, x+r]$、確保する$n-1$のコピー$x$に続く$x+r$。 

なぜ機能するのか: 不変条件は、範囲が正確であることです。$r$、合計は$nx + r$。 二次方程式を解くことで、$r^2 - r - nx = 0$、私たちは保証します$r = \sqrt{sum}$、条件を満たしています。 最後の数字が異なるため、すべての数字は区別されます。$r$繰り返される基数から。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        x = 1
        # Solve r^2 - r - n*x = 0
        r = (1 + int((1 + 4*n*x)**0.5)) // 2
        sequence = [x] * (n-1) + [x + r]
        print(' '.join(map(str, sequence)))

if __name__ == "__main__":
    solve()
```ソリューションはすべてのテスト ケースを読み取り、それぞれのテスト ケースを読み取ります。$n$二次根を計算します$r$直接。 基数を繰り返します$x$ $n-1$回して追加する$x+r$最後に。 整数の平方根とフロアを使用すると、常に整数が得られます。 の繰り返し$x$以下の限り区別性を保証します$r>0$。
