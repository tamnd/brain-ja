 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times m$各セルに 0 から 0 までの数字を示す時計があるグリッド。$h-1$または空です。 許可されている移動により、行または列を選択し、その行または列のすべてのクロックを 1 時間単位で進めることができます。$h$。 すべてのクロックが同じ数字を表示するような一連の動きが存在する場合、構成は解決可能です。 タスクは、部分的に塗りつぶされたグリッドについて、グリッドが解決できるように空のセルを塗りつぶす方法の数を数えることです。 

入力されたサイズから、$n$そして$m$それぞれが到達できるか$2 \cdot 10^5$すべてのグリッドの合計を上限とする$2 \cdot 10^5$。 これにより、アルゴリズムがセル数において線形になるように強制されます。$O(n \cdot m)$。 行と列にわたるネストされたループは、二次関数を避ける限り実現可能です。$n$または$m$別に。 時間数$h$と同じ大きさにすることができます$10^9$したがって、時間値を直接反復するアルゴリズムは実行不可能です。 

空のセルは最初は任意の値を取ることができるため、微妙な点が生じます。 すべてを試すという素朴なアプローチ$h^{\text{\#empty}}$割り当ては不可能です。 もう 1 つのエッジ ケースは、行または列に競合するクロックがある場合です。たとえば、行 1 に 0 と 2 があり、列 2 に 1 がある場合、不一致を検出するには慎重なチェックが必要です。 小さなグリッド、すべてのセルが空のグリッド、および 1 行または 1 列のグリッドはすべて、同じロジックで一貫して動作する必要があります。 

たとえば、2x2 グリッドの場合、```
1 -1
-1 2
```を均一にすることはできません$h = 3$行と列の既知のセルの差が法 3 で競合するためです。不注意な解決策では、空のセル (右上) に 1 を、左下) に 2 を任意に割り当てる可能性がありますが、これでは一連の行/列の移動でグリッドを統一することができなくなります。 

## アプローチ

 ブルート フォース手法では、すべての空のセルに 0 から 0 までの値が割り当てられます。$h-1$行/列の移動のシミュレーションを使用して解決可能性をチェックします。 これは原理的には正しいですが、$2 \cdot 10^5$細胞と$h$まで$10^9$、それはまったく実用的ではありません。 

重要な洞察は、問題を代数的にモデル化することです。 させて$r_i$行に適用される移動の数になります$i$そして$c_j$列の番号$j$。 次に、最終的なクロック値は、$(i,j)$は$$\text{initial}_{i,j} + r_i + c_j \equiv X \pmod{h}$$どこ$X$統一時間です。 同じ行または列にある 2 つの既知のセルを減算すると、次のような式が得られます。$$r_i + c_j - (r_i + c_k) \equiv \text{initial}_{i,j} - \text{initial}_{i,k} \pmod{h}$$または$$c_j - c_k \equiv \text{initial}_{i,j} - \text{initial}_{i,k} \pmod{h}$$システムが線形モジュロであることがわかります。$h$。 セルの各接続コンポーネント (行と列を介して接続) は、差異に関する一貫性条件を満たさなければなりません。 これは、ノードが行と列であり、エッジが差を法的に伝えるグラフを使用して効率的にモデル化できます。$h$。 1 つのノードから値を伝播する深さ優先検索により、矛盾をチェックできます。 空のセルの場合は、伝播と一致する割り当てが機能します。 

カウントに関しては、システムに一貫性がある場合、次の任意の値が使用されます。$r_0$（列0の動き）は自由に選択できます$[0, h-1]$、残りの変数が決定されます。 したがって、答えは次のとおりです。$h^{\text{\#connected components}}$、モジュロ$10^9 + 7$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(h^{n \cdot m})$|$O(n \cdot m)$| 遅すぎる |
 | 最適 |$O(n \cdot m)$|$O(n + m)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. グリッドを読み取り、行の配列を初期化します。$r[i]$とコラム$c[j]$未割り当てとして。 
2. 既知のセルを介して行と列を接続する 2 部グラフを作成します。 各エッジには必要な差分が保存されます。$(\text{row value} + \text{col value}) \equiv \text{cell value} \pmod{h}$。 
3. 未訪問の行または列ごとに、DFS を開始します。 開始ノードに任意の値(0)を代入します。 差分を使用してエッジに沿って割り当てを伝播します。 ノードにすでに値が割り当てられている場合は、それが伝播された値のモジュロと一致することを確認します。$h$。 競合が見つかった場合、コンポーネントは矛盾しているため、答えは 0 になります。 
4. 一貫した接続コンポーネントをそれぞれカウントします。 各コンポーネントは正確に許可します$h$異なるグローバル割り当て (開始ノードの値の選択) があるため、コンポーネントの数を次のように乗算します。$h$モジュロ$10^9 + 7$。 
5. 各テストケースの結果を出力します。 

機能する理由: 不変条件は、開始ノードを割り当てた後、コンポーネント内の他のすべてのノードがすべてのエッジ制約を満たさなければならないことです。 DFS は、到達可能なすべてのノードが一貫して割り当てられるか、矛盾が検出されることを保証します。 コンポーネント間にエッジがないためコンポーネントは独立しているため、選択肢が増えます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, m, h = map(int, input().split())
        grid = [list(map(int, input().split())) for _ in range(n)]
        row_vals = [None] * n
        col_vals = [None] * m
        adj = [[] for _ in range(n + m)]
        for i in range(n):
            for j in range(m):
                if grid[i][j] != -1:
                    adj[i].append((n+j, (grid[i][j]) % h))
                    adj[n+j].append((i, (grid[i][j]) % h))
        visited = [False]*(n+m)
        ans = 1
        def dfs(u):
            for v, val in adj[u]:
                if visited[v]:
                    if (vals[v] - vals[u]) % h != val:
                        return False
                else:
                    vals[v] = (val + vals[u]) % h
                    visited[v] = True
                    if not dfs(v):
                        return False
            return True
        vals = [0]*(n+m)
        for i in range(n+m):
            if not visited[i]:
                vals[i] = 0
                visited[i] = True
                if not dfs(i):
                    ans = 0
                    break
                ans = ans * h % MOD
        print(ans)
```コードは最初に行をインデックス 0..n-1 に、列を n..n+m-1 にマップして、それらを均一に処理します。 各エッジには、行と列の間で必要な差分が格納されます。 DFS は値を伝達し、競合をチェックします。 の乗算$h$各コンポーネントの は、開始ノードの値の自由な選択に対応します。 モジュロ演算は大きな結果を処理します。
