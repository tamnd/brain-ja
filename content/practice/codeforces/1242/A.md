 ## アルゴリズムのチュートリアル

 1.読む`n`入力から取得し、それをタイルの数を表す単一の整数として扱います。 
2. かどうかを確認します。`n`からのすべての整数の割り切れ性をテストすることで素数になります。`2`まで`sqrt(n)`。 このステップが必要なのは、答えは完全に次のとおりであるかどうかに依存するためです。`n`自明ではない約数を持っています。 
3. 約数が見つかった場合は、すぐに次のように結論付けます。`n`複合です。 除数が 1 つでも存在すると、位置をマージする制約が生じ、使用可能な色の数が減ります。 
4. 約数が見つからない場合は、次のように結論付けます。`n`プライムです。 この場合、以下の有効な距離はありません。`n`分割する`n`, そのため、個別のタイル間で平等制約がトリガーされず、各タイルに一意の色を割り当てることができます。 
5. 出力`n`素数の場合、それ以外の場合は出力`n // 2`これは、すべての除数制約が構造を崩壊させた後の独立したカラー クラスの数の減少を表します。 

### なぜ効果があるのか

 すべての有効な制約は、次の約数から生じます。`n`、そしてこれらの制約はインデックスを等価クラスに分割します。 もし`n`が素数の場合、制約セットはペアごとの識別に関して空であるため、各インデックスは分離されたままになります。 もし`n`が複合である場合、少なくとも 1 つの非自明な約数が存在すると、グローバルなマージ効果が導入され、それ以上のことが妨げられます。`n/2`独立した階級が生き残れなくなる。 したがって、最終的な答えは素数によってのみ決定されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input().strip())

if n == 1:
    print(1)
else:
    is_prime = True
    x = n
    i = 2
    while i * i <= x:
        if x % i == 0:
            is_prime = False
            break
        i += 1

    if is_prime:
        print(n)
    else:
        print(n // 2)
```実装は些細なケースを処理することから始まります`n = 1`、タイルが 1 つしかないため、使用できる色は 1 つだけです。 大型の場合`n`、標準的な試行除算の素数性テストを最大で実行します。`sqrt(n)`。 制約を考慮すると、これで十分です`n ≤ 10^12`。 

約数が見つかった場合、その数値を合成としてマークします。 それ以外の場合はプライムです。 

最終的な決定は構造観察から直接得られます: 素数`n`すべてのタイルを独立させたままにすることができますが、複合`n`強制的にマージして最大色数を減らします。`n // 2`。 

ここでよくある落とし穴は、すべての約数を誤って計算または列挙しようとすることです。 それは不必要であり、遅すぎます。 もう 1 つの微妙な点は、ループ条件で必ず次を使用することです。`i * i <= n`これにより、浮動小数点演算が回避され、大きな値の正確性が維持されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
