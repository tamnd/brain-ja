 ## 解決策
 ## 問題の理解

 多角形の面で構成される平面構造を構築するように求められます。各面は共有グラフ内の単純なサイクルです。 各面 i は、その境界上に正確に a_i 個の頂点を持たなければなりません。 2 つの面が接触するときは常に、頂点だけでなくエッジ全体を共有する必要があります。 目標は、接続され、複数のエッジや自己ループを持たず、1 つの面のみに属するエッジの数を最小限に抑えるような平面グラフを構築することです。これは、埋め込みの外側境界の長さを最小限に抑えることと同じです。 

これを再解釈する便利な方法は、結合していないポリゴンから開始して、それらを共有エッジに沿って接着することを考えることです。 2 つの面がエッジを共有するたびに、そのエッジは外周に寄与しなくなります。 したがって、このタスクは、隣接する面間でできるだけ多くのエッジが「ペアになる」ように面を配置することと同じです。 

制約は構造的には大規模ですが、算術的には単純です。 すべての a_i の合計は最大でも 3・10^5 であり、これは、どの構造も面の合計サイズが本質的に線形でなければならないことを意味します。 面間のペアごとの相互作用を考慮したり、グローバルな平面埋め込み検索を試みたりするアプローチは、面の数が二次関数に向かって変化するため、すぐに遅すぎます。 

すべての面が三角形の場合、微妙なエッジケースが発生します。 単純なアプローチでは、面をチェーンに接着しようとする可能性がありますが、チェーンが慎重に構築されていない場合、エッジの繰り返しが発生したり、平面性が損なわれたりする可能性があります。 もう 1 つの問題となるケースは、1 つの非常に大きなポリゴンが多数の小さなポリゴンとペアになっている場合です。 不注意な戦略は、大きな面の頂点を過剰に使用し、誤って自己交差やエッジの繰り返しを強制する可能性があります。 

隠れた主な困難は、単にグラフを構築しているのではなく、厳格な単純さの制約の下で最大限のエッジ共有構成を構築していることです。 

## アプローチ

 強引な解釈では、各面を独立したサイクルとして開始し、次に単純さと平面性を維持するエッジに沿って面のペアを繰り返し接着しようとすることになります。 平面埋め込みを維持し、すべての有効なマージを試みることを想像することもできます。 概念的には正しいですが、これには幾何学的埋め込みや動的な平面グラフ構造の維持に関する推論が必要であり、可能なアタッチメントの選択肢の数は面とエッジの数に応じて急速に増加します。 最悪の場合、各マージの決定はグローバルな平面性制約に依存し、指数関数的または少なくとも二次関数的な探索につながります。 

重要な単純化は、幾何学から二重構造へと視点を変えることによってもたらされます。 平面に面を埋め込むことを考えるのではなく、共有エッジを介して面がどのように相互に接続されるかを考えます。 共有エッジごとに、周囲がちょうど 2 だけ減ります。したがって、周囲を最小化することは、共有エッジの数を最大化することと同じです。 各面には固定数のエッジがあるため、期待できる最善の方法は、各接続で 1 つのエッジ共有ペアを使用するツリー状構造で面を接続することです。 

これにより、問題は、成長するコンポーネントに面を貪欲に「接続」し、各接続が既存の境界エッジ 1 つと新しい面のエッジ 1 つを確実に消費するように、面上に接続された構造を構築するという問題が軽減されます。 これは、利用可能な境界エッジのプールを維持し、既存のエッジを分割して新しい頂点を介して再ルーティングすることで面を段階的に挿入するという建設的な戦略を示唆しています。 

中心的な観察は、頂点を複数の面に属する「ポート」として使用して構造を表現できるということです。 各面が確実にサイクルになるように頂点を順番に作成し、面に割り当てます。連続する頂点のペアを再利用することで共有エッジが自然に生成されます。

 ## アルゴリズムのチュートリアル

 頂点を慎重に割り当てながら、単一の成長サイクル構造を再利用してすべての面を構築します。 

1. 空の頂点リストと次の未使用の頂点ラベルのカウンターから開始します。 必要な場合にのみ頂点を徐々に作成し、許容される合計を決して超えないようにするという考えです。 
2. 最初の面では、a_1 個の個別の頂点の単純なサイクルを作成します。 これにより、初期境界が確立されます。 
3. 後続の面をアタッチするために再利用する「現在のアクティブな境界エッジ」を維持します。 概念的には、このエッジは、平面性を損なうことなく新しい面を接着できる場所を表します。 
4. 次の面 i > 1 ごとに、現在の境界を取得し、その上の単一のエッジを選択します。 既存の構造と正確に 1 つのエッジを共有するサイクルを形成する、a_i - 2 つの新しい頂点の新しいパスを挿入します。 これにより、面が 1 つの共有エッジを介して確実に接続されます。 
5. 具体的には、選択した境界エッジが (u, v) の場合、新しい面の構築でそれをパスに置き換えます。 

u → x1 → x2 → ... → x_{a_i-2} → v、

 次に、共有される既存のエッジを使用して u に戻るサイクルを閉じます。 
6. エッジ (u, v) を新しい頂点を含むチェーン エッジに置き換えることにより、境界表現を更新します。 これにより、構造が平面的かつ接続された状態に保たれます。 
7. すべての面が挿入されるまで繰り返します。 

正確さは、すべての新しい面が正確に 1 つの既存のエッジに沿ってアタッチされるという事実に依存しており、新しく導入された頂点はすべて一意であり、共有端点を除いて現在の面内でのみ使用されるため、各アタッチメントは単純さを維持します。 

### なぜ効果があるのか

 不変条件は、i 個の面を処理した後の構造が、これまでに導入されたすべての面が単純なサイクルとして表される接続された平面埋め込みであり、境界が 2 つの面によってまだ共有されていないエッジで構成されることです。 各ステップでは、正確に 1 回のエッジ共有操作によって利用可能な境界が減少し、交差を導入することなく内部構造が増加します。 新しい各面は単一の既存のエッジに沿って接続され、端点を除いて頂点の再利用が導入されないため、マルチエッジや自己ループは表示されません。 各操作は既存の境界エッジに沿って面を細分することに対応するため、平面性は維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    f = int(input())
    a = list(map(int, input().split()))
    
    n = sum(a)
    print(n)
    
    # We will construct a simple chain-like embedding.
    # Maintain a running vertex label
    cur = 1
    
    # Store previous face's last vertex to glue structures
    prev_chain = []
    
    for i, k in enumerate(a):
        if i == 0:
            # first polygon: simple cycle
            face = list(range(cur, cur + k))
            cur += k
            print(*face)
            prev_chain = face
        else:
            # attach new cycle by reusing one edge of previous structure
            # pick edge (prev_chain[0], prev_chain[1])
            u, v = prev_chain[0], prev_chain[1]
            
            face = [u]
            # create new vertices
            for _ in range(k - 2):
                face.append(cur)
                cur += 1
            face.append(v)
            
            print(*face)
            
            # update prev_chain for next attachments
            prev_chain = face

if __name__ == "__main__":
    solve()
```この構築では、最初のポリゴンが基本サイクルとして保持されます。 後続のすべてのポリゴンは、1 つの既存のエッジを再利用し、概念的にそれをより長いパスに置き換えることによってアタッチされます。 印刷された面の順序によって、連続する頂点がエッジを定義することがすでに保証されており、各サイクルの最終的な閉包がその定義に暗黙的に含まれています。 

実装上の微妙な決定は、前の面の同じエッジを常に再利用することです。 これにより、完全な平面埋め込みを明示的に追跡する必要がなくなります。 この構造では、新しい頂点がそれぞれ新鮮であり、共有構造がアタッチメント エッジの端点に限定されているため、エッジが繰り返されないことが保証されます。

 ## 特殊なケース

 特殊なケースの 1 つは、面が 1 つしかない場合です。 このアルゴリズムはサイズ a_1 の 1 サイクルを出力するだけであり、接続は実行されません。 エッジの共有は不可能であるため、これは平面性と最小周囲長を自明に満たします。 

もう 1 つの特殊なケースは、すべての面が三角形である場合です。 この状況では、すべての新しい面が 1 つの既存のエッジを使用してアタッチされ、各ステップで 1 つの新しい頂点が正確に導入されます。 各三角形は共有エッジを除いて独立しており、各三角形は新しい内部構造を使用しているため、繰り返しエッジが発生しないため、この構造は依然として有効です。 

最後のエッジケースは、1 つの面が他の面よりもはるかに大きい場合です。 このアルゴリズムは、有効性を損なうことなく、すべての小さな面を同じベース エッジに接続します。 各アタッチメントは新しい頂点を使用するため、同じベース エッジを繰り返し使用しても、隣接関係は常に面ごとに異なる中間頂点によって定義されるため、複数のエッジが発生することはありません。
