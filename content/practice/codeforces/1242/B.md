 ## 解決策
 ## 問題の理解

 完全な無向グラフが与えられます。$n$頂点。 すべての頂点のペアは接続されていますが、エッジの重みは 0 または 1 の 2 つだけです。$\binom{n}{2}$エッジ、まさに$m$そのうちのエッジは重み 1 を持ち、他のすべてのエッジは暗黙的に重み 0 を持ちます。 

タスクは、このグラフの最小スパニング ツリーの合計の重みを計算することであり、明示的に構築することではありません。 スパニングツリーは常に正確に使用するため、$n-1$エッジ、目標は選択することです$n-1$欠けているエッジをウェイト 0 として自由に使用できることを考慮して、総ウェイトが可能な限り小さいエッジ。 

制約は大きいです:$n$まで可能です$10^5$、重み 1 のエッジの数は最大でも$10^5$。 グラフ自体は、それらを除いて明示的に保存されません。$m$高価なエッジ。完全なグラフを構築または横断しようとするソリューションは即座に除外されます。 すべてのエッジを暗黙的に考慮するメソッドでも、$O(n^2)$これは 1 秒の制限をはるかに超えています。 

エッジ セットは 2 次であるため、すべてのエッジに対する Kruskal のような単純な MST アルゴリズムは不可能です。 隣接関係は暗黙的かつ密であるため、Prim のアルゴリズムでさえ、特殊な構造がなければ実行できません。 

見落としがちないくつかの特殊なケース:

 いつ$m = 0$、すべてのエッジの重みが 0 であるため、スパニング ツリーの合計重みは 0 になります。少なくとも 1 つの重み 1 のエッジを想定した不注意な実装では、誤ってゼロ以外のデフォルトが返される可能性があります。 

すべての頂点が重み 0 のエッジのみを介して接続されている場合 (グラフが完成しているため常にそうなります)、すべての答えが 0 であると考えがちですが、重み 1 のエッジにより一部のコンポーネントが強制的に分離されるため、MST コストが増加する可能性があります。 

重要な点は、重み 0 のエッジがいくつかのエッジを除いた完全なグラフを形成することです。つまり、0 エッジを介した接続性は、どのペアが「1 エッジ リスト」から欠落しているかによってのみ依存します。 

## アプローチ

 ブルートフォースアプローチでは、すべての要素を含む完全なグラフを明示的に構築します。$\binom{n}{2}$エッジを作成し、それに応じて重みを割り当て、クラスカルのアルゴリズムを実行します。 MST アルゴリズムはエッジの順序のみに依存するため、これは原理的には正しいですが、規模が大きくなるとすぐに失敗します。 エッジの数は次のとおりです。$5 \cdot 10^9$いつ$n = 10^5$、保存したり並べ替えたりすることは不可能です。 

重要な観察は、重み 0 のエッジが圧倒的に豊富であり、$m$重み-1のエッジ。 エッジの観点から考えるのではなく、どの頂点が安価に接続されなければならないのかという観点から考える方が良いでしょう。 

すべての重み 1 エッジを無視すると、グラフは重み 0 エッジのみと完全に接続されるため、MST のコストは 0 になります。 重み 1 エッジの導入$(u, v)$これは、他の頂点を介して無料で接続できる 2 つの頂点間の「ペナルティ接続」として解釈できます。 コスト 1 を支払う唯一の理由は、重み 0 のエッジのみを使用して接続できないコンポーネントを接続するためにそのようなエッジを使用する必要がある場合です。 

これは補完的な視点につながります。つまり、スパニング ツリーを構築する代わりに、重み 1 のエッジが「空き接続」の数をどのように減らすかを理解しようとします。 各重み 1 エッジは、そのエンドポイント間で直接自由接続を使用することを禁止し、重み 0 エッジの補グラフに構造を効果的に刻み込みます。 

より直接的で標準的な解釈は次のとおりです。重み 1 のエッジのみで形成されたグラフを考えてみましょう。 その接続コンポーネントを次のようにします$C_1, C_2, \dots, C_k$。 各コンポーネントの内部では、頂点は高価な制約によって結び付けられています。つまり、コストを支払わずに頂点を自由に分離することはできません。 重要な事実は、その答えは次のとおりです。$k - 1$なぜなら、各コンポーネントはスーパーノードのように動作し、少なくとも$k-1$Weight-1 エッジを使用して、MST 内のこれらの制約されたグループを接続します。 

これにより、グラフ内の連結成分を見つけるという問題が軽減されます。$m$これは、DSU を使用すると、ほぼ直線的な時間で実行できます。

 | 重み 1 エッジの DSU |$O(m \alpha(n))$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 私たちは、$m$重み 1 のエッジを作成し、素の集合和集合構造を使用して頂点をグループ化します。 

1. 次のコマンドを使用して DSU を初期化します。$n$孤立した頂点。 まだ制約を適用していないため、各頂点は独自のコンポーネントとして開始されます。 これは、すべての頂点が最初は重み 0 のエッジを介して自由に接続可能であるという考えを表しています。 
2. それぞれについて$m$重み-1エッジ$(a_i, b_i)$、DSU 内のエンドポイントをマージします。 各マージは、これら 2 つの頂点がコスト 1 のエッジによって結び付けられることを意味するため、それらは同じ制約された構造に属します。 
3. すべてのエッジを処理した後、個別の DSU 代表がいくつ残っているかを数えます。 この数字を$k$。 各代表は、重み 1 のエッジのみによって形成されるグラフ内の連結成分に対応します。 
4. 最終的な答えは次のとおりです。$k - 1$。 これは、スパニング ツリーでこれらのコンポーネントを接続するときに重み 1 エッジの使用を強制される回数を反映しています。 

### なぜ効果があるのか

 DSU コンポーネントは、重み 1 のエッジを介して接続された頂点の最大セットを表します。 このような単一のセット内では、MST を形成するときに純粋に自由な構造に依存して任意に分離したり接続したりすることはできません。これは、これらの制約によって引き起こされる構造は、最適推論では単一のユニットに崩壊するためです。 

各コンポーネントがスーパーノードに圧縮されたら、残りのタスクはこれらのスーパーノードを接続することです。 欠落しているエッジはすべて元のグラフの重み 0 に対応するため、元の 1 エッジによって引き起こされる各コンポーネントのマージが効果的に柔軟性を低下させることを除いて、異なるコンポーネント間の接続は重み 0 エッジを使用して実現できます。 すべてのコンポーネントを統合するために必要な避けられない「高価なマージ」の数は、まさに$k - 1$、これらのスーパーノード上の MST 構造と一致します。 

この不変条件は、すべての重み 1 のエッジを処理した後、すべての DSU セットがコスト 1 の関係によって内部的に強制され、これらのセット上の MST がツリーのように動作するということです。$k$各エッジが 1 つの単位コストの支払いに対応するノード。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n
        self.components = n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]
        self.components -= 1

def solve():
    n, m = map(int, input().split())
    dsu = DSU(n)

    for _ in range(m):
        a, b = map(int, input().split())
        dsu.union(a - 1, b - 1)

    print(dsu.components - 1)

if __name__ == "__main__":
    solve()
```DSU 実装は、重み 1 のエッジによってリンクされた頂点の接続されたコンポーネントを維持します。 パス圧縮により、検索操作の複雑さがほぼ一定に償却され、サイズによる結合により構造が浅く保たれます。 

最後の 1 の減算は、コンポーネントをメタグラフ内のノードとして解釈することによって直接行われます。$k$コンポーネントに必要なもの$k-1$あらゆるスパニングツリーのエッジであり、そのような各接続は必要なコスト単位に対応します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import defaultdict

    class DSU:
        def __init__(self, n):
            self.p = list(range(n))
            self.sz = [1]*n
            self.c = n

        def f(self, x):
            while self.p[x] != x:
                self.p[x] = self.p[self.p[x]]
                x = self.p[x]
            return x

        def u(self, a, b):
            a, b = self.f(a), self.f(b)
            if a == b:
                return
            if self.sz[a] < self.sz[b]:
                a, b = b, a
            self.p[b] = a
            self.sz[a] += self.sz[b]
            self.c -= 1

    n, m = map(int, input().split())
    d = DSU(n)
    for _ in range(m):
        a, b = map(int, input().split())
        d.u(a-1, b-1)
    return str(d.c - 1)

 ## 特殊なケース

 重み 1 のエッジがない場合、DSU はそのまま残ります。$n$これは、すべてのエッジが無料であり、支払う必要がないという直観と一致します。 

重み 1 のエッジがすべての頂点にわたって接続されたグラフを形成すると、DSU はすべてを 1 つのコンポーネントにまとめます。 アルゴリズムは再び 0 を返します。これは、スパニング構造での強制的な高価な接続を回避する方法ですべての頂点が結合されていることを反映しています。 

重み 1 のエッジが疎で孤立している場合、各エッジは小さなコンポーネントを作成し、最終的な数は独立した制約付きグループがいくつ存在するかを反映します。 このようなグループごとに、圧縮された MST 構造内で必要な接続の数が増加し、DSU はコンポーネントのカウントを通じてこれを正確に捕捉します。
