 ## 解決策
 ## 問題の理解

 ボードは整数のグリッドであり、すべてのセルがその行と列によって識別されます。 各セルにはすでに数値が含まれており、一度に 4 つのセル (少なくとも 2 x 2 のサイズの長方形のサブグリッドの角) に影響を与える非常に特殊な変換を適用することができます。角の一方の対角線のペアは 3 を法として 1 つ増加し、もう一方の対角線のペアは 3 を法として 2 つ増加します。 

問題は、このような操作をいくつでも使用して、初期グリッドをターゲット グリッドに変換できるかどうかです。 

重要な制約は、操作が四角形の角のみに触れることです。これは、グリッドの大部分がセルごとに自由に編集できるというよりは、何らかの構造化された線形制約の下で不変であることを強く示唆しています。 これは通常、答えが明示的な一連の動きを構築するのではなく、グローバル プロパティの小さなセットに依存する問題を示しています。 

グリッドは最大 500 x 500 まで可能ですが、合計入力サイズは管理可能なため、テスト ソリューションごとに O(nm) が予想されます。 操作をシミュレートしたり、一連の変換を検索したりする試みは、1 つの操作でも O(1) ですが、可能な四角形の数は O(n^2 m^2) であるため、すぐには実行不可能になります。そのため、ブルート フォースはまったく使用できなくなります。 

明らかではない難しさは、グリッドのどのプロパティが操作によって保存されるかを理解することにあります。 不用意なアプローチでは、貪欲にセルを修正したり、局所的な修正をシミュレートしようとしますが、すべての操作が同時に 4 つの隅に影響を及ぼし、長距離の依存関係が生じるため、これは失敗します。 

典型的な失敗例は、2 x 2 のグリッドのように見えます。 から始めるとしましょう```
0 0
0 0
```そして到達したい```
1 0
0 0
```単純な考えは、唯一の四角形に演算を適用することかもしれません。 ただし、どの操作でも 2 つの対角セルを同時に変更するため、他の角に影響を与えずに 1 つの角だけを変更することは不可能です。 これは、個々の細胞の独立性が壊れていることを直ちに示唆します。 

## アプローチ

 強引な解釈では、各四角形操作を可能な動きとして扱い、そのような動きのシーケンスとして変換を表現しようとすることになります。 各移動は 4 つのセルを変更するため、状態を追跡し、ターゲット グリッドに一致するシーケンスを検索することを試みることができます。 

問題は、状態遷移を表現することさえ困難になることです。 3 を法とする n × m グリッドの構成の数は 3^(nm) で、遷移は密な陰的グラフを形成します。 州をまたいだBFSすら不可能だ。 

重要な観察は、各演算が非常に厳密な代数構造を持っているということです。 座標 (i, j) を割り当てると、すべての操作で (i1, j1)、(i1, j2)、(i2, j1)、(i2, j2) が選択され、固定パターンが追加されます。つまり、向かい合う 2 つの角は +1 mod 3 を取得し、他の 2 つの角は +2 mod 3 を取得します。 

この構造は、保存された量を探すことを示唆しています。 グリッド全体を追跡する代わりに、各役割 (正の対角線と負の対角線) で各セルが何回影響を受けるかを調べます。 このような問題における古典的なトリックは、すべてを 3 を法とする線形方程式系に還元することです。 

初期グリッドとターゲット グリッドの差について考える場合、これらの四角形演算によって差分行列を生成できるかどうかを確認したいと考えます。 重要な単純化は、すべての有効な操作を、特定の境界相互作用を除いてキャンセルするコントリビューションに分解できることです。 代数を単純化した後、唯一の独立制約は単一のグローバル不変式に縮小されます。つまり、交互パリティ構造を持つグリッド上の合計はモジュロ 3 で保存されます。 

これにより、問題は、変換されたグリッドが初期グリッドの不変式と一致するかどうかを確認することになります。 操作ではその不変条件が維持されるため、不一致があると変換が不可能になります。 不変式が一致する場合、有効な構成を実現する方法で操作を組み合わせてセルを調整できることを建設的に示すことができます。 

この構造は、四角形演算により境界条件の自由度が減少する他のグリッド変換問題に似ています。

 | --- | --- | --- | --- |
 | ブルート フォース (操作をシミュレート) | 指数 | O(nm) | 遅すぎる |
 | 不変/モジュラー分析 | O(nm) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各セルが (ターゲット[i][j] - 初期[i][j]) 3 を法とする差分グリッド d を計算します。これにより、2 つのグリッドを直接操作するのではなく、達成する必要がある内容が分離されます。 
2. 有効な演算シーケンスは、パリティ加重和に長方形の角がどのように寄与するかによって導出されるグローバル制約を保持する必要があることに注意してください。 この不変量を表す d にわたる単一の累積値を計算します。 
3. すべてのセルを反復処理し、その寄与を (i + j) % に基づいて 2 つのパリティ クラスに累積します。 2. 1 つのクラスは演算の特定のコーナーから効果的に +1 の寄与を受け取り、もう 1 つのクラスは +2 の寄与を受け取り、これは符号付き合計モジュロ 3 になります。 
4. 差分グリッドから得られた不変量をゼロと比較します。 ゼロ以外の場合、一連の操作で必要な変換を生成できません。 
5. ゼロの場合、変換が可能であることを返します。 

これが機能する理由は、許可されたすべての操作がセル値の同じ線形結合を保持する方法でグリッドを変更するためです。 したがって、到達可能な状態はすべて、この不変条件の下で同じ同値クラスに存在する必要があります。 逆に、長方形演算はその 1 つの関係によって制約される完全な解空間に及ぶため、演算はそれを満たすすべての構成を生成するのに十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = [list(map(int, input().split())) for _ in range(n)]
    b = [list(map(int, input().split())) for _ in range(n)]

    diff = 0

    for i in range(n):
        for j in range(m):
            d = (b[i][j] - a[i][j]) % 3
            if (i + j) % 2 == 0:
                diff = (diff + d) % 3
            else:
                diff = (diff - d) % 3

    print("YES" if diff % 3 == 0 else "NO")

if __name__ == "__main__":
    solve()
```このコードは、最初に問題を差分グリッドに圧縮して、すべてのセルが必要な変更を独立して表すようにします。 次に、パリティで重み付けされた合計を累積します。これは、許可されたすべての操作によって保存される不変式です。 (i + j) % 2 に基づく交互符号は、操作ルールの下で長方形の角がどのように相互作用するかをエンコードします。 最後に、結果がモジュロ 3 でチェックされます。 

重要な主な実装の詳細は、モジュロ演算の一貫した処理、特にモジュロ正規化の範囲外で減算によって負の値が生成されないことを保証することです。 パリティ分割は正確に一致する必要があります。そうでない場合、不変式が壊れて偽陰性が生成されます。 

## 実用的な例

 2×2の小さなケースを考えてみましょう。 

入力：```
1 1
1 1
0 0
```ここで差分グリッドを計算します。 

| 私 | j | | b | 差分 |
 | --- | --- | --- | --- | --- |
 | 0 | 0 | 1 | 0 | 2 |
 | 0 | 1 | 1 | 0 | 2 |
 | 1 | 0 | 1 | 0 | 2 |
 | 1 | 1 | 1 | 0 | 2 |

 次に、不変式を計算します。 

| セル | パリティ | 貢献 | 累計 |
 | --- | --- | --- | --- |
 | (0,0) | 偶数 | +2 | 2 |
 | (0,1) | 奇数 | -2 | 0 |
 | (1,0) | 奇数 | -2 | 1 (mod 3) |
 | (1,1) | 偶数 | +2 | 0 (mod 3) |

 最終結果は 0 なので、変換が可能です。 これにより、対称的な変更が四角形操作の下で相殺されることが確認されます。 

次に、1 つのセルだけが異なる場合を考えてみましょう。```
0 0
0 0

1 0
0 0
```単一の不均衡はペアのコーナー更新によってキャンセルできないため、不変量はすぐに非ゼロになります。 これは、個別の変更がグローバル制約に違反していることを示しています。

 ## 特殊なケース

 微妙なエッジ ケースは、初期グリッドとターゲット グリッド間で 1 つのセルだけが異なる場合です。 その状況では、その 1 つの差が取り消されることなく 1 つのパリティ クラスに寄与するため、アルゴリズムはゼロ以外の不変式を計算します。 すべての操作は常に対角構造のセルを変更するため、一連の操作によって単一のセルの変更を分離することはできません。 

もう 1 つのエッジ ケースは、グリッドは均一であるが、どこでも同じ値だけシフトされる場合です。 すべてのセルが変化しても、同数の偶数と奇数の寄与が互いに相殺されるため、交互パリティの合計は相殺され、不変式はゼロのままで、アルゴリズムは変換を正しく受け入れます。
