 ## 問題の理解

課題は、1 つの割り当てを構築することではなく、有効な割り当てがどれほど柔軟であるかを理解することです。 すべての有効な割り当ての中で、出現する個別のエッジの重みの数を考慮し、その数値を呼び出します。$f$、可能な最小値と最大値を決定する必要があります。$f$。 

この条件は葉から葉へのパスにのみ課されるため、ツリー構造は非常に重要です。 内部頂点は、エッジを共有する複数のパス間で一貫性を強制することにより、間接的に制約を課します。 

制約により、最大で$10^5$したがって、どの解もエッジの数が線形またはほぼ線形である必要があります。 パスや葉のペアに関する二次関数は直ちに不可能です。$\Theta(n^2)$葉のペア。 

微妙な落とし穴は、条件が頂点のすべてのペアに適用されると仮定していることです。 そうではありません。 葉のペアのみが重要です。 この区別により、制約の構造が大きく変わります。内部間のパスは、リーフを接続しない限り無関係です。 

もう 1 つのよくある間違いは、XOR 制約がグローバルに伝播することを認識せずに、エッジごとに独立してまたは貪欲に重みを割り当てようとすることです。 たとえば、単純なチェーンでは、ローカルで有効に見える交互の割り当てでも、リーフのすべてのペアがフル パスであるため、リーフ間の制約に違反する可能性があります。

代わりに、重要なのは、XOR 制約をエッジの構造制約に変換することです。 中心的な観察は、XOR パスのパリティのみが重要であり、パス上の XOR はエッジ上で加算的であるため、制約はすべての線形条件に変換されるということです。$\mathbb{F}_2$ビットごとのような動作。 ただし、重みには任意の大きな整数を使用できるため、さまざまなビットを独立して処理し、エッジごとに慎重に選択した値を割り当てることができます。 

本当の構造上の洞察は、この制約により、すべてのリーフがシステム内の端末のように動作するように強制され、すべてのリーフ間のパスがゼロ XOR に評価される必要があるということです。 これは、すべてのリーフが同じ「XOR ポテンシャル」値を共有する必要があると言っているのと同じです。 ツリーをルート化し、各頂点に値を割り当てると、$p[v]$、すると、各エッジの重みは次のようになります。$p[u] \oplus p[v]$。 リーフ条件により、すべてのリーフが同一になるように強制されます。$p$-価値観。

ここで重要な点を整理します。多様性を高めるには、次数が少なくとも 3 の頂点 (分岐点) のみが重要です。 分岐のない最大パスに沿って、すべてのエッジは最小構成で同じ値を共有できます。 多様性を最大限に高めるために、各分岐でエッジ値を分割する新しい制約を強制できます。 

最終的に、答えは非分岐次数 2 チェーンを削除することによって形成された圧縮ツリー内の「良好なエッジ」の数によって決まります。 ツリーが複数の分岐を強制するような葉の間の単純なパスでない限り、最小値は 1 です。 最大値は、事実上、分岐構造に付随するエッジの数に等しくなります。$n - \text{number of degree-2 chain compressions}$これは、エッジの数から削減可能な構造を引いた数に単純化されます。

最小値の場合、すべてのエッジに常に同じ重みを割り当てることができます。これは、2 つのリーフ間のパス上の XOR は偶数の同一値になり、パスの長さが偶数の場合にのみゼロにキャンセルされるためです。 ただし、任意の整数が許可されているため、すべてのエッジに重みを割り当てることができます。$0$XOR の意味では、2 のべき乗構造を使用するか、潜在的な割り当てを通じて各エッジがグローバルにキャンセルされるようにします。 これにより、$f_{\min} = 1$。

 ## アルゴリズムのチュートリアル

 1. すべての頂点の次数を計算し、ツリーの隣接リスト表現を構築します。 これは、エッジの多様性が変化する可能性がある構造的なボトルネックを特定するために必要です。 
2. 次数が 2 に等しくないすべての頂点を特定します。これらの頂点は、葉 (次数 1) または分岐点 (次数 3 以上) のいずれかです。 次数 2 の頂点には分岐の決定が導入されないため、これらの頂点は圧縮構造内で重要となる唯一の頂点です。 
3. 元のツリーの各エッジをトラバースし、圧縮をシミュレートします。次数 2 の頂点のチェーンを非次数 2 の頂点に到達するまでたどり、そのチェーンを縮小ツリー内の単一のエッジとしてカウントします。 このステップでは、分岐構造を維持しながら線形冗長性を削除します。 
4. この圧縮ツリー内のエッジの数は、個別の重みの可能な最大数を直接示します。これは、圧縮された各エッジが、リーフ パス全体にわたる XOR 制約に違反せずに重みを別のエッジと共有できないセグメントを表すためです。 
5. 最小値については、すべてのエッジに同じ重みを割り当てることができることに注意してください。 XOR 制約はパリティの累積にのみ依存し、一貫した潜在的な割り当てにより、すべてのリーフ間のパスが 0 に評価されるため、これは有効です。 したがって、個別の重みの最小数は常に 1 です。 

### なぜ効果があるのか

 重要な不変条件は、XOR 制約がエンドポイントのポテンシャル間の差異のみに依存するということです。 すべてのリーフが同じポテンシャルを共有するように強制されると、すべての有効な割り当ては、内部ノードの頂点ポテンシャルを自由に選択し、各エッジをエンドポイントの XOR 差として定義することに対応します。 この構造により、次数 2 チェーンの圧縮により、冗長性が削除されながらすべての制約が保持されることが保証されます。 圧縮後の独立したエッジ セグメントの数は、個別のエッジの重みを割り当てる際の自由度の数に等しく、これは個別の値の最大数を直接制限します。 最小値は、すべてのエッジの差を単一の値クラスに集約する均一な潜在的な割り当ての存在から得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    adj = [[] for _ in range(n)]
    deg = [0] * n

    for _ in range(n - 1):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        adj[a].append(b)
        adj[b].append(a)
        deg[a] += 1
        deg[b] += 1

    # minimum is always 1
    min_f = 1

    # maximum: count edges that are not inside degree-2 chains
    visited = [False] * n
    max_f = 0

    def next_node(u, p):
        for v in adj[u]:
            if v != p:
                return v
        return -1

    for i in range(n):
        if deg[i] != 2:
            visited[i] = True

    for i in range(n):
        if deg[i] != 2:
            for v in adj[i]:
                if deg[v] == 2:
                    cnt = 1
                    prev = i
                    cur = v
                    while deg[cur] == 2:
                        visited[cur] = True
                        nxt = adj[cur][0] if adj[cur][1] == prev else adj[cur][1]
                        prev, cur = cur, nxt
                        cnt += 1
                    max_f += 1

    print(min_f, max_f)

if __name__ == "__main__":
    solve()
```コードは、ツリーを読み取り、次数を保存することから始まります。これは、ソリューション全体が次数 2 の頂点を構造端点から区別することに依存しているためです。 最小の答えは 1 に固定されており、XOR 制約の下では常に均一なエッジ割り当てが可能であることを反映しています。 

最大値を得るために、コードは一種のチェーン圧縮を実行します。 これは、すべての非次数 2 頂点から開始して次数 2 チェーンを通過し、各最大チェーンを 1 つのカウントされたセグメントに折りたたみます。 このようなチェーンが横断されるたびに、それは縮小ツリー内の 1 つの独立した構造エッジを表すため、最大カウントに 1 つだけ寄与します。 

微妙な点は、各次数 2 のチェーンが 1 回カウントされるようにすることです。 トラバースは常に非次数 2 頂点から開始され、外側に進むため、チェーンは二重にカウントされません。

 ## 特殊なケース

 単一の長いパスである縮退ツリーは、2 次圧縮によってすべての構造が完全に崩壊するかどうかをテストします。 このアルゴリズムはエンドポイントからすべての次数 2 ノードを通過し、正確に 1 つのセグメントをカウントし、最大 1 を生成します。

分岐が奥深くで発生する混合ツリーにより、トラバースが内部分岐点を見逃すことがなくなります。 次数 2 以外の頂点はすべて開始点であるため、最終的にはすべての分岐が 1 回だけ探索され、セグメントのカウントの正確さが維持されます。
