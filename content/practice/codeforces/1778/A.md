 ## 解決策
 ## 問題の理解

 以下のみからなる配列が与えられます。`1`と`-1`s. タスクは、2 つの連続する要素を選択し、それらの符号を反転するという 1 つの操作を実行することです。 これを実行した後、すべての配列要素の合計を最大化したいと考えます。 入力には複数のテスト ケースがあり、それぞれに配列が含まれており、出力は各ケースで達成可能な最大合計である必要があります。 

この制約は、配列が非常に長くなり、テスト ケースあたり最大 100,000 個の要素が含まれる可能性があり、すべてのテスト ケースの合計も 100,000 に制限されることを示しています。 これは、線形よりも複雑なアルゴリズムはすべて、`n`テストケースごとに実行すると遅すぎます。 

アレイにすべてがある場合、エッジケースが発生します。`1`またはすべて`-1`s. たとえば、配列が`[1,1,1,1]`、任意の 2 つの要素を反転すると合計が減少するため、最適な動きはダメージを最小限に抑えることです。 逆に、配列が`[-1,-1]`、それらを反転すると、合計が増加します`-2`に`2`。 もう 1 つの微妙なケースは、配列にミックスが含まれているものの、連続したペアが存在する場合に発生します。`-1`または`1`端にある。 適切なペアを選択すると、最大の改善をもたらすことも、低下を防ぐこともできます。 

## アプローチ

 ブルートフォース手法では、すべてのインデックスに対して反復処理が行われます。`i`から`1`に`n-1`、フリップ`a[i]`そして`a[i+1]`、合計を計算し、最大値を追跡します。 これはすべての可能性をテストするため正しいですが、テスト ケースごとに O(n) の操作が必要であり、この問題では許容されますが、不要です。 ここでは総入力サイズが小さいため単純なアプローチが機能しますが、貪欲な観察によって簡素化できます。 

重要な洞察は、連続する数値のペアを反転すると、合計が次のように変化するということです。 ペアの場合`[x, y]`、両方を反転すると、`-x - y`。 合計の変化は、`(-x - y) - (x + y) = -2*(x + y)`。 合計を最大化するには、次のようにします。`x + y`できるだけ小さくするため、`-2*(x + y)`となると最大の増加となる。 2 つの要素の最小和は次のとおりです。`-2`、両方の場合に発生します。`-1`。 逆に最大の金額は、`2`（両方`1`s)、反転すると合計が減少します。 したがって、最適な戦略は、次のペアが存在するかどうかを確認することです。`-1, -1`; 存在する場合、そのペアを反転すると合計が 4 増加します。そのようなペアが存在しない場合は、次のペアを反転します。`1,1`または`1,-1`合計を 4 または 0 減らします。 

ペアの可能性が少ないことを考えると (`-1,-1`、`1,1`、`1,-1`、`-1,1`)、これらのパターンの配列を貪欲にチェックし、対応する変更を適用できます。

 | ペアの合計に基づく貪欲 | テスト ケースあたり O(n) | お(1) | 受け入れられ、よりシンプル |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. テスト ケースごとに、配列の長さを読み取ります。`n`そして配列`a`。 
3. 配列の初期合計を計算します。 これは反転前のベースラインです。 
4. 配列を最初の要素から最後から 2 番目の要素まで繰り返します。 インデックスごとに`i`、の合計を計算します`a[i] + a[i+1]`。 
5. この合計が`-2`（両方`-1`s)、このペアを反転すると、合計が 4 増加します。これが可能な限り最良の増加であることを記録し、他のペアではこれより大きな増加が得られないため、ループを終了します。 
6. ない場合`-1,-1`ペア、チェックする`1,1`ペア。 それらを反転すると、合計は 4 減ります。`1,-1`または`-1,1`ペアを反転すると、合計が 0 ずつ変化します。 
7. 達成可能な最良の増減を初期合計に加算し、結果を出力します。 

機能する理由: この操作は、連続する 2 つの要素にのみ影響します。 合計の変化はこれら 2 つの要素のみに依存します。 考えられる 4 つのペアを調べて、増加を最大化する (または減少を最小化する) ペアを選択することで、最適な合計が保証されます。 配列には次のものしか含まれていないため、`1`そして`-1`、構成はこれら 4 つだけなので、貪欲な選択は正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total = sum(a)
        best_change = -float('inf')
        for i in range(n-1):
            pair_sum = a[i] + a[i+1]
            change = -2 * pair_sum
            if change > best_change:
                best_change = change
            if best_change == 4:  # maximum possible, can't do better
                break
        print(total + best_change)

if __name__ == "__main__":
    solve()
```このソリューションでは、合計を 1 回計算し、連続するペアを反復処理し、反転した場合の潜在的な変化を計算し、可能な限り最大の改善を維持します。 It short-circuits once a pair of`-1,-1`これにより最大の増加が得られるため、 が見つかります。

 ## 特殊なケース

 2要素配列の場合`[1,1]`、唯一の操作はこれら 2 つの要素を反転することです。 初期合計は 2 で、反転すると合計は -2 になります。 アルゴリズムは計算します`pair_sum = 2`、`change = -4`となり、合計が -2 に正しく更新されます。 のために`[ -1, -1 ]`、反転すると合計が -2 から 2 に増加します。`[1, -1, 1, -1]`常に生産する`change = 0`, したがって、合計額は変わりません。 このソリューションは、連続する各ペアを検査し、正味の変化を最大化するペアを選択するため、このようなすべてのエッジ ケースを正しく処理します。
