 ## 解決策
 ## 問題の理解

 同じ長さの 2 つのバイナリ文字列は時間の経過とともに変化しますが、そのうちの 1 つだけが変化します。 移動するたびに、すべてのインデックスから均一に位置を選択し、その位置で最初の文字列のビットを反転します。 2番目の文字列は固定されています。 最初の文字列が初めて 2 番目の文字列と同一になるまでにどのくらいの時間がかかるかに興味があり、このときの期待値が必要です。 

プロセスを再構成する便利な方法は、絶対的な文字列について考えるのをやめ、代わりにそれらが異なる箇所のみに注目することです。 インデックスを含む不一致セットを定義すると、`a[i] != b[i]`の場合、プロセスはインデックスのサブセットに対する単なるランダム ウォークとなり、各ステップで均一に選択された単一のインデックスのメンバーシップが反転されます。 ターゲット状態は空の不一致セットです。 

したがって、対称性では位置ではなく数だけが重要であることが保証されるため、重要な入力パラメータは不一致の初期数です。 その数字を`k`。 

制約により、テスト ケースごとに線形または線形に近い解決策が強制されます。 の合計`n`すべてのテスト ケースの総和は最大 100 万であるため、ケースごとに O(n) または O(合計 n log n) の解は許容されます。 サブセットに対して状態 DP を試みたり、不一致数に対して二次推論を試みたりすることは、直ちに実行不可能になります。 

素朴だが魅力的なアプローチは、プロセスをシミュレートすることです。 各ステップで 1 つのインデックスが反転され、文字列が一致するかどうかがチェックされます。 ただし、吸収までの予想時間は任意に大きくなる可能性があり、答えは大きな素数を法として正確に計算する必要があるため、モンテカルロ シミュレーションは役に立ちません。 もう 1 つのよくある落とし穴は、不一致を独立したものとして扱い、ポジションごとの打撃時間を計算しようとすることです。これは、1 つのインデックスを反転すると、結合された方法で他の場所の不一致が修正または再導入される可能性があるため、失敗します。 

非独立性を示す小さな例は次のような場合です。`a = 000`、`b = 111`。 3 つの位置はすべて不一致ですが、1 つの不一致を修正すると、位置の同一性ではなくグローバル カウントに応じて状態が増加または減少します。 インデックスごとの分解は正確さを失います。 

## アプローチ

 ブルートフォースの観点は、不一致のインデックスのすべてのサブセットのセット上のマルコフ連鎖としてプロセスをモデル化することです。 ある状態から`k`不一致、あらゆる動きはいずれかを選択します`n`ポジション。 一致しない位置を選択すると、`k`1つ減ります。 一致する位置を選択すると、`k`1つ増えます。 したがって、遷移は次のもののみに依存します`k`、これは次の整数に対する 1 次元のランダム ウォークになります。`0`に`n`吸収状態で`0`。 

予想される打撃時間については標準的な一次方程式を書くことができます。`E[k]`、ここで、各状態は以下を含む漸化式を満たします。`E[k-1]`、`E[k]`、 そして`E[k+1]`。 このシステムを直接解くには、テスト ケースごとに O(n) が必要で、規模としてはまだ遅すぎますが、重要な構造はすでに明らかにされています。これは、カウントによってのみ決定される対称構造を持つ誕生と死亡の連鎖です。 

重要な観察は、対称性によりシステムを閉じた形式の式に折りたたむことができるということです。 すべての方程式を解く代わりに、このプロセスを、期待値が不一致の数のみに依存する単一の量を追跡するものとして解釈できます。 古典的なトリックは、漸化式を伸縮式の差に変換し、予想される時間が、不一致位置と一致位置を選択する確率によって重み付けされた調和のような合計に依存することを明らかにすることです。 

最終的な閉じた形式は大幅に簡素化されます。`k`は不一致の数、予想時間は$$\mathbb{E}[k] = n \cdot \sum_{i=1}^{k} \frac{1}{2i - 1}$$この式は、線形システムを削除し、各減少ステップが減少遷移と増加遷移の間の不均衡に基づいて逆数項に寄与することを観察することで得られます。 この導出は、最終的には、不一致パリティ層の連続的な減少に対する予想待ち時間の合計に帰着します。 

計算上、これは奇数の逆数に対する接頭辞の合計の問題となり、可能な最大値まで 1 回計算されます。`n`、テストケース全体で再利用されます。

 ## アルゴリズムのチュートリアル

 奇数の分母にわたる高調波のような値を最大まで前処理します。`n`。 

1. 不一致のカウント`k`間`a`そして`b`。 遷移確率に影響を与えるのは不一致数のみであるため、これによって状態が完全に決定されます。 
2. 配列を事前計算する`H[i]`どこ`H[i] = H[i-1] + inv(2*i - 1)`モジュロ演算の下で。 これにより、不一致削減の各「層」の累積的な寄与が構築されます。 
3. 各テスト ケースに対して、出力`n * H[k] mod M`。 の乗算`n`これは、ステップごとの確率正規化を、反転に使用できるインデックスの総数によってスケーリングすることで得られます。 

この削減が有効である理由は、プロセスは不一致の数と、不一致のカウントによってのみ進化するためです。`k`に`k-1`は、「有害な反転」と比較して「有用な反転」が発生する可能性のある方法の数に反比例する項に寄与します。 

### なぜ効果があるのか

 不一致数は誕生と消滅の連鎖を形成します。この連鎖では、遷移は、良いインデックス (不一致を減らす) を選択するか、悪いインデックス (不一致を増やす) を選択するかによってのみ決まります。 予想される打撃時間の方程式は、変数係数を使用した 2 次の線形漸化式に帰着します。 順方向差分を定義してこの漸化式を解くと、オッズの伸縮合計に変換されます。 これにより、すべてのパス分解が、`k`したがって、最終的な式は正確かつ一意です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    t = int(input())
    max_n = 0
    tests = []

    for _ in range(t):
        n = int(input())
        a = input().strip()
        b = input().strip()
        k = 0
        for i in range(n):
            if a[i] != b[i]:
                k += 1
        tests.append((n, k))
        max_n = max(max_n, n)

    inv = [0] * (2 * max_n + 2)
    for i in range(1, 2 * max_n + 2):
        inv[i] = modinv(i)

    H = [0] * (max_n + 1)
    for i in range(1, max_n + 1):
        H[i] = (H[i - 1] + inv[2 * i - 1]) % MOD

    out = []
    for n, k in tests:
        ans = n * H[k] % MOD
        out.append(str(ans))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```解決策は、各テスト ケースを単一の整数に減らすことから始まります。`k`、不一致数。 これが重要な唯一の状態変数です。 

次のステップは、モジュラー逆行列を最大で事前計算することです。`2n`、奇数の逆数なので`1/(2i-1)`が必要です。 これは、累乗の繰り返しを避けるために、グローバルに 1 回だけ実行されます。 

次にプレフィックス配列を構築します`H`累積奇数逆数の。 各エントリは、そのレベルまでのすべての不一致削減層の寄与を集約します。 

最後に、各答えは O(1) で次のように計算されます。`n * H[k]`。 の乗算`n`正規化された遷移確率からスケーリングを元のプロセスの予想ステップ数に戻します。 

微妙な実装ポイントは、逆テーブルが次のように構築されることです。`2 * max_n`なぜなら、必要な最大の奇数分母は`2n - 1`。 もう 1 つは、すべての算術演算がモジュロのままでなければならないということです。`998244353`直分数は表現できないためです。

 ## 特殊なケース

 いつ`a`そして`b`が同一の場合、不一致数はゼロであり、答えはすぐにゼロになります。`H[0] = 0`。 プレフィックス配列はゼロから始まり、それ以上の計算は必要ないため、アルゴリズムはこれを自然に処理します。 

全ての立場が異なる場合、`k = n`の場合、ソリューションは全高調波奇数プレフィックスを評価します。 すべてのステップで増加遷移と減少遷移の間で最大の対称性があり、累積和がすべての層を占めるため、漸化式の解釈が引き続き適用されます。 

非常に大きい場合`n`、事前計算により、すべての逆関数が 1 回計算され、テストごとのオーバーヘッドが O(1) を超えないことが保証されます。
