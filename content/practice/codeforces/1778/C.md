 ## 問題の理解

 2 つの同じ長さの文字列が与えられ、最初の文字列を非常に特殊な方法で変更できます。 最初の文字列の文字を変更するたびに、その位置の元の文字が特別なセットに「記録」されます。 このセットは、これまでに上書きした元の文字を追跡し、そのサイズは制限によって制限されます$k$。 

すべての変更の最後に、変更された最初の文字列と 2 番目の文字列を比較します。 それらの間で同一の部分文字列がいくつあるかを数えます。記録されたセットに追加される個別の文字の数が以下を超えないようにしながら、その数を最大化したいと考えています。$k$。 

操作を再解釈する便利な方法は、すべてのポジションが元のキャラクターを保持するか、そのキャラクターをセットに追加するコストを支払うことで「許される」ことです。 キャラクターをセットに追加すると、そのキャラクターのすべての出現を追加コストなしで自由に変更できます。 

重要な構造上の観察は、セット制約が位置ではなく文字に対してグローバルであるということです。 初期文字列には最大 10 個の異なる文字が含まれるため、実際の決定は、これらの文字のどのサブセットに予算を「費やす」かを選択することになります。 

この制約は、サブセットにわたる組み合わせ爆発がまだ実現可能であることを意味します。 最大 10 文字の場合、$2^{10} = 1024$サブセット、および$n$すべてのテストケースにわたって$10^5$、だから、$O(n \cdot 2^{10})$解決策は受け入れられます。 二次関数の何か$n$すぐに失敗してしまうだろう。 

微妙なエッジケースが現れるのは、$k = 0$。 この場合、元の値がターゲットの配置と異なる文字を変更することはできません。つまり、答えは、次の位置にのみ依存します。$a[i] = b[i]$。 不一致を自由に上書きできると想定する単純なアプローチでは、ここで不正確な結果が生成されます。 

別の例外的なケースが発生するのは、$k$すべての異なる文字をカバーするのに十分な大きさです$a$。 そうすれば、任意の位置を制限なく効果的に変更できるため、最適な結果は構造上のアライメントのみに依存します。$b$、ローカルな決定を前提とした部分的な貪欲なロジックは、グローバルな最適値を逃す可能性があります。

 ## アルゴリズムのチュートリアル

 まず、異なる文字のセットを圧縮します。$a$、決定において重要なのはそれらだけだからです。 彼らの数を数えてみましょう$m \le 10$。 

1. それぞれの異なる文字を割り当てます。$a$0 から 0 までのインデックス$m-1$。 これにより、任意のサブセットをビットマスクとして表現できるようになります。 これが機能する理由は、すべての操作が位置固有の動作ではなく、キャラクターが変更のために「アクティブ化」されているかどうかのみに依存するためです。 
2. 位置ごとに、次のことをマークする配列を事前計算します。$a[i]$等しい$b[i]$。 これにより、変更を加えずにベースラインの寄与が取得されます。 
3. 文字のすべてのサブセットを反復処理します。$a$ビットマスクを使用します。 各マスクについて、マスクに含めることを選択した文字のセットとして解釈します。$Q$。 選択文字数を超えた場合$k$、制約に違反するため、このマスクはすぐに破棄されます。 
4. 固定マスクの場合、各位置での効果をシミュレートします。$a[i]$マスクの中にあるので、それに合わせて自由に変更できます$b[i]$、その位置が「固定可能」になります。 そうでない場合、位置はロックされ、すでに等しい場合にのみ寄与します。 
5. 結果の配列をゲイン配列に変換します。ゲイン配列は、次と等しくできる場合、各位置が 1 に寄与します。$b[i]$問題は、この配列で完全にサポートされている部分文字列の数を数えることに帰着します。 
6. 左から右にスキャンし、現在の有効なセグメントの長さを維持することによって、有効な部分文字列の数を計算します。 有効なセグメントの長さを延長するたびに$L$、追加します$L$その時点で終わるすべてのサフィックス部分文字列が有効であるため、答えに戻ります。 
7. すべてのマスクの最大値を追跡します。 

中心的な考え方は、変更可能な文字を固定的に選択すると、有効性は位置に関する単純な連続構造の問題になり、部分文字列のカウントは線形累積に崩壊するということです。 

### なぜ効果があるのか

 文字の固定サブセットの場合、各位置は独立して完全に修正可能になるか、永続的に制約されます。 この独立性により、部分文字列の有効性は、部分文字列内のすべての位置が修正可能であるか、すでに一致しているかどうかにのみ依存することが保証されます。 すべての有効な終了位置が現在の連続セグメント内の有効な開始位置の数に正確に寄与するため、線形スキャンはすべての有効な部分文字列を正確にカウントします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = input().strip()
        b = input().strip()

        # compress characters of a (at most 10 distinct)
        chars = list(set(a))
        m = len(chars)
        idx = {c: i for i, c in enumerate(chars)}

        # precompute equality
        eq = [1 if a[i] == b[i] else 0 for i in range(n)]

        ans = 0

        # iterate all subsets of characters in a
        for mask in range(1 << m):
            if mask.bit_count() > k:
                continue

            # build transformed validity array
            ok = [0] * n
            for i in range(n):
                if eq[i]:
                    ok[i] = 1
                else:
                    if mask & (1 << idx[a[i]]):
                        ok[i] = 1

            # count valid substrings in ok array
            cur = 0
            total = 0
            for i in range(n):
                if ok[i]:
                    cur += 1
                    total += cur
                else:
                    cur = 0

            ans = max(ans, total)

        print(ans)

if __name__ == "__main__":
    solve()

マスクごとに、どの位置を等しくできるかを表すバイナリ配列を構築します。$b$。 位置がすでに一致している場合、その位置は常に良好です。 それ以外の場合は、そのキャラクターが選択されたマスク内にある場合にのみ有効になります。 これは、操作制約の効果を直接エンコードします。 

部分文字列をカウントするステップでは、バイナリ配列内のすべてのサブ配列の寄与をカウントするための標準的な手法、つまり長さの連続したランを使用します。$L$貢献する$L(L+1)/2$部分文字列。累計として段階的に蓄積されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n, k = map(int, input().split())
        a = input().strip()
        b = input().strip()

        chars = list(set(a))
        idx = {c:i for i,c in enumerate(chars)}
        eq = [1 if a[i]==b[i] else 0 for i in range(n)]

        best = 0
        for mask in range(1<<len(chars)):
            if mask.bit_count() > k:
                continue
            ok = [0]*n
            for i in range(n):
                if eq[i] or (mask & (1<<idx[a[i]])):
                    ok[i]=1
            cur = ans = 0
            for v in ok:
                if v:
                    cur += 1
                    ans += cur
                else:
                    cur = 0
            best = max(best, ans)

        out.append(str(best))
    return "\n".join(out)
