 ## 解決策
 ## 問題の理解

 パズル ボードを表す 3×n のグリッドが与えられます。 各セルは、禁止、自由、または特別な円でマークすることができます。 1×2 または 2×1 のタイルであるドミノは、禁止されていない 2 つのセルを正確にカバーするように配置する必要があります。 目標は、円でマークされたセルを除くすべての禁止されていないセルがカバーされるようにドミノを配置することです。すべてのドミノの配置はグリッド構造を尊重します。水平のドミノは同じ行の隣接するセルをカバーし、垂直のドミノは同じ列の隣接するセルをカバーします。 この問題では、これらのルールを満たす個別の有効なドミノ配置がいくつ存在するかを数えるよう求められます。 

入力制約は中程度です。n は最大 10^4 まで可能です。 考えられるすべてのドミノ配置またはすべてのタイリングを列挙する単純なアプローチは、n で指数関数的になるため、10^4 列では明らかに実行不可能です。 出力は 10^9+7 を法として指定する必要があり、これは答えが非常に大きくなる可能性があることを意味します。 

エッジケースは微妙です。 たとえば、列が完全に禁止されている場合、ドミノはその列に触れることができないため、アルゴリズムが「ギャップ」を正しく処理することを確認する必要があります。 もう 1 つのエッジ ケースは、有効なドミノ配置が制限されるため、円セルが連続する空きセルのブロックの中央にある場合です。 アルゴリズムが円のセルや禁止されたセルを考慮せずに盲目的にタイルを配置しようとすると、カウントしすぎたり、ドミノを不正に配置したりすることになります。 たとえば、入力```
3
...
.O.
...
```円セルは中央の列にドミノを 1 つ垂直に配置できないため、有効な配置は 1 つだけ生成する必要があります。 不注意な方法では、円のセルを誤ってカバーする複数の配置がカウントされる可能性があります。 

## アプローチ

 ブルートフォース手法では、3×n グリッドのすべてのドミノ タイリングを列挙し、それぞれについて、正確に 1 つのセル (円) が空であり、他のすべてのセルがカバーされているかどうかを確認しようとします。 1 つの列に対して、8 つの占有状態が考えられます (各行に 3 ビット: 占有または空)。 n 列の場合、つまり 8^n 個の状態となり、n=20 の場合でも天文学的に大きくなります。 したがって、n=10^4 の場合、ブルートフォース タイリングはまったく実用的ではありません。 

重要な観察は、この問題には自然な動的計画構造があるということです。 各列は、どのセルが埋められるかをエンコードする 3 ビットのマスクで表すことができます。 列 i から列 i+1 への遷移は、現在の列の状態と次の列に広がるドミノの配置にのみ依存します。 考えられるすべての「列充填」を列挙し、DP を使用して有効な構成を伝播できます。 各 DP 状態は、禁止されたセルを尊重し、最終的な配置で円のセルを空のままにして、列 i のそのマスクに到達する方法の数をカウントします。 

したがって、最適なアプローチは、列ごとにビットマスク状態を使用する DP です。 列ごとの状態の数は最大 2^3=8 です。 各列について、以前の可能なすべてのマスクと現在の列内のドミノの可能なすべての配置を繰り返し、配置が禁止されたセルに違反しない、または円を覆わない場合にのみカウントを更新します。 n≤10^4 の場合、8×8×n≈6.4×10^5 の遷移が実現可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(3n)) | O(2^(3n)) | 遅すぎる |
 | ビットマスクを使用した DP | O(n * 8 * 8) = O(n) | 列ごとに O(8) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 3×n グリッドを列マスクの配列としてエンコードします。 各列のマスクには 3 ビットがあります。セル i が禁止されているか、すでに占有されているとみなされる場合、ビット i は 1、それ以外の場合は 0 です。 これにより、列ごとにどのドミノ配置が許可されているかをすぐに確認できます。 
2. 各列のすべての有効な「列タイリング」を事前計算します。 すべてのドミノ配置が水平方向または垂直方向にちょうど 2 つの隣接する空きセルを使用し、禁止されたセルを覆うドミノがない場合、タイリングは有効です。 各タイリングを占有セルのビットマスクとして表します。 
3. サイズ 8 の DP 配列を初期化します。ここで、dp[mask] は、末尾が Mask=mask である現在の列まで列をタイル化する方法の数を表します。 dp[initial_mask] = 1 に設定します。ここで、initial_mask は最初の列の禁止セルをエンコードします。 
4. 列ごとに繰り返します。 可能な以前のマスク prev_mask と、禁止されたセルと重なり合うことなく現在の列に適合する可能なタイリング マスク cur_mask ごとに、 dp[cur_mask | cur_mask を更新します。 前のマスク] += dp[前のマスク]。 オーバーフローを防ぐためにモジュロ演算が適用されます。 
5. すべての列を処理した後、円のセルを空のままにするすべての dp[mask] を合計します。 この合計は、10^9+7 を法とする答えです。 
6. 答えを返します。 

機能する理由: 各ステップで、 dp[mask] は現在の列までのすべての有効な配置を正確にカウントします。 マスクの更新を合法的なドミノ配置と禁止されたセルに制限することで、カウントされたすべての配置が有効であることが保証されます。 トランジションでは隣接するセルのみが考慮されるため、すべてのドミノ配置ルールが尊重され、円のセルが最終的な合計に含まれることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input())
    grid = [input().strip() for _ in range(3)]
    
    # Convert grid columns to bitmasks
    cols = []
    circle_pos = None
    for j in range(n):
        mask = 0
        for i in range(3):
            if grid[i][j] == 'X':
                mask |= 1 << i
            elif grid[i][j] == 'O':
                circle_pos = (i, j)
        cols.append(mask)
    
    # Precompute valid fillings per column
    from functools import lru_cache
    
    @lru_cache(None)
    def valid_fillings(mask):
        fillings = []
        # Try all placements recursively
        def dfs(pos, cur_mask):
            if pos >= 3:
                fillings.append(cur_mask)
                return
            if mask & (1 << pos):
                dfs(pos + 1, cur_mask)
            else:
                # Vertical domino
                if pos < 2 and not (mask & (1 << (pos+1))):
                    dfs(pos + 2, cur_mask | (1 << pos) | (1 << (pos+1)))
                # Horizontal domino (to next column handled in dp)
                dfs(pos + 1, cur_mask | (1 << pos))
        dfs(0, 0)
        return fillings
    
    dp = [0]*8
    dp[cols[0]] = 1
    
    for j in range(n):
        ndp = [0]*8
        fillings = valid_fillings(cols[j])
        for prev_mask in range(8):
            if dp[prev_mask]:
                for fill in fillings:
                    if (fill & cols[j]) == fill:
                        new_mask = fill
                        ndp[new_mask] = (ndp[new_mask] + dp[prev_mask]) % MOD
        dp = ndp
    
    circle_mask = 1 << circle_pos[0]
    ans = 0
    for mask in range(8):
        if not (mask & circle_mask):
            ans = (ans + dp[mask]) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```コードは、各列を、禁止されたセルがマークされているビットマスクに変換します。 再帰的 DFS を使用して、すべての有効な列充填を列挙し、効率を高めるために結果をキャッシュし、DP 配列を通じてカウントを伝播します。 円セルは最後にマスクすることで明示的に処理されます。 完全に禁止されている列や最初または最後の列の円などの境界条件は、マスク ロジックによって自然に処理されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n * 8 * 8) = O(n) | 各列について、最大 8 つの以前のマスクと 8 つの可能な塗りつぶしを繰り返します。 
| スペース | 列ごとに O(8) | サイズ 8 の dp 配列を保存し、再帰的な塗りつぶしをキャッシュします。 

このソリューションは、n ≤ 10^4 の時間とメモリの制約に簡単に適合します。
