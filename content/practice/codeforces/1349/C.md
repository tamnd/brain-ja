 ## 解決策
 ## 問題の理解

 グリッドは離散時間で進化します。 各セルは 2 つの色のいずれかを持ち、その 4 つの近傍のみに基づいて各ステップを同時に更新します。 

セルは現在の状態を調べます。 隣接する色が同じ色を持たない場合、その色は変化しません。 少なくとも 1 つの隣接するものがその色と一致すると、反転します。 

このルールはローカルですが、クエリの数が多く、時間パラメータが非常に大きくなる可能性があります。$10^{18}$。 これにより、ステップを直接シミュレートすることは直ちに除外されます。 1 つのクエリでも多くの遷移を繰り返す必要があるため、時間の経過とともにグリッドを進化させるアプローチは不可能です。 

主な問題は、グリッドがセルごとに独立していないことです。 細胞の動作は近くの構造に依存し、変化は伝播します。 

一般的な失敗例は、周期的な動作を想定するのが早すぎる場合に発生します。 たとえば、交互のチェッカーボード パターンではセルが反転することはありませんが、クラスター化された領域では反転が波状に外側に伝播します。 素朴なアプローチでは、安定化するまでシミュレーションしようとするかもしれませんが、安定化時間は線形になる可能性があります。$n+m$セルあたりのサイズは全体的に大きすぎます。 

もう 1 つの微妙な問題は、クエリの独立性を前提とすることです。 各クエリは同じ進化するシステムに依存するため、事前計算ではすべてのセルを同時に処理する必要があります。 

## アプローチ

 直接シミュレーションでは、すべてのセルをスキャンしてルールを適用することで各ステップを計算します。 各反復のコスト$O(nm)$。 の値以来、$p$まで行く$10^{18}$、異なる領域が異なる時間で安定し、大域的な周期性がきれいに保持されないため、サイクルを検出することすら信頼できません。 

重要な観察は、このプロセスが、すでに少なくとも 1 つの同じ色の隣接セルを持つセルが即座に「アクティブ」になる、グラフ上のマルチソース BFS と同等であるということです。 反対の色に囲まれたセルは、均一な領域のセルとは異なる動作をします。 

時間を進めてシミュレーションするのではなく、視点を逆転させます。 各セルは、競合する隣接セルによってどれだけ早く「影響」を受けるかによって決まります。 すでに同じ色の隣接セルがあるセルは早く反転を開始しますが、孤立したセルは安定した状態を長く保ちます。 

これにより、各セルが最も早く不安定になる時間を計算することができます。 この瞬間以降、同じ色の隣接セルが少なくとも 1 つあるセルが決定的に交互に現れるため、動作は期間 2 で周期的になります。 

したがって、問題は、BFS を使用してすべてのセルの安定までの距離を事前計算し、次にクエリに応答することに帰着します。$O(1)$。 

ブルートフォースはルールに直接従うため機能しますが、次の場合には失敗します。$p$伝播はグローバルであり、クエリごとに繰り返されるため、この値は大きくなります。 BFS の削減が機能するのは、不安定な時間はローカル構造のみに依存し、クエリ数には依存しないためです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション |$O(tnm p)$|$O(nm)$| 遅すぎる |
 | BFS 事前計算 |$O(nm)$|$O(nm)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのセルについて、同じ初期色の隣接するセルが少なくとも 1 つあるかどうかを確認します。 そのようなセルを最初は「不安定」としてマークします。 これらのセルは早期に反転動作を開始します。 
2. 時刻 0 のすべての不安定なセルで BFS キューを初期化します。これは、不安定性が外側に広がるため有効です。セルは、すでに不安定な隣接セルがあるか、同じ色の影響が到達すると不安定になります。 
3. グリッド上で BFS を実行します。 各セルについて、不安定になる最小時間を計算します。 不安定性は反復ごとに 1 ステップ広がるため、これは層に伝播します。 
4. 今回の時間を配列に格納する`dist[i][j]`。 セルに到達しない場合、そのセルは永久に安定したままになります。 
5. 各クエリについて$(i, j, p)$、 比較する$p$と`dist[i][j]`。 
6. もし$p < dist[i][j]$、セルは反転を開始していないため、色は初期から変化していません。 
7. もし$p \ge dist[i][j]$、セルは交互体制にあるため、時間ごとの色$p$～のパリティのみに依存する$p - dist[i][j]$。 

不変条件は、BFS が各セルが同じ色の隣接セルの影響を受ける正確な最も早い時間を計算するということです。 その瞬間以降、更新は周期 2 で決定的かつ周期的になります。影響はタイム ステップごとに 1 層広がるため、BFS 距離は時間の発展と正確に一致します。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m, t = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    INF = 10**18
    dist = [[INF] * m for _ in range(n)]
    q = deque()

    # Step 1: find initially unstable cells
    for i in range(n):
        for j in range(m):
            for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
                ni, nj = i + di, j + dj
                if 0 <= ni < n and 0 <= nj < m:
                    if g[ni][nj] == g[i][j]:
                        dist[i][j] = 0
                        q.append((i, j))
                        break

    # Step 2: BFS propagation
    while q:
        i, j = q.popleft()
        for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
            ni, nj = i + di, j + dj
            if 0 <= ni < n and 0 <= nj < m:
                if dist[ni][nj] == INF:
                    dist[ni][nj] = dist[i][j] + 1
                    q.append((ni, nj))

    # Step 3: answer queries
    out = []
    for _ in range(t):
        i, j, p = map(int, input().split())
        i -= 1
        j -= 1

        if p <= dist[i][j]:
            out.append(g[i][j])
        else:
            diff = p - dist[i][j]
            if diff % 2 == 0:
                out.append(g[i][j])
            else:
                out.append('1' if g[i][j] == '0' else '0')

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```メモリ使用量をコンパクトにするために、グリッドは文字列として保存されます。 BFS キューは、既に同じ色の隣接セルを持つすべてのセルから開始されます。 これにより、本当に不安定な地域からのみ拡張することが保証されます。 

距離配列は、各セルが交互に切り替わり始める時間をエンコードします。 クエリ処理は定数時間です。 

よくある実装上の間違いは、時間比較を行う必要があることを忘れていることです。`p <= dist[i][j]`対厳格`<`。 正しい境界は、不安定性が始まるのです`dist`、つまり、まさにそのときに最初の反転が発生します。

 ## 特殊なケース

 完全に均一なグリッドでは、最初はすべてのセルが不安定であるため、BFS はすべての距離をゼロとしてマークします。 システムはただちに交互パリティ動作に入ります。 

チェッカーボード グリッドには同じ色の隣接がないため、すべての距離は無限のままです。 クエリは常に初期の色を返します。 

1x1 などの小さなグリッドは、不安定性を引き起こす隣接グリッドがないため反転することはなく、BFS キューは空のままで、距離は無限のままです。
