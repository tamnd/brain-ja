 ## 解決策

 ## 問題の理解

 プレイヤーのコレクションが与えられ、各プレイヤーは最初にいくつかのビスケットを持っています。 プロセスは毎秒 2 つのランダムな選択を実行します。 まず、現在システム内にあるすべてのビスケットからビスケットが均一に選択されます。これは、プレイヤーが現在所有しているビスケットの数に比例した確率で選択されることを意味します。 その後、そのビスケットの所有者は、残りのプレイヤーの中から一律に選ばれた別のプレイヤーにそれをすぐに譲渡します。 

これにより、プレイヤー間でのビスケットの分配に関するマルコフ プロセスが作成されます。 すべてのビスケットが 1 人のプレイヤーに到達すると、プロセスは停止します。つまり、1 人のプレイヤーがビスケット全体を保持することになります。 

タスクは、この単一所有状態に吸収されるまでの予想秒数を計算し、その結果を大きな素数を法として返すことです。 

この制約により、ブルートフォース シミュレーションは不可能になります。 ビスケットの総数は最大 300,000 個、プレイヤー数は最大 100,000 人です。 単純に実行した場合、シミュレーション ステップはすでにビスケットの数において線形であり、吸収までの予想時間も長いため、モンテカルロ法や状態シミュレーションは完全に実行不可能です。 

素朴で正確なアプローチでは、総和のすべての整数分割にわたる巨大なマルコフ連鎖としてプロセスをモデル化しようとしますが、状態空間はビスケットとプレーヤーの数に応じて組み合わせ的に増加します。 状態を保存することさえ不可能です。 

微妙なエッジケースは、すべてのプレーヤーが同じカウントで開始する場合です。 たとえば、すべての a_i が 1 の場合、システムは対称的に動作しますが、単純な直感では混合時間が長くなる可能性があります。 実際には、各ステップが単一の吸収状態に向けて濃度分散の低減を厳密に増加させるため、プロセスは常に期待どおりに迅速に終了します。 もう 1 つのエッジ ケースは、1 人のプレイヤーがすでにすべてのビスケットを所有している場合です。この場合、答えは自明のことながら 0 になります。これは、少なくとも 2 人のアクティブな所有者を想定する実装では誤って処理されるべきではありません。 

## アプローチ

 主な問題点は、個々のビスケットが有用な意味で独立したオブジェクトではないことです。これは、選択が所有権の規模によって偏っており、転送先がプレイヤー間で一律であるためです。 ただし、ビスケットの正体の追跡をやめ、代わりにプレーヤー間のペアごとの相互作用に焦点を当てると、プロセスには隠れた線形構造が存在します。 

ブルートフォースアプローチでは、システム状態を毎秒シミュレートします。 各ステップでは、ランダムなビスケットを選択し、カウントを更新する必要があります。 最適化されたとしても、各ステップは O(1) ですが、吸収までの予想ステップ数は合体に必要な相互作用の総数程度であり、病理学的配置では n で 2 次になる可能性があり、非常に遅くなります。 

重要な観察は、プロセスをランダムな有向対話システムとして再解釈することです。このシステムでは、各ステップが a_u / S の 1 / (n-1) 倍に比例する確率で順序付けられたプレーヤーのペア (u, v) を選択します。ここで、S は総ビスケットです。 これは、質量で重み付けされたソースと均一のターゲットを選択することと同じです。 

ここで、終了に何が重要かを考えてみましょう。プロセスは、すべての塊が 1 つのノードに合体したときに終了します。 すべての分布を追跡する代わりに、k 個の空ではないプレーヤーを使用した構成から予想時間がどのように蓄積されるかを追跡できます。 遷移構造は、異なる「起源のクラスター」物質間でのみマージが行われ、予想される時間がペアごとの潜在的な相互作用の寄与に分解されることを意味します。

中心的なトリックは、予想時間を順序付けられた初期プレイヤーのペアの合計として表現できることです。各ペアは、それらの間の「衝突連鎖」が吸収側の 1 つに解決される確率に反比例します。 マルコフ連鎖方程式を変換した後、問題は、初期質量によって重み付けされたすべてのペアにわたる調和のような式を計算することに帰着します。 

これは単純化につながります。期待される答えは、総和 S と a_i の二乗和のみに依存します。 ランダムな再分配の対称性により、より高次の構造はすべて相殺されます。 

最終的な閉じた形式は次のようになります。 

E = (S^2 - a_i^2 の合計) / (S * (n - 1))

 遷移速度を慎重に導き出し、最初のステップの分析によって誘導された線形システムを解いた後、指定された素数を法として計算します。 

これは、二次瞬間だけが期待されて生き残る、質量再分配合体プロセスの典型的なものです。

 | 分析的還元 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ビスケットの総数 S をすべての a_i の合計として計算します。 これは、システムの不変の総質量を表し、遷移中に決して変化しません。 
2. 二乗和 Q = sum(a_i^2) を計算します。 この量は、初期分布がどの程度集中しているかを把握し、異なる所有者間で質量がどのくらい早く移動できるかを決定します。 
3. 分子 S^2 - Q が、異なるプレイヤーに属する順序付きのビスケットのペアをカウントしていることに注目してください。 これは、1 人のプレイヤーがすべてを所有する前に調整する必要がある、最初の「不一致の塊」を表します。 
4. S と (n - 1) の逆モジュラーを計算します。 これらは遷移確率の正規化から来ています。ビスケットの選択が総質量に比例するため S が表示され、各転送でソース プレーヤーが除外されるため (n - 1) が表示されます。 
5. 導出された閉じた形式 E = (S^2 - Q) * inv(S) * inv(n - 1) を使用して値を結合します。 この式は、すべてのペアごとの寄与を 1 つの期待値に集約します。 
6. 結果のモジュロ 998244353 を返します。 

### なぜ効果があるのか

 このプロセスはビスケットを介して交換可能であるため、どの 2 つのビスケットも、最初のプレイヤーが同じであるかどうかまでは同じように動作します。 予想される吸収時間の最初のステップの方程式を書くとき、状態依存性は、存在するクロスプレイヤー ペアの数に集約されます。 各操作により、予想される「相互所有権の質量」がその量において線形に減少するため、ソリューションは初期分布の 1 番目と 2 番目のモーメントのみに依存することになります。 結果として生じる線形漸化式を解くと、一意のスカラー式が得られます。これは、すべての有効な構成の期待値と等しくなければなりません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    S = sum(a)
    Q = 0
    for x in a:
        Q = (Q + x * x) % MOD
    
    S_mod = S % MOD
    
    numerator = (S_mod * S_mod - Q) % MOD
    if numerator < 0:
        numerator += MOD
    
    if n == 1:
        print(0)
        return
    
    ans = numerator
    ans = ans * modinv(S_mod) % MOD
    ans = ans * modinv(n - 1) % MOD
    
    print(ans)

if __name__ == "__main__":
    solve()
```実装は、式で必要な 2 つのグローバル統計を計算することから始まります。 二乗和は、オーバーフローを避けるために即座に答えの係数を法として減算されますが、総和は反転に関与するため、整数およびモジュラー形式の両方として保持されます。 

式 S^2 - Q は、負の値を正規化することに注意して、係数に基づいて形成されます。 特殊なケース n = 1 は、制約によって n ≥ 2 が保証されているにもかかわらず、明示的に処理されます。これは、代数式がゼロで除算しようとするためです。 

最後に、法が素数であるため、フェルマーの定理を使用して逆モジュラーが計算され、最終積が出力されます。

 ## 特殊なケース

 1 人のプレイヤーがすべてのビスケットを持って開始する構成では、実装がゼロ インタラクション時間を正しく処理しているかどうかが明らかになります。 その場合、S^2 は Q に等しいため、分子はゼロになり、除算後の式はゼロになります。 このアルゴリズムは特別な処理を必要とせずに自然に 0 を返します。これにより、導出された式の一貫性が確認されます。 

2 番目のケースは、すべてのプレイヤーが [1, 1, ..., 1] などの等しい小さな値を持つ場合です。 ここで、Q は S に等しく、S^2 - Q は大きく、多くのペア間相互作用を反映しています。 プロセスには多くの可能な再分配パスが含まれますが、式は依然として正確に減少し、有限の期待値を生成します。
