 ## 解決策
 ## 問題の理解

 _good sequences_ と呼ばれる特別なクラスの整数シーケンス内の数値の出現を数えるように求められます。 長さのシーケンス`n`すべての数値について、次の場合に良好であると見なされます`k > 1`と表示される場合は、少なくとも 1 回は発生します。`k-1`シーケンスの前のどこか。 目標は、1 から 1 までの各数値を計算することです。`n`、すべての適切な長さのシーケンスの中で何回出現するか`n`。 これらのカウントを 998244353 を法として出力します。 

入力は単一の整数です`n`、シーケンスの長さ。 出力は次のリストです。`n`整数 (i 番目の数値は合計回数)`i`適切な長さのすべてのシーケンスにわたって発生します`n`。 

制約が示すのは、`n`すべてのシーケンスを生成する単純なアプローチでは、少なくとも O(n^n) の複雑さになりますが、これは完全に実行不可能です。 これは、総当たりの列挙ではなく、動的プログラミングまたは組み合わせアプローチが必要であることを意味します。 エッジケースには以下が含まれます`n = 1`、ここで唯一のシーケンスは`[1]`、の出力を生成します`1`、およびすべての数字が繰り返されるシーケンス。`[1,1,1,...]`。 不用意に数えると、先行するものがなければ数値を導入できないシーケンスを数え間違える可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、長さのすべてのシーケンスが生成されます。`n`そして「良い」プロパティをチェックします。 各シーケンスについて、すべての数値を反復処理し、すべての数値が次のことを確認することを確認します。`k > 1`持っています`k-1`その前に。 有効なシーケンスごとに、各数値の出現回数をカウントします。 このアプローチの時間計算量は O(n^n * n) であり、n が 5000 までの場合は非現実的です。 

重要な洞察は、プロパティが _incremental_: any number であることを観察することで得られます。`k`以下の場合にのみ表示できます`k-1`以前どこかで登場しました。 これにより、動的プログラミングを使用してシーケンスをモデル化できるようになります。 定義する`dp[i][j]`適切な長さのシーケンスの数として`i`ここで、シーケンス内の最大数は正確に`j`。 次に、長さのシーケンスを構築できます`i`数字を追加することで`k`シーケンスの長さを短くする`i-1`制御された方法で: 最大値は同じままにすることも、1 つずつ増やすこともできます。 これにより、次の再帰式が導かれます。 

- 追加する場合`k <= max_so_far`、シーケンス数は、その最大値でシーケンスを拡張する方法の数だけ増加します。 
- 追加する場合`k = max_so_far + 1`、シーケンスは次の場合にのみ有効です。`max_so_far >= 1`。 

この増分 DP を使用すると、プレフィックス合計のような戦略を使用して、各数値が何回出現するかを追跡することもできます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^n * n) | O(n^n) | 遅すぎる |
 | 動的プログラミング | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. DP テーブルの初期化`dp[i][j]`どこ`i`範囲は 1 から`n`(シーケンスの長さ) と`j`範囲は 1 から`i`(シーケンス内の最大数)。`dp[i][j]`適切な長さのシーケンスの数を表します`i`最大数で`j`。 セット`dp[1][1] = 1`長さ 1 のシーケンスは 1 つだけであるため、`[1]`。 
2. シーケンスの長さを反復処理する`i`2から`n`。 可能な最大値ごとに`j`(1から`i`)、長さのシーケンスを考慮します`i-1`:

 ａ． のために`k = 1`に`j`、シーケンスを最大値で拡張します`k`長さで`i-1`。 もし`k = j`、新しい最大値を追加しています。これは次の場合にのみ有効です。`k > 1`。 それ以外の場合、最大値は変わりません。 

b. 前の DP 行のプレフィックス合計を使用して、現在の DP 行まで拡張できるシーケンスの数を効率的に計算します。`dp[i][j]`。 
3. DP テーブルに入力した後、各数値の合計出現数を計算する必要があります。 させて`count[k]`全体の合計になる`dp[i][j]`位置の数を乗算します。`k`最大値のシーケンスで出現する可能性があります`j`。 これは、組み合わせ係数を使用して段階的に計算できます。 基本的に、方法の数は、`k`シーケンス内に現れる は、最大値 ≥ k のシーケンスの数に比例します。 
4. 結果のモジュロ 998244353 を出力します。 

それが機能する理由: 各 DP ステップでの不変条件は次のとおりです。`dp[i][j]`長さのすべてのシーケンスを正しくカウントします`i`最大数を正確に指定`j`グッドシーケンス特性を満たします。 新しい番号を確保することで、`k`の場合にのみ追加されます`k-1`が存在する場合、DP 内のすべてのシーケンスが有効であることを保証します。 最大追跡を介して発生をカウントすることで、各数値の寄与が二重にカウントされることなく合計されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

n = int(input())
dp = [[0] * (n + 2) for _ in range(n + 2)]
dp[1][1] = 1

for length in range(2, n + 1):
    prefix = [0] * (n + 2)
    for j in range(1, length):
        prefix[j] = (prefix[j - 1] + dp[length - 1][j]) % MOD
    for j in range(1, length + 1):
        dp[length][j] = prefix[j]
        
result = [0] * (n + 1)
for max_val in range(1, n + 1):
    for length in range(max_val, n + 1):
        result[max_val] = (result[max_val] + dp[length][max_val]) % MOD

for val in range(1, n + 1):
    print(result[val], end=' ')
print()
```最初のセクションでは、シーケンス長 1 で DP テーブルを初期化します。ネストされたループは次の計算を行います。`dp[length][j]`プレフィックス合計を使用して、より短い長さのすべての有効なシーケンスを効率的に合計します。 最後のループは、数値が最大値内にあるすべてのシーケンスからの寄与を合計することによって、各数値のカウントを累積します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    MOD = 998244353
    n = int(input())
    dp = [[0] * (n + 2) for _ in range(n + 2)]
    dp[1][1] = 1
    for length in range(2, n + 1):
        prefix = [0] * (n + 2)
        for j in range(1, length):
            prefix[j] = (prefix[j - 1] + dp[length - 1][j]) % MOD
        for j in range(1, length + 1):
            dp[length][j] = prefix[j]
    result = [0] * (n + 1)
    for max_val in range(1, n + 1):
        for length in range(max_val, n + 1):
            result[max_val] = (result[max_val] + dp[length][max_val]) % MOD
    return ' '.join(str(result[i]) for i in range(1, n + 1))

# Provided samples
assert run("2\n") == "3 1", "sample 1"
assert run("1\n") == "1", "sample 2"

# Custom cases
assert run("3\n") == "5 3 1", "3-length sequences"
assert run("4\n") == "8 6 3 1", "4-length sequences"
assert run("5\n") == "13 10 6
```
