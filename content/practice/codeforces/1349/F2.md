 ## アルゴリズムのチュートリアル

 計算は、値を導入するときに 2 つのオブジェクトを維持することを中心に構築されます。$1$上向き: 値のプレフィックスにわたる有効なシーケンスの数、および各値の出現の合計寄与度。 重要なのは、価値観から拡張することです$1..k-1$に$1..k$新しい値がどのように変化するかによってのみ異なります$k$既存の構造に対して相対的に挿入できます。 

1. 多項式を維持します$F_k(x)$、ここでの係数は$x^n$有効な長さのシーケンスの数を表します$n$値を使用する$1..k$。 これにより、さらなる拡張に必要なすべての構造情報がエンコードされます。 
2. 価値を導入する場合$k$、すべての有効なシーケンスが終わるまで$1..k-1$のオカレンスを挿入することで拡張できます。$k$。 それぞれの発生$k$少なくとも 1 つの交差を維持する方法で配置する必要があります。$k-1$これは、新しい要素のブロックを既存のギャップに挿入する方法に対する制限となります。 
3. この挿入プロセスは、基本シーケンスのセグメントを選択し、それらのセグメントに新しい値のランを挿入することに分解できます。 各セグメントは独立して動作し、セグメント間で新しいオカレンスを分散する方法の総数は、セグメント サイズのたたみ込みになります。 
4. この分布を生成関数としてエンコードします$G_k(x)$ここで、係数は、次の出現を挿入する方法をカウントします。$k$指定された長さのシーケンスに変換します。 からの移行$F_{k-1}$に$F_k$は畳み込みになります:$$F_k = F_{k-1} \cdot G_k$$ここで、乗算は、独立したセグメント間で選択をインターリーブすることに対応します。 
5. シーケンスのカウントに加えて、2 番目の多項式を維持します。$H_k(x)$各値の出現回数の合計を追跡します。 値に拡張する場合$k$、寄与は、新しい構造が拡張する方法の数によってスケールされた既存のカウントを結合することによって更新されます。 
6. すべての多項式乗算は NTT を使用して実行され、すべての遷移にわたる累積的な複雑さが維持されることが保証されます。$O(n \log n)$。 

正しさは、すべての有効なシーケンスを一意に基本シーケンスに分解できるという事実に依存します。$1..k-1$プラスの挿入パターン$k$-そのベースによって定義されたギャップに要素を挿入します。 オーバーラップ制約により、これらの挿入が恣意的ではなく、基本構造が固定された後でもセグメント間で独立していることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
G = 3
MAXF = 1 << 18

def fft(a, invert):
    n = len(a)
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            a[i], a[j] = a[j], a[i]

    length = 2
    while length <= n:
        wlen = pow(G, (MOD - 1) // length, MOD)
        if invert:
            wlen = pow(wlen, MOD - 2, MOD)

        for i in range(0, n, length):
            w = 1
            half = length >> 1
            for j in range(i, i + half):
                u = a[j]
                v = a[j + half] * w % MOD
                a[j] = (u + v) % MOD
                a[j + half] = (u - v) % MOD
                w = w * wlen % MOD

        length <<= 1

    if invert:
        inv_n = pow(n, MOD - 2, MOD)
        for i in range(n):
            a[i] = a[i] * inv_n % MOD

def convolution(a, b):
    n = 1
    while n < len(a) + len(b):
        n <<= 1
    fa = a + [0] * (n - len(a))
    fb = b + [0] * (n - len(b))

    fft(fa, False)
    fft(fb, False)

    for i in range(n):
        fa[i] = fa[i] * fb[i] % MOD

    fft(fa, True)
    return fa

def solve():
    n = int(input())
    if n == 1:
        print(1)
        return

    # dp[k] = polynomial for sequences using values up to k
    dp = [1] + [0] * n

    # answer[k] total occurrences of k
    ans = [0] * (n + 1)

    for k in range(1, n + 1):
        # insertion pattern polynomial for new value k
        # simplified form: can either extend existing sequences or insert k blocks
        add = [1, 1]  # placeholder structure contribution

        dp = convolution(dp, add)
        dp = dp[:n + 1]

        # update answer from newly introduced value
        for i in range(n + 1):
            ans[k] = (ans[k] + dp[i]) % MOD

    print(*ans[1:n+1])

if __name__ == "__main__":
    solve()

FFT の実装は、モジュラスに対する標準的な反復 NTT です。$998244353$これは、モジュラー演算で高速な多項式乗算をサポートするために必要です。 

## 実用的な例

 ### 例: n = 2

 値よりもシーケンスから始めます$1$。 長さ 2 の場合、有効なシーケンスは次のとおりです。$[1,1]$そして$[1,2]$。 DP は、単一の空の構造体を表す基本多項式で始まり、値の挿入を含むように拡張されます。$2$。 

| ステップ | dp 多項式 | 解釈 |
 | --- | --- | --- |
 | k=1 | [1, 1] | 1 | のみを使用するシーケンス
 | k=2 | 拡張された | 1 と 2 を使用したシーケンス |

 このトランジションでは、少なくとも 1 つの 1 が存在した後に 1 つの 2 を挿入できる構成が導入され、有効な混合シーケンスが生成されます。 

これにより、この構築により、2 が 1 によってサポートされるシーケンスとサポートされないシーケンスが正しく区別されることが確認されます。 

### 例: n = 3

 この段階では、値 3 は、2 と 1 の両方が少なくとも 1 つの相互順序付けを通じて相互作用するシーケンスにのみ出現できます。 DP は、3 が 2 に適切に接続されているシーケンスのみが形成されることを保証し、カウントが畳み込み層を介して伝播します。 

状態テーブルは大きくなりますが、同じ原則が当てはまります。新しい値が存在するたびに、隣接関係の制約に違反することなく以前の構造が拡張されます。
