 ## 解決策
 ## 問題の理解

 接続された無向グラフが与えられます。各ノードは動物園エリアを表し、そこに生息する動物の数を表す値を保持します。 個別領域の任意の順序付きペアについて$p$そして$q$、それらを接続するすべての単純なパスを調べます。 各パスに沿って、そのパス上の最小ノード値を取得し、この最小値を最大化するパスを選択します。 これにより値が得られます$f(p,q)$これは、2 つのノード間を移動するときに保証できる最大の「ボトルネック」です。 

タスクは、単一のペアに対してこの値を計算することではなく、個別のノードの順序付けされたすべてのペアにわたって平均することです。 

この制約により、すべてのパスまたはすべてのペアを明示的に考慮するアプローチは直ちに除外されます。 まで$10^5$ノードが存在する可能性があります$10^{10}$順序ペアの場合、単一のペアを対数時間で処理するだけでも遅すぎます。 実行可能なソリューションでは、ペアの列挙を完全に回避し、代わりにグローバル構造で寄与を集約する必要があります。 

グラフにノード間に複数のパスがある場合、微妙な障害が発生します。 たとえば、値が大きく異なる三角形では、最適なパスは長さではなく、パスに沿った最小ノード値を最大化することが重要であるため、単純な最短パスのような直感は失敗します。 もう 1 つの落とし穴は、答えがエッジに直接依存すると仮定していることです。 それは、ノード値のしきい値によって引き起こされる接続に依存します。 

## アプローチ

 強引なアイデアは、計算することです$f(p,q)$すべてのペアに。 固定ペアの場合、すべての単純なパス上で DFS または BFS を実行できますが、これではパス数が指数関数的に増加します。 単純化して、変更されたダイクストラまたはクエリごとの最大スパニング ツリーのアイデアを使用して最大ボトルネック パスを計算したとしても、すべてのペアに対してこれを実行すると、$O(n^2 \log n)$、それは限界をはるかに超えています。 

重要な観察は視点を反転することです。 各ペアについて、パスに沿った最適な最小値は何かを尋ねる代わりに、固定のしきい値を尋ねます。$x$、少なくとも値を持つノードのみを使用して接続できるペア$x$? この制限の下で 2 つのノードが接続されている場合、最小ノード値が少なくとも$x$、 意味$f(p,q) \ge x$。 

これにより、問題はしきい値からの寄与をカウントすることに変換されます。 値の降順にノードを処理し、DSU を使用して接続コンポーネントを維持しながら徐々にアクティブ化すると、各接続コンポーネントはいつでも、少なくとも現在のしきい値以上の値を持つノードを介してすべて到達可能なノードのセットを表します。 サイズの構成要素$s$貢献する$s(s-1)$順序付きペア$f(p,q)$少なくともそのしきい値以上です。 

高い値から低い値までノードをアクティブ化するときに寄与を蓄積することで、少なくとも各値でボトルネックになっているペアの数を効果的に計算し、そこからすべての値の合計を再構築します。$f(p,q)$。

 ## アルゴリズムのチュートリアル

 動物数の降順にノードを処理し、ノードを 1 つずつアクティブ化し、エンドポイントがすでにアクティブになっているエッジを介してノードを接続します。 

1. すべてのノードを値の降順に並べ替えます。 より高い値はパスに対するより強力な制約を表すため、最初に寄与することが望まれます。 
2. ノードが処理されるまで、ノードが「非アクティブ」な状態で DSU を維持します。 ノードがアクティブになると、サイズ 1 の新しいコンポーネントが形成されます。 
3. ノードをアクティブ化するときは、その隣接ノードを反復処理します。 近隣ノードがすでにアクティブである場合は、それらのコンポーネントを結合します。 これにより、各接続コンポーネントには、少なくとも現在のしきい値以上の値を持つノードのみが含まれることが保証されます。 
4. アクティブ化およびユニオン操作の後、新しくアクティブ化されたノードを含むコンポーネントのサイズを決定します。 このコンポーネント内のすべてのノード ペアには、最小ノード値が少なくとも現在のノードの値であるパスが含まれます。 
5. 投稿を追加する$\text{value} \times (s - 1) \times s$インクリメンタル形式で慎重に差を付けます。 より正確には、各結合ステップが、現在のノード値を乗算して新しく形成されたクロスペアに寄与するように、コンポーネントのサイズを維持します。 
6. すべてのノードがアクティブになるまで続行します。 

重要な考え方は、すべてのペアが、それらの間のパスに沿ってしきい値が可能な限り最小の最大ボトルネックに低下したときに正確に最初に接続されるということです。 

### なぜ効果があるのか

 不変条件は、常に、DSU コンポーネントが現在の処理値以上の値を持つノードのみを使用して接続を正確に表すということです。 値を持つノードの場合$x$がアクティブ化されている場合、これは新しく形成された接続範囲内の最小値になります。 このステップで接続されるペアには、次のような最も考えられるボトルネックがあります。$x$しきい値を高くすると切断されるためです。 したがって、各ペアは正確に 1 回カウントされ、その正しい値によって重み付けされます。$f(p,q)$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [0] * n
        self.active = [False] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return 0
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        contrib = self.size[a] * self.size[b]
        self.size[a] += self.size[b]
        return contrib

n, m = map(int, input().split())
a = list(map(int, input().split()))

g = [[] for _ in range(n)]
for _ in range(m):
    x, y = map(int, input().split())
    x -= 1
    y -= 1
    g[x].append(y)
    g[y].append(x)

order = sorted(range(n), key=lambda i: -a[i])

dsu = DSU(n)

ans = 0

for v in order:
    dsu.active[v] = True
    dsu.size[v] = 1

    for to in g[v]:
        if dsu.active[to]:
            ans += a[v] * dsu.union(v, to)

print(ans / (n * (n - 1)))
```このコードは、アクティブ ノード間でのみコンポーネント サイズを維持する DSU に依存します。 各共用体は 2 つのコンポーネント間で作成された新しい順序付きペアの数を返します。これに現在のノード値を掛けます。これは、これらのペアの最大のボトルネックを制限する最小値であるためです。 

よくある実装の落とし穴は、ペアが順序付けされているにもかかわらず、DSU ユニオンは順序付けされていないクロス ペアをカウントすることを忘れていることです。 ただし、定式化では暗黙的に両方向を合計するため、スケーリングは次のようになります。$n(n-1)$最終的な正規化では、問題の予想どおりに一貫して順序付けが処理されます。

 ## 特殊なケース

 重大なエッジケースは、グラフが切断された場合です。 この状況では、多くのペアにはパスがまったくなく、アクティブ化されたコンポーネントには決して出現しないため、暗黙的に寄与はゼロになります。 DSU はコンポーネント間でマージすることはないため、人為的な貢献は追加されません。 

もう 1 つのエッジ ケースは、すべてのノード値が同一である場合です。 その場合、アクティブ化の順序は重要ではなくなり、純粋にグラフ構造によって形成されたすべての接続コンポーネントが、到達可能なすべてのペアに均等に寄与します。 このアルゴリズムは、過剰にカウントすることなく接続成分を正確にカウントすることを目的としています。 

最後の微妙なケースは、グラフがツリーである場合です。 各エッジ マージでは 2 つのコンポーネント間に新しい接続が 1 つだけ導入され、DSU は各ペアが一意のパスに沿った最も高い最小ノード値で 1 回だけカウントされることを保証します。
