 ## 解決策
 ## 問題の理解

 平面内には、プラグとソケットという 2 つの剛構造が与えられます。 各構造は 3 つの円形のピンまたは穴で構成されます。 各円には中心と半径があり、各構造内で 3 つの円はペアごとに素です。 

各構造内の 3 つの円のうちの 1 つはグランド コネクタとして指定されており、常に入力の最初のものになります。 他の 2 つの円は AC ピンを表しており、プラグとソケットを一致させるときに識別を交換できます。 

タスクは、すべてのプラグ ピンが対応するソケットの穴に収まるように、剛体変換 (平行移動と回転を意味する) のみを使用してプラグを移動できるかどうかを判断することです。 グランドはグランドと正確に一致する必要がありますが、他の 2 つのピンは入れ替えることができます。 プラグ ピンの中心が正確に一致し、半径が穴の半径より大きくなく、公差 1e-6 までであれば、プラグ ピンはソケットの穴に適合します。 

有効な配置が存在する場合は、YES を出力し、プラグ センターの有効な変換された構成を 1 つ提供する必要があります。 出力構成では、すべてのペアごとの距離を精度誤差まで正確に保存する必要があります。つまり、形状の変形は許可されず、移動と回転のみが許可されます。 

入力サイズは一定で、正確に 6 行であるため、漸近的な複雑さは無関係です。 難しさは完全に幾何学的なものです。剛体運動下での合同を認識し、2 つの非地面点を一致させる際の曖昧さを処理することです。 

主なエッジ ケースは、AC ピンの並べ替えに由来します。 単純なアプローチでは、注文を誤って修正し、有効なスワップを拒否する可能性があります。 もう 1 つの微妙な問題は、回転後に座標を再構築するとき、特に点がほぼ同一直線上にある場合、または互いに非常に近い場合の数値安定性です。 

たとえば、プラグの 2 つの AC ピンがソケットに対して交換されている場合、たとえグランドを中心に 180 度回転すると完全に一致する可能性があっても、インデックスの位置合わせを強制する単純な一致は失敗します。 

## アプローチ

 ブルートフォースの見方は簡単です。 2 つの非接地プラグ ピンを 2 つの非接地ソケット ホールに割り当てるためにあらゆる方法を試みます。 割り当てごとに、プラグをソケットにマップする剛体変換を見つけようとします。 点が 3 つしかないため、剛体変換は接地点と追加の 1 点の方向を固定することによって一意に決定されます。 

マッピングの選択ごとに、接地から 2 番目および接地から 3 番目の間の距離、および 2 つの非接地点の間の距離がプラグとソケットの間で一致するかどうかを計算します。 それらが一致する場合、変換を明示的に再構築できます。 

入力サイズが固定されているため、単純なコストは一定時間ですが、概念的な総当りによって重要な構造が強調表示されます。問題は、ラベル付きの 2 つの三角形が合同であるかどうかを確認することと、2 つの頂点を交換することにまで帰着します。 

重要な観察は、これがまさに 1 つのアンカーされた頂点と反射の可能性がある三角形合同問題であるということです。 地上点が固定されると、他の 2 つの点は平面内の回転まで決定されます。唯一のあいまいさは、マッピングで三角形の方向が保持されるか交換されるかです。 

したがって、解決策は、非地上点の 2 つの可能な順列を試し、ベクトル位置合わせを使用して剛体変換を再構築しようとすることになります。 有効なマッピングを選択したら、回転を使用してプラグからソケットまで 1 つのベクトルを位置合わせし、それを 2 番目と 3 番目の点に適用し、変換された座標を出力します。

 ## アルゴリズムのチュートリアル

 プラグとソケットの両方の最初の点をアンカーとして扱い、それを基準にすべてを位置合わせします。

1. 接地点の対応を修正します。 プラグのグランドが概念的に原点に位置するように両方の構造を変換し、他のすべての点をグランドを基準としたベクトルとして扱います。 これにより、翻訳が問題から完全に削除されます。 
2. 2 つのプラグ ベクトルと 2 つのソケット ベクトルを抽出します。 これらは、各構造内の残りのピンの幾何学的形状を表します。 
3. プラグとソケットの非接地点間で考えられる両方の一致を試します。 1 つのマッピングは順序を維持し、もう 1 つのマッピングは順序を入れ替えます。 AC ピンは互換性があり、方向が不明であるため、これが必要です。 
4. 各マッピングについて、プラグとソケットの間の 3 つのペアごとの距離が許容差まで一致するかどうかを確認します。 これにより、何らかの剛体変換の下で三角形が合同になることが保証されます。 
5. マッピングが有効な場合は、1 つのプラグ ベクトルを対応するソケット ベクトルに揃える回転を計算します。 これは、ドットと外積による標準の 2D 回転を使用して行い、回転のコサインとサインを構築します。 
6. この回転を両方の非接地プラグ ポイントに適用し、接地点がソケットの接地点と一致するように結果を変換します。 
7. YES と変換された座標を出力します。 

重要なアイデアは、1 つのエッジを整列させると全体の構成が固定され、選択したマッピングで三角形が一致する場合に限り、3 番目の点が自動的に定位置に収まるということです。 

### なぜ効果があるのか

 接地点を固定すると、移動の自由度が失われます。 その後、有効な解は原点を中心とした純粋な回転でなければなりません。 平面内の回転は、単一の非ゼロ ベクトルを同じ長さの別のベクトルにマッピングすることによって完全に決定されます。 このような回転が 1 つの一致する点のペアに存在する場合、2 番目の点は正しくマッピングされるか、または誤ってマッピングされます。 距離チェックにより一貫性が確保され、真に一致するマッチングのみが合格することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

EPS = 1e-9

def read():
    x, y, r = map(float, input().split())
    return (x, y, r)

def sub(a, b):
    return (a[0] - b[0], a[1] - b[1])

def dist2(a, b):
    dx = a[0] - b[0]
    dy = a[1] - b[1]
    return dx*dx + dy*dy

def rotate(v, cos_t, sin_t):
    x, y = v
    return (x*cos_t - y*sin_t, x*sin_t + y*cos_t)

plug = [read() for _ in range(3)]
sock = [read() for _ in range(3)]

pg = plug[0]
sg = sock[0]

p = [sub(plug[i], pg) for i in range(3)]
s = [sub(sock[i], sg) for i in range(3)]

# indices 1 and 2 are swappable
ok = False
best = None

for perm in [(1, 2), (2, 1)]:
    i, j = perm

    v1p, v2p = p[i], p[j]
    v1s, v2s = s[1], s[2] if perm == (1, 2) else (s[2], s[1])

    # check distances match
    def d2(u, v):
        return dist2(u, v)

    if abs(d2(v1p, (0,0)) - d2(v1s, (0,0))) > 1e-6:
        continue
    if abs(d2(v2p, (0,0)) - d2(v2s, (0,0))) > 1e-6:
        continue
    if abs(d2(v1p, v2p) - d2(v1s, v2s)) > 1e-6:
        continue

    # compute rotation from v1p -> v1s
    xp, yp = v1p
    xs, ys = v1s

    denom = xp*xp + yp*yp
    if denom < 1e-12:
        continue

    cos_t = (xp*xs + yp*ys) / denom
    sin_t = (xp*ys - yp*xs) / denom

    r1 = rotate(p[1], cos_t, sin_t)
    r2 = rotate(p[2], cos_t, sin_t)

    # check consistency
    if abs(dist2(r1, (0,0)) - dist2(s[1], (0,0))) > 1e-6:
        continue
    if abs(dist2(r2, (0,0)) - dist2(s[2], (0,0))) > 1e-6:
        continue

    ok = True
    best = (r1, r2)
    break

if not ok:
    print("NO")
else:
    print("YES")
    print(f"{sg[0]:.10f} {sg[1]:.10f}")
    print(f"{sg[0] + best[0][0]:.10f} {sg[1] + best[0][1]:.10f}")
    print(f"{sg[0] + best[1][0]:.10f} {sg[1] + best[1][1]:.10f}")
```コードはまず、グランド ピンが原点基準になるように両方の構造の中心を再調整します。 これにより、ベクトル比較に対するすべてのチェックが簡素化されます。 

コア ロジックは、非グランド ピンの 2 つの可能な割り当てにわたる置換ループです。 割り当てごとに、すべてのペアごとの二乗距離が一致することを検証します。 これにより、回転を計算する前に三角形の形状が同一であることが保証されます。 

回転は、ドットと外積の式を使用して 1 つのベクトルを別のベクトルに整列させることで導出されます。これにより、明示的な角度の計算が回避され、数値の安定性が高く保たれます。 回転すると、2 番目の点が暗黙的に決定され、ソケットに対してチェックされます。 

最後に、出力はソケットの地面の位置を追加し直すことによって絶対座標を再構築します。

 ## 特殊なケース

 エッジ ケースの 1 つは、2 つの非接地点が接地点を中心に対称であり、二等辺構成を形成する場合です。 この状況では、それらを交換すると同じ距離セットが生成されるため、正しい回転チェックのみが有効なマッピングと無効なマッピングを区別します。 

もう 1 つのエッジ ケースは、地上からのベクトルの 1 つが数値精度で長さがゼロに近い場合です。 その場合、正規化が小さな値で除算されるため、回転の計算が不安定になります。 アルゴリズムは、回転を構築する前に分母をチェックすることでこれを回避し、未定義の動作が発生しないようにします。 

最後のエッジケースは、両方の構造が有効であるが、反射によってのみ異なる場合です。 ここでの剛体運動では反射が許可されないため、ドットクロス構造では、両方の非接地点にわたって方向を一貫して一致させることができないケースは自然に拒否されます。
