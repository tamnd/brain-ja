 ## 解決策
 ## 問題の理解

 シンボルのセットが与えられ、各シンボルは文字列内に 1 回だけ出現します。 これらのシンボルからサブセットを選択します。選択されたシンボルの順序は無関係で、どのシンボルが含まれるかだけが重要です。 選択されたサブセットのスコアは 2 つのソースから形成されます。選択された各シンボルは自己値に寄与し、選択されたシンボルの順序のないペアは文字列内の元の位置に依存する相互作用値に寄与します。 

より具体的には、入力文字列内の位置によってシンボルに 1 から n までの番号を付ける場合、サブセット S を選択すると、i ≤ j である S 内のすべてのペア i, j のすべての d[i][j] の合計に等しいスコアが得られます。 これは、選択した各要素の対角項を追加し、順序なしペアごとに 1 つの値を正確に追加することを意味します。 

タスクは、この合計スコアを最大化するためにこれらの最大 30 個のシンボルのサブセットを選択し、達成可能な最大スコアとそれを達成する 1 つのサブセットの両方を出力することです。 

n ≤ 30 という制約は、サブセットに対する指数関数的な検索が期待できるほど十分に小さいですが、単純な 2^n 列挙に構造が必要になるほど十分に大きいです。 完全なサブセット列挙はすでに約 10^9 状態に達しており、状態ごとに O(n) または O(n^2) 個の作業を追加すると、制限をはるかに超えてしまいます。 これにより、サブセットごとにペアの寄与を最初から再計算するアプローチは即座に除外されます。 

欲張って考えると、さらに微妙な問題が見えてきます。 シンボルは、正の対角項により単独では有益に見えるかもしれませんが、他のシンボルと組み合わせると負の相互作用により有害になります。 逆に、マイナスの自己スコアを持つシンボルでも、他のシンボルとの相互作用が強くプラスであれば、最適なサブセットの一部である可能性があります。 これにより、独立した選択や並べ替えベースの貪欲な戦略の可能性が排除されます。 

3 番目の落とし穴は、ペアの寄与が独立して処理され、ローカルで合計できると仮定していることです。 選択された各要素は、以前に選択されたすべての要素と相互作用するため、決定はグローバルに結合されます。 

## アプローチ

 ブルートフォースのアイデアは単純です。シンボルのすべてのサブセットを反復処理し、選択されたすべての対角項とすべてのペアごとの相互作用を合計して合計スコアを計算し、最良のものを維持します。 各サブセットについて、その中のすべてのペアをチェックする可能性があるため、スコアの評価には O(n^2) のコストがかかります。 これにより、O(2^n · n^2) が得られます。これは、n = 30 の場合、すでに約 10^9 の演算に相当し、実際には遅すぎます。 

問題の構造は、スコアがバイナリ選択ベクトルに対して二次関数であるということです。 各サブセットはバイナリ ベクトル x を定義し、スコアは d[i][j] で与えられる係数を持つ x 上の二次形式です。 重要な観察は、インデックス セットを 2 つの半分に分割し、半分の内側と半分にまたがる交互作用を別々に扱うのに十分なほど n が小さいことです。 

インデックスを左半分 A と右半分 B に分割すると、任意のサブセットがペア (SA、SB) になります。 合計スコアは、SA の内部スコア、SB の内部スコア、および SA と SB 間の相互作用の 3 つの部分に分割されます。 内部部分は各半分にのみ独立して依存し、各半分のすべてのサブセットについて事前計算できます。 クロスタームは両方の側を結合するため、難しいのです。 

ただし、他方が固定されている場合、相互寄与は各側で線形になります。 固定サブセット SB の場合、A のすべての要素 i は、i と SB 内の選択されたすべての要素の間の相互作用の合計に等しい固定量に寄与します。 これにより、SB が A のサブセットにわたる線形スコアリング関数に変換されます。この構造により、サブセット動的計画法を使用して、一方の側を完全に列挙し、もう一方の側に対してその誘導線形関数を評価することができます。 

この中間の変換により、指数次元が 2^30 から 2 つの管理可能な 2^15 部分に縮小され、それぞれが約 32768 サブセットであり、これは実現可能です。

 | 中間サブセット DP | O(2^(n/2) · 2^(n/2) · n) | O(2^(n/2)) | 承認済み |

 ## アルゴリズムのチュートリアル

 インデックスを 2 つのグループに分割します。A には最初の n/2 シンボルが含まれ、B には残りのシンボルが含まれます。 

1. A のすべてのサブセットと B のすべてのサブセットの内部スコアを事前計算します。サブセットの場合、その内部スコアは、両方のエンドポイントがサブセット内に存在するすべての d[i][j] の合計です。 これは、一度に 1 つの要素を追加し、以前に選択した要素との相互作用を蓄積する標準のサブセット DP を使用して行われます。 
2. 右半分 B のすべてのサブセット SB を列挙します。そのようなサブセットごとに、その内部スコアと A に対するその「影響ベクトル」という 2 つのことを計算します。影響ベクトルは、A の要素 i ごとに 1 つの値を持ち、SB のすべての j に対する d[i][j] の合計に等しくなります。 このベクトルは、SB が A 内の考えられる各要素の寄与をどのように変更するかをエンコードします。 
3. 固定 SB の場合、修正された重み付けシステムの下で A 内の最適なサブセット SA を見つけたいと思います。 A の各要素 i には、元の寄与に加えて、影響ベクトルによって与えられる追加の項が含まれます。 合計スコアは、内部(SB) + SA の最高 (内部(SA) + SA 内の i に対する影響力[i] の合計) になります。 
4. 各 SB について、A 上のサブセット DP を使用して可能な限り最良の SA を計算します。各サブセットは、一度に 1 つの要素を追加する反復を使用して O(n_A) で評価されます。 
5. すべての SB の選択肢の中から最良の値を追跡します。 対応する SA とそれを生成した SB を保存します。 
6. 最適な SA と SB を組み合わせて最終サブセットを再構築し、そのサイズと対応する文字を出力します。 

正確さは、すべてのサブセットを左右の部分に一意に分解でき、すべての相互作用が影響ベクトルによって完全に捕捉されるという事実に依存します。 すべてのペアは A の内部、B の内部、または分割全体のいずれかであり、アルゴリズムは各コンポーネントのこれらのカテゴリの 1 つを正確に考慮するため、相互作用が二重にカウントされたり省略されたりすることはありません。 

重要な不変条件は、固定された SB ごとに、A 上の DP が正しく変更された重みの下でその SB に対する正確な最良の応答を計算することです。 すべての SB が列挙されるため、グローバル最適値はこれらの評価の 1 つに現れる必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    n = len(s)

    d = [[0] * n for _ in range(n)]
    for i in range(n):
        row = list(map(int, input().split()))
        for j, val in enumerate(row):
            d[i][i + j] = val

    m = n // 2
    A = list(range(m))
    B = list(range(m, n))

    sizeA = m
    sizeB = n - m

    # precompute internal weights
    def build_internal(group):
        sz = len(group)
        idx = {group[i]: i for i in range(sz)}
        W = [[0] * sz for _ in range(sz)]
        for i in range(sz):
            for j in range(sz):
                if group[i] <= group[j]:
                    W[i][j] = d[group[i]][group[j]]
                else:
                    W[i][j] = d[group[j]][group[i]]
        dp = [0] * (1 << sz)
        for mask in range(1 << sz):
            for i in range(sz):
                if mask & (1 << i):
                    prev = mask ^ (1 << i)
                    add = W[i][i]
                    for j in range(sz):
                        if prev & (1 << j):
                            add += W[j][i]
                    dp[mask] = dp[prev] + add
                    break
        return dp

    dpA = build_internal(A)
    dpB = build_internal(B)

    best = -10**30
    bestA = bestB = 0

    for maskB in range(1 << sizeB):
        # build influence on A
        infl = [0] * sizeA
        internalB = dpB[maskB]

        for bi in range(sizeB):
            if maskB & (1 << bi):
                bj = B[bi]
                for ai in range(sizeA):
                    infl[ai] += d[A[ai]][bj]

        # DP over A with linear modification
        dp = [0] * (1 << sizeA)
        for maskA in range(1 << sizeA):
            if maskA == 0:
                continue
            lsb = maskA & -maskA
            i = (lsb.bit_length() - 1)
            prev = maskA ^ lsb
            val = dp[prev] + infl[i]
            dp[maskA] = val

        for maskA in range(1 << sizeA):
            total = dpA[maskA] + dp[maskA] + internalB
            if total > best:
                best = total
                bestA = maskA
                bestB = maskB

    res = []
    for i in range(sizeA):
        if bestA & (1 << i):
            res.append(s[A[i]])
    for i in range(sizeB):
        if bestB & (1 << i):
            res.append(s[B[i]])

    print(len(res))
    print("".join(res))

if __name__ == "__main__":
    solve()
```この解決策は、任意のペアを一貫してクエリできるように、上三角行列を完全な対称アクセス フォームに再構築することから始まります。 配列は中間列挙を可能にするために 2 つの半分に分割されます。 

の`build_internal`この関数は、標準のサブセット DP を使用して、半分の内側のすべてのサブセットの正確なスコアを計算します。この場合、新しい要素はそれぞれ、既に選択されている要素との相互作用を合計することによって追加されます。 これにより、ペアの合計を最初から再計算する必要がなくなります。 

右半分のサブセットごとに、それが左半分をどのように変更するかを計算します。`infl`配列。 これにより、左側の最適化が、各要素に追加の線形ゲインを持つ修正サブセット DP に変わります。 

最後に、左 DP、右 DP、および相互寄与を組み合わせて、すべての分割構成のフル スコアを評価します。 

## 実用的な例

 3 つのシンボルが正と負のペアの寄与の両方と相互作用する小さなケースを考えてみましょう。 A = 最初の要素と B = 残りの要素に分割します。 

固定 B サブセットの場合、アルゴリズムは次を計算します。 

| ステップ | マスクB | 内部B | A | でのインフレ 最高の貢献 | 合計 |
 | --- | --- | --- | --- | --- | --- |
 | 0 | 000 | 0 | [0] | 0 | 0 |
 | 1 | 010 | dpB[010] | d | から計算 dpA + 線形 | 評価済み |
 | 2 | 011 | dpB[011] | 更新されたインフレ | 再計算された | 候補者 |

 これは、B の各選択が A とは異なる最適化問題をどのように引き起こすかを示しています。 

B に 1 つの要素がある 2 番目の例では、影響ベクトルは A 要素ごとに 1 つの寄与を持ちます。 A に対する DP は、これらの線形項によってすべてのサブセット スコアを単純にシフトし、それに応じて最良のサブセットが変化し、交差項が完全に捕捉されていることを確認します。

 ## 特殊なケース

 単一シンボル入力の場合、両方の半分には単一のサブセットを持つ片側しか含まれないため、アルゴリズムは対角項のみを評価します。 空のサブセットと単一要素のサブセットの両方が考慮され、最大値が選択されるため、DP はこれを正しく処理します。 

強い負の相互作用を持つ 2 つのシンボルの場合、正しい出力は、より良い 1 つのシンボルのみを選択することになります。 分割定式化では、一方の側がサブセットを独立して列挙し、クロス項が存在しないか負のいずれかであるため、DP は、影響によって合計スコアが低下する場合に両方の要素の組み合わせを正しく回避します。
