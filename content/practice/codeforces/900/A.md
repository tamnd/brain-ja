 ## 解決策

 ## 問題の理解

 平面内に一連の点が与えられていますが、それらのどれも垂直軸上にありません。 これは、すべての点が y 軸の厳密に左側か、厳密に右側にあることを意味します。 タスクは、残りのすべての点が完全に y 軸の片側に収まるように、正確に 1 つの点を削除できるかどうかを確認することです。つまり、残りのすべての x 座標が厳密に正か負のいずれかになります。 

したがって、中心的な質問は、深い意味での幾何学に関するものではなく、単一の外れ値点を除去した後に集合が「片側」になるかどうかということです。 

入力サイズは最大 100000 ポイントを許可し、すべての除去を試して毎回 O(n) で残りを直接チェックするような二次戦略を排除します。 これにより、最悪の場合、約 10^10 の操作が必要となり、1 秒の制限には遅すぎます。 線形または線形に近いスキャンが必要です。 

重要な微妙な点は、答えは左側 (x < 0) にある点の数と右側 (x > 0) にある点の数にのみ依存することです。 y 座標はこの条件には関係ありません。 

よくある間違いは、空間構造が x の符号を超えて重要であると考えることです。 たとえば、誰かが並べ替えたり凸性をチェックしたりしようとするかもしれませんが、それは残りのすべての点が厳密に y 軸の片側にあるかどうかには影響しません。 

両側がバランスよく配置されている場合、エッジケースが発生します。 たとえば、両側に 2 つの点がある場合、1 つの点を削除しても両側が表現されたままになるため、これは不可能です。 

もう 1 つの微妙なケースは、すべての点がすでに片側にある場合です。 たとえば:

 入力:```
3
1 2
3 4
5 6
```任意の 1 つの点を削除すると、残りのすべての点がプラス側に保たれるため、これはすでに有効です。 

単純な間違いは、側面の分布を変更する点を削除する必要があると想定することですが、特別な構造がなくても条件はすでに満たされています。 

## アプローチ

 ブルートフォース手法では、各ポイントを順番に削除し、残りのポイントをすべてスキャンして、すべての x 値が同じ符号を共有しているかどうかを確認します。 n 個の候補のそれぞれについて、さらに O(n) スキャンを実行することになり、時間計算量は O(n^2) になります。 n が 100000 までの場合、これは約 10^10 チェックになり、現実的ではありません。 

重要な観察は、1 つの点を削除した後の状態は、負と正の x 座標の数のみに依存するということです。 削除後は、ゼロ ネガティブまたはゼロ ポジティブのいずれかが必要です。 つまり、1 つのポイントを削除することで、最大 1 つの違反を「修正」できるということです。 

そこで、各辺にいくつの点があるかを計算します。 双方が少なくとも 2 点を持っている場合、1 点を削除しても両方を排除することはできないため、答えは即座に「いいえ」になります。 少なくとも片側が 0 ポイントであれば、答えはすでに「はい」です。 片側にちょうど 1 つの点がある場合、その 1 つの点を削除すると問題が解決するため、答えは「はい」です。 

これにより、問題は単純な計数タスクに軽減されます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | お(1) | 遅すぎる |
 | 最適な計数 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての点を読み取り、x 座標の符号によって分類します。 正確な値や y 座標ではなく、x が正か負かだけを考慮します。 
2. x < 0 を持つ点がいくつあるか、x > 0 を持つ点がいくつあるかを数えます。 
3. すべての点がすでに片側にある場合は、単一の点を削除するとプロパティが保持されるため、「はい」を返します。 
4. 両方のカウントが 1 より大きい場合は、「いいえ」を返します。これは、1 つの点を削除しても各側に少なくとも 1 つの点が残るためです。 
5. それ以外の場合は、片側に残っている 1 つの点を削除すると、その側が完全に削除されるため、「はい」を返します。 

### なぜ効果があるのか

 削除後に条件を満たす唯一の方法は、残ったすべての点が同じ符号の x を持つようにすることです。 1 点を削除すると、片側のカウントが最大で 1 つ減ります。 したがって、最初に両陣営が少なくとも 2 ポイントを持っている場合、1 回の除去ではどちらの陣営も完全に除去することはできません。 逆に、少なくとも 1 つの辺のサイズが 0 または 1 であれば、いつでも点を削除して残りのセットを片側にすることができます。 

これにより、すべての有効な構成の完全な特徴が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
neg = 0
pos = 0

for _ in range(n):
    x, y = map(int, input().split())
    if x < 0:
        neg += 1
    else:
        pos += 1

# already one-sided
if neg == 0 or pos == 0:
    print("Yes")
elif neg <= 1 or pos <= 1:
    print("Yes")
else:
    print("No")
```コードはカウント ロジックを直接実装します。 最初の条件は、すべての点がすでに片側にある場合を処理します。 2 番目の条件は、1 つの点を削除することで一方の側を完全に排除できる状況を捉えています。 

x の符号のみが重要であるため、並べ替えや幾何学的計算は必要ありません。

## 特殊なケース

 重要なエッジ ケースの 1 つは、すべての点がすでに片側にある場合です。 たとえば、すべての x が正の場合、アルゴリズムは neg = 0 および pos = n をカウントします。 条件`neg == 0 or pos == 0`すぐにトリガーされ、出力は「Yes」になります。 これは、任意の点を削除すると片側特性が維持されるという事実と一致します。 

もう 1 つの特殊なケースは、ちょうど 1 つの点が片側にある場合です。 たとえば:

 入力:```
3
-1 2
1 3
2 4
```カウントは neg = 1 および pos = 2 になります。`neg <= 1`は true なので、1 つのマイナスのポイントを削除し、プラスのポイントだけを残すことができます。 アルゴリズムは、削除をシミュレートすることなく、これを正確に識別します。 

最後のエッジケースは、両側に少なくとも 2 つのポイントがある場合です。 例えば：```
4
-1 0
-2 0
1 0
2 0
```ここでは、neg = 2 および pos = 2 です。どの受け入れ条件も満たされていないため、出力は「いいえ」になります。 どの削除を行っても各側に少なくとも 1 つのポイントが残るため、1 回の削除で要件を満たすことは不可能です。
