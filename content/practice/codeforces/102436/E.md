 ## 問題の理解

 私たちに与えられているのは、`h × w`スタンプ。 を含むセル`X`は紙セルの真下にペイントします。`.`透明です。 スタンプは移動できますが、回転することはできません。 これを何度でも使用することができ、ペイントされたセルのセットが完全に塗りつぶされた長方形を形成するようにしたいと考えています。 生成できるすべての長方形の中で、面積が最小の長方形が必要であり、その高さと幅を出力します。 

スタンプの 4 隅のセルには、次のものが含まれることが保証されています。`X`。 この制限は、問題を処理可能にする構造的な特性です。 最終的な長方形の境界に寄与するスタンプの配置は、その 4 つの角のいずれかに揃える必要があります。`X`境界コーナーまたは境界セグメントを持つセル。 スタンプは回転できないため、水平方向と垂直方向の寸法は固定されます。 

どちらの寸法も最大で`3000`したがって、グリッドには最大 900 万個のセルがあります。 時間制限が 1 秒であるため、多項式係数が大きいアルゴリズムは現実的ではありません。 アン`O(h²w²)`または`O((hw)²)`メソッドはすでに大きすぎるでしょう。 すべてのグリッド セルを一定の回数だけ処理する必要があるため、`O(hw)`解決。 

答えの次元には 2 つの有用な境界があります。 結果として得られる長方形はスタンプよりも短くすることはできないため、その高さは少なくとも`h`そしてその幅は少なくとも`w`。 一方、四隅は埋められているため、高さを最大 1 つ拡張するには、垂直方向にずらして 2 つのコピーで十分です。`h - 1`行なので、からの高さを考慮するだけで十分です。`h`を通して`2h - 1`。 同じ現象が水平方向にも当てはまります。 

最初のエッジ ケースは、すでに完全に充填されているスタンプです。 例えば、```
2 3
XXX
XXX
```は一度だけ使用できるので、答えは`2 3`。 複数の配置が常に必要であると想定する不用意な解決策は、長方形を不必要に拡大する可能性があります。 

2 番目のエッジ ケースは、穴のある 1 次元スタンプです。```
1 3
X.X
```答えは、`1 4`。 スタンプを列に配置します`0..2`、与える`X.X`、そして再びコラムで`1..3`、別のペイントされたセルのペアが得られます。 ペイントされたセルが 4 つの位置すべてを占めます。 元のスタンプの寸法のみを考慮するソリューションでは、誤った結果が返されます。`1 3`。 

3 番目のエッジ ケースは垂直穴です。```
3 1
X
.
X
```答えは、`5 2`。 幅を 2 ​​にすると、2 つのコピーで水平方向の寸法を処理できるようになり、スタンプの垂直方向のシフトにより 5 行すべてが埋められます。 水平方向と垂直方向の寸法を個別に扱うソリューションでは、この相互作用が見逃される可能性があります。 

最後に、`1 × 1`スタンプ```
1 1
X
```答えがあります`1 1`。 考慮すべき拡張機能はなく、より大きなフォールバック四角形への応答を初期化する実装でも、スタンプ自体を使用して応答を更新する必要があります。 

## アプローチ

 直接的なアプローチでは、考えられるすべての長方形のサイズを列挙し、スタンプ配置のコレクションでそれを描画できるかどうかを判断しようとします。 可能な最小の寸法は次のとおりです。`h × w`、各次元は最大で まで成長できますが、`2h - 1`そして`2w - 1`。 特定の長方形が達成可能かどうかを確認する前であっても、これは次のようになります。`O(hw)`候補寸法。 考えられるすべてのスタンプ翻訳を考慮して 1 つの候補をテストするには、すでに別の候補が必要です`O(hw)`仕事の量、おおよその生産量`O(h²w²)`最悪の場合の運用。 と`h = w = 3000`、それは次のとおりです`8.1 × 10^13`基本的な操作は実行不可能です。 

有益な観察は、実際にはスタンプ配置のシーケンスを構築する必要がないということです。 四隅`X`セルは、可能な長方形の境界構造を強制します。 高さが固定されると、あらゆる問題が解決されます。`.`cell は必要な幅に下限を課すか、その高さを完全に不可能にします。 

固定行と`.`列のセル`j`。 一番近くで見てください`X`同じ行の左右にあるセル。 ある場合`X`左側に、させてください`l[j]`最も近いそのようなものの 1 つ後の位置になります`X`。 ある場合`X`右側に、させてください`r[j]`その 1 つ前の位置になります。 間隔`[l[j], r[j]]`は、このギャップの周囲で利用できる水平方向の自由度を示しています。 そのサイズは追加の影響を与えます`r[j] - l[j] + 1`元のスタンプの幅を超える列。 

垂直方向も同様に機能します。 各列について、`up[j]`、現在の行の上にある最新の行。`X`。 現在のセルが`.`そしてそのようなものがあります`X`、その垂直距離は`i - up[j]`。 このギャップによって、そのセルの周囲の水平方向の自由度を使用した場合にどの長方形の高さが互換性があるかが決まります。 

このギャップに関連する高さは次のようになります。`n + (i - up[j]) - 1`。 

前回が無い場合は`X`その列では、制約は極端な高さに属します。`2n - 1`。 

水平ギャップがスタンプの左端または右端に達する場合、特殊な状況が 1 つあります。 このような隙間は、対応する高さの有限長方形内で水平方向に移動しても修復できず、その高さは不可能になります。 これを無限大で表します。 

すべての制約を収集した後、可能な高さの最大サフィックスによって、個々の制約がすべての高さに対して必要な最小幅に変わります。 次に、すべての高さを単純にテストできます。`h`に`2h - 1`最小化するものを選択します`height × required_width`。 

公開されたソリューションは、まさにこの特性評価を使用し、グリッドを線形時間で処理します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |`O(h²w²)`|`O(hw)`| 遅すぎる |
 | 最適 |`O(hw)`|`O(hw)`| 承認済み |

 ## アルゴリズムのチュートリアル

 1. スタンプを読み取って配列を作成する`need`可能な最終的な高さによってインデックスが付けられます。`need[H]`最終的には、高さの長方形に必要な最小幅が格納されます。`H`。 最初は、どの高さにも少なくとも元のスタンプの幅が必要です`w`。 
2. 最大高さに対応する`2h - 1`一番下の行を使用します。 一番下の行をスキャンして、次から構成される最長の接尾辞を見つけます。`.`細胞。 その接尾辞に長さがある場合`x`、幅は少なくとも`w + x`。 そのような最大の要件を次の場所に保存します`need[2h - 1]`。 
3. メンテナンス`up[j]`列ごとに。 行を処理する前に、`up[j]`現在の行の上にある最後の行です。`X`列内`j`、 または`-1`何もない場合。 
4. 各行について、すべての行で使用できる水平間隔を決定します。`.`細胞。 左から右へのスキャンでは、最も近い位置の直後の位置が記録されます。`X`左に。 右から左へのスキャンでは、最も近い位置の直前の位置が記録されます。`X`右側に。 セルに何もない場合、`X`一方では、その間隔はその境界に触れます。 
5. 毎回の処理`.`細胞。 その水平方向の要件は次のとおりです。`w + r[j] - l[j] + 1`。 もし`l[j] == 0`または`r[j] == w - 1`、ギャップがスタンプの境界に触れ、関連する高さが不可能になるため、その要件は無限大に設定されます。 
6. セルの影響を受ける高さのインデックスを決定します。 もし`up[j] == -1`、 使用`2h - 1`。 それ以外の場合は使用します`h + i - up[j] - 1`。 制約はこのインデックスに保存されます。 
7. 個々の制約を、接尾辞の最大値が付いたより小さい高さごとの制約に変換します。 この操作の後、`need[H]`高さに必要な幅です`H`、その高さの長方形が存在できない場合は無限大。 
8. すべての高さを列挙します。`h`を通して`2h - 1`。 必要な幅が無限大である高さを無視します。 残りの高さごとに計算します`H × need[H]`そして最低限のものは残しておきます。 
9. 最小領域に属する高さと幅を出力します。 

アルゴリズムの背後にある不変条件は、関連する境界ギャップ上のすべての問題のある空のセルが 1 つの制約によって表されるということです。 その水平方向の間隔は、そのギャップをバイパスするために必要な最小幅を示し、その垂直方向の距離は、そのバイパスを使用できる最終的な高さを示します。 接尾辞の最大値を取得すると、すべての独立した制約が結合されて固定高さが決まります。 したがって`need[H]`あらゆる高さのギャップと互換性のあるまさに最小の幅です`H`。 考えられるすべての高さをチェックして、全体的に最小の長方形を見つけます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    h, w = map(int, input().split())
    a = [input().strip() for _ in range(h)]

    INF = 10**9

    # need[H] = minimum width required for height H.
    # Only H in [h, 2h - 1] can be relevant.
    need = [w] * (2 * h)

    # For the maximum possible height, the bottom row gives a direct
    # horizontal requirement.
    longest_suffix = 0
    cur = 0
    for j in range(w):
        if a[h - 1][j] == '.':
            cur += 1
        else:
            cur = 0
        longest_suffix = max(longest_suffix, cur)

    need[2 * h - 1] = w + longest_suffix

    # up[j] is the last row above the current row containing X in column j.
    up = [-1] * w

    for i in range(h):
        # l[j] and r[j] describe the interval around a dot that is
        # bounded by X cells in the current row.
        l = [0] * w
        r = [w - 1] * w

        last_x = -1
        for j in range(w):
            if a[i][j] == 'X':
                last_x = j
            elif last_x != -1:
                l[j] = last_x + 1

        next_x = w
        for j in range(w - 1, -1, -1):
            if a[i][j] == 'X':
                next_x = j
            elif next_x != w:
                r[j] = next_x - 1

        # Evaluate all dots using the vertical information from
        # previous rows.
        for j in range(w):
            if a[i][j] == 'X':
                continue

            width_needed = w + (r[j] - l[j] + 1)

            if l[j] == 0 or r[j] == w - 1:
                width_needed = INF

            if up[j] == -1:
                height_index = 2 * h - 1
            else:
                height_index = h + (i - up[j]) - 1

            need[height_index] = max(
                need[height_index],
                width_needed
            )

        # Update the vertical last-X positions after processing the row.
        for j in range(w):
            if a[i][j] == 'X':
                up[j] = i

    # A constraint stored at height H also applies to every smaller
    # candidate height. Propagate those constraints backwards.
    for H in range(2 * h - 1, 0, -1):
        need[H - 1] = max(need[H - 1], need[H])

    best_area = (2 * h) * (2 * w)
    best_h = 2 * h
    best_w = 2 * w

    for H in range(h, 2 * h):
        if need[H] >= INF:
            continue

        area = H * need[H]
        if area < best_area:
            best_area = area
            best_h = H
            best_w = need[H]

    print(best_h, best_w)

if __name__ == "__main__":
    solve()
```の`need`配列は中心的なデータ構造です。 そのインデックスは、からのあらゆる可能な最終高さを表します。`h`を通して`2h - 1`、その値は対応する最小幅を表します。 

一番下の行の前処理は、垂直方向の分離が最大である特殊なケースを処理します。 その行のドットのサフィックスは、最終的な長方形を水平に拡張しないとカバーできないため、その長さが必要な幅に直接影響します。 

すべての行について、2 つの方向のスキャンによって計算が行われます。`l`そして`r`同じ点の連続を繰り返し通過する必要はありません。 これは、元の線形時間のアイデアの Python フレンドリーなバージョンです。 元の実装は、それぞれの周囲のドットをたどることによって同等の更新を実行します。`X`。 

の`up`配列は、現在の行のすべてのドットが処理された後にのみ更新されます。 この順序は微妙です。 ドットの場合`(i, j)`、関連する以前の`X`厳密にそれを上回っている必要があります。 以来`(i, j)`それ自体はドットなので、`X`しかし、更新を遅らせると、意図した不変式が明示的になります。 

接尾辞の最大値も必須です。 より大きな高さで生成された制約は、互換性のあるすべてのより小さな高さに対する制限を表します。 右から左に伝播すると、`need[H]`高さに適用されるすべての制限が含まれています`H`。 

Python の整数はオーバーフローせず、格納されるすべての値は最大でも`INF`通常の次元を除くため、特別な整数の処理は必要ありません。

水平ギャップの場合```
