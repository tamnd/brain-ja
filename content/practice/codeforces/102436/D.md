 ## 問題の理解

 整数のセットを構築する必要があります。各整数は最大でも次の値を使用します。`s`ビット、つまりセットの空ではないすべてのサブセットのビットごとの AND をとった場合、正確に`k`異なる値が表示されます。 セット自体が出力であるため、必要な数の個別のサブセット AND 結果を満たす任意の数値を自由に選択できます。 

たとえば、このセットでは、`{9, 6, 10}`、シングルトンのサブセットは次のようになります。`9`、`6`、 そして`10`。 いくつかのより大きなサブセットは、`9 & 10 = 8`、`10 & 6 = 2`、 そして`9 & 6 = 0`。 したがって、結果の値のセットは次のようになります。`{0, 2, 6, 8, 9, 10}`、これには 6 つの値が含まれます。 公式サンプルでは、​​まさにこの構造が使用されています。 

決定的な問題は、サイズのセットの空ではないサブセットの数が`n`は`2^n - 1`。 出力自体は最大でも次のように制限されます。`125`数値なので、すべてのサブセットを直接列挙するには、最大で`2^125 - 1`、 だいたい`4.25 * 10^37`、AND 演算。 たとえ各操作が非常に安価だったとしても、これは 3 秒の制限でサポートできる範囲をはるかに超えています。 スコアリングの制約により、`k`の順序に達するために`2^20`したがって、構築では、それらの答えを明示的に列挙することなく、表現される答えの数が指数関数的に増加する必要があります。

 ## アルゴリズムのチュートリアル

 1. から始める`k = 1`そしてセット`{0}`。 空ではないサブセットが 1 つだけ存在するため、異なる AND 値が 1 つだけ存在します。 メンテナンスも行っております`bit`、構築に使用できる次のビット位置。 
2. 現在のターゲットの場合`k`が奇数で 1 より大きい場合は、まず次のセットを構築します`k - 1`。 次に、新しいビットに移動し、新しいビットを含め、これまでに使用されたすべてのビットに 1 を含む数値を追加します。 この数値自体により、新しい AND 値が 1 つだけ作成されます。 これを古いサブセットと AND 演算しても、以前に関連していたすべてのビットが新しい数値の 1 になるため、そのサブセットの結果は変わりません。 
3. 現在のターゲットが`k`が偶数である場合は、最初に個別の結果の数が であるセットを構築します。`k / 2`。 させて`bit`最初の未使用ビットになります。 このビットを既存のすべての番号に設定します。 
4. 新しい数値を追加します。`bit`ビットはすべて 1 で、新しいビットは 0 です。 この数字は数値的には`(1 << bit) - 1`。 
5. 新しく追加された数値を含まないサブセットを考えます。 その AND には新しいビットが設定されており、その下位ビットは、対応する古いサブセットによって生成された AND とまったく同じです。 したがって、これらのサブセットは`k / 2`新しいビットが設定されたグループ内の値。 
6. 次に、新しい数値を含むサブセットを考えます。 新しいビットはゼロになりますが、新しい数値の位置には常に 1 が含まれるため、下位ビットは変更されません。 これらは別のものを与えます`k / 2`新しいビットがクリアされた状態で値が表示されます。 
7. 一方のグループには新しいビットがセットされ、もう一方のグループにはクリアされているため、2 つのグループに同じ整数を含めることはできません。 したがって、個別の AND 値の数は正確に次のようになります。`k`。 
8. 到達するまで再帰的に繰り返します。`k = 1`、構築された数値を返します。 すべての偶数のターゲットは 2 で除算され、最終的に偶数の値に達する前に 1 より大きいすべての奇数のターゲットが 1 ずつ減らされるため、再帰の深さは対数のみになります。 

不変条件は、ターゲットを構築した後です。`k`、生成されたすべてのサブセット AND 値は現在の構造によって表され、すべての数値はすでに導入されているビットのみを使用します。 の`+1`演算では新しい値が 1 つだけ追加されますが、倍加演算ではすべての古い AND 値の互いに素なコピーが 2 つ作成されます。 これらの操作は異なる結果の数を変換するため、`x`に`x + 1`または`2x`正確に、再帰的分解に従って、`k`最終セットが正確に含まれることを保証します`k`個別のサブセットの AND 値。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build(k):
    if k == 1:
        return [0], 0

    if k & 1:
        result, bit = build(k - 1)

        # Reserve a fresh bit and add a number having
        # all currently relevant bits set.
        bit += 1
        result.append((1 << bit) - 1)

        return result, bit

    result, bit = build(k // 2)

    # Put the fresh bit into every old number.
    mask = 1 << bit
    for i in range(len(result)):
        result[i] |= mask

    # The new number has the fresh bit cleared and
    # every older bit set.
    result.append(mask - 1)

    bit += 1
    return result, bit

def solve():
    k, s = map(int, input().split())

    result, _ = build(k)

    print(len(result))
    print(*result)

if __name__ == "__main__":
    solve()
```再帰的`build`関数は 2 つの構築ルールを直接実装したものです。 基本ケースが返されます`{0}`、これには 1 つの異なるサブセット AND があります。 

奇数のために`k`、再帰呼び出しによって作成される`k - 1`価値観。 ビットカウンターをインクリメントして追加します`(1 << bit) - 1`。 以前に構築されたすべての数値は下位ビットを使用するため、この追加された値はすべての古いサブセット AND よりも大きく、したがって 1 つの新しい結果に寄与します。 

偶数の場合`k`、再帰呼び出しによって作成される`k / 2`価値観。 表現`1 << bit`現在未使用のビットを識別し、それを既存のすべての数値と OR 演算すると、そのビットがすべての古いサブセットの AND に入れられます。 追加された`mask - 1`古いビットはすべて設定されていますが、新しいビットはクリアされています。 したがって、古いサブセットと新しい数値を含むサブセットは、新しいビットによって分離されます。 

Python の整数には任意の精度があるため、整数のオーバーフローの問題はありません。 唯一関連する境界は問題の境界です`s`-ビット制限。 この構築では、再帰中に導入された新しいビットのみが使用され、問題により、要求されたデータに対して十分な使用可能なビットが保証されます。`k`。 

再帰の深さは小さく、次のビット数によって制限されます。`k`, そのため、指定された制約に対して Python の再帰制限には近づきません。

import io

    if k == 1:
        return [0], 0

 のために`k = 1`、正確な入力は次のとおりです`1 1`。 アルゴリズムはすぐに基本ケースに到達し、戻ります。`{0}`。 単一の数値を含む、空ではないサブセットが 1 つだけあります。`0`したがって、唯一の AND 結果は次のようになります。`0`。 したがって、出力は 1 つの数値であり、異なる結果が 1 つだけあります。 

奇妙なターゲットに対して`k = 3`、 考慮する`3 2`。 アルゴリズムはまず次の答えを構築します。`2`、与える`{1, 0}`。 次に、次のビットに移動して追加します`3`、生産`{1, 0, 3}`。 シングルトン`3`は新しい結果ですが、`3 & 1 = 1`そして`3 & 0 = 0`, したがって、他の新しい値は表示されません。 明確な結果はまさに`{0, 1, 3}`、必要な出力数は次のようになります。`3`。 

2 のべき乗境界の場合`k = 4`、 考慮する`4 2`。 構造が与えるもの`{3, 2, 1}`。 そのサブセットの AND 値は次のとおりです。`3`、`2`、`1`、`2`、`1`、`0`、 そして`0`したがって、個別の結果は正確に次のようになります。`{0, 1, 2, 3}`。 すべての値は 2 ビットに収まります。 これは、2 倍演算で新しく導入されたビットによってサブセットを区別する必要がある理由を示しています。 

最大限の目標に向けて`k = 2^20`、再帰的プロセスは完全に 2 倍演算で構成されます。 2 倍になるたびに 1 つの新しいビットが導入され、構築される要素の数が少なくなります。 結果の数値は以下のままです`2^20`、つまり、それらは適合します`20`ビット。 したがって、この構築は、指数関数的に多くのサブセットを列挙することなく、スコアリング制約から最大のターゲットに到達します。 

同様の構築的な問題に適用する最も有用な不変条件は、新しいビットがセパレータとして機能できることです。 すべての古い結果がそのビットを設定し、特別に選択された新しい要素を含むすべての結果がそのビットをクリアすると、以前は同一だった 2 つの結果のコレクションが結合されなくなります。 この考え方が認識されると、達成可能な状態の数を 2 倍にすることは、指数関数的な検索ではなく、単純なビット単位の構築になります。
