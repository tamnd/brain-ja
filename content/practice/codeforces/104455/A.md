 ## 解決策
 ## 問題の理解

 2 人のプレーヤーが独立して、均一な整数の「サイコロ間隔」のペアを 2 回振り、2 つの結果を合計します。 アリスはインターバルを使用します$[l_1, r_1]$そしてボブが使うのは$[l_2, r_2]$。 各ロールは区間内の整数にわたって均一であるため、各合計は 2 つの独立した一様変数の合計になります。 

タスクは正確な確率を計算することではなく、どのプレイヤーがより大きな合計額を取得する可能性が高いかを判断することです。 両方のプレーヤーの結果は独立した均一範囲の対称的な合計であるため、この比較は、合計の 2 つの離散分布を比較することになります。 

入力には多くのテスト ケースが含まれているため、ソリューションでは間隔の各ペアを独立して効率的に処理する必要があります。 制約は以下に達します$10^5$テスト ケース、および値は次のように大きくできます。$10^9$、結果の列挙は除外されます。 正しい解決策は、テスト ケースごとに比較を定数時間の式に減らす必要があります。 

単純なシミュレーションでは、すべてを列挙しようとします。$(r_1 - l_1 + 1)^2 (r_2 - l_2 + 1)^2$範囲が大きくなり、二乗の組み合わせが爆発する可能性があるため、中程度の範囲であっても、結果は完全に実行不可能です。 テスト ケースごとに分布の完全な畳み込みを計算するだけでも遅すぎます。 

重要な問題は、それぞれの合計分布は三角形ですが、必要なのはそのような 2 つの分布間の比較のみであり、その完全な形状ではないことです。 

## アプローチ

 ブルートフォース手法では、アリスとボブの考えられるすべての結果のペアを列挙し、それらの合計を計算し、アリスの合計がどのくらい大きくなるかを数えます。 これは確率を正しく取得しますが、4 つの独立した確率変数のすべての組み合わせを反復する必要があり、制約の下では不可能です。 

重要な観察は、各プレイヤーの合計分布が 2 つの一様分布の畳み込みであり、対称な三角形分布を形成しているということです。 確率を明示的に計算する代わりに、そのような 2 つの分布間の順位の期待値を比較するだけで済みます。 

均一な整数間隔の場合$[l, r]$、2 つの独立した描画の合計には分布があり、その順序は平均と分散の構造によって完全に決定されます。 より具体的には、アリスがボブに勝つ確率は、数直線上の間隔の相対的な位置と間隔の幅にのみ依存します。 これにより、問題は、確率的優位性の意味で、アリスの分布がボブの分布と比較して「右にシフト」しているかどうかを比較することに帰着します。 

どちらも同一の独立した均一の合計であるため、分布は単峰性かつ対称的であるため、比較は区間の中点の比較に帰着します。$(l + r)$。 2 つの独立したドローの合計には期待値があります$l + r$、したがって、アリスの期待合計は次のようになります。$2(l_1 + r_1)/2 = l_1 + r_1$、ボブについても同様です。 

したがって、アリスは次の場合に勝率が高くなります。$$l_1 + r_1 > l_2 + r_2$$アリスに有利ではない絆で。 

これにより、各テスト ケースが定数時間の演算に削減されます。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 各テスト ケースは独立しているため、テスト ケース間で状態が引き継がれることはありません。 
2. 各テスト ケースについて、2 つの間隔を読み取ります。$[l_1, r_1]$そして$[l_2, r_2]$。 これらは、アリスとボブの 1 つのサイコロの出目の分布を定義します。 
3. アリスのスコアを次のように計算します。$l_1 + r_1$、これは彼女の合計分布の中心を表します。 
4. ボブのスコアを次のように計算します。$l_2 + r_2$、これは彼の合計分布の中心を表します。 
5. 2 つのスコアを比較します。 アリスの値が厳密に大きい場合は「Yes」を出力し、それ以外の場合は「No」を出力します。 

中心が等しいということは分布の対称性が同じであることを意味するため、比較は厳密であり、どちらのプレイヤーも厳密には勝率が高くありません。 

### なぜ効果があるのか

 各プレイヤーの合計は、ある間隔にわたる 2 つの独立した一様変数の合計です。 このような分布は対称的であり、そのエンドポイントによって完全に決定されます。 ある合計が別の合計を超える確率は、これらの対称分布の相対的なシフトにのみ依存します。 両方の分布は同一の形状ファミリーを持っているため、それらの中心を比較することによってそれらの順序が保存されます。 したがって、比較すると、$l + r$どちらの分布が他方の分布を確率的に支配するかを判断するには、これで十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        l1, r1 = map(int, input().split())
        l2, r2 = map(int, input().split())

        a = l1 + r1
        b = l2 + r2

        if a > b:
            out.append("Yes")
        else:
            out.append("No")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```このソリューションは各テスト ケースを独立して処理し、定数時間の演算のみを実行します。 使用する`sys.stdin.readline`最大で高速な入力処理を保証します。$10^5$ケース。 結果はバッファリングされ、印刷が遅く繰り返し行われるのを防ぎます。 

微妙な点は、確率を明示的に計算しないことです。 これには分布の畳み込みが必要になりますが、順序付けが間隔の中心の比較に限定されるため不要です。

 ## 特殊なケース

 両方の間隔が同じ場合、両方のプレイヤーの分布は同じになるため、条件は次のようになります。$l_1 + r_1 > l_2 + r_2$失敗し、出力は正しく「No」になります。 

アリスの間隔が厳密に広いが左にシフトされている場合、次のようになります。$[1, 100]$対$[50, 51]$, ボブの中心が大きいため、それでも勝ちます。 エンドポイントの合計のみが重要であるため、アルゴリズムはこれを正しく捕捉します。 

両方の間隔が極端に大きい場合（最大$10^9$)、Python ではオーバーフローは発生せず、整数の加算は安全なままであり、正確性が維持されます。
