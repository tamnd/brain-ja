 ## 解決策
 ## 問題の理解

 ドミノのコレクションが与えられます。各ドミノは 1 から n までの整数のペアとして表され、ドミノの総数 n は偶数です。 タスクは、これらのドミノを 2 つのグループに分割し、各グループ内で複数のドミノに数字が表示されないようにすることです。 すべてのドミノは、正確に 1 つのグループに割り当てられる必要があります。 出力は、そのような分割が可能かどうかに応じて、テスト ケースごとに単純な YES または NO になります。 

制約が非常に厳しいため、考えられるすべてのパーティションを試行することはできません。 n が最大 2・10^5 で、テスト ケースが最大 10^4 の場合、すべての除算をチェックする単純な O(2^n) アプローチは完全に不可能です。 最悪の場合、テスト ケースあたり O(n^2) でも遅すぎる可能性があります。 このため、線形または線形に近いアルゴリズムの観点から考える必要があります。 

ドミノに繰り返しの数字または同一のドミノが含まれる場合、明らかではないエッジケースが発生します。 たとえば、n = 2 でドミノが [1,1] と [2,2] の場合、グループの 1 つで数字を繰り返さない限りドミノを分割することはできないため、出力は NO になる必要があります。 もう 1 つの注意が必要なケースは、2 つのドミノが [1,2] と [2,1] である場合です。 すべての番号はグローバルに一意ですが、競合を避けるために慎重に割り当てる必要があります。 

## アプローチ

 ブルートフォースアプローチでは、n 個のドミノを n/2 個のドミノからなる 2 つのグループに分割するあらゆる可能な方法が試行されます。 部門ごとに、各グループに一意の番号のみが含まれているかどうかを確認します。 このアプローチは正しいですが、完全に非現実的です。2・10^5 ドミノの分割には、およそ 10^60 通りの可能性があり、計算上の実現可能性をはるかに超えています。 

問題を単純化する重要な観察は、問題をグラフとして扱うことです。 1 から n までの各数字をノードとして、各ドミノをその 2 つの数字を接続するエッジとして考えます。 どのグループにも同じ数字が含まれていないという条件を満たすには、ノードを共有する 2 つのエッジが同じグループに属さないようにドミノを分割する必要があります。 これは、グラフが **2 部**であるかどうかを確認するのと同じです。同じノードに属するエッジが異なる色になるように、グラフのエッジを 2 色で着色できますか? エッジの 2 部グラフの色付けは、すべての接続されたコンポーネントが偶数長さのサイクルまたは非巡回である場合に限り、常に可能です。これは、奇数長さのサイクルでは競合が強制されるためです。 

この洞察により、問題をドミノ接続の隣接リストの構築、接続されたコンポーネントの検出、各コンポーネントが 2 部構成であるかどうかの確認に減らすことができます。 深さ優先検索 (DFS) またはパリティを使用した共用体検索は、このチェックを効率的に処理できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | DFS によるグラフの二分割 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. n 個のノード (番号ごとに 1 つ) を含む隣接リストを初期化します。 各ドミノ (a、b) について、a の隣接リストに b を追加し、b の隣接リストに a を追加します。 これにより、接続数を表す無向グラフが構築されます。 
2. 配列を作成する`color`サイズ n+1 は -1 に初期化され、各ノードの 2 分割カラー (0 または 1) が格納されます。 
3. 数値 1 から n までを繰り返します。 番号が色付けされていない場合は、そのノードから開始して初期色 0 で DFS を実行します。 
4. DFS で、現在のノードに指定された色を割り当てます。 次に、各近傍について、色が付いているかどうかを確認します。 

- 色が付いていない場合は、反対の色の隣に再帰します。 
- 現在のノードと同じ色で既に着色されている場合、競合が存在し、グラフは 2 部構成ではありません。 
5. DFS 中に競合が検出された場合は、現在のテスト ケースに対して NO を出力します。 それ以外の場合は、すべてのノードを処理した後、YES を出力します。 

これが機能する理由は、適切な 2 部カラーリングにより、同じグループに割り当てられた 2 つの入射エッジを持つノードがないことが保証されるためです。 ドミノのたとえでは、これにより、同じグループ内に数字が 2 回出現することがなくなります。 すべての接続されたコンポーネントは個別に処理され、競合は DFS トラバーサルでローカルに検出されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        adj = [[] for _ in range(n + 1)]
        dominoes = []
        for _ in range(n):
            a, b = map(int, input().split())
            adj[a].append(b)
            adj[b].append(a)
            dominoes.append((a, b))

        color = [-1] * (n + 1)
        possible = True

        def dfs(u, c):
            nonlocal possible
            color[u] = c
            for v in adj[u]:
                if color[v] == -1:
                    dfs(v, 1 - c)
                    if not possible:
                        return
                elif color[v] == c:
                    possible = False
                    return

        for i in range(1, n + 1):
            if color[i] == -1:
                dfs(i, 0)
                if not possible:
                    break
        print("YES" if possible else "NO")

solve()
```隣接リストは、どの番号が同じセット内に存在できないかを効率的に追跡します。 DFS は、各番号が競合せずに 1 つのセットのみに表示されるように色を割り当てます。 長いチェーンの深い DFS を処理するために、再帰制限が増加しました。 チェック中`not possible`内部再帰により、競合が発生した場合に早期に終了することが保証されます。

## 特殊なケース
