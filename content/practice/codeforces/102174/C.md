 ## 問題の理解

 最初の (i) だけの怪には (d_i) 点の生命値と (x_i) 点の攻撃力があり、森林時間の攻撃力は次のとおりです。 (k)。 森が攻撃するたびに、その怪人がこの攻撃を受けていない限り、怪人は 1 回反撃することができ、その回数は森が直接害を受ける回数であり、その回数はこの怪人が次の対戦の回数まで存続することになる。 

それぞれに、最後に結合された攻撃力が (k) 追加されます。つまり、これが (t) の結合水の結果に含まれる場合、これは ((t+1)k) になります。 水果の効果は前回組み合わせたもののみ継続し、除去された水果も再度使用することはできません。 

私たちは、すべての森林が受ける全体的な被害を最小限に抑えるために、水の分配方法を決定する必要があります。 

第 (i) だけ怪兽については、完全に水果を使用しない場合、必要があります

 [
 q_i=\left\lceil\frac{d_i}{k}\right\rceil
 ]

 森クニクの最初の攻撃により、最後の攻撃は受け付けられないため、これは唯一の脅威である。 

[
 (q_i-1)x_i。 
]

 あるフィールドで追加の水フルーツを獲得した場合、追加のベース攻撃単位 (k) に相当します。 次の攻撃は、この怪奇な投入 (f) の結果として、合計 (q_i+f) 単位の攻撃力を共有し、これらの攻撃力をいくつかの回帰に分配することができる。 (q_i-f)、水フルーツの帯からの攻撃力をすべて前倒し終了缶に使用することができます。したがって、水フルーツを1つ投入するたびに、この怪奇な反撃を1回減らすことができ、(x_i)の点害も減らすことができます。 

一只怪兽最多只能从 (q_i) 回合短到回合，故它最多能使用

 [
 q_i-1
 ]

 その後、模擬コンテナからのリソース割り当ての問題が発生しました。各怪盗は (q_i-1) の位置を提供し、各位置で 1 つの水の結果を使用して (x_i) の利益を得ることができ、全体で (c) のみを共有します。 份水果。 

(n) は (10^5) に達することができますが、(k,c,d_i,x_i) は最大で (10^6) に達することができるため、すべてのウォーターフルーツ状態とすべての怪獣状態に関係する二元運動のいずれも通過できません。 (10^{11}) の状態では、1 の制限の下ではまったく実行できません。私たちが必要としているのは、各ウォーター フルーツ バンドを利用する毎秒の収益が、この特性にのみ割り当てられているということだけです。 

危険が生じやすい境界状況にも注意が必要です。 

最初のケースは、一度だけ接続する必要がある場合です。```
1 10 100
7 5
```出应该です`0`ベース攻撃の強度が非常に強力な怪奇であるため、害を及ぼす場合に怪奇は根本的に反応しません。 

2 番目のケースは、生命値が攻撃力の整数倍である場合です。```
1 3 1
6 7
```出应该です`0`水の果がない場合は2回の攻撃が必要ですが、水の果があれば最初の再攻撃力は6になり、直接書き込むことができます。`d // k + 1`典型的な除去境界問題が発生します。 

3 番目のケースは、水果の数が利益を生み出すことができるすべての場所を超えている場合です。```
2 10 100
1 4

```出て然です`0`両方とも一度結合するだけでよく、多くの水の結果は何の利益ももたらさないようにコード化すると、利益が得られます。 

4 番目のケースは、ウォーター フルーツが優先的に攻撃する怪奇です。```

```最初の怪奇は 1 回だけ必要で、それ自体には短縮可能な回数はありません。`0`各水果ごとに害を減らすのではなく、より小さな水果を分配する場合、危険な戦略が得られる可能性がある。 

## アプローチ

 最も直接的な方法は、各怪獣を 1 つのリソース消費の対象とみなすことです。 (q_i) 次に、以前のいくつかの怪獣にそれぞれどのくらいの水が割り当てられたかを検討します。 水の結果、移行時に現在使用されている水の数。 

たとえさらなる変換が行われたとしても、この種の方法は、少なくとも(n)と(c)の両方の状態を処理する必要がある。 

[
 n c=10^5\times10^6=10^{11},
 ]

 これは、許容範囲を超えている。真新しいものは、各怪獣が使用できる水の量を超えており、濃度もさらに高くなる可能性がある。 

真の突破口は、より綿密な見解から得られる。 (i) のただの怪奇については、本来は (q_i) 次の攻撃が必要、つまり反撃される (q_i-1) 次に、追加の水を使用することは、1 回のベース攻撃単位を追加することに相当するため、必要な攻撃回数が 1 回減少すると考えられます。 点害があるので、この奇妙なものはどれも完全に同じ利益（x_i）を持っています。 

次に、(i) の (q_i-1) 個の物品の重量が (x_i) であると仮定すると、バックパックの容量は (c) になります。 

同じ怪奇から生成されるすべての物品の値は同じであるため、これらの物品はすべて (x_i) から順に並べて、可能な限り攻撃力が最も高い怪獣を水果に配置するだけで済みます。 ただし、削除後、次の唯一の怪奇現象を再処理します。 

最初の解決策は、すべての怪奇現象が水のない間に造られる害です。 

[
 \sum_i(q_i-1)x_i。 
]

 １つの水の結果を使用するたびに、（ｘ＿ｉ）を応答計画から取り除くだけでよい。

 ## アルゴリズムのチュートリアル

 1. 对每只怪兽計算它水果無し時必要的攻撃回数

 [
 q_i=\left\lceil\frac{d_i}{k}\right\rceil
 =\frac{d_i+k-1}{k}。 
]

 最後の攻撃は反撃に遭わないため、最初の害は ((q_i-1)x_i) になります。 
2. 第 (i) 只怪兽の可用水果の数量は次のとおりです

 [
 cap_i=q_i-1。 
]

 １つの水の効果を使用するたびに、この怪奇の１回だけが反作用の再結合を引き起こす可能性があると考えられ、したがって、各水の効果は（ｘ＿ｉ）点の害を減らすことができる。したがって、（ｑ＿ｉ－１）を超える水の効果は使用できない。 
3. すべての怪獣に大きな順から順に攻撃力 (x_i) を与えます。 

このように並べると、上の例は、すべての水果の消費量が 1 であるため、各水果はそれぞれのわずかな害のみを考慮し、より収益が得られる位置に配置することに劣らない、最大の水果を優先して使用することを意味します。 
4. 順番に処理した後の怪獣。 

[
 \min(c,cap_i)
 ]

 これらの水果バンドからの収益は、応答計画から除外され、その後、残りの水果の量が減少する。 
5. 水の効果がなくなるか、すべての怪獣が短い回復時間を経ずに終了する。 

### なぜ効果があるのか

 每只怪兽拆成 (q_i-1) 个虚拟物品，每个消費物品一份水果并提供 (x_i) 特定の水の結果は、特定の怪奇に対する効果であり、怪異の反応が 1 つ減るごとに、適切に 1 回受けることができるため、すべてがその中からそのような仮想物品を選択すると見なすことができます (x_i) 点害は、これらの単位重量の物品の中から最も多く（ｃ）を選択して、値を全体的かつ最大にする。 

単位重量の物品については、最大の物品が選択されるが、ここでは、各物品の攻撃値は、攻撃力（ｘ＿ｉ）であるため、（ｘ＿ｉ）となる。 最初の害から得られる最大の利益を取り除き、各怪獣ごとに最も多く選択するのが、完全に局所的な最善の解決策です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k, c = map(int, input().split())

    monsters = []
    answer = 0

    for _ in range(n):
        d, x = map(int, input().split())

        rounds = (d + k - 1) // k
        useful = rounds - 1

        answer += useful * x

        if useful > 0:
            monsters.append((x, useful))

    monsters.sort(reverse=True)

    remaining = c

    for x, useful in monsters:
        if remaining == 0:
            break

        use = min(remaining, useful)
        answer -= use * x
        remaining -= use

    print(answer)

if __name__ == "__main__":
    solve()
```代初先計算`rounds = (d + k - 1) // k`、これは整数形式での方向取りです。`d // k + 1`(d) が (k) によって適切に削除されるため、両者は異なります。`useful = rounds - 1`この奇妙な現象は、水の効果によって多少なりとも打ち消される可能性があることを示しています。`useful`0 の場合、この奇妙な鳥だけがすでに死亡しているため、順序付けグループに追加する必要はありません。 

变量`answer`この値は、各怪獣について、完全に無水で保存した場合の全体的な害悪である。`(rounds - 1) * x`。 

続いて写真`x`Python の要素の順序は最初の要素よりも優先されるため、`monsters.sort(reverse=True)`2番目の要素は容量だけであり、必要な主要な順序には影響しません。 

一怪を処理したとき、実際に使用した水果の量は`min(remaining, useful)`これにより、過剰な水の効果を超えることはなく、また、同じ怪奇な果物がすべて減少することもありません。`x`点最终伤害，所以直接実行`answer -= use * x`。 

すべての数値で整数計算を使用する必要があります。最大全体害は約 (10^5\times10^6\times10^6=10^{17}) の量レベルに達する可能性がありますが、Python の整数には 64 ビットの固定制限がないため、C++ で使用されます。`long long`。
