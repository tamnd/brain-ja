 ## 問題の理解

 各テスト ケースに対して、2 つの整数 (a) と (b) が与えられ、以下を定義します。 

[
 f(x)=\sqrt{ax}+b。 
]

 すべての固定点、つまり (f(x)=x) を満たすすべての (x) を見つけて、それらの値を昇順に出力する必要があります。 元の問題では、少なくとも 1 つの固定小数点が存在し、すべての固定小数点が整数であることが保証されます。 公式ステートメントでは、(1\le T\le100) と (-1000\le a,b\le1000) を使用して、まさにこの形式の関数が使用されています。 

平方根は、(a\ne0): (ax\ge0) が必要な場合にも定義域条件を課します。 興味深いのは、浮動小数点演算を使用せずに平方根を消去できることです。 固定点では、

 [
 x=\sqrt{ax}+b。 
]

 (b)を反対側に移動して定義します

 [
 y=x-b。 
]

 すると (y=\sqrt{ax})、(x) と (b) は整数であるため、(y) は非負の整数でなければなりません。 二乗すると (y) に二次方程式が与えられます。これは、固定点が最大 2 つ存在できることを意味します。 

(a) と (b) の境界は小さいため、慎重に境界を定めた総当りのソリューションでも合格します。 たとえば、から

 [
 y^2=a(y+b)
 ]

 私たちは持っています

 [
 y^2\le |a|y+|ab|。 
]

 (y\ge0) の場合、これは (y\le |a|+\sqrt{|ab|}\le2000) を意味します。 (x=y+b) なので、すべての固定点は (-1000) と (3000) の間にあります。 100 件すべてのケースについてこの範囲全体をスキャンする場合、候補チェックのコストはわずか約 (400100) です。 ケースごとに 200 万個の可能な (x) 値をチェックするなど、より広範な単純スキャンでは、すでに約 (2\times10^8) 個のチェックが必要となり、1 秒の制限に対して不必要にコストがかかります。 二次定式化ではスキャンが完全に削除されます。 

不用意に実装すると失敗するケースがいくつかあります。 (a=0) の場合、方程式はまったく二次方程式ではありません。 入力用```
1
0 -5
```関数は (f(x)=-5) であるため、唯一の固定小数点は (-5) です。 正しい出力は次のとおりです```
1
-5
```(a) で除算したり、二次公式を盲目的に適用したりする実装は、ここでは失敗します。 

もう 1 つの罠は、二次ルートが (y=\sqrt{ax}) を表すため、非負のルートのみが有効であるということです。 のために```
1
-1 -2
```二次方程式は (y^2+y-2=0) で、その根は (1) と (-2) です。 (y=1) のみが平方根になります。 (x=y+b=-1) となるため、出力は次のようになります。```
1
-1
```両方の 2 次ルートを保持すると、別の値が誤って出力されます。 

3 番目の問題は、判別式が完全二乗である必要があることです。 のために```
1
1 1
```判別式は (1+4=5) であるため、二次方程式には整数根 (y) がありません。 この入力は問題の保証の範囲外ですが、浮動小数点の使用と平方根の四捨五入が一般的な手法として不適切である理由を示しています。 整数判別テストは正確です。 

## アプローチ

 直接的なアプローチは、可能な (x) を列挙し、(ax\ge0) かどうかを計算し、

 [
 x-b=\sqrt{ax}。 
]

 答えは整数であることが保証されているため、((x-b)^2=ax) と (x-b\ge0) をチェックすることで浮動小数点を回避できます。 安全な範囲は方程式から導き出すことができ、実際の制約の下では、この強引な方法ではテスト ケースごとに数千回のチェックしか必要としません。 この問題については受け入れられていますが、数学的構造は明らかにされていません。 

より便利なアプローチは、平方根自体を変数に置き換えることです。 固定点で、

 [
 y=\sqrt{ax}。 
]

 固定小数点方程式は直ちに (x=y+b) になります。 これを (y^2=ax) に代入すると、次のようになります。 

[
 y^2=a(y+b)、
 ]

 または

 [
 y^2-ay-ab=0。 
]

 元の問題を二次方程式の非負の整数根を求める問題に縮小しました。 その判別式は

 [
 D=a^2+4ab。 
]

 (D) が非負の完全平方でない場合、整数根 (y) は存在しません。 それ以外の場合、考えられる 2 つのルートは次のとおりです。 

[
 y=\frac{a+\sqrt D}{2},
 \qquad
 y=\frac{a-\sqrt D}{2}。 
]

 非負で整数の根のみを保持し、(x=y+b) を使用してそれぞれを逆変換します。 最後に、最大 2 つの回答を並べ替えることで、必要な順序が得られます。 

ブルートフォース手法は、制約により検索空間がたまたま小さくなるため機能しますが、二次観測により作業が定数の整数演算に削減されます。 また、すべての浮動小数点の問題もソリューションから削除されます。

 | 最適 | (O(T)) 整数平方根コストは別 | テスト ケースごとの (O(1)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. (a) と (b) を読んでください。 (a=0) の場合、すべての (x) に対して (\sqrt{ax}=0) となるため、関数は単純に (f(x)=b) となります。 唯一の不動点は (x=b) です。 一般的な導出では (a\ne0) が想定されるため、この特殊なケースは二次方程式を作成する前に処理する必要があります。 
2. (a\ne0) には、(y=\sqrt{ax}) を導入します。 固定点では (x=y+b) となり、平方根なので (y\ge0) になります。 
3. (x=y+b) を (y^2=ax) に代入します。 これにより、

 [
 y^2-ay-ab=0。 
]

 したがって、すべての固定点はこの二次方程式の根に対応し、すべての有効な非負整数の根 (y) は固定点を与えます。 
4. 判別式を計算する

 [
 D=a^2+4ab。 
]

 (D<0) の場合、二次方程式には実根がありません。 問題の保証の下では、有効なテスト ケースではこのようなことは起こりませんが、これを処理することで実装が完了します。 
5. 正確な整数平方根 (s=\lfloor\sqrt D\rfloor) を計算します。 パイソンの`math.isqrt`非負整数の整数平方根を正確に返すため、浮動小数点で発生する可能性のある精度の問題を回避できます。`sqrt`。 
6. (s^2\ne D) の場合、(D) は完全な正方形ではないため、二次方程式は整数根を持つことができません。 それ以外の場合は、分子 (a+s) と (a-s) の両方をテストします。 対応する根が整数になるためには、分子が (2) で割り切れなければなりません。 
7. すべての整数根 (y) に対して、(y\ge0) が必要です。 (x=y+b) を計算して保存します。 負の (y) は (\sqrt{ax}) と等しくないため、非負の条件が必要です。 
8. 判別式が 0 の場合は重複を削除し、結果の値を並べ替えて、そのカウントとそれに続く固定小数点を出力します。 

機能する理由: すべての固定点は、(y\ge0)、(x=y+b)、および (y^2=a(y+b)) を満たす値 (y=\sqrt{ax}) を生成するため、アルゴリズムで考慮される二次根の中にその値が出現する必要があります。 逆に、二次方程式のすべての非負整数根 (y) は (y^2=ax) で (x=y+b) を与え、したがって (\sqrt{ax}=y)、結果として (f(x)=y+b=x) となります。 このアルゴリズムは、これらの条件を満たすルートを正確にフィルタリングするため、すべての固定点が生成され、無効な固定点は生成されません。 

## Python ソリューション```python
import sys
from math import isqrt

input = sys.stdin.readline

def solve():
    T = int(input())
    out = []

    for _ in range(T):
        a, b = map(int, input().split())

        if a == 0:
            out.append("1")
            out.append(str(b))
            continue

        # y = sqrt(a*x), x = y + b
        # y^2 = a(y + b)
        # y^2 - a*y - a*b = 0

        D = a * a + 4 * a * b

        if D < 0:
            out.append("0")
            out.append("")
            continue

        s = isqrt(D)

        if s * s != D:
            out.append("0")
            out.append("")
            continue

        ans = []

        for num in (a + s, a - s):
            if num % 2 != 0:
                continue

            y = num // 2

            if y < 0:
                continue

            x = y + b
            ans.append(x)

        ans = sorted(set(ans))

        out.append(str(len(ans)))
        out.append(" ".join(map(str, ans)))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```最初のブランチは (a=0) を直接処理します。 その場合、根の下の式は (0x=0) であるため、(x) 自体が負の場合でも、平方根の項は常に 0 になります。 したがって、(x=b) は一意の固定点です。 

(a\ne0) の場合、コードは整数を直接使用して (D=a^2+4ab) を形成します。 指定された制約の下では、中間値の最大の大きさは非常に小さく、Python の整数ではオーバーフローの懸念も解消されます。 

の`isqrt`呼び出しは正確な平方根の下限を返します。 次に確認します`s * s == D`、浮動小数点に何も変換せずに、完全な正方形と非正方形を区別します。 

二つの表現`a + s`そして`a - s`は 2 つの二次根の分子です。 Python の整数除算では、黙って小数部分が破棄されるため、除算の前に 2 で割り切れるかどうかをテストする必要があります。 

小切手`y < 0`も同様に重要です。 二次方程式は平方根方程式の二乗から生まれましたが、二乗すると間違った符号を持つ根が発生する可能性があります。 (y) は (\sqrt{ax}) を表すため、(y\ge0) のみが許可されます。 

ついに、`set`(D=0) の場合、重複したルートが削除され、ソートにより必要な昇順が得られます。 候補は最大 2 つであるため、両方の演算は事実上定数時間です。
