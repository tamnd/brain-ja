 ## 問題の理解

 (n\times) のボードがあり、すべてのセルには (1) から (k) までの整数が含まれています。 セルの値がその行内の他のすべての値よりも厳密に大きく、またその列内の他のすべての値よりも厳密に大きい場合、そのセルは双点と呼ばれます。 

すべての塗りつぶされたボードについて、(I) をそのボード上の bi ポイントの数とします。 (B_i) が正確に (i) 個の bi ポイントを持つボードの数である場合、必要な数量は次のようになります。 

[
 \sum_i i^2 B_i。 
]

 これは、すべての (k^{n^2}) 個の可能なボードの (I^2) の単純な合計です。 (I) の分布全体を決定する必要はありません。 二乗が鍵です。(I^2) を展開した後は、指定された 1 つの Bi ポイントを含む構成と、指定された 2 つの Bi ポイントを含む構成をカウントするだけで済みます。 

境界 (n,k\le 200) は、(n^2) 内の指数関数を除外します。 テスト ケースは最大 (20) 個なので、ケースごとの (O(k\log n)) または (O(k^2)) の計算は簡単に十分小さくなりますが、(O(n^2k)) でさえすでに不必要に大きくなります。 ボード自体には最大 (40,000) 個のセルがありますが、割り当てを記号的にカウントするだけで済みます。 

境界ケースがいくつかあり、慎重に分離しないと式が壊れる可能性があります。 (n=1) の場合、その値に関係なく、唯一のセルが自動的に 2 点になるため、答えは正確に (k) になります。 たとえば、入力`1 5`答えは(5)です。 (2n-4) などの累乗を含む式は、指数が負になるため、ここでは直接使用できません。 

(k=1) および (n>1) の場合、すべてのセルは値 (1) を持つため、行または列内の他のセルより厳密に大きいセルはありません。 したがって、答えは (0) です。 たとえば、入力`3 1`答えは(0)です。 (0^0) を有効な最大値の証拠として扱う不用意な実装では、bi ポイントを誤ってカウントする可能性があります。 

(n=2,k=2) の場合、答えは (12) です。 正確に 1 つの Bi ポイントを持つボードは、1 つ (2)、行に隣接する 1 つ (1)、列内に隣接する 1 つ (1)、および寄与する (4) に等しい (1) の反対側のセルを持つ 4 つのボードです。 2 つの対角ボードにはそれぞれ 2 つの双点があり、それぞれ (2^2) に寄​​与し、別の (8) に寄与します。 よくある間違いは、選択したバイ ポイントを含むすべてのボードを、ちょうど 1 つのバイ ポイントを持つボードとして数えることです。 このようなボードには複数の bi ポイントが含まれる場合があるため、指標変数が必要です。 

## アプローチ

 直接的なアプローチでは、すべてのボードを列挙し、そのバイ ポイントを数え、そのカウントを 2 乗して、それを答えに加算します。 (k^{n^2}) 枚のボードがあります。 たとえ 1 つのボードのチェックに (O(n^2)) しかかからなかったとしても、合計は (O(n^2k^{n^2})) になります。 最大の制約では、これには (200^{40000}) 個のボードが含まれるため、このアプローチは完全に実行不可能です。 

有益な観察は、必要な量は一瞬であるということです。 セル (c) が 2 点の場合 (X_c) を (1)、それ以外の場合 (0) とします。 それから

 [
 I=\sum_c X_c
 ]

 そして

 [
 I^2=\sum_c X_c+2\sum_{c<d}X_cX_d。 
]

 したがって、必要なカウントは 2 種類だけです。1 つの固定セルがバイポイントであるボードの数と、2 つの固定セルが同時にバイポイントであるボードの数です。 

1 つの固定セルについて、その値が (x) であるとします。 行と列の 1 つおきのセルは (x) より小さくなければなりません。 このような細胞は (2n-2) 個あり、それらは個別です。 誰もが (x-1) 個の選択肢を持っています。 残りのセルはすべて無制限です。 

2 つの固定セルの場合、3 つの幾何学的可能性があります。 それらが同じ行にある場合、両方が厳密な行最大値になることはできません。 同じ列にある場合も同様です。 したがって、異なる行と異なる列を持つペアのみが問題となります。 

このようなペアを考えて、その値を (a) と (b) と呼びます。 各固定セルは (2n-2) 個のセルを制約しますが、2 つのセルは他の固定セルの行または列の交差点にあります。 これら 2 つのセルは (a) と (b) の両方より小さい必要があるため、それぞれ (\min(a,b)-1) 個の選択肢があります。 残りの制約されたセルは、どの固定値より小さくなければならないかに応じて分離できます。 これにより、プレフィックス合計を維持することで単一のループに削減できる対称合計が生成されます。 

1 つのボードをチェックすることでその寄与が正確に決定されるため、総当たり攻撃は機能しますが、ボードの数が指数関数的に多いため失敗します。 (I^2) には 1 セルと 2 セルのインジケーター積のみが含まれるという観察により、問題は少数のべき乗和に帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(n^2k^{n^2})) | (O(n^2)) | 遅すぎる |
 | 最適 | (O(k\log n)) | (O(1)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. (n=1) を個別に扱います。 正確に 1 つのセルがあり、それは常に 2 点であるため、(k) 個のボードのすべてが (1^2) に寄​​与し、答え (k) が得られます。 
2. 特定の 1 つのセルを修正し、その値を (x) とします。 その行または列には (2n-2) 個の他のセルがあり、それらはすべて (x) より小さくなければなりません。 したがって、この固定セルは、

 [
 (x-1)^{2n-2}k^{(n-1)^2}
 ]

 ボード。 (x=1,\ldots,k) を合計すると、1 つの固定セルでカウントされるボードの数は次のようになります。 

[
 A=k^{(n-1)^2}\sum_{t=0}^{k-1}t^{2n-2}。 
]

 固定セルには (n^2) 個の選択肢があるため、答えの最初の部分は (n^2A) になります。 

1. 2 つの固定セルを考えます。 2 つのセルが行または列を共有する場合、2 つのセルの両方が同じ行または列内の他のセルよりも厳密に大きいことはできないため、同時寄与はゼロになります。 
2. 異なる行と列にある 2 つのセルの値を (a) と (b) として書き込み、(t=a-1)、(u=b-1) と置きます。 各固定セルには、それ自体の値によってのみ制約される (2n-4) 個のセルがあります。 交差する 2 つのセルは両方の値より小さい必要があるため、それぞれ (\min(t,u)) の選択肢があります。 あります

 [
 (n-2)^2
 ]

 完全に無制限のセル。 

したがって、この固定ペアの割り当ての数は次のようになります。

[
 k^{(n-2)^2}
 \sum_{t=0}^{k-1}\sum_{u=0}^{k-1}
 t^{2n-4}u^{2n-4}\min(t,u)^2。 
]

 しましょう

 [
 p=2n-4。 
]

 二重和は (t,u) において対称です。 (t>u) の場合、(\min(t,u)=u) なので、その部分は次のようになります。 

[
 \sum_{t=0}^{k-1}t^p\sum_{u=0}^{t-1}u^{p+2}。 
]

 対角線 (t=u) が寄与します

 [
 \sum_{t=0}^{k-1}t^{2p+2}。 
]

 したがって、二重和全体は次のようになります。 

[
 2\sum_{t=0}^{k-1}t^p
 \left(\sum_{u=0}^{t-1}u^{p+2}\right)
 +
 \sum_{t=0}^{k-1}t^{2p+2}。 
]

 スキャン (t) 中に内部和を増分的に計算できるため、二重和が 1 つのループになります。 

1. 異なる行および異なる列に、順序付けられていないセルのペアがいくつあるかを数えます。 2 つの行を選択し、2 つの列を選択して、2 つの対角線の一致のうち 1 つを選択します。 

\frac{n^2(n-1)^2}{2}。 
]

 (I^2) の展開には順序のないペアが 2 回含まれるため、係数は次のようになります。 

[
 n^2(n-1)^2。 
]

 したがって、答えの後半部分は次のようになります。 

[
 n^2(n-1)^2
 k^{(n-2)^2}
 \左(
 2\sum_{t=0}^{k-1}t^p
 \sum_{u=0}^{t-1}u^{p+2}
 +
 \sum_{t=0}^{k-1}t^{2p+2}
 \右）。 
]

 1. 1 セルの寄与と 2 セルの寄与のモジュロを加算します (998244353)。 すべてのべき乗はべき乗モジュラーと Python の組み込み関数で評価されます。`pow(a, b, MOD)`これを (O(\log b)) で実行します。 

なぜ機能するのか: 不変式が恒等式である

 [
 I^2=\sum_c X_c+2\sum_{c<d}X_cX_d。 
]

 最初の計算式は、各項 (X_c) のボードの数を正確に示します。 すべてのペア (X_cX_d) について、行または列を共有するペアの寄与はゼロですが、異なる行および列のすべてのペアには、制限されたセルと制限されていないセルのカウントされたセットが正確に含まれます。 考えられるすべての 1 セル項とすべての考えられる 2 セル項は、展開からの係数とともに正確に現れるため、最終的な合計は正確に (\sum_i i^2B_i) になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve_case(n, k):
    if n == 1:
        return k % MOD

    # Contribution of one fixed cell.
    single_exp = 2 * n - 2
    free_single = (n - 1) * (n - 1)

    sum_single = 0
    for t in range(k):
        sum_single += pow(t, single_exp, MOD)
        if sum_single >= MOD:
            sum_single -= MOD

    one_fixed = pow(k, free_single, MOD) * sum_single % MOD
    first = n * n % MOD * one_fixed % MOD

    # Contribution of one fixed pair in different rows and columns.
    p = 2 * n - 4
    free_pair = (n - 2) * (n - 2)

    prefix = 0
    pair_core = 0

    for t in range(k):
        tp = pow(t, p, MOD)

        # u < t contributes t^p * u^(p+2).
        pair_core += 2 * tp % MOD * prefix
        pair_core %= MOD

        # The diagonal term t = u.
        pair_core += pow(t, 2 * p + 2, MOD)
        pair_core %= MOD

        # Add u = t for the next iteration.
        prefix += pow(t, p + 2, MOD)
        prefix %= MOD

    pair_fixed = pow(k, free_pair, MOD) * pair_core % MOD

    pair_factor = n * n % MOD
    pair_factor = pair_factor * (n - 1) % MOD
    pair_factor = pair_factor * (n - 1) % MOD

    second = pair_factor * pair_fixed % MOD

    return (first + second) % MOD

def main():
    T = int(input())
    out = []

    for _ in range(T):
        n, k = map(int, input().split())
        out.append(str(solve_case(n, k)))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```最初の分岐は、一般的なペアの式に負の指数が含まれる唯一のケースを処理します。 (n=1) の場合、答えは単純に単一セル内の可能な値の数になります。 

(n>1) の場合、`single_exp`固定 bi ポイントの行にはちょうど (n-1) 個の制約されたセルがあり、その列には別の (n-1) 個の制約されたセルがあるため、これは (2n-2) です。 残りの ((n-1)^2) セルには制限がありません。 

ペア計算の場合は、`p = 2*n-4`。 異なる行と列の 2 つのセルを固定した後、各固定値は (2n-4) 個のセルを独立して制御します。 2 つの交差するセルは両方の値によって制御されるため、小さい方の値の指数 (p+2) で表される追加の係数が寄与します。 

変数`prefix`店

 [
 \sum_{u<t}u^{p+2}。 
]

 現在の (t) をプレフィックスに追加する前に、対称合計の (u<t) 部分に必要な値が正確に含まれています。 対角寄与 (t=u) は (t^{2p+2}) として個別に追加されます。 

すべての乗算は縮小法 (998244353) です。 Python の整数はオーバーフローしませんが、中間積を減らすと値が小さく保たれ、実装が数式に近づきます。 

要因`n*n*(n-1)*(n-1)`は順序のないペアの数ではありません。 これには、(I^2) の展開からの係数 (2) がすでに含まれています。 これは、2 倍の誤差が発生しやすい場所です。

import sys
import io

MOD = 998244353

def solve_case(n, k):
    if n == 1:
        return k % MOD

    single_exp = 2 * n - 2
    free_single = (n - 1) * (n - 1)

    sum_single = 0
    for t in range(k):
        sum_single = (sum_single + pow(t, single_exp, MOD)) % MOD

    one_fixed = pow(k, free_single, MOD) * sum_single % MOD
    first = n * n % MOD * one_fixed % MOD

    p = 2 * n - 4
    free_pair = (n - 2) * (n - 2)

    prefix = 0
    pair_core = 0

    for t in range(k):
        tp = pow(t, p, MOD)
        pair_core = (pair_core + 2 * tp * prefix) % MOD
        pair_core = (pair_core + pow(t, 2 * p + 2, MOD)) % MOD
        prefix = (prefix + pow(t, p + 2, MOD)) % MOD

    pair_fixed = pow(k, free_pair, MOD) * pair_core % MOD

    pair_factor = n * n % MOD
    pair_factor = pair_factor * (n - 1) % MOD
    pair_factor = pair_factor * (n - 1) % MOD

    return (first + pair_factor * pair_fixed) % MOD

def reference(n, k):
    if n == 1:
        return k % MOD

    single = 0
    for t in range(k):
        single += pow(t, 2 * n - 2, MOD)
    single %= MOD
    first = n * n % MOD
    first = first * pow(k, (n - 1) * (n - 1), MOD) % MOD
    first = first * single % MOD

    p = 2 * n - 4
    core = 0
    for t in range(k):
        for u in range(k):
            core += (
                pow(t, p, MOD)
                * pow(u, p, MOD)
                * min(t, u) ** 2
            )
            core %= MOD

    pair = pow(k, (n - 2) * (n - 2), MOD) * core % MOD
    pair_factor = n * n * (n - 1) * (n - 1) % MOD

    return (first + pair_factor * pair) % MOD

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input_func = sys.stdin.readline

    T = int(input_func())
    ans = []

    for _ in range(T):
        n, k = map(int, input_func().split())
        ans.append(str(solve_case(n, k)))

    return "\n".join(ans)

    "12\n216\n129097970"
), "provided samples"

# Minimum-size input.
assert run("1\n1 1\n") == "1", "minimum n and k"

# n = 1 with many possible values.
assert run("1\n1 200\n") == "200", "single-cell boundary"

# All boards are equal when k = 1 and n > 1.
assert run("1\n3 1\n") == "0", "all-equal boards"

# Small case that exercises the pair formula.
assert run("1\n2 3\n") == "48", "n=2 pair counting"

# Maximum-size input, checked against a direct O(k^2) reference.
max_expected = reference(200, 200)
assert run("1\n200 200\n") == str(max_expected), "maximum constraints"

 ## 特殊なケース

 (n=1,k=5) の場合、ボードは単一のセルで構成されます。 含まれる値が何であれ、他のセルがないため、その行および列内の他のすべてのセルよりも大きくなります。 したがって、5 つのボードのすべてに (I=1) があり、次のようになります。 

[
 5\cdot1^2=5。 
]

 実装はすぐに (k) を返し、ペア式を評価しません。 

(n=3,k=1) の場合、すべてのボードは (1) のみを含む単一構成になります。 行または列内の他のセルよりも厳密に大きいセルは存在しないため、(I=0)、答えは (0) になります。 1 セルの数式では、すべての項に (t^{2n-2}=0^4=0) が含まれるため、寄与は自然に消えます。 ペアの寄与も消えます。 

(n=2,k=2) の場合、固定セルの 1 セル数は次のようになります。 

[
 2^{1}(0^2+1^2)=2。 
]

 4 つのセルがあり、線形項から (8) が得られます。 2 つのセルが同時に双点になることができるのは、対角線上にある場合のみです。 各固定対角ペアについて、選択された 2 つの値に対する唯一の有効な割り当ては (2,2) ですが、残りの 2 つのセルは (1) でなければならず、割り当ては 1 つになります。 対角線のペアが 2 つあり、(I^2) の因数 (2) から (4) が得られます。 合計は(8+4=12)となります。 

(n=200,k=200) の場合、アルゴリズムはボードを構築したり、(n^2) 個のセルを反復したりすることはありません。 可能な値 (200) にわたる 1 セルの電力合計とペアの電力合計のみを評価します。 最大の指数は (40000) 未満であるため、べき乗剰余演算は低コストであり、すべての中間値は剰余 (998244353) で減算されます。
