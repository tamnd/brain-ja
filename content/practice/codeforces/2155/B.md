 ## 解決策
 ## 問題の理解

 私たちは迷路をデザインするように頼まれました。$n \times n$グリッドでは、各セルに 4 つの基本方向 (上、下、左、右) のいずれかを指す矢印が含まれています。 アブラハムは、任意のセルから開始して、そのセル内の矢印に従って次のセルに移動し、この方法で移動を続けます。 グリッドから外に出れば逃げ出す。 私たちの目標は、まさに次のような矢印の配置を作成することです。$k$開始セルによりエイブラハムは脱出することができます。 入力は複数のテスト ケースを提供し、それぞれがグリッド サイズを指定します。$n$そしてエスケープセルの数$k$。 出力では、有効なグリッドを提供するか、それが不可能であると宣言する必要があります。 

制約は中程度です。$n$は最大 100 であり、すべてのテスト ケースにわたるセルの合計数は最大でも$10^5$。 これにより、複雑なアルゴリズムを大まかに使用できるようになります。$O(n^2)$最悪のケースはまだ下にあるため、テストケースごとに$10^7$操作は 2 秒の制限時間内で許容されます。 

考えられるすべての矢印の配置をシミュレートする素朴な試みは、構成の数が膨大であるため、現実的ではありません。$4^{n^2}$。 明らかではないエッジケースには、次のような状況が含まれます。$k$正確には実現できません。 たとえば、$2 \times 2$グリッドでは、ちょうど 3 つのエスケープ セルを持つことは不可能です。 グリッドの境界を尊重せずに貪欲に矢印を割り当てようとすると、このような行き止まりにつながる可能性があります。 小さなグリッドまたは値$k$奇妙ではあるが、グリッドの行または列の自然なレイアウトと一致できない場合は、注意が必要です。 

## アプローチ

 ブルートフォースアプローチでは、矢印のあらゆる組み合わせを試します。$n^2$セルを確認し、各構成のエスケープ セルの数をカウントします。 それは正しいのですが、すぐに手に負えなくなります。$10 \times 10$グリッド、あります$4^{100}$計算限界をはるかに超えた可能な配置。 

重要な観察は、矢印が外側を向いている場合、脱出を許可する唯一のセルはグリッドの境界にあるセルであるということです。 矢印を連鎖させた場合、内部セルは最終的に境界に到達するだけですが、最初にコーナーとエッジに焦点を当てることで正確な制御を保証できます。 構造化されたソリューションの場合、すぐに脱出できるセル (境界上) と残りのセル (内部) の 2 つのタイプのセルを考慮してグリッドを埋めることができます。 単純な貪欲なパターンは、左上隅を上または左を指す矢印で埋め、右の次のセルを右の矢印で埋め、次の行を下矢印でというように、チェッカー盤のような順序を維持して正確に到達することです。$k$細胞を逃がします。 

ブルートフォースはあらゆる可能性を考慮するため機能しますが、次の場合には失敗します。$n > 3$指数関数的な成長のため。 境界セルのみが脱出を制御するという洞察により、系統的な充填パターンを計算できるようになります。$O(n^2)$完全なシミュレーションなしで。 グリッドを斜めのストライプで埋めることにより、割り当て時にエスケープ セルを数え、正確に停止することができます。$k$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(4^{n^2})$|$O(n^2)$| 遅すぎる |
 | 構造化された斜めの充填 |$O(n^2)$|$O(n^2)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$そして$k$。 もし$k > n^2$、合計セルよりも多くのエスケープ セルを含めることはできないため、すぐに NO を出力します。 
2. を初期化します。$n \times n$初期デフォルトとして、グリッドは「U」で埋められます。 これにより、最上列の細胞が確実に上方に逃げます。 
3. 左上隅から対角線上にセルを埋めていきます。 これにより、境界付近のセルに優先順位を付けて、脱出の制御を最大限に高めることができます。 
4. 「エスケープ」として割り当てられたセルの数のカウンターを維持します。 各対角セル (行と列が偶数であるか、ヘビ パターンに従います) に、カウンターが下にある場合に外側を指す矢印を割り当てます。$k$。 必要に応じて右への水平移動には「R」を使用し、下への垂直移動には「D」を使用して、避難経路が境界に到達することを確認します。 
5. 正確に到達できれば$k$セルをエスケープし、残りのセルをグリッドの内側を指す矢印で塗りつぶして、エスケープを許可しないようにします。 非境界セルで「L」または「D」を使用すると、エイブラハムはこれらの場所から逃げられなくなります。 
6. YES と完成したグリッドを印刷します。 

機能する理由: 境界指向の矢印を割り当てる際にエスケープ セルをカウントすることで、境界を超えないようにします。$k$そしていつでも一度止められる$k$に達します。 非エスケープ セルを内側に向いた矢印で埋めると、誤ってエスケープを許可しないことが保証されます。 対角線の順序により、セルが互いのエスケープ パスに干渉しないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    if k > n * n:
        print("NO")
        continue

    grid = [['D']*n for _ in range(n)]
    escape_count = 0

    for i in range(n):
        for j in range(n):
            if escape_count < k and (i+j) % 2 == 0:
                grid[i][j] = 'U'
                escape_count += 1
            else:
                grid[i][j] = 'D'

    if escape_count < k:
        print("NO")
    else:
        print("YES")
        for row in grid:
            print(''.join(row))
```このコードは、下向き矢印を使用してグリッドを初期化します。 次に、対角線 (インデックスの合計も) を上向きの矢印で満たしていきます。$k$細胞を逃がします。 もし$k$満足できない場合は NO を出力します。 このパターンにより、細胞が意図せずに逃げ出すことがなくなります。
