 ## 解決策
 ## 問題の理解

 長さの配列を数えています`n`負でない整数で構成されます。 隣接する値は最大で移動する可能性があります`k`どちらの方向でも。 

少なくとも 1 つの要素が間隔に属している場合、配列はファンシーであるとみなされます。$$[x, x+k-1].$$タスクは、そのような配列をすべて剰余としてカウントすることです。$10^9+7$。 

まず最初に異常に見えるのは、配列の値が制限されていないことです。 値は任意に大きくなる可能性があるため、値に対する直接的な動的プログラミングは不可能です。 

制約は、実際の構造がどこにあるかを説明します。 両方`n`そして`k`到達できる$10^9$したがって、どちらのパラメータでも線形のものは直ちに不可能になります。 唯一の小さなパラメータは、`x`、最大でも`40`。 受け入れられている解決策はすべて、問題を状態空間に還元する必要があります。`x`次に、行列のべき乗を使用して巨大な長さを処理します。 

微妙な点は、値を無制限に上にシフトできるため、隣接条件のみを満たすすべての配列のセットが無限であることです。 ある要素が存在する要件$[x,x+k-1]$それが答えを有限にするものです。 

もう 1 つの簡単な間違いは、ターゲット間隔の値を含む配列を直接カウントしようとすることです。 この間隔は複数回アクセスされる可能性があるため、位置の包含と除外が複雑になります。 

考慮する：```
n = 2, x = 1, k = 1
```有効な配列は次のとおりです。```
[0,1]
[1,0]
[1,1]
[1,2]
[2,1]
```それらは5つあります。 「最初の訪問」位置を個別にカウントすると、複数の配列が二重にカウントされます。 

2番目のトラップが現れるのは、`x = 0`。```
n = 1, x = 0, k = 3
```のすべての値`{0,1,2}`すでに要件を満たしているため、答えは次のようになります。`3`。 

以下の配列全体を減算する式`x`以下の値がないという事実を正しく処理する必要があります`0`。 

## アプローチ

 まず総当たり的な解決策を想像してみましょう。 

値が有限の範囲に制限されていると仮定します。 すべての配列を列挙し、隣接する差分が範囲内にあるかどうかを確認できます。`k`少なくとも 1 つの要素がターゲット間隔に属しているかどうか。 これは明らかに正しいですが、たとえ小さな範囲であっても、配列の数は次のように指数関数的に増加します。$M^n$。 と$n$まで$10^9$、そのようなアプローチは絶望的です。 

重要な観察は、配列の最小値を調べることから得られます。 

隣接条件を満たす任意の配列を取得します。 その最小値を`m`。 

引き算すると`m`すべての要素から、すべての違いは変わりません。 シフトされた配列の最小値は`0`。 

ここで、連続する要素間の一連の増分を見てみましょう。 各ステップには任意の整数を指定できます。`[-k,k]`、正確に与える`2k+1`可能性。 

最小値になったら`m`とステップ順序が固定されているため、配列全体が一意に決定されます。 

これは、配列を最小値でカウントすることを示唆しています。 

最小値が最大値であれば配列は派手です$x+k-1$、すべての要素が厳密に以下であるわけではありません`x`。 

確かに、最小値を超えると、$x+k-1$、すべての要素が超過します$x+k-1$, そのため、目標間隔に到達することはありません。 

逆に、最小値が最大値の場合は、$x+k-1$の場合、一部の要素は最小値に等しいため、次の位置にあります。$[0,x+k-1]$。 目標間隔を逃す唯一の方法は、すべての要素が実際にそれを下回っている場合です。`x`。 

これにより、答えは次のように変換されます$$(\text{arrays with minimum } \le x+k-1) - (\text{arrays entirely in } [0,x-1]).$$最初の量は非常に単純になります。 

最小値を選択します。 以下の任意の整数を指定できます。`0`に`x+k-1`、与える`x+k`選択肢。 

最小値を固定した後、それぞれ`n-1`違いは独立して選択できます`[-k,k]`、与える$$(2k+1)^{n-1}$$可能性。 

したがって、$$A=(x+k)(2k+1)^{n-1}.$$2 番目の数量には、次の値のみが含まれます。`[0,x-1]`。 以来`x ≤ 40`、これらの状態に対して DP を実行できます。 

させて$$dp_i[j]$$長さの数値になります-`i`value で終わる配列`j`、すべての値が内部に留まります`[0,x-1]`。 

移行は、$$dp_i[j] = \sum_{|j-t|\le k} dp_{i-1}[t].$$これは最大 40 の状態に対する線形変換であるため、行列のべき乗は膨大な数の結果を計算します。`n`。 

答えは$$(x+k)(2k+1)^{n-1} - \text{count\_below\_x}.$$これにより、$O(x^3\log n)$解決。 

基礎となるアイデアは、公式ソリューションで使用されているものとまったく同じです。

 ## アルゴリズムのチュートリアル

 1. コンピューティング$$T=(x+k)(2k+1)^{n-1}.$$これは、最小値が属するすべての配列をカウントします。`[0, x+k-1]`。 
2. すべての値が含まれる配列をカウントします。`[0,x-1]`。 

状態を値とする`0,1,...,x-1`。 
3. を構築します。`x × x`遷移行列`M`。`M[i][j] = 1`もし`|i-j| ≤ k`、 さもないと`0`。 

これは隣接性制約と正確に一致します。 
4. 初期行ベクトルを作成する$$V=[1,1,\dots,1].$$のすべての値`[0,x-1]`最初の要素として現れる場合があります。 
5. コンピューティング$$V' = V \cdot M^{\,n-1}.$$行列のべき乗では、巨大な指数が次のように減ります。$O(\log n)$。 
6. すべてのエントリを合計します。`V'`。 

これは、値が決して離れることのない配列の数です。`[0,x-1]`。 
7. からその量を引きます。`T`。 
8. 結果のモジュロを出力します。$10^9+7$。 

### なぜ効果があるのか

 隣接条件を満たすすべての配列には、一意の最小値があります。 

連続する差の最小値とシーケンスを固定することで、配列全体が一意に決定されます。 すべての違いは正確に存在するため、`2k+1`可能性、最小値が固定された配列の数は以下に等しい$(2k+1)^{n-1}$。 

最小値は以下の任意の値を取ることができます。`0`に`x+k-1`、降伏$(x+k)(2k+1)^{n-1}$最小値が超えない配列$x+k-1$。 

それらの中で、派手な条件を満たさない唯一の配列は、その値がすべて厳密に以下である配列です。`x`。 これらの配列は行列 DP によってカウントされます。 

2 つのセットは、派手な配列のセットによって正確に異なるため、減算によって正しい答えが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def mat_mul(A, B):
    n = len(A)
    m = len(B[0])
    p = len(B)

    C = [[0] * m for _ in range(n)]

    for i in range(n):
        for k in range(p):
            if A[i][k] == 0:
                continue
            aik = A[i][k]
            for j in range(m):
                C[i][j] = (C[i][j] + aik * B[k][j]) % MOD

    return C

def mat_pow(M, e):
    n = len(M)

    R = [[0] * n for _ in range(n)]
    for i in range(n):
        R[i][i] = 1

    while e:
        if e & 1:
            R = mat_mul(R, M)
        M = mat_mul(M, M)
        e >>= 1

    return R

def solve_case(n, x, k):
    total = (x + k) % MOD
    total = total * pow(2 * k + 1, n - 1, MOD) % MOD

    if x == 0:
        below = 0
    else:
        M = [[0] * x for _ in range(x)]

        for i in range(x):
            for j in range(x):
                if abs(i - j) <= k:
                    M[i][j] = 1

        P = mat_pow(M, n - 1)

        vec = [[1] * x]
        res = mat_mul(vec, P)

        below = sum(res[0]) % MOD

    return (total - below) % MOD

def main():
    t = int(input())
    ans = []

    for _ in range(t):
        n, x, k = map(int, input().split())
        ans.append(str(solve_case(n, x, k)))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    main()
```計算は自然に 2 つの独立した部分に分割されます。 

最初の部分は、最小値が最大である配列をカウントします。`x+k-1`。 それは単なるべき乗剰余です。 

2 番目の部分は、その下にある配列全体をカウントします。`x`。 以来`x ≤ 40`、状態空間は小さいです。 遷移行列には、値間の有効な移動が正確に含まれています。 

以下の値があるため、初期ベクトルはすべて 1 です。`x`最初の要素として選択できます。 乗算$M^{n-1}$トランジションを適用します`n-1`回。 

微妙な境界ケースの 1 つは、`x = 0`。 その場合、「x 以下」の DP には州がまったく存在しません。 以下の配列の数`x`単にゼロです。 

もう一つの詳細は、`n`等しいことができます`1`。 指数による行列のべき乗`0`は単位行列を正しく返すため、コードはこのケースを自然に処理します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 |$O(x^3 \log n)$| 行列のべき乗`x × x`マトリックス |
 | スペース |$O(x^2)$| 行列の保存 |

        m = len(B[0])

        for i in range(n):
            for k in range(p):
                if A[i][k] == 0:
                    continue

                    C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD

        R = [[0] * n for _ in range(n)]
        for i in range(n):
            R[i][i] = 1

            if e & 1:
                R = mat_mul(R, M)
            M = mat_mul(M, M)
            e >>= 1
        return R

    data = io.StringIO(inp)

    out = []

 ## 特殊なケース

 次のことを考慮してください。```
1
1 0 3
```目標間隔は、`[0,2]`。 すべての有効な配列には 1 つの要素があり、その要素は次のいずれかである必要があります。`0,1,2`。 式は次のようになります$$(0+3)\cdot 1 = 3.$$以下に完全に配列はありません`0`, したがって、減算項はゼロになります。 アルゴリズムは戻ります`3`。 

次に、次のことを考えてみましょう。```
1
1 4 25
```最初の式は、以下からすべての最小値を数えます。`0`を通して`28`、与える`29`。 このうち価値観は、`0,1,2,3`目標間隔に決して到達しない`[4,28]`。 行列 DP はこれら 4 つの配列を正確にカウントし、答えは次のようになります。`25`。 

最後に、次のことを考慮してください。```
1
2 1 1
```間隔は`[1,1]`。 式は次のようになります$$2 \cdot 3 = 6.$$以下のDP`x`状態だけを持っています`0`、そこには長さ 2 の配列が 1 つだけ存在します。`[0,0]`。 それを減算すると、`5`、直接列挙に一致します。 これは、行列 DP が非派手な配列を正確に削除し、それ以外は何も削除しないことを確認します。
