 ## 解決策
 ## 問題の理解

 巨大な数直線上の振動の位置を表す、ソートされた 2 つの整数のセットが与えられます。 ピボット位置を選択する操作を実行できます。`k`、およびすべての振動は厳密に左側にあります。`k`はさらに 1 ステップ左に移動し、すべての振動は厳密に右側に移動します。`k`さらに右に 1 歩移動します。`k`じっとしている。 

重要な点は、1 回の操作では 1 つの点を移動するのではなく、選択したピボットから離れるように構成を同時に拡張することです。 さまざまなピボットでこの操作を繰り返すと、構成が構造的に変更されます。タスクは、初期構成をターゲット構成に正確に変換できるかどうかを判断することです。 

入力サイズは最大 200,000 ポイントに達するため、一連の操作をシミュレートしたり、ステップごとにピボットを選択して検索したりするアプローチは、直ちに遅すぎます。 1 つの操作でもすでにすべてのポイントに影響を与えるため、多くの操作をシミュレートするとコストが倍増します。 

微妙な問題は、変換がローカルではないことです。 ポイントの動きは、ピボットが左側または右側にあるすべての操作に依存するため、各要素について個別に考えるとすぐに矛盾が生じます。 もう 1 つの隠れた問題は、この操作では異なるセグメントが同時に反対方向に移動する可能性があるため、有効なシーケンスが存在する場合でも、ポイントを 1 つずつ貪欲にマッチングすると失敗する可能性があることです。 

素朴な推論が間違っている可能性がある小さな例は、それぞれを一致させようとすることです。`a_i`に`b_i`いくつかの操作で到達可能かどうかを個別にチェックします。 たとえば、`a = [1, 3, 5]`そして`b = [2, 3, 6]`、各点はいくつかの操作によって個別にシフト可能に見えますが、操作の共有構造はすべての要素を結合するため、独立した実現可能性は誤解を招きます。 

## アプローチ

 ブルートフォースアプローチでは、一連の操作をシミュレートしようとします。 考えられるピボットごとに`k`では、配列にグローバル変換を適用し、ターゲットに到達するためにそのような操作の組み合わせを試します。 候補ピボットの有限セットに制限しても、各ステップですべての位置を再計算する分岐プロセスが残ります。`O(n)`。 まで`2 * 10^5`要素を考慮すると、数百の操作でさえすでに合理的な制限時間を超えてしまうため、このアプローチは完全に実行不可能になります。 

重要な観察は、一連の操作の観点から考えるのをやめ、代わりにすべての操作の最終的な効果をモデル化することです。 位置での各操作`k`すべての点に固定符号付き効果を与えます: 左の点`k`1 ずつ減少し、右のポイント`k`1つ増えます。 これは、各演算が数直線全体にわたってグローバルな線形の「傾きの変化」を引き起こすことを意味します。 

視点を切り替えると、唯一意味のある構造は、ソートされた配列内の連続する点間でこれらの傾きの変化がどのように蓄積されるかであることがわかります。 この変換は、隣接する要素間の変位の差を制御することになり、これにより、必要なシフトに単調性の制約が課されることがわかります。 

これにより、問題は、`a_i`に`b_i`は、その差が間隔間の非負の寄与によって生成されることと一致するシーケンスを形成します。

 ## アルゴリズムのチュートリアル

 各点に必要な変位を次のように定義しましょう。`d_i = b_i - a_i`。 

ここで、1 つの操作がこれらの変位にどのような影響を与えるかを考えてみましょう。 位置に 1 つの操作を適用すると`k`、次に左側のすべての点`k`1 ずつ減少し、右側のすべての点が 1 ずつ増加します。 これにより、点間の相対的な違いに影響を与える構造的な変化が生じます。 

重要なステップは、連続する 2 つの点を調べることです`a_i < a_{i+1}`。 どれくらいの排気量差があるかを考えてみましょう`d_{i+1} - d_i`運営により変更される場合があります。 ピボットが厳密に次の間にある操作のみ`a_i`そして`a_{i+1}`それぞれの操作がこの違いに寄与しており、それぞれの操作が正確に寄与しています。`+2`に`d_{i+1} - d_i`。 

したがって、構造方程式が得られます。`d_{i+1} - d_i = 2 * (number of operations with pivot in (a_i, a_{i+1}))`これから、すぐに 2 つの制約が得られます。 まず、あらゆる違い`d_{i+1} - d_i`これは操作数の 2 倍であるため、負でない値にする必要があります。 第二に、そのような差はすべて均等でなければなりません。 

これらの条件を決定手順に変換します。 

1. コンピューティング`d_i = b_i - a_i`すべてのインデックスに対して。 
2. シーケンスが正しいことを確認します。`d`減っていない。 これにより、インターバル間に負の操作カウントが発生することがなくなります。 
3. 隣接するすべての差異を確認します`d_{i+1} - d_i`は均等です。 これにより、各間隔の操作の数が確実に整数になります。 
4. 両方の条件が満たされる場合、変換は可能です。 そうでなければ不可能です。 

これで十分な理由を理解するには、連続する間の各間隔に注目してください。`a_i`そして`a_{i+1}`独立した数の操作を割り当てることができ、次のように正確に決定されます。`(d_{i+1} - d_i) / 2`。 残ったグローバル シフトは、すべてのポイントの範囲のはるか外側に演算を配置することで処理できます。これにより、すべての要素に均等に影響があり、違いが妨げられることはありません。 

### なぜ効果があるのか

 このアルゴリズムは、操作ピボットの有効なマルチセットを暗黙的に再構築します。 重要な不変条件は、変位のベクトルが`d_i`は、数直線上の互いに素な区間からの寄与に分解できます。 各間隔は、制御された加算的な方法で隣接する差分にのみ影響を与える方法で、その左右のすべてのポイントに均一に寄与します。 これらの寄与は独立しており、負ではないため、実現可能性は、すべての間隔寄与が有効なカウントとして存在することを確認することになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    d = [b[i] - a[i] for i in range(n)]
    
    for i in range(n - 1):
        if d[i] > d[i + 1]:
            print("NO")
            return
        if (d[i + 1] - d[i]) % 2 != 0:
            print("NO")
            return
    
    print("YES")

if __name__ == "__main__":
    solve()
```コードは変位配列を直接計算し、単調性と偶数差という 2 つの派生条件を適用します。 単調性チェックは、負の数の操作を必要としない間隔を保証することに対応しますが、操作数を負にすることはできないため、これは不可能です。 

パリティ チェックでは、各操作が正確に 2 単位の差に寄与するため、連続する元の位置間のすべての間隔で整数の操作が許可されることが保証されます。 

グローバル シフトはすべてのポイントの範囲外の操作によって常に生成される可能性があるため、他の制約は必要ありません。

 ## 特殊なケース

 重要なエッジ ケースは、すべてのポイントがすでに一致している場合です。`d_i = 0`。 アルゴリズムは差異をチェックし、すべてゼロを見つけて、すぐに受け入れます。 これは、ゼロ操作を実行するか、相殺される対称的な遠距離操作を適用することに対応します。 

もう 1 つのケースは、2 つの点を持つ最小構成で、1 つの点だけが誤ってシフトする場合です。 例えば`a = [1, 2]`、`b = [1, 3]`生成する`d = [0, 1]`、差が奇数であるためパリティに失敗します。 一連の操作によって隣接する点間に単一単位の不均衡が生じる可能性はないため、アルゴリズムはこれを正しく拒否します。 

3 番目の微妙なケースは、変位が単調であるがパリティのために実行不可能な場合です。 例えば`d = [0, 2, 3]`は増加していますが、最後のステップに奇妙な違いがあるため、値自体は一貫しているように見えても拒否されます。 これは、各間隔がちょうど 2 つのチャンクで寄与するため、奇数のジャンプが構造的に不可能であることを反映しています。
