 ## 問題の理解

 私たちに与えられたのは、$n$人形と呼ばれる隠しアイテム。 まさに 1 つの人形が特別であり、異なる動作をします。他の人形と比較すると、結果は常に同点になります。 残り$n-1$人形はそれぞれ 3 つのカテゴリのいずれかに属し、これらのカテゴリは周期的な支配関係を形成します。つまり、幸せは怒りに勝ち、怒りは悲しみに勝ち、そして悲しみは幸せに勝ちます。 

どの人形がどれなのかは分かりません。 代わりに、「does doll」という形式のクエリを実行できます。$i$ビートドール$j$？」 そして二者択一の答えを受け取ります。 応答が肯定的なのは、次の場合のみです。$i$ルールに従って厳密に勝ちます。 同点と損失はどちらもゼロを返します。 

任務は、最大でも使用して特別な感情のない人形のインデックスを特定することです。$3n$そういった比較。 

制約$n \le 20000$これは、どのソリューションもクエリ数が線形またはほぼ線形である必要があることを意味します。 すべての人形のペアを比較する二次アプローチでは、約$n^2$クエリですが、これは完全に不可能です。 平$O(n \log n)$ソリューションは許容されますが、線形クエリの複雑さよりも悪いものは、対話型の制限に達する危険性があります。 

微妙な問題は、クエリ応答の「0」があいまいであるという事実から生じます。 それは引き分けか負けのどちらかを意味します。 このため、注意深い構造を持たずに、固定された基準に対して勝ち負けをカウントするだけでは、特別な人形を直接識別することは不可能になります。 

単純な間違いは、推移性を仮定することです。 たとえば、A が B に勝ち、B が C に勝つ場合、A と C について何かを誤って推測する可能性がありますが、感情の周期的な性質により、これは完全に崩れます。 

もう 1 つのよくある失敗は、多数決で候補者を選ぼうとすることです。 特別ではない各人形は対戦相手のタイプに応じて対称的な動作をするため、生の勝利数は特別であることを示す安定した指標ではありません。 

## アプローチ

 強引なアイデアは、すべての人形を固定ピボットと比較し、その反応に基づいて他の人形を分類しようとすることです。 ただし、比較すると 2 つのまったく異なる理由でゼロが返される可能性があるため、感情のない人形と通常の人形を確実に区別することはできません。 この曖昧さを修正するには、構造化された方法で人形を相互に比較する必要があります。 

重要な観察は、3 つの非特別な人形の中で、少なくとも 1 つの比較で循環ルールに従って厳密な勝利が得られなければならず、特別な人形だけが相互作用全体で一貫した勝ち負けの結果を生み出さないということです。 特に、感情のない人形は万能のタイブレーカーのように振る舞い、決して誰にも負けません。 

これはトーナメント形式の排除戦略を示唆しています。 現在のスペシャルドール候補を維持しております。 新しい人形ごとにテストします。 候補者が誰かに勝った場合、それは特別な人形であることはできず、交換する必要があります。 それ以外の場合は保管します。 これが機能するのは、真の特別な人形が勝利の応答を決して生成しないため、誤って排除されることがないためです。 

これが効率的である理由は、各人形が一定数のクエリのみに参加し、総クエリ数が線形になるためです。

 ## アルゴリズムのチュートリアル

 インタラクティブな消去プロセスをシミュレートします。 

1. 人形 1 が無感情の候補であると仮定することから始めます。 最初は情報が入手できないため、これは任意です。 
2. 人形を 2 から 2 まで反復します。$n$、現在の候補者を比較$c$新しい人形ごとに$i$。 
3. どうかを尋ねます。$c$ビート$i$。 答えが 1 の場合、$c$感情のない人形はどんな戦いにも決して勝てないからです。 候補を次のように置き換えます$i$、 以来$i$まだ特別なものかもしれない。 
4. 答えが 0 の場合は、次のいずれかを行います。$c$失うか引き分けられる$i$。 いずれの場合も、$c$は有効な候補のままであるため、変更しないままにします。 
5. すべての人形を処理した後、最終候補を出力します。 

置換ステップの背後にある理由が重要です。 候補者を排除できる唯一の方法は、その候補者が通常の人形のように動作する (少なくとも 1 回は勝つ) ことを証明することです。 特別な人形は決してその状態を引き起こすことができないため、それが出現するあらゆる比較に耐えます。 

### なぜ効果があるのか

 プロセスは不変条件を維持します。最初のプロセスを処理した後、$k$人形たち、今の候補者はその中でも感情のない人形であることは確実だ$k$そのような人形がそのプレフィックスに存在する場合。 候補者が資格を失うたびに、勝利の証拠によってまだ失格になっていない人形に置き換えられます。 本物の無感情人形は、どんな比較においても決して勝てる反応を生み出さないので、排除されることはありません。 すべての帰納法によって$n$最終候補は特別なものでなければなりません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def ask(i, j):
    print(f"? {i} {j}")
    sys.stdout.flush()
    return int(input().strip())

def solve():
    n = int(input().strip())

    candidate = 1

    for i in range(2, n + 1):
        res = ask(candidate, i)
        if res == 1:
            candidate = i

    print(f"! {candidate}")
    sys.stdout.flush()

if __name__ == "__main__":
    solve()
```この解決策は、それが特別な人形ではないことが証拠によって証明された場合にのみ更新される単一の候補ポインターを中心に構成されています。 の`ask`関数は対話ロジックをラップし、すべてのクエリが即座にフラッシュされるようにします。これは対話型の問題では不可欠です。 

ループは厳密にシーケンシャルであり、各人形が現在の候補と最大 1 回比較されることが保証されます。 これにより、冗長な対話が回避され、クエリの総数が直線的に保たれます。 

よくある実装上の間違いは、各クエリの後に出力をフラッシュするのを忘れることです。 対話型の問題では、フラッシュに失敗するとプログラムがアイドル状態に見え、ロジックが正しい場合でも実行時にエラーが発生します。

 ## 特殊なケース

 最初の人形がすでに感情のない人形である場合、最小限のエッジケースが発生します。 この場合、形式 (1, i) のすべてのクエリは 0 を返します。これは、引き分けが勝利としてカウントされることがないためです。 アルゴリズムは候補を置換しないため、正しく 1 を出力します。 

もう 1 つのエッジケースは、特別な人形が最後の人形である場合です。 以前の各比較では、周期的勝利により誤って優勢に見える候補が除外される可能性がありますが、最後の反復では必然的に最後に残った有効な候補が昇格されます。 特別な人形は誰に対しても勝利反応を引き起こすことがないため、途中で破棄されることはなく、最後まで生き残ります。
