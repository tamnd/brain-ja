 ## 解決策
 ## 問題の理解

 高さのリストが与えられ、それらを任意に並べ替えて行にすることができます。 固定配置の場合、すべての連続するセグメントは、そのセグメント内の最も背の高い人と最も低い人の差に等しいコストを寄与します。 ラインの不快感の合計は、すべてのセグメントにわたるこれらの値の合計です。 

課題は、この全体的な不快感を最小限に抑える要素の順序を見つけることと、その最小限に達するさまざまな順列の数をカウントすることです。 

入力サイズは最大 1,000 までしかありませんが、目的関数はすべての部分配列にわたって定義されており、これはすでにセグメントの 2 次数を暗示しており、各セグメントには最大値と最小値が含まれます。 すべての順列を明示的に評価する解決策は、n! であるため、実現可能性をはるかに超えています。 非常に早く成長します。 単一の順列を単純に評価しようとしても O(n^2) 以上のコストがかかるため、問題の構造は最適な順列がどのようなものであるかを強く制約する必要があります。 

微妙な点は、同じ高さが存在するということです。 値が繰り返される場合、同一の要素を交換すると異なる順列が生成されますが、セグメントの最大値または最小値の動作は変わりません。 これらは、コストの観点から区別できない場合でも、最終的な回答に含める必要があります。 

よくある落とし穴は、とにかくすべての部分配列が考慮されるため、要素の順序はあまり重要ではないと仮定することです。 実際には、配置によってセグメント内のどの要素が極大値または極小値になるかが変わり、構造全体にわたる各要素の寄与が完全に変わります。 

たとえば、入力の場合`[3, 1, 2]`、異なる順列は異なる範囲の合計を生成し、小さな反転でも一度に多くの部分配列に影響を与える可能性があります。 最適な構造は非常に厳格であることが判明し、カウント部分は同一の値の同値クラス内でのみ存続します。 

## アプローチ

 直接的なアプローチでは、すべての置換を試行し、それぞれの部分配列範囲の合計を計算します。 固定順列の場合、O(n^2) 個の部分配列があり、事前に計算されたプレフィックス構造を使用して各範囲を計算するには、最大値と最小値についての推論が必要になります。 範囲クエリを最適化したとしても、すべての n! を評価します。 順列は不可能です。 n が 10 を超えると、これはすぐに失敗します。 

重要な観察は、目的が値の相対的な順序のみに依存しており、グローバルにソートされた構造からの逸脱により、より大きな要素が早すぎるか遅すぎる部分配列のセットを拡張する反転を引き起こし、最大値と最小値の合計への寄与が増加するということです。 直観的には、大きな要素が小さな要素の左側に現れると、それは多くのセグメントの最大値となり、その要素が優勢になるべきではなくなり、同様に、小さな要素が最小値になることが非常に多くなります。 これにより、他では補償できない追加の範囲への寄与が生じます。 

これは、最適な順列は単に値を並べ替えたものであるという事実につながります。 一度ソートされると、すべての部分配列の構造は単調な方法で固定されます。つまり、どのセグメントでも、最大値は常に右端の要素になり、最小値は常に左端の要素になります。 これにより、問題が単一の標準的な構成に集約されます。 

最適な配置がわかったら、すべてのサブアレイをスキャンし、実行中の最小値と最大値を維持することにより、最小コストを O(n^2) で直接計算できます。 ソートされた構造を変更せずに等しい値を自由に並べ替えることができるため、最適な並べ替えの数は完全に重複によって決まります。

 ## アルゴリズムのチュートリアル

 ### 1. 配列をソートする

 まず、すべての高さを降順でない順に並べ替えます。 これにより、すべての反転が削除された標準的な配置が生成されます。 コストを増加させることなく、あらゆる最適なソリューションをこの形式に変換できます。 

### 2. ソートされた配列の最小合計不快感を計算します。 

部分配列のすべての開始インデックスを反復処理します。 各開始位置について、現在の最小値と最大値を維持しながら、右側の境界を段階的に拡張します。 各拡張子は、それらの間の現在の差分を答えに寄与します。 これは、O(n^2) 内のすべての部分配列にわたる範囲の合計を直接累積します。 

### 3. 値の多重度を数える

 それぞれの異なる高さが何回出現するかを数えます。 これらの頻度によって、区別できないスワップまでソートされた構造を保持する順列の数が決まります。 

### 4. 最適な順列の数を計算する

 ソートされた構成は値の順序に関して固定されていますが、同じ値をそれらの間で並べ替えることができます。 したがって、有効な順列の数は多項係数となります。 

ん！ それぞれの個別の値の頻度の階乗の積で除算し、998244353 を法として計算されます。 

### なぜ効果があるのか

 重要な構造特性は、2 つの値の反転によって追加のサブ配列が作成され、大きい要素の出現が早すぎたり、小さい要素の出現が遅すぎたりして、最大値と最小値が不必要な距離にまたがるセグメントの数が増加することです。 反転を削除すると、値の順序と位置の順序の間の局所性が復元されるため、常に寄与が減少または保存されます。 結果として、グローバルにソートされた配置はローカルかつグローバルな最適であり、すべての最適な置換は等しい値のみによって引き起こされる分割を保存する必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    a.sort()
    
    # compute minimal cost
    ans = 0
    for l in range(n):
        mn = a[l]
        mx = a[l]
        for r in range(l, n):
            if a[r] < mn:
                mn = a[r]
            if a[r] > mx:
                mx = a[r]
            ans += mx - mn
    
    # count permutations (multiset permutations)
    from collections import Counter
    cnt = Counter(a)
    
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD
    
    res = fact[n]
    for v in cnt.values():
        res = res * pow(fact[v], MOD - 2, MOD) % MOD
    
    print(ans, res)

if __name__ == "__main__":
    solve()
```コードは、正規の最適な構造を適用するために配列をソートすることから始まります。 次に、二重ループによってすべての部分配列が列挙されます。 実行最小値と最大値は増分的に維持されるため、各拡張は O(1) になります。 これにより、範囲の極値を最初から再計算する必要がなくなります。 

計数セクションは最大 n までの階乗を構築し、周波数グループごとに逆モジュラーを適用します。 これは、多項係数式を直接実装します。 

微妙な実装の詳細は、n が小さいため、n までの階乗を 1 回計算するだけで十分であり、素数法 998244353 を考慮するとべき乗剰余演算は安全です。

## テストケース```python
import sys, io

MOD = 998244353

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))
    
    a.sort()
    
    ans = 0
    for l in range(n):
        mn = a[l]
        mx = a[l]
        for r in range(l, n):
            mn = min(mn, a[r])
            mx = max(mx, a[r])
            ans += mx - mn
    
    from collections import Counter
    cnt = Counter(a)
    
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD
    
    res = fact[n]
    for v in cnt.values():
        res = res * pow(fact[v], MOD - 2, MOD) % MOD
    
    return f"{ans} {res}"

assert run("2\n1 2") == "1 2"

 ## 特殊なケース

 単一要素配列ではサブ配列範囲への寄与が生成されないため、最小コストはゼロです。 二重ループは l = r = 0 (最大値と最小値が等しい) の寄与のみを蓄積するため、アルゴリズムはこれを処理します。 

すべて等しい配列では、すべての部分配列の寄与もゼロになります。 この場合、周波数マップは 1 つのグループに折りたたまれ、すべての順列が値の構造において同等であるため、多項係数は正しく 1 を返します。 

配列を厳密に増減すると、ゼロ以外の寄与が生成されますが、ソートされた変換では変化しないため、アルゴリズムが単調性を超える特別な順序付けに依存していないことが確認されます。
