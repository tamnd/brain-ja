 ## 問題の理解

 私たちには偶数人の生徒がいて、固定の友達ペアに分かれています。 各ペアは 2 つの連続した位置を占める必要がありますが、どちらの友達が最初に来るかを選択できます。 タスクは、完全な高さの配列が最初は決して減少せず、ある程度のピークの後は決して増加しないように、ペアを順序付けし、各ペアの方向を調整することです。 出力は任意の有効な配置である可能性があります。または、`-1`そのような取り決めが存在しない場合。 これは、公式の問題ステートメントの構造と一致します。 

すべてのペアについて、元の順序を忘れて間隔として書き込みます`[l, r]`、 どこ`l`身長は低い方で、`r`高いほうの高さです。 ペアが図の増加側に表示される場合は、次のように記述する必要があります。`l, r`。 減少側に表示される場合は、次のように記述する必要があります。`r, l`。 

増加側に連続して配置された 2 つのペアを考えます。 それらの間隔が`[l1, r1]`そして`[l2, r2]`、それらの 4 つの高さは次のようになります。`l1, r1, l2, r2`。 これが減少しないためには、次のことが必要です。`r1 <= l2`。 言い換えれば、端点での接触は許可されますが、2 つの間隔は重なることはできません。 順序が逆になることを除いて、同じ議論が減少側のペアにも当てはまります。 

これにより中心的な再定式化が行われます。 すべてのペアの間隔を 2 つのグループに分割する必要があります。同じグループ内の間隔は、ペアごとに重複しません。 一方のグループは増加する半分を形成し、もう一方のグループは減少する半分を形成します。 

バウンド`n <= 3 * 10^5`までの可能性があることを意味します`150000`ペア。 二次アルゴリズムはすでにおおよそのパフォーマンスを発揮します`2.25 * 10^10`最悪の場合、2 秒の制限をはるかに超えてペアの比較が行われる可能性があります。 必要なのは`O(n log n)`ソリューション。対数係数はソートから得られます。 

厳密な不等式を使用する実装を騙す可能性のあるエッジケースがいくつかあります。 まず、タッチ間隔が互換性があります。 例えば、```
4
1 2
2 3
```有効な取り決めがある`1 2 2 3`。 2つの間隔`[1,2]`そして`[2,3]`高さで触れる`2`、隣接する同じ高さが許可されます。 を使用した実装`l > previous_r`の代わりに`l >= previous_r`はこのケースを誤って拒否してしまいます。 

2 番目のケースは、ピークがペアの内側にある場合です。 例えば、```
4
1 4
2 3
```次のように配置できます`2 3 4 1`。 最初のペアは増加側にあり、2 番目のペアはピークを含むペアであり、降順で書かれています。 間隔`[1,4]`そして`[2,3]`したがって、問題全体をすべての間隔が素である必要があるものとして扱うと、誤って拒否されてしまいます。 

3 番目のケースは、共通の高さで重なる 3 つの間隔です。```
6
1 5
2 4
3 6
```これには解決策がありません。 高所で`3`、3 つのペア間隔すべてがアクティブです。 山の側面は 2 つしかないため、これらのペアのうち 2 つは同じ側面に属さなければなりませんが、重なり合う間隔は 1 つの単調な側面に共存できません。 

最後に、同じ高さは完全に有効です。 例えば、```
4
3 3
3 3
```単純に生産できる`3 3 3 3`。 ソリューションでは間隔を処理する必要があります`[x,x]`他のすべてのインターバルと同様に、複数のそのようなインターバルを異なる側に割り当てることができるようにする必要があります。 

## アプローチ

 最も直接的なアプローチは、各ペアを分割できないブロックとして扱い、ブロックのすべての順序を試し、すべてのブロックに対して両方の向きを試し、結果の高さの配列が山であるかどうかを確認することです。 と`m = n/2`ペア、あります`m!`ペアの注文方法と`2^m`それらを方向付ける方法。 すべての候補者が必要とするのは、`O(n)`チェックする作業があるため、合計作業量は`O(n * m! * 2^m)`。 最大入力の場合、これは`3 * 10^5 * 150000! * 2^150000`、これは遠隔的には実現不可能です。 

ブルート フォースが機能するのは、あらゆる可能な配置と方向を明示的に調査するためです。 問題は、それらの選択肢のほとんどすべてが不要であるということです。 すべてのペアに正確に 2 つの要素があるという事実により、より強力な構造が得られます。 

すべてのペアの 2 つの高さを並べ替え、そのペアを間隔として表示します`[l,r]`。 増加側では、ペアは次のように表示される必要があります。`l,r`。 2 つの連続した増加ペアは、最初の間隔が 2 番目の間隔の開始前または開始時に正確に終了するときに有効になります。 したがって、増加側は重複しない間隔のチェーンになります。 減少する側は、順序を逆にしても同じ性質を持ちます。 

その結果、問題を、間隔を重複しない間隔の 2 つのチェーンに分割することにしました。 間隔スケジューリングは単純な貪欲な構造を持っているため、これは重要な観察です。 

すべての間隔を左の終点で並べ替えます。 2 つのチェーンのそれぞれで現在占有されている右端のエンドポイントを維持します。 新しい間隔に向けて`[l,r]`、次の場合に正確にチェーンに追加できます。`l >= end[chain]`。 どちらのチェーンも使用できない場合、現在の間隔は両方のチェーンをすでに占有している間隔と重複するため、3 つの間隔が共通点で重複し、解は存在しません。 

2 つのチェーンが得られると、微妙な問題が 1 つ残ります。 増加するチェーンをピークで減少するチェーンに接続する必要があります。 この問題は、世界的に最大の右エンドポイントの間隔を減少チェーンに強制的に所属させることで解決します。 この場合、減少する側の最初の区間は、右の端点が減少する順に並べられた場合、増加する側の最後の区間と少なくとも同じ大きさの端点を持ちます。 これにより、ピークを越える移行が有効になります。 

貪欲な色付けによってグローバルに最大の間隔が最初のチェーンに配置される場合は、2 つのチェーンのラベルを単純に交換します。 色を交換すると、すべてのチェーンに重複しない間隔のみが含まれるという特性が維持されます。 

結果の比較は次のようになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |

 | 最適 |`O(n log n)`|`O(n)`| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての友達ペアを変換する`(a,b)`間に入って`[l,r]`、 どこ`l = min(a,b)`そして`r = max(a,b)`。 後で 2 つの高さを再構築できるように、元のペアのインデックスを保持しておきます。 モノトーン サイド内の互換性に関連する唯一の情報は、小さいエンドポイントと大きいエンドポイントです。 
2. 正しいエンドポイントを持つペアを見つけます。`r`は世界的に最大です。 このペアは最終的には減少側に配置されます。 グローバル最大値を選択すると、ピークの増加側の最後の間隔が自動的に支配されるため便利です。 
3. すべての間隔を左のエンドポイントで並べ替えます。 維持する`end[0]`そして`end[1]`、現在 2 つのチェーンに割り当てられている最後の間隔の右端のエンドポイント。 最初は両方のチェーンが空です。 
4. ソートされた間隔を左から右に処理します。 現在の左端点の場合`l`満足する`l >= end[0]`、チェーンに間隔を割り当てます`0`。 それ以外の場合は、`l >= end[1]`、チェーンに割り当てます`1`。 どちらの条件も当てはまらない場合は報告する`-1`。 

インターバルは左のエンドポイントを増加させることによって処理されるため、貪欲な割り当ては有効です。 両方のチェーンがブロックされている場合、現在の間隔は各チェーンの間隔と重複するため、現在の左側のエンドポイントで 3 つの間隔が重複します。 重複しない 2 つのチェーンに分割することはできません。 
5. すべての間隔を割り当てた後、グローバル最大右エンドポイント間隔の色を確認します。 チェーンに属する場合`0`、間隔ごとに 2 つのチェーン ラベルを交換します。 これにより変更されるのは、チェーンが表す山のどちら側のみであり、各チェーン内の間隔がバラバラであるという事実は変更されません。 
6. ソートチェーン`0`左のエンドポイントを増やして、すべてのペアを次のように追加します`(l,r)`。 このチェーンの連続する間隔は次の条件を満たすため、`previous_r <= current_l`、この連鎖によって生成される完全なシーケンスは減少しません。 
7. ソートチェーン`1`右のエンドポイントを減らして、すべてのペアを次のように追加します`(r,l)`。 間隔は重複していないため、その左端点も逆方向に適切に順序付けされ、このシーケンスは増加しません。 
8. 増加するチェーンと減少するチェーンを連結します。 増加するチェーンの最後の値は、その最終間隔の最大のエンドポイントです。 減少するチェーンの最初の値は、チェーン内のすべての間隔の中で最大のエンドポイントです。`1`。 世界最大の適切なエンドポイントが意図的にチェーンに組み込まれているため、`1`、減少側の最初の値は少なくとも増加側の最後の値です。 したがって、アレイ全体が必要な山の形状を持ちます。 

### なぜ効果があるのか

 貪欲な割り当て中の不変条件は、既に構築されているすべてのチェーンが重複しない間隔の有効なシーケンスであるということです。 新しい間隔がチェーンに割り当てられると、その左端点は少なくともそのチェーンの最後の右端点になるため、不変条件は true のままになります。 両方のチェーンが間隔を拒否した場合、右エンドポイントが少なくとも現在の左エンドポイントである各チェーンからの間隔が存在します。 現在の間隔と合わせると、その時点で 3 つの間隔が重複するため、2 つのチェーン パーティションは存在できません。 

パーティションの後、増加するチェーンのすべての間隔は小さいものから大きいものへ、減少するチェーンのすべての間隔は大きいものから小さいものへ書き込まれます。 各チェーン内の順序付けにより、単調性が保証されます。 グローバルに最大の右端点は減少するチェーンに配置されるため、そのチェーンの最初の値は少なくとも増加するチェーン内のすべての右端点になります。 これは、ピークでの遷移も有効であることを証明しています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    m = n // 2

    intervals = []
    global_max_idx = -1
    global_max_r = -1

    for i in range(m):
        a, b = map(int, input().split())
        l = min(a, b)
        r = max(a, b)
        intervals.append((l, r, i))

        if r > global_max_r:
            global_max_r = r
            global_max_idx = i

    intervals.sort()

    # end[c] is the right endpoint of the last interval
    # assigned to chain c.
    end = [-1, -1]
    color = [-1] * m

    for l, r, idx in intervals:
        if l >= end[0]:
            color[idx] = 0
            end[0] = r
        elif l >= end[1]:
            color[idx] = 1
            end[1] = r
        else:
            print(-1)
            return

    # The globally largest right endpoint must be on the
    # decreasing side. If it is currently on chain 0,
    # swap the two chain labels.
    if color[global_max_idx] == 0:
        for i in range(m):
            color[i] ^= 1

    left = []
    right = []

    for l, r, idx in intervals:
        if color[idx] == 0:
            left.append((l, r, idx))
        else:
            right.append((l, r, idx))

    left.sort(key=lambda x: (x[0], x[1]))
    right.sort(key=lambda x: (-x[1], -x[0]))

    ans = []

    for l, r, idx in left:
        ans.append(l)
        ans.append(r)

    for l, r, idx in right:
        ans.append(r)
        ans.append(l)

    print(*ans)

if __name__ == "__main__":
    solve()

間隔は次の基準で並べ替えられます。`l`。 二人`end`値は、各チェーンの現在の最後の間隔を表します。 比較は`l >= end[c]`、 ない`l > end[c]`隣接する高さが等しいことが正当であるためです。 初期値`-1`すべての高さが少なくとも次のとおりであるため、機能します`1`。 

どちらのチェーンも間隔を受け入れない場合、考えられる解決策はないため、アルゴリズムはすぐに終了できます。 後戻りする必要はありません。 

グローバル最大値の正しいエンドポイントが強制的にチェーンに追加されます`1`。 チェーンに割り当てられていた場合`0`、すべての色を反転するだけで十分です。 これは、貪欲な手順を変更してスキャン中に特定の間隔を強制するよりも簡単です。 

左側のチェーンは増加順にソートされます。`l`。 貪欲不変式により、各間隔が前の間隔の終了より早く開始することが保証されるため、各ペアは次のように記述されます。`l,r`非減少シーケンスを作成します。 右側のチェーンは降順でソートされます`r`そして各ペアは次のように書かれます`r,l`、増加しないシーケンスが生成されます。

def validate(inp: str, out: str) -> bool:
    data = list(map(int, inp.split()))
    n = data[0]
    pairs = [tuple(sorted(data[i:i + 2])) for i in range(1, len(data), 2)]

    if out.strip() == "-1":
        # Verify that the instance really has no solution by
        # checking the same two-chain condition.
        intervals = [(a, b) for a, b in pairs]
        intervals.sort()

        end = [-1, -1]

        for l, r in intervals:
            if l >= end[0]:
                end[0] = r
            elif l >= end[1]:
                end[1] = r
            else:
                return True

        return False

    ans = list(map(int, out.split()))

    if len(ans) != n:
        return False

    expected = sorted(x for pair in pairs for x in pair)
    if sorted(ans) != expected:
        return False

    # Every original pair must appear as two consecutive values.
    remaining = pairs[:]
    used = [False] * len(remaining)

    for i in range(0, n, 2):
        cur = tuple(sorted((ans[i], ans[i + 1])))

        found = False
        for j, pair in enumerate(remaining):
            if not used[j] and pair == cur:
                used[j] = True
                found = True
                break

        if not found:
            return False

    # Check mountain property.
    phase = 0
    for i in range(1, n):
        if phase == 0:
            if ans[i] < ans[i - 1]:
                phase = 1
        else:
            if ans[i] > ans[i - 1]:
                return False

    return True

def run(inp: str) -> str:
    return solve_case(inp)

 ## 特殊なケース

 接触間隔については、次の点を考慮してください。```
6
1 2
2 3
3 4
```正規化された間隔は次のとおりです。`[1,2]`、`[2,3]`、 そして`[3,4]`。 新しい左エンドポイントはそれぞれ前の右エンドポイントとまったく同じであるため、貪欲スキャンでは 3 つすべてを同じチェーンに入れることができます。 結果として得られる増加シーケンスは次のようになります。`1 2 2 3 3 4`、これは有効です。 の使用`l >= end`まさにこれが機能するものです。 

ペア内のピークについては、次のように考慮します。```
4
1 4
2 3
```間隔は重なっていますが、2つしかないので反対側に配置することもできます。 貪欲な割り当てにより、`[1,4]`そして`[2,3]`さまざまなチェーンに。 最大右端点の間隔は次のとおりです。`[1,4]`, そのため、そのチェーンは減少側になります。 他のチェーンが生産する`2 3`、 そして`[1,4]`と書かれています`4 1`、与える`2 3 4 1`。 間隔自体が重なっている場合でも、遷移は有効です。 

3 つの重複する間隔については、次のことを考慮します。```
6
1 5
2 4
3 6
```並べ替えた後、`[1,5]`最初のチェーンを占有し、`[2,4]`2番目を占めています。 いつ`[3,6]`加工されて、`3 < 5`そして`3 < 4`, そのため、どちらのチェーンも利用できません。 高所で`3`、3 つの間隔がすべて重なっています。 有効な山には増加する側と減少する側しかないため、これらの区間のうち少なくとも 2 つは一方の側を共有する必要がありますが、これは不可能です。 アルゴリズムは正しく印刷します`-1`。 

等しいペアの場合、次のように考慮します。```
4
3 3
3 3
```どちらの間隔も`[3,3]`。 最初の人はチェーンに入ることができます`0`、2番目はチェーンに入ることができます`1`なぜなら`3 >= 3`。 構築後、両方のペアが生成します`3 3`、最後のシーケンスは次のとおりです。`3 3 3 3`。 これは、エンドポイントとペアの高さが等しい場合、非厳密な比較を使用する以外に特別なケースを必要としないことを示しています。 

最大入力サイズの場合、生成される応力ケースには次のものが含まれます。`150000`フォームのペア`(i, i+1)`。 左端点が前の右端点と等しいため、各間隔は前の間隔に続くことができます。 貪欲スキャンはバックトラックすることなく効率的にそれらを割り当て、2 つの並べ替え操作は残ります。`O(n log n)`。 これはオリジナルで必要なスケールです`n <= 3 * 10^5`制約。
