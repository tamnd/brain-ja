 ## 解決策
 ## 問題の理解

 順列で表される円形の座席があります`a`の`1..n`。 学生たち`a[i]`そして`a[(i+1) mod n]`古い取り決めでは隣人だった。 新しいサークル内のすべての隣り合うペアが古いサークル内で隣接しないように、同じ生徒の別の順列を出力する必要があります。 出力された順列の最初と最後の要素も隣接要素であるため、ラップアラウンド ペアは同じ条件を満たす必要があります。 元々の問題は`3 <= n <= 3 * 10^5`有効な取り決めを要求する、または`-1`何も存在しない場合。 引用0検索0

 古い順列がわかれば、学生 ID 自体は問題になりません。 重要なのは、古いサークル内での各生徒の立場です。 階乗どころか古い位置が 2 つある場合。 ソリューションは生徒ごとに一定量の作業を実行する必要があります。`O(n)`建設は当然の目標です。 Python は線形時間で数十万の整数を快適に処理できますが、順列を試みることは完全に不可能です。 

小さな不可能なケースが 2 つあります。 のために`n = 3`、学生のすべてのペアは古いサークル内ですでに隣接しているため、新しいサークル内で隣接できるペアはありません。 例えば、`3 / 1 2 3`可能な循環ペアのみが存在します`{1,2}`、`{2,3}`、 そして`{3,1}`、すべて禁止されているため、答えは次のとおりです。`-1`。 のために`n = 4`、古いサイクルは`1-2-3-4-1`。 その補数にはエッジのみが含まれます`1-3`そして`2-4`、2つの切断されたペアを形成するため、円形の配置は不可能です。 したがって`4 / 1 2 3 4`も必要です`-1`。 

2 番目の簡単な間違いは、最初と最後の出力要素によって形成されたペアを忘れることです。 のために`n = 5`、アレンジメント`1 3 5 2 4`動作します。すべての連続するペアは、5 を法とした 2 つの位置によって異なります。`4`そして`1`。 内部の連続要素のみをチェックする構造では、誤って無効な最終ペアを受け入れる可能性があります。 

偶数の値`n`別途調整が必要です。 のために`n = 6`、奇数の位置に続いて偶数の位置を取るだけで、次のようになります。`1 3 5 2 4 6`、しかし最後のペア`6,1`古くからの隣人たちで構成されています。 修正した配列`1 3 5 2 6 4`そのペアも避けます。 これが、偶数の場合でも奇数の場合と同じ構造を盲目的に使用できない理由です。 

## アプローチ

 直接的な総当たりアプローチは、生徒のすべての順列を生成し、その順列が正しいかどうかを確認することです。`n`循環隣接ペアはすべて、古い隣接ペアとは異なります。 これは正しいです。考えられるすべての新しい座席が考慮され、最初の有効な座席が返されるからです。 問題は候補者の数だ。 がある`n!`順列、および 1 つの候補をチェックする場合`Theta(n)`時間、与えること`Theta(n * n!)`最悪の場合の運用。 で`n = 3 * 10^5`、式を書き留めることさえ`300000 * 300000!`すでに、プログラムが列挙できる数をはるかに超えた数を記述しています。 

有益な観察は、学生 ID について推論する必要がまったくないということです。 古い立場を次のように考えてください。`0, 1, ..., n-1`。 円周距離がちょうど次の場合、2 つの位置が解答内で連続することは禁止されます。`1`。 したがって、必要なのは、すべての連続するペアが異なる距離を持つ位置の並べ替えだけです。`1`。 

奇数の場合`n`、ゼロベースのインデックスを使用して、すべての偶数インデックスの位置を取得し、その後にすべての奇数インデックスの位置を取得します。 1 ベースのポジションでは、これは次のようになります。`1, 3, 5, ..., 2, 4, 6, ...`。 各グループ内では、連続する位置が 2 つずつ異なります。 グループ間の境界でも、差は少なくとも 2 モジュロです`n`なぜなら`n`奇数です。 最後のペアは同じプロパティを持ちます。 

偶数の場合`n >= 6`、同じシーケンスには、問題のある遷移が 1 つだけあります。つまり、最後の偶数位置から最初の位置に戻るラップアラウンドです。 最後の 2 つの要素を交換すると、問題が修正されます。 同様に、`n = 6`私たちは得る`1 3 5 2 6 4`、そしてのために`n = 8`私たちは得る`1 3 5 7 2 8 6 4`。 すべての隣接するペアには、古い位置の距離が少なくとも 2 あります。 

この構造は、順列に格納されている値とは独立しています。 古いポジションの必要な順序を構築し、それらのポジションを占める学生を出力します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 |---|---|---|---|
 | ブルートフォース |`O(n * n!)`|`O(n)`| 遅すぎる |
 | 最適 |`O(n)`|`O(n)`| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 古い循環順列を読み取る`a`。 学生 ID を直接操作するのではなく、インデックスの順序を構築します。 

2. もし`n < 5`、印刷`-1`。 のために`n = 3`すべてのペアは禁止されていますが、`n = 4`許可されたペアのみが 2 つの切断されたエッジを形成するため、どちらの場合もハミルトニアン サイクルを形成できません。 

3. もし`n`奇数です、ポジションを収集します`0, 2, 4, ...`最初に、次にポジション`1, 3, 5, ...`。 1 ベースの表記法では、これは次のようになります。`1, 3, 5, ..., 2, 4, 6, ...`。 

4. もし`n`が偶数の場合は、同じシーケンスを構築し、最後の 2 つの位置を交換します。 このスワップにより、変更されていない奇数-偶数の順序によって作成された唯一の問題のあるラップアラウンド遷移が削除されます。 

5. 作成した職位順序を次のように学生 ID に変換します。`a[position]`選択した位置ごとに。 これらの ID を順番に印刷します。 以来`a`は順列であり、すべての生徒が 1 回だけ出現します。 

これが機能する理由: 奇数位置のグループ内と偶数位置のグループ内では、連続する古い位置がちょうど 2 だけ異なるため、これらの生徒は以前は隣人ではありませんでした。 奇数の場合`n`、2 つの境界遷移も少なくとも 2 の円周距離を持ちます。 偶数の場合`n`、最後の 2 つの位置を交換すると、影響を受ける 2 つのトランジションが変更され、それらの円周距離も少なくとも 2 になります。 この構造はすべての古い位置の順列であるため、生徒が失われたり重複したりすることはありません。 したがって、新しい円形の隣り合うペアはすべて、古い座席では隣接していませんでした。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve(data=None):
    if data is None:
        n = int(input())
        a = list(map(int, input().split()))
    else:
        it = iter(data.split())
        n = int(next(it))
        a = [int(next(it)) for _ in range(n)]

    if n < 5:
        return "-1\n"

    order = list(range(0, n, 2)) + list(range(1, n, 2))

    if n % 2 == 0:
        order[-1], order[-2] = order[-2], order[-1]

    ans = [a[i] for i in order]
    return " ".join(map(str, ans)) + "\n"

if __name__ == "__main__":
    sys.stdout.write(solve())
```最初のブランチは、2 つの不可能なサイズを即座に処理します。 実行可能性があるため、実際の順列を検査する必要はありません。`n = 3`そして`n = 4`循環構造のみに依存します。 

の`order`式では、ゼロから始まるすべての偶数の位置が作成され、その後にゼロから始まるすべての奇数の位置が作成されます。 値ではなくインデックスを使用することが、実装の重要な詳細です。 入力順列には任意の順序で生徒を含めることができますが、その位置は常に同じ隣接構造を持ちます。 

偶数の場合`n`、`order[-1]`そして`order[-2]`構築されたシーケンスの最後の 2 つの要素です。 これら 2 つを交換することは、まさに偶数の場合に必要な調整です。 Python の負のインデックスにより、これは実際の値から独立したものになります。`n`、そしてそれ以前の`n < 5`check は、これらの位置が存在することを保証します。 

ついに、`a[i]`古い職位をそれぞれの学生 ID にマッピングします。 以来`a`が順列であることが保証されている場合、訪問した配列やセットを必要とせずに別の順列が生成されます。 

大規模な積を伴う整数演算は必要ないため、整数のオーバーフローは問題になりません。 構築と最終的な成果物は、それぞれ一定の回数、すべての生徒に影響を与えます。

## 特殊なケース

 のために`n = 3`、 考慮する`3 / 1 2 3`。 古い円形のエッジは`{1,2}`、`{2,3}`、 そして`{3,1}`、考えられるすべての生徒のペアをカバーします。 アルゴリズムはすぐに出力します`-1`、不可能なサイクルを構築しようとする試みを避けます。 

のために`n = 4`、 考慮する`4 / 1 2 3 4`。 唯一の非旧近隣ペアは、`1-3`そして`2-4`。 新しい円形の座席には 4 つの許容エッジが必要ですが、これら 2 つの許容エッジは切断されているため、解決策は存在しません。 の`n < 5`状態が正しく印刷される`-1`。 

奇数の場合`n = 5`、 考慮する`5 / 1 2 3 4 5`。 ポジションの順番は、`0,2,4,1,3`、に対応`1 3 5 2 4`。 内部的な違いは 2 つの位置ですが、ラップアラウンド ペアは`4,1`円周距離も 2 です。 したがって、この構築では特別な修正を行わずに境界を処理します。 

偶数の場合`n = 6`、最初の奇数-偶数の順序は次のようになります。`1 3 5 2 4 6`。 最後のペア`6,1`彼らの学生は古いサークルの隣人だったため、禁止されています。 最後の 2 つの位置を交換すると、`1 3 5 2 6 4`。 影響を受けるトランジションは次のようになります。`2-6`そして`4-1`、その円周距離はそれぞれ 4 と 3 であるため、ラップアラウンド違反は消えます。 

実際の学生ラベルは完全に任意のものにすることができます。 たとえば、サンプルの順列は次のように始まります。`6`それよりも`1`、しかし、構築は依然としてその位置でのみ機能します。 このため、学生の値による並べ替え、マッピング、ID の検索は必要ありません。
