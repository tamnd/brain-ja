 ## 解決策
 ## 問題の理解

 入力は、前月の円形座席について説明しています。 配列自体は時計回りの順序で生徒を与えるため、連続する配列位置は隣接しており、最初と最後の要素も隣接しています。 

すべての生徒を含む別の循環順序を 1 回だけ出力する必要があります。 新しいサークルで隣り合って座っている生徒のペアはすべて、古いサークルで隣接していてはなりません。 いかなる有効な取り決めも受け入れられます。`-1`そのような取り決めが存在しない場合には必須です。 以下の構造は、この問題の標準的な解決策に従っています。 

と`n`と同じくらい大きい`3 * 10^5`1 秒しか利用できない場合、解は線形または線形に近いものである必要があります。 すべての順列を含むものは直ちに不可能です。`O(n^2)`検索は周囲で実行されます`9 * 10^10`上限での操作。 便利な構造は、古い配置自体がサイクルであるため、学生 ID ではなく役職について推論できることです。 

特別な処理が必要な 2 つの小さな値があります。 のために`n = 3`、学生のすべてのペアは古いサークル内で隣接しているため、新しい隣接に使用できるペアはありません。 のために`n = 4`、唯一の非隣接ペアは、反対側の生徒の 2 つのペアであり、4 頂点サイクルではなく 2 つの切断されたエッジを形成します。 したがって、どちらの場合も不可能です。 

たとえば、`n = 3`そして入力`1 3 2`、古い円には 3 つの可能なペアがすべて含まれているため、正しい出力は次のようになります。`-1`。 線形配列内の連続する位置のみをチェックし、最初と最後の隣接関係を忘れる不注意な実装では、配置が誤って受け入れられる可能性があります。 

のために`n = 4`、 考慮する```
41 2 3 4
```許可される新しい隣接関係は次のとおりです`(1,3)`そして`(2,4)`。 円形の配置には 4 つの許可されたエッジが必要ですが、これらの 2 つの許可されたエッジは 1 つのサイクルを形成できないため、正しい出力は再び次のようになります。`-1`。 

偶数の境界問題もあります`n`。 偶数位置にあるすべての要素を取得し、続いて奇数位置にあるすべての要素を取得するだけではほぼ機能しますが、最後から最初のエッジは禁止されています。 たとえば、ポジションについては、`0,1,2,3,4,5`、注文`0,2,4,1,3,5`端で終わる`5 -> 0`、これは元々の隣接関係でした。 その境界を修復するには、最後の 2 つの要素を交換する必要があります。 

入力は順列であることが保証されているため、「すべての値が等しい」テストは有効な問題インスタンスではありません。 次のようなテスト`4 / 1 1 1 1`入力契約に違反しているため、提出されたプログラムの正当性テストとして使用すべきではありません。 

## アプローチ

 直接的なアプローチは、スチューデントのすべての順列を試し、その円形隣接ペアがすべて元の円形隣接ペアと異なるかどうかを確認することです。 単一の候補者が必要とするのは、`n`隣接性チェックがありますが、`n!`候補者、諦める`n * n!`最悪の場合のチェック。 たとえ`n = 10`、それは約です`36.3`100 万回の隣接チェック。 で`n = 3 * 10^5`、階乗増加により、このアプローチは完全に使用できなくなります。 

候補者を直接チェックするのは簡単なので、ブルートフォースが機能します。 難しいのは候補者を見つけることだ。 有益な観察は、制限が古い円内の位置のみに依存するということです。 2 つの古い位置がどちらも異なる場合`1`または`-1`モジュロ`n`、生徒は安全に隣同士に配置できます。 

これは、より大きな固定ステップでポジションを取ることを示唆しています。 奇数の場合`n`、ステップバイ`2`モジュロ`n`すべての位置を 1 回だけ訪問します。`2`そして`n`は互いに素である。 この新しい順序のすべての連続するペアは、最後のペアを含め、古い円内の 2 つの位置で区切られているため、すべての新しい隣接関係が有効になります。 

偶数の場合`n`、ステップバイ`2`同じパリティの位置のみを訪問します。 最初にすべての偶数の位置を答えに入れてから、すべての奇数の位置を答えに入れることができます。 各グループ内では、元の円内で連続する位置が 2 つ異なるため、それらのエッジは安全です。 境界に問題があるだけです。 奇数位置グループの最後の 2 つの要素を交換すると、両方の境界エッジが元の隣接関係に変わります。`n >= 6`。 

これにより、単純な結果が得られます`O(n)`工事。 答えが存在しないという事実`n < 5`そしてその建設があらゆる状況にうまく機能することを`n >= 5`既知の参照実装にも反映されています。

 ## アルゴリズムのチュートリアル

 1. 円順列を読み取る`a`。 の位置を使用して答えを構築します`a`、禁断の関係は完全に古い立場によって決定されるからです。 
2. もし`n < 5`、印刷`-1`。 のために`n = 3`そして`n = 4`、古いサイクルの補部分にはハミルトニアン サイクルが含まれていないため、すべての制限を満たす循環配置は存在しません。 
3. 追加`a[0], a[2], a[4], ...`答えに。 これらの位置は元の円内で 2 つ離れているため、このパーツ内に作成されたすべての隣接関係が許可されます。 
4.追加`a[1], a[3], a[5], ...`答えに。 連続する位置も 2 つ異なるため、同じ議論がこの 2 番目の部分にも当てはまります。 
5. もし`n`奇妙です、ここでやめてください。 この順序は、元の円の周りの 2 つの位置を繰り返し移動することによって得られる順序とまったく同じです。 なぜなら`gcd(2, n) = 1`、これはすべての位置を 1 回訪問し、最後から最初のペアもモジュロで 2 位置離れています。`n`。 
6. もし`n`が偶数の場合は、作成された答えの最後の 2 つの要素を交換します。 交換前の最後の要素は、`a[n-1]`、最初の要素に隣接します`a[0]`昔のサークルで。 交換後、最後の要素は次のようになります。`a[n-3]`から安全に分離されています。`a[0]`いつ`n >= 6`。 影響を受けるもう一方の境界も安全になります。 
7. 結果の順列を出力します。 元の位置を再配置しただけなので、元の要素がすべて 1 回だけ含まれています。 

### なぜ効果があるのか

 最初の奇数を考慮する`n`。 すべての答えのエッジは、その差が次の位置に接続されます。`2`モジュロ`n`。 以来`n >= 5`、の違い`2`は古い隣接関係ではありません。考えられる違いは次のとおりです。`1`そして`n - 1`。 なぜなら`2`奇数と互いに素である`n`を繰り返し追加します`2`はすべての位置を訪問するため、構築は 1 つの循環順列になります。 

偶数の場合`n >= 6`、偶数位置グループ内のすべてのエッジと奇数位置グループ内のすべてのエッジには位置の違いがあります。`2`。 潜在的に危険なエッジは、グループ間の 2 つの接続と、最後から最初へのエッジだけです。 最後の 2 つの要素を交換した後、これらは位置を接続します`n-2`に`1`、`n-3`に`n-1`、 そして`n-3`に`0`。 それらの円周距離は少なくとも`3`または`2`存在せずに`1`または`n-1`, したがって、どれも古い隣接関係ではありませんでした。 したがって、作成された円内のすべてのエッジが有効になります。 

不変条件は、連続して配置されたすべてのペアが元の円内で 2 つの位置離れているか、または特別に修復されたグループ間の境界の 1 つであることです。 これらのペアはいずれも、元の隣接ペアではありません。 

## Python ソリューション```python

def solve():    n = int(input())    a = list(map(int, input().split()))
    if n < 5:        print(-1)        return

    for i in range(0, n, 2):        ans.append(a[i])
    for i in range(1, n, 2):        ans.append(a[i])
    if n % 2 == 0:        ans[-1], ans[-2] = ans[-2], ans[-1]
    print(*ans)

奇数の場合`n`、他には何も必要ありません。 結果として得られるシーケンスは、元の円のステップ 2 の横断です。 たとえば、ポジションが 5 つある場合、ポジションの順序は次のようになります。`0, 2, 4, 1, 3`、終了エッジは次のようになります。`3`に戻る`0`、再び円を2周する距離。

このアルゴリズムは入力からの整数を格納してインデックスを作成するだけであるため、整数オーバーフローの問題はありません。 また、この実装ではコストのかかる検索が回避されるため、実行時間は読み取りと印刷に大半が費やされます。`n`価値観。

```アルゴリズムが戻るようにします`-1`何かを構築する前に。 3 人の生徒のすべてのペアは古い円内ですでに隣接しているため、法的に新しい円のエッジを形成することはできません。
