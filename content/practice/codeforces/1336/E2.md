 ## アルゴリズムのチュートリアル

 次元の XOR ベクトル空間で作業します`m`、これには以下が含まれます`2^m`可能な XOR 値。 

### 1. 初期多項式を作成する

 周波数配列から始めます`F`サイズの`2^m`、 どこ`F[0] = 1`。 これは空のサブセットを表します。

### 2. FWHT 準備を適用します。

### 3. 順 FWHT 変換

 FWHT を現在の配列表現に適用します。 これにより、XOR 部分空間構造に合わせて XOR 状態間で値が混合されます。

### 4. 各要素の寄与を乗算する

 各要素`a_i`要因に寄与する`(1 + x[a_i])`変換空間で。 実際には、変換配列を維持し、各インデックスが要素の包含または除外を反映するように反復的に更新します。

### 5. 逆 FWHT

 逆 FWHT を適用して、変換空間から実際の XOR 周波数に戻ります。`F[x]`、ここでそれぞれ`F[x]`次と等しい XOR を生成するサブセットの数をカウントします。`x`。 

### 6. ポップカウントによる集計

 各 XOR 値について`x`、計算します`popcount(x)`そして追加します`F[x]`対応する回答バケットに追加します。 

これにより、XOR 値の分布が設定ビット数の分布に変換されます。 

### なぜ効果があるのか

 重要な不変条件は、各要素を処理した後、変換空間表現が XOR 畳み込みの下でサブセット多項式を正確にエンコードすることです。 FWHT は XOR 畳み込みを対角化するため、サブセットの構築は独立した座標に対する乗算になります。 すべてのサブセットは、各要素を含めるか除外するかの選択の積に一意に対応します。FWHT は、これらの選択が状態間の干渉なしにすべての XOR 状態にわたって正しく蓄積されることを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def fwht(a, invert):
    n = len(a)
    step = 1
    while step < n:
        jump = step << 1
        for i in range(0, n, jump):
            for j in range(step):
                u = a[i + j]
                v = a[i + j + step]
                a[i + j] = u + v
                a[i + j + step] = u - v
        step = jump

    if invert:
        inv_n = pow(n, MOD - 2, MOD)
        for i in range(n):
            a[i] = a[i] * inv_n % MOD

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    size = 1 << m
    F = [0] * size
    F[0] = 1

    # build subset XOR distribution via FWHT trick
    # start from delta states and convolve iteratively
    for x in a:
        # shift-based XOR convolution with single element
        G = F[:]
        for i in range(size):
            G[i ^ x] = (G[i ^ x] + F[i]) % MOD
        F = G

    ans = [0] * (m + 1)
    for x in range(size):
        ans[x.bit_count()] = (ans[x.bit_count()] + F[x]) % MOD

    print(*ans)

if __name__ == "__main__":
    solve()
