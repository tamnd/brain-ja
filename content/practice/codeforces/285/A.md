 ## 解決策
 ## 問題の理解

 数値がその直後の数値より大きい、正確に _k_ 個の位置を持つ、1 から _n_ までの数値の順列を構築するように求められます。 言い換えれば、正確に _k_ 個の「降下」が発生する長さ _n_ のシーケンスが必要です。 入力は 2 つの整数 _n_ と _k_ で構成され、出力はこのプロパティを満たす任意の順列になります。 順列内の数値は個別であり、範囲は 1 から _n_ までです。 

この制約では、10^5 までの _n_ と _n_ 未満の _k_ が許可されます。 これは、二次以上の複雑さのアルゴリズムを使用する余裕がないことを意味します。 ソリューションは、線形または線形に近い時間で動作する必要があります。 メモリの使用量は多量にありますが、不必要な追加のデータ構造は避けるべきです。 

エッジ ケースには 0 に等しい _k_ が含まれます。この場合、順列は完全に増加する必要があります。 もう 1 つのケースは、_k_ が _n_-1 に等しい場合で、この場合、順列は完全に減少しています。 試行錯誤によってシーケンスを構築したり、構造を持たずに交換したりする不注意な実装は、これらの極端な場合に失敗する可能性があります。 たとえば、入力の場合`5 0`、単純な降順優先戦略では次のような結果が得られます。`[5,4,3,2,1]`、ゼロではなく 4 つの降下があります。 

## アプローチ

 ブルートフォース手法では、1 から _n_ までの数値のすべての順列を試し、正確に _k_ 個の下降を持つ順列が見つかるまで下降数を数えます。 順列の数は _n_ です! また、下降のカウントには O(n) かかるため、総作業量は O(n! × n) ですが、これは _n_ が 10! と小さい場合でも実行不可能です。 すでに 3,628,800 です。 

最適な解決策を導き出すための重要な洞察は、大きな数値の直後に小さな数値が続くときに各降下が発生するということです。 正確に _k_ 個の降下を生成するには、最初の _k_ 数値を降順で最大の _k_ 数値として選択し、すべての位置で降下を保証し、その後、追加の降下を避けるために残りの数値を昇順に追加します。 この貪欲な構造により、試行錯誤なしで正確に _k_ 回の降下が保証されます。 

貪欲なアプローチは、各降下が次の数値よりも大きい数値を選択することによって直接制御されるため機能します。 最初の _k_ 数値を降順で配置すると、それ以上の数値を昇順で追加しても余分な降下を作成できず、減少する係数が正確に _k_ になるようにします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! × n) | O(n) | 遅すぎる |
 | 貪欲な建設 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つのポインターを初期化します。`left = 1`そして`right = n`。 これらは、順列に配置できる最小数と最大数を表します。 
2. 空のリストを作成する`perm`最後の順列を保持します。 
3. _k_ 回繰り返します:

 - 追加`right`に`perm`。 これにより、確実に降下するために利用可能な最大の数値が配置されます。 
- 減少`right`これにより、使用可能なセットから数値が削除されます。 
4. 残りの _n ～ k_ 番号について繰り返します。 

- 追加`left`に`perm`。 これにより、利用可能な最小の数値が配置され、それ以上の降下は維持されません。 
- 増加`left`これにより、使用可能なセットから数値が削除されます。 
5. を出力します。`perm`リスト。 

機能する理由: すべての下降は、小さい数値の前に大きい数値を配置することによって引き起こされます。 _k_ 個の最大値を降順で取得することで、開始時に正確に _k_ 個降下することが保証されます。 残りの数値を昇順に配置すると、それ以上の降下がなくなることが保証されます。 不変条件は、各ステップの後に配置される降下の数が、次のステップから選択した回数に等しいということです。`right`ポインタ。 この方法では、降下を過剰に生成したり、過少に生成したりすることはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

perm = []
left, right = 1, n

for _ in range(k):
    perm.append(right)
    right -= 1

for _ in range(n - k):
    perm.append(left)
    left += 1

print(" ".join(map(str, perm)))
```最初のループでは、最初に最大の数値を選択することで、正確に _k_ 個の降下を取得します。 2 番目のループでは、追加の降下を防ぐために、残りの数値を昇順に入力します。 2 ポインターのアプローチでは、余分な並べ替えや集合操作が回避され、O(n) になります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, k = map(int, input().split())
    perm = []
    left, right = 1, n
    for _ in range(k):
        perm.append(right)
        right -= 1
    for _ in range(n - k):
        perm.append(left)
        left += 1
    return " ".join(map(str, perm))

# provided sample
assert run("5 2\n") == "5 4 1 2 3", "sample 1"

# custom cases
assert run("4 0\n") == "1 2 3 4", "increasing permutation, k=0"
assert run("4 3\n") == "4 3 2 1", "fully decreasing permutation, k=n-1"
assert run("1 0\n") == "1", "single element, k=0"
assert run("6 2\n") == "6 5 1 2 3 4", "mixed descending/ascending"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 4 0 | 1 2 3 4 | k=0 を正しく処理します。 
| 4 3 | 4 3 2 1 | k=n-1 を正しく処理します。 
| 1 0 | 1 | 単一要素のエッジケース |
 | 6 2 | 6 5 1 2 3 4 | k 個の下降と残りの昇順の適切な配置 |

 ## 特殊なケース

 のために`k=0`入力あり`4 0`、アルゴリズムは右ポインターから数値を配置せず、すべての数値が左から取得され、次の結果が生成されます。`[1,2,3,4]`。 これにより、いかなる降下も正確に回避できます。 

のために`k=n-1`入力あり`4 3`、アルゴリズムは最大 3 つの数値を取得します。`[4,3,2]`右から、残りの小さいものから`[1]`左から、生産中`[4,3,2,1]`、ちょうど 3 つの降下を与えます。 

のために`n=1`、入力`1 0`、ループはそれぞれ 0 回と 1 回実行され、`[1]`、これは要件を自明に満たします。 

これは、貪欲なアプローチが最小サイズ、最大サイズ、および境界のケースを正しく処理することを確認します。
