 ## 解決策
 ## 問題の理解

 整数の配列が与えられており、私たちの目標は、「きちんとした」可能な限り長いサブシーケンスを抽出することです。 きちんとしたサブシーケンスは 1 つ以上のブロックを連結することによって作成されます。ここで、ブロックは一連の同一の数字であり、その数字の値はブロックの長さに等しくなります。 例えば、`[3,3,3]`は、3 つの要素が含まれており、すべて 3 に等しいため、有効なブロックです。 配列`[2,2]`有効なブロックですが、`[2,2,2]`これは、値 2 が長さ 3 と一致しないためではありません。空の配列は常に適切であるとみなされます。 

これらのブロックに分割できる入力配列の最長のサブシーケンスの長さを見つける必要があります。 これには、繰り返される数値を見つけるだけでなく、その数が数値自体と一致するようにそれらをグループ化する必要があります。 

制約が示すのは、`n`すべてのテスト ケース全体で最大 200,000 件になる可能性があります。 最大 10,000 のテスト ケースでは、テスト ケースあたり約 O(n) よりも遅いものは許容できません。 すべてのサブシーケンスを試す単純なアプローチでは、n が指数関数的になるため、まったく実用的ではありません。 考慮すべきエッジ ケースには、きちんとしたサブシーケンスが存在しない配列、完全に 1 または n で構成される配列、同じ番号の複数の互いに素なブロックが存在するが、より大きなきちんとしたブロックに結合できない配列が含まれます。 

たとえば、配列`[2,2,1,1]`ブロックを形成できる`[2,2]`そして2つ`[1]`ブロックで構成され、長さ 4 のきちんとしたサブシーケンスが得られます。`[2,3,3]`有効なブロックを形成できないため、長さ 0 の整ったサブシーケンスが生成されます。 

## アプローチ

 ブルートフォース手法では、すべてのサブシーケンスを考慮し、有効なブロックに分割できるかどうかを確認し、最大長を取得します。 これは原理的には正しいですが、部分列の数は`2^n`、それはたとえ`n = 20`。 

重要な洞察は、ブロックが完全に数値の頻度によって決定されることを認識することです。 ブロック内またはブロック間の順序は気にしません。 完全なブロックを形成するのに十分な同一の数だけが必要です。 それぞれの番号について`x`配列内で、同じサイズのブロックをできるだけ多く形成することを試みることができます。`x`できるだけ。 貪欲な戦略は、各数値の可能な最大数から完全なブロックを形成し続け、すべての完全なブロックの合計長を累積することです。 ブロックの形成は数値ごとに独立しているため、動的計画法配列を使用できます。`dp[x]`Number のブロックで終わる整ったサブシーケンスの最大長を格納します`x`。 

実際には、配列内の各数値を反復処理し、出現回数を維持し、十分な出現が確認されたときにこの数値を完全なブロックの一部として追加することで構築できる最大の整ったサブシーケンス長を追跡します。 問題はカウントとグループ化に帰着し、テスト ケースごとに O(n) の処理が可能になります。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 テスト ケースごとに、次の内容を読んでください。`n`そして配列`a`。 
2. 辞書を作成する`count`各数字が何回出現するかを追跡する`a`。 
3. 辞書を作成する`dp`その番号のブロックで終わる整ったサブシーケンスの最大長を追跡します。 
4. 配列を反復処理します。 要素ごとに`x`:

 - インクリメント`count[x]`。 
- もし`count[x]`到達する`x`、これは、サイズの完全なブロックを形成できることを意味します`x`。 
- アップデート`dp[x]`として`dp[x] = dp[x] + x`そしてリセット`count[x]`次の潜在的なブロックに向けて。 
5. 最大値を追跡します。`dp`すべての数字にわたって。 これは、最も長い整ったサブシーケンスの長さを表します。 
6. 各テスト ケースの結果を出力します。 

その理由は、各ブロックは独立しており、その数値が十分に出現することのみに依存しているためです。 出現回数を段階的にカウントし、貪欲にブロックを形成することで、潜在的なブロックが無駄にならず、全長が最大化されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        from collections import defaultdict
        
        count = defaultdict(int)
        dp = defaultdict(int)
        res = 0
        
        for x in a:
            dp[x] = max(dp[x], 0)
            count[x] += 1
            if count[x] >= x:
                dp[x] += x
                count[x] -= x
            res = max(res, dp[x])
        print(res)
```このソリューションは、次を使用して複数のテスト ケースを効率的に読み取ります。`sys.stdin.readline`高速入力用。 私たちは`defaultdict`カウントを増加する際のキーエラーを回避するため。 の`dp`辞書は、各数値で達成可能な最大長を追跡します。 貪欲な更新により、すべての完全なブロックがきちんとしたサブシーケンスの合計長に寄与することが保証されます。

 ## 特殊なケース

 配列に使用可能な数より大きい数値が含まれている場合、ブロックは形成できません。 例えば`[10]`長さ 10 のブロックには 10 が 10 回出現する必要があるため、結果は長さ 0 になります。 1 が繰り返される配列は、サイズ 1 の複数のブロックを正しく形成します。 次のように、出現総数が数値の倍数である配列`[2,2,2,2]`、正しくブロックを生成します`[2,2]`このアルゴリズムは、追跡によってこれらのケースを処理します。`count[x]`そして更新のみ`dp[x]`完全なブロックが利用可能な場合、正確性が保証されます。
