 ## 解決策
 ## 問題の理解

 私たちはハーフタイムのスコアとフルタイムのスコアを知っています。 

ハーフタイムスコアが`a:b`その後、前半中にRiOIチームが正確に得点しました`a`ゴールと KDOI チームが正確に得点しました`b`目標。 

最終スコアが次の場合`c:d`その後、後半中にRiOIチームが得点しました`c-a`ゴールとKDOIチームの得点`d-b`目標。 

唯一の制限は、どのチームも各前半内で連続して 3 ゴールを決めてはいけないということです。 2 つの部分は独立しています。 前半終了時の連勝は後半まで続かない。 

テスト ケースごとに、どちらの前半にも同じチームによる 3 連続ゴールが含まれないように前半と後半にゴールを配置することが可能かどうかを判断する必要があります。 

スコアは最大 100 で、テスト ケースは最大 1000 です。 これらの境界は小さいです。 考えられるすべてのスコア ペアに対して何らかの計算を実行するソリューションでも、簡単に制限内に収まります。 本当の課題は、有効なゴール シーケンスが存在する場合を特徴づける数学的条件を特定することです。 

よくある間違いは、試合の合計スコアだけを考えることです。 制限は各半分に個別に適用されます。 例えば：```
a=1 b=4 c=2 d=5
```前半は得点あり`1:4`そして後半は貢献します`1:1`。 両方の半分を有効に配置できるため、答えは次のようになります。`YES`。 

もう 1 つの簡単な間違いは、ゴールのない前半が常に有効であることを忘れていることです。 例えば：```
a=4 b=1 c=4 d=1
```後半はゴールゼロ。 空のシーケンスには 3 つの連続したゴールを含めることはできないため、答えは次のようになります。`YES`。 

最も重要なエッジケースは、一方のチームが他方のチームよりもはるかに多くのゴールを獲得したときに発生します。 例えば：```
a=0 b=100
```すべての目標は KDOI に属します。 これにより、必然的に 100 個の連続した KDOI ゴールが作成され、ルールに違反します。 前半だけでは無理なので答えは`NO`。 

## アプローチ

 総当り的な観点は、状態を発見するのに役立ちます。 

Suppose a half contains`x`RiOIの目標と`y`KDOI の目標。 正確にそれらのカウントを含むすべてのシーケンスを試して、同じ 3 つの連続ゴールを回避するシーケンスがあるかどうかを確認できます。 これは、妥当性の定義を直接テストするため、正しいです。 

問題は、シーケンスの数が膨大であることです。 100 ゴールを達成したハーフはすでにおよその目標を達成しています`2^100`可能な取り決め。 徹底的な捜索は絶望的だ。 

重要な観察は、チームのゴールは最大でも長さ 2 のブロックにのみ表示されるということです。 

一方のチームがもう一方のチームよりも多くのゴールを決めたと仮定します。 させて```
big = max(x, y)
small = min(x, y)
```の`small`ゴールは区切り文字として使用できます。 彼らが作成するのはせいぜい`small + 1`ギャップ:```
_ S _ S _ S _ ...
```各ギャップ内では、得点の多いチームが最大 2 ゴールに貢献できますが、それ以外の場合は長さ 3 のランが表示されます。 

あるので`small + 1`ギャップがあり、各ギャップには最大 2 ゴールを保持できます。大規模なチームの最大ゴール数は次のとおりです。```
2 * (small + 1)
```したがって、有効なシーケンスが存在するのは次のとおりです。```
big <= 2 * (small + 1)
```この条件でも十分です。 それが成り立つ場合、ギャップごとに 2 を超えずに、より大きなチームのゴールを利用可能なギャップに分配することができます。 

この条件を前半と後半で個別に確認するだけです。

 ## アルゴリズムのチュートリアル

 各テスト ケースについて:

 1. 前半のスコア数を計算します。```
(a, b)
```2. 有効な前半シーケンスが存在するかどうかを確認します。 

させて：```
big = max(a, b)
small = min(a, b)
```次の場合、半分は有効です。```
big <= 2 * (small + 1)
```3. 後半に得点したゴールを計算します。```
x = c - a
y = d - b
```4. 同じ条件を確認します。`(x, y)`。 

繰り返しますが、次の場合には半分が有効です。```
max(x, y) <= 2 * (min(x, y) + 1)
```5. 印刷`"YES"`両方の半分が有効な場合。 それ以外の場合は印刷します`"NO"`。 

### なぜ効果があるのか

 カウントのある半分を考慮します`(x, y)`。 大きい方のカウントを次のようにします。`big`そして小さいほうのカウントは`small`。 

の`small`目標はシーケンスを最大で次のように分割します`small + 1`より大きなチームのゴールを配置できる位置。 3 回連続の同点ゴールは禁止されているため、各ポジションに同点ゴールを含めることができるのは最大 2 つです。 したがって、すべての有効なシーケンスは次の条件を満たします。```
big <= 2 * (small + 1)
```逆に、この不等式が成り立つ場合、`big`その中の目標`small + 1`どのポジションも 2 ゴールを超えることがないようにポジションを調整します。 これらの位置の間にセパレータ ゴールを配置すると、有効なシーケンスが生成されます。 

したがって、この不等式は必要かつ十分です。 2 つの部分は独立しているため、両方の部分が条件を満たしたときに夢が実現します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def valid(x, y):
    big = max(x, y)
    small = min(x, y)
    return big <= 2 * (small + 1)

t = int(input())

for _ in range(t):
    a, b, c, d = map(int, input().split())

    first_half = valid(a, b)
    second_half = valid(c - a, d - b)

    print("YES" if first_half and second_half else "NO")
```ヘルパー関数は、有効な半分の数学的特徴付けを実装します。 

各テスト ケースについて、2 つの独立した半分を評価します。 前半は直接使用します`(a, b)`。 後半はハーフタイム後に得点した追加ゴールを使用します。`(c-a, d-b)`。 

実際のゴール シーケンスを構築する必要はありません。 この証明は、不等式が有効な取り決めが存在するかどうかを完全に決定することを示しています。 

この実装により、すべての境界問題が自動的に回避されます。 空の半分が機能するのは、たとえば次のような理由です。`(0, 0)`不等式を満たします。 1 つのチームのみが得点する場合も正しく処理されます。 例えば`(0, 2)`は有効ですが、`(0, 3)`そうではありません。

 ## 特殊なケース

 次のことを考慮してください。```

```前半に関しては、`big = 2`そして`small = 0`。 条件は次のようになります。```

```それは本当です。 シーケンス`KK`制限により 2 つではなく 3 つの連続ゴールが禁止されているため、許可されます。 アルゴリズムは出力します`YES`。

small = 0
```そして```

```は誤りです。 唯一可能な順序は次のとおりです`KKK`、同じチームによる3連続ゴールが含まれています。 アルゴリズムは正しく印刷します`NO`。
