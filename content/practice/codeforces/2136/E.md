 ## 解決策
 ## 問題の理解

 各頂点が整数のラベルを持つ無向接続グラフが与えられます。 一部のラベルは固定されていますが、その他は不明で範囲から選択する必要があります$0$に$V-1$。 単純なパスの場合、そのパスに沿ったすべての頂点ラベルの XOR としてその値を定義します。 

すべての頂点のペアについて、グラフはバランスがとれていると呼ばれます。$p$そして$q$、それらを接続するすべての単純なパスは同じ XOR 値を生成します。 つまり、次の XOR は、$p$に$q$は明確に定義されており、どの単純なパスを選択するかには依存しません。 

タスクは、この一貫性条件が成立するように、未知の頂点に値を割り当てることができる方法が何通りあるのかを数えることです。 

この制約により、私たちはパス列挙のアイデアから即座に遠ざけられます。 グラフには最大で次のものを含めることができます$2 \cdot 10^5$頂点と$4 \cdot 10^5$すべてのテスト ケースにわたるエッジなので、すべての単純なパスや頂点のすべてのペアを検査することは不可能です。 サイクルの列挙でも大きすぎます。 

重要な問題は、サイクルによって制約が課されることです。 同じエンドポイント間の 2 つの異なるパスが等しい XOR を生成する必要がある場合、すべてのサイクルの XOR 値が 0 でなければなりません。そうしないと、異なるルートが一致しなくなります。 

微妙だが重要なエッジ ケースは、グラフがツリーの場合に現れます。 サイクルがないため、2 つの頂点間には単純なパスが 1 つだけ存在します。 その場合、ラベル間に制約はまったく存在せず、すべての割り当てが有効になります。 サンプルではこれを確認しています。$n$ノードの収量$V^n$有効な割り当て。 

もう 1 つのエッジ ケースは、単一サイクルを含むグラフです。 このサイクルでは、頂点全体に 1 つの XOR 制約が強制されます。 未知の値がサイクル内に現れる場合、それらは XOR に対して線形制約されますが、それでも GF(2) に対してシステムとして解くことができます。 

単純なアプローチでは、値を割り当ててすべてのサイクルまたはすべてのペアを検証しようとしますが、1 つの割り当ての一貫性をチェックするだけでも、指数関数的に多くのパスを探索する必要があります。 実際の構造は、すべての制約がサイクルによって引き起こされる線形 XOR 方程式であるということです。 

## アプローチ

 強引なアイデアは、すべてに値を割り当てることです。$-1$考えられるすべての方法で頂点を調整し、グラフのバランスが取れているかどうかを確認します。 検証とは、ノードのすべてのペアについて、異なるパスが同一の XOR 結果を与えることを確認することを意味します。 直接チェックするには、すべての単純なパスを列挙するか、サイクル全体にわたる不一致を検出する必要がありますが、どちらも最悪の場合は指数関数的になります。 スパニング ツリーとすべての追加エッジのチェックに限定したとしても、割り当て全体でサイクル XOR 制約を繰り返し計算すると、依然として次のような結果が得られます。$O(V^k)$どこでの行動$k$は未知の頂点の数です。 

重要な観察は、この条件が純粋にサイクル上の XOR 一貫性に関するものであるということです。 ルートを修正して潜在的な値を定義すると$dist[v]$ルートからの任意のパスに沿った XOR として、次にすべてのエッジ$(u,v)$課す$dist[u] \oplus dist[v] = a_u \oplus a_v$。 これを一貫させるには、すべてのサイクルがその周囲のエッジ制約の XOR がゼロであることを満たさなければなりません。これは、すべての頂点が GF(2) 上の線形システムを満たすと言うのと同じです。 

これにより、グラフが連立方程式に変換され、各頂点の値が変数となり、各エッジが線形関係を強制します。 グラフ構造から得られるのは、$n$変数と$m$方程式だけですが、$n - 1$それらのうちの 1 つは接続コンポーネントごとに独立しており、XOR 等式によって形成される制約グラフ内のコンポーネントの数に等しい自由度が残ります。 

この問題は、関係を伝播するためにパリティを備えた DSU (または同等の制約上の BFS) を構築することに帰着します。 各接続コンポーネントは、すべてのノード値が 1 つのグローバル XOR オフセットまで決定されるシステムを定義します。 コンポーネントに固定値が含まれていない場合は、任意のルート値を選択できます。$[0, V)$、与える$V$選択肢。 少なくとも 1 つの固定値が含まれている場合、一貫性があれば、コンポーネント全体が完全に決定されます。 

最終的な答えは、既知の値を固定した後にまだ空いている変数の数によって調整されたコンポーネント間の積になります。

 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | O(n) | 遅すぎる |
 | 最適 (XOR 制約のある DSU) |$O(n \alpha(n))$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 各エッジをエンドポイント間の XOR 差異の制約として再解釈します。 この考え方は、各頂点にコンポーネントのルートを基準とした相対値を割り当てることです。 

1. 接続性だけでなく、各ノードからその親への XOR パリティも保存する DSU 構造を構築します。 これにより、任意のノードを次のように表現できるようになります。$value[root] \oplus parity[node]$。 この表現により、パスの XOR 一貫性がエッジ上のローカル一貫性チェックに変わります。 
2. あらゆるエッジに対して$(u, v)$、DSU セットの統一を試みます。 もし$u$そして$v$がすでに接続されている場合は、暗黙の XOR 関係が既存の XOR 関係と一致するかどうかを確認します。 矛盾する場合、その構成は不可能であり、答えへの寄与はゼロになります。 
3. 2 つのコンポーネントを結合するとき、制約を一貫させるために必要な XOR オフセットを記録します。 これにより、コンポーネント内のすべてのノードが単一のルート変数に対して表現可能であることが維持されます。 
4. すべてのエッジを処理した後、各 DSU コンポーネントは、XOR 制約によって値が結合された頂点のセットを表します。 コンポーネント内で、1 つの頂点値を固定すると、他のすべての頂点値が決定されます。 
5. 次に、固定頂点値を組み込みます。 すべてのコンポーネントについて、既知の値を持つ頂点が少なくとも 1 つ含まれている場合、そのコンポーネントの暗黙のルート値を計算できます。 複数の固定頂点がルート値の競合を意味する場合、その構成は無効です。 
6. コンポーネントに固定頂点が含まれていない場合、そのルート値は完全に自由であり、任意の値を取ることができます。$[0, V-1]$の要因に寄与する$V$合計数に。 
7. すべてのコンポーネントからの寄与を乗算します。 制約のあるコンポーネントは、1 (一貫性があり固定されている場合) または$V$(制約されていない場合)。 最終積モジュロ$998244353$が答えです。 

### なぜ効果があるのか

 XOR を備えた DSU は、グラフ上のポテンシャル関数を保存します。各ノードにはそのコンポーネント ルートに関連する値が割り当てられ、すべてのエッジに線形 XOR 方程式が適用されます。 グラフ内の任意のサイクルは、キャンセルする必要がある制約の合計に対応します。 そうでない場合、DSU はすでに接続されているノードをマージしようとしたときに矛盾を検出します。 したがって、すべての有効な割り当てはコンポーネントごとのルート値の一貫した割り当てに正確に対応し、カウントはそれらのルートの独立した選択をカウントすることになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n
        self.xor = [0] * n

    def find(self, x):
        if self.parent[x] == x:
            return x
        p = self.parent[x]
        root = self.find(p)
        self.xor[x] ^= self.xor[p]
        self.parent[x] = root
        return self.parent[x]

    def get_xor(self, x):
        self.find(x)
        return self.xor[x]

    def unite(self, a, b, w):
        ra = self.find(a)
        rb = self.find(b)

        if ra == rb:
            return (self.get_xor(a) ^ self.get_xor(b)) == w

        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
            a, b = b, a

        self.parent[rb] = ra
        self.xor[rb] = self.get_xor(a) ^ self.get_xor(b) ^ w
        self.size[ra] += self.size[rb]
        return True

def solve():
    t = int(input())
    for _ in range(t):
        n, m, V = map(int, input().split())
        a = list(map(int, input().split()))

        dsu = DSU(n)

        ok = True

        for _ in range(m):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            if not dsu.unite(u, v, 0):
                ok = False

        if not ok:
            print(0)
            continue

        root_value = {}
        comp_has_fixed = {}
        comp_cnt = {}

        for i in range(n):
            r = dsu.find(i)
            x = dsu.get_xor(i)

            comp_cnt[r] = comp_cnt.get(r, 0) + 1

            if a[i] != -1:
                val = a[i] ^ x
                if r in root_value:
                    if root_value[r] != val:
                        ok = False
                        break
                else:
                    root_value[r] = val
                    comp_has_fixed[r] = True

        if not ok:
            print(0)
            continue

        ans = 1
        for r in comp_cnt:
            if r not in comp_has_fixed:
                ans = ans * V % MOD

        print(ans)

if __name__ == "__main__":
    solve()
```DSU は接続性を維持するだけでなく、各ノードからそのコンポーネント ルートまでの XOR オフセットも維持します。 これにより、すべての頂点値をコンポーネントごとに単一の未知数として表現できるようになります。 

結合中に、エッジによって暗示される XOR 制約が満たされるように強制します。 エンドポイントがすでに同じコンポーネント内にあり、制約に違反している場合、そのケースは直ちに破棄されます。 

コンポーネントを構築した後、固定値を持つすべての頂点は、そのコンポーネントのルートに制約を引き起こします。 XOR オフセットを調整した後に複数の固定頂点が一致しない場合、コンポーネントは一貫性がありません。 

最後に、制約のない各コンポーネントが寄与します。$V$そのルートは許容範囲内の任意の値にできるため、独立した選択が可能です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import prod

    MOD = 998244353

    class DSU:
        def __init__(self, n):
            self.p = list(range(n))
            self.x = [0]*n

        def find(self, a):
            if self.p[a] != a:
                pa = self.p[a]
                self.p[a] = self.find(pa)
                self.x[a] ^= self.x[pa]
            return self.p[a]

        def xorv(self, a):
            self.find(a)
            return self.x[a]

        def unite(self, a, b, w):
            ra, rb = self.find(a), self.find(b)
            if ra == rb:
                return (self.xorv(a) ^ self.xorv(b)) == w
            self.p[rb] = ra
            self.x[rb] = self.xorv(a) ^ self.xorv(b) ^ w
            return True

    t = int(input())
    out = []
    for _ in range(t):
        n,m,V = map(int,input().split())
        a = list(map(int,input().split()))
        dsu = DSU(n)
        ok = True
        for _ in range(m):
            u,v = map(int,input().split())
            if not dsu.unite(u-1,v-1,0):
                ok=False
        if not ok:
            out.append("0")
            continue

        comp = {}
        fixed = {}
        for i in range(n):
            r = dsu.find(i)
            val = dsu.xorv(i)
            comp[r] = comp.get(r,0)+1
            if a[i]!=-1:
                rootval = a[i]^val
                if r in fixed and fixed[r]!=rootval:
                    ok=False
                    break
                fixed[r]=rootval
        if not ok:
            out.append("0")
            continue

        ans = 1
        seen = set()
        for i in range(n):
            seen.add(dsu.find(i))
        for r in seen:
            if r not in fixed:
                ans = ans * V % MOD
        out.append(str(ans))
    return "\n".join(out)

 すべてのノードが固定値なしで接続されている完全な循環グラフは、DSU が矛盾を検出せず、自由なコンポーネントを 1 つだけ生成していることを示しています。$V$ルート割り当ての選択肢。
