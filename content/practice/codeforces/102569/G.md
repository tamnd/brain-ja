 ## 解決策
 ## 問題の理解

 オブジェクトのコレクションが 2 つあります。 1 つのコレクションにはナットが含まれ、もう 1 つのコレクションにはボルトが含まれます。 すべてのナットには固有のサイズがあり、すべてのボルトには固有のサイズがあり、サイズは同じ範囲になります。 2 つのコレクション間の関係を知る唯一の方法は、1 つのナットと 1 つのボルトを比較することです。 比較すると、ナットがボルトより小さいか、大きいか、またはまったく同じサイズであるかがわかります。 

目標は、すべてのナットについて、同じサイズのボルトのインデックスを検出することです。 プログラムはサイズを直接受け取りません。 代わりに、比較を行い、その答えを使用して、隠された一致を再構築する必要があります。 

の限界`5 * n * log2(n)`比較してみると、考えられるすべてのナットとボルトの組み合わせを試すのは現実的ではないことがわかります。 と`n = 1000`、二次法では約 100 万回の比較が行われますが、許容される比較の数は約 5 万回のみです。 このソリューションでは、検索スペースの大部分を繰り返し削除する必要があり、これはクイックソートと同様の分割統治アプローチを指します。 

厄介なケースは、2 つのグループが順序付けされておらず、比較がグループ間でのみ許可されているという事実によって引き起こされます。 不注意な解決策では、ナッツを互いに比較することによってナッツを分類する可能性がありますが、そのような比較は不可能です。 たとえば、2 つのナットと 2 つのボルトの場合、隠れた順序はナット サイズです。`[2, 1]`そしてボルトのサイズ`[1, 2]`、正解はあのナッツです`1`マッチボルト`2`そしてナッツ`2`マッチボルト`1`。 ナットとボルトを個別に並べ替えようとする方法では、必要な比較を実行できません。 

もう 1 つの失敗例は、パーティションが両側で同じピボット情報を使用する必要があることを忘れていることです。 選択したナットがボルト配列の中央にあるボルトと一致すると仮定します。 そのボルトを見つけたら、その正確なボルトとの比較を使用して残りのナットを分割する必要があります。 実装で別のボルトをピボットとして選択すると、2 つのパーティションが同じサイズ範囲を記述できなくなり、有効な一致が失われる可能性があります。 

## アプローチ

 直接的な解決策は、一致するものがすべて見つかるまで、すべてのナットとすべてのボルトを比較することです。 各ナットには一致するボルトが 1 つだけあるため、これは最終的には成功します。 最悪の場合に必要となるのは、`n * n`なぜなら、適合するボルトは常に各ナットについてテストされた最終的なボルトである可能性があるからです。 のために`n = 1000`、これは 100 万件の比較であり、必要な制限をはるかに超えています。 

重要な観察は、比較によって単なる一致の可能性以上のものが得られるということです。 注文情報も提供します。 ナットをボルトと比較し、ナットの方が小さい場合、そのナットはそのボルト以上のボルトと一致することはできません。 それより大きい場合は、逆の制限が適用されます。 

これにより、クイックソート スタイルのパーティションを使用できるようになります。 ピボットとしてナットを 1 つ選択し、それをすべてのボルトと比較します。 これにより、ボルトが小さいボルト、一致する 1 つのボルト、および大きいボルトに分割されます。 適合するボルトが判明しました。 次に、そのボルトを使用して、残りのナットを同じ 2 つのサイズのグループに分割します。 ナットの左側のグループはボルトの左側のグループとのみ一致でき、右側のグループはボルトの右側のグループのみと一致できます。 同じプロセスを再帰的に繰り返すことができます。 

比較の数はクイックソートと同じパターンに従います。 再帰の各レベルは残りのすべての要素を処理し、ピボットがグループを合理的に分割すると、深さは対数になります。 比較限界には、標準のランダム化バージョンに対して十分なマージンがあります。

 ## アルゴリズムのチュートリアル

 1. 現在の範囲から 1 つのナットをピボットとして選択します。 現在のボルト範囲内のすべてのボルトと比較してください。 等価の答えが得られたボルトを保管します。 比較では、他のすべてのボルトもピボット ナットより小さいボルトとピボット ナットより大きいボルトに分けられます。 

他に同じサイズのボルトがないため、ピボット ナットの適合ボルトが固定されました。 

1. 現在のナット範囲内の 1 つおきのナットを、前のステップで見つかった一致するボルトと比較します。 小さいナッツを左側のグループに、大きいナッツを右側のグループに入れます。 

セパレータとしてマッチングボルトを使用することで、ナットのパーティションとボルトのパーティションの一貫性が保たれます。 左側のナット グループは左側のボルト グループにのみ一致し、右側も同じルールに従います。 

1. ピボット ナットとそのボルトの間に見つかったペアを保存します。 
2. 左側のナットとボルトのグループを再帰的に解決し、次に右側のナットとボルトのグループを再帰的に解決します。 空のグループと単一要素グループはすでに解決されています。 
3. すべての再帰呼び出しが終了したら、保存されているボルト インデックスをナット インデックスごとに出力します。 

なぜ効果があるのか:

 不変条件は、すべての再帰呼び出しが、まったく同じサイズのセットを含む 2 つのグループ (1 つはナットで表され、もう 1 つはボルトで表されます) を受け取ることです。 ピボット ナットをすべてのボルトと比較すると、ちょうど 1 つのボルトがそれに一致し、他のすべてのボルトはそのサイズに基づいて分類されます。 ナットを対応するボルトと比較すると、ナット側に同じ分割が生成されます。 考えられるすべての一致が 1 つの再帰サブ問題内に残り、ピボット一致が永続的に記録されるため、すべてのナットが正しいボルトを受け取ります。 

## Python ソリューション```python
import sys
import random

input = sys.stdin.readline

def solve():
    n = int(input())
    ans = [0] * n

    def ask(nut, bolt):
        print("?", nut + 1, bolt + 1, flush=True)
        return input().strip()

    def divide(nuts, bolts):
        if not nuts:
            return

        if len(nuts) == 1:
            ans[nuts[0]] = bolts[0]
            return

        pivot_nut = nuts[random.randrange(len(nuts))]

        smaller_bolts = []
        larger_bolts = []
        pivot_bolt = -1

        for bolt in bolts:
            res = ask(pivot_nut, bolt)
            if res == "<":
                larger_bolts.append(bolt)
            elif res == ">":
                smaller_bolts.append(bolt)
            else:
                pivot_bolt = bolt

        smaller_nuts = []
        larger_nuts = []

        for nut in nuts:
            if nut == pivot_nut:
                continue
            res = ask(nut, pivot_bolt)
            if res == "<":
                smaller_nuts.append(nut)
            else:
                larger_nuts.append(nut)

        ans[pivot_nut] = pivot_bolt

        divide(smaller_nuts, smaller_bolts)
        divide(larger_nuts, larger_bolts)

    divide(list(range(n)), list(range(n)))

    print("!", *[x + 1 for x in ans], flush=True)

if __name__ == "__main__":
    solve()
```再帰関数は、現在未解決のナットとボルトを表す 2 つの並列配列を保持します。 基本ケースでは、空の範囲と、答えがすでに強制されている残りの 1 つのペアを処理します。 

固定ピボットは最小または最大の要素を繰り返し選択し、次の再帰の深さを作成できるため、ピボットの選択はランダム化されます。`n`。 ランダムな選択により、比較限界に必要な予期されたバランスのとれた動作が得られます。 

最初のパーティションでは、ピボット ナットとボルトのみを比較します。 2 番目のパーティションでは、ナットと既に検出されたピボット ボルトのみを比較します。 ピボット ボルトはボルト側からナット側に情報を伝達するブリッジの役割を果たすため、これらの操作の順序は重要です。 

回答配列には、内部でゼロベースのインデックスを使用してボルト インデックスが格納されます。 最終出力では、対話型プロトコルで必要な 1 ベースのインデックスに変換されます。

 ## 特殊なケース

 残った 1 つのペアが最小の再帰状態です。 同サイズのナットが1個の場合`1`そして同じサイズのボルト1本`1`、アルゴリズムは不必要な分割を実行せず、一致する可能性のあるもののみを直接記録します。
