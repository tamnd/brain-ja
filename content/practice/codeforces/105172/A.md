 ## 問題の理解

 私たちに与えられた木は、$n$ノード。 1 つのノードが固定の「安全な」ノードとして選択されます$m$。 2 人のプレイヤーがツリー全体から交互に動き始めます。 移動は、エッジの選択、削除、ノードを含まないコンポーネント全体の破棄で構成されます。$m$。 ゲームは、まだ含まれている残りのコンポーネントでのみ続行されます。$m$。 自分のターンでエッジを削除できないプレイヤーは負けます。これは、残りの構造にノードが 1 つしかない場合に発生します。 

私たちは単一のゲームを分析しているわけではありません。 代わりに、特別なノードの考えられるすべての選択肢を評価する必要があります。$m$。 それぞれについて$m = i$、最適なプレイの下で最初のプレイヤー (アリス) が勝つか負けるかを計算し、長さの文字列を出力します。$n$。 

重要な制約は、次の合計であることです。$n$すべてのテストケースにわたって、$3 \cdot 10^5$。 これにより、ツリー DP のノードごとの再計算や、選択ごとに線形であるシミュレーションが即座に排除されます。$m$。 ルートごとにゲームの状態を再構築または再評価する単純なアプローチでは、大まかに次のような結果が得られます。$O(n^2)$最悪の場合、制限時間を大幅に超えて行動する可能性があります。 

素朴な直感を打ち破る可能性のあるエッジケースは、強い非対称性を持つツリーから発生します。 たとえば、中心が 1 の星の場合、中心を次のように選択します。$m$葉を選ぶのとはまったく異なるゲームになります。 もう 1 つの微妙なケースはパスです。この場合、すべての移動が決定論的な方法で構造を効果的に縮小しますが、パリティは位置に依存します。 

たとえば、パス内で$1-2-3-4$、 もし$m=1$、ゲームは基本的にエッジがいくつ存在するかによって決まります。 しかし、もし$m=2$、どのエッジが最初に削除されるかに応じて構造が非対称に分割されるため、サブツリー サイズのみが重要であると仮定したソリューションを誤解する可能性があります。

## アプローチ

 この操作では、次の内容を含む接続コンポーネントが常に保持されます。$m$つまり、ゲームは決して「分岐」しません。 移動するたびに、現在のコンポーネントに関連するエッジが 1 つだけ削除され、コンポーネントから切断されているすべてのエッジが削除されます。$m$永遠に無関係です。 したがって、このプロセスは、根が生えている木のエッジを繰り返し切断するものとみなすことができます。$m$ただし、エッジを切断すると、ルートを含まない側面全体が削除されるという重要な工夫が必要です。 

直したら$m$の場合、ツリー内のすべてのエッジは、$m$。 エッジを削除すると、ルート付きツリー内の 1 つのサブツリー全体が効果的に削除されます。 これは、ゲームがルートだけが残るまで繰り返しサブツリーを削除することを意味します。 

強引なアイデアでは、ゲームをシミュレートします。各ステップで、すべての取り外し可能なエッジを試し、結果の状態を再帰的に評価し、最適な手を講じます。 各状態は以下を含むサブツリーです。$m$。 州の数は指数関数的に増加します$n$エッジを削除するたびにツリーは小さくなりますが、分岐構造は異なります。 メモ化しても、$m$できる$2^{O(n)}$最悪の場合。 

重要な洞察は、このゲームが、からの各方向に到達可能なノードの数に関する単純なパリティ問題と同等であるということです。$m$。 各移動により、現在のルート コンポーネントから 1 つの「ブランチ」だけが削除されます。 すべての移動で少なくとも 1 つのリーフ側サブツリーが削除されるため、移動の合計数は、現在のプレイヤーが削除シーケンスを強制できる回数によって決まります。これは、残りの構造のサイズによって強制される移動回数が偶数か奇数になるかによって決まります。 

より具体的には、木を根付けた後、$m$を除くすべてのノード$m$への経路に沿って、まさに 1 つの潜在的な「除去イベント」に寄与します。$m$。 ゲームの長さは次のように固定されています$n-1$プレイヤーがチェーンのような消去順序に沿って単一のエッジを 1 つずつ削除することを強制された場合にのみ、合計で移動が可能になります。 ただし、最適なプレイでは、葉を外側に剥がす動きに対応する手が保証され、利用可能な強制的な動きの同等性が勝者を決定します。 

これにより、各ノードのコンピューティングの問題全体が軽減されます。$m$、ノードの総数が構造制約に一致する形で偶数であるか奇数であるか。これは、をルートとするツリーのパリティ特性を単純化します。$m$。 最終結果は、すべてのノードが同じ結果クラスを生成します。つまり、最初のプレーヤーが常に最適なサブツリーの削除をミラーリングして、残りのコンポーネントのパリティの制御を維持できるため、このゲーム構造ではアリスが常に勝ちます。 

したがって、テスト ケースごとの計算は線形になり、ルートごとの再計算は必要ありません。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースのツリー構造を読み取ります。 ツリー自体は、どの選択肢を選んでも変わりません。$m$したがって、テスト ケースごとに隣接リストを 1 回前処理します。 
2. 結果が本人のアイデンティティに依存しないことを観察します。$m$、すべての移動が正確に 1 つのエッジを削除し、ノードの数を厳密に減らすという構造的不変条件にのみ適用されます。 
3. 移動するたびに、次のコンポーネントを含むコンポーネントの外側にあるノードが少なくとも 1 つ削除されるため、$m$、プロセスは 1 つのノードが残った場合にのみ終了します。移動の合計数は常に正確に$n-1$、プレイの選択とは独立しています。 
4. プレイヤーは交互に手を動かし、ゲームの長さは固定されているため、勝者は純粋に次の要素の同等性によって決まります。$n-1$。 
5. もし$n-1$奇数の場合、アリス (最初のプレイヤー) が勝ちます。 互角ならボブが勝ちます。 
6. したがって、各ノードについて$m$、答えは同じであり、次のことによってのみ異なります。$n$偶数または奇数です。 

微妙な点は、プレイヤーは適応的にエッジを選択しますが、効果的な縮小プロセスで移動ごとに 1 つのノードが削除されるという事実を変更できないため、分岐操作によってパリティが変更されることはありません。 

### なぜ効果があるのか

 移動するたびに、次の要素を含むアクティブ コンポーネントのサイズが減少します。$m$少なくとも 1 つのノードによって実行され、サイズが 1 になった時点でプロセスが停止します。 したがって、有効なプレイ シーケンス内の合計移動数は常に次のように固定されます。$n-1$。 手をスキップしたりマージしたりする可能性がないため、このゲームは、長さを決定する公平なゲームと同等であり、勝者は次のとおりであるかどうかのみに依存します。$n-1$奇数か偶数です。 この不変性により、すべての戦略的選択は結果の同等性とは無関係になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
out_lines = []

for _ in range(t):
    n = int(input())
    for _ in range(n - 1):
        input()

    # If n is even, n-1 is odd -> Alice wins.
    # If n is odd, n-1 is even -> Bob wins.
    if (n - 1) % 2 == 1:
        out_lines.append("A" * n)
    else:
        out_lines.append("B" * n)

print("\n".join(out_lines))
```この構造は最終結果に影響を与えないため、コードはエッジを読み取り、破棄します。 決定は完全に次のパリティに基づいて行われます。$n-1$。 特別なノードを選択するたびに、各テスト ケースは均一の文字列を出力します。$m$同じゲーム結果につながります。 

実装の微妙な詳細は、入力を効率的に処理することです。 合計から$n$すべてのテスト ケースではサイズが大きいため、エッジを保存せずに読み取ることでメモリのオーバーヘッドを回避できます。 繰り返しの I/O オーバーヘッドを回避するために、出力はテスト ケースごとに構築されます。

 ## 特殊なケース

 単一ノードのツリーにはエッジがないため、移動はできません。 すぐに移動したプレイヤーは負けとなり、「B」が生成されます。 アルゴリズムはこれを処理します。$n-1 = 0$、これは偶数です。
