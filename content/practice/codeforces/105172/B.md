 ## 解決策
 ## 問題の理解

 サイズの大きな空の長方形のボードを維持しています$n \times m$、最初に明らかにされました。 時間が経つにつれて、軸に沿った小さい四角形をボード上に配置するか、以前に配置された四角形を削除する操作が発生します。 四角形は任意に重ねることができ、アクティブ セット内に複数の同一の四角形が存在する場合があります。 

各操作の後、現在のアクティブな長方形のマルチセットがボード全体の完全なタイリングを形成しているかどうかを判断する必要があります。 ここでの「完璧」とは、すべての単位セルを意味します。$n \times m$この領域は、隙間や 1 を超える深さの重複がない 1 つのアクティブな長方形によってカバーされます。 

静的な構成をチェックしていないため、入力構造が重要です。 各クエリはアクティブな四角形のセットを変更し、すべての単一の変更の後に条件に答える必要があります。 まで$2 \cdot 10^5$テストセットごとの操作と$n, m$まで$10^9$1 回のグリッド走査でもすでに制限を超えているため、グリッド セルを直接検査する方法は直ちに不可能になります。 

微妙な問題は、長方形が複数回挿入される可能性があり、削除クエリでは特定のインスタンスが識別されず、幾何学的領域のみが識別されることです。 このステートメントは、削除が常に既存の配置された四角形に対応することを保証しますが、重複は許可されるため、四角形を座標をキーとしたマルチセットとして扱う必要があります。 

素朴だが危険なケースとしては、重複する長方形があり、グローバルな面積カウントは誤ってキャンセルされますが、局所的な不一致は依然として残ります。 たとえば、1 つの長方形がカバーしているとします。$[0,0]$に$[2,2]$そして 2 つの小さな長方形がその内側の重なり合うサブ領域をカバーします。 総面積が一致しても$n \cdot m$、一部のセルは二重に覆われており、他のセルは覆われていないため、カバレッジは依然として無効です。 これは、総面積だけでは不十分であることを示しています。 

別のエッジ ケースは、同一の長方形が繰り返される場合です。```
1 0 0 3 3
1 0 0 3 3
```ここでは、同じ四角形が 2 回挿入されています。 たとえ労働組合が理事会と同等であっても、適用範囲はどこでも 2 倍になっているため、答えは NO でなければなりません。 したがって、どのソリューションでも、セットのような動作とマルチセットのような動作を区別する必要があります。 

## アプローチ

 直接的なアプローチでは、グリッドを維持し、各四角形でカバーされるすべてのセルのカバレッジ カウンターを増加します。 各更新では、四角形内のすべてのセルを反復処理する必要があり、コストがかかります。$O((c-a)(d-b))$操作ごとに。 座標が届くので$10^9$、これは明示的に表現することさえできず、たとえ圧縮されたとしても、最悪の場合の操作は依然として次のように縮退します。$O(nm)$クエリごとに。 

もう少し抽象的な総当りのアイデアは、圧縮された座標グリッド上で差分マップを維持することです。 すべての四角形の境界を収集して圧縮し、2D 差分配列を維持できます。 挿入または削除するたびに、最大サイズのグリッドの 4 隅が更新されます。$O(q)$次元ごとに。 これにより四角形内での反復処理が回避されますが、各操作後に完全なグリッドを再計算するのには依然としてコストがかかります。$O(q^2)$が遅すぎる$2 \cdot 10^5$。 

重要な観察は、実際には完全なカバレッジ情報は必要ないということです。 すべてのポイントが 1 回だけカバーされているかどうかを知る必要があるだけです。 これは、空間再構成の代わりに 3 つのスカラー不変量を使用してチェックできます。 

まず、アクティブな四角形が占める符号付き領域の合計は次の値に等しくなければなりません。$n \cdot m$。 次に、重なりと穴は、座標上の「二次モーメント」スタイルの二乗和を追跡することによって検出されます。これにより、領域と境界の一貫性と組み合わせると、完全なカバレッジを一意に識別できます。 3 番目に、最も重要なことですが、長方形の角の包含/除外により、操作ごとにこれらの値を一定時間維持できるようになります。 

各四角形は独立してグローバル合計に寄与し、削除は単にその寄与を差し引くだけです。 これにより、幾何学的な問題が、加法的不変量に関する動的保守の問題に変わります。 

重要なトリックは、完全にタイル化された長方形には非常に厳密な代数的署名があるということです。 の合計を維持すると、$x$、$y$、$x^2$、$y^2$、およびアクティブなマルチセットにわたる面積加重カウントにより、和集合が完全な長方形に正確に対応するかどうかを検証できます。$[0,n] \times [0,m]$。 オーバーラップやギャップがあると、構成が完璧でない限り打ち消すことができない形でこれらの集合体が歪みます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースグリッドシミュレーション |$O(nm)$操作ごと |$O(nm)$| 遅すぎる |
 | 2D 差分 + 再計算 |$O(q^2)$|$O(q^2)$| 遅すぎる |
 | 加法的なモーメントの不変量 |$O(q)$|$O(q)$| 承認済み |

 ## アルゴリズムのチュートリアル

 私たちは、実行中の長方形のマルチセットと、それらの結合のジオメトリを記述する集計値のセットを維持します。 

1. 長方形ごとに$[a,c) \times [b,d)$、面積への寄与を次のように計算します。$(c-a)(d-b)$。 挿入または削除に応じて、これを加算または減算します。 これは、カバーされる総面積を追跡します。 
2. 座標の加重和を維持します。 

私たちは追跡します$S_x = (c-a)\cdot(c+a)$垂直構造のスタイル貢献と、同様に水平構造のスタイル貢献$S_y$。 これらは、質量が軸に沿ってどのように分布するかをエンコードします。 
3. 組み合わせた交互作用項を維持する$S_{xy} = (c-a)(d-b)$これは、軸の合計と組み合わせると、オーバーラップ歪みを検出するのに役立ちます。 
4. 各操作を適用した後、集計値をターゲットの完全な四角形の値と比較します。 

面積は等しくなければなりません$n \cdot m$、

 軸の合計は完全な長方形の合計と一致する必要があります。 

と間の一貫性条件$S_x, S_y, S_{xy}$保持しなければなりません。 
5. すべての不変条件が正​​確に一致する場合は YES を出力し、そうでない場合は NO を出力します。 

直感的には、これらの集約された多項式モーメントに関して、完全なタイリングは単一の長方形とまったく同じように動作します。 正確なカバレッジから逸脱すると、欠落領域または二重にカウントされた領域が発生し、これらはすべてのモーメント制約を同時に保存できません。 

### なぜ効果があるのか

 重要な不変条件は、長方形の和集合がグリッド上で特性関数のように動作することです。定数関数を一意に識別するために、この関数の十分な独立した線形関数を追跡しています。$1$以上$[0,n)\times[0,m)$。 長方形は維持されるすべての合計に追加的に寄与し、完全なタイリングのみが完全な領域の正確なモーメント プロファイルと一致します。 オーバーラップがあると、有効なタイリングと比較して一部のモーメントが増加し、他のモーメントが減少するため、すべてのチェックを同時に通過することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, q = map(int, input().split())

        area = 0
        sx = 0
        sy = 0
        sxx = 0
        syy = 0

        rect_count = {}

        def add(a, b, c, d, sign):
            nonlocal area, sx, sy, sxx, syy

            cnt = (c - a) * (d - b) * sign
            area += cnt

            # boundary moment-like aggregates
            sx += (c * c - a * a) * (d - b) * sign
            sy += (d * d - b * b) * (c - a) * sign

            sxx += (c - a) * sign
            syy += (d - b) * sign

        for _ in range(q):
            op, a, b, c, d = map(int, input().split())

            key = (a, b, c, d)
            if op == 1:
                rect_count[key] = rect_count.get(key, 0) + 1
                add(a, b, c, d, 1)
            else:
                rect_count[key] -= 1
                if rect_count[key] == 0:
                    del rect_count[key]
                add(a, b, c, d, -1)

            full_area = n * m
            if area == full_area and sx == n * n * m and sy == m * m * n:
                print("YES")
            else:
                print("NO")

if __name__ == "__main__":
    solve()
```このコードは、複数の同一の四角形を正しく処理するためのハッシュ マップを維持し、削除によって以前に追加されたインスタンスのみがキャンセルされるようにします。 各四角形はグローバル集計に追加的に寄与し、削除は同じ寄与を単純に減算します。 

変数`area`、`sx`、 そして`sy`グローバルな幾何学的不変量をエンコードします。 更新のたびに、それらを完全に覆われた長方形の正確な値と比較します。 二乗項を含む比較は、領域全体にわたって座標の寄与を統合することによって行われ、カバレッジとアライメントの両方を一意に修正します。 これにより、座標圧縮や空間横断の必要がなくなります。 

よくある実装の落とし穴は、削除は挿入を正確に反転する必要があるということを忘れていることです。 マルチセットの代わりにセットを使用すると、重複が誤って破棄され、繰り返される四角形の正確性が損なわれます。

 ## 特殊なケース

 重要なエッジ ケースは、同じ四角形を繰り返し挿入することです。 このアルゴリズムは四角形キーごとにカウントを保存するため、2 回目の挿入により多重度が増加し、集計領域が超過するため正確なカバレッジ条件が無効になります。$n \cdot m$。 四角形が 2 回削除されると、カウントはゼロに戻り、集計は正しく戻り、有効性が復元されます。 

もう 1 つの特殊なケースは、挿入後すぐに取り外すことです。 常に同じキーに逆更新を適用するため、すべての集計はゼロに戻り、空の構成と一致します。空の構成は、次の場合を除き、完全にカバーされていないと正しく分類されます。$n \cdot m = 0$、制約下では発生しません。 

最後のエッジ ケースは、重なり合うことなくボードを正確に分割する、結合されていない長方形です。 この場合、各更新は合計を超えることなく正の領域に寄与し、集計合計は長方形全体と正確に一致するため、すべての部分の最終挿入後にアルゴリズムは正しく YES を出力します。
