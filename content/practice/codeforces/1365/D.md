 ## 解決策

 ## 問題の理解

 迷路は小さな格子で、各セルが壁、空きスペース、善人または悪人のいずれかになります。 すべての移動は 4 方向であり、壁によってブロックされます。 唯一の出口は右下のセルです。課題は、すべての善良な人が出口に到達できるようにしながら、すべての悪人が出口に到達できないように、空のセルに追加の壁を配置できるかどうかを決定することです。 

壁の配置を明示的に構築するように求められるのではなく、そのような構成が存在するかどうかを判断するだけです。 これにより、問題は最適化から制約条件下での到達可能性に移ります。つまり、いくつかの頂点 (空のセル) を削除してグラフを効果的に再形成しようとしています。これにより、悪い人から出口までの経路はすべて遮断されますが、善良な人から出口までの経路は一切遮断されません。 

制約は小さく、最大でも 50 x 50 のグリッドと 100 のテスト ケースです。 これは、テスト ケースごとに線形または線形に近いグラフの走査で十分であることを直ちに示唆しています。 グリッド上の完全な BFS または DFS であっても、ノード数はわずか 2500 なので、O(nm) または O(nm log nm) のソリューションでも十分に高速です。 

いくつかの微妙な特殊なケースが重要です。 まず、悪意のある人物がすでに出口の隣にいる可能性があり、出口を安全に壁で囲えない場合は彼らを阻止することができません。 第二に、善良な人はすでに初期グリッドの出口から孤立している可能性があり、壁は接続性を低下させるだけであるため、これは直ちに失敗を暗示します。 3 番目に、出口自体をブロックすることが許可されていますが、これは重要です。場合によっては、到達可能性の低下を防ぐ唯一の有効な方法は、出口を完全に封鎖することですが、それは善良な人がそれを必要としない場合に限ります。 

単純な間違いは、グローバル接続を確認せずに「悪意のある人々の周囲を貪欲にブロック」しようとすることです。 これは失敗します。なぜなら、代替のグローバルな配置が存在する場合でも、不良セルの近くでローカルにブロックすると、正常なセルの出口への唯一のパスが誤って切断される可能性があるからです。 

## アプローチ

 強引な解釈では、空のセルのすべてのサブセットを考慮し、それらを壁として扱い、すべての善良な人々は出口に到達できるが、すべての悪い人々は出口に到達できないかどうかをテストすることになります。 各グリッドには最大 2500 個のセルがあるため、サブセットの数は 2^2500 となり、これは不可能です。 

すべてのブロック構成を列挙することなく、到達可能性を推論する方法が必要です。 重要な観察点は、壁はエッジを削除するだけであり、エッジを追加することは決してないということです。 したがって、壁を最適に配置した後でも悪い人が元のグリッドの出口に到達できる場合、そのパスは、善良なパスを損なうことなく同時にブロックできないセルで完全に構成されている必要があります。 

これは構造的なアイデアにつながります。つまり、どのセルをブロックするかを考える代わりに、出口のすべての不良隣接セルを強制的に分離し、結果として得られる制約付きグラフで到達可能性の制約を検証することを考えます。 

古典的な洞察は、すべての不良セルを囲むことによって悪影響を「封じる」というものです。不良セルが出口に隣接している場合、または避けられないパスを通じて強制的に隣接する可能性がある場合、その構成は拒否される必要があります。 その後、すべての不良セルをブロックされたソースとして扱い、不良セルがまだ正常なセルまたは出口に到達できるかどうかを確認することで、壁の影響をシミュレートします。 

標準的な建設的な解決策は次のとおりです。 

まず、不良セルの隣接セルをすべてブロックします (不良セルが不良なエスケープ ルートを許可する場合は、良好なパスからも到達できてはならないため)。 次に、出口から BFS を実行し、到達可能なものを確認します。 不良セルが到達可能な場合、その設定は無効です。 正常なセルに到達できない場合も、そのセルは無効になります。

これが機能する理由は、すべての不良セルが出口から切り離された領域に囲まれるように強制すると同時に、正常なセルにもパスが存在する場合はそのパスが存在することを保証しているためです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 壁サブセットに対するブルート フォース | O(2^(nm) · nm) | O(nm) | 遅すぎる |
 | BFS ベースの制約シミュレーション | テスト ケースあたり O(nm) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グリッドをスキャンし、すべての不良セル、良好なセル、および (n-1, m-1) の出口セルを特定します。 最初に出口が壁だった場合でも、後でブロックされているとみなすことができるため、横断の目的では出口を空として扱います。 
2. すべての不良セルについて、その 4 つの隣接セルを検査します。 隣接セルが良好なセルである場合、その答えは即座に不可能になります。良好なセルには壁を置くことはできず、隣接関係には制約を破らなければ解決できない強制的な相互作用がすでに含まれているからです。 
3. 不良セルごとに、隣接する空のセルを壁に変換します。 これは強制的な防御策です。空きスペースの隣に不良セルを放置すると、後で安全にブロックすることができない避けられないアクセス ルートが作成される可能性があります。 
4. 出口セルから開始して BFS を実行しますが、壁ではないセルのみを横断します。 
5. BFS 中に、不正なセルに到達すると、不正な人物が逃げ出す可能性があることを意味するため、設定は無効になります。 
6. BFS が完了したら、すべての正常なセルが訪問されたことを確認します。 正常なセルに到達できない場合は、誤って正常な人物をトラップしたことを意味するため、構成は無効です。 
7. 両方の条件が成立する場合は「Yes」を出力し、そうでない場合は「No」を出力します。 

これが機能する理由は分離の不変条件に基づいています。不良セルの周囲に壁を設けた後、不良セルから出口までの残りのパスはブロックされていないセルのみを通過する必要があり、BFS がそれを検出します。 BFS が不良セルに到達できない場合は、強制ブロック ルールと一致する有効な壁の配置の下にパスは存在しません。 同時に、正常なセルをブロックすることは決してないので、最終的な制約されたグリッド内で到達可能な正常なセルは有効なエスケープ パスに対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        grid = [list(input().strip()) for _ in range(n)]

        dirs = [(1,0), (-1,0), (0,1), (0,-1)]

        # Step 1: block around bad cells
        for i in range(n):
            for j in range(m):
                if grid[i][j] == 'B':
                    for di, dj in dirs:
                        ni, nj = i + di, j + dj
                        if 0 <= ni < n and 0 <= nj < m:
                            if grid[ni][nj] == 'G':
                                print("No")
                                break
                            if grid[ni][nj] == '.':
                                grid[ni][nj] = '#'
                    else:
                        continue
                    break
            else:
                continue
            break
        else:
            # Step 2: BFS from exit
            if grid[n-1][m-1] == '#':
                # exit can be blocked, but BFS starts only if open or blocked
                pass

            from collections import deque
            q = deque()
            vis = [[False]*m for _ in range(n)]

            if grid[n-1][m-1] != '#':
                q.append((n-1, m-1))
                vis[n-1][m-1] = True

            ok = True

            while q:
                x, y = q.popleft()
                if grid[x][y] == 'B':
                    ok = False
                    break
                for dx, dy in dirs:
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < n and 0 <= ny < m:
                        if not vis[nx][ny] and grid[nx][ny] != '#':
                            vis[nx][ny] = True
                            q.append((nx, ny))

            if ok:
                for i in range(n):
                    for j in range(m):
                        if grid[i][j] == 'G' and not vis[i][j]:
                            ok = False
                            break
                    if not ok:
                        break

            print("Yes" if ok else "No")

def main():
    solve()

if __name__ == "__main__":
    main()
```最初のフェーズではグリッドを変更して、不良セルの周囲に即時安全性を確保します。 不良セルの空の隣接セルは導管として機能する可能性があるため、これは非常に重要です。そのため、これらのオプションを事前に削除します。 

次に、BFS フェーズはグリッドを固定グラフとして扱い、出口からの到達可能性をチェックします。 訪問配列により、壁以外の有効なパスのみを通過することが保証されます。 不良セルへの到達を明示的にチェックすることで、不良セルが依然として回避できるケースを確実に拒否します。 

最後に、すべての正常なセルが到達可能な領域に含まれていることを確認し、強制的なブロックによって正常な人物が誤って出口から孤立しないようにします。 

不良セルと良好なセルの間の無効な隣接関係を検出した後、ネストされたループが中断される場合は注意が必要です。 そこで正常に終了できないと、すでに無効なテスト ケースで計算が続行されることになります。

## 特殊なケース

 主なエッジケースは、不良セルが出口に隣接している場合です。 この状況では、BFS は出口から開始し、ブロックされていない場合は不良セルへの長さ 1 のパスを直ちに検出します。 前処理ステップにより、隣接するセルをブロックするか、正常なセルが競合する形で隣接している場合に構成を拒否することが保証されます。 

もう 1 つのエッジ ケースは、出口自体をブロックする必要がある場合です。 この問題により宛先がブロックされる可能性があるため、BFS が空のキューで開始される可能性があります。 この場合、到達可能な良好なセルがないこと、および代替のエスケープ パスを持つ不良セルがないことを確認するだけで済みます。 空の BFS は誰も逃げられないことを意味するため、アルゴリズムはこれを自然に処理します。その後、すべての正常なセルも到達不能であることを検証します。これは、安全でない位置に正常なセルがない場合にのみ正しいことになります。
