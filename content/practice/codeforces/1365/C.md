 ## 解決策

 ## 問題の理解

 1 から n までの同じ数値セットの 2 つの順列が与えられています。 それらは、同じラベルの付いたタイルを 2 つの異なる円形に配置したものであると考えてください。 各円を独立して何度でも回転させることができ、回転後、固定位置に配置します。 両方の配列のその位置に同じ値が出現する場合、その位置は答えに寄与します。 

本当の質問は、2 つの巡回シフトを選択した後、a[i] == b[i] を満たすインデックス i をいくつ作成できるでしょうか?

 両方の配列にはまったく同じ値が含まれているため、すべての値 x は a の固定位置と b の固定位置を持ちます。 配列を回転すると、これらすべての位置が均一に移動するだけなので、各順列内の相対的な順序は変化せず、グローバル オフセットのみが変化します。 

n が 2 × 10^5 までの制約により、すべてのシフトにわたる二次比較は不可能になります。 一方の配列の n シフトをすべて試し、もう一方の配列の n シフトを試すと、すでに O(n^2) が得られますが、これは遅すぎます。 O(n log n) または O(n sqrt n) のアプローチでも許容されますが、位置に基づく線形または線形に近い変換を期待する必要があります。 

置換が回転まで同一である場合、微妙なエッジ ケースが発生します。この場合、すべての位置を揃えて n 個の一致を取得できます。 逆に、すべてのアライメントで 1 つの一致のみが得られる場合もあります。次に例を示します。 

a = [1,2,3,4]、b = [2,3,1,4]。 循環構造が矛盾するため、回転によって 2 つ以上の位置を同時に整列させることはできません。 

もう 1 つの隠れた詳細は、両方の配列を回転することは、一方の配列を固定し、もう一方の配列を反対方向に回転することと同じであることです。 この対称性は問題を 2 つの自由度から 1 つに減らすため、不可欠です。 

## アプローチ

 強引なアイデアは簡単です。 a の回転を固定し、次に b のすべての回転を試し、一致するインデックスの数を計算し、最大値を取得します。 各比較には O(n) のコストがかかり、O(n^2) 個の回転ペアがあるため、単純に実行した場合は O(n^3) 時間、比較を慎重に事前計算した場合は O(n^2) 時間かかります。 いずれにしても、n = 2 × 10^5 には大きすぎます。 

重要な観察は、位置ではなく値が位置合わせを決定するということです。 各値 x は、a の pos_a[x] と b の pos_b[x] のいずれかの位置に現れます。 b の x の位置が a の x の位置に来るように b を回転すると、x は 1 つの一致に寄与します。 固定ローテーションの場合、一致の数は、必要なシフトが一致する値の数と正確に一致します。 

したがって、すべての値によって、a と b の間に「必要な回転オフセット」が生じます。 このオフセットを x ごとに計算すると、最も頻繁に使用されるオフセットが最適な位置合わせになります。 これにより、問題は n 個の計算された差分にわたる頻度をカウントすることになります。 

これにより、問題は、すべての位置合わせを試行することから、必要な回転量に基づいて値をグループ化することに変わります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) または O(n^2) | O(1)-O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最初の順列における各値の位置を計算します。 すべての値 x について、それが発生する a の場所に保存します。 
2. 2 番目の順列内の各値の位置を同様に計算します。 これにより、各値がどこに到達する必要があるかを迅速に検索できるようになります。 
3. 各値 x について、b[x] を a[x] と位置合わせするために必要な回転シフトを計算します。 pos_a[x] が i で、pos_b[x] が j の場合、b を (i - j) 法 n だけシフトすると、x が正しく位置合わせされます。 これにより、問題はどのシフト値が最も一般的かを特定することに変換されます。 
4. 各シフトを生成する値の数を数えます。 n を法とするシフト値によってインデックス付けされた周波数配列またはハッシュマップを維持します。 
5. 答えは、すべてのシフトの最大頻度です。

これが機能する理由は、シフトごとに配列間のグローバルな位置合わせが定義されるためです。 値がシフトに寄与するのは、そのシフトが b の位置を a の位置に直接マッピングする場合のみです。 したがって、有効なローテーションはいずれもこれらのシフト バケットの 1 つに対応し、そのローテーションに基づくすべての一致は、そのバケットに含まれる値とまったく同じになります。 

不変条件は、選択された回転について、一致する値は、a と b の間の相対変位がその回転に等しい値であるということです。 すべての値が独立して 1 つの変位に寄与するため、すべての値の頻度をカウントすることで、考えられるすべての配置が網羅的に取得されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

pos_a = [0] * (n + 1)
pos_b = [0] * (n + 1)

for i, x in enumerate(a):
    pos_a[x] = i

for i, x in enumerate(b):
    pos_b[x] = i

freq = [0] * n

for x in range(1, n + 1):
    shift = (pos_a[x] - pos_b[x]) % n
    freq[shift] += 1

print(max(freq))
```最初の部分では、値からインデックスへの逆マッピングを構築します。これにより、配列の繰り返しスキャンが回避されます。 コア ループは、各値に必要な回転を計算します。 モジュロ演算により、負のシフトが範囲 [0, n-1] に正しくラップされることが保証されます。 

正確に n 個の可能な個別の回転があるため、周波数配列のサイズは n です。 最終的な最大値は、最適な位置合わせに直接対応します。 

よくある間違いは、シフト方向を逆にしてしまうことです。 どちらの規則も、一貫性が維持されている限り機能します。 もう 1 つは、等価な回転を負のバケットと正のバケットに分割するモジュロ正規化を忘れていることです。 

## 実用的な例

 ### 例 1

 a = [1,2,3,4,5]、b = [2,3,4,5,1]

 | × | pos_a[x] | pos_b[x] | シフト |
 | --- | --- | --- | --- |
 | 1 | 0 | 4 | 1 |
 | 2 | 1 | 0 | 1 |
 | 3 | 2 | 1 | 1 |
 | 4 | 3 | 2 | 1 |
 | 5 | 4 | 3 | 1 |

 すべての値はシフト 1 を生成するため、frequency[1] = 5 となり、答えは 5 になります。 

これは、1 回の回転で両方の順列が完全に揃うケースを裏付けています。 

### 例 2

 a = [1,3,2,4]、b = [2,3,1,4]

 | × | pos_a[x] | pos_b[x] | シフト |
 | --- | --- | --- | --- |
 | 1 | 0 | 2 | 2 |
 | 2 | 2 | 0 | 2 |
 | 3 | 1 | 1 | 0 |
 | 4 | 3 | 3 | 0 |

 0 と 2 の 2 つのシフトが得られ、それぞれの周波数は 2 です。答えは 2 です。 

これは、最適な回転が複数存在する可能性があり、アルゴリズムがそれらの中から最適なものを正確に特定することを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | 各値は、そのシフト | を計算するために 1 回処理されます。 
| スペース | O(n) | 配列はシフトの位置と頻度を格納します。

def run(inp: str) -> str:

 ## 特殊なケース

 n = 1 の場合、両方の置換には 1 つの要素のみが含まれます。 唯一のシフトは 0 で、周波数配列は 1 つのバケットに折りたたまれるため、答えは自明のことながら 1 になります。 

配列が同一の場合、すべての値にシフト 0 が含まれます。シフト 0 の頻度は n になり、アルゴリズムは特別なケースを必要とせずに完全な位置合わせを返します。 

順列が互いに完全に回転している場合、すべての値が同じシフト値を生成します。 頻度表は完全に 1 つのバケットに集中しており、この方法が回転を明示的にシミュレートすることなく、グローバルな周期的等価性を正しく取得していることを示しています。 

小さなサブセットを除くほとんどの要素を 1 回の回転で整列させない場合、度数テーブルは自然に値をさまざまなシフトに分散させ、最大値は依然として達成可能な最良の整列に対応します。
