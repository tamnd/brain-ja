 ## 解決策
 ## 問題の理解

 一連の数字が与えられています`a_i`それぞれにタイプのタグが付けられている`b_i`それは 0 または 1 です。このタスクは、異なるタイプの要素を交換するだけでシーケンスを非降順でソートできるかどうかを判断することです。 言い換えれば、ポジション間の交換が許可されます`i`そして`j`場合のみ`b_i != b_j`。 入力は複数のテスト ケースで構成され、それぞれが配列の長さ、値の配列、および型の配列を持ちます。 これらの制約の下で並べ替えが可能な場合、出力は「はい」、それ以外の場合は「いいえ」になります。 

制約を考慮すると、`n`最大 500 個、最大 100 個のテスト ケースを含めることができます。 各シーケンスを直接ソートするのは高速ですが、考えられるすべてのスワップをシミュレートすると、潜在的なスワップの数が組み合わせ的に増加するため、非常に遅くなります。 実際にすべてのスワップを実行せずに並べ替えが可能かどうかを判断するには、より分析的なアプローチが必要です。 

すべての要素が同じタイプである場合、微妙なエッジ ケースが発生します。 このシナリオでは、スワップは許可されないため、配列はすでに非降順になっている場合にのみソート可能であると見なされます。 たとえば、次の場合`a = [3, 1, 2]`そして`b = [0, 0, 0]`の場合、スワップは発生しないため、正しい出力は「No」です。 不注意なアプローチを行うと、型制約が無視され、配列を内部でソートした後に誤って「はい」と答えてしまう可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、配列がソートされるかすべての可能性がなくなるまで、有効なスワップのすべてのシーケンスが試行されます。 これは原理的には正しいです。ルールで許可されているスワップのシーケンスは、最終的には配列を並べ替えることができるからです。 ただし、スワップの数は指数関数的に増加します。`n`、この方法は、`n = 20`。 最悪のシナリオでは、スワップの階乗の組み合わせをチェックする必要があり、許容される計算時間を大幅に超える可能性があります。 

重要な洞察は、並べ替えを妨げる唯一の要因は型の多様性の欠如であることに気づくことです。 タイプ 0 の要素が少なくとも 1 つとタイプ 1 の要素が 1 つある場合、中間スワップを繰り返し使用することで要素のペアを効果的に交換でき、完全な並べ替えが可能になります。 配列に両方のタイプが含まれている場合、答えは自明に「はい」になります。 すべての要素が同じ型である場合、配列がすでにソートされている場合にのみ、答えは「はい」になります。 

この観察により、問題は単純なチェックに集約されます。つまり、配列がすでにソートされているか、配列に両方の型が含まれているかのいずれかです。 実際の交換シミュレーションは必要ありません。

 | 最適 | テスト ケースあたり O(n) | O(1) おまけ | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`、配列`a`、および型配列`b`。 
2. 配列が正しいかどうかを確認します`a`はすでに降順でない順にソートされています。 そうであれば、「Yes」と出力して次のテスト ケースに進みます。 この場合、並べ替えは簡単に可能です。 
3. 配列がソートされていない場合は、配列内にタイプ 0 とタイプ 1 の両方が存在するかどうかを確認します。`b`。 両方のタイプが存在する場合は、「Yes」を出力します。`a`異なるタイプ間のスワップを使用して実現できます。 
4. タイプが 1 つだけ存在し、配列がまだソートされていない場合は、「No」を出力します。 スワップが許可されていないため、並べ替えは不可能です。 
5. すべてのテスト ケースに対して繰り返します。 

機能する理由: 不変条件は、両方のタイプを持つことにより、許可されたスワップのシーケンスを通じて、任意の要素を他の要素と間接的にスワップできるということです。 これにより、ソートされていない配列をソートされた順序に変換できることが保証されます。 型が 1 つだけ存在する場合、スワップは許可されないため、配列のソート順が唯一の基準となります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        if a == sorted(a):
            print("Yes")
            continue
        
        has_zero = 0 in b
        has_one = 1 in b
        
        if has_zero and has_one:
            print("Yes")
        else:
            print("No")

if __name__ == "__main__":
    solve()
```このソリューションでは、些細なケースを迅速に処理するために、配列がすでにソートされているかどうかを最初にチェックします。 次に、型配列をスキャンして、両方の型が存在するかどうかを確認します。 小切手`0 in b`そして`1 in b`重要なのは両方のタイプの数ではなく、両方のタイプの存在だけであるため、単純かつ十分です。

 ## 特殊なケース

 すべての要素が同じタイプの場合、スワップは発生しません。 例えば、`a = [3, 1, 2]`そして`b = [0, 0, 0]`。 配列はソートされていません。`0 in b`それは本当です、`1 in b`は False であるため、アルゴリズムは「No」を出力します。 配列がすでにソートされている場合、次のようになります。`a = [1, 2, 2]`と`b = [1, 1, 1]`をクリックすると、「はい」と表示されます。 両方のタイプが存在する場合、次のように`a = [4, 3, 2]`そして`b = [0, 1, 0]`の場合、スワップにより並べ替えが可能になるため、アルゴリズムは「はい」を出力します。 これらのケースでは、すべての微妙な入力構成が正しいことが確認されます。
