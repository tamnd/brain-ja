 ## 解決策
 ## 問題の理解

 私たちは、_n_ 人のエイリアンのグループが 3 つのセクションからなる宇宙船の 3 番目のセクションから最初のセクションに移動するのに必要な最小時間を計算するように求められました。 セクションは直線的にリンクされています。セクション 1 はセクション 2 に接続し、セクション 2 は 1 と 3 の両方に接続し、セクション 3 は 2 にのみ接続します。一度に移動できるエイリアンは 1 人だけであり、エイリアンは、現在ソース セクションと宛先セクションにいるすべてのエイリアンと比較してランクが上位である場合にのみ、隣接するセクション間を移動できます。 各移動にはちょうど 1 分かかります。目標は、すべてのエイリアンがセクション 1 に到達するまでの合計時間を _m_ を法として求めることです。 

入力には 2 つの数値 _n_ と _m_ が含まれており、どちらも最大 10^9 です。 _n_ は非常に大きくなる可能性があるため、すべての動きを個別にシミュレートするソリューションは非常に遅くなります。 各エイリアンを反復せずに合計時間を数学的に計算する方法が必要です。 

注意が必要なエッジケースには、エイリアンが 1 人だけの場合が含まれます。 この場合、エイリアンは 2 分かけてセクション 3 からセクション 2、次にセクション 2 からセクション 1 に移動します。 もう 1 つのエッジ ケースは、_n_ が非常に大きく、単純な反復では妥当な計算時間を超える場合です。 モジュロ演算には別の微妙な点があります。整数のオーバーフローを避けるために、適切な位置でモジュロ演算を適用するように注意する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、ルールに従って移動するすべてのエイリアンをシミュレートしようとします。 各エイリアンについて、移動前に移動元セクションと移動先セクションのすべてのエイリアンのランクをチェックし、他のエイリアンよりも上位の場合にのみエイリアンを移動します。 それぞれの動きを数えると、最終的に合計時間が得られます。 この方法は論理的には正しいですが、移動ごとに関連するセクションの現在の占有者と照合する必要があるため、最悪の場合は O(n^2) の操作が必要になります。 n が 10^9 までの場合、これは実行不可能です。 

解決を加速するための重要な洞察は、問題が既知の組み合わせシーケンスと同等であることを認識することです。 年功序列に従ってエイリアンに 1 から n まで番号を付けると、すべてのエイリアンがセクション 3 から 1 に移動するのにかかる時間は再帰的なパターンに従います。 させて`T(n)`_n_ 人のエイリアンにとっての最小時間になります。 最後に移動するエイリアンは、自由に移動できる最上級のエイリアンです。 その前に、上級エイリアンの通過を許可するには、他の n-1 人のエイリアン全員がセクション 2 に到達する必要があります。 再帰を使用すると、次のことを導き出すことができます。`T(n) = 2*T(n-1) + 2`、これは閉じた式に単純化されます。`T(n) = 2^(n+1) - 2`。 この公式がわかれば、べき乗剰余を使用して結果を計算し、大きな _n_ を効率的に処理できます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(log n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 再発関係を特定します。 定義する`T(n)`n 人のエイリアンに必要な最小限の動きとして。 構造を観察すると、最後に移動するエイリアン (最年長) は、他の n-1 人のエイリアンがすべてセクション 2 に来た後にのみ移動できます。n-1 人のエイリアンをセクション 2 に再配置する動きは、再帰的に同じパターンに従います。 
2. 繰り返しを確立します。`T(n) = 2*T(n-1) + 2`。 の`+2`は、セクション 3 から 2 へ、そして 2 から 1 への最上級エイリアンの移動を説明します。因数 2 は、n-1 エイリアンが脇に移動し、上級エイリアンが通過した後にセクション 2 に戻る必要があるため発生します。これは古典的な「ハノイの塔」問題を反映しています。 
3. 再発を解決します。 再帰的に展開すると、閉じた式が次のようになります。`T(n) = 2^(n+1) - 2`。 これにより、シミュレーションなしで最小限の移動が直接得られます。 
4. コンピューティング`T(n) mod m`。 n が大きい場合は、累乗剰余を使用して計算します`2^(n+1) % m`O(log n) 時間で効率的に実行できます。 
5. 結果を返します。 以来`T(n) = 2^(n+1) - 2`、計算します`(pow(2, n+1, m) - 2) % m`モジュロを処理し、否定的な結果を防ぐため。 

それが機能する理由: 重要な不変条件は、どの段階でも、まだ移動していない最上位のエイリアンの通過を許可しなければならないということです。これにより、すべての小さなエイリアンは一時的に移動する必要があります。 これにより、再帰式での 2 倍の動作が強制されます。 閉じた数式は各動きを正確にカウントし、モジュラー演算により大きな数値の正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

# calculate 2^(n+1) % m
result = pow(2, n + 1, m) - 2
# ensure non-negative result modulo m
print(result % m)
```このソリューションは、n と m を読み取り、計算します。`2^(n+1) mod m`Python の組み込み高速累乗を使用して、ベースの移動を考慮して 2 を減算し、最後に再び法 m を適用して、負でない結果を保証します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    return str((pow(2, n+1, m) - 2) % m)

# provided samples
assert run("1 10\n") == "2", "sample 1"
# custom cases
assert run("3 100\n") == "14", "3 aliens"
assert run("0 5\n") == "0", "no aliens"
assert run("5 1\n") == "0", "mod 1"
assert run("10 1000\n") == "46", "10 aliens modulo 1000"
```| テスト入力 | 期待される出力 | 検証内容 |

 ## 特殊なケース

 n = 0 の場合、式は次のようになります。`2^(0+1)-2 = 0`エイリアンは移動する必要がないため、正しく 0 を返します。 n = 1 の場合、式は 2 を生成し、セクション 3 から 2、次に 2 から 1 への直接移動と一致します。10^9 などの大きな n 値はべき乗剰余演算によって正しく処理され、完全な 2^(n+1) を直接計算することが回避され、整数のオーバーフローが防止されます。 モジュロ演算により、2 を減算した場合でも、結果が常に [0, m-1] の範囲内に収まることが保証されます。
