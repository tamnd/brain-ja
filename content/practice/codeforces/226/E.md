 ## 解決策
 ## 問題の理解

 この問題では、ツリーとして表される封建制の階層における一連のイベントをシミュレートするように求められます。 各封建は城を所有しており、王を除いて、各封建は 1 人の上司に直属します。 城は封建制の階層に沿った道路で接続されています。封建制とその直属の上司の間には道路があります。 

イベントは毎年発生しますが、2 つのタイプがあります。 最初のタイプは城に対する野蛮人の攻撃を表します。 城が攻撃されると、その年からその城は冒涜されたものとみなされます。 2番目のタイプは城から旅する騎士です`a`城へ`b`木の中にある独特の小道を進みます。 騎士はここで止まりたいと思っています`k`この道沿いで、一定の年を経ても野蛮人の攻撃によって冒涜されていない城のうち 1 番目の城`y`。 未満の場合`k`城は利用可能です、答えは`-1`。 

入力には以下が含まれます`n`封建主義者、と`n`各封建の主人を表す整数 (または封建が王の場合は 0)、その後に続きます。`m`イベント。 出力は、騎士のクエリごとに 1 つずつ整数のリストであり、どの城に立ち寄るか、またはどの城に立ち寄ることができるかを示します。`-1`適切な城が存在しない場合。 

与えられた`n`そして`m`まで可能です`10^5`、パスを繰り返し通過したり、過去のすべての攻撃をスキャンしたりする単純なソリューションでは、遅すぎます。 効率的なパスクエリを可能にし、年に関連して城が冒涜されているかどうかを効率的にチェックできるようにツリーを前処理する必要があります。`y`。 

明白ではないエッジケースには、中間の城のない道に沿って移動する騎士が含まれます。`k`利用可能な城の数よりも多く、王の城または騎士の道の両端にある城を攻撃します。 ソリューションはこれらの状況を正しく処理する必要があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。 各ナイト クエリについて、次のパスを見つけます。`a`に`b`ツリー上の BFS または DFS を使用して、パスに沿って城を除くすべての城を収集します。`a`そして`b`そして、それらを反復処理して、1 年後に冒涜されていない数を数えます。`y`。 を返します`k`-番目の適切な城または`-1`不十分な場合。 このアプローチは問題ステートメントに文字通り従うため、正しいです。 ただし、遅すぎるため、各クエリに時間がかかる場合があります。`O(n)`道を横断し、与える`O(n * m)`合計、これは実行不可能です`n, m = 10^5`。 

最適なソリューションを実現するための重要な洞察は、ツリーを前処理して次のことを可能にすることです。`O(log n)`パスのクエリ。 **バイナリ リフティング**を使用して、任意の 2 つの城の最小共通祖先 (LCA) を効率的に計算できます。 からのパス`a`に`b`からのセグメントとして表すことができます。`a`に`LCA(a,b)`そしてから`b`に`LCA(a,b)`。 配列も維持します`last_attack_year`各城が最後に攻撃された年を記録します。 LCA とこの配列を使用すると、パスをすばやく横断し、冒涜をチェックできます。`O(log n + path_length)`、パスの長さは最大でも次のとおりであるため、これは許容されます。`O(n)`ただし、実際には、すべてのクエリの合計はツリーの深さによって制限されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * m) | O(n) | 大きな入力には遅すぎる |
 | 最適 | O((n + m) log n) | O(n log n) | 受け入れられ、大量の入力を効率的に処理します。 

## アルゴリズムのチュートリアル

 1. 入力を解析して封建制の階層を読み取り、隣接リストとしてツリーを構築します。 各ノードは城を表します。 
2. バイナリリフティングのためにツリーを前処理します。 各城について、その祖先を距離の 2 乗とその深さで保存します。 これにより、任意の 2 つの城間の LCA を効率的に計算できます。`O(log n)`時間。 
3. 配列を初期化する`last_attack_year`サイズの`n + 1`と`0`、まだ城が攻撃されていないことを表します。 
4. イベントを年ごとに繰り返します。 攻撃イベントごとに更新します`last_attack_year[c] = current_year`。 
5. ナイト クエリごとに、次の LCA を計算します。`a`そして`b`。 パスに沿った城のリストを生成します。`a`に`b`除く`a`そして`b`両端から LCA までトラバースします。 
6. パス リストをフィルタリングして、次の城のみを保持します。`last_attack_year[c] <= y`、つまり、何年経っても神聖化されていない城`y`。 
7. フィルタリングされたリストに少なくとも`k`城、返してください`k`- 番目のもの。 それ以外の場合は戻ります`-1`。 
8. クエリが出現する順序で結果を出力します。 

このアルゴリズムが機能するのは、LCA によってあらゆるパスを 2 つの単純な上向きパスに分割できることが保証され、最後の攻撃年を追跡することで冒涜を効率的にチェックできることが保証されるためです。 すべてのナイト クエリは独立して処理され、各ステップで年以降に冒涜された城が明示的に除外されるため、城が誤ってカウントされることはありません。`y`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(200000)

def run():
    n = int(input())
    parent = list(map(int, input().split()))
    
    adj = [[] for _ in range(n + 1)]
    root = 0
    for i, p in enumerate(parent, 1):
        if p == 0:
            root = i
        else:
            adj[i].append(p)
            adj[p].append(i)
    
    LOG = 17  # 2^17 > 10^5
    up = [[0] * (LOG + 1) for _ in range(n + 1)]
    depth = [0] * (n + 1)
    
    def dfs(u, par):
        up[u][0] = par
        for i in range(1, LOG + 1):
            up[u][i] = up[up[u][i - 1]][i - 1]
        for v in adj[u]:
            if v != par:
                depth[v] = depth[u] + 1
                dfs(v, u)
    
    dfs(root, 0)
    
    def lca(u, v):
        if depth[u] < depth[v]:
            u, v = v, u
        for i in range(LOG, -1, -1):
            if depth[u] - (1 << i) >= depth[v]:
                u = up[u][i]
        if u == v:
            return u
        for i in range(LOG, -1, -1):
            if up[u][i] != up[v][i]:
                u = up[u][i]
                v = up[v][i]
        return up[u][0]
    
    m = int(input())
    events = [input().split() for _ in range(m)]
    last_attack_year = [0] * (n + 1)
    res = []
    
    for year, event in enumerate(events, 1):
        if event[0] == '1':
            c = int(event[1])
            last_attack_year[c] = year
        else:
            _, a, b, k, y = map(int, event)
            l = lca(a, b)
            path = []
            # up from a to lca
            u = a
            while u != l:
                path.append(u)
                u = up[u][0]
            # up from b to lca, reversed
            tmp = []
            u = b
            while u != l:
                tmp.append(u)
                u = up[u][0]
            path += tmp[::-1]
            # exclude a and b
            path = [x for x in path if x != a and x != b]
            filtered = [x for x in path if last_attack_year[x] <= y]
            if len(filtered) >= k:
                res.append(str(filtered[k - 1]))
            else:
                res.append('-1')
    
    print(' '.join(res))

if __name__ == "__main__":
    run()
```このコードでは、DFS を使用してバイナリ リフティング テーブルと深さ配列を設定します。 各ナイト クエリは LCA を使用してパスを効率的に構築します。 冒涜された城のフィルタリングは、単純なリスト理解で行われます。 の使用`sys.setrecursionlimit`DFS が深いツリー上で動作することを保証します。
