 ## 解決策
 ## 問題の理解

 私たちは人の生年月日と上限の年を与えられています。 クエリごとに、この人が誕生の翌年から指定された年末までに誕生日を祝う回数をカウントする必要があります。 

重要な問題は、誕生日が 2 月 29 日である場合を除いて、毎年同じ暦日にしか誕生日が発生しないことです。この特別な場合、誕生日はうるう年にのみ発生します。 年が 400 で割り切れる場合、または 4 で割り切れるが 100 では割り切れない場合、その年は閏とみなされます。 

したがって、タスクは、有効な暦日として「D/M」という日付が範囲内に何年含まれているかを数えるということになります。 通常の日付の場合、毎年 1 つの誕生日が寄与します。 2 月 29 日については、うるう年のみが寄与します。 

制約は大きく、クエリ数は最大 100,000、年数は最大 2,000,000 です。 これにより、年間のシミュレーションは除外されます。 クエリごとに毎年繰り返す単純なアプローチでも、最悪の場合、最大 2e11 回の操作が必要になりますが、これは実行不可能です。 

微妙な特殊なケースとして、正しいうるう年のルールで 2 月 29 日が正しく処理されることがあります。 もう 1 つは、問題が明示的に翌年からカウントされるため、誕生日が同じ年の後半であっても、誕生年自体を確実に除外することです。 

たとえば、2000 年 1 月 1 日生まれで YE が 2000 年の場合、答えは 0 です。2020 年 2 月 29 日生まれで YE が 2020 年の場合、答えも 0 になります。 

## アプローチ

 直接的なアプローチは、Y+1 から YE まで毎年繰り返し、その年に誕生日が存在するかどうかを確認することです。 ほとんどの日付では、毎年その日と月が含まれるため、これは簡単です。 2 月 29 日については、閏条件をさらに確認します。 

これは概念的には機能しますが、最悪の場合、範囲の長さはテストごとに最大 200 万になる可能性があり、最大 100,000 のテストでは、これでは非常に遅くなります。 ボトルネックは、毎年繰り返されるチェックです。 

重要な観察は、誕生日は常に 1 年に 1 回存在するため、2 月 29 日を除くすべての日付について、答えは純粋に範囲内の整数の数であるということです。 2 月 29 日の場合、範囲内に閏年が何年存在するかを数えるだけで済みます。 これにより、各クエリが定数時間の減算または閏年のプレフィックス カウントのいずれかに削減されます。 

閏年の数え方を効率的にサポートするために、[1, N] に閏年が何年含まれるかを計算する式を導き出します。 これは、4、100、および 400 の倍数の包含/除外を使用して計算できます。この関数を取得すると、各クエリは O(1) になります。

 ## アルゴリズムのチュートリアル

 各クエリを個別に処理します。 

1. まず、有効なカウント範囲を厳密に誕生年から終了年までのすべての年、つまり Y+1 から YE に設定します。 これにより、誕生年が正しく除外されます。 
2. 誕生日が 2 月 29 日ではない場合、この期間内の毎年、ちょうど 1 つの誕生日が寄与します。 答えは (YE − Y) として計算されます。 これは、範囲内のすべての年がその日付に対して有効であるためです。 
3. 誕生日が 2 月 29 日の場合、代わりに [Y+1, YE] の間隔に閏年が何年含まれるかをカウントする必要があります。 
4. ≤ X であるうるう年の数を計算するには、次の式を使用します。 

床(X/4) − 床(X/100) + 床(X/400)。 

これは 4 の倍数を数え、無効な世紀を削除し、400 で割り切れる世紀を加算します。 
5. [L, R] の閏年の数は、F(R) − F(L−1) として計算されます。ここで、F(X) は接頭辞の閏数です。 
6. この公式を L = Y+1 および R = YE に適用して、最終的な答えを導き出します。 

なぜ効果があるのか

閏特別でない誕生日の場合、「誕生日が発生する」というイベントは年とは無関係で常に true であるため、カウントは範囲内の整数をカウントすることになります。 2 月 29 日のイベントは、標準の割り算ルールによって完全に特徴付けられる、閏年セットのその年のメンバーに厳密に縮小されます。 プレフィックス関数 F(X) は、X までの設定を正確にカウントし、減算により重複や省略なしに任意の区間を分離します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def leap_count(x):
    if x <= 0:
        return 0
    return x // 4 - x // 100 + x // 400

def solve():
    T = int(input())
    out = []
    for _ in range(T):
        d, m, y, ye = map(int, input().split())
        l = y + 1
        r = ye

        if m == 2 and d == 29:
            if l > r:
                out.append("0")
                continue
            ans = leap_count(r) - leap_count(l - 1)
            out.append(str(ans))
        else:
            if l > r:
                out.append("0")
            else:
                out.append(str(r - l + 1))
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この解決策は、うるう年のケースを他のすべての日付から分離します。 ヘルパー関数`leap_count`うるう年をしきい値までカウントするための包含/除外式を実装します。 

通常の日付の場合、[Y+1, YE] の範囲内の整数の数を計算します。これは単純に次のようになります。`r - l + 1`。 2 月 29 日の場合、接頭辞の違いを使用して、同じ間隔内に有効な閏年が何年存在するかを数えるという問題に変換します。 

境界条件`l > r`YE が Y に等しい場合を処理し、負のカウントが表示されないようにします。

import sys, io

def run(inp: str) -> str:

    import sys
    input = sys.stdin.readline

    def leap_count(x):
        if x <= 0:
            return 0
        return x // 4 - x // 100 + x // 400

    T = int(input())
    out = []
    for _ in range(T):
        d, m, y, ye = map(int, input().split())

        else:
            out.append(str(max(0, r - l + 1)))
    return "\n".join(out)

 ## 特殊なケース

 特殊なケースの 1 つは、誕生年が終了年と等しい場合です。 YE = 2000 の 10/5/2000 のような通常の日付の場合、2001 年から開始するため、間隔は空になります。アルゴリズムは L = Y+1 を設定するため、L > R となり、0 を直接返します。 

もう 1 つの特殊なケースは、うるう年を含まない範囲の 2 月 29 日です。 たとえば、2021 年 2 月 29 日から 2023 年までは、L = 2022 および R = 2023 となります。どちらのエンドポイントにも閏年が含まれていないため、閏プレフィックスの差は 0 を返します。 

最後のエッジケースは、2e6 に近い非常に大きな年の値です。 すべての演算は単純な整数の除算であり、オーバーフローや反復が発生しないため、プレフィックス式は依然として安全に機能します。
