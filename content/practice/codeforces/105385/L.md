 ## 問題の理解

 ## アルゴリズムのチュートリアル

 1. ツリーを任意にルート化し、サブツリーのサイズと親関係を計算します。 これは、重心分解とエッジの重みの更新がどのように伝播するかを決定するために必要です。 
2. ツリーの重心分解を構築します。 すべての元の木のエッジが属します$O(\log n)$セントロイド レベル。これにより、ローカライズされた更新とクエリが可能になります。 
3. すべてのセントロイド ノードについて、その分解されたサブツリーからの最適パスの寄与を保存するデータ構造を維持します。 各コントリビューションは、子コンポーネントから重心に入り、別のコンポーネントを通って出るパスに対応します。 
4. クエリごとに、指定された条件の下でどの頂点が「有効なエンドポイント」であるかを判断します。$k$。 これはサブツリーのサイズ制約から導出されます。エンドポイントは、少なくとも 1 つの隣接する方向が少なくとも 1 つ含まれる場合に有効です。$k$頂点を設定し、実行可能なパスの終点として機能できるようにします。 
5. このクエリに対して有効なエンドポイントのみをアクティブにします。 重心構造では、無効なエンドポイントからの寄与を無視します。 
6. 一時的なエッジの重みの更新を適用します。 影響を受けるエッジを、それが関与するすべての重心分解レベルで更新します。 各セントロイドには部分的なパスの合計が格納されるため、$O(\log n)$アップデートが必要です。 
7. 更新された値を使用して最適な重心構成パスを再計算し、両方のエンドポイントが妥当性条件を満たしていることを確認します。 結果は、最大重みの実行可能なパスであり、最良の交差値と等しくなります。

    def __init__(self, n, adj):
        self.n = n
        self.adj = adj
        self.dead = [False] * (n + 1)
        self.sub = [0] * (n + 1)
        self.parent = [-1] * (n + 1)
        self.level = [0] * (n + 1)
        self.build(1, 0, 0)

    def dfs_size(self, u, p):
        self.sub[u] = 1
        for v, _ in self.adj[u]:
            if v != p and not self.dead[v]:
                self.dfs_size(v, u)
                self.sub[u] += self.sub[v]

    def dfs_centroid(self, u, p, total):
        for v, _ in self.adj[u]:
            if v != p and not self.dead[v]:
                if self.sub[v] > total // 2:
                    return self.dfs_centroid(v, u, total)
        return u

        self.dfs_size(u, -1)
        c = self.dfs_centroid(u, -1, self.sub[u])
        self.dead[c] = True
        self.parent[c] = p
        self.level[c] = depth

            if not self.dead[v]:
