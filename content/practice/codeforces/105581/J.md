 ## 解決策
 ## 問題の理解

 まずは直角二等辺三角形の紙を用意します。 45-45-90の三角形と考えてください。 Vitya は、この三角形を 2 つの合同な部分に分割する線に沿って繰り返し折ります。 彼はこの折り操作を正確に実行します`n`常に、結果として得られた形を再び半分に折ります。 

すべての折りが完了したら、紙を完全に広げて元の三角形に戻します。 折り目のパターンにより、三角形が多数の小さな領域に格子状に分割されます。 タスクは、それらの領域のうちのいくつが完全な正方形であるかを数えることです。 

重要な問題は、折り目によって任意のジオメトリが生成されないことです。 それぞれの折り目は特定の構造化パターンを 2 倍にし、展開後、折り線は非常に規則的な細分割を形成し、その組み合わせ構造は折り目の数に応じて指数関数的に増加します。 

入力`n`これにより、ジオメトリを明示的にシミュレートしたり、折りパターンを構築しようとするアプローチは即座に除外されます。 すべてのセグメントまたはセルを追跡する単純な再帰的構築であっても、指数関数的に増大し、フォールドごとの複雑さがおよそ 2 倍になり、約 100 メートルを超えると不可能になります。`n = 20`。 

出力は単一の整数、つまり最終的に展開された折り目パターンで形成される正方形のセルの数です。 

難しい書式設定や複数のテスト ケースはありません。 主な課題は、対称的な折り畳みを繰り返すことによって生成される組み合わせパターンを発見することです。 

非常に小さい場合に微妙なエッジケースが表示されます`n`。 いつ`n = 1`、折り目は 1 つだけ存在し、折り目のパターンは単一の対角線です。 これでは正方形の領域がまったく形成されないため、答えは次のようになります。`0`。 のために`n = 2`、構造は最初の非自明な格子状の区画となり、正方形が現れ始めます。 折り目を独立したオーバーレイとして扱う誤った直観は、構造化された指数関数的な細分化ではなく線形成長を想定するため、ここでカウントを誤る傾向があります。 

## アプローチ

 直接シミュレーションのアプローチでは、紙を幾何学的オブジェクトとして明示的にモデル化してから、既存のセグメントを反映し、すべての交点を追跡することによって各折り目を適用しようとします。 後`n`折り目がある場合は、すべての折り線によって引き起こされる平面の細分割を計算し、正方形の面をカウントしようとします。 

このアプローチは概念的には単純で正しいものです。なぜなら、折りはすべての折り線を生成する繰り返しの反射に実際に対応するからです。 ただし、折り目ごとにセグメントの数がおよそ 2 倍になります。 後`n`折りたたむと、セグメントの数は指数関数的に増加します。`n`、交点の数も同様です。 でさえ`n = 20`、これはすでに時間とメモリの両方で実行不可能になります。 

重要な観察は、直角二等辺三角形を半分に折り返すと、自己相似グリッドを構築するのと同等の決定論的再帰構造が繰り返し生成されるということです。 折り目ごとに、三角格子の実効解像度が 2 倍になります。 幾何学で考える代わりに、このプロセスを組み合わせ的に解釈します。折り目ごとに、三角形の両脚に沿った単位「レベル」の数が増加し、水平方向と垂直方向の隣接構造が同じ深さで並んだ場合にのみ正方形が現れます。 

これにより、問題は、再帰的に二重化された三角形グリッド内の正方形の部分構造を数えるという問題に縮小されます。 各レベルで`n`、パターンは、既存の正方形のような領域がより小さな構成に分割され、新しい正方形が両方の軸を横切って整列した隣接するセルからのみ出現する前のレベルの改良版として見ることができます。 

この自己相似性は直接反復につながります。つまり、正方形の数は前のレベルにのみ依存する形で増加し、ジオメトリなしで O(n) 時間で計算できます。

 ## アルゴリズムのチュートリアル

 折り畳みプロセスは、ステップごとに解像度が 2 倍になる三角形グリッドを生成すると解釈します。 重要なのは、最終的な展開パターンの正方形が、2 つの独立した折り曲げ方向から継承された交差する折り目方向によって形成される、軸が整列した単位正方形に対応するということです。 

1. その後の観察から始めます`n`折り畳むと、構造は一定のサイズのグリッドとして見ることができます。`2^n`折り畳まれた座標系の各有効次元で。 折りたたむたびに、方向性のあるパーティションの数が 2 倍になります。 
2. 最終的なパターンの正方形は、両方とも閉じたセルを形成するのに十分に細分化されている 1 組の垂直方向を選択することによって決定されることを認識します。 これは、正方形はサブディビジョンの第 2 レベルからのみ表示されることを意味します。 
3. しましょう`f(n)`後の正方形の数を示します`n`折り目。 レベルを比較する`n`レベル付き`n-1`。 折りの深さを増やすと、既存のすべての構成が 4 つのサブ構成に洗練されますが、新しい正方形は洗練された古い正方形からだけでなく、隣接するサブディビジョン間に作成された新しい配置からも形成されます。 
4. 反復は、新しいレベルごとに現在のグリッド解像度の二次関数に等しい数の正方形を追加する累積構造に単純化されます。 実効解像度は`2^(n-1)`各軸に沿った、レベルで導入された新しい正方形の数`n`に比例する`(2^(n-1) - 1)^2`。 
5. この貢献を繰り返し蓄積します。`1`に`n`から始まる`f(1) = 0`。 

これにより、グリッドを明示的に構築せずに O(n) の計算が行われます。 

### なぜ効果があるのか

 折り畳みプロセスは自己相似です。各折り畳みは、解像度を 2 倍にしながら局所的な隣接構造を維持する均一な改良として機能します。 これにより、この段階で重要なのは唯一のものであることが保証されます`n`これは暗黙的なグリッドのサイズであり、以前の折り目の正確なジオメトリではありません。 すべての正方形は、垂直な折り方向に沿って 2 つの隣接するサブディビジョンを選択することによって一意に決定され、これらの選択はレベル間で独立しています。これにより、2 次の数え方の公式が、重複や省略なしにすべての可能な正方形の面を正確に列挙することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    if n == 1:
        print(0)
        return
    
    # total squares after n folds
    # derived from cumulative sum of (2^(k-1) - 1)^2
    res = 0
    for k in range(2, n + 1):
        m = 1 << (k - 1)
        res += (m - 1) * (m - 1)
    
    print(res)

if __name__ == "__main__":
    solve()
```このソリューションは、派生した反復を直接実装します。 ループは次から始まります`k = 2`最初の折り目では正方形の領域が生成されないためです。 各レベルで、有効なグリッド サイズを計算します。`m = 2^(k-1)`ビット シフトを使用します。これは効率的であり、浮動小数点演算を回避します。 

表現`(m - 1)^2`各方向で 2 つの異なるグリッド線を選択することによって形成された内部の正方形のセルを数えることに相当します。 これらの寄与を合計すると、各洗練レベルで導入されたすべての正方形が累積されます。 

注意が必要です`n = 1`、不必要な計算を回避し、1 回折り畳んだ後に正方形が存在しないという事実を尊重するために、個別に処理されます。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n = int(input().strip())
    if n == 1:
        return "0"
    
    res = 0
    for k in range(2, n + 1):
        m = 1 << (k - 1)
        res += (m - 1) * (m - 1)

# minimal case
assert run("1\n") == "0"

# first nontrivial case

# growth check
assert run("3\n") == "10"

# larger case

# maximum boundary
assert run("5\n") == str(sum(( (1 << (k-1)) - 1 )**2 for k in range(2, 6)))

 ## 特殊なケース

 のために`n = 1`、アルゴリズムはすぐに戻ります`0`。 これは、単一の折り目によって斜めの折り目が導入されるだけで、正方形の領域を囲むことができないという幾何学的な状況と一致します。 

のために`n = 2`、ループは 1 回実行されます`k = 2`。 私たちは計算します`m = 2^(1) = 2`、 それで`(m - 1)^2 = 1`。 これは、2 つの対称的な折り曲げの後に現れる最初の囲まれた正方形の領域に正確に対応します。 

最大限に`n = 40`、ループは 39 回繰り返し実行されます。 最大の用語は`(2^39 - 1)^2`、これは Python の任意精度の整数に簡単に適合します。 アルゴリズムは幾何学的オブジェクトを構築せず、整数演算のみを実行するため、安定したままです。
