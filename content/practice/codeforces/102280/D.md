 ## 問題の理解

 ルートには価値がある`k`。 乗客が通過を希望する場合`n`停車した場合の運賃は、`n`-th`k`-ゴナル番号。 のために`k = 4`、これらは平方数です。`k = 3`これらは三角数であり、より大きな値です。`k`より多くの辺を持つ正多角形の図形を記述します。 

入力には 2 つの整数が含まれています。`n`そして`k`。 ここ`n`乗客が希望する停車駅の数です。`k`ルートがどのポリゴン番号シーケンスを使用するかを決定します。 を出力する必要があります`n`-th`k`-ゴナル番号。 

の重要な公式は、`n`-番目の多角形番号は

 [
 P_k(n)=\frac{(k-2)n^2-(k-4)n}{2}。 
]

 制約により許可されるのは、`n`(10^8) に到達し、`k`到達する`100`。 入力には値のペアが 1 つだけ含まれているため、意図したソリューションは次の値に依存すべきではありません。`n`。 停止ごとにループを 1 回実行するには、すでに最大 (10^8) 回の反復が必要ですが、0.5 秒の制限の下では不必要にコストがかかります。 この式は、わずかな算術演算だけで定数時間の解を与えます。 

誤って処理されやすい境界ケースが 2 つあります。 初め、`n = 0`ゼロを生成する必要があります。 たとえば、入力`0 4`出力があります`0`。 多角形の番号付けが次から始まることを前提とした数式または実装`n = 1`特別な初期化を実行すると、誤って戻る可能性があります`1`。 

第 2 に、除算は分子が形成された後に実行する必要があります。 例えば、`4 5`与える

 # \frac{48-4}{2}

 1.

 ]

 誤った三角数式を使用したり、線形項を削除したりする不注意な実装では、間違った値が生成されます。 正方形の場合は、別の便利なチェックを提供します。`4 4`(4^2=16) を生成します。 

## アプローチ

 直接的なアプローチは、多角形図形をレイヤーごとに構築することです。 最初の多角形の数は`1`、後続の各レイヤーは、次のように決定されるポイントの数を追加します。`k`そして現在のレイヤー。 これは正しいです。ポリゴン番号は、連続したジオメトリ レイヤーを追加することによって正確に定義されるからです。 

問題は、このようなシミュレーションでは、値ごとに 1 回の反復が必要になることです。`n`。 と`n = 10^8`、最悪の場合は (10^8) 回程度の反復になります。 Python では、これは 0.5 秒のコンテスト制限が合理的に許容できる値をはるかに超えており、より高速な言語であっても、閉じた形式の式を持つ問題を解決することになります。 

有益な観察は、レイヤーのサイズが等差数列を形成しているということです。 のために`k`-gonal sequence では、ある項から次の項への増加は次のようになります。 

[
 (k-2)n-(k-3)。 
]

 (P_k(1)=1) から開始して、これらの算術増分を合計すると、次の 2 次式が得られます。`n`。 合計を単純化すると、次のようになります。 

[
 P_k(n)=\frac{(k-2)n^2-(k-4)n}{2}。 
]

 この総当たり手法は、この合計を明示的に実行するため機能しますが、次の場合には失敗します。`n`大きいです。 閉じた形式では、同じ合計を代数的に実行し、計算全体を一定時間に短縮します。

 ## アルゴリズムのチュートリアル

 1.読む`n`そして`k`。 要求されたポリゴン数は完全に決定されるため、追加のデータ構造は必要ありません。 
2. 分子を計算する

 [
 (k-2)n^2-(k-4)n。 
]

 これは、レイヤー サイズの等差数列を合計することによって得られる標準的な閉じた形式です。 
3. 分子を次の値で割ります。`2`そして結果を印刷します。 多角形の数値は整数なので、割り算は正確です。 

### なぜ効果があるのか

 の`k`-gonal シーケンスは (P_k(1)=1) で始まり、その連続する差分が等差数列を形成します。 

[
 k-2、\ 2(k-2)-(k-4)、\ 3(k-2)-(k-4)、\ldots
 ]

 これを単純化すると

 [
 (k-2)n-(k-3)。 
]

 前期から後期までの違いをまとめると、`n`-番目の項は与えます

 # \frac{n((k-2)n-(k-4))}{2}

 \frac{(k-2)n^2-(k-4)n}{2}。 
]

 アルゴリズムはこの数学的定義を正確に評価するため、出力される値は有効なすべての運賃に必要な運賃になります。`n`そして`k`。 

## Python ソリューション```python

式は閉じた形式に直接続きます。 コンピューティング`n * n`乗算する前に`k - 2`式との対応を明確に保ちます。 Python の整数には任意の精度があるため、最大入力サイズでもオーバーフローの問題は発生しません。 

の`// 2`整数の分子は常に偶数であるため、操作は安全です`n`そして`k`。 整数除算を使用すると、出力が浮動小数点値ではなく整数として出力されることも保証されます。 

ケース`n = 0`特別なブランチは必要ありません。 分子の両方の項には次のものが含まれます`n`したがって、式は当然ゼロに評価されます。

import sys
import io

def solve():
    input = sys.stdin.readline
    n, k = map(int, input().split())
    answer = ((k - 2) * n * n - (k - 4) * n) // 2
    print(answer)

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout
    try:
        sys.stdin = io.StringIO(inp)
        sys.stdout = io.StringIO()
        solve()
        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout
