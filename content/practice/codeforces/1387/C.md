 ## 解決策
 ## 問題の理解

 私たちには、各「遺伝子」が整数ラベルであるシステムが与えられており、1 より大きいすべての遺伝子は、固定された突然変異規則に従って一連の遺伝子に拡張できます。 たった一つの遺伝子から始まる$x$、現在の配列内の非末端遺伝子をその拡張によって繰り返し置換し、配列が完全に遺伝子 0 と 1 で構成されている場合にのみ停止します。 

したがって、各開始遺伝子は、突然変異中にどの拡張選択を適用するかに応じて、潜在的に巨大なバイナリ文字列のセットを定義します。 すべての中間状態は遺伝子 ID のアルファベット上のシーケンスであり、最後にのみそれを {0, 1} 上のバイナリ文字列として解釈します。 

また、抗体と呼ばれる一連のバイナリ パターンも与えられます。 抗体は、そのパターンが最終バイナリ文字列内の連続した部分文字列として現れる場合にウイルスと一致します。 開始遺伝子ごとに$x \ge 2$、すべての可能な完全に展開されたバイナリ文字列が少なくとも 1 つの抗体で「カバー」されているかどうかを判断する必要があります。 カバレッジが保証されていない場合は、から到達可能なバイナリ文字列の最小長を見つける必要があります。$x$これはすべての抗体を完全に回避します。つまり、指定されたパターンが部分文字列として表示されないことを意味します。 

重要な問題は、拡張が非決定的であることです。遺伝子は異なる配列に拡張することができ、それらの配列の一部は後で別の方法で再び拡張する可能性があります。 これにより文字列の巨大な状態空間が作成されますが、抗体は最終的なバイナリ文字列のみを制約し、中間形式は制約しません。 

複雑さの観点から見ると、突然変異グラフには次のものがあります。$G \le 10^5$最悪の CF バージョンではスケール構造が使用されますが、ここでは合計拡張サイズが 100 で制限されているため、遷移がまばらになります。 抗体の全長は最大でも 50 なので、禁止パターンはどれも短いです。 これは、構築する必要がある効果的なオートマトンが小さく、どのソリューションでも文字列を明示的にシミュレートするのではなく、「突然変異ルール」と「パターン マッチング」の両方を単一の状態空間に圧縮する必要があることを強く示唆しています。 

遺伝子が 0 と 1 だけで終わらずに無限に拡張できる場合、微妙なエッジケースが発生します。その場合、有効なウイルスは生成されず、抗体に関係なく答えは「YES」でなければなりません。 終了を想定した単純なシミュレーションでは、最小限の文字列を誤って計算しようとし、スタックしたり、そのような遺伝子を誤って分類したりする可能性があります。 

別の失敗例は、各遺伝子が独自の拡張を生成すると仮定することです。 たとえば、遺伝子に複数の生成ルールがある場合 (これはステートメント構造で許可されています)、異なる選択は異なる二値の結果につながる可能性があるため、すべての可能性を同時に考慮する必要があります。 貪欲な拡張や単一パス DP では不十分です。 

## アプローチ

 直接的な試みは、各遺伝子の可能なすべての展開をバイナリ文字列に明示的に生成し、抗体に対してパターン マッチングを実行することです。 これは原理的には正しいです。0/1 だけが残るまで突然変異ツリーを探索し、すべての終端文字列を収集して、それぞれに禁止された部分文字列がないかチェックします。 ただし、分岐要素により、これは実行不可能になります。 それぞれの作品は短くても、展開を繰り返すと、指数関数的に多くの文字列が作成されます。 爆発は徹底的に起こるのではなく、選択によって起こります。各遺伝子は位置や段階にわたって複数の方法で置き換えられ、選択ごとに状態の数が増加します。 

重要な点は、実際には明示的な文字列が必要ないということです。 必要なのは、部分導出によって禁止された部分文字列のない結果が生成されるかどうか、また、生成できる場合、そのような結果の最小長がどれくらいであるかを知ることだけです。 これは、「構成」のグラフに対する最短経路の視点を即座に示唆します。 

それぞれの構成は遺伝子のマルチセットのような配列ですが、配列を直接追跡するのは大きすぎます。 秘訣は、プロセスを逆転させることです。遺伝子を前方に拡張するのではなく、最終的なバイナリ出力に向けて遺伝子を縮小するという観点から考え、同時に禁止されたパターンに一致するかどうかを追跡します。 これはまさに、状態が現在のシンボルとパターン マッチングの進行状況の両方をエンコードする暗黙的オートマトンにおける最短経路問題です。 

複数のパターン制約を処理する標準的な方法は、すべての抗体に対する Aho-Corasick オートマトンです。 これにより、各状態がこれまでに一致した禁止パターン プレフィックスの量を表す障害追跡マシンが得られます。 端末一致状態に入ると、その設定は禁止されます。 したがって、生成されたすべてのバイナリ文字がオートマトンを遷移させるため、終了状態を回避する必要があります。 

ここで、これを遺伝子拡張と組み合わせます。 各遺伝子は、他の遺伝子の上に文字列を生成するノードです。 最終的には、各遺伝子と各オートマトンの状態について、取得可能なバイナリ文字列の最小長を計算することにすべてが集約されます。 これにより、問題は州間のグラフ DP に変わります。$(gene, ac\_state)$しかし、遷移は単一のエッジではありません。遺伝子はシーケンスに拡張されるため、一連の DP 状態を通じて遷移を構成する必要があります。 

これは、DP 値を定義し、遺伝子展開構造に対して逆位相順序で計算することで処理されますが、サイクルが存在する可能性があるため、代わりに積グラフに対して最短パス (ダイクストラ型または緩和を伴う 0-1 BFS スタイル) を使用します。 各展開ルールはパス展開演算子になります。 

最後に、各開始遺伝子について、次のことを確認します。$(gene, root)$端子 AC 状態になる場合は、YES と答えます。 それ以外の場合は、非終端 AC 状態までの最小距離を抽出します。

 ## アルゴリズムのチュートリアル

 まず、すべての抗体パターンを単一のオートマトンに圧縮して、出力ビットを生成しながら禁止された部分文字列の形成を段階的に追跡できるようにします。 

1. すべての抗体に対して Aho-Corasick オートマトンを構築します。 各状態は、現在生成された出力のサフィックスである禁止パターンの最長のプレフィックスを表します。 完了したパターンに対応する状態を禁止としてマークします。これは、そこにアクセスするとウイルスが検出され、そのパスが無効になることを意味するためです。 
2. 遺伝子展開ルールを、子遺伝子の配列を生成する遷移として解釈します。 拡張は直接ビットではなく遺伝子に対して行われるため、ビットの生成を延期し、代わりに各遺伝子と各オートマトンの状態について、その遺伝子をバイナリ出力に完全に拡張した後に何が起こるかを計算します。 
3. DP 値を定義する`dist[g][s]`遺伝子から開始して生成される有効なバイナリ文字列の最小長として`g`AC オートマトンが現在状態にある間`s`。 これにより、「何がまだ拡張されていないのか」と「どれだけの禁止されたプレフィックス コンテキストが含まれているか」の両方が把握されます。 
4. 基本ケースを初期化します。すでに末端 (0 および 1) である遺伝子は単一の文字を生成します。 州から`s`、ビット 0 または 1 を発行すると、オートマトンが新しい状態に遷移し、遷移が禁止されていない場合はコスト 1 が寄与します。 
5. 非末端遺伝子の場合、各生成ルールにより子遺伝子のシーケンスが与えられます。 ルールを評価するには、状態から開始して、その子の DP 遷移を概念的に構成します。`s`、既知の値を繰り返し適用しながら、シーケンスを伝播します。`dist`トランジション。 ルールの総コストは、正しい中間オートマトン状態での子展開のコストの合計です。 
6. 遺伝子ごとに複数のルールが存在するため、すべてのルールの最小値を採用します。 これにより、ノードが次のようなグラフ上に最短経路問題が形成されます。$(gene, ac\_state)$。 
7. 初期 AC 状態の各クエリ遺伝子から開始して、これらの状態に対してダイクストラを実行します。 遷移は、遺伝子拡張ルールを適用し、結果として得られるバイナリ出力をオートマトンを通じて消費することに対応します。 禁止された AC 状態に到達すると、そのパスは破棄されます。 
8. 距離が安定した後、各遺伝子について、その開始状態から有限の距離が存在するかどうかを確認します。 何も存在しない場合、考えられるすべての拡張は最終的に禁止されたパターンに強制されるか、終了しません。 「YES」と印刷します。 それ以外の場合は、NO と最小距離を出力します。 

### なぜ効果があるのか

 重要な不変条件は次のとおりです`dist[g][s]`遺伝子から取得可能なバイナリ文字列の最小可能長を常に格納します。`g`すでに生成されたプレフィックスがオートマトンの状態に対応することを維持しながら`s`。 すべての緩和ステップは、1 つの有効な突然変異ルールを適用し、生成されたバイナリ文字列を AC オートマトンの遷移と一貫して拡張することに正確に対応します。 すべての遷移では接頭辞一致の正確性が維持されるため、無効な部分文字列が形成後に「隠蔽」されることはありません。 ダイクストラは、状態が完了すると、それより短い有効な構造が存在しないことを保証するため、最小長は全体的に正しいものになります。 

## Python ソリューション```python
import sys
import heapq

input = sys.stdin.readline

INF = 10**30

class Aho:
    def __init__(self):
        self.next = [[-1, -1]]
        self.fail = [0]
        self.out = [False]

    def add(self, s):
        v = 0
        for ch in s:
            c = int(ch)
            if self.next[v][c] == -1:
                self.next[v][c] = len(self.next)
                self.next.append([-1, -1])
                self.fail.append(0)
                self.out.append(False)
            v = self.next[v][c]
        self.out[v] = True

    def build(self):
        from collections import deque
        q = deque()
        for c in range(2):
            u = self.next[0][c]
            if u != -1:
                self.fail[u] = 0
                q.append(u)
            else:
                self.next[0][c] = 0

        while q:
            v = q.popleft()
            self.out[v] |= self.out[self.fail[v]]
            for c in range(2):
                u = self.next[v][c]
                if u != -1:
                    self.fail[u] = self.next[self.fail[v]][c]
                    q.append(u)
                else:
                    self.next[v][c] = self.next[self.fail[v]][c]

def solve():
    G, N, M = map(int, input().split())

    gmap = [[] for _ in range(G)]
    for _ in range(N):
        a, k, *rest = map(int, input().split())
        gmap[a].append(rest)

    ac = Aho()
    patterns = []
    for _ in range(M):
        arr = list(map(int, input().split()))
        l = arr[0]
        pat = ''.join(map(str, arr[1:]))
        ac.add(pat)

    ac.build()

    S = len(ac.next)

    dist = [[INF] * S for _ in range(G)]

    pq = []

    def relax(g, s, d):
        if ac.out[s]:
            return
        if d < dist[g][s]:
            dist[g][s] = d
            heapq.heappush(pq, (d, g, s))

    for g in range(2, G):
        relax(g, 0, 0)

    while pq:
        d, g, s = heapq.heappop(pq)
        if d != dist[g][s]:
            continue
        if ac.out[s]:
            continue

        for rule in gmap[g]:
            cur_s = s
            cost = d
            ok = True

            for x in rule:
                if x <= 1:
                    cur_s = ac.next[cur_s][x]
                    if ac.out[cur_s]:
                        ok = False
                        break
                    cost += 1
                else:
                    if dist[x][cur_s] >= INF:
                        ok = False
                        break
                    cost += dist[x][cur_s]

            if ok and cost < dist[g][cur_s]:
                dist[g][cur_s] = cost
                heapq.heappush(pq, (cost, g, cur_s))

    for g in range(2, G):
        ans = dist[g][0]
        if ans >= INF:
            print("YES")
        else:
            print("NO", ans)

if __name__ == "__main__":
    solve()

微妙な点は、遷移がすぐに禁止された AC 状態に達する可能性があるため、それらのパスは早めに破棄する必要があることです。 もう 1 つのデリケートな側面は、抗体は空のプレフィックスから始まる生成された完全な文字列に対してチェックされるため、DP を状態 0 からのみ初期化することです。

 ## 特殊なケース

 重大なエッジケースは、その拡張が末端のバイナリのみの配列に決してつながらない遺伝子です。 このような状況では、その遺伝子の DP 状態は到達不能または無限のままであり、有効なウイルスが存在しないため、アルゴリズムは正しく YES を出力します。 ダイクストラ初期化ではその遺伝子の状態が最終決定されることはないため、有限長のバイナリ文字列が生成されないものとして扱われます。 

もう 1 つの微妙なケースは、遺伝子がすでに抗体プレフィックスと部分的に一致しているものの完全には一致しないバイナリ出力を生成する場合です。 AC オートマトンは、中間プレフィックス状態をアクティブに保つことでこれを処理し、最終状態が非終端である限り遷移は有効なままになります。 DP は、一致が完了するとすぐに失敗状態を伝播することで、「永久に安全なプレフィックス」と「最終的に禁止された完了」を正しく区別します。
