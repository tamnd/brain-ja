 ## 解決策
 ## 問題の理解

 指定された 2 つの文字列を同時に説明できる「テンプレート」文字列を構築するように求められます。 テンプレートは小文字とアスタリスクで構成されます。 各アスタリスクは、元の文字列と一致するように、空の文字列を含む任意の文字列に置き換えることができます。 重要なのは、アスタリスクの数がテンプレート内の文字数を超えない場合、テンプレートは「アスタリスクマイナー」であるということです。 

2 つの文字列が与えられた場合、目的は、両方の文字列が一致する単一のアスタリスクマイナー テンプレートが存在するかどうかを判断し、存在する場合はテンプレートを生成することです。 各テスト ケースは長さが最大 ​​50 の 2 つの文字列で構成され、テスト ケースは最大 10,000 個存在する場合があります。 

最初に注目すべきことは、文字列の長さが短いため、文字列全体に対する操作が可能であるということです。 二次比較 (すべての文字ペアのチェックなど) も許容されます。$50 \cdot 50 = 2500$10,000 のテスト ケースを掛けても、2 秒以内に収まります。 

明らかではないエッジケースには次のものが含まれます。 

- 完全に同一の文字列。 例えば、`a = "abc"`、`b = "abc"`。 テンプレートは、アスタリスクのない単なる文字列そのものです。 
・途中だけ弦が違う。 例えば、`a = "abXcd"`、`b = "abYcd"`。 相違点ごとに常に 1 つのアスタリスクを挿入する単純なアプローチは、誤って「アスタリスクマイナー」制約に違反する可能性があります。 
- 長さ1のまったく異なる文字列。`a = "x"`、`b = "y"`、唯一の有効なテンプレートは`*`、これは 1 文字なので (空の文字列を含めた場合?) アスタリスクマイナーですが、文字数のカウントは慎重に行う必要があります。 

## アプローチ

 ブルートフォース手法では、テンプレート内のアスタリスクと文字のあらゆる組み合わせを生成し、両方の文字列に対してテストしようとします。 長さ 50 の 2 つの文字列の場合、アスタリスクを挿入する方法の数は指数関数的に増加し、短い長さの場合でも実行できなくなります。 

重要な洞察は、アスタリスクを使用して、異なる文字の任意のセグメントを「吸収」できるということです。 したがって、最も単純で有効なテンプレートは、最も長い共通のプレフィックスとサフィックスをリテラル文字として保持し、その間のすべてを 1 つのアスタリスクに置き換えるものです。 

たとえば、与えられた`a = "aaab"`そして`b = "zzzb"`、最も長い共通接尾辞は次のとおりです。`"b"`、最長の共通プレフィックスは空であり、中央のプレフィックスは空です。`"aaa"`対`"zzz"`で置き換えることができます`*`。 結果として得られるテンプレートは、`*b`。 このテンプレートはアスタリスクマイナーです。1 つのアスタリスクと 1 つの文字があり、制約を満たしています。 

2 つの文字列に一致するプレフィックスまたはサフィックスがない場合、最も単純なテンプレートは次のとおりです。`*`、少なくとも 1 つの文字列の長さが 1 以上の場合、これもアスタリスクマイナーになります。 共通のプレフィックスとサフィックスを合わせたものが必要なアスタリスクの総数より短い場合は、アスタリスクマイナー規則に違反する可能性があるため、報告する必要があります。`NO`。

 ## アルゴリズムのチュートリアル

 1. 文字列のペアごとに`a`そして`b`、まず、最長の共通プレフィックスを見つけます。 初期化する`i = 0`そして増加します`i`その間`a[i] == b[i]`。 文字が異なる場合、または 1 つの文字列の終わりに達した場合に停止します。 
2. 次に、最も長い共通接尾辞を見つけます。 初期化する`j = 0`そして増加します`j`その間`a[-1-j] == b[-1-j]`残りの部分文字列はプレフィックスと重なりません。 これにより、プレフィックスとサフィックスが交差しないことが保証されます。 
3. プレフィックスの長さとサフィックスの長さの合計がいずれかの文字列の長さ以上である場合、その範囲内の文字列が同一であり、内部アスタリスクなしでテンプレートを構築できることを意味します。 
4. それ以外の場合は、異なる中間セグメントを単一のアスタリスクに置き換えます。 プレフィックス、アスタリスク、サフィックスを連結してテンプレートを形成します。 
5. アスタリスクのマイナー条件を確認します: 文字とアスタリスクを数えます。 文字≧アスタリスクの場合、印刷します`YES`そしてテンプレート。 それ以外の場合は、印刷します`NO`。 

機能する理由: 単一のアスタリスクは任意の部分文字列を吸収できるため、異なるセグメントを置き換えるには最大でも 1 つのアスタリスクが必要です。 一致するプレフィックスとサフィックスをそのまま維持することで、すべてのリテラル文字が確実に保持されます。 アスタリスクマイナー条件は、長さが 50 以下の文字列については自動的に満たされます。これは、中間セグメントが最大 1 つのアスタリスクで置き換えられるためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a = input().strip()
    b = input().strip()
    
    n = len(a)
    m = len(b)
    
    # Longest common prefix
    i = 0
    while i < min(n, m) and a[i] == b[i]:
        i += 1
    
    # Longest common suffix
    j = 0
    while j < min(n - i, m - i) and a[n-1-j] == b[m-1-j]:
        j += 1
    
    if i + j == 0 and n != m:
        # No overlap and no common letters: * cannot be minor if no letters
        print("NO")
    else:
        template = a[:i] + "*" + a[n-j:] if j > 0 else a[:i] + "*"
        letters = len(a[:i]) + len(a[n-j:])
        stars = 1
        if letters >= stars:
            print("YES")
            print(template)
        else:
            print("NO")
```コードでは、プレフィックスとサフィックスの重複を慎重に避けています。 異なるセグメントの長さに関係なく、単一のアスタリスクのみを挿入します。これは、両方の文字列を一致させるのに十分です。 チェック中`letters >= stars`アスタリスクマイナー条件が満たされていることを確認します。
