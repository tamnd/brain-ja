 ## 問題の理解

 私たちは、「美しい」整数のセットを扱うように求められています。これは、セット内の任意の 2 つの数値が割り切れる条件下で比較できることを意味します。 2 つの整数が与えられた場合`l`そして`r`、タスクは、区間内の数値のみで構成される可能な限り最大の美しいセットを見つけることです。`[l, r]`そして、そのような最大セットがいくつ存在するかを数えます。 各テスト ケースには 2 つの出力が必要です: 最大セットのサイズと、そのサイズを法としたセットの数です。`998244353`。 

重要なのは、美しい集合は本質的に可分性関係に基づく連鎖であることを認識することです。 これにより、各要素が前の要素の倍数であるシーケンスとしてセットを構造化することができます。 制約は、`r`まで`10^6`そして最大まで`2 * 10^4`テスト ケースは、サブセットの数が指数関数的に増加するため、すべてのサブセットを反復するアルゴリズムは不可能であることを意味します。 代わりに、間隔の長さまたは最大数の対数に関して線形または線形に近い時間で機能する方法が必要です。 

注意すべきエッジケースには、次のような間隔が含まれます。`l`に非常に近いです`r`、サイズ 1 のセットのみが許可される場合があります。たとえば、`l = 5, r = 5`出力する必要があります`1 1`。 もう一つの微妙なケースは次のような場合です。`l`は 1 であり、すべての数で割り切れます。 最小チェーンの開始点として 1 を含めるのを忘れた単純なアプローチでは、カウントを誤る可能性があります。 また、次のような 2 のべき乗が優勢な区間も`l = 1, r = 16`、アルゴリズムが倍数に沿って最大チェーン長を正確に識別する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、次のすべてのサブセットを生成しようとします。`[l, r]`すべてのペアの割り算条件を確認します。 これは概念的には単純で正しいですが、サイズの範囲が異なるため、すぐに実行不可能になります。`10^6`もっている`2^10^6`サブセット。 

より高速な解決策を明らかにする観察は、美しいセットを乗算チェーンとして見ることです。 すべての要素が互いに分割される集合はシーケンスとして表現できます。`x, 2x, 4x, ...`最小限の要素から始める`x`。 最大設定長は、2 を超えるまで繰り返し 2 を乗算することで決定されます。`r`。 これにより、問題は最長シーケンスの計算に軽減されます。`x * 2^k ≤ r`と`x ≥ l`。 最大セットの数は、すべての開始番号のカウントに対応します。`x`このような最大チェーン長を可能にします。 

チェーンの最大長は間隔の長さと 2 倍にのみ依存し、有効な開始点の数は 2 のべき乗の単純な算術で計算できるため、これを効率的に計算できます。 考えられる各サブセットのループを回避し、代わりに 2 のべき乗の構造を利用して、間隔サイズに対して対数時間で結果を生成します。

 ## アルゴリズムのチュートリアル

 1. 美しいセットの最大長を最大として計算します。`k`そのような`l * 2^(k-1) ≤ r`。 これは、ある数値から始まるチェーンで形成できる要素の最大数を見つけます。`x`を超えずに`r`。 私たちは取る`l`これより小さい数値は間隔内に出現できないため、最小の開始点として使用されます。 
2. 最大セット数のカウンターを初期化します。 チェーンの長さ`k`2 倍化プロセスの指数を定義します。 開始番号ごとに`x`から`l`まで`r // 2^(k-1)`、長さのチェーン`k`存在します。 そのようなものをすべて数えてください`x`値を使用して最大セットの合計数を計算します。 
3. モジュロを適用する`998244353`標準の整数制限を超える可能性があるため、カウントに制限されます。 
4. すべてのテスト ケースに対して手順 1 ～ 3 を繰り返します。 

これが機能する理由: 最大限に美しいセットはすべて、各数字が次の数字を分割する一連の数字でなければなりません。 セットのサイズを最大化する唯一の方法は、最小の数値から開始することです`x`これにより、すべての割り算条件が満たされることが保証され、他の数が割り算に含まれないことが保証されます。`[l, r]`チェーンを伸ばすことができます。 この範囲を超えて開始するチェーンは短すぎるか超過するため、完全なチェーンを許可する開始番号をカウントすると、すべての個別の最大セットが捕捉されます。`r`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

t = int(input())
for _ in range(t):
    l, r = map(int, input().split())
    length = 0
    x = l
    while x <= r:
        x *= 2
        length += 1
    max_size = length
    
    # Count starting numbers x for which x*2^(length-1) <= r
    count = r - (l * (2 ** (length - 1))) + 1
    print(max_size, count % MOD)
```このソリューションでは、最初に最小開始数値を繰り返し乗算して最大チェーン長を計算します。`l`を超えるまで2ずつ増加します`r`。 次に、その長さのチェーンが範囲内に収まるすべての開始番号をカウントします。`[l, r]`。 算術演算を使用すると、明示的にチェーンを構築したり、すべてのサブセットの可分性をチェックしたりすることがなくなります。

 ## 特殊なケース

 のために`l = r`、アルゴリズムは次のように計算します。`x = l`を超えるには 1 回乗算します`r`、チェーンの長さは 1 になります。カウントの計算は次のようになります。`r - l + 1 = 1`、シングルトン間隔を正しく処理します。 

のために`l = 1`、チェーンは 1 から開始でき、間隔全体で最大長が保証されます。 例えば、`l = 1, r = 22`7 つの開始番号を持つ長さ 5 が得られ、すべての可能な最大セットが正しくカウントされます。
