 ## 解決策
 ## 問題の理解

 正の整数の 3 倍を数えるように求められます`(a, b, n)`特定の奇妙な特性を満たすもの。 ここ、`a`1 から までの範囲で指定できます`A-1`、`b`1から`B-1`、 そして`n`1から`N-1`。 プロパティ自体は、連結すると`a`と`n`形成する`an`そして`n`と`b`形成する`nb`、次に分数`an/nb`等しい必要があります`a/b`。 連結とは、乗算や加算ではなく、数字を並べて配置することを意味します。 

例えば、`(1, 5, 9)`は有効です。`19 / 95`に減少します`1/5`。 入力は 3 つの整数で構成されます。`a`、`b`、 そして`n`。 出力は単一の整数、つまりこれらの範囲内のすべての有効なトリプルの数です。 

最初の制約は、`A`そして`B`まで可能です`10^5`、 そして`N`まで可能です`10^9`。 これは、すべての可能なトリプルを直接反復処理するアプローチでは、次のことが必要になることを意味します。`10^5 * 10^5 * 10^9`操作は不可能なほど大規模です。 ネストされたループも可能`a`そして`b`単独で、それぞれ最大`10^5`、100 億の演算を実行することになりますが、これは遅すぎます。 したがって、すべての組み合わせをブルートフォースすることなく、有効なトリプルを効率的に計算する方法が必要です。 

次の場合、微妙なエッジケースが発生します。`a`または`b`10 の倍数であるか、`n`連結に大きな影響を与えるのに十分な大きさです。 連結を加算または乗算として扱う単純なアプローチでは、誤った結果が生じる可能性があります。 たとえば、治療する`an`として`a*10 + n`失敗したとき`n`複数の桁があります。 

## アプローチ

 ブルートフォースの解決策は簡単です。考えられるすべてのことを繰り返します。`a`、`b`、 そして`n`それぞれの範囲内で、連結された数値を計算します`an`そして`nb`、等しいかどうかを確認します`an/nb == a/b`が成立する。 この方法は定義を直接実装するため原理的には正しいですが、反復回数が増加するにつれて計算上実行不可能になります。`A * B * N`、到達できる`10^19`最悪の場合。 

重要な洞察は、連結の等価性を純粋な算術形式に変換することです。 の桁数で表すと`n`として`d`、 それから`an = a*10^d + n`そして`nb = n*10^len(b) + b`。 方程式`an/nb = a/b`線形ディオファントス方程式として書き直すことができます`b * (a*10^d + n) = a * (n*10^len(b) + b)`。 展開して並べ替えると、`b*n - a*n*10^len(b) = a*b - a*b*10^d`、これを単純化すると、`n*(b - a*10^len(b)) = a*b*(10^d - 1)`。 

これはつまり`n`満たさなければなりません`n = a*b*(10^d - 1) / (b - a*10^d)`、次の場合にのみ有効です。`n`より小さい正の整数です`N`。 この観察により、問題は反復処理に帰着します。`a`そして`b`そして候補を計算する`n`直接的に、すべての反復を回避します`n`。

 ## アルゴリズムのチュートリアル

 1. すべての値を反復処理します。`a`1から`A-1`。 それぞれ`a`が分子候補です。 
2. それぞれについて`a`のすべての値を反復処理します。`b`1から`B-1`。 それぞれ`b`が候補の分母です。 
3. 桁数を計算する`d`のために`n`。 方程式は代数的に処理できるため、これは明示的に必要ありません。 
4. 方程式を解く`n*(10^len(b) - a) = a*b*(10^len(b) - 1)`のために`n`。 分母かどうかを確認します`(b - a*10^len(n))`はゼロではなく、分子を除算します。 
5. もし`n`は正の整数であり、`n < N`、このトリプルを有効なものとしてカウントします。 
6. 有効なトリプルをすべて合計します。 

このアルゴリズムが機能するのは、連結等式を単一の整数方程式に変換することで、次のような解が得られることが保証されるためです。`n`この方法で見つかると、有効な奇妙なトリプルが生成されます。 境界を直接チェックするので、`n`、過剰にカウントしたり、無効なトリプルを含めたりすることを避けます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def strange_triples(A, B, N):
    count = 0
    for a in range(1, A):
        for b in range(1, B):
            # find length of b
            len_b = len(str(b))
            denom = 10**len_b * a - b
            if denom <= 0:
                continue
            n = a * b * (10**len_b - 1) // denom
            if 1 <= n < N and a * 10**len(str(n)) + n == n * 10**len_b + b:
                count += 1
    return count

A, B, N = map(int, input().split())
print(strange_triples(A, B, N))
```ソリューションは各ペアに対して反復されます`(a, b)`そして候補を計算します`n`直接。 まず、変換された方程式の分母を計算し、それが正でない場合はスキップします。これにより、無効な結果が得られます。`n`。 次に計算します`n`そして、範囲と連結プロパティの両方を検証します。 整数演算を使用すると、浮動小数点精度の問題が回避されます。
