 ## 解決策
 ## 問題の理解

 サイズ _n_ × _m_ のグリッドとして表される長方形のトウモロコシ畑があり、各セルには特定のトン数のトウモロコシが含まれています。 父親は、この畑を 3 人の息子に分割して、各息子があらかじめ決められた量 (_A_、_B_、または _C_ トン) のトウモロコシを正確に受け取るようにしたいと考えています。 除算は、厳密に行または列の間にある水平または垂直の 2 本の平行線を使用して実行する必要があります。 結果として得られる各セクションには、少なくとも 1 つの正方形が含まれている必要があります。 

入力は、畑の寸法、各セル内のトウモロコシの量、および 3 人の息子の目標合計で構成されます。 出力は、結果として得られる 3 つの部分に正確な量 _A_、_B_、および _C_ が任意の順序で含まれるように 2 つの平行線を配置する方法の数です。 

_n_ と _m_ が両方とも最大 50 であることを考えると、合計を効率的に計算すれば、考えられるすべての行のペアを調べる総当りアプローチが実現可能です。 任意の四角形内の合計はプレフィックス合計を使用して一定時間で計算できるため、制限時間を超えることなく、考えられるすべてのパーティションをチェックする余裕があります。 希望する金額の 1 つがゼロの場合、特にフィールドにゼロが含まれている場合、微妙なエッジ ケースが発生します。 もう 1 つのエッジ ケースは、すべてのセルが等しい値を持ち、必要な量が同じである場合です。これにより、一意の合計を想定する単純な実装では、複数の有効なパーティションが失われる可能性があります。 

## アプローチ

 単純な総当たりアプローチは、水平線または垂直線のすべてのペアに対して反復されます。 水平線の場合、最初の線を行 1 と _n-1_ の間に配置し、2 番目の線を最初の線 +1 と _n-1_ の間に配置してみます。 垂直線の場合は、列に沿って同じことを行います。 系統の候補ペアごとに、結果として得られる 3 つのセクションのトウモロコシの合計を計算し、それらがマルチセット {_A_、_B_、_C_} と一致するかどうかを確認します。 この方法はフィールドが小さいため機能しますが、セルを反復処理して各セクションの合計を計算すると、時間計算量は O(n²・m + m²・n) になり、最悪の場合の 50×50 グリッドでは非効率的になります。 

重要な最適化は、プレフィックス合計を使用することです。 サイズ n × m の 2D プレフィックス合計配列を事前計算することにより、任意の長方形セクションの合計を一定時間で計算できます。 水平パーティションの場合、行 r1..r2 の合計は単にプレフィックスの合計の差であり、垂直パーティションの場合も同様に列の合計です。 これにより、複雑さが O(n² + m²) に軽減されます。これは、n² + m² ≤ 50² + 50² = 5000 であるため、許容範囲内です。合計を効率的に計算した後は、{_A_、_B_、_C_} のすべての順列を 3 つのセクションの合計に対してチェックするだけで済みます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | プレフィックス合計なしのブルート フォース | O(n²・m + m²・n) | お(1) | 遅すぎる |
 | プレフィックス合計で最適化 | O(n² + m²) | O(n・m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 寸法 _n_、_m_ およびフィールドグリッドを読み取ります。 トウモロコシの目標量 _A_、_B_、_C_ を読み取ります。 
2. 2D プレフィックス合計配列を計算します。`ps`どこ`ps[i][j]`は、左上隅からセル (i,j) までの四角形の合計を表します。 式は`ps[i][j] = field[i][j] + ps[i-1][j] + ps[i][j-1] - ps[i-1][j-1]`。 
3. 有効なパーティションを追跡するために、カウンターをゼロに初期化します。 
4. 水平パーティションを確認します。 線のペアごとに`r1`そして`r2`(1 ≤ r1 < r2 < n)、接頭語の合計を使用して 3 つの水平ストリップのトウモロコシの合計を計算します: 上の行 0..r1-1、真ん中の行 r1..r2-1、下の行 r2..n-1。 これらの合計のマルチセットが {_A_、_B_、_C_} に一致する場合、カウンターをインクリメントします。 
5. 垂直パーティションも同様にチェックします。 列のペアごとに`c1`そして`c2`(1 ≤ c1 < c2 < m)、プレフィックスの合計を使用して 3 つの垂直ストリップのトウモロコシの合計を計算します: 左列 0..c1-1、中央列 c1..c2-1、右列 c2..m-1。 これらの合計のマルチセットが {_A_、_B_、_C_} に一致する場合、カウンターをインクリメントします。 
6. カウンタを印刷します。 

機能する理由: プレフィックス合計配列により、すべての長方形領域の合計が O(1) で計算できることが保証されます。 すべての有効な行のペアを反復処理し、{_A_、_B_、_C_} のすべての順列に対して合計をチェックすることで、考えられるすべての有効な除算が 1 回だけカウントされることを保証します。 ループ境界により、各パーティションには少なくとも 1 つの行または列が含まれることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
field = [list(map(int, input().split())) for _ in range(n)]
A, B, C = map(int, input().split())

# compute prefix sums
ps = [[0]*m for _ in range(n)]
for i in range(n):
    for j in range(m):
        ps[i][j] = field[i][j]
        if i > 0:
            ps[i][j] += ps[i-1][j]
        if j > 0:
            ps[i][j] += ps[i][j-1]
        if i > 0 and j > 0:
            ps[i][j] -= ps[i-1][j-1]

def rect_sum(r1, c1, r2, c2):
    res = ps[r2][c2]
    if r1 > 0:
        res -= ps[r1-1][c2]
    if c1 > 0:
        res -= ps[r2][c1-1]
    if r1 > 0 and c1 > 0:
        res += ps[r1-1][c1-1]
    return res

targets = sorted([A, B, C])
count = 0

# horizontal partitions
for r1 in range(1, n):
    for r2 in range(r1+1, n):
        s1 = rect_sum(0, 0, r1-1, m-1)
        s2 = rect_sum(r1, 0, r2-1, m-1)
        s3 = rect_sum(r2, 0, n-1, m-1)
        if sorted([s1, s2, s3]) == targets:
            count += 1

# vertical partitions
for c1 in range(1, m):
    for c2 in range(c1+1, m):
        s1 = rect_sum(0, 0, n-1, c1-1)
        s2 = rect_sum(0, c1, n-1, c2-1)
        s3 = rect_sum(0, c2, n-1, m-1)
        if sorted([s1, s2, s3]) == targets:
            count += 1

print(count)
```プレフィックスの合計計算により、定数時間の四角形クエリが保証されます。 境界を慎重に処理して、off-by-one エラーを回避します。 比較の前に合計を並べ替えることで、_A_、_B_、_C_ の順序は重要ではないという事実に対処します。
