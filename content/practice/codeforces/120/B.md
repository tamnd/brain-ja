 ## 解決策
 ## 問題の理解

 円形のテーブルが与えられます。`n`各セクターにはクイズの質問が含まれています。 いくつかの質問はすでに寄せられており、 が付いています。`0`、その他はまだ利用可能で、 のマークが付いています。`1`。 矢印はセクターを指します`k`, そして目標は、次に尋ねられる質問の番号を決定することです。 矢印が指すセクターがすでに質問されている場合、ホストは時計回りの順序で次の未回答の質問を選択します。 番号付けはセクターから循環します`n`セクターに戻る`1`。 

入力は 2 つの整数で構成されます。`n`そして`k`、その後に次のリストが続きます。`n`各セクターのステータスを表す整数。 出力は、次に尋ねられる質問のセクター番号を表す単一の整数です。 

制約は小さいです。`n`最大 1000 まで増加する可能性があります。これは、最悪の場合、`n`クエリごとのチェック数は最大 1000 操作です。 

明らかではないエッジ ケースとしては、矢印が最後のセクターを指しており、次に利用可能な質問が先頭に回り込むか、矢印が利用可能な質問を直接指している (移動は必要ありません) ことが含まれます。 たとえば、次の場合`n = 5`、`k = 5`、配列は`[0, 1, 0, 1, 0]`、矢印はすでに質問されているセクターを指します (`0`）。 次の未回答のセクターは時計回りに`2`、 ない`5`、 なぜなら`5`すでに使用されています。 

## アプローチ

 ブルートフォースアプローチはシンプルかつ正確です。矢印で示されたセクターから開始して、質問がすでに行われているかどうかを確認します。 存在する場合は、利用可能な質問が見つかるまで、時計回りに一度に 1 セクターずつ移動し、必要に応じて折り返してください。 最悪の場合の複雑さは、`O(n)`、これは許容可能です`n ≤ 1000`。 このアプローチが機能するのは、少なくとも 1 つの質問が未回答であることが保証されているためです。 

問題の構造 (小さな円形配列) により、ペナルティなしで線形探索が可能になるため、最適解は基本的に総当たり法と同じです。 追加のデータ構造は必要なく、ラップアラウンドはモジュロ演算を使用して処理できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n) | O(n) | 承認済み |
 | 最適 | O(n) | O(n) | 承認済み |

 問題の制約が小さく、操作が簡単であるため、素朴で最適なアプローチがここに収束します。 

## アルゴリズムのチュートリアル

 1.読む`n`そして`k`。 調整する`k`配列へのアクセスを容易にするためにゼロベースのインデックスに変更します。 
2. 質問ステータスの配列を読み取ります。 それぞれの要素は`1`質問に答えがない場合と、`0`すでに質問されている場合。 
3. インデックスでループを開始します`k-1`そして時計回りに移動します。 反復ごとに、現在のセクターが利用可能かどうかを確認します。 
4. 現在のセクターに未回答の質問がある場合 (`1`)、1 から始まるインデックスを出力して停止します。 
5. 現在のセクターが尋ねられた場合 (`0`)、インデックスを 1 つインクリメントし、モジュロを使用します`n`必要に応じて先頭に戻ります。 

なぜうまくいくのか: 不変なのは、各ステップで答えのない質問が見つかるか、次の分野に進むかのどちらかであるということです。 この問題では少なくとも 1 つの未回答の質問が保証されるため、ループは常に正しいセクターで終了します。 モジュロ演算により、テーブルの循環的な性質を正しく処理できるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
a = list(map(int, input().split()))

# convert to zero-based index
idx = k - 1

while True:
    if a[idx] == 1:
        print(idx + 1)  # output 1-based index
        break
    idx = (idx + 1) % n
```コードは矢印で示されたセクターから開始され、応答がないかどうかを確認し、必要に応じて時計回りに移動します。 モジュロにより、最後のセクターを越えて移動すると最初のセクターにラップアラウンドすることが保証されます。 ゼロベースのインデックスを内部的に使用すると、配列へのアクセスと演算が簡素化されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | 最悪の場合、すべてのセクターを一度チェックする必要があるかもしれません。 |

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    idx = k - 1
    while True:
        if a[idx] == 1:
            print(idx + 1)
            break
        idx = (idx + 1) % n
    return output.getvalue().strip()

# Provided sample
assert run("5 5\n0 1 0 1 0\n") == "2", "sample 1"

# Custom cases
assert run("1 1\n1\n") == "1", "single sector, unanswered"
assert run("3 2\n0 0 1\n") == "3", "arrow points at asked, next is last sector"
assert run("4 4\n1 0 1 0\n") == "4", "arrow points at available, no move"
assert run("5 3\n0 0 0 1 0\n") == "4", "wrap around multiple zeros"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1 1\n1`|`1`| 単一セクターのエッジケース |
 |`3 2\n0 0 1`|`3`| 矢印は質問に向かって指します。次は最後のセクターです。 
|`4 4\n1 0 1 0`|`4`| 矢印は利用可能な質問を指します |
 |`5 3\n0 0 0 1 0`|`4`| 次の未回答のラップアラウンド検索 |

 ## 特殊なケース

 矢印が最後のセクターを指しており、以前のすべてのセクターがすでに質問されている場合、モジュロにより検索が最初から継続されることが保証されます。 入力用`5 5\n0 1 0 1 0`、検索はインデックスから移動します`4`に`0`、 それから`1`、これは最初に利用可能なセクターであり、正しく出力されます。`2`。 

未回答の質問がある単一セクターのテーブルの場合、`1 1\n1`、ループは反復なしですぐに利用可能な質問を見つけ、正しく出力します。`1`。 

このアルゴリズムは、未回答の質問が見つかるまで各セクターを常に時計回りの順序でチェックするという不変条件によってすべてのエッジ ケースを処理し、モジュロは円形テーブルの適切なラップを保証します。
