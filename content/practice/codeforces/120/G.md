 ## 解決策
 ## 問題の理解

 複数のチームとカードを使用したパーティー ゲーム「Boom」の簡易版をシミュレートしています。 がある`n`各チームには 2 人のプレーヤーがいます。 各プレイヤーは言葉を説明する能力を持っています (`a`）と言葉を理解する能力（`b`）。 のデッキがあります`m`それぞれのカードには複雑な単語が含まれています`c`。 ゲームは順番に進行し、プレイヤーはデッキの一番上からカードを取り出し、チームメイトに説明しようとします。 各ターンには一定の時間があります`t`。 

単語の説明に必要な時間は、カードの複雑さ、現在のターンのプレイヤーのスキル、チームがその単語に費やした時間によって異なります。 具体的にはカードの場合`k`選手から説明を受ける`j`チームの`i`他のチームメイトに`q`、効果的な説明時間は`max(1, c_k - (a_ij + b_iq) - d_ik)`、 どこ`d_ik`は、このチームがこのカードにすでに費やした累積時間です。 チームがターン内に単語を推測した場合、カードは取り除かれ、チームはポイントを獲得します。 そうでない場合は、ターンの残り時間が終了し、カードは山札の一番下に置かれます。 ゲームはすべてのカードが推測されるまで続きます。 

入力により、すべてのプレイヤーのスキル、カード、およびそれらの複雑さが提供されます。 出力には、各チームの得点数と推測した単語のシーケンスを順番にリストする必要があります。 

制約は中程度です。`n, m ≤ 100`そして`t ≤ 100`。 これにより、ターンの合計数が次のように制限されるため、ゲームの明示的なシミュレーションが可能になります。`m * n * 2`、ターンごとの各演算は単純な算術です。 エッジケースは、単語の複雑さが説明スキルと理解スキルの合計よりも低く、説明時間が 1 になる場合、またはターンの継続時間が必要な説明時間より短く、単語がデッキに戻される場合に発生します。 

単純な実装では、カードごとの累積時間を誤って管理する可能性があります (`d_ik`）またはプレーヤーを間違って循環させて、間違ったスコアリングや無限ループを引き起こします。 

## アプローチ

 ブルートフォース手法は、ルールに従ってゲームを直接シミュレーションするものです。 カードのキューを維持し、各プレイヤーのターンごとに、現在のカードを説明するのに必要な時間を計算します。 残りのターン時間内にカードを推測できた場合、チームのスコアをインクリメントし、カードを取り除き、その単語を記録します。 それ以外の場合は増分します`d_ik`ターン持続時間までにそのカードを山札の一番下に戻す。 すべてのカードが推測されるまで、プレーヤーを順番に循環させます。 このアプローチは文字通りゲームのルールを実装しているので正しいですが、チームごとの各カードの累積時間を注意深く追跡する必要があります。 操作回数はおおよそ`O(m * n * 2)`ターンの場合、これは制約 (`≤ 20,000`操作）。 

重要な洞察は、すべてのカードを推測するにはさまざまなプレイヤーが複数のターンを必要とする可能性があるため、カードの並べ替えやスキップに基づく最適化は必要なく、シミュレーションが安価であるということです。 課題は、推測された単語の順序を維持し、累積時間を正しく更新することです。

 | ブルートフォースシミュレーション | O(m * n * 2) | O(n * m + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力値の読み取り`n`そして`t`チーム数とターン期間。 
2. チームごとに、2 人のプレイヤーのスキル値を読み取り、ペアとして保存します`(a, b)`プレーヤー 1 とプレーヤー 2 用。 
3. カードの枚数を読み取ります`m`次に、各カードについて、その単語と複雑さを読み取ります。`c`。 
4. を初期化します。`deque`デッキを表すカードのインデックスを使用します。 初期化する`d_ik = 0`すべてのチームとカード、および各チームの推測された単語の空のリスト。 
5. デッキにカードがある場合:

 1. 各プレーヤーの順序: チーム 1 のプレーヤー 1、...、チーム n のプレーヤー 2、次の操作を実行します。 
2.セット`remaining_time = t`。 
3. その間`remaining_time > 0`そしてデッキは空ではありません:

 1.山札の前からカードを1枚取り出します。 
2. 説明に必要な時間を次のように計算します。`max(1, c_k - (a_ij + b_iq) - d_ik)`。 
3. 所要時間 ≤ Remaining_time の場合:

 - からの時間を差し引きます`remaining_time`。 
- チームが推測した単語を記録します。 
- チームのスコアを増やします。 
- デッキからカードを取り出します。 
4. それ以外の場合:

 - インクリメント`d_ik`このカードについては、`remaining_time`。 
- セット`remaining_time = 0`。 
- カードをデッキの一番下に移動します。 
6. 各チームの結果 (推測された単語の数と単語の順序) を出力します。 

機能する理由: 各ターンが貢献するため、すべてのカードは最終的に推測できるのに十分な有効時間を蓄積します。`t`その累積に`d_ik`それぞれのチームのために。 シミュレーションではターン順序、時間制限、スキルの貢献度が尊重されるため、ポイントと単語のシーケンスがゲームのルールに一致することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

n, t = map(int, input().split())
teams = []
for _ in range(n):
    a1, b1, a2, b2 = map(int, input().split())
    teams.append([(a1, b1), (a2, b2)])

m = int(input())
cards = []
for _ in range(m):
    word = input().strip()
    complexity = int(input())
    cards.append((word, complexity))

# Initialize
deck = deque(range(m))
d = [[0] * m for _ in range(n)]
guessed_words = [[] for _ in range(n)]
scores = [0] * n

while deck:
    for player in range(2):
        for team_id in range(n):
            remaining_time = t
            while remaining_time > 0 and deck:
                card_id = deck[0]
                word, c = cards[card_id]
                a, b = teams[team_id][player]
                other_player = 1 - player
                _, b_other = teams[team_id][other_player]
                required_time = max(1, c - (a + b_other) - d[team_id][card_id])
                if required_time <= remaining_time:
                    remaining_time -= required_time
                    guessed_words[team_id].append(word)
                    scores[team_id] += 1
                    d[team_id][card_id] += required_time
                    deck.popleft()
                else:
                    d[team_id][card_id] += remaining_time
                    remaining_time = 0
                    deck.rotate(-1)

for i in range(n):
    print(scores[i], *guessed_words[i])
```コードはアルゴリズムに厳密に従います。 の`deque`カードを効率よく下に移動できます。 の`d`アレイは、カードごとのチームごとの累積時間を追跡します。 ネストされたループはプレイヤーのターン順序を強制し、`max(1, ...)`1 秒未満を要する単語がないことを保証します。 

細心の注意が必要です`remaining_time`そして`d[team][card]`オフバイワンエラーを回避するために更新します。
