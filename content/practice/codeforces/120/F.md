 ## 解決策
 ## 問題の理解

 私たちはクモのおもちゃのコレクションを与えられました。 それぞれのクモは木であり、糸 (エッジ) で接続されたビーズ (ノード) で表されます。 蜘蛛と$k$ビーズが持っています$k-1$すべてのビーズが接続され、サイクルが存在しないようにビーズを接続する文字列。 Petya は、クモ全体にいくつかのビーズを特定することでクモを接着し、より大きなツリーを形成することができます。 スパイダーまたは接着されたコレクションの「長さ」は、2 つのビーズを接続するパスに沿ったエッジの合計として測定される、2 つのビーズ間の最長距離です。 

タスクは、結果として得られるツリーの長さが最大になるように、指定されたすべてのスパイダーを 1 つのツリーに接着し、その長さを報告することです。 

入力によりスパイダーの数が得られます$n$その後に各クモの説明が続きます。 各クモの説明はビーズの数から始まります$k$、 それから$k-1$どのビーズが接続されているかを説明するペア。 各スパイダー内のビーズには 1 から 1 までの番号が付けられています。$k$。 

制約は中程度です。$n \le 100$各クモには最大 100 個のビーズがあります。 したがって、ビーズの総数は最大でも 10,000 個で、エッジの総数はわずかに少なくなります。 これにより、おおよそのアルゴリズムが可能になります。$O(\text{total beads})$または$O(\text{total beads} \cdot n)$複雑。 

1 つのスパイダーが非常に長く (鎖)、もう 1 つのスパイダーがコンパクト (星のように) である場合、明らかではないエッジ ケースが発生します。 クモを任意に接着する単純な貪欲な方法では、全長が大幅に過小評価される可能性があります。 たとえば、小さな星を長いチェーンの中央に接着すると、端点に接着した場合に達成できる最大距離よりも短縮される可能性があります。 

## アプローチ

 ブルートフォースアプローチは、あるスパイダーのビーズを別のスパイダーのビーズと再帰的に識別するあらゆる可能な方法を検討することです。 組み合わせごとに、結果として得られるツリーの長さを計算します。 これは明らかに実行不可能です。合計 10,000 個のビーズを使用すれば、クモを接着する方法は天文学的にたくさんあります。 ブルート フォースはすべての接着剤の位置を探索するため、理論的には正しいだけですが、計算的には失敗します。 

重要な洞察は、結果として生じるツリーの長さを最大化するには、クモをその「最も深い」点で接着するのが最適であるということです。 スパイダーの深さは、ビーズから最も遠いビーズまでの距離です。 正式には、木の最長の経路はその直径と呼ばれ、常に 2 つの端点を結びます。 直径を最大化するために 2 本の木を接着する場合、2 本の木の直径の端点で接続することのみを考慮する必要があります。 さらに、あるスパイダーを別のスパイダーに接着する場合、達成可能な最大直径は、最初のスパイダーの直径、2 番目のスパイダーの直径、またはそれらの深さの合計に 1 (それらを接続するエッジ) を加えたものになります。 したがって、各クモについて、選択した「ルート」ビーズからの直径と深さを知る必要があるだけです。 

これにより、問題は単純な貪欲な戦略に集約されます。つまり、スパイダーを深さ (または直径) で分類し、残っている最大のスパイダーを現在の構造の最も深いビードに繰り返し接着し、結合された直径を更新します。 これは効率的であり、複雑さはビーズの総数に比例します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(ビーズの合計)) | O(ビーズの合計) | 遅すぎる |
 | 最適 | O(ビーズの合計) | O(ビーズの合計) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各スパイダーについて、その直径を計算します。 2 つの BFS トラバーサルを実行します。最初は任意のビードから最も遠いビードを見つけます。$u$、その後から$u$一番遠いビーズを見つけるために$v$。 距離$d(u, v)$直径です。 端点からの深さは、この距離の半分、または端点からの最大距離です。 
2. 各スパイダーの直径と「高さ」(接着点から葉までの最大距離) を保存します。 最初に、接着点を直径の 1 つの端点として選択できます。 
3. クモを高さの降順に並べ替えます。 これにより、最も背の高いスパイダーが最初に接着されることが保証され、全体の直径を大きくできる可能性が最大になります。 
4. 結果として得られる構造の現在の直径の変数を初期化します。 最初のスパイダーの直径から始めます。 
5. 残りの各スパイダーを現在の構造に繰り返し接着します。 新しい潜在的な直径は、以前の直径、新しいスパイダーの直径、または現在の構造と新しいスパイダーの高さの合計に 1 (接続エッジ) を加えたものになります。 それに応じて現在の直径を更新します。 
6. すべてのスパイダーを接着したら、結果の直径を出力します。 

これが機能する理由: 木の直径は最長のパスによって定義されます。 端点で木を接着すると、高さの合計が直径に最大限に寄与するようになります。 他の接着点ではパスが短くなります。 残りの最も高いスパイダーを常に接続することで、新しいエッジが最適に直径を増加させることが保証されます。 

## Python ソリューション```python
import sys
from collections import deque
input = sys.stdin.readline

def bfs(farthest_from, n, adj):
    dist = [-1] * n
    q = deque()
    q.append(farthest_from)
    dist[farthest_from] = 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    farthest_node = max(range(n), key=lambda x: dist[x])
    return farthest_node, dist[farthest_node]

def spider_info(n, edges):
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
    u, _ = bfs(0, n, adj)
    v, diameter = bfs(u, n, adj)
    return diameter, (diameter + 1) // 2  # diameter, height from one endpoint

def main():
    n = int(input())
    spiders = []
    for _ in range(n):
        data = list(map(int, input().split()))
        k = data[0]
        edges = [(x-1, y-1) for x, y in zip(data[1::2], data[2::2])]
        spiders.append(spider_info(k, edges))
    
    spiders.sort(key=lambda x: x[1], reverse=True)
    cur_diameter, cur_height = spiders[0]
    
    for dia, height in spiders[1:]:
        cur_diameter = max(cur_diameter, dia, cur_height + height + 1)
        cur_height = max(cur_height, height + 1)
    
    print(cur_diameter)

if __name__ == "__main__":
    main()
```BFS 関数は、指定された開始ノードから最も遠いノードを検索し、最も遠いノードとその距離の両方を返します。 の`spider_info`関数は、各スパイダーの直径と高さを計算します。 高さで並べ替えると、最大のクモが最初に貢献することが保証されます。 現在の直径を高さの合計に 1 を加えた値で更新すると、直径が最適に成長することが保証されます。 現在の高さを増やす`height + 1`次のスパイダーを接着するときの接続エッジを考慮します。
