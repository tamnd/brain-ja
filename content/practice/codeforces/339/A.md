 ## 解決策
 ## 問題の理解

 入力は、すべての数値が次のいずれかである合計を表す文字列です。`1`、`2`、 または`3`、数値はプラス記号で区切られています。 たとえば、次の文字列`3+2+1+3`は 4 つの加数を表します。 

Xenia は、数値が非降順で表示される場合にのみ式を評価できます。 私たちの仕事は合計を計算すること自体ではありません。 代わりに、すべての数値が一致するように既存の数値を並べ替える必要があります。`1`が最初に来て、その後にすべてが来ます`2`では、すべて`3`s を実行し、結果の式を同じファイルに出力します。`a+b+c`形式。 

入力長は最大 100 文字です。 すべての数字が 1 文字を占め、すべての区切り文字が 1 文字を占めるため、数字は最大で約 50 個になります。 このような小さな制約は、ほぼすべての合理的なアプローチが十分に高速であることを意味します。 並べ替えベースのソリューションでも即座に実行されます。 

主な課題は、文字列形式を正しく処理することです。 文字列全体ではなく、数値を並べ替える必要があります。 すべての文字をソートする不注意な実装では、数字とプラス記号が混在し、無効な式が生成されます。 

特殊なケースの 1 つは、式に数値が 1 つだけ含まれている場合です。 

入力：```
2
```出力：```
2
```元の構造を超えて挿入するプラス記号はありません。 分割と結合は引き続き正しく機能します。 

もう 1 つの特殊なケースは、すべての数値がすでに並べ替えられている場合です。 

入力：```
1+1+2+3
```出力：```
1+1+2+3
```アルゴリズムは式を変更しないままにする必要があります。 

別のケースは、すべての数値が同一である場合です。 

入力：```
3+3+3
```出力：```
3+3+3
```並べ替えによって結果が変更されることはなく、重複した値は保持される必要があります。 

## アプローチ

 強引な考え方では、数値の考えられるすべての順序を生成し、その順序が減少していないかどうかを確認し、最初の有効な順序を出力することになります。 これが機能するのは、正しい答えが単に指定された加数の順列の 1 つであるためです。 

問題は、順列が階乗的に増加することです。 数字が 50 個ある場合、`50!`可能な順序は天文学的に大きく、完全に実行不可能です。 

問題の構造からは、はるかに簡単な観察が得られます。 表示される値は次のとおりです。`1`、`2`、 そして`3`、そして Xenia はそれらを非降順で並べたいと考えています。 すべての小さい値が大きい値の前に現れる場合、シーケンスは非減少となります。 つまり、順列間で検索する必要はまったくありません。 数値を抽出し、並べ替えて、式を再構築できます。 

ソートは一意の非減少配列を直接生成するため、問題は簡単な実装タスクになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力文字列を読み取ります。 
2. 以下を使用して文字列を分割します。`'+'`区切り文字として。 

これにより、すべての数値が次のような個別の文字列として抽出されます。`["3", "2", "1"]`。 
3. 結果のリストを並べ替えます。 

場所をすべて並べ替える`1`最初に、それからすべて`2`では、すべて`3`s、これはまさに必要な順序です。 
4. 並べ替えた数値を次のように結合して戻します。`'+'`。 

これにより、有効な式が元の形式で再構築されます。 
5. 結果を印刷します。 

### なぜ効果があるのか

 式は数字だけで構成されています`1`、`2`、 そして`3`。 有効な回答には、入力とまったく同じ複数の数値セットが含まれている必要があります (並べ替えのみ)。 

抽出された数値を並べ替えると、すべての要素が次の要素以下であるシーケンスが生成されます。 それがまさに非減少次数の定義です。 並べ替えでは数値の削除も重複も行わないため、結果の式には元の加数が正確に含まれ、Xenia の要件を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s = input().strip()

numbers = s.split('+')
numbers.sort()

print('+'.join(numbers))
```最初のステップでは、式を文字列として読み取ります。 使用する`strip()`末尾の改行文字を削除します。 

への呼び出し`split('+')`キー解析操作です。 個々の文字を処理するのではなく、数値を個別の要素として直接抽出します。 

次に、リストは辞書順に並べ替えられます。 可能な値は次のとおりであるため、`"1"`、`"2"`、 そして`"3"`、辞書編集上の順序は数値の順序と一致します。 

ついに、`'+'.join(numbers)`必要な区切り文字を使用して式を再構築します。 これにより、特別な場合を除いて、単一数値式と複数数値式の両方が自動的に処理されます。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    s = input().strip()
    numbers = s.split('+')
    numbers.sort()
    print('+'.join(numbers))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.strip()

# provided sample
assert run("3+2+1\n") == "1+2+3", "sample 1"

# minimum-size input
assert run("1\n") == "1", "single number"

# already sorted
assert run("1+1+2+3\n") == "1+1+2+3", "already sorted"

# all equal values
assert run("3+3+3\n") == "3+3+3", "all equal"

# reverse order
assert run("3+3+2+2+1+1\n") == "1+1+2+2+3+3", "full sorting"

# mixed duplicates
assert run("2+1+3+1+2\n") == "1+1+2+2+3", "duplicates preserved"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1`|`1`| 最小サイズの入力 |
 |`1+1+2+3`|`1+1+2+3`| すでにソートされたシーケンス |
 |`3+3+3`|`3+3+3`| すべて等しい値 |
 |`3+3+2+2+1+1`|`1+1+2+2+3+3`| 完全な並べ替え |
 |`2+1+3+1+2`|`1+1+2+2+3`| 重複の処理 |

 ## 特殊なケース

 単一の数値入力を考えてみましょう。```
2
```アルゴリズムは以下を実行します。```
"2".split('+')
```これにより次のものが生成されます。```
["2"]
```並べ替えは何も行わず、結合すると次の結果が返されます。```
2
```特別な処理を行わなくても、出力は正しいままになります。 

すでにソートされている式を考えてみましょう。```
1+1+2+3
```分割後:```
["1", "1", "2", "3"]
```並べ替えるとリストは変更されません。 最終出力は入力と同一であり、これが望ましい動作です。 

同一の値のみを含む式を考えてみましょう。```
3+3+3
```分割すると次のようになります。```
["3", "3", "3"]
```並べ替えでは、3 つの出現箇所がすべて保持されます。 結合再構築:```
3+3+3
```これにより、アルゴリズムが加数を失ったり複製したりすることがなく、元の数値のマルチセットが常に保持されることが確認されます。
