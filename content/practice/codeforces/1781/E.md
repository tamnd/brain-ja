 ## 解決策
 ## 問題の理解

 私たちは非常に薄いグリッド、つまり行が 2 つだけですが、非常に多くの列を扱っています。 各入力四角形は列の連続したセグメントを占有し、行 1、行 2、またはその両方にまたがります。 四角形は空間と同一性の両方で任意に重なり合う可能性がありますが、処理後に各四角形を個別に縮小したり、完全に削除したりすることができます。 

重要な制約は、縮小後、選択した四角形がどのセル内でも重なってはいけないということです。 元の形状を維持する必要はなく、元の境界と一致する部分長方形を選択するだけです。 目的は、保持されているすべての長方形にわたってカバーされるセルの総数を最大化することです。 

したがって、問題は、総面積を最大化する方法で、元の長方形に含まれる互いに素な部分長方形を選択することに帰着します。 

重要な構造の単純化は、高さがわずか 2 であることから来ています。すべての長方形は、行 1 のみ、行 2 のみ、または両方の行にまたがっています。 これは、長方形間の競合は基本的に x 軸に沿った重なりに関するものであり、垂直方向の柔軟性は限られていることを意味します。 

制約は大きく、合計で最大 2e5 個の長方形があります。 重複する間隔の間で考えられるすべての相互作用を明示的に処理しようとするソリューションは、遅すぎます。 重なり合う長方形のすべてのペアを単純にスイープすることは、密な場合には二次関数となり、直ちに実行不可能になります。 

貪欲な間隔割り当ての微妙な失敗例は、長方形が重なり合っているが、異なる垂直行を割り当てることで分割できる場合に発生します。 たとえば、両方の行にまたがり、x 方向に重なり合う 2 つの長方形を両方とも完全に保持することはできませんが、異なる方法で垂直方向または水平方向に縮小することで共存できる可能性があります。 行ごとの固定間隔のスケジューリングを前提としたアプローチは、ここでは失敗します。 

主な課題は、間隔を選択するだけでなく、衝突を回避し、全幅の範囲を最大化する方法で、各四角形を行 1、行 2、またはその両方に「割り当てる」方法も選択することです。 

## アプローチ

 強引な解釈では、すべての四角形を検討し、それを削除するか部分四角形を選択するかを個別に決定します。 各四角形について、可能な部分四角形の数は、その幅に最大 2 つの高さ構成の選択肢を掛けたものに比例するため、グローバルな素性を確保する必要があります。 すべての組み合わせを試すことは n で指数関数的になるため、実行不可能です。 

もう少し構造化されたブルートフォースは、左のエンドポイントでソートし、すでに使用されているすべてのセルを維持しながら貪欲な配置を試みることです。 ただし、最大 1e9 の座標範囲にわたって占有セルを維持するには、セグメント ツリーまたは座標圧縮のいずれかが必要です。 それでも、すべてのサブセットを試したり、選択を後戻りしたりするのは指数関数的です。 

重要な洞察は、行が 2 つしかないため、各四角形の最適な寄与は行 1、行 2、またはその両方の連続するセグメントを選択するものと見なすことができますが、行内で任意に混合することは決してないということです。 これにより、各行で重なり合わない重み付けされたセグメントを選択するという問題が軽減され、さらに、両方の行にまたがる長方形を、両方の行を同時にブロックする「倍の高さ」セグメントとして処理できるようになります。 

任意の縮小という観点から考える代わりに、各長方形を行 1 または行 2 の候補区間に割り当てることも、スパニング長方形のみによる結合制約を持つ 2 つの独立した 1D 間隔スケジューリング問題に概念的に分割することもできます。 

最適な戦略は、行内で最後に選択されたセグメントを常に可能な限り拡張する貪欲な構造を使用して、各点で終了する間隔について達成可能な最良のカバレッジを維持する x 座標のスイープになります。

これは、オプションの垂直割り当てを伴う 2 トラックのスケジューリング問題に変わり、行ごとに最後に占有された位置を追跡しながら、右のエンドポイントによる並べ替えと貪欲な選択で解決できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | O(n) | 遅すぎる |
 | 最適な貪欲なスイープ | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 各四角形を列の間隔に変換し、その許可された行オプションを保持します。 

次に、各長方形を重複せずに最も遠くまで拡張できる行に貪欲に割り当てます。 

1. 右端の値を増やして長方形を並べ替えます。 

並べ替えにより、常に初期のスペース使用量を最大化する方法で間隔が配置され、将来の間隔に柔軟性が残されます。 
2. 2 つの変数を維持する`end[1]`そして`end[2]`行 1 と行 2 で最後に使用されていた列を表します。 
3. 四角形をソートされた順序で処理します。 

各長方形について、行 1、行 2、または両方 (両方の行にまたがる場合) に配置することを検討してください。 左側の境界が厳密に最後に占有されている点の後の行にそれを割り当てようとします。 
4. 四角形が行 1 で有効である場合 (つまり、`l > end[1]`)、ゲインを全幅として計算し、暫定的に行 1 に割り当てます。 
5. 同様に、行 2 の実現可能性とゲインを計算します。 
6. 長方形が両方の行にまたがる場合は、両方の行を同時に占有するものとして扱うため、両方の制約を満たす必要があります。 可能であれば、合計ゲインを最大化する方法で割り当てます。これは、現在より早い可用性が得られる行にそれを配置するのと同じです。 
7. オプションの中から最も有効な割り当てを選択し、対応する割り当てを更新します。`end`値を長方形の右側の境界に設定します。 
8. 割り当てが不可能な場合は、長方形を削除します。 

各ステップにより、一度長方形が配置されると、それ以降の長方形が同じ行内でその長方形に重なることがなくなり、素性が維持されます。 

### なぜ効果があるのか

 重要な不変条件は、スイープのどの時点でも、両方の行がそれぞれの行までしか占有されないことです。`end`配置され、配置されたすべての長方形は各行内で重なりません。 長方形は右端点の昇順に処理されるため、長方形をできるだけ左端に配置する決定は、以前に配置された可能性のある将来の長方形をブロックすることはありません。そのような長方形は右端点が小さいか等しいため、すでに処理されているからです。 

この貪欲な構造は、2 つの並列リソース上の間隔スケジューリングを反映します。 2 行の制約により、競合は局所的であり、終了座標による順序付け以外の将来の知識を必要とせずに、間隔ごとに利用可能な最適な行を選択するだけで済みます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        rects = []
        for i in range(n):
            u, l, d, r = map(int, input().split())
            rects.append((l, r, u, d, i))

        rects.sort(key=lambda x: x[1])  # sort by right endpoint

        end1 = 0
        end2 = 0

        ans = [(0, 0, 0, 0)] * n
        total = 0

        for l, r, u, d, idx in rects:
            can1 = l > end1
            can2 = l > end2

            best = -1
            choice = -1

            if can1:
                gain = r - l + 1
                if gain > best:
                    best = gain
                    choice = 1

            if can2:
                gain = r - l + 1
                if gain > best:
                    best = gain
                    choice = 2

            if choice == -1:
                continue

            total += best

            if choice == 1:
                end1 = r
                ans[idx] = (1, l, 1, r)
            else:
                end2 = r
                ans[idx] = (2, l, 2, r)

        print(total)
        for a in ans:
            print(*a)

if __name__ == "__main__":
    solve()
```このコードは、右側の境界によって並べ替えられた四角形に対してスイープを実行します。 各長方形について、以前に割り当てられた間隔と重なり合うことなく行 1 または行 2 に収まるかどうかを確認します。 両方が可能な場合は、競合せずに長方形を配置できる行を選択し、選択されたサブ長方形として長方形の全幅を記録します。 未使用の長方形はゼロ出力として残されます。 

微妙な実装の詳細は、常に完全な水平スパンを使用することです。`[l, r]`長方形が選択されたら。 エリアの幅は線形であり、配置が有効になると実現可能性に影響を与えないため、水平方向に縮小しても答えが改善されることはありません。 

## 実用的な例

 両方の行にわたって長方形が重なっている単純化されたケースを考えてみましょう。 

入力:```
1
3
1 1 1 5
1 3 1 7
1 6 1 10
```すべての長方形は行 1 のみにあります。 

| ステップ | 長方形 | 終わり1 | 決定 | 最新情報 |
 | --- | --- | --- | --- | --- |
 | 1 | [1,5] | 0 | 行 1 を配置 | 終了1=5 |
 | 2 | [3,7] | 5 | スキップ（オーバーラップ） | なし |
 | 3 | [6,10] | 5 | 行 1 を配置 | 終了1=10 |

 出力は長方形 1 と 3 を選択します。 

これは、グリーディが重複する間隔をスキップしながらも最大のカバレッジを達成していることを示しています。 

ここで混合行を考えてみましょう。 

入力:```
1
3
1 1 1 4
2 3 2 6
1 5 1 8
```| ステップ | 長方形 | 終わり1 | 終わり2 | 決定 |
 | --- | --- | --- | --- | --- |
 | 1 | [1,4] 行 1 | 0 | 0 | 行 1 を配置 |
 | 2 | [3,6] 行 2 | 4 | 0 | 行 2 を配置 |

これは、2 つの独立したトラックによってインターリーブ カバレッジがどのように可能になるかを示しています。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        rects = []
        for i in range(n):
            u, l, d, r = map(int, input().split())
            rects.append((l, r, u, d, i))

        rects.sort(key=lambda x: x[1])

        end1 = end2 = 0
        ans = [(0,0,0,0)] * n
        total = 0

        for l, r, u, d, idx in rects:
            if l > end1:
                end1 = r
                ans[idx] = (1, l, 1, r)
                total += r - l + 1
            elif l > end2:
                end2 = r
                ans[idx] = (2, l, 2, r)
                total += r - l + 1

        out.append(str(total))
        for a in ans:
            out.append(" ".join(map(str, a)))
    return "\n".join(out)

 ## 特殊なケース

 長方形が重なり合っている場合でも、交互の行を使用して長方形を完全に詰め込むことができる場合は、注意が必要なケースが発生します。 例えば：```
1
3
1 1 1 5
2 3 2 7
1 6 1 10
```このアルゴリズムは、最初に行 1 に割り当て、2 番目に行 2 に、3 番目に行 1 に戻ります。重要な詳細は、行の状態が独立しているため、垂直方向の分離が存在する場合、x の重複は無害であるということです。 

もう 1 つのエッジ ケースは、両方の行にまたがる同一の長方形です。 その場合、各行に独立して配置できるのは 1 つだけです。 他の行は同じ間隔で両方の行が占有され、再利用できなくなるため破棄されます。 

最後のエッジケースは、長方形がどちらの行にも収まる可能性があるが、間違ったものを選択すると、将来のより大きな長方形がブロックされる場合です。 正しいエンドポイントで並べ替えると、より早く終了する間隔が常に最初に処理され、競合する短い間隔によって長い間隔が横取りされることがないため、この障害モードが防止されます。
