 ## 解決策
 ## 問題の理解

 私たちは箱のような形をした長方形の部屋の中で作業をしています。 床上の点はラップトップが置かれている場所を示し、天井の真上の点はプロジェクターが吊り下げられている場所を示します。 ケーブルはこれら 2 点を接続する必要がありますが、部屋の表面に沿ってのみ移動するように制約されています。つまり、ケーブルは床、壁、天井の上を移動でき、常にボックスの端に平行な方向に従う必要があります。 

タスクは、これらの制限の下でラップトップとプロジェクター間の可能な最短のケーブル長を計算することです。 ケーブルはボックスの内部を貫通できないため、パスは直方体の面上にある軸に沿ったセグメントで構成する必要があります。 

重要な制約は、組み合わせではなく幾何学的です。 私たちは、3D ボックスの表面上で、向かい合う面にある 2 点間のマンハッタン スタイルの最短パスを効果的に見つけています。 

テスト ケースごとの入力サイズは小さく、最大 10^4 ケースであるため、各ケースを一定時間で解決する必要があります。 これにより、サーフェス上のグラフ検索やシミュレーションが除外されます。 解決策は、少数の固定数の候補表面展開のみが重要であることを認識することから得られる必要があります。 

2 つの点の水平投影が 1 つの座標に揃うと、微妙なエッジ ケースが現れます。 このような場合、複数の候補パスが同じジオメトリに崩れ、個別の座標を仮定する単純な式では、最適なルートが過大にカウントされたり、最適なルートが欠落したりする可能性があります。 

## アプローチ

 ブルート フォース ビューは直方体表面をグラフとして扱います。エッジと面のすべての点がノードであり、面に沿った移動はマンハッタン コストで許可されます。 表面をグリッドに離散化し、最短経路アルゴリズムを実行することができます。 これは原理的には正しいですが、状態の数は離散化の解像度とともに増加します。また、端点は連続座標であるため、粗い離散化さえも不要になります。 これにより、ブルートフォースが使用できなくなります。 

重要な観察は、ボックス表面上の 2 点間の最適なパスは、常に 2 つの隣接する面を平面に展開することに対応するということです。 展開すると、パスは 2 つの平面点間のマンハッタンの直線距離になります。 意味のある展開は一定数のみ存在し、それぞれがケーブルが通過する隣接する面のペアの選択に対応します。 

床点 (a、b、0) と天井点 (f、g、h) の場合、最適なパスは常に、床から垂直の壁を上って、天井まで移動することで構成されます。 最短ルートは、左壁、右壁、前壁、後ろ壁のいずれを経由するかによってのみ決まり、これはいくつかの絶対的な差の式に変換されます。 

これにより、問題は、マンハッタン距離の候補の少数のセットを評価し、最小値を取得することになります。

 ## アルゴリズムのチュートリアル

 まず、有効なパスは床から壁に移動し、次におそらくその壁を横切って、最後に天井に到達する必要があることを観察します。 移動は面上の軸に沿ったエッジに制限されるため、すべてのパスは床の長方形を「出る」方向の選択に対応します。

1. 床面の水平方向の間隔、つまり |a - f| を計算します。 および |b - g|。 これらは、2 つの床軸に沿った 2 点の投影がどれだけ離れているかを表します。 
2. 長方形の辺に沿った壁を使用して、床と天井の間を移動する 4 つの可能な方法を検討します。 それぞれの選択は、ボックスの片側の周囲にパスを配線することに対応します。 
3. 候補ルートごとに、3D パスを 2D マンハッタン距離式に変換します。 すべてのルートは、1 つの水平方向の差、1 つの垂直方向の差、および高さ h の合計に寄与します。 
4. すべての候補式を評価し、最小値を取得します。 

一定数の式だけが必要な理由は、最短のサーフェス パスは 2 つの隣接する面の 1 つの展開に対応する必要があり、単一の壁の境界を介して床と天井を接続するそのような展開は 4 つだけであるためです。 

### なぜ効果があるのか

 床から天井までの有効なサーフェス パスは、壁を通って z = 0 から z = h への垂直遷移を 1 つだけ通過する必要があります。 トランジション ポイントがボックスの端に固定されると、各面の残りのパスは直線のマンハッタン セグメントになります。 考えられるすべての壁のエッジを最小化すると、一定の構成セットを比較することになり、内部の迂回は平らな面上のマンハッタン パスを改善できません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        w, d, h = map(int, input().split())
        a, b, f, g = map(int, input().split())

        dx = abs(a - f)
        dy = abs(b - g)

        # four candidate surface routes
        ans = min(
            dx + b + g + h,
            dx + (d - b) + (d - g) + h,
            dy + a + f + h,
            dy + (w - a) + (w - f) + h
        )

        print(ans)

if __name__ == "__main__":
    solve()
```この実装では、水平方向の差が事前計算され、4 つの幾何学的構成が評価されます。 各式は、床と天井の間の移行面として部屋の 4 つの垂直側面の 1 つを選択することに対応します。 b + g または (d - b) + (d - g) などの追加された項は、高さ h を垂直に通過する前に、点から選択した壁の端まで歩くことを表します。 

よくある間違いは、投影内で最も近い壁だけでなく、4 つの壁のいずれでもトランジションが発生する可能性があることを忘れていることです。 もう 1 つは、マンハッタンの直線距離に高さを加えたものを仮定するものですが、単純な投影法が示唆するよりも両方の点が別の壁に近い場合は失敗します。 

## 実用的な例

 サンプルセットから 2 つのケースを追跡します。 

### 例 1

 入力: w=55、d=20、h=29、a=23、b=10、f=18、g=3

 | 式 | 値 |
 | --- | --- |
 | dx + b + g + h | 5 + 10 + 3 + 29 = 47 |
 | dx + (d-b) + (d-g) + h | 5 + 10 + 17 + 29 = 61 |
 | dy + a + f + h | 7 + 23 + 18 + 29 = 77 |
 | dy + (w-a) + (w-f) + h | 7 + 32 + 37 + 29 = 105 |

 最小値は 47 です。 

これは、一方の側壁への最も近い水平投影を介した配線がすべての選択肢を支配していることを裏付けています。 

### 例 2

 入力: w=20、d=10、h=5、a=1、b=5、f=2、g=5

 | 式 | 値 |
 | --- | --- |
 | dx + b + g + h | 1 + 5 + 5 + 5 = 16 |
 | dx + (d-b) + (d-g) + h | 1 + 5 + 5 + 5 = 16 |
 | dy + a + f + h | 0 + 1 + 2 + 5 = 8 |
 | dy + (w-a) + (w-f) + h | 0 + 19 + 18 + 5 = 42 |

 最小値は 8 です。 

これは、b が g に等しい縮退ケースを示しており、垂直方向の位置合わせが無関係となり、壁への直接遷移が可能になります。

 ## 特殊なケース

 両方の点が 1 つの軸上で同じ投影を共有する場合、一部の候補ルートが崩れ、複数の式が等しくなります。 絶対差がゼロになり、最小値でも有効な壁パスが選択されるため、アルゴリズムはこれを自然に処理します。 

点がすでに境界に近づいている場合、その壁を含む式は大幅に減少し、最小値がその側を正しく選択します。 式の構造により、すべての候補が壁を通過する表面の通過と垂直方向の移行を明示的に強制するため、内部を通過する無効なショートカットが考慮されることはありません。
