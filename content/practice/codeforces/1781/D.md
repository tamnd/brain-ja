 ## 解決策
 ## 問題の理解

 シフト値を選択できます$x$、そしてこのシフトは、追加することによって固定セット内のすべての数値を変換します。$x$。 シフト後、結果の数値のうちいくつが完全な平方になるかを検査します。 課題は選択することです$x$どこからでも$0$に$10^{18}$この数が最大になるようにします。 

問題を別の見方で見ると、それぞれの元の数値が$a_i$正方形に変える候補シフトのファミリーを定義します。 もし$a_i + x = t^2$、 それから$x = t^2 - a_i$。 したがって、すべての要素は「適切なシフト」のまばらなセットに寄与しており、これらのセットのできるだけ多くに単一のシフトが現れることが必要です。 

非常に重要な意味で、制約は小さいです。 テストごとに最大 50 個の数値、全体で最大 50 個の数値を使用すると、要素のペアに対して 2 次または軽度 3 次の列挙を行うことができますが、可能な限りすべての反復を伴うものはすべて可能です。$x \le 10^{18}$不可能です。 この構造は、整列された各ペアが特定のシフトを固定するため、少数の要素を正方形に整列させることによって答えが決定されることを強く示唆しています。 

よくある失敗例は、選択の観点から考えることから生じます。$x$可能な値をスキャンするか、一度に 1 つの要素を貪欲に位置合わせすることによって。 たとえば、選択しようとすると、$x$最小値のみに基づいて$a_i$、複数の大きな要素を同時に整列させるシフトを見逃す可能性があります。 もう 1 つの微妙な間違いは、次のことに気づかずにすべての二乗差を事前計算しようとすることです。$t^2 - a_i$負でない必要があります。これにより、多くの候補ペアが無効になります。 

## アプローチ

 強引なアイデアは、すべての整数を試すことです$x$まで$10^{18}$そして正方形になる値の数を数えます。 これは直ちに不可能です。$10^9$反復回数が大きすぎるため、範囲が天文学的に大きくなります。 

重要な観察は、私たちは選択しないということです。$x$孤立して自由に。 有効な$x$2 つの要素を同時に正方形にする場合は、次の 2 つの方程式を満たさなければなりません。$$a_i + x = u^2,\quad a_j + x = v^2$$減算すると次のようになります。$$a_i - a_j = u^2 - v^2 = (u-v)(u+v)$$これは、要素の各ペアが正方形空間内の小さな候補差分のセットのみを定義すること、したがって、候補シフトの小さなセットのみを定義することを意味します。 

Instead of enumerating$x$、要素のペアを列挙し、両方を正方形に「整列」させようとします。 各アライメントにより候補が生成されます$x$そして、そのシフトに適合する要素の数を数えます。 以来$n \le 50$、$O(n^2)$候補者の世代と$O(n)$候補者ごとの検証で十分です。 

ストーリーは、問題の構造が要素のペア間の制約から自然にシフトを生成する一方で、シフトを超えて検索するために総当たりが失敗するというものです。

 ## アルゴリズムのチュートリアル

 どの要素が正方形になるかを決定すると、適切なシフトが決定されるという事実を利用したいと考えています。 

1. すべての要素について$a_i$、可能な値を検討してください$t^2 \ge a_i$。 これにより候補者のシフトが定義されます$x = t^2 - a_i$。 このようなペアをすべて直接列挙すると大きすぎるため、個別に生成しません。 
2. 代わりに、2 つの要素を選択します$a_i$そして$a_j$。 同じシフトで両方が正方形になった場合$x$、 それから：$$a_i + x = u^2,\quad a_j + x = v^2$$それで$u^2 - v^2 = a_i - a_j$。 

これにより、問題は固定差を持つ正方形のペアを見つけることに変換されます。 
3. 違いを因数分解します。$$u^2 - v^2 = (u-v)(u+v)$$させて$d = a_i - a_j$。 因子ペアを列挙します$(p, q)$そのような$p \cdot q = d$、一致するパリティがあるため、$u = (p+q)/2$、$v = (q-p)/2$は整数です。 
4. 有効なそれぞれについて$(u, v)$、暗黙のシフトを計算します。$$x = u^2 - a_i$$私たちはそれを検証します$x \ge 0$。 
5. 各候補者のシフトについて$x$、すべての要素をスキャンし、満たす要素がいくつあるかを数えます。$a_k + x$は完全な正方形です。 整数の平方根を使用して平方チェックを計算します。 
6. すべての候補の最大数を追跡し、ベースラインケースも含めます$x = 0$、すでに自明ではない数の正方形が得られている可能性があります。 

### なぜ効果があるのか

 すべての最適なシフトは、少なくとも 1 組の要素を正方形に整列させる必要があります (または、単一要素の整列によって検出されます)。 このような配置は一意に決定されます$x$。 すべてのペアによって引き起こされるアライメントを列挙し、それらをグローバルにテストするため、候補の中に最適な構成が含まれることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def is_square(x):
    if x < 0:
        return False
    r = math.isqrt(x)
    return r * r == x

def all_divisors(d):
    res = []
    i = 1
    while i * i <= d:
        if d % i == 0:
            res.append((i, d // i))
        i += 1
    return res

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    best = 0
    n = len(a)

    # baseline: x = 0
    cnt0 = 0
    for v in a:
        if is_square(v):
            cnt0 += 1
    best = cnt0

    seen = set()

    for i in range(n):
        for j in range(n):
            if i == j:
                continue
            diff = abs(a[i] - a[j])
            if diff == 0:
                continue

            for p, q in all_divisors(diff):
                # u - v = p, u + v = q or swapped
                if (p + q) % 2 != 0:
                    continue
                u = (p + q) // 2
                v = (q - p) // 2
                if v < 0:
                    continue

                # try both orientations
                for ui, ai in [(u, a[i]), (v, a[i])]:
                    x = ui * ui - a[i]
                    if x < 0:
                        continue
                    if x in seen:
                        continue
                    seen.add(x)

                    cnt = 0
                    for val in a:
                        if is_square(val + x):
                            cnt += 1
                    if cnt > best:
                        best = cnt

    print(best)
```この実装では、要素のすべてのペアから候補シフトを構築し、配列をスキャンして各シフトを検証します。 二乗チェックでは、効率的かつ正確に行うために整数の平方根が使用されます。 セットでは、多くの異なるペアが同じシフトを生成できるため、同じシフトを複数回再計算する必要がなくなります。$x$。 

重要な点は、いずれかの要素がより大きな正方形に対応する可能性があるため、候補の生成に正方形のペアの両方の方向が確実に含まれるようにすることです。

## テストケース```python
import sys, io

def is_square(x):
    import math
    if x < 0:
        return False
    r = int(math.isqrt(x))
    return r * r == x

def solve(inp):
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    import math

    def divisors(d):
        res = []
        i = 1
        while i * i <= d:
            if d % i == 0:
                res.append((i, d // i))
            i += 1
        return res

    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        best = sum(is_square(v) for v in a)

        seen = set()

        for i in range(n):
            for j in range(n):
                if i == j:
                    continue
                diff = abs(a[i] - a[j])
                if diff == 0:
                    continue

                for p, q in divisors(diff):
                    if (p + q) % 2:
                        continue
                    u = (p + q) // 2
                    v = (q - p) // 2
                    if v < 0:
                        continue

                    for ui in [u, v]:
                        x = ui * ui - a[i]
                        if x < 0 or x in seen:
                            continue
                        seen.add(x)

                        cnt = 0
                        for val in a:
                            if is_square(val + x):
                                cnt += 1
                        best = max(best, cnt)

        out.append(str(best))

    return "\n".join(out)

assert solve("1\n1\n100\n") == "1"
assert solve("1\n2\n1 2\n") == "1"
assert solve("1\n3\n1 2 3\n") >= "1"

 ## 特殊なケース

 重要なエッジ ケースは、最適なシフトにより 1 つの要素のみが正方形になる場合です。 このような場合でも、ペアベースの生成では、すべての単一要素が概念的に正方形の配置を介してそれ自体とペアになることができるため、候補シフトが引き続き生成されることが保証されます。 別のエッジ ケースは、複数のペアが同じシフトを生成するときに発生します。これは、`seen`冗長な再計算を避けるために設定されます。
