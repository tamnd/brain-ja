 ## 解決策
 ## 問題の理解

 私たちは、壁、床、天井が完全に反射している長方形の廊下内をボールが移動する 3 次元のビリヤードのようなシナリオをシミュレートするように求められます。 回廊は _y_ 方向に無限であり、ボールは最初、負の _y_ 軸に沿って出口ドアから _m_ の距離にある回廊の中心に配置されます。 ボールには指定された速度ベクトルがあり、_y = 0_ でボールがドア面に当たる場所を計算する必要があります。 ドア自体は _xOz_ 平面内の長方形であり、`(0,0,0)`に`(a,0,b)`。 

入力によりコリドーの寸法が与えられます`a`そして`b`、距離`m`、および速度ベクトル`(vx, vy, vz)`。 出力は正確なポイントです`(x0, 0, z0)`ボールがドアに当たる場所、最高の精度で`10^-6`。 

制約は小さく、寸法と速度の最大値は 100 です。 これは、必要に応じて簡単なシミュレーションを使用できることを示唆しています。 ただし、ボールの動きとバウンドの各ステップをシミュレートするのは面倒で、エラーが発生しやすくなります。 周期性を利用した、より数学的なアプローチが望ましいです。 

ボールが壁や床/天井で正確にバウンドする場合、微妙なエッジケースが発生します。 たとえば、ボールが正確な高さで天井に当たった場合、`b`、単純なモジュロ計算では次の結果が返される可能性があります。`b`コリドー境界内にマッピングするのではなく、 もう 1 つの潜在的なトラップは、特に負の速度成分の処理です。`vy < 0`、ボールがドアに向かって移動するとき、これは常に当てはまります。 リフレクション ロジックの処理を誤ると、座標が外部に与えられる可能性があります`[0,a]`または`[0,b]`。 

## アプローチ

 ブルートフォースアプローチは、ボールを段階的にシミュレートし、各反射でボールがドア面に到達したかどうかを確認することです。 各バウンスには、対応する軸の速度コンポーネントを反転するための条件チェックが必要になります。 これは、問題が離散的で有界であるため機能しますが、3 次元での複数のバウンスを注意深く処理する必要があるため、面倒になります。 操作数は、移動距離を速度ステップ サイズで割った値に比例し、軸ごとに数百回の操作が行われる可能性がありますが、この問題では許容できますが、洗練されていません。 

最適なアプローチのための重要な洞察は、「ミラーリング」トリックを使用して反射を処理することから得られます。 すべてのバウンスをシミュレートする代わりに、各軸に沿ってコリドーを概念的に展開することができます。 ボールが壁を越えて移動すると、廊下が両方向に伸びているかのように、壁の周りの座標が反映されます。 数学的には、反射のある軸に沿った位置はモジュラー演算で計算できます。 長さの軸の場合`L`、時間後のボールの座標`t`は`(initial + v*t) % (2*L)`。 この値を超えると`L`を使用して反射します。`2*L - coord`。 

私たちの問題では、ボールがドアに当たるのは、`y`ゼロに達します。 扉にたどり着くまでの時間は、`t = m / -vy`。 次に、`x`そして`z`ミラーリングトリックを使用してその時点の座標を表示します。

 ## アルゴリズムのチュートリアル

 1.時間を計算する`t`ボールが届くまでに時間がかかる`y = 0`。 初期の y 座標は`y = m`そして`vy < 0`、私たちは解決します`m + vy * t = 0`、与える`t = m / -vy`。 ボールは跳ね返ることなく y 方向に直線的に移動するため、これは正確です。 
2. に沿って仮の位置を計算します。`x`そして`z`時間軸`t`壁を考慮せずに:`x = a/2 + vx * t`そして`z = b/2 + vz * t`。 ボールは中央から始まります`(a/2, m, b/2)`。 
3. 反射にミラーリング トリックを適用します。 コーディネートに`coord`長さの軸に沿って`L`、計算する`coord_mod = coord % (2*L)`。 もし`coord_mod > L`を使用して反映させます。`2*L - coord_mod`。 これにより、何度バウンスした後でも、座標が内部にマッピングされることが保証されます。`[0, L]`。 
4. 最終的な座標を出力する`(x0, z0)`十分な精度で。 y 座標は常に`0`。 

機能する理由: 反射をミラーリングとして扱うことで、繰り返されるバウンスを単純なモジュラー算術演算に削減します。 各反射は、対応する壁の周囲で座標を反転することに相当します。 速度が一定でバウンスが理想的であるため、反復シミュレーションを行わなくても、ボールがドアに当たる正確な位置が生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

a, b, m = map(int, input().split())
vx, vy, vz = map(int, input().split())

# time to reach y = 0
t = m / -vy

# compute x and z without walls
x = a / 2 + vx * t
z = b / 2 + vz * t

# reflection function
def reflect(coord, length):
    coord_mod = coord % (2 * length)
    if coord_mod > length:
        coord_mod = 2 * length - coord_mod
    return coord_mod

x0 = reflect(x, a)
z0 = reflect(z, b)

print(f"{x0:.10f} {z0:.10f}")
```最初のステップでは、負の y 速度を直接使用して、ドアに向かう移動時間を計算します。 暫定的な x および z 位置は、単なる線形投影です。 の`reflect`関数は、モジュラー演算とミラーリング ロジックを適用して、x 軸と z 軸に沿ったバウンスを処理します。 精度は小数点以下 10 桁を出力することで維持されますが、問題の許容範囲には十分です。
