 ## 解決策
 ## 問題の理解

 私たちは、限られた燃料供給を使用してロボットを一定の距離を移動するという任務を負っています。 各ロボットには、搭載できる他のロボットの数、単独で移動するために消費する燃料の量、および移動できる最大距離の 3 つの特性があります。 Valera は、直接移動するロボットをいくつか選択し、その中に他のロボットをロードして、一種の再帰的輸送構造を形成できます。 必要な距離に到達できるロボットのみがキャリアとして使用できます。 出力は、目的地に到達できるロボットの最大数と、目的地に到達するために費やされる最小燃料の 2 つの数値です。 

この制約は、ロボットのすべてのサブセットをシミュレートできないことを意味します。 まで$10^5$ロボットと燃料と距離の値は最大$10^9$、より悪いスケールのソリューション$O(n \log n)$制限時間を超える可能性があります。 ロボットのあらゆる組み合わせを試す素朴なアプローチは次のようになります。$O(2^n)$、それは不可能です。 主なエッジケースには、容量がゼロのロボット、目的地にまったく到達できないロボット、燃料の点で最も安価なロボットが他のロボットを運ぶことができないシナリオなどが含まれます。 たとえば、燃料コストが 1 で運搬能力が 0 のロボットが、私たちが購入できる唯一のロボットである可能性があり、間違ったサブセットを選択すると、2 台ではなく 1 台のロボットしか動かなくなる可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、自ら移動できるロボットのすべてのサブセットを試し、それぞれが追加で運べるロボットの数を計算し、燃料制約が満たされているかどうかを確認します。 これには、次のことを繰り返す必要があります。$2^n$サブセットとそれぞれの合計容量が必要ですが、これは完全に非現実的です。$n$まで$10^5$。 

重要な洞察は、私たちは遠くまで到達できるロボットのみを考慮しているということです$d$。 最大距離が以下のロボット$d$輸送には役に立たないので、すぐに廃棄できます。 次に、直接移動するロボットを選択する順序は、低燃料コストと高い運搬能力の最適な組み合わせを持つロボットを優先する必要があることに注意してください。 最初に燃料コストの低い順にロボットを並べ替えることで、最も安価なオプションを試すことができる一方で、総容量に基づいて貪欲な選択を維持することで、輸送するロボットの数を最大化することができます。 

フィルタリングとソートの後、優先キューまたは単純な線形トラバースを使用して、燃料バジェット内に収まりながら他のすべてのロボットを運ぶのに必要なロボットの最小数を決定できます。 これにより、組み合わせ問題が、次の方法で管理できる貪欲な選択問題に変換されます。$O(n \log n)$仕分けのせいで。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 必要な距離を移動できないロボットをすべて除外します。$d$。 あらゆるロボット$l_i < d$自分自身や他の人を目的地まで運ぶことができないため、削除されます。 
2. 残りのロボットを燃料要件ごとに並べ替えます$f_i$昇順で。 これにより、どのロボットを直接動かすかを検討する際に、常に最も安価なものを最初に試すことができます。 
3. 2 つのカウンターを初期化します。`robots_transported`何台のロボットが目的地に到着するかを数えるため、そして`fuel_spent`使用された燃料の合計を追跡します。 
4. ソートされたロボットに対して貪欲な選択ループを使用します。 各ロボットについて、直接移動するロボットとして追加すると燃料バジェットを超えるかどうかを判断します。 「はい」の場合はスキップしてください。 いいえの場合は、それを選択してください。 選択された各ロボットはそれ自体に 1 を貢献し、$c_i$再帰輸送を含む、運ぶことができるロボットの数。 
5. 運搬できるロボットの総数を追跡し、容量を再帰的に合計します。 優先キューまたはソートされたリストを維持して、残りの燃料バジェットに適合する利用可能な最大の運搬能力を持つ次のロボットを常に選択します。 
6. すべてのロボットが検討されるか、燃料バジェットがなくなるまで選択を続けます。 選択したロボットと再帰的に搬送されるロボットの合計が最大搬送数となります。 
7. 輸送されたロボットの総量と使用された燃料を出力します。 

このアルゴリズムが機能するのは、各ステップで、目的地に到達できるロボットの中から単位燃料あたりの輸送ロボット数を最大化するロボットを選択するためです。 不変条件は、燃料バジェットを決して超過せず、選択された各ロボットが貪欲なフレームワーク内で残りのロボットを最適に運ぶことができるということです。 

## Python ソリューション```python
import sys
import heapq
input = sys.stdin.readline

n, d, S = map(int, input().split())
robots = []

for _ in range(n):
    c, f, l = map(int, input().split())
    if l >= d:
        robots.append((f, c))

robots.sort()  # sort by fuel cost

fuel_spent = 0
robots_transported = 0
capacity_heap = []

for f, c in robots:
    if fuel_spent + f <= S:
        fuel_spent += f
        robots_transported += 1
        heapq.heappush(capacity_heap, -c)
    else:
        break

while capacity_heap:
    c = -heapq.heappop(capacity_heap)
    additional = min(c, n - robots_transported)
    robots_transported += additional
    if robots_transported >= n:
        break

print(robots_transported, fuel_spent)
```このコードは、まず目的地に到達できないロボットを除外し、燃料コストで並べ替え、移動するために最も安価なロボットを貪欲に選択します。 最大ヒープは容量を追跡します。 これにより、燃料を超過することなく追加の輸送を最大化するロボットを常に選択することが保証されます。 容量を追加する場合は、ロボットの総数を超えないよう注意が必要です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import heapq
    n, d, S = map(int, input().split())
    robots = []
    for _ in range(n):
        c, f, l = map(int, input().split())
        if l >= d:
            robots.append((f, c))
    robots.sort()
    fuel_spent = 0
    robots_transported = 0
    capacity_heap = []
    for f, c in robots:
        if fuel_spent + f <= S:
            fuel_spent += f
            robots_transported += 1
            heapq.heappush(capacity_heap, -c)
        else:
            break
    while capacity_heap:
        c = -heapq.heappop(capacity_heap)
        additional = min(c, n - robots_transported)
        robots_transported += additional
        if robots_transported >= n:
            break
    return f"{robots_transported} {fuel_spent}"

# Provided sample
assert run("3 10 10\n0 12 10\n1 6 10\n0 1 1\n") == "2 6"

# Minimum input
assert run("1 1 1\n0 1 1\n") == "1 1"

# Maximum capacity
assert run("3 5 10\n2 4 5\n1 5 5\n0 3 5\n") == "3 9"
