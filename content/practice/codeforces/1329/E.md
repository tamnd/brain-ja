 ## 解決策
 ## 問題の理解

 最初と最後の文字が常に A であることが保証された、文字 A と B のみで構成される非常に長いバイナリ文字列が与えられます。これらの固定エンドポイントに加えて、文字列内の他の A 文字の位置も与えられます。 残りのポジションはすべて暗黙的に B になります。 

問題の構造は、連続する A 文字間のギャップによって完全に決まります。 0 と n を含むすべての A 位置を昇順でリストすると、隣接する各ペアがセグメント長を定義します。 すべての隣接する A ペアの最小セグメント長は l、最大長は r、そして注目する値は r から l を引いたもので、これらのギャップがどの程度不均一であるかを測定します。 

正確に k 個の B 位置を A 位置に変換することができます。 その後、これらの新しい A 位置は既存のギャップをより小さなギャップに分割し、隣接する最小距離と最大距離の両方を変更する可能性があります。 目標は、最大ギャップと最小ギャップの間の最終的な差が最小になるように k 個の新しい A 位置を選択することです。 

制約は、どのような種類の解決策が可能であるかを即座に示します。 テスト ケースの総数は最大 400,000 と非常に多くなりますが、すべてのテストの m の合計も 400,000 に制限されます。 これは、どのような解も、償却されたテストごとの m 単位でほぼ線形である必要があることを強く示唆しています。 n の値は 10^15 に達する可能性があるため、文字列全体を反復処理したり、文字列全体を明示的に表現したりすることはできません。 すべての計算は、n 自体ではなく、A 文字の位置のみに依存する必要があります。 

素朴なアイデアは、考えられるすべての方法で k 個の新しい A の配置を明示的にシミュレートし、すべてのギャップを再計算し、最適なバランスを追跡することです。 長さ L の 1 つのギャップでも、その中に k 個の挿入を配置する方法が指数関数的に多く存在するため、これは直ちに不可能です。 k 点を複数のギャップに分散しても、組み合わせ爆発が発生します。 

まず最大の差を縮めることを貪欲に考えると、さらに微妙な失敗例が現れます。 これは必ずしも機能するとは限りません。最大ギャップを減らすと、数回の挿入後にどのギャップが新しい最大値になるかが変わる可能性があり、この相互作用により、グローバル構造がなければローカルの貪欲戦略の信頼性が低くなります。 

重要な隠された構造は、セグメント内に A を挿入すると、セグメントがより小さなセグメントに分割され、最適な戦略は、挿入された A の正確な位置ではなく、元の各ギャップに割り当てる分割数にのみ依存します。 

## アプローチ

 まずは元の A 位置を見てください。 ラインを m+1 のギャップに分割します。 長さ d の各ギャップは 1 つの間隔に寄与します。 その中に x 個の新しい A を挿入すると、そのギャップは x+1 個の小さなセグメントに分割されます。 

長さ d の 1 つのギャップについて、x の挿入を最適に分散すると、セグメントを可能な限り均等にすることが達成できる最善の方法となるため、割り切れる場合、結果のセグメントの最大値はおよそ ceil(d / (x+1)) となり、最小値は Floor(d / (x+1)) になります。 これは、受信する挿入の数を決定すると、各ギャップが独立して動作することを示唆しています。 

ブルートフォースソリューションでは、m+1 ギャップにわたる k 個の挿入のすべての分布が試行されます。 分布ごとに、結果のセグメント長を計算し、r-l を評価します。 分布の数は k を m+1 個の部分に合成した程度であり、最悪の場合 k で指数関数的になるため、実行不可能になります。 

重要な洞察は、挿入を明示的に割り当てる必要がないということです。 代わりに、視点を逆にすることができます。つまり、バランス度の候補となる答え x を固定し、最大 k 回の挿入を使用して r - l ≤ x を達成できるかどうかを確認します。 これにより、問題は単調な述語に関する決定問題に変わり、当然、答えに対する二分探索が示唆されます。

課題は、実現可能性を効率的にチェックすることです。 r と l の両方を直接追跡する代わりに、r - l を小さくするには、基本的に、結果として得られるすべてのセグメントの長さが何らかの狭い間隔に収まるように努めていることがわかります。 ターゲットの最大許容セグメント長を推測すると、元のギャップをすべて破り、結果として生じる部分がこのしきい値を超えないようにするために必要な挿入の数を計算できます。 これにより、各ギャップに対するコスト関数が個別に得られます。 

サイズ d のギャップの場合、すべてのセグメントの長さを最大 L にしたい場合は、セグメントを少なくとも ceil(d / L) 個の部分に分割する必要があります。これは、そのギャップに ceil(d / L) - 1 回の挿入が必要であることを意味します。 すべてのギャップを合計すると、必要な挿入の合計が得られます。 これがｋを超えると、候補Ｌが小さすぎることになる。 

これにより、実現可能性のチェックがギャップ上の単純な線形パスに減ります。 次に、達成可能な最小の L を二分探索します。 L がわかれば、l はギャップの整数換算で少なくとも 1 であるため、可能な限り最小の r-l を推測できます。また、最適なパッキングの構造により、L の周りのセグメント長の密なクラスタリングが保証されます。

 ## アルゴリズムのチュートリアル

 A の位置を境界として扱い、すべてのセグメントの長さを導き出します。 

1. 0 から最初の A まで、および最後の A から n までのエッジを含む、連続する A 位置間のすべてのギャップ長を計算します。 これにより、問題が独立したセグメント長のリストに変換されます。 
2. 最大 k 個の新しい A を挿入した後、すべての最終セグメントの長さが最大 ​​L であることを確認できるかどうかを判断する関数 check(L) を定義します。 長さ d のギャップごとに、それをいくつの部分に分割する必要があるかを計算します。これは ceil(d / L) です。 このような各分割では、部分よりも 1 つ少ない挿入が必要です。 
3. すべてのギャップにわたって必要な挿入を合計します。 合計が ≤ k の場合、L は実現可能です。 
4. L に対して 1 から n までの二分探索を実行します。 実現可能な最小の L は、セグメントの長さに関して達成可能な最良の上限です。 
5. L が見つかったら、結果として得られるセグメント構造を概念的に計算します。 最適な分割後のセグメント長の最小値は、各ギャップ内で可能な限りバランスが取れており、全体的な最小値は、ギャップをどの程度均等に分割できるかによって決まります。 答えは、分割構造によって暗示される最大セグメント サイズと最小セグメント サイズを比較することによって得られます。 

二分探索により、セグメント サイズの可能な限り厳しい上限が特定されることが保証され、一方、実現可能性関数により、k 回の挿入でその上限を強制するのに十分であることが保証されます。 

### なぜ効果があるのか

 最大許容セグメント長 L を固定すると、各ギャップは独立します。1 つのギャップ内に挿入された A の構成は、別のギャップで必要な A の数には影響しません。 この分離性により、ギャップ全体の総コストが加算されます。 「≤ k 個の挿入を使用して最大セグメント長 ≤ L を達成できるか」という述語は、L を増加しても必要な分割を減らすか維持することしかできないため、L では単調です。 単調性により、二分探索の正確さが保証されます。 最適な答えは、実現可能な最小の L に対応します。これは、L が小さいと厳密に k が許容するよりも多くの分割が必要になるためであり、L が大きいと定義上次善となります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def feasible(L, gaps, k):
    need = 0
    for d in gaps:
        need += (d - 1) // L
        if need > k:
            return False
    return True

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        pos = list(map(int, input().split()))
        pos = [0] + pos + [n]

        gaps = []
        for i in range(len(pos) - 1):
            gaps.append(pos[i + 1] - pos[i])

        lo, hi = 1, n
        while lo < hi:
            mid = (lo + hi) // 2
            if feasible(mid, gaps, k):
                hi = mid
            else:
                lo = mid + 1

        L = lo

        # compute induced min and max segment lengths
        min_seg = 10**30
        max_seg = 0

        for d in gaps:
            parts = (d + L - 1) // L
            max_piece = (d + parts - 1) // parts
            min_piece = d // parts
            max_seg = max(max_seg, max_piece)
            min_seg = min(min_seg, min_piece)

        print(max_seg - min_seg)

if __name__ == "__main__":
    solve()
```これらのギャップのみが重要であるため、コードは最初に A 位置間のギャップの完全な構造を再構築します。 実現可能性関数は、長さ d の各ギャップが ceil(d / L) セグメントに分割する必要があるという観察を直接エンコードし、これは (d - 1) // L 個の挿入に変換されます。 

二分探索は、セグメント長の候補上限である L に対して実行されます。 実現可能性は単調であるため、検索は安全です。値 L が機能すると、それより大きな値も機能します。 

L を決定した後、コードはギャップごとに暗黙のセグメンテーションを再構築します。 各ギャップはほぼ等しい部分に分割され、サイズの違いは最大でも 1 つです。 最大セグメント長はすべてのギャップにわたる最悪のケースであり、最小セグメント長はすべてのギャップにわたる最良のケースであり、それらの差が最終的な答えを与えます。 

このタイプの問題では、天井演算および床演算におけるオフバイワンエラーが誤答の最も一般的な原因であるため、必要な分割とセグメントサイズを計算するときは整数の除算に注意する必要があります。

 ## 特殊なケース

 微妙なケースの 1 つは、内部 A ポジションがない場合です。 全体の構造は、長さ n の単一のギャップです。 すべての挿入は、この 1 つのセグメントのみを細分化します。 アルゴリズムはこれを単一のギャップ リストとして扱い、実現可能性は、k 個のカットを使用して n を最大サイズ L の断片に分割できるかどうかを確認することになります。 二分探索では n/(k+1) 付近の L が正しく検出され、再構成ではほぼ等しいセグメントが生成されるため、r-l は最小になります。 

別のケースは、k がゼロの場合です。 その場合、分割は不可能になり、答えは完全に元のギャップによって決まります。 実現可能性関数は、最大初期ギャップより小さいすべての L を即座に拒否するため、二分探索ではその最大ギャップが返され、計算された最小セグメント長と最大セグメント長は変更されません。 

3 番目のケースは、k が非常に大きい場合です。 そうすれば、すべてのギャップをほぼ均一に分割できます。 実現可能性関数は非常に小さな L 値を受け入れ、二分探索は達成可能な最小の均一セグメント サイズに収束します。 各ギャップ内の再構成されたセグメントの違いは最大でも 1 であるため、r-l はゼロに向かって縮小し、密な挿入によって不均衡が解消されるという直観と一致します。
