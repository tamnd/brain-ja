 ## 問題の理解

 このタスクでは、単純な数学的観察が求められます。 私たちには番号が与えられています`k`最大の正の整数を見つける必要があります`n`そのような`n`より大きくない`k`との値`n`階乗とまったく同じです。 数値の階乗は、その数値までのすべての正の整数の積です。 元の問題は、Codeforces Gym 106106、問題 I、「Немножко математики」からのものです。 

入力には整数が 1 つだけ含まれています`k`、 と`1 ≤ k ≤ 10^5`。 上限が小さいため、直接シミュレーションはすでに可能ですが、より有益な観察は、階乗が非常に急速に増加することです。 最初のいくつかの値の後、`n!`よりもはるかに大きくなります`n`, そのため、チェックする候補は多くありません。 

を満たす唯一の正の整数`n = n!`は`1`そして`2`。 のために`n = 1`、階乗は`1! = 1`。 のために`n = 2`、階乗は`2! = 2`。 あらゆる人にとって`n ≥ 3`、階乗には少なくとも次の乗算が含まれます。`2`、結果は厳密に次よりも大きくなります。`n`。 

主なエッジケースは次のような場合です。`k`は、これらの有効な値のいずれか、またはそれらの間にある場合に指定されます。

## アプローチ

 簡単なアプローチは、次のすべての数値を反復処理することです。`1`に`k`、その階乗を計算し、その階乗がそれ自体と等しい最大の数を記憶します。 これは、有効な回答の定義を直接チェックするため、正しいです。 しかし、たとえ`k`だけです`100000`、階乗を繰り返し計算する必要はありません。 階乗値はすぐに膨大になるため、これらの値を保存または計算すると、有用な情報が得られずに複雑さが増します。 

重要な観察は、次の方程式であるということです。`n = n!`は非常に制限的です。 一度`n`到達する`3`、階乗はすぐに大きくなります。```
3! = 6 > 3
```数値が大きくなるたびに、ギャップは増加するだけです。 これにより、考えられる答えが 2 つだけ残ります。`1`そして`2`。 

そこで問題は単純な比較になります。 もし`k`少なくとも`2`、利用可能な最大の有効値は次のとおりです。`2`。 それ以外の場合、考えられる唯一の答えは、`1`。

 ## アルゴリズムのチュートリアル

 1. 値を読み取る`k`。 
2. かどうかを確認します。`k`少なくとも`2`。 値`2`は有効です。`2! = 2`、これより大きな正の整数は方程式を満たすことができません。 
3. もし`k`よりも小さいです`2`、出力`1`、 なぜなら`1! = 1`残っている唯一の有効な値です。 

なぜ機能するのか: 階乗関数は次の点にのみ固定点を持ちます。`1`そして`2`正の整数の間。 数に達したら`3`、以前のすべての正の整数を乗算すると、階乗は元の数値より永久に大きくなります。 

## なぜ機能するのか

 このアルゴリズムは、数値とその階乗が等しい正の整数が 2 つだけ存在するという事実に基づいています。 価値観`1`そして`2`を直接確認することができます。 あらゆる人にとって`n ≥ 3`、 我々は持っています：```
n! = 1 * 2 * 3 * ... * n
```製品には要素が含まれています`1 * 2 * ... * (n - 1)`、これはすでに少なくとも`2`これらの値に次の値を掛けます。`n`階乗は厳密に次よりも大きくなります`n`。 したがって、これより大きな値はありません`2`答えになる可能性があります。 アルゴリズムは 2 つの有効な数値の中から選択するだけなので、常に次の値を超えない最大の数値を返します。`k`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    k = int(input())
    if k >= 2:
        print(2)
    else:
        print(1)

if __name__ == "__main__":
    solve()
```実装は数学的観察に直接従うものです。 条件`k >= 2`答えが得られるすべてのケースをカバーします`2`。 さもないと、`k`でなければなりません`1`、そして答えもまた`1`。 

コードには階乗計算はありません。 これにより、不必要な乗算が回避され、より小さい整数型を使用する言語での整数オーバーフローのリスクが排除されます。

## 特殊なケース

 のために`k = 1`、アルゴリズムがチェックします`k >= 2`これは false であり、次の値を返します。`1`。 これは正しいです。なぜなら、`1! = 1`であり、これより小さい正の整数の候補はありません。
