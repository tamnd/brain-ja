 ## 問題の理解

 一定の長さの直線セグメント上の制約された移動プロセスをシミュレートしています。$N$。 エイミーは位置 0 から開始し、最終的に位置に到達する必要があります$N$。 彼女の動きは任意ではありません。最初の動きは長さ 1 に固定され、最後の動きも長さ 1 でなければならず、すべての中間の動きは前の動きに依存します。 もし彼女の最後のジャンプに長さがあったなら$k$、次のジャンプには長さが必要です$k-1$、$k$、 または$k+1$、ジャンプの長さは常に正でなければなりません。 

私たちが気にする量は、正確に着地するために必要な最小限のジャンプ数です。$N$これらのルールの下で。 

制約$N \le 10^{12}$位置に関する動的プログラミングや距離に関する直接的な状態シミュレーションは除外されます。 ジャンプのすべてのシーケンスを調査するソリューションは指数関数的に爆発的に増加します。これは、有効なシーケンスの数が時間とともに急速に増加するためです。$N$。 

微妙なエッジ具合は両端強制構造です。 最初と最後のジャンプは 1 に固定されています。これにより、「山のような」構造が作成されます。すべてのジャンプの長さの合計は正確に 1 からピーク値まで増加し、その後 1 に戻さなければなりません。$N$。 小さな例でも、これがいかに厳格であるかを示しています。 

のために$N = 2$、 のみ$1 + 1$動作し、2 つのジャンプを与えます。 

のために$N = 3$を使用する必要があります$1 + 1 + 1$、すぐに増加しようとすると制約をオーバーシュートしてしまうためです。 

のために$N = 4$、最適なのは$1 + 2 + 1$、3つのジャンプを生み出します。 

重要な問題は、許容されるステップ変更により拡大および縮小できる速度が制限されるため、形状が厳密に制御された制約付きシーケンスを効果的に最適化することになることです。 

## アプローチ

 直接的なアプローチは、再帰またはステート上の BFS を使用して、すべての有効なジャンプ シーケンスを試すことです。$(position, last\_jump)$。 各状態から、最大 3 つの次のジャンプ サイズに分岐します。 正確な位置に到達したら停止します$N$最終ジャンプは 1 です。 

これは正しいですが、まったく実行不可能です。 状態の数は位置と最後のジャンプ サイズの両方に応じて増加し、分岐係数は一定ですが、次のようなパス長に適用されます。$N$。 中程度の場合でも$N$、これは指数関数的になります。 

重要な観察は、最適なシーケンスは非常に構造化された形状をしているということです。 ジャンプは最大でも 1 しか変更できないため、最高速度戦略は 1 からあるピーク値まで増加する必要があります。$h$、おそらくその値付近に留まり、その後対称的に減少して 1 に戻ります。したがって、ジャンプ数を最小限に抑えるシーケンスは、どれだけの大きさの「三角形の累積」を当てはめることができるかに密接に関係しています。$N$。 

最大高さを固定すると$h$、1 から 1 まで上昇する可能な最短のシーケンス。$h$そして、固定長と固定合計の 1 に戻ります。 増加するランプの合計は次のようになります。$1 + 2 + \dots + h = \frac{h(h+1)}{2}$、完全なアップダウン構造では、ピークの重なりを除いてこれが 2 倍になります。 この構造から、特定のオブジェクトを表現するために必要なジャンプの数を導き出すことができます。$N$、次の場合は最小限に調整します。$N$厳密には完全な対称構造ではありません。 

シーケンスをシミュレートする代わりに、範囲内に留まりながらピークがどのくらい大きくなり得るかを計算します。$N$、残りの距離に基づいて最終的な答えを調整します。

 ## アルゴリズムのチュートリアル

 1. このプロセスを、まず 1 からあるピークまでステップごとに最大 1 ずつ増加し、その後 1 に戻るシーケンスを構築すると解釈します。この構造は、±1 制約と、開始ジャンプと終了ジャンプが 1 であるという要件によって強制されます。 
2. 最高の高さに到達するために必要な歩数を計算します。$h$。 上向きの部分は三角和に寄与します$1 + 2 + \dots + h$、下向きの部分はそれを反映していますが、ピークの繰り返しは除外されています。 これにより、完全に対称な高さの「山」の予測可能な合計距離が得られます。$h$。 
3. 最大のものを選択します$h$完全な対称構造の合計距離が次の値を超えないようにします。$N$。 これにより、可能な限り最大の「高速成長」領域が使用されるようになり、ジャンプの数が最小限に抑えられます。 
4. 1回$h$が修正されたら、残りのギャップを埋めるために追加のジャンプが何回必要かを決定します。$N - \text{base}(h)$。 ジャンプの長さは最大 1 の増分で移動するように制約されているため、追加の距離単位ごとに、プラトー領域で追加のフラットまたは調整されたステップが効果的に強制されます。 
5. 基本構造の長さと残りの修正を最終的な答えに組み合わせて、両方のエンドポイント制約 (最初と最後のジャンプが 1 に等しい) が満たされたままであることを確認します。 

### なぜ効果があるのか

 有効なシーケンスはすべて、ジャンプ長さの最大 1 のローカル スロープ変化によって制約されます。つまり、距離を蓄積する最速の方法は、許容される最大ジャンプ サイズにできるだけ近づけることです。 その構造は必然的に単一のピークを形成します。 複数のピークがある場合は、不必要な下降と上昇のステップが導入され、リーチは改善されずにジャンプの合計が増加します。 したがって、最適なシーケンスは常に単一ピークのプロファイルと等価であり、そのピークを最大化すると総ジャンプ数が最小化されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N = int(input().strip())

    # We binary search the maximum height h such that
    # we can form a valid symmetric structure within N.
    #
    # For a peak h:
    # sum up = h(h+1)/2
    # sum down = (h-1)h/2
    # total distance = h^2

    lo, hi = 1, 10**6
    best = 1

    while lo <= hi:
        mid = (lo + hi) // 2
        if mid * mid <= N:
            best = mid
            lo = mid + 1
        else:
            hi = mid - 1

    h = best

    used = h * h
    remaining = N - used

    # base number of jumps in full peak structure:
    # up: h steps, down: h-1 steps => 2h-1 jumps
    ans = 2 * h - 1

    # Each extra unit beyond perfect square requires extending flat region,
    # effectively increasing jump count by 1 per unit adjustment in this model.
    ans += remaining

    print(ans)

if __name__ == "__main__":
    solve()
```実装の最初の部分では、実現可能な最大のピーク高さを見つけます。$h$完全に対称的な「上から下」の構造が内部に収まるように$N$。 使用される重要なアイデンティティは、そのような構造が正確に使用することです。$h^2$合計距離。これがバイナリ検索条件でチェックされる理由です。$mid^2 \le N$。 

決定した後$h$、どのくらいの距離がカバーされていないまま残っているかを計算します。 ベース構造はまさに貢献します$h^2$、残りは、ジャンプ長の ±1 制約に違反することなく構造を拡張することによって吸収されなければなりません。 これは、総ジャンプ数に対する追加ユニットの寄与としてモデル化されます。 

最後に、答えは完璧なピークのための最小ジャンプ数から始まります。$2h - 1$、そして残りの距離を計算します。

 ## 特殊なケース

 のために$N = 1$、アルゴリズムは依然として選択します$h = 1$、1 つのジャンプを生成します。これは、1 レングスのジャンプで開始および終了するという強制された構造と一致します。 

完全な正方形のすぐ上の値の場合、次のように$N = 5$、ピークは変化しませんが、残りはゼロ以外になります。 アルゴリズムは、ピーク構造を変更せずに追加の修正手順の必要性を反映して、この残りに応じてジャンプ カウントを直線的に増加します。 これにより、不必要な余分なジャンプを引き起こす可能性のある時期尚早にピークを誤って増加させることが回避されます。 

非常に大きい場合$N$、二分探索により、シーケンスを明示的に構築しようとしないことが保証されます。 計算は整数の平方根の動作のみに依存するため、プロセスは次の条件でも安定したままになります。$10^{12}$。
