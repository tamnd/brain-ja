 ## 解決策
 ## 問題の理解

 長さの配列を数えるように求められます`n`各要素が間にある場所`0`そして`2^k - 1`、すべての要素のビット単位の AND がゼロになり、要素の合計ができるだけ大きくなるようにします。 結果はモジュロで返される必要があります`10^9 + 7`。 

具体的には、配列の各要素は次のように視覚化できます。`k`-ビット番号。 ビット単位の AND が 0 であるということは、次のすべてのビット位置に対して次のことを意味します。`0`に`k-1`、配列内にそのビットが存在する要素が少なくとも 1 つ存在する必要があります。`0`。 少しでもあれば`1`すべての要素で、AND はそれを保持します。`1`。 各要素ができるだけ大きい場合、合計は最大になります。この範囲では、`2^k - 1`。 ただし、すべての要素を単に次のように設定することはできません。`2^k - 1`なぜなら、その場合、AND はゼロにならないからです。 

問題の制約により、`n`まで`10^5`そして`k`まで`20`。 と`t`最大 10、おおよそ以上のパフォーマンスを発揮するソリューション`10^8`動作が遅くなりすぎます。 これにより、可能なすべての配列を明示的に列挙したり、反復したりすることさえ排除されます。`2^k`あらゆる要素の可能性。 ソリューションでは、ビットごとの演算の組み合わせ構造と特性を活用する必要があります。 

明らかではないエッジケースが発生するのは次の場合です。`n = 1`。 単一要素の AND がゼロになる唯一の方法は、要素自体がゼロである場合であるため、最大合計は次のようになります。`0`配列は 1 つだけあります。 いつでも選択できると仮定した素朴なアプローチ`2^k - 1`要素はここで失敗します。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての長さの配列を生成しようとします。`n`要素を含む`0..2^k-1`、そのビットごとの AND を計算し、最大合計を追跡します。 これは原理的には正しいですが、完全に実行不可能です。 たとえば、`k=20`そして`n=10^5`、 がある`(2^20)^10^5`天文学的に大きい配列。 

重要な洞察は、要素からビットのパターンに切り替えることです。 最大合計を得るには、各要素は次のようにする必要があります。`2^k - 1`(すべてのビットが設定されています) ただし、AND はゼロである必要があります。 AND がゼロであることを保証するには、すべてのビットを「オフ」にする要素を少なくとも 1 つ選択する必要があります。 配列の数を数えるということは、配列間でゼロを分配できる方法が何通りあるかを数えるということになります。`n`要素のそれぞれが`k`bits には少なくとも 1 つのゼロがあります。 

正式にラベルを付けると、`x = 2^k - 1`の場合、各要素は次のいずれかになります`x`または`x`いくつかのビットがクリアされています。 AND がゼロになるには、配列全体が次のもので構成されていてはなりません。`x`。 これは、長さの配列をカウントするのと同じです。`n`セットを超えて`{0, 1}`すべての要素がそうではないという制限付き`1`。 それは組み合わせ的に`2^n - 1`。 ここで、`2^k`各要素の可能性は、厳密に 1 つのパターン (すべて 1) が禁止されるように構造化されており、`2^k - 1`要素ごとの選択肢。 したがって、有効な配列の数は次のようになります。`(2^k - 1)^n`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((2^k)^n) | O(n) | 遅すぎる |
 | 最適 | O(k + log n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. テスト ケースごとに、整数を読み取ります。`n`そして`k`。 
3. コンピューティング`mod = 10^9 + 7`モジュラー演算用。 
4. コンピューティング`ways = pow(2^k - 1, n, mod)`。 これは計算します`(2^k - 1)^n mod 10^9 + 7`。 Python の組み込みモジュラべき乗を使用すると、大規模なデータを確実に処理できます。`n`効率的に。 
5. 出力`ways`。 

なぜ機能するのか: 各要素には次の特徴があります。`2^k`可能な値。 要素ができるだけ大きい場合、合計は最大化されるため、次のように使用します。`2^k - 1`ベースとして。 AND 制限は、すべての要素が次の配列である配列のみを削除します。`2^k - 1`。 したがって、残りの配列は、少なくとも 1 つの要素が最大ではないすべての配列になります。 べき乗モジュラーは、非常に大規模な場合でもこれを効率的に計算します。`n`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        max_val = (1 << k) - 1
        # number of arrays with at least one element different from max_val
        result = pow(max_val, n, MOD)
        print(result)

if __name__ == "__main__":
    solve()
```ソリューションは最初に計算します`max_val = 2^k - 1`明確にするために。 使用する`pow(base, exp, mod)`オーバーフローを回避し、O(log n) の計算を提供します。 すべてのテスト ケースは独立しているため、ループします。`t`結果をすぐに印刷します。

 ## 特殊なケース

 いつ`n=1`、アルゴリズムは次のように計算します。`pow(2^k-1,1) = 2^k - 1`、すべての単一要素配列をカウントします。 ゼロ配列のみが AND ゼロを与えるため、出力モジュロ 10^9+7 は正しく返されます。`1`。 のために`n`大きい場合、アルゴリズムはモジュロによるべき乗を効率的に処理し、暗黙的に AND ゼロ制約を尊重しながら整数のオーバーフローを回避します。 オフバイワンエラーは発生しません。`pow()`有効な配列の正確な数を直接計算します。
