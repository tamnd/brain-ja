## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input().strip())

used = [False] * n
res = []

def modinv(x, n):
    # extended Euclid for modular inverse
    a, b, m = x, n, n
    u0, u1 = 1, 0
    while b:
        q = a // b
        a, b = b, a - q * b
        u0, u1 = u1, u0 - q * u1
    if a != 1:
        return -1
    return u0 % m

for x in range(1, n):
    if used[x]:
        continue
    if x == 1:
        continue
    y = modinv(x, n)
    if y == -1 or y == x or y <= 0 or y >= n:
        continue
    if not used[y]:
        used[x] = used[y] = True
        res.append(x)
        res.append(y)

res.append(1)
res.sort()

print(len(res))
print(*res)
```このコードは、拡張ユークリッド アルゴリズムを使用してモジュラー逆ペアを構築します。 各番号は 1 回ペアになるか、スキップされます。 配列`used`要素が複数のペアで再利用されないようにします。 

特別な取り扱いは、`1`これはそれ自体の逆ですが、製品の状態を壊さないシングルトンとして扱う必要があるため、それ自体とペアにすることを避けます。 

最後に並べ替えると、出力が必要な昇順に従っていることが保証されます。
