 ## 解決策
 ## 問題の理解

 整数のコレクションが与えられ、各整数をグラフ内のノードとして解釈します。 2 つのノードは、それらのビットごとの AND がゼロ以外の場合に接続されます。これは、1 に設定された少なくとも 1 つの共通ビットを共有することを意味します。 

タスクは、このグラフ内の最短サイクルの長さを決定するか、サイクルが存在しないことを報告することです。 

すべての数値のペアが接続されている可能性があるため、グラフは潜在的なエッジの点で非常に大きくなる可能性があります。 ただし、キー構造はビット表現に隠されています。各数値には最大 60 個の関連ビットがあり、エッジは共有ビットを介してのみ存在します。 これは、すべてのペアについて直接推論することは不可能であり、ビットを使用して構造を圧縮する必要があることを直ちに示唆しています。 

n を最大 100,000 に制限すると、明示的なエッジ上の O(n²) 構造または BFS が排除されます。 O(n√n) であっても、重い定数因数を単純に実装すると大きすぎます。 正しい解決策は、通常、エッジがビットの小さな世界によって引き起こされるという事実を利用して、グラフを大幅に削減する必要があります。 

微妙なエッジ ケースは、3 つの数字すべてで共有されるビットが 1 つもないにもかかわらず、ペアごとに異なるビットを共有する 3 つの数字で形成される三角形がある場合に発生します。 もう 1 つの注意が必要な状況は、複数の数値が同じ 1 ビットを共有する場合です。このような数値が少なくとも 3 つ存在すると、長さ 3 の非常に小さなサイクルが即座に形成される可能性があります。 

完全なグラフを構築したり、すべてのペアの AND ≠ 0 をチェックしたりする単純なアプローチは、時間制限だけでなくメモリの爆発により失敗します。 

## アプローチ

 ブルートフォースのアイデアは単純です。 グラフを明示的に構築します。ノード i と j のすべてのペアについて、a_i AND a_j がゼロでないかどうかを確認し、ゼロでない場合はエッジを追加します。 次に、すべてのノードから BFS を実行して最短サイクルを計算し、各 BFS をそれ自体に戻る最短パスとして扱います。 重み付けされていないグラフの BFS はバック エッジを通る最短サイクルを見つけるため、これは正しいです。 

問題は規模だ。 すべてのペアをチェックすると O(n²) のコストがかかり、最悪の場合でもすでに 10¹⁰ の操作になります。 何らかの方法で隣接ストレージを最適化したとしても、各ノードからの BFS により、O(n²) 個のエッジが含まれる可能性のあるグラフの走査が繰り返されることになります。 ブルートフォース手法は、時間とメモリの両方の制約の下では破綻します。 

重要な点は、エッジが任意ではないということです。 各エッジは共有ビットによってのみ存在し、約 60 ビットしかありません。 ノードに接続されているノードの観点から考える代わりに、ノードを接続しているビットの観点から考えることができます。 

何らかのビットが 3 つ以上の数値に現れる場合、これら 3 つのノードは長さ 3 のサイクルを直ちに形成します。各ペアはそのビットを共有するため、三角形を形成します。 したがって、頻度 ≥ 3 のビットは、すぐに最適な答えを 3 として返します。 

どのビットも 3 回出現しない場合、各ビットは最大 2 つの数値に出現します。 これにより、グラフが大幅に制限されます。各数値は最大 60 ビットなので、各ノードの次数は 60 で制限され、エッジの総数は管理可能になり、およそ O(60n) になります。 この体制では、隣接リストを明示的に構築できます。 

スパースなグラフを作成したら、すべてのノードから BFS を実行して最短サイクルを計算しますが、距離がこれまでに見つかった最良の答えを超えた場合は早期に停止します。 度数には限界があるので、これは実現可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべてのペア + BFS) | O(n² + n·(n+m)) | O(n²) | 遅すぎる |
 | ビットベースのリダクション + BFS | O(60²・n) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

1. すべての数値にわたって各ビットの出現を数えます。 少なくとも 3 つの数値にビットが出現した場合は、すぐに 3 を返します。これは、これら 3 つのノードがそのビットを介して三角形を形成するためです。 
2. すべてのゼロの数字を削除します。 これらはエッジに寄与せず、サイクルに影響を与えることはできません。 
3. 各番号を反復処理し、ビットを共有している以前に確認された番号に接続することにより、隣接リストを作成します。 各ビットは最大 2 回出現するため、各ペアは最大 1 回追加されます。 
4. 各ノードに対して BFS を実行して、すべてのノードへの最短パスを計算します。ただし、現在の距離がこれまでに見つかった最適なサイクル長を超える場合は停止します。 
5. ノード u からの BFS 中に、親ではないすでに訪問済みのノード v に遭遇するたびに、長さが dist[u][x] + dist[u][y] + 1 であるサイクルが見つかります。答えを更新します。 
6. 見つかった最小サイクル長を返します。存在しない場合は -1 を返します。 

なぜそれが機能するかは、ビットによって引き起こされる構造に関係しています。 ビットが大量に共有されてすぐに三角形が生成されるか、各ビットが十分に疎で、誘導されたグラフが次数が少なく完全に走査可能になるかのいずれかです。 グラフ内のすべてのサイクルは、この BFS 探索のサイクルとして現れる必要があり、BFS は最短パス距離を保証するため、各エッジを通過する最初に検出されたサイクルは、そのエッジを含む最小サイクルを示します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque, defaultdict

INF = 10**9

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    bit_count = [0] * 61
    for x in a:
        for b in range(61):
            if x >> b & 1:
                bit_count[b] += 1
    
    if any(c >= 3 for c in bit_count):
        print(3)
        return
    
    nums = [x for x in a if x != 0]
    n = len(nums)
    
    adj = [[] for _ in range(n)]
    seen = [[] for _ in range(61)]
    
    for i, x in enumerate(nums):
        for b in range(61):
            if x >> b & 1:
                for j in seen[b]:
                    adj[i].append(j)
                    adj[j].append(i)
                seen[b].append(i)
    
    ans = INF
    
    def bfs(start):
        dist = [INF] * n
        parent = [-1] * n
        q = deque([start])
        dist[start] = 0
        
        best = INF
        
        while q:
            u = q.popleft()
            if dist[u] >= best:
                continue
            for v in adj[u]:
                if dist[v] == INF:
                    dist[v] = dist[u] + 1
                    parent[v] = u
                    q.append(v)
                elif parent[u] != v:
                    best = min(best, dist[u] + dist[v] + 1)
        return best
    
    for i in range(n):
        ans = min(ans, bfs(i))
        if ans == 3:
            break
    
    print(ans if ans < INF else -1)

if __name__ == "__main__":
    solve()
```この解決策は、ビット周波数を通じて即時トライアングル条件をチェックすることから始まり、これにより、唯一の本当に高密度の障害ケースが処理されます。 次に、共有ビットのみを介して隣接リストを構築することでグラフを圧縮し、中間の「認識ビット リスト」を介して各エッジが 1 回だけ検出されるようにします。 

BFS 関数は、距離配列と親配列の両方を維持します。 親チェックは不可欠です。これがないと、すべての無向エッジはすぐに長さ 2 のサイクルのように見えます。無向グラフでは単純なサイクルの長さが少なくとも 3 でなければならないため、誤検知を避けるために直接バックトラッキングを無視する必要があります。 

各 BFS は開始ノードを含む最短サイクルを返し、グローバル最小値はすべてのソースにわたって累積されます。 

## 実用的な例

 ### サンプル 1

 入力:```
4
3 6 28 9
```ビット頻度は、ビットが 3 回出現しないことを示しているため、グラフの作成に進みます。 

| ステップ | ノード | ビット | 新しいエッジが追加されました |
 | --- | --- | --- | --- |
 | 0 | 3 | {0,1} | なし |
 | 1 | 6 | {1,2} | (3,6) |
 | 2 | 28 | {2,3,4} | (6,28) |
 | 3 | 9 | {0,3} | (3,9)、(28,9) |

 BFS 探索により、4 つのノードすべてを含むサイクル (9 → 3 → 6 → 28 → 9) が見つかります。 

これは、ここでのサイクルが必ずしも三角形である必要はなく、BFS が最小の閉じたウォーク構造を正確に捕捉していることを裏付けています。 

### サンプル 2 (構築済み)

 入力:```
3
5 12 9
```ビット構造は共有ビットを通じて間接的に三角形を形成します。 

| ステップ | ノード | ビット | 新しいエッジが追加されました |
 | --- | --- | --- | --- |
 | 0 | 5 | {0,2} | なし |
 | 1 | 12 | {2,3} | (5,12) |
 | 2 | 9 | {0,3} | (5,9)、(12,9) |

 これにより、すぐに 3 サイクルが形成され、任意のノードの BFS が長さ 3 でそれを検出します。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(60n + 60m BFS) | ビット数と有界次数にわたるスパース BFS のグラフ |
 | スペース | O(n + m) | 隣接リストと BFS 配列 |

 この構造により、各ノードが最大 60 個のエッジのみを提供し、繰り返しの BFS 実行が 1 秒の制限内で通過できるようにグラフが十分にまばらに保たれます。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque, defaultdict
    INF = 10**9

    n = int(input())
    a = list(map(int, input().split()))
    
    bit_count = [0]*61
    for x in a:
        for b in range(61):
            if x >> b & 1:
                bit_count[b] += 1
    if any(c >= 3 for c in bit_count):
        return "3"
    
    nums = [x for x in a if x != 0]
    n = len(nums)
    
    adj = [[] for _ in range(n)]
    seen = [[] for _ in range(61)]
    
    for i, x in enumerate(nums):
        for b in range(61):
            if x >> b & 1:
                for j in seen[b]:
                    adj[i].append(j)
                    adj[j].append(i)
                seen[b].append(i)
    
    def bfs(s):
        dist = [INF]*n
        parent = [-1]*n
        dist[s] = 0
        q = deque([s])
        best = INF
        
        while q:
            u = q.popleft()
            if dist[u] >= best:
                continue
            for v in adj[u]:
                if dist[v] == INF:
                    dist[v] = dist[u] + 1
                    parent[v] = u
                    q.append(v)
                elif parent[u] != v:
                    best = min(best, dist[u] + dist[v] + 1)
        return best
    
    ans = INF
    for i in range(n):
        ans = min(ans, bfs(i))
    
    return str(ans if ans < INF else -1)

 ## 特殊なケース

 重要なエッジ ケースは、3 つの数値に 1 つのビットが出現する場合です。 たとえば、入力`[1, 1, 1]`明示的なサイクル構造が表示されない場合でも、完全な三角形が作成されます。 アルゴリズムはグラフ構築前にこれを捕捉し、不必要な BFS を回避し、正確性を保証します。 

もう 1 つの微妙なケースは、数値がゼロではないが、ペアごとにビットを共有しない場合です。`[1, 2, 4, 8]`。 構築されたグラフにはエッジがなく、BFS はバック エッジを検出せず、結果は正しく残ります。`-1`。 

より興味深いケースは、次のようにサイクルが 3 より長い場合です。`[3, 6, 28, 9]`。 ここでは、周波数 3 以上のビットは存在しないため、完全に BFS に依存します。 共有ビットを通じて構築された隣接関係により、有効な無向サイクルが生成され、BFS は最も短いサイクルを正しく検出し、4 を返します。
