 ## 解決策
 ## 問題の理解

 ある長さの文字列を調べています$n$サイズのアルファベットから作られています$k$、一様にランダムに選択されます。 固定文字列については、同じ長さの接尾辞としても表示される接頭辞がいくつあるかを調べます。 このような長さはすべて境界長と呼ばれ、関数は$f(s)$文字列にある境界線の数を数えます。 

タスクは、1 つの文字列のこの値を計算することではなく、次の文字列の期待値を計算することです。$f(s)^2$全体$k^n$可能な文字列。 四角形を拡大することは、個々の接頭辞と接尾辞の一致だけでなく、境界イベントのペアがどのように相互作用するかを実際に研究していることを意味します。 

この制約により、文字列シミュレーションではなく、組み合わせの視点が強制されます。 と$n \le 10^5$、文字列を列挙するアプローチや、文字列ごとにプレフィックス関数の動作をシミュレートしようとするアプローチは、実現可能性をはるかに超えています。 平$O(n^2)$境界ペアに関する推論は、大幅に圧縮しない限り大きすぎます。 

微妙な問題は、国境は独立した出来事ではないということです。 2 つの異なるプレフィックス長が両方とも境界であるかどうかにより、文字列の位置間の等価性制約が重なり合います。 これらの制約は構造化された方法で相互作用するため、その構造を無視すると、確率が過大にカウントされたり、不正確になったりすることにつながります。 

素朴なアプローチでは、たとえば境界イベントを独立したものとして扱ったり、単一期間の条件のみを調べたりして、各確率を個別に計算しようとする可能性があります。 2 つの境界線が互換性のある周期性を課す場合、これは直ちに失敗します。 たとえば、境界線を長めに設定すると、$i$そして$j$同時に、単に確率を乗算するわけではありません。 これにより、文字列は両方の周期性を同時に尊重するようになり、より強力な単一の周期構造が得られます。 

## アプローチ

 直接的な総当たりアプローチは、すべてを反復することになります。$k^n$文字列と計算$f(s)$プレフィックス関数または境界チェック ルーチンを使用して、二乗して平均します。 これは正しいですがコストがかかります$O(nk^n)$、それはすでに小さなものでも不可能です$n$。 

重要な構造的変化は、文字列についての推論をやめ、代わりに境界線によって引き起こされる制約について推論することです。 長さの境界線$i$それはあらゆるポジションに対して$t \le i$、位置の文字$t$位置の文字と等しい$n-i+t$。 これはインデックス間の等価性システムです。 各境界線は「シフト」に対応します$p = n-i$、文字列はピリオドで周期的になります$p$。 

複数の境界線が存在する場合、周期的な制約と交差します。 2つの期間$p$そして$q$一緒に文字列をピリオドで強制的に周期的にします$\gcd(p,q)$。 これにより、潜在的に複雑な制約システムが単一の周期クラスに集約されます。 この観察により、境界イベントの同時確率を計算することが可能になります。 

次に、指標変数を使用して期待値を書き換えます。 させて$X_i$長さの指標になる$i$国境です。 それから$$f(s)^2 = \sum_i X_i + 2 \sum_{i<j} X_i X_j.$$単一の境界線と境界線のペアの確率が必要です。 

単一の長さの境界線$i$修正期間$p = n-i$、文字列は最初の文字列によって決定されることを意味します$p$文字。 したがって、確率は$k^{p-n} = k^{-i}$。 

2つの境界線の場合$i$そして$j$、対応するピリオド付き$p = n-i$そして$q = n-j$、文字列はピリオドを使用して周期的である必要があります$\gcd(p,q)$、したがって、確率は次のようになります。$k^{\gcd(p,q)-n}$。 

これにより、問題は、すべてのペアにわたる gcd の関数の合計、つまり除数変換とメビウス反転を使用して処理される古典的な数論的集計に集約されます。 

結局、ペアを gcd でグループ化し、gcd が指定された値と等しいペアがいくつあるかを数えます。 この数は、メビウス関数を含む標準の公式を使用して計算できます。

 ## アルゴリズムのチュートリアル

 すべてを期間で書き換えます$p = n-i$、 どこ$p \in [1, n-1]$。 

1. 単一の境界線の寄与を計算します。 

それぞれについて$p$、それが境界である確率は$k^{-p}$。 これを直接合計します。 
2. 二重和を期間で書き直します。 

のために$p < q$、結合確率は$k^{\gcd(p,q)-n}$。 これにより、依存関係が gcd 項に分離されます。 
3. グローバル スケーリングを考慮します。 

次の形式の合計を分離します$k^{\gcd(p,q)}$、要因以来$k^{-n}$すべてのペアにわたって一定です。 
4. gcd によってペアをカウントします。 

gcd 値を修正する$g$。 書く$p = g a$、$q = g b$、 どこ$\gcd(a,b) = 1$。 両方$a$そして$b$寝そべる$[1, \lfloor (n-1)/g \rfloor]$。 この範囲内の共素ペアの数が必要です。 
5. メビウス反転を使用して互いに素のペアの数を計算します。 

順序付けられた互いに素のペアの数$[1, m]$は$$\sum_{d=1}^{m} \mu(d) \left\lfloor \frac{m}{d} \right\rfloor^2.$$これから、順序のないペアに変換します。 
6. 貢献を集計します。 

各 gcd グループが貢献$k^g$有効なペアの数の倍。 
7. モジュロ演算で単一寄与と二重寄与を結合します。 

### なぜ効果があるのか

 2 つの境界のすべての構成は、シフトの gcd によって支配される単一の周期構造に崩壊する等価制約を引き起こします。 これは、すべての境界線のペアが単一の整数によって完全に分類されることを意味します。$g$、両方の境界を満たすすべての文字列は、正確にピリオドを含む周期的なものになります。$g$。 Möbius 関数は、正確な gcd でペアを抽出するときに過剰カウントを正しく修正し、各構造クラスが 1 回カウントされるようにします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def build_mobius(n):
    mu = [1] * (n + 1)
    prime = []
    vis = [False] * (n + 1)

    for i in range(2, n + 1):
        if not vis[i]:
            prime.append(i)
            mu[i] = -1
        for p in prime:
            if i * p > n:
                break
            vis[i * p] = True
            if i % p == 0:
                mu[i * p] = 0
                break
            else:
                mu[i * p] = -mu[i]
    return mu

def solve():
    n, k = map(int, input().split())
    m = n - 1

    if m <= 0:
        print(0)
        return

    mu = build_mobius(m)

    powk = [1] * (m + 1)
    invk = pow(k % MOD, MOD - 2, MOD)
    for i in range(1, m + 1):
        powk[i] = powk[i - 1] * (k % MOD) % MOD

    invpow = [1] * (m + 1)
    for i in range(1, m + 1):
        invpow[i] = invpow[i - 1] * invk % MOD

    # single borders
    ans = 0
    for p in range(1, m + 1):
        ans = (ans + invpow[p]) % MOD

    # double borders
    # sum over gcd groups
    for g in range(1, m + 1):
        m2 = m // g
        if m2 == 0:
            break

        # ordered coprime pairs
        cnt = 0
        for d in range(1, m2 + 1):
            cnt = (cnt + mu[d] * (m2 // d) * (m2 // d)) % MOD

        # convert ordered to unordered pairs
        cnt = (cnt - m2) % MOD
        cnt = cnt * ((MOD + 1) // 2) % MOD

        ans = (ans + 2 * powk[n] % MOD * powk[g] % MOD * cnt) % MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```この実装では、個々の境界確率、gcd で分類されたペア相互作用、およびメビウスに基づく共素構造の計数という 3 つの独立した構造が分離されます。 の逆べき乗$k$は、各境界確率が一定時間で処理されるように事前に計算され、逆モジュラーにより除算のない演算が保証されます。 

実装でよくある落とし穴は、ペアの確率が次の要素に依存することを忘れることです。$\gcd(p,q)$、オンではありません$p$そして$q$独立して。 もう 1 つのよくあるエラーは、順序付きペアの数と順序なしのペアの数を混合することです。 補正ステップでは、対角線のペアを減算し、明示的に 2 で割ります。

 ## 特殊なケース

 のために$n=1$、適切な境界線がないため、$f(s)=0$すべての文字列に対して、答えはゼロになります。 期間の範囲が空であるため、アルゴリズムは正しくゼロを返します。 

いつ$k=1$、すべての文字列は同一であり、最大限に周期的です。 すべてのプレフィックスはサフィックスでもあるため、$f(s)=n-1$決定論的に。 すべての確率質量が完全な周期性に集中し、gcd 集計が一貫してすべてのペアをカウントするため、式は正しく折りたたまれます。 

いつ$k$が非常に大きくなると、国境はまれな出来事になります。 短期間のみが有意義に寄与し、その力は逆になります。$k$モジュラー演算下で数値が不安定になることなく、長周期寄与を正確に抑制します。
