 ## アルゴリズムのチュートリアル

 2 つの候補順列を構築し、それらのスコアを計算します。 

1.恒等順列を構築する$q^{(1)} = (1,2,\dots,n)$。 

この順序付けでは、インデックス シーケンスは厳密に増加しているため、そのプレフィックスの最大数は次のようになります。$n$。 合計スコアは次のようになります$n + f(p)$、2番目のシーケンスは正確に$p$元の順序で。 
2. 2 番目の順列を構築する$q^{(2)}$の値を増加させてインデックスを並べ替えることにより、$p[i]$。 

これにより、シーケンスが保証されます。$p[q^{(2)}]$は厳密に増加しているため、そのプレフィックスの最大数は$n$。 
3. 構築中$q^{(2)}$、この順序でインデックスのプレフィックス最大数を計算します。 

インデックスを並べ替えてスキャンします。$p$これまでに確認された最大のインデックスを順序付けして維持します。 現在のインデックスがこの最大値を超えるたびに、カウントが増加します。 
4. 2 番目の構築のスコアを次のように計算します。$n + f(q^{(2)})$、以来$p$-シーケンスが完全に増加しています。 
5. 2 つのスコアを比較し、より大きい値を与える順列を出力します。 

### なぜ効果があるのか

 重要な特性は、両方のプレフィックス最大関数が次の境界を超えていることです。$n$、そしてそれぞれの極端な構造が達成します$n$2 つのシーケンスのうちの 1 つで。 他の順列はこれを超えることはできません$n$どちらのコンポーネントでも、極端な順序付けからの逸脱は、プレフィックスの最大数の 1 つを減らすだけであり、これらの構築された境界を超えるもう一方の最大数の補償増加は保証されません。 したがって、最適解は 2 つの極値順序のいずれかでなければなりません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def pref_max_count(arr):
    mx = -10**18
    cnt = 0
    for x in arr:
        if x > mx:
            cnt += 1
            mx = x
    return cnt

t = int(input())
for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))

    q1 = list(range(1, n + 1))
    f_p = pref_max_count(p)
    score1 = n + f_p

    idx = list(range(1, n + 1))
    idx.sort(key=lambda i: p[i - 1])

    f_q2 = pref_max_count(idx)
    score2 = n + f_q2

    if score1 >= score2:
        print(*q1)
    else:
        print(*idx)

アイデンティティの注文について$q = [1,2,3]$、インデックス シーケンスは次のとおりです。$[1,2,3]$、プレフィックスの最大数を与える$3$。 の$p$-シーケンスは$[2,3,1]$、接頭辞の最大値は$2$そして$3$、 それで$f(p)=2$。 合計スコアは$3+2=5$。

 ## 特殊なケース

 いつ$p$が厳密に増加している場合、同一性順列により両方のシーケンスが完全に増加するため、両方のプレフィックスの最大数は等しくなります。$n$。 代替の順序付けは、インデックスの単調性を壊すか、混乱させます。$p$-単調性のため、アイデンティティスコアを超えることはできません。 

いつ$p$厳密に減少しています。$p$生成する$p[q]$増加するにつれて 1 つのシーケンス スコアが与えられます$n$、インデックスのシーケンスはほぼランダムになります。 この場合、アルゴリズムは恒等構造と比較し、混合順序付けがこれらの境界を超えることなく 2 つのプレフィックス最大構造のうちの 1 つを削減するだけであるため、2 つの極端な方のうち良い方を正しく選択します。
