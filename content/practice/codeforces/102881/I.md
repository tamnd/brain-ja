 ## 解決策
 ## 問題の理解

 最大 100 個の頂点を持つ接続された無向グラフが与えられます。 入力はその隣接行列であるため、頂点のすべてのペアによって、元のグラフにそのエッジが含まれているかどうかがわかります。 このグラフは、同じ頂点セット上の複数のツリーの XOR として表現する必要があります。 エッジは、選択されたツリーの奇数に現れるときに、最終 XOR に存在します。 

すべての有効な分解の中で、使用する木の最大直径をできるだけ小さくしたいと考えています。 出力は、その最小値を達成するツリーのリスト、または`-1`分解が存在しない場合。 

小さな制限は、`n`問題の性質が変わります。 頂点が最大 100 個の場合、可能なエッジの数は最大 4950 であるため、グラフをビット ベクトルとして表し、XOR ガウス消去法を使用するのが実用的です。 考えられるツリーの数が膨大であるため、ツリーのサブセットを直接検索することは不可能です。 

最初の隠れた制限はパリティから来ます。 それぞれの木々に`n`頂点は正確に持っています`n-1`エッジ。 XOR は選択されたエッジの総数のパリティを保持するため、最終的なグラフのパリティはグラフのパリティと等しくなければなりません。`k * (n-1)`ある数字に対して`k`木の。 いつ`n`が奇数の場合、すべてのツリーには偶数のエッジがあるため、最終的なグラフにも偶数のエッジが含まれている必要があります。 もし`n`エッジの数が両方とも奇数である場合、答えは存在しません。 

いくつかのケースでは、簡単に誤って処理されてしまいます。 3 つの頂点を持つ三角形には 3 つの辺があります。```
3
0 1 1
1 0 1
1 1 0
```答えは、`-1`。 3 つの頂点上のすべてのツリーには 2 つのエッジがあり、偶数サイズのエッジ セットを XOR 演算しても、3 つのエッジを持つグラフを作成することはできません。 

2 頂点グラフは異なります。```
2
0 1
1 0
```答えは、唯一のエッジを含む単一のツリーです。 直径 2 のツリーのみを検索する一般的な実装は、2 ノード ツリーの直径が 1 (真の最小値) であるため、ここでは失敗します。 

スターには、それを可能にする 3 つ以上の頂点を持つグラフの最小直径がすでに設定されています。```
3
0 1 1
1 0 0
1 0 0
```答えは、複数の小さな木片ではなく、1 本の木です。 常に多くのツリーに分解しようとすることは正しい可能性がありますが、最小直径要件を満たせなくなります。 

## アプローチ

 ブルート フォース ビューでは、考えられるツリーを列挙し、XOR がターゲット グラフと等しくなるまで組み合わせを試行します。 これは正しいです。なぜなら、すべての候補ツリーはエッジのベクトルとして扱うことができ、目的のグラフは選択されたベクトルの単なる XOR 和であるからです。 問題は探索空間のサイズです。 頂点が 100 個しかない場合でも、ラベル付きツリーの数は`100^98`, したがって、列挙することは完全に不可能です。 

重要な点は、すべてのツリーを列挙する必要はないということです。 ターゲット エッジ ベクトルが、慎重に選択された小径木のファミリーの線形スパンに属しているかどうかを知る必要があるだけです。 

可能な限り最小の直径が最初にチェックされます。 のために`n = 2`、直径 1 が最適です。 より大きなグラフでは、直径 2 つのツリーがまさに星になります。 すべての星を生成し、XOR ガウス消去法を使用して星だけでグラフを形成できるかどうかをテストします。 

それが失敗した場合、次に考えられる答えは直径 3 です。 直径が最大 3 のツリーは二重星として構築できます。 異なる頂点の順序付きペアごとに`(a, b)`、エッジのあるツリーを作成します`(a, b)`を中心エッジとして、他のすべての頂点をそれに接続します`b`。 あるのは`n(n-1)`十分に小さい木です。 それらのスパンは、パリティ条件を通過するすべてのグラフを表すのに十分であるため、この 2 番目の消去が成功すると、答えは最適になります。 

消去プロセスでは、どの生成ツリーが各基底ベクトルを作成したかも保存されます。 ターゲット ベクトルを削減した後、保存されている選択肢の XOR 演算によって選択されたツリーを復元します。

 ## アルゴリズムのチュートリアル

 1. 入力グラフをビット ベクトルに変換します。 考えられるすべてのエッジに 1 ビットを割り当てると、グラフ間の XOR は整数間の XOR になります。 
2. パリティ不可条件を確認します。 もし`n`が奇数でエッジの数が奇数である場合、印刷します`-1`。 この状況では、すべてのツリーに偶数のエッジがあるため、XOR の組み合わせがグラフと一致することはありません。 
3. 特殊なケースに対処する`n = 2`。 可能な唯一の接続されたグラフは単一のエッジであり、そのエッジ自体が最適なツリーです。 
4. オールスターを生成します。 頂点を中心とした星`v`あらゆるエッジが含まれています`(v, u)`のために`u != v`。 これらのツリーに対して XOR ベースの消去を実行します。 
5. スターから対象のグラフを作成できる場合は、選択したスターを出力します。 星の直径は 2 であり、直径 1 は不可能であるため、`n > 2`、これが最適です。 
6. 順序付けられたすべての二重星を生成します。 注文したペアごとに`(a, b)`、エッジを追加します`(a, b)`頂点を 1 つおきに接続します`b`。 生成された各ツリーの直径は最大 3 です。 
7. 二重星に対して同じ XOR ベースの消去を実行します。 選択した木が答えです。 

なぜ効果があるのか:

 アルゴリズムは、可能な直径を昇順にチェックします。 3 つ以上の頂点にあるツリーの直径を 1 にすることはできないため、最初に成功したファミリーによって可能な最小の直径が与えられます。 星はまさに直径 2 の木であり、生成された二重星は直径 3 のケースをカバーします。 グラフ XOR は 2 つの要素を持つフィールド上のベクトル加算にすぎないため、XOR ガウス消去は正しいです。 ターゲット ベクトルがファミリーで表現できる場合、消去によりそのファミリーの有効なサブセットが回復されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def xor_basis(candidates, target, edge_count):
    basis = {}
    for idx, (vec, _) in enumerate(candidates):
        x = vec
        mask = 1 << idx
        while x:
            p = x.bit_length() - 1
            if p in basis:
                bx, bm = basis[p]
                x ^= bx
                mask ^= bm
            else:
                basis[p] = (x, mask)
                break

    x = target
    ans = 0
    while x:
        p = x.bit_length() - 1
        if p not in basis:
            return None
        bx, bm = basis[p]
        x ^= bx
        ans ^= bm

    return ans

def main():
    n = int(input())
    a = [list(map(int, input().split())) for _ in range(n)]

    edges = []
    pos = {}
    for i in range(n):
        for j in range(i + 1, n):
            pos[(i, j)] = len(edges)
            edges.append((i, j))

    m = len(edges)
    target = 0
    for i, j in edges:
        if a[i][j]:
            target ^= 1 << pos[(i, j)]

    if n % 2 == 1 and target.bit_count() % 2 == 1:
        print(-1)
        return

    if n == 2:
        print(1)
        print("1 2")
        return

    def make_vec(es):
        v = 0
        for x, y in es:
            if x > y:
                x, y = y, x
            v ^= 1 << pos[(x, y)]
        return v

    stars = []
    for c in range(n):
        es = []
        for x in range(n):
            if x != c:
                es.append((c, x))
        stars.append((make_vec(es), es))

    res = xor_basis(stars, target, m)
    if res is not None:
        out = [str(res.bit_count())]
        for i in range(len(stars)):
            if (res >> i) & 1:
                for u, v in stars[i][1]:
                    out.append(f"{u + 1} {v + 1}")
        print("\n".join(out))
        return

    doubles = []
    for a in range(n):
        for b in range(n):
            if a == b:
                continue
            es = [(a, b)]
            for x in range(n):
                if x != a and x != b:
                    es.append((b, x))
            doubles.append((make_vec(es), es))

    res = xor_basis(doubles, target, m)
    if res is None:
        print(-1)
        return

    out = []
    chosen = []
    for i in range(len(doubles)):
        if (res >> i) & 1:
            chosen.append(doubles[i][1])

    out.append(str(len(chosen)))
    for tree in chosen:
        for u, v in tree:
            out.append(f"{u + 1} {v + 1}")
    print("\n".join(out))

if __name__ == "__main__":
    main()
```エッジのインデックス付けにより、考えられるすべてのグラフが 1 つの整数に変換されます。 このアルゴリズムで必要な演算は XOR のみであるため、Python 整数は便利なビットセット表現を提供します。`xor_basis`GF(2) に対してガウス消去法を実行します。 辞書キーは、基底ベクトルの最上位の設定ビットです。 挿入中、ベクトルは消滅するか新しい基本要素が作成されるまで削減されます。 付随するマスクは、どのツリーがそのベクトルを生成したかを記録し、選択されたツリーの最終的な再構築を可能にします。 

スターの生成は、直径 2 の場合と正確に一致します。 各中心に対して、コードはすべてのインシデント エッジを追加します。 ダブルスター生成では、2 番目のエンドポイントが残りのすべての頂点が接続される場所を決定するため、順序付きペアが使用されます。 このような各ツリーには正確に`n-1`エッジと直径は最大 3 つです。 

再構成は、選択したマスクをループして、係数が 1 であるツリーのみを出力します。 選択されたツリーの数は、エッジ空間のランクによって制限されます。エッジ空間のランクは、最大でも可能なエッジの数であるため、常に次の条件を満たします。`n + m`出力制限。 

## 実用的な例

| 2 | 星を試す | ターゲットは表現できません |

 ## 特殊なケース

 三角形のケースは、除外の前に拒否されます。 アルゴリズムは 3 つのエッジをカウントし、次のことを確認します。`n`エッジ数が奇数である間は奇数です。 考えられるすべてのツリーには偶数のエッジがあるため、ターゲットは存在できません。 

2 ノードの場合は個別に処理されます。 接続されている唯一のグラフは次のとおりです。```
2
0 1
1 0
```このアルゴリズムは、次の内容を含む 1 つのツリーを出力します。`1 2`。 これにより、答えが直径 2 の構造として誤って扱われることがなくなります。 

スターケースは最初のエリミネーション中に成功します。 のために：```
3
0 1 1
1 0 0
1 0 0
```頂点 1 を中心とする生成されたスターは、ターゲットとまったく同じエッジ ベクトルを持ちます。 アルゴリズムはこのツリーのみを選択し、最小直径を与えます。 

星ではないグラフは二重星の段階に達します。 2 番目の基底には、残りのすべての有効なケースを表すのに十分な直径 3 のツリーが含まれており、除去ステップでは、XOR によって元のすべてのエッジが正しいパリティで再現されるサブセットが選択されます。
