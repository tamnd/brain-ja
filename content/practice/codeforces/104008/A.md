 ## 解決策
 ## 問題の理解

 私たちには一次元の細胞の細片が与えられています。 各セルは空であるか、または文字列で表されるユリが含まれています。`L`ユリがすでに植えられていることを意味し、`.`細胞が空の土壌であることを意味します。 

いくつかの空のセルにキャットフードを置くことができ、それらにマークを付けます。`C`。 ただし、キャットフードを所定の位置に置くと、`i`セル自体とその隣接セルに厳しい安全制約を課します。`i-1`そして`i+1`ユリを含めてはいけません。 言い換えれば、キャットフードを配置すると、その周囲の半径 1 がユリの存在から「ブロック」されます。 

課題は、キャットフードの数を最大化する位置を選択することです。`C`この制約を尊重しながらセルを配置します。 キャットフードの配置の最大数を達成する有効な構成はどれでも受け入れられます。 

制約`n ≤ 1000`これは、二次または緩やかな三次の解でも問題ないことを意味しますが、問題の構造は、貪欲なスキャンまたは線形スキャンで十分であることを強く示唆しています。 各決定は隣接するセルにのみ影響するため、グローバル検索や DP は必要ありません。 

ユリが非常に密集している場合、微妙なエッジケースが現れます。 たとえば、文字列が次の場合、`LLL`、ユリに隣接するすべての空のセルがすぐに制約に違反するため、どこにもキャットフードを置くことはできません。 もう 1 つのエッジケースは、次のような交互パターンです。`L.L.L`、単純な貪欲な配置が誤って配置しようとする可能性がある場所`C`両方の隣をチェックせずにユリに近づきすぎます。 

両側を確認するのではなく、隣接する 1 つのセルが安全なときにキャットフードを配置するという不注意なアプローチは、失敗することがよくあります。 たとえば、`..L..`、位置 2 にキャットフードを配置すると、位置 3 の使用がブロックされ、欲張った左から右への配置はその伝播を考慮する必要があります。 

## アプローチ

 ブルートフォース戦略では、空のセルのすべてのサブセットを試して、有効性をチェックします。 各サブセットについて、文字列をスキャンし、選択されていないことを確認します。`C`近くのユリとのルール違反。 まであります`n`位置なので、サブセットの数は`2^n`、各小切手にかかる費用`O(n)`、につながる`O(n·2^n)`操作。 これは小さくても不可能になります`n`。 

重要な観察は、各キャットフードの配置がサイズ 3 の局所的な近傍のみを制限するということです。この局所性は、左から右にスキャンする場合、以前の決定を再検討する必要がないことを意味します。 を配置したら、`C`位置で`i`、ポジション`i-1`そして`i+1`百合が含まれている場合は事実上禁止されるため、貪欲な構成では自然に百合をスキップします。 

最適な構造は、文字列をトラバースして、`C`現在の位置が空で、その隣接位置にルールに違反するユリが含まれていない場合。 を配置した後、`C`では、今後の配置で偶発的に隣接関係が競合することを避けるために、次のセルをスキップします。

 ## アルゴリズムのチュートリアル

 文字列を左から右に処理し、段階的に答えを作成します。 

1. インデックス 0 から開始し、グリッドの変更可能なコピーを維持します。 

可変性が必要なのは、`C`将来許可されるポジションが変更されます。 
2. 各ポジションで`i`、セルが空かどうかを確認します。 

すでに含まれている場合`L`, そこには何も置けないので先に進みます。 
3. セルが`.`を配置しているかどうかを確認します。`C`ここではルール違反になります。 

これには、次のいずれでもないことを確認する必要があります。`i-1`、`i`、 または`i+1`含まれています`L`。 
4. 条件が満たされると、`C`位置で`i`。 

これを実行したら、すぐにマークを付けて、将来の決定がその効果を確認できるようにします。 
5.配置後`C`、増分することで次の位置をスキップします`i`1ではなく2で。 

これにより、制約された近傍で重複の競合が発生するような誤った配置が防止されます。 
6.置かない場合`C`、次のインデックスに移動するだけです。 

### なぜ効果があるのか

 重要な不変条件は、`C`、すべての禁止された相互作用は厳密にローカルであり、距離 1 を超えて伝播することはありません。これは、以前に行われた決定が後の選択によって無効になることはできないことを意味します。 を置くだけなので、`C`隣接するセルがクリーンな場合、それ以降の配置によってそのセルに関連する競合が発生する可能性はありません。`C`少なくとも 2 歩離れています。 したがって、貪欲な選択は安全で局所的に最適であり、各配置が正確に最小限の禁止領域を消費するため、局所的な最適性は全体的な最適性を意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = list(input().strip())
    n = len(s)

    i = 0
    while i < n:
        if s[i] == '.':
            left_ok = (i == 0 or s[i - 1] != 'L')
            right_ok = (i == n - 1 or s[i + 1] != 'L')

            if left_ok and right_ok:
                s[i] = 'C'
                i += 2
                continue
        i += 1

    print(''.join(s))

if __name__ == "__main__":
    solve()
```この実装は貪欲スキャンを反映しています。 Python 文字列は不変であるため、文字列をリストに変換してインプレース更新を可能にします。 2 つの境界チェックは、インデックス エラーなしでエッジ セルをきれいに処理します。 を配置した後、`C`、次のインデックスをスキップすることは、近傍が「使用された」ばかりの位置の再評価を防ぐ実際的な最適化です。 

よくある落とし穴は、配置する前に両方の隣をチェックするのを忘れることです。`C`。 もう 1 つは境界を適切に処理できず、誤った拒否やインデックス エラーが発生する可能性があります。`i = 0`または`i = n - 1`。
