 ## 解決策
 ## 問題の理解

 このプロセスの各試行では、「特別な」人形または「通常の」人形が作成されます。 確率で特別な人形が出現$p = \frac{a}{b}$チルノは正確に収集するまで独自の試行を繰り返します$n$特別な人形。 確率変数$x$は、それらに到達するために必要な試行の合計数です。$n$成功。 

これは古典的な負の二項設定です。$x$の合計です$n$独立した待ち時間。各待ち時間は、確率で 1 回の成功を得るのに必要な試行回数です。$p$。 

タスクは単に期待値を計算することではありません。$x$ただし、すべての瞬間を計算するには$$\mathbb{E}[x^k] \quad \text{for } k = 0,1,\dots,m$$有限場の弾性率の下で$998244353$。 

出力は次のシーケンスです。$m+1$値。各値は$k$- の分布の生の瞬間$x$、指定された素数を法として解釈されます。 

この制約により、多項式ベースの解決策が求められます。 両方$n$そして$m$までです$10^5$したがって、各瞬間を個別に処理したり、プロセスをシミュレートしたりするアプローチは、すぐに遅すぎます。 平$O(nm)$すでに$10^{10}$、それは限界をはるかに超えています。 

単純な確率的シミュレーションも不可能です。$x$無制限です。 すべての可能な値について明示的に確率を計算することもできます。$x$サポートは無限であるため、実行できません。 

主要な構造上の困難は、1 つだけではなく多くのモーメントが必要であるため、どのソリューションでも共有計算でモーメント シーケンス全体を計算する必要があることです。 

微妙なエッジケースが現れるのは、$p = 1$。 そうすれば、すべての試みは成功するので、$x = n$決定論的に。 その場合、すべての瞬間はただ単に$n^k$。 ここでは、あらゆる確率的機構が正しく縮退する必要があります。 そうしないと、ゼロ除算または無限級数の切り捨てエラーが発生する可能性があります。 

## アプローチ

 問題について考える直接的な方法は、以下を参照することです。$x$独立した幾何学的確率変数の合計として。 各スペシャルドールは成功までの待ち時間に対応しています。 1 つの幾何学的変数のモーメントを計算し、それらを組み合わせることができれば$n$時には問題を解決します。 

単一の幾何学的変数については、通常のモーメントではなく、階乗モーメントの観点からコンパクトな記述を導き出すことができます。 これが重要な変化です。通常の累乗は和の下では悪い挙動をしますが、階乗モーメントは組み合わせ構造で線形に動作します。 

確率変数の場合$X$、その下降階乗モーメントを定義します。$$\mathbb{E}[(X)_k] = \mathbb{E}[X(X-1)\cdots(X-k+1)].$$独立変数の合計の場合、階乗モーメントは指数母関数によってきれいに結合されます。 定義すると$$A(t) = \sum_{k \ge 0} \mathbb{E}[(X)_k]\frac{t^k}{k!},$$次に、独立したコピーの合計については、対応する系列が単純に累乗されます。 

したがって、問題全体は次の 3 つの変換に集約されます。 

まず、1 つの幾何学的待ち時間の階乗モーメント生成系列を計算します。 

次に、累乗します$n$の合計を表す倍$n$そのような変数。 

3 番目に、第 2 種スターリング数を使用して階乗モーメントを通常のモーメントに変換します。 

重要な単純化は、幾何学的分布が特にきれいな階乗モーメント構造を持っていることです。 させたら$q = 1 - p$、シフトされた変数を定義します$Y = X - 1$、 それから$Y$階乗モーメントがある$$\mathbb{E}[(Y)_k] = (k-1)! \left(\frac{q}{p}\right)^k \quad (k \ge 1).$$この恒等式により、ランダム性が単純な指数対対数形式に折りたたまれます。$$\sum_{k \ge 1} \mathbb{E}[(Y)_k]\frac{t^k}{k!}
= \sum_{k \ge 1} \frac{1}{k}\left(\frac{q}{p}t\right)^k
= -\ln(1 - rt),$$どこ$r = \frac{q}{p}$。 

したがって、1回の試行待ち時間の階乗モーメント母関数は次のようになります。$$A(t) = 1 - \ln(1 - rt).$$以来$x$の合計です$n$i.i.d. このような変数を使用して、この級数を指数関数的に計算します。$$A_n(t) = A(t)^n.$$最後に、次数までの係数を抽出します。$m$、スターリング変換を使用して階乗モーメントから通常モーメントに変換します。 

解全体は多項式代数になります: 対数、べき乗、次数で切り捨てられたスターリング畳み込み$m$。

 ## アルゴリズムのチュートリアル

 完全に形式べき級数モジュロの代数で解を構築します。$998244353$。 

1. コンピューティング$p = a \cdot b^{-1} \bmod MOD$そして$r = (1-p)/p$。 これにより、幾何分布が単一のパラメータに正規化されます。 
2. 切り捨てべき級数を構築します。$$A(t) = 1 - \ln(1 - rt)$$程度まで$m$。 対数は標準級数を使用して拡張されます$$-\ln(1-x) = \sum_{k \ge 1} \frac{x^k}{k}.$$各係数は直接計算されます。$O(m)$。 
3. 上げる$A(t)$力に$n$形式的なべき級数べき乗を使用します。 これは次の方法で行われます。$$A(t)^n = \exp(n \ln A(t)).$$log と exp は両方とも、切り捨てられた系列に対するニュートン反復を使用して計算されます。 
4. 結果として得られる系列は、次の階乗モーメントを与えます。$x$:$$F_k = \mathbb{E}[(x)_k].$$5. スターリング数を使用して階乗モーメントを通常モーメントに変換します。$$\mathbb{E}[x^k] = \sum_{i=0}^k S(k,i) F_i.$$これは、事前に計算されたスターリング三角形を使用して計算されます。 
6. すべての値を出力します。$k=0$に$m$。 

### なぜ効果があるのか

 核となる不変条件は、各変換が異なる基底で正しいモーメント エンコードを保持することです。 対数ステップは独立性を加算性に変換するため、幾何学的待ち時間の合計は級数形式の累乗になります。 指数関数的なステップにより、合計の分布が復元されます。 最後に、スターリング変換は要因モーメントと通常モーメントの間の基底の変更そのものであるため、どの段階でも確率情報が失われることはありません。 正しさは、各ステップが形式べき級数の代数における単位であり、近似ではないという事実からわかります。

def stirling2(m):

 ## 特殊なケース

 いつ$p = 1$、すべての試行はすぐに成功するため、$x = n$決定論的に。 この場合、アルゴリズムはすべての一連の機械をバイパスし、直接出力します。$n^k$。 計算を試みる$r = (1-p)/p$そうしないとゼロによる除算が発生するため、この分岐は正確さを保つために不可欠です。 

いつ$n = 1$の場合、問題は単一の幾何学的変数に帰着します。 階乗モーメント系列は底対数展開に帰着し、べき乗ステップは恒等になります。 級数を 1 乗することで正確に保存されるため、この実装は引き続き正しく動作します。 

いつ$m = 0$、ゼロ番目のモーメントのみが必要です。 アルゴリズムは正しく出力します$1$、すべての確率変数には$\mathbb{E}[x^0] = 1$、スターリング変換は単一の定数項に縮退します。
