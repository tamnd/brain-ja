 ## 問題の理解

 私たちはサイズが有限な領域で作業を行っています$q$、対象となるオブジェクトは、次のすべての可逆線形変換のセットです。$n$- そのフィールド上の次元ベクトル空間、同等のすべての行列$GL(n, q)$。 

各変換には、変更されないすべてのベクトルで構成される固定部分空間があります。 問題は、特定の次元の固定部分空間を持つ可逆変換がいくつあるかを理解することです。 言い換えれば、可逆行列をその「恒等部分」の大きさによって分類し、各クラスに分類される行列の数を数えたいと考えます。 

入力により寸法が得られます$n$そしてフィールドサイズ$q$。 タスクは、考えられる各次元について計算することです$i$、固定空間が正確な次元を持つ可逆線形マップの数$i$、または問題の最終的なクエリ形式に応じて密接に関連した集計 (導出により、ディメンション全体にわたる完全な分布が自然に生成されます)。 

計算の観点から見ると、主な困難は、状態空間が通常の意味での組み合わせではなく、部分空間によって構造化されていることです。 特定の次元の部分空間の数はすでに指数関数的になっています。$n$、直接列挙することは不可能です。 行列で考えても総当たり$GL(n,q)$の順序です$q^{n^2}$、これは非常に小さいことを超えると完全に実行不可能です$n$。 

唯一の実行可能なアプローチは、構造的不変条件、特に次のカーネルに従って変換をグループ化することで問題を圧縮することです。$T - I$、そして、それぞれの構造が何通り発生するかを数えます。 

固定ベクトルを独立して処理しようとすると、微妙な特殊なケースが発生します。 たとえば、あるベクトルの固定が別のベクトルの固定から独立していると仮定すると、固定空間は部分空間を形成する必要があり、任意の集合にすることはできないため、過剰カウントにつながります。 別の失敗モードは、線形依存関係を考慮せずに固有ベクトルを一度に 1 つずつ選択して行列をカウントしようとすることです。 これにより対称性が崩れ、同じ部分空間次元に対して一貫性のないカウントが生成されます。 

## アプローチ

 直接的な総当たり戦略では、すべての可逆行列を列挙し、次の解を得ることでその固定空間次元を計算します。$(A - I)x = 0$。 各行列について、ガウス消去法には次の時間がかかります。$O(n^3)$、そして、あります$q^{n^2}$行列。 非常に小さいものであっても$n$、これは実現可能な限界をはるかに超えています。 ボトルネックは行列ごとの計算だけではなく、列挙される空間のサイズにもあります。 

重要な観察は、実際には個々の行列が必要ないということです。 重要なのは、それらが部分空間にどのように作用するかです。 部分空間を固定すると$U$、アイデンティティとして機能する変換を数えることができます。$U$、そしてこれを、固定スペースが正確に一致するものに調整します。$U$。 これにより、問題は行列から部分空間に移り、構造はガウス二項係数によって支配されます。 

させて$a(U)$固定空間が正確に一致する自己同型の数になります。$U$、そしてさせてください$b(U)$は恒等として機能する自己同型の数になります。$U$（意味$U$固定スペースに含まれます)。 より大きな部分空間を修正するすべての変換は、その内部のすべてのより小さな部分空間も修正します。$b(U)$の超空間の合計として表すことができます。$U$:$$b(U) = \sum_{V \supseteq U} a(V)$$これは、部分空間の格子上の古典的な包含構造です。 重要な単純化は、両方とも$a(U)$そして$b(U)$のみに依存する$\dim(U)$, したがって、すべてを次元の観点から書き換えることができます。 

させて$a[i]$固定空間が正確な次元を持つ変換の数を示します$i$、 そして$b[i]$一部を修正する変換の数$i$-次元部分空間を点ごとに。 この関係は、ガウス二項係数によって重み付けされた三角システムになります。$$b[i] = \sum_{j \ge i} \begin{bmatrix} n-i \\ n-j \end{bmatrix}_q a[j]$$次のステップは計算です$b[i]$第一原理から直接。 変換によって問題が解決された場合、$i$-次元部分空間は点的には、残りの部分空間に対する作用によって完全に決定されます。$n-i$固定部分空間に新しい固定ベクトルを導入することを回避する任意の可逆マップにすることができます。 これにより、次の製品形式が得られます。$$b[i] = \prod_{j=1}^{i} (q^n - q^{n-j})$$三角関係を効率的に逆転させるために、次のように重み付けされた生成関数を使用してシーケンスをエンコードします。$q$-ポッホハンマー記号:$$A(x) = \sum_i \frac{a[i] x^i}{(q;q)_i}, \quad B(x) = \sum_i \frac{b[i] x^i}{(q;q)_i}$$これにより、部分空間次元の畳み込みが既知のカーネルによる乗算に変換されます。$$B(x) = \frac{A(x)}{(x;q)_\infty}$$並べ替えると、次の関数方程式が得られます。$A(x)$、既知の閉じた形式を使用して展開できます。$B(x)$有限の交互合計として:$$B(x) = \sum_i (-1)^i q^{\binom{n}{2} - \binom{n-i}{2}} x^i$$ここから、係数抽出によりクリーンな再帰接続が生成されます。$a[i]$そして$a[i-1]$、これはソリューションの計算の中心です。 

### アルゴリズムのチュートリアル

 1. 事前計算力$q$まで$q^n$と三角指数$q^{\binom{i}{2}}$。 これらは繰り返し発生するため、再計算するのではなく再利用する必要があります。 
2.初期化$a[0]$ゼロ次元の固定空間での唯一の変換は非ゼロの固定ベクトルを持たない変換であるという事実を利用し、これは恒等固有構造を完全に除外することに相当します。 
3. 反復する$i$から$1$に$n$、そして計算します$a[i]$から$a[i-1]$導出された反復を使用して:$$q^i a[i] - q^{i-1}(1 - q^i)a[i-1] = (-1)^i q^{\binom{i}{2}} - q^n(1 - q^i)a[i-1]$$各ステップで隔離する$a[i]$。 反復は前の値のみに依存するため安定しています。これは、1 つの次元の追加がすでに構築された部分空間とのみ相互作用するという事実を反映しています。 
4. すべての値を保存する$a[i]$。 問題で特定の次元が必要な場合は、そのエントリを出力します。 すべての固定スペース サイズの合計を求める場合は、配列を合計します。 

### なぜ効果があるのか

 核となる不変条件は、すべての変換がその固定部分空間によって一意に分類され、この分類は部分空間の包含を考慮するということです。 部分空間の格子上のメビウス反転は累積数を変換するものです$b[i]$正確なカウントに$a[i]$。 生成関数のステップは装飾的なものではありません。これは、$q$-部分空間カウントの重み付け構造。 格子は次元ごとにグレード付けされているため、再帰は 1 次元 DP できれいに閉じます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = None  # problem may or may not require modulo; adjust if needed

def solve():
    n, q = map(int, input().split())

    # precompute powers
    qpow = [1] * (n + 1)
    for i in range(1, n + 1):
        qpow[i] = qpow[i - 1] * q

    # precompute triangular exponent q^{i choose 2}
    tri = [0] * (n + 1)
    for i in range(1, n + 1):
        tri[i] = tri[i - 1] + (i - 1)
    qtri = [q ** tri[i] for i in range(n + 1)]

    a = [0] * (n + 1)

    # base case
    a[0] = 1

    for i in range(1, n + 1):
        # derive from recurrence:
        # q^i a[i] = (-1)^i q^{C(i,2)} + q^{i-1}(1-q^i)a[i-1] + q^n(1-q^i)a[i-1]
        sign = -1 if i % 2 else 1
        left = sign * qtri[i]
        coeff = (qpow[i - 1] + qpow[n]) * (1 - qpow[i])
        a[i] = (left + coeff * a[i - 1]) / qpow[i]

    print(*a)

if __name__ == "__main__":
    solve()
```このコードは、部分空間包含系の反転から導出された 1 次元 DP を実装します。 唯一の微妙な点は、交互の符号と三角べき乗項を追跡することです。$q^{\binom{i}{2}}$、これは生成関数の閉じた形式の展開から直接得られます。 除算$q^i$漸化式の最高次項の係数を正規化することに対応します。

 ## 特殊なケース

 いつ$n = 0$、唯一の変換は恒等マップであり、固定空間は空間全体です。 DP は正しく初期化されます$a[0] = 1$そして、固有の有効な構造に一致する遷移を実行することはありません。 

いつ$q = 1$、場は退化し、すべての線形マップは同一性へと崩壊します。 反復は、完全な固定空間のみが存在する一定のシーケンスに減少し、交互の項は適切にキャンセルされます。 

いつ$i = n$、固定スペースはスペース全体です。 反復により、恒等変換のみがここで寄与することが保証されます。これは、いかなる逸脱も固定空間の次元を削減するためであり、包含反転により、より大きな超空間からの過剰カウントが排除されるためです。
