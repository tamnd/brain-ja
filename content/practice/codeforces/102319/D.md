 ## 解決策
 ## 問題の理解

 私たちはツーパイルの公平なゲームを行っています。 位置は 2 つのパイル サイズで表されます。`(x, y)`。 ターンでは、プレイヤーはちょうど 1 つの山から正の数の石を取り除くことができます。 両方の山から正の金額を削除することもできますが、削除される 2 つの金額の差は最大でも異なります。`k`。 正当な手を打たなかったプレイヤーは負けとなるので、`(0, 0)`負けの立場です。 

それぞれ最大で`10^5`独立したゲームの場合、2 つの初期パイル サイズと許容値を受け取ります。`k`。 印刷する必要があります`2`開始位置が最初のプレイヤーに負けているとき、そして`1`さもないと。 公式声明では、これらの限界とサンプルデータが確認されています。 

大きな座標の境界、`x,y <= 10^9`、パイルサイズによってインデックス付けされた動的プログラミングは除外されます。 1 つのゲームでも約`10^18`異なる立場。 と`10^5`ゲームと 2 秒の制限がある場合、目的のソリューションではゲームごとに定数または対数の演算を使用する必要があります。 という事実`k <= 12`これは、考えられる公差を大規模に検索する必要はなく、公差によって制御された方法で構造が変化するという強力なヒントでもあります。 

誤って対処しやすい特殊なケースがいくつかあります。 

端子位置が特殊です。 入力用```
1
0 0 0
```正しい出力は```
2
```最初のプレイヤーには移動がないからです。 正のインデックスのみを処理し、誤ってインデックス 0 を通常の P 位置として扱う数式では、この問題が発生する可能性があります。 

杭は交換可能であるため、入力座標の順序は重要ではありません。 のために```
1
2 1 0
```正しい出力は`2`、 なぜなら`(1,2)`負けているワイソフの立場です。 実際に値を交換せずに最初の座標が常に小さいと想定する実装では、有効な P 位置が拒否される可能性があります。 

許容値により、関連する対角線の間隔が変更されます。 のために```
1
1 3 1
```正しい出力は`2`。 この位置は、一般化されたワイソフ位置の 1 つであるため、負けています。`k=1`。 条件を次のように扱う`|a-b| < k`の代わりに`|a-b| <= k`ゲームを変更し、間違った分類を与えます。 

山の差が割り切れない場合`k+1`も重要です。 のために```
1
1 2 1
```正しい出力は`1`。 ここでの違いは`1`、 その間`k+1=2`したがって、位置自体が解によって記述される P 位置の 1 つになることはできません。 必要な等差数列に一致するかどうかではなく、差が「小さい」かどうかだけをチェックする不注意な実装では、誤って分類されてしまいます。 

最後に、パイルが等しいということは、ポジションが負けていることを意味するわけではありません。 のために```
1
5 5 3
```正しい出力は`1`。 このゲームで唯一等しい P ポジションは`(0,0)`なぜなら、一般化された P 位置は、そのインデックスが正であるときは必ず正の差があるからです。 

## アプローチ

 最も直接的なアプローチは、ゲームを再帰的に解決することです。 すべての正当な手が勝ちのポジションに行くと、そのポジションは負けとなり、少なくとも 1 つの手が負けのポジションに行くと、そのポジションは勝ちとなります。 メモ化を使用すると、正しい動的プログラムが得られます。 

問題は状態空間のサイズです。 初期の山が`X`そして`Y`、メモ化には依然としてすべての位置が必要になる場合があります`(x,y)`と`0 <= x <= X`そして`0 <= y <= Y`。 それはおおよそです`XY`州。 単一パイルの動きだけを数えたとしても、すべての状態で検査される遷移の合計数は次のようになります。 

\frac{XY(X+Y+2)}2.
 ]

のために`X=Y=10^9`、これについてです`10^27`2 パイルの動きを検討する前にトランジションを行ってください。 メモ化を行わない再帰は、同じサブゲームを繰り返し探索するため、さらに悪化します。 

画期的な点は、すべてのポジションを個別に考えるのをやめ、代わりにどのポジションが負けているかを正確に特徴付けることです。 このゲームはワイソフ ニムを一般化したものです。 正の整数の場合`r = k+1`、その P 位置は次によって生成されます。 

[
 a_n=\left\l フロア n\alpha\right\r フロア、
 \qquad
 b_n=a_n+rn、
 】

 どこで

 [
 \alpha=\frac{2-r+\sqrt{r^2+4}}2.
 】

 これは標準的な一般化された Wythoff 構造であり、2 つの相補的な Beatty シーケンスは以下の点で異なります。`rn`。 対応する P 位置の特性評価は、`k`-ワイソフ・ニムの特徴。 

理由`r=k+1`特にきれいに見えます。 連続する P ポジションには違いがあります

 [
 b_n-a_n=rn。 
】

 P ポジションから移動しようとすると`n`前の P ポジションへ`m`、2 つの削除量の違いは次のとおりです。 

[
 rn-rm=r(n-m)。 
]

以来`r=k+1`、この違いは少なくとも`k+1`、したがって、そのような動きは許可された境界に違反します`k`。 座標シーケンスは相補的であるため、P ポジション間での単一パイルの移動は不可能です。 

補完的な特性は、ソリューションの残りの半分です。 シーケンス`(a_n)`そして`(b_n)`すべての正の整数が 1 回だけ含まれます。 2 つの傾きは次の条件を満たすため、これはビーティの定理の直接の結果です。 

[
 \frac1\alpha+\frac1{\alpha+r}=1。 
】

 これにより、すべての非 P ポジションが P ポジションに移行する可能性があることを証明する方法が得られます。 

最後の分類は特に単純です。 2 つの山を次のように並べ替えます。`x <= y`、 させて`d=y-x`、と置きます`r=k+1`。 もし`d`で割り切れます`r`、させてください

 [
 n=\frac d r.
 】

 まさにその時点でポジションが負けています

 [
 x=a_n。 
】

 それ以外の場合は勝ちです。 

数値的な問題が 1 つ残っています。 コンピューティング`floor(n*alpha)`浮動小数点を直接使用するのは危険です。`n`と同じ大きさにすることができます`10^9`。 浮動小数点を完全に削除できます。 以来

 \左\l階
 \frac{n(2-r)+n\sqrt{r^2+4}}2
 \右\r床、
 】

 させてください

 [
 q=\left\lfloor n\sqrt{r^2+4}\right\rfloor。 
】

 それから

 [
 q=\left\lfloor\sqrt{n^2(r^2+4)}\right\rfloor,
 】

 これは Python で正確に計算できます。`math.isqrt`。 したがって、

 [
 a_n=
 \frac{n(2-r)+q}{2}
 】

 整数フロア除算を使用します。 浮動小数点近似は必要ありません。

 ## アルゴリズムのチュートリアル

 1. ゲームごとに、まずパイルの順序を変更します。`x <= y`。 ゲームは対称的であるため、結果は変わりません。 
2.セット`r = k + 1`。 一般化されたワイソフ P 位置は次の形式になります。`(a_n,b_n)`と

 [
 b_n-a_n=rn。 
】

 したがって、ポジションは次の場合にのみ P ポジションになることができます。`y-x`で割り切れます`r`。 
3. もし`d = y-x`で割り切れない`r`、ポジションをすぐに勝ちとして分類します。 P-ポジションは正確に違いがあります`rn`ある整数に対して`n`。 
4. それ以外の場合は計算します`n = d // r`。 この差がある場合に可能な唯一の P ポジションは次のとおりです。`(a_n,b_n)`、したがって、残りの質問は、`x`等しい`a_n`。 
5. コンピューティング

 [
 a_n=
 \左\l階
 n\frac{2-r+\sqrt{r^2+4}}2
 \右\r床
 】

 浮動小数点なし。 計算する

 [
 q=\演算子名{isqrt}(n^2(r^2+4)),
 】

 それから使用します

 [
 a_n=(n(2-r)+q)//2。 
】

 の`isqrt`この演算により、平方根の正確な整数の下限が得られます。 
6. もし`x == a_n`、ポジションは P ポジションなので、最初のプレイヤーが負けて次のように出力します。`2`。 それ以外の場合は N ポジションなので、最初のプレイヤーが勝ちとなり、次のように出力されます。`1`。 

### なぜ効果があるのか

 2つのシーケンス

 [
 a_n=\lf フロア n\alpha\r フロア、
 \qquad
 b_n=\l フロア n(\alpha+r)\r フロア
 】

 それらの傾きは次の条件を満たすため、相補的です。 

[
 \frac1\alpha+\frac1{\alpha+r}=1。 
】

 したがって、すべての正の整数は 2 つのシーケンスのうちの 1 つに正確に現れます。 

インデックスを持つ 2 つの異なる P 位置を考慮します。`m < n`。 それらの座標の差は両方とも正であり、除去される 2 つの量の差は次のようになります。 

k+1。 
】

 したがって、合法的な 2 パイルの動きは 2 つの P ポジションを接続できません。 相補性とは、異なる P ポジション座標間で座標が共有されないことを意味するため、1 パイル移動でもそれらを接続することはできません。 

今度は非 P ポジションを取ります`(x,y)`と`x <= y`。 一つの座標が上位配列に属する場合`b_n`、相補性により、単一パイル移動を使用して、対応する P 位置を取得するために他の座標を減らすことができます。 

残りのケースは、`x=a_m`そして`y=a_n`。 もし`y>b_m`、減らすことができます`y`に`b_m`そして到達する`(a_m,b_m)`。 それ以外の場合は、

 [
 d=y-x=a_n-a_m<b_m-a_m=rm。 
】

 選択してください

 [
 j=\left\lfloor\frac d r\right\rfloor。 
]

それから`j<m`そして

 [
 0\le d-rj\le r-1=k。 
]

以来`a_j < a_m=x`そして`b_j=a_j+rj <= y`、両方の山を次のように減らすことができます`(a_j,b_j)`。 2 つの除去量は正確に異なります`d-rj`、最大でも`k`。 したがって、すべての非 P ポジションには P ポジションへの移動があります。 

これら 2 つの特性は、まさに損失ポジションの特性を定義するものです。P ポジションから離れる動きはありませんが、他のすべてのポジションには P ポジションへの動きがあります。 したがって、分類は正しいです。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        x, y, k = map(int, input().split())

        if x > y:
            x, y = y, x

        r = k + 1
        d = y - x

        if d % r != 0:
            out.append("1")
            continue

        n = d // r

        # a_n = floor(n * (2 - r + sqrt(r^2 + 4)) / 2)
        # floor(n * sqrt(D)) = isqrt(n^2 * D)
        D = r * r + 4
        q = math.isqrt(n * n * D)

        a = (n * (2 - r) + q) // 2

        if x == a:
            out.append("2")
        else:
            out.append("1")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```ループの最初の部分では 2 つの山を並べ替えます。 これにより、コードの残りの部分で規則を使用できるようになります。`x <= y`また、すべての P ポジションの両方の方向をチェックする必要がなくなります。 

変数`r`は`k+1`、 ない`k`。 このオフバイワンがゲームの中心的な詳細です。 P 位置の差は次の倍数です。`k+1`2 つの P ポジションは許容差以上離れている必要があるため`k`削除された量の間。 

割り算テストは平方根計算の前に行われます。 もし`d`で割り切れない`r`、その座標差では可能な P 位置は存在しないため、答えはすぐに得られます。`1`。 

いつ`d`割り切れる、`n=d/r`唯一の候補 P ポジションを特定します。 次に、コードはより小さい座標を計算します。`a_n`。 

を含む表現`isqrt`正確です。 させて`D=r*r+4`。 以来

 [
 \operatorname{isqrt}(n^2D)=\lfloor n\sqrt D\rfloor,
 】

 Beatty の式の無理数部分を整数に置き換えることができます。 Python の整数には任意の精度があるため、最大の中間値は約`10^20`、オーバーフローすることはできません。 

の`// 2`不合理な用語にもかかわらず、操作も安全です。 もし

 [
 n\sqrt D=q+f,\qquad 0\le f<1,
 】

 その場合、下限される数量は次のようになります`(integer + f)/2`。 整数部分が偶数か奇数かに関係なく、小数部分が結果を次の整数に押し込むことはできません。 したがって、フロアは次を使用して整数の分子から正確に取得されます。`// 2`。 

コードは使用します`sys.stdin.readline`要求どおりに。 ゲームごとに少数の整数演算と 1 つの整数平方根のみを使用する実装により、大規模なゲーム状態テーブルの構築が簡単に回避されます。

 最初のサンプル ゲームを考えてみましょう。`(0,0,k=0)`。 ここ`r=1`そして杭はすでに注文されています。

 |`5 5 3`、`10^9 10^9 12`、`0 10^9 0`|`1, 1, 1`| 等しい山、最大座標、および 1 つの山が空になる位置。 |

 ## 特殊なケース

 端子位置について```
1
0 0 0
```アルゴリズムは取得します`r=1`、`d=0`、 そして`n=0`。 正確な平方根式はゼロなので、`a_0=0`。 以来`x=0`、ポジションは負けとして認識され、出力は次のようになります。`2`。 実際には特別なケースは必要ありません`(0,0)`。 

座標を反転する場合は、次のことを考慮してください。```
1
2 1 0
```アルゴリズムはまずパイルを交換し、次の結果を取得します。`(1,2)`。 と`r=1`、違いは`1`、与える`n=1`。 式は次のようになります`a_1=1`、したがって、位置は P であり、答えは次のようになります。`2`。 最初のスワップがないと、座標が逆の順序で提供されたという理由だけで、正しい P 位置が拒否される可能性があります。 

公差の境界については、次のことを考慮してください。```
1
1 13 12
```ここ`r=13`そして`d=12`。 以来`12 % 13 != 0`、アルゴリズムはすぐに戻ります`1`。 一般化された P 位置には違いがあるため、これは正しいです。`0,13,26,39,...`。 ポジションは実際にからの直接の動きによって勝っています。`(1,13)`に`(0,0)`を削除します。`1`そして`13`石、その違いが許容誤差に正確に一致する`12`。 

同じ公差での実際の P ポジションについては、次のことを考慮してください。```
1
1 14 12
```今`d=13`、 それで`n=1`。 と`r=13`、

 [
 a_1=
 \左\l階
 \frac{2-13+\sqrt{173}}2
 \右\r床
 =1。 
]

したがって`(1,14)`は P 位置で、出力は`2`。 このペアは、関連する間隔が適切である理由を正確に示しています。`k+1`、 それよりも`k`。 

等しい山については、次のことを考慮してください。```
1
5 5 3
```その差はゼロなので、`n=0`そして`a_0=0`。 小さいパイルなので、`5`、 ない`0`、位置は P ではなく、答えは次のとおりです。`1`。 最初のプレイヤーは 1 つの山から 5 つの石を取り除き、`(0,5)`、その後、相手は動きます。 

最大座標については、次の点を考慮してください。```
1
1000000000 1000000000 12
```また`d=0`、だからそれだけ`n=0`考慮する必要があります。 アルゴリズムは計算します`a_0=0`、パイルサイズがゼロではないことを確認し、出力します`1`。 解では位置が列挙されないため、大きな座標によって状態空間の爆発が発生することはありません。 

最後の微妙なケースは、正確な浮動小数点境界です。 式には、無理平方根に次のような大きさのインデックスを乗じた値が含まれています。`10^9`。 使用する`float`そして電話`int(n*alpha)`四捨五入が整数の間違った側に達した場合、理論的には答えが間違っている可能性があります。 この実装では、無理計算を次のように置き換えることで、そのクラスのエラー全体を回避します。`math.isqrt(n*n*(r*r+4))`したがって、すべての比較は正確な整数を使用して実行されます。
