 ## 解決策
 ## 問題の理解

 ピンを三角形に配置しています。`n`最下段のピン、`n - 1`その上の行など、合計\[
1+2+\dots+n=\frac{n(n+1)}2
\]ピン。 

ボールが転がった後、ボール自体が倒すことができる唯一のピンは上のピンです。 ノックダウンされたピンは 1 つおきに、その直前のピンによって引き起こされたものに違いありません。 ピンは、前の列でピンを支えている 2 本のピンがすでに倒れている場合にのみ倒れます。両側のピンの自然な境界解釈が使用されます。 

課題は、特定の最終的な取り決めを見つけることではありません。 1 つのロールの後に発生する可能性のあるすべての個別の配置を数える必要があります。 

入力には辺の長さが含まれます`n`、 どこ`4 <= n <= 20`。 最大の三角形には 210 個のピンしか含まれていないため、1 つの構成を保存するのは簡単です。 難しいのは、210 個の独立した二者択一が既に与えられてしまうことです。\(2^{210}\)考えられるサブセット、大まかに\(1.6 \times 10^{63}\)。 直接列挙は、1 秒で実行できるものをはるかに超えています。 の小さな値`n`有効な構成の組み合わせ構造が見つかった後にのみ役に立ちます。 

誤って扱いやすいエッジケースが 2 つあります。 のために`n = 4`、答えは`42`、 ない`2^10 = 1024`ほぼすべてのサブセットが因果律に違反しているためです。 有効な構成は、まさにこの三角形の依存関係構造に関連付けられたカタロニア語オブジェクトです。 もう一方の端では、`n = 20`には 210 個のピンがありますが、答えは依然として 64 ビット整数に快適に収まります。\[
C_{21}=24466267020.
\]固定幅の 32 ビット整数を使用する不注意な実装では、入力自体が小さい場合でも、この入力でオーバーフローが発生します。 Python の任意精度の整数を使用すると、この問題が回避されます。 

## アプローチ

 直接的な解決策では、210 個のピン位置のすべてのサブセットを列挙します。 各サブセットについて、ノックダウンされたピンをすべてチェックし、必要な先行ピンもノックダウンされていることを確認します。 これは正しいです。物理的に考えられるすべての結果は単に 1 つの有効なサブセットであり、先行条件のチェックがルールに正確に一致するためです。 

問題はサブセットの数です。 \(N=\frac{n(n+1)}2\) ピンの場合、ブルート フォースにはおよその時間がかかります\(2^N\)構成チェック、さらには構成ごとの定常的なチェックさえも絶望的です。 最大でも`n = 20`、これは\(2^{210}\)、 約\(1.64\times10^{63}\)構成。 各構成に \(O(N)\) 検証を追加すると、アプローチはさらに悪化します。 

重要な観察は、有効なノックダウン セットは任意のサブセットよりもはるかに強力な構造を持っているということです。 ピンが落下すると、依存関係チェーンに沿ってその上にあるすべてのピンも落下する必要があります。 言い換えれば、倒れたピンは三角形の依存関係ポセットの次数イデアルを形成します。 そのような理想は、その境界によって完全に説明されます。 

倒れたピンと直立したピンを分ける境界を描くと、その境界は単調なパスとしてエンコードできます。 依存関係条件により、パスがそれ自体を横切ったり三角形領域から出たりすることが防止され、両端での通常のパディングの後、これらの境界はまさにセミレングスの Dyck パスになります。`n + 1`。 

セミレングスのDyckパスの数`m`です`m`-番目のカタルーニャ語の数字、\[
C_m=\frac{1}{m+1}\binom{2m}{m}.
\]ここ`m = n + 1`したがって、必要な答えは次のとおりです。\[
\boxed{C_{n+1}
=\frac{1}{n+2}\binom{2n+2}{n+1}}.
\]ブルート フォースは、考えられるすべての状態を考慮し、無効な状態を拒否するため機能しますが、状態空間はピンの数で指数関数的であるため失敗します。 境界観測により、これらすべての州が標準的なカタロニア語族にまとめられ、計算が短い算術ループに削減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 |---|---|---|---|
 | ブルートフォース | \(O(n^2 2^{n(n+1)/2})\) | \(O(n^2)\) | 遅すぎる |
 | カタルーニャ語の式 | \(O(n)\) | \(O(1)\) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. しましょう`m = n + 1`。 有効なピン構成は、Dyck パスと 1 対 1 で対応します。`m`オープニングステップと`m`終わりのステップ。 余分な1つは、`n + 1`は三角形の境界の 2 つの辺と上部の依存関係から得られるため、ピンの境界は辺の長さよりも 1 つ大きいセミレングスの Dyck パスによって表されます。 

2. カタロニア語番号を計算します\[
   C_m=\frac{1}{m+1}\binom{2m}{m}.
   \]階乗を使用して二項係数を計算することもできますが、乗法漸化式の方が単純であり、大規模な中間階乗を構築する必要がありません。 

3. から始める`C_0 = 1`そして使用します\[
   C_k=C_{k-1}\frac{2(2k-1)}{k+1}.
   \]これはカタロニア数の標準的な整数反復であるため、すべての除算は正確です。 

4. まで続けます`k = n + 1`、印刷します`C_{n+1}`。 

### なぜ効果があるのか

 すべての有効な構成には、ピンが落ちた場合、その先行ピンがすべて強制的に落ち込むという特性があります。 したがって、倒れた領域は任意の形状をとることができない。 その境界は三角形の配置内を単調に移動し、依存条件はまさに、対応する境界パスが禁止対角線を決して横切らないという条件です。 したがって、各有効なピン構成は 1 つの Dyck パスを提供し、そのような各 Dyck パスは 1 つの有効な構成を再構築します。 セミレングスのダイクパスなので`n + 1`によって数えられます\(C_{n+1}\)の場合、アルゴリズムは物理的に可能な最終位置の数を正確に返します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    m = n + 1

    # Catalan number C_m.
    cat = 1
    for k in range(1, m + 1):
        cat = cat * 2 * (2 * k - 1) // (k + 1)

    print(cat)

if __name__ == "__main__":
    solve()
```入力は単一の整数で構成されているため、`solve`それを直接読みます。 設定`m = n + 1`ピン三角形のジオメトリを対応するカタロニア語インデックスに変換します。 

変数`cat`現在のカタロニア語番号を保存します。 最初にそれが表すのは、\(C_0=1\)。 反復時`k`、再発により次のように変換されます。\(C_k\)。 乗算は除算の前に実行され、Python の整数は任意の精度を持つため、オーバーフローのリスクはありません。 

ループは次で終了します`n + 1`、組み合わせ対応で必要なインデックスと正確に一致します。 配列や再帰がないため、実装では一定の補助空間が使用されます。

のために`n = 5`、必要です\(C_6\)。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 |---|---|---|
 | 時間 | \(O(n)\) | カタルーニャ語の再発は次のように評価されます。`n + 1`価値観。 |
 | スペース | \(O(1)\) | 現在のカタルーニャ語値といくつかの整数のみが保存されます。 |

def solve_value(n: int) -> str:

 ## 特殊なケース

 のために`n = 4`、三角形にはピンが 10 個しか含まれていないため、強引に見える可能性があります。 アルゴリズムはそれらを列挙しません\(1024\)サブセット。 直接計算します\(C_5\)、生産`42`。 任意のサブセットの大部分が先行条件に違反しているため、この区別は重要です。 

のために`n = 20`、ピンが 210 個あるため、構成を列挙するには考慮する必要があります。\(2^{210}\)サブセット。 代わりにアルゴリズムが計算します\(C_{21}\)21 の繰り返しステップを経ます。 値は正確なままで、次で終わります。`24466267020`。 

インデックス作成は最も犯しやすい算術ミスです。 使用する\(C_n\)与えるだろう`14`のために`n = 4`、正しい結果は次のとおりです。`42`。 三角形の境界はセミレングスの Dyck パスに対応します`n + 1`したがって、実装では意図的に設定されています。`m = n + 1`再発を評価する前に。 

漸化式では、分母も次のようにする必要があります。`k + 1`。 たとえば、`k = 5`、\[
C_5=C_4\frac{2(2\cdot5-1)}{5+1}
=14\cdot\frac{18}{6}
=42.
\]使用する`k`代わりに、すべての演算が依然として整数であるにもかかわらず、不正な値が暗黙的に生成されます。 実装は標準的なカタロニア語の再帰に正確に従っているため、この境界条件は特別なケースなしで処理されます。
