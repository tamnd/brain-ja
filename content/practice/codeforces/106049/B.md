 ## 解決策
 ## 問題の理解

 から番号が付けられた頂点を持つ正多角形があります。`1`に`n`時計回りの順に。 頂点間にセグメントを描画できます`i`そして`j`頂点がポリゴン境界上で隣接していない場合のみ、および`gcd(i, j) = 1`。 目標は、図面が交差しないようにしながら、そのようなセグメントをできるだけ多く描画することです。 セグメントは端点で接触することができますが、2 つのセグメントが内部で交差することはできません。 

入力には複数のテスト ケースが含まれており、それぞれが 1 つの値で構成されています`n`。 すべてのテスト ケースについて、追加できるセグメントの最大数を出力する必要があります。 

の最大値`n`は`10^5`、最大まであります`10^4`テストケース。 頂点ごとのジオメトリやグラフの構築を実行するソリューションは不要です。 テストケースごとに一定時間に近い時間が必要です。 

微妙な点は、共素性条件が重要に見えるため、複雑なグラフ構造を探索したくなるかもしれないということです。 重要な観察はその頂点です`1`は他のすべての頂点と互いに素です。 

考慮する`n = 3`。```
3
```三角形には対角線がないので、答えは次のようになります。`0`。 

共素性条件のみをチェックする不注意なソリューションでは、頂点に関係するセグメントが誤ってカウントされる可能性があります。`1`、隣接する頂点を接続できないことを忘れています。 

考慮する`n = 4`。 

唯一の対角線は、`(1,3)`、そしてそれは有効です。`gcd(1,3)=1`。 答えは`1`。 

すべての互いに素のペアを数えようとするソリューションでは、多くの有効なペアが交差なしでは共存できないため、過剰にカウントされてしまいます。 

## アプローチ

 ブルートフォースの方法は、すべての有効なセグメントを生成してから、最大の非交差サブセットを検索することです。 すべての候補セグメントを構築するだけでも、おおよその時間がかかります`O(n²)`ペアがあり、互換性のある最大のサブセットを見つけるのははるかに困難です。 と`n = 10^5`、これはまったく不可能です。 

ポリゴンの構造は、より強力な事実を与えます。 どれでも`n`-gon、交差しない対角線の最大可能数は次のとおりです。`n - 3`。 これはあらゆる三角測量で起こります。 

そこで問題は、実際に達成できるかということです。`n - 3`許可されたセグメントのみを使用しますか?

 はい。 

頂点からすべての対角線を取得します`1`頂点へ`3, 4, ..., n-1`。 

これらのセグメントは扇形三角形分割を形成します。 これらはすべて同じエンドポイントを共有するため、交差することはありません。 このようなセグメントはすべて有効です。`|1 - j| > 1`のために`j = 3 ... n-1`, したがって、頂点は隣接していません。`gcd(1, j) = 1`すべての整数に対して`j`。 

これらの対角線の数は正確に次のとおりです。$$(n-1) - 3 + 1 = n-3$$非交差構成には以下のものを含めることはできないため、`n-3`対角線、正確に構築しました`n-3`、これが最適です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) 以上 | O(n²) | 遅すぎる |
 | 最適 | テスト ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`n`。 
2. 交差しない対角線のセットはすべて、`n`-gon には最大でも次のものが含まれます`n - 3`対角線。 
3. 頂点からのすべての対角線を観察します。`1`頂点へ`j`と`3 ≤ j ≤ n-1`許可されている理由は`gcd(1, j) = 1`。 
4. これらの対角線は扇形を形成するため、どの対角線も互いに交差しません。 
5. このような対角線の数は正確に`n - 3`。 
6. 出力`n - 3`。 

### なぜ効果があるのか

 上限は多角形の三角形分割理論に由来しており、交差しない対角線のセットには以下のものを含めることはできません。`n - 3`対角線。 私たちの建設は正確に使用します`n - 3`対角線。そのすべてが問題の妥当性規則を満たします。 大域的な上限を達成し、すべての制約を同時に満たすので、答えは次のようになります。`n - 3`。

```すべての作業は数学的観察によって行われるため、実装は非常に小規模です。 

テストケースごとに出力します`n - 3`。 ジオメトリ、グラフ構築、GCD 計算は必要ありません。 証明により、ファンが頂点の中心にあることがすでに保証されています`1`常に存在し、最適です。 

唯一の境界条件は、`n = 3`。 その場合、式は次のようになります`0`三角形には対角線がないので、これは正しいです。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        ans.append(str(n - 3))

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out
