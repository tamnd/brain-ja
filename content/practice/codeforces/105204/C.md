 ## 解決策
 ## 問題の理解

 ルートは次の文字列で記述されます。`'0'`、`'1'`、 そして`'?'`。 

マークされたセグメント`'0'`サンダルで歩く必要があり、セグメントにマークが付いています`'1'`ブーツを履いて歩く必要があり、セグメントにはマークが付いています`'?'`どちらのタイプの履物も割り当てることができます。 サンダルからブーツへの履き替え費用`a`, ブーツからサンダルに履き替える際にかかる費用`b`。 旅行者はどちらの履物で出発し、どちらの履物で終了することもできるため、連続するルート区間間の変更のみが問題となります。 

タスクは、すべてを割り当てることです。`'?'`どちらか`'0'`または`'1'`すべての靴の交換にかかる総コストが可能な限り少なくなるように。 

ルートの長さは最大で`200000`, したがって、二次関数は直ちに不可能になります。 考えられるすべての割り当てをスキャンすることすら不可能です。`'?'`可能性の数が2倍になります。 アン`O(n)`または`O(n log n)`アルゴリズムは簡単に十分に高速です。 

難しいのは、すべての`'?'`はブロックに属しており、1 つのブロック内で異なる値を代入しても役に立ちません。 例えば：```
0??1
```それを次のように割り当てると、`0011`、遷移が 1 つあります。 それを次のように割り当てると、`0101`、3つの遷移があります。 ブロック内で追加の変更を行うと、コストが増加するだけです。 

もう 1 つのエッジ ケースは、文字列全体が次のもののみで構成されている場合です。`'?'`。```
???
```正しい答えは、`0`なぜなら、すべての位置に同じ値を割り当てることができるからです。 最初の既知の文字が常に存在すると仮定する解決策は失敗します。 

もう 1 つの微妙なケースは、`'?'`ブロックは既知の 1 つの側面のみに触れます。```
??111
```ブロックの割り当て`'1'`遷移はまったく生成されません。 近隣ブロックの欠落を考慮せずにすべてのブロックを個別に最適化しようとするソリューションでは、不必要な変更が導入される可能性があります。 

## アプローチ

 ブルートフォースソリューションでは、すべての割り当てを試します。`'?'`。 あれば`k`疑問符、これには必要です`2^k`課題。 各割り当ては線形時間でチェックでき、`O(n · 2^k)`数十の疑問符があっても不可能になる複雑さ。 

重要な観察は、隣接する文字間の遷移のみが答えに寄与するということです。 連続したブロック`'?'`左右の境界にのみ影響します。 ブロック内に変更を導入しても境界遷移の数を減らすことはできないため、最適な割り当てが行われるたびに、ブロック全体が 1 つの同一文字で埋められます。 

これにより、正確なブロック長を無視することができます。 代わりに、すべてを削除します`'?'`概念的に、固定された文字のシーケンスだけを見てください。 2 つの連続する固定文字が異なる場合は、避けられない履物の変更が 1 回発生する必要があります。 移行が次の場合`0 → 1`、費用がかかります`a`。 そうであれば`1 → 0`、費用がかかります`b`。 

毎`'?'`ブロックは、可能な限り常に 1 つの隣接する辺に一致するように埋めることができ、人為的な遷移を排除します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |`O(n · 2^k)`|`O(n)`| 遅すぎる |
 | 最適 |`O(n)`|`O(1)`| 承認済み |

 ## アルゴリズムのチュートリアル

 1. ルート文字列と値を読み取ります。`a`そして`b`。 
2. 文字列を左から右に、そうでない最初の文字が見つかるまでスキャンします。`'?'`。 これが以前の固定文字になります。 
3. 固定文字が存在しない場合は出力`0`なぜなら、すべての位置に同じ値を割り当てることができるからです。 
4. 文字列の残りのスキャンを続けます。 
5. すべて無視する`'?'`、その値は後で選択されるためです。 
6. 別の固定文字が見つかったら、それを前の固定文字と比較します。 
7. 異なる場合は追加します。`a`移行のために`0 → 1`または追加します`b`移行のために`1 → 0`。 
8. 以前の固定文字を更新して続行します。 
9. 累積コストを出力します。 

### なぜ効果があるのか

 連続するブロックごとに、`'?'`隣接する固定文字は 2 つだけです。 混合値でブロックを埋めると、ブロック内に追加の遷移が導入されるだけであり、総コストが減少することはありません。 ブロック全体を 1 つの値で埋めることは、常に少なくとも同等の効果があります。 

隣接する両方の固定文字が等しい場合、ブロック全体にその値が割り当てられ、遷移は作成されません。 

それらが異なる場合、ブロック内のどこで発生しても、1 つの遷移だけが避けられません。 コストは固定文字の順序のみに依存し、ブロックの長さには依存しません。 

全て取り外した後`'?'`、連続する固定キャラクター間のすべての移行は、まさに避けられない靴の交換 1 回であるため、これらのコストを合計すると最小限の答えが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    a, b = map(int, input().split())

    prev = None
    ans = 0

    for ch in s:
        if ch == '?':
            continue
        if prev is not None and prev != ch:
            if prev == '0':
                ans += a
            else:
                ans += b
        prev = ch

    print(ans)

if __name__ == "__main__":
    solve()
```実装では、以前の固定文字と現在の答えのみが保持されます。 

疑問符は答えに直接寄与しないため、すぐにスキップされます。 連続する 2 つの固定文字が異なる場合は、対応する移行コストが加算されます。 

旅行者はどちらの履物でも開始できるため、最初の固定キャラクターはコストを追加せずに状態を初期化します。 

文字列にのみが含まれている場合`'?'`、`prev`残っている`None`、遷移はカウントされず、答えは正しくゼロのままです。

## テストケース```python
import sys
import io

def solve():
    input = sys.stdin.readline
    s = input().strip()
    a, b = map(int, input().split())

    prev = None
    ans = 0

    for ch in s:
        if ch == '?':
            continue
        if prev is not None and prev != ch:
            ans += a if prev == '0' else b
        prev = ch

    print(ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    solve()
    sys.stdin = backup_stdin
    sys.stdout = backup_stdout
    return out.getvalue()

# provided sample
assert run("?0110?1?1\n5 9\n") == "19\n"

# minimum size
assert run("?\n3 4\n") == "0\n"

# all question marks
assert run("????\n5 7\n") == "0\n"

# alternating fixed characters
assert run("0101\n2 3\n") == "7\n"

# question block between equal symbols
assert run("1???1\n6 8\n") == "0\n"

# question block between different symbols
assert run("0???1\n6 8\n") == "6\n"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`?\n3 4`|`0`| 単一の不明なセグメント |
 |`????\n5 7`|`0`| ルート全体が柔軟です |
 |`0101\n2 3`|`7`| すべての移行は避けられません。 
|`1???1\n6 8`|`0`| エンドポイントが等しいと、すべての変更が排除されます。 
|`0???1\n6 8`|`6`| 異なるエンドポイントには 1 つの遷移が必要です。
