 ## 解決策
 ## 問題の理解

 一連の塔の高さで表される 2 つの壁があります。 

クマの壁には以下が含まれています`n`塔があり、ホレスの壁には`w`塔。 ホレスは壁全体をいくらでも垂直に動かすことができます。 壁内のすべての塔は同じ値だけシフトする必要がありますが、その値は正、負、またはゼロの場合があります。 

ある長さのセグメントの場合`w`クマの壁では、ホレスが壁をそのセグメントに正確に一致させるために垂直方向のシフトを選択できるかどうかを知りたいと考えています。 タスクは、そのようなセグメントがいくつ存在するかを数えることです。 

重要な詳細は、ホレスが壁内のすべての塔に同じ定数を追加できることです。 つまり、絶対的な高さは重要ではありません。 連続するタワー間の違いのみが問題となります。 

制約が到達する`2 · 10^5`要素。 あらゆる長さを比較するアルゴリズム -`w`パターンに対して直接セグメントを作成するには、大まかに必要になります`n · w`約に到達できる操作`4 · 10^10`、2秒の制限に収まる範囲をはるかに超えています。 線形時間に近いものが必要です。 

いくつかの特殊なケースは見落とされがちです。 

考慮する：```
n = 5, w = 1
a = [10, 20, 30, 40, 50]
b = [7]
```ホレスは壁をいくらでも移動できるため、すべての塔は 1 つの塔の壁と一致します。 正しい答えは、`5`。 

差分配列のみに基づくソリューションでは、空の差分シーケンスが生成され、誤って返される可能性があります。`0`このケースが個別に処理されない限り。 

別の例:```
a = [5, 8, 11]
b = [1, 4]
```セグメント`[5,8]`追加後に一致する`4`のあらゆる要素に`b`、 そして`[8,11]`追加後も一致します`7`。 

答えは`2`たとえ直接等しい高さがないとしても。 

3 番目の例は、連続した差分だけで十分である理由を示しています。```
a = [100, 103, 106]
b = [1, 4, 7]
```違いは次のとおりです。```
a: [3, 3]
b: [3, 3]
```追加後に壁が一致します`99`のあらゆる要素に`b`。 

## アプローチ

 ブルートフォースソリューションはあらゆる長さを検査します -`w`クマの壁の一部。 セグメントごとに、最初のタワーを位置合わせするために必要なシフトを計算し、そのシフトを適用した後に残りのすべてのタワーが一致することを確認します。 

有効な一致には単一の定数シフトを使用する必要があるため、これは正しいです。 コストを分析すると問題が見えてきます。 おおよそあります`n`候補セグメント、および各比較は最大で検査できます。`w`塔。 最悪の場合の複雑さは次のとおりです。`O(nw)`、これは約になります`4 · 10^10`両方の配列に長さがある場合の演算`2 · 10^5`。 

重要な観察は、すべてのタワーに定数を追加すると、連続した差異が維持されるということです。 

ホレスの壁が次のようなものであると仮定します。```
b1, b2, b3, ...
```そして何らかの価値を追加します`c`:```
b1+c, b2+c, b3+c, ...
```それから：```
(b2+c) - (b1+c) = b2-b1
```隣接するすべてのペアについても同様です。 

セグメントは、それらの差分配列が同一である場合にのみ、何らかのシフト後にホレスの壁と一致します。 

させて：```
DA[i] = a[i+1] - a[i]
DB[i] = b[i+1] - b[i]
```元の壁の一致は、以下の発生に正確に対応します。`DB`内部`DA`。 

ここで、問題は整数シーケンスでの古典的な文字列マッチング問題になります。 パターンの回数を数える必要があります`DB`文中に出てくる`DA`。 

Knuth-Morris-Pratt アルゴリズムは、線形時間内のパターンのすべての出現を見つけます。 差分配列には長さがあるので、`n-1`そして`w-1`、全体の複雑さは次のようになります。`O(n+w)`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(nw) | お(1) | 遅すぎる |
 | 最適 (差異 + KMP) | O(n+w) | O(n+w) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つの高さ配列を読み取ります。 
2. 特殊なケースに対処する`w = 1`。 

適切な垂直方向のシフトを選択すると、単一の塔は単一の塔の象の壁と一致することができます。 答えは単純です`n`。 
3. クマの壁の差分配列を構築します。 

隣接するペアごとに、以下を保存します。```
a[i+1] - a[i]
```2 つの一致する壁には同一の連続した差異がなければなりません。 
4. 同様にホレスの壁の差分配列を構築します。 
5. パターン差分配列の KMP プレフィックス関数を計算します。 

prefix 関数は、すべての位置について、サフィックスでもある最長の適切なプレフィックスの長さを格納します。 KMP はこの情報を使用して、不一致後の値の再チェックを回避します。 
6. クマの差分配列に対して KMP マッチングを実行します。 

一致したパターンの長さに達するたびに`len(DB)`、1件の出現が見つかりました。 
7. すべての出現をカウントし、結果を出力します。 

### なぜ効果があるのか

 定数が存在する場合、2 つの壁の違いは垂直方向のシフトだけです。`c`対応するすべてのタワーが正確に異なるようにする`c`。 

このような定数が存在する場合、隣接するすべての差分は同一であるため、差分配列は一致します。 

逆に、差分配列が一致する場合は、ホレスの壁の最初のタワーをセグメントの最初のタワーと位置合わせした後、連続するすべての変更が同じであるため、残りのすべてのタワーが強制的に一致します。 したがって、一致する差分配列は必要かつ十分です。 

KMP は、テキスト差分配列内のパターン差分配列のすべての出現を検出するため、すべての有効なセグメントが 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def prefix_function(pattern):
    pi = [0] * len(pattern)

    for i in range(1, len(pattern)):
        j = pi[i - 1]

        while j > 0 and pattern[i] != pattern[j]:
            j = pi[j - 1]

        if pattern[i] == pattern[j]:
            j += 1

        pi[i] = j

    return pi

def solve():
    n, w = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    if w == 1:
        print(n)
        return

    text = [a[i + 1] - a[i] for i in range(n - 1)]
    pattern = [b[i + 1] - b[i] for i in range(w - 1)]

    pi = prefix_function(pattern)

    j = 0
    ans = 0

    for x in text:
        while j > 0 and x != pattern[j]:
            j = pi[j - 1]

        if x == pattern[j]:
            j += 1

        if j == len(pattern):
            ans += 1
            j = pi[j - 1]

    print(ans)

solve()
```最初の重要な選択は取り扱いです`w = 1`すぐに。 1 要素の壁の差分配列は空であり、空のパターンで KMP を実行しようとすると、実装が不必要に複雑になります。 どの位置も有効なので、答えは単純です。`n`。 

次のステップでは、両方の壁を差分配列に変換します。 この変換により、無関係な絶対高さが削除され、垂直方向のシフトの下で保存された情報が正確に保持されます。 

prefix-function は、標準の KMP 前処理フェーズです。 不一致の後に一致したパターンがどの程度残っているかを記録し、スキャンを線形に保つことができます。 

マッチング段階では、`j`は常に、現在一致するプレフィックスの長さを表します。 いつ`j`パターンの長さ全体に達すると、1 つの出現が見つかりました。 リセットする`j`に`pi[j-1]`重複する一致を正しくカウントできるようになります。 

すべての算術演算は Python の整数に快適に適合します。 差はマイナスになる可能性がありますが、KMP は文字列に対して動作するのとまったく同じように、任意の整数シーケンスに対して動作します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + w) | 差分配列の構築、プレフィックス関数の計算、および KMP スキャンはすべて線形です。 
| スペース | O(n + w) | 差分配列とプレフィックス関数を格納します。 

と`n, w ≤ 2 · 10^5`、線形時間アルゴリズムは数十万回の演算のみを実行し、制限内に問題なく収まります。

 ## 特殊なケース

 1 つの塔のパターンを考えてみましょう。```
5 1
10 20 30 40 50
7
```アルゴリズムは即座にトリガーします。`w == 1`分岐と返却`5`。 どの塔も高さになれる`7`適切なシフトを選択した後、すべてのポジションが有効になります。 

次に、マッチングに大きなシフトが必要な場合を考えてみましょう。```
3 3
100 103 106
1 4 7
```差分配列は次のとおりです。```
DA = [3,3]
DB = [3,3]
```KMP は 1 つのオカレンスを見つけます。 アルゴリズムは実際のシフト値を使用しません。`99`なぜなら、マッチングの違いは、そのようなシフトが存在することをすでに証明しているからです。 

最後に、繰り返される値を考慮します。```
5 3
7 7 7 7 7
2 2 2
```差分配列は次のようになります。```
DA = [0,0,0,0]
DB = [0,0]
```KMP は、位置から始まるオカレンスを検索します。`0`、`1`、 そして`2`、答えを生み出す`3`。 完全に一致するたびに、KMP はゼロから再開するのではなく、プレフィックス関数を使用してフォールバックするため、重複する一致は正しくカウントされます。
