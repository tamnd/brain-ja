 ## 解決策
 ## 問題の理解

 ちょうど 6 つのスティックの長さが与えられています。 動物を作るには、4 本の棒を足として使用する必要があります。つまり、4 本の棒はすべて同じ長さでなければなりません。 

4 本の足のスティックを選択すると、2 本のスティックが残ります。 これらによって動物の種類が決まります。 

ゾウの場合、頭と体が同じサイズであるため、残りの 2 本の棒は同じ長さでなければなりません。 

クマの場合、頭は胴体より短くなければならないため、残りの 2 本の棒の長さは異なる必要があります。 

私たちの仕事は、6 本の棒がクマかゾウを形成できるか、あるいはそのどちらでもないかを判断することです。 この声明は、両方の動物が同時に存在することは不可能であることを保証しています。 

制約はわずかです。 スティックは 6 本のみで、それぞれの長さは 1 ～ 9 です。適切なアルゴリズムであれば即座に実行されます。 課題はパフォーマンスではなく、同じ長さが複数存在する場合に、どの 4 本のスティックを脚として選択するかを正確に識別することです。 

よくある間違いは、正確に 4 回出現する値だけを探すことです。 脚は 4 つの等しいスティックのみを必要とするため、5 回または 6 回出現する値でも脚を提供できます。 

考慮する：```
4 4 4 4 4 5
```長さ4の棒5本のうち4本を足として使用できます。 残りの棒は4と5で違うので、答えは次のようになります。`Bear`。 「正確に 4 回の出現」をチェックすると、このケースは誤って拒否されます。 

6 本のスティックが同じ場合には、別の微妙なケースが発生します。```
3 3 3 3 3 3
```4 本の棒が足になり、長さ 3 と 3 の棒が 2 本残ります。残りの棒は等しいので、正解は次のとおりです。`Elephant`。 

3 番目の注意が必要な状況は、長さが少なくとも 4 回出現しない場合です。```
1 2 3 4 5 6
```4 本の等しい棒は存在しないため、動物を形成することはできません。 答えは`Alien`。 

## アプローチ

 この強引なアイデアは、6 つのスティックのうち 4 つのスティックを可能な限りすべて選択してみるというものです。 可能性は C(6,4) = 15 個だけです。 選択ごとに、選択したスティックの長さが等しいかどうかを確認します。 残っている場合は、残りの 2 本のスティックを調べてください。 残りの長さが等しい場合はゾウを意味し、残りの長さが異なる場合はクマを意味します。 

このアプローチは、脚を選択する有効なすべての方法を直接テストするため、正しいです。 組み合わせは 15 個だけなので、十分に高速です。 

周波数に注目すると、問題はさらに単純になります。 重要なのは、ある長さが少なくとも 4 回出現するかどうかだけです。 そのような長さが存在しない場合、答えはすぐに得られます。`Alien`。 

少なくとも 4 回出現する長さを見つけたら、そのコピーをちょうど 4 つ削除します。 残り棒は2本だけです。 彼らの関係が答えを完全に決定します。 長さが等しいと、`Elephant`、長さが異なると、`Bear`。 

この観察により、組み合わせを列挙する必要がなくなり、実装が非常に短くなります。

 ## アルゴリズムのチュートリアル

 1. 6 本のスティックの長さを読み取ります。 
2. 各長さが何回出現するかを数えます。 
3. 頻度が少なくとも 4 である長さを見つけます。 

このような長さであれば、必要な 4 本のレッグスティックを提供できます。 
4. 長さが少なくとも 4 の頻度を持たない場合、出力します。`Alien`。 

4 本の等しい棒がなければ、どちらの動物も組み立てることはできません。 
5. 選択した長さの出現箇所を正確に 4 つ削除します。 

この4本の棒を足として固定しています。 
6. 残りの 2 本のスティックを集めます。 
7. 残りの 2 つの長さが等しい場合は、次のように出力します。`Elephant`。 

頭と体の長さが等しいということは、ゾウの定義と一致します。 
8. それ以外の場合は印刷します`Bear`。 

残りの長さが異なるとクマの定義と一致します。 

### なぜ効果があるのか

 両方の動物の決定的な要件は、同じ長さの脚のスティックが 4 本存在することです。 有効な構築では同じ長さの 4 本のスティックを使用する必要があるため、ある長さが少なくとも 4 回出現する必要があります。 

このようなスティックを 4 つ選択すると、ちょうど 2 つのスティックが残ります。 動物の種類はこの 2 本の棒のみに依存します。 残りの長さが等しい場合はゾウの条件を満たし、残りの長さが異なる場合はクマの条件を満たします。 このステートメントでは、答えが一意であることが保証されているため、少なくとも 4 回の頻度で任意の長さを調べると、正しい分類が得られます。 

## Python ソリューション```python
import sys
from collections import Counter

input = sys.stdin.readline

sticks = list(map(int, input().split()))
cnt = Counter(sticks)

leg_length = None

for length, freq in cnt.items():
    if freq >= 4:
        leg_length = length
        break

if leg_length is None:
    print("Alien")
else:
    remaining = []
    removed = 0

    for x in sticks:
        if x == leg_length and removed < 4:
            removed += 1
        else:
            remaining.append(x)

    if remaining[0] == remaining[1]:
        print("Elephant")
    else:
        print("Bear")
```最初の部分では、各スティックの長さの出現回数をカウントします。 次に、少なくとも 4 回出現する長さを検索します。 何も存在しない場合は、有効な脚のセットを形成できないことがすぐにわかります。 

除去ステップは注目に値します。 すべてのコピーではなく、正確に 4 つのコピーを削除します。 などのケース`4 4 4 4 4 5`5本目のスティックを維持するかどうかにかかっています。 すべての出現箇所を削除すると、スティックが 1 つだけ残り、誤った結果が生成されます。 

取り外した後、ちょうど 2 つのスティックが残ります。 これら 2 つの値を比較すると、動物の種類が直接決まります。 

並べ替えは必要ありませんが、並べ替えベースのソリューションも受け入れられます。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io
from collections import Counter

def solve():
    sticks = list(map(int, input().split()))
    cnt = Counter(sticks)

    leg_length = None

    for length, freq in cnt.items():
        if freq >= 4:
            leg_length = length
            break

    if leg_length is None:
        print("Alien")
        return

    remaining = []
    removed = 0

    for x in sticks:
        if x == leg_length and removed < 4:
            removed += 1
        else:
            remaining.append(x)

    print("Elephant" if remaining[0] == remaining[1] else "Bear")

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue().strip()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided sample
assert run("4 2 5 4 4 4\n") == "Bear", "sample 1"

# custom cases
assert run("3 3 3 3 5 5\n") == "Elephant", "equal remaining sticks"
assert run("1 2 3 4 5 6\n") == "Alien", "no four equal sticks"
assert run("4 4 4 4 4 5\n") == "Bear", "frequency greater than four"
assert run("9 9 9 9 9 9\n") == "Elephant", "all sticks equal"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`3 3 3 3 5 5`|`Elephant`| 残りのスティックが等しい |
 |`1 2 3 4 5 6`|`Alien`| 有効な脚セットが存在しません |
 |`4 4 4 4 4 5`|`Bear`| すべてではなく、正確に 4 つのコピーを削除する必要があります。 
|`9 9 9 9 9 9`|`Elephant`| すべてのスティックは同じです |

 ## 特殊なケース

 次のことを考慮してください。```
4 4 4 4 4 5
```4 の頻度は 5 ですが、脚にはまだ十分です。 このアルゴリズムは 4 のコピーを 4 つだけ削除し、残りは`[4, 5]`。 残りのスティックが異なるので出力します`Bear`。 正確に 4 の周波数を必要とするソリューションは、ここでは失敗します。 

考慮する：```
3 3 3 3 3 3
```アルゴリズムは脚の長さとして 3 を選択し、4 つのコピーを削除します。 残ったスティックは、`[3, 3]`。 それらは等しいため、出力は次のようになります。`Elephant`。 これにより、6 本のスティックすべてが同じ長さの場合に正しい取り扱いができることが確認されます。 

考慮する：```
1 2 3 4 5 6
```長さが少なくとも 4 回表示されません。 脚の長さの検索が失敗したため、アルゴリズムはすぐに出力します。`Alien`。 これにより、動物の構築が不可能な入力が正しく処理されます。
