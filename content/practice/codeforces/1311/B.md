 ## 解決策

 ## 問題の理解

 整数の配列と、限られた「スワップ権限」のセットが与えられています。 各権限はポジションに対応します`i`、ペアを交換できることを意味します`(a[i], a[i+1])`。 このような各スワップは任意に何度でも使用できるため、配列の特定のエッジでのみ隣接するスワップを効果的に実行できます。 

問題は、これらの許可された隣接スワップのみを使用して、配列を完全に非減少シーケンスに変換できるかどうかです。 

これを再解釈する便利な方法は、配列をエッジで接続された位置のラインとして考えることです。 位置の場合`i`セットに入っています`p`、その場合、間にエッジがあります`i`そして`i+1`それは交換を可能にします。 接続されたエッジのシーケンスに沿ってスワップできる場合、隣接するスワップにより接続されたコンポーネント内で任意の順列が生成されるため、その接続されたセグメント内の要素を任意に再配置できます。 

これにより、問題は、許可されたスワップ エッジによって引き起こされる各連結成分が、グローバルにソートされた配列と一致するように個別にソートできるかどうかを確認することに変わります。 

制約は小さいです。`n ≤ 100`そして`t ≤ 100`。 これは、`O(n^2)`または`O(n log n)`テスト ケースごとのソリューションで十分です。 高度なデータ構造や重いグラフ アルゴリズムは必要ありません。 

素朴だが間違った考えは、スワップを貪欲にシミュレートし、要素をソート順に移動させるために可能な限り常にスワップを試みることです。 ローカルのグリーディ スワップはグローバル接続構造をキャプチャしないため、これは失敗する可能性があります。 もう 1 つの間違ったアプローチは、位置が許可されている場合、その位置を横切って要素を一方向に自由に移動できると想定することです。これは、スワップを繰り返し対称的に適用する必要があることを無視しています。 

許可される位置がまばらな場合、微妙なエッジケースが発生します。 たとえば、スワップ位置が指定されていない場合、配列はすでにソートされている必要があります。 すべての位置が指定されている場合、配列は完全に接続された線のように動作するため、常に並べ替えることができます。 興味深いケースは、セグメントのみを再配置できる部分的な接続です。 

## アプローチ

 ブルートフォース解釈では、許可されたスワップの可能なすべてのシーケンスをシミュレートします。 各スワップは任意に何度でも適用できるため、これは隣接する転置によって生成された順列に対する無制限の検索になります。 最悪の場合、到達可能な状態の数は次のとおりです。`n!`、これはたとえ`n = 10`。 

重要な洞察は、許可された位置での隣接スワップがインデックス上のグラフを定義し、このグラフの各接続コンポーネントがその内部で完全な順列の自由を許可するということです。 これは、操作をシミュレートする必要がないことを意味します。 代わりに、許可されたスワップを通じて相互に到達可能なインデックスをグループ化するだけで済みます。 

コンポーネントがわかったら、各コンポーネントに属する値を抽出して並べ替え、並べ替えた値を同じインデックスに戻すとグローバルに並べ替えられた配列が生成されることを確認できます。 

これにより、問題は動的な変換から静的なグループ化と比較の問題に軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | 指数 | 指数 | 遅すぎる |
 | コンポーネント + 並べ替え | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 配列インデックスをノードとしてモデル化します。`0`に`n-1`。 許可されたスワップポジションごとに`p`、私たちは接続します`p-1`そして`p`(0 ベースのインデックス付け)。 各連結成分は、値を任意に変更できるインデックスを表します。 

次に、各コンポーネント内のソートがグローバルにソートされた配列を生成するのに十分であるかどうかを検証します。 

1. インデックス上に素集合結合 (DSU) またはグラフ隣接構造を構築します。 

それぞれの許容位置`p`インデックスを接続します`p-1`そして`p`。 これはダイレクト スワップ機能をモデル化します。 
2. インデックス グラフの連結成分を計算します。 

同じコンポーネント内の 2 つのインデックスは、一連の隣接するスワップを通じて値を交換できます。 
3. コンポーネントごとに、それに属するすべてのインデックスを収集します。 

完全な置換自由を共有するポジションをグループ化しています。 
4. これらのインデックスに対応する元の配列から値を抽出し、両方を並べ替えます。 

1 つは元の配列からのリスト、もう 1 つはターゲットのソートされた配列の位置からのリストです。 
5. 各コンポーネントの 2 つのマルチセットを比較します。 

ソートされたターゲット分布と一致しないコンポーネントがある場合、ソートは不可能です。 
6. すべてのコンポーネントが一致する場合は「YES」を出力し、そうでない場合は「NO」を出力します。 

### なぜ効果があるのか

 重要な不変条件は、スワップは許可されたエッジ間でのみ発生するため、異なる接続コンポーネント間で値が移動することは決してないということです。 これは、各コンポーネントが値のマルチセットを永久に保存することを意味します。 コンポーネント内では、隣接するスワップだけで順列を生成できるため、コンポーネント内の値の再配置は実現可能です。 

したがって、問題は、グローバルにソートされた配列内で必要な値を各コンポーネントに正確に割り当てることができるかどうかをチェックすることになります。 すべてのコンポーネントが必要なマルチセットと一致する場合、有効なスワップ シーケンスが存在します。 そうしないと、何らかの値が禁止された境界を越える必要がありますが、これは不可能です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        p = list(map(int, input().split()))

        dsu = DSU(n)

        for x in p:
            dsu.union(x - 1, x)

        groups = {}
        for i in range(n):
            root = dsu.find(i)
            if root not in groups:
                groups[root] = []
            groups[root].append(i)

        sorted_a = sorted(a)

        pos_map = {}
        for i in range(n):
            root = dsu.find(i)
            pos_map.setdefault(root, []).append(i)

        for root, indices in pos_map.items():
            original_vals = [a[i] for i in indices]
            target_vals = [sorted_a[i] for i in indices]

            if sorted(original_vals) != sorted(target_vals):
                print("NO")
                break
        else:
            print("YES")

if __name__ == "__main__":
    solve()
```DSU は、直接スワップできるインデックス間の接続を構築します。 結合ステップでは、許可された各位置を 2 つの隣接するインデックス間のエッジに変換します。 

コンポーネントを構築した後、各ルートを反復処理し、そのコンポーネントに属するすべてのインデックスを収集します。 このようなグループごとに、そのグループに現在含まれている値と、グローバルにソートされた配列に含まれるべき値を比較します。 グローバルにソートされた配列は、最終的なターゲット構成として機能します。 

重要な点は、グループ化に値ではなくインデックスを使用することです。 よくある間違いは、位置ではなく数値について直接推論しようとすることですが、演算の制約は位置に関するものです。 

決勝戦`else`ループ上で、検証に失敗したコンポーネントがない場合にのみ「YES」を出力するようにします。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    class DSU:
        def __init__(self, n):
            self.parent = list(range(n))
            self.size = [1]*n

        def find(self, x):
            while self.parent[x] != x:
                self.parent[x] = self.parent[self.parent[x]]
                x = self.parent[x]
            return x

        def union(self, a, b):
            ra, rb = self.find(a), self.find(b)
            if ra != rb:
                self.parent[rb] = ra

    def solve():
        t = int(input())
        out = []
        for _ in range(t):
            n, m = map(int, input().split())
            a = list(map(int, input().split()))
            p = list(map(int, input().split()))

            dsu = DSU(n)
            for x in p:
                dsu.union(x-1, x)

            sorted_a = sorted(a)

            comp = {}
            for i in range(n):
                r = dsu.find(i)
                comp.setdefault(r, []).append(i)

            ok = True
            for idxs in comp.values():
                if sorted([a[i] for i in idxs]) != sorted([sorted_a[i] for i in idxs]):
                    ok = False
                    break

            out.append("YES" if ok else "NO")

        return "\n".join(out)

    return solve()

## 特殊なケース

 主なエッジケースは次のような場合です`m = 0`、スワップは許可されないことを意味します。 この場合、すべてのインデックスは独自のコンポーネントとなるため、各コンポーネントには 1 つの値が含まれます。 このアルゴリズムは、配列が既にソートされていない限り、各単一値を対応するソート済みの値と比較し、不一致を検出します。 

別のエッジケースが発生するのは次の場合です。`m = n-1`つまり、隣接するすべてのスワップが許可されます。 これにより単一の連結成分が生成されるため、アルゴリズムは配列全体のソートが可能かどうかをチェックすることになります。完全な順列の自由が存在するため、これは常に真です。 

より微妙なケースは、コンポーネントが大きいにもかかわらず、交互のエッジのようなパターンで接続されていない場合です。 DSU は隣接する許可されたスワップのみをマージし、偶発的なコンポーネント間の混合が発生しないようにするため、アルゴリズムはこれを自然に処理します。
