 ## 解決策
 ## 問題の理解

 単一の整変数を操作するプログラムが与えられています。`x`から始まる`0`。 各命令はインクリメントまたはデクリメントします。`x`による`1`。 次に、一連のクエリが行われます。クエリごとに、連続する命令のサブシーケンスを無視し、個別の値の数を決定します。`x`残りの命令を順番に実行するときにかかります。 クエリの出力は単に個別の値の数です。`x`達成します。 

制約は重要です。 各プログラムには最大 200,000 の命令を含めることができ、最大 200,000 のクエリを含めることができます。 すべてのテスト ケースにわたって、命令とクエリの合計も 200,000 に制限されます。 これにより、クエリごとにプログラムを最初からシミュレートするソリューションは即座に除外されます。$O(n \cdot m)$できる操作$4 \cdot 10^{10}$最悪の場合。 各クエリに一定時間または対数時間で回答できるように、情報を前処理するソリューションが必要です。 

重要な点は、サブシーケンスを無視すると、後続のすべての値が固定オフセットだけシフトされる可能性があることです。 たとえば、プログラム「+-+-」と命令 2 ～ 3 を無視したクエリについて考えてみましょう。結果として得られるシーケンスは命令 1 と 4 からの「+-」ですが、相対的な最小値と最大値は`x`無視された命令の累積的な影響に基づいて変更されます。 単純にシーケンスを再計算するだけの不注意なソリューションでは、個別の値を過大評価または過小評価してしまいます。 同様に、最初または最後の命令を削除するクエリは、プログラムが空になる可能性がある境界条件を正しく処理する必要があります。 

## アプローチ

 素朴なアプローチは簡単です。クエリごとに、クエリからの命令をスキップして新しいプログラム シーケンスを構築します。`l`に`r`、シミュレートする`x`段階的にすべての値を記録し、個別の値の数を返します。 これは小さな入力に対しては正しく機能しますが、非常に非効率的です。 もし`n`そして`m`それぞれです$2 \cdot 10^5$、これには必要になる可能性があります$O(n \cdot m) = 4 \cdot 10^{10}$これは 2 秒の制限をはるかに超えています。 

重要な洞察は、プログラムに関するプレフィックスとサフィックスの情報を前処理できることです。 各ポジションの最小値と最大値がわかっている場合`x`その時点までの値 (プレフィックス) と、その時点から最後までの値 (サフィックス) を調べると、無視されるセグメントの前のプレフィックスとその後のサフィックスを組み合わせることで、あらゆるクエリに答えることができます。 無視されたセグメントは純変化に寄与します`delta`、これはそのセグメントの増分と減分の合計です。 サフィックス内の値はこれによってシフトします`delta`プレフィックスの後に連結される場合。 プログラム全体をシミュレートする必要はありません。 最小値と最大値を追跡するだけで十分です`x`プレフィックスとサフィックスの両方を変更し、無視されたセグメントの最終的な変更に基づいて調整します。 

これにより、線形前処理後のクエリごとの計算が一定時間に短縮されます。 前処理では、プレフィックスの最小/最大配列とサフィックスの最小/最大配列が計算されます。$O(n)$。 各クエリはこれらの配列を使用して残りの命令全体で有効な最小値と最大値を計算し、個別の値の数を次のように出力します。`max_val - min_val + 1`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * m) | O(n) | 遅すぎる |
 | 最適 | O(n + m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. プログラム文字列を配列に変換する`a`どこ`a[i] = 1`「+」の場合、および`a[i] = -1`のために '-'。 これにより、文字列処理の代わりに数値演算が可能になります。 
2. プレフィックスの合計を構築する`pref[i]`そのような`pref[i]`の値です`x`最初の実行後`i`説明書。 初期化する`pref[0] = 0`。 
3. プレフィックスの最小値を計算する`pref_min[i]`およびプレフィックスの最大値`pref_max[i]`配列。`pref_min[i]`は最小値です`x`始まりから指導まで`i`。`pref_max[i]`が一番大きいです。 
4. 同様にサフィックス情報を構築します。 させて`suff[i]`命令からの累積和を表します`i`最後まで。 次に計算します`suff_min[i]`そして`suff_max[i]`の最小値と最大値を表します。`x`その接尾辞は、その開始点を基準として、最初は`0`。 
5. 各クエリについて`[l, r]`、プログラムを 2 つの部分に分割します。`1..l-1`と接尾語`r+1..n`。 無視されたセグメントは、正味デルタに寄与します。`pref[r] - pref[l-1]`。 
6. サフィックスの最小値と最大値を、正味の変化によって調整します。`x`接頭辞 (`pref[l-1]`）。 の最小値`x`残りの指示は`min(pref_min[l-1], pref[l-1] + suff_min[r+1])`、最大値は`max(pref_max[l-1], pref[l-1] + suff_max[r+1])`。 
7. 質問の答えは次のとおりです。`max_val - min_val + 1`。 

機能する理由: 不変条件は、連続するサブシーケンスを削除すると、削除されたセグメントの正味の効果によって、後のすべての値が単純にシフトされるということです。 すべてのプレフィックスとサフィックスの最小値と最大値を保存することにより、すべてのステップをシミュレートすることなく極値を再構築できます。 シフト後に 2 つの極値を結合すると、それぞれの増分/減分が変化するため、個別の値の完全なセットが得られます。`x`ちょうど 1 までに。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        s = input().strip()
        a = [1 if c == '+' else -1 for c in s]

        # prefix sums and min/max
        pref = [0] * (n + 1)
        pref_min = [0] * (n + 1)
        pref_max = [0] * (n + 1)
        for i in range(1, n + 1):
            pref[i] = pref[i - 1] + a[i - 1]
            pref_min[i] = min(pref_min[i - 1], pref[i])
            pref_max[i] = max(pref_max[i - 1], pref[i])

        # suffix min/max
        suff_min = [0] * (n + 2)
        suff_max = [0] * (n + 2)
        suff_sum = 0
        for i in range(n, 0, -1):
            suff_sum += a[i - 1]
            suff_min[i] = min(0, suff_min[i + 1] + a[i - 1])
            suff_max[i] = max(0, suff_max[i + 1] + a[i - 1])

        res = []
        for _ in range(m):
            l, r = map(int, input().split())
            # prefix before ignored segment
            pre_min = pref_min[l - 1]
            pre_max = pref_max[l - 1]
            # suffix after ignored segment, shifted by pref[l-1]
            suf_min = pref[l - 1] + suff_min[r + 1]
            suf_max = pref[l - 1] + suff_max[r + 1]
            total_min = min(pre_min, suf_min)
            total_max = max(pre_max, suf_max)
            res.append(str(total_max - total_min + 1))
        print('\n'.join(res))

if __name__ == "__main__":
    solve()
```コードはまず文字列を数値の増分と減分に変換します。 プレフィックスの合計とその最小/最大値は、各命令までの極値を追跡します。 サフィックスの最小/最大配列は逆に計算され、末尾から相対的な最小/最大値が累積されます。 クエリごとに、プレフィックス値とサフィックス値を結合し、無視されるセグメントの前のプレフィックスの合計によってサフィックス値を調整します。 最終的な答えは、個別の範囲です。`x`価値観。
