 ## 解決策
 ## 問題の理解

 整数の配列が与えられたので、それを連続したセグメントに分割する必要があります。 各要素は 1 つのセグメントに正確に出現する必要があります。 セグメント内のすべての要素が次のセグメント (存在する場合) にも出現する場合、そのパーティションはクールであるとみなされます。 私たちの目標は、セグメントの数を最大化することです。 

入力は複数のテスト ケースで構成され、各テスト ケースのサイズは最大 200,000 です。 すべてのテスト ケースにわたる配列サイズの合計は 200,000 を超えません。これは、配列ごとに線形時間ソリューションを提供できることを意味します。 すべての部分配列を反復処理すると最大で$10^{10}$操作。 

明白ではないエッジケースは、要素が複雑なパターンで繰り返される場合に発生します。 たとえば、同じ要素が断続的に現れる配列を考えてみましょう。`[1, 2, 1, 2, 1, 2]`。 繰り返される要素ごとに分割する単純なアプローチは、セグメント内のすべての要素が次の要素にも出現する必要があるという要件に違反するため、失敗する可能性があります。 もう 1 つのエッジ ケースは、すべてが一意の要素を持つ配列です。この場合、唯一のクールなパーティションは配列全体です。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのパーティションを生成し、それがクールかどうかをチェックしようとします。 候補となる各パーティションについて、セグメントのすべての要素が次のセグメントに出現することを確認します。 これは概念的には正しいですが、長さの配列の場合は非常に遅くなります。$n$、 がある$2^{n-1}$可能な分割ですが、これはたとえ$n = 20$。 

これを高速化するための重要な洞察は、セグメントが終了できるのは、現在セグメント内にあるすべての要素が配列の後半にも出現する場合のみであることに注意することです。 言い換えれば、位置で終わる候補セグメントに対して$i$、このセグメントに出現する要素がその後再び出現しないことを確認する必要があります。$i$次のセグメントの一部ではありません。 この観察により、すべての要素の最後の出現を追跡し、現在のインデックスがこれまでに確認されたすべての要素の最後の出現と一致する場合にのみセグメントを閉じることができます。 

配列を 1 回繰り返し、現在のセグメント内で最後に出現する要素の最大数を追跡することにより、1 回のパスでセグメント境界を決定できます。 現在のインデックスが最後の出現の最大値と一致するたびに、セグメントを安全に閉じることができ、そのセグメント内のすべての要素が次のセグメント (存在する場合) に表示されることが保証されます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、配列を読み取ります。`a`そしてその長さ`n`。 
2. 各一意の要素を配列内の最後の出現インデックスにマッピングする辞書を計算します。 これにより、あらゆる要素について、クール セグメント条件を満たすために含める必要がある最も遠いインデックスを知ることができます。 
3. 2 つの変数を初期化します。`current_max`現在のセグメント内で最後に出現した要素の最大値を追跡するため、および`segments`見つかったセグメントの数を数えます。 
4. インデックスを使用して配列を反復処理します。`i`0から`n-1`。 要素ごとに`a[i]`、 アップデート`current_max`それ自体の最大値と最後の出現として`a[i]`。 
5. もし`i`等しい`current_max`、これは、現在のセグメント内のすべての要素がここで終了することを意味します。 インクリメント`segments`必要に応じて、セグメント固有のトラッキングをリセットします。 
6. ループ後、合計を出力します`segments`このテストケースでは。 

重要な不変条件は次のとおりです`current_max`は常に、現在のセグメントのクール パーティション条件を満たすために含める必要がある最も遠いインデックスを表します。 現在のインデックスがこの最大値に達したときに正確にセグメントを閉じることで、セグメント内の要素が条件に違反しないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_cool_segments(n, a):
    last_occurrence = {}
    for i, val in enumerate(a):
        last_occurrence[val] = i
    
    segments = 0
    current_max = -1
    for i, val in enumerate(a):
        current_max = max(current_max, last_occurrence[val])
        if i == current_max:
            segments += 1
    return segments

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(max_cool_segments(n, a))
```このソリューションでは、最初に辞書を構築します。`last_occurrence`各要素が出現する最後のインデックスを格納します。 反復中に`a`、追跡します`current_max`現在のセグメントを安全に終了できる時期を判断します。 インクリメント`segments`現在のインデックスが等しい場合のみ`current_max`正確性を保証します。 このアプローチでは、ゼロベースのインデックスを一貫して使用することで、off-by-1 エラーを回避します。
