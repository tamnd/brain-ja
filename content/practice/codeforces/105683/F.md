 ## 問題の理解

 次のサイズの非常に大きな長方形のグリッドが与えられます。$w \times h$。 固定長のヘビ$k$正確に占めることを意味する「まっすぐな」形で配置する必要があります。$k$連続したセルは 1 行で水平方向、または 1 列で垂直方向に配置されます。 

数回のラウンドの後、複数の軸が揃った長方形の障害物が与えられるため、グリッドは完全には配置できません。 各障害物はその内部のすべてのセルをブロックし、障害物が重なる場合があります。 ヘビはブロックされたセルを占有することはできませんが、障害物に決して重ならない限り、障害物に触れたり、障害物に隣接して横たわったりすることは許可されます。 

このタスクは、すべての水平および垂直の直線配置を考慮して、グリッド全体に存在するヘビの有効な配置がいくつあるかを数えるというものです。 

重要な点は、シェイプを恣意的に配置しているわけではないということです。 長さを設定しています-$k$セグメント。 したがって、水平方向の配置は開始セルを選択することによって一意に決定されます。$(x,y)$、そしてそれは占めます$(x,y),(x+1,y),\dots,(x+k-1,y)$。 垂直方向の配置も同様です。 

この制約により、セルごとまたは行ごとのシミュレーションが即座に除外されます。 両方の次元は次までに達します$10^9$、障害物の数は最大です。$10^5$。 行、列、またはセルを反復するアプローチは不可能です。 最悪の場合、影響を受ける個別の行と列の数が依然として多すぎるため、行の完全なグリッドまたは圧縮されたグリッドを維持することさえ不可能です。 

さらに微妙な問題は、障害物が重なり合い、相互作用することです。 単純な結合構造が必要ですが、長方形を結合した後でも、有効な長さのセグメントをカウントする必要があります。$k$フリーセルだけではありません。 

空き領域が断片化されている場合、素朴な「空きセルを数えてから分割する」ロジックを破るエッジケースが 1 つ発生します。 たとえば、行に次のような空きセルがあるとします。```

## アプローチ

 強引な解釈では、ヘビのあらゆる可能な開始位置を調べようとします。 おおよそあります$(w-k+1) \cdot h$水平スタートと$(h-k+1) \cdot w$垂直が始まります。 開始するたびに、ヘビのセルが障害物と交差するかどうかを確認します。 前処理を使用したとしても、各候補の開始を個別にチェックするのは非常に時間がかかり、最大で$10^{18}$最悪の場合の候補者も。 

構造改善の第一は視点を逆転させることです。 開始位置が有効かどうかを尋ねるのではなく、どのような条件がそれを無効にするかを尋ねます。 から始まる水平方向の配置$(x,y)$セグメントと交差する障害セルが存在する場合にのみ無効です。$[x, x+k-1] \times \{y\}$。 したがって、各障害物の四角形は、その行の開始位置の範囲を禁止します。 

固定長方形の場合$[x_1,x_2]\times[y_1,y_2]$、水平方向の配置を検討してください。 から始まるプレースメント$x$そのセグメントが長方形と水平に交差する場合は無効です。これはまさに次の場合に発生します。$$x \le x_2 \quad \text{and} \quad x+k-1 \ge x_1$$これを有効な開始位置に関して書き直すと、次のようになります。$$x \in [x_1-k+1, x_2]$$行ごとに$y \in [y_1,y_2]$。 

So each obstacle generates another axis-aligned rectangle in the space of valid starting positions$(x,y)$。 元の計数問題は、「開始位置グリッド」上の 2D 長方形の和集合問題になります。 水平方向の答えは、すべての可能な開始領域の完全な長方形から禁止された開始領域を減算することで得られます。 

垂直方向の配置は対称的です。役割を交換します。$x$そして$y$、禁止された長方形を生成します$(y_{\text{start}}, x)$空間。 

したがって、問題全体は、長方形の結合領域を 2 回計算することに帰着します。 

この変換された空間上の直接のスイープ ラインは効率的に機能します。$O(n)$座標を圧縮し、一方の軸上でセグメント ツリーを維持しながら、もう一方の軸をスイープすることができます。

 ## アルゴリズムのチュートリアル

 水平方向の場合について説明します。 垂直方向の場合は、軸を交換しても同じです。 

1. 各障害物の四角形を禁止された開始位置の四角形のセットに変換します。 長方形の場合$[x_1,x_2]\times[y_1,y_2]$、私たちは以下を生産します：$$[x_1-k+1, x_2] \times [y_1,y_2]$$有効な開始境界と交差しています$x \in [1, w-k+1]$。 これにより、法的な開始位置のみを考慮することが保証されます。 
2. クランプ後に空になった、変形された長方形はすべて破棄します。 これは、障害物が狭すぎて全長セグメントに影響を与えない場合に発生します。 
3. 長方形の境界からすべての X 座標を収集し、それらを圧縮します。 座標は次のとおりであるため、これが必要です。$10^9$、しかし、ただ$O(n)$スイープ構造では、明確なエンドポイントが重要です。 
4. Y 軸に沿ってスイープ イベントを作成します。各四角形は、「間隔の追加」イベントに寄与します。$y_1$および「間隔の削除」イベント$y_2+1$。 
5. y を昇順にスイープします。 連続するイベントの y 値の間では、アクティブな四角形のセットは一定であるため、カバーされる x 間隔の和集合は変化しません。 
6. カバーされた長さを格納する圧縮された x 座標上のセグメント ツリーを維持します。 指定された y でイベントを処理した後、ツリーはその y での禁止された x 間隔の結合を表します。 
7. X 軸上の覆われていない長さを次のように計算します。$$(w-k+1) - \text{covered\_length}$$これに現在の y 間隔の高さを乗算して、禁止領域の合計を累積します。 
8. スイープが終了したら、水平スタートの可能性のある合計から禁止エリアを差し引きます。$(w-k+1)\cdot h$。 
9. 垂直方向の配置についても同じプロセスを繰り返し、x と y の役割を交換し、さらに$w-k+1$と$h-k+1$。 
10. 水平方向と垂直方向の結果を合計します。 

### なぜ効果があるのか

 重要な不変条件は、すべての無効なスネーク配置が 1 つの禁止された開始位置の長方形に正確に対応し、すべての禁止された開始位置が少なくとも 1 つのそのような長方形でカバーされるということです。 The sweep line computes the exact union area of these forbidden regions without double counting overlaps. Since horizontal and vertical placements are defined on disjoint orientation spaces, their counts can be summed directly without interaction.

 ## Python ソリューション```python
import sys
input = sys.stdin.readline

class SegTree:
    def __init__(self, xs):
        self.xs = xs
        self.n = len(xs) - 1
        self.tree = [0] * (4 * self.n)
        self.cnt = [0] * (4 * self.n)

    def _pushup(self, v, l, r):
        if self.cnt[v]:
            self.tree[v] = self.xs[r] - self.xs[l]
        else:
            if r - l == 1:
                self.tree[v] = 0
            else:
                self.tree[v] = self.tree[v*2] + self.tree[v*2+1]

    def update(self, v, l, r, ql, qr, val):
        if ql >= r or qr <= l:
            return
        if ql <= l and r <= qr:
            self.cnt[v] += val
            self._pushup(v, l, r)
            return
        m = (l + r) // 2
        self.update(v*2, l, m, ql, qr, val)
        self.update(v*2+1, m, r, ql, qr, val)
        self._pushup(v, l, r)

def solve(rects, W, H, K, horizontal=True):
    if horizontal:
        limit_x = W - K + 1
    else:
        limit_x = H - K + 1

    events = []
    xs = set()

    for x1, y1, x2, y2 in rects:
        if horizontal:
            lx = max(1, x1 - K + 1)
            rx = min(limit_x, x2)
            ly, ry = y1, y2
        else:
            lx = max(1, y1 - K + 1)
            rx = min(limit_x, y2)
            ly, ry = x1, x2

        if lx > rx or ly > ry or limit_x <= 0:
            continue

        events.append((ly, lx, rx, 1))
        events.append((ry + 1, lx, rx, -1))
        xs.add(lx)
        xs.add(rx + 1)

    if not events:
        if horizontal:
            return max(0, (W - K + 1)) * H
        else:
            return max(0, (H - K + 1)) * W

    xs.add(1)
    xs.add(limit_x + 1)
    xs = sorted(xs)

    idx = {v: i for i, v in enumerate(xs)}

    events.sort()
    st = SegTree(xs)

    prev_y = events[0][0]
    area = 0
    i = 0

    while i < len(events):
        y = events[i][0]

        area += st.tree[1] * (y - prev_y)

        while i < len(events) and events[i][0] == y:
            _, l, r, t = events[i]
            st.update(1, 0, len(xs) - 1, idx[l], idx[r+1], t)
            i += 1

        prev_y = y

    if horizontal:
        total = max(0, W - K + 1) * H
    else:
        total = max(0, H - K + 1) * W

    return total - area

def main():
    w, h, k = map(int, input().split())
    n = int(input())
    rects = [tuple(map(int, input().split())) for _ in range(n)]

    hor = solve(rects, w, h, k, True)
    ver = solve(rects, w, h, k, False)

    print(hor + ver)

if __name__ == "__main__":
    main()
```この実装では、問題が 2 つの独立した和集合領域の計算に分割されます。 それぞれが二次軸上のスイープ ラインと圧縮された座標上のセグメント ツリーを使用して、アクティブな禁止間隔の結合を維持します。 

微妙な点は、長方形の X 範囲を有効な開始位置に座標変換することです。 によるシフト$k-1$これは、細胞のブロッキング領域をスネーク スタートのブロッキング領域に変換するものであり、この変換を忘れることが最も一般的な間違いです。 

## 実用的な例

 Consider a small grid where a single obstacle blocks part of the board. 仮定する$w=5, h=3, k=2$、および 1 つの長方形ブロック$[2,3]\times[2,3]$。 

水平配置の場合、有効な開始位置は次のとおりです。$4 \times 3$グリッド。 長方形は禁止された開始部分に変換されます。$[2-1, 3] \times [2,3] = [1,3]\times[2,3]$。 

スイープ中に、$y \in [2,3]$、すべての x から始まります$[1,3]$ブロックされ、残るのは$x=4$有効。 

| y 間隔 | アクティブな禁止 X | 行ごとのフリースタート | 貢献 |
 | --- | --- | --- | --- |
 | 1 | なし | 4 | 4 |
 | 2-3 | [1,3] | 1 | 2 |
 | 4 | なし | 4 | 4 |

 これにより、合計水平スタートが生成されます$4 + 2 + 4 = 10$、直接列挙に一致します。 

トレースは、スイープ ラインが行全体で繰り返される構造をどのように圧縮し、行ごとの再計算を回避するかを示しています。

 ## 特殊なケース

 いつ$k = 1$、すべてのセルは有効な水平方向と垂直方向の配置の両方です。 この変換により、障害物の投影と同じ開始四角形が生成され、アルゴリズムはブロックされていないすべてのセルを 2 回カウントすることになります。 各セルが単位開始間隔に対応しているため、スイープ ラインは依然として正しく動作します。 

障害物が幅または高さ全体を覆う場合、有効な開始範囲にクランプした後、変換された間隔は空になります。 これらの四角形は早期に破棄され、無効なメモリやオーバーカウントが発生しないようにします。 

障害物が重なり合うと、複数の長方形が同一の禁止領域またはネストされた禁止領域にマッピングされることがあります。 セグメント ツリーはこれを正しく処理します。これは、間隔を明示的に重複排除しようとするのではなくカバレッジ カウントを維持し、任意のオーバーラップ パターンの下で正確さを維持するためです。
