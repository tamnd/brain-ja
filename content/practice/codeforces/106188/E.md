 ## 解決策
 ## 問題の理解

 私たちは、`n × n`タイルのグリッド。 各タイルには、金または銀の 2 つの色のいずれかが付いています。 家族は 1 つの正方形の領域を確保したいと考えています`k × k`可視化して、その可視領域を単一色で構成します。 選択した正方形内のタイルは他の色に置き換えることができます。目標は、置換が最も少ない正方形を選択することです。 

入力は、壁のサイズ、必要な表示される正方形のサイズ、およびすべてのタイルの現在の色を記述します。 出力は、変更する必要があるタイルの最小数です。`k × k`壁の一部が均一になります。 

制約はアルゴリズムを選択するための鍵となります。 壁には最大で`1000 × 1000`タイル、つまり 100 万個のセルが存在できることを意味します。 考えられるすべての正方形を試し、そのすべてのセルをスキャンするには、おおよその時間がかかります`n² * k²`最悪の場合は動作します。 100 万個のセルを使用すると、約 1 兆回の操作になる可能性があり、通常の制限時間をはるかに超えます。 すべてのタイルを再チェックせずに、考えられる各正方形を評価する方法が必要です。 

扱いにくいケースは、境界線に接している正方形やすでに均一な正方形に関連することがほとんどです。 表示されている正方形全体がすでに同じ色である場合、答えはゼロでなければなりません。 

例えば：```
Input
3 2
GGG
GGG
SSS

Output
0
```上の 2 行にはユニフォームが含まれます`2 × 2`四角。 少なくとも 1 つの交換が必要であると常に想定するソリューションは失敗します。 

もう 1 つのケースは、最適な正方形が最初または最後の可能な位置ではない場合です。```
Input
5 3
GGGGG
SSSSS
GGGGG
SSSSS
GGGGG

Output
3
```真ん中`3 × 3`正方形には金タイルが 6 枚、銀タイルが 3 枚あるため、3 枚の銀タイルを変更するのが最適です。 角だけをチェックすると、この答えは見逃されます。 

## アプローチ

 直接的な解決策は、可能な限りすべての左上隅を試してみることです。`k × k`四角。 各位置について、その位置に含まれる金タイルと銀タイルの数を数えます。 あれば`g`ゴールドのタイルと`s`銀のタイル、すべて金のコストになります`s`変更するとすべてシルバーコストになります`g`変化します。 この正方形のコストは、2 つの値のうち小さい方です。 

このアプローチは、可能なすべての可視領域をチェックするため、正しいです。 問題は繰り返し作業の量です。 くらいあります`(n-k+1)²`可能な正方形、および各正方形には以下が含まれます`k²`タイル。 最悪の場合こうなります`O(n²k²)`が遅すぎる`n = 1000`。 

重要な観察は、隣接する正方形が重なり合っていることです。 正方形を 1 列右に移動すると、次の 1 列が削除されます。`k`タイルを張り、別の列を追加します`k`タイル。 広場全体を数え直す理由はありません。 

2 次元のプレフィックス合計により、必要な情報が正確に得られます。 各セルが原点からそのセルまでの長方形内に何個の金タイルが存在するかを示す行列を構築します。 その後、4 つのプレフィックス値を使用して、任意の長方形の合計を定数時間で求めることができます。 その後、すべての候補正方形を次の方法で評価できます。`O(1)`時間をかけて完全な解決策を作る`O(n²)`。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n²k²) | お(1) | 遅すぎる |
 | 最適 | O(n²) | O(n²) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グリッドを読み取り、ゴールド タイルのプレフィックス合計配列を構築します。 の値`(i, j)`長方形内の金タイルの数を格納します。`(1, 1)`に`(i, j)`。 これにより、セルをスキャンせずに四角形のクエリに答えることができます。 
2. 可能なすべての左上隅を反復処理します。`k × k`四角。 右下隅は左上の位置から決定され、`k`。 
3. 接頭辞の合計公式を使用して、現在の正方形内の金タイルの数を見つけます。 銀のタイルの数は`k * k - gold`。 
4. この正方形の金を作るコストと銀を作るコストを計算します。 小さい値が、この正方形に必要な置換の数です。 
5. すべての正方形の中で最小コストを維持し、それを印刷します。 

機能する理由: プレフィックス合計はグリッドの意味を変更せず、蓄積された情報を保存するだけです。 目に見えるすべての正方形が検査され、それぞれの正方形に含まれる各色のタイルの数が正確に計算されます。 正方形の変更の最小数は色数が少ないため、検査されたすべての正方形の最小値が全体的な最適値になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    pref = [[0] * (n + 1) for _ in range(n + 1)]

    for i in range(n):
        row_sum = 0
        for j in range(n):
            if grid[i][j] == 'G':
                row_sum += 1
            pref[i + 1][j + 1] = pref[i][j + 1] + row_sum

    ans = k * k

    for i in range(n - k + 1):
        for j in range(n - k + 1):
            x1, y1 = i, j
            x2, y2 = i + k, j + k

            gold = (
                pref[x2][y2]
                - pref[x1][y2]
                - pref[x2][y1]
                + pref[x1][y1]
            )

            silver = k * k - gold
            ans = min(ans, gold, silver)

    print(ans)

if __name__ == "__main__":
    solve()
```プレフィックス構築では、内部で 1 から始まるインデックスが使用されます。 これにより、グリッドの前の行と列がゼロで埋められるため、四角形が最初の行または列から始まるという特殊なケースが回避されます。 

長方形クエリは、ターゲット正方形の外側の 2 つの長方形を減算し、重なっている部分を追加し直します。 これは、2 次元のプレフィックス合計の標準的な包含/除外式です。 

ループは次で停止します。`n - k + 1`なぜなら、正方形は、その下端または右端が壁の外側に出る位置から始めることができないからです。 最終的な答えは次のように始まります`k * k`考えられる最悪の正方形では、すべてのタイルを変更する必要があるためです。

## テストケース```python
import sys
import io

def solve():
    input = sys.stdin.readline

    n, k = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    pref = [[0] * (n + 1) for _ in range(n + 1)]

    for i in range(n):
        cur = 0
        for j in range(n):
            if grid[i][j] == 'G':
                cur += 1
            pref[i + 1][j + 1] = pref[i][j + 1] + cur

    ans = k * k
    for i in range(n - k + 1):
        for j in range(n - k + 1):
            x2, y2 = i + k, j + k
            gold = (
                pref[x2][y2]
                - pref[i][y2]
                - pref[x2][j]
                + pref[i][j]
            )
            ans = min(ans, gold, k * k - gold)

    return str(ans) + "\n"

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    out = solve()
    sys.stdin = old
    return out

assert run("3 2\nGGG\nSSG\nGGG\n") == "1\n"
assert run("5 3\nGGGGG\nSSSSS\nGGGGG\nSSSSS\nGGGGG\n") == "3\n"

assert run("1 1\nG\n") == "0\n"
assert run("4 4\nGSSG\nSGGS\nSGGS\nGSSG\n") == "8\n"
assert run("3 3\nSSS\nSSS\nSSS\n") == "0\n"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1 1`単一タイル |`0`| 最小サイズとすでに均一な正方形 |
 | オールシルバー`3 × 3`|`0`| すべて等しい値 |
