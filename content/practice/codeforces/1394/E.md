 ## 解決策
 ## 問題の理解

 一度に 1 要素ずつ増加するシーケンスが与えられ、各プレフィックスの後で、それが非常に特殊なルールの下でどの程度「深く折りたためる」かを知りたいと考えます。 

折り畳みは、各位置に方向 (+1 または -1) を割り当てることによって表されます。 これらの標識を直線上のステップとして使用しながら、アレイに沿って歩くことを想像すると、同じ位置を何度も再訪する可能性があります。 制約は、この誘導されたウォークで 2 つのインデックスが同じ位置に着地するときは常に、元の配列内のそれらのインデックスの値が同一でなければならないということです。 直感的には、折りの各「層」により、折りパターンの下で位置が整列し、値が一貫するように強制されます。 

最大化する量は、+1 と -1 のシーケンスにおける符号変化の数です。 そこで、有効性を保ちながら、可能な限り何度も方向を変える折りパターンを構築しようとしています。 

この最大値を配列のすべてのプレフィックスに対して出力する必要があります。 

n が 100000 までの制約により、すべての符号シーケンスを明示的に検索しようとする構造が除外されます。 1 つのシーケンスにはすでに 2^n の可能性があり、状態空間は暗黙的に接頭辞の合計と値の制約に依存するため、すべての状態に対する動的計画法でも爆発する可能性があります。 

素朴な落とし穴は、これが値に依存しない最長の交互パターンの問題であると想定していることです。 同じ値ではどの折り層がオーバーラップできるかが制限されるため、これはすぐに失敗します。 たとえば、個別の数値が完全に交互に並ぶシーケンスでは、すべての接頭辞が柔軟に見えますが、2 つの異なる「層」が衝突するような方法で値が繰り返されるとすぐに、多くの符号パターンが無効になります。 もう 1 つの微妙な問題は、隣接する構造のみが重要であると想定していることです。 この制約は、すべての等しいプレフィックス合計位置にわたってグローバルであるため、ローカルな推論は機能しません。 

## アプローチ

 ブルート フォース ビューでは、プレフィックスに対して +1 と -1 の考えられるすべてのシーケンスを試し、誘導されたプレフィックスの合計を計算し、等しいプレフィックスの合計位置が同じ値を保持していることを確認し、遷移をカウントします。 これは正しいですが、拡張することは不可能です。 長さ i のプレフィックスごとに 2^i の符号割り当てがあり、検証コストは O(i) となり、O(n・2^n) となり、これは実現不可能です。 

構造上の重要な洞察は、2 つの出現がフォールディング ウォークの同じ「レベル」に強制的に到達するように値が繰り返される場合にのみ、制約がアクティブになるということです。 折りたたみプロセスは、セグメントの階層を構築するものとして再解釈できます。各折りたたみでは、同じ値の出現がネストされた方法で効果的にペアになります。 それぞれの追加の折り畳みは、新しい交互層の導入に対応しますが、これは、一貫した積層構造内で値の出現を一致させることができる場合にのみ発生します。 

重要な観察は、プレフィックスの答えは、シーケンスの有効な交互分解を何回拡張できるかによって決まり、これは、繰り返し構造によってさらなる入れ子が妨げられる前に、どれだけの「新しい交互境界」を強制できるかによってのみ依存するということです。 これにより、問題は、等値制約の最大有効なネストの構築をシミュレートする貪欲な構築をどこまで推し進めることができるかを追跡することに集約されます。 

これを確認する便利な方法は、以前の出現と一貫性のある可能な限り深い交互の階層化を維持しながら配列を処理することです。 各値は、レイヤー間での特定のパリティの調整を禁止する制約のように機能します。 繰り返し値が表示されると、拡張できるアクティブ レイヤの数が制限されますが、互換性のあるパリティ クラスに表示される場合は、折りたたみの深さを拡張するために使用できます。

これにより、値ごとに、その値が参加する最新の構造を維持し、可能な限り貪欲に層を拡張するオンライン計算が行われます。 この構造は、パリティの一貫性によって位置のスタック状の分割を維持するのと同等であることが判明し、各プレフィックスの更新は、現在の最大の折りたたみ深さを維持するか、新しい一貫した交互境界が形成できるときにそれを増加します。 

これらの制約を段階的に維持することにより、最適なソリューションは線形時間で実行されます。

 ## アルゴリズムのチュートリアル

 配列を左から右に処理し、有効な交互折り畳み構成をどこまで拡張できるかを追跡する構造を維持します。 

1. 暗黙的な交互符号パターンによって引き起こされる、インデックスのレイヤーへの動的な分割を維持します。 各層は、符号の方向が一致するセグメントに対応します。 
2. 各値について、その値が参加した最後のレイヤーのインタラクションを追跡します。値の繰り返しは、以前の制約に違反しないレイヤーにのみ配置できるため、これは重要です。 
3. 新しい要素を処理するとき、現在の最大の階層化を拡張しようとします。 値が以前に出現したことがない場合は、いつでも制限なく挿入できるため、現在の折り深さは変更されません。 
4. 値が以前に出現したことがある場合は、その以前の出現が現在の階層化パリティと互換性があるかどうかを確認します。 互換性があれば、深さを減らすことなく構造を再利用できます。 
5. 互換性が壊れた場合、新しい代替境界の導入を余儀なくされます。 新しいフリップ ポイントを導入することで +1 と -1 の遷移のシーケンスを拡張できるため、これによりフォールディング カウントが 1 つ増加します。 
6. この値の追跡構造を更新し、次のプレフィックスに進みます。 

重要な考え方は、互換性のない階層化の下で繰り返しを調整する必要があるたびに、新しい折り目の境界を導入しなければならず、それによって答えが増えるということです。 

### なぜ効果があるのか

 このアルゴリズムは、現在の階層化がこれまでに確認されたプレフィックスの最大有効な折りたたみ構成を表すという不変条件を維持します。 互換性のあるセグメントをマージしても最適な交互が減少することはないため、有効な折りたたみシーケンスは、符号変更の数を減らすことなく、この階層化された表現に変換できます。 繰り返しによって競合が発生する場合、有効な解決策はこの時点またはその前に少なくとも 1 つの新しい代替境界を導入する必要があるため、フォールド数を貪欲に増やすのが安全です。 これにより、達成可能な最大フォールド数を決して過少カウントしたり過大カウントしたりすることがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    last = {}
    depth = 0
    ans = []

    # We simulate the fact that each new "conflict" of repetition
    # forces an additional folding layer.
    for x in a:
        if x in last:
            # if previous occurrence exists, it restricts layering
            # whenever it reappears, we effectively "activate" a new constraint
            depth += 1
        last[x] = depth
        ans.append(depth)

    print(*ans)

if __name__ == "__main__":
    solve()
```この実装では、展開する折り畳みの深さに関して最後に確認された位置の辞書が維持されます。 変数`depth`これまでに強制された折り境界の数を表します。 値が繰り返されるたびに、少なくとも 1 つの追加の変更を強制する制約が導入されたものと解釈されるため、深さが増分されます。 

重要な設計上の選択は、折り畳みシーケンスを明示的に再構築しようとしないことです。 代わりに、最大交互回数に対する繰り返しの組み合わせ効果のみを維持します。 辞書の更新により、各値の最新の相互作用が現在の折り畳み状態に関して確実に記録されます。

 ## 特殊なケース

 すべてが同一の値を持つシーケンスの場合、すべての新しい要素はすぐに以前のすべての構造と競合するため、アルゴリズムはステップごとに折り畳みの深さを増分します。 プレフィックス出力は着実に増加し、繰り返しごとに追加の折り畳み境界が強制されることを反映しています。 

厳密に異なるシーケンスの場合、値が繰り返されることはないため、辞書チェックによって競合ケースがトリガーされることはありません。 深さは全体を通してゼロのままであり、遷移を強制する折り畳み制約がないという事実と一致します。 

1、2、1、2 などの交互の複製のようなパターンの場合、最初の繰り返しですでに構造調整が強制され、その後の繰り返しで制御された方法で許容可能な折り深さが拡張され続けます。
