 ## 解決策
 ## 問題の理解

 単位円の境界上の点が与えられます。 各点は角度によって指定され、これらの点は円の内側の直線カットに使用できる端点を表します。 

私たちは正確に実行しなければなりません$K-1$直線のカットであり、各カットは指定された境界点の 2 つを結ぶ弦です。 これらのカットは独立していません。最初のカット以降のすべてのカットは、前のカットが終了したエンドポイントから開始する必要があるため、すべてのカットは接続されたコードの単一の連続チェーンを形成します。 このチェーンはディスクを正確にパーティション分割します。$K$地域。 

各領域は、部分的に円弧によって境界付けされ、部分的にはこのチェーンの弦によって境界付けされます。 目標は、結果として得られる最小領域の面積が最大になるようにカットのチェーンを選択することであり、その面積を出力する必要があります。 

重要な構造的制約は次のとおりです。$N \le 30$したがって、任意の幾何学的構成や、考えられるすべてのカットに対して継続的な最適化を試みることは明らかに期待されていません。 代わりに、解決策は問題を境界点の小さなサブセットの選択と順序付けに減らす必要があります。 

微妙なエッジケースは、カットがチェーンを形成する必要があるという事実から生じます。 素朴な解釈では独立したコードを許可するかもしれませんが、新しいカットはそれぞれ前のカットが終了した場所から開始する必要があるため、それは不可能です。 これにより、選択されたすべての点が円の周囲に単一の循環順序で配置されます。 

もう 1 つの重要なエッジ ケースは、ジオメトリの円形の性質です。 たとえば、近くの角度$0^\circ$そして$359^\circ$円上では隣接していますが、数値的には遠く離れています。 ラップせずに角度を線形化するソリューションは、次のような場合に失敗します。 

入力:```
3 2
0 180 359
```正しい構造は、円をセグメントとしてではなく連続したものとして扱うかどうかに依存します。 

最後に、目的は円形セグメントの面積によって異なります。 よくある落とし穴は、各領域の面積を最初から独立して計算しようとすることです。 正しい定式化では、すべてを循環順序で選択した連続した頂点間の角度ギャップに換算します。 

## アプローチ

 ブルートフォース戦略では、次の順序を選択しようとします。$K$頂点の外$N$、次にそれらをチェーンで接続し、結果として得られるすべての領域面積を幾何学的に計算します。 選択と注文の方法の数$K$ポイントは大体$P(N, K)$、最悪の場合、$N = 30$天文学的に大きいです。 サブセットに制限しても、$\binom{30}{15} \approx 1.5 \times 10^8$、各候補はすべてのスライスの幾何学的再構成を必要とするため、実行不可能になります。 

重要な観察は、円に沿って訪問する境界点の順序を固定すると、分割構造が連続する点間の角度ギャップによって完全に決定されるということです。 各スライスはこれらのギャップの 1 つに対応します。 したがって、問題は選択に帰着します$K$連続して選択された点間の最小周期ギャップが最大化されるように、円の周囲に点を配置します。 

角度ギャップを次のように表すと、$\theta$、スライスの面積は円形セグメントの面積です。$$A(\theta) = \frac{1}{2}(\theta - \sin \theta)$$この機能は厳密に増加しています$\theta \in (0, \pi]$したがって、最小面積を最大化することは、最小角度ギャップを最大化することと同じです。 

これにより、問題は古典的な円形間隔の実現可能性問題に変わります。つまり、最大の間隔を決定します。$d$選択できるように$K$すべての連続したギャップが少なくとも$d$。 一度$d$がわかっている場合、答えは対応するスライス領域から直接計算されます。 

候補者の実現可能性をテストできます$d$貪欲に。 各開始点について、少なくとも次の利用可能な点を繰り返し選択します。$d$度先、円を囲み、選択できるかどうかを確認します$K$ポイントを獲得しながら、スタートまでの差を詰める。

 ## アルゴリズムのチュートリアル

 1. 指定された角度をソートされたリストに変換し、各角度に 360 度を加えて拡張します。 これにより、線形配列での循環ラップをシミュレートできるようになります。 このステップにより、貪欲な選択中の特殊なケースのモジュラー演算が回避されます。 
2. 候補の最小ギャップがあるかどうかをチェックする関数を定義します。$d$達成可能です。 この関数は、有効なチェーンの構築を試みます。$K$ポイント。 
3. 可能な開始インデックスごとに$i$、少なくとも以前に選択した角度に角度を加えた最初の点を繰り返し選択して、貪欲にシーケンスを構築しようとします。$d$。 可能な限り早い有効な次の点を選択すると、将来の選択に対して最も柔軟性が残されるため、この貪欲さは正しいです。 
4. 選択後$K$ポイントでは、円形の閉じ状態を確認します。 最後に選択したポイントから開始ポイントまでのギャップ (+360 ラップ経由) も少なくとも$d$。 このチェックがないと、構築では巡回一貫性を満たさないシーケンスが誤って受け入れられてしまいます。 
5. いずれかの開始インデックスが成功すると、候補は$d$実現可能です。 
6.二分探索$d$範囲内で$[0, 360]$十分な精度で実現可能性を繰り返しテストします。 
7. 実現可能な最大値を達成したら$d$が見つかったら、ラジアン単位のスライス面積の式を使用して答えを計算します。$$A = \frac{1}{2}(\theta - \sin \theta), \quad \theta = d \cdot \pi / 180$$### なぜ効果があるのか

 有効な解決策はどれも選択に対応します。$K$境界点を循環的な順序で並べます。 チェーン制約により、パーティションは連続する角度の差のみに依存するようになります。 各スライス領域は角度とともに単調に増加するため、最小スライス領域を最大化することは最小ギャップを最大化することと同じです。 貪欲な実現可能性チェックは、すべてのギャップに均一の下限を強制できるかどうかを正確に捕捉し、二分探索によりそのような最適な上限を見つけます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def can(d, ang, n, k):
    for start in range(n):
        cnt = 1
        last = ang[start]
        i = start
        while cnt < k:
            j = i + 1
            while j < start + n and ang[j] < last + d:
                j += 1
            if j >= start + n:
                break
            last = ang[j]
            i = j
            cnt += 1

        if cnt == k:
            if ang[start] + 360 - last >= d:
                return True
    return False

def main():
    n, k = map(int, input().split())
    a = list(map(float, input().split()))
    a.sort()

    ang = a + [x + 360 for x in a]

    lo, hi = 0.0, 360.0
    for _ in range(60):
        mid = (lo + hi) / 2
        if can(mid, ang, n, k):
            lo = mid
        else:
            hi = mid

    theta = lo * math.pi / 180.0
    ans = 0.5 * (theta - math.sin(theta))
    print("{:.10f}".format(ans))

if __name__ == "__main__":
    main()
```コードは最初に、循環ラップを自然に処理するために 2 倍の角度配列を構築します。 最適な構成は円上のどこからでも始まる可能性があるため、実現可能性関数は考えられるすべての開始点を試みます。 内部貪欲スキャンは、最小ギャップ制約に従って次の有効なポイントが見つかるまで、ポインターを前方に進めます。 

二分探索では、イプシロン チェックの代わりに固定反復回数が使用されます。この設定では、浮動小数点比較の方が安定しています。 最後に、円セグメント領域の幾何学的公式はラジアンで定義されているため、度からラジアンへの変換が必要です。 

よくある微妙なバグは、最後のラップアラウンド ギャップ チェックを忘れることです。これにより、ローカルでは有効でも、サークル上でグローバルに矛盾するチェーンが誤って受け入れられてしまいます。

```ここでは、すべてのギャップがジオメトリによって修正されるように、すべての点を選択する必要があります。 

| ステップ | 開始 | 選択済み | ギャップ |
 | --- | --- | --- | --- |

 ## 特殊なケース

 1 つの重要なエッジ ケースは、1 つの大きなギャップを除いてポイントがクラスター化されている場合に発生します。 たとえば、角度の場合$0, 1, 2, 3, 300$、最適な選択では、密な領域が回避され、大きなギャップの周囲に広がることが優先されます。 貪欲な実現可能性チェックは、常に最も早い有効な次のポイントに進み、残りの選択に対する最大限の柔軟性を維持するため、これを正しく処理します。 

もう 1 つのエッジケースは次のような場合です$K = 2$。 解決策は、円形距離を最大化する点のペアを選択することになります。 このアルゴリズムはすべての開始点を効果的にチェックし、制約の下で最も遠くに到達可能な 2 番目の点を選択するため、引き続き機能します。$d$、正しい二分探索収束を保証します。 

最後のエッジケースは次のような場合です$K = N$、選択の自由は残されていません。 このアルゴリズムでは当然、すべてのポイントが循環順序で選択されます。最小ギャップは、ラップアラウンドを含む連続する入力角度間の正確な最小距離です。
