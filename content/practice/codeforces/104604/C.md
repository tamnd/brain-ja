 ## アルゴリズムのチュートリアル

 ### 最適な戦略

 1. 2 つの大きな整数を選択します$m_1$そして$m_2$、通常は次の値に近い$10^{18}$そしてお互いに遠く離れています。 この分離により、一方のクエリが除数への近さによって影響を受ける場合でも、もう一方のクエリは独立して動作することが保証されます。 
2. それぞれについて$m_i$、タイプ 2 クエリを実行し、距離を受け取ります。$d_i$。 この距離は、約数または倍数までの最小距離を表します。$n$。 
3. 2 つの候補値を作成します。$$a_i = m_i - d_i, \quad b_i = m_i + d_i$$これらのうちの 1 つが、次の要素に最も近い要素であることが保証されます。$D_n \cup M_n$。 典型的な高範囲領域では、これは次の倍数です。$n$。 
4. 各クエリから、次の倍数であると一致する値を選択します。$n$。 実際には、どちらも$a_i$そして$b_i$明示的に正しさを判断するのではなく、gcd の整合性を介して暗黙的にテストされます。 
5. 以下を計算します。$$n = \gcd(\text{candidate from query 1}, \text{candidate from query 2})$$6. 出力$n$。 

正しさは、選択された両方の候補が次の倍数であるという事実から得られます。$n$選択された範囲内で高い確実性があり、残りの除数の汚染は、両方のクエリ間で一貫性がない限り、gcd 交差部分で存続しません。これは、別個の大規模なクエリでは起こりそうにありません。 

### なぜ効果があるのか

 タイプ 2 クエリからのすべての有効な応答は、除数または倍数のいずれかの点をエンコードします。$n$。 クエリが数直線のかなり奥まで取得されると、境界のない倍数の等差数列と比較して、約数は有界で疎になります。 これにより、最も近い要素がほぼ常に倍数セットに属する体制が作成されます。 したがって、各クエリは次の隠れた倍数を明らかにします。$n$、報告された距離だけずれている可能性があります。 このような 2 つの独立した倍数を取得し、それらの gcd を計算すると、基本周期が分離されます。$n$、 以来$n$は、観測されたすべての倍数を生成する最小の正の整数です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    # we assume interactive environment
    # placeholder structure for CF-style interaction
    def ask(m):
        print(f"? 2 {m}", flush=True)
        d = int(input())
        return d

    m1 = 10**18
    d1 = ask(m1)

    m2 = 10**18 - 10**9
    d2 = ask(m2)

    # candidate multiples (typical case assumes m - d is multiple)
    import math

    cand1 = m1 - d1
    cand2 = m2 - d2

    ans = math.gcd(cand1, cand2)

    print(f"! {ans}", flush=True)

t = int(input())
for _ in range(t):
    solve()

 ## 特殊なケース

 ### ケース:$n = 1$もし$n = 1$、すべての整数は約数であると同時に倍数でもあります。 タイプ 2 クエリは、クエリ ポイント自体が常に距離 0 にあるため、常に距離 0 を返します。$D_n \cup M_n$。 再構築により生成されるのは、$m$を候補として指定し、同一の候補にわたる gcd は 1 を返します。これは正しいです。 

＃＃＃ 場合：$n$プライムです

 プライムの場合$n$、約数は 1 のみであり、$n$。 遠く離れたクエリでも、約数ではなく最も近い倍数が返されます。 たとえ除数 1 が干渉したとしても、大きなクエリ ポイントからは遠く離れているため、高範囲で返される最小距離には影響せず、正確性が保たれます。 

### ケース: 除数に近いクエリ

 クエリが誤って小さな約数の近くに到達した場合、返される距離は倍数ではなく、その約数に対応する可能性があります。 これにより、次の倍数ではない候補が生成されます。$n$ただし、2 番目のクエリは独立しているため、少なくとも 1 つのクエリが有効な複数ベースの候補を生成する限り、gcd ステップによってこの汚染が除去されます。
