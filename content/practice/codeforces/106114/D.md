### なぜ効果があるのか

 到達可能なすべての最終文字列は、一連のスタンプ配置に対応します。 各スタンプは、以下と同一のローカル構造を強制します。$T$、スタンプで覆われた位置はすべて、次の特定のインデックスに関連付けられることを意味します。$T$。 オーバーラップは完全に上書きするだけであるため、最後に適用されたスタンプによって文字が決まり、この DP では常に有効な位置合わせとして表現できます。 逆に、すべてのローカル整合性チェックにより、隣接する位置を完全な出現まで拡張できることが保証されるため、DP 有効な割り当てはスタンプの一貫した階層化に対応します。$T$矛盾なく。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    t = input().strip()
    
    n = len(s)
    m = len(t)
    
    if n == 0:
        print("Yes")
        return
    
    # dp[i][j][k]: after processing i pairs, left state j, right state k
    # j,k in [0..m], where 0 means original character
    dp = [[[False] * (m + 1) for _ in range(m + 1)] for _ in range(n // 2 + 1)]
    
    dp[0][0][0] = True
    
    def ok_left(i, j):
        if j == 0:
            return True
        return t[j - 1] == s[i - 1]
    
    def ok_right(i, k):
        if k == 0:
            return True
        return t[k - 1] == s[n - i]
    
    for i in range(1, n // 2 + 1):
        for j in range(m + 1):
            for k in range(m + 1):
                if not dp[i - 1][j][k]:
                    continue
                
                li = i
                ri = i
                
                for nj in range(m + 1):
                    for nk in range(m + 1):
                        if ok_left(li, nj) and ok_right(ri, nk):
                            dp[i][nj][nk] = True
    
    for j in range(m + 1):
        for k in range(m + 1):
            if dp[n // 2][j][k]:
                print("Yes")
                return
    
    print("No")

if __name__ == "__main__":
    solve()

ダブルトランジションオーバー$(nj, nk)$スタンプが重なっていると内部の配置がリセットされる可能性を反映しています。$T$、厳密な直線的な進行ではなく、パターン位置間のジャンプが可能になります。 

最後のチェックでは、完全に構築された回文に対応する中間境界に一貫した割り当てが存在するかどうかをスキャンします。
