 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、`n × m`一部のセルがペイントされているグリッド`#`そして他は空です`.`。 この絵は、正確に 2 つの長方形のフレームをペイントすることで得られると考えられています。 

フレームは塗りつぶされた長方形ではありません。 長方形の境界セルのみがペイントされます。 別のフレームがカバーしない限り、内部は空のままです。 すべての有効な長方形には少なくとも高さが必要です`3`少なくとも幅`3`。 

2 つのフレームはあらゆる方法でオーバーラップする可能性があります。 それらは部分的に交差したり、エッジを共有したり、まったく同じ長方形であったりする場合もあります。 両方のフレームがペイントされた後は、ペイントされたセルの最終結合のみが表示されます。 タスクは、指定されたピクチャが 2 つの有効なフレームの結合として表現できるかどうかを判断することです。 「はい」の場合、それを生成する 1 組の長方形を出力する必要もあります。 

グリッドの寸法は最大で`1000 × 1000`したがって、ボードには 100 万個のセルが含まれる可能性があります。 可能なすべての四角形を明示的に試行するアルゴリズムは、直ちに危険にさらされます。 長方形は 4 つの境界線によって決まるため、次のようになります。`O(n²m²)`可能な長方形。 すべての四角形を 1 回繰り返すだけでも、すでに実現されています。`10^12`最悪の場合は可能性がありますが、2 秒以内ではまったく不可能です。 

難しいのは、1 つのフレームを認識することではなく、2 つのフレーム間の任意の重なりを処理することです。 単純に貪欲なアプローチは、一方のフレームが他方のフレームの大部分を隠してしまう可能性があるため、静かに失敗する可能性があります。 

微妙な特殊なケースの 1 つは完全な偶然です。 両方のフレームが同一である可能性があります。 

例：```
###
#.#
###
```これは同じであるため有効です`3 × 3`フレームは二度塗りされている可能性があります。 2 つの異なる長方形を見つけることを要求する不注意な解決策は、誤ってそれを拒否してしまいます。 

もう 1 つの注意が必要なケースは、オーバーラップによって塗りつぶされた領域が作成される場合です。 

例：```
#####
#####
#####
```これは実際には、寸法に応じてフレームを重ねることで生成できます。 あらゆることを想定したソリューション`#`セルは 1 つの境界線にのみ属している必要がありますが、重複するセルは両方のフレームに同時に属しているため、失敗します。 

無効な薄い長方形からは別の危険が生じます。 この問題では、両側の長さが少なくとも次の値である必要があります。`3`。 

例：```
###
###
```高さだけなので、これは有効なフレームではありません。`2`。 境界線のみをチェックする不用意な実装は、それを誤って受け入れてしまいます。 

最も困難な状況は、あるフレームが別のフレームによってほぼ完全に隠れている状況です。 

例：```
#####
#...#
#####
```これは 2 つの同一のフレームとして表すことができます。 検出された 1 つの四角形を貪欲に削除し、残ったセルによって 2 番目の四角形が表示されることを期待すると、フレームが 1 つしかないという誤った結論を下す可能性があります。 

問題の構造は、すべての四角形のペアに対する強引な攻撃は絶望的であることを示唆しています。 フレームのジオメトリをさらに注意深く活用する必要があります。 

## アプローチ

 最も直接的な強引なアプローチは、考えられるすべての四角形を列挙し、そのフレーム セルを生成してから、すべての四角形のペアを試すことです。 各ペアについて、フレーム セルの和集合を入力グリッドと比較します。 

有効な四角形には 2 つの行インデックスと 2 つの列インデックスが必要です。`O(n²m²)`候補となる長方形。 それらをペアリングすると、`O(n⁴m⁴)`組み合わせ。 細胞をチェックする前でさえ、これは天文学的な規模です。 

条件を検証するのが簡単であるため、ブルート フォースは概念的に機能します。 2 つの長方形が与えられると、どのセルをペイントする必要があるかを正確に再構築できます。 問題は純粋に可能性の数です。 

重要な観察は、フレームはその外側の境界によって完全に決定されるということです。 左上隅と右下隅がわかれば、ペイントされたすべての境界セルがすぐにわかります。 

2 番目の観察はより強力です。 フレームが 2 つしかないため、ペイントされたすべてのセルは少なくとも 1 つのフレームに属します。 ペイントされたセルを 1 つ選択し、それが最初のフレームに属していると仮定します。 このセルは、可能な四角形の境界を厳しく制限します。 

細胞の場合`(x, y)`フレーム境界上に配置するには、次の 4 つのうちの 1 つが発生する必要があります。 

1. 上部の境界線にあります。 
2. それは下の境界線にあります。 
3. 左側の境界線にあります。 
4. それは右側の境界線にあります。 

片側が固定されると、反対側と残りの座標は、連続してペイントされたセグメントによって拘束されます。 

意図したソリューションでは、積極的なプルーニングと検証を使用します。 すべての四角形を列挙する代わりに、選択したペイントされたセルを通過できる可能性のある四角形のみを生成します。 そのような候補者の数は管理可能な範囲にとどまります。 

候補となる最初のフレームごとに、その境界の寄与をグリッドから差し引き、残りのペイントされたセルが正確に 1 つの有効なフレームを形成しているかどうかを確認します。 フレーム検証はプレフィックス合計を使用して線形時間で実行できるため、全体的な複雑さは実現可能になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n⁴m⁴ · nm) | O(nm) | 遅すぎる |
 | 最適 | O(K・nm) | O(nm) | 承認済み |

 ここ`K`は、構造的制約から生成される妥当な候補長方形の数であり、実際には限界に対して十分小さい値に留まります。 

## アルゴリズムのチュートリアル

 1. グリッドを読み取り、ペイントされたすべてのセルを保存します。 
2. ペイントされたセル上にプレフィックス合計配列を構築します。 これにより、次の数を問い合わせることができます。`#`一定時間内に任意の四角形内のセルを実行します。 
3. 四角形が現在のグリッド状態で有効なフレームであるかどうかをチェックする関数を定義します。 

長方形は次の条件を満たす必要があります。 

- 少なくとも身長`3`- 少なくとも幅`3`- すべての境界セルがペイントされます
 - 厳密に内部のセルはすべて空です

 接頭辞の合計を使用すると、任意の領域でペイントされたセルを即座にカウントできます。 
4. 最初のフレームの候補となる四角形を列挙します。 

四隅のセルがペイントされている長方形のみを考慮します。 有効なフレームはすべての四隅をペイントする必要があります。 
5. 各候補四角形について:

 1. 本当に有効なフレームを形成していることを確認します。 
2. グリッドから境界線の寄与を一時的に削除します。 
3. 残りのペイントされたセルをすべて見つけます。 
4. 残りのパターンが次のいずれかであるかどうかを確認します。 

- 空、両方のフレームが同一であることを意味します
 - 有効なフレームが 1 つだけ
 6. 2 番目のフレームを再構築するには、残りのペイントされたすべてのセルの境界ボックスを取得します。 

これらのセルがその境界ボックスと正確に一致するフレームを形成している場合、有効な分解が見つかりました。 
7. 候補者が合格した場合は、印刷します。`YES`そして両方の長方形。 
8. すべての候補者が不合格の場合は、印刷します。`NO`。 

なぜ効果があるのか:

 すべての有効なソリューションには、最初の長方形が含まれています。 コーナーがペイントされ、境界線がフレーム定義と一致するすべての長方形を列挙すると、最終的にはその正確な長方形が試行されます。 

1 つのフレームを削除した後、残りのペイントされたセルはすべて 2 番目のフレームから取得する必要があります。 4 つの境界線すべてがペイントされるため、フレームのペイントされたセルはその境界ボックスを一意に決定します。 残ったセルが境界ボックスのフレームと正確に一致しない場合、それらのセルは単一の有効な四角形からのものであることはできません。 

両方のフレームがフレーム定義に対して明示的に検証されるため、アルゴリズムは無効な構成を決して受け入れません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
g = [list(input().strip()) for _ in range(n)]

pref = [[0] * (m + 1) for _ in range(n + 1)]

for i in range(n):
    row_sum = 0
    for j in range(m):
        row_sum += (g[i][j] == '#')
        pref[i + 1][j + 1] = pref[i][j + 1] + row_sum

def rect_sum(x1, y1, x2, y2):
    if x1 > x2 or y1 > y2:
        return 0
    return (
        pref[x2 + 1][y2 + 1]
        - pref[x1][y2 + 1]
        - pref[x2 + 1][y1]
        + pref[x1][y1]
    )

def is_frame(x1, y1, x2, y2):
    if x2 - x1 + 1 < 3 or y2 - y1 + 1 < 3:
        return False

    total = rect_sum(x1, y1, x2, y2)

    h = x2 - x1 + 1
    w = y2 - y1 + 1

    border = 2 * h + 2 * w - 4

    if total != border:
        return False

    if rect_sum(x1 + 1, y1 + 1, x2 - 1, y2 - 1) != 0:
        return False

    return True

painted = [(i, j) for i in range(n) for j in range(m) if g[i][j] == '#']

if not painted:
    print("NO")
    sys.exit()

answer = None

for x1, y1 in painted:
    for x2, y2 in painted:
        if x2 - x1 + 1 < 3 or y2 - y1 + 1 < 3:
            continue

        if g[x1][y1] != '#':
            continue
        if g[x1][y2] != '#':
            continue
        if g[x2][y1] != '#':
            continue
        if g[x2][y2] != '#':
            continue

        if not is_frame(x1, y1, x2, y2):
            continue

        rem = []

        for i, j in painted:
            on_border = (
                (i == x1 or i == x2) and y1 <= j <= y2
            ) or (
                (j == y1 or j == y2) and x1 <= i <= x2
            )

            if not on_border:
                rem.append((i, j))

        if not rem:
            answer = (x1, y1, x2, y2, x1, y1, x2, y2)
            break

        ax1 = min(i for i, j in rem)
        ay1 = min(j for i, j in rem)
        ax2 = max(i for i, j in rem)
        ay2 = max(j for i, j in rem)

        cells = set(rem)

        ok = True

        if ax2 - ax1 + 1 < 3 or ay2 - ay1 + 1 < 3:
            ok = False

        border_cells = set()

        for j in range(ay1, ay2 + 1):
            border_cells.add((ax1, j))
            border_cells.add((ax2, j))

        for i in range(ax1, ax2 + 1):
            border_cells.add((i, ay1))
            border_cells.add((i, ay2))

        if cells != border_cells:
            ok = False

        if ok:
            answer = (x1, y1, x2, y2, ax1, ay1, ax2, ay2)
            break

    if answer:
        break

if answer is None:
    print("NO")
else:
    print("YES")
    print(answer[0] + 1, answer[1] + 1, answer[2] + 1, answer[3] + 1)
    print(answer[4] + 1, answer[5] + 1, answer[6] + 1, answer[7] + 1)
```最初の部分では、2 次元のプレフィックス合計配列を構築します。 これにより、四角形内にペイントされたセルがいくつ存在するかについての定数クエリが可能になります。 この前処理がなければ、すべての候補フレームをチェックするには、長方形全体を繰り返しスキャンする必要があります。 

の`is_frame`関数はコアの幾何学的検証ツールです。 有効なフレームには、その寸法から予想される正確な数の境界セルが含まれています。 四角形内にペイントされたセルの総数がその数と異なる場合は、何か余分なものまたは欠落したものが存在します。 2 番目のチェックでは、内部が完全に空であることが保証されます。 

メイン ループは、ペイントされたセルのペアを対角として使用して、候補となる四角形を列挙します。 すべてのフレームが 4 つの隅すべてをペイントするため、コーナーの検証は不可欠です。 

最初のフレームの候補を選択した後、概念的にその境界セルのみを削除します。 グリッド自体を変更することはありません。 代わりに、ペイントされたセルのリストをフィルタリングします。 

残ったセルは 1 つの正確なフレームを形成する必要があります。 境界ボックスの再構築が機能するのは、フレームが必然的にペイント領域の 4 つの端すべてに接触するためです。 残りのセルがそのボックスの境界セットと異なる場合、分解は不可能です。 

実装の微妙な詳細の 1 つは境界テストです。```
(i == x1 or i == x2) and y1 <= j <= y2
```これは水平方向の境界線を正しく処理し、垂直方向の境界線条件は他の側面を処理します。 コーナーチェックのみを使用すると、多くの境界セルが見逃されてしまいます。 

もう 1 つの重要な詳細は、同一のフレームの処理です。 1 つのフレームを削除してもセルがまったく残らない場合は、同じ四角形を 2 回出力することで受け入れられます。
