 ## 解決策
 ## 問題の理解

 長方形のグリッドがあり、各セルにはコスト、つまりセルをコンクリートで舗装した場合に破壊される花の数が設定されています。 すべてのセルの中に、重要な建物を含む特別なセルが最大 7 つあります。 すべての重要なセルが舗装領域に属し、すべての重要なセルが舗装セル内の 4 方向の移動を使用して他のすべてのセルに到達できるように、舗装セルの接続セットを選択する必要があります。 

目的は、すべての舗装セルのコストの合計を最小限に抑えることです。 

グリッドを加重グラフとして考えると便利です。 すべてのセルは頂点であり、隣接するセルはエッジで接続されており、セルに入るには花の数が消費されます。 すべての端末を含む最小コストの接続されたサブグラフを探しています。 これはまさにグリッド グラフ上のシュタイナー ツリー問題です。 

グリッドには最大 200 個のセルを含めることができますが、これはすべての頂点にわたるグラフ アルゴリズムには十分な小ささです。 端末の数は最大でも 7 つであり、これが本当の手がかりです。 一般的なスタイナー ツリー問題は NP 困難ですが、端末の数が少ない場合はサブセット動的計画法が可能になります。 

すべてのグリッド サブセットに対する単純なサブセット列挙では、以下のチェックが必要になります。$2^{200}$状態、完全に不可能です。 すべてのツリーまたは端末間のすべてのパスを列挙するだけでも、組み合わせ的に爆発的に増加します。 

端末数が少ないことは、DP が端末マスクよりも優れていることを示唆しています。 以来$2^7 = 128$、端末のすべてのサブセットとすべてのセルの DP 状態を維持できます。 

見逃しやすいコーナーケースがいくつかあります。 

微妙なケースの 1 つは、最適なソリューションが複数の端末接続によって共有されるセルを再検討する場合です。 

例：```
2 3 3
1 100 1
1 1 1
1 1
1 3
2 2
```最も安価な構造は、3 つの別々の最短パスではありません。 中下段は共用廊下として機能します。 端末をペアごとに独立して接続する貪欲な戦略は、コストを過大評価し、最適ではない結合を生成します。 

もう 1 つの注意が必要なケースは、2 つの端末が隣接している場合です。```
1 2 2
5 7
1 1
1 2
```答えは、両方のセルを合計コスト 12 で舗装する必要があります。パス コストを頂点コストではなくエッジ コストとして扱う不注意な実装では、1 つのエンドポイントを含めるのを忘れる可能性があります。 

再構築中には、さらに微妙な問題が発生します。 異なるサブセットが同じセルに結合する場合があります。```
3 3 3
1 1 1
1 100 1
1 1 1
1 1
1 3
3 2
```最適なツリーは、安価な外側セルの周囲にマージし、中心を避けます。 親追跡が最短経路緩和のみを保存し、サブセットのマージを保存しない場合、DP 値が正しい場合でも再構築は失敗します。 

## アプローチ

 ブルートフォースアプローチは、グリッドセルのすべてのサブセットを列挙し、それがすべての端子を含む接続コンポーネントを形成しているかどうかを確認し、その総コストを計算することです。 グリッドには最大 200 個のセルがあるため、これを調べる必要があります。$2^{200}$サブセットは天文学的に大きい。 

もう少し賢い強引なアイデアは、端末を接続する可能なすべてのツリーを試すことです。 グラフ自体には最大 200 個の頂点があり、多くの可能なシュタイナー点があるため、候補ツリーの数は依然として実現可能をはるかに超えています。 

重要な観察は、重要な細胞の数が非常に少ないということです。 少数の端末しか存在しない場合は、ビットマスクを使用して接続要件を記述することができます。 

次のように定義するとします。$$dp[mask][v]$$の端子を正確に含む接続された舗装領域の最小コストとして`mask`そしてセルで終わります`v`、 意味`v`接続された構造に属します。 

これで、問題は対処可能になり始めました。 あるのは$2^k \le 128$マスクと最大 200 個のセルがあるため、状態の総数は約 25,000 になります。 

次の観察は、これらの状態がどのように組み合わされるかです。 

2 つの接続された構造が両方とも同じセルで終わる場合`v`、1 つのサブセットをカバー`A`そしてもう一つのカバーサブセット`B`でそれらをマージします。`v`有効な接続構造を作成します`A ∪ B`。 

これにより、次のような遷移が得られます。$$dp[A \cup B][v] = dp[A][v] + dp[B][v] - cost(v)$$両方の構造ですでにセル コストがカウントされているため、セル コストを 1 回差し引きます。 

サブセットのマージを実行した後も、グリッド内を移動する必要があります。 すべてのセルから、グラフ上の最短パスとまったく同じように近傍を緩和できます。 すべてのエッジの追加は隣接セルのコストの支払いに対応するため、マルチソース最短パス伝播は到達可能なすべてのエンドポイントを最適に更新します。 

サブセット DP と最短パスのこの組み合わせは、古典的な Dreyfus-Wagner スタイルの Steiner Tree DP です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^{nm})$|$O(2^{nm})$| 遅すぎる |
 | 最適 |$O(3^k \cdot nm + 2^k \cdot (nm)^2)$|$O(2^k \cdot nm)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのグリッド セルをグラフの頂点に変換します。 

各セルに整数の ID を与えます。 4 つの基本方向で隣接するセルは接続されます。 
2. DP 状態を定義します。 

させて：$$dp[mask][v]$$すべてのターミナルを含む接続された構造物の最小総舗装コストになります。`mask`そして頂点で終わる`v`。 
3. シングルトンマスクを初期化します。 

端子の場合`i`頂点に位置します`v`、 それから：$$dp[1 << i][v] = cost(v)$$なぜなら、その端子のみを含む最小の接続構造は単一セルそのものだからです。 
4. 小さいサブセットを大きいサブセットにマージします。 

すべてのマスクと空ではないすべての適切なサブマスクについて:$$sub \subset mask$$アップデート：$$dp[mask][v] = \min( dp[mask][v], dp[sub][v] + dp[mask \oplus sub][v] - cost(v) )$$接続された両方の構造が同じセルで出会う`v`、より大きな接続構造が生成されます。 
5. すべてのマスクに対して最短経路緩和を実行します。 

サブセットのマージ後、1 つのセルで終わる最適な構造が隣接するセルに拡張される可能性があります。 

すべてのコストは正であるため、ダイクストラは自然に機能します。 

マスクごとに、初期距離を持つすべての頂点から開始してダイクストラを実行します。`dp[mask][v]`。 

からリラックス`u`に`to`追加します`cost(to)`。 
6. 親情報を追跡します。 

再構築には 2 種類の親が必要です。 

まず、ダイクストラからの最短経路の親です。 

2 番目に、どの 2 つのサブマスクがマージされたかを示すサブセット分割親。 
7. 最適なエンドポイントを見つけます。 

答えは次のとおりです。$$\min_v dp[(1<<k)-1][v]$$構造自体が接続されているため、どのエンドポイントも機能します。 
8. 使用したセルを再構築します。 

親ポインタを再帰的にたどります。 

状態がサブセット マージから得られる場合は常に、両方の部分を再帰します。 

最短経路緩和から状態が得られるたびに、前のセルに再帰します。 

訪問したすべてのセルを舗装済みとしてマークします。 

### なぜ効果があるのか

 DP の不変式は次のとおりです。$$dp[mask][v]$$のすべてのターミナルを含む、接続されているすべての舗装サブグラフ間の最小コストに常に等しくなります。`mask`頂点を含む`v`。 

接続されたシュタイナー ツリーは分岐頂点で、互いに素な終端サブセットをカバーする小さな接続されたツリーに分解できるため、サブセットの遷移は正確です。 

隣接する 1 つのセルによって接続された構造を拡張すると接続性が維持され、そのセルの舗装コストが正確に追加されるため、最短パス緩和は正しいです。 

接続されたすべてのシュタイナー ツリーは、より小さな端末グループを繰り返しマージし、隣接するセルに拡張することによって構築できるため、DP はすべての有効な可能性を探索します。 すべての遷移で最適性が維持されるため、完全なマスクの最終状態は全体的に最適になります。 

## Python ソリューション```python
import sys
import heapq

input = sys.stdin.readline

INF = 10**18

def solve():
    n, m, k = map(int, input().split())

    grid = [list(map(int, input().split())) for _ in range(n)]

    terminals = []
    for _ in range(k):
        x, y = map(int, input().split())
        terminals.append((x - 1, y - 1))

    V = n * m

    def vid(x, y):
        return x * m + y

    cost = [0] * V

    for i in range(n):
        for j in range(m):
            cost[vid(i, j)] = grid[i][j]

    adj = [[] for _ in range(V)]

    dx = [-1, 1, 0, 0]
    dy = [0, 0, -1, 1]

    for x in range(n):
        for y in range(m):
            v = vid(x, y)

            for d in range(4):
                nx = x + dx[d]
                ny = y + dy[d]

                if 0 <= nx < n and 0 <= ny < m:
                    adj[v].append(vid(nx, ny))

    FULL = 1 << k

    dp = [[INF] * V for _ in range(FULL)]

    parent = [[None] * V for _ in range(FULL)]

    for i, (x, y) in enumerate(terminals):
        v = vid(x, y)
        dp[1 << i][v] = cost[v]

    for mask in range(FULL):

        sub = (mask - 1) & mask

        while sub:
            other = mask ^ sub

            for v in range(V):
                val = dp[sub][v] + dp[other][v] - cost[v]

                if val < dp[mask][v]:
                    dp[mask][v] = val
                    parent[mask][v] = ("merge", sub, other)

            sub = (sub - 1) & mask

        pq = []

        for v in range(V):
            if dp[mask][v] < INF:
                heapq.heappush(pq, (dp[mask][v], v))

        while pq:
            dist, v = heapq.heappop(pq)

            if dist != dp[mask][v]:
                continue

            for to in adj[v]:
                nd = dist + cost[to]

                if nd < dp[mask][to]:
                    dp[mask][to] = nd
                    parent[mask][to] = ("move", v)

                    heapq.heappush(pq, (nd, to))

    full = FULL - 1

    best_v = min(range(V), key=lambda v: dp[full][v])

    ans = dp[full][best_v]

    used = [[False] * m for _ in range(n)]

    sys.setrecursionlimit(10**6)

    def build(mask, v):
        x = v // m
        y = v % m

        used[x][y] = True

        p = parent[mask][v]

        if p is None:
            return

        if p[0] == "move":
            build(mask, p[1])

        else:
            _, a, b = p
            build(a, v)
            build(b, v)

    build(full, best_v)

    print(ans)

    for i in range(n):
        row = []

        for j in range(m):
            row.append('X' if used[i][j] else '.')

        print("".join(row))

solve()
```このソリューションには、サブセット DP と最短パスという 2 つの絡み合ったコンポーネントがあります。 

DP テーブルには、すべての端末サブセットおよびエンドポイントに最適な接続構造が格納されます。 すべての端末の数は小さいため、すべてのマスクを反復処理することが可能です。 

サブセット マージ ループでは、標準のサブマスク反復パターンが使用されます。```
sub = (mask - 1) & mask
```これにより、空ではない適切なサブマスクがすべて効率的に列挙されます。 

ここでよくあるバグは、会議セルを二重にカウントすることです。 両方の部分構造にはすでに頂点が含まれています`v`, そのため、マージ中にそのコストを 1 回差し引きます。 

マージ後、ダイクストラは接続された構造をグリッドを通じて伝播します。 新しい舗装されたセルに入るとその花が破壊されるため、距離の更新により目的地のセルのコストが追加されます。 

親追跡には 2 種類のトランジションが保存されます。```
("move", prev_vertex)
```ディクストラ緩和を意味します。```
("merge", left_mask, right_mask)
```2 つのサブセットが同じ頂点でマージされたことを意味します。 

再構成 DFS は、これらの遷移を再帰的に追跡し、訪問されたすべてのセルをマークします。 

微妙な点の 1 つは、複数の再帰呼び出しが同じ状態を再訪する可能性があることです。 必要なのは使用済みセルの最終セットのみであるため、これは無害です。

# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    import heapq

    input = sys.stdin.readline
    INF = 10**18

    out = io.StringIO()
    sys.stdout = out

    n, m, k = map(int, input().split())

    grid = [list(map(int, input().split())) for _ in range(n)]

    terminals = []
    for _ in range(k):
        x, y = map(int, input().split())
        terminals.append((x - 1, y - 1))

    V = n * m

    def vid(x, y):
        return x * m + y

    cost = [0] * V

    for i in range(n):
        for j in range(m):
            cost[vid(i, j)] = grid[i][j]

    adj = [[] for _ in range(V)]

    for x in range(n):
        for y in range(m):
            v = vid(x, y)

            for dx, dy in [(-1,0),(1,0),(0,-1),(0,1)]:
                nx = x + dx
                ny = y + dy

                if 0 <= nx < n and 0 <= ny < m:
                    adj[v].append(vid(nx, ny))

    FULL = 1 << k

    dp = [[INF] * V for _ in range(FULL)]

    for i, (x, y) in enumerate(terminals):
        dp[1 << i][vid(x, y)] = cost[vid(x, y)]

    for mask in range(FULL):

        sub = (mask - 1) & mask

        while sub:
            other = mask ^ sub

            for v in range(V):
                dp[mask][v] = min(
                    dp[mask][v],
                    dp[sub][v] + dp[other][v] - cost[v]
                )

            sub = (sub - 1) & mask

        pq = []

        for v in range(V):
            if dp[mask][v] < INF:
                heapq.heappush(pq, (dp[mask][v], v))

        while pq:
            dist, v = heapq.heappop(pq)

            if dist != dp[mask][v]:
                continue

            for to in adj[v]:
                nd = dist + cost[to]

                if nd < dp[mask][to]:
                    dp[mask][to] = nd
                    heapq.heappush(pq, (nd, to))

    ans = min(dp[FULL - 1])

    print(ans)

    sys.stdout = sys.__stdout__

    return out.getvalue().strip()
