 ## 解決策
 ## 問題の理解

 クラス内で少なくとも 1 つの科目で最も優れた生徒の数を見つけるように求められます。 各学生には複数の科目の成績があり、各成績は 1 から 9 までの 1 桁の数字です。入力は、サイズが _n_ × _m_ のグリッドとして成績を表します。各行は学生に対応し、各列は科目に対応します。 少なくとも 1 つの列で、その生徒の成績がその科目の全生徒の最高成績と一致する場合、その生徒は合格したとみなされます。 

制約は緩やかです: 生徒の数と被験者の数は両方とも最大 100 です。これは、最大 10,000 回の操作に相当する生徒と被験者の二重ループを含むソリューションが 1 秒の制限時間内で快適に実行されることを意味します。 注意しなければならないエッジケースには、すべての生徒が同じ成績である場合、すべての科目で 1 人の生徒だけがトップである場合、または科目の最高成績が複数回表示される場合などがあります。 不注意なアプローチでは、生徒が科目内で唯一の最大値である場合にのみ生徒をカウントする可能性があり、間違った答えが生成されてしまいます。 

## アプローチ

 簡単な強引なアプローチは、各生徒をすべての科目でチェックし、その科目の最高成績を追跡することです。 最大値を達成したら、それを達成したすべての生徒にマークを付けます。 これには、各列を反復処理して最高成績を見つけ、次に各生徒を再度反復してその最高成績と一致するかどうかを確認することが含まれます。 すべての科目のすべての生徒を明示的に比較するため、正確さが保証されます。 

この総当り攻撃は、これらの制約に対してすでに最適です。 重要な洞察は、追加のデータ構造を並べ替えたり使用したりする必要がないということです。 成功した生徒の一連のインデックスを維持し、生徒が科目の最高成績に一致するたびにインデックスを更新するだけです。 グリッドが小さく、列ごとの最大計算が安価であるため、問題の構造によりこれが実現可能になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * m) | O(n) | 承認済み |
 | 最適 | O(n * m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 学生数 _n_ と科目数 _m_ の入力値を読み取り、次の _n_ 行を学生の成績を表す文字列として読み取ります。 各行はインデックス付けを容易にするためにリストに変換されます。 
2. 成功した生徒を追跡するためにセットを初期化します。 セットを使用すると、二重カウントが回避され、効率的に挿入できます。 
3. 各主題インデックスを 0 から _m-1_ まで反復します。 科目ごとに、その列の行を反復処理して、全生徒の最高成績を見つけます。 
4. 現在の科目の最高成績が決定したら、すべての生徒に対して再度反復処理を行い、その科目の最高成績と一致する生徒を合格セットに追加します。 
5. すべての科目を処理した後の成功セットのサイズは、成功した生徒の総数を表します。 この値を出力します。 

機能する理由: 列ごとに反復することにより、すべての主題で上位のパフォーマンスがチェックされることが保証されます。 このセットでは、各生徒がトップの科目数に関係なく 1 回だけカウントされることが保証されます。すべての生徒の成績比較が明示的に行われるため、アルゴリズムは合格した生徒を見逃すことはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
grades = [list(input().strip()) for _ in range(n)]
successful = set()

for col in range(m):
    max_grade = max(grades[row][col] for row in range(n))
    for row in range(n):
        if grades[row][col] == max_grade:
            successful.add(row)

print(len(successful))
```コードは最初に寸法とグレード グリッドを読み取ります。 各生徒の成績は文字のリストとして保存されます。 メインループは各主題 (列) を反復します。 各列について、ジェネレーター式を使用して最高成績が計算され、別のループでその成績を達成したすべての生徒がマークされます。 最後に、セットの長さによって、合格した生徒の数が決まります。 微妙な点は、成績が 1 桁の文字であるため、文字列として処理することです。 これが機能するのは、数字の文字比較では整数比較と同じ順序が与えられるためです。 セットを使用すると、追加の簿記を行わずに重複を回避できます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n * m) | 各科目の反復では、すべての生徒をスキャンして最大値を見つけ、再度成功した生徒にマークを付ける必要があります。 
| スペース | O(n) | このセットには最大 n 人の生徒のインデックスが保存されます。 

n と m が最大 100 の場合、合計操作は最大 10,000 回であり、1 秒の制限内に簡単に収まります。 メモリ使用量は、256 MB の制限に比べれば無視できます。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    grades = [list(input().strip()) for _ in range(n)]
    successful = set()
    for col in range(m):
        max_grade = max(grades[row][col] for row in range(n))
        for row in range(n):
            if grades[row][col] == max_grade:
                successful.add(row)
    return str(len(successful))

# Provided samples
assert run("3 3\n223\n232\n112\n") == "2", "sample 1"
assert run("2 2\n99\n99\n") == "2", "sample 2"

# Custom cases
assert run("1 1\n5\n") == "1", "single student and subject"
assert run("3 3\n111\n111\n111\n") == "3", "all equal values"
assert run("2 5\n12345\n54321\n") == "2", "top in multiple subjects"
assert run("4 4\n9123\n1294\n2912\n3219\n") == "4", "multiple winners"
assert run("100 1\n" + "\n".join("9" for _ in range(100)) + "\n") == "100", "maximum n edge case"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 1\n5\n | 1 | 最小サイズの入力 |
 | 3 3\n111\n111\n111\n | 3 | すべて等しい値 |
 | 2 5\n12345\n54321\n | 2 | 異なる勝者を持つ複数の主題 |
 | 4 4\n9123\n1294\n2912\n3219\n | 4 | 勝者の複雑な組み合わせ |
 | 100 1\n9 を繰り返します | 100 | 生徒の最大数 |
