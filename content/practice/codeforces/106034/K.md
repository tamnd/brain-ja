 ## 解決策
 ## 問題の理解

 次数 3 の固定線形反復によって定義されるシーケンスが与えられます。 最初の 3 つの値は 1、1、および 2 に固定されています。後のすべての値は、前の 3 つの値の加重和、具体的には、前の項とその前の項の 2 倍と 3 番目の前の項の 3 倍を加算し、その結果を剰余して減算することによって生成されます。$10^9 + 7$。 タスクは、$n$このシーケンスの - 番目の値。ここで、$n$非常に大きくなる可能性があり、最大で$10^{12}$。 

重要な構造上の詳細は、これが「アレイの構築」の問題ではないということです。 反復により決定的なシーケンスが定義されますが、インデックス範囲により直接シミュレーションが不可能になります。 100万歩でもいいけど$10^{12}$ステップでは、圧縮された代数形式で遷移を表現する必要があります。 

制約$n \le 10^{12}$追加の構造を持たずに反復状態に依存する線形時間または対数時間のアプローチは除外されます。 有効な解決策では、反復の繰り返し適用を減らして、累乗するか、大きなインデックス ギャップを飛び越えることができるものにする必要があります。 

いくつかの特殊なケースは、見た目よりも重要です。 いつ$n = 1, 2, 3$の場合、答えは初期化によって直接与えられるため、反復ロジックを通じて処理する必要はありません。 

小さな間違いの場合、最も危険な失敗モードはインデックス付けの変更です。 たとえば、誰かが治療した場合、$a_0, a_1, a_2$の代わりに初期値として$a_1, a_2, a_3$の場合、遷移行列のべき乗は 1 だけオフになり、すべての重要なテストで見た目は正しくても正しくない出力が生成されます。 もう 1 つのよくある問題は、すべての算術演算は剰余で計算する必要があることを忘れていることです。$10^9+7$最後だけでなく、乗算のすべてのステップで、これは大きな整数を持たない言語では静かにオーバーフローします。 

## アプローチ

 ブルート フォースの解釈は簡単です。最初の 3 つの値から開始し、インデックスに到達するまで反復を繰り返し適用します。$n$。 各ステップには一定の時間がかかるため、これは次のように実行されます。$O(n)$。 これは数学的に正しいです。各項は前の 3 つの項にのみ依存するため、状態が失われることはありません。 この失敗は純粋に計算上のものです。$n = 10^{12}$、これには約 1 兆回の操作が必要ですが、これは実現可能な時間制限をはるかに超えています。 

重要な観察は、反復が線形であり、以前の値の固定サイズのウィンドウにのみ依存するということです。 これは、システムの進化が定数遷移行列の乗算として表現できることを意味します。 一度に 1 ステップずつ進める代わりに、この行列をべき乗することができます。$n-3$、それを初期状態ベクトルに適用します。$[a_3, a_2, a_1]$。 行列のべき乗は、線形時間から対数時間への繰り返しの遷移を削減します。$n$累乗は二乗を繰り返すことで実行できるためです。 

これにより、問題は 3×3 行列のべき乗を効率的に計算し、それを基底ベクトルに 1 回適用することに変換されます。

 ## アルゴリズムのチュートリアル

 繰り返しを状態遷移にエンコードします。 位置の状態$i$は、最後の 3 つの値を含むベクトルであり、固定行列を乗算すると次の状態が生成されるように順序付けされています。 

1. 状態ベクトルを次のように定義します。$[a_i, a_{i-1}, a_{i-2}]$。 この順序付けにより、シーケンスを前方にシフトすることが線形変換に対応することが保証されます。 
2. 遷移行列を構築する$T$次のような:$$a_{i+1} = a_i + 2a_{i-1} + 3a_{i-2}$$これが最初の行になります$T$一方、残りの行は値を状態ベクトルの下にシフトするだけです。 この構造は、1 回の操作で繰り返しとメモリ更新の両方をエンコードします。 
3. もし$n \le 3$、遷移が必要ないため、事前定義された値がすぐに返されます。 
4. それ以外の場合は計算します$T^{n-3}$2進累乗を使用します。 各二乗ステップは 2 つの線形変換を構成し、そのようなステップの数は次のように対数になります。$n$。 これが機能する理由は、線形変換の繰り返し適用が結合的であるため、べき乗ルールが適用されるためです。 
5. 結果の行列に初期状態ベクトルを乗算します。$[a_3, a_2, a_1] = [2, 1, 1]$。 結果の最初の座標が答えです。 

### なぜ効果があるのか

 すべてのステップで、状態ベクトルは次の値を計算するために必要なすべての情報を完全に取得します。 遷移行列は再発を正確に再現するため、次のように乗算します。$T$近似せずにシーケンスを 1 インデックスだけ進めます。 行列乗算は正しく遷移を構成するため、$T^k$正確に表す$k$再発の繰り返しの適用。 これにより、べき乗後の計算された状態がインデックスの真のシーケンス値と一致することが保証されます。$n$、大きさに関係なく$n$は。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mat_mul(a, b):
    n = 3
    res = [[0] * n for _ in range(n)]
    for i in range(n):
        for k in range(n):
            if a[i][k]:
                aik = a[i][k]
                for j in range(n):
                    res[i][j] = (res[i][j] + aik * b[k][j]) % MOD
    return res

def mat_pow(mat, p):
    n = 3
    res = [[0]*n for _ in range(n)]
    for i in range(n):
        res[i][i] = 1

    base = mat
    while p > 0:
        if p & 1:
            res = mat_mul(res, base)
        base = mat_mul(base, base)
        p >>= 1
    return res

def solve():
    n = int(input())
    if n == 1:
        print(1)
        return
    if n == 2:
        print(1)
        return
    if n == 3:
        print(2)
        return

    T = [
        [1, 2, 3],
        [1, 0, 0],
        [0, 1, 0]
    ]

    Tn = mat_pow(T, n - 3)

    init = [2, 1, 1]
    ans = 0
    for i in range(3):
        ans = (ans + Tn[0][i] * init[i]) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```コードは漸化係数から直接遷移行列を構築します。 最初の行は前の 3 つの項から次の項がどのように形成されるかを示し、下の行は状態のシフトを実装します。 指数は$n-3$基本状態がすでに位置 3 を表しているためです。 

乗算ルーチンは各算術演算で完全にモジュール化されているため、オーバーフローが防止され、モジュラス制約の下での正確性が保証されます。

 ## 特殊なケース

 のために$n = 1, 2, 3$の場合、アルゴリズムは行列のべき乗を完全にバイパスし、ハードコードされた初期値を返します。 たとえば、入力$n = 2$行列を構築したり乗算したりせずに、出力 1 に直接マッピングします。 

のために$n = 4$、アルゴリズムは単一の遷移を実行します。 マトリックスパワーは次のようになります。$T^{1}$これはまさに遷移行列そのものであるため、初期ベクトルを乗算すると正しい第 4 項が得られます。 

非常に大きい場合$n$、 のような$n = 10^{12}$、べき乗ループは約 40 回繰り返し実行されます。 各反復では 3×3 行列の 2 乗または乗算が行われ、すべての演算がモジュロで実行されるため、状態は一貫したままになります。$10^9+7$値がオーバーフローすることがなく、常に有効なシーケンス状態に対応するようにします。
