 ## 問題の理解

 同心円状の凸多角形のスタックが与えられ、その内側に別の多角形が配置されており、各多角形には前の多角形が完全に含まれています。 各レイヤーにはスコアが関連付けられています。 ダーツがある領域に着地した場合、その点をまだカバーしている最も内側のポリゴンのスコアが常にクレジットされます。 

幾何学的には、これにより、平面が互いに素な「リング」、つまり多角形の間の領域に分割されます。$i-1$とポリゴン$i$。 リング上のどこにでも着地するダーツ$j$スコアが得られます$S_j$, 投げを定義する外側の境界内にある限り、外側にどれだけ投げられたかに関係なく。 

アリスが投げる$M$ダーツ。 彼女は最初に「精密領域」ポリゴンを選択します。$t$。 その通り$K$ダーツはポリゴン内で均一にランダムに投げられます$t$、残りは$M-K$ダーツは最も外側のポリゴン内に均一に投げられます$N$。 

目標は、最適なポリゴンを選択することです$t$すべてのダーツの予想合計スコアが最大になるようにします。 答えはモジュロで求められるため、$10^9+7$、最終値は逆剰余を使用した分数として表されます。 

この制約は、ランダムな点をシミュレートしたり、ジオメトリを離散化したりできないことを意味します。 領域と期待値の計算は、ポリゴン全体にわたって線形時間で実行する必要があり、すべての比較は浮動小数点ではなく正確である必要があります。 

素朴な解釈では、各候補者を評価しようとするでしょう。$t$幾何学的サンプリングを使用したり、ポリゴン上で繰り返し統合を行ったりすると、非常に遅すぎます。 もう 1 つの微妙な落とし穴は、浮動小数点領域の使用です。期待値の比率を比較するため、小さな精度誤差でも、選択された最適なポリゴンが変化する可能性があります。 

ポリゴンが非常に薄いシェルである場合、さらに特殊なケースが発生します。 たとえば、1 つのポリゴンが追加するエリアが非常に小さいものの、スコアが大きい場合、単純な浮動除算では候補が誤ってランク付けされる可能性があります。 

## アプローチ

 ポリゴンを固定すると$t$、領域をリングに分解することで、その内部に均一に投げられたダーツの予想スコアを計算できます。 それぞれのリング$j$の総面積内のその面積に比例して寄与します。$t$。 This leads to a clean expectation formula: the expected score is a weighted average of scores, where weights are area proportions of each ring inside the chosen polygon.

 固定の場合$t$、含まれるすべてのリングに対して線形時間でその期待値を計算できます。 全員のためにこれを行う$N$選択肢は$O(N^2)$解決。 これが機能するのは、候補ごとにリング寄与のプレフィックス合計を個別に再計算するためです。 

ボトルネックは明らかです。$N$大きいです、と言う$2 \cdot 10^5$、 それから$O(N^2)$操作は実行不可能です。 

重要な観察は、各候補の期待値が 2 つのプレフィックスの合計の比率として記述できることです。 具体的には、それぞれについて、$i$では、分子を累積された「スコア加重面積」、分母を総面積と定義します。 期待は次のようになります$E_i = \frac{\text{num}_i}{\text{den}_i}$。 

問題がプレフィックス間の比率の比較に帰着すると、次はそれらの間の最大の部分を見つけるだけで済みます。$N$候補者たち。 これは、浮動小数点を完全に回避して、クロス乗算を使用して線形時間で実行できます。

 ## アルゴリズムのチュートリアル

 ### 幾何学的な構成要素の計算

 1. 靴紐の公式を使用して、各多角形の 2 倍の符号付き面積を計算します。 比率のみが重要であるため、分数を避けるために面積を 2 倍のままにします。 これにより、すべてのジオメトリが整数のままになります。 
2. 連続する領域を減算して、各ポリゴンを「リング寄与」に変換します。 ポリゴンとの違い$j$そして$j-1$リングの面積を与えます$j$。 これが機能するのは、ポリゴンが厳密にネストされているため、重複の曖昧さが存在しないためです。 

### 期待コンポーネントの構築

 1. 2 つのプレフィックス アキュムレータを維持します。 1 つはリングまでの合計加重スコア領域を保存します$i$、その他の店舗のリングまでの総面積$i$。 分子は足すと大きくなります$R_j \cdot S_j$を加えると分母が大きくなりますが、$R_j$。 

この構造は、ポリゴン内に均一に着地する期待値を直接エンコードします。$i$、すべての点が一様に分布し、面積に基づいた比例確率に寄与するためです。 

### 最適な精度領域を見つける

 1. 各候補者について$i$、その期待値を分数として解釈します$\frac{\text{num}_i}{\text{den}_i}$。 交差乗算を使用して候補を比較します。$a > b$もし、そしてその場合に限り$\text{num}_a \cdot \text{den}_b > \text{num}_b \cdot \text{den}_a$。 これにより、浮動小数点が完全に回避されます。 
2. 最大の部分を生成するインデックスを追跡します。 

### 最終的な答えを計算しています

 1. 最高精度のポリゴンを一度作成する$i^*$が見つかったら、最終的な予想スコアを計算します。$$K \cdot E_{i^*} + (M-K) \cdot E_N$$それぞれの期待値は分数なので、次の逆モジュラーを使用して変換します。$10^9+7$。 

### なぜ効果があるのか

 核となる不変条件は、各ポリゴンが$i$は、互いに素なリングにわたる明確に定義された確率分布に対応し、期待値はこれらの素な寄与に対して線形です。 リングは空間を正確に分割するため、プレフィックス合計はポリゴン内のすべてのランダム性を完全に捕捉します。 したがって、すべての候補は単一の有理値に帰着し、期待値の最大化は、同一の累積構造から導出される部分の純粋な比較になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def inv(x):
    return pow(x, MOD - 2, MOD)

def shoelace(poly):
    n = len(poly)
    s = 0
    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]
        s += x1 * y2 - x2 * y1
    return abs(s)

def solve():
    N, M, K = map(int, input().split())
    S = [0] + list(map(int, input().split()))

    polys = []
    for _ in range(N):
        v = int(input())
        poly = [tuple(map(int, input().split())) for _ in range(v)]
        polys.append(poly)

    area2 = [0] * (N + 1)
    for i in range(1, N + 1):
        area2[i] = shoelace(polys[i - 1])

    R = [0] * (N + 1)
    for i in range(1, N + 1):
        R[i] = area2[i] - area2[i - 1]

    num = [0] * (N + 1)
    den = [0] * (N + 1)

    for i in range(1, N + 1):
        num[i] = num[i - 1] + R[i] * S[i]
        den[i] = den[i - 1] + R[i]

    best = 1
    for i in range(1, N + 1):
        if num[i] * den[best] > num[best] * den[i]:
            best = i

    numN, denN = num[N], den[N]
    numB, denB = num[best], den[best]

    ans = (K * numB % MOD) * inv(denB) % MOD
    ans = (ans + (M - K) * (numN % MOD) % MOD * inv(denN)) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```実装は、靴紐の公式を介して 2 倍のポリゴン領域を計算することから始まり、すべての幾何学的値が整数のままであることを確認します。 次に、連続するポリゴンを区別することによってこれらをリング領域に変換し、それぞれの互いに素な環状領域を分離します。 

プレフィックス合計は、各プレフィックス ポリゴンの予想スコアの分子と分母を維持するために構築されます。 これは、幾何学的期待を比率比較問題に変える重要な単純化です。 

最適なポリゴンの選択には 64 ビット整数の相互乗算が使用され、精度の問題が完全に回避されます。 最後に、モジュラー演算により、フェルマー逆関数を使用して期待値が再構築されます。

 ## 特殊なケース

 主なエッジ ケースは、ポリゴンが追加するリング領域が非常に小さいにもかかわらず、スコアが大きい場合です。 このような場合、浮動小数点実装では面積が過大評価され、スコアのスパイクが過小評価されることがよくあります。 ここでは、すべてが整数プレフィックスの合計によって計算され、相互乗算によって比較されるため、比率は正確で安定したままになります。 

もう 1 つの特殊なケースは、複数の候補者間で期待が同じであることです。 比較では厳密な大なりを使用するため、最初の最大値が保持されます。 すべての分数は正確に等しいため、どの選択も有効で一貫性があります。 

最後に、すべてのスコアが同一の場合、すべてのプレフィックス比は同じ値に縮小します。 このアルゴリズムは、面積に比例する等しい分子と分母を正しく計算し、等価性を正確に保ちます。
