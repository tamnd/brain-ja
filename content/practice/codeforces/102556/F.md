 ## 解決策
 ## 問題の理解

 同じ年に生まれたすべてのユーザーは自動的に同じ年齢になるため、各ユーザーは誕生年で表すことができます。 唯一の追加の接続は、「早い年」の誕生日、つまり 1 月 1 日から 2 月 28 日までの日付から得られます。`y`年を結びます`y`年付き`y-1`。 

これらの接続の推移閉包によって、最終的な年齢グループが定義されます。 Riana は、新規ユーザーをできるだけ少なく追加した後、すべての既存ユーザーと自分自身を 1 つの年齢グループに所属させたいと考えています。 

入力には、既存のユーザーと Riana の登録された誕生日が含まれます。 出力では、接続された年齢グループを作成する追加の誕生日の最小数と、追加する有効な誕生日が続いて求められます。 

まで`100000`ユーザーにとって、すべてのペアをチェックすることは不可能です。 二次解のパフォーマンスは約`10^10`限界をはるかに超えた比較。 便利な構造は、年が線を形成するため、問題はパス上の欠落しているエッジを接続することになります。 

よくある間違いは、正確な誕生日を比較することです。 ルールは、年のグループと早い年のつながりのみに依存します。 もう一つの間違いは、リアナ自身を忘れてしまうことです。 彼女が既存のチャット メンバーに含まれていない場合でも、彼女の年を含める必要があります。 

## アプローチ

 直接的なアプローチでは、すべてのユーザー間にグラフを作成し、2 人のユーザーが同じ年齢であるとみなされるたびにエッジを追加し、グラフがつながるまでユーザーを繰り返し追加します。 年齢の定義はこれらのルールに基づく接続性そのものであるため、これは正しいです。 ただし、すべてのペアを比較するのはコストがかかりすぎるため、グラフに含まれる可能性があります。`100001`頂点。 

重要な観察は、すべてのユーザーの年が数直線上のノードであるということです。 一年で早い誕生日`y`間のエッジのみを作成します`y`そして`y-1`。 どの隣接する年のエッジが既に存在するかを知る必要があるだけです。 

関連する最小および最大の年が`L`そして`R`、間のすべての欠落エッジ`y-1`そして`y`この間隔内で作成する必要があります。 年に早い年ユーザーを追加する`y`まさにそのエッジを生み出す操作です。 追加された各ユーザーが作成できる隣接年の接続は 1 つだけであるため、エッジの欠落は避けられません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(N²) | O(N²) | 遅すぎる |
 | 最適 | O(N + 年の範囲) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. Riana の誕生日と既存のすべての誕生日を解析します。 表示された年を保存し、少なくとも 1 つの早い年の誕生日を含むすべての年にマークを付けます。 
2. 関連する年にリアナの誕生年を含めます。 最終的な年齢グループには彼女も含まれている必要があります。 
3. 関連する最小年と最大年を見つけます。 必要なすべてのつながりは、この 2 年間の間にあります。 
4. 毎年`y`から`min_year + 1`に`max_year`、年に生まれた早い年のユーザーがすでに存在するかどうかを確認します`y`。 そうでない場合は、その年の 1 月 1 日に生まれた新しいユーザーを追加します`y`。 
5. 追加されたすべての誕生日を出力します。 

機能する理由: 年齢グラフは長年にわたる軌跡です。 可能なエッジは連続する年の間のみです。 既存の高速ユーザーは、これらの利点の一部を提供します。 エッジが欠落しているとパスが 2 つの切断された部分に分割されるため、少なくとも 1 人の新しいユーザーがエッジを追加する必要があります。 このアルゴリズムは、欠落しているエッジごとに 1 人のユーザーを正確に追加します。これは十分かつ必要です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def parse_date(s):
    y, m, d = map(int, s.split("-"))
    return y, m, d

def format_date(y, m=1, d=1):
    if y < 10000:
        return f"{y:04d}-{m:02d}-{d:02d}"
    return f"{y:05d}-{m:02d}-{d:02d}"

def solve():
    n = int(input())
    ry, rm, rd = parse_date(input().strip())

    years = {ry}
    fast = set()

    for _ in range(n):
        y, m, d = parse_date(input().strip())
        years.add(y)
        if m == 1 or (m == 2 and d <= 28):
            fast.add(y)

    lo = min(years)
    hi = max(years)

    ans = []
    for y in range(lo + 1, hi + 1):
        if y not in fast:
            ans.append(format_date(y))

    print(len(ans))
    for x in ans:
        print(x)

if __name__ == "__main__":
    solve()
```パーサーは、年の正確な書式幅を無視します。`-`数値の年を直接与えます。 早い年の条件は、1 月と 2 月 28 日以前についてのみチェックされます。 

ループは次から始まります`lo + 1`年の早いユーザーなので`y`接続します`y`に`y - 1`。 から始まる`lo`必要な間隔を超えて不要な接続が作成される可能性があります。 1 月 1 日は常に有効な早年の日付であるため、1 月 1 日を使用すると便利です。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(N + Y) |`N`誕生日が読まれたり、`Y`は最小年と最大年の間の距離です |
 | スペース | O(N) | セットには、関連する年と既存の早い年の接続が保存されます。 

年の範囲は最大でも`99999 - 1000`なので、リニアスキャンは小さいです。 このソリューションは制約に簡単に適合します。
