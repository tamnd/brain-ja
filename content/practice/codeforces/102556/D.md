 ## 解決策
 ## 問題の理解

 選択した割合を`i`-人目は`P_i`、間の分数として書かれます。`0`そして`1`。 

いつ人`i`ターンが経過すると、2 つのことが起こります。 彼らは取る`P_i`手つかずのパイの一部も奪われる`P_i`以前の人がすでに所有していたすべてのスライスの。 すべての人がプレイした後は、パイの触れられていない部分はゼロでなければならず、最終的なスライスのサイズはできるだけ同じになるようにしたいと考えています。 

入力には人数のみが含まれます。 出力は、各人が順番に選択したパーセンテージです。 

唯一の制約は、`N ≤ 1000`、したがって、`O(N^2)`シミュレーションは簡単に適合します。 課題は効率ではなく、プロセスの数学的構造を発見することです。 

最初の明白ではないエッジケースは次のとおりです。`N = 1`。 唯一の有効な答えは、`100%`そうしないと、食べられないパイが残るからです。 

2 番目の微妙なケースは、最後の人に選択をさせることです。`100%`は必要ありません。 たとえば、`N = 2`、選択する`100%, 50%`最初のプレイヤーがすでにすべてのパイを消費しているため、手つかずのパイは残りません。 常に最後のプレイヤーにすべてを奪わせるような貪欲な戦略は、最適な配分を逃します。 

最後の罠は、プレイヤーが選択したパーセンテージと最終的に所有するパーセンテージを混同することです。 後のプレーヤーは前のプレーヤーから繰り返し盗むため、選択されたパーセンテージと最終的なシェアは異なります。 

## アプローチ

 直接シミュレーションでは、すべてのプレーヤーの現在のスライスが保持されます。 新しいプレイヤーが到着するたびに、以前のすべてのスライスに次の値が乗算されます。`(1 - P_i)`、新しいプレーヤーはそれらのスライスから削除されたすべてのものを受け取ります。`P_i`触れられていないパイの と、触れられていないパイにも が乗算されます。`(1 - P_i)`。 これはゲームを忠実にモデル化していますが、パーセンテージを選択する方法は教えてくれません。 

重要な観察は、プレイヤーが手つかずのパイと盗みから得る利益は常に同じ値になるということです。 

人の前の未処理の端数を仮定します`i`は`R`。 以前のプレイヤーがすでに所有していた合計金額は、`1 - R`。 新規プレイヤーが受け取るのは、`P_i · R + P_i · (1 - R) = P_i`。 

したがって、自分のターンの直後、プレイヤーは`i`常に正確に所有します`P_i`オリジナルのパイの。 

その後、後続のプレイヤーはそのスライスを単純にスケールします。`(1 - P_j)`。 したがって、最終的なシェアは次のようになります。$$F_i=P_i\prod_{j=i+1}^{N}(1-P_j).$$ここで定義します$$S_i=\prod_{j=i}^{N}(1-P_j),$$人の直前の変更されていない部分`i`。 

それから$$F_i=S_{i+1}-S_i.$$残ったパイは、`S_1`、食べ残しがないという要件は、`S_1=0`。 また`S_{N+1}=1`。 

最終的な株式の合計は次のようになりますので、`1`、すべての最終シェアが正確に一致する場合、最大シェアと最小シェアの間の可能な限り最小の差が達成されます。`1/N`。 

設定間隔`F_i=1/N`与える$$S_i=\frac{i-1}{N}.$$パーセンテージを回復すると、$$P_i=\frac{S_{i+1}-S_i}{S_{i+1}}.$$のために`i=1`、$$P_1=1.$$あらゆる人にとって`i≥2`、$$P_i=\frac{1/N}{i/N}=\frac1i.$$したがって、答えは驚くほど簡単です。

 ## アルゴリズムのチュートリアル

 1.読む`N`。 
2. 印刷`100.0`初めての人のために。 これにより、手付かずのパイが即座にゼロになり、残らない条件が満たされることが保証されます。 
3. すべての人に`i`から`2`に`N`、印刷`100 / i`。 これはまさに導出された式から得られた値です`P_i = 1/i`。 

この導出により、すべてのプレイヤーの最終的な取り分が正確になることが保証されます。`1/N`、すべての株式の合計が 1 になるため、これが可能な限り最良の方法です。 

### なぜ効果があるのか

 不変条件はそのプレイヤーです`i`正確に所有しています`P_i`自分のターン終了直後。 その後のターンでは、既存のすべてのスライスに同じ係数を単純に乗算します。 これにより式が得られます$$F_i=P_i\prod_{j>i}(1-P_j).$$接尾辞の積を次のように書くと、`S_i`式を次のように変換します$$F_i=S_{i+1}-S_i.$$最終シェアが等しいと、すべてのものが一意に決定されます。`S_i`、およびそれらの接尾辞積はすべてのパーセンテージを一意に決定します。 均等な配分により最大値と最小値が同一になるため、これより良い配分は存在しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    print(f"{100.0:.10f}")
    for i in range(2, n + 1):
        print(f"{100.0 / i:.10f}")

if __name__ == "__main__":
    solve()
```プログラムは、クローズドフォームの回答を直接出力します。 最初の値は常に`100%`。 それ以降のすべての値は単純に`100/i`。 数学的導出により独自の最適解がすでに特徴付けられているため、シミュレーションは必要ありません。 

ここでは浮動小数点精度で十分です。 必要なエラーは`1e-4`一方で、小数点以下 10 桁を印刷すると、累積誤差が何桁も小さくなります。

## テストケース```python
import io
import sys

def solve():
    input = sys.stdin.readline
    n = int(input())
    print(f"{100.0:.10f}")
    for i in range(2, n + 1):
        print(f"{100.0 / i:.10f}")

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    solve()
    sys.stdin = backup_stdin
    sys.stdout = backup_stdout
    return out.getvalue()

assert run("1\n") == "100.0000000000\n"

assert run("2\n") == (
    "100.0000000000\n"
    "50.0000000000\n"
)

assert run("3\n") == (
    "100.0000000000\n"
    "50.0000000000\n"
    "33.3333333333\n"
)

out = run("1000\n").splitlines()
assert len(out) == 1000
assert abs(float(out[-1]) - 0.1) < 1e-9
```| テスト入力 | 期待される出力 | 検証内容 |

 ## 特殊なケース

 いつ`N = 1`、アルゴリズムは印刷のみを行います`100`。 手つかずのパイはすぐにゼロになり、唯一のプレイヤーがパイ全体を所有します。 両方の要件が満たされています。 

いつ`N = 2`、アルゴリズムは出力します`100`そして`50`。 最初のプレイヤーは最初にパイ全体を所有します。 2 番目のプレーヤーがその半分を盗み、両方のプレーヤーにちょうど残ります。`50%`。 これは、最後のプレイヤーではなく最初のプレイヤーが選択しなければならないことを示しています。`100%`。 

より大きな値の場合、`N = 3`、アルゴリズムは出力します`100`、`50`、 そして`33.333...`。 結果として得られる最終的なシェアはすべて正確に`1/3`, この構築により、すべてのプレイヤーの最終的な所有権が平等になり、なおかつ手つかずのパイが残らないことが確認されました。
