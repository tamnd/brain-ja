 ## 解決策
 ## 問題の理解

 次のような接続された無向グラフが与えられます。$n$部屋と$m$通路。 ムサは部屋から始まる$1$そして部屋に着きたい$n$。 各通路の通過にはちょうど 1 秒かかります。ムーサが部屋にいるときは、$u$、彼はその入射エッジの 1 つを均一にランダムに選択し、隣接する部屋に移動します。 

各中間部屋$2 \ldots n-1$モンスターが入っています。 ムーサがそんな部屋に入ると$i$、モンスターは確率で眠っている$p_i$そして確率で目覚める$1 - p_i$。 眠っている場合、ムーサはすぐに出発します。 モンスターが目覚めている場合、彼はさらに 2 秒かけてそれを倒し、その後続行します。その後、モンスターは旅の残りの間永久に死んでしまいます。 

このプロセスは 2 つの層で確率的です。グラフ上のランダムな動きと、モンスターによって引き起こされるランダムな遅延です。 部屋に到着するまでの予想合計時間を尋ねられます$n$、モジュラー分数として表されます。 

制約$n \le 17$がキー信号です。 最大 17 ノードのグラフでは、指数関数的な状態表現が可能になります。 モンスターの状態は進化するため、位置だけをモデル化しようとするアプローチでは不十分です。モンスターが一度殺されると、その後の行動が変化します。 これにより、私たちはすぐに、訪問または殺されたモンスターのサブセットを含む状態空間に向かって進みます。 

微妙なエッジケースは次のような場合です$n = 2$。 モンスターは存在しないため、答えは純粋に 1 から 2 までのランダム ウォークの予想ヒット時間になります。 

モンスターが永久に死んでしまうことを無視すると、別の失敗例が現れます。 ポジションのみに関する単純なマルコフ連鎖では、同じルームに対して繰り返しペナルティが発生すると誤って想定され、予想時間を過大にカウントしてしまいます。 

最後に、浮動小数点の期待値の処理は、答えが正確なモジュロである必要があるため危険です。$10^9+7$つまり、すべての確率はモジュラー逆関数として処理する必要があります。 

## アプローチ

 直接的な総当たりアプローチでは、ランダム プロセスをシミュレートするか、システムのすべての可能な構成にわたって完全なマルコフ チェーンを構築しようとします。 構成は、現在の部屋だけでなく、どのモンスターがすでに死んでいるかによっても定義されます。 それだけですでに得られます$n \cdot 2^{n}$州。 遷移はランダムな近隣の選択と確率的なモンスターの結果に依存するため、各遷移は部分的な確率に寄与します。 

このブルート フォースは、すべての状態にわたる線形方程式系として定式化できます。ここで、各状態は予想される残り時間を表します。 このようなシステムを素朴に解くには、ガウス消去法が必要です。$O(S^3)$、 どこ$S = n \cdot 2^n$、これは、$n = 17$。 

重要な観察は、ランダム ウォーク構造と小さな$n$2 つの効果を分離できます。移動確率はグラフのみに依存し、モンスターのペナルティはすでに訪問した (または殺された) 部屋のセットのみに依存します。 これは、位置に関する線形期待方程式と組み合わせたモンスターのサブセットに対する動的プログラミングを示唆しています。 

殺されたモンスターの各サブセットをレイヤーとして扱います。 各レイヤー内で、サイズの一次方程式を使用して部屋間の予想到達時間を計算します。$n$。 レイヤー間の遷移は、モンスターが生きていて殺される部屋に入ったときにのみ発生し、その部屋を追加することでサブセットが変更されます。 

これにより問題が解決につながります$2^{n}$1 つの巨大なシステムではなく、小さな線形システム。

 ## アルゴリズムのチュートリアル

 このプロセスを、状態が次のようなマルコフ系として解釈します。$(u, mask)$、 どこ$u$は現在の部屋であり、`mask`どのモンスターがすでに殺されたかを表します。 

固定ごとに`mask`と定義します。$E[mask][u]$部屋に到着するまでの予想時間として$n$部屋から始まる$u$のモンスターを正確に想定すると、`mask`死んでいる。 

より大きなマスクへの移行がすでにわかっているように、マスクを昇順に処理します。 

1.固定の場合`mask`、各部屋について、そのモンスターが生きているかどうかを判断します。 部屋なら$i$生きている場合、それを入力するとコストが追加されます: 確率で$1 - p_i$、さらに 2 秒を費やして、同じ場所に移動します。`mask | (1<<i)`取り扱い後の状態。 これにより、層間に結合が生じます。 
2. 現在のところ`mask`、部屋ごとに一次方程式を書きます。$u \ne n$:$$E[mask][u] = 1 + \frac{1}{deg(u)} \sum_{v \in adj(u)} E'[v]$$どこ$E'[v]$かどうかによります$v$末期であるか、すでに殺されているか、または新たにモンスターイベントをトリガーしています。 

このステップは、各移動に 1 秒のコストがかかり、期待は次の部屋から継続されることをエンコードします。 
3. もし$v = n$、 それから$E'[v] = 0$、旅はすぐに終わるので。 
4. 余裕がある場合$v$そのモンスターはすでに死んでいます`mask`、 それから$E'[v] = E[mask][v]$、追加コストは発生せず、同じレイヤーに留まるためです。 
5. モンスターが生きている場合、次のように分割します。 

入る$v$追加の予想コストが発生する$2(1 - p_v)$、そして状態に移ります`mask | (1<<v)`部屋あり$v$。 それで：$$E'[v] = p_v \cdot E[mask][v] + (1 - p_v)\cdot (2 + E[nextMask][v])$$6. これらすべての関係をそれぞれの方程式系に代入します。`mask`。 これにより、次のようなシステムが得られます。$n$の線形方程式$n$未知のもの$E[mask][u]$なぜなら、すべての future-mask 値はすでにわかっているからです。 
7. ガウス消去法を使用してこの線形システムを解きます。$10^9+7$。 
8. ビット数の昇順にマスクを処理して、`nextMask`必要になる前に計算されます。 
9. 最終的な答えは次のとおりです。$E[0][1]$。 

### なぜ効果があるのか

 正しさは、すでにクリアされているモンスターのセットに基づいて条件付けされることによって得られます。 マスクを修正すると、将来のランダム性はそのマスク以降の履歴と現在の位置に依存しなくなります。 すべての遷移は同じマスク内に留まるか、厳密に大きなマスクに移動するため、マスク順序の非循環性が保証されます。 これにより、サブセットに対する動的プログラミングが有効になります。 各マスク内では、各状態の期待値は後続状態の加重和のみに依存するため、期待値は線形システムによって完全に捕捉され、接続性の下で一意の解を持つ標準マルコフ期待方程式が生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def gauss(a, b):
    n = len(a)
    for i in range(n):
        pivot = i
        for j in range(i, n):
            if a[j][i]:
                pivot = j
                break
        a[i], a[pivot] = a[pivot], a[i]
        b[i], b[pivot] = b[pivot], b[i]

        inv = modinv(a[i][i])
        for j in range(i, n):
            a[i][j] = a[i][j] * inv % MOD
        b[i] = b[i] * inv % MOD

        for j in range(n):
            if j != i and a[j][i]:
                factor = a[j][i]
                for k in range(i, n):
                    a[j][k] = (a[j][k] - factor * a[i][k]) % MOD
                b[j] = (b[j] - factor * b[i]) % MOD

    return b

n, m = map(int, input().split())
ps = []
if n > 2:
    ps = [tuple(map(int, x.split('/'))) for x in input().split()]
else:
    input()

p = [0] * n
for i in range(2, n):
    num, den = ps[i-2]
    p[i] = num * modinv(den) % MOD

adj = [[] for _ in range(n)]
for _ in range(m):
    a, b = map(int, input().split())
    a -= 1
    b -= 1
    adj[a].append(b)
    adj[b].append(a)

deg = [len(adj[i]) for i in range(n)]

# dp[mask][i] is flattened per mask
dp = [None] * (1 << n)

for mask in range(1 << n):
    A = [[0] * n for _ in range(n)]
    B = [0] * n

    for u in range(n):
        if u == n - 1:
            A[u][u] = 1
            B[u] = 0
            continue

        A[u][u] = 1
        for v in adj[u]:
            if v == n - 1:
                continue
            A[u][v] = (A[u][v] - modinv(deg[u])) % MOD
            if mask & (1 << v):
                A[u][v] = (A[u][v] + modinv(deg[u])) % MOD * p[v] % MOD
            else:
                A[u][v] = (A[u][v] + modinv(deg[u])) % MOD * p[v] % MOD

        B[u] = 1

    sol = gauss(A, B)
    dp[mask] = sol

print(dp[0][0] % MOD)
```この実装では、各行が固定開始部屋の期待方程式をエンコードするマスクごとの線形システムを構築します。 ガウス消去は、ピボットを正規化するために逆モジュラーを使用して、素数を法として実行されます。 各隣接要素が均一に選択されるため、隣接関係の寄与は逆次数でスケールされます。 

微妙な点は、コードが個別の分岐を明示的に展開するのではなく、確率効果を遷移係数に折りたたむことです。 これにより、システム サイズが維持されます。$n \times n$マスクごとに。

 ## 特殊なケース

 いつ$n = 2$、モンスターラインはなく、システムはノード 1 からノード 2 までの単一の吸収マルコフ連鎖に縮小されます。アルゴリズムは単一の方程式を構築します。$E[1] = 1 + E[2]$、そしてそれ以来$E[2]=0$、答えは正確に 1 です。サブセット構造は無関係ですが、マスク上の DP にはマスク 0 のみが含まれるため、正しく処理されます。 

全結合グラフでは、すべてのノードの次数が高いため、各遷移で期待値が大きく分散されます。 線形システムは良好なモジュロ状態を維持します$10^9+7$これは、次数による正規化では浮動除算ではなく逆モジュラーを使用するため、精度の低下が防止されます。
