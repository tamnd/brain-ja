 ## 解決策
 ## 問題の理解

 頂点によって反時計回りの順序で記述された単純な多角形が与えられます。 ポリゴンは非縮退であるため、エッジは端点でのみ交わっており、連続する 3 つの頂点は同一線上になく、適切な閉じた形状を形成します。 

この多角形の境界内で、エッジの 1 つにある点を考慮します。 このような点 P から、線分 PQ が完全に多角形の内側または境界上に留まり、P と Q でのみ接触するような、多角形の境界上に他の点 Q が存在するかどうかを尋ねます。言い換えれば、それらの間の直線セグメントが外部を通過しない、または多角形の内部を通過しない場合、P は Q を「見る」ことができます。 

ポリゴン境界上のどこにもそのような目に見える Q がない場合、点 P は死角と呼ばれます。 このようなすべての盲点のセットが有限である場合、ポリゴンは「要塞」とみなされます。 ポリゴンごとに、この条件が当てはまるかどうかを判断する必要があります。 

重要な問題は、定義が連続的であることです。P と Q の範囲は、エッジに沿った無限の多くの点に及びます。 したがって、頂点上の離散的な可視性グラフを扱うのではなく、境界に沿った完全な幾何学的可視性を扱います。 

制約は大きく、テスト ケースごとに最大 10^5 頂点、すべてのテストで合計 2 × 10^5 です。 これにより、エッジ上の任意の点のペアを推論したり、可視性を継続的にシミュレートしたりするアプローチが除外されます。 ポリゴンごとに 2 次または 2 次に近いものは不可能です。 

微妙なエッジ ケースは、エッジに沿って局所的に「反射のような」構造を持つポリゴンで、孤立点ではなくエッジ間隔全体の可視性が崩れます。 たとえば、ポリゴンが、あるエッジ セグメントのすべての内部点の可視性を妨げる長い「廊下」形状をしている場合、死角が連続した間隔を形成し、答えは直ちに NO になります。 

もう 1 つの例外的なケースは、凸多角形です。 凸多角形では、すべての境界点から他のすべての境界点が見えるため、死角はまったくありません。 答えは言うまでもなく「YES」です。 

本当の課題は、死角がエッジに沿って連続セットを形成するときと、有限個の幾何学的縮退だけによって死角が孤立するときを認識することです。 

## アプローチ

 直接のブルートフォース解釈では、各エッジ上の点 P を選択し、セグメント PQ がポリゴン内部を横切らないようにすべての Q を決定しようとします。 P と Q は連続的に変化するため、エッジのすべてのペアを考慮し、代表的なサンプル間の可視性をチェックすることで離散化できます。 頂点に限定したとしても、すべてのペア間の可視性のチェックは O(n^2) であり、これは問題の連続的な性質を無視しているため、正しくありません。 

2 つの境界点の間の可視性はセグメントがポリゴン エッジと交差するかどうかによって決まるため、総当たりのアイデアは概念的に機能します。 しかし、欠点は、有限個のサンプル点によって盲点が決定されないことです。 エッジに沿った間隔全体をブロックまたはブロック解除できるため、サンプリング頂点の構造が失われます。 

重要な観察は、境界点に可視方向があるかどうかは、ポリゴン境界の局所的な角度構造にのみ依存するということです。 境界を横切るとき、可視性は組み合わせイベントの場合にのみ変化します。サポート ラインがポリゴンに接するか、エッジの延長線と一致する場合です。 これらのイベントは、凸包構造と相互作用するエッジに対応します。

これは核となる単純化につながります。多角形は有向セグメントのチェーンのように動作し、その点から多角形から出る支持線がない方向が存在する場合に、まさに死角が発生します。 これにより、連続問題はポリゴンの形状の全体的な幾何学的特性のチェックに分解されます。これは、すべてのエッジが少なくとも 1 方向で「無限遠から見える」かどうかのみに依存することがわかります。これは、連続的なブロック間隔を作成する特定のフラット反射構成を含まないポリゴンと同等です。 

最終的な結果は、ポリゴンに少なくとも 1 組のエッジがあり、そのサポート ラインが境界周囲の完全な方向性を定義しているかどうかをチェックすることになります。 これは、エッジの外向き法線のセットが方向の覆われていない円弧を残さずに完全な円をカバーしていることを検証することと同等であり、これはすべてのエッジ方向が何らかの閉じた半平面内にあるかどうかをチェックすることに帰着します。 そうした場合、ポリゴンは可視性の点で退化し、無数の盲点が作成されます。 そうしないと、死角が孤立して有限になってしまいます。 

したがって、タスクはエッジ ベクトルに対する方向の凸包スタイル チェックになります。

 ## アルゴリズムのチュートリアル

 各ポリゴンのエッジを方向ベクトルに変換します。 頂点 i から i+1 までの各エッジは、ベクトル vi = (x_{i+1} − x_i, y_{i+1} − y_i) に寄与します。 

次に、これらのベクトルの角度分布を分析します。 

1. ポリゴンの周りのすべてのエッジ方向ベクトルを順番に計算します。 これらは、可視性制約が光線を「ブロック」できるすべての可能な境界方向を表します。 
2. 各ベクトルが [0, 2π) の角度に対応するように、通常は atan2 を使用して各方向を角度で正規化します。 
3. これらの角度を並べ替えます。 
4. 各角度に 2π を加算して追加することにより、ソートされたリストを複製し、円形のラップアラウンドをシミュレートします。 
5. この 2 倍の配列上でウィンドウをスライドさせて、連続する方向間の最大角度ギャップを見つけます。 
6. 厳密に π より大きいギャップが存在する場合、すべての方向が開いた半円の内側に位置します。これは、連続的に視界を遮る支持半平面が存在し、無限に多くの盲点が作成されることを意味します。 この場合はNOを出力します。 
7. それ以外の場合は、YES を出力します。 

直観的には、多角形のエッジ方向が半円に制限されていない場合、多角形には有限個のブラインド境界点しか存在しないことが分かります。 それらが制限されている場合、ポリゴンが決して「見えない」グローバル方向が存在し、エッジ間隔全体が連続的に見えなくなります。 

### なぜ効果があるのか

 死角は、境界点からのすべての可視光線が方向の単一の半平面内に位置するエッジによって妨げられる方向が存在する場合にのみ、連続セットを形成します。 これは、すべてのエッジ方向が半円内に収まる場合に正確に発生します。その場合、ポリゴン境界の周りの可視性の伝播をブロックする補助線の方向が存在するためです。 エッジの方向が半円を超えて広がっている場合、可視方向は必然的にポリゴンを「包み込み」、非可視ポイントは間隔ではなく離散的な接線によって決定される孤立したイベントになるため、有限になります。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        pts = [tuple(map(int, input().split())) for _ in range(n)]
        
        ang = []
        for i in range(n):
            x1, y1 = pts[i]
            x2, y2 = pts[(i + 1) % n]
            dx = x2 - x1
            dy = y2 - y1
            ang.append(math.atan2(dy, dx))
        
        ang.sort()
        
        # duplicate for circular sweep
        m = len(ang)
        ang += [a + 2 * math.pi for a in ang]
        
        max_gap = 0.0
        for i in range(m):
            max_gap = max(max_gap, ang[i + 1] - ang[i])
        
        # check wrap gap too
        for i in range(m, 2 * m - 1):
            max_gap = max(max_gap, ang[i + 1] - ang[i])
        
        # if all directions fit in a semicircle, max gap > pi
        if max_gap > math.pi + 1e-12:
            print("NO")
        else:
            print("YES")

if __name__ == "__main__":
    solve()
```コードは、各ポリゴンを読み取り、エッジ方向ベクトルを構築することから始まります。 各ベクトルは atan2 を使用して角度に変換されます。これにより、すべての象限が正しく処理され、手動による符号の処理が回避されます。 

角度を並べ替えた後、ラップアラウンド ギャップが均一に処理されるように、複製ステップで円形表現が作成されます。 連続する角度間の最大ギャップは、エッジ方向のない最大の空の角度セクターを表します。 

この空のセクターが π を超える場合、すべての方向が半円内に含まれ、無限に多くの死角につながる病的な可視性のケースが引き起こされます。 それ以外の場合は、視界が十分に広がり、死角が連続的な間隔を形成できないため、ポリゴンは要塞として適格となります。 

比較のイプシロンは、atan2 からの浮動小数点精度を処理します。

 ### 例 1

 正方形を考えてみましょう。 

| ステップ | 角度 | 最大ギャップ |

 すべてのギャップは等しく、π より小さいため、出力は YES になります。 

これは、凸多角形には連続したブラインド領域がないという直観と一致します。 

### 例 2

 すべてのエッジがほぼ半平面内を向いている、縮退した細長い形状を考えてみましょう。 

| ステップ | 角度 | 最大ギャップ |
 | --- | --- | --- |
 | エッジの方向 | [0, 2π/3] にクラスター化 | |
 | 並べ替え済み | クラスター化された | |
 | 最大ギャップ | > π | > π |

 ここでは、エッジがまったくない方向範囲が存在し、方向が欠けている完全な半平面を意味します。 これにより、エッジの一部に沿って視界が継続的に遮断され、無限に多くの死角が生じるため、出力は NO になります。

 ## 特殊なケース

 三角形には正確に 3 つのエッジ方向があります。 角度の広がりは常に半円の制約を超えるため、最大ギャップは常に π より小さくなり、YES が生成されます。 アルゴリズムは単純に等間隔の角度を確認し、すぐに YES を返します。 

完全に凸の正方形は、均一な角度間隔を保ちます。 π を超えるギャップはなく、凸多角形が常に受け入れられることが確認されます。 

小さな摂動を除いて、エッジがほぼすべて平行である多角形は、故障モードを示しています。 角度が密集して、π を超える単一の大きなギャップを生成します。 エッジの方向が半平面に限定され、境界エッジに沿った連続したブラインド インターバルに対応するため、アルゴリズムは NO を正しく識別します。
