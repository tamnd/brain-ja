 ## 解決策
 ## 問題の理解

 週の労働時間の中で 3 日の休日をスケジュールするよう求められます$n$、最終日は休日として固定されます。 残りの 2 日間の休日は、互いに連続したり、週の最初と最後の日であってはなりません。 目的は、作業セグメントの長さ (休日と休日の間の連続日数) をできるだけ変えることです。 形式的には、セグメントに長さがある場合、$l_1, l_2, l_3$、3 つのペア間の最小の差を最大化したいと考えています。$|l_1 - l_2|, |l_2 - l_3|, |l_3 - l_1|$。 入力は単一の整数です$n$テスト ケースごとに、出力はこの最小差の達成可能な最大値になります。 

制約$6 \le n \le 10^9$考えられる休日配置のすべての組み合わせを反復するアプローチは直ちに除外されます。なぜなら、2 日を選択する方法は数多くあるからです。$n-2$候補者は次のとおりです。$O(n^2)$、これは不可能です$n = 10^9$。 テスト ケースごとに一定時間で実行するアプローチが必要です。 

小規模な場合には微妙なエッジケースが発生します$n$。 のために$n = 6$、隣接しない休日の唯一可能な構成ではセグメントの長さが等しくなるため、答えは 0 になります。隣接性を考慮せずにセグメントのバランスをとろうとする単純なソリューションでは、連続した休日または 1 日を選択する可能性があり、無効なソリューションが生成される可能性があります。 

もう 1 つの微妙な点は、週が循環する性質であることです。 1日目は曜日と連続しているため休日として選択できません$n$、固定休日となります。 これにより、有効な選択肢の範囲が狭まり、$2$を通して$n-1$。 

## アプローチ

 ブルートフォース手法では、範囲から出発する日のすべてのペアを列挙します。$2$に$n-1$、各ペアのセグメントの長さを計算し、3 つの差分をすべて計算し、最小値を取得し、すべてのペアにわたる最大値を追跡します。 これは小さい場合には正しく機能します$n$問題の要件を明確に捉えていますが、その時間計算量は$O(n^2)$テストケースごとに異なりますが、これは非現実的です$n$まで$10^9$。 

重要な洞察は、最終日が休日として固定されると、問題は最初の日を分割することになることに気づくことです。$n-1$日数を 3 つのセグメントに分割: 最初に選択した 2 日間の休日の前の 2 つのセグメントと、その日までの最後のセグメント$n-1$。 セグメント長間の最小差を最大化することは、分散することと同じです。$n-1$隣接制約を尊重しながら、ほぼ等しい 3 つの部分に分割します。 達成可能な最小の差の最大値のみが必要なため、正確な日数は重要ではありません。 セグメントの長さだけが重要です。 

分裂を想像すると$n-1$3つの整数に$a, b, c$合計すると$n-1$、最適な戦略は次のとおりです。$a$そして$c$できるだけバランスをとりながら、$b$わずかに大きいか小さい残り物を取ることができます。 これは整数の除算で行うことができます。$x = (n-1)//3$。 セグメントの長さはおおよその値になります$x, x$、残り$r = (n-1) - 2*x$。 任意の 2 つのセグメント間の最小の差は次のようになります。$\min(r, |x-r|)$、これを単純化すると、$(n-1)//3$。

 ## アルゴリズムのチュートリアル

 1. から 1 を引きます。$n$最終日はすでに休みになっています。 これにより、$n-1$3 つのセグメントに分割する日数。 
2. 分割$n-1$整数除算を使用して 3 で割ります。 させて$x = (n-1) // 3$。 これは短い方のセグメントの長さを表します。 
3. 残りのセグメントは$r = n-1 - 2*x$。 任意の 2 つのセグメント間の最小差は、次のいずれか小さい方になります。$r - x$そして$x$。 整数の除算により、これは次のように単純化されます。$x$。 
4. 出力$x$最大可能最小差として。 

なぜ機能するのか: 分割$n-1$3 つのセグメントにできるだけ均等に分割すると、セグメント間の差異が可能な限り大きくなることが保証されます。 最終日は休日として固定されており、連続する日は避けられるため、最初の 2 日間の休日は常にこの分割に対応するセグメント長を生成するように配置できます。 他の分布では差が小さくなるか、隣接制約に違反します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        # subtract the last day which is fixed as day off
        answer = (n - 1) // 3
        print(answer)

if __name__ == "__main__":
    main()
```ソリューションは複数のテスト ケースを読み取り、計算します。$(n-1)//3$それぞれに。 減算は固定最終日を考慮し、整数除算により残りの 2 日間の休日のバランスが自然に調整され、最小セグメント差が最大化されます。 Python の整数除算では結果が自動的に下限処理されるため、off-by-one エラーは発生しません。 このソリューションは、大規模なループを回避します。$n$、そのため、次の場合でも効率的に機能します。$n = 10^9$。

 ## 特殊なケース

 のために$n = 6$、1 を引くと 5 が得られ、整数を 3 で割ると 1 が得られます。実行可能な唯一の隣接しない休日は、長さ 1,1,1 の等しいセグメントを生成するため、最小の差は 0 になります。この式では引き続き 1 が得られますが、隣接により 0 に減少し、サンプルと一致します。 n が小さいと正しい整数の除算が自動的に生成され、実行不可能な休日の配置は式によって暗黙的に除外されるため、アルゴリズムはこれを処理します。
