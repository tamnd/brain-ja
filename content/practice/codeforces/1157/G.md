 ## 問題の理解

 私たちに与えられているのは、$n \times m$0 と 1 だけを含む行列。 任意の行と任意の列を何度でも反転できます。 反転とは、その行または列のすべての値を反対の値に置き換えることを意味します。 

選択したすべての反転が適用された後、行列は行優先の順序で読み取られます。 最初の行が最初に来て、次に 2 行目というように続きます。 結果のシーケンスは非減少でなければなりません。 すべての値はいずれかであるため、$0$または$1$、非減少行優先シーケンスは、すべての 0 がすべての 1 の前に現れることを意味します。 

タスクは、変換された行列を出力することではありません。 代わりに、どの行とどの列が反転されたかを出力する必要があります。 反転を選択しても行列をソートできない場合は、次のように出力します。`NO`。 

制約は、一方の次元では驚くほど小さいですが、もう一方の次元ではかなり大きくなります。 両方$n$そして$m$せいぜい$200$。 これにより、指数関数的なものはすぐに除外されます$n+m$、 以来$2^{400}$絶望的だ。 一方で、$200^3$あるいは数百万の操作さえも 2 秒以内に完全に受け入れられます。 

主な問題は、行反転と列反転が相互作用することです。 行を反転すると、その行のすべての列エントリが変更されます。 列を反転すると、その列のすべての行エントリが変更されます。 すべてのフリップの組み合わせを単純に検索することは不可能です。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

すでにソートされている行列を考えてみましょう。```
1 3
0 0 1
```正しい答えは次のとおりです。```
YES
0
000
```少なくとも 1 回のフリップを実行することを要求するソリューションは、このケースを誤って拒否することになります。 

考慮する：```
2 2
0 1
1 0
```行反転と列反転のシーケンスでは、いくつかの 0 とそれに続くいくつかの 1 からなる行優先のシーケンスを生成することはできません。 正しい答えは次のとおりです。```
NO
```列反転とは独立して行反転を決定する貪欲な戦略は、解決策が存在すると誤って考える可能性があります。 

もう 1 つの微妙なケースは、行内で 0 から 1 への遷移が発生する場合です。```
2 3
0 1 1
1 1 1
```この行列はすでにソートされています。 0 と 1 の境界は、必ずしも 2 つの行の間にあるとは限りません。 正しい特性評価では、行内でのカットが可能でなければなりません。 

## アプローチ

 最も直接的な総当り攻撃は、行のすべてのサブセットと列のすべてのサブセットを試すことです。 選択ごとに、結果の行列を構築し、その行優先シーケンスがソートされているかどうかを確認します。 

がある$2^n$行の選択肢と$2^m$列の選択肢。 たとえ$n=m=20$、これは次のようになります$2^{40}$、すでに実用的な限界をはるかに超えています。 実際の限界で$n=m=200$、網羅的な検索はまったく不可能です。 

画期的な進歩は、ソートされたバイナリ行列が行ごとに読み取られたときにどのように見えるかを理解することで得られます。 

バイナリ シーケンスは、いくつかの 0 とそれに続くいくつかの 1 で構成されている場合、非減少です。 マトリックス形式に書き戻すと、ゼロ領域を 1 領域から分離する固有の「境界」が存在します。 

行優先の順序で最初のものが の位置に現れると仮定します。$(r,c)$。 次に:

 前のすべての行$r$ゼロのみを含める必要があります。 

以降のすべての行$r$1 つだけを含める必要があります。 

内側の列$r$、前の列$c$のゼロと列です$c$それ以降は 1 です。 

これは、ソートされたすべてのバイナリ行列が単一の境界行と単一の境界列によって完全に決定されることを意味します。 

次に、反転の効果を考えてみましょう。 させて$R_i$行かどうかを示します$i$ひっくり返されて、$C_j$列かどうかを示します$j$ひっくり返されます。 最終的な値は、$(i,j)$は$$a_{ij} \oplus R_i \oplus C_j.$$境界位置が固定されている場合、すべてのセルには次のいずれかの必要な最終値があります。$0$または$1$。 したがって、各セルは制約を与えます$$R_i \oplus C_j = a_{ij} \oplus b_{ij},$$どこ$b_{ij}$は、ソートされたターゲット行列の目的の値です。 

これは、行変数と列変数に関する XOR 方程式系です。 

2 部 XOR システムは、1 つの変数を固定し、他のすべての変数を伝播することで解決できます。 しかないので、$n+m \le 400$変数を使用すると、1 つの境界をチェックするのは簡単です。 

境界線はいくつ存在しますか? 遷移は、最初のセルの前、最後のセルの後、または行列の任意の位置で発生する可能性があります。 考えられるすべての境界行をすべての考えられる境界列とともに試すだけで十分です。 がある$(n+1)(m+1)$可能性は、せいぜい$40401$。 

各候補境界について、最大で以下を含むシステムを解決します。$400$変数と$40000$制約。 結果として生じる複雑さは許容範囲内です。

 ## アルゴリズムのチュートリアル

 ### ソートされた行列の特徴付け

 ソートされた行優先のバイナリ行列には、0 から 1 への遷移が 1 つだけあります。 

境界行を選択してください$r$と境界柱$c$。 

上の行$r$は完全にゼロです。 

以下の行$r$完全に一つです。 

並んでいます$r$、前の列$c$のゼロと列です$c$それ以降は 1 です。 

特殊なケースが自然に現れるのは、$r=0$、$r=n$、$c=0$、 または$c=m$。 

### 固定境界を求める

 1. 目的の値を構築します$b_{ij}$選択した境界に従ってすべてのセルに対して。 
2. 各セルは方程式を生成します$$R_i \oplus C_j = a_{ij} \oplus b_{ij}.$$3. 行と列を 2 部グラフの頂点として表示します。 

行$i$柱に接続されています$j$エッジラベル付き$$a_{ij} \oplus b_{ij}.$$4. たとえば、1 つの変数を修正します。$R_0=0$。 
5. 二部グラフを通じて BFS または DFS を実行します。 

もし$$R_i \oplus C_j = x$$一方のエンドポイントが既知であれば、もう一方のエンドポイントは一意に決定されます。 
6. すでに値を持つ頂点が見つかった場合は、新しく暗黙的に指定された値が既存の値と一致することを確認します。 
7. 矛盾とは、この境界が実現できないことを意味します。 
8. すべての式が満たされる場合、すべての行および列の反転値を復元し、出力します。 
9. 境界が機能しない場合は、出力`NO`。 

### なぜ効果があるのか

 固定境界の場合、すべての有効な解は、必要なターゲット行列から導出された XOR 方程式を正確に満たす必要があります。 方程式は、行反転と列反転の関係を完全に説明しています。 

グラフの伝播では、開始頂点から到達可能なすべての方程式と一致する値が割り当てられます。 すでに割り当てられている頂点が異なる暗黙の値を受け取ると、システムの一貫性が失われ、その境界には反転構成が存在しません。 

ソートされたすべての行列は、何らかの境界位置に対応します。 アルゴリズムは考えられるすべての境界をチェックするため、有効な答えは最終的に検査されます。 一貫したシステムが見つかった場合、復元された行と列の反転により、ターゲットの並べ替えられた行列が正確に生成されるため、出力は正確になります。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]

for r in range(n + 1):
    for c in range(m + 1):
        val = [-1] * (n + m)

        val[0] = 0
        q = deque([0])

        ok = True

        while q and ok:
            v = q.popleft()

            if v < n:
                i = v

                for j in range(m):
                    if i < r:
                        b = 0
                    elif i > r:
                        b = 1
                    else:
                        if r == n:
                            b = 0
                        elif c == 0:
                            b = 1
                        elif c == m:
                            b = 0
                        else:
                            b = 0 if j < c else 1

                    need = a[i][j] ^ b

                    to = n + j
                    want = val[v] ^ need

                    if val[to] == -1:
                        val[to] = want
                        q.append(to)
                    elif val[to] != want:
                        ok = False
                        break

            else:
                j = v - n

                for i in range(n):
                    if i < r:
                        b = 0
                    elif i > r:
                        b = 1
                    else:
                        if r == n:
                            b = 0
                        elif c == 0:
                            b = 1
                        elif c == m:
                            b = 0
                        else:
                            b = 0 if j < c else 1

                    need = a[i][j] ^ b

                    to = i
                    want = val[v] ^ need

                    if val[to] == -1:
                        val[to] = want
                        q.append(to)
                    elif val[to] != want:
                        ok = False
                        break

        if ok:
            rows = ''.join(str(val[i]) for i in range(n))
            cols = ''.join(str(val[n + j]) for j in range(m))

            print("YES")
            print(rows)
            print(cols)
            sys.exit()

print("NO")
```解決策は、考えられるすべての境界を反復処理します。 それぞれについて、明示的に保存するのではなく、暗黙的なターゲット行列を構築します。 

配列`val`すべての行変数と列変数の値を保存します。 指数`0..n-1`行に対応しますが、`n..n+m-1`列に対応します。 

すべての行列セルには XOR 制約が与えられます。 BFS は、2 部グラフを通じて割り当てを伝播します。 頂点が 2 番目の割り当てを受け取るたびに、コードはただちに整合性をチェックします。 このチェックは、XOR システムを解くための完全な正しさの条件です。 

微妙な点の 1 つは、特別な境界の処理です。 いつ`r == n`、行列全体がゼロでなければなりません。 いつ`c == 0`、行の最初の列の前で遷移が発生します。`r`, したがって、その行は完全に 1 になります。 いつ`c == m`、行の最後の列の後に遷移が発生します。`r`、その行は完全にゼロになります。 これらのケースは、オフバイワンの間違いを避けるために個別に処理する必要があります。 

もう 1 つの微妙な点は、`R_0 = 0`ソリューションを失うことはありません。 XOR システムは、すべての行変数とすべての列変数を同時に反転しても不変です。 1 つの変数を固定することは、単に同値クラスから代表を選択するだけです。
