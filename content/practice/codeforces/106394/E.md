 ## 解決策
 ## 問題の理解

 次のサイズの正方形グリッドが与えられます。$n \times n$、各セルは赤または青の 2 色のいずれかで色付けする必要があります。 すべてのセルにそれ自体と同じ色を持つ隣接する (側面を共有する) 2 つのセルがある場合、その色は有効であるとみなされます。 

したがって、各セルは上下左右に隣接するセル (存在する場合) を調べ、それらの隣接するセルのうち、ちょうど 2 つのセルがその色と一致する必要があります。 境界上のセルには隣接セルが少ないため、その状態は既存の隣接セルのみを使用して解釈されます。 

タスクは、指定されたそれぞれの色にそのような色が存在するかどうかを判断することです。$n$存在する場合は、有効な構成を 1 つ出力します。 

制約により、最大で次のことが許可されます。$t \le 100$テストケースと$n \le 1000$, の合計$n^2$最大でも複数のテストにわたって$10^6$。 これは、あらゆる解決策を意味します。$O(n^2)$テスト ケースごとは許容されますが、3 次的なものや複数の反復内でセルごとのシミュレーションを繰り返すと遅すぎます。 

全体にわたるブルートフォース割り当て$2^{n^2}$グリッドは明らかに不可能です。 すべてのセルの有効性は、ローカルの一貫性だけではなく、グローバルな構造に依存するため、貪欲に色を割り当ててローカルでバックトラッキングしようとしても、爆発的な結果になります。 

小さなサイズでは、微妙なエッジケースがすぐに現れます。 のために$n = 1$、単一のセルには隣接セルがないため、同じ色の隣接セルが 2 つだけ存在することはなく、答えは不可能です。 のために$n = 2$、すべてのセルにはちょうど 2 つの隣接セルがあるため、条件は「両方の隣接セルがセルの色と一致する必要がある」となり、グリッド全体が強制的に単色になり、実際に機能します。 のために$n = 3$、隅と中心の制約が競合し、すべての次数を同時に満たすことができない周期パターンがあるため、条件を満たす試みは失敗します。 

ローカル制約を満たしながら行ごとに色を割り当てようとする単純なアプローチは、1 つの行を修正すると隣接する行に矛盾が生じるため、失敗することがよくあります。 

## アプローチ

 総当たり的な観点は、セルごとに色を割り当て、最後に条件が満たされるかどうかを確認することです。 これは概念的に機能します。検証が簡単であるため、セルごとに、一致する隣接セルをカウントし、それが 2 に等しいかどうかを確認します。 費用は$O(n^2)$ただし、構成の数は指数関数的なものであるため、これは直ちに実行不可能です。 

これを貪欲に改善しようとすると、部分的な有効性を維持しながら色を割り当て、各セルに「ターゲット」数の一致する隣接セルが確実に存在するようにすることができます。 失敗点は、決定が両方向に伝播することです。セルの設定は隣接セルに影響しますが、それらの隣接セルは後で元のセルにも制約を与えるため、ローカルでの貪欲な決定は安定しません。 

重要な構造的洞察は、ローカルな制約の観点から考えるのをやめ、代わりに、すべてのセルが同一のローカル環境を持つグローバルな繰り返しパターンを探すことです。 すべての内部セルが隣接するセルの同じパターンを認識すると、条件は自動的に均一になり、どこでも当てはまるか、どこにも当てはまらないかのどちらかになります。 

「正確に 2 つの同じ色の隣り合うもの」という要件は、固定次数パターンを示唆しており、グリッド内でそのような均一な制約を満たす最も簡単な方法は、周期的なタイリングを使用することです。 あ$2 \times 2$繰り返しブロックは、すべての内部セルに対して同一の近傍構造を保証するため、自然な候補です。 

次のようなブロックを試してみると:```
BB
BB
```内部のすべてのセルには、それ自体と等しい隣接セル (最大 4 つ) がすべてあります。これにより、各内部セルには 2 つではなく 4 つの一致する隣接セルが存在するため、失敗します。 

次の試行はチェッカーボード パターンですが、一致する近傍はゼロとなり、これも失敗します。 

正しい構造は、各セルが水平方向または垂直方向に正確に 2 つの同一の隣接セルを認識できるように、両方のパリティ クラスにわたる構造を混合することによって得られます。 このようなパターンの 1 つは、傾斜 1 の対角線に沿って平等を強制することで、両方向に隣接ペアを作成します。 これをわかりやすく表現する方法は次のとおりです。$$color(i, j) = (i + j) \bmod 2 \text{ with a controlled flip on alternating rows}$$しかし、より具体的に言うと、この問題に有効な構築は、繰り返しを構築することです。$2 \times 2$形式のブロック:```
R R
B B
```これにより、各行内で隣接セルがペアで一致し、各セルが位置に応じて水平方向と垂直方向の 2 つの同じ色の隣接セルを正確に認識するように垂直方向の隣接関係が構築されます。 

ただし、このパターンは次の場合にのみ一貫して機能します。$n$は均等です。 いつ$n$が奇数の場合、パリティの不一致により境界でペアになっていない行が強制され、次数均一条件が破られます。 これが、奇数のサイズが失敗する理由です。 

したがって、完全な解はパリティ引数になります。$n$タイル張りの構造を認める、奇妙な$n$しません。

 | --- | --- | --- | --- |

 ## アルゴリズムのチュートリアル

 1. まず次のことを確認します。$n$は均等です。 これが奇数である場合は、有効な構造が存在しないと直ちに結論付けます。これは、均一なタイリングが境界行で壊れ、必要な近傍カウントをグローバルに保存できないためです。 
2. もし$n$が偶数の場合、繰り返しを使用して行ごとにグリッドを構築します。$2 \times 2$パターン。 これにより、すべてのローカル近傍がグリッド全体で同じように繰り返されることが保証されるため、検証する必要があるのは代表的なセル 1 つだけです。 
3. 行のペアごとに$i$そして$i+1$、列を 2 つのブロックに埋めます。 各ブロック内で、水平方向に同じ色を割り当て、そのペアを垂直方向に交互に配置して、各列も一貫した垂直方向のペアを形成します。 
4. 結果のグリッドを出力します。 

### なぜ効果があるのか

 この構造では、すべてのセルが均一に属することが強制されます。$2 \times 2$すべての隣接関係が変換まで同一であるタイル。 このようなタイリングでは、各色クラスが行方向と列方向の両方で長さ 2 の互いに素なチェーンを形成するため、各セルには同じ色の隣接セルが 2 つあります。 すべてのセルは同一のローカル環境に存在するため、1 つのセルを検証すると他のすべてのセルが暗黙的に検証され、条件がグローバルに一貫したものになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())

        if n % 2 == 1:
            print("NO")
            continue

        print("YES")
        for i in range(n):
            row = []
            for j in range(n):
                # 2x2 repeating block:
                if (i // 2 + j // 2) % 2 == 0:
                    row.append('R')
                else:
                    row.append('B')
            print("".join(row))

if __name__ == "__main__":
    solve()
```コードは直接実装します$2 \times 2$周期的なタイリング。 表現`i // 2`そして`j // 2`グリッドをサイズ 2 のブロックにグループ化し、それらの合計のパリティによってブロック全体で色が交互になります。 これにより、水平方向と垂直方向の両方で一貫性が確保され、すべてのセルが同じ近傍構造を持つようになります。 

奇数の早期拒否$n$建設を試みることなく、不可能な場合に対処します。 

よくある実装上の間違いは、次のように使用することです。`(i + j) % 2`、チェッカーボードが生成され、近隣カウント要件に失敗するか、整数の除算グループ化を忘れて、$2 \times 2$完全に構造。

 ## 特殊なケース

 のために$n = 1$の場合、同じ色の隣り合う 2 つのセルが存在しない場合、セルはこの要件を満たすことができないため、アルゴリズムは即座にそれを拒否します。 入力`1\n1\n`早期チェックと出力をトリガーします`NO`。 

のために$n = 2$、この構造により完全に均一なブロックが生成されます。 すべての隣接セルが同一であるため、すべてのセルの隣接セルはルールと一致しており、各セルは条件を自明に満たします。 

より大きな偶数の場合$n$、繰り返します$2 \times 2$タイリングにより、すべての境界セルが内部セルと同じ隣接パターンを持つ完全なブロック内に存在するため、境界効果によって構造が破壊されないことが保証されます。
