 ## 解決策
 ## 問題の理解

 固定文字列があります`T`長さは最大 20。クエリ文字列ごとに`s`の文字を削除する場合があります。`T`、残りの文字の相対的な順序が維持されます。 

目標は、結果の文字列に次の内容を含めることです。`s`連続した部分文字列として。 文字を削除するすべての有効な方法の中で、削除の数を最小限に抑えたいと考えています。 一連の削除が不可能な場合`s`部分文字列として表示される場合は出力します`-1`。 

重要な点は、削除しても文字の順序が変更されないことです。 のコピー`s`削除後に表示されるものは、次の部分に由来する必要があります。`T`。 

クエリは 100,000 件もありますが、固定文字列`T`は非常に短いです。 その長さは最大でも 20 なので、問題は完全に変わります。 複雑さが二次関数であるアルゴリズム`|T|`実質的には一定時間です。`20² = 400`。 

よくある間違いは、次のことだけを考えることです。`s`の続きです`T`。 これは必要ですが、最小限の削除を計算するには十分ではありません。 また、一致した文字の間で削除される文字の数を最小限に抑える必要もあります。 

考慮する：```
T = abxc
s = abc
```唯一一致するサブシーケンスは位置を使用します`0,1,3`。 キャラクター`x`間`b`そして`c`を削除する必要がありますので、`abc`連続的になります。 答えは`1`、 ない`0`。 

もう 1 つの簡単な罠は、一致するサブシーケンスが見つかったら、その外側のすべての文字も削除する必要があると仮定することです。 

例：```
T = zabcz
s = abc
```削除は必要ありません。 文字列にはすでに含まれています`abc`部分文字列として。 周囲を維持する`z`文字は完全に許可されます。 

3 番目のエッジ ケースは、同じクエリの複数の埋め込みが存在する場合に発生します。 

例：```
T = axbxc
s = abc
```マッチングポジション`(0,2,4)`2 つの内部文字を削除する必要があります。 最初の一致で停止する不注意な実装は、他の入力へのより適切な埋め込みを見逃す可能性があります。 考えられるすべての開始位置を検討する必要があります。 

## アプローチ

 ブルートフォースの観点は、次のサブシーケンスを選択することです。`T`、削除後に結果の文字列を構築し、その文字列に次のものが含まれているかどうかを確認します。`s`部分文字列として。 以来`|T| ≤ 20`、せいぜいあります`2^20 ≈ 10^6`後続。 これは考えるのに十分な小さなものですが、クエリごとに個別に実行するのは無駄です。 

より直接的なアプローチは、有効な発生が観察されることから始まります。`s`最後の文字列は、次の部分列から来ています。`T`。 

の文字を仮定します。`s`位置に合わせてあります```
p1 < p2 < ... < pk
```内部`T`。 

これらの一致した文字が削除後に連続した部分文字列を形成するようにするには、一致しない文字はすべて、それらの間にあります。`p1`そして`pk`削除する必要があります。 前の文字`p1`そしてその後`pk`部分文字列に干渉しないため、そのままでも構いません。 

この埋め込みに必要な削除の数は正確に```
(pk - p1 + 1) - k
```なぜならインターバルの長さは`pk - p1 + 1`、一方、`k`その間隔の文字は目的の文字列に属します。 

したがって、問題は次のようになります。 

次の部分一致を検索します。`s`内部`T`誰のスパン`(last - first + 1)`できるだけ小さいです。 

以来`T`長さが最大 ​​20 である場合、最初に一致した文字として機能するすべての可能な位置を試すことができます。 その開始点から、単純な 2 ポインター スキャンにより、サブシーケンスの可能な限り早い完了が検出されます。 これにより、選択した開始の最小終了位置、つまりその開始の最小スパンが得られます。 

すべてのスタートで最良のスパンを取ることで答えが得られます。

 ## アルゴリズムのチュートリアル

 1. しましょう`n = |T|`そして`m = |s|`。 
2. 答えを無限大として初期化します。 
3. ポジションごとに`start`で`T`そのような`T[start] == s[0]`、この位置から始まるクエリ文字列全体の構築を試みます。 
4. ポインタを設定します。`T`で`start`そしてポインタ`s`で`0`。 
5. 通過する`T`左から右へ。 現在の文字が現在の文字と一致するたびに、`s`、ポインタを中に進めます`s`。 
6. のすべての文字が`s`が一致した場合は、最後の文字が一致した位置を記録します。 
7. スパン長は```
last - start + 1
```そのスパン内で必要な削除は次のとおりです。```
span - m
```8. すべての有効な開始位置にわたってこの値を最小化します。 
9. 完全に一致するものが見つからなかった場合、出力`-1`。 それ以外の場合は、最小削除数を出力します。 

### なぜ効果があるのか

 有効な発生箇所を修正します。`s`最後の文字列で。 内部の部分シーケンスの一致に対応します`T`最初に一致した位置`first`最後に一致した位置`last`。 

間隔内のすべての文字`[first, last]`一致の一部ではないものは削除する必要があります。 間隔外の文字は常に保持できます。 したがって、必要な削除の数は正確に次のようになります。```
(last - first + 1) - |s|
```固定開始位置の場合`first`、貪欲な左から右のマッチングにより、後続のすべての文字に対して可能な限り最も早い位置が選択され、これにより最小化されます。`last`。 削除数はスパンにのみ依存するため、これによりその開始に対する最適な埋め込みが得られます。 

可能なすべての開始を試すことで、実行可能なすべての埋め込みがカバーされます。 それらを上回る最小値が全体的な最適値です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

T = input().strip()
n = len(T)

q = int(input())

for _ in range(q):
    s = input().strip()
    m = len(s)

    best = float('inf')

    for start in range(n):
        if T[start] != s[0]:
            continue

        j = 0
        last = -1

        for i in range(start, n):
            if j < m and T[i] == s[j]:
                j += 1
                last = i
                if j == m:
                    break

        if j == m:
            best = min(best, (last - start + 1) - m)

    print(-1 if best == float('inf') else best)
```外側のループは各クエリを独立して処理します。 

考えられる開始位置ごとに、コードは標準的なサブシーケンスの一致を実行します。 変数`j`すでに一致したクエリの文字数を格納します。 

クエリ全体が一致すると、`last`最後に一致した文字の位置を保存します。 数量```
(last - start + 1) - m
```は、スパン内の一致しない文字 (削除する必要がある文字) の正確な数です。 

微妙な点は、文字数をカウントしないことです。`start`またはその後`last`。 部分文字列の存在に影響を与えることなく、最終文字列に残すことができます。 

もう 1 つの詳細は、有効な開始位置をすべて試す必要があるということです。 最初の文字が最も早く出現することが常に最適解の一部であるとは限りません。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    T = input().strip()
    n = len(T)

    q = int(input())

    ans = []
    for _ in range(q):
        s = input().strip()
        m = len(s)

        best = float('inf')

        for start in range(n):
            if T[start] != s[0]:
                continue

            j = 0
            last = -1

            for i in range(start, n):
                if j < m and T[i] == s[j]:
                    j += 1
                    last = i
                    if j == m:
                        break

            if j == m:
                best = min(best, (last - start + 1) - m)

        ans.append("-1" if best == float('inf') else str(best))

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# custom cases
assert run("abc\n1\nabc\n") == "0", "already a substring"

assert run("abxc\n1\nabc\n") == "1", "delete one internal character"

assert run("abc\n1\nd\n") == "-1", "impossible"

assert run("aaaaa\n2\naaa\naaaaa\n") == "0\n0", "all equal characters"

assert run("axbxcxd\n1\nabcd\n") == "3", "multiple internal deletions"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`abc`、クエリ`abc`|`0`| 削除は必要ありません |
 |`abxc`、クエリ`abc`|`1`| 内部隙間除去 |
