 ## 解決策
 ## 問題の理解

 平面内に 2 組の点が与えられます。 最初のセットは「消毒液」を表し、2 番目のセットは細菌の位置を表します。 3 つのパラメータを選択できます: スケーリング係数$S \ge 0$、および翻訳ベクトル$(X, Y)$。 

各消毒ドロップは元々$(x_i, y_i)$は最終的な位置に変換されます。$$(Sx_i + X,\ Sy_i + Y)$$それぞれの形質転換液滴で除去できる細菌は最大 1 つであり、すべての細菌は 1 つの形質転換液滴によって除去されなければなりません。 したがって、変換後、2 つの点セットは複数の座標セットとして一致する必要があります。 

したがって、核心的な質問は、ある点セットを他の点セットと正確に等しくなるようにスケールおよびシフトできるかということです。 

重要な詳細は、スケーリングが両方の座標で均一であることです。 これは、ジオメトリが類似度まで保持されることを意味します。つまり、点間の相対ベクトルはスケーリングされますが、回転または歪められません。 

制約により、最大 2000 ポイントが許可されます。 すべてのペアにわたる単純な 3 次または 2 次マッチングは実行可能ですが、すべてのマッピングをチェックするようなことは実行できません。 

エッジケースは次の場合に発生します。 

すべての点が同一になるなど、構成の縮退が発生します。 その場合は、いずれか$S$機能しますが、翻訳は多重度に正確に一致する必要があります。 たとえば:

 入力:```
1
0 0
5 5
```マッピングは 1 つだけ存在し、答えは単純です。$S=0$、$X=5$、$Y=5$。 を前提とした不注意なアプローチ$S \neq 0$失敗します。 

もう 1 つの微妙なケースは、点が対称パターンを形成する場合です。 アンカーのペアが異なると、異なる変換候補が生成される可能性があり、すべてのポイントを一貫して保持するのは一部だけです。 

## アプローチ

 強引なアイデアは、2 つの点セット間の対応関係を推測することです。 すべての間のマッピングを修正すると、$N$ドロップと$N$バクテリアについては解決できるでしょう$S, X, Y$2 つの一致したペアから抽出し、他のすべてを検証します。 

ただし、全単射の数は$N!$、でもそれは不可能です$N = 10$。 たとえ削減したとしても、すべてのアンカーペアを試してみると、依然として次の結果が得られます。$O(N^3)$不用意に行われた場合の行動。 

重要な観察は、変換が単一のスカラー パラメーターでアフィンであることです。$$b_i = S x_i + X,\quad d_i = S y_i + Y$$したがって、違いにより翻訳が排除されます。$$(b_i - b_j, d_i - d_j) = S(x_i - x_j, y_i - y_j)$$これは、点セットの構造が、グローバル スケーリング係数まで、ペアごとの差分ベクトルによって完全にエンコードされることを意味します。 

したがって、点を直接照合する代わりに、差分の構造を照合します。 2 つのペアが同じ差方向を定義している場合、それらは候補スケールを与えます。$S$。 一度$S$修正されました、翻訳$(X, Y)$すぐに決まるようになる。 

したがって、問題は次のようになります。 

少数のアンカーペアのセットから候補の対応を試み、計算します$S, X, Y$を実行し、変換されたセット全体が一致するかどうかを確認します。 

重要な点は、有効な解は入力点のペアを出力点のペアにマッピングする必要があるということです。 それは与える$O(N^2)$の候補者$S$、各候補者は次の方法で確認できます。$O(N \log N)$または$O(N)$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースマッピング | お(ん!) | O(N) | 遅すぎる |
 | すべてのペアアンカーを試す | O(N^3) | O(N) | 遅すぎる |
 | ペアを修正し、変換を計算し、ハッシュ/ソートで検証する | O(N^2 log N) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 2 つの点を固定して変換を決定するというアイデアに基づいてソリューションを構築します。 

1. 両方の点セットをソートします。 これにより、変換後のマルチセットの決定論的な比較が可能になります。 
2. 消毒セットから個別のポイントの順序付きペアを選択します。$(x_i, y_i)$そして$(x_j, y_j)$、同様に細菌セットからペアを選択します。 

これら 2 つのペアは次の理由から変換を定義します。 

- 2 点の差により決定されます。$S$- 絶対位置によって平行移動が決まります
 3. 以下を計算します。$$S = \frac{a_j - a_i}{x_j - x_i}$$そして、それが整数であり、両方の座標で一貫していることを確認します。$$S = \frac{b_j - b_i}{y_j - y_i}$$分母がゼロの場合は、その次元での一貫性を要求することで個別に処理します。 

1. 1回$S$が修正されている場合、変換を計算します。$$X = a_i - S x_i,\quad Y = b_i - S y_i$$1. すべての元の点に変換を適用し、結果のセットを保存します。 
2. この変換されたセットを細菌セットと比較します。 それらが完全に一致する場合 (多重度を含む)、パラメータを出力します。 
3. 有効な一致が得られるペアがない場合は、-1 を出力します。 

### なぜ効果があるのか

 有効な変換では、元のセットをターゲット セットに正確にマップする必要があります。 したがって、選択されたオリジナル ポイントのペアをターゲット ポイントのペアにマッピングする必要があります。 スケーリングはすべての座標にわたって均一であるため、このペアはスケーリング係数を一意に決定します。 

スケーリングが修正されると、変換が強制されます。 自由度が残っていないため、セット全体が一致するか、失敗します。 これにより、ペアベースの列挙が完了します。すべての有効なソリューションが、テストされたアンカーの 1 つとして表示されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    A = [tuple(map(int, input().split())) for _ in range(n)]
    B = [tuple(map(int, input().split())) for _ in range(n)]

    A.sort()
    B.sort()

    if n == 1:
        x, y = A[0]
        u, v = B[0]
        print(0, u, v)
        return

    def try_pair(i, j):
        ax1, ay1 = A[i]
        ax2, ay2 = A[j]
        bx1, by1 = B[0]
        bx2, by2 = B[1]

        dxA = ax2 - ax1
        dyA = ay2 - ay1
        dxB = bx2 - bx1
        dyB = by2 - by1

        if dxA == 0:
            if dxB != 0:
                return None
            S = 0
        else:
            if dxB % dxA != 0:
                return None
            S = dxB // dxA

        if dyA * S != dyB:
            return None

        X = bx1 - S * ax1
        Y = by1 - S * ay1

        transformed = [(S * x + X, S * y + Y) for x, y in A]
        transformed.sort()

        if transformed == B:
            return S, X, Y
        return None

    for i in range(n):
        for j in range(i + 1, n):
            res = try_pair(i, j)
            if res:
                print(*res)
                return

    print(-1)

if __name__ == "__main__":
    solve()
```この実装では、2 つのアンカー ポイントを使用して変換候補を修正します。 最もデリケートな部分は、ゼロ差異を処理することです。$x_j = x_i$、スケーリングは純粋に y 座標から推測する必要があり、一貫性を注意深くチェックする必要があります。 

両方のセットをソートすると、比較が複数セットの等価性チェックになります。 これにより、ハッシュの衝突が回避され、ロジックの決定性が維持されます。

 ## 特殊なケース

 すべての点が同じ x 座標を共有する場合、重大なエッジ ケースが発生します。 その場合、水平方向の差は情報を提供しないため、スケーリングは完全に Y 軸から導出する必要があります。 アルゴリズムは、両方の座標を個別にチェックし、矛盾する比率を拒否することでこれを処理します。 

もう 1 つの特殊なケースは、複数の点が一致する場合です。 変換後にソートされたマルチセットを比較するため、多重度は自動的に保持されます。 単純なセットベースの比較は、重複が崩れて誤検知が発生するため、ここでは失敗します。 

最後の微妙なケースは、$S = 0$、変換されたすべての点が単一の座標に折りたたまれます。 すべての変換されたポイントが同一になり、正しく崩壊する有効な細菌構成のみと一致するため、アルゴリズムはこれを自然に処理します。
