 ## 解決策
 ## 問題の理解

 2 人のプレイヤーが異なる頂点から開始するツリーが与えられています。 アリスが先に動きます。 各ターンで、アリスは距離内の任意の頂点にジャンプできます`da`とボブは距離内の任意の頂点にジャンプできます`db`。 距離は、ツリー内の標準的な最短パスの長さです。 

アリスの目標は、何らかの移動シーケンスの最後に最終的にボブと同じ頂点に着地することです。 それが起こらなければ、ボブは永遠に逃げ出したと考えられます。 

重要な点は、動作が段階的に局所的に行われないことです。 各移動により、ツリー メトリックの半径内のどこにでもジャンプできるため、ゲームは隣接性ではなく、大きな近隣への到達可能性が重視されます。 

すべてのテストの頂点の総数が最大 100,000 であるため、制約はテスト ケースごとに線形に近いソリューションを示唆しています。移動ごとにツリーを繰り返し探索したり、ゲームをシミュレートしたりするソリューションは、すぐに遅すぎます。 

素朴な解釈では、各移動後のすべての可能な位置をシミュレートすることになります。 各移動がツリー内の大きなボールに拡張され、最悪の場合、分岐要素がツリー全体になるため、これは失敗します。 到達可能な集合を明示的に表現することさえ二次関数になります。 

初期距離のみを比較すると、より微妙な故障モードが現れます。 たとえば、アリスが最初はボブからわずかに離れていても、はるかに大きな機動力を持っている場合、ツリーの構造により、アリスは後でボブを捕まえる可能性があります。 逆に、ボブの移動半径がはるかに大きい場合、最初は近づいていても逃げる可能性があります。 

素朴な推論に欠けている重大な要素は、ツリー構造によって距離が縮んだり伸びたりする速度が制限され、グローバル構造、特に直径によって脱出ルートが制限されるということです。 

## アプローチ

 ブルート フォース シミュレーションでは、各プレイヤーがターンごとに到達できるすべての頂点を追跡します。 それぞれの現在の位置から、その中のすべてのノードに展開します。`da`または`db`BFS を使用します。 これを順番に繰り返すと、重複する大きなサブツリーを繰り返し探索することになります。 最悪の場合、移動ごとに費用がかかる`O(n)`そして、ゲームは何手も続く可能性があるため、問題の時間制限の下では無制限になります。 

重要な洞察は、時間をかけてゲームをシミュレーションする必要がないということです。 結果は、プレイヤー間の最初の距離と、直径によって捉えられる木の全体の「幅」という、小さな構造量のセットにのみ依存します。 

推論は 3 つの体制に分かれます。 

アリスが一手でボブに到達できれば、即座にアリスが勝ちます。 

ボブがアリスに比べて比較的遅い場合、つまりボブの最大ジャンプがアリスの 2 倍を超えない場合、アリスは構造に関係なく、最終的に常にギャップを埋めることができます。 直感的に、アリスはボブが補うことができない速度で 1 秒ごとに距離を減らします。 

ボブの方が著しく速い場合は、木の最も遠い部分に向かって走ろうとすることができます。 この場合、アリスが勝つ唯一の方法は、木がボブにとって分離を維持するには「小さすぎる」場合、つまり直径が避難通路を支えるのに十分大きくない場合です。 

これにより、問題は単一の最短パス距離とツリーの直径の計算に軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O(n²) 最悪の場合 | O(n) | 遅すぎる |
 | 直径 + 距離のロジック | テストあたり O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 1. アリスとボブの間の距離を計算します。 

BFS または DFS を実行して最短パス距離を計算します`d(a, b)`木の中で。 これは、アリスが一手でボブを捕まえられるかどうかを直接決定します。 

この距離が最大であれば`da`, アリスはボブの位置に直接ジャンプできるため、すぐに勝ちます。 

### 2. 木の直径を計算します。 

2 つの BFS パスを使用して木の直径を見つけます。 任意のノードからの最初の BFS は最も遠いノードを検索します`x`、次に 2 番目の BFS`x`最も遠い距離を見つけます`D`。 

この直径は、ツリー内の任意の 2 つのノード間の最大の分離距離を表し、ボブが継続的に後退できる距離の境界として機能します。 

### 3. ボブがアリスに対して速すぎるかどうかを確認します

 もし`db <= 2 * da`, アリスは常に勝ちます。 

直感的には、ボブが最適に遠ざかったとしても、アリスは交互にターンすることで有効距離を縮めることができるということです。 ボブは、アリスがそれを中和するよりも速く分離を増加させることはできません。 

### 4. 高速ボブ体制に対処する

 もし`db > 2 * da`, ボブは、常に木の最も遠い部分に向かって移動することで、潜在的に距離を保つことができます。 

この場合、アリスが勝つのは、木が小さすぎて持続的な脱出ができない場合、つまり直径が満たされる場合のみです。`D <= 2 * da`。 

直径がこれより大きい場合、ボブは遠い端点に向かって位置を変更し続け、キャプチャを妨げる可能性があります。 

### 5. 条件を組み合わせる

 次のいずれかが当てはまれば、アリスの勝ちです。 

-`d(a, b) <= da`-`db <= 2 * da`-`D <= 2 * da`そうでなければボブが勝ちます。 

### なぜ効果があるのか

 核となる不変条件は、ボブの捕獲を回避する能力は、ツリー内の最長のパスに沿って減少しない距離を維持することに依存するということです。 木が十分に「幅」（直径が大きい）で、ボブがアリスよりも十分に速い場合、ボブはいつでも位置を変更して、アリスの捕捉半径よりも大きな距離を保つことができます。 

ボブが十分に速くない場合、アリスが交互に有利になるため、最終的には分離は崩れます。 ボブはグローバル構造を十分に高速に利用できないため、直径条件はその領域では無関係になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def bfs(start, g):
    n = len(g) - 1
    dist = [-1] * (n + 1)
    q = deque([start])
    dist[start] = 0
    far = start
    while q:
        v = q.popleft()
        for to in g[v]:
            if dist[to] == -1:
                dist[to] = dist[v] + 1
                q.append(to)
                if dist[to] > dist[far]:
                    far = to
    return far, dist

def distance(a, b, g):
    _, dist = bfs(a, g)
    return dist[b]

def diameter(g):
    x, _ = bfs(1, g)
    y, dist = bfs(x, g)
    return dist[y]

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n, a, b, da, db = map(int, input().split())
        g = [[] for _ in range(n + 1)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            g[u].append(v)
            g[v].append(u)

        d = distance(a, b, g)
        D = diameter(g)

        if d <= da:
            out.append("Alice")
        elif db <= 2 * da:
            out.append("Alice")
        elif D <= 2 * da:
            out.append("Alice")
        else:
            out.append("Bob")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装では、ロジックを 3 つの独立した測定値 (アリスとボブの距離、木の直径、速度の比較) に分割します。 BFS ルーチンは、トラバーサル ロジックの重複を避けるために、距離クエリと直径計算の両方に再利用されます。 

よくある落とし穴は、テスト ケースごとに距離を繰り返し再計算することです。 ここでは、すべてがツリーごとに線形時間で計算され、全体の複雑さが制限内に収まることが保証されます。

この星形の木の直径は 2 です。 

条件を確認します。

これは、ボブが分岐ツリー内であっても分離を維持できるほど速くない状況を示しています。

3 4
4 5

```これはパスグラフです。 端点間の距離は 5 です。 

| 数量 | 値 |
 | --- | --- |
 | d(a,b) | 5 |
 | だ | 2 |
 | データベース | 5 |

ボブはいつでも遠方のエンドポイントに向かって後退し、分離を維持できます。 これでボブの勝利が確定します。

 ## 特殊なケース

 アリスとボブがすでに近くにいるが、ボブの移動範囲が広い場合、重大なエッジケースが発生します。 たとえボブが遠くまで移動できたとしても、継続的な回避を妨げるほど直径が小さければ、アリスが勝つ可能性があります。 条件`D <= 2 * da`ボブが長い逃走経路を利用する能力を制限することで、これを捕捉します。 

もう 1 つの微妙なケースは、ボブの方が速いにもかかわらず、ツリーのバランスが著しく崩れている場合です。 それでも、直径が小さい場合、ボブは距離を繰り返しリセットすることができません。 このアルゴリズムは、このようなケースをアリスの勝ちとして正しく分類します。 

最後に、単一のエッジのような非常に小さなツリーでは、直接距離の比較が優先されます。 BFS 距離チェックは、直径の推論に依存せずに正確さを保証します。
