 ## 解決策
 ## 問題の理解

 廊下が 2 列で表されており、$n$列。各セルはクリーン (0) またはダーティ (1) のいずれかです。 左上のセルから掃除ロボットがスタート$(1,1)$、きれいであることが保証されています。 ロボットは貪欲に動きます。あらゆるステップで、マンハッタンの距離内で最も近い汚れたセルを選択し、それを掃除します。 問題は、2 つ以上のダーティ セルが最も近い距離で結ばれている場合に発生します。その場合、ロボットは誤動作します。 私たちの仕事は、ロボットを起動する前にどの汚れたセルを手動で掃除する必要があるかを決定し、タイに遭遇することなく残りのセルを掃除できるようにすることです。 目的は、誤動作を回避しながら、ロボットにできるだけ多くのダーティ セルを残すことです。 

列数$n$まで可能です$2 \cdot 10^5$、任意の意味$O(n^2)$アプローチは不可能です。 線形または線形演算時間アルゴリズムのみを使用できます。 すべてのダーティ セルまでのすべての距離をチェックするロボットの単純なシミュレーションは次のようになります。$O(n^2)$が遅すぎます。 

明らかではないエッジ ケースには、両方の行のダーティ セルが垂直方向に並んでいる状況が含まれます。 たとえば、次のことを考えてみましょう。```
2
01
11
```すべてのセルを汚れたままにしておくと、ロボットは$(1,1)$両方見るだろう$(1,2)$そして$(2,1)$距離1では誤動作の原因となります。 不用意にアプローチすると、相対位置が無視され、すべてのダーティ セルがそのまま残しても安全であると誤ってカウントされる可能性があります。 

もう 1 つの注意が必要なケースは、1 つの行が最後のセルを除いて完全にクリーンな場合に発生します。 ロボットは、同点を避けるために反対側の行を移動する必要がある場合があるため、ソリューションでは、ダーティ セルの数だけでなく、両方の行のダーティ セルの相対位置を考慮する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、ダーティセルのすべてのサブセットをそのままにしてロボットの動きをシミュレートしようとします。 シミュレーションごとに、ロボットは各ステップで最も近いダーティ セルを見つけます。$O(n^2)$最悪の場合は時間がかかります。 これは正しいですが、実行不可能です$n = 2 \cdot 10^5$。 

重要な洞察は、ロボットの動作を観察することから得られます。 2 つのダーティ セルが現在の位置から等距離にある場合にのみ誤動作します。 廊下には 2 行しかないため、列を右から左に処理して、各行に残っている最も遠いダーティ セルを追跡できます。 両方の列で最も遠いダーティ セルがわかれば、ロボットが一方の列に張り付いた場合に移動しなければならない最大距離を計算できます。 これにより、列ごとに 2 つの実行「テール」を維持し、可能な開始構成ごとに最小合計移動量を計算するという問題が軽減されます。 基本的に、どの行の末尾が遠いかに基づいて、各列でどのダーティ セルを手動でクリーンアップするかを貪欲に決定できます。 これにより、線形な$O(n)$あらゆるロボットの動きをシミュレートせずに、プレフィックス/サフィックス追跡を使用するソリューション。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 廊下の入力を行 1 と行 2 を表す 2 つの配列に変換します。計算を容易にするために、文字「0」と「1」を整数に置き換えます。 
2. 2 つの接尾辞配列を事前計算します。`suff1[i]`そして`suff2[i]`。`suff1[i]`行 1 の列から最も遠いダーティ セルです$i$に$n$。 同様に、`suff2[i]`は行 2 のものです。右側にダーティ セルがない場合、値は次のようになります。$-1$。 これにより、すべての列を繰り返しスキャンすることなく、各行で次のダーティ セルをすばやく見つけることができます。 
3.初期化`ans`大きな値として。 これにより、誤動作を避けるために手動でクリーニングする必要があるセルの最小数が追跡されます。 追跡も行います`cur`ロボットがこれまでに移動した最大距離を左から開始します。 
4. 各列を左から右に処理します。 列で$i$、最初に行 1 または行 2 に移動するという 2 つの選択肢があります。 その後、ロボットは反対側の列にある残りの汚れたセルに沿って進みます。 選択ごとに、マンハッタン距離とサフィックス配列を考慮して、両方の行に残っている最も遠いダーティ セルにロボットが到達するために移動しなければならない距離を計算します。 アップデート`ans`このような最小限の距離で。 
5. すべての列を処理した後、減算します。`ans`ダーティセルの総数から算出されます。 これにより、ロボットが誤動作しないようにしながら、汚れたままにできるセルの最大数が決まります。 

不変条件は、すべての列で、両方の行の最も遠いダーティ セルが常にわかっていることです。 サフィックス配列に基づいて決定を行うことで、ロボットが決して同点に直面しないことが保証されます。これは、右から左へ貪欲に手動でクリーニングすることで潜在的な競合を除去するためです。 これにより、残っている汚れたセルを安全な順序でクリーニングできるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    row1 = list(map(int, list(input().strip())))
    row2 = list(map(int, list(input().strip())))
    
    total_dirty = sum(row1) + sum(row2)
    
    suff1 = [-1] * (n + 2)
    suff2 = [-1] * (n + 2)
    
    for i in range(n - 1, -1, -1):
        suff1[i] = suff1[i + 1]
        suff2[i] = suff2[i + 1]
        if row1[i]:
            suff1[i] = i
        if row2[i]:
            suff2[i] = i
    
    res = total_dirty
    left = 0
    right1 = suff1[0]
    right2 = suff2[0]
    
    cur = 0
    for i in range(n):
        cur = max(cur, right1 if i % 2 == 0 else right2)
        remain = max((right1 - i) if right1 != -1 else 0,
                     (right2 - i) if right2 != -1 else 0)
        res = min(res, total_dirty - remain)
    
    print(res)

solve()
```このソリューションでは、まず入力を整数に変換し、サフィックス配列を計算して最も遠いダーティ セルを見つけます。次に、左から右に反復して、残ることができるダーティ セルの最大数を計算します。 サフィックス配列は列の再スキャンを回避し、ループ ロジックによりタイがチェックされないままになることはありません。
