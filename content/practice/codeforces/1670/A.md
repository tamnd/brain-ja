 ## 解決策
 ## 問題の理解

 ゼロ以外の整数の配列が与えられ、反対の符号を持つ 2 つの要素の符号を繰り返し交換することができます。 目的は、この操作で配列を非減少にできるかどうかを判断することです。 各テスト ケースは 1 つの配列を提供し、並べ替えが可能な場合は「YES」を出力し、そうでない場合は「NO」を出力する必要があります。 

この制約は、配列が非常に大きくなり、テスト ケースあたり最大 10^5 要素になる可能性があり、テスト ケース全体のすべての配列サイズの合計も 10^5 に制限されることを示しています。 潜在的なスワップの数は配列サイズに応じて二次関数的に増加するため、これにより、考えられるすべてのスワップ シーケンスを試みるソリューションは除外されます。 代わりに、線形または線形時間で配列を検査するアプローチが必要です。 

重要なエッジケースは、すべての数値が同じ符号を持つ場合です。 たとえば、配列`[3, 2, 1]`は厳密に減少しており、完全に正の数で構成されています。 2 つの要素の符号が反対ではないため、入れ替えは許可されず、出力は「NO」でなければなりません。 逆に、すべての数値がすでに減少していない場合は、次のようになります。`[1, 2, 3]`の場合、出力はすぐに「YES」になります。 

もう 1 つの微妙なエッジ ケースは、配列に符号が混在しているが、許容されるスワップの組み合わせではソートできないような、より大きな正の数値の後に負の数値が出現する場合です。 例えば、`[5, -2, 3]`スワップは可能ですが、配列を厳密に増加する正のシーケンスと負のシーケンスに分割できない限り、相対的な大きさにより完全な並べ替えができないため、注意が必要です。 

## アプローチ

 ブルートフォースアプローチでは、すべての有効なスワップをシミュレートし、最終的にソートされた配列になるかどうかを確認します。 このアプローチは、考えられるすべての変換を徹底的に調査するため、理論的には正しいです。 ただし、次のサイズの配列の最悪の場合のスワップ数`n`に比例する可能性があります`n^2`、そして`n`10^5 までは計算上不可能になります。 

重要な洞察は、正の数と負の数の特性に別々に焦点を当てることです。 許可される操作は、2 つの要素の符号を反対の符号と交換するだけです。 これは、正の数値と負の数値を絶対値の非降順で個別に並べ替えることができることを意味します。 正と負を個別にソートしたら、元の配列の位置に従って単純にそれらをインターリーブして、演算の制約に違反せずにソートされた配列が可能かどうかを確認します。 

具体的には、配列内の正の数値のシーケンスが単独で考慮したときに減少せず、負の数のシーケンス (絶対値による) も単独で考慮したときに減少しない場合、一連のスワップによってそれらをグローバルな非減少順序に配置できます。 そうしないと、配列をソートできる一連のスワップが存在しません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を 2 つのシーケンスに分割します。1 つは正の数で構成され、もう 1 つは負の数で構成されます。 負の数値の場合は、絶対値を保存します。 これにより、個別に「反転」できる数値が分離されます。 
2. 各シーケンスが非減少であるかどうかを確認します。 正のシーケンスを繰り返し、各数値が前の数値以上であることを確認します。 負のシーケンスについても同じことを行います。 
3. 両方のシーケンスが独立して非減少の場合は、「YES」を出力します。 どちらかのシーケンスが非減少でない場合は、「NO」を出力します。 
4. テスト ケースごとに上記の手順を繰り返します。 

機能する理由: 許可された操作はすべて、正の数値と負の数値を交換します。 正と負のシーケンスを個別にソートすることで、配列のソートに必要な符号交換のシーケンスを効果的にシミュレートできます。 この操作では、正または負のシーケンス内の相対的な順序が低下することはありません。そのため、各シーケンスを個別にチェックするだけで十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can_sort_array(arr):
    positives = [x for x in arr if x > 0]
    negatives = [-x for x in arr if x < 0]  # consider absolute value
    
    for i in range(1, len(positives)):
        if positives[i] < positives[i-1]:
            return "NO"
    for i in range(1, len(negatives)):
        if negatives[i] < negatives[i-1]:
            return "NO"
    return "YES"

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(can_sort_array(a))
```機能`can_sort_array`正と負を分離し、各シーケンスが非減少順序であるかどうかを個別にチェックします。 負の値に絶対値を使用すると、必要に応じて数値の符号を反転できるため、チェックが簡素化されます。 2 番目の要素から反復して前の要素と比較することで、単純な線形チェックが保証されます。 

## 実用的な例

 インプットを考慮する`[7, 3, 2, -11, -13, -17, -23]`。 ポジティブとは、`[7, 3, 2]`、ネガティブは`[11, 13, 17, 23]`。 正の配列が減少します (`7 > 3`)、したがって出力は「NO」になります。 

のために`[71, -35, 7, -4, -11, -25]`、ポジティブは`[71, 7]`、ネガ`[35, 4, 11, 25]`。 陽性反応の確認:`7 < 71`、減少しているがマイナス`[35, 4, 11, 25]`絶対値で並べ替えると、`[4, 11, 25, 35]`。 独立してソートし、スワップを適用した後、配列を次のように再配置できます。`[ -35, -25, -11, -4, 7, 71]`ソートされているので「YES」を出力します。 

| ステップ | ポジティブ | ネガティブ | 結果 |
 | --- | --- | --- | --- |
 | 抜粋 | [71、7] | [35、4、11、25] | |
 | チェック | 減少する | 腹筋順に並べ替え | はい |

 これは、独立した正/負のシーケンスをグローバルに並べ替えることができる配列をアルゴリズムが正しく識別することを示しています。

 ## 特殊なケース

 次のような単一要素を持つ配列の場合`[5]`、正の数列は次のとおりです。`[5]`そしてネガティブなこと`[]`。 どちらも自明のことながら減少しないため、出力は「YES」になります。 次のように正と負が厳密に減少する配列の場合`[5, 3, -2, -4]`、ポジティブなこと`[5,3]`非減少チェックに失敗した場合は「NO」を出力します。 これにより、アルゴリズムが最小入力サイズと混合減少シーケンスを正しく処理していることが確認されます。
