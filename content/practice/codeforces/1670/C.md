 ## 解決策
 ## 問題の理解

 サイズの 2 つの順列が与えられています$n$、以下の各整数を含む配列です。$1$に$n$まさに一度。 これら 2 つの順列から、各位置に対して最初の順列または 2 番目の順列の値を選択することによって 3 番目の配列が構築されます。 結果の配列自体が有効な順列である必要があります。 この配列内の一部の位置はすでに固定されている可能性があります。 残りのポジションは不明です。 私たちのタスクは、これらのルールに基づいて形成できる有効な順列の総数を数えることです。$10^9 + 7$。 

制約が意味するのは、$n$と同じ大きさにすることができます$10^5$テストケースごと、およびすべての合計$n$すべてのテストケース全体で最大でも$5 \cdot 10^5$。 これにより、未知の位置に対する選択肢のすべての組み合わせを試みる強引なアプローチが排除されます。$2^n$固定位置を考慮しなくても可能な方法があります。 代わりに、テスト ケースごとに線形または線形に近いアプローチが必要です。 エッジ ケースには、すでに固定されている位置と、2 つの順列による位置間の依存関係によって形成されるサイクルが含まれます。 たとえば、次から 1 つの要素を選択する位置のサイクルが存在する場合、$a$サイクルの残りを自動的に決定するため、単純なアプローチでは可能性を過大評価する可能性があります。 

## アプローチ

 単純な総当たりソリューションでは、すべてが列挙されます。$2^k$自由に選択できる位置の組み合わせを調べ、結果の配列が有効な順列であるかどうかを組み合わせごとにチェックします。 これは原理的には正しいですが、明らかに不可能です。$k$大きいので$k$近づくことができる$10^5$。 

重要な観察は、位置間の依存関係をグラフとしてモデル化できることです。 からの各値を検討します。$1$に$n$ノードとして、および各位置に対して$i$の間にエッジを描きます。$a_i$そして$b_i$。 このエッジは、順列が割り当てる必要がある制約を表します。$c_i$どちらかに$a_i$または$b_i$。 このグラフの連結成分は、限られた数の方法でのみ配置できる値のセットに対応します。 コンポーネント内のいずれかのノードにすでに固定値が割り当てられている場合、$c$、コンポーネントの残りの部分の選択肢が決まります。 コンポーネントに固定値がない場合、制約を満たすために値を割り当てる方法は 2 つあります。いずれかを選択します。$a_i$または$b_i$サイクル内の 1 つの要素に対して、残りは独自に続きます。 

したがって、最適な解決策は、固定値を持たない連結成分の数を数えるということになります。 このような各コンポーネントは、有効な順列の総数に 2 の係数を与えます。 少なくとも 1 つの固定値を持つコンポーネントは係数 1 に寄与します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 (グラフ / 循環棚卸) | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、長さを読み取ります。$n$そして 3 つの配列$a$、$b$、 そして$d$。 
2. 配列を初期化する`used`どの値が訪問されたかを追跡するためのサイズ (n+1`)。 
3. 各ノードが 1 から 1 までの値を表すグラフを構築します。$n$。 ポジションごとに$i$、間に無向エッジを追加します。$a_i$そして$b_i$。 
4. 各ノードを 1 から 1 まで反復します。$n$。 ノードにアクセスしたことがない場合は、深さ優先検索 (DFS) または幅優先検索 (BFS) を実行して、接続されているコンポーネントを横断します。 
5. コンポーネントをトラバースしているときに、このコンポーネント内のノードに固定割り当てがあるかどうかを確認します。`d`。 少なくとも 1 つのノードが固定されている場合、このコンポーネントの配置数は 1 になります。それ以外の場合、配置数は 2 になります。 
6. すべてのコンポーネントの寄与を剰余で乗算します。$10^9+7$、テストケースの答えを取得します。 

機能する理由: グラフの各接続コンポーネントは、相互依存する値のサイクルを表します。 1 つの値を固定するかどうかによって、残りのサイクルが決まります。 コンポーネントに固定値がある場合、あいまいさはありません。 固定値がない場合は、サイクルを反転して、正確に 2 つの有効な順列を与えることができます。 他のコンポーネントと相互作用するコンポーネントはないため、すべてのコンポーネントの数を乗算すると、有効な順列の合計数が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**6)
MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        d = list(map(int, input().split()))
        
        # Build the graph
        graph = [[] for _ in range(n+1)]
        for i in range(n):
            if a[i] != b[i]:
                graph[a[i]].append(b[i])
                graph[b[i]].append(a[i])
        
        used = [False] * (n+1)
        result = 1
        
        def dfs(node):
            stack = [node]
            has_fixed = False
            while stack:
                u = stack.pop()
                if used[u]:
                    continue
                used[u] = True
                if u in fixed:
                    has_fixed = True
                for v in graph[u]:
                    if not used[v]:
                        stack.append(v)
            return has_fixed
        
        # Collect fixed values from d
        fixed = set(x for x in d if x != 0)
        
        for val in range(1, n+1):
            if not used[val]:
                has_fixed = dfs(val)
                if not has_fixed:
                    result = (result * 2) % MOD
        print(result)

if __name__ == "__main__":
    solve()
```グラフは、値間の依存関係のサイクルを表します。 DFS は各コンポーネントを調査し、固定ノードをチェックします。 固定されていない各コンポーネントは、有効な順列の数を 2 倍にします。 使用する`stack`大規模な場合の Python 再帰制限を回避します`n`。 の`fixed`set を使用すると、ノードが事前に割り当てられているかどうかの確認が簡単になります。 モジュロ演算により、整数の制限内に確実に収まります。
