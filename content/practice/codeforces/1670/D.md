 ## 解決策
 ## 問題の理解

 私たちは、各六角形が 6 つの隣接する六角形とエッジを共有する無限六角形グリッドを使用しています。 タスクは、六角形の辺の方向に沿って直線を追加して正三角形を形成することです。 すべての三角形は完全に空である必要があります。つまり、六角形のエッジや以前に追加された線がその内部を通過しないことを意味します。 入力は多数のテスト ケースで構成され、各テスト ケースに対して 1 つの整数が含まれます。$n$が与えられ、作成する必要がある空の正三角形の数を表します。 各テスト ケースの出力は、少なくとも達成するために必要な直線の最小数です。$n$三角形。 

制約が示すのは、$n$と同じ大きさにすることができます$10^9$、テスト ケースの数は次のとおりです。$10^5$。 各三角形または各ラインの配置を明示的にシミュレートしようとするアルゴリズムは、以下に比例する操作が必要となるため、遅すぎます。$n$またはそれ以上。 したがって、直接的なシミュレーション手法は実現不可能であり、最小ライン数を効率的に計算するには、閉じた形式または数学的に導出された式が必要です。 

重要なエッジケースは、非常に小さな値の場合です。$n$。 たとえば、$n = 1$または$n = 2$、必要な最小ラインは両方とも 2 です。単純なアプローチでは、1 行を追加すると常に三角形が生成されると想定するかもしれませんが、サンプルが示すように、最初の行では三角形が生成されず、2 行目では複数の三角形が同時に作成される可能性があります。 このパターンを認識することは、off-by-one エラーを回避するために重要です。 

## アプローチ

 ブルートフォース手法では、ラインの増分追加をシミュレートし、各ラインの後に形成される三角形の数を数えようとします。 これは概念的には単純ですが、すぐに実行不可能になります。$n$到達できる$10^9$、行ごとに繰り返すと何十億もの操作が必要になります。 さらに、三角形の数を幾何学的に追跡することは自明ではなく、実装エラーが発生しやすくなります。 

重要な観察は、形成される正三角形の数が予測可能なパターンで増加することです。 と表すと$k$線の数と同様に、形成できる三角形の最大数は次の順序に従います。$f(k) = k \cdot (k + 1) / 2$。 これは、三角形がレイヤーに配置されているためです。最初の行では 0 個の三角形が寄与し、2 番目の行では 2 個の三角形が寄与し、3 行目では 3 個の新しい三角形が追加され、以下同様に三角形の数列が形成されます。 これにより、問題は最小の整数を見つけることに帰着します。$k$そのような$k \cdot (k + 1)/2 \ge n$。 

この公式が認識されたら、最適なアプローチは二次不等式を解くことです。$k^2 + k - 2n \ge 0$。 これは、直接計算することによって行うことができます。$k = \lceil(-1 + \sqrt{1 + 8n}) / 2\rceil$または二分探索を使用して$k$。 どちらのアプローチも、特定の制約に対しては効率的です。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、整数を読み取ります。$n$、必要な三角形の数。 
2. 値を計算する$k$三角数列から導出された式を使用して、次のようにします。$k = \lceil(-1 + \sqrt{1 + 8n}) / 2\rceil$。 この公式は不等式を解くことで得られます$k(k+1)/2 \ge n$を保証します。$k$ラインは少なくとも生成できます$n$三角形。 
3. 出力$k$必要な最小限の行数として。 

なぜ機能するのか: シーケンス$k(k+1)/2$で形成できる正三角形の最大数を正確にモデル化します。$k$最初の線の後に追加される新しい線ごとに、新しい三角形の数が増加するためです。 二次不等式を解くと、計算された結果が保証されます。$k$は、必要な三角形の数を満たす最小の整数です。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    # Solve k(k+1)/2 >= n -> k^2 + k - 2n >= 0
    k = math.ceil((-1 + math.sqrt(1 + 8 * n)) / 2)
    print(k)
```コードは最初にテスト ケースの数を読み取ります。 テストケースごとに計算します。$k$閉じた形式のソリューションを使用します。 の`math.sqrt`関数により正確な計算が保証され、`math.ceil`不等式を満たすために切り上げられることを保証します。 使用する`sys.stdin.readline`大規模な入力の高速読み取りが可能$t$。

## テストケース```python
import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    t = int(input())
    for _ in range(t):
        n = int(input())
        k = math.ceil((-1 + math.sqrt(1 + 8 * n)) / 2)
        print(k, file=out)
    return out.getvalue().strip()
