 ## 解決策
 ## 問題の理解

 平面内に原点に固定され、点まで広がる長方形の部屋が与えられます。$(X, Y)$。 この長方形の内側には、他の人々を表すいくつかの固定点があります。 アリスはから始まります$(0, 0)$そして到達しなければならない$(X, Y)$常に長方形の中に留まりながら。 

重要な制約は、最短経路や特定のルートを見つけることではなく、クリアランスを維持することです。アリスは、他のすべての人との距離が常に少なくとも一定の値になるような経路を望んでいます。$d$、そしてこれを最大化するように求められます$d$。 アリスは任意の方向に連続的に移動できるため、問題は幾何学的なものであり、グリッド構造ではなく、平面内の連続距離に依存します。 

出力は、アリスのパスから任意の点までの最大可能最小距離を表す実数です。 

と$N \le 1000$、おおよそ余裕があります$O(N^2)$または$O(N^2 \log N)$推論は可能ですが、平面の密な離散化やパスの列挙を伴うものは不可能です。 パスを明示的にシミュレートしたり、平面を細かいグリッドに離散化しようとすると、座標が次まで連続しているため、すぐに失敗します。$10^6$規模。 

複数の人が近くにいる場合、微妙な問題が発生します。 たとえば、2 人の人が非常に近い場合、それぞれが個別に回避可能であるように見えても、2 人の間の安全領域が消滅する可能性があります。 安全な空間の接続性を考慮せずに、各点からの距離だけを独立して考慮する単純なアプローチは失敗します。 

もう 1 つのエッジ ケースは、最適なパスが 2 人の人物の間を正確に通過する必要がある場合に発生します。この場合、制限距離は、影響領域間の最も狭い「廊下」によって定義されます。 障害物を個別に扱うと (直線上の任意の点までの最小距離を取るなど)、アリスは障害物の周りを曲がることができるため、実行可能な動きを過小評価したり、誤って表現したりすることになります。 

## アプローチ

 強引な解釈では、候補の距離を考えることになります。$d$そしてアリスがそこから旅行できるかどうか尋ねます$(0,0)$に$(X,Y)$少なくとも距離を保ちながら$d$あらゆる人から。 幾何学的に、これは各人を半径の円に拡張することに相当します。$d$そして、長方形の中にすべての円を避ける連続したパスが存在するかどうかを尋ねます。 

固定の場合$d$、長方形の細かい離散化に対して連続的な BFS またはグリッドベースのフラッド フィルを試み、少なくとも次の点にマークを付けることができます。$d$すべてのサークルから離れてください。 パスが存在する場合、$d$実現可能です。 二分探索をオンにしてこれを繰り返す$d$解決策を与えます。 ただし、平面を十分に細かく離散化すると、$10^{-5}$精度には巨大なグリッドが必要であり、簡単に超えます$10^9$細胞、それは不可能です。 

重要な観察は、問題を修正すると問題の構造が変わるということです。$d$。 連続した空間について考える代わりに、禁止された領域間の接続性の観点から考えることができます。 各人が半径の円盤を定義します$d$、これらのディスクはスペースを分割します。 アリスは次のことを知りたいと思っています$(0,0)$そして$(X,Y)$自由空間の同じ接続コンポーネント内にあります。 

これは古典的な幾何学的接続性の問題であり、障害物と境界壁の間の接続性をグラフ化することができます。 ノードが障害物を表すグラフを構築し、長方形の 4 つの境界線の仮想ノードも含めます。 2 つの障害物は、展開されたディスクが重なると接続されます。 ディスクが境界に触れたり、境界を越えたりすると、ディスクは境界に接続されます。 重要なアイデアは、開始側と終了側を分離する接続されたディスクのチェーンが存在し、長方形を横切るバリアを事実上形成する場合、アリスはブロックされるということです。 

これにより、実現可能性チェックが、サイズのグラフでのユニオン検索または BFS 接続チェックに変換されます。$O(N)$、これは二分探索内で十分効率的です。$d$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |

 ここ$R$座標スケールです。 

## アルゴリズムのチュートリアル

 答えを二分探索して問題を解決します$d$、各候補について安全なパスが存在するかどうかを確認します。 

1. 検索範囲を設定します。$d$から始まる$0$などの十分に大きな値まで$\max(X, Y)$。 部屋の寸法より大きいディスク半径はすぐに動きを完全にブロックしてしまうため、この上限は安全です。 
2. 候補者が確定した場合$d$で一人ひとりを治療します。$(x_i, y_i)$ブロックされた半径の円盤として$d$。 
3. これらのディスクと、長方形の左、右、下、上の壁を表す 4 つの追加の境界ノードをノードとするグラフを構築します。 
4. 2 つの人物ノード間のユークリッド距離が最大以下の場合、2 つの人物ノードを接続します。$2d$。 これは、重複する禁止領域をモデル化します。これは、それらが単一の接続されたバリアを形成することを意味します。 
5. 人物ノードと境界ノードとの距離が最大でも$d$。 これは、禁止された領域が壁に触れるか、壁と交差するときをキャプチャします。 
6. 次に、左側の境界を右側の境界に接続する、または下部の境界を上部の境界に接続するブロック領域の接続コンポーネントが存在するかどうかを確認します。$(0,0)$から$(X,Y)$。 このような障壁が存在する場合、現在の$d$実行不可能です。 
7. この実現可能性チェックを使用して、最大の値を二分探索します。$d$それはまだ実現可能です。 

重要な幾何学的解釈は、禁止された円盤の結合によって長方形が切断された領域に切断される連続的な障壁を作成しない場合に限り、アリスは最初から最後まで通過できるということです。 

### なぜ効果があるのか

 固定の場合$d$、禁止された領域は閉じられたディスクです。 これらのディスクが長方形の反対側を結ぶ接続チェーンを形成すると、自由空間が切断されたコンポーネントに分割され、最初から最後まで連続したパスができなくなります。 逆に、そのような分離チェーンが存在しない場合、ディスクの補体は 2 点間で接続されたままになります。 Union-Find 構造はディスクと境界間の接続を正確に取得するため、実現可能性テストはブロッキング バリアが存在するかどうかを確認することと同等です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def can(d, pts, X, Y):
    n = len(pts)
    # nodes: 0..n-1 persons, n=left, n+1=right, n+2=bottom, n+3=top
    L, R, B, T = n, n+1, n+2, n+3

    parent = list(range(n + 4))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(a, b):
        ra, rb = find(a), find(b)
        if ra != rb:
            parent[rb] = ra

    def dist2(a, b):
        dx = pts[a][0] - pts[b][0]
        dy = pts[a][1] - pts[b][1]
        return dx*dx + dy*dy

    # connect person-person
    for i in range(n):
        for j in range(i+1, n):
            dx = pts[i][0] - pts[j][0]
            dy = pts[i][1] - pts[j][1]
            if dx*dx + dy*dy <= 4*d*d:
                union(i, j)

    # connect to boundaries
    for i, (x, y) in enumerate(pts):
        if x <= d:
            union(i, L)
        if X - x <= d:
            union(i, R)
        if y <= d:
            union(i, B)
        if Y - y <= d:
            union(i, T)

    # check blocking conditions:
    # left connects to right OR bottom connects to top
    return find(L) != find(R) and find(B) != find(T)

def solve():
    X, Y = map(float, input().split())
    n = int(input())
    pts = [tuple(map(float, input().split())) for _ in range(n)]

    lo, hi = 0.0, max(X, Y)
    for _ in range(60):
        mid = (lo + hi) / 2
        if can(mid, pts, X, Y):
            lo = mid
        else:
            hi = mid

    print(f"{lo:.10f}")

if __name__ == "__main__":
    solve()
```このソリューションは、重複する禁止ディスクとその境界との相互作用をマージするための Union-Find 構造に依存しています。 重要な実装の詳細は、比較における浮動小数点の不安定性を回避するために二乗距離を使用することです。 二分探索は、必要な誤差範囲内の精度を保証するために、固定回数の反復を実行します。 

微妙な点の 1 つは、実現可能条件です。 アリスのパスを直接チェックすることはありません。 代わりに、禁止領域が反対側の間に連続した障壁を形成しているかどうかを確認します。 そうすれば、アリスは閉じ込められてしまいます。 それ以外の場合は、空きスペースを通るパスが存在します。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、人が境界線上、または境界に非常に近くに横たわっている場合です。 たとえば、点が次の場所にある場合、$(0, y)$、それから非常に小さいものでも$d$すぐにそのディスクを左の壁に接続します。 ユニオンステップ`if x <= d`ディスクがすでに半径で境界に触れているため、これを正しくキャプチャできます。$d$。 

もう 1 つのケースは、2 つの点が正確な距離にある場合です。$2d$。 浮動小数点演算では、接続と切断の間で変動する可能性があります。 二乗距離を使用すると、比較するため、精度の低下を回避できます。$dx^2 + dy^2 \le 4d^2$一貫して。 

最後の微妙なケースは、人が存在しない場合です。 結合検索グラフには境界ノードのみがあり、結合は発生しないため、左が右に接続されたり、下から上に接続されたりすることはありません。 アルゴリズムは完全な自由を正確に返し、$d = \max(X, Y)$制限二分探索限界として。
