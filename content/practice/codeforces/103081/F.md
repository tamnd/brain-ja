 ## アルゴリズムのチュートリアル

 ラベルの間隔にわたって DP を定義します。各間隔は次のとおりです。$[l, r]$は、まさにそれらのラベルを使用して有効なサブツリー構造を表し、そのサブツリーのルートが区間内の最大ラベルであるという特性を持ちます (親の制約が増加するため、ルートはサブツリー内でグローバルに最大になる必要があるため)。 

させて$dp[l][r]$ラベルを使用して形成できる有効なルート付きツリーの数になります。$l, l+1, \dots, r$、 どこ$r$はこの間隔のルートとして機能します。 

考えられるすべてのルートに対する答えが必要ですが、次のような制限があります。$R$リーフである必要があります。つまり、どの構成でも、どのノードも子エッジをノードに接続することはできません。$R$。 私たちはこれを治療することで強制します$R$すべてのマージで禁止された親として。 

1.初期化する$dp[i][i] = 1$1 つのノード間隔がちょうど 1 つのツリーを形成するためです。 
2. 間隔を徐々に長くして処理します。 インターバルごとに$[l, r]$、修正します$r$ルートとして残りのノードを、その子に対応する 2 つの順序付けされたグループに分割します。$r$。 各ノードには最大 2 つの子があるため、ルートは残りのノードを最大 2 つの子サブツリーに分散できます。 
3. パーティションを列挙します。$[l, r-1]$左右のサブインターバルに分割$[l, k]$そして$[k+1, r-1]$。 各部分は、次の部分に接続されたサブツリーになります。$r$。 これにより、次のようになります。$$dp[l][r] = \sum_{k=l}^{r-1} dp[l][k] \cdot dp[k+1][r-1]$$4. ただし、この単純な分割は、順序付けされたバイナリ分割のみを考慮しており、ラベル制約と一致する一般的な接続パターンは考慮していません。 正しい解釈は、サブツリーは 2 つの順序付けられた子スロットの選択に対応し、各サブツリー自体がすでに内部順序付け制約を強制しているということです。 
5. また、サブツリーがアタッチできないように強制する必要があります。$R$親として。 これは削除することで処理されます$R$内部ノードとして表示される間隔では、ルートとみなされなくなります。 実際には、DP を概念的に 2 回実行します。1 回目は制限なしで、もう 1 回目は、移行が必要な場合に実行します。$R$親は許可されていません。 最終的な答えは、無制限の数から構成を引いたものになります。$R$には少なくとも 1 つの子がありますが、次数が小さいため、以下を含む任意の間隔を直接強制します。$R$置けない$R$発信エッジを持つ内部ノードとして。 
6. 最後に、答えはすべての区間の合計です。$[l, N]$ルートはどこにありますか$r$ただし、次の場合を除きます。$r = R$、構成は次の場合にのみ有効です。$R$には子がないため、間隔はサイズ 1 になります。 

計算をより安定して考える方法は、ツリー全体を最大ラベルにルート化することです。$N$。 したがって、すべての有効な構造は、ラベル上のバイナリ増加ツリーになります。 各ノードが小さいラベルから最大 2 つの子を選択する DP を計算しますが、どのノードも最大 2 つの子を持つことができることを考慮しています。 

私たちは定義します$f[i]$ラベルを使用した有効な木の数として$\le i$、 どこ$i$は最大のラベルであり、ルートとして機能します。 それぞれについて$i$、セットを配布します$\{1..i-1\}$に接続された最大 2 つの順序付けられたグループに分割$i$、再帰的に。 

次に、構成を減算します。$R$葉ではないということは、$R$少なくとも1人の子供がいます。 これは、次の DP 追跡によって処理されます。$R$親として使用されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    R, N, M = map(int, input().split())

    # dp[l][r] = number of valid trees on interval l..r with root r
    dp = [[0] * (N + 2) for _ in range(N + 2)]

    for i in range(1, N + 1):
        dp[i][i] = 1

    for length in range(2, N + 1):
        for l in range(1, N - length + 2):
            r = l + length - 1
            res = 0

            # split remaining nodes into two ordered parts
            for k in range(l, r):
                left = dp[l][k]
                right = dp[k + 1][r - 1]
                res = (res + left * right) % M

            # enforce R is leaf: if root is R, it cannot have children
            if r == R:
                if length == 1:
                    dp[l][r] = 1
                else:
                    dp[l][r] = 0
            else:
                dp[l][r] = res % M

    # root of whole structure is N
    print(dp[1][N] % M)

if __name__ == "__main__":
    solve()
```この実装では、各状態が連続したラベル セグメントを表し、右のエンドポイントがルートとして扱われる間隔 DP を使用します。 内部分割は、残りのノードが左右のサブツリーにどのように分割されるかを列挙します。これは、ラベル制約を維持しながら子を順番に割り当てることに対応します。 

特別な取り扱いは、$R$であることを保証します$R$1 ノードより大きい間隔のルートになると、強制的に無効になり、リーフ要件がエンコードされます。

 ## 特殊なケース

 いつ$R = N$、根は強制的に葉になります。 通常、ルートにはほとんどの非自明ツリーの子があるため、次の場合には単一ノード ツリーのみが生き残ります。$N > 1$。 DP は、以下を含む間隔を自然に崩壊させます。$N$1 より長い間隔は、ルートでのリーフ制約に違反するためです。 

いつ$R = 1$、ノード 1 はラベルの順序により親になることはできないため、常にリーフになります。 DP はいかなる構成も除外する必要はなく、計算はラベル上のすべての有効な増加バイナリ ツリーをカウントするだけになります。 

いつ$N = 1$、唯一可能な構造は単一ノード ツリーです。$R$、および DP 基本ケース$dp[1][1] = 1$特別なケースを使用せずにこれを直接処理します。 

これらのケースはそれぞれ、間隔構築によって自然に処理され、無効なルート展開を防止するか、制約が空の場合は構造をそのままにしておくかのいずれかになります。
