 ## 解決策
 ## 問題の理解

 正の整数を表現したい`n`正確に合計として`k`2 の累乗:$$n = 2^{a_1} + 2^{a_2} + \cdots + 2^{a_k}$$指数は、正、ゼロ、または負の場合もあります。 すべての有効な長さのシーケンスの中で`k`、まず、出現する最大の指数を最小化します。 最小可能な最大の指数を次のようにします。`y`。 すべてのシーケンスの中でその最適性を達成する`y`、辞書編集上最大のシーケンスを出力する必要があります。 

の値`n`と同じ大きさにすることができます`10^{18}`、 その間`k`せいぜい`10^5`。 のバイナリ表現`n`には最大でも 60 ビットが含まれるため、バイナリ分解で現れる 2 の累乗を使用して機能する解は当然非常に小さくなります。 一方、表現の数は爆発的に増加するため、すべての可能な指数割り当てを検索することは完全に不可能です。 

この問題の特殊な点は、負の指数が許可されていることです。 例えば、$$2^{-1} + 2^{-1} = 1.$$これは、常に 1 つのべき乗を 2 つの小さなべき乗に分割できることを意味します。$$2^x = 2^{x-1} + 2^{x-1}.$$この操作により、合計を維持しながら項の数が 1 つ増加します。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

考慮する`n = 1, k = 2`。 解決策が存在する理由は、$$1 = 2^{-1} + 2^{-1}.$$非負の指数のみを考慮するソリューションでは、誤って出力されます。`No`。 

考慮する`n = 3, k = 1`。 長さ 1 の唯一の表現は 2 の累乗になりますが、`3`は 2 の累乗ではありません。 正しい答えは、`No`。 

考慮する`n = 8, k = 8`。 最適な答えは指数の 8 つのコピーです`0`、分割を繰り返すため$$2^3 \to 2^2+2^2 \to \cdots \to 1+1+\cdots+1.$$必要な項数をチェックせずに大きな指数を保持しようとする貪欲な手順では、正確に到達できない可能性があります。`k`条項。 

辞書編集上の要件も微妙な点です。 可能な限り最小の最大指数を見つけた後、できるだけ早くより大きな指数を配置する必要があります。 同じ複数セットの指数を持つ 2 つの解は、辞書編集上の順序が異なる場合があります。 

## アプローチ

 強引な見方とは、次のすべての表現を考えることです。`n`2 のべき乗を繰り返し分割するようなものです。 のバイナリ表現から始めると、`n`、各分割は 1 つの指数を置き換えます`x`2部コピーで`x-1`。 正確な結果が得られるまで、考えられるすべての分割シーケンスを調査できます。`k`という用語が出てきます。 

このような分割を通じてあらゆる表現を取得できるため、これは正しいです。 残念なことに、州の数は膨大です。 中程度の値であっても、分岐要素は膨大になり、すべての可能性を探索することはできません。 

重要な観察は、実際にはすべての表現を気にしているわけではないということです。 まず、最大の指数の可能な最小値に注目します。 

すべての指数は最大でも次の値でなければならないと決定したとします。`M`。 任意のオリジナルビット`2^i`と`i > M`結果のすべての指数が次のようになるまで分割する必要があります。`M`。 1 部`2^i`に変わる$$2^{i-M}$$指数のコピー`M`。 

これにより、最大指数を最大に保ちながら取得できる項の数がすぐにわかります。`M`。 

固定の場合`M`、用語の最小数もあります。 最大でも指数付きの各ビット`M`変わらないままでいられる。 上記のすべてのビット`M`レベルに分割する必要があります`M`。 

させて`cnt(M)`は最小用語数を示します。 もし`cnt(M) > k`の場合、最もコンパクトな表現でもすでに使用されている用語が多すぎるため、`M`不可能です。 

もし`cnt(M) \le k`そうすると、最大でも指数をさらに分割することで、いつでも追加の項を作成できます。`M`。 分割すると用語のカウントが 1 つだけ増加するため、より大きなカウントに到達することができます。 したがって`M`実現可能です。 

実現可能性は単調です。 もし`M`機能する場合、より大きな指数制限もすべて機能します。 これにより、実行可能な最小値を二分探索します。`M`。 

最適な最大指数を見つけた後`M`、辞書編集上最大のシーケンスを構築する必要があります。 制限に関する最小期間の表現から始めます`M`。 次に、正確に到達するまで追加の分割を実行します。`k`条項。 

辞書編集上の順序を最大化するには、可能な限り大きな指数を保持し、利用可能な最小の指数を最初に分割する必要があります。 より小さい指数を分割すると、降順に並べ替えられたシーケンスの後の位置に影響し、先頭の大きな値が保持されます。 

指数の優先キューを使用すると、現在の最小指数を正確に分割するまで繰り返し分割できます。`k`という用語が存在します。 

最後に、すべての指数を降順で出力します。 その順序は、同じマルチセットを持つすべての表現の中で辞書編集的に最大です。

 ## アルゴリズムのチュートリアル

 1.分解する`n`バイナリに変換します。 位置に設定されたビットごとに`i`、指数のコピーを 1 つ記録します`i`。

3. 候補者をテストするには`M`、その制限の下で必要な用語の最小数を計算します。 

ビットが指数に寄与する場合`i ≤ M`、1つの用語に貢献します。 

もし`i > M`、レベルまで分割する必要があります`M`、生産`2^(i-M)`条項。 
4. この最小数を超えた場合`k`、限界`M`不可能です。 
5. それ以外の場合は、分割を追加すると用語数が常に 1 つずつ増加する可能性があるため、この制限は実現可能です。 
6. 二分探索が終了したら、答えを実行可能な最小値とします。`M`。 
7. これに対する最小期間表現を構築する`M`。 

すべての元の指数`i ≤ M`1 つの指数に寄与する`i`。

9. ながら`cur < k`、現在存在する最小の指数を繰り返し分割します。

### なぜ効果があるのか

 固定制限の場合`M`、より大きいすべての指数`M`最終的には次のように削減される必要があります`M`またはそれ以下。 レベルに直接分割する`M`その制限内で可能な限り最小の数の項が生成されます。 同じ制限に関する他の表現には、少なくとも同じ数の項しか含めることができません。 

したがって`cnt(M)`は達成可能な最小用語数です。 もし`cnt(M) > k`、最大指数をもつ解は存在しません。`M`。 もし`cnt(M) ≤ k`、分割を繰り返すと、毎回用語数をちょうど 1 つずつ増やすことができるため、正確に到達します。`k`条件はいつでも可能です。 

二分探索では実行可能な最小値が見つかります`M`、これはまさに最小可能な最大の指数です。 

固定後`M`、必要な長さに達する場合にのみ、追加の分割が必要になります。 最小の指数を分割すると、より大きな指数が保存され、降順シーケンスの先頭ができるだけ大きく保たれます。 したがって、最終的な降順シーケンスは、すべての最適解の中で辞書編集的に最大になります。 

## Python ソリューション```python
import sys
import heapq

input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())

    bits = []
    x = n
    pos = 0
    while x:
        if x & 1:
            bits.append(pos)
        pos += 1
        x >>= 1

    if n == 0:
        print("No")
        return

    def min_terms(M):
        total = 0
        for b in bits:
            if b <= M:
                total += 1
            else:
                total += 1 << (b - M)
            if total > k:
                return total
        return total

    lo = -100000
    hi = max(bits) if bits else 0

    while lo < hi:
        mid = (lo + hi) // 2
        if min_terms(mid) <= k:
            hi = mid
        else:
            lo = mid + 1

    M = lo

    exps = []
    for b in bits:
        if b <= M:
            exps.append(b)
        else:
            exps.extend([M] * (1 << (b - M)))

    cur = len(exps)

    heapq.heapify(exps)

    while cur < k:
        x = heapq.heappop(exps)
        heapq.heappush(exps, x - 1)
        heapq.heappush(exps, x - 1)
        cur += 1

    ans = sorted(exps, reverse=True)

    print("Yes")
    print(*ans)

if __name__ == "__main__":
    solve()
```バイナリ分解には最大 60 個の指数が含まれるため、実現可能性テストは非常に小規模になります。 

機能`min_terms(M)`すべての指数を強制的に最大数に抑えながら、可能な最小数の項を計算します。`M`。 上記の指数の場合`M`、各分割レベルはコピー数を 2 倍にし、`2^(b-M)`条項。 

二分探索は、負の値を含む指数に対して機能します。 下限`-100000`これまでに必要となる可能性のあるものよりも安全に下回っているため、`k ≤ 10^5`。 およそ以上のものは必要ありません`log2(k)`既存の最小指数を超える追加の分割レベル。 

最適値を取得した後、`M`の場合、コードは明示的に最小項表現を構築します。 生成される用語の総数が以下を超えることはありません`k`、 なぜなら`M`実現可能であり、次のように選択されました`min_terms(M) ≤ k`。 

ヒープには、現在の指数がすべて保存されます。 各分割では、1 つの指数が削除され、1 レベル下に 2 つのコピーが挿入されます。 項の数がちょうど 1 つ増えるので、ちょうど`k - cur`分割が必要です。 

最後に、降順に並べ替えると、辞書編集上最大のシーケンスが得られます。

import sys
import io
from contextlib import redirect_stdout

def solve():
    import heapq

    n, k = map(int, input().split())

    bits = []
    x = n
    p = 0
    while x:
        if x & 1:
            bits.append(p)
        p += 1
        x >>= 1

        total = 0
        for b in bits:
            total += 1 if b <= M else (1 << (b - M))
            if total > k:
                return total
        return total

        mid = (lo + hi) // 2
        if min_terms(mid) <= k:
            hi = mid
        else:
            lo = mid + 1

    M = lo

    exps = []
    for b in bits:
        if b <= M:
            exps.append(b)
        else:
            exps.extend([M] * (1 << (b - M)))

    cur = len(exps)

    while cur < k:
        x = heapq.heappop(exps)
        heapq.heappush(exps, x - 1)
        heapq.heappush(exps, x - 1)
        cur += 1

    ans = sorted(exps, reverse=True)

    print("Yes")
    print(*ans)

    with redirect_stdout(out):
