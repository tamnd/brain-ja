 **評価:** 1600
 **タグ:** 建設的アルゴリズム、グラフ、最短パス
 **解決時間:** 5 分 35 秒
 **確認済み:** いいえ

 ## 解決策
 ## 問題の理解

 2 つの素数関連の制約を満たす、正確に _n_ 個の頂点と _m_ 個のエッジを備えた無向重み付きグラフを構築するように求められます。 まず、頂点 1 から頂点 _n_ までの最短パスの長さは素数でなければなりません。 第 2 に、最小スパニング ツリー (MST) 内のエッジの合計も素数でなければなりません。 グラフにはループや複数のエッジを含めることはできません。すべての重みは 10^9 までの正の整数でなければならず、グラフは接続されている必要があります。 

入力では、頂点とエッジの数を示す 2 つの整数 _n_ と _m_ のみが提供されます。 出力は、グラフ自体に、最短パスと MST の合計の数値を加えたものです。 _n_ 個の頂点を持つグラフの場合、MST には正確に _n_-1 個のエッジが含まれます。 したがって、どのようなソリューションでも、最初に _n_-1 エッジとの接続を確保し、次に重みが許容範囲内に留まり、最短パスが素数のままであることに注意しながら、残りのエッジ (_m_ > _n_-1 の場合) を任意に埋める必要があります。 

コンストレイントでは、2 秒の時間制限で最大 10^5 の頂点を使用できます。 これにより、考えられるすべてのグラフを明示的にテストしようとするアルゴリズムが除外されます。 代わりに、直接構築するアプローチが必要です。 明らかでないエッジ ケースには、小さなグラフ (_n_=2、_m_=1)、正確に _n_-1 個のエッジを持つグラフ (つまり、調整する追加のエッジがない)、および _m_ が _n_ に比べて極端に大きいグラフ (エッジの重複を避けるために慎重な処理が必要) が含まれます。 

## アプローチ

 ブルート フォース アプローチでは、サイズ _n_ の考えられるすべての接続グラフを試し、すべてのペアの最短パスと MST 合計を計算し、素数性をチェックします。 これは明らかに実行不可能です。可能なグラフの数は _n_ と _m_ の組み合わせで増加し、最短パス/MST の計算は候補ごとに O(n log n + m) になります。 

重要な洞察は、この問題ではプロパティを満たす**任意のグラフ**が許可されるため、明示的にグラフを構築できるということです。 頂点 1 から _n_ までを順番に接続するパス グラフから始めることができます。 各エッジに重み 1 を割り当て、MST の合計が _n_-1 に等しくなります。 次に、パス上の 1 つのエッジ (たとえば、最初のエッジ) を調整して、最短パスの長さを次の素数まで増加します。 他のすべてのエッジは最小 (重み 1) になる可能性があるため、わずかな調整で MST 合計も素数になります。 MST を超える追加のエッジは、最短パスを妨げない任意の高い重みで埋めることができます。 これにより、問題は、特定の値を超える最も近い素数を計算し、1 つのエッジの重みを慎重に割り当てるように軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(n*m)) | O(n+m) | 遅すぎる |
 | 建設的なパス グラフ | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. エッジの空のリストを初期化します。 エッジ (1,2)、(2,3)、...、(n-1,n) を使用して、頂点 1 から頂点 _n_ までの単純なパスを構築します。 最初にすべてのエッジに重み 1 を割り当てます。 これにより接続が保証され、1 から _n_ までの長さ _n_-1 の最短パスの候補が提供されます。 
2. _n_-1 以上の最小の素数を計算します。 これを望ましい最短経路長とします。`sp`。 最初のエッジ (1,2) の重みを次のように増加します。`sp - (n-1)`。 この調整により、パス 1→2→…→n が正確な長さになるようにします。`sp`、他のエッジはまだ最小限であるか接続されていないため、より短いパスは存在しません。 
3. 最初のように MST 合計を計算します。`n-1`。 この合計がすでに素数である場合は、代入します`mstw = n-1`。 それ以外の場合は、MST 合計を素数にする最小量だけ最初のエッジの重みを増加します。 最初のエッジの重みのみが増加しているため、MST は同じエッジのセットのままであり、合計は素数になります。 
4. 残りの _m_ - (_n_-1) 個のエッジについては、この追加セット内でまだ接続されていない頂点を任意に接続し、大きな重み (例: 10^9) を割り当てます。 これらのエッジは MST エッジよりも重いか、より短いパスを作成しないため、MST または最短パスには影響しません。 
5. 出力`sp`、`mstw`、およびエッジのリスト。 

**機能する理由**: パスがすべての頂点をカバーするため、この構造では接続が保証されます。 MST はまさにパス エッジであるため、最初のエッジの重みを調整することで素数合計を微調整できます。 1 から _n_ までの最短パスがパスに沿って強制的に設定され、その長さは 1 つのエッジを調整することでプライムに設定できます。 追加のエッジは、重みが高すぎて MST または最短パスに含めることができないため、干渉できません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_prime(x):
    if x < 2:
        return False
    if x == 2:
        return True
    if x % 2 == 0:
        return False
    i = 3
    while i*i <= x:
        if x % i == 0:
            return False
        i += 2
    return True

def next_prime(x):
    while not is_prime(x):
        x += 1
    return x

def main():
    n, m = map(int, input().split())
    edges = []
    
    # Step 1: build initial path
    for i in range(1, n):
        edges.append([i, i+1, 1])
    
    # Step 2: adjust shortest path to prime
    sp = next_prime(n-1)
    edges[0][2] += sp - (n-1)  # increase first edge weight
     
    # Step 3: adjust MST sum to prime
    mstw = sum(w for _,_,w in edges)
    if not is_prime(mstw):
        mstw = next_prime(mstw)
        edges[0][2] += mstw - sum(w for _,_,w in edges)
    
    # Step 4: add extra edges if needed
    extra_edges = m - (n-1)
    u, v = 1, 3
    for _ in range(extra_edges):
        if v > n:
            u += 1
            v = u + 2
        edges.append([u, v, 10**9])
        v += 1
    
    print(sp, mstw)
    for u, v, w in edges:
        print(u, v, w)

if __name__ == "__main__":
    main()
```ソリューションはアルゴリズムに正確に従います。`next_prime`確実に素数和に到達し、最初のエッジを慎重に調整することで MST と最短経路素数の両方が保証されます。 余分なエッジには干渉を避けるために高いウェイトが使用されます。 難しいのは、最初の調整後に MST 合計が一貫していることを確認することです。 重みを合計して再度調整することでこれが保証されます。 

## 実用的な例

 **サンプル入力 1**:```
4 4
```| ステップ | ステップ後のエッジ | スプ | ムストウ |

**カスタム入力 2**:```
5 6
```アルゴリズムに従います:

 - パスのエッジ: 1→2→3→4→5、重み 1
 - 最初のエッジを調整して SP プライムを作成します (next_prime(4)=5)
 - MST をプライムに調整します (next_prime(5)=5、変更なし)
 - 余分なエッジを追加します: (1,3,10^9)、(2,4,10^9)
