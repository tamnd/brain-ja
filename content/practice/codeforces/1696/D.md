 ## 解決策
 ## 問題の理解

 1 から n までの整数の順列が与えられ、連続するセグメントの相対的な最小値と最大値に基づいてグラフを構築するように求められます。 具体的には、2 つのインデックス i < j について、i から j までの部分配列に最小値の a_i と最大値の a_j が含まれる場合、またはその逆の場合、頂点 i と j を接続します。 タスクは、このグラフの頂点 1 から頂点 n までの最短パスを見つけることです。 

制約は重要です。n はテスト ケースごとに 2.5×10^5 に達し、すべての n の合計は最大 5×10^5 になります。 すべてのインデックスのペアをチェックしてエッジが存在するかどうかを判断する単純なアプローチでは、テスト ケースごとに O(n²) の操作が必要となり、これでは遅すぎます。 テスト ケースごとにほぼ線形、つまり O(n log n) のメソッドが必要です。 

エッジの定義には微妙な点が生じます。 たとえば、[1,2,3,4] のような厳密に増加または減少するシーケンスでは、一部の部分配列の端点がすぐに接続されますが、[3,1,4,2] のような順列では、どのインデックスが最小-最大条件を満たすかを慎重に検討する必要があります。 より大きな要素またはより小さな要素によって引き起こされるジャンプを無視するアプローチでは、誤った答えが生成されます。 n=1 や n=2 のような小さなテスト ケースも正しく動作する必要があります。開始点と終了点が等しい場合、パスの長さは 0 になり、2 つの要素が直接接続されている場合は 1 になります。 

## アプローチ

 ブルートフォース手法では、i < j のすべてのペアに対して反復処理が行われ、最小値と最大値の条件がチェックされます。 これによりグラフが正しく構築され、頂点 1 からの BFS が最短パスを生成します。 ただし、ペアの数は O(n²) であるため、n≈10^5 ではこれは不可能になります。 エッジ チェックがプレフィックス min/max 配列を使用して最適化されていても、最悪の場合でも O(n²) 個の候補エッジが存在します。 

重要な洞察は、グラフのエッジが「単調ジャンプ」特性を持っているということです。 どのインデックスでも、最小-最大条件に違反することなく 1 つのステップで到達できるのは、シーケンス内の次に小さい要素または次に大きい要素のみです。 単調スタックを使用すると、これらのジャンプを効率的に前処理できます。 たとえば、厳密に増加するスタックは最大ジャンプの候補を追跡し、厳密に減少するスタックは最小ジャンプの候補を追跡します。 各要素は最大 1 回プッシュおよびポップされ、BFS に必要な隣接表現の O(n) 構造が得られます。 その後、標準 BFS が頂点 1 から頂点 n までの最短パスを O(n) 時間で計算します。 

つまり、ブルート フォースは最小-最大エッジ ルールを正しく適用するため機能しますが、二次関数の複雑さのために失敗するということです。 各頂点が、最小値または最大値が変化する次の要素に接続する必要があるだけであることに注目すると、グラフはまばらなエッジのセットに縮小されます。 2 つの単調スタックを使用すると、このセットが効率的にキャプチャされ、線形時間 BFS が最短パスを見つけることができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n²) | 遅すぎる |
 | 単調スタック + BFS | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 各テスト ケースについて、長さ n の順列配列 a を読み取ります。 
2. 2 つの空のスタックを初期化します。1 つは増加シーケンス (次に大きい要素) 用、もう 1 つは減少シーケンス (次に小さい要素) 用です。 これらのスタックは、最小-最大ルールに従って、特定の頂点がどの頂点に直接到達できるかを決定します。 
3. 配列を左から右に繰り返します。 各インデックス i について、減少するスタックを維持します。つまり、先頭の要素が a[i] より小さい間に、それをポップし、i にジャンプできることを記録します。 次に i をスタックにプッシュします。 これにより、各頂点が減少シーケンスを壊す次の頂点に確実に接続できるようになります。 
4. 増加するスタックで同じロジックを繰り返します。最上位の要素が a[i] より大きい間に、それをポップして i に接続します。 i をスタックにプッシュします。 
5. 両方のスタックを処理した後、各頂点に対して、有効な最小-最大ジャンプを表す一連の出力エッジが得られます。 
6. 頂点 1 から開始して BFS を実行します。ゼロに設定された開始頂点を除き、無限大で初期化された距離配列を維持します。 BFS からデキューされた各頂点について、その近傍を反復処理します。 隣接ノードの距離が設定されていない場合は、距離 +1 を割り当ててキューに追加します。 
7. BFS が完了したら、最短パスの長さを表す頂点 n までの距離を報告します。 

機能する理由: 不変条件は、各ステップで、可能なすべての「最小-最大ジャンプ」が単調スタックによって捕捉されるということです。 より短いパスは、一部のサブ配列の最小-最大条件に違反するため、必要な最小または最大境界をスキップできません。 BFS では、すべてのエッジの重みが同じであり、グラフはジャンプに関しては疎で非周期的であるため、確実に最短パスを見つけることができます。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    # adjacency list
    adj = [[] for _ in range(n)]
    
    # next greater and next smaller using monotonic stacks
    inc_stack = []
    dec_stack = []
    
    for i in range(n):
        while inc_stack and a[inc_stack[-1]] < a[i]:
            j = inc_stack.pop()
            adj[j].append(i)
        if inc_stack:
            adj[i].append(inc_stack[-1])
        inc_stack.append(i)
        
        while dec_stack and a[dec_stack[-1]] > a[i]:
            j = dec_stack.pop()
            adj[j].append(i)
        if dec_stack:
            adj[i].append(dec_stack[-1])
        dec_stack.append(i)
    
    # BFS
    dist = [float('inf')] * n
    dist[0] = 0
    q = deque([0])
    
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == float('inf'):
                dist[v] = dist[u] + 1
                q.append(v)
    
    print(dist[n-1])
```最初の部分では、単調スタックを使用して隣接リストを効率的に構築します。 各頂点は、シーケンス内で次に大きいまたは小さい要素のみを考慮します。 プッシュとポップにより、冗長なエッジがなくなります。 次に、BFS セクションは開始頂点からの距離を伝播します。 の`dist`配列は最短パスを追跡し、無限大は未訪問のノードをマークするために使用されます。 エッジの方向性は暗黙的です。正しくするためには、インデックスが増加する方向に出ていくエッジのみが必要です。
