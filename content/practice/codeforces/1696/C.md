 ## 解決策
 ## 問題の理解

 2 つの配列と固定整数が与えられます。$m$。 最初の配列から始めて、次の数で割り切れる要素を繰り返し分割します。$m$の中へ$m$等しい部分、またはマージ$m$連続する等しい要素を 1 つの大きな要素にまとめます。 

問題は、これらの操作で最初の配列を 2 番目の配列に変換できるかどうかです。 

配列の長さが変化し、さまざまな一連の移動が可能であるため、操作は複雑に見えます。 重要な観察は、どちらの操作も要素内に隠された「原子値」を変更しないということです。 

要素を取得する$x$。 繰り返して割ります$m$可能な限り:$$x = base \cdot m^t$$どこ$base$はもう割り切れません$m$。 

たとえば、次のようなとき$m=2$、$$12 = 3 \cdot 2^2$$そして$$8 = 1 \cdot 2^3.$$分割操作はべき乗のみを移動します$m$値と部数の間。 根底にあるもの$base$決して変わりません。 

この制約は、ほぼ線形の解決策が必要であることを強く示唆しています。 すべてのテスト ケースにわたるすべての配列の長さの合計は、最大でも$2 \cdot 10^5$。 アン$O(n^2)$アルゴリズムには次のようなものが必要です$4 \cdot 10^{10}$限界をはるかに超えた最悪の場合の操作。 解決策$O(n)$または$O(n \log n)$テストケースごとに必要です。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

考慮する：```
m = 2
a = [8]
b = [4,4]
```正しい答えは、`Yes`。 配列を要素ごとに比較するだけのソリューションでは、誤って拒否されてしまいます。 ターンの分割$8$二つに分けて$4$さんの。 

考慮する：```
m = 2
a = [2,2]
b = [4]
```正しい答えは、`Yes`。 ここでの変換には、分割ではなく結合が必要です。 

考慮する：```
m = 2
a = [2,4]
b = [1,1,1,1,1,1]
```正しい答えは、`Yes`。 

完全に拡張した後:$$2 \to (1,2),\quad 4 \to (1,4)$$基本値のコピーを 6 つ与える$1$。 2 つのグループを分離したままにする不用意な実装は、同じ塩基を持つ隣接するグループが結合する可能性があることを見逃してしまいます。 

考慮する：```
m = 3
a = [3,3]
b = [9]
```正しい答えは、`No`。 

それぞれ$3$ベースのコピーを 1 つ提供します$1$。 これらは一緒に 2 つのコピーを提供しますが、マージには正確なグループが必要です。$m=3$。 単一のものを作成することはできません$9$。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての分割とマージのシーケンスをシミュレートしようとします。 これは原理的には正しいです。到達可能なすべての配列が最終的に探索される可能性があるからです。 

問題は状態空間のサイズです。 次のような単一の値でも、$$10^9 = 2^9 \cdot 1953125$$何度も分割できるため、指数関数的に多くの中間配列が作成されます。 到達可能な構成の数は、網羅的な検索を行うにはあまりにも急速に増加します。 

画期的な進歩は、決して変わらないものを調べることから生まれます。 

要素を取得する$x$。 考えられるすべての要素を取り除く$m$:$$x = base \cdot m^t.$$完全に拡張すれば$x$、になります。$$base$$繰り返された$m^t$回。 

たとえば、$m=2$、$$12 = 3 \cdot 2^2$$の 4 つのコピーとまったく同じように動作します$3$。 

これらの基本値の順序は決して変わりません。 オペレーションは権限を再分配するだけです$m$同じ基本値に対応する連続ブロック内。 

これは、すべての要素をペアとして表現できることを意味します。$$(base,\ count)$$どこ$$count = m^t.$$のために$12$と$m=2$、ペアは$(3,4)$。 

同じ塩基を持つ隣接するペアは、展開された形状が区別できないため、マージできます。 この方法で配列全体を圧縮した後、変換の問題は次のようになります。 

次の 2 つの圧縮シーケンスを実行します。$(base,count)$ペアは正確に一致しますか？ 

存在する場合、配列は同じ完全に展開されたシーケンスを表し、相互に到達可能です。 そうでない場合、一連の操作を行っても不一致を修正できません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | 指数 | 遅すぎる |
 | 最適 |$O((n+k)\log_m V)$|$O(n+k)$| 承認済み |

 ここ$V \le 10^9$最大の要素値です。 

## アルゴリズムのチュートリアル

 1. 最初の配列を左から右に処理します。 
2. 各値について$x$、繰り返し除算$m$割り切れる一方で。 残りの値を次のようにします`base`。 
3. の因数を数えます。$m$削除されました。 もし$x = base \cdot m^t$の場合、この要素が貢献します`cnt = m^t`のコピー`base`。 
4. ペアを保存する`(base, cnt)`。 
5. 以前に保存されたペアが同じである場合`base`、新しいペアを作成する代わりに、カウントを加算します。 

これは、同じベースを持つ隣接するブロックが同じ拡張された値の連続したコピーを表すため、機能します。 
6. 2 番目のアレイに対して同じ圧縮プロセスを繰り返します。 
7. 結果として得られる 2 つのペアのシーケンスを比較します。 
8. シーケンスが同一の場合は、次のように出力します。`Yes`。 それ以外の場合は印刷します`No`。 

### なぜ効果があるのか

 あらゆる要素について$x$、値$$base = \frac{x}{m^t}$$どちらの操作でも変更できません。 

コンバートの分割$$(base,m^t)$$の中へ$m$のコピー$$(base,m^{t-1}),$$一方、マージでは逆の変換が実行されます。 

したがって、すべての操作で基本値の展開されたシーケンスが保存されます。 唯一の自由は、基本値の多重度の合計をどのように要素にグループ化するかです。 

隣接する等しい基数を 1 つのカウントに圧縮した後、正規表現が得られます。 2 つの配列は、これらの正規表現が同一である場合にのみ、相互に到達可能です。 アルゴリズムはこの表現を正確に計算し、結果を比較します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def normalize(arr, m):
    res = []

    for x in arr:
        base = x
        cnt = 1

        while base % m == 0:
            base //= m
            cnt *= m

        if res and res[-1][0] == base:
            res[-1][1] += cnt
        else:
            res.append([base, cnt])

    return res

def solve():
    t = int(input())

    ans = []

    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))

        k = int(input())
        b = list(map(int, input().split()))

        na = normalize(a, m)
        nb = normalize(b, m)

        ans.append("Yes" if na == nb else "No")

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```の`normalize`関数は正規表現を構築します。 各数値は割り切れない基本値に減らされ、次の累乗が取り除かれます。$m$多重度数に変換されます。 

微妙な部分は、同じベースを持つ隣接するエントリをマージすることです。 この手順を行わないと、次のような配列が作成されます。`[2,4]`そして`[1,1,1,1,1,1]`同じ展開されたシーケンスを表している場合でも、異なる方法で正規化されます。 

カウントは次のように直接保存されます。$m^t$。 すべての元の値は最大であるため、$10^9$、繰り返される乗算は Python の整数の範囲内に安全に収まります。 

最後の比較は、2 つのペアのリスト間の単純な同等性です。 正規形式が一致すると、必要なすべての分割またはマージ シーケンスが自動的に存在します。
