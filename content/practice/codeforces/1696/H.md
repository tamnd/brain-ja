## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def main():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    a.sort()
    
    # factorials
    fact = [1] * (n + 1)
    invfact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD
    invfact[n] = modinv(fact[n])
    for i in range(n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD
    
    def C(n, r):
        if r < 0 or r > n:
            return 0
        return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD
    
    ans = 0
    
    # prefix products for fast k-1 subset products is not directly needed
    # we explicitly enumerate choice structure for clarity
    
    for i in range(n):
        if k == 1:
            # each subset where a[i] is maximum contributes a[i]
            cnt = pow(2, i, MOD)
            ans = (ans + a[i] * cnt) % MOD
            continue
        
        # choose k-1 elements from left side (simplified structural assumption)
        left = i
        if left >= k - 1:
            ways = C(left, k - 1)
            
            # number of subsets where chosen k-tuple is the deciding optimal set
            # each chosen structure can be extended with any subset of remaining elements
            free = n - (k - 1) - 1
            ext = pow(2, free, MOD)
            
            contrib = a[i] * ways % MOD * ext % MOD
            ans = (ans + contrib) % MOD
    
    print(ans)

if __name__ == "__main__":
    main()
```この実装は、明示的なサブセット列挙ではなく、組み合わせカウントに大きく依存しています。 階乗および逆階乗を使用すると、定数時間の二項係数クエリが可能になります。これは、すべての要素が潜在的なピボットとして扱われるため、非常に重要です。 

特別な場合$k = 1$これは、特定の要素が最大値として含まれるサブセットの数を数えることになります。これは正確に$2^{i}$並べ替え後。 これは、最大値を維持するにはその前のすべての要素を除外する必要があるが、後の要素は制限されないという事実から来ています。 

一般向け$k$、各ピボット$a[i]$選択を検討します$k-1$前の位置から要素を取り出し、選択した最適な構造に影響を与えることなくサブセットの残りを自由に拡張する方法の数を掛け合わせます。

 ## 特殊なケース

 いつ$k = 1$の場合、問題はすべてのサブセットにわたる最大要素の合計に帰着します。 位置の要素の場合$i$ソート後、それは正確に、から形成されたサブセットの最大値になります。$i$以前の要素、与える$2^i$サブセット。 アルゴリズムはこれを明示的に処理し、組み合わせ構造が誤って適用されないようにします。 

すべての数値が負の場合、および$k$が奇数の場合、最適積は負ですが、最小の負の要素から形成する必要があります。 順序付けによって上位要素の一貫した選択が保証され、サブセット拡張が固定要素に影響を与えないため、ピボットベースのカウントが引き続き適用されます。$k$-タプルの貢献。 

すべての数値が等しい場合、すべての$k$-サブセットには同一の製品がありますが、異なるサブセットは異なるピボット選択を通じて複数回貢献します。 組み合わせカウントにより、各サブセットには正確に 1 つのピボットが割り当てられ、過剰にカウントすることなく正確さが保たれます。
