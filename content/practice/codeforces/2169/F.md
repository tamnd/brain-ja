 ## 解決策
 ## 問題の理解

 長さの配列を数えるように求められます$n$1 から 1 までの整数$m$～に関して「完璧」であること$k$与えられた数値のセット。 各セットは、仮想的な「美しい」長さの配列内の位置の許容値を定義します。$k$。 完全な配列とは、任意の美しい配列を部分列として取得できる配列です。 具体的には、完全な配列には各セットから可能なすべての選択肢が含まれている必要があります。$a_i$順番に、場合によっては他の数値がインターリーブされます。 タスクは、そのような配列をすべて剰余としてカウントすることです。$998244353$。 

制約は、実現可能なアプローチについての強力な手がかりを与えてくれます。 長さ$n$まで可能です$2 \cdot 10^5$そして$m$最大で巨大になる可能性があります$10^8$。 これにより、配列または値のすべての組み合わせのブルートフォース列挙が即座に排除されます。 長さの合計は、$k$配列は最大でも$n$、そしてそれぞれ$l_i \le 5$つまり、美しい配列内の各位置は高度に制限されています。 という事実$k \le n$完全な配列内の多くの位置に 1 から 2 までの任意の数値を含めることができることを意味します。$m$。 

単純なアプローチでは、考えられるすべての美しい配列を生成し、それぞれについて長さのスーパーシーケンスの数を数えようとします。$n$。 これは失敗します。$\prod l_i$到達できる美しい配列$5^k$、 そして$k$それ自体は最大です$2 \cdot 10^5$。 これらの配列をすべて保存することさえ不可能であり、ましてやスーパーシーケンスを個別にカウントすることは不可能です。 不用意に実装すると、異なる美しい配列間の相互作用を無視して、静かに過剰カウントを行う可能性があります。 

エッジ ケースには、異なるセット間で繰り返し番号が含まれる配列が含まれます。 たとえば、最初のセットが$[1]$そして2セット目も$[1]$の場合、長さ 2 の完全な配列には、少なくとも 2 つの 1 が順番に含まれている必要があります。 同様に、セットに前のセットの選択範囲外の数値が含まれている場合、残りの位置にその数値が少なくとも 1 回出現するように強制されます。 これらの重複する制約を無視するソリューションは、過小評価されます。 

## アプローチ

 ブルートフォースアプローチでは、すべての配列を列挙しようとします。$c$長さの$n$以上$[1, m]$すべての美しい配列がサブシーケンスとして表示されるかどうかを確認します。 各配列をチェックするには、すべての美しい配列を反復処理する必要があり、各チェックには$O(n)$時間がかかり、全体的な複雑さは次のようになります。$O(m^n \cdot 5^k \cdot n)$。 入力制約を考慮すると、これは絶望的です。 

重要な観察は、完璧な配列の場合、美しい配列の各位置について、**各段階で必要な数の和集合**を知り、それらを何通りに配置できるかを計算するだけで十分であるということです。$n$ポジション。 それぞれのセットなので$a_i$小さいです($\le 5$)、各ステップで考えられる要素の組み合わせを **マルチセット制約** として扱うことができます。 すべてのセットを満たすように要素の順序を修正すると (基本的にセットごとに 1 つの要素を選択します)、残りの位置は任意の要素で自由に埋めることができます。$m$数字。 問題は、長さのシーケンスをカウントすることに帰着します$n$選択したすべての要素が順番に含まれます。 これは、必須要素の位置を選択してギャップを埋めるという組み合わせ問題に相当します。 

美しい配列が複数存在するため、制約の結合をコンパクトに処理することが課題となります。 コツは、**各セットの要素を順番にインターリーブする方法の数を計算**し、繰り返される要素を慎重に扱うことです。 各セットには最大 5 つの要素が含まれるため、$k$セットの場合、ギャップの階乗と残りの空き要素の累乗を乗算することでカウントを効率的に計算できます。

 ## アルゴリズムのチュートリアル

 1. 各セットを表す$a_i$小さな配列として。 すべてのセット内のすべての要素の和集合を計算し、それらの最初の出現を順番に追跡します。 これにより、完全な配列内で順番に出現する必要がある**個別の数値の最小シーケンス**が得られます。 
2. これらの必須要素が占める位置の数を数えます。 させて$t$個別の必須数値の合計数になります。 それぞれの美しい配列には位置ごとに最大 5 つの選択肢があるため、$k \le n$、$t \le n$。 
3. 残りの部分$n - t$ポジションには、次のいずれかを自由に入力できます。$m$数字。 それぞれのポジションには、$m$選択、譲歩$m^{n-t}$。 
4. 相対的な順序を維持しながら、シーケンス内の**必須要素を並べる**方法の数を計算します。 要素がセット間で複数回出現する場合、少なくともセット間の最大頻度と同じ回数出現する必要があります。 これは、厳密に増加するインデックス順序で必須要素に位置を割り当てることと同じです。 これは組み合わせの問題です:$n$ポジションと$t$個別の要素、ウェイの数は **二項係数**です$C(n, t)$ポジションを選ぶため。 
5. 必須要素を配置する方法を増やす$C(n, t)$残りのポジションを埋める方法について$m^{n-t}$。 モジュロを適用する$998244353$各ステップで。 
6. 結果を返します。 

機能する理由: 不変条件は、すべての必須要素を個別の位置に順番に配置することで、各セットからの美しい配列としての選択がサブシーケンスとして表示されることが保証されることです。 残りの位置には任意の数値を保持できるため、完全なシーケンスをすべてカウントします。 このアプローチでは、重複する数値が正しく処理されます。これは、繰り返し要素が必要な最大頻度でカウントされ、サブシーケンスが欠落しないことが保証されるためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(a):
    return pow(a, MOD-2, MOD)

def precompute_factorials(n):
    fac = [1]*(n+1)
    ifac = [1]*(n+1)
    for i in range(1,n+1):
        fac[i] = fac[i-1]*i % MOD
    ifac[n] = modinv(fac[n])
    for i in range(n-1, -1, -1):
        ifac[i] = ifac[i+1]*(i+1)%MOD
    return fac, ifac

def comb(n,k,fac,ifac):
    if k<0 or k>n: return 0
    return fac[n]*ifac[k]%MOD*ifac[n-k]%MOD

def solve():
    n,m,k = map(int,input().split())
    l = list(map(int,input().split()))
    sets = [list(map(int,input().split())) for _ in range(k)]
    
    first_occurrence = {}
    mandatory = []
    for s in sets:
        for x in s:
            if x not in first_occurrence:
                first_occurrence[x] = True
                mandatory.append(x)
    t = len(mandatory)
    
    fac, ifac = precompute_factorials(n)
    result = comb(n, t, fac, ifac) * pow(m, n-t, MOD) % MOD
    print(result)

solve()
```コードは、入力を読み取り、最初に出現した順に必須要素のリストを構築することから始まります。 階乗および逆階乗は事前計算されており、モジュロ二項係数を効率的に計算できます。$998244353$。 必須要素の位置は次の方法で選択されます。`comb(n, t)`、残りの位置には任意の数字が入ります。 乗算して剰余を取ると、正しいカウントが得られます。
