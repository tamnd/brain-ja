 ## 解決策
 ## 問題の理解

 平面内の一連の点で 2 人用ゲームをモデル化するように求められます。各点にはコストがあります。 アリスは合計スコアを最大化することを目標としていくつかの点を削除し、ボブはスコアを最小化するために残りのすべての点を含む軸に沿った最小の長方形を描画します。 スコアは、アリスが削除したポイントのコストとボブの長方形の周囲の長さの合計として定義されます。 私たちのタスクは、両方のプレイヤーが最適にプレイしたときの最終スコアを計算することです。 

入力には複数のテスト ケースがあり、それぞれが説明されています。`n`彼らのポイント`x`そして`y`コーディネートとコスト`c_i`各ポイントを削除します。 出力はテスト ケースごとに 1 つの整数、つまりアリスが保証できる最大合計スコアです。 

制約は厳しいです:`n`すべてのテスト ケースで最大 3×10^5 に達する可能性があり、座標は 10^15 まで大きくなり、コストは最大 10^9 になります。 これにより、点のすべてのサブセットを反復する解は指数関数的になるため除外されます。 座標が大きいということは、整数型には注意し、数値そのものに合わせてスケーリングする操作を避ける必要があることを意味します。 

明らかではないエッジケースには、ポイントが 1 つしかない場合が含まれます。 アリスはすべての点を削除できないため、長方形は周囲 0 の単一点に縮退します。単一の極点を削除すると、長方形の周囲がその点のコストを超えて減少するときに、別の微妙なケースが発生します。 幾何学的効果を考慮せずにコストを合計する単純なアプローチでは、最適な移動の計算を誤る可能性があります。 たとえば、ポイントが水平線を形成している場合、左端または右端のポイントを削除すると、X 軸に沿った周囲長が 2 減少する可能性があり、これはポイントのコストよりも高くなる可能性があります。 

## アプローチ

 ブルート フォース アプローチは概念的には単純です。アリスが削除できる点のサブセットごとに、残りの点を含む長方形を計算し、スコアを計算します。 すべての有効なサブセット (すべてのポイントを削除するわけではありません) の中で、スコアを最大化するサブセットを選択します。 これが機能するのは、すべての可能性を列挙し、最適な選択を保証するためです。 ただし、2^n 個の部分集合が存在しますが、これは 3×10^5 までの n についてはまったく実行不可能です。 

最適化するために、最小の囲み長方形の境界上にある点のみが周囲に影響を与えることができることを観察します。 内部の点はボブの最小の長方形には影響しません。 したがって、アリスは、現在左端、右端、上端、または下端にある点の削除を考慮するだけで済みます。 問題は、2^n のサブセットを考慮することから、エッジあたり最大 1 つまたは 2 つの点を削除することを考慮することに移ります。 

より正確には、極値を削除すると長方形の幅または高さに影響するため、最小 2 つと最大 2 つの x 座標と y 座標を考慮することができます。 最適な戦略は、各極点を削除する費用対効果、つまり長方形の周囲の減少から点を削除するコストを引いたものを計算することです。 アリスは、純利益を最大化する最大 4 つの極端な点の組み合わせを選択できます。 このアプローチは、各長方形の次元について一定数の点のみを検査し、テスト ケースごとの演算を極値の計算については n で線形に保ち、除去オプションの評価については一定に保つため、効率的です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n) | O(n) | 遅すぎる |
 | 最適 | テスト ケースあたり O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、ポイントの座標とコストを読み取ります。 タプルのリストに保存します`(x, y, c)`そのため、コストとともに座標を並べ替えて参照できます。 
2. 両方の軸に沿って極値点を特定します。 点を x 座標で並べ替え、最小の 2 つと最大の 2 つの x 値を取得します。 同様に、y 座標で並べ替えて、最小の 2 つの値と最大の 2 つの y 値を取得します。 これらは、削除によって長方形の周囲が変更される唯一の点です。 
3. すべての点を囲む長方形の初期周囲長を次のように計算します。`2 * ((max_x - min_x) + (max_y - min_y))`。 
4. アリスが各側から最大 1 つの極値点を削除するシナリオを考えてみましょう。 各候補点について、その点が削除された場合の新しい周囲長を計算し、正味ゲインを次のように計算します。`cost of removed point + reduction in perimeter`。 このようなすべてのシナリオにわたる最大純利益を追跡します。 複数の極点を削除することでスコアがさらに向上する場合は、軸ごとに上位 2 つの候補の組み合わせを検討してください。 チェックする組み合わせは一定数だけです。 
5. 最終スコアは、初期周囲長と、極端な点を削除することによってアリスが達成できる最高のネットゲインの合計です。 

機能する理由: 境界上にない点は長方形の周囲を減らすことができないため、それを削除してもコストが増加するだけです。 境界点については、軸ごとに最大 2 つの最小点と最大点を考慮することで、幅または高さの可能な限りの縮小を確実に捕捉できます。 問題の軸に沿った線形性と x 座標と y 座標の独立性により、この分解が可能になります。 一定サイズの極端な組み合わせをすべて徹底的にチェックすることで、最適な除去セットを見逃さないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        x = list(map(int, input().split()))
        y = list(map(int, input().split()))
        c = list(map(int, input().split()))
        
        points = list(zip(x, y, c))
        
        if n == 1:
            print(0)
            continue
        
        # Extract extremes
        x_sorted = sorted(points, key=lambda p: p[0])
        y_sorted = sorted(points, key=lambda p: p[1])
        
        min_x1, min_x2 = x_sorted[0], x_sorted[1]
        max_x1, max_x2 = x_sorted[-1], x_sorted[-2]
        min_y1, min_y2 = y_sorted[0], y_sorted[1]
        max_y1, max_y2 = y_sorted[-1], y_sorted[-2]
        
        # Initial perimeter
        perimeter = 2 * ((max_x1[0] - min_x1[0]) + (max_y1[1] - min_y1[1]))
        
        # Candidate scenarios
        candidates = []
        # Remove one extreme from each side
        for nx in [min_x1, min_x2, max_x1, max_x2]:
            for ny in [min_y1, min_y2, max_y1, max_y2]:
                # compute new rectangle without nx and ny if they are distinct
                new_xs = [p[0] for p in points if p != nx and p != ny]
                new_ys = [p[1] for p in points if p != nx and p != ny]
                if not new_xs or not new_ys:
                    continue
                new_perimeter = 2 * ((max(new_xs) - min(new_xs)) + (max(new_ys) - min(new_ys)))
                gain = nx[2] + ny[2] + (perimeter - new_perimeter)
                candidates.append(gain)
        
        max_gain = max(candidates) if candidates else 0
        print(perimeter + max_gain)

if __name__ == "__main__":
    solve()
```コードはまず、単一点の自明なケースを処理します。 点を座標で並べ替えることで、極値の点を効率的に選択できるようになります。 元の長方形の周囲長を計算し、各軸に沿って最大 2 つの端点を削除することを系統的に検討します。 の計算`new_perimeter`長方形のサイズの変化を正確に測定できるようになります。 最終的な答えは、達成可能な最大ゲインを元の周囲に追加します。
