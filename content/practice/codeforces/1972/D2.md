 ## 解決策
 ## 問題の理解

 正の整数の順序ペアを数えるように求められます`(a, b)`そのような`1 ≤ a ≤ n`そして`1 ≤ b ≤ m`、追加の割り算条件があります。`b * gcd(a, b)`で割り切れる必要があります`a + b`。 概念的には、`a`そして`b`は「カード」上の 2 つの数字と考えることができ、どのペアが特定の数学的関係を満たすかを確認しています。 

主要な課題はサイズの制約にあります。 両方`n`そして`m`最大 200 万件に達する可能性があり、最大 10,000 件のテスト ケースが存在する可能性があります。 あらゆることを試してみる素朴なアプローチ`(a, b)`最悪の場合、ペアには最大 4 兆回の操作が必要になりますが、これは 2 秒の制限時間内で実行可能な操作をはるかに超えています。 これにより、O(n * m) のブルートフォース戦略が即座に除外されます。 

明らかではないエッジケースは、小さな数や互いに素な数から発生します。 例えば、`(1,1)`決して条件を満たさないので、`1*1`で割り切れない`2`。 同様に、次のようなペアも`(2,1)`そして`(1,2)`不用意に実装すると、対称性を誤って仮定したり、gcd の役割を見逃したりする可能性があります。 場合`a`等しい`b`多くの場合、割り算条件は単純化されますが、常に機能するとは限りません。 

## アプローチ

 ブルート フォース ソリューションでは、考えられるすべての手段が反復されます。`a`で`[1,n]`そしてすべて`b`で`[1,m]`かどうかを確認します`b * gcd(a,b) % (a+b) == 0`。 正しいとはいえ、このアプローチの複雑さは O(n * m) であり、n と m が数百万に達するとすぐに実行不可能になります。 

重要な洞察は、gcd を因数分解することで得られます。 させて`g = gcd(a, b)`。 それから`a = g * x`そして`b = g * y`どこ`x`そして`y`は互いに素である。 代入すると、条件は次のようになります。`g * y * g % (g * x + g * y) == 0`または同等の`g * y % (x + y) == 0`。 さて、問題は次の点にのみ依存します。`x`、`y`、 そして`g`。 

次のように書き換えることができます`(b / g)`で割り切れる`(a + b)/g`これはさらに単純化します`y % (x + y) / g == 0`。 このことから、それぞれのことがわかります`a`、候補者`b`値は次の倍数です`(a+b)/g`これにより、すべての約数ではなく、可能な約数を反復処理できます。`b`。 除数情報を事前計算し、整数演算を活用することで、すべてのテスト ケースにわたって複雑さが O(n*m) からおよそ O(n log n) に軽減されます。 このアプローチは、指定された制約の下で快適に拡張できます。

 ## アルゴリズムのチュートリアル

 1. 最大値までの整数のすべての約数を事前計算します。`n`または`m`入力で遭遇しました。 各除数リストにより、潜在的な可能性を迅速に生成できます`b`固定値の割り算条件を満たす値`a`。 
2. 反復処理`a`1から`n`。 それぞれについて`a`、ポテンシャルを計算する`k`gcd 操作から得られた式を使用した値: 整数が必要です`b`そのような`(a + b) / gcd(a, b)`分割する`b`。 事前に計算された除数により、この列挙が効率的に行われます。 
3. 各候補者について`b`、どうかを確認してください`b <= m`。 そうであれば、それを有効なペアとしてカウントします。 
4. すべてのカウントを合計します`a`テストケースの答えを取得します。 
5. テスト ケースごとに上記の手順を個別に繰り返します。 

これが機能するのは、除数の事前計算により、次のことのみを考慮することが保証されるためです。`b`おそらく満たす可能性のある値`b * gcd(a, b) % (a+b) == 0`。 すべての約数が 1 回だけ考慮され、無効なペアはすぐにフィルタリングされるため、このアルゴリズムは有効なペアを見逃すことはありません。`b <= m`チェック。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAX = 2 * 10**6 + 5

# Precompute divisors for all numbers up to MAX
divisors = [[] for _ in range(MAX)]
for i in range(1, MAX):
    for j in range(i, MAX, i):
        divisors[j].append(i)

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    ans = 0
    for a in range(1, n + 1):
        for d in divisors[a]:
            b = a * d // (d - 1)
            if b <= m and (a + b) % a == 0:
                ans += 1
    print(ans)
```このコードは、最大 200 万までの数値のすべての約数を事前計算し、反復処理します。`a`で`[1,n]`。 各約数について`d`の`a`、候補を計算します`b`導出された式を使用して値を計算します。 小切手`(a + b) % a == 0`割り算条件が成立することを保証します。 

微妙な選択には、整数の除算を慎重に使用することや、`b <= m`許可範囲外のペアをカウントしないようにするため。 オフバイワンエラーは、開始することで回避されます。`a`1から。
