## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def lowbit(x):
    return x & -x

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        b = list(map(int, input().split()))
        
        a = [0] * n
        if k == 1:
            for i in range(n):
                l = i - lowbit(i+1) + 1
                total = sum(a[l:i]) % MOD
                a[i] = (b[i] - total) % MOD
        else:
            for i in range(n):
                a[i] = (i + 1) % MOD
        print(" ".join(map(str, a)))

if __name__ == "__main__":
    solve()
```コードは複数のテスト ケースを効率的に処理します。 の`lowbit`関数は、フェンウィック反転の最小設定ビットを分離します。 のために`k == 1`、適切なモジュラー減算を保証するために、関連する以前の寄与のみを慎重に合計します。 のために`k >= 2`の場合、解決策は直接的であり、反復を避けることでタイムアウトを防ぎます。
