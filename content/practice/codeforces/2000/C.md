 ## 解決策
 ## 問題の理解

 この問題では、文字列が数値テンプレートと一致するかどうかを確認するように求められます。 テンプレートは整数の配列であり、同じ数値が文字列内の同じ文字に対応し、同じ文字が同じ数値に対応する必要があります。 言い換えれば、配列の個別の要素と文字列の個別の文字の間には 1 対 1 のマッピングが必要です。 各テスト ケースは数値テンプレートと文字列のセットを提供し、各文字列がこの対応関係を満たすかどうかを判断する必要があります。 

この制約により、すべてのテスト ケースにわたる配列の長さの合計と文字列の長さの合計が最大 200,000 であることがわかります。 これは、各要素または文字を線形時間で処理するソリューションが必要であることを意味します。 文字列の長さに二次計算量があるソリューションは遅すぎます。 エッジ ケースには、数字が繰り返される配列、文字が繰り返される文字列、単一要素の配列、または負の数が含まれる配列が含まれます。 素朴なアプローチでは、2 つの文字が同じ数字にマッピングされたり、2 つの数字が同じ文字にマッピングされたりする不一致を見逃してしまう可能性があります。 

たとえば、配列の場合`[3,5,2,1,3]`と文字列`"abfda"`、`3`2 回表示され、次のようにマッピングされます。`'a'`どちらの場合も、他のすべての数字は個別の文字にマップされるため、一致します。 しかし`"afbfa"`失敗する理由`'f'`両方に対応する位置に表示されます`5`そして`1`、1対1のマッピングが壊れます。 

## アプローチ

 ブルートフォース手法は、各文字列の数字と文字の間で考えられるすべてのマッピングを試みることですが、マッピングの順列の数は、個別の数字または文字の数に応じて指数関数的に増加するため、これは明らかに実行不可能です。 重要な洞察は、マッピングを試す必要がないということです。 一貫性をチェックする必要があるだけです。 2 つの辞書を維持できます。1 つは数値を文字にマッピングし、もう 1 つは文字を数値にマッピングします。 テンプレートと文字列を同時に反復処理しながら、すべてのマッピングが以前のマッピングと一貫していることを確認します。 不一致が発生した場合、文字列はテンプレートと一致しません。 矛盾なく最後まで到達すれば一致します。 これは、文字列の長さに比例して線形時間で機能します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k!) ここで、 k = 個別の数値の数 | O(k) | 遅すぎる |
 | マッピングチェック | 文字列ごとに O(n) | 文字列ごとに O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして配列`a`。 
3. 文字列の数を読み取る`m`。 
4. 各文字列について`s`:

 ａ． 長さの場合、`s`一致しません`n`、すぐに出力`"NO"`。 

b. 2 つの空の辞書を初期化します。`num_to_char`数値を文字にマッピングするため、および`char_to_num`文字から数字へ。 

c. 各インデックスを反復処理する`i`から`0`に`n-1`。 現在の番号については`a[i]`そして性格`s[i]`：

私。 もし`a[i]`すでにマッピングが含まれています`num_to_char`、一致していることを確認してください`s[i]`。 そうでない場合は出力`"NO"`この文字列のチェックを停止します。 

ii. もし`s[i]`すでにマッピングが含まれています`char_to_num`、一致していることを確認してください`a[i]`。 そうでない場合は出力`"NO"`そしてやめてください。 

iii. 両方のマッピングに一貫性があるか新しい場合は、辞書を更新します。 

d. ループが矛盾なく完了した場合、出力`"YES"`。 

**機能する理由**: 辞書は、各数字が正確に 1 つの文字にマッピングされ、各文字が正確に 1 つの数字にマッピングされるという不変条件を維持します。 この不変条件に違反すると、直ちに不一致が特定され、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    m = int(input())
    for _ in range(m):
        s = input().strip()
        if len(s) != n:
            print("NO")
            continue
        
        num_to_char = {}
        char_to_num = {}
        valid = True
        for ai, ci in zip(a, s):
            if ai in num_to_char and num_to_char[ai] != ci:
                valid = False
                break
            if ci in char_to_num and char_to_num[ci] != ai:
                valid = False
                break
            num_to_char[ai] = ci
            char_to_num[ci] = ai
        print("YES" if valid else "NO")
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`そして、各文字列を反復処理し、2 つの辞書を使用してマッピングの一貫性をチェックします。 の使用`zip(a, s)`対応する位置を直接比較することが保証されます。 辞書を使用すると、スキャンの繰り返しが回避され、文字列ごとの直線的な複雑さが維持されます。

                    break

                    valid = False
                    break
                num_to_char[ai] = ci
                char_to_num[ci] = ai
            output.append("YES" if valid else "NO")
    return "\n".join(output)

## 特殊なケース

 要素が 1 つだけの配列の場合、任意の 1 文字の文字列が一致し、次の結果が得られます。`"YES"`。 長さが 1 で文字列が 1 より長い配列の場合、出力は次のようになります。`"NO"`。 文字が複数の数値にマッピングされている文字列の場合、コードは不一致を即座に検出し、出力します。`"NO"`。 Python 辞書は任意のキーを効率的に処理するため、負の数と大きな数は他の整数と同じように扱われます。 このソリューションは、そのようなすべてのエッジケースを正しく処理します。
