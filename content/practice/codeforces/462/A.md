 ## 解決策
 ## 問題の理解

 _n_×_n_ ボードが与えられ、各セルには「x」または「o」が含まれます。 このタスクは、すべてのセルのローカル プロパティをチェックすることです。つまり、「o」を含む直角に隣接するセルの数が偶数であるかどうかです。 2 つのセルが 1 辺を共有している場合、これらのセルは隣接していることになります。そのため、各内側セルには最大 4 つの隣接セルがあり、エッジ セルには 3 つまたは 2 つ、コーナー セルには 2 つの隣接セルがあります。 すべてのセルがこのプロパティを満たしている場合、出力は「YES」、そうでない場合は「NO」です。 

入力サイズの制約は小さく、_n_ ≤ 100 です。これは、パフォーマンスを気にせずにすべてのセルとその隣接セルを直接チェックできることを意味するため、重要です。 100×100 ボードの最悪のケースでも、最大でも 100×100×4 = 40,000 回の操作が実行されますが、これは 1 秒の制限時間としては無視できる程度です。 

明らかではないエッジ ケースには、隣接するセルが存在しない非常に小さなボード (n=1) や、境界セルのみに「o」が付いている構成が含まれます。 たとえば、単一の「o」を持つ 1×1 ボードは、隣接するボードが 0 つあり、偶数であるため、「YES」を出力するはずです。 もう 1 つのエッジ ケースは、すべてのセルに「o」が含まれる場合です。 各内側セルには 4 つの隣接セルがあり、これは偶数ですが、隅のセルには 2 つの隣接セルしかなく、依然として偶数であるため、ボードは有効です。 

## アプローチ

 ブルート フォースのアプローチは簡単です。すべてのセルを反復処理し、隣接するセルの「o」の数を数えます。 いずれかのセルのカウントが奇数の場合は、すぐに「NO」を返します。 それ以外の場合は、すべてのセルをチェックした後、「YES」を返します。 これが機能するのは、基板が十分小さいため、隣接するものを直接検査できるためです。 

ブルートフォースを形式化できます。セル (i,j) について、(i-1,j)、(i+1,j)、(i,j-1)、(i,j+1) が存在するかどうかを確認します。 各セルの近傍をカウントすると O(1) となり、n² 個のセルがあるため、合計時間は O(n²) になります。 ここではこれは許容されます。 これより迅速な漸近アプローチは必要ありません。 問題の制約により、ブルート フォースが正確かつ効率的になります。 重要な洞察は、隣接関係が厳密にローカルであるため、グラフの走査のようなグローバルなことを行う必要がないことを認識することです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n²) | 承認済み |
 | 最適 | O(n²) | O(n²) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数 n を読み取り、n 文字の n 行をボードを表す 2D リストに読み取ります。 これにより、行および列のインデックスによって任意のセルに直接アクセスできるようになります。 
2. 行と列に対して 2 つのネストされたループを使用して、ボード内の各セルを反復処理します。 
3. 位置 (i,j) の各セルについて、カウンターをゼロに初期化します。 このカウンタは、4 つの可能な近傍のうち、「o」を含むものがいくつあるかを追跡します。 
4. それぞれの近傍を確認します: 上 (i-1,j)、下 (i+1,j)、左 (i,j-1)、右 (i,j+1)。 インデックスがボードの範囲内にある場合にのみ、近隣をチェックします。 近隣に「o」が含まれている場合、カウンタをインクリメントします。 
5. 現在のセルの隣接セルをカウントした後、カウンタが奇数かどうかを確認します。 奇数の場合は、「NO」を出力して終了します。 これが機能するのは、1 つの違反でボード全体を無効にするのに十分であるためです。 
6. 奇数のカウントを持つセルが見つからずにループが完了した場合は、「YES」を出力します。 すべてのセルが偶数隣接条件を満たしています。 

機能する理由: このアルゴリズムはすべてのセルを 1 回だけ検査し、そのすぐ隣のセルのみを使用して対象のプロパティを評価します。 問題は局所的であり、関連する情報はすべてセルの隣接する位置にあるため、隠れた相互作用はありません。 奇数の「o」隣接セルを持つセルはすぐに検出され、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
board = [input().strip() for _ in range(n)]

for i in range(n):
    for j in range(n):
        count = 0
        if i > 0 and board[i-1][j] == 'o':
            count += 1
        if i < n-1 and board[i+1][j] == 'o':
            count += 1
        if j > 0 and board[i][j-1] == 'o':
            count += 1
        if j < n-1 and board[i][j+1] == 'o':
            count += 1
        if count % 2 != 0:
            print("NO")
            sys.exit()
print("YES")
```このソリューションはボードを効率的に読み取ります。`sys.stdin.readline`～によるオーバーヘッドを避けるため`input()`。 インデックス エラーを防ぐために、近傍にアクセスする前に境界を明示的にチェックします。 使用する`sys.exit()`違反が見つかるとすぐに計算を停止します。これは、ループ後にフラグをチェックするよりもわずかに効率的です。 近傍を直接カウントすることで余分なデータ構造が回避され、空間の複雑さが最小限に抑えられます。
