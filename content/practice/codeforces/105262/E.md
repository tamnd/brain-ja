 ## 解決策
 ## 問題の理解

 ノード 1 がルートとして固定されたルート付きツリーが与えられます。 2 人のプレイヤーがシークレット パートナーから順番に交互に動きます。 移動は、ルート以外のノードを選択し、そのノードをそのサブツリー内のすべてのノードとともに削除することで構成されます。 最後に有効な手を行ったプレイヤーが勝ち、つまり、ルート以外のノードが残っていない位置に直面したプレイヤーが負けます。 

より構造的な観点から見ると、移動するたびにルート化された 1 つのサブツリー全体が崩壊し、ルート自体を選択したり削除したりすることはできません。 直接的または以前の削除によって間接的に、ルートを除くすべてのノードが削除されると、ゲームは終了します。 

この制約により、すべてのテスト ケースで最大 4 · 10^5 ノードが許可され、各手の後のゲーム状態をシミュレートしようとする戦略が除外されます。 サブツリーを再計算したり、移動ごとに動的構造を更新したりする単一の単純なシミュレーションでさえ、最悪のケースでは演算数が二次関数的に増加する可能性があるため、すでに遅すぎます。 意図したソリューションでは、ゲームをテスト ケースごとに線形時間で計算できるプロパティに削減する必要があります。理想的には、非常に大まかな方法​​でツリーの構造にのみ依存するものです。 

局所的に動きを考えると、微妙な問題が現れます。 ツリーの奥にあるノードはそれ自体のサブツリーのみを削除しますが、上位のノードはツリーの大部分を削除します。 「大きな」手を打つことが有利なのか、それとも最適なプレイが最小限の除去を好むのかは明らかではありません。 この選択の解像度がゲーム全体の結果を決定します。 

## アプローチ

 ゲームについて直接的に考える方法は、ツリー状態における標準的な公平なゲームとして扱うことです。 各位置はルート 1 を持つ残りのフォレストであり、移動するたびにサブツリー全体が削除されます。 考えられるすべてのルート付きフォレストに Sprague-Grundy 値を割り当てようとすることもできますが、サブツリーを削除すると構造がグローバルに変更され、独立したサブゲームにきれいに分解されないため、状態空間は膨大になります。 Grundy 値を明示的に計算しようとすると、最悪の場合、指数関数的に多くの構成を調査する必要があり、すぐに実行不可能になります。 

重要な単純化は、動きに関して実際に何が重要かを観察することから生まれます。 移動するたびに少なくとも 1 つのノードが削除され、選択した頂点によってはさらに多くのノードが削除される場合があります。 重要な構造上の観察は、必要以上に削除しても将来の追加の手を作成することはなく、オプションを削除するだけであるということです。 消えるノードはそれ自体が潜在的な動きであるため、大規模な削除は両方のプレイヤーが利用できる将来の決定の数を厳密に減らします。 

これにより、問題は単調なプロセスに変わります。消費される唯一のリソースは取り外し可能なノードのセットであり、移動するたびにそのうちの少なくとも 1 つが消費されます。 両方のプレイヤーが最適に行動する場合、どちらのプレイヤーも必要以上に削除する動機はありません。そうすることでゲームが短縮され、後で自分が移動する回数が減るだけだからです。 

これは中心的な削​​減につながります。最適なプレイでは、すべての手がちょうど 1 つのノードを削除すると想定できます。 これが受け入れられると、ゲーム全体の長さが決定的になります。 取り外し可能なノードが正確に n − 1 個あるため (ルートを除くすべて)、ゲームはツリーの形状に関係なく正確に n − 1 移動続きます。 したがって、勝者は純粋に n − 1 のパリティによって決まります。

 ## アルゴリズムのチュートリアル

 このソリューションでは、動きをシミュレートする必要はまったくありません。 ツリーのサイズのみを抽出します。

1. テスト ケースのノード数 n を読み取ります。 最適なプレイ動作を受け入れるとツリー構造は無関係になるため、これによって答えが完全に決まります。 
2. すべての手が少なくとも 1 つのノードを削除することを観察します。最適なプレイでは、ちょうど 1 つのノードを削除する動きに注意を制限できます。 その正当性は、余分なノードを削除しても、ゲームを延長する可能性がある将来の手を排除するだけであるということです。 
3. ゲームは n − 1 個の非ルート ノードから始まり、各手はそのうちの 1 つだけを削除するものとして扱うことができるため、最適なプレイ シーケンスの合計手数は n − 1 に固定されます。 
4. n − 1 のパリティをチェックして勝者を決定します。n − 1 が奇数の場合、最初のプレイヤー (シークレット パートナー) が最後の手を打って勝ちます。 それ以外の場合は、2 番目のプレーヤー (エダード) が勝ちます。 

### なぜ効果があるのか

 解決策の背後にある不変条件は、唯一の関連する量が残りの非ルート ノードの数であるということです。 すべての正当な動きはこのカウントを少なくとも 1 だけ厳密に減らし、それを 2 つ以上減らす動きは、最適な結果を変えることなく、削除されたノード上の一連の動きに置き換えることができます。 この等価性は、すべての最適なプレイを、ターンごとに 1 つのノードが正確に削除されるシーケンスに変換できることを意味し、手番の数を最大化しながらターン順序と勝者を維持します。 最終状態は固定されており、戦略とは独立しているため、取り外し可能なノードの初期数のパリティによって勝者が決まります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        # read and discard edges
        for _ in range(n - 1):
            input()
        # game reduces to parity of n - 1 moves
        if (n - 1) % 2 == 1:
            out.append("The Secret Partner")
        else:
            out.append("Eddard")
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```コードには削減が直接反映されます。 すべてのエッジは入力を消費するために読み取り専用です。 それらは計算では何の役割も果たしません。 テスト ケースごとに意味のある唯一の値は n であり、決定は n − 1 に対する単純なパリティ チェックで行われます。 

ここでよくある間違いは、隣接リストを構築したり、サブツリー サイズを計算しようとしたりすることです。これは不必要なオーバーヘッドであり、完全な制約の下では TLE の危険性があります。 

## 実用的な例

 n = 4 の小さなツリーを考えます。ルート以外のノードが 3 つあるため、ゲームの長さは 3 手になります。 シークレットパートナーがスタートしてから、1手目と3手目を取ったので勝ちです。 

| ターン | 残りの非ルート ノード | アクションの解釈 |
 | --- | --- | --- |
 | 1 (シークレットパートナー) | 2 | 1 つのノードを削除します |
 | 2 (エダード) | 1 | 1 つのノードを削除します |
 | 3 (シークレットパートナー) | 0 | 最後のノードを削除します |

 これは、奇数 n − 1 の場合、最初のプレーヤーが最後の手を打つことを確認します。 

次に、n = 5 について考えます。非ルート ノードが 4 つあるため、4 つの移動が発生します。 

| ターン | 残りの非ルート ノード | アクションの解釈 |
 | --- | --- | --- |
 | 1 (シークレットパートナー) | 3 | 1 つのノードを削除します |
 | 2 (エダード) | 2 | 1 つのノードを削除します |
 | 3 (シークレットパートナー) | 1 | 1 つのノードを削除します |
 | 4 (エダード) | 0 | 最後のノードを削除します |

 ここで後手のプレーヤーが最後の動きをしたので、彼らが勝ちます。 

これらのトレースは、ツリーの構造はシーケンスの長さに影響せず、ノードの初期数のみが影響することを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

 | スペース | O(1) おまけ | カウンタと出力ストレージのみが使用されます。

 ## 特殊なケース

 単一ノードのケースでは、移動が存在しない境界が強調表示されます。 n = 1 の場合、有効な選択がないため、シークレット パートナーは即座に負けます。 この式では n − 1 = 0 が得られ、これは偶数であり、正しく 2 番目のプレイヤーの勝利となります。 

n = 2 の場合、正確に 1 つの手が存在します。 シークレット パートナーは唯一の非ルート ノードを削除し、ルートを残してゲームを終了するため、彼らが勝ちます。 パリティ ルールは、n − 1 = 1、奇数を与え、この結果と一致します。 

スターのような大きなツリーでは、すべてのノードがルートの直接の子であるという事実は何も変わりません。 原則として、移動によってさまざまな数のノードを削除できますが、最適なプレイは単一ノードの削除に限定され、結果は削除可能なノードの合計数が奇数か偶数かによってのみ決まります。
