 ## 解決策
 ## 問題の理解

 数直線上の個別の点のソートされたリストが与えられます。 タスクは、これらすべての点を最大でも次のコマンドを使用してカバーすることです。$k$セグメント。セグメントは任意の間隔にすることができます。$[a,b]$そのコストは幾何学的な長さです$|a-b|$。 点が端点の間にある場合、セグメントはその点をカバーします。 目標は、選択したすべてのセグメントの合計の長さを最小限に抑えることであり、すべてのセグメントの最適な値を報告する必要があります。$k$1から$n$。 

問題を再構成する有効な方法は、ポイントをグループ化することを考えることです。 連続するポイントのグループをカバーすることにした場合$x_l, x_{l+1}, \dots, x_r$1 つのセグメントの場合、最も安価なセグメントは正確に$[x_l, x_r]$、そのコストは$x_r - x_l$。 非連続点にまたがるセグメントはカバレッジを失わずに短縮できるため、最適なソリューションでは常に、ソートされた配列の連続ブロックをカバーするセグメントが使用されます。 

制約により、最大で$2 \times 10^5$すべてのパーティションを試したり、使用したりするソリューションは直ちに除外されます。$O(n^2)$動的プログラミングは直接遷移します。 線形に近いものが必要です。$O(n \log n)$、そしてすべてに対する答えも必要です$k$、ごとに再計算するのではなく、グローバル構造を一度構築することを提案します。$k$。 

と考えると微妙な点が見えてきます。$k=1$。 唯一のセグメントがすべてのポイントをカバーする必要があるため、答えは次のようになります。$x_n - x_1$。 大型の場合$k$、各セグメント内のスパンに対してのみ支払うことで、配列を複数のセグメントに分割することが事実上許可されます。 

素朴なアプローチでは、配列を次のように分割するあらゆる方法を試みる可能性があります。$k$それぞれのグループ$k$、しかしそれは組み合わせ爆発につながります。 単一の計算でも$k$- DP コストを考慮して最適に分割$O(n^2 k)$または$O(n^2)$、大きすぎます。 

## アプローチ

 重要な点は、セグメントを分割すると、非常に構造化された方法でコストが削減されるということです。 すべてのポイントを 1 つのセグメントでカバーすると、コストは次のようになります。$x_n - x_1$。 間に分割を挿入するとします。$x_i$そして$x_{i+1}$。 1 つのセグメントの代わりに$[x_1, x_n]$、現在 2 つのセグメントを使用しています$[x_1, x_i]$そして$[x_{i+1}, x_n]$。 新たなコストは、$$(x_i - x_1) + (x_n - x_{i+1})$$に比べ$$x_n - x_1.$$違いは$$(x_n - x_1) - [(x_i - x_1) + (x_n - x_{i+1})] = x_{i+1} - x_i.$$これは、隣接するポイント間のあらゆる可能な分割には、それらの間のギャップに等しい「節約」があることを意味します。 分割すると、セグメントがまたがることがなくなるため、総コストからそのギャップが削除されます。 

したがって、問題は次と同等になります: コストから始めます$x_n - x_1$まで挿入できます。$k-1$分割します。 それぞれの位置で分割$i$の利益を与えます$x_{i+1} - x_i$。 総コストを最小限に抑えるには、選択したゲインの合計を最大化する必要があります。これは、最大のギャップを選択することによって達成されます。 

したがって、それぞれについて$k$、最適な戦略は、$k-1$最大の隣接ギャップを計算し、その合計をから引きます。$x_n - x_1$。 

これにより、問題はギャップを 1 回ソートしてプレフィックスの合計を計算するだけになり、その後、各答えは単純な減算になります。

 ## アルゴリズムのチュートリアル

 1. 隣接するすべての差分を計算する$d_i = x_{i+1} - x_i$のために$i = 1$に$n-1$。 

これらは、これら 2 つのポイントの間で分割することを決定した場合に得られる節約を表します。分割すると、そのギャップが 1 つのセグメントでカバーされなくなるためです。 
2. 配列をソートする$d$降順で。 

各分割は独立しており、全体の改善に相加的に貢献するため、最初に最大の節約を優先したいと考えています。 
3. ソートされたギャップに対してプレフィックス合計配列を構築します。`pref[i]`最大のものの合計です$i$ギャップ。 

これにより、あらゆることに答えることができます$k$合計を再計算することなく効率的に実行できます。 
4. 基本コストを次のように初期化します。$x_n - x_1$、これは単一のセグメントですべてをカバーすることに相当します。 
5. それぞれについて$k$1から$n$、出力:$$(x_n - x_1) - \text{pref}[k-1]$$なぜなら使っているから$k$セグメントは正確に挿入することを意味します$k-1$分割します。 

なぜ効果があるのか

 すべての有効なセグメンテーションは、カットが配置されるギャップのサブセットの選択に対応します。 各カットは、隣接するギャップを 1 つだけ除去し、スパニング セグメントに含まれないようにします。 ギャップは独立しており、相互作用しないため、全体的な改善は相加的になります。 したがって、最適解は最大のものを選択することによって得られます。$k-1$これはまさに並べ替えによって保証されるものです。 カットを再配置しても、選択されたギャップのマルチセットは変更されず、どのギャップが含まれるかのみが変更されるため、代替構造ではこれ以上の削減は実現できません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input().strip())
x = list(map(int, input().split()))

if n == 1:
    print(0)
    sys.exit()

gaps = [x[i+1] - x[i] for i in range(n - 1)]
gaps.sort(reverse=True)

pref = [0] * (n)
for i, v in enumerate(gaps, start=1):
    pref[i] = pref[i - 1] + v

base = x[-1] - x[0]

ans = []
for k in range(1, n + 1):
    ans.append(str(base - pref[k - 1]))

print(" ".join(ans))
```この実装では、セグメントの分割からギャップの選択への変換が直接反映されます。 必要な唯一の注意はインデックス作成です。$n-1$ギャップがあるが答えが必要$k-1$したがって、プレフィックス配列は長さを指定して構築されます$n$ゼロのケースを安全に含めるために。 

基本コストは 1 回計算され、すべてのクエリは定数時間の減算となります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    input = _sys.stdin.readline

    n = int(input().strip())
    x = list(map(int, input().split()))

    if n == 1:
        return "0"

    gaps = [x[i+1] - x[i] for i in range(n - 1)]
    gaps.sort(reverse=True)

    pref = [0] * (n)
    for i, v in enumerate(gaps, start=1):
        pref[i] = pref[i - 1] + v

    base = x[-1] - x[0]

    ans = []
    for k in range(1, n + 1):
        ans.append(str(base - pref[k - 1]))

    return " ".join(ans)

# provided samples
assert run("3\n1 2 3\n") == "2 1 0"

# minimum size
assert run("1\n100\n") == "0"

# simple spaced points
assert run("2\n1 10\n") == "9 0"

# all equal gaps
assert run("5\n1 2 3 4 5\n") == "4 3 2 1 0"

# large uneven gaps
assert run("4\n1 2 100 101\n") == "100 1 0 0"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | シングルポイント | 0 | 基本ケースの処理 |
 | 離れた 2 点 | 9 0 | シングルギャップの動作 |
 | 均一な間隔 | 4 3 2 1 0 | 一貫した貪欲な削減 |
 | 混合された大きなギャップ | 100 1 0 0 | ギャップのソートの正確性 |

たとえば、次のように入力します。```

```ギャップ リストは空で、プレフィックスの合計はすべてゼロで、すべての$k$ゼロを返します。 プレフィックス配列のサイズは次のとおりであるため、アルゴリズムは無効なインデックスへのアクセスを試みることはありません。$n$、 そして$k-1$安全な範囲は 0 から 0 です。
