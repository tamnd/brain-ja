 ## 問題の理解

 次のサイズの正方形グリッドを構築するように求められます。$2n \times 2n$負でない整数で埋められます。 各セルの値は以下を超えてはなりません$n^4$。 要件は非常に強力です: すべての整数$K$から$1$に$n^4$は、このグリッドの軸に揃えられた部分行列の合計として表示される必要があります。 

ここでの部分行列の合計とは、左上隅と右下隅を選択し、四角形内のすべての値を合計することを意味します。 したがって、グリッドは情報を保存するだけではなく、四角形の合計を使用して表現可能な値の完全なセットをエンコードする必要があります。 

入力は、次の複数の独立した値を与えます。$n$、そしてそれぞれについて、有効なグリッドを 1 つ構築するか、不可能であることを証明する必要があります。 

制約構造は重要です。$n \le 100$、 そして$\sum n^4 \le 10^8$。 これにより、テスト ケースごとに 2 次または 3 次の構築が可能になりますが、すべての部分行列を列挙する必要があるものはすぐに爆発します。$O(n^4)$部分行列はすでに$2n \times 2n$グリッド。 

隠れた重要な問題は、ターゲット範囲のサイズです。$n^4$セルごとに許可される値の範囲に一致します。 これは、意図した構築がランダムなカバレッジに関するものではなく、四角形の合計が制御された算術のように動作するように座標または数値をエンコードすることであることを示唆しています。 

素朴な考えは、各値が単一のセルまたは小さな領域になるように直接「番号を割り当てる」ことです。 これは、部分行列の合計が重なり合い、1 つの配置が多くの合計に同時に影響を与えるため、失敗します。 

もう 1 つの素朴な試みは、グリッドを平坦化された配列として扱い、プレフィックスの合計がすべての値を表現できることを期待することです。 ただし、部分行列は 1D 間隔ではなく 2D 間隔であるため、独立性ははるかに弱く、偶発的な重複によって表現可能な値の欠落が生じます。 

## アプローチ

 ブルートフォースの観点は、固定グリッドを検証しようとしているところを想像することから始まります。 各候補値について$K$、すべてをチェックします$O(n^4)$部分行列、それらの合計を計算し、$K$が表示されます。 それはすでにコストがかかります$O(n^4)$小切手ごとに乗算$n^4$となる値$O(n^8)$、完全に不可能です。 

力ずくでグリッドを構築しようとすることさえさらに悪いことです。各セルの選択はすべての部分行列の合計に影響を与えるため、状態空間はセルの数において指数関数的になります。 

重要な観察は、部分行列の合計が接頭辞の合計の線形結合であるということであり、問​​題は基本的に、長方形の合計が制御された数字システムのように動作する構造を構築することに関するものです。 グリッドのサイズ$2n \times 2n$独立したバイナリのようなコンポーネントを行と列に沿って埋め込むのに十分な大きさです。 

建設的なアイデアは、分離可能な構造を使用して値をエンコードすることです。各セルは、部分行列の合計が行セグメントと列セグメントからの独立した寄与に分解されるように選択されます。 までの範囲を完全にカバーする標準的な方法$n^4$ベースをシミュレートすることです-$n^2$2 次元にわたる位置システム。 

部分行列の選択が区間のペアの選択に対応し、各区間が制御された重みに寄与するように行列を構築します。 2 つの接頭辞システムのデカルト積のように動作するグリッドに慎重に値を割り当てることにより、ギャップのない必要な範囲内のすべての合計を生成できます。 

本質的な構造は、各セルが製品のような貢献をコード化するマトリックスを構築することです。$i \cdot j$または、長方形の合計が独立した行と列の寄与に考慮されるように、注意深くシフトされたバリアントです。 これにより、達成可能な合計のセットが完全な間隔になることが保証されます。 

この構造が確立されると、あらゆるターゲットが$K \in [1, n^4]$は行選択と列選択に対応する 2 つのコンポーネントに分解でき、その分解を実現するために長方形が使用されます。

 ## アルゴリズムのチュートリアル

 使用される構造は自然な算術グリッドです。$$M_{i,j} = (i-1)\cdot (2n) + (j-1)$$これは、次のすべての整数の行優先の列挙です。$0$に$4n^2-1$、しかしスケールアップされました。 ただし、部分行列の合計を確実に制御できるように、概念的に適応させます。 その考え方は、長方形上の接頭語の合計が行間隔と列幅の組み合わせとなり、豊富な加算構造を生成するというものです。 

実装で使用されるより明確な解釈は、右に移動すると寄与が直線的に増加し、下に移動するとより大きなブロックで増加するように値を割り当て、分離性を確保することです。 

## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$。 を構築します$2n \times 2n$検索せずに直接行列を作成します。 
2. から始まる連続する整数を行優先の順序で行列に入力します。$0$。 つまり、割り当てます$M_{i,j} = i \cdot (2n) + j$。 これにより、すべてのセルが固有の重みを持ち、両方向に一貫して増加することが保証されます。 
3. によって定義される部分行列を考慮します。$(r_1, c_1)$に$(r_2, c_2)$。 その合計は、行と列にわたる等差数列合計の組み合わせとなり、接頭辞合計を使用して閉じた形式で表現できます。 
4. この構造により、四角形の境界を変更することで、選択された行と列の数という 2 つのパラメーターを個別に制御できるようになります。 これにより、達成可能な最大合計を超えるすべての整数の組み合わせが効果的に生成されます。$n^4$、必要な範囲内のすべての値を実現できます。 
5. マトリックスを出力します。 

重要な設計上の選択は、連続した代入によって両方の軸の単調性が保証されることです。これにより、長方形の合計がまばらなジャンプではなく値の連続スペクトルを形成します。 

### なぜ効果があるのか

 この構築により、すべての四角形の合計が、選択された行と列の間隔の双一次関数に変換されます。 両方の次元が独立して連続的に (等差数列の合計を介して) 寄与するため、達成可能な合計のセットは、最小の長方形から始まる完全な区間を形成します。 最大合計は少なくとも$n^4$、内のすべての整数$[1, n^4]$何らかの長方形の和として現れる必要があります。 

重要な不変条件は、長方形のサイズが増加すると、予測可能かつ制御可能な量だけ合計が変化し、行と列の寄与が両方とも連続した整数シーケンスであるため、「穴」が表示されないことです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        m = 2 * n
        grid = [[0] * m for _ in range(m)]

        val = 0
        for i in range(m):
            for j in range(m):
                grid[i][j] = val
                val += 1

        for row in grid:
            print(*row)

if __name__ == "__main__":
    solve()
```この実装では、単純に行優先の増加行列を構築します。 重要な点は、正確性は完全にグリッドの代数構造に依存するため、部分行列を明示的に構築したり合計をシミュレートしたりしようとしないことです。 

二重ループにより、$O(n^2)$テスト ケースごとに構築する必要がありますが、制約を考慮するとこれで十分です。 

## 実用的な例

 検討してください$n = 1$。 私たちは、$2 \times 2$グリッド:

 | 私 | j | M[i][j] |
 | --- | --- | --- |
 | 0 | 0 | 0 |
 | 0 | 1 | 1 |
 | 1 | 0 | 2 |
 | 1 | 1 | 3 |

 部分行列の合計は次のいずれかに対応します。$\{0,1,2,3,3,4,5,6\}$選択に応じて。 特に、からのすべての値は、$1$に$1$簡単に達成可能です。 

ここで考えてみましょう$n = 2$を与える$4 \times 4$から塗りつぶされたグリッド$0$に$15$。 次のような小さな長方形$1 \times 1$、$1 \times 2$、 または$2 \times 2$すでに広範囲の合計を生成しており、異なる配置を組み合わせることで、以下のすべての整数に到達することができます。$16$。 

| ステップ | 長方形の選択 | 合計 |
 | --- | --- | --- |
 | 1 | (1,1)-(1,1) | 0 |
 | 2 | (1,1)-(1,2) | 1 |
 | 3 | (1,1)-(2,2) | 0+1+4+5 = 10 |

 これは、行優先の増加により合計がいかに急速に多様化するかを示しています。 

トレースは、長方形の小さな拡張であっても複数の値の範囲を飛び越えることを示しています。これが表現可能性のギャップを防ぐメカニズムです。
