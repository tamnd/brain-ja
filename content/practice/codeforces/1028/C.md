 ## 解決策
 ## 問題の理解

 2D 整数グリッド上に軸に揃えられた長方形のコレクションが与えられます。 各長方形は左下隅と右上隅によって表され、境界と内部も含まれます。 重要な保証は、いずれかの長方形を削除しても、残りの長方形は少なくとも 1 つの共通点を共有するということです。 

タスクは、少なくとも内部にある整数座標点を見つけることです。$n-1$これらの長方形の。 言い換えれば、「見逃す」ことは最大 1 つの四角形までであり、他のすべての四角形の中に同時に入る必要があります。 

制約は大きく、$n$くらいまで$1.3 \times 10^5$。 これにより、長方形間の二次相互作用が即座に排除されます。 平$O(n^2)$ペアごとの重複推論は、実行可能な限界をはるかに超えています。 私たちは、グローバル制約を増分的に維持したり、線形または線形に近い時間で交差点を再計算したりするソリューションを求めています。 

微妙なエッジ ケースは、答えが 1 つの長方形を除くすべての長方形を満たす必要があるだけであるという事実から生じます。 すべての四角形の素朴な交差は、有効な答えが存在する場合でも失敗する可能性があります。これは、単一の「悪い」四角形によってグローバル交差が空に縮小される可能性があるためです。 

たとえば、2 つの長方形が重なり合い、3 つ目の長方形が交点をわずかにシフトしている 3 つの長方形について考えてみましょう。 

入力:```
3
0 0 2 2
1 1 3 3
100 100 200 200
```3 つすべての交差部分は空ですが、3 番目の長方形を削除すると、最初の 2 つの長方形の間に有効な重複領域が残り、その領域内の任意の点が受け入れられます。 

2 番目の落とし穴は、固定サブセットの交差が機能すると仮定していることです。 この問題では、どの四角形が外れ値であるかはわかりません。そのため、すべてを最初から再計算せずに、暗黙的に各四角形を削除することを「シミュレート」できなければなりません。 

## アプローチ

 強引な発想は自然と条件から始まります。 各長方形を 1 つずつ削除してみると、残りの長方形の交差を計算できます。$n-1$四角形を選択し、それが空でないかどうかを確認します。 長方形の交差の計算は簡単です。すべての左側の x 座標の最大値、すべての右側の x 座標の最小値を取得し、y についても同様です。 

削除された四角形ごとにこれを個別に実行すると、$n$再計算。 各再計算ではすべての四角形がスキャンされ、次のようになります。$O(n^2)$トータルオペレーション。 と$n \approx 10^5$、これは遅すぎます。 

重要な観察は、各交差クエリがグローバル極値 (左エッジの最大値と 2 番目の最大値、右エッジの最小値と 2 番目の最小値、および y の同じ構造) に依存していることです。 1 つの長方形を削除すると、その長方形からの極値の寄与だけが問題になります。 それが境界の原因ではない場合、グローバル交差は変更されないままになります。 責任がある場合は、2 番目に最適な値がアクティブになります。 

これにより、ソートされた極端な場合にプレフィックスとサフィックスの情報を維持するという問題が軽減されます。 各方向について、最良の寄与と次善の寄与の両方をカウントとともに事前計算できます。 次に、各長方形について、一定時間内に交差点が削除された場合にどのようになるかを再構築できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^2)$|$O(1)$| 遅すぎる |
 | 最適 |$O(n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 グローバル極値と「バックアップ」極値を維持しながら、すべての長方形を処理します。 

1. すべての長方形について、各次元の 4 つのグローバル量 (左の最大境界、右の最小境界) を計算し、これらの各極値に達する長方形の数を追跡します。 また、2 番目に最適な値も追跡して、1 つの四角形が削除されたときに境界を回復できるようにします。 

次善の値が必要な理由は、極端な境界を定義する四角形を削除すると、その制約が完全に失われるためです。 
2. 同じロジックを x 次元と y 次元に対して個別に繰り返します。 交差条件は因数分解されるため、各次元は独立して動作します。 
3. 各長方形について、その除去をシミュレートします。 それが極値に寄与していない場合、グローバル交差点は変化しないままです。 それが寄与しており、それが唯一の寄与者である場合は、2 番目に最適な値に切り替えます。 それ以外の場合は、極端な値は変わりません。 
4. 長方形の削除をシミュレートした後、次のように定義される交差長方形の候補を取得します。 

左 = max_left_exclude_i、右 = min_right_exclude_i、

 ボトム = max_bottom_exclude_i、トップ = min_top_exclude_i。 

この四角形が有効な場合 (左 ≤ 右、下 ≤ 上)、すぐにその中の任意の整数点を選択します。 
5. この問題では存在が保証されているため、少なくとも 1 つの四角形を削除すると空ではない交差が得られ、答えが見つかります。 

### なぜ効果があるのか

 正確さは、軸に揃えられた長方形の交差が x および y 間隔の独立した制約によって完全に決定されるという事実に基づいています。 各次元について、左の最大境界と右の最小境界の 2 つの値のみが重要です。 1 つの四角形を削除すると、これら 2 つの値にのみ影響します。 次善の候補を保存することにより、単一の削除でも正しい境界が維持されます。 したがって、「1 つを除くすべて」の交差は、最初から再計算することなく正確に計算されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    xs1, ys1, xs2, ys2 = [], [], [], []

    for _ in range(n):
        x1, y1, x2, y2 = map(int, input().split())
        xs1.append(x1)
        ys1.append(y1)
        xs2.append(x2)
        ys2.append(y2)

    def prep_max(arr):
        max1 = -10**18
        max2 = -10**18
        cnt1 = 0
        for v in arr:
            if v > max1:
                max2 = max1
                max1 = v
                cnt1 = 1
            elif v == max1:
                cnt1 += 1
            elif v > max2:
                max2 = v
        return max1, max2, cnt1

    def prep_min(arr):
        min1 = 10**18
        min2 = 10**18
        cnt1 = 0
        for v in arr:
            if v < min1:
                min2 = min1
                min1 = v
                cnt1 = 1
            elif v == min1:
                cnt1 += 1
            elif v < min2:
                min2 = v
        return min1, min2, cnt1

    xL1, xL2, xLcnt = prep_max(xs1)
    yL1, yL2, yLcnt = prep_max(ys1)
    xR1, xR2, xRcnt = prep_min(xs2)
    yR1, yR2, yRcnt = prep_min(ys2)

    for i in range(n):
        l = xL2 if xs1[i] == xL1 and xLcnt == 1 else xL1
        r = xR2 if xs2[i] == xR1 and xRcnt == 1 else xR1
        d = yL2 if ys1[i] == yL1 and yLcnt == 1 else yL1
        u = yR2 if ys2[i] == yR1 and yRcnt == 1 else yR1

        if l <= r and d <= u:
            print(l, d)
            return

    print(0, 0)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず各四角形を境界を表す 4 つの配列に圧縮します。 次に、左、右、下、上端のグローバル極値と、次に最適な値およびカウントを計算して、極値が一意の四角形に依存するかどうかを検出します。 

除去シミュレーション中に、長方形かどうかを確認します。$i$極端な境界に対して独自の責任を負います。 その場合は、2 番目に最適な値に戻ります。 そうしないと、地球規模の極端な状態が変化しないままになります。 これは x と y に対して独立して実行され、交差する四角形の候補が形成されます。 

有効な交差点が見つかったら、その左下隅を出力します。 交差点内の任意の点が機能するため、左下隅を選択すると追加の計算が回避されます。

 ## 特殊なケース

 重要なケースの 1 つは、最大左境界が単一の長方形で定義されている場合です。 例えば：```
3
5 0 10 10
0 0 6 6
0 0 6 6
```最初の四角形が削除されると、左の最大境界は 5 から 0 に下がります。アルゴリズムは、最大寄与者の数をチェックし、必要な場合にのみ 2 番目の最大値に切り替えることでこれを処理します。 この場合、四角形 1 を削除すると、すぐに左側の境界が 0 に変更され、残りの四角形との有効な交差が生成されます。 

もう 1 つのケースは、両方の極端な境界が同じ長方形から来ている場合です。 アルゴリズムは左右の境界を個別に調整するため、引き続き機能します。 1 つの長方形が両側に影響を与える場合でも、それを削除すると両方の値が次善の候補に置き換えられ、正しい交差領域が維持されます。 

最後のエッジケースは、すべての四角形がすでに重なっている場合です。 その後、どの削除でも同じグローバル交差が生成されます。 このアルゴリズムは、2 番目に最適な値に依存する必要なく、最初の反復ですぐに有効性を検出します。
