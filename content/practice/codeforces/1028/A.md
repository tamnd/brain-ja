 ## 解決策
 ## 問題の理解

 サイズのグリッドが与えられています$n \times m$白と黒の2種類のセルで構成されています。 最初はグリッド全体が白ですが、ある時点で辺の長さが奇数の単一の正方形領域が黒く塗られます。 その正方形は軸に沿って配置されており、黒いセルで完全に埋められています。 その広場の外では、すべてが白いままです。 

タスクは、黒い四角形の正確な中心セルを決定することです。 辺の長さは奇数であることが保証されているため、固有の中央セルが存在し、正方形の 4 辺すべてから正確に等しい距離に配置されます。 

入力は単純にペイント後のグリッドです。 出力は、黒い領域の中央セルの座標です。 

制約は小さいです。$n, m \le 115$。 これは、グリッドの 2 次スキャンでさえ、複雑さの点では些細であることをすぐに示します。 すべてのセルを複数回検査するソリューションは、制限内で快適に動作します。 すべての黒セルは、ノイズや追加の形状を持たず、軸が揃った 1 つの連続した正方形に属しているため、問題の構造も非常に厳密です。 

主な微妙な点は、正方形が直接与えられるのではなく、塗りつぶされたピクセルだけが与えられることです。 黒い領域の正確な範囲を慎重に抽出しないと、単純な解釈でジオメトリや境界形状を誤って推論しようとする可能性があります。 

いくつかの特殊なケースが重要です。 

最小サイズの正方形$1 \times 1$グリッドに黒のセルが 1 つだけ含まれていることを意味します。 「領域」または「複数行」の検出に依存するアルゴリズムは、これを正しく処理する必要があります。 たとえば:

 入力:```
1 1
B
```出力：```
1 1
```もう 1 つのケースは、正方形がグリッドの境界線に接触している場合です。 黒のセルの境界ボックスは行 1 または列 1 から始まる可能性があるため、インデックス作成時に 1 つずつずれたエラーが発生すると、直ちに正確さが失われます。 

最後に、正方形は完全であることが保証されているため、複数の切断された黒いコンポーネントを想定してはなりません。 リージョンのマージやフラッドフィルの実行を試みるソリューションは不要ですが、制約の下では有効です。 

## アプローチ

 直接的な総当たり戦略は、グリッド内のすべての可能なサブ正方形をスキャンし、それが完全に黒であるかどうか、およびそれが固有のペイント領域を形成しているかどうかを確認することです。 各候補正方形について、その内部のすべてのセルを検証します。これにはコストがかかります$O(k^2)$候補者ごとに、全体の$O(n^4)$最悪の場合はアプローチします。 それでも$n \le 115$最適化された C++ ではこの境界線が実現可能ですが、Python では不必要に複雑で遅くなります。 

より自然な観察は、入力の構造から得られます。 すべての黒セルは 1 つの軸に沿った正方形に属しているため、すべての黒セルは高さと幅が等しい連続した長方形領域を形成します。 正方形を直接検索する代わりに、すべての黒いセルの境界ボックスを見つけることができます。 一番上、一番下、一番左、そして一番右の黒いセルが長方形を定義します。 形状は辺の長さが奇数の正方形であることが保証されているため、この外接する長方形はすでに必要な正確な正方形です。 

正方形の角がわかれば、中心は単に縦方向と横方向の範囲の中点になります。 

ブルートフォース手法では、すでに保証されている構造の正確性をチェックするのに労力が無駄になります。 境界ボックスのアプローチにより、問題はグリッドの 1 回のスキャンに軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^2 m^2)$|$O(1)$| 遅すぎる |
 | 最適 (バウンディング ボックス スキャン) |$O(nm)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 黒セルの極端な境界を追跡するように変数を初期化します。左と右についても同様に、上部を非常に大きな値、下部を非常に小さな値に設定します。 これにより、黒のセルがこれらの境界を正しく更新することが保証されます。 
2. グリッド内のすべてのセルを行ごとにスキャンします。 黒のセルに遭遇するたびに、その座標を使用して 4 つの境界値を更新します。 正方形はグリッド内のどこにでも表示される可能性があるため、この手順は不可欠です。 
3. スキャンが完了すると、黒い正方形はこれらの境界によって定義される長方形で完全に囲まれます。 
4. 中央の行を上下の境界の平均として計算し、中央の列を左右の境界の平均として計算します。 正方形の辺の長さは奇数であることが保証されているため、これらの平均は整数になります。 
5. 計算された中心座標を出力します。 

### なぜ効果があるのか

 すべての黒いセルは、単一の塗りつぶされた正方形に属します。 各方向に沿った極端な黒いセルは、その正方形のエッジに正確に対応する必要があります。これを超える延長は塗りつぶし領域の定義と矛盾するためです。 形状は軸に合わせて完全に塗りつぶされているため、すべての黒いセルの最小境界長方形は元の正方形と正確に一致します。 したがって、その長方形の中点は正方形の幾何学的中心であり、奇数の辺の長さから一意性が生じます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    
    top, bottom = n, -1
    left, right = m, -1
    
    for i in range(n):
        row = input().strip()
        for j, ch in enumerate(row):
            if ch == 'B':
                if i < top:
                    top = i
                if i > bottom:
                    bottom = i
                if j < left:
                    left = j
                if j > right:
                    right = j
    
    # convert to 1-based indexing
    r = (top + bottom) // 2 + 1
    c = (left + right) // 2 + 1
    
    print(r, c)

if __name__ == "__main__":
    solve()
```この実装では、グリッドを 1 回スキャンしている間、4 つの極端な値を実行し続けます。 重要な点は、グリッドは内部的に 0 から始まるインデックスを使用して読み取られるため、1 から始まるインデックスへの変換は最終ステップでのみ行われることです。 中点の計算では整数の除算が使用されますが、正方形のサイズが奇数であることが保証されているため安全です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque
    n, m = map(int, input().split())
    top, bottom = n, -1
    left, right = m, -1
    
    for i in range(n):
        row = input().strip()
        for j, ch in enumerate(row):
            if ch == 'B':
                top = min(top, i)
                bottom = max(bottom, i)
                left = min(left, j)
                right = max(right, j)
    
    r = (top + bottom) // 2 + 1
    c = (left + right) // 2 + 1
    return f"{r} {c}"

 ## 特殊なケース

 単一の黒いセルを含む最小グリッドは、アルゴリズムが縮退正方形に対する特別な処理を必要としないことを示しています。 スキャンによりすべての境界がその単一の座標に設定され、中点は同じセルを返します。 

グリッドの境界線に接する四角形は、境界の初期化が有効なインデックスの外側で開始される必要があることを示しています。 極端なセンチネルではなくゼロから開始した場合、検出された領域を誤って縮小する可能性があります。 

グリッドの大部分を占める大きな正方形は、スキャンが以前の極端な値を上書きすることなく複数の更新を正しく集約するかどうかをテストします。 すべての黒いセルは境界の強化または拡大に寄与し、最終結果では全体的な極端な値のみが重要になります。
