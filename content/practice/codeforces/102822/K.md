 ## 解決策
 ## 問題の理解

 問題は数字を与えます`x`そして、合計が正確に一致する整数のコレクションを要求します`x`。 選択されたすべての整数は 1 より大きい必要があり、少なくとも 2 つの整数が存在し、コレクション内のすべての整数のペアが互いに素である必要があります。 すべての有効なコレクションの中で、選択された最大値と最小値の差を最小限に抑える必要があります。 

入力には最大で次のものが含まれます`10^5`の独立した値`x`、それぞれの大きさは`10^9`。 これにより、可能なセットを検索したり、テスト ケースごとにコストのかかる因数分解を実行したりすることが排除されます。 目的のソリューションでは、直接的な数学的特徴付けを使用し、一定時間内に各クエリに応答する必要があります。 

難しいのは、単純に分割するだけでは最良の答えは得られないことです。`x`2 つの近い数字に分割します。 近い 2 つの数値であっても、因数を共有することができます。 たとえば、`x = 6`、分割`{3, 3}`の範囲は最小ですが、等しい数値は互いに素ではないため無効です。 正しい出力は次のとおりです`-1`。 

もう 1 つの境界ケースは奇数の値です。 のために`x = 5`、セット`{2, 3}`動作し、範囲があります`1`、したがって、答えは次のとおりです`1`。 偶数分割のみを検索する不用意な実装では、これを見逃してしまいます。 

3 番目に重要なケースは次のような場合です。`x`は 4 で割り切れます。 のために`x = 8`、セット`{3, 5}`動作します。 違いは`2`、 ない`1`2 つの連続する整数の合計が奇数になるためです。 2 つ離れた数値間の共素性条件を見逃すと、間違った答えが生じる可能性があります。 

## アプローチ

 ブルートフォースソリューションでは、可能な最小の要素を試し、それらの周囲に候補セットを構築します。 考えられる範囲ごとに、間隔のサブセットを列挙し、合計が以下であるかどうかを確認します。`x`すべてのペアが互いに素であるかどうか。 これは、考えられるすべての回答候補を検討するため正しいですが、ここでは不可能です。 間隔とサブセットの数は、それをはるかに超えて増加します`10^5`テストケースを処理できます。 

有益な観察は、非常に狭い範囲だけが最適になる可能性があるということです。 の範囲`1`2 つの連続する数字を使用できる場合にのみ可能です。 それらの合計は奇数なので、すべての奇数`x`答えがあります`1`。 

偶数の場合`x`、 範囲`1`仕事ができない。 次に範囲を見ていきます`2`。 違いのある 2 つの数字`2`形を持っている`a`そして`a + 2`。 彼らの gcd は`gcd(a, 2)`、したがって、それらは正確に互いに素になります`a`奇数です。 それらの合計は`2a + 2`で割り切れます。`4`。 したがって、すべての`x`で割り切れる`4`答えがあります`2`。 

残りの偶数値は、`x ≡ 2 (mod 4)`。 の範囲`2`は不可能なので、より広い間隔が必要です。 建設`{a, a+1, a+3}`範囲を与える`3`。 その合計は`3a+4`。 選択することで`a`適切に、このクラス内の十分に大きな値をすべて表現できます。 失敗する唯一の偶数値は、`x = 6`。 

問題全体は、パリティと可分性のチェックに帰着します。

 ## アルゴリズムのチュートリアル

 1. もし`x`奇数です、出力`1`。 2 つの連続する整数`(x-1)/2`そして`(x+1)/2`必要な合計があり、常に互いに素です。 
2. もし`x`は偶数であり、次で割り切れます`4`、出力`2`。 ペア`x/2 - 1`そして`x/2 + 1`合計があります`x`、 違い`2`、小さい方の数は奇数であるため、ペアは互いに素です。 
3. もし`x`等しい`6`、出力`-1`。 1 より大きい数値に分割できるのは、数値を繰り返すか、共通因数を含むかのいずれかであるため、有効なセットは存在しません。 
4. 1 つおきの偶数値について、出力します。`3`。 4 つの要素ウィンドウ内で 3 つの数値を使用した構造は、次の範囲が証明されます。`3`いつも十分です。 

なぜ効果があるのか:

 下限はパリティと gcd の制限によって決まります。 範囲`0`繰り返される数値は互いに素ではないため、これは不可能です。 範囲`1`連続する 2 つの数値のみを許可し、その合計が奇数である必要があります。 4 で割り切れない偶数の場合、範囲`2`2 つ離れた数値は共素性の誤ったパリティを持つため、有効なペアを生成できません。 上記の構造は、以下を除き、これらの下限に一致します。`x = 6`、建物が存在しない場所。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []
    for case in range(1, t + 1):
        x = int(input())

        if x & 1:
            res = 1
        elif x % 4 == 0:
            res = 2
        elif x == 6:
            res = -1
        else:
            res = 3

        ans.append(f"Case #{case}: {res}")

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```プログラムは算術チェックのみを実行するため、データのサイズには依存しません。`x`。 パリティテストは範囲を処理します`1`まずは建設。 これらのケースでは範囲が狭いため、4 で割り切れるチェックが次に行われます。`2`答え。 特別な場合`6`これは唯一不可能な偶数値であるため、最終フォールバックの前にチェックする必要があります。 

出力形式には、必要に応じてケース番号が正確に含まれます。 すべての計算は数十億未満にとどまるため、Python の整数で十分です。

## テストケース```python
import sys
import io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)

    data = sys.stdin.readline
    t = int(data())
    out = []

    for case in range(1, t + 1):
        x = int(data())
        if x & 1:
            res = 1
        elif x % 4 == 0:
            res = 2
        elif x == 6:
            res = -1
        else:
            res = 3
        out.append(f"Case #{case}: {res}")

    sys.stdin = old
    return "\n".join(out)

assert run("4\n5\n6\n7\n10\n") == (
    "Case #1: 1\n"
    "Case #2: -1\n"
    "Case #3: 1\n"
    "Case #4: 3"
)

assert run("1\n8\n") == "Case #1: 2"

assert run("5\n12\n16\n20\n14\n18\n") == (
    "Case #1: 2\n"
    "Case #2: 2\n"
    "Case #3: 2\n"
    "Case #4: 3\n"
    "Case #5: 3"
)

assert run("3\n1000000000\n999999999\n6\n") == (
    "Case #1: 2\n"
    "Case #2: 1\n"
    "Case #3: -1"
)

 ## 特殊なケース

 のために`x = 6`、アルゴリズムは明示的に不可能なケースに達します。 の範囲`1`2 つの連続する整数を合計して偶数にする必要がありますが、このようなことは起こり得ません。 の範囲`2`次のようなペアが必要になります`{2,4}`、しかし彼らの gcd はそうではありません`1`。 範囲を大きくしても必要な最小値を超えることはできず、有効なセットは存在しません。 

のために`x = 5`、奇数のブランチはすぐに戻ります`1`。 数字`2`そして`3`合計して`5`、そしてそれらの gcd は`1`、可能な限り最小の範囲が達成可能であることを証明しています。 

のために`x = 8`、アルゴリズムは戻ります`2`なぜなら`8`は 4 で割り切れます。 セット`{3,5}`合計があります`8`、両方の値が 1 より大きく、かつ`gcd(3,5)=1`。 範囲は指定できません`1`連続する数字の合計は常に奇数になるためです。 

次のような大きな値の場合、`x = 1000000000`、プログラムは構築や反復を試みません。 割り算のみをチェックし、値が 4 で割り切れることを確認して、次の値を返します。`2`すぐに。 これにより、ソリューションが数値サイズに関係なくスケーリングされることが確認されます。`x`。
