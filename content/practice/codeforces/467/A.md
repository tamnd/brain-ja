 ## 解決策
 ## 問題の理解

 この問題は単純なシナリオを示しています。ジョージとアレックスは、一緒に寮の部屋を探したいと考えています。 寮の各部屋には現在の占有人数と最大収容人数が設定されています。 入力により、部屋の数、各部屋の現在の居住者数と総収容人数がわかります。 課題は、ジョージとアレックスの両方が同時に入ることができる部屋の数を数えることです。 

制約は小さく、部屋の数は最大 100 で、各部屋の収容人数も 100 を超えません。これは、各部屋を個別に検査するアルゴリズムは、ネストされたチェックが含まれていても、制限時間内で快適に実行できることを意味します。 数値はすべて小さな整数であるため、整数のオーバーフローや精度の問題が発生するリスクはありません。 

部屋がほぼ満員の場合、微妙なエッジケースが発生します。 たとえば、定員 2 名で占有者 1 人の部屋には、あと 1 名しか収容できないため、ジョージとアレックスの両方が入居することはできません。同様に、定員 2 で部屋が空の場合、両方がぴったり収まります。 「2 人分のスペース」条件をチェックしないと、誤った結果が生成されます。 

## アプローチ

 ブルートフォースアプローチは簡単です。 各部屋について、収容人数から現在の居住者を差し引いて利用可能なスペースを計算します。 使用可能なスペースが少なくとも 2 ある場合は、カウンターをインクリメントします。 部屋の数は最大 100 個であるため、必要な単純な算術チェックは最大 100 回ですが、現代のコンピュータではこれは簡単なことです。 各部屋を少なくとも 1 回は検査する必要があるため、これより迅速な漸近アプローチはありません。 重要な洞察は、「両方を収容できる部屋」を単純な比較に帰着させることです。`q_i - p_i >= 2`。 この小さな簡略化により、不必要な簿記や複雑なロジックが排除されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n) | お(1) | 承認済み |
 | 最適 | O(n) | お(1) | 承認済み |

 問題は非常に単純であるため、総当たりの解決策も最適です。 

## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`、部屋の数。 
2. カウンタの初期化`count`ゼロに。 これにより、ジョージとアレックスの両方が宿泊できる部屋の数が追跡されます。 
3. 次のそれぞれについて`n`行:

 1. 現在の占有者数を読み取ります。`p`そして部屋のキャパシティ`q`。 
2. 利用可能なスペースを次のように計算します。`q - p`。 
3. 利用可能なスペースが少なくとも 2 ある場合は、インクリメントします。`count`1までに。 
4. すべての部屋を処理した後、次の値を出力します。`count`。 

機能する理由: 各ステップで、アルゴリズムはジョージとアレックスが入居するために必要な条件を正確にチェックします。部屋には少なくとも 2 つの空きスペースが必要です。 すべての部屋が考慮され、それぞれが独立して評価されるため、最終的な数はすべての有効な部屋を正確に反映します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
count = 0

for _ in range(n):
    p, q = map(int, input().split())
    if q - p >= 2:
        count += 1

print(count)
```ソリューションはアルゴリズムに直接に従います。 このループは各部屋を反復し、収容人数から現在の占有者数を減算し、2 つ以上のスペースが利用可能な場合はカウンターを増分します。 の選択`q - p >= 2`問題の要件を直接実装します。 高速 I/O を使用することは、入力サイズが大きくなる場合の予防策です。`n ≤ 100`厳密には必要ありません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    count = 0
    for _ in range(n):
        p, q = map(int, input().split())
        if q - p >= 2:
            count += 1
    return str(count)

# provided samples
assert run("3\n1 1\n2 2\n3 3\n") == "0", "sample 1"

# custom cases
assert run("4\n0 2\n1 3\n2 5\n3 5\n") == "4", "all fit"
assert run("1\n0 0\n") == "0", "room has zero capacity"
assert run("2\n0 1\n1 2\n") == "0", "rooms cannot fit both"
assert run("5\n0 2\n1 2\n0 3\n2 2\n1 4\n") == "3", "mixed case"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`3\n1 1\n2 2\n3 3\n`| 0 | 全室満室 |
 |`4\n0 2\n1 3\n2 5\n3 5\n`| 4 | 正確なスペースを持つ複数の部屋 |
 |`1\n0 0\n`| 0 | 定員ゼロの部屋 |
 |`2\n0 1\n1 2\n`| 0 | 2人で泊まれない部屋 |
 |`5\n0 2\n1 2\n0 3\n2 2\n1 4\n`| 3 | 満室と一部満室の混合部屋 |

 ## 特殊なケース

 部屋の現在の居住者が 0 人だが、収容人数が 2 人未満の場合、両方を収容することはできません。例:`p=0, q=1`。 アルゴリズムは正しく計算します`q - p = 1 < 2`、 それで`count`は増分されません。 ちょうど 2 つのスペースが残っている部屋の場合、`p=1, q=3`、アルゴリズムは次のように計算します。`q - p = 2`、増加します`count`正しく。 すでに満員の部屋は自動的に無視されます。 これにより、比較が`q - p >= 2`微妙な占有状況をすべて正確に処理します。
