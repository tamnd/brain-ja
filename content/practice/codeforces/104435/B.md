 ## 解決策
 ## 問題の理解

 各テスト ケースには、小文字の単語の 2 つのコレクションが含まれています。 

最初のコレクションは Wah-List です。これには、暗号化されたメッセージがデコードされた後に表示される必要があるすべての単語が含まれています。 

2 番目のコレクションは、暗号化されたメッセージ自体です。 すべての単語は同じシーザー暗号シフトで暗号化されました。 暗号化中、すべての文字は次のように転送されます。`k`アルファベット内の位置、後ろに折り返す`z`。 デコードするには、すべての文字を同じ量だけ後方にシフトする必要があります。 

私たちのタスクは、**正**の最小シフト値を見つけることです。`k`つまり、メッセージ全体をデコードした後、Wah-List のすべての単語がデコードされたメッセージのどこかに表示されます。 この条件を満たす正のシフトがない場合は、次のように出力します。`-1`。 

アルファベットには 26 文字しか含まれていないため、個別のシーザー シフトは 26 しかありません。 この問題では正の値のみが許容されるため、`k`からのシフトをテストするだけで済みます。`1`を通して`25`。 のシフト`26`元のメッセージを再度生成します。これは次と同等です。`0`, したがって、これは最小の肯定的な答えになることはありません。 

メッセージの長さは最大 1500 文字で、Wah-List には最大 20 ワード、最大 50 ワードが含まれます。考えられるすべてのシフトについてメッセージ全体をデコードする場合でも、必要な時間はわずか約 20 です。`25 × 1500 = 37500`テスト ケースごとの文字操作は、快適に小さいです。 

微妙なケースの 1 つは、複数のシフトによって有効なデコードされたメッセージが生成される場合です。 例えば、```
Wah-List:
aaa

Message:
bbb ccc ddd
```シフト`1`、`2`、 そして`3`すべては以下を含むメッセージを生成します`aaa`。 正しい答えは、`1`なぜなら、単なる有効なシフトではなく、最小の正のシフトを返さなければならないからです。 

もう 1 つの簡単な間違いは、シフトがアルファベットを囲むことを忘れることです。```
Wah-List:
xyz

Message:
abc
```でデコードする`k = 3`ターン`abc`の中へ`xyz`。 折り返しを行わずに各文字から 3 を単純に減算すると、無効な文字が生成されます。 

3 番目の落とし穴は、重複したメッセージ ワードを誤って扱うことです。 考慮する```
Wah-List:
cat dog

Message:
fdw fdw grj
```正しいシフトでデコードすると、メッセージは次のようになります。```
cat cat dog
```重複は関係ありません。 必要な単語がそれぞれ少なくとも 1 回出現するかどうかだけを知る必要があるため、デコードされた単語をセットに保存するだけで十分です。 

## アプローチ

 最も直接的な解決策は、可能な限りポジティブなシフトを試みることです。 シフトごとに、メッセージ内のすべての単語をデコードし、デコードされた単語をセットに集めて、すべての Wah-List 単語がそのセットに属しているかどうかを確認します。 候補シフトは 25 しかないため、このアプローチはすでに非常に効率的です。 

アルファベットには 26 文字しかないという事実を無視し、代わりに任意の大きな値を検索したとします。`k`。 無限に多くのシフトが存在するため、それは明らかに不可能です。 重要な観察は、シーザー暗号のシフトが 26 位置ごとに繰り返されるということです。 27 によるシフトは 1 によるシフトとまったく同じであり、52 によるシフトは 0 によるシフトと同じです。 この周期性により、検索スペースが 25 個の意味のある候補のみに減ります。 

これを認識すれば、ハッシュ、試行、文字列マッチングなどのより高度なアルゴリズムは必要ありません。 すべての候補メッセージのデコードは、すでに制限内に十分に収まっています。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 任意のシフトに対するブルートフォース | 無制限 | お(1) | 不可能 |
 | 25 種類のシーザー シフトをすべて試す | O(25×L) | お(お) | 承認済み |

 ここ、`L`は暗号化されたメッセージの合計文字数です。`M`メッセージ内の単語数です。 

## アルゴリズムのチュートリアル

 1. ワウリストを読み、その単語をセットに保存します。 セットを使用すると、後のメンバーシップ チェックが一定時間になります。 
2. 暗号化されたメッセージを単語のリストとして読み取ります。 
3. シフトごとに`k`から`1`に`25`、各文字を後方にシフトしてすべてのメッセージ ワードをデコードします。`k`モジュロ 26 演算による位置。 
4. デコードされたすべての単語をセットに挿入します。 必要な単語が少なくとも 1 回出現するかどうかのみを考慮するため、デコードされた単語の重複は無関係です。 
5. すべての Wah-List ワードがデコードされたワード セットに属しているかどうかを確認します。 
6. 1 つのシフトが条件を満たしたらすぐに、そのシフトを出力し、検索を停止します。 シフトは昇順にテストされるため、最初の有効なシフトが自動的に最小の肯定的な答えになります。 
7. 25 のシフトがどれも成功しなかった場合、出力`-1`。 

### なぜ効果があるのか

 考えられるすべてのシーザー暗号は、シフト モジュロ 26 によって一意に決定されます。テストは次から移行します。`1`を通して`25`すべての明確な正の暗号を 1 回だけカバーします。 固定シフトの場合、デコードでは、そのシフトによる暗号化前に存在していたメッセージが正確に再構築されます。 アルゴリズムは、デコードされたメッセージに必要なすべての単語が出現するタイミングを正確に受け入れます。 シフトは昇順にチェックされるため、最初に成功したシフトが最小の有効な答えであることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def decode_word(word, shift):
    res = []
    for c in word:
        x = (ord(c) - ord('a') - shift) % 26
        res.append(chr(ord('a') + x))
    return "".join(res)

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        wah = set(input().split())

        m = int(input())
        message = input().split()

        answer = -1

        for shift in range(1, 26):
            decoded = set()

            for word in message:
                decoded.add(decode_word(word, shift))

            if wah.issubset(decoded):
                answer = shift
                break

        print(answer)

if __name__ == "__main__":
    solve()
```必要な操作はメンバーシップのテストだけであるため、ソリューションは Wah-List をセットに保存することから始まります。 すべての候補シフトは独立して処理されます。 

ヘルパー関数はシーザー デコードを実行します。 各文字は次の値に変換されます。`0`に`25`、シフトが減算され、モジュロ演算によってラップアラウンドが自動的に処理され、結果が文字に変換されます。 

シフトごとに、すべてのメッセージ ワードが 1 回だけデコードされ、セットに挿入されます。 セットを使用すると、定数時間のルックアップを提供しながら重複は自然に無視されます。 サブセット テストは、必要な単語がすべて存在するかどうかを直接回答します。 

ループは、最初の有効なシフトが見つかった直後に停止します。 シフトは昇順で検査されるため、これにより最小の肯定的な答えが保証されます。

 | 測定 | 複雑さ | 説明 |

## テストケース```python
import sys
import io

def run(inp: str) -> str:
    from contextlib import redirect_stdout

    sys.stdin = io.StringIO(inp)
    out = io.StringIO()

    def decode_word(word, shift):
        return "".join(chr((ord(c) - 97 - shift) % 26 + 97) for c in word)

    def solve():
        input = sys.stdin.readline
        t = int(input())
        for _ in range(t):
            n = int(input())
            wah = set(input().split())
            m = int(input())
            msg = input().split()

            ans = -1
            for k in range(1, 26):
                dec = {decode_word(w, k) for w in msg}
                if wah.issubset(dec):
                    ans = k
                    break
            print(ans)

    with redirect_stdout(out):
        solve()

    return out.getvalue()
