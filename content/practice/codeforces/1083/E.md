 ## 解決策
 ## 問題の理解

 各長方形は原点に固定され、点まで伸びます。$(x_i, y_i)$したがって、幾何学的には、すべての長方形は左下に揃えられた軸に平行な長方形になります。 すべての長方形は同じ原点の角を共有するため、2 つの長方形は非常に構造化された方法で重なり合います。それらの結合はそれらの最大値のみに依存します。$x$そして最大の$y$選択したセットの中から。 

選択した四角形のサブセットの場合、結合領域は単にそれらすべてをカバーする境界四角形の領域です。$\max x \cdot \max y$。 サブセットを選択するコストは、この結合領域からペナルティの合計を引いたものになります。$a_i$選択した長方形の上に。 タスクは、この値を最大化するサブセットを選択することです。 

重要な制約は、$n$まで可能です$10^6$、座標は次のようになります。$10^9$。 これにより、ペアごとの DP またはサブセット DP が直ちに除外されます。 おおよそを超えたもの$O(n \log n)$すでに境界線に達しており、$O(n^2)$長方形のペアを推論することは不可能です。 

素朴なアプローチが各四角形が独立して寄与すると仮定した場合、微妙な失敗例が発生します。 たとえば、すべての長方形を選択することを考えるかもしれません。$x_i y_i > a_i$しかし、これは、長方形を追加すると結合領域が劇的に増加し、以前は良好だった選択が悪化する可能性があることを無視しています。 

もう 1 つの隠れた落とし穴は、結合の形状を明示的に追跡する必要があると仮定していることです。 長方形は優位性によってのみネストされるため、幾何学的な結合の計算を不用意に行うと、不必要な複雑さと不正確な遷移が発生します。 

## アプローチ

 ブルートフォースソリューションでは、長方形のすべてのサブセットを試し、最大値を取得して各サブセットの和合面積を計算します。$x$そして$y$の合計を引きます。$a_i$、最高の結果を維持します。 サブセットが固定されると和集合の計算が簡単になるため、これは概念的に機能します。 ただし、サブセットの数は$2^n$、さらに各サブセットを評価することもできます。$O(n)$総作業量が実現可能な限界を超えて指数関数的に増加します。 

重要な構造的観察は、サブセットが最大値を持つ長方形によって完全に決定されるということです。$x$そして最大の$y$。 長方形を固定すると$i$結合の右上隅として (つまり、最大値を提供します)$x$)、選択した長方形は領域内になければなりません。$[0, x_i] \times [0, y_i]$。 その領域内では、結合領域は常に$x_i \cdot y_i$、どのサブセットが選択されるかに関係なく、$i$が含まれています。 

したがって、問題は長方形ごとに決定することになります。$i$、それを「アクティブな境界四角形」にし、オプションでその領域内に他の四角形を含めるかどうか。 直したら$i$、貢献度は次のようになります。$$x_i y_i - a_i + \sum (x_j y_j - a_j \text{ for selected } j \subseteq i\text{'s valid set})$$しかし重要なのは、長方形を選択することです$j$最大値でない限り境界ボックスは変更されないため、スキップするよりも悪くない場合にのみ意味があります。 

これは、古典的なエンベロープ DP 構造につながります。つまり、増加することによって四角形を並べ替えます。$x$、有効な値に対して達成可能な最良の値を維持します。$y$制約を設け、より小さいすべての四角形の中で最良の以前の状態をクエリする構造を使用します。$y$。 

ネストされた四角形がないことで、きれいな部分順序が保証されます。つまり、両方の次元で他の四角形を完全に支配する四角形は存在しないため、複数の同一の状態が競合する退化したケースが回避されます。 

民進党が圧勝となる$x$をキーとした構造を維持します。$y$、その高さの境界までの長方形に対して達成可能な最良の値を保存します。

 ## アルゴリズムのチュートリアル

 長方形を昇順に処理します。$x$、各四角形を和集合の潜在的な右上隅として扱います。 

1. 長方形を増加順に並べ替えます。$x$。 これにより、長方形を処理するときに、$i$、厳密にその幅の内側にある可能性のあるすべての候補がすでに考慮されています。 
2. インデックス付きの動的プログラミング構造を維持します。$y$ここで、各状態は、高さの制約が最大で以下の長方形を使用して達成可能な最良の値を表します。$y$。 実現可能性は両方の側面に依存するため、これが必要です。 
3. 長方形ごとに$i = (x_i, y_i, a_i)$、その基本ゲインを次のように計算します。$x_i y_i - a_i$。 これは、外接する四角形として単独で選択した場合の値です。 
4. すべての状態の中で最良の DP 値をクエリします。$y \le y_i$。 これは、長方形の中に含めることができる小さな長方形の最適な構成を表します。$i$境界制約に違反することなく。 
5. クエリの結果をベースゲインと組み合わせます。$i$。 これにより最良の解決策が得られます。$i$境界長方形として機能します。 
6. 位置で DP 構造を更新します。$y_i$この組み合わせた値を使用して、将来の長方形をその上に構築できるようにします。 

中心となる考え方は、すべての最適解には、その最大値を定義する固有の長方形があるということです。$x$。 その四角形が修正されると、他のすべては制約された部分問題に帰着します。$y$、これはまさに DP 構造が捉えているものです。 

### なぜ効果があるのか

 あらゆる実現可能な解決策は、最大値を達成する長方形に関連付けることができます。$x$。 その四角形が結合領域を決定します。 選択した他のすべての長方形はその下になければなりません$y$-身長。 DP は、この四角形を処理するときに、次の条件によって制約されるすべての有効なサブ構成から可能な最良の寄与をすでに知っていることを保証します。$y$。 増えていく中で加工していきますので、$x$、将来の四角形は以前の最適な部分構造を遡って無効にすることはできないため、最適な部分構造が保証され、二重カウントが防止されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class Fenwick:
    def __init__(self, n):
        self.n = n
        self.bit = [-10**30] * (n + 2)

    def update(self, i, v):
        while i <= self.n:
            if v > self.bit[i]:
                self.bit[i] = v
            i += i & -i

    def query(self, i):
        res = -10**30
        while i > 0:
            if self.bit[i] > res:
                res = self.bit[i]
            i -= i & -i
        return res

def solve():
    n = int(input())
    rects = []
    ys = []

    for _ in range(n):
        x, y, a = map(int, input().split())
        rects.append((x, y, x * y - a))
        ys.append(y)

    rects.sort()
    ys = sorted(set(ys))

    def get_idx(y):
        # manual binary search
        lo, hi = 0, len(ys) - 1
        while lo <= hi:
            mid = (lo + hi) // 2
            if ys[mid] == y:
                return mid + 1
            elif ys[mid] < y:
                lo = mid + 1
            else:
                hi = mid - 1
        return lo + 1

    fw = Fenwick(len(ys))
    ans = 0

    for x, y, val in rects:
        yi = get_idx(y)
        best = fw.query(yi)
        if best < 0:
            best = 0
        cur = best + val
        if cur > ans:
            ans = cur
        fw.update(yi, cur)

    print(ans)

if __name__ == "__main__":
    solve()
```ソリューションはすべてを圧縮します$y$-座標は、フェンウィック ツリーが生の値を操作できないためです。$10^9$。 クエリは、現在の四角形の高さ制約内に収まる達成可能な最適な構成を取得し、更新によって新しい最適な状態が伝播されます。 

実装の微妙な詳細は、DP 値を大きな負の数で初期化する一方で、空のセットのベースラインとしてゼロを個別に許可することです。 これにより、無効な遷移による結果の汚染が防止されます。

 ## 特殊なケース

 デリケートなケースの 1 つは、複数の長方形が同じものを共有する場合です。$y$価値はあるが違う$x$。 アルゴリズムは、座標圧縮によって状態が誤ってマージされないようにする必要があります。そうしないと、更新が互いに上書きされ、最適な部分構造が壊れてしまいます。 

もう 1 つのエッジケースは次のような場合です$a_i = x_i y_i$、長方形をニュートラルにします。 このような四角形は正の値をもたらすべきではありませんが、他の四角形を含めることを可能にする境界四角形として機能することはできます。 基本寄与がゼロになるため、DP はこれを正しく処理し、強制ゲインなしで構造的な使用が可能になります。 

最後のケースは、最良の回答にいずれの座標による最大の長方形も含まれない場合です。 スイープにより、すべての四角形が潜在的な境界アンカーとして考慮されるため、最適解が全体的な最大値に偏りません。
