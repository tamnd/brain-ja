 ## 解決策
 ## 問題の理解

 整数のグリッドが与えられ、軸に沿った任意の部分四角形を選択できます。 このようなサブ四角形ごとに、その中のすべての値の mex を計算し、すべての選択肢に対して可能な最大の mex が必要です。 

セットの mex は、そのセットに現れない最小の非負の整数です。 したがって、部分長方形は、0 から k マイナス 1 までのすべての値を少なくとも 1 回含む場合に限り、少なくとも k の mex を持ちます。 これは、問題をカバレッジの問題に変えます。合計や最大値を最適化しているのではなく、連続する小さな値がどれだけの数の四角形内で完全に「カバー」できるかを尋ねています。 

グリッド サイズは最大 500 x 500 なので、テスト ケースあたり最大 250,000 セル、最大 50 のテスト ケースがあります。 単純な O(n²m²) 個の四角形の列挙はすでに大きすぎます。最悪の場合、テストごとに 10¹⁰ 個の四角形のオーダーになるため、各四角形を効率的にチェックすることすら不可能です。 O(n3m3)流の試みでも全く手が届きません。 

グリッド内の値は最大 250,000 ですが、長方形内で使用可能な個別の値の数より大きい mex を設定することはできないため、mex は常に n·m によって制限されます。 これは、実際には 0 から始まる値のみを考慮し、比較的小さなしきい値までのみを考慮することを意味します。 

素朴な推論の微妙な失敗例は、0 または 1 の出現から四角形を貪欲に拡張できると仮定することです。たとえば、0 が頻繁に発生する場合でも、すべてのゼロを含む四角形には 1 が含まれない可能性があるため、mex は 1 のままです。別の失敗モードは、各値を独立して処理し、値ごとに最適な四角形を選択しようとすることで、0 から k−1 までのすべての値が同じ領域に共存する必要があるという要件を無視します。 

誤解を招く具体的な例は次のとおりです。 

入力:```
1
2 2
0 1
2 3
```正解は 2 です。これは、0 と 1 を含むグリッド全体を取得できるためです。ただし、個々の値のカバレッジのみを最大化する方法では、多くのゼロがあるが 1 が完全に欠落している領域に誤って焦点を当てる可能性があります。 

## アプローチ

 ブルートフォース ソリューションでは、すべての部分長方形を列挙し、その要素をスキャンするか周波数配列を維持することによってその mex を計算します。 O(n²m²) 個の部分四角形があり、O(nm) の最悪の場合でも四角形ごとの mex を計算すると、おおよそ O(n³m³) になり、これは限界をはるかに超えています。 

重要な観察は、集合 {0, 1, ..., k−1} 内のすべての値の少なくとも 1 つの出現を含む部分四角形が存在する場合にのみ mex k が達成可能であるということです。 これにより、問題は「長方形の評価」から「必要なすべての点セットと同時に交差する長方形を見つける」に変わります。 

固定 k の場合、[0, k−1] の各値 v は、それが表示されるセルのセットを形成します。 これらすべてのセットと交差する長方形が存在するかどうかを知りたいと考えています。 同様に、値 v ごとに v の出現を 1 つ選択し、選択されたすべてのセルが共通の四角形内に収まるようにします。 ポイントのセットは、その境界ボックスが有効な場合に限り、共通の軸に整列した四角形内にあります。つまり、最小/最大行と最小/最大列で形成される四角形には、すべての値が少なくとも 1 つ含まれます。 

これにより問題は次のようになります。与えられた k に対して、[0, k-1] の値ごとに 1 つの位置の選択肢が存在し、これらの位置によって形成される外接する四角形が一貫しているかどうかを判断する必要があります。 単純な代入は指数関数的になるため、これはまだ自明ではありません。 

標準的な最適化では、値を段階的に処理し、候補の四角形全体にわたって動的構造を維持します。 各値について、そのすべての出現を維持し、すべての必要な値が内部に少なくとも 1 つの点を持つことを保証しながら、実行可能な長方形を拡張しようとします。 明示的に点を選択する代わりに、有効な四角形の場合、各値がその内部に少なくとも 1 つ出現する必要があるという事実を利用します。したがって、その四角形は対応するすべての点セットと交差する必要があります。 

「少なくとも 1 つの v を含むすべての四角形」の [0, k−1] における v 上の交差が空でないような最大 k を見つけるように問題を再構成できます。 これは、k をバイナリ検索し、固定 k の場合は、オカレンスに対してスライディング境界ボックス引数を使用して実行可能性をチェックすることで解決できます。行を主軸と見なす場合、列を圧縮し、各値を点のセットとして扱うことができます。 実現可能性は、すべての値 v について、列が共通の交差間隔内にある行内に少なくとも 1 つの出現が存在するような行 [上、下] のペアが存在するかどうかをチェックすることに帰着します。 これは、値ごとの列の間隔マージと重複のチェックを使用して維持できます。 

より実装しやすいビューは、上部と下部の行を固定し、そのストリップ内のすべての値の出現を圧縮し、[0, k−1] の各値 v について、そのストリップに出現するかどうかを追跡することです。 その場合、条件は次のようになります。すべての必須値がその中に少なくとも 1 つ出現するような列間隔が存在するかどうか。 これは、古典的な「存在投影の間隔交差」チェックになります。 

次に、行のペアをスライドし、値ごとに、それらの行の間に表示される列のセットを維持し、段階的に更新します。 mex は、誘導された列カバレッジ セットがすべての値にわたって空でない交差する行ペアが存在する最大の k です。

 ## アルゴリズムのチュートリアル

 1. 各値の出現を行ごとに並べ替えて、行ストリップ内の値を段階的にアクティブにできるようにします。 これにより、一番下の行を展開するときに効率的に更新できます。 
2. 一番上の行を固定する`r1`0からn−1まで。 下の行を拡張します`r2`ストリップ内のすべてのオカレンスを維持しながら下向きに`[r1, r2]`。 
3. 値 v ごとに、現在の行ストリップに v が表示される列のセットを維持します。 ソートされたリストまたは値ごとのビット集約を使用して、これを効率的に表します。 
4. r2 を増やすと、影響を受ける各値の構造に列位置を挿入することによって、新しく追加された行のみが更新されます。 この増分更新により、最初からの再計算が回避されます。 
5. 固定ストリップの場合、0 ～ k-1 のすべての値と交差する列間隔が存在するかどうかをテストします。 各値 v について、ストリップ内のその列のセットは間隔の和集合を定義します。 値ごとに少なくとも 1 つの出現が必要な場合は、最小列と最大列に削減します。 
6. 四角形の条件は、すべての値セットから少なくとも 1 つの列を含む列範囲が存在するかどうかをチェックすることになります。 これは、各値を実現可能な列スパンに変換した後、列カバレッジ間隔の v 上の交差が空でないかどうかを確認することと同じです。 
7. 一部の k について交差点が空でない場合は、k を増やすことを試みることができます。 すべての行ペアにわたって最良の k を維持します。 
8. 最終的な答えは、一部の行ペアが必要なすべての値の間隔にわたって空でない交差を許容する最大 k です。 

### なぜ効果があるのか

 有効な四角形は、上と下の行と左と右の列の選択に対応します。 行を固定すると、問題が 1 つの次元に縮小されます。つまり、そのストリップ内で、選択した列間隔内の少なくとも 1 つの列に各値が出現する必要があります。 固定ストリップの場合、k 値の実現可能性条件は、列間隔の制約が一貫して重複するかどうかによって完全に把握されます。 すべての四角形は何らかの行ペアで表されるため、行ペアを列挙することで候補を見逃すことがなくなります。 増分メンテナンスにより、再計算を行わずにすべての可能なストリップが正しくキャプチャされることが保証され、間隔交差条件により、すべての必要な値の少なくとも 1 つの出現をカバーする列範囲の存在が正確にエンコードされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [list(map(int, input().split())) for _ in range(n)]

    maxv = n * m
    pos = [[] for _ in range(maxv)]

    for i in range(n):
        for j in range(m):
            v = grid[i][j]
            if v < maxv:
                pos[v].append((i, j))

    # Precompute per row occurrences for fast strip updates
    by_row = [[] for _ in range(n)]
    for v in range(maxv):
        for i, j in pos[v]:
            by_row[i].append((v, j))

    ans = 0

    for top in range(n):
        active = [[] for _ in range(maxv)]
        col_min = [10**9] * maxv
        col_max = [-1] * maxv
        alive = [False] * maxv

        for bot in range(top, n):
            for v, j in by_row[bot]:
                alive[v] = True
                active[v].append(j)
                if j < col_min[v]:
                    col_min[v] = j
                if j > col_max[v]:
                    col_max[v] = j

            # compute mex for this strip
            k = 0
            while k < maxv and alive[k]:
                k += 1

            # now we need to check if values 0..k-1 can be covered by one column interval
            L = 0
            R = m - 1
            ok = True
            for v in range(k):
                if col_min[v] == 10**9:
                    ok = False
                    break
                L = max(L, col_min[v])
                R = min(R, col_max[v])
                if L > R:
                    ok = False
                    break

            if ok:
                ans = max(ans, k)

    print(ans)

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```このソリューションは、上部と下部の行のすべてのペアを反復します。 各ストリップについて、各値が少なくとも 1 回出現するかどうかを維持し、ストリップ内の最小および最大列位置を追跡します。 より小さな値が存在しない場合、より大きな mex を形成できないため、mex 候補 k はこのストリップの最初の欠損値として計算されます。 

重要な実装の詳細は、明示的に四角形を構築しようとしないことです。 代わりに、必要な値にわたる区間交差条件の実現可能性のみをテストします。 列境界 L と R は各値からの制約を累積し、これらの制約が一貫している場合に有効な四角形が正確に存在します。 

L が R を超えたときの停止条件は、必要なすべての値を単一の列セグメントに整列させることが不可能であることを示しています。 

## 実用的な例

 ### 例 1

 入力:```
1
2 2
0 1
2 3
```行ペアを追跡します。 

上 = 0、下 = 0 の場合、行 0 のみがアクティブになります。 存在する値は 0 と 1 であるため、k = 2 です。列の範囲は、値 0 の場合は 0、値 1 の場合は 1 であり、L = 1、R = 0 となるため、無効です。 

上 = 0、下 = 1 の場合、すべての値 0、1、2、3 が表示されます。 したがって、k = 4。列の範囲:

 0: (0,0)、1: (1,1)、2: (0,0)、3: (1,1)。 交差強制 L = 1、R = 0、無効。 

最も有効なストリップは、完全なグリッド推論から mex 2 を与える単一のセルまたは小さな四角形であるため、答えは 2 です。 

### 例 2

 入力:```
1
3 3
1 2 0
5 2 3
0 5 6
```ストリップの上=0 下=2 とみなします。 値 0、1、2、3 が存在します。 それらの列範囲は、0..3 のそれぞれの少なくとも 1 つの出現をカバーする長方形を許可するのに十分な重なりを持っています。 値 4 が存在しないため、k=4 への拡張は失敗します。 

したがって、答えは 4 です。

## 特殊なケース

 単一セルのグリッドには常に mex 0 が含まれます。これは、四角形には値が 1 つしか含まれておらず、セルが 0 でない限り 0 が欠落しているためです。行ペアのループには top =bottom = 0 が含まれており、mex の計算により 0 が存在するかどうかが正しく識別されるため、アルゴリズムがこれを処理します。 

ゼロのないグリッドでは、すべての四角形の mex が 0 になります。 このアルゴリズムでは、値 0 はどのストリップでも生きているとマークされていないため、k はすぐに 0 になり、実現可能性チェックは空の制約セットで簡単に合格します。 

値 0 と 1 が存在するが空間的に分離されているグリッドは、交差が重要である理由を示しています。 両方がグローバルに存在する場合でも、それらの列間隔がどの行ペアでも重複していなければ、L と R は発散し、不正な mex が 2 になることを防ぎます。
