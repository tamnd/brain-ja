 ## 解決策
 ## 問題の理解

 3 行 N 列のグリッドが与えられています。 各セルには 0 または 1 が含まれており、2 人の候補者への投票を表します。 各セルは、バイナリ ラベルが付いた単位都市として考えることができます。 

すべての 3N 個のセルをちょうど N 個のグループに分割する必要があります。各グループにはちょうど 3 個のセルが含まれており、グリッド グラフ内の連結成分を形成します。 接続性とは、セルが対角線ではなくエッジで隣接していることを意味します。 このような各グループは地区と呼ばれます。 地区の 3 つのセルのうち少なくとも 2 つが 0 の場合はココナッツが勝ち、それ以外の場合はオレンジが勝ちます。 

タスクは、ゼロが多数を占める地区の数を最大化するために、グリッドの分割を接続されたトリプルに再配置することです。 

重要な自由は、元の列への垂直方向のスライスに制約されないことです。 すべてのセルが 1 回だけ使用される限り、接続されたトリオミノ形状のコンポーネントは許可されます。 

制約は小さく、N は最大 100、T は最大 10 です。これは、テスト ケースごとに O(N^3) さえも実行可能であることをすぐに示唆しています。 ただし、この構造は任意の組み合わせではなく、3 行のみのグリッドであり、通常、列ごとの動的プログラミングまたは列全体の状態圧縮が可能であることを示します。 

ゼロがまばらであるものの、接続された多数の異なるトリプルにグループ化できるように配置されている場合、微妙なエッジ ケースが発生します。 各列を個別にグループ化する単純な貪欲なアプローチは失敗する可能性があります。これは、最適な地区が列の境界を越えることが多いためです。 もう 1 つの失敗ケースは、局所的に最適なグループ化が初期にあまりにも多くのゼロを使用し、後で勝利するトリプルとペアにすることができない孤立したゼロを残す場合です。 

たとえば、パターン (0, 0, 1) を持つ 1 つの列について考えてみましょう。 単純なグループ分けでは、すぐに 1 つの地区が形成され、それが勝利としてカウントされます。 ただし、複数列の設定では、この列を隣接する列と組み合わせることで、地区全体でより効率的にゼロを再配分できるようになり、合計勝利数が増加する可能性があります。 

主な問題点は、各トリプルをグリッド内で接続する必要があり、可能な形状が大きく制限されることです。3 行グリッド内のすべての有効な 3 セル接続コンポーネントは、3 つの直線の垂直線、2 つの隣接する列をカバーする曲がった形状、または水平の鎖のような形状のいずれかになります。 この構造により、問題は扱いやすくなります。 

## アプローチ

 ブルートフォースアプローチでは、3×N グリッドを接続されたトリプルに分割する可能なすべての方法を列挙しようとします。 各状態は接続されたコンポーネントの選択を表し、それを再帰的に削除して続行します。 3×N グリッド内の接続されたトリオミノの数はすでに多く、パーティションの数は超指数関数的に増加します。 N が 10 程度の場合でも、各ステップで複数の形状の配置と重複する制約があるため、これはすぐに実行不可能になります。 

ボトルネックは、1 つの列で行われた決定が残りのセルのグループ化方法に影響を与えるが、ブルート フォースでは重複する部分問題が再利用されないことです。 同じ部分的な列構成が繰り返し表示されますが、再計算されます。 

重要な洞察は、グリッドを列ごとに処理し、部分的に形成された地区が列の境界を越えてどのように広がるかをエンコードすることです。 行が 3 つしかないため、考えられる「アクティブな境界状態」の数は少なくなります。 各状態は、現在および前の列のどのセルがすでに使用されているか、または次の列で完了するのを待っているかを示します。 これにより、問題は小さな状態空間を持つ列に対する動的プログラミングに変換されます。 

各ステップで、現在の列を含む接続されたトリプルを形成する方法を決定します。場合によっては、前の列の保留中のセルとペアになります。 各地区のサイズは正確に 3 であるため、部分的に形成された地区のセルの数がすでに取得されているかを追跡し、接続制約が確実に維持されるようにすることができます。

また、完了した地区ごとに、これまでに含まれるゼロの数を維持し、閉鎖されたときにその地区が勝利地区になるかどうかを決定します。 各地区は小さいため、州は完全な履歴を保存する必要はなく、現在オープンしているコンポーネントの部分的なカウントのみを保存する必要があります。 

これにより、指数関数的分割の問題が列遷移上の管理可能な DP に軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | N の指数 | 指数 | 遅すぎる |
 | 列状態に対する DP | O(N × S) ここで、S は小さな定数 | O(S) | 承認済み |

 ## アルゴリズムのチュートリアル

 列を左から右に処理し、現在の境界内のセルが未完成のコンポーネントにどのように接続されるかを記述する DP 状態を維持します。 

各州は、3 行のうちどの行に現在次の列への接続が保留されているか、および部分的に形成された地区ですでに使用されているセルの数をエンコードします。 各地区のサイズは 3 であるため、考えられる部分州は、開いたコンポーネントにすでに 0、1、または 2 個のセルが割り当てられている州だけです。 

また、部分的に形成された各コンポーネントに含まれるゼロの数も追跡して、コンポーネントが完成したときに、それが答えに貢献するかどうかを判断できるようにします。 

遷移は、有効な接続されたトリプルを配置することによって、現在の部分コンポーネントを次の列に拡張するあらゆる方法を試行することで構成されます。 グリッドの高さは 3 であるため、各列はその 3 つのセルのサブセットを列挙し、それらを前の列の残りの状態とペアにすることによって処理できます。 

## アルゴリズムのチュートリアル

 1. 列全体の DP を定義します。各状態は、現在の列のセルが前の列からの未完成のコンポーネントにどのように接続されているかを表します。 これが必要なのは、接続が複数の列にまたがる可能性があるため、ローカルで最終決定を行うことができないためです。 
2. 各状態について、有効な接続構成を使用して、現在の列の 3 つのセルをサイズ 3 のグループに割り当てようとします。 各構成は、列内で完全に地区を完了するか、前の列の保留中のセルに接続します。 これにより、すべてのコンポーネントがグリッド内で接続されたままになります。 
3. コンポーネントがサイズ 3 に達するたびに、コンポーネントに含まれるゼロの数が計算されます。 少なくとも 2 つのゼロが存在する場合、スコアが増加します。 この評価は地区が完全に閉鎖されている場合にのみ行われるため、正確性が保証されます。 
4. 現在の列の処理後に開いたままになっている部分コンポーネントの数に基づいて、次の列の DP 状態を更新します。 これらのオープン コンポーネントは、必要な接続情報を転送します。 
5. すべての地区が完全に形成されている必要があるため、すべての列を処理した後、開いている部分コンポーネントがない州のみを考慮します。 これらの状態の最大スコアが答えになります。 

### なぜ効果があるのか

 DP の不変条件は、列 i を処理した後、すべての有効な状態が、列 [1..i] のすべてのセルの完了した地区への正しい分割と、有効な接続されたトリプルにまだ拡張できる未完了のコンポーネントの一貫したセットを表すことです。 すべての遷移はグリッドの隣接関係と一致する最大 3 サイズの接続されたセットのみを構築するため、無効な部分グループ化は決して許可されません。 すべての最終状態は完全なパーティションに対応し、すべての可能なパーティションには対応する一連の遷移があるため、最適なソリューションが保存されます。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、ゼロが異なる列に分離されているが、列をまたがる形状によってのみ結合できる場合です。 A naive per-column grouping would fail here, but the DP correctly carries partial components across columns, allowing those zeros to be grouped into a single district later.

 もう 1 つのエッジ ケースは、1 つの列で垂直トリプルを形成することが局所的には最適であると思われるが、次の列ではより良いペアリングができない場合です。 The DP avoids committing greedily by keeping all partial configurations, ensuring that delayed grouping decisions can still recover optimal structures later.
