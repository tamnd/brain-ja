 ## 解決策
 ## 問題の理解

 単一の整数が与えられます$N$、これはサイコロの出目の隠されたシーケンスの結果です。 各ロールは標準的なサイコロであったため、隠れたシーケンスのすべての要素は 1 から 6 までの整数です。タスクは、積が次のようなサイコロの値の有効なマルチセットを再構築することです。$N$、すべての有効な再構成の中から、ロール値の可能な最大の合計を持つものを選択します。 

1 ～ 6 の範囲の数値の複数セットが積を生成できない場合$N$、答えは不可能なので出力します$-1$。 出力の上限もあります。可能な限り最適な合計が非常に大きくなった場合は、出力する必要があります。$10^9 + 7$その代わり。 

主な困難は、1 つの有効な因数分解を再構築することが求められるのではなく、乗法制約の下ですべての有効な因数分解を最適化することが求められることです。 これにより、単純な分解ではなく、直ちに因数分解と組み合わせ最適化の問題になります。 

制約$N \le 10^5$自由に因数分解できることを意味します$N$で$O(\sqrt{N})$または$O(\log N)$-type の動作でも安全です。 すべてのマルチセットを列挙したり、サイコロの値の組み合わせを検索しようとするアプローチは爆発的になります。なぜなら、中程度の製品でも多くの分解が存在する可能性があるからです。 

微妙な問題は、サイコロの値 1 にあります。 1 を掛けると積は変わりませんが、合計が増加するため、任意の 1 を許可すると、答えは無制限になります。 これは、最適な構築において 1 は無関係なものとして扱われなければならないことを意味し、製品構造について推論する際には 1 を事実上無視します。 

一般的にナイーブな解決策を破るエッジ ケースは、外部の素因数を含む入力です。$\{2,3,5\}$、特に 7 など$N=7$、分解は存在しません。 もう一つの厄介なケースは、$N=1$ここで、空の製品が許可されるかどうかを決定する必要があります。 正しい解釈は、任意の数の 1 を導入することは有効な有界最適構造ではないため、ロールは必要なく、合計が 0 になるということです。 

## アプローチ

 ブルートフォース解釈では、積が$N$、次にそれらの合計を計算し、最大値を取得します。 番号 2 から 6 に限定したとしても、これは依然として、各ステップが残りの積を分割し、因子の数で状態の数が指数関数的に増加する分岐プロセスを探索することを意味します。 たとえば、次のような適度な数字でも、$N = 2^{20}$すでに 2、4、およびその組み合わせへの膨大な数のパーティションに対応しているため、時間制限内で列挙することは不可能です。 

重要な観察は、構造が完全に乗算的であり、有効な解はすべて次の因数分解に対応するということです。$N$からの数字に$\{2,3,4,5,6\}$。 これらの数値自体は素数 2、3、5 から構成されており、4 が寄与しています。$2^2$そして6人が貢献$2 \cdot 3$。 任意の因数分解$N$素数 2、3、5 の外側では、即座に答えを得ることができなくなります。 

すべてを素指数で表現すると、問題は再分配タスクになります。有益な場合は常に 2 と 3 を 6 に束ねる方法を決定し、そうでない場合は 2 と 3 のままにしておく方法を決定します。 最適化は、同じ素数を維持しながら、異なるグループが合計にどのように影響するかを比較することにかかっています。 唯一の重要な取引は次のとおりです。$6$そしてペア$3 + 2$、両方とも同じ素数積を表しますが、合計は異なります。 

これにより、問題は組み合わせ検索から素数カウントに対する貪欲な構築へと軽減されます。

 ## アルゴリズムのチュートリアル

 ### アルゴリズムのチュートリアル

 1.因数分解$N$2、3、5 が何回現れるかを数えて、素数に変換します。 2、3、5 以外の素数が現れた場合は構築不可能なので、答えは次のようになります。$-1$。 このステップにより、表現可能なサイコロ係数内でのみ作業することが保証されます。 
2. しましょう$c_2, c_3, c_5$はそれぞれ素数 2、3、5 の数になります。 これらは、次の乗算構造を完全に説明します。$N$。 
3. できるだけ多くの 6 を構築します。 各 6 は 2 と 3 を 1 つずつ消費します。6 の数は$k = \min(c_2, c_3)$。 6 は (2,3) と同じ素数コストを持ちますが、2+3 よりも大きな合計が得られるため、これが最適です。 
4. 6 を形成した後、残りのカウントを減らします。$c_2 \leftarrow c_2 - k$、$c_3 \leftarrow c_3 - k$。 
5. 残りの素数を直接サイコロの面に変換します。 残りの 3 はそれぞれ 3 になり、残りの 2 はそれぞれ 2 になり、それぞれの 5 は 5 に貢献します。 
6. 合計を次のように計算します。$6k + 3c_3 + 2c_2 + 5c_5$。 
7. もし$N = 1$、必要なロールがないため、直接 0 を返します。 
8. 計算された合計が次の値を超える場合$10^9 + 7$、出力$10^9 + 7$。 

### なぜ効果があるのか

 有効な構造はどれも、次の素因数の分布に正確に対応します。$N$サイコロの値を形成するグループに分けます。 積を変えずに合計を変更できる唯一の自由は、2 と 3 を個別の面または組み合わせた 6 にグループ化する方法です。同じ因数分解を維持しながら合計では 6 が厳密に 2+3 よりも優勢であるため、すべての最適解はそのような組み合わせの数を最大化する必要があります。 残りのすべての因子には、実現可能性を変えることなく合計を改善する代替表現がないため、(2,3) の貪欲なペアリングは最適性を完全に特徴付けます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input().strip())
    
    if n == 1:
        print(0)
        return
    
    c2 = c3 = c5 = 0
    x = n
    
    while x % 2 == 0:
        c2 += 1
        x //= 2
    while x % 3 == 0:
        c3 += 1
        x //= 3
    while x % 5 == 0:
        c5 += 1
        x //= 5
    
    if x != 1:
        print(-1)
        return
    
    k = min(c2, c3)
    c2 -= k
    c3 -= k
    
    total = 6 * k + 3 * c3 + 2 * c2 + 5 * c5
    
    if total > MOD:
        print(MOD)
    else:
        print(total)

if __name__ == "__main__":
    solve()
```コードは特殊なケースを処理することから始まります。$N=1$次に、完全な素因数分解が実行されますが、追跡されるのは 2、3、および 5 のカウントのみです。残りの因数は、直ちに無効な構成を意味します。 

その後、2 と 3 を貪欲に組み合わせて 6 にするという、唯一の意味のある最適化ステップを実行します。 これは最小限のカウントを使用して行われ、ペアリングの機会が無駄にならないようにします。 

最後に、導出された式を使用して合計を計算します。 合計はカウントに応じて線形に増加し、Python の整数をオーバーフローさせることはできないため、最後にキャップ チェックが適用されますが、この問題では切り捨てが必要です。

 ## 特殊なケース

 ケース$N = 7$無効なプライムチェックをトリガーします。 因数分解中、2、3、5 の寄与を除いた残りの値は 7 になります。 1 ではないため、アルゴリズムは正しく拒否し、出力します。$-1$。 7 を許可された面に貪欲に分割しようとする単純なアプローチは、有効な分解が存在しないため失敗します。 

ケース$N = 1$因数分解ロジックの前に処理されます。 このガードがなければ、アルゴリズムはそれを素数がゼロであるものとして扱い、暗黙的に合計 0 を生成します。これはまだ正しいですが、これを明示的に処理することで、空の積のセマンティクスに関する曖昧さが回避され、意図された解釈との一貫性が保証されます。
