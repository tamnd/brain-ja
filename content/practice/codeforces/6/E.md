 ## 解決策
 ## 問題の理解

 私たちは、それぞれの高さがわかっているバールベリーの一連の本を年代順に並べて与えられます。 図書館は、選択した中で最も高い本と最も低い本の差が所定の制限を超えないように、連続する本を選択して博覧会を開催したいと考えています。`k`。 私たちのタスクは 2 つあります。1 つ目は、そのような選択に含まれる書籍の数を最大化すること、2 つ目は、高さの制約を満たしながらこの最大数に達するすべての連続する間隔を列挙することです。 

入力により提供されるのは、`n`、本の数、`k`、最大許容高さの差、および配列`h`本の高さの。 出力では最初に本の最大数を指定する必要があります。`a`および有効期間の数`b`、 に続く`b`各期間の開始と終了を示す 1 から始まるインデックスの行。 

と`n`最大 10^5 で 2 秒の時間制限がある場合、考えられるすべてのサブ配列をチェックする単純なアプローチでは遅すぎます。 考えられるすべての間隔を総当りで調べるには O(n^2) 回の操作が必要となり、最悪の場合は 10^10 回の比較に達する可能性があります。 これは実現不可能であるため、より効率的な方法を見つける必要があります。 

重要なエッジケースが発生するのは、`k`はゼロです。つまり、高さがまったく同じ連続した本のみを選択できます。 もう 1 つは、すべての本の高さが厳密に増減する場合で、注意しないと、最初または最後の本がすべての最大間隔で除外される可能性があります。 不用意にアプローチすると、境界の間隔を見逃したり、最大長を数え間違えたりする可能性があります。 

## アプローチ

 ブルート フォース アプローチは、考えられるすべての開始インデックスに対して反復されます。`i`そしてそれぞれについて、高低差が超えるまで間隔を右に延長します。`k`。 間隔ごとに長さを追跡し、現在の最大値と比較します。 この方法は、連続するすべてのサブシーケンスを考慮するため正しいですが、最悪の場合、O(n^2) の比較が必要になります。 と`n = 10^5`、これにより 10^10 の操作が行われ、2 秒の制限時間には遅すぎます。 

効率的な解決策を導き出す重要な観察は、最小値と最大値を効率的に維持する必要がある連続する部分配列のみに関心があるということです。 この構造により、スライディング ウィンドウの O(1) の最小値と最大値を取得できるデータ構造と組み合わせた 2 ポインター手法を使用できるようになります。 具体的には、2 つの両端キューを使用して最小高さと最大高さのインデックスを追跡すると、間隔を有効に保ちながら正しい境界を拡張できます。 間隔が無効になると、2 つのポインター間の間隔が常に高さの差の制約を満たすという不変条件を維持しながら、左ポインターを前方に移動します。 これにより、各要素が両端キューからプッシュおよびポップされるのは最大 1 回だけになるため、複雑さは O(n) に軽減されます。

 ## アルゴリズムのチュートリアル

 1. 2 つの両端キューを初期化します。1 つは最大高さを追跡するためのものです (`max_deque`) と最小の高さ用の 1 つ (`min_deque`）。 2つのポインタを初期化します。`l = 0`そして`r = 0`、現在の間隔を表します`[l, r]`。 現在の最大長を格納する変数を初期化します。`max_len`そしてリスト`intervals`有効な間隔で。 
2. 右ポインタを展開します`r`一度に一冊。 新しい本ごとに`h[r]`、後ろからインデックスを削除します。`max_deque`その間`h[r]`それらが表す高さよりも大きくなります。 これにより、`max_deque[0]`は常に間隔内の最大値を指します。 同様に、後ろのインデックスも削除します。`min_deque`その間`h[r]`それらが表す高さよりも小さいです。 
3.追加後`r`両方の両端キューに対して、現在の間隔かどうかを確認します。`[l, r]`高低差の制約に違反します。`h[max_deque[0]] - h[min_deque[0]] > k`。 そうなった場合はインクリメントします`l`差が最大になるまで間隔を縮めます`k`。 間隔外になった両端キューの先頭からインデックスを削除します。 
4. 間隔が空いたとき`[l, r]`は有効です。その長さを次と比較してください`max_len`。 超えた場合`max_len`、 アップデート`max_len`そしてリセットしてください`intervals`現在の間隔のリスト。 等しい場合`max_len`、現在の間隔を追加します。 
5. インクリメント`r`配列の最後まで。 ループ後、出力`max_len`、間隔の数、および 1 から始まるインデックス付けの各間隔。 

**機能する理由**: このアルゴリズムは、次の不変条件を維持します。`[l, r]`は常に次で終わる最大連続間隔です。`r`有効な身長差がある場合。 デキューを使用すると、最小値と最大値が常に効率的に追跡されるため、有効なサブシーケンスを見逃すことなく、各最大間隔の長さが正しく計算されます。 

## Python ソリューション```python
import sys
from collections import deque
input = sys.stdin.readline

n, k = map(int, input().split())
h = list(map(int, input().split()))

l = 0
max_len = 0
intervals = []

min_deque = deque()
max_deque = deque()

for r in range(n):
    while max_deque and h[r] > h[max_deque[-1]]:
        max_deque.pop()
    max_deque.append(r)
    
    while min_deque and h[r] < h[min_deque[-1]]:
        min_deque.pop()
    min_deque.append(r)
    
    while h[max_deque[0]] - h[min_deque[0]] > k:
        l += 1
        if max_deque[0] < l:
            max_deque.popleft()
        if min_deque[0] < l:
            min_deque.popleft()
    
    curr_len = r - l + 1
    if curr_len > max_len:
        max_len = curr_len
        intervals = [(l + 1, r + 1)]
    elif curr_len == max_len:
        intervals.append((l + 1, r + 1))

print(max_len, len(intervals))
for a, b in intervals:
    print(a, b)
```デキューにより、デキューに対する各操作が O(1) で償却されることが保証されます。 境界条件は、インデックスをチェックすることによって慎重に処理されます。`l`左ポインタが移動したとき。 間隔を保存する場合は、1 から始まるインデックスが適用されます。
