 ## 解決策
 ## 問題の理解

 花は上に生えます`d`-次元の整数グリッド。 原点から開始され、1 秒ごとに 1 つの座標軸に沿って 1 単位だけ移動します。 方向は常にその軸に沿って原点から離れる必要があります。 タスクは、正確な後に成長決定の異なるシーケンスが何通りあるかを数えることです。`t`秒。 2 つのシーケンスは、どの瞬間でも異なる軸または異なる方向を選択すると、異なります。 

入力により、次元数と成長ステップ数が与えられます。 出力は、これらのステップの有効な順序付けされたシーケンスの数を法でとったものです。`998244353`。 

制約により両方が許可されます`d`そして`t`と同じくらい大きくなる`200000`。 二次解法には次のものが必要になります`4 * 10^10`限界をはるかに超えた最悪の場合の操作。 最終的なソリューションは線形に近い必要があるため、ネストされたループで個々の秒数やディメンションを追跡することを避ける必要があります。 

難しいのは、単一の座標に何が起こるかを理解することです。 座標が初めて選択されると、それは正または負のいずれかになります。 ゼロに向かうことは禁止されているため、その座標上でその後の成長は 1 つの方向のみ可能です。 一度も使用されていない座標は方向の選択に寄与しません。 

いくつかの特殊なケースでは、よくある間違いが明らかになります。 

1 次元と 1 秒の場合:```
Input:
1 1

Output:
2
```唯一の座標は、プラスまたはマイナスのいずれかに成長できます。 軸ごとに 1 つの方向しかないことを前提としたソリューションは、誤った結果を返します。`1`。 

2 次元と 1 秒の場合:```
Input:
2 1

Output:
4
```花はどちらの次元とどちらの符号を選択​​することもできます。 ここでは最終位置のみを数えると同じ答えが得られますが、より大きな例では、異なる成長順序が同じ最終点に到達する可能性があります。 この問題では、異なる終了座標ではなく、異なる履歴が求められます。 

3 次元と 3 秒の場合:```
Input:
3 3

Output:
126
```2 回使用された座標には、可能な方向履歴が 4 つではなく 2 つだけあります。 最初のサインが選択されると、その座標での今後のすべての動きが強制されます。 

## アプローチ

 直接的なアプローチでは、考えられるすべての成長履歴をシミュレートしようとします。 毎秒、最初は`2d`座標が固定されると利用可能な選択肢の数はわずかに減少しますが、可能な履歴の数は依然として指数関数的に増加します。 のために`t`これはおよそ秒程度です`(2d)^t`、非常に小さな入力でも使用できなくなります。 

有用な観察は、各座標で行われた選択を分離することで得られます。 特定の座標が正確に選択されたと仮定します。`k`プロセス全体で 3 回。 もし`k = 0`、座標には決して触れないという動作が 1 つ考えられます。 もし`k > 0`、選択されたすべての動きが正の方向に進むか、選択されたすべての動きが負の方向に進むかの 2 つの動作が考えられます。 

残りの問題は、ステップがグローバルに順序付けされていることです。 コーディネートなら`i`選択されています`c_i`時間、すべてのステップの中でのそれらのステップの位置`t`瞬間は次の方法で選択できます。$$\frac{t!}{c_1!c_2!\cdots c_d!}$$方法。 

これは指数母関数につながります。 1 つの次元の寄与は次のとおりです。$$1 + 2\frac{x}{1!} + 2\frac{x^2}{2!} + 2\frac{x^3}{3!}+\cdots$$それは:$$1+2(e^x-1)=2e^x-1$$のために`d`次元の場合、必要な係数は次の係数です。`x^t`で：$$(2e^x-1)^d$$二項定理はこれを直接評価できる合計に変換します。$$(2e^x-1)^d
=
\sum_{i=0}^{d}
\binom di 2^i(-1)^{d-i}e^{ix}$$の係数`x^t`で`e^{ix}`は`i^t/t!`。 元のカウント式に次の乗算が行われます。`t!`となり、階乗は消えます。$$\text{answer}
=
\sum_{i=0}^{d}
(-1)^{d-i}\binom di2^ii^t$$ここで、問題は次元にわたる単一のループに縮小されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((2d)^t) | O(t) | 遅すぎる |
 | 最適 | O(d) | O(d) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 階乗および逆階乗を最大で事前計算します。`d`。 この式には二項係数が必要ですが、それぞれを個別に計算すると時間がかかりすぎます。 
2. 可能なすべての値を反復処理します。`i`から`0`に`d`。 値`i`展開時に指数項に寄与するために選択される次元の数を表します`(2e^x-1)^d`。 
3. それぞれについて`i`、次を計算します。$$(-1)^{d-i}\binom di2^ii^t$$そしてそれを答えに追加します。 二項係数はどの次元が寄与するかを選択します`2e^x`、一方、サインとパワーは残りの部分から来ます。`-1`項と指数係数。 

1. 最終結果のモジュロを正規化します。`998244353`そしてそれを印刷します。 

なぜ効果があるのか:

 生成関数は、すべての次元を個別にモデル化します。 の係数`x^t/t!`を配布する方法を記録します。`t`次元間の順序モーメント、一方、`2`使用されるすべての寸法について、可能な 2 つの符号が記録されます。 1次元母関数を次のように上げると、`d`の乗はすべての次元を結合します。 二項展開はカウントされるオブジェクトを変更せず、必要な係数をより速く抽出する方法を提供するだけです。 この拡張では、考えられるすべての履歴が 1 つの項に正確に対応し、すべての項が有効な履歴を表すため、式ではすべての回答が 1 回だけカウントされます。 

## Python ソリューション```python
import sys

input = sys.stdin.readline

MOD = 998244353

def solve():
    d, t = map(int, input().split())

    fact = [1] * (d + 1)
    for i in range(1, d + 1):
        fact[i] = fact[i - 1] * i % MOD

    inv_fact = [1] * (d + 1)
    inv_fact[d] = pow(fact[d], MOD - 2, MOD)
    for i in range(d, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % MOD

    ans = 0
    pow_two = 1

    for i in range(d + 1):
        comb = fact[d] * inv_fact[i] % MOD * inv_fact[d - i] % MOD
        term = comb * pow_two % MOD
        term = term * pow(i, t, MOD) % MOD

        if (d - i) & 1:
            ans -= term
        else:
            ans += term

        ans %= MOD
        pow_two = pow_two * 2 % MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```階乗配列を使用すると、すべての二項係数を一定時間で計算できます。`inv_fact`係数は素数であるため、フェルマーの小定理を使用して構築されます。 

ループは式に直接続きます。`pow_two`店`2^i`incrementally, avoiding repeated exponentiation. 値`pow(i, t, MOD)`モジュラー 2 進累乗を使用して大きな指数を効率的に処理します。 

ケース`i = 0`自然に扱われます。 制約があるため、`t >= 1`、`0^t`は`0`, したがって、この用語は何も貢献しません。 特別なケースは必要ありません。 

すべての加算は剰余化されます`MOD`すべての反復の後。 Python の整数はオーバーフローしませんが、値を減らしたままにしておくことで不必要な増加を回避し、実装を数式に近づけることができます。

    inv_fact = [1] * (d + 1)

    pow_two = 1

        comb = fact[d] * inv_fact[i] % MOD * inv_fact[d - i] % MOD

        else:
            ans += term

 ## 特殊なケース

 対象:```
1 1
```唯一の座標が一度選択されます。 花は次の場所に移動できます。`1`または`-1`、したがって、答えは次のとおりです`2`。 式では、`i = 1`期間は存続し、与えられます`2`。 

のために：```
2 1
```考えられる最初の動きは 4 つあります。いずれかの次元に沿ってプラスまたはマイナスです。 アルゴリズムは以下を計算します。$$(-1)^2\binom20 0^1
+
(-1)^1\binom21 2(1^1)
+
(-1)^0\binom22 4(2^1)$$これは次のようになります。$$-4+8=4$$のために：```
3 3
```座標を 3 回選択しても、8 つの可能性は生成されません。 最初の動きはその符号を選択​​し、次の 2 つは強制されます。 生成関数は係数を使用します`2x^3/3!`、その座標の 2 つの符号の選択肢のみが正しく寄与します。 

次のような大きな入力の場合:```
12345 67890
```アルゴリズムがパスや状態を構築することはありません。 次元を越えて線形パスを実行するだけであるため、膨大な数の成長履歴が考えられるにもかかわらず、依然として実行可能です。
