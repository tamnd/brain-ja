 ## 問題の理解

 花の種類ごとに、花束にはその種類の花をある程度の数だけ含めることができます。また、種類を使用する場合は常に、その選択された数が奇数である必要があります。 花の総数をできるだけ多くしたいと考えています。 タイプはブーケ内にまったく出現する必要がないため、その寄与はゼロになる可能性があります。 

1種類につき`a_i`利用可能な花の場合、可能な限り最高の奇数の寄与は、単純に次を超えない最大の奇数です。`a_i`。 もし`a_i`すでに奇数なので、すべて使用できます。 もし`a_i`が偶数の場合、花は 1 つ残さなければならないため、貢献度は次のようになります。`a_i - 1`。 

この調整をタイプごとに個別に行った後、ゼロ以外の寄与はすべて奇数になります。 合計の同等性は、使用する型の数のみに依存します。 奇数の奇数の値は奇数の合計を持ち、偶数の奇数の値は偶数の合計を持ちます。 したがって、もし`n`これは奇妙ですが、すべてのタイプを保持できます。 もし`n`が偶数の場合、1 つの型を完全に省略する必要があります。 損失をできるだけ少なくするために、調整後の寄与が最小となるタイプを除外します。 

制約`n <= 100000`これは、ソリューションがほぼ直線的な時間で配列を処理する必要があることを意味します。 アン`O(n^2)`メソッドは周囲で実行できます`10^10`1 秒の制限をはるかに超える上限での操作。 たとえ`O(n log n)`答えには合計と最小値だけが必要なので、ここではメソッドは不要です。 個体値が満たされている`a_i <= 1000`したがって、答えは標準の 32 ビット整数に簡単に収まりますが、Python 整数でも自然に処理できます。 

選択されたすべてのカウントを奇数にすることだけに重点を置いた実装を騙す可能性のあるエッジ ケースがいくつかあります。 たとえば、あるタイプでは、```
1
2
```最大の有効な花束には以下が含まれます`1`花ではなく、`2`使用できるカウントは奇数でなければならないためです。 

型の数が偶数の場合、1 つの型全体を削除する必要があります。 例えば、```
2
2 3
```調整されたカウントになります`1`そして`3`。 両方を維持すると得られる`4`、これは偶数なので、正しい答えは次のとおりです。`3`。 すべての型の最大の奇数カウントを単に合計する不用意な解決策では、次の出力が出力されます。`4`。 

削除する型は、使用可能な数を奇数に調整した後に選択する必要があります。 例えば、```
4
2 7 4 9
```になる`1, 7, 3, 9`。 4 種類あるので 1 つを省略し、寄与分を削除する必要があります。`1`最大限の答えを与える`19`。 オリジナルに基づいてタイプを選択する`a_i`奇妙な調整を考慮せずに行うと、間違った選択をしてしまう可能性があります。 

## アプローチ

 直接的な総当たりアプローチでは、花の種類のすべてのサブセットを考慮できます。 各サブセットについて、選択したすべてのタイプから最大の奇数を取得し、それらの寄与を合計し、選択したタイプの数が奇数であるかどうかを確認し、最大の有効な合計を保持します。 これは正しいです。選択した種類のセットが固定されると、選択した種類から花の数を減らしても、花束が小さくなるだけだからです。 

問題はサブセットの数です。 と`n`種類があります`2^n`可能なサブセット。 で`n = 100000`、これについてです`10^30103`したがって、1 つのサブセットを一定時間で検査することさえ絶望的です。 ブルート フォースは、可能な型のすべてのコレクションを明示的に探索するため機能しますが、型の数が多くなると失敗します。 

重要な観察により、これらの選択肢がほぼすべて削除されます。 各タイプについて、利用可能な最大の奇数カウント以外のものを取得する理由はありません。 その調整後、使用されるすべての型は奇数に寄与します。 したがって、残る唯一の決定は、使用するタイプの数です。 もし`n`が奇数である場合、すべてのタイプを使用すると合計が奇数になります。 もし`n`が偶数の場合、すべてのタイプを使用すると合計は偶数になるため、1 つのタイプだけを省略する必要があります。 調整された寄与はすべて正であるため、複数のタイプを省略しても、答えが小さくなるだけです。 最適に省略されたタイプは、単純に調整された寄与が最小のタイプです。 

これにより、問題全体がアレイを 1 回通過するだけで済み、調整された奇数カウントの合計とその最小値が維持されます。

 ## アルゴリズムのチュートリアル

 1. を読んでください。`n`利用可能な花の数を調べ、合計と最小調整済み寄与分を初期化します。 
2. あらゆる人にとって`a_i`を超えない最大の奇数に変換します。 もし`a_i`が偶数なので、1 を引きます。 この調整された値を合計に加算し、最小値を更新します。 

これは、個々のタイプにとって最適です。なぜなら、奇数の寄与を正の量だけ減らすと、無効になるか、花束が小さくなるからです。 
3. もし`n`奇数なので合計をそのままにしておきます。 すべての調整後の寄与は奇数であり、その数も奇数であるため、それらの合計は奇数になります。 
4. もし`n`が偶数である場合は、調整後の寄与の最小値を合計から差し引きます。 これにより、その花の種類全体が事実上省略され、残りの部分が残ります。`n - 1`使用されているタイプ。 以来`n - 1`が奇数の場合、結果の合計は奇数になります。 

すべての調整された寄与がプラスであり、すべての単一タイプの中で最も小さいタイプを削除すると失われる花が最も少ないため、1 つのタイプだけを削除するのが最適です。 
5. 結果の合計を出力します。 

### なぜ効果があるのか

 調整後、含める可能性のあるすべての型は正の奇数に寄与し、それがその型の有効な最大寄与になります。 したがって、最適なブーケは、含まれるすべてのタイプに対して最大の奇数寄与を使用します。 

奇数の和のパリティは項の数によって決まります。 いつ`n`が奇数の場合、調整された寄与分はすべて使用でき、合計は自動的に奇数になります。 いつ`n`が偶数である場合、すべての寄与を使用すると偶数の合計が生成されるため、奇数の合計には奇数の使用型が必要です。 そのような最大の数は`n - 1`つまり、1 つのタイプだけを削除する必要があります。 調整された寄与はすべて正であるため、より多くのタイプを削除しても答えは改善されず、最小の寄与を削除すると最大の残りの合計が得られます。 したがって、アルゴリズムは常に最適な花束を構築します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    total = 0
    mn = 10**18

    for x in a:
        if x % 2 == 0:
            x -= 1

        total += x
        mn = min(mn, x)

    if n % 2 == 0:
        total -= mn

    print(total)

if __name__ == "__main__":
    solve()

import io

def solve():

    n = int(input())

    mn = 10**18

    for x in a:
        if x % 2 == 0:

def run(inp: str) -> str:
    old_stdin = sys.stdin

        return sys.stdout.getvalue().strip()
    finally:
