 ## 解決策
 ## 問題の理解

 プログラムはすべての 4 回転を考慮します`(a, b, c, n)`正の整数の`n >= 3`。 その順序には 2 つのレベルがあります。 まず、4 つの座標のうちの最大値によって 4 つがグループ化されます。 このようなグループの 1 つでは、それらは辞書順に並べ替えられます。`(a, b, c, n)`。 4 倍ごとに、次のことを出力するだけで済みます。`a^n + b^n`より大きいか小さい`c^n`。 

入力により 2 つの位置が与えられます`l`そして`r`この無限のシーケンスの中で。 これらの位置を占める 4 倍体を正確に再構成し、対応する不等式を出力する必要があります。 

難しいのは、`l`そして`r`と同じ大きさにすることができます`10^12`。 要求された間隔には最大でも`10^4 + 1`答えは、位置自体がシーケンスのはるか奥にある可能性があります。 以前の 4 回転をすべて生成することは完全に不可能です。 

制約の中に有用な境界が隠されています。 すべての座標が最大であれば`m`、それから、`m^3(m-2)`4回転の可能性があるため、`a`、`b`、 そして`c`それぞれが持っています`m`選択肢をしながら`n`もっている`m-2`からの選択肢`3`を通して`m`。 以来`1001^3 * 999`すでに超えています`10^12`、リクエストされたすべてのポジションは、最大で最大のグループに属します。`1001`。 これにより、たとえシーケンス自体が巨大であっても、最大値の探索空間が非常に小さくなります。 

いくつかの注文詳細は誤って処理されやすいものです。 

最初の4回転は、`(1,1,1,3)`、つまり指数は次から始まります`3`ではありません`1`。 たとえば、入力`1 1`生産しなければならない`1^3+1^3>1^3`。 を扱う実装`n`からの範囲として`1`すぐに間違ったシーケンスを構築してしまいます。 

2 つの最大値の間の遷移は、もう 1 つの一般的なオフバイワン トラップです。 最大の最後の4回転`3`は`(3,3,3,3)`、位置があります`27`。 次の4回転は、`(1,1,1,4)`の位置で`28`。 したがって、入力`28 28`生成する`1^4+1^4>1^4`。 ポジションを含むグループを検索する`<=`間違った側では、後のすべての答えをグループ全体でずらすことができます。 

最大値が辞書編集上の接頭辞の以前にすでに表示されている可能性があるという事実も、有効な補完の数を変更します。 たとえば、かつて`a=M`、以降のすべての座標は自由に選択できます`M`、クアドルプルにはすでに最大値があるため、`M`。 一方、次のようなときは、`a<M`、残りの座標には`M`。 この区別を無視すると、プレフィックスに間違った数の 4 倍子が与えられ、その結果、間違ったタプルが選択されます。 

最後に、比較自体は実際の整数累乗を使用する必要があります。 例えば、`(3,3,2,3)`与える`3^3+3^3 > 2^3`。 Python の整数には任意の精度があるため、オーバーフローすることなくこれらのべき乗を直接評価できます。 

## アプローチ

 直接的な解決策では、必要な順序で正確に 4 倍子を列挙します。 あらゆる可能な最大値に対して`M`のすべての値を列挙できます。`a`、`b`、`c`、 そして`n`、最大値を持たない組み合わせをスキップします。`M`、位置に到達するまで`r`。 これは、シーケンスの定義に文字通り従うため、正しいです。 

問題は反復回数です。 最初`M`グループに含まれるもの`M^3(M-2)`4倍になるので、およその位置に到達します`10^12`処理が必要です`10^12`四倍。 検出力を計算するコストを考慮する前でさえ、1 兆回の反復は制限時間をはるかに超えています。 二乗によるべき乗で各べき乗を計算すると、別の対数係数が追加されます。 

重要な観察は、先行する 4 倍を生成する必要がまったくないということです。 指定された最大値の前に 4 つ組が何個存在するかを数え、二分探索で要求された位置を含む最大値を特定し、次にプレフィックス カウントを使用してその最大グループ内の各座標を特定できます。 

固定最大値の場合`M`、すべての座標は次のとおりです。`[1,M]`そして`n`にある`[3,M]`。 最大値を含むクワドルプルの合計数`M`は`F(M) = M^3(M-2)`。 

したがって、その最大値が正確に次の 4 倍数になります。`M`地位を占める`F(M-1)+1`を通して`F(M)`。 

見つけた後`M`、そのグループ内で要求された位置がわかります。 次に再構築します`(a,b,c,n)`左から右へ。 各座標には、関連するケースが 2 つだけあります。 プレフィックスにすでに含まれている場合`M`、残りのすべての座標は制限されません。 そうでない場合は、以下の値を選択します。`M`後の座標が等しくなる必要があることを意味します`M`。 

固定位置の場合、すべての候補値は次の値より小さい`M`有効な完了の数は同じです。 値`M`最大要件を即座に満たすため、完了数が異なります。 この候補ごとの定数構造により、すべての値をスキャンするのではなく、二分探索で正しい座標を見つけることができます。 

ブルート フォースはシーケンスに正確に従うため機能しますが、要求されたランクが大きくなると失敗します。 すべてのプレフィックスが代数的に数えられるという観察により、必要なグループに直接ジャンプしてから、必要な 4 倍体にジャンプできます。

## アルゴリズムのチュートリアル

 1. 定義する`F(M) = M^3(M-2)`。 

これは、4 つの座標が最大以下であるすべての 4 つ組をカウントします。`M`、 と`n`に限定される`3..M`。 したがって`F(M)`まさに最大値に属する最後の位置です`M`。 
2. 最小値の二分探索`M`満足のいく`F(M) >= rank`。 

これにより、要求された位置を含む最大のグループが識別されます。 このグループの最初のポジションは、`F(M-1)+1`ので、設定します`k = rank - F(M-1)`。 

今`k`正確に最大値を持つグループ内の 1 から始まる位置です`M`。 
3. 再構築`a`、`b`、`c`、 そして`n`左から右へ。 

ブール値を維持する`maxed`すでに選択されているプレフィックスに次のものが含まれているかどうかを確認する`M`。 最初は誤りです。 

のために`a`、 もし`a<M`、次のいずれか`b`、`c`、 または`n`等しい必要があります`M`。 完成数は、`M^2(M-2) - (M-1)^2(M-3)`。 

もし`a=M`、最大条件はすでに満たされており、`M^2(M-2)`完成品。 

これらのカウントはどの場合でも一定です。`a<M`, したがって、最小のものを二分探索できます`a`累計クリア数が に達した方`k`。 
4. 選択後`a`、より小さい値に属するタプルの数を減算します。`a`、更新します`maxed`もし`a=M`。 

同じ考え方が当てはまります`b`。 最大値がまだ現れていない場合は、`b<M`もっている`M(M-2) - (M-1)(M-3)`完了しながら、`b=M`もっている`M(M-2)`完成品。 

すでに最大値が出現している場合は、`b`まさに`M(M-2)`完成品。 
5. 同じ推論を次の場合にも適用します。`c`。 

もし`M`がまだ表示されていないため、選択します`c<M`力`n=M`, つまり、完了は 1 つだけです。 選択する`c=M`すべての指数を許可します`n`から`3`を通して`M`、与える`M-2`完成品。 

すでに最大値が出現している場合は、`c`もっている`M-2`考えられる指数。 
6.ハンドル`n`最後。 

最大値がすでに出現している場合、有効な指数は正確に次のようになります。`3,4,...,M`、という順番で。 ローカルランクが直接決定します`n = 3 + k - 1`。 

選択後に最大値が表示されない場合`c`、 それから`n`強制される`M`。 
7. Python の任意精度の整数を使用して 2 つの辺を比較します。 

印刷する`a^n+b^n>c^n`左側が大きい場合、そうでない場合は印刷します`a^n+b^n<c^n`。 

フェルマーの最終定理は、これらの正の整数に対して等価性が生じないことを保証します。`n>=3`。 

### なぜ効果があるのか

 中心的な不変条件は次のとおりです`k`は常に、すでに固定されたプレフィックスのすべての有効な補完の中で必要なタプルの辞書編集上のランクです。 すべての候補座標について、その候補で始まる有効なタプルの数を正確に数えます。 辞書編集的な順序では、小さい候補を持つすべてのタプルが最初に配置されるため、累積完了数が次の値に達した最初の候補が配置されます。`k`必要なタプルの座標である必要があります。 先行するすべての候補を削除した後、同じ不変式が次の座標にも当てはまります。 

可能性は 2 つだけであるため、完了カウントは正しいです。 最大の場合`M`がすでに出現している場合、残りのすべての座標は独立して任意の許容値を取ることができます。 表示されていない場合は、以下の値を選択してください`M`残りの座標を含める必要があります`M`に制限された割り当てを差し引いてカウントされます。`1..M-1`。 これにより、すべての接頭辞によって表されるタプルの正確な数が得られるため、すべての二分探索で正しい辞書編集座標が選択されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def total(m):
    if m < 3:
        return 0
    return m * m * m * (m - 2)

def find_maximum(rank):
    lo, hi = 3, 4

    while total(hi) < rank:
        hi *= 2

    while lo < hi:
        mid = (lo + hi) // 2
        if total(mid) >= rank:
            hi = mid
        else:
            lo = mid + 1

    return lo

def choose_coordinate(m, k, pos, maxed):
    if pos == 0:
        if maxed:
            small = big = m * m * (m - 2)
        else:
            small = (
                m * m * (m - 2)
                - (m - 1) * (m - 1) * (m - 3)
            )
            big = m * m * (m - 2)

    elif pos == 1:
        if maxed:
            small = big = m * (m - 2)
        else:
            small = (
                m * (m - 2)
                - (m - 1) * (m - 3)
            )
            big = m * (m - 2)

    else:
        if maxed:
            small = big = m - 2
        else:
            small = 1
            big = m - 2

    lo, hi = 1, m

    while lo < hi:
        mid = (lo + hi) // 2

        if mid < m:
            count = mid * small
        else:
            count = (m - 1) * small + big

        if count >= k:
            hi = mid
        else:
            lo = mid + 1

    value = lo

    before = (value - 1) * small
    k -= before

    return value, k

def get_tuple(rank):
    m = find_maximum(rank)

    k = rank - total(m - 1)

    a, k = choose_coordinate(m, k, 0, False)
    maxed = (a == m)

    b, k = choose_coordinate(m, k, 1, maxed)
    maxed = maxed or (b == m)

    c, k = choose_coordinate(m, k, 2, maxed)
    maxed = maxed or (c == m)

    if maxed:
        n = 3 + k - 1
    else:
        n = m

    return a, b, c, n

def solve(data):
    l, r = map(int, data.split())

    ans = []

    for rank in range(l, r + 1):
        a, b, c, n = get_tuple(rank)

        left = a ** n + b ** n
        right = c ** n

        if left > right:
            op = '>'
        else:
            op = '<'

        ans.append(f"{a}^{n}+{b}^{n}{op}{c}^{n}")

    return '\n'.join(ans)

def main():
    data = input()
    sys.stdout.write(solve(data))

if __name__ == "__main__":
    main()

いつ`maxed`それは本当です、`small`そして`big`最大要件がすでに満たされているため、これらは等しいです。 それが偽りのときは、`small`決して使用しない構成を差し引くことで得られます。`M`。 この減算が重要な組み合わせステップです。 

二分探索では、タプルの累積数が少なくとも次の最初の座標を求めます。`k`。 以下の候補者については`M`、累積カウントは単純に`candidate * small`。 のために`M`、それは`(M-1)*small + big`。 座標を見つけたら、`(value-1)*small`タプルはすでにスキップされているため、その量はから削除されます。`k`。

 ## 特殊なケース

 最低限の入力に関しては`1 1`、二分探索で次のことがわかります。`M=3`なぜなら`F(2)=0`そして`F(3)=27`。 ローカルランクは`1`したがって、最初の座標は`1`、2番目は`1`、そして3番目は`1`、そして最後に`n=3`。 結果はまさに`1^3+1^3>1^3`。 これにより、誤って指数を許可する実装が捕捉されます。`1`または`2`。 

入力用`27 27`、ローカルランクは`27`、最大値の最終位置`3`グループ。 したがって、すべての座標は次のように選択されます。`3`、生産`(3,3,3,3)`。 出力は`3^3+3^3>3^3`。 これにより、特別な`M`候補はより大きな完了カウントを受け取り、グループの最後のタプルはスキップされません。 

入力用`28 28`、`F(3)=27`, したがって、検索は次のようになります。`M=4`。 ローカルランクは`1`。 正確に最大値を持つ辞書編集上最小のタプル`4`は`(1,1,1,4)`最大値はどこかで発生する必要があるため、`n`は最後の座標であり、最初の場所になります。`4`以前のすべての座標を次と等しく保ちながら表示できます`1`。 出力は`1^4+1^4>1^4`。 これは、グローバル ランクをローカル ランクに変換するための重要な境界ケースです。 

最大入力の場合`10^12 10^12`、最大グループは`M=1001`。 ローカルランクは`2,000,000,000`、そして再構築により得られるのは`(667,1001,668,336)`。 の外観`1001`で`b`は、最大条件に関して完了したものとしてプレフィックスをただちにマークするため、残りの座標は通常の辞書編集値として選択されます。 最後の比較は、`667^336+1001^336>668^336`。 これにより、カウント方法がシーケンスのずっと先まで有効であり、先行するものを列挙する必要がないことが確認されます。`10^12`タプル。
