 ## 解決策
 ## 問題の理解

 各テスト ケースには、(a) と (b) と呼ばれる 2 つの交差しない線分と、ゼロ以外の方向ベクトル (\vec v) があります。 (a) 上の点 (A) が (A) から (\vec v) の方向に移動して、(b) 上の点 (B) に当たるかどうかを判断する必要があります。 

同様に、次のような点 (A\in a) と (B\in b) が必要です。 

[
 B-A=t\vec v
 】

 一部の場合は (t>0)。 厳密な肯定性は、2 つのセグメントが交差しないという事実から得られるため、(A) と (B) は同じ点になることはできません。 

各テスト ケースには、2 つのセグメントの端点の 8 つの座標と視線方向の 2 つの座標が含まれています。 最大 (50,000) の独立したテスト ケースが存在する可能性があります。 すべての座標の絶対値は最大 (10^6) であるため、(O(n)) または (O(n\log n)) の合計解は容易に十分高速ですが、すべてのセグメント内で大規模な検索を実行するアルゴリズムは適切ではありません。 

主な問題は、(A) と (B) がセグメント上の任意の実点であることです。 エンドポイントのみをチェックするだけでは十分ではありません。 例えば、```
1
0 0 4 4 1 3 3 1 1 1
```方向は ((1,1)) です。 端点のペアは目的の方向を示しませんが、2 つのセグメントには同じ垂直座標を持つ点が含まれており、2 番目のセグメント上のそのような点の 1 つは、最初のセグメント上の対応する点より前にあります。 4 つのエンドポイント ペアのみをチェックするソリューションでは、これが見逃される可能性があります。 

2 つ目の罠は方向です。 考慮する```
1
0 0 1 0 -3 0 -2 0 1 0
```これらのセグメントは同じ水平線上にありますが、方向 ((1,0)) を見ると 2 番目のセグメントが最初のセグメントの後ろにあります。 正しい答えは、`No`。 2 つのセグメントが同じ線上にあるかどうかだけをチェックするテストでは、誤答が発生します。`Yes`。 

3 番目のエッジ ケースは、セグメントが視線方向に平行な場合に発生します。 例えば、```
1
0 0 1 0 2 0 2 1 1 0
```(\vec v) に平行な最初のセグメントがあります。 正しい答えは、`Yes`なぜなら、点 ((1,0)) は右に移動して 2 番目のセグメントの ((2,0)) に到達する可能性があるからです。 最初のセグメントの垂直座標の差で除算する式は、分母ゼロを個別に処理する必要があります。 

最後に、セグメントは共通の垂直座標を 1 つだけ持つことができます。 例えば、```
1
0 0 1 0 2 0 2 1 1 0
```まさにこの状況にあります。 投影された間隔の重なりを閉じた間隔ではなく開いた間隔として扱うと、境界での有効な点が失われます。 

## アプローチ

 直接的な強引なアイデアは、両方のセグメントをパラメータ化し、(A) の可能な位置を検索することです。 固定 (A) の場合、光線 (A+t\vec v)、(t\geq0) が交差するかどうかをテストできます (b)。 難しいのは、(A) のパラメータが連続であることです。 サンプリング (K) 位置では、テストごとに (O(K)) 個の作業量が得られ、最悪の場合は (50,000K) 個のサンプルが得られます。 (K=10^5) の場合でも、つまり (5\cdot10^9) 個のサンプルになります。 より根本的には、有効なブロッキング ポイントが 2 つのサンプルの間に存在する可能性があるため、有限サンプリングは正確なアルゴリズムではありません。 

正確な定式化は、最初は 3 つの連続変数、(a) の位置、(b) の位置、および移動距離 (\vec v) を持つシステムのように見えます。 考えられるすべての構成に対してシステムを個別に解決することは、不必要に複雑になります。 有益な観察は、方向条件には 2 つの独立した部分があるということです。 変位 (B-A) には (\vec v) に垂直な成分があってはならず、(\vec v) に沿った成分は正でなければなりません。 

任意の点 (P=(x,y)) に対して 2 つの座標を定義します。 

[
 q(P)=\演算子名{cross}(\vec v,P)=v_x y-v_y x
 】

 そして

 [
 p(P)=\演算子名{ドット}(\vec v,P)=v_xx+v_yy。 
】

 値 (q) は、一定のスケールまで、視線方向に垂直な位置を測定します。 値 (p) は、視線方向に沿った位置を一定のスケールで測定します。 

ここで、(B-A=t\vec v) と仮定します。 それから

 # \オペレータ名{cross}(\vec v,B-A)

 # \オペレーター名{cross}(\vec v,t\vec v)

 1.

 】

 したがって、(A) と (B) は同じ (q) 座標を持つ必要があります。 

同時に、

 # \オペレータ名{ドット}(\vec v,B-A)

 t|\vec v|^2。 
】

 (t>0) なので、(p(B)>p(A)) が必要です。 セグメントが交差していないことが保証されているため、有効なペアに対して等価性は発生しません。そのため、(p(B)\geq p(A)) のチェックも安全です。 

(q) はセグメントに沿って線形であるため、セグメントの (q) 値は間隔を形成します。 したがって、2 つのセグメントは、(q) 間隔がオーバーラップする場合にのみ互いに​​ブロックする可能性があります。 

その重なりの内側で、指定された (q) 座標を持つ各セグメントの点が線形補間によって決定されます。 したがって、(p_A(q)) と (p_B(q)) は一次関数になります。 彼らの違い

 [
 d(q)=p_B(q)-p_A(q)
 】

 も直線的です。 閉区間上の線形関数は、2 つの終点のいずれかで最大値に達します。 したがって、重複する (q) 間隔の 2 つの端点を検査するだけで済みます。 

これが重要な削減です。 連続存在の問題は、有理数の 2 つの正確な比較になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースサンプリング | (O(K)) テストごと | (O(1)) | 遅すぎて正確ではありません |
 | 最適な投影法 | テストあたり (O(1)) | (O(1)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 両方のセグメントのすべての端点について、その垂直座標 (q=\operatorname{cross}(\vec v,P)) と平行座標 (p=\operatorname{dot}(\vec v,P)) を計算します。 これら 2 つの整数値は、この問題の目的の要点を完全に説明しています。 
2. 各セグメントについて、その 2 つの (q) 値の最小値と最大値を取得します。 これらは、まさにそのセグメントがカバーする垂直座標の範囲です。 
3. 2 つの (q) 範囲の交差を計算します。 左の端点が右の端点より大きい場合、範囲は互いに素であるため、どの点のペアも同じ (q) 座標を持つことはできません。 答えはすぐに`No`。 
4. 重なりを ([L,R]) とします。 セグメントの範囲内の特定の値 (q=t) について、線形補間によってその (p) 座標を回復します。 セグメントの端点の座標が ((q_0,p_0)) および ((q_1,p_1)) である場合、

 [
 p(t)=
 \frac{p_0(q_1-t)+p_1(t-q_0)}
 {q_1-q_0}。 
】

 (q_0=q_1) の場合、セグメントは (\vec v) に平行であるため、その (q) 座標は一定であり、唯一の関連する (q) における (p) 座標は単にその端点 (p) になります。 

1. 両方のセグメントを (q=L) で評価します。 それらの (p) 座標を比較します。 (p_B(L)\geq p_A(L)) が必要です。 
2. 両方のセグメントを (q=R) で評価し、同じ比較を実行します。 (p_B(q)-p_A(q)) はオーバーラップにわたって線形であるため、どこでも負でない場合、これら 2 つの端点のいずれかでも負ではありません。 
3. 浮動小数点の代わりにクロス乗算を使用して補間された値を比較します。 もし

 [
 p_A=\frac{n_A}{d_A},
 \qquad
 p_B=\frac{n_B}{d_B},
 】

 分母が正の場合、

 [
 p_B\geq p_A
 】

 と同等です

 [
 n_Bd_A\geq n_Ad_B。 
】

 Python の整数は任意の精度を持つため、これらの積は安全です。 

これが機能する理由: オーバーラップ内のすべての垂直座標 (q) に対して、各セグメント上に対応する点が 1 つあります。ただし、(\vec v) に平行なセグメントには可能な点 (q) が 1 つだけあります。 2 つの点が同じ視線上にあるという条件は、正確に (p_B(q)>p_A(q)) です。 2 つの (p) 座標の差は (q) では線形であるため、オーバーラップにわたる最大値は (L) または (R) で達成されます。 アルゴリズムは両方をチェックするため、有効なペアが存在する場合は正確にそれを見つけます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(data):
    ax1, ay1, ax2, ay2, bx1, by1, bx2, by2, vx, vy = data

    def coords(x, y):
        # q: coordinate perpendicular to v
        # p: coordinate along v
        q = vx * y - vy * x
        p = vx * x + vy * y
        return q, p

    a0 = coords(ax1, ay1)
    a1 = coords(ax2, ay2)
    b0 = coords(bx1, by1)
    b1 = coords(bx2, by2)

    aq0, ap0 = a0
    aq1, ap1 = a1
    bq0, bp0 = b0
    bq1, bp1 = b1

    left = max(min(aq0, aq1), min(bq0, bq1))
    right = min(max(aq0, aq1), max(bq0, bq1))

    if left > right:
        return False

    def value_at(q0, p0, q1, p1, q):
        if q0 == q1:
            return p0, 1

        den = q1 - q0
        num = p0 * (q1 - q) + p1 * (q - q0)

        if den < 0:
            den = -den
            num = -num

        return num, den

    for q in (left, right):
        an, ad = value_at(aq0, ap0, aq1, ap1, q)
        bn, bd = value_at(bq0, bp0, bq1, bp1, q)

        if bn * ad >= an * bd:
            return True

    return False

def main():
    t = int(input())
    out = []

    for _ in range(t):
        data = list(map(int, input().split()))
        out.append("Yes" if solve_case(data) else "No")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```の`coords`関数は中心座標変換を実行します。 外積は垂直座標を示し、ドット積は視線方向に沿った座標を示します。 どちらの座標系に共通の正のスケールを乗算しても比較は変わらないため、(|\vec v|) による正規化は必要ありません。 

次の 4 行は 2 つの (q) 間隔を計算し、それらを交差させます。 ブロッキング ポイントはいずれかのセグメントのエンドポイントになることが許可されているため、エンドポイントが含まれています。 

の`value_at`関数は正確な線形補間を実行します。 分母は正になるように正規化されているため、以降のすべての比較が同じ方向になります。 特別な場合`q0 == q1`視線方向に平行なセグメントは一定の垂直座標を持つため、 が必要になります。 

最後のループではチェックのみが行われます`left`そして`right`。 これらは任意のサンプル ポイントではありません。 これらは、垂直座標の実現可能な範囲全体の端点であり、2 つの平行座標の差はその範囲で線形です。 

ソリューションのどこにも浮動小数点演算はありません。 これは、投影後に 2 つのセグメントが非常に小さな正確な差によって分離される可能性があり、浮動小数点比較によって答えが変わる可能性があるため、重要です。 最大の中間値は (10^6) よりもはるかに大きくなりますが、Python の整数は自動的に増加するため、オーバーフローの問題はありません。

 ## 特殊なケース

 最初のエッジ ケースは、垂直座標の境界です。 考慮する```
1
0 0 1 0 2 0 2 1 1 0
```(\vec v=(1,0)) の場合、(q=y) と (p=x) が得られます。 セグメント (a) には (q) 範囲 ([0,0]) があり、セグメント (b) には (q) 範囲 ([0,1]) があります。 それらの重なりは正確に (q=0) です。 その座標では、(a) には (p=0) ～ (1) があり、(b) には (p=2) があるため、比較は成功し、答えは次のようになります。`Yes`。 ここでは閉じた間隔が重要です。 

2 番目のエッジ ケースは、視線方向に平行なセグメントです。 同じ入力において、セグメント (a) は (q_0=q_1=0) を持ちます。 補間ルーチンは、分割する前にこれを検出します。 その (p) 座標はエンドポイントから直接取得され、アルゴリズムはそれをセグメント (b) が到達する点 (q=0) と比較します。 これにより、`Yes`ゼロ除算なしで。 

3 番目のエッジ ケースは、同一線上にある 2 つのセグメントが間違った順序で指している場合です。```
1
0 0 1 0 -3 0 -2 0 1 0
```両方の (q) 範囲は ([0,0]) であるため、垂直条件だけでアライメントの可能性が存在することがわかります。 ただし、(q=0) では、最初のセグメントは (0) から (1) までの (p) 値を持ち、2 番目のセグメントは (-3) から (-2) までの (p) 値を持ちます。 2 番目のセグメントは最初のセグメントの後ろにあるため、どこでも (p_B<p_A) となり、答えは次のようになります。`No`。 

4 番目のエッジ ケースは、完全に独立した垂直投影です。```
1
0 0 1 0 0 2 1 2 1 0
```最初のセグメントは (q=0) を持ち、2 番目のセグメントは (q=2) を持ちます。 範囲の交差部分は空であるため、アルゴリズムは補間前に停止し、戻ります。`No`。 これにより、近くにあるが異なる投影座標を持つセグメントを誤って位置合わせされたものとして扱うことが回避されます。 

5 番目のエッジ ケースは、方向テストのゼロ距離境界です。 この問題では、セグメントが交差しないことが保証されているため、(q_A=q_B) と (p_A=p_B) の場合、点は実際には同一となり、入力の保証に矛盾します。 したがって、実装では次を使用できます。`>=`最終的な比較で、長さゼロの変位を誤って受け入れることがなくなります。 指定された入力クラスの場合、受け入れられたすべてのペアは (\vec v) に沿った真の正の変位を持ちます。
