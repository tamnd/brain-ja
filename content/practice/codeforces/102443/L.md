## アプローチ

 直接シミュレーションでは、各タイム ジャンプ後に到達可能な都市のセットが維持されます。 構成が発生するたびに`a_i`、その道路を検査し、他の終点が現在到達可能な道路の終点をマークします。 これは正しいです。その時点で 1 つの道路が使用できるため、現在の到達可能なセットから最大 1 つ離れたグラフの距離にある頂点が到達可能になります。

これにより、あらゆる普通の道路が時間に依存した変化に変わります。 1 つの終点での現在の最も早い到着時刻を考慮すると、二分探索により、道路の構成の最も早い合法的な出現が検出されます。 このような遷移が発生すると、問題は最短経路問題と同じ構造になります。つまり、都市に早く到着しても後の遷移が悪化することは決してないため、ダイクストラのアルゴリズムが適用されます。

## アルゴリズムのチュートリアル

 1. すべての道路を読み取り、それを 1 つの通常の無向グラフに保存します。 各エッジとともに、その道路が存在した歴史的構成の識別子を保存します。 エッジをいつ使用できるかを判断するには構成識別子で十分であるため、個別のグラフを保持する必要はありません。 
2. シーケンスを読み取ります。`k`歴史的な構成。 あらゆる構成に対して`g`、すべての位置を含むソートされたリストを保存します`i`誰のために`a_i = g`。 入力シーケンス自体はすでに順序付けされているため、これらのリストは自然に並べ替えられます。 
3. 定義する`dist[v]`どの都市の最も早い時間位置として`v`到達できる。 最初は`dist[1] = 0`、都会にいるから`1`初めてジャンプする前に。 1 つおきの距離は無限です。 
4.都市を置く`1`を最小ヒープに格納し、ダイクストラのアルゴリズムを実行します。 とき市`u`現在のベストタイムでヒープから削除されます`dist[u]`、すべての道路を検査します`(u, v)`それに伴う出来事。 
5. 道路だと仮定します`(u, v)`構成に属します`g`。 ソートされたポジションのリストを見てください。`g`が表示され、厳密に次よりも大きい最初の位置を二分探索します。`dist[u]`。 これは、到着後、この道を横断できる最も早い瞬間です。`u`。 
6. その位置が`w`、そうすれば到達できます`v`時に`w`。 リラックス`dist[v]`と`w`。 もし`w`現在の値より小さいです`dist[v]`、新しいペアをヒープに挿入します。 
7.都市のときに停止`n`ダイクストラは最終的な最短経路距離の減少しない順序で頂点を削除するため、ヒープから削除されます。 ヒープが最初に空になった場合、都市`n`は到達できません、そして答えは`-1`。 

重要な不変条件は次のとおりです`dist[u]`私たちが街に立つことができる最も早い時間です`u`。 構成に属するエッジの場合`g`、到達後のすべての法的手続き`u`～の発生時に必ず発生する`g`厳密にその後`dist[u]`。 二分探索では、そのような発生が最も早いものを選択するため、遷移により、そのエッジを介して他のエンドポイントに可能な限り早く到着します。 次に、ダイクストラは、通常の非負の最短パスの場合とまったく同様に、これらの最も早い遷移を昇順で考慮します。 すべての遷移は時間的に厳密に前進するため、どの遷移も以前の状態に戻ることはできません。 

## Python ソリューション```python
import sys
import heapq
from bisect import bisect_right

input = sys.stdin.readline

def solve():
    n, t = map(int, input().split())

    graph = [[] for _ in range(n)]

    for g in range(t):
        m = int(input())
        for _ in range(m):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            graph[u].append((v, g))
            graph[v].append((u, g))

    k = int(input())
    sequence = list(map(int, input().split()))

    occurrences = [[] for _ in range(t)]
    for i, g in enumerate(sequence, 1):
        occurrences[g - 1].append(i)

    INF = k + 1
    dist = [INF] * n
    dist[0] = 0

    pq = [(0, 0)]

    while pq:
        du, u = heapq.heappop(pq)

        if du != dist[u]:
            continue

        if u == n - 1:
            print(du)
            return

        for v, g in graph[u]:
            times = occurrences[g]

            # We must use the road at a strictly later time.
            pos = bisect_right(times, du)

            if pos == len(times):
                continue

            nd = times[pos]

            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))

    print(-1)

if __name__ == "__main__":
    solve()
```グラフの構築では、各道路を 2 回、つまり各エンドポイントから 1 回ずつ保存し、その履歴構成を記憶します。 これにより、元のグラフのコレクションが、エッジに時間ラベルが付いた 1 つの疎なグラフに変換されます。 

出現リストは、完全な時系列を読み取った後に構築されます。 ポジションはから追加されるため、`1`を通して`k`、すべてのリストはすでにソートされており、次のコマンドで検索できます。`bisect_right`。 

の選択`bisect_right(times, du)`は中心となる実装の詳細です。`bisect_right`厳密に次より大きい最初の出現を返します`du`。 使用する`bisect_left`現在の都市に到達すると同時にエッジを通過することができ、誤って 1 回のタイム ジャンプ後に 2 回の道路横断が許可されてしまいます。 

ヒープストア`(time, city)`したがって、既知の最小の到着時間が最初に処理されます。 古いヒープ エントリは、その保存時間が異なる場合には無視されます。`dist[u]`、これはダイクストラの標準的な遅延削除の実装です。 

すべての時間は最大です`k`、 それで`INF = k + 1`で十分です。 Python の整数はオーバーフローしませんが、とにかくここでは大きなセンチネルは必要ありません。 

都会のときの早退`n`ダイクストラのヒープ順序により、その後の緩和によってその都市への到着時間が短縮されることが保証されるため、ポップされた場合は安全です。
