 ## 解決策
 ## 問題の理解

 2 つの整数が与えられます。$x$そして$y$、および目標閾値$m$。 2 つの数値のうちの少なくとも 1 つが以下の値以上であれば、そのペアは _m-perfect_ とみなされます。$m$。 ペアからスタート$(x, y)$、数値の 1 つを消去し、両方の数値の合計に置き換える操作を実行できます。 目標は、ペアを「m-perfect」にするために必要な操作の最小数を見つけるか、それが不可能であると判断することです。 

整数は非常に大きくなり、最大で$\pm 10^{18}$これにより、考えられるすべての合計シーケンスを試行する単純な総当たりの試みが排除されます。 出力は単一の数値です: 演算の最小数または$-1$どのシーケンスもターゲットに到達できない場合。 

主なエッジケースは、両方の場合に発生します。$x$そして$y$は非陽性ですが、$m > 0$。 この状況では、2 つの非正の数値を繰り返し加算しても、到達することはありません。$m$。 たとえば、入力の場合$-5, -3, 2$、の合計$-5$そして$-3$is still negative, so the target is unreachable. もう 1 つの微妙なケースは、1 つの数値がすでに次の数値以上である場合です。$m$これは、操作が必要ないことを直ちに意味します。 

## アプローチ

 素朴なアプローチは、考えられるすべての操作シーケンスをシミュレートすることです。 各ステップで、次のいずれかを置き換えることができます。$x$または$y$と$x + y$、2 つの新しい状態を再帰的に生成します。 このアプローチはあらゆる可能性を検討するため、原理的には正しいですが、すぐに非現実的になってしまいます。 控えめな値であっても、再帰ツリーは指数関数的に成長し、その結果、$O(2^n)$これは、1 秒の制限時間に収まる時間をはるかに超えています。 

効率的な解決策を可能にする観察は、小さい方の数値を常に 2 つの数値の合計に置き換えるべきであるということです。 こうすることで、各操作は小さい数の増加を最大化し、シーケンスが次の値に達することを保証します。$m$最小限のステップ数で。 小さい数値が非正で、大きい数値が より小さい場合$m$, まず、必要に応じて交換することで、小さい数値が負であることを確認し、大きい数値が正であることを確認します。 両方の数値が正でない場合、$m > 0$、問題は不可能です。 

このアプローチでは、各演算で現在の大きい数値が小さい数値に加算されるため、小さい数値は大まかにフィボナッチのような進行に従って増加します。 これは効率的な$O(\log m)$各ステップで少なくとも 1 つの数値が実質的に増加するため、アルゴリズムの計算に使用されます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 (小さいものを交換) | O(log m) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数の読み取り$x, y, m$。 確保する$x \le y$必要に応じて交換します。 これにより、どの数値を置き換えるかについての後の推論が簡素化されます。 
2. もし$y \ge m$、ペアはすでに_m-perfect_です。 0を出力して停止します。 
3. もし$y \le 0$そして$m > 0$、到達することは不可能です$m$。 -1 を出力して停止します。 2 つの非正の数値で始まる一連の和は、正になることはありません。 
4. カウンタの初期化`ops = 0`。 その間`y < m`、次の操作を実行します。 

- 追加`y`に`x`(小さい方の数字を置き換えます) 維持するために必要に応じて交換します`x <= y`。 
- インクリメント`ops`1までに。 
5. 1回`y >= m`、印刷`ops`。 

**なぜ機能するのか:** 維持される不変条件は次のとおりです。`y`は常に大きい数です。 小さい方の数値を置き換えると、シーケンスができるだけ早く成長します。`m`。 各ステップでは数値の合計が厳密に増加し、負の数値は事前に処理されるため、アルゴリズムは最小限の演算数を保証するか、不可能性を正確に識別します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    x, y, m = map(int, input().split())
    
    if x > y:
        x, y = y, x
    
    if y >= m:
        print(0)
        return
    
    if y <= 0:
        print(-1)
        return
    
    ops = 0
    while y < m:
        x += y
        if x > y:
            x, y = y, x
        ops += 1
    
    print(ops)
```**説明:** 最初に交換して作成します`x`数値が小さいほど、メインループが簡素化されます。 The loop repeatedly adds`y`に`x`成長を最大化するために。 操作ごとに交換することで、`x`は常に小さい方の数です。 の取り扱い`y <= 0`エッジケースは、無限ループや不必要な計算を早期に防止します。 このソリューションは、Python の任意精度演算のおかげで、非常に大きな整数を適切に処理します。

 ## 特殊なケース

 入力用`-5 -3 2`、どちらの数値も正ではありません。 アルゴリズムが検出するのは、`y <= 0`と`m > 0`冒頭と印刷物`-1`。 入力用`1 0 2`、ループは置き換えます`x`と`1+0=1`、交換し、再び交換します`1+1=2`到達`m`。 最小操作数は 2 として正しく計算されます。各エッジ ケースでは、初期チェックとループの不変式が正確性を保証するのに十分であることを確認します。
