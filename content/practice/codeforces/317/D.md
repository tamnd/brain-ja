 ## 解決策
 ## 問題の理解

 1 から n までの整数のセットが与えられます。 2 人のプレイヤーが交互にターンし、各手はまだ消されていない数字を選択することで構成されます。 ツイストは消去法がどのように機能するかにあります。プレイヤーが数字 x を選択すると、x のすべての高次の累乗も将来の動きに対して安全でないとみなされます。 したがって、x 自体は永久にブロックされ、x²、x³ なども永久にブロックされます。 ただし、x を選択することは、その約数や無関係な数値を直接禁止するものではありません。 

プレーヤーが選択できる有効な番号を持たず、そのプレーヤーが負けた場合、ゲームは終了します。 Vasya が最初に動きます。最初のプレイヤーと 2 番目のプレイヤーのどちらが強制的に勝つかを判断する必要があります。 

n ≤ 10^9 という制約により、すべての数値を反復したり、ゲームの状態を明示的にシミュレートしたりするアプローチは即座に除外されます。 サイズ n のブール配列を格納することさえ不可能です。 どのような解決策であっても、問題を個々の状態ではなく構造に関する推論に帰着させる必要があります。 

n が小さいが構造化されている場合、微妙なエッジ ケースが発生します。 たとえば、n = 1 の場合、最初のプレーヤーが即座に勝ちます。 n = 2 の場合、最初のプレーヤーは 1 または 2 を選択し、2 番目のプレーヤーはいつでも残りの有効な番号を取ることで応答できるため、2 番目のプレーヤーが勝ちます。 単純なシミュレーションでは、パワー ブロッキング ルールを考慮せずに数値間の独立性を誤って仮定する可能性がありますが、相互作用は実際にはパワーの連鎖を通じてグローバルに行われます。 

## アプローチ

 ブルートフォース解釈では、各数値がゲーム グラフの状態として扱われます。 現在の位置から、移動によって数字 x とそのすべてのパワーが削除され、次のプレイヤーが縮小されたセットから続行します。 これにより、[1, n] のサブセットに対する組み合わせゲームが発生し、サイズが指数関数的になります。 n が約 40 の場合でも、状態空間はすでに 2^40 であり、実現可能な限界をはるかに超えています。 

重要な構造上の観察は、x の選択によって引き起こされる制限は、x^k 形式の数値にのみ影響するということです。 これにより、整数が独立したチェーンに分割されます。各基本整数 a (別の数値の完全累乗ではありません) から、チェーン a、a²、a³、... 最大 n が生成されます。 数値の選択はそのチェーン内の要素にのみ影響するため、これらのチェーンは相互作用しません。 

したがって、ゲームは、チェーンごとに 1 つずつ、独立した公平なゲームの合計に分解されます。 各チェーンは、要素を選択するとそのチェーンの残りのサフィックス全体が削除される、単純な山取りゲームのように動作します。 これは、最適なプレイにおいて各チェーンが正確に 1 つの動きに寄与することを意味し、ゲームは存在するチェーンの数を n まで数えることになります。 

このような独立したチェーンの数は、1 より大きい別の整数の完全累乗ではない [1, n] 内の整数の数と同じです。同様に、すべての整数 a はチェーンに寄与しますが、k ≥ 2 で a = b^k の場合、それは b から始まるチェーンに属しているため、新しい塩基ではありません。 

結果は、完全累乗ではない整数を数えることに単純化されます。 勝者はこのカウントの同等性に依存します。独立したチェーンの数が奇数の場合は、最初のプレーヤーが勝ちます。 それ以外の場合は、2 番目のプレーヤーが勝ちます。

 ## アルゴリズムのチュートリアル

1. 可能な塩基 a を 2 から n まで繰り返します。 各 a について、a²、a³、... 最大 n までのすべてのべき乗を生成します。 これらの値は既存のチェーンに属しているため、「非基本要素」としてマークします。 
2. 数値がより小さい底のべき乗としてすでにカバーされているかどうかを追跡するブール構造 (概念的に) を維持します。 これにより、二重カウントの連鎖が回避されます。 
3. 1 から n までの整数がマークされていないものがいくつあるかを数えます。 これらは、独立したパワーチェーンの開始点に対応します。 
4. 1 は意味のある高次基本構造を持たず、独自の自明なチェーンを形成するため、特殊なケースとして 1 を含めます。 
5. 最終カウントの同等性に基づいて勝者を決定します。 カウントが奇数の場合は、Vasya が勝ちます。 そうでなければ、Petya が勝ちます。 

重要な考え方は、マークされていない数字はすべてパワーチェーンの「ルート」を表し、そのようなルートのそれぞれが、縮小されたゲーム構造における 1 つの独立した動きに正確に対応するということです。 

### なぜ効果があるのか

 重要な不変条件は、[1, n] 内のすべての整数が、その最小基数表現によって定義される 1 つの最大パワーチェーンに正確に属するということです。 数値が完全累乗の場合、その数値は常にその最小の底の連鎖に割り当てられます。 これにより、チェーンが互いに素であり、整数のセットを完全にカバーすることが保証されます。 

各移動は 1 つのチェーンのサフィックス全体を削除します。チェーンは重複しないため、どの移動も別のチェーンの内部構造に干渉することはできません。 したがって、ゲームは、それぞれが 1 つの効果的な動きに寄与する、独立した 1 次元ゲームの山と同等になります。 勝者は、その山の数が奇数か偶数かによってのみ決まります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())

    if n == 1:
        print("Vasya")
        return

    # mark numbers that are perfect powers
    is_power = [False] * (n + 1)

    a = 2
    while a * a <= n:
        power = a * a
        while power <= n:
            is_power[power] = True
            power *= a
        a += 1

    count = 0
    for i in range(1, n + 1):
        if not is_power[i]:
            count += 1

    if count % 2 == 1:
        print("Vasya")
    else:
        print("Petya")

if __name__ == "__main__":
    solve()
```この実装では、k ≥ 2 の累乗 a^k として記述できるすべての数値を明示的にマークします。ネストされたループ構造により、各塩基が累乗シーケンスごとに O(log n) ステップで累乗チェーン全体に寄与することが保証されます。 最後のスキャンでは、独立したチェーン ルートに対応するマークのない数値がカウントされます。 

一般的なマーキング ロジックは引き続き機能しますが、ゲームの解釈は自明であるため、特殊なケース n = 1 は直接処理されます。 

## 実用的な例

 ### 例 1: n = 1

 | ステップ | アクション | is_power カバレッジ | カウント |
 | --- | --- | --- | --- |
 | 1 | 初期化 | なし | 0 |
 | 2 | マーキングはできません | なし | 1 |
 | 3 | カウントパリティを評価する | なし | 1 |

 唯一の数字は 1 であり、これが単一の自明なチェーンを形成します。 カウントが奇数なので、すぐに1を取ってVasyaが勝ちます。 

### 例 2: n = 5

 | | マークされた力 | is_power のアップデート | カウント状態 |
 | --- | --- | --- | --- |
 | 2 | 4 | {4} | 保留中 |
 | 3 | 9 (無視 > n) | なし | 保留中 |
 | 4 | 16 (無視 > n) | なし | 保留中 |
 | 最終 | チェック1..5 | {4} | 4 無印 |

 マークのない数字は 1、2、3、5 で、カウント = 4 となります。4 は偶数なので、Petya が勝ちます。 

これは、真の非完全パワーのみがゲーム内の独立した決定ポイントにどのように貢献するかを示しています。

 ## 特殊なケース

 n = 1 の場合、アルゴリズムはマーキング ロジックを入力せずに、ただちに Vasya を出力します。 単一要素は 1 つの独立したチェーンとして扱われ、パリティは奇数です。 

n = 9 のような数値の場合、マーキング ループは a = 2 から始まり、4、8 などをマーキングします。 a = 3 の場合、9 と 27 がマークされます (n を超えると無視されます)。 マーク付け後、マークされていない数値はチェーン ルート {1,2,3,5,6,7,8,10,... 最大 9 個のフィルター済み} に正確に対応し、独立したパワー チェーンへの分解と一貫してパリティによって勝者が決定されます。 

n = 16 の場合、2 から始まる連鎖は 4、8、16 をカバーしますが、4 と 16 は他の塩基の累乗でもあります。 マーキングにより、16 が基数として二重にカウントされないことが保証され、チェーン分解の正確さが維持されます。
