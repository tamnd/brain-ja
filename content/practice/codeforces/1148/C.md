 ## 解決策
 ## 問題の理解

 1 から 1 までの数字の順列が与えられます。$n$、 どこ$n$均等であることが保証されています。 順列とは、各数値が配列内に 1 回だけ出現することを意味します。 タスクは、この順列を昇順に並べ替えることです。 ただし、許可される交換には制約があります。要素を交換できるのは位置でのみです。$i$そして$j$それらの間の距離が少なくとも$n/2$、 具体的には$2 \cdot |i-j| \ge n$。 

入力により得られるのは、$n$そして順列$p$、出力には、配列をソートするために実行するスワップのシーケンスがリストされている必要があります。 スワップ数を最小限に抑える必要はありませんが、次の数を超えてはなりません$5n$交換します。 

なぜなら$n$まで可能です$3 \cdot 10^5$、より遅いアルゴリズム$O(n \log n)$タイムアウトになる可能性があります。 単純なバブルソートスタイルのブルートフォースを実行するには、$O(n^2)$スワップ、それは現実的ではありません。 不注意なアプローチでは、距離の制限を考慮せずに要素を貪欲に交換しようとする可能性があります。 たとえば、$n = 6$そして$p = [6, 1, 3, 2, 4, 5]$中間スワップを使用せずに 6 を最初の位置にスワップしようとすると、インデックス 1 と 2 をスワップしようとする可能性があり、距離の制約に違反します。 

エッジケースには、すでに配置されているが「法的な交換」パートナーから遠く離れた要素、またはどちらの端とも直接交換できない配列の中央近くの要素が含まれます。 などの小さな入力$n = 2$些細なことですが、それでも距離ルールに従う必要があります。 

## アプローチ

 強引な方法では、各位置を繰り返しチェックすることになります。$i$そして交換する$p[i]$許可されている場合は常に正しい値を使用します。 これは、最終的にはすべての要素を移動できるため、概念的には機能しますが、距離の制約により、このアプローチは厄介で非効率になる可能性があり、最大で$O(n^2)$操作。 

重要な点は、距離制約により配列の前半と後半を自由に交換できることです。 左半分の要素は右半分の要素と交換できます。$|i-j| \ge n/2$。 この観察により、すべての移動を要素あたり最大 3 回の交換に減らすことができます。つまり、要素を最も近い端に移動し (まだ正しい半分にない場合)、必要に応じて残りの半分の正しい位置と交換します。 

同じ半分内で移動する必要がある要素は、反対側の半分を経由する迂回が必要です。 たとえば、6 要素配列の位置 2 と 3 の要素を交換するには、2 を最後の位置に移動し、3 を最初の位置に移動して、両端を介して交換します。 このトリックにより、すべての要素が最大でも固定数のスワップを使用して正しい位置に到達し、以下の範囲内に留まることが保証されます。$5n$限界。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. まず、各要素の現在位置を配列に保存します。`pos`そのような`pos[x]`現在の値のインデックスを与える`x`。 これにより、各要素がどこにあるかを知ることができます$O(1)$。 
2. 各位置を反復処理します。$i$1から$n$。 もし`p[i]`すでに等しい$i$、 続く。 それ以外の場合は、正しい値を所定の位置に移動する必要があります$i$。 
3. 現在のインデックスを特定する`j`価値の$i$を使用して`pos[i]`。 もし$|i-j| \ge n/2$、交換`p[i]`そして`p[j]`直接。 交換を記録します。 
4. もし$i$そして`j`どちらも前半、移動`j`配列の最後まで移動し、次と交換します`i`(または、次の場合は中間スワップ シーケンスを使用します)`i`も終わりに近づいています）。 
5. 同様に、次の場合も$i$そして`j`どちらも後半、移動します`j`配列の先頭に移動して続行します。 
6. 交換するたびに、`pos`新しい位置を反映する配列。 順列がソートされるまで繰り返します。 

このアプローチでは、最大一定数のスワップを使用して各要素が正しい位置に到達することが保証されます。 ハーフ間のスワップは常に距離条件を満たします。 同じ半分内のスワップは、反対側の半分を一時的なプレースホルダーとして使用して、2 つまたは 3 つの合法的なスワップに分割されます。 

**機能する理由:** 不変条件は、各スワップの後、少なくとも 1 つの要素が正しい半分または正しい位置に移動し、スワップが距離制約に違反しないことです。 反対側の半分を通る迂回により、一方の半分内に詰まった要素が常にもう一方の半分に到達できるようになります。 最終的には、すべての要素が超過することなく正しい位置に到達します。$5n$交換します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
p = list(map(int, input().split()))
p = [0] + p  # 1-indexed
pos = [0] * (n + 1)
for i in range(1, n + 1):
    pos[p[i]] = i

swaps = []

def do_swap(i, j):
    p[i], p[j] = p[j], p[i]
    pos[p[i]] = i
    pos[p[j]] = j
    swaps.append((i, j))

for i in range(1, n + 1):
    while p[i] != i:
        j = pos[i]
        if abs(i - j) >= n // 2:
            do_swap(i, j)
        else:
            if i <= n // 2 and j <= n // 2:
                do_swap(j, n)
                do_swap(i, n)
            elif i > n // 2 and j > n // 2:
                do_swap(j, 1)
                do_swap(i, 1)
            else:
                if i <= n // 2:
                    do_swap(j, 1)
                    do_swap(1, n)
                    do_swap(i, n)
                else:
                    do_swap(j, n)
                    do_swap(1, n)
                    do_swap(i, 1)

print(len(swaps))
for a, b in swaps:
    print(a, b)
```このコードは、`pos`配列を使用して、各数値がどこにあるかを効率的に見つけることができます。 の`do_swap`関数は順列と位置の両方を更新します。 各条件は、次の異なる相対位置を処理します。`i`そして`j`すべてのスワップが距離ルールを満たしていることを確認します。
