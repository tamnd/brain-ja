 ## 解決策
 ## 問題の理解

 ラベルの完全なセットの頂点に配置された整数の配列が与えられます。 任意の 2 つの頂点間で、関連する 2 つの値が自明でない公約数を共有する場合、つまり gcd が 1 より大きい場合、無向エッジを暗黙的に定義します。 したがって、グラフの構造は明示的に与えられるのではなく、数論的な関係によって誘導されます。 

このグラフから、選択したサブセットが均一な「公平性」特性を持つように、正確に k 個の頂点を選択する必要があります。選択したすべての頂点が他のすべての選択した頂点に接続されるか、選択したどの頂点もこの特性を持たないかのいずれかです。 頂点がサブセット内の他のすべての頂点に隣接している場合、その頂点はサブセット内で公平であると呼ばれます。 

言い換えると、誘導されたサブグラフ内ですべての頂点の次数がサブセット内で k マイナス 1 になるか、すべての頂点がサブセット内で厳密に k マイナス 1 よりも小さい次数になるように、k 個のインデックスを選択します。 

制約は大きく、n は最大 10^5、値は最大 10^7 です。 これにより、すべてのペアに対するペアごとの gcd チェック手法 (O(n^2)) が即座に除外されます。 ペアごとに O(n sqrt A) の因数分解を行っても、多くの比較に単純に適用すると遅すぎます。 明示的にグラフを構築することを避ける構造が必要です。 

微妙な特殊なケースは、すべての数値がペアごとに互いに素である場合です。 その場合、エッジはまったく存在しないため、サイズが少なくとも 2 のサブセットではすべての頂点が自動的に不公平になります。有効な答えは任意の k 個の頂点を選択する必要があります。 反対の極端な場合は、すべての数値が共通の素因数を共有し、完全なグラフが生成されます。この場合、すべての頂点がどのサブセットでも公平であるため、ここでも任意の k 個の頂点が機能します。 問題は、素数による局所クラスタリングが存在する混合ケースにあります。 

## アプローチ

 直接的なアプローチでは、グラフを明示的に構築しようとします。すべてのペアの gcd を計算し、隣接リストを構築し、条件を満たす k サイズのサブセットを検索します。 これにはすでに O(n^2 log A) のコストがかかりますが、n = 10^5 では実行不可能です。 

より構造化されたブルート フォースでは、サイズ k のサブセットを試し、公平性条件をテストします。 サブセットの列挙を無視しても、単一のサブセットをチェックするには O(k^2) 回の gcd チェックが必要で、サブセットの数は指数関数的になります。 これは使えません。 

重要な構造的観察は、隣接性が共有される素因数によって決定されるということです。 各エッジは、少なくとも 1 つの素数が両方の端点を分割するために存在します。 したがって、グラフは素数によって引き起こされるクリークの結合ですが、クリーク間の重なりによって交差が生じ、全体的な構造が複雑になります。 

重要な単純化は、エッジの観点から考えるのをやめ、代わりに素数について推論することです。 すべての頂点がペアごとに接続されているサブセットを選択すると、すべてのペアが少なくとも 1 つの共通素数を共有します。 公平な頂点がないサブセットを選択すると、選択された頂点ごとに、素因数を共有しない他の選択された頂点が少なくとも 1 つ存在します。 

これを利用する標準的な方法は、最小の素因数の出現によって頂点を分類し、高度に接続されたクラスターまたは疎な集合を貪欲に構築することです。 この問題の隠れた保証は、「十分に密な」構造が存在するか、「十分に疎な」構造が存在し、そのうちの 1 つだけを検出すればよいということです。 

これは、素数による二分割に基づく建設的な戦略につながります。つまり、少なくとも k 個の頂点に出現する素数を見つけて、高度に構造化されたサブセットを選択できるようにするか、素数の重複制約の繰り返しを回避して、スパース性を保証するセットを徐々に構築します。

 ## アルゴリズムのチュートリアル

1. すべての数値を因数分解し、その個別の素約数を記録します。 

このステップでは、各頂点をそのすべてのエッジを説明する素数のセットに変換します。 gcd > 1 は共有因数の存在のみに依存するため、個別の素数のみを考慮します。 
2. 各素数が分割する頂点の数を数えて、素数の頻度マップを作成します。 

これにより、大規模な共有接続構造を誘発する素数が特定されます。 
3. 少なくとも k 個の頂点を分割する素数 p が存在する場合、値が p で割り切れるすべてのインデックスを収集します。 

これにより、すべての頂点が少なくとも p を介してそのプール内の他のすべての頂点に接続される自然な候補プールが得られます。 このプールから、任意の k 個の頂点が完全に接続された誘導サブグラフを形成します。 
4. そうしないと、k 以上の頂点に素数が現れません。 次に、貪欲にセットを構築します。 集合 S を最初は空にしておきます。 
5. 頂点を任意の順序で繰り返し、既に選択されている頂点との素構造の過剰な重複が生じない場合は、頂点を S に追加します。 具体的には、選択したすべての頂点で素数が共有されないようにします。これにより、誘導された構造が公平性において不均一なままになります。 
6. S がサイズ k になるまで続けて、出力します。 

### なぜ効果があるのか

 何らかの素数が少なくとも k 個の頂点に現れる場合、そのサブセット内のすべてのペアがその素数を共有するため、gcd グラフ内で少なくとも k のサイズのクリークが直接誘発されます。 そこから k 個の頂点を選択すると、選択したサブセット内ですべての頂点が公平であることが保証されます。 

そのような素数が存在しない場合、すべての素数は配列全体で「疎」になります。 これにより、単一の要因によってグローバル隣接関係が強制されることがなくなります。 その結果、サイズ k のセットを構築するときに、完全に接続された構造に崩壊することを常に回避できます。 この構造により、少なくとも 1 つのエッジ欠落状態がサブセット全体にわたって持続することが保証され、すべての頂点が一様に不公平になります。 

不変条件は、その素数が有効なクリーク ケースをすでに証明している場合を除き、単一の共有因子を介してすべてのペアごとの gcd が 1 より大きくなるような方法で、素数が選択されたセットを支配することを決して許可しないことです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXA = 10**7 + 1

# sieve for smallest prime factor
spf = list(range(MAXA))
for i in range(2, int(MAXA ** 0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, MAXA, step):
            if spf[j] == j:
                spf[j] = i

def factorize(x):
    primes = []
    while x > 1:
        p = spf[x]
        primes.append(p)
        while x % p == 0:
            x //= p
    return primes

n, k = map(int, input().split())
a = list(map(int, input().split()))

prime_to_nodes = {}
fact = []

for i, val in enumerate(a):
    ps = factorize(val)
    fact.append(ps)
    for p in set(ps):
        if p not in prime_to_nodes:
            prime_to_nodes[p] = []
        prime_to_nodes[p].append(i)

for p, nodes in prime_to_nodes.items():
    if len(nodes) >= k:
        print(*[nodes[i] + 1 for i in range(k)])
        sys.exit(0)

# fallback greedy construction
used = set()
ans = []

for i in range(n):
    ok = True
    for p in fact[i]:
        cnt = 0
        for j in ans:
            if p in fact[j]:
                cnt += 1
                if cnt >= len(ans):
                    ok = False
                    break
        if not ok:
            break
    if ok:
        ans.append(i)
        if len(ans) == k:
            break

print(*[x + 1 for x in ans])
```最初のブロックは、すべての値を効率的に因数分解するために必要な最小の素因数ふるいを構築します。 その後、各数値はほぼ O(log A) の償却時間で個別の素数に分解されます。 

辞書 prime_to_nodes には、素数ごとに、それで割り切れる数値のインデックスが格納されます。 これは、単一の素因数によって引き起こされる大きなクリークを検出するために使用されるコア構造です。 

いずれかの素数クラスがサイズ k に達すると、直ちにそのインデックス k を出力します。 これは、保証された完全に接続されたサブセットを選択することに対応します。 

フォールバック ループは、単一の支配的な素数交差への崩壊を防ぎながらセットの構築を試みます。 候補頂点ごとに、それを追加すると、選択されたすべての頂点で素数が共通になる状況が強制的に発生し、意図した「不公平な」構造と矛盾するかどうかがチェックされます。

 ## 特殊なケース

 完全に互いに素な配列は、フォールバックを即座にトリガーします。 素数が複数回出現することはないため、アルゴリズムは密なクラスターを見つけることはなく、任意の選択に依存する必要があります。 エッジが存在しないため、構築されたセットは有効なままであり、どの頂点も公平になることはできません。 

2 のべき乗のような完全に複合された配列は、早期終了をトリガーします。 素数 2 がすべての頂点を支配するため、最初の条件はすぐにサイズ k のクリークを生成し、選択されたサブセット内のすべての頂点に対して公平性が維持されます。 

1 つの素数が正確に k 回出現するが、他の多くの素数とインターリーブされている混合配列でも、頻度条件が分布順序を無視し、カウントのみに依存するため、正しく解決され、構造に関係なくクリークが確実に検出されます。
