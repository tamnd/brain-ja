 ## 解決策
 ## 問題の理解

 2D グリッド上に軸が揃った 2 つの正方形が与えられます。 各正方形は、その左下隅の座標と辺の長さによって記述されます。 その情報から、各正方形は平面の閉じた領域を占めます。すべての点の x 座標は左端と右端の間にあり、y 座標は下端と上端の間にあります。 

タスクは、2 つの正方形の周囲が何らかの形で重なっているかどうかを判断することです。 オーバーラップは厳密に定義されており、角での接触も含め、単一点での接触でもオーバーラップとみなされます。 したがって、共有ポイントが禁止されるというルールで、内部の交差だけをチェックするのではなく、境界セットの交差もチェックします。 

各正方形は、X 軸上の間隔および Y 軸上の間隔として表すことができます。 最初の正方形は、x1 から x1 + s1 まで、および y1 から y1 + s1 までの範囲にあります。 2 番目の範囲は、x2 から x2 + s2 まで、および y2 から y2 + s2 までです。 したがって、ジオメトリは、実際には正方形である 2 つの軸に整列した長方形についての推論に帰着します。 

制約は非常に小さく、座標の境界は 10^3、辺の長さは最大 10^3 です。 これにより、定数時間の計算で十分であることが保証されます。 ポイントごとの単純な幾何学的チェックでも許容されますが、構造が純粋に間隔ベースであるため、それは不要です。 

正方形が単一点または境界線に沿ってのみ接触する場合、微妙なケースが発生します。 たとえば、ある正方形が x 軸上の別の正方形の開始位置と正確に一致する場合、それらの y 範囲が 1 つの座標で重複している場合でも、重複としてカウントされます。 同様に、あるマス目の右上角と別のマス目の左下角が重なるなどの角接触も無効となります。 

## アプローチ

 ブルートフォース手法では、各正方形の周囲を点または線分のセットとしてモデル化し、線分が交差しているかどうか、または点が共有されているかどうかを確認しようとします。 そのためには、すべてのエッジを列挙し、すべてのセグメントのペア間の交差をチェックするか、グリッドを離散化してすべての境界点をマークする必要があります。 座標が小さい場合でも、浮動小数点ジオメトリを使用すると、不必要な複雑さが生じ、エッジタッチのケースが欠落するリスクが生じます。 

重要な観察は、内部構造は無関係であるということです。 軸が整列した 2 つの正方形は、両方の軸上の投影が重なる場合にのみ、禁止された方法で重なり合います。 x 間隔が空でない方法で交差し、y 間隔が空でない方法で交差する場合、長方形はどこかで交差します。 接触は重複としてカウントされるため、単一の共有境界点でも十分であるため、間隔は閉じたものとして扱います。 

これにより、問題は、形状に関する幾何学的な推論から、1 次元での間隔の交差チェックに縮小されます。

 ## アルゴリズムのチュートリアル

 1. 両方の正方形の x 間隔を [x1, x1 + s1] および [x2, x2 + s2] として計算します。 これにより、各正方形の水平方向の範囲が完全にキャプチャされます。 
2. [y1, y1 + s1] および [y2, y2 + s2] と同様に y 間隔を計算します。 これにより、垂直方向のカバレッジがキャプチャされます。 
3. x 間隔が交差しているかどうかを確認します。 閉じた区間の場合、最大(左の端点) ≤ 最小(右の端点)の場合に交差が存在します。 この条件により、少なくとも 1 つの X 座標が共有されることが保証されます。 
4. 同じロジックを使用して、y 間隔が交差するかどうかを確認します。 
5. 両方の軸投影が交差する場合、正方形は少なくとも 1 つの点を共有しているため、YES を出力します。 それ以外の場合は NO を出力します。

両方の次元が重なる必要がある理由は、点が両方の制約を同時に満たす場合にのみ両方の正方形に属するためです。 共有 Y 範囲のない共有 X 範囲は、垂直方向に分離された長方形に対応し、その逆も同様です。 

### なぜ効果があるのか

 各正方形は、まさにその x 間隔と y 間隔のデカルト積です。 このような 2 つの積の交差は、対応する両方の区間が交差する場合にのみ空ではありません。 このプロパティにより、間隔推論の外に幾何学的なコーナーケースが存在しないことが保証されます。 間隔を閉じたものとして扱うため、境界接触は正しく交差として分類されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def intersect(a1, a2, b1, b2):
    return max(a1, b1) <= min(a2, b2)

def solve():
    x1, y1, s1 = map(int, input().split())
    x2, y2, s2 = map(int, input().split())

    x1r, x2r = x1 + s1, x2 + s2
    y1r, y2r = y1 + s1, y2 + s2

    if intersect(x1, x1r, x2, x2r) and intersect(y1, y1r, y2, y2r):
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```このソリューションは 2 つの正方形を読み取り、それぞれを軸ごとに 2 つの閉じた間隔に変換し、ヘルパー関数を使用して間隔の重なりをチェックします。 ヘルパー関数は、主要な幾何学的条件をコンパクトにエンコードし、x および y 次元のロジックの重複を回避します。 

よくある間違いは、間隔を半開きとして扱うことであり、エンドポイントが接触するケースを誤って拒否してしまいます。 もう 1 つは、ここでは接触も重複としてカウントされるため、重複条件では平等が許可されるべきであることを忘れていることです。

 ## 特殊なケース

 重要なエッジケースは、正方形が角で正確に接触する場合です。 たとえば、[0,0,1] や [1,1,2] などです。 x 間隔は [0,1] と [1,3] で、正確に 1 で交差し、y についても同様です。 max(0,1) ≤ min(1,3) が成立するため、アルゴリズムは YES を返します。 これにより、単一の共有ポイントが重複として正しく扱われます。 

もう 1 つのケースは、[0,0,2] や [2,1,3] などの純粋なエッジタッチです。 ここで、x 間隔は 2 で交差しますが、[0,2] と [1,3] が重なっているため、y 間隔は交差しません。 実際にはそれらは重なり合うので、これは [1,2] の x=2 と y で始まるコーナー領域となり、有効な重なりとなります。 間隔ロジックは、特別なケースを使用せずにこれを自然に捉えます。 

[0,0,1] や [2,2,1] のように完全に分離された構成では、x 間隔と y 間隔が互いに素になるため、条件はすぐに失敗します。 これは、どちらの軸でも分離していれば交差がないことを保証するのに十分であることを示しています。
