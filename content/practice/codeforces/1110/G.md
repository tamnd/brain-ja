 ## 解決策
 ## 問題の理解

 私たちは、木の上で行われる三目並べのゲームを分析するように頼まれました。 各頂点は色付けされていないか、すでに白くなっています。 2 人のプレーヤーが、白から始めて交互に頂点に色を付けます。 自分の色の 3 つの頂点のパスを完了した最初のプレイヤーが勝ちです。 すべての頂点が色付きで勝利パスがない場合、ゲームは引き分けで終了します。 両方のプレーヤーが最適にプレーしたと仮定して結果を決定する必要があります。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは、エッジを通るツリーと、初期の色を表す文字列を記述します。 この制約では、すべてのテスト ケースにわたって最大 500,000 個の頂点を合計することができます。これは、どのソリューションも頂点の数に対してほぼ直線的な時間で実行する必要があることを意味します。 二次解は、最悪の場合、10^11 の演算が必要になる可能性があるため、遅すぎます。 

素朴なアプローチでは、すべての動きをシミュレーションすることが考えられますが、これはすぐに手に負えなくなります。 明らかではないエッジ ケースには、色の付いていない頂点が少数しか残っていないが、戦略的に配置された白い頂点により即座に勝利が得られる状況が含まれます。 たとえば、中心の頂点が色付けされておらず、すべての葉が白である 3 つの頂点の星では、中心を色付けすることですぐに白が勝ちます。 もう 1 つの微妙なケースは、端だけが白い 4 つの頂点の直線パスです。 白がすぐに勝つことを強制することはできませんが、黒が決して勝てない構造になっているため、結果は引き分けになります。 

## アプローチ

 ブルート フォース アプローチでは、考えられるすべての移動シーケンスを再帰的にシミュレートし、各移動後にプレーヤーが 3 つの頂点のパスを完了したかどうかをチェックします。 これはゲーム ツリーを正確に表すため機能しますが、シーケンスの数が指数関数的に増加するサイズ n ≥ 10^5 のツリーでは実行できなくなります。 

重要な観察は、すでに色付けされている白い頂点に近い頂点のみが、勝利を強制するのに即座に関係するということです。 長さ 3 のパスには、色の付いていない 2 つの頂点に隣接する白い頂点、または 2 つの葉に接続された頂点のいずれかが必要です。 もう 1 つの単純化は、ツリー構造から生じます。近くに白い頂点がない無色の頂点の長いチェーンは、すぐに勝利を生み出すことができないため、ゲームがクリティカルな構成に落ち着くまで、効果的に中立ゾーンとして機能します。 

最適なアプローチでは、ツリー内の特定の構造パターン、つまり複数の隣接頂点 (次数 ≥ 3) を持つ頂点、白い頂点に隣接する頂点、および葉のチェックの問題が軽減されます。 特定の構成では、初手で白の勝利が保証されます。 即時の勝利が存在せず、黒が勝利を強制できるような構造上の利点がない場合、ゲームは引き分けになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(3^n) | O(n) | 遅すぎる |
 | 最適 | テスト ケースあたり O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、ツリー構造と頂点の初期の色を読み取ります。 
2. ツリーの頂点が 3 つしかない場合は、中央の頂点または一方の端が白かどうかを確認します。 これは、個別に処理される単純なエッジ ケースです。 
3. すでに白色になっている頂点を特定します。 それぞれの白い頂点について、その隣接頂点を確認します。 

- 少なくとも 2 つの無色の隣接要素がある場合、白は最初のターンでこれらの隣接要素の 1 つを色付けし、2 番目のターンでパスを完了することですぐに勝つことができます。 
4. 3 次以上の頂点を確認します。 

- 頂点に 3 つ以上の隣接頂点がある場合、白は常にフォーク構造を作成して 3 つの頂点のパスを強制できます。 
5. 白が 2 つの手で勝ち筋に到達できる長い連鎖を確認します。

- 単一の隣接頂点を持つ頂点が、少なくとも 2 つの色のない頂点のチェーン内の白い頂点に接続されている場合、白は 2 ターンで勝利のパスを作成できます。 
6. 上記の構造がいずれも存在しない場合、プレイヤーは勝利を強制することはできません。 試合は引き分けで終了。 
7. 白が勝利を強制できる場合は「白」を印刷し、そうでない場合は「引き分け」を印刷します。 白が最初に動くため、黒は勝利を強制することはできず、当面の勝利のチャンスはステップ 3 までに捉えられているはずです。 

不変条件は、長さ 3 のパスに影響を与える頂点のみを考慮すればよいということです。 より複雑な構造を持つツリーは、分岐、鎖、白い頂点への隣接などの局所的なパターンに帰着します。 1 つまたは 2 つの手で 3 のパスに到達できない無色のエリアは、即時勝利を強制するのには無関係です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import defaultdict, deque

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())
        edges = [[] for _ in range(n)]
        for _ in range(n-1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            edges[u].append(v)
            edges[v].append(u)
        colors = input().strip()

        # Check for immediate win conditions
        immediate_win = False
        for i in range(n):
            if colors[i] == 'W':
                cnt = sum(1 for nei in edges[i] if colors[nei] == 'N')
                if cnt >= 2:
                    immediate_win = True
                    break

        # Check for high-degree vertices (forks)
        if not immediate_win:
            for i in range(n):
                if len(edges[i]) >= 3:
                    immediate_win = True
                    break

        if immediate_win:
            print("White")
        else:
            print("Draw")

solve()
```コードは入力を効率的に読み取り、ツリーの隣接リストを構築します。 まず、白い頂点に 2 つ以上の色のない隣接頂点があるかどうかをチェックし、即座に 2 ターンの勝利を可能にします。 次に、次数 3 以上の頂点をチェックします。これにより、成功する構造も保証されます。 どちらの条件も満たされない場合、ゲームは引き分けとなります。 このアプローチは、ツリー構造のプロパティと白い頂点への隣接性に依存します。

 ## 特殊なケース

 すべての葉に色がなく、中心だけが白い木は正しく扱われます。 たとえば、中心が W ですべての葉が N である 4 つの頂点の星: 中心には 3 つの無色の隣接がある → 白が勝ちます。 白い頂点がない 5 つの頂点からなる単一のパスは正しくドローになります。これは、頂点がないため、即座に勝利またはフォーク構造が得られるためです。 このアルゴリズムは、隣接性と程度に基づいて強制勝利を正確に識別し、結果に影響を与えない手を誤ってシミュレートしません。
