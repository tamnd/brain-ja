 ## アルゴリズムのチュートリアル

 1. 各クエリ値について$a$、厳密に次より大きい 2 の最大累乗を計算します。$a$。 これは、次のビット長を使用して取得できます。$a$。 
2. この 2 のべき乗より 1 少ない数として答えを形成し、結果的に、次の最上位ビット位置まですべて 1 からなる 2 進数を作成します。$a$。 
3. この値をクエリに出力します。 

このステップが機能する理由は、ビット長が最上位ビットの位置を直接エンコードし、すべての有効な構造が下位ビットではなくその位置のみに依存するためです。 

### なぜ効果があるのか

 XOR と AND の構造により、すべての候補値がビット数のみに依存することが保証されます。$a$を使用して共有位置と異なる位置に分割できます。$b$。 最大の gcd は、結果として得られる両方の数値が可能な最大の均一ビット パターンに一致するときに達成されます。 そのパターンは、正確に、最上位ビットまでの 1 の完全なブロックです。$a$、ビット長によって一意に決定されます。 偏差があると上位ビットの欠落が生じ、達成可能な gcd が厳密に減少します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    q = int(input())
    for _ in range(q):
        a = int(input())
        msb = a.bit_length()
        ans = (1 << msb) - 1
        print(ans)

if __name__ == "__main__":
    solve()
```このソリューションは、各クエリを個別に処理します。 キー操作は、`bit_length()`、これは、次の中で最も高い設定ビットの位置を見つけます。$a$。 1 をその量だけ左にシフトすると、次の 2 のべき乗が作成され、1 を減算すると、すべてのビットがその位置より下に設定された 2 進数が生成されます。 

間違った 2 のべき乗から 1 を減算しないように注意する必要があります。 使用する`bit_length()`ビットを手動でスキャンする場合に発生するオフバイワンエラーを直接回避します。

def run(inp: str) -> str:

 ## 特殊なケース

 2 の累乗の場合は次のようになります$a = 8$、アルゴリズムは次のように計算します。$msb = 4$、したがって、答えは$2^4 - 1 = 15$。 それでも$a$それ自体に 1 つのビット セットしかない場合、結果は完全なマスクに拡張されます。 これは、下位ビットが$b$最大の gcd 構造を維持しながら、XOR と AND の両方の結果を完全に再形成できます。 

次のようなすでにすべて 1 の形式になっている数値の場合、$a = 7$、私たちは得ます$msb = 3$そして答える$7$。 その他$b$境界内にはより大きな均一なビット構造が存在しないため、より大きな公約数を生成することはできません。 

次のような帯分数の場合$a = 6$、バイナリ`110`、答えが得られます`111`。 異なるものを選択する$b$値は下位ビットの相互作用にのみ影響しますが、最高ビット位置が達成可能な gcd 構造を支配するため、アルゴリズムはそのようなすべての構成にわたって安定しています。
