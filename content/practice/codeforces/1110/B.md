 ## 解決策
 ## 問題の理解

 損傷が発生した長い線分上の位置のソートされたリストが与えられます。 損傷した各位置はテープで覆う必要がありますが、テープは健康な位置を避ける必要はなく、その間のあらゆるものを自由に覆うことができます。 テープを最大でカットできます。`k`連続したセグメントであり、各セグメントは数直線上の連続した区間をカバーします。 コストはすべてのテープ セグメントの合計長であり、損傷したすべての位置が少なくとも 1 つのテープ セグメントでカバーされるようにしながら、このコストを最小限に抑えたいと考えています。 

この問題を考えるのに役立つ方法は、各テープ セグメントが損傷ポイントの連続ブロックをカバーする責任があるということです。 近くにある破損したポイントを同じテープ セグメントにグループ化すると、そのセグメントのコストは、そのグループ内の左端のカバーされたポイントから右端のカバーされたポイントまでの距離になります。 タスクは、ソートされたシーケンスを最大でどこに分割するかを決定することです。`k`すべてのグループの合計スパンを最小化するためのグループ。 

この制約により、二次関数や状態圧縮のアプローチから遠ざけられます。 まで`10^5`すべてのパーティションを試したり、すべてのセグメント分割に対して動的プログラミングを使用したりするソリューションは、通常、少なくとも次のような問題につながるため、遅すぎます。`O(n^2)`行動。 

すべての壊れた位置が非常に離れている場合、微妙なエッジケースが発生します。 たとえば、次の場合`b = [1, 1000000, 2000000]`そして`k = 2`、近接性による単純な貪欲なグループ化は、慎重に構造化されていない場合、間違ったペアを誤ってマージする可能性があります。 もう 1 つのエッジケースは次のような場合です`k = n`、各セグメントが正確に 1 つの点をカバーするため、すべての点を分離でき、答えはゼロになります。 不注意に実装すると、分割が最適な場合でも、隣接するポイント間の距離が誤って追加される可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、ソートされた壊れた位置を最大でも次の数に分割するあらゆる方法が試行されます。`k`グループ。 各パーティションについて、次の合計としてコストを計算します。`(max - min)`各グループで。 ただし、パーティションの数は指数関数的に増加します。`n`というのは、連続するポイント間のすべてのギャップはカットであるかどうかのどちらかであるためです。 これはおおよそ次のことにつながります`2^(n-1)`たとえ小さくても実現不可能な可能性`n`。 

重要な観察は、固定グループ内では、コストはそのエンドポイントにのみ依存するということです。 最初にすべてのポイントが 1 つのグループにあると仮定すると、総コストは次のようになります。`b[n] - b[1]`。 間隔を空けてグループを分けるたびに、`b[i]`そして`b[i+1]`1 つのセグメントでそのギャップをカバーすることを効果的に停止します。これにより、以前は 1 つの長いセグメント内でカバーされていたオーバーラップが削除され、総コスト削減が増加します。 ギャップでの分割によるゲインは正確に`(b[i+1] - b[i])`。 

したがって、グループを構築することを考えるのではなく、すべてをカバーする単一のセグメントから始めて、それをどこに分割するかを決定します。`k`個。 各カットにより、合計スパンからギャップ コストが削除されます。 全長を最小限に抑えるには、無駄なカバレッジを最大限に削減できるため、最初に最大のギャップでカットします。 

したがって、問題はすべての隣接する差異をソートし、`k-1`最大のものをカットポイントとして使用します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべてのパーティション) | O(2^n) | O(n) | 遅すぎる |
 | 最適（貪欲なギャップ選択） | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 連続する壊れた位置の差を計算します。 それぞれの違いは、テープを分割することで大きな空の間隔をカバーできる可能性のある場所を表しています。 
2. 最大のギャップが最初に考慮されるように、これらの違いを降順に並べ替えます。 直感的には、大きな空きスペースで分割すると、カバーされるテープの総量が最も少なくなります。 
3. すべてをカバーする 1 つのセグメントから始めます。そのコストは次のとおりです。`b[n-1] - b[0]`。 
4. までに取る`k-1`最も大きなギャップを検出し、それらを分割点として扱います。 選択した各ギャップは、1 つの長い間隔を 2 つの短い間隔に分割するため、そのギャップの長さだけ合計コストが削減されます。 
5. 初期フルスパンコストから選択したギャップ長を引きます。 
6. もし`k >= n`、 戻る`0`各ポイントを分離でき、間隔の長さが必要ないためです。 

### なぜ効果があるのか

 このアルゴリズムは、ポイントの有効な分割がカットするギャップのサブセットの選択に対応するという不変条件に依存します。 パーティションの総コストは、フル スパンからカットされたギャップの合計を引いたものと等しくなります。 ギャップはポイント間の分離に独立して寄与するため、`k-1`ギャップを最大にすると、セグメント数の制限を守りながらコストを最大限に削減できます。 どのカットも隣接ギャップの寄与を 1 つ除去するだけであり、これらの寄与は相互作用しないため、カットの配置は最大のギャップの選択よりも優れたパフォーマンスを発揮することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())
    b = list(map(int, input().split()))
    
    if k >= n:
        print(0)
        return
    
    gaps = []
    for i in range(n - 1):
        gaps.append(b[i + 1] - b[i])
    
    gaps.sort(reverse=True)
    
    total = b[-1] - b[0]
    
    for i in range(k - 1):
        total -= gaps[i]
    
    print(total)

if __name__ == "__main__":
    solve()
```このソリューションは、まず壊れた位置を読み取り、各位置を個別にカバーできる縮退ケースを即座に処理します。 その場合、どの間隔も複数のポイントにまたがる必要がないため、コストはゼロになります。 

次に、連続する壊れた位置間の距離のリストを作成します。 これらのギャップは、2 つのポイントが同じセグメント内にあるときにどれだけの「余分なテープ」が強制されるかを表します。 それらを並べ替えることで、切断するのに最も高価な接続を優先することができます。 

初期合計は、最小の破損位置から最大の破損位置までの全範囲です。 これは、1 枚のテープですべてをカバーすることに相当します。 選択された各分割は、この統合されたスパンから 1 つのギャップを削除します。`k`セグメントを作成できます`k-1`カット。 

よくある落とし穴は、セグメントの長さを直接合計するのではなく、グローバル スパンからギャップを減算していることを忘れることです。 どちらのビューも同等ですが、これらを混合すると、二重にカウントされたり、貢献が欠落したりする可能性があります。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from sys import stdout
    import sys

    input = sys.stdin.readline

    def solve():
        n, m, k = map(int, input().split())
        b = list(map(int, input().split()))
        
        if k >= n:
            print(0)
            return

        gaps.sort(reverse=True)

        for i in range(k-1):
            total -= gaps[i]
        
        print(total)

    solve()
    return ""

 ## 特殊なケース

 いつ`k = 1`の場合、アルゴリズムはギャップを選択しません。 初期スパン`b[n-1] - b[0]`これは、単一のテープ セグメントですべてをカバーする必要があるという事実と一致します。 

いつ`k ≥ n`、早期終了が戻ります`0`。 これは、すべての点を独自のセグメントに分離でき、各セグメントは点を超える長さの寄与がゼロであるという事実と一致します。 

ポイントが極端に分散している場合など`1, 100, 1000, 100000`、最大のギャップが並べ替えステップを支配します。 アルゴリズムは、これらの大きな間隔での分割を最初に正しく優先し、総カバレッジを最小限に抑えます。 

1 つの大きな外れ値ギャップを除いてポイントが密集している場合、単一の最大ギャップが唯一の有効なカットになります。 ソートされた相違点リストの最初に現れるため、アルゴリズムは自然にそれを選択し、最適な 2 分割を生成します。
