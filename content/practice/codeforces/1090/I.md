 ## 解決策
 ## 問題の理解

 一連の整数が与えられ、そこから正確に固定数の要素を選択するように求められます。 それらを選択した後、選択した値を掛け合わせて 1 つの数値を取得します。 必要な要素数を選択するすべての可能な方法の中で、通常の整数の順序で可能な限り最小の積が必要です。つまり、負の値が大きいほど常に正の値よりも小さいとみなされ、同じ符号を持つ数値の間では標準的な方法で絶対値を比較します。 

中心的な問題は、積が選択された要素の大きさだけでなく、その符号にも依存することです。 より多くの負の数値を選択すると積の符号が反転する可能性があり、単一の非常に大きな絶対値が他のすべてを支配する可能性があります。 タスクは、符号と大きさの両方が最適に制御されるように、どの要素を取得するかを決定することです。 

入力サイズでは、定格 2000 の問題の一般的な CF 制約で最大約 10 万要素が許可されます。 これにより、サイズ k のすべてのサブセットを試行したり、積を繰り返し再計算したりするアプローチは即座に除外されます。 O(n^2) 戦略でも遅すぎます。 ソートに近いもの、またはソートされたデータの線形パスが必要です。 

いくつかのエッジの状況は見逃しがちです。 

すべての数値が正の場合、選択に関係なく積は常に正になります。 たとえば、より大きな値を選択すると積が増加するため、それを最小化するには絶対値を最小にする必要があります。 

すべての数値が負であり、奇数の要素を選択した場合、積は負となり、その大きさが大きくなるにつれて小さくなるため、最大の絶対値を選択すると役立ちます。 

ゼロが存在する場合、積を強制的にゼロにすることができます。これは、厳密に負の積が回避可能な場合には常に最適である可能性があります。 ゼロを無視する素朴な貪欲なアプローチでは、これを簡単に見逃してしまう可能性があります。 

もう 1 つの微妙なケースは、選択したセットに負の値が偶数個含まれている場合です。 積がプラスになり、全体の値が小さくなる場合は、1 つの要素を意図的に交換してパリティを変更することもできます。 

## アプローチ

 ブルートフォースアプローチでは、k 個の要素のすべての組み合わせを試し、その積を計算し、最小値を追跡します。 これは、考えられるすべての候補解を直接評価するため、正しいです。 ただし、組み合わせの数は、$\binom{n}{k}$, which grows exponentially. n = 50 や k = 25 のような中程度の値であっても、これは実行不可能になり、n が 100000 までの場合は完全に不可能になります。 

重要な観察は、積が任意の構造ではなく、主に絶対値と負の数のパリティによって制御されるということです。 配列を絶対値で並べ替える場合、最適な解は絶対値が小さい要素を取得することに密接に関係しています。これは、絶対値の大きい要素を小さい要素に置き換えると、符号制約を悪化させることなく常に積の大きさが小さくなるからです。 

問題を最小の絶対値を持つ k 個の要素を選択することに帰着させると、残りの困難は符号を修正することだけになります。 選択した負の値の数が偶数であれば、積は正になります。 奇数の場合は負です。 負の値は常に正の値より小さいため、一般に、可能であれば負の数が奇数であることを好みます。 パリティが間違っている場合は、選択した 1 つの要素を、パリティを反転しながら積の変更を最小限に抑える次の利用可能な候補と交換することで修正します。 

これにより、問題は組み合わせ選択から並べ替えに加え、いくつかの制御された調整にまで軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n は k を選択) | O(k) | 遅すぎる |
 | Sorting + greedy correction | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての数値を絶対値で昇順に並べ替えます。 これにより、初期の要素が製品の大きさに最も寄与しないように候補が整理されます。 
2. 最初の k 要素を初期候補セットとして選択します。 この選択により、サイズ k のすべてのサブセット間の絶対積が最小化されますが、今のところ符号制約は無視されます。 
3. この選択したセットに負の数がいくつあるかを数えます。 This determines the sign of the product.
 4. 配列内に少なくとも 1 つのゼロがあり、最良の符号構成でも正の積が生成される場合は、ゼロ以外の積は順序付けでゼロに改善できるため、スワップ候補としてゼロを使用することを検討してください。 
5. 負の要素の数が可能な限り最小の積を生成するのにすでに最適である場合は、選択したセットから積を直接計算します。 
6. パリティが間違っている場合は、選択した 1 つの要素と選択されていない 1 つの要素を交換して修正を試みます。 スワップの目的は、絶対値の増加を最小限に抑えながら符号を変更することです。 これは、候補を比較することによって行われます。つまり、選択したセットの中で最小の絶対負性または最大の絶対正性を削除し、それをセット外の利用可能な最適な反対符号の要素に置き換えます。 
7. 調整されたセットから最終積を計算します。 

これらのステップの背後にある主な考え方は、絶対値によるソートによってベースラインの最小振幅サブセットが得られ、それ以上の改善は振幅の乱れを最小限に抑えて符号制約を修正することによってのみ得られるということです。 

### なぜ効果があるのか

 すべての段階で、選択されたセットには、現在の符号パリティ制約に一致するすべてのセットの中で最小の k 個の絶対値が含まれるという不変条件が維持されます。 これらの要素からの逸脱は、小さい絶対値を大きい値に置き換える必要がありますが、これは積の大きさを増加または維持するだけで、改善することはありません。 符号はパリティ補正を通じて明示的に処理され、その制約の下で絶対値が常に最小化されるため、結果として得られる積は全体的に最小になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    if k == n:
        prod = 1
        for x in a:
            prod *= x
        print(prod)
        return

    a.sort(key=abs)

    chosen = a[:k]
    rest = a[k:]

    neg = sum(1 for x in chosen if x < 0)
    zero_present = any(x == 0 for x in a)

    if zero_present:
        # if we can force zero product, it is optimal unless we already get negative
        prod_nonzero = True
        for x in chosen:
            if x == 0:
                prod_nonzero = False
                break
        if prod_nonzero:
            print(0)
            return

    # If parity is already "good" (we want negative if possible)
    if neg % 2 == 1:
        ans = 1
        for x in chosen:
            ans *= x
        print(ans)
        return

    # try to fix parity by swapping
    # find candidates
    min_neg_abs = None
    min_neg_val = None
    min_pos_abs = None
    min_pos_val = None

    for x in chosen:
        if x < 0:
            if min_neg_abs is None or abs(x) < min_neg_abs:
                min_neg_abs = abs(x)
                min_neg_val = x
        elif x > 0:
            if min_pos_abs is None or abs(x) < min_pos_abs:
                min_pos_abs = abs(x)
                min_pos_val = x

    best_neg_out = None
    best_neg_out_abs = None
    best_pos_out = None
    best_pos_out_abs = None

    for x in rest:
        if x < 0:
            if best_neg_out_abs is None or abs(x) > best_neg_out_abs:
                best_neg_out_abs = abs(x)
                best_neg_out = x
        elif x > 0:
            if best_pos_out_abs is None or abs(x) > best_pos_out_abs:
                best_pos_out_abs = abs(x)
                best_pos_out = x

    cand1 = None
    if min_pos_val is not None and best_neg_out is not None:
        cand1 = (abs(min_pos_val) - abs(best_neg_out), min_pos_val, best_neg_out)

    cand2 = None
    if min_neg_val is not None and best_pos_out is not None:
        cand2 = (abs(min_neg_val) - abs(best_pos_out), min_neg_val, best_pos_out)

    if cand1 is None and cand2 is None:
        # no swap possible, just compute
        ans = 1
        for x in chosen:
            ans *= x
        print(ans)
        return

    if cand2 is None or (cand1 is not None and cand1[0] < cand2[0]):
        remove, add = cand1[1], cand1[2]
    else:
        remove, add = cand2[1], cand2[2]

    chosen.remove(remove)
    chosen.append(add)

    ans = 1
    for x in chosen:
        ans *= x
    print(ans)

if __name__ == "__main__":
    solve()
```コードは、選択肢がないため、単純な全選択のケースを処理することから始まります。 絶対値による並べ替えは中心的な構造ステップであり、初期の選択で大きさが最小限に抑えられるようにします。 

次の重要なブロックは、最初の k 要素セットを構築し、マイナスをカウントしてパリティを決定します。 ゼロ処理は、注文時にゼロ以外のすべての製品を支配する可能性があるため、早期に表示されます。 

The swap logic is the most delicate part. これは、符号に影響を与える選択範囲内の最小の絶対値要素と、外側の最も有用な候補を識別します。 パリティが間違っている場合には符号反転が必須であるため、スワップ オプション間の比較は、絶対値がどれだけ損失または獲得されるかに基づいて行われます。 

最後に、場合によってはセットを調整した後、積が直接再計算されます。

 ## 特殊なケース

 すべての数値が正の場合、アルゴリズムは最小の絶対値を選択し、これにより積も最小化されます。 スワップは符号を改善できないため、パリティ ロジックは無関係になります。 たとえば、入力の場合`5 2 / 10 3 4 1 2`、選択したセット`[1, 2]`直接最小積が得られます。 

ゼロが存在する場合、それを達成できれば、ゼロ以外の積はゼロよりも悪くなります。 アルゴリズムはこれを早期にチェックし、選択されたサブセットが強制的な制約の下で厳密に優れた負の積を保証していない限り、ゼロを返します。 これにより、規模が増大するだけとなる不必要なスワップが防止されます。 

すべての数値が負で、k が奇数の場合、最大の絶対値を選択すると、積が可能な限り負になります。 絶対値による並べ替えにより、これらの要素が後で表示されることが保証され、スワップ ロジックにより、強い負の値をより弱い正の値に誤って置き換えることが回避されます。 

k が n に等しい場合、選択の自由は存在しません。 このアルゴリズムは、貪欲な構造をすべてバイパスして、すべての要素を直接正確に乗算します。
