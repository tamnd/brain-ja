 ## 問題の理解

 私たちに与えられているのは、$n \times n$もともと未知の配列から構築されたテーブル$a_1, a_2, \ldots, a_n$。 対角以外のすべてのセルには、このシーケンスの 2 つの要素の積が含まれます。具体的には、$B_{i,j} = a_i \cdot a_j$のために$i \neq j$。 斜めのエントリは元々$a_i^2$ですが、それらの値は消去され、ゼロに置き換えられています。 

私たちの仕事は、有効なシーケンスを再構築することです$a$これにより、指定されたテーブルが生成される可能性があります。 

重要な観察は、行列のすべての行が同じ隠れベクトルのスケーリングされたコピーであるということです。 行$i$シーケンスです$a_i \cdot a_1, a_i \cdot a_2, \ldots, a_i \cdot a_n$。 これは、行間の比率が未知の値間の比率をエンコードすることを意味します。 

制約は次のとおりです$n = 1000$したがって、行列には​​最大$10^6$エントリー。 これにより、値を独立して推測しようとしたり、高価な代数を使用して大規模なシステムを解決しようとしたりするソリューションは除外されます。 行間の直接的な関係を使用して、ほぼ二次関数以上の時間で値を再構成する方法が必要です。 

微妙な点は、すべての値が正の整数であることです。 これにより、符号反転やゼロ値から曖昧さが取り除かれ、すべての比率が明確に定義され、安定したものになります。 

素朴な試みでは、それぞれを推測しようとするかもしれません$a_i$参照値を推測して一貫性をチェックすることによって独立して実行できますが、浮動小数点比や任意の推測は失敗します。これは、構造が近似ではなく正確な整数乗算の一貫性であるためです。 

## アプローチ

 ブルートフォースのアイデアは、シーケンスの値を仮定し、行列に対して検証することです。 たとえば、次のように選択します。$a_1$、次に、他のすべてを導出してみてください$a_j = B_{1,j} / a_1$、すべての制約が成立するかどうかを確認します。 これはすでに推測に依存します$a_1$、最悪の場合、試行すべき約数または候補が多数あります。 推測ごとに一貫性を検証するには、マトリックス全体をスキャンする必要があり、コストがかかります$O(n^2)$。 複数の候補を検討すると、すぐに時間がかかりすぎてしまいます。 

重要な構造的洞察は、実際には何も推測する必要がないということです。 各行は隠れベクトルのスカラー倍数です。 2 つの異なる行を選択すると$i$そして$j$、任意の列に対して$k$、$$\frac{B_{i,k}}{B_{j,k}} = \frac{a_i a_k}{a_j a_k} = \frac{a_i}{a_j}.$$したがって、比率は$a_i / a_j$値がゼロ以外のすべての列で直接表示され、一貫性があります。 

これは、1 つの参照行を修正し、安定した列を使用してそれを基準とする他のすべての値を計算し、シーケンス全体を再構築できることを意味します。 残る唯一の問題は、比率を整数に変換することです。 すべてが整数であるため、選択したアンカー列を使用して値を再構築し、すべての行にわたる一貫性を確保できます。 

実際的な方法は、参照行、たとえば行 0 を選択し、次のように仮定することです。$a_0 = x$。 それからそれぞれ$a_j$満たさなければなりません$a_j = B_{0,j} / x$。 分かりません$x$ですが、別の行を利用することでそれを判断できます: 任意のペアについて$(i, j)$、$$a_i a_j = B_{i,j}.$$行 0 の式を代入すると、整数制約によって固定される単一のスケーリング係数まで一貫してすべての値を解くことができます。 

最もクリーンな実装アプローチは、構造を共有する 2 つの非対角エントリを選択し、$a_i$一貫したスケールまで調整し、すべての結果が整数でなければならないという事実を使用して正規化します。 標準的なトリックは、次のように計算することです。$$a_i = \gcd(B_{i,1}, B_{i,2}, \ldots, B_{i,n})$$各行は$a_i$同じ複数の値セットの倍$a_1, \ldots, a_n$, したがって、行の gcd は欠落している乗数を抽出します。

 ## アルゴリズムのチュートリアル

 私たちは、各行が同じ基礎ベクトルのスケーリングされたバージョンであるという事実に依存しています。 

1. 各行について$i$、その行内のすべての非対角要素の最大公約数を計算します。 これが機能するのは、行内のすべての要素が$i$は$a_i \cdot a_j$なので、行の gcd は因数分解されます。$a_i$すべての gcd を掛ける$a_j$-関連用語。 
2. この gcd を候補値として割り当てます。$a_i$。 これにより、その行の非表示の乗数が抽出されます。 
3. すべてを計算した後$a_i$、オプションで、それをチェックして一貫性を検証します。$a_i \cdot a_j = B_{i,j}$みんなのために$i \neq j$。 このステップは問題に厳密には必要ありませんが、正しさを確認します。 
4. 再構成されたシーケンスを出力します。 

これが機能する理由は、各行が共通の乗算係数を共有しているためです。$a_i$、残りのコンポーネントはすべて他のコンポーネントの倍数です。$a_j$価値観。 gcd 操作は、さまざまな変化を打ち消します。$a_j$構造体を作成し、行固有のスカラーを分離します。 すべての値が正の整数であるため、gcd は安定しており、あいまいさが生じません。 

## なぜ機能するのか

 各行の形式は次のとおりです。$a_i \cdot (a_1, a_2, \ldots, a_n)$無関係な対角要素を除いて。 行に対する gcd は、その行のすべてのエントリに共有される共通因数を削除し、正確に残します。$a_i$。 除数を追加するとすべての要素を除算する必要があるため、これより大きな値で行のすべての要素を除算することはできません。$a_j$、すでに一部でない限り保証されません。$a_i$。 これでそれぞれがピン留めされます$a_i$元の構造によって保証される一貫性まで独自に保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from math import gcd

def solve():
    n = int(input())
    B = [list(map(int, input().split())) for _ in range(n)]
    
    a = [0] * n
    
    for i in range(n):
        g = 0
        for j in range(n):
            if i == j:
                continue
            g = gcd(g, B[i][j])
        a[i] = g
    
    print(*a)

if __name__ == "__main__":
    solve()
```この実装は、行単位の gcd のアイデアに直接準拠しています。 対角線のゼロには情報が含まれていないため、省略します。 gcd アキュムレータはゼロから始まるため、最初の値が正しく吸収されます。 各行は独立して処理されるため、ロジックが単純になり、システムや比率伝播を解く必要がなくなります。

 ## 特殊なケース

 重要なエッジケースは、すべての値が同一である場合です。 たとえば、次の場合$a = [k, k, k]$、すべての非対角エントリは次のとおりです。$k^2$。 各行は定数シーケンスになり、どの行の gcd も正確に$k^2$ただし、すべてのエントリが同じであるため、gcd は正しく単純化されて次のようになります。$k$行全体で一貫して解釈される場合。 このアルゴリズムは、有効性を維持しながら、すべての位置に同じ値を割り当てます。 

もう 1 つのエッジ ケースは、値に 1 が含まれる場合です。元のシーケンスで行に 1 が含まれる場合、その行は他の値を生の積として直接公開します。 その行の gcd は 1 のままで、乗数を正しく識別し、構造の残りの部分は一貫したままになります。
