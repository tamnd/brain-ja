 ## 解決策
 ## 問題の理解

 私たちには、選挙の投票を表す一連の名前が与えられます。 各行は候補者の 1 票に対応し、各候補者は 1 つの大文字の文字列で識別されます。 課題は、どの候補者が他のすべての候補者よりも厳密に多くの票を獲得したかを判断することです。 

重要な構造の詳細は、入力によって独自の勝者が保証されるということです。 これにより、同点や二次的なルールについて推論する必要がなくなります。 最も頻度の高い名前を特定するだけで済みます。 

制約は小さく、投票数は最大 500 票、各名前の長さは最大 20 です。これは、単純な集計戦略でも快適に機能することをすぐに示唆しています。 投票数が線形であるか、最悪の場合は 2 次である解もまだ許容されます。 ただし、入力サイズが小さいため、最もクリーンなアプローチは周波数マップを使用することです。 

素朴な実装でよくつまずく微妙なエッジケースは、名前が任意の順序で繰り返され、グループ化されていない可能性があることを忘れていることです。 たとえば、次のような入力

 ジョン

 ジョフリー

 タイウィン

 ジョン

 隣接しない位置全体でカウントを集計する必要があります。 連続した重複をチェックするだけのアプローチは、ここでは失敗します。 もう 1 つの潜在的な落とし穴は、辞書編集上の順序が何らかの役割を果たしていると仮定することですが、投票頻度が唯一の決定要因であるため、これは無関係です。 

## アプローチ

 この強引なアイデアは、各名前を候補として扱い、リスト全体をスキャンして、その名前が出現する回数を数えるというものです。 すべての投票について、すべての投票を再度繰り返すことによって、その合計頻度を再計算します。 これは「最も頻繁に」の定義を直接評価するため正しいですが、冗長な作業が実行されます。 N 個の投票がある場合、N 個のエントリごとに O(N) 個のカウント作業を実行し、O(N²) 個の操作が行われます。 

N ≤ 500 とすると、これは数値的にはまだ小さいですが、構造的に非効率であり不必要です。 重要な観察は、周波数カウントにはスキャンを繰り返す必要がないということです。 カウントを集計する必要があるのは 1 回だけです。 ハッシュ マップまたは辞書を使用すると、1 回のパスで頻度を蓄積し、各投票を読み取るたびにカウントを更新できます。 その後、単純に最大値を見つけます。 

これにより、繰り返しの作業が 1 回の線形走査に減り、その後に個別の名前に対する別の線形スキャンが実行されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(N²) | お(1) | 受け入れられますが冗長です |
 | 周波数マップ | O(N) | O(K) | 承認済み |

 ここで、K は個別の名前の数です。 

## アルゴリズムのチュートリアル

 1. 空の辞書を初期化して、候補者名をキーとした投票数を保存します。 この構造は、投票を順次処理する際に蓄積された選挙に関する知識を表します。 
2. 各投票を 1 つずつ読みます。 名前ごとに、辞書内のその数を増やします。 名前がまだ存在しない場合は、そのカウントを 1 に初期化します。このステップにより、すべての投票が 1 回だけ考慮されることが保証されます。 
3. 現在の最良の候補者とその投票数を追跡するための変数を管理します。 カウントを更新するときに、最後に最大値を再計算することも、段階的に更新することもできます。 最も単純でエラーが発生しにくいアプローチは、度数表を作成した後に計算することです。 
4. すべての投票を処理した後、辞書エントリを反復処理し、最大頻度の名前を選択します。 この問題では唯一の勝者が保証されているため、同点突破ロジックは必要ありません。 

### なぜ効果があるのか

処理中の任意の時点で、辞書には、これまでに検出された各名前の正確な出現数が保存されます。 すべての投票は正確に 1 回処理され、1 つのカウンタのみが増加するため、情報が失われたり二重にカウントされたりすることはありません。 すべての投票が処理されると、度数表はデータセットを正確に表現したものになります。 したがって、このテーブルで最大値を選択することは、元の入力で最も頻繁に使用される名前を選択することと同じです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n_line = input().strip()
    if not n_line:
        return
    n = int(n_line)
    
    freq = {}
    
    for _ in range(n):
        name = input().strip()
        freq[name] = freq.get(name, 0) + 1
    
    best_name = ""
    best_count = -1
    
    for name, cnt in freq.items():
        if cnt > best_count:
            best_count = cnt
            best_name = name
    
    print(best_name)

if __name__ == "__main__":
    solve()
```このソリューションでは、文字列をキーとする辞書を使用してカウントを蓄積します。 各入力行は改行文字を削除するために削除されます。 の`.get()`このメソッドは明示的な存在チェックを回避します。 すべての投票を読んだ後、辞書エントリに対して最終スキャンを実行して最大値を見つけます。 

微妙な実装の詳細が初期化されています`best_count`-1 にすると、1 票でも回答が正しく更新されます。

 ## 特殊なケース

 主なエッジケースは、勝者がグループ化されずに別々の位置に表示される場合です。 たとえば、入力では```
3
A
B
A
```辞書は次のように進化します`{A: 1}`、`{A: 1, B: 1}`、`{A: 2, B: 1}`。 連続していなくても、最後の最大値は A を正確に識別します。 隣接性に依存するアプローチでは、これを 2 つの無関係な A セグメントとして誤って扱うことになります。 

もう 1 つのエッジ ケースは、可能な最小の入力です。```
1
KING
```頻度表は次のようになります。`{KING: 1}`すぐに。 最大選択ステップは単純に KING を返し、縮退の場合には特別なロジックが必要ないことを示しています。 

最後に、次のように、すべての名前が同じ場合です。```
4
A
A
A
A
```単一の辞書エントリを生成します`{A: 4}`。 アルゴリズムはこれを曖昧にすることなく自然に処理し、最大値はすべてのステップを通じて一貫したままになります。
