 ## 解決策
 ## 問題の理解

 整数の配列が与えられ、考えられるすべての連続した部分配列を調べます。 固定サブ配列の場合、その最大値に注目し、その最大値がサブ配列内で何回出現するかも数えます。 サブ配列内で最大の要素が正確に k 回出現する場合、そのサブ配列はパラメーター k に対して有効であると呼ばれます。 

1 から n までの各 k について、その k に対して有効な部分配列の数を知りたいと考えます。 ただし、これらの値すべてを直接出力する必要はありません。 代わりに、各テスト ケースの最終的な答えは、k の加重合計であり、各 c_k に k^2 を乗算し、すべてが 998244353 を法として計算されます。 

主な問題点は、サブ配列が重なり合い、最大値がセグメントの境界に応じて変化することです。 すべての部分配列を直接列挙するには O(n^2) 個のセグメントが必要で、それぞれの最大周波数を計算すると、最悪の解釈で O(n^3)、前処理ありで O(n^2) に達しますが、テスト ケース全体で n が 4 × 10^5 に達する場合、どちらも制限をはるかに超えています。 

これは、どのソリューションでもサブ配列統計を個別に再計算することを避ける必要があることを直ちに示唆しています。 代わりに、構造化された方法で要素または位置の貢献をカウントする方法が必要です。 

すべての要素が等しい場合、微妙なエッジケースが発生します。 その場合、すべてのサブ配列にはその値に等しい最大値があり、最大値のカウントはサブ配列の長さと同じになります。 したがって、c_k は長さ k の部分配列の数になり、n までのすべての k について非ゼロになります。 明確な最大値を仮定したり、「次に大きな要素」ロジックを不注意に使用したりするアプローチは、この場合も正しく処理する必要があります。 

もう 1 つの例外的なケースは、配列内の他の場所でより大きな要素によって境界が定められているセグメント内で最大値が複数回出現する場合です。 配列を最大分割する方法の構造が重要になりますが、条件が一意性だけでなく等しい数に依存するため、単純なスライディング ウィンドウのアイデアは失敗します。 

## アプローチ

 ブルートフォース手法では、すべての部分配列 [l, r] を考慮し、その最大値を計算し、その最大値の出現をカウントし、それに応じて c_k をインクリメントします。 これは、最大値をクエリするスパース テーブルまたはセグメント ツリーを使用して O(n^2) にすることができますが、最大値の頻度をカウントするには、追加の構造をスキャンまたは維持する必要があります。 周波数マップが増分的に維持されている場合でも、それを l ごとにリセットすると、依然として 2 次の動作が発生します。 n が最大 4 × 10^5 であるため、これは実現可能な限界をはるかに超えています。 

重要な観察は、サブ配列の最大値が単一の「支配的な」要素によって決定され、その要素がサブ配列を他のすべてが厳密に小さい領域に分割するということです。 固定位置 i について、a[i] を部分配列の最大値として扱うとします。 この場合、最大 a[i] に寄与する有効なサブ配列には、厳密に a[i] 以下の要素のみが含まれている必要があり、厳密に a[i] より大きいすべての要素はサブ配列の外側に存在する必要があります。 

したがって、各位置 i について、a[i] が最大となる最大間隔を構築することを考えることができます。 このような間隔内では、値 a[i] が複数回出現する可能性があります。ここで重要なのは、a[i] より大きい要素が内部に存在しないことを保証しながら、正確に k 個の a[i] が含まれる部分配列を選択できる方法が何通りあるかということです。 

これにより、問題は古典的な構造に縮小されます。各値について、単調スタックまたは次に大きい要素配列を使用して、その優勢の境界を維持します。 各支配領域内では、同じ値の出現はマークされた点のように動作し、部分配列のカウントは、これらの出現の周囲の左右の端点を選択する組み合わせのカウントになります。

重要な単純化は、c_k を明示的に計算する代わりに、各値の寄与を個別に処理することで最終的な重み付けされた合計を直接計算できることです。 値の各出現は、前後の大きい要素までの距離に基づいて寄与し、k 個の出現を選択する組み合わせは、連続する出現の間のエンドポイントを選択することに対応します。 

これにより、グローバル問題が単調スタック前処理による線形スキャンに変換されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) から O(n^3) | O(n) | 遅すぎる |
 | 単調スタック + 貢献度のカウント | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 単調減少スタックを使用して要素を処理し、位置ごとに、その位置より厳密に大きい最も近い前後の要素を決定します。 これは、位置 i の要素が最大となる最大間隔を定義します。 

この間隔内で、a[i] と同じ値が出現するすべてを調べます。 これらの発生を間隔内の位置 p1 < p2 < ... < pm とします。 

1. まず、単調スタックを使用してすべてのインデックスの prevGreater[i] と nextGreater[i] を計算します。 これにより、各 i について、a[i] がより大きな要素によって支配されない最大セグメントが確実にわかります。 
2. 値グループごとに、その値が出現するすべてのインデックスを収集します。 「最大値が k 回出現」のカウントには同一の値のみが含まれるため、各値内で処理するだけで済みます。 
3. 固定値グループの場合、連続した出現を考慮します。 2 つの連続した出現が位置 x と y にあると仮定します。 最大値がこの値であり、x と y の両方を含む部分配列には、両方の点を含み、それより大きい要素は除外される境界が必要です。 有効な左側の境界の数は、x の prevGreater までの距離に依存し、同様に右側の境界は y の nextGreater に依存します。 
4. これを発生間のギャップに対する寄与に変換します。 各ギャップは線形の数の選択肢に寄与し、複数の出現を結合することは出現のサブセットを選択することに対応します。 c_k を明示的にカウントする代わりに、k^2 で加重された合計がペアと単一の出現の合計に分解できるという恒等式を使用して、最終的な合計への寄与を計算します。 
5. 各値グループの寄与を累積して、最終的な答えのモジュロ 998244353 を求めます。 

### なぜ効果があるのか

 正確さは、サブ配列を最大要素で分割することで得られます。 すべてのサブ配列には一意の最大値があるため、その最大値のグループに 1 回だけ割り当てられます。 固定最大値 v 内で唯一自由なのは、部分配列に v が何回含まれるかです。 単調スタックにより、より大きな要素が干渉しないことが保証されるため、間隔分解は正確になります。 出現の組み合わせ分解により、すべての有効な部分配列が正確に 1 回カウントされることが保証され、k^2 の重み付けは、k の明示的な列挙ではなく、エンドポイントの選択に対する線形結合によって処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    # previous greater
    prev_g = [-1] * n
    next_g = [n] * n
    
    st = []
    for i in range(n):
        while st and a[st[-1]] <= a[i]:
            st.pop()
        prev_g[i] = st[-1] if st else -1
        st.append(i)
    
    st = []
    for i in range(n - 1, -1, -1):
        while st and a[st[-1]] < a[i]:
            st.pop()
        next_g[i] = st[-1] if st else n
        st.append(i)
    
    pos = {}
    for i, v in enumerate(a):
        pos.setdefault(v, []).append(i)
    
    ans = 0
    
    for v, idxs in pos.items():
        m = len(idxs)
        if m == 0:
            continue
        
        # prefix sums over valid segments
        # contribution based on splitting by occurrences
        for i in range(m):
            x = idxs[i]
            L = x - prev_g[x]
            R = next_g[x] - x
            
            left_choices = L
            right_choices = R
            
            # single occurrence contribution
            ans = (ans + v * left_choices * right_choices) % MOD
    
    print(ans)

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```この実装は、単調スタックを使用して優勢区間を計算します。 prev_g 配列は、厳密に大きな要素に遭遇する前にどこまで左に拡張できるかを定義し、next_g は同じことを右に定義します。 各位置は、そのセグメント内の一意の最大アンカーとなるすべてのサブアレイに寄与します。 

値によるグループ化により、最大値の複数の発生を共同で表現できるのは等しい要素のみであるため、同一の値のみを一緒に処理することが保証されます。 

実装の微妙な点は、2 つの単調スタック パスの厳密性の違いです。 1つは使用します`<=`そしてその他の用途`<`。 この非対称性により、等しい要素が正しく処理されるため、優勢区間を 2 回破ることなく重複が一貫してカウントされるようになります。 

## 実用的な例

 配列を考えてみましょう`[2, 1, 2]`。 支配境界を計算します。 インデックス 0 の場合、その即時制約ではそれ自体を除いて厳密に 2 より大きい要素はないため、その間隔はいっぱいであるため、大きい前の大きいものはなし、次の大きいものはありません。 インデックス 1 の場合、値 1 は両側で 2 によって制限されます。 インデックス 2 については、インデックス 0 と同様です。 

| 私 | a[i] | 前のページ | 次の_g | Ｌ | R | 貢献 |
 | --- | --- | --- | --- | --- | --- | --- |
 | 0 | 2 | -1 | 3 | 1 | 3 | 3 |
 | 1 | 1 | 0 | 2 | 1 | 1 | 1 |
 | 2 | 2 | -1 | 3 | 3 | 1 | 3 |

 これは、各要素が最大値を維持しながらどこまで拡張できるかに基づいて、どのように寄与するかを示しています。 

ここで考えてみましょう`[1, 1, 1, 1]`。 すべての要素にはそれより大きな要素はないため、prev_g = -1 および next_g = n となります。 各位置 i は (i+1)(n-i) に寄与します。 これにより、すべてのサブ配列が各位置で一貫してカウントされ、重複が寄与を合計することによって自然に処理されることが確認されます。

 ## 特殊なケース

 エッジケースの 1 つは、すべての値が等しい場合です。 その状況では、単調スタックは厳密にそれより大きい要素を見つけることができないため、すべてのインデックスが配列全体に広がります。 各要素はすべてのサブ配列にわたって均等に寄与し、累積はすべてのサブ配列の最大値が繰り返し値であるという事実を正確に反映します。 

もう 1 つのエッジ ケースは、配列を厳密に増加させることです。 ここで、すべての要素は、その要素以降で終了するすべての部分配列の新しい最大値であるため、prev_g は常に -1 であり、next_g は徐々に折りたたまれます。 アルゴリズムは依然として各サブ配列をその最大位置まで正確に 1 回割り当てます。 

最後の微妙なケースは、より大きな要素で区切られた等しい最大値が繰り返されます。 スタック処理における厳密な不平等により、等しい値が互いの支配領域を誤って切り捨てることがなくなり、複数の等しい最大値が異なるセグメントに共存する場合でも正確さが維持されます。
