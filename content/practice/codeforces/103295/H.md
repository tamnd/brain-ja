 ## 解決策
 ## 問題の理解

 私たちには、セグメントで構成される線形の世界が与えられており、一部の位置は固体の土地であり、他の位置は水です。 このタスクは、開始地域からターゲット地域まで陸地の連続した経路を構築することを中心に展開しますが、水の隙間に限られた数の「橋」を建設することでマップを変更することができます。 各橋は、連続する水域を通過可能な陸地に効果的に変換します。目標は、最大でも所定の数のそのような構造物を使用して必要な終点を接続できるかどうかを判断することです。 

入力は、セルの一次元配置と、配置できるブリッジの数および接続性の観点からの効果に関する制約を記述します。 出力は二分決定であり、陸上のみの横断で開始点と終了点に到達できるようにする有効な橋の配置シーケンスが存在するかどうかを示します。 

主な困難は、到達可能性自体をチェックすることではなく、予算の制約の下で、橋の配置によって複数の切断された土地セグメントが単一の接続されたコンポーネントにどのようにマージされるかを理解することです。 

複雑さの観点から見ると、自然なスケールは線形または線形に近い解決策を示唆します。 セルの数が 10^5 以上のオーダーである場合、ブリッジの配置を繰り返しシミュレートしたり、接続を最初から再計算したりするアプローチは遅すぎます。 これにより、操作ごとの単純なグラフ再構成や二次マージ戦略が即座に排除されます。 

いくつかの特殊なケースが非常に重要です。 すでに連続した陸路が存在する場合、橋は必要なく、制約に関係なく答えは常に肯定的になるはずです。 逆に、土地が水のギャップによって分離された孤立した単一セルに極度に断片化されている場合は、すべての合流が重要となり、貪欲な戦略や数え間違いによる戦略により、必要な橋が簡単に過小評価される可能性があります。 微妙な例としては、次のような水の隙間のサイズが不均一な場合があります。 

入力:```
land-water-water-land-water-land
k = 1
```単純なアプローチでは、1 つの橋が複数のセグメントに「接触」していればすべてを接続できると想定するかもしれませんが、正しく解釈するには、1 つの橋は 1 つの連続する水のギャップのみを排除し、複数の分離されたギャップを同時に排除するわけではないことを認識する必要があります。 

## アプローチ

 この強引なアイデアは、橋を配置する可能なすべての方法を明示的にシミュレートすることです。 私たちは、陸地構成要素間の各水の間隔を、埋めることができる潜在的なギャップとして扱い、最大 k 個のギャップのすべての組み合わせを試してマージします。 それぞれの仮説を選択した後、結果の構造が最初から最後まで完全に接続されたパスを形成するかどうかを再計算します。 

これは、ブリッジ使用の有効なシーケンスをすべて列挙するため正しいですが、すぐに実行不可能になります。 g 個のギャップがある場合、サイズが最大 k のサブセットの数は binomial(g, k) のオーダーであり、各チェックでは構造に対するスキャンまたはユニオン操作が必要です。 最悪の場合、これは本質的に指数関数的、または少なくとも組み合わせ的なものとなり、大規模な入力に対する合理的な制限をはるかに超えます。 

重要な洞察は、実際にはさまざまな選択肢をシミュレートする必要がないということです。 重要なのは、開始点から終了点までの経路に沿って連続する土地セグメントを分離するバラバラな水のギャップがいくつあるかだけです。 各ブリッジはそのようなギャップを 1 つだけ除去できます。つまり、問題は、構成を調査するのではなく、接続されたコンポーネントと内部分離を数えることに減ります。 

陸地のセグメントがコンポーネントに圧縮されると、開始点と終了点の間の構造は、陸地と水のブロックが交互に並んだものになります。 すべての水ブロックは強制的な分離を表します。 すべてを接続するには、排除することを選択した水ブロックごとに 1 つの橋を「支払う」必要があります。 隣接するランド コンポーネントを結合すると、ブリッジごとにギャップの数がちょうど 1 つ減少するため、最適な戦略は単純に必要最小限の分離ギャップでブリッジを使用することです。これは、エンドポイントのコンポーネント間のギャップの数からしきい値 1 を引いたものとなります。

 | ブルートフォース | O(2^g・n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 入力文字列を同じタイプの最大の連続セグメントに減らし、陸地と水のブロックを分離します。 

1. アレイをスキャンし、交互のセグメントに圧縮します。 各セグメントには、陸地か水域か、およびその境界が格納されます。 これが必要なのは、個々のセルではなく、セグメント間の遷移のみが重要であるためです。 
2. 開始位置を含むセグメントと終了位置を含むセグメントを特定します。 両方が同じ土地セグメント内にある場合、横断や変更は必要ないため、答えはすぐに「はい」になります。 
3. 開始セグメントから終了セグメントまで順番に歩き、それらの間に厳密に存在する水セグメントの数を数えます。 このような各水セグメントは断絶を表しており、連続性を維持したい場合は橋を架けなければなりません。 
4. 必要な水の隙間の数と利用可能な橋の数 k を比較します。 k が少なくともギャップの数であれば、すべての分離を除去し、最初から最後まで接続できます。 
5. 実行可能な場合は「yes」を出力し、実行可能な場合は「no」を出力します。 

これが機能する理由は、開始と終了の間の構造が線形であるため、有効な接続はすべての中間境界を順番に通過する必要があるためです。 各水域は必須の障害物として機能し、橋を経由しない限り迂回することはできません。 橋は複数の独立したギャップをスキップするような形で相互作用しないため、問題は障害物の直接のカウントになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    s = input().strip()
    a, b = map(int, input().split())
    a -= 1
    b -= 1

    # assume '1' is land, '0' is water
    if a > b:
        a, b = b, a

    # if start and end are same type land cell in trivial interpretation
    if s[a] == '1' and s[b] == '1' and s[a:b+1].count('0') == 0:
        print("YES")
        return

    # count water segments between a and b
    i = a
    gaps = 0

    while i < b:
        if s[i] == '1':
            i += 1
            continue

        # we are in water, count full block
        gaps += 1
        while i < b and s[i] == '0':
            i += 1

    print("YES" if gaps <= k else "NO")

if __name__ == "__main__":
    solve()
```コードはバイナリ文字列を読み取り、トラバーサルが常に左から右になるようにエンドポイントを正規化します。 次に、その間隔を 1 回スキャンし、陸上セルをスキップし、連続する水ブロックを単一の障害物としてカウントします。 各障害物は 1 つの橋の要件を表します。 k との最終比較により、実現可能性が決定されます。 

微妙な点は、連続する水のセルが二重にカウントされないようにすることです。 内側のループは、各水流をギャップ カウンターの正確に 1 増分に折りたたみます。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、エンドポイント間の間隔全体に水が含まれていない場合です。 例えば、`111111`どのkでも。 このアルゴリズムはギャップがゼロであることを即座にカウントするため、ブリッジ ロジックを実行せずに YES を出力し、パスが既に存在するという事実と一致します。 

もう 1 つのエッジ ケースは、エンドポイントが大きな水ブロックに囲まれているが、許可されるブリッジは 1 つだけである場合です。 例えば、`1000001`k = 1 の場合。スキャンでは 1 つの連続した水ブロックが見つかり、そのブロック全体を 1 回の操作で変換できるため、アルゴリズムは正しく YES を出力します。 

より微妙なケースは、すべての位置で陸と水が交互になることです。 このアルゴリズムは、各水の流量を別個の単位として扱い、個々のゼロを誤って複数回カウントしないようにします。 のために`101010`、5 つの個別のセルではなく 2 つの水ブロックを正確に識別し、橋の要件の正確さを維持します。
