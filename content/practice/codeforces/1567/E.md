 ## 解決策
 ## 問題の理解

 ポイント更新の下で配列を維持します。 各更新の後、今後のクエリでは新しい値を使用する必要があります。 

セグメントに対するクエリの場合`[l, r]`、完全にその範囲内にある減少しないサブ配列の数を数えなければなりません。 サブアレイ`[p, q]`内部の隣接するすべてのペアが次の条件を満たす場合に有効です`a[i] ≤ a[i+1]`。 

課題は、更新とクエリの両方が頻繁に行われることです。 配列サイズと演算数はそれぞれ次のようになります。`2 · 10^5`。 

すべてのクエリを直接再計算することは不可能です。 クエリされた間隔全体をスキャンするだけでもコストがかかります`O(n)`クエリごとに、おおよそ次のようになります`4 · 10^10`最悪の場合の運用。 

制約からの重要な観察は、何かが必要であるということです。`O(log n)`操作ごとに。 これは、セグメント ツリーまたは別の対数データ構造を強く示唆しています。 

単純なマージが失敗する微妙なケースがいくつかあります。 

考慮する：```
[1, 2] + [2, 3]
```両方の半分は非減少であり、境界も満たされます。`2 ≤ 2`。 中間点を横切る部分配列は、追加の有効な答えを提供します。 それぞれの半分の中に答えを格納して加算するだけだと、交差する部分配列をすべて見逃してしまいます。 

ここで次のことを考えてみましょう。```
[1, 3] + [2, 4]
```それぞれの半分は内部的には減少しませんが、境界が条件に違反しています。`3 > 2`。 有効な交差部分配列はありません。 常に実行を結合するマージではオーバーカウントが発生します。 

もう 1 つのよくある間違いは、値が等しい場合に発生します。```
1 1 1
```すべての部分配列は減少しないため、答えは次のようになります。```
3 + 2 + 1 = 6
```非厳密な不等式の代わりに厳密な不等式を使用すると、より小さな答えが生成されます。 

最後に、単一の要素範囲は常に 1 つの有効な部分配列に寄与します。 セグメント ツリーの状態は、長さ 1 のセグメントを正しく処理する必要があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。 あらゆるクエリに対して`[l, r]`、その範囲内のすべての部分配列を列挙し、それぞれが減少していないかどうかを確認します。 

がある`O((r-l+1)^2)`候補の部分配列。 それぞれを直接チェックすると、`O(n^3)`最悪の場合は時間がかかります。 情報を事前計算して検証を削減したとしても、`O(1)`、まだ必要です`O(n^2)`クエリごとに作業します。 と`2 · 10^5`これはまったく実行不可能な操作です。 

ブルートフォースソリューションが概念的に機能する理由は、すべての有効な答えが、減少しない部分配列の数にすぎないためです。 難しいのは、セグメントの境界をまたぐものを効率的にカウントすることです。 

この問題を考えるのに役立つ方法は、長さが減少しないすべての最大ランが次のとおりであるということです。`k`貢献する$$\frac{k(k+1)}2$$有効な部分配列。 

例えば：```
1 2 3 1 5
```一定の長さのランが含まれています`3`そして`2`、貢献```
6 + 3 = 9
```サブアレイ。 

セグメント ツリー ソリューションには、2 つの隣接するセグメントが結合されたときに実行がどのように動作するかを再構築するために、各セグメントに関する十分な情報が保存されます。 

次のことがわかっているとします。 

1. それぞれの子供の中にある合計の答え。 
2. 各子の最長の非減少プレフィックス。 
3. 各子の最長の非減少接尾辞。 
4. 左端と右端の値。 

次に、2 つのセグメントを結合するときに、境界が次の条件を満たすかどうかを判断できます。```
right_value_left ≤ left_value_right
```存在する場合、左側の子からのサフィックス実行と右側の子からのプレフィックス実行が 1 つの大きなランに接続されます。 すべての交差する非減少部分配列は、左側の接尾辞で開始点を選択し、右側の接頭辞で終了点を選択することによって形成されます。 

サフィックスの長さが`s`プレフィックスの長さは`p`、交差する部分配列の数は正確に```
s · p
```これにより、きれいなセグメント ツリーがマージされます。`O(1)`時間。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | クエリごとに O(n²) から O(n³) | お(1) | 遅すぎる |
 | 最適なセグメント ツリー | 操作ごとに O(log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### セグメント情報

 間隔を表すセグメント ツリー ノードごとに、以下を保存します。`len`= 間隔の長さ。`lv`= 左端の値。`rv`= 右端の値。`pref`= 最長の減少しないプレフィックスの長さ。`suff`= 最長の非減少接尾辞の長さ。`ans`= 区間内全体で減少しない部分配列の数。 

### 結合ルール

 左の子をマージするとします`A`そして右の子`B`。 

#### 1. 基本フィールドを計算する

 結合された長さは次のとおりです。```
len = A.len + B.len
```一番左の値は次から取得されます`A`、右端の値は次のとおりです。`B`。 

#### 2. 社内の回答から始める

 いずれかの子の完全に内部にあるすべての有効なサブ配列は、すでに寄与しています。```
ans = A.ans + B.ans
```#### 3. ランが中間点を越えて接続されているかどうかを確認します

 もし```
A.rv <= B.lv
```次に、次の非減少接尾辞`A`の非減少プレフィックスを結合します`B`。 

すべての交差する有効な部分配列は、以下を選択することによって取得されます。```
start in A's suffix
end in B's prefix
```それで追加します```
A.suff * B.pref
```答えに。 

#### 4. マージされたプレフィックスを計算する

 プレフィックスは最初は次と等しくなります`A.pref`。 

左側のセグメント全体が 1 つの非減少プレフィックスであり、境界が接続されている場合、プレフィックスは右側の子に拡張されます。```
pref = A.len + B.pref
```#### 5. マージされたサフィックスを計算する

 対称的に、右セグメント全体が 1 つの非減少接尾辞であり、境界が接続されている場合は、次のようになります。```
suff = B.len + A.suff
```それ以外の場合はそのままです`B.suff`。 

#### 6. セグメント ツリーを構築する

 各リーフは 1 つの配列要素に対応します。 

葉の場合:```
len = 1
pref = 1
suff = 1
ans = 1
lv = rv = value
```#### 7. 更新の処理

 1 つのリーフを変更し、マージ ルールを使用してルートへのパス上のすべてのノードを再計算します。 

#### 8. クエリを処理する

 標準のセグメント ツリー範囲クエリを実行します。 

クエリは、説明する集約ノードを返します。`[l, r]`。 

その`ans`フィールドはまさに必要な回答です。 

### なぜ効果があるのか

 セグメント内のすべての非減少部分配列は、3 つのカテゴリのいずれかに属します。 

それは完全に左の子の中にあるか、完全に右の子の中にあるか、または中間点を横切っています。 

最初の 2 つのカテゴリはすでにカウントされています`A.ans`そして`B.ans`。 

交差部分配列は、左端点が左子の最大非減少接尾辞内で選択され、右端点が右子の最大非減少接頭辞内で選択された場合に正確に存在します。 中間値が非減少条件に違反する場合、交差する部分配列は存在できません。 

マージでは、交差するすべてのサブ配列が 1 回だけカウントされます。`A.suff × B.pref`、無効なものはカウントされません。 すべてのセグメント ツリー ノードはこの不変式を使用して構築されるため、クエリされた間隔のルートには、減少しない部分配列の正確な数が格納されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class Node:
    __slots__ = ("length", "lv", "rv", "pref", "suff", "ans")

    def __init__(self, length=0, lv=0, rv=0, pref=0, suff=0, ans=0):
        self.length = length
        self.lv = lv
        self.rv = rv
        self.pref = pref
        self.suff = suff
        self.ans = ans

def merge(a, b):
    if a.length == 0:
        return b
    if b.length == 0:
        return a

    res = Node()
    res.length = a.length + b.length
    res.lv = a.lv
    res.rv = b.rv

    res.ans = a.ans + b.ans

    connected = a.rv <= b.lv

    if connected:
        res.ans += a.suff * b.pref

    res.pref = a.pref
    if connected and a.pref == a.length:
        res.pref = a.length + b.pref

    res.suff = b.suff
    if connected and b.suff == b.length:
        res.suff = b.length + a.suff

    return res

n, q = map(int, input().split())
a = list(map(int, input().split()))

size = 1
while size < n:
    size <<= 1

seg = [Node() for _ in range(2 * size)]

for i in range(n):
    seg[size + i] = Node(
        length=1,
        lv=a[i],
        rv=a[i],
        pref=1,
        suff=1,
        ans=1,
    )

for i in range(size - 1, 0, -1):
    seg[i] = merge(seg[i * 2], seg[i * 2 + 1])

for _ in range(q):
    t, x, y = map(int, input().split())

    if t == 1:
        pos = x - 1

        p = size + pos
        seg[p] = Node(
            length=1,
            lv=y,
            rv=y,
            pref=1,
            suff=1,
            ans=1,
        )

        p //= 2
        while p:
            seg[p] = merge(seg[p * 2], seg[p * 2 + 1])
            p //= 2

    else:
        l = x - 1
        r = y - 1

        left_res = Node()
        right_res = Node()

        l += size
        r += size + 1

        while l < r:
            if l & 1:
                left_res = merge(left_res, seg[l])
                l += 1

            if r & 1:
                r -= 1
                right_res = merge(seg[r], right_res)

            l //= 2
            r //= 2

        res = merge(left_res, right_res)
        print(res.ans)
```ノードには、マージ操作に必要な情報が正確に保存されます。 追加のデータは必要ありません。 

最もデリケートな部分は範囲クエリです。 セグメント ツリー クエリは、左右の方向からピースを別々に収集します。 マージは可換ではないため、順序は重要です。 セグメント`[A][B]`とは異なる方法でマージする必要があります`[B][A]`。 

それが実装が維持される理由です`left_res`そして`right_res`独立して最後にのみ結合します。 

もう 1 つの微妙な詳細は、ニュートラル ノードです。 ノード`length = 0`アイデンティティ要素として機能します。 マージ関数は、一方のオペランドが空になるとすぐにもう一方のオペランドを返します。 

長さ内のサブ配列の最大数は制限されているため、すべての応答値は 64 ビット整数内に快適に収まります。`2 · 10^5`間隔は約`2 · 10^10`。

 ## 特殊なケース

 次のことを考慮してください。```
3
1 1 1
```隣接するすべての比較は成功します。 セグメント全体が 1 つの長さになります`3`、貢献:$$\frac{3\cdot4}{2}=6$$マージ条件は次を使用します`<=`、両方の境界が正しく接続され、セグメント ツリーが返されます。`6`。
