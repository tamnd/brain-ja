 ## 解決策
 ## 問題の理解

 サイズのグリッドが与えられています$n \times m$ここで、一部のセルには`X`そして残りは無印です`.`。 マークされたセルがグリッドの境界上に存在することはありません。 私たちのタスクは、マークされていないすべてのセルに 1 または 4 を入力し、次にマークされた各セルに隣接するマークされていないセルの合計を入力することです。 さらに、マークされた各セルの最終値は 5 で割り切れる必要があります。割り当てが存在しない場合は、次の値を出力する必要があります。`NO`; それ以外の場合は、有効な塗りつぶされたグリッドが生成されます。 

入力制約$1 \le n, m \le 500$と提案する$O(n \cdot m)$解決策は実現可能です。 みたいなもの$O((n \cdot m)^2)$遅すぎる危険があるので、$500^2 = 250{,}000$それはいいけど、$500^4$考えられない。 256 MB のメモリ制限により、グリッドと補助配列の保存に簡単に対応できます。 

素朴なアプローチでは、すべてのマークされていないセルに対して 1 と 4 のすべての組み合わせを試行し、マークされたセルの割り算をチェックする可能性があります。 これは失敗します。なぜなら、控えめな 10×10 グリッドでも$2^{100}$その組み合わせは天文学的に膨大です。 

明白でないエッジ ケースには、マークされていない隣接セルが 1 つまたは 2 つだけあるマークされたセルが含まれます。 たとえば、マークされたセルに完全に囲まれたマークされたセルは 0 を取得する必要があります。別のケースは、マークされたセルが 4 つのマークされていないセルに隣接する場合です。 1 と 4 のすべての組み合わせの合計が 5 の倍数になるわけではありません。 隣接関係の合計が実現可能であることを確認する必要があります。 不用意に貪欲な割り当てを行うと、3 や 6 のようなマークされたセルの合計が作成される可能性があり、これは隣接する割り当てでは修正できません。 

## アプローチ

 ブルートフォースアプローチは、マークされていないセルへの 1 または 4 の可能なすべての割り当てを反復し、マークされたセルの合計をチェックすることです。 マークされていない各セルには 2 つのオプションがあります。$2^{u}$～の可能性$u$マークのないセル。 検証ステップには、マークされたセルのスキャンと隣接セルの合計が含まれます。 これは原理的には正しいですが、マークされていないセルが 20 個を超えるグリッドでは実行できなくなります。 

重要な洞察は、マークされた各セルがマークされていないセルのサブセットに隣接しており、モジュロ 5 の合計が 0 でなければならないということです。問題は 2-sat スタイルの制約に帰着します。つまり、隣接するマークされていないセルの値は 2 つの状態を取ることができる変数として表すことができ、それらの合計のモジュロ 5 のパリティが制約を満たさなければなりません。 具体的には、マークされていないセルをチェッカーボード パターンでペイントすると、マークされたすべてのセルには、一方の色が 2 つ、もう一方の色が 2 つ隣接することになります (エッジにはさらに少ないが、エッジにはマークされたセルがありません)。そのため、すべての合計が 5 で割り切れるように 2 つの色に値を割り当てることができます。マークされていないセルには、チェス盤パターンで 1 と 4 を交互に割り当てるのが自然な選択です。 次に、マークされた各セルの合計は 5 で割り切れます。つまり、2 つの 1 と 2 つの 4 の合計は 10 になり、5 で割り切れます。マークされたセルに隣接するセルが 1 つしかない場合でも、1+4 = 5 は機能します。 

この観察により、貪欲にソリューションを構築できるようになります。$O(n \cdot m)$後戻りのない時間。

 ## アルゴリズムのチュートリアル

 1. 出力グリッドを保存する 2D 配列を作成します。 マークされていないすべてのセルを、プレースホルダーとして -1 を使用して初期化します。 
2. マークされていないセルの値をチェス盤パターンで割り当てます。行インデックスと列インデックスの合計が偶数の場合は 1 を割り当て、そうでない場合は 1 を割り当てます。 奇数の場合は、4 を割り当てます。これにより、マークされていないセルに隣接するマークされたセルには、合計が 5 の倍数になる隣接セルがあることが保証されます。 
3. グリッド内の各セルを繰り返し処理します。 セルがマークされている場合は、隣接するマークされていないすべてのセルの合計を計算します。 マークのないセルには 1 と 4 が交互に割り当てられていることがわかっているため、この合計は自動的に 5 で割り切れます。マークの付いたセルにこの合計を入力します。 
4. 出力`YES`塗りつぶされたグリッドを行ごとに印刷します。 隣接セルがゼロのマークされたセルがある場合、その合計は 0 であり、5 で割り切れるため、特別な処理は必要ありません。 

機能する理由: チェス盤の割り当てにより、マークされていない隣接セルのどのような構成でも、マークされたセルの周囲の数値の合計が常に 5 の倍数になることが保証されます。この不変条件は 1+4 = 5 であるため成り立ち、隣接セルの任意の組み合わせにおける複数の 1 と 4 の合計は 5 で割り切れる合計を生成します。それ以上のバックトラックや 2 回のサット解決は必要ありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
grid = [list(input().strip()) for _ in range(n)]
ans = [[0]*m for _ in range(n)]

for i in range(n):
    for j in range(m):
        if grid[i][j] == '.':
            ans[i][j] = 1 if (i+j) % 2 == 0 else 4

directions = [(-1,0),(1,0),(0,-1),(0,1)]

for i in range(n):
    for j in range(m):
        if grid[i][j] == 'X':
            s = 0
            for dx, dy in directions:
                ni, nj = i+dx, j+dy
                if 0 <= ni < n and 0 <= nj < m and grid[ni][nj] == '.':
                    s += ans[ni][nj]
            ans[i][j] = s

print("YES")
for row in ans:
    print(' '.join(map(str,row)))
```マークのない各セルには、インデックスのパリティを使用して値が直接割り当てられ、チェッカーボード パターンが保証されます。 マークされたセルを埋めるときは、隣接するマークされていないセルのみを合計します。 境界は尊重されるため、範囲外のエラーは発生しません。 このアプローチでは、チェッカーボード プロパティによって 5 で割り切れる合計が保証されるため、割り算を明示的にチェックする必要はありません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    grid = [list(input().strip()) for _ in range(n)]
    ans = [[0]*m for _ in range(n)]
    for i in range(n):
        for j in range(m):
            if grid[i][j] == '.':
                ans[i][j] = 1 if (i+j) % 2 == 0 else 4
    directions = [(-1,0),(1,0),(0,-1),(0,1)]
    for i in range(n):
        for j in range(m):
            if grid[i][j] == 'X':
                s = 0
                for dx, dy in directions:
                    ni, nj = i+dx, j+dy
                    if 0 <= ni < n and 0 <= nj < m and grid[ni][nj] == '.':
                        s += ans[ni][nj]
                ans[i][j] = s
    output = ["YES"] + [' '.join(map(str,row)) for row in ans]
    return '\n'.join(output)

# provided sample

# marked cell with one neighbor
