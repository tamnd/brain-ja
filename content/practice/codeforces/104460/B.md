 ## 解決策
 ## 問題の理解

 有向グリッドが与えられ、各セルには方向 (上、下、左、右) と正のジャンプ長という 2 つの情報が含まれます。 選択したセルから開始して、そのセル内のルールに従って繰り返し「テレポート」します。つまり、保存されている距離だけその方向に正確に移動します。 目的地がグリッドの外に出るか、現在の歩行ですでに訪問したセルに到達すると、プロセスは停止します。 

問題は、この決定論的な動きが終了前にグリッド内のすべてのセルを正確に 1 回訪問するような開始セルが少なくとも 1 つ存在するかどうかです。 グラフの用語では、すべてのセルは 1 つの外向きエッジ (グリッドの外につながる場合は何もない) を持つノードであり、この関数グラフにすべてのノードをカバーするハミルトニアン パスが含まれているかどうかを尋ねます。 

制約$n \times m \le 10^5$これは、最大 10 万のノードとエッジを操作していることを意味します。 各シミュレーションがほぼすべてのノードを横断できるため、すべての開始セルからのパスをシミュレートしようとするソリューションは、最悪の場合、すぐに 2 次になります。 それはその辺でしょう$O(N^2)$、これは許容範囲をはるかに超えています。 

グラフが複数のサイクル、またはサイクルとテールを形成する場合、微妙な失敗のケースが発生します。 たとえば、2 つの互いに素なサイクルが存在する場合、どちらの開始点もその両方を通過することはできませんが、単純なシミュレーションでは依然としてサイクル全体を通過し、早期に戻った場合に誤って成功したと想定する可能性があります。 すべてのノードが 1 サイクル内にあるが、サイクルの長さが 1 サイクルより短い場合、別の問題が発生します。$n \times m$; 内部で開始すると決してエスケープされないため、すべてのノードに有効な発信エッジがある場合でもカバレッジは不可能です。 

主要な問題はパス シミュレーションではなく、グローバル構造です。すべてのノードが単一の有向サイクル上にあるかどうかを判断する必要があります。 

## アプローチ

 各セルは出力遷移を 1 つだけ定義するため、グリッドは、すべてのノードが出次数 1 を持つ有向グラフ (関数グラフ) を形成します。 このようなグラフは、ツリーがそこに入るサイクルに分解されます。 

問題をブルート フォースで解決する場合は、すべての開始セルを試し、プロセスが停止するか繰り返されるまでシミュレーションします。 それぞれのシミュレーションにかかる時間は、$O(N)$、そして、あります$N$開始、与える$O(N^2)$。 と$N = 10^5$、これでは遅すぎます。 

重要な構造上の観察は、このグラフ内のウォークは常に最終的にサイクルに入るということです。 一度サイクルに入ると、そこから出ることはできません。 したがって、すべてのノードを 1 回だけ訪問するには、グラフに 1 つのサイクルが含まれている必要があり、すべてのノードがそのサイクルの一部である必要があります。 サイクルにフィードするツリー内にノードが 1 つでもある場合、そのノードはサイクルに入る前にアクセスされますが、サイクルは開始の選択に応じて強制的に再アクセスするか、ノードに到達できないままになります。 どのような場合でも、ツリー エッジが存在すると、単一の完全な走査の可能性が失われます。 

したがって、タスクは、関数グラフがすべてのノードを含む単一の有向サイクルであるかどうかをチェックすることになります。 これは、すべてのノードの出次数 1 だけでなく入次数も正確に 1 であることを検証することと同じです。これは、どこでも出次数 1 を持つ有限有向グラフでは、「すべての入次数 1」によってすべてのノードに対して単一の置換サイクルが強制されるためです。 

したがって、各セルの宛先を計算し、入次数を構築し、すべてのノードが入次数 1 を持ち、境界外に出るエッジがないこと (サイクル構造を壊すことになる) を検証します。

 ## アルゴリズムのチュートリアル

 各グリッド セルを一意のインデックスにマップします。 各セルについて、その方向とステップ サイズを使用してターゲット セルを計算します。 

1.各セルを変換する$(i, j)$ノードIDに$u = i \cdot m + j$。 これにより、グリッドをグラフとして扱うことができます。 
2. 各ノードについて、その宛先を計算します。$(x, y)$矢印とジャンプの長さを使用します。 宛先がグリッドの外側にある場合、このノードは直ちに無効としてマークされます。 有効な完全な走査はグリッドから「出る」ことができないため、これは重要です。 
3. 次の度数配列を構築します。`ind[v]`を指すノードの数を数えます$v$。 
4. いずれかのノードに無効な発信エッジがある場合は、「No」を返します。 これは、途中で終了するパスに相当します。 
5. すべてのノードの入次数が正確に 1 であることを確認します。いずれかのノードの入次数が 0 である場合、そのノードは入力されません。 いずれかのノードの indegree > 1 がある場合、複数のパスがそのノードにマージされます。これは、単一のハミルトニアン サイクルと互換性のない分岐構造を意味します。 
6. すべてのノードが次数 1 を持ち、すべてのエッジが有効な場合は、「Yes」を返します。 

### なぜ効果があるのか

 すべてのノードには出力エッジが 1 つだけあるため、グラフは、可能性のある入力ツリーを含む有向サイクルの素結合になります。 ツリー内のノードは構造に沿って入次数 0 または 1 より大きくなければなりませんが、完全な単一サイクル内のサイクル ノードは入次数が正確に 1 になります。 

あらゆる場所で内次数 1 を要求すると、ツリーが強制的に存在せず、すべてのノードがサイクルに属することが強制されます。 ノードの数はエッジの数に等しく、すべてのノードには入次数と出次数 1 があるため、コンポーネント全体にわたる入次数のグローバルな一貫性を損なうことなくグラフを複数のサイクルに分割することはできません。 これにより、すべてのノードを含む 1 つのサイクルが強制されます。これは、すべてのノードを 1 回訪問するトラバーサルに必要な条件とまったく同じです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, m = map(int, input().split())
        dirs = [input().strip() for _ in range(n)]
        a = [list(map(int, input().split())) for _ in range(n)]

        N = n * m
        indeg = [0] * N

        def id(i, j):
            return i * m + j

        ok = True

        for i in range(n):
            for j in range(m):
                step = a[i][j]
                d = dirs[i][j]
                ni, nj = i, j

                if d == 'u':
                    ni -= step
                elif d == 'd':
                    ni += step
                elif d == 'l':
                    nj -= step
                else:
                    nj += step

                if ni < 0 or ni >= n or nj < 0 or nj >= m:
                    ok = False
                else:
                    indeg[id(ni, nj)] += 1

        if not ok:
            print("No")
            continue

        for v in range(N):
            if indeg[v] != 1:
                ok = False
                break

        print("Yes" if ok else "No")

if __name__ == "__main__":
    solve()
```この実装では、まずグリッドが線形化され、遷移が単純な整数エッジになります。 各セルは正確に 1 つのターゲットを計算します。 そのターゲットがグリッドから離れると、ウォークが早期に終了し、すべてのセルをカバーできないため、ケースは直ちに拒否されます。 

indegree 配列は、各ノードに入ることができる方法の数をキャプチャします。 正しい構成では、すべてのノードが 1 回だけ入力されるようにする必要があります。そうしないと、一部のノードがまったくアクセスされないか、一部のノードが複数の先行ノードからアクセスされ、必要な単一パス構造が壊れます。 

最後のチェックでは、グラフがすべてのノードにわたって順列のように動作する必要があるというグローバル制約が適用されます。

url

```セルに 0 ～ 5 のインデックスを付けます。 

| セル | 方向 | ステップ | 目的地 | 有効 | 度数更新 |

 | (1,2) | r | 1 | (1,3) | はい | +1 |

 少なくとも 1 つの遷移がグリッドから離れるため、この構成はフルサイクル要件の下では無効になります。 

これは、単一の無効なエッジによって完全な走査の可能性がどのように妨げられるかを示しています。 

### 例 2

 入力:```
2 2
rr
rr
1 1
1 1
```すべての移動は 1 ずつ右を指し、次の結果が得られます。 

| セル | 目的地 |
 | --- | --- |

 | (1,2) | アウト |

 | (2,2) | アウト |

 右下の出口は両方とも有効性を破っており、indegree 条件も失敗します。 

これは、移動が決定的で単純であるにもかかわらず、部分的なサイクルまたは終了によってすべてのノードを訪問する可能性が失われることを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(nm) | 各セルの遷移は 1 回計算され、度数が 1 回チェックされます。 
| スペース | O(nm) | 度数配列とグリッド表現を格納します。 

すべてのテスト ケースにわたるセルの合計数は最大で$10^6$したがって、テスト ケースごとに 1 つの線形パスは時間制限内に問題なく収まります。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    return sys.stdout.getvalue() if False else exec_solution(inp)

def exec_solution(inp: str) -> str:
    import sys
    input = sys.stdin.readline
    data = inp.strip().split()
    it = iter(data)
    T = int(next(it))
    out = []

    for _ in range(T):
        n = int(next(it)); m = int(next(it))
        dirs = []
        for _ in range(n):
            dirs.append(list(next(it)))
        a = [[int(next(it)) for _ in range(m)] for _ in range(n)]

        N = n * m
        indeg = [0] * N

        def id(i,j): return i*m+j

        ok = True
        for i in range(n):
            for j in range(m):
                step = a[i][j]
                d = dirs[i][j]
                ni, nj = i, j
                if d == 'u':
                    ni -= step
                elif d == 'd':
                    ni += step
                elif d == 'l':
                    nj -= step
                else:
                    nj += step
                if ni < 0 or ni >= n or nj < 0 or nj >= m:
                    ok = False
                else:
                    indeg[id(ni,nj)] += 1

        if ok and all(x == 1 for x in indeg):
            out.append("Yes")
        else:
            out.append("No")

    return "\n".join(out)

 ## 特殊なケース

 サイズ 1×1 の最小グリッドは、単一の自己ループが自明に存在する唯一の状況であり、当然に次数条件が成立します。 

矢印がグリッドの外に飛び出す構成は、他のすべてのノードがクリーンなサイクルを形成している場合でも、すぐに失敗します。これは、すべてのノードを 1 回だけ訪問しながら完全な走査をグラフの外で終了できないためです。 

複数の小さなサイクルを持つケースは、一部のノードが最終的に次数 0 になり、それらがハミルトニアン走査に必要なグローバル構造の一部ではないことを示すため、拒否されます。
