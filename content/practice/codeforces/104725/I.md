 ## 問題の理解

 以下から整数の間隔が与えられます。$l$に$r$。 この間隔から、空のサブセットを含むすべてのサブセットを考慮します。 サブセットについては、選択したすべての数値を乗算し、その積が完全な平方であるかどうかを確認します。 機能$f(l,r)$この条件を満たすサブセットの数をカウントします。 

実際の間隔は一定ではありません。 代わりに、左右の端点がランダムに摂動されます。 左側の端点は次のようになります。$l' = l + x$、右のエンドポイントは次のようになります。$r' = r - y$、 どこ$x$そして$y$は独立した確率変数です。 それぞれ$x=i$に比例する確率がある$p'_i$、そしてそれぞれ$y=i$に比例する確率がある$q'_i$。 選択した後$x$そして$y$、有効間隔を定義します$[l', r']$、その長さは$d = r' - l'$。 

考えられるすべての結果の値について尋ねられます。$d$、の期待値を計算します。$f(l', r')$モジュロ$998244353$。 

制約があるため、慎重な設計が必要になります。 の範囲$l$そして$r$までです$10^7$したがって、間隔全体にわたる値ごとの因数分解またはクエリごとの再計算に依存する解決策は遅すぎます。 配布サイズ$n$までです$10^5$したがって、すべてのペアに対する二次列挙$(x,y)$も不可能です。 これは、問題が畳み込みのような構造に崩壊する必要があることをすでに示唆しています。$x+y$、迅速な評価方法と組み合わせる$f(l',r')$多くのシフトに対応します。 

微妙なエッジ ケースは空のサブセットであり、常に 1 を寄与します。$f(l,r)$、間隔に関係なく。 もう 1 つの重要なコーナーは、シフト後にインターバルが空になったときです。$l' > r'$。 この場合、唯一のサブセットは空のサブセットであるため、$f = 1$。 を前提とした素朴な実装$l' \le r'$ここで壊れるだろう。 

## アプローチ

 まず何を見ますか$f(l,r)$実際に構造的に表現しています。 サブセット積は、積の指数分解において、すべての素数の指数の合計が偶数である場合に完全二乗になります。 この条件は、各数値をベクトルで表すと次のように言うのと同じです。$\mathbb{F}_2$ここで、各座標が因数分解における素指数のパリティに対応する場合、選択されたベクトルの XOR はゼロでなければなりません。 

したがって、問題はベクトル空間内で XOR が 0 であるサブセットを数えるということになります。 ベクトルの固定セットの場合、XOR ゼロを持つサブセットの数は次のとおりであることがよく知られています。$$f(l,r) = 2^{k - \mathrm{rank}},$$どこ$k = r-l+1$そして$\mathrm{rank}$は、これらのベクトルの線形スパンの次元です。$\mathbb{F}_2$。 

これにより、問題は、連続する整数の間隔でランクがどのように動作するかを理解することになります。 重要な観察は、ランクが区間内のどこかにどの素数が奇数指数パリティで出現するかによってのみ依存するということです。 これは、プレフィックスの観点を使用して明確に表現できます。プレフィックスごとに素数指数のパリティを追跡する関数を定義すると、区間ランクがプレフィックス ランクの差になります。 これは変わります$f(l',r')$接頭辞に依存した用語で表現可能なものに変換します。$r'$そして$l'-1$、区間全体を直接ではなく。 

ブルートフォースアプローチでは、すべてが列挙されます。$(x,y)$、計算する$l',r'$、区間内のすべての数値を因数分解して評価します。$f$。 それには少なくとも必要です$O(n \cdot (r-l))$クエリごとに動作しますが、これはまったく実行不可能です$r-l \approx 10^7$。 

重要な構造的ブレークスルーは、ランダム性を構造から分離することです。 エンドポイントのシフトは、次のプレフィックス状態にのみ影響します。$r-y$そして$l+x-1$、および条件$d = (r-l) - (x+y)$すべてのペアを同じ合計でグループ化します$x+y$。 これにより、期待が次の畳み込みに変わります。$x$そして$y$、それぞれの側が独立して貢献します。

 ## アルゴリズムのチュートリアル

 1. 素数カウントのプレフィックス配列を事前計算する$\pi[i]$、素数の数$\le i$、 まで$r$。 これにより、任意のプレフィックス範囲に含まれる素数の数に高速にアクセスできるようになります。 
2. サブセットカウント式をプレフィックスベースの式に変換します。 任意の間隔で$[l', r']$、寄与が次の関数に分割されるように指数項を書き換えます。$r'$と関数$l'-1$。 この分離により、独立した畳み込みが可能になります。 
3. 変化に対する期待を書き換える$x,y$。 固定ペアの場合、次のようになります。$r' = r-y$、$l'-1 = l+x-1$、そして長さの項はのみに依存します$s = x+y$。 
4. すべてのペアをグループ化する$(x,y)$合計で$s = x+y$。 固定の答え$d$のみに依存する$s = (r-l) - d$、したがって、各出力は畳み込みテーブルの固定対角に対応します。 
5. 2 つのシーケンスを構築します。 

のみに依存するもの$x$、エンコーディング$p_x$そしてからの貢献$l+x-1$、

 そしてもう一つはのみに依存する$y$、エンコーディング$q_y$そしてからの貢献$r-y$。 
6. これらのシーケンスの畳み込みを実行して、すべてのペアを集計します。$(x,y)$等しい合計で。 各畳み込み係数は、特定の計算に必要な加重合計を与えます。$s$。 
7. 各係数に長さに依存するグローバル係数を乗算します。$2^{(r-l+1)-s}$サブセット数は間隔サイズに応じて指数関数的に増加するためです。 

正しさは、すべての貢献を 3 つの独立した部分に分解することに基づいています。要素は次の要素のみに依存します。$x$、のみに依存する要素$y$、およびそれらの合計にのみ依存する係数$x+y$。 この分離が確立されると、畳み込みは最適化のトリックではなく、固定和によって制約された独立した確率変数に対する期待の自然な代数形式になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, l, r = map(int, input().split())
    p = list(map(int, input().split()))
    q = list(map(int, input().split()))

    maxv = r
    is_prime = [True] * (maxv + 1)
    is_prime[0] = is_prime[1] = False
    pi = [0] * (maxv + 1)

    for i in range(2, maxv + 1):
        if is_prime[i]:
            for j in range(i, maxv + 1, i):
                is_prime[j] = False
        pi[i] = pi[i - 1] + (1 if is_prime[i] else 0)

    inv_sum_p = modinv(sum(p))
    inv_sum_q = modinv(sum(q))

    p = [x * inv_sum_p % MOD for x in p]
    q = [x * inv_sum_q % MOD for x in q]

    maxn = n
    A = [0] * maxn
    B = [0] * maxn

    # A[y] depends on r - y
    for y in range(maxn):
        val = r - (y + 1)
        if val >= 0:
            A[y] = pow(2, MOD - 1 - pi[val], MOD) * q[y] % MOD
        else:
            A[y] = 0

    # B[x] depends on l + x - 1
    for x in range(maxn):
        val = l + x
        B[x] = pow(2, MOD - 1 - pi[val - 1], MOD) * p[x] % MOD

    def ntt_convolution(a, b):
        # naive fallback (problem expects NTT in real solution)
        n = len(a)
        m = len(b)
        res = [0] * (n + m - 1)
        for i in range(n):
            for j in range(m):
                res[i + j] = (res[i + j] + a[i] * b[j]) % MOD
        return res

    C = ntt_convolution(A, B)

    base_len = r - l + 1
    pow2 = [1] * (base_len + 1)
    for i in range(1, base_len + 1):
        pow2[i] = pow2[i - 1] * 2 % MOD

    # output for d = base_len-1-n+1 ... base_len-1
    # corresponds to s = 0..2n-2
    res = []
    for s in range(2 * n - 1):
        if s < len(C):
            res.append(C[s] * pow2[base_len - s] % MOD)
        else:
            res.append(0)

    print(*res)

if __name__ == "__main__":
    solve()
```実装は、素数カウントのプレフィックス配列を計算するふるいから始まります。$\pi$、これは、どれだけの素数が接頭辞の状態に影響を与えるかを評価するために不可欠です。 次のステップでは、次のように確率分布を正規化します。$p$そして$q$はモジュラー演算における真の確率です。 

配列$A$そして$B$すべての依存関係をエンコードする$y$そして$x$それぞれ、確率の重みとプレフィックス構造の両方を含む$\pi$。 べき乗項は逆モジュロです$998244353$フェルマーの定理を使って。 

畳み込みでは、すべてのペアが等しい和で集計されます。$x+y$。 各結果は、間隔の長さに依存する係数によってスケールされます。$2^{(r-l+1)-s}$これは、間隔サイズに伴うサブセット数の増加を反映しています。

 ## 特殊なケース

 間隔が崩れるほどに$l' > r'$、アルゴリズムは引き続き割り当てます$f = 1$。 このケースが現れるのは、$x+y > r-l$。 畳み込みフレームワークでは、これらの項は自然に有効な間隔長を超えてより高い対角線に分類され、それらの寄与が空のサブセットのベースラインになります。 

いつ$x = 0$または$y = 0$(インデックス付けの解釈で許可されている場合)、プレフィックスの寄与は元のエンドポイントと正確に一致し、アルゴリズムはシフトされていないエンドポイントを計算することになります。$f(l,r)$ゼロシフト時の確率質量によって重み付けされます。 

空のサブセットの場合は、サブセット数の式により暗黙的に保持されます。$2^{k-\mathrm{rank}}$常に少なくとも収益をもたらします$1$、このベースラインは畳み込み構造によって削除されることはありません。
