 ## アルゴリズムのチュートリアル

 この問題を、単一のブロック上で定義された有向グラフ内の複数の樹木をカウントすることに帰着します。 

1. の隣接構造を構築します。$n$-ノードテンプレートグラフ。 最初は、注文されたすべてのペア$u \ne v$がエッジである場合は、$m$禁止された有向エッジ。 これは、単一ブロックの内部接続を表します。 1 つのブロックを分離する理由は、すべてのブロックが$K$ブロックは同じように動作するため、すべての組み合わせ構造はこのテンプレートから誘導されます。 
2. 有向スパニング ツリー カウンティング用のラプラシアン行列を構築します。 各ノードについて$i$、対角線の入口をその出次数に設定し、各エッジに対して$i \to j$、行列の位置で 1 を減算します。$(i, j)$。 この行列は、ノードをルートとするスパニング樹木が行列ツリー定理によってどのようにカウントされるかをエンコードします。 
3. ラプラシアン行列の余因子行列式を使用して、固定ノードをルートとする有向スパニング ツリーの数を計算します。 これにより、1 つのブロック内の内部構造を最終的なグローバル構造の接続コンポーネントとして機能できるように方向付けるための有効な方法が多数得られます。 
4. 1 つのブロックから$K$ブロック。 グローバル接続要件を除いて、すべてのブロックは同一で独立しているため、最終的な構造は、グローバルな到達可能性を固定する区別された「ルート ブロック」を選択するものとみなすことができます。 がある$K$このルート ブロックの選択と、各ブロック内の内部スパニング構造が有効である必要があります。 
5. 有効な内部構造の数にルート ブロックの選択肢の数を掛けます。 これにより、最終的なカウントのモジュロ 998244353 が得られます。 

### なぜ効果があるのか

 分解は、グラフが同一のテンプレートのデカルト反復であるという事実に基づいています。 グローバルに有効な任意のセット$nK-1$到達可能性を保証するエッジは、ブロックによって縮小される場合、広がる樹木構造に制限する必要があります。 すべてのブロックは同一であるため、グローバルな自由度はどのブロックが構造ルートとして機能するかだけです。 ルート ブロックが修正されると、すべての内部設定は独立し、同じスパニング ツリー数の同一のコピーになります。 この不変性により、ブロック間の非対称性がカウントに現れないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def det(mat):
    n = len(mat)
    res = 1
    for i in range(n):
        pivot = -1
        for j in range(i, n):
            if mat[j][i] != 0:
                pivot = j
                break
        if pivot == -1:
            return 0
        if pivot != i:
            mat[i], mat[pivot] = mat[pivot], mat[i]
            res = -res
        inv = pow(mat[i][i], MOD - 2, MOD)
        res = res * mat[i][i] % MOD
        for j in range(i, n):
            mat[i][j] = mat[i][j] * inv % MOD
        for j in range(i + 1, n):
            factor = mat[j][i]
            if factor:
                for k in range(i, n):
                    mat[j][k] = (mat[j][k] - factor * mat[i][k]) % MOD
    return (res % MOD + MOD) % MOD

def solve():
    n, m, K = map(int, input().split())
    
    bad = set()
    for _ in range(m):
        u, v = map(int, input().split())
        bad.add((u - 1, v - 1))

    # build Laplacian for directed graph
    L = [[0] * n for _ in range(n)]

    for i in range(n):
        outdeg = 0
        for j in range(n):
            if i != j and (i, j) not in bad:
                outdeg += 1
        L[i][i] = outdeg

    for i in range(n):
        for j in range(n):
            if i != j and (i, j) not in bad:
                L[i][j] = (L[i][j] - 1) % MOD

    # remove last row/col for cofactor
    M = [row[:-1] for row in L[:-1]]
    ways = det(M)

    # K identical blocks, choose root block
    print(ways * (K % MOD) % MOD)

if __name__ == "__main__":
    solve()

最終的な乗算$K$すべてのブロックは対称コピーであるため、どのブロックがグローバル構造ルートとして機能するかの選択を反映します。 行列式ルーチンはモジュラー ガウス消去法を実行し、行の交換とモジュラー逆行列を注意深く追跡します。
