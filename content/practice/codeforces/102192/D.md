## アプローチ

 直接的な総当たりアプローチは、可能なすべての割り当てを検討することです。`(`そして`)`に`h × w`細胞。 まさにあります`2^(hw)`そのような課題。 割り当てごとに、すべての行と列をスキャンして、括弧の実行残高がマイナスになってゼロで終了するかどうかを確認できます。 これにはかかります`O(hw)`1 つの行列にかかる時間、合計複雑さは次のようになります。`O(hw · 2^(hw))`。 

ブルート フォースは、考えられるすべての行列を検査するため、列挙された行列の 1 つが最大の良好性を持っている必要があるため、正しいです。 問題は行列の数です。 最大サイズでは、`h = w = 200`、与える`40,000`細胞と`2^40000`可能な行列。 これだけの候補者を書き出すことすら不可能であり、ましてや候補者を一つ一つ確認することは不可能である。 

問題の構造から、より強力な観察が得られます。 バランスの取れたシーケンスは長さが均一である必要があるため、次元のパリティによってどの方向に寄与できるかがすぐに分かります。 両方の次元が均等であれば、市松模様のパターンを使用して、すべての行とすべての列のバランスをとることができます。 幅だけが偶数であれば、すべての行のバランスがとれますが、列の高さは奇数であるため、必然的に不可能です。 高さだけが均一であれば、柱は対称施工となります。 両方の次元が奇数の場合、どちらの方向も寄与できないため、どの行列も最適になります。

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        h, w = map(int, input().split())

        if h % 2 == 0 and w % 2 == 0:
            # Checkerboard: every row and every column is balanced.
            for i in range(h):
                row = ''.join(
                    '(' if (i + j) % 2 == 0 else ')'
                    for j in range(w)
                )
                print(row)

        elif w % 2 == 0:
            # h is odd, so columns cannot be balanced.
            # Make every row balanced.
            row = '()' * (w // 2)
            for _ in range(h):
                print(row)

        elif h % 2 == 0:
            # w is odd, so rows cannot be balanced.
            # Make every column balanced.
            open_row = '(' * w
            close_row = ')' * w

            for i in range(h):
                print(open_row if i % 2 == 0 else close_row)

        else:
            # Both dimensions are odd, so no row or column can be balanced.
            for _ in range(h):
                print('(' * w)

if __name__ == "__main__":
    solve()

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:

        return sys.stdout.getvalue()

def goodness(output: str, h: int, w: int) -> int:
    lines = output.strip().splitlines()

    assert len(lines) == h
    assert all(len(row) == w for row in lines)
    assert all(c in '()' for row in lines for c in row)

    def balanced(seq):
        balance = 0
        for c in seq:
            balance += 1 if c == '(' else -1
            if balance < 0:
                return False
        return balance == 0

    ans = 0

    for row in lines:
        ans += balanced(row)

    for j in range(w):
        col = ''.join(lines[i][j] for i in range(h))
        ans += balanced(col)

    return ans

def expected_goodness(h: int, w: int) -> int:
    return (h if w % 2 == 0 else 0) + (w if h % 2 == 0 else 0)
