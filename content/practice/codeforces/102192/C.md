 ## 解決策
 ## 問題の理解

 私たちは持っています`n`都市は順番に配置され、それらの都市は同時に入れ子になった行政グループに分割されます。 レベルのグループ`i`正確に含まれています`n_i`連続した都市であり、すべての細かいグループは 1 つの粗いグループの中に完全に収まります。 最終レベルは、`n_k = 1`したがって、個々の都市自体がレベルです-`k`グループ。 

2 つの都市の場合、相互作用係数は両方の都市を含む最上級の行政レベルにのみ依存します。 それらが異なるトップレベルグループに属している場合、それらの係数は次のようになります。`rho_0`。 それらがより細かいレベルで最初に分離されると、対応する`rho_i`が使用されます。 都市は、次のものを使用してそれ自体と対話します。`rho_k`。 

1 年は、都市の価値の現在のベクトルの線形変換です。 それを変革と呼ぶなら`A`、タスクは計算することです`A^T d_0`モジュロ`998244353`、 どこ`T`と同じ大きさにすることができます`10^18`。 

直接解釈すると、`n x n`しかし、そのような行列を保存したり乗算したりすることは直ちに不可能です。 マトリックスの 1 つの適用でも、`Theta(n^2)`操作。 と`n = 3 * 10^5`、それは約です`9 * 10^10`1年間のペアのやり取りは、4秒の制限をはるかに超えています。 指数`T`また、年ごとにシミュレーションすることも除外されます。 

階層自体が有用な構造です。 すべてのグループ サイズが前のグループ サイズを分割するため、サイズが厳密に減少しても、最大でも前のサイズの半分になります。 したがって、`k`と同じ大きさにすることができます`n`連続する同じサイズが許可されるため、最大でも`O(log n)`異なるグループサイズ。 

不注意な実装を黙って破壊してしまう可能性のあるエッジケースがいくつかあります。 1つ目は`n = 1`。 例えば、```
1
1 1 3
1
7
2 5
```唯一の都市は、以下を使用してそれ自体と対話します。`rho_1 = 5`、したがって、答えは次のとおりです`7 * 5^3 = 875`。 治療中`rho_0`対角係数が間違った結果を与えるためです。 

もう 1 つの特殊なケースは、管理サイズが繰り返されることです。 例えば、```
1
4 3 1
4 2 1
3 3 3 3
1 2 4 7
```すべての都市は他の 3 つの都市と完全な交流を持っています`1 + 4 + 1 + 7`レベルに従って配置され、行の合計は次のようになります。`13`。 すべての初期値は`3`、正しい出力は次のとおりです。```
39 39 39 39
```すべてのレベルで新しいパーティションが導入されると想定したソリューションでは、ゼロ次元の固有空間が作成され、繰り返されるサイズが誤って処理される可能性があります。 

3 番目の境界ケースは、最大の行政グループにすでにすべての都市が含まれている場合に発生します。 例えば、```
1
4 3 2
4 2 1
1 2 3 4
1 1 1 2
```ここでの行列は単純に`J + I`、 どこ`J`はオールワン行列です。 二乗すると得られる`6J + I`、したがって、答えは次のとおりです```
61 62 63 64
```最上位グループの外側に常に空ではないスペースがあると想定するソリューションでは、このケースは誤って破棄されてしまいます。 

## アプローチ

 ブルートフォース手法では、相互作用行列を明示的に構築します。 都市の各ペアについて、最低の共通行政レベルを決定し、対応する係数をマトリックスに配置します。 1年申請すると費用がかかります`O(n^2)`、そしてこれを行うのは`T`年数のコスト`O(Tn^2)`。 行列のべき乗を試みたとしても、密な`n x n`行列を使用すると、乗算のコストが高くなりすぎます。 で`n = 3 * 10^5`、行列だけでも大まかに次の内容が含まれます。`9 * 10^10`エントリ。 

有益な観察は、行列が任意ではないということです。 定義する`B_i`エントリが次のような行列として`1`まさに、2 つの都市が同じレベルに属するとき、`i`グループ。 係数が変化するので、`rho_{i-1}`に`rho_i`レベルに移動するとき`i`、相互作用行列は次のように書くことができます。 

[
 A = \rho_0 J + \sum_{i=1}^{k}(\rho_i-\rho_{i-1})B_i。 
】

 この表現は強力です。`B_i`はネストされたブロック行列です。 より正確に言えば、`P_m`連続するすべてのブロック内のベクトルを平均することを意味します。`m`都市、その後

 [
 B_i = n_i P_{n_i}。 
】

 これらの平均演算子はすべて、入れ子になった部分空間への射影であるため、相互に変換され、同時に独立した階層コンポーネントに分解できます。 

個別のブロック サイズの場合`m`、そのサイズを持つすべての項を 1 つの係数に集めます

 [
 \gamma_m = \sum_{i=m}(\rho_i-\rho_{i-1})m。 
】

 すると行列は次のようになります

 [
 A = \rho_0 J + \sum_m \gamma_m P_m。 
】

 個別のサイズが次のとおりであるとします。 

[
 m_1 > m_2 > \dots > m_r=1。 
]

させて`P_0`全体にわたるグローバル平均演算子になる`n`都市。 違い

 [
 P_{m_q}-P_{m_{q-1}}
 】

 内部で不変の情報を正確に抽出します。`m_q`ブロックですが、その親ブロック内の平均はゼロです。 このような各部分空間は次の固有空間です。`A`。 

サイズで導入されたコンポーネントに属する固有値`m_q`接尾語の合計です

 [
 \lambda_q=\sum_{j=q}^{r}\gamma_{m_j}。 
】

 グローバル定数コンポーネントには固有値があります

 [
 \lambda_0=n\rho_0+\sum_{j=1}^{r}\gamma_{m_j}。 
】

 最上位グループ間の差分で構成される残りの成分は、固有値 0 を持ちます。 以来`T >= 1`、行列を まで引き上げると、そのコンポーネントは消えます。`T`-乗。 

ブルート フォースが機能するのは、正確な相互作用行列が適用されるためです。 すべての都市のペアを独立して処理するため、失敗します。 行列が入れ子になった平均演算子の合計であるという観察により、ペアごとの相互作用を少数の階層射影に置き換えることができます。 個別のサイズは変化するたびに半分になるため、`O(log n)`そのような予測。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |`O(T n^2)`|`O(n^2)`| 遅すぎる |
 | 最適 |`O(n + n log n)`|`O(n)`| 承認済み |

 以下の実装は、すべてのレベルのすべての都市を明示的に訪問するよりもさらに効率的です。 各投影は、そのブロックに範囲を追加することによって適用されます。 すべての異なるサイズにわたるブロックの合計数は次のとおりです。`O(n)`サイズが少なくとも 2 分の 1 に減少するためです。 

## アルゴリズムのチュートリアル

 1. 管理サイズと相互作用係数を読み取り、連続する等しいサイズを単一の個別のサイズに置き換えます。 あらゆるサイズに対応`m`、蓄積する

 [
 \gamma_m \mathrel{+}=m(\rho_i-\rho_{i-1})。 
】

 等しいレベルでは同じ平均化演算子が生成されるため、それらの行列の寄与を安全に組み合わせることができます。 
2. サフィックスの固有値を計算します。 個別のサイズを最小から最大まで処理すると、次のようになります。 

[
 \lambda_q=\gamma_{m_q}+\lambda_{q+1}。 
】

 これはまさに、`m_q`- ブロックの平均とその親ブロックの平均。より細かい射影はすべて、そのコンポーネントのブロック サイズによる乗算として機能するためです。 
3. グローバル固有値を計算する

 [
 \lambda_0=n\rho_0+\sum_q\gamma_{m_q}。 
】

 相互作用行列の各行の合計が同じであるため、全定数ベクトルは固有ベクトルです。 
4. 関連するすべての固有値を次のように計算します。`T`モジュロ`998244353`。 以来`T`到達できる`10^18`、2進のべき乗が必要です。 
5. 累乗演算子を平均化射影の線形結合として表現します。 から始める`lambda_0^T`世界平均で言えば。 あらゆるサイズに対応`m < n`、対応する固有空間が寄与します

 [
 \lambda_m^T(P_m-P_{\text{親}})。 
】

 に正の係数を追加すると、`P_m`そしてそれを親投影から減算すると、すべての投影の最終係数が生成されます。 
6. 都市の初期値のプレフィックス合計を作成します。 これにより、管理ブロックの合計を一定時間で取得できるため、そのサイズのモジュール逆数を乗算した後の一定時間での平均が得られます。 
7. 差分配列を使用して各射影係数を適用します。 ブロックごとに`[l,r)`、その平均を計算し、2 つの差分配列の更新を通じて対応する値を区間全体に追加します。 あるのは`n/m`サイズのブロック`m`。 
8. 差分配列を 1 回前置合計して、すべての都市の最終値を回復します。 

正確性の不変条件は、階層コンポーネントのコレクションを処理した後、都市に割り当てられた累積値が、初期ベクトルの固有空間分解におけるそれらのコンポーネントの寄与と正確であることです。 オペレーター`P_m`はネストされた射影であるため、すべてのベクトルはグローバル定数コンポーネント、ネストされたブロック平均間の連続する差分、および残りの最上位の差分コンポーネントに一意に分解されます。 後者は固有値がゼロで、少なくとも 1 年後には消滅します。 他のすべての成分には、次のように計算された正確な固有値が乗算されます。`T`したがって、結果のベクトルは正確に次のようになります。`A^T d_0`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve_case(n, k, T, sizes, d, rho):
    # Compress equal administrative sizes.
    groups = []
    gamma = []

    for i in range(k):
        m = sizes[i]
        add = (rho[i + 1] - rho[i]) * m % MOD

        if groups and groups[-1] == m:
            gamma[-1] = (gamma[-1] + add) % MOD
        else:
            groups.append(m)
            gamma.append(add)

    r = len(groups)

    # Suffix eigenvalues for the hierarchical difference spaces.
    eig = [0] * r
    cur = 0
    for i in range(r - 1, -1, -1):
        cur += gamma[i]
        cur %= MOD
        eig[i] = cur

    # Eigenvalue of the global constant subspace.
    global_eig = (rho[0] * n + cur) % MOD
    global_pow = pow(global_eig, T, MOD)

    # Coefficients of the projection operators.
    #
    # The decomposition is
    # A^T = global_pow * P_global
    #       + sum eig[i]^T * (P_i - P_parent).
    #
    # If groups[i] == n, P_i == P_global, so that component is zero.
    coeff = [0] * r
    coeff_global = global_pow

    previous = -1

    for i in range(r):
        m = groups[i]
        if m == n:
            continue

        ep = pow(eig[i], T, MOD)

        coeff[i] = (coeff[i] + ep) % MOD

        if previous == -1:
            coeff_global = (coeff_global - ep) % MOD
        else:
            coeff[previous] = (coeff[previous] - ep) % MOD

        previous = i

    # Prefix sums of the initial vector.
    pref = [0] * (n + 1)
    s = 0
    for i, x in enumerate(d):
        s += x
        pref[i + 1] = s % MOD

    # Difference array for range additions.
    diff = [0] * (n + 1)

    # Global average contribution.
    if coeff_global:
        avg = pref[n] * pow(n, MOD - 2, MOD) % MOD
        value = coeff_global * avg % MOD
        diff[0] += value
        diff[n] -= value

    # Contributions of every nontrivial administrative size.
    for i in range(r):
        c = coeff[i]
        m = groups[i]

        if c == 0 or m == n:
            continue

        inv_m = pow(m, MOD - 2, MOD)
        factor = c * inv_m % MOD

        for l in range(0, n, m):
            rr = l + m
            block_sum = (pref[rr] - pref[l]) % MOD
            value = block_sum * factor % MOD

            diff[l] += value
            diff[rr] -= value

    # Recover point values from the range additions.
    ans = [0] * n
    cur = 0
    for i in range(n):
        cur += diff[i]
        ans[i] = cur % MOD

    return ans

def main():
    t = int(input())
    out = []

    for _ in range(t):
        n, k, T = map(int, input().split())
        sizes = list(map(int, input().split()))
        d = list(map(int, input().split()))
        rho = list(map(int, input().split()))

        ans = solve_case(n, k, T, sizes, d, rho)
        out.append(" ".join(map(str, ans)))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```最初の部分は同じサイズを圧縮します。 要因`m`で`gamma`から来ています`B_i = mP_m`、ブロック全体の平均をとると、その合計が次のように除算されるためです。`m`, 元のブロック行列は合計を返します。 

サフィックス ループは、すべての階層差分空間の固有値を計算します。 ベクトルがすべての親ブロックでゼロ平均を持ち、現在のブロック内で一定である場合、すべての粗い平均化演算子はそのベクトルを消滅させますが、より細かいブロック演算子はすべてそのベクトルをブロック サイズで乗算します。 これにより、サフィックスの合計が正確に得られます。`gamma`価値観。 

特別な場合`m == n`は、対応する差分空間をスキップすることによって処理されます。 グループにすべての都市が含まれるレベルには、グローバル投影と同じ平均演算子があるため、新しいコンポーネントであるかのように累乗固有値を減算すると、偽の 0 次元コンポーネントが導入されます。 

プレフィックス配列はモジュロで保存されます`MOD`。 すべてのブロック サイズは最大でも`3 * 10^5`、厳密には以下よりも小さいです`998244353`したがって、必要なすべての逆モジュラーが存在します。 

差分配列は実装の最適化の鍵となります。 1 つのブロックの平均をすべてに加算する代わりに`m`都市では、2 つの境界更新が範囲全体を表します。 ブロックサイズのあるレベル全体`m`、あるだけです`n/m`そういったアップデート。 

Python の整数はオーバーフローしませんが、モジュラー リダクションが定期的に実行されるため、中間値は小さいままになります。 べき乗呼び出しでは Python の 3 つの引数を使用します`pow`、対数時間でべき乗剰余演算を実行します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 |`O(n + S)`どこ`S = sum(n/m)`異なるサイズを超える | プレフィックスの構築、ブロックの処理、および最終的な再構成は、ブロックと都市の総数に比例します。 
| スペース |`O(n + r)`| 初期値、プレフィックスの合計、差分配列、および最大`O(log n)`異なるサイズ |

 2 つの連続する別個の管理サイズの場合、小さい方が大きいを分割し、厳密に小さいため、最大でも大きい方の半分になります。 その結果、

 [
 \frac{n}{m_1}+\frac{n}{m_2}+\cdots < 1+2+4+\cdots < 2n。 
】

 したがって、処理される管理ブロックの総数は次のようになります。`O(n)`、 ない`O(n log n)`。 したがって、実装の実際的な複雑さは次のとおりです。`O(n + k + log T)`テストケースごとに、`k`入力の読み取りと圧縮に由来する用語。 すべてのテスト ケースの合計は、`n`せいぜい`10^6`、したがって、ソリューションは意図された制限内に留まります。

            out.append(" ".join(map(str, ans)))

        return "\n".join(out)
    finally:
        sys.stdin = old_stdin
