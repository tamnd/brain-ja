 ## 解決策
 ## 問題の理解

 複数の独立したクエリが与えられます。 各クエリは 2 つの整数を与えます。ここで、エントリが厳密に正で合計が固定される固定長の配列を構築する必要があります。 このようなすべての配列の中で、辺の順序が重要となる、まさにその数の辺を持つ非縮退多角形の辺の長さを表現できるものだけを保持します。 

したがって、テストケースごとに、整数の順序付けされた構成を効果的にカウントしています。$m$の中へ$n$追加の幾何学的制約を伴う正の部分: シーケンスは閉じた形状を形成できなければなりません。$n$-側面多角形。 

幾何学的条件は重要な重要な部分です。 正の長さのシーケンスは、残りのすべての辺の合計と少なくとも同じ大きさの辺がない場合に限り、多角形を形成できます。 これは標準的な一般化された三角不等式です。 一方の側が大きすぎると、他の側で「閉じる」ことができなくなります。 

合計が次の場合、条件を代数形式で書き直すと、$m$の場合、有効な配列はすべて次の条件を満たす必要があります。$$\max(a_i) < m - \max(a_i)$$これは以下と同等です$$\max(a_i) < \frac{m}{2}$$したがって、問題は長さの正の整数配列をカウントすることになります。$n$、合計$m$、すべてのエントリは厳密に次の値より小さい$m/2$。 

制約により最大で許可されるのは、$10^5$テストケースと最大値$10^6$したがって、テストごとの組み合わせ列挙は不可能です。 ソリューションは、一定時間または対数時間で各クエリを事前計算するか、回答する必要があります。 

微妙なエッジケースが現れるのは、$m$に比べて小さい$n$。 例えば、$n = 3, m = 3$有効な配列は 1 つだけありますが、$n = 3, m = 4$には、有効な配列がゼロです。これは、構成が存在しても、一方の辺が他方の辺に比べて必然的に大きすぎるため、三角形を形成できるものがないためです。 もう一つのケースは次のような場合です。$m < 2n$、ポリゴン制約が非常に制限的になり、多くの場合、すべてのソリューションが削除されます。 

## アプローチ

 最も直接的な解釈から始めます。長さの配列をすべて列挙します。$n$正の整数の合計は$m$を選択し、それぞれがポリゴンの条件を満たすかどうかを確認します。 これは、次のすべての構成を生成することと同等です。$m$の中へ$n$部品、つまり$\binom{m-1}{n-1}$可能性。 のために$m$まで$10^6$、この数は天文学的に大きいため、列挙することは直ちに不可能です。 

代わりに、標準の組み合わせ変換を使用します。 を定義して変数をシフトしましょう$b_i = a_i - 1$。 それからそれぞれ$b_i \ge 0$そして$$\sum b_i = m - n$$したがって、制約がなければ、配列の数は次のようになります。$$\binom{m-1}{n-1}$$次に、ポリゴン コンストレイントを組み込みます。 条件は、どの要素も合計の半分以上にならないことです。 この条件に違反するものを差し引いて、有効な解決策をカウントします。 

最大要素を次のように修正します$x$。 要素が 1 つある場合、$x$、残りの合計は$m - x$、違反の場合は次のことを要求します$x \ge m - x$、つまり$x \ge \lceil m/2 \rceil$。 

したがって、識別された要素が大きすぎる構成をカウントします。 固定位置の場合、残りの$n-1$要素の合計は$m-x$、与える:$$\binom{m-x-1}{n-2}$$すべての合計が無効です$x$、乗算$n$位置の選択により、完全に無効な構成が得られます。 

したがって、答えは次のようになります。$$\binom{m-1}{n-1} - n \cdot \sum_{x=\lceil m/2 \rceil}^{m-1} \binom{m-x-1}{n-2}$$以下を代入することで、標準的な組み合わせ恒等式を使用して合計を簡略化します。$y = m-x$、それを二項係数の前置和に変換し、これは 2 つの組み合わせの閉じた形式の差に分解されます。$$\sum_{y=1}^{\lfloor (m-1)/2 \rfloor} \binom{y-1}{n-2}
= \binom{\lfloor (m-1)/2 \rfloor}{n-1}$$これにより、最終的な閉じた式が得られます。$$\binom{m-1}{n-1} - n \cdot \binom{\lfloor (m-1)/2 \rfloor}{n-1}$$残りのタスクは二項係数のモジュロを計算することです$10^9+7$階乗事前計算とモジュラー逆関数を使用して、多くのクエリを効率的に実行します。

 ## アルゴリズムのチュートリアル

 ### 1. 階乗と逆階乗を最大まで事前計算します。$m$二項係数を高速に計算する必要があります。 階乗配列とモジュラー逆行列を最大で構築します。$10^6$。 これにより、あらゆることが保証されます$\binom{n}{k}$一定時間内に答えることができます。 

### 2. テスト ケースごとに、構成の総数を計算します。 

配列は正の整数の組み合わせとして解釈されるため、ベースライン数は次のようになります。$$\binom{m-1}{n-1}$$これにより、幾何学的制限なしですべてのシーケンスがカウントされます。 

### 3. 禁止範囲の中点を計算します。 

有効な多角形では、すべての辺が周囲の半分よりも厳密に小さい必要があります。 したがって、しきい値は次のようになります。$$t = \left\lfloor \frac{m-1}{2} \right\rfloor$$これにより、辺が大きすぎるすべてのケースを確実に捕捉できます。 

### 4. 無効な構成を差し引く

 無効なケースは、「大きすぎる」側を選択し、残りの合計を他の側に分配することに相当します。 対称性により、これは次のようになります。$$n \cdot \binom{t}{n-1}$$この減算により、少なくとも 1 つの辺がポリゴン条件に違反しているすべての配列が削除されます。 

### 5. 結果のモジュロを出力します。$10^9+7$### なぜ効果があるのか

 すべての無効な構成には、ポリゴンの不等式に違反する支配的な側面が 1 つだけあります。これは、2 つの側面が両方とも周囲の少なくとも半分である場合、合計が合計を超えるためです。 これにより、減算ステップでのオーバーカウントが防止されます。 各無効な配列を大きな要素の一意の選択にマッピングし、残りを独立して分配することにより、減算式で無効な配列とカウントされた項の間の全単射が得られます。 これにより正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAXN = 10**6 + 5

fact = [1] * MAXN
invfact = [1] * MAXN

for i in range(1, MAXN):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAXN - 1] = pow(fact[MAXN - 1], MOD - 2, MOD)
for i in range(MAXN - 2, -1, -1):
    invfact[i] = invfact[i + 1] * (i + 1) % MOD

def ncr(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    if n > m:
        print(0)
        continue

    total = ncr(m - 1, n - 1)
    half = (m - 1) // 2
    bad = (n * ncr(half, n - 1)) % MOD

    ans = (total - bad) % MOD
    print(ans)
```階乗事前計算により、すべての二項クエリが定数時間になることが保証されます。 主要な実装の詳細は、次の使用です。$(m-1)//2$、ポリゴン クロージャの厳密な不等式要件を正しくエンコードします。 

減算ステップはモジュロで実行する必要があります$10^9+7$, そのため、負の出力を避けるために最後に結果を正規化します。

## テストケース```python
import sys, io

MOD = 10**9 + 7
MAXN = 10**6 + 5

fact = [1] * MAXN
invfact = [1] * MAXN
for i in range(1, MAXN):
    fact[i] = fact[i-1] * i % MOD
invfact[MAXN-1] = pow(fact[MAXN-1], MOD-2, MOD)
for i in range(MAXN-2, -1, -1):
    invfact[i] = invfact[i+1] * (i+1) % MOD

def ncr(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n-r] % MOD

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    it = iter(sys.stdin.read().strip().split())
    t = int(next(it))
    out = []
    for _ in range(t):
        n = int(next(it)); m = int(next(it))
        if n > m:
            out.append("0")
            continue
        total = ncr(m-1, n-1)
        half = (m-1)//2
        bad = n * ncr(half, n-1) % MOD
        out.append(str((total - bad) % MOD))
    return "\n".join(out)

 ## 特殊なケース

 のために$m = n$、すべての要素は 1 である必要があるため、可能な配列はすべて 1 だけです。 どの辺も周囲の半分を超えることができないため、多角形の条件は自明に当てはまります。 この式は正しく減少します。$\binom{n-1}{n-1} = 1$残額不足により無効期間は消滅します。 

いつ$m < 2n$、しきい値$\lfloor (m-1)/2 \rfloor$よりも小さくなる$n-1$、2 番目の二項係数をゼロにします。 これは、どの構成もポリゴンの不平等に違反せずに十分な大きさの分布に対応できないため、すべてのカウントは基本構成式のみから得られるという直観と一致します。 

いつ$n = 3$とすると、問題は周囲が固定された三角形を数えることに帰着し、式は最大辺が厳密に周囲の半分より小さいという古典的な三角形の数え方の結果と一致します。
