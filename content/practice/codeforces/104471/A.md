 ## 問題の理解

 いくつかの独立したテスト ケースが与えられています。 各テスト ケースにはペアのコレクションがあります。 各ペアは正の重みで構成されます$a_i$そしてサイン$b_i$それはどちらかです$+1$または$-1$。 

1 つの要素からすべての要素まで、任意のサイズのインデックスのサブセットを選択できます。 サブセットを選択すると$S$、そのスコアはすべての合計を計算することによって計算されます。$a_i$サブセット内ですべての合計を乗算します$b_i$サブセット内で。 課題は、この製品を最大化するサブセットを選択することです。 

主な問題点は、サブセットのサイズが固定されていないことです。 すべての要素は両方の合計に寄与するため、要素を追加すると両方の要素が同時に変更されます。 要素$b_i = -1$2 番目の合計は減少しますが、それでも最初の合計は増加するため、分離できないトレードオフが生じます。 

制約は大きく、すべてのテスト ケースにわたる要素の合計数は最大です。$2 \cdot 10^5$、最大で$10^5$テストケース。 これにより、すべてのサブセットまたはテスト ケースごとの二次メソッドさえも試行するソリューションは即座に除外されます。 有効なソリューションは、テスト ケースごとに、または全体的に線形に近いものでなければなりません。 

いくつかの危険な状況には、早めに気づく価値があります。 

要素を 1 つだけ選択すると$i$、スコアは次のようになります$a_i \cdot b_i$、どちらかです$a_i$または$-a_i$。 これは、単一の大きなポジティブな要素を意味します。$b_i = 1$場合によっては、すでに最適化されている可能性があります。 

もしすべてなら$b_i = -1$より多くの要素を選択すると、2 番目の合計がより負になるため、最良の答えは、絶対的な負の効果が最も小さい単一の要素から得られることがよくありますが、それでも大きな要素との交互作用を考慮する必要があります。$a_i$。 

もしすべてなら$b_i = 1$、その場合、問題は最大化になります$(\sum a_i)^2$, したがって、答えは単純にすべてを取ることです。 

主な課題は、両方の符号が存在する場合に現れます。負の要素を追加すると、最初の合計は増加しますが、2 番目の合計は減少し、積が非線形に動作するためです。 

## アプローチ

 ブルートフォース手法では、すべてのサブセットが列挙されます。 各サブセットについて、次の合計を計算します。$a_i$と合計$b_i$、それらを乗算します。 がある$2^n$サブセットと各評価コスト$O(n)$素朴に行われた場合、または$O(1)$プレフィックスブックキーピングを使用しますが、最良のバージョンであっても指数関数的です。$n$。 と$n$まで$2 \cdot 10^5$、これは不可能です。 

もう少し素朴な考えとしては、要素を並べ替えて貪欲な選択戦略を試すという方法がありますが、合計間の相互作用により、単純な順序付けの引数が明らかに正しいとは言えません。 難しいのは、要素が独立して良いか悪いかではなく、その値がすでに選択されているものに依存することです。 

重要な点は、式を書き直すことです。 選択したサブセットについて$S$、$$\left(\sum a_i\right)\left(\sum b_i\right)$$各要素が 1 つの部分で線形に寄与し、ペアごとの相互作用が暗黙的に現れる形式に拡張されます。 サブセットについて直接推論するのではなく、セットを段階的に構築するときに値がどのように変化するかを理解しようとします。 

現在のサブセットを合計で維持すると仮定します。$A = \sum a_i$そして$B = \sum b_i$。 新しい要素を追加すると$x$の場合、新しい値は次のようになります。$$(A + a_x)(B + b_x) = AB + A b_x + B a_x + a_x b_x$$したがって、ゲインは次のようになります。$$\Delta = A b_x + B a_x + a_x b_x$$これは、決定が完全なサブセット構造ではなく、現在の集計値のみに依存することを示しています。 これは、慎重に選択した順序で要素を処理すれば、最適な状態を効率的に維持できる可能性があることを示唆しています。

重要な単純化は、固定サブセット サイズについて次のことを観察することです。$k$、最良のサブセットは、$k$の最大値$a_i$選ばれたパターンの記号を持つすべての要素の中で。 問題は、その数を決定することになります。$+1$そして何個$-1$取るべき要素。 

させて$P$のリストになる$a_i$と$b_i = 1$、 そして$N$のリストになる$a_i$と$b_i = -1$。 選択するとします$x$からの要素$P$そして$y$からの要素$N$。 それから：$$A = \sum P_x + \sum N_y,\quad B = x - y$$固定用$x, y$、最良の選択は明らかに最大のものを選択することです$x$ポジティブかつ最大$y$否定的。

## なぜ機能するのか

 固定カウントの場合$x$そして$y$、選択した要素を同じ符号のより大きな利用可能な要素に置き換えても、合計を減らすことはできません。$A$を保ちながら$B$変わらない。 これは、固定カーディナリティの最適なサブセットが常にソート後のプレフィックスの取得に対応することを意味します。 すべての実行可能なサブセットは何らかのペアに対応するため、$(x, y)$、そのようなペアをすべて網羅すると、最適解はこの列挙に現れるはずです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        pos = []
        neg = []

        for i in range(n):
            if b[i] == 1:
                pos.append(a[i])
            else:
                neg.append(a[i])

        pos.sort(reverse=True)
        neg.sort(reverse=True)

        ps = [0]
        ns = [0]

        for x in pos:
            ps.append(ps[-1] + x)
        for x in neg:
            ns.append(ns[-1] + x)

        best = -10**30

        for x in range(len(pos) + 1):
            A_pos = ps[x]
            for y in range(len(neg) + 1):
                A = A_pos + ns[y]
                B = x - y
                best = max(best, A * B)

        out.append(str(best))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```このソリューションでは、まず値を符号によって分割し、次の構造が得られます。$B$は単に選択されたカウントの差になります。 各グループをソートすると、スワップにより改善されるため、固定サイズ内の最適な選択は必ず最大の値を取る必要があります。$A$影響を与えずに$B$。 

プレフィックス合計を使用すると、サブセット合計を一定時間で計算できます。 ネストされたループは、選択された正の要素と負の要素の数のすべての組み合わせを調査します。最適なサブセットは常にそのようなペアに対応するため、これで十分です。 

微妙な点は、各グループに空の選択肢を含めていることです。 これにより、ポジティブのみ、またはネガティブのみを選択できます。これは、最適なサブセットが一方の側を完全に無視する可能性があるため必要です。

 ## 特殊なケース

 エッジケースの 1 つは、すべてが$b_i = 1$。 その状況では、アルゴリズムはすべてを考慮します。$x$と$y = 0$, したがって、効率的に計算されます$x \cdot (\sum \text{top } x)$。 最大値は次の時点で発生します。$x = n$、すべての要素を取得することに一致します。
