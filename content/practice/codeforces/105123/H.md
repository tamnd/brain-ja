 ## 解決策
 ## 問題の理解

 無限の整数グリッド上で生きているすべての細菌の現在のスナップショットが与えられます。 元々は未知の格子点に単一の細菌が存在し、未知の数分後に細菌がマンハッタンに隣接する場所に広がったと言われています。 細菌は毎分、隣接する 4 つの細菌の一部を感染対象として選択することも、感染対象として選択しないこともでき、細菌が拡散した後に消滅することもあります。 重要なのは、現在生きているすべてのセルが起点から正確に到達可能でなければならないということだけです。$t$マンハッタンの移動のステップ数に相当します。これは、プロセス中に 1 分あたりマンハッタンの距離の 1 単位よりも速く情報を伝達できるものがないためです。 

タスクは、時間から構成される有効なトリプルを再構築することです。$t$、開始位置$(x_0, y_0)$、そのようなすべての有効なトリプルの中で、辞書編集的に最小のものを選択します。つまり、最小化します。$t$、そして関係間で最小化します$x_0$、 その後$y_0$。 

制約は大きく、最大で$2 \cdot 10^5$したがって、すべてのポイントに対して候補開始位置を試したり、距離を繰り返し再計算したりするアプローチは失敗します。 解決策では、問題をセット全体にわたる少数の集計計算に減らす必要があります。 

素朴な落とし穴は、初期点が指定されたバクテリアの位置の 1 つでなければならないと仮定することです。 原点が観測されたセットの外にある可能性があるため、これは真実ではありません。 別の失敗例を修正しようとしています$t$次に、BFS またはマルチソース拡張を介して実現可能性を確認します。これは、最大の座標範囲を考慮すると遅すぎます。$10^9$。 

## アプローチ

 強引な視点は、私たちが推測することを想像することから始まります$(t, x_0, y_0)$。 それぞれの推測について、観測されたすべての点が最大でもマンハッタン距離内にあるかどうかを検証します。$t$から$(x_0, y_0)$。 これは簡単です。候補原点からすべての点までの最大距離を計算し、それが最大距離であるかどうかを確認します。$t$。 感染拡大プロセスとの正確な一貫性も必要な場合でも、感染は 1 分あたり 1 単位を超える速度で伝播できないため、状態は依然としてマンハッタンの境界距離まで縮小します。 

ただし、この乱暴なアプローチは実行不可能です。$t$と同じ大きさにすることができます$2 \cdot 10^9$そして、候補原点は巨大なグリッド上のどこにでもあります。 制限さえする$x_0, y_0$観察された点に与えられる$O(n^2)$可能性と各チェックのコスト$O(n)$、につながる$O(n^3)$、それは限界をはるかに超えています。 

重要な観察は、「すべてのポイントが範囲内で到達可能である」という条件が成立していることです。$t$「ステップ」は幾何学的拘束に相当します。すべての点は半径のマンハッタン ボール (ダイヤモンド形) の内側になければなりません。$t$を中心に$(x_0, y_0)$。 したがって、問題は次のようになります。マンハッタンを取り囲む最小半径が最小になるような中心を見つけ、それらの中心の中から辞書編集的に最小のものを選択します。 

これは、回転した座標を使用してマンハッタンの距離を分解できるという事実を利用した古典的な短縮です。 どの点でも$(x, y)$、 定義する：$$u = x + y,\quad v = x - y.$$マンハッタン ボールは、範囲の制約に対応します。$u$そして$v$。 具体的には、固定中心の場合、最大マンハッタン距離を最小化することは、変換された両方の軸の最大偏差を最小化することと同じです。 

したがって、最適な中心は、次の極値点を使用して特徴付けることができます。$u$そして$v$独立して。 最高の$t$いずれかの最大スプレッドによって決まります。$u$または$v$、そして中心はこれらの極端なバランスをとることに対応します。 

一度$t$が固定されている場合は、 を押して辞書順に最小の有効な中心を選択できます。$x_0$すべての制約を満たしたまま、可能な限り小さくします。

 ## アルゴリズムのチュートリアル

 1. 各点を変換する$(x_i, y_i)$の中へ$u_i = x_i + y_i$そして$v_i = x_i - y_i$。 

これにより、マンハッタン距離のジオメトリが 2 つの独立した直線軸に分離されます。 
2. コンピューティング$u_{\min}, u_{\max}, v_{\min}, v_{\max}$すべての点にわたって。 

これらは、回転された座標でセットの全広がりをキャプチャします。 
3. 変換された空間での実行可能な最小半径は次のとおりです。$$t = \max(u_{\max} - u_{\min},\; v_{\max} - v_{\min}) / 2$$これは、中心が両方向の両極端の間になければならないという事実から来ています。 
4. 変換された座標で中心候補を決定します。$$u_0 = (u_{\max} + u_{\min}) / 2,\quad v_0 = (v_{\max} + v_{\min}) / 2$$パリティによって小数値が発生する場合、両方の整数オプションが有効な候補になりますが、有効な整数を生成する方を選択します。$(x_0, y_0)$。 
5. 元に戻す:$$x_0 = (u_0 + v_0) / 2,\quad y_0 = (u_0 - v_0) / 2$$6. 複数の整数中心が有効な場合は、辞書編集的に最小になるように調整します。$(x_0, y_0)$半径の制約に違反することなく。 

### なぜ効果があるのか

 すべての制約はマンハッタンの境界距離まで減少し、これは次の場合に線形制約になります。$u$そして$v$。 内部点は最大偏差に影響を与えることができないため、最適解は完全に極値によって決定されます。 中点の構築により、変換された両方の軸で同時に最小の最大偏差が保証され、中点からの偏差は最大範囲の片側を増加させるだけであり、実現可能性や辞書編集上の順序を改善することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    xs = []
    ys = []
    
    u_min = v_min = 10**30
    u_max = v_max = -10**30
    
    for _ in range(n):
        x, y = map(int, input().split())
        xs.append(x)
        ys.append(y)
        
        u = x + y
        v = x - y
        
        if u < u_min:
            u_min = u
        if u > u_max:
            u_max = u
        if v < v_min:
            v_min = v
        if v > v_max:
            v_max = v

    du = u_max - u_min
    dv = v_max - v_min

    t = max(du, dv) // 2

    # candidate midpoint in transformed space
    u0 = (u_max + u_min) // 2
    v0 = (v_max + v_min) // 2

    # convert back
    x0 = (u0 + v0) // 2
    y0 = (u0 - v0) // 2

    print(t, x0, y0)

if __name__ == "__main__":
    solve()
```この実装では、ジオメトリ全体が 4 つの極値に圧縮されます。 への変革$u, v$マンハッタン距離の制約を分離可能な線形範囲に変換するため、これは不可欠です。 

整数の除算には注意が必要です。 以来$u$そして$v$有効な整数のパリティは一致する必要があります$(x_0, y_0)$、床分割を使用した整数中点構築は、実行可能な中心がこれらのパリティと一致する離散格子内に存在するため機能します。 最終的な逆変換により、整数座標が確実に復元されます。

 ## 特殊なケース

 すべての点が単一線上にある場合、重要なエッジ ケースが発生します。 このような場合、変換された範囲の 1 つがゼロに崩壊し、答えは完全に他の軸に依存します。 折りたたまれた軸の中点が明確に定義されており、実現可能性に影響を与えないため、アルゴリズムは引き続き機能します。 

極度の座標が奇数パリティを生成する場合、別のエッジ ケースが発生します。$u$そして$v$。 整数の中点構築では、フロアリングによってこれを暗黙的に解決します。これは、有効なラティス中心の 1 つを選択することに対応します。 1 単位ずつシフトしても少なくとも 1 点の最大距離が増加するだけであるため、このような中心は最適なままです。 

最後に、いつ$n = 1$、両方の範囲がゼロであり、正解は次のようになります。$t = 0$点自体を原点として、些細な感染事例と一致します。
