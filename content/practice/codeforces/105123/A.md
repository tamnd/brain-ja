 ## 解決策
 ## 問題の理解

 セルは次から始まります`c`染色体を形成し、以下を含む 2 つの娘細胞に分裂します。`a`そして`b`染色体。 すべての染色体が 2 つの娘細胞のうちの 1 つに正確に到達する場合にのみ、分裂は正しいと見なされます。 つまり、分割後の染色体の総数は分割前とまったく同じでなければなりません。 

入力は、各娘セルに 1 つと元のセルに 1 つずつ、計 3 つの染色体数で構成されます。 タスクは、2 つの娘の数が元の数に達するかどうかを判断するだけです。 存在する場合は、印刷してください`"YES"`。 それ以外の場合は、印刷します`"NO"`。 

すべての値が 1 ～ 100 の間であるため、制約は非常に小さいです。非効率なアルゴリズムであっても即座に実行されます。 答えは単一の算術比較に依存するため、定数時間の解で十分です。 

間違いの主な原因は、間違った条件を確認することです。 

インプットを考慮する```
20 20 40
```正しい出力は次のとおりです```
YES
```不注意な実装は比較される可能性があります`a == c`または`b == c`、この有効な分割が誤って拒否されてしまいます。 

もう 1 つの簡単な間違いは、1 つの娘の染色体が元の細胞よりも少ないかどうかだけを確認することです。 例えば、```
45 93 39
```正しい出力は次のとおりです```
NO
```それでも`45`に近いです`39`、除算後の合計は`138`、 ない`39`, したがって、分割は無効です。 

## アプローチ

 この問題を考える強引な方法は、すべての染色体を個別に数えることによって分割をシミュレートすることです。 それぞれを割り当てることは想像できます。`c`染色体を 2 つの娘細胞の 1 つに移し、それぞれが何本受け取ったかを数えます。 これは有糸分裂を正確にモデル化していますが、その仕事は染色体の数に比例して実行されます。 与えられた制約を考慮すれば、これでも許容できますが、必要以上に難しい問題を解決することになります。 

重要な観察は、染色体の最終的な配置は重要ではないということです。 分割が正しいかどうかを決定する唯一の特性は、染色体の総数が保存されているかどうかです。 娘たちが含む場合`a + b`染色体を完全に分割した場合、分割は正確に有効になります。`a + b == c`。 

これにより、問題全体が 1 つの加算と 1 つの比較に減ります。

 ## アルゴリズムのチュートリアル

 1. 3 つの整数を読み取ります`a`、`b`、 そして`c`。 
2. 合計を計算します`a + b`。 これは、細胞分裂後に存在する染色体の総数です。 
3. この合計を次と比較します。`c`。 正しい有糸分裂では、染色体の総数が維持されます。 
4. もし`a + b == c`、印刷`"YES"`。 それ以外の場合は、印刷します`"NO"`。 

### なぜ効果があるのか

 正しい有糸分裂の特徴は、元の細胞のすべての染色体が 2 つの娘細胞のうちの 1 つに正確に現れることです。 染色体が失われたり複製されたりすることはありません。 その結果、分割後の染色体の総数は元の数と等しくなければなりません。 アルゴリズムはこの条件を正確にチェックするため、すべての有効な分割を受け入れ、すべての無効な分割を拒否します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

a, b, c = map(int, input().split())

if a + b == c:
    print("YES")
else:
    print("NO")
```プログラムは最初に入力から 3 つの整数を読み取ります。 テスト ケースは 1 つだけなので、ループは必要ありません。 

比較`a + b == c`これは、正しい有糸分裂の定義と直接一致します。 すべての値は正の整数であり、その最大値は 100 のみなので、Python では整数のオーバーフローは不可能であるため、特別な処理は必要ありません。 

出力は 1 つの単語のみで構成されます。`"YES"`または`"NO"`、必要な形式と一致します。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline
    a, b, c = map(int, input().split())
    print("YES" if a + b == c else "NO")

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout
    return out

# provided samples
assert run("45 93 39\n") == "NO\n", "sample 1"
assert run("39 21 60\n") == "YES\n", "sample 2"

# custom cases
assert run("1 1 2\n") == "YES\n", "minimum valid case"
assert run("100 100 100\n") == "NO\n", "maximum values but invalid total"
assert run("50 50 100\n") == "YES\n", "boundary equality"
assert run("1 100 100\n") == "NO\n", "sum exceeds original by one"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1 1 2`|`YES`| 最小有効染色体数 |
 |`100 100 100`|`NO`| 合計が正しくない最大値 |
 |`50 50 100`|`YES`| 境界における平等 |
