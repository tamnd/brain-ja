 ## 解決策
 ## 問題の理解

 私たちは数日間にわたる花の水やりの履歴を与えられます。 配列の各要素は 1 日を表します。 の値`1`花に水が与えられたことを意味しますが、`0`無視されたという意味です。 

花は高さから始まる`1`。 毎日水をやるたびに身長は伸びますが、その量は前日の出来事によって異なります。 連続した 2 日が両方とも水やりの場合、その日が寄与します`5`センチメートル。 そうでなければ、水を注いだ日だけが貢献します`1`。 乾いた日は何も貢献しません。 乾燥した日が 2 日連続して現れた場合、花はすぐに枯れてしまい、答えは次のようになります。`-1`。 

テストケースの数は最大で`100`、各テスト ケースには最大でも次のものが含まれます。`100`日々。 毎日 1 つずつ検査するアルゴリズムでも、実行される操作はわずか 1 万件程度であり、ごくわずかです。 リニアスキャンほど高度なものは必要ありません。 

誤って対処しやすい状況がいくつかあります。 

1 つのケースは、初日が乾燥している場合です。 例えば：```
1
1
0
```答えは`1`、 ない`0`。 花はすでに高さがあります`1`一日が始まる前に。 

もう 1 つのケースは、乾燥した日が 2 日連続した場合です。```
1
4
1 0 0 1
```正しい答えは、`-1`。 不用意に実装すると、単に乾燥した日をスキップして処理を続行し、不正確な正の高さを生成する可能性があります。 

水やりの日が続く場合にも注意が必要です。```
1
3
0 1 1
```答えは`7`。 2日目は貢献します`1`、3番目は貢献します`5`、最終的な高さは次のようになります。`1 + 1 + 5 = 7`。 水やりの毎日を追加として扱う`1`間違った結果が得られます。 

## アプローチ

 最も直接的なアイデアは、花の一生を説明どおりにシミュレートすることです。 日を左から右に処理し、現在の高さを維持し、必要に応じて前日を調べて、当日の成長量を判断します。 毎日一度しか訪れないので、最悪の場合に必要なのは`100`テストケースごとの操作。 

ブルート フォース シミュレーションはすでに制限内に問題なく収まっています。 毎日の効果は前日にのみ依存するため、動的プログラミングや前処理は必要ありません。 ルールのローカルな性質は、配列をスキャンしながらすべてを即座に決定できることを意味します。 

重要な観察は、重要なパターンは 3 つだけであるということです。 ペア`0 0`花を殺します。 ペア`1 1`追加します`5`2日目に向けて。 単一の孤立した`1`追加します`1`。 これらの条件は隣接する要素のみに依存するため、配列を 1 回通過するだけで十分です。

 ## アルゴリズムのチュートリアル

 1. 花の高さを次のように初期化します。`1`これは、日が処理される前の開始高さであるためです。 
2. 配列を左から右に走査します。 
3. 当日と前日が両方とも同じ場合`0`、すぐに停止し、回答にマークを付けます`-1`。 乾燥した日が2日連続するとすぐに花は枯れてしまいます。 
4. 当日に水やりがあり、前日も水やりをしていた場合は、`5`高さまで。 ルールでは現在の日が寄与するという`5`の代わりに`1`。 
5. 当日は水やりをしていても、前日は乾いていた場合は、`1`高さまで。 
6. その日が乾燥している場合は、何も追加しません。 
7. すべての日が処理された後、花が早く枯れていない限り、高さを出力します。 

### なぜ効果があるのか

 処理日後`i`、保存された高さは、それらの後の花の実際の高さに等しくなります。`i`花がまだ生きている限り、数日。 可能な連続する日のすべてのペアがルールに従って処理されます。 あ`0 0`ペアは即時終了を引き起こしますが、水を与えられた日ごとに、問題で指定された量が正確に寄与します。 アルゴリズムは毎日の効果を時系列で再現するため、最終結果は花の実際の高さと一致する必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        height = 1
        alive = True

        for i in range(n):
            if a[i] == 1:
                if i > 0 and a[i - 1] == 1:
                    height += 5
                else:
                    height += 1
            else:
                if i > 0 and a[i - 1] == 0:
                    alive = False
                    break

        if alive:
            ans.append(str(height))
        else:
            ans.append("-1")

    sys.stdout.write("\n".join(ans))

solve()
```変数`height`から始まります`1`、花の初期状態と一致します。 ループは日付を時系列順に処理します。 重要な日には、1 ポジション遡って貢献度が適切かどうかを判断します。`1`または`5`。 

条件`i > 0`アクセスを妨げます`a[-1]`初日の処理時。 この境界ケースは見落とされがちです。 

連続する 0 のペアが見つかるとすぐに、ループは停止します。 これ以上続けても花は枯れてしまっているので意味がありません。 

高さが数百を超えることはないため、通常の整数で十分です。
