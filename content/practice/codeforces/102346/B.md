 ## 解決策
 ## 問題の理解

 選挙結果は投票数の配列で表され、最初の順位はカルロスに属し、その後のすべての順位は彼の後に登録した候補者に属します。 勝者は、最も多くの票を獲得した候補者です。 複数の候補者が同じ最大数を持っている場合、最も早く登録された候補者が勝ちます。 カルロス氏が最初に登録したため、カルロス氏の得票数が少なくとも他のすべての候補者の得票数と同じになった時点で当選します。 

入力には整数が含まれています`N`、 に続く`N`肯定的な投票数。 最初のカウントはカルロスの結果であり、残りのカウントは他の候補者のものです。 必要な出力は次のとおりです`S`カルロスが勝てば`N`さもないと。 

制約`N <= 10^4`は十分に小さいため、一部の言語では二次アルゴリズムさえも実行可能ですが、ここでは不要です。 二次解のパフォーマンスは約`10^8`ペアワイズ チェックは最大サイズで行われますが、リニア スキャンではわずか約`10^4`比較。 投票総数は最大で`100,000`したがって、値自体も小さいため、Python の整数にはオーバーフローの心配はありません。 

主要なエッジケースはネクタイです。 例えば、```
2
10
10
```生成する```
S
```カルロスが最初に登録したからです。 カルロスに厳密により多くの投票を要求する不用意な解決策は、誤って印刷されます。`N`。 

もう 1 つのエッジ ケースは、カルロスが一意の最大値ではない場合です。```
3
5
7
5
```正しい出力は次のとおりです```
N
```2番目の候補者の方が多くの票を持っているからです。 カルロス氏を最後の候補者とのみ比較すると、彼を誤って受け入れることになります。 

カルロス氏は、後続の複数の候補者が同じ得票数を持っている間に最大値を同点にすることもできます。```
4
8
8
8
3
```正しい出力は次のとおりです`S`。 タイブレーク ルールでは常にカルロスが有利になります。カルロスが 1 位を占めるからです。 

## アプローチ

 完全に直接的な総当たりアプローチは、すべての候補者を他のすべての候補者と比較し、カルロスの得票数が少なくともすべての候補者と同じかどうかを判断することです。 これは正しいです。なぜなら、カルロス氏が勝つのは、厳密にそれより多くの票を獲得している候補者がいない場合だからです。 考えられるすべての順序ペアの比較を実行すると、次のようになります。`N(N-1)`比較。 と`N = 10,000`、つまり`99,990,000`比較は、このような単純な条件に対して不必要にコストがかかり、言語や時間制限によっては問題になる可能性があります。 

ブルートフォースは勝者の定義を明示的にチェックするため機能しますが、同じ情報が何度も繰り返されます。 候補者 7 の票がカルロスよりも少ない場合、それを確認する必要があるのは 1 回だけです。 候補 7 を他のすべての候補と比較する理由はありません。 

重要な観察は、カルロスの立場が特別であるということです。 彼が最初に登録したため、すでに引き分けは彼に有利です。 したがって、正確な勝者を決定したり、すべての投票数を並べ替えたりする必要はありません。 私たちが知る必要があるのは、後の候補者が厳密にカルロスよりも多くの票を持っているかどうかだけです。 残りの部分を 1 回通過する`N - 1`値で十分です。 

同じアイデアを表現するさらに一般的な方法は、最初の候補者の優先順位を維持しながら最大投票数を計算することです。 第一候補はカルロスなので、`votes[0]`すべての投票数の最大値以上であれば十分です。 これにより、線形時間の解が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ペアワイズブルートフォース | O(N²) | お(1) | 不必要に遅い |
 | 最適なリニアスキャン | O(N) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`N`そして最初の投票数。 最初の候補者は常にカルロスであるため、最初のカウントをカルロスの投票合計として保存します。 
2. 残りの部分をそれぞれ読みます。`N - 1`投票数。 いずれかの値が厳密にカルロスのカウントより大きい場合は、カルロスが勝てないと即座に判断し、出力します。`N`。 
3. より大きな投票数が見つからずに入力全体が処理された場合、出力`S`。 他のすべての候補者は最大でもカルロスの票数を持っており、最初に登録したカルロスが勝つには平等で十分です。 

これが機能する理由: スキャン中、不変条件は、これまでに処理されたすべての候補者の得票数が最大でもカルロス氏の票数であるということです。 候補者が厳密により多くの票を獲得することでこの不変条件に違反した場合、その候補者は残りの候補者全員に関係なくカルロス氏を倒さなければなりません。 全員を処理した後で違反が発生しなかった場合、カルロスは少なくともすべての候補者と同じ数の票を持っているため、同点ルールによりカルロスが勝者になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
carlos = int(input())

for _ in range(n - 1):
    votes = int(input())
    if votes > carlos:
        print("N")
        break
else:
    print("S")
```最初の 2 つの読み取りでは、候補者の数とカルロスの投票数が取得されます。 カルロスのカウントは、後の候補者がそれを超えるかどうかによって全体の決定が決まるため、個別に保持されます。 

ループは正確に処理します`N - 1`残った候補者たち。 比較は厳密に言うと`votes > carlos`、 ない`votes >= carlos`。 カルロスが先に登録したため、同じ票数を獲得した後の候補者がカルロスを破ることはありません。 

の`break`より多くの票を獲得した候補者が見つかると、最終的な選挙結果が変わることはないため、安全です。 の`for ... else`コンストラクトは逆のケースを処理します。`else`ブロックは、ループが終了することなく終了した場合にのみ実行されます。`break`、つまり、カルロスより多くの票を持った人は誰もいませんでした。 

整数オーバーフローの問題はありません。 最大の個体値は最大で`100,000`、Python 整数はそれを直接表すことができます。

## テストケース```python
import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())
    carlos = int(input())

    for _ in range(n - 1):
        votes = int(input())
        if votes > carlos:
            print("N")
            break
    else:
        print("S")

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()
    result = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return result
