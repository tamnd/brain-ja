 ## 解決策
 ## 問題の理解

 部屋は角のある長方形です`(0, 0)`そして`(M, N)`。 泥棒は、すべてのセンサーの検出ディスクの外側に厳密に留まりながら、左下隅から右上隅まで連続した経路を必要とします。 

各センサー`(x, y, s)`幾何学的に半径の閉じた円として見ることができます`s`を中心に`(x, y)`。 問題は実際のパスを見つけることではありません。 有益な問題は、禁止されたディスクの集合が、必要な 2 つの角を隔てる連続した壁を形成できるかどうかです。 

と`K <= 1000`、センサーのすべてのペアをチェックすることは実現可能です。`K(K-1)/2`、せいぜい約`500,000`、ペア。 したがって、二次アルゴリズムが実用的です。 立体的なアプローチはすでに存在しているでしょう`10^9`操作は上限に達しており、1 秒のコンテスト制限には遅すぎます。 部屋の寸法が到達できる`10^4`センサー半径も到達可能`10^4`したがって、座標値自体はグリッド シミュレーションを魅力的なものにしません。 実際、部屋の上のグリッドには、次のようなものを含めることができます。`10^8`これは不必要であり、センサーの数よりもはるかに多くなります。 

誤って処理しやすい境界の詳細が 2 つあります。 まず、泥棒はセンサーの感度よりも厳密に大きい距離に留まらなければならないため、接触はブロックとみなされます。 たとえば、正確に接している 2 つのセンサーは、接続されているものとして扱う必要があります。```
10 10 2
3 5 2
7 5 2
```2 つのディスクは次の位置で接触します。`(5, 5)`そして左側から右側へ壁を形成します。 正しい答えは、`N`。 厳密な使用法`<`比較すると誤って報告される`S`。 

第 2 に、センサーの中心が厳密に部屋の内側にある場合でも、センサーは部屋の境界に到達する可能性があります。 例えば：```
10 10 1
5 5 5
```ディスクは 4 つの側面すべてに接しているため、左下隅と右上隅が完全に分離されます。 正しい答えは、`N`。 センサーの中心が境界上にあるかどうかだけをチェックする不注意な実装では、障害物を見逃してしまいます。 

関連する 4 つの境界ペアも混同しやすいです。 上部と左側に接触する接続された障害物が、部屋の残りの部分から左下隅をブロックしています。 コンポーネントが下辺と右側に触れていると、右上隅がブロックされます。 上下に接触するコンポーネントは 2 つの垂直側面を分離し、左右に接触するコンポーネントは 2 つの水平側面を分離します。 したがって、ブロッキング条件は、接続された 1 つのセンサー コンポーネントが少なくとも 1 つの側面に接触することです。`{top, left}`そして少なくとも片側から`{bottom, right}`。 

## アプローチ

 直接的な幾何学的なアプローチでは、自由空間領域を構築し、そこを通るパスを検索しようとします。 1 つの可能性は、部屋を細かいグリッドに離散化し、BFS を実行して、センサーがカバーするすべてのグリッド ポイントをマークすることです。 これは概念的には簡単で、小さな部屋でも機能しますが、部屋が狭い場合もあります。`10^4`による`10^4`。 1 メートルあたり 1 つのセルでも、`10^8`入力にはセルのみが含まれますが、`1000`センサー。 実際の障害物は単位正方形ではなく円であるため、離散化では厄介な精度の問題も発生します。 

有用な観察は、禁止された円が連続した障壁を形成する場合にのみ、パスが不可能になるということです。 2 つのセンサーは、ディスクが交差するか接触するとき、正確に同じバリアに属します。 センサー用`i`そして`j`、これは次のときに起こります。`(xi - xj)^2 + (yi - yj)^2 <= (si + sj)^2`。 

したがって、接続を確立した後は、重複領域の正確な形状を忘れてしまう可能性があります。 すべてのセンサーをグラフの頂点にし、ディスクが交差または接触するたびに 2 つの頂点を接続します。 このグラフのすべての接続されたコンポーネントは、1 つの接続された禁止領域を表します。 

ブルート フォース グラフの構築では、センサーのすべてのペアがチェックされます。`O(K^2)`。 グラフが構築された後、DFS はすべての頂点とエッジを 1 回訪問します。 各コンポーネントについて、その円がどの部屋の境界に接触しているかを記録します。 コンポーネントが 1 つの境界を接続する場合、`{top, left}`からの1つに`{bottom, right}`、間の区切り文字を形成します。`(0, 0)`そして`(M, N)`、したがって、答えは次のとおりです`N`。 これを行うコンポーネントがない場合、空きスペースには 2 つの角の間のルートが含まれるため、答えは次のようになります。`S`。 

同じアイデアは、DFS の代わりに素セット共用体構造を使用して実装できます。 この問題に対して、DFS は十分に単純であり、接続コンポーネントの解釈を明示的にします。

 | グリッドシミュレーション | 潜在的に`O(MN)`それより悪い |`O(MN)`| 大きすぎる |

 ## アルゴリズムのチュートリアル

 1. すべてのセンサーを次のように保存します`(x, y, s)`。 距離が正確に等しいため、検出領域を閉じた円板として扱います。`s`も検出されます。 
2. センサーの各ペアについて、中心間の二乗距離を計算し、それを半径の二乗和と比較します。 もし`dx² + dy² <= (si + sj)²`、

 グラフ内の 2 つのセンサーを接続します。 二乗距離は浮動小数点演算を完全に回避し、最大の中間値は Python 整数で簡単に処理できます。 
3. 未訪問のすべてのセンサーから DFS を実行します。 DFS 中に、接続されたコンポーネント内のすべてのセンサーが接触した部屋の境界を収集します。 センサーが左側の境界に触れたとき`x - s <= 0`、右境界の場合`x + s >= M`、下の境界`y - s <= 0`、および上部の境界`y + s >= N`。 
4. 1 つの接続コンポーネントが終了したら、それが少なくとも 1 つの境界に触れているかどうかをテストします。`{top, left}`少なくとも 1 つの境界`{bottom, right}`。 そうであれば、そのコンポーネントは入口コーナーと塗装コーナーを隔てる連続した壁であるため、すぐに出力します。`N`。 
5. すべての接続コンポーネントがそのテストに合格しなかった場合、出力`S`。 2 つの隅を区切る禁止されたコンポーネントがないため、部屋の残りの部分を通る連続したパスが存在します。 

これが機能する理由: 不変条件は、すべての DFS コンポーネントがセンサー ディスクの接続された 1 つの結合を正確に表すということです。 2 つのディスクが接触するときは常に、等価性が禁止されているため、窃盗者はその接触点を通過できません。そのため、接触しているディスクをマージすると、パスの存在に関連するトポロジが保存されます。 上から下または左から右を結合する接続された禁止セットは、長方形の対向する 2 つの辺を分離し、上から左または下から右を結合すると、ターゲットの 2 つの角のうちの 1 つが切り取られます。 逆に、片側にコンポーネントが接続されていない場合は、`{top, left}`片側で`{bottom, right}`、2 つの対角隅を分離できる接続された障害物の壁はありません。 アルゴリズムは、これらの考えられる区切り文字を正確にチェックします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    M, N, K = map(int, input().split())
    sensors = [tuple(map(int, input().split())) for _ in range(K)]

    graph = [[] for _ in range(K)]

    for i in range(K):
        x1, y1, r1 = sensors[i]
        for j in range(i + 1, K):
            x2, y2, r2 = sensors[j]

            dx = x1 - x2
            dy = y1 - y2
            sr = r1 + r2

            if dx * dx + dy * dy <= sr * sr:
                graph[i].append(j)
                graph[j].append(i)

    visited = [False] * K

    for start in range(K):
        if visited[start]:
            continue

        stack = [start]
        visited[start] = True

        top = False
        right = False
        bottom = False
        left = False

        while stack:
            u = stack.pop()
            x, y, r = sensors[u]

            if y + r >= N:
                top = True
            if x + r >= M:
                right = True
            if y - r <= 0:
                bottom = True
            if x - r <= 0:
                left = True

            for v in graph[u]:
                if not visited[v]:
                    visited[v] = True
                    stack.append(v)

        if (top or left) and (bottom or right):
            print("N")
            return

    print("S")

if __name__ == "__main__":
    solve()
```最初のネストされたループは交差グラフを構築します。 二乗距離を比較するとまったく同じ結果が得られ、浮動小数点境界エラーが回避されるため、平方根はありません。 の`<=`比較は意図的です。接している 2 つの検出ディスクは、その接触点を通る正当な経路を残しません。 

DFS は、再帰的 DFS ではなく明示的なスタックを使用します。 と`K = 1000`, 再帰制限を増やした後は、Python の再帰でおそらく十分ですが、反復走査により再帰の深さへの依存が回避され、実装がより堅牢になります。 

各センサーは 4 つの独立した境界テストに貢献します。 部屋の境界に単に接触しているだけの円盤は遮断壁に関与しているため、不等式も包括的です。 例えば、`x - r == 0`センサーが左側の境界に到達し、カウントする必要があることを意味します。 

コンポーネントは次の場合に拒否されます。`(top or left) and (bottom or right)`それは本当です。 このコンパクトな式は、座標系で使用される角の方向を考慮した上で、上下、右上、左下、および左右の 4 つの分離ペアを表します。 と`top`とペアになった`left`一つのグループとして、そして`bottom`とペアになった`right`もう 1 つは、2 つの対角の角を隔てる 4 つの考えられる障壁をチェックすることと同じです。 

入力にはテスト ケースが 1 つだけあるため、`solve()`が一度呼び出されます。 Python の任意精度の整数では、2 乗座標と半径の計算からオーバーフローの懸念も排除されます。

 ## 特殊なケース

 接線ペアは、最も一般的な数値境界の間違いです。 考慮する：```
10 10 2
3 5 2
7 5 2
```中心間の距離は 4 メートル、半径の合計は 4 であるため、比較は次のようになります。`16 <= 16`。 ディスクは正確に 1 点で接続されます。 泥棒は厳密にセンサーの感度よりも遠くに留まらなければならないため、この接触はポイントを通過する経路をブロックするのに十分です。 グラフでは両方のセンサーが 1 つのコンポーネントに配置されており、コンポーネントは左右の境界に触れています。 アルゴリズムの出力`N`。 

すべてのセンサーの中心が厳密に部屋の内側にある場合でも、大きなセンサーは隅に届く可能性があります。 のために：```
10 10 1
3 3 5
```センサー中心からの距離`(0,0)`は`sqrt(18)`より小さい`5`。 入り口自体は検出ディスクの内側にあるため、入り口に法的な開始点はありません。 境界チェックでは、ディスクが左側と下側の両方に到達していることもわかります。 アルゴリズムのセパレータ ロジックは、接続された境界バリアを処理しますが、幾何学的解釈により、これがブロックされた入口ケースである理由が明らかになります。 

境界に正確に触れたセンサーをカウントする必要があります。 例えば：```
10 10 1
5 5 5
```与える`x-r = 0`、`x+r = 10`、`y-r = 0`、 そして`y+r = 10`。 コンポーネントはあらゆる面に接触するため、状態は`(top or left) and (bottom or right)`それは真実であり、答えは`N`。 境界比較を厳密な不等式に置き換えると、このケースが誤って見逃されてしまいます。 

最後に、いくつかのセンサーは個別に壁を形成しない場合がありますが、推移的結合後に壁を形成する可能性があります。 センサー A が B に接触し、B が C に接触し、C が部屋の境界に接触したとします。 A 自体が境界から遠く離れていても、A はその境界に接続されています。 3 つのセンサーはすべて同じ接続コンポーネントに属しているため、DFS はこれをキャプチャします。 コンポーネントは、そのメンバーのいずれかが到達したすべての境界を記録します。これはまさに、チェーン全体が部屋をブロックしているかどうかを判断するために必要な情報です。
