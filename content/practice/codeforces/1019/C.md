 ## アルゴリズムのチュートリアル

### なぜ効果があるのか

 頂点を選択するたびに$v$、から到達可能なすべての頂点$v$2 ステップ以内でカバーされます。 これにより、以降の反復ですでに支配されている頂点が選択されなくなります。$v$。 したがって、選択された 2 つの頂点をエッジで接続することはできません。そのようなエッジの端点は、他の端点が選択されたときにカバーされているとマークされるからです。 

同時に、スキャンした瞬間に頂点が覆われていない場合は、以前に選択した頂点が 1 つまたは 2 つのステップでその頂点に到達できないことを意味します。 したがって、それを選択するには、その頂点のカバレッジ要件を満たす必要があります。 これにより、すべての頂点が$Q$の頂点の 2 段階の外向き近傍内になければなりません。$Q$。 

このプロセスでは、新しく追加されたすべての頂点が、その 2 ステップ前進近傍全体を今後の考慮事項から除外するという制約の下で最大セットを構築します。これにより、独立性とカバレッジの両方が同時に強制されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
g = [[] for _ in range(n + 1)]

for _ in range(m):
    a, b = map(int, input().split())
    g[a].append(b)

used = [False] * (n + 1)
ans = []

for v in range(1, n + 1):
    if used[v]:
        continue

    ans.append(v)
    used[v] = True

    for u in g[v]:
        if not used[u]:
            used[u] = True
        for w in g[u]:
            used[w] = True

print(len(ans))
print(*ans)
```隣接リストには発信エッジが格納されるため、グローバル BFS を使用せずに 2 段階の到達可能性をローカルで計算できます。 の`used`配列は、カバレッジ マーカーとして、また冗長な処理を防ぐためのプルーニング メカニズムとして機能します。 

入れ子になったループ構造は、2 段階の到達可能性要件を直接反映しています。 私たちが気にするグラフの深さは 2 に固定されており、明示的な拡張が最適になるため、距離を保存したり BFS を実行したりする必要はありません。 

特に密なグラフでは、マークを繰り返すと定数係数が大幅に増加する可能性があるため、すでにマークされたノードを再度訪問しないように注意する必要があります。
