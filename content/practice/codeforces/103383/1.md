 ## 問題の理解

 それぞれが「ボーン セグメント」の無限のマルチセットを所有する 2 人のコレクターが関与するシナリオが与えられています。各コレクターは、正の整数の長さごとに、その長さの同一のセグメントを 2 つ正確に持ちます。 これらのコレクションから、各コレクターは、等しい長さのセグメントのペアを 1 つ独立して選択する必要があります。つまり、長さを選択する必要があります。$a$最初のコレクターと長さについて$b$2人目のコレクターに。 

これらの選択された長さは、周囲を含む長方形の辺を形成することを目的としています。$P$。 長方形には等しい対辺のペアが 2 つあるため、選択した 4 つのセグメントは長さの辺を形成する必要があります。$a$そして$b$したがって、境界条件は次のようになります。$$2(a + b) = P$$または同等の意味で:$$a + b = \frac{P}{2}$$タスクは、順序付けられたペアの数をカウントすることです$(a, b)$の正の整数がこの条件を満たします。 

入力の観点からは、整数のみが与えられます。$P$そして、有効な長方形を形成できる 2 つのセグメント長の有効な順序付き選択肢の数を出力する必要があります。 

制約$P \le 2 \cdot 10^9$どのような解も定数時間、または最悪の場合は対数時間で実行する必要があることがすぐにわかります。 可能なすべてのセグメント長を反復するアプローチ$P$遅すぎるでしょう。 

微妙なエッジケースが現れるのは、$P$奇数です。 その場合、$P/2$は整数ではないため、整数のセグメント長のペアは長方形の条件を満たすことができず、答えはゼロでなければなりません。 別のエッジケースが発生する場合$P = 2$、与える$a + b = 1$、正の整数解はありません。 

## アプローチ

 直接的な総当たりアプローチでは、可能なすべての値に対して反復処理が行われます。$a$、そしてそれぞれについて計算します$b = \frac{P}{2} - a$かどうかを確認します$b$はポジティブです。 これは、ターゲット合計の 2 つの正の整数への有効な分解をすべて列挙しているため、正しいです。 ただし、これには次のことが必要です$O(P)$最悪の場合は繰り返しますが、次の場合は不可能です。$P$と同じ大きさにすることができます$2 \cdot 10^9$。 

重要な観察は、問題の構造が純粋に算術的であるということです。固定整数の順序分解を数えています。$S = \frac{P}{2}$2 つの正の整数に変換します。 すべての有効なペアは、選択することによって一意に決定されます。$a$、 と$b = S - a$。 唯一の要件は、$a \ge 1$そして$b \ge 1$、これは次のように変換されます。$$1 \le a \le S - 1$$したがって、すべての整数$a$この範囲では、有効な 1 つだけが生成されます$b$。 するとすぐに次のような答えが得られます。$$S - 1$$これにより、パリティをチェックした後の定数時間の算術計算に問題全体が軽減されます。

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る$P$。 問題には追加の構造がないため、必要なのはこの 1 つの値だけです。 
2. かどうかを確認します。$P$奇数です。 そうであれば、すぐに 0 を出力します。$P/2$は整数ではないため、有効な長方形の辺の長さは存在できません。 
3. コンピューティング$S = P / 2$。 これは、2 つの辺の長さの必要な合計を表します。 
4. 有効な順序ペアの数を次のように計算します。$S - 1$、 なぜなら$a$1 から までの範囲で指定できます$S-1$、そしてそれぞれの選択は一意に決定します$b = S - a$。 
5. 計算値を出力します。 

### なぜ効果があるのか

 正確さは、すべての有効な四角形の直接の特徴付けから得られます。 すべての解は 2 つの正の整数を選択することに対応します$a$そして$b$それらの合計が次のように固定されます。$S = P/2$。 両側が正でなければならないという制約により、厳密な線形範囲が強制されます。$a$であり、その範囲内のすべての値は、個別の有効な構成を生成します。 この算術条件を超える隠れた幾何学的制約はないため、解を数えるということは、厳密に、制限された区間内の整数点を数えるということになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    P = int(input().strip())
    
    if P % 2 == 1:
        print(0)
        return
    
    S = P // 2
    # number of positive integer pairs (a, b) with a + b = S
    # a can be 1..S-1
    if S <= 1:
        print(0)
    else:
        print(S - 1)

if __name__ == "__main__":
    solve()
```実装は派生した式に直接に従います。 パリティ チェックを省略すると誤って小数和が許可されてしまうため、パリティ チェックは必須です。 境界チェックは、$S \le 1$次のような小さな入力を処理します$P = 2$、ここでは正の分解は存在しません。

 ## 特殊なケース

 奇数の場合$P$の場合、アルゴリズムは除算が実行される前に入力を即座に拒否します。 これは重要です。$P/2$整数はチェックされないと暗黙のうちに正確性を失います。

非常に大きな偶数の場合$P$すべての演算は Python の 64 ビット範囲内の単純な整数演算であり、反復や再帰が含まれないため、計算は安全なままです。
