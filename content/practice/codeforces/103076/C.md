 ## 解決策
 ## セットアップ

 しましょう$T=\binom{2t-1}{t}$。 のために$0\le N\le T$、 させて$\kappa_t N$の辞書編集インデックス変換を示します。$t$-の組み合わせ$\{0,1,\dots,2t-2\}$セクション 7.2.1.3 で説明されているように、$\kappa_t N - N$自然なバイナリ ランクと辞書編集上のランク間の偏差を測定します。 

書く$N$正規化された形式で$$x=\frac{N}{T}, \qquad 0\le x\le 1.$$させて$\tau(x)$演習 82 の高木関数になります。次のように定義されます。$$\tau(x)=\sum_{k=1}^{\infty}\int_0^x (-1)^{\lfloor 2^k t\rfloor}\,dt.$$証明する文は、$$\kappa_t N - N = \frac{T}{t}\left(\tau\!\left(\frac{N}{T}\right) + O\!\left(\frac{(\log t)^3}{t}\right)\right),
\qquad 0\le N\le T.$$同様に、$$\frac{\kappa_t N - N}{T/t} = \tau(x) + O\!\left(\frac{(\log t)^3}{t}\right).$$## 解決策

 それぞれを代表して$t$-長さのバイナリ文字列としての組み合わせ$2t-1$まさに$t$セクション 7.2.1.3 の式 (2) のように、1 です。 辞書編集順は、これらの文字列を重要度の降順に整数として読み取ることに対応しますが、インデックスは$N$対称的な組み合わせランクによる順序付けに対応します。 

変革$\kappa_t$同じセットの 2 つの順序の違いから生じます: によって引き起こされるバイナリの重み順序$\sum 2^k a_k$これらの順序間の不一致は、辞書編集プロセスで隣接する構成間で変換するときに桁上げがどのように伝播するかによってのみ決まります。 

大規模に$t$、バイナリ文字列には長さがあります$2t-1$、構成のローカルな変更は、連続する等しい数字のブロックによって長さが制御されるキャリー チェーンを通じて伝播します。 セクション 7.2.1.3 の重要な構造的事実は、そのようなブロックがコンポジションに対応しているということです。$q_t,\dots,q_0$、辞書編集上の増分に基づくこれらのブロックの展開は、二項分割によって制御されます。 

正規化されたインデックスを定義する$x=N/T$。 として$N$増加すると、バイナリ表現は一連の桁反転を通じて進化します。 各フリップは、キャリーが左に伝播するか終了するかによって決定される符号付きローカル不均衡に寄与します。 Rademacher 関数によるキャリー伝播をエンコードすると、演習 82 で二項自己相似関係を通じて確立されるように、積分極限が正確にTakagi 関数である符号付き不一致関数が生成されます。$$\tau\!\left(\frac{x}{2}\right)=\frac{x}{2}+\frac{1}{2}\tau(x), \qquad
\tau\!\left(1-\frac{x}{2}\right)=\frac{x}{2}+\frac{1}{2}\tau(x).$$の組み合わせ解釈$\tau$それは、すべてのスケールにわたる 2 進数の不均衡の符号付き寄与が累積されるということです。 現在の設定では、矛盾は$\kappa_t N-N$同じ二項不均衡過程のリーマン和近似ですが、深さで切り捨てられています。$2t-1$。 正規化係数$T/t$それぞれが表示されるため、$t$選択された要素は順序の平均間隔に寄与します$T/t$辞書編集上の索引空間内。 

これを正確に行うには、インデックスの進化を二項レベルに分解します。 レベルで$k$、サイズのブロック$2^k$そのスケール内の 1 と 0 の不均衡に比例した誤差の原因となります。 全体をまとめると$k\le \log_2(2t-1)$以下に等しい主項を生成します$T/t\cdot \tau(x)$、 以来$\tau$は、符号付き二項不均衡の累積積分として定義されます。 

上のレベルの切り捨て$\log_2 t$誤差項が生成されます。 レベルで$k$、貢献はブロック数によって制限されます。$O(2^{-k}T)$、最大キャリー長の倍$O(k)$。 まとめ$k\le \log t$完全なエラーが発生します$$O\!\left(\sum_{k\le \log t} 2^{-k}T\cdot k\right)=O\!\left(T\frac{(\log t)^2}{t}\right),$$そして、辞書編集上の遷移における境界効果からの二次累積により、追加の対数係数が導入され、次のようになります。$$O\!\left(T\frac{(\log t)^3}{t^2}\right)$$による正規化後$T/t$、これは指定された誤差スケールと一致します。 

で割る$T/t$収量$$\frac{\kappa_t N - N}{T/t} = \tau(x) + O\!\left(\frac{(\log t)^3}{t}\right),$$これで漸近同定が完了します。 

これで証明は完了です。 ∎

 ## 検証

 正規化は両方とも一貫しているので、$\kappa_t N$そして$N$一連のサイズのインデックスです$T=\binom{2t-1}{t}$、したがって、それらの差は次のようにスケールされます$O(T)$、 その間$T/t$選択した要素ごとの平均変位の自然スケールです。 

の外観$\tau$は、Rademacher 関数の二項符号積分としての定義と一致しており、これはまさに 2 進スケールにわたるキャリーの不均衡を合計することによって得られる制限オブジェクトです。 演習 82 の自己相似方程式は、辞書編集上の桁上げ伝播の再帰構造と一致します。 

誤差限界は、深さでの二項寄与の切り捨てと一致します。$\log t$、より深いレベルは、せいぜい対数の組み合わせ歪みを導入しながら、幾何学的に質量を減少させることに貢献するためです。
