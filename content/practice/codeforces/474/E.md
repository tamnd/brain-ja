 ## 解決策
 ## 問題の理解

 左から右に並べられた一連の柱があります。 柱`i`高さがある`h[i]`。 有効なジャンプは、小さいインデックスから大きいインデックスへ前方にのみ進むことができ、2 本の柱間の高さの差は少なくとも`d`。 

タスクは、一連のピラーインデックスを選択することです`i1 < i2 < ... < ik`連続するすべてのペアが有効なジャンプを形成するようにします。 このようなシーケンスすべての中で、可能な最大長のシーケンスが必要であり、実際のインデックスを出力する必要があります。 

この構造は、最長パス形式の動的計画法の問題を即座に示唆します。 定義すると`dp[i]`ピラーで終わる最長の有効なシーケンスとして`i`、 それから`dp[i] = 1 + max(dp[j])`全体`j < i`満足のいく`|h[i] - h[j]| ≥ d`。 

課題は、その最大値を効率的に見つけることです。 

制約があるからこそ、問題は面白くなります。 まであります`100000`柱、高さは次のように大きくすることができます。`10^15`。 二次アルゴリズムは大まかに検査します`10^10`最悪の場合、1 秒で実行できる速度をはるかに超えます。 周りに何かが必要です`O(n log n)`。 

いくつかの特殊なケースは注目に値します。 

いつ`d = 0`、すべての前方ジャンプが許可されます。 例えば：```
3 0
5 5 5
```答えは3つの柱すべてです。 次の場合に誤って同じ高さを除外してしまうソリューション`d = 0`有効なトランジションが失われます。 

同じ高さの柱がたくさんある場合、`d > 0`、それらの間のジャンプは禁止されています。```
4 1
7 7 7 7
```高低差がゼロであるため、ジャンプは不可能です。 正解には長さがある`1`。 

より小さい高さとより大きい高さの両方が有効な先行者である場合、別の微妙なケースが発生します。```
4 3
10 1 20 8
```柱用`8`、両方の高さ`1`と高さ`20`条件は絶対差を使用するため、制約は満たされます。 高さ範囲の片側のみを検索するソリューションでは、有効な遷移が失われます。 

高さの制限が大きいということは、高さの値に基づいてセグメント ツリーを直接構築できないことも意味します。 まず身長をランクに圧縮する必要があります。 

## アプローチ

 最も直接的な解決策は、ピラーのすべてのペアに対する動的プログラミングです。 

させて`dp[i]`ピラーで終わるシーケンスの最大長にする`i`。 柱ごとに`i`、以前のすべての柱を検査します`j`。 もし`|h[i] - h[j]| ≥ d`で終わるシーケンスを拡張します。`j`。```
dp[i] = max(dp[i], dp[j] + 1)
```すべての有効なシーケンスは次で終わるため、この繰り返しは正しいです。`i`以前の有効な先行者からのものでなければなりません。 残念ながら、`O(n²)`ペア。 と`n = 100000`、これはおよそ 100 億件の比較を意味します。 

ボトルネックは見つけることです```
max(dp[j])
```初期の柱のうち、高さが 2 つの領域のいずれかに属するもの:```
h[j] ≤ h[i] - d
```または```
h[j] ≥ h[i] + d
```重要な観察は、すでに柱を左から右に処理した後は、条件が位置ではなく高さのみに依存するということです。 

インデックス順にピラーを処理するとします。 柱に到達すると`i`、すべての有効な先行処理はすでに処理されています。 加工された柱のうち、2 つの高さ間隔における最大の DP 値が必要です。 

これは、高さに関する範囲最大クエリの問題になります。 

高さは、ソートされた一意の座標に圧縮できます。 次に、圧縮された高さによってインデックス付けされたセグメント ツリーを維持します。 各ツリーの位置に最適な情報が保存されます。`(dp value, pillar index)`その高さではこれまで見られました。 

柱用`i`では、2 つのセグメント ツリー クエリを実行します。 

最初の間隔:```
(-∞, h[i] - d]
```2 番目の間隔:```
[h[i] + d, +∞)
```これら 2 つの答えのうち、より良い方の答えは、次で終わる最長のシーケンスを生成する前任者を与えます。`i`。 

計算後`dp[i]`、圧縮された位置でセグメントツリーを更新します。`h[i]`。 

これにより、ピラーごとの作業が数回のバイナリ検索とセグメントツリー操作に減り、次の結果が得られます。`O(n log n)`時間。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての柱の高さを読み取ります。 
2. 個別の値を並べ替え、その並べ替えられたリスト内の位置を各高さに割り当てることによって、高さを座標圧縮します。 
3. 各ノードがペアを格納するセグメント ツリーを作成します。`(best_dp, pillar_index)`その高さ範囲で処理された柱の中で最も強いシーケンスを表します。 
4. 柱を左から右に処理します。 
5. 現在の身長について`h[i]`、値が最大で次の圧縮された最後の座標を見つけます。`h[i] - d`。 
6. そのプレフィックス範囲についてセグメント ツリーをクエリします。 これにより、高さが十分に小さい最適な前任者が見つかります。 
7. 少なくとも次の値を持つ最初の圧縮座標を見つけます。`h[i] + d`。 
8. そのサフィックス範囲についてセグメント ツリーをクエリします。 これにより、高さが十分に大きい最適な前任者が見つかります。 
9. 2 つのクエリからより良い結果を取得します。 どちらの範囲にも処理されたピラーが含まれていない場合は、新しい長さのシーケンスを開始します。`1`。 
10.セット```
dp[i] = predecessor_dp + 1
```再構築のために前のインデックスを保存します。 

1. 圧縮された位置でセグメント ツリーを更新します。`h[i]`ペアと一緒に`(dp[i], i)`保存されている値が改善される場合。 
2. すべての柱が処理された後、最大値を持つ柱を見つけます。`dp`。 
3. 先行ポインタを逆方向にたどって、最適なシーケンスを再構築します。 
4. 再構成されたリストを反転して印刷します。 

### なぜ効果があるのか

 柱を加工する場合`i`、セグメント ツリーには、より小さいインデックスを持つピラー、正確に法的な先行者のセットに関する情報のみが含まれます。 すべての有効な前任者は高さ以下でなければなりません`h[i] - d`または少なくとも`h[i] + d`。 2 つの範囲クエリは、これらの高さを正確に調べて、その中の最大 DP 値を返します。 

漸化式は二次動的プログラムと同じですが、セグメント ツリーは必要な最大値を効率的に計算します。 すべての DP 状態はすべての有効な先行操作から計算され、無効な先行操作は考慮されないため、結果の`dp[i]`が最適です。 保存された先行インデックスを介して再構築すると、実際の最大長のシーケンスが得られます。 

## Python ソリューション```python
import sys
from bisect import bisect_left, bisect_right

input = sys.stdin.readline

n, d = map(int, input().split())
h = list(map(int, input().split()))

vals = sorted(set(h))
m = len(vals)

NEG = (0, -1)

class SegmentTree:
    def __init__(self, n):
        self.n = 1
        while self.n < n:
            self.n <<= 1
        self.seg = [NEG] * (2 * self.n)

    def _better(self, a, b):
        if a[0] >= b[0]:
            return a
        return b

    def update(self, pos, value):
        p = pos + self.n
        if value[0] > self.seg[p][0]:
            self.seg[p] = value
        else:
            return

        p >>= 1
        while p:
            self.seg[p] = self._better(self.seg[p * 2],
                                       self.seg[p * 2 + 1])
            p >>= 1

    def query(self, l, r):
        if l > r:
            return NEG

        l += self.n
        r += self.n

        left_res = NEG
        right_res = NEG

        while l <= r:
            if l & 1:
                left_res = self._better(left_res, self.seg[l])
                l += 1

            if not (r & 1):
                right_res = self._better(self.seg[r], right_res)
                r -= 1

            l >>= 1
            r >>= 1

        return self._better(left_res, right_res)

st = SegmentTree(m)

dp = [0] * n
parent = [-1] * n

for i in range(n):
    best = NEG

    right_small = bisect_right(vals, h[i] - d) - 1
    if right_small >= 0:
        best = st.query(0, right_small)

    left_large = bisect_left(vals, h[i] + d)
    if left_large < m:
        cand = st.query(left_large, m - 1)
        if cand[0] > best[0]:
            best = cand

    dp[i] = best[0] + 1
    parent[i] = best[1]

    pos = bisect_left(vals, h[i])
    st.update(pos, (dp[i], i))

end = max(range(n), key=lambda x: dp[x])

answer = []
cur = end

while cur != -1:
    answer.append(cur + 1)
    cur = parent[cur]

answer.reverse()

print(len(answer))
print(*answer)
```座標圧縮ステップでは、高さが次のように変換されます。`10^15`間のインデックスに`0`そして`m - 1`により、セグメントツリーストレージが実現可能になります。 

セグメントツリーにはペアが格納されます`(dp value, index)`DP 値だけではなく。 DP 値は最適化に必要ですが、インデックスは後で再構築に必要になります。 

2 つのバイナリ検索により、2 つの有効な高さの領域が特定されます。`bisect_right(vals, h[i] - d) - 1`より低い区間にまだ属している最大の圧縮座標が得られます。`bisect_left(vals, h[i] + d)`上部の区間に属する最初の座標を与えます。 

よくある間違いは、クエリを実行する前にセグメント ツリーを更新することです。 そうすることで、柱自体を前任者として使用できるようになります。 厳密に左から右の順序で処理し、更新前にクエリを実行することで、この問題を回避できます。 

もう 1 つの微妙な点は、空の範囲の処理です。 クエリされた間隔に高さが属さない場合、セグメント ツリー クエリはスキップされ、結果は中立値のままになります。`(0, -1)`。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io
from bisect import bisect_left, bisect_right

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    n, d = map(int, input().split())
    h = list(map(int, input().split()))

    vals = sorted(set(h))
    m = len(vals)

    NEG = (0, -1)

    class SegmentTree:
        def __init__(self, n):
            self.n = 1
            while self.n < n:
                self.n <<= 1
            self.seg = [NEG] * (2 * self.n)

        def better(self, a, b):
            return a if a[0] >= b[0] else b

        def update(self, pos, value):
            p = pos + self.n
            if value[0] <= self.seg[p][0]:
                return
            self.seg[p] = value
            p >>= 1
            while p:
                self.seg[p] = self.better(
                    self.seg[p * 2],
                    self.seg[p * 2 + 1]
                )
                p >>= 1

        def query(self, l, r):
            if l > r:
                return NEG
            l += self.n
            r += self.n
            res = NEG
            while l <= r:
                if l & 1:
                    res = self.better(res, self.seg[l])
                    l += 1
                if not (r & 1):
                    res = self.better(res, self.seg[r])
                    r -= 1
                l >>= 1
                r >>= 1
            return res

    st = SegmentTree(m)

    dp = [0] * n
    par = [-1] * n

    for i in range(n):
        best = NEG

        p = bisect_right(vals, h[i] - d) - 1
        if p >= 0:
            best = st.query(0, p)

        q = bisect_left(vals, h[i] + d)
        if q < m:
            cand = st.query(q, m - 1)
            if cand[0] > best[0]:
                best = cand

        dp[i] = best[0] + 1
        par[i] = best[1]

        st.update(bisect_left(vals, h[i]), (dp[i], i))

    ans = max(dp)
    return str(ans)

assert run("5 2\n1 3 6 7 4\n") == "4"

# minimum size
assert run("1 5\n10\n") == "1"

# all equal heights, d > 0
assert run("4 1\n7 7 7 7\n") == "1"

# d = 0, every jump allowed
assert run("5 0\n2 2 2 2 2\n") == "5"

# alternating valid jumps
assert run("5 10\n1 20 2 30 3\n") == "5"

 ## 特殊なケース

 次のことを考慮してください。```
4 1
7 7 7 7
```各柱の有効な高さの範囲は次のとおりです。`≤ 6`そして`≥ 8`。 どちらの範囲にも処理されたピラーは含まれません。 どちらのセグメント ツリー クエリも中立値を返すため、`dp[i]`になる`1`。 アルゴリズムはジャンプが不可能であることを正しく報告します。 

考慮する：```
5 0
2 2 2 2 2
```これで、以前のすべての柱が有効な先行柱となります。 下の間隔は次のようになります。`≤ 2`、これにはすでに処理されたすべての柱が含まれています。 新しい柱はそれぞれ、これまでに見つかった最良のシーケンスを拡張し、DP 値を生成します。`1, 2, 3, 4, 5`。 答えは完全なシーケンスです。 

考慮する：```
4 3
10 1 20 8
```高さの場合`8`、有効な先行者は両方とも高さです`1`と高さ`20`、条件は絶対的な差に基づいているためです。 このアルゴリズムは、2 つの別々の範囲クエリを実行し、1 つは低い高さに対して、もう 1 つは高い高さに対して実行し、より良い結果を取得します。 これにより、高さスペクトルの片側だけを考慮するというよくあるバグが回避されます。 

考慮する：```
3 1000000000
1 1000000000000000 2
```高さは膨大ですが、座標圧縮により小さなインデックス範囲にマップされます。 セグメント ツリーは生の高さの値に依存しないため、アルゴリズムは完全な高さの値を処理します。`10^15`メモリ使用量を増やさずに範囲を変更できます。
