 ## 解決策
 ## 問題の理解

 一様にランダムに選択された 2 つの実パラメータが与えられます。 

被害者の身長`p`狭間にある`[0, a]`、および風のパラメータ`q`にある`[-b, b]`。 すべてのペアについて`(p, q)`、特定の二次方程式に少なくとも 1 つの実根があれば、金床は正常にヒットします。 

ステートメントから得られる式は次のとおりです。$x^2+px+q=0$二次方程式は、その判別式が負でない場合に正確に実根を持ちます。 したがって、問題全体は次のような確率を計算することに帰着します。$p^2-4q\ge0$以来`p`そして`q`が均一かつ独立して選択されるため、この確率は単に有効なすべての領域です。`(p, q)`ペアを長方形の合計面積で割った値：$0\le p\le a,\ -b\le q\le b$アルゴリズムの観点から見ると、制約は非常に小さいです。 までしか処理しません`10^4`各テスト ケースには 2 つの整数のみが含まれます。 テスト ケースごとの定数時間の数式は、簡単に十分に高速です。 たとえ`O(log n)`または`O(sqrt n)`解決策は快適に通過するでしょう。 本当の課題は、正しいジオメトリを導き出し、境界ケースを慎重に処理することです。 

厄介なケースは、放物線が長方形とどのように相互作用するかによって生じます。 

考慮する：```
a = 1, b = 100
```放物線`q = p² / 4`長方形の高さに比べて非常に低いままです。 ほとんどのポイントは失敗するため、確率は次のようになります。`1/2`、近くにはありません`1`。 

不用意に実装すると、放物線が常に上部の境界に到達すると仮定する可能性があります。`q = b`、ここでは誤りです。 

もう 1 つの重要なエッジケースは次のとおりです。```
a = 0, b = 5
```それから`p`は常にゼロであるため、条件は次のようになります。```
-4q >= 0
```つまり`q <= 0`。 間隔のちょうど半分`[-5, 5]`動作するので、答えは次のとおりです`0.5`。 

バグのある導出では、次のように除算されることがよくあります。`a`どこかでクラッシュするか NaN が生成される場合`a = 0`。 

最後の微妙な状況は、放物線がちょうど上端に触れているときです。```
a = 4, b = 4
```なぜなら`a² / 4 = 4`。 

統合により、正確にこの境界で動作が変更されます。 厳密な不等式を間違った場所で使用すると、小さな浮動小数点エラーが発生したり、間違った式が選択されたりする可能性があります。 

## アプローチ

 ブルートフォースの観点は単純です。 可能なすべての長方形を考えることができます`(p, q)`ペアを作成し、各点が次の条件を満たすかどうかを確認します。$q\le\frac{p^2}{4}$長方形を非常に細かいグリッドに離散化し、不等式を満たすセルの数を数え、セルの総数で割ると、確率の近似値が得られます。 

一様ランダム選択は面積比に直接対応するため、これは概念的に機能します。 問題は精度です。 達成するために`10^-6`精度を高めるには、グリッドには数百万または数十億のサンプルが必要になります。 のために`10^4`テストケースでは、それは完全に非現実的になります。 

重要な観察は、有効な領域が非常に単純な幾何学的形状をしているということです。 

固定ごとに`p`、の有効な値`q`は：$-b\le q\le\min\left(b,\frac{p^2}{4}\right)$したがって、面積を数値的に近似する代わりに、この間隔の高さを正確に積分することができます。 

2 つのケースが自然に現れます。 

もし：$\frac{a^2}{4}\le b$その場合、放物線は長方形の上の境界線に到達することはありません。 それぞれの有効な高さ`p`は：$b+\frac{p^2}{4}$からの統合`0`に`a`面積を直接与えます。 

代わりに:$\frac{a^2}{4}>b$そしてある時点の後、放物線が長方形の上に上がります。 その時点から、すべての`q`値が機能します。 

移行は次の場所で行われます。$p=2\sqrt b$これにより、積分が 2 つの簡単な部分に分割されます。 

ソリューション全体はテスト ケースごとに一定時間になります。

 ## アルゴリズムのチュートリアル

 1. 二次判別条件から開始します。 

次の場合、方程式は実根を持ちます。$p^2-4q\ge0$並べ替えると次のようになります。$q\le\frac{p^2}{4}$2. 確率を幾何学的に解釈します。 

可能なすべてのペア`(p, q)`面積の長方形を形成する：$2ab$答えは次のようになります。 

有効面積 / 総面積。 
3. 固定値の有効な垂直間隔を決定します。`p`。 

以来`q`からの範囲`-b`に`b`さらに次のものが必要です。$q\le\frac{p^2}{4}$有効な高さは次のようになります。$\min\left(b,\frac{p^2}{4}\right)+b$4. 放物線が上端に到達しない最初のケースを処理します。 

もし：$a\le2\sqrt b$それから：$\frac{p^2}{4}\le b$あらゆる人にとって`p`で`[0, a]`。 

有効な領域は次のとおりです。$\int_0^a\left(b+\frac{p^2}{4}\right)dp=ab+\frac{a^3}{12}$で割る`2ab`与える:$\frac12+\frac{a^2}{24b}$5. 放物線が上端と交差する 2 番目のケースを処理します。 

もし：$a>2\sqrt b$それから`p > 2√b`、 毎`q`値が機能します。 

エリアを 2 つの領域に分割します。 

最初の地域からは、`0`に`2√b`、貢献:$\int_0^{2\sqrt b}\left(b+\frac{p^2}{4}\right)dp=\frac{8}{3}b^{3/2}$2番目の地域からは、`2√b`に`a`、長方形全体の高さに寄与します。$2b(a-2\sqrt b)$収量を合計して単純化すると、次のようになります。$1-\frac{2\sqrt b}{3a}$6. 現在のケースに対応する数式を出力します。 

### なぜ効果があるのか

 アルゴリズムは、すべての成功の正確な測定値を直接計算します。`(p, q)`サンプリング長方形内のペア。 固定ごとに`p`, 垂直間隔がどの程度判別条件を満たすかを正確に計算します。 これらの有効な長さをすべて統合する`p`値は正確な成功領域を示します。 

放物線は区間全体にわたって長方形の上端の下に留まるか、ちょうど 1 回交差するかのいずれかであるため、2 つのケースに分割することは網羅的です。 他の幾何学的動作は不可能です。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

t = int(input())

for _ in range(t):
    a, b = map(float, input().split())

    if b == 0:
        print("1.0000000000")
        continue

    if a * a <= 4 * b:
        ans = 0.5 + (a * a) / (24.0 * b)
    else:
        ans = 1.0 - (2.0 * math.sqrt(b)) / (3.0 * a)

    print(f"{ans:.10f}")
```実装はウォークスルーからの派生に正確に従っています。 

最初のブランチのハンドル`b = 0`別に。 そのような状況では、`q`は常にゼロであるため、判別式は次のようになり、二次方程式は常に実根を持ちます。`p²`。 確率はまさに`1`。 

2 番目のブランチは、放物線が長方形の上の境界に達しているかどうかをチェックします。 使用方法:```
a * a <= 4 * b
```不要な平方根を回避し、境界付近の小さな浮動小数点精度の問題も回避します。 

数式は浮動小数点式として直接評価されます。 すべての中間値は、標準の倍精度内に快適に収まります。`a`そして`b`せいぜい`10^6`。 

小数点以下 10 桁の書式設定は、必要な精度許容差を簡単に満たします。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io
import math

def solve():
    input = sys.stdin.readline

    t = int(input())

    out = []

    for _ in range(t):
        a, b = map(float, input().split())

        if b == 0:
            out.append("1.0000000000")
            continue

        if a * a <= 4 * b:
            ans = 0.5 + (a * a) / (24.0 * b)
        else:
            ans = 1.0 - (2.0 * math.sqrt(b)) / (3.0 * a)

        out.append(f"{ans:.10f}")

    print("\n".join(out))

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    return sys.stdout.getvalue()

# provided sample
assert run("2\n4 2\n1 2\n") == (
    "0.7642977396\n"
    "0.5208333333\n"
), "sample"

# minimum values

# boundary where a^2 = 4b

# very large values
assert run("1\n1000000 1\n") == "0.9999993333\n", "large a"

# a = 0 with positive b

 ## 特殊なケース

 次のことを考慮してください。```
1
0 5
```ここ`p`はゼロに固定されます。 条件は次のようになります。$-4q\ge0$つまり:$q\le0$内部`[-5, 5]`、ちょうど半分の間隔が機能します。 次の理由により、アルゴリズムは最初の式分岐に入ります。```
a² <= 4b
```そして以下を計算します:```
0.5 + 0 / (24 * 5) = 0.5
```それは正しいです。 

次に、次のことを考えてみましょう。```
1
4 4
```放物線は上の境界に正確に接触します。`p = 4`。 両方の派生式は同じ値を生成します。```
2 / 3
```実装では使用します`<=`分岐条件では境界が途切れることなく一貫して扱われます。 

最後に、次のことを考慮してください。```
1
10 0
```それから`q`は常にゼロであり、すべての二次式には判別式があります。$p^2$これは常に負ではありません。 専用の`b == 0`ブランチリターン`1.0`すぐに、数式内でのゼロ除算を避けます。
