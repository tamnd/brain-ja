 ## 解決策
 ## 問題の理解

 2 つの単純な多角形が与えられ、それぞれの頂点が反時計回りの順序で記述されます。 それらは、凸型クッキーが砕かれた後に平面内に横たわる 2 つの「割れたクッキー片」と考えることができます。 タスクは、2 つの部分を一緒に配置したときに、それらの結合がエッジの位置合わせに幾何学的な矛盾のない凸多角形を形成するように、部分の 1 つを移動する方法が存在するかどうかを判断することです。 

重要な条件は、形状がうまく重なるだけでなく、その境界が端から端まで一貫して一致する必要があることです。 特に、ポリゴンの 1 つのエッジが他のエッジの複数のエッジと整列するような状況や、境界セグメントの 1 対 1 の対応が崩れるような同様の縮退は発生できません。 変換後、結合された外側の境界は単一の凸多角形をトレースする必要があります。 

計算の観点から見ると、各ポリゴンには最大 2000 個の頂点があるため、エッジのすべてのペアまたは頂点ペア間のすべての平行移動を試す単純な幾何学的位置合わせテストは、すでに境界線に達しています。 3 次または 2 次のエッジのペアリングは、約 10^6 ～ 10^7 の幾何学的チェックにヒットする危険性があり、各チェックにはセグメント比較または方向テストが含まれますが、それでも許容できる可能性があります。 ただし、すべての頂点ペアの位置合わせを効果的に試し、凸性を最初から再計算するソリューションは、O(n^2 m) 以上の速度に達し、遅すぎます。 

主なエッジケースは、次のような幾何学的縮退です。 

多角形はすでに凸状ですが、同一線上にある連続した点が多数あります。 その場合、複数のエッジが同じ線分上に存在することになり、単純な「エッジ マッチング」ロジックがそれらを別個のものとして誤って扱ったり、誤って重なり合っているものとして扱ったりする可能性があります。 

もう 1 つのケースは、両方の多角形が凸状であるが、サポート ラインの部分的な重なりのみが存在するように一方が他方に対して回転されている場合です。 たとえば、2 つの三角形が 2 つの平行なエッジを共有しているが、それらの 3 番目のエッジに互換性がない場合、平行度のみに基づく単純なマッチングでは誤って受け入れられる可能性があります。 

さらに微妙なケースは、ポリゴンが長い同一線上のチェーンを共有する場合です。 たとえば、1 つのポリゴンに多くのセグメントで構成される長い直線の境界があり、もう 1 つのポリゴンがその一部のみと一致する場合、単純なセグメント マッチングはステートメントで説明されている 1 対 1 制約に違反する可能性があります。 

## アプローチ

 ブルートフォース解釈は、そのペアを平行移動ベクトルとして使用して、最初の多角形のすべての頂点を 2 番目の多角形のすべての頂点と位置合わせすることから始まります。 変換したら、結合境界が凸多角形を形成しているかどうか、およびすべての境界エッジが有効な方法で一致しているかどうかをチェックしようとします。 

このアプローチは原理的には正しいです。有効な変換では、1 つのポリゴンの少なくとも 1 つの頂点を他のポリゴンのいくつかの頂点にマッピングするか、少なくともポリゴン エッジの離散構造を考慮した後で頂点の位置合わせに還元できる方法でサポート エッジを位置合わせする必要があるためです。 ただし、問題はコストです。 すべての O(nm) 変換を試してからマージされたハルを再計算したり、凸性を検証したりすると、試行ごとに O(n + m) 以上のコストがかかり、複雑さは O(n^2 m + nm^2) になります。これは、n、m が 2000 までの場合、制限をはるかに超えます。 

重要な観察は、平行移動によってエッジの方向や長さが変化しないことです。 重要なのは、各ポリゴンの周囲のエッジ ベクトルのシーケンスです。 2 つの多角形を平行移動によって 1 つの凸多角形にマージできる場合、それらの境界サイクルは全体的な凸性を維持する方法でインターリーブする必要があります。 これにより、問題はエッジ ベクトルの循環シーケンスの比較に変わります。基本的に、2 つの循環シーケンスを (循環シフトの可能性を伴う) 連結して、すべての回転が同じ方向にあり、エッジが一貫して一致する単一の凸多角形境界を形成できるかどうかをチェックしています。

これにより、エッジ方向のシーケンスを操作し、それらを組み合わせたときに結果のシーケンスが有効な凸包境界を形成するようにするという問題が軽減されます。 これを推論する標準的な方法は、各ポリゴンをエッジ ベクトル シーケンスに正規化し、凸ターン構造を維持しながらこれらのシーケンスを「マージ」しようとすることです。 これは、ミンコフスキー和境界構造と凸多角形の畳み込みのアイデアと密接に関連しています。 

このレンズを通して見ると、問題は、エッジ ベクトルの 2 つの循環シーケンスを、結合された角度順序が単調になり、矛盾する向きが生じないように位置合わせできるかどうかを確認することになります。 これは、エッジを極角に変換し、ソートし、両方のシーケンスが矛盾する方法で折り返されない連続した角度間隔内にあるかどうかを確認し、一貫した方向 (時計回りまたは反時計回りの一貫性) を確保することによって実行できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべての翻訳を試行 + 凸包を再計算) | O(n^2 m) 以上 | O(n + m) | 遅すぎる |
 | エッジベクトル角度マージ (ミンコフスキー流推論) | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最後の頂点を最初の頂点に接続しているものとして扱い、連続する頂点を減算して両方のポリゴンのエッジ ベクトルを計算します。 これにより、各ポリゴンが有向セグメントの循環シーケンスに変換されます。 このステップを行う理由は、平行移動がエッジの方向に影響しないため、エッジは形状の不変構造であるためです。 
2. atan2 を使用して、各エッジ ベクトルを角度表現に変換します。 これにより、座標空間ではなくグローバル角度空間でポリゴンの回転動作を推論することができます。 
3. 各ポリゴンのエッジ角度シーケンスを正規化して周期的に処理できるようにします。つまり、概念的には開始点の回転を許可します。 開始頂点は任意であるため、これが必要になります。 
4. 各ポリゴンがエッジ角度シーケンスで個別に凸状チェーンを形成しているかどうかを確認します。 これにより、各ピースがマージ後の凸状境界の形成にすでに適合していることが保証されます。 
5. 角度が 2π を法として単調増加する 2 つの巡回角度シーケンスを 1 つの巡回シーケンスにマージしようとします。 これは、両方の多角形のすべてのエッジを単一の凸包順序で配置できるような回転が存在するかどうかをチェックすることに対応します。 
6. 角度間隔が矛盾する形でラップアラウンドしていないことを確認します。 実際には、これは両方の角度セットの和集合が長さ π 以下の半開区間内にあるかどうかをチェックすることになり、結果として得られる境界の凸性が保証されます。 
7. そのようなアライメントが存在する場合は「yes」を出力し、存在しない場合は「no」を出力します。 

### なぜ効果があるのか

 凸多角形は、エッジ方向の角度が単調であることによって完全に特徴付けられます。 2 つのポリゴンが平行移動されてマージされる場合、それらの結合された境界は依然としてこの単調な角度順序を満たさなければなりません。 有効な変換が存在する場合、凹型ターンを導入することなく、両方のエッジ方向シーケンスを単一の循環シーケンスにインターリーブする一貫した方法が存在します。 逆に、そのような角度順序が存在しない場合、どの配置でも方向の競合が強制され、反射角またはエッジの不一致が生じ、凸性または 1 対 1 のエッジ対応条件に違反します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def read_polygon(n):
    pts = [tuple(map(int, input().split())) for _ in range(n)]
    edges = []
    for i in range(n):
        x1, y1 = pts[i]
        x2, y2 = pts[(i + 1) % n]
        dx, dy = x2 - x1, y2 - y1
        edges.append(math.atan2(dy, dx))
    return edges

def is_convex_angles(angles):
    n = len(angles)
    # find max gap
    a = sorted(angles)
    a.append(a[0] + 2 * math.pi)
    max_gap = 0
    for i in range(n):
        max_gap = max(max_gap, a[i + 1] - a[i])
    # convex if all angles lie in an arc of length <= pi
    return (2 * math.pi - max_gap) <= math.pi

n = int(input())
A = read_polygon(n)

m = int(input())
B = read_polygon(m)

angles = A + B

print("yes" if is_convex_angles(angles) else "no")
```このコードは、各ポリゴンをそのエッジ方向に縮小し、すべての方向が角度空間内の半円に収まるかどうかをチェックします。 この条件は、マージされた境界を凸多角形として方向付けることができることと同じです。 

微妙な点は、明示的に翻訳を試みることは決してないということです。 平行移動は位置にのみ影響し、方向には影響しないため、実現可能性の問題全体は、方向の制約が互換性があるかどうかに集約されます。 ソートのステップは、循環順序付けの問題を線形間隔の問題に変換するため、重要です。

## テストケース```python
import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math

    def read_polygon(n):
        pts = [tuple(map(int, input().split())) for _ in range(n)]
        edges = []
        for i in range(n):
            x1, y1 = pts[i]
            x2, y2 = pts[(i + 1) % n]
            dx, dy = x2 - x1, y2 - y1
            edges.append(math.atan2(dy, dx))
        return edges

    def solve():
        n = int(input())
        A = read_polygon(n)
        m = int(input())
        B = read_polygon(m)
        angles = A + B
        a = sorted(angles)
        a.append(a[0] + 2 * math.pi)
        max_gap = 0
        for i in range(len(angles)):
            max_gap = max(max_gap, a[i + 1] - a[i])
        print("yes" if (2 * math.pi - max_gap) <= math.pi else "no")

    from io import StringIO
    old = sys.stdout
    sys.stdout = StringIO()
    solve()
    out = sys.stdout.getvalue()
    sys.stdout = old
    return out.strip()

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、ポリゴンに多くの同一線上のエッジがある場合です。 その場合、複数の連続するエッジが同一の角度を生成し、単純な一意性ベースのアプローチでは角度セットが誤って縮小され、実際のスパンが過小評価されてしまいます。 重複は計算された最大角度ギャップに影響を与えないため、アルゴリズムはこれを正しく処理します。 

もう 1 つのエッジ ケースは、1 つのポリゴンがほぼ直線であり、前後にわずかなずれがある場合です。 エッジ角度は半円の境界の周りに密集しており、合計スパンが π を超えない場合、アルゴリズムはこれをマージ可能である可能性があるものとして正しく処理します。 

最後のエッジ ケースは、角度が -π から π の境界を囲む場合です。 ソートされた配列に最初の角度に 2π を加えた値を追加することにより、アルゴリズムは周期的な連続性を正しく処理し、ラップ ポイントでの誤ったギャップを回避します。
