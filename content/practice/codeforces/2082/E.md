 ## 解決策
 ## 問題の理解

 各セルに 0 から 3 までの数値が含まれる行列が与えられます。タスクは、この行列を問題で「適切な」行列と呼ばれるものに変換することです。 すべての行のすべての要素の XOR が 0 であり、すべての列のすべての要素の XOR が 0 であれば、行列は良好です。 与えられた行列を適切なものにするために必要な変更の最小数を計算し、そのような結果として得られる行列を 1 つ生成するように求められます。 

各テスト ケースでは、行列の次元、n 行、m 列が提供され、その後に n 行自体が 0 ～ 3 の数字のシーケンスとして続きます。 出力は、最小の変更数を示し、次に XOR 条件を満たす最終行列を示す必要があります。 

制約を見ると、n と m はそれぞれ最大 1000 まで可能ですが、すべてのテスト ケースにわたるセルの総数は 100 万に制限されています。 これにより、テスト ケースごとに O(n·m) アルゴリズムが実行可能になりますが、ケースごとのセル数が 2 次のもの (O((n·m)^2) など) は遅すぎます。 可能な行列は 4^(n・m) 通りあるため、可能な変更の組み合わせをすべて試す余裕はありません。 

n と m が両方とも奇数の場合、微妙なエッジ ケースが発生します。 この状況では、すべての行とすべての列の XOR が両方とも 0 である必要があります。 ただし、XOR は結合的かつ可換であるため、n·m が奇数の場合、すべての行のすべての要素の XOR は、すべての列のすべての要素の XOR と等しくなければなりません。 このプロパティにより、常に解決策を可能にすることができますが、不注意に実装すると、変更のカウントを間違えたり、最後の行/列を正しく調整できなかったりする可能性があります。 

1×1 や 1×n などの小さな行列では、別の自明ではない状況が発生します。 このような場合、行と列の XOR 制約が一致するため、概念的には 1 つのセルを複数回変更する必要がある場合があります。 私たちのアルゴリズムは、二重にカウントすることなくこれを処理する必要があります。 

## アプローチ

 ブルート フォース アプローチでは、セルごとに考えられる変更の組み合わせをすべて試し、結果の行列が行と列の XOR 条件を満たすかどうかを確認します。 このアプローチは明らかに指数関数的であり、実行不可能です。 行または列ごとに 2^n の組み合わせをすべて試しても、n と m が 1000 までの場合は遅すぎます。 

重要な洞察は、XOR の特性と可能な値の狭い範囲 (0 ～ 3) を利用することです。 XOR は線形に動作します。行または列の XOR がわかっていれば、その行または列の最後のセルの値をいつでも選択して、XOR を 0 にすることができます。 したがって、おそらく最後の行を除く各行について、1 列を除くすべての列に値を自由に割り当て、その行の最後の値を計算して行の XOR を満たすことができます。 同様に、後で最後の行を調整して列の XOR を修正できます。 

数値が小さい (0 ～ 3) ため、最善のアプローチは貪欲です。 n または m の偶数の行または列のペアで行列を埋め、XOR 制約を満たすように各ペアの 1 つの要素を調整します。 n と m が両方とも奇数の場合、最後の行と最後の列を同時に満たすように右下のセルを調整できます。 

この方法では、行と列ごとに必要に応じて 1 つの要素のみを調整し、他の要素は可能な限り変更しないため、最小限の変更が保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(4^(n・m)) | O(n・m) | 遅すぎる |
 | XOR を使用した貪欲な行/列の修正 | O(n・m) | O(n・m) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 行列を読み取り、各文字を整数に変換します。 これにより、高速な XOR 演算が可能になります。 
2. 各行と各列の XOR を追跡するために配列を初期化します。 行列を反復処理して、これらの初期 XOR を計算します。 
3. 最後の行を除き、行列を行ごとに処理します。 各行について、最後の列を除くすべての列を反復処理します。 値をそのままにしておきます。 最初の (m-1) セルの XOR を計算します。 行全体の XOR がゼロになるように行の最後のセルを調整します。 それに応じて列 XOR 配列を更新します。 これにより、最後の行を除くすべての行が行 XOR 制約を満たすことが保証されます。 
4. 次に、最後の行を処理します。 最後を除く各列について、列 XOR を満たすようにセルを設定します (列 XOR はすでに前の行によって部分的に決定されているため)。 最後に、最後の行と最後の列の両方の XOR を満たすように右下のセルを設定します。 XOR 演算は結合的であるため、機能する 0 ～ 3 の間の一意の値が常に存在します。 元の行列と異なるセルの変更をカウントします。 
5. 変更の数と最終的な行列を出力します。 

機能する理由: すべてのステップで、処理されたすべての行が行 XOR を満たすという不変条件を保持します。 最後の行を注意深く計算することで、列の XOR もゼロであることが保証されます。 XOR のプロパティにより、この手順では常に正しく、最小限の変更で解決できることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        mat = [list(map(int, list(input().strip()))) for _ in range(n)]
        changes = 0
        
        # row XORs and column XORs
        row_xor = [0]*n
        col_xor = [0]*m
        for i in range(n):
            for j in range(m):
                row_xor[i] ^= mat[i][j]
                col_xor[j] ^= mat[i][j]
        
        # copy matrix to result
        res = [row[:] for row in mat]
        
        # fix all rows except last
        for i in range(n-1):
            xor_sum = 0
            for j in range(m-1):
                xor_sum ^= res[i][j]
            target = xor_sum ^ 0
            if res[i][m-1] != target:
                changes += 1
                res[i][m-1] = target
            col_xor[m-1] ^= target ^ mat[i][m-1]
            for j in range(m-1):
                col_xor[j] ^= 0  # no change
        
        # fix last row
        for j in range(m-1):
            target = col_xor[j] ^ mat[n-1][j]
            if res[n-1][j] != target:
                changes += 1
                res[n-1][j] = target
            row_xor[n-1] ^= target ^ mat[n-1][j]
        
        # fix bottom-right cell
        target = row_xor[n-1] ^ col_xor[m-1] ^ mat[n-1][m-1]
        if res[n-1][m-1] != target:
            changes += 1
            res[n-1][m-1] = target
        
        print(changes)
        for row in res:
            print("".join(map(str, row)))

solve()
```このコードは、最初に行と列の XOR を計算し、次に最後の行を除くすべての行の最後の列を貪欲に調整し、最後に最後の行と右下のセルを調整します。 各調整は、元のマトリックスと異なる場合にカウントされます。 マトリックスをコピーすると、元の値が途中で上書きされなくなります。
