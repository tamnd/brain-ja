 ## 解決策
 ## 問題の理解

 元の配列に関して重要なのは、隣接するすべての比較の符号だけです。 

ポジションごとに$i$、間のエッジを定義します。$a_i$そして$a_{i+1}$。 

もし$a_i < a_{i+1}$、エッジをポジティブと呼びます。 

もし$a_i > a_{i+1}$、エッジをネガティブと呼びます。 

すべてのエッジが正の場合、配列はすでに厳密に増加しています。 

操作では、連続したセグメントを選択し、その中のすべての値を書き換えます。 重要な制限は、選択したセグメント内に完全に含まれるすべての比較が元の符号を維持する必要があることです。 正のエッジは正のままであり、負のエッジは負のままです。 

入力サイズが大きいです。 すべてのテスト ケースの合計の長さは次のとおりです。$2 \cdot 10^5$したがって、二次アルゴリズムは直ちに除外されます。 テスト ケースごとに線形または線形に近いものが必要です。 

最も簡単な間違いは、実際の値について考えることです。 この演算では大きさは考慮されず、比較符号のみが考慮されます。 

考慮する：```
3 2 1
```負のエッジが 2 つあります。 1 つの操作は、その間隔の境界にあるエッジにのみ影響を与えることができるため、両方のマイナスを一度に削除することはできません。 正しい答えは、`2`。 

もう 1 つの簡単な罠は、負のエッジのすべてのペアが常に一緒に削除できると仮定することです。```
3 2 1
```2 つの負のエッジは最初と最後のエッジです。 1 つの間隔で両方を除去しようとすると、その間隔の外側の値は次の条件を満たす必要があります。`3 < 1`、それは不可能です。 答えは残っている`2`。 

より微妙な例は次のとおりです。```
-2 -5 5 2
```負のエッジは位置 1 と 3 にあります。ここで、外側の値は次のとおりです。`-2`そして`2`, そのため、1回の操作で十分です。 正しい答えは、`1`。 

これらの例は、答えが負のエッジの位置と 2 つの境界値間の 1 回の比較に依存することを示唆しています。 

## アプローチ

 ブルートフォースの観点では、すべての操作を間隔を選択し、その中の値を変更するものと考えることです。 すべての可能な間隔、すべての可能な操作シーケンスをモデル化し、最小カウントを検索することもできます。 

そのアプローチはすぐに崩れます。 がある$O(n^2)$一定間隔で操作を繰り返すことができ、状態空間は膨大です。 

重要な点は、操作によって区間境界に接する 2 つのエッジのみが変更されるということです。 

選択するとします$[l,r]$。 

厳密に間隔の内側にあるすべてのエッジは、その操作中、元の符号を永久に保持します。 端だけ$(l-1,l)$そしてエッジ$(r,r+1)$変更される可能性があります。 

これは、1 回の操作で最大 2 つの負のエッジを削除できることを意味します。 させて$m$は負のエッジの数になります。 それから：$$\text{answer} \ge \left\lceil \frac{m}{2} \right\rceil.$$問題全体は次のようになります。 

この下限を常に達成できるでしょうか?

 もし$m$奇妙ですが、答えは「はい」です。 

もし$m$は偶数ですが、答えは「はい」の場合もあれば、1 つ大きい場合もあります。 

残りのタスクは、下限がいつ達成可能になるかを正確に特徴付けることです。

 ## アルゴリズムのチュートリアル

 負のエッジを位置に置く$$d_1 < d_2 < \dots < d_m.$$ここ$d_i$手段$a_{d_i} > a_{d_i+1}$。 

### 1. 負のエッジを数える

 彼らの数を数えてみましょう$m$。 

もし$m=0$、配列はすでに厳密に増加しているため、答えは次のようになります。`0`。 

### 2. 奇妙なケースに対処する

 もし$m$奇妙です、答えは$$\frac{m+1}{2}.$$下限は、最初の操作で 1 つの負のエッジを削除し、その後、残りの負のエッジを一度に 2 つずつ削除することで達成できます。 

### 3. 偶数の場合を処理する

 しましょう$$k = \frac{m}{2}.$$正確に達成するには$k$演算では、すべての演算で 2 つの負のエッジを正確に削除する必要があります。 

これにより、最初のネガティブ エッジと最後のネガティブ エッジが構造全体の 2 つの外側境界として残ります。 それらの隣接する外側の値は次のとおりです。$$x = a_{d_1}, \qquad y = a_{d_m+1}.$$これら 2 つの値は、正確に使用する戦略の不変条件になります。$k$操作。 

### 4. 不変式を確認する

 もし$$x < y,$$その後、すべての負のエッジを 2 つずつペアにしながら、それらの間の領域全体を厳密に増加するシーケンスに再構築できます。 下限$k$達成可能です。 

もし$$x \ge y,$$その場合、そのような厳密に増加する橋は不可能です。 追加の操作が 1 つ必要です。 

それで：$$\text{answer} = \begin{cases} k, & x < y,\\ k+1, & x \ge y. \end{cases}$$### なぜ効果があるのか

 ネガティブ エッジは、何らかの操作の境界エッジになる場合にのみ消滅します。 1 つの操作には境界が 2 つしかないため、最大 2 つのネガティブ エッジを削除できます。 これにより下限が得られます$\lceil m/2 \rceil$。 

いつ$m$が奇数である場合、その下限は常に一致する可能性があります。 

いつ$m$が偶数である場合、下限と一致する場合、すべての操作で 2 つの負の値を正確に除去する必要があることを意味します。 その状況では、最初の負のエッジの隣の左側の値と最後の負のエッジの隣の右側の値は変更できません。 最終的な厳密に増加する構築では、これら 2 つの固定値を接続する必要があります。 

もし$a_{d_1} < a_{d_m+1}$、そのような接続が存在し、下限は達成可能です。 

もし$a_{d_1} \ge a_{d_m+1}$、厳密に増加するシーケンスは左側の値で開始し、右側の値で終了することはできないため、もう 1 回の操作は避けられません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        desc = []
        for i in range(n - 1):
            if a[i] > a[i + 1]:
                desc.append(i)

        m = len(desc)

        if m == 0:
            ans.append("0")
            continue

        if m & 1:
            ans.append(str((m + 1) // 2))
        else:
            k = m // 2
            first = desc[0]
            last = desc[-1]

            if a[first] < a[last + 1]:
                ans.append(str(k))
            else:
                ans.append(str(k + 1))

    sys.stdout.write("\n".join(ans))

solve()
```実装には負のエッジの位置のみが必要です。`desc`すべてのインデックスを保存する`i`そのような`a[i] > a[i+1]`。 

カウントが奇数の場合、式は即時に実行されます。 

カウントが偶数の場合は、最初の負のエッジのすぐ左側の値と最後の負のエッジのすぐ右側の値を調べます。 これら 2 つの値を比較することで、下限を達成できるかどうかが決まります。 

最も間違いやすいインデックス作成の詳細は、正しいエンドポイントです。 最後の負のエッジが 位置にある場合`i`、右の境界値は`a[i + 1]`となり、`a[last + 1]`ゼロベースのインデックス付けで。
