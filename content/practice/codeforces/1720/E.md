 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times n$整数のグリッド。 各セルには最初に何らかの値が含まれており、任意の正方部分行列を選択し、その中のすべてのセルを選択した 1 つの整数で上書きする操作を実行できます。 このような正方形の再描画操作を任意の数だけ適用した後の最終目標は、グリッドに正確な内容が含まれるようにすることです。$k$明確な価値観。 

重要なのは、最終的な値そのものではなく、元の行列を次の構成に折りたたむのに必要な操作の数です。$k$異なる整数はグリッド内のどこにでも残ります。 各操作は正方形の領域に任意の値を自由に割り当てることができるため、以前の多くの値を同時に破棄することができますが、後で導入される他の値と重複する可能性のある新しい値を導入する可能性もあります。 

制約$n \le 500$までを暗示$2.5 \cdot 10^5$細胞。 考えられるすべての部分行列を調べたり、すべての変換を明示的に試行したりするソリューションは、大規模すぎます。 立方体のものなら何でも$n$オペレーションごとの実行は直ちに不可能であり、$O(n^3)$総仕事量はボーダーラインです。 

重要な点は、操作が任意の長方形ではなく正方形に制限されていることです。 この制限により、通常の「接頭辞長方形 DP」スタイルの単純化が妨げられ、カバー構造の観点から考える必要が生じます。 

素朴な推論を打ち破る重要なエッジ状況が 2 つあります。 まず、最初のグリッドがすでに正確に設定されている場合、$k$個別の値の場合、答えはゼロですが、不注意な貪欲なマージによって不必要な操作が実行される可能性があります。 第二に、いつ$k = 1$の場合、最適な答えは、初期構成に関係なく、常に 1 つの操作 (行列全体をペイントする) です。 構造を保持する必要があることを前提とした解決策は、このケースを過度に複雑にしてしまいます。 

## アプローチ

 ブルートフォースの観点は、各操作を正方形の領域を選択し、それを選択した値に統合することを決定するものと考えることです。 このような操作のすべてのシーケンスを試し、一連の個別の値がどのように変化するかを追跡することを想像することもできます。 各操作が非ローカルな方法で前の操作と相互作用するため、これは急速に指数関数的になります。後の四角形が前の四角形を部分的に上書きし、効果的にレイヤー化された描画プロセスを作成する可能性があります。 

重要な観察は、最終目標は、そのアイデンティティではなく、どれだけ多くの値が生き残るかによってのみ決まるということです。 前向きに推論する代わりに、視点を逆にします。区別されたままの各値には、別の値の最終カバー領域によって決して上書きされないセルが少なくとも 1 つ必要です。 これは、代表者を選出し、その周囲の地域を拡大するという観点から考えることを示唆しています。 

ここで重要な構造の単純化は、「保持」することを決定した値は、二乗展開によって形成される接続された領域を占有することができるということです。 個別の値の数を減らすことだけを考慮しているため、不要な値を保持された値にマージするために必要な操作の数を最小限に抑えたいと考えています。 

これをより正確に理解するには、各操作でセルの接続コンポーネント全体を (正方形のカバレッジの影響下で) 削除できますが、それは非常に構造化された方法でのみであるということです。 最適な戦略は、正確に到達するまで領域を繰り返しマージすることです。$k$接続された「値グループ」は、正方形のオーバーラップを介して影響を共有するセル上の派生隣接構造に残ります。 

これにより、問題は、値に対するグラフのような構造を計算し、コンポーネントの数を初期の個別の値の数から最小の数まで減らすために必要なマージの数を決定することに変換されます。$k$。 各操作は効果的に「アクティブ コンポーネント」の数を最大 1 つ削減します。これは、正方形到達可能性の制約によって引き起こされる正しいコンポーネント構造を特定すると、直接的な式につながります。 

最後の重要なステップは、2 つの値の出現を含む正方部分行列が存在する場合に、2 つの値が接続されていることを認識することです。 これにより、正方形のカバレッジの空間的実現可能性に基づいて、値に対する和集合検索構造が誘導されます。 コンポーネントが形成されたら、その数を減らすだけで済みます。$k$、各マージは 1 つの操作に対応します。

 ## アルゴリズムのチュートリアル

 1. まず、行列内に存在するすべての個別の値を収集します。 目的は個別の値の数を減らすことであるため、各値をグラフ内のノードとして扱います。 
2. 幾何学的実現可能性を使用して値間の接続性を構築します: 2 つの値の場合$x$そして$y$、少なくとも 1 つの出現を含む正方部分行列が存在するかどうかを確認します。$x$そして1回の発生$y$。 その場合は、1 回の操作でそれらをマージできます。 
3. これを効率的にテストするために、各値の座標を前処理し、マンハッタン制約の境界正方形が有効な部分正方形部分行列内に収まる 2 つの出現が存在するかどうかを確認することに問題を落とし込みます。 これは、ソートされた座標リストと区間交差ロジックを使用して実装できます。 
4. すべての値に対して Union-find 構造を実行します。 正方形の領域内で 2 つの値が共存できると判断した場合は、それらを結合します。 
5. すべての結合の後、値間の連結成分の数を計算します。 これをそのままにしておきます$C$。 
6. 各連結コンポーネントは、正方形の再描画操作を繰り返すことで 1 つにマージできる一連の値を表します。 したがって、削減する必要があります$C$まで$k$、各操作によりコンポーネントの数は最大で 1 つずつ減ります。 
7. したがって、答えは次のとおりです。$\max(0, C - k)$。 

### なぜ効果があるのか

 正確かどうかは、どの演算でも 1 つの正方部分行列で同時にカバーできる値のみを統合できるという事実にかかっており、そのような実現可能性が和集合検索グラフのエッジを正確に定義します。 値が相互にカバー可能な最大のセットに分割されると、マージあたりの操作数が 1 つ未満になるような方法でコンポーネント間で操作を分離したり、部分的にマージしたりすることはできません。 これにより、不変条件が生じます。各操作の後、接続された値コンポーネントの数は最大 1 つ減少し、有効な操作は、コンポーネントのそのような 1 つのペアを正確にマージすることに対応します。 したがって、最小操作数は、正確に、初期コンポーネント数を$k$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    grid = [list(map(int, input().split())) for _ in range(n)]
    
    coords = {}
    for i in range(n):
        for j in range(n):
            v = grid[i][j]
            if v not in coords:
                coords[v] = []
            coords[v].append((i, j))
    
    vals = list(coords.keys())
    idx = {v:i for i, v in enumerate(vals)}
    
    parent = list(range(len(vals)))
    
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    
    def union(a, b):
        ra, rb = find(a), find(b)
        if ra != rb:
            parent[rb] = ra
    
    # Check if two values can be covered together by a square submatrix
    def can_merge(v1, v2):
        c1 = coords[v1]
        c2 = coords[v2]
        for x1, y1 in c1:
            for x2, y2 in c2:
                r1, r2 = min(x1, x2), max(x1, x2)
                cmin, cmax = min(y1, y2), max(y1, y2)
                if r2 - r1 == cmax - cmin:
                    return True
        return False
    
    for i in range(len(vals)):
        for j in range(i + 1, len(vals)):
            if can_merge(vals[i], vals[j]):
                union(i, j)
    
    comps = len({find(i) for i in range(len(vals))})
    print(max(0, comps - k))

if __name__ == "__main__":
    solve()
```このソリューションでは、まずすべてのセル位置を値ごとにグループ化し、幾何学的な推論が個別の整数ごとに行われるようにします。 Union-Find 構造は、少なくとも 1 つの有効な正方部分行列を介してどの値をマージできるかを維持します。 

機能`can_merge`各値から 1 つずつ出現のペアが存在するかどうかをチェックします。その結果、それらを含む軸に沿った最小の正方形が有効になります。つまり、その高さと幅が等しいことを意味します。 This encodes whether a square submatrix can include both values simultaneously.

 Finally, we count connected components of values and subtract$k$なぜなら、各操作は個別の値コンポーネントの数を最大 1 つ減らすことができるからです。 

微妙な点は、値のすべてのペアを反復処理することですが、個別の値の数は最大でも$n^2$、しかし実際には、結合ステップは座標の比較によって支配されます。

 ### 例 1

 入力:```
3 4
1 1 1
1 1 2

```個別の値をリストします: {1,2,3,4,5}。 どのペアが共通の正方部分行列に現れるかを確認します。 

| ペア | マージ可能 | 理由 |
 | --- | --- | --- |
 | (1,2) | はい | 両方とも左上の 2x2 の正方形に表示されます。 
| (その他) | いいえ | | 両方を含む正方形はありません。 

Union 検索の結果、コンポーネント: {1,2}、{3}、{4}、{5} が得られます。 それで$C = 4$。 

ターゲット$k = 4$、したがって、答えは$C - k = 0$。 

これにより、1 と 2 をマージできても、個別の値の数をさらに減らす必要がないことがわかります。

コンポーネント: {1,2}、{3}、{4}、{5} が見つかりました。$C = 4$。 

| ステップ | コンポーネント |
 | --- | --- |

 答えは$4 - 2 = 2$これは、2 つの余分な値グループを削除する必要があるという直観と一致します。 

このトレースは、アルゴリズムが空間密度ではなく、値間の接続性によって完全に駆動されていることを示しています。

 ## 特殊なケース

 グリッドにセルが 1 つしかない場合、アルゴリズムはただちに単一の値コンポーネントを見つけるため、次の場合には操作の数はゼロになります。$k = 1$。 マージを実行しようとすると、誤ってカウントが増加しますが、コンポーネントの計算によりそれが防止されます。 

すべての値がすでに同一である場合、union-find 構造は単一のコンポーネントを生成します。 たとえアルゴリズムが多数の潜在的なマージを検出したとしても、それらはすべて 1 つのルートに集約され、最終的な減算は$k$誤った操作がカウントされないことを保証します。 

いつ$k = 1$の場合、アルゴリズムはコンポーネントの数から 1 を引いた値を正しく返します。これは、すべての値グループを単一の最終ペイント値に折りたたむことに対応します。
