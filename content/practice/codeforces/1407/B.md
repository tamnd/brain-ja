 ## 解決策
 ## 問題の理解

 正の整数のシーケンスが与えられているので、それらをシーケンスに並べ替える必要があります。$b$プレフィックスの最大公約数のシーケンスが$c_i = \gcd(b_1, b_2, \dots, b_i)$は辞書編集上最大です。 言い換えれば、各位置で、他の順序と比較して、左端の異なる位置で実行中の GCD をできるだけ大きくする必要があります。 

入力は複数のテスト ケースで構成され、それぞれのテスト ケースは比較的小さいシーケンス ($n \le 10^3$) とそれに囲まれた数値$10^3$。 全部の合計だから$n$テストケース全体で次を超えない$10^3$、$O(n^2)$テストケースごとのソリューションは許容されます。 

明らかではないエッジケースは、複数の数値が因数を共有しているもののサイズが異なる場合に発生します。 たとえば、シーケンスが次の場合、`[4, 2, 8]`、最初に 8 を選択するとプレフィックス GCD が生成されるため、常に最大の数値を最初に選択する単純なアプローチは失敗する可能性があります。`[8, 2, 2]`、一方、4 から始めると、`[4, 2, 2]`。 ここで、貪欲なステップでは、各候補の現在の GCD を考慮し、結果の GCD を最大化するものを選択する必要があります。 単一要素のシーケンス、すべての数値が等しいシーケンス、および 1 を含むシーケンスも正しく処理する必要があります。 

## アプローチ

 ブルートフォースメソッドは、すべてを生成することです。$n!$シーケンスの順列を計算し、それぞれのプレフィックス GCD シーケンスを計算し、辞書編集上最大のプレフィックス GCD シーケンスを生成する順列を選択します。 これは、考えられるすべての順序を検討するため正しいですが、$n = 10$、 として$10! = 3.6 \cdot 10^6$演算、GCD シーケンスの計算によりさらにオーバーヘッドが追加されます。 

最適なソリューションを実現するための重要な洞察は、プレフィックス GCD シーケンスが増加していないことです。$\gcd(b_1, \dots, b_{i+1}) \le \gcd(b_1, \dots, b_i)$。 したがって、最大化するには最初の要素が常に最大の数値である必要があります。$c_1$。 最初の要素の後の各ステップで、現在のプレフィックス GCD と組み合わせたときに GCD を最大化する番号を残りのプールから選択します。 この貪欲なアプローチは、辞書編集的な比較が主に左端の要素に依存するため有効です。各ステップで現在の GCD を最大化すると、シーケンスの前半でより小さい GCD が出現することがなくなります。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * n) | O(n) | 遅すぎる |
 | 最適な貪欲さ | O(n^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取り、各ケースをループします。 
2. 各テスト ケースについて、シーケンスを読み取ります。$a$そして空の結果リストを初期化します$b$。 
3. 内の最大の数値を選択します。$a$の最初の要素として$b$。 これにより、最初のプレフィックス GCD が最大になることが保証されます。 プールから取り出します。 
4.初期化`current_gcd`最初の要素の値として。 
5. プールに数値が残っている間、それらを反復処理して、次の GCD を計算します。`current_gcd`それぞれの候補者と一緒に。 この GCD を最大化する数値を選択します。 に追加します$b$そして更新します`current_gcd`。 選択した番号をプールから削除します。 
6. すべての数字が入力されるまで繰り返します。$b$。 出力$b$。 

機能する理由: 各ステップで、アルゴリズムは、これまでに生成されたプレフィックス GCD シーケンスが残りの数値の順序と比較して辞書編集上最大であるという不変条件を維持します。 プレフィックス GCD は増加しないため、各ステップをローカルで最大化すると、グローバルな辞書編集上の最大値が保証されます。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        used = [False] * n
        b = []
        # Step 1: pick the largest number first
        max_idx = a.index(max(a))
        b.append(a[max_idx])
        used[max_idx] = True
        current_gcd = a[max_idx]

        for _ in range(1, n):
            best_gcd = -1
            best_idx = -1
            for i in range(n):
                if not used[i]:
                    g = math.gcd(current_gcd, a[i])
                    if g > best_gcd:
                        best_gcd = g
                        best_idx = i
            b.append(a[best_idx])
            used[best_idx] = True
            current_gcd = best_gcd
        print(*b)

if __name__ == "__main__":
    solve()
```このコードは、最初のプレフィックス GCD を最大化するため、最初に最大の数値を選択します。 の`used`配列は、重複を避けるためにどの番号がすでに選択されているかを追跡します。 内側のループは、貪欲不変式を反映して、現在のプレフィックスで最も高い GCD を与える数値を選択します。 使用する`math.gcd`正確さを保証し、手動による GCD 計算を回避します。
