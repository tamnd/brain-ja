 ## 解決策
 ## 問題の理解

 私たちは、夜道と朝道という 2 種類の道路で結ばれた都市の有向グラフを通じてエゴールの移動を制御するように求められます。 各都市には、黒 (夜) または白 (朝) の色を割り当てることができます。 エゴールは、その色と一致する道路に沿ってのみ都市を離れることができます。 管理者の仕事は、都市 1 から都市 n までの最短経路の長さを最大化するか、可能であれば都市 n にまったく到達できないように都市の色を割り当てることです。 

入力は最大 500,000 の都市と 500,000 の道路で構成されており、O(n + m) よりも複雑なソリューションは即座に除外されます。 n または m のいずれかで 2 次のグラフ アルゴリズムは遅すぎます。 複数の道路が同じ都市のペアを接続でき、自己ループも許可されます。 エッジ ケースには、外向きのエッジがない都市、完全に切断されたグラフ、または都市に割り当てられた色に対して「間違った」タイプである都市からのすべての道路が含まれます。 

たとえば、都市 1 に夜間と朝の外向き道路がある場合、これを白に割り当てると、すぐに夜間道路を使用できなくなります。 都市 n にすべての進入道路と互換性のない色が割り当てられている場合、その経路は完全にブロックされる可能性があります。 複数の道路タイプや自己ループを無視した不注意なアプローチは、実際に可能よりも短いパスを報告したり、すべてのパスをブロックする可能性を見逃したりする可能性があります。 

## アプローチ

 ブルートフォースアプローチは、2^n 個の可能な色の割り当てをすべて試し、それぞれの最短パスを計算することです。 2^500,000 は天文学的に大きいため、これは明らかに実行不可能です。 小さなサブグラフに対して色付けのすべての順列を試しても時間がかかりすぎます。 このブルート フォースは、すべてのカラーリングを徹底的にチェックすることで正確性を保証するため機能しますが、指数関数的な複雑さのため、大きな n については完全に失敗します。 

重要な観察は、この問題は 2 回の BFS トラバーサルで解決できるということです。 ソース都市の色がエッジ タイプと一致する場合にのみエッジがアクティブになる有向グラフとしてグラフを扱うことを検討してください。 最短経路を最大化するために貪欲に色を割り当てる場合、都市の外に出るエッジの大多数のタイプと反対の色を選択すると横断が遅れるという事実を利用して、最長の最小距離を計算できます。 

最適なソリューションでは、都市 n への最速パスを回避する色を各都市に割り当てます。 最長の最短パスを計算するために、都市 n から開始して後方 BFS を実行し、両方の種類の道路に沿った各ノードの都市 n に到達する最小距離を個別に記録します。 次に、都市ごとに、より短い距離につながるエッジをブロックする色を割り当て、効果的にエゴールをより長いパスに沿って移動させます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * (n + m)) | O(n + m) | 遅すぎる |
 | 最適な BFS ベース | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つの隣接リストを作成します。1 つはタイプ 0（夜間）の発信エッジ用で、もう 1 つはタイプ 1（朝）用です。 また、都市 n から逆方向に BFS を実行する逆隣接リストも作成します。 逆エッジは、各タイプに沿って任意の都市から都市 n までの最小距離を計算するのに役立ちます。 
2. 2 つの距離配列を初期化する`dist0`そして`dist1`から無限大まで、それぞれタイプ 0 またはタイプ 1 の道路に沿って始まるパスを使用して都市 n までの最短距離を表します。 セット`dist0[n]`そして`dist1[n]`ゼロに。 
3. タイプ 0 のエッジに沿って逆方向に BFS を実行して埋める`dist0`。 タイプ 0 エッジを介してノード v からノード u に到達するたびに、次のように設定します。`dist0[v] = min(dist0[v], dist0[u] + 1)`。 タイプ 1 のエッジを埋めるために繰り返します`dist1`。 
4. 都市ごとに、最短経路を最大化する色を割り当てます。 もし`dist0[u] >= dist1[u]`、黒 (0) を選択すると、パスはタイプ 0 のエッジを使用する必要があります。 それ以外の場合は、白 (1) を選択して、タイプ 1 エッジを強制的に通過します。 これにより、Egor がより長いパスに沿って押し込まれるか、距離の 1 つが無限である場合に完全にブロックされることが保証されます。 
5. 選択したカラーリングを使用して都市 1 からの最短経路長を計算します。 ソース都市に割り当てられた色と同じタイプのエッジを考慮します。 都市 n に到達できない場合は、-1 を返します。 それ以外の場合は、許可されたエッジに沿った長さを返します。 
6. すべての都市の最短パス長と割り当てられた色を出力します。 

このアルゴリズムは、BFS 距離が両方の道路タイプに沿った任意のノードから都市 n までの可能な最小距離をエンコードしているため、最短経路を最大化する、または Egor を完全にブロックするカラーリングを見つけることを保証します。 短い距離の反対の色を選択することで、より長いルートに沿って強制的に横断します。 

## Python ソリューション```python
import sys
from collections import deque
input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[], []]  # adj[0] for night, adj[1] for morning
rev_adj = [ [[] for _ in range(n + 1)] , [[] for _ in range(n + 1)] ]

for _ in range(m):
    u, v, t = map(int, input().split())
    adj[t].append((u, v))
    rev_adj[t][v].append(u)

INF = n + 5
dist = [[INF] * (n + 1) for _ in range(2)]
queue = [deque(), deque()]

# BFS from n for both edge types
for t in range(2):
    dist[t][n] = 0
    queue[t].append(n)
    while queue[t]:
        u = queue[t].popleft()
        for v in rev_adj[t][u]:
            if dist[t][v] == INF:
                dist[t][v] = dist[t][u] + 1
                queue[t].append(v)

# choose colors
color = [0] * n
for i in range(1, n + 1):
    if dist[0][i] >= dist[1][i]:
        color[i-1] = 0
    else:
        color[i-1] = 1

# BFS from 1 along allowed edges
d1 = [INF] * (n + 1)
d1[1] = 0
q = deque([1])
while q:
    u = q.popleft()
    for t, v in adj[ color[u-1] ]:
        if t == color[u-1] and d1[v] == INF:
            d1[v] = d1[u] + 1
            q.append(v)

ans_len = d1[n] if d1[n] != INF else -1
print(ans_len)
print("".join(map(str, color)))
```コードはまず、各エッジ タイプの隣接リストと都市 n からの BFS の逆リストを構築します。 各エッジ タイプに沿った最小距離を満たします。 色の割り当てにより、より長いルートに沿った横断を強制するタイプが選択されます。 最後の BFS は、割り当てられた色を使用して最短パスを計算します。 BFS でのエッジ選択により、安全な道路のみが考慮されるようになり、INF 距離によって到達不能なノードが正確に識別されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + m) | 各エッジ タイプに沿って都市 n から BFS を 2 回、次に 1 から BFS を 1 回 |
 | スペース | O(n + m) | 隣接リスト、逆隣接リスト、距離、およびカラー配列の保存 |

 線形グラフの走査は競技プログラミングの制限内で許容されるため、これは n、m ≤ 500,000 の場合 2 秒以内に収まります。
