 ## 解決策
 ## 問題の理解

 を構築するように求められています。$n \times n$行と列のビットごとの XOR に対する 2 つの同時制約と全体の合計制約を備えた 0 と 1 の行列。 具体的には、偶数を与えると、$n$そして目標の 1 の数$k$、すべての行が同じ XOR 値を持ち、すべての列が同じ XOR 値を持ち、1 の合計数が正確に一致する行列を構築する必要があります。$k$、またはそれは不可能であると報告します。 各テスト ケースは次のように指定します$n$そして$k$、複数のテストケースがある場合があります。 

サイズの制約、$2 \le n \le 1000$すべての合計で$n$2000 を上限とするテスト ケース全体で、最大 2000 のアルゴリズムを使用できます。$O(n^2)$すべてのテスト ケースで処理されるセルの総数はおおよそ次のとおりであるため、テスト ケースごとに$2 \times 10^6$。 The evenness of$n$XOR プロパティは偶数長のシーケンスでは異なる動作をするため、これは重要です。偶数の同一ビットの XOR は 0 であり、これは行と列のバランスをどのようにとれるかをすぐに示唆します。 

エッジケースには以下が含まれます$k = 0$そして$k = n^2$ここで、行列はそれぞれ完全に 0 または完全に 1 です。 たとえば、対角線に沿ったものだけを埋める不注意な解決策は、小さなサイズでは失敗する可能性があります。$k$または大きい$k$一部の行または列に奇数の 1 があり、他の行または列には 1 が含まれていない場合、XOR プロパティに違反するため、行または列全体に 1 が必要な値。 もう一つの微妙なケースは次のような場合です。$k$で割り切れない$n$これにより、行または列全体に 1 を均等に分散できなくなる可能性があります。 

## アプローチ

 ブルートフォースアプローチは簡単ですが、非効率的です。 あらゆる可能な配置を試すことができます$k$中のもの$n \times n$グリッドを調べて、行と列の両方の XOR 制約を確認します。 がある$\binom{n^2}{k}$控えめな人でも天文学的に大きいものを配置する方法$n$、これを実行不可能にします。 

重要な洞察は、偶数長シーケンスに対する XOR の特性から得られます。 もし$n$は偶数であり、偶数の 1 を含む行または列は XOR 0 となり、奇数の 1 を含む行または列は XOR 1 になります。 これにより、すべての順列をチェックすることなく、行と列の XOR を推論することができます。 具体的には、行列を「斜めストライプ」パターンで埋めると (行と列ごとに最大 1 つの 1 を周期的に配置します)、すべての行と列にわたって均一な XOR を実現できます。 このパターンに配置できる 1 の最大数は次のとおりです。$n \times n / n = n$対角層ごとに、到達するには$k$, 目標合計に達するまで、レイヤー全体で斜めの塗りつぶしプロセスを繰り返します。 アルゴリズムは効率的に機能します$O(n^2)$また、すべての行と列が 2 を法とする同じ数の 1 を受け取るため、均一な XOR 値が保証されます。

 ## アルゴリズムのチュートリアル

 1. まずは次のことを確認します。$k > n^2$。 その場合は、1 の合計がセルの総数を超えることはできないため、すぐに No を返します。 
2. を初期化します。$n \times n$ゼロの行列。 
3. ラウンドロビン循環方式で対角に沿って配置します。 具体的には、カウンターを反復します。`i`0から$k-1$。 それぞれについて`i`、位置を行として計算します`i % n`そしてコラム`(i + i // n) % n`。 これにより、モジュロを使用してすべての行と列に均等に分散されることが保証されます。$n$。 
4.充填後$k$1、すべての行とすべての列に次のいずれかが含まれます`k // n`または`k // n + 1`1 です。これにより、各行と列の XOR が同じになることが保証されます。$n$は均等です。 
5. Output Yes and print the resulting matrix.

 The reason this works is that each row and column receives ones in a balanced cyclic pattern, and the evenness of$n$各行と列に同じ数の 1 があることにより、XOR が同一であることが保証されます。 分布モジュロ 2 は均一であるため、誤って XOR 制約に違反するリスクはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        if k > n * n:
            print("No")
            continue
        matrix = [[0] * n for _ in range(n)]
        for i in range(k):
            row = i % n
            col = (i // n + i) % n
            matrix[row][col] = 1
        print("Yes")
        for row in matrix:
            print(" ".join(map(str, row)))

if __name__ == "__main__":
    solve()
```解決策は、テスト ケースの数を読み取ることから始まります。 各テスト ケースでは、まず、要求された 1 の数がセルの総数を超えているかどうかを確認します。 次に、ゼロ行列を初期化し、周期的に対角に沿って 1 を埋めます。 式`(i // n + i) % n`は、各行と列にほぼ同じ数の 1 が含まれるように 1 が斜めに回転され、すべての行と列で均一な XOR が維持されます。
