 ## 解決策
 ## 問題の理解

 ツリーに表示される必要があるすべてのエッジの長さが与えられます。 木にはまさに$n$エッジと$n+1$したがって、配列のすべての長さがエッジの重みとして 1 回だけ使用されます。 

問題は、これらのエッジを接続して、重み付けされた直径が正確に一致するツリーを作成できるかどうかです。$d$。 

この問題を考えるのに役立つ方法は、すべての木の直径が単純なパスであるということです。 木に直径がある場合$d$の場合、ツリー内のどこかに、全長が正確に一致するパスが存在する必要があります。$d$、そして他のすべてのエッジは、より長いパスを作成せずにそのパスに接続されます。 

重量の点での制約は驚くほど小さいです。 両方$d$そしてすべての$l_i$せいぜい$2000$、およびすべての合計$n$入力を超えるものも最大です$2000$。 これは、値に対するある種のサブセット合計またはナップザック動的プログラミングを直ちに示唆します。$d$。 アン$O(nd)$または$O(nd^2 / 64)$解決策は完全に合理的ですが、指数関数的なサブセットの列挙は不可能です。 

単純な構築を容易に誤解させる可能性がある、自明ではない状況がいくつかあります。 

考慮する：```
n = 2
d = 5
lengths = [3, 3]
```正しい答えは、`No`。 

2 つの端を持つ木は単なる道です。 その直径は$3+3=6$、すでにより大きい$d$。 一部のサブセットの合計が以下になるかどうかだけをチェックする単純なアプローチ$d$これは見逃すでしょう。 

別の例:```
n = 3
d = 10
lengths = [6, 2, 2]
```正しい答えは、`Yes`。 

長さの端を使用する$6$直径に関しては。 残りの 2 つのエッジは、ある長さのパスを形成します$4$、長さの直径を生成します$10$。 最大のエッジを持たずに直径を構築することに固執する戦略は、このケースを誤って拒否することになります。 

より微妙なケースは次のとおりです。```
n = 4
d = 10
lengths = [4, 4, 4, 4]
```正しい答えは、`No`。 

多くのサブセットの合計は次のようになりますが、$10$、すべての未使用のエッジには長さがあります$4$。 長さの直径上の任意の接続点$10$せいぜい距離にある$5$1 つの端点からの長さを付加するため、$4$エッジは、より長いパスを簡単に作成できます。$10$。 サブセットの合計だけでなく、直径の形状も重要です。 

## アプローチ

 ブルート フォース ソリューションでは、エッジのすべてのサブセットが直径パスの候補として試行されます。 サブセットの合計が次の場合$d$、その後、直径を増やさずに残りのエッジを接続できるかどうかを確認できます。 

これはもう絶望的です。 がある$2^n$サブセット、および$n$到達できる$2000$。 

重要な観察は、直径に属さないすべてのエッジのうち、実際に重要なのは最大のエッジだけであるということです。 

最大の辺の長さを次のようにします。$M$。 

すでに全長の直径パスを構築していると仮定します。$d$。 残りのエッジはすべて、そのパス上の 1 つの頂点にアタッチできます。 より長い直径を作成せずに最大の未使用エッジを取り付けることができる場合は、すべての小さな未使用エッジもそこに取り付けることができます。 

これにより、直径パスと適切なアタッチメント頂点を見つける問題が軽減されます。 

もう 1 つの重要な観察は、2 つの最大エッジ長が次の条件を満たしている場合です。$$l_n + l_{n-1} > d,$$そうすれば答えはすぐに出ます`No`。 

どの木にもこれら 2 つのエッジを通過するパスが含まれており、そのパスはすでに$d$。 

長さを並べ替えたら、$M=l_n$。 

最大のエッジを他のエッジから分離し、DP を実行します。 DP は残りのエッジを 3 つのグループに分割します。 

まず、選択したアタッチメント頂点の片側にエッジを配置します。 

2 番目に、反対側にエッジを配置します。 

第三に、直径にエッジが使用されていません。 

2つの辺に長さがある場合$x$そして$y$の場合、結果として得られる直径の長さは次のようになります。$x+y$。 

未使用の最大エッジには長さがあります$M$。 安全にアタッチするには、アタッチ頂点が少なくとも離れている必要があります$M$直径の両端から。 つまり、$$x \ge M,\qquad y \ge M.$$唯一の特別なケースは、最大エッジ自体が直径上にある場合に発生します。 あとは残りの長さを形成するだけです$d-M$他のエッジを使用します。 

DP 状態は当然、2 次元の部分集合和になります。 なぜなら$d \le 2000$、ビットセット実装により十分に高速になります。

 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^n)$|$O(n)$| 遅すぎる |
 | 最適なビットセット DP |$O(nd^2/64)$|$O(d^2/64)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのエッジの長さを並べ替えます。 
2. しましょう$M$最大の長さになります。 
3. 最大の長さ 2 つの合計が 2 を超える場合$d$、出力`No`。 

どの木の直径も必然的に次の値よりも大きくなります。$d$。 
4. 無視する$M$一時的に他のものを処理する$n-1$DPとの長さ。 
5. 定義する`dp[a][b]`将来の直径の片側が全長になるように処理されたエッジを分散できるかどうか$a$反対側は全長です$b$。 

すべてのエッジには 3 つの選択肢があります。 

1面目に追加可能です。 

2面目にも追加可能です。 

未使用のままでも構いません。 
6. 2 番目の次元をビットセットとして保存します。 

エッジに長さがある場合$w$、遷移は次のとおりです。 

2番目の面に置きます:$$dp[a] \gets dp[a] \;|\; (dp[a] \ll w)$$それを最初の面に置きます。$$dp[a] \gets dp[a] \;|\; dp[a-w]$$7. を除くすべてのエッジを処理した後$M$、2つの可能性を確認してください。 
8. 最初の可能性:$M$直径に属します。 

次に、残りのエッジが長さを形成する必要があります$d-M$。 

かどうかを確認してください$$dp[d-M][0]$$到達可能です。 
9. 2番目の可能性:$M$直径には属しません。 

次に、長さの直径が必要です$d$アタッチメント頂点の周囲で分割します。 

存在するかどうかを確認する$$x+y=d$$と$$x\ge M,\qquad y\ge M,$$そして`dp[x][y]`到達可能な。 
10. いずれかの条件が成功した場合、出力`Yes`; それ以外の場合は出力`No`。 

### なぜ効果があるのか

 すべての有効なツリーは、直径以外のすべてのエッジが直径上の 1 つの頂点に接続されているツリーに変換できます。 直径以外の最大のエッジのみが新しい長いパスを作成できる可能性があるため、このエッジが安全に取り付けられることを確認するだけで十分です。 

最大のエッジ自体が直径上にある場合は、残りの直径の長さを完了するだけで済みます。$d-M$。 

直径上にない場合、アタッチメント頂点は少なくとも距離離れている必要があります$M$直径の両端から。 それらの距離を次のように書くと、$x$そして$y$、条件を取得します$x+y=d$、$x\ge M$、 そして$y\ge M$。 

DP は、可能なすべてのペアを正確に列挙します。$(x,y)$残りのエッジから取得できます。 したがって、アルゴリズムは、必要かつ十分な構造の 1 つが存在する場合を正確に受け入れます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n, d = map(int, input().split())
        a = list(map(int, input().split()))
        a.sort()

        if a[-1] + a[-2] > d:
            print("No")
            continue

        dp = [0] * (d + 1)
        dp[0] = 1  # bit 0 set

        for w in a[:-1]:
            ndp = dp[:]

            for x in range(d, -1, -1):
                cur = dp[x]
                if cur == 0:
                    continue

                # put w on second side
                ndp[x] |= cur << w

                # put w on first side
                if x + w <= d:
                    ndp[x + w] |= cur

            mask = (1 << (d + 1)) - 1
            for i in range(d + 1):
                ndp[i] &= mask

            dp = ndp

        m = a[-1]

        ok = False

        if d - m >= 0:
            ok |= ((dp[d - m] >> 0) & 1) != 0

        for x in range(m, d - m + 1):
            if ((dp[x] >> (d - x)) & 1):
                ok = True
                break

        print("Yes" if ok else "No")

if __name__ == "__main__":
    solve()
```最大のエッジが特別な役割を果たすため、配列は最初にソートされます。 

早期の拒否`a[-1] + a[-2] > d`不可能なケースを即座に排除します。 

DP はビットセットの配列を使用します。 索引`x`の到達可能なすべての値を格納します`y`。 各エッジは無視することも、最初の辺に追加することも、2 番目の辺に追加することもできます。 以前の DP のコピーから開始するため、「無視」の選択は自動的に処理されます。 

ビット シフトは、2 番目の辺にエッジを追加することを実装します。 からの移動`x`に`x+w`それを最初の面に追加することを実装します。 

最終チェックは、上で証明された 2 つの建設的なケースと正確に一致します。

 次のことを考慮してください。```

2 5
3 3
```アルゴリズムは最初に 2 つの最大の長さをチェックします。$$3+3=6>5$$そしてすぐに戻ります`No`。 

これにより、部分集合和の推論のみに基づいて誤って受け入れることが回避されます。

1
3 10

```並べ替えた後、$M=6$。 残りのエッジの DP は、合計するサブセットを見つけます。$d-M=4$。 アルゴリズムは「最大エッジが直径上にある」ケースを受け入れて出力します。`Yes`。
