## アプローチ

 直接的な総当たりアプローチでは、許可された操作をシミュレートしようとします。 1 つの値から開始して、値を繰り返し加算または減算できます。`b`他のすべての要素から到達可能な値を検索します。 すべての正当な操作が検索で表現されるため、このアプローチは概念的には正しいですが、状態空間には制限がありません。 操作を永久に適用し続けることができ、さまざまなシーケンスを通じて同じ値に到達することができます。 

より抑制された総当たりアプローチでは、要素のすべてのペアを検査する可能性があります。`a`そして、それらの差が次の値の組み合わせとして表現できるかどうかを判断してみます。`b`。 のすべての値を使用する場合、`b`すべてのペアを処理する際、最悪のケースは次のとおりです。`O(n^2m)`、おおよそ到達することができます`10^18`基本的なチェック`n,m = 10^6`。 これをペアごとに縮小しても`O(n^2)`チェックはまだ約を与えます`10^12`操作。 

操作が加算システムを形成するため、ブルート フォースは機能しますが、そのシステムを明示的に列挙しようとすると失敗します。 問題を解く観察は、いくつかの整数によって生成される加法系がそれらの gcd によって完全に記述されるということです。 

させて```
g = gcd(b[0], b[1], ..., b[m-1]).
```許可されるすべてのステップは次のように割り切れます。`g`、つまり剰余モジュロ`g`決して変わりません。 これにより、必要な条件がすぐに得られます。`a[i]`同じ剰余モジュロを持つ必要があります`g`。 

同じ条件でも十分です。 以来`g`の要素の gcd です。`b`、整数が存在します`c1, c2, ..., cm`そのような```
c1*b[0] + c2*b[1] + ... + cm*b[m-1] = g.
```各係数は加算または減算の繰り返しとして解釈できるため、次のように構成できます。`g`、したがって、次の任意の倍数`g`。 次の 2 つの値がある場合、`a`同じ剰余モジュロを持つ`g`、それらの差は次のように割り切れます。`g`, そのため、許可された操作を使用して差分を生成できます。 すべての要素を同じターゲット残基クラス代表に変換できます。 

これにより、問題全体が 1 回の gcd 計算と最初の配列の 1 回のパスに短縮されます。

### なぜ効果があるのか

 不変式は、最初の配列の各要素の剰余です。`g`。 許可されたすべての演算は、次の値で割り切れる数値を加算または減算するため、`g`、この余りは決して変わりません。 2 つの要素の余りが異なる場合、それらは決して満たされず、棄却条件が証明されます。

## Python ソリューション```python
import sys
from math import gcd

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    g = 0
    for x in b:
        g = gcd(g, x)

    r = a[0] % g

    for x in a[1:]:
        if x % g != r:
            print("No")
            return

    print("Yes")

if __name__ == "__main__":
    solve()
