 ## 問題の理解

 ゲームは現在の番号から始まります`m = n`。 キラニが最初に動きます。 毎ターン、プレイヤーは正の整数を減算します。`x`から`m`。 もし`m > k`、プレイヤーは何かを減算することができます`1`を通して`m-k`したがって、新しい値は次のいずれかの整数になります。`k`を通して`m-1`。 もし`m <= k`、許可される減算は次のとおりです。`1`, したがって、ゲームは一度に1つずつ数字を減らしていきます。 

対戦する選手は`m = 0`法的措置がないので負けます。 テストケースごとに、開始位置が次のとおりであるかどうかを決定する必要があります。`(n, k)`両方のプレーヤーが最適な選択をしたと仮定すると、キラニの勝ちです。 印刷します`Kilani`勝利のスタートポジションを獲得するために、`Ayoub`さもないと。 

可能な限り最大の`n`は`10^9`、最大までありますが、`10^4`テストケース。 までのすべての値を処理するアルゴリズム`n`1 つのテスト ケースに 10 億回の操作が必要になる可能性があるため、すでに遅すぎます。 二次仕事を伴うアルゴリズム`n`全く不可能です。 意図したソリューションでは、許可される手の構造を活用し、各テスト ケースを一定時間に短縮する必要があります。 

ゲームを通常の引き算のように扱うと間違った答えにつながる可能性がある境界例がいくつかあります。 のために`n = 1, k = 1`, キラニが勝ちます。 唯一の動きは引き算です`1`、アユーブはゼロで何も動かなくなります。 不注意なパリティ ルールを間違った範囲に適用すると、この位置が誤って分類される可能性があります。 

のために`n = 2, k = 2`, キラニが負けます。 以来`m <= k`、唯一の動きは`2 -> 1`、そしてアユーブは動きます`1 -> 0`、キラニは動くことができなくなります。 という事実`n = k`ここでは特別な境界が重要です。 

のために`n = 2, k = 1`、正解は`Ayoub`。 キラニはからのみ移動できます`2`に`1`、その後アユーブはに移動します`0`。 これは奇数のすぐ上の最初の位置です`k`、合法的な手を打っているにもかかわらず負けています。 

のために`n = 3, k = 1`、答えは`Kilani`。 Kilani はから直接移動できます`3`に`1`、アユーブに最後の動きをゼロにすることを強制します。 これにより区別されます`n = k+1`から`n >= k+2`。 

## アプローチ

 直接的なアプローチは、考えられるすべての値を分類することです。`m`勝ち負けとして。 すべての合法的な手が勝ちポジションに到達すると、そのポジションは負けになります。 少なくとも 1 つの合法的な手が負けの局面に到達した場合、勝ちとなります。 のために`m <= k`、遷移は 1 つだけあり、`m -> m-1`。 のために`m > k`、 がある`m-k`可能な動き、からのすべての値に到達`k`を通して`m-1`。 

この動的計画法は正しいです。なぜなら、すべての動きが減少するからです。`m`, したがって、昇順に位置を決定できます。 ただし、一つ上の位置の状態を計算すると、`k`まで検査することができます`m-k`以前の状態。 までのすべての位置を計算します`n`したがって二次時間がかかり、`O(n^2)`、最悪の場合。 と`n = 10^9`、つまり、おおよその意味です`5 * 10^17`1 つの大規模なテスト ケースの移行チェックですが、これはまったく実現可能とは言えません。 

重要な観察は、実際にはすべてのポジションを分類する必要はないということです。 まず以下の位置を検討してください`k`。 打つ手は1を引くだけなので、単純に普通のテイクワンゲームです。 したがって`k`まさにいつ負けているのか`k`が均等で、正確に勝った場合`k`奇数です。 

次に、次よりも大きい値を考えます。`k`。 そのような値から`m`、プレーヤーは間隔内のすべての値に移動できます`[k, m-1]`。 このインターバルに 1 つの負けポジションが含まれるとすぐに、`m`プレイヤーは負けているポジションに直接移動できるため、自動的に勝ちになります。 

もし`k`偶数であれば、`k`それ自体が負けている。 したがって、すべての`m > k`このようなポジションはすべて直接移動できるため、勝ちです。`k`。 

もし`k`それは奇妙です、それでは`k`勝っている。 次のポジションは、`k+1`、にのみ移動できます`k`、だから負けているのです。 あらゆるポジション`m >= k+2`に直接移動できます`k+1`、全員が勝利します。 

これにより、負ける可能性のある開始位置は 2 つだけになります。 いつ`k`偶数です、ただ`n = k`負けています。 いつ`k`奇妙だ、ただ`n = k+1`負けています。 他のすべてのスタートポジションはキラニの勝利です。

### なぜ効果があるのか

 不変条件は、すべての位置が次の値よりも大きいということです。`k`あらゆる小さな位置まで到達可能`k`。 いつ`k`均等です、`k`は最初の負けポジションなので、より大きなポジションがすべて勝ちになります。 いつ`k`奇妙です、`k`勝っていますし、`k+1`最初の負けポジションとなり、それより上のすべてのポジションが勝ちになります。 したがって、負けているポジションは次のとおりです。`k`均等に`k`、 そして`k+1`奇数の場合`k`。 アルゴリズムはこれらのポジションを正確にチェックするため、すべての有効な勝者に対して正しい勝者を生成します。`(n, k)`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve(data: str) -> str:
    tokens = data.split()
    t = int(tokens[0])
    pos = 1
    ans = []

    for _ in range(t):
        n = int(tokens[pos])
        k = int(tokens[pos + 1])
        pos += 2

        if k % 2 == 0:
            losing = (n == k)
        else:
            losing = (n == k + 1)

        ans.append("Ayoub" if losing else "Kilani")

    return "\n".join(ans)

def main():
    data = sys.stdin.read()
    sys.stdout.write(solve(data))

if __name__ == "__main__":
    main()
