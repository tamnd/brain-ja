 ## 解決策
 ## 問題の理解

 フォトジェニックな連続ペアの数が最大になるように、生徒のセットを一列に並べてもらいます。 身長の平均が整数であれば、そのペアはフォトジェニックです。 入力は複数のテスト ケースで構成されます。 各テスト ケースでは、生徒の身長を表す整数のリストが提供されます。 出力は、フォトジェニックなペアの数を最大化する各テスト ケースのこれらの高さの順列である必要があります。 

主な観察は、両方の数値が偶数または奇数の場合、数値のペアは整数平均を持つということです。 これにより、問題はすぐに単純な分類に帰着します。つまり、連続する数値が同じパリティを共有する必要があるということです。 すべてのテスト ケースの高さの合計は 2000 で制限されるため、テスト ケースごとの高さの数に関して線形時間で実行されるアルゴリズムで十分です。 

厄介なエッジ ケースには、すべての数値が偶数である場合、すべての数値が奇数である場合、または 1 つのパリティの数値が 1 つしかない場合などがあります。 たとえば、高さが次の場合、`[2, 4, 6]`、どの注文でもすべてのフォトジェニックなペアが作成されます。 高さがある場合`[1, 2, 3]`、連続するペアを最大化するには、慎重な配置が必要です。 

## アプローチ

 強引なアプローチは、高さのリストのすべての順列を生成し、順列ごとに写真映えする連続ペアの数を数え、最大数のペアを選択することです。 のために`n`2000 年までは、階乗的な時間計算があるため、これは明らかに実行不可能です。 たとえ`n=10`、順列は 360 万通りあります。 

重要な洞察は、写真映えの特性はパリティのみに依存するということです。 数字を奇数と偶数の 2 つのグループに分けることで、同じグループ内の連続する数字のすべてのペアが写真映えすることを保証できます。 これにより、問題は単純な並べ替えまたはグループ化タスクに軽減されます。 最も単純なアプローチは、すべての偶数を出力し、その後にすべての奇数を出力することです (またはその逆)。 同じパリティ グループ内の 2 つの連続する番号はフォトジェニックになります。反対のパリティの番号間に追加のフォトジェニック ペアを作成する方法はありません。 これにより、最適な配置が保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | パリティのグループ化 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テストケースについて、生徒の数を読み取ります。`n`そして彼らの身長のリスト。 
2. 2 つの空のリストを初期化します。1 つは奇数の高さ用、もう 1 つは偶数の高さ用です。 
3. 高さのリストを繰り返し処理します。 高さが奇数の場合は、それを奇数リストに追加します。 偶数の場合は、偶数リストに追加します。 
4. 偶数リストと奇数リストを連結します。 この順序により、各グループ内のすべての連続する番号が同じパリティを持つことが保証され、フォトジェニックなペアの数が最大化されます。 
5. 連結リストを出力します。 

機能する理由: 同じパリティの連続するペアは常に整数平均を生成します。 すべての偶数とすべての奇数をグループ化することで、そのようなペアの最大数が保証されます。 異なるパリティの番号をインターリーブしようとしてもフォトジェニック ペアの数を増やすことはできないため、この戦略が最適です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    heights = list(map(int, input().split()))
    odd = []
    even = []
    for h in heights:
        if h % 2 == 0:
            even.append(h)
        else:
            odd.append(h)
    result = even + odd
    print(" ".join(map(str, result)))
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 パリティによって高さを分離し、リストを連結します。 この順序により、フォトジェニックな連続ペアの最適な数が保証されます。 すべての数値が偶数または奇数であるなどの境界条件は、自然に処理されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        n = int(input())
        heights = list(map(int, input().split()))
        odd = []
        even = []
        for h in heights:
            if h % 2 == 0:
                even.append(h)
            else:
                odd.append(h)
        result = even + odd
        print(" ".join(map(str, result)))
    return output.getvalue().strip()

 ## 特殊なケース

 すべての高さが同じである場合、アルゴリズムはそれらを元のグループに配置し、フォトジェニックなペアの最大数を自動的に生成します。 たとえば、入力`[2, 4, 6]`結果として`[2,4,6]`、フォトジェニックな2足付き`(2,4)`そして`(4,6)`。 

特定のパリティの高さが 1 つだけ存在する場合、それは最適な連結の最後に配置されます。 のために`[1,2,4]`、偶数`[2,4]`が最初に配置され、その後に単一の奇数が配置されます`1`。 フォトジェニックなペアたち`(2,4)`がカウントされ、奇数の場合は追加のペアは作成できません。
