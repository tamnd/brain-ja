 ## 解決策
 ## 問題の理解

 各エッジに重みがある接続された無向グラフから始めます。 このグラフから、折れ線グラフと呼ばれる別のグラフを作成します。 この変換されたグラフでは、元のすべてのエッジが頂点になります。 元のグラフ内の対応するエッジが端点を共有している場合、折れ線グラフ内の 2 つの頂点は接続されており、その接続の重みは 2 つの元のエッジの重みの合計です。 

タスクは、この折れ線グラフを明示的に作成することではありません。 代わりに、最大重み付けマッチングの合計重みが必要です。 マッチングとは、どの頂点も複数回使用されないように折れ線グラフの頂点のペアを選択し、選択したエッジの重みの合計を最大化することを意味します。 

元のグラフに戻すと、選択された各一致エッジは、元のグラフ内の 2 つの隣接するエッジを選択し、それらの重みの合計を支払うことに対応します。 

制約は厳しく、頂点は最大 100,000、エッジは 200,000 です。 折れ線グラフを構築するソリューションは、元のグラフの密な部分に最大 O(m^2) のエッジが作成される可能性があるため、直ちに実行不可能になります。 折れ線グラフに隣接性を保存することさえ不可能です。 

折れ線グラフ内のすべての相互作用は共有エンドポイントによって引き起こされるため、これにより、元のグラフの頂点の周囲で局所的に推論する必要が生じます。 

重要なエッジ ケースは、頂点の次数が高い場合に発生します。 たとえば、1 つのノードが異なる重みを持つ多くのエッジに接続している場合、それらのエッジの周囲の折れ線グラフはクリークとなり、個々のエッジに対する単純な一致推論は失敗します。 

星を考えてみましょう。 

n = 4

 エッジ: (1-2,1)、(1-3,2)、(1-4,3)

 折れ線グラフでは、3 つのエッジすべてが頂点となり、ペアごとの合計に等しい重みを持つ三角形を形成します。 最小エッジの単純な貪欲なペアリングでは、最初に最適なペアリングを見逃す可能性があります。これは、ペアリング構造が隣接順序ではなくグローバルなソートに依存するためです。 

本当の課題は、すべての折れ線グラフのエッジが単一の元の頂点に由来するため、問題は頂点ごとに局所的に分解されますが、エッジはそのような 2 つのローカル構造に関与していることです。 

## アプローチ

 強引なアイデアは、折れ線グラフを明示的に作成することです。 元の各エッジはノードになり、エンドポイントを共有するエッジのペアごとに、それらの重みの合計で重み付けされたエッジを作成します。 次に、このグラフに対して最大重み付けマッチング アルゴリズムを実行します。 

これは概念的には正しいですが、完全に実行不可能です。 次数 d の頂点は、折れ線グラフの O(d^2) エッジに寄与します。 密なグラフでは、これは頂点ごとに 2 次となり、合計エッジ数が O(m^2) となり、制限をはるかに超えます。 

重要な観察は、折れ線グラフのすべてのエッジが元のグラフのちょうど 1 つの端点で生成されていることです。 元のグラフの頂点 u を固定すると、u に付随するすべてのエッジが、w(e_i) + w(e_j) に等しいエッジの重みを持つ完全なグラフを折れ線グラフに形成します。 この構造は非常に特殊です。マルチセット内のすべてのペアごとの合計です。 

ここで問題が発生します。各頂点 u には入射エッジの重みのマルチセットがあり、ローカルでペアを形成したいと考えていますが、元の各エッジはグローバルに 1 回しか使用できません。つまり、すべてのエッジの 2 つの端点間の選択を調整する必要があります。 

これは当然、貪欲な順序付けを示唆しています。 合計完全グラフにおける最適なマッチングは、大きな重みをペアにすることで得られますが、各エッジはそのような 2 つのローカル構造に参加しているため、一貫性を確保する必要があります。

これを解決する正しい方法は、各エッジを 1 つのペアリング決定にのみ寄与するものとして扱い、問題をグローバルにエッジをソートし、各エッジが 1 回使用されるようにしながらそれらを貪欲にペアリングすることに帰着することです。 折れ線グラフの構造により、あらゆる最適なマッチングが元のエッジの互いに素なペアの選択に対応することが保証され、各ペアが頂点を共有する場合は重みの合計に寄与します。 最大合計は、利用可能な最大の互換性のある寄与を常にペアリングすることによって達成されます。これは、派生構造での貪欲なペアリングに帰着します。 

この実装は、要約すると、重みでソートされたエッジを処理し、次数を意識した構造を使用して、ローカルで利用可能な未使用のインシデント エッジと一致させます。

 ## アルゴリズムのチュートリアル

 この問題を元のエッジのペアとして再解釈します。2 つのエッジが少なくとも 1 つの端点を共有する場合、各ペアは重みの合計に寄与します。 

1. 頂点ごとにエッジの隣接リストを作成し、エッジのインデックスと重みを保存します。 これにより、どのエッジが各頂点を介して合法的にペアにできるかを知ることができます。 
2. すべてのエッジを重みの降順に並べ替えます。 ソートの理由は、重いエッジが最終的な合計に大きく寄与するためであり、価値の高い組み合わせが失われないように、それらに関係するペアリングの決定を優先する必要があるためです。 
3. 各エッジが一致するペアですでに使用されているかどうかをマークするブール配列を維持します。 これにより、各エッジが最大 1 回寄与し、折れ線グラフのマッチングの定義と一致することが保証されます。 
4. 頂点を反復処理します。 各頂点 u について、まだ使用されていないすべてのインシデント エッジを収集します。 グローバル順序付けを使用して、暗黙的に重みでソートまたは分類します。 
5. 各頂点 u で、未使用の入射エッジを重みの降順で貪欲にペアにします。 各ペアは w(e_i) + w(e_j) を答えに寄与し、両方のエッジが使用済みとしてマークされます。 エッジが固定されると、u を介して考えられるすべての寄与が他の頂点から独立するため、このステップは有効です。 
6. すべての頂点が処理されるまで続行します。 一部のエッジは頂点で一致しないままになる場合がありますが、可能であれば他のエンドポイントで処理されます。 

重要な詳細は、各エッジが両方のエンドポイントから考慮されることを許可されていますが、グローバルに一致できるのは 1 回だけであるということです。 初めてペアになったときの貢献度が決まります。 

### なぜ効果があるのか

 折れ線グラフの構造により、一致するすべてのエッジが、頂点を共有する 2 つの元のエッジの選択に対応することが保証されます。 したがって、すべての有効なソリューションは、元のエッジのサブセットを互いに素なペアに分割することと同等であり、各ペアは共通のエンドポイントの 1 つに割り当てられます。 貪欲な順序付けにより、高重みのペアリングが可能である場合は常に、より小さい寄与を優先してペアリングが延期されることがないことが保証されます。これは、遅延が発生しても実現可能性が低下または維持されるだけで、合計が増加することはないためです。 これにより、交換議論が引き起こされます。最適なソリューションは、合計値を減らすことなく、最初に重いエッジをペアにするソリューションに変換され、最適性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

edges = []
adj = [[] for _ in range(n + 1)]

for i in range(m):
    u, v, w = map(int, input().split())
    edges.append((w, u, v, i))
    adj[u].append(i)
    adj[v].append(i)

edges.sort(reverse=True)

used = [False] * m
ans = 0

for w, u, v, i in edges:
    if used[i]:
        continue

    best = -1
    bu = bv = -1

    for j in adj[u]:
        if used[j]:
            continue
        w2, x, y, _ = edges[j]
        if best < w2:
            best = w2
            bu = j
            bv = -1

    for j in adj[v]:
        if used[j]:
            continue
        w2, x, y, _ = edges[j]
        if w + w2 > w + best:
            best = w2
            bu = j
            bv = -1

    if bu != -1:
        used[i] = True
        used[bu] = True
        ans += w + best

print(ans)
```コードはすべてのエッジを維持し、寄与度の高いペアが最初に考慮されるように、重みの降順でそれらを繰り返します。 隣接リストを使用すると、両方のエンドポイントでペアリング エッジの候補を見つけることができます。 

の`used`配列は、折れ線グラフの観点から一致制約を強制します。 エッジがペアになると、それ以降の考慮事項から削除されます。 

実装の主な困難は、エンドポイント間のエッジを二重にカウントしないようにすることです。 コードはチェックすることでこれを処理します。`used`隣接スキャンでエッジを考慮する前に。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべての入射エッジが異なる重みを持つ高度なハブです。 このような場合、ハブの周囲の折れ線グラフは、エッジの重みが大きく偏った完全なグラフになります。 このアルゴリズムにより、最大の入射エッジが最初にペアリングされることが保証され、より小さなエッジ間での最適でないペアリングが防止されます。 

もう 1 つのケースは、エッジが長いパスを形成する場合です。 各エッジは正確に 2 つの頂点に参加しており、貪欲ペアリングでは、一方の頂点で使用されているエッジが他方の頂点で誤って再利用されないようにする必要があります。 の`used`array はこれをグローバルに強制し、ソートされた処理により、エッジが消費されると、その後のステップでそれを含むより良いペアリングを生成できないことが保証されます。 

最後のケースは、複数の最適なペアが頂点に局所的に存在する場合です。 エッジが固定されると寄与は加算的で独立しているため、等しい重みの候補間のタイブレークは正確さに影響を与えず、アルゴリズムはそのような構成全体で安定したままになります。
