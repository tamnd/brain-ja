 ## 問題の理解

 拡張複素平面上に点の 3 つの入出力ペアが与えられます。ここで、各点は実数部と虚数部で表される複素数です。 これらのペアは、形式の一意の線形分数変換を定義します。$f(z) = \frac{az + b}{cz + d}$、複素係数が満たされる$ad - bc \neq 0$。 このような関数は、3 つの異なる点に対する作用が決まれば完全に決定されます。 

すべてのテスト ケースについて、この変換が 3 つの複素数をどのようにマッピングするかを知っています。$z_1, z_2, z_3$3 つの複素数値へ$w_1, w_2, w_3$、そして 4 番目の点の画像を計算するように求められます。$z_0$同じ変換下で。 

入力は各複素数を 2 つの整数としてエンコードするため、各テスト ケースでは 3 つのマッピングに対して 12 の整数が与えられ、マッピングに対して 2 つの整数が与えられます。$z_0$。 出力は、実数部と虚数部を表す実数のペアです。$f(z_0)$、非常に高い精度が要求されます。 

制約はテスト ケースの数によって支配されます。$10^5$。 これにより、重い定数因数を使用した単純なガウス消去法を使用して一般的な 4 変数線形システムを解くことを含む、テスト ケースごとのアプローチや、拡張形式での複雑な有理式の記号操作を含むものは直ちに除外されます。 ソリューションでは、各テスト ケースを一定量の算術作業に減らす必要があります。 

微妙な問題は数値の安定性です。 直接展開$\frac{az+b}{cz+d}$を解いた後$a,b,c,d$浮動小数点誤差が蓄積される可能性があります。 もう 1 つの危険は、明示的に計算しようとすることです。$a,b,c,d$すべての入力が小さな整数であっても、大きな中間複素数を繰り返し形成する方法で行列式を介して。 意図した解決策では、係数を明示的に求めることは一切避けられます。 

素朴な推論による代表的な失敗例は、計算を試みることです。$a,b,c,d$3 つの制約と正規化から 4 つの方程式を解くことによって。 これにより、交差比の不変条件を利用することで変換をよりきれいに計算できるにもかかわらず、不必要な代数の複雑さと浮動小数点の不安定性が生じます。 

## アプローチ

 線形分数変換では交差比が維持されます。 任意の 4 つの異なる点について$z, z_1, z_2, z_3$、 我々は持っています$$\frac{(z - z_1)(z_2 - z_3)}{(z - z_3)(z_2 - z_1)}
=
\frac{(f(z) - f(z_1))(f(z_2) - f(z_3))}{(f(z) - f(z_3))(f(z_2) - f(z_1))}$$このアイデンティティは、導入することなく、変換動作を完全に特徴づけます。$a,b,c,d$。 

ブルートフォースアプローチは明示的に解決します$a,b,c,d$3 つの既知のマッピングと正規化制約を使用します。たとえば、$d = 1$または固定スケール。 これにより、3 つの未知数を含む 3 つの複雑な方程式の系が得られます。 これを解くには、複雑な算術と割り算を繰り返す必要があります。$10^5$テスト ケースでは、定数係数の非効率性さえも顕著になります。 さらに重要なのは、分母が小さくなると浮動小数点の不安定性が現れる可能性があることです。 

重要な観察は、変換自体は必要なく、一点に対するそのアクションのみが必要であるということです。 交差比の恒等式は、未知の領域における直接方程式を与えます。$w_0 = f(z_0)$、テスト ケースごとに定数時間で代数的に解くことができます。 

交差比方程式を書き直すと、次のような有理式が得られます。$w_0$, 分母をクリアした後、線形方程式に並べ替えることができます。 これにより、システムを解く必要がなくなり、すべてが複雑な算術演算の固定シーケンスに削減されます。

1. クロスレシオ係数を計算する$$k = \frac{(z_0 - z_1)(z_2 - z_3)}{(z_0 - z_3)(z_2 - z_1)}$$これは、イメージ空間内の対応する式と一致する必要がある不変値です。

### なぜ効果があるのか

 線形分数変換は、射影構造を維持しながら円と直線を円と直線にマッピングする変換のグループであるため、交差比が維持されます。 3 つの点が固定されると、4 番目の点とそれら 3 つの点の間の交差比は変換下で不変になります。 この不変式により、次のような単一の複雑な方程式が生成されます。$w_0$、そして変換は拡張平面上で全単射であるため、その方程式は一意の解を持ちます。 導出により、すべての自由度が崩壊します。$a,b,c,d$単一の合理的な恒等式に変換し、計算された値の正確さを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    out = []

    for _ in range(T):
        p1, q1, r1, s1 = map(int, input().split())
        p2, q2, r2, s2 = map(int, input().split())
        p3, q3, r3, s3 = map(int, input().split())
        p0, q0 = map(int, input().split())

        z1 = complex(p1, q1)
        z2 = complex(p2, q2)
        z3 = complex(p3, q3)
        z0 = complex(p0, q0)

        w1 = complex(r1, s1)
        w2 = complex(r2, s2)
        w3 = complex(r3, s3)

        num_k = (z0 - z1) * (z2 - z3)
        den_k = (z0 - z3) * (z2 - z1)
        k = num_k / den_k

        num = k * (w2 - w1) * w3 - (w2 - w3) * w1
        den = k * (w2 - w1) - (w2 - w3)
        w0 = num / den

        out.append(f"{w0.real:.10f} {w0.imag:.10f}")

    print("\n".join(out))

if __name__ == "__main__":
    solve()

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、中間の差が非常に小さくなるようにポイントが配置される場合です。たとえば、次のような場合です。$z_0$に非常に近いです$z_1$または$z_3$。 このような場合、単純に係数を拡張すると浮動小数点誤差が増幅されてしまいます。 クロスレシオ形式は、分子と分母の対称構造を維持することでこれを回避します。 

もう 1 つのケースは、変換が単純な反転のように動作する場合です。 もし$w_1 = 1/z_1$、$w_2 = 1/z_2$、$w_3 = 1/z_3$の場合、式は正確に次のように減ります。$w_0 = 1/z_0$。 アルゴリズムにプラグインすると、分子と分母の両方が一貫した逆数に単純化され、特別なケースを使用せずに正しい値が生成されます。 

最後のケースは次のような場合です。$z_0, z_1, z_2, z_3$は複素平面内でほぼ同一線上にあるため、交差比の値が大きくなる可能性があります。 すべての爆発は分子と分母で対称的に現れ、最終的な除算の前にキャンセルされるため、代数公式はこれを依然として正しく処理します。
