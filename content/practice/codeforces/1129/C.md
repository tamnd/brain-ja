 ## 解決策
 ## 問題の理解

 文字列を一度に 1 文字ずつ段階的に構築しながら、モールス信号でエンコードされた英語の文字のシーケンスを追跡するように求められます。 文字列`S`空から始まり、ドット (`0`) またはダッシュ (`1`）各ステップで。 追加するたびに、現在のパーティションを分割できる空でない方法をすべてカウントする必要があります。`S`文字に対応する有効なモールス符号シーケンスに変換します。 各文字のモールス信号の長さは 1 ～ 4 ですが、4 つの特定のシーケンスがあります。`"0011"`、`"0101"`、`"1110"`、`"1111"`どの文字にも対応しません。 長さ 1 ～ 4 の他のすべてのシーケンスは有効です。 

入力サイズは最大 3000 の変更です。これは、時間計算量がおよそよりも悪いソリューションを意味します。`O(n^2)`危険です。 追加のたびに出力が要求されるため、最初から再計算するのではなく、カウントを段階的に更新できるメソッドが必要です。 これは動的プログラミングを示唆しています。 すべての部分文字列をチェックする単純な方法`S`繰り返しかかるだろう`O(n^3)`最悪の場合、遅すぎます。 

不用意な解決策を破る可能性のあるエッジ ケースには、非常に短いシーケンス (長さ 1)、禁止パターンに正確に一致するシーケンス、有効な文字が部分文字列の境界を越えて重複する 4 より長いシーケンスなどがあります。 たとえば、`"1"`4回で生成されます`"1111"`、これは禁止されていますが、次のような部分文字列は`"1"`または`"11"`はまだ有効です。 

## アプローチ

 ブルートフォース手法では、現在の文字で終わるすべての部分文字列を反復処理し、それが文字の有効なモールス信号であるかどうかを確認します。 新しい文字が追加されるたびに、`S`、そこで終わるすべての部分文字列を考慮し、前の位置で終わる可能性のある有効なパーティションの数を合計します。 これは原理的には機能しますが、パフォーマンスは大まかです`O(n^3)`のための操作`n`最大 3000 まで`O(n^2)`部分文字列と各部分文字列について、前の位置の分割を合計する場合があります。 

重要な点は、有効な文字はすべて長さ 4 までの部分文字列に対応するということです。これにより、新しい文字を追加するときは常に、部分文字列のチェックを最後の 4 文字に制限することができます。 動的プログラミングを使用すると、次のように定義できます。`dp[i]`プレフィックスを分割する有効なシーケンスの数として`S[0..i]`。 それから`dp[i]`合計は終わりましたか`dp[i-l]`長さの場合`l`1..4 の場合`S[i-l+1..i]`は有効なモールス信号であり、部分文字列自体が先頭から始まる有効な文字である場合は 1 を加えます。 これにより、文字ごとの計算が次のように削減されます。`O(4)`、与える`O(n)`合計時間。 保管する`dp`必要`O(n)`空間。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n^2) | 遅すぎる |
 | ラスト 4 最適化を使用した DP | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 長さ 1 ～ 4 のすべての有効なモールス符号シーケンスのセットを事前計算します。`0`そして`1`長さ 1 ～ 4 の 4 つの禁止シーケンスを削除します。`"0011"`、`"0101"`、`"1110"`、`"1111"`。 
2. 配列を初期化する`dp`長さの`m+1`、 どこ`dp[i]`最初の有効なパーティションの数を表します。`i`の登場人物`S`。 セット`dp[0] = 1`空のシーケンスを基本ケースとして表現します。 
3. 文字列を維持する`S`文字が追加されるので。 追加される新しい文字ごとに、最後の 1 ～ 4 文字を考慮します。 長さの部分文字列ごとに`l`現在の位置で終わる場合は、それが事前計算された有効なセット内にあるかどうかを確認します。 その場合は追加してください`dp[i-l]`に`dp[i]`。 すべての和を剰余として計算する`10^9 + 7`。 
4. 新しい文字を処理した後、出力します`dp[i]`空のシーケンスを除外するには、マイナス 1。 追加するたびにこれを繰り返します。 

これが機能する理由は、どのパーティションでも`S[0..i]`有効な文字で終わる場合は、最後の文字の長さが 1 ～ 4 である必要があります。 合計すると`dp[i-l]`有効な長さについては、次で終わる可能性のあるすべてのシーケンスが正しくカウントされます。`i`二重に数えることなく、`dp[i-l]`プレフィックスのすべてのシーケンスがすでに含まれています`i-l`。 DP の不変条件は次のとおりです。`dp[i]`最初のシーケンスの合計数が常に含まれます。`i`文字。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def main():
    m = int(input())
    S = []
    # Generate valid Morse codes of length 1 to 4
    valid = set()
    for length in range(1, 5):
        for num in range(1 << length):
            code = bin(num)[2:].zfill(length)
            valid.add(code)
    forbidden = {"0011", "0101", "1110", "1111"}
    valid -= forbidden

    dp = [0] * (m + 1)
    dp[0] = 1

    for i in range(1, m + 1):
        c = input().strip()
        S.append(c)
        dp[i] = 0
        # Check last 1 to 4 characters
        for l in range(1, 5):
            if i - l >= 0:
                substring = ''.join(S[i-l:i])
                if substring in valid:
                    dp[i] = (dp[i] + dp[i-l]) % MOD
        print((dp[i]) % MOD)

if __name__ == "__main__":
    main()
```この実装はアルゴリズムに正確に従います。 考えられるすべてのモールス信号を生成し、禁止されているモールス信号を削除して、`dp[i]`シーケンスの数を保存します。 新しい追加ごとに最後の 4 文字のみを考慮するため、ステップごとの計算が 4 つの操作に制限されます。 モジュロ演算により、結果が必要な境界を超えないことが保証されます。
