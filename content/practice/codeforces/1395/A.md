 ## 解決策
 ## 問題の理解

 赤、緑、青、白の 4 種類のボールの数が与えられます。 唯一許可されている操作は、赤、緑、青のボールを 1 つずつ取り、3 つすべてを白のボールに変換することです。 この操作は何度でも適用できます。 

これらの変換を実行した後、残りのすべてのボールを回文シーケンスに並べ替えることが可能かどうかを判断する必要があります。 

回文の配置は、各色の数にのみ依存し、色のアイデンティティや対称性を超える順序の制約には依存しません。 本当の難しさは、この操作により 3 つの色のグループのそれぞれから 1 つのユニットを白に交換することになり、これによりシステムのパリティ構造が連動して変更されることです。 

テスト ケースごとの制約は小さく、値が 10^9 ほど大きい場合は最大 100 ケースまでです。 これにより、操作上のシミュレーションや状態検索が即座に除外されます。 唯一の実行可能なアプローチは、不変式とパリティについて推論することです。これは、操作によってカウントの特定のモジュール特性が保持されるためです。 

単純な間違いは、白以外のボールの合計が偶数かどうかだけを気にすることです。 この操作では一度に 3 つの色が結合され、パリティ パターンが重要な方法で変更される可能性があるため、これでは不十分です。 

もう 1 つの一般的な失敗ケースは、r、g、b がすべて奇数である場合です。 たとえば、r = g = b = 1 および w = 0 です。1 回の演算で、これは (0, 0, 0, 3) に変わります。 パリティ制約を理解していないと、すべてを白に変換した後、答えは常に「はい」であると誤って仮定する可能性がありますが、回文のパリティ実現可能性は、すべての変換後に最大 1 つのカテゴリのカウントが奇数であるかどうかによって決まります。 

## アプローチ

 ブルートフォースの観点は、可能なすべての方法で操作の適用を繰り返し試行し、到達可能な状態を追跡し、最終的な構成を回文に並べ替えることができるかどうかを確認することです。 これはすべての有効な変換を調査するため、原理的には正しいですが、状態空間は色間の質量の可能な分布に関して際限なく拡大し、深さは指数関数的になります。 たとえ小さな入力でも多くの中間構成が生成されるため、これは実行不可能になります。 

重要な洞察は、この演算によって r + g + b modulo 2 の値が保存されるということです。各演算では、r、g、b のそれぞれが 1 ずつ減算されるため、個々のパリティが同時に反転されますが、結合されたパリティの動作は制限されたままになります。 さらに重要なのは、回文の形成を妨げる唯一の障害は、白への最適な再配分後の奇数カウントの色の数です。 白は、過剰なパリティを吸収できる柔軟なバッファとして機能しますが、追加の白ボールが利用できない限り、3 つの奇数カウントすべてを同時に解決することはできません。 

問題は、r、g、b のうち最大 1 つが奇数になるように、演算を使用して r、g、b を調整できるかどうかを確認することに帰着します。 この操作では 3 つのパリティすべてが一度に変更されるため、(操作を 2 回適用することで) パリティを変更しないことも、(1 回適用することで) 3 つすべてを一度に反転することもできます。 したがって、r、g、b のパリティと、w が残りの不均衡を補償できるかどうかを確認するだけで済みます。 

正しい条件は次のようになります。演算パリティ効果を使用して最大 1 回の調整を行った後、r、g、b、w の間の奇数カウントの合計数は最大 1 でなければなりません。 

これにより、テスト ケースごとに一定時間のチェックが行われます。

 ## アルゴリズムのチュートリアル

 回文配置の実現可能性に関しては、各カウントのパリティのみが重要であることがわかります。 

r、g、b のうち奇数がいくつあるかを計算します。 この値をkとします。

次に、操作によってパリティがどのように変更されるかを検討します。 1 回の操作で 3 つのパリティすべてを同時に反転します。 これは、3 つすべてを反転すると各色の奇数が切り替わるため、k を変更しないままにするか、3 - k に変換できることを意味します。 

白いボールは残った不均衡を吸収できるため、2 つの可能性のうち良い方を選択し、それを w の寄与と組み合わせます。 

次に、結果のシステム全体に奇妙なコンポーネントが 1 つだけ含まれているかどうかを確認します。 「はい」の場合、残りのすべての奇数カウントを中心位置に配置し、偶数カウントは対称的にペアを配置できるため、回文配置が可能です。 

そうしないと、一連の操作の後にすべてのボールを回文に配置することができなくなります。 

不変条件は、すべての演算がグローバル フリップまで r、g、b の間のパリティ関係構造を保持し、白は柔軟な吸収体としてのみ機能するということです。 したがって、唯一の障害は、奇数成分の数を最大 1 つに減らすことができるかどうかです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        r, g, b, w = map(int, input().split())

        odd = (r & 1) + (g & 1) + (b & 1)

        if odd <= 1:
            print("Yes")
            continue

        if w > 0:
            print("Yes")
        else:
            print("No")

if __name__ == "__main__":
    solve()
```このソリューションは、3 原色のパリティを直接カウントします。 すでに回文条件 (奇数カウントが 1 つまで) を満たしている場合、操作は必要ありません。 それ以外の場合、パリティの不均衡を修復する唯一の方法は、少なくとも 1 つの演算を使用することです。これは、白球によって導入される十分な柔軟性がある場合にのみ有益です。 白いボールが存在する場合、パリティ調整後に残った不均衡を吸収できます。 そうしないと、構成は不可能なままになります。 

微妙な点は、操作を明示的にシミュレートすることは決してないということです。 これは意図的なものです。なぜなら、操作はそのパリティ効果を通じてのみ重要であり、より深いシミュレーションを行っても不変条件が曖昧になるだけだからです。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        r, g, b, w = map(int, input().split())
        odd = (r & 1) + (g & 1) + (b & 1)
        out.append("Yes" if odd <= 1 or w > 0 else "No")
    return "\n".join(out)

# provided samples

assert run("1\n1 1 1 1") == "Yes", "white allows fix"
assert run("1\n0 0 0 0") == "Yes", "empty case"
assert run("1\n2 2 2 0") == "Yes", "already valid"

 ## 特殊なケース

 重要なエッジ ケースは、r、g、b の 3 つがすべて奇数で、白球が存在しない場合です。 例えば：```
1 1 1 0
```すべての操作で各色を 1 つずつ消費する必要がありますが、そのような一連の操作では白の容量を導入せずに根本的なパリティの不均衡を解消することはできません。 アルゴリズムは、奇数カウントが 3 で w が 0 であることを検出することによってこれをチェックし、正しく「いいえ」と導きます。 

別のケースは、すべてのカウントが偶数の場合です。```
2 4 6 0
```ここでは奇数カウントが 0 であるため、構成はすぐに有効になります。 アルゴリズムは、不必要な変換を試行せずに、純粋にパリティ構造に依存して「はい」を返します。 

最後のケースは、白ボールが優勢な場合です。```
1 1 1 10
```初期パリティが無効であっても、白いボールの存在により、最大 1 回の操作後に不均衡を吸収する柔軟性が保証されるため、答えは「はい」になります。
