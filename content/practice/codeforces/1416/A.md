 ## 解決策
 ## 問題の理解

 値が以下の範囲にある配列が与えられます。`1`そして`n`。 

あらゆる長さに対して`k`、**すべて**の長さの部分配列を調べます`k`。 値`x`このようなすべてのサブ配列に少なくとも 1 つの次の出現が含まれる場合、有効であるとみなされます。`x`。 すべての有効な値の中で、最小のものを出力する必要があります。 すべての長さに値が表示されない場合は、`k`部分配列、答えは`-1`。 

条件についての別の考え方は次のようになります。`x`一部の長さが欠けています-`k`部分配列、その後`x`は候補ではありません。 任意の長さのセグメントを取得するときに回避不可能な値が必要です`k`。 

すべてのテスト ケースの合計サイズは最大でも`3 · 10^5`。 すべてを処理するあらゆるソリューション`k`個別にスキャンしたり、値ごとにすべてのサブ配列をスキャンしたりすると、非常に遅くなります。 と`n = 3 · 10^5`、通常はそれに近いものが必要です`O(n log n)`または`O(n)`テストケースごとに。 

難しいのは、すべての項目に対して答えを生成する必要があることです。`k`から`1`に`n`したがって、特定のセグメント長に対して値がいつ有効になるかを特徴付ける方法が必要です。 

次の配列を考えてみましょう。```
1 2 1
```のために`k = 2`、セグメントは`[1,2]`そして`[2,1]`。 価値`1`は両方に表示されるため、答えは次のようになります。`1`。 

不注意なアプローチでは、発生件数の合計のみがカウントされる可能性があります。 以来`2`一度登場し、`1`2 回出現する場合、重要なのは頻度であるように思われるかもしれません。 そうではない。 ポジションはカウントよりもはるかに重要です。 

もう 1 つの重要なケースは次のとおりです。```
1 2 3 4 5
```すべての値は 1 回だけ表示されます。 

のために`k = 3`、セグメントは次のとおりです。```
[1,2,3]
[2,3,4]
[3,4,5]
```値のみ`3`はすべてに出てくるので、答えは`3`。 

周波数ベースのアプローチでは、この動作が完全に欠落します。 

もう 1 つのエッジ ケースは、値が何度も出現するが、大きなギャップがある場合です。```
1 1 1 2 1
```価値`1`は 4 回表示されますが、これがなければ長い区間があれば、一部のセグメントがそれを回避できる可能性があります。 重要なのは、出現の合計数ではなく、連続する出現の間の最大距離です。 

## アプローチ

 ブルートフォース ソリューションでは、すべてのデータが処理されます。`k`独立して。 それぞれの値について、すべての長さが次のとおりであるかどうかを確認できます。`k`サブ配列にはその値が含まれます。 

1 つの方法は、すべてを生成することです`n-k+1`サブ配列を作成し、各サブ配列にどの値が現れるかを追跡します。 最適化を行ったとしても、これはすぐに少なくとも`O(n²)`そしてしばしば`O(n³)`。 と`n = 3 · 10^5`、そのようなアプローチは絶望的です。 

重要な観察は、単一の値を観察することで得られます。`x`。 

次のようなことが起こったとします。`x`次の位置にあります:```
p1, p2, ..., pm
```2 つの仮想位置を追加します。```
0 and n+1
```次に、ギャップについて考えてみましょう。```
p1 - 0
p2 - p1
...
pm - p(m-1)
(n+1) - pm
```最大のギャップを次のようにします`g`。 

これはどういう意味ですか？ 

長さに隙間がある場合`g`、その後、それらの 2 つの連続した出現の間には、`g-1`を含まない位置`x`。 

長さのセグメント`g-1`その隙間に完全に収まり、`x`完全に。 

それで`x`あらゆる長さのセグメントに存在することはできません`g-1`。 

一方、任意の長さのセグメント`g`少なくとも 1 回は交差する必要があります`x`、保持できるほど大きな隙間がないため`g`連続ポジションなし`x`。 

これにより、非常に有用な特徴が得られます。 

値`x`長さのすべての部分配列に出現します`k`もし、そしてその場合に限り```
k ≥ largest_gap(x)
```したがって、すべての値にはしきい値があります。```
need[x] = largest_gap(x)
```全員にとって`k ≥ need[x]`、 価値`x`有効です。 

ここで問題は次のようになります。 

それぞれについて`k`、しきい値が最大以下である最小値を見つけます。`k`。 

これははるかに簡単です。 

私たちは計算します`need[x]`あらゆる価値観に対して。 次に、それぞれの値について`x`、ポジションから候補になります`need[x]`。 私たちは以下を保管します:```
ans[need[x]] = min(ans[need[x]], x)
```その後、プレフィックス最小スイープによって候補がより大きな候補に伝播されます。`k`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) から O(n³) | O(n²) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての値の出現位置のリストを作成します。`1`に`n`。 
2. 配列の各位置について`i`、追加`i`の出現リストに`a[i]`。 
3. あらゆる値について`x`、その最大ギャップを計算します。 

前の位置から開始`0`。 出現位置ごとに`p`、 アップデート：```
gap = p - previous
```このようなギャップを最大にしてください。 

すべてのオカレンスを処理した後、次のことも考慮してください。```
(n + 1) - last_occurrence
```これは、最後の出現後のサフィックスを処理します。 
4. この最大ギャップを次のようにします。`need[x]`。 

価値`x`すべての場合に有効です`k ≥ need[x]`。 
5. 配列を作成する`ans`無限大で初期化されます。 
6. あらゆる値について`x`少なくとも 1 回表示される場合は、次を更新します。```
ans[need[x]] = min(ans[need[x]], x)
```しきい値が正確に一致する最小値を記録します。`need[x]`。 
7. プレフィックス最小スイープを実行します。```
ans[k] = min(ans[k], ans[k-1])
```みんなのために`k`から`2`に`n`。 

値が有効になると、それより大きなセグメント長すべてに対して有効なままになります。 
8. 残りの無限エントリを次のように置き換えます。`-1`。 
9. 出力`ans[1] ... ans[n]`。 

### なぜ効果があるのか

 価値のために`x`、連続する出現間の最大距離 (配列境界を含む) によって、長さのない最長領域が決まります。`x`。 

サブ配列で回避できるのは`x`まさにそのような領域内に完全に収まるときです。 サブ配列の可能な最大長。`x`は`largest_gap(x) - 1`。 

したがって、長さのすべての部分配列は、`k`含まれています`x`まさにいつ`k ≥ largest_gap(x)`。 

アルゴリズムは、すべての値に対してこのしきい値を計算します。 値は、そのしきい値から有効な候補となり、その後も有効なままになります。 それぞれのすべての候補の中から最小値を取得します。`k`必要な k-驚異的な数を正確に生成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    out = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        pos = [[] for _ in range(n + 1)]

        for i, x in enumerate(a, start=1):
            pos[x].append(i)

        INF = n + 1
        ans = [INF] * (n + 1)

        for value in range(1, n + 1):
            if not pos[value]:
                continue

            mx_gap = 0
            prev = 0

            for p in pos[value]:
                mx_gap = max(mx_gap, p - prev)
                prev = p

            mx_gap = max(mx_gap, n + 1 - prev)

            ans[mx_gap] = min(ans[mx_gap], value)

        for k in range(2, n + 1):
            ans[k] = min(ans[k], ans[k - 1])

        result = []

        for k in range(1, n + 1):
            if ans[k] == INF:
                result.append("-1")
            else:
                result.append(str(ans[k]))

        out.append(" ".join(result))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```出現リストはソリューションの基礎です。 各値について必要なのは、その値が出現する位置だけです。出現間の最大ギャップによって、その値がいつ有効になるかが完全に決まるからです。 

境界位置`0`そして`n+1`を通じて暗黙的に処理されます`prev = 0`そして最終チェック`n + 1 - prev`。 どちらかの境界を忘れることは、この問題で最も一般的なバグです。 最初の位置に出現する値には、依然として次のサイズのプレフィックス ギャップが残ります。`1`、最後の位置に表示される値には、サフィックスのサイズのギャップがまだ残ります。`1`。 

配列`ans`情報をしきい値ごとに保存します。 もし`need[x] = 5`、次に値`x`最初に有効になるのは`k = 5`。 プレフィックス最小パスは、これらのしきい値エントリをすべてのより長い長さの応答に変換します。

 次のことを考慮してください。```
