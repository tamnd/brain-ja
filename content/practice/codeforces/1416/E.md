 ## 解決策
 ## 問題の理解

 正の整数の配列が与えられ、配列内の各要素を 2 つの正の整数に分割し、その合計が元の数値に等しくなるようにすることができます。 すべての要素を分割した後、これらのペアを連続して配置して新しい配列を構築します。 次に、連続する等しい数値を 1 つの数値にマージします。 私たちの目標は、マージ後のこの配列の最終的な長さを最小限に抑えることです。 

入力サイズは、すべてのテスト ケースにわたって最大 500,000 要素にすることができます。 各要素の大きさは次のとおりです。$10^9$。 各要素に対して考えられるすべての分割を試みる総当り的なアプローチは、最悪の場合には指数関数的になるでしょうが、これは明らかに実行不可能です。 テストケースごとに線形または線形に近いアプローチが必要です。 重要な洞察は、隣接する分割の境界の数値が等しい場合にのみ、最終的な配列内の連続する要素がマージされるということです。 したがって、当社の戦略は、合併の機会を最大化するために、これらの境界を制御することに重点を置く必要があります。 

間違いやすいエッジ ケースには、すべて同じ値を持つ配列、小さな数値が交互に並ぶ配列、素数または最小値 (2) などがあります。 たとえば、次の場合$a = [2,2,2]$、それぞれを分割します$[1,1]$与えるだろう$b = [1,1,1,1,1,1]$にマージします$[1]$。 境界でのマージ効果を考慮しない単純なアプローチでは、最終的な長さ 6 が誤って予測されてしまいます。 

## アプローチ

 ブルート フォースのアプローチは簡単です。要素ごとに、考えられるすべてのペアの分割を試し、マージ プロセスをシミュレートします。 これは、考えられるすべての組み合わせを検討するので正しいですが、遅すぎます。 単一の要素の場合$x$、 がある$x-1$有効な分割と$n$要素を追加すると、操作数がすぐに膨大になります。 

効率的な解決策につながる重要な観察は、各分割の正確な値が必要ないということです。 分割の最初の部分または 2 番目の部分が配列内の前の数値と一致するかどうかを知る必要があるだけです。 これにより、各ステップで 2 つの状態のみを追跡できます。マージされた配列の最後の数値が現在の分割の最初または 2 番目の部分と等しい場合の最終的な最小長です。 動的プログラミングを使用すると、これらの状態を効率的に維持できます。 要素ごとに、以前の状態に基づいて新しい状態を計算し、可能な限りマージを継続する分割を選択します。 これにより、複雑さがテスト ケースあたり O(n) に軽減されます。

 ## アルゴリズムのチュートリアル

 1. 2 つの変数を初期化します。`prev_len1`そして`prev_len2`の最小長を表します。`b`マージされた配列の最後の要素が、前の分割の最初または 2 番目の番号と一致する場合。 処理前は配列が空であるため、最初は両方を 0 に設定します。 
2. 各要素を反復処理する`x`配列内で`a`。 それぞれについて`x`、次の 2 つの分割を考えてみましょう。`(1, x-1)`そして`(x-1, 1)`。 これらは極端な分割を表し、両方の数値が等しい可能性を最小限に抑えますが、境界一致をテストするには十分です。 
3. 各候補の分割について`(p,q)`、潜在的な新しい長さを計算します。`b`合併後。 もし`p`の前の数値と等しい`b`、マージされ、長さは増加しません。 それ以外の場合は、前の長さに 1 を加えます。 
4.アップデート`prev_len1`そして`prev_len2`マージされた配列の最後の番号が次の場合に達成可能な最小の長さになります。`q`または`p`、 それぞれ。 可能な最後の 2 つの数字に対応する 2 つの状態のみを保持します。 このステップにより、配列を明示的に保存せずに、最適な長さの可能性を確実に引き継ぐことができます。`b`。 
5. すべての要素を処理した後、可能な最小の長さは`b`の最小値です`prev_len1`そして`prev_len2`。 

このアルゴリズムが機能するのは、次の不変条件が維持されているためです。`prev_len1`そして`prev_len2`各境界番号に対して達成可能な最小の長さを常に格納します。 必要な境界条件のみを考慮することで、問題を指数関数的な分割から要素ごとの一定の作業に削減します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

T = int(input())
for _ in range(T):
    n = int(input())
    a = list(map(int, input().split()))
    
    # previous states: last number in merged array and current length
    prev_numbers = set()
    prev_numbers.add(a[0])  # first element if we treat as one big split
    prev_len = {a[0]: 1}
    
    for i in range(n):
        x = a[i]
        candidates = [(1, x-1), (x-1, 1)]
        new_len = {}
        for p,q in candidates:
            for last_num in prev_len:
                length = prev_len[last_num]
                length += (p != last_num)
                if q not in new_len or length < new_len[q]:
                    new_len[q] = length
        prev_len = new_len
    
    print(min(prev_len.values()))
```コードは最初にテスト ケースの数と配列を読み取ります。 私たちは辞書を使います`prev_len`の最小長を追跡するには`b`マージされた配列の最後の数値が特定の値である場合。 配列要素ごとに 2 つの分割を考慮し、以前に考えられるすべての最後の数値の新しい長さを計算し、更新します。`prev_len`最小限の長さのみを維持します。 最後に、最小の長さを次のように出力します。`prev_len`。 

繊細さは更新にあります`prev_len`効率的: マージは境界で発生するため、最後の番号のみを考慮します。 配列全体を維持しようとすると不必要かつ時間がかかります。 この選択により、メモリと時間の使用量が線形に保たれます。
