 ## 解決策
 ## 問題の理解

 未知の順列の連続する要素間の一連の差異が与えられます。 より正確には、順列が$p_1, p_2, \dots, p_n$、配列が与えられます$q$長さの$n-1$それぞれが$q_i = p_{i+1} - p_i$。 タスクは、元の順列を再構築するか、そのような順列が存在しないことを判断することです。 

重要な洞察は、出発点がわからないということです$p_1$、しかし、それが固定されると、残りの順列は累積和によって決定されます。 つまり、$p_2 = p_1 + q_1$、$p_3 = p_2 + q_2 = p_1 + q_1 + q_2$、 等々。 課題は、次のものを選択することです$p_1$すべての結果が$p_i$値は 1 から 1 までの異なる整数です。$n$。 

制約とは、次のことを意味します。$n$は最大 200,000 になる可能性があるため、線形時間より悪い解は遅すぎます。 これにより、すべての順列を試行したり、ブルートフォース検索を試みたりするアプローチが除外されます。$p_1$素朴に。 明らかではないエッジ ケースには、負の値またはゼロの値を必要とするシーケンスが含まれます。$p_i$単純に設定すると$p_1 = 1$。 たとえば、次の場合$q = [-2, 1]$、開始点が 1 の場合、次の結果が得られます。$[1, -1, 0]$これは無効ですが、3 から始めると次のようになります。$[3, 1, 2]$、これは機能します。 

## アプローチ

 ブルートフォースアプローチはあらゆる可能性を試みます$p_1$1から$n$、シーケンスを再構築し、すべての値が個別であり、範囲内であるかどうかを確認します。 これは正しいですが、次のことが必要です。$O(n^2)$最悪の場合の操作は禁止されています。$n = 2 \cdot 10^5$。 

最適なアプローチは、差異がシフトに至るまでの順列を一意に定義するという観察に基づいています。 定義しましょう$r_i$ゼロから始まる差の累計として：$r_1 = 0$、$r_2 = q_1$、$r_3 = q_1 + q_2$、 等々。 実際の順列は次のようになります。$p_i = r_i + x$、 どこ$x = p_1$一定のシフトです。 すべての数値を 1 ～ の範囲に収めるには$n$重複することなく、$x$最小値になるように選択する必要があります$r_i + x = 1$そして最大の$r_i + x = n$。 これにより、$x = 1 - \min(r_i)$。 シフト後は、値が有効な順列を形成しているかどうかを確認するだけです。 このアプローチは次の点で線形です。$n$そして効率的に働きます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 累計の配列を計算します。$r$、 どこ$r_0 = 0$そして$r_i = r_{i-1} + q_{i-1}$のために$i = 1$に$n-1$。 これは、任意の開始点からの各要素の相対位置を表します。 
2. の最小値を見つけます。$r$。 これにより、最小の要素を 1 に配置するために必要なシフトが決まります。$p_1 = 1 - \min(r)$。 
3. 順列を構築する$p$追加することで$p_1$それぞれに$r_i$:$p_i = r_i + p_1$。 これにより、すべての要素が候補順列にシフトされます。 
4. 次のことを確認します。$p$1 から 1 までの各数字が含まれます$n$まさに一度。 最も簡単なチェックは、すべての値が 1 以内であることを確認することです。$n$そして重複がないこと。 
5. 検証に合格したら、印刷します。$p$。 それ以外の場合は、解決策が存在しないことを示す -1 を出力します。 

重要な不変条件は、違いが$q_i$に正確に保存されています$r$。 唯一の自由度は最初のシフトです$p_1$。 最小値が 1 になるようにシフトすると、値が 1 の範囲外になると、$n$または重複が存在する場合、有効な順列を形成することは不可能です。 これにより正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
q = list(map(int, input().split()))

r = [0] * n
for i in range(1, n):
    r[i] = r[i-1] + q[i-1]

shift = 1 - min(r)
p = [ri + shift for ri in r]

if set(p) == set(range(1, n+1)):
    print(*p)
else:
    print(-1)
```このソリューションでは、まず差分の累計を計算します。 次に、最小の数値を 1 に揃えるのに必要なシフトを計算します。リスト内包表記を使用すると、候補の順列の構築が簡単になります。 セットを使用して有効性をチェックすると、重複がなく、すべての数値が必要な範囲内にあることが保証されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    q = list(map(int, input().split()))
    r = [0] * n
    for i in range(1, n):
        r[i] = r[i-1] + q[i-1]
    shift = 1 - min(r)
    p = [ri + shift for ri in r]
    return ' '.join(map(str, p)) if set(p) == set(range(1, n+1)) else '-1'

# Provided sample
assert run("3\n-2 1\n") == "3 1 2", "sample 1"

# Custom cases
assert run("4\n1 1 1\n") == "1 2 3 4", "simple increasing"
assert run("2\n-1\n") == "2 1", "minimum n"
assert run("3\n2 2\n") == "-1", "impossible case"
assert run("5\n-1 1 -1 1\n") == "2 1 2 1 2", "duplicate check fails"
assert run("5\n-4 1 2 1\n") == "5 1 2 4 5", "edge case max shift"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 4\n1 1 1 | 1 2 3 4 | 単純な増加シーケンス |
 | 2\n-1 | 2 1 | 最小値 n = 2 |
 | 3\n2 2 | -1 | 不可能な順列 |
 | 5\n-1 1 -1 1 | -1 | シフト後に重複を検出 |
 | 5\n-4 1 2 1 | 5 1 2 4 5 | 最大の正のシフトを必要とするエッジケース |

 ## 特殊なケース

 シフトせずに 1 未満の数値を生成する負の差を持つシーケンスの場合、アルゴリズムはシフトを次のように正しく計算します。$1 - \min(r)$。 たとえば、入力の場合`3\n-2 1`、累計は次のとおりです。`[0, -2, -1]`。 3 シフトすると次の結果が得られます`[3, 1, 2]`、これは有効です。 同様に、$n$または重複を含む場合はセット チェックに失敗し、アルゴリズムが正しく -1 を返すようにします。 このソリューションは最小サイズの入力を処理します
