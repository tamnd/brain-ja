 ## 問題の理解

 各キャンディーの重さが 1 グラムまたは 2 グラムのキャンディーのコレクションがあります。 アリスとボブは、それぞれが受け取る総重量がまったく同じになるようにキャンディーを分割したいと考えています。 各テスト ケースの入力により、キャンディーの数と個々の重みが得られます。 公平な分割が可能であれば出力は単純に「YES」、それ以外の場合は「NO」になります。 

問題の制約から、テスト ケースごとのキャンディーの数がわかります。\(n\)、最大 100 ですが、最大 10,000 のテスト ケースが存在する可能性があります。 すべてのテスト ケースにわたるキャンディーの総数は 100,000 を超えません。 これは、2 秒の制限時間内に収めたい場合、テスト ケースごとに O(n) より悪いものは許容できないことを意味します。\(10^8\)通常は問題ありませんが、\(10^9\)Python では厳しいかもしれません。 

キャンディーは分割できないため、微妙な点が生じます。 重みの合計が均等であっても、公平な分割を保証するには必ずしも十分ではありません。 たとえば、重さ 2 グラム、1 グラム、2 グラムのキャンディーが 3 個ある場合、合計は 5 になりますが、これは奇数であるため、直ちに不可能です。 不注意な解決策では、合計が均等であるかどうかだけをチェックする可能性がありますが、重さ 2 のキャンディーが 1 つだけある場合や、合計は均等であるが、利用可能な 1 グラムと 2 グラムのキャンディーを使用して配分のバランスをとれない組み合わせなど、いくつかの特殊なケースでは失敗します。 

エッジケースには、1 グラムのキャンディーのみ、2 グラムのキャンディーのみ、合計重量が奇数、合計重量は偶数だが 1 グラムのキャンディーの数が奇数である組み合わせが含まれます。 これらは 2 つの等しいサブセットを形成する能力に影響するため、合計の均等性と各キャンディー タイプの数の両方について慎重に検討する必要があります。 

## アプローチ

 ブルートフォースアプローチは、キャンディーの可能なすべてのサブセットを試し、サブセットの合計が総重量の半分に達するかどうかを確認することです。 これは部分集合和問題と同等です。 n=100 の単一テスト ケースの場合、サブセットの数は次のようになります。\(2^{100}\)、これは天文学的に大きいため、まったく実用的ではありません。 合計の重みを 2 で割った値までの合計をチェックする動的プログラミング アプローチを使用した場合でも、O(n * sum(weights)) がかかり、テスト ケースごとに最大 200 になる可能性があります。 それは許容範囲ですが、単純な算術推論を使用するとさらに優れた結果を得ることができます。 

重要な観察は、キャンディーの種類が 2 つだけであるということです。 させて\(c_1\)は 1 グラムのキャンディーの数であり、\(c_2\)2グラムのキャンディーの数になります。 総重量は\(c_1 + 2 c_2\)。 公平に分割するには、この合計が均等でなければなりません。 さらに、合計の重みが均等な場合、課題は合計の半分に等しいサブセットを形成することになります。 1 グラムと 2 グラムのキャンディーの総重量の半分の整数しか選択できないため、それを呼び出します。\(S\)、次の組み合わせを使用して達成できる必要があります。\(c_1\)ものと\(c_2\)2つ。 これは、S が奇数で、パリティを調整するための 1 グラムのキャンディーがない場合にのみ不可能です。 言い換えれば、総重量が奇数であれば、答えは「NO」になります。 総重量が偶数の場合、S が奇数であり、奇数にするための 1 グラムのキャンディーがない限り、答えは「YES」です。奇数の場合、答えは「NO」です。 

この洞察により、1 と 2 のカウントを使用して、テスト ケースごとに非常に単純な O(1) チェックが可能になります。 サブセットを反復処理したり、動的プログラミングを使用したりする必要はなくなりました。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 |---|---|---|---|
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、n とキャンディーの重量のリストを読み取ります。 
2. 1グラムのキャンディーの数を数えます。\(c_1\)、2グラムのキャンディーの数、\(c_2\)。 このステップにより、合計分布を推論するための重要なデータが得られます。 
3. 総重量を計算する\(T = c_1 + 2 c_2\)。 もし\(T\)が奇数の場合は、公平な分割ができないため、「NO」が出力されます。 
4. もし\(T\)偶数なので合計の半分を計算し、\(S = T / 2\)。 これは、2 つのサブセットのうちの 1 つの目標合計です。 
5. 入手可能な 2 グラムのキャンディーを使用して S が達成可能かどうかを確認します。 k を S // 2 と S を超えずに使用できる 2 グラムのキャンディーの最大数である c_2 の最小値とします。 
6. 2 グラムのキャンディーの重量を差し引きます。\(2 k\)残りの重量が 1 グラムのキャンディーで正確にカバーできる場合、つまり S - 2 k ≤ c_1 の場合、「YES」を出力します。 それ以外の場合は「NO」を出力します。 

機能する理由: このアルゴリズムでは、常に合計の半分を超えずにできるだけ多くの 2 グラムのキャンディーを選択するため、正確さが保証されます。これにより、1 グラムのキャンディーでカバーされる残りの合計が減ります。 重みは 1 と 2 のみであるため、達成可能な合計はこれら 2 つの組み合わせとなるため、この貪欲な選択で十分です。 パリティ チェックにより、合計が奇数の場合に不可能な分割が試行されることがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can_divide(weights):
    c1 = weights.count(1)
    c2 = weights.count(2)
    total = c1 + 2 * c2
    if total % 2 != 0:
        return "NO"
    half = total // 2
    # use as many 2s as possible without exceeding half
    max_twos = min(c2, half // 2)
    remaining = half - 2 * max_twos
    if remaining <= c1:
        return "YES"
    return "NO"

t = int(input())
for _ in range(t):
    n = int(input())
    weights = list(map(int, input().split()))
    print(can_divide(weights))
```このコードは、各テスト ケースの 1 と 2 の数をカウントします。 奇数の合計は即座に拒否されます。 合計が偶数の場合、合計の半分をできるだけ多くの 2 グラムのキャンディーで満たし、残りの合計が 1 グラムのキャンディーで作れるかどうかをチェックします。 min(c2,half // 2) を使用すると、目標合計のオーバーシュートを回避できます。 このソリューションは複数のテスト ケースを効率的に処理し、不必要な反復を回避します。 

## 実用的な例

 サンプル 1、1 番目と 4 番目のテスト ケースをトレースします。 

| n | 重み | c1 | c2 | 合計 | 半分 | マックスツー | 残り | 出力 |
 |---|---|---|---|---|---|---|---|---|
 | 2 | [1,1] | 2 | 0 | 2 | 1 | 0 | 1 | はい |
 | 3 | [2,2,2] | 0 | 3 | 6 | 3 | 1 | 1 | いいえ |

 最初のトレースは、1 グラムのキャンディーが 2 つある場合、合計は 2、半分は 1、そして存在するターゲットに到達するには重量 1 のキャンディーが 1 つ必要であることを示しており、「YES」となります。 4 番目のトレースは合計 6、半分は 3 です。2 に貢献する 2 グラムのキャンディーを 1 つ取ることができますが、3 に達するにはさらに 1 つ必要です。1 グラムのキャンディーがないため、できません。「いいえ」となります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = []
    t = int(input())
    for _ in range(t):
        n = int(input())
        weights = list(map(int, input().split()))
        out.append(can_divide(weights))
    return "\n".join(out)
