 # 問題の理解

 タスクは、数字かどうかを判断することです。`N`正確に次の合計として書くことができます`K`すべての項が非負の整数乗である項`X`。 このような表現が存在する場合は、用語を降順で出力する必要があり、すべての有効な降順シーケンスの中で辞書編集的に最小のものが必要です。 入力には 1 つの大きなターゲット値が含まれています`N`、必要な加数の数`K`、そしてベース`X`。 出力は、不可能な答えか、慎重に選択された次の累乗のリストのいずれかです。`X`正確にその合計は`N`。 

の値`N`到達できる`10^18`、そのため、可能なすべてのパワーの組み合わせを構築しようとすることは不可能です。 すべての値を反復処理しても、`N`あまりにも多くの操作が必要になります。 ベースはせいぜい`9`、これは次の基本表現を意味します。`N`約60桁しかありません。 の値`K`に限定されています`2 * 10^5`、したがって、アルゴリズムは次の値に比例する操作を行うことができます。`K`基本桁の数ですが、二次関数ではありません。`K`。 

よくある間違いは、通常のベースのみをチェックすることです`X`表現してそこで停止します。 基本表現では項の数が最小になりますが、問題では正確に次のことが求められます。`K`したがって、権力をより小さな権力に分割する必要があるかもしれません。 もう 1 つの間違いは、辞書編集上の順序を考慮せずに、恣意的に権限を分割することです。 

たとえば、次のことを考えてみましょう。```
9 4 2
```のバイナリ表現`9`は`1001`、条件を与える`8`そして`1`。 これには 2 つの用語だけが使用されます。 不用意にアプローチすると、亀裂が入る可能性があります`8`すぐに 8 つに分割できますが、それでは用語が多すぎます。 正しい答えは次のとおりです。```
YES
4 2 2 1
```4 つの項を合計すると、`9`、この順序は、次のような代替順序よりも辞書編集的に小さいです。`2 2 2 2 1`、必要な長さすらありません。 

もう 1 つのエッジ ケースは、要求された項の数が基本表現にすでに存在する数よりも小さい場合です。 例えば：```
10 1 2
```バイナリ表現は`1010`、 意味`10 = 8 + 2`。 各期のパワーを維持しながらパワーを統合する方法はありません。`2`したがって、正しい出力は次のようになります。```
NO
```最後のエッジケースは、必要な項数の増加が達成できない場合に発生します。 すべての分割`X^i`の中へ`X`のコピー`X^(i-1)`項の数を正確に増加させます`X - 1`。 例えば：```
5 2 3
```の三項表現`5`は`12`、次の 3 つの項が与えられます。`3 + 1 + 1`。 要求された条件よりも多くの条件がすでに必要であるため、答えは次のようになります。```
NO
```## アプローチ

 直接的なアプローチは、権力を分断するあらゆる可能な方法を生み出すことです。 ベースから始めましょう`X`代表を選択し、権力を繰り返し選択する`X^i`と置き換える`X`のコピー`X^(i-1)`。 この操作では合計が保存され、項の数が次のように増加します。`X - 1`。 これらの分割を逆にすると、すべての有効な表現を基本表現に変換して戻すことができるため、このアプローチは正しいです。 ただし、考えられるすべての選択肢を検索することは不可能です。 可能な分割シーケンスの数は爆発的に増加し、中程度の規模の場合はすべての選択肢を試してみることさえあります。`K`限界を超えてしまうだろう。 

重要な観察は、基底表現がすでに最小数の項を与えているということです。 必要な操作は分割だけです。 各分割は用語数に同じ影響を及ぼし、辞書編集上の要件によってどの分割が最適であるかがわかります。 最初に大きな累乗を分割すると、最終的な降順リストに現れる最大値が早く小さくなり、辞書編集上の順序が改善されます。 

必要な分割数は固定です。 基本表現に次のものが含まれる場合、`C`条件が必要です`K - C`追加の条件。 分割するたびに加算されるため、`X - 1`この条件では、分割数は次のようにする必要があります。```
(K - C) / (X - 1)
```これが整数でない場合、解は存在しません。 それ以外の場合は、常にこの数の分割を貪欲に実行し、常に最大の利用可能な電力を取得します。 可能な力は約 60 個しかありません。`N`せいぜい`10^18`, したがって、このプロセスは非常に小さいです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | O(状態の数) | 遅すぎる |
 | 最適 | O(log_X(N) + K) | O(log_X(N)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.変換`N`基地に`X`。 位置の数字`i`のコピー数を教えてください`X^i`私たちは現在持っています。 使用する用語が最小限であるため、これが開始表現となります。 
2. この表現内の項の数を数えます。 この数がより大きい場合は、`K`、出力`NO`分割すると項の数が増えるだけだからです。 
3. 必要な追加項の数を計算します。 もし`K - count`で割り切れない`X - 1`、出力`NO`考えられるすべての操作で用語カウントが正確に変更されるため、`X - 1`。 
4. 最大の累乗から始めて、必要な分割がまだ残っている間に、できるだけ多くの項を分割します。 分割`X^i`1 つの大きな用語を削除して、`X`したがって、最初に最大の累乗でこれを行うと、辞書編集的に最小の答えが得られます。 
5. 必要な分割がすべて実行された後、保存されたカウントをべき乗のリストに展開し、最大から最小の順に出力します。 

なぜ効果があるのか:

 基本表現は、項が最も少ない一意の表現です。 他の有効な表現は、それに分割を適用することによってのみ取得できます。 このアルゴリズムは必要な数の分割を正確に実行するため、正確な表現が得られます。`K`条項。 可能な分割のすべての選択肢の中で、より大きな累乗を早く置き換えると、2 つの降順シーケンスが異なる可能性がある最初の位置が常に減少し、生成されるシーケンスが辞書編集的に最小になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, K, X = map(int, input().split())

    cnt = []
    temp = N
    while temp:
        cnt.append(temp % X)
        temp //= X

    if not cnt:
        cnt = [0]

    current = sum(cnt)

    if current > K:
        print("NO")
        return

    diff = K - current
    if diff % (X - 1) != 0:
        print("NO")
        return

    need = diff // (X - 1)

    for i in range(len(cnt) - 1, 0, -1):
        if need == 0:
            break
        take = min(cnt[i], need)
        if take:
            cnt[i] -= take
            if i - 1 == len(cnt):
                cnt.append(0)
            cnt[i - 1] += take * X
            need -= take

    if need != 0:
        print("NO")
        return

    ans = []
    power = 1
    powers = []
    for _ in range(len(cnt)):
        powers.append(power)
        power *= X

    for i in range(len(cnt) - 1, -1, -1):
        ans.extend([str(powers[i])] * cnt[i])

    print("YES")
    print(" ".join(ans))

if __name__ == "__main__":
    solve()
```コードは最初にベースを格納します`X`の数字`cnt`。 のインデックス`cnt`は指数を表すので、`cnt[3] = 2`のコピーが 2 つあることを意味します`X^3`。 

変数`current`は最小表現内の項の数です。 可算性チェック`X - 1`分割するたびにその量だけカウントが変更されるため、不可能なケースを試行することがなくなります。 

ループは、指数を高い方から低い方へ処理します。 金額`take`は現在の指数を分割する回数です。 小さいべき乗の前に大きなべき乗を削除することは、辞書編集上の要件を強制する部分です。 

最終的な展開は指数の逆順で行われるため、出力されるシーケンスはすでに降順になっています。 Python の整数は、次の大きな値を処理します。`N`安全に生成され、生成される用語の総数は次のように制限されます。`K`、最大でも`200000`。
