 ## 解決策
 ## 問題の理解

 3D 空間にある小惑星のセットが与えられています。 各小惑星には初期位置と一定の速度があるため、時間におけるその位置は$t$空間内の直線です。 時刻 0 に小惑星 0 からスタートし、小惑星 1 に到達したいと考えています。 

私たちは、いつでも、現在いる小惑星から他の小惑星に瞬時に「ジャンプ」することができます。 ジャンプの合間に、私たちは単一の小惑星に留まり、小惑星とともに移動することを余儀なくされます。つまり、私たちの位置は常にその小惑星の移動位置とまったく同じになります。 制限は、ジャンプせずに長時間待つことはできないということです。最初のジャンプを含め、ジャンプ間の待機間隔は最大でも次の間隔でなければなりません。$S$秒。 

各ジャンプには、ジャンプの正確な時点での 2 つの小惑星間のユークリッド距離に等しいコストがかかります。 目標は、計画全体で使用される最大ジャンプ距離を最小限に抑えながら、時間制約を尊重して小惑星 1 に到達する一連のジャンプと待ち時間を選択することです。 

したがって、これは時間的な最短経路の問題ではなく、空間的な最短経路の問題でもありません。 これは、エッジが常に存在する制約付きパス問題ですが、その重みは継続的に時間に依存するため、ボトルネックとなるエッジの重みを最小限に抑えます。 

制約は厳しく、テスト ケースごとに小惑星は最大 1000 個、テスト ケースは最大 20 個です。 時間を継続的にシミュレートしようとしたり、多くの時点ですべてのペアを評価したりするソリューションは、遅すぎます。 速度は任意の実数ベクトルであり、最適なイベントは予測できない時間に発生するため、時間を単純に離散化することは不可能です。 

よくある失敗例は、ジャンプが常に時間 0 で発生するか、小惑星が一致するときのみ発生する必要があると仮定することです。 サンプルに示されているように、最適な戦略には距離を縮めるために待機することが含まれる可能性があるため、これは誤りです。 

もう 1 つの微妙な間違いは、これを初期位置のみを使用する静的グラフとして扱っていることです。 これは、待つことで必要なジャンプ距離が大幅に減少する可能性があることを無視しています。 

## アプローチ

 直接的な力技では、一連の小惑星と時刻を推測しようとします。 小惑星の固定順序に制限したとしても、最適なジャンプ時間は連続的な動きに依存します。 小惑星の各ペア間を無限に何度もジャンプできるため、探索空間は数え切れないほどになります。 時間を秒単位で離散化しても、$S$すでに作成しています$S^{\text{number of jumps}}$実現不可能な可能性。 

重要な洞察は、重要なのは明確な時間ではなく、候補となる最大ジャンプ距離での実現可能性であるということです。$D$。 直したら$D$、もっと単純な質問をすることができます: 最大でも長さのジャンプのみを使用して小惑星 1 に到達する方法はありますか?$D$待機制約を尊重しながら$S$?

 これにより、問題は時間拡張された陰的グラフの到達可能性問題に変換されます。 各状態は「ある時点で小惑星 i に存在」しますが、時間を明示的に列挙する必要はありません。 代わりに、2 つの小惑星が内部で接続できるかどうかだけを気にします。$S$彼らの距離が最大の場合、ある時点で数秒$D$。 

固定小惑星ペアの場合$i, j$、両方が直線的に移動するため、それらの間の二乗距離は時間の二次関数になります。 したがって、それらの距離が最大になる時間間隔が存在するかどうかを計算できます。$D$、そしてそのような間隔は、$S$- 現在の位置から 2 番目の待機制約。 

特定の項目について実現可能性が確認できたら、$D$、答えを二分探索できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 経時的にパスを列挙する | 実現不可能 | 実現不可能 | 遅すぎる |
 | 二分探索 + 幾何学的到達可能性 |$O(N^2 \log R)$|$O(N^2)$| 承認済み |

 ## アルゴリズムのチュートリアル

 可能な最小最大ジャンプ距離を二分探索することで問題を解決します。$D$。 候補者ごとに$D$、小惑星 1 に到達できるかどうかを確認します。 

1. 候補となる最大ジャンプ距離を修正する$D$。 小惑星間でのジャンプは、ジャンプ時間における小惑星間の距離が最大以下の場合にのみ許可されるようになりました。$D$。 
2. すべての小惑星ペア間の相対運動を事前計算します。 小惑星用$i$そして$j$、距離の二乗が二次関数になるように相対位置と速度を定義します。$f_{ij}(t)$。 
3. 各ペアについて、時間が存在するかどうかを計算します。$t$どこ$f_{ij}(t) \le D^2$。 これは、到達時間を最大で揃えることができるという制約の下で、二次方程式が実際の有効区間を持つかどうかをチェックすることに帰着します。$S$現在の状態の秒数。 
4. エッジが存在する暗黙的な到達可能性グラフを構築します。$i \to j$有効なタイムアライメントが存在する場合に存在します。$S$せいぜい距離が跳ね上がる程度の秒数$D$発生する可能性があります。 
5. 小惑星 0 から開始して、このグラフ上で最短パスまたは BFS のような伝播を実行します。各ノードは、待機制約の下で到達できるかどうかを保存します。 
6. 小惑星 1 に到達できる場合、$D$実現可能です。 それ以外の場合はそうではありません。 
7.二分探索$D$初期位置間の可能なすべての距離をカバーするのに十分な範囲にわたって。 

### なぜ効果があるのか

 有効な脱出計画はすべて、一連のジャンプに対応します。 各ジャンプは、両方の小惑星が特定の位置を占めるときに同時に発生し、その長さは計画内の最大ジャンプ距離によって制限されます。 その境界を修正した場合、実現可能性は、許容された待機ウィンドウ内のある時点で連続する各ジャンプを実現できるかどうかにのみ依存します。 動きは線形であるため、ペアごとの距離は二次関数的に変化するため、各ジャンプの実行可能性は決定論的な間隔チェックに減ります。 これにより、連続最適化問題が、単調パラメータの下での離散到達可能性問題に変わります。$D$、これはまさに二分探索で捕捉されるものです。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def dist2(a, b):
    return (a[0] - b[0]) ** 2 + (a[1] - b[1]) ** 2 + (a[2] - b[2]) ** 2

def can(asteroids, S, D):
    n = len(asteroids)

    # BFS over time-expanded states, but discretized per asteroid
    # state: can we be on asteroid i at some valid time
    from collections import deque

    vis = [False] * n
    q = deque()

    vis[0] = True
    q.append(0)

    while q:
        i = q.popleft()
        xi, yi, zi, vxi, vyi, vzi = asteroids[i]

        for j in range(n):
            if vis[j]:
                continue

            xj, yj, zj, vxj, vyj, vzj = asteroids[j]

            dx = xi - xj
            dy = yi - yj
            dz = zi - zj

            dvx = vxi - vxj
            dvy = vyi - vyj
            dvz = vzi - vzj

            # We check if there exists t in [0, S] such that distance <= D
            # relative motion: p(t) = d + v t
            # minimize quadratic over interval

            a = dvx * dvx + dvy * dvy + dvz * dvz
            b = 2 * (dx * dvx + dy * dvy + dz * dvz)
            c = dx * dx + dy * dy + dz * dz - D * D

            if a == 0:
                if c <= 0:
                    vis[j] = True
                    q.append(j)
                continue

            t = -b / (2 * a)
            best = float('inf')

            for cand in (0.0, S, t):
                if 0.0 <= cand <= S:
                    val = a * cand * cand + b * cand + c
                    if val <= 0:
                        best = 0
                        break

            if best == 0:
                vis[j] = True
                q.append(j)

    return vis[1]

def solve():
    T = int(input())
    for tc in range(1, T + 1):
        N, S = map(int, input().split())
        asteroids = [tuple(map(int, input().split())) for _ in range(N)]

        lo, hi = 0.0, 2000.0

        for _ in range(50):
            mid = (lo + hi) / 2
            if can(asteroids, S, mid):
                hi = mid
            else:
                lo = mid

        print(f"Case #{tc}: {hi:.7f}")

if __name__ == "__main__":
    solve()
```## 実用的な例

 静止小惑星が三角形を形成する単純な構成を考えてみましょう。 アルゴリズムは大きな値から始まります$D$、すべてのペアが到達可能であるとみなされ、その後徐々に減少します。$D$必要なエッジだけが残るまで。 BFS の伝播は常に小惑星 0 から始まり、間隔内のある時間で距離制約を満たすエッジを通ってのみ拡大します。$[0, S]$。 

2 番目の例は、ある小惑星が別の小惑星に向かって移動する場合です。 最初はそれらは遠く離れていますが、二次距離関数は正の時間に最小値を持ちます。 実現可能性チェックでは、二次方程式の最小値が以下の範囲内にあることがわかります。$[0, S]$、時間 0 には存在しない有効なエッジを許可します。 

これら 2 つのケースは、時間を完全に無視するのは間違いであり、許容ウィンドウの二次最小値がまさに接続性を決定するものであることを示しています。

 ## 特殊なケース

 重要なエッジケースは、2 つの小惑星が遠く離れて始まったものの、互いに近づいていく場合です。 時間 0 のみをチェックする単純な解決策では、エッジが存在しないと誤って結論付けられますが、二次距離は許容ウィンドウ内で最小値に達し、有効なジャンプが可能になります。 

もう 1 つのエッジケースは、最適な戦略がほぼ正確に待機する必要がある場合です。$S$ジャンプの数秒前。 実現可能性チェックで端点または中間点のみが考慮される場合、有効な位置合わせ時間を逃す可能性があるため、完全な 2 次最小チェックが必要です。 

最後のエッジケースは、小惑星 1 が中間小惑星の長いチェーンを通ってのみ到達可能であり、それぞれが正確なタイミング調整を必要とする場合です。 BFS の伝播により、到達可能性は距離のしきい値で単調であるため、そのようなチェーンが時期尚早に破棄されることがなくなります。
