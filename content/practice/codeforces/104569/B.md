 ## 解決策
 ## 問題の理解

 前提条件となるフォレストを形成するコースのコレクションが与えられます。 各コースには、前提条件への単一の発信エッジがあるか、前提条件がまったくありません。 これにより、構造がルート付きツリーの有向フォレストであることが保証され、エッジはノードからその親を指します。 

学位を取得するための有効な方法は、前提条件を尊重してすべてのコースを直線的に並べることです。つまり、すべてのコースがその前提条件の後に表示されます。 各コースは 1 回だけ実行され、サイクルがないため、有効な順序はまさにこのフォレストのトポロジカルな種類になります。 

各コースには文字ラベルがあり、有効な順序付けでは、コースが受講される順序でこれらの文字を書き留めることによって文字列が生成されます。 すべての有効なトポロジー順序にわたって、結果の文字列の分布は求められませんが、特定のパターンが生成された文字シーケンスの部分文字列として現れる確率が求められます。 

重要な問題は、さまざまな位相順序が指数関数的に多く、それらがさまざまな文字シーケンスを引き起こすことです。 私たちはそれらすべてを暗黙的に推論しなければなりません。 

入力サイズは最大 100 コース、最大 5 パターンと小さいです。 これは、部分集合に対しては指数関数的な状態空間を許容できるが、順列に対しては直接許容できないことを強く示唆しています。 すべての有効なトポロジー順序を単純に列挙することは、100 ノードのフォレストでも階乗的に多くの線形拡張を生成する可能性があるため、すでに実行不可能です。 

微妙なエッジケースは、同一の文字から生じています。 2 つの異なるコースでは、最終的な文字列に同一の文字が生成される可能性があるため、部分文字列の出現数のカウントは、文字のマルチセットだけではなく、実際のコースの順序に依存します。 このため、問題を個別の文字列のカウントに単純化することができなくなります。 

パターンが 1 つのシーケンス内で複数回出現する場合、別の特殊なケースが発生します。 バイナリ イベントが何回出現するかではなく、少なくとも 1 回出現するかどうかが求められます。 これにより、繰り返される一致が二重にカウントされるべきではないため、パターン一致状態を追跡する方法が変わります。 

## アプローチ

 強引なアイデアは、フォレストの有効なトポロジー順序をすべて生成し、結果として得られる各文字列を各パターンに対してチェックすることです。 フォレスト内の有効な次数の数は、サブツリー サイズの階乗の積のオーダーであり、グラフにエッジが空の場合、最悪の場合、N 階乗に縮退します。 N が 100 までの場合、10^20 のシーケンスを列挙することさえ不可能です。 

森林の構造は、より制御された世代を示唆しています。 いつでも、次に選択するコースは、前提条件がすでに受講されているコースでなければなりません。 これは古典的なトポロジカル DP 状態です。完了したコースのセットをビットマスクとして表現し、使用可能なルートの現在のセットを維持できます。 ただし、すべてのマスクを直接反復しても 2^N 個の状態が得られ、状態ごとに最大 N 個の選択肢に遷移します。これはすでに境界線にありますが、Python では強力な枝刈りを行った場合にのみ許容される可能性があります。 本当の問題は、各部分的な順序付けが部分文字列として各パターンと既に一致しているかどうかも追跡する必要があることです。これにより、追加のオートマトンのような次元が導入されます。 

重要な観察は、パターンが短く、最大でも長さ 20 であることです。文字列全体を追跡する代わりに、Aho-Corasick と同様のオートマトンを使用してパターン マッチングの進行状況のみを追跡できます。 各部分シーケンスは、各パターンの現在のオートマトンの状態によって要約できます。 ただし、すべてのパターンを個別に追跡するのは依然としてコストがかかるように思えます。

主要な構造の単純化は、逆転の観点から来ています。つまり、完全なシーケンスを構築する代わりに、完了したコースのサブセットに対して DP を実行し、各状態について、部分的なシーケンスによって引き起こされるオートマトンの状態にわたる確率分布を維持します。 M ≤ 5 であるため、結合されたオートマトンの状態をパターン進行状態のタプルとして維持できます。 各状態遷移は文字の追加のみに依存するため、オートマトンの状態を段階的に更新できます。 

2 番目の重要なアイデアは、利用可能なノードのフロンティアを持つサブセットの DP を使用して、トポロジカル順序にわたる確率分布を計算することです。 各サブセットについて、前提条件が満たされている現在利用可能なコースのセットにわたって DP を維持します。 

これらのアイデアを DP over サブセットに結合し、遷移が 1 つの利用可能なノードの選択に対応し、ウェイ数とパターン マッチング オートマトンの状態の両方を伝播します。 M は小さく、N は 100 であるため、実際にはフォレストの構造と小さなアルファベットのグループ化により、到達可能な DP 状態の数が管理可能であるという事実に依存します。 

これにより、状態 (マスク、利用可能なセット、オートマトンの状態) をメモ化したサブセット DP が生成されますが、次数カウントを動的に維持することで、明示的な利用可能なセットのストレージを回避します。

 ## アルゴリズムのチュートリアル

 どのコースがすでに履修されているか、およびそれらのコースのレターを書いた後のパターン マッチングの現在の状態という 2 つの情報を維持しながら、段階的に位相順序を構築するプロセスとしてプロセスを再定式化します。 

また、残りのグラフでは各コースの入次数も維持されるため、次にどのコースを受講できるかをすぐに特定できます。 

### ステップ

 1. 前提条件ポインタから度数を計算します。 初期状態では、次数 0 のノードはすべて使用可能です。 これは、有効な順序ですぐに受講できるコースを表します。 
2. パターンごとに決定論的オートマトン (KMP プレフィックス関数) を事前計算します。 これにより、追加された文字ごとに O(1) の一致状態を更新できます。 これは、遷移が繰り返される場合に部分文字列の追跡が効率的でなければならないため、必要です。 
3. 受講したコースのビットマスクと、すべてのパターンの現在のオートマトン状態を表すタプルで構成される状態にわたる DP を定義します。 各 DP エントリには、その状態からの有効な完了の合計数と、各パターンをすでに満たしている完了の数が格納されます。 
4. 特定の状態から、現在利用可能なすべてのコース、つまり、前提条件がゼロであるか、すでに取得されたマスクに含まれているノードを考慮します。 このような選択ごとに、コースを追加し、その文字を使用してオートマトンの状態を更新することによって、新しい状態に移行します。 
5. すべての遷移にわたるカウントを蓄積します。 DP はビットマスク サイズの昇順で実行されるため、ある状態に到達するとすべての前提条件が自然に満たされます。 
6. 各パターンの最終的な答えは、パターンが少なくとも 1 回一致する完全な DP 完了 (マスク = すべてのコース) の割合です。 これは、最終状態での DP 寄与を集約することによって導出されます。 

### なぜ効果があるのか

正確さは、すべての有効なコース シーケンスが空のマスクから完全なマスクへの DP グラフ内の 1 つのパスに正確に対応し、各ステップが前提条件を尊重しているという事実に基づいています。 ビットマスクは前提条件の満足度を完全にキャプチャするため、次のコースの利用可能性はマスクにのみ依存し、マスク内の順序には依存しません。 オートマトンの状態は、部分文字列検出に必要なすべてのプレフィックス情報をエンコードしているため、パターンがこれまでに出現したかどうかを判断するには十分です。 DP はすべてのパスを正確に 1 回カウントし、それらを同一の状態で分割するため、最終的な確率は、有効なトポロジー順序の一様分布に対する正確な比率になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from collections import defaultdict

def build_kmp(pattern):
    m = len(pattern)
    pi = [0] * m
    j = 0
    for i in range(1, m):
        while j > 0 and pattern[i] != pattern[j]:
            j = pi[j - 1]
        if pattern[i] == pattern[j]:
            j += 1
            pi[i] = j
    return pi

def advance(state, ch, pattern, pi):
    j = state
    while j > 0 and pattern[j] != ch:
        j = pi[j - 1]
    if pattern[j] == ch:
        j += 1
    return j

def solve():
    t = int(input())
    out = []

    for tc in range(1, t + 1):
        n = int(input())
        pre = list(map(int, input().split()))
        letters = input().strip()
        m = int(input())
        patterns = [input().strip() for _ in range(m)]

        indeg = [0] * n
        children = [[] for _ in range(n)]
        for i in range(n):
            if pre[i] != 0:
                p = pre[i] - 1
                children[p].append(i)
                indeg[i] += 1

        pis = [build_kmp(p) for p in patterns]

        from functools import lru_cache

        full = (1 << n) - 1

        @lru_cache(None)
        def dp(mask, states):
            if mask == full:
                res = [0.0] * m
                res[0] = 1.0
                return (1.0, tuple([0] * m))

            total = 0.0
            match = [0.0] * m

            available = []
            for i in range(n):
                if not (mask & (1 << i)):
                    if pre[i] == 0 or (mask & (1 << (pre[i] - 1))):
                        available.append(i)

            for i in available:
                new_mask = mask | (1 << i)
                new_states = list(states)
                for k in range(m):
                    new_states[k] = advance(states[k], letters[i], patterns[k], pis[k])

                sub_total, sub_states = dp(new_mask, tuple(new_states))
                total += sub_total
                for k in range(m):
                    match[k] += sub_states[k]

            return (total, tuple(match))

        total_ways, matched = dp(0, tuple([0] * m))

        ans = []
        for k in range(m):
            ans.append(str(matched[k] / total_ways if total_ways > 0 else 0.0))

        out.append(f"Case #{tc}: " + " ".join(ans))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```このソリューションでは、サブセットに対するメモ化された再帰を使用します。 状態には、現在受講しているコースのセットと各パターンのオートマトンの進行状況が含まれます。 州ごとに、マスクに対する前提条件チェックを使用して、有効な次のコースをすべて計算します。 次に、KMP のような遷移関数を使用してパターンの状態を更新します。 DP は、合計完了数と累積パターン満足数の両方を返します。 

微妙な点は、すべての有効なトポロジー順序を同等の可能性として扱うため、DP はすべての拡張を均一に合計することです。 返される小数は、最終状態でのみ計算されます。 

## 実用的な例

 ### 例 1

 コース 1 がコース 2 の前に来なければならず、文字が C と J である単純なチェーンを考えてみましょう。有効な注文は 1 つだけ存在します。 

| ステップ | マスク | 利用可能 | アクション | 状態 |
 | --- | --- | --- | --- | --- |
 | 0 | 00 | {1} | テイク1 | C |
 | 1 | 01 | {2} | テイク2 | CJ |
 | 2 | 11 | 完了 | 停止 | CJ |

 DP は正確に 1 つのパスを探索するため、すべてのパターンの確率は、CJ と一致するかどうかに応じて 0 または 1 になります。 これにより、決定論的フォレストの正しさが確認されます。 

### 例 2

 複数の位相順序を生成する 2 つの子を持つルートを考えてみましょう。 DP は、最初のステップで利用可能なノードのさまざまな選択肢に分割され、両方のコースを異なる順序で受講した後、同じ状態にマージして戻ります。 

| ステップ | マスク | 利用可能 | 支店 |
 | --- | --- | --- | --- |
 | 0 | 000 | {1,3} | 1 または 3 を選択してください |
 | 1 | 001 / 100 | 最新の在庫状況 | 複数 |
 | 2 | 111 | 完了 | マージされたカウント |

 これは、各サブセット状態が完了したコースの一意のセットを表すため、DP が二重にカウントすることなくすべての順列を正しく集計していることを示しています。

 | 時間 | O(N・2^N・M・L) | 各サブセットは最大 N 個の選択肢を考慮し、M 個のパターン状態を更新します。 
| スペース | O(2^N・M・L) | マスクとオートマトンの状態に関するメモ化 |

 ## 特殊なケース

 重要なエッジケースは、複数のコースが同じレターを共有する場合に発生します。 状態はキャラクターではなくコースのアイデンティティに基づいているため、DP はそれらを正しく区別します。 2 つの異なるコースが両方とも同じレターを投稿した場合でも、異なるマスクが作成され、将来の利用可能性も異なるため、それらの投稿が誤ってマージされることはありません。 

もう 1 つのエッジ ケースは、「AAA」など、パターンがそれ自体と重なる場合です。 KMP オートマトンは、部分一致後のオートマトンの状態がサフィックス情報を保持するため、重複するオカレンスが正しく処理されることを保証します。 これにより、前の一致内で始まる一致を見逃すことがなくなります。 

最後のエッジケースは、前提条件が複数の独立したツリーを形成する場合です。 この場合、有効なトポロジー次数の数は組み合わせ的に爆発的に増加します。 DP はこれを自然に処理します。これは、可用性セットが独立して結合され、各インターリービングが利用可能なノードに対する個別の選択シーケンスとして表現され、すべての有効なコース シーケンスに対して正しい均一な重み付けが保証されるためです。
