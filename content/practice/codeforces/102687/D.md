 ## 解決策
 ## 問題の理解

 フェリー航路で結ばれた島のコレクションがあります。 各ルートには最低年齢要件があり、年齢がルートの必須値以上である場合にのみそのルートを利用できます。 すべての反乱軍の年齢がわかっているので、2 つの島を選択する必要があります。1 つは反乱軍が住んでいる島、もう 1 つは反乱軍のパートナーが住んでいる島です。 パートナーは決して移動しませんが、反逆者は年齢が許す限りすべてのフェリールートを移動できます。 

1 人の反乱軍の場合、要件が反乱軍の年齢以下であるフェリー ルートのみを保持した後、反乱軍の開始島とパートナーの島が同じ接続コンポーネントに属している場合にのみ配置が無効になります。 すべての反乱軍の有効な配置の数を数え、これらの独立した選択肢を増やす必要があります。 

入力サイズが大きいです。 最大 100 万の島々、20 万ものフェリー航路と反乱軍が存在する可能性があります。 反乱軍ごとに個別にグラフを調査するソリューションでは、同じ接続情報が何度も再計算されるため、多大な作業が必要になります。 数十万のクエリがあるため、グラフをグローバルに処理し、各年齢のしきい値に効率的に答える必要があります。 

困難なエッジケースは、年齢が上がるにつれて接続が変化することから発生します。 たとえば、次のことを考えてみましょう。```
3 2 1
1 2 5
2 3 10
5
```5歳のとき、最初のフェリーだけが機能します。 コンポーネントは次のとおりです。`{1,2}`そして`{3}`。 無効なオーダー済みプレースメントの数は、`2*2 + 1*1 = 5`したがって、有効な答えは次のとおりです。`9 - 5 = 4`。 すべてのルートを使用してグラフを構築する不注意な解決策は、すべての島が接続されていると誤って認識する可能性があります。 

もう 1 つのケースは、すべての島が接続される場合です。```
3 3 1
1 2 1
2 3 1
1 3 1
10
```サイズ 3 のコンポーネントは 1 つだけなので、あらゆる配置によって反乱軍が最終的にパートナーに到達できるようになります。 答えは`0`。 この事件を忘れると、反乱軍の出発点である島を安全な場所とみなしてしまうことがよくあります。 

## アプローチ

 直接的な解決策では、各反政府勢力を個別に処理することになります。 年齢を重ねた反逆者にとって`H`を使用すると、要件がより大きいすべてのフェリーを無視してグラフ トラバーサルを実行できます。`H`、到達可能な島をマークし、そのセットの外にある島を数えます。 これは反乱軍の移動ルールを正確にシミュレートしているため、これは正しいです。 ただし、すべての反政府勢力に対してこれを行うには時間がかかります`O(k(n+m))`時間。 と`k`そして`m`その周り`2 * 10^5`、これは可能性をはるかに超えています。 

重要な観察は、フェリー航路は年齢が上がるにつれてしか利用できなくなるということです。 すべてのフェリーのルートを必要な年齢順に並べ替え、反乱軍を年齢の昇順に処理すると、グラフはエッジを追加するだけで進化します。 これはまさに、素のセット共用体構造が役立つ状況です。 

固定期間の場合、接続コンポーネントのサイズが次のようになると仮定します。`s1, s2, ...`。 不正な順序のアイランドのペアの数は次のとおりです。```
s1^2 + s2^2 + ...
```なぜなら、反逆者とパートナーが同じコンポーネント内で選択された場合、お互いを正確に避けることができないからです。 注文されたプレースメントの合計数は、`n^2`したがって、有効なプレースメントの数は次のようになります。```
n^2 - (s1^2 + s2^2 + ...)
```サイズの 2 つのコンポーネントをマージするとき`a`そして`b`、貢献度は から変わります`a^2 + b^2`に`(a+b)^2`。 この値を維持すると、すべてのクエリに即座に答えることができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k(n+m)) | O(n) | 遅すぎる |
 | 最適 | O((n+m+k) log m) | O(n+m+k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのフェリー航路を年齢要件に従って並べ替えます。 元の立場を思い出しながら、すべての反乱軍を年齢順に並べ替えます。 
2. それぞれの独立したセット コンポーネント内のすべてのアイランドから開始します。 最初にコンポーネント サイズの 2 乗の合計は次のようになります。`n`、すべてのコンポーネントのサイズが 1 であるためです。 
3. 反乱軍を最年少から最年長の順に処理します。 年齢による反抗に答える前に`H`、要件が最大でも以下のすべてのフェリールートを統合します。`H`。 
4. マージ中に、維持されている合計から 2 つの古いコンポーネントの寄与分を削除し、マージされたコンポーネントの寄与分を追加します。 コンポーネントのサイズが`a`そして`b`、 アップデート：```
sum = sum - a^2 - b^2 + (a+b)^2
```1. この年齢で考えられるすべてのフェリーが追加された後の、反乱軍の有効な配置は次のとおりです。```
n^2 - sum
```この値をその反乱軍のために保存します。 

1. 保存されているすべての値を剰余で乗算します。`10^9+7`なぜなら、すべての反逆者は独立して自分の2つの家を選択するからです。 

なぜ効果があるのか:

 現在の反乱軍の年齢までの要件ですべてのエッジを処理した後、素のセット構造は反乱軍が到達できる島を正確に表します。 同じコンポーネント内のすべてのペアが到達可能であるため、維持される 2 乗サイズの合計はすべての無効な配置をカウントします。 すべての可能な順序付けされた島のペアからそれを減算すると、正確に安全な配置が残ります。 すべての反乱者の選択は他の反乱者の選択を制限しないため、これらの数を乗算することで最終的な答えが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, m, k = map(int, input().split())

    edges = []
    for _ in range(m):
        u, v, d = map(int, input().split())
        edges.append((d, u - 1, v - 1))

    ages = list(map(int, input().split()))

    edges.sort()
    queries = sorted((h, i) for i, h in enumerate(ages))

    parent = list(range(n))
    size = [1] * n

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(a, b):
        ra = find(a)
        rb = find(b)
        if ra == rb:
            return
        if size[ra] < size[rb]:
            ra, rb = rb, ra

        nonlocal_sum[0] -= size[ra] * size[ra] + size[rb] * size[rb]
        parent[rb] = ra
        size[ra] += size[rb]
        nonlocal_sum[0] += size[ra] * size[ra]

    nonlocal_sum = [n]
    ans = [0] * k
    edge_ptr = 0
    total_pairs = n * n

    for h, idx in queries:
        while edge_ptr < m and edges[edge_ptr][0] <= h:
            _, u, v = edges[edge_ptr]
            union(u, v)
            edge_ptr += 1

        ans[idx] = total_pairs - nonlocal_sum[0]

    result = 1
    for x in ans:
        result = (result * x) % MOD

    print(result)

if __name__ == "__main__":
    solve()
```エッジリストは一度ソートされ、ポインタは`edge_ptr`前に進むだけです。 これは、すべてのフェリー ルートが 1 回だけ考慮されることを意味します。 素のセット構造は現在の接続コンポーネントを格納し、サイズとパス圧縮による結合により、各操作の時間をほぼ一定に保ちます。 

変数`nonlocal_sum`は、現在の年齢しきい値に対する無効な順序ペアの総数を表します。 結合後は 2 つの古いコンポーネントが存在しないため、結合の前後に更新する必要があります。 減算は親配列を変更する前に行われるため、元のコンポーネントのサイズが誤って失われることが回避されます。 

アイランド ペアの数に関するすべての計算では Python 整数が使用されるため、オーバーフローの問題は発生しません。 最後の乗算は減算法で行われます。`10^9+7`割り当ての数が非常に多くなる可能性があるためです。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O((n+m+k) log m) | ソートが優先されますが、各結合検索操作はほぼ一定時間です。 
| スペース | O(n+m+k) | グラフ、クエリ、および素セット配列を格納します。 

この制約により、グラフの反復走査を避ける必要があります。 エッジを並べ替えて DSU を使用すると、すべての接続変更を 1 つのパスで処理できるため、制限内に快適に収まります。

 ## 特殊なケース

 年齢がすべてのフェリー要件よりも小さい場合、要素セットはすべての島が分離されたままになります。 のために`n=3`、これにより、無効なペアの数は次のようになります。`3`したがって、有効な数は次のようになります。`9-3=6`。 エッジがマージされないため、アルゴリズムはこれを自然に処理します。 

複数のフェリー ルートが同じ島を結んでいる場合、最初に成功した合流のみが重要です。 後のルートでは、両方のアイランドがすでに同じコンポーネント内にあることが検出され、何も行われません。 これにより、重複したルートによってコンポーネント数が変更されるのを防ぎます。 

すべての島がつながったとき、維持される合計は`n^2`。 考えられる反乱軍とパートナーの配置はすべて 1 つの到達可能なコンポーネント内にあるため、答えはゼロになります。 

複数の反乱軍の年齢が同じ場合、それらはすべて同じ DSU 状態を使用します。 クエリを年齢で並べ替えるということは、グラフが反乱軍ごとに個別に再構築されるのではなく、そのしきい値に対して一度構築されることを意味します。 

出版用に編集したい場合は、コンテスト用の短い編集バージョンや、より正式な校正に重点を置いたバージョンも提供できます。
