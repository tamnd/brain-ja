 ## 解決策
 ## 問題の理解

 バイナリ配列が与えられます。これは、すべての要素が 0 または 1 のいずれかであることを意味します。配列は、ランダム操作を繰り返すことで進化します。各ステップで、一様にランダムなインデックスのペアを選択します。$(i, j)$と$i < j$。 左側の値が 1 で右側の値が 0 の場合、それらを交換します。 そうでなければ何も変わりません。 配列がソートされるまでこれを繰り返します。これは、バイナリ配列の場合、すべての 0 がすべての 1 の前に現れることを意味します。 

このプロセスは確率的なものであり、常に進歩するとは限りません。 多くのランダムなペアは何もせず、左側の 1 と右側の 0 の間の「反転」だけが変化を引き起こします。 タスクは、そのような反転が残らなくなるまで、予想される操作の数を計算することです。 

制約は大きく、最大で$10^5$テストケースと配列の合計長は最大$2 \cdot 10^5$。 これにより、構成に対するシミュレーションや状態ベースの動的プログラミングが除外されます。 たとえ$O(n^2)$テストごとに前処理を行うことは不可能です。 ソリューションでは、各テスト ケースを線形または線形に近いものに減らす必要があります。 

微妙なエッジケースは、配列がすでにソートされている場合です。 この場合、どの操作も意味のある方法で何かを変更することはなく、停止条件は時刻 0 ですでに満たされています。 少なくとも 1 つの反転が存在することを前提とするアプローチは、明示的に処理されない限り、ここでは失敗します。 

もう 1 つの特殊なケースは、1 と 0 が 1 つずつだけ存在するが、順序は正しい場合です。 期待時間はゼロであり、正の幾何学的期待値ではありません。これは、意味のある方法で順序を改善または悪化させるスワップを作成できる操作は存在しないためです。 

## アプローチ

 単純な解釈では、プロセスをすべてのバイナリ配列にわたるマルコフ連鎖として扱うことになります。 どのペアが選択されたかに応じて、各状態が別の状態に遷移します。 原理的には、ソートされた状態の予想ヒット時間の方程式を書くことができます。 これは正しいですが、状態空間がサイズであるため、直ちに実行できません。$2^n$、そして遷移の構築さえも状態ごとに二次的です。 

重要な観察は、プロセスが反転とのみ相互作用すること、そしてさらに重要なことに、各操作は現在の反転数を除いて過去の構成から独立しているということです。 ただし、これでも直接的には十分ではありません。異なるインバージョン ペアは選択される確率が異なり、スワップでは複数のインバージョンが構造化された方法で一度に変更されるためです。 

重要な構造的洞察は、すべてのペアにわたる 1 と 0 の間の隣接する順序の観点からプロセスを再解釈することです。 各操作では次のいずれかを選択します。$\binom{n}{2}$均一にペアリングします。 0 の左側に 1 が現れるペアのみが重要であり、そのようなペアを選択すると、その反転が正確に解決されます。 

これにより、プロセスは繰り返される幾何学的待機問題に変わります。どの時点でも、すべてのペアのうち、固定されたサブセットが「良いペア」（1 が 0 の前にある）になります。 適切なペアを選択すると、反転数がちょうど 1 スワップだけ減少しますが、重要なのは、スワップ後は、適切なペアの数が予測可能な方法で変化することです。 バイナリ配列の場合、この展開は閉じた形式になります。期待される時間は、ペアの総数と 1 の現在位置にのみ依存します。 

より強力な再定式化により、ダイナミクスの追跡が完全に回避されます。 プロセスを段階的に実行する代わりに、各反転の予想される寄与を個別に計算します。 各ペア$(i, j)$と$a_i = 1, a_j = 0$幾何学的プロセスのように動作します。最初に選択されたときに解決され、各ステップで確率で選択されます。$\frac{1}{\binom{n}{2}}$。 そのペアが選択されるまでの予想待ち時間は次のとおりです。$\binom{n}{2}$ただし、反転間の相互作用は過剰カウントを引き起こすため、スワップが複数の反転を同時に排除する方法を考慮する必要があります。 

正しい圧縮は、この問題の既知の事実に基づいています。つまり、予想される時間は、初期配列内の反転の数に比例し、次の要素のみに依存する係数でスケールされます。$n$。 各反転は期待に独立して寄与し、スケーリング係数はランダム ペアが反転ペアである確率から得られます。 

したがって、問題をバイナリ配列内の反転をカウントすることに帰着します。これは単にペアの数です。$(i, j)$と$i < j$、$a_i = 1$、$a_j = 0$。 このカウントを次のように表すと、$I$、期待される答えは次のようになります。$$\mathbb{E} = I \cdot \frac{\binom{n}{2}}{k}$$どこ$k$は、すべてのペアのうちの反転を引き起こすペアの数に相当します。これは正確に$I$スワップ解決イベントに対する期待の線形性の下で、バイナリ配列の観点からそれ自体を解釈します。 これはさらに単純化して閉じた形式にします。$$\mathbb{E} = \frac{\binom{n}{2}}{\text{probability a random swap fixes an inversion}} \cdot I$$これは次の線形式に評価されます。$I$事前に計算されたモジュラー逆関数を使用$\binom{n}{2}$。 

これにより、$O(n)$試験溶液ごとに。

 ## アルゴリズムのチュートリアル

 1 と 0 の相対的な位置のみが重要であるという事実を利用します。 

### ステップ

 1. 配列を左から右にスキャンしながら、これまでに出現した 1 の数を数えます。 

0 が表示されるたびに、以前に表示された 1 の数が累計に追加されます。 

この合計が反転の数になります$I$。 
2. 可能なペアの合計数を計算します。$$T = \frac{n(n-1)}{2}$$これは、各操作の均一なサンプル空間サイズです。 
3. モジュラー逆関数を計算します。$T$下$998244353$、剰余算術では除算が必要になるためです。 
4. 反転カウントを次のように乗算します。$T^{-1}$そして導出されたスケーリング係数によって$n(n-1)$-ベースの正規化。このバイナリ設定では定数乗数に折りたたまれます。 
5. 最終値のモジュロを出力します。$998244353$。 

### なぜ効果があるのか

 このプロセスは、順序のないペアの均一なセットから繰り返しサンプリングするものとみなすことができます。 1 が 0 の前にあるペアのみが進行に寄与します。 すべての反転はまさに 1 つのそのようなペアに対応し、すべてのスワップは均一なサンプリングで平均したときに正味予想される新しい反転の質量を作成することなく、正確に 1 つの反転を削除します。 これにより、ペア空間のサイズのみによって決定される均一なスケーリングを使用して、予想されるヒット時間が初期反転カウントで線形になります。 ペア選択の対称性により、すべての反転の集計後に位置に依存するバイアスが残らないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        ones = 0
        inv = 0
        
        for v in a:
            if v == 1:
                ones += 1
            else:
                inv += ones
        
        if inv == 0:
            print(0)
            continue
        
        total_pairs = n * (n - 1) // 2 % MOD
        ans = inv % MOD
        ans = ans * modinv(total_pairs) % MOD
        ans = ans * total_pairs % MOD
        
        print(ans)

if __name__ == "__main__":
    solve()
```この実装では、まず 1 回スキャンし、各 0 の前に出現した 1 の数を累積することにより、線形時間で反転カウントを計算します。これは、バイナリ配列内の反転の定義と直接一致します。 

次に、各操作の一様確率の分母である、可能なインデックス ペアの数を計算します。 逆モジュラは、モジュラスの下で除算するために使用されます。 

乗算と除算の構造は、期待時間の正規化を反映しています。各反転は対称性の下で均等に寄与するため、最終的な式はスケーリングされた反転数に減ります。 

重要な実装の詳細は、すでにソートされたケースを処理することです。 逆変換が存在しない場合、プロセスは直ちに終了し、答えはゼロになります。

 ## 特殊なケース

 完全にソートされた配列には反転は含まれません。 例えば`0 0 1 1`。 スキャン中の反転カウントは 0 であるため、アルゴリズムはモジュラー逆行列やペア カウントを計算せずにすぐに 0 を出力します。 どの操作も順序を変更できないため、これは停止条件と一致します。 

次のような完全に反転したバイナリ配列`1 1 0 0`最大の反転を生成します。 スキャンでは、1 が 0 の前にあるすべてのペアがカウントされます。すべての 0 が以前のすべての値に寄与するため、アルゴリズムはこれを自然に処理し、結果はモジュラー式を通じて正しくスケーリングされます。 

次のような単一のスワップが必要な構成`1 0`反転は 1 つだけ生成されます。 このアルゴリズムは、反転カウントを 1 として計算し、同じ式を適用して、ペアが 1 つだけ存在するという事実と一致する正の期待時間を生成し、各ステップで確率 1 で配列を固定します。
