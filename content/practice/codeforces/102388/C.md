 ## 解決策
 ## 問題の理解

 幅の長方形のテーブルがあります`m`と高さ`n`。 ボールは内側のポイントから始まります`(x0, y0)`そして到達しなければならない`(x1, y1)`。 光は常に直線セグメントに沿って進み、等しい入射角と反射角で壁から反射します。 必要な壁接触の数は正確に`k`、そして軌跡の最小全長が必要です。 

重要な問題は、バウンドによって方向が変わるため、ボールを直接シミュレートしようとすることは、考えられる多くの反射シーケンスに対処することを意味することです。 制約は十分小さいため、線形スキャンが可能です。`k`、しかし、それらは十分に大きいので、バウンスシーケンスに対する指数関数的な検索は完全に不可能です。 以来`k`100でも構いません`2^k`可能性はすでにあります`1.27 * 10^30`。 テーブルの次元は最大 100 であるため、変換された平面内の座標は通常の浮動小数点演算を行うのに十分な大きさのままであり、テスト ケースの数は 100 のみです。 

一般に、誤った解決策が発生するケースがいくつかあります。 まず、ゼロバウンスでは直接セグメントを許可する必要があるため、```
1
100 100 1 1 1 1 0
```答えがあります`0.00`。 常に反射イメージを構築するソリューションでは、少なくとも 1 つの壁との接触が誤って強制されてしまいます。 

次に、ボールが同時に垂直の壁と水平の壁に 1 つずつ接触するため、コーナーに到達すると 2 バウンドとしてカウントされます。 のために```
1
100 100 1 2 1 2 2
```ボールはどこからでも移動できます`(1,2)`隅まで`(0,0)`そして戻って`(1,2)`、距離を与える`2 * sqrt(5) = 4.47`。 壁との接触ではなく衝突イベントをカウントするソリューションでは、これを誤って 1 回の跳ね返りとみなす可能性があります。 

第三に、反射された像の方向が重要です。 のために```
1
10 10 1 1 9 1 1
```直線距離は`8`, しかし、そのパスにはバウンスがありません。 バウンスが 1 回だけある場合、最も近い有効な反射ターゲットは次のとおりです。`-9`または`11`、どちらも開始 x 座標から 10 単位なので、答えは次のようになります。`10.00`。 テーブル幅を 1 つだけ宛先座標に追加すると、間違ったジオメトリが生成されます。 

## アプローチ

 直接的な総当りのアプローチは、壁の方向の考えられるすべてのシーケンスを列挙することです。 バウンドするたびに、次の衝突が垂直の壁と水平の壁のどちらであるかを概念的に選択し、結果として得られる反射軌跡を追跡し、正確に終了後にエンドポイントが要求されたポイントになるかどうかを確認できます。`k`衝突。 がある`2^k`方向シーケンスなので、最悪の場合`k = 100`これはおおよその意味です`1.27 * 10^30`ケース。 すべての法的軌道には垂直および水平の壁接触が連続するため、このアプローチは概念的には正しいですが、探索空間は指数関数的に増大します。 

この爆発を除去する観察は、軌道の反射をまったく停止することです。 代わりに、ボールがバウンドするたびにテーブル全体を反映します。 この展開された平面内では、ボールは 1 つの直線に沿って移動します。 元の宛先の反射コピーはすべて、実際のテーブル内で可能な軌跡を表します。 

展開した直線が交わるとします`p`テーブルの垂直境界と`q`水平方向のテーブル境界。 実際の軌道は正確に次のようになります。`|p| + |q|`跳ねる。 必要です`|p| + |q| = k`。 

符号付き整数の場合`p`、対応する反射コピーの x 座標を計算できます。`x1`。 もし`p`が偶数の場合、コピーは次の場所にあります`p * m + x1`。 

もし`p`は奇妙です、コピーは次の場所にあります`(p + 1) * m - x1`。 

同じ式が次を使用して y 座標に適用されます。`q`そして`n`。 

の兆候`p`そして`q`展開されたコピーを通してボールがどの方向に移動するかを教えてください。 あらゆる可能性に対して`p`から`-k`を通して`k`、残りの水平バウンド数は`k - |p|`、最大で 2 つの選択肢が与えられます`q`。 結果として得られる各画像までのユークリッド距離を計算し、最小値を取得します。 

すべてのバウンス シーケンスが展開される可能性のあるラインに対応するため、ブルート フォース検索が機能します。 指数関数的に多くのシーケンスがあるため、失敗します。 観察が展開されると、バウンスの順序を完全に忘れることができます。 垂直方向と水平方向の境界を越える符号付きの数のみが重要となるため、検索は次のようになります。`O(k)`候補者たち。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |`O(2^k)`|`O(k)`| 遅すぎる |
 | 最適 |`O(k)`テストケースごと |`O(1)`| 承認済み |

 ## アルゴリズムのチュートリアル

 1. あらゆる方向に無限に繰り返されるテーブルについて考えます。 2 つおきのコピーがミラーリングされるため、テーブルを反映することはボールを直線に続けることと同じになります。 
2. 符号付き整数を代入する`p`垂直の壁を横切る数に応じて変化します。 その絶対値は垂直方向のバウンスの数です。 同様に、割り当てます`q`水平交差点へ。 

コーナー衝突はこのモデルに自然に適合します。 直線がコーナーを通過する場合、直線は 1 つの垂直境界と 1 つの水平境界を同じ点で交差するため、イベントは 2 つのバウンスに寄与します。 
3. バウンスの総数は正確に一致する必要があるため、`k`、候補者を次のように制限します。`|p| + |q| = k`。 
4. 列挙する`p`から`-k`に`k`。 それぞれの値について計算します`r = k - |p|`。 唯一可能な値は、`q`は`r`そして`-r`。 
5. 各符号付きバウンス数を展開されたターゲット座標に変換します。 X 軸については、次のように定義します。`image_x(p) = p*m + x1`いつ`p`は偶数であり、`image_x(p) = (p+1)*m - x1`いつ`p`奇数です。 

同様の式を適用すると、`image_y(q)`。 
6. 展開された軌跡は、単純に次のセグメントになります。`(x0, y0)`に`(image_x, image_y)`。 その長さは`sqrt((image_x - x0)^2 + (image_y - y0)^2)`。 
7. すべての候補の中で最小の距離を維持し、小数点以下 2 桁で出力します。 

### なぜ効果があるのか

 不変条件は、元のテーブル内のすべての正当な反射軌道が、開始点から展開平面内の目的地の適切に反射されたコピーまでの 1 つの直線セグメントに正確に対応するということです。 そのセグメントが横切る垂直境界の数は、垂直壁のバウンド数と正確に一致し、水平方向にも同じことが当てはまります。 したがって、すべての候補者が満足する`|p| + |q| = k`法的な軌道を正確に表します`k`跳ねる。 逆に言えば、あらゆる法的軌道はこれらの候補者のいずれかに展開します。 アルゴリズムはバウンス カウントを満たすすべての可能な符号付きペアをチェックし、対応する最短のセグメントを選択するため、計算される最小値がまさに必要な答えとなります。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def image_coordinate(pos, length, bounces):
    if bounces % 2 == 0:
        return bounces * length + pos
    return (bounces + 1) * length - pos

def solve_case(m, n, x0, y0, x1, y1, k):
    ans = float("inf")

    for p in range(-k, k + 1):
        remaining = k - abs(p)

        x = image_coordinate(x1, m, p)

        for q in {remaining, -remaining}:
            y = image_coordinate(y1, n, q)

            dx = x - x0
            dy = y - y0

            dist = math.hypot(dx, dy)
            ans = min(ans, dist)

    return ans

def main():
    t = int(input())

    for _ in range(t):
        m, n, x0, y0, x1, y1, k = map(int, input().split())
        ans = solve_case(m, n, x0, y0, x1, y1, k)
        print(f"{ans:.2f}")

if __name__ == "__main__":
    main()
```の`image_coordinate`関数は反射パターンを直接実装します。 署名付きコピーのインデックスが偶数の場合、宛先は元の方向を維持します。 奇数の場合、宛先は対応する繰り返される四角形内にミラーリングされます。 

負のインデックスは意図的です。 たとえば、`p = -1`、式は次のようになります`-x1`、これは左側の壁を越えた目的地の反射です。 と`p = -2`、それは与えます`-2m + x1`、反対方向に交差する 2 つの垂直壁を表します。 

メイン ループでは、考えられるすべての符号付き垂直交差カウントが考慮されます。 一度`p`固定されており、`k - |p|`は強制的に水平交差の数になるため、可能な記号は 2 つだけです。`q`。 セット`{remaining, -remaining}`次の場合に同じ計算を 2 回実行することを回避します。`remaining`はゼロです。`math.hypot(dx, dy)`平方根式を手動で記述する必要なく、ユークリッド距離を計算します。 すべての座標計算は整数であり、指定された制約の下では非常に小さいため、Python では整数オーバーフローの問題は発生しません。 

の`:.2f`フォーマットにより、必要な出力の丸めが実行されます。 特別な処理は必要ありません`k = 0`、そのときだから`p = 0`そして`q = 0`可能な候補値は直接距離を示す唯一の値です。

 ## 特殊なケース

 最初のエッジケースは`k = 0`。 のために```
1
100 100 1 1 1 1 0
```ループは選択することしかできません`p = 0`、強制的に`q = 0`。 目的地のイメージはまさに`(1,1)`したがって、両方の座標の差はゼロとなり、答えは次のようになります。`0.00`。 ゼロ以外の符号付きインデックスがあると少なくとも 1 つの壁越えが発生するため、反射パスは考慮されません。 

2 番目のエッジケースはコーナーヒットです。 のために```
1
100 100 1 2 1 2 2
```選択する`p = -1`そして`q = -1`イメージを与える`(-1,-2)`。 からの直線セグメント`(1,2)`に`(-1,-2)`通り抜ける`(0,0)`。 元の表では、これは物理的に同じコーナーで 1 回の垂直壁接触と 1 回の水平壁接触を意味するため、正しく 2 回のバウンスとしてカウントされます。 距離は`sqrt(2^2 + 4^2) = 4.47`。 

3 番目のエッジ ケースは、奇数の反射コピーです。 のために```
1
10 10 1 1 9 1 1
```正確に 1 回のバウンスが必要です。 選択する`p = -1`そして`q = 0`与える`image_x = (0)*10 - 9 = -9`そして`image_y = 1`。 展開距離は`|-9 - 1| = 10`、結果は次のようになります`10.00`。 正の垂直方向を選択すると、次のような画像が得られます。`11`、こちらも10単位離れています。 直接の目的地は、`9`はわずか 8 単位離れていますが、バウンスがゼロであるため、拒否されます。 

4 番目のエッジ ケースは、同じ座標を持つ大きなバウンス数です。```
1
100 100 50 50 50 50 100
```最適なソリューションは、100 回のバウンスを均等に分散します。`p = -50`そして`q = -50`。 どちらのインデックスも偶数であるため、画像は次のようになります。`-4950`それぞれの軸で。 各座標は次のように変化します。`5000`の距離を与える`sqrt(5000^2 + 5000^2) = 7071.067...`、次のように出力されます`7071.07`。 49 バウンスや 51 バウンスなど、より不均衡な分割では、より大きなユークリッド距離が作成されるため、別の最適化引数を必要とせずに、列挙によってバランスの取れた選択肢が自然に見つかります。
