 ## 解決策
 ## 問題の理解

 1 から n までの同じ頂点セット上に構築された 2 つの異なるフォレストが与えられています。 各フォレストはすでに非循環ですが、複数の接続されたコンポーネントがある場合があります。 タスクは、できるだけ多くの新しい無向エッジを追加することですが、強力な制限があります。追加するすべてのエッジは両方のフォレストに同時に挿入され、すべての挿入後も両方のグラフがフォレストのままでなければなりません。 

これは、選択したエッジが 2 つのグラフのいずれかでサイクルを作成してはいけないことを意味します。 したがって、u と v の間のエッジは、u と v が現在最初のフォレストの異なる接続コンポーネントにあり、2 番目のフォレストの異なる接続コンポーネントにもある場合にのみ許可されます。 

出力は、そのようなエッジの最大数だけでなく、この最大値を達成するエッジの明示的なリストでもあります。 

n が 100000 までの制約により、すべての解が線形時間または線形演算時間に近くなることが強制されます。 すべての頂点のペアを繰り返しチェックする単純な戦略では、n 乗のチェックが必要になりますが、これは 2 秒で実行できる量をはるかに超えています。 エッジを追加するたびに接続性を最初から再計算するアプローチでも、両方のグラフの大部分を繰り返し走査することになり、この規模ではすぐに失敗します。 

1 つの森だけで欲張って考えると、微妙な問題が生じます。 最初のフォレストでサイクルを作成しないことだけを保証した場合は、2 番目のフォレストの同じコンポーネントに既に存在する 2 つの頂点を簡単に接続でき、そこにサイクルが作成されます。 同様に、第二の森だけを貪欲に尊重するだけでは不十分です。 重要な問題は、両方の接続構造が同時に進化することです。 

両方のフォレストで接続コンポーネントを事前計算し、コンポーネントのペアを任意に接続しようとすると、別の失敗ケースが発生します。 エッジを追加すると、両方のコンポーネントの構造が変更されるため、静的なコンポーネント ビューはすぐに無効になります。 

## アプローチ

 ブルート フォースの観点では、頂点のすべてのペアを考慮し、各ペアについて、それらが両方のフォレストの異なるコンポーネントにあるかどうかを確認します。 存在する場合は、エッジを追加してコンポーネントをマージします。 追加するたびに接続を再計算するか、検索を繰り返して動的に維持します。 

これは森林の制約を常に尊重するので原理的には正しいですが、コストが法外に高くなります。 O(n²) 個の候補エッジがあり、各接続性チェックまたは更新には単純な形式で少なくとも O(n) のコストがかかり、最悪の場合は三次的な動作が発生します。 

重要な構造上の観察は、各フォレストがコンポーネントの互いに素なセットによって維持されており、エッジを追加することは、各 DSU 内の 1 つのコンポーネントを同時にマージすることと同等であるということです。 したがって、私たちは 2 つのパーティション システムの交差部分で効果的に作業を行っています。 両方のパーティションの異なるセットにある頂点のペアを繰り返し選択し、それらのセットを同時にマージしたいと考えています。 

重要な簡素化は、両方のエンドポイントがいずれかの DSU の同じコンポーネント内にあると、エッジを再検討する必要がないことです。 このようなペアは永久に無効です。 この単調性により、貪欲なスキャン戦略が可能になります。頂点を通過し、前進するだけの移動候補ポインタを維持できます。 

私たちは、フォレストごとに 1 つずつ、2 つの DSU 構造を維持しています。 いつでも、有効なエッジとは、エンドポイントが異なる DSU1 コンポーネントと異なる DSU2 コンポーネントにあるエッジです。 制御された方法でそのようなペアを繰り返し検索して追加し、両方の DSU を同時にマージします。 

これにより、問題はグローバル ペアの選択から、頂点に対するローカル 2 ポインタ検索に軽減されます。この場合、チェックに失敗するたびに、少なくとも 1 つの候補ペアが将来の検討対象から永久に除外されます。

 | DSU + 貪欲な 2 ポインター スキャン | O(n α(n)) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 私たちは、Mocha と Diana のフォレスト内の接続を表す、2 つの素なセット ユニオン構造 DSU1 と DSU2 を維持しています。 また、追加することを決定したエッジを保存するためのリストも保持します。 

1. すべてのノードを個別のコンポーネントとして使用して DSU1 と DSU2 を初期化します。 次に、各 DSU の指定されたすべてのエッジをマージします。 これにより、両方のグラフに初期フォレスト構造が設定されます。 
2. 2 つのポインタ i と j を設定します。 ポインタ i は最初のエンドポイント候補として機能し、j は i と互換性のあるパートナーを検索します。 
3. i を修正し、j が常に厳密に i より大きいことを確認します。 j がまだ有効でない場合は、j を i + 1 に設定します。これにより、ペアの重複が回避され、検索方向の一貫性が保たれます。 
4. i と j がすでに DSU1 の同じコンポーネントに属しているか、または DSU2 の同じコンポーネントに属しているときに、j を前方に移動します。 そのエッジを追加すると、少なくとも 1 つのフォレストにサイクルが作成されるため、このようなペアは禁止されています。 
5. j が n を超えた場合、i には有効なパートナーがいないことを意味します。 この場合、i をインクリメントし、それに応じて j を調整して検索を再開します。 
6. 有効な j が見つかった場合は、エッジ (i, j) を答えに追加し、DSU1 と DSU2 の両方で i と j をマージします。 これは、両方のフォレストがこのエッジを受け入れたことを反映しています。 
7. マージ後、最初から検索をやり直すことはありません。 以前に無効だったペアの一部は依然としてスキップされる可能性があるため、更新された DSU を続行しますが、正確性は失われません。 現在の i および j 位置から検索を繰り返します。 

このプロセスは、私がすべて疲れ果てるまで続きます。 

### なぜ効果があるのか

 DSU の不変条件は、各構造内でコンポーネントが常に現在の接続を正確に表現し、エッジが追加されるたびに両方の DSU のコンポーネントの数が同時に厳密に減少するということです。 選択されたすべてのエッジは両方のフォレスト内の 2 つの異なるコンポーネントを接続するため、どちらのフォレストもサイクルを取得することはありません。 

貪欲スキャンにより、拒否されたすべてのペア (i, j) がその固定 i に対して永久に無効になります。これは、DSU1 または DSU2 のいずれかの条件が等しい場合、将来のマージでは既に接続されているノードを分離できないことを意味するためです。 この単調性により、j はプロセス全体にわたって前方にのみ移動し、総作業量を制限することが保証されます。 

このアルゴリズムは最適です。なぜなら、有効なソリューションは両方の DSU の異なるコンポーネントにある頂点を接続することしかできず、制約に違反することなくそのような可能性をすべて貪欲に使い果たすからです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n + 1))
        self.size = [1] * (n + 1)

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]
        return True

n, m1, m2 = map(int, input().split())

d1 = DSU(n)
d2 = DSU(n)

for _ in range(m1):
    u, v = map(int, input().split())
    d1.union(u, v)

for _ in range(m2):
    u, v = map(int, input().split())
    d2.union(u, v)

edges = []

i = 1
j = 2

while i <= n:
    if j <= i:
        j = i + 1

    while j <= n and (d1.find(i) == d1.find(j) or d2.find(i) == d2.find(j)):
        j += 1

    if j > n:
        i += 1
        continue

    edges.append((i, j))
    d1.union(i, j)
    d2.union(i, j)

print(len(edges))
for u, v in edges:
    print(u, v)
```この解決策は、入力エッジを使用して両方のフォレストの DSU 表現を構築することから始まります。 これにより、接続クエリが一定の償却時間になることが保証されます。 

2 ポインター ループが中心です。 ポインタ j は前方にのみ進み、後方には進みません。
