 ## 解決策
 ## 問題の理解

 以下から整数の間隔が与えられます。`l`に`r`、パラメータ`k`。 数値が次で割り切れる場合、その数値は「悪い」とみなされます。`p^k`ある素数に対して`p`。 同様に、悪い数値には素因数が含まれており、その因数分解の指数は少なくとも`k`。 タスクは、次の整数がいくつあるかを数えることです。`[l, r]`悪くないよ。 

これを別の言い方で言えば、「大きすぎる」素数べき乗を含む数値を除外しているということです。 すべての素数について`p`、で割り切れる任意の数`p^k`は禁止されており、数値にそのような素数累乗が複数含まれている場合でも、1 回だけ禁止されます。 

制約は非常に大きいです。`r`まで可能です`10^14`、 そして`k`と同じ大きさにすることができます`10^9`。 これにより、範囲を直接反復するものはすべて即座に除外されます。 区間自体には最大で次の要素が含まれるため、数値ごとの線形または平方根ベースの因数分解さえ不可能です`10^14`要素。 

重要な観察は、この構造が任意の因数分解ではなく素数累乗のみに依存しているということです。 これは、数値を直接数えるのではなく、特定の構造化セットの倍数を削除していることを示唆しています。 

微妙なエッジケースが現れるのは、`k`大きいです。 もし`k > log_p(r)`すべての素数に対して`p`の場合、指数の素数乗を含む数値はありません。`k`したがって、すべての数値は有効であり、答えは単純です。`r - l + 1`。 素数パワーを列挙しようとする単純な実装では、注意深く保護しない限り、時間が無駄になったり、べき乗がオーバーフローしたりする可能性があります。 

もう 1 つの落とし穴は、除外セットを二重にカウントすることです。 のような数字`2^k * 3^k`は両方の素数によって除外されるものとしてカウントされるため、包含と除外を慎重に適用する必要があります。 

## アプローチ

 ブルートフォースのアイデアは、次のすべての整数を反復処理することです。`[l, r]`因数分解し、素指数が到達するかどうかを確認します。`k`。 素因数分解は指数を直接明らかにするため、これは概念的に機能します。 ただし、間隔には最大で次の値を含めることができます。`10^14`数値ごとに高速に因数分解したとしても、制限時間をはるかに超えてしまいます。 ボトルネックは因数分解そのものではなく、候補の多さです。 

条件の構造は、数値から禁止された構成要素に視点を移すことを示唆しています。 各整数を検査する代わりに、次の形式の少なくとも 1 つの数値で割り切れる整数の数を数えようとします。`p^k`。 ここでの自然なツールは、そのようなすべての主要な権限に対する包含と排除です。 

難しいのは、`p^k`成長が非常に速いため、固定`k`、素数のみ`p`と`p^k ≤ r`案件。 これにより、禁止された基地の世界が劇的に減少します。 そのようなものをすべてリストアップすると、`p^k`では、次の標準的な問題が残ります。次の数を数えます。`[l, r]`小さな集合内の少なくとも 1 つの要素で割り切れる。 

ただし、すべてのサブセットに対する直接の包含-除外は依然として素数の数において指数関数的であるため、2 番目の変換が必要です。 重要なのは、それぞれの数値が何らかの数で割り切れる場合は不良であるということです。`p^k`これは、「素数指数の k 乗が不要」ではない数を数えていることを意味します。 これは、k 乗を削除した後の縮小形式が明確に定義されている数を数えることと同等であり、枝刈りを伴う素数べき乗に対する DFS を使用するふるいのような構造を介して処理できます。 

最終的な実用的な解決策は、すべての素数パワーを生成することです。`p^k`まで`r`、次に、素数が重複しないようにこれらのべき乗の積を再帰的に構築し、DFS 中に包含-除外を適用します。 リストが小さいため（せいぜい約`10^6`最悪の概念的境界ではありますが、通常、大きな k でははるかに小さくなります)、再帰は除算制限による枝刈りで管理可能なままです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(r · sqrt(r)) | お(1) | 遅すぎる |
 | 最適 | O(M log M + DFS) | お(お) | 承認済み |

 ここ`M`素数の数です`p`そのような`p^k ≤ r`。 

## アルゴリズムのチュートリアル

 1. 以下のすべての素数を生成します。`r^(1/k)`簡単なふるいで`1e7`必要な場合のみですが、実際には以下の素数のみが必要です。`r^(1/k)`。 それぞれの素数`p`禁断の基地を生み出す`p^k`。 このステップでは、禁止されたジェネレーターの候補セットを構築します。 
2. 次のように素数をフィルタリングします。`p^k ≤ r`。 有効な素数ごとに、次のように計算します。`p^k`オーバーフローを避けるために、早い段階で停止しながら高速べき乗を使用します。 これによりリストが得られます`A`禁止された基本値の。 
3. リストを並べ替える`A`。 並べ替えは正確性を確保するために厳密に必要なわけではありませんが、大きな要素はすぐに境界を超えるため、DFS 中の枝刈りに役立ちます。 
4. 異なる要素の積を構築する再帰関数を定義します。`A`、現在のプロダクトと開始インデックスを維持します。 各状態は、選択された禁止塩基のサブセットで割り切れる数値を表します。 
5. 各再帰状態について、積が次の値を超える場合、`r`、そのブランチの探索をやめてください。 それ以外の場合は、この積の倍数を加算します。`[l, r]`サブセットのサイズによって決定される包含/除外記号付き。 
6. 包含/除外を使用する: 選択された各サブセットが寄与します`(+1)`または`(-1)`パリティに応じて。 これにより、複数の禁止基数で割り切れる数値が過大にカウントされることがなくなります。 
7. 不正な整数の合計数は、DFS の結果から累積されます。 最終的な答えは、`(r - l + 1) - bad_count`。 

これが機能する理由は、すべての悪い数値が少なくとも 1 で割り切れる必要があるためです。`p^k`、したがって、少なくとも 1 つのサブセット製品に表示されます。 包含-排他により、各数値が素数べき約数のすべてのサブセットにわたって正確に 1 回カウントされることが保証されます。 DFS は、これらの禁止塩基の四角形のない組み合わせのみを列挙し、プライムが繰り返されないことを保証し、包含-排除構造の正確さを維持します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from math import isqrt

def sieve(n):
    is_p = [True] * (n + 1)
    is_p[0] = is_p[1] = False
    primes = []
    for i in range(2, n + 1):
        if is_p[i]:
            primes.append(i)
            step = i
            start = i * i
            if start <= n:
                for j in range(start, n + 1, step):
                    is_p[j] = False
    return primes

def fast_pow_limit(a, k, limit):
    res = 1
    for _ in range(k):
        res *= a
        if res > limit:
            return limit + 1
    return res

def count_multiples(x, l, r):
    return r // x - (l - 1) // x

def dfs(arr, idx, cur, sign, l, r):
    total = 0
    for i in range(idx, len(arr)):
        nxt = cur * arr[i]
        if nxt > r:
            continue
        total += sign * count_multiples(nxt, l, r)
        total += dfs(arr, i + 1, nxt, -sign, l, r)
    return total

def solve():
    l, r, k = map(int, input().split())

    if k == 1:
        # every number divisible by p^1 for some prime p means non-prime-free structure,
        # but p^1 divides any composite; however condition becomes: divisible by any prime,
        # so only 1 is good.
        # But direct reasoning: every integer >1 has a prime divisor => all >1 are bad.
        return print(1 if l == 1 else 0)

    # find primes up to r^(1/k)
    limit = int(r ** (1 / k)) + 1
    if limit < 2:
        print(r - l + 1)
        return

    primes = sieve(limit)

    arr = []
    for p in primes:
        val = fast_pow_limit(p, k, r)
        if val <= r:
            arr.append(val)

    bad = dfs(arr, 0, 1, 1, l, r)
    ans = (r - l + 1) - bad
    print(ans)

if __name__ == "__main__":
    solve()
```ふるいは、以下の素数候補を生成するためにのみ使用されます。`r^(1/k)`。 各素数について、オーバーフロー保護を使用してその k 乗を計算します。 次に、DFS はこれらの禁止値の組み合わせを列挙し、間隔カウント関数に直接包含/除外を適用します。`count_multiples`。 

特別な場合`k = 1`定義は「何らかの素数で割り切れる数」、つまり 1 より大きいすべての整数に縮退するため、個別に処理されます。 

よくある実装上の間違いは、べき乗の上限を忘れることです。これにより、Python の整数が不必要にオーバーフローし、枝刈りが遅くなる可能性があります。 もう 1 つは、再帰を拡張するときに包含/除外記号を正しく適用できないことです。 

## 実用的な例

 ### 例 1

 入力:`l = 1, r = 10, k = 2`禁止されている値は素数の二乗です。`4, 9`。 貢献度を計算します。 

| ステップ | 現在の製品 | 貢献 | [1,10] の倍数を数える |
 | --- | --- | --- | --- |
 | 1 | 4 | + | 2 |
 | 2 | 9 | + | 1 |
 | 3 | 4・9=36 | 無視 | 0 |

 悪い数字は、`{4, 8, 9}`とても悪い = 3。答え = 10 - 3 = 7。 

このトレースは、単一要素のサブセットが直接の違反をどのように捕捉する一方で、より大きな積は範囲を超えて自然に消滅するかを示しています。 

### 例 2

 入力:`l = 1, r = 30, k = 2`立ち入り禁止の基地が残る`4, 9, 25`。 

| サブセット | 製品 | サイン | 倍数 |
 | --- | --- | --- | --- |
 | {4} | 4 | + | 7 |
 | {9} | 9 | + | 3 |
 | {25} | 25 | + | 1 |
 | {4,9} | 36 | - | 0 |

 悪い = 11、とても良い = 19。 

これにより、包含排他によって過剰カウントが防止され、有効な二乗累乗のみが寄与することが確認されます。

 ## 特殊なケース

 いつ`k = 1`、1 より大きいすべての整数には素数があるため、すぐに無効になります。 アルゴリズムは、次の値を返すことでこれを明示的に処理します。`1`もし`1`その間にあり、`0`さもないと。 たとえば、入力`1 5 1`生成する`1`、だけなので`1`生き残る。 

いつ`r^(1/k) < 2`、k乗が範囲内に収まる素数はありません。 DFS リストは空であるため、不良としてマークされる番号はありません。 入力用`10 20 5`、制限は 1 であるため、アルゴリズムは直接返します。`11`。 

禁止塩基が複数存在するが、その積が超える場合`r`、包含排他により、より深い再帰が自然に停止されます。 たとえば、`r = 10`、`k = 2`、組み合わせて`4`そして`9`収量`36`、これはすぐに削除され、無効な投稿がカウントに入らないようにします。
