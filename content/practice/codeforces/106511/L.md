 ## 解決策
 ## 問題の理解

 平面上に一連の点が与えられ、そのうちの 3 つまたは 4 つを選択できます。 選択した点は単純な多角形を形成する必要があります。つまり、エッジが交差することはできず、囲まれた領域を最大化する形状が必要です。 出力はエリアそのものではなく、そのような最適な三角形または四角形を形成する点のインデックスを循環順序で出力します。 

この制約により、広い座標範囲で最大 4000 点が許可されます。 これにより、サイズ 3 または 4 のすべてのサブセットを試行するアプローチは即座に除外されます。 すべてのトリプルに対する単純な列挙はすでに完了しています。$O(n^3)$、大まかに言うと$6.4 \times 10^{10}$1 ～ 2 秒で実行可能な限界をはるかに超える上限での操作。 注意深く最適化された四辺形列挙であっても、さらに悪くなる可能性があります。 

「3 つの点が同一線上にない」というジオメトリ条件は縮退を単純化します。すべてのトリプルは非ゼロの面積を持つ有効な三角形を形成し、凸包エッジは曖昧さなく明確に定義されます。 ただし、最適なポリゴンが凸包のような固定サブセットから簡単な方法で取得される必要があるという保証はありません。 四角形は構造を複雑にします。 

不注意だと、いくつかの特殊なケースを見逃してしまいがちです。 

すべての点が凸多角形を形成している場合、答えは常に凸包上にありますが、それを適切に正当化しない限り、正しさの十分な根拠とはなりません。 たとえば、4 つの点が凸状の四角形を形成している場合、その内側の三角形を選択しても四角形の領域を超えることはできません。 

点集合が最小の場合、次のようにします。$n = 3$、答えはその三角形であると強制されます。 四角形が存在することを前提とした解決策は失敗します。 

凸包がちょうど 3 つの点を持つように点が配置されている場合、内点を導入せずに四角形は不可能であるため、内点が存在する場合でも三角形を選択する必要があります。 

## アプローチ

 ブルートフォースのアイデアは簡単です。すべての 3 倍体とすべての 4 倍体の面積を計算し、4 倍体が単純な多角形を形成しているかどうかを確認し、最良のものを維持します。 外積による面積の計算は次のようになります。$O(1)$ただし、すべての 4 回転を列挙するのは$O(n^4)$、 について$2.5 \times 10^{14}$最大のケース。 三角形のみに限定しても、$O(n^3)$、まだ無理です。 

構造上の洞察は、面積最大化の下で最適なポリゴンが凸包上に存在する必要があるということです。 厳密にハルの内側にある点は、ハルの頂点を置き換えた場合、少なくとも 1 つのエッジを「内側に引っ張る」ことになるため、面積を増やすことはできません。 これにより、問題は点集合の凸包に帰着します。 

凸包に制限すると、凸多角形を次のように扱うことになります。$h \le 4000$頂点。 タスクは次のようになります。凸多角形に内接する最大面積の三角形または四角形を見つけます。 

凸多角形の三角形の場合、古典的な特性として、1 つの頂点を固定し、他の 2 つの頂点をハルに沿って移動すると、単峰性の領域動作が得られます。これは、回転キャリパーを使用して利用できます。 四角形の場合、最適な形状は対角線を共有する 2 つの三角形に分解できます。また、凸性により、ハルの頂点のペアを対角線として考慮するだけで済みます。 

これにより、検索が指数関数的な組み合わせから、2 ポインター技術を使用したハル頂点にわたる線形または線形に近いスキャンに減少します。 重要な構造上の制限は凸性です。頂点が周期的に順序付けされると、端点の単調な動きの下で面積関数は予測どおりに動作します。 

したがって、解決策は次のようになります。凸包を計算し、最適な領域を維持しながら、回転キャリパー スタイルのスイープを使用して、候補となる三角形と四角形を体系的に評価します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^4)$|$O(1)$| 遅すぎる |
 | 凸包 + キャリパー |$O(n \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. モノトーン チェーン アルゴリズムを使用して、指定された点の凸包を計算します。 これが必要なのは、最適なポリゴンはハル頂点のみを使用する必要があるためです。 内部ポイントが含まれている場合、領域を縮小することしかできません。 
2. ハルの頂点を反時計回りの順序で保存します。 面積の単調性に関する後続の推論はすべて循環構造に依存するため、この順序付けは重要です。 
3. これまでに確認された最良の三角形と四角形、および外積を使用して計算されたそれらの面積を追跡する変数を初期化します。 
4. 三角形の場合、開始頂点を固定します$i$ハル上で 2 ポインタ スキャンを使用して頂点を選択します$j$そして$k$三角形の面積を最大化するもの$(i, j, k)$。 ポインタの移動は次のように機能します。$k$船体に沿って前方に移動すると、エリアは固定のために単峰的に動作します。$i, j$。 
5. 四角形の場合、2つの頂点を固定します$i$そして$j$潜在的な対角線として。 次に、対角線で形成される三角形の面積の合計を最大化する、対角線の各辺で最適な頂点のペアを選択することで、四角形の 2 つの「辺」を個別に最適化します。$(i, j)$。 これが機能するのは、凸状の四角形が対角線を共有する 2 つの重なり合わない三角形に分割されるからです。 
6. すべての三角形および四角形の候補領域を比較し、インデックスの最適な構成を保存します。 
7. 保存されたインデックスを巡回順序で出力し、ポリゴンが一貫した方向 (時計回りまたは反時計回り) でレポートされるようにします。これはハルの順序から再構築できます。 

### なぜ効果があるのか

 正しさは、セットから選択された頂点を持つ最大面積のポリゴンが凸包上に存在する必要があるという事実に基づいています。 凸多角形に制限すると、凸以外の選択は、面積を減らさずに頂点をハルに沿って外側に「押す」ことで改善できます。 2 番目の構造特性は、凸多角形内では、トリプルまたは対角線で定義される面積関数がハル次数に沿って単峰性であるため、すべての組み合わせをチェックすることなく 2 ポインター最適化で最大値を見つけることができることです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def convex_hull(points):
    points = sorted(set(points))
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def tri_area(a, b, c):
    return abs(cross(a, b, c))

def main():
    n = int(input())
    pts = [tuple(map(int, input().split())) + (i,) for i in range(n)]

    hull = convex_hull([(x, y, i) for x, y, i in pts])
    m = len(hull)

    best_area = -1
    best = None

    # triangles
    for i in range(m):
        for j in range(i + 1, m):
            k = j + 1
            while k + 1 < m:
                a1 = tri_area(hull[i], hull[j], hull[k])
                a2 = tri_area(hull[i], hull[j], hull[k + 1])
                if a2 >= a1:
                    k += 1
                else:
                    break
            if k < m:
                area = tri_area(hull[i], hull[j], hull[k])
                if area > best_area:
                    best_area = area
                    best = (3, hull[i][2], hull[j][2], hull[k][2])

    # quadrilaterals via diagonal split
    for i in range(m):
        for j in range(i + 1, m):
            best1 = (0, -1)
            best2 = (0, -1)

            # pick best k on one side
            for k in range(j + 1, m):
                val = tri_area(hull[i], hull[j], hull[k])
                if val > best1[0]:
                    best1 = (val, k)

            # pick best l on other side
            for l in range(0, i):
                val = tri_area(hull[i], hull[j], hull[l])
                if val > best2[0]:
                    best2 = (val, l)

            if best1[1] != -1 and best2[1] != -1:
                area = best1[0] + best2[0]
                if area > best_area:
                    best_area = area
                    best = (4, hull[i][2], hull[j][2], hull[best1[1]][2], hull[best2[1]][2])

    print(best[0])
    print(*best[1:])

if __name__ == "__main__":
    main()
```凸包構造が基礎です。 それがなければ、残りのアルゴリズムは活用できる構造を持ちません。 三角形の検索では、エリアが改善された場合にのみ前進する制御されたポインタが使用され、完全な列挙が回避されます。 四辺形探索は固定対角線に沿った分割に依存しており、これにより 4 点選択がハル次数に沿った 2 つの独立した 1D 最適化に削減されます。 

微妙な実装の詳細は、出力では幾何学的座標ではなく入力順序を参照する必要があるため、ハル頂点が元のインデックスを保持する必要があることです。 もう 1 つは、外積の符号を慎重に解釈する必要があるため、四角形の三角形の面積を合計するときの方向の一貫した処理です。

 ## 特殊なケース

 すべての点が三角形上にある場合 (凸包サイズが 3 に等しい)、アルゴリズムは有効な四角形候補を見つけることができず、三角形スキャンが唯一の原因となります。 これは、頂点を複製したり、面積を減らす内部点を導入したりしない限り、単純な四角形は存在しないという幾何学的制約と一致します。 

船体のサイズがちょうど 4 の場合、三角形と四角形の両方が評価され、いずれかの対角線に沿った四角形の分割が考慮されます。 このアルゴリズムは、三角形と四角形の領域を正確に比較し、大きい方を選択します。これは、凸四角形が常に 3 つの頂点によって形成される最適な三角形に勝るとは限らないため、必要です。
