 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times m$グリッドであり、すべてのセルには最初に個別の役員が含まれているため、正確に$n \cdot m$役員の合計。 次に、これらの役員を同じグリッド位置のセットに再配置するため、最終的な構成は元の割り当ての順列になります。 

重要な制約は、個々の役職に関するものではなく、すべての役員間の関係に関するものです。 どの 2 人の警官についても、最終的な配置におけるマンハッタン距離は最初とまったく同じでなければなりません。 言い換えれば、元のグリッドで 2 人の警察官が一定の距離離れていた場合、再割り当て後もその正確なマンハッタン距離に留まらなければなりません。 

タスクは、すべてのペアごとのマンハッタン距離をモジュロで維持する、グリッド上の警察官の順列の数を数えることです。$998244353$。 

制約$n, m \le 5000$まで$10^4$テスト ケースは、テスト ケースごとの二次関数や、すべてのペアについて明示的に推論しようとするものを即座に除外します。 完全なペアごとの比較$nm$ポイントは次のとおりです$(nm)^2$、これは実現不可能です。 

さらに微妙な点は、この条件がすべてのペアにわたってグローバルであるということであり、これは剛直な幾何学的構造を示唆しています。 有効な再割り当ては、マンハッタン メトリックの下でグリッドの大域対称のように動作する必要があります。 

いくつかの特殊なケースは、何が起こっているかを明確にするのに役立ちます。 

いつ$n = 1, m = 1$、役員と役職は 1 つだけであるため、有効な割り当ては 1 つだけです。 

いつ$n = 1, m = 3$、3つの点の線があります。 3 つの位置の順列はすべてのペアごとのマンハッタン距離を保存します。これらの距離は単に直線上の絶対的な差であるため、直線を反転するか固定したままにするかは両方とも機能しますが、距離が相互作用する高次元ではすべての順列が機能するわけではありません。 

さらに明らかなケースは、$n = 2, m = 2$。 マンハッタン幾何学では正方形を形成する 4 つの点があります。 2 つの対角点を交換すると残りの点までの距離が壊れるため、すべての順列がすべてのペアごとの距離を保存するわけではありません。 これは、有効な変換が高度に制限されており、座標の任意の並べ替えではないことを示しています。 

重要な点は、恣意的な順列をカウントしているのではなく、グリッド上のマンハッタン メトリックの構造が保存された対称性をカウントしているということです。 

## アプローチ

 直接的なアプローチは、問題をグラフ同型問題として解釈することです。 各ノードがグリッド セルであり、エッジの重みがマンハッタン距離である完全な重み付きグラフができました。 この重み付き完全グラフの自己同型をカウントするように求められます。 

原理的には、すべての距離を検証することによって、順列がすべての距離を維持しているかどうかをチェックしようとすることができます。$(n m)^2$ペア。 順列を修正したとしても、それを検証するにはコストがかかります$O((nm)^2)$、これはすでに大きすぎるため、順列の列挙は階乗になります。 

したがって、ブルート フォースは遅いだけでなく、実現可能性とは完全に切り離されています。 

マンハッタン距離の構造が活路を与えてくれる。 ポイント$(x, y)$は、距離式の x 座標と y 座標を通じて独立して寄与します。$$|x_1 - x_2| + |y_1 - y_2|.$$順列は、絶対差を歪めないグローバル変換まで x 座標と y 座標のマルチセットを個別に保存する場合にのみ、そのような距離をすべて保存します。 

重要な観察は、有効なマッピングは両方の座標で相対的な順序構造を保持する必要があるということです。 すべてのペアごとの絶対差を保存する直線上の唯一の変換は、恒等と反転です。 グリッドでは、これらの選択は行と列に独立して適用されますが、x と y を交換してもマンハッタン距離は変わらないため、軸を交換する可能性もあります。 

したがって、グリッドは、大域対称性の小さなグループ、つまり同一性、水平方向の反射、垂直方向の反射、およびそれらの組み合わせ、さらには次の場合の軸の交換を正確に認めます。$n = m$。 

これにより、問題は、これらの対称性のうち、ラベル付きの将校に対する有効な個別の割り当てがいくつあるかを数えるということになります。 各対称性はグリッド セルの全単射に対応し、役員は個別であるため、有効な各対称性は正確に 1 つの割り当てに寄与します。 ただし、微妙な点があります。寸法が異なる場合、軸の交換は無効です。 

最終的な結果は、行と列を個別に反転できるかどうかにのみ依存します。 各次元の長さが 1 より大きい場合、その軸を反転するとペアごとのマンハッタン距離がすべて保存されるため、各次元の係数は 2 になります。 次元のサイズが 1 の場合、それを反転しても新しいことは何も起こりません。 両方の次元が 1 より大きい場合、独立した選択肢が得られ、4 つの構成が得られます。 

これにより、次のようなコンパクトな式が得られます。$$\text{answer} = 2^{[n>1]} \cdot 2^{[m>1]} \bmod 998244353.$$したがって、この問題は、大域的な組み合わせ順列問題から、完全に絶対値幾何の不変性によって駆動される小さな対称性の計数問題に崩壊します。

 ## アルゴリズムのチュートリアル

 1.読む$n$そして$m$各ケースは独立しているため、テストケースごとに。 有効な変換の構造は、これら 2 つの次元のみに依存します。 
2. グリッドを水平方向に反転できるかどうかを判断します。 これは次の場合にのみ可能です$n > 1$行が 1 つしかない場合、反転しても個別の構成が生成されないためです。 
3. グリッドを垂直方向に反転できるかどうかを判断します。 これは次の場合にのみ可能です$m > 1$、同じ理由です。 
4. 有効な軸反転ごとに、答えに 2 を掛けます。行の反転は列の距離に影響せず、またその逆も同様であるため、これらの選択肢は独立しています。 
5. 積モジュロを出力します。$998244353$。 

選択の独立性により、加算ではなく乗算が有効になります。 各軸の反転はバイナリのグローバル変換であり、それらを組み合わせることですべての異なる対称構成が生成されます。 

### なぜ効果があるのか

 2 点間のマンハッタン距離は、1 次元の絶対差の合計に分解されます。 すべてのペアごとのマンハッタン距離を保存する変換では、両方の座標に沿った絶対差を個別に保存する必要があります。 直線上で、すべての絶対的な差異を保存する唯一の全単射は同一性と反転です。 これを 2 次元に拡張すると、同じ制限の下で各軸が独立して動作することが強制され、グリッドが正方形でない限り座標の混合は許可されません。この場合、軸を交換しても同じ対称グループを超えた新しい距離パターンは導入されません。 これにより、すべての有効な割り当てが独立した軸反転の組み合わせに正確に制限されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    
    ans = 1
    if n > 1:
        ans *= 2
    if m > 1:
        ans *= 2
    
    print(ans % MOD)
```この実装では、対称分解を直接エンコードします。 各次元は、少なくとも 2 つの異なる座標があるかどうかに応じて、二項選択に影響します。 有効な変換の構造は軸の反転によって完全に決定されるため、置換をシミュレートしたり、マッピングを構築したりする必要はありません。 

ここでよくある間違いは、軸の交換をあらゆる場合に追加の要素として扱おうとすることです。 これは、より一般的な定式化における正方形グリッドの場合にのみ問題になりますが、この問題の定式化では、独立したフリップ構造を超えた追加の個別の割り当ては作成されません。

## テストケース```python
import sys, io

MOD = 998244353

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline
    
    t = int(input())
    out = []
    for _ in range(t):
        n, m = map(int, input().split())
        ans = 1
        if n > 1:
            ans *= 2
        if m > 1:
            ans *= 2
        out.append(str(ans % MOD))
    return "\n".join(out)

# provided samples
assert solve("2\n1 1\n2 3\n") == "1\n4"

# custom cases
assert solve("1\n1 5\n") == "2", "single row"
assert solve("1\n5 1\n") == "2", "single column"
assert solve("1\n2 2\n") == "4", "full symmetry"
assert solve("3\n1 1\n1 2\n2 1\n") == "1\n2\n2", "mixed edge cases"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1×5 | 2 | 列反転のみが存在します |
 | 5×1 | 2 | 行反転のみが存在します |
 | 2×2 | 4 | 両方の反転がアクティブ |
 | 混合 | 1,2,2 | 複数のエッジ構成 |

 ## 特殊なケース

 いつ$n = 1$、グリッドは 1 つの行に折りたたまれ、「行の反転」は恒等変換になります。 このアルゴリズムでは行次元から 2 の因数が正しく生成されないため、答えは列次元のみに依存します。 たとえば、入力$1 \ 3$結果は 2 で、1 行上のすべてのペアごとの絶対差を保存する 2 つの可能な順序が一致します。 

いつ$m = 1$、同じ推論が対称的に当てはまります。 次の場合、解は 2 を生成します。$n > 1$そして$m = 1$これは、行の反転のみが意味があることを反映しています。 

両方の次元が 1 の場合、両方のチェックが失敗し、結果は 1 のままになります。点が 1 つしかないため、追加の構成を導入する隠れた対称性はなく、どのような置換も自明で一意です。
