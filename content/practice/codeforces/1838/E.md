 ## 問題の理解

 長さの配列がいくつあるかを数えるように求められます$m$価値観を超えて$1$を通して$k$指定された配列を含む$a$長さの$n$続編として。 サブシーケンスでは、次の要素が許可されます。$a$順番に表示されますが、連続している必要はありません。 タスクは、すべての個別の配列をカウントすることです$b$長さの$m$この条件を満たすモジュロ$10^9+7$。 

主な課題は、その規模から生じます。$m$まで可能です。$10^9$。 明らかに、考えられるすべての配列を生成することは不可能です。 の合計$n$すべてのテストケース全体で最大でも$2 \cdot 10^5$、それで処理できるようになります$a$テスト ケースごとの線形時間ですが、線形に依存するアプローチはすべて、$m$実現不可能です。 強引な反復ではなく、数学的で組み合わせ的な方法が必要です。 

エッジケースは有益です。 もし$m = n$、唯一の配列$b$それはまさに機能します$a$。 もし$k = 1$、 それから$a$すべて 1 と任意の配列で構成されなければなりません$b$長さの$m$たった一つのものです。 もし$n = 1$そして$m$が大きい場合、単一の要素は任意の位置に配置でき、残りの位置は次のいずれかの値を取ることができます。$1$に$k$。 これらの特殊なケースは、ソリューションがポジションにわたる乗算カウントを効率的に処理する必要があることを示しています。 

## アプローチ

 ブルートフォースアプローチでは、すべてが列挙されます。$k^m$長さの配列$m$、それぞれについてチェックします。$a$サブシーケンスとして表示されます。 これは原理的には正しいのですが、$k^m$控えめな人でも天文学的に成長する$k$そして$m$。 直接の反復は不可能です。 

最適なアプローチのための重要な観察は、組み合わせ論から得られます。 埋め込むには$a$の中へ$b$でポジションを選択します。$b$の各要素に対して$a$。 ポジションを選択したら、残りのポジションは$m-n$位置には以下の任意の値を入力できます。$1$に$k$。 ポジションを選択する方法の数$a$は$\binom{m}{n}$要素は順番に出現する必要があるためです。 が占めていないポジションについては、$a$、それぞれが持っています$k$選択肢があるので、$k^{m-n}$詰め物。 最後に、の要素は、$a$彼ら自身がその価値観を尊重しなければならない$a$したがって、さらなる多重度には寄与しません。 これにより、問題はコンピューティングに限定されます$\binom{m}{n} \cdot k^{m-n} \mod 10^9+7$。 なぜなら$m$非常に大きくなる可能性があるため、モジュラー算術手法を使用して計算します$\binom{m}{n} \mod 10^9+7$階乗とモジュラー逆関数を使用して効率的に実行できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |

 | 最適 | テスト ケースあたり O(n + log m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 階乗を最大値まで事前計算する$n$すべてのテストケースにわたって。 階乗だけが必要です$n$ルーカスの定理またはモジュラー逆関数を使用して計算するためです。$\binom{m}{n}$モジュロ$10^9+7$いつでも効率的に$m$よりもはるかに大きいです$n$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$、$m$、$k$、および配列$a$。 の値$a$配列はその長さを超えて組み合わせカウントに影響を与えません。$b$の順序のみを保持する必要があります$a$。 
3. コンピューティング$\binom{m}{n} \mod 10^9+7$階乗とモジュラー逆行列を使用します。 もし$m$が大きく、係数が素数である場合、ルーカスの定理を適用して次のような場合を処理します。$m \ge 10^9$。 
4. コンピューティング$k^{m-n} \mod 10^9+7$高速べき乗剰余演算を使用します。 これは、次の要素によって占められていない位置を説明します。$a$。 
5. 2 つの結果を剰余で乗算します。$10^9+7$答えを得るために。 
6. 各テストケースの結果を出力します。 

正確さを保証する不変条件は、すべての有効な配列であることです。$b$ポジションの 1 つの選択肢に正確に対応します$a$そして残りの位置への値の割り当ては 1 つだけです。 配列が二重にカウントされたり、配列が欠落したりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modpow(x, y, mod):
    result = 1
    x %= mod
    while y > 0:
        if y & 1:
            result = result * x % mod
        x = x * x % mod
        y >>= 1
    return result

# Precompute factorials up to max n
MAX_N = 200000
fact = [1] * (MAX_N + 1)
invfact = [1] * (MAX_N + 1)
for i in range(1, MAX_N + 1):
    fact[i] = fact[i-1] * i % MOD
invfact[MAX_N] = pow(fact[MAX_N], MOD-2, MOD)
for i in range(MAX_N, 0, -1):
    invfact[i-1] = invfact[i] * i % MOD

def nCr(n, r):
    if r < 0 or r > n:
        return 0
    if n < MOD:
        return fact[n] * invfact[r] % MOD * invfact[n-r] % MOD
    # Lucas theorem for large n
    ni, ri = n % MOD, r % MOD
    return nCr(n//MOD, r//MOD) * nCr(ni, ri) % MOD

t = int(input())
for _ in range(t):
    n, m, k = map(int, input().split())
    a = list(map(int, input().split()))
    ways_positions = nCr(m, n)
    ways_fill = modpow(k, m - n, MOD)
    print(ways_positions * ways_fill % MOD)
```このソリューションは非常に大きなサイズを効率的に処理します$m$の組み合わせ配置を分離することで、$a$そして残りのポジションについては自由な選択が可能です。 べき乗モジュラーと階乗事前計算により、以下の条件下でも演算が高速に維持されることが保証されます。$10^9+7$。
