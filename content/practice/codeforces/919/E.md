 ## アルゴリズムのチュートリアル

 まず、次のような自明なケースを分離します。`a = 0 mod p`または`a = 1 mod p`、指数関数的な動作は退化し、等差数列として直接処理する必要があるためです。 

次に、離散対数情報を事前計算します。`a^n mod p`。 以来`p`は素数、乗法群の剰余`p`サイズがあります`p−1`したがって、ゼロ以外のすべての剰余は原始根の累乗として表現できます。 からマッピングを構築します`a^n mod p`値をその指数位置のモジュロに変換`p−1`。 

1. すべての値を計算する`a^k mod p`のために`k`から`0`に`p−2`、各剰余がどの指数で現れるかを記録します。 これにより、指数項のサイクル構造が作成されます。 このステップが必要なのは、指数部分によってどの残基が到達可能であるかが決まるためです。 
2. 考えられる各指数値について`k`、計算する`r = a^k mod p`。 これにより、元の式の指数部分の候補値が得られます。 
3. それぞれについて`k`、元の方程式を次の条件に変換します。`n mod p`:`n · r ≡ b (mod p)`となり、`n ≡ b · r^{-1} (mod p)`。 
4. 間の一貫性を強制します。`n mod p`そして`n mod (p−1)`。 以来`k ≡ n (mod p−1)`指数が等しい場合に成立する必要があります`a^n`、整数が必要です`n`両方の合同を満たす。 
5. 合同のペアごとに、CRT 推論を使用して、その数を数えます。`n ≤ x`彼らを満足させます。 有効な各システムは等差数列を定義し、その中に含まれる項の数を数えます。`[1, x]`。 

正しさは、すべての有効な情報が正しいかどうかにかかっています。`n`ある指数クラスに一意に対応します`k`、そのクラス内では、線形合同式は有効な剰余を法としてフィルタリングします。`p`。 

### なぜ効果があるのか

 すべての整数`n`2 つの独立したモジュラー投影を誘発します。1 つは制御します。`a^n mod p`のみに依存します。`n mod (p−1)`、および明示的に次のように表示されるもの`n mod p`。 このアルゴリズムは、一貫した指数クラスをすべて列挙し、これら 2 つのモジュール ビュー間の互換性を強制します。 どちらの制約もモジュール式で有限であるため、有効な制約はすべて`n`は 1 回だけカウントされ、すべての無効な割り当ては少なくとも 1 つの制約によって除外されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def egcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x, y = egcd(b, a % b)
    return g, y, x - (a // b) * y

def modinv(a, mod):
    g, x, _ = egcd(a, mod)
    return x % mod

def crt(a1, m1, a2, m2):
    g, x, y = egcd(m1, m2)
    if (a2 - a1) % g != 0:
        return None
    lcm = m1 // g * m2
    k = (a2 - a1) // g * x % (m2 // g)
    res = (a1 + m1 * k) % lcm
    return res, lcm

def solve():
    a, b, p, x = map(int, input().split())

    if x == 0:
        print(0)
        return

    a %= p
    b %= p

    if p == 2:
        cnt = 0
        for n in range(1, x + 1):
            if (n * pow(a, n, p)) % p == b:
                cnt += 1
        print(cnt)
        return

    # build discrete log table for a^k mod p
    pos = {}
    cur = 1
    for k in range(p - 1):
        if cur not in pos:
            pos[cur] = k
        cur = (cur * a) % p

    ans = 0

    for k in range(p - 1):
        r = pow(a, k, p)
        if r == 0:
            continue

        inv_r = modinv(r, p)
        n_mod_p = (b * inv_r) % p

        # n ≡ k (mod p-1)
        # n ≡ n_mod_p (mod p)
        res = crt(k, p - 1, n_mod_p, p)
        if res is None:
            continue

        start, mod = res

        if start > x:
            continue

        ans += (x - start) // mod + 1

    print(ans)

if __name__ == "__main__":
    solve()
