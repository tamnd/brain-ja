 ## 解決策
 ## 問題の理解

 いくつかの独立したテスト ケースが与えられています。 各テスト ケースには、一列に配置された一連の単語があります。 タスクは、ポジションのペアが何ペアかを数えることです$(i, j)$と$i < j$単純な視覚的条件を満たします。これらの位置にある 2 つの単語が同じ文字で始まる場合、「アーマドを魅了する」ということです。 

したがって、テスト ケースごとに、基本的に文字列のリストをスキャンし、同じ最初の文字を共有するペアの数を数えます。 

制約により、最大で$10^5$すべてのテストの合計で、テスト ケースごとの単語数が多く、各単語は非常に短く、最大でも 13 単語です。これは、単語のすべてのペアを直接比較するソリューションは、最悪の場合には遅すぎることを意味します。$n^2$テストケースごとの比較、これは約$10^{10}$操作時の操作$n = 10^5$。 これは 1 秒で実行できる速度をはるかに超えています。 

微妙な特殊なケースは、すべての単語が同じ文字で始まる場合です。 たとえば、入力が次の場合:```
1
5
aaa aab aac aad aae
```すべてのペアは有効なので、答えは次のようになります。$\binom{5}{2} = 10$。 単純なソリューションでも論理的に機能する可能性はありますが、ペアの反復ロジックが正しくないために二重にカウントされたり、ペアが欠落したりすることを回避する必要があります。 

もう 1 つの特殊なケースは、すべての単語が異なる文字で始まる場合です。```
1
4
apple banana cat dog
```ここで、答えはゼロであり、グループ化ロジックはシングルトン グループを正しく処理する必要があります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 すべてのインデックスのペアをチェックします$(i, j)$の最初の文字を比較します。$w_i$そして$w_j$、一致する場合は答えをインクリメントします。 これは、問題に記載されている条件を直接評価するため、正解です。 

問題は規模だ。 のために$n = 10^5$、比較の数は約$5 \times 10^9$、小さくてもまだ大きい入力の場合でも、速度が遅すぎます。 

重要な点は、各単語の最初の文字のみが重要であるということです。 単語をペアごとに比較する代わりに、単語をその開始文字ごとにグループ化できます。 文字が出てきたら$k$最初の文字の倍である場合、それは正確に寄与します$\frac{k(k-1)}{2}$有効なペア。 これにより、問題はペアの列挙から頻度のカウントに変換されます。 

私たちは問題を二次比較から単一の線形スキャンと 26 の可能な文字にわたる一定の作業に削減します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^2)$|$O(1)$| 遅すぎる |
 | 周波数計数 |$O(n)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. サイズ 26 の周波数配列をゼロに初期化し、小文字ごとに 1 つのスロットを割り当てます。 この配列には、各文字で始まる単語の数が格納されます。 
2. 入力内の各単語について、その最初の文字を読み取り、対応する頻度カウンターをインクリメントします。 このステップでは、文字列からのすべての関連情報を 1 つの整数更新に圧縮します。 
3. すべての単語を処理した後、26 文字を繰り返します。 周波数ごとに$f$、次の式を使用して、その文字によって寄与された有効なペアの数を計算します。$f \times (f - 1) / 2$、それを答えに追加します。 
4. テスト ケースの累積合計を出力します。 

### なぜ効果があるのか

 このアルゴリズムは、最初の文字に基づいてインデックスを素のグループに分割することに依存しています。 すべての有効なペアは、そのようなグループの 1 つからのものである必要があり、グループ内のすべてのペアは有効です。 グループは重複しないため、各グループ内の組み合わせを合計すると、各有効なペアが 1 回だけカウントされ、無効なペアが含まれることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        words = input().split()
        
        freq = [0] * 26
        
        for w in words:
            freq[ord(w[0]) - 97] += 1
        
        ans = 0
        for f in freq:
            ans += f * (f - 1) // 2
        
        print(ans)

if __name__ == "__main__":
    solve()
```コードは各テスト ケースを個別に処理します。 重要な実装の詳細は、最初の文字のみがアクセスされるため、不必要な文字列処理が回避されることです。 周波数配列は、ケース間の漏れを避けるためにテスト ケースごとにリセットされます。 

ペアのカウント式はすべての入力が読み取られた後に適用されるため、誤って部分的な情報をカウントすることがなくなります。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())

        n = int(input())
        words = input().split()

 ## 特殊なケース

 次のような単一単語のテストケースの場合`1 a`、周波数配列には 1 の非ゼロ エントリが 1 つ含まれています。組み合わせ式は次のようになります。$1 \cdot 0 / 2 = 0$なので、出力は正しいです。 

すべての単語が同じ最初の文字を共有する場合、たとえば、`a aa aaa aaaa`、「a」の頻度は 4 になります。 アルゴリズムは計算します$4 \cdot 3 / 2 = 6$、順序付けされていないインデックスのペアの数と一致します。 

次のような完全に多様なセットの場合`a b c d e`、各周波数は 1 であるため、すべての寄与はゼロになり、出力は 0 のままとなり、偶発的なクロスレターペアリングが正しく回避されます。
