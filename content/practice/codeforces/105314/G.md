 ## 問題の理解

 いくつかの独立したシナリオが与えられています。 各シナリオには、$n$映画、それぞれ固定チケット料金です。 目標は、すべての映画を一度だけ見ることです。 通常、映画を鑑賞するには、それぞれのチケット料金を支払う必要があります。 

ただし、別の購入オプションがあります。固定金額を支払うこともできます。$k$そして受け取る$m$無料の映画チケット。 このような各チケットはどの映画にも使用できるため、その映画の個別料金の支払いを「スキップ」することができます。 このバンドルは複数回購入でき、未使用のチケットは繰り越すことができます。 

各テスト ケースのタスクは、費やされる合計金額が最小限に抑えられるように、購入するバンドルの数と無料チケットをどの映画に使用するかを決定することです。 

重要な緊張関係は、高価な映画に直接支払うか、バンドル チケットを最適に使用するかということです。 各バンドルには固定コストと固定容量があるため、決定は 1 つの映画に対してローカルではなく、分類されたコスト構造全体でグローバルに行われます。 

制約は効率要件を意味します。 すべてのテスト ケースにわたる映画の総数は次のとおりです。$10^6$したがって、どの解も線形または線形に近い必要があります。$O(n \log n)$。 二次関数の何か$n$1 つのテスト ケースでも到達する可能性があるため、遅すぎます。$2 \cdot 10^5$映画。 

単純な試みでは、可能な限りの数のバンドルを試し、最も高価な映画へのチケットの割り当てをシミュレートします。 各シミュレーションには大きな配列の並べ替えやスキャンが繰り返し行われるため、これではすぐに遅くなりすぎます。 

いくつかのエッジ状況が重要です。 

すべての映画費用が少額の場合、バンドルを購入するのは完全に無駄になる可能性があります。$k$最安価格の合計を超える可能性があります$m$映画。 

ある映画が他の映画と比べて非常に高価な場合、ほとんどの場合、その映画にバンドル チケットを使用するのが最適です。$a_i$支出を正当化する$k$全体に広がる$m$を使用します。 

もし$m = n$1 つのバンドルですべての映画を置き換えることができるため、比較します。$k$すべての費用の合計で。 

素朴な推論が失敗する小さな例は次のとおりです。 

入力:$n=4, m=2, k=10$、費用:$[1, 2, 100, 101]$欲張って 2 バンドルを購入し、自由に割り当てると、小さな値でチケットを無駄にしてしまう可能性があります。 最適なソリューションでは、1 と 2 ではなく、100 と 101 のチケットが使用されることは明らかです。 

これは、割り当てでは常に高価な映画を世界的に優先する必要があることを示しています。 

## アプローチ

 直接的な総当たりアプローチでは、購入が検討されます。$x$バンドル、ここで$x$範囲は0から$n$。 それぞれの選択に対して、$x$を使用してシミュレーションします。$x \cdot m$最も高価な映画をカバーするチケットを購入すると、節約が最大化されます。 配列をソートし、カバーされていない要素と要素の合計として残りのコストを計算します。$x \cdot k$。 

これが機能するのは、無料チケットの数が固定されると、最適な戦略は常にそれらを最大値に適用することになるためです。 ただし、すべて試してみると、$x$遅すぎます。 それぞれについて$x$、プレフィックス/サフィックスの合計を再計算したり、データを繰り返し再スキャンしたりすることになり、$O(n^2)$または$O(n^2 \log n)$行動。 

重要な点は、実際にはすべてのバンドルを試す必要はないということです。 各バンドルが提供するのは、$m$「無料スロット」の費用$k$。 したがって、実際には、サイズのグループごとに固定コストで最大の要素をいくつ置き換えるかを決定しています。$m$。 この構造は、一度ソートしてから、いくつの要素を置き換える必要があるかを貪欲に決定することを提案しています。 

バンドルという観点から考えるのではなく、最初に最大の要素で無料チケットを使用するという観点から考えることができます。 使用することにした場合$t$無料チケットの総額を考えると、少なくとも支払わなければなりません$\lceil t / m \rceil \cdot k$そしてそれらのチケットは常に以下をカバーする必要があります$t$最大の映画費用。 

したがって、問題は最適な値を決定することになります。$t$これは、ソートされた配列の可能なプレフィックスを最大から最小までスキャンし、コストを動的に計算することに相当します。 

配列を降順に並べ替えます。 プレフィックスの合計が最初の合計コストを表すものとします。$i$最大の映画。 使用する場合$i$チケットの残りは私たちが支払います$n - i$直接映画を鑑賞できるほか、$\lceil i / m \rceil \cdot k$。 

全て評価いたします$i$から$0$に$n$、ソート後は線形となり、効率的なソリューションが得られます。

 ## アルゴリズムのチュートリアル

 1. 最も高価な映画の無料チケットの使用を常に最初に考慮するように、映画の費用を降順に並べ替えます。 これにより、チケットを使用すると、代替の配置と比較して最大の即時節約がもたらされることが保証されます。 
2. 最も高価な映画のサブセットの総コストを迅速に評価できるように、ソートされた配列に対してプレフィックスの合計を計算します。 
3. 使用された無料チケットの数を 0 から 0 まで繰り返します。$n$。 それぞれの値は決定を表します。高価な映画を置き換えるために、まさにその数のチケットを使用します。 
4. 固定数の場合$i$使用済みチケットの数から、必要なバンドルの数を計算します。$\lceil i / m \rceil$。 これを乗算します$k$それらのチケットを取得するためのコストを取得します。 
5. 残りの料金を通常どおり支払うコストを計算します。$n - i$映画、これは合計から次の合計を引いたものです。$i$最大の要素。 
6. 両方の部分を組み合わせてこの構成の合計コストを取得し、全体の最小値を追跡します。$i$。 
7. 見つかった最小値を出力します。 

この列挙で十分な理由は、チケットを小さな要素から大きな要素に交換してもコストが増加したり、実現可能性が損なわれることがないため、使用されるチケットが常に最大の要素に対応する最適なソリューションに変換できるためです。 

### なぜ効果があるのか

 どの時点でも、無料チケットの対象となる映画の数だけを気にしており、どのバンドルから来たのかは気にしません。 各チケットの価値は同じであり、各映画は独立しているため、最適な戦略では常にチケットに利用可能な最大のコストが最初に割り当てられます。 これにより、単調な構造が作成されます。使用されるチケットの数が増加するにつれて、対象となる映画のセットがソートされた配列のプレフィックス内で増加します。 バンドルのコストはサイズのグループの数のみに依存するため、$m$が必要な場合、このプレフィックスのコスト関数は明確に定義されており、すべてのプレフィックスの長さをチェックすることで最小化できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        a.sort(reverse=True)
        
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + a[i]
        
        total = prefix[n]
        ans = total
        
        for i in range(n + 1):
            bundles = (i + m - 1) // m
            cost = bundles * k + (total - prefix[i])
            if cost < ans:
                ans = cost
        
        print(ans)

if __name__ == "__main__":
    solve()
```コードはまず配列を並べ替えて、プレフィックスが最も高価な映画に対応するようにします。 プレフィックス合計配列を使用すると、上位の合計値を定数時間で計算できます。$i$映画。 

チケット利用可能回数ごとに$i$、チケットをサイズのブロックにグループ化することで、必要なバンドルの数を計算します。$m$。 バンドルの部分的な使用には依然としてバンドル全体の料金を支払う必要があるため、ここで上限区分が表示されます。 

残りのコストは、すべての未処理のムービーの合計からプレフィックスの合計を差し引いたものです。 全体的に最低限のもの$i$が答えです。 

微妙な点は、$i = 0$、これはバンドルをまったく購入しないことに相当し、バンドルが決して有益ではない場合に正確性を保証します。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    def solve():
        t = int(input())
        out = []
        for _ in range(t):
            n, m, k = map(int, input().split())
            a = list(map(int, input().split()))
            a.sort(reverse=True)
            prefix = [0]
            for x in a:
                prefix.append(prefix[-1] + x)

                ans = min(ans, bundles * k + (total - prefix[i]))
            out.append(str(ans))
        return "\n".join(out)

    return solve()
