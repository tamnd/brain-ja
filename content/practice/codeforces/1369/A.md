 ## 解決策
 ## 問題の理解

 このタスクでは、指定された正多角形のエッジの 1 つが水平軸に平行になり、もう 1 つのエッジが垂直軸に同時に平行になるように方向付けできるかどうかを判断するように求められます。 各ポリゴンは、そのポリゴンが持つ辺の数によってのみ定義され、これらの数のリストを受け取ります。 各カウントについて、そのような向きが存在する場合、出力は YES になり、そうでない場合は NO になります。 

入力制約から、最大 10,000 個のポリゴンが存在でき、各ポリゴンは最大 10 億の辺を持つことができます。 これにより、ポリゴンを明示的に構築したり、回転をシミュレートしたりするソリューションは除外されます。 どのアプローチも、辺の数から導出される数学的特性のみに依存する必要があります。 各ポリゴンのエッジ方向を列挙したり角度を計算したりする単純なアプローチでは、最悪の場合、数十億回の計算が必要となり、実行不可能です。 

エッジ ケースは、辺の数が少ない場合、特に三角形や正方形の場合に発生します。 正三角形は、どのような回転でも同時に 1 つのエッジを水平方向と 1 つの垂直方向に持つことはできませんが、正方形は可能です。 12 や 1,000,000,000 など、多数の辺を持つ多角形は同じ数学的規則に従い、ソリューションは非常に大きな整数を正しく処理できなければなりません。 

## アプローチ

 ブルートフォース手法では、各ポリゴンをシミュレートまたは回転して、すべてのエッジの方向をチェックします。 これは、考えられるすべての位置合わせを徹底的にテストするので正しいですが、10 億の辺を持つポリゴンではエッジを列挙するだけで 10 億回の操作が必要となるため、明らかに非現実的です。 

重要な観察は、正多角形の辺の数が 4 を均等に分割する場合、またはより一般的には、エッジが軸に揃うように多角形を正方形のグリッドに内接することができる場合、正多角形のエッジを水平および垂直にすることができるということです。 代数的に言えば、これは 360 度を辺の数で割った値が 90 度の倍数を許容するかどうかをチェックすることになります。 辺の数が 4 で割り切れる場合、エッジが両方の軸に揃うように回転できるため、多角形は美しくなります。 これにより、ポリゴンごとの定数時間の解が得られます。 

美しさの定義はエッジの位置合わせに依存するため、強引なアプローチは機能しますが、n が大きい場合は失敗します。 回転対称法 90 度で十分であるという洞察により、ポリゴンごとに結果を O(1) で計算できます。

 ## アルゴリズムのチュートリアル

 1. ポリゴン数 t を読み取ります。 これにより、アルゴリズムが反復される回数が決まります。 
2. 各多角形について、その辺の数 n を読み取ります。 
3. n が 4 で割り切れるかどうかを確認します。これは、多角形が 1 つのエッジが水平で、もう 1 つのエッジが垂直である方向を持つための条件です。 チェックではモジュラス演算子を使用します。 
4. n が 4 で割り切れる場合は、YES と出力します。 それ以外の場合は、NO を出力します。 各出力は、指定された順序で 1 つのポリゴンに対応します。 
5. すべてのポリゴンが処理されるまで繰り返します。 

これが機能する理由: 不変条件は、ポリゴンのエッジを両方の軸に揃えるために必要な回転は 90 度の倍数であるということです。 n 辺の正多角形は、エッジ間で 360 度を均等に分割します。 したがって、360/n が 90 の約数である場合、つまり n が 4 を割る場合、そのような回転が存在します。 これにより、非常に大きな数値を含む任意の n の正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        if 360 % n == 0 and (360 // n) % 90 == 0:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    main()
```このソリューションは、最初にポリゴンの数を読み取ります。 各多角形について、n を読み取り、360 が n で割り切れるかどうかを確認し、結果の角度 360/n が 90 度の約数になるかどうかを確認します。 これにより、エッジが軸に揃うようにポリゴンを回転できるようになります。 モジュラス演算は、10^9 までの大きな値を含むすべての整数を正しく処理します。
