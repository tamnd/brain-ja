 ## 解決策
 ## 問題の理解

 都市を表す、接続された重み付き無向グラフが与えられます。 一部のノードは放射線源であり、各線源ノードにはグラフ全体に広がり、最短経路距離に応じて線形に減衰する放射線強度があります。 具体的には、ノード i のソースが強度 r_i を持っている場合、任意のノード j は寄与 max(0, r_i − dist(i, j)) を受け取ります。 ノードの最終放射線レベルは、ノードがあらゆる発生源から受け取る最大の寄与です。 

したがって、ステートメントに隠されている最初のタスクは、すべてのノードの単一の値、つまりすべての線源が最短経路を通って伝播した後の最悪の放射線レベルを計算することです。 

その後、質問が与えられます。 各クエリは、開始ノード u から終了ノード v への商品の発送について尋ねます。グラフ内の任意のパスを選択できます。 選択したパスに沿って、訪問したすべてのノードがその放射値に寄与し、これらの値をパスに沿って並べ替えます。 特別なスーツにより、そのパス上の k 個の最大値を無視することができます。 パスのコストは、そのノードの中で (k+1) 番目に大きい放射値として定義され、パスに最大 k 個のノードがある場合はゼロとして定義されます。 

各クエリの目標は、結果として生じるコストを最小限に抑える u から v へのパスを選択することです。 

制約は大きく、テストあたり最大 100,000 ノードと 200,000 エッジ、全体で最大 10,000 クエリです。 これにより、最短パスを再計算したり、クエリごとにグラフ全体を再処理したりするソリューションは即座に除外されます。 O(n log n) を何度も繰り返す場合でも、クエリが非常に軽い場合を除き、危険になります。 重要な構造は、グラフがテスト ケースごとに固定されているため、前処理が優先される必要があるということです。 

素朴な解釈では、u と v の間のすべてのパスを列挙し、それらの k+1 番目に大きいノード値を計算しようとします。 エッジの重みは目的に影響しないため、最短パスに制限することさえ意味がありません。 これは基本的に組み合わせ経路最適化問題であり、メトリック最短経路問題ではありません。 

k が大きい場合、微妙なエッジケースが現れます。 k が少なくともパス上のノードの数である場合、答えは放射線レベルに関係なく常に 0 になります。 最適化を試みる不用意な実装は、たとえ答えが些細なものであっても、不必要にしきい値を調べることに時間を浪費する可能性があります。 

もう 1 つの落とし穴は、放射線フィールドがグローバルであり、クエリから独立していることを無視していることです。 クエリごとに再計算すると、解決策は直ちに実行不可能になります。 

## アプローチ

 最初の段階では、ノードの放射値を計算します。 各音源をエッジ距離によって減少する波を開始するものとして扱う場合、すべての音源 i はその位置で値 r_i に寄与していると見なすことができ、この値はエッジに沿って w だけ減少します。 各ノードに対して、可能な最大の伝播値が必要です。 

これは、各ソースが初期値 r_i で始まり、重み w のエッジをトラバースするたびに値が w ずつ減少するマルチソース プロセスと同等です。 正の値のみを伝播します。 自然な構造は、現在知られている最も高い値を常に拡張し、値からエッジの重みを引いた値で近傍を緩和する優先キューです。 各ノードはこれまでに確認された最大値を保持します。 これは本質的に、減少するポテンシャル場に対する「最大ダイクストラ」です。 

ソースからノードまでのパスは候補値 r_i からパス長を引いたものを定義しており、そのようなパスすべての最大値を単純に取得しているだけであるため、このステップは正しいです。 

この前処理の後、各ノードの重みは固定されます。 

次にクエリを考えてみましょう。 パス上の (k+1) 番目に大きいノードの重みを最小化する u から v へのパスが必要です。 有用な再定式化は、しきい値 x を固定し、重みが x を超える最大 k 個のノードを使用する u から v へのパスが存在するかどうかを尋ねることです。 重みが x より大きいノードを不良ノードと定義すると、条件「(k+1) 番目に大きい ≤ x」は「パス上に不良ノードが最大で k 個ある」と同等になります。

固定 x の場合、各ノードのコストが不良の場合は 1、その他の場合は 0 になる最短経路問題としてこれを解くことができ、u から v までの総コストを最小化したいと考えます。最小コストが高々 k であれば、x は実現可能です。 

これにより、各実現可能性チェックが、頂点コストを含むグラフ上の最短パスの計算に変わります。 これに対処する標準的な方法は、コストをノード遷移にプッシュし、ノード上でダイクストラまたは 0-1 BFS スタイルのトラバーサルを実行することです。 

k はクエリ固有であるため、最終的な答えは、考えられる放射値に対して x をバイナリ検索することによって見つかります。 各チェックは独立しています。 

ブルート フォース アプローチでは、再利用せずに候補 x ごとにこの最短パスが再計算され、クエリごとにおよそ O(log V · (n + m) log n) になります。これは境界線ですが、q ≤ 5 の場合には許容可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースパス列挙 | 指数 | O(n) | 不可能 |
 | チェックごとに放射 + ダイクストラによる二分探索を事前計算 | O(q · log V · (n + m) log n) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 放射線値の事前計算

 1. r_i > 0 を持ち、それぞれの値が r_i で始まるすべてのノード i で優先キューを初期化します。 これは複数の同時ソースを表します。 
2. ノード v でこれまでに見つかった最大放射線値を格納する配列 best[v] を維持します。 
3. 優先キューから現在の最高値状態 (u, val) を抽出します。 
4. val が best[u] に等しくない場合は、より適切な伝播が既に存在するため、スキップします。 
5. 各エッジ (u、v、w) について、候補値 cand = val − w を計算します。 cand が正で best[v] より大きい場合、best[v] を更新して (v, cand) をプッシュします。 

このプロセスは、各ノードに到達する可能な限り最も強い影響を常に維持しながら、「放射波」を外側に伝播します。 

### 質問に答える

 1. すべての個別の best[v] 値の中から、考えられるしきい値 x に対する二分探索。 これは、x がノード放射値と交差する場合にのみ答えが変化するため、有効です。 
2. 固定 x の場合、best[node] > x の場合、各ノードを不良としてマークします。 
3. u から v までの任意のパス上の不良ノードの最小数を計算します。これは最短パスで行われ、ノードに入ると、不良の場合はコスト 1 が追加され、そうでない場合は 0 が追加されます。 
4. 結果として得られる最小コストが最大でも k である場合、x は実行可能です。 
5. それに応じて二分探索を調整し、実行可能な最小の x が見つかるまで続行します。 

### なぜ効果があるのか

 放射前処理により、各ノードがクエリとは独立した固定の固有の重みを持つことが保証されます。 パスの目的は、エッジの重みではなく、パスに沿ったノードの重みのマルチセットのみに依存します。 しきい値の再定式化は、順序統計制約を、しきい値を超えるノードに対するカウント制約に変換します。 このようなノードの数を最小限に抑えることは、任意のパスに沿ってノードの重みの最適な順序を見つけることと同じです。 二分探索では、最大 k 個の違反があるパスを許可する最小のしきい値が分離されます。これは、(k+1) 番目に大きい値を最小化することに直接対応します。 

## Python ソリューション```python
import sys
import heapq

input = sys.stdin.readline
INF = 10**30

def compute_radiation(n, graph, r):
    best = [0] * (n + 1)
    pq = []

    for i in range(1, n + 1):
        if r[i] > 0:
            best[i] = r[i]
            heapq.heappush(pq, (-r[i], i))

    while pq:
        val_neg, u = heapq.heappop(pq)
        val = -val_neg

        if val != best[u]:
            continue

        for v, w in graph[u]:
            cand = val - w
            if cand <= 0:
                continue
            if cand > best[v]:
                best[v] = cand
                heapq.heappush(pq, (-cand, v))

    return best

def min_bad_path(n, graph, bad, start, target, limit):
    dist = [INF] * (n + 1)
    dist[start] = bad[start]
    pq = [(dist[start], start)]

    while pq:
        d, u = heapq.heappop(pq)
        if d != dist[u]:
            continue
        if u == target:
            return d
        for v, _ in graph[u]:
            nd = d + bad[v]
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))

    return dist[target]

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n, m, q = map(int, input().split())
        r = [0] + list(map(int, input().split()))

        graph = [[] for _ in range(n + 1)]
        for _ in range(m):
            u, v, w = map(int, input().split())
            graph[u].append((v, w))
            graph[v].append((u, w))

        rad = compute_radiation(n, graph, r)
        vals = sorted(set(rad[1:]))

        for _ in range(q):
            u, v, k = map(int, input().split())

            if u == v:
                out.append("0")
                continue

            lo, hi = 0, len(vals) - 1
            ans = vals[-1]

            while lo <= hi:
                mid = (lo + hi) // 2
                x = vals[mid]

                bad = [0] * (n + 1)
                for i in range(1, n + 1):
                    bad[i] = 1 if rad[i] > x else 0

                cost = min_bad_path(n, graph, bad, u, v, k)

                if cost <= k:
                    ans = x
                    hi = mid - 1
                else:
                    lo = mid + 1

            out.append(str(ans))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```最初の関数は、最大伝播ダイクストラ変種を使用して放射場を構築します。 2 番目の関数は、ノードがしきい値に違反しているかどうかをノード ペナルティで表す最短パスを実行することによって、候補しきい値を評価します。 外側のソルバーは、実行可能なしきい値に対する二分探索を使用してすべてを結び付けます。 

よくある微妙な点は、開始ノードの距離をそれ自体の不正なステータスで初期化することです。 これにより、コスト モデルがパスに沿った不良ノードのカウントの定義と一致することが保証されます。 

もう 1 つの重要な詳細は、両方のダイクストラ実行で古いヒープ状態をスキップすることです。 これがないと、更新が繰り返されると複雑さが大幅に低下する可能性があります。 

## 実用的な例

 ### 例 1

 ノード 1 と 3 が放射線源であり、ノード 2 がそれらの間にある小さなグラフを考えてみましょう。 伝播後、ノード 2 は両端から最大の減衰影響を受けます。 

k = 1 の 1 から 3 までのクエリの場合、可能なパスを比較します。 

| ステップ | パス | 不正なしきい値 x | 不良ノード | コスト |
 | --- | --- | --- | --- | --- |
 | 1 | 1-2-3 | 高い | なし | 0 |
 | 2 | 1-2-3 | 中 | ノード 2 | 1 |

 二分探索では、パスに存在する不良ノードが 1 つ以下である最小のしきい値が特定されます。これは、最小化される最適な 2 番目に大きい値に対応します。 

### 例 2

 k が十分に大きい場合、たとえばパス長から 1 を引いた値に等しい場合、どのパスも有効となり、答えはゼロになります。 

| ステップ | パス | k | コスト |
 | --- | --- | --- | --- |
 | 1 | 任意の u-v パス | 大 | 0 |

 これは、アルゴリズムが不必要な計算を行わずに縮退ケースを正しく処理していることを示しています。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべての放射線値がゼロの場合です。 その場合、すべてのノードの重みがゼロになるため、k に関係なくすべてのパスのコストがゼロになります。 二分探索では常に実行可能なしきい値 0 がすぐに見つかるため、アルゴリズムはこれを自然に処理します。 

Another edge case occurs when u equals v. The correct answer is always zero because no traversal is needed and there are no intermediate nodes contributing radiation.

 3 番目のケースは、k が非常に大きい場合です。 In that situation, the shortest path cost in terms of bad nodes is always less than or equal to k, so the binary search collapses to the minimum possible threshold, which is the smallest radiation value on any node reachable from u to v.
