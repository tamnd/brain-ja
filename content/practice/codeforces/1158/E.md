 ## 解決策
 ## 問題の理解

 未知のツリーを次のように再構築するように求められます。$n$単一タイプのクエリを許可するデバイスと対話することによって頂点を取得します。 木の各頂点にはランプがあり、デバイスによって一連の距離が提案されます。$d_1, d_2, \dots, d_n$。 これらの距離を送信すると、頂点のランプは$i$他に頂点が存在する場合に点灯します。$j \neq i$からの距離が$i$に$j$木の中にはせいぜい$d_j$。 この操作は最大 80 回まで繰り返すことができ、最終的には元のツリーのエッジを出力する必要があります。 

入力は次から始まります$n$、頂点の数。 その後、各クエリの後、デバイスは次の長さの文字列を返します。$n$「0」と「1」で構成され、どのランプが点灯しているかを示します。 出力にはリストが必要です$n-1$隠れたツリーと同じツリーを形成するエッジ。 

制約$n \le 1000$素朴な試みはできないことを意味します$O(n^2)$各クエリ内のすべての可能なペアを繰り返しチェックします (80 個のクエリとして)。$n = 1000$すでに実行可能な操作の限界に近づいている可能性があります。 主なエッジ ケースは、ツリーに長いチェーンがある場合に発生します。クエリされた距離が十分に大きくない限り、ランプはオフのままになるため、単純な戦略では接続の誤った推測が簡単に発生する可能性があります。 

たとえば、5 つの頂点からなるライン ツリーを考えてみましょう。$1-2-3-4-5$。 問い合わせてみると$d = [0,0,0,0,0]$、頂点間の距離が 0 以内にない頂点がないため、ランプは点灯しません。 問い合わせてみると$d = [1,0,0,0,0]$、木の正確な距離に応じて、頂点 2 に接続されたランプのみが点灯する場合があります。 距離条件を誤解すると、間違ったツリーが生成されやすくなります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのエッジを試し、特定のエッジが存在する場合にのみランプを点灯するクエリを作成してそれぞれをテストします。 概念的には単純ですが、これは実行不可能です。$n=1000$およそ50万足あります。 それぞれを検証するには 1 つまたは一連のクエリが必要となり、すぐに 80 クエリの制限を超えてしまいます。 

重要な点は、すべてのペアを直接クエリする必要がないということです。 ツリーの構造とデバイスの動作を利用できます。 でクエリすると$d_i = 1$単一の頂点に対して$i$そして$d_j = 0$他のすべての場合、点灯するランプはまさにその隣にあります。$i$ツリー内では頂点のみが直接接続されているため、$i$各頂点に対してこの手法を使用すると、隣接リスト全体を効率的に復元できます。 ツリー プロパティにより、複雑な距離計算や複数の間接的なクエリを必要とせずに、すべてのエッジが正しく識別されることが保証されます。 

これにより、作成の問題が軽減されます$n$クエリ。それぞれが単一の頂点の近傍を識別します。 このアプローチは、80 クエリ制限内で機能します。$n \le 1000$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) クエリ | O(n^2) | 遅すぎます。クエリ制限を超えています。 
| 最適 | O(n) クエリ | O(n^2) | 受け入れられ、すべてのエッジが再構築されます。 

## アルゴリズムのチュートリアル

 1.読む$n$、頂点の数。 
2. ツリーの空の隣接リストを初期化します。 
3. 頂点ごとに$i$1から$n$:

 1. クエリを作成する$d$どこ$d[i] = 1$そしてその他すべて$d[j] = 0$。 
2. デバイスにクエリを送信し、応答文字列を読み取ります。$s$。 
3. 頂点ごとに$j \neq i$、 もし$s[j] = '1'$、間にエッジを追加します$i$そして$j$隣接リストにあります。 これにより、すべての近傍が識別されます。$i$。 
4. すべてのクエリの後、各エッジが 1 回だけ記録されることを確認します (ツリーは無向です)。 
5.「!」を出力する 続いて$n-1$木の端。 

なぜ機能するのか: ツリーでは頂点からの距離$i$隣接するものまでの値はちょうど 1 です。$d_i = 1$他はすべてゼロの場合、ランプが点灯する唯一の方法は、頂点が直接隣接している場合です。 1 を超える距離が対応する頂点を超えるため、他の頂点はランプを点灯できません。$d_j$。 この不変条件により、すべてのエッジが重複なく識別されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def query(d):
    print("?", *d)
    sys.stdout.flush()
    return input().strip()

def solve():
    n = int(input())
    edges = set()
    for i in range(n):
        d = [0] * n
        d[i] = 1
        res = query(d)
        for j in range(n):
            if j != i and res[j] == '1':
                edges.add(tuple(sorted((i+1, j+1))))
    print("!")
    for a, b in edges:
        print(a, b)

solve()
```解決策は次のようになります$n$、各頂点のクエリを構築し、返されたランプの状態を使用してエッジを記録します。 各エッジは重複を避けるためにソートされたタプルに保存されます。 出力をフラッシュすることで、正しい相互作用が保証されます。 このソリューションは以下を保証します$n$クエリ数は 80 の制限内に収まります。
