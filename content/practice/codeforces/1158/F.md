 ## 解決策
 ## 問題の理解

 それぞれが数値で区切られた正の整数の配列が与えられます。$c$。 タスクは、この配列のすべてのサブシーケンスを調べ、それらを密度と呼ばれる数値によって分類することです。 密度は最大の整数として定義されます$p$可能なすべての長さの配列$p$、1 から 1 までの要素を持つ$c$、指定された配列のサブシーケンスとして表示されます。 言い換えれば、長さの部分列$p$1 から 2 までの数字のすべての組み合わせをカバーします。$c$長さの$p$その中に存在しなければなりません。 目標は、0 から最大までの可能な密度ごとにカウントすることです。$n$、正確にその密度を持つサブシーケンスがいくつあるか。 

入力サイズは$n \le 3000$そして$c \le 3000$。 これにより、すべてのサブシーケンスを明示的に考慮するアルゴリズムが即座に除外されます。$2^n$サブシーケンス、つまり大まかに言うと$10^{900}$上限で。 すべてのサブシーケンスを列挙するのではなく、配列の構造と密度定義を使用するアプローチが必要です。 

エッジケースには、すべての要素が等しい配列、または次の配列が含まれます。$c > n$。 たとえば、次の場合$a = [1,1,1,1]$と$c=1$、長さの任意の部分列$k$自動的に密度が設定されます$k$。 もし$c = 3$そして$a = [1,1]$、1 から 3 までのすべての要素を含むサブシーケンスはないため、すべてのサブシーケンスの密度は 0 です。サブシーケンスまたはその要素の長さを個別にチェックするだけの不注意なアプローチは、このような場合には失敗します。 

## アプローチ

 ブルートフォースアプローチでは、すべてのサブシーケンスを列挙し、長さのすべての配列をチェックしてそれぞれの密度を計算します。$p$、それぞれの密度を満たすものがいくつあるかを数えます。 このアプローチは理論的には正しいですが、操作数は$O(n 2^n)$サブシーケンスを生成するためと、$O(c^p)$それぞれをチェックするのは完全に不可能です$n \sim 3000$。 

重要な観察は、密度が各数値の最初と最後の出現の存在によって制御されるということです。 具体的には密度を確保するため$p$、サブシーケンスには 1 から 1 までのすべての数値が含まれている必要があります。$c$長さを形成する際に数字が除外されないように、$p$配列。 これにより、要素をセグメント内の最小値として固定し、有効なサブシーケンスを左右に再帰的にカウントする動的プログラミング アプローチが可能になります。 値 1 ～ を反復処理することにより、$c$それらの最初と最後の出現を考慮すると、すべてのサブシーケンスを直接列挙することを避けることができます。 

事実上、セグメント内の最小要素が配列を分割し、左右のセグメントからの寄与が乗算される分割統治 DP に問題を縮小します。 これは、最小要素を含むサブシーケンスを左右のセグメントから独立して組み合わせることができるという事実を利用します。

 | ブルートフォース | O(n 2^n c^p) | O(2^n) | 遅すぎる |
 | 最小要素セグメントの DP | O(n^2 c) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 1 から 1 までの各数値の最初と最後の出現を事前計算します。$c$配列内で。 これらの位置は、密度制約を維持するために各数値が表示される必要がある境界を決定します。 数字が表示されない場合、その不在によって密度が制限されます。 
2. DP テーブルを定義する`dp[l][r]`セグメント内の有効なサブシーケンスの数を表します$a[l..r]$密度の条件を満たしていること。 初期化する`dp[l][r] = 1`空のセグメントの場合、再帰的なカウントの乗算が可能になります。 
3. 可能なすべてのセグメントを長さを増やしながら繰り返します。 各セグメントについて、最小の数値を見つけます`min_val`セグメントに表示されます。 最初と最後の出現を使用して、セグメントを 3 つの部分に分割します。最初の出現の左側、最小要素をカバーする位置、最後の出現の右側です。 
4. 左セグメントと右セグメントを再帰的に結合して有効なサブシーケンスの数を計算し、すべてのサブシーケンスに最小要素が中央セグメントに 1 回だけ含まれるようにします。 左側と右側の部分列の数を掛けます。 
5. 各密度値に対応するすべてのセグメント長のカウントを累積します。 1 から 1 までの数字の正確な出現をカバーするセグメント`p`密度に貢献する`p`。 オーバーフローを避けるためにモジュラー演算を使用してください。 
6. 最後に、密度 0 の場合、ゼロより大きい密度を満たさないすべてのサブシーケンスをカウントします。これは、基本的に 1 から 1 までの数値が少なくとも 1 つ欠落しているサブシーケンスです。`c`。 

主な不変条件は、各 DP セグメントについて、そのセグメント内の最小値を持つすべての数値を含むすべてのサブシーケンスをカウントすることです。 最小要素がセグメントを分割するため、左右のサブシーケンスのすべての組み合わせは独立しており、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

n, c = map(int, input().split())
a = list(map(int, input().split()))

# Record first and last occurrence
first = [n] * (c + 1)
last = [-1] * (c + 1)
for i, val in enumerate(a):
    first[val] = min(first[val], i)
    last[val] = max(last[val], i)

# dp[l][r]: number of valid subsequences in a[l..r]
dp = [[0] * n for _ in range(n)]

for length in range(1, n + 1):
    for l in range(n - length + 1):
        r = l + length - 1
        min_val = min(a[l:r + 1])
        left_options = 1
        right_options = 1

        # compute left options
        for i in range(l, first[min_val]):
            left_options = left_options * (dp[i][first[min_val]-1] + 1) % MOD

        # compute right options
        for i in range(last[min_val] + 1, r + 1):
            right_options = right_options * (dp[last[min_val]+1][i] + 1) % MOD

        dp[l][r] = left_options * right_options % MOD

# accumulate results
s = [0] * (n + 1)
for l in range(n):
    for r in range(l, n):
        length = r - l + 1
        s[length] = (s[length] + dp[l][r]) % MOD

print(' '.join(map(str, s)))
```このソリューションは、最初と最後の出現配列を設定し、DP テーブルを初期化し、セグメントの長さにわたって反復します。 各セグメントについて、最小要素の左側と右側からの寄与を計算し、998244353 を法として乗算します。サブシーケンスのカウントは、密度によってインデックス付けされた最終応答配列に累積されます。
