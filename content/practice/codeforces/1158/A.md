 ## 解決策
 ## 問題の理解

 私たちは一緒にパーティーをします$n$男の子たちと$m$女の子たち。 各男の子はすべての女の子にいくつかのお菓子を与え、$n \times m$整数の行列。 各男の子について、女の子に与えるお菓子の最小数は次のように指定されます。$b_i$。 各女の子について、男の子から受け取るお菓子の最大数は次のように指定されます。$g_j$。 私たちの課題は、これらの制約をすべて満たし、同時に配られるお菓子の総数を最小限に抑える、妥当なお菓子の割り当てを再構築することです。 制約を満たすことが不可能な場合は、出力する必要があります。$-1$。 

入力サイズは大きく、最大$10^5$男の子にも女の子にも、各スイートのカウントは最大です。$10^8$。 これは、すべてを明示的に反復するソリューションはすべて、$n \cdot m$マトリックスのエントリはおそらく遅すぎるため、$10^5 \cdot 10^5 = 10^{10}$操作は法外なものになります。 ソリューションでは、マトリックス全体の走査を避けるために、賢い集計または並べ替えに依存する必要があります。 

微妙なエッジケースは、男子の最大の最小スイートが女子の最小の最大スイートを超える場合に発生します。 たとえば、次のように考えてみましょう$b = [5, 1]$そして$g = [4, 6]$。 最初の男の子は少なくとも与えなければなりません$5$誰かにお菓子をあげる、でも女の子はそれ以上のものを受け取ることはできない$4$誰からも。 この構成は不可能であり、実現可能性をチェックせずに貪欲にマトリックスを埋める単純なアプローチは何も言わずに失敗します。 

別の特殊なケースは、複数の男の子が女の子の最大の甘い値と同じ最小の甘い値を共有する場合に発生します。 分布では、女の子の最大値と一致するように、最大​​の最小値を適切な列に慎重に割り当てる必要があります。 

## アプローチ

 ブルートフォースアプローチでは、全体を構築しようとします。$n \times m$マトリックスを明示的に指定します。 を満たす値を割り当てます$b_i$各行と$g_j$各列ごとに。 貪欲な課題を試みることもできます。各男の子に対して、最小限の甘いものを埋めることから始めます。$b_i$すべての女の子を対象にして、女の子の最大値に一致するように特定のエントリを調整してみます。 このアプローチは原理的には正しいですが、$O(n \cdot m)$実行不可能な複雑さ$n, m$まで$10^5$。 

重要な洞察は、各男子にとっての最小のスイートが自分の行のどこかに表示され、各女の子にとっての最大のスイートがその列のどこかに表示される必要があるという観察から得られます。 合計を最小化するには、できるだけ多くのエントリに行の最小値を入力し、列の最大値を満たすように値のみを増やす必要があります。 仕分け$b$そして$g$これにより、男の子の最大最小値と女の子の最大最大値を揃えて、最小限の増分で制約を満たすことができます。 

具体的には、最大の男の子の最小値が最小の女の子の最大値と等しい場合、それをその女の子に割り当てる必要があります。 他の行の最小値はすべて、不必要に合計を増やすことなく他の女の子に割り当てることができます。 これにより、行列全体を反復処理するのではなく、問題が数回の算術演算に軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * m) | O(n * m) | 遅すぎる |
 | 最適 | O(n log n + m log m) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列をソートする$b$少年ミニマと$g$少女マキシマの。 させて$b_{\text{max}}$最小の男の子であること、そして$b_{\text{second}}$2番目に大きい。 させて$g_{\text{min}}$最大の小さな女の子であること。 
2. もし$b_{\text{max}} > g_{\text{min}}$、状況は不可能です、出力$-1$。 
3. 総和をすべての合計として初期化します。$b_i$乗算$m$、なぜなら、各男の子はすべての女の子に少なくとも最低限のものを与えるからです。 
4. それぞれの差を合計します。$g_j$そして$b_{\text{max}}$受け取る女の子を除くすべての女の子に$b_{\text{max}}$、なぜなら、各女の子はどこかで最大値に到達する必要があるからです。 
5. 最後に追加します$b_{\text{max}} - b_{\text{second}}$男子の最小値の最大値が女子の最大値の最大値よりも小さい場合は、合計に加算されます。 これは、合計を最小限に抑えながら最大の女の子の最大値に達するために必要な追加のお菓子を説明します。 

不変条件は、各男の子がすべての女の子に少なくとも自分の最小限の甘さを提供し、各女の子が自分の最大の甘さを正確に 1 回受け取るということです。 このアルゴリズムは、追加のスイーツを最小限に抑えながら、行または列の制約に違反しないことを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
b = list(map(int, input().split()))
g = list(map(int, input().split()))

b.sort()
g.sort()

if b[-1] > g[0]:
    print(-1)
    sys.exit()

total = 0
# sum of all minimal contributions
total += sum(b) * m

# add difference for each girl
for j in range(m):
    total += g[j] - b[-1]

# adjust for the largest boy if needed
if b[-1] < g[0]:
    total += b[-1] - b[-2]

print(total)
```最初のステップでは、配列を並べ替えて最大値と最小値を簡単に見つけ、実現可能性をチェックします。 行の最小値の合計に次の値を乗算します。$m$すべての最小限の貢献が確実にカウントされるようにします。 各女の子の最大値と最大の男の子の最小値の差によって調整することで、すべての列制約が確実に満たされます。 最終調整は、男子の最小値の最大値が女子の最大値の最大値よりも厳密に小さい場合を処理します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    b = list(map(int, input().split()))
    g = list(map(int, input().split()))

    b.sort()
    g.sort()

    if b[-1] > g[0]:
        return "-1"

    total = sum(b) * m
    for j in range(m):
        total += g[j] - b[-1]
    if b[-1] < g[0]:
        total += b[-1] - b[-2]
    return str(total)

# Provided samples
assert run("3 2\n1 2 1\n3 4\n") == "12", "sample 1"
assert run("2 2\n5 1\n4 6\n") == "-1", "sample 2"

# Custom tests
assert run("2 3\n1 1\n1 1 1\n") == "6", "all equal"
assert run("3 3\n0 0 0\n0 0 0\n") == "0", "all zeros"
assert run("3 2\n1 2 3\n3 3\n") == "15", "increasing minima"
assert run("2 2\n2 2\n3 3\n") == "10", "equal minima, higher maxima"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |

 |`3 2\n1 2 3\n3 3\n`| 15 | 最小値と最大値を増加させると、アルゴリズムが最大の最小値を最大の最大値に割り当てることが確認されます。 
|`2 2\n2 2\n3 3\n`| 10 | 最小値が等しい、最大値が大きい、合計最小化の調整をテストする |
