 ## 解決策
 ## 問題の理解

 整数の配列が与えられ、最初にその平均値 (総和を要素数で割ったもの) を計算します。 この平均は必ずしも整数である必要はありませんが、配列全体によって決定される固定の有理値です。 

タスクは、正確に 2 つの異なる要素を削除して、残りの要素の平均を再計算したときに元の平均とまったく同じになるようにすることです。 このプロパティを生成するインデックスのペアが何組あるかを数えるように求められます。 

重要な制約は配列サイズであり、最大 200,000 まで可能です。 すべてのペアを直接チェックするソリューションでは、次の点を考慮する必要があります。$\frac{n(n-1)}{2}$これは、最悪の場合でも約 200 億回の操作に相当します。 これは、Python や C++ で 2 秒に収まる時間をはるかに超えています。 これにより、二次関数のアプローチは即座に除外されます。 

すべての要素が同一である場合、微妙なエッジケースが存在します。 この場合、すべてのサブセットの平均値が同じになるため、任意の 2 つの要素を削除すると平均値が維持されます。 単純な実装では、平均を浮動小数点数として直接再計算しようとすると、不必要な算術演算が発生したり、精度の問題が発生したりする可能性があります。 

もう 1 つの重要なケースは、平均が整数ではない場合です。 不注意な解決策では、削除後に浮動小数点平均を比較しようとする可能性があります。 代数条件が正確に成立する場合でも、精度エラーにより不正確な等価性チェックが行われる可能性があるため、これは安全ではありません。 

## アプローチ

 ブルートフォースソリューションでは、すべてのペアに対して反復処理が行われます。$(i, j)$、これら 2 つの要素を削除し、残りの配列の合計を再計算し、平均が元の値と一致するかどうかを確認します。 残りの合計の計算は、プレフィックス合計を使用して O(1) に最適化できますが、テストするペアはまだ O(n^2) 個あり、約$10^{10}$最悪の場合のチェック。 チェックごとに定数演算を行ったとしても、これでは遅すぎます。 

重要な観察は、条件を代数的に書き直すことから得られます。 配列の総和を次のようにします。$S$、元の意味を次のようにします$k = S / n$。 2つの要素を削除した後$a_i$そして$a_j$、新しい合計は次のようになります$S - a_i - a_j$、新しい要素の数は$n - 2$。 私たちは次のことを要求します:$$\frac{S - a_i - a_j}{n - 2} = \frac{S}{n}$$交差乗算では分数が完全に回避され、ペアに対する線形制約が明らかになります。 これにより、問題は平均のチェックから、固定合計条件を使用したペアのカウントに変わります。 単純化した後、有効な各ペアは次の条件を満たす必要があります。$$a_i + a_j = \frac{2S}{n}$$したがって、タスク全体は、合計が一定の目標値になるペアの数をカウントすることに帰着します。 これは古典的な頻度計数問題であり、ハッシュ マップを使用すると線形時間で解くことができます。 

各値の頻度を計算し、個別の値ごとに$x$、その補数を探します$T - x$、 どこ$T = 2S / n$。 二重カウントを回避し、次のような場合に対処するように注意する必要があります。$x = T - x$。

 ## アルゴリズムのチュートリアル

 1. 合計を計算する$S$配列の値を計算し、目標の合計を導き出します$T = 2S / n$。 この値は、平均条件の代数変換後にすべての有効なペアの合計が何になるかを表します。 
2. もし$2S$で割り切れない$n$、すぐに停止し、0 を返します。この場合、ターゲットの合計は整数ではありませんが、すべての配列要素が整数であるため、条件を正確に満たすペアはありません。 
3. すべての配列値の頻度マップを作成します。 これにより、有効なペアを効率的にカウントするために必要な、各候補要素が出現する回数をカウントできるようになります。 
4. それぞれの個別の値を反復処理します。$x$周波数マップで。 このような値ごとに、その補数を計算します。$y = T - x$。 
5. もし$x < y$、 の出現を 1 つ選択することによって形成されたすべてのペアを数えます。$x$そして1回の発生$y$。 そのようなペアの数は$freq[x] \cdot freq[y]$。 順序付けの制約により、二重カウントが回避されます。 
6. もし$x = y$、同じ値グループ内で完全に形成されたペアをカウントします。 そのようなペアの数は$freq[x] \cdot (freq[x] - 1) / 2$。 
7. すべての寄与を合計し、結果を出力します。 

### なぜ効果があるのか

 平均制約から固定合計制約への変換は正確であり、元に戻すことができます。 すべての有効な削除は平均を保持する必要があり、代数は、これが削除されたペアの合計が正確であることを要求することと同等であることを示しています。$T = 2S/n$。 頻度ベースのカウントでは、個別の補数を通じて、または単一の値クラス内で、順序付けされていない各ペアが 1 回だけ列挙されます。 インデックスのすべてのペアが頻度マップ内の 1 つの値の組み合わせで表されるため、有効なペアが失われることはありません。また、カウントされたすべてのペアが導出された等式を満たすため、無効なペアは含まれません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    s = sum(a)
    if (2 * s) % n != 0:
        print(0)
        return
    
    target = (2 * s) // n
    
    freq = {}
    for x in a:
        freq[x] = freq.get(x, 0) + 1
    
    ans = 0
    for x in freq:
        y = target - x
        if y not in freq:
            continue
        if x < y:
            ans += freq[x] * freq[y]
        elif x == y:
            c = freq[x]
            ans += c * (c - 1) // 2
    
    print(ans)

if __name__ == "__main__":
    solve()
```解決策は、合計を計算し、割り算をチェックして、導出されたターゲット ペアの合計が整数であることを確認することから始まります。 これにより、浮動小数点比較が完全に回避されます。 頻度辞書は各値の出現を追跡するため、ペアのカウントは反復的ではなく組み合わせになります。 

ループオーバーキーは、次を使用して順序付けを慎重に強制します。`x < y`これにより、(x, y) と (y, x) のようなペアを二重にカウントするのを防ぎます。 等しい場合は、同じ値のグループから 2 つのインデックスを選択するための標準の組み合わせ式を使用します。

 ## 特殊なケース

 すべて等しい場合については、次のようにします。$n = 6$そして配列は`[5, 5, 5, 5, 5, 5]`。 合計は 30 なので、ターゲット ペアの合計は 10 になります。5 のすべてのペアが有効です。 アルゴリズムが周波数を構築します`freq[5] = 6`そして、大文字と小文字が等しい分岐に入ります。 計算します$6 \cdot 5 / 2 = 15$, これは、任意の 2 つのポジションを選択する方法の数に一致します。 

整数ターゲットが存在しない場合、たとえば、`[1, 2, 3]`、合計は 6 なので、$2S/n = 4$。 これは有効ですが、合計が 4 になるペアはありません。周波数マップはペアをチェックしますが、ペアが見つからず、結果は 0 になります。代わりに、合計が分数ターゲットを生成した場合、ペアをスキャンする必要がなく、初期の割り算チェックで正しく 0 が返されたでしょう。 

次のような混合配列の場合`[1, 4, 7, 3, 5]`、アルゴリズムは厳密に補体構造によって値をペアにします。 順序付けの制約により、有効な各ペアは 1 回だけ出現し、すべての有効な削除をキャプチャしながら過剰カウントを防止します。
