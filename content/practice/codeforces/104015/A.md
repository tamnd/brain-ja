 ## 問題の理解

 私たちには決まった数のキャンディーが与えられ、学校は生徒を男子と女子の 2 つのグループに分けます。 校長は、各男の子に対して正の整数の量のキャンディーを選択し、各女の子に対して異なる正の整数の量を選択する必要があります。 すべての男の子はまったく同じ数のキャンディーを受け取り、すべての女の子もまったく同じ数のキャンディーを受け取りますが、女の子 1 人あたりの量は男の子 1 人あたりの量よりも厳密に大きくなければなりません。 

したがって、配布されるキャンディーの合計は 2 つの整数によって完全に決定されます。$x$男の子用と$y$制約のある女の子の場合$x \ge 1$、$y \ge 1$、 そして$x < y$。 使用した総額は、$a \cdot x + b \cdot y$。 そんなものを選びたい$x, y$配布されるキャンディーの数を上限を超えないように最大化する$n$。 出力は未使用のキャンディーの数です。$n - \max(a x + b y)$。 

制約は小さいです。$n \le 1000$、$a, b \le 100$。 これは、小さな二次探索やさらには三次探索を超えるものを即座に除外しますが、さらに強力な特性、つまり最適な探索空間を示唆しています。$x, y$正しく構造化されていれば総当たり攻撃が可能なほど小さいです。 

重要なエッジケースは、制約が$x < y$きつくなります。 たとえば、次の場合$x = y$の場合、キャンディーを多く使用しても無効な構成になります。 もう 1 つの微妙な点は、少なくとも次の期間については実現可能性が保証されていることです。$x = 1$そして$y = 2$したがって、常に少なくとも 1 つの有効な割り当てが存在します。

 ## アルゴリズムのチュートリアル

 ## アルゴリズムのチュートリアル

2. 固定の場合$x$、男の子にキャンディーを与えた後の残りの予算を計算します。$rem = n - a \cdot x$。 もし$rem \le 0$そうすると、女の子以上のキャンディーは残りません。$x$悪化するだけなので、早めにやめましょう。 
3. 残りのキャンディーを考慮して、可能な限り最大のキャンディーが必要です$y$そのような$b \cdot y \le rem$そして$y > x$。 最有力候補は$y = \left\lfloor \frac{rem}{b} \right\rfloor$ただし、厳密な不等式制約を満たしている必要があります。 
4. If$\left\lfloor \frac{rem}{b} \right\rfloor \le x$、それからこれ$x$有効な割り当ては生成できません。$y$厳密に次より大きくなければなりません$x$。 このケースは省略します。 
5. それ以外の場合は、$y = \left\lfloor \frac{rem}{b} \right\rfloor$使用したキャンディーの合計を計算します$used = a \cdot x + b \cdot y$。 の最大値を追跡します。$used$全体的に有効$x$。 
6. すべてを繰り返した後$x$、答えは$n - \max(used)$。 

### なぜ効果があるのか

 固定の場合$x$、女子の貢献度が単調$y$したがって、最良の選択は常に実現可能な最大値にあります。$y$。 唯一の非単調制約は次のとおりです。$y > x$、ごとに 1 つのしきい値を作成します。$x$。 この順序付け条件を除いて、両方の制約が線形で独立しているため、最適解はこれらの境界点のいずれかに存在する必要があります。 これにより、すべてを列挙することが保証されます。$x$そして貪欲に最大化する$y$それぞれに$x$最適値が得られるすべての候補を探索します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, a, b = map(int, input().split())

    best = 0

    for x in range(1, n + 1):
        rem = n - a * x
        if rem <= 0:
            break

        y = rem // b
        if y <= x:
            continue

        used = a * x + b * y
        if used > best:
            best = used

    print(n - best)

if __name__ == "__main__":
    solve()
```このコードは、最初に男子の割り当てを修正し、次に女子の割り当てをできるだけ高くするというアイデアを直接実装しています。 男子だけが予算を超えるとループが早期に停止するため、不必要な繰り返しが防止されます。 整数の除算`rem // b`内部検索を変換する重要なステップです$y$一定の時間に。 条件`y <= x`厳密な不等式制約が適用されますが、数学を機械的に変換しすぎると見落とされがちです。
