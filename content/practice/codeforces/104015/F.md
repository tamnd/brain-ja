 ## アルゴリズムのチュートリアル

 すべての数値を正規表現に変換し、同じパワーチェーンに属する値をグループ化します。 

1. 数字ごとに$a_i$、その最小ルートベースを計算します$b_i$。 これは最小の整数を見つけることを意味します$b$そのような$a_i = b^k$ある整数に対して$k \ge 1$。 このステップにより、すべての完全電力が同じ基礎となるジェネレーターに対して正規化されることが保証されます。 
2. 数値がより小さい整数の完全累乗でない場合、その基数はそれ自体であるため、長さ 1 の自明なチェーンが形成されます。これは、完全累乗ではない素数および一般的な合成数を処理します。 
3. ベースからマップを維持する$b$すべての元の値の合計$a_i$そのチェーンに属しているもの。 それぞれの有効な山がそのフルサイズに寄与するため、単なるカウントではなく実際のココナッツを累積します。 
4. すべての値を繰り返し処理し、このマップを更新します。 最小ルート表現は一意であるため、各数値は正確に 1 つのチェーンに寄与します。 
5. すべての値を処理した後、答えはすべてのチェーン合計の最大値になります。 これは最適なベースを選択することに相当します$x$、各グループは形式のすべての値を表すため、$x^k$。 

なぜ機能するのか: すべての有効な選択は何らかのベースに対応します$x$。 含まれる数値は正確にべき乗でなければなりません$x$したがって、その最小ルートも等しくなければなりません$x$。 したがって、選択されたすべての数値は、この正規の基本マッピングの下で​​ 1 つのグループにまとめられます。 すべての数値が正確に 1 つの塩基にマッピングされるため、有効なグループ化を見逃すことはなく、グループの最大化によりすべての選択肢がカバーされます。$x$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def get_base(x):
    # find minimal base b such that x = b^k
    # try all powers up to log2(x)
    best = x
    # try exponent from 2 upward
    for k in range(2, 32):
        b = int(round(x ** (1.0 / k)))
        if b <= 1:
            continue
        # verify exact power
        p = 1
        for _ in range(k):
            p *= b
            if p > x:
                break
        if p == x:
            best = min(best, b)
    return best

n = int(input())
a = list(map(int, input().split()))

from collections import defaultdict
mp = defaultdict(int)

for v in a:
    b = get_base(v)
    mp[b] += v

print(max(mp.values()))
```機能`get_base`累乗を繰り返すと指定された数値が得られる最小の整数基数を計算します。 値は 10^9 で制限されるため、可能な指数を最大 30 まで反復します。そのため、意味のあるべき乗分解は指数が小さくなければなりません。 

候補となる各指数について、整数根抽出を使用して基数を近似し、浮動小数点精度エラーを回避するために直接乗算によって検証します。 塩基が特定されたら、元の値をそのグループに蓄積します。 

辞書`mp`拠点ごとのココナッツの合計を収集し、最終的な答えは最大合計になります。
