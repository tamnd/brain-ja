 ## 解決策
 ## 問題の理解

 それぞれの人は北岸の位置に住み、南岸の位置で働いています。 歩いて行けるのは岸辺に沿ってのみですが、川を渡るには通常ボートが必要です。`B`時間単位。 どこかの場所に一本の橋を架けるかもしれない`L`そして、その橋を渡るのにちょうどかかります`1`時間単位。 人は、橋のルートが最大でも次の場合に橋を選択します。`T`最適なボートルートよりも時間単位が遅い。 ブリッジの位置を選択し、最小の許容値を見つけたいと考えています。`T`少なくともそうなるように`M`人々は橋を使います。 

制約こそが本当の課題なのです。 まであります`10^5`人、ポジションとボートの時間は同じくらい大きくなる可能性があります`10^9`。 すべてのブリッジ位置を試すソリューションは不可能です。`10^9`候補地。 周りに何かが必要です`O(N log N)`。 

微妙な点は、最適なボートのルートは必ずしも自宅の位置や職場の位置を直接通過するわけではないことです。 最初は歩いてからボートに乗る人もいるかもしれません。 この観察を怠ると、移動時間が不正確になる可能性があります。 

ある人を考えてみましょう`H = 2`、`W = 8`、`B = 5`。 

最適なボートルートは次のとおりです。```
walk from 2 to any position between 2 and 8
cross by boat
walk to 8
```その費用は`|2 - 8| + 5 = 11`、 ない`5`。 

もう 1 つの簡単な間違いは、ブリッジの位置が整数でなければならないことを忘れることです。 不等式に 2 による除算が含まれる場合、丸めは慎重に処理する必要があります。 

例えば：```
H = 4, W = 4, B = 1
```もし`T = 0`、その場所に正確に建設された橋のみ`4`許容されます。 位置を連続したものとして扱うと、近くの位置が誤って許可されてしまいます。 

## アプローチ

 ブルートフォースアプローチでは、すべての橋の位置を試すことになる`L`から`0`に`K - 1`。 場所ごとに、何人が橋を使用するかを計算し、必要な許容値を決定できます。 たとえ 1 つの場所の評価に時間がかかったとしても`O(N)`、全体の複雑さは次のようになります。`O(NK)`、それは絶望的なときです`K`到達できる`10^9`。 

重要な観察は、橋を使用する追加コストを表現することから得られます。 

させて```
l = min(H, W)
r = max(H, W)
```ボートの最適な移動時間は、```
|H - W| + B
```なぜなら、間のどこかを横切るからです。`H`そして`W`歩く距離を最小限に抑えます。 

橋がその位置にある場合`L`、橋の移動時間は```
|H - L| + 1 + |W - L|
```追加費用となるのは、```
|H - L| + |W - L| - |H - W| + (1 - B)
```最初の 3 つの用語には、有益な幾何学的意味があります。```
|H - L| + |W - L| - |H - W|
= 2 * distance(L, [l, r])
```どこ`distance(L, [l, r])`からの距離です`L`間隔まで`[l, r]`。 

したがって、人は橋を使用します。```
2 * distance(L, [l, r]) + (1 - B) <= T
```再配置:```
distance(L, [l, r]) <= (T + B - 1) / 2
```させて```
D = floor((T + B - 1) / 2)
```距離は整数なので、条件は次のようになります。```
distance(L, [l, r]) <= D
```つまり、この人は内部のすべての橋の位置を受け入れます```
[l - D, r + D]
```にクリッピングした後、`[0, K - 1]`。 

固定の場合`D`、すべての人が許容可能な橋の位置の 1 つの間隔を提供します。 少なくともある場所がカバーされているかどうかを知る必要があるだけです。`M`間隔。 

これは標準的な最大オーバーラップの問題です。 差分イベントでスイープ ラインを使用すると、`O(N log N)`チェック。 

オーバーラップ数は単調です`D`, したがって、最小のものを二分探索できます`D`それは少なくとも可能にする`M`人々。 それを手に入れた後、`D`、最小許容誤差に変換し直します。`T`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(NK) | お(1) | 遅すぎる |
 | 最適 | O(N log N log K) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての人について、間隔を計算します。```
[l, r] = [min(H, W), max(H, W)]
```2. 最小の整数を二分探索する`D`少なくともカバーされる橋の位置が存在するように`M`間隔が広がった。 
3. 修正チェック中`D`、すべての間隔を次のように展開します```
[max(0, l - D), min(K - 1, r + D)]
```これらはまさにその人にとって受け入れられる橋の位置です。 
4. 間隔をスイープ イベントに変換します。```
+1 at left endpoint
-1 at right endpoint + 1
```5. すべてのイベント位置を並べ替え、現在のオーバーラップ数を維持しながら左から右にスキャンします。 
6. オーバーラップが少なくとも`M`、 これ`D`実現可能です。 
7. 二分探索により実行可能な最小値が見つかった後`D`、最小許容値を回復します。 

必要です```
floor((T + B - 1) / 2) >= D
```これを満たす最小の非負の整数は次のとおりです。```
T = max(0, 2 * D - (B - 1))
```### なぜ効果があるのか

 固定の人にとって、その量は```
|H - L| + |W - L| - |H - W|
```～からの距離のちょうど 2 倍です`L`自宅と職場の隙間に。 その間隔を拡張すると、`D`両側で、許容条件を満たす一連のブリッジ位置が正確に生成されます。 

橋の位置は、それが少なくとも以下のものに属している場合にのみ実現可能です。`M`これらの拡張された間隔の。 スイープ ラインは、任意の位置をカバーする間隔の最大数を計算するため、特定の場所の実現可能性を正確に判断します。`D`。 

増えるから`D`間隔を拡大するだけであり、実現可能性は単調です。 したがって、二分探索は実行可能な最小値を見つけます`D`。 最終的な式はその最小値を変換します`D`最小公差に戻る`T`、したがって、答えは最適です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k, b = map(int, input().split())

    segs = []
    for _ in range(n):
        h, w = map(int, input().split())
        l = min(h, w)
        r = max(h, w)
        segs.append((l, r))

    def feasible(d):
        events = []

        for l, r in segs:
            left = max(0, l - d)
            right = min(k - 1, r + d)

            events.append((left, 1))
            events.append((right + 1, -1))

        events.sort()

        cur = 0
        i = 0
        while i < len(events):
            pos = events[i][0]

            delta = 0
            while i < len(events) and events[i][0] == pos:
                delta += events[i][1]
                i += 1

            cur += delta
            if cur >= m:
                return True

        return False

    lo = 0
    hi = k

    while lo < hi:
        mid = (lo + hi) // 2
        if feasible(mid):
            hi = mid
        else:
            lo = mid + 1

    d = lo
    t = max(0, 2 * d - (b - 1))
    print(t)

solve()
```最初の部分には、各人の自宅と職場の間の間隔のみが保存されます。 後で必要なのはこの間隔だけです。 

実現可能性チェックでは、各間隔を次のように拡張します。`D`、有効なブリッジ範囲にクリップし、スイープ ラインを実行します。 使用する`right + 1`削除イベントは、包括的な間隔の標準的なトリックだからです。 

二分探索が実行されるのは、`D`、直接ではありません`T`。 オーバーラップ構造は次のもののみに依存します。`D`、これによりチェックがよりきれいになります。 

すべての算術演算では Python 整数が使用されるため、最大値は`10^9`以降は安全に取り扱われます。 

## 実用的な例

 ### 例 1

 入力:```
5 3 10 1
1 2
7 4
4 3
9 9
0 0
```のために`D = 1`:

 | 人物 | 元の間隔 | 拡張された間隔 |
 | --- | --- | --- |
 | 1 | [1、2] | [0, 3] |
 | 2 | [4、7] | [3、8] |
 | 3 | [3、4] | [2、5] |
 | 4 | [9、9] | [8、9] |
 | 5 | [0, 0] | [0, 1] |

 現場で`L = 3`、最初の 3 つの間隔は重なっています。 

| 場所 | 取材範囲 |
 | --- | --- |
 | 3 | 3 |

 それで`D = 1`実現可能です。 

答えは```
T = max(0, 2 * 1 - (1 - 1))
  = 2
```### 例 2

 入力:```
2 2 8 1
1 1
6 6
```のために`D = 2`:

 | 人物 | 拡張された間隔 |
 | --- | --- |
 | 1 | [0, 3] |
 | 2 | [4、7] |

 重複は存在しません。 

のために`D = 3`:

 | 人物 | 拡張された間隔 |
 | --- | --- |
 | 1 | [0, 4] |
 | 2 | [3、7] |

 所在地`3`そして`4`両方の間隔でカバーされるため、`D = 3`実現可能です。 

それから```
T = 2 * 3 = 6
```これはサンプル出力と一致します。

 ## 特殊なケース

 次のことを考慮してください。```
1 1 5 10
2 2
```現場の橋`2`時間がかかる`1`、ボートでは時間がかかりますが、`10`。 ブリッジはすでに良くなっているので、許容範囲`0`十分です。 アルゴリズムは次のことを見つけます`D = 0`、次に計算します```
T = max(0, -(B - 1)) = 0
```それは正しいです。 

次に、次のことを考えてみましょう。```
2 2 8 1
1 1
6 6
```元の間隔はバラバラです。 アルゴリズムは、二分探索中に両方の間隔を拡張します。 最初の実現可能な値は`D = 3`, ここで、拡張された区間は次のようになります。`[0,4]`そして`[3,7]`。 これらは重なっているため、1 つの橋の位置で両方の人が満足できます。 結果の許容誤差は次のようになります。```
T = 2 * 3 = 6
```予想される答えと一致します。 

最後に、丸めの影響を受けるケースを考えてみましょう。```
1 1 10 1
4 4
```のために`T = 0`、私たちは得ます```
D = floor((0 + 1 - 1)/2) = 0
```したがって、許容可能なブリッジ間隔は残ります`[4,4]`。 場所のみ`4`要求どおりに機能します。 整数の定式化により、半整数距離によって引き起こされる間違いが回避されます。
