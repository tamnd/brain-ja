 ## 解決策
 ## 問題の理解

 与えられた会社名が垂直鏡に対して対称であるかどうかを判断するように求められます。 実際には、大文字の英字で構成される単一の文字列が与えられ、その文字列が左右の軸に沿って垂直に置かれた鏡に反射された場合に同一に見えるかどうかを確認する必要があります。 このように特定の文字のみが対称になります。たとえば、`A`、`H`、`I`、`M`、`O`、`T`、`U`、`V`、`W`、`X`、`Y`。 のような文字`B`または`C`ミラーリングすると見た目が異なるため、有効な名前で表示できません。 

入力制約では、文字列の長さは最大 100,000 文字まで許可されます。 1 秒の時間制限では、アルゴリズムは最悪でも線形時間 O(n) で実行する必要があることを意味します。 二次関数や文字列のネストされた反復を伴うものはどれも遅すぎます。 メモリは 256 MB と豊富なので、有効な文字の小さなセットや長さ n のブール配列を保存するのは簡単です。 

注意すべき主なエッジケースは空または単一文字の文字列ですが、この問題では空でない入力が保証されます。 有効な 1 文字 (例:`A`) が返されるはずです`YES`。 単一の無効な文字を含む文字列 (例:`B`) が返されるはずです`NO`。 もう 1 つの微妙なシナリオは、すべて有効な文字を含むが非対称に配置された文字列です。`AHAH`はその逆なので無効です`HAHA`異なります。 

## アプローチ

 素朴なアプローチは簡単です。文字列を反転し、すべての文字がミラーリングされているか、許可されたセットに含まれているかどうかを確認します。 これが機能するのは、ミラーリングが各文字自体の対称性を確保しながら文字列を逆方向に読み取ることと同等であるためです。 ただし、単純な実装では、誤ってすべての文字をミラーリングされたバージョンにマップしようとする可能性がありますが、特定のサブセットのみが有効であるため、大文字の場合は不要です。 これにより冗長な操作が発生する可能性がありますが、それでも O(n) になります。 

重要な洞察は、問題が 2 つのチェックに集約されるということです。まず、すべての文字が垂直方向に対称な文字のセットに属している必要があります。 次に、文字列は前後から同じように読まれなければなりません。 これらのチェックを 1 回のパスで組み合わせることで、一定サイズの小さな文字セットを超える追加メモリを使用せずに、O(n) 時間で問題を効率的に解決できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース: リバース + ミラーチェック | O(n) | O(n) | 承認済み |
 | 最適: 許可されたセットと対称性に対するシングルパス チェック | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 垂直ミラーに対して対称であるすべての文字を含むセットを作成します。`A, H, I, M, O, T, U, V, W, X, Y`。 これにより、各キャラクターのメンバーシップを定期的にチェックできるようになります。 
2. 2 つのポインタを初期化します。1 つは文字列の先頭に、もう 1 つは文字列の末尾にあります。 真ん中に向かって繰り返していきます。 
3. 各ステップで、開始ポインタと終了ポインタの両方の文字が許可セット内にあるかどうかを確認します。 どちらかの文字が無効な場合は、印刷します`NO`そして終了します。 これにより、単一の禁止文字が文字列全体を無効にするケースが即座に処理されます。 
4. 開始ポインタと終了ポインタの文字が等しいかどうかを確認します。 そうでない場合は、印刷してください`NO`そして終了します。 これにより、文字列が前方と後方で同じように読み取られることが保証されます。 
5. 開始ポインタを 1 ステップ前進させ、終了ポインタを 1 ステップ後退させ、ポインタが出会うか交差するまでステップ 3 と 4 を繰り返します。 
6. ループが終了せずに完了した場合は、次のように出力します。`YES`。 文字列は対称性と文字の有効性の両方を満たしています。 

機能する理由: 不変条件は、反復ごとに、現在のポインターの外側にあるすべての文字の対称性と正しい配置が検証されていることです。 アルゴリズムはすべてのペアを 1 回だけチェックします。 有効な文字のみが許可され、各ペアが一致するため、最終的な文字列はその鏡面反射と同一であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s = input().strip()
valid_letters = {'A', 'H', 'I', 'M', 'O', 'T', 'U', 'V', 'W', 'X', 'Y'}

left, right = 0, len(s) - 1
while left <= right:
    if s[left] not in valid_letters or s[right] not in valid_letters:
        print("NO")
        sys.exit()
    if s[left] != s[right]:
        print("NO")
        sys.exit()
    left += 1
    right -= 1

print("YES")
```コードはまず入力文字列を読み取り、末尾の改行文字を削除します。 有効なミラーレターのセットにより、メンバーシップを迅速にテストできます。 次に、2 ポインター手法を使用して外側から内側への対称性をチェックします。失敗した場合はすぐに終了することで、不必要な作業を回避できます。 これにより、アルゴリズムが O(n) 時間で実行され、O(1) 個の追加スペースのみが使用されることが保証されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    s = input().strip()
    valid_letters = {'A', 'H', 'I', 'M', 'O', 'T', 'U', 'V', 'W', 'X', 'Y'}
    left, right = 0, len(s) - 1
    while left <= right:
        if s[left] not in valid_letters or s[right] not in valid_letters:
            return "NO"
        if s[left] != s[right]:
            return "NO"
        left += 1
        right -= 1
    return "YES"

# Provided sample
assert run("AHA\n") == "YES", "sample 1"

# Custom cases
assert run("ABBA\n") == "NO", "invalid letters"
assert run("AAA\n") == "YES", "all valid, odd length"
assert run("AHHHA\n") == "YES", "odd length palindrome"
assert run("XYX\n") == "YES", "symmetric X/Y letters"
assert run("XYZ\n") == "NO", "contains invalid Z"
assert run("A\n") == "YES", "single valid letter"
assert run("B\n") == "NO", "single invalid letter"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | アバ | いいえ | 真ん中に無効な文字があります |
 | AAA | はい | 有効な文字の繰り返し、奇数の長さ |
 | ああ | はい | 有効な文字を含む奇数長の回文 |
 | XYZ | いいえ | 無効な文字の存在 |
 | あ | はい | 単一の有効な文字 |
 | B | いいえ | 単一の無効な文字 |

 ## 特殊なケース

 単一の文字の場合`A`、ポインタ`left`そして`right`両方ともインデックス 0 を指します。ループは 1 回実行され、`A`有効なセット内で、かつ`s[left] == s[right]`、終了して戻ります`YES`。 単一の無効な文字の場合`B`、同じループがすぐにそれを検出します`B`有効なセットに含まれていないため、返されます`NO`。 最大長の文字列とすべての有効な文字は、小規模なセットを超える追加メモリなしで O(n) 時間で処理され、制約全体にわたる堅牢性が確認されます。
