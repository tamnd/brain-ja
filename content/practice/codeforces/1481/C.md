 ## 解決策
 ## 問題の理解

 私たちに与えられたフェンスは、`n`それぞれの板は最初は次の色で塗装されていました。`a_1`に`a_n`。 私たちの目標は、最終的なカラー構成がターゲット配列と一致するようにフェンスを再ペイントすることです。`b_1`に`b_n`。 我々は持っています`m`画家は順番に到着し、それぞれが 1 枚の板を特定の色でペイントすることができます。`c_j`。 塗装業者を断ることはできませんが、塗装する板を選ぶことはできます。 課題は、希望の色を実現できるかどうかを判断し、実現できる場合は、指定された順序で各画家に板を割り当てることです。 

制約により許可されるのは、`n`そして`m`まで`10^5`テスト ケースごとに、すべてのテスト ケースの合計も次の制限を受けます。`10^5`。 これは、テスト ケースごとにほぼ直線的な時間で実行されるソリューションが必要であることを示しています。 各ペインターに対して考えられるすべてのプランクの割り当てをチェックする総当り的なアプローチでは、潜在的に必要となる可能性があるため、非常に時間がかかりすぎます。`O(n^m)`操作。 

明らかではないエッジ ケースには、最後のペインターの色が再ペイントが必要な板と一致しない場合、または複数のペインターが同じ板をペイントできるが、必要な変更をすべてカバーする必要がある場合が含まれます。 たとえば、すべての板がすでに目的の色であるにもかかわらず、最後のペインタが現在どの板にも必要としない色を持っている場合、単純なアプローチでは有効な板を割り当てることができない可能性があります。 

たとえば、次の場合`a = [1, 1]`、`b = [1, 2]`、 そして`c = [2]`、目標を達成する唯一の方法は、1 人の塗装職人が 2 番目の板を塗装することです。 最初の板の選択を間違えると失敗します。 

## アプローチ

 強引なアプローチでは、各ペインターに対して考えられるすべての板の割り当てが考慮されます。 各ペインターについて、その色と一致するすべての板をペイントしてみて、次のペインターを再帰的にチェックすることができます。 これはあらゆる可能性を検討するので正しいですが、大規模な場合には対処が困難です。`n`そして`m`。 適度なサイズの場合でも、`n = m = 10^5`、これには天文学的な操作が必要になります。 

重要な洞察は、板がどこにあるのかを観察することによって得られます。`a_i != b_i`再塗装する必要があります。 各色からその色を必要とする板のリストへのマッピングを維持できます。 特定の色を持って到着する画家`c_j`理想的には、必要な残りの板の 1 つを塗装する必要があります。`c_j`。 そのような板が存在しない場合は、すでに色が付いている板をペイントできます`c_j`ペインターが使用されていることを確認します。 有効な板を選択しないと制約を満たすことができないため、最後の画家の板は非常に重要です。 

これは、その色をまだ必要とする板のリストに色をマッピングする辞書を使用して効率的に実装できます。 ペインタを順番に繰り返し、このマッピングに基づいてプランクを割り当て、必要に応じて最後のペインタを特別に処理します。 これにより、問題は組み合わせ爆発から線形時間処理に軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^m) | O(n) | 遅すぎる |
 | 最適 | O(n + m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、その色をまだ必要とする板のインデックスに色をマッピングする辞書を作成します (`a_i != b_i`）。 これにより、特定の画家がどの板を塗装できるかをすぐに見つけることができます。 
2. 最後の画家の色を特定する`c_m`。 ターゲットに少なくとも 1 つの板があるかどうかを確認します`b`この色で。 そうでない場合は、最後の塗装者がこの色の板を塗装する必要があるため、すぐに「NO」を出力します。 
3. 最初から最後から 2 番目までの画家について、自分の色を必要とする板がある場合は、それを割り当てて辞書から削除します。 色を必要とする板がない場合は、最後の画家の色の板を割り当てます。 これにより、最後の画家に有効な板を残しながら、すべての画家が何かを描くことが保証されます。 
4. 最後のペインターをその色の板に割り当てます。 ステップ 3 までに、そのような板が少なくとも 1 つあることを確認しました。 
5. すべての塗装担当者が割り当てられた後、まだ再塗装が必要な板があるかどうかを確認します。 その場合は「NO」を出力します。 それ以外の場合は、「YES」とプランク インデックスのリストを出力します。 

これが機能する理由: 不変条件は、各ペインターがまだ自分の色を必要とする板、または安全なフォールバック (最後のペインターの色で板) をペイントすることです。 最後のペインターは、その存在を確認したため、有効な板が保証されています。 必要な再描画はすべてカバーされており、正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        c = list(map(int, input().split()))
        
        need = {}
        for i in range(n):
            if a[i] != b[i]:
                need.setdefault(b[i], []).append(i)
        
        last_color = c[-1]
        if last_color in need:
            last_plank = need[last_color][-1]
        else:
            found = -1
            for i in range(n):
                if b[i] == last_color:
                    found = i
                    break
            if found == -1:
                print("NO")
                continue
            last_plank = found
        
        res = [0] * m
        res[-1] = last_plank
        for j in range(m-1):
            color = c[j]
            if color in need and need[color]:
                res[j] = need[color].pop()
            else:
                res[j] = last_plank
        
        impossible = any(need[color] for color in need)
        if impossible:
            print("NO")
        else:
            print("YES")
            print(' '.join(str(x+1) for x in res))

if __name__ == "__main__":
    solve()
```解決策は、テスト ケースの数を読み取ることから始まります。 テスト ケースごとに、再描画が必要な板への色のマッピングを作成します。 最後のペインターの色は少なくとも 1 つの板に表示される必要があるため、最初に最後のペインターを処理します。 残りのペインターには、自分の色が必要な板か代替の板のいずれかが貪欲に割り当てられます。 最終チェックでは、必要な再描画が割り当てられていないことが確認されます。 インデックスは出力用に 1 ベースに変換されます。
