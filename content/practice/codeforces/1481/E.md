 ## 解決策
 ## 問題の理解

 本が並んでいます。 それぞれの本には色があります。 任意の本を繰り返し選択し、行の最後に移動することがあります。 

目標は、最終的な配置をカラー ブロックで構成することです。つまり、すべての色が 1 つの連続したセグメントに表示されることになります。 異なる色は任意の順序で表示できますが、同じ色の本が隣接する必要があります。 

最小限の書籍を移動する必要があります。 

操作が異常です。 決して真ん中に本を挿入することはありません。 移動された本はすべて右端に移動します。 そのため、一部の本は元の相対的な順序を永久に維持しますが、移動された本は最後に収集されます。 

入力サイズが到達しました$5 \cdot 10^5$。 考えられるすべての最終的な色の順序、移動された本のすべてのサブセットを試したり、二次スキャンを実行したりするアルゴリズムは、直ちに不可能になります。 平$O(n \sqrt n)$この規模では不快だろう。 線形に近いものが必要です。$O(n \log n)$。 

難しいのは、その場に残された本がどのようなものかを理解することです。 単純な考えとしては、既に美しいサブシーケンスの最大のものを保持するというものがありますが、この操作は恣意的な削除よりもはるかに制限的です。 本を最後まで動かすことでできた構造を尊重しなければなりません。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

考慮する：```
1 2 1
```答えは 1. 中央の本を移動します。```
1 1 2
```各色が元の配列内ですでに連続しているかどうかだけをチェックするソリューションでは、2 冊の本が移動する必要があると誤って結論付けられてしまいます。 

別の微妙なケースは次のとおりです。```
1 2 2 1
```答えは 1. 最後に移動します`1`:```
1 2 2 1
→
1 2 2 1   (remove last 1)
→
1 2 2 1   (append to end, same position)
```より自然に、最初に移動します`1`:```
2 2 1 1
```重要な点は、色は必ずしもそのすべての出現を静止部分に保存する必要はないということです。 

3 番目のケースは、1 つの色がすでに完全な間隔を占めている場合です。```
1 2 2 2 3
```答えは 0 です。カラー ブロックの最終的な順序は完全に制限されていないため、色を値の昇順または降順で表示するアルゴリズムは失敗します。 

## アプローチ

 強引な観点は、どの本を所定の位置に残すかを決定することです。 残らない本はすべて最後まで移動する必要があります。 

文房具の本のセットを知っていたとします。 それらの相対的な順序は決して変わりません。 移動された本をすべて削除した後、固定された本はすでに美しい棚を形成している必要があります。移動された本は後で追加され、固定されたプレフィックスの内部構造を変更できないためです。 

これは、残る可能性のある書籍の最大のサブセットを検索することを示唆しています。 維持できれば$k$本なら答えは$n-k$。 

問題は、$2^n$可能なサブセット。 すべての有効なサブセットを直接特徴づけようとすることさえ不可能になります。 

重要な観察は、各色の最初と最後の出現を観察することによって得られます。 

させて：

-$L_c$= 最初に出現した色の$c$-$R_c$= 最後の色の出現$c$-$cnt_c$= 色の周波数$c$その色を決めたら$c$は固定部分に参加し、その後、$c$、内部のあらゆる出来事$[L_c,R_c]$も同じカラーブロックに属している必要があります。 そうしないと、別の色がブロックを分割してしまいます。 

この間隔構造により、問題は位置に関する動的計画法の問題に変わります。 

定義する$dp[i]$から始まる接尾辞の位置のみを使用して静止した状態にできる本の最大数として$i$。 

ポジションに立つとき$i$、2つの可能性が存在します。 

現在の本を単純に削除することもできます。 その後は何も得られず、そのまま続行します$dp[i+1]$。 

あるいは、ここで間隔が始まる色の保存を開始することもできます。 色が$c$そして$i=L_c$。 

内部$[L_c,R_c]$、色の出現ごとに$c$残ることができる。 間隔全体がこの範囲内にある他のすべての色についても、その出現をすべて保存することもできます。 これにより、ネストされた間隔のチェーンが作成されます。 

元の受け入れられているソリューションは、位置を右から左に処理し、色ごとに、その間隔が選択されたときに取得できる最良の値を維持します。 間隔構造により、すべての位置を 1 回だけ処理できるため、線形の複雑さが得られます。 

移行により、最終的に保持できる本の最大数が計算されます。その答えは次のとおりです。$$n - \max(\text{stationary books})$$| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |

 | 最適なDP + インターバル処理 |$O(n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 まず、すべての色の最初の出現、最後の出現、および頻度を計算します。 

させて`dp[i]`は、からの位置のみを考慮した、静止したままにできる本の最大数を示します。`i`これからも。 

位置を右から左に処理します。 

1.本を所定の位置で取り出すと`i`を取得します。`dp[i+1]`。 
2. 現在の色を次のようにします。`c`。 
3. メンテナンス`best[c]`、色の間隔の選択に対応する値`c`。 
4. 位置の場合`i`の最後の発生です`c`、初期化します$$best[c] = cnt_c$$なぜなら、少なくともこの色のすべての出現を維持できるからです。 
5. それ以外の場合は更新します$$best[c] = best[c] + 1$$同じ色の別の出現箇所を左に移動しながら。 
6. 位置の場合`i`の最初の出現です`c`、色の間隔を終了する可能性があります`c`そして最後に発生した後も続行します。$$best[c] += dp[R_c + 1]$$7.セット$$dp[i] = \max(dp[i+1], best[c])$$8. 位置 1 まで続けます。 

文房具の最大冊数は、`dp[1]`。 答えは`n - dp[1]`。 

### なぜ効果があるのか

 すべての色について、最初と最後の出現の間の間隔によって、一貫して処理する必要がある領域が決まります。 スキャンが色に達したとき`c`、`best[c]`間隔の現在のサフィックスを維持する最適なソリューションを保存します。`c`。 

左に移動すると、保存された間隔がさらに 1 回発生するまで延長されます。`c`。 スキャンが最初の発生に達すると、間隔全体が`c`説明されています。 その時点で、直後から始まる最適解を連結することができます。`R_c`。 

すべての有効な静止セットはそのような完全な色間隔に分解でき、DP によって生成されるすべての遷移は実現可能な静止セットに対応します。 再帰では、すべての位置で両方の可能性が検査されます。つまり、現在の本を破棄するか、その色の間隔構造にコミットするかです。 すべての間隔が 1 回だけ処理されるため、保持できる本の最大数は正しく計算されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    first = [-1] * (n + 1)
    last = [-1] * (n + 1)
    cnt = [0] * (n + 1)

    for i, x in enumerate(a):
        if first[x] == -1:
            first[x] = i
        last[x] = i
        cnt[x] += 1

    dp = [0] * (n + 1)
    best = [0] * (n + 1)

    for i in range(n - 1, -1, -1):
        c = a[i]

        if i == last[c]:
            best[c] = cnt[c]
        else:
            best[c] += 1

        if i == first[c]:
            best[c] += dp[last[c] + 1]

        dp[i] = max(dp[i + 1], best[c])

    print(n - dp[0])

if __name__ == "__main__":
    solve()
```最初のパスでは、すべての色の間隔情報が計算されます。`best[c]`が中心的な考え方です。 右から左にスキャンしながら、部分的に処理された色の間隔の値を保存します`c`。 別の出来事に遭遇すると、`c`その間隔を保存本 1 冊分延長します。 

最初の発生時の特別な処理が重要です。 最初の出現に到達した後でのみ、その色の間隔全体がカバーされていることがわかります。 その時点で、間隔の終了後に開始する最適解を追加することができます。 

DP 配列はサフィックス DP です。`dp[i]`常に、位置で始まるサフィックスで利用可能な最良の回答を表します`i`。 取る`max(dp[i + 1], best[c])`これは、現在の本を破棄するか、その色の間隔構造を使用するかの選択に正確に対応します。 

すべての値は 32 ビット整数を超えないため、快適に収まります。`n`, しかし、Python の整数を使用すると、その心配はなくなります。

## 特殊なケース

 次のことを考慮してください。```
3
1 2 1
```色の間隔`1`は`[0,2]`。 色の間隔`2`は`[1,1]`。 

右から左にスキャンしている間、DP は両方の発生を維持することを認識します。`1`そして、単一の発生`2`間隔内で可能です。 最大静止数は次のようになります。`2`、答えを生み出す`1`。 これは次の動きと一致します。```
1 2 1
→
1 1 2
```考慮する：```
4
1 2 2 1
```色`2`すでに連続したブロックを形成しています。 DP はその間隔全体を保持し、それを色の 1 つの出現ブロックと組み合わせます。`1`。 静止カウントが到達しました`3`、したがって、答えは次のとおりです`1`。 

一度選択した色をすべて保持することにこだわる貪欲な戦略では、この可能性を逃してしまいます。 

考慮する：```
5
1 2 2 2 3
```すべての色はすでに 1 つの連続したセグメントを占めています。 間隔は互いに素であり、すでに有効です。 DP は 5 冊の本をすべて保管しており、`dp[0] = 5`、したがって、答えは次のとおりです`0`。 

これにより、アルゴリズムが操作をまったく必要としないシェルフを正しく処理していることが確認されます。
