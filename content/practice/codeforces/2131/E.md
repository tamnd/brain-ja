 ## 解決策
 ## 問題の理解

 2 つの配列が与えられています。`a`そして`b`、両方の長さ`n`。 操作を実行できます`a`インデックスごとに最大 1 回: 任意のインデックスに対して`i`1から`n-1`、設定できます`a[i]`に`a[i] XOR a[i+1]`。 質問は、そのような一連の操作を選択することによって、次のような変換が可能かどうかを尋ねます。`a`まさに`b`。 

入力は複数のテスト ケースで構成されます。 各テスト ケースはサイズを提供します`n`そして2つの配列`a`そして`b`。 変換が可能であれば「YES」、そうでなければ「NO」を出力する必要があります。 

この制約は、ほぼ線形のアルゴリズムが必要であることを意味します。`n`テストケースごとに、`n`は最大 2·10^5 であり、次の合計は`n`すべてのテスト ケースの値も 2·10^5 によって制限されます。 すべての操作シーケンスを試行する単純なソリューションは指数関数的であり、非常に遅すぎます。 すべての操作をシミュレーションするのではなく、問題の構造を推論する必要があります。 

エッジ ケースには、ゼロを含む配列、最後の要素のみが異なる配列、または次のようなケースが含まれます。`a`はすでに等しい`b`。 たとえば、次の場合`a = [0,0,1]`そして`b = [0,0,0]`、単純な貪欲なアプローチでは、最初の要素の XOR を試行し、許可された一連の操作で末尾の要素を削除できないことを見逃してしまう可能性があります。`1`。 

## アプローチ

 ブルートフォースアプローチは簡単です: すべてのインデックスに対して`i`で XOR 演算を実行してみてください。`i+1`そして再帰的にチェックします`b`を得ることができます。 これは、許可されているすべての操作が考慮されるため、原理的には正しいですが、O(2^n) 個の可能性があり、次の場合には実行できません。`n`2・10^5まで。 

線形ソリューションを可能にする重要な観察は、次のような XOR の違いに注目することです。`a`そして`b`。 させて`d[i] = a[i] XOR b[i]`。 それぞれの操作`a[i] := a[i] XOR a[i+1]`トグル`d[i]`による`a[i+1]`。 左から右へのみ操作でき、各インデックスは前の要素によって 1 回だけ影響を受けるため、XOR 修正を貪欲に伝播できます。`a[i]`一致しません`b[i]`で操作を適用する必要があります。`i`それを調整するために。 唯一の注意点は、最後の要素は修正できないことです。`a[n+1]`。 これにより、重要な洞察が得られます。変換は、最後の要素が一致し、伝播された修正が以前に設定された要素と競合しない場合にのみ可能です。 

この洞察により、問題は単一の左から右へのパスに縮小され、差分配列が維持され、必要に応じて演算が適用されます。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、差分配列を計算します。`d[i] = a[i] XOR b[i]`。 
2. インデックスを左から右に反復します。`i = 0`に`n-2`。 各インデックスで、次の場合、`d[i] != 0`で操作を適用する必要があります。`i`。 アップデート`d[i+1] := d[i+1] XOR d[i]`そしてセット`d[i] := 0`。 これは申請に相当します`a[i] := a[i] XOR a[i+1]`。 
3. 反復後、チェックします。`d[n-1]`。 もし`d[n-1] == 0`、「YES」を出力します。 それ以外の場合は「NO」を出力します。 最後の要素は調整できないため、そこの不一致は変換が不可能であることを意味します。 

機能する理由: 不変条件は、インデックスの処理後に`i`、すべての違い`d[0]..d[i]`ゼロに修正されました。 必要な XOR を伝播する`d[i+1]`まさに操作が行うことです。 これにより、最後の差分がゼロになると、次のすべての要素がゼロになることが保証されます。`a`マッチ`b`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can_transform(a, b, n):
    d = [a[i] ^ b[i] for i in range(n)]
    for i in range(n - 1):
        if d[i]:
            d[i+1] ^= d[i]
            d[i] = 0
    return d[-1] == 0

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    print("YES" if can_transform(a, b, n) else "NO")
```コードはまず、次の間の XOR の差を計算します。`a`そして`b`。 次に、左から右にスイープし、差を次の要素に伝播することで差をゼロにします。 ループ後、最後の要素の差がゼロであれば、変換は可能です。 最後の要素とインデックスには注意が必要です。操作は次の要素にのみ影響します。`i`そして`i+1`、だから私たちは決して試みません`i = n-1`。
