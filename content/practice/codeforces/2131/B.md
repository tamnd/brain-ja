 ## 解決策
 ## 問題の理解

 長さの整数配列を構築する必要があります`n`2 つのプロパティを備えています。 

最初のプロパティは、隣接する要素が常に反対の符号を持たなければならないことを示します。 それらの積は負でなければならないため、どちらの要素もゼロにすることはできず、符号は交互になる必要があります。 

2 番目のプロパティははるかに強力です。 少なくとも 2 つの長さの連続するすべての部分配列は、厳密に正の和を持たなければなりません。 

これらの要件を満たすすべての配列の中で、有効な解決策を見つけることは求められません。 絶対値のシーケンスが辞書編集的に最小のものを見つけなければなりません。 つまり、私たちが作りたいのは、`|a1|`できるだけ小さいもの。 それを条件として、`|a2|`できるだけ小さい、など。 

入力には最大 500 のテスト ケースが含まれており、すべてのテスト ケースの合計が`n`せいぜい`2 · 10^5`。 テスト ケースごとに直線的な時間を費やすソリューションは、簡単に十分に高速です。 たとえ`O(n log n)`解は問題なく適合しますが、二次アルゴリズムは除外されます。`n`と同じ大きさにすることができます`200000`。 

難しいのは、サブ配列の条件によって実際に何が強制されるのかを理解することです。 単純な試みでは別の結果になる可能性があります`-1, 1, -1, 1, ...`、しかしその後、部分配列`[-1, 1]`合計があります`0`、これはポジティブではありません。 

もう 1 つの簡単な間違いは、長さ 2 の部分配列のみに注目することです。 例えば：```
-1 2 -1 2
```すべての隣接するペアの合計は次のようになります`1`、これはポジティブです。 ただし、長い部分配列もすべて正である必要があります。 どのような構造であっても、すべての長さに対してチェックする必要があります。 

3 番目の微妙な点は、辞書編集上の最適性です。 考慮する`n = 3`。```
-1 2 -1
```それは良いですが、```
-1 3 -1
```も良いです。 

最初の異なる絶対値が 2 番目の位置であるため、2 番目の配列は最適ではありません。`2 < 3`。 

課題は、正の制約​​を維持しながら、すべての位置で可能な最小の絶対値を決定することです。 

## アプローチ

 ブルートフォースの考え方では、考えられる値を検索し、すべての部分配列が正のままであるかどうかを確認することによって、各要素を決定しようとします。 すべてのサブアレイのチェックにはすでにコストがかかります`O(n²)`、すべてのポジションに対して複数の候補者を探索することは完全に不可能になります。 と`n = 200000`、単一でも`O(n²)`検証には大まかに必要になります`4 · 10^10`操作。 

重要な観察は、長さ 2 のすべての部分配列が正でなければならないという要件から来ています。 

隣接する要素は反対の符号を持つ必要があるため、符号パターンは次のいずれかである必要があります。```
- + - + - ...
```または```
+ - + - + ...
```最初の要素が正であると仮定します。 次に、2番目はマイナスです。 これら 2 つの要素で構成される長さ 2 の部分配列は、正の和を持たなければなりません。```
a1 + a2 > 0
```以来`a2`が負の場合、これは意味します```
a1 > |a2|
```辞書編集的に最小限にするには、次のようにします。`|a1|`できるだけ小さいもの。 最小のゼロ以外の絶対値は次のとおりです。`1`。 もし`a1 = 1`、それでは必要です`|a2| < 1`、ゼロ以外の整数では不可能です。 

したがって、配列を正の値で開始することはできません。 

最初の要素は次のようにする必要があります`-1`、可能な最小の絶対値。 

次に 2 番目の要素を考えてみましょう。 以来```
a1 + a2 > 0
```そして`a1 = -1`、必要です```
a2 > 1
```これを満たす最小の正の整数は次のとおりです。```
a2 = 2
```次に、負の値でなければならない 3 番目の要素を検討します。 The pair`(a2, a3)`満たさなければなりません```
a2 + a3 > 0
```と`a2 = 2`、これは次のようになります```
2 - |a3| > 0
```それで```
|a3| < 2
```ゼロ以外の最小の可能性は次のとおりです。```
|a3| = 1
```与える```
a3 = -1
```同じ議論が永遠に繰り返されます。 奇妙な位置はすべて強制的に`-1`、そしてすべての偶数の位置は強制的に`2`。 

結果の配列は次のとおりです```
-1 2 -1 2 -1 2 ...
```少なくとも 2 の長さのすべての部分配列が正の和を持つことを検証する必要があります。 

隣接するペアの合計は次のようになります```
-1 + 2 = 1
```または```
2 - 1 = 1
```すべての完全なペアが貢献します`1`。 部分配列の長さが奇数の場合、部分配列にはいくつかの完全なペアと 1 つの追加要素が含まれます。 The extra element can only be`2`または`-1`, and the total remains positive. 直接計算すると、少なくとも 2 つの長さのすべての部分配列の合計が少なくとも 2 つあることがわかります。`1`。 

したがって、この構造は有効であり、辞書編集的に最適です。

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、長さの配列を作成します。`n`。 
2.置く`-1`すべての奇数位置 (1 から始まるインデックス)。 

これは辞書編集上の最適性によって強制されます。 最初の要素を正にすることはできません。絶対値による最小の負の整数は次のとおりです。`-1`。 
3.置く`2`すべての偶数の位置で。 

前の要素は`-1`、隣接するペアは正の和を持つ必要があります。 機能する最小の正の整数は次のとおりです。`2`。 
4. 構築された配列を出力します。 

### なぜ効果があるのか

 最初の要素には少なくとも絶対値が必要です`1`。 選択する`+1`最初のペアの正の要件を満たすことが不可能になるため、辞書編集的に最小の選択は次のようになります。`-1`。 

一度`a1 = -1`は固定されており、有効な最小値は`a2`は`2`、 なぜなら`-1 + a2`ポジティブである必要があります。 

固定後`a2 = 2`、次の負の要素の最小有効な大きさは次のとおりです。`1`、与える`a3 = -1`。 

この議論は帰納的に繰り返され、すべての奇数の位置が強制的に`-1`そしてあらゆる偶数の位置にある`2`。 

すべての隣接するペアが正確に寄与します`1`合計に。 少なくとも 2 の長さのサブ配列には少なくとも 1 つのそのようなペアが含まれており、残りのすべての寄与により合計がプラスに保たれます。 したがって、必要なすべてのサブ配列は正の和を持ちます。 

各位置は、以前に強制されたすべての選択と一致する可能な限り最小の絶対値として選択されるため、絶対値シーケンスは辞書編集的に最小になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())

        cur = []
        for i in range(n):
            if i % 2 == 0:
                cur.append("-1")
            else:
                cur.append("2")

        ans.append(" ".join(cur))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```実装は、上で証明された構造に直接続きます。 

位置は、ゼロベースのインデックスを使用して処理されます。 索引`0`位置に対応する`1`、したがってインデックスでも受信します`-1`奇数のインデックスは受信します`2`。 

数学的証明によって正確さがすでに保証されているため、部分配列の検証は必要ありません。 このアルゴリズムは、辞書編集的に最適な独自のパターンを出力するだけです。 

値は次のとおりであるため、オーバーフローの心配はありません。`-1`そして`2`、許容範囲をはるかに超えています。 

唯一の境界条件は、`n = 2`、可能な限り最小の長さ。 同じ交互パターンがすぐに機能します。```
-1 2
```長さ 2 の部分配列のみが合計を持ちます`1`。

## テストケース```python
import sys, io

def solve():
    input = sys.stdin.readline

    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        arr = []
        for i in range(n):
            arr.append("-1" if i % 2 == 0 else "3")
        out.append(" ".join(arr))

    return "\n".join(out)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    return solve()
