 ## 解決策
 ## 問題の理解

 サイクルのない無向接続グラフであるツリーが与えられます。 Kagari は、パスを「再ルート」する操作を実行できます。つまり、2 つの頂点を選択し、それらを接続するパスに沿ったエッジを削除し、そのパスに沿ったすべての頂点を開始頂点に直接再接続します。 目標は、そのような操作を最小限に抑えて木の直径を最小限に抑えることです。 各テスト ケースはツリーをエッジのリストとして提供し、単一の整数、つまり最小操作数を出力する必要があります。 

木の直径は、任意の 2 つの頂点間の最長パスの長さです。 この操作により、内部ノードを新しいルートの近くに移動することで、長いパスを短縮できます。 可能な最小直径は、葉の数と木の構造によって異なります。 たとえば、すべての葉が中央の頂点に接続されている星形の木の場合、葉の数に応じて直径が 1 または 2 になります。 

制約は、パスのブルートフォース操作が実行不可能であることを意味します。 までの木$2 \cdot 10^5$ノードと$10^4$テスト ケースとは、ソリューションがテスト ケースごとに線形またはほぼ線形の時間で実行される必要があることを意味します。 すべての頂点のペアを試したり、すべての操作をシミュレートしたりする単純なアプローチでは、$O(n^2)$さらに悪いことに、遅すぎます。 

明らかではないエッジ ケースには、すでに最小限になっているツリー、本質的に直線状 (パス) のツリー、および同じ長さの複数の枝を持つ星状のツリーが含まれます。 常に 1 つの操作を実行しようとする不注意な解決策では、誤って直径を拡大したり、不必要な手順を実行したりする可能性があります。 

たとえば、2 つの頂点を持つ木について考えてみましょう。 直径はすでに 1 であるため、操作は必要ありません。 エンドポイントを盲目的に選択する単純なアルゴリズムでは、0 ではなく 1 が出力される可能性があります。 別の例は、1 つの中心頂点と複数の葉を持つ星です。 直径は 2 であり、これ以上縮小する操作はありませんが、単純なアプローチでは冗長な操作が実行される可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、頂点のすべてのペアを考慮し、操作をシミュレートして、結果の直径を確認します。 各テストケースについて、$n$頂点、これはチェックする必要があります$\binom{n}{2}$ペア。 毎回直径を計算すると、$O(n)$、全体的な複雑さは次のようになります。$O(n^3)$テストケースごとに。 これは実用的ではありません$n$まで$2 \cdot 10^5$。 

重要な観察は、木の直径が直径パスと呼ばれるその「最長のパス」によって決まるということです。 **直径の一部ではない**パスに対して操作を実行しても、直径を減らすことはできません。 したがって、現在の直径パスの端点のみを考慮する必要があります。 さらに、直径パス上の次数 2 の内部ノードは、エンドポイントの 1 つに直接接続するとパスの長さが短縮されるため、再ルートの候補となります。 

最小の操作数は、メイン パスから突き出る直径の「分岐」の数に対応します。 直径から外れた葉は無視でき、解決策は 2 より大きい次数の直径に沿った頂点を数えて 1 を引くことになります。 これにより、線形時間アルゴリズムが得られます。直径を計算し、それに沿って次数 > 2 の頂点をカウントし、そのカウントを出力します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n3) | O(n) | 遅すぎる |
 | 最適 | テスト ケースあたり O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 各テスト ケースについて、頂点とエッジの数を読み取り、ツリーを表す隣接リストを構築します。 
2. 任意の頂点を選択し、BFS を実行して、そこから最も遠い頂点を見つけます。 この頂点はツリーの直径の 1 つの端点です。 
3. その端点から開始して BFS を実行し、直径のもう一方の端点とすべての頂点までの距離を見つけます。 各頂点の親を記録して、直径パスを再構築します。 
4. 親配列を使用して直径パスを再構築します。 パスに沿ってすべての頂点を収集します。 
5. 直径パスに沿って次数が 2 より大きい頂点の数を数えます。 この数から 1 を引いて、必要な再ルート操作の最小数を決定します。 
6. 各テスト ケースの結果の数値を出力します。 

機能する理由: 直径は、最長のパスに沿った頂点によってのみ影響を受けます。 すべての操作では、このパスの終点間の距離を減らすことしかできません。 次数 2 の頂点はすでにパスに沿って位置合わせされており、他の場所でより長い直径を生成することはできません。 より高い次数の頂点は、ルートを再設定できるブランチを表し、各操作によってエンドポイントに向かってブランチが折りたたまれます。 直径に沿ってそのような頂点を数えると、直径を最小化するために必要な正確な操作数が得られます。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

def bfs_farthest(n, adj, start):
    dist = [-1] * (n + 1)
    parent = [-1] * (n + 1)
    q = deque()
    q.append(start)
    dist[start] = 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                parent[v] = u
                q.append(v)
    farthest_node = max(range(1, n+1), key=lambda x: dist[x])
    return farthest_node, parent, dist

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        adj = [[] for _ in range(n+1)]
        for _ in range(n-1):
            u, v = map(int, input().split())
            adj[u].append(v)
            adj[v].append(u)

        # find diameter endpoints
        u, _, _ = bfs_farthest(n, adj, 1)
        v, parent, _ = bfs_farthest(n, adj, u)

        # reconstruct diameter path
        path = []
        curr = v
        while curr != -1:
            path.append(curr)
            curr = parent[curr]

        # count internal nodes with degree > 2
        count = 0
        for node in path:
            if len(adj[node]) > 2:
                count += 1
        if count > 0:
            count -= 1
        print(count)

if __name__ == "__main__":
    solve()
```このソリューションでは、BFS を使用して直径を効率的に見つけます。 親配列を使用すると、正確なパスを再構築できます。 直径に沿って 2 より大きい次数のノードを数えると、操作が必要な分岐に対応します。 1 を減算すると、パスの開始エンドポイントが計算され、これ以上ルートを変更することはできません。 隣接リストを使用すると過剰なメモリ使用が回避され、BFS によって線形トラバーサルが保証されます。 単一分岐パスを正しく処理し、負の操作数を回避するように注意が必要です。 

## 実用的な例

 **サンプル 1、テスト ケース 1**

 入力ツリーエッジ:```
1-2
1-3
2-4
```頂点 1 から BFS を実行: 最も遠いノードは 4。BFS 4 から: 最も遠いノードは 3。直径パス: 3-1-2-4。 パスに沿った次数 > 2: ノード 1 の次数は 2、ノード 2 と 4 の次数 ≤ 2、ノード 3 の次数 1。ノード 2 のみ次数 2 ですが、次数 > 2 のチェックは失敗します。 カウント = 1 - 1 = 0。最小直径操作では直径が 1 減少し、操作が 1 回になります。 

**サンプル 1、テスト ケース 4**

 入力ツリーエッジ:```
1-2
1-3
2-4
3-5
3-8
5-6
5-7
7-9
7-10
5-11
```1 から最も遠いノードは 10 です。10 から最も遠いノードは 4 です。直径パス: 4-2-1-3-5-7-10。 パスに沿った次数 > 2 のノード: 1、3、5。 カウント = 3。減算 1 = 2 演算。 枝に沿って再発根した後、直径は最小になりました。 

BFS での状態のテーブルは簡潔にするために省略されていますが、親配列の後に続きます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | テスト ケースあたり O(n) | BFS はすべての頂点とエッジを 1 回横断し、パスの再構築は O(n) |
