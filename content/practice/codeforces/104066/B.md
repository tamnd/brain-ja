 ## 解決策
 ## 問題の理解

 私たちは平面上に幾何学的なセットアップを与えられています。 中心と半径が既知の固定円があり、その円上には 2 つのマークされた点を運ぶ剛体の「装置」があります。 重要な自由は、このデバイスを円の中心を中心に回転できることです。これにより、マークされた 2 つの点が中心からの距離を維持しながら、その中心を中心に効果的に回転します。 

これに加えて、平面内に一定の直線が存在します。 タスクは、マークされた 2 つの点によって形成される線が指定された固定線と平行になるように、円のマークされた構成を回転できるかどうかを判断することです。 

したがって、本当の問題は、円自体に関するものではなく、2 つの点によって定義されるセグメントが、共通の中心の周りで厳密に回転した後、指定された線の方向と一致する方向を達成できるかどうかです。 

入力は 3 つの独立した幾何学的オブジェクトを記述します。 まず、円の中心と半径で、ピボットと回転機構を定義します。 第 2 に、一般的に与えられる直線は ax + by + c = 0 の形になります。ここで重要なのは方向ベクトル (a, b) だけです。 3 番目に、セグメントを定義する 2 つの点が円の中心に固定されています。つまり、中心の周りの相対角度は変化しますが、中心からの距離は固定されています。 

出力は、セグメントの方向を指定された線と平行にする回転角度が存在するかどうかという、単純な実現可能性の決定です。 

制約は小さく、すべての座標と係数は 10^4 で制限されます。 これにより、基本的な三角法やベクトル推論を超えた、複雑な幾何学的な前処理や浮動小数点の精度のトリックの必要性が即座に排除されます。 テスト ケースごとに一定時間の幾何学的チェックを行うだけで十分です。 

マークされた 2 つの点が一致する場合、微妙なエッジ ケースが表示されます。 この状況では、「マークされた点を通る線」は定義されません。 方向ベクトルをやみくもに計算する単純な実装では、ゼロで除算するかゼロ ベクトルとして扱うことになり、誤った結論が得られる可能性があります。 たとえば、(0, 0) と (0, 0) のように、両方の点が同一である場合、セグメントには方向がありません。 その場合、正しい出力は解釈に依存します。線を形成できないため、縮退していない任意の線と平行にすることは不可能です。したがって、標準の CF ジオメトリ問題では許可されない縮退並列処理が問題で許可されない限り、答えは NO になるはずです。 

もう 1 つの例外的なケースは、指定されたラインの方向表現が縮退している場合です。たとえば、a と b の両方が 0 である場合です。 これにより行が無効になりますが、通常は制約によってこれが起こらないようになっています。 それでも、堅牢な推論では c を完全に無視し、方向ベクトルとして (a, b) のみに焦点を当てる必要があります。 

## アプローチ

 これを考える強引な方法は、中心を中心としたセグメントの回転をシミュレートし、考えられるすべての方向をチェックすることです。 連続的な回転が含まれるため、角度を離散化し、セグメントの多くの候補方向をテストする可能性があります。 これは概念的には、角度を 0 から 2π までスイープし、回転したベクトルが指定された線の方向と一致するかどうかをチェックすることによって機能します。 

ただし、これは不必要かつ不正確です。 細かく離散化したとしても、浮動小数点の粒度により正確な位置合わせが失われる危険性があり、正確さに必要なサンプル数は明確な方法で制限されません。 

重要な観察は、マークされた 2 つの点によって定義されるセグメントが固定長を持ち、中心の周りを厳密に回転するということです。 これは、その方向がエンドポイント構成ごとに自由に選択できないことを意味します。 代わりに、単一の基本ベクトルの可能なすべての回転に及びます。 したがって、唯一の問題は、セグメントの方向ベクトルを (a, b) に平行な方向に回転できるかどうかです。

2 つのベクトルは、回転によって角度が異なる場合に限り、回転によって平行にすることができます。これは、セグメントが単一点に縮退しない限り常に可能です。 平面内での回転は大きさを維持し、方向のみを変更するため、ゼロ以外のベクトルを回転して他の方向に一致させることができます。 

したがって、問題は、セグメントが非縮退であるかどうかをチェックすることに帰着します。 2 つの点が異なる場合は、有効な方向ベクトルが存在し、いつでもそれを回転して線の方向に揃えることができます。 それらが一致する場合、方向は存在せず、答えは NO です。 

したがって、ジオメトリ全体が単純な縮退チェックに集約されます。

 ## アルゴリズムのチュートリアル

 1. 円のパラメータ、線の係数、および 2 つの点を読み取ります。 円パラメータは実際の計算では使用されませんが、概念的に回転中心を設定します。 
2. 2 つの点によって形成される線分の方向ベクトルを (dx, dy) = (x2 − x1, y2 − y1) として計算します。 このベクトルは、意味のある唯一の幾何学的自由度を表します。 
3. このベクトルがゼロかどうかを確認します。 dx = 0 および dy = 0 の場合、2 点は一致し、有効な方向が存在しないため、直ちに NO を出力します。 
4. ベクトルがゼロでない場合は、線の方向 (a、b) に平行な方向を含む、平面内の任意の方向に回転できると結論付けます。 はいを出力します。 

ステップ 4 の背後にある理由は、ゼロ以外の 2D ベクトルはすべての角度にわたって連続的に回転でき、平行度は大きさではなく方向のみに依存するということです。 

### なぜ効果があるのか

 不変条件は、マークされたセグメントの重要なプロパティはその方向ベクトルだけであり、中心の周りの回転によりその長さが維持され、同時に全円にわたる方向の連続的な変更が可能になるということです。 到達可能な方向のセットは、ゼロ以外のベクトルの単位円全体です。 したがって、ベクトルが縮退していない限り、任意の直線に一致する方向が常に存在します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    x0, y0, r = map(int, input().split())
    a, b, c = map(int, input().split())
    x1, y1 = map(int, input().split())
    x2, y2 = map(int, input().split())

    dx = x2 - x1
    dy = y2 - y1

    if dx == 0 and dy == 0:
        print("NO")
    else:
        print("YES")

if __name__ == "__main__":
    solve()
```すべての幾何学的複雑性はすでに分析的に解決されているため、実装ではロジックが最小限に保たれます。 円パラメータは入力形式に一致するように読み取られますが、それ以上は使用されません。 唯一の重要な計算は、マークされた 2 つの点間の差です。 

ここでよくある間違いは、傾きまたは浮動小数点の角度比較を使用しようとすることです。 この問題は単純な非縮退チェックに帰着するため、これは不要です。

 ## 特殊なケース

 2 つのマークされた点が同一である場合、アルゴリズムは dx = dy = 0 を検出し、ただちに NO を出力します。 これにより、方向に関する未定義の概念がなくなり、ゼロ ベクトルを任意の方向を持つものとして扱うことがなくなります。 

たとえば、入力が (0,0) および (0,0) の場合、計算されるベクトルは (0,0) になります。 アルゴリズムは縮退チェックで停止し、幾何学的推論を試行せずに NO を返します。 

(0,0) と (0,1) のように、点が非常に近いものの同一ではない場合、ベクトルは依然として有効であり、アルゴリズムは回転を正しく許可します。 これは、数値的な近さではなく、正確な等しいことのみが重要であることを示しています。
