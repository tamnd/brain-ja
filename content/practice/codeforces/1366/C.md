 ## 解決策
 ## 問題の理解

 バイナリ行列があります。 パスは左上のセルで開始し、右下のセルで終了し、右または下にのみ移動します。 

すべてのパスは、開始点から測定された各「距離レイヤー」の 1 つのセルに正確にアクセスします。 セルがその位置にある場合`(i, j)`、その場合、その層は`i + j`ゼロベースのインデックスを使用する場合。 どのパスに沿っても、レイヤーは次から昇順にアクセスされます。`0`に`n + m - 2`。 

可能なすべてのパスで回文形式の一連の値を生成したいと考えています。 任意のセルを反転することができます`0`に`1`またはから`1`に`0`、目標は、変更されたセルの数を最小限に抑えることです。 

マトリックスの次元は最大でも`30 × 30`。 まであるかもしれないが`200`テスト ケース、各行列には最大でも次のものが含まれます。`900`細胞。 これはすぐに、あらゆる解決策が考えられることを示唆しています。`O(nm)`または`O(nm log nm)`テスト ケースごとの実行は簡単に十分に高速ですが、パスの列挙を伴うものは不可能です。 

からのパスの数`(1,1)`に`(n,m)`は$$\binom{n+m-2}{n-1},$$これは、中程度のサイズであっても巨大になります。 個々のパスについて推論する直接的なアプローチは機能しません。 

レイヤーがそれ自体とペアになっている場合、微妙なエッジケースが表示されます。 

考慮する：```
2 3
0 1 0
1 0 1
```レイヤーは次のとおりです。```
layer 0: (0,0)
layer 1: (0,1) (1,0)
layer 2: (0,2) (1,1)
layer 3: (1,2)
```レイヤー`1`そして`2`端からの距離が等しいため、ペアになります。 各ペアは 1 回だけ処理されます。 両方を処理する不用意な実装`(1,2)`そして`(2,1)`変更を二重にカウントしてしまいます。 

もう 1 つの重要なケースは、開始レイヤーと終了レイヤーです。 

例えば：```
2 2
0 1
1 1
```最初と最後のセルが最適化グループに含まれることはありません。 すべての道は常にそこで始まり、そこで終わります。 レイヤーペア`(0,2)`これらの層は回文の端に位置するため、処理してはなりません。 標準溶液では当然それらはスキップされます。 

3 番目のトラップは、合計パス長が奇数の場合の中間層です。 

例：```
3 3
0 1 0
1 1 1
0 1 0
```層`2`すべてのパスの正確な中心です。 回文では中心位置に制限がないため、このレイヤーのコストはゼロです。 これを処理すると、反転が誤って追加されてしまいます。 

## アプローチ

 この問題を考える強引な方法は、左上隅から右下隅までのすべてのパスを調べ、そのパスに沿ったシーケンスが回文であることを強制することです。 

この推論は正しいですが、パスの数は指数関数的に増加します。 のために`30 × 30`グリッド、カウントは$$\binom{58}{29},$$それは天文学的な大きさです。 すべてのパスを生成することさえ不可能です。 

重要な観察は、回文性はパス内の位置のみに依存し、通過する特定のルートには依存しないということです。 

すべてのセルは、次のように決定されるレイヤーに属します。$$d = i + j.$$同じレイヤー内のすべてのセルは、アクセスするすべてのパスの同じ位置に表示されます。 

パスの位置がレイヤーにあると仮定します`d`。 回文内の鏡像位置は層です$$(n+m-2)-d.$$すべてのパスが回文になるように、層内のすべてのセルが`d`層内のすべてのセル$$(n+m-2)-d$$同じ値が含まれている必要があります。 

なぜそれが必要なのでしょうか?

 レイヤーから任意のセルを選択します`d`およびそのミラー層の任意のセル。 両方を通る道が存在します。 そのパス内ではそれらの位置が対称になるため、それらの値は一致する必要があります。 

これは、ミラー化されたレイヤーの各ペアが 1 つの独立したグループを形成することを意味します。 これら 2 つの層内のすべてのセルは、最終的には次のいずれかになる必要があります。`0`またはすべて`1`。 

を含むグループの場合`z`ゼロと`o`最小コストは単純に$$\min(z, o).$$すべての 0 を 1 に反転するか、すべての 1 を 0 に反転します。 

異なる層のペアが相互作用することはないため、これらのコストを個別に合計します。

 | 最適 | O(nm) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. しましょう`L = n + m - 2`、最大レイヤーインデックス。 
2. すべてのセルをレイヤーごとにグループ化します。`d = i + j`。 
3. レイヤーごとのインデックス`d`、そのミラー層は`L - d`。 
4. 以下のペアのみを処理します。`d < L - d`。 これにより、二重カウントが回避され、ミラーリング時に中間層が自動的にスキップされます。 
5. レイヤーに属するすべてのセルを収集します`d`そしてレイヤー`L - d`。 
6. 値がいくつあるか数えます`0`そして何人ですか`1`この結合グループ内で。 
7. グループ全体を平等にする最も安価な方法は、少数派の値を反転することです。 追加`min(zeros, ones)`答えに。 
8. ミラー化されたレイヤーのペアごとに繰り返します。 
9. 蓄積された回答を出力します。 

### なぜ効果があるのか

 どの層にも`d`、パス内のすべての対称位置がレイヤーに対応します`L-d`。 最初のレイヤーの任意のセルと 2 番目のレイヤーの任意のセルを考えてみましょう。 両方のセルを訪問するパスを構築し、セルをそのパスのミラー位置に配置できます。 

このような 2 つのセルが異なる値を持っていた場合、そのパスは回文ではありません。 したがって、2 つのレイヤーを結合したすべてのセルは 1 つの共通の値を共有する必要があります。 

1 つのミラー化レイヤー ペアの制約には、他のペアのセルは含まれません。 各ペアは個別に最適化できます。 過半数の値を選択すると、そのグループ内の反転が最小限に抑えられ、`min(zeros, ones)`変化します。 これらの独立した最適コストを合計すると、全体的な最適値が生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n, m = map(int, input().split())
        a = [list(map(int, input().split())) for _ in range(n)]

        layers = [[] for _ in range(n + m - 1)]

        for i in range(n):
            for j in range(m):
                layers[i + j].append(a[i][j])

        L = n + m - 2
        ans = 0

        for d in range((L + 1) // 2):
            mirror = L - d

            zeros = 0
            ones = 0

            for x in layers[d]:
                if x == 0:
                    zeros += 1
                else:
                    ones += 1

            for x in layers[mirror]:
                if x == 0:
                    zeros += 1
                else:
                    ones += 1

            ans += min(zeros, ones)

        print(ans)

solve()
```最初の部分では、レイヤーの分解を構築します。 同じ値を持つすべてのセル`i + j`同じレイヤーに属します。 

変数`L`最後のレイヤーインデックスです。 層`d`レイヤーとペアになっています`L-d`。 

ループは中間点までのみ実行されます。 これは間違いを引き起こす可能性が最も高い詳細です。 いつ`d`それ自体をミラーリングするレイヤーに到達すると、制約は存在しないため、レイヤーは無視する必要があります。 使用する```
range((L + 1) // 2)
```有効なミラーリングされたペアを正確に処理します。 

各ペアについて、コードは両方の層の 0 と 1 を一緒にカウントします。 最終グループは均一になる必要があるため、最適な選択は、すでに出現頻度が高い値を保持することです。 

グリッドには最大でも次のものが含まれるため、オーバーフローの問題は発生しません。`900`細胞。

 ## 特殊なケース

 ### 中間層はそれ自体をミラーリングします

 入力:```
1
3 3
0 0 0
0 1 0
0 0 0
```レイヤーは次のとおりです。```
0, 1, 2, 3, 4
```層`2`が中心です。 アルゴリズムはペアのみを処理します`(0,4)`そして`(1,3)`。 中央の層は完全にスキップされ、答えが生成されます`0`。 

中央レイヤーを含むソリューションでは、1 回のフリップが誤ってカウントされます。 

### ミラーリングされたペアを二重にカウントする

 入力:```
1
2 3
1 1 0
1 0 0
```有効なペアは次のとおりです。```
(0,3)
(1,2)
```アルゴリズムは、レイヤーの後半に到達する前に停止します。 各制約グループは 1 回だけ貢献します。 

すべてのレイヤーにわたるループが処理されます`(1,2)`そしてその後`(2,1)`、答えを2倍にします。 

### 開始セルと終了セルが異なります

1 1

アルゴリズムは以下を計算します。```
zeros = 1
ones = 1
cost = 1
```そして出力`1`、これは、すべてのパスを回文にするために必要な反転の最小数です。
