 ## 解決策
 ## 問題の理解

 2 つの配列が与えられています。`a`そして`b`。 配列`b`は厳密に増加しており、私たちのタスクは配列を分割することです`a`正確に`m`連続した部分配列。各部分配列の最小値は、次の対応する要素と一致します。`b`。 の各要素`a`正確に 1 つのサブ配列に属している必要があり、パーティションは連続しています。 出力は、このパーティショニングを実行する有効な方法の数 (剰余 998244353) です。 

の制約`n`そして`m`は両方とも最大 200,000 であり、要素の値は 10^9 に達する可能性があります。 このようなサイズでは、パーティションの数が指数関数的に増加するため、考えられるすべてのパーティションを単純に考慮したソリューションは遅すぎます。`n`。 代わりに、アルゴリズムは問題の構造を利用する必要があります。つまり、部分配列の最小値がどこに現れるかのみを考慮し、残りの要素は最小制約に違反しない限り自由です。 

明らかではないエッジケースには、次のような状況が含まれます。`b[i]`の残りの部分には存在しません`a`。 たとえば、次の場合`a = [1,2,3]`そして`b = [2,3,4]`、有効なパーティションがありません。`4`が欠けています。 もう 1 つの特殊なケースは、値が繰り返されることです。`a`それは複数のサブ配列の一部である可能性があります。 過大なカウントを避けるために、アルゴリズムはこれらを正しく考慮する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての分割方法を生成します。`a`の中へ`m`連続したセグメントを検索し、各セグメントの最小値が一致するかどうかを確認します`b`。 このアプローチは制約を直接適用するため原理的には機能しますが、その複雑さは次の点で指数関数的になります。`n`大規模な配列では実行不可能です。 のために`n`最大 2 * 10^5 の場合、すべてのパーティションを反復処理することは不可能です。 

最適なアプローチは、有効なパーティションの場合、最後のセグメントの最小値は次の値でなければならないという観察を利用します。`b[m-1]`、最後から 2 番目のセグメントの最小値は次のようにする必要があります。`b[m-2]`、 等々。 スキャンできます`a`右から左に向かって各最小値が開始できる最も早い位置を決定し、残りの部分配列の最小値が対応するサブ配列と等しくなるようにします。`b[i]`。 これらの位置が決定されると、各セグメントの開始に有効な選択肢を数えることによって、分割ポイントを配置する方法の数が求められます。 具体的には、サブ配列の有効な分割数`i`前のセグメントの最後の最小値と次の現在の最小値の間の要素の数であり、パーティションの総数の乗算構造を形成します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^m) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. アレイのスキャンを開始します`a`右から左に、これまでに確認された最小値を追跡します。 各セグメントの右端の要素は少なくとも必要な最小値である必要があるため、これにより各セグメントの潜在的なエンドポイントが特定されます。`b[i]`。 
2. かどうかを確認します。`b[m-1]`、最後の部分配列の最小値は、の右端の部分に存在します。`a`。 そうでない場合、有効なパーティションが存在しないため、答えはゼロになります。 
3. セグメントごとに`i`最後から最初まで、最も古いインデックスを記録します。`b[i]`後続のセグメントの最小値に違反することなく表示できます。 これにより、各セグメントの有効な範囲が確立されます。 
4. セグメントごとに、左境界が取り得る位置の数を計算します。これは、次のセグメントの最小値の最も早い出現と現在のセグメントの最小値の差です。 これらの数を 998244353 を法として乗算して、パーティションの総数を取得します。 
5. 合計数を答えとして返します。 

重要な不変条件は、それぞれの最小値が`b[i]`はセグメント内のどこかに出現する必要があり、その右側のすべての要素は厳密に大きな最小値を持つセグメントに属します。 右から左にスキャンすることで、順序と連続性の制約の両方を尊重した方法で最小値が割り当てられることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

n, m = map(int, input().split())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

min_a = [0] * n
min_a[-1] = a[-1]
for i in range(n - 2, -1, -1):
    min_a[i] = min(a[i], min_a[i + 1])

if min_a[0] != b[0]:
    print(0)
    sys.exit()

pos = n
ans = 1
for i in range(m - 1, 0, -1):
    found = False
    for j in range(pos - 1, -1, -1):
        if min_a[j] < b[i]:
            ans = (ans * (pos - j - 1)) % MOD
            pos = j + 1
            found = True
            break
    if not found:
        print(0)
        sys.exit()

print(ans)
```このソリューションでは、まず接尾辞の最小値を計算します。`a`有効なセグメントのエンドポイントを迅速に特定します。 次に、最初の要素が有効なセグメントを開始できることを確認し、後方に反復処理します。`b`セグメント境界の有効な選択肢をカウントします。 乗算は必要に応じて 998244353 を法として実行されます。 サフィックス minima を使用すると、アルゴリズムがスキャンできるようになります。`a`セグメントごとに 1 回だけなので、時間の複雑さは O(n) になります。 

## 実用的な例

 のために`a = [12, 10, 20, 20, 25, 30]`そして`b = [10, 20, 30]`、サフィックス最小配列は次のようになります。`[10, 10, 20, 20, 25, 30]`。 右からスキャン、最後の最小値`30`はインデックス 5 で発生するため、最後のセグメントはインデックス 5 で開始する必要があります。2 番目の最小値`20`2 番目のセグメントの有効な開始位置はインデックス 2 と 3 であり、2 つの選択肢があります。 最初の最小値`10`インデックス 1 で発生し、最初のセグメントを開始する必要があります。 2 番目のセグメントの選択肢の数 (2) と最初のセグメントの 1 つの選択肢を乗算すると、合計 2 つの有効なパーティションが得られます。 

| インデックス | a[i] | min_a[i] | 有効な分割 |
 | --- | --- | --- | --- |
 | 5 | 30 | 30 | 最後のセグメントはここから始まります |
 | 4 | 25 | 25 | 次のセグメントは 2 または 3 から開始できます |
 | 3 | 20 | 20 | 上を参照 |
 | 2 | 20 | 20 | 上を参照 |
 | 1 | 10 | 10 | 最初のセグメントはここから始まります |
 | 0 | 12 | 10 | 最初のセグメントでカバー |

 このトレースは、サフィックス最小アプローチがすべての有効な位置を効率的にキャプチャしていることを確認します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    MOD = 998244353

    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    min_a = [0] * n
    min_a[-1] = a[-1]
    for i in range(n - 2, -1, -1):
        min_a[i] = min(a[i], min_a[i + 1])

    if min_a[0] != b[0]:
        return "0"

    pos = n
    ans = 1
    for i in range(m - 1, 0, -1):
        found = False
        for j in range(pos - 1, -1, -1):
            if min_a[j] < b[i]:
                ans = (ans * (pos - j - 1)) % MOD
                pos = j + 1
                found = True
                break
        if not found:
            return "0"

    return str(ans)

# Provided sample
assert run("6 3\n12 10 20 20 25 30\n10 20 30\n") == "2", "sample 1"

# Custom cases
assert run("3 2\n1 2 3\n1 3\n") == "1", "minimum size, one valid split"
assert run("5 3\n5 4 3 2 1\n1 3 5\n") == "0", "no valid partitions"
assert run("4 2\n2 2 2 2\n2 2\n") == "3", "all equal elements, multiple valid splits"
assert run("2 2\n1 2\n1 2\n") == "1", "each element forms its own subarray"
