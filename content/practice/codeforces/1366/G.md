### なぜ効果があるのか

 スタックは常に 2 つの部分に分割される可能性があります。 下部は最後の文字列のプレフィックスに対応します`t`。 上部は一時的な文字で構成されており、最終的には削除されます。 一時的なキャラクターの正確な身元は決して重要ではなく、現在存在するキャラクターの数だけが重要です。 

DP の不変条件は、状態が将来の決定に関連するすべての情報 (一致したプレフィックスの長さと一時要素の数) を完全に取得することです。 すべての法的なスタック操作は、実際のスタックとまったく同じようにこれらの量を変換します。 すべての文字は独立して保持または削除できるため、DP はすべての有効なサブシーケンスを探索します。 保持される文字数を最大化すると、最長の有効なサブシーケンスが生成されます。`t`これは、削除を最小限に抑えることと同じです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    t = input().strip()

    m = len(t)

    NEG = -10**9

    dp = [NEG] * (m + 1)
    dp[0] = 0

    for ch in s:
        ndp = dp[:]

        if ch != '.':
            for j in range(m, -1, -1):
                if dp[j] < 0:
                    continue

                # keep as temporary character
                ndp[j] = max(ndp[j], dp[j] + 1)

                # use as next character of t
                if j < m and ch == t[j]:
                    ndp[j + 1] = max(ndp[j + 1], dp[j] + 1)

        else:
            for j in range(m + 1):
                if dp[j] < 0:
                    continue

                # keep dot and pop matched character
                if j > 0:
                    ndp[j - 1] = max(ndp[j - 1], dp[j] + 1)

            dp = ndp
            continue

        dp = ndp

    longest = dp[m]
    print(len(s) - longest)

if __name__ == "__main__":
    solve()
```実装は DP に直接準拠します。`dp[j]`正確に次の状態に到達するすべての方法の中で、保持される文字の最大数を保存します。`j`の登場人物`t`現在スタック内に表されています。 

文字の場合、削除するか、一時的な文字として保持するか、次に一致する文字として使用することがあります。`t`。 文字を保持すると、サブシーケンスの長さが 1 つ増加します。 

ドットの場合、削除しても状態は変わりません。 これを維持するとポップ操作に相当します。 圧縮状態表現では、ポップは一致した 1 文字を削除します。これは、からの遷移によって反映されます。`j`に`j - 1`。 

文字の降順ループにより、新しく更新された状態が同じ反復中に再利用されるのを防ぎます。 これは標準的な 0/1 遷移パターンです。 

最終的な答えは、完全なターゲット文字列を表す状態から得られます。 DP は保持される文字数を最大化するため、から減算します。`|s|`最小の削除数を示します。

    t = data.readline().strip()

    m = len(t)
    NEG = -10**9

    dp = [NEG] * (m + 1)
    dp[0] = 0

                    continue

                if j > 0:

            continue
