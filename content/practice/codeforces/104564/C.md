 ## 問題の理解

 それぞれのフレーズが最初の単語と 2 番目の単語で構成されている 2 単語のフレーズのコレクションが与えられています。 これらのフレーズの中には、学生が提出した本物のものもあれば、捏造されたものもあります。 捏造されたフレーズは、データセット内のどこかに最初の単語として出現する最初の単語と、データセット内の 2 番目の単語として出現する 2 番目の単語を取得し、それらを組み合わせてリストにまだ存在しない新しいペアを作成することによって構築されます。 

目的は、登録シートに最初にどのように書かれたかを仮定した順序に基づいて、偽造される可能性のあるフレーズの最大数を決定することです。 順序が重要なのは、フレーズが作成された時点で、その最初の単語と 2 番目の単語の両方が以前の本物のフレーズにすでに出現している場合にのみ、フレーズを偽造できるためです。 

したがって、私たちは事実上、いくつかのフレーズを本物として指定し、一部を偽物として指定し、本物のフレーズが最初に現れる順序を選択するすべての可能な方法の中で、一貫して説明できる偽のフレーズの最大数は何であるかを尋ねることになります。 

重要な制約は、偽のフレーズによって新しい単語が導入されないことです。 偽のフレーズに出現するすべての単語は、シート上の実際のフレーズにすでに出現している必要があります。重要なことに、単語は、どこかで両方の役割にも出現しない限り、実際のフレーズの中ですでに出現している役割でのみ偽のフレーズで使用できます。 

入力サイズはテスト ケースごとに最大 1000 フレーズになるため、サブセットを超える指数関数はすぐに遅すぎます。 どのフレーズが本物であるかをすべてのサブセットを試す単純なアプローチでは、2^1000 の可能性が必要になりますが、これはまったく実行不可能です。 

両方の立場で単語が頻繁に再利用される場合、微妙な特殊なケースが発生します。 たとえば、すべてのフレーズが同じ最初の単語または同じ 2 番目の単語を共有する場合、両方の側面を実際にカバーしていなければ、新しい組み合わせを「ブートストラップ」する方法がないため、偽造は不可能です。 

もう 1 つのエッジ ケースは、構築されたペアが元のセットにすでに存在する場合です。 たとえ単語を混ぜて作成できたとしても、既存のフレーズと重複している場合は偽物とみなされません。 

## アプローチ

 この問題を考える強引な方法は、フレーズのどのサブセットが本物であるかを選択し、残りのフレーズをある順序で偽物として生成できるかどうかを確認することです。 各サブセットについて、実際のセットから利用可能な最初と 2 番目の単語を徐々に蓄積し、その後、単語がすでに利用可能な偽のペアを繰り返し追加することによって、残りのすべてのペアを構築できるかどうかをシミュレートします。 これには、すべてのサブセットをチェックし、サブセットごとに最大 N 個のフレーズにわたるシミュレーションを実行する必要があり、最悪の場合、およそ O(2^N · N^2) の動作が発生します。 これは中程度の N でも遅すぎます。 

重要な観察は、問題は正確な順序ではなく、選択された実際のフレーズのセットが必要な単語の出現をすべて「カバー」できるかどうかであるということです。 どのフレーズが本物であるかを特定したら、残りのすべてが決まります。最初の単語と 2 番目の単語の両方が実際のセットの投影に出現する場合、そのフレーズは偽物である可能性があります。 

これは問題を次のように再構成します。最初の単語と 2 番目の単語の結合が可能な限り大きくなるように実際のフレーズのサブセットを選択する必要があります。これにより、偽の組み合わせを形成する能力が最大化されるからです。 ただし、対象範囲だけでは十分ではありません。 実際の構造は、偽のフレーズは偽のセットではなく、実際のセットに存在することのみを必要とするということです。 

これは古典的な組み合わせ還元につながります。順序について推論する代わりに、どの単語が利用可能であるかを定義する「基礎」として実際のフレーズのセットについて推論します。 本物のフレーズのセットが固定されると、両方の単語がカバーされているすべてのフレーズがフェイクの候補になります。 

したがって、目的は最大化になります。

フレーズ数から実際のセットのサイズを引いたもの、

 偽のフレーズで使用されるすべての単語は実際のセットの単語セットに出現しなければならないという制約が適用されます。 

対象範囲を超えたフレーズの識別ではなく、単語のみが重要であるという事実を利用できます。 これにより、小さい N に対してはビットマスク スタイルの解決策が得られ、大きい N に対しては代わりに、各フレーズが最初の単語セットと 2 番目の単語セットの間のエッジに寄与する 2 部構成のセットカバー スタイルの最適化として問題を扱います。 最適な戦略は、そうでなければ使用できない必要なすべての単語のペアを「アクティブ化」する最小限のフレーズのセットを見つけることになります。フェイクを最大化することは、必要なリアルを最小限に抑えることと同じです。 

それを確認するためのより実用的な方法は、実際のフレーズの候補セットを修正し、最初と 2 番目の単語のセットを使用して実行可能性を貪欲にチェックすることです。 次に、一貫性を維持できる最小の実セットを検索します。 これは、出現する単語の交差部分に対する組み合わせ推論を使用して解決できます。これは、どちらかの側に新しい単語が導入されるため、どれだけのフレーズが「強制的に本物である」かをチェックすることになります。

 ## アルゴリズムのチュートリアル

 この問題を、フェイクとして分類できるフレーズの数を見つけることとして再定式化します。これは、実際のフレーズのより小さな「コア」セットを使用して両方の単語を説明できるフレーズの数を最大化することと同じです。 

以下のように進めていきます。 

1. 入力セット全体にわたるすべての最初の単語とすべての 2 番目の単語の頻度マップを作成します。 これにより、順序に関係なく、各側でどの単語がグローバルに使用できるかがわかります。 
2. その役割のどこにも現れない最初の単語または 2 番目の単語が含まれているという意味で、「必須の実際」であるフレーズを特定します。 このようなフレーズを削除すると、その位置でその単語が到達できなくなるため、そのようなフレーズを偽造することはできません。 これらは実際のセットに強制的に組み込まれます。 
3. すべての強制フレーズを含む実セットを初期化し、これらの強制実フレーズによって提供される単語を含む seen_first_words と seen_second_words の 2 つのセットを初期化します。 
4. 残りのフレーズを繰り返しスキャンします。 フレーズの最初の単語が seen_first_words にあり、2 番目の単語が seen_second_words にある場合、そのフレーズは偽であると判断されます。 それ以外の場合は、将来のフェイクを有効にするために必要な、これまで欠落していた制約に寄与するため、リアルに昇格する必要があります。 
5. 実際のセットにフレーズを追加するたびに、seen_first_words と seen_second_words を更新し、強制的な追加が発生しなくなるまで続行します。 
6. 安定化後、残りのフレーズはすべて偽の候補になります。 答えは単純に、合計フレーズから実際のフレーズの数を引いたものです。 

重要な考え方は、実際のフレーズが単語の利用可能性の「ジェネレーター」として機能するということです。 単語が現実の側に現れると、それは偽のフレーズを形成するために再利用可能になり、プロセスは終了するまで単調に増加します。 

### なぜ効果があるのか

 どの時点でも、フレーズが実際のものとして不要になるのは、そのフレーズの両方の単語が以前に受け入れられた実際のフレーズからすでに利用可能である場合に限られます。 この条件に違反する場合、そのフレーズは一貫した構造において本物である必要があります。そうでなければ、その単語は必要な役割に導入されないからです。 これにより、単調な閉包プロセスが作成されます。つまり、フレーズが実際であるとみなされると、到達可能な単語セットが拡張されるだけで、以前の決定が無効になることはありません。 アルゴリズムは、残りのすべてのフレーズが既存の単語カバレッジによってサポートされる固定点で正確に停止します。これは、可能な偽の最大数に相当します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(n, topics):
    from collections import defaultdict
    
    first_count = defaultdict(int)
    second_count = defaultdict(int)
    
    for a, b in topics:
        first_count[a] += 1
        second_count[b] += 1
    
    real = set()
    seen_first = set()
    seen_second = set()
    
    changed = True
    while changed:
        changed = False
        
        for i, (a, b) in enumerate(topics):
            if i in real:
                continue
            
            # if already fully supported, it can be fake
            if a in seen_first and b in seen_second:
                continue
            
            # otherwise it must be real
            real.add(i)
            seen_first.add(a)
            seen_second.add(b)
            changed = True
    
    return n - len(real)

def main():
    t = int(input())
    out = []
    for tc in range(1, t + 1):
        n = int(input())
        topics = [tuple(input().split()) for _ in range(n)]
        ans = solve_case(n, topics)
        out.append(f"Case #{tc}: {ans}")
    print("\n".join(out))

if __name__ == "__main__":
    main()
```コードは、増加する「実際の」フレーズのセットと、最初と 2 番目の単語の誘導語彙を維持します。 各反復では、両方の語彙でまだサポートされていないフレーズは実際のものになる必要があるという制約が強制されます。 フルパスで新しい実際のフレーズが生成されなくなると、プロセスは安定します。 

微妙な点は、偽のフレーズを明示的に構築することは決してないということです。 私たちは、語彙がそれらをサポートするのに十分であるかどうかだけを推論します。これにより、実際にソリューションが線形または線形に近い状態を維持できるようになります。

 ## 特殊なケース

 重要なエッジ ケースは、すべてのフレーズが同じ 2 番目の単語を共有する場合です。 この場合、たとえ多くの最初の単語が存在しても、2 番目の単語の多様性はゼロであるため、偽物は決して形成されません。 必要な役割で両方の単語が利用可能になっていないとフレーズをサポートできないため、アルゴリズムはすべてのフレーズを即座に本物として分類します。 

別の特殊なケースは、単語が完全な 2 部構造を形成している場合に発生します。 たとえば、最初の単語が {A, B} で 2 番目の単語が {C, D} で、4 つの組み合わせがすべて存在する場合、両側のロックを解除するために必要な本物のフレーズは 2 つだけで、残りの 2 つは偽物になります。 最初の強制選択により両方の語彙がすぐにシードされ、その後クロージャーが残りのすべてのペアをサポートされているとマークするため、アルゴリズムはこれを処理します。 

最後の微妙なケースは、フレーズが 1 つの位置にある特定の単語の唯一の伝達者である場合です。 このようなフレーズは直ちに実際のセットに強制的に組み込まれ、この伝播により、単語が正しい役割で表現されずに行き詰まることがなくなります。
