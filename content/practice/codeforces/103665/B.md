 ## 解決策
 ## 問題の理解

 私たちには、2 つのエイリアンのアルファベットのどちらかに正確に属する単語が与えられています。 1 つのアルファベットは文字だけを使用します`A`そして`B`、もう一方は数字のみを使用します`0`そして`1`。 タスクは、入力された単語がどのアルファベットに属しているかを判断し、固定の文字ごとのマッピングを使用して他のアルファベットに変換することです。 

マッピングは完全に決定的です。 毎`A`になる`0`、 毎`B`になる`1`、逆にすべての`0`になる`A`、 毎`1`になる`B`。 独立した文字置換以上の構造はないため、単語の長さは変化せず、各位置はコンテキストなしで処理できます。 

入力サイズの制約は小さく、単語の長さは最大 100 文字です。 これは、最大でも 100 文字のチェックと置換を実行するため、最も単純なリニア スキャンでさえ、わずかに高速であることをすぐに示唆します。 O(n²) まではまだ問題ありませんが、O(n) を超える理由はありません。 

エッジケースは最小限ですが、明示的に述べる価値のある微妙なケースがいくつかあります。 語長は 1 にすることができます。たとえば、`A`になるはずです`0`。 同様に、`1`になるはずです`B`。 もう 1 つのケースは、文字列全体がすでにバイナリ形式である場合です。`0101`、完全に文字に変換する必要があります。 不注意な実装では、チェックせずに 1 つのアルファベットを誤って想定する可能性がありますが、保証では、入力は完全に 1 つのアルファベットに属するため、1 回のスキャンで十分に判断できます。 

## アプローチ

 ブルートフォース解釈では、これを一般的な翻訳の問題として扱います。最初にアルファベットの検出を試み、次に置換を繰り返し適用するか、複数回スキャンしながら中間文字列を構築します。 文字列操作を繰り返したり、変更がなくなるまで文字を繰り返しスキャンして置換するネストされたループを使用して文字を置換することを想像することもできます。 変換は単純でローカルであるため、これでも機能しますが、不必要なオーバーヘッドになります。 

重要な観察は、入力が均一であることが保証されていることです。 すべてのキャラクターが出身であるか、`{A, B}`あるいはすべてが出身です`{0, 1}`。 つまり、スキャン時に文字を検査する以外には、複雑な検出や検証ロジックは必要ありません。 1 回のパスで十分です。各文字を対応する文字に直接マッピングし、1 回のスイープで結果を構築できます。 

これにより、問題は直接文字置換問題に還元され、各位置が O(1) で独立して変換され、合計 O(n) の解が得られます。

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`、単語に含まれる文字数がわかります。 実際には処理には必要ありませんが、入力の一貫性が確保されます。 
2. 文字列を読み取ります`s`長さの`n`。 
3. 文字列の最初の文字を検査して、翻訳の方向を決定します。 そうであれば`A`または`B`、次に、アルファベット文字からバイナリ文字に変換します。 それ以外の場合は、次のようになります。`0`または`1`、つまりバイナリから文字に変換します。 この問題により文字列の完全な一貫性が保証されるため、これが機能します。 
4. 出力を効率的に構築するために空のリストまたはバッファを作成します。 リストを使用すると、Python では速度が低下する文字列連結の繰り返しが回避されます。 
5. 文字列内の各文字を繰り返し処理します。 文字ごとに、マッピングを適用します。 

文字からバイナリへのモードの場合は、次のように置き換えます。`A → 0`そして`B → 1`。 

バイナリから文字へのモードの場合は、次のように置き換えます。`0 → A`そして`1 → B`。 

変換された文字を出力バッファに追加します。 
6. バッファを最終文字列に結合して出力します。 

### なぜ効果があるのか

 各文字は他の文字から独立しており、変換規則は 2 つのアルファベット間の全単射です。 これは、すべての有効な入力文字列が、曖昧さなく正確に 1 つの有効な出力文字列にマップされることを意味します。 モードを一度決定し、固定の文字ごとの変換を適用するため、アルゴリズムは位置ごとに正確さを維持します。 どの文字もコンテキストに依存しないため、連鎖的なエラーや状態の破損が発生する可能性はありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    s = input().strip()

    # detect alphabet from first character
    if s[0] in "AB":
        # Dobos -> Femos
        mp = {'A': '0', 'B': '1'}
    else:
        # Femos -> Dobos
        mp = {'0': 'A', '1': 'B'}

    res = []
    for c in s:
        res.append(mp[c])

    print("".join(res))

if __name__ == "__main__":
    solve()
```実装はアルゴリズムに正確に従います。 辞書`mp`変換ルールをエンコードするため、各文字の検索は定数時間になります。 文字列連結による二次的な動作を避けるために、結果はリストに蓄積されます。 方向の決定は最初の文字に基づいて一度行われますが、文字列全体が 1 つのアルファベットに属することが保証されているため安全です。

 ## 特殊なケース

 単一文字入力の場合でも、アルゴリズムはその 1 文字からアルファベットを正しく識別し、マッピングを 1 回適用します。 たとえば、入力`A`マッピングを設定します`{A → 0}`、生成されるとループが実行されます。`0`。 

バイナリ単一文字入力の場合`1`、マッピングは`{1 → B}`、出力は次のようになります`B`。 検出ステップは固定アルファベットのメンバーシップのみに依存しており、それらのアルファベットは互いに素であるため、あいまいさはありません。 

次のような交互の文字列の場合`ABAB`、アルゴリズムは構造を前提とせず、単にインデックスごとのマッピングを適用します。 各位置は独立しているため、位置間の相互作用が正確さに影響することはありません。
