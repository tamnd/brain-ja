 ## 解決策
 ## 問題の理解

 整数座標平面上の一連の点が与えられており、直角三角形を形成するこれらの点の異なる 3 つの要素がいくつあるかを数える必要があります。 点が同一線上にない限り、点のすべてのトリプルは三角形を定義します。角度の 1 つが正確​​に 90 度である三角形のみに関心があります。 

入力サイズは小さく、最大でも 100 ポイントです。 これは、N が 100 に等しい場合、トリプルの数は最大でも約 161700 であるため、点のすべてのトリプルを調べることが実行可能であることをすでに示唆しています。N で 3 次の解は制限内で快適に実行されます。 

問題の微妙な部分は組み合わせ論ではなく幾何学です。 三角形は、その辺のうちの 2 つが垂直である場合にのみ直角です。 座標用語で言えば、これは、共通の端点を共有する点のペア間の垂直ベクトルを検出する必要があることを意味します。 

単純な間違いは、浮動小数点演算やコサイン比較を使用して角度を明示的に計算しようとすることです。 これにより、精度の問題が発生します。 もう 1 つの間違いは、すべてのトリプルをチェックし、一貫した構造を持たずにドット積を計算しようとすることです。これにより、カウントが重複したり、縮退した場合に直角条件が欠落したりすることになります。 

単純な浮動小数点角度チェックの具体的な失敗例としては、(0,0)、(1,0)、(0,1) を期待するなど、完全な直角を形成しているものの、計算や丸めの際に座標がわずかに乱れている点が考えられます。 ここでも傾きの浮動小数点比較は機能しますが、10^9 のような大きな座標に一般化すると、オーバーフローやゼロ除算の処理により傾き比較が危険になります。 

2 番目の問題は、数えすぎです。同じ三角形は 3 つの頂点のそれぞれから識別できるため、不注意なアプローチでは各三角形を複数回数えることになる可能性があります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 点のトリプルをすべて試して、三角形が直角かどうかを確認します。 各トリプル (i、j、k) について、点のペア間の二乗距離を計算し、3 つの可能な順列すべてにピタゴラス条件を適用します。 これが機能するのは、直角三角形の場合、辺の順序が 1 つだけ a^2 + b^2 = c^2 を満たすためです。 

このアプローチは正しいですが、そのコストはトリプルの数 (約 N^3 / 6) によって決まります。N = 100 の場合、これは約 160,000 のチェックに相当し、各チェックには一定の作業が伴います。 これはすでに境界線に達していますが、Python ではまだ許容されます。 ただし、固定頂点での直角に焦点を当てることで、ソリューションをより明確に構造化し、幾何学的な再計算の繰り返しを避けることができます。 

重要な観察は、直角は頂点に対してローカルであるということです。 三角形が点 A で直角である場合、ベクトル AB と AC は垂直になり、それらの内積は 0 になります。 トリプルをグローバルに列挙する代わりに、直角の頂点 A を固定し、A からの垂直方向ベクトルを形成する他の点のペアの数を数えることができます。 

それぞれの固定 A について、他のすべての点へのベクトルを計算し、これらのベクトルのすべてのペアをチェックします。 内積が 0 である各ペアは、A を直角の頂点とする 1 つの直角三角形を構成します。 すべての A を合計すると合計数が得られ、各直角三角形には直角の頂点が 1 つだけあるため、三角形は二重にカウントされません。

 ## アルゴリズムのチュートリアル

 私たちは、すべての直角三角形には直角が位置する固有の頂点があるという事実に依存しています。

1. 潜在的な直角頂点として各点 A を繰り返します。 これにより、A が 90 度の角度を形成する角である三角形のみをカウントすることが保証されます。 
2. 現在の A について、A から 1 つおきの点 B までのすべてのベクトルを計算します。各ベクトルは (dx, dy) = (Bx - Ax, By - Ay) として表されます。 これにより、幾何学的な問題がベクトルの代数に変換されます。 
3. ベクトルのペア (dx1, dy1) と (dx2, dy2) ごとに、それらの内積 dx1 * dx2 + dy1 * dy2 を計算します。 結果がゼロの場合、それらの間の角度は 90 度です。これは、A、B、C が A で直角になる直角三角形を形成することを意味します。このようなペアをそれぞれ数えます。 
4. A のすべての選択肢のカウントを累積します。 

これが機能する理由は、ユークリッド幾何学の垂直性が内積がゼロになることによって正確に捉えられるためです。 各点 A に計算を固定することにより、グローバルな三角形条件をローカルなペア条件に変換します。 

### なぜ効果があるのか

 すべての直角三角形には、直角の頂点が 1 つだけあります。 その頂点 A では、ベクトル AB と AC が垂直になるように、2 つの隣接するエッジが 2 つの別個の点 B と C に対応します。 ドット積テストはこれらのペアを正確に捕捉し、他のペアは捕捉しません。 各三角形は直角の頂点で 1 回だけ寄与し、他の場所では決してカウントされないため、合計は正確です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]
    
    ans = 0
    
    for i in range(n):
        ax, ay = pts[i]
        vecs = []
        
        for j in range(n):
            if i == j:
                continue
            bx, by = pts[j]
            vecs.append((bx - ax, by - ay))
        
        m = len(vecs)
        for j in range(m):
            x1, y1 = vecs[j]
            for k in range(j + 1, m):
                x2, y2 = vecs[k]
                if x1 * x2 + y1 * y2 == 0:
                    ans += 1
    
    print(ans)

if __name__ == "__main__":
    solve()
```解は、潜在的な直角として各点をループします。 このような点ごとに、他の点へのすべての方向ベクトルを構築します。 ベクトルのペアに対する入れ子になったループは、すべての組み合わせをチェックし、ドット積条件を使用して垂直性を検出します。 

微妙な実装の詳細は、同じ頂点からの光線のペアを二重にカウントすることを避けるために、ペア j < k のみを考慮することです。 もう 1 つの重要な点は、ドット積に整数演算を使用することです。これにより、浮動小数点の精度の問題が完全に回避されます。

 ## 特殊なケース

 退化的だが重要なケースは、すべての点が単一線上にある場合です。 この状況では、三角形はまったく存在しないため、答えはゼロになるはずです。 任意の頂点からのすべてのベクトルは同一線上にあり、両方のベクトルが反対方向のスカラー倍数でない限り、どのペアもゼロの内積を持つことはできないため、アルゴリズムはこれを自然に処理します。これは、垂直性を形成する個別の点では起こり得ません。 

もう 1 つのケースは、最小入力サイズです。 点が 3 つ未満の場合は、三角形を形成できません。 外側のループは引き続き実行されますが、内側のベクトル リストのサイズは最大でも 1 であるため、ペアは存在せず、答えは 0 のままです。 

最後のケースは、正方形のような対称的な構成です。 正方形の場合、4 つの頂点のそれぞれは、その 2 つの隣接するエッジに対応する 1 つの直角三角形を構成します。 このアルゴリズムは、各頂点でこれらの寄与を個別にカウントし、各三角形がその直角の隅にのみ関連付けられているため、重複することなく正しい合計を生成します。
