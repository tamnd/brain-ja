 ## 解決策
 ## 問題の理解

 文字列と、その文字を制限された方法で再配置できる 2 種類の動きが与えられています。 1 つの移動は 2 位置離れた文字を交換し、もう 1 つの移動は固定長の連続したブロックを反転します。$k$。 これらの操作は、任意の回数、任意の順序で適用できます。到達可能な辞書編集上の最小の文字列が必要です。 

重要な問題は、これらの操作では一見しただけでは任意の並べ替えができないことです。 2 位置によるスワップ操作では同じパリティのインデックスのみが操作され、反転操作では同じ長さのセグメントのみが混合されます。$k$、微妙な方法でパリティ制約と相互作用する可能性があります。 

入力サイズにより、テスト ケースごとに線形または線形に近いソリューションが得られます。 すべてのテストケースの合計の長さは次のとおりです。$10^5$、操作をシミュレートしたり、位置ごとに並べ替えのような動作を実行しようとするソリューションでは、回避する必要があります。$O(n^2)$行動。 位置をグループ化し、それらのグループ内で文字を並べ替えることに問題を軽減するソリューションを期待する必要があります。 

単純な間違いは、文字列全体を自由にソートできると仮定することです。 たとえば、次のような場合$n=5, k=3$、すべての順列が実現できるわけではなく、やみくもに並べ替えると制約に違反します。 もう 1 つの微妙な失敗は、パリティ構造を無視することによって発生します。それは、スワッピングです。$i$と$i+2$これは、奇数のインデックスにある文字が偶数のインデックスと決して混合しないことを意味するため、文字列を単一のプールとして扱うと正確さが失われます。 

## アプローチ

 制約を無視して、許可されたすべての操作をシミュレートすると、初期文字列から到達可能なすべての順列の状態グラフを探索することになります。 各州には最大で$O(n)$遷移、状態の数は階乗になります。$n$, したがって、これはまったく実行不可能です。 

辞書編集的に改善操作を繰り返し適用して貪欲なシミュレーションを試みても、すぐに問題に遭遇します。反転操作により局所的な進行が元に戻される可能性があり、システムは単純な単調な方法では収束しません。 

このブレークスルーは、問題を 2 つの独立した構造効果に分離することで得られます。 スワップ$i \leftrightarrow i+2$2 つの独立したチェーンを作成します。すべての偶数インデックスはそれらの間で並べ替えることができ、すべての奇数インデックスはそれらの間で並べ替えることができますが、決して混合することはできません。 長さの逆演算$k$これにより、制御された方法でこれらのチェーン全体で文字を並べ替えることができ、$k$2 つのチェーンが相互作用するかどうかを決定します。 

もし$k$が奇数の場合、セグメントを反転するとパリティ位置が保持されるため、偶数位置と奇数位置は永久に分離されたままになります。 この場合、各パリティ クラス内の文字を個別に並べ替えることしかできません。 

もし$k$が偶数の場合、セグメントを反転すると、ブロック内のパリティ アライメントが反転され、パリティ クラス間の交換が効果的に可能になります。 これにより、システムが完全に接続されます。最終的には任意の文字が任意の位置に移動できるため、文字列全体をグローバルに並べ替えることができます。 

したがって、問題は次のようになります。 

いつ$k$奇数の場合は、偶数インデックスの文字と奇数インデックスの文字を別々にソートします。 

いつ$k$が偶数の場合は、文字列全体をソートします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | 指数関数 | 指数関数 | 遅すぎる |
 | パリティ + ソートに関する洞察 |$O(n \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

1. かどうかを確認します。$k$偶数または奇数です。 これにより、位置がパリティ グループ間で交差できるかどうかが決まります。 swap-by-2 ルールのみでパリティが維持されるため、構造が変更されるのは反転のみです。 
2. もし$k$が偶数の場合、文字列のすべての文字を収集し、並べ替えて、小さいものから大きいものへの順序で書き戻します。 その理由は、操作によって完全に接続された置換グループが生成されるため、すべての配置に到達できるためです。 
3. もし$k$が奇数の場合、文字を 2 つのマルチセットに分割します。1 つは偶数インデックスの文字を含み、もう 1 つは奇数インデックスの文字を含みます (0 ベースのインデックスを使用)。 各セットは、次の理由により個別に並べ替えることができます。$+2$スワップしますが、相互作用することはできません。 
4. 両方のマルチセットを個別にソートします。 
5. 対応するパリティ プールから文字を取得し、左から右に位置を埋めて最終文字列を再構築します。 

核となる推論ステップは、奇妙であるということです。$k$この場合、すべての操作でパリティ クラスが保持されます。 スワップ$i \leftrightarrow i+2$明らかにそうです。 長さ-$k$奇数で反転$k$インデックス オフセットを中心を中心に対称的にマップし、各位置のパリティを維持します。 したがって、文字を偶数インデックスから奇数インデックスに、またはその逆に移動する操作はありません。 

いつ$k$が偶数の場合、反転によりセグメント内のパリティが反転されるため、繰り返し適用すると文字列全体でパリティを混合できます。 ローカル スワップと組み合わせると、完全な置換機能が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        s = list(input().strip())

        if k % 2 == 0:
            s.sort()
            print("".join(s))
        else:
            even = []
            odd = []

            for i, ch in enumerate(s):
                if i % 2 == 0:
                    even.append(ch)
                else:
                    odd.append(ch)

            even.sort()
            odd.sort()

            res = []
            ei = oi = 0
            for i in range(n):
                if i % 2 == 0:
                    res.append(even[ei])
                    ei += 1
                else:
                    res.append(odd[oi])
                    oi += 1

            print("".join(res))

if __name__ == "__main__":
    solve()
```解はまずパリティで分岐します。$k$、これが構造的な分割線です。 偶数の場合は、すべての文字が相互に到達可能になるため、グローバル ソートで十分です。 奇妙なケースでは、2 つのソート済みプールを明示的に維持し、パリティ位置を交互に変更することで再構築します。 再構成ステップは線形であり、操作のシミュレーションを回避します。 

実装の微妙な点はインデックス付けです。パリティ分割は Python の 0 ベースのインデックス付けと一致している必要があります。 ここで 1 ベースの推論を混合すると、グループが誤って交換されてしまいます。

 奇数のインデックス: a(1)、d(3)

 ## 特殊なケース

 のような文字列の場合`aaaaa`どれでも$k$、すべての順列が同一であるため、両方の操作は無関係になります。 アルゴリズムは依然として分割または並べ替えを行いますが、結果は変更されないため、誤った再配置は発生しません。 

小さな文字列の場合、$n = 2$または$n = 3$の場合でも、グループの 1 つが空である可能性があり、空のリストの並べ替えは無害であるため、パリティ ベースの分割は依然として正しく動作します。 再構築は単に空ではないプールから取得します。 

次のような交互パターンの場合`ababab`奇数で$k$、分割では構造が正確に保持され、パリティ グループ内での並べ替えにより配置が大幅に変更される可能性がありますが、swap-by-2 接続により到達可能のままです。
