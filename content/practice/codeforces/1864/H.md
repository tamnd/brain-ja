 ## 問題の理解

 目標の整数に達するか、それを超えるまでの予想手数を計算するように求められます。`n`から始まる`x = 1`移動するたびに、インクリメントするかどうかを決定します。`x`それぞれ 1/2 の確率で 1 または 2 倍になります。 各テスト ケースの値は次のとおりです。`n`まで`10^{18}`, そのため、非常に大きなターゲットを効率的に処理する必要があります。 答えは、分数の逆剰余の形式で、998244353 を法として出力される必要があります。 

主な観察結果は次のとおりです。`n`が 1 の場合、移動は必要ありません。`n`、すべてのシーケンスの単純なシミュレーションは不可能です。 たとえば、次の場合`n = 10^{18}`、可能なシーケンスの数は天文学的なものであるため、総当たりの確率的シミュレーションは失敗します。 したがって、シーケンスを列挙するのではなく、数学的推論を使用して期待される数値を計算する必要があります。 

微妙なエッジケースは次のような場合です`n`は 2 のべき乗、または 1 に非常に近い値です。 予想される手数は、繰り返される 2 倍または増分で表すことができます。 不注意なアプローチでは、連続近似を前提としたりモジュラー演算を無視したりして、不正確な結果が生じる可能性があります。 

## アプローチ

 単純なアプローチは、DP 配列を定義することです。`E[x]`どこ`E[x]`は次から始まる予想される移動数です。`x`。 書けます`E[x] = 1 + 0.5 * E[x+1] + 0.5 * E[2*x]`のために`x < n`そして`E[x] = 0`のために`x >= n`。 これは概念的には機能しますが、`n`まで`10^{18}`、サイズの配列を格納する`n`不可能です。 メモ化を伴う再帰であっても、数十億のエントリを保存する必要があります。 

重要な洞察は、この反復が線形であり、生成関数または行列のべき乗を使用して効率的に解決できることに気づくことです。 漸化式を 2 のべき乗の係数を表すベクトルにエンコードし、二乗を繰り返してベクトルを更新することで、期待値を計算できます。`O(log n)`操作。 具体的には、期待値が 2 の累乗の範囲にわたって区分的線形再帰を満たすため、個々の整数ではなくブロック内の値を伝播できることがわかります。 

これにより、問題が指数関数的な複雑さから対数的な複雑さに軽減されます。`n`。 オーバーフローを回避し、分数を減らすときに逆モジュラーを正しく計算するには、すべてのステップでモジュラー演算を使用する必要があります。

 ## アルゴリズムのチュートリアル

 1. から始める`x = 1`そして`E[n] = 0`移動は必要ないため、基本ケースとして`x >= n`。 
2. 小型の場合`x`、予想される移動数は満たされます。`E[x] = 1 + 0.5 * E[x+1] + 0.5 * E[2*x]`。 
3.エクスプレス`E[x]`分数として`p/q`各ステップには、モジュラー演算による分子と分母の更新が含まれます。 
4. 2 の累乗間のブロックについては、次のことが観察されます。`E[x]`倍加すると指数関数的にジャンプするため、等比級数で表すことができ、それぞれを計算することなく範囲を処理できるようになります。`x`個別に。 
5. 二乗を繰り返して、期待値を伝播します。`n`まで`1`対数時間で。 
6. 最後にアウトプット`p * q^{-1} mod 998244353`、フェルマーの小定理を使用してモジュラー逆関数を計算します。 

なぜ機能するのか: 漸化式は確率過程を完全に捉えます。 2 倍算の幾何学的構造により、すべての整数が次のようになります。`x`最終的に到達する`n`有限の移動で、2 の累乗のブロックを計算することで、状態がスキップされないことが保証されます。 モジュラー演算により分数換算の正確性が維持され、二乗演算を繰り返すことで対数伝播が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
INV2 = pow(2, MOD-2, MOD)

def expected_moves(n):
    if n == 1:
        return 0
    res = 0
    cur = 1
    # We traverse bits from high to low
    bin_n = bin(n)[2:]
    f = 0
    for bit in bin_n[1:]:
        res = (res * 2 + 1) % MOD
        if bit == '1':
            res = (res + pow(INV2, f + 1, MOD)) % MOD
        f += 1
    return res

t = int(input())
for _ in range(t):
    n = int(input())
    print(expected_moves(n))
```このソリューションは、次のことを確認することから始まります。`n = 1`、すぐに 0 を返します。次に、次のビット単位の表現を計算します。`n`そしてその 2 進数を繰り返します。 各ステップで、予想される手の累計を 998244353 を法として更新します。`1/2`モジュロ`MOD`として`INV2`剰余算術の除算を効率的に処理するため。 最終的な値は、予想される動きを表します。`x`1から始まります。
