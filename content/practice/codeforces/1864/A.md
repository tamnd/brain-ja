 ## 解決策
 ## 問題の理解

 この問題により、次の 3 つの整数が得られます。`x`、終了値`y`、および長さ`n`。 配列を構築する必要があります`a`長さの`n`それはで始まります`x`そしてで終わります`y`は厳密に増加しており、連続差は厳密に減少しています。 言い換えれば、もし`b_i = a_{i+1} - a_i`、 それから`b`厳密に減少するシーケンスを形成する必要があります。 

これは難しいです。`b`連続する要素間の可能な間隔を制限します。 たとえば、最初の差は 2 番目の差よりも大きく、2 番目の差は 3 番目の差よりも大きくなければなりません。 からの範囲であれば、`x`に`y`に比べて小さすぎます`n`、厳密に増加する差と厳密に減少する差の両方を同時に満たすことは不可能な場合があります。 

制約は小さいです。`x`、`y`≤ 1000、`n`≤ 1000、および`t ≤ 1000`。 これは、大まかに実行されるソリューションを意味します`O(n)`テストケースごとに許容されます。 シーケンスの数は組み合わせによって増加するため、すべてのシーケンスを強引に列挙することは不可能ですが、貪欲または数学的な構築は実用的です。 

重要なエッジケースが発生するのは、`n`は 3 (最小サイズ) です。 ここで必要な違いは 2 つだけです。 例えば、`x=1, y=3, n=3`厳密に減少する 2 つの正の差が必要であるため、これは不可能です。 唯一可能なペア`(d1, d2)`と`d1 > d2 > 0`必要だろう`d1 + d2 = y - x = 2`。 しかし、正の整数の最小の減少ペアは次のとおりです。`(2,1)`の合計は 3 となり、2 より大きくなります。したがって、正しい出力は次のようになります。`-1`。 

## アプローチ

 ブルートフォースアプローチでは、長さのすべてのシーケンスが試行されます。`n`から始まる`x`そして終わる`y`、厳密に増加と減少の差をチェックします。 考えられるそれぞれの選択肢に対して、`a_2`、 それから`a_3`など、アルゴリズムは差が減少するかどうかを検証します。 これは指数関数的です`n`そして明らかに実行不可能です`n=1000`。 

より高速な解決策の重要な観察は、長さの差分シーケンスが厳密に減少することです。`n-1`逆順の連続する整数で表すことができます。 違いを次のように定義するとします。`d, d-1, d-2, ..., d-(n-2)`。 これらの差の合計は等しくなければなりません`y-x`、つまり、```
d + (d-1) + (d-2) + ... + (d-(n-2)) = (n-1)*d - (n-2)*(n-1)/2 = y - x
```この方程式から、最大の整数を求めることができます。`d`すべての差を正に保ちながら合計条件を満たします。 一度`d`順序が決まります`a`から順に差分を加算することで再構成されます。`x`。 この貪欲なアプローチが機能するのは、合計距離の合計となる連続する差分を減少させることで有効なシーケンスが生成され、最大の開始差分を使用するとすべての差分が確実に正の値を維持できるためです。

 | 数学的構築 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 合計の差を計算します`diff = y - x`。 これは、私たちの差異が減少するにつれて達成しなければならない合計です。 
2. 考えられる最後の相違点から開始します`d = 1`そして、長さの減少シーケンスの合計かどうかを段階的にチェックします`n-1`一致することができます`diff`。 数式を使用する`(n-1)*d - (n-2)*(n-1)/2`。 必要です`d`すべての差を正に保ちながら、できるだけ大きくする必要があります。 
3. 1回`d`が決定されたら、次のように差のシーケンスを生成します。`[d, d-1, ..., d-(n-2)]`。 
4.初期化`a[0] = x`そして、各差分を繰り返し追加して残りのシーケンスを生成します。 
5. 陽性でない場合`d`合計方程式を満たしている場合、戻り値`-1`そのテストケースに対して。 

機能する理由: 合計の公式により、一連の差分が次の距離を正確にカバーすることが保証されます。`x`に`y`。 連続して減少する整数を使用すると、差が厳密に減少し、次から始まることが保証されます。`x`厳密に増加する配列を生成します。 不変条件は、各ステップで、残りの距離が正の差が減少するように残りの位置に分配できることです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x, y, n = map(int, input().split())
        total = y - x
        found = False
        for d_last in range(1, total + 1):
            # Sum of n-1 decreasing differences starting from d
            # Let largest difference be d
            # Sum = (n-1)*d - (n-2)*(n-1)//2
            d = (total + (n-2)*(n-1)//2) // (n-1)
            if d*(n-1) - (n-2)*(n-1)//2 == total and d > 0:
                a = [x]
                curr = x
                for i in range(n-1):
                    curr += d
                    a.append(curr)
                    d -= 1
                print(" ".join(map(str, a)))
                found = True
                break
        if not found:
            print(-1)

if __name__ == "__main__":
    solve()
```このソリューションでは、最初に、導出された式を使用して最小開始差分が計算されます。 各ステップで差を 1 ずつ減分して配列を構築します。 ループチェック`d_last`最適化することもできますが、この形式は明確であり、制約内で機能します。 重要な微妙な点には、差がプラスのままであること、および合計が正確に等しいことを確認することが含まれます。`y - x`。
