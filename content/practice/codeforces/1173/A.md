 ## 解決策
 ## 問題の理解

 この問題では、単純な投票シナリオの結果を判断することが求められます。 投票者には 3 つのカテゴリがあります。賛成票を投じることが保証されている人、反対票を投じることが保証されている人、そして未定の人です。 入力により、各グループのカウントが得られます。 目標は、投票の最終結果 (肯定的、否定的、中立、不確実) を予測することです。 賛成票が反対票を厳密に上回っている場合は肯定的な結果が得られ、反対票が賛成票を厳密に上回っている場合は否定的結果が発生し、両者が等しい場合は中立であり、未知の投票者が投票方法に応じて結果を変える可能性があるかどうかは不確実です。 

制約は非常に小さいです。各カウントは最大 100 なので、投票者の総数は最大 300 です。これにより、効率を気にせずにすべての可能性を推論することができます。 狭い範囲での反復処理ではパフォーマンスの懸念はありませんが、考えられる投票合計の範囲を分析して定数時間の解決策を目指す必要があります。 

明らかではないエッジケースには、未知の投票によって結果が逆転する可能性がある状況が含まれます。 たとえば、賛成票と反対票が同数で、不明な投票者が少なくとも 1 人いる場合、1 票でバランスが崩れる可能性があるため、結果は不確実です。 もう 1 つのエッジ ケースは、賛成票 10 票、反対票 2 票、不明票 3 票など、不明票をすべてもう一方の側に割り当てた後でも、一方の側が優勢である場合です。 ここでは、たとえすべての不明票が反対票を投じたとしても、結果は間違いなく肯定的です。 

## アプローチ

 強引なアプローチでは、無名の有権者が投票できるあらゆる方法が考慮されることになる。 あれば`z`未知の有権者がいる`z+1`賛成票と反対票の間で分散する方法。 分布ごとに、最終結果を計算します。 すべての結果が同じであれば、それが最終結果です。 それ以外の場合、結果は不確実です。 これが機能する理由は、`z`は最大 100 なので、最大 101 個の可能性を計算します。 この問題は実際には実現可能ですが、その必要はなく、簡略化することができます。 

重要な観察は、賛成票と反対票の間の可能な最小値と最大値の差のみが必要であるということです。 最小の差は、未知の有権者が全員反対票を投じた場合に発生し、最大の差は全員が賛成票を投じた場合に発生します。 両方の極値が同じ符号を示す場合、結果が決定されます。 それ以外の場合は不確実です。 これにより、問題が少数の比較に減り、O(1) の解決策が生成されます。

 ## アルゴリズムのチュートリアル

 1. 保証された賛成票を表す 3 つの整数を読み取ります。`x`、反対票を保証`y`、不明票`z`。 
2. 考えられる最大純投票差を次のように計算します。`x + z - y`、すべての不明票が賛成票であると仮定します。 
3. 可能な最小の純投票差を次のように計算します。`x - (y + z)`、すべての未知の投票が反対票であると仮定します。 
4. 最大値と最小値の両方が厳密に正の場合、最悪のシナリオでも賛成票が反対票を上回るため、「+」を出力します。 
5. 最大値と最小値の両方が厳密に負である場合は、「-」を出力します。これは、未知の投票のすべての可能な割り当てにおいて反対票が優勢であるためです。 
6. 最大値と最小値の両方がゼロの場合、未知の投票に関係なく投票は同点であるため、「0」を出力します。 
7. それ以外の場合は、「?」を出力します。これは、未知の投票の割り当てが異なると異なる結果が生じる可能性があり、結果が不確実になる可能性があることを示します。 

それが機能する理由: 極端なシナリオのみを考慮することで、起こり得るあらゆる結果を把握します。 未知の投票が分布すると、これら 2 つの極端な値の間の結果が生成されます。 両方の極端な結果が同じ結果になる場合、すべての中間分布も同じ結果になります。 両極端が異なる結果を生成する場合、それぞれの結果を生成する何らかの割り当てが存在し、不確実性を意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

x, y, z = map(int, input().split())

max_diff = x + z - y
min_diff = x - (y + z)

if min_diff > 0:
    print("+")
elif max_diff < 0:
    print("-")
elif min_diff <= 0 <= max_diff and max_diff == 0 and min_diff == 0:
    print("0")
else:
    print("?")
```コードは投票数を読み取り、極端な投票差を計算し、これらの極端な結果に基づいて結果を決定します。 微妙な点は、ゼロの場合を慎重に処理することにあります。両方の極値が正確にゼロの場合、結果は中立です。 そうしないと、極値がゼロを挟んで異なる場合、結果は不確実になります。 ループや追加のデータ構造は必要ありません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    x, y, z = map(int, input().split())
    max_diff = x + z - y
    min_diff = x - (y + z)
    if min_diff > 0:
        return "+"
    elif max_diff < 0:
        return "-"
    elif min_diff <= 0 <= max_diff and max_diff == 0 and min_diff == 0:
        return "0"
    else:
        return "?"

# Provided samples
assert run("3 7 0\n") == "-", "sample 1"
assert run("3 1 2\n") == "+", "sample 2"
assert run("1 1 0\n") == "0", "sample 3"
assert run("1 0 1\n") == "?", "sample 4"

# Custom cases
assert run("0 0 0\n") == "0", "all zero votes"
assert run("100 0 0\n") == "+", "max upvotes only"
assert run("0 100 0\n") == "-", "max downvotes only"
assert run("50 50 0\n") == "0", "tie with no unknowns"
assert run("50 49 1\n") == "?", "tie possible with one unknown"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 0 0 0 | 0 | 最小の入力、中立的な結果 |
 | 100 0 0 | + | 最大の賛成票が優勢 |
 | 0 100 0 | - | 最大の反対票が優勢 |
 | 50 50 0 | 0 | 未知数のないネクタイ |
 | 50 49 1 | ? | 単一の未知によってもたらされる不確実性 |

 ## 特殊なケース

 次のような未知の投票によって結果が変わる可能性がある場合`1 0 1`、アルゴリズムは正しく計算します`max_diff = 2`そして`min_diff = 0`。 極値は両方とも厳密に正、負、または正確にゼロではないため、出力は「?」となり、不確実性が得られます。 

すべての投票が既知でバランスが取れている場合、たとえば`2 2 0`、両方の極値がゼロに等しく、出力は「0」になります。 

未知数の票でも一方が優勢な場合など`10 2 3`、極端なものは`11`そして`5`、両方とも正であるため、アルゴリズムは「+」を出力し、賛成票の優位性を正しく確認します。
