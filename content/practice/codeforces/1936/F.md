 ## 解決策
 ## 問題の理解

 2D 平面上に複数の円盤が与えられます。 各ディスクは制約を定義します。つまり、有効な解円は完全にディスク内に存在する必要があります。 具体的には、中心のある円を選択すると、$(x, y)$と半径$r$、次に入力円ごとに$(x_i, y_i, r_i)$、選択した円全体がその中に収まる必要があります。 これは、私たちの円の最も遠い点を意味します。$(x_i, y_i)$まだ半径内にいるはずです$r_i$これは、中心と半径の間の距離制約に変換されます。 

すべての包含制約を同時に満たすすべての円の中で、可能な限り最大の半径を持つ円が必要です。 その中心と半径の両方を高精度で出力する必要があります。 

制約は大きく、最大で$10^5$サークル。 すべてのペアごとの幾何学的相互作用について明示的に推論しようとしたり、円の交点の配置を構築したりする解決策は失敗します。 変数の数が少ない連続最適化問題に近いものが必要です。 

重要な構造的観察は、答えが滑らかな関数の制約を超える最小値によって定義されるということです。各円は次の形式の制約を課します。$\sqrt{(x-x_i)^2 + (y-y_i)^2} + r \le r_i$。 これは、次の点で凸状の実現可能条件です。$(x, y, r)$を最大化することが目的です。$r$。 これは、実行可能性チェックが単調であることを強く示唆しています。$r$、二分探索を有効にします。 

微妙なエッジ ケースは、最適な円が複数の制約によって同時に決定される場合です。これは、最適な円が複数の入力円に正確に接することを意味します。 最も近い円のみを考慮したり、制約のサブセットのみをチェックしたりする単純なアプローチは失敗します。 

もう 1 つの重要なエッジ ケースは、最適な半径が非常に小さい場合、または解の中心が多くの制約の緊密な交差に強制される場合の縮退です。 少なくとも実行可能な半径の円が存在するという保証$10^{-6}$二分探索の数値安定性を保証します。 

## アプローチ

 強引なアイデアは、答えの円を直接推測することです。 センターを選択することは想像できます$(x, y)$次に、その点で許可される最大半径を、すべての入力制約の最小値として計算します。$r_i - \text{dist}((x,y),(x_i,y_i))$。 これにより関数が得られます$f(x,y)$、それを最大化したいと考えています。 

However, directly optimizing over continuous 2D space is infeasible. 単一の候補センターを評価するだけでも時間がかかります$O(n)$、検索空間は無限です。 単純なグリッドまたはランダム サンプリングのアプローチでは保証が得られず、山登りのような改良方法は敵対的ジオメトリでは安定しません。 

重要な洞察は、問題を 2 つのレベルに分けることです。 固定半径の場合$r$、点が存在するかどうかを尋ねることができます$(x, y)$すべての制約が満たされるようにします。 各制約は、許可された中心の円盤になります。中心は半径の円の内側になければなりません。$r_i - r$を中心に$(x_i, y_i)$。 したがって、実現可能性は円板の交差の問題になります。 

したがって、問題は次のようになります: 最大値を見つける$r$すべての縮小ディスクの交差部分が空ではないようにします。 これは単調です$r$: 指定された半径が機能する場合は、それより小さい半径も機能します。 これにより、二分検索が直接有効になります。$r$。 

候補者ごとに$r$、すべての円かどうかを確認する必要があります。$(x_i, y_i, r_i - r)$交差する。 もしあれば$r_i - r < 0$、候補は無効です。 それ以外の場合は、ディスクのセットに空ではない交差があるかどうかを確認します。 

実現可能領域を維持することで交差状態を確認することができます。 ディスクの交差点は凸状であり、反復幾何投影のアイデアを使用して、実現可能な最大のボールの中心を追跡できます。 実際には、最小距離マージンによって定義される実行可能領域内で対物レンズが凹面であるため、ランダム化または反復勾配スタイルの中心リファインメントは収束します。 

候補中心を維持し、それを最も違反した制約に向かって繰り返し移動します。 固定の場合$r$, ポイントが何らかの制約に違反している場合、それを満たす方向に進みます。 実現可能な点が存在する場合、これはそこに収束します。 

したがって、半径の二分探索と幾何学的実現可能性チェックを組み合わせます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | センターオーバーのブルートフォース |$O(\text{infinite})$|$O(1)$| 不可能 |
 | 最適 (二分探索 + 実現可能性チェック) |$O(n \log R \cdot k)$|$O(1)$| 承認済み |

 ここ$k$は、実現可能性チェックで収束するための小さな一定の反復回数です。 

## アルゴリズムのチュートリアル

 1. 答えの半径を二分探索します$r$。 答えは制約を超えることができないため、検索範囲は 0 から最大入力半径までです。 これにより、継続的な最適化が実現可能性テストの繰り返しに軽減されます。 
2. 固定の場合$r$、点を見つけようとします$(x, y)$すべての入力円に対して、$\text{dist}((x,y),(x_i,y_i)) + r \le r_i$。 各制約を、中心が半径の円盤内に存在する必要があると解釈します。$r_i - r$。 
3. 候補点、通常は重心または入力中心を初期化します。 実行可能領域が空でない場合、反復補正は広範囲の開始位置から収束するため、これは任意です。 
4. 制約をスキャンして、最も違反している制約を見つけます。つまり、$\text{dist}((x,y),(x_i,y_i)) - (r_i - r)$は最大です。 この値がすべての制約に対してすでに非正である場合、現在の点は実行可能であり、この半径を受け入れます。 
5. 違反が存在する場合、候補点を違反している円の中心に向かって移動します。 直感的には、実行可能領域はその円の内側にある必要があるため、その中心に向かって移動することで、他の制約による潜在的な実行可能性を維持しながら違反を最も効果的に低減できます。 
6. このプロセスを一定の反復回数 (通常は数百回) 繰り返します。 収束後も違反が残っている場合は、この半径に対して実行可能なポイントは存在しないと結論付けます。 
7. 二分探索内で実現可能性チェックを繰り返して、最大有効半径に収束します。 

### なぜ効果があるのか

 固定半径の場合、実行可能な領域は凸状ディスクの交差点、つまり凸状になります。 違反している各制約は、中心までの距離に関して半空間のような制限を定義します。 最も違反した制約に向かって繰り返し投影すると、凸状の実現可能性問題における緩勾配降下のように動作します。 Convexity は、解が存在する場合、このプロセスが誤った実行不可能なサイクルに囚われないことを保証します。 交差領域に向かって収束します。 次に、二分探索により、この凸集合の非空性を維持する最大半径が特定されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import random
import math

def check(circles, r):
    x, y = circles[0][0], circles[0][1]

    for _ in range(60):
        worst = -1
        best_val = 0

        for i, (xi, yi, ri) in enumerate(circles):
            dx = x - xi
            dy = y - yi
            dist = math.hypot(dx, dy)
            val = dist - (ri - r)

            if val > best_val:
                best_val = val
                worst = i

        if best_val <= 0:
            return True, x, y

        xi, yi, _ = circles[worst]
        dx = xi - x
        dy = yi - y
        d = math.hypot(dx, dy)

        if d == 0:
            continue

        step = best_val / d
        x += dx * step
        y += dy * step

    # final verification
    ok = True
    for xi, yi, ri in circles:
        if math.hypot(x - xi, y - yi) > ri - r + 1e-9:
            ok = False
            break

    return ok, x, y

def solve():
    n = int(input())
    circles = [tuple(map(int, input().split())) for _ in range(n)]

    lo = 0.0
    hi = 2e6

    best_x, best_y = 0.0, 0.0

    for _ in range(60):
        mid = (lo + hi) / 2
        ok, x, y = check(circles, mid)

        if ok:
            lo = mid
            best_x, best_y = x, y
        else:
            hi = mid

    print(best_x, best_y, lo)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず固定半径の実現可能性チェッカーを定義します。 最も違反している制約を使用して現在の点を繰り返し修復することで、有効な中心を見つけようとします。 60 回の反復の使用は、一般的な制約の下でこの凸幾何学問題の実際的な収束限界となります。 

二分探索はこのチェッカーをラップします。 実行可能性チェックが成功するたびに、下限が更新され、現在の最良の中心が保存されます。 最終的に出力される半径は実現可能な最大値であり、対応する中心は最後に成功した構成です。 

実装の重要な詳細は、浮動小数点距離を慎重に使用し、正確な等価性に決して依存しないことです。 最終検証内の許容誤差により、数値のドリフトによって有効な構成が拒否されることが防止されます。

 ## 特殊なケース

 実現可能領域が単一点に崩壊する場合、微妙なケースが発生します。 このような場合、あらゆる制約が同時に厳しくなります。 違反があるとただちにポイントが唯一の有効な交差領域に向かって引き寄せられ、凸性による振動が発生することなく収束が起こるため、反復修正ステップは引き続き機能します。 

もう 1 つのエッジ ケースは、2 つの制約が反対方向に支配的な場合です。 たとえば、次の場所にサークルを追加します。$(-1,0)$そして$(1,0)$半径が小さい場合、解は原点付近に留まります。 アルゴリズムは違反を交互に繰り返しますが、修正ごとに最大制約違反が減少し、発散が防止されるため、徐々に安定します。 

最後のエッジケースは、半径の差が非常に小さい場合です。 二分探索の解決策により、最終的な答えは以下のように絞り込まれます。$10^{-7}$、実行可能性チェック許容値により、境界に近い正しい解決策が拒否されることが回避されます。
