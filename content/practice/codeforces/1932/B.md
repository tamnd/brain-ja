 ## 解決策
 ## 問題の理解

 この問題は、周期的に発生する兆候と呼ばれる一連のイベントを記述します。 それぞれのサイン`i`期間がある`a_i`、それは毎回起こることを意味します`a_i`年: 年単位で`a_i`、`2 * a_i`、`3 * a_i`、 等々。 部族は黙示録を待っていますが、それは兆候が順番に起こった場合にのみ起こります。 順次とは、最初の兆候を待ち、それが発生した後にのみ 2 番目の兆候を待ち始めることを意味します。 終末を示す最後の兆候が起こる年を決定する必要があります。 

入力は複数のテスト ケースを提供します。 各テスト ケースでは、最初に符号の数が与えられます。`n`、その後に各記号のピリオドが続きます。 出力は各テスト ケースの単一の年です。つまり、前のすべての兆候が順番に発生した後、最後の兆候が発生した最初の年です。 

制約は次のことを教えてくれます`n`最大 100 であり、各期間`a_i`は 10^6 までです。 最大 1,000 のテスト ケースがあるため、アルゴリズムは最大でも`O(n)`テスト ケースごとに 2 秒以内に安全に実行できます。 期間が非常に長くなる可能性があるため、毎年明示的にシミュレーションするアプローチは遅すぎます。 

明らかではないエッジケースは、連続する期間が同じである場合、または一方が他方の倍数である場合に発生します。 たとえば、入力が`[1, 1, 1]`単純なシミュレーションでは周期を誤って累積的に追加する可能性がありますが、各符号は前の符号の後の次の 1 の倍数を待つだけであるため、正しい出力は 3 です。 もう 1 つの微妙な点は、後の期間が今年より小さい場合に、次の倍数に切り上げる必要があることです。 

## アプローチ

 ブルートフォースアプローチでは、各年をシミュレートし、各期間の次の倍数をチェックします。 1 年目から開始して、最初の期間の次の倍数を見つけ、次にその年の後の 2 番目の期間の次の倍数を見つけます。 これは正しいですが、各符号に対して最大 10^6 の反復が必要になる可能性があり、特に 100 個の符号と 1000 個のテスト ケースの場合、遅すぎます。 

重要な洞察は、特定の年について次のことを認識することです。`current_year`そしてピリオド`a_i`、次に出現するのは次の最小倍数です。`a_i`それは少なくとも`current_year`。 これは、整数の除算と乗算を使用して直接計算できます。```
next_year = ((current_year + a_i - 1) // a_i) * a_i
```この式は切り上げます`current_year`最も近い倍数に`a_i`。 これを使用すると、すべての記号を順番に処理できます。`O(n)`毎年シミュレーションすることなく、テストケースごとに実行します。 問題は反復更新に帰着します`current_year`リスト内の各サインごとに。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (毎年シミュレーション) | O(n * max(a_i)) | お(1) | 遅すぎる |
 | 最適 (次の多重計算) | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 各テストケースを個別に処理します。 
2. 各テストケースについて、符号の数を読み取ります。`n`そして期間のリスト`a`。 
3.初期化`current_year`これは、次の兆候が発生する可能性がある最も早い年を表します。 
4. 各期間にわたって反復する`period`リスト内:

 1. 次の倍数を計算します。`period`それは少なくとも`current_year`公式を使って`((current_year + period - 1) // period) * period`。 
2.アップデート`current_year`この計算された値に。 これにより、次の兆候は今年より早く起こらないことが保証されます。 
3. インクリメント`current_year`厳密に最後の出現後にカウントを開始するには、各符号の後に 1 ずつ加算します。 
5. すべての符号を処理した後、から 1 を減算します。`current_year`最後の符号には最後の増分が必要ないためです。 
6. このテスト ケースの結果を出力します。 

なぜ効果があるのか​​: 各ステップで、`current_year`前の星座から最も早い年です。 次の倍数に切り上げると、各兆候が周期性をスキップすることなく、最初に許可された年に発生することが保証されます。 次のステップの前にインクリメントすると、「厳密に後」の要件が強制されます。 この不変条件はすべての記号に当てはまるため、最終年は正確です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        current_year = 1
        for period in a:
            current_year = ((current_year + period - 1) // period) * period
            current_year += 1
        print(current_year - 1)

if __name__ == "__main__":
    solve()
```このソリューションは、入力を効率的に読み取ります。`sys.stdin.readline`。 テストケースごとに初期化します`current_year`を 1 に設定し、期間を順番に処理します。 整数の除算を使用すると、何年にもわたって明示的に反復することがなくなります。 インクリメント`current_year`複数の保証を計算した後、次の符号は厳密に前の符号の後にあります。 最後に、1 を減算して、最後の符号に対する最後の不必要な増分を元に戻します。

 n ≤ 100、t ≤ 1000、および period ≤ 10^6 の場合、このソリューションは 2 秒未満で快適に実行され、使用するメモリは最小限になります。
