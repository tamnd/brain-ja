 ## 解決策
 ## 問題の理解

 私たちに与えられたタイムラインは、`n`ステップと`m`猫、それぞれが間隔によって定義される`[l_i, r_i]`その間にそれが現れます。 各ステップで、存在するすべての猫に餌を与えることができますが、猫に複数回餌を与えると損失が発生します。 私たちの仕事は、猫に二度餌を与えないように猫に餌を与えるいくつかの手順を選択し、餌を与える猫の総数を最大化することです。 

入力は複数のテスト ケースを記述します。 各テスト ケースが提供するのは、`n`そして`m`に続く`m`間隔。 出力はテスト ケースごとに 1 つの整数、つまり餌を与えることができる猫の最大数です。 

制約により許可されるのは、`n`まで`10^6`そして`m`まで`2*10^5`テスト ケースごとに異なりますが、すべてのテストの合計は制限されています。 これは、アルゴリズムが`O(n * m)`複雑さが遅すぎる。 もっと近いものが必要です`O(m log m)`または`O(n + m)`。 各間隔は少なくとも 1 ステップの長さであるため、次のような些細なケース`l_i = r_i`対処しなければなりません。 

明らかではないエッジ ケースには、完全に重なっている複数の間隔、長さ 1 の間隔、および非常に大きい間隔が含まれます。`n`まばらな間隔で。 すべてのステップをすべての間隔に対してチェックする単純なアプローチは失敗します。 たとえば、2 匹の猫がまったく同じ階段に現れた場合、`[1, 5]`そして`[1, 5]`、不注意で貪欲な餌やり戦略は、1 匹の猫がステップを選択した場合に餌を与えすぎてしまう可能性があります。`1`両方にとって。 このような場合の正しい出力は次のとおりです。`1`、階段の1つで1匹の猫にのみ餌を与えます。 

## アプローチ

 ブルートフォースアプローチは、ステップのすべてのサブセットを考慮することです。`1`に`n`そして、重複せずにカバーされる間隔の数を数えます。 これは理論的には正しいですが、次の点まで確認する必要があるため実行できません。`2^n`サブセット。 すべての間隔ですべてのステップを繰り返すだけでも、`O(n*m)`最大の制約に対して遅すぎる操作 (`10^6 * 2*10^5`）。 

重要な洞察は、猫に餌を与えるのは間隔内に 1 回だけで十分であるということです。 したがって、これを間隔スケジュールの問題としてモデル化できます。各間隔に最大 1 つの点が含まれるように点を選択します。 適切なエンドポイントで間隔を並べ替え、フィードする最も早い可能なステップを貪欲に選択すると、競合せずにカバーされる間隔の数が最大化されます。 これが機能するのは、可能な限り早い段階で給餌すると、重複する間隔で将来競合が発生する可能性が最小限に抑えられるためです。 

欲張りな選択は、正しいエンドポイントで間隔を並べ替えることです`r_i`そしてそれらを繰り返し処理し、最後に実行したステップを追跡します。 インターバルごとに`[l_i, r_i]`、最後の供給ステップが間隔外の場合、次の時点で供給できます。`r_i`。 それ以外の場合はスキップします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * m) | O(n + m) | 遅すぎる |
 | 間隔ソートによる貪欲 | O(m log m) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`そして`m`。 間隔の空のリストを初期化します。 
2. を読んでください。`m`間隔`[l_i, r_i]`そしてそれらをリストに保存します。 
3. 間隔を正しいエンドポイントで並べ替えます`r_i`。 分類することで、最も早く出発した猫から先に餌を与えることが確実に考慮されます。 
4. 変数を初期化する`last_fed = -1`猫に餌を与えた最後のステップを追跡するため。 
5.初期化`count = 0`餌を与えた猫の数を追跡するため。 
6. ソートされた間隔で反復する`[l_i, r_i]`：

- もし`last_fed < l_i`、これは、最後の給餌ステップがこの間隔と競合しないことを意味します。 
- ステップでフィード`r_i`そしてセット`last_fed = r_i`。 
- インクリメント`count`。 
- もし`last_fed >= l_i`、今すぐ餌を与えると猫に餌を与えすぎてしまうため、この間隔はスキップしてください。 
7. すべての間隔を処理した後、印刷します。`count`このテストケースでは。 

機能する理由: 適切なエンドポイントで分類することで、将来の給餌の機会を最大化する、ローカルで貪欲な選択を常に行うことができます。 餌をあげたら`r_i`、前の間隔または重複する間隔によって選択が無効になることはなく、猫に二度餌を与えることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def feed_cats():
    t = int(input())
    results = []
    for _ in range(t):
        n, m = map(int, input().split())
        intervals = []
        for _ in range(m):
            l, r = map(int, input().split())
            intervals.append((l, r))
        # Sort by right endpoint
        intervals.sort(key=lambda x: x[1])
        last_fed = -1
        count = 0
        for l, r in intervals:
            if last_fed < l:
                last_fed = r
                count += 1
        results.append(str(count))
    print("\n".join(results))

if __name__ == "__main__":
    feed_cats()
```このコードはアルゴリズムに正確に従います。 並べ替え順`r_i`貪欲な選択が有効であることを保証します。`last_fed`最後の給餌ステップを追跡します。 条件`last_fed < l`猫に二度餌を与えないことを保証します。 使用する`sys.stdin.readline`大規模なテスト ケースの高速入力を保証します。

 ## 特殊なケース

 すべての間隔が完全に重なっている場合でも、アルゴリズムは競合しない給電点のみを選択します。 入力用`[1,3],[1,3],[2,3]`、最初の間隔ではステップ 3 で餌を与えますが、last_fed が競合する場合は 2 番目と 3 番目の間隔をスキップし、結果として 2 匹の猫に最適な餌を与えることになります。 長さが 1 の間隔は同じように扱われます。 状態`last_fed < l`過給を正しく防ぎます。 間隔が疎であっても、余分なステップが発生することはありません。 アルゴリズムは自然に次の有効な給餌ステップにジャンプします。
