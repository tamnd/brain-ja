 ## 解決策
 ## 問題の理解

 一連の長方形の構成要素が与えられ、それを 1 つずつ追加して、より大きな長方形のベースを構築します。 初日の後は、単一の長方形から始めます。 その後毎日、新しい長方形が現在の形状に全辺に沿って取り付けられます。取り付けのたびに、構造全体が依然として長方形を形成する必要があります。 

新しいブロックはそれぞれ、取り付ける前に 90 度回転できます。 接続ルールは厳密です。新しいブロックの 1 つの側面が現在の長方形の完全な側面と正確に一致する必要があり、ブロックはその側面に沿って接着されます。 接着後の結果は依然として長方形のままです。これは、アタッチメントが突起や穴を作成することなく、以前の長方形を一方向に効果的に拡張することを意味します。 

与えられたブロックのシーケンスが、これらの制約を満たす何らかの有効な方法で配置できるかどうかを判断することが求められます。 可能であれば、可能なすべての最終的な長方形の寸法を出力する必要があります。 2 つの長方形は、幅と高さを入れ替えるだけで異なる場合、同じとみなされます。 

n が 100000 までの制約は、ほぼ線形または線形に近い処理が必要であることを意味します。 すべての配置を試行したり、大規模な幾何学的構成を維持したりするアプローチは失敗します。すべてのアタッチメントをすべての向きと側面で試行すると、単純な状態の数が指数関数的に増加するためです。 

素朴な推論における主な危険は、一度長方形が形成されると、将来の添付ファイルは独立して動作すると仮定することです。 実際には、各アタッチメントは、以前のすべての選択のジオメトリと方向の両方を制限します。 

向きの選択が複雑になると、微妙な失敗例が発生します。 

入力```
2
2 3
3 4
```単純な貪欲なアプローチでは、2×3 をアタッチしてから 3×4 拡張する可能性がありますが、最初のブロックが 2×3 として扱われるか 3×2 として扱われるかによって、2 番目のステップが適合するかどうかが決まります。 両方の可能性を追跡しないと、不可能であると誤って結論付ける可能性があります。 

重要な問題は、各ステップで長方形が複数の一貫した方向で解釈される可能性があり、すべてのグローバルに一貫した解釈を維持する必要があることです。 

## アプローチ

 ブルート フォース シミュレーションでは、あらゆる方法で各四角形の向きを変えて接続しようとします。 ステップ i では、現在の四角形の各状態は、最大 4 つの方法で新しいブロックを受け取ることができます。ブロックの方向を選択し、幅または高さに沿って接続するかどうかを選択します。 これにより、状態ごとに最大 4 つの分岐係数が作成されます。 同一の状態をマージした場合でも、個別の状態の数は n とともに急速に増加する可能性があり、最悪の場合は指数関数的に爆発的に増加します。 

重要な観察は、この分岐にもかかわらず、ジオメトリが非常に制限されていることです。 有効な長方形の状態を修正すると、どの辺が一致するかに応じて、幅または高さが決定論的に拡張されるという意味で、すべてのアタッチメントが強制されます。 これにより、発散が大幅に制限されます。 

より深い構造上の事実は、個別の有効な長方形の次元の数が 2 を超えることは決してないということです。 直観的には、曖昧さはステップ全体で幅と高さの解釈を交換することによってのみ生じます。 一貫した「軸の解釈」にコミットすると、その後のすべてのステップが決定論的に伝播します。 唯一の選択肢は、グローバルに解釈を交換することです。 

これにより、候補となる四角形の非常に小さなセットを維持し、それらを段階的に更新することができます。 各候補は最大でも一定数の次の候補を生成し、重複をマージします。

 ## アルゴリズムのチュートリアル

 ブロックの各プレフィックスを処理した後の現在の状態を表すことができる、考えられる長方形の寸法の小さなセットを維持します。 

各状態はペア (W、H) であり、順序はグローバルには重要ではないため、保存時に正規化します。 

### ステップ

 1. 最初の四角形を使用して状態のセットを初期化します。 どちらの側が幅と高さに対応するかまだわからないため、両方の方向を考慮します。 
2. 次の各長方形 (a, b) について、考えられる 2 つの方向 (a, b) と (b, a) を生成します。 これにより、回転の自由度が考慮されます。 
3. 現在の状態 (W、H) ごとに、すべての有効な方法で新しい四角形を接続してみます。 

新しい長方形の 1 つの辺が W に等しい場合、それを幅の辺に沿って接続して、新しい状態 (W, H + other_side) を生成できます。 

一方の辺が H に等しい場合、それを高さの辺に沿って接続し、(W + other_side, H) を生成できます。 

主な制限は、側面が完全に一致する場合にのみ接続が可能であるということです。 
4. 新しい四角形の現在の状態と方向のすべての組み合わせから得られたすべての状態を収集します。 
5. (min(W, H), max(W, H)) が使用されるようにその次元を並べ替えることによって各状態を正規化します。 これにより、同等の長方形が確実にマージされます。 
6. いずれかのステップで有効な状態が残っていない場合、構築は不可能です。 
7. すべての四角形を処理した後、残りのすべての個別の状態を出力します。 

重要な考え方は、すべてのステップで幾何学的に一貫した長方形の解釈のみを維持し、互換性のない部分的な履歴がマージされることを決して許可しないということです。 

### なぜ効果があるのか

どの時点でも、有効な状態は、以前のすべての長方形がどのように接続されているかについての完全な幾何学的解釈をエンコードします。 新しい長方形を処理する場合、自由なのは方向と接続する辺の選択だけですが、どちらも現在の長方形との等価条件によって完全に制約されます。 ステップ i を生き残った状態は、プレフィックスの完全な構築まで拡張可能であることが保証されます。 すべての有効な完全な構築は、そのような状態遷移の 1 つのシーケンスに正確に対応する必要があるため、解が失われることはありません。 

状態の数が制限されているのは、すべての制約を乗り越える唯一のあいまいさは、幅と高さの解釈の間のグローバルな交換であるため、存在する一貫した幾何学的解釈は最大 2 つであるという事実から来ています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def normalize(w, h):
    if w > h:
        w, h = h, w
    return (w, h)

n = int(input())
a1, b1 = map(int, input().split())

states = set()
states.add(normalize(a1, b1))

for _ in range(n - 1):
    a, b = map(int, input().split())
    nxt = set()

    for W, H in states:
        for x, y in ((a, b), (b, a)):
            if x == W:
                nxt.add(normalize(W, H + y))
            if x == H:
                nxt.add(normalize(W + y, H))

    states = nxt
    if not states:
        print(0)
        sys.exit()

print(len(states))
for w, h in states:
    print(w, h)
```実装は状態遷移モデルに直接に従います。 正規化ステップは、同じ四角形の対称表現をマージするため、不可欠です。 これがないと、状態空間が誤って 2 倍になってしまいます。 

ネストされたループは、状態の数が定数 (有効な場合は最大 2 つ) によって制限され、遷移が実質的に n で線形になるため、効率が維持されます。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    def normalize(w, h):
        if w > h:
            w, h = h, w
        return (w, h)

    n = int(input())
    a1, b1 = map(int, input().split())

    states = set()
    states.add(normalize(a1, b1))

    for _ in range(n - 1):
        a, b = map(int, input().split())
        nxt = set()

        for W, H in states:
            for x, y in ((a, b), (b, a)):
                if x == W:
                    nxt.add(normalize(W, H + y))
                if x == H:
                    nxt.add(normalize(W + y, H))

        states = nxt
        if not states:
            return "0\n"

    out = [str(len(states))]
    for w, h in sorted(states):
        out.append(f"{w} {h}")
    return "\n".join(out) + "\n"

 ## 特殊なケース

 重要なエッジ ケースは、最初の長方形が 2 つの方向で解釈され、後で異なる有効な構造に分岐する場合です。 たとえば、非正方形の基底から開始しても、両方の解釈が数ステップにわたって存続することができます。 アルゴリズムは両方の状態を同時に保持し、後続の各ブロックでそれらを個別にフィルタリングして、有効な方向が途中で破棄されないようにします。 

もう 1 つのエッジ ケースは、ブロックが現在の長方形の両方の寸法に一致する場合に発生し、事実上 2 つの異なる取り付け方向が許可されます。 この状況では、アルゴリズムは 2 つの候補状態を生成しますが、それらが同じ最終次元を生成する場合、正規化によってそれらがマージされます。 これにより、状態の人為的な重複が防止され、状態空間が制限されたままになることが保証されます。
