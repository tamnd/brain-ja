 ## 解決策
 ## 問題の理解

 各都市が現在 2 つの派閥のいずれかに属している都市のグラフが表示され、1 または 2 というラベルが付けられます。一部の都市は「変更可能」、つまり派閥を反転できることを意味しますが、他の都市は固定されており変更できません。 

目標は、グラフを「中立」にすることです。これは、2 つの都市間のすべての道路の終点が異なる派閥に属している必要があることを意味します。 グラフの観点から言えば、1 と 2 の最終的な割り当てによって、すべてのエッジの適切な 2 分割が形成されることが必要です。 

ただし、色を恣意的に割り当てることはできません。 最初の色付けから開始し、編集可能としてマークされた都市の色のみを反転できます。 各フリップは 1 つの操作としてカウントされるため、必要なフリップの数を最小限に抑えたいと考えています。 有効なニュートラル構成に到達できない場合は、-1 を出力する必要があります。 

この制約では、最大 10^4 のノードと 2・10^5 のエッジが許可されており、色の割り当てに対する指数関数的な列挙を伴う解決策は不可能であることがすぐにわかります。 エッジケースごとに二次関数であっても許容されますが、すべての代入を試したり、大規模な構造を繰り返し再計算したりするようなことは遅すぎます。 コンポーネントごとの線形または線形に近いグラフの走査が目標です。 

重要な微妙な点は、グラフが切断される可能性があることです。 各接続コンポーネントは独立して処理できますが、全体的なコスト最小化の相互作用は、コンポーネントの回答を合計することによってのみ行われます。 

単純な推論では重要な故障モードがいくつかあります。 最もよくある間違いは、貪欲に違反をエッジごとに修正できると考えることです。 たとえば、すべてのノードが色 1 で始まり、1 つのノードだけが編集可能である三角形について考えてみましょう。 間違ったノードを局所的に反転すると、1 つのエッジは修正されるものの、別のエッジが破損する可能性があり、発振や不正確な最小性が発生する可能性があります。 コンポーネントがすでに 2 部構成になっているが、最初の色付けがその 2 部構成と競合し、固定ノードにより一貫性のない割り当てが強制される場合、別の問題が発生します。 

3 番目の微妙なケースは、コンポーネントがグラフ構造で 2 部構成であるが、考えられる両方の 2 部構成で編集不可能なノードを反転する必要がある場合です。 その場合、答えは「反対側を選ぶだけ」ではなく、明らかに不可能です。 

## アプローチ

 どのノードが編集可能であるかに関する制約を無視すると、問題は単純になります。 グラフの接続された各コンポーネントは、BFS または DFS を使用して二部性をチェックし、エッジに沿って交互の色を割り当てることができます。 競合が見つかった場合、有効な 2 色分けは存在せず、答えは -1 になります。 

ただし、ここでの工夫は、すでに初期の色付けがあり、編集制約の下での変更の数を最小限に抑えたいことです。 これにより、問題は、ハミング距離で指定された割り当てに最も近い、ただし頂点が強制的に固定された 2 部構成の割り当てを選択することに変わります。 

強引なアプローチは、二部構成の制約と一致するすべての可能な色の割り当てを試行することです。 これは、各コンポーネントのサイズが指数関数的であり、基本的に 2^{コンポーネントまたはノードの数} であり、10^4 までの n では実現不可能です。 

重要な観察は、すべての接続コンポーネントが 2 部構成の場合、有効なカラーリングが 2 つあるということです。1 つとそのグローバル フリップです。 ルートを修正して交互パリティを伝播すると、すべてのノードにパリティ ラベルが付けられます。 これにより、割り当ての検索の問題が、コンポーネントごとに 2 つのグローバル状態の間で選択される問題に軽減されます。 

これら 2 つの候補割り当てを計算したら、そのコスト、つまり各割り当てに一致させるために反転する必要がある編集可能なノードの数を評価します。 固定ノードは実現可能性を制限します。固定ノードが候補の割り当てと一致しない場合、その候補は無効になります。

これにより、問題はコンポーネントごとの決定に変換されます。つまり、「パリティ 0 ルート」と「パリティ 1 ルート」に調整するコストを計算し、最小の有効なものを選択します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | コンポーネント 2 部構成 + 2 色の選択 | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 BFS または DFS を使用して、接続された各コンポーネントを個別に処理します。 

1. すべてのノードを反復処理します。 未訪問のノードを見つけると、そのコンポーネントの BFS を開始します。 これにより、切断されたグラフを正しく処理できるようになります。 
2. BFS 中に、開始ノードを基準とした 2 部カラーリングでの位置を表すパリティ値 (0 または 1) を各ノードに割り当てます。 すべてのエッジ u-v に対して、parity[v] = parity[u] XOR 1 を強制します。矛盾が見つかった場合、グラフは 2 部ではないため、すぐに -1 を返します。 
3. コンポーネントの BFS が完了すると、構造的な 2 つのパーティションが作成されます。 これにより、基本的な有効なカラーリングが得られますが、それを初期の派閥値に合わせる必要があります。 
4. このコンポーネントに対して 2 つの仮想的なグローバル割り当てを計算します。 

パリティ 0 がファクション 1 に対応し、パリティ 1 がファクション 2 に対応するもの、

 そして、これらの意味が入れ替わったものもあります。 
5. 割り当てごとにコストを計算します。 ノードが固定されている場合は、割り当てがその初期値と一致していることを確認する必要があります。 それ以外の場合、割り当ては無効になります。 ノードが編集可能な場合、割り当てられた色が初期の色と異なる場合は、コストに 1 を追加します。 
6. コンポーネントの有効な割り当ての中から最小コストを取得し、それをグローバルな答えに追加します。 両方の割り当てが無効な場合は、-1 を返します。 
7. すべてのコンポーネントを処理した後、総コストを出力します。 

重要な考え方は、BFS はグラフ内の唯一の構造的自由度を固定し、他のすべては制約の下で初期状態とその構造の最適な位置合わせを選択することに帰着するということです。 

### なぜ効果があるのか

 どの連結コンポーネントでも、有効な中立構成が存在する場合、グラフは 2 部構成でなければなりません。 二部構成が修正されると、有効なカラーリングはすべて、グローバル フリップまで一意に決定されます。 BFS パリティ割り当ては、まさにこの等価クラスをキャプチャします。 固定ノードは 2 つの反転のうちどちらが許可されるかを制限するだけであり、編集可能ノードは割り当てが選択されると独立してコストに寄与します。 これにより、コンポーネントごとに 2 つの候補カラーリングの外に最適な解決策が存在しないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, m = map(int, input().split())
    col = list(map(int, input().split()))
    can = list(map(int, input().split()))

    g = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    vis = [-1] * n
    ans = 0

    for i in range(n):
        if vis[i] != -1:
            continue

        q = deque([i])
        vis[i] = 0
        comp = []

        ok = True

        while q:
            u = q.popleft()
            comp.append(u)
            for v in g[u]:
                if vis[v] == -1:
                    vis[v] = vis[u] ^ 1
                    q.append(v)
                elif vis[v] == vis[u]:
                    ok = False

        if not ok:
            print(-1)
            return

        cost0 = 0
        cost1 = 0
        valid0 = True
        valid1 = True

        for u in comp:
            if vis[u] == 0:
                if col[u] == 2:
                    cost0 += 1
                if col[u] == 1:
                    cost1 += 1
            else:
                if col[u] == 1:
                    cost0 += 1
                if col[u] == 2:
                    cost1 += 1

            if can[u] == 0:
                if vis[u] == 0 and col[u] != 1:
                    valid0 = False
                if vis[u] == 1 and col[u] != 2:
                    valid0 = False
                if vis[u] == 0 and col[u] != 2:
                    valid1 = False
                if vis[u] == 1 and col[u] != 1:
                    valid1 = False

        if not valid0 and not valid1:
            print(-1)
            return

        best = 10**18
        if valid0:
            best = min(best, cost0)
        if valid1:
            best = min(best, cost1)

        ans += best

    print(ans)

if __name__ == "__main__":
    solve()
```BFS セクションは、一貫性をチェックしながら、各接続コンポーネントの 2 つのパーティションを構築します。 の`vis`配列はコンポーネント内のパリティをエンコードします。 競合が見つかった場合は、直ちに終了します。 

BFS の後、両方のグローバル フリップを評価します。 コストの計算では、現在のノードの色と暗黙の 2 部割り当てが比較されます。 の`can`配列は特定のノードを変更できないように強制します。これは、固定ノードの変更が必要な割り当てを無効にすることで処理されます。 

コンポーネントにわたる最終的な累積は、異なるコンポーネントでの選択が相互作用しないことを反映しています。

 ## 特殊なケース

 エッジ ケースの 1 つは、構造的に 2 部ではないグラフです。 ノードが長さ 3 のサイクルで接続されている三角形を考えてみましょう。BFS は最終的に、同じパリティの 2 つのノードを接続するエッジを見つけて、コンポーネントを直ちに無効としてマークします。 すべてのエッジを満たす割り当てはないため、多くのノードが編集可能であっても、これは正しく -1 を出力します。 

もう 1 つのエッジ ケースは、固定ノードによって 2 つのパリティの選択肢の間で矛盾する割り当てが強制される 2 部グラフです。 このような場合、両方のグローバル フリップが固定制約に違反する可能性があり、アルゴリズムは両方の候補を正しく無効にし、-1 を返します。 

最後の微妙なケースは、1 つのコンポーネントが解決可能で、別のコンポーネントが解決できない、複数のコンポーネントが切断されていることです。 アルゴリズムは無効なコンポーネントに遭遇するとすぐに停止します。これは、構成全体がグローバルに有効である必要があるという要件に一致します。
