 ## 解決策
 ## 問題の理解

 各ボールに色があるボールのコレクションが与えられるため、入力は基本的に色のマルチセットになります。 これに加えて、すべてのボールを正確に K 個のボックスに分配するように求められます。 ボックスは個別で順序付けられているため、2 つのボックスを交換すると、異なる配置が生成されます。 ただし、ボックス内では、複数の色のセットのみが重要です。つまり、ボックス内のボールの順序は無関係です。 

すべてのボックスには少なくとも 1 つのボールが入っていなければなりません。 2 つのパーティションは、すべてのボックスの同じ位置にまったく同じ色のマルチセットがある場合にのみ同一とみなされます。 

したがって、タスクは、色付きアイテムのマルチセットを取得し、それを K 個のラベル付きの空でないグループに分割できる方法が何通りあるかを数えることであり、各グループ内の色のカウントのみが問題となります。 

この制約から、N は最大 1000 であり、テスト ケース全体の作業量の合計は、N 倍 K で約 10^6 に制限されることがわかります。これは、テストごとに O(NK) または O(NK log N) の解が許容されるが、N または K で指数関数的なものは不可能であることを強く示唆しています。 単純な組み合わせ検索でボックスのサブセットを反復処理したり、ボールを個別に分配したりするソリューションは、限界をはるかに超えて爆発的に増加します。 

微妙な点は、ボールは別個のオブジェクトではないということです。 これを無視して各ボールを一意のものとして扱うと、複数のボールが同じ色を共有する場合に大幅に過大カウントされてしまいます。 もう 1 つの微妙な問題は、すべてのボックスに対する空でない制約です。これにより、異なる色の独立した分布が結合されます。 

いくつかのエッジ シナリオは、落とし穴を明確に示しています。 すべてのボールが同じ色である場合、たとえば N 個の同じボールと K 個のボックスの場合、問題は同じアイテムを順序付けられた空ではないボックスに分配することに帰着します。これは古典的な構成カウントの問題です。 色ごとの分布の単純な積では、誤って空のボックスが許可されてしまいます。 

K が N に等しく、すべての色が異なる場合、各ボックスにはちょうど 1 つのボールが含まれている必要があり、答えは単純に N 階乗になります。 ボックスの順序を忘れたり、ボールを区別できないものとして扱ったりするアプローチは、ここでは失敗します。 

## アプローチ

 構造を無視する場合、最も直接的なアイデアは、各ボールを K 個のボックスの 1 つに配置し、有効な割り当てをカウントすることを考えることです。 それはすぐに K^N の可能性を与えます。 ただし、これは同じ色のボールが区別できないことを無視しているため、多くの割り当てが同じ結果を表します。 また、無効な空のボックスを含む多くの構成も生成されます。 

これを解決しようとすると、色ごとに同じアイテムを配布するという観点から考えることになります。 周波数 f の固定色の場合、これらの同一のボールを K 個のラベル付きボックスに分配することは標準的な星と棒の計算であり、C(f + K - 1, K - 1) が得られます。 これを色ごとに個別に実行して結果を乗算すると、ボックスに色の数を割り当てるすべての方法が正しくカウントされますが、全体的に空のボックスは存在できないという制約は完全に無視されます。 ボックスにはどの色のボールも入らない可能性がありますが、これは無効です。 

したがって、2 つの層を分離すると、構造がより明確になります。 まず、色ごとに、その色のボールが各ボックスにいくつ入るかを割り当てます。 これにより、色ごとに独立した組み合わせが得られます。 次に、各ボックスがすべての色の合計が正になるように強制します。 この 2 番目の条件は色全体にわたってグローバルであり、まさにボックスに対する包含と除外が自然になる場所です。 

ボックスを制約として扱います。各ボックスは空であってはなりません。 空にすることが許可されるボックスのサブセットを選択し、それに応じて構成を減算または追加することにより、包含/除外を適用します。 m 個のボックスが強制的に空になるように修正すると、K - m 個のアクティブなボックスにのみ分散され、色ごとの分散が再び独立します。 これにより分離可能性が回復します。

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース割り当て | O(K^N) | お(1) | 遅すぎる |
 | 色ごとの分布のみ | O(NK) | O(K) | 不正解 |
 | ボックスの包含/除外 | O(K * 色の数) | O(K) | 承認済み |

 ## アルゴリズムのチュートリアル

 ## アルゴリズムのチュートリアル

 1. 入力配列内の各色の頻度をカウントします。 有効な構成では色物質ごとにのみカウントされるため、これにより問題がボールから色のクラスに圧縮されます。 
2. モジュラー演算を使用して、N + K までの階乗および逆階乗を事前計算します。 これにより、同一のアイテムを分配するための式に繰り返し現れる二項係数を高速に計算できます。 
3. 固定数のアクティブ ボックス B について、各色をそれらの B ボックスに個別に分配する方法が何通りあるかを計算します。 周波数が f の色の場合、これは C(f + B - 1, B - 1) です。 これをすべての色に掛けて、その B の合計ウェイ数を取得します。 
4. 空のボックスに対して包含/除外を使用します。 0 から K までの各 m について、m を強制的に空にするボックスの数として解釈します。 これらのボックスを選択する方法の数は C(K, m) で、残りのアクティブなボックスは B = K - m です。 
5. m に応じて加算と減算を交互に実行します。 m が偶数の場合、寄与分を加算します。 奇数の場合はそれを引きます。 各項は、ステップ 3 で B = K - m として計算された色の積を乗じた C(K, m) に寄与します。 
6. 1e9+7 を法とするすべての寄与を合計して、最終的な答えを取得します。 

### なぜ効果があるのか

 ボックスへの色数の固定割り当てについては、最終的に空になるボックスのセットを考慮してください。 包含-除外により、この構成に空のボックスがない場合は正味係数 1 が割り当てられ、それ以外の場合は 0 が割り当てられます。 これは、すべての無効な構成が空のボックスを含むサブセット全体で正負の符号付きで同じ頻度でカウントされ、キャンセルが発生するために発生します。 有効な構成は、ボックスが除外されていない用語にのみ表示されるため、1 回だけ存続します。 

ボックス構造が固定されると、各色の同一アイテムを配布しても他の色と相互作用しないため、色間の独立性が保たれます。 色間の唯一の結合は空でない制約であり、これは完全に包含-排他によって処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAXN = 2005

fact = [1] * (MAXN)
invfact = [1] * (MAXN)

def modexp(a, e):
    r = 1
    while e:
        if e & 1:
            r = r * a % MOD
        a = a * a % MOD
        e >>= 1
    return r

for i in range(1, MAXN):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAXN - 1] = modexp(fact[MAXN - 1], MOD - 2)
for i in range(MAXN - 2, -1, -1):
    invfact[i] = invfact[i + 1] * (i + 1) % MOD

def C(n, k):
    if n < 0 or k < 0 or k > n:
        return 0
    return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        arr = list(map(int, input().split()))

        freq = {}
        for x in arr:
            freq[x] = freq.get(x, 0) + 1

        colors = list(freq.values())

        ans = 0

        for m in range(0, k + 1):
            B = k - m
            if B == 0:
                continue

            ways = 1
            for f in colors:
                ways = ways * C(f + B - 1, B - 1) % MOD

            cur = C(k, m) * ways % MOD

            if m % 2 == 0:
                ans = (ans + cur) % MOD
            else:
                ans = (ans - cur) % MOD

        print(ans % MOD)

if __name__ == "__main__":
    solve()
```二項係数は包含-排他ループ内で何度も評価されるため、階乗事前計算が必要です。 コア ループは、空のボックスの可能な数を繰り返し、各ケースについて、残りのアクティブなボックスが色付きのボールを個別に受け取ることができる方法の数を計算します。 

二項項 C(f + B - 1, B - 1) は、f 個の同一項目を B 個のラベル付きボックスに分散することをエンコードします。 ボックスのアイデンティティが固定されると、色は相互作用しないため、色の乗算は有効です。 

加算と減算を交互に行うことで、ボックスのセットに対する包含と除外が実装されます。 B = 0 の場合をスキップすると、ボックスが存在しない無効な組み合わせが回避されます。

 ## 特殊なケース

 重要なエッジ ケースは、K が大きいにもかかわらず、中間の包含/除外条件で多くのボックスが空でなければならない場合です。 N ≥ 1 の場合、ボールをゼロのボックスに分配することは意味がなく、何も寄与しないため、アルゴリズムは B = 0 の場合をスキップしてこれを処理します。 

もう 1 つの特殊なケースは、すべてのボールが同じ色を共有する場合です。 この場合、周波数 f = N は 1 つだけあり、色ごとの分布は C(N + B - 1, B - 1) に単純化されます。 包含-排他は依然として空ではないボックスを正しく強制し、整数の合成を K 個の順序付けられた部分にカウントすることに帰着します。 

最後に、すべての色が異なる場合、各 f = 1 となり、式は C(B, B - 1) = B の積に帰着します。これは、順序付けされたボックス全体の順列と一致する階乗構造に崩壊します。
