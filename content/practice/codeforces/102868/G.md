 ## 解決策
 # 問題の理解

 このタスクでは、多くの範囲クエリに答えることが求められます。 可能な入力の間隔ごとに、数値を見つける必要があります。`x`その間隔内で、生成された ID コードが最大となるもの。 生成されたコードは`x * phi(x)`、 どこ`phi(x)`のすべての桁を置き換えることで得られます`x`この演算によって作成された先頭のゼロは無視されますが、数値は変わりません。 

キーの簡略化は数字演算の内部に隠されています。 もし`x`まさに`k`数字、すべての数字を置き換える`d`による`9-d`減算と同じ値を作成します`x`からの`k`9だけで構成される数字。 たとえば、3 桁の数字の場合、`phi(x) = 999 - x`。 先行ゼロは値に寄与しないため、先行ゼロを削除してもこの等価性には影響しません。 

入力には最大 1000 の間隔が含まれており、各エンドポイントは最大 1000 個の間隔です。`10^9`。 すべての間隔ですべての数値をチェックするソリューションには、最大で約`10^12`可能性をはるかに超えた評価。 範囲を反復処理する代わりに、関数の数学的形状を使用する必要があります。 

固定桁長の関数は次のとおりです。`f(x) = x * (10^k - 1 - x)`これを拡大すると、下向きの放物線が得られます。 その最大値は次の間隔の中間です。`0`に`10^k - 1`したがって、その中央付近の位置とクエリ間隔の境界だけを調べる必要があります。 

厄介なケースは、桁の長さの変更によって引き起こされます。 のような数字`99`は 2 桁のグループに属します。`phi(99)=0`、 しかし`100`は 3 桁のグループに属します。`phi(100)=899`。 クエリ全体が次の 1 つの値を使用することを前提としたソリューション`k`失敗する可能性があります。 

例えば：```
Input
1
99 100

Output
89900
```答えは次のとおりです。`x=100`、 なぜなら`100 * 899 = 89900`。 2 桁の数字だけを見ると、誤ってゼロが返されます。 

もう 1 つの特殊なケースは、間隔に数値が 1 つだけ含まれる場合です。```
Input
1
5 5

Output
20
```A careless implementation that only checks the middle of a range might miss the answer because there is no room to move toward the midpoint.

 ## アプローチ

 直接的な解決策としては、あらゆる可能性を試すことになります`x`で`[l,r]`、計算する`phi(x)`桁ごとに入力し、最大の積を保持します。 This is correct because every valid candidate is examined. However, an interval can contain close to one billion values, and there can be 1000 queries. 最悪の場合は次のことが必要になります`10^12`製品の評価は不可能です。 

有益な観察は、同じ桁数の数値は同じ補数基を共有するということです。 もし`x`もっている`k`数字、その後`phi(x)=10^k-1-x`したがって、積は次のようになります。`x * (10^k-1-x)`これは放物線です。 下に開いた放物線は頂点で最大になります。 クエリ間隔の場合、桁長のセグメント内の最適な値は、頂点がセグメント内にある場合は頂点、またはセグメントの端点の 1 つである必要があります。 

以来`x`せいぜい`10^9`の場合、考慮すべき桁長グループは 1 桁から 10 桁までの 11 個だけです。 各グループについて、それをクエリ範囲と交差させ、いくつかの考えられる候補をテストします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | クエリごとに O(r-l+1) | お(1) | 遅すぎる |
 | 最適 | クエリごとに O(10) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. クエリ間隔ごとに`[l,r]`、考えられるすべての桁の長さを考慮します`k`1 から 10 まで。正確に一致する数値の間隔`k`数字は`[10^(k-1), 10^k-1]`、下限は 1 として扱われます。`k=1`。 
2. この桁長の間隔を次のように交差します。`[l,r]`。 交差部分が空の場合、この桁長の候補はありません。 
3. コンピューティング`m = (10^k - 1) / 2`、これは次の位置です。`x * (10^k - 1 - x)`最大化されます。 現在のセグメント内の最良の候補は、セグメント境界と、セグメント境界に最も近い 2 つの整数の間です。`m`。 
4. セグメント内に残っているすべての候補について製品を評価し、グローバル最大値を更新します。 

機能する理由: 固定桁長ごとに、積関数は凹二次関数になります。 凹二次関数では、頂点よりも優れた内部点を持つことはできません。頂点が許容範囲外にある場合、最適な点は最も近い端点でなければなりません。 すべての桁の長さについてこれらの可能性を正確にテストするため、考えられるすべての最適な数値がカバーされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_query(l, r):
    ans = 0
    pow10 = 1

    for k in range(1, 11):
        low = 1 if k == 1 else pow10
        high = pow10 * 10 - 1

        left = max(l, low)
        right = min(r, high)

        if left <= right:
            limit = high
            middle_floor = limit // 2
            middle_ceil = middle_floor + (limit % 2)

            candidates = [
                left,
                right,
                middle_floor,
                middle_ceil
            ]

            for x in candidates:
                if left <= x <= right:
                    ans = max(ans, x * (limit - x))

        pow10 *= 10

    return ans

def main():
    t = int(input())
    out = []
    for _ in range(t):
        l, r = map(int, input().split())
        out.append(str(solve_query(l, r)))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```ループオーバー`k`可能なすべての桁長を処理します。 変数`pow10`店`10^(k-1)`次の反復のために更新される前に、累乗を繰り返すことなく現在の桁の範囲を構築できます。 

各桁の長さについて、`limit`は`10^k-1`、の式で使用されるすべて 9 の数値。`phi(x)`。 候補リストには、有効な間隔の両端と中央の 2 つの値が含まれます。 両方の中間値をテストすると、頂点が 2 つの整数の間にある場合に整数の除算によって引き起こされる問題が回避されます。 

乗算は Python の整数を使用して行われるため、可能な最大の積は次のようになります。`9 * 10^18`、安全に取り扱われます。 演算の順序により、浮動小数点の丸めも回避されます。

 ## 特殊なケース

 インターバルに関しては`[99,100]`、アルゴリズムは両方の数字グループをチェックします。 2 桁のグループは次のように使用します。`99 - x`でゼロのみを与えます`x=99`。 3 桁のグループは次のように使用します。`999 - x`、 そして`x=100`与える`899`、生産`89900`。 両方のグループは独立して考慮されるため、桁の遷移を見逃すことはできません。 

インターバルに関しては`[5,5]`、1 桁のグループの交点は 1 つの点です。 候補リストには両方の境界が含まれているため、`x=5`直接テストされます。 計算された値は次のとおりです。`5 * (9-5) = 20`。 

最大入力値の場合`1000000000`、アルゴリズムはそれを 10 桁のグループに配置します。 オール9の数字は、`9999999999`、 それで`phi(1000000000)=8999999999`。 この積は Python の整数型に適合し、オーバーフローなしで評価されます。
