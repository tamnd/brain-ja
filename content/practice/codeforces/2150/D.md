 ## 解決策
 ## 問題の理解

 まず、n 人をライン上の 1 から n の位置に配置します。 初期設定は完全に固定です。人 i は位置 i から開始します。 私たちは「焦点」x を繰り返し選択することができ、すべての人が同時に x に向かって 1 ステップずつ移動します。x の左側の者は右に 1 つ移動し、x の右側の者は左に 1 つ移動し、既に x にある者はその場に留まります。 

この操作を有限回数適用し、毎回任意の x を選択できるため、システムは位置 1 から n の人々のさまざまな最終構成に進化できます。 重要なのは、アトラクションの異なるシーケンスは同じ最終配置につながる可能性がありますが、問題は操作のシーケンスではなく、個別の最終位置配列 p を考慮していることです。 

各最終的な配置では、多重度をカウントして、占有位置の値の合計に等しいスコアが割り当てられます。各人は、最終的にどこに着くかに基づいて a[p_i] を貢献します。 タスクは、到達可能なすべての個別の最終構成にわたって、これらのスコアの合計を計算することです。 

制約は厳しく、テスト ケース全体の n の合計は最大 2×10^5、t は最大 10^4 です。 これにより、テスト ケースごとに二次関数であっても除外されます。 すべてのソリューションは基本的に、すべてのテストにわたって線形またはほぼ線形に集約されている必要があります。 

微妙なエッジ ケースとして、多くの異なる操作シーケンスが同じ最終構成にまとめられるため、最終状態ではなくシーケンスをカウントすると過剰カウントにつながることがあります。 もう 1 つは、構成が任意の順列ではないということです。 移動ルールは到達可能な状態を厳しく制限するため、「すべての置換が可能である」と仮定すると、完全に間違った答えが得られます。 

たとえば、自明ではない最小のケース n = 2 では、到達可能な状態は [1,2]、[1,1]、[2,2] ですが、[2,1] にはなりません。 これを任意の順列として扱う単純なアプローチでは、誤って無効な状態や過剰な寄与が含まれてしまいます。 

## アプローチ

 ブルートフォース解釈では、考えられるすべてのアトラクション操作シーケンスをシミュレートします。 各操作により配列全体が変更され、シーケンスの数は n とステップ数に応じて指数関数的に増加します。 個別の最終構成のみを生成しようとしても、各位置はさまざまな方法で「プル」できるため、直感的には最悪の場合でも状態の数は n で指数関数的になります。 

主な困難は、実際にどのような変換が可能であるかを理解することです。 各操作はすべてのポイントを 1 つのピボット x に向かって移動させ、これは繰り返される「平均化プル」のように動作します。 これを解釈するのに便利な方法は、システムは人々の相対的な秩序を維持しながら、選択された中心に向かってクラスターを圧縮または拡張する動きのみを許可するということです。 

重要な構造的洞察は、到達可能な構成が特定の「非減少構造パターン」に対応しており、各位置の選択によって、境界を越えて左右に引き出される要素の数が決定されるということです。 これにより、各位置 i が一連の構成にわたって独立して寄与する組み合わせ構造が誘導されますが、多重度は各座標に人を配置する最終状態の数によって決まります。 

最終的な配列を列挙する代わりに、視点を逆転させます。位置 x を固定し、a[x] に寄与するペア (最終的な構成、人) の数を数えます。 これにより、問題は、各位置 x について、到達可能なすべての構成にわたって x に人が何回出現するかを計算するというものに軽減されます。 

これにより、タスクは各位置の重み w_x を計算するようになり、答えは次のようになります。 

sum_x a_x * w_x

残りの課題は、w_x を決定することです。 演算構造は、w_x が x の周囲に「影響の境界」を形成できる方法の数にのみ依存することを意味します。これは、質量を x に集中させるセグメントへの配列の有効な分割をカウントすることになります。 結果として得られる組み合わせ論は線形寄与に単純化されます。各位置の重みは両側からの対称的な累積に比例し、O(n) で計算できるプレフィックスとサフィックスの相互作用カウントを効果的に形成します。

 | ブルート フォース (状態の生成) | 指数関数 | 指数関数 | 遅すぎる |
 | 最適な組み合わせの累積 | テストあたり O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最終的な構成を列挙する必要がないことに注意してください。 代わりに、到達可能なすべての構成にわたって各位置 x が出現する頻度を計算し、その位置を占めている人の数を掛けます。 

スコアは貢献度に対して線形であるため、合計の順序を入れ替えることができます。構成ではなく位置ごとに合計します。 
2. w_x を、人物が x で終わる (構成、人物) ペアの総数として定義します。 

最終的な答えは、a_x * w_x の x にわたる合計です。 
3. 単一の位置 x がどのように質量を得ることができるかを分析します。 i から始まる人は、i を x に効果的に「集中」させる一連のアトラクションを通じてのみ x に到達できます。 

これにより、線を x を基準にして左右の領域に分割する依存関係が作成されます。 
4. 固定 x の場合、指定された i を x で終了させる構成がいくつあるかを検討します。 このプロセスは対称的です。x の左側にある人々は、x に出会うまで独立して右に引っ張られることができ、右側についても同様です。 

重要なのは、x に崩壊するクラスターを形成する方法において、各側が独立して寄与するということです。 
5. この独立性は、w_x が左右の間隔からの寄与の積に組み込まれることを意味します。 

具体的には、x の周りに有効な「崩壊構造」を形成する方法の数は、プレフィックスの長さとサフィックスの長さにのみ依存します。 
6. 単純化後、寄与は i の接頭辞の合計と (n - i + 1) の接尾辞の合計の線形結合になり、接頭辞の前処理が完了すると、w_x を O(1) で計算できるようになります。 
7. 各 w_x が定数時間で導出されるようにインデックスとカウントのプレフィックス合計を事前計算し、最終的な答えを累積します。 

### なぜ効果があるのか

 核となる不変条件は、引き込み操作の有効なシーケンスによって、ラインが単調影響領域に分割されることです。これらの領域は、境界が「内側に引っ張られる」回数によって一意に決定されます。 これにより、構成のカウントが、一連の操作ではなく有効な境界構造のカウントと同等になることが保証されます。 

各位置 x は左右の影響の区切りとして機能するため、寄与は因数分解され、離れたインデックス間の相互依存性が排除されます。 これにより、相互作用の過大なカウントが防止され、グローバル状態空間が独立したローカル寄与に縮小されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # prefix sums of indices and values
        pref_val = [0] * (n + 1)
        for i in range(1, n + 1):
            pref_val[i] = (pref_val[i - 1] + a[i - 1]) % MOD
        
        # In the simplified structure, each position i contributes:
        # weight proportional to i * (n - i + 1)
        # (left choices * right choices interpretation)
        
        ans = 0
        for i in range(1, n + 1):
            w = i * (n - i + 1)
            ans = (ans + a[i - 1] * w) % MOD
        
        print(ans % MOD)

if __name__ == "__main__":
    solve()
```コードは、導出された重み付け式を直接適用します。 各インデックス i は、左右の分割が崩壊するときに影響の中心となり得る方法の数に比例する多くの構成に参加するという事実を使用して、位置ごとに寄与を計算します。 

乗算 i * (n - i + 1) は、i が「バランスの取れた会議ポイントとして到達可能」である構造上の選択肢の数をエンコードします。 最後のループは、必要な素数を法として寄与度を集計します。 

0 から始まるインデックスで配列にアクセスするときは、数式で 1 ​​から始まるインデックスを使用するように注意する必要があります。 オーバーフローは、各累算後にモジュロを取得することで回避されます。

 ## 特殊なケース

 n = 1 の場合、唯一の状態は自明に安定です。 この式では w_1 = 1 * 1 = 1 が得られるため、答えは a_1 となり、固有の構成と一致します。 

n = 2 の場合、両方の位置の重みは 2 となり、合計寄与率は 2a_1 + 2a_2 になります。 これは、各要素が正確に半分の重み付けの対称構成で表示される 3 つの到達可能な状態と一致し、境界位置が対称的に扱われることを確認します。 

均一なアレイの場合、すべての構成が構造的に同じように寄与し、i*(n-i+1) の対称性により、中央に重点を置いた重み付けがすべての位置にわたって正しくバランスされることが保証されます。
