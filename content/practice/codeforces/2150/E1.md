 ## 解決策
 ## 問題の理解

 長さの隠し配列が与えられます`2n-1`、以下の整数を含む`1`に`n`1 回しか出現しない 1 つの数値を除いて、すべての数値が正確に 2 回出現するようにします。 私たちの目標は、一度だけ出現する数値を特定することです。 位置は必要なく、値だけが必要です。 この対話により、配列の位置のサブセットに特定の数値が存在するかどうかを尋ねることができ、はい/いいえの答えが得られます。 主な制限は、実行できるクエリの総数です。`4n + 2 ⌈log₂ n⌉`テストケースごとに。 

この制約により、小規模な企業でもブルートフォースアプローチが実現可能になります。`n`しかし、それ以上の場合は不可能`n`。 以来`n`最大 300、テスト ケースの数は 4000 に達する可能性があるため、最悪の場合の合計を想定する必要があります。`n²`テストケース全体で最大`4·10⁵`。 つまり、テスト ケースごとに O(n²) クエリを使用するアプローチは遅すぎます。 クエリの数をほぼ線形、または線形よりわずかに上回る程度に減らす戦略が必要です。`n`。 

一意の要素が最大値または最小値である場合、または単純なペアごとの消去が無効になる位置にある場合、微妙なエッジ ケースが発生します。 たとえば、次の場合`n = 3`そして隠し配列は`[1, 2, 3, 2, 1]`、素朴なリニアスキャンはこう考えるかもしれません。`1`そして`2`サブセットに一度出現し、時期尚早に除外される`3`初期位置だけを確認する場合。 正しいアルゴリズムでは、要素の順序を仮定することなく、可能性を体系的に削減する必要があります。 

## アプローチ

 ブルートフォースの方法は、次の各数値をチェックすることです。`1`に`n`そして、配列のすべての位置をクエリして、出現回数をカウントします。 これにより、どの数値が 1 回だけ出現するかを直接特定するため、正確性が保証されますが、それには次のことが必要です。`n * (2n-1)`クエリは約 180,000 に達する可能性があります。`n = 300`、最悪の場合、許可されたクエリ数を超える可能性があります。 

最適なアプローチは、1 を除くすべての数字が 2 回出現するという問題の構造を利用します。 配列をペアにグループ化し、両方の半分に出現する数値を再帰的に削除すると、一度出現した数値が最終的に分離されます。 これを分割統治戦略と組み合わせて、ポジションを半分に分割し、各数値のサブセットをクエリすることができます。 どの数字がどの半分に現れるかを確認することで、効率的に候補を排除できます。 重要な洞察は、数値が 2 回出現する場合、その数値は両方の位置を含む少なくとも 1 つのクエリ サブセットに出現する必要があるということです。 それが一度だけ発生する場合、それが存在しないサブセットが常に存在します。 これにより、数値ごとの対数クエリとポジションに対する線形クエリを使用した系統的な削除プロセスが可能になります。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 テスト ケースごとに、次の内容を読んでください。`n`すべてのポジションのリストを初期化します`[1, 2, ..., 2n-1]`。 すべての数字を含む候補リストを初期化する`1`を通して`n`。 
2. 候補者番号が複数ある場合は、現在の役職リストをほぼ半分に分割します。 各候補番号について、前半をクエリして、表示されるかどうかを確認します。 前半にどの数字が表示され、どの数字が表示されないかを記録します。 
3. 両方の半分に表示される数値については、後続の反復で追跡を続けます。 半分にのみ表示される数値については、その半分を次のクエリ ラウンドのアクティブな位置として保持します。 これにより、候補セットと位置セットが同時に削減されます。 
4. 再帰的に分割して削除すると、候補番号は 1 つだけ残ります。 その数値を 1 回だけ出現する隠し要素として出力します。 
5. インタラクターが正しく応答することを確認するために、クエリのたびに出力をフラッシュします。 

アルゴリズム全体で維持される不変条件は、真の一意の番号が決して削除されないということです。 数値がその位置を含まない半分にある場合、それが一意の数値であるはずがないことがわかっているため、消去は安全です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
flush = sys.stdout.flush

def ask(x, S):
    print("?", x, len(S), *S)
    flush()
    r = int(input())
    if r == -1:
        sys.exit(0)
    return r

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        if n == -1:
            sys.exit(0)
        positions = list(range(1, 2*n))
        candidates = list(range(1, n+1))
        
        while len(candidates) > 1:
            mid = len(positions)//2
            left = positions[:mid]
            right = positions[mid:]
            
            new_candidates = []
            for num in candidates:
                if ask(num, left):
                    new_candidates.append(num)
            if not new_candidates:
                # none found in left, must be in right
                candidates = [num for num in candidates if ask(num, right)]
                positions = right
            else:
                candidates = new_candidates
                positions = left
                
        print("!", candidates[0])
        flush()

if __name__ == "__main__":
    solve()
```コードは最初に定義します`ask`インタラクターにクエリを実行します。 保守します`positions`そして`candidates`。 各反復で分割します`positions`を半分にして、各候補が左半分に出現するかどうかを尋ねます。 左側に候補が出現しない場合は、右側に出現する必要があるため、両方を更新します。`positions`そして`candidates`それに応じて。 最終的に、候補は 1 つだけ残り、それが固有の番号になります。 インタラクションのタイミングを処理するために出力を一貫してフラッシュします。 境界条件には以下が含まれます`n = 1`最後に残った候補は、両方とも while ループと最終出力によって処理されます。 

## 実用的な例

 ### 例 1

 入力配列の長さ`2n-1 = 3`、隠し配列`[2,2,1]`、`n=2`:

 | ポジション | 候補者 | クエリ | 応答 | 新規候補者 |
 | --- | --- | --- | --- | --- |
 | [1,2,3] | [1,2] | ask(1,[1,2]) | 0 | [1] |
 | [3] | [1] | - | - | 1 |

 アルゴリズムは位置 1 と 2 をクエリします。`1`。 応答は 0 であるため、一意の番号は次のようになります。`1`。 出力します`1`。 

### 例 2

 隠し配列`[1,2,3,2,1]`、`n=3`:

 | ポジション | 候補者 | クエリ | 応答 | 新規候補者 |
 | --- | --- | --- | --- | --- |
 | [1,2,3,4,5] | [1,2,3] | ask(1,[1,2]) | 1 | [1] |
 | [3,4,5] | [1] | ask(1,[3,4,5]) | 0 | 1 |

 サブセットをクエリすることで、2 回出現する数値を削除し、保持します。`3`ユニークな要素として。 

これらのトレースは、位置を分割してサブセットをクエリすると、不変式を維持しながら候補を確実に削減できることを示しています。
