 ## 解決策
 ## 問題の理解

 プレイヤーがゲームでスキルを解除しながら収益を最大化したいというシナリオが与えられています。 がある`n`スキルはそれぞれ、以前にロック解除された特定のスキルを必要とし、ロックが解除された場合はコイン報酬を提供します。 一部のスキルは前提条件なしですぐにロックを解除できますが、他のスキルは事前のスキルの組み合わせが必要です。 目標は、これらの前提条件を尊重したロック解除スキルの順序を選択することで、プレイヤーが獲得できるコインの最大合計を計算することです。 

入力では、各スキルの報酬とその前提条件が説明されます。 出力は、制約の下で達成可能な最大コインです。 

制約は十分小さいので、`n`これは、スキルのすべてのサブセットを反復するソリューションが実行可能であることを直ちに示唆しています。`2^20`は約 100 万であり、一般的な計算制限内に十分収まります。 ただし、ロック解除命令のすべての順列を試す単純なアプローチでは、`n!`操作は大きすぎます`n=20`。 したがって、サブセットやビットマスクに対する動的プログラミングなどの手法を考慮する必要があります。 

エッジケースは微妙です。 1 つは、最初はロック解除可能ですが報酬がゼロのスキルです。 もう 1 つは、ロックを解除するために他のすべてのスキルを必要とするスキルです。 たとえば、スキル 3 にスキル 1 と 2 が必要な 3 つのスキルの場合、最適な順序では、3 の前に 1 と 2 のロックを解除することを考慮する必要があります。最も高い報酬だけを最初に選択する不注意で貪欲なアプローチは失敗する可能性があります。 

## アプローチ

 ブルートフォースアプローチとは、スキルを解除するあらゆる順序を考慮することです。 の順列ごとに、`n`スキルの場合、各ステップで前提条件が満たされているかどうかを確認し、ロック解除されたスキルの報酬を合計します。 これにより正確性が保証されますが、次のことが必要です。`n!`最悪の場合の操作は実行不可能です。`n=20`。 

最適なアプローチは、ビットマスク動的プログラミングを活用します。 スキルの各サブセットは、長さのビットマスクとして表現できます。`n`、対応するスキルがロック解除されている場合、ビットが設定されます。 DP 状態`dp[mask]`サブセットのロックを解除した後に取得できる最大コインを表します`mask`。 重要な観察は、すべてのサブセットを反復処理し、現在のマスクで前提条件が満たされている場合、それぞれに対して 1 つの新しいスキルの追加を検討できるということです。 これにより、ソリューションのスペースが削減されます。`n!`への順列`n * 2^n`移行は許容されます`n ≤ 20`。 

ブルートフォースはあらゆる可能性を考慮するため機能しますが、次の場合には失敗します。`n`大きいです。 問題がサブセット間の遷移として表現できるという観察により、問題をビットマスク上の DP に減らすことができ、効率的で不必要なチェックを回避できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | ビットマスク DP | O(n * 2^n) | O(2^n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取り、各テスト ケースを繰り返します。 
2. スキルごとに、そのコイン報酬と前提条件のビットマスクを保存します。 
3. サイズの DP 配列を初期化します。`2^n`負の無限大を除く`dp[0] = 0`ロック解除されたスキルがないため、コインはゼロになります。 
4. すべてのマスクを反復処理します。`0`に`2^n - 1`。 マスクごとに、新しいスキルのロックを解除することを検討してください`i`まだマスクに入っていない。 
5. 現在のマスクにスキルの前提条件がすべて含まれているかどうか`i`、ビットを設定して新しいマスクを計算します`i`。 アップデート`dp[new_mask]`現在の値の最大値として、`dp[mask] + coins[i]`。 
6. すべてのマスクを処理した後、答えは、ロック解除されたスキルのサブセットに対応する DP 配列の最大値になります。 

不変条件とは、`dp[mask]`ロック解除されたスキルの正確なセットに対して取得できる最大のコインを常に保持します。 すべてのサブセットとすべての追加スキルを体系的に調査するため、有効な移行をスキップすることはありません。 有効なシーケンスが失われることはないため、最後に計算される最大値が正しいことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        coins = []
        prereq_masks = []
        for _ in range(n):
            parts = list(map(int, input().split()))
            c = parts[0]
            k = parts[1]
            prereqs = parts[2:] if k > 0 else []
            mask = 0
            for p in prereqs:
                mask |= 1 << (p - 1)
            coins.append(c)
            prereq_masks.append(mask)
        
        dp = [-1] * (1 << n)
        dp[0] = 0
        for mask in range(1 << n):
            if dp[mask] == -1:
                continue
            for i in range(n):
                if not (mask & (1 << i)) and (mask & prereq_masks[i]) == prereq_masks[i]:
                    new_mask = mask | (1 << i)
                    dp[new_mask] = max(dp[new_mask], dp[mask] + coins[i])
        
        print(max(dp))

if __name__ == "__main__":
    solve()
```このソリューションは入力を効率的に読み取り、前提条件のマスクを構築します。 DP 配列は各サブセットの最大コインを追跡し、前提条件が満たされた場合にのみ遷移が発生します。 慎重なビット単位の操作により、スキルが時期尚早にロック解除されることがなくなります。 使用する`-1`初期化されていない状態の場合、無効なサブセットと誤って合計することを回避します。
