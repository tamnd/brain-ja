 ## 解決策
 ## 問題の理解

 正、負、またはゼロの整数の配列が与えられます。 任意の 2 つのインデックスを選択する操作を実行できます。$i$そして$j$の値を追加します$a_j$に$a_i$。 目標は、配列を非減少シーケンスに変換することです。これは、各要素が最大でも次の要素と等しいことを意味します。 タスクは操作の数を最小限に抑えることではなく、各テスト ケースで最大 50 回の操作以内で目標を達成することです。 

重要な制約は次のとおりです。$n \le 20$そして各要素は間にあります$-20$そして$20$。 これは、次のことを行う余裕があることを意味します$O(n^2)$必要に応じてさらに多くの操作を行うこともできます。$n$小さいです。 主な課題は効率ではなく、**建設的な推論**です。つまり、体系的に反転を排除するためにどの要素をどの要素に追加するかを決定することです。 

エッジ ケースは、配列にすべて負の数、すべて正の数、ゼロ、または大きな負の数と正の数が混在している場合に発生します。 たとえば、配列が次の場合、$[1, -10, 2]$、正の数値を前方に加算するだけの不注意な戦略は、2 番目の位置の負の値を除去できない可能性があります。 もう 1 つの微妙なシナリオは、配列がすでに非減少である場合です。この場合、ソリューションは単純にゼロ演算を出力する必要があります。 

## アプローチ

 素朴なアプローチは、配列の反転を繰り返しスキャンすることです ($a_i > a_{i+1}$) それらの 1 つに他の要素を追加して修正してみてください。 これは原理的には機能しますが、数値によっては修正するために追加を繰り返す必要があるため、50 回の操作以内で正確さを保証するのは困難です。 

重要な洞察は、他のすべての要素を望ましい方向に進めるのに十分なほど極端な **ピボット要素 ** を特定することです。 配列に正の数値が含まれている場合、最大の正の数値を任意の要素に繰り返し追加して、少なくとも前の要素と同じ大きさにすることができます。 同様に、負の数がある場合、最も負の数を使用して、逆方向に要素を減らすことができます。 これらの極値から加算を伝播することにより、最大でもすべての反転を体系的に除去できます。$2n$これは、許容される 50 の範囲内に十分に収まります。$n \le 20$。 

正の最大値から加算するか、負の最小値から加算するかの選択は、どちらが絶対値が大きいかによって決まります。 これにより、非減少配列への最速の収束が保証されます。

 ## アルゴリズムのチュートリアル

 1. 配列内の最大絶対値を持つ要素を特定します。 これをピボット要素とします。 複数の要素の絶対値が同じ場合は、いずれかを選択します。 この要素は、追加を他の要素に伝播するために使用されます。 
2. ピボットが正の場合、左端の要素から右に向かって繰り返します。 インデックスごとに$i > 0$、 もし$a_i < a_{i-1}$、ピボットを追加する操作を実行します。$a_i$それまで$a_i \ge a_{i-1}$。 各操作を記録します。 
3. ピボットが負の場合、右端の要素から左に向かって繰り返します。 インデックスごとに$i < n-1$、 もし$a_i > a_{i+1}$、ピボットを追加する操作を実行します。$a_i$それまで$a_i \le a_{i+1}$。 各操作を記録します。 
4. 連続する要素のすべてのペアが満たされると、$a_i \le a_{i+1}$、配列は非減少です。 記録した操作を出力します。 
5. 他の要素を「プッシュ」するために常に最大の絶対値を持つ要素を使用するため、操作の数は小さな定数倍によって制限されます。$n$、操作が 50 を超えないようにします。$n \le 20$。 

機能する理由: ピボットベースのアプローチでは、電流の差を克服するのに十分な大きさの要素を使用してすべての反転が補正されるため、単調性が保証されます。 左から右 (負のピボットの場合は右から左) に伝播することで、修正によってすでに処理された位置に新しい反転が作成されなくなります。 不変条件は、要素を処理した後のものです。$i$、すべてのポジション$0$を通して$i$満足する$a_j \le a_{j+1}$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    ops = []
    
    # Find pivot element with maximum absolute value
    max_val = max(a, key=abs)
    pivot_index = a.index(max_val)
    
    if max_val >= 0:
        # Positive pivot: propagate from left to right
        for i in range(n):
            if i == 0:
                continue
            while a[i] < a[i-1]:
                a[i] += max_val
                ops.append((i+1, pivot_index+1))
    else:
        # Negative pivot: propagate from right to left
        for i in reversed(range(n-1)):
            while a[i] > a[i+1]:
                a[i] += max_val
                ops.append((i+1, pivot_index+1))
    
    print(len(ops))
    for x, y in ops:
        print(x, y)
```コードはまず、最大の大きさを持つピボット要素を特定します。 ピボットの符号に応じて 2 つの伝播戦略のいずれかを使用して、ピボットを繰り返し追加して反転を修正します。 各操作は記録され、最後に印刷されます。 インデックス付けは、0 ベースの Python リストから 1 ベースの問題ステートメントに調整されます。 

## 実用的な例

 ### 例 1

 入力:`[2, 1]`ピボット: 2 (インデックス 0)

 伝播: 左から右へ、$a_1 = 1 < 2$、ピボットを追加します。$1 + 2 = 3$操作:`(2,1)`最終的な配列:`[2,3]`| 私 | a[i] 前 | | の後の a[i] 操作 |
 | --- | --- | --- | --- |
 | 1 | 1 | 3 | (2,1) |

 これは、ピボットを使用した単一の加算によって反転がどのように修正されるかを示しています。 

### 例 2

 入力:`[1, 2, -10, 3]`ピボット: 3 (インデックス 3)

 左から右への伝播:

 - i=2: -10 < 2、ピボットの追加: -10 + 3 = -7 (≥2 になるまで繰り返し、数回の操作)
 - i=3: 3 ≥ -7、完了

 操作ではピボットを使用して追加が記録され、最終的な配列は非減少になります。`[1,2,2,3]`。
