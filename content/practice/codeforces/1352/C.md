## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())

        # number of full blocks of size (n-1) valid numbers
        blocks = (k - 1) // (n - 1)

        # position after accounting for removed multiples
        ans = blocks * n + (k - blocks * (n - 1))

        print(ans)

if __name__ == "__main__":
    solve()

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

 ## 特殊なケース

 いつ`k`非常に小さいです、例えば`k = 1`、この式はまだ機能します。`(k - 1) // (n - 1)`がゼロになり、最初の有効な数値に答えが正しく配置されます。これは常に`1`。 

いつ`k`はまさに次の倍数です`n - 1`、計算はブロックの境界に正確に到達します。 その状況では、次の乗算は`n`除外された倍数を正しくスキップし、剰余の調整により禁止された倍数への踏み込みを回避します。 

いつ`n`が非常に大きい場合、ブロック サイズは非常にまばらになり、ほぼすべての数値が有効になります。 式はきれいに退化して戻ります`k`または`k + 1`アラインメントに応じて、特別な処理を必要とせずに直感的なシーケンス構造と一致します。
