 ## 問題の理解

 与えられた整数を分割するように求められます$n$正確に$k$すべての部分が同じパリティを共有するような正の部分。 これは、すべて奇数かすべて偶数のいずれかを選択する必要があることを意味します。$k$数値の合計は正確に次のようにする必要があります$n$。 

出力は、そのようなシーケンスの具体的な構造か、そのような構造が存在しないという宣言のいずれかです。 有効な分解を自由に出力できるため、最適な解決策や独自の解決策を探しているのではなく、実現可能性と 1 つの例を検索しているだけです。 

制約により許可されるのは、$n$まで$10^9$最大 1000 のテスト ケース、$k \le 100$。 これにより、パーティションの指数関数的またはテストごとのブルート フォース列挙が即座に排除されます。 たとえ$O(n)$テストごとのアプローチは全体として遅すぎるでしょう。 問題の構造は、テスト ケースごとの定数時間の算術チェックを強く示唆しています。 

主な困難は、パリティが選択された後に数値を構築することではなく、正の制約​​を維持しながらそのような選択が可能であることを保証することです。 

いくつかのエッジな状況では、素朴な推論が失敗する場所が明らかになります。 常に奇数を使用しようとすると、パリティの不一致が発生する可能性があります。 例えば、$n = 10, k = 3$動作しますが、$n = 8, k = 7$7 つの奇数の正の最小和は 7 ですが、パリティ制約も失敗するため、そうではありません。 もう 1 つの微妙な失敗は、パリティを暗黙的に混合するときに発生します。たとえば、ほとんどの値を貪欲に選択した後で「最後にパリティを修正」しようとすると、すべての値が一致するという要件が破られます。$k$数値は同一のパリティを持つ必要があります。 

## アプローチ

 強引な解釈では、あらゆる方法で選択を試みることになります。$k$正の整数を取得し、その合計が次であるかどうかを確認します。$n$、すべて奇数かすべて偶数に制限します。 1 つのパリティに限定したとしても、組成の数はおおよそ組み合わせ的に増加します。$\binom{n-1}{k-1}$、これは、 の小さな値であっても完全に実行不可能です。$n$。 このアプローチは数学的には正しいですが、計算的には使用できません。 

重要な観察は、パリティが固定されると、有効な数値の構造が非常に厳格になるということです。 すべての数値が奇数の場合、それぞれの数値は少なくとも 1 です。すべての数値が偶数の場合、それぞれの数値は少なくとも 2 です。これにより、問題は、最小値を割り当てた後の残りの合計が 2 のステップで分配できるかどうかを確認することになります。 

奇数パリティの場合、次のように割り当てます。$k$もの、消費する$k$から$n$。 残りの合計は偶数である必要があるため、これらに加えた 2 の増分に分割できます。 偶数パリティの場合、次のように割り当てます。$k$2、消費$2k$から$n$。 残りの合計は負ではなく、偶数である必要があります。 

これにより、問題は 2 つの単純な実現可能性チェックに変換され、その後に単純な構築が行われます。

 ## アルゴリズムのチュートリアル

 各テストケースを個別に評価します。 

1. 奇数を使用できるかどうかを確認します。 すべてに 1 を割り当てることから始めます$k$ポジション。 これは、$k$合計額。 残りを計算します$r = n - k$。 もし$r \ge 0$そして$r$が偶数であれば、この構成は完了できます。 偶数の余りは、正またはパリティを壊すことなく、任意の位置に繰り返し 2 を加算することで分配できます。 
2. 奇数の構築が失敗した場合は、偶数の数を試してください。 すべてに 2 を割り当てます$k$ポジション。 これは、$2k$、出発$r = n - 2k$。 もし$r \ge 0$そして$r$が偶数である場合、配列全体に 2 のステップで分散できます。 
3. 両方の試行が失敗した場合は、NO を出力します。 
4. 構築が成功したら、基本配列 (すべて 1 またはすべて 2) から開始し、任意の位置 (通常は簡単にするために最初の位置) に 2 を繰り返し加算して残りを分配します。 

2 を追加すると有効性が維持されるのは、正の値を維持しながらパリティを変更しないためです。 

### なぜ効果があるのか

 有効な解はすべて、完全に奇数であるか、完全に偶数である必要があります。 すべて奇数の場合、各要素から 1 を引くと、負ではない偶数が全体に分散されます。$k$スロット。 これは、合計が少なくとも次の値でなければならないことを意味します$k$とは異なります$k$偶数で。 同じロジックが、基本値 2 の偶数にも適用されます。すべての奇数が少なくとも 1 に寄与し、すべての偶数が少なくとも 2 に寄与し、パリティによってステップ サイズが 2 増分に固定されるため、これらは十分条件であるだけでなく、必要条件でもあります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())

    # try odd: all 1s
    if n >= k and (n - k) % 2 == 0:
        base = [1] * k
        rem = n - k
        base[0] += rem
        print("YES")
        print(*base)
        continue

    # try even: all 2s
    if n >= 2 * k and (n - 2 * k) % 2 == 0:
        base = [2] * k
        rem = n - 2 * k
        base[0] += rem
        print("YES")
        print(*base)
        continue

    print("NO")
```最初のブロックは、すべて奇数の構築の実現可能性をチェックします。 条件$n \ge k$各要素が少なくとも 1 であるため、正であることが保証されます。パリティ条件により、残りを 2 の増分に分割できることが保証されます。 

2 番目のブロックでは、要素ごとの最小値が 1 ではなく 2 である全偶数構築と同じ推論を繰り返します。 

簡単にするために、残りをすべて最初の要素に分配します。 偶数を加算すると正数性とパリティ性の両方が維持されるため、これは安全です。

 ## 特殊なケース

 のために$n = k$、すべての 1 の合計が正確に一致するため、奇妙な構築は常に成功します。$k$、有効な全奇数シーケンスが生成されます。 アルゴリズムは次のものを正しく受け入れます$n - k = 0$、偶数剰余条件を満たします。 

のために$n = 2k$、偶数構造では、剰余がゼロのすべて 2 が生成されます。 条件$n \ge 2k$そして$(n - 2k) \% 2 = 0$が成立するため、出力は有効になります。 

のために$n < k$、可能な限り最小の合計でも、両方の構築はすぐに失敗します。$k$正の整数は$k$すべてが 1 の場合。アルゴリズムは、構築を試みる前に正しく拒否します。 

以下の場合については、$n - k$が奇数だが負ではない場合、十分な合計があるにもかかわらず、奇数の構築は失敗します。 これは重要なパリティ制限を捉えています。つまり、残りの質量は非負であるだけでなく、2 のステップに分割できる必要があります。
