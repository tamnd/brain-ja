 ## 解決策
 ## 問題の理解

 次のサイズの整数の長方形グリッドが与えられます。$n \times m$そしてそれを「素敵な」行列に変換したいと考えています。 行列は、すべての行とすべての列が前方と後方で同じ内容を読み取る、つまり回文である場合に優れています。 たとえば、行`[1, 2, 3, 2, 1]`は回文であり、列も同様です`[4, 7, 7, 4]`。 

許可される唯一の操作は、単一要素を 1 ずつインクリメントまたはデクリメントすることです。目的は、行列を適切なものにするためのそのような操作の最小数を見つけることです。 入力は複数のテスト ケースを与え、それぞれが行列の次元と行列自体を指定します。 出力は、各テスト ケースの最小操作数です。 

制約$1 \le n, m \le 100$行列が十分に小さいことを意味します。$O(n \cdot m)$解決策ですが、次のようなものには大きすぎます$O((n \cdot m)^2)$考えられるすべての変換を反復する必要がある場合。 各行列要素は次のように大きくできます。$10^9$したがって、要素の値に応じてスケーリングする操作は避けなければなりません。 

エッジ ケースは、単一の行または単一の列を含む行列です。 このような場合、行または列を回文にするには、ミラーリングされた対応する要素と一致するようにいくつかの要素を調整する必要がある場合があります。 たとえば、`1x5`マトリックス`[1, 3, 5, 3, 2]`になるはずです`[1, 3, 5, 3, 1]`最後の要素に対して 1 つの操作を使用します。 単純なアプローチでは、行と列の間の対称性が無視され、変更が誤って二重カウントされる可能性があります。 

もう 1 つの微妙なケースは、次のような両方の次元が奇数の行列です。`3x3`。 中心要素はすべての回文制約間で共有されますが、一致する必要があるのはそれ自体のみであるため、操作は必要ありません。 

## アプローチ

 ブルートフォース手法では、すべての行と列が回文になるまで各要素をインクリメントまたはデクリメントしようとします。 これは原理的には正しいですが、最大で次の時間がかかる可能性があるため、遅すぎます。$10^9$要素ごとの操作は実行不可能です。 

より良いアプローチは対称性を利用します。 各要素には、マトリックス内に最大 4 つの対称的な対応物 (水平ミラー、垂直ミラー、およびその両方) があります。 たとえば、`4x4`行列、要素`(0,0)`一致する必要があります`(0,3)`、`(3,0)`、 そして`(3,3)`。 重要な洞察は、これら 4 つの数値を最小ステップ数で等しくする必要があるということです。 これを行う最適な方法は、中央値との差の絶対値の合計が最小化されるため、4 つの数値すべてを中央値に変更することです。 

行列の左上の象限のみを反復処理し、ミラー化された 4 つの要素の各グループを収集することで、各グループの最小演算数を計算し、それらを合計することができます。 もし$n$または$m$が奇数である場合、一部のグループには 2 つの対称要素 (中央の行または列) または 1 つの要素 (行列の中心) のみが含まれます。これは、小さいグループの中央値を使用して同様に処理します。 

これにより、処理の問題が軽減されます$\lceil n/2 \rceil \cdot \lceil m/2 \rceil$それぞれ最大 4 つの数値のグループを作成するため、高速で最適性が保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * m * 最大要素) | O(n * m) | 遅すぎる |
 | 最適 (対称 + 中央値) | O(n * m) | O(1) おまけ | 承認済み |

 ## アルゴリズムのチュートリアル

 1. インデックスを使用して行列を反復処理します。`i`から`0`に`(n-1)//2`そして`j`から`0`に`(m-1)//2`。 これにより、左上の象限にのみアクセスし、各対称グループを 1 回ずつ処理することが保証されます。 
2. ポジションごとに`(i, j)`、対称要素を特定します。`(i,j)`、`(i, m-j-1)`、`(n-i-1, j)`、`(n-i-1, m-j-1)`。 それらの値をリストに収集します。 
3. リストをソートし、中央値を計算します。 4 つの要素の場合、中央値は並べ替え後の 2 番目または 3 番目の要素となり、絶対差の合計が最小になります。 
4. グループ内の各要素と中央値の間の絶対差を合計します。 これにより、そのグループに必要な操作の最小限の数が得られます。 
5. すべてのグループについてこの合計を累積します。 もし`n`または`m`が奇数の場合は、中央の行と列を同様に処理しますが、一部のグループには 2 つの要素だけ、または 1 つの要素しかありません。 
6. テスト ケースの答えとして合計を出力します。 

機能する理由: 行列内のすべての要素は、最終的な値を決定する 1 つの対称グループに属します。 すべての値を中央値に変更すると絶対差の合計が最小化されるため、各グループの中央値を常に選択することで、操作の合計数が最小限に抑えられることが保証されます。 これにより、行と列の両方の回文性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def min_operations_to_nice(matrix, n, m):
    ops = 0
    for i in range((n + 1) // 2):
        for j in range((m + 1) // 2):
            group = [
                matrix[i][j],
                matrix[i][m - j - 1],
                matrix[n - i - 1][j],
                matrix[n - i - 1][m - j - 1]
            ]
            group = list(set(group)) if i == n - i - 1 or j == m - j - 1 else group
            group.sort()
            median = group[len(group) // 2]
            ops += sum(abs(x - median) for x in group)
    return ops

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    matrix = [list(map(int, input().split())) for _ in range(n)]
    print(min_operations_to_nice(matrix, n, m))
```コードはすべてのテスト ケースを読み取り、行列の左上の象限のみを反復処理し、対称グループを計算し、中央値を使用して演算を最小限に抑えます。 条件付き`list(set(group))`次元が奇数の場合に中央の行/列の重複を処理し、二重カウントを回避します。 絶対差の合計が累積され、出力されます。
