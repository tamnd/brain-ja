 ## 解決策
 ## 問題の理解

 2 行のグリッドがあります。$m$列。各セルは特定の時間にのみアクセス可能になります。 ロボットは左上のセルから開始します$(1,1)$すべてのセルを 1 回だけ訪問し、隣接するセルにのみ移動するか、その場に 1 秒間留まる必要があります。 目標は、すべてのセルを走査するための最小合計時間を見つけることです。 

各テスト ケースには列の数が示されます。$m$および長さの 2 つのシーケンス$m$上部と下部の行のロック解除時間を表します。 出力は、ロボットが移動を完了するまでの最小時間です。 

制約は、次の合計が$m$すべてのテスト ケースで最大でも$2 \cdot 10^5$、したがって、次のような解決策があります$O(m^2)$複雑さは実現不可能です。 テスト ケースごとに線形または線形に近いアプローチが必要です。 ロック解除時間は次のとおりです$10^9$したがって、算術演算には注意する必要があり、毎秒の明示的な状態ストレージを備えた単純な BFS に依存することはできません。 

素朴なソリューションを壊す可能性のあるエッジケースには、ロボットがあまりにも貪欲に動く場合に待機が必要となる、一番上の行または一番下の行のロック解除時間が増加するグリッドや、次のような非常に小さなグリッドが含まれます。$2 \times 2$ここでは、走査順序が合計時間に重大な影響を与えます。 

## アプローチ

 ブルート フォース ソリューションでは、グリッドを通るあらゆる可能なパスを試行し、グリッドを通過する時間をシミュレートします。 あるので$2m$セルの順列の数は$(2m)!$、これはまったく手に負えません。 ロボットは次のセルに入る前にセル内で待機する必要があり、最適な順序が明らかではないため、すべてのパスを貪欲に試しても失敗する可能性があります。 

重要な洞察は、有効なトラバースは、必要な場合にのみ 1 つの行に沿って右に移動しながら、もう 1 つの行にジグザグに移動するものとして説明できることに気づくことから得られます。 基本的に 2 つの自然なパターンがあります。一番上の行から開始し、「ヘビ」パターンで移動し、一番下の列または一番上の列で終了します。 ロボットはセル内で待機できるため、ロック解除時間の最大値とそのセルに到達するまでの時間を考慮することで、各パターンの最小時間を効率的に計算できます。 

もう 1 つの重要な観察は、プレフィックスとサフィックスの最大値を使用して最適なパスを逆算できることです。 各列の残りのセルを終了するのに必要な時間を考慮することで、線形時間で可能な最小終了時間を計算できます。 これにより問題は次のように縮小されます$O(m)$テストケースごとに。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((2m)!) | O(2m) | 遅すぎる |
 | 最適なスネーク + プレフィックス/サフィックス | O(m) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$m$上段と下段のロック解除時間。 これらをそのままにしておきます`top`そして`bottom`。 
2. ロボットが残りのセルをジグザグ パターンで移動する場合に必要な最小時間を表す 2 つの接尾語配列を計算します。 させて`top_suffix[i]`そして`bottom_suffix[i]`列の右側にあるすべてのセルを走査するのに必要な最大時間です。`i`から始まる`i`それぞれの行に。 
3.初期化`current_time`0 として設定し、スネーク パターンのように行を交互に列ごとに移動することをシミュレートします。 各セルで更新します`current_time`ロボットの到着時間とセルのロック解除時間の最大値として。 
4. 各列について`i`、事前に計算されたサフィックスの最大値を使用して、ロボットがその列で行を切り替えた場合の合計終了時間を計算します。 考えられるすべての切り替えポイントにわたる最小終了時間を追跡します。 
5. テスト ケースの最小終了時間を出力します。 

重要な不変条件は、サフィックスの最大値を使用することにより、現在の位置に応じて残りのセルの可能な最も早い終了時刻が常にわかるということです。 ロボットは行の切り替えを列ごとに 1 回だけ考慮する必要があり、サフィックス配列によって正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        m = int(input())
        top = list(map(int, input().split()))
        bottom = list(map(int, input().split()))
        
        # Precompute suffix maximums for top and bottom
        top_suffix = [0] * m
        bottom_suffix = [0] * m
        for i in reversed(range(m)):
            if i == m - 1:
                top_suffix[i] = top[i]
                bottom_suffix[i] = bottom[i]
            else:
                top_suffix[i] = max(top[i], top_suffix[i + 1] - 1)
                bottom_suffix[i] = max(bottom[i], bottom_suffix[i + 1] - 1)
        
        ans = float('inf')
        time = 0
        for i in range(m):
            if i % 2 == 0:
                # Top row first, then bottom row
                finish_time = max(time + (m - i - 1) * 2, bottom_suffix[i])
            else:
                # Bottom row first, then top row
                finish_time = max(time + (m - i - 1) * 2, top_suffix[i])
            ans = min(ans, finish_time)
            # Move to next column in snake pattern
            if i % 2 == 0:
                time = max(time + 1, top[i]) + 1
            else:
                time = max(time + 1, bottom[i]) + 1
        print(ans)

solve()
```このソリューションでは、最初にサフィックス配列を構築して、残りの列を完了するまでにかかる時間を確認します。 スネーク パターンのトラバーサルにより、各列が効率的に考慮されます。 の`max`操作は、セルのロックが解除されるのを待機する処理を処理します。 エッジケースなど`m = 2`または、すべてのロック解除時間がゼロである場合も、この計算によって自然に処理されます。
