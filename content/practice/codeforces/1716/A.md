 ## 問題の理解

 私たちは数直線上の位置 0 に立っていて、目標の座標に到達したいと考えています。`n`。 1 分間に、どちらの方向にも 2 つまたは 3 つのユニットを移動できます。 タスクは、到達するまでに必要な最小時間を計算することです。`n`その通り。 入力は次のもので構成されます`t`テスト ケース、それぞれが 1 つの整数を与える`n`。 それぞれについて`n`、必要な最小の手数を出力する必要があります。 

重要な制約は次のとおりです。`n`と同じ大きさにすることができます$10^9$まであります$10^4$テストケース。 これにより、ポジションを反復したり、すべての一連の動きを明示的に試行したりするソリューションは除外されます。これは、遅すぎるためです。 代わりに、テスト ケースごとに一定時間または対数時間で機能するアプローチが必要です。 

微妙なエッジケースは次のような場合です`n`特に小さいです`1`。 2か3ずつしか動かせないので、1回で1に到達することはできません。 この場合、最小手数は 2 になります。つまり、2 前進して 1 後退するか、3 前進して 2 後退して、結果はちょうど 1 になります。同様に、2 または 3 で割り切れない数値はすべて慎重に扱う必要があります。 ナイーブ`n // 3`または`n // 2`このような小さなオフセットの場合、計算は失敗します。 

## アプローチ

 ブルートフォースアプローチは、到達するまであらゆる動きの組み合わせをシミュレートすることです。`n`。 これは、合計が等しくなるまで 2 と 3 のすべてのシーケンスを試すことで機能します。`n`。 これは正しいです。最終的には、2 と 3 の組み合わせを加算することで任意の整数に到達できるからです。 ただし、その複雑さは指数関数的です。 もし`n`は$10^9$、これには時間がかかりすぎます。 

重要な洞察はモジュラー演算から得られます。 2 と 3 の最大公約数は 1 であるため、すべての数値は 2 と 3 の組み合わせとして表現できます。これにより到達可能性が保証されます。 手数を最小限に抑えるために、最初に可能な最大手 3 を選択し、残りを 2 で埋めます。 

具体的には、特定の`n`、推定できます`n // 3`3 を移動します。余りが 0 であれば、完了です。 余りが 1 の場合、1 つの 3 を 2 つの 2 に置き換える必要があり、合計の手数が 1 増えます。余りが 2 の場合は、単純に 2 の手をもう 1 つ追加します。 このロジックは、大小を問わずすべての正の整数に対して機能し、テスト ケースごとに一定時間で実行されます。

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`。 目標は、到達するまでの最小手数を計算することです。`n`サイズ 2 または 3 の動きを使用して 0 から。 
2. コンピューティング`q`として`n // 3`そして`r`として`n % 3`。 ここ`q`は 3 ユニットの移動の最大数を表し、`r`は、まだカバーする必要がある残りの距離です。 
3. もし`r`が 0 の場合、答えは単純です。`q`3ユニットの動きが正確にカバーするため`n`。 
4. もし`r`が 1 の場合、1 回の 2 ユニット移動ではカバーできないため、3 ユニット移動を 1 回減らしてスペースを作り、2 ユニット移動を 2 回使用して余った距離をカバーします。 これにより、移動回数が 1 増加します。 
5. もし`r`が 2 の場合、2 ユニットの移動を 1 回追加することでカバーできるため、移動の合計は次のようになります。`q + 1`。 

機能する理由: 2 と 3 の組み合わせを使用すると、すべての整数に到達できます。 最初に 3 ユニットの移動を最大化することで、総移動数を最小限に抑えます。 残りに基づいて調整することで、残りの距離が最適にカバーされるようになります。 この公式により、手数が過小評価されないことが保証されます。これは、残りが 2 を追加するか、3 を 2 つの 2 に置き換えることによって修正されるためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    q, r = divmod(n, 3)
    if r == 0:
        print(q)
    elif r == 1:
        if q >= 1:
            print(q + 1)  # replace one 3 with two 2s
        else:
            print(2)      # n=1 or n=1 scenario
    else:  # r == 2
        print(q + 1)
```の`divmod`機能分割`n`商と余りを効率的に計算します。 残りを確認し、それに応じて動きを調整します。 繊細さは非常に小さいものを扱うことです`n`交換するのに十分な 3 ユニットの移動がない場合は値 (1 など) を使用するため、そのシナリオでは手動で 2 つの移動を返します。

            if q >= 1:

            else:
                print(2)
        else:
            print(q + 1)
