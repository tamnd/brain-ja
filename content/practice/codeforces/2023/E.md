 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、`n`によって接続されているノード`n-1`エッジ。 各ノードは魔法のエネルギーの源と考えることができ、各エッジはこのエネルギーが流れるチャネルと考えることができます。 重要な危険は、2 つ以上のチャネルが 1 つのノードで接触し、中和する必要がある「共鳴」を生成するときに発生します。 無力化は、木を通る道を選択し、それぞれの道に沿って儀式を行うことによって行われます。 パスは、それに沿った連続するエッジのすべてのペアをカバーし、内部ノードでの共振を防ぎます。 

タスクは、同じノードに属するすべてのエッジのペアが少なくとも 1 つのパスでカバーされるように、パスの数を最小限に抑えることです。 これは、次数 2 以上のノードがすべて、選択されたパスによって内部的にカバーされることを保証することと同じです。 

制約が厳しいです。`n`到達できる`5 * 10^5`テスト ケースごとに、テスト ケース全体のノードの総数は同じ数で制限されます。 考えられるすべてのパスまたはエッジのペアをチェックする単純なアプローチは、すぐに実行不可能になります。`n^2`以上。 必要なのは`O(n)`テストケースのソリューションごとに。 

いくつかの明らかではない特殊なケースが発生します。 たとえば、すでに単純なパスであるツリーには、次数が 2 を超える分岐ノードはありません。正解は次のとおりです。`0`カバーするエッジのペアがないためです。 もう 1 つのケースは、1 つの中心ノードが他のすべてのノードに接続された星型ツリーです。 ここで、中心にあるエッジの各ペアは何らかのパスに出現する必要があるため、パスの最小数は正確に次のようになります。`(degree of center) - 1`。 

## アプローチ

 ブルートフォース手法では、長さが 2 以上のパスをすべて列挙し、各ノードの入射エッジがカバーされているかどうかを確認します。 This is clearly impractical: for`n`その周り`5*10^5`、パスの数は組み合わせ的に爆発的に増加します。 すべてのパスを保存してもメモリ制限を超えます。 

重要な洞察は、次数 3 以上のノードのみが問題に寄与していることを認識することです。 程度のノード`d`もっている`d choose 2`カバーする必要があるエッジのペア。 パスは内部的にノードごとに最大 2 つのエッジをカバーできるため、すべてのペアをカバーするには少なくとも`ceil(d/2)`エッジが最適に配置されている場合はパス。 ツリーの場合、さらに単純化すると、必要なパスの最小数は、次数が 2 より大きいノードの数か、最大次数より 1 つ少ない数になります。 後者は計算が容易で、すべての制約を捕捉します。他のすべてのノードのエッジ ペアがそのノードから伸びるパスに含まれる可能性があるため、最大次数を持つノードがボトルネックを決定します。 

実際には、これにより、解はすべてのノードの次数の線形スキャンに縮小され、最大次数が計算され、ツリーがすでに単純なパスである場合は 0 が返されます。`(max degree - 1)`さもないと。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n^2) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、ノードの数を読み取ります。`n`およびツリーを接続するエッジのリスト。 各ノードの次数を格納する配列を初期化します。 
2. エッジを反復処理して、各エンドポイントの次数を増やします。 このパスの後、すべてのノードの次数がわかります。 
3. すべてのノード間の最大次数を計算します。 
4. 最大次数が 2 以下の場合、ツリーは単純なパスであるため、カバーするエッジのペアがなく、答えは 0 になります。 
5. それ以外の場合、エッジのすべてのペアをカバーするために必要なパスの最小数は次のとおりです。`(max degree - 1)`。 これが機能するのは、次数が最大のノードがボトルネックであるためです。各パスは、このノードに付随する最大 2 つのエッジをカバーできるため、最初のエッジを超える追加エッジごとに 1 つのパスが必要になります。 
6. テストケースの結果を出力します。 

これが機能する理由: 不変条件は、最も高い次数を持つノードが最も多くのカバレッジを必要とするということです。 この中心ノードから伸びるパスには他のノードを含めることができるため、最大次数制約を満たす必要があるだけです。 各パスは中央ノードでカバーされていないペアを 1 つ減らすため、必要なパスの総数は次のようになります。`max_degree - 1`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    results = []
    
    for _ in range(t):
        n = int(input())
        degrees = [0] * (n + 1)
        
        for _ in range(n - 1):
            u, v = map(int, input().split())
            degrees[u] += 1
            degrees[v] += 1
        
        max_deg = max(degrees)
        if max_deg <= 2:
            results.append(0)
        else:
            results.append(max_deg - 1)
    
    print("\n".join(map(str, results)))

if __name__ == "__main__":
    solve()
```最初のセクションでは入力を効率的に読み取ります。 次数配列は、各ノードに入射するエッジの数をカウントします。`max(degrees)`ボトルネックノードを見つけます。 を確認しています`max_deg <= 2`単純なパスを処理します。 追加中`max_deg - 1`必要なパスの最小数を示します。 結果リストを使用すると、stdout 呼び出しの繰り返しを回避できます。これは、多くのテスト ケースでの厳しい時間制限にとって重要です。

 ## 特殊なケース

 エッジケース: ツリーはすでにパスです。 入力`5\n1 2\n2 3\n3 4\n4 5`。 アルゴリズムが度をスキャン`[1,2,2,2,1]`。 最大次数は 2 です。出力は 0 で、パスが必要ないことが正しく識別されます。 

エッジケース: 木は大きな中心を持つ星型です。 入力`6\n1 2\n1 3\n1 4\n1 5\n1 6`。 学位`[5,1,1,1,1,1]`、最大次数 5. アルゴリズム出力`5 - 1 = 4`、中心に入射するエッジのすべてのペアをカバーします。
