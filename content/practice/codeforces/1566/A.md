 ## 解決策
 ## 問題の理解

 配列の最大の中央値を決定するように求められます。`n`合計が正確に一致する非負の整数`s`。 中央値は、長さの配列に対して従来の方法で定義されます。`n`： もし`n`が奇数の場合、それはソート順で中央の要素であり、`n`偶数、位置の要素です`n/2 + 1`（四捨五入）。 基本的に、合計の制約を尊重しながら、並べ替えられた配列の中心値を最大化したいと考えています。 

入力により得られるものは、`t`それぞれ配列の長さを指定するテスト ケース`n`そして合計`s`。 両方`n`そして`s`最大10億にもなる可能性があります。 これにより、配列を明示的に構築または反復しようとするソリューションが即座に除外されます。これは、最大サイズの配列が作成されるためです。`10^9`メモリとランタイムでは実行不可能です。 解決策は純粋に算術的である必要があり、次から中央値を導き出します。`n`そして`s`アレイを構築せずに。 

エッジケースは次の場合に発生します。`n`～に比べて非常に小さい、または非常に大きい`s`。 たとえば、次の場合`n=1`、中央値は単純に`s`。 もし`s`が少なくとも中央値と同じ大きさである必要がある要素の数より小さい場合、最大中央値は強制的に引き下げられます。 たとえば、次の場合`n=4`そして`s=2`、中央値は最大で`1`最大の 2 つの要素の合計がこれを超えることはできないため、`2`合計額を超えない範囲で。 

## アプローチ

 素朴なアプローチは、すべて 0 から始まる配列の構築を試み、次に合計が得られるまで中央位置から上向きに要素をインクリメントすることです。`s`に達します。 これは論理的には正しいですが、実行不可能です。 のために`n`そして`s`と同じくらい大きい`10^9`、そのようなシミュレーションには数十億回の操作が必要になります。 

重要な洞察は、中央値を最大化するには、中央値の右側のすべての要素 (中央値自体を含む) をできるだけ大きくする必要がある一方で、中央値より前の要素は最小化 (ゼロに設定) できるということです。 合計は固定されているため、中央値は配列の上半分に分配できる合計の量によって制限されます。 中央値から最後の要素までの要素数は、`ceil(n/2)`、つまり`(n + 1) // 2`整数演算で。 合計を割る`s`これらの位置全体で均等にすると、可能な最大の中央値が得られます。 

つまり、最大中央値は`s // ((n + 1) // 2)`。 この式は、中央値とその後のすべての要素の合計が次を超えないことを保証します。`s`、中央値はできるだけ大きくなります。 これにより、問題が単純な算術計算に削減され、配列の構築が回避されます。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 各テスト ケースには 2 つの整数が含まれます`n`そして`s`。 
2. 各テスト ケースについて、中央値から開始して配列の上半分にある要素の数を計算します。 これは`(n + 1) // 2`。 
3. 合計を割る`s`整数除算を使用してこの数値で計算し、中央値として使用できる最大の整数を取得します。 割り当てる`median = s // ((n + 1) // 2)`。 
4. 各テストケースの結果を出力します。 

機能する理由: 中央値の前の位置にゼロを配置すると、残りの合計を中央値とその後のすべての要素に集中させることができます。 中央値は上半分の平均を超えることはできません。これには、より多くの合計が必要になるためです。`s`。 これにより、配列の合計を維持しながら中央値が最大化されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, s = map(int, input().split())
    median = s // ((n + 1) // 2)
    print(median)
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`、複数のテスト ケースを処理し、整数の除算を使用して中央値を直接計算し、結果を出力します。 オフバイワンエラーはありません。`(n + 1) // 2`の上限を正しく計算します`n/2`。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(sys.stdin.readline())
    for _ in range(t):
        n, s = map(int, sys.stdin.readline().split())
        median = s // ((n + 1) // 2)
        output.append(str(median))
    return "\n".join(output)

 ## 特殊なケース

 いつ`n=1`、中央値は等しい`s`直接。 たとえば、入力`1 1000000000`生成する`1000000000`。 いつ`s`が上半分の要素の数より小さい場合、整数除算により中央値が正しく下限されることが保証されます。 例えば、`n=2, s=1`収量`1 // ((2+1)//2) = 1 // 1 = 1`ただし、合計では中央値が次を超えることはできません。`0`数式のコンテキストで整数の除算を考慮すると、次のようになります。 算術式は、反復チェックを行わずに、両方の極端な値を正しく処理します。
