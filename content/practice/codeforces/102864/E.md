 ## 解決策
 ## 問題の理解

 平面上に整数座標点のセットがあります。 3 つの点が同じ線上に存在することはありません。 点のうち 2 つを選択し、それらを通る線が他のすべての点を同じサイズの 2 つのグループに分割するようにする必要があります。 より正確には、選択した行が終了した場合`n - 2`残りの点は、線の各辺に正確に含まれている必要があります`floor((n - 2) / 2)`ポイント。 

出力は、選択した 2 つの点のインデックスのみです。 そのようなペアが存在しない場合は、次のように出力する必要があります。`-1 -1`。 

制約`n <= 100000`問題についての考え方が変わります。 すべての点のペアをチェックすると、すでに次のことがわかります`10^10`候補行は、1 秒の制限をはるかに超えています。 残りの点の線形スキャンですべてのペアをチェックする場合でも、約`10^15`操作。 解は線形に近いか、`O(n log n)`これは、ペアの検索を避け、代わりに保証された適切なペアを直接見つける必要があることを意味します。 

よくある間違いは、答えには凸包などの特別な幾何学的構造が含まれているに違いないと思い込むことです。 選択した線は 2 つの入力点を通る任意の線であり、バランス状態は各辺に表示される点の数によってのみ決まります。 重要なのは、単一点の周りの方向の循環順序を利用することです。 

不注意な実装を壊す可能性のある境界ケースがいくつかあります。 

のために`n = 2`、残りポイントはありません。 2 点を通る直線は条件を満たすため、答えは 2 点のインデックスになります。 角度配列内に中間点が存在する必要があると仮定した解決策は、ここで失敗する可能性があります。 

例えば：```
2
0 0
1 1
```正しい出力は次のとおりです。```
1 2
```他のポイント リストの中央の要素にアクセスしようとするソリューションは、空のリストにアクセスします。 

もう 1 つのエッジケースは次のような場合です`n`奇数です。 両側のポイントが同じである必要はありません。`floor((n - 2) / 2)`余分な点を意図的に無視します。 

例えば：```
5
0 0
1 0
2 0
3 1
4 2
```は 3 つの点が同一線上にあるため有効な入力ではありませんが、等しい半分について誤って推論する危険性を示しています。 有効な 5 点構成では、選択したラインに含まれるのは片側だけで済みます。`1`ポイントと反対側を含める`2`ポイント。 完全に等しい分割のみを検索する不注意な実装では、有効な回答が誤って拒否されてしまいます。 

大きな座標も実装の詳細です。 到達できる座標`10^9`、したがって、外積は約に達します`10^18`。 Python 整数はこれを安全に処理しますが、固定幅整数の実装には 64 ビット型が必要です。 

## アプローチ

 直接的なアプローチでは、考えられるすべてのポイントのペアを試します。 各ペアについて、外積を使用して、線の左側と右側にある他の点の数を数えることができます。 この条件はまさにこれら 2 つのカウントに関するステートメントであるため、これは正しいです。 ただし、`O(n^2)`可能なペアと、各ペアに必要な`O(n)`チェックする、～につながる`O(n^3)`仕事。 と`n = 100000`、これは不可能です。 

重要な点は、実際にはすべてのペアを検索する必要はないということです。 任意の点をピボットとして選択します。 そのピボットから他のすべてのポイントを確認し、ピボットを中心とした極角で並べ替えます。 ピボットからこれらの点のいずれかへの光線の場合、円形順序でその前に現れるすべての点は対応する線の一方の側にあり、その後のすべての点は反対側にあります。 

入力では 3 つの点が同一線上にないことが保証されるため、他の点は選択した線上に正確に存在することはできません。 これは、角度順序における点の位置が線の片側の点の数を直接示すことを意味します。 

他の点が角度の昇順で保存されている場合は、インデックスの点を選択します`floor((n - 2) / 2)`その前に必要な数のポイントを正確に与えます。 したがって、ピボットからこの点までの線は常に有効な答えになります。 

ブルートフォース ソリューションは、必要なバランス条件を明示的にチェックするため機能しますが、同じ幾何学的カウントを何度も繰り返すため失敗します。 角度順序付けの観察により、候補を 1 つずつテストする必要がなくなり、問題が 1 つの並べ替え操作に変わります。

 ## アルゴリズムのチュートリアル

 1. 任意の入力ポイントをピボットとして選択します。 もし`n = 2`、各辺に必要な点の数がゼロであるため、2 つの点をすぐに出力します。 
2. ピボットから他のすべての点までベクトルを構築します。 最終的な答えには座標ではなくインデックスが必要であるため、各ベクトルは元のポイント インデックスを保持します。 
3. これらのベクトルをピボット周りの方向に基づいて並べ替えます。 順序付けは、浮動小数点角の代わりに外積を使用して行われます。 半平面分割では、ベクトルを一貫した循環順序で配置し、外積によって同じ半分内の順序が決まります。 
4. しましょう`k = floor((n - 2) / 2)`。 位置の点を選択してください`k`ソートされたベクトルリスト内。 

この立場が正しい理由はまさに次のとおりです`k`ベクトルはその前に表示されます。 これらのベクトルは正確に表します`k`ピボットから選択した点までの線の片側にある点。 

1. ピボット インデックスと選択したポイント インデックスを出力します。 

なぜ効果があるのか:

 角度ソートでは、同一直線上にある 3 つの点がないため、ピボットを中心とした 1 つおきの点に一意の位置が与えられます。 ピボットとソート位置の点で形成される線の場合`k`、順序内のすべての以前の点は、正の参照方向と選択した方向の間の方向を持っているため、それらはすべて同じ側にあります。 それ以降の点はすべて反対側にあります。 まさにあります`k`先ほどのポイントと、`k = floor((n - 2) / 2)`, したがって、必要な分割が達成されます。 

## Python ソリューション```python
import sys
from functools import cmp_to_key

input = sys.stdin.readline

def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return

    n = int(data[0])
    points = []
    ptr = 1
    for i in range(n):
        x = int(data[ptr])
        y = int(data[ptr + 1])
        ptr += 2
        points.append((x, y))

    if n == 2:
        print(1, 2)
        return

    px, py = points[0]
    vectors = []

    for i in range(1, n):
        x, y = points[i]
        vectors.append((x - px, y - py, i))

    def half(x, y):
        if y > 0 or (y == 0 and x >= 0):
            return 0
        return 1

    def cmp(a, b):
        ax, ay, _ = a
        bx, by, _ = b

        ha = half(ax, ay)
        hb = half(bx, by)

        if ha != hb:
            return -1 if ha < hb else 1

        cross = ax * by - ay * bx
        if cross > 0:
            return -1
        if cross < 0:
            return 1
        return 0

    vectors.sort(key=cmp_to_key(cmp))

    k = (n - 2) // 2
    answer = vectors[k][2] + 1
    print(1, answer)

if __name__ == "__main__":
    solve()
```コードはピボットを最初の点として固定します。引数はどのピボットに対しても機能するため、これで十分です。 ベクトルはそのピボットを基準とした座標を格納するため、外積の符号は 2 方向の向きを直接表します。 

コンパレータは回避します`atan2`浮動小数点の角度は不要であり、精度の問題が発生する可能性があるためです。 半平面分割により、循環順序が正の x 方向から開始され、反対方向からのベクトルが混在するのを防ぎます。 次に、外積により、各半分の内部で正確な順序が得られます。 

インデックスの計算には次のものを使用します。`(n - 2) // 2`。 ベクトル配列には以下が含まれます`n - 1`ピボットが削除されるため、インデックスが作成されます。`k`は常に有効です。 決勝戦`+ 1`保存されている 0 から始まるインデックスを、問題に必要な 1 から始まるインデックスに変換します。 

Python の整数は任意精度であるため、近傍の座標によって大きな外積が発生します。`10^9`オーバーフローしないでください。

 ## 特殊なケース

 2 点の場合、アルゴリズムは角度順序を作成しようとしません。 唯一の可能な行を即座に返します。 これにより、空のリストへのアクセスが回避され、両側にゼロ点が出現する必要があるという事実と一致します。 

点の数が奇数の場合、選択されるインデックスは整数の除算に基づきます。 たとえば、`n = 5`、ターゲットのサイド数は`floor(3 / 2) = 1`。 アルゴリズムは、角度順序で 2 番目の点を選択し、その前に 1 点、その後に 2 点だけを残します。 2 つの辺は異なるサイズを持つことが許可されているため、これは有効な分割です。 

最大範囲の座標の場合、外積は次のようになります。`4 * 10^18`。 この実装では Python の整数を使用するため、比較は正確なままであり、精度の低下によって順序が変更されることはありません。 

ピボットが凸包の内側または外側にある場合を含む、任意の点分布の場合でも、証明は適用されます。 この解決策は、ピボットが特別であることに決して依存しません。 これは、ピボットを中心とした方向の循環順序付けのみを使用します。これは、3 つの点が同一線上にない場合に常に存在します。
