 ## 問題の理解

 この問題は、建物を繰り返しアップグレードできるゲームについて説明しています。 最初のアップグレードの費用`N1`金。 その後の各アップグレードは、以前のコストに を乗算することにより、より高価になります。`P`、すべてのアップグレードでは常に同じ固定量だけ時間当たりのゴールド生産量が増加します`M`。 選択したアップグレード番号について`Q`, そのアップグレードに費やされたゴールドを回収するには、そのアップグレードだけからの追加のゴールド生産に必要な時間を計算する必要があります。 

の費用は、`Q`-th upgrade は等比級数の用語です。 最初のアップグレードの費用`N1`、2番目のコスト`N1 × P`、Q 番目のアップグレードのコスト`N1 × P^(Q-1)`。 Q 回目のアップグレードのメリットは追加のみであるため、`M`1 時間あたりに生産されるゴールド、答えはアップグレードコストを次の値で割ったものです。`M`。 

テストケースの数は 100 に達する可能性がありますが、`Q`これは、問題に高度な最適化が必要ないことを意味します。 アップグレードごとに少量の作業を実行する方法でも、十分に高速です。 主な困難は、幾何学的な増加と浮動小数点の精度を正しく処理することです。`P`は有理数であり、最終的な答えは小数点以下 1 桁を保持する必要があります。 

アップグレード番号が最初のアップグレードである場合、不注意に実装すると失敗する可能性があります。 たとえば、入力の場合`1000 1.2 100 1`、答えは`10.0`, なぜなら、最初のアップグレードにはちょうど 1000 ゴールドかかるからです。 を使用した式`P^Q`の代わりに`P^(Q-1)`間違って計算してしまう`12.0`。 

もう 1 つのよくある間違いは次のような場合に発生します。`P`等しい`1`。 入力用`1000 1 100 50`、すべてのアップグレードには依然として 1000 ゴールドがかかるため、回復時間は`10.0`。 値が増加し、開始項を考慮せずに繰り返し乗算する必要があると想定して実装すると、誤った結果が生成される可能性があります。 

## アプローチ

 簡単なアプローチは、アップグレードのコストをシミュレーションすることです。 最初のアップグレード費用から始める`N1`、次にコストを乗算します`P`その通り`Q-1`Q 番目のアップグレードに到達するまでの時間。 そのコストを取得したら、それを次のように割ります。`M`。 これが機能するのは、各乗算が等比数列の 1 つの項から次の項に移動するためです。 

ここでは総当たりシミュレーションがすでに効率的になっています。`Q`は 50 に制限されています。最悪のケースでは、各テスト ケースで 49 回の乗算のみが実行されます。 何百万ものアップグレードがあった場合、繰り返し乗算するのは不必要な作業になりますが、所定の制限があるため、このアプローチは完全に十分です。 

より数学的なアプローチでは、等比数列の閉じた形式が使用されます。 Q 番目のアップグレードコストは`N1 × P^(Q-1)`なので、べき乗を直接計算して次で割ることができます。`M`。 これにより、演算の数が減り、関係がより明確に表現されますが、制約が小さいため実際の違いはわずかです。 

重要な点は、以前のアップグレードを計算する必要がないということです。 回復時間は現在のアップグレードのコストと固定生産量の増加のみに依存するため、以前のアップグレードのコストはすべて無関係です。

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        N1, P, M, Q = input().split()
        N1 = int(N1)
        P = float(P)
        M = int(M)
        Q = int(Q)

        cost = N1 * (P ** (Q - 1))
        ans.append(f"{cost / M:.1f}")

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()

指数は使用します`Q - 1`、これが問題の主な境界条件です。 いつ`Q`が 1 の場合、べき乗は 0 になり、Python は正しく評価します。`P ** 0`1 としてコストをそのままにします。`N1`。
