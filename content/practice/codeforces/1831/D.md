 ## 解決策
 ## 問題の理解

 2 つの配列が与えられています`a`そして`b`等しい長さの`n`。 タスクは、インデックス ペアの数をカウントすることです。`(i, j)`と`i < j`の積が`a`これらのインデックスの要素は、対応する要素の合計に等しい`b`要素:`a[i] * a[j] = b[i] + b[j]`。 基本的に、乗法関係が成立する位置の組み合わせを探しています。`a`の加法関係と一致します`b`。 

制約は次のことを教えてくれます`n`まで可能です`2 * 10^5`すべてのテスト ケースの合計で、個々の配列要素は次のように制限されます。`n`。 すべてのペアを検査する素朴な解決策では、大まかに次のことが必要になります。`O(n^2)`テストケースごとの操作。 と`n`まで`2 * 10^5`、これは最悪の場合 10^10 の操作につながる可能性があり、これは 4 秒の制限時間には遅すぎます。 線形に近い、またはわずかに超線形なソリューションが必要です。`n`テストケースごとに。 

エッジケースには、すべての要素が同一である配列、または次のような小さな値が含まれる配列が含まれます。`1`大きな値と対話します。 たとえば、次の場合`a = [1, 1]`そして`b = [1, 1]`、唯一のペア`(1,2)`満足する`1*1 = 1+1`それは`1 = 2`、 間違い。 小さな数値が自動的に有効なペアを生成すると仮定する不用意な実装は、間違った答えを与える可能性があります。 

もう一つの微妙なエッジは、`a[i] * a[j]`よりも早く成長する`b[i] + b[j]`, そのため、ほとんどのペアは等価性を満たせません。 ブルートフォース ソリューションでは、すべてをチェックする労力が無駄になる可能性があります。 

## アプローチ

 ブルートフォースアプローチは単純です。`i`から`1`に`n-1`、すべてを繰り返します`j > i`かどうかを確認してください`a[i]*a[j] == b[i]+b[j]`。 これは正しいですが、時間計算量は`O(n^2)`。 と`n`まで`2*10^5`、これはおよそ 10^10 の演算を必要とし、これは実行不可能です。 ブルート フォースは定義を直接実装するため機能しますが、次の場合には失敗します。`n`大きいです。 

効率的なアプローチのための重要な洞察は、条件を再配置することです`a[i]*a[j] = b[i]+b[j]`の中へ`a[i]*a[j] - b[j] = b[i]`。 扱う`i`固定して定義する`c[i] = a[i]*a[j] - b[j]`。 それぞれについて`i`、何個探していますか`j > i`満足する`b[i] = a[i]*a[j] - b[j]`。 の出現を数えるというふうに再構成できます。`a[j]*a[i] - b[j]`その一致`b[i]`。 終わりから始まりまで繰り返し、値を頻度マップに保存することで、一致するペアを効率的にカウントできます。`O(n * sqrt(n))`時間。 理由`sqrt(n)`関連するのはそれです`a[i]`によって制限されています`n`、したがって、可能な小さな乗数に対して内部反復を制限できます。 これにより、二次爆発が管理可能なものに縮小されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | お(1) | 遅すぎる |
 | 最適 | O(n * sqrt(n)) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. カウンタを初期化する`ans`ゼロに。 これにより、有効なペアの数が保存されます。 
2. 頻度辞書を作成する`freq`整数値をカウントにマッピングするには`b[j] - a[j]*k`これまで見られた。 
3. 反復する`i`から`n-1`まで`0`。 逆にスキャンすることで、ペアのみをカウントすることが保証されます。`(i,j)`と`i < j`。 
4. それぞれについて`i`、繰り返します`a[i]`の約数`d`まで`sqrt(n)`。 各約数について、潜在的な一致を計算します。`b[j]`使用する値`b[j] = d * a[i] - b[i]`。 この値が存在する場合、`freq`、そのカウントを追加します`ans`。 
5. 一致を数えた後`i`、 アップデート`freq`含める`a[i]*k - b[i]`小さいもの用`k`。 これにより、将来の反復で確実に見つけられるようになります。`i`として`j`。 
6. ループが終了したら、`ans`有効なペアの総数が含まれます。 

なぜ機能するのか: 逆方向に反復することで、次の不変条件が維持されます。`freq`すべてが含まれています`b[j]-a[j]*k`の値`j > i`。 確認するときは`i`、将来の数を効率的にクエリします。`j`すべてをスキャンせずに等式を満たす`j`。 除数ベースの列挙が機能する理由は、`a[i]`によって制限されています`n`、チェックの数を大まかに制限します。`sqrt(n)`インデックスごとに。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import defaultdict
import math

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        ans = 0
        freq = defaultdict(int)
        for i in reversed(range(n)):
            for d in range(1, int(math.isqrt(a[i])) + 1):
                if a[i] % d == 0:
                    # divisor d
                    target = a[i] // d * a[i] - b[i]
                    if target in freq:
                        ans += freq[target]
                    # complementary divisor
                    if d * d != a[i]:
                        target2 = d * a[i] - b[i]
                        if target2 in freq:
                            ans += freq[target2]
            # update freq for current element
            freq[a[i] * 1 - b[i]] += 1
        print(ans)

solve()
```このソリューションは、テスト ケースの数を読み取り、それぞれを個別に処理することから始まります。 初期化する`ans`そして`freq`数えるために。 逆方向に反復することで、有効なもののみをカウントすることが保証されます`i < j`ペア。 除数の列挙により、要素ごとにチェックする候補ペアの数を制限できます。 更新中`freq`数えた後、確実に含まれるのは`j > i`周波数マップで。 使用する`defaultdict(int)`キーエラーを回避し、カウントを簡素化します。
