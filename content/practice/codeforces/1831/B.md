 ## 解決策
 ## 問題の理解

 2 つの配列が与えられています。`a`そして`b`、同じ長さの`n`。 タスクは新しい配列を形成することです`c`長さの`2n`どちらかの配列の最初の要素を両方とも使い果たされるまで連続して取得します。 連続する部分配列の最大長を決定するように求められます。`c`同じ数字で構成されます。 言い換えれば、ある値ができるだけ長く連続して繰り返されるような方法で 2 つの配列をマージしたいと考えます。 

制約が示すのは、`n`は最大 2·10^5 に達する可能性があり、次の合計は`n`すべてのテスト ケースにわたって、 2·10^5 によって制限されます。 これは、複雑度が O(n^2) の解は遅すぎるが、O(n) または O(n log n) は許容されることを意味します。 連続した要素を調べているため、ソリューションでは考えられるすべてのマージ シーケンスを単純に試みるのではなく、両方の配列内の同一値の位置を注意深く追跡する必要があります。 

明らかではないエッジ ケースは、値が両方の配列で異なる位置に複数回出現する場合に発生します。 たとえば、次の場合`a = [1,2,2]`そして`b = [2,2,1]`不注意なアプローチは、すべてがすべてであると想定する可能性があります。`2`は連続してマージできます。 ただし、最大連続セグメントは、`2`私たちが達成できるのは`2`、 ない`3`これは、各配列内の順序を保持する必要があるためです。 

もう 1 つのエッジ ケースは、次のように両方の配列が同一である場合です。`a = b = [5,5,5]`。 このシナリオでは、マージされた配列全体は次のもので構成されます。`5`s、最大セグメント長は`6`。 ソリューションでは、順序を尊重しながら両方の配列からの寄与を正しく合計する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのマージを列挙します。`a`そして`b`各値の最大連続セグメントを追跡します。 マージごとに、どちらかの配列の先頭から要素を取得することをシミュレートします。 Since each array has`n`要素は大まかにあります`2n choose n`可能なシーケンス。 たとえ`n = 20`、これは 10^11 のオーダーであり、まったく実行不可能です。 ブルートフォースは常に最適な連続セグメントを見つけるため機能しますが、自明ではない場合はすぐに失敗します。`n`。 

重要な観察は、任意の値に対して次のことです。`x`、最大連続ブロックは、次の連続要素を取得することによってのみ拡張できます。`x`一方の配列の終わりからもう一方の配列の始まりまで。 これは、各数値を個別に分析し、一方の配列のサフィックスをもう一方の配列のプレフィックスと揃えることによって達成可能な最大の連続数を追跡できることを示唆しています。 

具体的には、それぞれの固有値に対して`v`に登場する`a`または`b`、次の位置を計算できます。`v`が表示され、最大連続回数が決まります。`v`の接尾辞を組み合わせることで収集できます。`a`と接頭辞`b`またはその逆。 これにより、すべてのマージを考慮する問題が値ごとの線形スキャンに軽減され、全体的な複雑さは O(n) になります。

 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースごとに配列を読み取ります。`a`そして`b`。 辞書または配列を初期化して、各値の最大連続ブロックを追跡します。 
2. 配列ごとに、配列内の同一要素の最大連続ブロックを計算します。 これは、連続するすべての要素が単一の配列内ですでに整列しているシナリオを処理します。 
3. 各値について`v`どちらかの配列に現れるポインタは 2 つ維持されます。1 つは配列内で左から右にスキャンします。`a`、別の右から左へ`b`。 の連続発生をカウントします。`v`それぞれの配列の先頭と末尾にあります。 
4. 連続した回数を合計する`v`からの`a`サフィックスと`b`マージされた連続ブロックを考慮するプレフィックス。 表示される最大長を更新します`v`。 
5. 同じプロセスを繰り返します`a`そして`b`他のマージ順序を考慮して交換されます。 
6. すべての値にわたる最大の最大ブロックをテスト ケースの結果として返します。 

このアプローチが機能するのは、要素内の要素の相対的な順序が異なるためです。`a`そして`b`は保持され、連続するプレフィックスとサフィックスに焦点を当てることで、マージによって形成される可能性のあるすべての連続セグメントを考慮します。 不変条件は、マージされた配列内の同じ番号のセグメントは、一方の配列内のその番号のサフィックスを、もう一方の配列内の同じ番号のプレフィックスと結合することによってのみ拡張できるということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_equal_segment(a, b, n):
    ans = 0
    # maximum in single array
    for arr in [a, b]:
        count = 1
        for i in range(1, n):
            if arr[i] == arr[i-1]:
                count += 1
                ans = max(ans, count)
            else:
                count = 1
        ans = max(ans, count)
    
    # maximum by combining suffix of a with prefix of b
    from collections import defaultdict
    positions_a = defaultdict(list)
    positions_b = defaultdict(list)
    
    for i, x in enumerate(a):
        positions_a[x].append(i)
    for i, x in enumerate(b):
        positions_b[x].append(i)
    
    for v in set(a+b):
        # suffix in a
        suf = 0
        for i in reversed(range(n)):
            if a[i] == v:
                suf += 1
            else:
                break
        # prefix in b
        pre = 0
        for i in range(n):
            if b[i] == v:
                pre += 1
            else:
                break
        ans = max(ans, suf + pre)
        
        # swap roles
        suf = 0
        for i in reversed(range(n)):
            if b[i] == v:
                suf += 1
            else:
                break
        pre = 0
        for i in range(n):
            if a[i] == v:
                pre += 1
            else:
                break
        ans = max(ans, suf + pre)
    
    return ans

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    print(max_equal_segment(a, b, n))
```このソリューションでは、まず各配列をスキャンして、その配列内全体で最大の連続ブロックを特定します。 次に、それぞれの個別の値を分析して、配列全体のサフィックスとプレフィックスをマージすることで作成できるブロックの大きさを確認します。 辞書を使用して位置を収集することはオプションですが、複数のブロックを追跡するようにソリューションを拡張すると、ロジックがより明確になり、一般化されます。
