 ## 解決策
 ## 問題の理解

 長さのかっこのシーケンスを数えるように求められます$n$これは、グローバルに規則的であると同時に、特定の指定されたサブインターバルではローカルに規則的でもあります。 入力により長さがわかります$n$とリスト$k$間隔$[l_i, r_i]$。 グローバルに規則的な括弧シーケンスとは、すべての開き括弧に対応する閉じ括弧があり、対応する開き括弧の前に閉じ括弧が存在しないものです。 指定された間隔のそれぞれが単独で有効な規則的なブラケット シーケンスを形成する場合、シーケンスは超規則的です。 私たちの出力は、そのような超正則シーケンスの数を法としたものです。$998{,}244{,}353$。 

制約は厳しいです。 合計$n$すべてのテストケースで到達できる$3 \cdot 10^5$、 そして$k$にも到達できます$3 \cdot 10^5$。 すべてのシーケンスを生成し、規則性をチェックし、間隔に基づいてフィルタリングするという単純なアプローチは、シーケンスの数が指数関数的に増加するため不可能です。$n$。 したがって、理想的には、$n + k$。 

エッジケースが発生するのは次の場合です$n$規則的なシーケンスが存在しないため、または間隔が重複またはネストされている場合、これらの制約により有効なシーケンスの数が減り、カウントがゼロになる可能性もあるため、奇数になります。 空の間隔と長さ 1 の間隔も、シーケンス内の特定の位置を自動的に制限するため、慎重に処理する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、すべてのものが生成されます。$2^n$シーケンスでは、それぞれがグローバルに規則的であるかどうかを確認し、次に各間隔でローカルな規則性があるかどうかを確認します。 これは原理的には正しいですが、次のような場合にはまったく実行不可能です。$n > 20$指数関数的な成長のため。 

重要な観察は、通常の括弧シーケンスは、開始括弧と終了括弧の数とその位置によって完全に特徴付けられるということです。 カタロニア語の数値は、指定された長さのすべての規則的なシーケンスを列挙します。 超規則的制約を使用して間隔を追加すると、特定の位置が強制的に一致し、シーケンスの一部が効果的に固定されます。 間隔が重なったりネストしたりする場合、内部のシーケンスはすべての重複する制約を同時に満たさなければなりません。 これは組み合わせの縮小につながります。つまり、これらの間隔の終点がどのように一致してより小さい有効なシーケンスを形成できるかを考慮するだけで済みます。 

最適なアプローチは、ネストされた間隔構造を独立したセグメントに再帰的に分割できるという事実を利用します。 カタロニア数を使用して各独立セグメントを埋める方法の数を数え、乗算することで、超正則シーケンスの総数を効率的に計算できます。 階乗および逆階乗モジュロの事前計算$998{,}244{,}353$これにより、各セグメントのカタロニア語数値を定数時間で計算できるようになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * k) | O(n) | 遅すぎる |
 | 最適 | O((n + k) log(n)) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$そして$k$、間隔を保存します$[l_i, r_i]$。 間隔を開始点で並べ替えます。 ネストされた間隔または重複する間隔を効率的に処理するには、並べ替えが必要です。 
2. スタックを初期化して、入れ子構造をシミュレートします。 間隔を繰り返して、それぞれの間隔でスタックの先頭より後に開始する場合は、現在の間隔が収まるまでスタックをポップします。 これにより、ネストされた間隔を表すツリーが構築されます。 
3. 区間ツリー内の各ノードについて、有効なシーケンスの数を再帰的に計算します。 ノードに子間隔がある場合、シーケンスをこれらの子によって定義されたセグメントに分割します。 長さの各セグメントに対して$m$、カタロニア数を計算します$C_{m/2}$もし$m$は均等です。 もし$m$が奇数の場合は、奇数の長さの正規シーケンスが存在しないため、カウントをゼロに設定します。 
4. すべてのセグメントのカタルーニャ語数値を、ネストされた子に対して再帰的に乗算します。 これにより、現在の間隔のカウントが得られます。 
5. テスト ケースの答えは、シーケンス全体をカバーする間隔のカウントです。 シーケンス全体をカバーする間隔がない場合は、シーケンス全体を 1 つの間隔とみなします。 

機能する理由: カタロニア語数値は、規則性を満たすすべてのシーケンスを列挙します。 ネストされた間隔構造によって決定される重複しないセグメントにシーケンスを分割することにより、各セグメントが独立してカウントされることが保証されます。 独立性があるため、カウントの乗算は有効です。 再帰ではネストが考慮されるため、すべての間隔制約が満たされます。

MAX = 3 * 10**5 + 10

# precompute factorials and inverse factorials
fact = [1] * MAX
invfact = [1] * MAX
for i in range(1, MAX):
    fact[i] = fact[i - 1] * i % MOD
invfact[MAX - 1] = pow(fact[MAX - 1], MOD - 2, MOD)
for i in range(MAX - 2, -1, -1):
    invfact[i] = invfact[i + 1] * (i + 1) % MOD

def catalan(n):
    if n == 0:
        return 1
    return fact[2 * n] * invfact[n] % MOD * invfact[n + 1] % MOD

def solve_case(n, k, intervals):
    intervals.sort()
    stack = []
    result = 1
    last = 0

    for l, r in intervals:
        # handle gaps
        if l - 1 > last:
            gap = l - 1 - last
            if gap % 2 != 0:
                return 0
            result = result * catalan(gap // 2) % MOD
        last = max(last, r)
    # handle tail
    if last < n:
        gap = n - last
        if gap % 2 != 0:
            return 0
        result = result * catalan(gap // 2) % MOD
    return result

        intervals = [tuple(map(int, input().split())) for _ in range(k)]
