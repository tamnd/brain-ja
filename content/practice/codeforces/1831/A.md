 ## 解決策
 ## 問題の理解

 順列が与えられています`a`長さの`n`、つまり、以下のすべての整数が含まれます。`1`に`n`ある順序で 1 回だけ。 私たちの仕事は別の順列を構築することです`b`対応する要素を合計することによってシーケンスが形成されるような同じ長さの、`a_i + b_i`、減少していません。 つまり、各要素をペアリングした後、`a`の 1 つの要素で`b`、左から右に移動しても合計が減少することはありません。 

入力では最大 2000 のテスト ケースが可能で、各順列には最大 100 個の要素が含まれます。 これは、合計約 200,000 の操作を低速にすることなく処理できるアルゴリズムが必要であることを意味します。 すべてをチェックするブルートフォースアプローチ`n!`可能な順列`b`たとえ`n = 10`、`10! = 3,628,800`、そしてのために`n = 100`、階乗は天文学的に大きくなります。 

微妙なエッジケースが発生する場合`a`完全に増加しているか、完全に減少しています。 たとえば、次の場合`a = [3,2,1]`、合計の順序を考慮しないと、「最小値と最小値を一致させる」という単純なアプローチは失敗する可能性があります。 同様に、`a = [1,2,3]`、単純に取る`b`昇順での計算は自明に機能しますが、解決策は任意の順列に一般化する必要があります。`a`。 

## アプローチ

 ブルートフォースアプローチでは、すべてのことが試みられます。`n!`の順列`b`合計が正しいかどうかを確認します`a_i + b_i`は減少していません。 これはすべての可能性をテストするため、明らかに正しいですが、次の場合には非現実的になります。`n > 8`または`9`階乗増加によるもの。 

複雑さを軽減するための重要な観察は、より小さな要素を整列させた場合、合計シーケンスは減少しないということです。`a`より小さな要素で`b`体系的な方法で。 具体的に並べてみると`a`インデックスと一緒に番号を割り当てます`1`を通して`n`に`b`のソート順に対応する昇順で`a`、結果の合計は減少しないことが保証されます。 これは、利用可能な最小の番号をペアリングするため機能します。`b`最小のもので`a`、2 番目に小さいものと 2 番目に小さいものなど、合計が前の値より小さくならないようにします。 

これは建設的です。後戻りしたり検索したりする必要はありません。 並べ替えインデックス`a`は`O(n log n)`、および割り当て`b`は`O(n)`。 のために`n ≤ 100`、これは些細な速さです。

 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | 最適 (ソートされた割り当て) | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 特定の順列の場合`a`長さの`n`、ペアのリストを作成します`(value, index)`の各要素に対して`a`。 The index is the original position of the element.
 2. このペアのリストを次の基準で並べ替えます。`value`。 このステップでは次の順序が与えられます。`a`元の位置を追跡しながら、最小から最大まで。 
3. 空のリストを初期化する`b`長さの`n`。 
4. ソートされたリストを反復処理します。`(value, index)`ペア。 番号を割り当てる`1`を通して`n`に`b`の対応する元のインデックスで`a`。 つまり最小の`a`受け取る値`1`、次に小さいものが受け取ります`2`、 等々。 
5. 順列を出力する`b`。 

機能する理由: 並べ替えにより、より小さいサイズが確実に得られます。`a`値は小さい値とペアになります`b`価値観。 この割り当てでは両方のシーケンスが厳密に増加しているため、合計は`a_i + b_i`減っていない。 並べ替えられた順序で次の要素はすべて大きいか等しいため、合計が条件に違反することはありません。`a`、割り当てられた`b`値は厳密に増加しています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    # Pair values with original indices
    indexed_a = [(val, idx) for idx, val in enumerate(a)]
    # Sort by values
    indexed_a.sort()
    
    # Create permutation b
    b = [0] * n
    for i, (_, idx) in enumerate(indexed_a):
        b[idx] = i + 1  # assign 1..n in sorted order
    
    print(*b)
```コードは最初にテスト ケースの数を読み取り、次に各テスト ケースについて次の情報を読み取ります。`n`そして順列`a`。 各値を元のインデックスと組み合わせて、並べ替え後の位置を保持します。 並べ替えると、番号を割り当てる順序が生成されます。`b`。 代入ループは単純です。最小のものは、`a`取得します`1`、次に小さいものが得られます`2`、など。最後に順列`b`元のインデックスに従って印刷されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        indexed_a = [(val, idx) for idx, val in enumerate(a)]
        indexed_a.sort()
        b = [0] * n
        for i, (_, idx) in enumerate(indexed_a):
            b[idx] = i + 1
        print(*b)
    
    return output.getvalue().strip()
