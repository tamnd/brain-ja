 ## 解決策
 ## 問題の理解

 2 台のロボットがグリッド上の 2 つの固定格子点に立っています。 彼らはボールを前後に投げ、ボールは彼らの位置を結ぶ直線部分に沿って移動します。 3点目のイブがボールをインターセプトしようとしている。 イブは、アリスからボブへの直線セグメントが自分の位置を通過するときに正確に成功します。 

イブの候補位置ごとに、その点が 2 台のロボット間の線分上にあるかどうかを判断する必要があります。 これは純粋な幾何学的なメンバーシップ テストであり、点が整数グリッド内の指定されたセグメント上に正確に存在するかどうかをテストします。 

入力は 2 つの固定点と最大 100 個のクエリ点で構成されます。 各クエリは独立しており、その点がセグメント上にあるかどうかを尋ねます。 座標はおよそマイナス 10,000 から 10,000 までの範囲の整数であり、クエリごとに定数時間の演算を行うだけで十分なほど十分に小さいです。 

重要な制約の意味は、前処理を行わずにクエリごとに直接幾何学的チェックを実行できることです。 クエリごとに O(E) のアプローチでも遅すぎますが、ここでは E が最大 100 であるため、クエリごとに O(1) のテストで十分です。 

よくある間違いは、共線性のみをチェックすることです。 それだけでは十分ではありません。 たとえば、アリスが (0, 0) にいて、ボブが (2, 2) にある場合、点 (3, 3) はそれらと同一直線上にありますが、明らかにボブの向こう側にあるため、セグメントをインターセプトするとみなすべきではありません。 もう 1 つの微妙なエッジ ケースは、イブがアリスまたはボブと一致する場合です。 この場合、セグメントはそのエンドポイントを通過するため、答えは依然として肯定的であるはずです。 

## アプローチ

 強引なアイデアは、線分を明示的にモデル化し、点がその上にあるかどうかを確認することです。 単純な方法の 1 つは、セグメントをパラメータ化し、その点がアリスにアリスからボブへのベクトルを t 掛けたものに等しいようなパラメータ t が [0, 1] に存在するかどうかをテストすることです。 これは、2 つの方程式を解き、一貫性をチェックすることになります。 これは正しいですが、直接実装すると浮動小数点精度の問題が発生しますが、座標の整数の性質を考慮すると不要です。 

より確実な観察は、2 つの条件が成立する場合にのみ、点がセグメント上にあるということです。 まず、3 つの点が同一線上にある必要があります。これは、ベクトル AB と AE の外積を使用してテストできます。 次に、点はアリスとボブによって形成された境界ボックス内になければなりません。これは、その x 座標が 2 つの x 座標の間にあり、その y 座標が 2 つの y 座標の間にあることを意味します。 

重要な単純化は、共線性により点が無限線上にあることを保証する一方で、バウンディング ボックス制約により点が有限セグメントに制限されることです。 これらの条件を組み合わせると、整数ジオメトリのセグメントのメンバーシップが完全に特徴付けられます。

 | --- | --- | --- | --- |
 | float を使用したパラメトリック ライン解決 | お(え) | お(1) | 精度によるリスク |
 | 外積 + 境界ボックスのチェック | お(え) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 アリスをポイント A、ボブをポイント B、各クエリをポイント C として扱います。 

1. 座標を減算して (dx, dy) を形成することにより、A から B へのベクトルを計算します。 これにより、セグメントの方向が定義されます。 
2. 各クエリ ポイント C について、A から C までのベクトルを計算し、(cx, cy) を形成します。 
3. 外積 dx * cy − dy * cx を評価して共線性を確認します。 この値がゼロでない場合、C は A と B を通る線上にありません。 
4. 同一直線上にある場合は、min(xa, xb) ≤ xc ≤ max(xa, xb) を検証し、y についても同様に検証することにより、C が A と B の軸に揃えられた境界ボックス内にあるかどうかを確認します。 
5. 両方の条件が当てはまる場合は Yes を出力し、そうでない場合は No を出力します。 

外積テストは傾きの比較を置き換え、除算を完全に回避するため、精度の問題が排除され、垂直線が自然に処理されます。 

### なぜ効果があるのか

外積条件により、ベクトル AB と AC が線形依存していることが保証されます。つまり、C が A と B を通る無限線上にあることを意味します。バウンディング ボックス制限により、同じ線上にあるがセグメントの端点の外側にあるすべての点が削除されます。 これら 2 つの条件を組み合わせると、点が平面内の閉じたセグメント上に存在するために必要かつ十分になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

xa, ya = map(int, input().split())
xb, yb = map(int, input().split())
e = int(input())

dx = xb - xa
dy = yb - ya

def on_segment(xc, yc):
    cx = xc - xa
    cy = yc - ya

    if dx * cy != dy * cx:
        return False

    if min(xa, xb) <= xc <= max(xa, xb) and min(ya, yb) <= yc <= max(ya, yb):
        return True

    return False

out = []
for _ in range(e):
    x, y = map(int, input().split())
    out.append("Yes" if on_segment(x, y) else "No")

print("\n".join(out))
```コードは、2 台のロボット間の方向ベクトルを固定することから始まります。 各クエリは、アリスからの相対ベクトルを計算することによって独立して処理されます。 外積チェックは除算なしで共線性をエンコードするため、中心的な決定点となります。 

共線性だけでは両方向に無限に伸びる点を受け入れるため、境界ボックスのチェックが必要です。 最小値と最大値の比較により、エンドポイント間にあるポイントのみを受け入れることが保証されます。 

実装の微妙な点は、すべての算術演算が整数のままであるため、浮動小数点エラーのリスクがないことです。 もう 1 つの重要な詳細は、平等性が包括的であるため、エンドポイントが自動的に受け入れられることです。 

## 実用的な例

 アリスが (0, 0)、ボブが (2, 2)、そして 2 つのクエリが (1, 1) と (-1, -1) であると考えてください。 

最初のクエリの場合:

 | ステップ | CX、CY | 外積 dx_cy − dy_cx | 共線性 | 境界ボックス内 | 結果 |
 | --- | --- | --- | --- | --- | --- |
 | (1,1) | (1,1) | 2_1 − 2_1 = 0 | はい | はい | はい |

 これにより、点がセグメントのちょうど中間にあることが確認されます。 

2 番目のクエリの場合:

 | ステップ | CX、CY | 外積 dx_cy − dy_cx | 共線性 | 境界ボックス内 | 結果 |
 | --- | --- | --- | --- | --- | --- |
 | (-1,-1) | (-1,-1) | 2*(-1) − 2*(-1) = 0 | はい | いいえ | いいえ |

 この点は同じ無限線上にありますが、セグメントの端点の外側にあるため、境界ボックス条件によって拒否されます。 

これら 2 つのケースは、両方のチェックの必要性を示しています。共線性だけでは不十分であり、点が線上にあることが保証されなければ境界ボックスだけでは意味がありません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from sys import stdin
    data = sys.stdin.read().strip().split()
    it = iter(data)

    xa, ya = int(next(it)), int(next(it))
    xb, yb = int(next(it)), int(next(it))
    e = int(next(it))

    dx = xb - xa
    dy = yb - ya

    def ok(xc, yc):
        cx = xc - xa
        cy = yc - ya
        if dx * cy != dy * cx:
            return False
        return min(xa, xb) <= xc <= max(xa, xb) and min(ya, yb) <= yc <= max(ya, yb)

    res = []
    for _ in range(e):
        x, y = int(next(it)), int(next(it))
        res.append("Yes" if ok(x, y) else "No")

    return "\n".join(res) + ("\n" if res else "")

 ## 特殊なケース

 イブがアリスまたはボブと一致する場合、ベクトルは同一またはゼロであるため、外積は自動的にゼロになります。 座標が 1 つの端点に等しいため、境界ボックス条件も合格します。 これにより、特別な処理を行わずにエンドポイントが確実に受け入れられます。 

垂直セグメントまたは水平セグメントの場合、dx または dy のいずれかが 0 になります。 外積公式は、除算を必要とせずに正しく減少するため、引き続き機能します。 たとえば、dx が 0 の場合、条件は dy * cx = 0 となり、cx は強制的に 0 になります。つまり、x はアリスの x 座標と一致する必要があります。 

ボブを越えて同じ方向に伸びるなど、同一線上にあるがセグメントの外側にある点の場合、外積は合格しますが、境界ボックスはそれらを拒否します。 この分離により、誤検知が防止され、セグメントが無限の線ではなく有限のオブジェクトとして扱われることが保証されます。
