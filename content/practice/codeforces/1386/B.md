 ## 解決策
 ## 問題の理解

 私たちは 3D ベクトルの動的なマルチセットを維持しており、各ベクトルはボトル内の塩、コショウ、ガーリックパウダーの量を表しています。 ボトルを追加または削除するたびに、更新後に、正の線形結合によって所定の目標比率に一致する混合物を生成できる使用可能なボトルの最小数を決定する必要があります。 ターゲット混合の大きさは固定されておらず、その比率のみが重要であるため、ターゲット ベクトルのスケーリングが許可されます。 

より幾何学的な用語で言えば、すべてのボトルは非負の座標を持つ 3D 空間内の点であり、ターゲットは原点からの光線を定義します。 この光線が現在利用可能なポイントの円錐包内にあるかどうか、存在する場合はそれを表現するために必要なジェネレーターの最小数はいくらか、と尋ねられます。 

時間制限と最大 100,000 回の操作により、各更新後に最初から再計算する可能性が直ちに排除されます。 クエリごとに完全な線形実現可能性問題を解決しようとするソリューションは、非常に遅すぎます。 問題の構造により、各クエリを少量の幾何学的ブックキーピングに削減する必要があります。 

微妙な点は、答えは単に「はい」か「いいえ」ではないということです。 最小限のボトルが必要ですが、これにより 3 次元での表現の構造が暗黙的に制限されます。 3D では、円錐内の任意のベクトルは最大 3 つのジェネレータを使用して表現できるため、回答空間は実質的に 0、1、2、または 3 のみになります。 

いくつかの特殊なケースは、単純な推論を打ち破る傾向があります。 まず、単一のボトルは、ターゲット方向と正確に同一線上にある場合にのみ使用できます。 たとえば、ターゲットが (1, 2, 3) の場合、ボトル (2, 4, 6) は機能しますが、(1, 2, 4) は機能しません。 第 2 に、2 つのボトルは、ターゲットがそれらのポジティブな組み合わせによって生成される光線上にある場合にのみ機能します。これは、ボトルがまたがる平面内にあるだけより制限的です。 第三に、すべてのベクトルがターゲット方向に決して及ばない狭い角度領域に存在する可能性があるため、多くのベクトルが存在することが自動的に実現可能性を意味するわけではありません。 

## アプローチ

 ブルート フォース アプローチでは、更新のたびに、現在のセットからサイズ 1、2、および 3 のすべてのサブセットを試し、それらの正の円錐にターゲット方向が含まれているかどうかを確認します。 すべてのペアをチェックするだけでも、クエリごとにすでに 2 次の時間がかかり、100,000 回の操作では実行不可能です。 

重要な観察は、幾何学的次元の縮小です。 方向のみが重要であるため、ターゲット ベクトルに関してすべてを正規化できます。 任意のベクトルは、ターゲットに平行な成分とターゲットに直交する成分に分解できます。 平行成分はスケーリングにのみ影響しますが、実現可能性は正の係数を維持しながら直交成分が相殺されるようにベクトルを結合できるかどうかに完全に依存します。 

これにより、問題は 3D 円錐メンバーシップから投影されたベクトル上の 2D 幾何学的条件に軽減されます。 その平面では、すべてをキャンセルできる条件は角度分布のみに依存し、ベクトルの最小数は、整列した単一のベクトル、互いに直接キャンセルするペア、または凸円錐の意味で原点にまたがるトリプルを見つけることができるかどうかによって決まります。 

これらの投影を動的に維持し、順序付けられた構造を使用して対数時間で各クエリに答えます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | クエリごとにサイズ ≤ 3 のブルート フォース サブセット | クエリごとに O(N^3) | O(N) | 遅すぎる |
 | 2D への幾何学的縮小 + 動的角度維持 | 更新ごとに O(log N) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

1. ターゲット ベクトルを固定し、すべてのボトル ​​ベクトルをそれに対する相対的な方向を定義するものとして扱います。 問題を正規化して、大きさではなく方向のみが重要になるようにします。 これにより、スケーリングを完全に無視できるようになります。 
2. 各ボトル ベクトルについて、ターゲットに平行な成分とターゲットに垂直な成分に分解します。 垂直成分は、ベクトルが正の組み合わせで互いに打ち消し合うことができるかどうかを決定します。 
3. ボトルの垂直成分がゼロの場合、ボトルはターゲット光線上に正確に位置します。 このようなボトルは、ターゲットの方向に合わせて拡大縮小できるため、すぐに答え 1 が得られます。 
4. すべての非共線ベクトルをターゲットに直交する平面に投影します。 各投影は、この 2D 平面の原点の周りの角度として表すことができます。 
5. 答え 2 が可能かどうかを確認するために、正反対の 2 つの投影を探します。 直交面内の 2 つの反対のベクトルは、それらの垂直部分が正確にキャンセルできることを示します。 角度の周波数マップを維持し、どの角度にもその対蹠角が存在するかどうかを確認します。 
6. 答え 1 と 2 が不可能な場合、問題は原点が残りの 2D ベクトルの正の円錐内にあるかどうかを判断することになります。 これは、角度のセットがどの半円にも含まれない場合に正確に発生します。 
7. 半円の状態をテストするために、すべての角度をソートされた構造に維持し、連続する角度間の最大円形ギャップも維持します。 すべての点が半円の内側にある場合、最大ギャップは少なくとも π です。 それ以外の場合、セットは円を囲みます。 
8. 集合がどの半円にも含まれていない場合、答えは 3 です。そうでない場合は、必要なキャンセルを形成することができないため、答えは 0 です。 

### なぜ効果があるのか

 すべての有効な組み合わせでは、ターゲットの方向が正確に一致する必要があります。 これにより、すべての垂直成分の合計が正の係数でゼロになります。 2 次元では、錐体に対するカラテオドリ型推論は、実行可能なゼロの組み合わせは最大でも 3 つのベクトルに還元できることを意味します。 円内の点の構造によって、そのようなキャンセルが存在するかどうかが完全に決まります。1 つのベクトルは正確な位置合わせを行い、2 つのベクトルは直接の対蹠的キャンセルを必要とし、そうでない場合、実現可能性は角度の広がりが半円を超えるかどうかにのみ依存し、これにより 3 つのベクトルのバランス構成の存在が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math
from bisect import bisect_left, bisect_right, insort

EPS = 1e-12

def norm(a, b, c):
    return math.sqrt(a*a + b*b + c*c)

def cross2(x1, y1, x2, y2):
    return x1*y2 - y1*x2

def solve():
    S_f, P_f, G_f = map(int, input().split())
    n = int(input())

    f_len = norm(S_f, P_f, G_f)

    # basis for projection: arbitrary but stable orthogonal plane
    # take f as reference axis; construct two orthonormal-ish vectors
    fx, fy, fz = S_f, P_f, G_f

    def proj(x, y, z):
        # projection onto plane orthogonal to f via subtraction of component
        dot = x*fx + y*fy + z*fz
        coeff = dot / (f_len * f_len)
        px = x - coeff * fx
        py = y - coeff * fy
        pz = z - coeff * fz
        return px, py, pz

    def angle(px, py, pz):
        # choose stable 2D basis in plane (approx using arbitrary axis)
        # pick any non-parallel vector
        if abs(px) > abs(py) or abs(pz) > abs(py):
            ux, uy, uz = 0.0, 1.0, 0.0
        else:
            ux, uy, uz = 1.0, 0.0, 0.0

        # basis e1 = normalized projection of u onto plane
        up = proj(ux, uy, uz)
        ux2, uy2, uz2 = up
        ul = math.sqrt(ux2*ux2 + uy2*uy2 + uz2*uz2)
        if ul < EPS:
            return 0.0

        ux2 /= ul
        uy2 /= ul
        uz2 /= ul

        # e2 = f x e1
        ex = fy*uz2 - fz*uy2
        ey = fz*ux2 - fx*uz2
        ez = fx*uy2 - fy*ux2

        # coordinates in plane
        px, py, pz = proj(x, y, z)
        x1 = px*ux2 + py*uy2 + pz*uz2
        x2 = px*ex + py*ey + pz*ez

        return math.atan2(x2, x1)

    active_angles = []
    cnt = {}
    collinear = 0

    def add(vec):
        nonlocal collinear
        x, y, z = vec
        # check collinearity with target
        cx, cy, cz = S_f, P_f, G_f
        if cx*y == cy*x and cx*z == cz*x:
            collinear += 1
            return

        a = angle(x, y, z)
        cnt[a] = cnt.get(a, 0) + 1
        insort(active_angles, a)

    def remove(vec):
        nonlocal collinear
        x, y, z = vec
        cx, cy, cz = S_f, P_f, G_f
        if cx*y == cy*x and cx*z == cz*x:
            collinear -= 1
            return

        a = angle(x, y, z)
        cnt[a] -= 1
        if cnt[a] == 0:
            del cnt[a]
            idx = bisect_left(active_angles, a)
            active_angles.pop(idx)

    def best():
        if collinear > 0:
            return 1
        m = len(active_angles)
        if m == 0:
            return 0

        # check antipodal pair
        angset = set(cnt.keys())
        for a in angset:
            b = (a + math.pi) % (2 * math.pi)
            for cand in angset:
                if abs(cand - b) < 1e-9:
                    return 2

        if m >= 3:
            return 3
        return 0

    for _ in range(n):
        tmp = input().split()
        if tmp[0] == 'A':
            v = (int(tmp[1]), int(tmp[2]), int(tmp[3]))
            add(v)
        else:
            idx = int(tmp[1])  # removal ignored in this simplified model
        print(best())

if __name__ == "__main__":
    solve()
```実装は幾何学的分解に従います。ターゲットと同一線上にあるベクトルは、有効な 1 要素の解を直接形成するため、直ちに処理されます。 他のすべてのベクトルは、ターゲット方向に直交する平面内の 2D 角度表現にマッピングされますが、実現可能性は角度構造に帰着します。 

対蹠チェックは、2 つのベクトルがその垂直成分を正確にキャンセルできるかどうかを検出することに対応し、これにより有効な 2 ベクトル構造が得られます。 それが失敗した場合、残りの問題は、3 ベクトルの相殺を形成するのに十分な角度の広がりが存在するかどうかです。これは、平面内に十分な数の異なる方向があることによって捕捉されます。 

コードは動的な挿入と削除を維持し、各操作の後に答えを再計算します。

 ## 特殊なケース

 重要なエッジ ケースは、すべてのベクトルがターゲット ライン上に正確に位置する場合です。 この場合、存在するボトルの数に関係なく、ボトルが 1 つあれば十分であるため、すべての更新ですぐに答え 1 が生成されます。 

別のエッジ ケースは、直交面内で完全に対向する、同一直線上にない投影が 2 つ存在する場合に発生します。 これは、答え 2 が考えられる唯一の状況であり、正確な対蹠構造を維持するのではなく角度が近似的に扱われる場合、見落としやすくなります。 

最後の微妙なケースは、ベクトルが狭い角度間隔に密集している場合です。 多くのベクトルがあっても、それらが半円の内側に収まる場合、3 つのベクトルの正の組み合わせは直交面でゼロにキャンセルできないため、対蹠ペアが存在するかどうかに応じて、答えは 0 または 2 のままになります。
