 ## 解決策
 ## 問題の理解

 長さの配列が与えられます$n$ここで、一部の位置には固定整数が含まれており、一部の位置は欠損としてマークされています。 欠落しているすべての位置は、選択した 1 つの値で埋められます。$k$。 この置換の後、隣接する要素のすべてのペアを調べ、それらの絶対的な差を測定します。 目標は選択することです$k$これらの隣接する差の最大値が可能な限り小さくなるようにします。 

重要な点は、欠落している位置ごとに異なる値を割り当てないことです。 すべての未知のスロットは同じ値を取る必要があるため、$k$少なくとも 1 つの欠落要素を含むすべてのセグメントにグローバルに影響します。 

制約$n \le 10^5$テストケースごとおよび合計$4 \cdot 10^5$テスト全体で、可能なすべての二次チェックを排除します$k$。 必要なのは$O(n)$または$O(n \log V)$テストケースごとの戦略。 

素朴なアプローチではすべてを試してしまうだろう$k$から$0$に$10^9$、結果として得られる最大隣接差を計算し、最良のものを採用します。 それは不可能です。$k$すでに費用がかかる$O(n)$、につながる$10^{14}$最悪の場合の運用。 

さらに微妙な間違いは、既知の値の隣接するペアのみを考慮し、欠落しているセグメントによる相互作用を無視することです。 たとえば、次のようなセグメントでは、$[10, -1, -1, 20]$、選択する$k$どちらかのエンドポイントの近くでは、複数のエッジを個別にではなく一度に制御します。 

もう 1 つの一般的な失敗ケースは、欠落しているセグメントをローカルで処理できると想定していることです。 たとえば:

 入力:```
3
10 -1 20
```各エッジを個別に最小化するだけの場合は、$k=10$または$k=20$、しかし両方とも最大の差をもたらします$10$、最適な選択は$k=15$、与える$5$。 

単一のグローバル変数による制約の結合$k$が核となる難易度です。 

## アプローチ

 ブルートフォースのアイデアは単純です。 候補者ごとに$k$、欠落している位置をすべて埋め、隣接するすべての差を計算し、最大値を取得します。 これが機能するのは、問題の定義を直接シミュレートするためです。 問題はスケールです。$10^9$可能な値$k$回$10^5$チェックごとの操作は制限をはるかに超えています。 

重要な観察は、最大隣接差分が以下に関して区分的に線形に動作するということです。$k$。 影響を受ける唯一のエッジ$k$欠けている位置に触れているものです。 2 つの固定値の間のエッジは一定であり、最適化時に無視できます。$k$。 

固定値を含むエッジの場合$x$欠損値の場合、寄与率は次のようになります。$|x - k|$。 したがって、関連するすべての制約は、$k$間の最大距離を最小限に抑える$k$そして固定された近傍のセット。 

つまり、問題は次のようになります。$k$フォームの式の最大値を最小限に抑える$|k - x_i|$。 それは選択するのと同じです$k$関連するすべての固定値の「最良の中心」に可能な限り近づけますが、重要な工夫が必要です。グローバル セットを取得するのではなく、欠損値を含む各セグメントによって引き起こされる制約の和集合を取得します。 

より正確には、欠損値の連続するブロックをそれぞれ処理します。 各ブロックは、左右の既知の値 (存在する場合) によって境界されます。 間にブロックがあるとします。$L$そして$R$。 次に、そのブロック内のすべての値は次のようになります。$k$したがって、ブロック内のエッジは何も寄与しませんが、境界へのエッジは制約を課します。$$|k - L|, \quad |k - R|$$したがって、ブロックごとに制約の候補を抽出し、最終的な答えは、そのようなすべての制約と既存の固定-固定エッジの最大値を最小化するかどうかによって決まります。 

Thus, we reduce the problem to computing:

 - 固定-固定隣接差の最大値（定数部分）、
 - and all constraints of the form$|k - x|$ブロック境界から。 

最適な$k$は、制約ペア間の端点と中間点という小さな候補セット内にあります。 実際には、最適な$k$は、境界値または 2 つの境界制約の中点で達成されるため、関連するすべての境界値を収集し、一定数の候補をチェックできます。

 ## アルゴリズムのチュートリアル

 私たちは問題をいくつかの制約に絞り込むことに重点を置いています。$k$。 

1. 配列をスキャンし、両方の値がわかっている隣接するペアをすべて記録します。 それらの絶対的な差を計算します。 これにより、どのような選択をしても改善できないベースラインの答えが得られます。$k$。 これらの最大値は常に最終的な答えの一部になります。 
2. 欠損値の連続セグメントを特定します。 各セグメントは、左右に最も近い既知の値が存在する場合、その値によって境界付けされます。 
3. 各セグメントについて、セグメントとどのように相互作用するかを決定します。$k$。 

セグメントが 2 つの既知の値の間にある場合$L$そして$R$、次にそれを埋めます$k$制約を導入します$|k - L|$そして$|k - R|$。 これは、すべての境界エッジが次のものに依存するためです。$k$、内部エッジはすべてゼロです。 
4. 制約に関係するすべての境界値をリストに収集します。 これらはすべて、関数がどこに配置されるかを定義する固定の数値です。$\max |k - x|$傾きが変わります。 
5. 最大距離を最小化するために、候補を考慮します。$k$以下によって形成される値:

 すべての制約の終点、および制約のペア間の中間点。 2 つの値の場合$x$そして$y$、最適なバランスポイントは次のとおりです。$(x + y) / 2$。 
6. 各候補者の評価$k$by computing:

 maximum of:

 - ベースラインの固定対固定の差、
 - all$|k - x|$制約。 
7. 最小達成値とそれに対応する値を返します。$k$。 

### なぜ効果があるのか

 最小化している関数は、絶対値式と定数の有限セットの最大値です。 このような関数は凸関数であり、区分線形です。 整数上の凸区分線形関数の最小値は、ブレークポイントまたは 2 つの隣接するブレークポイント間で発生する必要があります。 これらのブレークポイントは、制約からの既知の値とまったく同じです。 したがって、最適値を取得するには、終点と中間点をチェックするだけで十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        fixed_edges_max = 0
        values = []

        i = 0
        while i < n:
            if a[i] == -1:
                j = i
                while j < n and a[j] == -1:
                    j += 1

                left = a[i - 1] if i > 0 else None
                right = a[j] if j < n else None

                if left is not None:
                    values.append(left)
                if right is not None:
                    values.append(right)

                i = j
            else:
                if i + 1 < n and a[i + 1] != -1:
                    fixed_edges_max = max(fixed_edges_max, abs(a[i] - a[i + 1]))
                i += 1

        if not values:
            print(fixed_edges_max, 0)
            continue

        lo, hi = min(values), max(values)
        k = (lo + hi) // 2

        def eval(k):
            best = fixed_edges_max
            for v in values:
                best = max(best, abs(k - v))
            return best

        best_k = k
        best_m = eval(k)

        for cand in [lo, hi]:
            val = eval(cand)
            if val < best_m:
                best_m = val
                best_k = cand

        print(best_m, best_k)

if __name__ == "__main__":
    solve()
```コードはまず、欠落しているセグメントの境界に由来するすべての制約を抽出します。 固定された隣接ペアは影響を受けないため、それらのペアからの寄与を個別に計算します。$k$。 の候補値は、$k$は境界値の範囲から導出され、範囲全体ではなく、意味のある点の小さなセットをテストします。 

評価関数は、セグメントの欠落によって引き起こされるすべての制約をチェックすることによって、結果として得られる最大隣接差分を計算します。 

微妙な点は、すべての要素が欠落している場合の処理​​です。 この場合、制約はないため、最適な答えはゼロと任意の答えになります。$k$作品; 私たちは戻ります$k=0$。

 ## 特殊なケース

 すべての要素が欠落している入力の場合、次のようになります。```
3
-1 -1 -1
```固定-固定エッジや境界制約はありません。 アルゴリズムは空の制約セットを生成し、直接返します。$m = 0$そして$k = 0$。 他の値$k$も有効ですが、実装では一貫してゼロが選択されます。 

欠損値と固定値が交互に存在する場合:```
5

```収集される境界値は [1, 100, 1] です。 候補区間は[1, 100]となり、$k=50$最大偏差は 49 に最小化されます。すべての欠落ブロックが隣接する固定値に一度だけ寄与するため、スキャンはすべての制約を正確に捕捉します。 

欠損値のない完全に固定された配列の場合:```
4
1 2 3 4
```に関する制約はありません$k$、答えは単純に最大隣接差分、つまり 1 です。このアルゴリズムは、欠落しているセグメントがないことを検出し、候補の評価を完全にバイパスします。
