 ## 問題の理解

 小文字の文字列が与えられ、元の順序を維持しながらその文字の空でない部分シーケンスを選択できます。 

考えられるすべての部分列の中で、辞書編集上最大の部分列が必要です。 辞書編集的な比較は辞書の順序とまったく同じように動作します。2 つの文字列が異なる最初の位置が勝者を決定し、一方の文字列が他方の文字列のプレフィックスである場合、長い文字列の方が大きくなります。 

文字列の長さは次のとおりです$10^5$。 すべての文字は取得またはスキップされる可能性があるため、後続の問題はすぐに指数関数的な検索スペースを示唆します。 がある$2^n-1$空ではないサブシーケンス。列挙することは完全に不可能です。$n=10^5$。 大きなサフィックスを繰り返しスキャンするアルゴリズムでも、パフォーマンスが低下すると遅くなりすぎる可能性があります。$O(n^2)$仕事。 2 秒の制限があるため、直線的なタイムまたはそれに近いタイムを目標にする必要があります。

## アプローチ

 ブルートフォースのアイデアは単純です。すべてのサブシーケンスを生成し、それらを辞書編集的に比較し、最良のものを保持します。 

これが機能するのは、問題の定義が正確に「すべての部分列の中から最大値を見つける」であるためです。 残念ながら、次の長さの文字列$n$もっている$2^n$後続。 たとえ$n=50$、それはすでに 1,000 兆を超える可能性があります。 のために$n=10^5$、絶望的です。 

何かをより速く見つけるには、何が辞書編集上の順序を決定するのかを考える必要があります。 

最初の文字は最も重要な位置です。 サブシーケンスが次で始まる場合`y`で始まるサブシーケンスには決して勝てません。`z`。 つまり、答えの最初の文字は、文字列内の任意の場所に現れる最大の文字でなければなりません。 

現在のサフィックスに現れる最大の文字が次であると仮定します。`c`。 最適な答えはすべて次のようなもので始まる必要があります。`c`。 どの現象が発生するか`c`飼うべきですか？ 

全部取ってください。 

2 つの回答候補が同じ接頭辞で始まり、1 つが同じ最大文字の余分なコピーで続く場合、長い方が辞書編集的に大きくなります。 最大の文字を取得しても、以前の位置が悪化することはないため、ペナルティはありません。 

この観察により、非常に単純な見方が得られます。 これまでに確認された最大の文字を維持しながら、文字列を右から左に処理します。 文字がその位置のサフィックスの最大値と等しい場合、その文字は正確に答えに含まれます。 

例えば：```

```接尾辞の最大値は次のとおりです。```

```文字がそのサフィックスの最大値に等しい位置が選択されます。```

  ^   ^ ^ ^
```結果のサブシーケンスは次のようになります。```
bbba
```これには 1 回のリニア スキャンのみが必要です。

 ## アルゴリズムのチュートリアル

 1. 文字列を読み取ります。 
2. 文字列を右から左にトラバースします。 
3. メンテナンス`mx`、接尾辞でこれまでに見つかった最大の文字。 
4. 現在の文字がより大きい場合`mx`、 アップデート`mx`。 
5. 現在の文字が次の場合`mx`、回答に追加します。 

文字は接尾辞の最大値です。 辞書編集上最適な最大サブシーケンスには、それが含まれている必要があります。 
6. 集めた文字は右から左に取得できたので、それを逆にします。 
7. 結果の文字列を出力します。 

### なぜ効果があるのか

 どの位置でも、`M`それ自身を含め、その右側に表示される最大の文字になります。 

現在の文字が以下より小さい場合`M`、これを選択すると、サブシーケンスは、次の発生時に始まる文字よりも悪い文字で強制的に開始されます。`M`。 そのような選択は決して最適な答えに属しません。 

現在の文字が等しい場合`M`、それをスキップすることも最適ではありません。 この文字を保持すると、将来のすべての最適な文字を選択する可能性を維持しながら、利用可能な最大の文字が追加で出現します。 辞書編集順では、接頭辞が等しい場合には長い文字列が優先されるため、接尾辞の最大文字をすべて取得することが常に有益です。 

したがって、最適なサブシーケンスは、その文字がサフィックスの最大文字に等しい位置から正確に構成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()

    mx = ''
    ans = []

    for ch in reversed(s):
        if ch > mx:
            mx = ch
        if ch == mx:
            ans.append(ch)

    print(''.join(reversed(ans)))

if __name__ == "__main__":
    solve()
```変数`mx`これまでに処理されたサフィックスに含まれる最大の文字を格納します。 右から左にスキャンするため、これは正確に現在の位置のサフィックスの最大値になります。 

現在の文字が等しいときはいつでも`mx`、保管しております。 接尾辞の最大値より小さい文字は破棄されます。これは、より大きな文字が後に存在し、辞書編集順序を支配するためです。 

スキャンは文字列の末尾から先頭に向かって進むため、回答は逆の順序で収集されます。 最後に一度反転すると、サブシーケンスの元の左から右の順序が復元されます。 

このアルゴリズムは文字とリストのみを操作するため、整数オーバーフローの懸念はありません。 唯一の微妙な点は、`if ch == mx`潜在的にアップデートした後`mx`。 これにより、新たに検出された最大文字数が確実に含まれるようになります。

import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    ans = []

    for ch in reversed(s):

            mx = ch
        if ch == mx:
            ans.append(ch)

    return ''.join(reversed(ans))

# minimum size
