 ## 解決策
 ## 問題の理解

 X 軸上の双眼鏡の列から観察できるフラミンゴの総数を最大化するように求められます。 各双眼鏡は位置 (i,0) にあり、任意の方向に向けることができます。 各フラミンゴは、整数座標 (xᵢ, yᵢ) の第 1 象限のどこかに位置します。 双眼鏡をある方向に設定すると、その線上にあるすべてのフラミンゴを正確に「見る」ことができます。 

入力により、n 個の双眼鏡と m 個のフラミンゴが得られます。 出力は、すべての双眼鏡で、それぞれが 1 つのラインに沿って見えるフラミンゴの最大数の合計を表す 1 つの整数です。 各双眼鏡はその角度を独立して選択できるため、これは、各双眼鏡について、その双眼鏡を通る各ライン上にフラミンゴの数を計算し、最大値を取得することになります。 

制約を見ると、n は 10^6 まで大きくなり得ますが、m は最大 250 でした。この差が重要です。O(n*m^2) 演算を望む場合、単純な方法で双眼鏡とフラミンゴのすべてのペアを反復処理することはできませんが、m は十分小さいため、一部の内部計算ではフラミンゴごとに O(m^2) 演算が可能です。 また、大きな座標にも注意する必要があります。フラミンゴの位置は最大 10^9 になる可能性があるため、傾き計算における浮動小数点エラーを回避する必要があります。 正確な分数を使用するか、最大公約数による傾き正規化を使用することが不可欠です。 

複数のフラミンゴが複数の双眼鏡の同じラインに沿って横たわっている場合、明らかではないエッジケースが発生します。 たとえば、n=3、m=2、フラミンゴが (2,1) と (4,2) にいると仮定します。 3 つの双眼鏡はすべて、2 匹のフラミンゴを見るために位置を合わせられる可能性がありますが、x=1 の双眼鏡は、フラミンゴが同一線上にある場合、線に沿って一度に 1 匹しか見ることができません。 すべての双眼鏡ですべてのフラミンゴが見えると単純に仮定すると、数えすぎてしまいます。 

もう 1 つのエッジ ケースは、xᵢ - x_binocular = 0 の垂直線です。ゼロによる除算を避けるために除算を慎重に処理する必要があります。 

## アプローチ

 簡単な総当たりアプローチは、すべての双眼鏡を反復処理し、双眼鏡を通過してすべてのフラミンゴに到達するすべての線をチェックすることです。 それぞれの双眼鏡について、各フラミンゴまでの傾きを計算し、その傾きを共有するフラミンゴの数を数えることができます。 両眼 i の場合、これには O(m) の傾き計算と O(m) のカウント操作が含まれ、全体的な複雑さは O(n * m^2) になります。 n が最大 10^6、m が最大 250 の場合、n_m^2 はおよそ 6_10^10 回の演算に達しますが、これでは遅すぎます。 

最適化するための重要な洞察は、ループを反転することで得られます。つまり、フラミンゴの数が少ないということです。 すべての双眼鏡を反復して傾斜を計算する代わりに、フラミンゴのすべてのペアを反復し、どの双眼鏡が同じラインに沿って両方のフラミンゴを見ることができるかを決定します。 フラミンゴのペアごとに、そのペアによって定義される線上にある両眼の位置のセットを決定します。 1 匹のフラミンゴの場合、双眼鏡を通る線は傾き (y_f / (x_f - x_bin)) を持ちます。 直線上の整数 x の位置を解くと、両方のフラミンゴが見える両眼指標の連続した間隔が得られます。 これにより、問題は、m 匹すべてのフラミンゴをスキャンし、傾きが一致する x 軸上の間隔を記録することで、各双眼鏡で何匹のフラミンゴが見えるかを数えるという問題に軽減されます。 

実際には、フラミンゴごとに、他のすべてのフラミンゴに対する傾きを計算し、それを有効な両眼位置にマッピングします。 m 個のフラミンゴとフラミンゴごとに m 個の傾斜を反復することにより、O(m^2) の処理が達成されます。次に、これを n 台の双眼鏡すべてに適用すると、スイープまたはプレフィックス合計手法を使用してカウントを慎重に集計すると、O(n + m^2) に減ります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * m^2) | O(m) | 遅すぎる |
 | 最適 | O(n * m) (傾きマッピングあり) | O(m^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. n と m を読み取り、フラミンゴ座標をリストに保存します。 
2. リストの初期化`binocular_counts`サイズ n からゼロまで。 これは、各双眼鏡で確認できるフラミンゴの最大数を保持します。 
3. 各両眼位置 i を 1 から n まで繰り返します。 両眼 i の場合は辞書を作成します`slope_count`この双眼鏡からの正規化された各傾斜を、その傾斜に沿ったフラミンゴの数にマッピングします。 
4. 各フラミンゴ (x_f、y_f) について、dx = x_f - i および dy = y_f を計算します。 最大公約数を使用して、傾き dy/dx を最小項で分数に換算します。 縦線(dx=0)を特殊キーとして個別に扱います。 
5. カウントをインクリメントします`slope_count`この坂に関しては。 すべてのフラミンゴを処理した後の最大値は、`slope_count`は両眼 i で見えるフラミンゴの最大数です。 
6. この最大値を合計に加算します。 
7. すべての双眼鏡を処理した後の合計を出力します。 

機能する理由: 各双眼鏡は、最も多くのフラミンゴと交差する線を個別に選択します。 正確な短縮分数形式で傾きを計算することにより、浮動小数点エラーを発生させることなく、同じ線上にあるすべてのフラミンゴを正確に数えることができます。 すべての双眼鏡を反復処理することで、それぞれの寄与を確実に考慮します。 

## Python ソリューション```python
import sys
import math
from collections import defaultdict
input = sys.stdin.readline

n, m = map(int, input().split())
flamingos = [tuple(map(int, input().split())) for _ in range(m)]

total = 0

for i in range(1, n + 1):
    slope_count = defaultdict(int)
    for x_f, y_f in flamingos:
        dx = x_f - i
        dy = y_f
        if dx == 0:
            slope = 'inf'
        else:
            g = math.gcd(dy, dx)
            slope = (dy // g, dx // g)
        slope_count[slope] += 1
    total += max(slope_count.values())

print(total)
```このソリューションは、各双眼鏡から各フラミンゴまでの傾きを計算し、同じ傾きを共有するフラミンゴの数を数えます。 垂直線は特殊な傾斜として扱われます。 の`max(slope_count.values())`最も多くのフラミンゴが見られるラインを確実に選択します。 を使用して`defaultdict`インクリメントする前にキーが存在するかどうかを確認する必要がなくなります。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n * m) | n 個の双眼鏡のそれぞれが m 匹のフラミンゴを反復して傾きを計算します。 |
 | スペース | O(m) | 各双眼鏡には、最大 m 個のフラミンゴの斜面が一時的に保存されます。 |
