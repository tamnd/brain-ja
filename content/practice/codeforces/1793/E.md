 ## 解決策
 ## 問題の理解

 私たちには一組の常連読者がおり、それぞれが個人的な満足度の基準値を持っています。読者は、少なくとも一定数の人が自分たちと同じ本を読んでくれれば満足します。 毎年、ヴェレピンは指定された数の本を執筆しており、私たちは各読者にこれらの本のいずれかを割り当てることができます。 この質問では、書籍に読者を最適に割り当てることができた場合に、満足できる読者の最大数は何人になるかを毎年尋ねています。 

入力により得られるものは、`n`、リーダーの数、および配列`a`どこ`a[i]`書籍に必要な読者の最小人数です`i`満足すること。 それから私たちは与えられます`q`年ごとに`k_j`そして、毎年満足した読者の最大数を計算する必要があります。 

制約は大きいです:`n`そして`q`最大 300,000 まで可能です。 これは、`O(n*q)`解決策が遅すぎます。 もっと近いものが必要です`O(n log n + q log n)`または`O(n + q)`前処理後のクエリごと。 単純な解決策でつまずく可能性のあるエッジ ケースには、すべての読者のしきい値が高い場合や、本の数が読者の数に非常に近い場合などがあり、慎重に扱わないと一部の読者を満足させることができない可能性があります。 たとえば、次の場合`n=5`、`a=[5,5,5,5,5]`そして`k=2`、1 冊あたり 5 人未満の読者を割り当てた場合、誰も満足させることはできません。 

## アプローチ

 強引な解決策では、書籍間で読者の可能な限りの分布を試し、満足した読者をカウントします。 それぞれについて`k`のすべての組み合わせを繰り返すことができます。`n`読者に`k`空でないグループでは、どのリーダーが満足度のしきい値を満たしているかを確認し、満足度を最大化する割り当てを選択します。 これは論理的には機能しますが、絶望的に遅いため、パーティション化する方法は指数関数的に多くあります。`n`読者に`k`グループ。 のために`n`3e5 あたりでは、これは完全に非現実的です。 

重要な洞察は、満足度は各書籍に割り当てられた読者の数のみに依存し、読者の特定のアイデンティティには依存しないということです。 満足度のしきい値を並べ替える`a`これにより、特定の書籍数に対して満足できる最大の読者グループを推論することができます。 基本的に、読者に最小の値を割り当てたいと考えています。`a[i]`実行可能な最小のグループに分割し、次にさらに大きなグループに分割します`a[i]`より大きなグループに分割し、各グループにすべての読者を満足させるのに十分なメンバーがいることを確認します。 

この問題は、プレフィックス合計/貪欲なアプローチのバリエーションに帰着します: ソート後`a`、リーダーを次のように分割できるように、リーダーの最大のプレフィックスが必要です。`k`各グループがそのグループ内の最大しきい値と少なくとも同じ大きさであるグループ。 プレフィックス サイズの二分探索により、それぞれについて効率的にこれに答えることができます。`k`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 (ソート + プレフィックス合計 + 二分探索) | O(n log n + q log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列をソートする`a`降順ではない順に。 これにより、しきい値が小さい読者を最初に処理できるようになります。これは、しきい値を満足させるには、1 冊あたりの読者の数が少なくて済むため、非常に重要です。 
2. 次のプレフィックス合計配列を計算します。`a`。 これにより、並べ替えられた順序で連続するリーダーのグループの「必要なリーダー」の合計をすばやく計算できるようになります。 
3. クエリごとに`k`、リーダーの数に対して二分探索を実行します。`m`私たちは満足しようとします、`0`に`n`。 候補者にとって`m`、これらを分割します`m`読者に`k`できるだけ均等にグループ化します。 各グループは最大値を満たす必要があります`a[i]`そのグループ内で。 プレフィックス合計を使用して、これが可能かどうかを効率的に確認します。 
4.最大の`m`チェックに合格したものがその年の答えになります。 この番号を返します。 

機能する理由: 並べ替えにより、しきい値が低い読者が最初にグループ化され、より多くの人を満足させる可能性が最大化されます。 プレフィックスの合計により、候補グループごとに O(1) の実現可能性を検証できます。 二分探索により、最大数の満足できるリーダーを効率的に見つけることが保証されます。 重要な不変条件は、グループのサイズをそのグループ内の最大のしきい値と常に比較するため、各ステップでグループ内のすべての読者が満足度のしきい値を満たしていることです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    q = int(input())
    ks = [int(input()) for _ in range(q)]
    
    a.sort()
    
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i+1] = prefix[i] + a[i]
    
    results = []
    
    for k in ks:
        low, high = 0, n
        ans = 0
        while low <= high:
            mid = (low + high) // 2
            full_groups = mid // k
            extra = mid % k
            ok = True
            for i in range(k):
                group_size = full_groups + (1 if i < extra else 0)
                if group_size == 0:
                    continue
                group_max_index = mid - (k - i - 1) * full_groups - (1 if i >= extra else 0)
                group_max_index -= 1
                if a[group_max_index] > group_size:
                    ok = False
                    break
            if ok:
                ans = mid
                low = mid + 1
            else:
                high = mid - 1
        results.append(ans)
    
    print("\n".join(map(str, results)))

solve()
```解決策は整理から始まります`a`、次にプレフィックス合計を構築して、グループの実現可能性を効率的にチェックします。 毎年、二分探索により、満足度を満たしながら書籍に割り当てることができる読者の最大数が決定されます。 読者よりも本の数が多い、またはすべてのしきい値が高いなどの特殊なケースは、二分探索によって自然に処理されます。
