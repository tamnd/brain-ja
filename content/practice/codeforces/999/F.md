 ## アルゴリズムのチュートリアル

 それぞれの個別のカード値を個別に処理し、最大の貢献をグローバルな答えに蓄積します。 

1. 各カードの値の出現を数えます。 あらゆる価値観に対して$x$、カードが何枚存在するかがわかります。 
2. プレイヤーを好きな番号でグループ化します。 それぞれの値について$x$、お気に入りのプレイヤーをすべて収集します。$x$。 これらのプレイヤーだけが価値のあるカードの恩恵を受けることができます$x$。 
3. 固定値の場合$x$、DP 配列を定義します。$dp[i][j]$最初のを考慮した後の最大合計ゲインを表します$i$このグループのプレーヤーが正確に分布している$j$価値のあるカード$x$。 
4.初期化$dp[0][0] = 0$、その他すべての状態は不可能です。 
5. このグループの各プレーヤーについて、トランジションを計算します。 

現在の割り当てごとに$j$、このプレーヤーに与えてみてください$t$カード、どこ$0 \le t \le k$そして$j + t \le c_x$。 

追加されるゲインは、$h_t$。 

更新します$dp[i+1][j+t]$それに応じて。 

これが機能する理由は、各プレイヤーの報酬が各プレイヤーの試合数のみに依存し、それらの試合が他のプレイヤー間でどのように分割されるかには依存しないためです。 
6. すべてのプレイヤーの値を処理した後$x$、このグループで達成可能な最良の値を取得し、それをグローバルな答えに追加します。 
7. すべての個別の値について繰り返します。 

すべての値の最終合計が答えになります。 

### なぜ効果があるのか

 重要な不変条件は、各値について$x$、DP はすべての有効なディストリビューションを完全に調査します。$c_x$興味のあるプレイヤー間で同じアイテム$x$、最適な下部構造を維持しながら、プレーヤーが取得するアイテムの数を決定すると、その貢献は固定され、残りの容量の制約を除いて他のものから独立します。 値は独立しており、プレイヤーは値ごとに自分の試合からのみ利益を得ることができるため、各値を個別に最適化して合計するのが正しいことになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    cards = list(map(int, input().split()))
    fav = list(map(int, input().split()))
    h = [0] + list(map(int, input().split()))

    from collections import defaultdict

    cnt = defaultdict(int)
    for x in cards:
        cnt[x] += 1

    players_by_val = defaultdict(list)
    for i, x in enumerate(fav):
        players_by_val[x].append(i)

    ans = 0

    for val, players in players_by_val.items():
        c = cnt[val]
        if c == 0:
            continue

        m = len(players)

        dp = [[-1] * (c + 1) for _ in range(m + 1)]
        dp[0][0] = 0

        for i in range(m):
            ndp = [[-1] * (c + 1) for _ in range(m + 1)]
            for j in range(c + 1):
                if dp[i][j] < 0:
                    continue
                cur = dp[i][j]
                for t in range(k + 1):
                    if j + t > c:
                        break
                    val_gain = cur + h[t]
                    if ndp[i + 1][j + t] < val_gain:
                        ndp[i + 1][j + t] = val_gain
            dp = ndp

        best = 0
        for j in range(c + 1):
            best = max(best, dp[m][j])

        ans += best

    print(ans)

if __name__ == "__main__":
    solve()

遷移ループは、最大ですべての割り当てを明示的に試行します。$k$プレイヤーごとのカード。 キャップ$c + 1$利用可能なカードを超えないようにします。 使用する$-1$不可能な状態により、無効な遷移の伝播が防止されるためです。 

値間の結合が存在しないため、最終的な集計では、値グループごとの最適な寄与を単純に合計します。

 ## 特殊なケース

 微妙なエッジ ケースの 1 つは、カードに値が表示されているにもかかわらず、それを好むプレイヤーがいない場合です。 その値のプレイヤー リストが空であるため、その値の寄与はゼロであるため、アルゴリズムは当然これを無視します。 これにより、誤って無駄な DP が実行されるのを防ぎます。 

もう 1 つのケースは、カードの数がカードを必要とするプレイヤーの数よりも少ない場合です。 たとえば、3 人のプレイヤーが値を必要としているが、カードが 1 枚しか存在しない場合、DP は 1 人のプレイヤーだけが値を取得できるようにします。$t=1$そして他の人は得る$t=0$、最大化する$h_1$ゼロ貢献を誤って分散させるのではなく、単一の割り当てに対して。 

3 番目のケースは次の場合です。$h_t$が急激に増加するため、複数のプレイヤーが対象である場合でも、すべてのカードを 1 人のプレイヤーに集中させることが最適になります。 DP はすべての配分を明示的に評価するため、より高い総報酬が得られる場合には、この集中的な配分が自然に選択されます。
