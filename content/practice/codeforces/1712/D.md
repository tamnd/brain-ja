 ## 解決策
 ## 問題の理解

 各位置がライン内のノードを表す配列が与えられます。 任意の 2 つのインデックスの間$l$そして$r$、部分配列内に重みが最小値であるエッジがあります。$a_l, \dots, a_r$。 すべての頂点のペアが接続されているため、非常に特殊な構造を持つ完全なグラフが形成されます。エッジの重みはセグメントの最小値から得られます。 

せいぜい変更が許される$k$配列の位置を任意の値に設定します。 これらの変更後、このグラフの最短経路距離を考慮し、可能な最大のグラフ直径、つまり頂点のペア間の最大最短経路距離を求めます。 

重要な問題は、エッジの重みが独立していないことです。 単一の値はその位置を含むすべてのセグメントに影響を与えるため、1 つの変更が一度に多くのエッジに影響を与える可能性があります。 中間頂点を通過すると、直接の最小エッジよりも大きな総重みが生成される可能性があるため、最短パスも直接エッジではありません。 

制約が十分に厳しいので、$n$まで上がります$10^5$したがって、すべてのペアを試行したり、グラフの距離を明示的に再計算したりするソリューションは失敗します。 平$O(n^2)$テストケースごとに推論することは不可能です。 テストごとに線形または線形演算に近いものが必要です。 

素朴な推論でよくある失敗例は、答えが極大値または選択のみに依存すると仮定することです。$k$最大の要素。 たとえば、次の場合$a = [1, 100, 1]$そして$k = 1$、中間の要素を増やしてみることもできますが、実際の効果は、個々の値だけでなく、小さな最小値からどれだけのセグメントを「保護」できるかにかかっています。 

もう 1 つの罠は、最短パスが直接エッジの重みに等しいと仮定することです。$\min(a_l, \dots, a_r)$。 実際には、長い間隔をより小さい間隔に分割すると、中間ノードが小さな最小値を回避できるため、パスの長さが増加する可能性があります。 

## アプローチ

 グラフには特別な構造があります: あらゆるペアに対して$u < v$、直接エッジの重みはセグメント内の最小値です。$[u, v]$。 パスの観点から考えると、中間頂点を使用すると、大きなセグメントが、最小値が個別に取得される小さなセグメントに置き換えられます。 

このタイプの構築は、パスが区間をサブセグメントに分割することに対応するため、最短パスを「パーティションに沿ったセグメント最小値の最大値」に減らすことが知られています。 

ブルートフォースアプローチは、最大の変更方法をすべて試すことです。$k$要素を計算し、すべてのセグメントの最小値を再計算し、すべての最短パスを構築し、直径を計算します。 グラフの再計算を無視しても、配列の数は$\binom{n}{k} \cdot 10^k$、各評価には少なくとも$O(n^2)$すべてのペアの推論。 これはすぐに爆発します。 

重要な観察は、最適な変更は常に非常に構造化された方法で動作するということです。 恣意的な変更ではなく、「弱点」（セグメントの最小値を減らす小さな値）がどこに残っているかだけを考慮します。 それぞれの変更は、そのような弱点を 1 つ取り除くものと考えることができ、残るのは、最小値が動作を支配するブロックへの配列のセグメント化です。 

「低い値からどれだけのセグメントを分離できるか」に視点を移すと、問題はしきい値の選択と、しきい値の達成を妨げる不良要素の数の確認になります。 これにより、当然のことながら、貪欲な実現可能性チェックと組み合わせて、答えに対する二分探索が行われます。 

固定候補直径の場合$X$、その距離をサポートできる少なくとも 1 つの「強力な構造」セグメントが必要であると解釈します。 次に、直径を下回るセグメントが存在しないようにするには、アップグレードする必要がある位置の数を数えます。$X$修正できないままです。 このコスト以内であれば$k$、値は達成可能です。 

これにより、問題は単調な実現可能性条件に変換されます。$X$、二分探索を有効にします。

 ## アルゴリズムのチュートリアル

 可能な最大直径値を二分探索することによって問題を解決します。 

1. 回答候補を修正する$X$。 グラフの直径を少なくとも大きくできるかどうかをテストします。$X$せいぜい使用$k$修正。 

このチェックの意味は、最短パスが少なくとも次のノードのペアが存在する構成を強制できるかどうかです。$X$。 
2. 低い配列値を障害物として解釈します。 以下の任意の値$X$セグメント内ではセグメント最小値が減少する傾向があるため、エッジの重みが減少します。 

長い距離を維持するには、これらの障害物を十分に「無力化」して、長い経路がそれらを通過する必要がないようにする必要があります。 
3. アレイをスキャンし、変更が必要な箇所を貪欲に決定します。 長いセグメントの候補を分割するような形で低い値がクラスター化されている領域に遭遇するたびに、その影響を排除するために 1 回の操作を費やします。 

貪欲な性質が働くのは、ポジションが上向きに固定されると、それに関係するすべての制約が取り除かれるためです。そのため、ポジションを遅らせることは決して役に立ちません。 
4. 少なくとも直径と互換性のある構成を作成するために必要な修正の数を数えます。$X$。 このカウントが$\le k$、 それから$X$実現可能です。 
5. 可能な限り二分探索を行います$X$値の範囲を超えています。 

### なぜ効果があるのか

 正しさは実現可能性の単調性にかかっています。 直径の場合$X$は達成可能ですが、制約は緩和されるだけであるため、より小さい値も達成可能です。 それぞれの変更により、長い最短経路を妨げる構造的な障害物が除去されます。これらの障害物は、1 つを修正しても他の場所で必要な修正の数が増加しないという意味で独立しています。 これにより、必要な修正の貪欲なカウントが有効になり、実際のコストを過小評価したり過大評価したりすることがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can(a, k, x):
    n = len(a)
    used = 0
    i = 0
    while i < n:
        if a[i] >= x:
            i += 1
            continue
        used += 1
        if used > k:
            return False
        j = i
        while j < n and a[j] < x:
            j += 1
        i = j
    return True

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))

        lo, hi = 1, max(a) + k + 1
        ans = 1

        while lo <= hi:
            mid = (lo + hi) // 2
            if can(a, k, mid):
                ans = mid
                lo = mid + 1
            else:
                hi = mid - 1

        print(ans)

if __name__ == "__main__":
    solve()
```実装では、実現可能性のチェックが検索から分離されます。 の`can`関数は配列をスキャンし、しきい値以下の連続する位置をグループ化します。 このような各グループは、達成可能な直径が目標値を下回るのを防ぐために、少なくとも 1 回の操作で修復する必要がある領域に対応します。 

二分探索により可能な直径値が探索され、上限は調整可能な最大値を超えて安全に設定されます。 

微妙な点は、グラフの距離を明示的にシミュレートしようとしていないことです。 最短経路構造全体は、セグメント最小値において下位要素がどのようにボトルネックとして機能するかについての推論に圧縮されています。

 ## 特殊なケース

 重要なエッジケースは、すべての値がすでに大きい場合です。 のような入力の場合`[10^9, 10^9, 10^9]`どれでも$k$の場合、実現可能性チェックでは低いセグメントが検出されないため、二分探索はすぐに最大値に収束します。 これにより、アルゴリズムが不必要な変更を強制しないことが確認されます。 

もう 1 つのエッジ ケースは、次のような低い値と高い値が交互に現れることです。`[1, 100, 1, 100, 1]`。 ここでは、すべての下位要素が独自のセグメントを形成し、それぞれが独立した処理を必要とします。 スキャンは、孤立した低い位置をそれぞれ正確にカウントし、必要な操作数が障害物の大きさではなく構造に一致することを保証します。 

最後のエッジケースは次のような場合です$k = n$。 このアルゴリズムは、すべての低セグメントを修復可能として扱うため、上限までは任意のしきい値が実現可能になります。これは、配列を完全に上書きして直径を最大化できるという考えと一致します。
