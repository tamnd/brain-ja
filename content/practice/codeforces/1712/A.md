 ## 解決策
 ## 問題の理解

 1 から 1 までの整数の順列が与えられます。$n$、1 から 1 までのすべての数字を意味します$n$任意の順序で 1 回だけ表示されます。 タスクは、最初の合計を最小化することです。$k$任意の 2 つの位置の間で交換を実行することにより、この順列内の要素を取り除きます。 各スワップは 1 つの操作としてカウントされ、必要なそのような操作の最小数を見つけるように求められます。 

入力サイズが小さい場合:$n$最大 100 個、最大 100 個のテスト ケースを含めることができます。 これは、$O(n^2)$解決策は受け入れられますが、次のことを目指すこともできます。$O(n \log n)$並べ替えを使用して。 すべての数値は個別であり、次の範囲内にあるため、$n$重複した数値や範囲外の数値が存在することはないため、順列を検証する必要はありません。 

微妙なエッジケースは、最初の場合です。$k$要素にはすでに$k$最小の数字。 たとえば、次の場合$n=5$、$k=3$、配列は$[1, 2, 3, 5, 4]$スワップは必要ないため、答えは 0 になるはずです。 配置が間違っている数値が最初の値に既に存在するかどうかを考慮せずに、盲目的にカウントする単純なアプローチ$k$スロットがスワップを過剰にカウントする可能性があります。 

もう一つのエッジケースは、$k=1$または$k=n$。 もし$k=1$、最初の位置にある最小の要素のみが必要です。 もし$k=n$の場合、合計には順列全体が含まれますが、これはすでに固定されているため、スワップは可能または必要ありません。 

## アプローチ

 ブルートフォースアプローチは、考えられるすべてのスワップシーケンスを試し、最初のスワップの合計を計算することです。$k$各シーケンスの後の要素。 これは原理的には正しいですが、完全に非現実的です。 のために$n=100$、おおよそあります$\binom{100}{2} = 4950$単一のスワップの可能性があり、複数のスワップを検討すると、組み合わせが急速に爆発的になります。 

重要な洞察は、最初の合計を最小化することです。$k$要素の配置のみを考慮します。$k$最小の数値を最初に入れる$k$ポジション。 この中での順番は$k$番号は重要ではなく、残りの順序も重要ではありません。$n-k$数字。 したがって、問題は、次のものがいくつあるかを数えるということになります。$k$現在、最小の数値は最初の数値の外側にあります$k$ポジション。 これらの各数値を交換する必要があります。各交換では、最初の数値のうち 1 つだけを修正できます。$k$したがって、演算の数は、現在外側にある小さな数値の数に等しくなります。 

これを実装するには、まず次のことを決定します。$k$最小の数値 (単純に 1 から 1 まで)$k$。 次に、最後のものを繰り返します$n-k$位置を決めて、最初に何個あるか数えます$k$最初から数字が抜けています$k$スロット。 欠落している各番号は、必要なスワップに対応します。

 | --- | --- | --- | --- |
 | ブルートフォース | O((n!) * n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最初に必要な数値のセットを特定します。$k$ポジション。 これらは 1 から 1 までの整数です$k$。 セットを使用すると、$O(1)$会員チェック。 
2.最初のスキャン$k$要素を指定し、次のどれであるかをマークします$k$数字はすでに設定されています。 何個欠けているか数えてください。 1 から 1 までのどの数字を知る必要があるだけです$k$最初から欠席している$k$スロット。 
3. 最初の数字の欠落$k$ポジションは必要なスワップ数に正確に対応します。 各スワップは、残りの数字から 1 つの不足している小さな数字を取り込むことができます。$n-k$ポジション。 
4. 欠落している数値の数を最小操作数として返します。 

機能する理由: このアルゴリズムは、最初の数値以外のすべての数値が不変であることを維持します。$k$最初に属するポジション$k$は 1 回だけカウントされます。 欠落している各数字を交換すると、欠損が 1 つだけ修正されます。 必要な数字だけを交換するので、無駄な操作は一切行いません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    p = list(map(int, input().split()))
    
    # Set of numbers that should be in the first k positions
    needed = set(range(1, k+1))
    
    # Count numbers among first k that are already correct
    in_place = sum(1 for i in range(k) if p[i] in needed)
    
    # Missing numbers = total needed - already in place
    print(k - in_place)
```コードは各テスト ケースを読み取り、$k$最小の数字 (1 ～$k$)、最初のフィールドにすでに何個あるかをカウントします$k$位置を決め、その差を出力します。 最小数のセットを使用すると、メンバーシップの定数チェックが保証されます。 使用する`sum`ジェネレーター式を使用すると、一時リストの作成が回避されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        p = list(map(int, input().split()))
        needed = set(range(1, k+1))
        in_place = sum(1 for i in range(k) if p[i] in needed)
        print(k - in_place)
        
    return output.getvalue().strip()

 ## 特殊なケース

 もし$k = n$、 最初$k$位置には配列全体が含まれます。 アルゴリズムは 1 から 1 までの数字の数を数えます。$n$最初にいます$n$ポジション、これは常に$n$。 欠落しているカウントは$n-n=0$なので、正しく 0 が出力されます。 

もし$k = 1$最初の要素が 1 ではない場合、アルゴリズムは 1 が最初の位置にあるかどうかをカウントします。 そうでない場合は、1 を出力し、1 を前面に出すために 1 回のスワップが必要であることを示します。 

配列がすでにソートされている場合は、$k$最初の最小の数字$k$スロットの場合、アルゴリズムはすべてのスロットを正しくカウントし、0 を出力します。たとえば、(n=5、k=3、p=[1,2,3,5,4)
