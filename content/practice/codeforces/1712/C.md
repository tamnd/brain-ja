 ## 解決策
 ## 問題の理解

 それぞれが正の整数の配列で構成される、いくつかの独立したテスト ケースが与えられています。 1 回の操作で値を選択できるようになります`x`そして同時にすべての出現を消去します`x`配列内でそれらをゼロに変換します。 タスクは、結果として得られる配列が減少しないように、この操作をできるだけ少ない回数で適用することです。 

重要な点は、要素を再配置していないということです。 位置の相対的な順序は決して変更されず、値のみがゼロに置き換えられます。 ゼロは可能な最小値であるため、要素をゼロに変えることは、より大きな値がより小さな値の前に現れる逆転を修正するのにのみ役立ちます。 

制約`n ≤ 10^5`すべてのテスト ケースにわたって、テスト ケースごとに線形または線形に近い解決策が強制されます。 配列を繰り返しスキャンしたり、値ごとに単純に操作をシミュレートしたりするものは、削除のたびに順序構造を再計算すると遅すぎます。 

配列がすでに非減少である場合、微妙なエッジ ケースが発生します。 例えば、`[0, 0, 1, 1]`はすでに有効なので、操作は必要ありません。 常に何かを削除する不注意なアプローチ (たとえば、常に最初の反転をターゲットにする) は、不要な操作を誤って実行する可能性があります。 

もう 1 つの重要なケースは、値が大きく「インターリーブ」されている場合です。`[1, 2, 1, 2]`。 素朴な直観では、1 つまたは 2 つの操作で十分だと思われるかもしれませんが、ゼロは順序にグローバルに影響を与えるため、無秩序の異なる「層」がいくつ存在するかを慎重に推論する必要があります。 

## アプローチ

 ブルートフォース戦略では、考えられるすべての操作シーケンスをシミュレートします。 各操作で値が選択されます`x`そしてそれを完全に削除します。 各値は最大 1 回削除できるため、個別の値のサブセットを効果的に選択し、それらを適用した後に結果の配列がソートされるかどうかをチェックします。 

多くてもあります`n`個別の値であるため、サブセットの数は指数関数的になります。 有効性を確認しても`O(n)`サブセットごとの時間、これは次のようになります`O(2^n · n)`、それは完全に不可能です。 

重要な洞察は、「どの値を削除するか」から「配列内のどの構造が削除を強制するか」に視点を変えることです。 

削除後に配列が減少しないことが何を意味するかを観察してください。 残りのゼロ以外の値はすべて、ソートされた順序ですでに表示されている必要があり、すべての反転は、反転に含まれる 2 つの値のうちの少なくとも 1 つを削除することによって除去する必要があります。 

次に、これまでに確認された最大値を維持しながら、配列を左から右にスキャンすることを考えます。 減少 (実行最大値より小さい値) が見られるたびに、その位置によって制約が作成されます。つまり、反転を解消するには、現在の値か、その前の値を最終的に削除する必要があります。 削除はグローバルに値ごとに行われるため、そのような「ブレーク」に参加する個別の値ごとに少なくとも 1 つの操作が強制されます。 

重要な観察は、新しい「無秩序の層」に遭遇するたびに、それは別の操作で除去する必要がある個別の値に対応しているということです。 単調性を崩す原因となる個別の値がいくつあるかを数えることで答えが得られます。 

以下の位置に出現するすべての値を追跡することで、これを形式化できます。`a[i] < max(a[0..i-1])`。 このような値はすべて「不正」であるため、少なくとも 1 回は削除する必要があります。 1 回の操作で値の出現がすべて削除されるため、答えは減少する位置に出現する個別の値の数になります。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n · n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. これまでに確認された最大値を維持しながら、配列を左から右に走査します。 

これは、現在の「分類された期待」の境界を捉えています。 
2. 現在の要素が最大値以上である場合は常に、最大値を更新します。 

これは、この位置でシーケンスが壊れていないことを意味します。 
3. 現在の要素が最大値より小さい場合、この値を「不良」としてマークします。 

その理由は、この要素が以前のより大きな要素との反転に関与しているためです。 
4. このようなすべての「悪い」値をセットに保存します。 

同じ値が複数出現する場合に必要な操作は 1 回だけであるため、セットを使用します。 
5. 配列全体を処理した後の答えはセットのサイズになります。 

### なぜ効果があるのか

 不変条件は、検出するたびに、`a[i] < max_so_far`、有効なソリューションで絶対に削除する必要がある値を特定します。 これは、反転が含まれるためです。`a[i]`以前の最大値は、次のいずれかが発生しない限り修正できません。`a[i]`または、以前の大きい値が削除されます。 位置ではなく値でのみ削除できるため、値を次のようにマークします。`i`その制約をグローバルに説明するには十分です。 この方法で収集された個別の値は、すべての反転を排除するために必要な最小限の操作セットに正確に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        mx = 0
        bad = set()
        
        for v in a:
            if v >= mx:
                mx = v
            else:
                bad.add(v)
        
        print(len(bad))

if __name__ == "__main__":
    solve()
```コードは、前述のスキャンの直後に続きます。 変数`mx`実行最大値を維持し、単調性に違反する要素はセットに挿入されます。 最終的な答えは、そのような個別の値の数です。 重要な実装の詳細は、決定が純粋に左から右の構造に基づいているため、最大値をリセットしたり以前の要素を再検討したりしないことです。

値のみ`1`はドロップの一部であるため、すべてを削除します`1`s は配列を固定します。 

これは、複数の反転が 1 つの値の削除によって解決できることを示しています。

 ## 特殊なケース

 次のような完全にソートされた配列`[1, 2, 3]`決してトリガーしない`v < mx`そのため、不良セットは空のままになり、アルゴリズムは正しくゼロを返します。 

のような配列`[5, 5, 5]`保つ`mx`全体を通して変更されず、どの要素も不良とみなされないため、操作はまったく必要ありません。 

次のような降順配列では、`[4, 3, 2, 1]`、最初の要素を除くすべての要素が実行最大値に違反し、不正な値が生成されます。`{3, 2, 1}`。 したがって、アルゴリズムは、すべての反転の原因となる個別の値を正確にカウントし、必要な削除の最小数と一致します。
