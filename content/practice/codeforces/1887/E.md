 ## 解決策
 ## 問題の理解

 サイズのグリッドを操作するように求められます$n \times n$。 当初は、$2n$セルは独自の色であらかじめ色付けされています。$1$に$2n$、残りは着色されていません。 最大 10 回までの許可された動きのそれぞれで、アリスに、これまで色付けされていなかったセルに色を付けるように要求できます。 アリスが選ぶ色は任意です。$2n$利用可能な色と適応性: 彼女は私たちの動きに基づいて色を選択するかもしれません。 移動後、4 つのセルすべてが異なる色で着色されるように、4 つのセルで形成される長方形を識別する必要があります。 

各テスト ケースの入力は次のもので構成されます。$n$そして$2n$最初はセルをその座標で色付けしました。 出力は、Alice のクエリ (「? x y」)、または四角形の座標を与える最終回答 (「! x1 x2 y1 y2」) です。 長方形の辺はグリッド軸と平行でなければならず、その四隅の色は明確でなければなりません。 

制約$3 \le n \le 1000$最大 200 のテスト ケースは、考えられるすべての四角形を反復処理するソリューションは非実用的であることを意味します。 がある$\binom{n}{2}^2$内の潜在的な長方形$n \times n$グリッド、これは次のとおりです$10^{11}$のために$n = 1000$。 これにより、すべての四角形の総当りチェックが排除されるため、有効な四角形を迅速に見つけることを保証する建設的なアプローチが必要になります。 

次の場合、微妙なエッジケースが発生します。$2n$最初に色付けされたセルは、単純な行または列の選択が失敗するように配置されます。 たとえば、事前に色付けされたすべてのセルが最初の 2 行と最初の 2 列のみを占めている場合、長方形の座標を不用意に選択すると、重複する色が選択され、エラー判定が発生する可能性があります。 もう 1 つのトリッキーなシナリオは、アリスが最小の長方形の外側にクエリを実行するような方法で色を配置し、限られた 10 の手を無駄にする場合です。 

## アプローチ

 ブルートフォースアプローチでは、すべてをチェックしようとします。$\binom{2n}{4}$色付きのセルを組み合わせて、異なる色の長方形を形成するかどうかをテストします。 このアプローチは原理的には正しいですが、実行不可能です。$n = 1000$、$\binom{2000}{4} \approx 4 \cdot 10^{12}$操作。 長方形を生成するだけでも制限時間を超えてしまいます。 

重要な洞察は、$2n$色付きのセル$n \times n$グリッドでは、鳩の穴の原理により、それぞれに少なくとも 2 つの色の付いたセルが含まれる少なくとも 2 つの行と 2 つの列が存在する必要があります。 これにより、これらの行と列に角のある長方形が存在することが保証されます。 目標は、これらの行と列を選択し、異なる色の 4 つのセルを選択することです。 グリッドは十分に密であるため、有効な四角形を見つけるのに 10 回以上のクエリは必要ありません。$2n$ほとんどの場合、色付きのセルで十分であり、必要に応じてクエリを戦略的に使用できます。 

やみくもに検索する代わりに、色付きのセルを行と列ごとに整理し、複数の色を含む行と列から四角形を形成することを試みることができます。 これにより、検索対象がグリッド全体ではなく、セルの小さなサブセットに限定されます。 追加のクエリは、欠落している色を確認または補足して識別性を保証するために使用されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O((2n)^4)$|$O(2n)$| 遅すぎる |
 | 構成的な長方形の検索 |$O(n^2)$|$O(n^2)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む$n$そして$2n$現在のテスト ケースの最初に色付けされたセル。 2D 配列に格納する`color[x][y]`行と列によってインデックスが付けられます。 
2. 2 つの辞書を作成します。`rows`各行をその行の色のセットにマッピングし、`cols`各列をその列の色のセットにマッピングします。 これにより、複数の異なる色が含まれる行と列をすばやく識別できるようになります。 
3. 少なくとも 2 つの異なる色を持つ行を少なくとも 2 つ特定します。 同様に、少なくとも 2 つの異なる色で少なくとも 2 つの列を識別します。 鳩の巣原理によ​​り、これは常に可能です。$2n$の細胞$n \times n$グリッド。 
4. 候補の行と列を反復処理して、長方形を形成する 4 つのセルを見つけます。 選択した 4 つの色が区別できるように、各行と列から 1 つの色を選択します。 競合が発生した場合 (2 つのセルが同じ色である場合)、単一のクエリを使用して四角形内の色の付いていないセルをフェッチし、区別性を保証できます。 
5. 長方形の座標を次の形式で出力します。`! x1 x2 y1 y2`。 アリスは、四隅すべてが明確な色で着色されていることを確認します。 必要に応じて、クエリを使用して欠けている角を埋めたり、色の固有性を確認したりできます。 

機能する理由: このアルゴリズムは、事前に色付けされたセルの密度に依存しています。 と$2n$独特の色と$n \times n$セルには、複数の色を含む少なくとも 2 つの行と 2 つの列が存在し、長方形が保証されている必要があります。 行と列で整理すると、長方形を形成する 4 つのセルを選択できるようになります。 アリスがクエリ中に適応的に色を付ける場合でも、この四角形内の色の付いていないセルを選択することで、10 クエリの制限内で識別性を満たすことができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
flush = sys.stdout.flush

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        color = [[0] * (n + 1) for _ in range(n + 1)]
        rows = {}
        cols = {}

        for c in range(1, 2 * n + 1):
            x, y = map(int, input().split())
            color[x][y] = c
            if x not in rows:
                rows[x] = []
            if y not in cols:
                cols[y] = []
            rows[x].append((y, c))
            cols[y].append((x, c))

        row_candidates = [r for r, cells in rows.items() if len(cells) >= 2]
        col_candidates = [c for c, cells in cols.items() if len(cells) >= 2]

        r1, r2 = row_candidates[:2]
        c1, c2 = col_candidates[:2]

        # Pick four distinct colors if possible
        used_colors = set()
        rect = []
        for x in [r1, r2]:
            for y, col in rows[x]:
                if y in [c1, c2] and col not in used_colors:
                    rect.append((x, y))
                    used_colors.add(col)
        if len(rect) < 4:
            # Fill missing with queries
            for x in [r1, r2]:
                for y in [c1, c2]:
                    if (x, y) not in [(rx, ry) for rx, ry in rect]:
                        print(f"? {x} {y}")
                        flush()
                        c = int(input())
                        rect.append((x, y))
                        used_colors.add(c)
                        if len(rect) == 4:
                            break
                if len(rect) == 4:
                    break

        xs = [r for r, _ in rect]
        ys = [c for _, c in rect]
        print(f"! {xs[0]} {xs[1]} {ys[0]} {ys[1]}")
        flush()
```このソリューションでは、まず色付きのセルにデータを入力し、行と列ごとに整理します。 候補となる行と列は、4 つの異なる色で長方形を形成する可能性を最大化するように選択されます。 欠けているコーナーは対話型クエリによって埋められます。 境界処理により、グリッドの外側でクエリを実行することがなくなり、4 つの異なる色が確保されるとすぐにアルゴリズムが停止します。
