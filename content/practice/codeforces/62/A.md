 ## 解決策
 ## 問題の理解

 2 つのエイリアンの手の指の数を表す 4 つの整数があります。 金星の少女は、`al`彼女の左手の指と、`ar`彼女の右手に。 火星の少年は、`bl`そして`br`指。 

彼らはちょうど 1 組の手をつなぐことを望んでいます。 どちらの人も左側に立つことができるため、考えられる組み合わせは 2 つだけです。 

- 女の子の左手と男の子の右手
 - 女の子の右手と男の子の左手

 または反対の方向。 

配置は 2 つの快適さの規則を満たさなければなりません。 

まず、女の子の2本の指が直接触れてはいけません。 隣り合う女の子の指の間には、少なくとも 1 本の男の子の指がなければなりません。 

第二に、少年の 3 本の指が連続して触れてはなりません。 

タスクは、少なくとも 1 つの有効なハンド ペアが存在するかどうかを判断することです。 

制限は非常に小さく、すべての値は最大でも 100 です。すべての可能性に対する総当りのシミュレーションでさえ、即座に実行されます。 本当の課題は、文言の中に隠された数学的条件を認識することです。 

難しいのは、物理的記述を不等式に正しく変換することです。 

女の子が持っていると仮定します`g`指と少年は`b`選ばれた手の指。 

隣接する女の子の指をすべて分離するには、男の子には少なくとも次のものが必要です。`g - 1`指。 たとえば、女の子の指が 5 本の場合、次のような構造が必要です。`B G B G B G B G B G`女の子の指の間には4本の隙間があるため、男の子の指は少なくとも4本必要です。 

同時に、少年は連続して 3 本の指に触れることはできません。 つまり、女の子の指の周囲の各スロットに最大 2 本の男の子の指を配置できます。 

と`g`女の子の指、あるよ`g + 1`ボーイフィンガーが出現する可能性のあるスロット:

 - 最初の女の子の指の前
 - すべての隣接するペアの間
 - 最後の女の子の指の後

 各スロットには最大 2 つのボーイ フィンガーを含めることができるため、ボーイ フィンガーの最大数は次のようになります。`2 * (g + 1)`。 

よくある間違いは、エッジ スロットを忘れることです。 最大値は次のとおりであると誤って考える人もいるかもしれません。`2 * (g - 1)`、内部ギャップのみをカウントします。 例えば：```
girl = 1
boy = 4
```これは実際には有効です:`BBGBB`連続した 3 つのボーイフィンガーはありません。 

もう 1 つの簡単な間違いは、厳密な不等式を使用することです。 考慮する：```
girl = 5
boy = 4
```これは、男の子の指 1 本だけで女の子の指のすべてのペアを分離できるため、有効です。`GBGBGBGBG`下限は`boy >= girl - 1`、 ない`boy > girl - 1`。 

最後のエッジケースは、女の子の指がほとんどないときに現れます。```
girl = 1
boy = 0
```隣接する女の子の指を分離する必要がないため、これは有効です。 

この状態はまだ機能します。```
girl - 1 <= boy <= 2 * (girl + 1)
0 <= 0 <= 4
```## アプローチ

 最も直接的なアプローチは、総当たりの構築です。 選択した手のペアについて、考えられるすべての指の配置を生成して、ルールを満たす配置があるかどうかを確認することができます。 

女の子が持っている場合`g`指と少年は`b`、マージされたシーケンスの総数は次のとおりです。$$\binom{g+b}{g}$$実際の制約は小さいとしても、一般にこの制約は急速に増大します。 たとえば、合計フィンガー数がわずか 20 であるにもかかわらず、すでに 18 万以上のインターリーブが存在します。 有効な取り決めの構造を理解すれば、完全な検索は不要になります。 

重要な観察は、制約が間隔ルールを記述していることです。 

女の子の状態により、男の子の指が最低限必要になります。 女の子の指の隣接するすべてのペアには少なくとも 1 つのセパレータが必要なので、次のものが必要です。$$b \ge g - 1$$少年の状態は最大限の要求を生み出します。 男の子の 3 本の指が連続して接触することはできないため、女の子の指の周囲の各スロットには最大 2 本の男の子の指を含めることができます。 

と`g`女の子の指、あるよ`g + 1`スロット:```
_ G _ G _ G _
```各スロットには最大 2 本のボーイフィンガーを入れることができ、次のようになります。$$b \le 2(g+1)$$これら 2 つの不等式は必要かつ十分です。 

考えられる両方のハンドのペアリングを単純にテストします。 

-`(girl left, boy right)`-`(girl right, boy left)`どちらかが不等式を満たす場合、答えは次のようになります。`"YES"`。

 ## アルゴリズムのチュートリアル

 1. 4 本の指の数を読み取ります。 
2. 選択したハンドのペアのヘルパー チェック関数を定義します。 
3. 女の子が持っていると仮定します。`g`指と少年は`b`。 
4. 下限を確認します。$$b \ge g - 1$$これにより、隣接するすべての女の子の指を分離できることが保証されます。 

1. 上限を確認します。$$b \le 2(g+1)$$これにより、少年の指が複数の領域に分散されることが保証されます。`g + 1`3 つの連続したボーイ フィンガーを作成せずに利用可能なスロット。 

1. 両方の不等式が成立する場合、この組み合わせは実現可能です。 
2. 両方の方向をテストします。 

1. 女の子は左、男の子は右
 2. 女の子が右、男の子が左
 3. 少なくとも 1 つの方向が機能する場合は、印刷します。`"YES"`。 それ以外の場合は印刷します`"NO"`。 

### なぜ効果があるのか

 連続する女の子の指の間のすべてのギャップには少なくとも 1 つの男の子の指が含まれている必要があるため、下限は避けられません。 との手`g`女の子の指はまさに`g - 1`そういったギャップ。 

少年は連続 3 本の指を提供できない可能性があるため、上限も避けられません。 その周り`g`女の子の指はまさにそこにあります`g + 1`挿入位置には最大 2 本の少年の指を含めることができます。 

これらの条件も十分です。 少年の指の数が範囲内にある場合:$$g - 1 \le b \le 2(g+1)$$最初にすべての内部ギャップに 1 つのボーイ フィンガーを配置し、次に残りのボーイ フィンガーを利用可能なスロットに分配します。ただし、スロットあたり 2 つを超えないようにしてください。 それは常に有効な取り決めを構築します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def possible(g, b):
    return g - 1 <= b <= 2 * (g + 1)

def solve():
    al, ar = map(int, input().split())
    bl, br = map(int, input().split())

    if possible(al, br) or possible(ar, bl):
        print("YES")
    else:
        print("NO")

solve()
```ヘルパー関数は、有効な配置の数学的特徴付けを直接実装します。 

式:```
g - 1 <= b
```隣接する女の子の指を分離するのに十分な男の子の指があるかどうかを確認します。 

式:```
b <= 2 * (g + 1)
```連続 3 つを作成せずにボーイ フィンガーを配布できるかどうかをチェックします。 

誰がどちら側に立つかによってペアが入れ替わるため、このソリューションでは考えられる両方の向きをテストします。 2 番目の方向を忘れることは、最も一般的な実装ミスです。 

すべての計算は通常の整数内に問題なく収まります。 制約は小さいですが、値がはるかに大きい場合でも、このロジックは即座に実行されます。

import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    def possible(g, b):
        return g - 1 <= b <= 2 * (g + 1)

    bl, br = map(int, input().split())

    return "NO"
