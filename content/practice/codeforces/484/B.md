 ## 解決策
 ## 問題の理解

 一連の整数が与えられます`a1, a2, …, an`の最大値を計算するように求められました。`ai % aj`すべてのペアにわたって`(i, j)`どこ`ai ≥ aj`。 入力は整数の数で構成されます`n`そしてシーケンスそのもの。 出力は単一の整数、つまり配列の 1 つの要素をそれ自身より大きくない別の要素で除算して得られる最大の剰余です。 

最初の重要な観察は、すべての要素が次の値で囲まれた正の整数であるため、`10^6`そして`n`到達できる`2·10^5`、すべてのペアを直接チェックする素朴な試みは実行不可能です。 すべてのペアを反復するブルートフォース ソリューションは、おおよそのパフォーマンスを発揮します。`n^2`操作、最大`4·10^10`、これは 1 秒の制限をはるかに超えています。 したがって、すべてのペアの明示的な列挙を避ける戦略が必要です。 

配列に繰り返しの要素または単一の要素が含まれる場合、エッジ ケースが発生します。 たとえば、すべての要素が等しい場合、`ai % aj`は常にゼロなので、答えはゼロです。 配列に次のものが含まれている場合`1`、それは普遍的な約数として機能し、より小さな剰余を生成します。 要素が 1 つだけある配列は、当然のことながらゼロを返すはずです。`ai % ai = 0`。 

## アプローチ

 ブルートフォースアプローチは簡単です。 すべてのペアを反復処理する`(i, j)`そのような`ai ≥ aj`そして計算する`ai % aj`、最大値を追跡します。 これにより、許可されたすべてのペアが文字通り検査されるため、正確さが保証されます。 ただし、`n`まで`2·10^5`、最悪の場合の複雑さは O(n^2) であり、これは大きな入力では実行不可能です。 

最適なソリューションを見つけるための重要な洞察は、残りの`x % y`は常に未満です`y`。 これは、どんな場合でも、`y`、それを除数として使用して達成できる最大剰余は次のようになります。`max(x < 2y) x % y`。 配列をソートし、順番に約数を考慮することで、不必要なチェックを避けることができます。 より具体的には、最大剰余は、以下の最大の要素のいずれかによって達成されます。`2*y`または配列内の最大の要素を除く`y`。 ソートされた配列を逆方向にスキャンし、このプロパティを使用すると、最大剰余を O(n log n) 時間で効率的に計算できます。 

最適なアプローチが機能するのは、配列が一度ソートされると、潜在的な約数ごとに`y`、近くの剰余を生成する候補配当`y-1`の倍数の近くに位置しています`y`。 すべての要素をチェックする代わりに、次のようにジャンプすることができます。`y`増分し、各範囲内の最大の要素のみを考慮します。 これにより、操作の数が大幅に削減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`そして配列`a`。 配列には以下が含まれます`n`間の整数`1`そして`10^6`。 
2. 配列を昇順に並べ替えます。 並べ替えを行うと、候補となる約数の倍数より小さい最大の要素を効率的に見つけることができます。 
3.初期化`max_value`ゼロに。 これにより、見つかった最大の剰余が保存されます。 
4. すべての個別の値を反復処理します。`y`配列内の最大の要素を除きます。 それぞれについて`y`の倍数を考慮します。`y`から始まる`2*y`。 
5. 倍数ごとに`k*y`、最大の要素を見つけます`x`より小さい配列内`k*y`。 残り`x % y`が最大値の候補です。 アップデート`max_value`もし`x % y`現在より大きい`max_value`。 
6. すべての候補の約数を考慮した後、2 番目に大きい要素を法とする配列内の最大の要素もチェックします。これは、それより小さい要素よりも大きな剰余が生成される可能性があるためです。 
7. 印刷`max_value`。 

**機能する理由**: このアルゴリズムは、固定除数の場合、`y`、残り`x % y`最大化されるのは`x`の倍数のすぐ下にあります`y`。 配列をソートし、次の倍数でスキャンすることにより、`y`、各約数の可能な最大の剰余を見つけることが保証されています。 すべての関連性があるため、残りが見逃されることはありません`x`の倍数と相対的にみなされる`y`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))
a.sort()
max_a = a[-1]
max_value = 0
unique_vals = sorted(set(a))

for y in unique_vals:
    if y == max_a:
        continue
    k = 2
    while k * y <= max_a + y:
        # Find largest x < k*y using binary search
        left, right = 0, n - 1
        pos = -1
        while left <= right:
            mid = (left + right) // 2
            if a[mid] < k * y:
                pos = mid
                left = mid + 1
            else:
                right = mid - 1
        if pos != -1:
            max_value = max(max_value, a[pos] % y)
        k += 1

print(max_value)
```ソート手順により、バイナリ検索で、次の各倍数よりも小さい最大の要素が正しく検索されます。`y`。 正の剰余を生成できないため、最大の要素を除数としてスキップします。 の`while`ループは連続する倍数を考慮し、剰余候補が見逃されないようにします。 二分探索では境界条件が慎重に処理されるため、`pos`常に最大の有効な配当を指します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()
    max_a = a[-1]
    max_value = 0
    unique_vals = sorted(set(a))
    for y in unique_vals:
        if y == max_a:
            continue
        k = 2
        while k * y <= max_a + y:
            left, right = 0, n - 1
            pos = -1
            while left <= right:
                mid = (left + right) // 2
                if a[mid] < k * y:
                    pos = mid
                    left = mid + 1
                else:
                    right = mid - 1
            if pos != -1:
                max_value = max(max_value, a[pos] % y)
            k += 1
    return str(max_value)

# provided samples
assert run("3\n3 4 5\n") == "2", "sample 1"

# custom cases
assert run("1\n1\n") == "0", "single element"
assert run("5\n2 2 2 2 2\n") == "0", "all equal"
assert run("5\n1 2 3 4 5\n") == "2", "simple increasing"
assert run("6\n1 3 5 7 9 11\n") == "5", "odd numbers"
