 ## 解決策
 ## 問題の理解

 d 次元ユークリッド空間内のいくつかの点が与えられます。 各点は既知のベクトルであり、それらのそれぞれについて、未知の隠れベクトルまでの正確なユークリッド距離も与えられます。 タスクは、これらすべての距離制約と一致する R^d 内のベクトルを再構築することです。 

言い換えれば、R^d の点 x₁、x₂、…、xₙ と値 e₁、e₂、…、eₙ が与えられ、すべての i についてユークリッド距離 ‖p − xᵢ‖ が eᵢ に等しい未知の点 p が存在します。 すべての方程式を満たす有効な p を、浮動小数点誤差まで同時に出力する必要があります。 

各制約は、xᵢ を中心とし半径 eᵢ の球を定義し、隠れた点はこれらすべての球の交点にあります。 タスクは、高次元でそのような交点を 1 つ見つけることです。ここで、d と n は両方とも最大 500 です。 

制約が十分に大きいため、これを記号代数として扱ったり、候補解を列挙したりするアプローチは実行不可能です。 また、すべての値は実数値であり、高精度で与えられるため、離散構造に依存することはできません。 

微妙なエッジ ケースは、すべての球が 1 点で交差する場合と、システムが過剰決定されていても構築のために一貫性がある場合です。 もう 1 つの特殊なケースは、一部の距離がゼロである場合です。これは、隠れた点が既知のベクトルと正確に一致することを意味します。 たとえば、1 つの制約が x = (1,2)、e = 0 である場合、答えはその点と正確に一致する必要があり、射影ベースの手法における数値の不安定性は慎重に扱わないと失敗する可能性があります。 

## アプローチ

 主な問題点は、各制約が未知のベクトル p の座標において 2 次であることです。 d 個の変数で n 個の二次方程式を直接解くことは、このスケールでは標準的な代数消去法では実行できません。 

強引なアイデアは、p を未知のものとして扱い、一般的な非線形ソルバーを使用してシステムを反復的に解こうとすることです。 たとえば、二乗誤差関数を最小化できます。 

∑ᵢ (‖p − xᵢ‖² − eᵢ²)²

 勾配降下法を使用します。 これは概念的には正しいですが、数値的に脆弱であり、各反復のコストが O(nd) であり、制限されたステップ数内での収束が保証されないため、最悪の場合は遅すぎます。 d と n が最大 500 の場合、10⁴ の反復でもすでにコストが高くなります。 

重要な構造的観察は、2 つの距離方程式を減算すると、「p」² の二次項が除去されるということです。 拡張:

 ‖p − xᵢ‖² = ‖p‖² − 2 p·xᵢ + ‖xᵢ‖²

 制約 i と制約 1 の差を取ると、「p」² 項がキャンセルされ、p に線形方程式が残ります。 

2 p·(xᵢ − x₁) = ‖xᵢ‖² − ‖x₁‖² + e₁² − eᵢ²

 これにより、問題全体が d 変数の線形方程式系を解くことに変換されます。 d 個の未知数で最大でも n − 1 個の線形方程式が得られます。 d ≤ 500 であるため、ガウス消去法を使用してこのシステムを解くことができます。 

幾何学的には、球の各ペアは、すべての球の交点を含む超平面を定義します。 これらすべての超平面を交差させると、隠れた点が回復されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 直接非線形解決 | O(k・n・d) | O(d) | 遅すぎる/不安定 |
 | 線形化 + ガウス消去法 | O(d3 + n・d2) | O(d²) | 承認済み |

 ## アルゴリズムのチュートリアル

 最初の点を基準として選択し、すべての距離制約を未知のベクトル p の線形方程式に変換します。

1. 最初の既知のベクトル x1 とその距離 e1 を参照制約として固定します。 
2. 2 から n までの各 i について、i と 1 の両方の二乗距離方程式を展開します。これらを減算して、p の二次項を消去します。 これにより、aᵢ · p = bᵢ という形式の線形方程式が生成されます。ここで、aᵢ = xᵢ − x₁ であり、bᵢ は既知の定数から計算されます。 減算は、システムを線形にする重要なステップです。 
3. 最大 n − 1 個のそのような方程式を収集します。 各方程式は d 次元空間に存在するため、これを線形システム A p = b として解釈します。 
4. 拡張行列のガウス消去法を使用して、この系を解きます。 列ごとに処理を進め、無視できない係数を持つピボット行を選択し、それを所定の位置に交換し、他のすべての行から変数を削除します。 
5. 消去が完了したら、逆代入して p のすべての座標を取得します。 
6. 結果のベクトルを出力します。 

### なぜ効果があるのか

 2 つの有効な距離方程式を減算すると、近似を導入せずに共通項が削除されるため、各変換では解セットが保存されます。 元の球方程式をすべて満たす点は、導出されたすべての線形方程式を満たさなければなりません。 逆に、線形システムの任意の解は、元のシステムから導出されたペアごとの一貫性制約をすべて満たします。 システムは一貫した幾何学的構成から構築されているため、これらの超平面の交点は球の元の交点と一致し、これがまさに隠れベクトルです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    d, n = map(int, input().split())
    xs = []
    es = []
    
    for _ in range(n):
        *coords, e = map(float, input().split())
        xs.append(coords)
        es.append(e)

    x1 = xs[0]
    e1 = es[0]

    # We build augmented matrix: (n-1 equations) x d variables + RHS
    A = []
    b = []

    for i in range(1, n):
        row = [xs[i][j] - x1[j] for j in range(d)]
        rhs = 0.0

        xi = xs[i]
        for j in range(d):
            rhs += xi[j] * xi[j] - x1[j] * x1[j]
        rhs += e1 * e1 - es[i] * es[i]

        A.append(row)
        b.append(rhs)

    m = len(A)
    aug = [A[i] + [b[i]] for i in range(m)]

    r = 0
    c = 0
    nvar = d

    for c in range(nvar):
        pivot = r
        for i in range(r, m):
            if abs(aug[i][c]) > abs(aug[pivot][c]):
                pivot = i
        if abs(aug[pivot][c]) < 1e-12:
            continue
        aug[r], aug[pivot] = aug[pivot], aug[r]

        div = aug[r][c]
        for j in range(c, nvar + 1):
            aug[r][j] /= div

        for i in range(m):
            if i != r and abs(aug[i][c]) > 1e-12:
                factor = aug[i][c]
                for j in range(c, nvar + 1):
                    aug[i][j] -= factor * aug[r][j]

        r += 1
        if r == m:
            break

    p = [0.0] * d
    for i in range(d):
        p[i] = aug[i][d] if i < len(aug) else 0.0

    print(*p)

if __name__ == "__main__":
    solve()
```最初のフェーズでは、二乗距離方程式の減算から導出される線形システムを構築します。 行ベクトルには係数 (xᵢ − x₁) が格納され、右辺は二乗ノルムの定数差に距離調整を加えたものをエンコードします。 

ガウス消去は拡張行列に対して行われます。 ピボット選択では、係数がゼロに近い場合の数値の不安定性を回避するために部分ピボットを使用します。 行は正規化された後、他のすべての方程式から削除され、行階層形式が確実に縮小されます。 

最後の抽出ステップでは、解が一貫しており、システムが完全なランク d を持っていると仮定します。 より少ないピボットが見つかる縮退の場合、残りの座標はデフォルトでゼロになりますが、ランダム化された生成モデルでは、システムはほぼ確実にフルランクになります。 

## 実用的な例

 ### サンプル 1

 制約を 2D の 3 点からの距離として解釈します。 最初の点を基準として選択した後、残りの制約を線形方程式に変換します。 

| ステップ | 形成された方程式 | ピボット状態 |
 | --- | --- | --- |
 | 1 | 基準 x₁ = (0,0)、e₁ = 2.5 | 開始 |
 | 2 | (3,0) − (0,0) は p₁ | の方程式を与えます。 x 座標を中心にピボット |
 | 3 | (1.5,0.5) − (0,0) は 2 番目の方程式を与えます | システムを解決する |

 結果として得られるシステムは、p = (1.5, -2) を一意に決定します。 

これにより、制約が直交または整列していない場合でも、ペアごとの減算によって隠れた点が正しく再構築されることが確認されます。 

### サンプル 2

 ここで再び 2D の線形方程式に還元します。 

| ステップ | 形成された方程式 | ピボット状態 |
 | --- | --- | --- |
 | 1 | 基準 x₁ = (0,0)、e₁ = 2 | 開始 |
 | 2 | (4,-4) − (0,0) はライン制約を生成します | X 軸上の強力なピボット |

 これを解くと、対称点からの距離が等しいことを示す p = (1.414213..., 1.414213...) が得られます。 

これは、距離が大きく非対称な場合でも、線形化システムが正しい幾何学的交差を捕捉していることを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(d3 + n・d2) | ガウス消去法は d 変数で支配的です。 システムの構築コストは n·d |
 | スペース | O(n・d) | 線形システムの拡張行列を格納する |

 この制約により、d と n は最大 500 まで許可されます。これにより、最悪の場合でも d3 は約 1.25e8 の演算になりますが、特に一般的なランクが高く、実際には消去が早い段階で終了するため、枝刈りや浮動小数点演算を使用して最適化された Python ではまだ許容可能です。

 ## 特殊なケース

 距離の 1 つがゼロの場合、重大なエッジ ケースが発生します。 その状況では、隠れた点はその入力ベクトルと正確に一致する必要があります。 線形化後も、ゼロ距離方程式を減算すると、p がその点に等しいという制約が生成されるため、システムはこれを正しくエンコードします。 ただし、数値的には、ガウス消去法で異なるピボット順序が選択された場合、浮動小数点ノイズによって解がわずかにドリフトする可能性があるため、安定性を維持するには部分的なピボットが必要です。 

もう 1 つのケースは、すべての点が低次元のアフィン部分空間内にあり、線形システムがランク不足になる場合です。 たとえば、3D では、すべてのコンストレイントが平面上に折りたたまれる場合、削除によって生成されるピボットの数は d 個よりも少なくなります。 アルゴリズムは引き続き続行されますが、残りの座標はデフォルトでゼロまたは任意の値になります。 ランダム化された構築の仮定の下では、このケースは非常に起こりそうにありませんが、実装は時期尚早にフルランクを想定してはなりません。 

最後の微妙なケースは、2 つの制約によってほぼ同一の行が生成される、縮退に近いシステムです。 ピボットを行わないと、ゼロに近い係数で除算すると浮動小数点誤差が増幅されます。 行交換戦略により、使用可能な最大のピボットが常に選択され、数値の安定性が必要な 1e-5 許容誤差内に維持されます。
