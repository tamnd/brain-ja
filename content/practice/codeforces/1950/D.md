 ## 解決策
 ## 問題の理解

 最大 50,000 の独立したクエリが与えられます。 各クエリの数値`n`が提供されます。`1 ≤ n ≤ 100000`。 

通常の 10 進表現のすべての桁が次のいずれかである場合、その数値は 2 進 10 進数と呼ばれます。`0`または`1`。 例としては次のものが挙げられます。`1`、`10`、`11`、`101`、 そして`1001`。 

タスクは、次のことを判断することです。`n`1 つ以上の 2 進数の 10 進数の積として書き込むことができます。 繰り返しは許可されているので、次のようになります`121 = 11 × 11`有効です。 

制約から得られる最も重要な観察は次のとおりです。`n`決して超えない`100000`。 テスト ケースは多数ありますが、取り得る値の範囲は非常に狭いです。 各クエリを最初から解決する代わりに、次の値までのすべての数値を前処理できます。`100000`一度実行すれば、一定時間内にすべてのテスト ケースに回答できます。 

いくつかの特殊なケースは注目に値します。 

考慮する：```
1
1
```正しい答えは、`YES`。 番号`1`それ自体は 2 進数の 10 進数です。 数値をより小さい 2 進数に因数分解するだけのソリューションでは、誤って拒否される可能性があります。 

考慮する：```
1
100000
```正しい答えは、`YES`、すべての数字が次のいずれかであるため、`0`または`1`したがって、数値自体はすでに 1 つの要素から構成される有効な積です。 

考慮する：```
1
99
```正しい答えは、`NO`。 それでも`99 = 9 × 11`、要因`9`は 2 進数の 10 進数ではありません。 一部の約数が 2 進 10 進数であるかどうかだけをチェックし、残りの因数の有効性を再帰的に無視する不注意な実装では、間違った答えが生成されます。 

別の微妙なケースは次のとおりです。```
1
121
```答えは`YES`、 それでも`121`それ自体は 2 進数の 10 進数ではありません。 等しい`11 × 11`したがって、単に桁が次の数値だけでなく、2 進数の 10 進数の積も考慮する必要があります。`0`そして`1`。 

## アプローチ

 直接的な強引なアイデアは、すべての数値を再帰的に因数分解することです。 与えられた`n`を超えないすべての 2 進小数を列挙します。`n`、それぞれで割ってみて、商を再帰的に確認してください。 

これは正しいです。すべての有効な表現は、一度に 1 つの 2 進 10 進因数を繰り返し削除していると見なすことができるからです。 問題は繰り返しです。 最大 50,000 のテスト ケースで、多くの数値が繰り返しチェックされます。 再帰的探索では、異なる因数分解順序を通じて同じ状態を再訪することもできます。 

重要な観察は、非常に小さな制限から得られます。`n ≤ 100000`。 

二進小数は何までありますか`100000`? 桁数が制限されている 6 桁の数字`{0,1}`多くても`2^6 = 64`可能性。 先行ゼロ形式や超過数値などの無効な値を除外した後`100000`、残りは数十個だけです。 

これにより、問題は到達可能性の問題に変わります。 

から開始`1`、それは確かに表現可能です。 数字の場合`x`表現可能であれば、`x × b`すべての 2 進数の 10 進数でも表現可能です`b`を超えない限り、`100000`。 

表現可能なすべての数値を次のように構築できます。`100000`単純な動的プロセスを使用します。 前処理が完了すると、クエリに応答することは単に次のことを確認するだけです。`n`に達しました。 

これは基本的に、各数字が示すグラフです。`number × binary_decimal`。 しかないので、`100000`状態と 2 進数と 10 進数の乗数が数十個しかない場合でも、到達可能なセット全体を 1 回で計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 因数分解の深さの指数関数 | O(深さ) | 遅すぎる |
 | 最適 | O(MAX × B) の前処理、クエリごとに O(1) | O(MAX) | 承認済み |

 ここ`MAX = 100000`そして`B`は、以下の 2 進数の 10 進数です。`100000`、わずか数十件です。 

## アルゴリズムのチュートリアル

 1. 以下を超えないすべての 2 進 10 進数を生成します`100000`。 

各 10 進数の桁が次のいずれかの場合、その数値は 2 進 10 進数です。`0`または`1`。 制限が小さいため、次のすべての数値を単純にテストできます。`1`に`100000`。 
2. ブール配列を作成する`reachable`サイズの`100001`。`reachable[x]`それはそれを意味します`x`は 2 進数の 10 進数の積として表現できます。 
3. マーク`reachable[1] = True`。 

番号`1`自体は 2 進数の 10 進数なので、有効な開始状態です。 
4. 以下のすべての数値を反復処理します。`1`に`100000`。 

いつでも`reachable[x]`それは本当です、扱います`x`既知の有効な製品として。 
5. すべての 2 進数の 10 進数について`b`、計算する`x × b`。 

商品が以下の場合`100000`、到達可能であることをマークします。 

これは問題の定義を反映しています。 有効な積に別の 2 進数の 10 進数を乗算すると、別の有効な積が生成されます。 
6. 前処理後、各テスト ケースを印刷して回答します。`YES`もし`reachable[n]`それは真実であり、`NO`さもないと。 

### なぜ効果があるのか

 証明は乗算の下での閉包から直接続きます。 

当初は、`reachable[1]`それは本当です。 アルゴリズムが新しい数値をマークするたびに、すでに表現可能な数値に 2 進数の 10 進数を乗算してマークを付けます。 したがって、マークされたすべての数値は真に表現可能です。 

他の方向については、数値を考えてください。`n`は 2 進数の 10 進数の積として書くことができます。```
n = b1 × b2 × ... × bk
```から始まる`1`、前処理は次のように乗算できます。`b1`、その後、`b2`、 等々。 各中間生成物は到達可能としてマークされているため、最終的には`n`もマークされています。 

アルゴリズムによって生成されるセットは、まさに 2 進数の 10 進数の積として表現できる数値のセットです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXN = 100000

def is_binary_decimal(x):
    while x:
        d = x % 10
        if d != 0 and d != 1:
            return False
        x //= 10
    return True

binary_decimals = []
for x in range(1, MAXN + 1):
    if is_binary_decimal(x):
        binary_decimals.append(x)

reachable = [False] * (MAXN + 1)
reachable[1] = True

for x in range(1, MAXN + 1):
    if not reachable[x]:
        continue

    for b in binary_decimals:
        y = x * b
        if y > MAXN:
            break
        reachable[y] = True

t = int(input())
ans = []

for _ in range(t):
    n = int(input())
    ans.append("YES" if reachable[n] else "NO")

sys.stdout.write("\n".join(ans))
```最初の部分は、以下のすべての 2 進数 10 進数を生成します。`100000`。 制限が小さいため、各番号を 1 桁ずつ確認することは完全に手頃な価格です。 

の`reachable`配列には前処理結果が格納されます。 から始めます`1`そして、すべての 2 進数を繰り返し乗算します。 数値は昇順に処理されるため、到達可能なすべての値は、最終的にはその到達可能性をより大きな製品に伝播します。 

有用な実装の詳細は次のとおりです。`break`乗算ループ内。 2 進数の 10 進数のリストがソートされます。 一度`x * b`を超える`100000`、以降の乗数も制限を超えるため、続行すると無駄な作業になります。 

特別な処理は必要ありません`1`。 これは開始状態であり、2 進数の 10 進数であるため、前処理によって自然に処理されます。

# helper: run solution on input string, return output string
import sys
import io

MAXN = 100000

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    def is_binary_decimal(x):
        while x:
            d = x % 10
            if d != 0 and d != 1:
                return False
            x //= 10
        return True

    binary_decimals = [
        x for x in range(1, MAXN + 1)
        if is_binary_decimal(x)
    ]

    reachable = [False] * (MAXN + 1)
    reachable[1] = True

        if not reachable[x]:

        for b in binary_decimals:
            y = x * b
            if y > MAXN:
                break
            reachable[y] = True

    input = sys.stdin.readline
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        out.append("YES" if reachable[n] else "NO")

    return "\n".join(out)
