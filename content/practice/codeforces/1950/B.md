 ## 解決策
 ## 問題の理解

 より大きなチェッカーボード パターンを生成するように求められます。$2 \times 2$タイル。 各タイルはキャラクターで完全に埋められているか、`#`または完全に満たされています`.`。 グリッドのサイズは入力整数によって決まります。$n$、最終的なグリッドには寸法があります$2n \times 2n`. The top-left $2 \times 2$ タイルは常に`#`、タイルは水平方向と垂直方向に市松模様に交互に配置されます。 

たとえば、次のようなとき$n=2$、グリッドは$4 \times 4$、左上$2 \times 2$タイルは`#`。 その右隣は`.`、下の隣人は`.`、そして斜めの隣は`#`。 

制約は控えめです。$n$最大 20 であるため、グリッドの最大サイズは次のようになります。$40 \times 40$これは文字通りメモリ内にグリッド全体を構築して印刷できるほど小さいです。 ここでは時間の複雑さは制限要因ではありませんが、パターン化ルールを注意深く尊重する必要があります。 

単純な実装が失敗する可能性のあるエッジケースとしては、次のようなものがあります。$n=1$、グリッドがちょうどあるところ$2 \times 2$。 不注意なアプローチでは、個々のセルを交互に配置しようとする可能性があります。$2 \times 2$ブロックされ、間違った出力が生成されます。 もう 1 つの潜在的なエラーの原因は、タイルの位置がずれているため、ある行または列から移動するときに交互のパターンが維持されないことです。$2 \times 2$次にブロックします。 

## アプローチ

 ブルートフォースアプローチは、ファイル内の各行と各列を反復処理することです。$2n \times 2n$グリッド、特定のセルをセルに含めるべきかどうかを計算する`#`または`.`その行と列に基づいて。 各セルについて、行と列のインデックスを 2 で割って、どのセルがどのセルであるかを決定できます。$2 \times 2$それが属するタイルを決定し、それらのタイル インデックスのモジュロ 2 の合計を使用してキャラクターを決定します。 このアプローチは正しく、最大限の効果を得るには$n=20$それは結果として$1600$テスト ケースごとの操作は無視できます。 

重要な洞察は、これより複雑なものは必要ないということです。 この問題の構造により、単純な整数の除算とパリティ チェックによって各セルをそのタイルに直接マッピングできます。 再帰や動的プログラミングは必要ありません。 各タイルは 2 列にまたがるため、各行は 2 つの同一文字の繰り返しシーケンスで構成されます。 同様に、各タイルは 2 行にまたがるため、行の内容はタイルの 2 行目に 1 回繰り返されます。 認識する$2 \times 2$タイルの性質により、単純なネストされたループでグリッドを効率的に生成できます。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 各テスト ケースをループします。 
2. 各テスト ケースについて、次の内容を読んでください。`n`グリッド サイズを次のように計算します。`2n`。 
3. 反復処理`2n`インデックスを使用した行`i`。 これがどの水平タイル行であるかを整数除算によって決定します。`tile_row = i // 2`。 
4. 現在の行を空の文字列で初期化します。 反復処理`2n`インデックスを使用する列`j`。 これがどの垂直タイル列であるかを整数除算によって決定します。`tile_col = j // 2`。 
5. パリティを計算します。`tile_row + tile_col`。 偶数の場合は追加します`#`現在の行文字列へ。 奇数の場合は追加する`.`。 これにより、交互タイル パターンが実装されます。 
6. 行文字列を作成したら、すぐに印刷します。 テスト ケースのすべての行が印刷されるまで繰り返します。 
7. テスト ケース間に余分な空白行を印刷しないでください。 

効果がある理由: それぞれ$2 \times 2$タイルは次によって識別されます`(i//2, j//2)`。 タイルの行インデックスと列インデックスを合計し、パリティをチェックすることで、隣接するタイルの文字が交互になることが保証されます。 各タイル文字を 2 行 2 列繰り返すと、必要な文字列が生成されます。`2x2`ブロック。 不変条件は、グリッド内のすべての位置がそのタイル、つまり正しい文字に正しくマッピングされることです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    size = 2 * n
    for i in range(size):
        row = ''
        tile_row = i // 2
        for j in range(size):
            tile_col = j // 2
            if (tile_row + tile_col) % 2 == 0:
                row += '#'
            else:
                row += '.'
        print(row)
```まず、テスト ケースの数を読み取ります。 それぞれのケースについて、グリッドの合計サイズを次のように決定します。`2n`。 行ごとに`i`、`tile_row`どれを識別するか$2 \times 2$私たちがいる水平ブロックです。内側のループは、次を使用して行を 1 文字ずつ構築します。`(tile_row + tile_col) % 2`そうであるかどうかを判断する`#`または`.`。 これにより、ブロックが正しく交互に配置されるようになります。 行はグリッド全体をメモリに保存せずにすぐに印刷されますが、このサイズでは保存しても問題ありません。 整数の除算とパリティ チェックを使用することは、チェッカーボード パターンを効率的に構築するための一般的な手法です。
