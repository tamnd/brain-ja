 ## 解決策
 ## 問題の理解

 5 つの 3 次多項式が与えられます。 そのうち 3 つはアイスクリーム会社 3 社の長期にわたる「ステータス」を表し、2 つは外部要因 (UV インデックスと暑さインデックス) を表します。 特定の時間に`d`、5 つの多項式すべてを評価します。 

各企業の生体リズム状態は、独自の多項式値に、その時点の UV インデックスと暑さインデックスを加えたものになります。`d`。 3 つの結果の値が得られたら、それらの平均を計算します。 企業の「残存努力」は、企業価値からこの平均を引いたものとして定義されます。 この残差が負でない場合、企業は順調に経営しているとみなされ、そうでない場合は業績が良くないと考えられます。 

したがって、タスクは 5 つの 3 次多項式を 1 点で評価し、3 つの調整値を形成し、それらの平均を計算し、各値をその平均と比較することに要約されます。 

制約は構造的には小さいですが、係数の大きさは大きくなります。 時間`d`まで行くことができます`10^5`ただし、固定多項式のみを評価しているため、計算コストは​​多項式ごとに一定です。 これにより、記号操作や再計算の繰り返しによるアプローチが即座に排除されます。 すべては、ホーナー法または単純な算術を使用して、多項式ごとに O(1) で直接評価される必要があります。 

微妙な問題は整数の大きさです。 各多項式は最大約`10^9`、そのような値を複数合計します。 固定幅の整数を使用する言語で不注意に実装するとオーバーフローが発生する可能性がありますが、Python ではこれは当然安全です。 

入力構造に関してトリッキーなコーナーケースは存在しませんが、概念的なケースがあります。残差は 3 社すべての平均に依存するため、すべての企業にわたって一貫して UV と熱を含めることを忘れると、一貫性のない比較につながります。 

## アプローチ

 この問題を考える素朴な方法は、各多項式を関数として扱い、次の累乗を拡張することによって各値を直接計算することです。`d`。 それはコンピューティングを意味します`d^3`、`d^2`、 そして`d`、係数を掛けます。 これは依然として定数時間ですが、多項式ごとに複数の累乗ステップが含まれます。 

より構造化された方法は、ホーナーの法則を使用して、各 3 次多項式を書き換えることです。`ax^3 + bx^2 + cx + d`として`((ax + b)x + c)x + d`。 これにより、乗算の数が減り、数値の安定性と明瞭さが確保されます。 

5 つの値すべてが計算されると、`d`、調整された企業価値を構築します。 

それぞれの企業価値は`Fi(d) + G(d) + H(d)`。 

重要な観察は、3 つの調整された値の平均は、その合計を 3 で割った値であるということです。 この共有平均に対する 1 回の減算を超えて、企業ごとに何かを再計算する必要はありません。 これにより、解決策は簡単になります。3 つの値を計算し、それらの合計を計算し、平均を求めてから比較します。

 ## アルゴリズムのチュートリアル

 1. 3 つの会社多項式、UV 多項式、および熱多項式の係数を読み取ります。 これらは、同じ時点で評価する必要がある 5 つの 3 次関数を定義するため、それらを配列として保存します。 
2. 値を読み取る`d`。 これが唯一の評価点であるため、すべての計算はこの 1 つの整数をすべての多項式に代入することに依存します。 
3. 各三次多項式を次のように評価します。`d`。 それぞれについて、直接多項式評価を使用してその値を効率的に計算します。 これにより、次の 5 つの数値が生成されます。`v1`、`v2`、`v3`、`u`、 そして`h`。 
4. 各企業に外部要因を追加して、調整後の企業価値を構築します。`a1 = v1 + u + h`、`a2 = v2 + u + h`、`a3 = v3 + u + h`。 

それぞれに同じ外部コンポーネントを追加する理由は、紫外線と熱がすべての企業に平等に影響を与えるためです。 
5. 合計を計算します`S = a1 + a2 + a3`、次に次のように平均を計算します。`S / 3`。 
6. 各社ごと`i`、計算する`ai - average`。 マイナスの場合はうまくいっていないとマークし、それ以外の場合はうまくいっているとマークします。 これは残留努力の定義と直接一致します。 

### なぜ効果があるのか

 最終比較前のすべての変換は線形であり、すべての企業に均一に適用されます。 UV と熱の寄与は、3 つの調整値すべてで同一であるため、相対比較では相殺されます。 したがって、残差は、各企業の価値を 3 つの値すべての平均と比較することに相当します。 平均は同じセットから得られるため、分類は相対的な大きさのみに依存し、これは構築によって保存されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def eval_poly(coeffs, x):
    a3, a2, a1, a0 = coeffs
    return ((a3 * x + a2) * x + a1) * x + a0

def solve():
    f1 = list(map(int, input().split()))
    f2 = list(map(int, input().split()))
    f3 = list(map(int, input().split()))
    g = list(map(int, input().split()))
    h = list(map(int, input().split()))
    d = int(input())

    v1 = eval_poly(f1, d)
    v2 = eval_poly(f2, d)
    v3 = eval_poly(f3, d)
    uv = eval_poly(g, d)
    heat = eval_poly(h, d)

    add = uv + heat

    a1 = v1 + add
    a2 = v2 + add
    a3 = v3 + add

    total = a1 + a2 + a3
    avg = total // 3

    res1 = a1 - avg
    res2 = a2 - avg
    res3 = a3 - avg

    if res1 < 0:
        print("company 1 not doing well")
    else:
        print("company 1 doing well")

    if res2 < 0:
        print("company 2 not doing well")
    else:
        print("company 2 doing well")

    if res3 < 0:
        print("company 3 not doing well")
    else:
        print("company 3 doing well")

if __name__ == "__main__":
    solve()
```評価関数にはホーナーの方法が使用されており、不必要なべき乗を回避し、計算を最小限に抑えて安定した状態に保ちます。 

UV と熱の寄与はすべての企業で同一であるため、一度計算します。 共有された`add`変数を使用すると、冗長な再計算が回避されます。 

この問題では一貫した算術構造が保証されているため、整数の除算はここでは安全です。 使用して`//`これは、残差の比較が小数精度ではなく符号のみに依存するという事実と一致します。 厳密な実数除算が必要な場合は、float 除算が使用されますが、ここではすべてが積分のままです。

        return ((a3 * x + a2) * x + a1) * x + a0

    f1 = list(map(int, input().split()))
    f2 = list(map(int, input().split()))
    f3 = list(map(int, input().split()))

    return "\n".join(out)

 ## 特殊なケース

 エッジケースの 1 つは、UV と熱を加えた後に 3 つの企業の値がすべて同一になる場合です。 たとえば、すべてが`Fi(d)`が等しく、外部要因がゼロの場合、各調整値は平均と等しくなります。 すべての企業の残差はゼロになり、すべての企業が好調に分類されるはずです。 比較は次のとおりであるため、アルゴリズムはこれを正しく処理します。`>= 0`。 

もう 1 つのエッジ ケースは、値が負であるが不均一に分布している場合です。 調整された値が`-10, -5, -1`。 平均は`-16/3`、最小の負の値のみが適切に機能するはずです。 計算された平均に対する減算により、負の空間でも順序が維持されるため、分類の一貫性が保たれます。 

最後のエッジケースは、近くにある大規模な入力です。`10^9`。 Python の整数には制限がないため、オーバーフローは発生せず、Horner 評価により操作が安全かつ正確に保たれます。
