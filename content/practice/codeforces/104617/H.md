 ## 解決策
 ## 問題の理解

 直線上の異なる整数の位置に配置されたいくつかの円錐モールドが与えられます。 打者の垂直の流れが下に流れ始める開始位置を 1 つだけ選択することができます。 

工場には水平スプレッダー セグメントも含まれています。 各セグメントは x 軸上の間隔をカバーし、特定の高さに位置します。 垂直の流れがセグメントのいずれかの点に到達すると、流れは直ちにセグメント全体に広がり、単一の垂直線がアクティブな流れの水平区間全体に変わります。 その間隔内のすべてのアクティブな x 位置から、フローは独立して下向きに継続します。 

この拡散は繰り返すことができます。ある間隔がアクティブになると、その間隔と交差するその下にある他のセグメントがアクティブになり、アクティブな x 位置のセットがさらに拡張される可能性があります。 この伝播プロセスによって x 座標がカバーされるモールドはすべて、充填されたとみなされます。 

タスクは、最終的に充填された金型の数が最大になるように開始 x 位置を選択することです。 

この制約は、モールドとセグメントの数が両方とも最大 100,000 になる可能性があることを意味しているため、開始位置ごとの伝播をシミュレートするソリューションは遅すぎます。 単純なシミュレーションでは、各開始点の重複する間隔を繰り返し伝播する必要があり、最悪の場合は 2 次の動作が発生します。 

素朴な推論が微妙に失敗するケースは、複数のセグメントが間接的に重なる場合に現れます。 たとえば、セグメント A が B と重なり、B が C と重なる場合、A と C が直接重なり合わない場合でも、A 内の 1 つの開始によって B を介して C がアクティブ化される可能性があります。推移的マージを考慮せずに直接の包含のみをチェックするソリューションでは、到達可能性が過小評価されます。 

## アプローチ

 主な困難は、固定された開始 x 位置に対して伝播によって実際に何が生成されるかを理解することです。 プロセスを再解釈すると、ダイナミクスは間隔を置いて純粋に幾何学的なものになります。 

ブルートフォース手法では、考えられるすべての開始金型位置またはすべての整数 X 座標が試行されます。 開始ごとに、下向きの流れをシミュレートし、到達可能なすべてのセグメントを繰り返しマージします。 各シミュレーションはすべてのセグメントに接触する可能性があり、開始するたびにすべてのセグメントのスキャンが再度トリガーされる可能性があるため、最悪の場合は O(nm) になります。 これは 100,000 個の要素にとっては遅すぎます。 

重要な観察は、接続性を考慮すると、高さの順序付けによって最終的に到達可能な構造が意味のある形で変更されるわけではないということです。 セグメントがアクティブになると、間隔全体がアクティブになり、その間隔と交差するセグメントも最終的には同様にアクティブになります。 これは、到達可能性は、アクティブ化の正確な順序ではなく、間隔がオーバーラップを通じて接続されているかどうかのみに依存することを意味します。 

したがって、各スプレッダーを直線上の間隔として表示し、2 つの間隔が重なっている場合はそれらを接続することができます。 これにより、区間グラフ内に互いに素な連結成分が形成されます。 接続された各コンポーネントは単一のマージされたセグメントに折りたたまれます。これは、そのコンポーネント内のすべての間隔が単純に結合されたものです。 

これが確立されると、プロセスは簡単になります。 コンポーネント内の開始位置を選択すると、コンポーネント間隔全体がアクティブになります。 すべてのセグメントの外側の位置を選択すると、その単一点のみがアクティブになります。 

したがって、答えは、マージされた間隔内にある金型の最大数であり、さらに、正確に 1 つの金型を生成する位置を選択する可能性もあります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O(nm) | O(n + m) | 遅すぎる |
 | マージ間隔 + カウント | O((n + m) log m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 まず、すべてのスプレッダーを数直線上の区間として扱います。

1. すべてのスプレッダーを左のエンドポイントで並べ替えます。 これにより、マージの決定がローカルで行われる左から右のスイープ順序で間隔を処理することが保証されます。 
2. 間隔をスイープし、重なったり接触したりするものをマージします。 現在の間隔がアクティブなマージされた間隔の前または終了時に開始する場合、マージされた間隔の右側の境界を拡張します。 それ以外の場合は、現在のコンポーネントを閉じて、新しいコンポーネントを開始します。 これにより、区間オーバーラップ グラフのすべての連結コンポーネントが構築されます。 
3. すべての金型位置を並べ替えます。 これにより、二分探索または 2 つのポインターを使用して、任意の間隔内にある金型の数を効率的に数えることができます。 
4. マージされた各間隔について、その中にある金型位置の数を数えます。 このようなすべての間隔にわたって最大値を追跡します。 
5. インターバルにカバーされていない位置から開始する場合も考えてみましょう。 その場合、金型の位置と一致する開始位置を選択すれば、正確に 1 つの金型を充填できます。 したがって、答えは少なくとも 1 です。 

重要な決定点は、純粋にオーバーラップに基づいて間隔をマージすることです。これは、オーバーラップがあると、高さの順序に関係なくアクティブ化がそれらの間で伝播できることが保証されるためです。 

### なぜ効果があるのか

 各スプレッダー インターバル内の任意のポイントに到達すると、完全にアクティブになります。 一度アクティブになると、その範囲内のすべてのポイントのアクティブ化のソースとして動作します。 したがって、2 つの間隔は、それらの間に重複の連鎖が存在する場合に限り、同じ到達可能な構造に属します。 これはまさに、区間重複グラフにおける連結成分の定義です。 

接続されたコンポーネント内で、コンポーネントと交差する任意の場所から開始すると、そのコンポーネント内のすべての間隔が完全にアクティブ化され、その結果、それらのカバレッジが完全に結合されます。 すべてのコンポーネントの外側では、拡散は決して起こりません。 これは、すべての開始位置が単一のコンポーネント結合または単一点のいずれかにマップされることを意味し、金型の最大化はこれらのケースの評価に帰着します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    p = list(map(int, input().split()))
    p.sort()

    segs = []
    for _ in range(m):
        l, r, h = map(int, input().split())
        segs.append((l, r))

    if m == 0:
        print(1)
        return

    segs.sort()

    merged = []
    cur_l, cur_r = segs[0]

    for l, r in segs[1:]:
        if l <= cur_r:
            if r > cur_r:
                cur_r = r
        else:
            merged.append((cur_l, cur_r))
            cur_l, cur_r = l, r
    merged.append((cur_l, cur_r))

    def count_range(L, R):
        import bisect
        left = bisect.bisect_left(p, L)
        right = bisect.bisect_right(p, R)
        return right - left

    ans = 1
    for L, R in merged:
        ans = max(ans, count_range(L, R))

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、まず金型を並べ替えて、間隔内での素早いカウントを可能にします。 次に、スプ​​レッダー間隔を並べ替えてマージして、接続されたコンポーネントを構築します。 マージ ステップは、現在のアクティブな間隔を維持し、オーバーラップが検出されるたびにそれを延長する標準スイープです。 

カウント ステップでは、二分探索を使用して、マージされた各間隔に当てはまる金型位置の数を計算します。 最終的な答えはすべてのコンポーネントの中で最良であり、すべてのスプレッダーを回避する場合のベースラインは 1 です。 

微妙な点は、高さの値が決して使用されないことです。 これは、伝播の能力は、接続が存在した後の垂直方向の順序ではなく、オーバーラップ チェーンを通じて間隔に到達できるかどうかのみに依存するためです。

```間隔を並べ替えると、[1,2] と [3,5] が得られます。 これらは重複しないため、2 つの結合されたコンポーネントが得られます。 

| ステップ | アクティブな間隔 | カビをカバー |

```これは、切断された間隔が独立して動作し、最適なコンポーネントのみが選択されることを示しています。 

### サンプル 2

 入力:```
2 2
1 1000000
1 500000 1
500000 1000000 2
```2 つの間隔は 500000 で接触するため、単一のコンポーネント [1,1000000] にマージされます。 

| ステップ | アクティブな間隔 | カビをカバー |
 | --- | --- | --- |
 | 1 | [1,1000000] | {1,1000000} |

 両方の金型が結合された区間内にあるため、答えは 2 です。 

これは、推移的なオーバーラップが重要である理由を示しています。単一の接触点であっても、到達可能性全体がマージされます。

 ## 特殊なケース

 重要なエッジケースは、スプレッダーが存在しない場合です。 その状況では、すべての開始位置は独立して動作し、その直下の型を埋めることしかできません。 正解は 1 で、アルゴリズムは答えのベースライン初期化を通じてこれを処理します。 

もう 1 つのケースは、すべての間隔が互いに素である場合です。 マージ ステップでは複数のコンポーネントが生成され、最大の間隔のみが問題となります。 カウント ロジックは、それぞれを独立して正しく評価します。 

3 番目のケースは、接触するエンドポイントを通じて間隔がチェーンを形成する場合です。 単一の間隔が全範囲に及ばない場合でも、マージ プロセスはそれらを 1 つのコンポーネントに結合し、最後のカウント ステップではそれを単一の到達可能な領域として正しく処理します。
