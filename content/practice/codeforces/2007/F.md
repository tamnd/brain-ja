 ## 解決策
 ## 問題の理解

 すべての部分配列について、そのすべての値をセットに投入し、重複を削除します。 そのセットから開始して、平均が整数である 2 つの異なる要素を繰り返し選択し、その平均がまだ存在しない場合は追加します。 

問題は、集合が最終的に整数の完全な区間になれるかどうかです。 それができる場合、そのサブアレイは「ブリリアント」と呼ばれます。 素晴らしい部分配列を数えなければなりません。 

すべてのテスト ケースの合計の長さは最大でも$4 \cdot 10^5$。 すべてを明示的に検査するソリューション$O(n^2)$部分配列は無理です。 平$O(n^2 \log n)$前後が必要になります$10^{11}$最悪の場合の運用。 

難しいのは部分配列を数えることではありません。 難しいのは、セットが素晴らしいときを正確に特徴付けることです。 

セットを検討してください$\{3,6,10\}$。 中点挿入を繰り返すと、最終的には次からすべての整数が生成されます。$3$に$10$。 一方で、$\{1,5\}$生成されるすべての値は一致したままであるため、奇数のみを生成できます。$1 \pmod 2$。 障害は、すべての違いの奇数公約から生じます。 

2 番目の微妙なケースは重複です。 サブアレイ$[2,2,2]$セットに対応する$\{2\}$、すでに連続しています。 個別の値のセットではなく、配列の長さに直接基づいて推論するソリューションでは、そのような間隔を過大評価または過小評価します。 

## アプローチ

 ブルートフォースアプローチは簡単です。 すべての部分配列について、その個別の値を収集し、セットが優れているかどうかを決定する不変式を計算し、有効な値を数えます。 

問題は、$O(n^2)$サブアレイ。 たとえ 1 つのサブアレイをテストできたとしても、$O(1)$、合計作業量はまだ大きすぎます。 

重要な観察は、輝かしい集合の数理論的な特徴付けです。 

させて$$g = \gcd(|x_i-x_j|),$$セット内の個別の値のすべてのペアごとの差の gcd。 

すべての中間点演算では、この gcd の奇数部分が保存されます。 もし$g$奇数の素因数が含まれています$p$の場合、すべての要素は常に同じ剰余クラスのモジュロに留まります。$p$, そのため、連続した間隔を取得することは不可能です。 

逆に、もし$g$が 2 の累乗である場合、中点演算では、最小値と最大値の間のすべての整数が表示されるまで、間隔から 2 の因数を繰り返し削除できます。 

したがって、すべてのペアごとの差の gcd が 2 の累乗である場合にのみ、セットは優れています。 

gcd 全体を保存する代わりに、その奇数部分のみを保存します。 gcd に挿入する前に、すべての差を 2 の累乗で除算します。 この修正された gcd が以下に等しい場合、セットはまさに素晴らしいものになります。$1$。 

ここで問題は次のようになります。 

すべての部分配列について、すべてのペアごとの差の奇数部分の gcd が以下に等しいかどうかを判断します。$1$。 

この状態はモノトーンです。 範囲を拡張しても gcd は減少するだけです。 これにより二分探索が可能になります。 

セグメント ツリーは、区間ごとに、その区間内のすべての差分の奇数部分の gcd を維持できます。 次に、左のエンドポイントごとに、値が次になる最初の右のエンドポイントをバイナリ検索します。$1$。 より長い間隔も有効です。

 ## アルゴリズムのチュートリアル

 1. セグメントツリーを構築します。 

セグメントごとに 2 つの値を保存します。$$(\text{first value in the segment},\ \text{gcd of odd parts of all differences}).$$2. マージ操作を定義します。 

左側の子ストアが$(f_L,g_L)$そして適切な子ストア$(f_R,g_R)$。 

新しい gcd は次のように始まります$$\gcd(g_L,g_R).$$境界を越える違いも考慮する必要があります。 関連する違いは次のとおりです$$|f_L-f_R|.$$この差から 2 の因数をすべて削除し、それを答えに gcd します。 
3. 事前計算`same[i]`。`same[i]`で始まる等しい値の最大ブロックの最後の位置です。`i`。 

このブロック内のすべての部分配列は 1 要素セットに対応するため、自動的に優れたものになります。 
4. 左側のエンドポイントを修正する`i`。 

等しいブロック内で終わるすべての間隔を加算します。 彼らの数は$$same[i]-i+1.$$5. 等しいブロックを超えて広がる間隔については、セグメント ツリーをクエリします。 

クエリは、すべてのペアごとの差の奇数部分の gcd を返します。 

gcd が決して上がらない場合$1$、もはやインターバルは見事です。 
6. それ以外の場合は、クエリされた値が次の値になる最初の位置を二分探索します。$1$。 

範囲を拡張しても gcd は減少するだけであるため、単調性が成り立ちます。 
7. その位置またはその後で終わるすべての接尾語は素晴らしいです。 

彼らの数を答えに加えてください。 

### なぜ効果があるのか

 セグメント ツリーは、クエリされた範囲内のすべてのペアごとの差の奇数部分の gcd を正確に維持します。 すべてのペアごとの差は完全に 1 つの子の内部にあるか、境界を越えており、そのようなすべての差の gcd は子の gcd 値を 1 つの境界を越えた差と結合することによって取得されるため、マージ操作は正しいです。 

すべてのペアごとの差の gcd が 2 の累乗である場合、セットはまさに優れています。 すべての差から 2 の累乗を取り除いた後、その条件は、保存されている gcd と等価になります。$1$。 より多くの要素が追加された場合に gcd 値が減少するだけであるため、二分探索は有効です。 

## Python ソリューション```python
import sys
from math import gcd

input = sys.stdin.readline

class SegTree:
    def __init__(self, arr):
        n = len(arr)
        size = 1
        while size < n:
            size <<= 1
        self.size = size
        self.seg = [(-1, 0)] * (2 * size)

        for i, x in enumerate(arr):
            self.seg[size + i] = (x, 0)

        for i in range(size - 1, 0, -1):
            self.seg[i] = self.merge(self.seg[i << 1],
                                     self.seg[i << 1 | 1])

    @staticmethod
    def odd_part(x):
        while x and x % 2 == 0:
            x //= 2
        return x

    def merge(self, a, b):
        if a[0] == -1:
            return b
        if b[0] == -1:
            return a

        g = gcd(a[1], b[1])

        d = abs(a[0] - b[0])
        if d:
            g = gcd(g, self.odd_part(d))

        return (a[0], g)

    def query(self, l, r):
        left = (-1, 0)
        right = (-1, 0)

        l += self.size
        r += self.size

        while l < r:
            if l & 1:
                left = self.merge(left, self.seg[l])
                l += 1
            if r & 1:
                r -= 1
                right = self.merge(self.seg[r], right)

            l >>= 1
            r >>= 1

        return self.merge(left, right)

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        st = SegTree(a)

        same = [0] * n
        same[n - 1] = n - 1

        for i in range(n - 2, -1, -1):
            if a[i] == a[i + 1]:
                same[i] = same[i + 1]
            else:
                same[i] = i

        ans = 0

        for i in range(n):
            nxt = same[i]

            ans += nxt - i + 1

            if nxt == n - 1:
                continue

            if st.query(nxt, n).second if False else None:
                pass

            if st.query(nxt, n)[1] != 1:
                continue

            x = n

            for b in range(20, -1, -1):
                nx = x - (1 << b)

                if nx > nxt + 1 and st.query(nxt, nx)[1] == 1:
                    x = nx

            ans += n - (x - 1)

        print(ans)

if __name__ == "__main__":
    solve()
```セグメント ツリーには、単一の gcd ではなくペアが格納されます。 セグメントの最初の値は、マージ操作で境界を越える差異を考慮できるようにするために必要です。 

クエリはペアを返します。カウント ロジックでは 2 番目のコンポーネントのみが使用されます。 よくある間違いは、奇数部分ではなく通常の差を保存することです。 特性評価は、最終的な gcd が 2 の累乗であるかどうかのみに依存するため、gcd を取得する前に 2 の累乗をすべて削除する必要があります。 

二分検索は、2 のべき乗の降順検索として実装されます。 これにより、述語「gcd = 1」が単調であるため、中間点計算の繰り返しが回避され、機能します。

 ## 特殊なケース

 次のことを考慮してください。```
1
3
5 5 5
```すべての部分配列は集合に対応します`{5}`。 アルゴリズムはこれを次のように処理します。`same[]`配列。 等しいブロック内のすべての間隔はすぐにカウントされ、gcd クエリは必要ありません。 

考慮する：```
1
2
1 5
```唯一の複数値セットは、`{1,5}`。 違いは`4`、その奇数部分は`1`、セットは素晴らしいです。 セグメント ツリー クエリは gcd を返します`1`、間隔は正しくカウントされます。 

考慮する：```
1
2
1 7
```違いは`6`。 その奇妙な部分は、`3`。 セグメント ツリー クエリは gcd を返します`3`、 ない`1`、そのため、間隔は拒否されます。 このプロセスでは、次の範囲内のすべての整数を生成することはできません。`1`そして`7`生成されたすべての値はモジュロ一致のままであるため`3`。 

「奇数部の gcd が 1 に等しい」という正確さの基準が、まさにこれらのケースを区別するものです。
