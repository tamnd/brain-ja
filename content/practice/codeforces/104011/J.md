 ## 解決策
 ## 問題の理解

 私たちは固定長の一次元ストリートに取り組んでいます$L$。 1 つのエンドポイントは Julia のホームの位置です$0$、もう一方のエンドポイントは、ジェーンの自宅の位置です$L$。 時間 0 で、ジェーンは、与えられたリストから一様にランダムに選択された一定だが未知の速度で、自分の端からジュリアに向かって歩き始めます。$v_1, v_2, \dots, v_n$。 ジュリアはこの位置からスタート$0$、可能な速度のリスト全体を知っていますが、どれが選択されたかはわかりません。 

Julia はセグメントに沿ってどこにでも移動でき、いつでも方向を変え、最大速度まで任意の速度を使用できます。$V$。 彼女がジェーンを見るのは、二人が同じ地点で一致した場合だけです。 ジュリアはジェーンに会ったら、最高速度で家に戻らなければなりません$V$。 合計時間は集合時間と帰宅時間の合計となります。 

このタスクは、ジェーンの速度の一様なランダム性に対してジュリアが最適な戦略を選択すると仮定して、予想される最小の合計時間を計算することです。 

この制約により、どのような解も本質的に線形でなければならないことがわかります。$n$。 と$n$まで$10^5$、二次または偶数$n \log n$速度ごとのシミュレーションを推論するのは不必要であり、おそらくやりすぎです。 問題の核心は、各速度の単純な関数を評価することに帰着する必要があります。 

微妙な問題は、ジュリアがジェーンの速度を知らないため、プロセスが開始される前に戦略を選択する必要があり、実際の速度に依存できないことです。$v_i$。 これにより、インスタンスごとの適応的な最適化が排除され、ソリューションがすべての速度にわたって最適に動作するしきい値または構造ポリシーに向けて推進されます。 

よくある失敗例は、ジュリアが常にジェーンに向かって動くべきだと仮定することです。 たとえば、次の場合$L=1000$、$V=10$、 そして$v=50$ジェーンは、ジュリアが彼女に近づくよりもはるかに早くジュリアの家に到着するため、積極的に前進すると、待っている場合に比べて実際に結果が悪化する可能性があります。 

もう 1 つの失敗例は、往復の交通費を無視することです。 ジェーンの家の近くで会うと、会う時間は減りますが、往復の距離は長くなります。このトレードオフは不可欠です。 

## アプローチ

 自然な最初の試みは、可能な速度ごとに戦略をシミュレーションすることです。$v_i$、会議時間を計算し、平均します。 「ジュリアはいつも正しいスピードで走る」という単純な戦略を立てたとしても$V$」を使用すると、線形運動方程式の解として集合時間を計算できます。 

ジュリアが正しいスピードで動いたら$V$そしてジェーンは猛スピードで左に移動します$v$、その後、彼らの距離は急速に縮まります$V+v$。 彼らは時を同じくして出会う$t = \frac{L}{V+v}$、その瞬間、ジュリアはその位置にいます$x = Vt$。 合計時間は次のようになります。$t + \frac{x}{V} = \frac{2L}{V+v}$。 これにより、この戦略のきれいな閉じた形式が得られます。 

ただし、この戦略が常に最適であるとは限りません。 ジェーンがジュリアよりもはるかに速い場合は、ジェーンはすぐに到着するため、家で待っている方が良いでしょう。 待っていれば集合時間になる$L/v$また、会議はジュリアの家で行われるため、追加の移動コストはかかりません。 

重要な観察は、ジュリアが意味のある行動を 2 つだけ行っているということです。すぐにジェーンに向かうか、家で待つかのどちらかです。 移動前の中間待ち時間は、結果を改善することなく、これらの極端ないずれかに吸収される可能性があります。 これにより、ジェーンがジュリアよりも速いか遅いかのみに依存する、速度ごとの最適な決定が行われます。 

もし$v < V$、ジュリアはジェーンが近づくよりも早く会議時間を短縮できるため、すぐに移動する方が良いです。 もし$v \ge V$、ジュリアが移動して有利になるよりもジェーンが距離を縮めるのが速いため、待つのが最適です。 

したがって、問題はそれぞれの単純な式を評価することに帰着します。$v_i$そして平均化。

 | 速度ごとに最適な閉じた形状 |$O(n)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 ### 最適戦略の導出

 1. 一定速度を考慮する$v$。 2 つの極端な戦略を比較します。家で待つか、すぐに全速力でジェーンに向かって移動します。$V$。 
2. ジュリアが待っていると、ジェーンは時間が経つとジュリアに到着します$\frac{L}{v}$ですので、合計時間は$\frac{L}{v}$。 
3. ジュリアがすぐに動く場合は、相対速度を使用して会議の方程式を解きます。$V+v$、会議時間を与える$\frac{L}{V+v}$。 
4. 集合時間にジュリアは離れたところにいる$x = V \cdot \frac{L}{V+v}$、したがって、戻り時間は$\frac{x}{V} = \frac{L}{V+v}$。 
5. したがって、すぐに移動すると合計時間が得られます$\frac{2L}{V+v}$。 
6. これに対して 2 つの戦略のうち、より良い方を選択します。$v$:$$\min\left(\frac{L}{v}, \frac{2L}{V+v}\right)$$7. それらが等しいしきい値を決定します。$$\frac{L}{v} = \frac{2L}{V+v} \Rightarrow V = v$$8. 最適な決定ルールを結論付けます。 

もし$v \le V$、すぐに移動してください。 それ以外の場合はお待ちください。 
9. すべての最適コストを合計して期待値を計算します。$v_i$で割る$n$。 

### なぜ効果があるのか

 固定の場合$v$、どのような戦略も、最初の待機時間とそれに続く最大速度の動きに分解できます。 結果として得られるコストは、待機時間のアフィン関数となり、その傾きは次の符号のみに依存します。$V-v$。 これにより、単調な動作が作成されます。Julia の方が速い場合、待つのは苦痛だけです。 ジェーンの方が速いなら、動くのは苦痛だけです。 その結果、最適なポリシーは、待機ゼロか完全待機かの境界選択にまで崩れてしまうため、中間戦略によって期待値を改善することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, L, V = map(int, input().split())
    v = list(map(int, input().split()))

    ans = 0.0
    for x in v:
        if x <= V:
            ans += 2.0 * L / (V + x)
        else:
            ans += 1.0 * L / x

    print(ans / n)

if __name__ == "__main__":
    solve()
```コードは、派生した速度ごとの式を直接実装します。 最終的な答えは高精度で必要であり、式には除算が含まれるため、実装の主な詳細は浮動小数点演算を使用することです。 

条件`x <= V`両方の式が一致する場合、導出されたしきい値と正確に一致します (等しい場合を含む)。 これにより、エッジケースの分岐の不一致が回避されます。

 ## 特殊なケース

 平等の場合$v = V$が主な微妙な点です。 例えば：```
1 100 10
10
```「すぐに移動」の公式を適用すると、次のようになります。$\frac{2L}{V+v} = \frac{200}{20} = 10$。 待てば手に入る$\frac{L}{v} = 10$。 アルゴリズムはどちらかの動作を正しく割り当て、統一された公式により不連続性がなくなります。 

もう 1 つのエッジケースは次のような場合です$v \gg V$、 のような：```
1 1000 1
100
```ここでのジュリアは事実上遅すぎて移動の恩恵を受けられません。 アルゴリズムは待機、生成を選択します。$\frac{L}{v} = 10$。 集合場所がジュリアの家から遠く離れてしまい、返送コストが大幅に増加するため、移動を試みるとさらに大きな価値が生まれます。 

これらのケースは、しきい値ベースの分解が、より詳細な戦略を必要とせずに、状態空間を 2 つの領域に正しく分割することを確認します。
