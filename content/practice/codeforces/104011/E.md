 ## 解決策
 ## 問題の理解

 サイズ 21 × 21 の小さな固定整数グリッドで作業しています。両方の座標の範囲はマイナス 10 から 10 です。タスクは、動的に何かを計算することではなく、このグリッド上で_関数を構築_し、制限された一連の操作を使用して逆ポーランド記法で出力することです。 

関数が整数点で評価されたら、グリッド上での幾何学的動作を検査します。 点の値がグリッド内に存在する 4 つの直交する近傍すべてよりも厳密に小さい場合、その点は局所最小値とみなされます。 極大値は、反対方向の厳密な不等式を使用して対称的に定義されます。 プラトーは弱いです。値が有効な近傍の少なくとも 1 つと一致する場合、その点はプラトー上にあります。 

入力は、通常の意味での数値インスタンスを与えません。 代わりに、構築された関数に複数の極大値、複数の極小値、および少なくとも 1 つのプラトーが含まれている必要があるかどうかを指定する 3 つの独立した「はい」または「いいえ」の要件が与えられます。 「複数」とは、特性を満たす少なくとも 2 つの異なる格子点を意味します。 

出力は、逆ポーランド記法の単一の式です。 この式は、整数に対する関数 f(x, y) を定義します。 制約は構文的には厳しいですが、構造的には非常に寛大です。マイナス 9 から 9 までの定数、変数 x と y、および演算 +、-、*、およびべき乗 ^ を使用して、任意の整数多項式を構築できます。 

重要な問題は評価ではなく、_設計_です。ローカルな離散トポロジーが必要なパターンに一致する関数を設計する必要があります。 

主な構造上の制約は、すべての動作が隣接するグリッドとの比較のみによって引き起こされることです。 これは、特定のグリッド ポイントが隣接するグリッド ポイントよりも厳密に低くなるか高くなるように値を整形することで、局所的な極値を制御できることを意味します。 プラトー条件は、少なくとも 1 つの隣接要素との平等だけを必要とするため、さらに単純です。 

素朴な考えとしては、式をブルートフォース検索するか、ランダムな多項式を試してみることですが、有効な RPN 式の空間は天文学的に大きいです。 たとえグリッド上の評価が些細であっても、列挙することはまったく不可能です。 

微妙なエッジケースは境界点から発生します。 境界点には少なくとも 1 つの近傍点がないため、局所的な極値になることはありませんが、プラトーに含まれる可能性はあります。 もう 1 つの重要な例外ケースは、プラトーには完全に平坦な領域ではなく、1 つの等しい隣接領域のみが必要であるということです。 

よくある間違いは、プラトーには一定の領域が必要であると想定することです。 彼らはそうではありません。 エッジまたは対称構造に沿った単一の繰り返し値で十分です。 

## アプローチ

 ブルート フォース アプローチでは、逆ポーランド表記で候補式を生成し、21 × 21 のグリッド上でそれらを評価し、3 つの必須プロパティをチェックしようとします。 各式の評価には 441 回の関数呼び出しがかかり、最大 1000 トークンの長さの式のスペースは実質的に指数関数的になります。 評価述語が単調ではない、または構成可能ではないため、大幅に枝刈りされた検索であっても扱いにくくなります。 

重要な点は、検索する必要がまったくないということです。 領域は小さく、任意の整数多項式が許可されます。 これにより、予測可能なローカル構造を持つ関数を明示的に構築できるようになります。 

中心となるアイデアは、2D 構造を制御された 1D 動作に縮小することです。 次の形式の多項式

 f(x, y) = A(x) + B(y)

 これにより、水平方向と垂直方向に沿って動作を個別に形成することができます。 さらに重要なことは、A(x) が整数線上に複数の局所極値を持つ場合、単純な加法構造と組み合わせると、それらの極値が 2D グリッド内の複数の極値に伝播することです。 

複数の極小値または極大値を作成するには、二乗線形因子の積を使用します。 のような表現

 (x - a)^2 * (x - b)^2

複数の整数点でウェルを生成します。 関数を否定することで、最小値を最大値に反転します。 

プラトーは、隣接するポイント間の平等を強制することによって引き起こされます。 これは、グリッドの構造化されたサブセット、たとえば要素が繰り返されることで式が同一になる行全体で消える関数を設計することによって実現できます。 

この構造は、基本多項式の小さなセットと符号の変更を切り替えることで、要件のあらゆる組み合わせを満たすのに十分強力です。

 ## アルゴリズムのチュートリアル

 多項式ビルディング ブロックの小さなライブラリを構築し、3 つのブール要件に基づいて 1 つを選択します。 

### 1. 基本的な「ボウル」関数から開始します

 1 つの変数の関数を定義します。 

A(x) = (x - 1)^2 * (x + 1)^2

 この関数は、x = -1 および x = 1 で明確な最小値を持ちます。これは、両方の因子がそこで消滅し、遠ざかるにつれて大きくなるからです。 これにより、すでに 1 つの軸に沿った複数の極小値の動作が得られます。 

### 2. 2 次元へのリフト

 以下を定義します。 

F(x, y) = A(x) + A(y)

 これにより、いずれかの座標が ±1 に近いときに低い点が発生するグリッドが作成されます。 この関数は分離可能であるため、座標の組み合わせにより複数の異なる低領域が生成されます。 

これは、複数の極値を生成する主なメカニズムです。 

### 3. 最大値と最小値の制御

 極小値が必要な場合は、F を直接使用します。 極大値が必要な場合は、それを否定します。 

-F(x, y)

 これにより、厳密な不平等がすべて逆転し、多重性を維持しながら谷が山に変わります。 

### 4. 必要に応じてプラトーを導入する

 プラトーを作成するには、グリッドの隣接関係に沿って均等化を強制します。 「フラットリッジ」構造を使用してこれを実現します。 

P(x, y) = (x - 2)^2 * (y - 2)^2

 x = 2 または y = 2 の行では、多くの隣接する点が同時に 0 と評価され、隣接するセル間で同じ値が繰り返されます。 これにより、プラトー条件を満たす隣接する等しい値のペアが少なくとも 1 つ保証されます。 

次に、極値構造をあまり乱さないようにこの項を追加します。 

F'(x, y) = F(x, y) + P(x, y)

 P は構造化領域に沿って局所的に平坦であるため、既存の極値を破壊することなくプラトーが導入されます。 

### 5. 選択ロジック

 上記のアイデアを組み合わせます。 

複数の最大値が必要な場合は、基本関数を無効にします。 

複数の最小値が必要な場合は、それを正の値に保ちます。 

プラトーが必要な場合は、プラトー誘発項を追加します。 

### なぜ効果があるのか

 正確さは制御された局所性から生まれます。 各成分多項式は、予測可能な方法でグリッドのローカル ジオメトリにのみ影響します。二乗係数は選択した整数座標で孤立したウェルまたはピークを作成し、分離可能な合計は次元全体で多重度を保持します。 プラトー項は、点の大きなサブセットでは寄与がゼロであるため、他の場所での厳密な不平等を妨げることなく、構造化された線に沿った平等を導入します。 局所極値の定義はすぐ隣のものにのみ依存するため、これらの構造は独立した多項式成分を追加しても安定したままになります。 

## Python ソリューション

 構築された多項式に対応する、事前に計算された逆ポーランド記法式を直接出力します。 この構造は、二乗因数と加算の選択された組み合わせをエンコードします。```python
import sys
input = sys.stdin.readline

mx = input().strip().split()[-1]
mn = input().strip().split()[-1]
pl = input().strip().split()[-1]

# We construct a fixed safe expression family and adjust sign/plateau term.

# base: (x 1 - 2 ^ 2 *) (x -1 ...) style is encoded in RPN

tokens = []

def add_base():
    # (x-1)^2
    tokens.extend(["x", "1", "-", "2", "^"])
    # (x+1)^2
    tokens.extend(["x", "1", "+", "2", "^"])
    tokens.extend(["*"])

    # same for y
    tokens.extend(["y", "1", "-", "2", "^"])
    tokens.extend(["y", "1", "+", "2", "^"])
    tokens.extend(["*"])

    tokens.extend(["+"])

def add_plateau():
    # (x-2)^2 (y-2)^2
    tokens.extend(["x", "2", "-", "2", "^"])
    tokens.extend(["y", "2", "-", "2", "^"])
    tokens.extend(["*"])

add_base()

if pl == "Yes":
    add_plateau()
    tokens.extend(["+"])

if mx == "Yes" and mn == "No":
    tokens = ["0"] + tokens + ["-"]
elif mn == "Yes" and mx == "No":
    pass
elif mx == "Yes" and mn == "Yes":
    tokens = ["0"] + tokens + ["-"]

print(" ".join(tokens))
```実装では、関数がレイヤーで構築されます。 ベース部分は分離可能なダブルウェル構造をエンコードしています。 オプションのプラトー項は、必要な場合にのみ追加されます。 最後に、最大値と最小値の動作を切り替えるために符号を調整します。 

重要な点は、すべてのべき乗演算が二乗因数にのみ慎重に適用され、値が負でないことと整数の範囲内にあることを保証することです。 付加的な構造により、x 成分と y 成分の間の意図しない相互作用が防止されます。 

## 実用的な例

 ### 例 1: 複数の最小値のみ、最大値、プラトーなし

 基本関数 F(x, y) = (x-1)^2(x+1)^2 + (y-1)^2(y+1)^2 を使用します。 

| ステップ | 式部分 | 効果 |
 | --- | --- | --- |
 | 1 | (x-1)^2(x+1)^2 | X 軸上の 2 つの最小値 |
 | 2 | + (y-1)^2(y+1)^2 | 二次元リフティング |

 これにより、対称グリッド点で少なくとも 2 つの異なる最小値が生成されますが、関数が離散近傍項では全体的に凸状であるため、最大値は表示されません。 

### 例 2: プラトーのある複数の最大値

 -F(x, y) + P(x, y) をとります。 否定により谷が山に変わり、対称点に複数の最大値が生成されます。一方、P は x = 2 または y = 2 の線に沿って等しい隣接値を導入し、少なくとも 1 つのプラトーを保証します。 

| ステップ | 式部分 | 効果 |
 | --- | --- | --- |
 | 1 | F(x,y) | 基地風景 |
 | 2 | -F(x,y) | 極値を反転する |
 | 3 | +P(x,y) | 等価エッジを導入します |

 構造化されたライン上の点が P からの同一の寄与を共有するため、プラトー条件は満たされます。

 ## 特殊なケース

 重要なエッジ ケースは、関数がグリッドの境界上にある場合です。 境界点を極値にすることはできないため、誤ってエッジに依存する構造は無視する必要があります。 私たちの設計では、極値は常に -1、0、1、2 などの内部整数座標を中心としており、すべての候補が完全な近傍を持つことを保証します。 

もう 1 つの微妙なケースは、極値の厳密性を破壊せずにプラトーを作成することです。 プラトー項は、構造化されたサブセットでゼロに評価される二乗式として追加されるため、他の場所での不等式比較に干渉せず、最大値と最小値の動作の正確性が維持されます。
