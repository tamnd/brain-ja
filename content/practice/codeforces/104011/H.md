 ## 問題の理解

 私たちには番号が与えられています$n$、からのすべての整数を考慮します。$1$まで$n-1$。 この範囲から、公約数を共有しない数値のみを保持します。$n$1 を除きます。言い換えると、以下に関連する共素条件によって範囲をフィルタリングします。$n$。 

このフィルタリングされたリストを作成した後、標準の競技プログラミング規則を使用して、リストを昇順にソートし、その中央値を返すように求められます。リストの長さが奇数の場合は中央の要素を取得し、リストの長さが偶数の場合は、ステートメントの 1 ベースのインデックス付けルールで定義されている、中央の 2 つの位置のうち低い方を取得します。 

主な難点は、$n$と同じ大きさにすることができます$10^{18}$したがって、次の値までのすべての数値を明示的に構築したり反復したりすることはできません。$n$。 テストケースごとに 1 回繰り返しても、$n$それは不可能であるため、どのような解決策も共素集合の構造的特性に依存する必要があります。 

次の場合、微妙なエッジケースが発生します。$n$プライムです。 次に、からのすべての数字$1$に$n-1$と互いに素である$n$, したがって、答えは完全な接頭辞の中央値になります。 複合用$n$、特に 2 の累乗や小さな素数の積などの高度に合成された数では、共素の密度が大幅に変化するため、一様な分布を仮定するアプローチは失敗します。 

次の場合には、別のエッジケースが発生します。$n$は均等です。 数値の半分は自動的に互いに素ではなくなりますが、削除されたセットは次の素因数で割り切れるように構造化されています。$n$均一なスキップではないため、単純なパリティに基づく推論は誤解を招く可能性があります。

 ## アルゴリズムのチュートリアル

 1.因数分解$n$それぞれの異なる素因数に分けられます。 共素性は完全な多重度ではなく、これらの素数のみに依存するため、これが必要です。 
2. コンピューティング$\varphi(n)$、内の整数の数$[1, n-1]$と互いに素である$n$。 これにより、ターゲット リストの合計サイズが決まり、インデックスの中央値が決まります。 
3. 中央位置を決定する$m$、問題の 1 から始まるルールを使用して、ソートされた互いに素なリストの中央のインデックスとして定義されます。 
4. 関数を定義する$f(x)$それは整数が何個あるかを数えます$[1, x]$と互いに素である$n$。 これは、素因数に対する包含-排他を使用して計算されます。つまり、素数のサブセットで割り切れる数を減算します。 
5.二分探索オーバー$x \in [1, n-1]$次のような最小値を見つけます$f(x) \ge m$。 の単調性$f(x)$二分探索の正確性を保証します。 
6. 結果を返します$x$中央値要素として。 

### なぜ効果があるのか

 正確さは 2 つの構造特性に依存します。 まず、以下と互いに素な整数の集合$n$は、その素因数の複数を除外することによって正確に特徴付けられ、包含と除外が正確になります。 2番目に、プレフィックスカウント関数$f(x)$間隔を拡張しても有効な要素のみを追加できるため、単調非減少です。 したがって、二分探索では、累積カウントが中央値インデックスと交差する一意の位置が特定されます。これは、ソートされた順序で中央値要素に正確に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from math import isqrt

def factorize(n):
    primes = []
    d = 2
    while d * d <= n:
        if n % d == 0:
            primes.append(d)
            while n % d == 0:
                n //= d
        d += 1
    if n > 1:
        primes.append(n)
    return primes

def count_coprime(x, primes):
    k = len(primes)
    res = 0
    for mask in range(1 << k):
        mult = 1
        bits = 0
        for i in range(k):
            if mask & (1 << i):
                mult *= primes[i]
                bits += 1
        if mult > x:
            continue
        cnt = x // mult
        if bits % 2 == 1:
            res -= cnt
        else:
            res += cnt
    return x - res

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        primes = factorize(n)

        total = count_coprime(n - 1, primes)
        m = (total + 1) // 2

        lo, hi = 1, n - 1
        while lo < hi:
            mid = (lo + hi) // 2
            if count_coprime(mid, primes) >= m:
                hi = mid
            else:
                lo = mid + 1

        print(lo)

if __name__ == "__main__":
    solve()

有効な要素の合計数を計算します。$[1, n-1]$、次に中央値指数を導出します。 二分検索は範囲全体に適用され、収束するまでプレフィックス数のクエリを繰り返し実行します。 重要な点は、すべての算術演算が Python 整数内に収まらなければならないことです。$n$到達できる$10^{18}$。
