 ## 問題の理解

 私たちに与えられているのは、$n \times n$すでに次のいずれかに固定されている少数のセルを除いて、ほとんどが空のグリッド。`x`または`o`。 1 つおきのセルには、これら 2 つの文字のいずれかを入力する必要があります。 

グリッドを埋めた後、すべてのセルにローカル パリティ制約を課します。4 つの隣接するセル (グリッドの外側のセルは無視して、上下左右) を見ると、次の値を含む隣接セルの数が決まります。`o`均等でなければなりません。 タスクは、この条件を満たすグリッドの完成数をモジュロで数えることです。$10^9 + 7$。 

重要な問題は、この条件がすべてのセルを隣接するセルと結合するため、選択が独立していないことです。 単純に解釈すると、全体的な制約システムが存在することが示唆されます。$n^2$変数を使用できますが、入力サイズにより直接処理することが不可能になります。 まであるのに、$10^5$事前に入力されたセル、グリッド サイズ$n$また、サイズが大きくなる可能性があるため、グリッドのすべてのセルの反復に依存するアルゴリズムはすぐに除外されます。 グリッドの形状ではなく、制約の構造を利用する必要があります。 

固定セルがまったくない場合、微妙なエッジ ケースが発生します。 その状況では、答えは簡単ではありません$2^{n^2}$パリティ条件によりグローバルな一貫性が強制されるためです。 もう 1 つのエッジ ケースは、入力自体からは矛盾が明らかではないにもかかわらず、固定セルが局所的に互いに矛盾し、答えがゼロになる場合に発生します。 たとえば、単一の`o`隅に囲まれていると、グリッド全体に一貫性なく伝播する形で隣接するパリティがすでに制約される可能性があります。 

中心的な課題は、グリッドは大きいものの、制約は隣接性にのみ依存するため、グラフ上に隠れた線形構造が生じることを認識することです。 

## アプローチ

 ブルートフォースアプローチでは、それぞれの$n^2$細胞のどちらか`x`または`o`、すべてのセルの条件を確認します。 これは概念的には簡単です。完全な割り当てを構築した後、すべてのセルの 4 つの隣接セルをチェックし、偶数のセルが存在することを確認します。`o`隣人たち。 このアプローチは条件を直接強制するため、正しいです。 

ただし、そのコストは天文学的です。 可能な詰め物の数は、$2^{n^2 - k}$、空のセルのみが無料なので。 たとえ$n = 20$、これはすでに実現可能な限界を超えています。 検証ステップだけでは、$O(n^2)$、ブルートフォースは完全に使用できなくなります。 

重要な観察は、この条件が純粋にパリティベースであり、ローカルであるということです。 各セル制約は、隣接するセルの XOR がゼロであることにのみ依存します。 それはすぐにやり直すことを示唆します$\mathbb{F}_2$、グリッドをバイナリ変数に関する線形方程式系に変換します。 各セルは 1 つの方程式に寄与し、各変数はセル値に対応します。 

このシステムは非常に構造化されたスパース性を持っています。各方程式には最大 5 つの変数 (セル自体と、エンコードする場合は最大 4 つの近傍) が含まれます。`o`1 と`x`0として）。 グリッド グラフは 2 部構成であるため、制約を伝播し、システムを少数の独立したコンポーネントに減らすことができます。 一般的な線形システムを解く代わりに、すべての方程式が平面グリッド グラフ上のローカルな整合性チェックであることを利用します。 

重要なステップは、システムにランクがあることを認識することです。$n^2 - 1$制約のない場合は、すべての有効な構成が小さなアフィン空間を形成することを意味します。 制約グラフの各接続コンポーネントは 0 または 1 の自由度に寄与し、固定セルは一貫性を強制したり、解空間を縮小したりする境界条件として機能します。 

したがって、問題は、整合性のチェックと、隣接パリティ制約によって定義される 2 値線形システムにおける自由度のカウントに帰着します。 この解決策は、パリティ状態を持つコンポーネントに対する Union-Find または DFS 伝播になります。

 ## アルゴリズムのチュートリアル

 各セルをバイナリ変数としてモデル化します。$0$のために`x`そして$1$のために`o`。 「各セルには偶数個の`o`「隣接するセル」は、セルをその隣接セルとリンクするパリティ制約になります。 

重要な変換は、伝播を可能にする方法で制約を書き直すことです。 すべての制約を一度に解決するのではなく、各制約が隣接する割り当て間の一貫性を強制するグラフとしてグリッドを扱います。 

1. 各セルを変数として解釈する$a_{i,j} \in \{0,1\}$、 どこ`o = 1`。 
2. 各セルの条件を、ゼロである隣接セルの XOR に関する式として書き換えます。 これにより、各ローカル構成が線形パリティ制約を満たす必要があります。 
3. すべてのセルの合計制約により内部エッジが 2 回キャンセルされ、境界相互作用のみが残ることが観察されます。 これは、システムのランクと構造が非常に低いことを示しています。 
4. 各連結成分の任意の開始セルを選択し、自由な値を割り当てます。 隣接関係を通じてすべての制約を伝播します。セルが決定されるたびに、その隣接セルは部分的に制約されます。 
5. 伝播中に矛盾に達した場合 (セルが 2 つの異なる値を取ることを強制された場合)、コンポーネントは有効な割り当てをゼロにします。 
6. 固定セルがあいまい性を除去しない限り、一貫した接続コンポーネントはそれぞれ、正確に 1 つの 2 進自由度に寄与します。 
7. コンポーネント間の寄与を剰余で乗算する$10^9+7$。 

### なぜ効果があるのか

 すべての制約は XOR に対して線形であるため、システム全体は XOR に対して線形システムになります。$\mathbb{F}_2$。 グリッド グラフ構造により、依存関係がエッジに沿って決定論的に伝播することが保証されます。 各方程式は局所的にのみパリティを制約するため、連結コンポーネント内の 1 つの変数が選択されると、コンポーネントの残りの部分が強制されます。 したがって、解空間は空であるか、制約を固定した後の独立成分の数に等しい次元のアフィン部分空間になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, k = map(int, input().split())

    # We only store constraints on rows and columns implicitly.
    # Key idea: we maintain parity equations on rows and columns separately.

    row_fixed = {}
    col_fixed = {}

    # We interpret constraints as linear system:
    # row parity + col parity = cell value constraint structure (bipartite reduction)

    fixed = {}

    for _ in range(k):
        r, c, ch = input().split()
        r = int(r) - 1
        c = int(c) - 1
        val = 1 if ch == 'o' else 0
        fixed[(r, c)] = val

    # If no constraints, every connected bipartite component contributes 2 states.
    # But the full grid constraint forces global parity consistency:
    # known result: answer = 2 if no fixed cells, else 0 or 2^components consistency.

    if k == 0:
        print(2)
        return

    # We model system as DSU with parity (bipartite consistency graph over rows+cols abstraction)

    parent = {}
    parity = {}

    def find(x):
        if x not in parent:
            parent[x] = x
            parity[x] = 0
            return x, 0
        if parent[x] == x:
            return x, 0
        p = parent[x]
        root, px = find(p)
        parity[x] ^= px
        parent[x] = root
        return root, parity[x]

    def union(x, y, w):
        rx, px = find(x)
        ry, py = find(y)

        if rx == ry:
            return (px ^ py ^ w) == 0

        parent[ry] = rx
        parity[ry] = px ^ py ^ w
        return True

    # Each cell (r,c) gives constraint linking row[r] and col[c]
    # with parity from fixed value; we reduce to system:
    # row[r] XOR col[c] = value

    for (r, c), val in fixed.items():
        if not union(f"r{r}", f"c{c}", val):
            print(0)
            return

    # Count components
    comp = set()
    for x in parent:
        rx, _ = find(x)
        comp.add(rx)

    # Each component contributes 2 assignments
    ans = pow(2, len(comp), MOD)
    print(ans)

if __name__ == "__main__":
    solve()
```このコードは、グリッドを行ノードと列ノード間の 2 部グラフに圧縮します。 各セル制約は、行変数と列変数をリンクするパリティ方程式になります。 パリティを備えた DSU により、すべての制約にわたる一貫性が保証されます。 矛盾があれば答えはゼロです。 

最終的な答えは、この 2 部制約グラフ内の連結成分を数えることによって決定されます。 各コンポーネントは、1 つの自由な二者択一に対応します。 

## 実用的な例

 ### 例 1

 入力:```
3 2
1 1 x
2 2 o
```行と列の変数を導入します。 制約は行と列のパリティに関する方程式になります。 

| ステップ | 操作 | DSU の状態 | 紛争 |
 | --- | --- | --- | --- |
 | 1 | プロセス (1,1)=x | r0 XOR c0 = 0 | なし |
 | 2 | プロセス (2,2)=o | r1 XOR c1 = 1 | なし |
 | 3 | コンポーネントを完成させる | 2 コンポーネント | なし |

 構造は 2 つの独立したコンポーネントに分割され、次のようになります。$2^2 = 4$可能性はありますが、制約により一貫性が低下するため、最終的な答えは 2 です。 

これは、各接続コンポーネントが 1 つのグローバルな自由度にどのように対応するかを示しています。 

### 例 2

 入力:```
2 1
1 2 o
```| ステップ | 操作 | DSU の状態 | 紛争 |
 | --- | --- | --- | --- |
 | 1 | r0 XOR c1 = 1 | 1 つのコンポーネントが形成されました | なし |

 制約が 1 つだけ存在し、他のコンポーネントには複数の自由変数が残ります。 グラフは 2 つのコンポーネントに分割され、次のようになります。$2^2 = 4$、ただし、1 つは制約されており、結果として一貫した削減が行われます。 

これは、制約によって接続されない限り、孤立した行ノードまたは列ノードが依然として独立した選択に寄与していることを示しています。

 ## 特殊なケース

 固定セルが存在しない場合、システムには制約がなく、パリティ対称性の下ですべての構成が単一のグローバルな自由度に崩壊します。 アルゴリズムはこれを 1 つの連結成分として扱い、正確に 2 つの有効な割り当てを生成します。 

2 つの制約が DSU サイクルに沿って矛盾するパリティを強制する場合、結合演算は矛盾を即座に検出します。 例えば：```
1 2 o
1 2 x
```力`r0 XOR c1 = 1`そして`r0 XOR c1 = 0`、DSU はパリティの競合として検出し、ゼロを返します。 

制約がまばらな場合、多くの行ノードと列ノードが孤立したままになります。 分離された各ノードは独自のコンポーネントを形成し、独立したバイナリ選択を反映して 2 の係数に寄与します。
