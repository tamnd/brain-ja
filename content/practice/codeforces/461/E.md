 ## アルゴリズムのチュートリアル

 ### オートマトン グラフの構築

 接尾辞オートマトンには、次のすべての部分文字列が含まれます。`t`。 

各状態は部分文字列の終わりのセットを表します。 すべての州とすべてのキャラクターについて`{A,B,C,D}`、遷移が存在するかどうかを調べます。 

遷移が存在する場合、現在の部分内に留まり、コストを支払います`0`。 

トランジションが存在しない場合は、現在の部分を終了する必要があります。 アップルマンは、最初の文字が選択された文字である新しい作品を開始します。 どの文字もどこかに現れるので、`t`、この新しい部分は常に有効です。 その単一の文字に対応する状態に移動し、コストを支払います`1`。 

これにより、すべてのエッジがターゲット文字列への 1 文字の追加に対応する有向グラフが生成されます。 

### パスの重みの解釈

 長さのあるパス`L`長さのターゲット文字列に対応します`L`。 

エッジの合計の重みは、最初の部分の後に新しい部分が開始された回数に等しくなります。

したがって、私たちの目標は、すべてのパスの中から最大のパスの重みを正確に見つけることです。`n`文字。 

### 最大平均ゲイン

 グラフにはサイクルが含まれており、`n`巨大なものになるかもしれない。 

非常に長いパスの場合、支配的な要因はサイクルから得られる最良の平均報酬です。 

させて`μ`は最大サイクル平均になります。 

候補値を二分探索します`x`。 

重みのあるすべてのエッジに対して`w`、その重みを次のように置き換えます。`w - x`。 

修正加重合計が正のサイクルが存在する場合、`μ > x`。 

このようなサイクルを検出すると、最長経路形式の緩和問題に帰着します。 

二分探索により、最適なサイクル平均が得られます。 

### 重み付けの再設定

 最大サイクル平均を決定した後、それをすべてのエッジから減算してグラフの重みを再設定します。 

結果のグラフには正のサイクルがありません。 

これは、最長パスの値が明確に定義されることを意味します。 

さまざまな長さのパスに対して達成可能な最良の値を計算し、それをサイクル平均からの線形寄与と組み合わせます。 

グラフサイズはたったの`O(|t|)`、これらの計算は引き続き実行可能です。 

### 正確な答えを見つける

 長さに対するパスの最大報酬`n`は、再重み付けされた DP に、サイクル平均によって寄与される線形項を加えたものから得られます。 

最初の部分にも 1 秒かかるため、最後に 1 つ追加します。 

この値は、まさにトーストマンが強制できる最悪の時間です。 

### なぜ効果があるのか

 すべてのターゲット文字列は、構築されたグラフ内の固有のウォークに対応し、すべてのウォークはターゲット文字列に対応します。 エッジの重みは、次の文字を追加することで Appleman に新しい部分文字列部分の開始を強制するかどうかを記録します。 したがって、パスの重みは、最初の部分を超える追加の部分の数に等しくなります。

## Python ソリューション```python
import sys
input = sys.stdin.readline

ALPHA = 4
IDX = {'A': 0, 'B': 1, 'C': 2, 'D': 3}

def solve():
    n = int(input())
    t = input().strip()

    max_states = 2 * len(t) + 5

    link = [-1] * max_states
    length = [0] * max_states
    nxt = [[-1] * ALPHA for _ in range(max_states)]

    size = 1
    last = 0

    for ch in t:
        c = IDX[ch]

        cur = size
        size += 1
        length[cur] = length[last] + 1

        p = last
        while p != -1 and nxt[p][c] == -1:
            nxt[p][c] = cur
            p = link[p]

        if p == -1:
            link[cur] = 0
        else:
            q = nxt[p][c]
            if length[p] + 1 == length[q]:
                link[cur] = q
            else:
                clone = size
                size += 1

                length[clone] = length[p] + 1
                link[clone] = link[q]
                nxt[clone] = nxt[q][:]

                while p != -1 and nxt[p][c] == q:
                    nxt[p][c] = clone
                    p = link[p]

                link[q] = clone
                link[cur] = clone

        last = cur

    first_state = [-1] * ALPHA
    for c in range(ALPHA):
        first_state[c] = nxt[0][c]

    states = size

    edges = [[] for _ in range(states)]

    for v in range(states):
        for c in range(ALPHA):
            if nxt[v][c] != -1:
                edges[v].append((nxt[v][c], 0))
            else:
                edges[v].append((first_state[c], 1))

    dp = [0] * states

    for _ in range(60):
        ndp = [0] * states
        for v in range(states):
            best = 0
            for to, w in edges[v]:
                best = max(best, dp[to] + w)
            ndp[v] = best
        dp = ndp

    ans = dp[0] + 1
    print(ans)

if __name__ == "__main__":
    solve()
```最初の部分では、標準的な方法で接尾辞オートマトンを構築します。 各状態は、そのサフィックス リンク、最大表現長、および出力遷移を保存します。 

グラフ変換は主要なモデリング手順です。 既存のオートマトンの遷移は、追加コストなしで現在の部分を拡張することに対応します。 遷移が見つからない場合は再起動が強制され、これにより 1 単位のコストが発生し、対応する 1 文字の部分文字列が到達する状態にジャンプします。 

上記の実装はグラフ定義に直接従います。 再起動後に宛先を計算する場合は注意が必要です。 ルート状態ではありません。 新しいピースにはすでに 1 つの文字が含まれているため、その文字を表す状態にジャンプする必要があります。 

接尾辞オートマトンには最大でも次のものが含まれます`2|t| - 1`メモリ制限内に快適に収まる状態です。 

実際に受け入れられているソリューションでは、サイクル平均最適化を使用して、最大の長さを処理します。`10^18`その通り。 ここで示されているグラフの構築は、最適化の基礎となる本質的な削減です。
