 ## 問題の理解

 文字列が与えられています`s`そしてそれを2つの空ではないサブシーケンスに分割するように求められました`a`そして`b`のすべての文字が`s`まさにそのうちの 1 つに属します。 追加の要件は、`a`は、このパーティションの下に形成できる辞書編集上可能な最小の文字列でなければなりません。 制限はありません`b`～の有効な部分列であることを超えて`s`残りの文字で。 

入力文字列の長さは最大 100 まで、テスト ケースは最大 1000 個まで可能です。 これは十分に小さいため、文字列を反復処理し、テスト ケースごとに線形時間で単純な操作を実行することができます。 この問題は基本的に貪欲な選択を必要とします。どの文字をどの文字に入れるかを決定する必要があります。`a`となることによって`a`は最小限であり、残りの文字は`b`。 

注意すべきエッジケースには、次のようなすべての文字が同一である文字列が含まれます。`"aaaa"`。 この状況では、`a`最小化するには、正確に 1 文字にする必要があります。それ以外の場合、より多くの文字を使用しても同じ文字列が得られますが、そのままになります。`b`空の。 もう 1 つのエッジ ケースは、次のような、異なる文字を含む長さ 2 の文字列です。`"fc"`、ここで正しい文字を選択します`a`即座に分割を決定します。 

## アプローチ

 素朴なアプローチは、空ではない可能なパーティションをすべて試してみることです。`s`の中へ`a`そして`b`そしてどれが辞書編集的に最小のものかを計算します`a`。 各文字には 2 つの選択肢があります: に割り当てる`a`または`b`。 と`n`文字、これは与えます$2^n - 2$空の文字列を除く可能性があります。 この強引さは正しいが、たとえ彼らにとっても手に負えないものである`n = 100`、 以来$2^{100}$天文学的に大きいです。 

重要な観察は次のとおりです`a`辞書編集上の最小の文字列である必要があるだけです。 辞書編集上の最小性とは、次の中で最小の文字を選択する必要があることを意味します。`s`入る`a`初め。 最初の最小文字を選択した後、順序を維持しながら次に小さい文字を選択し続けることができます。`s`。 ただし、この問題では過度に複雑にする必要はありません。次の最小文字を選択するだけで十分です。`s`そしてそのすべてのインスタンスを`a`少なくとも 1 文字が得られるまで、残りの文字を`b`。 より単純で完全に正しい貪欲戦略は、** の辞書編集上最小の文字を取得することです。`s`として`a`**、他のすべての文字を形成させます`b`。 これにより、次のことが保証されます`a`最小限です。 

貪欲なアプローチが機能するのは、最初の文字が`a`辞書編集上の比較において最も重要です。 可能な限り小さい最初の文字を選択したら、残りの文字は`a`最小値に等しい文字のみを取得する場合、辞書編集上の最小値には影響しません。 他のすべてのキャラクターは自然に次の場所に移動します。`b`。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 テスト ケースごとに、文字列を読み取ります。`s`。 
2. 辞書編集上で最小の文字を見つける`min_char`で`s`。 
3. 2 つの空のリストを初期化します。`a`そして`b`。 
4. 各文字を反復処理します。`c`で`s`。 もし`c`等しい`min_char`そして`a`空です、追加します`c`に`a`。 それ以外の場合は追加します`c`に`b`。 
5. リストを変換する`a`そして`b`文字列に変換し、スペースで区切って出力します。 

なぜ機能するのか: の最初の文字`a`辞書編集上の最小性を決定します。 から最小の文字を取得すると、`s`そしてそれを入れます`a`、他の単一文字から形成された他の文字列がこれより小さくならないことを保証します。 残りを割り当てる`b`すべての文字が 1 つのサブシーケンスに属するという条件を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        s = input().strip()
        min_char = min(s)
        a = []
        b = []
        taken = False
        for c in s:
            if c == min_char and not taken:
                a.append(c)
                taken = True
            else:
                b.append(c)
        print("".join(a), "".join(b))

if __name__ == "__main__":
    solve()
```コードは、テスト ケースの数を読み取ることから始まります。 各文字列について、Python の関数を使用して最小の文字を決定します。`min`関数。 次に、文字列を反復処理して 2 つのサブシーケンスを構築します。 の`taken`フラグにより​​、最小文字のインスタンスが 1 つだけ取り込まれることが保証されます。`a`。 残りは追加されます`b`。 リストを文字列に結合して出力すると、正しい出力が生成されます。
