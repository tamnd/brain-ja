 ## 問題の理解

 長さのシーケンスを数えています$n$、各位置には次の間の整数が含まれます。$1$そして$k$。 分割点が存在する場合、シーケンスは無効であると宣言されます。$i$プレフィックスに含まれる最大値が$a_1 \dots a_i$接尾辞に含まれる最小値とまったく同じです$a_{i+1} \dots a_n$。 

同様に、いくつかのカットによって単一の値が分割される場合、シーケンスは不良になります。$v$境界として機能します。左側にあるものはすべてそれを超えることはありません$v$、右側にあるものはすべて下に行くことはありません$v$、 そして$v$カットの両側に現れます。 このような「完全な区切り文字」を避けるシーケンスがどれだけあるかを数えたいと思います。 

入力サイズによって、ソリューションの性質が完全に変わります。 長さ$n$は最大 400 であり、二次関数は除外されます。$k$または立方体$n$価値観に直接影響します。 値の範囲$k$まで上がります$10^8$したがって、実際の値を反復処理することは不可能です。 法は大きな素数であり、これは、範囲全体にわたって組み合わせによる事前計算ではなく、代数和に依存することを示唆しています。 

「ローカル」構造について推論するときに、微妙な落とし穴が現れます。 極端な値のみが重要であると考えがちですが、この条件は区切り文字として機能する任意の値によってトリガーされます。 もう 1 つのよくある間違いは、隣接する比較のみが重要であると想定することです。 実際には、プレフィックスとサフィックスの条件はグローバルです。 

これを明確にするために、小さな失敗例を示します。 

順番を考えてみる$[2, 1, 2]$。 2 番目の要素の後の分割では、プレフィックスの最大値は次のとおりです。$2$、接尾辞の最小値も$2$。 シーケンスは、単調ではなく、自明ではないパターンで繰り返される値が含まれている場合でも無効です。 これは、「非定数」が妥当性を保証するものではないことを示しています。 

## アプローチ

 ブルートフォースアプローチでは、すべてが列挙されます。$k^n$シーケンスを作成し、すべての分割をテストし、プレフィックスの最大値とサフィックスの最小値を再計算します。 プレフィックス前処理を使用する場合でも、各シーケンスには$O(n)$小切手、与える$O(n k^n)$、それはたとえ小さなものであっても実現不可能です$n$。 

より構造化された視点は、潜在的な「悪い出来事」を修正することで得られます。 値を選択するとします$v$そしてスプリットポジション$i$。 スプリットが苦手な場合$v$、プレフィックスは範囲内に収まる必要があります$[1, v]$、サフィックスは範囲内にある必要があります$[v, k]$、 そして$v$両側に表示する必要があります。 これが修正されると、左側と右側の部分が独立した制約付きシーケンスになります。 

この観察は、問題をカウントシーケンスに変換し、インデックス付けされた構造化イベントの結合を回避します。$(v, i)$。 イベントがさまざまな値やカット間で重なり合うため、すべてのペアを直接包含することはまだ複雑に見えます。 

重要な構造的単純化は、制約が次のような不等式にのみ依存することです。$v$、絶対的なアイデンティティではありません。 これにより、各シーケンスの数が固定になります$(v, i)$～のべき乗を使って表現できる$v$そして$k-v+1$、修正により次のようなケースが削除されます。$v$どちらの側にも不在です。 これを展開すると、すべては次の多項式の和​​になります。$v$範囲を超えて$1 \dots k$。 以来$n \le 400$、すべての指数は小さいままであり、これらの合計は次の形式の累乗和を評価することになります。$\sum v^t$そして$\sum (k-v)^t$これは、素数を法とする標準的な多項式合計手法を使用して計算できます。 

これにより、指数列挙による問題が軽減されます。$k$最大で次数を超える多項式時間代数へ$n$。

 ## アルゴリズムのチュートリアル

 1. 「悪いスプリット」をペアとして解釈します$(v, i)$ここで、左側のすべての要素は最大でも$v$、右側のすべての要素は少なくとも$v$、両側に少なくとも 1 つの次の出現が含まれます。$v$。 この再構成により、条件がしきい値に対する不等式に変換されます。 
2.固定の場合$v$そして$i$、有効な左側のセグメントをカウントします。 左側のセグメントは任意の長さのシーケンスです$i$値を超える$1 \dots v$決して使用しないものを除く$v$。 このカウントは$v^i - (v-1)^i$。 減算によりシーケンスが分離されます。$v$これらは「接頭辞の最大値と等しい」を満たすことができないため、決して表示されません。$v$」の要件。 
3. 同様に、有効な右セグメントをカウントします。 右側のセグメントは値を使用します$v \dots k$、少なくとも 1 つを含める必要があります$v$。 これにより、$(k-v+1)^{n-i} - (k-v)^{n-i}$。 
4. 2 つの式を乗算して、特定の値が含まれるシーケンスの数を取得します。$(v, i)$分割はダメです。 
5. これをすべて合計します$v$そして$i$。 これにより、次の多項式が生成されます。$v$そして$k-v$、度数の境界は次のとおりです$n$。 
6. すべてが次の形式の項の線形結合になるように式を拡張します。$\sum_{v=1}^k v^t (k-v)^s$。 
7. 二項展開を使用してこれらの合計を評価します。$(k-v)^s$、式を次の組み合わせに減らします。$\sum v^t$、ファウルハーバー スタイルの多項式和の剰余を使用して計算できます。$p$。 
8. 全空間から不良シーケンスの総数を減算します。$k^n$。 

### なぜ効果があるのか

 すべての無効なシーケンスには少なくとも 1 つの目撃ペアが含まれています$(v, i)$、そしてそのような各証人は、純粋に権力を通じて表現可能な独立した左右の制約を課します。 複数の証人が同じシーケンスを記述する可能性がありますが、積がすべてに拡張されると、代数拡張によりすべての重複が自動的に考慮されます。$v$そして$i$。 すべてのシーケンスが有効な監視設定ごとに 1 回だけ合計に寄与し、すべてのオーバーカウントが合計中に使用される多項式恒等式に吸収されるため、最終的な式は正確です。

def modpow(a, e):
    r = 1
    while e:
        if e & 1:
            r = r * a % MOD
        a = a * a % MOD
        e >>= 1
    return r

# we use Lagrange interpolation on prefix sums of powers up to n+2 points

def lagrange_sum(k, power_vals):
    # power_vals[i] = i^t for i=0..m where m=len(power_vals)-1

        pref[i] = (pref[i-1] + power_vals[i]) % MOD

    x = k
    xs = list(range(m + 1))

    res = 0
    for i in range(m + 1):
        num = 1
        den = 1
        for j in range(m + 1):

            den = den * (xs[i] - xs[j]) % MOD
        res = (res + y[i] * num % MOD * modpow(den, MOD - 2)) % MOD

    return res

 ## 特殊なケース

 次のような単一要素シーケンス$n=1$分割は決して認められないため、常に有効です。 このアルゴリズムは、すべての制約を空のプロダクトに減らし、唯一の制約を残します。$k$選択肢。 

いつ$k=1$、すべてのシーケンスは一定です。 どの分割でも、プレフィックスの最大値とサフィックスの最小値の等価性が即座に満たされるため、1 を超える長さのシーケンスは残りません。 引き算の構造$v^i - (v-1)^i$すべての高次項が消えるため、正しく折りたたまれます。 

小型用$n$、 のような$n=2$、可能な分割は次のとおりです。$i=1$、条件は 2 つの要素が等しいかどうかを確認することになります。 代数的分解は、値が異なるペアを数えることに帰着し、直感的な結果と一致します。
