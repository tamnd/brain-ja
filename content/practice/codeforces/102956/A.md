 ## 解決策
 ## 問題の理解

 2 つの整数を取る関数が与えられ、両方とも正確に表現されます。$n$ビットを生成し、別のビットを生成します$n$-ビット整数。 各出力ビットを生成するためのルールは完全にローカルです。$i$- 番目の出力ビットは、$i$2 つの入力の - 番目のビット。固定ルックアップ テーブルから選択されます。$c(i, x_i, y_i)$。 ビット位置間にキャリーはないため、各ビット位置は独立して動作します。 

この関数に加えて、整数の 2 つのマルチセットが与えられます。$A$そして$B$、範囲内にある各要素$[0, 2^n - 1]$。 タスクは、すべての順序付きペアを考慮することです$(a, b)$、関数を適用して生成します$f(a, b)$、考えられる各出力値が何回出現するかを数えます。 

制約は主に次のような要因によって引き起こされます。$n \le 18$、これは、値の世界が最大でも$2^{18} = 262144$。 マルチセット自体はこのドメイン上の周波数配列として与えられ、個々の周波数は最大で大きくなる可能性があります。$10^9$。 これにより、すべてのペアを明示的に反復するアプローチが除外されます。$(a, b)$、それが必要になるため、$O(2^{2n})$実行可能性をはるかに超えた操作です。 

関数の構造が重要な問題です。 変換規則に関しては各ビットは独立していますが、入力は$a$そして$b$すべてのビット位置で共有されるため、ビットごとの独立した問題への単純な因数分解が妨げられます。 

微妙なエッジケースは、関数がビット位置ごとに異なる動作をする場合に現れます。次に例を示します。 

もし$n = 2$、ルールはビット 0 が OR、ビット 1 が XOR であるため、各ビットが単純であっても結合分布は完全な数に依存します。 すべてのビットにわたって同じ数値が一貫して寄与することを考慮せずに、ビットを独立した値の分布として扱うアプローチでは、誤った組み合わせが過大評価されてしまいます。 

もう 1 つのエッジ ケースは、すべての質量が単一の値になるなど、1 つのマルチセットが極端に偏っている場合です。 その場合、問題は、他のマルチセットに対する固定変換の評価と、それらの間の対称的な仮定に依存する解決策に帰着します。$A$そして$B$失敗します。 

## アプローチ

 直接的な総当たりアプローチはすべてのペアに対して反復されます。$(a, b)$、計算します$f(a, b)$、頻度テーブルをインクリメントします。 関数はペアごとに明示的に定義されているため、これは正しいですが、反復処理が必要です。$2^n \cdot 2^n = 2^{2n}$ペア。 と$n = 18$、これはおおよそになります$7 \times 10^{10}$操作が大きすぎます。 

関数の構造はビットごとの分解を示唆しています。 各出力ビットは対応する入力ビットのみに依存するため、各ビットを独立して処理したいと考えるかもしれません。 ただし、ビット間の依存関係は、共有のグローバルな選択を通じて行われます。$a$そして$b$これにより、ビット位置ごとの独立した集計が防止されます。 

有益な観察は、ビット表現を 2 つの半分に分割することです。 させて$k = \lfloor n/2 \rfloor$。 すべての数値は、その下位の値からなるペアとして書くことができます。$k$ビットとハイ$n-k$ビット。 これにより、問題は 2 つの小さな独立した部分問題の組み合わせに変換されます。 各半分内の州の数は最大で$2^9 = 512$これにより、すべてのペアにわたる直接 2 次たたみ込みが可能になります。 

それぞれの半分が部分的な結果の分布に処理されると、2 つの半分は互いに素なビット範囲に寄与するため、高い寄与と低い寄与を組み合わせることで完全な答えが得られます。

 ## アルゴリズムのチュートリアル

 しましょう$k = n/2$、各数値を低い部分と高い部分に分けます。 

1. 周波数配列を分割する$A$そして$B$低い予測と高い予測に分けられます。 それぞれの半分について、集計は次のようにカウントされます。$A_{low}[x]$にいくつの数字を格納するか$A$下位ビットは以下に等しい$x$、上位ビットに関係なく、同様に$A_{high}$、$B_{low}$、 そして$B_{high}$。 これが機能するのは、半分以内では、そのセグメントに限定されたビット パターンのみを考慮するためです。 
2. 下位半分については、完全な寄与率テーブルを計算します。$F_{low}$。 すべてのペアについて$(a, b)$下位領域では、下位ビットのみに制限されたビットごとの関数をシミュレートします。 対応する周波数を乗算します$A_{low}[a] \cdot B_{low}[b]$そして、その結果を、生成された低部結果の周波数に加算します。 同じ手順を上位半分に対して繰り返して、$F_{high}$。 
3. 重要な点は、下位半分と上位半分はビット位置に関して独立しているため、下位の結果と上位の結果を連結することによって整数の結果が形成されるということです。 部分的な結果のペアごとに$r_{low}, r_{high}$、それらを組み合わせて、$r = r_{low} + 2^k \cdot r_{high}$、蓄積します$F[r] += F_{low}[r_{low}] \cdot F_{high}[r_{high}]$。 
4. 結果のサイズの周波数配列を出力します。$2^n$。 

正確さは、各数値がその低い部分と高い部分に一意に分解され、変換関数が半分のビットを混合しないという事実から得られます。 すべてのペア$(a, b)$によって一意に表されます$(a_{low}, a_{high}, b_{low}, b_{high})$、および寄与率は、2 つの半分の独立した処理を通じて考慮されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    raw = input().split()
    
    c = []
    for i in range(n):
        s = raw[i]
        c.append([int(x) for x in s])
    
    A = list(map(int, input().split()))
    B = list(map(int, input().split()))
    
    N = 1 << n
    k = n // 2
    low_mask = (1 << k) - 1
    
    A_low = [0] * (1 << k)
    A_high = [0] * (1 << (n - k))
    B_low = [0] * (1 << k)
    B_high = [0] * (1 << (n - k))
    
    for i, v in enumerate(A):
        if v == 0:
            continue
        A_low[i & low_mask] += v
        A_high[i >> k] += v
    
    for i, v in enumerate(B):
        if v == 0:
            continue
        B_low[i & low_mask] += v
        B_high[i >> k] += v
    
    def compute_half(Ah, Bh, bits):
        size = 1 << bits
        F = [0] * size
        for a in range(size):
            if Ah[a] == 0:
                continue
            for b in range(size):
                if Bh[b] == 0:
                    continue
                r = 0
                for i in range(bits):
                    ai = (a >> i) & 1
                    bi = (b >> i) & 1
                    ri = c[i][ai * 2 + bi]
                    r |= (ri << i)
                F[r] += Ah[a] * Bh[b]
        return F
    
    F_low = compute_half(A_low, B_low, k)
    F_high = compute_half(A_high, B_high, n - k)
    
    res = [0] * (1 << n)
    for r1 in range(1 << k):
        if F_low[r1] == 0:
            continue
        for r2 in range(1 << (n - k)):
            if F_high[r2] == 0:
                continue
            res[r1 | (r2 << k)] += F_low[r1] * F_high[r2]
    
    print(*res)

if __name__ == "__main__":
    solve()
```コードはまず、ビットごとの遷移テーブルと周波数配列を解析します。 次に、各マルチセットを低ビットと高ビットの投影に圧縮します。 機能`compute_half`半分の内側で完全な 2 次たたみ込みを実行し、ビットごとのルールを明示的にシミュレートします。 最後に、出力を独立したビット ブロックの連結として扱うことにより、2 つの半分が結合されます。 

実装の微妙な詳細は、内部の結果ビットマスクの構築です。`compute_half`。 各ビットは独立して計算され、シフトを使用して再結合されるため、変換のビットごとの構造が維持されます。

 ## 特殊なケース

 すべての要素が$A$単一の値に集中している場合、アルゴリズムは次の分布を計算することに帰着します。$f(a, b)$全体$b$。 低位および高位の射影が単一のアクティブ状態に正しく崩壊し、二次畳み込みが適切な周波数で単純に乗算されるため、半分割は引き続き機能します。 

いつ$c(i, x, y)$ビット位置が一定である場合、出力内のそのビットは入力から独立します。 その場合、`compute_half`均一なビット寄与が生成され、定数ビットは他の位置と相互作用することなく結果マスクに直接エンコードされるため、結合ステップでは半分全体の独立性が維持されます。 

いつ$n$が奇数の場合、下位半分と上位半分の分割は 1 ビット異なりますが、両方の半分は対称的に処理されるため、畳み込みは正確にシフトして正しく再結合されます。$2^k$。
