 ## 解決策
 ## 問題の理解

 まず、参加者の列から始めます。各参加者は初期強度値を持っています。 このプロセスは、一連の隣接する決闘を通じて展開されます。 すべての決闘では、隣接する 2 人のプレイヤーが選ばれ、弱い方が削除され、勝者の強さは 1 増加します。 削除後は行が閉じるため、隣接関係は常に維持されます。 まさにその後$n-1$このような除外により、残るプレイヤーは 1 人だけになります。 

不確実性はメカニズムにあるのではなく、スケジュールとタイブレークにある。 各ステップでどの隣接するペアが選択されるかは知らされず、2 人のプレイヤーが同じ強さの場合、どちらが勝つこともあります。 勝利するたびに強さが増すため、初期の結果がその後の行動を増幅させる可能性があり、決闘の順序が異なると最終的な生存者も異なる可能性があります。 

タスクは、有効な選択順序の下で、どの初期インデックスが最終的に生き残る可能性があるかを判断することです。 

制約は極端です: まで$10^6$までの強みを持つ選手$10^9$。 これにより、一致を明示的に処理するシミュレーションが即座に除外されます。 ステップごとに繰り返される線形スキャンでも、すでに 2 次になります。 唯一の実行可能な解決策は、トーナメント全体を線形時間で計算可能ないくつかのグローバル集計に縮小するものです。 

微妙な難点は、このプロセスが標準的なノックアウトのような固定バイナリ ツリーではないことです。 隣接制約は、排除がローカルに伝播し、勝者が位置を移動することを意味します。そのため、原則として、どのプレイヤーもマージのチェーンを通じて間接的に他の多くのプレイヤーと対話できます。 

素朴な間違いは、極大値のみが重要であると想定することです。 たとえば、配列では$[1, 100, 2]$、インデックス 2 が最初は世界的に最も強いため、勝たなければならないと考える人もいるかもしれません。 ただし、繰り返しの強制ペアリングと勝利による成長により、エリミネーションの順序によっては他の構造が優勢になる可能性があります。 

もう 1 つのよくある誤った仮定は、初期強度のみが実現可能性を決定するというものです。 実際には、弱いプレイヤーは、強い敵に出会う前に、さらに弱い隣のプレイヤーに繰り返し勝つことで強さを得ることができます。 

## アプローチ

 直接シミュレーションでは、プロセスを段階的にモデル化しようとします。 各操作で、現在の配列を維持し、隣接するペアを選択し、勝者を解決し、その強度を増加させ、敗者を削除します。 これにはすでに費用がかかります$O(n)$ステップごとに操作があり、$n-1$につながるステップ$O(n^2)$。 と$n = 10^6$、これはまったく実現不可能です。 

本当の難しさは、プレイヤーの「力」が固定されていないことです。 プレイヤーが最後の生存者になるために進むたびに、勝利する決闘ごとに +1 が蓄積されます。 これは、プレイヤーの有効な強さが、エリミネーションによってアレイ内をどれだけ移動したかによって決まることを意味します。 

プレーヤーがポジションにいる場合$j$最終的には位置に隣接する$i$、正確に勝たなければなりません$|i - j|$途中で決闘。 勝つごとに+1されるので、到達したときの強さは$i$は次のようになります:$$a_j + |i - j|$$これにより、問題はローカルな相互作用からグローバルな「線形報酬を伴う到達可能性」構造に変換されます。 

この式を再解釈します。 

固定位置の場合$i$、左側のプレイヤーは潜在的な値に貢献します。$$a_j + (i - j) = (a_j - j) + i$$右側のプレイヤーは次のことに貢献します。$$a_k + (k - i) = (a_k + k) - i$$ということで、それぞれのポジションごとに$i$、左から入ってくる可能性のある最強の脅威は、の最大値のみに依存します。$a_j - j$、右から、 の最大値のみに依存します。$a_k + k$。 

これにより、問題全体が 2 つのプレフィックス/サフィックス変換の計算に集約されます。 

ポジション$i$どちらかの側から到着するより強力な候補者によって厳密に支配されていない場合にのみ、最終的に生き残ることができます。 この条件は、変換された両方の座標系で同時に最適であるかどうかを確認することになります。

 ## アルゴリズムのチュートリアル

 1. 配列を計算する$L[i]$の最大値を格納する$a[j] - j$全体$j \le i$。 これにより、その位置に到達できる可能性のある最も強力な競合他社を捕捉します$i$移動でゲインを積み上げた後、左から。 
2. 配列を計算する$R[i]$の最大値を格納する$a[j] + j$全体$j \ge i$。 これは、右からやってくる最強の競争相手を捉えています。 
3. ポジションごとに$i$、2 つの潜在的な外部脅威を計算します。 

最強の左に到着$i$は$i + L[i]$、そして最強の権利の到着は$R[i] - i$。 
4. 以下を実行して、各位置で達成可能な全体的な最大の「影響力」を決定します。$$\max(i + L[i],\; R[i] - i)$$5. ポジション$i$自身の変換された値がその時点で達成可能な最良の構造と一致する場合、最終的な勝者として有効です。 具体的には、この支配的なランドスケープで最適性が達成されているかどうかを確認します。これは、両方向で競合するすべての変換値よりも厳密には悪くないことを意味します。 
6. この条件を満たすすべてのインデックスを収集し、昇順に出力します。 

重要なアイデアは、トーナメントのダイナミクスを 2 つの座標系 (1 つは左にシフトし、もう 1 つは右にシフト) で幾何学的な支配問題に線形化できるということです。 

### なぜ効果があるのか

 すべての除去は勝者に正確に 1 単位の強さを与え、その単位はアレイに沿った 1 ステップの移動に正確に対応します。 これにより、すべての候補が位置によって決定される傾きを持つ線に変わります。 インデックスに影響を与える最良の競合相手は、変換された座標の接頭辞と接尾辞の極値によって完全に決定されます。 一連の一致はこれらの蓄積の順序を並べ替えるだけで、全体の寄与構造は変更できないため、これら 2 つのシステムの優位性が生存可能性を完全に特徴づけます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    # 1-indexed transformations via arrays
    left_best = [-10**30] * n
    right_best = [-10**30] * n

    # compute max(a[j] - j)
    cur = -10**30
    for i in range(n):
        cur = max(cur, a[i] - i)
        left_best[i] = cur

    # compute max(a[j] + j)
    cur = -10**30
    for i in range(n - 1, -1, -1):
        cur = max(cur, a[i] + i)
        right_best[i] = cur

    res = []
    for i in range(n):
        left_val = i + left_best[i]
        right_val = right_best[i] - i

        # i is valid if it is not strictly dominated by both sides
        if a[i] >= max(left_val, right_val):
            res.append(i + 1)

    print(len(res))
    print(*res)

if __name__ == "__main__":
    solve()
```この実装では、左から右へのスキャンと右から左へのスキャンの 2 つの線形スキャンが構築されます。 左側のスキャンでは、次の最良の値が維持されます。$a[j] - j$、右方向に移動中に候補者が蓄積できる強さをエンコードします。 右のスキャンでは、左方向の移動に対して対称的な計算が行われます。 

最後の条件では、各インデックス自体の強さを、両方向からの最強の仮説到着値と比較します。 両方の比較で生き残ったインデックスは、一連の決闘を通じて最後に残った参加者になるように調整できるインデックスです。 

実装の微妙な詳細は、すべての計算を 64 ビット範囲で実行する必要があることです。$a[i]$大きくてもオフセットは最大$10^6$中間式に蓄積します。

 ## 特殊なケース

 単一要素の配列は、決闘が発生せず、唯一の参加者が自動的に勝者となるため、自明です。 

すべてが等しい配列は、すべての決闘が任意に解決される可能性があり、スケジュールに応じて任意のインデックスが勝利を蓄積し、支配的になる可能性があるため、より微妙です。 

厳密に単調な配列では、左右の蓄積間の非対称性が明らかになります。 増加シーケンスでは、右端の要素が他のすべてを吸収することで最も有利な勝ちのセットを蓄積できますが、減少シーケンスでは、左端の要素が支配的になります。 

これらのケースは、変換された優勢解釈と一致します。それぞれの場合、接頭辞または接尾辞の最大値が、内部インデックス間の複雑な相互作用を必要とせずに、生存可能性を完全に決定します。
