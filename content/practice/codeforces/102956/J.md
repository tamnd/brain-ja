 ## 解決策
 ## 問題の理解

 私たちは無向ケーブルで接続されたコンピューターのネットワークを与えられており、2 つの同時ルールに従って「アクティブ化」するコンピューターのサブセットを選択する必要があります。 まず、選択された 2 つのコンピューターがケーブルで直接接続されていないため、選択されたセットはグラフの観点から独立している必要があります。 第 2 に、すべてのケーブルが少なくとも 1 つの選択されたエンドポイントに接触する必要があるため、すべてのエッジが選択された頂点で覆われている必要があります。 両方の制約を満たすすべてのセットの中で、選択されたコンピューターの数が可能な限り最小のセットが必要であり、そのサイズを出力する必要があります。 そのようなセットが存在しない場合、答えは不可能です。 

制約は最大 30 万の頂点とエッジに達し、二次関数や二次関数に近いものは即座に除外されます。 n log n のような小さな係数でも許容されますが、ネストされた方法でエッジを繰り返し探索するものはタイムアウトになるため、どのようなソリューションも基本的にグラフのサイズが線形である必要があります。 

定義自体には微妙な問題が隠されています。そのようなセットが常に存在すること、または存在する場合の構造が単純であることは明らかではありません。 もう 1 つの潜在的な落とし穴は、エッジ間のグローバルな一貫性を考慮せずにセットが貪欲に選択できると想定していることです。 

いくつかの特殊なケースで構造が明確になります。 

グラフに 1-2-3-1 などの三角形がある場合、独立したセットには最大 1 つの頂点を含めることができますが、単一の頂点はすべてのエッジをカバーできません。 たとえば、頂点 1 を選択すると、エッジ 2 ～ 3 が露出したままになります。 この入力は -1 を返す必要があります。 

グラフにエッジがまったくない場合、すべてのセットは独立しており、頂点は空に覆われています。 ただし、この問題では選択したセットが空ではないことが必要なため、正解は 0 ではなく 1 になります。 

グラフが 1-2-3-4 のような単純なチェーンの場合、頂点 {1, 3} または {2, 4} を選択すると両方の条件が満たされ、最小サイズはグラフを分割する方法によって異なります。 

これらの例は、構造が二部構成と密接に結びついていることをすでに示唆しています。 

## アプローチ

 ブルート フォースの試行では、頂点のすべてのサブセットが試行され、両方の条件がチェックされます。 各サブセットについて、すべてのエッジをチェックすることで独立性を検証し、すべてのエッジを再度スキャンすることでカバレッジを検証します。 これはおよそ O(2^n · m) になりますが、これは n が 300,000 までの場合は完全に不可能です。 

2 つの条件を書き直すと、より構造化された観察が得られます。 集合 S が独立している場合、S 内に両方の端点を持つエッジはありません。S が頂点カバーでもある場合、すべてのエッジは S 内に少なくとも 1 つの端点を持ちます。両方のステートメントを組み合わせると、すべてのエッジが S 内に厳密に 1 つの端点を持つことになります。これは、すべてのエッジが S とその補数 V \ S の間に入る必要があることを意味します。 

これは、グラフが 2 部構成であり、S が 1 つの色クラスを形成し、V \ S がもう 1 つの色クラスを形成していることを直ちに意味します。 逆に、2 部グラフでは、2 部のどちらかの側が独立しており、すべてのエッジもカバーします。 したがって、問題は、グラフが 2 部であるかどうかを確認し、そうである場合は、各連結成分の小さい方の側を選択することになります。 

各接続コンポーネントは 2 色で着色できます。 コンポーネント内では、カラー 0 のすべての頂点を選択することも、カラー 1 のすべての頂点を選択することもできます。合計サイズを最小限に抑えるために、コンポーネントごとに小さい方のカラー クラスを個別に選択します。 残る唯一の複雑な点は、この問題では空のセットが禁止されているため、グラフにエッジがまったくない場合でも、0 ではなく 1 を返さなければならないことです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n・m) | O(n) | 遅すぎる |
 | 二部構成のカラーリング | O(n + m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 2 つの色を割り当てながら、BFS または DFS を使用して各連結コンポーネントを個別に処理します。

1. すべての頂点を反復処理します。 頂点が訪問されていない場合は、そこから BFS を開始します。 
2. BFS 中に、開始頂点カラー 0 を割り当て、エッジに沿って交互のカラーを伝播します。 隣接するグラフが既に同じ色で着色されている場合、グラフは 2 部構成ではないため、すぐに -1 を返します。 このような競合は、何らかのエッジが両方のエンドポイントを同じ側に強制し、必要な構造を破壊することを意味するため、これが必要です。 
3. 各連結コンポーネントについて、色 0 の頂点の数と色 1 の頂点の数のカウントを維持します。 
4. コンポーネントを終了した後、そのコンポーネントの選択セットとして安価な方を自由に選択できるため、答えに min(count0, count1) を追加します。 
5. すべてのコンポーネントを処理した後、合計の答えが 0 の場合、問題には空ではない選択セットが必要であるため、それを 1 に置き換えます。 

### なぜ効果があるのか

 カラーリングにより、隣接する頂点が常に反対側のセットに存在することが強制されます。 これにより、各カラー クラスの独立性が保証されます。 エッジの両方の端点が同じ色を必要とする瞬間、すべてのエッジが反対側に端点を持つようにグラフを分割することはできません。これは、有効なセットが存在しないことを意味します。 有効な 2 分割が見つかると、各エッジには各カラー クラスに 1 つのエンドポイントが自動的に割り当てられるため、カラー クラス全体を選択すると、独立性を維持しながら頂点カバー プロパティが確保されます。 コンポーネントは接続されていないため、決定が相互作用しないため、コンポーネントごとの最小化で十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, m = map(int, input().split())
    g = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    color = [-1] * n
    ans = 0

    for i in range(n):
        if color[i] != -1:
            continue

        q = deque([i])
        color[i] = 0
        cnt = [1, 0]

        while q:
            u = q.popleft()
            for v in g[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    cnt[color[v]] += 1
                    q.append(v)
                elif color[v] == color[u]:
                    print(-1)
                    return

        ans += min(cnt[0], cnt[1])

    if ans == 0:
        ans = 1

    print(ans)

if __name__ == "__main__":
    solve()
```隣接リストはグラフを効率的に保存して、線形トラバーサルをサポートします。 BFS は色を割り当て、同時にコンポーネント内の各パーティションのサイズをカウントします。 BFS 内の競合チェックは、非二部構造を即座に検出するため、重要な正当性ゲートとなります。 

空の答えの最終調整は、エッジがない縮退ケースを処理します。その状況では、すべての頂点が分離され、すべてのコンポーネントがゼロから最小値に寄与するためです。 

## 実用的な例

 ### 例 1

 入力:```
4 2
1 2
3 4
```2 つのコンポーネントを形成する 2 つの独立したエッジがあります。 

| コンポーネント | ノード | カラー0 | カラー 1 | 選ばれた |
 | --- | --- | --- | --- | --- |
 | 1 | {1,2} | 1 | 1 | 1 |
 | 2 | {3,4} | 1 | 1 | 1 |

 答えの合計は2になります。 

これは、各コンポーネントが個別に最適化されており、両方のパーティションのバランスが取れていることを示しています。 

### 例 2

 入力:```
4 3
1 2
2 3
1 3
```これは三角形です。 

BFS カラーリング中、頂点 1 は 0、頂点 2 は 1、頂点 3 は 0 になりますが、エッジ 1 ～ 3 は両方のエンドポイントにカラー 0 を強制すると同時に、反対の色も必要とするため、競合が発生します。 

アルゴリズムはこれを検出し、二重パーティションが存在しないという事実と一致して、すぐに -1 を返します。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + m) | 各頂点とエッジは BFS トラバーサル中に 1 回処理されます。 
| スペース | O(n + m) | 隣接リストとカラー配列 |

 この制約では最大 300,000 個の頂点とエッジが許可され、単一の線形トラバースは制限内に快適に収まります。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque

    n, m = map(int, input().split())
    g = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    color = [-1] * n
    ans = 0

    for i in range(n):
        if color[i] != -1:
            continue
        q = deque([i])
        color[i] = 0
        cnt = [1, 0]

        ok = True
        while q:
            u = q.popleft()
            for v in g[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    cnt[color[v]] += 1
                    q.append(v)
                elif color[v] == color[u]:
                    ok = False
        if not ok:
            return "-1"
        ans += min(cnt)

    if ans == 0:
        ans = 1

    return str(ans)

# provided sample-like cases
assert run("4 2\n1 2\n3 4\n") == "2"
assert run("4 3\n1 2\n2 3\n1 3\n") == "-1"

# custom cases
assert run("2 0\n") == "1"
assert run("3 2\n1 2\n2 3\n") == "1"
assert run("5 4\n1 2\n2 3\n3 4\n4 5\n") == "2"
assert run("6 3\n1 2\n3 4\n5 6\n") == "3"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 2 ノード、エッジなし | 1 | 空のグラフには空ではないセットが必要です。 
| パスグラフ | 1 | 単一コンポーネントの 2 部構成の処理 |
 | 5 のチェーン | 2 | 2 部パス上の最適な分割 |
 | 3 つの互いに素なエッジ | 3 | 独立したコンポーネントの集約 |

 ## 特殊なケース

 空のエッジ グラフの場合、アルゴリズムはすべてのコンポーネントを孤立した頂点として生成し、各コンポーネントは答えにゼロを寄与します。 累積された値がゼロになるため、最終調整により出力が 1 に強制され、エッジが存在しない場合でも選択されたセットを空にすることができないという要件が満たされます。 

三角形などの単一の奇数サイクルの場合、BFS カラーリングでは必然的に、トラバーサルのある時点で 2 つの隣接する頂点に同じ色が割り当てられます。 競合はサイクルの終了エッジに到達するとすぐに検出され、アルゴリズムはグラフの残りの部分を処理することなく -1 を返します。 

接続されていない 2 部グラフの場合、各コンポーネントは独立して処理されます。 1 つのコンポーネントが大きく、もう 1 つが単一のエッジである場合でも、エッジはコンポーネントを横断しないため、一方の決定は他方に影響を与えず、局所最小化は全体的に最適になります。
