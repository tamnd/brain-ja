 ## 解決策
 ## 問題の理解

 私たちは、ロボットが左上隅から開始し、4 方向の移動を使用して右下隅に到達したいというグリッドで作業しています。 パスのコストは単に通過したステップ数であるため、制限がなければ、最短パスは常に貪欲に右下に移動し、正確に取得することになります。$n + m - 2$ステップ。 

問題は、「レーザー」セルの周囲の禁止領域です。 レーザーまでのマンハッタン距離が最大以下のセル$d$これは致命的であり、ロボットがそこに入ることができないことを意味します。 これにより、中心にダイヤモンド型のブロックされた領域が作成されます。$(s_x, s_y)$。 ロボットは以下からの最短経路を見つけなければなりません。$(1,1)$に$(n,m)$禁制の独房に足を踏み入れることなく。 

入力サイズは最大で$10^4$最大グリッドを含むテスト ケース$1000 \times 1000$。 これにより、すべてのセルをスキャンするテストごとの BFS またはグリッド シミュレーションが即座に除外されます。$10^7$最悪の場合、テストごとの操作が遅くなり、全体として非常に遅くなります。 

重要な観察は、禁止されたダイヤモンドが可能な限り最短の単調なパスとどのように交差するかを除いて、グリッド自体は無関係であるということです。 問題は状態空間を探索することではなく、幾何学的制約の下で有効なパスが存在するかどうかを判断することです。 

単純な間違いは、開始点または終了点が禁止領域内にない限り、最短パスが常に有効であると想定することです。 たとえば、両方の終点が安全であっても、最短パスがダイヤモンド型の禁止領域を通過する必要がある小さなグリッドを考えてみましょう。 このような場合、禁止領域がグリッドを完全に分離しているかどうかに応じて、禁止領域を迂回できる場合とできない場合があります。 

もう 1 つの微妙なケースは、禁止領域が境界に接しているが、端点が含まれていない場合です。 それでも、グリッドが切り離されたコンポーネントに分割される可能性があります。 たとえば、ダイヤモンドが列の幅全体にわたる場合、グリッドの上部と下部の間の通過を完全にブロックする可能性があります。 

## アプローチ

 ブルートフォースのアイデアは簡単です。各セルがノードでエッジが隣接するセルを接続するグラフとしてグリッドをモデル化します。 次に、BFS を実行します。$(1,1)$禁止されたセルを避けて、到達するまで$(n,m)$。 BFS は重み付けされていないグラフで最短パスを自然に見つけるため、これは正しいです。 

ただし、このアプローチには最悪の場合のコストがかかります。$O(nm)$テストケースごとに。 まで$10^4$テストケースの場合、これは次のようになります$10^7$に$10^{10}$状態の拡張が大きすぎます。 

重要な洞察は、実際にはグリッドを探索する必要がないということです。 禁止領域はダイヤモンドを形成するマンハッタン ボールです。 パスが失敗する唯一の理由は、このダイヤモンドが始点と終点を切断する場合です。 移動は 4 方向に制限されておらず、コストは均一であるため、重要な唯一の障害はダイヤモンドを周回する方法が存在するかどうかであり、それは純粋に、禁止領域がいずれかの次元に沿ったすべての可能な回廊をブロックしているかどうかによって決まります。 

レーザーが境界線にどれだけ近いかという観点から推論できます。 禁止領域が最初の行/最後の行、または最初の列/最後の列のいずれかを完全に横切って広がっている場合、通行を完全にブロックする可能性があります。 具体的には、ひし形が上部境界 (行 1)、下部境界 (行 n)、左側境界 (列 1)、または右側境界 (列 m) に達しているかどうかを確認します。 開始と終了を分けるように反対側の両方に触れている場合、パスは存在しません。 

この条件は、ダイヤモンドの周囲にまだ通過できる垂直または水平の通路があるかどうかを確認することを単純化します。 これにより、問題はグリッドの横断ではなく、いくつかの幾何学的不等式に帰着します。

 ## アルゴリズムのチュートリアル

 1. レーザーからの各方向における禁止領域の最大可能範囲を計算します。 ダイヤモンドは列に達します$[s_x - d, s_x + d]$列はマンハッタン距離を通じて同様に拘束されます。 
2. 禁止領域が、横断を妨げるように上端または下端をブロックしていないかどうかを確認します。 これは、禁止領域の垂直方向の範囲が、バイパスに使用できない狭い帯域を除くすべての行をカバーしている場合に発生します。 
3. 同様に、禁止領域が列をまたぐ横断を妨げるように左端または右端をブロックしているかどうかを確認します。 
4. 禁止領域により両者の間に分離が生じた場合$(1,1)$そして$(n,m)$、-1を出力します。 それ以外の場合は、最短パス長を出力します$n + m - 2$なぜなら、迂回が不要になると、有効なパスはすべて単調なパスに短縮されるからです。 

決定ステップの背後にある重要な考え方は、均一な移動コストを持つグリッドでは、障害物を回避する有効なパスは、それが存在する限り最短のマンハッタン パスに変換できるということです。 障害物は実現可能性を決定する上でのみ重要であり、最適な経路長ではありません。 

### なぜ効果があるのか

 禁止領域はマンハッタン距離で凸状になっており、最短経路の障害は部分的な迂回ではなく完全な遮断によって発生する必要があることを意味します。 4 方向すべての移動が許可されているため、始点と終点が禁じられたダイヤモンドの補数で接続されたままであれば、最短の長さのパスに「直線化」できるパスが存在する必要があります。$n + m - 2$。 したがって、問題は単一の凸状障害物の下での接続性をチェックすることに帰着します。これは、ダイヤモンドが両方の対向する境界ペアを分離する方法で交差するかどうかによって完全に決定されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, sx, sy, d = map(int, input().split())

        # Check if the diamond reaches all possible escape corridors.
        # If it covers a full strip separating top/bottom or left/right,
        # then path is blocked.

        if sx + sy <= d + 1 and sx + sy != 2:
            print(-1)
            continue

        if (n - sx + 1) + (m - sy + 1) <= d + 1 and (sx, sy) != (n, m):
            print(-1)
            continue

        if sx + (m - sy + 1) <= d + 1 and (sx, sy) != (1, m):
            print(-1)
            continue

        if (n - sx + 1) + sy <= d + 1 and (sx, sy) != (n, 1):
            print(-1)
            continue

        print(n + m - 2)

if __name__ == "__main__":
    solve()
```このコードは、レーザーの禁止領域が 4 隅の脱出方向のいずれかをブロックしているかどうかをチェックします。 各条件は、そのコーナー近くの禁止されたマンハッタン ボールを最短経路で強制的に通過するかどうかに対応します。 このようなブロッキングが発生した場合、有効なルートが存在しないと判断されます。 

それ以外の場合、迂回を強いられる障害物がないため、最終的な答えはコーナー間のマンハッタン距離になります。

| ステップ | ポジション | アクション | 有効 |

これにより、禁止領域が最小限でブロックされていない場合、最短パスは変化しないことが確認されます。 

### サンプル 2

 次のことを考慮してください。```
3 3 2 2 1
```レーザーは中央にあり、中央付近をブロックします。 ロボットはその周囲を迂回する必要があります。 

| ステップ | 地域の状況 | 実現可能なパスが存在します |
 | --- | --- | --- |
 | 開始 | (1,1) 安全 | はい |
 | 真ん中 | センターブロック | 迂回が必要 |
 | 終わり | (3,3) 安全 | はい |

 境界付近にパスが存在するため出力が残る$3 + 3 - 2 = 4$。 

これは、中心がブロックされていても、境界が完全に分離されていない限り、接続がそのまま維持できることを示しています。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、禁止領域が境界を完全にブロックせずに境界に接触するだけの場合です。 たとえば、エッジ近くのレーザーでは、小さな$d$無害に見えるかもしれませんが、狭い廊下を通過しようとするすべての経路を排除することができます。 このアルゴリズムは、グリッドの中心だけをチェックするのではなく、境界ベースのエスケープ ルートが完全に排除されているかどうかを明示的にチェックすることでこれを処理します。 

別のエッジケースが発生するのは次の場合です。$d = 0$。 この場合、禁止されるのはレーザー セルのみであり、問​​題の保証の開始と終了はレーザーではないため、答えは常にマンハッタン距離になります。 アルゴリズムは当然デフォルトのケースに当てはまります。 

3 番目のエッジケースは、レーザーがコーナーの近くにあり、$d$2 つの隣接する境界を支配するのに十分な大きさです。 このチェックにより、そのような構成が障害物の周囲の水平方向または垂直方向の両方の動きをブロックする場合、関数は迂回路が存在すると仮定するのではなく、正しく -1 を出力することを確認します。
