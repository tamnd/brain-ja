 しましょう$f(x_1,\ldots,x_n)$真理値表がある$\tau$、そしてさせてください$f^Z$真理値表がある$\tau^Z$。 のために$0 \le k \le n$、 させて$S_k(x_1,\ldots,x_n)$固定することによって得られる部分関数を示します$x_1=\cdots=x_k=1$、したがって、その真理値表は次の部分表になります。$\tau$秩序ある$n-k$位置から開始$2^k$入力の辞書編集上の順序。 目標は、対応するサブ関数を決定することです$S_k^Z$の$f^Z$。 

Z 変換は連結で再帰的に定義されます$\alpha\beta$等しい長さのブロックで分割し、複製、ゼロ埋め込み、またはより小さいブロックへの変換の再帰的適用によって、特定の構造化された連結を置き換えます。 定義内のすべての句は、変数の固定プレフィックスに対応するブロックに対して変換が独立して動作するという特性を保持します。 固定による真理値表の部分表への分解$x_1,\ldots,x_k$最初のものだけに依存する$k$この再帰的なブロック構造のレベル。 

重要な観察は、次のことです。$\tau^Z$変数の順序付けの最初のセグメントに対する制限と互換性があります。 もし$\tau$の連結として書かれます$2^k$長さのブロック$2^{n-k}$の割り当てに対応する$(x_1,\ldots,x_k)$の場合、Z 変換の各節はブロック全体に均一に適用されるか、同じ構造のブロック内に再帰的に適用されます。 最初のブロックで決定された異なるブロックのビットを混合する句はありません。$k$変数。 

したがって、次の制限は$\tau^Z$固定して得られる$x_1=\cdots=x_k=1$まさに制限された文字列の Z 変換です$\tau_{x_1=\cdots=x_k=1}$。 これにより真理値表の同一性が得られます。$$(\tau_{x_1=\cdots=x_k=1})^Z = (\tau^Z)_{x_1=\cdots=x_k=1}.$$両辺をブール関数として解釈すると、次のサブ関数が得られます。$f^Z$最初の修正に対応$k$変数は、対応するサブ関数の Z 変換と等しくなります。$f$。 練習問題の表記では、$$S_k^Z(x_1,\ldots,x_n) = (S_k(x_1,\ldots,x_n))^Z.$$この平等はすべての場合に成り立つので、$k$と$0 \le k \le n$、全体$k$-プロフィール$f^Z$Z 変換をレベルごとに適用することで得られます。$k$-プロフィール$f$、演習 192 で確立されたプロファイルと Z プロファイル間の対応関係と一致します。 

したがって$$\boxed{S_k^Z = (S_k)^Z \quad \text{for all } 0 \le k \le n.}$$これで証明は完了です。 ∎
