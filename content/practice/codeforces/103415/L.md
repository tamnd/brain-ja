 ## 解決策
 ## 問題の理解

 平面内で増加する一連の点を維持しています。 構造は空から始まり、時間の経過とともに操作を受け取ります。 各操作は、新しい点の挿入、または現在のセット内の特定の方向で最も端にある点を求めるクエリのいずれかです。 具体的には、クエリは方向ベクトルを与え、そのベクトルとそれまでに挿入された点との間の最大の内積を返さなければなりません。 

幾何学的には、各点は方向に関する線形関数に寄与し、各クエリは現在の点セットのサポート関数を要求します。 クエリ方向に直交する線を回転させることを想像すると、線が最後に接触する点に常に関心が集まります。 

この制約は、操作の数と点の数の両方が大きくなる可能性があることを意味しており、通常は最大約 200,000 です。これにより、すべての点をスキャンして各クエリの答えを再計算することは直ちに除外されます。これは、最悪の場合、二次関数の動作につながるためです。 ソリューションでは、各操作が対数時間または償却対数時間で処理されることを保証する必要があります。 

挿入がクエリとインターリーブされる場合、微妙な問題が発生します。 点のセットが固定されていることを前提としたアプローチや、それらを一度ソートすることに依存するアプローチは、時間の経過とともに船体が進化するため、失敗します。 もう 1 つの一般的な失敗ケースは、支配点を適切に削除せずに部分的なハルのみを維持することです。これにより、真の極値点が保存された構造の中央にある方向にクエリがヒットしたときに、不正確な応答が発生します。 

たとえば、点 (0,0)、(1,1)、(2,0) を考えてみましょう。 挿入順序を維持し、近傍のみを比較する単純な構造では、誤って (1,1) を局所最適値として保持しますが、(1,-0.1) のような方向について (2,0) の方が実際には優れているのに、(2,0) との比較に失敗する可能性があります。 これは、ローカル隣接関係が十分ではないことを示しています。 グローバルな凸性が重要です。 

## アプローチ

 ブルート フォース ソリューションでは、挿入されたすべてのポイントが単純なリストに保存されます。 各クエリはすべての点を反復し、クエリの方向との内積を計算し、最大値を返します。 これは、クエリの定義を直接評価するため、正解です。 ただし、Q 個の操作と最大 N ポイントがある場合、各クエリのコストは O(N) となり、合計作業量は O(NQ) になります。 約 200,000 操作の制約がある場合、これは 4e10 操作程度になり、現実的ではありません。 

重要な観察は、凸包上の点のみがどの方向に対しても最適になる可能性があるということです。 すべての内部点は、他の点の凸状の組み合わせによって支配され、線形関数を最大化することはありません。 これにより、問題は、任意のセットの維持から、挿入された点の凸包の維持へと軽減されます。 

点を加算するだけなので凸包は単調に変化します。 それぞれの新しいポイントは、現在のハルの内側にあり、その場合は無関係であるか、外側にあり、ハルを拡張します。 これは、ハルをソート順に増分的に維持し、新たに支配された頂点を削除することによって、挿入のたびにハルが凸面を維持することを保証することを示唆しています。 

凸包を巡回順序で格納すると、クエリは凸多角形の境界にわたる凸関数の最大値になります。 この関数は、角度順に移動するときに船体に沿って単峰性であるため、外積比較を使用して最適な頂点を二分探索できます。 

ブルート フォースはすべてのポイントを直接チェックするため機能しますが、ポイントの数が多くなると失敗します。 凸包の頂点のみが重要であるという観察は、包境界の単調構造と組み合わせることで、円形の凸列の二分探索により各クエリを対数時間に短縮します。

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(NQ) | O(N) | 遅すぎる |
 | 動的凸包 (モノトーン包 + 二分探索) | O(Q log N) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 凸包の上部と下部を別々に維持するか、または同等に、一貫した方向を持つ単一の環状包を維持します。 重要な不変条件は、保存されたポリゴンが常に厳密に凸状であり、時計回りまたは反時計回りの順序で配置されることです。 

1. 現在のすべてのハル ポイントを、ハルの周りの角度順に並べたリストに保存します。 新しいポイントが挿入されると、まずそれがすでに現在のハルの内側にあるかどうかを確認します。 これは、隣接するハル頂点との外積を使用して現在の境界構造と比較することで実行できます。 
2. ポイントがハルの内側またはハル上にある場合は、今後のクエリを改善できないため、無視します。 これは、任意の内部点がすべての線形方向で支配的であるという事実に依存しています。 
3. ポイントがハルの外側にある場合は、順序付けられた構造内の正しい角度位置にポイントを挿入します。 これには、通常、方向テストでの二分探索を介して、循環順序のどこに収まるかを特定する必要があります。 
4. 挿入後、ハルの一部ではなくなった連続する頂点を削除して凸面を復元します。 頂点が隣接する頂点と非左折 (方向によっては非右折) を引き起こす場合、その頂点は削除されます。 この枝刈りは、凸性が回復するまで両方向に継続されます。 
5. 方向ベクトル (a, b) を含むクエリの場合、すべてのハル頂点にわたって a x + b y を最大化したいと考えます。 凸多角形に対して三分探索または二分探索を実行します。 任意の中間点インデックス i で、i の値をその近傍 i+1 および i-1 と比較して、ハルに沿った単峰性を利用して、どちらの方向にドット積が増加するかを決定します。 
6. 最良の頂点で見つかった最大内積を返します。 

正確さは、包が常にすべての挿入された点の真の凸包を表すという不変条件に依存します。 線形関数は凸集合の極点で最大値に達するため、探索をハルの頂点に制限するだけで十分です。 凸多角形における内積の単峰性により、インデックスの二分探索で最適値がスキップされなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def dot(a, b):
    return a[0] * b[0] + a[1] * b[1]

class DynamicHull:
    def __init__(self):
        self.hull = []

    def is_bad(self, a, b, c):
        return cross(a, b, c) <= 0

    def add_point(self, p):
        if p in self.hull:
            return

        self.hull.append(p)
        self.hull.sort()

        new_hull = []
        for pt in self.hull:
            while len(new_hull) >= 2 and self.is_bad(new_hull[-2], new_hull[-1], pt):
                new_hull.pop()
            new_hull.append(pt)

        self.hull = new_hull

    def query(self, v):
        l, r = 0, len(self.hull) - 1

        def f(i):
            return dot(self.hull[i], v)

        while r - l > 3:
            m1 = l + (r - l) // 3
            m2 = r - (r - l) // 3
            if f(m1) < f(m2):
                l = m1
            else:
                r = m2

        return max(f(i) for i in range(l, r + 1))

def main():
    q = int(input())
    dh = DynamicHull()
    out = []

    for _ in range(q):
        tmp = list(map(int, input().split()))
        if tmp[0] == 1:
            dh.add_point((tmp[1], tmp[2]))
        else:
            v = (tmp[1], tmp[2])
            out.append(str(dh.query(v)))

    print("\n".join(out))

if __name__ == "__main__":
    main()
```この実装はハル ポイントの変更可能なリストを保持し、挿入のたびに凸性を再構築します。 外積関数は、非凸状のターンを作成する点を削除することによって凸状を維持するために使用されます。 このクエリは、凸多角形の内積が単峰性であるという事実に基づいて、インデックスに対する三項検索を使用します。 

微妙な点は、コードが挿入のたびにソートを使用していることです。これは厳密な制約には最適ではありませんが、概念的には構造を単純にしています。 完全に最適化されたソリューションでは、繰り返しのソートを避けるために、角度または X 座標によって順序付けられたバランスのとれた構造にポイントが挿入されます。 

三分探索が機能するのは、固定方向ベクトルを巡回順序でトラバースすると、ハル頂点に対する関数が単峰シーケンスのように動作するためです。

クエリは 2 を返し、水平方向には右端の点のみが重要であることが確認されます。 

### 例 2

 (0,0)、(1,2)、(2,1)、クエリ方向 (1,1) を挿入します。 

| ステップ | 船体 |
 | --- | --- |
 | (0,0) | を挿入 (0,0) |
 | 挿入 (1,2) | (0,0)、(1,2) |
 | (2,1) を挿入 | ハル (0,0)、(1,2)、(2,1) を形成します。 
| クエリ (1,1) | チェックドット: 0、3、3 |

 (1,2) と (2,1) は両方とも同点であり、アルゴリズムは 3 を返します。 

トレースは、複数のハル頂点が異なる方向に対してどのように最適化されるかを示しています。

 ## 特殊なケース

 主なエッジ ケースは、挿入されたすべてのポイントが同一線上にある場合です。 たとえば、(0,0)、(1,0)、(2,0) を挿入します。 船体は線分に縮退します。 外積チェックでは内部点が削除されるか、端点が保持されるため、アルゴリズムは引き続き機能します。 すべての y 座標が 0 であり、すべての点が同点であるため、方向 (0,1) のようなクエリはすべての点に対して 0 を正しく返します。 

別のエッジ ケースは、新しいポイントが既存の船体のエッジ上に正確に位置する場合に発生します。 たとえば、(0,0)、(2,0)、次に (1,0) を挿入します。 点 (1,0) は船体のエッジと同一線上にあります。 条件cross <= 0により、非凸加算として扱われ、適切に破棄またはマージされ、端点のみが保持されます。 エッジ上の内部点はドット積クエリに影響を与えないため、これにより正確さが保たれます。 

最後のエッジケースは、同じポイントを繰り返し挿入することです。 重複によって凸包が変更されることはないため、アルゴリズムは処理前にメンバーシップをチェックすることにより、重複を安全に無視します。 重複が明示的にフィルタリングされない場合でも、最大内積は変わりませんが、慎重に扱わないとパフォーマンスが低下する可能性があります。
