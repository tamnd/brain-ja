 ## 解決策
 ## 問題の理解

 制限された構造を持つ無向接続グラフが与えられます。すべてのエッジは最大でも 1 つの単純なサイクルに属するため、サイクルは共有エッジを介してではなく、頂点でのみ重なり合うことができます。 これは、サボテン グラフの標準定義です。 

すべてのエッジを素のペアに分割するように求められます。 各ペアは、共通の終点を共有する 2 つのエッジで構成されている必要があるため、各ペアは長さ 2 のパスのような形状の「スティック」を形成します。 すべてのエッジはそのようなペアの 1 つに属している必要があり、ペアが重複することはできません。 

タスクは、そのようなスティックに含まれるすべてのエッジの有効な完全なペアがいくつ存在するかを数えることです (モジュロ 1000003)。 

制約では最大 100,000 個の頂点とエッジが許可されるため、ペアを明示的に列挙したり、エッジごとの構成を個別に考慮したりするソリューションは、非常に遅すぎます。 このスケールでは O(N^2) または O(N√N) でさえ安全ではないため、解は本質的に線形または線形に近いものでなければなりません。 

微妙な問題は、ペアリングの制約がグローバルであることです。 1 つのエッジが 2 つの頂点に属しており、一方の端点でペアにすることを選択すると、もう一方の端点で使用できなくなります。 これにより、グラフ全体に依存関係が作成され、ローカルの貪欲ペアリングの信頼性が低くなります。 

素朴な貪欲推論が失敗する小さな例は、長さ 4 の単純なサイクルです。貪欲に頂点の周囲で連続してエッジをペアにしようとすると、異なる開始選択により異なるグローバルな有効なペアが生成され、ローカルの決定が一貫性なく伝播します。 サイクルの構造ではまさに曖昧さが生じます。 

もう 1 つのエッジケースは木です。 ツリーであっても、すべての構成が有効であるわけではありません。これは、リーフの次数が 1 であり、唯一の入射エッジが隣接するエッジでペアになるように強制され、制約が上向きに伝播されるためです。 正しいソリューションでは、これらの強制伝播を一貫して暗黙的に処理する必要があります。 

## アプローチ

 強引なアイデアは、各エッジをその端点の 1 つに割り当てるあらゆる方法を検討することです。つまり、各エッジに対して、どの頂点がそのペアを担当するかを決定します。 この割り当てが修正されたら、各頂点をチェックします。頂点に割り当てられたエッジは、素のペアに分割可能である必要があります。これは、それらの数が偶数である場合にのみ可能であり、階乗形式のペアの数に寄与します。 

この強引な見方は正しいですが、まったく実現不可能です。 各エッジには 2 つのエンドポイントの選択肢があるため、2^M の割り当てがあり、100000 までの M ではすでに不可能です。 

重要な観察は、有効な代入の構造が高度に制約されていることです。 端点に向かうエッジの方向を固定すると、実現可能条件は頂点で純粋に局所的になりますが、グローバルな一貫性により強力な構造が強制されます。つまり、選択はパスとサイクルに沿って伝播します。 

ツリー状の構造では、リーフが解決されるとすべてが一意に強制されるため、本質的に自由がありません。 唯一の自由はサイクルから得られます。 サボテンの単純なサイクルをたどると、ローカルパリティ制約を満たした後、そのサイクルの周りでペアリングの方向を「反転」するかどうかという二者択一の選択肢が 1 つだけ残っていることがわかります。 サボテンのサイクルは頂点でのみ交差するため、これらのサイクル レベルの自由度は異なるサイクル間で独立しています。 

これにより、計数の問題全体が、サボテンに含まれる独立したサイクルの数を特定し、各サイクルからの寄与を乗算することに軽減されます。 

接続されたグラフの場合、独立したサイクルの数は M − N + 1 です。そのような各サイクルは 2 の係数に寄与しますが、ツリー部分は追加の乗算の選択肢に寄与しません。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^M) | お(お) | 遅すぎる |
 | 最適 (サイクルカウント) | O(N + M) | O(N + M) | 承認済み |

 ## アルゴリズムのチュートリアル

1. グラフを読み、接続されていることを確認します。 そうでない場合、各連結成分は独立して答えに寄与しますが、この問題では、グラフは仮定によって連結されています。 
2. 頂点 N とエッジ M の数を計算します。 
3. どのグラフでも、接続されたグラフの独立サイクル数 (循環数とも呼ばれます) が M − N + 1 であることに注目してください。 この値は、スパニング ツリーを超えるエッジの数を表します。 
4. この値を C = M − N + 1 として直接計算します。 
5. 最終的な答えは 2^C モジュロ 1000003 です。 

### なぜ効果があるのか

 ペアリング制約は、各エッジの責任を 1 つのエンドポイントに分散し、頂点でインシデント エッジをペアリングするものとして解釈できます。 非循環構造では、葉が選択肢を排除し、制約を内部に伝播するため、この代入は一意に強制されます。 

サイクルが現れると、ツリー状の制約がすべて解決された後、残りの自由度はそのサイクルの周囲で一貫した方向を選択することに正確に対応します。 サイクルに沿って選択を反転すると、ローカルでは有効性が維持されますが、個別のグローバル構成が生成されます。 サボテンのサイクルはエッジを共有しないため、これらの 2 値の選択は独立しており、サイクル間で乗算されます。 

したがって、解空間は、グラフのサイクル基本要素ごとに 1 つずつ、独立した 2 値決定に分解されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000003

def main():
    n, m = map(int, input().split())
    
    # We do not actually need the edges.
    # The graph is assumed connected, so cyclomatic number is m - n + 1.
    for _ in range(m):
        input()
    
    cycles = m - n + 1
    if cycles < 0:
        cycles = 0
    
    ans = pow(2, cycles, MOD)
    print(ans)

if __name__ == "__main__":
    main()
```答えは頂点とエッジのグローバルな数のみに依存するため、実装では意図的に隣接構造を無視しています。 唯一の微妙な点は、指数が負にならないようにすることです。これは縮退入力によってのみ発生する可能性があります。 少なくとも 1 つのエッジを持つ接続されたグラフでは、M ≥ N − 1 が常に成り立ちます。 

## 実用的な例

 ### 例 1: 単純なツリー

 3 つのエッジを持つ 4 つの頂点のチェーンを考えてみましょう。 すると、N = 4、M = 3 となります。 

| ステップ | 値 |
 | --- | --- |
 | N | 4 |
 | M | 3 |
 | C = M − N + 1 | 0 |
 | 答え | 1 |

 これは、すべての選択が葉によって内側に強制されるため、ツリーにはエッジをペアにするための有効な方法が 1 つだけあることが確認されます。 

### 例 2: 単一サイクル

 4 つのエッジを持つ 4 つの頂点のサイクルを考えてみましょう。 したがって、N = 4、M = 4 となります。 

| ステップ | 値 |
 | --- | --- |
 | N | 4 |
 | M | 4 |
 | C = M − N + 1 | 1 |
 | 答え | 2 |

 これは重要な現象を示しています。1 つのサイクルによって、グローバル構造内に 2 つの選択肢が 1 つだけ導入されます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

def run(inp: str) -> str:

 ## 特殊なケース

 純粋なツリーは最も重要な退化のケースです。 たとえば、長さ 3 のエッジのパスには N = 4、M = 3 があり、C = 0 となります。アルゴリズムは 1 を出力します。これは、すべてのエッジのペアがリーフの伝播によって強制され、自由がないという事実と一致します。 

単一の単純なサイクルで、式が唯一の自由源を正しく捉えているかどうかをテストします。 N = 4、M = 4 の場合、C = 1 が得られ、答えは 2 になります。これは、サイクルに沿ってペアを「方向付ける」ための 2 つの一貫したグローバルな方法に対応します。 

サボテンで許可されているように、複数のサイクルが頂点を共有するがエッジは共有しないグラフは、独立性を示します。 各サイクルは独立して指数に寄与するため、複数のサイクルに参加するエッジがないため、構成は干渉することなく増加します。
