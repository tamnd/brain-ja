 ## 問題の理解

 このタスクは、単一の変数が含まれる簡略化されたプログラミング言語をシミュレートすることです。`x`を通じて値を割り当てることができます`set`説明書。 それぞれ`set`命令を削除したい場合はコストがかかりますが、目的はそれを防ぐことです。`x`禁止された値が割り当てられないようにする`s`総コストを最小限に抑えながら。 プログラムには、以下で始まる条件ブロックも含まれています。`if y`そしてマッチングで終わる`end`、ブロック内の命令は次の場合にのみ実行されます。`x`現在は等しい`y`。 これらのブロックはネストして、実行パスのツリー状構造を作成できます。 

入力は次のもので構成されます`n`指示、ここで`n`最大200,000まで上がる可能性があり、費用は`v`最大 10^9 まで大きくすることができます。 すべての可能な命令削除の組み合わせを調査する総当りシミュレーションには、2^n 通りの可能性が含まれますが、これは実行不可能です。 したがって、命令数に対して線形時間でプログラムを処理するアルゴリズムが必要です。 

エッジケースには連続したものが含まれる`set`内部と外部の両方に禁止値を割り当てる命令`if`ブロック。 たとえば、次のように設定するプログラム`x`に`s`すぐにネストされました`if`他の禁止された割り当てを持つブロックは、安価な削除パスを見逃さないように慎重に処理する必要があります。 別の厄介なケースがネストされています`if`条件自体が禁止値である可能性のあるブロックをブロックし、命令のサブツリー全体をスキップする可能性があります。 

小さな例でその微妙さを強調します。 考慮する：```
4 1
set 1 10
if 0
set 1 5
end
```ここで、最初の`set`セット`x`1 に変更します。これは禁止されており、コスト 10 で削除する必要があります。`set`の中で`if`ブロックは決して実行されないため、コストはかかりません。 すべてを削除する単純なアルゴリズム`set`の`1`浪費してしまうだろう。 

## アプローチ

 単純なアプローチでは、プログラムを 1 行ずつたどって、次のことをシミュレートします。`x`変化するとき、そしていつでも`set`禁止された値を割り当てます`s`、そのコストを合計に追加します。 ネストされた場合`if`ブロックの場合、現在の値を維持する必要があります。`x`各レベルで。 これは概念的には機能しますが、ネストされた条件を介してすべての可能なパスを維持すると、最悪の場合、指数関数的に複雑になる可能性があるため、非効率的になります。 

最適なソリューションを実現するための重要な洞察は、プログラムのどの時点でも、`x`そしてそれを防ぐためのコスト`s`問題を割り当てられることから。 過去のすべてのパスを考慮する必要はなく、可能性のあるそれぞれの最小コストのみを考慮する必要があります。`x`ネストの各レベルで。 この観察により、スタックを使用した動的プログラミング アプローチを使用して、回避すべきコストを追跡できるようになります。`s`アクティブなそれぞれに対して`if`ブロック。 私たちが遭遇したとき、`set y v`指示、場合`y`等しい`s`の場合、現在の実行パスがアクティブかどうかに応じて、削除するか無視する必要があります。 入れ子になった`if`ブロックが閉じられると、ブロックは最小コストを上方向にのみ伝播するため、線形トラバースで十分であることが保証されます。 

間の移行`if`そして`end`辞書のスタックを使用して処理できます。各辞書は可能性のあるものをマップします。`x`割り当てを避けるために値を最小コストに設定する`s`そのブロックで。 ブロックを終了するとき、そのコスト テーブルをその親とマージし、各値の最小コストを取得します。

 ## アルゴリズムのチュートリアル

 1. アクティブを表すスタックを初期化します。`if`ブロック。 スタック上の各要素は、現在の辞書マッピングを保持します。`x`割り当てを避けるために値を最小コストに設定する`s`そのブロックで。 次のようにグローバル スコープをスタックにプッシュします。`x=0`そしてコストは0です。 
2. 各命令を繰り返し実行します。 のために`set y v`指示、チェックしてください`y`等しい`s`。 そうなった場合、プログラムを中断せずに継続するための最小コストは、現在のコストに現在のコストを加えたものとなります。`v`。 それ以外の場合、コストは変わりません。 それに応じてスタックの最上位にある辞書を更新します。 
3.`if y`命令を実行すると、新しい空の辞書がスタックにプッシュされます。 現在の辞書のエントリのみを設定します。`x`値の一致`y`。 これにより、アクティブな実行パスのみを追跡することが保証されます。`if`ブロックが実行されます。 
4.`end`命令を実行すると、一番上の辞書をポップし、それをスタック上の前の辞書とマージします。 それぞれについて`x`ポップされたディクショナリ内の値を取得するには、現在のコストと子コストの間の最小コストで親ディクショナリを更新します。 これにより、最小コストが上方に伝播されます。 
5. すべての命令を処理した後、グローバル スコープの辞書には回避すべき最小限のコストが含まれます。`s`のために`x=0`。 この値を出力します。 

機能する理由: スタックは、ネストのすべてのレベルで、現在の値が与えられた場合に可能な実行パスのコストのみを伝播するようにします。`x`。 私たちは決して不可能な道を考慮せず、選択肢の中から常に最小限のコストを選択します。 これにより、最終コストが全体的に最小限になることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, s = map(int, input().split())
instructions = [input().strip() for _ in range(n)]

stack = [{0: 0}]

for line in instructions:
    parts = line.split()
    if parts[0] == 'set':
        y = int(parts[1])
        v = int(parts[2])
        new_top = {}
        for x_val, cost in stack[-1].items():
            if y == s:
                new_cost = cost + v
                new_top[x_val] = min(new_top.get(x_val, float('inf')), new_cost)
            else:
                new_top[y] = min(new_top.get(y, float('inf')), cost)
        stack[-1] = new_top
    elif parts[0] == 'if':
        y = int(parts[1])
        new_top = {}
        for x_val, cost in stack[-1].items():
            if x_val == y:
                new_top[x_val] = cost
        stack.append(new_top)
    elif parts[0] == 'end':
        child = stack.pop()
        parent = stack[-1]
        for x_val, cost in child.items():
            parent[x_val] = min(parent.get(x_val, float('inf')), cost)

print(min(stack[0].values()))
```最初のセクションでは入力を解析し、グローバル実行スコープでスタックを初期化します。 の`set`慎重に取り扱い、関連する更新のみを行う`x`禁止された割り当てが発生した場合、コストは増加します。`if`条件が現在のパスと一致するパスに対してのみ新しい辞書を作成します。`x`。 の`end`この命令は、最小コスト比較を使用して子コストを親辞書にマージし、最適な伝播を保証します。
