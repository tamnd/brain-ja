 ## 解決策
 ## 問題の理解

 サイズのバイナリ行列を構築するように求められます。$n \times m$どこ$n$そして$m$均等であることが保証されています。 制約は、各セルがそれ自体とは異なる値を持つ隣接セルを 2 つだけ持たなければならないということです。 隣接セルは、直接隣接する 4 つのセルとして定義されます。 入力は複数のテスト ケースで構成され、それぞれが指定します$n$そして$m$、出力は近傍制約を満たす任意の行列になります。 

どちらの寸法も均等で適度に小さいため ($2 \le n,m \le 50$)、で動作するアルゴリズムを提供することができます。$O(nm)$テストケースあたりの時間。 素朴なアプローチでは、すべてのバイナリ行列をテストしようとしますが、$2^{nm}$可能性はありますが、それは完全に不可能です。 この問題では、与えられたすべての入力に対して解が存在することが保証されているため、目標は建設的であり、常に近傍プロパティを満たすパターンを見つけることです。 

エッジケースには最小の行列が含まれます$2 \times 2$両方の寸法が等しく、より大きい場合、例:$50 \times 50$。 不注意なアプローチでは、4 つの隣接セルを考慮せずに行または列を交互に行おうとし、2 つ以上の異なる隣接セルを持つセルが生成される可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、すべてが生成されます。$2^{nm}$行列を調べて、隣接するプロパティを確認します。 各チェックには時間がかかります$O(nm)$、しかし世代だけでは手に負えません。 一度に 1 ビットずつ反転しようとしても、非常に小さいサイズを超えることはできません。$n$そして$m$。 

重要な洞察は、2x2 ブロック パターンを繰り返すことで、すべてのセルに対して正確に 2 つの異なる隣接が保証されるということです。 ブロックを次のように定義すると、```
1 0
0 1
```それを行列上にタイル表示すると、各セルには同じ値を持つ 2 つの隣接セルと、異なる値を持つ 2 つの隣接セルがあります。 なぜなら$n$そして$m$が偶数であれば、パターンを壊さずにこのブロックを正確にタイル化できます。 これにより、隣接条件が自動的に保証されます。 1↔0 を反転して別の有効な解を取得し、複数の正しい行列を与えることもできます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(nm) * nm) | O(nm) | 遅すぎる |
 | ブロックタイリング | O(nm) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$そして$m$。 
3. 空のオブジェクトを初期化する$n \times m$マトリックス。 
4. 各セルについて$(i,j)$、その値を次のように計算します。$(i \bmod 2) \oplus (j \bmod 2)$。 この式は、行と列の両方で 1 と 0 を交互に並べて、タイル状の 2x2 ブロック パターンを形成します。 
5. 行列を行ごとに印刷します。 

機能する理由: 各 2x2 ブロックは、水平方向と垂直方向に隣接するセルが市松模様で異なることを保証します。 ブロックは偶数サイズの行列に並べて配置されるため、すべての内部セルと境界セルには、異なる値を持つ 2 つの隣接セルが存在します。 XOR パターンにより、タイリングがシームレスになり、問題の制約が満たされることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    for i in range(n):
        row = []
        for j in range(m):
            row.append((i % 2) ^ (j % 2))
        print(" ".join(map(str, row)))
```このソリューションは入力を効率的に読み取り、その場で行列を構築します。 の`(i % 2) ^ (j % 2)`市松模様のパターンで値が交互に配置されるようにします。 一度に 1 行を保存する以外に追加のメモリは必要ありません。また、Python はゼロベースのインデックスを使用するため、off-by-one エラーも発生しません。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(t * n * m) | 各セルはテスト ケースごとに 1 回だけ計算されます。 |
 | スペース | O(m) | 印刷中は一度に 1 行だけが保存されます。 |

 与えられた$t \le 100$そして$n,m \le 50$、操作の最大数は$100 * 50 * 50 = 250,000$、1秒の制限時間内にうまく収まります。

 ## 特殊なケース

 2x2 行列の場合:```
2 2
```私たちのアルゴリズムは以下を生成します:```
0 1
1 0
```左上のセルには隣接セル (0,1) と (1,0) があり、どちらも異なります。 4 つのセルのそれぞれには、制約を満たす 2 つの異なる隣接セルがあります。 これにより、アルゴリズムが最小の入力に対して正しく機能し、より大きな偶数次元まで自然にスケーリングされることが確認されます。
