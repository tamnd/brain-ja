 ## 問題の理解

 3 次元空間に 2 つのベクトルが与えられ、それぞれが 3 つの整数座標で記述されます。 タスクは、指定された両方のベクトルに垂直なゼロ以外の整数ベクトルを同時に構築することです。 幾何学的に、これは 2 つの入力ベクトルがまたがる平面に直交する方向が必要であることを意味します。 

入力は、どちらのベクトルもゼロ ベクトルではないこと、およびそれらが同一ではないことを保証します。 このステートメントに隠されている重要な幾何学的仮定は、2 つのベクトルが同一線上にないということです。そうでない場合、それらは一意の平面方向を定義できません。ただし、その縮退したケースであっても、外積公式は依然として有効な直交ベクトルを生成します。 

出力は、座標が境界範囲内にあり、ゼロ ベクトルではない整数ベクトルである必要があります。 有効な答えは複数存在するため、正しい垂直方向はどれでも許容されます。 

制約は非常に小さく、座標の範囲は 0 ～ 10 です。これにより、浮動小数点演算や複雑な数値手法の必要性が即座に排除されます。 有界整数を生成する正しい構造であれば十分であり、Python ではオーバーフローは問題になりません。 

微妙なエッジ ケースは、2 つのベクトルが平行である場合です。 たとえば、両方のベクトルが`(1, 2, 3)`そして`(2, 4, 6)`、素朴な幾何学的な直観は問題が不明確であることを示唆するかもしれませんが、それでも外積は次のようになります。`(0, 0, 0)`その場合は無効となります。 ただし、このステートメントはベクトルが等しくないことを保証するものであり、それらが非共線的であることを明示的に保証するものではないため、直接の外積がゼロになる可能性を処理する必要があります。 

もう 1 つのエッジ ケースは、コンポーネントは小さいが、キャンセルにより 1 つ以上の座標がゼロになるように構造化されている場合です。 例えば、`(1, 0, 0)`そして`(2, 0, 0)`ゼロクロス積が生成されますが、これはフォールバック直交構成を選択することで回避する必要があります。 

## アプローチ

 ブルートフォースのアイデアは、小さな整数ベクトルを検索することです。`(x, y, z)`許可された出力範囲内で、両方の入力ベクトルに対して垂直であるかどうかをテストします。 すべての値を反復処理します。`[-200, 200]^3`、ゼロベクトルをスキップし、ドット積をチェックします。 各候補には 2 つのドット積が必要なので、合計の複雑さはおよそ次のようになります。`(401^3) * 6`算術演算、これは約 4 億チェックに相当します。 これは境界線にありますが、概念的に Python で 1 秒としては遅すぎます。また、幾何学的構造を考慮すると不必要です。 

重要な観察は、3 次元では、与えられた両方のベクトルに直交するベクトルを外積を使用して直接構築できることです。 外積は両方の入力ベクトルに垂直な方向を正確にエンコードし、代数恒等式による内積制約を常に満たします。 これにより、検索が不要になり、問題は定数時間の計算に減ります。 

ただし、入力ベクトルが同一線上にある場合、外積はゼロ ベクトルになる可能性があります。 その場合、共有方向に垂直なベクトルはどれでも許容されます。 座標を交換して 1 つの成分を否定することで最初のベクトルに直交するベクトルを構築するなど、決定論的なフォールバックに安全に切り替えることができ、出力ゼロを確実に回避できます。

 ## アルゴリズムのチュートリアル

 1. 2 つの入力ベクトルを読み取ります。`a = (x1, y1, z1)`そして`b = (x2, y2, z2)`。 これらは、同一線上にない限り、平面の方向を定義します。 
2. 外積を計算します。`v = a × b`、標準的な公式を使用して`v = (y1*z2 - z1*y2, z1*x2 - x1*z2, x1*y2 - y1*x2)`。 

この構造が選択されるのは、各座標が両方の入力ベクトルとのドット積をキャンセルするように形成されるためです。 
3. かどうかを確認します。`v`はゼロベクトルです。 ゼロでない場合は、両方の入力に対して垂直であることが保証されているため、直接出力します。 
4. 外積がゼロの場合、ベクトルは同一直線上にあります。これは、ベクトルに垂直なベクトルを意味します。`a`にも垂直です`b`。 次のような単純な垂直ベクトルを構築します。`(y1, -x1, 0)`ない限り`(x1, y1)`は両方ともゼロです。 
5. もし`(x1, y1)`がゼロの場合、さらに後退します`(0, z1, -y1)`または、少なくとも 1 つの非ゼロ成分を保証する巡回置換。 これにより、必要な範囲内の有効な有界整数解が保証されます。 

### なぜ効果があるのか

 外積は、代数的相殺によって各入力ベクトルとの内積が全く同じゼロになるように定義されます。 ゼロ以外の場合、有効な答えが直接提供されます。 これが 0 の場合、入力ベクトルは線形依存しています。これは、入力ベクトルが空間内の単一の方向のみを定義することを意味します。 その場合、直交補数は完全な平面であるため、その方向に直交する任意のベクトルを構築することが常に可能であり、単純な座標交換構築により、範囲内で非ゼロの結果が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    x1, y1, z1 = map(int, input().split())
    x2, y2, z2 = map(int, input().split())

    # cross product
    x = y1 * z2 - z1 * y2
    y = z1 * x2 - x1 * z2
    z = x1 * y2 - y1 * x2

    if x != 0 or y != 0 or z != 0:
        print(x, y, z)
        return

    # fallback: vectors are collinear
    if x1 != 0 or y1 != 0:
        print(y1, -x1, 0)
    else:
        print(0, z1, -y1)

if __name__ == "__main__":
    solve()
```中心となる計算は外積であり、整数演算で直接実装されます。 これにより、一定時間内の正確さが保証されます。 フォールバック ブランチは、共線性によりすべての外積コンポーネントが相殺される縮退ケースを処理します。 

フォールバック構築`(y1, -x1, 0)`との内積があるため、 が選択されます。`(x1, y1, z1)`単純化すると`y1*x1 - x1*y1 = 0`に関係なく直交性を確保します。`z1`。 最初の 2 つの座標が両方とも 0 の場合、ベクトルは z 軸上にあるため、xy 平面内の任意のベクトルが機能します。`(0, z1, -y1)`それでもゼロ以外の直交方向が保証されます。

 ## 特殊なケース

 2 つのベクトルが平行である場合、外積はゼロになるため、一次構築は失敗します。 たとえば、入力`(1, 2, 3)`そして`(2, 4, 6)`収量`(0, 0, 0)`。 アルゴリズムがこれを検出し、次のように切り替えます。`(y1, -x1, 0) = (2, -1, 0)`。 直接チェックにより直交性が確認されます。`2*1 + (-1)*2 + 0*3 = 0`。 

ベクトルが純粋に 1 つの軸上にある場合、次のようになります。`(1, 0, 0)`そして`(2, 0, 0)`、同じフォールバックが生成します`(0, 1, 0)`、非ゼロで垂直であることが保証されます。 入力ベクトルでは 1 つの座標のみがアクティブであるため、内積はすぐに 0 になります。 

ベクトルが Z 軸上にある場合、次のようになります。`(0, 0, 5)`そして`(0, 0, 7)`、フォールバック ブランチ`(0, z1, -y1)`生成する`(0, 5, 0)`、その内積は、構築されたベクトル内でゼロである z 成分のみに依存するため、直交します。
