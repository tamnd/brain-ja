 ## 解決策
 ## 問題の理解

 アリョナは、中央のピースを中心に正方形のパズルを層ごとに構築します。 

最初のレイヤーは中央のピースのみで構成されているため、タイルが 1 つ含まれています。 後の各レイヤーは、前のパズルの周囲に完全な正方形のリングを形成します。 毎日、彼女は配列で指定された数のピースを追加します。`a`。 

Alyona は、これまでに組み立てたピースの総数が正確に正方形の層を完成させると、1 日の終わりに満足します。 あるレイヤーを終了し、同じ日にすぐに次のレイヤーを開始しても、その日の終わりには未完成のレイヤーがすでに存在するため、彼女は満足しません。 

毎日配置されるピースの数が与えられ、層の境界で正確に終わる日数を数えなければなりません。 

重要な観察は、正方形の層の形状から得られます。 いくつかの層を完成させた後、組み立てられたパズルは常に完全な正方形になります。 レイヤー終了後の総ピース数`k`は$$1, 9, 25, 49, 81, \dots$$これらはまさに奇数正方形です。$$1^2,\; 3^2,\; 5^2,\; 7^2,\dots$$つまり、配置されたピースの累積数が奇数の完全正方形になったときこそ、その日は幸せです。 

制約は非常に小さいです。 各テスト ケースの期間は最大 100 日で、テスト ケースの数は最大 500 です。 1 日に少量の作業を実行するアルゴリズムでも、十分に高速です。 課題は、正方形の層の背後にある数学的パターンを認識することです。 

よくある間違いは、ピースの累積数が完全な正方形であるかどうかを確認することです。 奇数の正方形のみが完成したレイヤーに対応します。 

考慮する：```
1
2
1 3
```累積合計は次のとおりです。`1`そして`4`。 その間`4`は完全正方形ですが、奇数正方形ではないので、2日目は満足できません。 正しい答えは次のとおりです。```
1
```もう 1 つの簡単な間違いは、その日の追加中にレイヤーが完了するたびに 1 日を数えるということです。 幸福は一日の終わりの状態によって決まります。 

例えば：```
1
2
1 10
```累積合計は次のとおりです。`1`そして`11`。 2日目は通過します`9`、これでレイヤーが完成しますが、次で終わります。`11`、次の層がすでに開始されています。 正しい答えは次のとおりです。```
1
```## アプローチ

 ブルート フォース ソリューションでは、レイヤー サイズを直接シミュレートできます。 

センターは1枚貢献します。 次の層が貢献します。$$8,\;16,\;24,\;32,\dots$$なぜなら周囲の長さは辺の長さの正方形のリングによって追加されるからです$2k+1$は$8k$。 

レイヤーの境界を生成し続け、毎日の後にピースの累積数がそれらの 1 つと等しいかどうかを確認できます。 これは正しいです。なぜなら、レイヤーの境界は、各リングを終了した後の正確な合計だからです。 

これは指定された制約に対して機能しますが、明示的に生成されるジオメトリック レイヤー情報に依存しています。 

より洗練された観察は、完成したレイヤーは常に奇数辺の長さの正方形を形成するということです。$$1 \times 1,\; 3 \times 3,\; 5 \times 5,\; 7 \times 7,\dots$$したがって、完成したレイヤーのピースの総数は次のようになります。$$1^2,\;3^2,\;5^2,\;7^2,\dots$$問題はすぐに次のようになります。 

「接頭辞の和が奇数の完全平方になるものがいくつあるか数えてください。」

 最大合計個数はわずかですので、$100 \times 100 = 10000$、10000 までのすべての奇数平方を事前計算し、セット内のメンバーシップを確認できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n + 層の数) | お(1) | 承認済み |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 10000 までの奇数の完全二乗をすべて事前計算し、セットに保存します。 
2. テスト ケースごとに、実行中のプレフィックス合計を初期化します。`s = 0`。 
3. 日付を順番に処理します。 
4.当日に置いた個数を`s`。 
5. かどうかを確認します。`s`奇数正方形の集合に属します。 
6. そうであれば、パズルは完成したレイヤーで正確に終了するため、答えを増やします。 
7. すべての日数が処理された後、回答を出力します。 

### なぜ効果があるのか

 完成したパズル層は常に一辺の長さが奇数の正方形を形成します。 最初の層を完了すると、次のようになります$1^2$2 番目の層を完了すると、次のようになります。$3^2$3 番目の層を完了すると、次のようになります。$5^2$断片など。 

逆に、すべての奇数の正方形は、完全に完成したレイヤーのコレクションに対応します。 したがって、配置されたピースの累積数が奇数の正方形に等しいとき、その日はまさに幸せです。 アルゴリズムはその日数を正確にカウントするため、過剰にカウントしたり、過少にカウントしたりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# all possible totals are at most 100 * 100 = 10000
odd_squares = set()
k = 1
while k * k <= 10000:
    odd_squares.add(k * k)
    k += 2

t = int(input())

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    s = 0
    ans = 0

    for x in a:
        s += x
        if s in odd_squares:
            ans += 1

    print(ans)
```最初のセクションでは、プレフィックスの合計として現れる可能性のあるすべての奇数平方を事前計算します。 ピースの総数が 10000 を超えることはないため、その制限までの奇数マスのみが必要です。 

各テスト ケースの変数は、`s`これまでに組み立てた累積ピース数を保存します。 1 日の処理後に、この累計が奇数の 2 乗に等しいかどうかを確認します。 

セットを使用すると、メンバーシップ チェックが平均して一定時間になります。 平方根計算は必要ないため、実装が単純になり、浮動小数点の問題が回避されます。 

境界条件は単純です。 初日は常に 1 個だけ寄与するため、最初のプレフィックスの合計は次のようになります。`1`、これは最初の奇数正方形として正しく認識されます。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    odd_squares = set()
    k = 1
    while k * k <= 10000:
        odd_squares.add(k * k)
        k += 2

    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        s = 0
        ans = 0

        for x in a:
            s += x
            if s in odd_squares:
                ans += 1

        out.append(str(ans))

    return "\n".join(out)

 ## 特殊なケース

 次のことを考慮してください。```
1
2
1 3
```プレフィックスの合計は次のとおりです。`1`そして`4`。 完全な正方形をチェックする不用意なソリューションでは、両方の日がカウントされてしまいます。 アルゴリズムは奇数平方セット内のメンバーシップをチェックするため、`1`カウントします。 出力は次のとおりです。```
1
```考慮する：```
1
2
1 10
```プレフィックスの合計は次のとおりです。`1`そして`11`。 2 日目には累計が通過します`9`、しかし、その日は次で終わります。`11`。 幸福はその日の最終的な状態にのみ依存します。 以来`11`が奇数の正方形ではない場合、アルゴリズムは最初の日のみをカウントします。```
1
```考慮する：```
1
2
1 8
```プレフィックスの合計は次のとおりです。`1`そして`9`。 どちらも奇数の正方形で、完全に完成したレイヤーに対応します。 アルゴリズムは日数と出力の両方をカウントします。```
2
```これにより、完成した正方形から次の正方形への移行を含め、正確なレイヤー境界が正しく認識されることが確認されます。
