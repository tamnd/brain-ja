 ## 問題の理解

 複数のクエリが与えられ、各クエリは 2 つの正の整数を提供します。これらは、長方形グリッドまたは 2 つの独立した範囲の寸法と考えることができます。 各ペアごとに$(n, m)$、タスクは、これらの範囲の約数のすべての組み合わせに対して数理論的な合計を計算することです。ここで、各ペアの寄与は、最大公約数の構造と乗法特性にのみ依存します。 

提供されたソリューション コードに隠された構造を解釈すると、本当の目標は次の形式の関数を評価することです。$$\sum_{i=1}^{n} \sum_{j=1}^{m} f(\gcd(i, j))$$どこ$f$は、オイラーのトーティエント関数とモジュラー逆関数から導出される乗法関数です。 メビウスの反転と再配置の後、式は、次のようにグループ化された値のみに依存する除数和形式に崩壊します。$\lfloor n / d \rfloor$そして$\lfloor m / d \rfloor$。 これが問題を実現可能にする重要な変換です。 

コードによって暗示される入力サイズは重要であり、事前計算は最大で約$10^6$。 これにより、二重ループが即座に排除されます。$n$そして$m$クエリごとに。 ナイーブ$O(nm)$あるいは$O(n \log n)$クエリごとのアプローチは、多くのテスト ケースで繰り返すと非常に遅くなります。

素朴な推論による微妙な失敗例は、次の等しい値によるグループ化を無視することです。$\lfloor n / i \rfloor$。 たとえば、次の場合$n = 10$、 それから$\lfloor 10 / i \rfloor$changes only at specific breakpoints. すべてを治療する$i$独立して同一の寄与を過大評価し、次の要因が発生します。$O(n)$クエリごとの速度の低下。

 ## アルゴリズムのチュートリアル

 実装は、前処理とクエリ応答の 2 つのフェーズで構成されます。 

1. オイラーの合計値を固定最大値まで事前計算します。$N$。 変換された式は次のものに依存するため、これが必要です。$\varphi(i)$、共素構造をエンコードします。 直線ふるいが使用されるため、これは次のように行われます。$O(N)$。 
2. 最大のすべての整数のモジュラー逆元を事前計算します。$N$。 これらは、最終的な式に正規化された高調波のような項と二乗逆寄与が含まれるために表示されます。 
3. 補助配列を構築する$p[i]$、変換された乗法項の接頭辞の合計を格納します。$\varphi(i)$そして$\text{inv}(i)^2$。 この配列は、メビウス反転後の gcd 加重成分の累積寄与を表します。 
4. 別のプレフィックス配列を構築する$preinv[i]$、モジュラー逆行列の接頭辞の合計を格納します。 これにより、後で次の形式の範囲にわたる合計を高速に計算できるようになります。$\sum 1/k$モジュール形式で。 
5. 各クエリについて$(n, m)$、 確保する$n \le m$。 分解は次の要素に依存するため、これによりループ内のブロック遷移の数が減ります。$\lfloor n / i \rfloor$そして$\lfloor m / i \rfloor$、小さい次元が支配的になります。 
6. 反復処理$i$両方が含まれるブロック内$\lfloor n / i \rfloor$そして$\lfloor m / i \rfloor$一定のままです。 適切なエンドポイント$r$は、どちらかの商が変化する最小位置として計算されます。 
7. 各ブロックについて、プレフィックスの合計の差として寄与を計算します。$p[r] - p[l-1]$に対応する値を乗算します。$preinv[n / i]$そして$preinv[m / i]$。 これにより、ブロック内のすべてのインデックスの寄与が一定時間内に分離されます。 
8. 結果を剰余として累積します。$998244353$を選択して出力します。 

正確さは、各ブロック内で次の値が存在するという事実に依存します。$\lfloor n / i \rfloor$そして$\lfloor m / i \rfloor$は一定であるため、そのセグメント内のすべてのインデックスの乗算寄与を因数分解できます。 

### なぜ効果があるのか

 核となる不変条件は、メビウス反転後の各整数の寄与が$i$のみに依存する$\lfloor n / i \rfloor$そして$\lfloor m / i \rfloor$、オンではありません$i$自体。 したがって、定数商のペアによって定義されるブロック内のすべてのインデックスは交換可能です。 プレフィックスの合計は、考えられるすべての gcd 寄与に対する累積された重みをエンコードし、ブロッキング ステップにより、各グループが正確に 1 回カウントされることが保証されます。 セグメント間で重複は発生せず、セグメント間のすべての整数は$1$に$n$は 1 回だけカバーされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
N = 10**6 + 5

phi = [0] * N
inv = [0] * N
is_comp = [False] * N
primes = []

def init():
    phi[1] = 1
    inv[1] = 1
    for i in range(2, N):
        inv[i] = (MOD - MOD // i) * inv[MOD % i] % MOD

        if not is_comp[i]:
            primes.append(i)
            phi[i] = i - 1

        for p in primes:
            if i * p >= N:
                break
            is_comp[i * p] = True
            if i % p == 0:
                phi[i * p] = phi[i] * p
                break
            else:
                phi[i * p] = phi[i] * (p - 1)

p = [0] * N
preinv = [0] * N

def solve():
    n, m = map(int, input().split())
    if n > m:
        n, m = m, n

    ans = 0
    l = 1
    while l <= n:
        r = min(n // (n // l), m // (m // l))
        cnt_n = n // l
        cnt_m = m // l

        seg = (p[r] - p[l - 1]) % MOD
        ans = (ans + seg * preinv[cnt_n] % MOD * preinv[cnt_m]) % MOD

        l = r + 1

    print(ans % MOD)

def main():
    init()

    for i in range(1, N):
        p[i] = (p[i - 1] + inv[i] * inv[i] % MOD * phi[i]) % MOD
        preinv[i] = (preinv[i - 1] + inv[i]) % MOD

    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```初期化フェーズでは、線形ふるいと漸化を使用してオイラーのトーティエントとモジュラー逆行列を構築します。 配列`p`そして`preinv`は、変換された算術関数のプレフィックス累積であり、定数時間のセグメント評価を可能にします。 

各クエリ内では、2 次元の合計が商ブロックにわたる 1 次元のスイープに折りたたまれます。 主要な実装の詳細は、次の計算です。`r = min(n // (n // l), m // (m // l))`以内であることを保証します。`[l, r]`、両方のフロア区分は一定のままです。 

最終的な乗算`preinv[cnt_n]`そして`preinv[cnt_m]`各商状態に対応する事前計算された高調波のような寄与を適用します。

 ## 特殊なケース

 重大なエッジケースは、一方の次元がもう一方の次元よりもはるかに大きい場合です。 例えば、$n = 1$そして$m = 10^6$。 この場合、ループは単一の長いブロックに折りたたまれます。$\lfloor 1 / i \rfloor = 1$みんなのために$i$。 アルゴリズムはこれを正しく処理します。`r = n`すぐに 1 つのセグメントが生成されます。 

もう 1 つのエッジケースは次のような場合です$n = m$。 ここでは、対称性により、スワップが何も起こらず、商ブロックが完全に整列することが保証されます。 たとえば、次のようなとき$n = m = 16$、ブロックは除数ブレークポイントによってのみ決定されます。$1, 2, 4, 8, 16$、それぞれが重複することなく 1 回だけ処理されます。
