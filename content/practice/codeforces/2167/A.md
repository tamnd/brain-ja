 ## 問題の理解

 テスト ケースごとに 4 つのスティックの長さが与えられており、これら 4 つのスティックを配置して正方形の境界を形成できるかどうかを知りたいと考えています。 各スティックはセグメント全体として使用する必要があり、それらを切断したり変形したりすることは許可されていないため、唯一の自由は各スティックを正方形の 1 辺に割り当てる方法だけです。 

正方形には同じ長さの 4 つの辺があります。 棒を組み合わせているわけではないので、各辺は正確に 1 つの棒に対応する必要があります。これは、指定された 4 つの長さが集合的に正方形の 4 つの等しい辺を表す必要があることを意味します。 

これにより、順序は重要ではないため、並べ替えの必要さえなくなり、タスクが 4 つの数値すべてを等しくできるかどうかを確認するだけになります。 

テスト ケースごとの制約は小さく、それぞれの長さは 1 ～ 10 ですが、テスト ケースの数は 10^4 に達する可能性があります。 これにより、テストごとに O(1) または O(log n) のソリューションが実現されます。これは、テストごとのリニア スキャンでさえ簡単ですが、組み合わせチェックを伴うものは不要になるためです。 

微妙な失敗例は、誰かがスティックを「ペアリング」したり、精神的に組み合わせたりするなど、過度に柔軟になろうとしたときに発生します。 たとえば、入力の場合`1 2 1 2`, 等しい値をペアにすることで正方形の反対側を形成できると考える人もいるかもしれません。 ただし、これは無効です。各辺が正確に 1 つの棒である必要があり、バランスの取れたペアで表示される場合でも、等しくない値は正方形を形成できません。 

もう一つの誤解を招くケースは、`1 1 5 5`。 長方形の直感に似ているかもしれませんが、正方形では 4 つの辺がすべて等しい必要があるため、これはまだ不可能です。 

## アプローチ

 強引な解釈では、各スティックを 4 つの辺のいずれかに割り当てて、有効な正方形が形成できるかどうかを確認することになります。 ただし、正方形の 4 つの辺はすべて等しい必要があるため、4 つのスティックすべてを使用する割り当てでは、選択されたすべての辺の長さが正確に一致する必要があるという 1 つの条件が直ちに強制されます。 

より一般的な強引なアイデアは、スティックの割り当てを側面に並べ替えることです。しかし、スティックは 4 つしかないので、これは最大でも 4 つです。 = 24 のアレンジメント。 配置ごとに、すべての辺が等しいかどうかを確認します。 これはすでにテスト ケースごとに一定の作業であるため、単純なアプローチでも事実上十分です。 

重要な単純化は、順列が無関係であることを認識することです。 4 つの辺はすべて同一である必要があるため、重要なプロパティは 4 つの値がすべて等しいかどうかだけです。 並べ替えはオプションですが、並べ替えを行わない場合でも、すべての要素の同等性をチェックするだけです。 

これにより、問題は 1 つの比較に集約されます。つまり、最大値が最小値と等しい、つまりすべての値が同一になります。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの 4 つのスティックの長さを読み取ります。 順序は関係ない小さなマルチセットとして扱います。 
2. 4 つの値がすべて等しいかどうかを確認します。 これは、各値を最初の値と比較することで実行できます。 
3. すべての比較が成功すると、すべてのスティックが正方形の等しい辺として機能するため、「YES」が出力されます。 
4. それ以外の場合は、少なくとも 1 つの辺の長さが異なり、スティックを切断または修正しないと正方形を作成できないため、「いいえ」を出力します。 

### なぜ効果があるのか

 正方形の境界は、正確に 4 つの等しい長さのエッジで構成されます。 各入力スティックは単一のエッジとして使用する必要があるため、有効な構成は 4 つの入力値がすべて同一であることだけです。 スティックの結合は許可されていないため、再配置やグループ化によってこの制約を変更することはできません。 したがって、4 つの値すべてが等しいことが必要かつ十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c, d = map(int, input().split())
    if a == b == c == d:
        print("YES")
    else:
        print("NO")
```このソリューションは、各テスト ケースを個別に読み取り、一定時間の比較チェーンを実行します。 連鎖的な等価性チェック`a == b == c == d`4 つの側面がすべて一致するという条件を直接強制し、並べ替えや余分なデータ構造を回避します。 

問題は配置に依存せず、平等性だけに依存するため、特別な順序付けや前処理は必要ありません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    t = int(input())
    out = []
    for _ in range(t):
        a, b, c, d = map(int, input().split())
        out.append("YES" if a == b == c == d else "NO")
    return "\n".join(out)

## 特殊なケース

 微妙なケースの 1 つは、3 つのスティックが等しく、1 つが異なる場合です。`5 5 5 4`。 アルゴリズムは順番に比較します。`a == b == c == d`失敗する`c == d`なので、正しく NO が出力されます。 これは、部分的な均一性が不十分であることを確認します。 

別のケースは、次のような値を交互に使用することです。`2 3 2 3`。 マルチセットのバランスが取れている場合でも、等価性チェーンは次の時点ですぐに失敗します。`a == b`、NOを生成します。 これは、周波数バランスが重要ではないことを示しています。 構造的な平等性が求められます。 

のような最大均一のケース`10 10 10 10`すべての比較を問題なく通過し、境界値が小さい値と同じように動作することを確認します。
