 ## 解決策
 ## 問題の理解

 2 つの文字列が与えられています。`s`そして`t`、それぞれの長さ`n`。 最初の文字列は文字付き立方体の行を表し、2 番目の文字列はターゲット名です。 タスクは、次の文字を並べ替えることが可能かどうかを判断することです。`s`正確に一致する`t`。 基本的に、次のことを確認しています。`t`の順列です`s`。 

制約は小さいです。`n`は最大 20 で、最大 1000 のテスト ケースが可能です。 これは、三次または階乗の演算を行う余裕があることを意味します。`n`単一のテスト ケースの場合ですが、単純な方法の方が高速かつクリーンです。 入力文字列には小文字のみが含まれるため、文字の頻度をチェックするソリューションであればどれでも十分です。 

文字列に繰り返し文字が含まれている場合、微妙な特殊なケースが発生します。 例えば、`s = "aaab"`そして`t = "abaa"`文字の量が一致するため、「YES」が返されるはずですが、頻度を考慮せずにソートされた文字列を 1 文字ずつ比較する単純なチェックは、実装が間違っていると失敗する可能性があります。 もう一つのケースは次のような場合です。`s`そして`t`文字は同じですがカウントが異なります。たとえば、`s = "abc"`そして`t = "aab"`、「NO」を返す必要があります。 

## アプローチ

 ブルートフォースアプローチは、次のすべての順列を生成することです。`s`等しいものがあるかどうかを確認します`t`。 これは文字通りあらゆる可能な再配置をテストするため正しいですが、その複雑さは次のとおりです。`O(n!)`テストケースごとに。 たとえ`n = 20`、20 階乗はおよそ 2.4 × 10^18 の演算であるため、これは完全に実行不可能です。 明らかに、より高速な方法が必要です。 

重要な点は、文字の順序は重要ではなく、文字の数だけが重要であるということです。 もし`s`形に並べ替えることができます`t`、 それから`s`そして`t`まったく同じ文字が同じ頻度で含まれている必要があります。 これにより、問題は単純な周波数比較に集約されます。 これを行う便利な方法の 1 つは、両方の文字列を並べ替えて文字ごとに比較することです。 あるいは、長さ 26 (「a」から「z」) の配列を使用して各文字の出現をカウントし、そのカウントを比較することもできます。 どちらの方法も、時間計算量が線形またはほぼ線形です。`n`、サイズが小さいことを考えると非常に高速です`n`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | 並べ替えと比較 | O(n log n) | O(n) | 承認済み |
 | 周波数をカウントする | O(n) | お(26) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取り、`q`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして2本の弦`s`そして`t`。 
3. 両方の文字列を並べ替えます。 ソートにより、文字が辞書編集順に配置されます。 もし`s`に並べ替えることができます`t`、それらのソートされたバージョンは同一である必要があります。 
4. ソートされた文字列を比較します。 それらが完全に等しい場合は、「YES」を出力します。 それ以外の場合は「NO」を出力します。 

機能する理由: 並べ替えは、並べ替えの問題を線形比較に変換します。 文字数または文字の不一致は、ソートされた文字列に表示され、正確さが保証されます。 不変条件は、ソートされた文字列が複数の文字セットを保持することです。 マルチセットが同一の場合、一方の文字列は他方の文字列の順列になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

q = int(input())
for _ in range(q):
    n = int(input())
    s, t = input().split()
    if sorted(s) == sorted(t):
        print("YES")
    else:
        print("NO")
```このソリューションは、テスト ケースの数を読み取ることから始まり、それぞれを反復処理します。 の`input().split()`call は同じ行から両方の文字列を効率的に読み取ります。 両方の文字列をソートすると、問題は単純な等価性チェックに減ります。 この実装は複数のテスト ケースを正しく処理し、Python の効率的な組み込みソートを活用します。これは、`n <= 20`。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(q * n log n) | 各文字列のソートがコストの大半を占めます。`q`テストケースはこれを掛け算します。 |
 | スペース | O(n) | 並べ替えると、文字列の長さに比例した一時配列が作成されます。 |

 与えられた`q <= 1000`そして`n <= 20`、合計操作は最大 1000 × 20 log 20 ≈ 1000 × 80 = 80,000 であり、1 秒の制限内に十分収まります。

def run(inp: str) -> str:

    for _ in range(q):
        n = int(input())
        s, t = input().split()
        if sorted(s) == sorted(t):
            print("YES")
        else:
            print("NO")
    return output.getvalue().strip()

 ## 特殊なケース

 最小サイズの入力の場合`s = "a"`、`t = "a"`の場合、アルゴリズムは両方を「a」にソートし、「YES」を返します。 もし`t = "b"`、ソートされた文字列が異なり、「NO」が返されます。 繰り返される文字の場合、次のようになります。`s = "aabb"`そして`t = "abab"`、並べ替えの結果は両方の文字列で「aabb」となり、アルゴリズムが一意の要素だけでなく複数の文字セットを正しく処理していることが確認できます。
