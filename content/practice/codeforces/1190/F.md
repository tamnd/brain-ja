 ## 問題の理解

 非常に具体的なルールに基づいて、考えられるパスワードのセットを生成するように求められます。 ロックは次の範囲の整数を受け入れます。`0`そして`m-1`。 候補番号が何らかの要素と共有する場合、その候補番号は無効です。`m`1 以外、または次のように表現できる場合`p^e mod m`負でない整数の指数の場合`e`、 どこ`p`は私たちに与えられた秘密の番号です。 私たちの仕事は、次のいずれかを生産することです。`n`有効なパスワードを使用するか、それが不可能であると宣言します。 

以来`m`は素数であり、すべての数は以下と素になります。`m`乗法群を法として形成する`m`。 これは、以下と互いに素な数値を生成することに集中できるため、非常に重要です。`m`そして、力として現れるものをすべて排除します。`p`。 

境界は極端です:`m`まで行くことができます`10^18`そして`n`まで`5*10^5`。 これにより、範囲全体にわたるブルートフォース反復が排除されます。`[0, m-1]`。 どのソリューションでも数値を線形に列挙することを避け、代わりに次のような構造を利用する必要があります。`m`第一の力であること。 

エッジケースは微妙です。 もし`p`それ自体は`1`とすると、すべての力は`1`、のみの意味`1`は共素集合では禁止されています。 もし`p`～と因子を共有する`m`、次の累乗`p`は常に次の素数の倍数です`m`、これらはすでに無効です。 もし`n`は有効な数値のカウントより大きいため、これを検出して出力する必要があります。`-1`。 

たとえば、次の場合`m = 2`そして`p = 1`のすべての数字`[0,1]`は互いに素でない（`0`) または次の乗`p`(`1`)、パスワードは存在しません。 

## アプローチ

 ブルート フォースのアプローチは簡単です。次のすべての数値を反復処理します。`0`に`m-1`、それらが互いに素であるかどうかを確認します`m`、それらがどれにも等しくないことを確認します`p^e mod m`。 これは正しいですが、それはまったく不可能です`m`近く`10^18`。 反復処理`10^18`値を格納することさえ不可能であり、`p`セットとしてメモリがオーバーフローする可能性があります。 

重要な洞察は次のとおりです`m`は素数累乗であるため、その互いに素な剰余は正確に素数の基数で割り切れない数になります。`q`。 させて`m = q^k`。 それから`x`と互いに素である`m`もし、そしてその場合に限り`q`分けない`x`。 他のすべての番号は自動的に無効になります。 これにより、検索スペースが大幅に減少します。 さらに、次のような力に焦点を当てることができます。`p`モジュロ`m`と互いに素である`m`。 もし`p`で割り切れます`q`、そのべき乗の剰余`m`も割り切れます`q`したがって、有効なセットには決して含まれないため、削除は必要ありません。 もし`p`と互いに素である`m`、その累乗は乗法群モジュロの巡回部分群を形成します。`m`これにより、セットを使用して禁止されたパワーを効率的に列挙することができます。 

これにより、問題は最初の生成に変換されます。`n`の数字`[0, m-1]`と互いに素である`m`そして力のセットには含まれていません`p`。 互いに素な数のモジュロなので、`m`は`m - m//q`、まず、十分な有効な数値が存在するかどうかを確認できます。 「はい」の場合、それらを列挙し、禁止された権限をスキップします。

 ## アルゴリズムのチュートリアル

 1. 素数基数を計算する`q`の`m`。 以来`m`第一大国であることが保証され、分裂を繰り返す`m`1 が残るまで最小の素因数で計算します。 店`q`。 
2. 禁止された数値のセットを生成します。 空のセットを初期化します。 もし`p`と互いに素である`m`、計算する`p^e mod m`増やすための`e`繰り返しが発生するまで、各値を禁止されたセットに追加します。 もし`p`で割り切れます`q`、力`p`モジュロ`m`は常に次の倍数です`q`すでに除外されているため、この手順はスキップしてください。 
3. 有効な数値の合計数を計算します。`[0, m-1]`と互いに素である`m`禁止されたセットを差し引いたもの。 この数が以下の場合`n`、印刷`-1`そして出ます。 
4. 以下の数値を列挙します。`0`に`m-1`。 割り切れる数をスキップする`q`。 禁止されたセット内の番号をスキップします。 長さに達するまで数値を結果リストに収集します`n`。 
5. を印刷します。`n`数字。 

不変条件は、収集されたすべての数値が以下と素であるということです。`m`そして力ではありません`p`モジュロ`m`。 昇順に繰り返し、無効な数値をスキップするため、結果には正確に次の値が含まれます。`n`有効な個別のパスワード。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, p = map(int, input().split())
    
    # Step 1: find prime base q
    q = None
    x = m
    for i in range(2, int(m**0.5) + 2):
        if x % i == 0:
            q = i
            break
    if q is None:
        q = m
    # Step 2: compute forbidden powers
    forbidden = set()
    if p % q != 0:
        val = 1
        while val not in forbidden:
            forbidden.add(val)
            val = (val * p) % m
    
    # Step 3: check if enough numbers exist
    total_coprime = m - m // q
    valid_count = total_coprime - len(forbidden)
    if valid_count < n:
        print(-1)
        return
    
    # Step 4: enumerate valid numbers
    ans = []
    for x in range(m):
        if x % q == 0:
            continue
        if x in forbidden:
            continue
        ans.append(x)
        if len(ans) == n:
            break
    
    print(' '.join(map(str, ans)))

if __name__ == "__main__":
    solve()
```解決策はまず、次の主要な塩基を特定します。`m`、次に、禁止されたセットを効率的に構築します。 大型用`m`、反復は範囲全体ではなく、互いに素な数に限定されるため、アルゴリズムの高速性が維持されます。 私たちは、次の繰り返しの力を保証します。`p`サイクルを検出するためのセットを使用して処理されます。
