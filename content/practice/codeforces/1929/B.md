 ## 解決策
 ## 問題の理解

 私たちは、$n \times n$グリッド。 すべてのセルは、2 つの対角方向のそれぞれの 1 つの対角線に正確に属します。 この問題では両方向がカウントされるため、グリッドには合計が含まれます。$2n-1$1 種類の対角線と$2n-1$他のタイプの対角線、合計$4n-2$対角線。 

少なくとも、色を付けるセルをできるだけ少なくしたいと考えています。$k$これらの対角線のうち、色付きのセルが含まれています。 少なくとも 1 つの色の付いたセルが対角線上にある場合、その対角線は覆われているとみなされます。 

入力により、いくつかのテスト ケースが得られます。 テスト ケースごとに、グリッド サイズを受け取ります$n$そして必要な数$k$覆われた対角線の。 色を付ける必要があるセルの最小数を出力する必要があります。 

制約は、単純な式を使用して答えを計算する必要があることを即座に示唆します。 グリッドのサイズは次のとおりです$10^8$そのため、実際にグリッドを構築するアプローチは不可能になります。 すべての対角線を反復処理する場合でも、テスト ケースごとに実行するとコストがかかりすぎます。 まであり得るので、$1000$テスト ケースでは、ターゲットの複雑さは基本的にケースごとに一定の時間です。 

微妙な点は、単一の色のセルが各方向から 1 つずつ、最大 2 つの対角線をカバーできることです。 不注意な解決策では、すべての色付きセルが常に 2 つの新しい対角線に寄与すると想定する可能性がありますが、これは、ほぼすべての対角線がすでにカバーされている最後の近くで当てはまらなくなります。 

考慮する$n=2$、$k=3$。 がある$6$対角線の合計。 最大でも 1 つの色付きセルでカバーできる$2$対角線なので 2 つのセルが必要です。 正しい答えは、$2$、 ない$\lceil 3/2 \rceil = 2$単なる偶然です。 これが一般的に有効であるという証拠が必要です。 

次の場合には、別のエッジケースが発生します。$k$は最大値に非常に近いです。 例えば、$n=3$、$k=10$。 グリッドには正確に$10$対角線。 答えは$6$、 ない$5$。 理論的には、5 つのセルで最大 10 個の対角線をカバーできますが、中央のセルは最も長い対角線の両方に同時に存在する唯一のセルであるため、最後に残った対角線をカバーするには追加のセルが 1 つ必要になります。 グリッドの構造が重要です。 

## アプローチ

 強引な観点は、各セルが 2 つの対角線をカバーしていると考えることです。 カバーする必要があるオブジェクトとして対角線をモデル化し、カバーされた対角線が少なくとも到達するセルの最小セットを検索できます。$k$。 これは基本的に、$n \times n$グリッド。 

中程度の値であっても、$n$、 がある$n^2$細胞。 と$n$と同じくらい大きい$10^8$、グリッドには以下が含まれます$10^{16}$したがって、セルを個別に検査するアルゴリズムは完全に実行不可能です。 

重要な観察点は、グリッドの中心の対角線には正確に次の要素が含まれていることです。$n$細胞。 この対角線上のすべてのセルは、別個の主対角線に属します。 同時に、それらはすべて同じ対角線に属します。 

この対角線に沿ってセルに色を付けると、通常、新たに色付けされた各セルは、以前にカバーされていなかった 2 つの対角線、つまり 1 つの新しい主対角線と共通の対角線に寄与します。 最初の色のセルは 2 つの対角線をカバーします。 共有の対角線がすでにカバーされているため、同じ対角線上のすべての追加セルは、正確にもう 1 つの新しい対角線に寄与します。 

これですべてをカバーできます$2n$それらに関連付けられた対角線$n$正確に使用しているセル$n$色付きのセル。 さらに重要なことは、$2n$カバーされた対角線の場合、対角線のすべてのペアを 1 つのセルで取得できます。 したがって、$k \le 2n$、答えは簡単です。$\lceil k/2 \rceil$。 

結局$2n$この構造の対角線はカバーされますが、残りのカバーされていない対角線ごとに追加のセルが 1 つ必要になります。 がある$4n-2-2n = 2n-2$このような対角線。 したがって、$k > 2n$、私たちは最初に費やします$n$カバーする細胞$2n$対角線を作成し、残りの必要な対角線ごとに 1 つの追加セルを追加します。 

それにより式が得られます$$\text{answer}= \begin{cases} \left\lceil \frac{k}{2}\right\rceil, & k\le 2n \\ n + (k-2n), & k>2n \end{cases}$$| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^2)$それより悪い |$O(n^2)$| 遅すぎる |
 | 最適 |$O(1)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む$n$そして$k$。 
2. かどうかを確認します。$k \le 2n$。 
3. そうであれば、戻ります$\lceil k/2 \rceil$。 整数演算ではこれは$(k+1)//2$。 
4. それ以外の場合は、$n$最初をカバーするセル$2n$対角線。 
5. さらに必要な対角線の数を計算します。$$k - 2n.$$6. 残りの対角線にはそれぞれ追加の色付きセルが 1 つ必要なので、リターンします。$$n + (k-2n).$$### なぜ効果があるのか

 色付きのセルは最大 2 つの対角線をカバーできます。 その間$k \le 2n$、色付きの各セルが 2 つの新しい対角線に寄与するように、いつでもセルを選択できます。$\lceil k/2 \rceil$達成可能かつ最適です。 

アンチダイアゴナル構造が正確に届きます$2n$を使用して覆われた対角線$n$細胞。 それらの後$2n$diagonals are exhausted, every remaining uncovered diagonal can only increase the count by one per added cell. Thus each additional required diagonal costs one additional colored cell. The formula matches both the lower bound and an explicit construction, so it is optimal.

 ## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, k = map(int, input().split())

    if k <= 2 * n:
        print((k + 1) // 2)
    else:
        print(n + (k - 2 * n))
```実装は式に直接に従います。 

最初の分岐は、2 つの新しい対角線をカバーするようにすべての色付きセルを配置できる領域を処理します。 使用する`(k + 1) // 2`浮動小数点演算を行わずに上限除算を実行します。 

2 番目の分岐は、最初の分岐が発生する状況に対応します。`2 * n`対角線はすでに使用してカバーされています`n`細胞。 必要な対角線が追加されるたびに、ちょうど 1 つ多くのセルが必要になるため、次のように追加します。`k - 2 * n`に`n`。 

すべての計算は 64 ビット整数に快適に収まります。 Python の整数には制限がないため、オーバーフローの心配はありません。

import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n, k = map(int, input().split())

        if k == 4 * n - 2:
            ans.append(str(2 * n - 1))
        else:
            ans.append(str((k + 1) // 2))

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out
