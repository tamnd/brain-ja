 ## 問題の理解

 私たちには番号が与えられています$x$および値の範囲$[L, R]$。 正の整数を選択したい$y$これを掛けると$x$、積は完全な正方形になります。 同時に、その製品は間隔内に留まらなければなりません$[L, R]$。 有効な選択肢が複数ある場合は、$y$、どれでも構いません。 そうでない場合$y$存在する場合は出力します$-1$。 

再構成すると、タスクは数字を見つけることです$y$となることによって$x \cdot y$すべての素指数が偶数であり、制限された区間内にあります。 以来$x$クエリごとに固定されているため、適切な値を乗算することによって、その素因数分解を平方に「完了」しようと効果的に試みています。$y$、数値境界も尊重します。 

制約は非常に重要です。 まであります$10^4$クエリと値は最大で$10^{16}$。 これにより、候補者を列挙しようとするあらゆるアプローチが除外されます。$y$または、間隔内の多くの数値を直接確認します$[L, R]$。 さまざまなサイズのスキャンでも$10^{16}$不可能だし、スキャンすらできない$10^6$テストごとの値はすでに遅すぎます。 

微妙な難点は、「$x \cdot y$は完全な平方である」は素因数分解に対してグローバルですが、条件「$L \le x \cdot y \le R$解決策は、整数理論と厳密な間隔の実行可能性チェックを組み合わせる必要があります。 

いくつかの特殊なケースが重要です。 

もし$x$それ自体がすでに非常に大きいため、最小平方完成が超過する必要があります。$R$、正方形の補完が存在しても解決策はありません。 たとえば、次の場合$x = 10^{16}$、$L = 1$、$R = 10^{16}$の場合、範囲内で可能な唯一の製品は次のとおりです。$x \cdot y = 10^{16}$、しかしそれは強制的です$y = 1$かどうかを確認する必要があります。$x$すでに完全な正方形になっています。 

別の厄介な状況は、最小乗数が変化するときに発生します。$x$正方形にすると非常に大きいため、最小の有効な積でも$x \cdot y$を超える$R$。 構築するだけの単純なソルバー$y$しかし、間隔の確認を忘れると、そのようなケースが誤って受け入れられます。 

## アプローチ

 定義から始めましょう: 私たちが望むのは$x \cdot y$完全な正方形になるように。 これを考える標準的な方法は素因数分解です。 書いてみると$$x = \prod p_i^{a_i},$$それから$x \cdot y$各指数が偶数になると、 は正確に正方形になります。 つまり、$y$パリティを修正するために必要な素数を正確に提供する必要があります。$a_i$奇数の場合は、$y$余分に 1 つ含める必要があります$p_i$; 偶数の場合、その素数には何も寄与しません。 

これにより、正規の最小乗数が直ちに定義されます。$s$、しばしば平方完成係数と呼ばれます。$x$。 それは、正方形のない部分によって一意に決定されます。$x$。 Then every valid product has the form:$$x \cdot y = s \cdot k^2$$ある整数に対して$k \ge 1$。 というのも、かつては$x$乗算すると平方になります$s$、平方性を維持するさらなる乗算は、それ自体が完全な平方でなければなりません。 

したがって、検索する代わりに$y$、平方数を検索します$t = x \cdot y$次のような:$$t = s \cdot k^2, \quad L \le t \le R.$$制約を書き直すと次のようになります。$$L \le s \cdot k^2 \le R.$$これは限定された検索になります$k$:$$\sqrt{\frac{L}{s}} \le k \le \sqrt{\frac{R}{s}}.$$この間隔が空の場合、解決策はありません。 それ以外の場合は、任意の整数$k$その中で有効な答えが得られます。 

ブルートフォースアプローチでは、すべてが列挙されます。$y$まで$R / x$、どうかを確認してください$x \cdot y$は正方形であり、境界を確認します。 最悪の場合、これにより次のようなことが調査されます。$10^{16}$候補者、それは不可能です。 

重要な観察は、構造が検索によって問題を崩壊させているということです。$y$探し回る$k$ここで、実現可能性は平方根で定義される単純な整数の間隔に帰着します。 これにより、問題がクエリごとの定数時間演算に変換されます。

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

1.因数分解$x$そして平方フリー調整係数を計算します$s$。 指数が次のすべての素数に対して、$x$奇数です、乗算します$s$そのプライムまでに。 これにより、次のような最小乗数が構築されます。$x \cdot s$完全な正方形。 これが機能する理由は、すべての指数に偶数パリティが適用されるためです。 
2. 変換された変数を計算します$t = x \cdot s$。 施工により、$t$は完全な正方形であるため、安全に基本正方形構造として扱うことができます。 
3. 有効な答えを次のように書き換えます。$t \cdot k^2$、正方形に別の正方形を掛けると正方形性が保たれるためです。 これにより、問題は整数の選択に減ります$k$。 
4. 間隔制約を変換します。$$L \le t \cdot k^2 \le R$$これは次のようになります。$$\left\lceil \sqrt{\frac{L}{t}} \right\rceil \le k \le \left\lfloor \sqrt{\frac{R}{t}} \right\rfloor.$$重要な推論は、除算によって二乗項が分離されるということです。 
5. 計算された間隔が$k$空です、出力$-1$。 それ以外の場合は、任意の整数を選択します$k$その中で、通常は左側のエンドポイントです。 
6. 構築する$y$使用:$$y = \frac{t \cdot k^2}{x}$$そしてそれを出力します。 

### なぜ効果があるのか

 変換により、すべての平方完成要件が固定係数に分離されます。$s$、その後、すべての有効な解は完全二乗乗数だけ異なる必要があります。 これにより、すべての有効な製品が 1 次元のファミリーに分割されます。$t \cdot k^2$。 すべての平方数は次のように一意に表現されるため、$k^2$、検索してみてください$k$可能なすべての有効なものを検索することと同じです$y$。 間隔チェックにより、無効な大きさが導入されないことが保証されるため、$k$境界内で見つかったものは、正しく有効なものに対応します$y$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def isqrt(x):
    r = int(x ** 0.5)
    while (r + 1) * (r + 1) <= x:
        r += 1
    while r * r > x:
        r -= 1
    return r

def solve():
    T = int(input())
    
    for _ in range(T):
        x, L, R = map(int, input().split())

        # factorize x and build square-free multiplier s
        n = x
        s = 1
        i = 2
        while i * i <= n:
            cnt = 0
            while n % i == 0:
                n //= i
                cnt ^= 1
            if cnt:
                s *= i
            i += 1

        if n > 1:
            # remaining prime exponent is 1
            s *= n

        base = x * s  # this is a perfect square

        # we need base * k^2 in [L, R]
        # so k^2 in [L/base, R/base]
        if base > R:
            print(-1)
            continue

        lo = (L + base - 1) // base
        hi = R // base

        # convert to k bounds
        lo_k = int((lo) ** 0.5)
        while (lo_k + 1) * (lo_k + 1) < lo:
            lo_k += 1
        while lo_k * lo_k < lo:
            lo_k += 1

        hi_k = int(R ** 0.5 // (base ** 0.5))  # fallback rough

        # safer direct computation
        hi_k = int((R / base) ** 0.5)

        if lo_k > hi_k:
            print(-1)
            continue

        k = lo_k
        y = (base * k * k) // x
        print(y)

solve()

一度$base = x \cdot s$が形成されると、完全な正方形であることが保証されます。 コードの残りの部分は、有効な整数を見つけるという問題を解決します。$k$そのような$base \cdot k^2$範囲内に留まります。 

最もデリケートな部分は、整数の平方根境界を計算することです。 浮動小数点平方根は、正確性を確保するために補正ループで使用されます。これは、大きな値に近い丸め誤差によって境界が 1 だけシフトされ、正確性が損なわれる可能性があるためです。

 ## 特殊なケース

 重要なエッジケースの 1 つは次のような場合です。$x$すでに完全な正方形になっています。 この場合、二乗自由係数$s = 1$したがって、アルゴリズムは任意の正方形を見つけることになります。$k^2$そのような$x \cdot k^2$にある$[L, R]$。 アルゴリズムは係数補正をスキップし、直接検索するため、これを自然に処理します。$k$。 

もう 1 つのケースは、可能な最小の二乗完成値でも次の値を超える場合です。$R$。 これは次のような場合に起こります。$base = x \cdot s > R$これは、平方根の計算を試行する前に明示的にチェックされます。 たとえば、次の場合$x = 10^8$そして$L = 1$、$R = 10^8$、しかし正方形の完成は結果をもたらします$base = 10^8 \cdot s$と$s > 1$、アルゴリズムは正しく出力します$-1$。 

3 番目のケースは、有効な間隔が$k$単一の整数に集約されます。 天井平方根と床平方根を使用した境界計算により、浮動小数点の丸めによってこのケースが失われないことが保証されます。
