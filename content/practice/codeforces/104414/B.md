 ## アルゴリズムのチュートリアル

 恒等式を使用して答えを計算します$\text{answer} = S(n+1, n+1-k)$、 どこ$S$は第 2 種スターリング数です。 

1. 問題を、一連のサイズのパーティションを数えるというものとして再解釈します。$n+1$の中へ$n+1-k$空ではないサブセット。 この再定式化は、階段ボード上の有効なルーク配置の組み合わせ構造と一致します。 
2. 完全な三角形を構築するのではなく、必要な対角線に沿ってのみスターリング値を追跡する DP 配列を定義します。 基本ケースを初期化します$S(0, 0) = 1$、空のパーティションを表します。 
3. 繰り返します$i$1から$n+1$、形式の値のみを維持します$S(i, i - d)$、 どこ$d$固定オフセットは次の値に等しいか$k$。 この圧縮が可能となるのは、ターゲットの列インデックスが行インデックスと常に同じ線形関係に従うためです。 
4. 各ステップで、再配置されたスターリング再帰を使用して対角状態を更新します。$$S(i, j) = S(i-1, j-1) + j \cdot S(i-1, j)$$置き換える$j = i-k$、各更新は以前に計算された対角値のみに依存するため、ローリング計算が可能になります。 
5. に達するまで値を前方に伝播します。$i = n+1$、その時点で目的のエントリが$S(n+1, n+1-k)$直接取得されます。 

これが機能する理由は、すべての Stirling トランジションが新しいシングルトン ブロックを作成するか、新しい要素を既存のブロックの 1 つに挿入するという事実に関係しています。 対角線上に$j = i-k$、ブロックの数は相対的に固定されます。$i$したがって、すべての有効な遷移は、次のインデックスが付いた 1 次元の状態空間内に留まります。$i$。 これにより、すべての有効な構造を維持しながら、完全な 2 次元 DP テーブルへの分岐が防止されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, k = map(int, input().split())
    
    N = n + 1
    K = k
    
    # dp[j] will represent S(i, j) only for the needed diagonal
    # but we only keep a rolling structure for j = i - K
    
    # We instead compute using full 1D diagonal DP:
    # dp[i] = S(i, i-K)
    
    dp = [0] * (N + 1)
    dp[0] = 1  # S(0,0)
    
    for i in range(1, N + 1):
        ndp = [0] * (N + 1)
        limit = i
        for j in range(1, limit + 1):
            val = dp[j - 1]
            val += j * dp[j]
            ndp[j] = val % MOD
        dp = ndp
    
    print(dp[N - K] % MOD)

if __name__ == "__main__":
    solve()
```このコードは Stirling 再帰を直接実装しますが、一度に 1 行のみを追跡します。 重要な実装の詳細は、遷移が前の行の値のみに依存するため、DP 配列を繰り返し上書きできることです。 

インデックス$j = i-k$最後にアクセスされ、必要な斜めのエントリに正確に対応します$S(n+1, n+1-k)$。 

乗算中の剰余演算には注意が必要です$j \cdot dp[j]$、中程度の場合でも値が急速に増加するため、$i$。 DP 配列は、遷移に必要な状態の上書きを避けるために、各ステップで完全に再構築する必要があります。
