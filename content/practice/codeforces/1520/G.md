 **解決時間:** 2 分 14 秒

 ## 解決策
 ## 問題の理解

 ディマが長方形の都市グリッドの左上隅から右下隅まで移動する最小時間を見つけるように求められます。 都市は次のように表されます。`n × m`各セルに値が含まれるグリッド:`-1`ブロックされた場合、`0`無料で、そして`x > 0`有料ポータルの場合`x`。 Dima は時間内に任意の直角に隣接するフリーセルに移動できます`w`。 さらに、どのポータル セルからでも、他のポータルにテレポートできます。テレポート時間は 2 つのポータル セルのコストの合計です。 

入力によりグリッドとステップ コストが提供されます`w`、出力は目的地に到達するまでの最小時間、または`-1`それが不可能な場合。 開始セルと終了セルの両方が無料であることが保証されているため、Dima には常に有効な開始点があります。 

制約は次のとおりです。`n, m ≤ 2000`、これは最大 400 万個のセルを意味します。 セルまたはポータルのすべてのペアを反復する単純なアプローチでは、大まかに次のものが必要になります。`O(n²m²)`操作が大きすぎます。 また、ポータル コストと移動コストが最大 10^9 に達する可能性があるため、コストを慎重に処理しないと一部の簡略化された BFS のみの戦略が除外されます。 

明らかではないエッジ ケースには、ポータルを使用せずに直接パスが存在するグリッド、ゴールに到達するためにポータルが必要なグリッド、ポータル経由を除く他のすべてのセルから開始または終了がブロックされているグリッドが含まれます。 例えば：```
2 2 1
0 -1
-1 1
```ここで、右下に到達する唯一の方法はポータルを使用することです。そうでない場合、ポータルを無視する単純な BFS は出力を出力します。`-1`。 

もう 1 つの注意が必要なシナリオは、最小限のパスに歩行と 1 回のテレポートの組み合わせが必要な場合です。 アルゴリズムが両方を独立して考慮しない場合、計算時間が長くなる可能性があります。 

## アプローチ

 ブルートフォースアプローチは、すべてのセルをグラフ内のノードとして扱い、すべてのポータルをすべてのペア間のテレポートエッジとして含むダイクストラのアルゴリズムを実行することです。 グリッド サイズは BFS ベースの検索には十分小さいため、これは機能しますが、ポータル間に完全なグラフを追加すると、`O(p²)`エッジどこ`p`ポータルの数です。 最悪の場合、`p ≈ n*m`、次の理由によりこのアプローチは実行不可能になります。`O(n²m²)`操作。 

重要な洞察は、すべてのポータル間のエッジを個別に考慮する必要がないということです。 最初から任意のポータルに到達するための最小コストと、任意のポータルから目標に到達するための最小コストを個別に計算できます。 させて`d_start[i][j]`セルに到達するまでの最短時間`(i,j)`最初から標準技のみを使用します。 させて`d_end[i][j]`セルに到達するまでの最短時間`(i,j)`再び標準的な動きだけを使用してゴールから。 次に、すべてのポータルについて`(i,j)`最小の合計テレポート パスを次のように計算します。`d_start[i][j] + cost[i][j] + cost[k][l] + d_end[k][l]`すべてのポータル ペアにわたって`(i,j),(k,l)`。 

これをさらに最適化できます。すべてのポータル ペアをチェックする代わりに、最小限のポータル ペアだけを追跡できます。`d_start[i][j] + cost[i][j]`そして最小限の`d_end[i][j] + cost[i][j]`。 最小のテレポート パスは、これら 2 つの最小値の合計になります。 最終的に、答えは、テレポートを使用しない最初から最後までの直接パス、いずれかの方向、または両方に 1 つのテレポートを使用するパスの最小値です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべてのポータルエッジを備えたブルートフォースフルダイクストラ | O(n² m²) | O(nm) | 遅すぎる |
 | 最小限のポータル距離で最適化された BFS/ダイクストラ | O(nm) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. を初期化します。`dist`サイズのグリッドの配列`n × m`、無限大で満たされ、設定されます`dist[0][0] = 0`。 これにより、スタートからの最小距離が追跡されます。 
2. コストがかかる隣接する空きセルへの標準的な移動のみを考慮して、開始セルから BFS (または優先キューを使用したダイクストラ) を実行します。`w`。 この後、`d_start[i][j]`到達までの最小時間を保存します`(i,j)`テレポーテーションを使わずに。 
3. ゴールセルから同様の BFS/ダイクストラを実行して計算します`d_end[i][j]`。 これは、テレポートなしで任意のセルからゴールまでの最小コストを表します。 
4. すべての門脈細胞を特定します。 ポータルごとに`(i,j)`、計算する`d_start[i][j] + cost[i][j]`そして`d_end[i][j] + cost[i][j]`。 これら 2 つの量のそれぞれについて、すべてのポータルの最小値を追跡します。 
5. テレポーテーションを使用した最小時間を 2 つの最小ポータル値の合計として計算します。`min_start_portal + min_end_portal`。 
6. テレポートなしの最小時間を計算します。`d_start[n-1][m-1]`。 
7. 最終的な答えは、直接パスとテレポート支援パスの最小値です。 すべてのオプションが無限大のままの場合、出力`-1`。 

これが機能するのは、BFS が標準的な移動のみを使用して各セルへの最小パスを確実に見つけるためです。 ポータルに到達するための最小コストを最初から最後まで個別に計算することで、すべてのポータルのペアを明示的に考慮するという二次関数の複雑さを回避します。 このアルゴリズムは、テレポートがオプション、必須、または直接歩行よりも悪い場合を正しく処理します。 

## Python ソリューション```python
import sys
import heapq
input = sys.stdin.readline

def solve():
    n, m, w = map(int, input().split())
    grid = [list(map(int, input().split())) for _ in range(n)]
    
    INF = 10**18
    
    def dijkstra(start_i, start_j):
        dist = [[INF] * m for _ in range(n)]
        dist[start_i][start_j] = 0
        heap = [(0, start_i, start_j)]
        while heap:
            d, i, j = heapq.heappop(heap)
            if d > dist[i][j]:
                continue
            for di,dj in ((0,1),(1,0),(0,-1),(-1,0)):
                ni, nj = i+di, j+dj
                if 0 <= ni < n and 0 <= nj < m and grid[ni][nj] != -1:
                    nd = d + w
                    if nd < dist[ni][nj]:
                        dist[ni][nj] = nd
                        heapq.heappush(heap, (nd, ni, nj))
        return dist

    d_start = dijkstra(0, 0)
    d_end = dijkstra(n-1, m-1)
    
    min_start_portal = INF
    min_end_portal = INF
    for i in range(n):
        for j in range(m):
            if grid[i][j] > 0:
                if d_start[i][j] < INF:
                    min_start_portal = min(min_start_portal, d_start[i][j] + grid[i][j])
                if d_end[i][j] < INF:
                    min_end_portal = min(min_end_portal, d_end[i][j] + grid[i][j])
    
    ans = d_start[n-1][m-1]
    if min_start_portal < INF and min_end_portal < INF:
        ans = min(ans, min_start_portal + min_end_portal)
    print(-1 if ans >= INF else ans)

solve()
```最初のセクションでは、グリッドを読み取り、無限距離配列を初期化します。 の`dijkstra`関数は、隣接する移動のみを使用して、ブロックされたセルを回避して、任意の開始点からの最小距離を計算します。 次に、開始と目標からの最小有効ポータル コストを見つけます。 最後に、答えは直接歩行パスとポータル支援パスの両方を考慮しています。
