 ## 解決策
 ## 問題の理解

 記入するよう求められます$n \times n$の数字が入った正方形のグリッド$1$に$n^2$水平方向または垂直方向に隣接する 2 つのセルに連続する整数が含まれないようにします。 言い換えれば、隣接するセルの数値の差が正確に 1 になることはあり得ません。 入力は複数のテスト ケースで構成され、それぞれが単一の整数を提供します$n$、出力はそのサイズの有効な行列であるか、または$-1$解決策が存在しない場合。 

制約はかなり小さいです。$n$範囲は 1 ～ 100 で、テスト ケースは最大 100 個まで存在します。 これは、複雑なソリューションを大まかに許容できることを意味します$O(n^2)$テストケースごとに、$100 \cdot 100^2 = 10^6$制限時間は 4 秒以内です。 

いくつかの特殊なケースはすぐに分かります。 のために$n = 1$の場合、解決策は簡単です。数値 1 を持つ 1 つのセルです。$n = 2$ただし、取り決めは存在しません。 1 ～ 4 を配置すると、少なくとも 1 組の連続する数字がエッジを共有するようになります。 大型の場合$n$課題は、連続する整数の隣接を避けるように数値を配置することですが、連続する数値は必然的に隣接するため、単純に行ごとに埋めると失敗します。 

## アプローチ

 ブルートフォースアプローチでは、次のすべての順列を生成しようとします。$1$に$n^2$それぞれの隣接関係違反をチェックします。 これは原理的には正しいですが、まったく実行不可能です。$n = 5$、 がある$25!$順列は天文学的に大きい。 

重要な観察は、連続する数字を 2 つのセット (奇数と偶数) に分けることで、隣接する数字を避けることができるということです。 最初にすべての奇数でグリッドを埋め、次にすべての偶数で埋めた場合、連続する 2 つの数字 (常に 1 ずつ離れている) の差が水平方向にも垂直方向にも隣接することはありません。 これはすべてに有効です$n \ge 3$。 これらのサブセット内の配置は、単純な上から下、左から右のパターンに従うことができます。 

このアイデアにより、複雑さが大幅に軽減されます。順列をチェックする代わりに、数値をパリティに従って体系的に並べます。 唯一の例外は次のとおりです$n = 2$、解決できない、そして$n = 1$、それは些細なことです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((n^2)!) | O(n^2) | 遅すぎる |
 | 奇数偶数配置 | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 テスト ケースごとに、次の内容を読んでください。$n$。 もし$n = 2$、出力$-1$解決策が存在しないのですぐに。 もし$n = 1$、1を含む単一のセルを出力します。 
2. 空のオブジェクトを初期化する$n \times n$グリッド。 
3. 2 つのリストを生成します。1 つは 1 から 1 までのすべての奇数です。$n^2$1 つは 1 から 1 までのすべての偶数です。$n^2$。 
4. 奇数リストと偶数リストを連結して、最終シーケンスを形成します。 これにより、連続する数字がグリッド内に連続して表示されなくなります。 
5. 連結されたシーケンスを使用して、グリッドを行ごとに左から右に埋めます。 次に配置する数字を追跡するためのポインターを維持します。 
6. 完成したグリッドを出力します。 

これが機能する理由: 重要な不変条件は、連続する整数のすべてのペアが異なるセットに分離され、グリッドを順番に埋めることです。 すべての奇数を最初に配置すると、1 の差がある 2 つの数字が水平方向または垂直方向に隣接するセルに入ることがなくなります。 この単純な順序付けにより、すべての隣接関係の制約が解決されます。$n \ge 3$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def not_adjacent_matrix(n):
    if n == 2:
        return -1
    if n == 1:
        return [[1]]
    
    grid = [[0] * n for _ in range(n)]
    odds = [i for i in range(1, n*n + 1) if i % 2 == 1]
    evens = [i for i in range(1, n*n + 1) if i % 2 == 0]
    sequence = odds + evens
    
    idx = 0
    for r in range(n):
        for c in range(n):
            grid[r][c] = sequence[idx]
            idx += 1
    return grid

t = int(input())
for _ in range(t):
    n = int(input())
    result = not_adjacent_matrix(n)
    if result == -1:
        print(-1)
    else:
        for row in result:
            print(' '.join(map(str, row)))
```このコードは、次を使用して高速入力を処理します。`sys.stdin.readline`。 の`not_adjacent_matrix`関数は最初に解決できないものをチェックします$n = 2$そして些細な$n = 1$ケース。 奇数リストと偶数リストを作成して連結し、グリッドを行ごとに埋めます。 単純なインデックスの使用`idx`間違いなく番号を順番に配置できるようにします。 リスト内包表記を使用すると、正確さが保証され、off-by-one エラーが回避されます。 

## 実用的な例

 入力用`n = 3`、奇数は`[1, 3, 5, 7, 9]`そして偶数`[2, 4, 6, 8]`。 連結:`[1, 3, 5, 7, 9, 2, 4, 6, 8]`。 行ごとに入力すると、次の結果が得られます。 

| ラジコン | 0 | 1 | 2 |
 | --- | --- | --- | --- |
 | 0 | 1 | 3 | 5 |
 | 1 | 7 | 9 | 2 |
 | 2 | 4 | 6 | 8 |

 水平方向または垂直方向に隣接するものは 1 だけ異なります。 

入力用`n = 2`、すぐに戻ります`-1`1 ～ 4 の配置には、差が 1 の隣接ペアが存在するためです。
