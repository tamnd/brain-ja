 ## 解決策
 ## 問題の理解

 文字列で表される 1 次元のボードがあります。 それぞれ`'*'`羊とそれぞれ`'.'`は空のセルです。 羊は 1 回の移動で、左右の位置を 1 つずつ移動して、隣接する空のセルに移動できます。 目標は、単一セルの移動の総数を最小限に抑えながら、すべての羊が隙間なく連続した位置を占めるようにすることです。 

重要な点は、羊は見分けがつかないということです。 どの羊が最終的にどの位置に着くかは気にせず、すべての羊が連続することだけを気にします。 移動するたびに羊の位置が 1 つ変化するため、答えはすべての羊が移動した合計距離になります。 

テスト ケースの長さは、すべてのテスト ケースを合わせると 100 万にも及ぶことがあります。 動きを繰り返しシミュレートしたり、考えられるすべての最終セグメントを試行したりするアルゴリズムは、遅すぎます。 テスト ケースごとに線形に近い時間が必要です。 

いくつかの特殊なケースには特別な注意が必要です。 

羊がまったくいない場合:```
...
```答えは、`0`。 羊はいないため、すでに「グループ化」されています。 不用意に実装すると、中央値の羊にアクセスしようとしてクラッシュする可能性があります。 

羊がちょうど 1 匹いる場合:```
.*.
```答えは、`0`。 1 匹の羊はすでに連続したグループになっています。 

羊同士が大きな隙間で隔てられている場合:```
*...*...*
```最適な解決策は、すべてを 1 つのエンドポイントに向けて移動することではありません。 一番左の羊に羊を集めるという単純な戦略では、余計な作業が行われます。 最適な収集ポイントは羊の中央値によって決まります。 

もう 1 つの微妙なケースは、羊の数が偶数の場合です。```
*.*.*
```真ん中の羊候補は2人です。 どちらの中央位置でも、同じ最小合計距離が得られます。 実装では、一貫して 1 つを選択するだけで済みます。 

## アプローチ

 最も直接的なアイデアは、最後の連続ブロックを選択し、すべての羊をそのブロックに配置するのに必要な移動数を計算することです。 あると仮定します`k`羊。 ブロックが 位置から始まる場合`L`、その場合、羊は次の位置を占める必要があります。```
L, L+1, L+2, ..., L+k-1
```羊を左から右にマッチさせて、総移動コストを計算できます。 考えられるすべての開始位置に対してこれを繰り返すと、正しい答えが得られます。 

問題は、最大で`n`可能な開始位置とそれぞれのコストの評価`O(k)`。 最悪の場合こうなります`O(n²)`、それは不可能です`n = 10^6`。 

これを改善するには、実際に何が重要なのかを理解する必要があります。 

羊の位置が次のとおりであるとします。```
p0, p1, p2, ..., p(k-1)
```連続したセルを占有することになった場合、羊は`i`に行く必要があります:```
x + i
```あるスタートポジションのために`x`。 

総コストは次のようになります。```
|p0 - (x+0)| +
|p1 - (x+1)| +
...
|p(k-1) - (x+k-1)|
```以下を定義して式を並べ替えます。```
qi = pi - i
```その場合、コストは次のようになります。```
|q0 - x| + |q1 - x| + ... + |q(k-1) - x|
```ここで問題は、値を選択するという古典的なタスクに変わりました。`x`絶対偏差の合計を最小化します。 

絶対偏差の最小合計は中央値で得られます。 

つまり、考えられるすべての最終ブロックを検索する必要はありません。 必要なのは以下だけです:

 1. すべての羊の位置を記録します。 
2. 変換された値を構築する`qi = pi - i`。 
3. 変換された中央値を選択します。 
4. その中央値までの距離を合計します。 

羊の位置は昇順で収集されるため、変換されたシーケンスも減少しないため、中央値がすぐに利用可能になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) 最悪の場合 | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 文字列をスキャンし、すべての羊のインデックスを配列に保存します`pos`。 
2. 羊が 0 頭または 1 頭の場合、出力`0`。 
3. しましょう`k`羊の数になります。 
4. 変換されたシーケンスを構築します。```
q[i] = pos[i] - i
```これにより、羊を連続した位置に強制する効果が取り除かれます。 
5. 中央値を選択します。```
median = q[k // 2]
```以来`q`がソートされている場合、これは有効な中央値です。 
6. 以下を計算します。```
answer = Σ |q[i] - median|
```7. 答えを出力します。 

### なぜ効果があるのか

 最後の連続ブロックが 位置から始まると仮定します。`x`。 それから羊`i`ポジションを占めなければなりません`x+i`, なぜなら、羊の相対的な順序を変更することは、動きを増やすだけであり、決して有益ではないからです。 

費用は次のとおりです。```
Σ |pos[i] - (x+i)|
```書き換え:```
Σ |(pos[i]-i) - x|
```価値観`pos[i]-i`固定されています。 残る唯一の変数は、`x`。 絶対値の基本的な特性は、一連の数値までの距離の合計が中央値で最小になることです。 変換された中央値を選択すると、可能な最小の移動コストが得られます。これはまさに必要な答えです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    answers = []

    for _ in range(t):
        n = int(input())
        s = input().strip()

        pos = []

        for i, ch in enumerate(s):
            if ch == '*':
                pos.append(i)

        k = len(pos)

        if k <= 1:
            answers.append("0")
            continue

        q = [pos[i] - i for i in range(k)]
        median = q[k // 2]

        ans = 0
        for x in q:
            ans += abs(x - median)

        answers.append(str(ans))

    sys.stdout.write("\n".join(answers))

if __name__ == "__main__":
    solve()
```最初のループでは、すべての羊の位置を抽出します。 羊の位置のみを扱う方が、空のセルについて推論するよりもはるかに簡単です。 

変革`pos[i] - i`が重要なステップです。 それがなければ、最終的な位置が連続している必要があるという事実を考慮する必要があります。 引き算`i`この制約を削除し、問題を純粋な中央値最小化問題に変換します。 

中央値は、変換された配列から直接取得されます。 元の羊の位置は昇順で出現し、増加するインデックスを減算すると非降下順序が維持されるため、ソートは必要ありません。 

答えは大きくなる可能性があるため、整変数に累積します。 Python の整数は、32 ビットの制限を超える値を自動的に処理します。
