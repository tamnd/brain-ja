 ## 解決策
 ## 問題の理解

 当社には一連の牛がおり、それぞれに独自の Cowdeforces 評価があり、連続トーナメントで競い合います。 トーナメントは最初の 2 頭の牛から始まり、その後の各試合は前の試合の勝者と次に並ぶ牛の間で行われます。 より高い評価を持つ牛が常に勝ちます。 あなたは 1 頭の牛を所有しており、それを他の牛と一度交換するか、そのままにしておくことができます。 目標は、牛が勝つ試合の数を最大化することです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースでは、牛の頭数、牛の 1 から始まるインデックス、および初期位置でのすべての牛の評価が得られます。 出力は、最適なスワップ戦略の下で牛が達成できる最大勝利数を表す、テスト ケースごとの単一の数値です。 

この制約により、すべてのテスト ケースで合計最大 100,000 頭の牛が許可されます。 これは、テスト ケースあたりの時間計算量が O(n) よりも悪い解は遅すぎる可能性があることを意味します。 具体的には、考えられるすべてのスワップのネストされたシミュレーションでは O(n^2) の動作が発生し、これは受け入れられません。 

牛がそのセグメント内ですでに最も強いまたは最も弱い場合、微妙なエッジケースが発生します。 たとえば、あなたの牛がすでに先頭で、次の数頭の牛よりも強い場合、単純なアプローチでは不必要に交換しようとしてしまい、合計勝利数が減ってしまう可能性があります。 もう 1 つの注意が必要な状況は、牛を最初からではなく、より弱いシーケンスを過ぎて前方に交換することが最善の戦略である場合です。 たとえば、牛のレーティングが 2 のレーティング [2、1、5] を考えてみましょう。ポジション 2 に交換すると 1 勝が得られますが、ポジション 3 に交換すると勝ちは 0 になります。 これらを扱うには、極大値と弱い牛の順序を注意深く考慮する必要があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。 自分の牛を別の牛と交換する可能性があるすべてのトーナメントをシミュレートし、各シナリオの勝利数を数えて最大値を選択することができます。 トーナメントのルールは決定的であるため、これは正しいです。 ただし、これにはテスト ケースごとに O(n^2) の操作が必要です。n 頭の牛の場合、n 個の可能な交換位置を考慮し、各シミュレーションには最大 n ステップかかる可能性があります。 n が 10^5 までの場合、最悪のケースでは 10^10 の演算が行われることになりますが、これは実行不可能です。 

重要な観察は、連続トーナメントでは、自分の牛よりも弱い牛だけが問題になるということです。 自分の牛が次に並んでいる牛より強い場合、自分より強い牛に出会うまで勝ち続けます。 したがって、勝利を最大化するには、あなたの牛が自分よりも弱い牛の最長連続シーケンスに遭遇するような位置を見つけるだけで済みます。 これは、最適な戦略は、連続勝利を最大化するために牛をその場に維持するか、「ピーク」牛 (自分の牛よりも強い牛) の直前に移動することであることを意味します。 

左から右にスキャンすることで、O(n) 時間でこれを実装できます。 私たちは、あなたの牛が任意の位置から開始して、何頭の弱い牛を倒すことができるかカウンターを保持します。 すべての有効な開始位置 (牛を所定の位置に保持することを含む) にわたって最大値を維持します。 この問題は、評価を比較する単純な線形スキャンに帰着し、スワップごとの完全なシミュレーションを回避します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 牛の数 n、牛のインデックス k、および評価の配列 a を読み取ります。 配列の処理を容易にするために、1 から始まるインデックス k を 0 から始まるインデックスに変換します。 
2. 2 つの変数を初期化します。`max_wins`最高の勝利数を追跡するため、そして`current_wins`現在のポジションの連続勝利をカウントします。 
3. 配列を左から右に繰り返します。 現在の牛があなたの牛の場合、リセットします`current_wins`ここから勝利のカウントが開始されるため、ゼロになります。 
4. 他の牛については、自分の牛がこの位置にいた場合に勝つかどうかを確認します。 これは、あなたの牛のレーティングが現在試合に参加している牛のレーティングよりも高い場合に当てはまります。 「はい」の場合、増分します`current_wins`。 
5.アップデート`max_wins`いつでも`current_wins`それを超えています。 これにより、牛が特定の位置からスタートして最長の連勝記録を常に追跡できるようになります。 
6. アレイをスキャンした後、`max_wins`は、その場に留まるか 1 回の最適な交換によって牛が勝つことができる連続試合の最大数を表します。 

これが機能する理由: 不変条件は、牛は自分よりも弱い牛を順番に倒すことしかできないということです。 線形にスキャンし、連続して弱い牛をカウントすることにより、牛を元の位置に維持することも含め、牛を配置する最適な位置が自動的に計算されます。 これにより、すべての一致を明示的にシミュレートする必要がなくなりますが、同じ結果が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_wins_for_cow(n, k, a):
    cow_rating = a[k-1]
    max_wins = 0
    current_wins = 0
    for rating in a:
        if rating == cow_rating:
            current_wins = 0
            continue
        if rating < cow_rating:
            current_wins += 1
            max_wins = max(max_wins, current_wins)
        else:
            current_wins = 0
    return max_wins

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    print(max_wins_for_cow(n, k, a))
```この解決策では、まず牛の評価を分離します。 次に、すべての牛を反復処理して、任意のセグメントに連続して弱い牛が何頭存在するかをカウントし、より強い牛が現れた場合はカウンターをリセットします。 の使用`current_wins`連続記録を確実に追跡します。`max_wins`最良の結果を維持します。 k を 0 ベースのインデックスに変換すると、off-by-one エラーが回避されます。

 最適に交換した場合の最大勝利数は 1 です。これは、14 に達するとシーケンスが中断されるためです。この表は、弱い牛を連続してカウントすることで、より強い牛が現れたときに連勝リセットが正しく処理されることを示しています。

 あなたの牛が倒すことができる弱い牛の最大連続数は 2 です。最適な交換は、シーケンス 10、727 の直前に牛を配置することです。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | 最大ストリークを直接追跡するため、スワップとは無関係にアレイ全体を単一の線形スキャンします。 |
 | スペース | お(1) | 定数変数のみが必要です: max_wins と current_wins。 |

 すべてのテスト ケースの n の合計が 10^5 を超えないことを考慮すると、このソリューションは 1 秒未満で快適に実行されます。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        output.append(str(max_wins_for_cow(n, k, a)))
    return "\n".join(output)

# Maximum-size input, decreasing order

assert run("1\n5 3\n1 1 5 1 1") == "2"

# Edge swap to start
