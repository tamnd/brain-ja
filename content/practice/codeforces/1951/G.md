 ## 解決策
 ## 問題の理解

 1 から 1 までの番号が付けられたバスケットの円が与えられます。$m$、 そして$n$ボールは最初は別々のバスケットに入れられます。 アリスは繰り返しボールの 1 つを均一にランダムに選択し、それを時計回りに次のバスケットに移動します。 そのバスケットにすでにボールが入っている場合、既存のボールは捨てられます。 このプロセスは、ボールが 1 つだけ残るまで続きます。 タスクは、このプロセスにかかる予想秒数を計算することです。 

入力の観点から、各テスト ケースはボールの数を提供します。$n$、バスケットの数$m$、およびボールの初期位置の配列。 出力は、期待される時間を秒単位で換算した値である必要があります。$10^9 + 7$分数として$p/q$、 どこ$q$可逆モジュロです$10^9 + 7$。 

制約は重要です。$n$まで可能です$3 \cdot 10^5$テストケースごとに、$m$まで$10^9$。 の合計額$n$すべてのテスト ケースで次を超えない$3 \cdot 10^5$。 各ボールを段階的に動かす単純なシミュレーションは実行不可能です。$O(m \cdot n)$テストケースごとの操作は、許容範囲をはるかに超えています。$m \sim 10^9$。 大まかに実行できるソリューションが必要です$O(n \log n)$または$O(n)$テストケースごとに。 

エッジケースには、次のようなシナリオが含まれます。$n = 1$この場合、時間が必要ない場合や、ボールが連続または逆の順序で配置される場合、予測可能な方法で相互作用するクラスターが作成される可能性があります。 不注意なアプローチでは 1 秒ごとにシミュレーションしようとするため、時間の計算量が爆発的に増加したり、重複する動作が誤って処理されたりする可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、アリスの動きを毎秒シミュレートします。 バスケットを表す配列を維持し、ランダムにボールを選択して移動し、衝突をチェックし、ボールが 1 つだけ残るまで繰り返します。 このアプローチは原理的には正しいですが、ボールが 1 つ残るまでのステップ数に応じて操作の数が増加するため、壊滅的に時間がかかります。$O(n \cdot m)$。 のために$n = 3 \cdot 10^5$そして$m = 10^9$、これは無理です。 

重要な洞察は、シミュレーションではなく確率的に問題をモデル化することです。 各ボールには時計回りの次のボールまでの「衝突までの距離」があります。 これらの距離がわかれば、ボールを排除するために必要な予想手数は、選択確率でスケールされた距離に比例します。 より正式には、ボールが$d$次のボールを打つ前にバスケットをフリーにする場合、衝突が発生するまでの予想手数は次のとおりです。$n \cdot d$。 最後のボールを除くすべてのボールについてこれらの寄与を合計します。 ボールを初期位置で並べ替えることで、時計回りの距離を効率的に計算できます。 期待値は分数であり、それをモジュロで減算する必要があるため、モジュロ逆関数が必要です。$10^9 + 7$。

 | ブルートフォース | O(n * m) | O(n + m) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$、$m$、および位置配列$a$。 
3. もし$n = 1$、ボールが 1 つしか存在しないため、答えはすぐに 0 になります。 
4. 位置配列をソートする$a$連続したボール間の時計回りのギャップを簡単に計算します。 
5. 次を使用して、連続するボール間の時計回りの距離を計算します。$(a_{i+1} - a_i - 1 + m) \% m$。 これにより、衝突が発生する前の空のバスケットの数がわかります。 
6. これらの距離を合計して、1 つのボールを除いてすべてのボールが除去されるまでの「フリームーブ」の総数を取得します。 この合計は、予想される時間の分子を表します。 
7. この合計に次の値を掛けます。$n$それぞれの動きは確率で発生するため、$1/n$、予想される合計秒数を有理形式で示します。 
8. 結果のモジュロを削減します$10^9 + 7$モジュラー逆関数を使用する$1$(必要に応じて分数を直接指定して)、結果が整数の剰余であることを確認します。$10^9 + 7$。 

このアルゴリズムが機能するのは、並べ替えられた順序でのボール間の距離によって、次のボールを排除するために各ボールが何回移動する必要があるかが一意に決定されるためです。 各ボールは予想される合計時間に独立して寄与し、均一なランダム選択によりこの寄与度がスケールされます。$n$。 ソートにより、円形配列上で距離が正しく計算されるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        if n == 1:
            print(0)
            continue
        a.sort()
        total_dist = 0
        for i in range(n):
            nxt = a[(i + 1) % n]
            dist = (nxt - a[i] - 1 + m) % m
            total_dist += dist
        expected_time = (total_dist * n) % MOD
        print(expected_time)

solve()
```コードは、入力を読み取り、モジュロ定数を定義することから始まります。 の`modinv`関数は、必要に応じて逆モジュラーを計算するユーティリティです。 各テスト ケースで、ボールが 1 つだけ存在する場合、答えはゼロになります。 それ以外の場合、ボールは時計回りの距離を計算するためにソートされます。 各距離は、モジュロ演算により円形になるように調整されます。 予想時間は距離の合計に次の値を乗算します。$n$各ボールには$1/n$1秒あたりの移動確率。 結果はモジュロで出力されます$10^9 + 7$。
