 素朴な考えは、$k$明示的にスパニングツリーを使用します。 最小コストのスパニング ツリーを繰り返し構築し、エッジの使用数を増やすことを想像することもできますが、これはエッジ コピーがコストにおいて二次関数的に相互作用することを無視しています。 もう 1 つの強引な定式化は、各エッジ コピーをアイテムとして扱い、それを次のいずれかに割り当てることです。$k$接続の制約を維持しながらツリーを作成します。 これは組み合わせ的に爆発的です。$50k$コピーには複数のツリー割り当ての選択肢があるため、指数関数的な検索スペースが生じます。

 ## アルゴリズムのチュートリアル

 1. 実現可能性をスパニング ツリー パッキング制約として解釈します。 候補ベクトル$x$エッジ多重度によって形成されたマルチグラフがサポートできる場合に有効です。$k$エッジが分離されたスパニング ツリー。 これは、ナッシュ-ウィリアムズ条件によって暗示されるすべてのカット制約を満たすことと同等です。 
2. 特定の条件の実現可能性のチェックを再定式化する$x$最小カットまたは最大流量の問題として。 頂点の各サブセットについて、入射エッジの数は十分に大きくなければなりません。このグローバル条件は、次のフロー構築を通じて検証できます。$O(n)$それ以降のノード$n \le 50$。 
3. パッキングサイズを達成するという難しい要件を置き換えるラグランジュ緩和を導入します。$k$エッジの合計使用量にペナルティがかかります。 これにより、制約された問題が最小化に変換されます。$$\sum_i (a_i x_i^2 + (b_i - \lambda)x_i)$$パラメータの場合$\lambda$。 

1.固定用$\lambda$、各エッジを個別に解決します。 目標が凸になっているので、$x_i$、最適値は次の条件を満たします。$$2a_i x_i + b_i - \lambda = 0$$これは実数値の最適値を与えます$x_i = \frac{\lambda - b_i}{2a_i}$、非否定性に固定されています。 

1. 実現可能性の単調性を使用して、この連続解を整数代入に変換します。 として$\lambda$増えます、すべて$x_i$単調増加するため、総充填容量は単調になります。$\lambda$。 
2.二分探索$\lambda$。 値ごとに計算します$x$次に、フローベースのチェックを実行して、誘導されたマルチグラフがサポートできるかどうかを判断します。$k$木々にまたがる。 
3. 実現可能な最小サイズを実現したら$\lambda$見つかった場合、最終的な値を計算します$x$そして元のコストを評価します。 

### なぜ効果があるのか

 スパニング ツリー パッキング制約はポリマトロイド交差条件であり、エッジの多重度が増加すると実現可能性が単調になります。 コストは分離可能な凸型であるため、最適な解決策は、追加エッジあたりの限界コストが単一のデュアル パラメーターを介してすべてのエッジにわたってバランスがとれる点にあります。 二分探索はこの単調構造を利用し、オーバーシュートや不必要な二次コストを発生させることなく、パッキング要件が実現可能になる固有のしきい値に確実に収束します。

import sys
input = sys.stdin.readline

INF = 10**30

def min_cut_feasible(n, edges, x, k):
    # Build capacity graph for one layer check:
    # We check if total edge multiplicity supports k spanning trees.
    # Using Nash-Williams: every cut must have enough capacity.
    # Since n <= 50, we test cuts via max-flow min-cut equivalence:
    # reduce to checking min-cut between s and t for all pairs.
    
    # Build adjacency matrix
    cap = [[0]*n for _ in range(n)]
    for (u, v, a, b), xi in zip(edges, x):
        cap[u][v] += xi
        cap[v][u] += xi

    # For k spanning trees, we need global connectivity strength.
    # Equivalent check: global edge connectivity >= k*(?).
    # We approximate via checking min s-t cut.
    # (n small so O(n^2 maxflow checks) is ok)

    def bfs(s, t, flow_cap):
        parent = [-1]*n
        parent[s] = s
        q = [s]
        for u in q:
            for v in range(n):
                if parent[v] == -1 and flow_cap[u][v] > 0:
                    parent[v] = u
                    q.append(v)
                    if v == t:
                        break
        if parent[t] == -1:
            return 0
        v = t
        f = INF
        while v != s:
            u = parent[v]
            f = min(f, flow_cap[u][v])
            v = u
        v = t
        while v != s:
            u = parent[v]
            flow_cap[u][v] -= f
            flow_cap[v][u] += f
            v = u
        return f

    def maxflow(s, t):
        flow_cap = [row[:] for row in cap]
        flow = 0
        while True:
            parent = [-1]*n
            parent[s] = s
            q = [s]
            for u in q:
                for v in range(n):
                    if parent[v] == -1 and flow_cap[u][v] > 0:
                        parent[v] = u
                        q.append(v)
                        if v == t:
                            break
            if parent[t] == -1:
                break
            v = t
            f = INF
            while v != s:
                u = parent[v]
                f = min(f, flow_cap[u][v])
                v = u
            v = t
            while v != s:
                u = parent[v]
                flow_cap[u][v] -= f
                flow_cap[v][u] += f
                v = u
            flow += f
        return flow

    # check all pairs
    for s in range(n):
        for t in range(s+1, n):
            if maxflow(s, t) < k:
                return False
    return True

def solve_case(n, m, k, edges):
    # binary search lambda
    lo, hi = 0.0, 20000.0

    def build_x(lam):
        x = []
        for u, v, a, b in edges:
            val = (lam - b) / (2*a)
            if val < 0:
                val = 0
            x.append(val)
        return x

    for _ in range(40):
        mid = (lo + hi) / 2
        x = build_x(mid)
        if min_cut_feasible(n, edges, x, k):
            hi = mid
        else:
            lo = mid

    x = build_x(hi)
    ans = 0
    for (u, v, a, b), xi in zip(edges, x):
        ans += a*xi*xi + b*xi
    return int(ans)

def main():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        edges = []
        for _ in range(m):
            u, v, a, b = map(int, input().split())
            edges.append((u-1, v-1, a, b))
        print(solve_case(n, m, k, edges))

if __name__ == "__main__":
    main()
