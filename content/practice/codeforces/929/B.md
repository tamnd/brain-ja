 ## 解決策

 ## 問題の理解

 飛行機の座席レイアウトが複数の行に分割されており、各行は座席とセパレーターを含む文字列です。 座席は列ごとに固定パターンで配置されますが、重要な詳細はより単純です。列内の水平方向に隣接する座席のみが「隣接」関係に寄与でき、ダッシュ文字は隣接関係を解除します。 

一部の座席はすでに 2 種類の乗客によって占有されています。 乗客ステータス、マーク付き`S`、「近隣カウント」が目的に貢献する唯一のものです。 一般乗客`P`すでにいくつかの席を占めており、隣の席を数えるときは他の席に座っているときと同じように動作します。 まで置くことが許可されています`k`追加の一般乗客がマークされた空席に座ります`.`; これらは次のようにマークされます`x`出力で。 

最小化したい数量は、すべてのステータスの乗客の隣接する占有座席の合計数です。 あらゆる人にとって`S`、その列の内側の左右と、どちらかが座っているすべての隣接する座席を見てみましょう。`S`、`P`、または新しく配置された`x`答えに1つ貢献します。 2 人のステータス乗客が隣り合って座っている場合、その隣接関係はエンドポイントごとに 1 回ずつ、計 2 回寄与します。 

制約`n ≤ 100`そしてせいぜい`10·n`新しい乗客は座席の総数が少ないことを意味するため、`O(total seats log total seats)`戦略は十分すぎるほどです。 ソートステップを伴うリニアスキャンは完全に安全です。 

微妙な点は、新しい乗客を配置しても座席間の隣接ルールは変更されず、座席が占有されているかどうかのみが変更されることです。 したがって、グリッドの構造は固定されています。 どの空いたポジションが占有されるかを決定するだけです。 

主なエッジ ケースは、ローカル クラスター内の位置に応じて、座席が 0、1、または 2 人のステータスの乗客に隣接する可能性があることです。 たとえば、次のようなフラグメントでは、`S.S`を配置して、`x`中央では 2 つの新しいコントリビューションが作成され、`S..P`中央の席には、左側に該当する隣席が 1 つだけあります。`S`。 

A naive approach that simulates all placements greedily without evaluating global best choices can fail because placing a seat with cost 1 might be worse than preserving a seat with cost 2 for later decisions when`k`は限られています。 

## アプローチ

 ブルートフォース方式では、あらゆる方法を試して選択します。`k`空席を設定して乗客を配置し、ステータスの乗客の合計隣接コストを再計算します。 あれば`m`空席、これは本質的に選択することです`k`から`m`、につながる`O(m choose k)`構成と各評価コスト`O(total seats)`。 入力が少なくても、数十席以上の空席があると、これは組み合わせ的に不可能になります。 

重要な観察は、各空席が最終的な回答に与える影響は他の選択肢から独立しているということです。 乗客を空席に座らせる場合、目的に影響を与える唯一の方法は、隣接する座席の数を増やすことです。`S`席。 他の席との隣接関係が変わることはありません。 

これにより、すべての空席にコストを割り当てるタスク、つまりその左側または右側のすぐ隣に何人のステータスの乗客が座るかを割り当てるタスクが軽減されます。 選択された各座席は、合計スコアをそのコスト分だけ増加させます。 したがって、最終的な値を最小化するには、乗客を`k`最小限のコストで空席を確保できます。 

これらの座席が選択されると、それらを占有済みとしてマークし、すべての座席の隣接性をスキャンして最終スコアを再計算します。`S`席。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースの組み合わせ | O(C(m,k) · n) | O(n) | 遅すぎる |
 | 空席を料金順に並べ替える | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての行をスキャンし、空の位置をすべて収集します`.`をリストにします。 このような各位置について、同じ行内のそのすぐ左と右の隣をチェックすることによってコストを計算します。 それぞれ隣り合う`S`1 単位のコストに貢献します。 
2. すべての空のポジションを、計算されたコストに基づいて昇順に並べ替えます。 これにより、目的への害が最も少ない座席を優先することが保証されます。 
3. 最初の項目を選択します`k`この並べ替えられた順序での位置を決定し、それらを埋められたものとしてマークします。`x`。 これらは、最終的な合計に対する増分の増加が最小限に抑えられるため、最適な配置となります。 
4.すべて配置したら`x`、すべてのセルを反復して最終的な答えを計算します。 あらゆる人にとって`S`、同じ行の左右の隣をチェックします。 隣の席が占有されている場合 (`S`、`P`、 または`x`)、合計に 1 を加えます。 
5. 計算された合計と、その後に変更されたグリッドを出力します。 

直接の隣接関係のみを考慮する理由は、隣接関係が行内で厳密にローカルであり、ダッシュ文字により行をまたがる相互作用が防止されるためです。 

### なぜ効果があるのか

 各空席は、その列の隣接する 2 人の乗客にのみ影響します。 どの配置も隣接しないペアに影響を与えたり、既存のペアを変更したりすることはできません`S-S`関係。 これにより、選択した座席に比べて総コストが加算されます。 すべての決定は独立したコストに寄与するため、最小のものを選択します。`k`貢献度は、直接交換引数によって合計を最小化します。つまり、選択された高コストのシートを、選択されていない低コストのシートと交換すると、常に結果が改善または維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    rows = [list(input().strip()) for _ in range(n)]

    empties = []

    # compute cost of placing x in each empty seat
    for i in range(n):
        row = rows[i]
        m = len(row)
        for j in range(m):
            if row[j] == '.':
                cost = 0
                if j - 1 >= 0 and row[j - 1] == 'S':
                    cost += 1
                if j + 1 < m and row[j + 1] == 'S':
                    cost += 1
                empties.append((cost, i, j))

    # choose best k positions
    empties.sort()
    for t in range(k):
        _, i, j = empties[t]
        rows[i][j] = 'x'

    # compute answer
    ans = 0
    for i in range(n):
        row = rows[i]
        m = len(row)
        for j in range(m):
            if row[j] == 'S':
                if j - 1 >= 0 and row[j - 1] != '-':
                    if row[j - 1] in 'SPx':
                        ans += 1
                if j + 1 < m and row[j + 1] != '-':
                    if row[j + 1] in 'SPx':
                        ans += 1

    print(ans)
    for r in rows:
        print(''.join(r))

if __name__ == "__main__":
    solve()
```第 1 段階では、地元への影響力を考慮した候補議席のリストを作成します。 第 2 フェーズでは貪欲に割り当てます。`x`最も危険の少ない位置に配置します。 最終スキャンでは、行間の隣接関係を無視することで、行の境界を注意深く尊重します。`-`、有効な隣の席のみをカウントするようにします。 

よくある間違いは、配置のたびにコストを動的に再計算することです。 コストは以前の配置に依存しないため、これは不要です。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、次のように、2 人のステータスの乗客の間に空席がある場合です。`S.S`。 コストは 2 になり、強制されない限りアルゴリズムは正しく回避します。 すべての座席のコストが 2 の場合でも、すべての選択肢が同等であるため、アルゴリズムは依然としてその中から任意に選択します。 

もう 1 つのケースは、座席がダッシュボードの境界に隣接している場合です。 例えば`S.-.`隣接関係が境界を越えないことを保証します。`-`、実装では、近傍をカウントする前に境界を明示的にチェックします。 

最後のエッジケースは次のような場合です`k`コストゼロのシートの数と同じです。 このアルゴリズムは、最初に無害な席をすべて埋め、有害な席には決して触れず、目標の増加を最小限に抑えるか、まったく増加させません。
