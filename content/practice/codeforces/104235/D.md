 ## 解決策
 ## 問題の理解

 次のサイズの長方形グリッドが与えられます。$n \times m$、単位セルで完全に覆われています。 プレイヤーは、「コーナー トロミノ」と呼ばれる特定の形状を使用して、正確に 1 つのセルを削除した後、残りのすべてのセルをタイル表示したいと考えています。これは、L を形成する 3 つのセルで構成される形状です。$2 \times 2$1 つのセルを削除した正方形。 

このプロセスには制約があります。まず、グリッドから 1 つのセルだけが削除されます。 その後、残りのセルを互いに素な L-トロミノに完全に分割できるかどうかを判断する必要があります。 タスクは、そのようなタイリングを構築することではなく、削除するとタイリングが不可能になるセルが少なくとも 1 つ存在するかどうかを判断することだけです。 

そこで質問は、削除によってグリッドのすべての可能な L-トロミノ タイリングが破壊される「クリティカル セル」が存在するかどうかです。 

制約$2 \le n, m \le 10^5$imply we cannot simulate tilings or run search over the grid. どのような解決策であっても、$O(1)$あるいは最悪の場合$O(\log n)$。 これにより、私たちはすぐに、建設的なレイアウトではなく、グローバルな不変条件についての推論へと進みます。 

微妙な点は、答えは削除された細胞の存在にあるということです。 これはしばしば混乱を引き起こします。多くの単純なアプローチは、最初にタイリングが存在するかどうかを確認せずに、ローカルで削除をテストしようとしたり、対称性の議論を仮定したりします。 

いくつかの小さなエッジ シナリオは、構造を明確にするのに役立ちます。 

いつ$n = m = 2$、任意の 1 つのセルを削除すると、ちょうど 3 つのセルが残り、常に 1 つの L-トロミノを形成できます。 したがって、タイリングをブロックする除去はなく、答えは「NO」です。 

いつ$n = m = 3$を選択すると、動作が変わります。グリッドには 9 つのセルがあります。 1 つ削除すると 8 つのセルが残り、タイリングを不可能にする削除が存在することが判明しました。 したがって、答えは「YES」になります。 

主な困難は、グリッドの構造が 1 つの欠落ユニットによってすべてのタイリングが破壊されるほど十分に厳格である場合と、単一セルを削除するたびに有効なタイリングが可能となるほど十分に柔軟である場合を理解することです。 

## アプローチ

 ブルートフォースの視点が自然に始まります。グリッド内の各セルについて、それを削除し、残りのボードを L トロミノで並べてみます。 各タイリング試行は複雑なカバー問題であり、本質的にはポリオミノ制約を持つグリッド グラフの完全なカバーです。 単一の構成であっても、これは本質的に指数関数的です。 タイリングの数は非常に急速に増加し、存在の検証はすでに厳密なカバー問題になっています。 

完全な列挙を無視して貪欲なタイリングを試みたとしても、L-トロミノの局所的な貪欲な配置はグローバルな実現可能性を保証しないため、すぐに失敗します。 状態空間は、長距離パリティ制約とカバーされていない領域の接続性に依存します。 

重要な観察は、長方形グリッドの L-トロミノ タイリングがほぼ完全にグローバル パリティと構造分解可能性によって支配されるということです。 特に、十分な大きさの長方形は柔軟性が高く、両方の次元が少なくとも 3 になると、グリッドをさまざまな方法で L-トロミノに分解でき、単一のセルを削除してもこの柔軟性は損なわれません。 グリッドには、欠落しているセルを回避するのに十分な「余裕」があります。 

脆弱な唯一のケースは、少なくとも 1 つの寸法が小さい場合です。 1 つの次元が 2 の場合、グリッドは幅 2 のストリップになり、使用できないフラグメントを残さずに L 字型のカバーをサポートするには、2×2 ブロックごとに制約が多すぎるため、L トロミノを配置することはできません。 同様に、非常に小さなグリッドには、削除後の修復に必要な組み合わせの自由度がありません。 

したがって、問題は、小さな次元と十分に大きなグリッドを分類することに帰着します。 答えは、両方の次元が少なくとも 3 であるかどうかによってのみ決まります。 

両方のとき$n \ge 3$そして$m \ge 3$を削除すると、タイリングの実現可能性が損なわれるセルを常に見つけることができます。 少なくとも 1 つの次元が 3 未満の場合、そのような破壊的なセルは存在しません。

 ## アルゴリズムのチュートリアル

 1. 整数の読み取り$n$そして$m$。 これらは基板の形状を定義し、それ以降の推論はすべて、個々のセル構造ではなく相対的なサイズのみに依存します。 
2. 両方あるかどうかを確認します$n$そして$m$少なくとも 3 です。このしきい値は、グリッドに十分な内部データが含まれているかどうかを決定するため、重要です。$2 \times 2$堅牢な L-トロミノの再配置をサポートする柔軟性。 
3. 両方の次元が 3 以上の場合、「YES」を出力します。 その理由は、十分に大きなグリッドには、L-トロミノのパリティとカバレッジの一貫性に関する構造上の制約により、その削除によりグローバル タイリングの実現可能性が損なわれるセルが少なくとも 1 つ存在するためです。 
4. それ以外の場合は「NO」を出力します。 薄いグリッド (幅または高さ 2) では、構造が制約されすぎているため、単一のセルを削除しても、タイル化可能な場合はいつでもタイル化できる領域が残るため、「ブロック」セルは存在しません。 

### なぜ効果があるのか

 核となる不変条件は、完全な内部 2D 構造 (両方の次元が少なくとも 3) を含むグリッドのみが、単一の欠落セルの正確な配置に依存する L トロミノ タイリングの構成上の十分な自由度を持っているということです。 狭いグリッドでは、タイリングは不可能か完全に固定されています。つまり、1 つのセルを削除しても新たな不可能性が生じることはありません。 したがって、ブロッキングセルの存在は、グリッドが両方向に少なくとも 3×3 であることと同等です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

if n >= 3 and m >= 3:
    print("YES")
else:
    print("NO")
```実装は直接的です。 2 つの整数を読み取った後は、それらをしきい値 3 と比較するだけです。答えは純粋に次元に依存するため、追加の状態や前処理は必要ありません。 

The only subtle point is ensuring both dimensions are checked simultaneously. Checking only one side would incorrectly classify grids like 2×100000, where the narrow dimension prevents any meaningful L-tromino structure.

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, sys.stdin.readline().split())
    if n >= 3 and m >= 3:
        return "YES"
    return "NO"

# provided samples
assert run("2 2\n") == "NO", "sample 1"

 ## 特殊なケース

 1 つの次元がちょうど 2 であるグリッドの場合、アルゴリズムはすぐに「NO」を返します。 たとえば、2×100000 ボードでは、次の条件が適用されます。$n \ge 3 \land m \ge 3$最初のチェックで失敗します。 グリッドは、L-トロミノの配置が構造的に制限されている狭いストリップのままであるため、1 つのセルを削除しても、根本的に新たな不可能性を導入することはできません。 

3×3 グリッドでは両方の条件が満たされるため、アルゴリズムは「YES」を出力します。 これは、完全な 2D 近傍があらゆる場所に存在すると、単一のセルを削除すると全体的なタイルの一貫性が崩れる可能性があるという考えと一致しています。 

100000×100000 のような大きな正方形グリッドの場合も、同じロジックが適用されます。 チェックはしきい値のみに依存するため、結果は即座に「YES」となり、大規模グリッドの高い柔軟性を反映しています。
