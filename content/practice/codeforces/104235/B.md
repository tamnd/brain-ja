 ## 解決策
 ## 問題の理解

 グリッド上に 2 つの同一の幾何学的オブジェクトが与えられます。各オブジェクトは辺の長さが 1 の正六角形です。各六角形は固定された方向に配置されます。つまり、その辺の 2 つは垂直で、その最下位の頂点は整数の座標点に固定されています。 これにより、平面内の六角形の位置が完全に決まります。 

タスクは、2 つの六角形間の重なり部分の面積を計算することです。 形状は固定されており、平行移動まで同一であるため、答えは底部頂点間の相対オフセットのみに依存します。 正確な交差領域を計算した後、標準のハーフアップ ルールを使用して最も近い整数に丸めた結果を出力する必要があります。 

座標は 10^9 まで大きくなる可能性がありますが、ジオメトリは小さく、局所的です。 各六角形のサイズは一定であるため、交差点は 2 つのアンカー ポイントの相対的な変位によってのみ影響を受けます。 これにより、絶対位置はその違いを超えて無関係であるため、平面を離散化しようとしたり、座標範囲全体にわたって高解像度でジオメトリをシミュレートしようとするアプローチは即座に除外されます。 

単純な落とし穴は、座標が大きいため、浮動小数点ジオメトリが不安定になる、または慎重なスケーリングが必要になると想定することです。 実際には、関連するすべてのジオメトリは、各六角形の周囲の一定サイズの領域内で境界付けされます。 

2 番目の微妙な問題は丸めに現れます。 この問題では切り捨てや下限は求められませんが、0.5 を四捨五入して最も近い整数に丸めることが求められます。 不用意に浮動小数点ポリゴン交差を使用して近似面積を計算するソリューションは、オーバーラップが整数から 0.5 に近い境界ケース付近で失敗する可能性があります。 

たとえば、2 つの六角形がかろうじて重なり合っている場合、真の交差は精度に応じて 0.4999999 または 0.5000001 になる可能性があり、処理を誤ると答えが 0 と 1 の間で反転する可能性があります。 

## アプローチ

 この問題を解決する強引な方法は、両方の六角形をポリゴンとして明示的に構築し、標準のポリゴン クリッピング アルゴリズムを使用してそれらの交差ポリゴンを計算し、そのポリゴンの面積を計算することです。 各六角形には頂点が 6 つしかないため、クリッピング ステップは理論的には一定時間ですが、それでも線の交差と浮動小数点演算の慎重な幾何学的処理が必要になります。 

一般的なポリゴンの交差はよく理解されているため、これは機能しますが、やりすぎです。 実際の所見は、両方の形状が同一であり、変換されるだけであるため、任意の形状を処理する完全なポリゴン クリッピング アルゴリズムは必要ないということです。 代わりに、六角形の形状を一度事前計算し、変換中の 2 つの固定凸多角形の重なりを計算するものとして問題を扱うことができます。 

重要な簡略化は、六角形が凸面で小さいことです。 凸多角形の場合、平行移動中の交差領域は相対変位のみに依存し、オーバーラップ構造をスキャンするか幾何学的分解を直接使用することで効率的に計算できます。 この問題では、形状が固定され対称であるため、一定数のエッジの重なりをチェックし、x スライスにわたって統合するだけの計算に減らすことができます。 

最も安定した標準的な解決策は、凸多角形交差ルーチンを使用して直接多角形交差を計算することです。ここでは頂点の数が固定されているため、このルーチンは一定時間で実行されます。

 ## アルゴリズムのチュートリアル

 六角形が固定されていることを利用して、その下の頂点を基準にしてその座標を明示的に構築します。

1. 底部の頂点が (0, 0) にあるローカル座標系で基本六角形の形状を定義します。 辺 1 が垂直な正六角形の幾何学形状から、6 つの頂点を順番に導出できます。 この形状は一定であり、ハードコーディングできます。 
2. このテンプレートを 2 回変換します。1 回目は (x1, y1) によって、もう 1 回目は (x2, y2) によってです。 これにより、絶対座標で 2 つの凸多角形が生成されます。 平行移動では形状と面積が維持されるため、相対的なシフトのみが問題となります。 
3. Sutherland-Hodgman などの凸多角形クリッピング法を使用して、これら 2 つの凸多角形の交差多角形を計算します。 各ポリゴンには 6 つの頂点があるため、各クリッピング ステップで一定数のエッジが処理されるため、プロセス全体は一定時間になります。 
4. 交差多角形を取得したら、靴紐の公式を使用してその面積を計算します。 ポリゴンの頂点の数は最大でも一定であるため、このステップは安定して高速です。 
5. 標準ルールを使用して、結果の領域を最も近い整数に丸めます。1.5 などの値は 2 に丸められ、1.4999 は 1 に丸められます。 

重要な実装の詳細は、すべての計算を十分な精度で浮動小数点で実行するか、必要に応じて正確な算術演算を使用する必要があることですが、サイズが一定であるため、慎重に実装すれば倍精度で十分です。 

### なぜ効果があるのか

 正しさは 2 つの事実から得られます。 まず、平行移動により問題が変位ベクトルの下での固定凸多角形の交差に帰着され、凸多角形の交差はエッジの半平面制約によって完全に決定されます。 第 2 に、Sutherland-Hodgman クリッピング アルゴリズムは、ポリゴン エッジによって定義された半空間を反復的に交差させることによって、凸多角形の正確な交差を保存します。 両方のポリゴンが凸状で固定サイズであるため、出力ポリゴンは正確にそれらの幾何学的交差となるため、靴紐の式はオーバーラップ領域の正しい面積を計算します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def polygon_area(poly):
    area = 0.0
    n = len(poly)
    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]
        area += x1 * y2 - x2 * y1
    return abs(area) / 2.0

def inside(p, a, b):
    # check if p is on left side of directed edge a->b
    return (b[0] - a[0]) * (p[1] - a[1]) - (b[1] - a[1]) * (p[0] - a[0]) >= 0

def intersect(a, b, p, q):
    # intersection of segment ab with line pq direction
    x1, y1 = a
    x2, y2 = b
    x3, y3 = p
    x4, y4 = q

    den = (x1 - x2) * (y3 - y4) - (y1 - y2) * (x3 - x4)
    if abs(den) < 1e-18:
        return a

    t = ((x1 - x3) * (y3 - y4) - (y1 - y3) * (x3 - x4)) / den
    return (x1 + t * (x2 - x1), y1 + t * (y2 - y1))

def clip(poly, a, b):
    res = []
    n = len(poly)
    for i in range(n):
        cur = poly[i]
        prev = poly[i - 1]
        cur_in = inside(cur, a, b)
        prev_in = inside(prev, a, b)

        if cur_in:
            if not prev_in:
                res.append(intersect(prev, cur, a, b))
            res.append(cur)
        elif prev_in:
            res.append(intersect(prev, cur, a, b))
    return res

def convex_intersection(poly1, poly2):
    res = poly1[:]
    for i in range(len(poly2)):
        a = poly2[i]
        b = poly2[(i + 1) % len(poly2)]
        res = clip(res, a, b)
        if not res:
            return []
    return res

def build_hex(x, y):
    h = 3**0.5 / 2.0
    return [
        (x, y),
        (x + 1, y),
        (x + 1.5, y + h),
        (x + 1, y + 2*h),
        (x, y + 2*h),
        (x - 0.5, y + h),
    ]

x1, y1 = map(int, input().split())
x2, y2 = map(int, input().split())

hex1 = build_hex(x1, y1)
hex2 = build_hex(x2, y2)

poly = convex_intersection(hex1, hex2)
area = polygon_area(poly) if poly else 0.0

ans = int(area + 0.5)
print(ans)
```実装は、六角形を明示的に構築することから始まります。 選択した座標は、対辺間の垂直方向の間隔が √3 である標準六角形ジオメトリから導出された、平らな垂直側面を持つ辺の長さ 1 の正六角形に対応します。 

クリッピング ルーチンは、2 番目の多角形の各エッジの半平面と多角形を繰り返し交差します。 各エッジは制約として機能し、交差候補ポリゴンを縮小します。 inside 関数は方向の一貫性を強制し、重なり合う領域のみが残るようにします。 

最後に、靴紐の式によって、結果として得られる凸多角形の正確な面積が計算され、0.5 を加算した後、整数変換を使用して丸めが適用されます。 

最もデリケートな部分は、交差計算における浮動小数点の安定性です。 すべての座標は固定された定数構造から導出され、変換されるだけであるため、数値誤差は制御されたままになります。

 ## 特殊なケース

 両方の六角形が同じ下部頂点を共有する場合、すべてのクリッピング ステップで完全な多角形が保持されます。 交差ルーチンは領域を削除しないため、出力面積は 1 つの六角形の面積と等しく、四捨五入して 6 になります。 

六角形が遠く離れている場合、各半平面制約により候補領域全体が早期に削除されます。 クリップ関数はすぐに空のリストを返し、領域は正しく 0 として扱われます。 

変位が小さい場合、特に対称線の近くでは、浮動小数点の精度が重要になります。 クリッピング交差は、ほぼ平行なエッジから計算されますが、ポリゴンは一定のサイズで適切に条件付けされているため、累積誤差は制限されたままであり、最終領域を計算した後の丸めによって小さな数値の偏差が吸収されます。
