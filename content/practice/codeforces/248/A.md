 ## 解決策
 ## 問題の理解

 私たちは食器棚のセットを与えられ、それぞれに左右 2 つのドアが付いています。 各ドアは開閉可能です。 各ドアの初期状態は入力で与えられます。 Karlsson は、すべての左側のドアが同じ位置にあり、すべての右側のドアが同じ位置にあることを望んでいます。 正確なターゲット位置は重要ではありません。すべての左側のドアが一致し、すべての右側のドアが一致することだけが重要です。 この均一性を達成するために必要なドアの開閉の最小数を見つける必要があります。 

入力は整数で構成されます`n`食器棚の数を表し、その後に`n`各戸棚の左右のドアの状態を表す整数のペア。 出力は単一の整数、つまり必要なドアの開閉の最小数です。 

制約`2 ≤ n ≤ 10^4`これは、すべての戸棚を通る単純な線形スキャンが実行可能であることを意味します。 O(n) よりも複雑なアルゴリズムは、制限時間内では危険となる可能性があります。 各ドアの状態は 0 (閉) または 1 (開) なので、各状態の発生を簡単にカウントできます。 明らかではないエッジ ケースには、すべてのドアがすでに同じ位置にある場合、または片側のすべてのドアを反転する方が反対側を反転するより安価である場合が含まれます。 

たとえば、次の入力を考えてみましょう。```
2
0 1
0 0
```左側のドアはすべてすでに同じであるため、左側のドアを裏返す必要はありません。 右側のドアは異なります。最も安価な方法は、異なるドアを反転して (1 が 0 になり)、1 回反転することです。 過半数に基づいて常に反転する単純な実装では、ここでも同じ結果が生成される可能性がありますが、0 と 1 のカウントを慎重に処理することで正確さが保証されます。 

## アプローチ

 ブルートフォース手法では、左側のドアと右側の両方のドアについて考えられる両方の最終状態を試し、各構成に必要なフリップの数を計算し、最小値を選択する必要があります。 左側のドアの場合、これは現在 0 がいくつあるか、1 がいくつあるかを数え、小さい方のカウントを選択して反転することを意味します。 右側のドアについても同じことを繰り返します。 このアプローチは簡単かつ正確で、各食器棚を 1 回スキャンするだけなので、O(n) 時間で実行されます。 

ここでの最適解は基本的に総当たり法と同じです。 重要な洞察は、各側の最終状態には均一性のみが必要であるということです。 したがって、各側で開いているドアと閉じているドアの数を数えて、少数派を反転するだけで済みます。 複雑なシミュレーションや動的プログラミングは必要ありません。 この直接カウント手法により、O(n) 時間と O(1) の追加スペースが実現されます。

 ## アルゴリズムのチュートリアル

 1. 2 つのカウンターを初期化する`left_open`そして`right_open`ゼロに。 これらは、開いている左右のドアの数を追跡します。 
2. 各食器棚について繰り返します。 各戸棚について、左側のドアが開いている場合 (1)、増分します。`left_open`。 右のドアが開いている場合は増加します`right_open`。 
3. 左側のドアに必要なフリップ回数を計算します。 させて`left_closed`なれ`n - left_open`。 左ドアの最小フリップは、次の小さい方です。`left_open`そして`left_closed`。 
4. 同様に、右側のドアの反転回数を計算します。 させて`right_closed`なれ`n - right_open`。 右ドアの最小フリップは、次の小さい方です。`right_open`そして`right_closed`。 
5. 左右のドアの反転を合計して最小反転の合計を取得し、結果を出力します。 

機能する理由: 各ドアには 2 つの状態しかありません。 片側のすべてのドアを均一にするには、開いているすべてのドアを閉じた状態に反転するか、閉じたすべてのドアを開きます。 各州のドアの数を数えると、より安価なオプションを選択できます。 この不変式は、左側と右側の両方に独立して当てはまります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
left_open = 0
right_open = 0

for _ in range(n):
    l, r = map(int, input().split())
    if l == 1:
        left_open += 1
    if r == 1:
        right_open += 1

left_flips = min(left_open, n - left_open)
right_flips = min(right_open, n - right_open)

print(left_flips + right_flips)
```このコードは、最初に食器棚の数を読み取り、次に各食器棚を反復処理して、現在開いているドアの数を数えます。 左右のドアの最小反転を個別に計算し、それらを合計します。 実装上の主な考慮事項には、整数演算を使用してオフバイワンエラーを回避すること、および次を使用して入力を効率的に読み取ることが含まれます。`sys.stdin.readline`より大きな入力の場合。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    left_open = 0
    right_open = 0
    for _ in range(n):
        l, r = map(int, input().split())
        if l == 1:
            left_open += 1
        if r == 1:
            right_open += 1
    return str(min(left_open, n-left_open) + min(right_open, n-right_open))

# provided sample
assert run("5\n0 1\n1 0\n0 1\n1 1\n0 1\n") == "3", "sample 1"

# all same doors
assert run("3\n0 0\n0 0\n0 0\n") == "0", "all closed"

# all open
assert run("2\n1 1\n1 1\n") == "0", "all open"

# mixed minimal flips
assert run("4\n0 1\n1 1\n0 0\n1 0\n") == "2", "mixed doors"

# minimum size
assert run("2\n0 1\n1 0\n") == "2", "minimum cupboards"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 5つの食器棚が混在 | 3 | 標準ケースマッチングサンプル |
 | 3 全て閉店 | 0 | フリップは必要ありません |
 | 2 全て開いています | 0 | フリップは必要なく、すべてオープン |
 | 4 混合 | 2 | マイノリティ反転の正しい計算 |
 | 2 最小サイズ | 2 | アルゴリズムは最小の入力を処理します |

 ## 特殊なケース

 次のような、最初はすべてのドアが同じである食器棚の場合:```
3
0 0
0 0
0 0
```このアルゴリズムでは、左側と右側の両方で開いているドアがゼロであるとカウントされます。 最小反転は両側とも min(0,3) = 0 であるため、反転は発生しません。 これにより、すでに均一なドアのエッジケースが正しく処理されます。 同様に、すべてのドアが開いている場合、アルゴリズムはゼロ フリップを出力します。 カウントが同数 (開いたドアと閉じたドアの数が等しい) の場合、アルゴリズムはどちらかを選択し、正しい最小限の反転が得られます。
