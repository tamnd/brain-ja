 ## 解決策
 ## 問題の理解

 私たちは、左側に垂直線上のゴール セグメントが含まれる長方形のサッカー フィールド内で作業しています。$x = 0$、右側には高さに水平な壁が含まれています$y = y_w$。 ボールは指定された点から始まります$(x_b, y_b)$そして、その水平壁上の選択された点に向かって直線として蹴らなければなりません。 壁にぶつかると、入射角と反射角が同じになるように完全に反射し、ゴールラインに向かって直進します。 

目標は、ゴールラインに当てることだけではなく、水平の壁でちょうど 1 回バウンドした後、ボールがラインのセグメントを横切ることです。$x = 0$間$y_1$そして$y_2$。 キッカーは任意のポイントを選択できます$(x_w, y_w)$目標は、そのような点が存在するかどうかを判断し、存在する場合はその点を出力することです。$x$-座標。 

重要な幾何学的複雑さは、ボールに半径があることです。$r$したがって、壁または柱に「接触」すると、ボールの中心が距離内に留まると解釈されます。$r$。 これにより、特にゴールセグメントとフィールドの境界付近に安全マージンが効果的に作成されますが、主要な幾何学的構造は依然として直線の動きと反射によって支配されています。 

制約により、最大の座標が許可されます。$10^6$を強く示唆しています。$O(1)$またはテストケースごとの対数幾何学構造。 壁上の候補点を離散化しようとしたり、多くの選択肢について軌道をシミュレートしようとするソリューションは、遅すぎて数値的に不安定になります。 

選択した反射方向によってボールが退化して壁に向かって戻る場合、微妙なエッジケースが発生します。 ジオメトリによりボールがゴールインターバルを外れるか、「正確に 1 バウンド」条件に違反する場合、答えは次のようになります。$-1$。 

## アプローチ

 甘い考えは、ターゲット ポイントの候補を多数試してみることです。$(x_w, y_w)$壁に沿って、軌道をシミュレートし、パスを反映して、最終セグメントがゴール区間を横切るかどうかを確認します。 これには、候補ごとに壁との交点を計算し、反射光線がセグメントに当たるかどうかを確認する必要があります。$[y_1, y_2]$。 壁を細かく離散化したとしても、例えば$10^5$各シミュレーションには浮動小数点ジオメトリと交差チェックが含まれますが、これは非常に遅くて壊れやすいものです。 

重要な観察は、目的地を鏡映するという標準的な幾何学的トリックを使用して、水平線を横切る反射を完全に除去できることです。 バウンドについて考える代わりに、壁を越えてゴール ラインを反映し、壊れたパスを開始点からミラーリングされたゴール点までの単一の直線セグメントに置き換えます。 バウンス ポイントは、このセグメントと壁の正確な交点になります。 

This converts the problem into choosing a point$y$ゴール間隔で、からのラインが$(x_b, y_b)$に$(0, 2y_w - y)$線と交差します$y = y_w$有効な$x_w$。 残りの唯一の制約は、スタートを出た後、ミラーリングされたゴールに到達する前に交差が発生する必要があるということです。これは、直線のパラメーターに関する単純な不等式に変換されます。 

すべてを試すことができるため、ブルートフォースが機能します$y \in [y_1, y_2]$, しかし、これは不要です。 制約の構造により、問題は間隔が次のとおりであるかどうかを確認するだけになります。$[y_1, y_2]$一次不等式を満たす任意の値が含まれます。

 ## アルゴリズムのチュートリアル

 私たちは完全にミラーリングされた目標構築の観点から取り組んでいます。 

1. ボールから壁までの垂直距離を計算します。$d = y_w - y_b$。 入力制約があるため、これは正の値です。 
2. 選択したゴールポイントに対して$y \in [y_1, y_2]$、壁を挟んで鏡映された位置を次のように定義します。$y' = 2y_w - y$。 これにより、2 セグメントの反射パスが次の直線に変換されます。$(x_b, y_b)$に$(0, y')$。 
3. ラインが到達すると壁との交差が発生します$y = y_w$。 セグメントに沿って、補間パラメータを次のように表すことができます。$$t = \frac{y_w - y_b}{y' - y_b}.$$これは、壁の高さに到達するために必要な水平移動の割合です。 

1. 壁上の交点は x 座標を持ちます$$x_w = x_b(1 - t).$$これは、次の間の線形補間から得られます。$x_b$そして$0$。 

1. ジオメトリが有効であるためには、交点が始点とミラーリングされた終点の間にある必要があります。$t \in (0,1)$。 この条件は次の制約に変わります。$y$: 値$y$～の側に寝なければなりません$y_b$反対の$y_w$、そして十分に遠いので、$|y - y_b| > y_w - y_b$。 
2.間隔を確認する$[y_1, y_2]$そして、この不等式を満たす値が少なくとも 1 つ含まれているかどうかを判断します。 「はい」の場合、構築します$y$、計算する$y'$、計算する$t$、そして計算します$x_w$。 
3. 有効でない場合$y$存在する場合は出力します$-1$。 

### なぜ効果があるのか

 正確さは反射の等価性によって決まります。つまり、水平線上の 1 回の反射は、反射されたターゲットへの直線の経路と正確に等価です。 すべての有効なバウンス軌道は、ミラーリングされたポイントへの 1 つの直線セグメントに正確に対応し、セグメント制約内の点で壁と交差するすべてのそのようなセグメントは、有効な物理的な軌道に対応します。 上の不平等$t$ミラーリングされたゴールに到達する前とスタート地点を出た後に交差点が発生するようにし、壁を越えて縮退した延長を防ぎます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    y1, y2, yw, xb, yb, r = map(float, input().split())

    # We need to find y in [y1, y2] such that:
    # |y - yb| > (yw - yb)

    d = yw - yb

    candidates = []

    # check lower side
    if y1 <= yb - d:
        candidates.append(y1)

    # check upper side
    if y2 >= yb + d:
        candidates.append(y2)

    if not candidates:
        print(-1)
        return

    # pick any valid candidate
    y = candidates[0]
    yp = 2 * yw - y

    t = (yw - yb) / (yp - yb)
    xw = xb * (1 - t)

    print(f"{xw:.10f}")

if __name__ == "__main__":
    solve()
```このコードは、ミラーリングされたポイント削減を直接適用します。 唯一重要な決定は、有効なオプションを選択することです。$y$ゴール間合いから。 実現可能条件は 2 つの互いに素な領域に分割されるため、間隔のエンドポイントをテストするだけで十分です。 

の計算$t$垂直座標の線形補間から直接得られ、$x_w$ボールからミラーリングされたゴールまでのセグメントに沿った比例的な動きによって導出されます。

 ## 特殊なケース

 ゴール間隔が壁に対するボールの垂直位置に完全に近すぎる場合、この条件は$|y - y_b| > y_w - y_b$どこでも失敗します。 このような場合、どの候補者も$y$無効なパラメータで壁に衝突するか、開始側に向かって反射する軌道が生成され、アルゴリズムはそのインスタンスを正しく拒否します。 

間隔が実現可能性の境界にほとんど触れない場合、1 つのエンドポイントのみが機能します。 このアルゴリズムは、有効な領域が切断されている縮退ケースでは失敗する中間点推論を試行するのではなく、両方のエンドポイントを明示的にチェックするため、安定した状態を保ちます。
