 ## 解決策
 ## 問題の理解

 最大 10 万の頂点とエッジを持つ接続された無向グラフが与えられます。 すべての頂点には、通常値と割引値という 2 つの値があります。 各頂点について、最終的な重みとしてこれら 2 つの値のうち 1 つを正確に選択する必要があります。 

目標は、合計や単一の頂点を最適化することではなく、グラフ全体にわたる最悪の不一致を制御することです。 すべてのエッジについて、そのエンドポイントの選択された値間の絶対的な差を調べます。 すべてのエッジの中で、そのような差の最大値を取得します。どの頂点が通常の値を使用し、どの頂点が割引値を使用するかを選択することで、この最大値をできるだけ小さくしたいと考えています。 

構造は重要です。各頂点は独立して 2 つの選択肢ですが、各エッジは、結果として生じる数値の差に対する制約を通じて 2 つの選択肢を結合します。 これは、問題が局所的な最適化ではなく全体的な一貫性に起因していることを直ちに示唆しています。 

この制約は、代入の数が 2^n であるため、すべての代入を試行する解決策は不可能であることを意味します。 1 つの割り当てをチェックするだけでも O(n + m) であり、これはすでに最大入力サイズの境界線に達しています。 したがって、解決策では問題を多項式時間の実現可能性チェックに落とし込み、答えを探索する必要があります。 

いくつかのエッジケースは、単純な推論が失敗する理由を明らかにします。 1 つのエッジを除いてすべての頂点が分離されている場合、問題はそのエッジに対して 4 つの可能な組み合わせを選択することになり、答えは単純にそれら 4 つの中で可能な最小の差になります。 しかし、チェーンでは、各頂点が複数の制約に関与するため、1 つのエッジに対して局所的に最適な割り当てを選択すると、後で不適切な割り当てが強制される可能性があります。 

もう 1 つの微妙なケースは、頂点の 2 つの可能な値の間に非常に大きなギャップがある場合に発生します。 たとえば、1 つのノードの値が 1 と 10^9 である場合、そのノードは隣接するエッジの実現可能性に大きな影響を与える「スイッチ」として機能する可能性があります。 同じ頂点が制約全体で再利用されるため、エッジごとに貪欲な決定は失敗します。 

## アプローチ

 ブルートフォースのアイデアは、各頂点に通常値または割引値を割り当て、最大エッジ差を計算することです。 これは問題を正しく解決しますが、すべての 2^n 代入を調べますが、これは n が約 40 の場合でも不可能です。 

より構造化された方法で問題を再構成できます。 答え X を修正し、すべてのエッジが |wu − wv| を満たすように値を選択できるかどうかを尋ねるとします。 ≤ X。これを効率的にテストできれば、有効な最小 X を二分探索できます。 

X が固定されている場合、各頂点には依然として 2 つの状態があります。 ただし、各エッジは許可される状態のペアを制限します。 u と v の間のエッジは、X を超える差を生み出す選択のペアを禁止します。これにより、すべてのエッジが 2 つのバイナリ変数間の禁止された状態の組み合わせのセットに変わります。 これはまさにブール変数に関する制約充足問題であり、2-SAT インスタンスとしてモデル化できます。 

各頂点はブール変数です。通常の値または割引された値を選択します。 各エッジは、どの組み合わせが無効であるかに応じて、これらの変数間の影響に影響を与えます。 特定の割り当てのペアが禁止されている場合は、残りの選択肢の少なくとも 1 つを強制する意味を追加します。 

2-SAT グラフに変換すると、O(n + m) の強接続成分を使用して実現可能性を確認できます。 X に対する二分探索内でこれを繰り返すと、最終的な解が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース割り当て | O(2^n・m) | O(n) | 遅すぎる |
 | 二分探索 + 2-SAT | O((n + m) log C) | O(n + m) | 承認済み |

 ここで C は、最大 10^9 までの可能な差の範囲です。 

## アルゴリズムのチュートリアル

 各頂点 i をブール変数 xi としてエンコードします。 xi = 0 の場合、ai を選択します。 xi = 1 の場合、bi を選択します。

次に、答え X を二分探索します。 

1. 候補値 X を修正し、有効な割り当てが存在するかどうかを判断します。 
2. 各エッジ (u, v) について、(au, av)、(au, bv)、(bu, av)、(bu, bv) の 4 つの可能な選択肢の組み合わせを調べます。 絶対差が X を超えるペアは禁止されます。 
3. すべての禁止されたペアについて、それを暗示に変換します。 組み合わせ (u = p、v = q) が無効な場合、両方が起こらないよう強制します。これは、「if u = p then v ≠ q」および「if v = q then u ≠ p」という形式の意味になります。 
4. 各変数とその否定を表す 2n 個のノードを含む含意グラフを構築します。 
5. このグラフの強連結成分を計算します。 変数とその否定が同じコンポーネント内にある場合、この X への代入は不可能です。 
6. 矛盾が存在しない場合、X は実行可能であるため、二分探索範囲を下に移動します。 それ以外の場合は、X を増加します。 

二分探索は実行可能な最小の X に収束します。 

重要な特性は、固定 X に対するすべての制約が二項選択間の純粋に論理的な含意であるため、充足可能性は有向含意グラフでの一貫性のチェックに帰着するということです。 

### なぜ効果があるのか

 固定しきい値 X の場合、すべてのエッジ制約は、その 2 つの端点の選択された状態にのみ依存します。 これは、問題全体がローカルのバイナリ制約に分解されることを意味します。 ローカルで禁止されているペアは論理的な含意として表すことができ、すべての制約が一緒になって 2-SAT インスタンスを形成します。 SCC 条件はグローバルな一貫性を保証します。つまり、変数がそれ自体の否定を暗黙的に示す場合、すべての暗示を満たす代入はできません。逆に、そのようなサイクルが存在しない場合は、有効な代入が存在することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

class TwoSAT:
    def __init__(self, n):
        self.n = n
        self.g = [[] for _ in range(2*n)]
        self.gr = [[] for _ in range(2*n)]

    def add_implication(self, a, b):
        self.g[a].append(b)
        self.gr[b].append(a)

    def add_or(self, a, b):
        self.add_implication(a ^ 1, b)
        self.add_implication(b ^ 1, a)

    def satisfiable(self):
        n = 2 * self.n
        visited = [False] * n
        order = []

        def dfs1(v):
            visited[v] = True
            for to in self.g[v]:
                if not visited[to]:
                    dfs1(to)
            order.append(v)

        comp = [-1] * n

        def dfs2(v, c):
            comp[v] = c
            for to in self.gr[v]:
                if comp[to] == -1:
                    dfs2(to, c)

        for i in range(n):
            if not visited[i]:
                dfs1(i)

        j = 0
        for v in reversed(order):
            if comp[v] == -1:
                dfs2(v, j)
                j += 1

        for i in range(0, n, 2):
            if comp[i] == comp[i ^ 1]:
                return False
        return True

def possible(n, edges, a, b, x):
    ts = TwoSAT(n)

    def var(i):
        return 2 * i

    def neg(i):
        return i ^ 1

    for u, v in edges:
        u -= 1
        v -= 1

        u0, u1 = var(u), var(u) ^ 1
        v0, v1 = var(v), var(v) ^ 1

        def add_forbidden(xu, xv):
            ts.add_or(neg(xu), neg(xv))

        # enumerate all pairs
        vals_u = [(0, a[u]), (1, b[u])]
        vals_v = [(0, a[v]), (1, b[v])]

        for su, vu in vals_u:
            for sv, vv in vals_v:
                if abs(vu - vv) > x:
                    # forbid (su, sv)
                    if su == 0:
                        xu = var(u)
                    else:
                        xu = var(u) ^ 1
                    if sv == 0:
                        xv = var(v)
                    else:
                        xv = var(v) ^ 1
                    ts.add_or(xu ^ 1, xv ^ 1)

    return ts.satisfiable()

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    edges = [tuple(map(int, input().split())) for _ in range(m)]

    lo, hi = 0, 10**9

    while lo < hi:
        mid = (lo + hi) // 2
        if possible(n, edges, a, b, mid):
            hi = mid
        else:
            lo = mid + 1

    print(lo)

if __name__ == "__main__":
    solve()
```この実装では、実現可能性チェックが二分探索から分離されます。 TwoSAT 構造は含意エッジを使用して構築され、充足可能性は Kosaraju の強接続コンポーネント アルゴリズムを使用してテストされます。 

最もデリケートな部分は、禁止されたペアを意味に変換することです。 禁止された各割り当ては、解空間から 1 つのエッジを削除し、残りのオプションの少なくとも 1 つを強制します。 これはまさに 2-SAT で使用される論理 OR 構造です。

 ## 特殊なケース

 重要なエッジ ケースは、すべての頂点が同じ ai と bi を持つ場合です。 その場合、すべての割り当ては同一の構造を生成するため、答えは単純に固定値の最大エッジ差となり、2-SAT グラフはそれを超える任意の X について自明に満足できるままになります。 

もう 1 つのエッジ ケースは、頂点の ai と bi が極端に離れている場合です。 この頂点は、複数のエッジの実現可能性を同時に反転できます。 含意グラフでは各状態が独立して処理されるため、アルゴリズムはこれを正しく処理します。そのため、大きな数値ギャップは構造の正確さに影響を与えません。 

最後のエッジ ケースは、完全に接続された密なグラフです。 多くのエッジがあっても、各エッジは一定サイズの制約のみに寄与するため、SCC 構造は合計入力サイズにおいて線形のままであり、二分探索ではその構造は変わりません。
