 ## 解決策
 ## 問題の理解

 私たちは四角いオフィスを与えられましたが、その左と下の壁しか存在しません。 上部と右側は開いており、継続的な入射光源のように機能します。 太陽光線は開いた境界からオフィスに入り、ベクトルで指定された一定の方向に移動します。$(x_s, y_s)$、両方の成分が正ではなく、少なくとも 1 つは厳密に負であるため、光線は常に正方形の内部に向かって移動します。 

オフィス内にはいくつかのデスクセグメントがあります。 開いた境界から入った光線は直線的に進み、いくつかの机と交差する場合があります。 開いた境界の一部にカーテンを設置することが許可されています。 境界点にカーテンを置くと、その点を通過するあらゆる光線が遮断され、オフィス内への光線の侵入がまったく妨げられます。 

目標は、境界に沿って使用されるカーテンの全長を最小限に抑えながら、机のセグメントと交差するすべての光線をブロックすることです。 

重要な点は、各光線が一意の境界エントリ ポイントに対応していることです。 問題は、正方形内の光線の観点から考えるのではなく、任意のセグメントに当たるすべての光線を「カバーする」最小長の境界点のセットを選択することになります。 

この制約は、光線の単純なシミュレーションが不可能であることを直ちに示唆します。 まであります$2 \cdot 10^5$セグメントと座標まで$10^9$したがって、光線ごとまたは境界点ごとにジオメトリをトレースするソリューションは実行不可能です。 構造は 2D ジオメトリを 1D 間隔カバー問題に折りたたむ必要があります。 

単純な間違いは、各デスクを独立して扱い、独自のカーテン間隔を割り当てることです。 1 つのカーテンが 2 つのセグメントを同時に覆うサンプルに見られるように、複数の机が光線のセットの重なりによってブロックされる可能性があるため、これは失敗します。 

セグメントが光線方向に平行な場合、別の微妙な故障モードが発生します。 その場合、光線は完全にそれを見逃すか、正の長さの境界間隔を強制することなくそれに沿って通過するため、ブロッキング要件には影響しません。 

## アプローチ

 ブルートフォース解釈では、すべての境界点からオフィスに侵入するすべての光線をシミュレートし、どの机に最初に到達するかを判断し、その侵入点を禁止としてマークします。 これは幾何学的には明確に定義されていますが、計算上は不可能です。 境界は連続的であり、事実上無限のサンプリングが必要であり、細かく離散化したとしても法外な複雑さになります。 

重要な観察は、光線は境界との交差によって完全に決定されるということです。 すべての光線は同じ方向に移動するため、光線の平行移動は、その入口点を境界に沿ってスライドさせることに相当します。 机のセグメントごとに、それに当たる一連の光線が境界に沿って連続した間隔を形成します。 すべてのセグメントをそのような間隔にマッピングすると、問題はすべての間隔をカバーする線上の点の最小合計長を選択することになります。これは、間隔の和集合の全長を正確に計算することになります。 

幾何学的ステップでは、セグメントの端点ごとに、光線が通過する境界に沿ったパラメーター値を計算します。 光線は方向を持って移動するため、$(x_s, y_s)$、垂直投影を使用して点を変換します$(x, y)$スカラー座標に変換します。$$t = x \cdot (-y_s) + y \cdot x_s$$この値は、光線が発生する境界に沿った位置に比例します。 各セグメントは間隔を生成します。$[t_1, t_2]$、結合の長さを計算します。

 ## アルゴリズムのチュートリアル

 1. 各セグメントのエンドポイントに対して、スカラー投影値を計算します。$t = x \cdot (-y_s) + y \cdot x_s$。 これにより、2D ジオメトリが、光線に直交する境界方向に沿った 1D 順序に変換されます。 
2. セグメントごとに間隔を形成します。$[min(t_1, t_2), max(t_1, t_2)]$。 この間隔は、セグメントと交差するすべての光線の起点を表します。 
3. すべての間隔をリストに収集します。 
4. 間隔を左側のエンドポイントで並べ替えます。 重複する構造はソートされた順序でのみ表示されるため、ソートが必要です。 
5. 現在のマージされたカバレッジ間隔を維持しながら、間隔をスイープします。 次の間隔が現在の間隔と重なったり接触したりする場合は、それを延長します。 それ以外の場合は、現在の間隔の長さを回答に追加し、新しい間隔を開始します。 
6. すべての間隔を処理した後、最後のアクティブな間隔の長さを追加します。 

最終的な答えは、すべての投影された間隔の合計長さです。 

### なぜ効果があるのか

 すべての光線は平行であるため、境界の入口点から任意の内部ラインへのマッピングはアフィンです。 セグメントは、その入口点が連続範囲内にある光線と正確に交差するため、各セグメントは 1D 空間の単一の間隔に対応します。 カーテンの配置はすべて、この 1D ラインの一部を削除することに対応し、すべてのセグメントをブロックするには、すべての間隔をカバーする必要があります。 したがって、カーテンの最小合計長は、これらの間隔の和分の正確な測定値となり、スイープでは重なり合わずに計算されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, xs, ys = map(int, input().split())
    k = int(input())

    intervals = []

    # projection direction perpendicular to ray direction
    # using a consistent linear form
    dx = -ys
    dy = xs

    for _ in range(k):
        x1, y1, x2, y2 = map(int, input().split())

        t1 = x1 * dx + y1 * dy
        t2 = x2 * dx + y2 * dy

        l, r = (t1, t2) if t1 <= t2 else (t2, t1)
        intervals.append((l, r))

    intervals.sort()

    ans = 0
    cur_l, cur_r = intervals[0]

    for l, r in intervals[1:]:
        if l <= cur_r:
            if r > cur_r:
                cur_r = r
        else:
            ans += cur_r - cur_l
            cur_l, cur_r = l, r

    ans += cur_r - cur_l

    print(f"{ans / (dx*dx + dy*dy) ** 0.5:.10f}")

if __name__ == "__main__":
    solve()
```コードはまず光線方向を垂直投影ベクトルに変換します。$(dx, dy)$。 これにより、同じ投影値が同じ境界線に沿って入射する光線に対応することが保証されます。 各デスクのエンドポイントはこの 1D 座標に投影され、間隔が形成されます。 

スイープ ステップでは、重複する範囲をマージし、共有カバレッジが 1 回カウントされるようにします。 最後に、座標スケールが境界に沿った実際の幾何学的な長さと一致するように、投影ベクトルの長さによって正規化します。 

実装でよくある落とし穴は、正規化ステップを忘れることです。 この投影では、任意の線形スケールで値が生成されるため、ベクトルの大きさで除算しないと、結果は次の条件に応じて定数係数だけずれてしまいます。$(x_s, y_s)$。 

## 実用的な例

 ### サンプル 1

 入力:```
6 -2 0
1
2 1 4 2
```ここ$dx = 0$、$dy = -2$。 

| エンドポイント | t値 |
 | --- | --- |
 | (2,1) | -2 |
 | (4,2) | -4 |

 間隔は[-4,-2]となります。 

結合する必要はありません。 

答えは間隔の長さを次の値で割ったものです$\sqrt{dx^2 + dy^2} = 2$、与える:$$\frac{2}{2} = 1$$これは、単一のセグメントが 1 つの連続したブロック範囲に明確にマッピングされていることを示しています。 

### サンプル 2

 入力:```
6 0 -2
1
2 1 4 2
```今$dx = 2$、$dy = 0$。 

| エンドポイント | t値 |
 | --- | --- |
 | (2,1) | 4 |
 | (4,2) | 8 |

 間隔は [4, 8]、長さ 4、次のように正規化されます。$\sqrt{4} = 2$、2を与えます。 

これは、境界に沿った水平カバレッジをマッピングする垂直光線に対応します。

 ## 特殊なケース

 重要なエッジ ケースは、セグメントが光線の方向に平行である場合です。 この状況では、両方のエンドポイントが同じ値に投影し、長さ 0 の間隔が生成されます。 結合長は増加しないため、アルゴリズムは当然これを無視します。 

もう 1 つのケースは、多くの重複セグメントがチェーンを形成している場合です。 スイープではそれらが 1 つの連続した間隔に正しくマージされ、二重カウントが防止されます。 

最後に、セグメントが遠く離れている場合、アルゴリズムは、別々のカーテンセクションの必要性に合わせて、長さが独立して合計されるばらばらの間隔を生成します。
