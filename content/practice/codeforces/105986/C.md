 ## 解決策
 ## 問題の理解

 寸法を持つ長方形のグリッドが与えられます$n \times m$。 このグリッドには、$k$鉱物畑。 各鉱物フィールドは中央のセルによって定義されます$(x_i, y_i)$とチェビシェフ半径$dis_i$、つまり、行と列の両方がその中にあるすべてのグリッド セルを占有します。$dis_i$センターの。 幾何学的には、各フィールドは、次の点を中心とする実線の軸に沿った正方形です。$(x_i, y_i)$。 

発射プラットフォームもグリッドセルの中心に配置したいと考えています$(x, y)$ですが、今回の影響はマンハッタン距離によって定義されます。マンハッタン距離が以下のすべてのセルを占有します。$(x, y)$せいぜい$D$。 重要な制約は、これらのプラットフォーム セルが鉱物フィールド セルと重複できないことです。 プラットフォームの中心はグリッドの内側にある必要がありますが、占有領域は外側に拡張することができます。 

タスクは、有効な中心を選択することです$(x, y)$そして最大化する$D$。 半径ゼロのプラットフォームさえも許可するセンターがない場合は、-1 を出力します。 

制約$n, m, k \le 500$までを暗示$2.5 \times 10^5$グリッドセルと500個の正方形の障害物。 考えられるすべての中心と半径にわたる直接シミュレーションはすでに厳密ですが、各チェックが効率的であれば管理可能です。 本当に難しいのは、大きな幾何学的領域間の重複チェックを繰り返し再計算することを避けることです。 

鉱物フィールドがグリッド全体を覆う場合、微妙なエッジケースが現れます。 この状況では、半径ゼロのプラットフォームであっても占有セルとどこでも交差するため、有効な中心は存在せず、答えは -1 でなければなりません。 もう 1 つのエッジ ケースは、完全にフリーのセルが少なくとも 1 つ存在する場合です。 その場合、答えは少なくとも 0 ですが、チェビシェフ正方形とマンハッタン ダイヤモンドのように形状が異なるため、最適な半径は最も近いブロックされたセルまでの距離によって決まります。 

## アプローチ

 センター候補を固定するという甘い考え$(x, y)$、その後増加します$D$マンハッタンのダイヤモンドが鉱物の正方形と交差するまで。 各チェックでは、すべての鉱物フィールドをスキャンし、占有されている正方形が現在のダイヤモンドと交差するかどうかを確認する必要がありますが、これはすでに高価です。 以来$D$まで成長することができます$n+m$、そして、あります$O(nm)$センターでは、これでは非常に遅くなります。 

重要な観察は、視点を反転することです。 ひし形を拡大して固定正方形と照合する代わりに、各グリッド セルについて、マンハッタン メトリックで最も近い禁止領域にどれだけ近いかを尋ねます。 鉱物フィールドによって占有されているすべてのセルをマークできた場合、問題は次のようになります。自由セルごとに、占有されているセルまでの最小マンハッタン距離を計算します。 その値はまさに有効な最大値です$D$そこを中心としたプラットフォームのために。 

したがって、問題全体は、禁止されたセルのバイナリ グリッドを構築し、マンハッタンの距離にわたってマルチソース BFS を実行することに帰着します。 すべての鉱物正方形がソースであり、BFS はグリッド上に拡張され、禁止されたセルまでの最小距離を計算します。 鉱物フィールド内のセルは距離 0 で、自由セルはマンハッタン メトリックで最も近い禁止セル境界までの距離を継承します。 答えはすべてのフリーセルの最大値です。 

唯一の問題は、禁止されたグリッドを効率的に構築することです。 各鉱物フィールドはチェビシェフ正方形であるため、次の 2D 差分配列を使用してその長方形をマークできます。$O(1)$フィールドごとに、その後プレフィックス合計を計算して最終的なカバレッジを取得します。 After that, BFS is straightforward.

 ## アルゴリズムのチュートリアル

 まず、どのセルが少なくとも 1 つの鉱物フィールドによって占められているかを示すグリッドを構築します。 各鉱物フィールドは軸が揃った正方形であるため、2D 差分配列を使用してその長方形に +1 を追加し、後でプレフィックス合計によってカバレッジを回復します。 

すべての占有セルがわかったら、距離 0 のすべての占有セルで BFS キューを初期化します。これにより、鉱物で覆われたすべてのセルが汚染源として扱われます。 

次に、4 近傍グリッド上で標準のマルチソース BFS を実行します。 セルから隣接する空きセルに拡張するたびに、親の距離にまだアクセスしていない場合は 1 を加えたものに等しい距離をそのセルに割り当てます。 この距離は、最も近い占有セルまでのマンハッタン距離を表します。 

BFS が終了すると、すべてのセルは鉱物フィールド セルまでの最小マンハッタン距離になります。 

最後に、占有されていないすべてのセルをスキャンし、最大距離値を取得します。 その値は可能な最大の半径です$D$そこを中心としたプラットフォームのために。 

占有されていないセルがない場合は、-1 を出力します。 

これが機能する理由は、グリッド エッジ上の BFS がマンハッタン グラフの最短経路距離を計算し、すべてのミネラル セルがソースであるため、すべてのフリー セルが最も近い禁止セルまでの距離でラベル付けされるためです。 半径のプラットフォーム$D$セルを中心とするセルは、禁止されたセルがマンハッタン距離内に存在しない場合に正確に有効です。$D$これは、最も近い禁止セルの距離が厳密に より大きいと言うのと同じです。$D$。 したがって、可能な限り最善の$D$は、すべての有効な中心間の正確な最大最短経路距離です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())
    
    diff = [[0] * (m + 2) for _ in range(n + 2)]

    for _ in range(k):
        x, y, d = map(int, input().split())
        x0, x1 = max(1, x - d), min(n, x + d)
        y0, y1 = max(1, y - d), min(m, y + d)
        diff[x0][y0] += 1
        diff[x1 + 1][y0] -= 1
        diff[x0][y1 + 1] -= 1
        diff[x1 + 1][y1 + 1] += 1

    grid = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            grid[i][j] = (diff[i][j]
                          + grid[i - 1][j]
                          + grid[i][j - 1]
                          - grid[i - 1][j - 1])

    from collections import deque
    dist = [[-1] * (m + 1) for _ in range(n + 1)]
    q = deque()

    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if grid[i][j] > 0:
                dist[i][j] = 0
                q.append((i, j))

    if len(q) == n * m:
        print(-1)
        return

    directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

    while q:
        x, y = q.popleft()
        for dx, dy in directions:
            nx, ny = x + dx, y + dy
            if 1 <= nx <= n and 1 <= ny <= m and dist[nx][ny] == -1:
                dist[nx][ny] = dist[x][y] + 1
                q.append((nx, ny))

    ans = 0
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if grid[i][j] == 0:
                ans = max(ans, dist[i][j])

    print(ans if ans > 0 else 0)

if __name__ == "__main__":
    solve()
```解決策は、各鉱物フィールドを長方形の更新に変換することから始まります。 プレフィックス合計の再構成により、各セルが少なくとも 1 つの正方形に属しているかどうかがわかります。 その後、占有されているすべてのセルが BFS にシードされます。これは、複数のソースの距離の問題を 1 つの走査に変えるため、非常に重要です。 

距離配列には、グリッド グラフ内のマンハッタン距離が格納されます。 定義上、占有セルでの起動は無効であるため、最終スキャンでは占有されていないセルのみが考慮されます。 答えは、有効な中心間の最大距離です。 

完全にカバーされたグリッドを早期にチェックすることで、不必要な BFS が防止され、「-1」のケースが処理されます。

        diff[x0][y1 + 1] -= 1

        for j in range(1, m + 1):

 ## 特殊なケース

 完全に覆われたグリッドは、BFS は実行されますが、有効な中心が生成されないため、最もデリケートなケースです。 アルゴリズムは、初期化中にソースをカウントすることによってこれを明示的に処理します。 すべてのセルがソースである場合、スキャン距離なしですぐに -1 を返します。 

鉱物フィールドのないグリッドはその対極です。 その場合、BFS は空のキューから開始されますが、実装ではすべてのセルを空きとして扱い、距離を -1 のままにすることでこれを回避します。 正しい解釈は、禁止領域が存在しないため、すべてのセルが有効であり、答えが 0 であるということです。実装は、最終スキャン後にデフォルトで 0 に設定することでこれを解決します。 

1×1 などの小さなグリッドは、境界条件が正しく処理されるかどうかをテストします。 唯一のセルが占有されている場合、早期終了は正しくトリガーされます。 それ以外の場合は距離 0 が返されます。
