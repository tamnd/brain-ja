 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、$N$各ノードには 1 つの大文字が含まれます。 ツリーの構造は固定されていますが、任意のノードを選択できます。$u$根として。 ルート化されると、すべてのノードは、それ自体とその下のすべてのノードで構成されるルート化されたサブツリーを定義します。 

ルートの選択ごとに$u$、そのルート付きツリー内の空ではないすべてのルート付きサブツリーを考慮します。 各サブツリーは、「ノードとそのすべての子孫」という形式のノードの接続されたセットに対応します。 このようなサブツリーごとに、その中の複数の文字セットを調べ、それらの文字を並べ替えて回文を形成できるかどうかを尋ねます。 複数の文字セットは、最大 1 つの文字が奇数の頻度を持つ場合に正確に回文に置き換えることができます。 

タスクは、考えられるすべてのルートを計算することです$u$、この回文再配置条件を満たすルート付きサブツリーの数。 

重要な点は、ルートを変更すると、「サブツリー」としてカウントされるものが変わることです。 親子の方向が変化するため、ルートが配置される場所に応じて、同じノードのセットが有効なルート付きサブツリーとして表示される場合と表示されない場合があります。 

制約は次のとおりです$2 \cdot 10^5$これにより、ルートごとにサブツリー情報を個別に再計算するアプローチは即座に除外されます。 一枚でも$O(N)$ルートごとに次のようになります$O(N^2)$、これは実現可能な限界をはるかに超えています。 異なるルート間で計算を再利用できるグローバル構造が必要です。 

問題を露呈させる単純なエッジ ケースは、パス グラフです。 一部のセグメントのみが有効な回文マルチセットを形成するように文字が配置されている場合、部分木のセグメントは方向に応じて接頭辞のような構造または接尾辞のような構造になるため、ルートがどこに配置されるかによって答えは大きく変わります。 

## アプローチ

 まずは直接的な解釈から始めましょう。 ルートを修正する$u$、次にルート化されたすべてのサブツリーを計算します。 簡単な方法は、すべてのノードをサブツリーのルートとして扱い、すべての子孫セットをカウントすることです。 このようなサブツリーごとに、文字の頻度をカウントし、パリティ条件をチェックします。 これはすでに二重ループを示唆しています。ルートごとにすべてのサブツリーを探索し、サブツリーごとに頻度ヒストグラムを計算します。 

1 つのルート ツリー内でプレフィックス頻度のアイデアを再利用したとしても、依然として大きな構造上の問題に直面します。ルートを変更すると、親子関係が変化するため、サブツリーの分解が完全に変化します。 これでは、ルートごとにゼロから再計算するという望みは打ち砕かれます。 

重要な観察は、視点を逆転させることです。 ルート付きサブツリーの観点から考える代わりに、あるルートの下にルート付きサブツリーとして現れる可能性があるすべての接続されたサブグラフを考慮してください。 ノードのセットは、そのセットの中でルートに最も近いノードが 1 つだけ含まれている場合に限り、選択したルートに対して有効なルート付きサブツリーを形成します。 そのノードは、誘導された方向の最上位要素として機能します。 

この再定式化により、ルートを切り離すことができます。 接続されている各サブセットについて考えて、このサブセットはルートがいくつあると有効なルート付きサブツリーとして表示されるでしょうか?

 現在、回文条件はルートとは関係なく、サブセット内の文字パリティのみに依存します。 したがって、問題は 2 つの部分に分かれます。つまり、すべてのルートにわたるルート付きサブツリーとして接続されたサブセットの構造的なカウントと、各サブセットの静的プロパティのチェックです。 

中心となるトリックは、セントロイド分解と文字のビットマスク パリティを組み合わせて使用​​することです。 各サブセットの回文条件は、最大 1 ビット セットを持つ XOR パリティ マスクと同等です。 分解中に、パスを列挙して XOR 状態を維持し、有効な組み合わせをカウントします。 各重心の寄与は、最高点が特定のルート方向の重心であるすべての接続されたサブセットを表します。 

分解ツリー全体にカウントを慎重に伝播することで、ルートとして機能するすべてのノードの寄与を蓄積します。 

ブルート フォースはすべてのサブセットを暗黙的に列挙し、指数関数的な爆発につながります。 重心分解により、これが次のように圧縮されます。$O(N \log N)$各エッジが確実に参加するようにすることで、$O(\log N)$再帰のレベル。

 ## アルゴリズムのチュートリアル

 各文字を 26 ビット整数のビットとしてエンコードします。 サブツリーの XOR マスクに設定されているビットが最大 1 ビットであれば、サブツリーは有効な回文再配置になります。 

次に、ノードごとに、そのノードの下でルート化されたサブツリーとして機能できる接続されたサブセットが条件を満たす数を数えます。 

1. ツリーの隣接リストを作成し、各文字をビットマスクにマップします。 
2. ツリーに対して重心分解を実行します。 各段階で重心を選択します$c$現在のコンポーネントの。 この重心は、そこを通過するすべての接続されたサブセットの最上位の構造セパレーターとして機能します。 接続されたすべてのサブセットには再帰階層内で固有の最高重心があるため、これは重要な構造分解ステップです。 
3. 重心から$c$、各子サブツリーに対して DFS を実行し、パスに沿って XOR マスクを収集します。$c$。 各パスは、次から始まる接続されたセットを表します。$c$そして下に伸びています。 
4. これまでに確認された XOR マスクの周波数マップを維持します。 新しく検出されたパスマスクごとに$m$、以前に見たマスクの数を数えます$m'$それを満たす$m \oplus m'$最大でも 1 つのビットが設定されています。 これにより、重心を介して 2 つのブランチを結合することによって結合サブセットが形成されることが保証されます。$c$回文有効です。 
5. 重心からのパスのみが既に条件を満たしている (マスクに最大 1 ビットが設定されている) 場合、単一ブランチの寄与もカウントします。 
6.重心処理後$c$、アクティブなツリーからそれを削除し、残りの各接続コンポーネントを再帰的に調べます。 
7. 寄与を蓄積しながら、どのノードがサブツリーのルート (現在の分解に関してそのサブセット内で最も高いノード) として機能するかに応じて、カウントをノードに分配します。 これにより、有効なルート付きサブツリーが有効なルートごとに 1 回だけカウントされるようになります。 

### なぜ効果があるのか

 重心分解では、接続されているノードのすべてのサブセットが、ある再帰レベルで一意の最大重心を持つことが保証されます。 その重心では、サブセットのすべてのノードが個別の子コンポーネント内にあり、サブセットはその重心を通る独立した DFS パスの組み合わせとして完全に表されます。 XOR 条件は連結下で保持され、すべての有効なサブセットがその最高重心で 1 回だけ形成されるため、過剰カウントが防止されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

N = int(input())
s = input().strip()

g = [[] for _ in range(N)]
for _ in range(N - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append(v)
    g[v].append(u)

# bitmask of letters
val = [1 << (ord(c) - 65) for c in s]

# centroid decomposition helpers
sub = [0] * N
dead = [False] * N

ans = [0] * N

def dfs_size(u, p):
    sub[u] = 1
    for v in g[u]:
        if v != p and not dead[v]:
            dfs_size(v, u)
            sub[u] += sub[v]

def dfs_centroid(u, p, n):
    for v in g[u]:
        if v != p and not dead[v] and sub[v] > n // 2:
            return dfs_centroid(v, u, n)
    return u

from collections import defaultdict

def add_paths(u, p, mask, store):
    mask ^= val[u]
    store.append(mask)
    for v in g[u]:
        if v != p and not dead[v]:
            add_paths(v, u, mask, store)

def decompose(root):
    dfs_size(root, -1)
    c = dfs_centroid(root, -1, sub[root])
    dead[c] = True

    freq = defaultdict(int)
    freq[0] = 1

    # process each subtree of centroid
    for v in g[c]:
        if dead[v]:
            continue
        store = []
        add_paths(v, c, 0, store)

        # count pairs with previous subtrees
        for m in store:
            # try match with existing masks in freq
            for k in freq:
                if (m ^ k) & ((1 << 26) - 1) and ((m ^ k) & ((m ^ k) - 1)) == 0:
                    ans[c] += freq[k]
            ans[c] += freq[m]

        for m in store:
            freq[m] += 1

    # include single node centroid itself
    ans[c] += 1

    for v in g[c]:
        if not dead[v]:
            decompose(v)

decompose(0)

for x in ans:
    print(x)
```重心分解は、標準サイズの DFS とそれに続く重心検索を使用して実装されます。 各セントロイドは、その子コンポーネントからすべてのパス XOR マスクを収集します。 の`add_paths`関数は、重心からそのコンポーネント内の到達可能なすべてのノードまでの XOR 状態を収集します。 

の`freq`ディクショナリは、すでに処理されたコンポーネントから各 XOR マスクが何回出現したかを追跡します。 新しいコンポーネントを処理するとき、各パス マスクは以前に保存されたマスクと比較され、XOR によって有効な回文マスク (最大 1 ビット セット) が生成されるかどうかがチェックされます。 これにより、重心を通過するすべての有効な組み合わせが確実にカウントされます。 

微妙な点は、単一コンポーネントのパスも経由でカウントされることです。`ans[c] += freq[m]`これは、1 つのブランチと重心に完全に含まれるサブセットを説明します。

 ## 特殊なケース

 単一ノード入力は最もクリーンな健全性チェックです。 唯一のサブツリーはノード自体であり、その文字は常に回文を形成するため、すべてのルートは 1 つの有効なサブツリーを報告します。
