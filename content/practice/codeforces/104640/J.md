 ## 解決策
 ## 問題の理解

 私たちは原点を中心とする円形の境界を与えられ、原点からあらゆる方向に光線を放射することを想像します。 各光線は、境界円に到達するか、先にブロックされるまで外側に進む「ウェブ ライン」を表します。 

ブロッキングは、平面上に点在する円形の障害物によって発生します。 各障害物は満たされた円盤であり、光線はその経路にある円盤に当たるとすぐに停止します。 原点自体はすべてのディスクの外側にあることが保証されているため、最初はすべての方向が有効です。 

タスクは、光線を直接シミュレートすることではなく、それは不可能ですが、原点からの方向のどの部分が外側の円に至るまで遮られずに残るかを計算することです。 

原点からの方向は角度によって特定できるので、$[0, 2\pi)$とすると、問題は次のようになります。原点から外円までの線分がどの円盤とも交差しない方向の角度の合計を計算し、それを次の値で割ります。$2\pi$。 

制約$n \le 10^5$各方向を個別にテストしたり、角度サンプルごとに交差をチェックしようとするソリューションは直ちに除外されます。 平$O(n^2)$ディスク間の相互作用が遅すぎる可能性があります。 この構造は、ジオメトリを角度間隔に変換してからそれらをマージする必要があることを示唆しています。 

ディスクが半径の円と交差しない場合、微妙なエッジケースが発生します。$10^6$しかし、それでも光線をより早くブロックします。 もう 1 つの注意が必要なケースは、ディスクが重なり合い、ブロック化された角度範囲が多数生成され、慎重にマージする必要がある場合です。 各ディスクを個別に扱い、マージせずに角度スパンを合計する単純なアプローチでは、ブロックされた領域が過剰にカウントされます。 

## アプローチ

 原点からの光線が境界円に到達する前にディスクを通過すると、ディスクによってブロックされます。 を中心とする固定ディスクの場合$(x, y)$半径あり$r$、この円盤と交差する原点からのすべての光線を考慮できます。 これらの光線は、円盤の中心方向を中心とした角度間隔を形成します。 

させて$d = \sqrt{x^2 + y^2}$。 もし$d \le r$、ディスクにはオリジンが含まれていますが、問題により許可されていません。 それ以外の場合、ディスクは単純な接線ジオメトリによって決定されるサイズの角度間隔をブロックします。 半角$\alpha$を満たす:$$\sin \alpha = \frac{r}{d}$$それで$$\alpha = \arcsin\left(\frac{r}{d}\right)$$中心方向は、$\theta = \operatorname{atan2}(y, x)$したがって、ブロックされる間隔は次のようになります。$$[\theta - \alpha, \theta + \alpha]$$したがって、各ディスクは 1 つの循環間隔に寄与します。$[0, 2\pi)$。 最終的な答えは、これらすべての間隔を結合した後の未カバーの測定値の合計です。 

ブルートフォースアプローチは、すべてのブロックされた角度を細かい解像度で計算します。たとえば、円を離散化して次のようにします。$K$ステップを確認し、すべてのディスクに対してステップごとの可視性をチェックします。 それには費用がかかります$O(nK)$、これは不可能です$n = 10^5$。 

重要な観察は、ジオメトリが各ディスクを単一の角度間隔に折りたたむことです。 間隔を設定すると、問題は円上での古典的な間隔の結合タスクになります。 エンドポイントを並べ替えてスイープすることで、カバーされる角度の合計を計算できます。$O(n \log n)$。

 ## アルゴリズムのチュートリアル

 各円板をブロックされた角度間隔に変換します。 

1. 各ディスクについて、原点からの距離を計算します。 これにより、光線の方向に影響を与えることができるかどうかが決まります。 円盤が非常に遠くにある場合でも、円盤に向かう光線が外円に到達する前に円盤を通過する限り重要であるため、距離は角度幅にのみ影響し、関連性には影響しません。 
2. 中心角を計算する$\theta = \operatorname{atan2}(y, x)$。 これは、円盤が原点から見た方向です。 この角度により、ブロックされた領域が固定されます。 
3. 角度の半値幅を計算します。$\alpha = \arcsin(r / d)$。 これは、原点からディスクまでの接線から導出されます。 この偏差内のすべての光線がディスクに当たります。 
4. 間隔を空ける$[\theta - \alpha, \theta + \alpha]$。 それを正規化して、$[0, 2\pi)$。 間隔が次の時点で境界を越える場合$0$、2つの区間に分割します。 円角空間は線形ではないため、このステップが必要です。 
5. すべての間隔を収集し、開始角度で並べ替えます。 
6. 重複する区間をスイープしながら結合します。 現在のアクティブな間隔を維持し、重複が発生するたびに間隔を延長します。 これにより、ブロックされた合計角度の測定値が得られます。 
7.ブロックされたメジャーをから減算します$2\pi$で割ります。$2\pi$可視方向の割合を取得します。 

正確さは、各ディスクが凸角度間隔を正確にブロックし、光線が方向全体で独立しているという事実に依存します。 これらの間隔を結合すると、ブロックされた光線がすべて正確に捕捉されます。 

### なぜ効果があるのか

 固定方向については、その角度が少なくとも 1 つの円盤の角度間隔内にある場合に限り、光線はブロックされます。 原点から円への接線のセットは連続しているため、各ディスクは連続した範囲の禁止角度に寄与します。 したがって、ブロックされたセットはまさにこれらの間隔の結合です。 それらの和集合を計算すると正確なカバレッジが維持され、完全な円から減算すると正しい表示比率が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def solve():
    n = int(input())
    events = []
    
    for _ in range(n):
        x, y, r = map(int, input().split())
        d = math.hypot(x, y)
        if d <= r:
            continue
        
        theta = math.atan2(y, x)
        alpha = math.asin(r / d)
        
        l = theta - alpha
        r_ = theta + alpha
        
        # normalize to [0, 2pi)
        twopi = 2 * math.pi
        
        while l < 0:
            l += twopi
            r_ += twopi
        while l >= twopi:
            l -= twopi
            r_ -= twopi
        
        if r_ <= twopi:
            events.append((l, r_))
        else:
            events.append((l, twopi))
            events.append((0.0, r_ - twopi))
    
    events.sort()
    
    total = 0.0
    cur_l, cur_r = None, None
    
    for l, r_ in events:
        if cur_l is None:
            cur_l, cur_r = l, r_
        elif l <= cur_r:
            cur_r = max(cur_r, r_)
        else:
            total += cur_r - cur_l
            cur_l, cur_r = l, r_
    
    if cur_l is not None:
        total += cur_r - cur_l
    
    ans = 1.0 - total / (2 * math.pi)
    print(ans)

if __name__ == "__main__":
    solve()
```このソリューションは、各ディスクを角度のあるエンドポイントのペアに変換し、ラップアラウンドを慎重に処理します。$2\pi$。 結合ステップにより、重複するブロック領域が二重にカウントされないことが保証されます。 最後の減算により、ブロックされた角度測定値が自由な比率に変換されます。 

よくある微妙な点は、$0$角度。 それらを分割すると、スイープ ラインが線形順序で有効なままになります。

 ## 特殊なケース

 遠く離れていても十分な大きさの円盤でも、非常に狭い角度間隔が生成されます。 計算ではこれが自然に処理されます。$r/d$小さくなり、$\arcsin(r/d)$ゼロに近づき、無視できるものの正確なカバレッジに寄与する有効な間隔が生成されます。 

原点からの接線上にほぼ正確に位置する円盤は、非常に小さな間隔を作成します。 浮動小数点精度が関係しますが、必要な精度は$10^{-4}$、標準の倍精度で十分です。 

交差する間隔$0$アングルは2つに分割されます。 分割しない場合、並べ替えではそれらが逆間隔として誤って扱われ、マージが中断されます。 正規化ステップでは、円形ドメインを線形ドメインに埋め込むことで正確さを保証します。
