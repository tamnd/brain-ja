 ## 解決策
 ## 問題の理解

 軸に揃えられた長方形のコレクションが与えられ、それぞれが高さと幅によって定義され、各長方形は 90 度回転することもできます。 これは、すべての長方形を 2 つの可能な方向があるものとして扱うことができ、役立つ方の方向を自由に選択できることを意味します。 

目標は、これらの長方形のサブセットを選択し、厳密に減少しないチェーンに配置し、各長方形が次の長方形の内側に収まるようにすることです。 寸法のある長方形$(h_1, w_1)$中に置くことができます$(h_2, w_2)$高さと幅の両方が対応する寸法を超えない場合。 このようなチェーンを可能な限り長くする必要があり、それを形成する長方形のインデックスを順番に出力する必要もあります。 

この問題は基本的に 2 次元の半順序の下で最長のチェーンを求めることですが、回転により各アイテムが 2 つの可能な状態を持つという追加のひねりが加えられています。 

制約$n \le 10^5$ペア間の二次比較は即座に除外されます。 すべてのペアを比較したり、以前のすべての長方形に対して単純な方法で動的プログラミングを実行したりするアプローチでは、約$10^{10}$実行可能な限界をはるかに超えた最悪の場合の操作。 

素朴だが誘惑しやすい間違いは、各四角形を個別に扱い、その最適な方向をローカルで選択し、並べ替えて貪欲にチェーンを取得することです。 向きの決定はグローバルであるため、これは失敗します。 後でより長いチェーンを有効にするには、長方形を最適でない方向に「犠牲」にする必要がある場合があります。 

回転後に両方の寸法が等しい場合、別の微妙な問題が発生します。 ディメンションを不注意にソートして常に正規化すると、意図せずに無効なチェーンが発生したり、タイの一貫性が損なわれたりして、正しいシーケンスの再構築が破壊される可能性があります。 

## アプローチ

 ブルート フォース ソリューションでは、すべてのサブセットとすべての方向の選択を試し、特定のシーケンスが有効なネスト チェーンを形成しているかどうかを確認します。 サブシーケンスに限定しても、これは指数関数的になります。$n$。 もう少し構造化されたブルートフォースは、サブセットまたはペアに対する動的プログラミングになりますが、その場合でも、最終的にはすべての四角形を他のすべての四角形と比較することになり、$O(n^2)$トランジション。 と$10^5$長方形の場合、これは完全に不可能です。 

重要な構造上の観察は、長方形がチェーンに配置されると、チェーンに沿って 1 つの次元が減少せず、ソートによって順序付けを強制できることです。 本当の課題は、2 次元の古典的な最長増加サブシーケンス (LIS) である 2 次元の順序付けを扱っていることです。 

回転の自由により、各長方形の 2 つの辺の順序を選択できるように単純化されます。 最善の戦略は、常に各長方形の小さい方の辺が高さとして扱われ、大きい方の辺が幅として扱われるように方向を変えることです。 この正規化により一貫性が確保され、すべての四角形が最小限の標準形式で表現されます。$(a, b)$と$a \le b$。 軸の交換は制約を軽減するのに役立つだけであるため、この表現を使用すると、あらゆる最適なチェーンを 1 つに変換できます。 

正規化後、問題は最長のペアのシーケンスを見つけることになります。$(a_i, b_i)$両方の座標が減少しないようにします。 これは標準的な 2D LIS の問題です。 最初の座標でソートし、次に 2 番目の座標で LIS を見つけると、最適なチェーン構造が得られます。 

シーケンスを再構築するには、LIS の計算中に先行データを保存する必要があります。

 ## アルゴリズムのチュートリアル

 ## アルゴリズムのチュートリアル

 1. 各長方形の寸法を次のように並べ替えます。$a = \min(h, w)$そして$b = \max(h, w)$。 これにより、回転の選択が正規表現に修正され、すべての四角形がネストに対して最も制限された方向で表現されるようになります。 
2. 各長方形をトリプルとして保存します$(a, b, index)$、後で答えを再構築できるように、元のインデックスを保存します。 
3. すべての四角形を次の基準で並べ替えます。$a$昇順かつ等しい$a$、 による$b$昇順で。 これにより、有効なネスト チェーンは最初の座標での順序を尊重する必要があるため、今後は 2 番目の座標を制御するだけで済みます。 
4. のシーケンスに対して最長の非減少サブシーケンス プロセスを実行します。$b$価値観。 各長さのサブシーケンスの可能な最小の終了値を保存する DP 構造を維持します。 
5. 再構築を可能にするために、要素ごとに、そこで終了する最適なサブシーケンスの長さと、そのサブシーケンス内の前の要素への先行ポインタを保存します。 この問題ではチェーンの長さだけでなく実際のチェーンが必要となるため、これが必要になります。 
6. LIS 構造を更新するとき、二分探索を使用して、現在の構造が存在する最初の位置を見つけます。$b$最小のテール値を維持しながら配置できます。 各更新は、サブシーケンスの拡張または改善に対応します。 
7. すべての四角形を処理した後、最大サブシーケンス長の位置を特定し、先行ポインタを逆方向にたどって結果を逆にしてチェーンを再構築します。 

### なぜ効果があるのか

 正しさは、2D ドミナンス問題を 1D LIS 問題に還元することにかかっています。 並べ替え順$a$有効なチェーンが最初の次元制約をすでに満たしている必要があることを確認します。 その後、残る条件は 2 次元のみになります。 すべての四角形は事前にソートされているため、構築するサブシーケンスは自動的に非減少を保持します。$a$、つまり LIS を強制する$b$完全な有効性を保証します。 

先行ポインタは、LIS 内のすべての拡張が、ソートされた順序で四角形間の実際の有効な遷移に対応することを保証するため、再構築されたチェーンは、両方の次元で有効なネスト シーケンスになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    rects = []
    for i in range(n):
        h, w = map(int, input().split())
        a, b = min(h, w), max(h, w)
        rects.append((a, b, i + 1))
    
    rects.sort(key=lambda x: (x[0], x[1]))
    
    import bisect
    
    tail = []
    tail_idx = []
    parent = [-1] * n
    pos_in_tail = [-1] * n
    
    # store best ending index for each length
    best_idx = []
    
    for i, (a, b, idx) in enumerate(rects):
        j = bisect.bisect_right(tail, b)
        
        if j == len(tail):
            tail.append(b)
            best_idx.append(i)
        else:
            tail[j] = b
            best_idx[j] = i
        
        pos_in_tail[i] = j
        
        if j > 0:
            parent[i] = best_idx[j - 1]
    
    # reconstruct LIS
    length = len(tail)
    last = best_idx[length - 1]
    
    ans = []
    while last != -1:
        ans.append(rects[last][2])
        last = parent[last]
    
    ans.reverse()
    
    print(len(ans))
    print(*ans)

if __name__ == "__main__":
    solve()
```コードはまず、方向が一貫した方法で固定されるように各四角形を正規化します。 最初の次元で並べ替えると、2 番目の次元での実現可能性を管理するだけで済みます。 LIS 構造は以下を使用します。`tail`各長さのサブシーケンスに対して可能な最小限の終了値を維持するため、および`best_idx`各サブシーケンスの長さのエンドポイントが現在どの四角形で定義されているかを記憶します。 

の`parent`配列は再構築を可能にするものです。 長方形がサブシーケンスを拡張するたびに、長さが 1 つ少ない最適なシーケンスへのポインターが格納されます。 これにより、最適なサブシーケンスの最後の要素からバックトラックしたときに、正しい順序で有効なチェーンが復元されることが保証されます。 

微妙な点は、`bisect_right`の代わりに`bisect_left`。 これにより、条件に一致する、厳密に増加するシーケンスではなく、非減少シーケンスが強制されます。$h_1 \le h_2$、$w_1 \le w_2$。

 ## 特殊なケース

 微妙なエッジ ケースは、正規化後に多くの四角形が同一になる場合です。 例えば、$(3,5), (5,3), (3,5)$すべてが正規化される$(3,5)$。 このアルゴリズムでは、非減少遷移を使用するため、それらすべてが LIS に参加できます。 これは正しいです。なぜなら、同一の四角形は常に任意の順序でネストできるからです。 

もう 1 つのケースは、実現可能性にとってローテーションが重要な場合です。 のような長方形$(2,10)$そしてもう一つ$(9,3)$両方とも正規化されます$(2,10)$そして$(3,9)$、正規化の一貫性がなければ、貪欲に向きを選択するとチェーンが壊れる可能性があります。 正準変換により、LIS 計算の前にこの曖昧さが除去されます。 

最後に、両方の次元でチェーンが大きく増加するケースでは、再構築の正確さが重視されます。 すべての DP 遷移には先行データが格納されるため、複数の最適なサブシーケンスが存在する場合でも、バックトラック ステップでは常に一貫したシーケンスが回復されます。
