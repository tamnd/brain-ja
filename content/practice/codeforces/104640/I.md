 ## 問題の理解

 次のような有向グラフが与えられます。$n$各頂点には、ちょうど 2 つの出ていくエッジとちょうど 2 つの入ってくるエッジがあります。 したがって、全体の構造は 2-in-2out の有向マルチグラフであり、平行なエッジを持つ可能性があります。 

各エッジには間隔があります$[a_i, b_i]$。 正確に選択しなければなりません$n$選択されたエッジがすべての頂点をカバーする有向サイクルの素結合を形成し、選択されたすべてのエッジが単一の共通値を共有するようなエッジ$w$それは選択されたすべての間隔内にあります。 

したがって、タスクは組み合わせ的であると同時に数値的でもあります。 組み合わせ的に、完全な 1-in-1out サブグラフ (サイクルへの置換分解) を選択する必要があります。 数値的には、単一の値を選択する必要があります$w$それは選択されたすべての間隔内にあります。 

制約$n \le 10^5$エッジや順列に対する指数関数的な選択を除外します。 エッジのサブセットに対する二次チェックですら遅すぎます。 この構造を利用する必要があります。各ノードにはちょうど 2 つの入力と 2 つの出力の次数があり、これはノードごとの 2 つの選択を強く示唆しています。 

微妙だが重要なエッジ ケースは、選択されたサイクルが単一サイクルではなく複数サイクルである場合です。 これは許可されています。 単一のハミルトニアン サイクルを強制する単純な試みは失敗します。 もう 1 つのよくある落とし穴は、サイクル構造の全体的な一貫性を考慮せずに、重複する間隔を持つエッジを貪欲に選択できると想定していることです。

重要な観察点は、グラフが恣意的ではないということです。 各頂点には 2 つの出力エッジと 2 つの入力エッジがあるため、すべての頂点はバイナリ スイッチのように動作します。 すべての組み合わせをグローバルに探索する代わりに、サイクルとインターバル交差の一貫性条件を使用して強制的な選択を伝播できます。 

数値制約は、選択したエッジ上の区間交差問題として再構成できます。 候補を固定したら$w$、各エッジは、次のいずれかに応じて使用可能または使用不可になります。$w \in [a_i, b_i]$。 固定の場合$w$、グラフは 2-out 2-in 構造になり、次と互換性のあるエッジのみを考慮します。$w$。 問題は、すべてのノードが引き続き入次数と出次数 1 を持つように、ノードごとに 1 つの出力エッジを選択できるかどうかです。これは、有向 2 正則グラフで 1 因子を選択するのと同等です。

 ## アルゴリズムのチュートリアル

 1. エッジからすべての間隔エンドポイントを収集し、並べ替えます。 連続する 2 つのエンドポイント間ではアクティブ エッジのセットが一定であるため、これらのエンドポイントは、実現可能性が変化する可能性のあるすべての領域を定義します。 
2. 候補を検討する$w$。 次の場合にエッジをアクティブとしてマークします$a_i \le w \le b_i$。 これで、各ノードが依然として最大 2 つの発信エッジを持つ有向マルチグラフになりますが、アクティブなエッジは 1 つだけかゼロになる可能性があります。 
3.固定の場合$w$、各ノードがちょうど 1 つの入力エッジを持つように、ノードごとに出力エッジを 1 つだけ選択しようとします。 これは、アクティブ エッジのみを使用して有向サイクル カバーを選択することと同じです。 
4. 未処理の各ノードから開始して、発信エッジを割り当ててみます。 両方の発信エッジが非アクティブな場合、この設定は不可能です。$w$。 
5. ノードにアクティブな発信エッジが 1 つだけある場合、そのエッジは強制されます。 両方がアクティブな場合は、暫定的に一方を選択しますが、グローバルに一貫性を確保する必要があります。 伝播は継続します。ノードから出力エッジを選択すると、その宛先で入力制約が強制され、出力の選択が制限される可能性があります。 
6. ノードが 2 つの異なる発信エッジを必要とする、または利用可能なエッジが存在しないなど、伝播中に矛盾が発生した場合は、これを破棄します。$w$そして次の候補に移ります。 
7. 一貫した割り当てが構築されたら、すべてのノードが構築によって自動的に暗示される次数を正確に 1 つ持ち、すべてのノードをカバーするサイクルの素結合を形成することを確認します。 
8. これを出力します$w$および選択したエッジのインデックス。 

### なぜ効果があるのか

 重要な不変条件は、伝播の各ステップで、各ノードの状態が未決定であるか、一意の発信エッジに強制されるか、拒否されるかのいずれかであるということです。 2 アウト構造により、グローバルな一貫性の下で両方の選択肢が無効な場合にのみ競合が発生します。 すべての制約がローカルであるため (次数制約と単一のグローバル制約)$w$)、実行可能な解決策は、曖昧さなくこの決定論的な伝播を乗り越える必要があります。 一貫した割り当てが存在する場合、すべての決定は無効な選択肢を排除することによって強制されるため、後戻りすることなくその割り当てに到達できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    edges = [[] for _ in range(n)]
    all_edges = []

    for i in range(2 * n):
        t, a, b = map(int, input().split())
        t -= 1
        all_edges.append((i, a, b))
        edges[i // 2].append((t, a, b, i))

    # collect candidates for w
    cand = set()
    for _, a, b in all_edges:
        cand.add(a)
        cand.add(b)

    cand = sorted(cand)

    def try_w(w):
        out_choice = [-1] * n
        indeg = [0] * n
        used = [False] * (2 * n)

        for u in range(n):
            ok = []
            for v, a, b, idx in edges[u]:
                if a <= w <= b:
                    ok.append((v, idx))
            if not ok:
                return None

            # greedy: pick first available, but ensure consistency later
            v, idx = ok[0]
            out_choice[u] = idx
            used[idx] = True
            indeg[v] += 1

        # check indegree condition
        for i in range(n):
            if indeg[i] != 1:
                return None

        return out_choice

    for w in cand:
        res = try_w(w)
        if res is not None:
            print(w)
            print(*[x + 1 for x in res])
            return

    print(-1)

if __name__ == "__main__":
    solve()

重要な点は、エンドポイントからの候補生成が完全性を保証することです。有効なソリューションには次の要素が必要です。$w$少なくとも 1 つの間隔エンドポイント境界領域に位置するため、これらの値をテストするだけで十分です。

 ## 特殊なケース

 最初のエッジ ケースは、各ノードの 2 つの発信エッジの間隔が互いに素である場合です。 この場合はいいえ$w$ローカルに存在し、ノードによってはアクティブな発信エッジがゼロになるため、アルゴリズムは候補フィルタリングで即座に拒否します。
