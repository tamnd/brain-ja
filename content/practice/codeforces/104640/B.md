 ## アルゴリズムのチュートリアル

 私たちは最大の有効なものを構築したいと考えています$m$なので、上限から始めます$n$必要な場合にのみ下方に調整してください。

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    
    if k == 1:
        print(n)
        return
    
    m_minus_1 = (n - 1) // k * k
    m = m_minus_1 + 1
    print(m)

if __name__ == "__main__":
    solve()
```実装は、次の構築の直後に行われます。$m - 1$。 表現$(n - 1) // k * k$数値を最も近い倍数にスナップダウンする標準的な方法です。$k$オーバーフローの問題もなく。 

特別な場合$k = 1$すべての数値が有効であり、式は引き続き機能しますが、推論は自明になるため、明示的に処理されます。 

最後に 1 を追加すると、割り切れることなく、必要な分析ステップが復元されます。

 ## 特殊なケース

 のために$k = 1$、任意の数の残りの部分が単一のスパイダーに均等に分配される可能性があるため、この状態は空です。 アルゴリズムは明示的に返します$n$、上限を超える制限は課されていないという事実と一致します。
