 ## 解決策
 ## 問題の理解

 高さのある垂直の円筒形のボトルが与えられます$h$と半径$r$。 ボトルにはある程度の高さまで水が部分的に満たされています$x$、底から測定。 水の上の残りの空間は空気で満たされます。 水と空気は密度が一定の連続物質として扱われます。$d_w$そして$d_a$、ボトル自体には重さはありません。 

最適化したい物理量は、ボトルを直立させたときの空気と水の柱を合わせた質量中心の垂直位置です。 円柱の断面積は一定であるため、ジオメトリはスケーリングにのみ影響し、高さに沿った質量の相対的な分布には影響しません。 目標は選択することです$x \in [0, h]$重心ができるだけ低くなるようにします。 

出力は、最適な水高を表す実数です。 

制約は小さく、すべてのパラメーターが最大 1000 であるため、$O(1)$または$O(\log n)$分析的な解決策が期待されています。 可能な値をサンプリングするあらゆるアプローチ$x$Finely は不必要に遅くなり、精度も低くなりますが、それでも実行可能です。 ただし、問題の構造は、閉じた形式の解決策を強く示唆しています。 

いくつかのエッジ動作は予測する価値があります。 ボトルが空の場合（$x=0$)、空気のみが寄与します。 いっぱいだったら($x=h$)、水のみが寄与します。 最適値が終点にあるはずだと仮定する素朴なアプローチは失敗します。上空の軽い空気と下の重水の間のコントラストにより、中間混合物が重心を下げる可能性があるからです。 

## アプローチ

 強引な解釈では、多くの候補の充填高さを試すことになります。$x$、それぞれの重心を計算し、最適なものを選択します。 各評価では高さに沿った質量分布を統合する必要がありますが、密度は区分的に一定であるため、一定時間で計算できます。 細かい解像度でのサンプリングは機能しますが、離散化に依存する場合は不必要であり、数値的に不安定になります。 たとえば、ステップ サイズを次のようにすると、$10^{-6}$、すでに精度要件の限界に近づいていることになりますが、これは依然として問題の本当の構造を隠しています。 

重要な観察は、システムが均一な断面を持つ 1 次元であるため、問題は区間に沿った加重平均に帰着するということです。 重心は次の場合に有理関数になります。$x$、二次分子から形成されます (積分から得られます)$z$) と線形分母 (総質量から得られます)。 これにより、目標が滑らかになり、微分可能になります。$(0, h)$を使用すると、数値的に検索する代わりに、単一の微分方程式を解くことによって最適値を見つけることができます。 

閉形式で書き直すと、導関数は 2 次方程式に単純化され、その解から最適な充填高さが直接得られます。

 ## アルゴリズムのチュートリアル

 充填高さの関数として重心を導き出します。$x$、それを最小化します。 

1. ボトルを垂直セグメントとしてモデル化します。$[0, h]$密度のある$d_w$の上$[0, x]$そして$d_a$の上$[x, h]$。 断面積は一定なので、どの比率でも相殺されます。 
2. 総質量を計算します (面積の一定係数まで)。 水が貢献している$d_w x$、そして空気が寄与します$d_a (h - x)$。 したがって、総質量は$$M(x) = d_a h + (d_w - d_a)x.$$3. 底部周りのモーメントを計算します。 水が貢献する$\int_0^x z d_w dz = d_w x^2/2$。 空気が寄与する$\int_x^h z d_a dz = d_a(h^2 - x^2)/2$。 したがって、合計瞬間は$$N(x) = \frac{d_a h^2 + (d_w - d_a)x^2}{2}.$$4. 重心は$f(x) = N(x)/M(x)$。 一定の要素$1/2$最小化のために無視できます。 
5. 定義する$A = d_w - d_a$、これはポジティブです。 次に最小化します$$g(x) = \frac{d_a h^2 + A x^2}{d_a h + A x}.$$6.差別化する$g(x)$商ルールを使用し、導関数の分子をゼロに設定します。 これにより、$$A x^2 + 2 d_a h x - d_a h^2 = 0.$$7. この二次方程式を解き、正の根を求めます。$$x = \frac{-2 d_a h + \sqrt{4 d_a^2 h^2 + 4 A d_a h^2}}{2A}.$$8. 平方根の項を簡略化します。$$d_a^2 + d_a A = d_a d_w,$$したがって、解決策は次のようになります$$x = h \cdot \frac{\sqrt{d_a d_w} - d_a}{d_w - d_a}.$$### なぜ効果があるのか

 機能$g(x)$スムーズです$(0, h)$凸二次関数と一次関数の比から生じます。 これにより、実行可能な区間内の単一の静止点が保証されます。 導関数はちょうど 1 つの正の根を持つ 2 次方程式に帰着するため、$[0, h]$、そのルートはグローバル ミニマイザーである必要があります。 境界点は純粋な空気または純粋な水の縮退ケースに対応し、常に静止点がそれらを厳密に支配します。$d_w > d_a$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def solve():
    h, r, da, dw = map(int, input().split())
    
    A = dw - da
    # avoid floating instability in degenerate reasoning
    x = h * (math.sqrt(da * dw) - da) / A
    print(x)

if __name__ == "__main__":
    solve()
```実装は派生した閉じた形式に直接に従います。 半径$r$質量とモーメントの両方を計算すると断面積が一定であるため、 が最終的な式に現れることはありません。 唯一デリケートな部分は平方根の計算です$\sqrt{d_a d_w}$、これは倍精度で実行する必要があります。 必要な許容誤差$10^{-6}$簡単に満足できます。 

## 実用的な例

 ### 例 1

 入力:```
22 4 1 4
```私たちは計算します$A = 3$、 そして$\sqrt{d_a d_w} = \sqrt{4} = 2$。 

| ステップ | 式 | 値 |
 | --- | --- | --- |
 | 平方根を計算する |$\sqrt{1 \cdot 4}$| 2 |
 | 分子 |$2 - 1$| 1 |
 | 分母 |$4 - 1$| 3 |
 | × |$22 \cdot 1/3$| 7.3333... |

 空気は水よりもはるかに軽いため、最適な位置はボトルの 3 分の 1 です。そのため、水を増やすと、最初は重心が低くなりバランスが改善されますが、最終的には総質量濃度が増加するため再び重心が高くなります。

 ## 特殊なケース

 いつ$d_w$よりわずかに大きいだけです$d_a$、最適な$x$水を追加すると、中心の配置が大幅に改善されることなく質量がすぐに増加するため、ゼロに近くなります。 分子が$\sqrt{d_a d_w} - d_a$は小さくなり、予想される制限と一致します。 

いつ$d_a$に比べて非常に小さいです$d_w$、平方根が支配的であり、解はより大きな部分に近づきます。$h$これは、空気が質量にほとんど寄与しておらず、水の配置が質量の中心を占めていることを反映しています。 

いつ$d_a$そして$d_w$分母が非常に近い$d_w - d_a$は小さくなりますが、 の膨張により分子も比例して小さくなります。$\sqrt{d_a d_w}$。 このキャンセルにより、数値の爆発が防止され、浮動小数点演算下で式が安定した状態に保たれます。
