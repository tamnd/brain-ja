 ## 解決策
 ## 問題の理解

 頂点 1 が出口として扱われる無向接続グラフを構築するように求められます。 プレイヤーは一様にランダムな頂点から開始し、その後常に頂点 1 に向かって最適に移動します。これは、ノードからの移動時間は単にノード 1 までの最短経路距離であることを意味します。私たちが気にする量は、すべての頂点にわたるこれらの最短経路距離の平均です。 

したがって、定義すると$d(i)$頂点からの最短パス距離として$i$頂点 1 に必要な値は次のとおりです。$$\frac{1}{n} \sum_{i=1}^{n} d(i)$$この目標は縮小された部分として与えられます$a/b$。 タスクは、平均距離がこの値と正確に等しい接続グラフを構築するか、それが不可能であると判断するかのどちらかです。 

の制約$a, b \le 1000$は小さいですが、グラフ自体には最大で$10^6$頂点とエッジ。 これは、解決策がグラフを検索することではなく、平均距離を分析的に表現して正確に調整できる、非常に構造化されたグラフのファミリーを構築することであることをすぐに示唆しています。 

主な困難は、最短経路距離はグローバルな特性であるが、制御しなければならないのはその平均値のみであることです。 つまり、距離が単純な閉じた形式を持つ構造が必要になります。 

単純な試みとしては、ランダムなグラフを試したり、力ずくで小さな構築を試したり、スケールしたりすることですが、これは失敗します。$n$、グラフを列挙することは不可能です。 単一のグラフをテストする場合でも、すべての最短パスを計算する必要があります。$O(n + m)$BFS経由ですが、グラフのスペースは天文学的に大きいです。 

ターゲット値が次のような非常に小さな端数である場合、微妙なエッジ ケースが発生します。$1/3$。 一部の平均はまったく実現できません。これは、接続されたグラフ構造内の最小の非ゼロ寄与により、継続的に調整できない最小の平均成長が強制されるためです。 サンプルはすでにそれを示しています$1/3$は不可能であり、数値近似の問題ではなく構造上の制限があることを示唆しています。 

## アプローチ

 強引なアイデアは、小さなグラフを考慮し、BFS を使用してノード 1 からのすべてのペアの距離を計算し、平均が一致するまで段階的にノードとエッジを追加してみることです。$a/b$。 新しいノードはさまざまな方法で接続できるため、これには指数関数的な数のグラフ構成を調査する必要があります。 樹木に限定したとしても、根を張った木の数は$n$ノードは依然として指数関数的です$n$そして、候補ごとにすべての距離を線形時間で再計算します。 これは非常に小さいものを超えるとすぐに実行不可能になります$n$。 

重要な構造的洞察は、ノード 1 をルートとする最短パス ツリーがすでにすべての距離を決定しており、追加のエッジは距離を減らすだけで、距離を増やすことはできないということです。 したがって、任意のグラフの代わりに、各ノードがその深さに正確に寄与するルート付きツリーの観点から考えることができます。 平均は深さ全体にわたって制御された合計になります。 

ここで問題は、各深度に存在するノードの数を正確に制御できるルート構造を構築することになります。 自然な候補は層状グラフです。ノードは 1 からの距離によってグループ化され、すべてのノードが層内にあります。$i$レイヤーのみに接続する$i-1$。 これにより、最短パスが正確にレイヤー インデックスになることが保証されます。 

これにより、問題は、加重合計が目標比率と一致する層サイズの整数シーケンスを構築することに変換されます。 柔軟性は、平行エッジと自己ループを許可することから生まれます。つまり、接続性と最短距離を維持する限り、最短パス構造に影響を与えることなくマルチエッジを安全に使用できます。 

構築の最終的なアイデアは、連続するレイヤー間の完全な 2 部展開により、最短パスを固定したまま各ノードを独立して処理できることを認識することです。 次に、平均距離は層サイズの線形結合となり、これに一致する小さなディオファントス構築問題を解くことができます。$a/b$。 

不可能なケースは、複数のノードを持つ接続されたグラフには少なくとも 1 の距離に少なくとも 1 つのノードが必要であり、平均が少なくとも$1/n$-スケールされた整数構造体。 次のような特定の分数$1/3$整性制約の下では、このような階層化された平均として表現することはできません。

 ## アルゴリズムのチュートリアル

 頂点 1 がルートで、他のすべてのノードに深さが割り当てられる、ルート化された階層化グラフを構築します。 この構造により、グラフ内の距離がこれらの深さと正確に等しくなることが保証されます。 

### ステップ

 1. まず、目標値を小数として解釈します。$a/b$。 目標は、グラフ内の整数値の距離を使用して、この有理数に等しい距離の平均合計を実現することです。 
2. グラフをノード 1 の周りのレイヤーとして表すことにします。レイヤーは$i$正確な距離にあるノードで構成されます$i$ノード 1 から。レイヤー内のすべてのノードを接続することによって最短パス構造が強制されます。$i$レイヤー内の少なくとも 1 つのノードに$i-1$。 
3. 一連の層サイズを構築します$s_0, s_1, \dots, s_k$と$s_0 = 1$。 合計距離への寄与は次のとおりです。$\sum i \cdot s_i$、ノードの総数は$\sum s_i$。 平均はそれらの比率です。 
4. 最初に非常に単純な 2 層システムを選択し、次にそれを拡張します。1 つのルート、深さ 1 に多数のノード、場合によっては深さ 2 に追加の構造を追加して平均を微調整します。 2 つの層で十分な理由は、有界区間内の任意の有理数を整数の凸組み合わせとして表現できるためです。 
5. レイヤ 1 とレイヤ 2 のノードの数を求めます。$$\frac{1 \cdot x + 2 \cdot y}{1 + x + y} = \frac{a}{b}$$そして線形ディオファントス方程式に整理し直す：$$(b - a)x + (2b - a)y = a$$答えが存在する場合、範囲内に存在することが保証される、負ではない小さな整数の解を検索します。 
6. 1回$x, y$ノード 1 をすべてのレイヤー 1 ノードに接続し、接続性を維持し、最短パスが正確に 1 または 2 のままになるようにレイヤー 1 ノードをレイヤー 2 ノードに接続します。 
7. 最後に、すべてのエッジを出力します。 自己ループと平行エッジは許可されますが、この構造では不要です。 

### なぜ効果があるのか

 この構造により、すべてのノードは、割り当てられたレイヤー インデックスと等しいノード 1 までの一意の最短パス距離を持つように強制されます。 レイヤー内のすべてのノードが均一に扱われるため、合計距離の合計はレイヤー サイズの決定的な線形関数になります。 重要な不変条件は、隣接しないレイヤー間にショートカット エッジが存在しないため、どのノードも指定された深さよりも短いパスを達成できないことです。 これにより、平均がレイヤー サイズの計算された有理式と正確に一致することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    line = input().strip()
    if line == "":
        return
    a, b = line.split('/')
    a = int(a)
    b = int(b)

    # brute search for small 2-layer construction
    # (1 + x + y) nodes, sum distances = x + 2y
    # (x + 2y) / (1 + x + y) = a / b
    # b(x + 2y) = a(1 + x + y)
    # (b - a)x + (2b - a)y = a

    A = b - a
    B = 2 * b - a

    # special case: single node
    if a == 0:
        print(1, 0)
        return

    # search small solutions
    LIMIT = 2000
    for x in range(LIMIT + 1):
        for y in range(LIMIT + 1):
            if A * x + B * y == a:
                n = 1 + x + y
                edges = []

                # connect root to layer 1
                for i in range(2, 2 + x):
                    edges.append((1, i))

                # connect layer 1 to layer 2 fully (or minimally)
                start = 2 + x
                for i in range(start, start + y):
                    # attach to first layer-1 node if exists
                    if x > 0:
                        edges.append((2, i))
                    else:
                        edges.append((1, i))

                print(n, len(edges))
                for u, v in edges:
                    print(u, v)
                return

    print("impossible")

if __name__ == "__main__":
    solve()
```コードは、階層化された 2 レベルのアイデアを直接エンコードします。 分数条件を、距離 1 および 2 のノード数にわたる線形ディオファントス方程式に変換します。ネストされたループは安全です。$a, b \le 1000$したがって、有効な構造が存在する場合は、限定された検索で見つけることができます。 

微妙な点は、次の場合に接続を確保することです。$x = 0$。 その場合、グラフが接続されたままになるように、深さ 2 のノードをルートに直接接続する必要があります。 レイヤ化により構造のみで距離が保証されるため、この構築は高度な最短経路の再計算に依存しません。
