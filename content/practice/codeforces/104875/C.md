 ## 問題の理解

 無限のグリッド上に配置された単位正方形の構成が与えられます。 整数格子線によって 1 × 1 のセルに分割された平面を考えてください。 円形のクッキーはグリッドの交点の中心に正確に配置されており、これらの単位正方形がどれだけ円の中に完全に含まれているかに興味があります。 

各正方形は、その 4 つの角すべてが円の内側または円上にある場合にのみカウントされます。 このタスクは、通常の数を数える問題とは逆になります。半径が与えられて正方形を数える代わりに、数値が与えられます。`s`これは、競合他社の Cookie に含まれる完全な正方形の数の上限を表しており、厳密にそれ以上の正方形を含む円を構築する必要があります。`s`半径をできるだけ小さく保ちながら完全な正方形にします。 

したがって、出力は、円内に完全に含まれる単位正方形の数が次を超えるような最小の半径になります。`s`。 

制約`s ≤ 10^9`大きな半径の正方形を明示的に列挙するアプローチは除外されます。 半径が約 10^5 であっても、単純な 2D スキャンではすでに約 10^10 のグリッド位置が生じており、これは 1 秒のソリューションで処理できる範囲をはるかに超えています。 問題の構造は、幾何学的形状内の格子オブジェクトを効率的にカウントし、単調探索を使用してそのカウントを反転する必要があることを示唆しています。 

微妙なエッジケースが現れるのは、`s`とても小さいです。 もし`s = 1`、答えは原点付近の単一の単位正方形によって決まるのではなく、正方形が円の内側に完全に収まり始めるまでの速さによって決まります。 もう 1 つのエッジ ケースは、正方形が格子点の中心に配置されず、その角によって定義されるため、中心を使用するか角を使用するかを誤解すると、体系的に不正確なカウントにつながることです。 

## アプローチ

 直接的なアプローチでは、半径を徐々に大きくし、半径ごとに境界ボックス内のすべてのグリッド正方形を反復処理して、4 つの角がすべて円内にあるかどうかを確認します。 これは概念的には正しいですが、半径に関しては`R`大まかに繰り返す必要があります`O(R^2)`正方形であり、各チェックは一定時間です。 有効な正方形の数は円の面積に比例して増加するため、`s`まで`10^9`次の半径が必要になります`sqrt(s)`、それは約です`3 × 10^4`。 それでも、その半径までのすべての正方形を反復処理すると、約`10^9`反復が遅すぎます。 

重要な観察は、有効な正方形のセットが半径とともに単調に増加するということです。 正方形が半径の円の内側に完全に入ったら`R`、それより大きな半径では内側に残ります。 この単調性により、半径の二分探索を使用してカウント関数を反転することができます。 

残りの課題は、固定半径の計算です。`R`、すべてを反復せずに円に完全に含まれる単位正方形の数。 正方形からその角に切り替えると、ジオメトリが単純化されます。つまり、左下隅のある単位正方形になります。`(x, y)`一番奥の隅まで完全に収まっている`(x+1, y+1)`is within the circle centered at the origin. これにより、条件が第 1 象限内の整数格子点のみを含む不等式に変換されます。 

次に、2 次元の接頭辞構造を偽装して使用して、有効な整数のペアを効率的に数えます。`x`、実現可能な最大値を計算します。`y`円方程式から。 これにより、固定半径のカウントが減少します。`O(R)`二分探索では対数係数が追加されます。

 ## アルゴリズムのチュートリアル

 この問題を、円制約を満たす整数のペアを数える問題に変換します。 

1. 左下隅を使用して各単位正方形を再解釈します。`(x, y)`。 正方形が円の中に完全に収まるのは、次の場合に限られます。`(x+1, y+1)`円の内側または上にあります。 これにより、条件が次のように変換されます。`(x+1)² + (y+1)² ≤ R²`。 
2. 変数を定義してシフトする`a = x+1`そして`b = y+1`、これは両方を作ります`a`そして`b`1 から始まる正の整数。条件は次のようになります。`a² + b² ≤ R²`。 
3. 固定半径の場合`R`、整数ペアの数を計算します`(a, b)`第 1 象限では不等式が満たされます。 それぞれについて`a`、有効な最大値`b`は`⌊sqrt(R² − a²)⌋`。 
4.全体を合計する`a`1から`R`、追加`max(0, b_max)`カウントに。 これにより、1 象限内の有効な正方形の数が得られます。 
5. 結果を 4 で乗算して、4 つの対称象限すべてを考慮します。 
6. 二分探索を使用します。`R`。 各中点の半径について、正方形の数を計算します。 それより大きい場合`s`、半径は実現可能なので、より小さい値を試します。 それ以外の場合は増やします。 
7. 厳密に次の値を超える最小半径を返します。`s`正方形。 

正確さは、カウント関数が単調であるという事実にかかっています。`R`。 より大きな円には、より多くの格子点を含めることができ、それを少なくすることはできないため、二分探索は常に最小の実現可能な半径に収束します。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def count_squares(R):
    R2 = R * R
    total = 0
    for a in range(1, R + 1):
        rem = R2 - a * a
        if rem <= 0:
            break
        b = int(math.isqrt(rem))
        total += b
    return total * 4

def solve():
    s = int(input())
    
    lo, hi = 0, 2 * 10**7
    
    while lo < hi:
        mid = (lo + hi) // 2
        if count_squares(mid) > s:
            hi = mid
        else:
            lo = mid + 1
    
    print(lo)

if __name__ == "__main__":
    solve()
```カウント関数は、導出された幾何学的条件を直接実装します。 ループオーバー`a`早めに止まるときは`a²`を超える`R²`これ以上有効なペアが存在しないためです。 使用する`math.isqrt`大きな半径の周囲で蓄積される浮動小数点精度の問題を回避します。 

二分探索範囲は寛大に選択されています。 正方形の数は半径とともに二次関数的に増加するため、与えられた制約に対して答えは数百万を超えることはできません。

 ## 特殊なケース

 いつ`s`非常に小さいです、例えば`s = 0`、正しい半径は、すでに少なくとも 1 つの完全な正方形が含まれている最小の半径です。 二分探索はゼロから開始され、すぐに実行可能な最小半径に移動するため、アルゴリズムはこれを処理します。`count(R) > 0`。 

いつ`s`非常に大きい、近い`10^9`、二分探索は、カウント関数がターゲットを超え始めるまで半径を拡大します。 検索範囲が広い場合でも、単調性により対数反復での収束が保証されます。 

より微妙なケースは、正方形が軸に接触している場合に発生します。 みたいな広場`(0,0)-(1,1)`最も遠いコーナーの場合のみカウントされます`(1,1)`円の中にあります。 この条件ではすべての角を完全に含むことが厳密に要求され、アルゴリズムはこれを`(a, b)`特別なケーシング境界正方形を使用しない変換。
