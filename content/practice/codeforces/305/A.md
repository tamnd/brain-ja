 ## 解決策
 ## 問題の理解

 Vasya がサブセット内の任意の 2 つの数値を合計できるように、指定されたセットから整数の可能な最大のサブセットを選択するように求められます。 Vasya の合計ルールは特殊です。小数点以下の桁ごとに、2 つの数値のうち少なくとも 1 つの桁にゼロがなければなりません。 簡単に言うと、2 つの数値の桁を並べる場合、同じ列に両方の数値がゼロ以外の桁を持つことはできません。 

入力は単一の整数で構成されます`k`個別の数値の数を表し、その後に続きます`k`出力は、合計要件を満たす最大サブセットのサイズとその後に数値自体が続く必要があります。 以来`k`が最大 100 の場合、原理的にはブルートフォース ペアワイズ チェックが可能ですが、賢いアプローチにより不必要なチェックを回避できます。 

主なエッジ ケースには、0 のような数値、1 桁の数値、10 の累乗が繰り返される数値が含まれます。 たとえば、入力の場合`0 10 100 1`の場合、各ペアは「重複する小数点以下の桁がゼロ」ルールに従うため、最適なサブセットは 4 つの数値すべてです。 単純なアプローチは、ゼロの数字によって同じ列にゼロ以外の数字が共存できることを考慮しない場合、失敗する可能性があります。 

## アプローチ

 ブルートフォース手法では、指定された数値のすべてのサブセットをチェックして、すべてのペアが Vasya の合計条件を満たしているかどうかを確認しようとします。 これが機能する理由は、`k`は小さいですが、サブセットのチェックには最大 2^100 の可能性が含まれており、これは天文学的に大きくなります。 サブセット内の各ペアをチェックするだけでも、`O(k^2)`ですが、サブセットの列挙がボトルネックになります。 この強引な方法は原理的には正しいですが、完全に非現実的です。 

最適なアプローチは、2 つの数値が同じ小数点以下の桁で非ゼロの桁を共有する場合にのみ「ゼロ桁ルール」に違反するという観察に基づいています。 したがって、10 進数に基づいて数値を分類できます。 数値の百の位にゼロ以外の桁がある場合、サブセット内にゼロ以外の百の位を持つ他の数値は共存できません。 実際には、数値は 100 以下であるため、考慮すべき桁の位置は 3 つの桁 (単位、十の位、および百の位) のみです。 これにより、複雑さが大幅に軽減されます。選択する必要があるのは、「数字パターン」ごとに最大 1 つの数値と、存在する場合はゼロだけです。 どの数字がすでに使用されているかを追跡しながら、入力を注意深く通過するだけで十分です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^k * k^2) | O(k) | 遅すぎる |
 | 最適 | O(k * D) ここで、D= 桁位置の数 (~3) | O(k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. セットを初期化して、どの数値を安全に答えに追加できるかを追跡します。 空のリストから始めます。 
2. ゼロにはゼロ以外の数字がなく、任意の数値と組み合わせることができるため、ゼロが存在する場合は常にゼロを含めます。 
3. 残りの数値については、各数値を昇順に処理します。 それぞれについて、単位、十、百の位の数字配列に変換します。 
4. その位置の現在のサブセットにゼロ以外の数字がすでに存在するかどうかをマークする 3 つのブール配列 (数字の位置ごとに 1 つ) を維持します。 
5. 新しい数値を検討するときは、ゼロ以外の各桁を確認してください。 いずれかの桁が以前に選択した番号と競合する場合 (同じ位置がすでにゼロ以外の桁で占められている場合)、この番号はスキップします。 それ以外の場合は、その桁を使用済みとしてマークし、含めます。 
6. すべての数値を処理すると、リストには最大のサブセットが含まれます。 その長さと数値自体を出力します。 

機能する理由: 不変条件は、サブセット内の 2 つの数値が同じ小数点以下の桁でゼロ以外の数字を共有しないことです。 進行中に各位置をチェックしてマークすることにより、すべてのペアが Vasya の合計条件を満たすことを保証します。 100 以下の数値には 3 つの位置しかないため、これにより最大限の選択が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

k = int(input())
numbers = list(map(int, input().split()))
numbers.sort()

used_digits = [set(), set(), set()]  # units, tens, hundreds
answer = []

if 0 in numbers:
    answer.append(0)

for num in numbers:
    if num == 0:
        continue
    digits = [num % 10, (num // 10) % 10, (num // 100) % 10]
    conflict = False
    for i, d in enumerate(digits):
        if d != 0 and d in used_digits[i]:
            conflict = True
            break
    if not conflict:
        for i, d in enumerate(digits):
            if d != 0:
                used_digits[i].add(d)
        answer.append(num)

print(len(answer))
print(*answer)
```コードはまず数値を並べ替えて、より小さい数値が最初に選択されるようにします。これは、予測可能な出力に役立ちます。 単位、十、百の位に使用されているゼロ以外の数字を追跡します。 番号ごとに、現在のサブセットと共存できるかどうかがチェックされます。 ゼロが含まれることを保証するために、ゼロは別個に処理されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(k) | 各数値は 1 回処理されます。 桁位置は固定 (3) |
 | スペース | O(k) | サブセットと数字の 3 つのセットを保存する |

 k ≤ 100 および数値 ≤ 100 の場合、ソリューションは無視できる時間で実行され、使用されるメモリも最小限になります。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    k = int(input())
    numbers = list(map(int, input().split()))
    numbers.sort()
    used_digits = [set(), set(), set()]
    answer = []
    if 0 in numbers:
        answer.append(0)
    for num in numbers:
        if num == 0:
            continue
        digits = [num % 10, (num // 10) % 10, (num // 100) % 10]
        conflict = False
        for i, d in enumerate(digits):
            if d != 0 and d in used_digits[i]:
                conflict = True
                break
        if not conflict:
            for i, d in enumerate(digits):
                if d != 0:
                    used_digits[i].add(d)
            answer.append(num)
    return f"{len(answer)}\n{' '.join(map(str,answer))}"

# Provided sample
assert run("4\n100 10 1 0\n") == "4\n0 1 10 100"

# Minimum input
assert run("1\n0\n") == "1\n0"

# Maximum distinct digits
assert run("3\n10 20 30\n") == "3\n10 20 30"

# Conflicting units
assert run("4\n1 2 3 11\n") == "3\n1 2 3"

# Including zero allows more numbers
assert run("5\n0 10 20 30 3\n") == "5\n0 3 10 20 30"

| 1\n0 | 1\n0 | 最小サイズの入力 |
 | 3\n10 20 30 | 3\n10 20 30 | 固有の 10 桁の数字 |
 | 4\n1 2 3 11 | 3\n1 2 3 | 単位桁の競合の解決 |
