 ## 問題の理解

 この問題では、動物園内の経路を表す無向、無重みのグラフに取り組むことが求められます。 一部の頂点にはゼブラの囲いが含まれています。 すべての頂点について、ゼブラ エンクロージャを含む頂点に到達するために必要な最小数のエッジが必要です。 頂点がすべてのゼブラの囲いから分離されている場合、その答えは次のようになります。`-1`。 ハード バージョンは、ゼブラ エンクロージャが 1 つではなく多数存在する可能性があるため、イージー バージョンとは異なります。 [Codeforces Gym 105940C - ASZoo のグレート ゼブラ クエスト (ハード)](https://codeforces.com/gym/105940/problem/C)

 入力には複数のテスト ケースが含まれています。 各テスト ケースでは、場所の数、それらの間のパスの数、ゼブラ エンクロージャの数が示されます。 次の行ではパスが説明され、その後にエンクロージャの場所のリストが続きます。 出力は、順序どおりのすべての位置の最小距離です。 

制約は線形グラフ アルゴリズムを中心に設計されています。 すべてのテスト ケースで、頂点とエッジの合計数は最大で`2 * 10^5`。 すべてのノードから BFS を実行すると約`O(n * (n + m))`、周囲に到達できる`4 * 10^10`操作。 近くにある解決策`O(n + m)`が意図した方向です。 

不注意な実装によって破損するケースがいくつかあります。 1 つ目は、頂点自体がゼブラ エンクロージャである場合です。 例えば：```
1
3 2 2
1 2
2 3
1 3
```正しい出力は次のとおりです。```
0 1 0
```距離を開始するソリューション`1`検出されたすべてのノードに対して、ソースを初期化するのを忘れます`0`間違った答えが生まれてしまいます。 

もう 1 つのケースは、接続されていないグラフです。```
1
4 2 1
1 2
3 4
1
```正しい出力は次のとおりです。```
0 1 -1 -1
```すべての距離を初期化するトラバース`0`または、すべての頂点が最終的​​に訪問されると想定すると、到達不能なコンポーネントに誤って値が割り当てられます。 

最後のエッジ ケースは、すべての頂点がゼブラ エンクロージャである場合です。```
1
3 3 3
1 2
2 3
1 3
1 2 3
```正しい出力は次のとおりです。```
0 0 0
```実装が複数の開始点を正しく処理しない場合、1 つのエンクロージャのみから不必要な距離が計算される可能性があります。 

## アプローチ

 簡単なアプローチは、BFS を各 Zebra エンクロージャから個別に実行することです。 BFS は重み付けされていないグラフで最短距離を与えるため、各実行では 1 つのソースからの距離が正しく計算され、すべての実行で最小値を取ることで答えが得られます。 問題は、同じ作業を何度も繰り返すことです。 

最悪の場合、こんなことも考えられます`n`ゼブラエンクロージャ。 BFS の実行`k`コストの倍`O(k(n + m))`。 と`k`に近い`n`、これは次のようになります`O(n(n + m))`、指定された制限に対して遅すぎます。 

重要な観察は、すべてのゼブラ エンクロージャが同様に有効な目的地であるということです。 どのシマウマに到達するかは気にせず、最も近いシマウマに到達するだけです。 すべてのシマウマから個別に探索する代わりに、視点を逆にすることができます。 すべてのゼブラの位置がグラフ内に同時に拡大することを想像してください。 初めて頂点に到達すると、その頂点に割り当てられる距離は、最も近いゼブラまでの最短距離になります。 

これはまさにマルチソース BFS です。 最初にすべてのゼブラ エンクロージャを距離を置いてキューに配置します`0`。 その後、通常の BFS が続行されます。 BFS は距離を増やしてノードを処理するため、頂点に到達する最初のソースは可能な限り最も近いソースである必要があります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k(n + m)) | O(n) | 遅すぎる |
 | 最適 | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グラフの隣接リストを作成します。 グラフは無向であるため、2 つの場所間のすべてのパスについて、各エンドポイントを他のエンドポイントの近隣リストに追加します。 
2. 距離配列を作成し、すべての値を次のように初期化します。`-1`。 これは、まだどの場所にも到達していないことを表します。 
3. すべてのゼブラ エンクロージャをキューに入れ、その距離を次のように設定します。`0`。 各エンクロージャはすでにそれ自体からの距離が 0 にあり、すべてが開始点として機能する必要があります。 
4. キューが空でない間に、次の場所を削除します。 まだ距離がある隣接するすべての場所について`-1`、その距離を現在の場所の距離に 1 を加えたものとして割り当て、キューに追加します。 BFS では最初の訪問が最短であることが保証されているため、未訪問のチェックで十分です。 
5. 走査が終了したら、距離配列を出力します。 残っているもの`-1`値は、ゼブラ エンクロージャに到達できない場所に対応します。 

機能する理由: キューは常に、最も近いゼブラからの距離が減少しない順序で頂点を格納します。 頂点が最初に検出されると、短いパスはすべてすでに処理されているため、可能な限り最小の数のエッジを介して頂点に到達します。 すべてのゼブラの位置が一緒に始まるため、計算された距離は、考えられるすべての囲いにわたって最小になります。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n, m, k = map(int, input().split())

        graph = [[] for _ in range(n)]
        for _ in range(m):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            graph[u].append(v)
            graph[v].append(u)

        zebras = list(map(int, input().split()))

        dist = [-1] * n
        q = deque()

        for x in zebras:
            x -= 1
            dist[x] = 0
            q.append(x)

        while q:
            u = q.popleft()
            for v in graph[u]:
                if dist[v] == -1:
                    dist[v] = dist[u] + 1
                    q.append(v)

        ans.append(" ".join(map(str, dist)))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```隣接リストには既存のエッジのみが保存されるため、グラフ表現は入力サイズに比例した状態に保たれます。 キューには BFS のフロンティアが含まれており、ノードが正しい順序で処理されることが保証されます。 

初期化ループが通常の BFS との主な違いです。 1 つのソースを選択する代わりに、トラバーサルが開始される前にすべてのゼブラが挿入されます。 挿入前に距離を設定すると、同じゼブラが再度表示されるのを防ぎます。 

条件`dist[v] == -1`重要な境界確認です。 これにより、すべての頂点が 1 回だけ割り当てられることが保証されます。 エッジに沿って移動すると距離が 1 増えるため、すでに訪問した頂点を比較して更新する必要はありません。

## テストケース```python
import sys
import io
from collections import deque

def solution(inp):
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []

    for _ in range(t):
        n, m, k = map(int, input().split())
        g = [[] for _ in range(n)]

        for _ in range(m):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            g[u].append(v)
            g[v].append(u)

        z = list(map(int, input().split()))

        d = [-1] * n
        q = deque()

        for x in z:
            x -= 1
            d[x] = 0
            q.append(x)

        while q:
            u = q.popleft()
            for v in g[u]:
                if d[v] == -1:
                    d[v] = d[u] + 1
                    q.append(v)

        out.append(" ".join(map(str, d)))

    return "\n".join(out)

 ## 特殊なケース

 切断された場合:```
1
4 2 1
1 2
3 4
1
```キューは頂点から始まります`1`。 頂点を訪問します`2`到達可能なノードがもうないため停止します。 頂点`3`そして`4`決してイニシャルを残さないでください`-1`状態なので、最終的な答えは`0 1 -1 -1`。 

すべての頂点がゼブラである場合:```
1
3 3 3
1 2
2 3
1 3
1 2 3
```すべての頂点は距離を持ってキューに入ります`0`。 隣接するものをチェックすると、すでに距離が割り当てられているため、値は変更されません。 結果は残る`0 0 0`。 

複数のゼブラ エンクロージャが同じ頂点をめぐって競合する場合、BFS オーダーは自動的に同点を処理します。 頂点に到達する最初のゼブラ波は可能な最小距離を示しますが、それ以降の波は同等以上の経路を通過する必要があるため、距離を改善することはできません。
