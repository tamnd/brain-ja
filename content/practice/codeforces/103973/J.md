 ## 解決策
 ## 問題の理解

 私たちには無限のチェス盤の上に 2 人のキングが与えられています。 1 人の王はウォーク アローン (白) に属し、もう 1 人の王はヤナギの葉 (黒) に属します。 彼らは白から始めて交互に動き、各キングは標準的なチェスのキングのように動きます。つまり、隣接する 8 つのマスのいずれかにステップすることができます。 

追加の制限があります。キングは、他のキングに隣接するマス目に移動することはできません。 実際には、これは、移動するたびに 2 人の王が常に厳密に 1 より大きいチェビシェフ距離に留まらなければならないことを意味します。 

ホワイトの目的は、特定の正方形をキャプチャしたり到達したりすることではなく、最終的には任意の大きな x 座標を持つ特定の位置、正式には (10^100, y) の形式のセルに到達することです。 ボードは無限であるため、これは白がブロックされることなく無限に x 座標を増加し続けることができるかどうかを尋ねることと同じです。 ブラックの目的は、これが不可能になるのを防ぐことです。 

各テスト ケースでは、両方のキングの初期座標が得られます。 両プレイヤーが最適にプレーすると仮定して、白が最終的に右に永遠に逃げるという強制的な戦略を持っているかどうかを判断する必要があります。 

この制約により、絶対値で最大 10^9 の座標を持つ最大 100,000 のテスト ケースが許可されます。 これにより、ゲームのシミュレーションが直ちに無効になります。 単一のゲームでも任意の数の手が続く可能性があり、各手は局所的な貪欲さではなく全体的な戦略に依存するため、どのような解決策でも、テスト ケースごとに問題を定数時間の幾何学的条件に帰着させる必要があります。 

微妙な点は、移動が近接によって制限されることです。 たとえ黒がユークリッドの観点から遠く離れていても、白が進みすぎる前に白の前に位置を合わせることができれば、それでも干渉できる可能性があります。 もう 1 つの重要なエッジ ケースは、黒が x 方向では前から始まり、y 方向では大幅にオフセットされている場合です。 直感的には、黒が有利な場合は常に勝つと思われるかもしれませんが、垂直方向の分離により黒が効果的なブロック ラインを形成することが妨げられる可能性があるため、これは真実ではありません。 

## アプローチ

 ゲームを総当たり的に解釈すると、両方のキングのすべての合法的な手をシミュレートし、無限のゲーム ツリーに対してミニマックス検索を実行します。 各州は無限グリッド上の 2 つのポジションで構成され、各州から両プレイヤーは最大 8 つの可能な手を持ちますが、隣接制限による追加の合法性の制約があります。 メモ化しても、座標には制限がなく、キングは任意に遠くに移動できるため、状態空間には制限がありません。 これにより、ブルートフォースは基本的に不可能になります。 

重要な観察は、重要なのは 2 人のキング間の相対的な幾何学だけであるということです。 白の目的は、黒が X 座標の増加を永久に阻止できるかどうかにのみ依存します。 両方のキングが同じ速度で移動し、同じ移動能力を持っているため、黒が白を制御できるのは、X 軸に沿って白の前に「ブロック位置」を一貫して維持できる場合のみです。 

これにより、問題は、黒が時間内に白と並ぶ位置に到達し、維持できるかどうかを理解することに変わります。 決め手となるのは、黒が縦方向の分離を補いながら横方向のズレを減らすことができるかどうかです。 黒が水平方向の距離に対して垂直方向に遠すぎる場合、白がすり抜けてしまう前に、同時にギャップを埋めて白の前に整列することができません。 

これにより、初期構成に関する単純な幾何学的条件が得られます。つまり、水平距離と垂直オフセットを比較します。

 ## アルゴリズムのチュートリアル

 ### 1. 座標を抽出し、相対位置を計算します。

各テスト ケースについて、(x1, y1) で白を取得し、(x2, y2) で黒を取得します。 dx = x2 - x1 および dy = y2 - y1 を計算します。 これにより、問題は、黒が最初に右にあるかどうか、および黒が垂直方向にどの程度変位しているかを分析することに変換されます。 

dx の符号は、黒が既に白の背後にあるかどうかを即座に判断します。 黒が後方または同じ x 座標から開始した場合、白は常に最初に右方向に移動し続けることができるため、前方に永続的なバリアを確立することはできません。 

### 2. 黒が先行していない場合の処理

 dx <= 0 の場合、白はすでに少なくとも黒と同じくらい右にあります。 白が先に動き、x を増やすことだけを考えているため、黒は白の前に阻止壁を形成できません。 このシナリオでは白が即座に勝ちます。 

### 3. 黒が有利な場合、垂直オフセットと水平有利を比較します。 

dx > 0 の場合、最初は黒が前面に表示されます。 唯一の問題は、黒が進行を阻止するのに十分な速さで白と垂直に並ぶことができるかどうかです。 

|dy| を比較します。 DXで。 値 dx は、黒が水平方向に何ステップ進んでいるかを表します。これは、白が x 位置を回避できるようになるまでに利用できる手の数でもあります。 その間、黒は |dy| の垂直方向の分離も修正する必要があります。 白の前に整列します。 

|死ぬ|なら < dx、黒は垂直方向に調整するのに十分な時間があり、白の前に残り、効果的なバリアを形成できます。 

|死ぬ|なら >= dx の場合、黒は垂直方向のギャップを埋めることも、時間内に水平方向のリードを維持することもできないため、白はいつでもすり抜ける経路を見つけて x を無限に増加し続けることができます。 

### 4.勝者を決定する

 黒が先行していて |dy| の場合 < dx、ヤナギの葉を出力します。 それ以外の場合は、Walk Alone を出力します。 

### なぜ効果があるのか

 重要な不変条件は、白をブロックするには、黒が最終的に白の x フロンティア上またはその前の位置を占めると同時に、バイパスを防ぐために y で十分に隣接した状態を維持する必要があるということです。 両方のキングがターンごとに 1 ステップ移動するため、水平方向の進行は、黒が垂直方向のずれを修正するための厳密な時間割り当てとして機能します。 その予算が不十分な場合、白は残っている水平方向のスラックを利用することで、常に x で前進を維持できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x1, y1, x2, y2 = map(int, input().split())
        dx = x2 - x1
        dy = y2 - y1

        if dx <= 0:
            print("Walk Alone")
        else:
            if abs(dy) < dx:
                print("Salix Leaf")
            else:
                print("Walk Alone")

if __name__ == "__main__":
    solve()
```このソリューションは各テスト ケースを読み取り、相違点を 2 つに絞り込みます。 最初の決定ポイントでは、黒が x 方向に既に進んでいるかどうかをチェックします。 そうでない場合は、黒が前進バリアを確立できないため、白が勝つのは自明です。 

黒が先行している場合、関連する唯一の比較は、水平方向のリードと垂直方向の分離の間です。 厳密な不平等`abs(dy) < dx`これは重要です。黒にとって平等だけでは十分ではありません。境界線の場合、白は完全な位置合わせを防ぐのに十分な水平方向の進歩を常に維持でき、ブロッキング戦略を破ることができるからです。 

すべての操作はテスト ケースごとに一定時間であるため、ソリューションは 100,000 の入力を簡単に処理できます。

 ## 特殊なケース

 黒が先行して開始するが、(0,0) や (2,2) など、大きさが垂直オフセットと正確に一致する場合、abs(dy) は厳密には dx より小さいわけではないため、アルゴリズムはそれを白の勝ちとして分類します。 この状況では、黒の垂直方向のずれを修正する能力は非常に厳しいため、同時に前方ブロックの位置を維持することができず、白が x で進み続けることができます。 

白が (2,0) で黒が (-1,0) であるなど、黒が x で遅れている場合、dx は負になり、アルゴリズムはすぐに Walk Alone を返します。 たとえ黒が白に向かって動いたとしても、白は常に x 方向の主導権を保持しているため、永続的なフォワード ブロッカーになることはできません。
