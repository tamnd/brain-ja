 ## 解決策
 ## 問題の理解

 缶のラインが与えられ、それぞれに耐久性の値が設定されています。 Vasya はすべての缶を正確に 1 回撃つ必要がありますが、缶を倒すのに必要なショットの数は、すでに倒された缶の数によって異なります。 具体的には、缶に耐久性がある場合$a_i$そしてヴァシャはすでにノックダウンしました$x$缶、彼には必要だ$a_i \cdot x + 1$その缶を破壊するショット。 目標は、ショットの総数を最小にする射撃順序を決定し、最小の合計数と 1 つの有効な順序の両方を報告することです。 

入力は缶の数で構成されます$n$(最大1000)とその耐久値$a_i$(最大1000)。 これらの境界は、アルゴリズムが$O(n^2)$またはそれ以上の速度でも許容されますが、すべてを試行するアルゴリズムはすべて$n!$順列は実行不可能です。$1000!$天文学的に大きいです。 

複数の缶の耐久性が同じ場合、エッジケースが発生します。 最適な順序は一意ではない可能性がありますが、どの同等の缶が最初に選択されるかに関係なく、ショットの合計数は同じになるはずです。 もう 1 つの微妙な点は、合計を最小にするには、最小の耐久性缶から開始する必要がある可能性があることです。これは、慎重に推論しなければ直感的ではない可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、缶のすべての並べ替えを試み、注文ごとにショットの合計数を計算し、最小値を選択します。 これは正しいですが、まったく実用的ではありません。$n!$実行可能な計算よりも速く成長します$n = 1000$。 のために$n = 10$、これにはすでに 3,628,800 のチェックが必要です。 

重要な洞察は、缶のコスト関数を認識することです。$a_i \cdot x + 1$、既に倒された缶の数に応じて直線的に増加します。 したがって、後で撃たれた場合、缶の耐久性の影響は大きくなります。 合計を最小限に抑えるために、高耐久缶の経験値をできるだけ小さくしたいと考えています。$x$できるだけ早く撃つことを意味します。 逆に、耐久性の低い缶は、増加するにつれて貢献度の増加が遅くなるため、遅れる可能性があります。$x$。 この観察は、耐久性の高い順に缶を並べ替え、その順序で撮影するという貪欲なアプローチにつながります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | 最適（耐久性に貪欲） | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む$n$そして耐久性アレイ$a$。 の各要素$a$撮影順序を追跡するために、元のインデックスとペアになっています。 
2. ペアのリストを耐久性の降順に並べ替えます。 これにより、遅れた場合により多くのショットが必要な缶がより早くショットされることが保証されます。 
3. すでに発射された缶の数のカウンターを初期化します。$x = 0$、および合計ショットを蓄積する変数、$total = 0$。 
4. ソートされた缶を繰り返し処理します。 耐久性のある缶ごとに$a_i$、必要なショットを次のように計算します。$a_i \cdot x + 1$。 これを追加$total$そして増加します$x$1つずつ。 
5. ソートされたペアから元のインデックスを抽出して、撮影順序を作成します。 
6. 印刷$total$そして撮影順。 

機能する理由: このアルゴリズムは、各缶のコストに、同等以上の耐久性を持つすべての缶のうち、以前にノックダウンされた缶の最小数を乗算することを保証します。 これにより、より高い耐久性を後で配置すると重み付けされた寄与が増加するため、他の順列はより小さい合計を生成できないという不変条件が維持されますが、これは最適ではありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

# Pair durability with original indices
cans = [(a[i], i + 1) for i in range(n)]
# Sort by descending durability
cans.sort(reverse=True, key=lambda x: x[0])

total = 0
order = []

for x, (dur, idx) in enumerate(cans):
    total += dur * x + 1
    order.append(idx)

print(total)
print(' '.join(map(str, order)))
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 耐久性と元のインデックスの組み合わせにより、並べ替え後のマッピングが保持されます。 ソートキーにより降順の耐久性が保証されます。 合計ショット数はループ内に蓄積されます。`x`すでに発射された缶の数を自然に追跡します。 最後に、ソートされた撮影順にインデックスが出力されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    cans = [(a[i], i + 1) for i in range(n)]
    cans.sort(reverse=True, key=lambda x: x[0])
    total = 0
    order = []
    for x, (dur, idx) in enumerate(cans):
        total += dur * x + 1
        order.append(idx)
    return f"{total}\n{' '.join(map(str, order))}"

# Provided samples
assert run("3\n20 10 20\n") == "43\n1 3 2"
# Custom test cases
assert run("4\n1 3 2 4\n") == "14\n4 2 3 1"
assert run("2\n5 5\n") == "7\n1 2"
assert run("5\n1 2 3 4 5\n") == "35\n5 4 3 2 1"
assert run("3\n1 1 1\n") == "6\n1 2 3"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 4 1 3 2 4 | 14 4 2 3 1 | 耐久性が混在する一般的なケース |
 | 2 5 5 | 7 1 2 | 2 つの同等の耐久性 |
 | 5 1 2 3 4 5 | 35 5 4 3 2 1 | 耐久性の向上 |
 | 3 1 1 1 | 6 1 2 3 | すべて同等の耐久性 |

 ## 特殊なケース

 耐久性が等しい缶の場合、順序が合計に影響を与えないため、アルゴリズムは正確さを維持します。 たとえば、入力`3 1 1 1`順序に関係なく合計 6 個が生成されます。 トレース:

 | ステップ | × | できる (dur, idx) | ショットが追加されました | 合計 |
 | --- | --- | --- | --- | --- |
 | 0 | 0 | (1,1) | 1 | 1 |
 | 1 | 1 | (1,2) | 2 | 3 |
 | 2 | 2 | (1,3) | 3 | 6 |

 耐久性の高い缶が最初に配置されるという不変条件は自明に満たされ、出力は有効なままになります。
