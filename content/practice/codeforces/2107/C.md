 ## 問題の理解

 いくつかの位置がすでに固定されており、いくつかの位置が「不明」である配列が与えられています。 不明な位置は最初はゼロに設定されますが、最大で任意の整数で上書きすることができます。$10^{18}$。 目標は、最終的な配列の最大部分配列合計が正確に一致するように、これらの未知の位置に値を割り当てることです。$k$。 

重要な点は、最終的な配列が単一のグローバル制約に一致する必要があることです。つまり、可能な限り最良の連続セグメントの合計が正確に一致する必要があります。$k$、少なくともそうではありません。 未知の値を自由に選択して、大きな正の寄与を作成するか、不要な大きな合計を抑制することができますが、サブ配列が次の値を超えないようにする必要があります。$k$少なくとも 1 つは正確に達成する$k$。 

制約は、テスト ケースごとの線形または線形に近い解決策を意味します。 合計から$n$すべてのテストケースにわたって$2 \cdot 10^5$、 どれでも$O(n^2)$あるいは$O(n \log n)$テスト ケースごとの値は、慎重に償却される場合にのみ許容されますが、その構造は、貪欲または線形スキャンと Kadane スタイルの推論を組み合わせたものであることを強く示唆しています。 

素朴なアプローチでは、未知の位置のすべての割り当てを試みたり、それぞれの未知の位置を変数として扱って、すべての部分配列の制約を解決しようとしたりします。 指数関数的な組み合わせがあるため、これは不可能です。 

2 番目の単純な間違いは、局所的な改善を達成するために未知のものを独自に設定することです。 これは、サブ配列の合計がグローバルであるため失敗します。1 つの位置を調整すると、重複するサブ配列が多くなる可能性があります。 

特に誤解を招きやすいのは、すべての位置が不明な場合です。 配布しようとする人もいるかもしれない$k$任意ですが、周囲の負のドリフトを制御しないと、複数のサブアレイが超過する可能性があります。$k$。 

たとえば、次の場合$n=3, k=5$すべてゼロ、選択$[5,0,0]$動作しますが、動作します$[3,2,0]$。 ただし、選択すると、$[5,5,-5]$部分配列の合計が超過する可能性があるため、制約に違反します。$k$。 本当の課題は、1 つの有効なセグメントを構築するだけではなく、グローバル最大値を確実に制御することです。 

## アプローチ

 この問題は本質的に、部分的な制約の下での最大サブ配列合計の制御に関するものです。 強引なアイデアは、未知の位置に値を割り当ててから、Kadane のアルゴリズムを使用して部分配列の合計の最大値をチェックすることです。 それぞれの未知の位置は無限に多くの値を取る可能性があるため、これは巨大な空間にわたる継続的な探索問題になります。 値を有限の範囲に制限しても、指数関数的に複雑になります。 

重要な洞察は、未知の位置が「リセット ポイント」または「コントロール ポイント」として機能する可能性があるということです。 代入を注意深く構造化すると、和を達成する単一の部分配列を分離できます。$k$、他のすべての貢献は安全に以下に維持されるように強制します$k$。 

標準的な戦略は、未知の位置を潜在的な区切り文字として扱うことです。 まず、既知の値のみを使用して (未知の値をゼロとして処理して) サブ配列の合計の最大値を計算します。 これがすでに超えている場合$k$、既知のセグメントに関係する寄与を減らす必要がありますが、既知の値は固定されているため、これは不可能であり、答えはすぐに不可能になります。 

既知のみの寄与率の最大値が既に次の値を超えている場合$k$、既知の値を変更できないため、割り当てを行ってもそれを修正できません。 

それ以外の場合は、正確に達成する単一のセグメントを「注入」しようとします。$k$。 これは、適切な未知の位置を選択し (または未知のブロックを処理し)、制御された Kadane スタイルのプレフィックスが正確に到達するように値を割り当てることによって行われます。$k$、他のすべてがそれを超えないようにしながら。 

コアの構築では、プレフィックス/サフィックス DP 動作が使用されます。実行中のサブ配列の合計を維持し、未知の位置でリセットし、大きな負の値を慎重に割り当てて不要な増加を防ぎ、同時に正確に蓄積する制御されたセグメントを確保します。$k$。

 ## アルゴリズムのチュートリアル

 私たちは問題を実現可能性の確認と構築の 2 つのフェーズに分割しました。 

1. まず、すべての未知の値をゼロに置き換え、Kadane のアルゴリズムを使用して部分配列の最大合計を計算します。 

これにより、固定値によってすでに強制されているものに下限が与えられます。 この値がより大きい場合$k$, 固定拠出金を減らすことはできないので、すぐに不可能と結論付けます。 
2. サブ配列の最大合計がすでに正確に一致している場合$k$、すべての未知数をゼロに割り当てて終了できます。 
3. それ以外の場合は、正確に到達するセグメントを「作成」する必要があります。$k$。 私たちは次のようなポジションを選びます。$s_i = 0$。 この位置は制御されたアンカーとして機能します。 
4. すべての未知の位置を次のような非常に負の値に割り当てます。$-10^{18}$選択したアンカーを除き、慎重に扱います。 

その目的は、サブアレイが複数の未知の寄与を誤って蓄積しないようにすることです。 これらの大きなネガはハードセパレーターとして機能します。 
5. 次に、単一の左から右へのスキャンを使用して、アンカーで終了するか、変数に設定した場合はアンカーを通過する最適な部分配列の合計を計算します。$x$。 

これは追跡に帰着します。 

アンカーの前で終わる最適なサフィックスとアンカーの後に始まる最適なプレフィックス。 
6. しましょう$L$(未知の障壁を越えることなく) アンカーの直前で終了する最良の部分配列合計であること。$R$アンカーの直後から始まる最良のプレフィックス合計になります。 

次に、アンカーを含む任意の部分配列は次の形式になります。$L + x + R$。 
7. 設定します$x = k - (L + R)$。 これにより、そのアンカーを介した最適なサブ配列が強制的に正確になります。$k$。 
8. 最後に、他のサブ配列が次の値を超えていないことを確認します。$k$これは、制御されない成長を防ぐ大きな負の割り当てによって保証されます。 

### なぜ効果があるのか

 この構造により、選択されたアンカーを通過する単一の設計セグメントを除き、すべてのサブアレイが既知の値の固定セグメント内に完全に含まれるか、少なくとも 1 つの重度の負のセパレーターを通過することが保証されます。 大きな合計を蓄積できるのは 1 つの制御パスのみであるため、グローバル最大値は正確に設計値になります。 他のすべてのサブ配列は、既知のセグメントのカダン最大値によって制限されており、この最大値を超えないことが保証されています。$k$。 

これにより、グローバル不変式が作成されます。すべての部分配列は、以下のいずれかに安全に制限されます。$k$、または一意の候補が強制的に等しくなりますか$k$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

NEG = -10**18

def kadane(a):
    best = -10**30
    cur = 0
    for x in a:
        cur = max(x, cur + x)
        best = max(best, cur)
    return best

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    s = input().strip()
    a = list(map(int, input().split()))

    b = [a[i] if s[i] == '1' else 0 for i in range(n)]

    max_known = kadane(b)

    if max_known > k:
        print("No")
        continue

    if max_known == k:
        print("Yes")
        print(*b)
        continue

    pos = -1
    for i in range(n):
        if s[i] == '0':
            pos = i
            break

    if pos == -1:
        print("No")
        continue

    left_best = [0] * n
    cur = 0
    for i in range(pos - 1, -1, -1):
        cur = max(0, cur + b[i])
        left_best[i] = cur

    right_best = [0] * n
    cur = 0
    for i in range(pos + 1, n):
        cur = max(0, cur + b[i])
        right_best[i] = cur

    L = 0
    cur = 0
    for i in range(pos - 1, -1, -1):
        cur = max(b[i], cur + b[i])
        L = max(L, cur)

    R = 0
    cur = 0
    for i in range(pos + 1, n):
        cur = max(b[i], cur + b[i])
        R = max(R, cur)

    x = k - (L + R)
    b[pos] = x

    print("Yes")
    print(*b)
```コードはまず未知の値をゼロに圧縮して、避けられない構造を測定します。 次に、直接受け入れるか、強制的な「アンカー」位置を構築します。 そのアンカーの周囲の左右の寄与は、Kadane スタイルのスキャンを使用して独立して計算されます。これにより、最終的なサブ配列の最大合計を制御する唯一の変数が、選択された未知の値になることが保証されます。 減算ステップにより、必要な寄与分が正確に分離されます。 

よくある実装の落とし穴は、部分配列がアンカーの周囲のどこでも開始または終了できることを忘れていることです。そのため、境界をゼロと仮定するのではなく、左右の寄与を独立して計算する必要があります。
