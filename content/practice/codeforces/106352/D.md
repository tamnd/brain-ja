 ## 解決策
 ## 問題の理解

 それぞれが Zveropolis の「労働者」を表す整数のリストが与えられます。 特定のインタラクション スコアが最大化されるように、すべてのワーカーに対して同じリストから異なるパートナーを選択する必要があります。 

2 つの数値間のスコア$x$そして$y$はバイナリ表現で定義されます。 すべてのビット位置を調べます$i$、そして両方の条件を満たすインデックスがいくつあるかを数えます。$x$そして$y$位置に連続したものがある$i$そして$i+1$。 言い換えれば、隣接するビットのペアごとに、両方の数値の同じ位置にパターン「11」が含まれているかどうかを確認し、そのような位置が一致する数を数えます。 

タスクはすべての要素に対して$a_i$、別のインデックスを見つけるには$j \neq i$このスコアを最大化する値を求め、その最大値を出力します。 

制約は、ソリューションの主要な推進力です。 要素の数は最大です$10^6$したがって、配列上の二次関数は直ちに不可能になります。 要素ごとに他のすべてに対して線形スキャンを行っても、$10^{12}$最悪の場合の運用。 同時に、各値は最大で$10^6$したがって、バイナリ表現は小さく、わずか約 20 ビットです。 これは、各数値の大きさよりもその「構造」が重要であるビットマスク ベースのソリューションを強く示唆しています。 

複数の同一の値が存在する場合、微妙なエッジケースが発生します。 ワーカーはそれ自体とペアにできないため、値のすべての出現が同一である場合でも、別のコピーが存在する場合は必ずそれを選択する必要があり、そうでない場合は、別のパートナーにフォールバックする必要があります。 

たとえば、配列が次の場合、$[3, 3, 3]$、各インデックスの最適なパートナーはさらに 3 であり、答えは次のスコアになります。$F(3,3)$、0 または未定義ではありません。 

もう 1 つの例外的なケースは、すべての数値が個別であり、バイナリ構造内で非常にまばらであるため、どこでも重複がゼロになる場合です。 その場合、すべての答えは正しく 0 になるはずです。 

## アプローチ

 直接的なアプローチでは、考えられるすべてのペアを試します$(i, j)$。 各ペアについて、すべてのビット位置をスキャンし、両方の数値に連続した数値が含まれているかどうかを確認することでスコアを計算します。 各数値には最大約 20 の関連ビット位置があるため、1 回の比較は安価ですが、$O(n^2)$ペアは大きすぎます$n = 10^6$。 これはおおよそ次のことにつながります$10^{12}$制限時間内では不可能なペアの評価。 

重要な観察は、スコアが隣接するセット ビットのパターンのみに依存するということです。 数値ごとに、ビットマスクとしてエンコードできます。$i$位置の場合は 1$i$そして$i+1$どちらもオリジナルの番号に設定されています。 これにより、問題は純粋なビットマスク類似性タスクに変換されます。マスクごとに、共通のセット ビットの数を最大化する別のマスクが必要になります。 

したがって、元の数値を扱う代わりに、それぞれを変換します。$a_i$派生マスクに$g(a_i)$。 この場合、スコアは単純に設定されたビット数になります。$g(a_i) \& g(a_j)$。 

ここでのタスクは、マスクごとに、交差サイズを最大化するセット内の別のマスクを見つけることです。 ビット幅が小さい (約 20) ため、サブセット動的プログラミングのアイデアを使用できます。 

入力にどのマスクが存在するかを事前計算してから、サブセットを推論します。 主なアイデアは、考えられるすべてのサブセットについて事前計算することです。$S$、派生マスクに含まれる数値が少なくとも 1 つ存在するかどうか$S$。 次に、固定クエリマスクの場合$A$、別のマスクとの共通の交差は、何らかのサブセットに対応します。$S \subseteq A$それは他のマスクにも含まれています。 

次に、そのような最大のサブセットを検索します$S$交差サイズの最大化は、次のサイズの最大化と同等であるためです。$S$。 

これにより、問題はペアごとの比較からサブセットにわたる構造化検索に軽減され、20 ビット空間にわたる SOS 動的プログラミングを使用して処理できます。

 | ブルートフォース |$O(n^2 \cdot 20)$|$O(1)$| 遅すぎる |
 | マスク越しのSOS DP |$O(2^m \cdot m)$、$m \le 20$|$O(2^m)$| 承認済み |

 ## アルゴリズムのチュートリアル

 しましょう$m \approx 20$は、派生マスク内のビット位置の最大数になります。 

1.各数値を変換する$a_i$マスクの中へ$g_i$、どこビット$k$両方のビットの場合に設定されます$k$そして$k+1$1インチです$a_i$。 これにより、各数値が構造シグネチャに圧縮され、すべてのペアごとのスコアが完全に決定されます。 
2. 各マスクの頻度をカウントします。 これは、ある番号が別の同じ番号とペアになる可能性がある場合を処理するために必要です。 
3. アレイを構築する`exist[S]`以下に等しい入力マスクが少なくとも 1 つあるかどうかを示します。$S$。 
4. スーパーセットに対して SOS DP を実行して計算します`sup[S]`、以下を含む入力内のマスクの数。$S$。 これにより、候補交差パターンが実際に有効なパートナー内に現れるかどうかを迅速に確認できます。 
5. 定義する`good[S]`場合は真実として$S$少なくとも 1 つのパートナー マスクとの有効な交差パターンとして使用できます。 もともとこれは`sup[S] > 0`。 
6. 定義する`best[S]`サブセットの最大サイズとして$T \subseteq S$そのような`good[T]`それは本当です。 これは、より小さなマスクからより大きなマスクに最適な値を伝播するサブマスク DP を使用して計算されます。 
7. 各クエリマスクについて$A$、答えは`best[A]`ただし、最良のサブセットが次の場合を除きます。$A$それ自体とこの正確なマスクは入力内で 1 回だけ発生します。 その場合、自己ペアリングを除外する必要があるため、内部の次に最適な有効なサブセットにフォールバックします。$A$。 

正しさは、2 つのマスク間の共通の交差自体が両方のマスクのサブセットであるという事実から得られます。 したがって、すべての有効なスコアはクエリ マスクの一部のサブセットに正確に対応し、スコアを最大化することは、少なくとも 1 つの他の要素によって実現可能なそのような最大のサブセットを見つけることと同じです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXB = 20
MAXM = 1 << MAXB

n_and_rest = sys.stdin.read().strip().split()
n = int(n_and_rest[0])
a = list(map(int, n_and_rest[1:]))

# Step 1: build derived masks g(x)
def build_mask(x):
    res = 0
    for i in range(MAXB - 1):
        if (x >> i) & 1 and (x >> (i + 1)) & 1:
            res |= 1 << i
    return res

freq = [0] * MAXM
masks = []

for x in a:
    g = build_mask(x)
    masks.append(g)
    freq[g] += 1

# Step 2: superset DP to compute sup[S]
sup = freq[:]
for i in range(MAXB):
    for mask in range(MAXM):
        if (mask >> i) & 1 == 0:
            sup[mask] += sup[mask | (1 << i)]

# Step 3: good masks
good = [sup[i] > 0 for i in range(MAXM)]

# Step 4: best submask DP
best = [-1] * MAXM
for mask in range(MAXM):
    if good[mask]:
        best[mask] = bin(mask).count("1")

for i in range(MAXB):
    for mask in range(MAXM):
        if mask & (1 << i):
            if best[mask ^ (1 << i)] > best[mask]:
                best[mask] = best[mask ^ (1 << i)]

# Step 5: answer queries
res = []
for i, g in enumerate(masks):
    ans = best[g]

    # handle self-exclusion if needed
    if ans == bin(g).count("1") and freq[g] == 1:
        # try to find second best by temporarily ignoring full mask
        tmp = g
        best_full = best[g]
        best_without = -1

        # recompute only over submasks of g
        s = tmp
        sub = s
        while True:
            if good[sub] and sub != tmp:
                best_without = max(best_without, bin(sub).count("1"))
            if sub == 0:
                break
            sub = (sub - 1) & s

        ans = best_without

    res.append(str(ans))

print(" ".join(res))
```この実装は、各数値を 20 ビットの構造マスクに圧縮し、スーパーセット DP を使用してどの交差パターンが実行可能であるかを決定するという考えに従っています。 サブマスク DP ステップは、実現可能性をマスクごとのベストスコア テーブルに変換するため、各クエリは直接ルックアップになります。 

唯一のデリケートな部分は、マスクが 1 回だけ発生する場合の自己ペアリングを除外することです。 この場合は、クエリ マスクのサブマスクをスキャンすることによって個別に処理されます。これは、マスク サイズが最大 20 ビットであるため実現可能です。 

## 実用的な例

 次のサンプルを考えてみましょう。 

数値から派生した入力マスクは小さなビット パターンを生成し、DP はすべての実行可能な交差サブセットを構築します。 みたいなマスクの場合`g = 0101`、アルゴリズムは次のようなすべてのサブセットをチェックします。`0101`、`0100`、`0001`、`0000`そして、他の要素に存在する最大のものを選択します。 

2 番目の例:

 数値にマスクを生成させます。```
A = 1100
B = 1010
C = 1000
```のために`A`、サブマスクは`1100`、`1000`、`0100`、`0000`。 もし`1000`別のマスクに存在する場合、完全なオーバーラップ 2 が不可能であっても、答えは 1 になります。 

各要素について、DP は常に実現可能な最大のオーバーラップを選択することを保証します。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、マスクの最適なパートナーがマスク自体であるにもかかわらず、コピーが 1 つしか存在しない場合です。 その場合、アルゴリズムの生の DP により誤ってセルフペアリングが許可されてしまいます。 フォールバック サブマスク スキャンにより、完全なマスクが明示的に除外され、次に最適なサブセットが検索され、正確さが維持されます。 

もう 1 つのエッジ ケースは、すべてのマスクが空の場合です。 この場合、空のマスクは常に有効なサブセットであり、データセット内に常に存在するため、すべての交差はゼロになり、DP はすべての最良の値を正しくゼロのままにします。 

最後のケースは、同一のマスクが複数存在する場合です。 次に、別の出現が存在するため、自己ペアリングが有効になり、頻度チェックにより、フルスコアのサブセットが変更なしで回答のままになることが許可されます。
