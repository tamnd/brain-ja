 ## 問題の理解

 一連のペイント ボールが与えられ、それぞれのペイント ボールが飛んだ瞬間と垂直方向の位置 (壁上の列) によって特徴付けられます。 壁には高さがある`h`、行には下から上に番号が付けられます。 各ペイントボールは指定された時間にのみ存在し、1 つの行にのみ影響します。 

選択した開始時間に`t0`、高さが固定されたシールド`w`行を覆って配置されます`[1, w]`。 その後、1 秒ごとにちょうど 1 行ずつ上に移動します。`t0 + k`行をカバーします`[1 + k, w + k]`。 最上部の有効な位置に達したら`[h - w + 1, h]`、1秒間そこに留まり、その後消えます。 ペイントボールは、その時点でその行がシールドでカバーされている現在の間隔内にある場合、ブロックされます。 

課題は選択することです`t0`ブロックされたペイントボールの数を最大化します。 

入力サイズは最大です`n = 10^5`、行の座標と時間は次のようになります。`10^9`。 これにより、考えられるすべての開始時間または寿命のすべての秒についてシールドをシミュレートしようとするソリューションは即座に除外されます。 二次関数または偶数`O(n log n)`すべての候補者に対する候補者ごとの戦略では遅すぎます。 

主な問題点は、各ペイント ボール制約が時間と行を結び付けることです。ペイント ボール制約がブロックされるかどうかは、その時間と選択した開始時間の間の線形関係に依存します。 

いくつかの特殊なケースが重要です。 

1 つは、複数のペイントボールが同時に異なる列で発生する場合です。 たとえば、ある時間に`t = 5`列があります`1, 2, 10`そして`w = 2`、連続する 2 列のみをカバーできるため、最大でも 2 列がブロックされ、3 列すべてがブロックされることはありません。 

もう一つは、いつ`w = h`。 その場合、シールドは位置に関係なく、グリッド全体を正確に 1 秒間カバーします。そのため、答えは、有効なシールドの存在間隔と一致する、常に存在するペイント ボールの数を単純に数えることになります。実際、位置を揃えれば、すべてのペイント ボールをブロックできます。`t0`時間とともに。 

3 番目の微妙なエッジ ケースは順序です。シールドは時間とともに決定論的に移動するため、シールドを「テレポート」したり、中間位置で数秒間固定したりする誤った解釈は、ブロック数を過剰にカウントします。 

## アプローチ

 ブルートフォース手法では、可能なすべての開始時刻が試行されます。`t0`ペイントボールの全回のセットから。 候補者ごとに`t0`では、シールドの動きを秒ごとにシミュレートし、各ペイントボールをチェックして、その時点でカバーされているかどうかを確認します。 シールドの動作は完全に決定的であるため、これは概念的に機能します。`t0`修正されているため、正確性は問題になりません。 

問題はパフォーマンスです。 試してみると`O(n)`可能`t0`値とそれぞれについてすべてをスキャンします`n`ペイントボール、もう手に入れました`O(n^2)`、これは限界をはるかに超えています`n = 10^5`。 さらに直接的に、シールド全体をシミュレートすると、`h`ステップは不可能なので、`h`到達できる`10^9`。 

重要な観察点は、各ペイントボールが有効なペイント ボールに制約を課すことです。`t0`価値観。 ペイントボールの場合`(t, s)`ブロックされるには、シールドが列を覆う必要があります`s`時に`t`、これは次のことを意味します:```
1 + (t - t0) <= s <= w + (t - t0)
```両方の不等式を並べ替えると、有効な区間が得られます。`t0`このペイントボールがカバーされる値。 したがって、各ペイントボールは次の数直線上のセグメントになります。`t0`。 

この変換が完了すると、問題は点を見つけることになります。`t0`それは最大間隔数の範囲内にあります。 これは間隔に関する古典的な最大重複問題であり、エンドポイントの並べ替えとスイープで解決できます。 

微妙な点は、シールドが存在するのは有限の秒数だけであることも考慮する必要があるということです。 ただし、有効範囲外では不等式が単に空の区間を生成するため、この制約は区間導出によって自然にエンコードされます。

 ## アルゴリズムのチュートリアル

 ### キー変換

 1. ペイントボールごとに`(t, s)`の範囲を導出します。`t0`ブロックされる値。 

時の盾`t`行をカバーします`[1 + (t - t0), w + (t - t0)]`。 私たちは次のことを要求します:```
1 + (t - t0) <= s <= w + (t - t0)
```両方の不等式を解くと次のようになります。```
t - s + 1 <= t0 <= t - s + w
```したがって、各ペイントボールは間隔になります`[L, R]`可能な開始時間のタイムラインに表示されます。 
2. すべてのペイントボールについて、そのような間隔をすべて収集します。 それぞれ有効`t0`シールド軌道の垂直方向の位置合わせを選択することに対応します。 
3. 私たちが望んでいるのは、`t0`それはこれらの間隔の最大数にあり、これは最大間隔オーバーラップに相当します。 
4. 各間隔を 2 つのイベントに変換します。 +1 at`L`、-1で`R + 1`。 
5. すべてのイベントを座標でソートし、現在の合計を維持しながら左から右にスイープします。 
6. 現在の合計の最大値を追跡します。 これが答えです。 

### なぜ効果があるのか

 各ペイントボールは独立して条件に影響を与えます。`t0`。 シングル`t0`は、ペイント ボールがその導出された間隔内にある場合にのみ有効です。 したがって、指定された間隔がいくつ含まれるかを数えると、`t0`ブロックされたペイントボールの数を正確に数えています。 スイープ ラインは、最適な開始時間に直接対応する最大オーバーラップ点を見つけます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, h, w = map(int, input().split())

events = []

for _ in range(n):
    t, s = map(int, input().split())
    L = t - s + 1
    R = t - s + w
    events.append((L, 1))
    events.append((R + 1, -1))

events.sort()

cur = 0
best = 0

for x, delta in events:
    cur += delta
    if cur > best:
        best = cur

print(best)
```実装の中核は間隔変換ステップです。 各ペイントボールは開始時間の範囲に変換されます`t0`ブロックされてしまうところ。 並べ替えられたイベント エンドポイント上のスイープ ラインは、そのような制約が同時に満たされる数を累積します。 

微妙なディテールが使用されています`R + 1`ネガティブな出来事に対して。 これにより、整数スイープ ロジックとの互換性を保ちながら、間隔が両端を含むものとして扱われることが保証されます。 このシフトがないと、オフバイワンエラーにより、シールド適用範囲の境界に正確にあるペイントボールが誤ってカウントされてしまいます。 

もう 1 つのポイントは、明示的には使用しないことです。`h`。 これはシールド パスの物理的制約を定義しますが、導出された不等式がすでに実現可能性をエンコードしているため、暗黙的に尊重されます。

 ## 特殊なケース

 重大なエッジ ケースは、特定の秒時にペイント ボールがシールドの下端または上端に正確に位置する場合です。 間隔の導出には両方の境界が含まれるため、そのようなペイント ボールは有効としてカウントされる必要があります。 制約を変換するときに厳密な不等式を使用すると、これらのケースは誤って削除されます。 

導出された間隔が実行可能な時間範囲を超えた場合、別のエッジ ケースが発生します。 たとえば、早い時点で非常に高い行は負の値を生成します。`L`。 整数上のスイープ ラインは無制限の範囲を自然に処理するため、これは問題ではありません。 このような間隔は、単に他の間隔よりも早く開始されます。 

最後に、複数のペイントボールが同じ位置で重なり合います。`(t, s)`値により同一の間隔が生成されます。 スイープでは、それぞれが個別の +1 イベントに寄与するため、多重度が正しくカウントされ、重複の正しい集計が保証されます。
