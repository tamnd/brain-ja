 ## 解決策
 ## 問題の理解

 ジュディがプレイした一連の試合が与えられています。 私たちは彼女が何回勝ち、引き分け、負けたかだけを知っていますが、それらの試合の順番は知りません。 得点システムは純粋に加算的なものではなく、勝利では 2 ポイント、引き分けでは 1 ポイント、負けでは 0 ポイントとなりますが、すべてを変える追加ルールがあります。 現在のゲームの直前にジュディが 2 連勝している場合、現在のゲームが勝ち、引き分け、または負けであるかどうかに関係なく、現在のゲームのポイントが 2 倍になります。 

したがって、問題は単に結果を数えることではなく、固定された勝ち数、引き分け数、負け数を尊重しながら、この「ポイント 2 倍」条件がトリガーされる頻度を最大化または最小化する順序で結果を配置することです。 

入力は 3 つの整数 a、b、c で​​構成され、シーケンス全体で何回勝ち、引き分け、負けが発生したかを表します。 これらの結果のすべての順列を考慮し、ルールに基づいて可能な最小および最大の合計スコアを計算する必要があります。 

この制約では最大 10^9 の値が許可されており、シーケンスを明示的にシミュレートしようとするアプローチは即座に除外されます。 関心のある状態は、シーケンス自体ではなく、「WW」パターンを何回形成できるか、そしてそれらが周囲のゲームとどのように相互作用するかです。 

クラスター勝利時に微妙な問題が発生します。 WWWWW のようなシーケンスでは、連続勝利の重複するペアが多数生成されるため、将来のスコアを 2 倍にする機会が数多く生まれます。 ただし、勝利ブロック内または勝利ブロックの後に引き分けまたは負けを配置すると、これらのボーナス トリガーが非明確な方法で「消費」または「保存」される可能性があります。 

重要なエッジケースは極端な分布から生じます。 

a = 0 の場合、勝ちは存在しないため、2 倍ルールは有効になりず、答えは固定されます。 たとえば、0 3 2 は常に 3 ポイントを与えます。 

b = 0 および c = 0 の場合、すべてのゲームが勝ちとなり、構造は連続する WW ペアが存在する最大数によって完全に制御されます。 

勝利が非勝利によって分離されている場合、倍増ルールはまったく有効になりません。 

これらの観察は、問題が勝ちをブロックに配置し、どれだけの「ボーナスアクティベーション」を作成できるかを推論することにあることをすでに示唆しています。 

## アプローチ

 ブルートフォース手法では、a 勝ち、b 引き分け、c 敗を含むマルチセットのすべての順列が生成されます。 順列ごとに、前の 2 つの試合が勝利したかどうかを追跡するブール値またはカウンターを維持しながら、スコアリング プロセスを順番にシミュレートします。 各シミュレーションには O(a + b + c) がかかりますが、順列の数は天文学的に多く、全長のおよそ階乗になります。 これは、たとえ小さな入力であっても完全に実行不可能です。 

重要な観察は、将来のボーナスを生み出すには勝利のみが重要であるということです。 引き分けや負けは「WW」状態の形成に寄与することはありませんが、勝利の連鎖を中断する可能性があるため、ボーナスチャンスがどれだけ存在するかを制御します。 これにより、勝利をグループ化する方法を制御するという問題が軽減されます。 

勝利が非勝利によって分離された k ブロックに分割される場合、長さ L の各ブロックは (L − 1) 個の隣接する WW ペアに寄与します。 これらのペアにより、将来何倍のポイントをトリガーできるかが決まります。 引き分けと負けの構造は、勝利ブロックを分離するかどうかによってのみ重要であり、両方とも倍増条件に関して同じように動作する (両方ともチェーンを切断する) ため、セパレーターとしては合計数のみが重要になります。 

これは核心的な洞察につながります。最大のスコアを得るには、後の勝利と未勝利が多くのアクティブな WW 状態から恩恵を受けるように、早い段階で連続勝利の数を最大化したいと考えています。 最小スコアを得るために、勝利を分散させることで WW 連鎖を可能な限り防ぎたいと考えています。

したがって、問題は、最適かつ悲観的な配置の下でどれだけ多くのボーナス「ダブルステート」をアクティブにできるかを計算することに帰着します。これは、非勝利によって分離された勝利のブロックに対する貪欲な構築になります。

 | ブルートフォース順列 | O((a+b+c)!) | O(a+b+c) | 遅すぎる |
 | ブロック構築+欲張りアレンジ | O(a + b + c) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 連続した勝利のみが将来のスコアに影響を与えるため、勝利を「状態の蓄積」の唯一のソースとして扱います。 

### 最大スコアの構築

 1. すべての勝利をできるだけ早く 1 つの連続したブロックに配置します。 

これにより、ブロック内の WW ペアの数が最大化され、倍加条件ができるだけ早くアクティブになることが保証されます。 
2. 長さ a のブロック内に、いくつの WW ペアが存在するかを計算します。 

隣接する勝ちのペアはすべて 1 つの潜在的なアクティベーションに寄与するため、これは - 1 です。 
3. チェーンがアクティブになると、最初の 2 回の勝利以降のすべてのゲームは、アクティブ化ポイント後に発生した引き分けや負けを含め、倍増の恩恵を受けます。 
4. すべての引き分けと負けを勝利ブロックの後に配置して、倍増状態の影響を受ける引き分けと負けの数を最大化します。 
5. 基本スコアに 2 倍のフェーズからの追加の寄与を加えた合計スコアを計算します。 

### 最小スコアの構築

 1. 引き分けと負けを使用して、勝ちをできるだけ分けます。 

それぞれの孤立した勝利により WW ペアの形成が回避され、アクティブ化が完全に妨げられるか、大幅に遅延します。 
2. 引き分けと負けの両方で連勝記録が途切れるため、セパレータがなくなるまでそれらを使用して勝利を 1 つずつ分離します。 
3. すべての勝利が分離された後にセパレーターが残っている場合は、それ以上減らすことはできないため、セパレーターを任意に配置します。 
4. a ≥ 2 および区切り文字が不十分な避けられない場合を除き、2 倍化の最小またはゼロの活性化を仮定してスコアを計算します。 

### なぜ効果があるのか

 システムには、前の 2 つのゲームが勝利したかどうかという 1 つのメモリ状態があります。 これは、シーケンスのすべての複雑さは、連続勝利を生み出すかどうか、そしてそれをどれだけ長く維持できるかにかかってくることを意味します。 したがって、最適な配置では、WW 遷移の数を最大化または最小化する必要があります。 引き分けと負けは連鎖を断ち切る上で対称的であり、勝ちが連鎖を構築する唯一のプラスの要因であるため、問題は勝ちの隣接性の制御に帰着します。 シーケンスの他の構造的プロパティはステート マシンに影響を与えることができないため、貪欲なグループ化で十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a, b, c = map(int, input().split())

    total = a + b + c

    # Base score without doubling
    base = 2 * a + b

    if a == 0:
        print(base, base)
        return

    # Maximum: make all wins consecutive to maximize WW chains
    # Once we have at least 2 consecutive wins, future games can be doubled.
    max_score = base

    if a >= 2:
        # First two wins are normal: 2 + 2
        max_score = 4

        remaining = total - 2

        # After WW is formed, every next game is doubled
        # Each win contributes 4 instead of 2, draw 2 instead of 1, loss 0 instead of 0
        # So each remaining win adds +2 extra, each draw adds +1 extra
        max_score += 2 * (a - 2) + 1 * b

    print(base, max_score)

if __name__ == "__main__":
    solve()
```この実装では、自明な基本スコアが 2 倍ルールの影響から分離されます。 基本スコアは 2 倍化が起こらないと仮定しており、単純に 2a + b です。 

最大の場合、コードは 2 回連続の勝利をできるだけ早く作成することを強制します。 それが発生すると、その後のすべてのゲームで「ダブリング モード」がアクティブになったものとみなされます。 最初の 2 回の勝利は通常のスコアで固定され、合計 4 ポイントに貢献します。 残りの勝利ごとに 2 ではなく 4 が追加され、それぞれ +2 が追加されます。 すべてのドローは 1 ではなく 2 を貢献し、それぞれ追加の +1 を与えます。 どちらのモードでも損失は何も寄与しないため、デルタには影響しません。 

最小のケースはベースと一致します。これは、倍増には少なくとも 2 回の連続勝利が必要であり、最悪の配置では勝利が可能な限り分離されると想定するためです。

 ## 特殊なケース

 a = 0 の場合、勝ちはないため、WW 条件は決して true にはなりません。 寄与ポイントを描画するだけなので、アルゴリズムはすぐにbase = bに戻ります。 

a = 1 の場合、引き分けや負けが多くても、どの配置でも 2 連勝を形成することはできません。 2 倍化状態には到達できないため、両方の答えが基本スコアに崩壊します。 

a ≥ 2 であるが b + c が大きい場合、最小の場合でも勝利は分離され、早期のアクティブ化が妨げられますが、最大の場合では 2 つの勝利の直接の隣接が強制され、残りのすべての一致に対してチェーンがアクティブに保たれます。
