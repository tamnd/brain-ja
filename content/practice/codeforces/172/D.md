 ## 解決策
 ## 問題の理解

 ベルランドの毎年の日数は決まっています。 最初の年は`a`数日、次は`a + 1`、など`n`連続した年。 

一緒に一年間`x`日の場合、政府は 2 つの条件を満たす月の長さを選択します。 まず、月の長さは完全な正方形でなければなりません。 第二に、分割する必要があります`x`まさにそのため、月数は整数になります。 そのようなすべての選択肢の中で、彼らは可能な限り長い月の長さを選択します。 

選択した月の長さが`d²`、その年の月数は次のようになります。`x / d²`。 毎月 1 枚の紙が必要なので、答えに対するその年の貢献度は正確に次のようになります。$$\frac{x}{\text{largest square divisor of }x}$$すべての年にわたるシートの総数を次から計算する必要があります。`a`に`a + n - 1`。 

制約は大きいです。 両方`a`そして`n`到達できる`10^7`、間隔の長さも次のようになります。`10^7`。 試行除算を使用してすべての数値を独立して因数分解するソリューションは、おおよそ次のように実行されます。$$10^7 \cdot \sqrt{10^7}$$制限時間を大幅に超えた最悪の場合の作戦。 

重要な課題は、連続する膨大な範囲の整数の二乗の約数に関する情報が必要であることです。 これは、数値を 1 つずつ処理するのではなく、ふるいのような方法で前処理することを強く示唆しています。 

ここには簡単な間違いがいくつかあります。 

よくある間違った考え方は、年の長さ以下の最大の完全平方を使用することです。 正方形は年を正確に分割する必要があるため、これでは十分ではありません。 

たとえば:

 入力:```
10 1
```一年は10日あります。 10 を超えない最大の正方形は 9 ですが、9 は 10 を割りません。正しい平方の約数は 1 なので、答えは次のようになります。```
10
```もう 1 つの微妙なケースは、年自体が完全な正方形である場合です。 

入力：```
36 1
```最大の平方約数は 36 自体であるため、1 年には 1 か月しか含まれず、以下の影響を受けます。```
1
```適切な約数のみを検索する不注意な実装では、代わりに誤って 4 または 9 が返されます。 

素数も重要なエッジケースです。 

入力：```
13 1
```唯一の二乗の約数は 1 であるため、寄与は次のようになります。```
13
```すべての数値がより大きな二乗除数を持っていると実装が想定している場合、ここで失敗します。 

## アプローチ

 直接的なブルートフォースの解決策は簡単です。 一年の長さごとに`x`、すべての整数を列挙します`d`そのような`d² ≤ x`。 いつでも`d²`分割する`x`、最適な平方約数を更新します。 最後に追加します`x / best`答えに。 

定義が明示的であるため、これは機能します。 考えられるすべての平方約数を単純にテストし、最大の有効な約数を保持します。 

問題は走行時間です。 最大 1 つの数字`10^7`大まかなチェックが必要`√10^7 ≈ 3162`候補者たち。 これを最大で行う`10^7`年間で数百億回の操作が行われます。 

繰り返しの除数検索を避ける必要があります。 

重要な観察は、実際に必要な量は次のとおりであるということです。$$\frac{x}{\text{largest square divisor of }x}$$この値には、数論におけるよく知られた解釈があります。 因数分解すると:$$x = p_1^{e_1} p_2^{e_2} \cdots p_k^{e_k}$$次に、最大の平方約数によって指数のすべての偶数部分が削除されます。 残りの値は次のとおりです。$$p_1^{e_1 \bmod 2} p_2^{e_2 \bmod 2} \cdots p_k^{e_k \bmod 2}$$これは、正方形のないカーネルと呼ばれます。`x`。 

例えば：$$108 = 2^2 \cdot 3^3$$最大の平方約数は次のとおりです。$$2^2 \cdot 3^2 = 36$$残りの要素は次のとおりです。$$3$$つまり、年は 3 枚のシートに貢献します。 

今では問題はずっと簡単になります。 最大範囲のすべての数値に対して平方フリー カーネルのみが必要です。`10^7`。 

これはふるいを使用すると効率的に計算できます。 

から始める`f[i] = i`。 すべての素数について`p`、 分ける`f[j]`による`p²`すべての倍数に対して繰り返し`j`の`p²`。 すべての素数を処理した後、`f[x]`はまさに次の正方形のないカーネルになります。`x`。 

全体の複雑さは調和ふるいの複雑さに近く、制限内に簡単に収まります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n\sqrt{A})$|$O(1)$| 遅すぎる |
 | 最適 |$O(M \log \log M)$|$O(M)$| 承認済み |

 ここ、`M = a + n - 1`。 

## アルゴリズムのチュートリアル

 1.読む`a`そして`n`、定義します`m = a + n - 1`、処理する必要がある最大の年の長さ。 
2. 配列を作成する`f`最初はどこで`f[i] = i`あらゆる人にとって`1 ≤ i ≤ m`。 

開始時に、すべての数値はそれ自体の正方形のないカーネルであると想定されます。 
3. ふるいを構築して、以下の素数を特定します。`√m`。 

正方形が範囲内に収まる素数のみを考慮します。 
4. 素数ごとに`p`、計算する`sq = p * p`。 
5. すべての倍数を反復処理します。`sq`。 

すべての倍数には少なくとも 1 つの因数が含まれます`p²`したがって、平方フリーのカーネルにはその平方係数が含まれるべきではありません。 
6. 現在値が次の値で割り切れる間、`sq`で割ります`sq`。 

数値には次のような高次の累乗が含まれる可能性があるため、割り算を繰り返すことが重要です。`p⁴`または`p⁶`。 
7. すべての素数を処理した後、`f[x]`の平方フリーカーネルに等しい`x`。 
8.合計`f[x]`何年もの間`x`から`a`に`m`。 
9. 合計を出力します。 

### なぜ効果があるのか

 すべての整数は一意に素因数分解できます。 仮定する：$$x = \prod p_i^{e_i}$$最大の平方約数は、指数からすべての偶数寄与を削除します。$$\prod p_i^{2\lfloor e_i/2 \rfloor}$$分割する`x`この量により、次のものが残ります。$$\prod p_i^{e_i \bmod 2}$$これはまさに正方形のないカーネルです。 

ふるいはすべての素数正方形を処理します`p²`影響を受けるすべての番号から繰り返し削除します。 このようなすべての削除の後、残りのすべての素数指数は 0 または 1 のいずれかになり、結果は平方フリーになることを意味します。 すべての二乗因数が削除され、二乗因数のみが削除されたため、最終値は正確にその年の必要な貢献度になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a, n = map(int, input().split())

    m = a + n - 1

    # f[x] will become the square-free kernel of x
    f = list(range(m + 1))

    # sieve for primes
    is_prime = [True] * (m + 1)
    is_prime[0] = is_prime[1] = False

    p = 2
    while p * p <= m:
        if is_prime[p]:
            # remove p^2 factors from all multiples
            sq = p * p

            for x in range(sq, m + 1, sq):
                while f[x] % sq == 0:
                    f[x] //= sq

            # mark composite numbers
            for multiple in range(p * p, m + 1, p):
                is_prime[multiple] = False

        p += 1

    ans = 0
    for x in range(a, m + 1):
        ans += f[x]

    print(ans)

solve()
```配列`f`ID マッピングとして開始されるため、`f[x] = x`。 ふるいにかけると、正方形のない部分だけが残るまで、各エントリから平方係数が削除されます。 

繰り返しの分割ループが不可欠です。 仮定する`x = 144 = 2^4 * 3^2`。 削除中`2²`1 回だけでは、別の二乗係数が残ります。$$144 \to 36$$しかし、36にはまだ含まれています`2²`。 ループは、因子が完全に消えるまで継続します。 

プライムシーブと角取りプロセスが 1 回の走査で組み合わされます。 この実装では、標準のエラトステネスのふるいとまったく同じように複合材料にマークが付けられます。 

答えは大きくなる可能性があり、次のようなものになる可能性があります。$$10^7 \cdot 10^7$$したがって、Python の整数が必要です。 Python はこれを自動的に処理します。 

配列にはおおよその内容が含まれているため、メモリ使用量は許容範囲内です。`10^7`それぞれの要素は、PyPy のコンテスト制限内に収まります。

import sys
import io

def solve():
    input = sys.stdin.readline

    a, n = map(int, input().split())

    m = a + n - 1

    f = list(range(m + 1))

    is_prime = [True] * (m + 1)
    is_prime[0] = is_prime[1] = False

    p = 2
    while p * p <= m:
        if is_prime[p]:
            sq = p * p

            for x in range(sq, m + 1, sq):
                while f[x] % sq == 0:
                    f[x] //= sq

            for multiple in range(p * p, m + 1, p):
                is_prime[multiple] = False

        p += 1

    ans = sum(f[a:m + 1])
    print(ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.strip()

 ## 特殊なケース

 次の入力を考えてみましょう。```
13 1
```13という数字は素数です。 平方係数が存在しないため、ふるいでは平方係数が削除されることはありません。 保存された値はそのまま残ります。$$f[13] = 13$$アルゴリズムは 13 を出力します。これは、二乗の除数が 1 だけであるため、正しいものです。 

次に、次のことを考えてみましょう。```
36 1
```最初に:$$f[36] = 36$$加工時`2² = 4`、アルゴリズムは繰り返し除算します。$$36 \to 9$$加工時`3² = 9`、再び分割します。$$9 \to 1$$最終的な拠出額は 1 で、これは 1 か月の 36 日を意味します。 

より微妙な例は次のとおりです。```
72 1
```因数分解:$$72 = 2^3 \cdot 3^2$$最大の平方約数は次のとおりです。$$2^2 \cdot 3^2 = 36$$したがって、答えは次のようになります。$$72 / 36 = 2$$ふるいは取り除く`2²`一度：$$72 \to 18$$その後削除します`3²`一度：$$18 \to 2$$残りの値はまさに正方形のないカーネルです。 

最後に、二乗べき乗がより大きい数を考えてみましょう。```
144 1
```因数分解:$$144 = 2^4 \cdot 3^2$$繰り返される除算ループにより、`2²`2回:$$144 \to 36 \to 9$$その後削除します`3²`:$$9 \to 1$$除算を繰り返さないと、アルゴリズムは 1 ではなく 9 で誤って停止します。
