 ## 解決策
 ## 問題の理解

 古典的な擬似乱数列の公式である線形合同生成器が与えられています。$$r_i = (a \cdot r_{i-1} + b) \bmod m$$シーケンスは次から始まります`r0`、次のすべての値は前の値から計算されます。 すべての値は剰余として取得されるため、`m`、あるだけです`m`考えられる状態:`0`を通して`m - 1`。 

タスクは、シーケンスが最初に繰り返されるタイミングを見つけることではありません。 特に、最終的に現れる繰り返しサイクルの長さが必要です。 シーケンスには、サイクルに入る前に非反復プレフィックスが含まれる場合があります。 

たとえば、次のようになります。```
a = 2
b = 6
m = 12
r0 = 11
```シーケンスは次のようになります。```
11 -> 4 -> 2 -> 10 -> 2 -> 10 -> ...
```値`11`は一度だけ出現します。 その後、シーケンスは次のように永遠に切り替わります。`2`そして`10`したがって、期間は`2`。 

制約`m ≤ 100000`が重要な観察です。 生成されるすべての値は次の範囲にあるため、`0`そして`m - 1`、シーケンスは最大で訪問できます`m`ある値が繰り返される前の個別の状態。 これにより、無限の探査に関する懸念は即座に排除されます。 たとえ`O(m)`または`O(m log m)`ソリューションは簡単に制限内に収まります。 

すべての位置のペアを比較する単純なアプローチでは、二次関数になります。 と`m = 100000`、`O(m²)`アルゴリズムには次のものが必要になる可能性があります`10^10`制限時間をはるかに超えた作戦。 

難しいのは、前周期と実際の周期を区別することです。 

次の入力を考えてみましょう。```
0 0 10 7
```順序は次のとおりです。```
7 -> 0 -> 0 -> 0 -> ...
```正しい答えは、`1`、 ない`2`。 任意の値の最初の出現と 2 番目の出現の間の距離を測定する不注意な実装では、プリピリオドの一部が誤ってカウントされる可能性があります。 

もう 1 つの微妙なケースは、サイクルがすぐに始まる場合です。```
1 1 5 0
```シーケンスは次のようになります。```
0 -> 1 -> 2 -> 3 -> 4 -> 0 -> ...
```シーケンス全体は最初から循環しているため、答えは次のようになります。`5`。 

3 番目のエッジ ケースは、シーケンスが固定点に到達したときに発生します。```
5 3 100 15
```最終的にシーケンスが次のようになると仮定します。```
78 -> 78 -> 78 -> ...
```期間はまだです`1`1 つの値が永久に繰り返されるためです。 

## アプローチ

 ブルートフォースのアイデアは単純です。 シーケンスを段階的に生成し、生成されたすべての値を保存します。 値が再び出現するたびに、将来の要素を比較してサイクル長を決定しようとします。 

これが機能するのは、シーケンスが決定的であるためです。 以前の状態に戻ると、その時点以降はすべて同じように繰り返されます。 問題は効率です。 候補期間を検証するために大きな接尾辞を繰り返し比較すると、最悪の場合の複雑さは二次関数になります。 

重要な観察は、ジェネレーターが、すべてのノードが出力エッジを 1 つだけ持つ有向グラフのように動作することです。 どの状態であっても、次の状態は 1 つだけ存在します。 このようなグラフは常に、サイクルに至るパスで構成されます。 

しかないので、`m`考えられる状態では、最初に繰り返された値によってサイクルの開始がすぐに識別されます。 

値を仮定する`x`の位置に最初に表示されます`p`、その後、 の位置に再び表示されます`q`。 

遷移関数は決定論的であるため、次のようになります。```
next(x) is always the same
```位置の後の接尾辞全体`p`位置の後の接尾辞と一致する必要があります`q`。 つまり、サイクルの長さは単純に次のようになります。```
q - p
```したがって、シーケンス全体を保存して比較を実行する代わりに、各値が出現した最初の位置を覚えておくだけで済みます。 

アルゴリズムは次のようになります。 

1. 値を 1 つずつ生成します。 
2. 各値が出現する最初のインデックスを保存します。 
3. 値が繰り返される場合、現在のインデックスと最初に出現したインデックスの差を返します。 

各状態は反復前に最大 1 回処理されるため、アルゴリズムは線形時間で実行されます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(㎡) | O(m) | 遅すぎる |
 | 最適 | O(m) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`a`、`b`、`m`、 そして`r0`。 
2. 辞書または配列を作成する`first_seen`各値が出現する最初のインデックスを格納します。 
3. 開始値をマークします`r0`位置で見ると`0`。 
4. 以下を使用して次の値を繰り返し生成します。$$r = (a \cdot r + b) \bmod m$$5. 新しい値を生成するたびに、現在位置カウンターを増加させます。 
6. 新しい値が以前に出現したかどうかを確認します。 
7. 値が新しい場合は、その最初の出現位置を保存して続行します。 
8. 値が既にその位置に現れている場合`p`、シーケンスはサイクルに入りました。 サイクルの長さは次のとおりです。$$\text{current position} - p$$9. その長さを出力して停止します。 

### なぜ効果があるのか

 シーケンスは現在の値によって完全に決定されます。 何らかの価値がある場合`x`2 つの異なる位置に出現した場合、両方の位置からの将来の進化は同一でなければなりません。 

仮定する：```
r_p = r_q
```と`p < q`。 

それから：```
r_{p+1} = r_{q+1}
r_{p+2} = r_{q+2}
...
```どちらの位置でも同じ値に同じ遷移式が適用されるためです。 

つまり、シーケンスは毎回繰り返されます。`q - p`位置から始まるステップ`p`。 最初に繰り返された値で停止するため、この差が最小有効期間になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

a, b, m, r = map(int, input().split())

first_seen = [-1] * m
first_seen[r] = 0

pos = 0

while True:
    r = (a * r + b) % m
    pos += 1

    if first_seen[r] != -1:
        print(pos - first_seen[r])
        break

    first_seen[r] = pos
```配列`first_seen`各剰余が現れる最初の位置を保存します。 すべての値が範囲内にあるため、`[0, m - 1]`、配列を使用する方が、辞書を使用するよりも高速かつ簡単です。 

変数`pos`シーケンス内の現在の値のインデックスを表します。 から始めます`r0`位置にある`0`。 

ループ内で、最初に次の値を生成し、次に位置をインクリメントします。 順序が重要です。 次の状態を生成する前にインクリメントすると、格納されたインデックスが誤ってシフトし、サイクル長に 1 つずれたエラーが発生します。 

以前に見た値に遭遇した瞬間に、その最初の出現位置を現在の位置から減算します。 その違いはまさに周期の長さです。 

のみであるため、ループは終了することが保証されています。`m`異なる州。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    a, b, m, r = map(int, input().split())

    first_seen = [-1] * m
    first_seen[r] = 0

    pos = 0

    while True:
        r = (a * r + b) % m
        pos += 1

        if first_seen[r] != -1:
            print(pos - first_seen[r])
            return

        first_seen[r] = pos

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output.strip()

# provided sample
assert run("2 6 12 11\n") == "2", "sample 1"

# minimum-size input
assert run("0 0 1 0\n") == "1", "single state"

# cycle starts immediately
assert run("1 1 5 0\n") == "5", "full modulo cycle"

# fixed point after one step
assert run("0 0 10 7\n") == "1", "constant sequence"

# off-by-one detection
assert run("2 0 7 1\n") == "3", "cycle length should be 3"
