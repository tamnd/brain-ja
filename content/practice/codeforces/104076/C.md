 しましょう$\tau$～の真理表になる$f(x_1,\ldots,x_n)$、そしてさせてください$f^Z$真理値表が次のようなブール関数になります。$\tau^Z$、 どこ$\tau^Z$は演習 192 の再帰 Z 変換によって定義されます。 

しましょう$S_k(x_1,\ldots,x_n)$の副次関数を示します$f$固定して得られる$x_1=\cdots=x_k=1$残りの変数は自由なままにしておくため、その真理値表は次のようになります。$2^{n-k}$のサブテーブル$\tau$割り当てによってインデックス付けされたサフィックスに対応する$(1,\ldots,1, x_{k+1},\ldots,x_n)$。 させて$S_k^Z$の類似のサブ関数を示します$f^Z$。 

目標は、次の関係を特定することです。$S_k^Z$そして$S_k$。 

Z 変換は文字列の再帰的分解によって定義されます。$\alpha\beta$かどうかに応じて$\beta$はゼロブロックであり、次と等しい$\alpha$、または一般的な連結の場合。 3 つの句すべてを通じて保持される唯一の構造は、等しい長さの半分への再帰的分割と、繰り返されるブロックまたはゼロ ブロックの認識です。 これは、変換が次のバイナリ分解ツリーに対してレベルごとに作用することを意味します。$\tau$。 

深さで$k$真理値表分解では、文字列$\tau$に分割されています$2^k$順序のサブテーブル$n-k$、それぞれ最初の修正に対応します。$k$変数。 Z 変換は、これらのサブテーブルのインデックス付けを変更しません。 各サブテーブルを置き換えるだけです$\sigma$による$\sigma^Z$そして場合によっては、重複または構造化されたペアを正規のゼロまたは繰り返しブロックに置き換えます。 

したがって、すべてのサブテーブル定義は$S_k$対応するサブテーブル定義に独立して変換されます。$S_k^Z$。 特に、制限操作「最初の部分を固定する」$k$「変数」は真理値表の Z 変換と互換性があります。 

正式には、$\tau_{x_1=\cdots=x_k=1}$サブテーブル定義のサフィックスを示します$S_k$、の再帰的定義$\tau^Z$収量$$(\tau_{x_1=\cdots=x_k=1})^Z = (\tau^Z)_{x_1=\cdots=x_k=1}.$$したがって、次の真理表は、$S_k^Z$まさに$(\tau_{x_1=\cdots=x_k=1})^Z$これは、サブ関数自体が、サブ関数に Z 変換を適用することによって取得されることを意味します。$S_k$。 

したがって、すべての$k$と$0 \le k \le n$、$$S_k^Z(x_1,\ldots,x_n) = (S_k(x_1,\ldots,x_n))^Z.$$制限が定義されているため、$S_k$自由変数の数を減らす$n-k$、この恒等式はプロファイル分解のすべてのレベルにわたって均一に保持され、BDD プロファイル内のサブ関数間の対応関係が保存されます。$f$と ZDD スタイルのプロファイル$f^Z$演習 192 で確立されます。 

したがって、$$\boxed{S_k^Z = (S_k)^Z \quad \text{for } 0 \le k \le n.}$$これで証明は完了です。 ∎
