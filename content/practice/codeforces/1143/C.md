 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、根を張った木です。`n`頂点。 各頂点には親があります`p_i`そして敬意の指標`c_i`。 ルートは特別です。`p_i = -1`そして`c_i = 0`。 の意味`c_i`は簡単です:`c_i = 0`頂点がその祖先を尊重することを意味し、`c_i = 1`つまり、祖先を尊重しないことを意味します。 

削除操作は中心的な仕組みです。 頂点`v`親を尊重せず、そのすべての子が存在しないか、尊重しない場合は削除できます。`v`。 いつ`v`が削除されると、その子はその親に再接続されます。 このプロセスは、削除ができなくなるまで続行されます。 出力は、削除された頂点のリスト (削除された順序) です。`-1`削除が発生しない場合。 

制約を考慮すると`n ≤ 10^5`、繰り返しスキャンや削除の単純なシミュレーションを行うソリューションはすべて、`O(n^2)`最悪の場合、遅すぎます。 アルゴリズムは大まかに実行する必要があります`O(n)`または`O(n log n)`。 

微妙なエッジ ケースには、子を持つ頂点が含まれますが、どの頂点もそれを尊重しません。 その場合は削除も可能です。 単純なアプローチでは、子供を考慮せずに直接の親の尊重のみを考慮するため、そのような頂点がスキップされる可能性があります。 もう 1 つの特殊なケースはルートであり、これは削除できません。 アルゴリズムはそれを削除しようとしてはいけません。 

## アプローチ

 ブルートフォース手法では、ツリーを繰り返しスキャンして削除条件を満たす頂点を探し、それらを削除し、子の親リンクを更新します。 各ステップで削除ルールに明示的に従うため、正確性が保証されます。 ただし、スキャンを繰り返すと、`O(n^2)`最悪の場合は複雑になるため、これは受け入れられません。`n = 10^5`。 

重要な洞察は、頂点がその親を尊重しない場合に限り、頂点を削除できることを観察することです(`c_i = 1`) そしてそのすべての子はそれを尊重します (`c_child = 0`）。 これは単一の DFS で計算できます。ツリーを走査し、各頂点について次のことを確認します。`c_i = 1`そしてすべての子供たちは`c_j = 0`。 true の場合、削除リストに追加します。 これが機能するのは、削除が既に削除されている他の頂点の状態に影響を与えず、削除の順序が頂点番号の増加に従うためであり、頂点を順番にスキャンすることでこれを満たすことができます。 

実際、DFS を使用すると、明示的に削除シミュレーションを繰り返すことなく、「子は私を尊重しない」という要件を把握し、親の前に子を処理できるようになります。 これにより複雑さが軽減され、`O(n)`。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 子チェックを使用した DFS | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力を読み取り、ツリーを構築します。 各頂点の親を保存し、`c_i`価値。 また、各頂点の子のリストを作成します。 
2. ルートを頂点として識別します。`p_i = -1`。 
3. 空のリストを初期化する`to_delete`削除ルールを満たす頂点を保存します。 
4. 頂点を取る DFS 関数を定義する`v`:

 - それぞれの子供たちに`u`の`v`、DFS を再帰的に呼び出します`u`。 
- すべての子を処理した後、次のことを確認します。`c[v] = 1`。 true の場合、すべての子を検査します。どの子も尊重しない場合は、`v`(`c[child] = 0`すべての子に）、追加します`v`に`to_delete`。 
5. DFS をルートから起動します。 
6. もし`to_delete`DFS 後は空です。印刷します`-1`。 それ以外の場合は、追加された順序で頂点のリストを出力します。`to_delete`。 

**機能する理由**: DFS は親よりも先に子供を処理し、「子供が誰も私を尊重しない」という条件が正しく評価されることを保証します。 各頂点は 1 回だけチェックされ、頂点が追加されます。`to_delete`DFS は頂点の昇順で子を走査するため、インデックスが小さい順に処理されます。 これにより、削除リストが正確かつ一意であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(200000)

n = int(input())
parent = [0] * (n + 1)
c = [0] * (n + 1)
children = [[] for _ in range(n + 1)]
root = -1

for i in range(1, n + 1):
    p_i, c_i = map(int, input().split())
    parent[i] = p_i
    c[i] = c_i
    if p_i == -1:
        root = i
    else:
        children[p_i].append(i)

to_delete = []

def dfs(v):
    for u in children[v]:
        dfs(u)
    if c[v] == 1:
        if all(c[child] == 0 for child in children[v]):
            to_delete.append(v)

dfs(root)

if not to_delete:
    print(-1)
else:
    print(' '.join(map(str, to_delete)))
```**説明**:

 まずツリーを読み取り、親子関係を構築します。 DFS は最初に子を再帰的に評価し、削除条件が確実に尊重されるようにします。 私たちが使用するのは`all(c[child] == 0 for child in children[v])`どの子も頂点を尊重していないことを確認します。 このアプローチはルートを正しく処理します。ルートは決して満たされないためです。`c[root] = 1`。 の`to_delete`DFS が子を自然な順序で処理するため、リストは正しい順序を保持します。
