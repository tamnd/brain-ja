 ## 問題の理解

 与えられた整数を見つけるように求められます$n$、1 から 1 までの数字の最大の積$n$持つことができる。 言い換えれば、1 から 2 までのすべての数値を反復処理することを想像してください。$n$各数値の桁を乗算します。 私たちはそのような製品を最大限に求めています。 

入力は単一の整数です$n$どこ$1 \le n \le 2 \cdot 10^9$。 この上限により、1 から 2 までのすべての数値を反復処理するとすぐにわかります。$n$これは実行不可能です。20 億回の操作が必要になる可能性があり、すべての数値をチェックするソリューションではタイムアウトが発生するからです。 

最適な数値の桁数が より小さい場合、明らかではないエッジ ケースが発生します。$n$自体。 たとえば、$n = 390$、最適な数は次のとおりです。$389$、 ない$390$最後の桁を 0 から 9 に変更すると、より大きな積が生成される可能性があるためです。 もう 1 つの注意を要するシナリオは次のような場合です。$n$ほとんどが 9 で構成されています。 それから$n$それ自体が最適である可能性があります。 ついに一桁に$n$値は些細なものですが、それでも正しく処理する必要があります。 

## アプローチ

 ブルート フォース ソリューションの説明は簡単です。1 から 2 までのすべての数値を反復処理します。$n$、その桁の積を計算し、最大値を追跡します。 すべての可能性を明示的にチェックするため、これは正しいです。 その複雑さは、$O(n \cdot d)$、 どこ$d$は現在の数値の桁数ですが、$d \approx 10$のために$n = 2 \cdot 10^9$が遅すぎるため、$n$それ自体が巨大です。 

より迅速なアプローチのための重要な洞察は、桁が減少したときに製品がどのように動作するかを観察することから得られます。 390 のような数値がある場合、桁の 1 つ (0 から 9) を下げ、後続のすべての桁を 9 に減らすと、積が増加することがよくあります。 これは、数字の 0 が製品を完全に破壊してしまうためです。 したがって、すべての数値をチェックするのではなく、次によって形成される数値のみをチェックする必要があります。 

1. のプレフィックスを保持する$n$同じ。 
2. 残りのサフィックスの最初の非ゼロ桁を 1 減算します。 
3. 後続の数字をすべて 9 に置き換えます。 

さらに、私たちは常に次のことを考慮する必要があります。$n$自体。 これにより、候補数が数十億から最大でも桁数に減ります。$n$プラス 1、つまり制約では最大 10 です。

 ## アルゴリズムのチュートリアル

 1.変換$n$文字列に$s$数字を個別に操作します。 
2.初期化`max_product`の桁の積として$n$自体。 これにより、常に考慮することが保証されます$n$候補として。 
3. 各桁位置を反復処理します。$i$で$s$:

 1. 位置の数字が$i$が 0 の場合、0 を減らすと負の数字または無効な数字が作成されるため、次の位置にスキップします。 
2. プレフィックスを次の値に維持して、新しい候補番号を構築します。$i-1$変わらない。 
3. の桁を減らします。$i$1までに。 
4. 後のすべての数字を置き換えます$i$9と。 
5. この候補の数字の積を計算し、更新します。`max_product`もっと大きい場合。 
4. 出力`max_product`。 

なぜ機能するのか: 不変条件は、以下の数値に対して$n$、最初のゼロ以外の桁を減らし、残りを 9 で埋めると、次を超えることなく積が最大化されます。$n$。 減少が発生する可能性のあるすべての位置をチェックすることで、最大の製品が見つかることを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def product_of_digits(num_str):
    prod = 1
    for ch in num_str:
        prod *= int(ch)
    return prod

def main():
    n = input().strip()
    max_prod = product_of_digits(n)
    
    n_list = list(n)
    for i in range(len(n_list)):
        if n_list[i] == '0':
            continue
        candidate = n_list[:i] + [str(int(n_list[i])-1)] + ['9'] * (len(n_list)-i-1)
        candidate_str = ''.join(candidate).lstrip('0')
        if candidate_str:
            max_prod = max(max_prod, product_of_digits(candidate_str))
    
    print(max_prod)

if __name__ == "__main__":
    main()
```このコードでは、まず、桁の積を計算するヘルパー関数を定義します。 次に、次のすべての桁を反復処理します。`n`、その数字を 1 減算し、残りを 9 で埋めて積を計算します。 先頭のゼロは数値に影響しないため、削除されます。 すべての候補の中から最大の積が出力されます。
