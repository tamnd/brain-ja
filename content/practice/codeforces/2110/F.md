 ## 解決策
 ## 問題の理解

 正の整数の配列が与えられ、配列の接頭辞ごとにその「美しさ」を計算するように求められます。 配列の美しさは関数の最大値として定義されます$f(x, y) = (x \bmod y) + (y \bmod x)$要素のすべてのペアにわたって$x, y$接頭辞で。 

入力は複数のテスト ケースで構成され、それぞれの長さは次のとおりです。$10^6$、すべてのテスト ケースの長さの合計も次によって制限されます。$10^6$。 これは、次のようなソリューションを意味します。$O(n^2)$テスト ケースごとの複雑さは実現不可能です。$10^{12}$最悪の場合の運用。 もっと近いものが必要です$O(n \log n)$または$O(n)$テストケースごとに。 

重要な微妙な点は、$f(x, y)$。 単一の要素の場合$x$、美しさはゼロなので$x \bmod x = 0$。 もう 1 つの重要な観察は、$f(x, y)$は常に未満です$\max(x, y)$、プレフィックス内の最大の要素が多くの場合、最大値を支配します。$f$。 注意すべきエッジケースには、要素が繰り返される配列、最大の要素が最初または最後に来る配列、サイズ 1 の配列などが含まれますが、これらは明らかに美しさ 0 になります。 

たとえば、配列`[5, 5]`美しさがある`0 + 0 = 0`、 そして`[5, 1]`美しさがある`(5 mod 1) + (1 mod 5) = 0 + 1 = 1`。 以前の最大値に対して新しい要素のみを考慮する不注意なアプローチでは、後で小さな要素が以前の大きな要素と合わせてより高い美しさを形成する場合を見逃す可能性があります。 

## アプローチ

 ブルートフォースメソッドは次のように計算します。$f(a_i, a_j)$すべてのプレフィックスのすべてのペアに対して。 これは定義が単純であるため機能しますが、各プレフィックスのすべてのペアを合計する必要があります。 長さの配列の場合$n$、つまり$O(n^2)$プレフィックスごとの操作、合計$O(n^3)$素朴に実装された場合。 明らかにこれでは遅すぎます$n \sim 10^6$。 

重要な洞察は機能の分析から得られます$f(x, y) = (x \bmod y) + (y \bmod x)$。 もし$x = y$、$f(x, x) = 0$。 もし$x > y$、 それから$x \bmod y < y$そして$y \bmod x = y$、与える$f(x, y) < 2y$。 したがって、最大値は通常、プレフィックス内の現在の最大の要素と、2 番目に大きい要素、またはそれよりわずかに小さい要素との間で達成されます。 

この観察により、プレフィックスを拡張するときに最大要素と 2 番目に最大の要素だけを維持することができます。 新しい要素ごとに、現在の最大および 2 番目に大きい要素と比較して、新しい美しさを計算します。 すべてのペアをチェックする必要はなく、時間の複雑さが軽減されます。$O(n^2)$に$O(n)$テストケースごとに。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 遅すぎる |
 | 上位 2 つの要素を維持する | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.初期化`max1 = 0`、`max2 = 0`、 そして`beauty = 0`。 これらはそれぞれ、最大の要素、2 番目に大きい要素、および現在の美しさを追跡します。 
2. 配列を反復処理する`a`。 要素ごとに`x`プレフィックス内:

 2.1 コンピューティング`f(x, max1)`そして`f(x, max2)`新たな美の可能性を見つけるために。 より小さい要素を含む他のペアはこれらの値を超えることができないため、これら 2 つの比較のみが必要です。 

2.2 アップデート`beauty`これらの値のいずれかが現在より大きい場合`beauty`。 

2.3 アップデート`max1`そして`max2`新しい要素に基づいて`x`。 もし`x`を超える`max1`、割り当てます`max2 = max1`そして`max1 = x`。 それ以外の場合は、`x > max2`、 アップデート`max2 = x`。 
3. 現在の値を追加します`beauty`このプレフィックスの出力配列に変換されます。 
4. 配列の最後まで繰り返します。 

ここでの不変条件は、`max1`そして`max2`これまでに確認された 2 つの最大の要素と現在の要素が常に保持されます。`beauty`は最大です$f(x, y)$現在のプレフィックスの場合。 最大関数値には常に最大の要素の 1 つが含まれるため、候補ペアを見逃すことはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        max1 = 0
        max2 = 0
        beauty = 0
        res = []
        for x in a:
            # Compute candidate f values
            if max1:
                beauty = max(beauty, (x % max1) + (max1 % x))
            if max2:
                beauty = max(beauty, (x % max2) + (max2 % x))
            # Update the top two elements
            if x > max1:
                max2 = max1
                max1 = x
            elif x > max2:
                max2 = x
            res.append(str(beauty))
        print(' '.join(res))

if __name__ == "__main__":
    main()
```コードは最大値と美しさを初期化し、配列を反復処理して、必要な値のみを計算します。`f`値を更新し、実行最大値を更新します。 更新の順番は`max1`そして`max2`値が時期尚早に上書きされることを避けるために重要です。 場合の対処方法`max1`または`max2`ゼロの場合、最初の要素で未定義のモジュロ演算がスキップされます。
