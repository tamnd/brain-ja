 ## 解決策
 ## 問題の理解

 一連の障害物を通過するドローン飛行を計画するように求められます。各障害物は許容される高さの範囲を定義します。 ドローンは高さ 0 から開始し、飛行プログラムは配列として定義されます。`d`, ここで、各要素は連続する障害物間でドローンがどれだけ上昇するかを表します。 各要素は 0、1、または不明 (`-1`）。 タスクは、未知の要素を埋めて、障害物の範囲を決して侵害しない有効な飛行経路を作成することです。 そのようなプログラムが存在しない場合は、報告します`-1`。 

入力は複数のテスト ケースを提供し、それぞれに多数の障害があります。`n`、現在の飛行プログラム`d`(可能性あり`-1`エントリ）、および障害物の範囲`[l_i, r_i]`。 出力は、動作する完全なプログラムを提供するか、または`-1`。 

制約は次のことを示します`n`最大 200,000 まで可能で、すべてのテスト ケースの合計も 200,000 になります。 これにより、以下よりも遅いアルゴリズムは禁止されます。`O(n)`テストケースごとに。 未知のすべての組み合わせを試すブルートフォースアプローチ`d_i`指数関数的であり、完全に実行不可能です。 の値`d_i`に限定されています`0`または`1`、これは貪欲な間隔追跡アプローチを示唆しています。 

明らかではないエッジケースには、既知の状況が含まれます。`d_i`すぐに障害物の範囲を侵害する、または未知の場所に侵入する`-1`エントリは、将来の障害の上限を超えないように慎重に設定する必要があります。 たとえば、次の場合`n=2`、`d=[-1,1]`、障害物の範囲は`[0,1]`そして`[1,1]`、最初の単純な割り当て`d_i=1`高みにつながるだろう`[0,1,2]`最後の障害を突破します。 正しい答えは、`d=[0,1]`。 

## アプローチ

 ブルートフォースアプローチでは、すべてが試行されます`2^k`未知の可能性`d_i`、 どこ`k`の数です`-1`s. 候補プログラムごとに累積高さを計算し、すべての制約を検証します。 中程度の場合でも`k`(例: 20)、これは次のようになります`O(2^k * n)`考えると遅すぎる`n`まで`2*10^5`。 

重要な洞察は、各ステップでドローンの高さを間隔として追跡できることを理解することです。`[min_height, max_height]`以前の未知の選択肢を与えられた場合に到達可能なすべての高さを表す`d_i`。 もし`d_i`がわかっている場合は、単に間隔をずらすだけです。 不明な場合は、次のいずれかを許可することで間隔が拡張されます。`0`または`1`。 次に、この間隔を障害物の許容高さ範囲と交差させます。 交差点が空いていたら無理です。 それ以外の場合は、貪欲に高さを選択できます (または`d_i`) 次の間隔を実行可能に保ちます。 これにより、問題は線形スキャンに帰着し、間隔を更新して未知の部分を埋めることになります。`d_i`ワンパスで。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^k * n) | O(n) | 遅すぎる |
 | インターバルトラッキング / 貪欲 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 現在の高さ間隔を次のように初期化します。`[0,0]`, ドローンは地上からスタートするので。 
2. それぞれを反復処理します。`i`から`0`に`n-1`。 
3. に基づいて間隔を更新します。`d[i]`。 もし`d[i]`がわかっている場合は、それを区間の両端に追加します。 不明な場合は、最大値を 1 増やしますが、最小値は変更しないでください。`d_i`0 または 1 のいずれかになります。 
4. 更新された間隔と障害物の許容範囲を交差させます。`[l_i, r_i]`。 交差点が空の場合、出力`-1`飛行機は無理だから。 
5. 決定する`d[i]`未知の人のために。 将来の可能性を有効に保つために、次のことを選択してください`d[i]=1`間隔の下限が後で`0`以下に落ちるだろう`l_i`; それ以外の場合は、選択してください`d[i]=0`。 
6. 現在の高さを、この障害物に対して選択した高さに更新します。 
7. すべての障害物が処理されるまで続行します。 塗りつぶされたものを出力します`d`配列。 

なぜ機能するのか: 各ステップでの間隔`[low, high]`過去の決定を考慮して到達可能なすべての高さを表します。 それと交差する`[l_i, r_i]`障害物が侵害されていないことを保証します。 有効な最小値の選択`d_i`次の間隔を実行可能に保つことで、将来のオプションを不必要に制限しないことが保証されます。 これは不変条件を維持します。つまり、間隔は常に既知の選択された到達可能な高さと一致することを表します。`d_i`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        d = list(map(int, input().split()))
        lr = [tuple(map(int, input().split())) for _ in range(n)]
        
        low = high = 0
        result = []
        possible = True
        
        for i in range(n):
            l, r = lr[i]
            if d[i] != -1:
                low += d[i]
                high += d[i]
            else:
                high += 1
            
            low = max(low, l)
            high = min(high, r)
            
            if low > high:
                possible = False
                break
            
            if d[i] == -1:
                if high > low:
                    d[i] = 1
                else:
                    d[i] = 0
                low = high = low + d[i] - (d[i] if d[i]==0 else 1) + d[i]  # keep bounds correct
            
        if possible:
            print(' '.join(map(str, d)))
        else:
            print(-1)

if __name__ == "__main__":
    solve()
```コードは間隔を維持します`[low, high]`説明したとおり。 いつ`d[i]`がわかっている場合は、間隔を正確にシフトします。 不明な場合、間隔は次のように増加する可能性があります`1`。 交差点により障害物の制約が確保されます。 選択する`d[i]`将来の間隔が引き続き実行可能であることを貪欲に保証します。
