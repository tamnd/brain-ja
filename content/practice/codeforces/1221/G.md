 ## 解決策
 ## 問題の理解

 無向グラフがあります。 すべての頂点は次のいずれかを割り当てる必要があります。`0`または`1`。 

各エッジについて、その 2 つの端点の値の合計を書き込みます。 エンドポイントはバイナリであるため、すべてのエッジは次の 3 つの可能な値のいずれかを受け取ります。 

-`0`両方のエンドポイントが`0`-`1`エンドポイントが異なる場合
 -`2`両方のエンドポイントが`1`3 つのエッジ値すべてを同時に生成する頂点の割り当ての数を数えなければなりません。 言い換えると、すべてのエッジの中に、次のラベルが付けられたエッジが少なくとも 1 つ存在する必要があります。`0`、少なくとも 1 つのエッジにラベルが付けられている`1`、およびラベルが付いた少なくとも 1 つのエッジ`2`。 

グラフには最大 40 個の頂点が含まれます。 この数は多くのグラフの問題に比べれば小さいですが、すべての割り当てを列挙するには多すぎます。 がある`2^40 ≈ 10^12`バイナリラベル付けも可能ですが、これは完全に不可能です。 

グラフは切り離すこともできます。 複数のコンポーネントが存在する場合、接続されたグラフでは不可能な一部の割り当てが可能になるため、これが重要な困難の 1 つであることがわかります。 

いくつかの特殊なケースは見落とされがちです。 

エッジのないグラフを考えてみましょう。```
3 0
```どのエッジもラベルを受け取ることはできません`0`、`1`、 または`2`、したがって、答えは次のとおりです`0`。 

単一のエッジを考えてみましょう。```
2 1
1 2
```可能なエッジラベルは次のとおりです。`0`、`1`、 または`2`, ただし、3つすべてを一度に行うことはできません。 答えはまた改めて`0`。 

もう 1 つの微妙なケースは、接続されていないグラフです。```
4 2
1 2
3 4
```割り当てによって完全に 1 つのコンポーネントが作成される場合があります`0`そしてまったく別の`1`。 このような割り当てにはエッジ ラベルが含まれます`0`そして`2`しかしエッジにラベルが付いていません`1`。 エッジについて局所的にのみ推論するカウント方法では、これらの構成を簡単に過剰にカウントする可能性があります。 

最も重要な特別な構造は二部構成です。 接続された 2 部コンポーネントでは、すべての割り当てでエッジ ラベルのみが生成されます。`1`2 つの二分割カラーリングのいずれかに正確に対応する必要があります。 この事実がカウントの大部分を左右します。 

## アプローチ

 ブルート フォース ソリューションでは、すべての頂点の割り当てが試行されます。 それぞれについて、`2^n`割り当てでは、すべてのエッジを検査し、エッジのラベルが付いているかどうかを確認します`0`、`1`、 そして`2`全部登場する。 

すべての割り当ては明示的にテストされるため、これは正しいです。 

残念ながら、いつ`n = 40`、おおよそ必要になります$$2^{40} \approx 1.1 \times 10^{12}$$課題。 エッジ処理を無視してもこれは絶望的です。 

重要な観察は、有効な割り当てを直接カウントするのは難しいが、無効な割り当てをカウントすることは驚くほど構造化されているということです。 

させて$$T = 2^n$$割り当ての合計数になります。 

少なくとも 1 つのエッジ ラベルが存在する場合、割り当ては無効です。`{0,1,2}`が欠けています。 

これは当然、包含と排除を示唆します。 

定義する：

-`A0`: ラベルの付いていないエッジの代入`0`-`A1`: ラベルの付いていないエッジの代入`1`-`A2`: ラベルの付いていないエッジの代入`2`そうすると答えは$$T-|A_0\cup A_1\cup A_2|.$$課題は、すべての包含語と除外語を数えることになります。 

グラフ構造により、これらのカウントが管理可能になります。 

ラベルの付いたエッジがない場合`0`の場合、割り当てられた 2 つの頂点をエッジが接続することはできません。`0`。 したがって、ゼロ値の頂点のセットは独立したセットでなければなりません。 

同様に、エッジのラベルが付いていない代入`2`割り当てられた頂点の独立したセットを選択することに正確に対応します`1`。 

したがって両方とも`|A0|`そして`|A2|`グラフの独立したセットの数に等しい。 

のために`n ≤ 40`、独立したセットのカウントは中間で行うことができます。 これは主要なアルゴリズム コンポーネントです。 

残りの包含-除外項は非常に簡単で、連結成分と二部成分を使用して表現できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n・m) | お(1) | 遅すぎる |
 | 最適 | O(2^(n/2) · n) | O(2^(n/2)) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 包含/除外の設定

 しましょう:

 -`I`= 独立集合の数
 -`cc`= 接続されたコンポーネントの数
 -`bip`= 接続された 2 部構成要素の数

 すべての割り当てから始めます。$$2^n.$$少なくとも 1 つのエッジ ラベルが欠落している割り当てを減算し、包含/除外に従って交差部分を追加し直します。 

### 数える`A0`そして`A2`

`A0`ラベルの付いていないエッジの割り当てで構成されます`0`。 

割り当てられたすべての頂点`0`独立した集合を形成しなければなりません。 

ゼロ頂点を選択すると、割り当てが完全に決まります。 

したがって、$$|A_0| = I.$$対称性により、$$|A_2| = I.$$### 数える`A1`エッジがラベルを受け取ります`1`まさにそのエンドポイントが異なる場合。 

ラベルの付いたエッジがない場合`1`、すべてのエッジが等しい値を結合します。 

各接続コンポーネント内では、すべての頂点が同じ値を持つ必要があります。 

各接続コンポーネントは独立して選択します`0`または`1`。 

したがって$$|A_1| = 2^{cc}.$$### 数える`A0 ∩ A1`エッジにラベルを付けることはできません`0`または`1`。 

したがって、すべてのエッジにラベルが必要です`2`。 

すべての接続されたコンポーネントの内部では、すべての頂点が次のとおりである必要があります。`1`。 

孤立した各頂点は引き続き自由に選択できます。 

このカウントは以下に等しい$$2^{iso},$$どこ`iso`孤立した頂点の数です。 

同じ値が表示されます`A1 ∩ A2`。 

### 数える`A0 ∩ A2`エッジにラベルを付けることはできません`0`または`2`。 

すべてのエッジにラベルが必要です`1`。 

すべてのエッジの端点は反対の値を持つ必要があります。 

したがって、接続された各コンポーネントは 2 部構成でなければなりません。 

接続された 2 部コンポーネントには、正確に 2 つの有効なカラーリングがあります。 

非 2 部構成要素の寄与はゼロです。 

非分離コンポーネントが 2 部構成でない場合、カウントは 0 になります。 

さもないと、$$|A_0 \cap A_2| = 2^{bip}.$$### 数える`A0 ∩ A1 ∩ A2`エッジにはラベルをまったく付けることはできません。 

これは、グラフにエッジがない場合にのみ可能です。 

包含と除外の場合は、単純に次のようになります。$$2^{iso}.$$### 独立したセットのカウント

 残りの難しい部分はコンピューティングです`I`。 

頂点を 2 つに分割します。$$L,\ R$$サイズは最大20まで。 

左半分のすべてのサブセットについて、それが独立しているかどうかを確認します。 

どの右半分の頂点を選択できるかを示すビットマスクを保存します。 

右半分の独立したサブセットごとに、互換性のある左半分のサブセットがいくつ存在するかを数えます。 

これは、標準的な中間集合独立セット計数手法です。 

互換性カウントは、右半分のマスクに対するサブセット ゼータ変換を使用して累積されます。 

### アルゴリズムのチュートリアル

 1. グラフを読み取り、隣接ビットマスクを構築します。 
2. 接続されたコンポーネント、孤立した頂点、および各コンポーネントが 2 部構成であるかどうかを計算します。 
3. 中間集合を使用して、すべての独立したセットをカウントします。 
4. しましょう`ans = 2^n`。 
5. 減算`|A0|`そして`|A2|`、与える`ans -= 2 * I`。 
6. 減算`|A1| = 2^cc`。 
7. 追加し直す`|A0 ∩ A1|`そして`|A1 ∩ A2|`、それぞれに等しい`2^iso`。 
8.追加`|A0 ∩ A2|`。 すべての非分離コンポーネントが 2 部構成である場合、これは次と等しくなります。`2^bip`; それ以外の場合はゼロです。 
9. 三重交差点を減算する`2^iso`。 
10. 結果の値を出力します。 

なぜ効果があるのか:

 すべての無効な割り当ては次のいずれかに属しているため、包含/除外式は正確です。`A0`、`A1`、 または`A2`。 式内のすべての項は、欠落しているエッジ ラベルによって課される構造的制約に従ってカウントされます。 中間を満たす手順は、独立したセットの数を正確に計算し、残りのすべての数量はコンポーネント レベルのグラフ プロパティから得られます。 すべての包含/除外用語が正しいため、最終的なカウントも正確になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    adj = [0] * n
    g = [[] for _ in range(n)]

    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1

        adj[u] |= 1 << v
        adj[v] |= 1 << u

        g[u].append(v)
        g[v].append(u)

    vis = [False] * n
    cc = 0
    iso = 0
    bip = 0
    all_bip = True

    from collections import deque

    for s in range(n):
        if vis[s]:
            continue

        cc += 1

        if not g[s]:
            iso += 1
            bip += 1
            vis[s] = True
            continue

        q = deque([s])
        vis[s] = True
        color = {s: 0}
        ok = True

        while q:
            v = q.popleft()

            for to in g[v]:
                if to not in color:
                    color[to] = color[v] ^ 1
                    vis[to] = True
                    q.append(to)
                elif color[to] == color[v]:
                    ok = False

        if ok:
            bip += 1
        else:
            all_bip = False

    n1 = n // 2
    n2 = n - n1

    left_adj = [0] * n1
    right_adj = [0] * n2
    cross = [0] * n1

    for i in range(n1):
        mask_l = 0
        mask_r = 0

        for j in range(n1):
            if adj[i] >> j & 1:
                mask_l |= 1 << j

        for j in range(n2):
            if adj[i] >> (n1 + j) & 1:
                mask_r |= 1 << j

        left_adj[i] = mask_l
        cross[i] = mask_r

    for i in range(n2):
        mask = 0
        v = n1 + i

        for j in range(n2):
            if adj[v] >> (n1 + j) & 1:
                mask |= 1 << j

        right_adj[i] = mask

    size_r = 1 << n2

    indep_r = [0] * size_r
    indep_r[0] = 1

    for mask in range(1, size_r):
        b = mask & -mask
        v = b.bit_length() - 1
        prev = mask ^ b

        if indep_r[prev] and (right_adj[v] & prev) == 0:
            indep_r[mask] = 1

    f = [0] * size_r

    for mask in range(1 << n1):
        ok = True
        allowed = (1 << n2) - 1

        cur = mask
        while cur:
            b = cur & -cur
            v = b.bit_length() - 1

            if left_adj[v] & (mask ^ b):
                ok = False
                break

            allowed &= ~cross[v]
            cur ^= b

        if ok:
            f[allowed] += 1

    for bit in range(n2):
        for mask in range(size_r):
            if mask & (1 << bit):
                f[mask] += f[mask ^ (1 << bit)]

    independent_sets = 0

    for mask in range(size_r):
        if indep_r[mask]:
            independent_sets += f[mask]

    ans = 1 << n

    ans -= independent_sets
    ans -= independent_sets
    ans -= 1 << cc

    ans += 1 << iso
    ans += 1 << iso

    if all_bip:
        ans += 1 << bip

    ans -= 1 << iso

    print(ans)

solve()
```グラフを 2 つの半分に分割した後、コードは左半分のすべてのサブセットと右半分のすべてのサブセットを個別に列挙します。 各半分には最大 20 個の頂点が含まれるため、最大のサブセット空間は約 100 万の状態であり、これは管理可能です。 

配列`f`特定の右頂点セットが許可する独立した左サブセットの数を格納します。 サブセット ゼータ変換は、この情報をすべての独立した右サブセットの互換性カウントに変換します。 

よくある間違いは、包含/除外条件で孤立した頂点を誤って処理することです。 分離された頂点はエッジ ラベルを作成しないため、通常の 2 部コンポーネントとは異なる動作をします。 式では、`iso`まさにこの理由から、別々に。 

もう一つの簡単なバグは、それを忘れることです`A0 ∩ A2`すべてのエッジにラベルが必要です`1`。 非二部連結成分を含むグラフは、この交差への割り当てがゼロになります。

 次のことを考慮してください。```

```すべての頂点は分離されています。 アルゴリズムは計算します`cc = iso = bip = 3`。 独立セットの数は次のとおりです。`2^3 = 8`。 包含と排除はすべてを打ち消し、生み出す`0`。 エッジが存在しないのでラベルを取得`0`、`1`、 そして`2`is impossible.

 考慮する：```
2 1
1 2
```課題は4つあります。 単一エッジのみにラベルを付けることができます`0`、`1`、 または`2`任務によっては。 3 つのラベルすべてを同時に作成できる割り当てはありません。 包含/除外式は正しくゼロと評価されます。 

考慮する：```
3 3
1 2
2 3
1 3
```グラフは三角形です。 BFS カラーリング中にパリティの競合が発生するため、`all_bip = False`。 その結果、`A0 ∩ A2`貢献度はゼロになります。 すべてのエッジが次と等しくなるため、これは正しいです。`1`三角形にはない適切な 2 色分けが必要です。 

考慮する：```

1 2
3 4
```グラフには 2 つの切り離されたコンポーネントがあります。`A1`としてカウントされます`2^cc = 4`各コンポーネントが独立して均一な値を選択するためです。 グラフを接続されているかのように扱うと、そのような割り当ては 2 つだけ誤ってカウントされます。 コンポーネントベースのカウントにより、その間違いを回避できます。
