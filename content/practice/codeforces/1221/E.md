 ## アルゴリズムのチュートリアル

 このソリューションは、文字列をスキャンし、連続する文字列の長さを抽出することで機能します。`.`セグメント。 このような各セグメントは、両方のプレーヤーの可能な手の数に独立して寄与します。 

1. 文字列を走査し、すべての最大の連続セグメントの長さを計算します。`.`。 これらのセグメントは、手をプレイできる独立した領域を表します。 これは有効です。`X`セルは領域間の相互作用を永続的に分離します。 
2. 長さの各セグメントについて`L`、アリスが単独で最適にプレイした場合に、そこから強制できる手数を計算します。 彼女は常にサイズのブロックを削除するため、`a`、彼女は少なくとも保証できます`L // a`そのセグメントから移動します。 
3. 同様に、同じセグメントからボブの容量を計算します。`L // b`。 ボブはより小さなセグメントを使用するため、同じ領域からより多くの動きを抽出できます。 
4. すべてのセグメントの寄与を合計します。アリスの合計移動量とボブの合計移動量です。 
5. 合計を比較します。 アリスの合計移動能力がボブよりも厳密に大きい場合、アリスは、ボブがすべての再生可能なセグメントを使い果たす前に、最後の有効な移動を確実に行うことができます。 そうでなければ、ボブは彼女に匹敵するか、彼女よりも長く生き残ることができ、強制的な勝利を防ぐことができます。 

重要なステップは、各セグメントを個別に処理し、フロア分割を合計することです。 これは、セグメントが以下に縮小されるため、機能します。`a`または`b`、そのプレイヤーは使用できなくなり、永続的なため、移動がセグメントをマージすることはありません。`X`障壁。 

### なぜ効果があるのか

 各移動により、少なくとも 1 つの完全な長さのブロックが永久に破壊されます`a`または`b`点セグメントの内側にあるため、いかなる移動も新しいものを生み出すことはできません。`.`細胞。 これにより、各ドット セグメントは固定チャンクでのみ消費できるリソースになります。 セグメントを混合しても最適なプレイは得られないため、ゲームはセグメントごとに独立したサブゲームに分解されます。 勝者は、アリスがボブよりも厳密に全体的により多くの手を抽出できるかどうかによって決まります。これにより、ボブが最終的に最初に正当な手を使い果たすことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    q = int(input())
    for _ in range(q):
        a, b = map(int, input().split())
        s = input().strip()

        alice = 0
        bob = 0

        i = 0
        n = len(s)

        while i < n:
            if s[i] == 'X':
                i += 1
                continue

            j = i
            while j < n and s[j] == '.':
                j += 1

            length = j - i

            alice += length // a
            bob += length // b

            i = j

        if alice > bob:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```コードは、各クエリを読み取り、単一の線形スキャンで文字列を処理することから始まります。 2 ポインター スイープを使用して、連続するドットをセグメントにグループ化します。 セグメントごとに、各プレーヤーがそれぞれの動きの長さによる整数除算を使用して抽出できる完全な動きの数を計算します。 

最後の比較は、以前に導出された優勢条件を反映しています。 厳密な不平等が必要なのは、平等とは、ボブが常にアリスの進歩を反映し、彼女が決定的な優位性を得るのを防ぐことができることを意味するためです。 

セグメント境界が発生した場合は、セグメント境界を正しくリセットするように注意する必要があります。`X`、セグメントは独立しており、マージしてはいけないためです。
