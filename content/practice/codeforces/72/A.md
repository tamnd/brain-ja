 ## 解決策
 ## 問題の理解

 この問題では、正の整数かどうかを判断するように求められます。$n$は個別の整数の合計として表すことができ、各整数は 1 または素数のいずれかになります。 そのような表現が存在する場合は、辞書編集上最大のものを作成する必要があります。 辞書編集上最大とは、シーケンスを要素ごとに比較するときに、より大きな数が先に出現するシーケンスが優先されることを意味します。 

入力は単一の整数です$n$と$1 \le n \le 10000$。 この上限は、次の値までのすべての素数を検査できるアルゴリズムを許可するのに十分小さいです。$n$または、線形時間処理を実行することもできますが、サブセットの数が指数関数的に増加するため、素数のすべてのサブセットを試行する総当り的なアプローチは除外されます。 

エッジケースは、小さな数やそれ自体が素数である場合に発生します。 例えば、$n = 1$出力する必要があります`1=1`。 もし$n$それ自体が素数である場合、辞書編集上最大の解は単にシングルトンシーケンスです`[n]`。 4 のような数値は特別な処理が必要です。`4 = 2 + 2`は許可されていないため (要素は個別である必要があります)、アルゴリズムでは次のような組み合わせを考慮する必要があります。`1 + 3`。 

主な微妙な点は、数値が個別である必要があり、答えが辞書編集上最大である必要があるという要件から来ています。 不注意な解決法では、最小の素数を取り出して 1 で埋めるだけかもしれませんが、それは辞書編集上の要件を満たしていません。 

## アプローチ

 ブルートフォースアプローチでは、次のすべてのサブセットが列挙されます。`1`そして最大の素数`n`それらの合計が等しいかどうかを確認します`n`。 これは正しいですが、実行不可能です`n`素数のサブセットの数が指数関数的に増加し、簡単に超えてしまうため、最大 10000 まで$2^{1229}$サブセット (素数の数 ≤ 10000)。 

重要な点は、辞書編集上最大のシーケンスが必要な場合は、可能な限り最大の数値から開始する必要があるということです。 どれについても$n$、 もし$n$プライムです、`[n]`は自動的に最適なシーケンスになります。 そうでない場合は、最大の素数 ≤ 残りの合計を繰り返し選択するか、十分に小さい素数がない場合は 1 を選択し、それをシーケンスに追加します。 この貪欲なアプローチが機能するのは、数値が個別であり、最大優先アプローチにより辞書編集上の優先順位が保証されるためです。 残りの合計は常に減少するため、処理は終了します。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^π(n)) | O(n) | 遅すぎる |
 | 最適な貪欲さ | O(n√n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 以下のすべての素数を生成します。$n$ふるいを使って。 ふるいにより、数値が素数であるかどうかを O(1) 時間以内にチェックできるようになります。 
2. もし$n$それ自体はプライムです、印刷します`n=n`そして終了します。 これは、辞書編集的には明らかに最大です。 
3. それ以外の場合は、空のリストを初期化します`answer`そしてセット`remaining = n`。 
4. 素数を降順に繰り返します。 素数ごとに$p$、 もし$p \le$残っているものを追加します`answer`そしてそれをから引きます`remaining`。 
5. もし`remaining > 0`すべての素数を考慮した後、追加します`1`必要に応じて s を合計すると`n`。 これが機能する理由は、`1`は複数回使用できますが、シーケンス内で区別されるものと見なす必要があります。 
6. シーケンスを次の形式で印刷します。`n=a1+a2+...+am`。 

機能する理由: 各ステップで、辞書編集上の最大値を保証する、利用可能な最大の素数を選択します。 素数 ≤ 残りのみを選択するため、オーバーシュートすることはありません。 残った量は詰めることができます`1`s 合計が正確であることを確認するため`n`。 素数は本来異なるものであるため、配列は明確なままです。`1`は別個に扱われます。 この貪欲なアプローチでは、有効な表現が存在する場合にはそれが生成されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def sieve(limit):
    is_prime = [True] * (limit + 1)
    is_prime[0] = is_prime[1] = False
    for i in range(2, int(limit**0.5) + 1):
        if is_prime[i]:
            for j in range(i*i, limit + 1, i):
                is_prime[j] = False
    primes = [i for i, val in enumerate(is_prime) if val]
    return primes

def main():
    n = int(input())
    primes = sieve(n)
    
    if n in primes or n == 1:
        print(f"{n}={n}")
        return
    
    answer = []
    remaining = n
    for p in reversed(primes):
        if p <= remaining:
            answer.append(p)
            remaining -= p
    answer.extend([1] * remaining)
    result = '+'.join(map(str, answer))
    print(f"{n}={result}")

if __name__ == "__main__":
    main()
```ふるいはすべての素数を生成します ≤`n`効率的に。 自明な素数または`1`まずケース。 降順反復により、辞書編集上の最大値として最大の素数が確実に選択されます。 で拡張`1`s は、残りが少ない場合に正確な合計に達することを保証します。 Off-by-one エラーは次の方法で回避できます。`<= remaining`そしてそれを含めて`remaining`最後に1秒。 

## 実用的な例

 ### 入力: 11

 | 残り | プライムが選択されました | 回答リスト |
 | --- | --- | --- |
 | 11 | 11 | [11] |
 | 0 | 完了 | [11] |

 最大の素数 ≤ 11 は 11 そのものです。 残りが0になるので出力します`11=11`。 最大の数値が最初に表示されるため、辞書編集的に最大になります。 

### 入力: 8

 | 残り | プライムが選択されました | 回答リスト |
 | --- | --- | --- |
 | 8 | 7 | [7] |
 | 1 | 素数なし ≤ 1 | [7,1] |

 7 を選択し、1 を残します。`1`取得するため`[7,1]`。 出力`8=7+1`。

 ## 特殊なケース

 のために`n = 1`、ふるいは 1 以下の素数を生成しませんが、次のように処理します。`n == 1`別途、与える`1=1`。 のために`n`それ自体が素数であるように、`11`、アルゴリズムは次のように直ちに終了します。`[n]`、最大の要素が最初に表示されることが保証されます。 次のような数字の場合`4`、最大の素数 ≤ 4 は 3 で、余りは 1 になります。`1`有効なシーケンスを与える`[3,1]`。 これらのチェックにより、最小ケース、素数ケース、および組み合わせケースの正確性が保証されます。
