 ## 解決策
 ## 問題の理解

 麺は長めに始まります`0`。 次のそれぞれの期間中に`T`秒、その長さは次のいずれかによって変化します。`+1`または`-1`。 一連の選択によって、一定の長さのランダム ウォークが生成されます。`T`。 

テストケースごとに、時間間隔全体で最高値を持つ歩行の数をカウントする必要があります。これには、時点での初期位置も含まれます。`0`、正確に等しい`M`。 答えは非常に大きくなる可能性があるため、すべての結果は剰余として取得されます。`10^9 + 7`。 

の最大値`T`だけです`2000`、ただし、いくつでもあります。`10^5`テストケース。 クエリごとに動的プログラムを個別に計算するには、おおよその必要量が必要になります。`10^5 × 2000²`まったく実行不可能な操作です。 小さな上限は`T`考えられるすべての値を一度前処理し、一定時間内に各クエリに応答することを提案します。 

微妙なケースの 1 つが次のような場合です。`M > T`。 歩行は 1 秒あたり 1 単位しか変化しないため、`T`ステップよりも高い高さに到達することはできません`T`。 例えば、```
1
2 3
```答えがあります`0`。 

もう 1 つの簡単な間違いは、最大値を計算するときに初期位置も考慮されることを忘れていることです。 例えば、```
1
1 0
```答えがあるだろう`1`、散歩だから`(0, -1)`決して上に上がらない`0`。 この問題は保証します`M ≥ 1`したがって、この状況が入力に現れることはありませんが、これは、次のような場合に常に最大値が引き​​継がれる理由を説明しています。`t = 0`。 

歩行が到達したときに、より興味深い境界ケースが発生します。`M`数回。 例えば、```
1
4 2
```散歩が含まれています```
0 → 1 → 2 → 1 → 2
```その最大値は依然として正確です`2`。 最初の訪問のみをカウントするソリューション`M`は、この有効なウォークを誤って拒否してしまいます。 

## アプローチ

 最も直接的な解決策は、すべてを列挙することです。`2^T`考えられるシーケンス`+1`そして`-1`動く。 各シーケンスは、その最大値を追跡しながら簡単にシミュレートできます。 すべてのウォークが 1 回だけ検査されるため、これは明らかに正しいです。 残念ながら、そのとき、`T = 2000`、検索スペースはおよそ`2^2000`、これは実用的な限界をはるかに超えています。 

指数関数的な爆発は、すべての歩行を独立して処理することで発生します。 重要な観察は、現在位置と、禁止された境界をすでに越えたかどうかだけが問題であるということです。 

最大値が何らかの制限を超えない歩行をカウントするとします。`K`。 すべての以前の情報は、現在時刻と現在位置を超えたことがないという事実によって要約されるため、すべての状態は現在時刻と現在位置にのみ依存します。`K`。 

させて```
f[K][T]
```長さの歩行の数を示します`T`その最大値は最大です`K`。 

そのとき望ましい答えは、```
f[M][T] - f[M - 1][T].
```あらゆる歩行を正確に最大値で行う`M`最初の数量によって 1 回カウントされ、2 番目の数量によって除外されます。 

すべてのクエリが満たされるため、`T ≤ 2000`のすべての値を前処理できます。`f`あらゆる人にとって`K`から`0`に`2000`。 状態空間は約`2001 × 4001`、位置は常に間にあるため`-T`そして`T`。 この前処理には約`O(MAXT²)`境界ごとに異なるため、全体的な複雑さが生じます。`O(MAXT³)`、それは約です`8 × 10^9`移行中ですが、まだ大きすぎます。 

2 番目の観察では、別の要因が除去されます。 から境界を増やしながら、`K`に`K + 1`、遷移グラフはローカルでのみ変化します。 減算して座標を移動する`K`あらゆる問題を、決してプラスにはならない四球のカウントに変換します。 反射原理により閉じた形状が得られます$$f(K,T)=\sum_x
\left(
\binom{T}{\frac{T+x}{2}}
-
\binom{T}{\frac{T+x}{2}+K+1}
\right),$$ここで、合計は到達可能なエンドポイントにわたって実行されます。 階乗および逆階乗を事前計算した後、すべての値が一定時間内に計算されます。 すべての解答表を埋めるのに必要な時間は、`O(MAXT²)`。

 ## アルゴリズムのチュートリアル

 1. 階乗および逆階乗モジュロを事前計算する`10^9 + 7`まで`2000`。 これにより、すべての二項係数を一定時間で評価できるようになります。 
2. あらゆる人にとって`T`から`0`に`2000`、考えられるすべての最大値に対して反復します`M`。 
3. 反射原理の式を使用して、最大値を超えない四球をカウントします。`M`。 
4. 境界に対して同じ量を計算します。`M - 1`。 
5. 2 つの値を剰余として減算します。`10^9 + 7`。 結果は、最大値が次の値に等しい四球の数と正確に一致します。`M`。 
6. すべての回答を、次のインデックスが付いたルックアップ テーブルに保存します。`(T, M)`。 
7. 各テスト ケースについて、事前計算された値を出力します。 

### なぜ効果があるのか

 反射原理は、禁止された境界を越える歩行と、シフトされた位置で終了する反射歩行との間の全単射を確立します。 すべての無効なウォークは 1 つの反射ウォークとペアになっており、すべての反射ウォークは 1 つの無効なウォークから生じます。 これらの反射パスを無制限のカウントから減算すると、最大値が境界を超えないウォークが正確に残ります。 連続する境界間の差を取得すると、最大値が正確に一致するウォークが分離されます。`M`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10 ** 9 + 7
MAXT = 2000

fac = [1] * (MAXT + 1)
for i in range(1, MAXT + 1):
    fac[i] = fac[i - 1] * i % MOD

invfac = [1] * (MAXT + 1)
invfac[MAXT] = pow(fac[MAXT], MOD - 2, MOD)
for i in range(MAXT, 0, -1):
    invfac[i - 1] = invfac[i] * i % MOD

def C(n, k):
    if k < 0 or k > n:
        return 0
    return fac[n] * invfac[k] % MOD * invfac[n - k] % MOD

ans = [[0] * (MAXT + 1) for _ in range(MAXT + 1)]

for T in range(MAXT + 1):
    at_most = [0] * (MAXT + 1)
    for M in range(MAXT + 1):
        s = 0
        for x in range(-T, T + 1, 2):
            k = (T + x) // 2
            s += C(T, k)
            s -= C(T, k + M + 1)
        at_most[M] = s % MOD

    for M in range(1, MAXT + 1):
        ans[T][M] = (at_most[M] - at_most[M - 1]) % MOD

n = int(input())
for _ in range(n):
    T, M = map(int, input().split())
    if M > T:
        print(0)
    else:
        print(ans[T][M])
```前処理では、階乗と逆モジュラーを使用して、すべての二項係数を一定時間で計算します。 反射原理式はペアごとに評価されます`(T, M)`、その後、連続する値が減算されて、最大値が正確に一致するウォークを分離します。`M`。 

減算は常にモジュロで実行する必要があります`10^9 + 7`中間値が負になる可能性があるためです。 もう 1 つの詳細は、エンドポイントの反復内に隠されたパリティ チェックです。 到達可能なエンドポイントは常に次と同じパリティを持ちます。`T`, したがって、ループは 2 つ進みます。

 ## 特殊なケース

 検討してください```
1
2 3
```歩行量は最大でも 1 秒あたり 1 回増加するため、高さに到達します`3`２段階では無理です。 アルゴリズムは即座に検出します`M > T`そして戻ってきます`0`。 

考慮する```
1
4 2
```散歩```
0 → 1 → 2 → 1 → 2
```高さに達する`2`2回。 それは、最大で最大値を持つ歩行のセットに属します。`2`、ただし、最大でもセットにはなりません`1`。 それらの差は正しく 1 回としてカウントされます。 

最後に考えてみましょう```
1
3 1
```散歩```
0 → 1 → 0 → 1
```最大値を超えずに最大値に数回触れます。 反射原則により、以下の範囲で区切られた歩行の中にカウントされます。`1`、一方、減算では、次の範囲にあるウォークのみが削除されます。`0`したがって、このウォークは最終的な答えに 1 回だけ貢献します。
