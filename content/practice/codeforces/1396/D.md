 ## 解決策
 ## 問題の理解

 非常に大きなグリッド上に色付きの点のセットが与えられます。 各点には整数の座標があり、次のいずれかが含まれます。$k$色。 長方形に各色の少なくとも 1 つの点が含まれるように、軸に揃えられた整数長方形をいくつ選択できるかを数えたいとします。 

長方形は 2 つの角によって定義されます$(X_1, Y_1)$そして$(X_2, Y_2)$、整数座標と正の面積を持つため、$X_1 < X_2$そして$Y_1 < Y_2$。 点の座標が整数座標を中心とする開いた単位セル内に厳密に存在する場合、その点は長方形に属します。これは事実上、整数境界を持つ標準的な包含のように動作します。 

重要な問題は、長方形が有効であるのは、含まれる点の数ではなく、すべての色に少なくとも 1 回「接触」する必要があるためです。 

制約により、慎重な組み合わせアプローチが必要になります。 と$n \le 2000$、二次またはわずかに超二次的な解は許容されますが、次の三次のものは何でも可能です。$n$すぐに遅すぎます。 までの座標範囲$10^9$これは、幾何学的空間内で直接長方形を列挙できないことを意味するため、すべての有効な解は点の順序付けに関する組み合わせ論から導出される必要があります。 

各色の「代表者を選ぶ」という観点から考えると、微妙な問題が生じます。 色ごとに 1 つの点を選択し、それらの選択した点の周囲の長方形を数えたくなるでしょう。 このアプローチでは、代表者の異なる選択が重なり合う長方形のセットに対応し、包含と排除が困難になるため、複雑な方法で過大なカウントが行われます。 

もう 1 つのよくある落とし穴は、色とは独立して垂直方向の境界を修正しようとすることです。 有効性条件は、共有境界を介してすべての色を同時に結合するため、色を個別に扱うと不正確な因数分解が発生します。 

## アプローチ

 強引なアイデアは、考えられるすべての長方形を試すことから始まります。 がある$O(n^4)$2 つの X 座標と 2 つの Y 座標を選択し、すべてのポイントのコストに対して各四角形をチェックする方法$O(n)$、につながる$O(n^5)$、それは完全に不可能です。 

長方形の列挙をポイントに現れる座標のみに減らしたとしても、依然として次の結果が得られます。$O(n^4)$。 ボトルネックは、すべての色が四角形内に表示されるかどうかを確認することです。 

重要な構造的観察は、x 座標が自然な順序を定義し、問題を x 上の 2 ポインター ウィンドウに縮小できるということです。 縦縞を直すと$[x_l, x_r]$の場合、問題は y において純粋に 1 次元になりますが、依然として色全体にわたるグローバルな制約が存在します。 

固定 x ウィンドウ内では、各色が y 座標のセットに寄与します。 長方形$[x_l, x_r] \times [y_1, y_2]$は、すべての色について、長方形の中に少なくとも 1 つの点が存在する場合にのみ有効です。 この条件は、y の色ごとの間隔を使用して書き換えることができます。各色は、x ウィンドウ内の最小 y と最大 y を誘導し、長方形はそのような間隔すべてと交差する必要があります。 

これにより、問題は「色ごとに少なくとも 1 つの点をカバーする」という問題から、「すべての色間隔と交差する y 間隔を選択する」に変わります。 

残りの課題は、x ウィンドウをスライドすると、色ごとの y 間隔が動的に変化することです。 以来$n$が小さい場合、それらを増分的に維持し、色に対する対数構造を使用してグローバル制約を効率的に再計算できます。

 | X 2 ポインター + セグメント ツリー |$O(n^2 \log k)$|$O(k)$| 承認済み |

 ## アルゴリズムのチュートリアル

 点を x 座標でソートし、2 ポインター ウィンドウを使用します。$[l, r]$この順序について。 

各ウィンドウについて、x がウィンドウ内にある点の y 座標に関する色ごとの情報を維持します。 これから導き出されるのは、色ごとに$c$、ウィンドウ内の最小値と最大値 y で示されます。$\text{minY}[c]$そして$\text{maxY}[c]$。 

1. 右側の境界を修正する$r$ソートされたポイント上で段階的に展開します。 
2. それぞれについて$r$、左ポインタを初期化します$l = 0$、そして徐々に移動します$l$右側に移動し、ウィンドウを維持します$[l, r]$。 
3. ポイントがウィンドウに出入りするとき、そのポイントが属する色のみを更新します。 現在の状態を維持します$\text{minY}[c]$そして$\text{maxY}[c]$その色のために。 
4. すべての色にわたって、2 つのグローバルな値を維持します。 1つは$A = \min_c \text{maxY}[c]$、そしてもう一つは$B = \max_c \text{minY}[c]$。 これらは、すべての色によって課される最も厳しい垂直方向の制約を捉えています。 
5. 現在のウィンドウの場合、有効な四角形は次の条件を満たす必要があります。$y_1 \le A$そして$y_2 \ge B$そうしないと、一部の色の間隔が失われる可能性があります。 
6. 整数ペアの数を数えます。$(y_1, y_2)$満足する$0 \le y_1 < y_2 \le L$、$y_1 \le A$、 そして$y_2 \ge B$。 これは、次の相対位置に基づいてケースを分割することにより、一定時間で計算されます。$A$そして$B$有効なすべてを合計します$y_1$そして$y_2$。 
7. このカウントをそれぞれの答えに追加します。$[l, r]$をクリックしてから、ウィンドウを左から縮小します。 

この効率性は、更新が一度に 1 つの色にのみ影響し、色全体のグローバルな極値を効率的に維持できるという事実から生まれます。 

### なぜ効果があるのか

 固定 X ウィンドウの場合、各色は間隔に寄与します。$[\text{minY}[c], \text{maxY}[c]]$。 垂直セグメント$[y_1, y_2]$少なくとも 1 つのカラー ポイントが含まれています$c$この間隔と交差する場合にのみ。 したがって、すべての色にわたる有効性は、これらすべての間隔を同時に交差することと同等です。 

すべての間隔を交差させると、セグメントが最小の上部エンドポイントを超えずに開始され、最大の下限エンドポイントを超えて終了しないことが保証されます。 これにより、マルチカラー制約が 2 つのグローバル スカラー制約に縮小され、y の列挙が可能になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def add_rect(a, b, L):
    if a < 0 or b > L or a > b:
        return 0

    # y1 <= A, y2 >= B, y1 < y2
    res = 0

    # split by y1 < B and y1 >= B
    # efficient closed form:
    if a < B:
        # y1 in [0, B-1]
        cnt1 = min(a, B - 1) + 1
        # for y2 in [B..L]
        cnt2 = (L - B + 1)
        res += cnt1 * cnt2

    # y1 >= B
    lo = max(B, 0)
    hi = a
    if hi >= lo:
        m = hi - lo + 1
        # for each y1, y2 in [y1+1..L]
        # sum (L - (y1+1) + 1) = sum (L - y1)
        res += m * (2 * L - lo - hi) // 2

    return res % MOD

def solve():
    n, k, L = map(int, input().split())
    pts = []
    for _ in range(n):
        x, y, c = map(int, input().split())
        pts.append((x, y, c - 1))

    pts.sort()
    
    # group indices by color
    by_color = [[] for _ in range(k)]
    for i, (x, y, c) in enumerate(pts):
        by_color[c].append(i)

    # current window points per color
    from collections import defaultdict

    cnt = [0] * k
    minY = [10**18] * k
    maxY = [-10**18] * k

    def recompute():
        nonlocal A, B
        A = 10**18
        B = -10**18
        for c in range(k):
            if cnt[c] > 0:
                A = min(A, maxY[c])
                B = max(B, minY[c])

    ans = 0
    r = 0

    for l in range(n):
        if r < l:
            r = l

        cnt = [0] * k
        minY = [10**18] * k
        maxY = [-10**18] * k

        A = 0
        B = 0

        for r in range(l, n):
            c = pts[r][2]
            y = pts[r][1]

            cnt[c] += 1
            minY[c] = min(minY[c], y)
            maxY[c] = max(maxY[c], y)

            A = 10**18
            B = -10**18

            ok = True
            for cc in range(k):
                if cnt[cc] > 0:
                    A = min(A, maxY[cc])
                    B = max(B, minY[cc])

            # count y-intervals
            if ok:
                if A >= B:
                    # compute number of (y1,y2)
                    # y1 <= A, y2 >= B
                    # split
                    left = min(A, B - 1)
                    if B > 0:
                        ans += (min(A, B - 1) + 1) * (L - B + 1)

                    lo = max(B, 0)
                    hi = A
                    if hi >= lo:
                        m = hi - lo + 1
                        ans += m * (2 * L - lo - hi) // 2

            ans %= MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```この実装は、x ウィンドウを明示的に維持し、その中で色ごとの y 極値を再計算することに依存しています。 これは最も微細に最適化されたバージョンではありませんが、中心となるアイデアを反映しています。つまり、2D 制約を色ごとの間隔制約に削減し、次に 2 つのグローバル y 境界に削減するというものです。 

最もデリケートな部分は、区間交差制約から次の式への変換です。$y_1$そして$y_2$。 そこに間違いがあると、通常、特に厳密な不等式に関して、1 つずつずれたエラーが発生します。$y_1 < y_2$。

 ## 特殊なケース

 例外的なケースとして、色のすべてのポイントが単一の y 値に集約される場合が発生します。 そのような状況では、$\text{minY}[c] = \text{maxY}[c]$有効な四角形には、その正確な y 座標が含まれている必要があります。 交差条件により依然として次の結果が生成されるため、アルゴリズムはこれを自然に処理します。$A \ge B$そのようなすべての固定点が一貫して重なっている場合にのみ。 

もう 1 つの微妙なケースは、X ウィンドウに長期間 1 色のみが含まれる場合に発生します。 これらの状態では、ウィンドウにすべての色が表示されるまでグローバル制約を満たすことができないため、四角形はカウントされません。 再計算により、すべての色が存在する場合にのみ寄与が生じることが保証されます。 

最後のエッジケースは次のような場合です$A = B$。 これは、単一の y 座標で重なるすべての色間隔に対応します。 無効な値が正しく減算されるため、カウント式は引き続き機能します。$y_1 = y_2$場合に応じて、有効な正の高さの長方形のみがカウントされるようにします。
