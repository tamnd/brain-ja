 ## 解決策
 ## 問題の理解

 ジオタが一連のゲーム レベルですべてのボスをクリアするのにかかる最小時間を計算するように求められます。 各レベルには、それぞれ 1 ヘルス ポイントを持ついくつかの通常のモンスターが含まれており、2 ヘルス ポイントを持つボスが 1 体だけ含まれています。 ジオタには 3 つの武器があります。1 匹のモンスターの HP を 1 減らすピストル、すべてのモンスターに 1 HP を与えるレーザー、そしてどんなモンスターでも瞬時に殺す AWP です。 各武器にはリロード時間があり、ジオタは一度に 1 つの銃しかリロードできません。 レベル間の移動には時間がかかります`d`時間単位であり、テレポート中にリロードしたり射撃したりすることはできません。 

入力配列`a`各レベルの通常モンスターの数をリストします。 私たちの目標は、レベル 1 から始めて、すべてのボスを排除するための最小限の合計時間です。重要な制限は、通常のモンスターがすべて殺されるまでピストルまたは AWP でボスを撃つことができないことです。また、即座に殺さずにボスにダメージを与えた場合は、戻る前に隣接するレベルに残さなければなりません。 

主な制約は、レベルの数です。`n`最大 10^6 で、レベルごとのモンスターの数を指定できます。`a_i`大きくすることもできます。 これにより、入れ子になったループで個々のモンスターを処理するソリューションは除外されます。 ソリューションは、線形または線形に近い時間で機能する必要があります。`n`。 明らかではないエッジ ケースには、単一のモンスターとボスが存在するレベルが含まれます。銃の選択によって、前後の移動が必要かどうかが大きく異なります。また、複数のレベルでレーザーを使用すると、リロード時間は短縮されますが、余分な移動が必要になる状況が含まれます。 

## アプローチ

 素朴なアプローチは、銃の使用法と動作のあらゆる組み合わせをシミュレートすることです。 おそらくレーザーを使用して通常のモンスターを撃ち、次にピストルまたはAWPでボスを倒し、必要に応じてレベル間を移動するという各シーケンスを試しました。 これはすべての有効な戦略を検討しているため、原則として正しいです。 ただし、最大 10^6 のレベルがあり、各レベルには最大 10^6 のモンスターが存在するため、すべてのモンスターや武器使用のすべてのシーケンスを考慮したシミュレーションは、10^12 の操作を軽く超えてしまいます。 これは 2 秒の制限時間としては遅すぎます。 

重要な洞察は、レベルごとに、すべての通常のモンスターとボスを倒すまでの最小時間を、小さなオプションのセットを使用して個別に計算できることを観察することで得られます。 レベルには 2 つの主な戦略があります。ピストルですべてのモンスターを個別に殺し、AWP でボスにとどめを刺すか、レーザーを最適に使用してすべてのモンスターに一度にダメージを与え、場合によってはボスを生かしておき、後で処理することです。 各レベルは、リロード時間のコストと、ボスを部分的に損傷したままにした場合のオプションの移動コストとして表すことができます。 これにより、問題をレベルに沿った動的プログラミングに落とし込むことができます。状態は、ボスが完全に殺されたか部分的に損傷した状態で前のレベルから来たのかということです。 DP はレベルごとに 2 つの状態のみを考慮する必要があるため、DP は線形になります。`n`。

 ## アルゴリズムのチュートリアル

 1. 各レベルについて、2 つの主要なコストを計算します。 1 つ目は単純な「すべてを直接殺す」コストです。通常のモンスターにはピストルを、ボスには AWP を使用します。 これは`a_i * r1 + r3`。 2 つ目は「レーザーまたはフレキシブル」コストです。レーザーとオプションのピストルまたは AWP を使用してボスを倒し、ボスが生き残った場合は強制移動を利用します。 これは`min(r2 + r1, r1 * a_i + r1 * 2, r3)`ボスの組み合わせに追加`a_i * r1`通常モンスターの場合。 
2. DP 状態を定義します。 させて`dp[i][0]`レベルを終了するまでの最短時間であること`i`ボスが完全に殺された状態で、`dp[i][1]`部分的に損傷したボスを残して終了するまでの最小時間。つまり、いったん離れて後で戻る必要があることを意味します。 レベル1の場合、`dp[1][0]`それは単なる直接殺害コストであり、`dp[1][1]`柔軟なコストに移動を加えたものです`d`ボスを生かしておくからです。 
3. レベルを順番に処理します。 レベルごとに更新します`dp[i][0]`前のレベルを完全に終了してからこのレベルを直接終了するか、部分的に損傷したボスで前のレベルを終了して戻ってくることが最低限必要です。 アップデート`dp[i][1]`同様に、このレベルを部分的に損傷したままにし、隣接するレベルへの移動コストを追加することを考慮しています。 
4. 最終的な答えは次のとおりです。`dp[n][0]`、部分的に損傷したボスを最後のレベルに残すことが初期の削減に有益である場合は、おそらく最小限の追加の動きを追加します。 

なぜ機能するのか: DP の不変条件は次のとおりです。`dp[i][0]`すべてのボスをレベルまで倒すまでの最小時間を常に表します`i`、 その間`dp[i][1]`すべてのボスをレベルまで倒すまでの最小時間を表します`i-1`プラスレベル`i`ボス部分破損。 レベル間の唯一の相互作用は、ボスが部分的に損傷したままにすることによる移動であるため、レベルごとに 2 つの状態を維持することで、すべての最適な戦略が得られます。 DP トランジションでは有効な手と最小限の選択肢のみが考慮されるため、次善の解決策を生み出すことはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, r1, r2, r3, d = map(int, input().split())
a = list(map(int, input().split()))

INF = 1 << 60

# cost to finish level i directly
direct = [0] * n
# cost to leave level i in "flexible" mode
flex = [0] * n

for i in range(n):
    ai = a[i]
    # kill all normal monsters with pistol + boss with AWP
    direct[i] = ai * r1 + r3
    # options: laser r2 + optional finishing, or pistol+r1 etc
    kill_boss_options = min(r3, r1 + r2, r1 * ai + r1 * 2)
    flex[i] = min(r1 * ai + r1 + r3, r2 + r1, r1 * ai + 2 * r1)

dp0 = 0  # previous level fully killed
dp1 = INF  # previous level partially damaged

for i in range(n):
    new_dp0 = min(dp0 + direct[i], dp1 + flex[i] + 2 * d)
    new_dp1 = min(dp0 + flex[i] + d, dp1 + flex[i] + 2 * d)
    dp0, dp1 = new_dp0, new_dp1

ans = dp0
print(ans)
```コードはまず、レベルごとに 2 つのコスト配列 (直接キル コストとフレキシブル キル コスト) を事前計算します。 次に、レベルを反復して、2 つの DP 状態を維持します。`dp0`完全にクリアされたレベルの場合、`dp1`ボスが部分的に生き残るレベルの場合。 更新式には移動コストが正しく組み込まれています。 オーバーフローを避けるために、INF に大きな整数を使用する場合は特別な注意が必要です。
