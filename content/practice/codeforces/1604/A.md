 ## 解決策
 ## 問題の理解

 整数のシーケンスが与えられており、任意の正の整数をシーケンス内のどこにでも好きなだけ挿入できます。 目標は、シーケンスが、各要素が次の位置にあるという条件を満たすようにすることです。`i`せいぜい`i`。 つまり、すべてのインデックスに対して`i`、その位置の値は 1 から始まるインデックスを超えることはできません。 これを達成するために必要な挿入の最小数を決定したいと考えています。 

シーケンスの長さは小さく、最大 100 要素ですが、値は 10^9 まで大きくなる可能性があります。 要素の値が大きいため、可能性のあるすべての挿入を総当り的な方法で単純に繰り返すことは現実的ではありません。 代わりに、各要素とその位置の間の矛盾について推論する必要があります。 要素の最大数は控えめであるため、テスト ケースごとに O(n log n) または O(n) のアルゴリズムが可能です。 

いくつかの特殊なケースはすぐにわかります。 シーケンスがすでに有効な状態にある場合、操作は必要ありません。 最初の要素が非常に大きい場合は、次のようにします。`10^9`、修正しても修正できません。 有効な位置に「プッシュ」するには、その前に多くの小さな数値を挿入する必要があります。 たとえば、シーケンス`[69]`挿入が必要です`68`要素`[1,2,...,68]`満足する前に`a[69] <= 69`。 

## アプローチ

 ブルートフォース手法では、必要な場所に要素を 1 つずつ挿入し、各ステップでシーケンスを確認します。 原理的には正しいですが、要素の値が膨大になる可能性があり、単純なシミュレーションでは最大 10^9 の挿入が必要になる可能性があるため、すぐに実行不可能になります。 つまり、各挿入を個別にシミュレートすることは不可能です。 

重要な観察は、問題が貪欲な戦略に帰着するということです。 シーケンスを並べ替えた後、最小の要素が最初の位置を占め、2 番目に小さい要素が 2 番目の位置を占め、以下同様になります。 要素が位置にある場合`i`より大きい`i`次に、その前に十分小さい数値を挿入して、その位置を移動する必要があります。`a[i]`それ以下。 基本的に、必要な挿入の最小数は、次の最大値です。`a[i] - i`すべての要素にわたって。 これが機能するのは、先頭に数字を挿入すると後続の要素のインデックスが増加し、不一致が効果的に減少するためです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * 最大(a)) | O(n + 最大(a)) | 遅すぎる |
 | 貪欲/選別インサート | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. 各テスト ケースについて、シーケンスの長さとシーケンス要素を読み取ります。 
3. シーケンスを並べ替えます。 挿入後の最適なシーケンスには、最初に最小の要素が含まれ、次に大きな要素が順番に含まれる必要があるため、並べ替えは非常に重要です。 これにより、必要な挿入の数が最小限に抑えられます。 
4. カウンタの初期化`ops`ゼロに。 これにより、必要な操作の数が追跡されます。 
5. 1 から始まるインデックスを使用して、ソートされたシーケンスを反復処理します。`i`。 要素ごとに`a[i]`、差を計算します`a[i] - i`。 この差が正の場合、この要素を有効な位置に移動するためにこの要素の前に必要な挿入の数を表します。 アップデート`ops`最大として`ops`そして`a[i] - i`。 
6. シーケンス全体を処理した後、`ops`必要な最小限の挿入数が含まれています。 この値を印刷または保存します。 
7. すべてのテスト ケースに対して繰り返します。 

機能する理由: 並べ替えにより、最小の数値が最小のインデックスを占めることが保証され、必要な挿入の数が最小限に抑えられます。 違い`a[i] - i`現在の位置より前に「欠落している」小さな要素の数を正確に捕捉します。 最大値を取得すると、計算された挿入回数を超えてもすべての要素が有効であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()
    ops = 0
    for i, val in enumerate(a, 1):
        ops = max(ops, val - i)
    print(ops)
```この解決策は、高速 I/O を使用して入力を読み取ることから始まります。 ソートにより、最小限の挿入で要素が順番に並べられるようになります。 このループでは、1 から始まるインデックスを使用して、要素の位置を必要な制限に合わせます。`ops`最大の不一致、つまり必要な挿入の数が正確に捕捉されます。 使用する`max`各ステップで、後の要素で追加の挿入が必要な場合に過小カウントを回避します。

## 特殊なケース

 単一の要素の場合`[1]`、シーケンスはすでに有効です。 ループは計算します`val - i = 0`、 それで`ops = 0`。 挿入する必要はありません。 

シーケンスの場合`[1000000000, 1, 1]`、収量の選別`[1, 1, 1000000000]`。 トレースは計算します`val - i`として`0, -1, 999999997`したがって、最大の不一致は次のようになります。`999999997`。 これにより、アルゴリズムが非常に大きな値を正しく処理し、その前に十分な小さな数値を挿入することでそれらの値を配置できるようになります。
