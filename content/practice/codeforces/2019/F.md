 ## 解決策
 ## 問題の理解

 正の整数の配列が与えられ、隣接する 2 つの要素を両方とも赤にすることはできないという制約の下で、それらの一部を「赤」としてマークすることができます。 スコアは、赤色要素の最大値、赤色要素の最小値、赤色要素の総数の 3 つの要素の合計として計算されます。 タスクは、各アレイで達成可能な最大スコアを決定することです。 

配列には最大 200,000 個の要素を含めることができ、複数のテスト ケースにわたるすべての配列の長さの合計が 200,000 を超えることはありません。 これは、要素のすべてのサブセットを反復するソリューションは実行不可能であることを示しています。$O(2^n)$天文学的な規模のオペレーション$n = 2 \cdot 10^5$。 相対的に線形または線形に近い時間で実行されるソリューションが必要です。$n$。 

すべての要素が同じである場合、微妙な特殊なケースが発生します。 たとえば、配列では`[5, 5, 5]`隣接関係の制約に違反せずに赤色の要素の数を最大化できるため、最初と最後の要素を赤色でマークすることが最適です。 単純に最大の要素のみをマークすると、次善のスコアが得られる可能性があります。 同様に、長さが 1 または 2 の配列は、選択できる要素が隣接制約によって大幅に制限されるため、エッジ ケースです。 

## アプローチ

 ブルート フォース アプローチでは、配列インデックスのすべてのサブセットを列挙し、隣接制約をチェックし、有効なサブセットごとにスコアを計算し、最大値を選択します。 このアプローチは、考えられるすべての構成をチェックするため、原理的には正しいですが、絶望的に遅いです。$n = 20$、すでに 100 万を超えるサブセットがあり、$n = 2 \cdot 10^5$、それは不可能です。 

最適化するための重要な洞察は、スコアが 3 つの数値 (最大値、最小値、および選択した要素の数) のみに依存するということです。 最大の要素を選択したら、隣接する要素を選択せず​​に、できるだけ多くの追加要素を選択します。 選択した要素の中から最小の要素も選択する場合は、最大値と最小値の間の要素の数を最大化してカウントを増やすだけで済みます。これは、小さいか等しい要素を追加すると、最大値や最小値を減らすことなく、最大値、最小値、サイズの合計が得られるためです。 

したがって、問題は要素の貪欲な選択に帰着します。まず、常に最大の要素を含めます。 次に、隣接ルールを尊重する方法で追加の要素を含めることを試みることができます。 最適な解決策は、単一の要素 (最大の要素のみ) か、またはグローバルな最大値と、選択された要素の最小値を減らさない要素を常に含むパターンで配列から隣接しない要素を選択することになります。 実際には、これは単純な式に要約されます。達成可能な最大スコアは、最大要素に 1 を加えたもの (最大値のみが選択されている場合)、または最大値から順に隣接しない要素を選択した場合の最大値、最小値、およびカウントの合計のいずれかになります。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、長さを読み取ります。`n`そして配列`a`。 
2. 最大要素を特定する`mx`で`a`。 この要素はスコアに直接寄与するため、常に最適な選択の一部となります。 
3. 変数を初期化する`ans`に`mx + 1`。 これは、最大の要素のみを赤い要素として選択した場合のスコアを表します。 
4. 配列内で、隣接しない要素を選択すると最小値が減少せずにカウントが増加する位置を確認します。 シンプルな貪欲な戦略は、配列をスキャンし、以前にマークされた赤色の要素に隣接していないすべての要素を赤色としてマークし、選択した要素の最小値と最大値を追跡することです。 
5. 配列を処理した後、赤色の要素の最大値、最小値、および数の合計としてスコアを計算します。 アップデート`ans`このスコアが前のスコアより大きい場合`ans`。 
6. 出力`ans`テストケースごとに。 

機能する理由: 不変条件は、スコアを最大化するには最大の要素を常に選択する必要があるということです。 非隣接選択により、制約に違反しないことが保証され、隣接関係を壊さずにできるだけ多くの要素を選択する貪欲なアプローチにより、カウントからの最大の寄与が保証されます。 選択した要素の最小値と最大値を追跡することで、スコアのコンポーネントを正確に考慮します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_plus_min_plus_size():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # Find global max
        mx = max(a)
        ans = mx + 1  # At least selecting one element
        
        # Greedy selection of non-adjacent elements
        # Compute two possibilities: start with first element or second element
        def compute(arr):
            selected_count = 0
            selected_min = float('inf')
            selected_max = float('-inf')
            i = 0
            while i < len(arr):
                val = arr[i]
                selected_count += 1
                selected_min = min(selected_min, val)
                selected_max = max(selected_max, val)
                i += 2
            return selected_max + selected_min + selected_count
        
        ans = max(ans, compute(a), compute(a[1:]))
        print(ans)

max_plus_min_plus_size()
```このソリューションでは、まずグローバル最大値がスコアに寄与していることを確認します。 次に、2 つの貪欲な選択を評価します。1 つはインデックス 0 から始まり、もう 1 つはインデックス 1 から始まります。これは、隣接しない要素を選択するすべてのケースをカバーします。 これらの可能性の中で最大のスコアが出力されます。
