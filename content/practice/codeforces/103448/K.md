 ## 解決策
 ## 問題の理解

 グラフが与えられました$n$頂点のすべてのペアがエッジで接続されている頂点。 これは、任意の重みをもつ標準的な完全なグラフではありません。ほとんどのエッジは頂点の重みに基づく単純なルールに従いますが、エッジのより小さなサブセットには、このルールをオーバーライドする明示的に指定されたコストが伴います。 

各頂点$i$価値がある$a_i$。 異なる頂点の任意のペアに対して$u, v$、そのペアに特別なエッジが提供されていない場合、エッジの重みは次のように定義されます。$\min(a_u, a_v)$。 さらに、入力により、$m$それぞれに重みのある特別なエッジ$w$、これらはそれらのペアのデフォルトのルールを置き換えます。 

タスクは、このグラフに対して最小スパニング ツリーを計算し、その合計の重みと選択したエッジの両方を出力することです。 

問題は完全にグラフのサイズにあります。 まで$5 \times 10^5$完全なグラフには次の頂点が含まれます。$10^{11}$したがって、それを明示的に構築することさえ考えられません。 どのソリューションでも、すべてのペアに対する反復処理を回避する必要があります。 

構造を解釈する便利な方法は、ほとんどのエッジがグローバル ルールによって決定され、少数のエッジだけがそのルールを破るということです。 課題は、MST 関連の構造をすべて維持しながら、暗黙的な完全なグラフを線形または線形に近いサイズに圧縮することです。 

よくある失敗例は、Kruskal を直接のみに適用しようとした場合に発生します。$m$与えられたエッジ。 たとえば、すべてが$a_i$は等しく、特別なエッジはなく、すべてのエッジに重みがあります$a_i$したがって、どのスパニング ツリーも有効であり、合計の重みがあります。$(n-1)\cdot a_i$。 暗黙的なエッジを完全に無視すると、グラフが切断されていると誤って結論付けられてしまいます。 

もう 1 つの素朴なアイデアは、各ノードとグローバル最小ノード間のエッジのみを考慮することです。$a_i$。 これは実際には、暗黙的なグラフだけでは正しいですが、特別なエッジが存在する場合には微妙になります。 特別なエッジは暗黙的なスター エッジよりも安価な場合があるため、含める必要があります。 

本当の問題は、完全なグラフを実体化せずに、密な暗黙的な構造と疎なオーバーライドを組み合わせることです。 

## アプローチ

 制約を無視する場合、最も直接的なアプローチは、すべてを構築することです。$\binom{n}{2}$エッジを作成し、ルールまたはオーバーライドを使用して各重みを割り当て、クラスカルのアルゴリズムを実行します。 MST はエッジ セット全体にわたって定義されているため、これは正しいです。 ただし、エッジの数は 2 次であり、エッジを生成するだけでもすでに実行可能な制限時間を超えています。 

重要な観察は、暗黙的な完全なグラフが非常に剛直な構造を持っているということです。 あらゆるエッジに対応$(u, v)$、その重みは常に次の小さい方になります。$a_u$そして$a_v$。 これは、頂点に属するすべてのエッジのうち、$v$、最も安価な接続は常に最小の頂点への接続です。$a$-価値。 頂点を選択すると$r$最小限で$a_r$、次に頂点ごとに$v$、エッジ$(r, v)$重さがある$a_r$、そしてこれは、$v$。 

これにより、密集したグラフ全体が、中心にある星形に折りたたまれます。$r$暗黙的な部分の MST 結果を変更することなく。 ルート以外の 2 つの頂点間のエッジには少なくとも重みがあります$a_r$なので、それを 2 つのエッジスルーに置き換えます。$r$決してコストが増加することはありません。 

次に、この圧縮された構造の上に特別なエッジを重ねることができます。 グラフは次のものから構成されるものとして扱います。$n-1$からのスターエッジ$r$プラス$m$与えられたエッジを指定し、この削減されたエッジ セットに対して Kruskal を実行します。

 ## アルゴリズムのチュートリアル

 ### 1. 全体的な最小頂点を見つける

 すべての頂点をスキャンしてインデックスを見つけます$r$そのような$a_r = \min a_i$。 この頂点は暗黙的な構造のハブとして機能します。 

### 2. 縮小エッジリストを作成する

 最初にすべての特別なエッジを含むエッジ リストを作成します。$(u, v, w)$入力から。 

頂点ごとに$v \neq r$、エッジを追加します$(r, v)$重さで$a_r$。 これは、可能な限り最良の暗黙的な接続を表します。$v$。 

このステップでは、MST 関連のオプションをすべて維持しながら、密な暗黙的グラフを線形の数のエッジに置き換えます。 

### 3. 縮小されたグラフで Kruskal を実行します。 

収集されたすべてのエッジを重みで並べ替え、DSU 構造を備えた Kruskal のアルゴリズムを適用します。 2 つの異なるコンポーネントを接続するエッジを取得するたびに、それを MST に含めます。 

### 4. 結果を出力する

 選択したエッジの合計重みを出力し、選択したすべてのエッジをリストします。 

### なぜ効果があるのか

 核となる不変条件は、すべての頂点について$v$、最も安価な接続方法$v$それ以下の任意の頂点に$a$-value は特別なエッジまたは単一のエッジによって表されます。$(r, v)$。 特別ではない暗黙的なエッジ$(u, v)$パスに置き換えることができます$u \to r \to v$そのパス上の両方のエッジには最大でも重みがあるため、コストが増加することはありません$\min(a_u, a_v)$。 これにより、注目をスター エッジと特別なエッジに制限することで、考えられるすべての MST 候補が保持されるため、この削減されたセットの Kruskal はグローバルに最適なスパニング ツリーを生成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0]*n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.r[a] < self.r[b]:
            a, b = b, a
        self.p[b] = a
        if self.r[a] == self.r[b]:
            self.r[a] += 1
        return True

n, m = map(int, input().split())
edges = []

special = []
for _ in range(m):
    u, v, w = map(int, input().split())
    u -= 1
    v -= 1
    special.append((w, u, v))

a = list(map(int, input().split()))

r = min(range(n), key=lambda i: a[i])

for w, u, v in special:
    edges.append((w, u, v))

for i in range(n):
    if i != r:
        edges.append((a[r], r, i))

edges.sort()

dsu = DSU(n)

total = 0
res = []

for w, u, v in edges:
    if dsu.union(u, v):
        total += w
        res.append((u, v))
        if len(res) == n - 1:
            break

print(total)
for u, v in res:
    print(u + 1, v + 1)
```Kruskal が重みの増加順にエッジを処理している間、DSU は接続を維持します。 特別なエッジは直接含まれ、暗黙的なエッジはグローバル最小頂点への接続を通じてのみ表現されます。 

微妙な点は、すべての星のエッジの重みが正確に一致していることです。$a_r$、 ない$a_i$。 これは、$\min(a_r, a_i) = a_r$みんなのために$i$、 以来$r$がグローバル最小値として選択されます。

    import sys
    input = sys.stdin.readline

    class DSU:
        def __init__(self, n):
            self.p = list(range(n))
            self.r = [0]*n
        def find(self, x):
            while self.p[x] != x:
                self.p[x] = self.p[self.p[x]]
                x = self.p[x]

        def union(self, a, b):
            a = self.find(a)
            b = self.find(b)
            if a == b:

            if self.r[a] < self.r[b]:
                a, b = b, a
            self.p[b] = a
            if self.r[a] == self.r[b]:

            return True

    n, m = map(int, input().split())

 ## 特殊なケース

 すべての頂点が同一の場合$a_i$、暗黙的なグラフはすべてのエッジに同じ重みを割り当てます。 このアルゴリズムは引き続き単一のルートを選択し、スターを構築します。これは有効です。これは、すべてのスパニング ツリーの総重みが同じであるため、どのツリーも最適です。 

特殊なエッジが 2 つの非ルート頂点を 2 よりも小さいウェイトで接続する場合$a_r$, Kruskal はスターエッジの前にそれを選択し、コンポーネントを早期にマージします。 次に、スター エッジは必要に応じて残りの頂点を接続し、最適性を維持します。 

特殊なエッジが低コストの代替エッジとサイクルを形成する場合、DSU はそのエッジが選択されるのを防ぎ、アルゴリズムが非周期性に違反しないようにしながら、ソートされた順序で考慮します。
