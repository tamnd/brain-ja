 ## 問題の理解

 長さの配列が与えられます$2^n$、初期値は次のように固定されています。$a_i = i$。 したがって、次の整数の完全に順序付けられたシーケンスから始めます。$0$に$2^n - 1$。 その後、このプロセスにより配列サイズが繰り返し縮小されます。$n$ラウンドします。 各ラウンドで、隣接する要素をペアにします$(a_0, a_1), (a_2, a_3), \dots$そして、ビットごとの演算を使用して各ペアを 1 つの値にマージします。 重要な点は、1 ラウンド内ではすべてのペアが同じ操作を使用しますが、ラウンド間で操作が変更される可能性があり、ラウンドごとに操作のシーケンスが与えられることです。 

後$n$四捨五入すると、数値が 1 つだけ残るので、その最終値をバイナリで出力する必要があります。 

制約は完全に次の要因によって駆動されます。$n \le 10^5$これにより、配列全体のシミュレーションが即座に除外されます。 完全なシミュレーションは以下から始まります$2^n$要素、そして最初の層でさえ、意味のあるものはすでに不可能になっています。$n$。 したがって、唯一の実行可能な解釈は、変換を明示的にではなく構造的に理解することです。 

明らかではない問題は、演算は単純なビット単位の演算子であるにもかかわらず、ペアの繰り返しにより再帰的な構造が誘発されることです。 単純な間違いは、マージ ツリーのレベルを明示的に構築しようとすることです。これはすぐに爆発してしまいます。 

たとえば、次の場合$n = 3$、配列は$[0,1,2,3,4,5,6,7]$。 1 回のラウンドで要素が 4 つに半分になり、次に 2、次に 1 になります。ここでも、構造は総当りの計算ではなく、バイナリ分解を示唆しています。 

もう 1 つの微妙なエッジ ケースは、一連の操作が均一である場合、たとえばすべて XOR である場合です。 この場合、結果は高度に構造化され、バイナリ表現のパリティ パターンのみに依存します。これは、ビットごとの位置ごとの独立性を再度示唆します。 

## アプローチ

 ブルート フォース アプローチでは、文字通り各ラウンドをシミュレートします。配列を構築し、隣接する各ペアに操作を適用し、これを繰り返します。 各ラウンドで配列の縮小が処理されるため、総作業量は次のようになります。$2^n + 2^{n-1} + \dots$、依然として支配されています。$2^n$。 これはすぐに不可能になります$n = 25$、ましてや$10^5$。 

重要な観察は、実際には完全な配列が必要ないということです。 すべての値は、固定バイナリ結合パターンを使用して初期インデックスから構築されます。 AND、OR、および XOR はビット間の相互作用なしでビットごとに動作するため、最終的な答えの各要素は入力の各ビット位置に独立して依存します。 

したがって、値を追跡する代わりに、マージ プロセスを通じて各ビット位置がどのように変換されるかを追跡します。 レベルで$k$、サイズのブロックを組み合わせます$2^k$、そしてその演算により、ビットが子から親にどのように伝播するかが決まります。 これにより、問題は深さの完全なバイナリ ツリーの分析に縮小されます。$n$、ここで、葉はインデックスの最初のビットです。 

各ビット位置を個別に処理します。 ビット位置固定の場合$b$、ビットの初期シーケンスを考慮します。$i_b$すべての指数にわたって。 このシーケンスは完全に周期的で構造化されているため、セグメント ツリーのような折り畳み操作を使用して最終結果を計算できますが、これは明示的ではなく概念的に適用されます。 

各演算はビットのペアに対する関数として見ることができ、その関数をインデックスのバイナリ分解を通じて上方に伝播します。 最終的な値は、バイナリ ツリー上でこれらの関数を合成した結果です。

 ## アルゴリズムのチュートリアル

 1. 初期配列は任意ではなく、インデックスによって完全に決定されることを認識します。これは、各ビット位置がマージ プロセスを通じて独立して進化することを意味します。 これにより、値シミュレーションからビットごとの構造解析に切り替えることができます。 
2. プロセスを深さの完全なバイナリ ツリーとして解釈します。$n$ここで、各内部ノードはラウンドに応じて固定のビット演算 (AND、OR、XOR) を適用します。 これは、問題を、再帰的に定義された二項関数のルートの値を計算するものとして再構成します。 
3. 各ビット位置について、葉の入力値が単なるインデックスのバイナリ表現であることを観察します。$k$、ビットのパターンは周期的です$2^{k+1}$。 この規則性が問題を圧縮可能にします。 
4. ビット分布のペアを単一の結果ビットにマッピングする各演算の変換関数を定義します。 AND、OR、および XOR は決定論的なブール関数に対応するため、問題はこれらの関数を上方に伝播することに帰着します。 
5. レベルを下から上に処理し、指定された演算を繰り返し適用することで単一のビット位置がどのように変化するかを維持します。 配列を構築する代わりに、ビット パターンの正規ベースに基づく効果のみを維持します。 
6. すべてのビット位置にわたる効果を組み合わせて、バイナリ形式で最終的な整数を再構築します。 

### なぜ効果があるのか

 重要な不変条件は、ビット単位の演算ではビット位置が混合されず、初期配列がインデックス ビットの決定論的関数であることです。 したがって、プロセス全体が各ビット位置に対する独立した変換に分解されます。 各マージ ステップでは、構造がバイナリ パーティショニングのみに依存する 2 つのサブツリーのみを結合するため、最終的な値は結合によって一意に決定されます。$n$決定的な二項関数が順番に適用されます。 各レベルは完全に構造化されたパーティションを削減するため、現在の機能効果を超える追加の状態は必要ありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def apply(op, a, b):
    if op == 0:
        return a & b
    if op == 1:
        return a | b
    return a ^ b

def solve():
    n = int(input().strip())
    if n == 0:
        print(0)
        return

    ops = list(map(int, input().strip()))

    # We work with the observation that final result is obtained
    # by propagating base patterns through a perfect binary tree.
    #
    # At level 0, leaves represent bits of indices.
    # We track effect on a "unit basis" for each bit position.

    # dp[k] represents effect of k levels on a single bit contribution
    # starting from (0,1,2,... structure), which alternates perfectly.

    # We only need two states per level due to symmetry:
    # even block contribution and odd block contribution.

    # Initialize:
    even = 0
    odd = 1

    # Process operations from bottom to top
    for op in ops:
        new_even = apply(op, even, odd)
        new_odd = apply(op, odd, even)
        even, odd = new_even, new_odd

    # After n levels, the root corresponds to even state
    # of the full interval [0..2^n-1]
    print(format(even, 'b'))

if __name__ == "__main__":
    solve()
```この実装では、完全なバイナリ ツリーが 2 つの標準状態 (各レベルでの偶数インデックスの位置と奇数インデックスの位置の寄与) に圧縮されます。 すべてのマージ ステップでは偶数インデックスと奇数インデックスが一貫した構造でペアになるため、各操作はこれら 2 つの状態を対称的に更新します。 操作シーケンスを反復することにより、ツリーを構築することなくツリーの崩壊を効果的にシミュレートします。 

ルートはインデックス 0 から始まる完全な間隔に対応するため、最終的な答えは偶数状態から取得されます。これは、この表現の偶数パリティ サブツリーと一致します。

 ## 特殊なケース

 いつ$n = 0$、配列には単一の要素があります$a_0 = 0$したがって、操作は適用されず、答えは自明です。$0$。 アルゴリズムは、操作シーケンスを読み取る前にこれを明示的に処理します。 

すべての演算が AND である場合、ゼロビットを含むペアはゼロのままであるため、マージのたびに値がすぐにゼロに向かって縮小されます。 状態表現では、偶数状態と奇数状態の両方がすぐに 0 に収束するため、最終出力は次のようになります。$0$、直接シミュレーションに一致します。 

すべての操作が XOR である場合、パリティは崩壊するのではなく上方に伝播します。 偶数/奇数の対称性はレベルごとに反転し、最終的な値はバイナリ シフトの構造化された累積になります。 XOR は、偶数状態と奇数状態を固定小数点にマージするのではなく、両者の区別を保持する唯一の演算であるため、このアルゴリズムはこれを捉えています。
