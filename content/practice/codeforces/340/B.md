 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、$n$2D デカルト平面内に点があり、これらの点のうち 4 つを選択して、最大面積の四角形を形成するように求められます。 四角形は凸である必要はありませんが、指定された点から 4 つの頂点を持たなければならず、自己交差することはできません。 出力は、達成可能な最大面積を表す単一の実数であり、精度は次のとおりです。$10^{-9}$。 

入力制約は重要です。 と$n$300 までは、考えられるすべての 4 回転をチェックするという単純なアプローチはすでに境界線に達しています。$\binom{300}{4} \approx 6.6 \times 10^7$組み合わせ。 それぞれの組み合わせでは四角形の面積を計算する必要があり、これには基本的な算術演算が必要ですが、これを 6,600 万回繰り返すと、Python の制限時間に近づいてしまいます。 座標は -1000 から 1000 までの範囲にあるため、必要に応じて整数演算で中間ステップを安全に処理でき、浮動小数点のオーバーフローを回避できます。 

明らかではないエッジケースがいくつか存在します。 たとえば、点自体が凸多角形を形成する場合、面積が最大の四角形は、必ずしも隣接する点ではなく、凸包上の点によって形成されます。 もう 1 つのケースは、すべての点がほぼ同一線上にあるものの、わずかな偏差がある場合です。 軸に沿って整列した長方形や単純な順列のみを考慮する不注意なアルゴリズムでは、真の最大値を見逃す可能性があります。 明示的な最小入力の例は、長方形を形成する 4 つの点です。 アルゴリズムは、カウントやソートのヒューリスティックに依存せず、正確な面積を 2D 座標として計算する必要があります。 

## アプローチ

 ブルートフォース手法は簡単です。 すべての四辺形の点を生成し、靴紐の公式を使用して可能な各四辺形の面積を計算し、最大値を追跡することができます。 このアプローチは、どの四角形もその 4 つの頂点によって完全に決定されるため機能しますが、組み合わせ爆発は次の時点で発生します。$O(n^4)$が遅すぎる$n = 300$以来$300^4 \approx 8 \times 10^9$操作。 

重要な洞察は、面積が最大の四角形の場合、通常、少なくとも 1 つの辺が 1 次元の極端な点にまたがるということです。 点の三角形を考慮し、2 つの点と組み合わせたときに面積の合計が最大になる 4 番目の点を選択することで、探索空間を縮小できます。 より簡単で非常に効果的なアプローチは、凸包を利用することです。最大面積を持つ四角形は、その頂点が点の凸包上にある必要があります。 凸包は次のように計算できます。$O(n \log n)$、凸順に候補ポイントを 300 から最大 300 に減らします。 その後、船体に沿ってすべての 4 回転をチェックできますが、これは最悪の場合です。$O(h^4)$、しかし実際には船体のサイズ$h$よりもはるかに小さいです$n$。 制約を考慮すると、Python が通過するにはこれで十分です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^4) | O(n) | n = 300 では遅すぎる |
 | 凸包 + クワッド検索 | O(n log n + h^4) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. まず、入力からポイントを読み取り、タプルとして保存します。$(x, y)$。 注文は便宜上のみ保存されます。 
2. グラハム スキャンやアンドリューのモノトーン チェーンなどの標準アルゴリズムを使用して、ポイントの凸包を計算します。 点を並べ替えてからハルを反復的に構築することで、最大面積の形状を形成できる極端な点のみを考慮することが保証されます。 
3. 凸包ポイントを反時計回りの順序で保存します。 靴紐の式では正しい符号付き領域を計算するために頂点を順番に走査する必要があるため、この順序は重要です。 
4. 見つかった最大領域を追跡するために変数を初期化します。 
5. 凸包点のすべての 4 つを反復処理します。 それぞれの 4 倍について、靴紐の公式を使用して面積を計算します。 四角形は凸面ではない可能性があるため、どちらかの対角線に沿って 2 つの三角形に分割し、面積を合計することができます。 
6. 現在の四角形の面積が以前の最大面積を超えている場合は、最大面積を更新します。 
7. すべての 4 倍が処理された後、最大領域を十分な精度で印刷します。 

機能する理由: 凸包にはすべての極点が含まれています。 内部点を使用する四角形は、内部点をハル ポイントに置き換えることによっていつでも改善できます。したがって、最大面積の四角形はハル上に 4 つの頂点すべてを持つ必要があります。 船体上ですべての 4 回転を繰り返すことで、どの候補も見逃さないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(a, b, c):
    # Compute the cross product AB x AC
    return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])

def polygon_area(quad):
    # Shoelace formula for quadrilateral area
    x1, y1 = quad[0]
    x2, y2 = quad[1]
    x3, y3 = quad[2]
    x4, y4 = quad[3]
    return abs(x1*y2 + x2*y3 + x3*y4 + x4*y1 - y1*x2 - y2*x3 - y3*x4 - y4*x1) / 2

def convex_hull(points):
    points = sorted(points)
    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)
    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)
    return lower[:-1] + upper[:-1]

n = int(input())
points = [tuple(map(int, input().split())) for _ in range(n)]
hull = convex_hull(points)

max_area = 0
h = len(hull)
for i in range(h):
    for j in range(i+1, h):
        for k in range(j+1, h):
            for l in range(k+1, h):
                quad = [hull[i], hull[j], hull[k], hull[l]]
                area = polygon_area(quad)
                max_area = max(max_area, area)

print(f"{max_area:.9f}")
```各セクションはアルゴリズムに直接マッピングされます。 凸包計算により、極値点のみをチェックすることが保証されます。 靴紐の式は凸面と凹面の両方の四角形を処理し、船体全体で四辺形を反復することで、候補を見逃さないことが保証されます。 最小入力 (4 ポイント) のようなエッジ ケースは、ハルが入力セットと等しいため、自然に処理されます。
