 ## 解決策
 ## 問題の理解

 整数のシーケンスが与えられ、その長さが偶数である必要があるという追加の制約付きで、同じ内容を前後に読み取るサブシーケンスを抽出するように求められます。 このようなすべての有効なサブシーケンスの中で、可能な限り長いものが必要であり、その長さと、それを達成する 1 つの具体的なサブシーケンスの両方を出力する必要があります。 

サブシーケンスとは、配列から要素を削除できるが、残っている要素を並べ替えることはできないことを意味します。 回文部分列とは、選択した要素を順番に書くと、その列がその中心に対して対称になることを意味します。 長さが偶数であるという追加の制限は、実際には、中央に一致しない要素を持たずに、中心の周りに等しい値のミラーリングされたペアを構築していることを意味します。 

配列サイズは最大 100000 で、値は大きくなりますが、制限されます。 これにより、部分列またはペアに対する 2 次または 3 次の推論が即座に除外されます。 サブシーケンスの列挙やすべての分割の試行を伴うものはすべて爆発します。 平$O(n^2)$ペアチェックが遅すぎる。 

微妙な制約は、すべての値が少なくとも 2 回出現し、配列がランダムに生成されることです。 これは、私たちが病理学的構造に依存するのではなく、等しい値のペアを使用する単純な周波数駆動の構造に依存することが期待されていることを強く示唆しています。 

素朴だが誘惑しやすい間違いは、等しい値を個別にペアにして、そのようなすべてのペアを任意に連結できると想定することです。 順序が重要であるため、これによりサブシーケンス制約が破られます。 

たとえば、配列が次の場合、`[1, 2, 1, 2]`、ペアリング`1-1`そして`2-2`独立して次のようなものを与えます`1 2 2 1`、これは有効です。 しかし、次のようなもっとインターリーブされた配置があったとしたら、`[1, 2, 3, 1, 3, 2]`、選択した位置の順序を尊重しない場合、不注意なペアリングにより、有効な部分列回文に配置できないインデックスが生成される可能性があります。 

本当の課題は、存在するペアの数を計算することではなく、選択したペアを単一の増加するインデックス シーケンスに確実に埋め込むことができるようにすることです。 

## アプローチ

 ブルートフォースアプローチでは、すべてのサブシーケンスを試し、それぞれが偶数長の回文であるかどうかをテストし、最大長を追跡します。 がある$2^n$後続のチェックと各チェックのコスト$O(n)$、これは完全に不可能になります$n = 40$、ましてや$10^5$。 

より構造化された総当たりのアイデアは、回文チェックと同様に、中心を固定して外側に拡張することです。 サブシーケンスは連続性を必要としないため、これはサブシーケンスではなくサブストリングに対して機能します。 削除が許可されると、拡張ロジックは構造を失い、再び組み合わせ選択を強いられます。 

重要な点は、有効な偶数回文内のすべての要素が、同じ値の別の要素とペアになっている必要があるということです。 したがって、問題全体は、等しい値のペアを選択し、それらをミラーリングされた方法で配置することに帰着します。 これにより、問題はサブシーケンスの選択から、同一の値のインスタンスのペアに変換されます。 

したがって、可能な限り最適な長さは、すべての値にわたって形成できる素のペアの総数の 2 倍になります。 表示される値に対して$f$私たちは貢献できる$\lfloor f/2 \rfloor$ペア。 すべての値を合計すると、ペアの最大数が得られます。 

残りの問題は構築です。長さだけでなく、有効なサブシーケンスを出力する必要があります。 私たちが使用する構造は、配列のスキャン中に貪欲にペアを形成し、サブシーケンスのインデックスの昇順を維持する方法でペアを出力することです。

 ## アルゴリズムのチュートリアル

 配列を処理し、出現位置を使用して等しい値のペアを動的に構築します。 

1. 配列を左から右に走査しながら、値ごとに、出現したがまだペアになっていないインデックスのリストを維持します。 すでに一致しない値が見つかった場合は、その値に対して利用可能な最も古いインデックスを使用して、すぐにペアを形成します。 この貪欲なペアリングにより、素のペアの数が最大化されます。 
2. ペアを形成するたびに、2 つのインデックスを保存します。 フル スキャン全体で、各値が 2 つの出現ごとに 1 つのペアに正確に寄与し、出現を無駄にすることがないため、可能な最大数のペアが生成されます。 
3. すべてのペアが収集されたら、最終的なサブシーケンスを構築します。 各ペアの最初の要素を左半分、2 番目の要素を右半分とします。 
4. ペアを最初のインデックスで並べ替えます。 これにより、左半分が元の配列内で昇順に位置することが保証されます。 
5. 左側のインデックスの値をこの順序で出力し、次に右側のインデックスの値を逆の順序で出力します。 これにより回文が作成されます。 

最初の出現による並べ替えが機能する理由は、構築されたシーケンス内ですべての左側のインデックスが厳密に増加しており、すべての右側のインデックスがそれらの後に逆対称に配置され、有効なサブシーケンスの順序付けが保証されるためです。 

### なぜ効果があるのか

 各ペアは、元の配列内のちょうど 2 つの位置に寄与し、左側のインデックスは右側のインデックスよりも厳密に小さくなります。 ペアを左のインデックスで順序付けすると、すべての左のエンドポイントが増加します。 右端点は、反転すると対称的に整列しますが、構築されたサブシーケンス順序で左半分の後に来る有効な位置に対応します。 これにより、選択されたインデックスのシーケンスが中間点まで厳密に増加し、その後ミラーリングされた後半に割り当てられている間増加し続けることが保証され、サブシーケンスの有効性と回文構造が同時に維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    pos = {}
    pairs = []

    for i, x in enumerate(a):
        if x not in pos:
            pos[x] = []
        pos[x].append(i)

        if len(pos[x]) >= 2:
            j = pos[x].pop()
            i0 = pos[x].pop()
            pairs.append((i0, j, x))

    pairs.sort(key=lambda t: t[0])

    left = [x for _, _, x in pairs]
    right = [x for _, _, x in reversed(pairs)]

    res = left + right

    print(len(res))
    print(*res)

if __name__ == "__main__":
    solve()
```コードは、値ごとにインデックスのスタックを維持します。 2 番目の未使用の出現が現れると、すぐにそれを前の出現と組み合わせます。 この貪欲なペアリングにより、後戻りすることなく最大数の素のペアを抽出できることが保証されます。 

最初のインデックスによるペアの並べ替えは、独立したペアのコレクションをグローバルに一貫したサブシーケンスに変えるステップです。 この順序付けがないと、構築されたシーケンスがインデックスの単調性に違反する可能性があります。 

最後の連結は標準的な回文構造で、左半分に続いて右半分が反転されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |

| スペース | O(n) | ポジションとペアを保存します |

 制約により、最大で$10^5$したがって、線形または線形に近い解決策が必要です。 アルゴリズムは各要素を 1 回処理し、最大で 1 回の並べ替えを実行します。$n/2$これは快適に効率的です。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from sys import stdout

    n = int(data[0])

 ## 特殊なケース

 重要なエッジ ケースは、同じ値の出現が高度に分離され、他の値と交互に配置される場合です。 このような場合でも、ペアリングは値ごとにローカルで行われ、グローバル構造に依存しないため、貪欲ペアリングは引き続き機能します。 

考慮する：```
1 2 1 3 2 3
```アルゴリズムのペア`(1,2)`各値を他の値とは独立して配置します。 値がインターリーブしても、順序は最初のインデックスによるソートによって後で復元されるため、各ペアは依然として有効です。 

もう 1 つのエッジ ケースは、1 つの値が配列を支配する場合です。 例えば：```
5
1 1 1 1 1
```形成されるペアは、`(0,1)`そして`(2,3)`、未使用の要素が 1 つ残ります。 このアルゴリズムは偶数の長さのみを正しく出力し、残り部分は自動的に破棄されます。 

最後のエッジ ケースは最小入力サイズで、ペアが 1 つだけ存在します。 このアルゴリズムは、並べ替えを複雑にすることなく、そのペアを直接出力します。
