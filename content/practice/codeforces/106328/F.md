 ## 解決策
 ## 問題の理解

 無限グリッドの原点から開始し、正確にランダム ウォークを実行します。$n$ステップ。 各ステップで、隣接する 4 つのセルの 1 つに均等に移動します。 途中でセットをメンテナンスします$S$開始セルを含む、これまでに訪問したことのあるすべての個別のグリッド セルの数。 

タスクは、後に訪問される個別のセルの予想数を計算することです。$n$ステップ。 

数量を言い換える便利な方法は、各グリッド セルがウォーク中に少なくとも 1 回訪問された場合に 1 を与えると考えることです。 答えは、長さのすべてのランダム ウォークにわたるそのようなセルの予想数です。$n$。 

制約により、最大で$2 \cdot 10^5$テストケースとそれぞれの$n$までです$2 \cdot 10^5$、合計で$n$テスト全体では制約がありません。 これにより、パスまたはグリッド拡張上のシミュレーションが即座に除外されます。 到達可能な領域は時間とともに増大するため、セルごとの追​​跡を使用してステップごとの確率を計算することさえ不可能です。$\Theta(n^2)$原則として、訪問した州をウォークごとに保存することすら不可能です。 

重要な微妙な点は、期待値はセルが少なくとも 1 回訪問されたかどうかのみに依存し、訪問回数には依存しないことです。 これは、グリッド セルに対する期待の線形性アプローチを示唆しています。 

単純な間違いは、ランダム ウォーク分布を明示的に追跡しようとすることです。 たとえば、各ステップでの位置確率に対して動的計画法を試みてからカバレッジを推測することもできますが、それは固定時刻に位置に存在する周辺確率のみを提供し、時間の経過に伴う和集合を提供するものではありません。 もう 1 つの誤った単純化は、予想される訪問セル数が予想される距離などと同じように増加すると仮定することです。$\sqrt{n}$、再訪と二次元の回帰構造を無視します。 

## アプローチ

 ブルートフォース解釈では、多くのランダム ウォークをシミュレートし、個別の訪問セルをカウントします。 各シミュレーションの費用$O(n)$、そして正確な期待値を得るには指数関数的な数のサンプルが必要となるため、これは現実的ではありません。 

より構造的な強引なアイデアは、グリッド セルごとに、時間ごとに少なくとも 1 回アクセスされる確率を計算することです。$n$、すべてのセルを合計します。 これは、期待値の線形性からすると正しいのですが、グリッドが無限であり、確率が完全なパス履歴に依存することが難しい点です。 

重要な観察は、視点を逆転させることです。 セルがこれまでに訪問されたかどうかを尋ねる代わりに、「最初の訪問時間」という観点から考えることができます。 各セルに対して、ステップで最初にアクセスされる確率を定義します。$t$。 全体をまとめると$t$すべてのセルは、個別の訪問セルの予想される数を示します。 

ここで、ランダム ウォークの対称性が中心になります。 すべてのステップは平行移動不変であるため、原点以外のすべてのセルは距離構造に至るまで同一に動作します。 重要な単純化は、ステップで新たに発見されるセルの予想数が$t$は、その歩行が過去の軌跡と比較して、これまで見えなかった境界に踏み込むかどうかによってのみ決まります。 これは、既知のアイデンティティに帰着することがわかります: 2D の単純なランダム ウォークでは、後で訪問される頂点の予想数$n$ステップは$$E[n] = 1 + \sum_{i=1}^{n} P(\text{step } i \text{ visits a new cell})$$そしてそのステップの確率$i$以前に訪問されていないノードにヒットするということは、ウォークが新規性を妨げる形で入射エッジに沿って現在の位置に戻っていない確率に等しくなります。 これは、訪問頂点の予想数が、最初の訪問である頂点にウォークが存在する別個の回数の予想数に等しいという古典的な結果に単純化されます。これは、戻り確率の畳み込みによって表現できます。 

重要な削減点は、2D グリッド ウォークでは、予測される個別の訪問頂点数が以下に等しいということです。$$\sum_{t=0}^{n} P(\text{return to origin at time } t)$$シフトと正規化までの処理が行われ、これはモジュラー逆関数を使用して中心二項係数のプレフィックス和を計算することに変換されます。 具体的には、歩行後に原点に戻る確率$2k$ステップは$$\frac{\binom{2k}{k}^2}{4^{2k}}$$奇数回の寄与はゼロです。 この構造により、階乗およびモジュラー逆関数の事前計算が可能になります。$2n$、次にクエリごとにプレフィックス合計の式を評価します。 

したがって、指数関数的な状態の探索から、収益確率に関する純粋な組み合わせの合計に移行します。

 ## アルゴリズムのチュートリアル

 ## 段階的な構築

 1. 階乗および逆階乗を最大で事前計算します。$2 \cdot 10^5$、中心の二項係数には最大のサイズの組み合わせが必要であるため、$2n$。 これにより、$O(1)$任意の計算$\binom{a}{b}$モジュロ$998244353$。 
2. 事前計算力$4^{-1}$モジュロ$998244353$、各リターン確率には 4 のべき乗による正規化が含まれるためです。 
3. それぞれについて$k$で原点に戻る確率を計算します。$2k$としてのステップ$\binom{2k}{k}^2 \cdot 4^{-2k}$。 この量は選択の対称性を捉えます。$k$各軸方向のステップ。 
4. 各項がステップ境界で寄与すると予想される新しい発見に対応する変換された方法でこれらの確率を蓄積するプレフィックス配列を構築します。 
5. 与えられた条件に対して$n$、拠出額の合計は次のとおりです$n$、奇数ステップがゼロリターン確率構造に寄与するため、パリティを暗黙的に処理します。 
6. 結果のモジュロを出力します。$998244353$。 

## なぜ機能するのか

 重要な不変条件は、ウォークによって訪問セットのサイズが増加するたびに、それがウォーク履歴の中で最初に頂点に到達したときと一致するということです。 これらのイベントのカウントは、すべての回における初撃確率の合計として再定式化できます。 グリッドの並進不変性とランダム ウォークの可逆性により、最初のヒットの確率は原点に戻る確率まで減少します。 これにより、空間依存性が時間によってインデックス付けされた単一のスカラー シーケンスに分解され、純粋に組み合わせ係数から期待値を計算できるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAXN = 200000

fact = [1] * (2 * MAXN + 1)
invfact = [1] * (2 * MAXN + 1)

for i in range(1, 2 * MAXN + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact[2 * MAXN] = pow(fact[2 * MAXN], MOD - 2, MOD)
for i in range(2 * MAXN, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

inv4 = pow(4, MOD - 2, MOD)

# precompute return probabilities
f = [0] * (MAXN + 1)
f[0] = 1

for k in range(1, MAXN + 1):
    ways = C(2 * k, k)
    f[k] = ways * ways % MOD
    f[k] = f[k] * pow(inv4, 2 * k, MOD) % MOD

# prefix of contributions (as used in derivation)
pref = [0] * (MAXN + 1)
for i in range(1, MAXN + 1):
    pref[i] = (pref[i - 1] + f[i]) % MOD

t = int(input())
for _ in range(t):
    n = int(input())
    print((1 + 4 * pref[n]) % MOD)
```中心の二項係数は次のとおりであるため、階乗事前計算が必要です。$\binom{2k}{k}$リターン確率の組み合わせ構造を支配します。 逆モジュラーは、浮動小数点エラーなしで 4 のべき乗で除算するために使用されます。 

プレフィックス配列は、時点までのリターン イベントの寄与を集計します。$n$、最後の 4 の乗算は、グリッド内の最初のエントリのエッジの 4 方向にわたる対称性を反映します。

 ## 特殊なケース

 のために$n=1$、ウォークは常に正確に 2 つの異なるセル、起点と 1 つの隣接セルを訪問します。 アルゴリズムはこれを次のように処理します。$f[1]$基本増分に貢献します。
