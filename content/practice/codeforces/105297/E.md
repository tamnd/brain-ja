 ## 解決策
 ## 問題の理解

 ノードが発電所を表し、エッジが考えられる伝送ルートを表す、接続された無向グラフが与えられます。 各ルートには、時間の二次関数に従って時間の経過とともに変化するコストがあります。$t$、 具体的には$a t^2 + b t + c$。 あらゆる決まった瞬間に$t$、すべてのエッジには具体的な非負の重みがあり、タスクはその時点での最小スパニング ツリーの重みを計算することです。 

ねじれは、答えが単一の固定時間に対して要求されるのではなく、すべての実際の値に対して要求されることです。$t$。 MST 重みの可能な最小値を次のように見つける必要があります。$t$すべての実数にわたって連続的に変化します。 

制約はグラフ サイズの点で小さく、最大でも 100 個のノードと 200 個のエッジです。 これにより、多くの候補回数にわたってエッジごとに大量の再計算を必要とするアプローチが即座に排除されます。 ただし、継続的な性質により、$t$が本当の難しさです。 MST 構造は、エッジの重み比較が変化する場合にのみ変化します。これは、二次関数が交差する場合に発生します。 

複数のエッジが同一のコスト関数を持つ場合、または最適な MST がエッジ ウェイト カーブの交点で正確に変化する場合、微妙なエッジ ケースが発生します。 たとえば、ある時点で 2 つのエッジの順序が入れ替わる場合、$t$、整数値をサンプリングするという素朴なアイデア$t$失敗します:

 入力:```
2 2
1 2 1 0 0
1 2 0 0 1
```で$t = 0$、両方のエッジのコストは 0 と 1 ですが、大きい場合は$t$、最初のものが支配的になります。 すべてにおいて真のミニマム$t$は、サンプリングではなく、MST 構造が変化したときの正確な追跡に依存します。 

もう 1 つの重要なケースは、単一のエッジ置換によって最適な MST が徐々に変化し、最適な時間がちょうど 2 つの二次関数の交点にある場合です。これは非整数である可能性があり、正確な計算が必要です。 

## アプローチ

 の値を固定すると、$t$の場合、問題は、その時点で評価されるエッジの重みを使用した標準的な最小スパニング ツリーの計算になります。 これは、ブルートフォース戦略を示唆しています。つまり、多くの値をサンプリングします。$t$、それぞれに対して Kruskal または Prim を使用して MST を計算し、最小の結果を取得します。 各 MST は固定ごとに明確に定義されているため、これは原理的には正しいです。$t$、そのようなすべての時間にわたって、答えは最小になります。 

問題は、関連するスペースが$t$値は連続的です。 MST 構造は、2 つのエッジの順序が変更された場合にのみ変更されます。これは、次の形式の方程式の根で発生します。$$a_i t^2 + b_i t + c_i = a_j t^2 + b_j t + c_j.$$これは二次方程式であるため、エッジの各ペアは最大 2 つの候補遷移点を生成します。 任意の 2 つの連続するこのようなポイント間では、MST 構造は一定であるため、MST の重みは次の関数として変化します。$t$は、これらのイベントによって決定される間隔にわたる凸の区分関数です。 

これにより、問題は、エッジ ペアの交差から導出される臨界点、および場合によっては無限境界でのみ MST を評価するようになります。 エッジは最大で 200 個あるため、ペアは最大で約 40,000 個、したがって臨界点の候補は約 80,000 個になります。 特に N が小さいため、それらを並べ替えて各間隔境界で MST を評価することは実現可能です。 

ただし、時間の経過に伴う MST の重みが、スパニング ツリーによって引き起こされる凸関数のファミリーの最小値であることを観察することで、より良い結果を得ることができます。 各スパニング ツリーは、次の 2 次関数を定義します。$t$、すべてのスパニング ツリーにわたって最小値が必要です。 ツリーを列挙する代わりに、固定されたツリーに対して次のことが行われるという事実を利用します。$t$、MST は貪欲に計算でき、最適な値は$t$は、選択された MST が変化する時点、つまり、クラスカル順序で入れ替わる可能性のある 2 つのエッジの交差イベントで達成されます。 

したがって、エッジ ペアの等価性からすべての候補イベント時間を計算し、並べ替えて、各イベントおよびイベント間の中間点で MST を評価します。

 ## アルゴリズムのチュートリアル

 連続的な最適化を候補評価点の離散セットに変換します。 

1. エッジのペアごとに、次の式を解いて重みが等しい時間値を計算します。$$(a_i - a_j)t^2 + (b_i - b_j)t + (c_i - c_j) = 0.$$それぞれの有効な実ルートは、エッジの順序が変更される可能性がある候補時刻です。 これが必要なのは、そのような点でのみエッジのクラスカル順序が変化する可能性があるためです。 
2. 有効な実ルートをすべて収集し、複雑な解と重複を破棄します。 非常に大きな負の時間や正の時間など、いくつかのセンチネル値も含めます。 これにより、すべての間隔が確実にカバーされます。 
3. すべての候補時間を並べ替えます。 これらは、エッジの順序が固定される実線上の間隔を定義します。 
4. 間隔ごとに、代表値 (通常は連続する候補間の中間点) を選択し、その時点でのエッジの重みを評価します。 
5. 選択した時間ごとに、その時点で評価されたエッジの重みを使用して Kruskal のアルゴリズムを使用して MST を計算します。 
6. すべてのテスト時間にわたる最小 MST コストを追跡します。 

### なぜ効果があるのか

 固定の場合$t$, MST は重みによるエッジの順序のみに依存します。 各エッジの重みは二次関数であるため、2 つのエッジ間の順序は等式の根でのみ変更できます。 連続するルート間では、すべてのエッジの順序が固定されているため、Kruskal はその区間全体で同じ MST 構造を生成します。 したがって、MST の重みは次の関数として表されます。$t$は各間隔内では一定であり、間隔の境界でのみ変更できます。 間隔ごとに代表点を評価すると、考えられるすべての個別の MST 値が取得されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def solve():
    N, M = map(int, input().split())
    edges = []
    
    for _ in range(M):
        x, y, a, b, c = map(int, input().split())
        edges.append((x - 1, y - 1, a, b, c))
    
    events = set()

    # collect candidate transition points
    for i in range(M):
        x1, y1, a1, b1, c1 = edges[i]
        for j in range(i + 1, M):
            x2, y2, a2, b2, c2 = edges[j]
            
            A = a1 - a2
            B = b1 - b2
            C = c1 - c2
            
            if A == 0 and B == 0:
                continue
            
            if A == 0:
                # linear equation Bt + C = 0
                if B != 0:
                    t = -C / B
                    events.add(t)
                continue
            
            D = B * B - 4 * A * C
            if D < 0:
                continue
            
            sqrtD = math.sqrt(D)
            t1 = (-B - sqrtD) / (2 * A)
            t2 = (-B + sqrtD) / (2 * A)
            
            events.add(t1)
            events.add(t2)
    
    events = sorted(list(events))
    
    def kruskal(t):
        parent = list(range(N))
        rank = [0] * N
        
        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x
        
        def union(a, b):
            ra, rb = find(a), find(b)
            if ra == rb:
                return False
            if rank[ra] < rank[rb]:
                ra, rb = rb, ra
            parent[rb] = ra
            if rank[ra] == rank[rb]:
                rank[ra] += 1
            return True
        
        def weight(e):
            x, y, a, b, c = e
            return a * t * t + b * t + c
        
        sorted_edges = sorted(edges, key=weight)
        
        total = 0
        cnt = 0
        for e in sorted_edges:
            if union(e[0], e[1]):
                total += weight(e)
                cnt += 1
                if cnt == N - 1:
                    break
        return total
    
    INF = 1e18
    times = events[:]
    
    if not times:
        times = [0.0]
    
    ans = float('inf')
    
    # check midpoints of intervals
    for i in range(len(times) + 1):
        if i == 0:
            t = times[0] - 1 if times else 0
        elif i == len(times):
            t = times[-1] + 1
        else:
            t = (times[i - 1] + times[i]) / 2
        
        ans = min(ans, kruskal(t))
    
    print("%.10f" % ans)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず、2 つのエッジの順序が変更される可能性のあるすべての潜在的なブレークポイントを構築します。 これらは、ペアごとの 2 次等式を解くことによって計算されます。 このような各時間は、エッジの順序が固定されている領域間の境界として扱われます。 

Kruskal 関数は、一定時間の MST を再計算します。$t$、各エッジの重みを動的に評価します。 計算された重み関数によってエッジを並べ替えることで、その特定の時間の正確性が保証されます。 

最後に、各間隔内では順序が安定しているため、イベント時間間の各間隔の代表点で MST を評価します。 

実装の微妙な詳細は、浮動小数点の安定性です。 交差時間は非合理的な場合があるため、比較は倍精度に依存しますが、問題の許容範囲を考慮するとこれで十分です。

 ## 特殊なケース

 エッジ ケースの 1 つは、すべてのエッジが同一の 2 次関数を持つ場合です。 この状況では、すべてのエッジ ペアの等価性がすべてのエッジ ペアに当てはまります。$t$、意味のあるイベントポイントは生成されません。 このアルゴリズムは、MST を 1 回評価するだけで正しく実行され、Kruskal は一貫して同じコストの有効なスパニング ツリーを選択します。 

もう 1 つのケースは、2 つのエッジが 1 回だけ交差し、単一のイベント ポイントを作成する場合に発生します。 たとえば、一方のエッジが改善している一方で、もう一方のエッジが悪化している場合、スワップ ポイントによってタイムラインが 2 つの間隔に分割されます。 両側の中間点を評価すると、両方の MST 設定が確実に考慮され、スワップ全体のグローバル最小値が取得されます。 

最後の微妙なケースは、単一のペアごとのエッジ スワップがすべての順序にグローバルに影響を与えることなく、最適な MST が変化する場合です。 その場合でも、MST の変更には少なくとも 1 つのエッジが MST に出入りする必要があり、これは構築されたイベント セットによってキャプチャされた比較反転を意味します。
