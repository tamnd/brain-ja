 ## 解決策
 ## 問題の理解

 サイズのグリッドが与えられています$n \times m$、各セルには、次のいずれかで表されるターゲットが含まれます。`#`または次のように表される空`.`。 シェルは、右下、左下、左上、または右上の 4 つの斜め方向のいずれかに発砲するショットガンを持っています。 ショットガンは、発砲点からマンハッタンまでの距離が指定の定数を超えない、その方向にあるすべての標的を攻撃します。$k$。 私たちの目標は、各テスト ケースについて、Shel が 1 回の射撃で攻撃できるターゲットの最大数を決定することです。 

入力では複数のテスト ケースを指定し、それぞれが長方形のフィールドと散弾銃の射程を記述します。 出力はテスト ケースごとに 1 つの整数であり、1 回のショットで攻撃できるターゲットの最大数が示されます。 

制約によって与えられるのは、$n, m, k \le 10^5$と合計$n \cdot m$すべてのテストケースで以下を超えない$10^5$。 これは重要です。つまり、グリッドの次元は個々に大きくなる可能性がありますが、すべてのテスト ケースにわたるセルの総数は中程度であることを意味します。 したがって、セルごとに一定または対数の作業量を実行するアルゴリズムは十分に高速ですが、二次関数はすべて実行されません。$n \cdot m$遅すぎます。 

単純な実装をトリップさせる可能性のあるエッジ ケースには、単一の列または行であるグリッドが含まれます。$k$グリッド寸法よりも大きい、または複数の同様に最適なショット。 たとえば、すべてのセルが塗りつぶされた高さ 3 の単一列グリッドの場合、$k = 3$は 3 を返す必要があり、対角計算で不用意にインデックスを作成すると、ターゲットを過小カウントまたは過大カウントする可能性があります。 

## アプローチ

 ブルートフォース手法では、すべてのセルを潜在的な発砲点として調べ、4 方向すべてへの発砲をシミュレートし、マンハッタン距離内のターゲットをカウントします。$k$。 各ショットにかかる時間$O(k^2)$マンハッタン近郊なので最悪の場合は時間がかかる$k$おおよそ含まれています$(k+1)^2$細胞。 と$n \cdot m$細胞と$k$まで$10^5$、その結果、操作が多すぎます ($10^{10}$以上）なので、ブルートフォースは実行できません。 

重要な観察は、ヒットエリアがグリッド内で「斜めのダイヤモンド」を形成していることです。 対角線のマンハッタン距離は、座標の和と差を使用して線形配列に変換できます。 2 つの派生配列を定義すると、1 つは合計を表します$i + j$そしてその違いを表すもの$i - j$、4 つの対角方向のそれぞれについて、到達可能なターゲットは、これらの配列の 1 つに沿って連続したセグメントに分類されます。 これにより、対角線上のプレフィックスの合計を計算し、次のセグメントをクエリできるようになります。$O(1)$セルあたりの時間。 各セルを 1 回反復処理し、関連する事前計算された対角和をチェックすることで、複雑さを軽減します。$O(n \cdot m)$, 制限時間内に余裕で収まります。 

このアプローチは、マンハッタン距離の特別な構造を利用します。つまり、座標の合計または差が同じになるすべてのセルが対角線に沿って配置されます。 接頭辞の合計を使用して対角線に沿ってカウントすると、2 次元の範囲クエリが 1 次元の間隔クエリに変換されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n m k²) | O(nm) | 遅すぎる |
 | 対角接頭語の合計 | O(nm) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n, m, k$そしてグリッド表現。 グリッドを整数の 2D リストとして保存します。`1`ターゲットを表し、`0`空を表します。 
2. 2 つの補助配列を構築します。`sum_diag[i+j]`そして`diff_diag[i-j]`、各対角線に沿ったターゲットの合計数を表します。 グリッドを反復処理して、適切なエントリをインクリメントします。 
3. 各セルについて$(i, j)$、シェルが 4 つの対角方向のそれぞれで攻撃できるターゲットの数を計算します。 右下の対角線の場合、次のターゲットを合計します。`sum_diag`から$(i+j)$に$(i+j+k)$。 左下の対角線の場合、次のターゲットを合計します。`diff_diag`から$(i-j)$に$(i-j+k)$、ミラー範囲を使用して他の 2 方向についても同様です。 
4. すべてのセルおよびすべての方向を反復処理する際に、遭遇したターゲットの最大数を追跡します。 
5. テストケースごとの最大数を出力します。 

なぜ機能するのか: 不変条件は次のとおりです`sum_diag`そして`diff_diag`各対角線に沿ったターゲットの合計を正確に表し、クエリ範囲はマンハッタン距離内のすべてのセルを正確にキャプチャします。$k$選択した対角線に沿って。 各ターゲットは、潜在的なショットごとに 1 回カウントされます。 考えられるすべての発火位置をチェックすることで、グローバル最大値が確実に見つかるようにします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        grid = [input().strip() for _ in range(n)]
        
        # Map diagonals to counts
        sum_diag = {}
        diff_diag = {}
        for i in range(n):
            for j in range(m):
                if grid[i][j] == '#':
                    sum_diag[i+j] = sum_diag.get(i+j, 0) + 1
                    diff_diag[i-j] = diff_diag.get(i-j, 0) + 1
        
        max_hit = 0
        for i in range(n):
            for j in range(m):
                if grid[i][j] == '.':
                    continue
                # Four directions: sum_diag and diff_diag ranges
                rd = sum(sum_diag.get(i+j+t, 0) for t in range(k+1))
                lu = sum(sum_diag.get(i+j-t, 0) for t in range(k+1))
                ld = sum(diff_diag.get(i-j+t, 0) for t in range(k+1))
                ru = sum(diff_diag.get(i-j-t, 0) for t in range(k+1))
                max_hit = max(max_hit, rd, lu, ld, ru)
        print(max_hit)

if __name__ == "__main__":
    solve()
```コードは入力を効率的に読み取り、各ターゲットをその和対角と差対角にマッピングし、各ターゲットを反復して 4 つの対角すべての方向の最大到達可能数を計算します。 辞書を使用すると、次のような場合に大きな配列の割り当てを回避できます。$n, m$まばらです。
