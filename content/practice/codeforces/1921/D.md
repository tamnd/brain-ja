 ## 問題の理解

 配列があります`a`長さの`n`。 別の配列`b`含まれています`m`値、ここで`m`少なくとも`n`。 

正確に選択することができます`n`からの要素`b`、選択した要素を任意の順序で配置して新しい配列を形成します`c`。 目標は最大化することです$$\sum_{i=1}^{n} |a_i - c_i|.$$タスクは、この合計の可能な最大値を見つけることです。 

最初の観察は、選択された要素の最終的な順序が完全に制御下にあるということです。 順序を維持することは強制されません`b`。 これにより、問題はマッチング問題に変わります。`n`から値を取得する必要があります`b`、そしてそれらを の値とどのように組み合わせるべきか`a`?

 制約が十分に大きいため、二次アルゴリズムや三次アルゴリズムは不可能です。 すべてのテスト ケースの合計サイズは、`b`せいぜい`2 \cdot 10^5`、だから、`O(m log m)`テストケースごとのソリューションは完全に許容されますが、次のようなものは`O(nm)`最悪の場合は遅すぎるでしょう。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

考慮する```

a = [1, 1, 1]
b = [1, 1, 1, 1]
```考えられるあらゆる選択が違いを生みます`0`。 何らかのプラスの寄与が常に存在することを前提とする貪欲な戦略は、ここでは失敗します。 

考慮する```

a = [5, 100]
b = [1, 2, 99, 100]
```常に世界最小または世界最大の残りの値を採用することによって最良の答えが得られるわけではありません。 立場が異なれば、反対の極端を好む場合もあります。 

考慮する```

課題は、小さい値と大きい値の正しい組み合わせを見つけることです。

 ## アルゴリズムのチュートリアル

 1. 並べ替え`a`減少しない順序で。 
2. 並べ替え`b`減少しない順序で。 
3. 事前計算$$L_i = |a_i - b_i|$$の最初の要素が`a`の左端から取得した値と一致します。`b`。 

1. 事前計算$$R_i = |a_i - b_{m-n+i}|$$の要素が存在する場合`a`の右端から取得した値と一致します。`b`。 

1. プレフィックスの合計を構築する`L`。 
2. サフィックスの合計を構築する`R`。 
3. あらゆる人にとって`k`から`0`に`n`、まさにそれを仮定します`k`値はsortedの左側から取得されます。`b`。 
4. それらの貢献`k`ペアは、次のプレフィックスの合計から取得されます。`L`。 
5. 残りの者の貢献`n-k`ペアは、次の接尾辞の合計から得られます。`R`。 
6. すべての選択肢の最大値を取得します。`k`。 

これが機能する理由は、一度`k`が固定されると、選択された要素が完全に決定されます。 我々が最初を取る`k`ソートされた値`b`そして最後`n-k`ソートされた値`b`。 ソートされた配列の最適なペアリングは、対極の一致から直接得られます。 

### なぜ効果があるのか

 ソート後、最適なソリューションは両端の要素のみを使用します。`b`。 選択された内部要素が使用されているときに未使用の極値が存在する場合、内部要素を極値で置き換えても、関連するすべての絶対差が増加または保存されるだけです。 

値を修正する`k`。 選択されたセットは最初のセットで構成されます。`k`要素と最後`n-k`ソートされた要素`b`。 

左側のブロックでは、選択した最大値を最小値と組み合わせる必要があります。`a`、プレフィックス部分によって表される寄与を生成します。 

右側のブロックでは、選択した最小値を最大値と組み合わせる必要があります。`a`、接尾辞部分によって表される寄与を生成します。 

実行可能なすべての最適解は、次の 1 つの値に正確に対応します。`k`となり、数式はその選択に対する最適な値を評価します。 全体的に最大限のことを考える`k`考えられるすべての最適な構造を検討します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n, m = map(int, input().split())

        a = sorted(map(int, input().split()))
        b = sorted(map(int, input().split()))

        pref = [0] * (n + 1)
        for i in range(n):
            pref[i + 1] = pref[i] + abs(a[i] - b[i])

        suff = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            suff[i] = suff[i + 1] + abs(a[i] - b[m - n + i])

        ans = 0

        for k in range(n + 1):
            ans = max(ans, pref[k] + suff[k])

        print(ans)

solve()
```両方の配列を並べ替えた後、ソリューションは 2 つの累積配列を構築します。`pref[k]`最初のときに取得された合計貢献度を格納します。`k`の要素`a`最初のものと一致します`k`の要素`b`。`suff[k]`ポジションからの貢献を保存します`k`を通して`n-1`これらの要素が右端の要素と一致する場合`n-k`の値`b`。 

固定スプリットポイントの場合`k`、左側の部分はから来ています`pref[k]`そして右側の部分は次のとおりです`suff[k]`。 それらを追加すると、並べ替えられた要素の左側からいくつの要素が取得されるかという特定の選択に対する答えが得られます。`b`。 

全体にわたるループ`k`考えられるすべての分割をチェックし、最大の結果を保持します。 

すべての算術演算では Python 整数が使用され、可能な最大の答えよりもはるかに大きな値を安全に処理します。
