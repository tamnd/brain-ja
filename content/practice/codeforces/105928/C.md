 ## 解決策
 ## 問題の理解

 大きな長方形のチェス盤と 1 つの開始マスが与えられます。 ナイトと呼ばれる駒は一般的な方法で移動できます。どのマスからでも、目的地がボード内にある限り、一方の軸に k ステップ、もう一方の軸に 1 ステップ、またはその逆にジャンプできます。すべての符号のバリエーションが含まれます。 

開始位置からこれらの動きを繰り返し適用し、一連の有効なジャンプによって到達できるすべてのマス目を検討します。 タスクは、この到達可能なセットに属する n × m グリッド内の個別の正方形の数を数えることです。 

制約は非常に大きく、ディメンションは最大 10^9、テスト ケースは最大 10^5 です。 これにより、ボード上のシミュレーションやグラフの走査が即座に排除されます。 セルごとの処理に依存するアルゴリズムではボード サイズが事実上制限されないため、訪問した状態を保存することさえ不可能です。 

唯一の実行可能な解決策は、明示的な探索ではなく、運動グラフの構造特性に依存する必要があります。 

いくつかのエッジな状況では、対処を誤ってしまいがちです。 

k が 1 に等しい場合、ピースはダイアゴナル ウォーカーに退化します。 (3,3) のような正方形からは、すべての動きは同じ対角線上 (4,4)、(5,5) などに強制的に留まるか、逆方向に後退することになります。 これは、到達可能なセットが 2 次元領域ではなく、直線セグメントであることを意味します。 ピースが常に大きな接続された領域を満たすという単純な仮定は、ここでは失敗します。 

k が 2 以上になると、挙動が大きく変わります。 たとえば、k = 2 の場合、大きなボード上での標準的なナイトの動きは、駒を線や薄い構造に限定しません。 到達可能領域は、主にパリティ条件によって制約される大きな連結成分に拡張されます。 線形または 1 次元の到達可能性を依然として前提としているソリューションでは、過大評価または過小評価が行われます。 

## アプローチ

 ブルートフォース手法では、各セルがノードでエッジが有効なナイトの動きに対応するグラフとしてボードをモデル化します。 開始ノードから BFS または DFS を実行し、訪問したノードをカウントします。 

これは原理的には正しいです。各移動によって到達可能性が維持され、BFS は接続されたコンポーネントを正確に探索するからです。 問題は規模だ。 ボードには最大 10^18 個のセルを含めることができるため、1 回の走査さえ不可能です。 ノードあたりのエッジの数は一定ですが、ノードの数が法外に多くなります。 

重要な観察点は、グラフ構造が非常に規則的であるということです。 すべての動きは、4 つのベクトル (k, 1)、(k, -1)、(1, k)、(1, -k) およびその負のベクトルのいずれかによる変換です。 これにより、グリッドが格子グラフに変わります。 k ≥ 2 の場合、この格子は十分に豊富であるため、到達可能なセットはチェス盤の色の色ごとに 1 つの完全な連結成分を形成します。 言い換えれば、到達可能性は x + y のパリティのみに依存します。 

これにより、問題は、巨大なグラフの探索から、開始正方形と同じパリティを共有する長方形内の正方形の数を単に数えるという問題に分解されます。 

例外が 1 つあります: k = 1。その場合、両方の移動タイプの大きさは同じになり、モーションは対角線に沿った移動になります。 グラフは独立した対角チェーンに縮退するため、到達可能性は密なコンポーネントではなく 1 つの線分になります。

 ## アルゴリズムのチュートリアル

 ### k = 1 件

1. (1,1) および (1,-1) スタイルのステップは x と y を一緒に変化させ続けるため、動きを厳密に斜めの動きとして解釈します。 これは、x − y が 1 つの移動方向に沿って不変であることを意味します。 
2. 開始正方形から、到達可能な領域は、(i, j) を通る対角線とボードの正確な交点です。 
3. ボードの境界に当たるまで、この対角線に沿って両方向に移動します。 
4. 4 つの境界内に同時に収まる整数ステップの数を数えます。 

これにより、(1,1) および (-1,-1) 方向に可能な限り拡張され、グリッドの制限によってクリップされます。 

### k ≥ 2 の場合

 1. すべての動きが両方の座標を変更するため、ボードは (x + y) mod 2 による標準の色付けの下で 2 部構成のままであることを観察します。 
2. k ≥ 2 の場合、移動セットはグリッド コンポーネント内の同じパリティのすべての正方形を接続するのに十分な量であるため、到達可能性は x + y が開始セルと同じパリティを持つかどうかにのみ依存することを示します。 
3. n × m グリッド内のいくつのセルが (i + j) のパリティに一致するかを計算します。 
4. そのカウントを返します。 

パリティ セルの数は、グリッド領域が偶数か奇数かによってのみ決まります。 nm が偶数の場合、両方のパリティが同じ頻度で表示されます。 nm が奇数の場合、(1,1) から始まるチェッカーボードがそこに偶数パリティを割り当てるため、1 つのパリティがもう一度正確に表示され、セル (1,1) のパリティになります。 

### なぜ効果があるのか

 k ≥ 2 の場合、移動グラフは無限グリッド上の各 2 部クラス内で強く結合されます。 境界は、追加のコンポーネントを作成せずに、この構造を切り詰めるだけです。 すべての移動はパリティを維持し、移動セットはコンポーネント内で同じパリティのすべての位置を生成するのに十分であるため、(x + y) mod 2 を超える算術不変式は存在しません。k = 1 の場合、追加の不変式が表示されます。x − y は一定のままで、グラフが独立した対角線に折りたたまれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        k, n, m, i, j = map(int, input().split())

        if k == 1:
            # diagonal walk: x - y invariant
            up_left = min(i - 1, j - 1)
            down_right = min(n - i, m - j)
            ans = up_left + down_right + 1
            print(ans)
        else:
            total = n * m

            # count of even cells in grid (1,1) is even
            even = (total + 1) // 2
            odd = total // 2

            # parity of starting cell
            if (i + j) % 2 == 0:
                print(even)
            else:
                print(odd)

if __name__ == "__main__":
    solve()
```k = 1 の分岐は、唯一利用可能な幾何学的構造である対角線に沿って明示的に展開されます。 境界は、2 つの対角方向の各境界までの最小距離を取ることによって対称的に処理されます。 

k ≥ 2 の場合、ソリューションはジオメトリを完全に無視し、パリティ分類に依存します。 唯一の微妙な点は、グリッド パリティの分布は開始点ではなく n と m のみに依存するのに対し、答えは開始正方形が多数パリティ クラスにあるか少数パリティ クラスにあるかによって決まることです。 

## 実用的な例

 k = 2 で (2,2) から始まる 3 × 3 ボードを考えてみましょう。 ボードには 9 セルがあるため、パリティ数は 5 と 4 です。 

| ステップ | n | メートル | 私 | j | 合計 | 偶数 | 奇数 | パリティ(i+j) | 答え |
 | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
 | 初期化 | 3 | 3 | 2 | 2 | 9 | 5 | 4 | 偶数 | 5 |

 これは、答えが手の幾何学には依存せず、パリティのみに依存することを示しています。 

ここで、(2,3) から始まる 4 × 5 ボード上の k = 1 を考えてみましょう。 

| ステップ | 私 | j | 左上 | 右下 | 結果 |
 | --- | --- | --- | --- | --- | --- |
 | 初期化 | 2 | 3 | 1 | 2 | 4 |

 到達可能な対角セグメントには 4 つのセルがあります: (1,2)、(2,3)、(3,4)、(4,5)。 

これは、動きが 1 次元であり、境界によって完全に制限されていることを確認します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    def solve():
        t = int(input())
        for _ in range(t):
            k, n, m, i, j = map(int, input().split())

            if k == 1:
                up_left = min(i - 1, j - 1)
                down_right = min(n - i, m - j)
                print(up_left + down_right + 1)
            else:
                total = n * m
                even = (total + 1) // 2
                odd = total // 2
                print(even if (i + j) % 2 == 0 else odd)

    solve()
    return sys.stdout.getvalue().strip()

# corner start parity difference
assert run("1\n2 3 3 1 1\n") == "5", "corner parity case"

# single row

 ## 特殊なケース

 k = 1 の場合、n = 10、m = 10、i = 1、j = 1 などの細い対角線の状況を考慮します。アルゴリズムは up_left = 0 および down_right = 9 を計算し、10 個の到達可能な正方形を与えます。 すべての移動で x − y が維持されるため、駒が対角線から離れることはなく、他の正方形に到達することはできません。 

1 × m または n × 1 グリッド上の k ≥ 2 の場合、すべての移動は直ちに無効になります (まったく移動しない場合を除く)。 パリティ カウントでは、開始正方形がそのパリティ クラス内の唯一の有効なセルであるかどうかに応じて 1 または 0 が返されるため、アルゴリズムは引き続き機能します。 実際には、グリッド内に収まる動きはないため、開始セルのみに到達できます。これは、このような縮退した長方形のパリティ ベースのカウントと一致します。 

非常に大きなグリッド上の k ≥ 2 の場合、n と m が最大 10^9 の場合でも、計算は nm と (i + j) の算術パリティのみに依存し、オーバーフローや座標探索を完全に回避するため、安定したままになります。
