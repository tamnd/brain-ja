 ## 問題の理解

 [
 f(i)=b(f(a_i))。 
】

なぜなら`a`そして`b`は順列であり、それらの関数グラフは完全に素な有向サイクルで構成されます。 これは、一般的な関数構成の問題よりも問題をはるかに簡単にする構造的な特性です。

## アプローチ

 直接的な総当たりアプローチは概念的に単純です。 (m^n) 個の可能な関数のそれぞれに対して、ターゲット値をそれぞれの関数に割り当てます。`n`ソースの位置を確認し、すべてをチェックします`n`方程式。 これは正しいです。考えられるすべての関数が考慮され、すべての方程式を満たす関数のみがカウントされるからです。 

問題は候補者の数だ。 (n=m=10^5) の最悪のケースでは、ブルート フォースは次のことを考慮します。 

[
 100000^{100000}
 】

 さまざまな関数があり、各候補をチェックするには (100,000) 方程式の評価が必要になる場合があります。 それは

 [
 100000\cdot100000^{100000}
 】

 基本的なチェックですが、これは実行可能な限界をはるかに超えています。 

重要な観察は、制約が任意のソース位置を結合していないことです。 サイクルに沿ってポジションを結合します。`a`。 の 1 サイクルを想定します。`a`長さがある`L`、ある位置から開始`x`:

 [
 x,\ a(x),\ a^2(x),\ldots,a^{L-1}(x)。 
]

一度`f(x)`が選択されると、方程式によって次の値が決まります。`f`このサイクルの 1 つおきの位置で。 唯一の問題は、戻ったときに割り当てが一貫しているかどうかです。`x`。 

サイクル全体に方程式を適用すると、次のようになります。 

[
 f(x)=b^L(f(x))。 
]

したがって`f(x)`正確な後に自分自身に戻るターゲット値でなければなりません`L`の応用`b`。 その目標値が次のサイクル内にある場合、`b`長さの`d`、その後、(b^L) は正確にそれを修正します

 [
 d\mid L.
 】

 仮定してください`b`(c_d) 個の長さのサイクルが含まれます`d`。 このようなサイクルはすべて貢献します`d`考えられる選択肢`f(x)`、そのいずれかが`d`要素は (b^L(y)=y) を満たします。 したがって、長さのソースサイクル`L`持っています

 [
 \sum_{d\mid L} d,c_d
 】

 有効な割り当て。 

さまざまなサイクル`a`独立しています。 1 つのソース サイクルの値を選択しても、他のソース サイクルには影響しないため、最終的な答えは、すべてのサイクルにわたるこれらの量の積になります。`a`。 

残りのタスクは、これらの約数の合計を効率的に計算することです。 のサイクル長を数えることができます。`b`一度。 次に、ソースサイクル長ごとに、`L`、(O(\sqrt L)) 時間で約数を列挙します。 ソースのサイクル長の合計は次のようになりますので、`n`、総除数検索作業は次のように制限されます。 

[
 \sum_i O(\sqrt{L_i})
 \le O\left(\sqrt{k\sum_i L_i}\right)
 \le O(n)、
 】

 どこで`k`のサイクル数です`a`。 サイクル分解自体には (O(n+m)) がかかるため、完全なアルゴリズムは (O(n+m)) になります。 これは、コンテストの編集者によって与えられた複雑さでもあります。

 ## アルゴリズムのチュートリアル

 1. 順列を分解する`b`素のサイクルに分割し、それぞれの可能な長さを持つサイクルの数を数えます。 させて`cnt[d]`長さのサイクル数になります`d`。 

有効なターゲット サイクルのすべての要素は同様に有効な開始値であるため、サイクル内の実際の要素ではなく、各長さのサイクル数のみが必要です。 
2. 順列を分解する`a`ばらばらのサイクルに分割し、その長さを記録します。 

ソース サイクルの場合、すべての関数値は 1 つの位置のみの画像を選択することによって決定されます。 これにより、割り当てによる計数の問題が軽減されます。`n`独立した値を使用して、ソース サイクルごとに 1 つの開始値を割り当てます。 
3. ソースサイクルの長さの場合`L`、計算します

 [
 way(L)=\sum_{d\mid L}d\cdot cnt[d]。 
】

 目標サイクルの長さ`d`まさに次のようなときに使用できます`d`分割する`L`。 貢献します`d`その要素のいずれかが、選択されたソース位置の画像になる可能性があるためです。 
4. 約数を列挙します`L`整数をテストすることで`d`から`1`(\lfloor\sqrt L\rfloor) を介して。 

いつ`d`分割する`L`、 両方`d`そして`L // d`は約数です。 異なる場合は、両方の貢献度を追加します。 もし`d * d == L`、追加のみ`d`一度。 
5. 乗算`ways(L)`すべてのソース サイクルの答えを計算し、モジュロ (10^9+7) を削減します。 

ソースサイクルが独立しているため、乗算は有効です。 すべてのグローバル関数は、各ソース サイクルの 1 つの有効な選択肢に一意に対応します。 

### なぜ効果があるのか

 のいずれかのサイクルを実行してください`a`長さのある`L`そして1つのポジションを選択してください`x`その上で。 定義式は、そのソース サイクルの他のすべての値を次から決定します。`f(x)`。 ソース サイクル全体をたどった後、一貫性には (b^L(f(x))=f(x)) が必要です。 ターゲットサイクルの長さの値`d`まさにこれを満たすとき`d`分割する`L`。 したがって、このソース サイクルの選択肢の数は正確に (\sum_{d\mid L}d,cnt[d]) になります。 

すべての有効な関数は、個別のサイクルでの選択によって一意に決定されます。`a`、そして異なるサイクルで行われた選択が相互作用することはありません。 すべてのソース サイクルの選択肢の数を乗算すると、すべての有効な関数が 1 回だけカウントされます。
