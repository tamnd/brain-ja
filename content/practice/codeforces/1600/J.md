 ## 解決策
 ## 問題の理解

 グリッドは、各セルが 4 つの側面の一部に壁を持つタイルである長方形の工場フロアを表します。 各タイルには 0 から 15 までの数字が含まれており、この数字は 4 ビットを使用してその壁をエンコードします。 バイナリ表現を最上位ビットから最下位ビットまで北、東、南、西として解釈すると、1 に設定されたビットはその側に壁が存在することを意味し、0 は開口部があることを意味します。 

隣接する 2 つのタイルは、共有エッジ上にそれらの間に壁がない場合、同じ部屋に属します。 タスクは、これらの接続ルールに基づいてこのグリッド内に存在する個別の接続コンポーネントの数を判断し、タイルの数に基づいて各コンポーネントのサイズを計算することです。 最後に、出力は降順に並べ替えられたコンポーネント サイズのリストです。 

この制約により、最大 10^6 セルが許可されます。 グラフの再構築を繰り返したり、セルごとに冗長な作業を試みたりするソリューションでは、セル数が線形に保たれるように注意する必要があります。 セルをマークせずに再訪問する単純なフラッド フィルでは、病的な場合には指数関数的または二次関数的な動作に劣化し、制限時間を超えてしまいます。 

壁がエッジとして誤って解釈されると、微妙な失敗が発生します。 たとえば、ソルバーがグリッド内の隣接性が常に接続性を意味し、壁ビットを無視すると仮定すると、すべてのセルが 1 つのコンポーネントにマージされます。 

もう 1 つのよくある間違いは、ビット順序の解釈に一貫性がないことです。 たとえば、バイナリ表現を北-東-南-西ではなく西-東-北-南として扱うと、部屋が誤って接続されてしまいます。 小さな例としては、値 8 (バイナリで 1000) のタイルがあります。 これは北側の壁のみを意味します。 読み間違えると、不正な上昇移動を許可したり、間違った方向を阻止したりする可能性があります。 

## アプローチ

 グリッドは、各セルがノードである暗黙的なグラフとして見ることができます。 エッジは直交する隣接セル間に存在しますが、これは両方のセルが共有側を通過できる場合に限られます。 各タイルは、各方向の移動が可能かどうかに関する制約に影響します。 

ブルート フォース アプローチでは、すべてのセルを開始点として扱い、DFS または BFS を実行して、接続されているコンポーネントを検出します。訪問したノードをグローバルにマークすることはありません。 各走査では、到達可能性を最初から再計算します。 最悪の場合、同じ領域の探索が何度も繰り返されることになり、コンポーネントが大きく、繰り返し再処理される場合、およそ O((NM)^2) の動作が発生します。 

重要な点は、各セルを 1 つのコンポーネントにのみ割り当てる必要があるということです。 一度セルにアクセスすると、再度処理する必要はありません。 これにより、問題は、隣接性が制限されたグリッド グラフ上の標準的な連結成分分解に変換されます。 未訪問のノードごとに単一の DFS または BFS により、すべてのコンポーネント サイズが線形時間で得られます。 

ウォール エンコーディングは、隣接するエッジ間にエッジが存在するかどうかに関するフィルターとして機能するだけなので、グリッドのトラバーサルは条件付きの隣接拡張を伴うグラフ検索になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (検索の再開) | O((NM)^2) | O(NM) | 遅すぎる |
 | 最適な DFS/BFS マーキングが訪問されました | O(NM) | O(NM) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 各グリッド セルをグラフ内のノードとして解釈します。 (i, j) のノードは、そのウォール ビットに応じて最大 4 つの隣接ノードに接続できる可能性があります。 
2. ビット マスクを使用して各方向を事前計算または直接テストします。北はビット 8、東はビット 4、南はビット 2、西はビット 1 です。これにより、動きを一定時間チェックすることができます。 
3. false に初期化されたサイズ N x M の訪問済み配列を維持します。 これにより、各セルが正確に 1 回処理されることが保証されます。 
4. すべてのセルを行優先の順序で繰り返します。 未訪問のセルが見つかったら、そこから BFS または DFS を開始します。 
5. トラバーサル中に、開始セルを訪問済みとしてマークし、コンポーネント サイズを追跡するためにカウンタを初期化します。 
6. 現在のセルごとに、4 方向すべてに移動してみます。 現在のセルにその方向に壁がなく、隣接するセルに反対方向に壁がない場合にのみ移動が許可されます。 この二重チェックにより、一貫性のない境界を越えることが防止されます。 
7. 新たに発見された到達可能なセルはすべて訪問済みとしてマークされ、トラバーサル構造に追加されます。 このような検出ごとにコンポーネントのサイズを増やします。 
8. 走査が完了したら、コンポーネントのサイズを保存します。 
9. すべてのセルを訪問するまでグリッドのスキャンを続けます。 
10. 収集したすべてのコンポーネントをサイズの大きい順にソートして出力します。 

### なぜ効果があるのか

 訪問された構造では、各セルが 1 つのトラバーサル ツリーにのみ属することが強制されます。 各 BFS は、壁の境界を越えることなく到達可能なセルのセットを正確に探索します。 隣接性は両方のタイルの開放性が一致する場合にのみ対称であるため、二重条件のエッジ チェックにより、グラフが暗黙的に正しく構築されることが保証されます。 したがって、トラバーサルでは、この暗黙的なグラフの接続されたコンポーネントが正確に列挙され、すべてのノードが正確に 1 つのコンポーネント サイズで 1 回カウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, m = map(int, input().split())
    grid = [list(map(int, input().split())) for _ in range(n)]

    visited = [[False] * m for _ in range(n)]

    # bit directions: N=8, E=4, S=2, W=1
    dirs = [(-1, 0, 8, 2), (0, 1, 4, 1), (1, 0, 2, 8), (0, -1, 1, 4)]

    def bfs(si, sj):
        q = deque()
        q.append((si, sj))
        visited[si][sj] = True
        size = 0

        while q:
            i, j = q.popleft()
            size += 1

            val = grid[i][j]

            for di, dj, wall_here, wall_next in dirs:
                if val & wall_here:
                    continue

                ni, nj = i + di, j + dj
                if ni < 0 or nj < 0 or ni >= n or nj >= m:
                    continue
                if visited[ni][nj]:
                    continue

                # check opposite wall in neighbor
                if grid[ni][nj] & wall_next:
                    continue

                visited[ni][nj] = True
                q.append((ni, nj))

        return size

    components = []

    for i in range(n):
        for j in range(m):
            if not visited[i][j]:
                components.append(bfs(i, j))

    components.sort(reverse=True)
    print(*components)

if __name__ == "__main__":
    solve()
```このソリューションは、未訪問の各セルから BFS を構築します。 方向配列は、移動デルタと、現在タイルおよび隣接タイル上の対応する壁ビットの両方をエンコードします。 最もデリケートな部分は二重壁チェックです。どちらかの側に壁がある場合は動作をスキップすることで、接続の一貫性が保証されます。 

訪問済みのマーキングは、ノードをデキューするときではなく、ノードをキューに入れるときにすぐに行われます。 これにより、重複した挿入が回避され、線形の複雑さが保証されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(NM) | 各セルは 1 回だけ訪問され、各エッジ チェックは継続的に行われます。 
| スペース | O(NM) | 訪問された配列と BFS キューには、ほとんどすべてのセルが格納されます。 

グリッド サイズは 100 万セルに達する可能性があり、一定時間の近隣チェックを伴う線形時間の走査は、制限内に問題なく収まります。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque

    def solve():
        n, m = map(int, input().split())
        grid = [list(map(int, input().split())) for _ in range(n)]
        visited = [[False] * m for _ in range(n)]
        dirs = [(-1, 0, 8, 2), (0, 1, 4, 1), (1, 0, 2, 8), (0, -1, 1, 4)]

        def bfs(si, sj):
            q = deque([(si, sj)])
            visited[si][sj] = True
            size = 0
            while q:
                i, j = q.popleft()
                size += 1
                val = grid[i][j]
                for di, dj, w1, w2 in dirs:
                    if val & w1:
                        continue
                    ni, nj = i + di, j + dj
                    if ni < 0 or nj < 0 or ni >= n or nj >= m:
                        continue
                    if visited[ni][nj]:
                        continue
                    if grid[ni][nj] & w2:
                        continue
                    visited[ni][nj] = True
                    q.append((ni, nj))
            return size

        res = []
        for i in range(n):
            for j in range(m):
                if not visited[i][j]:
                    res.append(bfs(i, j))
        res.sort(reverse=True)
        return " ".join(map(str, res))

    return solve()

 ## 特殊なケース

 すべてのセルが 15 である完全に分離されたグリッドにより、BFS が単一ノードを超えて拡大することはありません。 (0,0) から開始すると、4 つの方向すべてが即座にブロックされるため、コンポーネントのサイズは 1 になります。これをすべてのセルに対して繰り返すと、1 のリストが得られます。 

すべてのセルが 0 である完全に開いたグリッドでは、(0,0) から始まる 1 つの大きな BFS が生成されます。 移動を妨げる壁ビットがないため、すべての隣接セルに到達可能であり、隣接関係が対称であるため、すべての NM セルが 1 回の走査で消費されます。 

壁が交互に配置された単一の列のような混合境界ケースでは、方向の正確性がテストされます。 値 4 のセルは東方向への移動をブロックするため、接続が交互に行われます。 未訪問の各セルからの BFS は、隣接するタイルの両方が通過できる場所にのみ拡張され、複数のシングルトン コンポーネントが生成されます。
