 ## 問題の理解

 4 つの整数の等差数列から 1 つの要素が消去された後、3 つの数字が元の順序でボード上に残ります。 欠落した数値を復元し、結果として得られる 4 つの数値が等差数列を形成するように、その数値がどこに属するかを報告する必要があります。 

入力にはちょうど 3 つの正の整数が含まれています。 それらはすでに元の進行と同じ順序で表示されているため、順序を変更することはできません。 出力は、欠落している整数と 4 つの数値内のその位置で構成されます。 位置`1`与えられたすべての値の前に数値が挿入されることを意味します。`2`そして`3`連続する値と位置の間に挿入されることを意味します`4`最後に追加されることを意味します。 

入力値は最大でも`10^5`, しかし、それらは3つしかありません。 入力サイズは一定であるため、固定量の作業のみを実行するアルゴリズムは実質的に有効です。`O(1)`。 高度なデータ構造や最適化は必要ありません。 

いくつかの状況では、慎重な対応が必要です。 

欠落している番号が進行の一方の端にある場合、既存の差は両方とも等しくなります。 例えば、```
2
4
6
```正しい答えは、`8`位置にある`4`、 それでも`0`位置にある`1`等差数列も生成されます。 ソリューションでは、欠損値が常にシーケンス内に存在する必要があると想定するのではなく、どちらかの有効な答えを受け入れる必要があります。 

欠落している数値が最初の値と 2 番目の値の間にある場合は、大きいギャップが最初に表示されます。```
10
16
19
```違いは次のとおりです。`6`そして`3`。 より大きな差は 2 つの等しい差に分割する必要があるため、答えは次のようになります。`13`位置で`2`。 2 つの差が等しいかどうかを単純にチェックするだけでは、このケースは見逃されます。 

欠落している数値が 2 番目と 3 番目の値の間にある場合、ギャップが大きい方が 2 番目に表示されます。```
10
13
19
```違いは次のとおりです。`3`そして`6`。 答えは`16`位置にある`3`。 アルゴリズムは、正しい場所に値を挿入するために、どちらのギャップが大きいかを区別する必要があります。 

3 つの数字がすべて同じである場合、```
5
5
5
```進行には共通の違いがあります`0`。 挿入された値以外の値`5`進行を中断してしまうだろう。 正しい答えは、`5`どちらかの端で。 

## アプローチ

 簡単なアイデアは、4 つの可能な位置のそれぞれに数値を挿入して、結果のシーケンスを構築し、それが等差数列であるかどうかを確認することです。 残る唯一の問題は、どの値を挿入するかです。 すべての有効な数列は共通の差異によって完全に決定されるため、既存の数値から候補値を導き出し、それぞれの可能性を検証できます。 挿入位置が 4 つしかなく、候補の数が一定であるため、このアプローチは正しいです。 

重要な観察は、要素が 1 つだけ欠けている場合、3 つの状況のうち 1 つが必ず発生するということです。 欠落している番号は、最初の要素の前、最後の要素の後、または 2 つの既存のギャップの 1 つの内側にあります。 それがギャップ内にある場合、そのギャップは公差のちょうど 2 倍である必要があり、一方、もう一方のギャップはすでに公差と等しくなります。 それが端にある場合、観察された両方のギャップはすでに等しいです。 

この観察により、2 つの連続する違いを比較することで答えを直接決定できます。

 ## アルゴリズムのチュートリアル

 1. 3 つの数字を読み取ります`a`、`b`、 そして`c`。 
2. 連続的な差分を計算します`d1 = b - a`そして`d2 = c - b`。 
3. もし`d1 == d2`、指定された数値はすでに等差数列の連続した要素です。 いずれかの端にもう 1 つの要素を挿入します。 出力`c + d1`位置で`4`。 
4. もし`d1 > d2`、最初のギャップは 2 倍のギャップです。 欠落している番号は、最初の番号と 2 番目の番号の間に属します。 出力`a + d2`位置で`2`。 

最初のギャップは以下に等しい`2 * d2`ので、挿入します`a + d2`サイズが等しい 2 つのギャップに分割します`d2`。 
5. それ以外の場合は、`d2 > d1`。 2 番目のギャップは 2 倍になります。 出力`b + d1`位置で`3`。 

2 番目のギャップは以下に等しい`2 * d1`ので、挿入します`b + d1`結果として得られる両方のギャップを次と等しくします`d1`。 

### なぜ効果があるのか

 入力は 4 つの整数の等差数列から得られることが保証されています。 

欠落している要素が一方の端にある場合、残りの 3 つの数値は数列の連続する要素であるため、観測された両方の違いはすでに等しいです。 

欠落している要素が進行の内側にある場合、観察された 1 つのギャップは、消去された要素を 1 つだけスキップします。 このギャップは共通差異の 2 倍ですが、観察されたもう 1 つのギャップはすでに共通差異に等しいです。 2 つの相違点を比較すると、どのギャップを分割する必要があるかを一意に特定し、共通の相違点を 1 つ左端から離れた位置に挿入すると、元の進行が再構築されます。 

これらが可能な唯一の構成であるため、アルゴリズムは常に正しい答えを返します。

```プログラムはまず、既存の 2 つのギャップを計算します。 それらの関係により、欠落している番号がどこに属するかが完全に決まります。 

ギャップが等しい場合、3 つの数値はすでに数列の連続したメンバーであるため、末尾でのシーケンスの拡張は常に有効です。 最初に拡張することもできますが、必要な有効な回答は 1 つだけです。 

1 つのギャップが大きい場合、入力保証は、そのギャップが小さい方のギャップのちょうど 2 倍である必要があることを意味します。 挿入された値は、大きいギャップの左端点から 1 つ小さいギャップの距離です。 

すべての算術演算では整数が使用されるため、丸めの問題やオーバーフローの問題はありません。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    a = int(input())
    b = int(input())
    c = int(input())

    d1 = b - a
    d2 = c - b

    if d1 == d2:
        print(c + d1)
        print(4)
    elif d1 > d2:
        print(a + d2)
        print(2)
    else:
        print(b + d1)
        print(3)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()
    solve()
    out = sys.stdout.getvalue()
    sys.stdin = backup_stdin
    sys.stdout = backup_stdout
    return out

# provided sample
assert run("10\n16\n19\n") == "13\n2\n"

# custom cases
assert run("10\n13\n19\n") == "16\n3\n", "missing third element"
assert run("2\n4\n6\n") == "8\n4\n", "missing last element"
assert run("5\n5\n5\n") == "5\n4\n", "zero common difference"
assert run("99998\n99999\n100000\n") == "100001\n4\n", "large values"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`10 13 19`|`16`、 位置`3`| 2 番目のギャップに要素がありません |
 |`2 4 6`|`8`、 位置`4`| 末尾に要素がありません |
 |`5 5 5`|`5`、 位置`4`| ゼロ公差 |
 |`99998 99999 100000`|`100001`、 位置`4`| 大きな入力値 |

 ## 特殊なケース

 欠損値が既存のすべての数値の前にある場合、たとえば```
4
6
8
```アルゴリズムが計算します`d1 = d2 = 2`。 差が等しいので追加します`10`最後に。 本来の進行とは異なります`2, 4, 6, 8`, しかし、これは依然として有効な等差数列であり、問​​題の要件を満たしています。 

欠損値が最初の数値と 2 番目の数値の間にある場合、```
10
16
19
```違いは`6`そして`3`。 最初の差の方が大きいため、アルゴリズムは次の値を挿入します。`10 + 3 = 13`位置にある`2`。 結果のシーケンスは次のとおりです`10, 13, 16, 19`。 

欠損値が 2 番目と 3 番目の数値の間にある場合、```
10
13
19
```違いは`3`そして`6`。 2 番目の差の方が大きいため、アルゴリズムは次のように挿入します。`13 + 3 = 16`位置で`3`。 再構成された進行状況は、`10, 13, 16, 19`。 

すべての値が同一の場合、```
5
5
5
```どちらの差もゼロです。 アルゴリズムは別の出力を出力します`5`最後に、生産する`5, 5, 5, 5`、これは共通の差異を持つ等差数列です。`0`。
