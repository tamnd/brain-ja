 ## 解決策
 ## 問題の理解

 ゲーム内で各参加者が発表する内容を表す一連の数字が与えられます。 目標は、シーケンス全体で 1 回だけ出現する数字を識別することです。 これらの固有に発生する数値の中で、最も小さい値を選択し、それを勝者として出力します。 数値が 1 回だけ出現しない場合は、有効な勝者は存在しないため、-1 が出力されます。 

これは基本的に、最大 100,000 個の整数 (それぞれのサイズが 10^9 になる可能性があります) の配列に対する周波数解析の問題です。 重要な操作は、出現回数を効率的にカウントし、フィルター処理されたサブセットの中から最小値を抽出することです。 

n が 10^5 までという制約は、要素のすべてのペアを比較したり、周波数を求めて配列を繰り返しスキャンしたりするなど、二次的な動作を伴うソリューションは遅すぎることを意味します。 線形または線形演算のソリューションが必要であり、この規模では並べ替えが許容されるため、ハッシュ ベースのカウントと並べ替えベースの集計の両方が実行可能です。 

すべての数値が少なくとも 2 回繰り返される場合、微妙なエッジ ケースが発生します。 たとえば、入力が次の場合:```
2
3
9
3
9
9
2
```すべての値が複数回出現するため、有効な候補はなく、正しい出力は -1 です。 ここでの単純な間違いは、最小値を取得する前に周波数によるフィルター処理を忘れたことです。これにより、一意の出現の中でではなく、生の配列内の最小の要素が誤って返されてしまいます。 

もう 1 つのエッジ ケースは、1 つの数値が 1 回だけ出現し、それがグローバルに最小ではない場合です。次に例を示します。```
5
10
10
10
3
3
```ここでは 3 が 1 回だけ出現するため、他の値が一般的な順序で小さい場合でも、3 を返す必要があります。 

## アプローチ

 簡単な方法は、各数字が何回出現するかを数えることです。 各要素をスキャンし、要素ごとに配列全体を再度スキャンして出現回数をカウントすることができます。 これにより、O(n^2) の解が生成されます。これは、最悪の場合、n が 10^5 の場合に約 10^10 回の演算を意味しますが、これは実行可能な限界をはるかに超えています。 

より効率的な戦略は、問題を 2 つのフェーズに分けることです。 まず、ハッシュ マップまたは辞書を使用して、すべての数値の頻度を計算します。 これにより、カウントが O(n) の予想時間に短縮されます。 次に、すべての個別の数値を反復し、頻度がちょうど 1 である数値のみを考慮し、それらの最小値を維持します。 

重要な構造上の観察は、入力内の位置や順序は気にせず、多重度だけを気にするということです。 周波数がわかると、問題はセットをフィルタリングして、個別の値の数が線形である最小値を取得することになります。 

並べ替えベースの代替手段も機能します。 配列をソートすると、等しい値が連続するため、O(n log n) 時間で実行をカウントできます。 次に、ソートされた配列を 1 回スキャンして、ランレングス 1 の値を抽出します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | お(1) | 遅すぎる |
 | ハッシュマップのカウント | O(n) 平均 | O(n) | 承認済み |
 | 並べ替え + スキャン | O(n log n) | O(1) または O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 私たちは周波数マップアプローチを使用します。 

1. すべての数値を配列に読み取り、同時に頻度辞書を構築します。 数値を読み取るたびに、そのカウントが増加します。 これにより、カウントのために入力を 1 回だけトラバースすることが保証されます。 
2. 変数を初期化する`best`候補がまだ見つかっていないことを表すセンチネル値に設定します。 
3. 頻度ディクショナリ内のすべてのキーと値のペアを繰り返します。 各数値について、その頻度が正確に 1 に等しいかどうかを確認します。 この条件により、その番号がゲームのルールに従って適格であることが保証されます。 
4. 番号が適格で、候補者がまだ選ばれていない場合、または番号が現在の候補者より小さい場合は、更新します。`best`この番号に。 これにより、これまでに確認された最小有効値が維持されます。 
5. すべてのキーを処理した後、次のことを確認します。`best`が更新されました。 そうでない場合は -1 を出力、そうでない場合は出力`best`。 

### なぜ効果があるのか

 頻度ディクショナリは、各数値が何回出現するかという、適格性にとって重要な唯一のプロパティを完全に取得します。 選択ルールは周波数とフィルタリングされた値の全体的な最小値のみに依存するため、入力の並べ替えや部分的な処理は正確さに影響しません。 すべての有効なキーに対して実行最小値を維持すると、ループが終了すると、格納される値が頻度 1 の最小の数値 (そのような数値が存在する場合) になることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    freq = {}

    for _ in range(n):
        x = int(input())
        freq[x] = freq.get(x, 0) + 1

    best = None

    for x, c in freq.items():
        if c == 1:
            if best is None or x < best:
                best = x

    print(-1 if best is None else best)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず入力に対する単一パスで周波数マップを構築します。 ディクショナリにより、要素ごとに一定時間の平均更新が保証されます。 その後、配列全体ではなく個別の値のみが再度スキャンされるため、冗長な作業が回避されます。 

変数`best`として初期化されます`None`「有効な候補が見つかりません」と有効な整数値を明確に区別するため。 これにより、大きなセンチネルで初期化すると入力境界と誤って相互作用する可能性がある落とし穴が回避されます。 

最後の条件付き出力は、一意性条件を満たす要素がない場合を処理します。

 ## 特殊なケース

 主なエッジケースは、すべての数値が少なくとも 2 回重複する場合です。 次のような入力の場合:```
