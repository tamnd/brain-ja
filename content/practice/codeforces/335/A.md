 ## 問題の理解

 Piegirl がターゲット文字列を作成するためにステッカーのシートを購入するのを手伝ってほしいと頼まれました。`s`。 各シートには正確な内容が含まれています`n`ステッカー、およびシート上のすべてのステッカーは、そのシートに対して選択した文字列によって事前に決定されます。 Piegirl は同じシートを好きなだけ購入でき、任意のシートから任意の順序でステッカーを取り出してフォームを作成できます。`s`。 タスクは、購入する必要があるシートの最小枚数を決定し、ステッカーのシートを表す有効な文字列を 1 つ生成することです。 形成不可能な場合`s`これらのルールに従って、私たちは戻ります`-1`。 

入力はターゲット文字列で構成されます`s`最大1000の長さとシートサイズ`n`これは、両方の次元が最大 1000 である入力に対してアルゴリズムが効率的に実行されなければならないことを意味し、安全な上限としておよそ 100 万回の操作が与えられます。 

単純なアプローチでは、考えられる長さのシート文字列をすべて試してしまう可能性があります。`n`かどうかを確認してください`s`を形成することはできますが、可能な文字列は 26^n 個あり、これは完全に実行不可能です。`n`たとえ 10 個程度であっても、不注意な解決策を破る可能性があるエッジ ケースとしては、次のような場合があります。`n`内の任意の文字の最大頻度よりも小さい`s`。 たとえば、次の場合`s = "aaaaa"`そして`n = 3`, 1枚のシートに「a」のシールを3枚以上入れることはできません。 文字数を無視する単純な解決策では、1 枚のシートで十分であると誤って考えられてしまいます。 

その他のエッジケースとしては、次のような場合があります。`n`の長さよりも大きいです`s`またはいつ`s`シートに均等に分割されない頻度を持つ複数の文字が含まれています。 例えば、`s = "aabbc"`と`n = 3`シート全体に文字を慎重に配置する必要があります。 

## アプローチ

 ブルートフォースの解決策は概念的には単純です。同じ長さの文字列をすべて試してください。`n`かどうかを確認してください`s`同一のシートにまたがる各文字を任意の数だけ取り出すことで形成できます。 理論的にはあらゆる配置を試すことができるため、これは機能しますが、可能性の数は次のように指数関数的に増加します。`n`(26^n)。 たとえ`n`が 10 だった場合、文字列は 26^10 ≈ 1.4e14 となり、これはまったく実用的ではありません。 

重要な洞察は、シート上の文字の特定の順序は重要ではないということです。 私たちはカウントだけを気にします。 すべての文字に対して次のようなシート文字列が必要です。`c`、のコピー数`c`シート上のシート数に少なくとも次の周波数を乗算した値です。`c`で`s`。 正式に言うと、`freq[c]`の数です`c`で`s`そして`sheet[c]`の数です`c`1枚のシートに、`sheet_count * sheet[c] >= freq[c]`みんなのために`c`。 私たちの目標は最小限に抑えることです`sheet_count`。 

文字の頻度がわかれば、`s`, 最小シート数は、必要な頻度とシート容量の比率が最も高いキャラクターによって決まります。 具体的には、シートに`sheet[c]`のコピー`c`、必要な最小シートは`ceil(freq[c] / sheet[c])`。 選びたい`sheet[c]`合計すると次の値になります`n`（シート上のステッカーの合計）これらの比率の最大値を最小化します。 貪欲なアプローチで十分です。最高の周波数比を満たすのに十分なステッカーを各キャラクターに割り当て、残りのスロットを任意に埋めます。

 ## アルゴリズムのチュートリアル

 1. 対象文字列内の各文字の出現頻度をカウントします。`s`。 これで辞書が得られます`freq`各文字をそのカウントにマッピングします。 
2. 次のことを確認します。`n`内の任意の文字の最大頻度よりも小さい`s`。 そうであれば、形成`s`1 枚のシートではそのキャラクターのコピーを十分に保持できないため、これは不可能です。 その場合は返却してください`-1`。 
3. それ以外の場合は、必要なシートの最小数を決定します。 初期化する`sheets_needed`ゼロに。 キャラクターごとに`c`、計算する`ceil(freq[c] / n)`そして更新します`sheets_needed`全キャラの最大値となります。 これにより、シート全体ですべての文字を確実にカバーできます。 
4. 単一のシート文字列を作成します。 長さの空のリストから開始します`n`。 キャラクターごとに`c`で`freq`、ステッカーの枚数を計算します。`c`としてシート上に配置します`ceil(freq[c] / sheets_needed)`。 これらの文字をシート文字列に配置します。 必要な文字をすべて配置したら、長さを満たすために残りの位置を任意の文字 (通常は「a」) で埋めます。`n`。 
5. 出力`sheets_needed`そして構築されたシート文字列。 

機能する理由: アルゴリズムにより、シートに各文字の十分なコピーが含まれることが保証されるため、次の乗算が行われます。`sheets_needed`シートはターゲット文字列をカバーします`s`。 最大比率を使用すると、どの文字も過小表現されなくなります。 余分な文字が組み立て能力を損なうことはないため、残りのスロットを埋めても正確性は低下しません。`s`。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

s = input().strip()
n = int(input())

freq = {}
for ch in s:
    freq[ch] = freq.get(ch, 0) + 1

max_count = max(freq.values())
if max_count > n:
    print(-1)
    sys.exit(0)

sheets_needed = 0
for ch, count in freq.items():
    sheets_needed = max(sheets_needed, math.ceil(count / n))

sheet = []
for ch, count in freq.items():
    per_sheet = math.ceil(count / sheets_needed)
    sheet.extend([ch] * per_sheet)

while len(sheet) < n:
    sheet.append('a')  # fill remaining positions arbitrarily

print(sheets_needed)
print(''.join(sheet[:n]))
```このソリューションでは、文字の頻度をカウントし、文字の頻度とシート サイズの最大比率を考慮してシートの最小枚数を決定します。 シート文字列は、すべての文字数を満たすのに十分な各文字のコピーを配置し、必要な長さに達するまで残りの位置を埋めることによって構築されます。 使用する`math.ceil`丸めエラーが発生しないようにすることで、文字が過小評価されることはありません。 トリミングして`n`文字により、シートの長さの要件が満たされることが保証されます。
