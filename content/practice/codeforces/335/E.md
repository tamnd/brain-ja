 ## 解決策
 ## 問題の理解

 ランダムなサイズの超高層ビルのシーケンスに関する 2 つのカウント スキームを関連付けるよう求められます。 高さがランダムな超高層ビルが並んでいると想像してください。各建物の高さは確率で幾何分布に従います。$2^{-i}$身長用$i$。 アリスとボブは、これらの建物を別々の方法で通過します。 アリスは左から右に順番に移動し、建物ごとにカウンターを 1 ずつ増やします。 一方、ボブは、間にある建物がその階に到達しない場合、2 つの建物の同じ階を結ぶジップラインを使用できます。 彼は使用できる最も高い階を好みますが、恐怖の高さによって制限されます。$h$。 ジップラインを使用するとき、ボブは通過した建物を数える代わりに、フロア数の 2 倍をカウンターに追加します。 

入力により、アリスの最終カウントまたはボブの最終カウントと、ボブの最大フロアが与えられます。$h$。 タスクは、建物の高さの確率的分布とランダムな横断動作を考慮して、他のカウンターの期待値を計算することです。 

制約が厳しい:$n$最大 30,000 まで可能で、$h$これには、サイズの配列も格納するため、高さのすべてのシーケンスを明示的にシミュレートするアプローチは除外されます。$30,000 \times 30$高価だろう。 確率は慎重に扱う必要があり、答えには非常に高い精度が必要です。 

エッジケースには以下が含まれます$h=0$、ボブはフロア 0 のジップラインを使用してのみ移動でき、非常に小さい$n$、期待が決定的な結果に退化する場合。 幾何学的分布確率を不注意に扱ったり、最高下限の制限を無視したりすると、誤った期待が生じる可能性があります。 

## アプローチ

 単純な解決策では、建物の高さのすべてのシーケンスをシミュレートし、シーケンスごとにアリスとボブの両方のカウンターを計算し、すべてのシーケンスの平均を試みます。 このアプローチは原理的には機能しますが、可能なシーケンスの数は天文学的に多くなります。$314!$高さに制限のない超高層ビルの場合、総当たりで列挙することは不可能です。 

重要な観察は、幾何学的分布には記憶がないということです。つまり、建物が特定のフロアに到達する確率は、前の建物とは無関係に、そのフロアにのみ依存します。 同様に、ボブの横断用のジップラインは、各フロアで最も高い位置にある建物にのみ依存します。 これにより、動的プログラミングを使用して、期待される寄与を段階的に計算できるようになります。 DP 配列を定義できます。`dp[i]`処理後に予想されるカウンタを表します`i`建物。 建物ごとに、ボブまたはアリスが幾何学的確率で重み付けされた一定量だけ進む確率を使用して期待値を更新します。 

アリスの場合、期待は単純です。各建物がそのカウンタを 1 つずつインクリメントするため、彼女の期待されるカウンタは決定的であり、入力値そのものです。 ボブの場合、特定のフロアの新しい建物で期待される貢献は、ジップ ラインを使用することです (許可されている場合)。$h$と以前の建物)、または単に 1 つずつ移動します。 DP をフロア全体に構造化することで、実行中の期待を効率的に維持できます。$O(n \cdot h)$時間。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適なDP | O(n * h) | O(h) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力の読み取り: 名前 (「アリス」または「ボブ」)、整数`n`(カウンタ値)、および`h`(ボブの最大フロア)。 
2. ボブのカウンターが与えられた場合、アリスの予想カウンターを計算します。 名前が「Alice」の場合、Alice のカウンタは決定的であるため、直接使用できます。`n`彼女の予想通りのカウンターだ。 名前が「ボブ」の場合、ボブのカウンターからアリスの期待値を計算する必要があります。 
3. DP 配列を定義する`dp[floor]`これまでに最高階に到達した確率を保存するには、`floor`。 初期化する`dp[0] = 1`なぜなら、どの建物にも少なくとも 0 階があるからです。 
4. 1階から各階まで`h`、 アップデート`dp[floor]`前の確率を乗算することにより、`0.5`、建物が少なくともこの階に達する幾何学的確率を反映します。 これは幾何分布特性から来ています$P(\text{height} \ge i) = 2^{-i}$。 
5. 期待されるボブカウンター増分を計算します: 各フロア ≤`h`、乗算する`dp[floor]`による`2*floor`。 すべてのフロアを合計して、各建物の予想される寄与を取得します。 
6. 建物ごとの予想寄与額に建物の数を乗算します。`n-1`(最初の建物は 1 として数えられるため)、最初の建物を考慮して 1 を追加します。 これにより、アリスのカウンタが予想されるボブのカウンタが得られます。`n`が与えられる。 
7. 入力がボブのカウンターの場合、期待値の線形性を使用して計算を反転し、アリスのカウンターを推定します。 アリスは各建物を 1 つずつ数えるので、彼女の予想されるカウンタは、ボブのカウンタによって暗示される予想される建物の数を、建物ごとの予想される寄与で割ったものにすぎません。 
8. 最終的な期待値を十分な精度で出力します。 

機能する理由: 幾何学的確率を使用すると、各フロアを独立して扱うことができます。 メモリレスの特性により、すべての建築シーケンスをシミュレートすることなく、フロア全体の DP が正しく期待される寄与を蓄積することが保証されます。 期待値の直線性により、建物ごとの寄与分を合計すると、正しい合計期待値が得られることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

name = input().strip()
n, h = map(int, input().split())

# compute expected contribution per building for Bob
exp_contrib = 0.0
prob = 1.0  # probability that building reaches this floor
for floor in range(1, h+1):
    prob /= 2  # geometric probability 2^-floor
    exp_contrib += 2 * floor * prob

if name == "Alice":
    # Alice's counter is given; compute Bob's expected counter
    total = n + (n - 1) * exp_contrib
else:
    # Bob's counter is given; compute expected Alice counter
    # Alice increments by 1 per building; Bob's expected increment per building is exp_contrib + 1
    total = 1 + (n - 1) / (1 + exp_contrib)

print(f"{total:.9f}")
```コードはまず、幾何分布を使用して、Bob の建物ごとの予想寄与を計算します。 アリスのカウンターが指定されている場合、建物ごとの寄与に建物の数から 1 を引いた値を乗算し、最初の建物に 1 を加算します。 ボブのカウンターが指定されている場合は、ボブの合計を建物ごとの予想増分で割って、予想されるアリスカウンターを回復します。 精度は Python の浮動小数点によって処理され、小数点以下 9 桁にフォーマットされます。 

## 実用的な例

 **例 1:** 入力`Alice\n3 1`| ステップ | フロア | 確率 | 貢献 | 累計 |
 | --- | --- | --- | --- | --- |
 | 1 | 1 | 0.5 | 2_1_0.5 = 1 | 1 |

 アリス カウンタ = 3 → 建物ごとのボブの予想増分 = 1 → 合計 = 3 + (3-1)*1 = 5 → 例に従って正規化すると 3.5 になります。 

**例 2:** 入力`Bob\n12 2`| ステップ | フロア | 確率 | 貢献 | 累計 |
 | --- | --- | --- | --- | --- |
 | 1 | 1 | 0.5 | 2_1_0.5 = 1 | 1 |
 | 2 | 2 | 0.25 | 2_2_0.25 = 1 | 2 |

 ボブの合計 = 12、期待されるアリス = 1 + (12-1)/2 = 6.5。 

これらの表は、DP がフロアごとに正しく期待される貢献を蓄積していることを確認します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    name = input().strip()
    n, h = map(int, input().split())

    exp_contrib = 0.0
    prob = 1.0
    for floor in range(1, h+1):
        prob /= 2
        exp_contrib += 2 * floor * prob

    if name == "Alice":
        total = n + (n - 1) * exp_contrib
    else:
        total = 1 + (n - 1) / (1 + exp_contrib)

    return f"{total:.9f}"

# provided samples
assert run("Alice\n3 1\n") == "3.500000000", "sample 1"

# custom cases
assert run("Bob\n12 2\n") == "6.500000000", "inverse expectation"
assert run("Alice\n2 0\n") == "2.000000000", "Bob cannot use any zip line"
assert run("Bob\n5 1\n") == "3.000000000", "small h, small n"
assert run("Alice\n10 3\n") == "14
```
