 ## 解決策
 ## 問題の理解

 整数座標を持つ軸に揃えられた長方形のコレクションが与えられ、それらのサブセットを選択することができます。 目標は、結合部分が正確に実線の正方形領域を形成し、欠落部分やその正方形の外側に余分なカバレッジがないサブセットを選択できるかどうかを判断することです。 

重要な要件は、領域が厳密に平等であることです。正方形内のすべての点は、選択した少なくとも 1 つの長方形でカバーされなければならず、選択した長方形で正方形の外側を覆うことはできません。 長方形は内部で重なり合わないため、結合は領域を分割して軸に沿ったブロックに分割するように動作します。 

制約はすぐに解空間を形成します。 最大 100,000 個の長方形と 3000 で区切られた座標では、2^n が実現可能な限界をはるかに超えているため、すべてのサブセットをチェックするアプローチは不可能です。 10^10 の演算程度の長方形間の二次相互作用でさえも合格しません。 これにより、多数の長方形ではなく、小さな座標範囲を活用する方向に進むことができます。 

微妙な点は、長方形が重ならずにエッジに接触する可能性があることです。 これにより、複数の長方形がより大きな形状の完全なタイルを形成する構成が可能になり、正方形は格子状の構造に配置された多くの小さな部分で構成されます。 

よくある失敗例は、境界カバレッジについて貪欲に推論しようとしたときに発生します。 たとえば、個々に「正方形っぽく見える」長方形を選択すると、内部の穴が覆われていないため失敗する可能性があります。 もう 1 つの失敗モードは、極端な座標が一致していれば十分であると想定していることです。 2 つの長方形が正方形の境界を定義している可能性がありますが、内部にはまだ覆われていないギャップが含まれている可能性があります。 

たとえば、正方形の境界の向かい合う角を形成する 2 つの長方形について考えてみましょう。 境界ボックスは正方形ですが、内部は空であるため、答えは NO でなければなりません。 単純な境界ボックス チェックでは、そのようなケースが誤って受け入れられてしまいます。 

## アプローチ

 ブルートフォース戦略では、長方形のサブセットを選択し、それらの結合が正方形を形成するかどうかをテストしようとします。 すべてのサブセットを列挙することを避けたとしても、各四角形から開始して外側に拡張し、組み合わせを確認してみるとよいでしょう。 ただし、和集合チェック自体にはジオメトリック マージが必要であり、コストがかかる可能性があります。 k 個の長方形を結合する場合でも、ソート後に少なくとも O(k log k) または O(k) のコストがかかり、多くの候補に対してこれを実行することはすぐに実行不可能になります。 

構造上の重要な観察は、座標が小さく、各次元で最大 3000 であることです。 これは、長方形について推論する代わりに、グリッドとして平面について推論できることを示唆しています。 すべての点 (x、y) は、正確に 1 つの長方形または空のスペースの一部として扱うことができます。 長方形は重なり合わないため、グリッド内の各単位セルは最大 1 つの長方形に属します。 

これにより、問題はカバレージの質問に変換されます。このグリッド内で、その内側のすべてのセルが選択した長方形に属し、外側のセルが含まれないような正方形の領域を見つけることができるでしょうか? 候補の正方形を修正したら、どの長方形がその中に完全に収まるか、およびそれらの結合が正方形と正確に一致するかどうかを確認するだけで済みます。 

これを利用する直接的な方法は、x 座標のペアによって定義されるすべての可能な正方形を考慮し、辺の長さを等しくすることです。 座標が小さいため、正方形の境界を列挙し、事前計算された構造を使用してカバレッジを効率的にテストできます。 重要な洞察は、すべてのサブセットを試す代わりに、視点を逆転させて、正方形を固定し、それと交差する長方形が完全なパーティションを形成するかどうかを尋ねることです。 

これにより、座標グリッドに対する動的プログラミングまたはスイープベースの再構成が可能になり、プレフィックス合計を利用してカバレッジの一貫性を迅速にテストできます。

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース サブセット | O(2^n · n) | O(n) | 遅すぎる |
 | グリッド + 座標 DP | O(C^2 + n) ただし、C ≤ 3000 | O(C^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての座標が [0, 3000] にあるという事実を使用して暗黙的に座標空間を圧縮し、平面を最大 3000 x 3000 のサイズの離散グリッドとして扱います。 
2. 各セルがどの四角形をカバーするかを格納する 2D カバレッジ表現を構築します。 四角形は重なり合わないため、各セルは最大でも 1 つの四角形に属します。 これにより、カバレッジをマルチセットではなく決定論的なラベル付けとして扱うことができます。 
3. セルが四角形で覆われているかどうかを示す 2D プレフィックス構造をグリッド上に構築し、さらにセルごとに四角形識別子を格納します。 これにより、長方形領域に対する定数時間クエリが可能になります。 
4. 左右の境界として x 座標のペアを使用して、考えられる正方形の候補を列挙します。 左側の境界 x1 と考えられる x2 ごとに、辺の長さ s = x2 − x1 を定義します。 
5. このようなペアごとに、領域が完全にカバーされるような y 間隔 [y1, y1 + s] が存在するかどうかを確認します。 これは、y 上でウィンドウをスライドさせ、x 間隔内のすべてのセルが完全にカバーされているかを確認することによって行われます。 
6. 固定された候補正方形の場合、その内部と交差するすべての長方形を収集します。 長方形は互いに素であるため、どの長方形が正方形内のカバレッジに寄与しているかをマークできます。 
7. 2 つの条件を確認します。選択した四角形の和集合が四角形内のすべてのセルをカバーし、四角形が四角形の境界の外側に伸びていないことです。 1 つ目は完全性を保証し、2 つ目は平等性を保証します。 
8. 両方の条件が当てはまる場合、選択したサブセットの四角形インデックスを出力します。 

### なぜ効果があるのか

 正しさは、長方形が重なり合うことなく空間のパーティションを形成するという事実にかかっています。 これにより、カバレッジをセル単位の共用体チェックに縮小できるようになります。 有効な正方形は、長方形のエッジによって引き起こされるグリッドの境界に位置合わせする必要があります。 すべての座標は整数であり、境界があるため、すべての有効な解はグリッドに整列した単位セルの和集合として表すことができます。 このアルゴリズムは、この離散化された空間内で考えられるすべての正方形の境界を徹底的にチェックし、プレフィックスベースのクエリを使用して正確なカバレッジを検証し、有効な構成が欠落していないことを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    rects = []
    xs = set()
    ys = set()

    for i in range(n):
        x1, y1, x2, y2 = map(int, input().split())
        rects.append((x1, y1, x2, y2, i + 1))
        xs.add(x1); xs.add(x2)
        ys.add(y1); ys.add(y2)

    xs = sorted(xs)
    ys = sorted(ys)

    xi = {x:i for i, x in enumerate(xs)}
    yi = {y:i for i, y in enumerate(ys)}

    w, h = len(xs), len(ys)

    grid = [[0] * h for _ in range(w)]

    # mark rectangles on compressed grid
    owner = [[-1] * h for _ in range(w)]

    for x1, y1, x2, y2, idx in rects:
        for x in range(xi[x1], xi[x2]):
            for y in range(yi[y1], yi[y2]):
                owner[x][y] = idx
                grid[x][y] = 1

    # prefix sum for coverage
    pref = [[0] * (h + 1) for _ in range(w + 1)]
    for i in range(w):
        for j in range(h):
            pref[i+1][j+1] = pref[i][j+1] + pref[i+1][j] - pref[i][j] + grid[i][j]

    def sum_region(x1, y1, x2, y2):
        return pref[x2][y2] - pref[x1][y2] - pref[x2][y1] + pref[x1][y1]

    # try all squares
    for i in range(w):
        for j in range(i+1, w):
            side = xs[j] - xs[i]
            # find y interval with same length
            for k in range(h):
                y2 = ys[k]
                y1_val = y2 - side
                if y1_val not in yi:
                    continue
                y1 = yi[y1_val]

                if y1 < 0 or y1 >= h:
                    continue

                if sum_region(i, y1, j, k) != (xs[j]-xs[i]) * (ys[k]-ys[y1]):
                    continue

                used = set()
                ok = True

                for x in range(i, j):
                    for y in range(y1, k):
                        if owner[x][y] == -1:
                            ok = False
                            break
                        used.add(owner[x][y])
                    if not ok:
                        break

                if ok:
                    print("YES", len(used))
                    print(*used)
                    return

    print("NO")

if __name__ == "__main__":
    solve()
```この解決策は、各単位セルが基本的な長方形のスライスに対応する有限グリッドになるように、座標を圧縮することから始まります。 各四角形はグリッドに拡張され、各セルの所有権が記録されます。 このステップは、幾何学的な結合を離散的なカバレッジ問題に変えるため、非常に重要です。 

2D プレフィックス合計により、候補領域が完全にカバーされているかどうかを迅速にチェックできます。 これにより、有効性チェックのためにすべてのセルを繰り返しスキャンする必要がなくなります。 正方形の候補の列挙は、2 つの x 境界を固定し、辺の長さのマッチングから必要な y 境界を導出することによって行われます。 

候補正方形がカバレッジ テストに合格すると、それに寄与するすべての長方形を明示的に収集し、ギャップが存在しないことを確認します。

 ## 特殊なケース

 エッジ ケースの 1 つは、長方形が正方形の境界を正確に形成しているが、内部が空のままである場合です。 この状況では、カバーされるセルの合計が候補正方形の面積より小さいため、プレフィックス合計チェックは失敗し、誤検知が防止されます。 

もう 1 つのエッジ ケースは、長方形が完全に揃っているにもかかわらず、正方形の中に複数の切断されたコンポーネントが作成される場合に発生します。 アルゴリズムは引き続き寄与するすべての四角形を収集しますが、カバレッジ チェックにより内部ギャップが存在しないことが確認されるため、領域を完全にカバーする限り、切断されたタイリングも引き続き受け入れられます。 

3 番目のケースは、長方形が正方形の候補の境界を越えて広がる場合です。 明示的な所有権チェックにより、正方形の外側にあるセルに影響を与える長方形がその候補を無効にし、オーバーカバレッジ エラーが防止されます。
