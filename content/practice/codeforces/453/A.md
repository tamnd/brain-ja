 ## 解決策
 ## 問題の理解

 私たちは、次の番号が付けられた面で公平なサイコロを振ります。`1`に`m`、 その通り`n`回。 すべてのロールは独立しており、各面は確率で出現します。`1 / m`。 

その中で`n`ロールでは、出現した最大値のみを確認します。 タスクは、その最大値の期待値を計算することです。 

入力には以下が含まれます`m`そして`n`、 どこ`m`はサイコロの面の数であり、`n`投げる回数です。 出力は、すべてのスロー後の最大結果の期待値を表す実数です。 

制約により両方が許可されます`m`そして`n`と同じくらい大きくなる`100000`。 考えられるロールのシーケンスをすべて列挙することは不可能です。`m^n`結果。 次のような中程度の値であっても、`m = 100`そして`n = 100`、その数は天文学的な数字です。 

に比例した作業を実行するソリューション`m`全然大丈夫です。 に比例する解決策`m^2`すでに約が必要になります`10^10`制限時間を大幅に超えた最悪の場合の作戦。 

スローが 1 つしかない場合、微妙なケースが 1 つ発生します。 

入力：```
6 1
```最大値は単純にサイコロの結果そのものなので、答えは数値の平均になります。`1..6`に等しい`3.5`。 

もう 1 つの見落としやすいケースは、ダイの面が 1 つだけの場合です。 

入力：```
1 100000
```すべてのロールは常に`1`したがって、最大値は常に`1`、期待値は正確に`1`。 

よくある間違いは、最大値が次の値に等しい確率を計算しようとすることです。`k`直接、オフバイワンエラーを起こします。 たとえば:

 入力:```
2 2
```最大値は以下に等しい`1`両方のロールが揃っている場合のみ`1`、確率で起こります`1/4`。 最大値は以下に等しい`2`確率的に`3/4`。 期待は$$1 \cdot \frac14 + 2 \cdot \frac34 = 1.75.$$累積確率の処理を誤ると、異なる結果が生じることがよくあります。 

## アプローチ

 最も直接的なアプローチは、可能なすべてのロールのシーケンスを列挙し、その最大値を計算し、すべての最大値を平均することです。 これは正しいです。期待値は単に確率で重み付けされた平均値であるからです。 残念ながら、`m^n`考えられる結果。 と`m = n = 100000`、これはまったく不可能です。 

重要な観察は、累積確率を通じて最大値を推論するのがはるかに簡単であるということです。 

最大値が以下である確率が欲しいとします。`k`。 すべてのロールは最大でも`k`。 Since each roll independently lands in`{1,2,...,k}`確率的に`k/m`、私たちは得ます$$P(\max \le k) = \left(\frac{k}{m}\right)^n.$$これから、最大値が正確に一致する確率を得ることができます。`k`:$$P(\max = k) = P(\max \le k) - P(\max \le k-1) = \left(\frac{k}{m}\right)^n - \left(\frac{k-1}{m}\right)^n.$$そのときの期待値は、$$E[\max] = \sum_{k=1}^{m} k \cdot P(\max = k).$$上記の式を代入すると、`O(m)`解決。 

以来`m ≤ 100000`の値ごとに 1 つのべき乗といくつかの算術演算を評価します。`k`制限内に簡単に収まります。

 | 最適 |$O(m)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`m`そして`n`。 
2.初期化`answer = 0`。 
3. あらゆる値について`k`から`1`に`m`、計算する$$p_k = \left(\frac{k}{m}\right)^n$$これは最大値が超えない確率です`k`。 
4. コンピューティング$$p = p_k - p_{k-1}$$どこ$$p_{k-1}=\left(\frac{k-1}{m}\right)^n.$$これにより、最大値が正確に次の値になる確率が得られます。`k`。 
5.追加$$k \cdot p$$実行中の答えに。 
6. すべての値を処理した後、`k`、蓄積された期待値を出力します。 

### なぜ効果があるのか

 すべての整数に対して`k`、イベント「`maximum ≤ k`「すべてのロールが最高の場合に正確に発生します`k`。 ロールは独立しているため、その確率は$$\left(\frac{k}{m}\right)^n.$$イベント」`maximum = k`" サンプル空間全体を分割します。それらの確率は、連続した累積確率を減算することによって取得されます。$$P(\max = k) = P(\max \le k)-P(\max \le k-1).$$期待の公式$$E[X] = \sum_x x \cdot P(X=x)$$確率変数「最大ロール」に適用すると、アルゴリズムによって累積された値が正確に得られます。 考えられるすべての最大値は、その値に確率を乗算したものとなるため、最終的な合計は予想される最大値と等しくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    m, n = map(int, input().split())

    ans = 0.0

    for k in range(1, m + 1):
        p1 = (k / m) ** n
        p0 = ((k - 1) / m) ** n
        ans += k * (p1 - p0)

    print("{:.12f}".format(ans))

solve()
```実装は数学的導出に直接従います。 

ループは、考えられるすべての最大値を反復します。 For each`k`、すべてのロールが最大である累積確率を計算します。`k`、次に、対応する確率を減算します。`k - 1`。 違いはまさに、最大値が等しい確率です。`k`。 

必要な誤差許容範囲はわずかであるため、浮動小数点演算を使用するだけで十分です。`10^{-4}`。 Python の倍精度浮動小数点型は、はるかに高い精度を簡単に提供します。 

の表現`k = 1`自然に機能するので、$$\left(\frac{0}{m}\right)^n = 0.$$特別な取り扱いは必要ありません。 

小数点以下 12 桁を表示するだけで、裁判官は十分に満足できます。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    def solve():
        input = sys.stdin.readline
        m, n = map(int, input().split())

        ans = 0.0
        for k in range(1, m + 1):
            ans += k * ((k / m) ** n - ((k - 1) / m) ** n)

        return "{:.12f}".format(ans)

    return solve()

# provided sample

 ## 特殊なケース

 インプットを考慮する```
1 100000
```ループは次の場合にのみ実行されます。`k = 1`。$$(1/1)^{100000}=1, \qquad (0/1)^{100000}=0.$$最大値が次と等しい確率`1`は`1`、つまり貢献度は$$1 \cdot 1 = 1.$$アルゴリズムは正確に出力します`1`。 

インプットを考慮する```
6 1
```あらゆる人にとって`k`、確率差は$$\frac{k}{6}-\frac{k-1}{6} = \frac16.$$すべての面が等しい確率で寄与し、公平なサイコロの標準平均が生成されます。 出力は`3.5`。 

インプットを考慮する```
2 2
```累積確率は次のとおりです。$$P(\max \le 1)=\left(\frac12\right)^2=\frac14,$$

$$P(\max \le 2)=1.$$連続した値を減算すると確率が得られます`1/4`そして`3/4`最大値のために`1`そして`2`。 重み付けされた寄与を合計すると、`1.75`、最大値の真の分布と正確に一致します。
