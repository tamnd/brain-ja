 ## 問題の理解

 このタスクは、魔方陣全体を構築するように求めているわけではありません。 最初の行に配置された数値の合計だけが必要です。 通常の魔方陣の大きさ`n`～からのすべての整数が含まれます`1`に`n²`ちょうど 1 回、すべての行の合計が同じになります。 入力は正方形の辺の長さを示し、出力はその共通の行の合計である必要があります。 

サイズは次のように大きくすることができます`1000`なので、正方形をシミュレートする必要はありません。 単純な構築であっても、最大のケースでは 100 万個のセルを保存する必要がありますが、必要な答えは魔方陣の数学的性質にのみ依存します。 すべてを処理するアプローチでは、目的のソリューションは一定時間で実行される必要があります。`n²`細胞は問題が必要としない作業を行っています。 

珍しいケースとしては、少量の注文があります。 のために`n = 1`、唯一のセルに含まれるのは`1`、したがって、答えは次のとおりです`1`。 すべての正方形に複数の行があると想定するソリューションは、ここで失敗する可能性があります。 たとえば、入力`1`出力を生成する必要がある`1`。 

値`n = 2`そのサイズの通常の魔方陣は存在しないため、ステートメントによって除外されます。 この場合、プログラムは構築を試みたり、構築公式に依存したりすべきではありません。 裁判官はこの意見を提供しません。 

## アプローチ

 直接的なアプローチは、魔方陣を生成し、その最初の行の要素を追加することです。 これが機能するのは、すべての有効な構造に正しい最初の行が含まれており、行の合計が必要な答えと一致するためです。 ただし、広場の構築は不要です。 のために`n = 1000`、 がある`1,000,000`したがって、単純な走査でもすでに 100 万回の操作が実行され、大量のメモリが使用されます。 構造がより複雑になると、要求された値を見つけることができずにオーバーヘッドが追加されます。 

重要な観察は、以下のすべての数値が`1`に`n²`は 1 回だけ表示されます。 すべてのセルの合計は、最初のセルの合計です。`n²`正の整数:$$\frac{n^2(n^2+1)}{2}$$魔方陣には、`n`合計が同じ行。 合計を行数で割ると、1 行の合計が求められます。$$\frac{n^2(n^2+1)}{2n}$$これは次のように単純化されます。$$\frac{n(n^2+1)}{2}$$すべての行が同じ合計を共有するため、最初の行にはこの値が必要です。 問題全体は、この式を評価することに帰着します。

 ## アルゴリズムのチュートリアル

 1. 注文を読む`n`魔方陣の。 の値`n`行の合計は正方形のサイズによって完全に決定されるため、これで十分な情報になります。 
2. 次の式を使用してマジック サムを計算します。`n * (n * n + 1) // 2`。 この式は、すべてのセルの合計値を行数で割ることによって得られます。 
3. 計算された値を出力します。 

なぜ効果があるのか:

 正方形内の数字は正確に次の整数です。`1`に`n²`, したがって、それらの合計額は固定されます。 すべての行の合計は同じであるため、合計を均等に分割する必要があります。`n`行。 数式はその単一行の値を直接計算します。つまり、その値は最初の行の合計でもある必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    print(n * (n * n + 1) // 2)

if __name__ == "__main__":
    solve()
```プログラムは唯一の入力値を読み取り、派生した式をすぐに適用します。 掛け算`n * n`可能な最大値は 100 万のみなので安全です。 Python の整数を使用すると、オーバーフローの心配もなくなります。 

最終結果は常に整数になるため、除算は整数除算で実行されます。 式は次のように整理されます`n * (n * n + 1) // 2`これにより、正確な算術を維持しながら計算が単純になります。

 ## 特殊なケース

 のために`n = 1`、式は次のようになります。$$1 \times (1^2 + 1) / 2 = 1$$アルゴリズムは出力します`1`、正方形内の唯一のセルと一致します。 複数の行に関する仮定から始まる構築ベースのソリューションは、ここで誤って失敗する可能性があります。 

のために`n = 3`、式は次のようになります。$$3 \times (9 + 1) / 2 = 15$$不注意な解決策は、1 つの特定の魔方陣レイアウトから答えを導き出そうとする可能性があります。 この場合はこれでうまくいきますが、すべての有効な正方形の最初の行の合計が同じになる理由は説明できません。 この公式はすべての魔方陣に共通する不変式を使用するため、配置に関係なく機能します。 

のために`n = 1000`、式は次のようになります。$$1000 \times (1000000 + 1) / 2 = 500000500$$このアルゴリズムは、次の場合と同じいくつかの操作を実行します。`n = 1`、シミュレーションアプローチに必要な百万セルの処理を回避します。
