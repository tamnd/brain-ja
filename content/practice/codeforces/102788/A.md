 ## 問題の理解

 通常の秩序の魔方陣`n`です`n × n`からのすべての数字を含む配列`1`に`n²`まさに一度。 すべての行、すべての列、および両方の主対角線の合計は同じ値です。 任務は広場を建設することではありません。 このような正方形の最初の行の数値の合計が必要なだけです。 入力は正方形の辺の長さで、出力はこの一般的なマジック サムです。 

注文は次のような量まで可能です`1000`したがって、正方形全体を構築するには、最大 100 万個のセルを保存する必要があります。 一部の言語ではまだ可能ですが、その必要はありません。 意図した解決策は、正方形の数学的特性のみを使用し、一定時間で終了する必要があります。 値を配置したり、行と列を検証しようとするシミュレーションは、次の値に比例した作業を実行します。`n²`、一方、答えは直接導き出すことができます。 

主なエッジケースは、小規模な注文と同等の場合に発生します。 のために`n = 1`、正方形には数字のみが含まれます`1`、したがって、答えは次のとおりです`1`。 このケースを処理せずに構築式を盲目的に適用するプログラムは失敗する可能性があります。 例えば：```
Input:
1

Output:
1
```注文`2`そのサイズの通常の魔方陣は存在しないため、決して表示されません。 あらゆるポジティブなことを想定した不注意な実装`n`が有効である場合、不可能な正方形を構築しようとする可能性があります。 制約ではこのケースは除外されるため、プログラムは有効な入力範囲を読み取るだけで済みます。 

## アプローチ

 直接的なアプローチは、実際に通常の魔方陣を作成し、最初の行を計算することです。 奇数次数の場合はシャム構造を使用できますが、他の次数ではより複雑な構造が必要になります。 を構築した後、`n × n`グリッド、最初の行の読み取りにはさらに時間がかかります`O(n)`操作。 このアプローチの問題は、必要以上に難しい問題を解決してしまうことです。 最悪のケースは、`n = 1000`100 万個のセルを作成し、大量の不要な作業を実行します。 

重要な観察は、最初の行の合計が他のすべての行と同じであることです。 正方形全体に数字が含まれています`1`を通して`n²`したがって、すべてのセルの合計が等差級数になります。$$1 + 2 + \dots + n^2 = \frac{n^2(n^2+1)}{2}$$まさにあります`n`すべての行の合計は同じになります。 合計を行数で割ると、マジック サムが得られます。$$\frac{n^2(n^2+1)}{2n} = \frac{n(n^2+1)}{2}$$したがって、答えは完全に次のように決定されます。`n`。 正方形の実際の配置は関係ありません。

 ## アルゴリズムのチュートリアル

 1. 注文を読む`n`魔方陣の。 
2. 次のすべての数値の合計を計算します。`1`に`n²`等差数列の公式を使用すると、次のようになります。$$\frac{n^2(n^2+1)}{2}$$これが機能するのは、通常の魔方陣にはこれらの数値がそれぞれ 1 回だけ含まれるためです。 

1. 合計を次の値で割ります。`n`、正方形には`n`行とすべての行の合計が同じになります。 
2. 結果の値、つまり最初の行の合計を出力します。 

なぜ効果があるのか:

 魔方陣の特徴は、すべての行の合計が同じであることです。 からのすべての数字なので、`1`に`n²`一度出現すると、数値の配置に関係なく、すべてのセルの合計は固定されます。 この固定合計を均等に分割します。`n`rows は、最初の行を含むすべての行の値を返します。 有効な通常の魔方陣はすべて同じ合計と同じ行数を持つため、式は構造に依存できません。 

## Python ソリューション```python

Python の整数は中間の乗算を安全に処理します。 最大値に達するのは、`n = 1000`ただし、結果は依然として Python の整数制限をはるかに下回っています。 問題内の有効な次数のマジック サムは常に整数であるため、整数の除算は正確です。

## テストケース```python
import sys
import io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    return str(n * (n * n + 1) // 2)
