 ## 問題の理解

 重み付けされたグラフとして表された都市があります。 すべての家は固定座標を持つ頂点であり、すべての道路はエッジであり、その重みはその道路を移動する人の数です。 彫像の整数ポイントを選択する必要があります。 道路は、両方の終点の家が距離内にある場合にのみその重量に寄与します。`R`その時点から。 答えは、1 つの像の位置から見える道路の最大総重量です。 

座標は特殊な形をしています。 たくさんの家や道路があり、`100000`それぞれ、そして`y`座標は次のように大きくできます`10^9`。 平面内のすべての可能な点をスキャンするソリューションは不可能です。 全てスキャンしても可能`y`範囲が非常に大きいため、値は機能しません。 唯一の小さな寸法は、`x`家の座標は以下に限定されます`0..100`。 

像はこの範囲外にあると考える必要はありません。 候補点が`x < 0`に移動します`x = 0`同じ状態を保つ`y`を調整し、すべての家までの距離を減らすだけです。 同じ議論が機能します`x > 100`。 したがって、何らかの最適な答えが常に存在します。`0 <= x <= 100`、検査対象となる可能性のある 101 個の垂直線のみが残ります。 

いくつかの詳細は間違いやすいものです。 同じ家の間にある複数の道路は、それらの重みがすべて考慮されるため、個別に処理する必要があります。 道路が貢献するには家だけでは十分ではありません。両方の終点で像が見える必要があります。 例えば：```
2 1 1
0 0
2 0
1 2 5
```正しい出力は次のとおりです。```
0
```の銅像`(1,0)`距離です`1`両家から？ 実は二軒目は遠いんです`1`、でも最初の家も遠いです`1`したがって、この例では出力されます`5`。 危険なケースは、エンドポイントが 1 つだけ近くにある場合です。```
2 1 1
0 0
3 0
1 2 5
```正しい出力は次のとおりです。```
0
```1 つのエンドポイントのみをチェックする不用意なソリューションでは、道路が誤ってカウントされます。 

もう 1 つのエッジ ケースは、選択した道路の可視区間が空である道路です。`x`。 2 つの家はそれぞれ別々に表示されますが、それらの垂直方向の範囲は重なりません。 このような道路を追加してはなりません。 

## アプローチ

 直接的な解決策は、考えられるあらゆるスタチュー ポイントを試してみることです。 ポイントごとにすべての道路をチェックし、両方の終点が十分に近い場合はその重みを追加します。 これは正しいですが、候補点の数を数えることは不可能です。`y`到達できる座標`10^9`。 

より優れたブルートフォースでは、小さなものを使用します`x`範囲。 あらゆる人にとって`x`から`0`に`100`、どの整数を計算できますか`y`ポジションが機能します。 一軒家は次の間隔に貢献します`y`固定値`x`。 水平距離が`dx`の場合、残りの垂直距離は次のようになります。$$\sqrt{R^2-dx^2}$$したがって、家はすべての整数で表示されます`y`で：$$[y_i-dy, y_i+dy]$$道路の場合、2 つのエンドポイント間隔を交差させます。 すべての有効な道路は、現在の垂直線上の加重区間になります。 次に問題は、間隔の重み付けされた最大の重なりを見つけることになります。 

残りの課題は、これを十分な速度で実行することです。 垂直線は 101 本しかないので、すべての道路を処理する必要があります。`x`許容されます。 それぞれについて`x`、スイープイベントを作成します。 間隔`[l,r]`で重量を追加します`l`そしてそれを削除します`r+1`。 すべてのイベントを並べ替えてスキャンすると、そのイベントに表示される旅行者の最大数がわかります。`x`。 

固定後はジオメトリが 1 次元になるため、強引な方法が機能します。`x`、しかし、可能な限りすべてを維持すると失敗します`y`コーディネート。 座標範囲が狭いため、代わりにすべての可能な垂直スライスをチェックすることができます。

 ## アルゴリズムのチュートリアル

 1. すべての家とすべての可能な彫像について事前計算する`x`からのコーディネート`0`に`100`、家から像が見える高さの間隔。 間隔は家の周囲の半分の高さとして保存されます。`y`座標。 家が水平方向に遠すぎる場合、その間隔は無効とマークされます。 
2. 考えられるそれぞれの彫像について`x`、すべての道路を処理します。 道路のために`(a,b)`事前に計算された 2 つの垂直間隔の交差を計算します。 交差点が空でない場合は、2 つのスイープ イベントを作成します。つまり、区間の下部に道路重量を追加し、上部の直後で道路重量を減算します。 
3. イベントをその順に並べ替えます`y`それらを順番に調整してスキャンします。 現在の道路をカバーする現在の道路重量の合計を維持します。`y`座標。 このスキャン中に到達した最大値が、このスキャンに最適なスタチューの位置です。`x`。 
4. 可能な 101 個すべての中で最大の答えを維持します`x`価値観。 

なぜ機能するのか: 固定のため`x`、見えるすべての道路は、有効な整数の 1 つの連続した間隔に正確に対応します。`y`コーディネート。 スイープ ラインは、これらの間隔でカバーされる最大総重量を計算します。これはまさにその垂直線上の最適な像の位置です。 最適な像位置は存在しますので、`x`間`0`そして`100`、そのような行をすべてチェックすると、考えられるすべての最適化がカバーされます。 

## Python ソリューション```python
import sys
import math
from array import array

input = sys.stdin.readline

def solve():
    N, M, R = map(int, input().split())

    xs = [0] * N
    ys = [0] * N
    for i in range(N):
        xs[i], ys[i] = map(int, input().split())

    edges = []
    for _ in range(M):
        a, b, p = map(int, input().split())
        edges.append((a - 1, b - 1, p))

    reach = []
    r2 = R * R

    for x in range(101):
        cur = array('i', [-1]) * N
        for i in range(N):
            dx = x - xs[i]
            rem = r2 - dx * dx
            if rem >= 0:
                cur[i] = math.isqrt(rem)
        reach.append(cur)

    ans = 0

    for x in range(101):
        events = []
        rx = reach[x]

        for a, b, p in edges:
            ra = rx[a]
            if ra < 0:
                continue
            rb = rx[b]
            if rb < 0:
                continue

            low = max(ys[a] - ra, ys[b] - rb)
            high = min(ys[a] + ra, ys[b] + rb)

            if low <= high:
                events.append((low, p))
                events.append((high + 1, -p))

        events.sort()

        cur = 0
        best = 0
        i = 0
        while i < len(events):
            y = events[i][0]
            while i < len(events) and events[i][0] == y:
                cur += events[i][1]
                i += 1
            if cur > best:
                best = cur

        if best > ans:
            ans = best

    print(ans)

if __name__ == "__main__":
    solve()
```の`reach`テーブルには、各家と可能な各家の垂直半径のみが保存されます。`x`。 使用する`array('i')`値は最大でも次のとおりであるため、このテーブルはコンパクトに保たれます。`10000`。 

メインループは 1 つの彫像を修正します`x`すべての道路を区間に変換します。`y`軸。 区間交差には次のものを使用します。`max`下限と`min`上限にあります。 これは、両方のエンドポイントの確認が重要となる部分です。 

スイープ イベントで使用されるのは、`high + 1`の代わりに`high`座標は整数なので。 次の整数に削除イベントを追加すると、最後の有効な位置の直後の間隔が削除されます。 

すべての重みと合計には Python 整数が使用されるため、可能性のある大きな総母集団がオーバーフローすることはありません。

 ## 特殊なケース

 道路に 2 つの端点があり、それらの端点は個別に表示されているものの、その間隔が重なり合っていない場合、交差点テストには次の要求があるため、アルゴリズムはその端点を拒否します。`low <= high`。 これにより、ある地点から実際に像を見ることができない道路を数えるのを防ぐことができます。 

複数の道路が同じ家のペアを接続している場合、各エッジは独自のスイープ イベントのペアを作成します。 スキャンではすべての重みが追加されるため、トラフィックが失われることはありません。 

最適な位置が表示円の端に正確に位置する場合、間隔の端点が含まれるため、整数間隔の計算ではその位置が維持されます。 の使用`r + 1`削除の場合、この境界は正しく保存されます。
