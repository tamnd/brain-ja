 ## 解決策
 ## 問題の理解

 うちには根が生えた木があります。 すべての頂点は 1 から N までの一意の番号を所有するため、その番号は頂点の順列を形成します。 すべての頂点 v について、v のサブツリー内の頂点のみを調べ、その数を収集します。 これらの数値により、いくつかの最大連続範囲が作成されます。 タスクは、頂点ごとにそれらの範囲をカウントすることです。 

たとえば、サブツリーに次の値が含まれている場合、`{2,3,4,8,10,11}`、コンパクトな間隔は次のとおりです。`[2,4]`、`[8,8]`、 そして`[10,11]`したがって、このサブツリーの答えは 3 です。 

課題は、すべてのサブツリーに対してこの答えが必要になることから生じます。 N が 250000 に達し、すべてのテストの合計サイズが 500000 に達すると、すべての頂点の値のセットを再構築することは不可能になります。 二次アプローチでは、チェーン形状のツリー上で約 N² の演算を実行できますが、これは許容される 2 秒の制限をはるかに超えています。 線形または N log N に近い解決策が必要です。 

厄介なケースは、コンパクトな間隔がツリー構造に直接依存するのではなく、隣接する値に依存するという事実によって引き起こされます。 単一の挿入値により、2 つの既存の間隔をマージしたり、新しい間隔を作成したりできます。 

頂点が 1 つあるツリーを考えてみましょう。```
1
```価値のあるもの`1`。 答えは次のとおりです。```
1
```最大範囲ではなく隣接するペアをカウントするソリューションは、単一の値が依然としてコンパクトな間隔であるため、失敗します。 

別のケース:```
1
|
2
```値を使用:```
[2,3]
```頂点 1 のサブツリーには以下が含まれます`{2,3}`、したがって、答えは次のとおりです`1`。 すべての値に後続値があるかどうかのみをチェックする不注意な実装では、それを見逃してしまいます。`[2,3]`は 1 つの完全な間隔です。 

最後の重要なケースはマージです。```
values = {1,3}
```間隔は2回ありますが、`[1,1]`そして`[3,3]`。 付加価値`2`新しい値が両側を結ぶため、答えは 2 から 1 に変わります。 新しい分離された値のみをカウントする更新式は正しくありません。 

## アプローチ

 直接的なアプローチは、すべてのサブツリーを個別に処理することです。 各頂点について、その下にあるすべての値を収集し、並べ替えて、連続する数値の間の切れ目を数えます。 コンパクトな間隔は、連続する値が 1 だけ異なる最大グループであるため、これは正しいです。 

ただし、チェーン ツリーでは、ルート サブツリーには N 個の頂点が含まれ、次のサブツリーには N-1 個の頂点が含まれます。 すべてのサブツリーをソートすると、おおよそ次のようになります。```
N + (N-1) + ... + 1 = O(N²)
```ソートコストが考慮される前でも値が処理されます。 

重要な点は、ソートされたセット全体が必要ないということです。 維持されたセットに値 x を挿入する場合、問題となるのは x-1 と x+1 の存在のみです。 

どちらの近傍も存在しない場合、x は新しい間隔を作成します。 

隣接するものが 1 つ存在する場合、x は既存の間隔を拡張します。 

両方の近傍が存在する場合、x は 2 つの区間を 1 つに結合します。 

したがって、サブツリーを走査している間、コンパクトな間隔の数を動的に維持できます。 

すべてのサブツリー クエリに効率的に答えるために、小規模から大規模へのマージとも呼ばれる、ツリー上の DSU 手法を使用します。 各頂点について、最大の子のデータ構造を保持し、それを再利用します。 より小さな子サブツリーが一時的にこの構造に追加されます。 各頂点は構造間で O(log N) 回しか移動しないため、総作業量は O(N log N) になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(N² log N) | O(N) | 遅すぎる |
 | ツリー上の DSU | O(N log N) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ツリーを頂点 1 にルートし、すべてのサブツリーのサイズを計算します。 この DFS 中に、各頂点の重い子、つまり最大のサブツリーを持つ子を保存します。 
2. ツリー上の DSU を使用してツリーを移動します。 まず、すべてのライトの子を、その後データを保持せずに処理します。 次に、維持されたセットを維持しながら重い子を処理します。 
3. 重い子が処理された後、軽い子のサブツリーからのすべての頂点と現在の頂点を維持されたセットに追加します。 間隔カウンターの現在の値が、このサブツリーの答えを表します。 
4. 現在のカウンターを頂点の答えとして保存します。 このサブツリーが保持としてマークされていない場合は、親呼び出しが正しく続行できるように、保持されている構造からすべての頂点を削除します。 

維持される不変条件は、アクティブ セットには、現在処理されている DSU サブツリーに属する頂点が常に正確に含まれるということです。 間隔カウンターは、1 つの値の追加または削除によるローカルな変更によってのみ更新されるため、そのセット内のコンパクト間隔の数と常に等しくなります。 

x を挿入すると、変更は次のようになります。```
+1 - (x-1 exists) - (x+1 exists)
```x を削除すると、その逆の変化は次のようになります。```
-1 + (x-1 exists) + (x+1 exists)
```これらの式は、間隔の分割と結合を含むすべてのケースをカバーします。 

## Python ソリューション```python
import sys
sys.setrecursionlimit(1 << 20)

input = sys.stdin.readline

def solve():
    n = int(input())
    val = [0] + list(map(int, input().split()))

    g = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        a, b = map(int, input().split())
        g[a].append(b)
        g[b].append(a)

    size = [1] * (n + 1)
    heavy = [0] * (n + 1)
    parent = [0] * (n + 1)

    def dfs(v, p):
        parent[v] = p
        best = 0
        for u in g[v]:
            if u == p:
                continue
            dfs(u, v)
            size[v] += size[u]
            if size[u] > best:
                best = size[u]
                heavy[v] = u

    dfs(1, 0)

    tin = [0] * (n + 1)
    tout = [0] * (n + 1)
    order = []

    def euler(v, p):
        tin[v] = len(order)
        order.append(v)
        for u in g[v]:
            if u != p:
                euler(u, v)
        tout[v] = len(order)

    euler(1, 0)

    present = [False] * (n + 2)
    ans = [0] * (n + 1)
    current = 0

    def add_vertex(v):
        nonlocal current
        x = val[v]
        current += 1
        if present[x - 1]:
            current -= 1
        if present[x + 1]:
            current -= 1
        present[x] = True

    def remove_vertex(v):
        nonlocal current
        x = val[v]
        present[x] = False
        current -= 1
        if present[x - 1]:
            current += 1
        if present[x + 1]:
            current += 1

    def add_subtree(v):
        for i in range(tin[v], tout[v]):
            add_vertex(order[i])

    def remove_subtree(v):
        for i in range(tin[v], tout[v]):
            remove_vertex(order[i])

    def dfs2(v, p, keep):
        for u in g[v]:
            if u != p and u != heavy[v]:
                dfs2(u, v, False)

        if heavy[v]:
            dfs2(heavy[v], v, True)

        for u in g[v]:
            if u != p and u != heavy[v]:
                add_subtree(u)

        add_vertex(v)
        ans[v] = current

        if not keep:
            remove_subtree(v)

    dfs2(1, 0, True)

    print(*ans[1:])

t = int(input())
for _ in range(t):
    solve()
```最初の DFS はサブツリーのサイズを計算し、重い子を識別します。 2 番目の DFS は、DSU-on-tree トラバーサルです。 の`present`配列には、値が現在アクティブなサブツリー内にあるかどうかが格納されます。 

間隔カウンタは変更前に更新されます`present[x]`これは、古い隣接要素が既存の間隔を記述するためです。 削除中は、値自体が存在すると見なされなくなるため、最初に値が削除され、次に近傍がチェックされます。 

Python の整数は任意の精度であるため、オーバーフロー処理は必要ありません。 ツリーは深さ N のチェーンになる可能性があるため、再帰制限が増加します。オイラー順序を使用すると、1 つの連続したセグメントを反復処理することでサブツリー全体を追加または削除できます。
