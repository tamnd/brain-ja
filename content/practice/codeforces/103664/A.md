 ## 問題の理解

## アプローチ

 ## アルゴリズムのチュートリアル

 1. 与えられた正方形サイズに対して、次の関数を定義します。`s`、ボードを覆うために必要なステッカーの数を計算します。 これはコンピューティングによって行われます`ceil(a / s)`そして`ceil(b / s)`そしてそれらを掛け合わせます。 これは、可能な限り最良の軸が揃った配置をモデル化します。 
2. 観察してください`ceil(x / s)`減少するか一定のまま`s`が増加します。 これにより、必要なステッカーの数が単調になることが保証されます。`s`、二分探索には不可欠です。 
3. 二分探索範囲を設定します。`s`。 下限は`1`。 上限は安全に設定できます`max(a, b)`, 両辺より大きい正方形は、1 つのステッカーで長方形全体をカバーすることが簡単にできるためです。 
4. 二分探索を実行します。`s`。 中間点ごとに、必要なステッカーを計算します。 要件が以下の場合`k`、つまり`s`で十分なので、より小さい値を試します。 さもないと、`s`が小さすぎるため、それを増やします。 
5. 有効な最小値まで続行します。`s`が見つかりました。 

### なぜ効果があるのか

 固定の場合`s`、式`ceil(a / s) * ceil(b / s)`は、軸を揃えた最適なカバーに必要な等しい正方形の最小数を正確に表します。 カバーは少なくとも、各寸法を最大でも長さのセグメントに分割する必要があります。`s`、したがって、これらのカウントに勝る建設はありません。 増加するため、関数は単調です`s`どちらの上限期間も引き上げることはできません。 したがって、二分探索は実行可能な最小値に収束します。`s`候補者を逃さずに。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def needed(a, b, s):
    return ((a + s - 1) // s) * ((b + s - 1) // s)

def solve():
    a, b, k = map(int, input().split())

    lo, ro = 1, max(a, b)
    ans = ro

    while lo <= ro:
        mid = (lo + ro) // 2
        if needed(a, b, mid) <= k:
            ans = mid
            ro = mid - 1
        else:
            lo = mid + 1

    print(ans)

if __name__ == "__main__":
    solve()
```実装の中核となるのは、`needed`上限ベースのカウント ロジックをエンコードする関数。 表現`(a + s - 1) // s`標準的な整数安全な計算方法です`ceil(a / s)`浮動小数点演算なし。 

二分探索では、すべてのサイズが次の値よりも大きいという不変条件が維持されます。`ro`は有効で、すべてのサイズが以下より小さい`lo`は無効です。 各ステップは、有効な最小値までこの境界を縮小します。`s`孤立している。 

整数演算のみを使用するように注意する必要があります。 float を使用すると、最大で値の精度エラーが発生します。`10^18`。

 ## 特殊なケース

 重要なエッジケースの 1 つは次のような場合です。`k = 1`。 次に、長方形を 1 つの正方形で覆う必要があるため、答えは次のようになります。`max(a, b)`。 入力用`7 4 1`、アルゴリズムは次のように評価します`s = 4`不十分なので`ceil(7/4)=2`、 そして`s = 7`有効になり、正しく返されます`7`。 

もう一つのケースは次のような場合です。`a`そして`b`等しいし、`k`大きいです。 入力用`6 6 36`、 平`s = 1`36 個の単位正方形でボードをタイル表示できるため、機能します。 二分探索は正しく収束します。`1`。
