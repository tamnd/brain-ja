 ## 問題の理解

 与えられるコインの種類のリストは厳密に増加しており、各種類の種類が次の種類に分割されます。 これは、システムが任意のコインの値ではなく、連鎖乗算構造のように動作することを意味します。 目標金額も設定されています`b`、正確に形成できるかどうかを判断する必要があります`b`これらのコインを使用し、「はい」の場合は、使用されるコインの総数を最小限に抑えます。 

出力は、各金種のコインが何枚使用されているかを示すコインの種類の分布、または正確な表現が存在しないというステートメントのいずれかです。 

可分性条件は重要な構造的制約です。 それぞれなので`a[i]`で割り切れます`a[i-1]`、すべての宗派は、前の宗派の拡大縮小されたバージョンとして解釈できます。 これにより、貪欲な推論が潜在的に実行可能になりますが、それは桁上げと剰余がレベル間でどのように相互作用するかを尊重する場合に限ります。 

という点では制約は小さい`n`、最大でも 30 の宗派がありますが、`b`10^18 までの大きさになる可能性があります。 これにより、合計をめぐる動的計画法は即座に除外されます。 状態空間は天文学的に大きいため、すべてのサブセットまたは量にわたる DP ですら不可能です。 正しいソリューションはすべて、線形または線形に近い時間で実行される必要があります。`n`。 

割り算構造を考慮せずに、できるだけ多くの大きなコインを貪欲に取得しようとすると、微妙な失敗例が発生します。 たとえば、宗派が次のとおりである場合、`[1, 3, 9]`そして`b = 6`、素朴な貪欲な戦略では、`9`コインは無理なのでかかります`3 + 3`これは正しいですが、非標準的な動作を持つより複雑なシステムでは、貪欲は失敗する可能性があります。 ここで、正しさは、基本変換スタイルの推論を可能にする割り算チェーンに依存します。 

もう 1 つの失敗モードは、あるレベルで残った余りが、割り算の比率に応じて次の金種に転送できる場合とできない場合があることを忘れていることです。 適切に正規化しないと、不可能であると誤って結論付ける可能性があります。

 ## アルゴリズムのチュートリアル

 まず、連続する額面間の比率を前処理します。 それぞれについて`i > 1`、 定義する`r[i] = a[i] / a[i-1]`。 

次に、最大額面から下に向かって作業し、まだ表現する必要がある残りの金額を維持します。 

1. から始める`rem = b`。 この値は、より高級な宗派ではまだ表現されていないものを表しています。 配列も初期化します`cnt`サイズの`n`ゼロに。 
2. 宗派ごとに`i = n`まで`2`、フルコインが何枚あるかを計算します。`a[i]`から取ることができます`rem`ただし、次の小さなスケールと一貫した方法でのみです。 私たちは計算します`cnt[i] = rem // a[i]`、その後、減らします`rem = rem % a[i]`。 

価値のあるコインを取得するため、このステップは有効です`a[i]`より高い倍数のみに影響を与える`a[i-1]`、そして割り切れるため、より低い額面が常に余りを表すことができます。 
3. 下に進む前に、次のことを確認する必要があります。`rem`次のレベルのスケーリングと互換性があります。 具体的には、`a[i]`の倍数です`a[i-1]`、残り`rem`はすでに自然に単位になっています`a[i-1]`スケールが大きいため、整数除算以外の調整は必要ありません。 
4. まで加工した後、`i = 2`、私たちに残されたのは`rem`これは次を使用して処理する必要があります`a[1]`。 設定しました`cnt[1] = rem // a[1]`、更新します`rem = rem % a[1]`。 
5. 最後に`rem != 0`、それは正確に表現できないことを意味します`b`利用可能な金種を使用するので、出力します`"Impossible"`。 
6. それ以外の場合は、カウントを出力します。 

重要な考え方は、割り算の連鎖により、すべての余りがレベルにあるということです。`i`最終ステップで次のように割り切れる場合に限り、より小さい額面を使用して表現できることが保証されます。`a[1]`。 このアルゴリズムは、すべての決定が基数構造と局所的に一貫していることを保証することにより、後戻りを回避します。 

### なぜ効果があるのか

 宗派の構造により、各宗派が階層構造を形成します。`a[i]`の整数倍です`a[i-1]`。 これは、より高い額面を使用して表現できるすべての数字が、常に、より低い額面で定義されたグリッド上に配置されることを意味します。 各レベルで寄与を貪欲に抽出すると、効果的に位置分解を実行することになります。`b`混合基数システムで。 不変条件は、処理後のレベルです。`i`、残りの値は常に厳密に以下になります。`a[i]`宗派を使用して完全に表現可能です`1..i-1`それがまだ割り切れる場合に限り、`a[1]`。 これにより、今後のステップで以前に選択した係数が無効にならないことが保証されるため、構築はグローバルに一貫しています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    b = int(input())

    cnt = [0] * n
    rem = b

    for i in range(n - 1, -1, -1):
        cnt[i] = rem // a[i]
        rem %= a[i]

    if rem != 0:
        print("Impossible")
    else:
        print(*cnt)

if __name__ == "__main__":
    solve()
```この実装は、貪欲な分解を直接反映しています。 私たちは実行残金を維持し、最大額面から最小額面まで拠出金を剥がします。 重要な微妙な点は、構造によって整合性が保証されるため、隣接する宗派間の可分性を明示的にチェックする必要がないことです。`a[i]`の倍数です`a[i-1]`、つまりモジュロを削減します`a[i]`下位レベルの一貫性を維持します。 

よくある間違いは、比率伝播を明示的に使用してカウントを調整しようとすることです。 この混合基数システムでは整数除算がすでに正しい桁抽出を実行しているため、ここではその必要はありません。
