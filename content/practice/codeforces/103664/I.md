 ## 解決策
 ## 問題の理解

 次のシーケンスを構築するように求められます。$n$シーケンスから選択された任意の 3 つの数値が非縮退三角形の辺の長さを形成できるような、別個の正の整数。 幾何学的用語で言うと、すべてのトリプルに対して$a \le b \le c$この集合から、三角不等式が成り立つ必要があります。つまり、$a + b > c$。 選択したすべての値も個別である必要があり、それぞれが次の値を超えてはなりません$10^9$。 

入力は整数のみです$n$、出力は有効なセットです。$n$条件を満たす数値です。 

制約$n \le 10^5$トリプルを明示的に検証しようとする構造は直ちに除外されます。 すべてのトリプルを直接チェックするには、$O(n^3)$実行可能な限界をはるかに超えた操作。 候補となる 3 番目の要素に対してすべてのペアをチェックしたとしても、$O(n^2)$、これもこの規模では遅すぎます。 

素朴な思考による微妙な失敗例は、構造のない任意の数値またはランダムな増加シーケンスを選択することです。 たとえば、次のような 2 の累乗を選択すると、$1, 2, 4, 8$すぐに壊れてしまうので$1 + 2 \le 4$, したがって、小さなサブセットでも三角形条件に違反します。 これは、成長率が非常に重要であることを示しています。最大の要素が 2 つの小さい要素の合計を支配するため、急速に成長するシーケンスは失敗します。 

したがって、課題は、トリプル内の最小の 2 つの要素であっても最大の要素を超えることができるように、十分な密度を維持するシーケンスを設計することです。 

## アプローチ

 ブルートフォース試行では、候補セットが生成され、すべてのトリプルの三角形条件がチェックされます。 固定セットの場合、有効性を検証するにはすべてを調べる必要があります。$\binom{n}{3}$トリプル、つまり約$n^3 / 6$小切手。 と$n = 10^5$、これは天文学的に大きいため、制限時間内に実行することはできません。 

重要な観察は、トリプル内の最大の要素に対して可能な限り最小の和を求める場合に、三角形不等式を満たすことが最も難しいということです。 シーケンスをソートすると、条件はインデックスに関して連続するトリプルのみをチェックすることになります。これは、サブセット内の最小の 2 つの要素と最大の要素に当てはまる場合は、他のすべての要素にも当てはまります。 

これは構造の単純化につながります。つまり、最小の 2 つの要素の合計が、トリプル内の可能な最大の要素よりも常に大きくなるシーケンスが必要です。 これを保証する簡単な方法は、シーケンスを十分に大きな基数から始まる連続した整数にすることです。 連続する数値はギャップを最小限に抑え、最大の要素に対する最小の 2 つの要素の合計を最大化します。 

順序を選択すると$n-1, n, n+1, \dots, 2n-2$、すると、最悪の場合のトリプルは次のようになります。$n-1, n, 2n-2$。 この極端なケースでも、次のような結果が得られます。$$(n-1) + n = 2n - 1 > 2n - 2$$したがって、三角不等式は常に成り立ちます。 他のトリプルは、左側を改善するか、右側を減少させるだけです。

 ## アルゴリズムのチュートリアル

 この構築は、2 つの要素の最小和がトリプル内の最大要素よりも優先されるように、上方にシフトされた一連の連続する整数を出力することによって機能します。 

1. 開始値を次のように選択します。$n-1$。 これにより、可能な最小のペアの合計が、使用する最大要素に比べてすでに大きくなっていることが保証されます。 
2. 以下のすべての整数をリストしてシーケンスを構築します。$n-1$まで$2n-2$包括的な。 これは正確に生成します$n$明確な数字。 
3. これらの数値を昇順に出力します。 構造によって順序がすでに保証されているため、後で並べ替える必要はありません。 

この特定の間隔を選択する理由は、範囲を可能な限り厳密に圧縮しながら、最小要素と最大要素の間のギャップが最大化される極端な構成の三角不等式を保証するためです。 

### なぜ効果があるのか

 ソートされたシーケンスからのトリプルには、少なくとも最小の 2 つの要素が含まれます。$n-1$そして$n$、その最大の要素は最大でも$2n-2$。 最悪の場合の三角形の不等式チェックは 3 倍に縮小されます。$(n-1, n, 2n-2)$。 以来$2n-1 > 2n-2$、不等式は最も厳しい場合に厳密に当てはまります。 他のすべてのトリプルは、2 つの小さい要素の合計を増やすか、最大値を減らすだけなので、違反は発生しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    res = [str(i) for i in range(n - 1, 2 * n - 1)]
    print(" ".join(res))

if __name__ == "__main__":
    solve()
```実装は構築の直後に行われます。 範囲は次から始まります$n-1$そしてで終わります$2n-2$、正確に生産$n$価値観。 一度文字列に変換して結合すると、繰り返しの I/O オーバーヘッドが回避されます。これは、$n = 10^5$。 

よくある間違いは、範囲のエンドポイントが 1 つずれていることです。 正しいエンドポイントは包括的です$2n-2$、Python では次のようになります。`range(n - 1, 2 * n - 1)`上限は排他的であるため。

 ## 特殊なケース

 最小入力の場合$n = 3$、建設の成果$2, 3, 4$。 唯一可能なトリプルはフルセット自体であり、それは次の条件を満たします。$2 + 3 > 4$。 これにより、柔軟性が存在しない下限境界で構築が有効であることが確認されます。 

大型用$n$、 のような$n = 10^5$、シーケンスの範囲は次のとおりです。$99999$に$199998$。 三角形の状態は依然として最悪のケースにまで減少します$99999 + 100000 > 199998$、これは厳密に成り立ちます。 最大スケールでも、線形成長により、最小合計と最大要素の間のギャップが正しい方向に制限されたままになります。
