 ## 解決策
 ## 問題の理解

 いくつかの同一の棒が与えられ、そのすべてを正確に使用して長方形の格子構造を形成することが課題です。 サイズのグリッド$n \times m$は単位正方形に分割された長方形で、グリッド内のすべての単位エッジが棒で表されます。 これは、外側の境界線とすべての内側のグリッド線の両方にスティックが使用されることを意味します。 

固定ペアの場合$(n, m)$、必要なスティックの数は、両方向の単位セグメントの数によって決まります。 水平方向には、$n+1$水平線はそれぞれ次のもので構成されます$m$セグメント、貢献$m(n+1)$。 縦方向には、$m+1$それぞれの垂直線は、$n$セグメント、貢献$n(m+1)$。 したがって、スティックの合計数は次のようになります。$$k = m(n+1) + n(m+1) = 2nm + n + m$$各テスト ケースの目標は 2 つあります。 まず、正の整数のペアが少なくとも 1 つあるかどうかを判断します。$(n, m)$与えられた条件に対してこの式を満たします$k$。 存在しない場合、答えは不可能です。 それ以外の場合は、すべての有効なペアのうち、可能な最小および最大の領域を計算します。$n \cdot m$。 

制約により許可されるのは、$k$まで$10^9$最大 10 個のテスト ケースがあるため、どのソリューションでもディメンションのすべてのペアを反復することを避ける必要があります。 全体を直接検索$n, m$ナイーブでも遅すぎるでしょう$O(k)$テストケースごとにスキャンすることは不可能です。 

微妙なエッジ ケースは、次の値が小さい場合です。$k$。 例えば、$k = 3$有効なグリッドを形成することはできません。$1 \times 1$グリッドには4本のスティックが必要です。 もう 1 つのケースは、同じ形状に対して複数の形状が存在する場合です。$k$、 のような$k = 22$、ここで両方とも$1 \times 7$そして$2 \times 4$構成は有効ですが、生成される領域が異なります。 

## アプローチ

 ブルートフォースアプローチはあらゆる可能性を試みるでしょう$n, m$そのような$2nm + n + m = k$。 並べ替えると次のようになります。$$(2n+1)(2m+1) = 2k + 1$$したがって、効率的にファクタリングを行っています$2k+1$2つの奇数因子に分けられます。 単純な解決策では、考えられるすべての因子のペアを反復処理します。$2k+1$、それらが有効に対応しているかどうかを確認してください$n, m$、面積を計算します。 

番号$2k+1$と同じ大きさにすることができます$2 \cdot 10^9 + 1$したがって、平方根まですべての約数をスキャンすることはすでに境界線に達していますが、10 個のテスト ケースではまだ許容されます。 ただし、重要な観察は、因数分解すると、$2k+1$、各約数ペアは一意のグリッドに直接マッピングされ、ネストされた検索の必要がなくなります。 

変革$(2n+1)(2m+1) = 2k+1$重要な単純化です。 2 変数のディオファントス方程式を解く代わりに、問題を 1 つの数値の因数ペアを列挙し、それらを次元にデコードすることに縮小します。

 ## アルゴリズムのチュートリアル

 因数分解恒等式に依存します$(2n+1)(2m+1) = 2k+1$、すべての有効なグリッドを除数のペアにエンコードします。 

1. 入力を変換する$k$の中へ$N = 2k + 1$。 これにより、幾何学的制約が純粋な因数分解問題に変換されます。 
2. すべての整数を反復処理します。$d$1から$\lfloor \sqrt{N} \rfloor$。 それぞれ$d$の約数の候補です$N$。 
3. もし$d$分割する$N$、ペアの約数を計算します$N / d$。 
4.両方あるかどうかを確認します$d$そして$N/d$奇数です。 これにより、それらが次の有効な値に対応することが保証されます。$2n+1$そして$2m+1$。 
5. 以下を使用して寸法を復元します。$$n = \frac{d - 1}{2}, \quad m = \frac{N/d - 1}{2}$$6. 面積を計算する$n \cdot m$すべての有効なペアの最小値と最大値を追跡します。 
7. 有効なペアが存在しない場合は、-1 を出力します。 それ以外の場合は、最小面積と最大面積を出力します。 

### なぜ効果があるのか

 すべての有効なグリッドは整数のペアに一意に対応します$n, m$、奇数に一意に対応します$2n+1$そして$2m+1$、その製品はまさに$2k+1$。 逆に、次のすべての因子ペアは、$2k+1$奇数の整数に変換すると、有効なグリッドにマップされます。 これにより、解と奇数因子のペアの間に 1 対 1 の対応関係が作成され、約数を列挙します。$2k+1$冗長性や省略なしにソリューション空間全体を探索します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        k = int(input())
        N = 2 * k + 1

        import math
        best_min = float('inf')
        best_max = -1
        found = False

        r = int(math.isqrt(N))
        for d in range(1, r + 1):
            if N % d == 0:
                d2 = N // d

                if d % 2 == 1 and d2 % 2 == 1:
                    n = (d - 1) // 2
                    m = (d2 - 1) // 2

                    if n > 0 and m > 0:
                        area = n * m
                        best_min = min(best_min, area)
                        best_max = max(best_max, area)
                        found = True

        if not found:
            print(-1)
        else:
            print(best_min, best_max)

if __name__ == "__main__":
    solve()

奇数の値のみを次のように記述できるため、奇数の除数を明示的に強制します。$2n+1$。 私たちも執行します$n, m > 0$、これにより、他の方法で表示される縮退した 0 次元グリッドが除外されます。$d = 1$。 

異なる因子のペアが同じでも異なる長方形の形状を生成する可能性があるため、最小および最大面積の追跡はすべての有効な分解にわたって実行されます。$k$。

 ## 特殊なケース

 いつ$k = 3$、私たちは得ます$N = 7$、これは素数です。 唯一の因子ペアは次のとおりです。$1 \cdot 7$そして$7 \cdot 1$、両方とも生産しています$n = 0$または$m = 0$。 正の次元が必要なため、アルゴリズムは両方を正しく拒否し、結果は -1 になります。 

いつ$k = 4$、$N = 9$、唯一の有効な因子のペアは$3 \cdot 3$。 これにより、$n = m = 1$、単一単位正方形が生成されるため、最小面積と最大面積は両方とも 1 に等しくなります。 

いつ$k = 22$、$N = 45$、複数の因子ペアによって有効なグリッドが生成され、アルゴリズムはそれらすべてを対称的に列挙します。 最小値と最大値の追跡は、最小値と最大値の間の広がりを正確に捕捉します。$1 \times 7$そして$2 \times 4$非対称の重複を失わずに構造を構築できます。
