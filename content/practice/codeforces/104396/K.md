 ## 解決策
 ## 問題の理解

 有向グラフが与えられます$n$ノードでは、各ノードは厳密に 1 つの出力エッジと 1 つの入力エッジで終わることになっているため、最終的な構造は関数グラフとなり、これは次の順列に相当します。$n$ノード。 

一部のエッジはすでに修正されています。 これらの固定エッジは決して変化しません。 出力エッジがまだ欠落しているすべてのノードは出力次数ゼロ ノードと呼ばれ、入力エッジがまだ欠落しているすべてのノードは入次数ゼロ ノードと呼ばれます。 構築プロセスでは、自由な発信エンドポイントと自由な着信エンドポイントを繰り返しペアにし、それらの間に有向エッジをすべての可能性にわたって均一にランダムに作成します。 これは、すべてのノードに 1 つの発信エッジと 1 つの着信エッジが存在するまで続きます。 

ランダム性は、これらの残りのエンドポイントがどのようにペアになるかにのみ影響するため、最終的なグラフは、指定された部分構造と一致するすべての補完に均一に分散されます。 

タスクは、最終的な関数グラフ内の有向サイクルの予想数をモジュロで計算することです。$10^9+7$。 

制約$n \le 10^5$補完を列挙したり、ランダム性をシミュレートしたりするソリューションは直ちに除外されます。 すべての順列を保存することさえ不可能です。 構造は、線形または線形に近い時間で計算できるものに還元する必要があります。 

微妙なのは、最初の固定エッジがすでに部分的なチェーンと、場合によってはいくつかの完了したサイクルを作成していることです。 グラフを純粋なランダムな並べ替えとして扱う不用意なアプローチは、これらの強制エッジによって課される制約を無視し、誤った期待を生み出します。 

一般的なエッジ ケースは、すべてのエッジがすでに固定されていて、互いに素なサイクルになっている場合です。これは、ランダム性が残っていないことを意味します。 その場合、答えは、何にも勝る期待値ではなく、正確なサイクル数に等しくなければなりません。 もう 1 つのエッジ ケースは、最初はサイクルが存在せず、すべてのノードが単一の長い強制チェーン内にある場合です。 この場合、ランダム性はエンドポイントを並べ替えるだけであり、答えは純粋にそのエンドポイント セットのサイズに依存します。 

## アプローチ

 強引なアイデアは、欠落しているエッジを完成させるための有効な方法をすべて列挙し、結果として得られるそれぞれの順列を構築し、サイクルをカウントし、平均することです。 各補完の可能性は等しいため、これは原理的には正しいですが、補完の数は欠落エッジの数に応じて階乗的に増加します。 まで$10^5$ノードでは、単一の補完を保存することさえすでに不可能であるため、このアプローチはすぐに失敗します。 

重要な観察は、固定エッジがグラフを有向チェーンと、おそらくすでに閉じたサイクルに分解することです。 入力では入次数と出力次数が最大 1 であるため、すべてのノードはそのような構造に 1 つだけ属します。 

各有向チェーンには、一意の開始ノード (入力エッジなし) と一意の終了ノード (出力エッジなし) があります。 ランダム プロセスでは、チェーン全体の開始と終了のみが接続され、チェーンの終了のセットとチェーンの開始のセットの間にランダムな全単射が効果的に形成されます。 

これにより、問題は 2 つの部分に分かれます。 まず、既存の各有向サイクルは、最終的な答えに決定的に 1 だけ寄与します。 第二に、もしあれば$k$チェーンの場合、ランダムな補完は、一様にランダムな置換と同等になります。$k$要素。各要素はチェーンに対応します。 サイズのランダムな並べ替えで予想されるサイクル数$k$は高調波数です$H_k$。 

したがって、最終的な答えは次のようになります。$$\text{cycles in fixed part} + H_k$$どこ$$H_k = \sum_{i=1}^k \frac{1}{i} \pmod{10^9+7}$$| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |

 ## アルゴリズムのチュートリアル

 グラフを、各ノードが最大 1 つの出力エッジと 1 つの入力エッジを持つ構造に変換します。 

まず、単純なトラバーサルを使用して、完全に閉じた有向サイクルに既に属しているすべてのノードを検出します。 各ノードには出力エッジが最大 1 つあるため、ノードを再訪問するか行き止まりに到達するまでポインタをたどることができます。 ノードを再訪すると、サイクルが見つかりました。 

次に、これらのサイクルに属するすべてのノードをマークし、そのようなサイクルがいくつ存在するかを数えます。 これらのサイクルはすでに完了しており、有効な完了ごとにサイクルが残ります。 

3 番目に、残りの構造を特定します。これは、互いに素な有向パスの集合である必要があります。 各パスには、正確に 1 つの開始点 (入力エッジなし) と 1 つの終了点 (出力エッジなし) があります。 このようなパスの数を次のようにします。$k$。 この値は、一致しない送信エンドポイントと一致しない受信エンドポイントの数にも等しくなります。 

4 番目に、ランダムな構築では送信エンドポイントと受信エンドポイントのみが接続され、これらの間にランダムな全単射が形成されることが観察されます。$k$が始まり、$k$終わります。 これは、一様ランダム順列を生成するのと同じです。$k$要素。 

5 番目に、サイズをランダムに並べて予想されるサイクル数を計算します。$k$、これは高調波数です$H_k$。 モジュラー逆関数を最大で事前計算します。$n$そしてそれらを合計します。 

最後に、固定サイクルの合計を出力し、$H_k$。 

### なぜ効果があるのか

 固定エッジは、グラフをすでにサイクルまたは線形チェーンのコンポーネントに分割します。 ランダム プロセスはチェーン内で相互作用せず、エンドポイントを接続することによってチェーン全体を並べ替えるだけです。 この独立性により、グローバル構造はコンポーネントにわたる順列に還元され、サイクル形成はこの順列のみに依存します。 順列におけるサイクルの期待値は線形であり、高調波数に等しいため、結果は直接的に続きます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, m = map(int, input().split())
    
    nxt = [-1] * (n + 1)
    indeg = [0] * (n + 1)
    outdeg = [0] * (n + 1)

    for _ in range(m):
        a, b = map(int, input().split())
        nxt[a] = b
        outdeg[a] += 1
        indeg[b] += 1

    # detect cycles in functional graph
    vis = [0] * (n + 1)
    in_cycle = [0] * (n + 1)
    cycle_count = 0

    def dfs(u):
        stack = []
        while u != -1 and vis[u] == 0:
            vis[u] = 1
            stack.append(u)
            u = nxt[u]

        if u != -1 and vis[u] == 1:
            # found cycle
            cycle_nodes = set()
            while True:
                v = stack.pop()
                cycle_nodes.add(v)
                if v == u:
                    break
            for v in cycle_nodes:
                in_cycle[v] = 1
            return 1
        return 0

    for i in range(1, n + 1):
        if vis[i] == 0:
            cycle_count += dfs(i)

    # count chains (nodes not in cycles)
    start_nodes = 0
    for i in range(1, n + 1):
        if in_cycle[i] == 0:
            if indeg[i] == 0:
                start_nodes += 1

    k = start_nodes

    # harmonic number
    inv = [0] * (n + 2)
    inv[1] = 1
    for i in range(2, n + 2):
        inv[i] = MOD - (MOD // i) * inv[MOD % i] % MOD

    H = 0
    for i in range(1, k + 1):
        H = (H + inv[i]) % MOD

    print((cycle_count + H) % MOD)

if __name__ == "__main__":
    solve()
```このソリューションでは、最初に部分関数グラフを構築し、次に単一出次構造のトラバーサルを使用して決定論的なサイクルを抽出します。 これらのサイクルを削除した後に残るのは一連のチェーンでなければならず、それらの開始点を数えることで、暗黙的に形成しているランダムな順列のサイズがわかります。 高調波の合計は、浮動小数点推論を回避する逆モジュラーを使用して効率的に計算されます。 

実装の微妙な詳細は、チェーンのエンドポイントをカウントする前にサイクル ノードを分離することです。 サイクルが除外されない場合、サイクルは入次数と出次数の両方のブックキーピングに誤って寄与し、次数の値が破損します。$k$。 

## 実用的な例

 ### サンプル 1

 入力:```
4 2

3 1
```2 つのチェーンから始めます。$2 \to 4$そして$3 \to 1$。 サイクルの一部となるノードはありません。 

したがって、cycle_count = 0 となり、次のようになります。$k = 2$鎖。 

高調波値:$$H_2 = 1 + 1/2$$したがって、答えは次のとおりです。$$1/2 = 500000004,\quad 1 + 500000004 = 500000005$$### サンプル 2

import sys, io

MOD = 10**9 + 7

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n, m = map(int, input().split())
    nxt = [-1] * (n + 1)
    indeg = [0] * (n + 1)
    vis = [0] * (n + 1)
    in_cycle = [0] * (n + 1)

    edges = []
    for _ in range(m):
        a, b = map(int, input().split())
        nxt[a] = b
        indeg[b] += 1

    def dfs(u):
        stack = []
        cur = u
        while cur != -1 and vis[cur] == 0:
            vis[cur] = 1
            stack.append(cur)
            cur = nxt[cur]
        if cur != -1 and vis[cur] == 1:
            cyc = set()
            while True:
                v = stack.pop()
                cyc.add(v)
                if v == cur:
                    break
            for v in cyc:
                in_cycle[v] = 1
            return 1
        return 0

    cycle_count = 0
    for i in range(1, n + 1):
        if not vis[i]:
            cycle_count += dfs(i)

    start_nodes = 0
    for i in range(1, n + 1):
        if not in_cycle[i] and indeg[i] == 0:
            start_nodes += 1

    k = start_nodes

    inv = [0] * (n + 2)
    inv[1] = 1
    for i in range(2, n + 2):
        inv[i] = MOD - (MOD // i) * inv[MOD % i] % MOD

    H = 0
    for i in range(1, k + 1):
        H = (H + inv[i]) % MOD

    return str((cycle_count + H) % MOD)

 ## 特殊なケース

 重要なエッジ ケースは、ランダムな完了の前に、すべてのノードがすでに有効なサイクルを形成している場合です。 その場合、チェーンのエンドポイントは存在しないため、$k = 0$高調波の寄与はゼロです。 このアルゴリズムは、確定的なサイクル数のみを正確に返します。 

もう 1 つのケースは、サイクルがまったくなく、グラフが単一の長いチェーンである場合です。 それから$k = 1$したがって、高調波数は 1 です。これは、ランダムな再接続後に順列全体が単一のサイクル コンポーネントとして動作することを反映して、最終的に予想されるサイクル数が 1 であることを意味します。 

どちらの場合も、決定論的サイクルへの分解に直接続き、さらにチェーン コンポーネントの順列が続き、これは構造のサイズに関係なく有効です。
