 ## 解決策
 ## 問題の理解

 原点から固定点まで広がる、軸に沿った大きな直方体が与えられます。$(W, H, L)$。 このコンテナの中に、誰かがいくつかの小さな軸を揃えた直方体を配置しました。 それぞれの小さな直方体は 2 つの対向する角によって指定されるため、座標軸に沿った閉じた長方形の体積を占めます。 

課題は、これらの小さな直方体が大きな直方体を完全に分解したものであるかどうかを検証することです。 つまり、大きな直方体内のすべての点は、正確に 1 つの小さな直方体に属している必要があり、重複や覆われていないスペースがあってはなりません。 

直接的な解釈は幾何学的なものです。指定されたボックスが 3D ボックスを完全に並べているかどうかをチェックしています。 

この制約により、カバレッジをポイントごとにテストしたり、3D グリッドをシミュレートしようとするアプローチは直ちに除外されます。 座標は次のようになります$10^9$したがって、全空間にわたる離散化は不可能です。 到達できる直方体の数$10^5$テストケースごとに、$3 \cdot 10^5$全体として、私たちは次の方向に向かうことになります。$O(n \log n)$またはテストケースごとの線形解。 

直感だけに頼っていると、いくつかの失敗例を見逃してしまいがちです。 

1 つの問題は、総体積を維持するオーバーラップです。 たとえば、同じ領域に配置された 2 つの同一の直方体は、別の領域がカバーされていない場合にのみ、ターゲットと等しい総体積を生成します。 単純なボリューム チェックだけでは重複を検出できません。 

もう一つの問題は内部の穴です。 1 つの軸に沿って隙間をあけて積み重ねられた 2 つの直方体を考えてみましょう。 別の直方体が他の場所で誤って重なった場合でも、合計の体積は一致する可能性があります。 

3 番目の問題は、投影でのみ表示される 1 つの次元に沿った部分的な重なりです。 たとえば、2 つのボックスは 3D ボリューム内で完全には重なりませんが、断面におけるそれらの投影により、特定のスライスにのみ現れる重なりやギャップが生じる可能性があります。 

したがって、本当に難しいのは、総量だけでなく、グローバルな適用範囲とローカルな一貫性の両方を確保することです。 

## アプローチ

 最も素朴なアイデアは、空間を離散化するか、大きな直方体の内部の点をサンプリングすることによってカバレッジをチェックすることです。 座標範囲が大きすぎて、実際には潜在的な点の数が無限であるため、この方法はすぐに失敗します。 有効または無効なタイリングは内部でのみ異なる可能性があるため、コーナーやエッジをサンプリングしても不十分です。 

もう少し良いアイデアは、総体積を計算することです。 すべての直方体の体積の合計が次の値に等しくない場合$W \cdot H \cdot L$、答えは即座にノーです。 ただし、重複により 1 つの領域のボリュームが膨張し、他の領域ではギャップが解消される可能性があるため、ボリュームが等しいことは正確さを保証しません。 

重要な構造的観察は、軸を揃えたボックスがスライス下でも適切に動作することです。 座標を固定する場合は、次のようにします。$z$、そして 2 つの連続するユニークな構造の間にある薄いスラブを見てください。$z$-すべての直方体から座標を取得し、そのスラブ内でアクティブな直方体のセットが固定されます。 各直方体はスラブを完全に覆うか、まったく交差しません。 これにより、3D 問題が一連の 2D 問題に縮小されます。 

各スラブ内では、アクティブな四角形がスラブ内にあるかどうかを確認するだけで済みます。$xy$- 平面は長方形の完璧なタイリングを形成します$[0, W] \times [0, H]$。 これは古典的な 2D カバレッジ検証の問題です。 

2D では、1 つの軸に沿ってスイープすることで、幾何学的な点のチェックを再度回避します。 長方形の垂直エッジをソートし、もう一方の軸に沿ってアクティブな間隔を維持します。 いつでも固定$x$-ストリップ、結合$y$-間隔は正確にカバーする必要があります$[0, H]$隙間や重なりがないように。 

これにより、元の 3D 検証が大幅に簡素化されます。$z$、各スラブの内側をスイープします。$x$。 この構造はネストされていますが、各四角形が一定数のイベントのみを提供するため、依然として効率的です。

 ## アルゴリズムのチュートリアル

 この問題を、水平スライスにわたる独立した 2D タイリング チェックに分解することで解決します。 

### 1. すべての一意の Z 座標を抽出します。 

ごとに収集します$z_l$そして$z_r$入力四角形から選択して並べ替えます。 これらの値は、Z 軸に沿ったスラブの境界を定義します。 

連続する Z 値間の間隔内では、アクティブな直方体のセットは変化しないため、このステップは重要です。 

### 2. 各 Z スラブを個別に処理する

 インターバルごとに$[z_i, z_{i+1}]$、z 範囲がこのスラブを完全にカバーするすべての直方体を考慮します。 このような各直方体は、xy 平面上への完全な 2D 長方形の投影に寄与します。 

スラブと交差しない直方体は、そこでのカバレッジに影響を与えないため、無視します。 

### 3. スラブの 2D カバレッジを確認する

 このスラブ内のアクティブな長方形に対して、X 軸に沿ってスイープ ラインを実行します。 

私たちは次の場所でイベントを作成します$x_l$そして$x_r$、+1 および -1 マーカーを持つ y 間隔を保存します。 

イベントを x 座標で並べ替えます。 

アクティブな y カバレッジを表す構造を維持します。 あるイベント x から次のイベント x に移動すると、アクティブな y 間隔のセットが完全にカバーするはずです。$[0, H]$。 

x 間隔ごとに、アクティブな y セグメントの結合が 0 から H まで重複やギャップなく正確に連続しているかどうかを確認します。 

いずれかの時点で不一致がある場合、タイリングは失敗します。 

### 4. グローバルな一貫性を検証する

 すべての Z スラブが 2D テストに合格し、すべての長方形が集合的にボリュームと一致する場合$W \cdot H \cdot L$の場合、分解は有効です。 

### なぜ効果があるのか

 重要な不変条件は、各 Z 間隔内で、ジオメトリが静的な 2D タイリング問題に帰着するということです。 3D のオーバーラップまたはギャップは、少なくとも 1 つのスラブに現れる必要があります。これは、違反には境界座標間の Z 間隔への非ゼロのボリューム投影があるためです。 

2D 内では、スイープ ラインにより、すべての x 位置で、アクティブな y 間隔の結合が正確に分割されることが保証されます。$[0, H]$。 これにより、重複なしと完全なカバレッジの両方が同時に適用されます。 すべてのスラブは独立して検証され、スラブは高さ全体を分割するため、すべてのスラブの正確性は、完全な 3D 領域の正確性を意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def check_2d(rects, W, H):
    events = []
    for xl, yl, xr, yr in rects:
        events.append((xl, yl, yr, 1))
        events.append((xr, yl, yr, -1))

    events.sort()
    from collections import defaultdict

    active = defaultdict(int)

    def add(y1, y2, v):
        active[(y1, y2)] += v
        if active[(y1, y2)] == 0:
            del active[(y1, y2)]

    def covered_ok():
        segs = sorted(active.keys())
        if not segs:
            return False
        cur = 0
        for y1, y2 in segs:
            if y1 > cur:
                return False
            cur = max(cur, y2)
        return cur == H

    i = 0
    while i < len(events):
        x = events[i][0]

        # process all events at x
        while i < len(events) and events[i][0] == x:
            _, y1, y2, t = events[i]
            add(y1, y2, t)
            i += 1

        if i < len(events):
            if not covered_ok():
                return False

    return True

def solve():
    T = int(input())
    for _ in range(T):
        W, H, L = map(int, input().split())
        n = int(input())

        cuboids = []
        z_vals = {0, L}

        for _ in range(n):
            xl, yl, zl, xr, yr, zr = map(int, input().split())
            cuboids.append((xl, yl, zl, xr, yr, zr))
            z_vals.add(zl)
            z_vals.add(zr)

        z_vals = sorted(z_vals)

        total_volume = 0
        for xl, yl, zl, xr, yr, zr in cuboids:
            total_volume += (xr - xl) * (yr - yl) * (zr - zl)

        if total_volume != W * H * L:
            print("No")
            continue

        ok = True

        for i in range(len(z_vals) - 1):
            z1, z2 = z_vals[i], z_vals[i + 1]
            if z1 == z2:
                continue

            rects = []
            for xl, yl, zl, xr, yr, zr in cuboids:
                if zl <= z1 and zr >= z2:
                    rects.append((xl, yl, xr, yr))

            if not check_2d(rects, W, H):
                ok = False
                break

        print("Yes" if ok else "No")

if __name__ == "__main__":
    solve()
```コードはまず、総量を使用して不可能なケースを除外します。 これは、ボリュームに影響を与える重複またはギャップのあるすべての構成を削除する高速拒否です。 

次に、すべての一意の Z 境界を構築し、連続するスラブに対して反復処理を行います。 スラブごとに、スラブを完全に覆う直方体を正確に抽出し、それらを 2D 長方形に変換します。 

の`check_2d`関数は、X 軸に沿ったスイープを実装します。 アクティブな y 間隔のマルチセットのような構造を維持します。 各 X 座標でイベントを処理した後、アクティブな間隔の和集合が全範囲を正確にカバーしていることを検証します。$[0, H]$。 カバレッジは四角形の境界でのみ変化するため、チェックはイベント位置の間に配置されます。 

微妙な点は、イベント境界間のみを検証することです。 このようなすべての点でカバレッジが正しい場合、連続性により X 軸全体の正確さが保証されます。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、直方体がスラブ境界上に正確に位置合わせされる場合です。 その状況では、直方体は複数の Z スラブに完全にまたがる場合にのみ複数の Z スラブに寄与します。 アルゴリズムは、その Z 範囲がスラブ全体をカバーする場合にのみそれを正しく組み込み、部分的な二重カウントを防ぎます。 

もう 1 つのケースは、多くの直方体が同一の境界を共有する場合です。 スイープ ラインはこれを自然に処理します。これは、同じ座標のイベントが一緒に処理され、検証前に間隔の更新がアトミックに発生することが保証されるためです。 

最後の微妙なケースは、離散 x イベント ポイントではカバレッジが正しいが、その間で失敗する場合です。 このアルゴリズムは、一連のアクティブな間隔が一定であるイベント境界間のみを検証することでこれを回避します。そのため、セグメント内で目に見えない変更が発生することはありません。
