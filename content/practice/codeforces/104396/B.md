 ## 解決策
 ## 問題の理解

 各スターがノードであり、各スター レールが負の整数コストを持つ有向エッジである有向グラフが与えられます。 すべての開始ノードに対して$x$で始まるすべての可能な閉鎖ルートを考慮します。$x$、少なくとも 1 つのエッジをたどり、最終的には$x$。 ノードとエッジは任意に何度でも再訪できます。 

各ルートの総コストはエッジの重みの合計に等しいため、総コストが奇数であるルートのみを考慮します。 開始ノードごとに$x$、そのようなすべての閉じられたルートの中で、可能な限り最小の奇数の合計コストが必要です。 

に開始および終了する閉鎖ルートがない場合$x$総コストが奇数である場合、それは不可能であると出力します。 から到達可能な負のサイクルを使用して、最小奇数コストを際限なく減らすことができる場合$x$、答えは無限であると出力します。 

この制約では、最大 1000 個のノードと 10000 個のエッジが許可されます。 これは、周囲のアルゴリズムにとって十分小さいです$O(nm)$または$O(n^2 m)$ただし、すべてのノードに対して個別に最短経路の計算を効果的に繰り返すものはすべて慎重に扱う必要があります。単純な全ペアのアプローチでは遅すぎるためです。 

微妙な点は、このルートが単なる自転車ではなく、一般的な散歩であることです。 これは、負のサイクルが直接的に重要であることを意味します。負のサイクルが到達可能であり、必要なパリティを備えたリターン パスに結合できる場合、答えは無制限になります。 

もう 1 つの重要な詳細はパリティです。 私たちはコストの大きさだけを気にするのではなく、合計が奇数かどうかを気にします。 これにより、偶数和と奇数和という 2 つの状態で最短経路を追跡する必要があります。 

単純な間違いは、パリティなしで最短サイクルを計算し、その後パリティをチェックすることです。 これは失敗します。なぜなら、最短のサイクルが偶数である一方で、わずかに長い奇数のサイクルが存在する場合や、その逆の場合があるからです。 

もう 1 つの失敗例は、負のサイクルを無視することです。 たとえば、総コストのサイクルがある場合、$-2$、パリティを変更せずに任意に何度でも繰り返すことができ、これにより答えが導き出されます。$-\infty$パリティを適切に調整するパスと組み合わせた場合。 

## アプローチ

 直接的なアプローチは、各ノードを考慮することです$x$独立して最短経路計算を実行します。$x$累積合計のパリティを追跡しながら、すべてのノードに送信します。 これを 2 倍の状態空間を持つグラフとしてモデル化できます。各状態は次のようになります。$(v, p)$、 どこ$v$はノードであり、$p\in\{0,1\}$これまでのパス コストの等価です。 

あらゆるエッジ$u \to v$重さで$w$からの移行$(u, p)$に$(v, p \oplus (w \bmod 2))$費用がかかる$+w$。 次に、固定開始ノードの場合$x$、答えはからの最短距離です。$(x,0)$に$(x,1)$奇数の合計値で同じノードに戻る必要があるためです。 

重みが負になる可能性があるため、ダイクストラは有効ではありません。 拡大グラフでは標準ツールは Bellman-Ford です。 各実行コスト$O(nm)$元のグラフでは、パリティの 2 倍化は定数のみを乗算するためです。 

重要な問題は、すべての開始ノードにこの結果が必要であるということです。 各ノードからの単純な Bellman-Ford の繰り返しでは、最悪の場合、遅すぎる可能性があります。 

ただし、グラフのサイズは適度であり、DP の構造は均一です。 意図された解釈は、各ソースに対して同じ緩和プロセスを実行し、パリティ拡張グラフ内のソースごとに独立した距離テーブルを維持するということです。 

各ソースが独立した単一ソースの最短経路問題を定義しているため、総当たりのアイデアが機能します。 ブラックボックスアルゴリズムを繰り返すと遅くなりすぎる$n$構造を共有せずに何度も繰り返します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ソースごとの Bellman-Ford のパリティ グラフ |$O(n^2 m)$|$O(n^2)$| 制約の下では許容される |
 | 単一実行マルチソース DP (ソース分離については不正確) |$O(nm)$|$O(n)$| 不正解 |
 | フロイド・ウォーシャルのパリティグラフ |$O(n^3)$|$O(n^2)$| 遅すぎる |

 ## アルゴリズムのチュートリアル

 ソースノードを修正します$x$展開された状態グラフ内の最短パスを計算します。 

1. 各元のノードが配置された概念グラフを構築します。$v$2つの状態になる$(v,0)$そして$(v,1)$、現在のパスの合計が偶数か奇数かを表します。 
2. を除くすべての距離を無限大に初期化します。$dist[x][0] = 0$で始まるので、$x$和はゼロ、つまり偶数です。 
3. ベルマンフォードを使用してすべてのエッジを繰り返しリラックスさせます。 有向エッジごとに$u \to v$重さで$w$、両方のパリティ状態を更新します。 もし私たちがいるなら$(u,p)$に移動できます$(v, p \oplus (w \bmod 2))$コストが増加して$w$。 これにより、パリティがすべてのステップで正しく追跡されるようになります。 
4.その後$2n$展開されたグラフのすべてのエッジを反復すると、それ以上の緩和は、ソースから到達可能な負のサイクルの存在を示します。 
5. さらなる緩和によって影響を受けるすべての州を距離があるとマークする$-\infty$、任意に改善できるため。 
6. ソースの答え$x$の値です$dist[x][1]$。 まだ無限である場合は、有効な奇数サイクルが存在しません。 そうであれば$-\infty$、答えは無限です。 それ以外の場合は、最小の奇数コストです。 

それが機能する理由は、標準的なベルマン・フォードの不変条件から導き出されます。 後$k$完全なリラクゼーション ラウンド、すべての最短パスは最大でも使用$k$展開された状態グラフのエッジが正しく計算されます。 グラフ内の有効なウォークはすべて、$n$ノードは、単純なパスと繰り返しサイクルに分解できます。 その先に短いパスが存在する場合$2n$エッジにはサイクルが含まれている必要があります。 そのサイクルによってコストが削減される場合、継続的な緩和によってそれが検出され、パリティ追跡により、一貫した奇数/偶数の和を持つ状態のみを比較することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = 10**30

def solve():
    n, m = map(int, input().split())
    edges = []
    for _ in range(m):
        x, y, w = map(int, input().split())
        edges.append((x, y, w))

    # dist[x][v][p]
    # p = 0 even, 1 odd
    dist = [[[INF] * 2 for _ in range(n)] for _ in range(n)]

    for src in range(n):
        dist[src][src][0] = 0

        # Bellman-Ford on expanded graph
        for _ in range(2 * n):
            updated = False
            for u, v, w in edges:
                wp = w & 1
                for p in (0, 1):
                    if dist[src][u][p] == INF:
                        continue
                    np = p ^ wp
                    nd = dist[src][u][p] + w
                    if nd < dist[src][v][np]:
                        dist[src][v][np] = nd
                        updated = True
            if not updated:
                break

        # detect negative cycles affecting odd return
        bad = [[False] * 2 for _ in range(n)]
        for u, v, w in edges:
            wp = w & 1
            for p in (0, 1):
                if dist[src][u][p] == INF:
                    continue
                np = p ^ wp
                if dist[src][u][p] + w < dist[src][v][np]:
                    bad[v][np] = True

        # propagate bad states
        for _ in range(2 * n):
            for u, v, w in edges:
                wp = w & 1
                for p in (0, 1):
                    if bad[u][p]:
                        bad[v][p ^ wp] = True

        if dist[src][src][1] == INF:
            print("Battle with the crazy Honkai")
        elif bad[src][1]:
            print("Haha, stupid Honkai")
        else:
            print(dist[src][src][1])

if __name__ == "__main__":
    solve()
```このソリューションは完全な状態を維持します。$n \times n \times 2$距離テーブルを使用して、各ソースを個別に処理できるようにします。 各緩和ステップではすべてのエッジが考慮され、両方のパリティ状態が更新され、すべてのパス コストがパリティとともに追跡されることが保証されます。 

負のサイクル検出フェーズは、収束後も距離を改善できる状態にフラグを立てます。 有害なサイクルから到達可能なあらゆる状態も駆動される可能性があるため、伝播ステップにより、到達可能な遷移に沿ってこの効果が拡張されます。$-\infty$。 

最終的な決定では、ソース ノードでの奇数パリティの戻り状態のみがチェックされます。 

## 実用的な例

 ### 例 1

 入力:```
2 2
0 1 1
1 0 1
```ノード 0 から計算します。 

| ステップ | 距離[0][0][0] | 距離[0][1][1] |
 | --- | --- | --- |
 | 初期化 | 0 | インフ |
 | リラックスした後 | 0 | 1 |
 | 最終回 | 0 | 1 |

 唯一のサイクル 0 → 1 → 0 の合計コストは 2 であり、偶数です。 奇数サイクルがないため、開始時の奇数状態は到達不可能なままとなり、必要な「不可能な」出力が生成されます。 

同じ構造がノード 1 に対して繰り返されます。 

### 例 2

 入力:```
2 2
0 1 0
1 0 1
```| ステップ | 距離[0][0][0] | 距離[0][0][1] |
 | --- | --- | --- |
 | 初期化 | 0 | インフ |
 | リラックスした後 | 0 | 1 |
 | 最終回 | 0 | 1 |

 サイクル 0 → 1 → 0 の総コストは 1 で、これはすでに奇数であるため、最小の奇数サイクルは 1 です。 

これは、パリティ追跡が不可欠であることを裏付けています。パリティ追跡がないと、両方の例が誤って同じ「サイクルが存在する」分類に分類されてしまいます。

 ## 特殊なケース

 奇数の重みを持つ自己ループは、答えが即時である基本的なケースを示しています。サイクルはすでに閉じており、正しいパリティがあるため、距離がそのエッジの重みになります。 

すべてのサイクルが均等であるグラフは、パリティ追跡が必要な理由を示しています。 状態を分割しないと、アルゴリズムはサイクルが存在すると誤って判断し、それが有効であると想定します。 

到達可能な負のサイクルを含む構成は、収束チェックが重要である理由を示しています。 状態を無制限に改善できるようになると、そこから到達可能な奇数の戻り状態も無制限とマークする必要があります。そうしないと、アルゴリズムが有限の最小値を誤って報告することになります。
