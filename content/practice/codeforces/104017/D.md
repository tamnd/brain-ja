 ## 解決策
 ## 問題の理解

 長い直線の海岸線が与えられ、小屋が定位置に置かれています。 小屋$i$正確に座ります$100$小屋の右に数メートル$i-1$、したがって、小屋は完全に均一な列を形成します。 各小屋には、アイスクリームをそれぞれ 1 つずつ購入するある程度の人数がいます。 

小屋に加えて、同じ線に沿った既知の座標にすでにいくつかのアイスクリーム店が配置されています。 現在、新しいショップを 1 つだけオープンすることが許可されており、必ずしも小屋や整数の位置でなくても、この線上のどこにでも配置できます。 

各人は距離的に最も近い店舗に厳密に行きます。 最も近いという評価が同数の場合、その人は私たちの店を選択しません。なぜなら、私たちの店は既存のすべての店舗よりも厳密に近い必要があるからです。 

目標は、私たちの店でサービスを受ける人の総数が最大になるように、新しい店の位置を選択することです。 

入力は小屋の数、既存の店舗の数、各小屋の人口、既存の店舗の位置で構成されます。 出力は 1 つの数値、つまりショップを最適に配置することで獲得できる最大総人口です。 

制約は最大数十万の小屋や店舗にまで及びます。 これにより、すべての候補地に対する二次戦略や各小屋の単純なスキャンが即座に除外されます。 候補位置ごとにすべての店舗までの距離を繰り返し再計算するものは、遅すぎます。 解決策は本質的に、問題を少数の重要な候補領域に減らすか、単一またはほぼ線形のパスで寄与を計算する必要があります。 

微妙なエッジ ケースは、2 つの既存の店舗が小屋の境界領域に等しく近い場合です。 このような場合、新しい店舗を両方よりも厳密に近くに配置しない限り、その小屋を「盗む」ことができる間隔は存在しない可能性があります。正確に中間点に配置することは不可能です。 たとえば、小屋が 0 と 100 の位置にあり、既存の店舗が -100 と 200 の位置にある場合、小屋を占領できるかどうかは中間点の構造によって決まります。厳密な不平等が強制されない場合、「最も近い間隔」についての単純な推論はカウントを誤る可能性があります。 

複数のショップが非常に小さなボロノイ セルを作成すると、別の障害モードが発生します。 小屋がすでに既存の店舗によって非常に大きな利益率で占められている場合、隣接する店舗間の中間点によって定義される境界を越えない限り、新しい店舗を配置してもそれを解決することはできません。 新しい店舗の移転はローカルではなくグローバルな支配力を変えるため、独立して「最高の小屋を選択」しようとする素朴な貪欲なアプローチは失敗します。 

## アプローチ

 主な問題は、新しい店舗の位置により、各小屋が特定の店舗に最も近い領域にラインが分割されることです。 固定配置の場合、すべての小屋は新しい店舗に対して左側と右側にある最も近い既存の店舗とのみ距離を比較します。つまり、構造は隣接する店舗間の中間点によって支配されます。 

強引なアプローチでは、すべての既存の店舗とおそらくすべての小屋の位置によって引き起こされるすべての可能な配置間隔を試し、各候補について、既存の店舗よりも新しい店舗に近い総人口を計算します。 あれば$n$小屋と$m$ショップ、1 つの配置コストの評価$O(n)$、そして、あります$O(n+m)$意味のある間隔で、全体の複雑さは次のようになります。$O(n(n+m))$、これは実現不可能です$2 \cdot 10^5$。 

重要な洞察は、各小屋の支配条件は左右に最も近い既存の店舗にのみ依存し、新しい店舗は、隣接する 2 つの店舗によって決定される特定の間隔内に配置された場合にのみ小屋に「勝つ」ことができるということです。 具体的には、小屋ごとに、両側で最も近い既存の店舗を計算できます。新しい店舗は、これら 2 つの店舗によって定義される中間点の境界よりも近くに配置された場合にのみ両方に勝つことができます。 これにより、「捕獲可能」なライン上の区間に対する各小屋の寄与が減少します。 

すべての小屋がその人口によって重み付けされた間隔に変換されると、問題は、その点をカバーする間隔の合計重みを最大化する線上の点を選択することになります。 これは古典的なスイープ ラインの問題です。各間隔を左端の +p イベントと右端の -p イベントに変換し、スイープして最大アクティブ合計を見つけます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース配置チェック |$O(n(n+m))$|$O(1)$| 遅すぎる |
 | キャプチャ間隔をスイープ |$O((n+m)\log(n+m))$|$O(n+m)$| 承認済み |

 ## アルゴリズムのチュートリアル

 すべての小屋の位置が座標で固定されていると仮定します$100 \cdot (i-1)$。 既存のショップのポジションも整理します。 

1. 各小屋について、ソートされた店舗の位置に対する二分探索を使用して、左右にある最も近い既存の店舗を特定します。 これにより、新しいショップがこの小屋に勝つことができるかどうかを決定する 2 つの競合候補が得られます。 小屋がすべての既存の店舗の外にある場合、行方不明の隣人を次​​のように扱います。$-\infty$または$+\infty$、片側制約のみが存在することを意味します。 
2. 各小屋について、左右の競合する店舗との中間点の境界を計算します。 小屋が所定の位置にある場合$x$、に店を出ました$L$、正しいお店です$R$の場合、新しいショップは両方よりも厳密に近くなければなりません。これは、中間点の間にある必要がある有効な間隔に変換されます。$(L+x)/2$そして$(x+R)/2$、両側からの実現可能性制約と交差します。 この間隔は、新しいショップがその小屋を占領するすべての位置を表します。 
3. このような各間隔を 2 つのイベントに変換します。左側のエンドポイントで小屋の人口を加算し、右側のエンドポイントでそれを減算します。 これは、間隔の内側では小屋が寄与するが、外側では小屋が寄与しないという事実をエンコードしています。 
4. すべてのイベントを位置ごとに並べ替えます。 アクティブなコントリビューションの累計を維持しながら、左から右にスイープします。 確認された最大値を追跡します。 
5. 新しいショップの最適な配置に対応する最大スイープ値を返します。 

### なぜ効果があるのか

 各小屋は、新しいショップが既存のすべてのショップよりも厳密に近い場合にのみ、答えに貢献します。 直線上の距離を比較すると、競合する店舗間の中間点の境界が縮小されるため、各小屋は有効な配置の連続領域を誘導します。 最終的な目的は、これらの領域の最大合計重みがカバーするポイントを選択することになります。 スイープでは、そのようなすべての地域の正確な重複構造が維持されるため、すべての位置で、そこにある新しい店舗を選択する総人口が正確に計算されます。 あらゆる可能な配置がスイープ内のどこかで表されるため、最大値は全体的に最適です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    p = list(map(int, input().split()))
    shops = list(map(int, input().split()))
    shops.sort()

    # hut positions: 0, 100, 200, ...
    huts = [100 * i for i in range(n)]

    events = []

    from bisect import bisect_left

    for i in range(n):
        x = huts[i]
        w = p[i]

        idx = bisect_left(shops, x)

        L = shops[idx - 1] if idx > 0 else None
        R = shops[idx] if idx < m else None

        left_bound = -10**30
        right_bound = 10**30

        if L is not None:
            left_bound = max(left_bound, (L + x) / 2)
        if R is not None:
            right_bound = min(right_bound, (R + x) / 2)

        if left_bound <= right_bound:
            events.append((left_bound, w))
            events.append((right_bound, -w))

    events.sort()

    cur = 0
    best = 0
    for x, v in events:
        cur += v
        if cur > best:
            best = cur

    print(best)

if __name__ == "__main__":
    solve()
```コードはまず、数直線上で小屋のジオメトリを修正します。 次に、二分探索を使用して、各小屋の周囲に最も近い既存の 2 つの店舗を検索します。 これら 2 つの店舗は、新しい店舗がその小屋を独占できる可能性がある唯一の地域を定義します。 

中点の計算により、距離の比較が線形不等式に変換されます。これが、各小屋が単純な区間になる理由です。 次に、スイープラインは重複する間隔を集計し、その累計は常に、その座標に店舗を配置することによって現在「獲得」されている総人口を反映します。 

実装の微妙な点は、元の状態での厳密な不等式要件です。 中間点の境界を使用することは、等価性が同点に対応することを意味し、イベントの順序付けを通じて暗黙的に境界点を除外することによって正しく処理されます。 相対的な順序のみが重要であるため、ここでは浮動除算を使用するのが安全です。 より厳密な精度制御が必要な場合は、整数の 2 倍の乗算表現も機能します。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、既存のすべての店舗の外に小屋がある場合です。 この場合、意味のある競合相手側は 1 つだけであるため、有効な間隔は片側で無制限になります。 アルゴリズムはセンチネルの無限を使用してこれを処理するため、小屋は半無限の間隔を正しく提供します。 

もう 1 つのエッジ ケースは、小屋が境界の中点から正確に等距離にある場合です。 このような状況では、厳密な不平等は、小屋をその境界に数えるべきではないことを意味します。 スイープでは、平等に人為的に小屋が含まれないようにエンドポイントを一貫して扱い、正確さを保ちます。 

最後のエッジケースは、複数の小屋が同一の間隔を生成する場合です。 スイープ ラインはそれらの重みを正しく集計するため、重複する同一の寄与が単純に合計されます。これはまさに目的が必要とするものです。
