 ## 解決策
 ## 問題の理解

 根を張った木の動きを分析するように求められます。 木には、$n$頂点、頂点あり$1$根として。 Chefir、指定された頂点から開始$v_i$、スタミナが限られている$k_i$。 移動ルールは非対称です。頂点から子孫への移動にはコストはかかりませんが、非子孫 (祖先または別のサブツリー内のノードである可能性があります) への移動には移動ごとに 1 スタミナがかかります。 スタミナがゼロになると、チェフィールは子孫以外に移動できなくなります。 各クエリの目標は、ツリーに沿った距離として測定され、Chefir が到達できる最も遠い頂点を見つけることです。 

この制約は、クエリごとに到達可能なすべてのノードをシミュレートする単純なソリューションでは遅すぎることを意味します。 各テスト ケースには最大で次のものを含めることができます。$2 \cdot 10^5$ノード数とテスト ケース全体のクエリの合計数も$2 \cdot 10^5$。 各クエリ頂点からの単純な幅優先検索では、次のような時間がかかります。$O(n)$クエリごとに、$O(nq)$までの操作$4 \cdot 10^{10}$最悪の場合、4 秒の制限時間内に収まる時間をはるかに超えます。 ツリーを前処理し、クエリごとにサブリニア時間でクエリに応答するアプローチが必要です。 

エッジケースには、スタミナがゼロの根から開始すること、スタミナが高い葉から開始すること、または本質的にパス (チェーン) である木から開始することが含まれます。 たとえば、ツリーが長さ 5 のチェーンである場合、$v_i = 5$と$k_i = 0$, チェフィールは先祖に沿って上に移動し、スタミナがなくなるまでに可能な歩数に等しい距離に到達することしかできません。 子孫の動きとスタミナを消費する動きの違いを単純に無視すると、間違った答えが生まれてしまいます。 

## アプローチ

 ブルート フォース手法は簡単です。クエリごとに、深さ優先検索 (DFS) を実行します。$v_i$、残りのスタミナを追跡し、見つかった最大距離を更新します。 このアプローチは、スタミナの制約の下で可能なすべての動きを検討するため、正しいです。 その複雑さは、$O(n)$クエリごと、または$O(nq)$全体。 これは次の場合に失敗します。$n$そして$q$大きいです。 

重要な洞察は、スタミナが現在のサブツリーから移動するときにのみ消費されることに気づくことから得られます。 子孫の移動は自由であるため、サブツリー内の距離を事前に計算することが推奨されます。 また、上向きの移動を効率的に処理するために、ツリー内の「各頂点からの最も遠い距離」を事前計算することもできます。 DFS、サブツリーの最大距離、スタミナ コストを含む距離を伝播する上向きパスを組み合わせて使用​​すると、次の各クエリに答えることができます。$O(1)$後$O(n)$テストケースごとに前処理を行います。 

最適な解決策には、DFS の 2 つのパスが含まれます。1 つは下向きでサブツリーの高さ (子孫までの最大距離) を計算し、もう 1 つは上向きでスタミナの減少に伴う祖先からの距離を伝播します。 各クエリは、利用可能なスタミナを考慮して、到達可能な最大距離を単純に検索します。 これにより、クエリのコストが削減されます。$O(n)$に$O(1)$と$O(n)$前処理中。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(nq) | O(n) | 遅すぎる |
 | 最適 | O(n + q) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力エッジからツリー隣接リストを構築します。 これにより、どちらの方向への効率的なトラバースが可能になります。 
2. ルートから開始して DFS を実行して各ノードを計算します$u$サブツリー内の最大の深さ。 これを次のように保存します`subtree_height[u]`。 これは、スタミナを消費しないすべての子孫の動きに当てはまります。 
3. 2 回目の DFS を実行して、スタミナを消費して上方または兄弟に移動することによって達成可能な最大距離を各ノードに対して計算します。 ノードの場合$u$親と一緒に$p$、祖先の伝播距離と他の兄弟の最大深さを組み合わせます。 これを次のように保存します`upward_distance[u]`。 
4. 各クエリについて`(v_i, k_i)`、最大到達距離は次の合計です。`subtree_height[v_i]`そして`min(k_i, upward_distance[v_i])`。 下への移動は自由ですが、上への移動はスタミナによって制限されます。 
5. 各クエリに対して計算された距離を出力します。 

なぜ効果があるのか​​:`subtree_height[u]`無料で到達可能な最も遠い距離を撮影しますが、`upward_distance[u]`スタミナを使用して達成可能な最大の追加距離を獲得します。 2 つの要素を合計し、利用可能なスタミナへの上向きの寄与を固定することにより、二重にカウントすることなくすべての正当な動きを考慮します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        tree = [[] for _ in range(n + 1)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            tree[u].append(v)
            tree[v].append(u)
        
        subtree_height = [0] * (n + 1)
        upward_distance = [0] * (n + 1)

        def dfs1(u, parent):
            max_h = 0
            for v in tree[u]:
                if v == parent:
                    continue
                dfs1(v, u)
                max_h = max(max_h, subtree_height[v] + 1)
            subtree_height[u] = max_h

        dfs1(1, 0)

        def dfs2(u, parent):
            # collect top two heights from children
            child_heights = []
            for v in tree[u]:
                if v == parent:
                    continue
                child_heights.append(subtree_height[v] + 1)
            child_heights.sort(reverse=True)
            for v in tree[u]:
                if v == parent:
                    continue
                # pick max among siblings
                use = child_heights[0] if child_heights[0] != subtree_height[v] + 1 else (child_heights[1] if len(child_heights) > 1 else 0)
                upward_distance[v] = max(upward_distance[u] + 1, use + 1)
                dfs2(v, u)

        dfs2(1, 0)

        q = int(input())
        res = []
        for _ in range(q):
            v, k = map(int, input().split())
            # downward distance free, upward distance limited by stamina
            res.append(str(subtree_height[v] + min(k, upward_distance[v])))
        print(' '.join(res))

if __name__ == "__main__":
    solve()
```最初の DFS は、各頂点のサブツリー内の最大深さを計算します。 2 番目の DFS は、スタミナを伴う動きを考慮して最大距離を伝播します。 子の高さを並べ替えることで、上方向の距離を計算するときに同じ子が二重にカウントされることを回避できます。 クエリは一定時間内に応答されます。
