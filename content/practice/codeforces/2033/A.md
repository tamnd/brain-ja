 ## 問題の理解

 2 人のプレイヤーが位置 0 から始まる数直線に沿ってドットを移動するターンベース ゲームの勝者を決定するように求められます。 桜子は、自分のターンに奇数のユニットを増やすことによって常に左に移動します (-1、-5、-9 など)。 コスケは、3、7、11 などの奇数の同じ順序で右に移動します。ドットが間隔の外に移動するとすぐにゲームは終了します。`-n`に`n`。 私たちのタスクは、ドットがこの間隔を出る前に、どのプレイヤーが最後に有効な手を行ったかを判断することです。 

入力により複数の独立したゲームが提供され、それぞれが単一の整数で定義されます。`n`。 出力は、各ゲームで最後に移動したプレーヤーの名前である必要があります。 境界は小さいです:`t`最大100ゲーム、`n`これにより、ゲームごとに最悪でも O(n) で実行されるアルゴリズムが可能になり、手の単純なシミュレーションでもすぐに完了します。 

エッジケースは、次の値が非常に小さい場合に発生します。`n`。 たとえば、次の場合`n=1`、手の順序は -1 (桜子)、3 (康介) です。 桜子の最初の行動の後、`x=-1`インターバル内なのでゲームは続行されます。 康介の次の動きで 3 が追加され、`x`を超える2まで`n=1`。 コウスケが最後に範囲内で行動したため、コウスケが勝ちます。 このような場合、単純に 1 つずつ計算したり、手の符号を忘れたりすると、間違った答えが得られます。 

## アプローチ

 最も簡単なアプローチは、それぞれのゲームをシミュレートすることです。`n`。 から開始`x=0`プレイヤーを交代しながらターンごとに繰り返します。 ターン中`i`、 追加`2*i-1`正しい方向に。 次の移動に時間がかかる場合は停止します`x`外`[-n, n]`。 これは、各移動の大きさが増加するため、指定された制約に対して機能します。`n`は小さいため、ゲームごとの反復回数はおおよそ次の平方根によって制限されます。`2*n`(奇数の合計はほぼ二次関数になるため)。 ゲームごとの最悪のオペレーションは 100 をはるかに下回っており、これは実現可能です。 

ただし、あるパターンが観察できます。 手を桜子のネガティブなステップとコウスケのポジティブなステップに分けると、それぞれの側の累積和は一連の奇数になります。 させて`S = sum_{k=1}^{m} (2k-1)`最初の累積和になります`m`動く。 これはいつも`m^2`。 ゲームは基本的に、左の累積合計が次のいずれかを超えるまで継続します。`n`または正しい累積合計が次を超えています`n`。 したがって、すべての手をシミュレートする代わりに、どの累積二乗が最初に超えるかを事前計算できます。`n`それぞれの側に。 累計が超えるプレイヤー`n`次に負け、他のプレイヤーが最後の有効な手を行った。 これにより、問題は単純な整数演算に集約されます。

 | 最適累積和分析 | 1 試合あたり O(1) | お(1) | 受け入れられ、クリーンです |

 ## アルゴリズムのチュートリアル

 1.ゲーム数を読む`t`。 空の結果リストを初期化します。 
2. 各ゲームについて、以下をお読みください。`n`。 位置変数を初期化する`x = 0`そして移動カウンター`i = 1`。 
3. の絶対値は`x`内にあります`[-n, n]`、現在の移動量を決定します`2*i - 1`。 もし`i`が奇数なので、それを引きます (桜子は左に移動します)。 もし`i`が偶数なので、それを追加します（コースケは右に移動します）。 アップデート後`x`、増分`i`。 
4. いつ`x`最初に間隔の外に移動します`[-n, n]`、最後の有効な手は前のプレイヤーによって行われました。 もし`i`は互角で、桜子が最後の有効な手を打ちました。 もし`i`奇妙だ、コースケは最後の有効な動きをした。 
5. 勝者の名前を結果リストに追加します。 
6. すべてのゲームを処理した後、結果を印刷します。 

それが機能する理由: 動きは大きさと方向が交互に単調に増加します。 アップデートすることで`x`順番に、次の不変条件を維持します。`x`ドットの実際の位置を反映します。 その瞬間`x`を超える`[-n, n]`、最後の有効な手が前のターンであることがわかっており、正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
results = []

for _ in range(t):
    n = int(input())
    x = 0
    i = 1
    while True:
        move = 2*i - 1
        if i % 2 == 1:
            x -= move
        else:
            x += move
        if abs(x) > n:
            winner = "Sakurako" if i % 2 == 1 else "Kosuke"
            results.append(winner)
            break
        i += 1

print("\n".join(results))
```コードはゲーム数を読み取ることから始まります。 ゲームごとに、ドットを 0 に初期化し、動きを 1 つずつシミュレートします。 移動の大きさは、`2*i-1`。 桜子は奇数ターンで左に移動し、康介は偶数ターンで右に移動します。 ドットが境界を出ると、誰の番だったかを確認し、勝者を記録します。 このアプローチでは、オフバイワンミスの原因となりやすいサインとターンパリティを注意深く処理します。
