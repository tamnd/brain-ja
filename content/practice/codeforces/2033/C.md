 ## 解決策
 ## 問題の理解

 整数で表される関心のあるトピックに関連付けられた一連の学生が与えられます。 ラインの乱れは、同じトピックを共有する隣接する生徒のペアの数としてカウントされます。 教師は生徒の位置を交換できます$i$生徒と対称の位置に$n-i+1$、この操作は何度でも繰り返すことができます。 目標は、これらの対称スワップを使用してラインを再配置し、全体の乱れを最小限に抑えることです。 

入力は複数のテスト ケースで構成されます。 テストケースごとに生徒の数を受け取ります$n$そして配列$a$長さの$n$、 どこ$a_i$の話題です$i$-番目の生徒。 各テスト ケースで達成可能な最小の外乱を出力します。 

とすれば$n$到達できる$10^5$すべてのテスト ケースの合計が以下を超えないこと$2\cdot 10^5$、複雑なソリューション$O(n^2)$テストケースごとの処理が遅すぎます。 したがって、線形または線形に近い解決策が必要です。$O(n)$または$O(n \log n)$、テストケースごと。 

明らかではないエッジケースには、すべての生徒が同じトピックを持っている配列が含まれ、その結果、最初は最大の混乱が生じます。 もう 1 つの微妙なケースは、配列が対称またはほぼ対称で、一部のスワップが冗長である場合です。 たとえば、次の場合$a = [1, 2, 1, 2]$、どのスワップでも、隣接する重複がゼロであるという事実は変わりません。 隣接性を考慮せずにスワップをカウントする不用意なアプローチは、外乱の削減を過大にカウントしたり過少にカウントしたりする可能性があります。 

## アプローチ

 単純なアプローチでは、許可されたスワップのシーケンスをすべて列挙し、各シーケンスの後に外乱を計算し、最小値を選択します。 これは原理的には正しいですが、各生徒が鏡の位置を何度も入れ替える可能性があるため、計算上実行不可能です。 のために$n$学生の皆さん、スワップ シーケンスの数は指数関数的です。$n/2$、明らかに制限時間を超えています。 

重要な洞察は、対称スワップが配列をペアに分割するということです。$(i, n-i+1)$、各ペア内でのスワップは、すぐ隣のペアにのみ影響します。 したがって、**連続する等しい要素のブロック**に焦点を当てることができます。 最適な戦略は、各対称ペア内でシーケンスが可能な限り交互になるようにして、各ブロックの長さを最小限に抑えることです。 連続する同一要素のブロックの場合、最小の外乱は次のように比例します。$\lfloor \text{length}/2 \rfloor$なぜなら、各スワップで壊れる可能性があるのは、等しい隣接ペアの最大 1 組だからです。 これにより、問題は、配列をスキャンし、同一のトピックの実行をカウントし、それらの長さの半分の下限を合計することに軽減されます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(n/2) * n) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 外乱カウンタをゼロに初期化し、ポインタを初期化します。$i = 0$配列を走査します。 
2. その間$i < n$:

 1. から始まる連続する等しい要素の現在のブロックを特定します。$i$。 させて$j = i$。 
2. インクリメント$j$それまで$a[j] \neq a[i]$または$j = n$、ブロックの長さを効果的に見つける$L = j - i$。 
3. 外乱カウンタを次のようにインクリメントします。$\lfloor L/2 \rfloor$。 対称ペア内の各スワップは 1 つの隣接関係を壊す可能性があり、フロアはペアになっていない要素の残りを占めます。 
4. 移動$i$に$j$次のブロックを処理します。 
3. 配列を走査した後、外乱カウンタを出力します。 

機能する理由: 対称スワップでは、ペア内の任意の要素が許可されます。$(i, n-i+1)$交換されること。 したがって、同一のトピックの各実行は、ペアの制約内で最適に再配置できます。 隣接する重複の最小数は、正確にすべてのブロックの合計です。$\lfloor \text{length}/2 \rfloor$これは、許可されたスワップによって解除できる隣接関係の最大数であるためです。 これにより、すべてのブロック構成が正確であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def minimal_disturbance(a):
    n = len(a)
    res = 0
    i = 0
    while i < n:
        j = i
        while j < n and a[j] == a[i]:
            j += 1
        length = j - i
        res += length // 2
        i = j
    return res

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(minimal_disturbance(a))
```この解は配列を 1 回走査し、連続する同一の要素をカウントし、それらの半分の長さを合計します。 内部の while ループは各要素を 1 回だけ進むため、アルゴリズムは線形時間で実行されます。 境界条件は正しく処理されます。ブロックが配列の最後に到達すると、$j = n$、との計算$\lfloor L/2 \rfloor$まだ保持しています。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        res = 0
        i = 0
        while i < n:
            j = i
            while j < n and a[j] == a[i]:
                j += 1
            res += (j - i) // 2
            i = j
        out.append(str(res))
    return '\n'.join(out)
