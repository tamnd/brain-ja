 ## 解決策
 ## 問題の理解

 すべての y 座標が厳密に正であるため、平面内に点のセットが与えられます。各点は x 軸の上のどこかに配置されたスプリンクルを表します。 それぞれのスプリンクルには赤または青の色があります。 ボブは原点に固定されて立ち、原点に頂点を持つ扇形のような形状の幾何学的領域を選択します。 この領域は半径に制限はありませんが、角度間隔に制限されているため、幾何学的には原点から 2 本の光線を選択し、それらの間のすべての点を反時計回りの順序で取得することに対応します。 

スプリンクルは、このセクターの内側または境界上にある場合に収集されます。 ボブは、青い点がまったく含まれていないセクターを 1 つ選択し、その中にある赤い点の数を最大にしたいと考えています。 

入力サイズは 200,000 ポイントに達する可能性があるため、すべてのポイントのペアまたはすべての角度間隔を明示的に検査するアプローチは失敗します。 二次解では、最悪の場合、約 400 億のペアの考慮が必要になりますが、これは 2 秒で許容されるものをはるかに超えています。 これは、問題が 1 次元構造に帰着する必要があることを直ちに示唆しており、おそらく原点を中心とした角度ソートが関係しています。 

円上のジオメトリに微妙な問題が生じます。 すべての点が上半平面内にある場合でも、角度は負の X 軸で回り込みます。 どのソリューションでも、角度による点の循環順序付けを慎重に処理する必要があります。 

別のエッジケースは、青い点が角度順に赤いクラスターの間にある場合に現れます。 角度ソートで赤い点の最大連続ブロックを単に取得する単純なアプローチは、間隔内に青い点が含まれたり、最適なセクターが任意の点で開始および終了できることを見逃したりする可能性があるため、間違っています。 

3 番目の落とし穴は、ラップアラウンドのケースを処理せずにセクターを線形間隔として扱うことです。 最適なセクターは、x 軸の正の方向と交差する可能性があります。これは、円の連続性をシミュレートするために角度間隔を複製する必要がある可能性があることを意味します。 

## アプローチ

 強引なアイデアは、考えられるすべての点のペアをセクターの境界とみなすことです。 順序付けされた点のペアごとに、反時計回りの順序で最初の角度から始まり 2 番目の角度で終わるセクターを想像し、青い点が含まれていないことを確認しながら、内側にある赤い点の数を数えます。 これには、各ペアのすべてのポイントをチェックする必要があり、時間計算量は O(N^3) になります。前処理でカウントが最適化されていても 200,000 ポイントには大きすぎる場合は、時間計算量は O(N^2) になります。 

重要な観察は、意味のあるセクター境界のみが、指定された点によって定義された角度で発生するということです。 一方の境界を固定し、もう一方の境界を回転すると、「内部に青い点がない」という条件が、ソートされた角度順序に対するスライディング ウィンドウ制約になります。 これにより、問題は、青い点を含まず、赤い点を最大化する最長の有効な角度間隔を見つけることに変換されます。 

すべての点が極角に変換されたら、それらを並べ替えて配列を複製し、ラップアラウンドを処理できます。 次に、問題は、青い点を含まず、赤い点の数が最大になるように、この 2 倍の円形配列内の連続するセグメントを選択することになります。 2 ポインター スイープでは、青い点が存在しないウィンドウが維持されます。 青い点がウィンドウに入ると、制約が復元されるまで左ポインタを前方に移動します。 

各有効なウィンドウ内で、含まれる赤い点の数を追跡し、最大値を取得します。

 ## アルゴリズムのチュートリアル

 1. atan2(y, x) を使用して、各点 (x, y) を極角に変換します。

これにより、象限構造を考慮して、原点の周りで正しい角度順序が保証されます。 
2. 各角度とその色を組み合わせて、リストを角度ごとに並べ替えます。 

ソートにより、円形ジオメトリがシーケンスに線形化されます。 
3. 各要素に (角度 + 2π、色) を追加して、ソートされた配列を複製します。 

これにより、ラップアラウンド間隔を通常の部分配列として表現できるようになります。 
4. 倍増配列の先頭で 2 つのポインター l と r を初期化し、ウィンドウを維持します。 

ウィンドウは、現在の候補角度セクターを表します。 
5. r を段階的に展開し、ウィンドウに点を追加します。 

ポイントを含めるたびに、赤と青のポイントの数が更新されます。 
6. ウィンドウに青い点が表示された場合は、青い点がなくなるまで l を前方に移動します。 

これにより、セクターには青い点が 0 個含まれていなければならないという有効条件が復元されます。 
7. ウィンドウが有効な場合は常に、内部の赤い点の数を計算し、答えを更新します。 

最良のセクターは、最大有効なウィンドウ境界ペアに対応する必要があります。 
8. 有効なセクターには一回転以上の固有ポイントを含めることはできないため、ウィンドウの長さが N を超えないように注意してください。 

### なぜ効果があるのか

 角度によってソートした後、すべての有効なセクターは円上の連続した間隔に対応します。 配列を複製すると、候補セクターを失うことなく、円形の間隔が線形の間隔に変換されます。 2 ポインタ プロセスでは、現在のウィンドウに青い点が含まれていないという不変条件が維持され、青い点が入るたびに、左の境界がそれを除去するのに十分なだけ前進します。 これにより、右ポインターが展開するときにすべての最大有効角度間隔が 1 回だけ考慮されることが保証されるため、すべての有効な青のないセクターの中の赤点の最大数がキャプチャされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def main():
    n = int(input())
    colors = input().strip()
    
    pts = []
    for i in range(n):
        x, y = map(int, input().split())
        ang = math.atan2(y, x)
        pts.append((ang, colors[i]))
    
    pts.sort()
    
    arr = pts + [(ang + 2 * math.pi, col) for ang, col in pts]
    
    l = 0
    red = 0
    blue = 0
    ans = 0
    
    for r in range(len(arr)):
        if arr[r][1] == 'r':
            red += 1
        else:
            blue += 1
        
        while blue > 0:
            if arr[l][1] == 'r':
                red -= 1
            else:
                blue -= 1
            l += 1
        
        ans = max(ans, red)
        
        if r - l + 1 > n:
            if arr[l][1] == 'r':
                red -= 1
            else:
                blue -= 1
            l += 1
    
    print(ans)

if __name__ == "__main__":
    main()
```実装は角度スイープの構築に直接続きます。 atan2 変換は、すべての象限にわたって正しい順序を維持するため、重要です。 ソートにより、有効なセクターが角度空間内の連続した間隔になることが保証されます。
