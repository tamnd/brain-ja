 ## 問題の理解

 私たちに与えられているのは、$n \times n$すべてのセルが 1 つのトークンで始まるグリッド。 1 回の移動で、トークンを 1 つ選択し、それを対角線を含む 8 つの隣接するセルのいずれかに移動します。 トークンは積み重ねることができ、同じセルに入る数に制限はありません。 目標は、総移動数を最小限に抑えながら、すべてのトークンを 1 つのセルに入れることです。 

すべてのセルには最初に 1 つのトークンが含まれているため、タスクは最終的な「ターゲット」セルを選択し、他のすべてのトークンをそのセルに移動することと考えることができます。 各トークンは、8 方向の移動下で選択されたターゲットまでの最短経路距離に等しいコストを与えます。 

重要な隠された構造は、8 方向の移動がチェビシェフ距離に対応するということです。 細胞の場合$(i, j)$そしてターゲット$(x, y)$、距離は次のとおりです。$$\max(|i-x|, |j-y|)$$したがって、問題は次のようになります。すべてのグリッド セルからのチェビシェフ距離の合計が最小になる中央セルを選択します。 

制約$n \le 5 \cdot 10^5$テストの合計を制限すると、グリッド操作をシミュレートしたり、すべてを反復したりできないことを意味します$n^2$細胞。 どのような解決策でも、グリッドを次の 1D 合計数式に縮小する必要があります。$O(1)$または$O(n)$テストごとに。 

微妙なエッジケースは、$n = 1$。 グリッドにはすでにすべてのトークンが 1 つのセルに含まれているため、答えはゼロです。 どの式でも、特別なケースを使用せずにこれを自然に処理する必要があります。 

対称性について推論するときに、別の暗黙のエッジ動作が現れます。 なぜなら$n$奇妙です、ユニークな中央セルがあります。 正しい解決策では、この事実を暗黙的に使用する必要があります。 そうしないと、複数の中心間の距離を平均すると、誤った二重計算や分数推論が発生します。 

## アプローチ

 ブルートフォースソリューションでは、考えられるすべてのターゲットセルを試します。$(x, y)$、すべてのセルからセルまでの距離を計算し、すべての寄与を合計します。 それぞれの評価にかかる費用$O(n^2)$、そして、あります$O(n^2)$目標を達成し、$O(n^4)$、これはたとえ$n = 200$。 

座標を分離することでこれを大幅に減らすことができます。 チェビシェフ距離$\max(|i-x|, |j-y|)$2D では扱いにくいですが、対称性が役に立ちます。すべてのセルを直接合計するのではなく、中心の周囲の各層が均一に寄与していることが観察されます。 

ボードを中心の周りの同心円状の正方形の「リング」と考えてください。 離れたところにあるすべてのセル$k$正方形の辺の境界線を形成する$2k+1$。 そのリング内のすべてのトークンは少なくとも移動する必要があります$k$中心に到達するまでのステップ、そして正確に$k$達成可能です。 したがって、各層は次のように貢献します。$$(\text{number of cells in ring}) \cdot k$$一定のサイズのグリッドの場合$n$、中心は遠くにあります$0$、からのレイヤーがあります$1$に$\frac{n-1}{2}$。 の$k$-th 層は、その層の正方形の周囲長に寄与します。 周囲長のカウントは次のように単純化されます。$8k$したがって、総コストは次のようになります。$$\sum_{k=1}^{(n-1)/2} 8k^2$$これにより、問題が閉じた形式の二乗和に変換され、依存性が排除されます。$n^2$。

 ## アルゴリズムのチュートリアル

 1. すべてのトークンが選択した中央セルに向かって個別に移動するため、総コストは各セルから中央までの最短経路距離の合計になることに注目してください。 これにより、動きをシミュレートするのではなく、各セルを個別に扱うことができます。 
2. 8 方向に移動すると、距離がチェビシェフ距離に等しくなることがわかります。 これにより、パス シミュレーションが正方形のレイヤーに基づく単純な幾何学的解釈に置き換えられます。 
3. 最適なターゲットは固有の中央セルであることに注意してください。$(\frac{n}{2}, \frac{n}{2})$対称性により、偏差があると少なくとも 1 つの対称領域の合計距離が増加することが保証されるためです。 
4. グリッドを中心を中心として同心円状の正方形のリングに分割します。 最も外側のリングには半径があります$\frac{n-1}{2}$、それぞれのリング$k$中心からの最大座標距離が正確に一致するすべてのセルが含まれます$k$。 
5. リング上に正確に存在するセルの数を計算します。$k$。 辺の正方形$2k+1$辺の二乗を引いたもの$2k-1$与える:$$(2k+1)^2 - (2k-1)^2 = 8k$$したがって、各リングには次のものが含まれます$8k$細胞。 

1. それぞれ$8k$トークンは少なくとも移動する必要があります$k$内側に向かって進みますが、パスは常に中心に向かって単調に選択できるため、この境界はタイトです。 
2. すべてのリングにわたる寄与を合計します。$k = 1$に$k = \frac{n-1}{2}$、各レイヤーの距離とカウントを乗算します。 
3. 結果として得られる閉じた形式をテスト ケースごとに効率的に評価します。 

### なぜ効果があるのか

 すべてのセルは中心から正確に 1 つのチェビシェフ距離レイヤーに属し、各レイヤーは独立して総コストに寄与します。 互いに素なリングに分解することで、二重カウントがなくなり、距離の下限が保証されます。$k$リング用$k$斜めの移動により両方の座標を同時に減らすことができるため、 はタイトになります。 これにより、合計されたレイヤー コストが最小合計移動数と正確に一致することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        k = (n - 1) // 2
        # sum_{i=1..k} 8*i*i
        # = 8 * sum i^2
        s = k * (k + 1) * (2 * k + 1) // 6
        print(8 * s)

if __name__ == "__main__":
    solve()
