 ## 問題の理解

 のマルチセットが与えられています$3N$整数。 2 人のプレイヤーが構造化された選択プロセスでこれらの数字を操作し、各数字を 3 つの役割 (赤、青、捨て札) のいずれかに徐々に割り当てます。 以上$N$ラウンドすると、ちょうど 1 つの数字が赤になり、ちょうど 1 つの数字が青になり、ちょうど 1 つが消去されるので、合計で次のようになります。$N$赤い要素と$N$青色の要素、残りの要素$N$要素はスコアに影響を与えずに消えます。 

赤のプレーヤー (カルリーニョス) は、ラウンドごとに利用可能な番号を 1 つ選択します。 すると対戦相手はすぐに反応して、他の利用可能な数字を 2 つ選び、そのうちの 1 つを青に割り当て、もう 1 つを破棄します。 すべてのラウンドを終えて、両プレイヤーは敵対的な条件下で効果的にセットを形成しました。カルリーニョスは赤の和と青の和の差を最大化しようとしますが、対戦相手はこれらの和を強制的に等しくしようとします。 

結果は、カルリーニョスが、最適なプレーを前提として、相手が構築できるすべての可能な青の和と最終的な赤の和を強制的に異ならせることができるかどうかにのみ依存します。 

制約$N \le 1000$と$3N \le 3000$ソートと線形スキャンで十分であり、指数部分集合や合計に対する動的計画法を伴うものは不可能であることを示唆しています。 

微妙な点は、対戦相手が非常に強力であるということです。各ラウンドで未使用の要素を 2 つ選択することで、今後の青の選択にどの要素が残るかを効果的に制御します。 これにより、ローカルな貪欲な決定だけでなく、グローバルな意味でプロセスが敵対的になります。 

単純な間違いは、ゲームがラウンドごとに独立してペアをマッチングすることであると仮定することです。 初期の選択が後の構造を制約するため、これは失敗します。 

たとえば、すべての数値が等しい場合、次のようになります。$5,5,5,5,5,5$のために$N=2$、どの分割でも同じ合計が得られるため、カルリーニョスが勝つことはできません。 「局所的にバランスをとろう」という貪欲な戦略は、勝利の可能性を誤って示唆する可能性がありますが、グローバルな対称性により平等が保証されます。 

もう 1 つの失敗例は、次のような数値が 2 の累乗のように構成されている場合です。$1,2,4,8,16,32$。 ここでは、すべてのサブセットの合計は一意であるため、対戦相手は異なる赤の選択と一致することはできません。 平均値やバランスに基づいた推論では、この厳密性が失われる可能性があります。 

## アプローチ

 ブルートフォース ビューではゲームをシミュレートしようとします。カルリーニョスは赤い要素を選択し、対戦相手は残りの要素の可能なすべてのペアを試して、どれが青になるかを決定します。 後$N$ラウンドでは、結果として得られる赤と青の構成をすべて列挙し、平等が常に回避可能か強制可能かどうかを確認します。 分岐要素は非常に大きく、各ラウンドで次の要素が導入されます。$O(n^2)$相手に選択肢を与え、それをはるかに超えた爆発を引き起こす$10^{18}$州。 

重要な観察は、対戦相手の「2 つ選んで 1 つキープ」の動きが見た目よりも強力であるということです。 選択された 2 つの要素のうち 1 つだけが青になり、もう 1 つは破棄されるため、対戦相手は事実上、どの要素が青の割り当て候補のプールに残るかを自由に決定できます。 これは、ゲーム全体を通じて、対戦相手が最終的な青セットが基本的に任意のサイズのサブセットであることを保証できることを意味します。$N$から引き出された$2N$赤として選択されなかった要素。 

これにより、ゲームはきれいな組み合わせ構造に縮小されます。 カルリーニョスはレッドセットを選択$R$サイズの$N$。 残りのマルチセット$S$サイズがあります$2N$。 その後、対戦相手は任意のサブセットを選択します$B \subset S$サイズの$N$可能であればレッドサムと一致するようにします。 

そこで問題は、赤色の選択は存在するかということです。$R$すべてのサブセットに対して$B$サイズの$N$補数、等価性$\sum R = \sum B$不可能ですか？ 

同様に、レッドサムを達成可能な範囲外に押し出すことができれば、カルリーニョスが勝ちます。$N$-残りの要素のサブセットの合計。 

分類後は構造が扱いやすくなります。 固定セットから対戦相手の可能な最高および最悪の青の合計は、利用可能な最小または最大の要素を取得することによって達成されます。 これにより、不確実性全体が極端な構成に崩壊します。 

カルリーニョスには、分離を最大化するための意味のある戦略が 2 つだけあります。$N$要素を取得するか、最小のものを取得します$N$要素。 混合の選択は、相手の達成可能な範囲外に合計を押し出す能力を弱めます。 

彼が最大のものを取った場合$N$、相手は最小のもので動作します$2N$。 対戦相手の可能な最大のブルーサムは、最大の値を取ることで達成されます。$N$このうち、ソートされた配列の中央のブロックに対応します。 

カルリーニョスが最小値を取った場合$N$、相手は最大のものと協力します$2N$、そして対戦相手の最小可能な青の合計は再び中央のブロックに対応します。 

したがって、すべてはソートされた配列のプレフィックス、ミドル、サフィックスの合計を比較することに集約されます。

 ## アルゴリズムのチュートリアル

 極値についての推論が意味のあるものになるように配列を並べ替えます。 ソートされた配列を次のようにします$a_1 \le a_2 \le \dots \le a_{3N}$。 

連続したブロックの合計を一定時間内に取得できるように、プレフィックスの合計を事前計算します。 

配列を 3 つの等しいブロックに分割します。$N$、真ん中$N$、そして最大の$N$。 

1. 最小値の合計を計算します。$N$要素。 これは、カルリーニョスが可能な限り小さい赤の寄与を選択したことを表しています。 
2. 中間値の合計を計算します。$N$要素。 これは、両方の極端なシナリオで達成可能な青の合計に対する対戦相手の強制境界を表します。 
3. 最大値の合計を計算します。$N$要素。 これは、カルリーニョスが可能な限り最大の赤の貢献を選択したことを表します。 
4. 最大値の合計が$N$要素は厳密に中間値の合計より大きくなります$N$要素を考慮すると、カルリーニョスは最大のブロックを選択し、達成可能な青の構成よりも高いスコアを強制することができ、勝利を保証します。 
5. 最小値の合計が$N$要素は中間の合計よりも厳密に小さい$N$要素を考慮すると、カルリーニョスは最小のブロックを選択して、達成可能な青の構成を下回るスコアを強制することができ、これも勝利を保証します。 
6. どちらの厳密な不等式も成り立たない場合、考えられるすべての極端な赤の和は、何らかの有効な青の構造と一致するため、対戦相手は平等を強制することができます。 

これら 2 つの極端な値で十分である理由は、他の赤の選択ではこれら 2 つの極端な値の間にある合計が生成され、対戦相手の柔軟性により、残りの要素の達成可能なサブセット合計の範囲内で任意の内部値が確実に一致することが保証されるためです。 

### なぜ効果があるのか

 ソート後、対戦相手はサイズのサブセットを選択できます$N$残ったものから$2N$要素は、任意の固定赤セットについて、青の合計が任意ではなく、可能な最小値と最大値の間に制限されることを意味します。$N$-補体のサブセット。 これらの極端な値は、ソートされた配列の連続するセグメントと常に一致します。 

カルリーニョスがマッチングの失敗を保証できるのは、選択した合計がこの達成可能な間隔の厳密に外側にある場合のみです。 このような分離を強制する唯一の方法は、2 つの極端なブロックの 1 つを選択することです。これは、混合選択では、可能な青色の合計の中間範囲で「カバーされる」合計が生成されるためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N = int(input())
    a = list(map(int, input().split()))
    a.sort()

    prefix = [0]
    for x in a:
        prefix.append(prefix[-1] + x)

    def range_sum(l, r):
        return prefix[r] - prefix[l]

    total = 3 * N

    small = range_sum(0, N)
    mid = range_sum(N, 2 * N)
    large = range_sum(2 * N, 3 * N)

    if large > mid or small < mid:
        print("Y")
    else:
        print("N")

if __name__ == "__main__":
    solve()
```この実装は、最適なプレイの構造を明らかにするためにソートに依存しています。 プレフィックスの合計は、ソート後に 3 つのブロックの合計を一定時間内に計算できるようにするために使用されます。 

重要な点は、ゲームのシミュレーションを決して試みないことです。 すべての相互作用効果は、ソートされた配列から導出された 3 つの決定論的な量間の比較に圧縮されます。

 ## 特殊なケース

 すべての数値が同一の場合、ソートされたブロックの合計は等しいことになります。 その状況では、どちらの極端な戦略も厳密なアドバンテージを生み出すことはできないため、対戦相手は対応する青の選択を使用して、常に赤の合計をミラーリングできます。 アルゴリズムは正しく返します`N`なぜなら、どちらの不等式も成り立たないからです。 

値が厳密に増加しているものの、間隔が適度にある場合、多くの場合、最大のブロックが中央のブロックを支配します。 たとえば、$[1,2,3,100,200,300]$、大きいブロックの合計が中央のブロックの合計を超えるため、カルリーニョスは最大の要素を選択することで強制的に分離できます。 条件`large > mid`ゲームのシミュレーションを必要とせずに、これを正確にキャプチャします。
