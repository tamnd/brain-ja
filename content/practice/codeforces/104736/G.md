 ## 解決策
 ## 問題の理解

 2D 整数グリッド上にいくつかの電波塔が与えられています。 各タワーは未知のユーザー位置までの正確なマンハッタン距離を認識しており、これらすべての距離が同時に正しいことが保証されます。 タスクは、すべての距離制約が満たされるように、ユーザーが位置している可能性のあるすべての整数座標を復元することです。 

タワーからの単一の制約$(a,b)$距離を置いて$d$未知の点を意味します$(x,y)$を中心とするマンハッタンの円の境界上にあります。$(a,b)$。 ユークリッド円とは異なり、この境界はひし形であるため、制約は滑らかな曲線ではなく、軸に沿った区分的な線形形状になります。 

出力は、すべての制約を一度に満たす整数点の完全なセットであり、辞書順に並べ替えられています。$x$、 それから$y$。 重要な部分は、解セットが有限であることが保証されているため、実行可能な点の無限の領域を扱っているわけではないということです。 

制約により、最大で次のことが許可されます。$10^5$これにより、候補となるグリッド ポイントを明示的にテストしたり、交差をペアごとに列挙したりするアプローチは直ちに除外されます。 座標が範囲を超える可能性があるため、適度なサイズの境界ボックスをチェックすることさえ不可能です。$10^4$、可能性を与える$10^8$エリア。 

重要な点は、マンハッタンの等式制約が、傾斜のある線で構成されるポリゴンの境界を定義していることです。$+1$そして$-1$、最終的な実行可能な領域は、そのようなポリゴンの交差点です。 素朴な解釈では、答えはまだ多くの頂点を持つ複雑な多角形であると思われるかもしれませんが、この問題では、構造は非常に小さな構造化されたセットに崩壊します。 

よくある失敗例は、各制約が独立して単純な境界ボックスに帰着すると仮定することです。$(x,y)$。 それは間違った扱いになります$|x-a| + |y-b| = d$長方形の領域として表示されますが、実際にはその領域の境界にすぎません。 

もう 1 つの微妙な落とし穴は、拘束を 1 つずつ幾何学的に交差させようとすることです。 各ステップが凸多角形を維持する場合でも、それを明示的に維持する複雑さは制約ごとに頂点単位で線形に増大し、これは実行不可能になります。$10^5$塔。 

## アプローチ

 強引なアイデアは、十分に大きな境界ボックス内のすべての整数点を考慮することです (たとえば、$[-2\cdot10^4,2\cdot10^4]^2$)、すべてのタワー制約をテストします。 それぞれのチェックは、$O(1)$、ただしグリッドには約$1.6 \cdot 10^9$ポイント、それは完全に不可能です。 

もう少し良い試みは、各制約がダイヤモンド境界であることを観察し、境界線が交わる場所で交差が発生することを観察することです。 各制約は次の 4 つの線種に影響します。$x+y = a+b+d$、$x+y = a+b-d$、$x-y = a-b+d$、$x-y = a-b-d$。 

これらすべての線をペアごとに交差させてみることもできますが、それは次のような結果になります。$O(N^2)$候補者だがまだ無理$10^5$。 

重要な構造的洞察は、座標を切り替えることです。 定義する$u = x + y$そして$v = x - y$。 

これらの座標では、マンハッタンの幾何学形状は軸に沿って配置されます。 それぞれの制約によって制限されるのは、$u$そして$v$間隔に対して独立して:$u \in [a+b-d, a+b+d]$、$v \in [a-b-d, a-b+d]$。 

したがって、すべての塔が長方形を形成します。$(u,v)$-space であり、解セットはこれらすべての長方形の交差部分です。 この交差自体は長方形です。つまり、必要なのはグローバルな最小/最大境界だけです。$u$そして$v$。 

最後のステップは有効な変換です$(u,v)$整数に戻る$(x,y)$、これにはパリティの一貫性が必要です。$x = (u+v)/2$、$y = (u-v)/2$、 それで$u$そして$v$同じパリティを持つ必要があります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースグリッドチェック |$O(R^2 N)$|$O(1)$| 遅すぎる |
 | 最適な間隔$u,v$スペース |$O(N + K)$|$O(1)$| 承認済み |

 ここ$K$出力点数です。 

## アルゴリズムのチュートリアル

 1. 各タワーごと$(a,b,d)$、4 つの値を計算します。$a+b-d$、$a+b+d$、$a-b-d$、$a-b+d$。 これらは、次の許容範囲を定義します。$u$そして$v$。 
2. グローバルな境界を維持する$u$:$U_{\min} = \max(a+b-d)$、$U_{\max} = \min(a+b+d)$。 

これにより、$u$すべての制約を同時に満たします。 
3. グローバルな境界を維持する$v$:$V_{\min} = \max(a-b-d)$、$V_{\max} = \min(a-b+d)$。 

これにより、$v$また、すべての制約も同時に満たします。 
4. 間隔が無効な場合 ($U_{\min} > U_{\max}$または$V_{\min} > V_{\max}$)、解決策は存在しませんが、この問題はこれが起こらないことを保証します。 
5. すべての整数を反復処理します。$u$で$[U_{\min}, U_{\max}]$そして$v$で$[V_{\min}, V_{\max}]$。 
6. ペアのみを保持します。$u \equiv v \pmod 2$、そうでないので$(x,y)$整数ではありません。 
7. 有効なペアを変換して戻します。$x = (u+v)/2$、$y = (u-v)/2$、ソート順 (昇順) で出力します。$x$、 それから$y$）。 

### なぜ効果があるのか

 各マンハッタンの等式制約は、凸状のひし形を定義します。 に変身すると、$(u,v)$座標に応じて、そのようなすべてのダイヤモンドは軸に沿った長方形になります。 したがって、すべての制約と交差すると、軸に揃えられた別の長方形が生成されます。$(u,v)$-空間。 この長方形内の整数点は候補に対応します。$(x,y)$すべての制約を同時に満たし、外側の点は少なくとも 1 つの制約を満たすことができません。$u$または$v$縛られた。 パリティ条件は、整数のバック マッピングを保証するために必要な残りの唯一の制限です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    U_min = -10**30
    U_max = 10**30
    V_min = -10**30
    V_max = 10**30

    for _ in range(n):
        x, y, d = map(int, input().split())
        s = x + y
        t = x - y

        U_min = max(U_min, s - d)
        U_max = min(U_max, s + d)
        V_min = max(V_min, t - d)
        V_max = min(V_max, t + d)

    res = []

    for u in range(U_min, U_max + 1):
        for v in range(V_min, V_max + 1):
            if (u & 1) != (v & 1):
                continue
            x = (u + v) // 2
            y = (u - v) // 2
            res.append((x, y))

    res.sort()
    out = sys.stdout.write
    for x, y in res:
        out(f"{x} {y}\n")

if __name__ == "__main__":
    solve()
```最初のフェーズでは、すべての幾何学的拘束を 2 つの独立した 1 次元間隔交差に圧縮します。$u = x+y$そして1つは$v = x-y$。 これは、各タワーが一定時間の境界を更新することによって実行可能な範囲を狭めるだけであるため、幾何学的な困難全体がなくなる場所です。 

第 2 フェーズでは、実行可能なすべての項目を列挙します。$(u,v)$結果として得られる長方形内のペア。 パリティチェックは必須であるため、$u$そして$v$整数に対応する必要があります$x$そして$y$。 このフィルターがないと、再構成されたポイントの半分が無効なグリッド位置になります。 

列挙では自然に辞書順が保証されないため、ソートは最後に行われます。$(x,y)$。 

## 実用的な例

 最初のサンプルを考えてみましょう。 

制約を境界に集約します。$u$そして$v$。 最終結果が小さな長方形になると仮定します。 その中のすべての整数ペアを列挙し、パリティによってフィルターします。 

| ステップ | U 範囲 | Vレンジ | アクション |
 | --- | --- | --- | --- |
 | タワーの加工後 | 一定の間隔 | 一定の間隔 | 交差制約 |
 | 列挙 | すべてのあなたが範囲内にあります | 範囲内のすべての v | テストパリティ |
 | 出力 | 有効な (x,y) | 並べ替え | 最終的な答え |

 この場合の重要な観察は、交点が単一の点ではなく、実行可能な整数解の小さなグリッドであるため、複数の候補点が生き残ることです。 

次に、制約がより厳しい 2 番目のサンプルを考えてみましょう。 

| ステップ | U 範囲 | Vレンジ | アクション |
 | --- | --- | --- | --- |
 | タワーの加工後 | より小さい間隔 | より小さい間隔 | より強力な制約 |
 | 列挙 | ペアが少なくなる | ペアが少なくなる | パリティフィルターが適用されました |
 | 出力 | 削減されたセット | 並べ替え | 最終的な答え |

 これは、追加のタワーが 2 つの変換された軸に沿って独立して実行可能領域をどのように縮小するかを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 |$O(N + K)$| 各タワーは境界を 1 回更新し、その後、それぞれの有効な境界を更新します。$(u,v)$ペアが列挙されます |
 | スペース |$O(1)$| 少数の間隔変数と出力ストレージのみ |

 このアルゴリズムは、タワーの数に有効な回答の数を加えたもので線形です。これは、すべての制約を少なくとも 1 回読み取る必要があり、すべての出力ポイントを出力する必要があるため、最適です。

 ## 特殊なケース

 コーナーケースは、実行可能領域が単一の格子点に崩壊する場合に発生します。 そのような状況では、$U_{\min} = U_{\max}$そして$V_{\min} = V_{\max}$ループが単一の反復に縮退し、パリティ チェックが自動的にパスするため、アルゴリズムは引き続き機能します。 

もう 1 つの微妙なケースは、長方形が$(u,v)$-space には多くのポイントが含まれていますが、パリティのため半分だけが有効です。 たとえば、次の場合$U_{\min}=0$、$U_{\max}=2$、$V_{\min}=0$、$V_{\max}=2$の場合、4 つの組み合わせのみが存在し、一致するパリティを持つ組み合わせだけが整数を生成します。$(x,y)$。 アルゴリズムは、特別な処理を行わずにこれらを自然にフィルタリングします。 

最後に、複数のタワーによって境界が非常に厳しくなった場合、交差部分が空の領域に縮小する可能性がありますが、この問題ではこのようなことが起こらないことが保証されているため、明示的な処理は必要ありません。
