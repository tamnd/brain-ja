 ## 問題の理解

 単一の整数が与えられます$N$10 進数で表現され、さまざまな基数で表現できる値として扱われます。 あらゆる拠点に$b$範囲内で$[2, N]$、私たちは書きます$N$基地内で$b$そして、その表現が数字シーケンスとして読み取られたときに回文であるかどうかを確認します。 

ここでの回文は純粋に基数に変換した後に得られる数字列に関するものです。$b$。 先頭のゼロは、表現自体には決して含まれないという意味では重要ではないため、生成された数字の対称性のみをチェックします。 

タスクはすべての塩基を出力することです$b$この回文条件が成り立つものを昇順に示します。 機能するベースがない場合は、アスタリスクが出力されます。 

制約$N \le 10^{12}$中央信号です。 変換を繰り返してすべての塩基を単純にテストするわけにはいきません。$N$基地に$b$で$O(\log_b N)$時間。 それはまだ大まかに意味します$O(N \log N)$制限をはるかに超えた最悪の場合、数値演算が実行されなくなります。 ソリューションでは、基本表現がどのように動作するかの構造を利用する必要があります。 

小さなベースに微妙なエッジケースが現れます。 たとえば、ベースでは$N$、表現は常に$"10"$、これは回文ではありません。 基地内$N-1$、私たちは得ます$"11"$、これは常に回文です。 これらの極塩基は中間塩基とは異なる動作をするため、一般的なロジックで一貫して処理する必要があります。 

もう 1 つの重要なエッジケースは、$N = 2$。 基数 2 のみが存在し、その表現は次のようになります。$"10"$したがって、答えは空であり、次のように出力する必要があります。`*`。 

## アプローチ

 ブルートフォースのアイデアは単純です。すべての塩基を反復処理します。$b$2から$N$、 変換する$N$基地に$b$、数字シーケンスが回文であるかどうかを確認します。 変換には時間がかかります$O(\log_b N)$、すべての塩基にわたってこれが累積すると、おおよそ次のようになります。$O(N)$数字の操作。 以来$N$まで可能です$10^{12}$、これは不可能です。 

重要な観察は、ベースに回文があることです。$b$強い代数的制約を課す$N$。 数字の観点から考える代わりに、基数の回文多項式の構造に切り替えます。$b$。 数値に長さの回文表現がある場合$k$の場合、その値は対称多項式として次のように書くことができます。$b$、間の関係を強制します。$b$、$k$、 そして$N$。 

これは、根本的に異なる 2 つのソリューション群につながります。 

まず、短い表現。 回文の長さが 1 または 2 の場合、すべての塩基を明示的に特徴付けることができます。 1 桁の表現は、$b > N$、これは許容範囲外です。 2 桁の回文は次の形式でなければなりません。$xx$、これは次のことを意味します。$$N = x \cdot b + x = x(b+1)$$それで$b = \frac{N}{x} - 1$、 そして$x < b$。 これにより、次の約数から導出される候補塩基の有界セットが生成されます。$N$。 

2つ目は、長い回文です。 長さが 3 以上の場合、底辺は相対的に小さくなります。$\sqrt{N}$。 実際、桁数が大きくなると、底は最大でも約$\sqrt{N}$なぜなら、最小の自明ではない回文であっても、基底とともに二次関数的に成長するからです。 これにより、以下のすべての塩基のチェックに制限されます。$O(\sqrt{N})$、それは実現可能です。 

したがって、解決策は分割されます。除数を使用して短い回文から得られる有効な基数を明示的に列挙し、ブルート チェックのみを行います。$\sqrt{N}$残りのケースについては。

 ## アルゴリズムのチュートリアル

 1. 可能な小さな基底を反復処理します。$b$2から$\lfloor \sqrt{N} \rfloor$。 変換する$N$基地に$b$、数字のリストが回文かどうかを確認します。 これは、表現の長さが少なくとも 3 であるすべてのケースをキャプチャします。 
2. ステップ 1 で見つかったすべての有効な塩基を結果セットに収集します。 異なる構築によって同じベースが生成される可能性があるため、重複を避けるためにセットを使用します。 
3. すべての約数を列挙します$x$の$N$。 各約数について$x$、基地を建設しようとします$b = \frac{N}{x} - 1$。 これは 2 桁の回文形式に対応します$xx$。 
4. 構築されたそれぞれを検証します$b$確保することで$b \ge 2$そして$x < b$。 不平等$x < b$桁を保証します$x$ベースでは有効です$b$。 
5. ステップ 3 で得たすべての有効な塩基を結果セットに追加します。 
6. 結果セットをソートして出力します。 空の場合は印刷します`*`。 

### なぜ効果があるのか

 すべての有効な基本表現は、少なくとも 3 桁か、正確に 2 桁のいずれかの 2 つのカテゴリのいずれかに分類されます (1 桁の場合は発生しません)。$b \ge 2$）。 最初のカテゴリは、以下のすべての塩基をチェックすることで完全にカバーされます。$\sqrt{N}$, 回文が長いと底が小さくなるからです。 2 番目のカテゴリは厳密な代数形式を持ちます$N = x(b+1)$、これは、の約数を反復することによって完全にキャプチャされます。$N$。 これらのケースはばらばらで網羅的であるため、有効なベースが見逃されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_pal_base(n, b):
    digits = []
    while n > 0:
        digits.append(n % b)
        n //= b
    return digits == digits[::-1]

def solve():
    n = int(input().strip())
    res = set()

    import math
    limit = int(math.isqrt(n))

    for b in range(2, limit + 1):
        if is_pal_base(n, b):
            res.add(b)

    # handle 2-digit palindromes: N = x * b + x
    # => b = N // x - 1
    for x in range(1, limit + 1):
        if n % x == 0:
            y = n // x
            b = y - 1
            if b >= 2 and x < b:
                res.add(b)

            # paired divisor
            x2 = y
            b2 = n // x2 - 1 if x2 != 0 else -1
            if x2 != x and x2 <= limit:
                b2 = x - 1
                if b2 >= 2 and x2 < b2:
                    res.add(b2)

    if not res:
        print("*")
    else:
        print(*sorted(res))

if __name__ == "__main__":
    solve()
```変換関数はベースを構築します。$b$除算を繰り返し、剰余を格納することで表現します。 回文チェックは数字リストに対して直接行われます。 桁の長さは最大でも次のとおりであるため、これは安全です$O(\log N)$、小さいままです。 

除数ループは、対称ケースを見逃すことなく、各除数ペアの両方のメンバーを生成するように構造化されています。 制約$x < b$それを確実にするために不可欠です$x$基数内の有効な数字です$b$そうでない場合、構築された表現は無効になります。
