 ## 解決策
 ## 問題の理解

 私たちは、原点が点に固定されている無限の 2D 平面で作業しています。$(0,0)$。 クマは、ちょうどユークリッド距離にある点のみを考慮できます。$D$原点からの距離なので、幾何学的には原点を中心とする円になります。 

時間の経過とともに、一連の直線が導入されます。 各線は永続的な障壁となり、一度出現するとクマはそれを越えることができなくなります。 これは、各線が交差する領域を 2 つの切断された部分に分割するため、平面が徐々に小さな接続領域に切断されることを意味します。 

問題は、原点を含む接続領域が半径円に触れなくなる最も早い瞬間を判断することです。$D$。 言い換えれば、いくつかの線の接頭辞を処理した後、すべての禁止線を差し引いた平面内の原点の接続されたコンポーネントを調べ、そのコンポーネント内に原点からの距離が正確に一致する点がまだ存在するかどうかを尋ねます。$D$。 初めてこれが不可能になることを望んでいます。 決して不可能にならない場合、答えはアスタリスクです。 

制約は次のとおりです$2 \cdot 10^5$したがって、プレフィックスごとにジオメトリを最初から再計算するアプローチは遅すぎます。 平$O(N^2)$推論はすぐに範囲外になります。 私たちは、グローバルな幾何学的プロパティを効率的にチェックできる方法で各ラインが処理される構造に強制されます。 

微妙な点は、線が原点を決して通過しないため、原点は常に各線で定義される 2 つの開いた半平面のいずれかに厳密に存在することです。 これにより、原点は常に、交差する半平面によって形成される明確に定義された凸面領域内に留まることが保証されます。 

素朴な考え方による重要な失敗例の 1 つは、原点がグラフのような意味で孤立するかどうかを検出するだけでよいと想定していることです。 接続構造は連続的かつ幾何学的であるため、領域がまだ無限であるものの、半径に到達するには「狭すぎる」ときに分離が発生する可能性があります。$D$。 もう 1 つの微妙なケースは、領域が円の制約を満たさずに境界のないままであるか、境界があるものの円に到達するのに十分な大きさである可能性があることです。 

## アプローチ

 重要な変換は、プロセスを半平面の観点から再解釈することです。 各線は平面を分割し、原点は決して線上にないため、各線は原点を含む必要がある固定の半平面を生成します。 最初の処理後$k$直線の場合、原点から到達可能な領域は正確に次の交点になります。$k$半面。 

それでその後$k$凸状 (おそらく境界のない) 領域を維持するステップ$R_k$、すべての有効な半平面の交点として定義されます。 問題は、この領域が半径の円と交差するかどうかです。$D$? 同様に、次の点は存在しますか?$R_k$そのユークリッドノルムが少なくとも$D$?

 定義すると$$F(k) = \max_{x \in R_k} \|x\|,$$そのときの条件は、クマがまさにその瞬間に閉じ込められることです。$F(k) < D$。 さらに多くのハーフプレーンが追加されると、実行可能な領域は縮小するだけです。$F(k)$単調非増加$k$。 この単調性は、答えに対する二分探索を示唆しています。 

主な計算タスクは、半平面のプレフィックスをチェックし、それらの交点内の原点からの最大距離が少なくとも$D$。 領域がどの方向にも境界がない場合、$F(k)$は無限であり、そのプレフィックスに対する答えは false です。 

ブルートフォース手法では、標準の半平面交差を使用して、プレフィックスごとに半平面の交差を最初から再計算します。$O(k \log k)$、次に最も遠い頂点を計算します。 全員のためにこれを行う$k$につながる$O(N^2 \log N)$が遅すぎます。$2 \cdot 10^5$。 

この改善は 2 つの観察から得られました。 まず、実現可能性は単調であるため、二分探索により完全なチェックの数が減少します。$O(\log N)$。 次に、各チェックは、標準の半平面交差ルーチンを使用して実行できます。$O(k \log k)$、この規模では許容範囲です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(N^2 \log N)$|$O(N)$| 遅すぎる |
 | 二分探索 + 半平面交差 |$O(N \log N \log N)$|$O(N)$| 承認済み |

 ## アルゴリズムのチュートリアル

 各ラインを、原点を実行可能領域内に保つ半平面制約として扱います。 

1. 各直線について、それを半平面不等式に変換します。 半平面に原点が含まれるように方向を選択します。 これは、原点で直線方程式を評価し、それに応じて辺を選択することによって行われます。 
2. のプレフィックスをテストするには$k$ラインの場合、対応するすべての半平面の交点を計算します。 これにより、空または境界のない凸領域が得られます。 
3. 交差点が空の場合、原点には到達できなくなるため、最大距離は事実上ゼロとなり、プレフィックスはすでに円をブロックするのに十分です。 
4. 交差部分に境界がない場合、領域が無限に広がる何らかの方向が存在するため、最大距離は無限となり、プレフィックスは十分ではありません。 
5. 領域が境界付けされている場合は、半平面の交点からその凸多角形表現を計算します。 
6. ユークリッド距離の二乗を使用して、原点からこの多角形の最も遠い頂点を計算します。 凸多角形上の凸関数の最大値は頂点で得られるため、これで十分です。 
7. この最大距離を次のものと比較します。$D^2$。 厳密に小さい場合、プレフィックスは距離にあるすべてのポイントをブロックします。$D$。 
8. 最小の二分探索$k$という条件が成り立つもの。 

正確かどうかは、行を追加するにつれて実行可能な領域が単調に縮小するという事実にかかっており、到達可能な最大半径が下回ると、$D$、二度と増えることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from math import atan2
from collections import deque

EPS = 1e-12

def cross(a, b, c):
    return (b[0]-a[0])*(c[1]-a[1]) - (b[1]-a[1])*(c[0]-a[0])

def intersection(p, d, q, e):
    # p + t d intersects q + s e
    # solve p + t d = q + s e
    det = d[0]*(-e[1]) - d[1]*(-e[0])
    if abs(det) < EPS:
        return None
    qp = (q[0]-p[0], q[1]-p[1])
    t = (qp[0]*(-e[1]) - qp[1]*(-e[0])) / det
    return (p[0] + t*d[0], p[1] + t*d[1])

def halfplane_intersection(halfplanes):
    halfplanes.sort(key=lambda x: (atan2(x[1][1], x[1][0])))
    dq = deque()

    def valid(p, h):
        a, b = h
        return a[0]*p[0] + a[1]*p[1] <= b + EPS

    for h in halfplanes:
        while len(dq) >= 2 and not valid(intersection(dq[-2][0], dq[-2][1], dq[-1][0], dq[-1][1]), h):
            dq.pop()
        while len(dq) >= 2 and not valid(intersection(dq[0][0], dq[0][1], dq[1][0], dq[1][1]), h):
            dq.popleft()
        dq.append(h)

    while len(dq) > 2:
        p = intersection(dq[-2][0], dq[-2][1], dq[-1][0], dq[-1][1])
        if not valid(p, dq[0]):
            dq.pop()
        else:
            break

    while len(dq) > 2:
        p = intersection(dq[0][0], dq[0][1], dq[1][0], dq[1][1])
        if not valid(p, dq[-1]):
            dq.popleft()
        else:
            break

    if len(dq) < 3:
        return None, False

    pts = []
    for i in range(len(dq)):
        p = dq[i][0]
        d = dq[i][1]
        q = dq[(i+1) % len(dq)][0]
        e = dq[(i+1) % len(dq)][1]
        pt = intersection(p, d, q, e)
        if pt is not None:
            pts.append(pt)

    if len(pts) < 3:
        return None, True

    return pts, True

def max_dist2(poly):
    best = 0.0
    for x, y in poly:
        best = max(best, x*x + y*y)
    return best

def check(lines, D):
    halfplanes = []
    for (x1, y1, x2, y2) in lines:
        dx = x2 - x1
        dy = y2 - y1
        # line normal
        a = (dy, -dx)
        b = a[0]*x1 + a[1]*y1
        # ensure origin is inside
        if a[0]*0 + a[1]*0 > b:
            a = (-a[0], -a[1])
            b = -b
        halfplanes.append((a, b))

    poly, ok = halfplane_intersection(halfplanes)
    if not ok:
        return False
    if poly is None:
        return True
    return max_dist2(poly) < D*D

def main():
    n, D = input().split()
    n = int(n)
    D = float(D)

    lines = [tuple(map(int, input().split())) for _ in range(n)]

    lo, hi = 1, n
    ans = None

    while lo <= hi:
        mid = (lo + hi) // 2
        if check(lines[:mid], D):
            ans = mid
            hi = mid - 1
        else:
            lo = mid + 1

    print(ans if ans is not None else "*")

if __name__ == "__main__":
    main()
```実装の中心となるアイデアは、原点が常に実行可能な状態を維持できるように、一貫した方向を持った線から半平面に変換することです。 二分探索はジオメトリ チェックをラップし、重いジオメトリのみを再計算するようにします。$O(\log N)$回。 

最もデリケートな部分は、半平面の妥当性をチェックして交差を計算する際に数値の安定性を確保することです。小さな符号の間違いが実現可能性を反転させ、交差を壊すためです。 

## 実用的な例

 原点の周りで徐々にくさび形をカットする行のプレフィックスを考えてみましょう。 最初は、交差点は平面全体であるため、最遠距離には制限がありません。 さらに制約を追加すると、領域は原点の周囲で縮小する凸多角形になります。 

| ステップ | アクション | 地域の種類 | 最大距離 vs D |
 | --- | --- | --- | --- |
 | 1 | 1行 | 半平面 | 無限 |
 | 2 | 2行 | ウェッジ | 無限 |
 | 3 | 3 行以上 | 境界付きポリゴン | 減少する |

 これは、実行可能領域が単調に縮小することを示しています。 

最終的に領域が小さくなりすぎる場合については、原点付近を中心とし、線が反対方向に切れて内側に縮小する正方形を想像してください。 内接半径が下回ると$D$、原点がまだ領域内にあるにもかかわらず、円に到達できなくなります。 

| プレフィックス | 実現可能な地域 | 最大$\\|x\\|$| 結果 |
 | --- | --- | --- | --- |
 | 1 | 飛行機 | ∞ | いいえ |
 | k | 大きな多角形 | >D | いいえ |
 | k+1 | タイトなポリゴン | < D | はい |

 これにより、遷移点が明確に定義されており、二分探索が有効であることが確認されます。

 ## 特殊なケース

 重大なエッジ ケースは、すべての制約によって方向が完全に開いたままになる場合です。 たとえば、平面を通る単一の線は、原点から無限に広がる半平面を残すため、最大距離は無限のままです。 アルゴリズムは、半平面の交差に境界がないため、条件が満たされていないことを正しく返します。 

もう 1 つのケースは、領域が有界になっても、距離に達するのに十分遠い点がまだ含まれている場合です。$D$。 この状況では、凸多角形は有効ですが、最大頂点距離がまだ超えています。$D$したがって、二分探索はこの接頭辞を超えて正しく続行されます。 

最後の微妙なケースは、領域が非常に薄くなったものの、まだ原点が含まれている場合です。 ポリゴンの面積がほぼゼロであっても、最大距離は面積ではなく頂点によって決定されるため、アルゴリズムは幅の概念ではなく頂点の距離に正しく依存します。
