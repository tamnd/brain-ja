 ## 解決策
 ## 問題の理解

 配列内の「良いペア」の数を数えるように求められます。 ポジションのペア$(l, r)$インデックスから移動できれば良いのですが$l$に$r$連続する各ペアの差が最大でも異なるインデックスのシーケンスに沿って配列内を前方にホップすることにより、$k$。 簡単に言うと、配列内の各数値を足がかりとして考えることができ、石の間の差が最大である限り、先に進むことができます。$k$。 私たちのタスクは、有効なステッピング パスを可能にするすべての可能な開始位置と終了位置をカウントすることです。 

入力には複数のテスト ケースが含まれており、それぞれの長さの配列が含まれます。$n$まで$5 \cdot 10^5$、およびすべての合計$n$テスト ケース全体の境界も次のとおりです。$5 \cdot 10^5$。 これにより、次のようなアルゴリズムが除外されます。$O(n^2)$テストケースごとに、最悪の場合、$2.5 \cdot 10^{11}$3秒ではまったく実行不可能な操作です。 アン$O(n \log n)$または$O(n)$アプローチが必要です。 

Edge cases that can easily break a naive implementation include arrays with all identical elements, arrays with strictly increasing or decreasing values, and$k = 0$。 たとえば、配列の場合`[1,1,1]`そして$k = 0$、すべての部分配列は良好であり、答えは 6 です。連続する要素のみをチェックする不注意なアプローチでは、次のようなペアを見逃してしまいます。`(1,3)`。 

## アプローチ

 ブルートフォースアプローチは、すべてのペアを反復処理することです。$(l,r)$各ペアについて、接続する有効なシーケンスが存在するかどうかを確認します。$l$に$r$。 これは、適切なペアの定義を直接モデル化するため、原理的には機能しますが、$O(n^2)$テストケースごとに。 と$n$まで$5 \cdot 10^5$、これは明らかに実行不可能です。 

重要な洞察は、インデックスから移行できるかどうかです。$i$インデックスを付ける$j$、その後、その間のすべての連続したインデックス$i$そして$j$絶対的な差を維持する$\le k$連続した「良好なセグメント」に折りたたむことができます。 各インデックスから始まる最大範囲を特定したら、違反せずに先に進むことができます。$|a[i] - a[i+1]| \le k$、各ペアを列挙する代わりに、単純な算術式を使用して、そのインデックスから始まる適切なペアの数を計算できます。 

具体的には、配列の左側からスライディング ウィンドウを維持し、条件が満たされるまで右端を拡張します。$|a[r] - a[r-1]| \le k$失敗します。 各拡張機能は複数の適切なペアを一度に追加し、$O(n^2)$料金。 これは問題を次のように変換します$O(n)$これは、すべてのインデックスが最大 2 回アクセスされるためです。1 回は左ポインタとして、もう 1 回は右ポインタとしてアクセスされます。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 テスト ケースごとに、次の内容を読んでください。$n$、$k$、および配列$a$。 各配列を個別に処理します。 
2. 結果カウンターを初期化する`res`ゼロに。 これにより、良好なペアの数が蓄積されます。 
3. 2 つのポインタを初期化します。`l = 0`そして`r = 0`。 ポインタ`l`候補の良好なセグメントの左端を表し、`r`を維持しながら到達可能な最も遠いインデックスを表します。$|a[r] - a[r-1]| \le k$。 
4. 配列を反復処理します。`l`0から$n-1$。 処理する前に拡張します`r`できる限りその間に`r < n`そして$|a[r] - a[r-1]| \le k$（のために`r > l`）。 これにより、`[l, r)`連続した良好なセグメントを形成します。 
5. から始まる良好なペアの数`l`まさに`r - l`。 これを追加`res`。 
6. インクリメント`l`そして繰り返します。 以来`r`左に移動することはなく、合計実行時間は直線的です。 
7. 配列を処理した後、印刷します。`res`。 

機能する理由: アルゴリズムは連続したセグメントを維持します`[l, r)`どのペアでも`(l, x)`のために`x`で`[l, r-1]`良いものであることが保証されています。 この不変式は次の条件により成立します。$|a[i] - a[i+1]| \le k$セグメントに沿って推移的です。 数えることによって`r - l`それぞれに`l`、二重にカウントすることなく、すべての適切なペアを正確に 1 回列挙します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    res = 0
    r = 0
    for l in range(n):
        if r < l:
            r = l
        while r + 1 < n and abs(a[r+1] - a[r]) <= k:
            r += 1
        res += r - l + 1
    print(res)
```外側のループは、セグメントの潜在的な左端をそれぞれ反復処理します。 内側の while ループが拡張されます`r`配列が許す限り、`k`- 差異の状態。 小切手`if r < l: r = l`右ポインタが左ポインタより遅れないようにします。 数える`r - l + 1`から始まるすべての適切なペアを正しく追加します`l`。
