 ## 問題の理解

 要素のインデックスを見つけるように求められます`0`からの整数の隠された順列で`0`に`n-1`。 順列は直接与えられませんが、配列内の任意の 2 つの異なる要素の最大公約数 (GCD) を求めることができます。 インタラクションにより、最大でも次のことが制限されます。`2n`テストケースごとのクエリ。 を含むインデックスがわかったと確信したら、`0`、少なくとも 1 つが`0`。 

重要な観察は、次のような数値の GCD が`0`数字そのものです。 したがって、2 つの非ゼロ要素の GCD をクエリすると、結果は少なくとも次のようになります。`1`。 クエリに関連する場合`0`の場合、結果は他の要素とまったく同じになります。 つまり区別できるということです`0`GCD が関係する数値の 1 つと等しいクエリを探すことによって間接的に行われます。 

制約が教えてくれるのは`n`まで可能です`2·10^4`と合計`n`すべてのテスト ケースにわたって次の制限も受けられます。`2·10^4`。 これは、次のような解決策があることを意味します。`O(n)`テストケースごとにクエリを実行することが可能です。 すべてのペアをクエリする単純な総当り攻撃には、`O(n^2)`クエリが多すぎるため、制限を超えてしまいます。 

明白ではないエッジケースには、非常に小さいサイズの配列が含まれます`2`または`3`不注意な実装では、要素を積極的に削除しようとしたり、繰り返されるインデックスを正しく処理できなかったりする可能性があります。 たとえば、次の場合`n=2`そして配列は`[0,1]`、2 つの要素間のクエリはすぐに明らかになります。`0`GCD がゼロ以外の要素に等しいためです。 正しい出力は次のいずれかです`(1,2)`または`(2,1)`。 

## アプローチ

 ブルートフォースアプローチは、インデックスのすべてのペアの GCD をクエリすることです。 これにより、どの要素がどの要素であるかが明らかになります`0`なぜなら、`0`他の要素を返します。 ただし、これには大まかに必要です`n*(n-1)/2`クエリ、それは周りにあります`2·10^8`最悪の場合、`n`は`2·10^4`。 2 秒の制限時間を考慮すると、これは受け入れられません。`2n`クエリ制限。 

重要な洞察は、順列の構造から得られます。 からのすべての数字なので、`0`に`n-1`正確に 1 回出現し、最大の GCD が含まれます。`0`ユニークで簡単に区別できます。 具体的には、候補インデックスを選択し、他のすべてのインデックスに対してクエリを実行すると、最大の結果が他の数値を示します。 一度に 2 つの候補を系統的に比較し、比較できないインデックスを排除することで、`0`GCD の比較に基づいて、クエリの数をおよそ次まで減らすことができます。`2n`。 

GCD が次の意味で単調であるため、このプロセスは機能します。`GCD(a,b)`そして`GCD(b,c)`繰り返される数値のない順列では、非常に大きな結果を確認する唯一の方法は、ゼロ以外の数値が含まれている場合です。これにより、より大きな要素を安全に削除して、要素を絞り込むことができます。`0`。

 ## アルゴリズムのチュートリアル

 1. まず、2 つの候補インデックスを初期化します。`0`、電話してください`candidate1`そして`candidate2`。 最初は、最初の 2 つのインデックスに設定します。 
2. これら 2 つの候補の GCD をクエリします。 可能性が高い方を残しておく`0`。 実際には、残りの要素でより小さい GCD が得られるものは、おそらく`0`。 
3. 残りのインデックスを繰り返します。 新しいインデックスごとに、現在の候補に対して GCD をクエリします。 GCD が現在の候補がゼロでないことを示している場合は、候補を置き換えます。 具体的には、`GCD(candidate, i) == i`の場合、候補はゼロではなく、新しいインデックスは次のようになります。`0`。 
4. すべてのインデックスを処理した後、生き残った候補は確実に以下をポイントします。`0`ゼロ以外の要素はすべて削除されるためです。 
5.両方の生き残った候補を使用して最終的な答えを報告します`x`そして`y`、つまり、`! candidate candidate`。 

機能する理由: 各消去ステップは、GCD のプロパティによって裏付けられています。`0`。 要素のみ`0`他の要素と厳密に等しい GCD 結果を生成できます。 ペアをクエリすることで、使用できないインデックスを破棄します。`0`そして、生き残った候補者を1名維持します。 反復の終了時に、候補者は次のようになっている必要があります。`0`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import gcd

def find_zero(n):
    candidate = 1
    for i in range(2, n + 1):
        print(f"? {candidate} {i}")
        sys.stdout.flush()
        g = int(input())
        if g == 0:
            candidate = i
    print(f"! {candidate} {candidate}")
    sys.stdout.flush()
    verdict = int(input())
    if verdict == -1:
        sys.exit()

t = int(input())
for _ in range(t):
    n = int(input())
    find_zero(n)
```このソリューションは、最初のインデックスを候補として扱い、それを後続のすべてのインデックスと照合することで機能します。 GCD の場合`0`の場合は候補者を置き換えますが、そうでない場合は候補者を保持します。 最後に、同じインデックスを 2 回出力します。必要なのは の位置が 1 つだけであるためです。`0`。 私たちは直ちに判決を読み、プログラムがインタラクティブなフィードバックを適切に処理していることを確認しました。
