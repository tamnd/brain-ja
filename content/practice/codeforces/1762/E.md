 ## 解決策
 ## 問題の理解

 1 から 1 までの番号が付けられた頂点を持つエッジ加重ツリーを考慮するように求められます。$n$、各エッジには重みがあります。$1$または$-1$。 すべての頂点について、その頂点に付随するすべてのエッジの重みの積が以下に等しい場合、ツリーは良好であると呼ばれます。$-1$。 与えられた課題は、$n$、頂点からエッジに沿った距離の合計を計算します。$1$頂点へ$n$すべての良い木の上でモジュロ$998{,}244{,}353$。 

入力は単一の整数です$n$、出力は単一の整数であり、この合計のモジュロを表します。$998{,}244{,}353$。 

制約$1 \le n \le 5 \cdot 10^5$すべてのツリーを明示的に生成することは即座に除外されます。$n^{n-2} \cdot 2^{n-1}$合計エッジ加重ツリー。 たとえ$n = 10^3$、その数は天文学的に多くなります。 したがって、どのような解決策でも、総当たりの列挙ではなく、組み合わせ推論または代数推論を使用する必要があります。 

明らかではないエッジケースとしては、以下のものがあります。$n = 1$、ここで唯一の木にはエッジがないため、合計はゼロになります。 別の微妙な問題が発生する場合、$n = 2$、一意のエッジには重みがなければなりません$-1$の合計を与える$-1$モジュロ$998{,}244{,}353$。 ツリーを生成しようとする素朴な試みは、スケーリングに失敗したり、「良好なツリー」条件を正しく適用したりすることができません。 

## アプローチ

 ブルートフォースアプローチでは、すべてを列挙しようとします。$n^{n-2}$木々もすべても$2^{n-1}$エッジの重みの割り当て、各頂点の「良好な」状態をチェックし、合計$d(1,n)$通り過ぎる人のために。 このアプローチは明らかに実行不可能です。$n=20$おおよそ生成します$20^{18} \cdot 2^{19} \approx 10^{26}$可能性。 

重要な洞察は、ツリーを生成する必要がまったくないということです。 プリューファー配列からのよく知られた組み合わせ結果は、次のことを示しています。$n^{n-2}$ラベルが貼られた木。 各頂点の入射積が次の値になるようにエッジに重みを割り当てる$-1$頂点ごとに線形制約を 1 つだけ導入します。 これにより、単純なパリティ観察が得られます。$n = 1$、答えはゼロです。 のために$n \ge 2$、ちょうど 1 つのエッジにウェイトが必要になります$-1$1からへの道に沿って$n$、残りは独立して配置できます。 モジュラー算術および組み合わせ公式を使用してこれらの可能性を数えると、次の結果が得られます。$O(1)$べき乗に関する公式$2$そして$-1$。

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る$n$入力から。 
2. 係数を定義する$MOD = 998244353$大きな数を扱うため。 
3. もし$n = 1$、エッジがないため、0 を出力して戻ります。 
4. それ以外の場合は計算します$-1$モジュロ$MOD$として$MOD - 1$。 これは、1 から までのパスに沿った唯一のエッジを占めます。$n$貢献しなければならないこと$-1$すべての良い木々に。 
5. コンピューティング$2^{n-2} \mod MOD$。 これは、「良好なツリー」特性に違反することなく、残りのエッジの重みを独立して割り当てる方法の数を表します。 
6. ステップ 4 の値とステップ 5 の値を乗算し、剰余を求めます。$MOD$最終的な答えを得るために。 
7. 結果を印刷します。 

それが機能する理由: すべての良好なツリーは、1 から$n$まさに$-1$他のすべての独立した重み割り当てを乗算します。 独立した割り当ての数は次のとおりです。$2^{n-2}$。 この不変式はどんな場合にも当てはまります$n \ge 2$、正確性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input().strip())
    if n == 1:
        print(0)
        return
    # The only edge along 1->n must be -1
    ans = (MOD - 1) * pow(2, n - 2, MOD) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```解決策は次のようになります$n$安全に使って`.strip()`、エッジケースを処理します$n = 1$、そして使用します`pow`効率的なべき乗剰余演算を行うための 3 つの引数を使用し、オーバーフローを回避します。 

## 実用的な例

 のために$n = 2$:

 これらの表は、この式がパス 1→n の寄与を保証しながらエッジ割り当ての多重度を捉えていることを示しています。$-1$。

 主なエッジケースは次のとおりです。$n = 1$そして小さい$n$のような値$2$そして$3$。 のために$n = 1$、エッジがないため、合計はゼロになります。 のために$n = 2$、エッジのみに重みがあります$-1$アルゴリズムは、条件チェックとモジュラー演算によってこれらを正しく処理します。 この式は、大規模な場合にも自然に拡張されます。$n$独立したエッジ重み割り当ての乗算特性により、明示的な列挙が回避されます。
