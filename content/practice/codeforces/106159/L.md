 ## 解決策
 ## 問題の理解

 高さの階段状ピラミッドを構築するために必要なダイヤモンド ブロックの数を計算するように求められます。$N$。 構造は階層化されています: レベル$i$(上から1から)一辺の長さが次の正方形です。$2i+1$、つまり、これには次の内容が含まれます。$(2i+1)^2$ブロック。 したがって、ブロックの総数は、レベル 1 からレベルまでの奇数辺の長さの 2 乗の合計になります。$N$、答えはモジュロで与えられる必要があります$10^9 + 7$。 

入力は単一の整数です$N$、次のように大きくすることができます$10^{18}$。 これにより、レベル間で反復するアプローチは即座に除外されます。 たとえ$O(N)$まで必要になるため、解決策は不可能です$10^{18}$操作。 合計を閉じた形式の式または非常に少数の算術演算に圧縮する必要があります。 

計算しようとすると、オーバーフロー処理に微妙な問題が発生します。$(2i+1)^2$モジュールケアなしで繰り返し使用できます。 中間値は次のように二次関数的に増加するため、$i$、 そして$i$それ自体は最大です$10^{18}$, 64 ビット算術における単純な乗算は、合計する前からすでに安全ではありません。 

エッジケースは構造的には最小限ですが、数値的には重要です。 いつ$N=1$、答えは簡単です。$3^2 = 9$。 ここでは単純なループはパフォーマンスの問題ではありませんが、健全性チェックとして機能します。 上限で$N=10^{18}$、式に基づいた解決策のみが実行可能です。 

## アプローチ

 問題を直接解釈すると、各レベルを繰り返して合計することを提案します。$(2i+1)^2$。 This is correct because it follows the definition literally. Expanding this expression gives$4i^2 + 4i + 1$したがって、合計は次のようになります。$$\sum_{i=1}^{N} (4i^2 + 4i + 1)
= 4\sum i^2 + 4\sum i + \sum 1$$この変換は、簡素化の重要なステップです。 二次式をレベルごとに合計する代わりに、問題を既知の合計に還元します。$$\sum_{i=1}^{N} i = \frac{N(N+1)}{2}, \quad \sum_{i=1}^{N} i^2 = \frac{N(N+1)(2N+1)}{6}$$これらを式に代入すると、定数時間で計算可能な閉じた形式が得られます。 ボトルネックはもはや反復ではなく、大きな中間値を伴うモジュラー演算であるため、以下の 2 と 6 のモジュラー逆数に依存します。$10^9 + 7$。 

ブルートフォース手法は次のような理由で失敗します。$N$繰り返し、それぞれが平方を計算して加算することで、$O(N)$時間。 で$N = 10^{18}$、これは不可能です。 最適化された方法では、代数恒等式を使用して合計を定数時間演算に分解します。

 ## アルゴリズムのチュートリアル

 まず、ブロックの総数を書き換えます。$$\sum_{i=1}^{N} (2i+1)^2$$正方形を拡張すると多項式が得られます。$i$これにより、標準の合計数式を使用できるようになります。 

### ステップ

 1. 各用語を展開する$(2i+1)^2$の中へ$4i^2 + 4i + 1$。 

このステップでは、幾何学的構造を独立して合計できる代数コンポーネントに変換します。 
2. 合計を 3 つの別々の合計に分割します。$$4\sum i^2 + 4\sum i + \sum 1$$加算が線形であるため、この分離は機能します。 
3. 各合計を既知の式に置き換えます。$$\sum i = \frac{N(N+1)}{2}, \quad \sum i^2 = \frac{N(N+1)(2N+1)}{6}, \quad \sum 1 = N$$4. すべてをモジュロで 1 つの式に結合します。$$4 \cdot \frac{N(N+1)(2N+1)}{6} + 4 \cdot \frac{N(N+1)}{2} + N$$5. 以下の 2 と 6 の逆モジュラーを計算します。$10^9 + 7$、オーバーフローを避けるために剰余乗算を使用して式を慎重に評価します。 

重要な実装の詳細は、中間値を剰余的に減らすことです。$10^9 + 7$次のような大きな整数の直接乗算なので、すべての乗算ステップで$10^{18}$言語によっては 128 ビット算術でもオーバーフローする可能性があるため、不要です。 

### なぜ効果があるのか

 正しさは、元の和のすべての項が次の二次多項式であるという事実に依存します。$i$。 連続範囲にわたる多項式の合計は、べき乗和の公式を使用して正確に表現できます。 式全体を次のように書き換えるので、$\sum i^2$、$\sum i$、 そして$\sum 1$、これらはすべての整数の正確な恒等式です。$N$の場合、変換では等価性が維持されます。 すべての演算は素数法で定義された体で実行され、2 と 6 による除算は逆剰余を介して有効であるため、モジュラー算術ステップの正確性は変わりません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

inv2 = modinv(2)
inv6 = modinv(6)

def solve():
    N = int(input().strip())

    n = N % MOD

    sum_i = n * (n + 1) % MOD * inv2 % MOD
    sum_i2 = n * (n + 1) % MOD * (2 * n + 1) % MOD * inv6 % MOD

    # 4 * sum_i2 + 4 * sum_i + N
    ans = (4 * sum_i2) % MOD
    ans = (ans + 4 * sum_i) % MOD
    ans = (ans + n) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```これらの定数による除算が両方の合計式に現れるため、このソリューションでは 2 と 6 の逆剰余を 1 回計算します。 入力$N$剰余を減算したもの$10^9 + 7$すべての代数式は多項式であるため、早い段階で$N$、初期値を減らすと、中間の乗算でのオーバーフローを防ぎながら正確性が維持されます。 

モジュラーリダクションを複雑にする用語の混合を避けるために、各合計は独立して計算されます。 最終的な式は派生した式を直接反映するため、実装ミスのリスクが低くなります。

 ## 特殊なケース

 のために$N=1$、アルゴリズムは次のように計算します。$n=1$、次に両方の合計を直接評価します。 中間値は次のとおりです。$$\sum i = 1, \quad \sum i^2 = 1$$最終的な結果は次のようになります$4 + 4 + 1 = 9$、単層タワーと一致します。 

非常に大きい場合$N$、 のような$10^{18}$、アルゴリズムが反復されることはありません。 減少します$N$モジュロ$10^9+7$そして、乗算と逆算の固定シーケンスを実行します。 元の値が巨大であっても、式の多項式の性質により、評価前のモジュラー換算により有限体で正しい結果が生成されることが保証されます。 

次のような中間値の場合$N=2$、すべての合計が包含範囲で定義されているため、アルゴリズムはオフバイワンエラーなしで両方の層からの寄与を正しく結合します。$[1, N]$、これは、1 から始まる問題のレベルのインデックス付けと一致します。
