 ## 解決策
 ## 問題の理解

 各頂点が正の重みを持つツリーが与えられます。 タスクは、選択した重みの合計を最大化する頂点のサブセットを選択することですが、厳密な幾何学的制限があります。選択した 2 つの頂点は、次の値を超える必要があります。$k$木の端が離れています。 

同様に、頂点を選択すると、その距離内の頂点の選択を「禁止」します。$k$それから。 目標は、選択した頂点をツリー上に配置し、それらのペアごとの距離がすべて厳密に より大きくなるようにすることです。$k$総重量を最大化しながら。 

制約$n \le 200$は十分に小さいので、ノード上の状態に対する二次または三次動的計画法が実行可能です。 ただし、単純なサブセット列挙はまだ不可能です。$2^n$たとえ実現可能性をはるかに超えて成長する$n = 200$。 これにより、ツリーを超えた構造化された DP が実現します。 

微妙な点は、制限がエッジに局所的なものではなく、ツリー内の距離を超えて伝播することです。 これにより、この問題は、ツリー上の古典的な独立集合 (これは、$k=1$）。 ここで、選択したノードの「除外ゾーン」は半径です。$k$木の中にボール。 

重みの高いノードがクラスタ化されている場合、エッジ ケースが発生します。 たとえば、チェーンを考えてみましょう$1-2-3-4$と$k=2$。 ノード 1 を選択するとノード 2 と 3 は禁止されますが、ノード 4 は引き続き有効です。 極大値の貪欲な選択は失敗する可能性があります。一部の重み設定では、2 と 4 を選択すると 1 だけを選択するよりも大きな重みが与えられますが、2 を選択すると 1 と 3 も禁止され、非局所的な方法で下流の実現可能性が変化します。 

もう 1 つのエッジケースは次のような場合です$k=0$。 この場合、制限は存在せず、すべてのノードを選択できます。 常に親子の除外を強制する単純な DP では、誤って過小カウントされてしまいます。 

最後に、いつ$k$大きい（近い）$n$)、2 つのノードさえも選択することは、それらが非常に遠く離れていない限り不可能であるため、最適な答えは最大の単一頂点に縮退することがよくあります。 正しいソリューションでは、この移行をスムーズに処理する必要があります。 

## アプローチ

 ブルートフォースのアイデアは、頂点のすべてのサブセットを試し、すべてのペアごとの距離を計算することで妥当性をチェックすることです。 各ノードからの距離が BFS を使用して事前計算されていても、サブセットのチェックには依然としてコストがかかります$O(n^2)$、およびサブセットのコストを列挙する$2^n$、おおよそにつながります$O(2^n \cdot n^2)$、それは不可能です。 

重要な観察は、制約が木の距離という意味で局所的であるということです。 ノードを選択したとおりに固定すると、その禁止領域は距離によって境界が定められたサブツリー状の近傍になります。$k$。 これは、状態がツリー上の選択されたノードにどれだけ「近い」かを記憶する必要がある DP を示唆しています。 

標準的な方法は、ツリーをルート化し、ノードごとに、選択した最も近い祖先からの距離を追跡する DP を定義することです。 ただし、選択したすべてのノードまでの正確な距離を保存すると大きすぎます。 代わりに、これを有界パラメータ、つまり現在のノードから処理されたサブツリー内で最も近い選択されたノードまでの距離に圧縮します。 

これにより、各状態がノードが選択されているかどうか、およびそのサブツリーまたは祖先内で最も近い選択されたノードがどのくらい離れているかを表すノード上の DP が得られます。$k$。 以来$k \le 200$、次のサイズの DP テーブルを維持できます。$O(nk)$ノードごとに、ツリーのナップザックのような遷移を介して子を結合します。 

マージのステップはマルチステートの伝播に似ています。ノードを処理するとき、それが選択されているかどうかを考慮し、選択されている場合は、距離内のすべてのノードを考慮します。$k$サブツリー内の を選択することはできません。 これが選択されていない場合、子供たちは更新された距離状態を独自に提供できます。 

これにより、グローバルな距離制約がルート付きツリー上のローカルな遷移に変換されます。

 ## アルゴリズムのチュートリアル

 ツリーをノード 1 にルートし、各ノードの DP テーブルを定義します。$u$。 

させて$dp_u[d]$のサブツリー内の最大重みを表します$u$サブツリーの上または内側で選択された最も近いノードが距離にあるという条件の下で$d$、 どこ$d$上限は$k$。 値$d=0$手段$u$が選択され、値が大きいほど、最も近い選択されたノードまでの距離が増加することを表します。 

私たちはボトムアップで情報を広めます。 

1. 各ノードの初期化$u$すべての状態が負の無限大に設定される DP 配列を使用します。ただし、次の場合を除きます。$u$が選択されます。 もし$u$選ばれると貢献する$a_u$そしてすべての子は、距離内にノードがないことを尊重しなければなりません$k$相反する方法で選択することができます。 
2. 子を 1 つずつ処理し、その DP テーブルを現在のノードの DP テーブルにマージします。 マージ操作では、現在の DP と子 DP の状態のすべてのペアが考慮され、上に移動するときに距離値を 1 ずつ増やすことで距離が適切に更新されます。 
3. 子状態が遠くにある選択されたノードを示している場合$d$、親の観点からすると、そのノードは遠くにあります$d+1$、上限は$k$。 1 つのエッジを上に移動すると距離がちょうど 1 だけ増加するため、このシフトは非常に重要です。 
4. マージ中に、選択した 2 つのノードが離れてしまう組み合わせを破棄することで、実現可能性を確保します。$\le k$。 これは、DP テーブルを結合するときに距離のしきい値に違反する状態を禁止することによって暗黙的に強制されます。 
5. すべての子を処理した後、最終処理を行います。$dp_u$両方のケースを考慮すると、次のようになります。$u$選択されているかどうかを判断し、結果を上方に伝播します。 

最終的に、答えはルート ノードのすべての状態の最大値になります。
