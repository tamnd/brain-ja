 ## 解決策
 ## 問題の理解

 同じ長さの 2 つの配列が与えられています。`a`そして`b`。 特別な交換操作を実行できます。任意の 2 つの位置を選択します。`i`そして`j`、同時に交換します`a[i]`と`a[j]`そして`b[i]`と`b[j]`。 目標は、これらの移動を最大 10,000 回使用して、両方の配列を非降順に並べ替えることです。 これを達成する一連の動きを生み出すか、それは不可能であると報告するかのどちらかでなければなりません。 

入力では複数のテスト ケースを指定します。 各テスト ケースでは、配列の長さと配列の要素が示されます。 出力は次のいずれかを行う必要があります。`-1`シーケンスが存在しない場合、または最初に手の数、その後に手のペア自体が続きます。 

制約を考慮すると、`n`最大 100 まで指定でき、10,000 回の移動が許可されます。 これは寛大です。順序が乱れた各要素に対してバブルソートのようなスワップを実行する単純なアルゴリズムは、最大 O(n²) スワップを実行できます。これは、n = 100 のとき n² = 10,000 であるため、最大でも 10,000 回です。したがって、二次時間アルゴリズムが実行可能です。 それぞれの要素が入っています`[1, n]`これにより、大きな整数のオーバーフローを心配せずに単純な比較が可能になります。 

主なエッジ ケースは、各配列が個別に並べ替え可能であっても、同時に並べ替えることができない配列です。 例えば、`a = [2, 1]`そして`b = [1, 2]`任意の数の同時スワップを使用してソートすることはできません。`a`壊れるだろう`b`。 もう 1 つの特殊なケースは、すでにソートされている配列です。 ソリューションはゼロ手を出力する必要があります。 値が繰り返される配列は、同じ数値が複数出現してもソートを妨げないため、有効です。 

## アプローチ

 ブルートフォースアプローチは、アレイを繰り返しスキャンし、任意のペアを交換することです。`(i, j)`どちらかの配列が正しくない場合。 これが機能するのは、スワップごとに少なくとも 1 つの反転が減少するためです。 長さの 2 つの配列の場合`n`、各配列には最大で O(n²) 個の反転が存在するため、最悪の場合、スワップの数は O(n²) になります。 以来`n ≤ 100`、これにより最大 10,000 のスワップが生成されますが、これは許可されます。 ただし、一方の配列が左にスワップしたいのにもう一方の配列が右にスワップしたいなど、配列の順序が矛盾している場合、ブルート フォース アプローチは失敗する可能性があります。 このような場合、両方の配列を同時にソートすることは不可能になります。 

重要な点は、単純なペアごとのバブル ソート アプローチを使用してソートできることですが、最初の配列の不変条件を維持する必要があることです。`a`そして2番目の配列`b`どちらも各移動後に減少しません。 これを確実にするために、次の場合にのみスワップします。`a[i] > a[j]`または`b[i] > b[j]`同時に。 いずれかの時点で、一方の配列の反転をもう一方の配列と整列させることができない場合、不可能であることが検出されます。 残りの最小要素を体系的に正しい位置にプッシュし（選択ソートなど）、同時に入れ替えることによって`b`、両方の配列を並べ替えるか、競合を検出できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースバブルのような | テスト ケースあたり O(n²) | O(n) | 承認済み (10⁴ 手以内) |
 | 最適な選択ソートのバリアント | テスト ケースあたり O(n²) | O(n² 移動) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`、配列`a`そして`b`。 
3. 空の動きのリストを初期化します。 
4. ポジションごとに`i`から`0`に`n-1`、最小のものを見つけます`j ≥ i`両方とも`a[j]`そして`b[j]`所定の位置に配置できます`i`前の要素に対する非減少順序に違反することなく。 そうでない場合`j`存在する、出力`-1`それは不可能だからです。 
5. もし`j ≠ i`、交換`a[i]`と`a[j]`そして`b[i]`と`b[j]`、移動を記録します`(i+1, j+1)`1 から始まるインデックスを使用します。 
6. アレイの終わりまでこのプロセスを続けます。 すべての繰り返しの後、`a`そして`b`並べ替える必要があります。 
7. 移動回数と移動順序を出力します。 

機能する理由: アルゴリズムは、位置の前の要素という不変式を維持します。`i`両方の配列でソートされます。 各スワップは、以前の順序に違反することなく、要素を両方の配列内の正しい位置に移動します。 いずれかの時点で適切な要素を所定の位置に移動できない場合`i`、配列は競合状態にあり、同時に並べ替えることはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        moves = []
        possible = True
        for i in range(n):
            for j in range(i+1, n):
                if a[i] > a[j] or b[i] > b[j]:
                    a[i], a[j] = a[j], a[i]
                    b[i], b[j] = b[j], b[i]
                    moves.append((i+1, j+1))
        if a != sorted(a) or b != sorted(b):
            print(-1)
        else:
            print(len(moves))
            for x, y in moves:
                print(x, y)

if __name__ == "__main__":
    solve()
```外側のループは各位置を反復して、残りの最小要素が正しく配置されるようにします。 内側のループは、必要な場合にのみスワップを実行します。 問題文の要求に応じて、1 から始まるインデックスの移動を追加します。 すべてのスワップの後、配列はソートされたバージョンに対してチェックされ、不可能性が検出されます。

## 特殊なケース

 重複した値を含む配列。`a = [2,2]`そして`b = [1,1]`、スワップは必要ありません。 アルゴリズムは正しく出力します`0`。 配列の順序が矛盾している場合、次のようになります。`a=[2,1]`そして`b=[1,2]`、アルゴリズムはスワップを実行します`i=0,j=1`、配列をチェックし、不可能であることを特定します。 すでにソートされた配列の場合、移動は記録されません。 アルゴリズムは最小サイズの配列の正確さを維持します`n=2`そして最大の`n=100`。
