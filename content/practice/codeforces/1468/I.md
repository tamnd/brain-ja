 ## 解決策
 ## 問題の理解

 のセットを構築するように求められます。$n$整数点$(x_i, y_i)$すべての整数が点になるように$(x, y)$平面内の は、これらの選択された点の 1 つと 2 つの固定方向ベクトルの整数の組み合わせを使用して、正確に 1 つの方法で書き込むことができます。 

具体的には、選択された各点は、2 つのベクトルによって生成された完全な無限グリッドの「代表」として機能します。$(dx_1, dy_1)$そして$(dx_2, dy_2)$。 基点から$(x_i, y_i)$、フォームのすべての点に到達できます$$(x_i, y_i) + a(dx_1, dy_1) + b(dx_2, dy_2)$$どこ$a, b$は任意の整数です。 

要件は、これらのシフトされた格子が整数グリッド全体を分割する必要があることです。$\mathbb{Z}^2$。 すべての整数点は、そのような格子の 1 つに属している必要があります。これは、2 つの異なるトリプルを意味します。$(a, b, i)$決して同じポイントを生成してはならず、ポイントを逃してはなりません。 

入力サイズ$n \le 10^5$これは、グローバル構造を明示的にシミュレートできないことを意味します。 どのようなソリューションでも、線形時間で直接代表を構築する必要があります。 座標は最大まで上がるので、$10^9$、大きな有限パターン上に自由に点を配置できます。 

単純な試みとしては、貪欲に点を割り当て、格子生成をシミュレートすることで重複をチェックしてみることです。 各格子は無限であり、単一点のメンバーシップを確認するだけでも 2D 線形システムを解く必要があるため、この方法はすぐに失敗します。 

2 番目の単純なアイデアは、代表者の小さなグリッドを生成し、周期性を仮定することです。 これは、2 つのベクトルによって生成された格子に正確なインデックスがある場合にのみ機能します。$n$, しかし、その仮定は自動的に満たされるわけではありません。 

2 つのベクトルが同一線上にある場合、微妙なエッジ ケースが発生します。 その場合、完全な平面ではなく線のみが生成されるため、$\mathbb{Z}^2$しないと不可能になる$n = 0$、これは制約の外側です。 もう 1 つの失敗ケースは、2D 格子の行列式が 0 の場合です。これにより、構造が崩壊し、一意の座標表現が妨げられます。 

## アプローチ

 中心的な観察は、2 つのベクトルが次の格子を定義するということです。$\mathbb{Z}^2$。 単一の基点を配置すると、そこから到達可能なすべての点がこの格子の 1 つの剰余類を形成します。 平面全体がこの格子の剰余類に分割されます。 個別の剰余類の数は、次の格子のインデックスと等しくなります。$\mathbb{Z}^2$、これは絶対行列式によって決まります。$$D = |dx_1 \cdot dy_2 - dx_2 \cdot dy_1|$$もし$D = 0$、ベクトルは線形依存しており、完全な 2D 格子にまたがりません。 平面に埋め込まれた 1D サブグループしか取得できないため、平面をカバーしようとする試みは失敗します。$\mathbb{Z}^2$したがって、一意に割り当てることはできません$(a, b)$すべての点の座標。 したがって、不可能なカバーに堕落しない限り、解決策は存在しません。 

もし$D \ne 0$、格子には有限のインデックスがあります$D$。 つまり、飛行機は正確に次のように分割されます。$D$この格子を法とする等価クラス。 各クラスは単一の点で表すことができます。 したがって、有効な代表者の最大数は正確に$D$、そして選択する必要があります$n$彼らのうち。 これにより条件が強制されます$n \le D$。 

一度$n \le D$、基本的な平行四辺形内のすべての剰余クラスをスキャンすることにより、明示的に代表を構築できます。 標準的なトリックは、格子基底を法として座標を解くことです。 すべてのペアを列挙できます$(a, b)$境界領域内でそれらを個別の残基にマッピングし、最初の残基を選択します$n$。 

より直接的な構築的なアプローチでは、線形代数を完全に回避します。基底ベクトルと一致する座標のグリッドとして代表を構築します。 各整数点$(x, y)$次のように一意に書くことができます$$(x, y) = (x_0, y_0) + a(dx_1, dy_1) + b(dx_2, dy_2)$$どこ$(x_0, y_0)$基本的な平行四辺形の中にあります。 私たちが選ぶ$n$このようなベースは、一意性を保証する境界ボックスの内側を直接指します。 

重要な洞察は、格子構造が無限平面問題を 2D 基底を法とする剰余の有限分類問題に還元するということです。

 ## アルゴリズムのチュートリアル

 1. 行列式を計算する$D = dx_1 \cdot dy_2 - dx_2 \cdot dy_1$。 もし$D = 0$、すぐにNOを出力します。 これは、ベクトルが 2D グリッドにまたがることができないため、平面の一意の分解が不可能であるためです。 
2. もし$D \ne 0$、構築を進めます。 2 つのベクトル分割によって生成された格子がわかっています。$\mathbb{Z}^2$の中へ$D$異なる残基クラス。 
3. 私たちは次のことを保証しなければなりません$n \le D$。 もし$n > D$、一意性を侵害せずに利用可能な剰余類より多くの代表を選択できないため、NO を出力します。 
4. 与えられたベクトルを使用して暗黙的に格子の基底を構築します。 明示的な反転は必要ありません。 代わりに、すべての残基を表す有界四角形内に点を生成します。 
5. 整数ペアを列挙する$(i, j)$のような範囲にわたって$i \in [0, |dy_2|)$、$j \in [0, |dy_1|)$またはすべての残基をカバーするのに十分な大きさの対称境界ボックス。 各候補点について、線形システム解釈を使用して格子を法とする同値クラスを計算します。 
6. クラスが収集されるまで、クラスが使用されていないポイントを選択し続けます。$n$代表者。 
7. これらの点を出力します。 選択された各点は格子の個別の剰余類に対応し、表現の一意性が保証されます。 

### なぜ効果があるのか

 ベクトル$(dx_1, dy_1)$そして$(dx_2, dy_2)$行列式がゼロ以外の場合、フルランク格子を定義します。 すべてのポイント$\mathbb{Z}^2$は、この格子のちょうど 1 つの剰余類に属します。 剰余類ごとに 1 つの代表を選択すると、すべての整数点を基点と 2 つのベクトルの整数の組み合わせとして一意に書き込むことができます。 この構造により、同じ剰余類から 2 つの点を決して選択しないことが保証され、一意性が維持されます。また、正確に選択されるため、$n$有効な剰余類であれば、必要なタイル数のカバレッジが完了します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    dx1, dy1 = map(int, input().split())
    dx2, dy2 = map(int, input().split())

    det = dx1 * dy2 - dx2 * dy1

    if det == 0:
        print("NO")
        return

    # We construct points in a simple structured way:
    # use a rectangular grid and take first n valid distinct coset representatives.
    used = set()
    res = []

    # brute enumeration in a bounded box large enough to generate distinct residues
    LIM = 300  # sufficient for typical constraints since n <= 1e5 and det != 0 ensures many residues

    for x in range(-LIM, LIM + 1):
        if len(res) == n:
            break
        for y in range(-LIM, LIM + 1):
            if len(res) == n:
                break

            # represent point; its coset is determined by solving linear system implicitly
            # we normalize by projecting onto lattice basis using determinant
            # Cramer's rule coordinates (a, b)
            a_num = x * dy2 - y * dx2
            b_num = y * dx1 - x * dy1

            if a_num % det != 0 or b_num % det != 0:
                continue

            a = a_num // det
            b = b_num // det

            key = (a, b)
            if key in used:
                continue

            used.add(key)
            res.append((x, y))

    if len(res) < n:
        print("NO")
    else:
        print("YES")
        for x, y in res:
            print(x, y)

if __name__ == "__main__":
    solve()
```行列式チェックは、縮退したベクトルのペアを除去する最初の構造フィルターです。 フルランクがなければ、飛行機のタイリングは存在しません。 

列挙ループは、対称の境界領域内に候補の代表を構築します。 Cramer の法則を使用した変換により格子座標が計算されます$(a, b)$、各点の剰余類を一意に識別します。 これにより、商空間を明示的に構築することが回避されます。 

セット`used`これにより、剰余類ごとに最大でも 1 つの代表が選択され、分割の正確さが保証されます。

 ## 特殊なケース

 たとえば、2 つのベクトルが同一線上にある場合、$(1,2)$そして$(2,4)$、行列式はゼロになります。 アルゴリズムは入力を即座に拒否します。 これは正しいです。生成されたすべての点は単一の無限の直線上にあるため、平面の分割は存在しません。 

ベクトルが次のような有効な基礎を形成するとき$(1,0)$そして$(0,1)$、すべての整数点はすでに次のように一意に表現可能です。$a, b$, したがって、単位正方形ごとに剰余類は 1 つだけ存在します。 構造は正確に選択します$n$競合することなくグリッド ポイントを取得し、Cramer ルール チェックによって各ポイントを一意の残基に分類し、重複が選択されないようにします。 

次のようにベクトルが歪んでいる場合$(1,1)$そして$(1,-1)$、格子が回転されます。 行列式は非ゼロのままであるため、軸が揃っていない場合でも、列挙では個別の剰余類の代表が見つかります。 射影式は、この回転基底で同値クラスを正確に識別し、代表者の一貫した選択を保証します。
