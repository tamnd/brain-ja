 ## 解決策
 ## 問題の理解

 整数の複数のコレクションが与えられ、各コレクションはセットとみなされます。 少なくとも 2 つの共通の数値がある場合、2 つのセットは類似しているとみなされます。 目標は、類似したセットのペアを見つけるか、存在しないことを報告することです。 各セットは個別の整数のリストとして記述され、1 つの入力で複数のテスト ケースが与えられます。 

入力の制約が厳しいです。 1 つのテスト ケースには最大 100,000 のセットを含めることができ、各セットには最大 100,000 の整数を含めることができます。 ただし、すべてのテスト ケースにわたるすべての整数の合計は 200,000 によって制限されます。 この制限は、セットのすべてのペアを直接比較するという単純なアプローチを妨げるため、非常に重要です。 単純な比較には、セットのすべてのペアをチェックすることが含まれます。$10^{10}$最悪の場合の操作は、1 秒の制限時間には遅すぎます。 重要なのは、セットはたくさんありますが、要素の総数は比較的少ないということです。 

エッジ ケースは、すべてのセットが小さい場合、または各セットに完全に固有の要素がある場合に発生します。 たとえば、2 つのセットが 1 つの要素のみを共有する場合、それらは類似していません。2 つの要素の要件を検証せずに交差サイズのみをカウントする不注意なアプローチは、誤検知を報告します。 同様に、2 つのセットが同一である場合、それらは自明のことながら類似しており、ソリューションはそれを即座に検出する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、セットのすべてのペアを反復処理し、それらが共有する要素の数を確認します。 各ペアに対して交差集合を使用することもできますが、すべてのペアに対して交差を繰り返し計算するのはコストがかかります。 もし持っていれば$n$セットと各セットの平均は$k$要素の総当たりの複雑さは次のとおりです。$O(n^2 \cdot k)$、これは不可能です$n$要素の合計がバインドされている場合でも、最大 100,000 個になります。 

最適なアプローチにつながる重要な観察は、数値は限られた回数を超えて出現しないということです。 数値が多くのセットに出現する場合、それがハブとして機能し、類似する可能性のあるセットを迅速に特定できます。 数値が 1 つのセットにのみ出現する場合、その数値は類似性に寄与することはできません。 セット内の要素のペアに焦点を当てることで、どのセットにどの要素のペアが含まれているかを保存できます。 数値のペアが 2 つのセットに一緒に出現する場合、それらのセットは類似しています。 

私たちは問題を、数値のすべてのペアをそれらが出現するセットにマッピングすることに帰着します。 要素の総数は 200,000 で制限されており、各セットには最大で 200,000 個の要素が含まれるためです。$k_i$要素を使用すると、すべてのセットにわたる一意のペアの合計数を管理できます。 これを要素の総数に対して線形時間で処理し、総当たりアプローチの二次爆発を回避できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2 * k) | O(n * k) | 遅すぎる |
 | 最適 | O(要素の合計 + ペアの合計) | O(合計ペア) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 各テスト ケースについて、セットの数を読み取り、各セットを整数のリストとして読み取ります。 すべてのセットをリストに保存します。 
2. 必要に応じて、各一意の整数をより小さい ID にマッピングして要素を正規化します。 これにより、整数のサイズが辞書操作に影響を与えることがなくなります。 
3. セットごとに、要素のすべてのペアを生成します。 各ペアについて、ペアからそれが出現するセットのインデックスへのマッピングを維持します。 ペアがすでにマッピングに存在する場合、このペアを共有する 2 つのセットが見つかりました。 これら 2 つのセットのインデックスをすぐに出力します。 
4. 複数のセットにペアが出現しない場合、このテスト ケースでは -1 を出力します。 

重要な不変条件は、2 つのセットが少なくとも 2 つの要素を共有する場合、これらの共有要素の少なくとも 1 つのペアが両方のセットに現れるということです。 個々の要素ではなくペアを保存することにより、類似したセットが検出されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        sets = []
        elements = {}
        idx = 0
        for _ in range(n):
            line = list(map(int, input().split()))
            k = line[0]
            s = line[1:]
            sets.append(s)
            for num in s:
                if num not in elements:
                    elements[num] = idx
                    idx += 1

        # map numbers to compressed IDs
        compressed_sets = [[elements[x] for x in s] for s in sets]

        pair_map = {}
        found = False
        for i, s in enumerate(compressed_sets):
            s_sorted = sorted(s)
            for j in range(len(s_sorted)):
                for k in range(j + 1, len(s_sorted)):
                    pair = (s_sorted[j], s_sorted[k])
                    if pair in pair_map:
                        print(pair_map[pair] + 1, i + 1)
                        found = True
                        break
                    pair_map[pair] = i
                if found:
                    break
            if found:
                break
        if not found:
            print(-1)

if __name__ == "__main__":
    main()
```このコードは、効率を高めるためにすべての整数をより小さい ID に圧縮し、各セットを反復してすべてのペアを生成します。 ペアがすでに辞書に存在する場合は、対応するインデックスをすぐに出力します。 これにより、解が見つかった後にアルゴリズムが不要なペアをチェックするのを防ぎます。
