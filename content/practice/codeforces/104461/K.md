 ## 解決策
 ## 問題の理解

 平面内に 3 つの固定点が与えられます。 各点は円自体を直接拘束するのではなく、その点が未知の円の境界からどのくらい離れているかを示します。 この距離の符号は重要です。値がゼロの場合、点は円上に正確に存在します。 それが正の場合、点は内側にあり、境界はそれだけ遠くにあります。 負の場合、点は外側にあり、境界はそれだけ近くなります。 

この間接的な情報から、タスクは 3 つの制約と一致するすべての円を復元し、そのような円がいくつ存在するか、およびそれらの中で可能な最小半径はいくらかを報告することです。 すべての制約を同時に満たす円がない場合、答えはゼロになります。 制約によって円の有限セットが特定されない場合、答えは無限になります。 

明らかではない部分は、各ポイントが単純な「通過しなければならない」条件を定義していないことです。 代わりに、各点は未知の中心と未知の半径の間の関係を定義し、点が円の内側にあるか外側にあるかに応じてシフトする方法でそれらを結合します。 これにより、ジオメトリは標準の外接円の再構築よりも大幅に剛性が高くなります。 

座標に関する制約は小さいですが、テスト ケースの数は非常に多く、最大 20 万件です。 これにより、中心を数値的に検索したり、テスト ケースごとに反復的な幾何学的最適化を実行したりするアプローチは直ちに除外されます。 実行可能なソリューションでは、各テスト ケースを定数時間の代数計算に減らす必要があります。 

制約が一貫しているものの、一意の円が決定されない場合、微妙なエッジ ケースが発生します。 このような場合、通常は 3 つの条件がより少数の独立した幾何方程式に崩壊する場合、有効な円が無限に存在する可能性があります。 別の故障モードは、代数操作によって、導出方程式は満たすが元の幾何学的制約は満たさない無関係な解が導入された場合、特に距離式を二乗する場合に発生します。 

## アプローチ

 直接的な試みは、問題を円の中心と半径の検索として扱うことです。 各候補中心について、半径は 1 点だけ強制され、他の 2 点との一貫性を確認できます。 これはすぐに 2 次元平面にわたる連続検索になり、たとえ離散化したとしても非常に遅すぎます。 単一の候補を評価する場合でも 3 つの距離を計算する必要があるため、平面上に高密度のグリッドを作成することは計算上不可能です。 

重要な構造観察は、平方根を消去すると、各点が線形関係を示すということです。 未知の円に中心を持たせる$O(x, y)$と半径$R$。 ポイントとしては$P$符号付き距離付き$d$、幾何拘束は次のように書くことができます。$$|OP| = R - d.$$これを二乗すると、$$(x - x_p)^2 + (y - y_p)^2 = (R - d)^2.$$これを 2 つの異なる点について展開し、結果として得られる方程式を減算すると、次の 2 次項が得られます。$x$そして$y$キャンセル。 残るのは次の一次方程式です。$x$、$y$、 そして$R$。 したがって、点の各ペアは 3 次元空間内の平面を定義します。$(x, y, R)$。 

3 つの点を使用すると、3 つの平面が得られます。 これらの平面の交差により、考えられるすべての解決策が決定されます。 平面が一致しない場合、解決策は存在しません。 3 つすべてが一致するか、単一の制約にまとめられる場合、無限に多くの解決策が存在します。 それ以外の場合、それらの交点は次の単一点になります。$(x, y, R)$、一意の円に対応します。 

ただし、代数系がキャンセル後にどのように減少するか、および中間の二乗ステップで複数の有効な分岐が導入されるかどうかに応じて、幾何学的空間に 2 つの有効な円が生成される形で縮退が発生する可能性があります。 幾何学的実現可能性を強制する前は線形化システムが一意であるように見えても、最終的な答えが最大 2 つの異なる有効な円をカウントする可能性があるのはこのためです。

 ## アルゴリズムのチュートリアル

 1. 各ポイントについて$P_i(x_i, y_i)$符号付き距離付き$d_i$、制約を次のように書き換えます$|OP_i| = R - d_i$。 これは、未知の中心と半径に関してすべての制約を表現します。 
2. 各方程式を 2 乗して平方根を取り除き、次のようになります。$$(x - x_i)^2 + (y - y_i)^2 = (R - d_i)^2.$$このステップが必要なのは、幾何学的距離制約を代数形式に変換するためです。 
3. 点 1 から点 2 の方程式を減算します。$x$そして$y$線形方程式を残してキャンセルします$x$、$y$、 そして$R$。 (1,3) と (2,3) についても繰り返します。 これにより、最大 3 つの線形制約が生成されます。 
4. 結果として得られる線形システムを解きます。 ランクが 0 または 1 で、すべての制約が一貫している場合、解空間は無限であり、無限に多くの円が存在することを意味します。 
5. システムに一貫性がない場合、3 つの制約をすべて満たす円は存在しません。 
6. それ以外の場合は候補を取得します$(x, y, R)$。 元の 3 つの二乗方程式すべてに対してそれを検証し、代数操作によって導入された無関係な解を排除します。 
7. 有効な幾何学的解がいくつ存在するかを数えます。 検証後に複数の一貫したブランチが残っている場合は、それぞれの半径を計算し、最小値を選択します。 

### なぜ効果があるのか

 各制約は二次曲面を定義します。$(x, y, R)$-空間。 ペアワイズ減算では二次項が削除され、システムがすべての有効な解を保持する線形制約に減らされます。 唯一の危険は二乗法によるもので、符号対称または無関係な解が導入される可能性があります。 元の非二乗制約に対して候補を再チェックすることで、幾何学的に有効な円のみが保持されることが保証されます。 ゼロ、有限、または無限の解への分類は、これらの平面がパラメーター空間内で交差する点がないか、単一の点で交差するか、または完全な線または平面で交差するかに正確に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    out = []

    eps = 1e-9

    for _ in range(T):
        pts = []
        for __ in range(3):
            x, y, d = map(int, input().split())
            pts.append((x, y, d))

        (x1, y1, d1), (x2, y2, d2), (x3, y3, d3) = pts

        # Build linear system by subtracting squared equations:
        # (x-xi)^2+(y-yi)^2 = (R-di)^2
        # After expansion:
        # -2x xi -2y yi + 2R di + (xi^2+yi^2-di^2) = x^2+y^2-R^2 (common term cancels in subtraction)

        def eq(a, b):
            (xa, ya, da) = a
            (xb, yb, db) = b

            A1 = xa - xb
            B1 = ya - yb
            C1 = db - da
            D1 = (xa*xa + ya*ya - da*da) - (xb*xb + yb*yb - db*db)

            return A1, B1, C1, D1

        e1 = eq((x1, y1, d1), (x2, y2, d2))
        e2 = eq((x1, y1, d1), (x3, y3, d3))
        e3 = eq((x2, y2, d2), (x3, y3, d3))

        # Each equation: A x + B y + C R = D

        eqs = [e1, e2, e3]

        # Try solve using two independent equations first
        def solve_two(ea, eb):
            A1, B1, C1, D1 = ea
            A2, B2, C2, D2 = eb

            det = A1*B2 - A2*B1
            detx = D1*B2 - D2*B1
            dety = A1*D2 - A2*D1

            # express x,y in terms of R if possible
            # handle degenerate cases by returning None
            if abs(det) < eps:
                return None

            x0 = detx / det
            y0 = dety / det

            # plug back to get R
            # A x + B y + C R = D
            denom = C1
            if abs(denom) < eps:
                denom = C2
                if abs(denom) < eps:
                    return None

            R = (D1 - A1*x0 - B1*y0) / C1
            return x0, y0, R

        # brute try pairs
        candidates = []
        pairs = [(e1, e2), (e1, e3), (e2, e3)]

        for a, b in pairs:
            res = solve_two(a, b)
            if res is None:
                continue
            candidates.append(res)

        def valid(x, y, R):
            if R <= 0:
                return False
            for x0, y0, d in pts:
                lhs = (x-x0)**2 + (y-y0)**2
                rhs = (R - d)**2
                if abs(lhs - rhs) > 1e-6:
                    return False
            return True

        sols = []
        for x, y, R in candidates:
            if valid(x, y, R):
                sols.append(R)

        # deduplicate
        sols = list(set([round(s, 12) for s in sols]))

        if len(sols) == 0:
            out.append("0")
        elif len(sols) > 1:
            out.append(str(len(sols)) + " " + str(min(sols)))
        else:
            out.append("1 " + str(sols[0]))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装は線形消去の考え方に直接従っています。 点の各ペアは、未知の中心と半径で 1 つの線形方程式を生成します。 次に、一度に 2 つの方程式を解くことで、候補解を再構築しようとします。 有効な解はすべてのペアごとの制約を満たさなければならないため、少なくとも 2 つのペアごとの制約の交差部分に存在する必要があるため、これで十分です。 

二乗すると代数アーチファクトが生じるため、検証ステップは不可欠です。 候補解は、3 点すべての正確な二乗距離が厳密な数値公差内で再現される場合にのみ受け入れられます。 このチェックを行わないと、中間線形化で符号情報が失われたときに、無効な解が漏洩する可能性があります。 

ペアワイズ方程式解法を使用すると、縮退も自然に処理されます。 方程式のペアが並列または依存している場合、ソルバーはそれをスキップして別のペアを試行し、すべての一貫した幾何学的構成が引き続き調査されることを保証します。

### 例 2

| ステップ | 候補者 | 有効性 |

これは、個々の線形解析が決定論的であるように見えても、システムが複数の幾何学的実現を許容できることを示しています。
