 ## 解決策
 ## 問題の理解

 私たちには、すでに相互に尊敬し合っている武士のグループといくつかのペアが与えられています。 リスペクトは対称的であるため、情報は、頂点がサムライでエッジが既存のリスペクト関係である無向グラフとして見ることができます。 

欠けているエッジを追加できるようにペアを「導入」することは許可されています。つまり、非エッジをエッジに変えることができますが、そのような追加の数は制限されなければなりません。 これらの追加を実行した後、すべてのサムライを空ではない 2 つのグループに分割し、各グループ内ですべてのサムライが同じグループ内のすべてのサムライを尊重するようにする必要があります。 グラフの用語では、エッジを追加した後、両方のグループがクリークを誘発する必要があります。 

したがって、タスクは、そのような分割が可能かどうかを判断するだけでなく、有効な分割と、両方の部分を完全に接続する一連の追加エッジを明示的に構築することも必要です。 

主要な構造要件は、各グループが完全な部分グラフを形成する必要があるということです。 グループ内の欠落しているエッジは明示的に追加する必要があります。 候補者はそのグループ内でのみチェックされるため、グループ間のエッジはまったく問題になりません。 

許可される導入数の制約により、注意が必要になります。非常に不均衡なパーティションを選択すると、1 つのグループが大きくなり、その中に欠落しているエッジをほぼすべて追加する必要が生じる可能性があります。 空のグラフという極端なケースでは、ほぼすべての頂点を 1 つのグループに配置するには Θ(N²) 回の加算が必要となり、制限に違反する可能性があります。 

唯一、自明ではないエッジ ケースは、N = 1 の場合です。その場合、空ではない 2 つのグループに分割できないため、答えは直ちに不可能になります。 

## アプローチ

 ブルートフォースのアイデアは、頂点の可能なすべての分割を空ではない 2 つのセットに分けて試し、各セット内に欠落しているエッジがいくつあるかを計算することです。 固定パーティションの場合は、欠落しているエッジを正確に追加し、追加の数が許容範囲内であるかどうかを確認します。 これは正しいです。有効なソリューションはいずれもパーティションに対応するからです。 ただし、2^N 個の可能なパーティションがあり、1 つのパーティションを評価するだけでもすべてのペアをスキャンする必要があるため、O(N² · 2^N) となり、1000 までの N ではまったく実行不可能です。 

重要な点は、実際には賢いパーティションを検索する必要がないということです。 バランスを制御している限り、どのパーティションでも機能します。 支払うコストは、両方のグループ内の欠落しているエッジの数です。 このコストは、グラフにエッジがまったくない場合に最大になります。これは、すべてのペアにエッジが欠けているためです。 その最悪のケースでは、必要な加算の数は 2 つのグループのサイズのみに依存し、グラフの構造には依存しません。 

これにより、内部ペアの安全な上限を保証するパーティションを選択するという問題が軽減されます。 最善の戦略は、頂点をできるだけ均等に分割することです。 最悪の場合でも、内部ペアの数は約 N²/4 で制限され、制限に一致します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | パーティションに対するブルート フォース | O(2^N · N²) | O(N) | 遅すぎる |
 | バランスの取れたパーティション + 欠けているエッジを追加 | O(N²) | O(N²) | 承認済み |

 ## アルゴリズムのチュートリアル

 インデックスのみに基づいて固定パーティションを構築します。 

1. 頂点のセットを 2 つのグループに分割します。最初の ⌊N/2⌋ 頂点は S1 に移動し、残りの頂点は S2 に移動します。 これにより、N ≥ 2 の場合、両方のグループが空でないことが保証されます。 
2. どのペアがすでに尊重関係を持っているかを表す構造 (隣接行列など) を構築します。 これにより、エッジが存在するかどうかを迅速にテストできます。 
3. S1 内の頂点のペアごとに、エッジがすでに存在するかどうかを確認します。 そうでない場合は、追加して紹介として記録します。 
4. S2 内のすべてのペアに対して同じプロセスを繰り返します。 
5. 記録されたすべての追加エッジを出力します。

グループ間のエッジを考慮しない理由は、この問題では S1 と S2 間の接続が必要ないためです。 重要なのは内部的な完全性だけです。 

### なぜ効果があるのか

 この構造では、欠落している内部エッジがすべて明示的に追加されるため、S1 と S2 の両方がクリークになることが保証されます。 残る唯一の懸念は、追加されるエッジの数が制限を超えるかどうかです。 

最悪のケースは、最初のグラフにエッジがない場合に発生します。 この場合、S1 と S2 内のすべてのペアが欠落しているため、加算数は C(|S1|,2) + C(|S2|,2) になります。 この式は、分割が可能な限りバランスが取れているときに最大化されます。これはまさにパーティションの構築方法です。 その場合、合計は最大でも N(N−1)/4 となり、制約と一致します。 入力内の既存のエッジは必要な加算の数を減らすだけであり、増やすことはないため、境界は常に保持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, M = map(int, input().split())
    if N == 1:
        print("NO")
        return

    adj = [[False] * N for _ in range(N)]

    for _ in range(M):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        adj[a][b] = adj[b][a] = True

    S1 = list(range(N // 2))
    S2 = list(range(N // 2, N))

    ans = []

    def add_edges(group):
        g = group
        for i in range(len(g)):
            for j in range(i + 1, len(g)):
                u, v = g[i], g[j]
                if not adj[u][v]:
                    adj[u][v] = adj[v][u] = True
                    ans.append((u + 1, v + 1))

    add_edges(S1)
    add_edges(S2)

    print("YES")
    print(len(ans))
    for u, v in ans:
        print(u, v)

if __name__ == "__main__":
    solve()
```解決策は、2 つの空でないサブセットを形成できないため、唯一不可能なケース N = 1 を拒否することから始まります。 

次に、欠落しているエッジを一定時間でテストできるように隣接行列を構築します。 最大 O(N²) ペアを検査する必要がある可能性があるため、これは重要です。 

パーティションはインデックス分割によって決定的に固定され、検索や最適化が回避されます。 

最後に、各グループ内のすべてのペアを反復処理し、欠落しているエッジを正確に追加します。 重複した追加を避けるために、隣接行列は更新されます。

 ## 特殊なケース

 N = 1 の場合、2 つの空でないセットへの分割が存在しないため、アルゴリズムはそのケースを即座に拒否します。 

空のグラフの場合は、すべての内部ペアを追加する必要があります。 バランスのとれた分割により、追加されるエッジの数が許容範囲内に収まることが保証され、アルゴリズムは各グループ内のすべての欠落ペアを明示的に列挙します。 

全結合グラフの場合、追加はまったく行われません。 アルゴリズムは引き続き有効なパーティションを出力し、両方のグループは何も変更せずにクリークのままになります。 

混合グラフの場合、既存のエッジは必要な挿入の数を減らすだけです。 欠落している内部エッジのみを追加するため、正確性に違反したり、制約を超えたりすることはありません。
