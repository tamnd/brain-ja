 ## 問題の理解

 この問題のドミノは、1 つの垂直区切り記号が付いたドットの行で表されます。 セパレータの左側と右側にあるドットは、タイルの 2 つの半分のポイントの数です。 このようなタイルが 2 つ与えられており、それらを一緒に配置できるかどうかを決定する必要があります。 

2 つのドミノは、最初のドミノの少なくとも半分と 2 番目のドミノの少なくとも半分に 0 から 6 までの数字が出現する場合に一致します。 出力は`Yes`このような共通の半値が存在する場合、および`No`さもないと。 元の問題ステートメントは、2 つの仮想ドミノ ピースのこの互換性条件を正確に説明しています。 

各半分には最大 6 つのドットが含まれるため、入力文字列は非常に小さくなります。 すべての可能な値の直接チェックはすでに定数時間です。 小さな境界を無視してより大きな文字列を想像したとしても、各ドミノの 2 つの半分を 1 回検査するだけで済むため、グラフ アルゴリズム、動的プログラミング、またはシミュレーションの必要性が排除されます。 

主なエッジケースは、ゼロドットが許可されるという事実から生じます。 ドットがゼロのドミノ ハーフはセパレータの空の側で表されるため、セパレータ自体が最初または最後の文字になる可能性があります。 

例えば：```
|
.
```最初のドミノの値は 0 と 0 で、2 番目のドミノの値は 0 と 1 です。正しい出力は次のとおりです。```
Yes
```ドットだけを数えて空の辺を無視する不注意な実装では、最初のドミノが誤って扱われ、値 0 の一致を見逃してしまいます。 

もう 1 つのケースは、同じ値が同じ側にない場合です。```
.|...
....|.
```最初のドミノには値 1 と 3 が含まれています。2 番目のドミノには値 4 と 1 が含まれています。正しい出力は次のとおりです。```
Yes
```左半分のみまたは右半分のみを比較するソリューションでは、このペアが誤って拒否されます。 

## アプローチ

 ブルートフォース手法では、最初のドミノの 2 つの値を生成し、2 番目のドミノの 2 つの値を生成し、一方のドミノのすべての値をもう一方のドミノのすべての値と比較します。 比較は 4 つだけなので、演算回数は一定です。 入力にドミノが 2 つしか含まれていないため、このアプローチはすでに十分に高速です。 

よくある間違いは、ドミノを接続する行為をシミュレートしようとして問題を複雑にしすぎてしまうことです。 条件は非常に単純です。2 つのタイルには、一致する半分の値が 1 つだけ必要です。 一致する半分の位置は重要ではありません。 

重要な観察は、各ドミノが最大 2 つの数字のセットに還元できるということです。 両方のセットが構築されたら、答えはそれらの交差部分が空でないかどうかだけです。 ブルートフォース比較とセットベースのビューは同等ですが、セット表現の方が推論が明確になり、ゼロを含むケースの欠落が回避されます。

 ## アルゴリズムのチュートリアル

 1. 各入力文字列を垂直区切り文字で分割します。 セパレータの前後のドットの数によって、ドミノに書かれた 2 つの値が得られます。 
2. 各ドミノの 2 つの値を保存します。 値はゼロになる可能性があるため、文字列の空の部分も有効な半分としてカウントされる必要があります。 
3. 最初のドミノの値が 2 番目のドミノの値と等しいかどうかを確認します。 
4. 印刷`Yes`一致する値が見つかった場合。 それ以外の場合は印刷します`No`。 

これが機能する理由は、互換性の定義全体が、2 つの半値のセットが少なくとも 1 つの要素を共有するかどうかのみに依存するためです。 半分のドミノの物理的な位置や向きが答えに影響することはありません。 

## なぜ機能するのか

 このアルゴリズムは、各ドミノから必要な正確な情報を保存します。 ドミノには関連するプロパティが 2 つだけあります。それは、左半分のドットの数と右半分のドットの数です。 互換性のある配置が存在する場合、何らかの値`k`両方のドミノのこれら 2 つの値の間に出現する必要があり、アルゴリズムは考えられるすべてのペアをチェックします。 アルゴリズムが共通の値を見つけた場合、その値は必要な条件を満たします。 見つからない場合は無効です`k`存在します。 したがって、生成される答えは常に正しいものになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a = input().strip()
    b = input().strip()

    def values(s):
        left, right = s.split('|')
        return {left.count('.'), right.count('.')}

    first = values(a)
    second = values(b)

    print("Yes" if first & second else "No")

if __name__ == "__main__":
    solve()
```の`values`関数は、ドミノの記述をその半分に書かれた 2 つの数字に変換します。 分割`|`などの空の半分を自然に処理するため、手動でスキャンするよりも安全です。`|`または`...|`。 

セットを使用すると重複が削除されます。 たとえば、ドミノは次のように記述されます。`|`になる`{0}`、両方の半分に 3 つの点が含まれるドミノは次のようになります。`{3}`。 交差演算では、少なくとも 1 つの共通の値が存在するかどうかがチェックされます。 

インデックスは使用されないため、境界の問題はありません。 ドットを直接カウントすると、考えられるすべての値が 0 ～ 6 の間になるため、整数変換の問題も回避できます。

## テストケース```python
import sys
import io

def solve_data(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    a = sys.stdin.readline().strip()
    b = sys.stdin.readline().strip()

    def values(s):
        left, right = s.split('|')
        return {left.count('.'), right.count('.')}

    ans = "Yes" if values(a) & values(b) else "No"
    sys.stdin = old_stdin
    return ans
