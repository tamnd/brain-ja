 ## 問題の理解

 チケットは次の文字列です。`n`数字、ここで`n`は均等です。 2 つのバランス条件を満たすそのような文字列がいくつあるかを数える必要があります。 最初の条件は、左半分の数字の合計が右半分の合計と等しいことを示します。 2 番目の文は、奇数位置の数字の合計が偶数位置の合計と等しいことを示します。 チケットは固定長の一連の数字であるため、先頭のゼロは許可されます。 

前半に合計を入れます`a`奇数の位置と`b`偶数の位置で。 後半に和を持たせる`c`奇数の位置と`d`偶数の位置で。 条件は次のようになります。`a + b = c + d`そして`a + c = b + d`。 

方程式を減算すると、`a = d`、 その後`b = c`。 これが重要な簡素化です。2 つのグローバル条件を処理する代わりに、ポジション グループの 2 つのペアの合計を照合するだけで済みます。 

長さは 200000 に達する可能性があるため、チケットを生成したり、すべてのポジションとすべての可能な合計に対して動的プログラミングを使用したりすることは不可能です。 可能な最大桁合計は 100 万に近く、二次関数は除外されます。`n`。 可能な合計の数が線形に近い解が必要です。 

トリッキーなケースは、ハーフレングスの同等性から生じます。 たとえば、次のようなとき`n = 2`、2 つの半分にはそれぞれ 1 桁の数字が含まれます。 2 番目の条件は、2 桁の一致を要求することと自動的に同じになるため、答えは 10 になります。ポジションの 4 つのグループすべてが同じサイズであると仮定する方法は、ここでは失敗します。 

入力の場合:```
2
```正しい出力は次のとおりです。```
10
```なぜならチケットは`00, 11, ..., 99`。 

もう 1 つの境界ケースは、半分の長さが偶数である場合です。`n = 8`。 4 つのグループはすべて同じサイズです。 奇数の半分の長さのみを処理するソリューションでは、異なるサイズのグループが誤って結合されてしまいます。 

## アプローチ

 直接的なアプローチは、グループへの可能な数字の割り当てをすべてカウントすることです。 チケットには最大 200,000 桁が含まれるため、これは絶望的です。 ポジション間の単純な遷移を伴うすべての可能な桁合計分布を保存する場合でも、非常に多くの操作が必要になります。 

有益な観察は、グループの合計のみが重要であるということです。 を含むグループの場合`k`数字、みましょう`f(k, s)`それらの数字を選択する方法の数であり、その合計は`s`。 1 桁の生成関数は次のとおりです。`1 + x + x² + ... + x⁹`。 

選択した後`k`数字の場合、分布は次のように表されます。`(1 + x + x² + ... + x⁹)^k`。 

答えには、このような 2 つの分布のスカラー積のみが必要です。 グループにサイズがある場合`k`そして`k`、次のものが必要です。`sum(f(k, s)^2)`。 

グループにサイズがある場合`k`そして`k + 1`、次のものが必要です。`sum(f(k, s) * f(k + 1, s))`。 

どちらも、多項式のべき乗の単一の係数として記述することができます。 以来：`1 + x + ... + x⁹ = (1 - x¹⁰) / (1 - x)`、

 包含-除外を使用して必要な係数を抽出できます。`[x^s](1+x+...+x⁹)^m = Σ (-1)^j * C(m,j) * C(s-10j+m-1,m-1)`。 

この合計の項の数は最大約 90,000 であり、制約を容易に満たします。

 ## アルゴリズムのチュートリアル

 1. ポジションを前半の奇数ポジション、前半の偶数ポジション、後半の奇数ポジション、後半の偶数ポジションの 4 つのグループに分割します。 元の 2 つの条件は、対立するグループ間の平等に帰着します。 
2. 半分の長さが偶数の場合、すべてのグループは同じサイズになります。`k = n / 4`。 計算:`S = sum(f(k, s)^2)`。 

最終的な答えは、`S²`2 つのグループのペアは独立しているためです。 
3. 半分の長さが奇数の場合、グループのサイズは異なります。 させて：`k = floor(n / 4)`。 

2つのペアにはサイズがあります`k`そして`k + 1`。 計算:`S = sum(f(k, s) * f(k+1, s))`。 

最終的な答えはまた`S²`。 
4. 必要な係数を計算します。`(1+x+...+x⁹)^m`包含-除外を使用します。 階乗および逆階乗を事前計算して、すべての二項係数を一定時間内に取得します。 

これが機能する理由: 2 つのバランス方程式を 2 つの独立した等和ペアに変換すると、有効なチケットが正確に保存されます。 各ペアについて、生成関数は、可能なすべての数字の割り当てをその合計によってカウントします。 スカラー積を計算すると、ペアの両側の合計が同じになる方法が正確にカウントされます。 2 つのペアは互いに素な位置を使用するため、2 つのカウントを乗算すると、有効なチケットの合計数が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    
    if n % 4 == 0:
        m = n // 2
        s = 9 * (n // 4)
    else:
        m = n // 2
        s = 9 * ((n // 4) + 1)

    max_fact = s + m
    fact = [1] * (max_fact + 1)
    for i in range(1, max_fact + 1):
        fact[i] = fact[i - 1] * i % MOD

    invfact = [1] * (max_fact + 1)
    invfact[-1] = pow(fact[-1], MOD - 2, MOD)
    for i in range(max_fact, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    def comb(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

    def coefficient(power, target):
        ans = 0
        for j in range(target // 10 + 1):
            cur = comb(power, j) * comb(target - 10 * j + power - 1, power - 1) % MOD
            if j & 1:
                ans -= cur
            else:
                ans += cur
        return ans % MOD

    if n % 4 == 0:
        x = coefficient(m, s)
    else:
        x = coefficient(m, s)

    print(x * x % MOD)

if __name__ == "__main__":
    solve()
```プログラムはまず、2 つのパリティ ケースのどちらが適用されるかを決定します。 変数`m`は、比較される 2 つの構造のうちの 1 つの内部の合計桁数に等しいため、生成関数の指数です。 

階乗配列を使用すると、包含排除式内での高速な二項計算が可能になります。 最大の階乗指数は 600000 未満であるため、事前計算は小さくなります。 

の`coefficient`関数は次の拡張を実装します。`(1+x+...+x⁹)^power`。 ループは、係数によって削除できる有効な 10 の倍数のみを考慮します。`(1-x¹⁰)^power`、不必要な作業を回避します。 

最後の正方形は、2 つの反対側の位置のペアの独立性から生じます。 乗算はモジュロで行われます`998244353`最後に。

 ## 特殊なケース

 のために`n = 2`、アルゴリズムは奇数の半長分岐に入ります。 この係数は、可能な唯一のサイズ 0 のグループのペアを表し、それを数字の選択肢と合わせて 2 乗すると、10 枚の等しい数字のチケットが得られます。 

のために`n = 6`、最初と 2 番目の位置グループには同じ桁数が含まれていません。 このアルゴリズムでは、対称性を仮定する代わりに混合サイズの係数を使用するため、`k = n/4`式のとき`n/2`奇数です。 

のために`n = 200000`、可能な最大入力であるため、アルゴリズムは合計の分布全体を構築することはありません。 包含排他を通じて必要な中間係数のみを評価し、メモリと実行時間の両方を線形に保ちます。
