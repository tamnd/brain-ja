 ## 解決策
 # 問題の理解

 部屋が頂点、トンネルがエッジである無向グラフがあります。 2 つのプロパティのいずれかを持つ部屋の小さなグループを見つける必要があります。 最初の可能性は、規模の大きなグループです。`l`これは、グループ内の各部屋のペアの間にトンネルがあることを意味します。 2番目の可能性は、規模の反勢力です。`k`これは、グループ内のどのペアの部屋の間にもトンネルがないことを意味します。 どちらの構造も存在しない場合は、次のように出力します。`-1`。 

入力により、部屋の数、トンネル、および 2 つのターゲット サイズが与えられます。 グラフには最大 300,000 個の頂点と 300,000 個のエッジを含めることができますが、要求されたグループ サイズは両方とも最大 5 です。`k`そして`l`が重要な制約です。 一般的なクリークの検索は困難ですが、クリークまたは最大 5 つのサイズの独立したセットを検索することで、ラムジー理論を使用することができます。 考えられるすべての頂点のペアを保存したりチェックしたりすることは不可能であるため、スパースなグラフ表現も重要です。 

頂点が 300,000 ある場合、部屋のすべてのペアをチェックするだけでも約 90000000000 回の操作が必要となり、制限をはるかに超えています。 3 倍、4 倍、またはより大きなグループを直接列挙する解決策もすぐに不可能になります。 グラフ サイズにほぼ線形に依存し、最大応答サイズによって生じる小さな検索ツリーのみを探索するアプローチが必要です。 

最初のエッジ ケースは、要求されたサイズが 1 である場合です。 単一の頂点はサイズ 1 のクリークと反クリークの両方であるため、答えはすぐに任意の頂点になります。 例えば：```
Input:
5 0 1 3

Output:
1
```エッジまたは非エッジのみを検索するソリューションは、1 つの頂点グループが常に有効であるという事実を見逃してしまうため、誤って失敗します。 

もう 1 つのエッジ ケースは、グラフが空の場合です。 アンチクリークが必要な場合は、すべての頂点セットが機能しますが、1 より大きいサイズのクリークが必要な場合は、クリークは存在しません。 例えば：```
Input:
4 0 3 2

Output:
1 2 3
```選択された頂点を除くすべての頂点は反クリーク側に属するため、アルゴリズムは非隣接頂点を正しく移動できなければなりません。 

最後の厄介なケースは、グラフが完成したときです。 その場合、1 より大きい反クリークは不可能ですが、頂点のすべてのグループはクリークになります。 例えば：```
Input:
4 6 3 4

Output:
1 2 3 4
```欠落しているエッジのみをチェックする不用意な実装は、たとえクリークの答えが即時であっても失敗します。 

## アプローチ

 直接的なアプローチでは、必要なサイズの頂点の考えられるすべてのグループを列挙し、クリークまたは反クリークを形成しているかどうかを確認します。 ターゲット サイズが 5 の場合、これは大まかにチェックすることを意味します。`n^5`グループ。 と`n = 300000`、これはまったく不可能です。 

より良い方向性は問題の構造から生まれます。 任意のサブグラフを探しているわけではありません。 私たちが気にするのは、クリークまたはその反対の独立したセットのいずれかを見つけることだけであり、どちらのサイズも最大 5 です。 

頂点を 1 つ選択します`v`。 以下を含むすべての有効なグループ`v`残りの頂点を 2 つの場所のうち 1 つから選択する必要があります。 グループがクリークの場合、残りの頂点はすべて隣接する頂点でなければなりません。`v`。 グループが反クリークの場合、残りの頂点はすべてそのグループの非隣接頂点でなければなりません。`v`。 

これにより、再帰的な検索が行われます。 サイズのクリークを見つけるには`c`または規模の反勢力`i`では、現在の候補セットを 1 つの頂点の近傍と非近傍に分割します。 次に、同じサイズのクリークを検索します`c - 1`近隣諸国の間、または規模の大きな反勢力の間で`i - 1`隣人ではない人々の間で。 

ブルート フォース手法はすべてのサブセットを同等に扱うため失敗します。 再帰的方法は、必要な構造の 1 つをまだ含むことができる組み合わせのみに従います。 どちらのパラメータも最大 5 であるため、再帰の深さはわずかです。 ラムジー理論は、答えが存在しない場合、両方の構造を回避するグラフが大きくなり得ないという追加の保証を提供します。 再帰は、困難な場合には少数の頂点にのみ到達します。 

再発を使用できます`R(a, b) <= R(a - 1, b) + R(a, b - 1)`ベースケース付き`R(1, x) = R(x, 1) = 1`。 これにより、次のサイズのクリークを含める必要があるセットのサイズに安全な上限が与えられます。`a`または規模の反勢力`b`。 候補セットがこの値より小さい場合、再帰呼び出しは直ちに停止できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^5) | お(1) | 遅すぎる |
 | 最適 | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 頂点の完全なセットを使用して再帰的検索を開始します。 パラメータは、クリークとアンチクリークにさらにいくつの頂点が必要かについて記述します。 
2. クリーク要件またはアンチクリーク要件が 1 つの場合、現在の頂点を返します。 単一の頂点は常に両方の定義を満たします。 
3. 現在の候補セットが残りの要件の Ramsey 限界より小さい場合、この分岐を停止します。 有効な回答を含めることはできません。 
4. 頂点を 1 つ選択します`v`現在のセットから。 他のすべての候補者を 2 つのグループに分割します。 最初のグループには近傍が含まれます。`v`、2 番目のグループには、次の非隣接グループが含まれます。`v`。 
5. 必要なクリーク サイズを 1 つ減らしながら、隣接グループを検索します。 これは正しいです。なぜなら、クリークの追加頂点には次のものが含まれるからです。`v`に接続する必要があります`v`。 
6. それが失敗した場合は、必要なアンチクリークのサイズを 1 つ減らしながら、非隣接グループを検索します。 これは正しいです。なぜなら、アンチクリークの追加頂点には次のものが含まれるからです。`v`避けなければなりません`v`。 
7. 両方の再帰呼び出しが失敗した場合、このブランチには有効な構造が存在しません。 答えが見つかるか、ルートが失敗を返すまで、失敗を返し続けます。 

なぜ効果があるのか:

 不変条件は、すべての再帰呼び出しが、必要な 2 つの構造のうちの 1 つを完成できる頂点を正確に受け取るということです。 ソリューションに選択した頂点が含まれている場合`v`、その解の残りの部分は、完全に隣接グループまたは非隣接グループのいずれかに存在する必要があります。 再帰では両方の可能性が調査されるため、有効な答えを破棄することはできません。 Ramsey 境界は、要求されたサイズの解が含まれていないことが数学的に保証されているセットのみを削除します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k, l = map(int, input().split())

    graph = [[] for _ in range(n)]
    for _ in range(m):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        graph[a].append(b)
        graph[b].append(a)

    ramsey = [[0] * 6 for _ in range(6)]
    for i in range(1, 6):
        ramsey[1][i] = 1
        ramsey[i][1] = 1

    for i in range(2, 6):
        for j in range(2, 6):
            ramsey[i][j] = ramsey[i - 1][j] + ramsey[i][j - 1]

    mark = [0] * n
    token = 0

    def dfs(vertices, clique_need, indep_need):
        nonlocal token

        if clique_need == 1 or indep_need == 1:
            return [vertices[0]]

        if len(vertices) < ramsey[clique_need][indep_need]:
            return None

        v = vertices[0]

        token += 1
        cur = token
        for u in graph[v]:
            mark[u] = cur

        neigh = []
        non_neigh = []

        for u in vertices[1:]:
            if mark[u] == cur:
                neigh.append(u)
            else:
                non_neigh.append(u)

        if clique_need > 1:
            res = dfs(neigh, clique_need - 1, indep_need)
            if res is not None:
                return [v] + res

        if indep_need > 1:
            res = dfs(non_neigh, clique_need, indep_need - 1)
            if res is not None:
                return [v] + res

        return None

    ans = dfs(list(range(n)), l, k)

    if ans is None:
        print(-1)
    else:
        print(*[x + 1 for x in ans])

if __name__ == "__main__":
    solve()
```隣接リストには既存のエッジのみが保存されます。グラフには 300,000 個の頂点を含めることができるため、これが必要です。 の`mark`array は隣接セットを繰り返し構築することを避けます。 選択された頂点ごとに、その隣接頂点が現在のトークン値を受け取り、候補リストを 1 回スキャンするだけで隣接頂点と非隣接頂点に分割できます。 

再帰関数は 2 つのカウンターを保持します。`clique_need`クリークにまだ必要な頂点の数を表します。`indep_need`反派閥についても同じことを表します。 そのうちの 1 つが 1 に達すると、現在の頂点リストには有効な単一の頂点の答えがすでに含まれています。 

Ramsey テーブルでは、正確な値ではなく上限が使用されます。 不可能な枝を剪定することだけが目的なのでこれで十分です。 どちらのターゲット サイズも最大 5 であるため、値は非常に小さいです。 

返された頂点は、印刷前に 1 ベースのインデックスに変換されます。 Python の整数には任意の精度があるため、実装では整数のオーバーフローが自動的に回避されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + m) | 各大規模な再帰的分割では現在の候補のみがスキャンされ、両方のターゲット サイズが最大 5 であるため、再帰の深さは 10 で制限されます。 
| スペース | O(n + m) | 隣接リストにはすべてのエッジが格納され、再帰には小さな候補リストのみが格納されます。 |

 再帰の高価な部分は、候補セットが問題になるほど大きい場合にのみ発生するため、この解決策は制約に適合します。 ラムゼイ境界は、失敗した検索がすぐに小さな集合に縮小されることを保証します。
