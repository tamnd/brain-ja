 ## 解決策
 ## 問題の理解

 分数を繰り返し生成し、それらを結合するプロセスが与えられています。 ある時点で、次の形式の部分のコレクションが完成します。$\frac{a_1}{b_1}, \frac{a_2}{b_2}, \dots, \frac{a_k}{b_k}$。 タスクは、考えられるすべての演算を適用した後に最終値を計算することです。重要な演算は分数の結合です。 

このステートメントに隠されている重要な観察は、このプロセスでは分数の並べ替えや結合が可能であり、任意の分数を自由に「反転」できるということです。$\frac{a}{b}$の中へ$\frac{b}{a}$それが有益であれば。 目標は、すべての変換後に得られる合計を最大化することであり、最終的には分数を組み合わせる最適な方法を計算することになります。 

このステートメントはやや圧縮された代数形式で書かれていますが、核となる構造は次のとおりです。分数を合計していますが、合計の前に分数を反転することができます。また、最終的な結合ルールは、分子が分母を超えたときに単調改善特性を維持する加重結合のように動作します。 

ステートメントに示されている不等式から、2 つの分数を 1 つの「マージされた」分数に結合すると、常に、それらを別々に保つ場合と少なくとも同じくらい大きな値が生成されることがわかります。 これは、マージを繰り返すとすべてが単一の実効分数に崩壊し、最終的な答えはすべての反転後に調整された分子と分母の合計にのみ依存することを意味します。 

このタイプの問題 (多数の分数) に特有の制約を考慮すると、解は入力に対して線形時間で実行される必要があります。 ペアごとのマージをシミュレートしたり、値を繰り返し再計算したりするアプローチは、二次関数の動作につながり、失敗します。 

一部の分数が 1 より大きい場合、微妙なエッジ ケースが発生します。分数を反転しないと、分母の重みが必要以上に大きくなり、最終結果が低下します。 たとえば、次のような分数$\frac{5}{2}$に反転する必要があります$\frac{2}{5}$そうしないと、最終合計の複合比率が悪化します。 

もう 1 つのエッジ ケースは、すべての分数がすでに 1 以下である場合です。この場合、反転は発生せず、解は分子と分母の単純な合計になります。 

## アプローチ

 単純な考えは、プロセスを文字通りに扱うことです。 すべての小数を取得し、可能なすべてのマージ シーケンスを試し、結果の値を計算します。 各マージでは、指定されたルールを使用して 2 つの分数が 1 つの新しい分数に結合され、1 つの分数のみが残るまで続行されます。 

これは、許可された操作に直接従うため、原則的には正しいです。 ただし、マージごとに分数の数が 1 ずつ減り、k 個の分数に対して k−1 個のマージが行われます。 構造をスキャンまたは再構築することによって各マージの効果を再計算すると、最悪の場合、コストは 2 次になります。 k が大きい場合、これは不可能です。 

重要な構造的洞察は、マージが単調な改善特性を維持する方法で結合的であるということです。最初に各分数を最適に正規化した場合、分数を結合しても、達成可能な最適な値が減少することはありません。 ステートメントに示されている不等式は、最適な反転の下で 2 つの分数をそれらのマージされた等価物で置き換えると、それらを別々にしておくことと比較して常に厳密に良いか等しい値が得られることを示しています。 

これは、マージ順序をシミュレートする必要がまったくないことを意味します。 代わりに、各分数を独立して正規化できます。$a > b$、反転すると「悪さ」の寄与が減り、最終的な集計値が向上します。 正規化後、変換された分子と分母を合計することで、すべての分数を 1 回のパスで安全に組み合わせることができます。 

したがって、プロセス全体は、入力に対する単一の線形パスに短縮され、各部分にローカル ルールを適用して集計されます。

 ## アルゴリズムのチュートリアル

 各部分を個別に処理し、最終的に結合された構造を表す累計を維持します。 

1. 各分数を読み取ります$a_i, b_i$。 正規化が適用されるとマージは順序に依存しないため、各部分を最終的なマージ結果への独立した寄与として扱います。 
2. もし$a_i > b_i$、分数を反転したバージョンに置き換えます$\frac{b_i}{a_i}$。 このステップにより、分母が不必要に大きくならないように、すべての分数が寄与するようになります。 ステートメント内の不等式により、最終的な合計値の点で反転が常に有益であることが保証されます。 
3. 2 つのアキュムレータを維持します。1 つは分子用、もう 1 つは分母用です。 正規化された分数ごとに、その分子を分子アキュムレータに加算し、その分母を分母アキュムレータに加算します。 これは、最終的な結合分数構造を表します。 
4. すべての分数を処理した後、累積された分子の合計と累積された分母の合計の比率として最終結果を計算します。 
5. この値を必要な形式で出力します。 

### なぜ効果があるのか

 核となる不変条件は、各ステップの後に、現在の累積ペアが$(N, D)$は、最適な反転ルールに基づいて処理されたすべての部分をマージするのと同等のものを表します。 ステートメントで指定された不等式により、2 つの正規化された分数を 1 つの分数にマージすると、それらを別々にしておくよりも悪くない値が生成され、実質的に集計が結合されます。 各分数は独立して正規化されるため、$a \le b$、その後のマージでは再反転の恩恵を受けることはできないため、ローカルな最適な選択がグローバルな最適化を構成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    data = input().strip().split()
    k = int(data[0])
    idx = 1

    num = 0
    den = 0

    for _ in range(k):
        a = int(data[idx]); b = int(data[idx + 1])
        idx += 2

        if a > b:
            a, b = b, a

        num += a
        den += b

    print(num / den)

if __name__ == "__main__":
    main()
```このソリューションは 1 回のパスですべての部分を読み取るため、繰り返しの解析や中間構造によるオーバーヘッドが回避されます。 条件付きスワップにより、分子が常に分母以下になるように各分数が正規化されます。 これは重要な局所的な決定だけです。なぜなら、不等式により、端数を反転しないままにしておくことが決して有益ではないことが保証されるからです。 

アキュムレータは、マージされた状態を直接表します。 最終出力は換算された分数ではなく実数の比であるため、gcd の換算や中間の単純化は必要ありません。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべての分数が正確に等しい場合です。$\frac{5}{5}$。 この場合、反転しても値は変更されず、アルゴリズムによって対称性が維持されます。 入力用`1 5 5`の場合、アキュムレータは分子 5 と分母 5 になり、期待どおり 1 が得られます。 

別のケースは、次のように 1 つの分数が優勢な場合です。$\frac{10^9}{1}$。 アルゴリズムはそれを次のように反転します$\frac{1}{10^9}$、分母の合計を圧倒するのを防ぎます。 このルールがないと、最終的な比率は大きく歪んでしまい、意図した最適化では不正確になります。 

最後のケースは、単一の小数による最小入力サイズです。 アルゴリズムは次のいずれかを直接返します。$a/b$または$b/a$、比較に応じて、マージのない縮退の場合でも最適な反転の定義と一致します。
