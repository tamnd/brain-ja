 ## 問題の理解

 サイズの正方形のボードが与えられます$n \times n$。 注文ペアに興味があります$(a, b)$、ここで両方とも$a$そして$b$間の整数です$1$そして$n$そして、そのようなペアが割り切れる条件を満たす数を数えたいとします: 少なくとも 1 つの数値$a$または$b$固定整数で割り切れる$k$。 

元の動機は長方形をタイル状に並べることについて述べていますが、$1 \times k$個数を増やすと、計算タスクは完全に、単純な算術特性を満たす正方形内の格子点を数えることに減ります。 

出力は単一の整数、つまりペアの数です。$(a, b)$グリッドの中で$[1, n] \times [1, n]$どこ$a$で割り切れます$k$、 または$b$で割り切れます$k$、またはその両方。 

制約は明示的には示されていませんが、これは典型的な Codeforces の算術問題であるため、次のことを期待する必要があります。$n$そして$k$少なくともここまでは$10^9$以上、場合によっては複数のテスト ケース。 これにより、すべての反復処理が即座に除外されます$n^2$偶数なのでペア$n = 10^5$すでに与えています$10^{10}$これは実現不可能です。 

よくある落とし穴は、ペアをシミュレートまたは列挙しようとしたり、タイリングの解釈を考えすぎたりすることです。 もう 1 つの間違いは、両方の座標が次の値で割り切れるペアを二重に数えることです。$k$。 たとえば、次の場合$n = 5$、$k = 2$、次のようにペアリングします$(2, 4)$は両方の条件でカウントされるため、修正する必要があります。 

## アプローチ

 ブルートフォースソリューションでは、すべてのペアに対して反復処理が行われます。$(a, b)$、どうかを確認してください$a \bmod k = 0$または$b \bmod k = 0$、条件を満たすものをカウントします。 これは要件の定義を直接実装しているため、これは正しいです。 ただし、実行します$n^2$各チェックは定数時間であるため、合計の複雑さは次のようになります。$O(n^2)$。 これは、中程度の値であっても不可能になります。$n$、 以来$n = 10^5$必要になるだろう$10^{10}$操作。 

重要な観察は、この条件は個々の座標の可分性のみに依存し、座標間の相互作用には依存しないということです。$a$そして$b$労働組合を通さない限り。 これにより、ペアを列挙する代わりに、相補的な構造化セットを数えることができます。 

2 つのセットを定義します。最初の座標が次の値で割り切れるペアです。$k$、および 2 番目の座標が次の値で割り切れるペア$k$。 割り算は周期的であるため、各セットを独立して数えることは簡単です。 範囲内$1$に$n$、 その通り$\lfloor n / k \rfloor$数値は次で割り切れます$k$。 それがわかれば、ペアを数えるのは簡単になります。$n$、無制限の座標は任意の値を取ることができるためです。 

唯一の問題は、両方の座標が次の値で割り切れるペアのオーバーラップです。$k$は 2 回カウントされるため、その交差部分を減算します。 これは、クリーンな包含-排他構造に直接つながります。

 ## アルゴリズムのチュートリアル

 すべてのペアをカウントしたい$(a, b)$少なくとも 1 つの座標が次の値で割り切れるようにする$k$。 

1. の整数がいくつあるかを計算します。$[1, n]$で割り切れます$k$。 これは$cnt = \lfloor n / k \rfloor$。 この値は、割り算条件を満たす必要がある座標の選択肢がいくつあるかを表します。 
2. ペアを数えます。$a$で割り切れます$k$。 それぞれの有効な$a$、$b$のいずれかになります$n$価値観。 これにより、$cnt \cdot n$ペア。 これが機能する理由は、条件が制限するだけであるためです。$a$、 そして$b$完全に無料です。 
3. 同様に、ペアを数えます。$b$で割り切れます$k$。 これにより、$cnt \cdot n$。 対称性により、両方の寄与が同一であることが保証されます。 
4. 両方が一致するペアを減算します。$a$そして$b$で割り切れます$k$。 両方の座標は同じ割り切れるサイズのセットから取得する必要があります$cnt$、したがって、この交差点は貢献します$cnt^2$ペア。 
5. 包含/除外を使用して結合します。$ans = 2 \cdot cnt \cdot n - cnt^2$。 

機能する理由: すべての有効なペアは、各座標が次の値で割り切れるかどうかに基づいて分類されます。$k$。 どちらの座標も割り切れないペアは自動的に除外されます。 割り切れる座標が 1 つだけあるペアは、正しい用語で 1 回カウントされます。 両方の割り切れる座標を持つペアは 2 回カウントされ、交差部分の減算によって修正されます。 これにより、すべての有効なペアが正確に 1 回カウントされることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    cnt = n // k
    ans = 2 * cnt * n - cnt * cnt
    print(ans)

if __name__ == "__main__":
    solve()
```実装は導出された式に直接続きます。 唯一の計算は、次の整数の倍数を決定するための整数の除算です。$k$範囲内にあります。 最後の式は Python の 64 ビット安全な算術演算を使用するため、オーバーフローは心配ありません。 

微妙な点は、結果が正確である必要があるため、浮動小数点除算ではなく整数除算が使用されていることを確認することです。 もう 1 つの詳細は、両方の項が対称であるため、個別に追跡する必要がないことです。$a$そして$b$共有数を超えています。

 ## 特殊なケース

 エッジケースの 1 つは次のような場合です$k > n$。 この場合、次の倍数はありません。$k$範囲内なので、$cnt = 0$。 特別な分岐をしなくても、式は自然にゼロになります。 入力用$n = 10, k = 11$、計算します$cnt = 0$したがって、両方の項が消滅し、結果は次のようになります。$0$、これは予想される解釈と一致します。 

もう 1 つのエッジケースは次のような場合です$k = 1$。 すべての整数は次で割り切れます$1$、 それで$cnt = n$。 式は次のようになります$2n^2 - n^2 = n^2$、すべてのペアが有効であることを意味します。 のために$n = 4, k = 1$、グリッドには$16$ペアであり、数式は正しく返されます$16$。 

最後の構造的なエッジ ケースは、包含と除外の重複が直観を支配する小さなグリッドです。 のために$n = 2, k = 2$、数字のみ$2$割り切れるので、$cnt = 1$。 式は次のようになります$2 \cdot 1 \cdot 2 - 1 = 3$。 ペアをリストすると、次のことが確認されます。$(2,1), (2,2), (1,2)$、正確に 3 つの有効なペア。減算により二重カウントが正しく削除されることを示しています。$(2,2)$。
