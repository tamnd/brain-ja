 ## 問題の理解

 このタスクでは、指定された数値と少なくとも 1 桁の 10 進数を共有する最小の非負の整数を見つけるように求められます。 すべてのテストケースに対して番号が提供されます`x`数値を生成する必要があります`y`ある数字が入るように`y`にも登場します`x`。 番号`y`できるだけ小さくする必要があります。 

入力は、最大 1000 個の複数のテスト ケースと各数値で構成されます。`x`これらの境界は控えめです。つまり、数値を文字列に変換したり、数値を反復処理したり、すべての 1 桁の数値を直接試したりするなどの単純な操作が可能です。 以来`x`は最大でも 4 桁の長さであるため、その桁をセットまたは配列に格納することはメモリの観点からは簡単です。 

考慮すべきエッジケースには、それ自体が 1 桁の数値が含まれます。 たとえば、次の場合`x = 7`、最小の`y`は`7`自体。 不注意なアプローチでは、ゼロから始まる数値をループしてそれぞれをチェックしようとする可能性があります。 これは機能しますが、やりすぎであり、次の事実を無視しています。`y`は常に次の数字の 1 つである必要があります`x`。 もう 1 つの微妙なケースは、次のようなゼロを含む数値です。`x = 102`、ここで最小値は`y`は`0`、 ない`1`または`2`必ず必要ですが、次の桁の中で最も小さいものは何でも`x`。 

## アプローチ

 ブルートフォースアプローチは、次から始めることです。`y = 0`そして、すべての数字を段階的にチェックして、数字が同じかどうかを確認します。`x`。 これを実装するには、両方の数値を文字列に変換し、各数字のペアが等しいかどうかをチェックします。 最悪の場合、`y`一致するものが見つかる前に 1000 に達する可能性があり、文字列比較を繰り返し行うと、このアプローチは必要以上に遅くなります。 指定された制約については合格しますが、エレガントでも概念的にも最小限ではありません。 

重要な洞察は次のとおりです`y`1 桁の数字のみである必要があります。`x`0 ～ 9 が存在し、その数字はすでに可能な最小値です`y`。 問題は、次の数字を抽出することに帰着します。`x`そして最小のものを返します。 これが機能するのは、1 桁の数値が負ではない最小の整数であるためです。そのため、最小の解は単に次の値に存在する最小の桁になります。`x`。 この洞察により、不必要な反復が回避され、テスト ケースごとに直接的な一定時間のソリューションが提供されます。

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る`t`、テストケースの数。 
2. 各テスト ケースについて、整数を読み取ります。`x`。 
3.変換`x`文字列に変換して、その数字を反復処理できるようにします。 
4. すべての数字を抽出します。`x`そしてそれらを整数に変換します。 
5. これらの整数の中から最小の桁を見つけます。 これが最小限です`y`と数字を共有するもの`x`。 
6. 現在のテスト ケースのこの最小桁を出力します。 

機能する理由: 任意の数`y`と数字を共有するもの`x`に存在する数字の 1 つが含まれている必要があります`x`。 0 ～ 9 の数字は整数の最小構成要素であるため、最小値は`y`の最小桁であることが保証されます`x`。 桁の外の数値は決して考慮しないため、この不変条件は常に真です。`x`、したがってこれ以上有効ではありません`y`存在することができる。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    x = input().strip()
    digits = [int(d) for d in x]
    print(min(digits))
```このソリューションは、まずテスト ケースの数を読み取ります。 各テスト ケースでは、数字を文字列に変換して簡単に数字を抽出し、比較のために各数字を整数に変換します。 最小桁はすぐに出力されます。 これにより、不要なループが回避され、先頭のゼロが正しく処理され、1 桁の数値と複数桁の数値の両方に機能します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        x = input().strip()
        digits = [int(d) for d in x]
        output.append(str(min(digits)))
    return "\n".join(output)

# Provided samples
