 ## 解決策
 ## 問題の理解

 2 つの整数配列が与えられています。`p`そして`s`、それぞれの長さ`n`。 配列`p`未知の配列のプレフィックス GCD を表します`a`、および配列`s`は、同じ配列のサフィックス GCD を表します。 タスクは、そのような配列かどうかを判断することです`a`存在します。 正式に言うと、`a`存在する場合、すべてのインデックスに対して`i`:```
p[i] = gcd(a[1], a[2], ..., a[i])
s[i] = gcd(a[i], a[i+1], ..., a[n])
```入力は最大 10^4 のテスト ケースで構成され、すべてのテスト ケースの合計`n`テスト ケース全体の値は最大 10^5 です。 これは、O(n^2) 時間では遅すぎるため、各テスト ケースをおよそ O(n) 時間で効率的に処理する必要があることを意味します。 

問題の明らかではない部分は、GCD 伝播の制約に起因します。 たとえば、プレフィックス GCD 配列`p`最初の要素が 1 になるまでは増加しない必要があります。同様に、`s`最後の要素から後方に向かって増加しない必要があります。 単純なアプローチでは、すべての候補配列を再構築しようとする可能性があります。`a`そして、指定されたものが生成されるかどうかを確認します`p`そして`s`、しかしこれは大規模な場合には不可能です`n`。 小規模なエッジ ケースには、すべてが一致する配列が含まれます。`p`値が等しいかすべて`s`値が等しい、および配列`1`それらはGCDの伝播に影響を与えます。 たとえば、次の場合`p = [2, 2, 2]`そして`s = [2, 2, 1]`の場合、すべての位置でプレフィックス GCD とサフィックス GCD の両方を満たす単一の配列は存在しないため、答えは「いいえ」です。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての配列を試行します。`a`と一致する`p`そして`s`。 それぞれのポジションで`i`で割り切れる整数を試すことができます。`p[i]`そして`s[i]`実行中のプレフィックスとサフィックス GCD を満たしながら。 これは原理的には正しいですが、可能な配列の数は組み合わせによって増加するため、非常に遅くなります。`n`。 と`n`10^5 までの場合、このアプローチは実用的ではありません。 

重要な洞察は、位置の価値です。`i`配列内`a`前のプレフィックス GCD (または`p[i]`それ自体) とそれに続く接尾辞 GCD (または`s[i]`）。 具体的には、次のように定義できます。`a[i]`の最小公倍数 (LCM) として`p[i]`そして`s[i]`。 以来`p[i]`プレフィックス GCD を分割し、`s[i]`接尾辞 GCD を除算して、`a[i] = lcm(p[i], s[i])`両方の GCD がその位置に保持されるようにします。 この候補配列を構築した後、プレフィックスとサフィックスの GCD を再計算し、それらが一致することを確認できます。`p`そして`s`。 これにより、問題は各ステップでの単純な演算による線形スキャンに縮小されます。

 ## アルゴリズムのチュートリアル

 1. 候補配列を初期化する`a`長さの`n`。 インデックスごとに`i`、 セット`a[i] = lcm(p[i], s[i])`。 推論は、これが両方で割り切れる最小数であるということです。`p[i]`そして`s[i]`、これにより、プレフィックスとサフィックスの GCD に必要な可分性が保持されます。 
2. プレフィックス GCD 配列を計算します`p_check`から`a`。 から始める`p_check[0] = a[0]`、それぞれについて`i`1から`n-1`、 セット`p_check[i] = gcd(p_check[i-1], a[i])`。 
3. サフィックス GCD 配列を計算します。`s_check`から`a`。 から始める`s_check[n-1] = a[n-1]`、それぞれについて`i`から`n-2`0まで下げる、設定する`s_check[i] = gcd(s_check[i+1], a[i])`。 
4. 比較する`p_check`と`p`そして`s_check`と`s`。 両方の配列が正確に一致する場合は、「YES」を出力します。 それ以外の場合は、「NO」を出力します。 

なぜ機能するのか: 不変条件は次のとおりです。`lcm(p[i], s[i])`インデックスのプレフィックスとサフィックスの両方の GCD で割り切れます。`i`。 GCD は結合性および可換性があるため、候補配列が各位置で割り切れない場合、再計算されたプレフィックスおよびサフィックス GCD は、有効な配列が存在する場合にのみ元の配列と一致します。 矛盾がある場合は、そのような配列が両方を満たすことができないことを示します。`p`そして`s`同時に。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        s = list(map(int, input().split()))
        a = [0] * n
        for i in range(n):
            a[i] = (p[i] * s[i]) // math.gcd(p[i], s[i])
        p_check = [0] * n
        s_check = [0] * n
        p_check[0] = a[0]
        for i in range(1, n):
            p_check[i] = math.gcd(p_check[i-1], a[i])
        s_check[-1] = a[-1]
        for i in range(n-2, -1, -1):
            s_check[i] = math.gcd(s_check[i+1], a[i])
        if p_check == p and s_check == s:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    main()
```このソリューションでは、LCM を使用して候補配列を構築し、プレフィックスとサフィックスの GCD を検証します。 整数除算を使用して LCM を効率的に計算し、浮動小数点エラーを回避します。 長さ 1 の配列や 1 に等しい値などの境界条件は自然に処理されます。`lcm(x, x) = x`そして`gcd(x, x) = x`。
