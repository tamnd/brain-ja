 ## 解決策
 ## 問題の理解

 一連の日が与えられ、それぞれが雨 (1) または晴天 (0) のいずれかにラベル付けされます。 ジーンはできるだけ多くのハイキングを完了したいと考えています。 それぞれのハイキングには正確な時間がかかります`k`好天が何日も続き、ハイキングを終えた後は、次のハイキングを始める前に少なくとも 1 日は休まなければなりません。 この問題では、一連の日数に収まる最大のハイキング回数を決定するよう求められます。 

入力は大きくなる可能性があります:最大`10^5`テストケースごとに最大数日`10^4`テスト ケース。テスト ケース全体の日数の合計が以下を超えない`10^5`。 これは、どのソリューションも日数に比例して直線的な時間で実行する必要があることを意味します。 日数の範囲にわたって反復する二次ループまたはネストされたループは遅すぎます。 

明らかではないエッジケースには、ハイキングの可能性を妨げる断続的な雨が降るシーケンス、`k`は、連続する好天日の数よりも大きく、すべての日が雨であるか、すべての日が良好であるシーケンスです。 たとえば、次の場合`n = 5`、`k = 2`、 そして`a = [0, 1, 0, 0, 0]`、あらゆることにジャンプする素朴な貪欲さ`k`途中の休憩を確認しない日が続くと、ハイキングの回数が過大にカウントされる可能性があります。 

## アプローチ

 強引なアプローチでは、毎日ハイキングを開始しようとします。`i`次かどうかを確認します`k`日々は順調です。 そうであれば、ハイキング回数を増やしてその日までスキップします`i + k + 1`次の上昇の可能性のために。 これが機能するのは、必須の休息日を尊重しているためです。 ただし、これには確認が必要です`k`考えられる開始日ごとに数日かかるため、最悪の場合の複雑さは次のとおりです。`O(n * k)`。 大型用`n`そして`k`、これは到達する可能性があります`10^10`容認できない操作です。 

重要な点は、重複するセグメントを繰り返し再チェックする必要がないということです。 代わりに、1 回のパスで連続した良好な日の数を数えることができます。 ブロックを見つけるたびに、`length`連続したゼロの場合、そのブロックで実行できるハイキングの数は`length // k`。 このブロック内の各ハイキングは、概念的に各ハイキングの後に「1」を配置して、使用可能な長さを効果的に削減できるため、当然のことながら必須の休憩日を尊重します。 これにより、問題はアレイの 1 回の線形スキャンに軽減され、制約を考慮すると最適です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * k) | お(1) | n と k が大きいと遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`count`現在のテスト ケースのハイク数を保存するには、ゼロに設定します。 変数を初期化する`length`現在の好調な日が連続して続いていることを追跡するには、ゼロに設定します。 
2. 配列内の毎日を繰り返します。 天気が良ければ(`a[i] = 0`)、増分`length`。 その日が雨の場合（`a[i] = 1`)、リセット`length`ゼロに。 これにより、次の不変条件が維持されます。`length`は常に、次で終わる現在の連続する良好な日のブロックを表します。`i`。 
3. いつでも`length`到達する`k`、ハイキングの計画を立てることができます。 インクリメント`count`1つずつ。 次に、強制的な休息日を強制するために、減分します。`length`による`k + 1`。 この減算では、ハイキングに使用した日数と休息日を実質的にスキップします。`length`残り数日で次の利上げの可能性をカウントする準備ができている。 
4. 配列の終わりまで反復を続けます。 反復の後、`count`テストケースの最大ハイキング数を保持します。 
5. 印刷`count`テストケースごとに。 

これが機能する理由は、アルゴリズムが連続する良好な日の長さを維持し、サイズのブロックがすべて満たされるたびに貪欲にハイキングをスケジュールするためです。`k`利用可能です。 引き算`k + 1`再スキャンやセグメントの重複を行わずに、次のハイキングで必須の休憩日が確実に守られるようにします。 有効なハイキングを怠ったり、ルールに違反したりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    count = 0
    length = 0
    for day in a:
        if day == 0:
            length += 1
            if length >= k:
                count += 1
                length -= k + 1
        else:
            length = 0
    print(count)
```最初の行はテスト ケースの数を読み取ります。 各テストケースについて、次のように読みます。`n`そして`k`そして配列`a`。 メイン ループは毎日反復され、現在の好天の連続記録を更新します。 ハイキングが可能であれば増額します`count`削減して休息日を強制する`length`。 リセットする`length`雨の日には、悪天候を伴うハイキングは絶対に行わないようにします。
