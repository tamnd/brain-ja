 ## 解決策
 ## 問題の理解

 すべての正の整数がノードであるグラフが与えられ、任意の 2 つのノードについて$x$そして$y$、それらを接続するコストは、それらの最小公倍数の異なる素因数の数によって決まります。 言い換えれば、いずれかの数値に現れるすべての素数を調べ、各素数を 1 回だけカウントし、そのカウントがエッジの重みになります。 

各クエリは、注目をノードの連続セグメントに限定します。$[l, r]$。 そのセグメントについては、上記のエッジの重みを持つノード上の完全なグラフを考慮し、すべてのノードを接続するための可能な最小コスト、つまり最小スパニング ツリーの重みを求められます。 

この制約は、非常に重要な点で異例です。 範囲のエンドポイントが次の範囲に達するまでの間、$10^6$まであります$5 \cdot 10^4$クエリの場合、すべてのセグメントの長さの合計は最大でも$10^6$。 これは、すべてのクエリ全体にわたって、整数ごとにほぼ線形の時間を費やすことができますが、単一の範囲で二次的なものは、大きな間隔ですぐに失敗することを意味します。 

素朴なアプローチはすべてを構築します$\binom{n}{2}$各クエリ範囲内のエッジを検索し、Kruskal または Prim を実行します。 単一のクエリのサイズであっても$10^5$、それはすでに暗示しています$10^{10}$エッジ、これは完全に不可能です。 オンザフライで素因数分解を再計算しながらクエリごとに標準 MST を実行しようとすると、別の障害モードが発生します。 平$O(n \sqrt{n})$クエリごとのサイズが大きすぎます。 

微妙なエッジケースは、次の定義から生じます。$\omega(1)=0$。 単一要素の範囲はゼロを返す必要があり、すべてのノードが少なくとも 1 つの素因数に寄与すると仮定する実装では、そのような場合に誤って過剰カウントが行われます。 

## アプローチ

 重要な問題は、エッジの重みが両方のエンドポイントの素構造に依存することです。これは、グラフが任意ではなく、隠れた因子ベースの構造を持っていることを示唆しています。 

ブルートフォース MST アプローチでは、内側のすべてのエッジが明示的に考慮されます。$[l,r]$、計算する$\omega(\mathrm{lcm}(x,y))$それぞれに対して、Kruskal を実行します。 MST は重み付きグラフ上で明確に定義されているため、これは正しいです。 問題はスケールです。各クエリには次のものが必要です。$O((r-l+1)^2)$エッジが増加し、全体の複雑さが限界をはるかに超えて爆発的に増加します。 

重要な観察は次のとおりです$\omega(\mathrm{lcm}(x,y))$の素因数の結合にのみ依存します$x$そして$y$。 これは、素数が独立して動作することを意味します。各素数は、少なくとも 1 つのエンドポイントに出現する場合、エッジのコストに 1 回だけ寄与します。 

これは視点を反転することを示唆しています。 エッジを原子オブジェクトとして考える代わりに、素数を、それを含むコンポーネントを接続するときに「アクティブ化」する必要があるリソースとして考えます。 それぞれの数字$x$固定素数セットを運ぶ$P(x)$、すべてのエッジ コストは、これらのセットの和集合のサイズになります。 

ここで構造を単純化します: あらゆる素数について$p$、で割り切れるすべての数値$p$料金を繰り返し支払わずに接続を実現できるグループを形成する$p$共有複数を介して接続している限り。 これは、効果的な MST 構築には「有用な隣接エッジ」 (2 つの数値が素因数を共有するか、共有素数の連鎖を通じてリンクされる) を考慮するだけでよいという考えにつながります。 完全なグラフの代わりに、素数対倍数の関係から構築された疎なグラフに縮小します。 

各数値について、その素因数のリストと各素数を事前計算します。$p$のすべての倍数を維持します。$p$。 固定範囲の場合、その範囲内の各素数の連続する倍数間のエッジのみが必要です。これは、冗長性を持たずにその素数を共有するすべてのノード間の接続を確保するには十分であるためです。 

これにより、範囲ごとのグラフ サイズが 2 次からほぼ線形に縮小され、すべての範囲の合計が制限されているため、関連するエッジのみでローカル DSU を使用して各クエリを独立して安全に処理できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 完全なグラフ上のブルート フォース MST |$O(n^2 \log n)$クエリごと |$O(n^2)$| 遅すぎる |
 | 素数ベースのスパース グラフ + クエリごとの DSU |$O(\sum r \log r)$全体 |$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 ### キーの前処理

 1. までのすべての数値の最小の素因数を計算します。$10^6$。 
2. すべての数値を因数分解する$x$その個別の素数セットに$P(x)$。 
3. 各素数について$p$、で割り切れるすべての数値のソートされたリストを保存します。$p$。 

### クエリ構造の構築

 1. クエリごとに$[l,r]$、その範囲内の数値のみを収集します。 
2. この間隔でインデックスに対して DSU を構築します。最初はコストがゼロです。 

### 候補エッジの生成

 1. 各素数について$p$、倍数のリストをスキャンし、その中にあるものだけを抽出します$[l,r]$。 
2. このフィルタリングされたリストを並べ替えて、連続する要素を接続します。 
3. 重みを付けて連続する要素間にエッジを追加する$\omega(\mathrm{lcm}(x,y))$。 

連続した要素のみを接続する理由は、大きなギャップ接続はコストを有利に増加させることなく、中間の倍数を介したチェーンによって支配されるためです。 

### MST の実行

 1. 生成されたエッジをすべて収集し、重みで並べ替えます。 
2. 現在の範囲で DSU を使用して Kruskal のアルゴリズムを実行します。 
3. 選択したエッジの重みを答えとして合計します。 

### なぜ効果があるのか

 重要な不変条件は、すべての素数に対して$p$、で割り切れる数値の誘導部分グラフ$p$ソートされた複数のリスト内の隣接する接続のみを使用して接続されます。 離れた倍数を直接接続しようとする MST はコストを改善できません。そのような接続は、素因数の和集合をすでに考慮されている以上に増やすことなく、中間倍数を介したチェーンに置き換えることができるからです。 

したがって、候補エッジ セットには、完全なグラフの二次爆発を回避しながら、すべての有益な MST 選択肢をシミュレートするのに十分な構造が含まれています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXN = 10**6

spf = list(range(MAXN + 1))
for i in range(2, int(MAXN ** 0.5) + 1):
    if spf[i] == i:
        for j in range(i * i, MAXN + 1, i):
            if spf[j] == j:
                spf[j] = i

def factor_distinct(x):
    res = []
    last = 0
    while x > 1:
        p = spf[x]
        if p != last:
            res.append(p)
            last = p
        while x % p == 0:
            x //= p
    return res

omega = [0] * (MAXN + 1)
for i in range(2, MAXN + 1):
    x = i
    last = 0
    cnt = 0
    while x > 1:
        p = spf[x]
        if p != last:
            cnt += 1
            last = p
        while x % p == 0:
            x //= p
    omega[i] = cnt

prime_pos = {}
for i in range(2, MAXN + 1):
    x = i
    seen = set()
    while x > 1:
        p = spf[x]
        seen.add(p)
        while x % p == 0:
            x //= p
    for p in seen:
        prime_pos.setdefault(p, []).append(i)

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.r[a] < self.r[b]:
            a, b = b, a
        self.p[b] = a
        if self.r[a] == self.r[b]:
            self.r[a] += 1
        return True

def lcm_omega(x, y):
    # recompute distinct primes of lcm via union
    sx = set()
    while x > 1:
        p = spf[x]
        sx.add(p)
        while x % p == 0:
            x //= p
    while y > 1:
        p = spf[y]
        sx.add(p)
        while y % p == 0:
            y //= p
    return len(sx)

T = int(input())
for _ in range(T):
    l, r = map(int, input().split())
    arr = list(range(l, r + 1))
    idx = {v: i for i, v in enumerate(arr)}
    n = len(arr)

    dsu = DSU(n)
    edges = []

    for p, lst in prime_pos.items():
        cur = [x for x in lst if l <= x <= r]
        for i in range(1, len(cur)):
            a = idx[cur[i - 1]]
            b = idx[cur[i]]
            w = lcm_omega(cur[i - 1], cur[i])
            edges.append((w, a, b))

    edges.sort()
    ans = 0
    for w, a, b in edges:
        if dsu.union(a, b):
            ans += w

    print(ans)
```このソリューションでは、最初に最小の素因数ふるいを構築します。これにより、高速な因数分解と計算が可能になります。$\omega(x)$。 各クエリは、セグメントに対して独自のローカル インデックス マッピングを構築し、そのセグメント上に DSU を構築します。 

各素数について、クエリ範囲内のすべての倍数を抽出し、連続する倍数を接続します。 これらのエッジは、そのプライムの接続貢献に必要な唯一のバックボーンを形成します。 次に、Kruskal は、これらのエッジを使用してすべてのコンポーネントをコストの昇順にマージします。 

実装の微妙な詳細は、クエリごとにインデックス マップを再構築することです。 これにより、グローバルなインデックス作成の複雑さが回避され、DSU がコンパクトに保たれます。これは、範囲の合計の制約を考慮すると重要です。

これは、Kruskal がグローバル MST にマージする接続エッジに各プライムがどのように独立して寄与するかを示しています。

 ## 特殊なケース

 サイズ 1 の範囲の場合、$[7,7]$の場合、DSU はエッジをアクティブにすることはなく、答えはゼロのままです。これは、接続が必要ないことを正しく反映しています。 

すべての数値が素数である範囲の場合、次のようになります。$[2,11]$、各ノードは別個の素数グループに属しているため、エッジは共有構造から間接的にのみ発生します。 各素数が独立して寄与し、クラスカルが必要な接続のみを選択するため、アルゴリズムは引き続き正しく動作します。 

次のような単一の素数のべき乗によって支配される範囲の場合$[8,32]$、その素数のフィルタリングされたリストは密なチェーンを形成し、連続エッジ構造により最小限の冗長性で完全な接続が保証されます。
