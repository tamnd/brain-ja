 ## 解決策
 ## 問題の理解

 私たちには非常に大きなものが与えられています$n \times m$グリッドですが、そのほとんどは、次のセットを除いて空です。$k$「壁」。 各壁は垂直セグメントであり、柱全体をブロックします。$y$行から$x_1$に$x_2$。 ブロックされたセルはすべて通行できなくなり、残りはフリー セルになります。 

重要な構造的約束は、すべての自由セルが接続された領域を形成するということです。 したがって、どの空のセルからでも、他の空のセルにアクセスできます。 問題は到達可能性ではなく、パスの一意性です。空のセルの各ペアについて、それらの間に単純なパスが 1 つだけ存在するでしょうか。 

これは、空のセルによって形成されるグラフがグラフ理論の意味でツリーであるかどうかを尋ねることに相当します。ここで、各セルはノードであり、エッジは 4 方向に隣接する空のセルを接続します。 接続されたグラフには、サイクルがない場合に限り、ノードの各ペアの間に一意の単純なパスがあります。 

したがって、問題は、すべての壁セルを除去した後に、誘導されたグリッド グラフにサイクルが含まれているかどうかを確認することになります。 

制約の次元は極端です。$n, m \le 10^9$したがって、グリッドを明示的に構築することはできません。 私たちが使用できる唯一の構造は、$k \le 10^5$垂直方向のブロックされたセグメント。 

これにより、セルごとまたは行ごとのシミュレーションが即座に除外されます。 行ごとのスイープでも慎重に圧縮する必要があります。 唯一管理可能な表現は、グリッドを壁によって引き起こされる意味のある構造イベントに圧縮することです。 

壁が互いに回り込む「細い廊下」を形成すると、微妙なエッジケースが現れます。 たとえば、2 つの独立した垂直壁があると、パスが両側に迂回することになり、サイクル状の廊下が形成される可能性があります。 「各列が独立している」などの単純な考えは、水平方向の動きが列をグローバルに接続するため、すぐに失敗します。 

もう 1 つのエッジ ケースは、投影では壁が重なっているが実際には接触しておらず、二重グラフ内でサイクルを形成する交互の通路を作成する場合です。 どのソリューションでも、ローカルでブロックされたセグメントではなく、接続構造についてグローバルに推論する必要があります。 

## アプローチ

 ブルートフォースアプローチは、グリッドグラフを明示的に構築し、ブロックされたセルをマークし、サイクル検出 (DFS または Union-Find) を実行することです。 これは、隣接関係を直接モデル化し、エッジが 2 つの既に接続されているコンポーネントを接続するかどうかを検出するため、概念的に機能します。 

ただし、グリッドには最大で$10^{18}$したがって、空のセルを反復処理することさえ不可能です。 たとえ壁がまばらだったとしても、空きスペースはあまりにも大きいままです。 

重要な観察は、グリッドが平面であり、垂直セグメントのみがブロックされていることです。 これは、複雑さが壁の水平境界に沿ってのみ導入されることを意味します。 各壁セグメントは柱を自由空間の間隔に分割し、柱間の水平方向の隣接によってサイクルが作成される可能性があります。 

セルを個別に表示するのではなく、連続する壁の端点間の各行間隔を「コリドー構造」として表示します。 各壁の端点は垂直方向のアクセスのしやすさに変化をもたらし、トポロジにとって重要なのはこれらの端点のみです。 

私たちは問題を「イベント」によって形成されるグラフに還元します。壁を含む各柱について、自由な垂直セグメントの間隔を追跡し、隣接する柱間の隣接性によって間隔間の接続が引き起こされます。 この構造は垂直カットによって引き起こされる平面グラフのように動作し、サイクルの存在はイベント ノード間を横断する複数の方法を検出することと同等です。 

すべてのエンドポイントを圧縮した後、スイープ ライン全体の接続性 (定式化に応じて x または y による) をシミュレートし、隣接する垂直ストリップ間のコンポーネントを維持できます。 重要なのは、各壁セグメントが導入する境界イベントは最大 2 つであるため、全体の複雑さは変わらないということです。$O(k)$。 

次に、Union-Find を使用して各行スライス内の隣接する空きセグメントを接続し、サイクルを作成する方法ですでに接続されているコンポーネントを接続しようとするユニオンがあるかどうかを確認します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(nm)$|$O(nm)$| 不可能 |
 | 最適 (圧縮スイープ + DSU) |$O(k \log k)$|$O(k)$| 承認済み |

 ## アルゴリズムのチュートリアル

 中心となるアイデアは、壁の端点を使用して行に沿ってグリッドを圧縮し、連続するイベント行間の各水平ストリップを列間の単純な 1D 接続問題として扱うことです。 

1. 壁の端点からすべての個別の行境界を抽出します。 それぞれの壁ごとに$(x_1, x_2, y)$でイベントを作成します。$x_1$そして$x_2 + 1$。 これらは、垂直構造が変化するポイントを表します。 これが必要なのは、壁が開始または終了しない区間内では、ブロックされた構造が変化しないためです。 
2. すべての一意のイベント行をソートし、連続するペアを「水平レイヤー」として扱います。 各層内では、アクティブな壁のセットは一定であるため、自由空間構造は垂直方向に静的です。 
3. 各レイヤーについて、そのレイヤーでどの列がブロックされているかを維持します。 壁は垂直セグメントであるため、柱にある壁$y$の間のみ列全体をブロックします。$x_1$そして$x_2$。 レイヤーをスイープするときに、これらのブロックをアクティブ化または非アクティブ化します。 
4. 各層について、その層内で両方ともブロックされていない隣接する列間の接続を構築します。 すべての列を反復する代わりに、すべての列をソートすることで列を圧縮します。$y$- 壁に出現する座標をインデックスとして扱います。 これにより、意味のある境界のみを考慮することが保証されます。 
5. 各層内で、圧縮された列間隔にわたって Union-Find 構造を使用して、水平方向に隣接する空きセグメントを接続します。 別のパスを介してすでに接続されている 2 つのコンポーネントを結合するたびに、サイクルが検出されます。 
6. すべての層を処理した後、サイクルが検出されなかった場合、グラフはツリーであり、答えは「YES」です。 それ以外の場合は「NO」です。 

### なぜ効果があるのか

 境界間の空のスペースは内部構造を持たない単純な長方形であるため、グリッド内のすべてのサイクルは壁境界の有限セット内に含まれている必要があります。 壁が始まるか終わるすべての X 境界で圧縮することにより、すべてのトポロジ変化が少なくとも 1 つのレイヤーで確実にキャプチャされます。 各レイヤー内の接続は純粋に水平方向であり、どの列がブロックされるかによって完全に決定されます。 Union-Find は、水平方向の接続がループを閉じるかどうかを検出します。これは、まさにこの縮小された平面グラフにおけるサイクルの定義です。 すべての垂直遷移はレイヤー間で一貫して処理されるため、元のグリッド内のサイクルは少なくとも 1 つのレイヤーにサイクルとして表示される必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.r[a] < self.r[b]:
            a, b = b, a
        self.p[b] = a
        if self.r[a] == self.r[b]:
            self.r[a] += 1
        return True

def solve():
    n, m, k = map(int, input().split())
    walls = []
    ys = set()
    xs = set()

    for _ in range(k):
        x1, x2, y = map(int, input().split())
        walls.append((x1, x2, y))
        xs.add(x1)
        xs.add(x2 + 1)
        ys.add(y)

    xs = sorted(xs)
    ys = sorted(ys)

    x_id = {x:i for i, x in enumerate(xs)}
    y_id = {y:i for i, y in enumerate(ys)}

    events = [[] for _ in range(len(xs) + 1)]

    for x1, x2, y in walls:
        events[x_id[x1]].append((y_id[y], 1))
        events[x_id[x2 + 1]].append((y_id[y], -1))

    active = [0] * len(ys)

    for i in range(len(xs)):
        for y, t in events[i]:
            active[y] += t

        # build free segments in this layer
        dsu = DSU(len(ys))
        last = -1

        for j in range(len(ys)):
            if active[j] == 0:
                if last != -1:
                    if dsu.find(last) == dsu.find(j):
                        print("NO")
                        return
                    dsu.union(last, j)
                last = j
            else:
                last = -1

    print("YES")

def main():
    solve()

if __name__ == "__main__":
    main()
```このコードは、壁のアクティビティが変化するすべての X 境界上でスイープを実行します。 の`active`配列は、現在の水平レイヤーで現在ブロックされている圧縮列を追跡します。 各層内で、DSU を使用してブロックされていない連続する列を接続します。 すでに接続されている 2 つの空き位置が別の水平隣接チェーンを通じて再度マージされると、サイクルが検出されます。 

垂直方向の遷移によってブロックされる列が変わる可能性があるため、重要な実装の詳細は、すべてのレイヤー境界で水平方向のスキャンをリセットすることです。 

## 実用的な例

 ### サンプル 1

 壁の端点によって引き起こされるすべての X 境界をスイープします。 この構成ではループが作成されないため、各レイヤーの空き列が単一のチェーンを形成します。 

| レイヤー | アクティブなブロックされた列 | DSU のマージ | サイクル |
 | --- | --- | --- | --- |
 | 1 | なし | すべてのフリーカラムは直線的に接続されています。 いいえ |
 | 2 | なし | 線状構造が続く | いいえ |

 これは、この構造が 2 つのセル間に代替ルートのないツリー状のコリドー システムであることを裏付けています。 

### サンプル 2

 ここでは壁がグリッドを分割しているため、障害物の周囲に代替ルートが存在します。 

| レイヤー | アクティブなブロックされた列 | DSU のマージ | サイクル |
 | --- | --- | --- | --- |
 | 1 | 列 2 が部分的にアクティブです | 分割パスを作成します | いいえ |
 | 2 | 列 2 は異なる間隔でアクティブになります | 代替の水平接続が出現 | はい |

 ある層では、2 つの異なる水平チェーンが異なる垂直遷移を介して再接続され、ループが生成されるため、答えは NO です。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 |$O(k \log k)$| エンドポイントの並べ替えが優先され、DSU 操作は圧縮サイズで線形です。

## 特殊なケース

 主なエッジ ケースは、壁が別の壁のスパン内で別の柱内で始まり、終わる場合です。 局所的には 2 つの独立したバリアのように見えますが、全体的には迂回ループを作成します。 スイープ ラインの表現により、両方のエンドポイントが確実に処理されるため、両方の壁がアクティブなレイヤーで水平方向の接続分割が露出し、DSU がサイクルを検出できるようになります。 

もう 1 つの特殊なケースは、壁が端点でのみ接触している場合です。 セルのオーバーラップは存在しませんが、隣接グラフはコーナー接続を通じてループを形成します。 座標圧縮$x_2 + 1$エンドポイントの遷移が個別のレイヤーとして処理されるようにすることで、接触の瞬間が明示的に表現され、サイクルの検出漏れを防ぎます。
