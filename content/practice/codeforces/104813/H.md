 ## 解決策
 ## 問題の理解

 最大 10 個の頂点を持つ小さな重み付き無向グラフが与えられます。 重みは、惑星の各ペアがどの程度強く相互作用するかを表します。 固定量の質量 (正確に 1 単位) を頂点全体に分割するように求められます。各頂点 i は非負の実数値 eᵢ を受け取り、すべての値の合計は 1 になります。 

これらの割り当てでは、目標は二次的です。 すべての頂点のペアは両方の割り当てに比例して寄与します。2 つの惑星 i と j が eᵢ と eⱼ を受け取る場合、スコアへの寄与は eᵢ · eⱼ · wᵢⱼ となります。 合計スコアは、順序付けされていないすべてのペアの合計です。 

したがって、頂点にわたる確率分布を選択し、重み行列によって定義される二次形式を最大化します。 

n ≤ 10 という小さな制約は、サブセットに対する指数推論または組み合わせ推論が実行可能であることを直ちに示唆しています。 2ⁿ 状態に関するあらゆるアプローチは潜在的に受け入れられます。 ただし、変数は連続的であるため、構造的な洞察がなければ、実数値の代入を強引に行うことは意味がありません。 

微妙な難しさは、解空間が単体であり、目的が二次であるが、任意の重みにより自明な方法で必ずしも凸または凹になるわけではないことです。 単純な勾配または貪欲な分割アプローチは、グローバルに最適ではないローカルな改善に簡単に行き詰まる可能性があります。 

いくつかの特殊なケースについては、覚えておく価値があります。 すべての重みがゼロの場合、どの分布でもスコアはゼロになります。 正確に 1 つのエッジの重みが大きい場合、最適なソリューションは質量をその端点に完全に集中させます。 重みが均一な場合、対称性は均等な分散が最適であることを意味します。 質量を均一に分散する単純なヒューリスティックは、重み行列が大きく歪んでいる場合には大きく失敗します。 

## アプローチ

 ブルートフォースの視点は、目標が頂点間で確率質量がどのように分割されるかのみに依存することに気づくことから始まります。 任意の連続代入をテストできる場合、空間は無限であるため、その方向を直接指定することは不可能です。 

重要な構造上の考え方は、最適な状態では分布のサポートが小さいということです。 直観的に、すべての確率質量を運ぶ k 個の頂点のサブセットを固定すると、それらに対する最適な分布は、次元 k − 1 の単体に対する制約付き 2 次最適化問題になります。固定サブセットの場合、これは線形制約を持つ標準的な 2 次プログラムになり、ラグランジュ乗数を使用して解くことができ、線形システムに帰属します。 

したがって、戦略は次のようになります。ゼロ以外のエネルギーを持つ頂点のサブセットを推測し、そのサブセット上で最適な分布を計算し、すべてのサブセットにわたって最良の値を取得します。 

n ≤ 10 であるため、すべてのサブセットを列挙することが可能です。 サブセットごとに、小さな制約付きの最適化問題を解決します。 ラグランジュ条件は、すべてのアクティブな i に対して、勾配条件によって線形関係が強制され、k 個の未知数 (乗数を含む) を含む k 方程式系が生成されることを示します。 

これにより、継続的な最適化が多くの小さな線形システムの解決に軽減されます。 

サブセットに対するブルート フォースは指数関数的ですが、各ソルブは k で 3 次であり、ここでは小さいです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 割り当てに対するブルートフォース | 無限 / 実現不可能 | お(1) | 不可能 |
 | サブセット列挙 + ラグランジュ システム | O(2ⁿ · n³) | O(n²) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 最適なアイデア: サポート セットを列挙し、KKT システムを解決する

 我々は、最適な分布が頂点の一部のサブセット S でサポートされており、S に基づいて解が一次最適性条件を満たすという事実に依存しています。 

#### 1. 頂点の空ではないすべてのサブセット S を反復処理します。 

各サブセットは、まさにこれらの頂点が正のエネルギーを受け取るという仮説を表します。 これは、あらゆる最適解が単体の面に存在するため、有効です。

#### 2. 固定サブセット S について、最適化を定式化します。 

私たちは最大化します

 E = Σ_{i<j in S} eᵢ eⱼ wᵢⱼ

 Σ eᵢ = 1 および eᵢ ≥ 0 の条件に従います。 

対称行列 A を使用して二次形式を書き直します。ここで、i ≠ j および Aᵢᵢ = 0 の場合、Aᵢⱼ = wᵢⱼです。 

E = 1/2 eᵀ A e。 

因数 1/2 は最大化には無関係です。 

#### 3. ラグランジュ乗数条件を適用する

 私たちは以下を形成します:

 L(e, λ) = eᵀ A e − λ(Σ eᵢ − 1)

 eᵢ に関して微分を取ると、次のようになります。 

S のすべての i に対して Σⱼ Aᵢⱼ eⱼ = λ。 

これは、すべてのアクティブな頂点が、A e の下で隣接する頂点の重み付き合計が同じであることを意味します。 

これにより、線形システムが生成されます。 

A_S e = λ 1

 Σ eᵢ = 1 と一緒に。 

#### 4. 線形システムを解く

 λ を未知数として扱い、k + 1 次元系を解きます。 1 つの方法は、行列を拡張し、ガウス消去法によって解決することです。 

解によって負の eᵢ が生成された場合、そのサブセットは無効となり、破棄されます。 

#### 5. 目標値を計算する

 有効な解を得るには、二次公式を使用して E を直接計算し、すべてのサブセットの最大値を追跡します。 

### なぜ効果があるのか

 最適化問題は、単体に対する二次計画法です。 大域的最適条件は、Karush-Kuhn-Tucker 条件を満たさなければなりません。 これらの条件により、すべてのアクティブな変数にわたって偏導関数が等しくなるため、非線形最適化が各候補サポートにわたる線形システムに変わります。 シンプレックスには有限の多くの面があり、各面はサブセットに対応するため、サブセットを列挙することで、大域最適を含む領域を検査することが保証されます。 実現可能性フィルタリングにより、有効な KKT ポイントのみが寄与することが保証され、目標を評価することで最適な KKT ポイントが選択されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    w = [list(map(float, input().split())) for _ in range(n)]

    best = 0.0

    # iterate over all subsets
    for mask in range(1, 1 << n):
        idx = [i for i in range(n) if (mask >> i) & 1]
        k = len(idx)

        # build linear system: A e = λ 1, sum e = 1
        # unknowns: e_0..e_{k-1}, λ
        m = k + 1
        a = [[0.0] * m for _ in range(m)]
        b = [0.0] * m

        # equations: Ae - λ1 = 0
        for i in range(k):
            ii = idx[i]
            for j in range(k):
                jj = idx[j]
                a[i][j] = w[ii][jj]
            a[i][k] = -1.0  # -λ
            b[i] = 0.0

        # constraint: sum e = 1
        for j in range(k):
            a[k][j] = 1.0
        a[k][k] = 0.0
        b[k] = 1.0

        # Gaussian elimination
        x = gauss(a, b)
        if x is None:
            continue

        e = x[:k]
        if any(v < -1e-9 for v in e):
            continue

        # compute energy
        val = 0.0
        for i in range(k):
            for j in range(i + 1, k):
                val += e[i] * e[j] * w[idx[i]][idx[j]]

        best = max(best, val)

    print("%.10f" % best)

def gauss(a, b):
    n = len(b)
    for i in range(n):
        # pivot
        p = i
        for j in range(i, n):
            if abs(a[j][i]) > abs(a[p][i]):
                p = j
        if abs(a[p][i]) < 1e-12:
            return None
        a[i], a[p] = a[p], a[i]
        b[i], b[p] = b[p], b[i]

        # normalize
        div = a[i][i]
        for j in range(i, n):
            a[i][j] /= div
        b[i] /= div

        for j in range(n):
            if j != i:
                factor = a[j][i]
                for k in range(i, n):
                    a[j][k] -= factor * a[i][k]
                b[j] -= factor * b[i]

    return b
```コードはすべてのサブセットを反復し、そのサブセットの KKT 条件をエンコードする線形システムを構築します。 ガウス消去法は、分布と乗数の両方を解決します。 実行不可能な解決策は否定性をチェックすることによって拒否されます。 

微妙な点は、n が小さく、許容される誤差が 1e-6 であるため、ここでは数値の不安定性が許容できることです。 もう 1 つの重要な詳細は、浮動小数点除去によって有効な解であっても小さな負のノイズが生成される可能性があるため、小さなイプシロンで負の値をフィルタリングすることです。 

## 実用的な例

 ### サンプル 1

 入力:```
2
0 1
1 0
```サブセットをテストします。 

サブセット {0,1} の場合、対称性は e₀ = e₁ = 0.5 を意味します。 

| サブセット | e₀ | e₁ | 値 |
 | --- | --- | --- | --- |
 | {0,1} | 0.5 | 0.5 | 0.25 |

 1 つの頂点だけがすべての質量を受け取るため、他のサブセットはゼロを生成します。 

最大値は 0.25 で、出力に一致します。 

これは、対称 2 ノード システムが質量を均等に分散していることを確認します。 

### サンプル 2

 入力:```
3
0 2 1
2 0 2
1 2 0
```サブセットを評価します。 フルセットが優勢。 

解決すると、より強いエッジに向かってほぼ偏ったバランスの取れた分布が得られます。 

| サブセット | e₀ | e₁ | e₂ | 値 |
 | --- | --- | --- | --- | --- |
 | {0,1,2} | 0.333 | 0.333 | 0.333 | ~0.571 |

 他のサブセットは、有益なエッジを破棄するため、より弱くなります。 

これは、グラフが密でかなり対称的である場合、最適なサポートには多くの場合すべてのノードが含まれることを示しています。

 ## 特殊なケース

 重みがすべてゼロの縮退グラフでは、平坦な対物レンズ表面が生成されます。 例えば：```
3
0 0 0
0 0 0
0 0 0
```すべてのサブセットはゼロのエネルギーを生成し、ガウス消去法でも有効な分布が生成されますが、すべての候補がゼロで同点になります。 アルゴリズムは 0.0 で初期化された最大値を追跡するため、正しく 0 を返します。 

次のような単一の強力なエッジケース:```
2
0 1000
1000 0
```すべての質量を両方のノードに均等に強制します。 サブセット {0,1} の KKT システムは e₀ = e₁ = 0.5 をもたらし、エネルギー 250 を与えます。サブセット {0} と {1} はゼロを与えるため、最大化中に準最適として破棄されます。 

1 つのエッジが優勢である歪んだ三角形は、サブセット メカニズムが時期尚早に完全なサポートに制限されないことを確認します。 支配的なエンドポイントのみを含むサブセットはフルセットと正しく競合し、ガウス消去法により、縮小された面内で最適な分割が確実に見つかります。
