 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times n$もともと何らかの隠し配列から生成されたテーブル$a_1, a_2, \dots, a_n$。 テーブルのすべてのエントリは、この配列の 2 つの要素を乗算して形成されているため、行のセルは$i$、 カラム$j$等しい$a_i \cdot a_j$。 何らかの損傷があった後、対角線のエントリは消去され、ゼロに置き換えられましたが、対角線以外の製品はすべてそのまま残ります。 タスクは、指定されたテーブルを生成した可能性のある有効な元の配列を復元することです。 

主要な構造上の制約は、行列が偽装されてランク 1 であることです。つまり、すべての行は、隠れた配列のスケーリングされたバージョンにすぎません。 これは行全体にわたる強い代数的一貫性を意味しており、これを利用します。 

入力サイズ$n \le 1000$許可します$O(n^2)$行列の処理は可能ですが、考えられるすべての因数分解を試したり、セルごとに値を個別に再構築したりするようなことは除外されます。 各値は多くの方程式に出現するため、ソリューションでは個別のエントリではなく行間の関係を使用して配列を抽出する必要があります。 

対角線がゼロになるという事実から、微妙なエッジ ケースが発生します。 素朴な読者は次のようなものを使おうとするかもしれません$M_{ii}$回復する$a_i$, しかし、それらの値は役に立ちません。 もう 1 つの潜在的な間違いは、整合性チェックを行わずに単一行で十分であると想定することです。 浮遊する不一致があると、単純な再構成が壊れてしまいます。 

たとえば、推測しようとすると、$a_1$他のすべてを次から導き出します$M_{1j} / a_1$、間違った約数を選択しています$a_1$誤ったスケーリングが配列全体に伝播する可能性があります。 正確かどうかは、一貫したアンカーを選択し、すべての値が一致するかどうかに依存します。 

## アプローチ

 強引なアイデアは、非表示配列の 1 つの値を推測して、他の値をすべて導出するというものです。 選ぶとしましょう$a_1$。 次に、最初の行から次のようになります$a_j = M_{1j} / a_1$。 問題は、導出されたすべての値が整数であるかどうか、およびそれらが完全な行列を再現するかどうかを確認することになります。 考えられる値をすべて試してみると、$a_1$は実現不可能です。$a_1$複数の制約によって間接的に暗示される任意の約数を指定でき、行列の値は最大で次のようになります。$10^9$したがって、単純な列挙は非常に高価になります。 

重要な観察は、実際には何も推測する必要がないということです。 有効なインデックスのペア$(i, j)$与える$M_{ij} = a_i a_j$。 3番目の指標も見てみると$k$、次のようになります。$$M_{ij} \cdot M_{ik} = (a_i a_j)(a_i a_k) = a_i^2 a_j a_k$$そして同様に:$$M_{ii} \text{ is missing, but we can avoid it entirely.}$$代数的消去法ではなく、次の点に注意するのがきれいなトリックです。$$a_i = \sqrt{\frac{M_{ij} \cdot M_{ik}}{M_{jk}}}$$あらゆる異なるものに対して$i, j, k$、 以来：$$M_{ij} = a_i a_j,\quad M_{ik} = a_i a_k,\quad M_{jk} = a_j a_k$$最初の 2 つを乗算し、3 番目で割ると分離されます。$a_i^2$。 

これにより、すべての値を計算する直接的な方法が得られます。$a_i$3 行のみを使用して、行列全体との整合性を検証します。

 ## アルゴリズムのチュートリアル

 まず信頼できる値を 1 つ抽出し、次にすべてを決定論的に再構築することでソリューションを構築します。 

1. 任意の 3 つの異なるインデックス (通常は 0、1、2) を選択します。これらを使用するのは、対角要素に依存せずに安定した方程式系が得られるためです。 
2. コンピューティング$a_0$ID を使用して:$$a_0 = \sqrt{\frac{M_{01} \cdot M_{02}}{M_{12}}}$$これが機能するのは、分子が次のようになるためです。$a_0^2 a_1 a_2$そして分母は削除します$a_1 a_2$。 
3. 1回$a_0$既知であるため、1 つおきに回復します$a_j$使用:$$a_j = \frac{M_{0j}}{a_0}$$これは次のことから直接導き出されます。$M_{0j} = a_0 a_j$。 
4. 完全な配列を構築した後、次のことを確認してマトリックス全体の一貫性を検証します。$$a_i \cdot a_j = M_{ij}$$すべてのペアに$(i, j)$。 これにより、算術エラーや無効な平方根が見逃されることがなくなります。 
5. 再構成された配列を出力します。 

### なぜ効果があるのか

 すべてのエントリはそのベクトルの 2 つの成分の積であるため、行列は単一の隠れベクトルによって完全に決定されます。 3 つのインデックスを使用する比率トリックでは、すべての値が正の整数であるため、不明瞭な 1 の 2 乗を曖昧さなく分離します。 1 つの値が固定されると、他の値はすべて同じスケーリングまで一意に決定され、スケーリングは相対的な比率ではなく実際の行列エントリを使用して解決されます。 すべてのペアにわたる一貫性により、復元されたベクトルは元の構造と正確に一致する必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    M = [list(map(int, input().split())) for _ in range(n)]
    
    i, j, k = 0, 1, 2
    
    # compute a[i]
    num = M[i][j] * M[i][k]
    den = M[j][k]
    a0_sq = num // den
    a0 = int(a0_sq ** 0.5)
    
    # fix possible rounding issues (guaranteed perfect square)
    if (a0 + 1) * (a0 + 1) == a0_sq:
        a0 += 1
    
    a = [0] * n
    a[i] = a0
    
    for t in range(n):
        if t != i:
            a[t] = M[i][t] // a[i]
    
    print(*a)

if __name__ == "__main__":
    solve()
```再構成は必然的にペアごとの関係に依存するため、解決策は完全な行列を読み取ることから始まります。 非縮退を保証するために、インデックス 0、1、および 2 を選択します。 

コアの計算では、三重積恒等式を使用して以下を導き出します。$a_0^2$、整数の平方根を取ります。 すべての値が有効な乗法構造を形成することが保証されているため、除算は正確であり、完全な二乗が生成されます。 

1 つのアンカー値を回復した後、配列の残りの部分が最初の行から直接計算され、各エントリが回復された値で除算されます。$a_0$。 このステップは、行 0 が正確に一致するという不変条件に依存します。$a_0$隠れベクトルの倍。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべての値が 1 に等しい場合です。行列は対角部分を除いて完全に 1 になります。 アルゴリズムは計算します$a_0^2 = 1$、平方根を取得し、除算の問題なくすべての 1 を正しく回復します。 

もう 1 つのエッジ ケースは、値が大きくても完全に一貫性がある場合です。たとえば、最大値が近くにある非表示の配列などです。$10^9$。 乗算ステップ$M_{ij} \cdot M_{ik}$到達できる$10^{18}$ただし、Python はこれを安全に処理し、構造によって割り算が保証されているため、整数の割り算は正確なままになります。 

3 番目のエッジ ケースは、対称性またはスケーリングの曖昧さのために複数の有効な再構成が存在する場合です。 この問題では何でも許されるので、
