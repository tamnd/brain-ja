 ## 解決策
 ## 問題の理解

 各頂点が都市を表し、各都市が固定値を持つ、接続された無向グラフが与えられます。 アレックスは特定の都市から開始し、エッジを横断することによってグラフ内を歩きますが、1 つの制限があります。使用したばかりのエッジに沿ってすぐに戻ることは許可されていません。 言い換えれば、彼がそこから去った場合、$u$に$v$、から次のステップに進むことはできません$v$に戻る$u$、再訪問するのは自由ですが、$u$後で別のパスを経由します。 

どの都市もその価値を合計に反映しますが、それは最初に訪れたときのみです。 都市を再訪問しても特別な価値はありませんが、グラフの他の部分に到達するのに役立つ場合があります。 

目標は、最初の都市から始めてアレックスが訪問できるすべての個別の都市の値の合計を最大化することです。$s$、パスが即時のエッジ反転のないウォークであるという制約の下で。 

制約$n, m \le 2 \cdot 10^5$すべてのウォークを明示的に探索するソリューションは除外されます。 パスをエッジまたは頂点のシーケンス上の状態として扱うアプローチは、指数関数的に爆発的に増加します。 有効なソリューションでは、グラフの構造を、通常は線形または線形に近い時間で、反復された走査が要約される形式に圧縮する必要があります。 

貪欲に考えると、微妙な問題が発生します。ローカルで値の高い近傍を最初に取得すると、サイクルをバックトラックする理由を慎重に検討しない限り、グラフの領域での走査がトラップされ、他のコンポーネントへのアクセスが永久にブロックされる可能性があります。 別の障害モードは、関節点を含むグラフで発生します。異なる方向からノードを再訪問すると、異なるサブグラフのロックが解除されます。 

誤解を招く貪欲な状況の簡単な例は、サイクルに接続されたチェーンです。サイクルに入るのが早すぎると、サイクル内でサイクルが繰り返され、カットされた頂点から大きなサブツリーが失われる可能性があります。 

## アプローチ

 直接的な総当たり解釈では、問題を状態空間のウォーク検索として扱います。$(v, p)$、 どこ$v$は現在の都市であり、$p$前の都市です。 各州から、次の場合を除く近隣の州に移動できます。$p$。 移動するたびに訪問ノードのセットが変更される可能性があるため、単純な検索では訪問ノードのサブセットを追跡する必要があり、これによりすぐに次のような結果が得られます。$O(2^n)$複雑。 

訪問済みセットを無視してパスのみを検索した場合でも、状態グラフは次のようになります。$O(m)$次までに分岐する州$d$、指数関数的な数の四球を生み出します。 これは不可能です。 

重要な観察点は、この制約は即時のバックトラッキングのみを禁止し、一般的なサイクルは禁止しないということです。 これは、グラフの二重接続領域 (関節点のないコンポーネント) に入ると、ほぼ自由に領域を横断できることを意味します。瞬時に方向を反転しない限り、どのエッジも複数回使用できます。 このようなコンポーネント内では、すべてのノードがサイクルを通じて相互に到達できるため、コンポーネントに入ると、そのすべての頂点を収集できます。 

これにより、当然のことながら、グラフが二重接続コンポーネントに圧縮されます。 各コンポーネントは、関節点を介して接続された「サイクル可能な塊」のように動作します。 縮小後、構造はコンポーネントのツリーになります。 次に、トラバーサルはツリー DP 問題になり、開始コンポーネントからどの隣接コンポーネントに入るかを決定します。 

最終的な解決策は、次のコンポーネントを含むコンポーネントから開始してこのコンポーネント ツリーをたどることにより、達成可能な最大合計を計算することになります。$s$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 散歩に対するブルートフォース O(2^n) | O(n) | 遅すぎる |
 | ツリー上の二重接続コンポーネント + DP | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. DFS ベースのローリンク アルゴリズムを使用して、グラフを二重結合コンポーネントに分解します。 各頂点は 1 つ以上のコンポーネントに属しますが、各エッジは 1 つのコンポーネントに属するものとして扱います。 目的は、即時のバックトラッキング制約が関係することなく、サイクルによって無制限のトラバースが許可される最大のサブグラフを特定することです。 
2. 各コンポーネントがノードであり、関節頂点を共有するコンポーネントをエッジで接続するコンポーネント グラフを構築します。 このグラフは木か森ですが、元のグラフがつながっているので木になります。 
3. 各コンポーネントに、その内部のすべての頂点の値の合計を割り当てます。 これは有効です。なぜなら、コンポーネントに入ると、サイクルを横断する機能により、コンポーネント内のすべての頂点に確実にアクセスできるからです。 
4. 開始都市を含むコンポーネントでコンポーネント ツリーをルートします。$s$。 問題は、このルートから到達可能なコンポーネント値の最大合計を見つけることになります。 
5. ルートからツリーの走査を実行します。 すべてのコンポーネント値は負ではないため、到達可能なすべてのコンポーネントを含める必要があります。 唯一の制限は、ツリーを介した構造的な到達可能性です。 

重要な点は、二重接続分解で複数の DFS エッジに属する頂点を二重にカウントしないようにする必要があることです。 標準のエッジベースのコンポーネント割り当てでは、これを回避します。 

### なぜ効果があるのか

 不変条件は、各二重接続コンポーネント内で、いずれかの頂点に到達すると、「即時エッジ反転なし」ルールに違反することなく、そのコンポーネント内のすべての頂点に到達可能になるということです。 再訪問が必要な領域を分離できる唯一の障壁は、アーティキュレーション ポイントです。 このような各最大領域を単一のノードに縮小することで、冗長な内部構造を排除しながら領域間の到達可能性を維持します。 結果として得られるツリーの走査は、元のグラフ内のすべての実行可能なウォークを正確に反映しますが、繰り返される内部の動きは区別されません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n, m = map(int, input().split())
w = [0] + list(map(int, input().split()))

g = [[] for _ in range(n + 1)]
edges = []

for i in range(m):
    u, v = map(int, input().split())
    g[u].append((v, i))
    g[v].append((u, i))
    edges.append((u, v))

s = int(input())

tin = [0] * (n + 1)
low = [0] * (n + 1)
timer = 0
st = []
comp_id = [-1] * (n + 1)
comp_cnt = 0

comp_nodes = []

def dfs(v, pe):
    global timer, comp_cnt
    timer += 1
    tin[v] = low[v] = timer
    st.append(v)

    for to, ei in g[v]:
        if ei == pe:
            continue
        if not tin[to]:
            dfs(to, ei)
            low[v] = min(low[v], low[to])
        else:
            low[v] = min(low[v], tin[to])

    # articulation boundary for biconnected component
    if pe != -1:
        if low[v] >= tin[v]:
            comp_cnt += 1
            comp_nodes.append([])
            while True:
                x = st.pop()
                comp_nodes[comp_cnt - 1].append(x)
                if x == v:
                    break

dfs(s, -1)

# any remaining nodes
while st:
    x = st.pop()
    if comp_cnt == 0:
        comp_cnt = 1
        comp_nodes.append([])
    comp_nodes[comp_cnt - 1].append(x)

# assign component sums
comp_sum = [0] * comp_cnt
node_comp = [-1] * (n + 1)

for i in range(comp_cnt):
    for v in comp_nodes[i]:
        node_comp[v] = i
        comp_sum[i] += w[v]

cg = [[] for _ in range(comp_cnt)]

for u, v in edges:
    cu, cv = node_comp[u], node_comp[v]
    if cu != cv:
        cg[cu].append(cv)
        cg[cv].append(cu)

start = node_comp[s]

visited = [False] * comp_cnt
ans = 0

stack = [start]
visited[start] = True

while stack:
    c = stack.pop()
    ans += comp_sum[c]
    for to in cg[c]:
        if not visited[to]:
            visited[to] = True
            stack.append(to)

print(ans)
```この実装では、まず低リンク DFS を実行して、二重接続されたコンポーネントを抽出します。 スタックは現在の DFS パスを維持し、低リンク状態が分離を示すと、完全なコンポーネントがポップされます。 コンポーネントの形成後、各頂点がそのコンポーネントにマッピングされ、コンポーネントの重みが頂点値の合計として計算されます。 

次に、各コンポーネントがノードとなる圧縮グラフを構築します。 最後に、開始コンポーネントからの単純な DFS/BFS により、到達可能なすべてのコンポーネントの重みが蓄積されます。 

主な実装リスクは、スタックを使用して二重接続コンポーネントを正しく形成し、各ノードが 1 回だけ割り当てられるようにすることにあります。 もう 1 つのデリケートな部分は、DFS のルートの処理です。これには、トラバース後に残りのスタック コンテンツをフラッシュする必要があります。

 ## 特殊なケース

 クリティカルなエッジケースは純粋なサイクルです。 この場合、すべての頂点は単一の二重接続コンポーネント内にあります。 DFS スタックは決して分割されないため、サイクル全体がマージされ、答えはすべてのノードの合計になります。 これは、アレックスが即時後戻り禁止ルールに違反することなく無限に横断できるという事実と一致します。 

もう 1 つの重要なケースは木です。 すべてのエッジがブリッジになるため、実装に応じて、各頂点は事実上、独自のコンポーネントまたは自明なペアの一部になります。 から始まる$s$、圧縮されたグラフは同じツリーになり、トラバーサルは到達可能なすべてのノードを単純に収集します。 グラフはつながっているので、すべてのノードが集まります。 

最後に、値の高いサブツリーが 1 つの関節点を介してのみ到達できるグラフを考えてみましょう。 分解により、そのアーティキュレーション ポイントに到達すると、サブツリー コンポーネント全体へのアクセスが自動的に許可され、元のグラフでの貪欲なパス選択による損失が防止されます。
