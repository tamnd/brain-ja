 ## 問題の理解

 有限の正の整数のセットが与えられていますが、そこから構築する構造は無限です。 すべての整数は頂点であり、セット内の各数値は「距離タイプ」として解釈されます。 あらゆる価値観に対して`d`セットでは、絶対差が正確に一致するすべての整数のペアを接続します。`d`。 

それでそれぞれ`d`単一のエッジを作成するのではなく、整数ラインを横切る無限のエッジ ファミリを作成し、間隔をあけたすべての整数間に制約を効果的に強制します。`d`。 

タスクは、結果として得られる無限グラフが 2 部構成になるように、セットからできるだけ少ない数値を削除することです。これは、すべての整数が 2 つの色で着色され、すべてのエッジが反対の色に接続されることを意味します。 

主な制限は、`n ≤ 200000`、それぞれの数値は次のように大きくなります。`10^18`。 これにより、グラフ自体の構築が即座に排除されます。 選択した値が 1 つであっても`d`すでに無限に多くのエッジを誘発しているため、解決策は純粋に算術構造上で機能する必要があります。 

素朴な解釈では、グラフについて直接推論しようとします。 たとえば、各色によって引き起こされる制約に基づいて貪欲に色を割り当てることを考えるかもしれません。`d`、しかし複数の間で競合します`d`値はグローバルに現れる可能性があり、より深い構造がなければローカルに解決できません。 

2 番目の微妙な故障モードは、パリティの直感のみから生じます。 奇数のみが重要である、またはすべての奇数またはすべての偶数を削除すれば十分であると推測する人もいるかもしれません。 これはすぐに失敗します。 たとえば、`{1, 2, 3}`、葉だけをすべて偶数に保ちます`{2}`それは問題ありませんが、`{1, 3}`どちらも奇数であっても動作します。 本当の制約は数値自体のパリティではなく、それらが引き起こす gcd のパリティ構造です。 

隠された構造は、それぞれの選択された距離です。`d`無限ラインに周期的なカラーリングの制約を強制し、これらの周期性に互換性がない場合にのみ競合が発生します。 

## アプローチ

 単一の距離を選択すると`d`、グラフは異なる整数を接続します。`d`。 これは無限のパスの結合であり、各パスはステップのあるチェーンです`d`。 このようなグラフは 2 部構成です。パリティによって整数に色を付けることができます。`x / d`。

重要な洞察は、この問題を、可分性構造に対するパリティの一貫性の問題として再解釈することです。 サブセットを選択すると`S`の場合、グラフは 2 部要素になります。`S`記号を割り当てることができます`+1 / -1`一貫して、すべての`d`有効なパリティ伝播を強制します。 これは、乗算パリティ構造に基づいて数値セットを 2 つのグループに分割できるかどうかをチェックすることになります。 

重要な単純化は、2 の累乗が異なる数値の存在だけが重要であるということです。 すべての数字を次のように書きます`d = 2^k * t`どこ`t`奇数です。 奇数の部分は基本制約クラスを決定し、2 の累乗は互換性を決定します。 

奇数部分が異なる 2 つの数値は独立して相互作用するため、奇数部分でグループ化できます。`t`。 

各グループ内では、2 の最大累乗のみを考慮します。 同じ奇数グループに複数の値を保持する場合、最大値のみが`k`パリティ制約を強制する場合、より小さいべき乗は冗長であるため、重要です。 

したがって、各奇数に対して、`t`、すべての数値を単一の代表値に圧縮します。`2^{k_max} * t`。 問題は、グローバルな一貫性を確保しながら、これらの代表者の一部を選択することに帰着します。 唯一残っている障害は、選択されたすべての代表がパリティの伝播に矛盾を生じさせてはいけないということです。つまり、互換性のないパリティ レベルが混在しないサブセットを選択することになります。 

最適な戦略は次のようになります。`t`、最大値を持つ要素のみを保持します`v2`指数。 これらの候補のうち、唯一の競合は、それらの候補を比較することによって引き起こされる異なるパリティ クラスの混合によって発生します。`k`。 これを、パリティに対する 2 部構成の選択としてモデル化できます。`k`。 保持される要素を最大化するために、パリティのより大きなクラス (偶数または奇数) を保持します。`k`）、残りを削除します。

 ## アルゴリズムのチュートリアル

 1. すべての数値を因数分解する`d = 2^k * t`、 どこ`t`奇数です。 これにより、数値間の相互作用を定義する構造コンポーネントが分離されます。 
2. 数値を奇数部分でグループ化する`t`。 各グループ内では、最大指数のみを追跡します。`k`。 小さい指数は大きい指数よりも強い制約を作成しないため、これで十分です。 
3. 奇数グループごとに、単一の代表者を作成します。`(t, k_max)`。 
4. これらの代表者を等価性に基づいて 2 つのクラスに分割します。`k_max`(偶数または奇数)。 これが重要な削減です。グローバル互換性に影響するのは指数のパリティのみです。 
5. 一貫性を維持しながら残りの要素を最大化したいため、保持する 2 つのクラスのうち大きい方を選択します。 
6. 選択したクラスにないすべての代表を削除された要素として出力します。 

### なぜ効果があるのか

 各値は、整数に対する周期的なパリティ制約を定義します。 奇数成分は独立したサブシステムを決定し、2 のべき乗はパリティ 反転がどのように伝播するかを決定します。 削減されると、制約間の競合は、それらの指数パリティが一致するかどうかのみに依存します。 両方のパリティ クラスが混在すると、誘発される 2 カラーリングに矛盾が生じます。 したがって、パリティ クラスを 1 つだけ保持することで二部性が保証され、より大きなクラスを選択することで削除が最小限に抑えられます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    arr = list(map(int, input().split()))

    groups = {}

    # step 1: compress by odd part, keep max power of two
    for x in arr:
        k = (x & -x).bit_length() - 1
        t = x >> k
        if t not in groups:
            groups[t] = (k, x)
        else:
            if k > groups[t][0]:
                groups[t] = (k, x)

    # step 2: split by parity of k
    even = []
    odd = []

    for t, (k, x) in groups.items():
        if k % 2 == 0:
            even.append(x)
        else:
            odd.append(x)

    # step 3: keep larger group
    if len(even) >= len(odd):
        keep = set(even)
    else:
        keep = set(odd)

    # step 4: output removed elements
    removed = [x for x in arr if x not in keep]

    print(len(removed))
    print(*removed)

if __name__ == "__main__":
    solve()
```このコードは、2 のべき乗係数を効率的に計算するために、最初に最も低い設定ビットを分離します。 各数値は、可能な限り最も強い 2 のべき乗成分が保存された状態で奇数の底に圧縮されます。 次に、この指数のパリティによって代表を分割し、支配的な側を選択します。 

微妙な点は、出力では入力セットからの元の要素が期待されるため、圧縮された表現ではなく、出力に対して元の値を保存する必要があることです。

 ## 特殊なケース

 重要なエッジケースは、すべての数値が同じ奇数コンポーネントを共有する場合です。`{1, 2, 4, 8}`。 この場合、決定全体は指数パリティ分割に帰着します。 アルゴリズムはすべてを以下にグループ化します`t = 1`で分割します。`k % 2`一貫した二部構成の選択を保証します。 

もう 1 つのケースは、すべての数値が奇数である場合です。`{3, 5, 7}`。 ここにすべて`k = 0`したがって、すべてが同じパリティ クラスに分類されます。 このアルゴリズムはすべての要素を保持し、何も削除しません。これは、競合するパリティ構造が導入されないため有効です。 

3 番目のケースは、複数の奇数グループが存在する場合です。`{2, 3, 6, 12}`。 各グループは独立して処理され、代表間の同等の一貫性のみが問題となります。 グループ化ステップにより相互干渉が防止され、単純なアプローチにより無関係なコンポーネントが誤って結合される場合でも正確さが保証されます。
