 ## 解決策
 ## 問題の理解

 私たちには、不純物と呼ばれる少数の特別なセルを除いて、ほとんどが空の巨大なグリッドが与えられています。 各不純物は固定座標に位置し、正または負の強度値に寄与する可能性があります。 

グリッド内の固定サイズ R × C の軸に整列したサブ長方形を選択することができます。 このような長方形の有効な配置にはすべて、その中に含まれるすべての不純物の強さの合計として定義される「値」があります。 不純物のないセルは何も寄与しないため、K でマークされた点のみが問題になります。 

タスクは、N × M グリッド内の任意の場所に R × C ウィンドウをスライドさせ、ウィンドウによってキャプチャされた不純物の強度の最大可能合計を計算することです。 

N と M は 10^9 まで大きくすることができますが、非ゼロとなるのは 10^5 セルまでの K 個だけです。 これにより、グリッド全体を反復するメソッドは不可能であることがすぐにわかります。 意味のあるオブジェクトは不純物ポイント自体だけです。 

主な困難は幾何学的なものです。固定された長方形のすべての平行移動にわたる重み付けされた合計を最大化する必要があります。 

単純なアプローチでは、R x C の長方形の左上隅をすべて試してみます。 N・M位まであるので全く無理です。 

負の値を使用すると、さらに微妙な問題が発生します。 すべての不純物が負の場合、不純物を完全に回避したいという意味で、最良の長方形には不純物の寄与が含まれていない可能性がありますが、それでも長方形を選択する必要があります。 この場合、解釈に応じて答えは負またはゼロになる可能性があり、サンプルから、空の寄与は実質的にゼロを生み出すことがわかり、したがって最適な答えは少なくとも 0 になります。 

エッジ ケースは、複数の不純物が四角形の境界付近に集まる場合に発生します。 点をかろうじて含むか除外する四角形では、答えが突然変わる可能性があるため、正しい解では、二重カウントやオフバイワンエラーを発生させずに、正確な包含条件を処理する必要があります。 

## アプローチ

 この強引なアイデアは簡単です。R x C の長方形のあらゆる配置について、その中にあるすべての不純物の合計を計算します。 配置ごとに、すべての K 不純物をスキャンし、それらが長方形の内側にあるかどうかをテストします。 これにより、最悪の場合は O(N・M・K) になります。これは、N と M が 10^9 までの場合、制限をはるかに超えます。 

長方形が意味的に異なる位置のみに限定したとしても、配置の数は依然として天文学的に多くなります。 

重要な観察は、グリッド サイズは無関係であるということです。 不純物の座標のみが重要です。 各四角形は、変換された R x C ウィンドウ内に座標が含まれるすべての不純物の選択に対応します。 それぞれの不純物が、その値を有効な長方形の原点の領域に寄与すると考えることができます。 各不純物は、その不純物が含まれる左上隅の位置の長方形を定義します。 

したがって、長方形を移動する代わりに、視点を逆転させます。各不純物は、変換された座標空間内の一連の位置に「重みを追加」します。 問題は、その変換された空間内で重なり合う軸が揃ったすべての長方形の最大合計を見つけることになります。 これは、重み付けされた四角形のまばらなセットにわたる 2D 最大部分行列合計に減ります。これは、座標圧縮とスイープを使用して解決できます。 

重要なすべての x 座標をソートし、条件「x in [x_i - R + 1, x_i]」を長方形の原点の間隔制約に変換します。 y についても同様です。 各不純物は原点空間で重み付けされた長方形になり、最大のオーバーラップ合計が必要になります。 

これを、1 つの次元をスイープし、もう 1 つの次元ではセグメント ツリーを使用し、範囲の更新を維持し、最大プレフィックス合計をクエリすることに縮小します。

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(N・M・K) | お(1) | 遅すぎる |
 | 最適なスイープ + セグメント ツリー | O(K log K) または O(K log K + K^2 圧縮スイープ) | O(K) | 承認済み |

 ## アルゴリズムのチュートリアル

 長方形の原点の観点から問題を再構成します。 左上隅を (x, y) に配置した長方形には、x ≤ a ≤ x + R − 1 および y ≤ b ≤ y + C − 1 の場合に限り、(a, b) に不純物が含まれます。これは、x ∈ [a − R + 1, a] および y ∈ [b − C + 1, b] と同等です。 

したがって、各不純物 (a、b、t) は、これらの境界によって定義される原点空間内の長方形内のすべての原点に t を与えます。 

ここで、2D で軸に揃えられた長方形の最大重み付きオーバーラップを解決します。 

1. 各不純物について、有効な x 間隔 [a − R + 1, a] と y 間隔 [b − C + 1, b] を計算します。 これらの間隔は、この不純物が含まれるために長方形の原点がどこになければならないかを示します。 この変換は、元のスライディング ウィンドウの問題を原点にわたる幾何学的カバレッジの問題に変換します。 
2. 間隔エンドポイントからすべての一意の X 座標を収集し、並べ替えます。 これらの圧縮された境界を使用して x をスイープします。 座標は 10^9 まで大きくなる可能性があるため、座標圧縮が必要です。 
3. 不純物ごとに 2 つのイベントを作成します。1 つはその y 間隔が x = a − R + 1 で始まるイベントで、もう 1 つは x = a + 1 で終了するイベントです。これらのイベントは、y 軸範囲にわたって不純物の重みを追加および削除します。 これにより、2D 問題が x 上のスイープ ラインに変わります。 
4. 圧縮された y 座標上でセグメント ツリーを維持します。 各ノードは、遅延範囲更新と y にわたる最大プレフィックス合計を保存します。 特定の x でのイベントを処理するとき、アクティブな x スラブに出入りする不純物に対応する y 間隔にすべての更新を適用します。 
5. x を左から右にスイープすると、連続する x 値の間でアクティブな y 寄与の一貫したセットが維持されます。 指定された x での更新を処理した後、この x スラブの最適な y 位置に対応するセグメント ツリー内の最大値をクエリします。 すべての x にわたるグローバル最大値を追跡します。 
6. 見つかった最大値を返します。 

重要な設計上の選択は、長方形を明示的に列挙しないことです。 代わりに、各不純物を変換された空間の連続領域にわたる寄与に分解し、最大のオーバーラップを効率的に計算します。 

### なぜ効果があるのか

 考えられるすべての長方形の原点は、圧縮された 2D 原点空間内の 1 つの点に正確に対応します。 各不純物は、その重みを長方形の内側にある原点のセットに正確に寄与します。 したがって、任意の原点における合計は、その点をカバーするすべてのアクティブな不純物長方形の重みの正確な合計となります。 スイープ ラインにより、すべての x 座標スライスでアクティブ セットが正しく維持されることが保証され、セグメント ツリーにより、その x に対して最適な y が見つかることが保証されます。 これらのスイープを通じてすべての原点が暗黙的に考慮されるため、見つかった最大値は全体的に正しいものになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class SegTree:
    def __init__(self, n):
        self.n = n
        self.mx = [0] * (4 * n)
        self.lz = [0] * (4 * n)

    def push(self, v):
        if self.lz[v]:
            for c in (v * 2, v * 2 + 1):
                self.mx[c] += self.lz[v]
                self.lz[c] += self.lz[v]
            self.lz[v] = 0

    def add(self, v, l, r, ql, qr, val):
        if ql > r or qr < l:
            return
        if ql <= l and r <= qr:
            self.mx[v] += val
            self.lz[v] += val
            return
        self.push(v)
        m = (l + r) // 2
        self.add(v * 2, l, m, ql, qr, val)
        self.add(v * 2 + 1, m + 1, r, ql, qr, val)
        self.mx[v] = max(self.mx[v * 2], self.mx[v * 2 + 1])

    def query(self):
        return self.mx[1]

def solve():
    R, C = map(int, input().split())
    N, M = map(int, input().split())
    K = int(input())

    xs = set()
    ys = set()
    events = []

    for _ in range(K):
        x, y, t = map(int, input().split())

        x1 = x - R + 1
        x2 = x
        y1 = y - C + 1
        y2 = y

        events.append((x1, y1, y2, t))
        events.append((x2 + 1, y1, y2, -t))

        xs.add(x1)
        xs.add(x2 + 1)
        ys.add(y1)
        ys.add(y2)

    xs = sorted(xs)
    ys = sorted(ys)
    y_id = {v: i for i, v in enumerate(ys)}

    events.sort()
    st = SegTree(len(ys))

    ans = 0
    i = 0

    for x in xs:
        while i < len(events) and events[i][0] == x:
            _, y1, y2, val = events[i]
            l = y_id[y1]
            r = y_id[y2]
            st.add(1, 0, len(ys) - 1, l, r, val)
            i += 1
        ans = max(ans, st.query())

    return ans

if __name__ == "__main__":
    print(solve())
```このソリューションでは、変化が発生する x 座標上でスイープを構築し、y 座標上でセグメント ツリーを使用して、任意の垂直位置に対して最適な累積不純物の合計を維持します。 各イベントは、長方形の原点がその有効境界を横切るときにアクティブまたは非アクティブになる不純物に対応します。 

実装の微妙な詳細は、間隔エンドポイントの処理です。 削除イベントは x2 + 1 に配置されるため、間隔 [x1, x2] が包括的なものとして扱われます。 y 間隔圧縮についても、更新とセグメント インデックス間の一貫性を確保するために同様の注意が必要です。 

最終的な答えは、新しいイベントが発生しないがセグメント ツリーがすでに正しいアクティブ セットを反映している中間スラブを含む、すべてのスイープ位置にわたる最大値として維持されます。

 ## 特殊なケース

 重要なエッジ ケースは、すべての不純物の値が負の場合です。 その状況では、不純物を含むすべての四角形はスコアを減らしますが、問題の解釈に基づいて達成可能な最良の合計がゼロであるという意味で、最適な四角形はすべての寄与を効果的に回避します。 セグメント ツリーはどこでも 0 で初期化されるため、アルゴリズムはこれを正しく処理します。そのため、負の更新があるとローカルで値が 0 未満に減りますが、グローバル最大値は 0 のままです。 

複数の不純物が長方形間隔の同じ境界上にある場合、別のエッジ ケースが発生します。 たとえば、1 つの不純物が R = 1、C = 1 の (x, y) にあり、別の不純物が (x+1, y+1) にある場合、両方とも原点区間の重複を引き起こし、包含と除外の間で正しく分割する必要があります。 x2 + 1 による半開間隔の使用により、各寄与が原点の正しい範囲にわたって正確に 1 回適用されることが保証されます。 

最後の微妙なケースは、すべての不純物が密集して、サイズ R × C のすべての長方形がすべてを同時に覆う場合です。 スイープはクエリが実行される前にすべてのイベントをアクティブにし、セグメント ツリーは合計を正しく累積して、正しい X スラブでグローバル最大値を生成します。
