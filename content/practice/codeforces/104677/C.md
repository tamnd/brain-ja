 ## 解決策
 ## 問題の理解

 私たちには、何人かのグループが与えられ、それぞれがいくつかのケーキのスライスを持っています。 ケーキが完全に分割されていた場合、スライスの総数は人数で割り切れることが保証されているため、各人はまったく同じ数のスライスを受け取ることになります。 

課題は、この理想的な均等配分に適合しない人が何人いるかを判断することです。 つまり、1 人あたりの平均スライス数を計算し、その値と異なる人が何人いるかを数えます。 

入力は小さな整数配列で、出力は単一の整数、つまり値が平均と等しくない位置の数です。 

人数、スライス数ともに最大10なので、入力サイズが非常に小さくなります。 これにより、配列を 1 回通過する以上に高度なデータ構造や最適化が必要なくなります。 

すべての値がすでに等しい場合、微妙な特殊なケースが発生します。 その場合、答えはゼロになるはずです。 もう 1 つの特殊なケースは、人間が 1 人だけ存在する場合です。これは、「平均」がその人の価値にすぎないため、やはり答えはゼロになります。 

単純な間違いは、計算された平均と直接比較するのではなく、再分配操作を再計算またはシミュレートすることです。 これは不必要であり、慎重に扱わないと丸めや整数の除算エラーが発生する可能性があります。 

## アプローチ

 強引な解釈では、全員が平等になるまでスライスを再分配し、そのプロセス中に変更された人の数を数えることになります。 平衡に達するまでペア間の移動をシミュレートできます。 ただし、ここでは制約が小さいとはいえ、そのアプローチは基本的に不必要であり、問​​題の構造を曖昧にしてしまいます。 

重要な観察は、各人の最終的な正しい値は固定されており、一意に決定されるということです。つまり、それは単純に合計を N で割ったものになります。分布プロセスをシミュレートする必要はありません。 この目標値がわかれば、問題は配列の各要素との直接比較に減ります。 

これにより、問題はプロセス シミュレーションから単純な集計とカウントのタスクに変換されます。 この強引なアイデアは、再分配が最終的には均一性につながるため、概念的には機能しますが、最終的な質問とは無関係な余分な状態変更を導入するため、方法としては失敗します。

 | ブルートフォースシミュレーション | O(k・N²) 以上 | O(N) | 遅すぎる/不必要 |
 | 直接比較 | O(N) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### ステップ

 1. 人数 N とスライス数のリストを読み取ります。 
2. すべてのスライスの合計を計算します。 これは、参加者全員に分配されたフルケーキを表します。 
3. 1 人当たりのスライスの目標数を、合計を N で割った値として計算します。これは、問題条件により整数であることが保証されています。 
4. カウンタをゼロに初期化します。 
5. 各人のスライス数を繰り返します。 
6. 各個人について、自分の値を目標値と比較します。 
7. 値が異なる場合は、カウンターをインクリメントします。 
8. 最終的なカウンタ値を出力します。 

それぞれの比較により、その人が公平な配分から逸脱しているかどうかが直接わかるため、中間の変換は必要ありません。 

### なぜ効果があるのか

 合計制約により、公平なシェアを表す一意の整数値が存在することが保証されます。 公平性は純粋にこの導出定数との等価性によって定義されるため、すべての不正確なケースは、その定数と等しくない要素が 1 つだけ存在します。 このアルゴリズムは、ターゲット値がグローバルに正しく、順序や要素間のローカルな関係に依存しないという不変条件に依存します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    a = list(map(int, input().split()))
    
    target = sum(a) // n
    ans = 0
    
    for x in a:
        if x != target:
            ans += 1
    
    print(ans)

if __name__ == "__main__":
    solve()
```実装はアルゴリズムを直接翻訳したものです。 最も重要な詳細は、すべての要素を合計した後、整数除算を使用してターゲットを計算することです。 この問題では割り切れることが保証されているため、浮動小数点の処理や丸めの必要はありません。 

ループは単純に不一致をカウントします。 仕分けや追加の保管は必要ありません。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    a = list(map(int, input().split()))

 ## 特殊なケース

 1 人の場合は次のように入力します`1\n5`、アルゴリズムは合計 5、ターゲット 5 を計算し、不一致は検出されず、0 が生成されます。これは、N = 1 の場合に公平性の定義が正しく縮退していることを確認します。 

次のようなすでに均一な配列の場合`3\n2 2 2`の場合、計算されたターゲットは 2 であり、すべての比較が成功するため、カウンターは全体を通して 0 のままになります。 これにより、アルゴリズムが冗長チェックや整数除算の問題により、等しい構成に誤ってフラグを立てていないことが検証されます。
