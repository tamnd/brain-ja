 ## 解決策
 ## 問題の理解

 単一の整数が与えられます`n`、そしてステートメントはそれを保証します`n`それ自体はフィボナッチ数です。 任務は代表することです`n`3 つのフィボナッチ数の合計として。 3 つの値は繰り返すことができ、シーケンスが次で始まるため、ゼロも有効なフィボナッチ数です。`F0 = 0`。 

この問題は最初は数論の探索問題のように聞こえますが、制約によって状況は完全に変わります。 の値`n`よりも小さいです`10^9`これは、フィボナッチ数列に関連する数値がほとんど含まれていないことを意味します。 フィボナッチ値は指数関数的に増加するため、以下のフィボナッチ数は約 45 個のみになります`10^9`。 すべてのフィボナッチ値に対する 3 次総当たり法でも、まだ十分に小さいでしょう。 

最も危険な間違いは、定理を考えすぎることです。 このステートメントは、分解を証明または検索する必要があることを示唆しようとしていますが、入力はフィボナッチ数であることがすでに保証されています。 これにより、すぐに簡単な構造が作成されます。 

たとえば、入力が次の場合:```
5
```それから：```
0 0 5
```3 つの数値はすべてフィボナッチ数であり、その合計は次のとおりであるため、 はすでに有効です。`5`。 

もう一つの簡単な間違いは、それを忘れることです`0`フィボナッチ数列の一部です。 不用意に実装すると、次から始まるフィボナッチ数が生成される可能性があります。`1, 1`これにより、次のような有効な回答が誤って拒否されてしまいます。```
1
```正しい出力は次のようになります。```
0 0 1
```3 番目の微妙なケースは最小値です。```
0
```正しい出力は次のとおりです。```
0 0 0
```実装によっては、ゼロ自体がフィボナッチ数であるにもかかわらず、誤ってゼロを特別な不可能なケースとして扱ってしまうことがあります。 

## アプローチ

 ブルートフォースアプローチは簡単です。 まず、次の値までのすべてのフィボナッチ数を生成します。`10^9`。 シーケンスは急速に増加するため、このリストには要素が約 45 個しかありません。 次に、すべてのトリプルを試してください`(a, b, c)`そして、次のことを確認してください。```
a + b + c = n
```検索スペースが小さいため、これが機能します。 その周り`45^3 ≈ 91,000`2 秒以内の組み合わせは完全に許容されます。 

ブルート フォースはフィボナッチ数の考えられるすべての組み合わせを明示的にチェックするため、正しいです。 ここでの問題はパフォーマンスではなく、不必要な複雑さです。 私たちはステートメントが実際に要求するよりもはるかに難しい問題を解決しています。 

重要な観察は、入力自体がフィボナッチ数であることが保証されていることです。 ゼロもフィボナッチなので、いつでも次のように書くことができます。```
n = 0 + 0 + n
```これにより、考えられるすべての入力に対して有効な構造が即座に得られます。 検索、動的計画法、または数理論機構は必要ありません。 

問題は実際に、最も単純で有効な表現に気づくかどうかをテストすることです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k3) | O(k) | 承認済み |
 | 最適 | お(1) | お(1) | 承認済み |

 ここ`k`は以下のフィボナッチ数の数です`10^9`、およそ45。 

## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`。 
2. 合計が以下に等しい 3 つのフィボナッチ数を出力します。`n`。 
3.以来`0`はフィボナッチ数であり、`n`はフィボナッチ数であることが保証されており、出力は次のようになります。```
0 0 n
```1. この構造は次の理由から常に機能します。```
0 + 0 + n = n
```3 つの項はすべて有効なフィボナッチ数です。 

### なぜ効果があるのか

 正確さは問題の保証から直接得られます。 フィボナッチ数列にはゼロが含まれており、入力`n`もシーケンスに属することが保証されています。 このアルゴリズムは正確に 3 つのフィボナッチ数を出力し、それらの合計は必要なターゲットに等しくなります。 この構築が失敗する入力はありません。

プログラムは指定されたフィボナッチ数を読み取り、すぐに出力します。`0 0 n`。 ステートメントはすでに次のことを保証しているため、フィボナッチ数列を生成したり、何かを検証したりする必要はありません。`n`フィボナッチです。 

微妙な点の 1 つは、ゼロを有効なフィボナッチ数として扱う必要があることです。 建設全体はその事実に依存します。 シーケンスは から始まるように定義されているため、`F0 = 0`、出力は常に正当です。

import io
