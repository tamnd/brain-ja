 ## 解決策
 ## 問題の理解

 私たちは、ニムが整数配列の連続した部分配列でプレイしたゲームの複数ラウンドを考慮するように求められます。 それぞれの整数は石の山を表します。 ゲームは標準的な Nim ルールに従います。2 人のプレイヤーが順番に、空でない山から少なくとも 1 つの石を取り除き、移動できないプレイヤーが負けます。 各ラウンドでは、最初のプレイヤー (Artem) は固定されており、2 番目のプレイヤー (Ruslan) は、少なくとも 1 つの山が残っている限り、ゲーム開始前に山全体を削除することができます。 課題は、ルスランが勝利を保証しながら削除できる山の最大数と、それらの山を選択できる明確な方法が何通りあるかを決定することです。 

問題の入力では、最大 100,000 個の整数の配列と、この配列のセグメントを指定する最大 100,000 個のクエリが与えられます。 各整数は最大 50 であるため、パイル サイズは小さくなります。 この制約は、各セグメントを単純に線形時間で処理するソリューションは、特に杭のすべてのサブセットを削除対象として考慮する場合、セグメントの長さに応じてサブセットの数が指数関数的に増加するため、遅すぎることを意味します。 事前計算と、クエリを効率的に処理するための賢い組み合わせまたはビットごとのトリックを使用するソリューションが必要です。 

サイズがゼロの杭というエッジ ケースからは、微妙な点が 1 つ生じます。 セグメント内のすべての山がゼロの場合、Artem は何も動かずに開始し、すぐに負けます。そのため、Ruslan は山を削除する必要がありません。 もう 1 つの注意が必要なケースは、セグメントの Nim-sum がすでにゼロである場合に発生します。 ルスランがアルテムのニムサムをゼロにするのに十分な山を取り除くことができなければ、勝利を保証することはできません。 不注意な実装では、最初のプレーヤーの負けの位置を維持するために、ゼロの山を削除することと 1 つ以上の山を削除することの区別を見落とす可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、セグメント内の空でないパイルのサブセットをすべて列挙し、各サブセットの Nim-sum を計算し、Ruslan が勝利を強制できるかどうかを判断します。 ある長さのセグメントの場合`m`、これは確認が必要です`2^m - 1`サブセット。 と`m`最大 100,000 になる可能性がありますが、これは計算上不可能です。 

重要な観察は、Nim には強力な特性があるということです。つまり、すべてのパイル サイズの XOR がゼロの場合にのみ、ポジションが失われます。 ルスランは、残りの山のニムサムがゼロになるようにすることで、アルテムを負けの立場に追い込むことができます。 したがって、セグメントごとに、残りの山の XOR がゼロになるように削除する最大のサブセットを見つける必要があります。 これにより、問題はビット単位の XOR 組み合わせ問題に帰着します。セグメント内の各パイル サイズの頻度を追跡し、パイル サイズのセットに対して GF(2) に対するガウス消去法を使用して、どのサブセットがゼロ XOR 和を形成できるかを決定します。 ウェイの数は、基底内の線形独立した選択肢の数に対応します。 

各杭サイズと小さな最大杭値にプレフィックス XOR 配列を使用する (`a_i ≤ 50`)、任意のセグメント内の各数値の数を効率的に計算できます。 次に、複数セットのパイル サイズに対してガウス消去法を実行します。 これにより、すべてのサブセットを直接列挙することが回避され、複雑さが指数関数的なものから大まかなものに軽減されます。`O(n * 50)`クエリごとに。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^m * m) | O(m) | 遅すぎる |
 | 最適 (XOR 基準 + 周波数) | O(50 * q + n * 50) | O(n * 50) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 0 ～ 50 の各パイル サイズのプレフィックス数を事前計算します。インデックスごとに`i`配列内で、`cnt[i][x]`何回保存するか`x`から発生します`a[0]`に`a[i]`。 これにより、セグメント内の各パイル サイズの頻度を数値ごとに O(1) で取得できます。 
2. クエリごとに`(l, r)`、プレフィックス数を使用して、セグメント内の各パイル サイズの頻度を計算します。 これにより、セグメントが複数の数値セットとしてコンパクトに表現されます。 
3. サイズが 6 ビット (50 < 64 であるため)、または実装に応じて最大 50 ビットの空の XOR 基底配列を初期化します。 セグメントの各数値を XOR ベースに挿入します。 GF(2) のガウス消去法は、達成可能なすべての XOR 合計を表す線形独立要素の基礎を維持します。 
4. すべてのパイルの XOR を使用して、セグメント全体の Nim-sum を計算します。 XOR が 0 の場合、そのセグメントは既に Artem に負けており、Ruslan は少なくとも 1 つを残しながら最大数の山を取り除くことができます。 ウェイの数は、1 つの山を残すサブセットの選択に対応します。 これは`segment_length`すべての山が個別である場合の方法。 
5. XOR がゼロでない場合は、XOR がゼロになるようにパイルを削除してみてください。 これは、XOR が合計 Nim-sum に等しいマルチセットのサブセットを見つけることと同じです。 XOR ベースを使用して、合計 XOR を達成できる独立した選択肢の数を数えます。 このサブセットのサイズによって、残すことができる杭の数が決まります。 取り外し可能な杭の最大数は`segment_length - minimal_subset_size`。 方法の数は、`2^(number_of_free_basis_elements)`モジュロ 998244353。 
6. 合計と XOR するサブセットが存在しない場合は、-1 を出力します。 
7. 各クエリの結果を出力します。 

不変条件は、すべてのステップで、XOR 基底がセグメントからの達成可能なすべての XOR 合計を表すということです。 ガウス消去法により、考えられるサブセットの合計を見逃さないことが保証され、除去可能なパイルの最大数は常にゼロ XOR を残す最小サブセット サイズを減算することによって計算されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def xor_basis(numbers):
    basis = []
    for num in numbers:
        for b in basis:
            num = min(num, num ^ b)
        if num:
            basis.append(num)
    return basis

def solve():
    n, q = map(int, input().split())
    a = list(map(int, input().split()))
    
    prefix_count = [[0] * 51 for _ in range(n+1)]
    for i in range(1, n+1):
        for x in range(51):
            prefix_count[i][x] = prefix_count[i-1][x]
        prefix_count[i][a[i-1]] += 1
    
    for _ in range(q):
        l, r = map(int, input().split())
        freq = [prefix_count[r][x] - prefix_count[l-1][x] for x in range(51)]
        
        elements = []
        for x in range(51):
            elements.extend([x] * freq[x])
        
        total_xor = 0
        for num in elements:
            total_xor ^= num
        
        if total_xor == 0:
            max_remove = len(elements) - 1
            ways = len(elements)
            print(max_remove, ways % MOD)
            continue
        
        basis = xor_basis(elements)
        can_make = 0
        xor_check = total_xor
        for b in sorted(basis, reverse=True):
            if xor_check >= b:
                xor_check ^= b
        if xor_check != 0:
            print(-1)
            continue
        # maximum removable is total - minimal subset forming XOR
        max_remove = len(elements) - 1  # at least one remains
        ways = 1 << (len(elements) - len(basis))
        print(max_remove, ways % MOD)

if __name__ == "__main__":
    solve()
```コードはまず、効率的な頻度クエリのためにプレフィックス カウントを構築します。 セグメントごとに、マルチセットを再構築し、合計 XOR を計算し、XOR 基底を構築して、Ruslan がゼロ Nim-sum を強制できるかどうかを確認します。 ウェイの数は、基底に制約されない自由な要素の数から来ます。 微妙な点には、少なくとも 1 つの杭が残っていることを確認すること、XOR がすでにゼロになっているセグメントを処理することが含まれます。
