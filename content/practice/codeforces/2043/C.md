 ## 問題の理解

 ほぼすべての要素が次のいずれかである配列が与えられます。`1`または`-1`、最大 1 つの要素を任意の整数にすることができます。 私たちのタスクは、連続する部分配列のすべての個別の合計を見つけることです。 部分配列の合計は、単にその要素の合計です。 この問題では、空の部分配列の合計を含め、テスト ケースごとにこれらの合計を昇順で生成するよう求められます。これには常に空の部分配列の合計が含まれます。`0`。 

入力制約は重要です。 各配列には最大で次のものを含めることができます`2 * 10^5`すべてのテスト ケースにわたる要素の合計数は次を超えません。`2 * 10^5`。 これにより、考えられるすべてのサブ配列を個別に調べようとする単純な解決策が即座に排除されます。なぜなら、長さの配列内のサブ配列の数は`n`は`O(n^2)`。 もし`n`大きいため、約`4 * 10^10`1 秒の制限時間では実行不可能な最悪の場合の操作。 

エッジケースは主に、そうではない可能性のある異常な要素から発生します。`1`または`-1`。 たとえば、配列が次の場合、`[1, -1, 100]`、のみを想定した素朴なアプローチ`1`そして`-1`以下を含むサブ配列が欠落します`100`。 もう 1 つの注意が必要なシナリオは、すべてを含む配列です。`1`またはすべて`-1`s; ここで、部分配列の合計は単純な等差数列を形成しており、空の部分配列または順序を正しく処理しないと数え間違いが発生しやすくなります。 

## アプローチ

 ブルートフォースアプローチでは、開始インデックスと終了インデックスのすべてのペアに対して反復処理が行われます。`(i, j)`部分配列の合計を計算します`a[i..j]`、各合計をセットに格納します。 これは正しいことが保証されていますが、次のことが必要です。`O(n^2)`テストケースあたりの時間は遅すぎます`n`できる`2 * 10^5`。 

最適化するための重要な洞察は、アレイの構造から得られます。 おそらく 1 つを除くすべての要素は`1`または`-1`、例外要素のない部分配列の合計は予測可能な範囲内に収まります。 具体的には、次のシーケンスに対して、`k`すべてである要素`1`または`-1`、可能な合計は次からの連続する整数です。`-k`に`k`そばにいて`2`。 例外的な要素が存在する場合、配列をこの要素の周りのセグメントに分割し、単純な等差数列プロパティを使用して各セグメントの合計を計算し、これらの合計を例外的な要素と組み合わせることができます。 これにより、すべての部分配列を個別に生成することから問題が軽減され、範囲の計算とそれらの結合が線形時間で実行できるようになります。

 ## アルゴリズムのチュートリアル

 1. 現在のテスト ケースのすべての個別の部分配列の合計を格納するセットを初期化します。 含む`0`空の部分配列の場合。 
2. 配列を走査して例外要素が 1 つあるかどうかを特定し、それを呼び出します。`x`。 存在する場合は、その位置に注意してください`pos`。 
3. プレフィックスの合計を左から次まで計算します。`pos-1`各要素が`1`または`-1`。 これにより、連続した範囲の合計が得られます`[-count_neg..count_pos]`。 
4. から始まる右からプレフィックスの合計を計算します。`pos+1`同様に、別の範囲の合計を与えます。 
5. 例外的な要素が存在する場合は、追加して新しい合計を生成します。`x`左側のセグメントの各合計に加算したり、右側のセグメントの合計と結合したりすることができます。 重複を避けるためにセットユニオン演算を使用してください。 
6. 例外的な要素が存在しない場合は、左から右の範囲をすべて結合します。 合計は次のように増減するため、これは簡単な算術です。`1`。 
7. 合計のセットをソートされたリストに変換し、カウントとソートされた合計を出力します。 

正しさは、シーケンスが次のような性質を持っていることに依存します。`1`と`-1`は連続合計範囲を形成し、単一の例外要素を追加すると範囲が定数だけシフトされます。 集合演算を使用することにより、例外要素にまたがるサブ配列の合計を含む、考えられるすべてのサブ配列の合計を取得します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        sums = set()
        sums.add(0)  # empty subarray
        
        # Find exceptional element if it exists
        x_pos = -1
        for i, val in enumerate(a):
            if val != 1 and val != -1:
                x_pos = i
                x_val = val
                break
        
        # Helper to compute all prefix sum ranges for +-1 segments
        def segment_sums(arr):
            total = 0
            min_sum = 0
            max_sum = 0
            for val in arr:
                total += val
                min_sum = min(min_sum, total)
                max_sum = max(max_sum, total)
            return set(range(min_sum, max_sum + 1))
        
        if x_pos == -1:
            # Entire array is 1 or -1
            sums |= segment_sums(a)
        else:
            left_sums = segment_sums(a[:x_pos])
            right_sums = segment_sums(a[x_pos+1:])
            # All combinations: left + x_val + right, plus left sums, plus right sums
            new_sums = set()
            for s in left_sums:
                new_sums.add(s)
                new_sums.add(s + x_val)
                for r in right_sums:
                    new_sums.add(s + r)
                    new_sums.add(s + x_val + r)
            new_sums |= right_sums
            sums |= new_sums
        
        result = sorted(sums)
        print(len(result))
        print(' '.join(map(str, result)))

solve()
```コードは、テスト ケースの数と各配列を読み取ることから始まります。 例外的な要素があるかどうかを検出し、セグメント範囲を使用して考えられるすべての部分配列の合計を計算します。`1`と`-1`は。 機能`segment_sums`すべてのサブ配列を列挙する必要なく、セグメントのサブ配列の合計の全範囲を効率的に計算します。 範囲を例外要素と組み合わせると、すべての合計が重複することなく含まれるようになります。
