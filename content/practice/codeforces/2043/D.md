 ## 解決策
 ## 問題の理解

 2 つの数字を見つけるように求められます$A$そして$B$閉鎖範囲内で$[l, r]$それらの最大公約数が正確に$G$、距離$|A - B|$できるだけ大きいです。 複数の最適解のうち、最も小さいもの$A$が好ましいです。 そのようなペアが存在しない場合は、次のように出力する必要があります。`-1 -1`。 

入力$l$、$r$、 そして$G$と同じ大きさにすることができます$10^{18}$、範囲全体を反復処理する解法は除外されます。これには、最大で$10^{18}$繰り返し。 テストケースの数は最大で$10^3$したがって、テストケースごとのソリューションは、基本的に一定時間、または最悪の場合でも数値範囲内の対数で実行する必要があります。 

微妙なケースが発生する場合$G$よりも大きいです$r$, なぜなら、次の倍数はないからです。$G$収まる$[l, r]$。 たとえば、次の場合$l = 1$、$r = 5$、 そして$G = 6$、整数はありません$A, B$条件を満たしているため、出力は次のようになります。`-1 -1`。 別のケースが発生するのは、$G$範囲内ですが、可能な最大倍数です$G$まさに$l$または$r$を最大化する方法に影響します$|A-B|$。 

不注意なアプローチでは、すべてのペアを試してしまう可能性があります。$[l, r]$そしてGCDを計算します。 のために$r-l = 10^{18}$、これでは決して終わりません。 複数回繰り返しても$G$単純に、間違って処理すると遅すぎる可能性があります。 

## アプローチ

 ブルートフォースソリューションはすべてのペアを考慮します$(A, B)$範囲内で$[l, r]$、GCD を計算し、GCD を使用してペアを追跡します。$G$そして最大距離。 これは自明の理ですが、完全に実行不可能です。 範囲サイズが$n = r-l+1$、それは実行します$O(n^2)$GCD 計算は不可能です。$n \sim 10^{18}$。 

重要な観察は次のとおりです$A$そして$B$の倍数でなければなりません$G$。 定義すると$A = G \cdot x$そして$B = G \cdot y$、問題は整数を見つけることに帰着します$x$そして$y$そのような$l/G \le x \le y \le r/G$そして$\gcd(x, y) = 1$。 最大化するには$|A-B|$、私たちが欲しいのは$x$できるだけ小さく、そして$y$できるだけ大きく。 スケーリングしてから$G$GCD を保存します。$\gcd(G \cdot x, G \cdot y) = G\cdot \gcd(x, y)$したがって、必要なのは$x = 1$そして$y = \lfloor r/G \rfloor$もし$1$スケール範囲内にあります。 

したがって、アプローチは次のようになります。次の最小倍数を見つけます。$G$以上$l$との最大倍数$G$以下$r$。 最小倍数が最大倍数を超える場合、解は存在しません。 それ以外の場合、これら 2 つの数値を選択することで距離が最大化されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((r-l+1)^2) | お(1) | 遅すぎる |
 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 特定のテスト ケースに対して、$l, r, G$、の最小倍数を計算します。$G$それはそれ以下ではありません$l$。 これは整数演算で次のように計算できます。$A = \lceil l/G \rceil \cdot G = ((l+G-1)//G) \cdot G$。 これにより、$A \ge l$そして$A$で割り切れます$G$。 
2. 次の最大倍数を計算します。$G$それはそれより大きくない$r$を使用して$B = (r//G) \cdot G$。 これにより保証されます$B \le r$そして$B$で割り切れます$G$。 
3. 次のことを確認します。$A > B$。 true の場合、その中に数値のペアは存在しません。$[l, r]$それはの倍数です$G$。 出力`-1 -1`。 
4. それ以外の場合は、ペアを出力します$(A, B)$。 これにより最大化されます$|A-B|$保ちながら$A$最小限。 

なぜ機能するのか: の最小倍数と最大倍数を選択することにより、$G$間隔内では、距離が自動的に最大化されます。 スケーリング引数により、GCD が次の 2 つの倍数になることが保証されます。$G$少なくとも$G$、そして選択することで$A$そして$B$それ自体が倍数であるため、$\gcd(A, B) = G$の場合は保証されます$A = G \cdot x$、$B = G \cdot y$そして$\gcd(x, y) = 1$。 ピッキング$x = 1$そして$y$可能な限り大きくすることが常に機能します。$1$は任意の整数と互いに素です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    l, r, G = map(int, input().split())
    A = ((l + G - 1) // G) * G
    B = (r // G) * G
    if A > B:
        print(-1, -1)
    else:
        print(A, B)
```最初の行はテスト ケースの数を読み取ります。 テストケースごとに、次のように計算します。`A`の上限倍数として`G`それはそれ以下ではありません`l`、 そして`B`のフロア倍数として`G`それはそれより大きくない`r`。 計算された場合`A`よりも大きいです`B`、出力します`-1 -1`解決策がないことを示します。 それ以外の場合は、計算されたペアが出力されます。 天井と床の操作では、1 つずつずれたエラーが発生しないように注意が払われます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    t = int(input())
    for _ in range(t):
        l, r, G = map(int, input().split())
        A = ((l + G - 1) // G) * G
        B = (r // G) * G
        if A > B:
            print(-1, -1)
        else:
            print(A, B)
    return out.getvalue().strip()
