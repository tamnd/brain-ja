 ## 解決策
 # 問題の理解

 ネットワークには単一の環状バックボーンがあります。 すべてのバックボーン スイッチにはツリー状のサブネットを接続できるため、グラフ全体にはちょうど 1 つのサイクルが含まれ、他のすべてのエッジはそのサイクルからぶら下がっているツリーに属します。 

スイッチに保護ツールをインストールすると、そのスイッチに直接接続されているすべてのケーブルが監視されます。 ケーブルは、その 2 つのエンドポイントのうち少なくとも 1 つにツールがある場合に監視されます。 タスクは、すべてのケーブルが監視されるように最小限のスイッチの数を選択することです。 グラフ用語で言えば、これは接続された一巡グラフ上の最小頂点カバー問題です。 

バックボーン スイッチの数は 100000 に達する可能性があり、サブネット スイッチの数も 100000 に達する可能性があります。したがって、頂点の総数は約 200000 となり、エッジの数は同じになります。 すべてのサブセットを試したり、一般的なグラフ頂点カバー アルゴリズムを実行したりする解決策は不可能です。 特別な構造、つまりツリーが接続された単一サイクルを使用する線形時間アルゴリズムが必要です。 

厄介なケースはサイクルから発生します。 ツリーは貪欲に解くことができますが、最初と最後のサイクル頂点が接続されているため、サイクルには依存関係が生じます。 

たとえば、グラフ全体が三角形のみの場合:```
3 0
0 1
1 2
2 0
```答えは`2`。 スイッチを 1 つだけ選択すると、反対側のケーブルは覆われないままになります。 

もう 1 つのエッジ ケースは、サイクル頂点に接続された長いチェーンです。 例えば：```
3 2
0 1
1 2
2 0
0 3
3 4
```サイクルは依然としてサイクルとして処理する必要がありますが、頂点は`3`そして`4`ツリーとして処理する必要があります。 グラフ全体をツリーとして扱うと、余分なサイクル エッジを見逃してしまいます。 

# アプローチ

 直接的なアプローチは、グラフ全体の最小頂点カバーを解決することです。 すべての頂点は選択することも選択しないこともできるため、総当たりチェックではすべての頂点がチェックされます。`2^V`あらゆる可能性を検証し、あらゆるエッジを検証します。 これは、考えられるすべてのスイッチのセットを検査するので正しいですが、頂点が約 200,000 個あるグラフの場合、これは完全に不可能です。 

有益な観察は、グラフが恣意的ではないということです。 固有のサイクルからいずれか 1 つのエッジを削除すると、グラフがツリーに変わります。 すべての子サブツリーは 1 つのエッジを介してのみ親と対話するため、ツリーには頂点カバーのための単純な動的プログラミング ソリューションがあります。 

ブルートフォースは、考えられるすべての選択を考慮するため機能します。 グラフが大きすぎるため失敗します。 構造を観察すると、グラフをツリー部分と 1 つの小さなサイクルに分離できます。 すべてのサイクル頂点が選択されているかどうかに応じて最良の答えを計算し、残りのサイクルを小さな動的プログラミング パスで解決します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^V * E) | O(V) | 遅すぎる |
 | 最適 | O(V) | O(V) | 承認済み |

 # アルゴリズムのチュートリアル

 1. 次数消去を使用して、一意のサイクルに属する頂点を見つけます。 すべてのリーフをサイクルの一部にすることはできないため、次数 1 の頂点を繰り返し削除すると、サイクル頂点がそのまま残ります。 
2. すべてのサイクル頂点からそれに接続されたツリーに対してツリー動的プログラミングを実行します。 頂点の場合`u`、2 つの値を計算します。 最初の値は、次の場合の最小カバー サイズです。`u`は選択されていません。つまり、すべての子を選択する必要があります。 2 番目の値は、次の場合の最小カバー サイズです。`u`が選択されているため、すべての子を選択することも選択しないこともできます。 
3. 木の端は当面無視し、サイクルのみを考慮します。 各サイクル頂点には、頂点自体が選択されるかどうかに応じて、考えられるコストが 2 つあります。 
4. 最初のサイクル頂点の状態を固定してサイクルを解決します。 これが選択された場合、最後の頂点は選択されても選択されなくてもよい。 それが選択されない場合は、その 2 つの隣接サイクルを選択する必要があります。 両方の可能性を試して、結果が小さい方を維持してください。 
5. 2 つのサイクルのケースから得られた最小値を出力します。 

不変条件は、すべてのサブツリー DP 値が、サブツリー ルートの選択状態または非選択状態を尊重しながら、そのサブツリー内のすべてのエッジをカバーするために必要な選択された頂点の正確な最小数を表すことです。 サイクル DP は残りのサイクル エッジを強制するだけでよいため、独立したサブツリー ソリューションを組み合わせることで全体的な最適値が得られます。 

# Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    total = n + m

    g = [[] for _ in range(total)]
    for _ in range(total):
        a = int(next(it))
        b = int(next(it))
        g[a].append(b)
        g[b].append(a)

    deg = [len(x) for x in g]
    from collections import deque

    q = deque(i for i in range(total) if deg[i] == 1)
    alive = [True] * total

    while q:
        u = q.popleft()
        alive[u] = False
        for v in g[u]:
            if alive[v]:
                deg[v] -= 1
                if deg[v] == 1:
                    q.append(v)

    cycle = [i for i in range(total) if alive[i]]
    cycle_set = set(cycle)

    sys.setrecursionlimit(300000)

    def dfs(u, p):
        take = 1
        leave = 0
        for v in g[u]:
            if v != p and v not in cycle_set:
                a, b = dfs(v, u)
                leave += a
                take += min(a, b)
        return leave, take

    cost = {}
    for c in cycle:
        cost[c] = dfs(c, -1)

    order = []
    start = cycle[0]
    prev = -1
    cur = start
    while True:
        order.append(cur)
        nxt = None
        for v in g[cur]:
            if v in cycle_set and v != prev:
                nxt = v
                break
        prev, cur = cur, nxt
        if cur == start:
            break

    def solve_cycle(first_state):
        inf = 10**18
        k = len(order)
        dp = [inf, inf]
        dp[first_state] = cost[order[0]][first_state]

        for i in range(1, k):
            ndp = [inf, inf]
            for prev_state in (0, 1):
                for state in (0, 1):
                    if prev_state == 0 and state == 0:
                        continue
                    ndp[state] = min(
                        ndp[state],
                        dp[prev_state] + cost[order[i]][state]
                    )
            dp = ndp

        ans = inf
        for last_state in (0, 1):
            if first_state == 0 and last_state == 0:
                continue
            ans = min(ans, dp[last_state])
        return ans

    print(min(solve_cycle(0), solve_cycle(1)))

if __name__ == "__main__":
    solve()
```最初の部分ではグラフを構築し、リーフを削除します。 すべての木の枝は最終的に葉で終わるため、このプロセスではサイクル頂点のみが生き残ります。 

DFS は、標準的な木の頂点被覆の反復を計算します。 頂点が選択されていない場合は、それらの間のエッジをカバーする必要があるため、すべての子を選択する必要があります。 頂点が選択されると、各子はより安価な状態を選択します。 

サイクル・トラバーサルはバックボーン順序を保管します。 最後の動的プログラミング パスは、2 つの状態がサイクル頂点が選択されているかどうかを表すことを除いて、円上の古典的な住宅強盗に似ています。 特別な最初と最後の遷移により、カバーされていないサイクル エッジが防止されます。 

Python の整数はオーバーフローしませんが、実装では依然として不可能な状態に対して大きなセンチネル値が使用されます。 サブネットは入力サイズに近い長さのチェーンになる可能性があるため、再帰制限が増加します。

 # エッジケース

 サイクルのみを含むグラフの場合:```
3 0
0 1
1 2
2 0
```リーフの削除では何も削除されないため、すべての頂点がサイクル頂点として識別されます。 ツリー DP は追加コストに寄与せず、サイクル DP は少なくとも 2 つの頂点を強制的に選択します。 

パスがアタッチされたサイクルの場合:```
3 2
0 1
1 2
2 0
0 3
3 4
```ピーリングフェーズでは頂点を削除します`4`そして`3`、出発`0,1,2`サイクルとして。 DFS はブランチ コストを独立して計算し、サイクル DP によってどのバックボーン スイッチを選択するかを決定します。 分岐は、アルゴリズムが依存する正確な分離であるサイクルの順序に影響を与えることはできません。 

複数のリーフの子を持つ頂点の場合、DFS は親を選択する方がコストが低い場合を正しく処理します。 親が選択されていない場合は、すべてのリーフの子を選択する必要があります。 親が選択されている場合は、すべての葉を無視できます。 2 つの DP 状態は、特別な場合を除いて両方の可能性を捉えています。
