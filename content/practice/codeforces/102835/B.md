 ## 解決策
 ## 問題の理解

 このタスクは、指定された 4 つの数字を取得し、できるだけ多くの異なる非負の整数を作成することです。 有効な式はそれぞれ、4 桁すべてを 1 回だけ使用する必要があります。 桁を並べ替えたり、複数桁の数値に結合したり、基本的な算術演算である加算、減算、乗算に接続したりすることができます。 目標は、1 つの式を見つけることではなく、生成できる個別の最終値の数を数えることです。 

たとえば、数字の場合`1 1 2 1`、式`21 + 11`作成します`32`、 その間`111 - 2`作成します`109`。 同じ値を生成する異なる式は 1 回だけ貢献します。 出力は、到達可能なすべての非負の結果のセットのサイズです。 

入力には 4 桁しか含まれていないため、検索スペースが小さくなります。 通常の問題`n = 10^5`ほぼ直線的な時間を必要としますが、ここでは固定サイズにより戦略が完全に変わります。 4 つの位置を指数関数的に列挙する余裕があります。`2^4 = 16`サブセット。 課題はデータの量ではなく、考えられるすべての表現形式を確実に表現することです。 

難しいのは、数字をグループ化できるすべての方法を処理することです。 不注意な解決策を使用すると、元の桁の順序だけを試行し、並べ替えをミスする可能性があります。 入力用`1 1 2 1`、決して形にならないプログラム`21`次のような値が失われます`32`たとえ有効であっても。 

もう 1 つのよくある間違いは、繰り返された結果を無視することです。 入力用`1 1 1 1`、式`11 + 1 - 1`そして`1 * 111`は異なる式ですが、答えは生成された各整数を 1 回だけカウントします。 正しい出力は次のとおりです`15`。 

最後のエッジ ケースは、負の値を生成する減算です。 この問題では負ではない整数のみが求められるため、負の中間結果や最終結果を解答セットに挿入してはなりません。 たとえば、次のような式`1 - 2 - 1 - 1`貢献すべきではない`-3`。 

## アプローチ

 直接的なアプローチは、考えられるすべての式を生成することです。 1 つの方法は、4 つの数字を配置し、連結が行われる場所を決定し、結果の部分の間に演算を挿入して、式を評価することです。 すべての法的表現はこれらの選択肢によって説明できるため、これは正しいです。 

ただし、この列挙を手動で記述するとエラーが発生しやすくなります。 操作をさまざまな方法でネストできるため、式の形状の数が増加します。 再帰的な生成方法はよりクリーンです。 数字のすべてのサブセットを、より小さな独立した式の問題として扱います。 

総当たりのアイデアは、4 桁の位置のサブセットが 16 個しかないという重要な観察の後、はるかに管理しやすくなります。 すべてのサブセットについて、正確にその数字を使用して作成できるすべての値を保存できます。 サブセットは、その数字をあらゆる順序で連結することによって、または空ではない 2 つの小さなサブセットに分割してそれらの値を結合することによって、値を生成できます。`+`、`-`、 または`*`。 

ブルート フォース バージョンは同じ小さな式を繰り返し再構築しますが、サブセット動的プログラミング バージョンは各サブセットを 1 回計算して再利用します。 最終的な答えは、4 桁の完全なセットに対して保存されている値から得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(式の数) | O(式の数) | 概念的には機能しますが、見落としやすいケース |
 | 最適 | O(3^4 * V^2) | O(2^4 * V) | 承認済み |

 ここ`V`1 つのサブセットに保存される値の最大数です。 桁数は 4 に固定されているため、これは容易に制限内に収まります。 

## アルゴリズムのチュートリアル

 1. 4 桁の数字を読み取り、次の位置で表します。`0`に`3`。 同じ数字が依然として異なる利用可能なタイルを表すため、位置が使用されます。 
2. 位置のサブセットから取得できるすべての数値を返す再帰関数を構築します。 返されたコレクションは、それらの数字を正確に使用して、考えられるすべての式を表します。 
3. サブセットの場合は、最初に、その数字をあらゆる順序で連結して作成されたすべての数値を加算します。 これは次のような値を処理します。`21`、`112`、 そして`1112`。 
4. あらゆる方法を試して、サブセットを空ではない 2 つの素な部分に分割します。 左部分と右部分のすべての値を計算し、加算、減算、乗算を使用してすべてのペアを結合します。 
5. 4 桁すべてを含む完全なサブセットの結果セットを保存します。 負でない整数のみが有効な回答であるため、負の値を削除し、残りの個別の値の数を出力します。 

これが機能する理由は、有効な式の最後の演算が連結または 3 つの算術演算のいずれかであるためです。 算術の場合、式は自然に 2 つの小さな式に分割されます。 再帰はこの構造に正確に従っているため、すべての有効な式が生成されます。 生成された式はすべて有効であるため、不正な値が追加されることはありません。 

## Python ソリューション```python
import sys
from functools import lru_cache
from itertools import permutations

input = sys.stdin.readline

def solve():
    digits = list(map(int, input().split()))

    @lru_cache(None)
    def dp(mask):
        res = set()
        ids = [i for i in range(4) if mask & (1 << i)]

        for p in permutations(ids):
            value = 0
            for i in p:
                value = value * 10 + digits[i]
            res.add(value)

        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other and sub < other:
                for a in dp(sub):
                    for b in dp(other):
                        res.add(a + b)
                        res.add(a - b)
                        res.add(a * b)
                        res.add(b - a)
            sub = (sub - 1) & mask

        return res

    ans = sum(1 for x in dp(15) if x >= 0)
    print(ans)

if __name__ == "__main__":
    solve()
```再帰関数`dp(mask)`ソリューションの核心です。 ビットマスクは、どの桁位置が使用可能かを示します。 数値ではなく位置を使用すると、同じ数値が誤ってマージされるのを防ぎます。 

順列ループは、連結された可能なすべての数値を追加します。 これは、桁の順序が柔軟であるために必要です。 数字を含むサブセットの場合`1`そして`2`、 両方`12`そして`21`考慮する必要があります。 

サブセット分割ループは、次のように要求することにより、すべてのパーティションを 1 回だけ試行します。`sub < other`。 これにより、同じ分割を 2 回行うことがなくなります。 式の左部分と右部分は順序付けされているため、算術の組み合わせには両方の減算方向が含まれます。 

Python の整数はオーバーフローしないため、乗算は安全です。 メモ化デコレータは、各サブセットが何度も再計算されるのではなく、確実に 1 回評価されるようにします。 

## 実用的な例

 入力用`1 1 1 1`重要な状態は、完全なマスクから生成された値のセットです。 

| ステップ | 現在のサブセット | アクション | 結果のサイズ |
 | --- | --- | --- | --- |
 | 1 | 一桁 | 可能な 1 桁の値を保存する | 1 |
 | 2 | ペア | 連結と算術組み合わせを追加する | いくつかの値 |
 | 3 | トリプル | 以前に計算されたペアとシングルを結合する | 大きいセット |
 | 4 | すべての数字 | すべてのパーティションを結合する | 15 個の負でない値 |

 この例では、重複した式が問題にならないことを確認しています。 アルゴリズムはセットを保持するため、繰り返された値は自動的に消えます。 

入力用`1 1 2 1`、最後の結合ステップには次のような式が含まれます。`21 + 11`。 

| ステップ | 現在のサブセット | 生成される値の例 | 理由 |
 | --- | --- | --- | --- |
 | 1 | 数字`2`そして`1`| 21 | 連結は許可されます |
 | 2 | 残りの桁`1`そして`1`| 11 | 2 番目の連結 |
 | 3 | フルセット | 32 | 組み合わせる`21 + 11`|
 | 4 | フルセット | 109 | 組み合わせる`111 - 2`|

 トレースは、中間サブセットを保存することがなぜ役立つかを示しています。 大きな式では、すべての完全な式を個別に試行するのではなく、小さな構成要素を再利用します。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(3^4 * V^2) | 各サブセットはより小さなサブセットに分割され、値が結合されます。 
| スペース | O(2^4 * V) | 16 個のマスクが保存され、それぞれに到達可能な値が含まれています。 

桁数は決して変化しないため、指数部分は一定サイズの検索になります。 このソリューションは、少数の再帰状態とセット操作のみを実行するため、1 秒の制限に問題なく適合します。

        res = set()
        ids = [i for i in range(4) if mask & (1 << i)]

            x = 0
            for i in p:
                x = x * 10 + digits[i]

                        res.add(a - b)
                        res.add(b - a)
                        res.add(a * b)

        return res

    return str(sum(x >= 0 for x in dp(15)))

 ## 特殊なケース

 のために`1 1 1 1`、アルゴリズムは、さまざまな式を通じて多数の同一の値を構築します。 すべてのサブセットの結果はセットに格納されるため、次のような式が作成されます。`1+1+1+1`そして`11-7`スタイルの重複は答えを水増しすることはできません。 

のために`0 0 0 0`、連結ではゼロのみが作成され、すべての算術演算もゼロのままになります。 最後のセットには有効な非負の数値が 1 つだけ含まれているため、出力は次のようになります。`1`。 

数字を使用する場合など、減算によって負の値が作成される場合`1 2 3 4`、ゼロ未満で終わる式は内部で生成されますが、カウントする前にフィルターされます。 これにより、無効な負の整数が答えに影響を与えるのを防ぎます。
