 ## 解決策
 ## 問題の理解

 入力はグラフ カードのデッキを記述します。 各カードには方向性のない単純なグラフが含まれています。 グラフが同じ数の頂点とエッジを持ち、接続されているため、カードは有効です。つまり、すべてのカードが接続された一巡グラフ、つまり追加のエッジが 1 つだけあるツリーを表します。 グラフのラベルを変更して同一になる場合、2 つのカードは同じであるとみなされます。 タスクは、デッキ全体に表示されるさまざまなグラフの形状の数を数えることです。 

入力のグラフ ラベルは無関係です。 頂点に番号が付けられたグラフ`1,2,3`頂点に番号が付けられた同じグラフ`10,20,30`貢献できるのは 1 回だけです。 課題は、頂点名を無視した構造の表現を構築することです。 

カード内の頂点の数は大きくなる可能性があるため、一般的なグラフ同型アルゴリズムを使用してグラフのすべてのペアをチェックすることは現実的ではありません。 一般的な同型性の比較は非常にコストがかかる可能性があり、この問題には追加の構造があります。 同じ数の頂点と辺を持つ接続されたグラフにはちょうど 1 つのサイクルがあり、そのサイクルの外側にあるものはすべてルート ツリーのコレクションです。 この構造により、カードごとに線形時間で正規表現を作成できます。 

エッジ ケースは、サイクルの対称性とサイクルに接続されたツリーから発生します。 選択された開始点が 2 つの同一のグラフで異なる可能性があるため、任意の頂点からの単純な走査は失敗します。 

たとえば、次の 2 つのカードは、異なる番号の頂点を持つ同じサイクルを表しています。```
1
3 1 2 2 3 3 1
3 2 3 3 1 1 2
```正しい出力は次のとおりです。```
1
```頂点を訪問する順序を記録する走査は、サイクル上の異なる場所から開始されるため、異なる文字列を生成する可能性があります。 

もう 1 つのよくある間違いは、サイクルはどちらの方向にも通過できることを無視することです。 例えば：```
1
4 1 2 2 3 3 4 4 1
4 1 4 4 3 3 2 2 1
```正しい出力は次のとおりです。```
1
```2 番目のグラフは、最初のグラフを逆方向から見たものにすぎません。 回転のみをチェックし、逆回転はチェックしない表現は、それらを異なるものとして扱います。 

3 番目のエッジ ケースは、いくつかの分岐が接続されたサイクル頂点です。 1 つの頂点に 2 つの同一のリーフの子があるサイクルを考えてみましょう。 子には順序がないため、子の説明をソートする必要があります。 ソートを行わないと、2 つの同等のツリーが異なるエンコーディングを受け取る可能性があります。 

## アプローチ

 この強引なアイデアは、カードのすべてのペアを比較し、グラフの同型性チェックを実行することです。 これが機能するのは、グラフ間に同型性が存在する場合、2 つのカードが正確に同一であるためです。 問題は、カードの数が多い場合、比較の数が 2 次になることです。 と`n`カード、これにはすでに必要です`O(n^2)`各比較ですべてのエッジと頂点を検査する必要がある場合があり、合計の作業量が非常に大きくなります。 

有益な観察は、この問題のすべてのグラフにちょうど 1 つのサイクルがあるということです。 一般的なグラフ同型アルゴリズムは必要ありません。 まず固有のサイクルを特定し、それを概念的に削除し、各サイクルの頂点からぶら下がっている根の生えた木を確認します。 

根のあるツリーは単純な標準的な形式を持っています。 葉は空のかっこのペアで表されます。 頂点は、括弧で囲まれた子の標準形式のソートされたリストによって表されます。 並べ替えにより、子の順序への依存関係が削除されます。 

残る唯一の困難はサイクル自体です。 サイクルは、根付きツリー記述の循環シーケンスです。 2 つの循環シーケンスは、一方を回転または反転して他方を取得できる場合には等しいです。 シーケンスのすべての回転と反転シーケンスのすべての回転の中で最小の表現を生成します。 

ブルートフォース手法は、同じ構造上の問題を繰り返し解決するため、失敗します。 正規表現では、カードごとに 1 回解決され、等価性チェックが文字列またはタプルの比較に変わります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(C²・V) | O(V) | 遅すぎる |
 | 最適 | O(C・VlogV) | O(V) | 承認済み |

 ここ`C`はカードの枚数であり、`V`は 1 枚のカード内の頂点の総数です。 対数係数は、ツリー ノードの子を並べ替えることから得られます。 

## アルゴリズムのチュートリアル

 1. 1 つのグラフ カードを読み取り、その隣接リストを作成します。 最終的な表現が頂点番号に依存してはいけないため、頂点番号は一時的な識別子にすぎません。 
2. 葉の剪定を使用して固有のサイクルを見つけます。 次数が 1 のすべての頂点をサイクルの一部にすることはできないため、リーフを繰り返し削除すると、サイクル頂点がそのまま残ります。 これが機能するのは、一巡グラフには閉じたコンポーネントが 1 つしかないためです。 
3. すべてのサイクル頂点について、2 つのサイクル近傍を無視して、それに接続されているツリーの標準形式を計算します。 ツリー エンコーディングは、すべての子エンコーディングをソートされた順序で再帰的に結合します。 
4. 取得したツリーエンコーディングをサイクルの順序に並べます。 開始サイクル頂点は任意であるため、回転ごとに生成します。 また、同じサイクルを逆方向​​に歩くことができるため、逆の順序のすべての回転を生成します。 
5. 辞書編集上最小のサイクル表現を選択します。 この値は、グラフ全体の正規の識別子です。 
6. 識別子をセットに挿入します。 すべてのカードが処理された後のセットのサイズは、異なるグラフ カードの数になります。 

なぜ効果があるのか:

 すべてのノードがその子サブツリーのマルチセットによって表され、ソートによってそのマルチセットが決定的な順序に変換されるため、ツリー エンコーディングは一意です。 サイクル エンコーディングは、開始点と方向のあらゆる可能な選択が考慮されるため、独特です。 2 つの同型一巡グラフは、正準識別子が一致するように、同じサイクル長と、回転と反転までの接続されたルート付きツリーの同じシーケンスを持たなければなりません。 非同型グラフは、識別子が完全なサイクルとすべての接続されたツリーを再構築するため、同じ識別子を生成できません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def rooted_tree_code(v, parent, adj, on_cycle):
    children = []
    for u in adj[v]:
        if u != parent and not on_cycle[u]:
            children.append(rooted_tree_code(u, v, adj, on_cycle))
    children.sort()
    return "(" + "".join(children) + ")"

def canonical_graph(edges, n):
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)

    degree = [len(x) for x in adj]
    alive = [True] * n
    stack = [i for i in range(n) if degree[i] == 1]

    while stack:
        v = stack.pop()
        alive[v] = False
        for u in adj[v]:
            if alive[u]:
                degree[u] -= 1
                if degree[u] == 1:
                    stack.append(u)

    cycle = [i for i in range(n) if alive[i]]
    on_cycle = alive[:]

    cycle_adj = [[] for _ in range(n)]
    for v in cycle:
        for u in adj[v]:
            if on_cycle[u]:
                cycle_adj[v].append(u)

    start = cycle[0]
    order = []
    prev = -1
    cur = start

    while True:
        order.append(cur)
        nxt = cycle_adj[cur][0]
        if nxt == prev:
            nxt = cycle_adj[cur][1]
        prev, cur = cur, nxt
        if cur == start:
            break

    parts = [rooted_tree_code(v, -1, adj, on_cycle) for v in order]

    m = len(parts)
    best = None

    for arr in (parts, list(reversed(parts))):
        for i in range(m):
            cand = tuple(arr[i:] + arr[:i])
            if best is None or cand < best:
                best = cand

    return best

def solve():
    t = int(input())
    ans = []
    for _ in range(t):
        cards = int(input())
        seen = set()

        for _ in range(cards):
            data = list(map(int, input().split()))
            k = data[0]
            vals = data[1:]

            edges = []
            mx = 0
            for i in range(k):
                u = vals[2 * i] - 1
                v = vals[2 * i + 1] - 1
                edges.append((u, v))
                mx = max(mx, u, v)

            seen.add(canonical_graph(edges, mx + 1))

        ans.append(str(len(seen)))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```隣接リストには、一時的なグラフ表現が格納されます。 葉枝刈りループはすべての木の頂点を削除し、固有のサイクルのみを残します。 ブール値`on_cycle`配列は、接続されたツリーからサイクルを分離します。`rooted_tree_code`別のサイクル頂点に入ることはありません。そのため、すべての再帰呼び出しは 1 つのルート ツリー内にとどまります。 子は結果を構築する前に並べ替えられます。これは、入力順序への依存を取り除く詳細です。 

サイクル トラバースにより、サイクルの一方向が作成されます。 最後のループは、考えられるすべての開始位置と両方向を処理します。 タプルは自然に比較され、連結された文字列間のあいまいさを回避するため、最終的な識別子に使用されます。 

この実装では、サイクル自体で再帰は使用されません。 再帰の深さは、接続されたツリーの深さのみであり、構造的に表現する必要がある部分です。

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | カードあたり O(V log V) | 各頂点は 1 回処理され、子のリストはツリーのエンコード中にソートされます。

import sys
import io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    data = sys.stdin.read().split()
    sys.stdin = old

    it = iter(data)
    t = int(next(it))
    out = []

    for _ in range(t):
        c = int(next(it))
        seen = set()
        for _ in range(c):
            k = int(next(it))
            edges = []
            mx = 0
            for _ in range(k):
                u = int(next(it)) - 1
                v = int(next(it)) - 1
                edges.append((u, v))
                mx = max(mx, u, v)
            seen.add(canonical_graph(edges, mx + 1))
        out.append(str(len(seen)))

    return "\n".join(out)

 ## 特殊なケース

 すべてのサイクル頂点が同じ空のツリー コードを受け取るため、ツリーがアタッチされていないサイクルが処理されます。 サイクルの正規化でも回転と反転がチェックされるため、入力の番号付けに関係なく、三角形以上のリングが正しく識別されます。 

唯一の違いがサイクルの実行に使用される方向であるグラフは、元のシーケンスとその逆のシーケンスの両方を比較することによって処理されます。 たとえば、入力```
1
4 1 2 2 3 3 4 4 1
```および逆方向にリストされた同じサイクルはどちらも同じ最小循環表現を生成します。 

多数の同一の子を持つ頂点は、子のエンコーディングをソートすることによって処理されます。 2 つのリーフに接続されたサイクル頂点の場合、アタッチされたツリー コードは 2 つの同一のリーフ コードのソートされた組み合わせになります。 このアルゴリズムは、入力にエッジが現れる順序には決して依存しないため、同じ分岐構造は常に同じ表現を受け取ります。
