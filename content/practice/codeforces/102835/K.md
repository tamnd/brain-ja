 ## 解決策
 ## 問題の理解

 学士番号は、選択された基数での表現に繰り返しの数字が含まれない番号です。 この問題では、10 進数と 16 進数の 2 つの基数がサポートされています。 たとえば、123 は 10 進数の学士番号であり、9af は 16 進数の学士番号です。10 進数の 101 のような値は、数字 1 が 2 回出現するため無効です。 

各クエリは、範囲内にいくつの学士番号があるかを尋ねるか、または学士番号の順序付きリスト内の特定の 0 から始まる位置にある番号を尋ねます。 最初のキャラクターがベースを選択し、`d`10進数の場合と`h`16進数の場合。 

入力値は、符号なし 64 ビット数値と同程度の大きさにすることができます。 これにより、間隔内の反復や、境界までのすべての値の生成が即座に排除されます。 クエリは最大 50000 個あるため、各クエリは、理想的には桁数に比例した少量の作業で応答する必要があります。 

難しい部分は、ゼロが含まれていることと、順序が数値であるという事実です。 ゼロは、その唯一の数字が 1 回出現するため、有効な学士番号です。 クエリ インデックスは 0 から始まるため、最初の学士番号は 0 になります。次に例を示します。```
d 1 10
```10 番目の学士番号を 10 進数で要求します。 インデックス 0 ～ 9 の数値は 0、1、2、...、9 であるため、答えは次のようになります。```
9
```2 番目のエッジ ケースは、基数より桁数が多い番号は学士番号にならないということです。 16 進数では、使用可能な桁は 16 桁のみであるため、17 桁の 16 進数では桁を繰り返す必要があります。 構築後に繰り返される数字のみをチェックする不用意なソリューションは、存在しない大きなインデックスを検索するときに失敗する可能性があります。 

例えば：```
h 1 ffffffffffffffff
```非常に大きな位置で 16 進数を要求します。 答えは次のとおりです。```
-
```なぜなら、独身者になれる数は限られているからです。 

## アプローチ

 直接的なアプローチは、すべての数値を生成し、その桁が一意であるかどうかを確認し、要求された位置が見つかるか間隔がカウントされるまで継続することです。 これは定義に直接従うため、正しいです。 ただし、検索スペースは膨大です。 64 ビット間隔には最大 2^64 の数値を含めることができますが、これは処理できる数値をはるかに超えています。 

重要な観察は、学士号は数字の選択のみに依存するということです。 一度使用した数字は再度表示することはできません。 これにより、有効な継続の数が予測可能になります。 数字を 1 つずつ参照するのではなく、長さごとに有効な数字がいくつ存在するかを数え、桁ごとに答えを作成します。 

間隔をカウントするために、境界を超えない学士番号の数を計算します。 これは、より短い長さを考慮し、どの桁がすでに使用されているかを追跡しながら、境界の桁をスキャンすることによって行われます。 

k 番目の学士号を見つけるには、まず各長さの有効な数値の数を減算してその長さを決定します。 長さがわかったら、次に考えられる各桁が作成する有効な数値の数を数えることによって、左から右にすべての桁を選択します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(チェックされる値の数 × 桁数) | お(1) | 遅すぎる |
 | 最適 | クエリあたり O(基数 × 桁数 ²) | O(ベース) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. クエリベースを 10 または 16 に変換し、使用可能な数字記号を準備します。 
2. 値を限界までカウントするには、まず桁数の少ないすべての学士号をカウントします。 長さ`len`貢献する`(base - 1) * (base - 1) * ...`最初の数字をゼロにすることはできず、その後の数字はすべて、以前に選択した数字を避ける必要があるためです。 
3. 境界の数字を左から右に処理します。 各位置で、現在の数字より小さい有効な数字をすべて試して、その後形成できる接尾辞の数を数えます。 次に、境界の実際の数字が以前に表示されていない場合は、その数字を続けます。 
4. ゼロ自体が学士号であるため、負でない値を数えるときはゼロに 1 を加えます。 
5. k 番目の学士番号を見つけるには、最初に k = 0 を処理します。これはゼロを返します。 次に、残りのインデックスが 1 つの長さに属するまで、各長さの完全なグループを削除します。 
6. 最上位桁から答えを作成します。 各位置について、可能な数字を昇順にテストします。 その数字を選択した後の有効なサフィックスの数によって、ターゲット インデックスがそのブロック内にあるかどうかがわかります。 
7. すべての位置が固定されるまで続けます。 インデックスが学士番号の合計数を超える場合は、戻り値が返されます。`-`。 

機能する理由: このアルゴリズムは常に、接頭辞に従って数値を素のグループに分割します。 考えられるすべての有効な数値は、このプレフィックス ツリーの 1 つのブランチに正確に属します。 各枝のサイズをカウントすると、個々の数値を調べることなくグループ全体をスキップできます。 構築中は、必要なインデックスを含むブランチに入るだけなので、生成される数値は要求された順序統計とまったく同じになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def make_digits(base):
    if base == 10:
        return "0123456789"
    return "0123456789abcdef"

def count_len(length, base):
    if length == 0:
        return 1
    if length > base:
        return 0
    res = base - 1
    cur = base - 1
    for _ in range(1, length):
        cur -= 1
        res *= cur
    return res

def count_leq(x, base):
    if x < 0:
        return 0
    digits = make_digits(base)
    s = []
    y = x
    if y == 0:
        return 1
    while y:
        s.append(y % base)
        y //= base
    s.reverse()

    ans = 1
    for length in range(1, len(s)):
        ans += count_len(length, base)

    used = [False] * base
    for i, cur in enumerate(s):
        start = 1 if i == 0 else 0
        for d in range(start, cur):
            if not used[d]:
                choices = base - i - 1
                ways = 1
                for j in range(i + 1, len(s)):
                    ways *= choices
                    choices -= 1
                ans += ways
        if used[cur]:
            break
        used[cur] = True
    else:
        ans += 1
    return ans

def kth_number(k, base):
    digits = make_digits(base)
    if k == 0:
        return "0"

    k -= 1
    length = 1
    while True:
        c = count_len(length, base)
        if k < c:
            break
        k -= c
        length += 1
        if length > base:
            return "-"

    ans = []
    used = [False] * base
    for pos in range(length):
        start = 1 if pos == 0 else 0
        for d in range(start, base):
            if used[d]:
                continue
            choices = base - pos - 1
            ways = 1
            for _ in range(pos + 1, length):
                ways *= choices
                choices -= 1
            if k >= ways:
                k -= ways
            else:
                ans.append(digits[d])
                used[d] = True
                break
    return ''.join(ans)

def solve():
    out = []
    for _ in range(int(input())):
        q = input().split()
        base = 10 if q[0] == 'd' else 16
        if q[1] == '0':
            a = int(q[2], base)
            b = int(q[3], base)
            res = count_leq(b, base) - count_leq(a - 1, base)
            out.append(str(res) if base == 10 else format(res, 'x'))
        else:
            k = int(q[2], base)
            out.append(kth_number(k, base))
    print('\n'.join(out))

if __name__ == "__main__":
    solve()
```計数ルーチンでは、標準的な桁構成の考え方が使用されます。 すでに使用されている数字をブール配列に保持し、現在の位置でより小さな数字を試した後、考えられるすべての接尾辞をカウントします。 

機能`count_len`固定長の学士番号の数を計算します。 最初の桁には、`base - 1`ゼロは禁止されており、後続の数字ごとに利用可能なオプションが 1 つ少なくなっているためです。 

k 番目の数値の構築ルーチンは、カウント ロジックを反映しています。 選択されたすべての数字が使用されているセットに対してチェックされるため、無効なプレフィックスを構築しようとすることはありません。 インデックス演算はゼロベースであるため、ゼロの特別な処理が必要です。 

## 実用的な例

 対象:```
d 0 10 20
```このアルゴリズムは、10 から 20 までの 10 進数の学士号をカウントします。 

| ステップ | 現在の値 | アクション | 結果 |
 | --- | --- | --- | --- |
 | 1 | 10 | カウント値は 20 まで | 10、12、13、14、15、16、17、18、19、20が含まれます |
 | 2 | 10 | 9 までの値をカウント | 0 ～ 9 が含まれます |
 | 3 | 間隔 | プレフィックス数を減算する | 答えは 10 |

 間隔カウントは、すべての数値をスキャンするのではなく、2 つのプレフィックス カウントを比較することによって機能します。 

のために：```
h 1 f
```アルゴリズムはインデックス 15 で 16 進数の学士番号を見つけます。 

| ステップ | 残りのインデックス | 決定 |
 | --- | --- | --- |
 | 開始 | 15 | インデックス 0 なのでゼロをスキップ |
 | 長さ 1 | 14 | 1 桁の値が最初の位置に入力されます。 
| 結果 | 14 | 16 進数`e`選択されています |

 これは、問題で使用されるゼロベースの順序付けを示しています。

 ## 特殊なケース

 クエリの場合:```
d 0 0 0
```ゼロ自体が学士号であるため、count 関数は 1 つの有効な数値から始まります。 正の長さのみをカウントするソリューションは、誤ってゼロを返します。 

のために：```
h 1 ffffffffffffffff
```この構造では、有効な長さの利用可能なグループがすべて削除されます。 長さが 16 桁を超えると、すべての桁が一意である必要があるため、有効な 16 進数は存在できなくなります。 アルゴリズムはこれを検出して返します`-`。 

のために：```
d 1 10
```構築はゼロ値を削​​除した後に始まります。 残りのインデックスは、10 番目の正の位置、つまり数字 9 を指します。これは、順序付けが 1 ベースではなく 0 ベースであることを確認します。
