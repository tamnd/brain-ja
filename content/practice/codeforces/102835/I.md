 ## 解決策
 ## 問題の理解

 入力は通信ネットワークを記述します。 各頂点はコンピューティング ノードであり、各エッジは 2 つのノード間の通信リンクです。 クリティカル ノードは、削除するとネットワークが切断される頂点です。 クリティカル リンクは、削除するとネットワークが切断されるエッジです。 

必要な残りの構造は、サイクル内で一緒に属するエッジのグループに基づいています。 クリティカル コンポーネントは、エッジのすべてのペアがサイクル上に同時に現れることができるエッジの最大グループです。 これらのグループは、まさにグラフの二重連結コンポーネントです。 最後の端数では、そのようなコンポーネントの数を最大コンポーネントのエッジの数で割って、端数を減らします。 

制約は、線形グラフの走査用に設計されています。 テスト ケースごとに最大約 1,000 個の頂点があり、合計で最大 100 万個のエッジがある場合、すべての頂点またはエッジを削除した後で接続をチェックするのは非常に時間がかかりすぎます。 ブルートフォース アーティキュレーション ポイント チェックでは、DFS を繰り返し実行する必要があり、頂点またはエッジの数が 2 次になります。 すべてのエッジを一定回数処理する Tarjan DFS は、制限内に簡単に収まります。 

いくつかの特殊なケースは見落とされがちです。 単一のエッジは、ブリッジでもありますが、それ自体が二重接続されたコンポーネントです。 例えば：```
1
2 1
1 2
```答えは次のとおりです。```
1 1 1 1
```2 つの頂点は両方ともクリティカル ノードであり、唯一のエッジはクリティカル リンクであり、唯一のクリティカル コンポーネントには 1 つのエッジが含まれています。 サイクルが見つかった場合にのみコンポーネントを記録する実装では、このコンポーネントが誤って失われます。 

サイクルにはアーティキュレーションポイントもブリッジもありません。 例えば：```
1
4 4
1 2
2 3
3 4
4 1
```答えは次のとおりです。```
0 0 1 4
```ローリンク値をチェックせずに、訪問したすべての頂点を疑わしいものとしてマークする DFS は、ここで頂点を誤ってカウントします。 

いくつかの二重接続部分がブリッジで接続されているグラフも重要なケースです。 例えば：```
1
6 7
1 2
2 3
3 1
4 5
5 6
6 4
1 4
```答えは次のとおりです。```
2 1 1 1
```3 つの二重接続コンポーネントがありますが、その分数は 3 を最大コンポーネント サイズの 3 で割ると、1 対 1 になります。 小数を減らすのを忘れたソリューションは失敗します。 

## アプローチ

 直接的なアプローチは、すべての頂点とエッジを個別にテストすることです。 頂点の場合は、それを削除し、グラフの走査を実行して、一部のノードが到達不能になるかどうかを確認します。 エッジの場合は、それを取り外して同様に行います。 アーティキュレーション ポイントとブリッジはこれらの削除によって正確に定義されるため、これは正しいです。 ただし、ほぼ同じトラバースを何度も繰り返します。 エッジが多いと演算数が多くなりすぎます。 

重要な観察は、DFS がこれらすべての質問に答えるために必要な情報をすでに公開しているということです。 DFS 中に、すべての頂点が検出時間を受け取ります。 また、頂点ごとに、0 個以上のツリー エッジと最大 1 つのバック エッジを使用して、そのサブツリーから到達可能な最短の検出時間を維持します。 

頂点の子サブツリーがその頂点のどの祖先にも到達できない場合、頂点はそのサブツリーをグラフの残りの部分から分離します。 これによりアーティキュレーションポイントの条件が得られます。 子が別のルートを介して頂点自体に到達することさえできない場合、接続エッジはブリッジになります。 

同じ DFS は二重接続されたコンポーネントを収集できます。 ブリッジを発見するか、別個の二重接続領域を形成するサブツリーの探索を終了するたびに、現在スタックに格納されているエッジは 1 つのコンポーネントに属します。 次に、各コンポーネントがカウントされ、そのエッジ数を使用してコンポーネントの最大サイズが更新されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n(n+m)) | O(n+m) | 遅すぎる |
 | タルジャン DFS | O(n+m) | O(n+m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 検出時間と低リンク値を維持しながら、グラフに対して DFS を実行します。 ローリンク値は、サブツリーから到達できる最も古い祖先を示します。 
2. トラバースされたすべてのエッジがエッジ スタックにプッシュされます。 頂点だけでなくエッジを保持すると、DFS が領域の探索を終了したときに二重接続コンポーネントを再構築できるようになります。 
3. 頂点からの DFS ツリー エッジの場合`u`子供に`v`、 アップデート`low[u]`から戻った後`v`。 もし`low[v] >= tin[u]`、次にスタックからエッジまでのエッジ`u-v`1 つの完全な二重接続コンポーネントを形成します。 不等式は次の部分木を意味します。`v`上記では接続できません`u`。 
4. 同じ子エッジの場合、`low[v] > tin[u]`、エッジ`u-v`橋です。 からの代替パスはありません`v`の側に戻る`u`以上。 
5. 同じローリンク情報を使用してアーティキュレーションポイントをマークします。 非ルート頂点`u`子がある場合はアーティキュレーションポイントです`v`と`low[v] >= tin[u]`。 DFS ルートは、少なくとも 2 つの DFS 子がある場合にのみ重要であるため、特別です。 
6. すべてのコンポーネントが見つかったら、`c`彼らの数になって、`s`エッジ内の最大のコンポーネント サイズになります。 減らす`c/s`最大公約数を使用します。 

正確さは、DFS のローリンクの不変式から得られます。 どの時点でも、`low[v]`は、サブツリーの最上位の祖先を正確に表します。`v`親エッジを使用せずに到達できます。 このため、`low[v] >= tin[u]`これはまさに以下のサブツリーの条件です。`v`～の先祖から切り離されている`u`。 同じ分離プロパティによって、関節点と二重接続コンポーネントの境界の両方が定義されるため、報告されたすべての構造は有効であり、有効な構造が見逃されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case():
    n, m = map(int, input().split())
    graph = [[] for _ in range(n)]
    edges = []
    for i in range(m):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        edges.append((a, b))
        graph[a].append((b, i))
        graph[b].append((a, i))

    tin = [-1] * n
    low = [0] * n
    timer = 0

    edge_stack = []
    components = []
    is_bridge = [False] * m
    is_cut = [False] * n

    sys.setrecursionlimit(1 << 25)

    def dfs(u, parent_edge):
        nonlocal timer
        tin[u] = low[u] = timer
        timer += 1
        children = 0

        for v, eid in graph[u]:
            if eid == parent_edge:
                continue

            if tin[v] == -1:
                edge_stack.append(eid)
                children += 1
                dfs(v, eid)
                low[u] = min(low[u], low[v])

                if low[v] > tin[u]:
                    is_bridge[eid] = True

                if low[v] >= tin[u]:
                    if parent_edge != -1 or children > 1:
                        is_cut[u] = True

                    comp = []
                    while True:
                        x = edge_stack.pop()
                        comp.append(x)
                        if x == eid:
                            break
                    components.append(comp)
            else:
                if tin[v] < tin[u]:
                    edge_stack.append(eid)
                low[u] = min(low[u], tin[v])

    dfs(0, -1)

    cut_count = sum(is_cut)
    bridge_count = sum(is_bridge)
    comp_count = len(components)
    largest = max(len(c) for c in components)

    g = __import__("math").gcd(comp_count, largest)
    return f"{cut_count} {bridge_count} {comp_count // g} {largest // g}"

def main():
    t = int(input())
    ans = []
    for _ in range(t):
        ans.append(solve_case())
    print("\n".join(ans))

if __name__ == "__main__":
    main()
```隣接リストには、隣接する頂点とエッジ インデックスの両方が格納されます。 グラフは無向であり、正確な DFS ツリー エッジを識別する場合、親頂点のみを比較するだけでは十分ではないため、エッジ インデックスが必要です。 

の`edge_stack`二重接続コンポーネントの重要な部分です。 DFS が頂点に到達すると、`low[child] >= tin[parent]`、その境界より上のすべてのエッジは 1 つのコンポーネントに属します。 木の端が削除されるまでポップすると、まさにそのコンポーネントが得られます。 

ブリッジの状態は厳密な比較を使用します。`low[v] > tin[u]`。 等しいということは、直接戻る代替パスがあることを意味します。`u`したがって、エッジは依然としてサイクルに属しています。 関節条件は、`>=`バックエッジでも`u`子サブツリーを上の頂点に接続するのには役立ちません`u`。 

ルート処理はチェックによって分離されます`parent_edge`。 1 つの子を持つルートは削除されても何も切断されませんが、1 つのそのような子を持つ非ルート頂点は依然としてその子のサブツリーを分離できます。

## 複雑さの分析

## テストケース```python
import sys
import io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)

    import math
    input = sys.stdin.readline

    t = int(input())
    out = []

    for _ in range(t):
        n, m = map(int, input().split())
        g = [[] for _ in range(n)]
        for i in range(m):
            a, b = map(int, input().split())
            a -= 1
            b -= 1
            g[a].append((b, i))
            g[b].append((a, i))

        tin = [-1] * n
        low = [0] * n
        bridges = [False] * m
        cut = [False] * n
        stack = []
        comps = []
        timer = 0
        sys.setrecursionlimit(100000)

        def dfs(u, pe):
            nonlocal timer
            tin[u] = low[u] = timer
            timer += 1
            children = 0
            for v, e in g[u]:
                if e == pe:
                    continue
                if tin[v] == -1:
                    stack.append(e)
                    children += 1
                    dfs(v, e)
                    low[u] = min(low[u], low[v])
                    if low[v] > tin[u]:
                        bridges[e] = True
                    if low[v] >= tin[u]:
                        if pe != -1 or children > 1:
                            cut[u] = True
                        c = []
                        while True:
                            x = stack.pop()
                            c.append(x)
                            if x == e:
                                break
                        comps.append(c)
                else:
                    if tin[v] < tin[u]:
                        stack.append(e)
                    low[u] = min(low[u], tin[v])

        dfs(0, -1)
        a = len(comps)
        b = max(map(len, comps))
        g0 = math.gcd(a, b)
        out.append(f"{sum(cut)} {sum(bridges)} {a//g0} {b//g0}")

    sys.stdin = old
    return "\n".join(out)
