 ## 解決策
 ## 問題の理解

 私たちには政党の集まりが与えられており、それぞれが一定の議席を持っています。 「連立」は単にこれらの政党の一部にすぎません。 私たちは、有効な統治連合であるという非常に具体的な概念を満たすサブセットがいくつあるかを数えたいと考えています。 

サブセットは、全議席の厳密に過半数を獲得している場合、つまりサブセット内の議席の合計が全政党の合計の半分より大きい場合に許容されます。 しかし、これでは十分ではありません。 また、連立政権からいずれか一党を排除すると、その政党は直ちに完全多数派でなくなるという意味で、連立政権は最小限のものでなければならない。 したがって、過半数を維持するには連立政権内のすべての政党が不可欠である。 

この制約により、最大 60 の政党が許可され、各政党の議席数は最大 10,000 になります。 これは、サブセットが約 2^60 あるため、すべてのサブセットを直接列挙することは原理的には可能ですが、実際には明らかに不可能であることを直ちに示唆しています。 有効なソリューションはすべて、ブルート フォース サブセットではなく、「最小限の多数」条件で構造を利用する必要があります。 

単純な試みでは、すべてのサブセットを試して両方の条件をチェックします。 2^60 は天文学的に大きく、実行可能な計算をはるかに超えているため、これは失敗します。 

より微妙な失敗のケースは、大部分の条件のみをチェックすることで発生します。 たとえば、合計が半分をわずかに上回るサブセットを取得した場合、それは必ずしも最小であるとは限りません。 合計が 159 である 60, 50, 49 のようなケースを考えてみましょう。サブセット {60, 50} の合計は 110 であり、これは過半数ですが、50 を削除すると 60 が残り、依然として過半数です。 したがって、最初の条件を通過したとしても無効です。 

逆の間違いもよくあります。つまり、多数派を確保せずに最小限度を確保するということです。 すべての要素が「残りの要素と比較して大きい」サブセットであっても、全体の半分を超えることができない可能性があります。 

## アプローチ

 ブルート フォースのアプローチは簡単です。すべてのサブセットを反復処理し、それらの合計を計算し、サブセット内の各要素について、削除によって多数決条件が破られるかどうかを確認します。 これは正しいですが、サブセットの列挙とサブセットごとの検証の両方において指数関数的に複雑になります。 要素が 60 個になると、これは完全に不可能になります。 

重要な観察は、サブセット内の各要素を個別にチェックする依存性を取り除く方法で最小性を再定式化することです。 サブセットに合計があると仮定します。`S_sub`。 要素を削除すると過半数が失われる場合、すべての要素に対して`x`サブセットには以下が必要です。`S_sub - x <= S_total / 2`並べ替えると次のようになります。`x >= S_sub - S_total / 2`これは、サブセット内のすべての要素が、サブセットの合計自体に依存する特定のしきい値以上である必要があることを意味します。 この依存関係は最初は循環しているように見えますが、サブセット内の最小の要素を修正すると管理可能になります。 

サブセットに最小要素があると仮定すると`m`の場合、すべての要素は少なくとも`m`、条件は次のようになります。`S_sub <= S_total / 2 + m`同時に、次のものも必要です。`S_sub > S_total / 2`したがって、固定最小要素の場合、有効なサブセットは、まさにその合計がその最小値によって制御される狭い範囲内にあるサブセットです。 

これは、どの要素が最小であるかによって並べ替えまたは反復し、すべての要素がその値以上の要素の接尾辞に由来するサブセットをカウントすることを示唆しています。 これにより、問題は合計範囲の制約の下でサブセットの合計をカウントすることに変換されます。 

動的計画法を使用してすべてのサフィックスのサブセット合計数を事前に計算し、可能な最小要素ごとに、必要な間隔に該当するサブセット合計の数をクエリできます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n · n) | お(1) | 遅すぎる |
 | サフィックス DP + 最小ピボット | O(n・S) | O(n・S) | 承認済み |

 ここ`S`は議席の合計であり、最大でも約 6e5 です。 

## アルゴリズムのチュートリアル

 最初に最小要素を選択し、次にそれをより大きな要素または同等の要素で拡張することによって各連合がカウントされるように、カウントを再定式化します。 

1. すべての議席の合計を計算し、過半数のしきい値をこの合計の半分として定義します。 
2. 締約国を議席値でソートするか、接尾辞が「最小要素アンカーサブセット」の有効な選択肢を表すように、議席サイズの昇順でインデックスを同等に処理します。 
3. 動的プログラミング テーブルを構築します。`dp[i][s]`インデックスからパーティのみを使用してサブセットを選択する方法の数を表します`i`に`n`その合計は`s`。 
4. この DP を右から左に計算します。 各パーティーごとに`i`を除外するか含めて、それに応じて合計をシフトします。 これにより、すべてのサフィックスが完全なサブセット合計分布を持つことが保証されます。 
5. 各インデックスについて`i`、おやつパーティー`i`連合の最低限の要素として。 それを含む有効な連合は、他のすべてのメンバーをインデックスから選択する必要があります`i+1`これからも。 
6. 最小要素が`p[i]`、次に、サフィックスの選択されたサブセットに対して合計を付けます。`t`、連合総額は次のようになります。`t + p[i]`。 有効性条件を制約に変換します。`t`:

 連合は満足しなければならない`S_total / 2 < t + p[i] <= S_total / 2 + p[i]`、これを単純化すると、`S_total / 2 - p[i] < t <= S_total / 2`。 
7. すべての dp カウントを合計します`t`この間隔でそれぞれ`i`、結果を蓄積します。 

その正しさは、すべての有効な連合が独自の最小要素を持っているという事実から生まれます。 その要素が固定されると、連合の残りの部分は、少なくともその最小値 (接尾語の制限によって保証される) であることを除いて制限されなくなり、多数派/最小限度の制約は単純な合計境界になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    total = sum(a)
    half = total // 2
    
    max_sum = total
    
    dp_next = [0] * (max_sum + 1)
    dp_next[0] = 1
    
    ans = 0
    
    for i in range(n - 1, -1, -1):
        p = a[i]
        
        dp_cur = dp_next[:]  # not take p[i]
        for s in range(max_sum - p, -1, -1):
            if dp_next[s]:
                dp_cur[s + p] += dp_next[s]
        
        dp_next = dp_cur
        
        low = half - p + 1
        high = half
        
        if low < 0:
            low = 0
        
        for t in range(low, high + 1):
            ans += dp_next[t]
    
    print(ans)

if __name__ == "__main__":
    solve()
```DP は最後から構築されるため、`dp_next`常に、現在のインデックスの後に厳密にサフィックスのサブセットを表します。 新しい要素を処理するときは、DP を複製し、現在のシート数を含むトランジションを追加します。 

間隔クエリでは、変換された不等式が使用されます。 下限は`half - p[i] + 1`左辺では厳密な不等式が必要ですが、上限は次の値を含みます。`half`。 

微妙な点は、意図的に再利用していることです。`dp_next`インデックスごとに更新した後、各パーティはサフィックス内の潜在的な最小のサブセットとして正しく扱われます。 

## 実用的な例

 座席を備えた小規模な構成を検討する`[3, 2, 2]`。 合計は7なので、半分は3です。 

サフィックス DP テーブルを構築します。 

インデックス 2 (値 2) の場合、サブセットは次のとおりです。`{}`、`{2}`したがって、合計は 0 と 2 になります。 

インデックス 1 (値 2) の場合、サブセットは次のとおりです。`[2,2]`合計を与える`{0,2,2,4}`。 

インデックス 0 (値 3) の場合、サブセットは次のとおりです。`[3,2,2]`すべての組み合わせを与えます。 

次に、それぞれの最小値を評価します。 

最小 3 の場合、サフィックスは次のとおりです。`[2,2]`。 必要です`t`そのような`3.5 - 3 < t <= 3.5`、 意味`0.5 < t <= 3.5`、とても有効です`t`は`{2}`。 それはサブセットを与えます`{3,2}`そして`{3,2}`(どちらを選択するかによって異なります)、2 つの連合に貢献します。 

インデックス 1 の最小値 2 の場合、サフィックスは次のとおりです。`[2]`。 必要です`3.5 - 2 < t <= 3.5`、 それで`1.5 < t <= 3.5`、与える`t=2`。 それが連合を生み出す`{2,2}`。 

| 最小 | サフィックス | 有効な t 範囲 | 有効な連合 |
 | --- | --- | --- | --- |
 | 3 | [2,2] | (0.5, 3.5] | {3,2} バリアント |
 | 2 | [2] | (1.5, 3.5] | {2,2} |

 これにより、各連合がその最小要素を介して正確に 1 回カウントされることが確認されます。

 ## 特殊なケース

 一人パーティーの場合`[x]`、合計は`x`そして半分は`x/2`。 唯一のサブセットは`{x}`、常に多数派と最小限度を満たします。 サフィックス DP は空のサブセットで始まり、範囲クエリには次のものが含まれるため、DP はこれを正しくカウントします。`t = 0`。 

などのアンバランスが大きい場合`[100, 1, 1, 1]`、最小限の方法で過半数の制約に到達できるのは、100 に固定された連合のみです。 DP は、より小さい要素が独立した多数決セットを形成できないように、サフィックスの合計を正しく制限します。 

次のような対称の場合`[2,2,2]`、すべてのペアは有効な最小多数連合です。 各連合はその固有の最小インデックスに関連付けられているため、正確に 1 回カウントされ、過剰カウントが防止されます。
