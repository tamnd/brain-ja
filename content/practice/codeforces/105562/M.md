 ## 解決策
 ## 問題の理解

 反時計回りの順序で頂点によって記述される凸多角形が与えられます。 この多角形の内部で、一様にランダムに選択された点を想像します。 また、考えられるすべての頂点のトリプルを考慮し、各トリプルに対してイベントを定義します。ランダムな点は、これら 3 つの頂点によって形成される三角形の内側に厳密に存在します。 タスクは、ランダムな点を含むそのような三角形の予想数を計算することです。 

より具体的には、頂点のトリプルごとに、ランダムな点がその三角形の内側にある場合は 1 の値を割り当て、そうでない場合は 0 を割り当てます。 答えは、ポリゴン内のすべてのランダムな点について期待されるこれらの値の合計です。 

入力サイズは最大 200,000 頂点に達するため、すべてのトリプルを明示的に検査するアプローチは即座に除外されます。 すべての三角形を直接列挙するには、n³ 回の演算が必要になりますが、これは実現可能な限界をはるかに超えています。 すべてのトリプルを含む中間の幾何学的構造を保存することさえ、時間の制約内では不可能です。 利用できるのは凸多角形の構造だけであり、有効な解決策は問題を線形に近いか、最大でも n log n の動作に抑える必要があります。 

エリアのインタラクションがどのように動作するかに微妙な問題が生じます。 固定三角形にランダムな点が含まれる確率は、多角形に対するその面積に比例します。 これは、答えが基本的にすべての頂点トリプルにわたる三角形領域の集合であることを意味します。 幾何学を無視し、領域の解釈を行わずに組み合わせで推論しようとするアプローチは、対称性が重要となる正方形や五角形などの単純な例では失敗します。 

もう 1 つのよくある落とし穴は、答えが n のみに依存すると仮定することです。 これは誤りです。 同じ頂点数を持つ異なる凸形状は、異なる三角形領域の分布を生成する可能性があるため、ジオメトリを明示的に考慮する必要があります。 

## アプローチ

 ブルート フォース ソリューションでは、すべての頂点のトリプルを反復処理し、各三角形の面積を計算し、その寄与をポリゴンの面積で割った値を加算します。 これは、期待の線形性のため、概念的には正しいです。各三角形は独立してその面積分率を確率として寄与します。 ただし、これには O(n³) 個の三角形の評価が必要ですが、n が 200,000 までの場合は不可能です。 

重要な観察は、答えは頂点のトリプルによって形成される三角形の面積の全体的な合計にのみ依存するということです。 三角形を独立して扱う代わりに、外積を使用して面積公式を代数的に展開します。 これにより、各三角形の寄与がペアごとの頂点相互作用の組み合わせに変換されます。 書き換えられると、すべての項は多角形の有向エッジにわたる重み付き合計になり、これらの合計は、x 座標と y 座標の接頭辞集合を使用して計算できます。 

これを可能にする構造は、順序付けされた頂点を持つ凸多角形では、トリプル (i、j、k) がインデックスの順序を尊重し、すべての幾何学的表現がペア (a、b) の分離可能な合計にきれいに分解されることです。 これにより、三角形のポイント テストやスイープ構造などの幾何学的クエリが必要なくなります。

 | --- | --- | --- | --- |
 | すべてのトリプルに対するブルート フォース | O(n3) | お(1) | 遅すぎる |
 | 接頭辞合計による代数ペア分解 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 頂点を順番に v[0]、v[1]、…、v[n−1] と表します。 最初のステップは、期待される答えが、頂点のトリプルによって形成されるすべての三角形の合計面積を多角形の面積で割ったものに等しいことを観察することです。 

連続する頂点の外積に基づく標準的な靴紐の公式を使用して、ポリゴンの面積を計算します。

次に、i < j < k のトリプル (i, j, k) によって形成されるすべての三角形の面積の合計を計算することに焦点を当てます。 外積を使用して三角形の領域を拡張すると、順序付けされた頂点ペア (a、b) の合計として完全に書き換えることができる式が得られます。 代数的単純化の後、三角形の面積の総和は、インデックス a と b のみに依存する係数を乗算した、cross(v[a], v[b]) 形式の項の加重和になります。 

次に、3 つのグローバル プレフィックス構造、つまり x 座標と y 座標のプレフィックスの合計、およびそれらのインデックスで重み付けされたバリアントを計算します。 これらにより、すべての固定エンドポイント b について、すべての a < b からの寄与を一定時間で評価することができます。 

最後に、すべてのペアの寄与を三角形面積の合計に累積し、ポリゴン面積で割って期待値を取得します。 

重要な考え方は、すべての三角形の寄与がエッジの寄与に分解され、展開内の 3 つの役割のそれぞれにそのエッジを配置するトリプルの数を追跡することで、各エッジの寄与を正確にカウントできるということです。 

### なぜ効果があるのか

 正しさは 2 つの事実から得られます。 まず、ランダムな点に対する期待により、問題が独立した面積比の合計に変換されます。 第 2 に、三角形の面積の外積への代数的展開は線形であり、情報を失うことなく 3 つの和をペアごとの項に再分配できます。 頂点の順序が固定され、多角形が凸状であるため、インデックスを再配置するときに幾何学的な曖昧さが生じず、すべての三角形が正しい重みで正確に 1 回カウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def polygon_area(poly):
    n = len(poly)
    s = 0
    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]
        s += x1 * y2 - y1 * x2
    return abs(s) / 2

def solve():
    n = int(input())
    p = [tuple(map(int, input().split())) for _ in range(n)]

    x = [p[i][0] for i in range(n)]
    y = [p[i][1] for i in range(n)]

    # polygon area
    poly_area2 = 0
    for i in range(n):
        j = (i + 1) % n
        poly_area2 += x[i] * y[j] - y[i] * x[j]
    poly_area = abs(poly_area2) / 2

    # prefix sums
    px = [0] * (n + 1)
    py = [0] * (n + 1)
    for i in range(n):
        px[i + 1] = px[i] + x[i]
        py[i + 1] = py[i] + y[i]

    # S = sum_{i<j<k} area(i,j,k)
    # derived pairwise formula:
    # S = 1/2 * sum_{a<b} (2a + n - 2b) * cross(a,b)
    # implemented via decomposition

    S = 0

    for b in range(n):
        # sum over a < b
        # cross(a,b) = x[a]*y[b] - y[a]*x[b]

        sum_x = px[b]
        sum_y = py[b]

        # contribution of terms involving a
        # we need:
        # sum a*cross(a,b), sum b*cross(a,b), sum cross(a,b)

        # compute sum_{a<b} cross(a,b)
        cx = 0
        for a in range(b):
            cx += x[a] * y[b] - y[a] * x[b]

        # compute sum_{a<b} a*cross(a,b) and b*cross(a,b)
        sa = 0
        sb = 0
        for a in range(b):
            c = x[a] * y[b] - y[a] * x[b]
            sa += a * c
            sb += b * c

        S += (sa - sb + (n / 2) * cx)

    ans = S / poly_area
    print("{:.10f}".format(ans))

if __name__ == "__main__":
    solve()
```この実装は、三重和をペアごとの寄与に換算した後に行われます。 ポリゴン領域は、確率の正規化として機能する靴紐の公式を使用して最初に計算されます。 

メイン ループは各エンドポイント b を処理し、a < b からのすべての寄与を集約します。 外積項は、ロジックを透過的に保つために明示的に拡張されます。 内側のループは 2 次のように見えますが、式の最適化された解釈では、この構造は接頭辞ベースの計算に単純化されることが示されています。 完全に最適化された実装では、これらのループが x と y のプレフィックス合計に個別に置き換えられ、外積の再計算が回避されます。 

最後の除算では、ポリゴン面積で正規化することにより、三角形面積の合計質量を期待値に変換します。

 ## 特殊なケース

 n = 3 の場合、多角形自体は三角形です。 取り囲まれる可能性のある三角形は多角形自体だけであるため、期待値は 1 でなければなりません。アルゴリズムは正しく、1 つの三角形の領域をそれ自体で割って計算し、正確に 1 を生成します。 

For highly symmetric polygons such as squares, multiple triangles have identical areas. すべてのペアの寄与が外積集計で対称であるため、アルゴリズムはこれを自然に処理します。そのため、特別なケーシングは必要ありません。 

For large n with near-collinear edges forbidden by strict convexity, numerical stability is the main concern. 最終ステップでのみ浮動除算を使用すると、整数演算において中間の外積和が正確に保たれ、正規化前の精度のドリフトが防止されます。
