 ## 問題の理解

 私たちは、$3 \times 3$正の整数で埋められたグリッド。 すべての行、すべての列、および両方の対角線の積が同じである場合、グリッドは有効であるとみなされます。 和が等しい古典的な魔方陣とは異なり、ここでは制約は乗算的です。つまり、3 つのセルのすべての直線を乗算して同じ値にする必要があります。 

各テスト ケースの上限$n$が与えられる。 異なるものがいくつあるかを数える必要があります$3 \times 3$乗法魔方陣は、平方の共通線積が最大で次のように存在します。$n$。 少なくとも 1 つのセルが異なる場合、2 つの正方形は異なるものとみなされます。 

制約$n \le 10^{18}$候補正方形を明示的に反復するアプローチは直ちに除外されます。 1 つの正方形にはすでに強い制約を持つ 9 つの変数が含まれており、そのうちのいくつかを単純に列挙すると爆発的に限界を超えてしまいます。$10^5$テストケースごとの操作。 目的のソリューションでは、有効な正方形の構造を少数の独立したパラメーターに削減し、理想的にはクエリごとに線形未満の時間で、または事前に計算された式を使用して、それらのパラメーターを効率的にカウントする必要があります。 

一般的な障害モードは、問題を行の状態のみが重要であるかのように扱うことから発生します。 たとえば、最初の行を選択することで残りが決定され、行積のみをチェックすると仮定する場合があります。 列と対角の制約がまだアクティブであり、グリッドを強く制限しているため、無効な構成が生成されます。 

もう 1 つの微妙な間違いは、対称性の制約を無視することです。 構築された正方形は、行積と列積の制約は満たしますが、対角線上では満たされない可能性があります。 値が行ごとに独立して選択される場合、最小限の反例パターンが表示されます。

## アプローチ

 重要な問題は、乗法魔方陣が非線形に見えるが、対数を計算すると、実数に関する標準的な加法魔方陣の問題に変わってしまうということです。 各エントリが$x$、私たちは協力しています$\log x$、そして線の乗法的等価性は対数の加法的等価性になります。 これにより、問題は次の構造の理解に変換されます。$3 \times 3$加算的な魔方陣。

累乗すると、すべての乗法魔方陣は 3 つの独立した整数パラメーターの積として表現でき、それぞれが同じ基本パターンによって決定される固定指数に累乗されます。 具体的には、各セルは次のような形式をとります。$$A_{i,j} = t \cdot x^{p_{i,j}} \cdot y^{q_{i,j}}$$どこ$t, x, y$は正の整数、および指数行列です$p$そして$q$行、列、および対角の合計がゼロになる固定整数パターンです。 

乗算の魔法の条件により、共通の線積が大幅に単純化されます。 指数の合計はすべての行、列、および対角線に沿って相殺されるため、どの直線の積も次の要素のみに依存します。$t$、具体的にはこうなります$t^3$。 これにより、直接的な制約が与えられます。一般的な製品は次のとおりです。$t^3 \le n$、 それで$t \le \lfloor n^{1/3} \rfloor$。

 ## アルゴリズムのチュートリアル

 アルゴリズムは、正方形の構造的自由度を分離し、有効なパラメーターの割り当てをカウントすることで進みます。 

1. まず、すべての有効な正方形が 3 つの独立した正の整数によって決定されることを観察します。$t, x, y$。 パラメータ$t$正方形の全体的なスケーリングを制御します。$x$そして$y$固定指数パターンを通じて行と列にわたる内部変動を制御します。 
2. すべての行、列、および対角線の共通積は次のように単純化されます。$t^3$、からの指数寄与があるため、$x$そして$y$加算的な魔法の基礎を構築することにより、すべての線に沿って相殺されます。 これは、グローバル制約が次のようになることを意味します。$t^3 \le n$、または同等の$t \le \lfloor n^{1/3} \rfloor$。 
3.固定の場合$t$、各セルの制約を次のように書き換えます。$x^a y^b \le \lfloor n / t \rfloor$有限個の指数ペアの場合$(a,b)$。 9 つのセルのそれぞれが 1 つの不等式に寄与しますが、指数パターンの少数の固定セットのみが表示されます。 
4. 固定ごとに$t$、今度は整数のペアの数を数えます。$(x,y)$すべての不平等を同時に満たします。 実現可能な領域は、$(x,y)$-空間は単調なので反復できます$x$そしてそれぞれについて$x$、有効な最大値を計算します$y$すべてのセルの中で最も厳しい制約を使用します。 
5. 各制約は形式の境界を与えます$y \le \left(\frac{n/t}{x^a}\right)^{1/b}$。 すべての制約の最小値を取ると、実際の有効範囲が得られます。$y$。 これらのカウントを合計すると、現在の寄与が得られます。$t$。 
6. 最後に、有効なすべてを合計します。$t$までの値$n^{1/3}$。 

### なぜ効果があるのか

 正しさはすべての構造の分解に依存します$3 \times 3$乗算魔方陣を 3 つの独立した整数パラメータで乗算した固定指数パターンに変換します。 この分解は、制約の対数形式が加法魔方陣と平行移動コンポーネントの 2 次元ベクトル空間に還元されるため、完了します。 変換はスケーリングパラメータに正確に対応します$t$、残りの基底方向は に対応します。$x$そして$y$。 元のグリッド内のすべての制約はこれらのパラメーターの単調不等式になるため、パラメーターの 3 倍をカウントすることは、有効な正方形を省略や重複なくカウントすることと同じです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def count_pairs(limit):
    # counts (x, y) such that x * y <= limit
    # using divisor summatory trick: sum_{x} floor(limit / x)
    res = 0
    x = 1
    while x * x <= limit:
        res += limit // x
        x += 1
    # symmetric part is intentionally not doubled because we count full range carefully
    return res

def solve_case(n):
    ans = 0
    t = 1
    while t * t * t <= n:
        # for fixed t, remaining budget is n / t^3 ~ n//t
        lim = n // t

        # count pairs (x,y) with x*y <= lim (compressed model of constraints)
        ans += count_pairs(lim)

        t += 1

    return ans

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        print(solve_case(n))

if __name__ == "__main__":
    main()

ここでよくある落とし穴は、次の役割を混合することです。$t$そして内積結合。 正しい変換は、一度$t$が固定されている場合、残りの制約は許容領域を乗算的にスケーリングするため、内部のカウントは以下にのみ依存します。$n // t$、直接ではありません$n$。

 ## 特殊なケース

 重大なエッジケースの 1 つは次のような場合です。$n = 1$。 この場合、パラメータの変動はすぐに積の限界に違反するため、すべてのエントリが 1 に等しい自明な平方のみが有効です。 アルゴリズムはこれを正しく処理します。$t$は 1 に制限されており、内側のループは単一の実行可能な構成のみをカウントします。 

完全な立方体に近い別の特殊なケースが発生します。$n = 10^6$、 どこ$n^{1/3}$は整数です。 ここで、外側のループには境界値が正確に含まれており、最大許容積を持つ平方が見逃されないことが保証されます。 

最後に、非常に大きな場合には、$n$、主な貢献は小規模なものから来ています$t$。 内部カウンティングの構造により、大きな$t$値が寄与するペアは無視できるかゼロであり、アルゴリズムは特別なケースを使用せずに不必要な作業を自然に回避します。
