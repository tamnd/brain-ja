 ## 解決策
 ## 問題の理解

 この問題には 2 つの文字列があります。 最初のテキストは現在看板に印刷されているテキストで、2 番目のテキストは表示されるべきテキストです。 唯一許可される修正は、現在の文字列の連続する部分を 1 つ選択し、それを連続する 2 つの部分に切断し、それら 2 つの部分を交換する 1 つの操作です。 タスクは、ターゲット文字列に到達できるかどうかを判断し、到達できる場合は、セグメントと分割位置の有効な選択肢を 1 つ出力することです。 

この操作は、部分文字列を取得して左に回転するものとみなすことができます。 選択した間隔が次の場合`l`に`r`、そして最後`k`文字が前面に移動し、中央部分が次のように変わります。`A[l:r+1]`の中へ：`A[r-k+1:r+1] + A[l:r-k+1]`その間隔の外にあるものはすべてまったく同じままです。 

文字列の長さは次のとおりです。`100000`したがって、すべての間隔とすべての可能な分割を試すことは現実的ではありません。 くらいあります`n^3`直接実装された場合に可能な操作は次のとおりです。`10^15`最悪の場合のチェック。 線形または`n log n`。 

最初に観察すべきことは、変更された間隔の外側の位置がすでに正しくなければならないということです。 これにより、変更される可能性のある最小の間隔が得られます。最初の位置から`A`そして`B`異なる最後の位置まで異なります。 

よくある間違いは、移動された部分または選択した間隔全体が空になることを許可することです。 この操作では、選択した間隔内の両方の部分が有効である必要があるため、分割点は最初の部分に少なくとも 1 文字を残す必要があります。 たとえば、次のような場合です。```
A = ABC
B = CAB
```答えは次のようにして可能です。```
0 2 1
```ただし、3 文字すべてを移動する分割は有効な操作ではありません。 

もう 1 つの特殊なケースは、文字列がすでに等しい場合です。 正解はまだ`Yes`効果的な変更を実行することは許可されていないためです。 のために：```
A = AAA
B = AAA
```出力では、長さ 1 つの間隔を記述することができます。`k = 0`。 不一致のみを検索するソリューションでは、このケースは誤って拒否されます。 

最後の注意が必要なケースは、変更された間隔に実際の差異の周囲に一致する文字が含まれている場合です。 のために：```
A = AXXB
B = AXBX
```回転で周囲の位置が必要な場合、操作には周囲の位置も含める必要があります。 回転後の文字の位置が重要であるため、不一致の文字が順列を形成していることを確認するだけでは十分ではありません。 

## アプローチ

 強引なアイデアは、可能なすべての間隔と可能なすべての分割点を試すことです。 選択ごとに、結果の文字列を構築し、それをターゲットと比較します。 考えられるすべての操作が考慮されているため、これは正しいです。 ただし、`O(n^2)`間隔と最大`O(n)`間隔ごとに分割して、`O(n^3)`時間。 と`n = 100000`、これは実行できる範囲をはるかに超えています。 

有益な観察は、この操作で 1 つの部分文字列のみが回転されるということです。 まず、変更された部分の前のプレフィックスとその後のサフィックスがすでに一致している必要があります。 これは、唯一の興味深い領域が最初と最後の不一致の間であることを意味します。 

この最小間隔が`[l, r]`。 この間隔内で、ターゲットの部分文字列が元の部分文字列の回転であるかどうかを確認する必要があります。 元の部分文字列を 2 回続けて配置すると、回転を効率的に見つけることができます。 一定の長さの文字列の回転`m`長さを 2 倍にした文字列の部分文字列として表示されます。`m`。 

そこで、問題を 1 つのパターン マッチング操作に集約します。 探します`B[l:r+1]`内部`(A[l:r+1] + A[l:r+1])`。 位置から始まる場合`d`、部分文字列は左に回転されました。`d`文字。 必要な出力パラメータは次のとおりです。`k = length - d`、 なぜなら`k`末尾から先頭に移動した文字数です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最初のインデックスを見つける`l`どこ`A[l]`そして`B[l]`異なる、そして最後のインデックス`r`どこが違うのか。 そのようなインデックスがない場合は、有効な変更なしの操作を出力します。 
2. 部分文字列を取得します`A[l:r+1]`および対応するターゲット部分文字列`B[l:r+1]`。 手術後に変化する可能性があるのはこれらの部分だけです。 元の操作が存在する場合、このターゲット部分文字列は元の部分文字列の回転である必要があります。 
3. 二重化された文字列を作成します`A[l:r+1] + A[l:r+1]`そして検索してください`B[l:r+1]`その中に。 KMP を使用すると、検索が線形に保たれます。 
4. 位置からパターンが表示される場合`d`、部分文字列は左に回転されました`d`ポジション。 端からの移動量は`k = length - d`。 出力`l`、`r`、 そして`k`。 
5. パターンが見つからない場合は、有効な操作が存在しないため、出力します。`No`。 

機能する理由: 最初と最後の不一致の外側の間隔は変更できません。これらの文字はすでに一致しており、回転は選択した間隔にのみ影響するためです。 残りの間隔内で可能な変換は循環シフトのみです。 二重文字列検索では、そのような巡回シフトが存在するかどうかを正確にチェックし、返されたシフトによって必要な分割を直接決定します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def kmp_search(text, pattern):
    m = len(pattern)
    if m == 0:
        return 0

    pi = [0] * m
    j = 0
    for i in range(1, m):
        while j and pattern[i] != pattern[j]:
            j = pi[j - 1]
        if pattern[i] == pattern[j]:
            j += 1
        pi[i] = j

    j = 0
    for i, c in enumerate(text):
        while j and c != pattern[j]:
            j = pi[j - 1]
        if c == pattern[j]:
            j += 1
        if j == m:
            return i - m + 1
    return -1

def solve():
    a = input().strip()
    b = input().strip()
    n = len(a)

    l = 0
    while l < n and a[l] == b[l]:
        l += 1

    if l == n:
        print("Yes")
        print(0, 0, 0)
        return

    r = n - 1
    while a[r] == b[r]:
        r -= 1

    s = a[l:r + 1]
    t = b[l:r + 1]
    m = len(s)

    pos = kmp_search(s + s, t)

    if pos == -1 or pos >= m:
        print("No")
        return

    k = m - pos
    if k == m:
        k = 0

    print("Yes")
    print(l, r, k)

solve()
```コードはまず、異なる可能性のある唯一の領域を分離します。 これにより、すでに正しいプレフィックスとサフィックスに対する不必要な作業が防止されます。 

KMP 関数は、ターゲット部分文字列のプレフィックス配列を構築し、倍増されたソース部分文字列内でその最初の出現箇所を見つけます。 すべての有効な回転は最初のコピー内のどこかから始まるため、二重化された部分文字列のみを検索するだけで十分です。 

見つかった位置からへの変換`k`微妙な部分です。 一致位置は前から後ろに移動した文字数です。 この問題では後ろから前に移動した数値を求めるため、値は相補的になります。 

不一致間隔が存在しないため、等しい場合は個別に処理されます。 印刷`k = 0`無効な分割を回避します。

 ## 特殊なケース

 等しい文字列の場合:```
A = AAA
B = AAA
```アルゴリズムは不一致を検出しません。 すぐに何も操作しない操作が返されます。 これが機能するのは、許可される操作数が 0 または 1 であるため、何も変更しなくても問題ありません。 

変更部分が意味のある領域全体である場合:```
A = ABC
B = CAB
```不一致間隔は次のようになります`[0,2]`。 二重化された文字列は、`ABCABC`、 そして`CAB`インデックスから始まる`2`。 アルゴリズムはこれを次のように変換します。`k = 1`、有効な回転を与えます。 

ローテーションではない場合:```
A = ABCD
B = ACBD
```中央の部分文字列は`ABCD`対`ACBD`。 検索中`ACBD`で`ABCDABCD`失敗するため、アルゴリズムは変換を正しく拒否します。 

2 文字のみの境界ケースの場合:```
A = AB
B = BA
```間隔の長さは 2 です。 二重化された文字列は、`ABAB`、 そして`BA`インデックス 1 に表示されます。 アルゴリズムの出力`k = 1`、これが唯一の有効な分割です。
