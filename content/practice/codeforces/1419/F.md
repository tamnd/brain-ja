 ## 解決策
 ## 問題の理解

 値を修正する`t`。 

ブリムストーンは、任意の時間だけ任意の分遣隊で待機することができます。 彼が移動することを決定したとき、彼は 4 つの軸方向の 1 つを選択し、その光線上にある最初の分遣隊に到達するまで移動を続けます。 

2 つの分遣隊が同じ垂直線または水平線上にあり、それらの距離は最大で`t`。 ブリムストーンは常に軌道衝突直後に移動を開始し、次の衝突の前に到着することができます。 待ち時間は無料なので、移動時間が最長の移動はすべて可能です。`t`いつでも使える。 

これにより、ジオメトリがグラフの問題に変わります。 

剥離を頂点とするグラフを作成します。 2 つの分遣隊が共有する場合、接続されます。`x`座標または`y`座標とその線に沿ったマンハッタン距離は最大でも`t`。 

固定の場合`t`, ブリムストーンは、追加の頂点を 1 つ以上追加した後にこのグラフが接続された場合に限り、すべての分遣隊を訪問できます。 

座標の大きさは次のとおりです`10^9`、しかし、それしかありません`1000`ポイント。 これは、グラフ構造が座標平面のサイズではなく、指定された点のみに依存することを直ちに示唆しています。 アン`O(n^2)`グラフの構築は完全に許容されますが、座標グリッド全体に関わるものは不可能です。 

微妙なエッジ ケースは、単一の新しいポイントがすべてに触れることのできない、複数の切断されたコンポーネントで構成される構成です。 

例：```
(0,0)   (100,100)   (200,200)
```あらゆる有限に対して`t`の場合、新しいポイントはこれらのポイントのうち水平方向には最大 1 つ、垂直方向には最大 1 つと接続できるため、3 つのコンポーネントすべてをマージすることはできません。 正しい答えは、`-1`。 

もう 1 つの簡単な間違いは、新しい点を既存の座標に配置する必要があると仮定することです。 考慮する：```
(0,100)
(100,0)
(-100,0)
(0,-100)
```最適な新しいポイントは`(0,0)`, これはもともと存在しません。 答えは`100`。 

## アプローチ

 ブルートフォースのアイデアは単純です。 二分探索の答え`t`。 候補値ごとにグラフを構築し、整数座標点を追加してグラフを接続できるかどうかをテストします。 

ネックとなるのは追加点の配置だ。 座標の範囲は次のとおりです`10^9`, そのため、考えられる場所を列挙することは絶望的です。 

重要な観察は、固定された`t`、新しい点は、接続できる頂点を通じてのみ重要になります。 

新しいポイント`(X,Y)`既存のポイントに接続します`(x,y)`いずれかの場合:```
X = x and |Y - y| ≤ t
```または```
Y = y and |X - x| ≤ t
```成功した配置が存在するとします。 これらの不平等のいずれかが厳しくなるまで新しいポイントをスライドさせても、接続性は悪化しません。 したがって、関連するすべての x 座標は次の形式になります。```
x_i - t, x_i, x_i + t
```関連するすべての y 座標は次の形式になります。```
y_i - t, y_i, y_i + t
```あるのは`O(n)`そのような候補 x 値と`O(n)`候補の y 値。 座標圧縮後のみ`O(n^2)`配置候補は残っています。 

配置候補ごとに、新しい頂点を到達可能なすべての元の頂点に一時的に接続し、グラフ全体が接続されるかどうかを確認します。 候補がたくさんあるため、毎回 DSU を再構築するのはコストがかかりすぎます。 ロールバック DSU を使用すると、一時的なエッジを追加し、接続をテストし、ほぼ一定の時間でそれらを元に戻すことができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 座標上のブルート フォース配置 | 座標範囲内の指数 | O(n²) | 不可能 |
 | 二分探索 + 圧縮候補 + ロールバック DSU | O(n² log V) | O(n²) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 実現可能な最小値を二分探索する`t`。 
2. 固定の場合`t`、オリジナル上に DSU を構築します。`n`分遣隊。 
3. X 座標または Y 座標を共有し、その距離が最大で`t`。 
4. すべての元の頂点がすでに 1 つの DSU コンポーネントに属している場合、これは`t`実現可能です。 
5. すべての候補 x 値を生成します。```
x_i - t, x_i, x_i + t
```およびすべての候補 y 値:```
y_i - t, y_i, y_i + t
```6. これらの値を座標圧縮します。 
7. 番号付きの DSU 頂点を 1 つ追加します。`n + 1`、新たな分離の可能性を表しています。 
8. すべての圧縮ペアについて`(X,Y)`:

 1.頂点を仮接続する`n+1`柱上のすべての点に`X`誰との垂直距離`Y`せいぜい`t`。 
2. 頂点を仮接続する`n+1`行上のすべての点に`Y`誰との水平距離`X`せいぜい`t`。 
3. DSU コンポーネントに頂点が含まれているかどうかを確認します`1`サイズがあります`n+1`。 
4. すべての一時マージをロールバックします。 
9. いくつかの候補者の配置が成功すると、現在の`t`実現可能です。 
10. 実現可能な最小値を求める二分探索`t`。 

### なぜ効果があるのか

 固定の場合`t`、有効な移動によって形成されたグラフは、軌道攻撃の間にどのデタッチメントを連続して訪問できるかを正確に示しています。 

新しい分離を追加すると、その新しい頂点に付随するエッジのみが導入されます。 成功した配置が存在する場合は、その x 座標を最も近い値に移動します。`x_i-t`、`x_i`、`x_i+t`y に対して同じことを行っても、有用な接続は削除できません。 したがって、圧縮された候補座標の中にいくつかの成功した配置が表示されます。 

ロールバック DSU は常に、元のグラフの接続性と、現在テストされている配置に対応する一時的なエッジを表します。 すべての接続性`n+1`頂点はまさにすべての分遣隊を訪問できる条件です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class RollbackDSU:
    def __init__(self, n):
        self.fa = list(range(n))
        self.sz = [1] * n
        self.stk = []

    def find(self, x):
        while self.fa[x] != x:
            x = self.fa[x]
        return x

    def union(self, a, b, record):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return
        if self.sz[a] > self.sz[b]:
            a, b = b, a

        if record:
            self.stk.append(a)

        self.fa[a] = b
        self.sz[b] += self.sz[a]

    def rollback(self):
        while self.stk:
            a = self.stk.pop()
            b = self.fa[a]
            self.sz[b] -= self.sz[a]
            self.fa[a] = a

n = int(input())
orig = [tuple(map(int, input().split())) for _ in range(n)]

def check(t):
    dsu = RollbackDSU(n + 1)

    for i in range(n):
        xi, yi = orig[i]
        for j in range(i + 1, n):
            xj, yj = orig[j]

            if xi == xj and abs(yi - yj) <= t:
                dsu.union(i, j, False)

            if yi == yj and abs(xi - xj) <= t:
                dsu.union(i, j, False)

    if dsu.sz[dsu.find(0)] == n:
        return True

    xs = []
    ys = []

    for x, y in orig:
        xs.extend((x - t, x, x + t))
        ys.extend((y - t, y, y + t))

    xs = sorted(set(xs))
    ys = sorted(set(ys))

    vx = [[] for _ in range(len(xs))]
    vy = [[] for _ in range(len(ys))]

    xid = {v: i for i, v in enumerate(xs)}
    yid = {v: i for i, v in enumerate(ys)}

    px = [0] * n
    py = [0] * n

    for i, (x, y) in enumerate(orig):
        px[i] = xid[x]
        py[i] = yid[y]
        vx[px[i]].append(i)
        vy[py[i]].append(i)

    extra = n

    for X in range(len(xs)):
        for Y in range(len(ys)):

            for idx in vx[X]:
                if abs(ys[Y] - orig[idx][1]) <= t:
                    dsu.union(idx, extra, True)

            for idx in vy[Y]:
                if abs(xs[X] - orig[idx][0]) <= t:
                    dsu.union(idx, extra, True)

            if dsu.sz[dsu.find(0)] == n + 1:
                return True

            dsu.rollback()

    return False

lo, hi = 0, 2_000_000_000
ans = -1

while lo <= hi:
    mid = (lo + hi) // 2

    if check(mid):
        ans = mid
        hi = mid - 1
    else:
        lo = mid + 1

print(ans)
```最初の DSU パスは、現在の値の接続グラフを構築します。`t`。 これらの結合は、実現可能性チェック全体にわたって永続的です。 

候補座標は次から生成されます。`{x_i-t, x_i, x_i+t}`そして`{y_i-t, y_i, y_i+t}`。 圧縮後、`vx`特定の圧縮された x 座標を持つすべての点を保存し、`vy`y に対しても同じことを行います。 

各候補配置では、追加の頂点に接触するエッジのみが追加されます。 これらの結合はロールバック操作としてマークされます。 候補をテストした後、DSU は元のグラフのみを含む状態に戻ります。 

DSU は意図的にパス圧縮を使用しません。 ロールバック DSU では、親の変更を元に戻せる必要があります。 

## 実用的な例

 ### サンプル 1

 入力:```
4
100 0
0 100
-100 0
0 -100
```のために`t = 100`:

 | 候補点 | 接続された元の頂点 |
 | --- | --- |
 | (0,0) | 4点すべて |
 | その他 | 頂点が少なくなる |

 オリジナルのポイントによって形成された DSU には、4 つの独立したコンポーネントがあります。 追加`(0,0)`それぞれが正確に位置するため、すべての点が接続されます`100`同じ行または列上で単位が離れています。 5 つの頂点すべてが接続されます。 

これは、最適な点が入力に存在しない理由を示しています。 

### 不可能な構成```
3
0 0
100 100
200 200
```あらゆる有限に対して`t`:

 | 候補点 | 同じ行/列を通じて到達可能な頂点 |
 | --- | --- |
 | 任意 | 最大 2 つのコンポーネント |
 | 可能な限り最善の方法 | まだ 3 つすべてではありません |

 2 つの元の点が X 座標または Y 座標を共有することはありません。 1 つの追加ポイントでは、必要なすべての行と列の配置を同時に作成することはできません。 実現可能性テストは常に失敗するため、答えは次のとおりです。`-1`。

 ## 特殊なケース

 次のことを考慮してください。```
3
0 0
100 100
200 200
```行または列を共有するペアはありません。 元の DSU には 3 つのコンポーネントがあります。 すべての候補配置では、点の限られたサブセットへの行または列の接続のみが作成されます。 ロールバック DSU がサイズに達しない`n+1`、 それで`check(t)`は常に false であり、最終的な答えは`-1`。 

考慮する：```
4
100 0
0 100
-100 0
0 -100
```のために`t=99`、候補配置が 4 つの頂点すべてに到達することはありません。 のために`t=100`、候補者`(0,0)`圧縮された座標セットに表示され、すべての元の点に接続されます。 DSU コンポーネントのサイズは次のようになります。`5`、正確に答えを出します`100`。 

考慮する：```
2
0 0
0 1
```元のグラフはすでに接続されています`t=1`。 実現可能性テストのステップ 4 ではこれを即座に検出し、不必要な候補の列挙を回避します。 これは、新しい分離を追加することが無駄な場合に対処します。
