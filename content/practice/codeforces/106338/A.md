 ## 問題の理解

 寸法を持つ単位立方体で構成される直方体ブロックが与えられます。$a \times b \times c$。 このブロック内のすべての単位立方体には、角、端、面、または完全な内部など、位置に応じて、外面に露出した面がいくつかあります。 タスクは、ブロック全体の外側をペイントした後、合計で何個の単位立方体の面がペイントされるかを計算することです。 

入力は 3 つの次元で構成され、出力はすべての単位立方体にわたるペイントされた面の合計数を表す単一の整数です。 各立方体は、ブロックの外面にある側面の数に等しい数のペイント面を提供します。 

問題の構造は完全に幾何学的なものですが、計算は各カテゴリー (コーナー、エッジ、面、内部) に該当する立方体の数を注意深く数えることになります。 

制約は十分小さいので、$O(1)$という式が予想されます。 すべてのキューブを反復するアプローチは次のようにスケールされます。$O(abc)$これは、次元が数千を超えるとすぐに実行不可能になります。 でさえ$100 \times 100 \times 100$これはすでに 100 万個のキューブであり、より大きな非表示テストの場合は失敗します。 

主な困難は計算ではなく、組み合わせです。 課題は、すべての立方体を二重にカウントせずに正しく分類し、1 つ以上の次元が 1 に等しい縮退ケースを処理することです。これらのケースでは、ジオメトリが完全に変更され、面が線または単一の点に崩壊し、完全な 3D 構造が壊れることを想定した単純な数式が使用されます。 

よくある間違いは、標準を使用することです$2(ab + bc + ca)$表面積の式を直接使用すると、面は正しくカウントされますが、ブロックが事実上 2D または 1D である縮退ケースでは、問題の立方体ごとの面カウントの解釈と一致しません。 

## アプローチ

 ブルート フォース手法では、ブロックを明示的に構築し、すべてのキューブをチェックします。 位置にある各立方体について$(i, j, k)$、6 つの面のうちのいくつが境界上にあるかを数えます。 もし$i$1 または$a$、 または$j$1 または$b$、 または$k$1 または$c$、そのような各条件が 1 つのペイントされた面に寄与します。 すべての立方体を合計すると、答えが直接得られます。 これは定義に正確に従っているので正しいですが、次のことが必要です。$abc$反復は、次元が適度に大きくなるとすぐに遅くなりすぎます。 

重要な観察は、立方体が構造の対称性によってグループ化できるということです。 すべての立方体を反復処理するのではなく、コーナー、エッジ、面内部の立方体、完全に内部の立方体などの少数のタイプに分類します。 各タイプはペイントされた面の固定数を提供し、各タイプに属する立方体の数を数えるだけで済みます。 

1 つ以上の次元が 1 に等しい場合、複雑さが発生します。その場合、通常は 3D 構造であるものが長方形または線分に崩れ、分類が変わります。 通常はエッジ キューブである立方体が、縮退ジオメトリではコーナー キューブになる場合があります。 このため、1 に等しい次元がいくつあるかに応じてケースを個別に処理する必要があります。 

単位次元の数に基づいてケースに分割すると、カウントは純粋に算術的になります。 各構成には立方体カテゴリへの固定分解があり、ペイントされた面の合計は重み付けされた合計になります。

 ## アルゴリズムのチュートリアル

 この問題は、1 に等しい次元の数に応じてジオメトリをケースに分割することで解決します。これは、ケースごとにキューブ間の隣接構造が変化するためです。 

まず、3 つの次元がすべて 1 であるかどうかを確認します。この場合、立方体は 1 つだけであり、6 つの面すべてが露出しています。 答えは単純に6です。 

次に、正確に 2 つの次元が 1 である場合を考えます。構造は 1 列の立方体に崩壊します。 2 つのエンドポイントのみが内部キューブとは異なる動作をします。 各エンドポイント キューブには、ライン方向に沿った 2 つの面のみが欠落しているため、5 つの公開面がありますが、他のすべてのキューブには 4 つの公開面があります。 合計は、エンドポイントの寄与と内部の寄与を別々に合計することによって計算されます。 

次に、正確に 1 つの次元が 1 である場合を処理します。ブロックは立方体の平坦な長方形になります。 この長方形の角には 4 つの露出した面があります。 角ではなく境界上にある立方体には、3 つの露出した面があります。 内部キューブには 2 つの露出面があります。 長方形の寸法に基づいた単純な組み合わせ式を使用して、各カテゴリをカウントします。 

最後に、すべての次元が 1 より大きい場合は、完全な 3D 分解を使用します。 8 つのコーナー キューブがあり、それぞれが 3 つの面に貢献します。 エッジ キューブは、角を除くブロックの 12 個のエッジに沿って配置され、それぞれが 2 つの面を構成します。 面の内部立方体はエッジを除くサーフェス上にあり、それぞれが 1 つの面に寄与します。 内部立方体の寄与は 0 です。グリッドの次元に対する包含/除外を使用してカウントを計算します。 

各ケースでは、反復なしで閉じた形式の式が生成されます。 

### なぜ効果があるのか

 ブロック内のすべての立方体は、境界にある座標の数によって決まる 1 つの構造カテゴリに正確に属します。 これらのカテゴリは、キューブのセット全体を重複することなく分割します。 各カテゴリには公開される面の数が固定されているため、合計はカテゴリ サイズの線形結合になります。 ケース分割により、縮退によって分類が歪められることがなくなり、次元が崩れた場合でも正確さが保たれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a, b, c = map(int, input().split())

    if a == 1 and b == 1 and c == 1:
        print(6)
        return

    # count how many dimensions are 1
    ones = (a == 1) + (b == 1) + (c == 1)

    if ones == 2:
        # line of cubes
        n = max(a, b, c)
        # two endpoints + interior
        if n == 1:
            print(6)
        else:
            # endpoints: 5 faces each, interior: 4 faces each
            print(2 * 5 + (n - 2) * 4)
        return

    if ones == 1:
        # rectangle a x b (assuming c == 1 or permuted)
        if c == 1:
            x, y = a, b
        elif b == 1:
            x, y = a, c
        else:
            x, y = b, c

        if x == 1 and y == 1:
            print(6)
            return

        if x == 1 or y == 1:
            n = max(x, y)
            print(2 * 5 + (n - 2) * 4)
            return

        corners = 4
        edges = 2 * (x - 2) + 2 * (y - 2)
        interior = (x - 2) * (y - 2)

        print(corners * 4 + edges * 3 + interior * 2)
        return

    # full 3D case
    corners = 8
    edges = 4 * (a - 2 + b - 2 + c - 2)
    faces = (a - 2) * (b - 2) + (b - 2) * (c - 2) + (c - 2) * (a - 2)
    interior = (a - 2) * (b - 2) * (c - 2)

    ans = corners * 3 + edges * 2 + faces * 1 + interior * 0
    print(ans)

if __name__ == "__main__":
    solve()
```この実装はケース分割を直接反映しています。 最初の分岐は、後の数式が少なくともある程度の範囲を想定しているため、単一立方体の縮退ケースを分離します。 2 番目のブランチは、1D 構造を線に縮小し、内部立方体とは別に端点をカウントします。 3 番目のブランチは、コーナー、境界ストリップ、および内部セルを明示的に計算することによって長方形を処理します。これにより、構築によりエッジの二重カウントが回避されます。 

最後のブランチでは、完全な 3D 組み合わせ分解が使用されます。 各項は幾何学的カテゴリに対応します。コーナーはちょうど 3 つの座標が境界上にあるため 3 つの面に寄与し、エッジはちょうど 2 つの面上にあるため 2 つ寄与し、面内部の立方体は 1 つ寄与し、内部立方体はまったく寄与しません。 カウントの式は、各軸に沿った境界層の減算から直接得られます。

 ## 特殊なケース

 入力用`1 1 1`, the block is a single cube and every face is exposed. このアルゴリズムは、完全縮退分岐に即座に一致し、より大きな構造を想定した幾何学的分解を行わずに 6 を返します。 

入力用`5 1 1`、構造は 5 つの立方体が並んだものになります。 このアルゴリズムは 2 つの単位次元を検出し、それを 1D ケースとして処理し、5 つの面を持つ 2 つの端点と、それぞれ 4 つの面を持つ 3 つの内部立方体を生成し、正しい合計と一致します。 

入力用`2 3 1`, the block collapses into a rectangle. このアルゴリズムは、ジオメトリを 2D グリッドに明示的に再解釈し、コーナー、エッジ、内部セルを正しく分離し、エッジ キューブがコーナーとして二重にカウントされないようにします。 

入力用`3 3 3`、すべてのカテゴリが存在します。 このアルゴリズムは、包含/除外カウントを使用して各クラスを個別に計算し、すべてのキューブに 1 つのカテゴリが正確に割り当てられ、最終的な合計に重複が発生しないようにします。
