 ## 解決策
 ## 問題の理解

 私たちには大きな広場が与えられました$ABCD$辺の長さで$n$。 中には小さな広場があります$AEFG$辺の長さが可変整数である$m$、間隔に制限されています$[l, r]$。 小さな正方形の一角は次のように固定されます。$A$、そしてもう一つの点$E$横向きに寝そべる$AD$、したがって、小さな正方形はに固定されています$A$そして、大きな正方形の内側で制限された向きで成長します。 

この幾何学的構成から、五角形は$CDFGE$は、大きな正方形と小さな正方形の間の重なりによって決定される 5 つの特定の点を取ることによって形成されます。 私たちが気にする量は面積です$S$この五角形の、有効な整数を選択することがタスクです$m \in [l, r]$それは最大化します$S$。 

重要な隠れた構造は、ジオメトリが一度完全に固定されることです。$m$固定されています。 五角形全体の領域が決定関数になります$S(m)$。 この問題は、有界整数区間にわたる単一変数関数の最適化に帰着します。 

制約は極端です: まで$2 \cdot 10^5$テストケースと$n$まで$10^{12}$。 これにより、テスト ケースごとのシミュレーションや幾何学的な再構築が即座に除外されます。 正しいソリューションはすべて、最適なソリューションを評価する必要があります。$m$テストごとに一定時間で。 

素朴なアプローチではすべてを試してしまうだろう$m \in [l, r]$そして計算する$S(m)$毎回。 それぞれの評価があったとしても$O(1)$、間隔の長さは次のようになります。$10^{12}$, なのでこれは無理です。 

さらに微妙な問題は、浮動小数点ジオメトリです。 直接座標を計算すると、決定が平滑関数の値の比較に依存するため、精度誤差が生じる危険があります。 浮動小数点演算に依存するソリューションは、敵対的な入力では失敗します。 

エッジケースは区間の境界から生じます。 関数が単峰性の場合、最大値は厳密に区間内、または正確に区間内にある可能性があります。$l$または$r$。 たとえば、次の場合$l = r$、答えは強制され、最適化ロジックはその自明なケースを尊重する必要があります。 

## アプローチ

 重要なステップは、形状が複雑に見えても、その領域は複雑であることを認識することです。$S(m)$二次関数に単純化されます$m$。 座標が明示的に書き込まれると、五角形は、サイズが線形または二次的に依存する三角形のカットを差し引いた固定長方形領域に分解できます。$m$。 単純化後の結果は次の形式になります。$$S(m) = A - Bm + Cm^2$$定数の場合$A, B, C$によって決定される$n$。 

これにより、問題は整数区間にわたる凹または凸の二次方程式を最大化することに変換されます。 の兆候$C$形状を決定します。 この構造では、ジオメトリは凹面放物線を生成します (事実上、$C < 0$) なので、ピークは 1 つです。 

ブルートフォースメソッドはすべてを評価します$m \in [l, r]$、式を直接計算します。 これは正しいですが、間隔が大きい場合は実行できません。最悪の場合、最大で反復処理が必要になるためです。$10^{12}$テストケースごとの値。 

という観察$S(m)$単峰性は、放物線の頂点を見つけるだけでよいことを意味します。 二次関数の場合$Cm^2 - Bm + A$、最大値が近い$m^\* = \frac{B}{2C}$。 以来$m$整数である必要があり、答えはこの値に最も近い整数の 1 つである必要があります。 最後に、それをクランプします。$[l, r]$。 

これにより、各テスト ケースが一定時間の評価に短縮されます。

 ## アルゴリズムのチュートリアル

 1. 実数値の最適点を導出する$x = \frac{B}{2C}$の二次形式から$S(m)$。 これは、面積関数の制約のないマキシマイザーを表します。 
2. を考慮して、この連続最適値を整数候補に変換します。$m_0 = \lfloor x \rfloor$そして$m_1 = \lceil x \rceil$。 二次関数は単調性を 1 回だけ変更するため、整数の最大値はこれら 2 つの点のいずれかになければなりません。 
3. 両方の候補を有効な間隔に制限します$[l, r]$。 候補者が枠外にある場合は選出できません。 
4. 評価する$S(m)$最大 2 つの値: クランプされた候補。 面積が大きい方を残してください。 
5. 同じ値にクランプまたはコラプスした後、両方の候補が無効な場合は、その値を直接出力します。 

2 点のみのチェックが機能する理由は、関数が整数に対して単峰性であるためです。 導関数の符号が変わると、一方の値は厳密に増加し、もう一方の値は厳密に減少します。 

### なぜ効果があるのか

 面積関数は 2 次関数になります。$m$、したがって、その二次導関数は定数です。 これにより、単一の転換点が保証されます。 整数に関して、これは離散単峰性を意味します: シーケンス$S(l), S(l+1), \dots, S(r)$ピークまで増加し、その後減少します。 極大値はすべてグローバルであり、可能な極大値は実頂点の隣接する整数、または区間の境界にのみ存在します。 この構造的特性により、それらの候補のみを評価しても最適なソリューションを見逃すことがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n, l, r = map(int, input().split())

        # From geometric derivation:
        # S(m) = constant - m^2 + n*m (up to irrelevant constants)
        # So maximize f(m) = -m^2 + n*m

        # vertex at m = n/2
        x = n / 2

        cands = set()

        for m in (int(x), int(x) + 1):
            if l <= m <= r:
                cands.add(m)

        # ensure boundaries are considered
        cands.add(l)
        cands.add(r)

        def f(m):
            return -m * m + n * m

        best_m = l
        best_val = f(l)

        for m in cands:
            val = f(m)
            if val > best_val:
                best_val = val
                best_m = m

        out.append(str(best_m))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装は、幾何学的表現が二次方程式に崩壊するという事実をエンコードします。 機能`f(m)`は整数演算のみで評価され、浮動小数点の問題が回避されます。 

候補の選択には実際の頂点が使用されます$n/2$、次に床と天井をテストします。 境界値$l$そして$r$放物線の頂点が区間外にある場合、制約付き最適値がエッジに位置する可能性があるため、含まれています。 

このロジックは、頂点に対して間隔がどこに位置するかを決して想定しないため、次の場合でも正しいままになります。$[l, r]$からは遠い$n/2$。

 ## 特殊なケース

 いつ$l = r$の場合、最適化は不可能であるため、アルゴリズムはその値をすぐに返す必要があります。 候補セットにはまだその点のみが含まれているため、最大選択が自明に当てはまります。 

頂点のとき$n/2$はるか外にある$[l, r]$、床と天井の候補も両方とも外側にあります。 の包含$l$そして$r$正しい境界解が引き続き考慮されるようにします。 

いつ$n$奇妙です、$n/2$は整数ではありません。 アルゴリズムは引き続き両方の隣接値をチェックし、離散ピークがスキップされないことを保証します。 

どのような場合でも、選択セットには常に少なくとも 1 つの有効な要素が含まれるため、アルゴリズムによって空の候補セットや未定義の動作が生成されることはありません。
