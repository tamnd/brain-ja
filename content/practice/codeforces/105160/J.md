 ## 解決策
 ## 問題の理解

 1 から n までのラベルが付けられたノードと追加のノード 0 を含むツリーが与えられます。ノード 0 はノード 1 に接続されているため、実質的にノード 0 は元のツリーの上に接続されたルートのように機能します。 1 つおきのエッジが n 個の生徒の位置をツリーに接続します。 

各学生は固有のノード i に住んでいます。 バス ルートは、エッジを繰り返すことがなく、常にノード 0 で終了するトレイルです。学生は自分のノードでのみバスに乗車でき、一度乗車すると、ノード 0 に到着するまでそのバスに沿って乗車します。 

グラフはツリーであるため、ノード 0 で終了するエッジ単純ルートは、ルートに向かう下向きから上向きのパスのように動作します。つまり、分岐したり、エッジを再訪問したりすることはできないため、開始ノードを選択し、ノード 0 に向かって一意の単純なパスに沿って歩くことに事実上対応します。 

重要な結果は、すべてのスチューデントが 1 つのルート方向のパス上にある場合、つまり、それらのスチューデントのノードがルート ツリー (ノード 0 をルートとする) の 1 つの祖先チェーン上に配置されている場合に限り、1 つのバスで複数のスチューデントにサービスを提供できることです。 

1 台のバスで全員が移動しないように 3 人の生徒を選ぶ方法が何通りあるかを数えるよう求められます。 言い換えれば、3 つのノードが単一のルートからリーフへのパス上にあるノードを除く、ノードのすべてのトリプルをカウントします。 

n が 2 × 10^5 までの制約は、どの解も線形または O(n log n) に近い必要があることを意味します。 ノードのペアまたはトリプルにわたる二次関数はどれも遅すぎます。 この構造はツリーであり、前処理後に単純な組み合わせカウントを提案するため、O(n^{4/3}) スタイルの解法もここでは不要です。 

「同じバス」の意味を誤解すると、微妙な特殊なケースが発生します。 それは元のツリー内の接続性についてではなく、1 つの祖先チェーン上にあることについてです。 たとえば、ノード 1 を中心とするスターでは、ノード 2、3、4 は単一のパス上にないため、これらを含むトリプルは有効です。 対照的に、チェーン 4-3-2-1-0 では、4 から 0 までの 1 つのバスがすべてのノードを通過するため、そのチェーンに沿った 3 つのノードは無効になります。 

## アプローチ

 直接的なアプローチでは、ノードのトリプルをすべて列挙し、それらが単一の root-to-0 パス上にあるかどうかを確認します。 この条件を確認するには、1 つのノードがそれらの中で最も深いかどうか、および他の 2 つのノードがその祖先であるかどうかを確認する必要があります。 これは、O(1) または O(log n) で親ポインターまたは LCA クエリを使用して実行できますが、すべてのトリプルを列挙するには O(n^3) のコストがかかり、n = 2 × 10^5 では不可能です。 

重要な観察は、視点を反転することです。 トリプルをチェックする代わりに、悪いものを数えます。 3 つのノードすべてがルート ツリー内の単一の祖先チェーン上にある場合、トリプルは正確に悪影響を及ぼします。 

ここで、ノード v をそのようなトリプルの最も深いノードとして修正します。 他の 2 つのノードは、v の祖先の中から選択する必要があります (v 自体を除外するか、定式化に応じて慎重に含めます)。 深さを適切に定義すると、不良トリプルにはそれぞれ固有の最も深いノードがあり、二重カウントが回避されます。 

これにより、問題は、ノード 0 からの単一の DFS または BFS で深さを計算した後のノードにわたる純粋な組み合わせの合計に縮小されます。

 ## アルゴリズムのチュートリアル

 ノード 0 でツリーをルートし、すべてのノードの深さを計算します。ここで、深さ[v] は、v 自体を含む、v からノード 0 までのパス上のスチューデント ノードの数です。

1. ノード 1 に接続されたノード 0 を含む、ツリーの隣接リストを作成します。 
2. ノード 0 から BFS または DFS を実行して、親関係と深さを計算します。 Depth[0] = 0 に設定し、v の子 u については、 Depth[u] = Depth[v] + 1 に設定します。これにより、ノード 0 を除く、v からルート側へのパス上にあるスチューデント ノードの数が Depth[v] でカウントされるようになります。 
3. 生徒のトリプルの合計数を C(n, 3) として事前計算します。 これは可能なすべての選択を表します。 
4. 不良トリプルの数を計算します。 各ノード v について、v をトリプル内の最も深いノードとして扱います。 次に、他の 2 つのノードは、スチューデント ノードでもある v の祖先の中から選択する必要があり、その深さ[v] - 1 が存在します。 

したがって、深さ[v] ≥ 3 の場合、v の寄与は C(深さ[v] - 1, 2) となります。 
5. すべてのノードでこの値を合計します。 v.
 6. 答えは、合計トリプルから不良トリプルを引いたものです。 

この分解が機能する理由は、すべての有効な「同じバス」トリプルがツリー順序の最も深い 1 つのノードに正確に対応するためです。 そのノードが固定されると、残りの 2 つのノードはその上に配置されるように一意に制約されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
adj = [[] for _ in range(n + 1)]

for _ in range(n - 1):
    u, v = map(int, input().split())
    adj[u].append(v)
    adj[v].append(u)

# include node 0 connected to 1
adj.append([])  # index n+1 unused (just safety, not needed)
adj[0] = [1]
adj[1].append(0)

parent = [-1] * (n + 1)
depth = [0] * (n + 1)

stack = [0]
parent[0] = 0

while stack:
    v = stack.pop()
    for u in adj[v]:
        if u == parent[v]:
            continue
        parent[u] = v
        depth[u] = depth[v] + 1
        stack.append(u)

def C2(x):
    return x * (x - 1) // 2

total = n * (n - 1) * (n - 2) // 6
bad = 0

for v in range(1, n + 1):
    if depth[v] >= 3:
        bad += C2(depth[v] - 1)

print(total - bad)
```コードは最初にツリーを構築し、ノード 0 とノード 1 の間の接続を明示的に追加します。DFS はノード 0 をルートとする親配列と深さの配列を計算します。 

関数 C2(x) は、ペアの二項係数を効率的に計算します。 各ノード v について、深さ [v] - 1 を v より上のスチューデント ノード内の有効な祖先の数として解釈します。そのうちの 2 つを v と一緒に選択すると、不正なトリプルが形成されます。 

最後に、トリプルの総数からこれらを減算します。 

よくある落とし穴は深さの定義を誤ることです。深さがノード 0 ではなくノード 1 から始まると、組み合わせ式が壊れます。 もう 1 つの問題は、ノード 0 は学生ではないため、組み合わせに含めてはいけないことを忘れていることです。 

## 実用的な例

 ### 例 1

 3-2-1-0 という単純なチェーンを考えてみましょう。 

深さは次のとおりです。 

ノード 1: 1、ノード 2: 2、ノード 3: 3。 

| v | 深さ[v] | 悪い寄与 C(深さ[v]-1,2) |
 | --- | --- | --- |
 | 1 | 1 | 0 |
 | 2 | 2 | 0 |
 | 3 | 3 | 1 |

 トリプルの合計は C(3,3) = 1 です。 

不正なトリプル = 1 (トリプル {1,2,3})。 

答え = 0。 

これは、チェーン内ではすべてのトリプルが 1 つのパス上にあるため無効であることを確認します。 

### 例 2

 スター型のノード 1 が 0 に接続され、ノード 2、3、4 が 1 に接続されているとします。 

深さ:

 ノード 1 = 1、ノード 2、3、4 = 2。 

| v | 深さ[v] | 貢献 |
 | --- | --- | --- |
 | 1 | 1 | 0 |
 | 2 | 2 | 0 |
 | 3 | 2 | 0 |
 | 4 | 2 | 0 |

 トリプルの合計 = C(4,3) = 4。 

不良トリプル = 0。 

答え = 4。 

これは、分岐構造では 1 つの祖先チェーン上に 3 つのノードが存在しないことを示しています。
