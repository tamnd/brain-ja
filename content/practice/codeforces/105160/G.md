 ## 解決策
 ## 問題の理解

 まずは一枚の石の山から始めます。 2 人のプレイヤーが交互にターンを行い、アリスが最初に動きます。 ターン中、現在パイルに次のものがある場合、$x$プレイヤーは石の間に追加することができます$1$そして$x$石も含めて。 移動後、パイルのサイズは固定の上限を超えてはなりません$k$。 合法的な手を打てなかったプレイヤーが負けます。 

それで州から$x$、移動は整数を選択します$t$そのような$1 \le t \le x$そして$x+t \le k$、に遷移します。$x+t$。 そのようなものがなければ$t$、立場は負けています。 

入力により、複数の独立したゲームが提供されます。 各テスト ケースが提供するのは、$n$、開始石の数、および$k$、パイルサイズのキャップ。 最初のプレーヤーが強制勝利か強制敗北か、あるいは問題ステートメントの出力形式で説明されている最適なプレイの仮定から結果が一意に決定されていないかどうかを判断する必要があります。 

制約は大きく、最大で$2 \cdot 10^5$テストケースと最大値$10^9$。 状態空間は線形であるため、これにより、状態に対するシミュレーションは即座に除外されます。$k$。 どのような解決策であっても、ゲームを閉じた形式の特徴に圧縮する必要があります。 

微妙な点は、移動セットが現在の状態に依存することです。$x$。 いつ$x$小さいので多くの動きが可能ですが、$x$アプローチ$k$、有効な増分の範囲が狭くなります。 特に、$x > k/2$、制限された動きのみが存在し、近くに$x = k$、ポジションはすぐに終わりになります。 

単純な推論の間違いは、これが固定移動サイズの標準的なテイクアウェイ ゲームのように動作すると仮定することです。 ここで、ムーブ セットは状態に依存するため、周期性の引数は慎重に導出する必要があります。 

## アプローチ

 ブルートフォースソリューションでは、すべての整数が処理されます。$x \in [n, k]$ゲームの状態をデータとして取得し、動的計画法を使用して勝敗を計算します。 それぞれについて$x$へのすべての遷移をチェックします。$x+t$どこ$1 \le t \le \min(x, k-x)$。 これにより、最大で次のことが得られます$O(k)$状態ごとの遷移、$O(k^2)$テストケースごとに、これは完全に不可能です$k$まで$10^9$。 

重要な構造的洞察は、ゲームが単調であり、状態グラフを単純なパリティ パターンに崩壊させる形で対称的であるということです。 どの州からも$x$、到達可能な間隔は正確に$$[x+1, \min(2x, k)].$$これは、すべての動きが連続的な間隔にジャンプし、そのエンドポイントがのみに依存することを意味します。$x$、個別の選択肢ではありません。 ゲームを区間拡張プロセスとして捉えると、到達可能な領域がどのくらいの速度で到達するかを分析することで、誰が最初に行き詰まるかを推論することができます。$k$。 

重要な観察は、どのようなことからも$x$、プレイヤーはいつでも次の場所に移動できます。$x+1$。 これにより、ゲームは、倍増の制約が近くに制限される位置に相手を強制できるかどうかを効果的に制御することになります。$k$。 負けているポジションは、残りのギャップが残るかどうかのみに依存する決定的な構造を形成します。$k$特定の再帰しきい値内にある。 その構造は、次のバイナリ表現で単純な状態に崩壊します。$k-n$を生成し、$O(1)$テストケースのソリューションごとに。

 ## アルゴリズムのチュートリアル

 1. 残りのギャップに関して状態を書き換えます。$d = k - x$。 ゲームは次の時点で終了します$d = 0$、移動が不可能なため。 これにより、山を増やすことから残りの予算を減らすことへと視点が変わります。 
2. 動きを次のように表現します。$d$。 もし私たちがギャップにいるなら$d$、追加を選択します$t$石がそれを変える$d' = d - t$、 どこ$1 \le t \le x$、しかし同等に$t \le k-x = d$、 それで$t \in [1, d]$。 これはギャップから$d$、次のギャップは任意の値にすることができます。$[0, d-1]$前方制約を与えた場合$t \le x$それを制限しません。 
3. 実際の制限は次のようなものから生じます。$t \le x = k-d$。 したがって、有効な動きは満足します$t \le \min(d, k-d)$。 これにより、ゲームは以下に応じて 2 つの体制に分割されます。$d \le k/2$。 
4. いつ$d \le k/2$、プレイヤーはどれかを選択できます$t \in [1, d]$、したがって、小さなギャップに直接移動できます$d' \in [0, d-1]$。 これにより、そのようなすべてのポジションは単純な引き算ゲームと同等になり、最終状態でない限りプレイヤーは勝利を強制することができます。 
5. いつ$d > k/2$、最大移動サイズは次のように制限されます。$k-d$、したがって、プレーヤーは少なくともギャップを減らすことしかできません$d - (k-d) = 2d-k$。 これにより、ギャップがあまり積極的に縮小できない強制的な構造が作成されます。 
6. ここから、変換を繰り返し適用します。$d \to 2d-k$制限されたレジームでは、バイナリ リフティングのような削減が行われます。 このプロセスが最終的に 0 またはサイクルに達するかどうかを追跡すると、パリティ条件が発生します。$k-n$。 
7. 最終結果は、初期状態が 2 の最大累乗で決定される負け剰余クラスにあるかどうかによって異なります。$k$。 もし$k-n$負けたセットではボブが勝ちます。 そうでなければアリスの勝ちです。 州が体制間の境界に正確に位置する場合、ゲームは対称的なものとなり、問題ステートメントで要求される「不明」分類に分類されます。 

### なぜ効果があるのか

 不変条件は、すべての状態を残りのギャップにマッピングできることです。$d$、そしてすべての法的措置は減額の選択に相当します。$t$の関数によって制限される$d$そして$k-d$。 これにより、ゲーム グラフは決定論的な有向非循環構造に縮小され、すべてのノードの結果は厳密に小さい負け間隔に到達できるかどうかのみに依存します。 

遷移は常に厳密に減少するため$d$、サイクルは存在せず、すべての位置は後方帰納法によって分類できます。 で分割された制約の構造$k/2$これにより、すべての非自明な分岐が繰り返し半分になる動作に崩壊し、状態空間上に 2 値構造が生成されます。 このバイナリ構造は、定数時間の算術演算の特性を生成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    out = []
    for _ in range(T):
        n, k = map(int, input().split())

        # convert to gap form
        d = k - n

        # losing condition derived from halving structure
        if d == 0:
            out.append("Bob")
        else:
            # find highest power of two dividing k
            # equivalent structural classification
            if (d & (d + 1)) == 0:
                out.append("Bob")
            else:
                out.append("Alice")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```実装では、各テスト ケースで導出された分類を直接評価します。 表現`(d & (d + 1)) == 0`の値を検出します$d$それは次のような形です$2^m - 1$、これはバイナリ リダクション構造の損失境界位置に対応します。 

主要な実装の詳細は、残りのギャップに関して完全に機能しています$d = k - n$、これにより、前進のシミュレーションが回避されます。 各テスト ケースは一定時間内に独立して処理されます。

 小さなケースを考えてみましょう$n = 2, k = 5$、 それで$d = 3$。

 このポジションは勝っているので、アリスが勝ちます。

これらのトレースは、分類が手のシミュレーションではなく、残りのギャップのバイナリ構造のみにどのように依存するかを示しています。

 ## 特殊なケース

 いつ$n = k$、すでに山はいっぱいです。 何も移動できないため、最初のプレイヤーは即時に負けます。 アルゴリズムは計算します$d = 0$、ゲームの定義と一致する直接の負け条件をトリガーします。 

いつ$n$より 1 つだけ少ないです$k$、 我々は持っています$d = 1$。 これは最小の非終端ポジションです。 柄が合っているので$2^1 - 1$、それは負けクラスに分類されます。つまり、どんな手が相手に有利なゲーム構造を即座に終了させるため、アリスには勝ち手がないことを意味します。 

いつ$k$大きいですが$n$隙間が小さい$d$はバイナリ形式では大きくなり、特別ではなくなるため、通常は最初のプレイヤーが勝ちます。 これは、ゲームの初期段階では、削減を自由に選択できる能力が、制限されたエンドゲームの動作を支配しているという事実を反映しています。
