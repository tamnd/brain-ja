 ## 解決策
 ## 問題の理解

 問題の難易度のリストが与えられます。各問題には、入力内の位置によって与えられる暗黙の識別子も含まれます。 タスクは、問題のインデックスを難易度に従って最小から最大まで並べ替えることです。 2 つの問題が同じ難易度を共有する場合、元のインデックスが小さい方が最初に表示される必要があります。 

出力はソートされた難易度そのものではなく、このルールに従ってソートされた後の元のインデックスのシーケンスです。 

入力サイズは小さく、問題数は最大 1000 です。 これにより、二次時間以上のあらゆるアプローチが直ちに可能になります。 100 万回程度の基本操作を実行するソリューションは完全に安全ですが、別のループ内でフル スキャンを繰り返すものはパスする可能性が高くなりますが、その必要はありません。 

よくある間違いは、インデックスを追跡せずに難易度の値だけを並べ替えることで、必要な出力が失われます。 もう 1 つの間違いは、インデックスを並べ替えるのにタイブレーク ルールを忘れることです。これにより、同じ値が表示された場合に誤った順序付けが行われます。 たとえば、入力が`3 1 1`、正しい出力は次のとおりです。`2 3 1`、なぜなら二人だから`1`元の順序を維持します。 

すべての値が等しい場合、別の微妙なエッジ ケースが発生します。 もし`a = [5, 5, 5]`、出力は次のようにする必要があります`1 2 3`、元の順序を完全に保持します。 

## アプローチ

 この問題を考える強引な方法は、残っている最小の難易度を繰り返し検索し、それを使用済みとしてマークし、そのインデックスを結果に追加することです。 各選択では、配列全体をスキャンして、まだ使用されていない次の最小値を見つける必要があります。 これは基本的に選択プロセスを n 回繰り返すことになり、各スキ​​ャンのコストは O(n) となり、合計操作は O(n²) になります。 

このアプローチは、ソート ルールに直接従うため、正しいです。つまり、常に最小の利用可能な要素が選択され、慎重に実装されていれば、スキャンは等しい値の中から最小のインデックスを選択することによって自然に同点を解決します。 ただし、すでに処理された要素を何度も冗長に再検査するため、概念的には非効率になります。 

重要な観察は、各要素をそのインデックスでパッケージ化した場合に、順序付けルールが標準の並べ替えアルゴリズムがすでに提供しているものとまったく同じであるということです。 ペアを並べ替えると`(ai, i)`、並べ替え比較では最初に難易度が使用され、難易度が等しい場合は自動的にインデックス順に戻ります。 これにより、問題は n 項目にわたる 1 つの並べ替えに変換されます。 

改善は、構造が静的であることを認識することからもたらされます。 処理中に何も変更されないため、段階的に選択する必要はありません。 1 回限りのグローバル注文で十分です。

 ## アルゴリズムのチュートリアル

 1. 整数 n と難易度の配列を読み取ります。 各位置は、1 から始まる問題識別子を暗黙的に表します。 
2. 各要素が難易度と元のインデックスの両方を格納するペアのリストを作成します。 これにより、比較が可能になりながら、各問題の同一性が保持されます。 
3. ペアのリストを並べ替えます。 並べ替えルールは最初に難易度を比較し、2 つの難易度が等しい場合はインデックスを比較します。 これにより、必要な順序付けが 1 回の操作で確実に実行されます。 
4. ソートされたリストをたどってインデックスのみを抽出し、最終的な出力順序を生成します。 

### なぜ効果があるのか

 並べ替えにより、問題に必要な順序関係と一致する全体的な順序が強制されます。 比較関数は全体の順序を定義します。`(ai, i)`難易度が主キーであり、インデックスがタイブレーカーであることが保証されます。 並べ替えると、任意の 2 つの要素が正しい相対順序で表示され、並べ替えの推移性により、さらなる調整を必要とせずにシーケンス全体の一貫性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input().strip())
a = list(map(int, input().split()))

pairs = []
for i in range(n):
    pairs.append((a[i], i + 1))

pairs.sort()

res = [str(idx) for _, idx in pairs]
print(" ".join(res))
```実装における中心的なアイデアは、次の構築です。`(value, index)`ペア。 出力では問題の番号付けが 1 から始まることが想定されるため、インデックスは 1 ベースにシフトされます。 

Python の組み込みソートはタプルを辞書順に比較します。つまり、最初の要素が自動的に比較され、それらが等しい場合にのみ 2 番目の要素が比較されます。 これにより、追加のロジックを使用せずに、必要なタイブレーク ルールが直接エンコードされます。 

最後のループではインデックスのみを順番に抽出し、高速結合できるように文字列に変換します。 使用する`sys.stdin.readline`入力処理が効率的であることが保証されますが、n が 1000 までの場合、これは厳密には必要ありません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    input = _sys.stdin.readline

    n = int(input().strip())
    a = list(map(int, input().split()))
    pairs = [(a[i], i + 1) for i in range(n)]
    pairs.sort()
    return " ".join(str(idx) for _, idx in pairs)

# provided sample style case
assert run("5\n3 1 1 4 2\n") == "2 3 5 1 4"

# all equal
assert run("3\n5 5 5\n") == "1 2 3"

# already sorted
assert run("4\n1 2 3 4\n") == "1 2 3 4"

# reverse order
assert run("4\n4 3 2 1\n") == "4 3 2 1"

# minimum size
assert run("1\n7\n") == "1"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 5 3 1 1 4 2 | 2 3 5 1 4 | タイ処理による一般的な並べ替え |
 | 3 5 5 5 | 1 2 3 | すべて同等の安定性 |
 | 4 1 2 3 4 | 1 2 3 4 | すでにソートされたケース |
 | 4 4 3 2 1 | 4 3 2 1 | 逆順 |
 | 1 7 | 1 | 最小入力サイズ |

 ## 特殊なケース

 入力などの難易度がすべて同じ場合`5 5 5 5`の場合、アルゴリズムはすべてのペアで同一の最初の要素を構築します。 その後、ソートは完全にインデックスに基づいて行われ、自然な順序が維持されます。 出力は次のようになります`1 2 3 4 5`、元の位置によってタイが解決されるという要件に一致します。 

配列が厳密に増加している場合、たとえば`1 2 3 4`、並べ替えによってペアの順序はまったく変更されません。 アルゴリズムは引き続き同じステップを実行しますが、出力は入力インデックスと順番に同じになります。 

配列が厳密に減少している場合、次のようになります。`4 3 2 1`の場合、並べ替えにより構造が完全に逆になります。 各要素は値に基づいて正しい位置に移動します。値は個別であるため、インデックスは順序に影響しません。
