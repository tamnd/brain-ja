 ## 解決策
 ## 問題の理解

 の行から始めます`n`パネルはすべてオフになります。 ターゲットのパスワードは別の構成であり、正確には`k`特定の位置はオンにし、他の位置はすべてオフのままにする必要があります。 

1 回の操作で、長さが配列に属する連続したパネルのセグメントを選択します。`a`。 そのセグメント内のすべてのパネルが反転されます。 ONがOFFになり、OFFがONになります。 

タスクは、ターゲット構成に到達するために必要な操作の最小数を見つけるか、それが実行できないことを報告することです。 

最も重要な観察は、反転が XOR スタイルの操作であるということです。 同じセグメントを 2 回適用すると、その効果は完全にキャンセルされます。 操作の順序は重要ではなく、各セグメントが何回使用されるかというパリティのみが重要です。 

制約によってソリューションが完全に形作られます。 ボードサイズ`n`到達する`10000`したがって、すべての構成にわたってボード全体の状態を DP で表すことはできません。 それには必要になります`2^10000`州、それは不条理に大きいです。 

キー保存の制約は次のとおりです。`k ≤ 10`。 最終的な構成で実際に重要となるのは最大 10 個の位置だけです。 他のすべての位置は OFF で終了する必要があります。 これは、問題をそれらの特別な立場間の相互作用にまで圧縮することを示唆しています。 

2 番目の重要な制約は、`l ≤ 100`。 可能なセグメント長は最大 100 個のみです。 これにより、グラフの前処理が可能になります。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

考慮する：```
3 1 1
2
2
```必要なのはポジションだけ`2`を ON にすると、すべての移動で 2 つの隣接するパネルが反転します。 すべての操作で ON セルの数のパリティが偶数だけ変更されるため、ON セルが 1 つだけ存在する状態に到達することは不可能です。 正しい答えは、`-1`。 

貪欲な戦略も大失敗します。 例：```
5 2 1
1 5
3
```単純なアイデアは、ターゲット セルをカバーするセグメントを直接反転することです。 ただし、長さ 3 のすべてのセグメントは常に 3 つの位置に同時に影響を与えるため、孤立したターゲットはキャンセルによってのみ達成できる可能性があります。 フリップがグローバルに相互作用するため、ローカル推論は機能しません。 

もう 1 つの微妙なケースは、許可された操作の下で一部のターゲット位置が切断される場合です。```
6 2 1
1 6
2
```すべての操作で 2 つの隣接するセルが反転されます。 すべての OFF から開始して、交互の色クラス内の ON セルのパリティは制約されたままになります。 ポジション`1`そして`6`独立して切り替えることはできません。 正解はまたしても`-1`。 

本当に難しいのは、セグメントを直接選択しないことです。 一連のフリップを通じてどのターゲット位置が相互作用できるかを理解することです。 

## アプローチ

 ブルートフォースの観点は単純です。 考えられるすべてのセグメント配置はバイナリ変数です。つまり、そのセグメントを奇数回使用するか、使用しないかのどちらかです。 あれば`m`可能なセグメントがある場合、`2^m`試してみるサブセット。 

各サブセットについて、すべてのフリップをシミュレートし、最終的なボードがターゲットと一致するかどうかを確認できます。 セグメント数はおおよそ`n * l`、最大約100万。 平`2^50`すでに不可能であるため、このアプローチはすぐに崩壊します。 

次に自然なアイデアは、ボードの状態にわたる最短パスの検索です。 各状態は ON/OFF パネルのビットマスクであり、各操作でセグメントが切り替わります。 BFS は最小限の移動数を提供します。 

状態空間にはサイズがあるため、それでも失敗します`2^n`、 そして`n`までです`10000`。 

ブレークスルーは、演算を代数的に見ることで得られます。 

移動するたびに、連続した間隔が切り替わります。 2 つのターゲット位置を比較すると`u`そして`v`、さらに有益な質問をすることができます。 

正確に切り替えるために必要な操作の最小数は何ですか`u`そして`v`、他のすべての位置は元の状態に戻りますか?

 これにより、問題はターゲット位置間のペアごとの相互作用に変換されます。 

ターゲット位置のすべてのペアのコストがわかっているとします。 その場合、タスク全体は次のようになります。 

ターゲットポジションをペアにして、各ペアに最低コストを支払います。 

なぜペアリングするのか？ すべての操作で偶数の境界遷移が反転されるためです。 線形代数の用語では、到達可能な構成は区間演算によって生成されるベクトル空間を形成し、すべての達成可能なターゲットはペアの相互作用に分解できます。 

プレフィックス パリティを導入すると、構造がより明確になります。 

各操作で左境界線と右境界線に 1 を加えた 2 つの位置のみが変更される新しい配列を定義します。 間隔反転は、この変換された空間内の 2 つの点を切り替えることと同等になります。 

ここで問題は次のようになります。 

ポジションに関するグラフがあります`0..n`。 許容される間隔の長さにより、その長さだけ異なる位置間にエッジが作成されます。 1 つの操作を使用すると、1 つのエッジが横断されます。 頂点のサブセットを切り替える必要があります。 最も安価な方法は、頂点をペアにして、各ペアを最短パスで接続することです。 

これにより、2 つの別個の副問題が生じます。 

まず、関連するすべての頂点間の最短パス距離を計算します。 

次に、サブセットに対して DP を実行して、最も安価な完全なペアを見つけます。 

以来`k ≤ 10`、ペアリング DP には、`2^10 = 1024`州。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(n・l)) | O(n・l) | 遅すぎる |
 | 最適 | O(n・l + k・(n+l) + 2^k・k^2) | O(n + 2^k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ターゲット構成をプレフィックスパリティ形式に変換します。 

位置の場合`x`ON である必要がある場合、プレフィックス XOR 表現で位置を切り替えます。`x-1`そして`x`。 

より具体的には、セットを作成します。```
S = {x_i - 1, x_i}
```出現するたびにパリティが切り替わるので、重複は自動的にキャンセルされます。 
2. XOR パリティを使用して重複したトグルを削除します。 

ある位置が 2 回表示される場合、2 回切り替えるとキャンセルされるため、その位置はセットから消えます。 

すべてのターゲット位置を処理した後、残りの位置は奇数パリティを持つ必要がある頂点になります。 
3. 頂点に基づいてグラフを構築する`0..n`。 

許容されるすべての長さについて`a_j`、エッジを追加します。```
u <-> u + a_j
```エンドポイントが内部に留まるたびに`[0, n]`。 

1 つのエッジを横断することは、1 つの間隔反転を適用することに対応します。 
4. すべての重要な頂点間の最短パスを計算します。 

残りのパリティ位置を次のようにします。```
p[0], p[1], ..., p[m-1]
```どこ`m`は常に均等です。 

それぞれから BFS を実行します`p[i]`グラフの上で。 ペアごとの最短距離を保存します。 
5. 到達可能性を確認します。 

グラフを介して必要なペアを接続できない場合、一部の構成は不可能になります。 

これらの距離は無限のままであるため、DP はこれを自然に検出します。 
6. 最小限のペアリングのためにサブセット DP を実行します。 

定義する：```
dp[mask]
```ビットが設定されているすべての頂点をペアにするための最小コストとして`mask`。 

以下から始めます:```
dp[0] = 0
```7. 最初の未使用の頂点を選択して遷移します。 

最初のセットビットを選択します`i`で`mask`、それから他のすべてのセットビットとペアリングしてみてください`j`。 

遷移：```
dp[mask] =
    min(dp[mask without i,j] + dist[i][j])
```8. 答えは次のとおりです。`dp[(1<<m)-1]`。 

無限のままの場合は印刷する`-1`。 

### なぜ効果があるのか

 重要な不変条件は、すべての間隔フリップがプレフィックス表現の 2 つの境界でのみパリティを変更することです。 

スイッチオン間隔`[l, r]`位置でのプレフィックスの状態を切り替えます`l-1`そして`r`。 以来`r-l+1`許容される長さに等しくなければならないため、各操作は 1 つのグラフ エッジのトラバースに正確に対応します。 

演算を結合するとは、このグラフ内のパスを結合することを意味します。 有効な最終構成は、グラフ パリティ問題におけるパスの端点のペアとまったく同じように、奇数次の頂点をペアにする必要があります。 

最短パスにより、2 つのパリティ頂点を接続するための最小コストが得られます。 サブセット DP はすべての完全なペアを列挙し、すべての実行可能なソリューションはそのようなペア接続に一意に分解されます。 DP はすべてのペアリングをチェックするため、見つかった最小値が全体的に最適になります。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

INF = 10**18

def solve():
    n, k, l = map(int, input().split())

    x = list(map(int, input().split()))
    a = list(set(map(int, input().split())))

    parity = [0] * (n + 1)

    for pos in x:
        parity[pos - 1] ^= 1
        parity[pos] ^= 1

    points = [i for i in range(n + 1) if parity[i]]

    m = len(points)

    if m % 2:
        print(-1)
        return

    graph = [[] for _ in range(n + 1)]

    for length in a:
        for u in range(n - length + 1):
            v = u + length
            graph[u].append(v)
            graph[v].append(u)

    dist = [[INF] * m for _ in range(m)]

    for i in range(m):
        start = points[i]

        d = [-1] * (n + 1)
        d[start] = 0

        q = deque([start])

        while q:
            u = q.popleft()

            for v in graph[u]:
                if d[v] == -1:
                    d[v] = d[u] + 1
                    q.append(v)

        for j in range(m):
            if d[points[j]] != -1:
                dist[i][j] = d[points[j]]

    size = 1 << m
    dp = [INF] * size
    dp[0] = 0

    for mask in range(size):
        if dp[mask] == INF:
            continue

        first = -1

        for i in range(m):
            if not (mask & (1 << i)):
                first = i
                break

        if first == -1:
            continue

        for j in range(first + 1, m):
            if mask & (1 << j):
                continue

            if dist[first][j] == INF:
                continue

            nxt = mask | (1 << first) | (1 << j)

            dp[nxt] = min(dp[nxt], dp[mask] + dist[first][j])

    ans = dp[size - 1]

    print(ans if ans < INF else -1)

solve()
```最初のセクションでは、元のターゲット ボードをプレフィックス パリティ形式に変換します。 これは問題全体の中で最も重要な変換です。 間隔について直接推論する代わりに、境界の切り替えについて推論します。 

グラフの構築には細心の注意が必要です。 頂点はからの位置です`0`に`n`、 ない`1`に`n`。 この 1 つずつ異なる詳細は、間隔の境界から直接得られます。 間隔`[l, r]`プレフィックスの位置に影響を与える`l-1`そして`r`。 

BFS は重要な頂点からのみ実行され、すべての頂点から実行されることはありません。`n+1`ポジション。 せいぜい`2k ≤ 20`パリティ ポイントが存在する場合、BFS コストの合計は管理可能なままになります。 

サブセット DP は、標準の完全ペアリング最適化を使用します。 最初の未使用の頂点を選択すると、同じペアを異なる順序で何度もカウントすることがなくなります。 

実装の微妙な詳細は、グラフのエッジを双方向に保存することです。 すべての間隔演算はプレフィックス グラフ内で対称的に解釈できるため、グラフは無向です。 

もう 1 つの簡単な間違いは、等しい間隔の長さを重複排除するのを忘れることです。 同じ長さが複数ある場合、新しいトランジションは追加されません。
