 ## 解決策
 ## 問題の理解

 長方形のフィールドに作物を植えるシミュレーションをするよう求められますが、いくつかのセルが荒れ地であるという問題があります。 フィールドは _n_ × _m_ のグリッドとして表され、行には 1 ～ _n_、列には 1 ～ _m_ の番号が付けられます。 一部のセルには廃棄物が含まれており、残りのセルにはニンジン→キウイ→ブドウの順序で周期的に植えられた作物が含まれており、廃棄セルをスキップして列ごとに畑を埋めていきます。 

入力により、フィールドの寸法、廃棄セル座標のリスト、およびクエリ座標のリストが与えられます。 クエリごとに、そのセルが廃棄物であるか、またはどの作物が含まれているかを判断する必要があります。 

制約は適度に大きく、フィールドには最大 40,000 行と列を含めることができます。 これにより、最大 16 億個の細胞が得られます。 明らかに、メモリ制限内ではフィールド全体を明示的に格納することは不可能であるため、完全なグリッドを構築するソリューションは実現できません。 ただし、廃棄セルとクエリの数は少なく (それぞれ最大 1000)、これはフィールド全体の直接シミュレーションが不要であることを示唆しています。 より抽象的なインデックスベースの方法で、無駄なセルとクエリを処理する必要があります。 

単純なソリューションを壊す可能性のあるエッジ ケースには、無駄なセル、植え付け順序の最初または最後のセルをクエリすること、または同じセルに対して複数のクエリを実行することが含まれます。 作物を数えるときに廃棄セルを正しくスキップしないと、作物の割り当てが 1 つ以上ずれてしまい、不正確な答えが生成されます。 

## アプローチ

 ブルートフォースソリューションでは、植栽プロセス全体をシミュレートしようとします。 各セルを行優先の順序で繰り返し、無駄なセルをスキップし、ニンジン、キウイ、ブドウのサイクルで作物を割り当てることができます。 これは概念的には単純で正しいですが、フィールドは最大 40,000 × 40,000、つまり 16 億個のセルになる可能性があります。 反復が高速であっても、各セルのシミュレーションには数百秒かかります。2 秒の制限には遅すぎます。 

最適化を可能にする重要な観察は、植える順序が予測可能であるということです。栽培された各セルは、その前にある廃棄セルを無視し、行優先シーケンスのインデックスにのみ基づいて作物を取得します。 したがって、任意のセルの「線形インデックス」を O(1) 時間で計算できます。 次に、この線形順序で特定のセルの前に表示される廃棄セルの数がわかっている場合は、その数を減算して、そのセルの作物の種類を決定できます。 廃棄セルはシーケンス内でオフセットとして機能し、後続のセルのクロップ インデックスをシフトします。 

この洞察により、ソリューションは 3 つの主なステップに短縮されます。2D 座標を 1D インデックスにマッピングし、インデックスによって廃棄セルを並べ替えます。各クエリについて、それが廃棄セルかどうかを確認し、そうでない場合は、その前の非廃棄セルの数に基づいてモジュロ演算を使用してクロップを決定します。 廃棄細胞の選別には O(k log k) のコストがかかり、各クエリは二分探索を使用して O(log k) で答えることができます。k ≤ 1000 の場合、これは効率的です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n*m) | O(n*m) | 遅すぎる |
 | 最適 | O(k log k + t log k) | O(k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 次の式を使用して、行優先の順序ですべてのセルの 1D インデックスを計算します。`(row - 1) * m + (col - 1)`。 これにより、各セルに一意の整数が与えられ、廃棄セルを単純な線形方式で処理できるようになります。 
2. 各廃棄セルの座標を対応する 1D インデックスに変換し、リストに保存します。 次に、このリストを並べ替えます。 並べ替えにより、どのクエリでも、二分検索を使用してそのクエリの前に無駄なセルが何個あるかを効率的に判断できるようになります。 
3. 各クエリについて、まず座標を 1D インデックスに変換します。 二分検索を使用して、このインデックスが廃棄物インデックスのソート済みリストに含まれているかどうかを確認します。 そうであれば、そのセルは廃棄物であるため、「廃棄物」を出力します。 
4. セルが無駄ではない場合は、次のコマンドを使用して、クエリ セルよりも小さいインデックスを持つ無駄なセルの数を数えます。`bisect_left`。 このカウントをクエリセルインデックスから減算して、培養細胞内でのゼロベースの位置を取得します。 
5. この位置でモジュロ 3 を使用して作物を決定します。位置 % 3 == 0 はニンジン、1 はキウイ、2 はブドウに対応します。 

これが機能する理由: 重要な不変条件は、培養細胞の作物の種類は、圃場全体ではなく、培養細胞間の相対的な位置のみに依存するということです。 廃棄細胞を分類することにより、この相対位置を効率的に決定することができます。 先行する廃棄セルの数を減算すると、順序が正しくシフトされ、意図した植え付け順序が維持されます。 

## Python ソリューション```python
import sys
import bisect
input = sys.stdin.readline

n, m, k, t = map(int, input().split())
waste = []

for _ in range(k):
    a, b = map(int, input().split())
    idx = (a - 1) * m + (b - 1)
    waste.append(idx)

waste.sort()
crops = ["Carrots", "Kiwis", "Grapes"]

for _ in range(t):
    i, j = map(int, input().split())
    query_idx = (i - 1) * m + (j - 1)
    pos = bisect.bisect_left(waste, query_idx)
    if pos < len(waste) and waste[pos] == query_idx:
        print("Waste")
    else:
        crop_idx = (query_idx - pos) % 3
        print(crops[crop_idx])
```このコードは、無駄なセルとクエリの両方を線形インデックスに変換します。 無駄インデックスをソートすると、二分探索で無駄を検出し、先行する無駄の数を効率的に計算できます。 以前の廃棄物の数を差し引くと、作物を周期的に決定するための培養細胞指数が得られます。
