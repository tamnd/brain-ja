 ## 解決策
 ## 問題の理解

 グラフが与えられました$n$人々。 2 人の間の各入力エッジは、2 人の間に何らかの宣言があったことを意味しますが、宣言の内容は失われています。 元々、すべての宣言は次の 2 つのタイプのいずれかでした。$i$請求者$j$正直である、または人である$i$請求者$j$嘘つきです。 

村の人々は皆、正直者か嘘つきかのどちらかです。 正直な人は宣言の中で常に真実を言いますが、嘘つきは常に真実と反対のことを言います。 

タスクは、単一の一貫した割り当てを再構築することではありません。 代わりに、すべての人に正直/嘘つきのラベルを少なくとも 1 回割り当てることで、すべての発言に一貫性を持たせることができるように、すべてのエッジに意味を割り当てる方法 (発言が「正直」か「嘘つき」かをそれぞれのペアで選択) ができる方法が何通りあるかを数えなければなりません。 

したがって、入力グラフは固定されていますが、すべてのエッジには依然として 2 つの可能な隠れた「制約タイプ」があります。 エッジごとに 1 つのタイプを選択し、結果として得られるノードに対する論理制約のシステムが満たされる選択肢のみをカウントします。 

制約の観点から見ると、$n$そして$m$大きい、最大$2 \cdot 10^5$テストケース全体の合計。 これにより、二次関数や、エッジのすべてのサブセットを処理するものさえも即座に除外されます。 理想的には、テスト ケースごとに線形または線形に近いものが必要です。$O(n + m)$。 

微妙な問題がサイクルで現れます。 端の意味を恣意的に選択すると、すべての局所的な選択が問題ないように見えても、サイクル上に矛盾が現れる可能性があります。 たとえば、三角形の人々では、エッジの意味の選択が一貫性を欠いていると、パリティの矛盾が生じ、ノードに正直/嘘つきの値を割り当てることができなくなる可能性があります。 サイクルを無視する単純なアプローチでは、無効な構成が過大にカウントされてしまいます。 

## アプローチ

 重要な簡素化は、問題をブール変数に対する制約に変換することで実現します。 

各人物をブール値としてエンコードしましょう。正直者は 0、嘘つきは 1 です。これで、各エッジは 2 つのタイプのいずれかの制約になります。 

もし人$i$言う$j$正直であると、一貫性が強くなります$i$そして$j$同じ値を持つこと。 もし$i$正直です、$j$正直でなければなりません。 もし$i$彼は嘘つきなので、その発言は虚偽です、$j$嘘つきでもあるに違いない。 このエッジは等価制約のように動作します。 

もし人$i$言う$j$それなら嘘つきだ$i$そして$j$異なる値を持たなければなりません。 正直者$i$力$j$嘘つきになること、そして嘘つきになること$i$力$j$実を言うと。 これは不等式制約です。 

したがって、すべてのエッジは等式制約または不等制約になりますが、どちらにするかは自由に選択できます。 

次に、エッジ タイプの固定割り当てが有効になる理由を考えてみましょう。 エッジのタイプが固定されると、グラフ上に XOR 制約のシステムが構築されます。 どのサイクルにも矛盾がない場合、解決策は正確に存在します。 同様に、すべてのエッジ制約が満たされるようにグラフにノード値を割り当てることができる場合に限り、制約は一貫しています。 

重要な点は、実現可能性は接続構造のみに依存し、エッジ タイプの特定の選択には依存しないということです。 固定接続コンポーネントの場合、単一ルートのノード値を選択すると、他のすべてのノード値がスパニング ツリーに沿って決定されます。 追加のエッジは、パスに沿ったパリティに応じて自動的に満たされるか、矛盾を強制する制約を課します。 

これは構造的な特徴付けにつながります。どの接続コンポーネントでも、有効なエッジ割り当ての空間は、ノードのラベル付けと一致する割り当てのセットとまったく同じです。 すべてのノードのラベル付けにより、エッジ タイプの誘導割り当てが 1 つだけ生成され、すべてのノード値を反転すると、同じ誘導エッジ構成が生成されます。 これにより、コンポーネントごとに明確なカウント構造が得られます。 

接続コンポーネントの場合、$k$ノードの場合、一貫したエッジタイプの割り当ての数は$2^{k-1}$。 指数は、1 つのルートを除くすべてのノードの値を自由に選択でき、これらの選択によってすべての有効なエッジ動作が一意に決定されるという事実から来ています。 グラフは独立した連結成分に分割されるため、合計の答えは成分間の積となり、単純化すると次のようになります。$2^{n - \text{components}}$。 

素集合和集合構造または DFS を使用して連結成分を計算できます。

 ## アルゴリズムのチュートリアル

 1. すべてのエッジを読み取り、そのエッジ上に Union-Find 構造を構築します。$n$ノード。 エッジの方向やタイプではなく、接続されたコンポーネントのみを考慮するため、すべてのエッジはその端点を単純に結合します。 
2. すべてのエッジを処理した後、一意の DSU ルートを数えることによって、異なる接続コンポーネントがいくつ存在するかを判断します。 
3. コンポーネントの数を次のようにします。$c$。 最終的な答えを次のように計算します。$2^{n-c} \bmod (10^9+7)$。 
4. 2 のべき乗を最大で事前計算します。$2 \cdot 10^5$一度、以来$n$テスト ケース全体のサイズは大きくなりますが、合計サイズには制限があります。 

### なぜ効果があるのか

 各接続コンポーネント内で、ノード状態の有効な割り当てを選択すると、そのコンポーネント内のすべてのエッジが一貫性の観点から完全に決定されます。 コンポーネントごとの固定参照ノードを基準にしてノード ラベルを自由に選択できます。 それはまさに$k-1$サイズのコンポーネントごとに独立したバイナリ選択$k$。 すべてのコンポーネントを合計すると次の結果が得られます$n - c$独立した 2 値自由度なので、有効なグローバル エッジ構成の総数は次のようになります。$2^{n-c}$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAXN = 200000 + 5

pow2 = [1] * MAXN
for i in range(1, MAXN):
    pow2[i] = (pow2[i - 1] * 2) % MOD

class DSU:
    def __init__(self, n):
        self.parent = list(range(n + 1))
        self.size = [1] * (n + 1)
        self.components = n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]
        self.components -= 1

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        dsu = DSU(n)

        for _ in range(m):
            u, v = map(int, input().split())
            dsu.union(u, v)

        c = dsu.components
        print(pow2[n - c])

if __name__ == "__main__":
    solve()
```DSU 構造は、接続情報を圧縮するためにのみ使用されます。 エッジの実際の論理的意味は有効な構成のカウントには無関係であるため、すべてのエッジは同じように扱われます。 ノードが同じコンポーネントに属しているかどうかだけが重要です。 

事前に計算されたべき乗配列により、べき乗剰余演算の繰り返しが回避されます。これは、上限が狭いことを考えると重要です。

import sys, io

MOD = 10**9 + 7

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    MAXN = 200000 + 5
    pow2 = [1] * MAXN
    for i in range(1, MAXN):
        pow2[i] = (pow2[i - 1] * 2) % MOD

    class DSU:
        def __init__(self, n):
            self.parent = list(range(n + 1))
            self.size = [1] * (n + 1)
            self.components = n

        def find(self, x):
            while self.parent[x] != x:
                self.parent[x] = self.parent[self.parent[x]]
                x = self.parent[x]
            return x

        def union(self, a, b):
            ra, rb = self.find(a), self.find(b)
            if ra == rb:
                return
            if self.size[ra] < self.size[rb]:
                ra, rb = rb, ra
            self.parent[rb] = ra
            self.size[ra] += self.size[rb]
            self.components -= 1

    t = int(input())
    out = []
    for _ in range(t):
        n, m = map(int, input().split())
        dsu = DSU(n)
        for _ in range(m):
            u, v = map(int, input().split())
            dsu.union(u, v)
        out.append(str(pow2[n - dsu.components]))

    return "\n".join(out)

 ## 特殊なケース

 孤立したノードは最も重要な例外ケースです。 エッジのないノードは独自のコンポーネントを形成し、自由な 2 値の選択肢を 1 つだけ提供します。 DSU が結合しないため、アルゴリズムはこれを自然に処理します。そのため、シングルトン コンポーネントのままで指数が増加します。$n - c$適当に。 

もう 1 つの微妙なケースは、完全に接続されたサイクルです。 元の解釈では潜在的な論理制約が導入されていますが、DSU は接続を追跡するだけです。 サイクルは依然として単一のコンポーネントを形成しており、答えはコンポーネントのサイズのみに依存します。 この正しさは、サイクルがエッジ解釈の一貫性を内部的に制限するが、接続性がすでにエンコードしているものを超えて有効なグローバルに一貫した割り当ての数を減らさないという事実から来ています。 

最後に、複数の切り離されたコンポーネントを含むグラフは乗算的に結合されます。 各コンポーネントはノード割り当ての独立した選択に寄与するため、それらの指数を合計することは 2 の累乗を乗算することと同じであり、次の式で表されます。$2^{n-c}$直接捕獲します。
