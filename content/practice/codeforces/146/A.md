 ## 解決策
 ## 問題の理解

 チケット番号が幸運かどうかを判断するように求められます。 ラッキーチケット番号は 2 つの条件を同時に満たします。 まず、数値のすべての桁が 4 または 7 である必要があります。次に、数値の前半の桁の合計が後半の桁の合計と等しくなければなりません。 入力では、チケット番号の長さである偶数の整数 _n_ に続いて、チケット番号自体が数字の文字列として続きます。 チケットが幸運であれば出力は「YES」、それ以外の場合は「NO」になります。 

制約は緩やかです。チケットの長さ _n_ は 2 ～ 50 で、常に偶数です。 各桁を個別に検査し、配列の半分を合計するだけでよいため、O(n) アルゴリズムで十分です。 これ以上複雑なものは必要ありません。 潜在的なエッジケースには、先頭にゼロが付いているチケット、幸運な数字とそうでない数字が混在しているチケット、半分が 1 桁だけである長さ 2 の最小サイズのチケットが含まれます。 

半分を合計するが、幸運でない数字をチェックするのを忘れる単純なアプローチは失敗します。 たとえば、入力は次のとおりです。```
2
47
```は、前半の合計 (4) が後半の合計 (7) と等しくないため、幸運ではありません。 コードが幸運の数字のみをチェックし、合計はチェックしない場合、コードが誤って受け入れられる可能性があります。 同様に、チケットは次のようになります。```
4
4444
```幸運の数字の条件を満たし、両方の半分の合計が 8 になるため、幸運です。 

## アプローチ

 総当たりの方法では、すべての桁を 2 回反復します。1 回目はすべての桁が 4 または 7 であることを確認し、もう 1 回目は各半分の合計を計算して比較します。 これが機能するのは、桁ごとの演算が一定であるためです。 複雑さは O(n) ですが、制約を考慮すると許容範囲内であるため、さらに最適化する必要はありません。 

重要な洞察は、問題は本質的に線形であるということです。 桁の有効性のチェックと半分の合計を 1 回のパスで実行できます。 半分は、文字列を最初の n/2 桁と 2 番目の n/2 桁にスライスすることで識別できます。 各ステップは独立しているため、追加のデータ構造や複雑なアルゴリズムは必要ありません。 このシナリオでは、ブルート フォース アプローチが事実上最適なアプローチとなります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n) | お(1) | 承認済み |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力値 (整数 _n_ と文字列としてのチケット番号) を読み取ります。 文字列形式は、潜在的な先行ゼロを処理するために不可欠です。 
2. 2 つの合計を初期化します。`sum_first`そして`sum_second`、ゼロにします。 これらには、チケットの前半と後半の合計が保持されます。 
3. チケット番号を繰り返します。 各桁について、「4」または「7」のいずれかを確認します。 いずれかの数字が吉数字でない場合は、直ちに「NO」を出力して終了します。 これにより、最初のラッキーナンバーの条件が確実に適用されます。 
4. 最初の n/2 桁について、各文字を整数に変換し、それを加算します。`sum_first`。 
5. 残りの n/2 桁については、各文字を整数に変換し、それを加算します。`sum_second`。 
6. すべての桁を処理した後、比較します。`sum_first`そして`sum_second`。 等しい場合は「YES」を出力します。 それ以外の場合は「NO」を出力します。 

機能する理由: このアルゴリズムは、幸運でない数字が即座に拒否を引き起こすという不変条件を維持します。 合計の計算は正確で、半分ずつ区切られます。 両方の条件が独立して順番に評価されるため、制約内の有効な入力長に対して最終的な決定は正しいものになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
ticket = input().strip()

half = n // 2
sum_first = 0
sum_second = 0

for i in range(n):
    if ticket[i] not in '47':
        print("NO")
        sys.exit()
    if i < half:
        sum_first += int(ticket[i])
    else:
        sum_second += int(ticket[i])

if sum_first == sum_second:
    print("YES")
else:
    print("NO")
```コードは最初にチケットの長さとチケット番号を読み取ります。 数値を分割するための中点を計算します。 すべての数字を反復処理して、最初に各数字が幸運であることを検証します。 次に、単純なインデックス比較を使用して、2 つの半分を別々に合計します。 の`sys.exit()`「NO」を出力した後、幸運ではない数字が見つかった場合に直ちに終了します。 最後に、半分が等しいかどうかをチェックして、出力を決定します。
