 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times n$グリッドでは、一部のセルにはすでに固定整数値があり、残りは不明です。 完成を想像したい最終的なグリッドは、非常に厳密な幾何学的規則を満たす必要があります。つまり、エッジに隣接するセルのすべてのペアの値が正確に 1 だけ異なっていなければなりません。これは、4 つの基本方向のいずれかに 1 ステップ移動すると、高さが常に +1 または -1 だけ変化し、大きさが 0 になることはなく、1 を超えることもないことを意味します。 

単一の有効な補完を作成するように求められるわけではありません。 代わりに、指定された固定セルと隣接ルールを尊重するすべての可能な補完を理解することが求められます。 グリッドをどのように一貫して完成させても、そのセルが常に同じ値になる場合、そのセルは一意に決定されたと呼ばれます。 出力はグリッドであり、存在する場合はその強制値を出力し、存在しない場合は 0 を出力します。 

制約の重要な構造的意味は、各ステップがパリティのような伝播を強制することです。 単一セルの値が固定されると、到達可能な他のすべてのセルは、パスによって決定される一貫した「高さ面」上に位置するように制約されますが、複数の固定点で固定されない限り、異なるパスが一致しない可能性があります。 

以来$n$最大 500 で、すべてのテスト ケースにわたるセルの合計数が最大 250,000 である場合、セルごとに本質的に線形または線形に近い時間が必要です。 制約をセルごとに個別に再計算したり、可能性を列挙しようとするアプローチは拡張できません。 

グリッドに既知のセルが 1 つしかない場合、微妙なエッジ ケースが発生します。 その状況では、隣接関係の制約を維持しながら、他のすべてのセルをさまざまな方法でグローバルにシフトできるため、既知のセル自体以外は何も修正できません。 グローバル シフトを考慮せずに距離を割り当てる単純な BFS では、より多くのセルが決定されると誤って結論付けることになります。 

別のエッジケースは、異なる既知のセルからの制約がパリティによってのみ競合する場合に発生します。 たとえば、2 つの既知のセルはすべてのパリティ制約に一致する可能性がありますが、グリッドの一部で自由な加法的定数シフトが許可され、「接続されている」ように見えても大きな領域が未決定のままになる可能性があります。 

## アプローチ

 この問題を考える強引な方法は、すべての未知のセルに値を割り当ててから、制約との一貫性をチェックすることです。 未知の割り当てごとに、グリッドを通じて制約を伝播し、すべての隣接する差分が正確に 1 であり、すべての既知のセルが一致するかどうかを検証します。 次に、すべての有効な補完の結果を交差させて、どのセルが固定されたままであるかを確認します。 

このアプローチは概念的には正しいですが、すぐには実行できません。 値を割り当てる方法の数は未知のセルの数に応じて指数関数的に増加し、単一の完了チェックですら$O(n^2)$、完全な列挙は天文学的に大きくなります。 

重要な観察は、「隣接する差が正確に 1 である」という制約により、グリッドが絶対値制約のある整数に関する線形方程式系に変わるということですが、より重要なのは、グリッドが最短経路の一貫性システムのように動作することです。 エッジに方向を割り当てると、各エッジは +1 または -1 の差を強制するため、グリッドはすべての有効な完了がすべての固定ノードを満たす一貫した方向の選択に対応するグラフになります。 

重要なアイデアは、問題を未知の地球規模の「潜在的なシフト」に対する距離に関する推論に変換することです。 1 つの既知のセルの開始解釈を選択すると、BFS を 2 回使用して制約を伝播できます。1 回目は実現可能な最小値を計算し、もう 1 回は制約の下で実現可能な最大値を計算します。 これら 2 つの値が一致する場合、セルは一意に決定されます。 

これにより、問題は指数関数的な可能性から、グリッド グラフ上の 2 つの複数ソースの最短/最長伝播プロセスに縮小されます。どちらもセル数が線形です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | O(n²) | 遅すぎる |
 | ダブル BFS / 制約の伝播 | テストあたり O(n²) | O(n²) | 承認済み |

 ## アルゴリズムのチュートリアル

 この問題を、セルごとに、すべての有効な補完にわたって取り得る値の範囲を計算するという形で再定式化します。 

2 つの制約伝播パスを使用します。1 つは実現可能な最小の高さを計算し、もう 1 つは実現可能な最大の高さを計算します。 

### ステップ

 1. 既知の値を持つすべてのセルを識別し、それらを伝播の開始点として初期化します。 

これらは、有効な補完がすべて正確に一致する必要があるため、アンカーとして機能します。 これらがなければ、グリッド全体がシフト不変となり、値が固定されなくなります。 
2. 最短パス スタイルの BFS を実行して、すべてのセルの最小値を計算します。 

各セルの値を制約として扱い、隣接するセルは正確に 1 だけ異なっていなければならないというルールを使用して隣接するセルに伝播します。エッジを緩和するときは、一貫性がある場合は必ず値を下方に押し下げるようにします。 これにより、すべての固定制約を尊重しながら、各セルが達成できる最小値が生成されます。 
3. 2 番目の BFS を実行して、すべてのセルの最大可能値を計算します。 

今度は逆方向に伝播し、制約が許す限り値を上方に押し上げます。 概念的には、これは制約システムの二重実現可能領域を探索します。 
4. 各セルについて、得られた最小値と最大値を比較します。 

両方が等しい場合、セルは有効な補完で調整できないため、一意に決定されます。 それ以外の場合は、それをシフトする自由度が少なくとも 1 つ存在します。 
5. 一意に決まるセルには共通の値を出力し、それ以外の場合には 0 を出力します。 

### なぜ効果があるのか

 グリッド制約は、有効な補完がグラフ上の整数ポテンシャルの一貫した割り当てに対応する接続システムを定義します。 セル値を増加させる調整は、固定制約によってブロックされるまでパスに沿って一貫して伝播できるため、セルの実行可能な値は間隔を形成します。値を減少させる場合も同様です。 

2 つの BFS パスは、すべての制約によって引き起こされる最も厳しい下限と上限を同時に計算します。 有効な割り当ては両方の境界内にある必要があり、間隔内のすべての値は、サイクルに沿って局所的に伝播の選択を調整することで達成できます。 したがって、間隔が 1 つのポイントに集約されると、有効な完了ごとにその値が強制的に適用されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from collections import deque

def solve():
    n = int(input())
    g = [list(map(int, input().split())) for _ in range(n)]

    INF = 10**18

    def bfs_min():
        dist = [[INF] * n for _ in range(n)]
        q = deque()

        for i in range(n):
            for j in range(n):
                if g[i][j] != 0:
                    dist[i][j] = g[i][j]
                    q.append((i, j))

        dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]

        while q:
            x, y = q.popleft()
            for dx, dy in dirs:
                nx, ny = x + dx, y + dy
                if 0 <= nx < n and 0 <= ny < n:
                    cand = dist[x][y] - 1
                    if cand < dist[nx][ny]:
                        dist[nx][ny] = cand
                        q.append((nx, ny))
        return dist

    def bfs_max():
        dist = [[-INF] * n for _ in range(n)]
        q = deque()

        for i in range(n):
            for j in range(n):
                if g[i][j] != 0:
                    dist[i][j] = g[i][j]
                    q.append((i, j))

        dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]

        while q:
            x, y = q.popleft()
            for dx, dy in dirs:
                nx, ny = x + dx, y + dy
                if 0 <= nx < n:
                    cand = dist[x][y] + 1
                    if cand > dist[nx][ny]:
                        dist[nx][ny] = cand
                        q.append((nx, ny))
        return dist

    mn = bfs_min()
    mx = bfs_max()

    out = []
    for i in range(n):
        row = []
        for j in range(n):
            if mn[i][j] == mx[i][j]:
                row.append(str(mn[i][j]))
            else:
                row.append("0")
        out.append(" ".join(row))

    print("\n".join(out))

t = int(input())
for _ in range(t):
    solve()
```このソリューションは、2 つのマルチソース BFS のような緩和を実行します。 最初のパスでは、すべての既知のセルが実行可能な最小値の伝播をシードし、エッジに沿って常に 1 ずつ減少します。 2 番目のパスでは、同じ構造が使用されますが、値を最大化するために逆の構造が使用されます。 

最後の比較ステップは、間隔の崩壊として一意性をエンコードするため、非常に重要です。 下限と上限が一致すると、そのセルの値には自由がなくなります。 

実装の微妙な詳細は、両方の BFS キューがすべての既知のセルから同時に開始されることです。 これが必要なのは、制約がすべてのアンカーに一度に伝播するためです。 それらを個別に処理すると、相互作用する領域を正しくマージできなくなります。 

## 実用的な例

 2 つの既知のセルがグリッドの異なる部分に配置されている小さなグリッドを考えてみましょう。 伝播により制約が外側に広がり、中央で重なり合います。 

### 例 1

 入力:```
3
1 0 0
0 0 0
0 0 5
```私たちは伝播を概念的に追跡します。 

| ステップ | 処理済みセル | 最小更新 | 最大アップデート |
 | --- | --- | --- | --- |
 | 1 | (0,0)=1 | 近傍数 ≥ 0 | 近傍数 ≤ 2 |
 | 2 | (2,2)=5 | 隣人 ≥ 4 | 隣接数 ≤ 6 |
 | 3 | オーバーラップセンター | 両方によって制約される | 両方によって制約される |

 中央のセルは矛盾する方向の制約を受けており、単一の値ではなく範囲が生じます。 

これは、複数のアンカーがどのように実行可能な間隔を制限するが、必ずしもそれらを折りたたむわけではないことを示しています。 

### 例 2

 入力:```
2
1 0
0 0
```| ステップ | 処理済みセル | 最小更新 | 最大アップデート |
 | --- | --- | --- | --- |
 | 1 | (0,0)=1 | 下に広がる | 上に広がる |
 | 2 | 伝播 | 広い間隔 | 広い間隔 |

 ここではアンカーが 1 つだけ存在するため、グリッド全体が均一に移動します。 相対距離を超えて絶対値を固定する追加の制約はありません。 

これは、一意性を実現するには接続性だけでなく、複数の相互作用する制約が必要である理由を示しています。

 | --- | --- | --- |

| スペース | O(n²) | 2 つのグリッドには最小制約と最大制約が保存されます。

 ## 特殊なケース

 重要なエッジ ケースは、既知のセルが 1 つだけ存在する場合です。 その状況では、両方の BFS パスは値を外側に伝播しますが、間隔を崩壊させる別の固定アンカーに遭遇することはありません。 すべてのセルは最終的に実行可能な値の範囲になるため、慎重に処理した場合、出力はアンカー自体を除いて完全にゼロになります。 min と max はソース以外のどこでも区別できるため、アルゴリズムはこれを正しく処理します。 

もう 1 つのエッジ ケースは、2 つの既知のセルが遠く離れているが一致している場合です。 両方のソースからの伝播は中間で合流しますが、それらの制約がすべてのパスに沿って厳密に同期しない限り、間隔は非シングルトンのままになります。 BFS ベースの制限された計算は、ソースを個別に扱うのではなく、すべての制約フロントを同時にマージするため、これを正確に捕捉します。 

最後の微妙なケースは、グリッドが完全に決定されたときに発生します。 ここでは、既知のセルからの伝播によりすべてのパスが完全にロックされ、最小値と最大値があらゆる場所で収束します。 一貫性が達成されると、緩和はどちらの境界も改善できないため、アルゴリズムはこの崩壊を自然に検出します。
