 ## 問題の理解

 私たちは、各タイプが変換可能なリソースのように動作するコーヒー タイプのシステムを使用しています。 目標は、最終的にできるだけ多くのタイプ 1 のコーヒーを生産することです。 

最初、カナコはスミカから制御可能な量のコーヒーを受け取ります。 sumika は、バイナリ文字列で示される特定の型のみを提供します。 タイプが利用可能な場合、選択したすべての開始タイプの合計量が固定予算を超えない限り、そのタイプのマイナスでない実際の量を受け取ることができます。$v$。 これは、許可されたタイプ間で初期予算を任意の割合で自由に分割できることを意味します。 

この設定後、取引ルールを繰り返し適用することができます。 各取引には 2 つの入力タイプが含まれ、1 つの出力タイプが生成されます。 取引は離散的ではなく、連続的です。スケーリング係数を選択します。$k$、そして取引は 2 種類のコーヒーを比例した量で消費し、3 番目の種類のコーヒーを比例した量で生産します。 これにより、すべての取引が資源量間の線形変換になります。 

最終的な目的は、任意に多くの取引を行った後に最終的に得られるタイプ 1 コーヒーの量を最大化することです。 

制約は種類数が少なく、コーヒーの種類は最大 20 種類、取引ルールは最大 100 個です。 初期ボリューム$v$非常に大きくなる可能性があり、最大で$10^{18}$これは、解が量を直接シミュレートすることができず、代わりに比率または正規化された値を使用する必要があることを示唆しています。 実数値係数の存在は、組み合わせ検索ではなく、連続最適化または線形不等式定式化を強く示唆しています。 

重要なエッジケースは、取引が総生産高を無限に増加させるサイクルに連鎖できる場合に現れます。 たとえば、一連の交換により、ある型の 1 つの単位をそれ自体の複数の単位に変えることができる場合、適用を繰り返すと無制限の増加が生じ、その答えは次のようになります。$-1$。 これは複数の中間型を通じて間接的に発生する可能性があるため、微妙です。 

もう 1 つの微妙なケースは、システムが制限されているものの、複数の初期ソースがある場合です。 利用可能な開始タイプ間で初期予算を任意に分配できるため、最適な戦略は固定されておらず、どのタイプが最終的にタイプ 1 への最良の変換をもたらすかによって決まります。 

数量は実数値であり、プロセスが収束するか完全に発散するには無限に多くの改善が必要になる可能性があるため、取引の単純なシミュレーションや数量に対する繰り返しの適用はすぐに失敗します。 

## アプローチ

 直接シミュレーションでは、コーヒー量の現在のベクトルを維持し、改善を求めて可能なすべての取引を繰り返し適用しようとします。 各取引は継続的にスケーリングされるため、1 つのアプリケーションでも、状況に応じて無限に多くの中間状態を生成できます。$k$。 したがって、離散シミュレーションは明確に定義されておらず、たとえ離散化されたとしても、取引ごとにリソース配分の新しい組み合わせが作成されるため、意味のある状態の数は爆発的に増加します。 

より構造化されたアプローチは、視点を数量から値の伝播に移すことです。 コーヒーの量を追跡する代わりに、各コーヒーの種類に値を割り当てます。つまり、その種類の 1 単位から最終的にどのくらいの量のタイプ 1 のコーヒーを得ることができるかです。 これらの値がわかっていれば、最終的な答えは初期供給量に対する単純な線形式になります。 

これにより、問題は一貫した値の割り当てを見つけることに変わります。$R[i]$ここで、各取引には制約が課せられます。出力の値は、適切にスケーリングされた入力の加重合計と少なくとも同じ大きさでなければなりません。 取引が転換した場合$a$型の単位$x$そして$b$型の単位$y$の中へ$c$型の単位$z$なら、次のようにする必要があります。$$c \cdot R[z] \ge a \cdot R[x] + b \cdot R[y].$$並べ替えると、次の推定値を改善できる緩和ルールが得られます。$R[z]$。 

これは、エッジが単一の先行ノードではなくノードのペアに依存することを除いて、最長パス問題と同様の単調最大化システムを形成します。 緩和を繰り返すと、正のサイクルがない限り、達成可能な最良の値に収束します。正のサイクルがある場合、値は際限なく増大する可能性があり、答えは無限です。 

もう一度$R[i]$が計算されると、初期条件は単純になります。総体積を分配できます。$v$利用可能なソース タイプの中から最適なソース タイプを選択し、その単位値に次の値を掛けます。$v$。

 ## アルゴリズムのチュートリアル

 各タイプからタイプ 1 への最適な変換率を計算するようにシステムを再定式化します。 

### 1. 値の推定値を初期化する

 配列を定義します$R$どこ$R[i]$タイプ 1 コーヒー 1 単位からどれだけのタイプ 1 コーヒーが得られるかを表します。$i$。 から始めます$R[1] = 1$、タイプ 1 の 1 ユニットはすでにターゲットの 1 ユニットであり、他のすべての値はゼロから始まるためです。 

この初期化では既知の情報のみがエンコードされ、取引による改善が可能になります。 

### 2. すべての貿易ルールを繰り返し緩和する

 取引変換ごとに$x, y \to z$を生成することによって得られるタイプ 1 の値の可能な限り最良のゲインを計算します。$z$から$x$そして$y$。 この取引には次のような意味があります。$$R[z] \leftarrow \max\left(R[z], \frac{a \cdot R[x] + b \cdot R[y]}{c}\right).$$1 つの値を改善すると、下流でのさらなる改善が可能になるため、すべての取引でこのプロセスを複数回繰り返します。 依存関係が循環を形成するため、この伝播が必要です。 

### 3. 際限のない増大を検出する

 緩和中に、すべての取引を何度も完全に通過した後でも何らかの価値がまだ増加する可能性があることが観察された場合、システムには収益性の高いサイクルが含まれています。 これは、リソースを増幅するためにトレードを無期限に適用し続けることができることを意味します。したがって、答えは次のとおりです。$-1$。 

実際的な方法は、せいぜい実行することです$n$完全に反復し、その後も改善が見られるかどうかを確認します。 

### 4. 最適な初期割り当てを計算する

 値が安定したら、Sumikaから入手可能なすべてのタイプを調べます。 総量を任意に分配できるため、次のようになります。$$\max_{i \in S} R[i] \cdot v,$$どこ$S$利用可能な開始タイプのセットです。 

これは、初期予算全体を最も効率的な開始リソースに投資することに相当します。 

### なぜ効果があるのか

 重要な不変条件は次のとおりです$R[i]$常に、タイプからの達成可能な最良の変換率の下限を表します。$i$各取引は真の変換効率を過大評価できない有効な線形変換をエンコードするため、すべての緩和ステップで正確さが維持されます。 これ以上の緩和が不可能な場合は、可能な限り厳しい値ですべての制約が満たされます。 伝播を繰り返しても改善が可能であれば、厳密に価値を高めるサイクルが存在することを意味し、際限のない成長を意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, v = input().split()
        n = int(n)
        m = int(m)
        v = float(v)

        s = input().strip()

        edges = []
        for _ in range(m):
            a, x, b, y, c, z = input().split()
            a = float(a)
            b = float(b)
            c = float(c)
            x = int(x) - 1
            y = int(y) - 1
            z = int(z) - 1
            edges.append((a, x, b, y, c, z))

        INF = 1e100
        R = [0.0] * n
        R[0] = 1.0

        def relax():
            changed = False
            for a, x, b, y, c, z in edges:
                val = (a * R[x] + b * R[y]) / c
                if val > R[z] + 1e-15:
                    R[z] = val
                    changed = True
            return changed

        # propagate values
        for _ in range(n * 5):
            if not relax():
                break

        # check unbounded growth
        if relax():
            print(-1)
            continue

        best = 0.0
        for i in range(n):
            if s[i] == '1':
                best = max(best, R[i])

        print(best * v)

if __name__ == "__main__":
    solve()

ここでは、制約が小さく、必要な精度により小さなイプシロンしきい値で標準の倍精度が許可されるため、浮動小数点演算が安定しています。 

最終的な乗算`v`初期予算を最も効率的な開始コーヒーの種類に完全に集中できることを反映しています。

 ## 特殊なケース

 重要なケースの 1 つは、たとえ単一の取引で利益が得られそうにない場合でも、サイクルによって厳密な改善が可能になる場合です。 このようなシナリオでは、リラックスを繰り返すと、最終的にはいくらか増加します。$R[i]$フルパスの後、無制限の検出ロジックがトリガーされます。 たとえば、次のようなチェーン$1 \to 2 \to 3 \to 1$結合比率が 1 を超える場合は、単一ステップでは検出されませんが、伝播後に表示されます。 

もう 1 つの微妙なケースは、最適な初期選択がタイプ 1 である場合でも、タイプ 1 ではない場合です。 出力を最大化しているため、アルゴリズムはタイプ 1 が常に最適であると仮定するのではなく、すべてのソース タイプを正しく比較します。 

最後のエッジケースは、改善が非常に小さい場合の数値安定性です。 イプシロンしきい値により、微小な浮動小数点ノイズが誤ったサイクル検出や無限ループを引き起こさないことが保証されます。
