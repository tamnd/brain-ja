 ## 解決策
 ## 問題の理解

 座標軸に沿って配置された幅のある長方形の屋根が与えられます。$w$と高さ$h$。 屋根は、から始まる平面内にあります。$(0,0)$。 固定サイズの同一の長方形タイルもあります$a \times b$。 これらのタイルは回転できないため、方向は固定されています。 

作業は、タイルを最初から見つけることではありません。 代わりに、2 つのタイルがすでに平面のどこかに配置されています。 それらは屋根の外側に延びていてもよいが、それぞれが屋根の少なくとも一部と重なり、互いに重なり合わない。 これら 2 つのタイルは、正確にその場所に留まる必要があります。 

同じものをコピーして屋根全体をカバーできるかどうかを判断する必要があります。$a \times b$既存の 2 つのタイルを移動せず、タイルを重ねることなく、タイルを屋根の境界を越えて拡張できるようにします。 

重要な問題は、タイリングの構造が全体的に固定であることです。タイルは回転できず、すべて同一であるため、有効なタイリングは幅のグリッドに揃える必要があります。$a$と高さ$b$。 事前に配置された 2 つのタイルにより、どのグリッドの位置合わせが可能であるかが制限されます。 

入力サイズは最大で$10^4$テスト ケース、座標と寸法は次のようになります。$10^9$。 これにより、シミュレーションやブルートフォース配置が排除されます。 各テストは、モジュラー演算と構造観察に基づいて、一定時間内に解決する必要があります。 

単純な間違いは、タイルをわずかに移動することで配置を局所的に「修正」できると想定することです。 これは不可能です。タイリングが存在すると、すべてのタイル位置が厳密な周期格子に従うよう強制されるからです。 もう 1 つの微妙な問題は、1 つの座標方向のみが重要であると考えることです。 実際には、x と y の両方の位置合わせが同時に一貫していなければなりません。 

素朴な推論が失敗する具体的なシナリオは、配置された 2 つのタイルの X 座標のモジュロが異なる場合です。$a$。 たとえば、1 つのタイルが で始まる場合、$x=0$そしてもう一つは$x=1$と$a=2$、まだギャップを埋めることができると思うかもしれませんが、グローバルグリッドは両方を同時に通過できないため、これは不可能です。 

## アプローチ

 タイルの構造を無視する場合、配置のシミュレーションを試みる可能性があります。開始タイル位置を選択し、両方の固定タイルがその上に配置されるようにしながら、グリッドを水平方向と垂直方向に拡張しようとします。 グリッドには配置の選択肢が制限されておらず、総当りのシフトによって一貫性をチェックするには、両方の軸で考えられるすべてのオフセットを反復する必要があるため、これはすぐに実行不可能になりますが、制約の下では不可能です。 

重要な観察は、固定された平面の有効なタイリングはすべて、$a \times b$長方形は単一のオフセットの選択に対応します$(x_0, y_0)$、すべての位置にタイルを配置します$(x_0 + ka, y_0 + lb)$。 これは、すべてのタイルの左下隅が次の条件を満たす必要があることを意味します。$$x \equiv x_0 \pmod a, \quad y \equiv y_0 \pmod b$$次に、事前に配置された 2 つのタイルについて考えてみましょう。 それぞれがこのグローバル オフセットに制約を課します。 両方のタイルが同じタイルに属する場合、それらの x 座標は一致する法でなければなりません$a$、それらの y 座標は一致するモジュロでなければなりません$b$。 

ただし、さらに微妙な点があります。たとえそれらが合同モジュロであっても、$a$そして$b$、屋根の境界を越えて長方形の完全な範囲をどのように拡張できるかに関して矛盾を生じさせてはなりません。 屋根自体はタイルを制約しませんが、両方の固定タイルが同じ無限グリッドの一部に留まるという要件によって制約されます。 

したがって、問題は 2 つのタイルが共通のタイルに属することができるかどうかを確認することになります。$a \times b$格子の位置合わせ。 そうでない場合、答えは即座に「ノー」です。 「はい」の場合、屋根が垂直または水平のグリッド線で分割される方法に強制的な不一致が生じないことも確認する必要があります。 これにより、タイルが屋根のさまざまなストリップ分解を「ブロック」する可能性がある少なくとも 1 つの次元に沿って位置合わせの一貫性をチェックすることができます。 

これを確認するためのより操作的な方法は次のとおりです: プレーンは垂直方向の幅のストリップに分割されます。$a$。 各ストリップは、y 方向に独立してタイル状に並べられます。 両方の固定タイルが異なる垂直位相にある場合 (つまり、それらの x 座標のモジュロが$a$異なる）の場合、互換性のないストリップの位置合わせが強制されます。 同じロジックが高さの水平方向にも適用されます。$b$。 

したがって、決定は、2 番目のタイルによって引き起こされる矛盾なしに、x 整列または y 整列のいずれかをグローバルに一貫させることができるかどうかをチェックすることに帰着します。

 ## アルゴリズムのチュートリアル

 1. 次のことを確認して、x オフセットの互換性を計算します。$x_1 \equiv x_2 \pmod a$。 これにより、両方のタイルを同じ垂直タイル グリッド上に配置できるかどうかが決まります。 
2. 次のことを確認して、y オフセットの互換性を計算します。$y_1 \equiv y_2 \pmod b$。 これにより、両方のタイルを同じ水平タイル グリッド上に配置できるかどうかが決まります。 
3. 両方の合同が成り立つ場合は、一貫したグローバル タイル アライメントが存在すると結論付けられ、「はい」と出力されます。 
4. それ以外の場合、単一の周期タイルには両方の固定タイルを同時に含めることはできないと結論付け、「いいえ」を出力します。 

モジュラー比較のみが必要な理由は、完全なタイリングは格子原点の選択と同等であるためです。 2 つのタイルはそのラティスに一致するか、または 2 つの互換性のないラティスを強制します。 

### なぜ効果があるのか

 同一の非回転による平面の有効なタイリング$a \times b$長方形は、点が次の整数倍だけ異なる平面上で一意の等価関係を引き起こします。$a$xで、そして$b$yで。 すべてのタイルの左下隅は、次のように決定される 1 つの等価クラスに属します。$(x \bmod a, y \bmod b)$。 事前に配置された 2 つのタイルが異なるクラスにある場合、拡張機能はグローバルに同じクラス構造を保持するため、補完はそれらを調整できません。 それらが同じクラスにある場合、整列された各ストリップ内で矛盾なくプレーンを独立して埋めることができるため、タイリングを一貫して拡張できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        w, h, a, b = map(int, input().split())
        x1, y1, x2, y2 = map(int, input().split())

        if (x1 - x2) % a == 0 and (y1 - y2) % b == 0:
            out.append("Yes")
        else:
            out.append("No")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装は、モジュラー アラインメントのアイデアに直接準拠しています。 唯一の微妙な点は、負の座標を正しく処理することですが、Python のモジュロ演算子はすでに、`(x1 - x2) % a == 0`。 

このソリューションは、各テスト ケースを一定時間で独立して処理し、入力を読み取り、2 つのモジュール条件をチェックします。

 ## 特殊なケース

 エッジ ケースの 1 つは、座標が負であっても有効なタイル配置を表す場合です。 たとえば、次のタイル$(-1,-1)$モジュロ演算の下で一貫して処理する必要があります。 小切手`(x1 - x2) % a == 0`は絶対的な残基ではなく相対的なアライメントを比較するため、これを正しく処理します。 

別の特殊なケースは、タイルが屋根の境界のはるか外側にある場合に発生します。 両方のタイルが完全に外側にある場合でも、依然としてグローバル タイルを制約します。 たとえば、両方のタイルが次の場所に配置されている場合、$(10^9, 10^9)$そして$(10^9 + a, 10^9)$、x 条件は合格しますが、y 条件は独立して失敗または合格する可能性があり、決定は純粋にモジュールのままです。 

最後のエッジ ケースは、1 つのタイルがグリッド境界に正確に位置合わせされ、もう 1 つのタイルが境界付近にあるものの境界上にない場合です。 座標の違いが 1 でも、実現可能性は損なわれます。これは、互換性のない 2 つの格子原点が強制され、部分的な調整ではそれらを調和させることができないためです。
