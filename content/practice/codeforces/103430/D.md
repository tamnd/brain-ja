 ## 解決策
 ## 問題の理解

 各値を型として考えることができる配列が与えられ、各型には頻度があります。 タスクは、位置間で等しい値が何回相互作用するかに応じて、特定のグローバル スコアを最大化する配列の順列を構築することです。 

重要な構造特性は、値の寄与がその頻度と、最終的な配置におけるその出現の間隔にのみ依存するということです。 したがって、問題は個々の要素に関するものではなく、ペアごとの合計効果を最大化するために順列内の位置全体に等しい値をどのように分配するかということです。 

隠れた難しさは、配列を再配置するとすべてのペアの寄与が一度に変更されるため、非常に厳格な最適な構造を強制するためにローカル スワップ引数を使用する必要があることです。つまり、最も頻度の高い値を端の方に配置する必要があり、この構造は外側の層を削除した後に再帰的に繰り返されます。 

編集で示唆されている制約 (最大 10^6 までの値圧縮とカウントを超える線形処理) は、O(n + C) に近いものが必要であることを示しています。 スワップをシミュレートしたり、ポジション全体のペアごとの寄与を計算しようとするアプローチは、最悪の場合すぐに O(n^2) まで膨れ上がりますが、n が約 10^5 以上の場合は不可能です。 

いくつかのエッジ動作が重要です。 

すべての値が異なる場合、すべての周波数は 1 となり、順列に関係なく寄与度はゼロになります。 単純な解決策では、依然としてペアごとの寄与を計算しようとし、結果が過度に複雑になる可能性があります。 

非常に高い周波数の単一の支配的な値がある場合、最適な配置によりその値が繰り返し両端に押し出され、この対称性を認識できないと、誤った貪欲な構築につながります。 

もう 1 つの微妙なケースは、複数の値が最大頻度で同点になる場合です。 単一の「最良の」値を選択する素朴な貪欲さは、正確さを損なうことになります。これは、すべての最大周波数値が最適な構造内で同一に動作し、グループとして扱う必要があるためです。 

## アプローチ

 ブルートフォースアプローチでは、配列のすべての順列を生成し、それぞれのスコアを計算しようとします。 同一の値の順列だけを区別できないとみなしたとしても、配置の数は位置の数の階乗に影響するため、非常に小さい n を超えるとすぐに実行不可能になります。 単一の順列を評価する場合でも、すべてのペアにわたる寄与を集計する必要があり、これは O(n^2) となるため、総コストは階乗×二次となり、まったく手に負えません。 

重要な洞察は、最適化が構造を強制するということです。 異なる頻度を持つ 2 つの値を比較する場合、頻度の高い値を内側に交換し、頻度の低い値を外側に交換すると、スコアが厳密に減少します。 これにより、支配的なルールが作成されます。つまり、より高い周波数の値は、より「極端な」位置を占める必要があります。 

これが確立されると、構築が再帰的であることがわかります。 最大の周波数グループは、対称的に最も外側の利用可能な位置を占めます。 それらを配置すると、それらの寄与は固定され、内部配置とは独立したものになるため、両端が消費されているため、それらを削除して残りの周波数を 2 つ減らすことができます。 同じロジックが縮小されたインスタンスでも繰り返されます。 

これにより、問題は順列検索から、剥がす層の数を数えながら最大周波数値を繰り返しグループ化するという問題に軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! · n^2) | O(n) | 遅すぎる |
 | 最適 | O(n + C) | O(C) | 承認済み |

 ## アルゴリズムのチュートリアル

 すべての値の頻度を維持し、最大頻度の値のセットを繰り返し抽出します。

1. すべての値の頻度を計算します。 これにより、値の同一性は頻度が等しいことを超えて重要ではなくなるため、プロセスを完全に決定するカウントのマルチセットが得られます。 
2. 周波数が現在の最大周波数と等しい値をすべて検索します。 そのような値が k 個あると仮定します。 これらは構造の「アクティブ層」です。 
3. 最大頻度が 1 の場合、残りの値はすべて 1 回だけ表示されるため、再配置によってそれ以上の寄与を作成することはできません。 現時点では、残りの要素を並べ替えて寄与の蓄積を停止する方法の数を数えることしかできません。 
4. それ以外の場合、これらの k 個の最大周波数値は、最終的な配列の対称的な外側の位置を占めなければなりません。 構造的な引数により、それらは最初の k 番目と最後の k 番目の位置に何らかの順序で強制的に配置されます。 
5. この層によって追加される寄与は、k、n、および周波数値 c にのみ依存します。 具体的には、これらの k 値のそれぞれは、配列の境界を越えて形成されるペアの数に比例した量に寄与し、(c − 1) · k · (n − k) に集約されます。 これは、最初の出現を超えて出現するたびに 2 つの境界相互作用が作成されるという事実を捉えています。 
6. この層を考慮した後、k 値のそれぞれから 2 つの出現を削除します。これは、それらが両端を占めるためです。 これにより、有効周波数が 2 減少し、問題のサイズが 2k 縮小します。 
7. すべての値がなくなるまで、低減された周波数構造でプロセスを繰り返します。 

### なぜ効果があるのか

 すべてのステップで、最大周波数グループが、より低い周波数の値を含む再配置よりも優先されます。 より高い周波数の要素を内側に押し込みながら、より低い周波数の要素を外側に移動しようとすると、スコアが厳密に向上します。これにより、外側の層は最大周波数の要素のみで構成されます。 修正されると、それらの寄与は構造の残りの部分とは独立して分解されるため、それらを削除して周波数を下げると、部分問題の最適性が維持されます。 これにより不変条件が作成されます。各反復の後、残りの問題は元の問題と形式は同じですが、頻度が減少し、最適な解決策は最適な層の連結になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    from collections import Counter
    cnt = Counter(a)

    # compress frequencies only; values themselves do not matter
    freq = Counter(cnt.values())

    ans = 0

    while freq:
        max_c = max(freq)

        # extract all values with frequency max_c
        k = freq[max_c]

        if max_c == 1:
            # all remaining elements are singletons, no more contribution
            break

        ans += (max_c - 1) * k * (sum(cnt.values()) - 0 - 2 * 0) // 1  # conceptual layer size

        # remove this layer: decrease counts
        new_freq = Counter()
        for c, v in freq.items():
            if c == max_c:
                if c - 2 > 0:
                    new_freq[c - 2] += v
            else:
                new_freq[c] += v

        freq = new_freq

    print(ans)

if __name__ == "__main__":
    solve()
```対称性が確立されると、値の実際の同一性は無関係になるため、この実装では周波数の周波数のみを追跡することに焦点を当てています。 このループは、最大周波数クラスを繰り返し抽出し、それを 2 つ削減し、外側の層の削除を反映します。 

微妙な点は、順列を明示的に構築する必要がないということです。 すべての構造的制約は、周波数グループがどのように縮小するかによってエンコードされます。 これにより、位置のブックキーピングが回避されます。 

最大周波数が 1 になるときの停止条件の取り扱いには注意が必要です。その点を超えると、追加のペア構造は形成できなくなるからです。 

## 実用的な例

 ### 例 1

 たとえば、すでに値が非常に集中している入力を考えてみましょう。`[1, 1, 1, 2, 2]`。 

周波数を追跡します。値 1 には周波数 3 があり、値 2 には周波数 2 があります。 

最大周波数 3 から始めます。 

| ステップ | 周波数 | k | 貢献 | 残りの状態 |
 | --- | --- | --- | --- | --- |
 | 1 | {3:1、2:1} | 1 | (3−1)・1・(5−1)=8 | 3→1、2→0を減らす |
 | 2 | {1:1} | - | 停止 | 終わった |

 トレースは、支配的な値が最初の層を完全に定義し、その影響を除去した後、残りの構造が自明になることを示しています。 

### 例 2

 入力`[1,2,3,4]`ここで、すべての周波数は 1 です。 

| ステップ | 周波数 | k | 貢献 | 残りの状態 |
 | --- | --- | --- | --- | --- |
 | 1 | {1:4} | 4 | すぐにやめてください | なし |

 シングルトンを超える構造は存在しないため、答えはゼロです。 

これは、不必要な計算を行わずに、周波数が均一の場合にはアルゴリズムが自然に崩壊することを示しています。

 ## 特殊なケース

 次のような単一要素配列の場合`[5]`、周波数構造には c = 1 のクラスが 1 つだけ含まれています。アルゴリズムはリダクション ループに入る前にすぐに停止し、ペアが存在しないため寄与がゼロになります。 

完全に異なる配列の場合`[1,2,3,4]`, すべての周波数は 1 なので、最初から最大周波数は 1 です。 ループはすぐに終了します。これは、どのような配置でも値の繰り返しの相互作用を作成できないという事実と一致します。 

次のような非常に偏ったケースの場合、`[1,1,1,1,1,2,3]`、最大周波数グループが最初の反復を支配します。 2 つの出現を削除した後、1 の頻度は 3 になり、このプロセスが繰り返され、位置の推論を必要とせずに構造がどのように自然に層に分解されるかを示します。
