 ## 問題の理解

 一連の撮影を行っています$n$バスケットボールの試み、そしてそれぞれの試みは成功するか失敗します。 重要な難点は、得点の確率が固定されていないことです。得点の確率は前のショットの結果のみに依存するため、プロセスには単純な「1 ステップの記憶」があります。 

初めに、最初のショットの成功確率は分数で与えられます。$\frac{p_0}{q_0}$。 その後、システムは以下のように進化していきます。 前のショットが成功した場合、次のショットは確率で成功します$\frac{p_1}{q_1}$。 前のショットが失敗した場合、次のショットは確率で成功します$\frac{p_2}{q_2}$。 

タスクは、全体にわたって予想される成功ショット数を計算することです。$n$試み。 各ショットの確率は前の結果に依存するため、イベントは相関しており、それらを独立して扱うことはできません。 出力はモジュロで指定する必要があります$998244353$つまり、すべての分数は逆剰余を使用した剰余算術で解釈されなければなりません。 

制約は、どのような種類の解決策が期待されるかについての主なヒントです。 テスト ケースの数は次のように大きくなります。$5 \cdot 10^4$、 そして$n$まで行くことができます$10^{12}$。 これにより、シミュレーションやステップごとの動的プログラミングが即座に排除されます。 平$O(n)$テストケースごとに実行することは不可能であり、$O(\log n)$ステップごとに遅すぎるでしょう。 目的のソリューションでは、通常、閉形式の反復を見つけるか、システムを小さな線形変換に削減することによって、プロセス全体をテスト ケースごとの一定数の操作に削減する必要があります。 

素朴なアプローチを壊すことが多い微妙な問題は、各ショットを独立して扱ったり、遷移が以前の結果の分布に依存することを忘れずに「現在の確率」だけを追跡したりすることです。 もう 1 つの落とし穴は、時間の経過に伴う確率をシミュレートしようとすることです。$n$、単一の線形 DP ステップが繰り返された場合でも$10^{12}$時代は無理だ。 

たとえば、すべてのショットに確率があると誤って仮定した場合、$\frac{p_1}{q_1}$、答えは次のようになります$n \cdot \frac{p_1}{q_1}$最初のショットとミス状態がその後のすべてに影響を与えるため、これは明らかに間違っています。 

## アプローチ

 直接的な総当たりアプローチは説明が簡単です。 ショットごとにシミュレーションを行います。 前回のショットが成功したか失敗したかを追跡し、各ステップでその状態を条件とした成功の確率を計算します。 また、州全体の確率分布も維持します。 後$n$ステップごとに、各ステップでの成功確率を合計して期待値を取得します。 

これはマルコフ依存性を尊重しているため、正しく機能します。各ステップは前のステップにのみ条件付けされます。 ただし、コストは直線的です$n$。 単一のテスト ケースの場合、$n = 10^{12}$、これはまったく不可能です。 

重要な観察は、プロセスには関連する状態が 2 つだけあるということです。つまり、前のショットは成功か失敗でした。 これらの状態間の遷移確率は、前の分布では線形です。 これにより、システム全体を現在のショットが成功する確率の一次元の反復に圧縮することができます。 反復が確立されると、期待値は閉じた形式を持つ線形反復の合計になります。 

これにより、問題は、長い確率過程のシミュレーションからモジュラー算術における幾何学的タイプの系列の評価へと変換されます。

 ## アルゴリズムのチュートリアル

 しましょう$a = \frac{p_1}{q_1}$、$b = \frac{p_2}{q_2}$、 そして$s_i$となる確率になります。$i$- 番目のショットは成功しました。 

また、$E_i$最初のショットのうち成功したショットの予想数として$i$。 

1. コンピューティング$s_1 = \frac{p_0}{q_0}$。 最初のショットは以前の結果に依存しないため、これが基本ケースです。 
2. 遷移を表現する$s_i$のために$i \ge 2$。 前のショットは確率で成功するか$s_{i-1}$、または確率的に失敗します$1 - s_{i-1}$。 したがって：$$s_i = s_{i-1} \cdot a + (1 - s_{i-1}) \cdot b$$3. 漸化式をアフィン形式に単純化します。$$s_i = b + (a - b)s_{i-1}$$これは一次線形漸化式です。 
4. 定数を定義する$d = a - b$そして$c = b$、 それで：$$s_i = c + d s_{i-1}$$5. この繰り返しを解決します。 もし$d \ne 1$、閉じた形式になります。$$s_i = s_* + (s_1 - s_*) d^{i-1}$$どこ$s_* = \frac{c}{1-d}$は固定点です。 
6. 期待値を計算します。$$E_n = \sum_{i=1}^{n} s_i$$閉じた形式を代入し、2 つの合計に分割します。 

定数部分と等比級数部分です。 
7. モジュラー算術を使用して両方の合計を評価します。 

幾何学的な和と算術幾何学的な組み合わせ。 これにより、すべてが数回のべき乗剰余演算と逆演算に削減されます。 

もし$d = 1$、繰り返しは次のようになります。$$s_i = s_{i-1} + c$$それで$s_i$直線的です$i$、合計は単純な等差数列になります。 

### なぜ効果があるのか

 核となる不変条件は、プロセスの履歴全体が単一のスカラーによって完全にキャプチャされることです。$s_i$、前のショットが成功した確率。 将来の確率はすべてこの値のみに依存し、更新規則は線形です。 システムが線形反復になると、長期的な動作は閉じた形式の式に崩壊し、合計が計算されます。$n$標準の等比級数恒等式に変換します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    T = int(input())
    out = []

    for _ in range(T):
        n = int(input())
        p0, q0, p1, q1, p2, q2 = map(int, input().split())

        s1 = p0 * modinv(q0) % MOD
        a = p1 * modinv(q1) % MOD
        b = p2 * modinv(q2) % MOD

        d = (a - b) % MOD
        c = b

        if n == 1:
            out.append(str(s1))
            continue

        if d == 1:
            # s_i = s1 + (i-1)*c
            # sum = n*s1 + c*(n*(n-1)/2)
            n_mod = n % MOD
            sum_n = n_mod * (n_mod - 1) % MOD * modinv(2) % MOD
            ans = (n_mod * s1 + c * sum_n) % MOD
            out.append(str(ans))
            continue

        # fixed point s*
        denom = (1 - d) % MOD
        inv_denom = modinv(denom)
        s_star = c * inv_denom % MOD

        dn = pow(d, n, MOD)
        dn1 = pow(d, n - 1, MOD)

        # sum s_i = n*s* + (s1 - s*) * sum d^(i-1)
        geom = (dn - 1) % MOD * modinv(d - 1) % MOD

        ans = (n % MOD * s_star % MOD + (s1 - s_star) % MOD * geom) % MOD
        ans %= MOD

        out.append(str(ans))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```実装は、モジュラー逆関数を使用してすべての確率をモジュラー形式に変換することから始まります。 これが必要なのは、すべての確率は有理数であり、モジュロ算術で評価する必要があるためです。 

次に、遷移規則を 2 つの定数に還元します。$a$そして$b$、プロセスを完全に決定します。 そこから、漸化式は乗算器を備えた単一の線形形式に単純化されます。$d = a - b$。 

ソリューションは 1 回だけ分岐します。$d = 1$。 このケースは、確率が幾何級数ではなく線形に増加する縮退再発に対応しており、等比級数の式でのゼロ除算を避けるために個別に処理する必要があります。 

他のすべては、線形項と組み合わせた等比数列の閉じた形式の合計から直接得られます。
