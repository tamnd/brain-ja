 ## 解決策
 ## 問題の理解

 私たちには円形のトラックが与えられています$n$からラベル付けされた等間隔の位置$0$に$n-1$。 カエルはその位置から開始します$0$。 それぞれの動きでカエルは正確にジャンプします$x$円に沿って前進する、つまりその位置から前に進む$i$それは常に次の場所に着陸します$(i + x) \bmod n$。 

問題は、カエルが元の位置に戻ることができるかどうかです。$0$いくつかのジャンプの後。 動きは決定論的であるため、これは追加を繰り返すかどうかを尋ねることに相当します。$x$モジュロ$n$最終的に生成する$0$また。 

入力には複数のテスト ケースが含まれており、それぞれが独立しているため、ペアごとにこの到達可能性の質問に答える必要があります。$(n, x)$。 

制約により、最大で$10^3$テストケースと値$n, x$まで$10^6$。 これにより、最大で実行されるシミュレーションが即座に除外されます。$n$最悪の場合、テストごとにジャンプします。$10^9$トータルオペレーション。 

微妙なエッジケースが発生する場合$x = 0$。 その場合、カエルは決して動きません。 で始まる場合$0$、すでにすぐに「戻ってきています」。 したがって、次の場合、正しい答えは常に「はい」です。$x = 0$、 かかわらず$n$。 

もう 1 つのエッジケースは次のような場合です$x \ge n$。 移動はモジュロなので$n$、これは次の使用と同等です。$x \bmod n$。 この削減を忘れた単純な実装は、生のジャンプをシミュレートしようとすると、一貫性のない動作をする可能性があります。 

## アプローチ

 直接シミュレーションは位置から開始されます$0$そしてトランジションを繰り返し適用します$i \to (i + x) \bmod n$に戻るまで、訪問した位置をマークします。$0$または状態を繰り返します。 しかないから$n$状態、これは常に最大で終了します$n$ステップ。 

これは移動規則に正確に従っているため、これは正しいです。 ただし、最悪の場合、$x = 1$または$x$と互いに素である$n$、サイクル長は次のようになります。$n$、以上$10^3$これがもたらすテストケース$O(n \cdot t)$が鈍くなるにもほどがあります。$n$大きいです。 

重要な観察は、動きがモジュラー算術サイクルであるということです。 到達可能な位置のセットは、正確に、によって生成された追加のサブグループです。$x$モジュロ$n$。 数論からの古典的な事実は、この部分群は次のすべての倍数から構成されるということです。$\gcd(n, x)$、サイクルは に戻ります。$0$まさにその後$n / \gcd(n, x)$ステップ。 戻りがまったく起こるかどうかだけを気にするので、移動によって状態構造が意味のある形で変化しないという些細なケースを除いて、答えは常に肯定的になります。 実際には、から始めて、$0$、繰り返される加算は常に有限サイクル内に留まり、元のサイクルに戻らなければなりません。$0$最終的にはどんな人にとっても$x$、 含む$x = 0$。 

したがって、到達可能性条件は定数時間チェックに縮小されます。縮退解釈によって移動が禁止されている場合を除き、すべての場合に「はい」を返しますが、モジュラー演算の下でも同様です。$x = 0$カエルを一定に保つ$0$、それでも要件を満たします。 

したがって、モジュラーサイクリングを正しく解釈すると、問題は自明な「常にはい」という答えに崩壊します。

 ## アルゴリズムのチュートリアル

 1.読む$n$そして$x$テストケースごとに。 これらは、有限状態空間上で決定論的なモジュール遷移システムを定義します。 
2. すべての状態には出力エッジが 1 つだけあるため、プロセスは最終的にサイクルに入らなければならないことに注目してください。 
3. システムは有限かつ決定論的であるため、次から始めます。$0$、パスは最終的に以前に確認された状態を繰り返す必要があります。 
4. 繰り返しが発生すると、シーケンスはサイクルを形成し、システムはモジュール加算であるため、$0$は常に次から始まるサイクルの一部です$0$。 
5. 選択に関係なく、カエルは常に開始位置に戻ると結論付けます。$x$。 

同じ事実をより代数的に見るには、次のようになります。$k$位置をジャンプします$kx \bmod n$。 存在するかどうかを尋ねています$k > 0$そのような$kx \equiv 0 \pmod n$。 選択する$k = n$常に機能するため$nx \equiv 0 \pmod n$、したがって返品が保証されています。 

### なぜ効果があるのか

 不変条件は次のとおりです$k$カエルを動かすと常にその位置にいます$kx \bmod n$。 この式は循環群から離れることはありません$\mathbb{Z}_n$、および乗算$x$地図$\mathbb{Z}_n$それ自体の中に。 以来$\mathbb{Z}_n$は有限であり、状態のシーケンスは周期的であり、周期は分割されます$n$。 したがって、状態$0$から始まる軌道に再び現れる必要があります$0$、答えが常に肯定的であることを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n, x = map(int, input().split())
        out.append("yes")
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装は、入力の読み取り以外の計算は必要ないという事実を反映しています。 各テスト ケースは独立しているため、すべてのペアに単に「yes」を追加します。 

唯一の微妙な点は、最大で高速 I/O を確保することです。$10^3$テストケースですが、単純な印刷でも十分です。 数学的構造によりすべての構成での到達可能性が保証されるため、算術的なエッジ ケースは必要ありません。

 ## 特殊なケース

 のために$x = 0$、カエルは決して動きません。 から開始$0$、シーケンスは一定です$0 \to 0 \to 0$。 すべてのテスト ケースが肯定的に回答され、開始点がすでに到達可能であるという要件と一致するため、アルゴリズムは正しく「はい」を出力します。

どれについても$n$そして$x$、シーケンスは有限状態空間に限定されており、繰り返す必要があります。 から始まるので、$0$、を含むサイクル$0$は常に即座に入力され、出力はどの場合でも「yes」のままになります。
