 ## 解決策
 ## 問題の理解

 私たちには、最大 10 枚のカードと、固定された戦闘統計を持つ 1 体のボス モンスターという非常に小さな手札が与えられます。 私たちの目標は、このボスが二度と戻ってこないようにゲームから削除できるかどうかを判断することです。 

ボスは 2 つのフェーズでカードを操作します。 まずは手札のモンスターカードを使って破壊してみます。 モンスターカードで破壊できるかどうかはボスの戦闘位置によって異なります。 攻撃表示の場合は攻撃力2500以上のモンスターが必要です。守備表示の場合は守備値2100を超える必要があるため、厳密に攻撃力2100以上のモンスターが必要です。 

ボスが戦闘で破壊された場合、ボスは墓地に行きます。 そこから、特別なスペルカードを使用してそれを追放し、将来の復活を防ぐことができます。 あるいは、ボスを直接フィールドから追放できる罠のようなカードもありますが、これを使用するには手札からもう一枚カードを捨てる必要があります。 

タスクは、ボスが最終的に追放されることを保証する、指定されたハンドを使用した一連のプレイが存在するかどうかを判断することです。 

制約はカードが最大 10 枚と極めて小さいため、大規模な構造物に対する大量の組み合わせ検索は即座に排除されます。 最悪のケースは 1024 州のみであるため、すべてのサブセットにわたる指数関数的推論も実現可能です。 これは、問題が複雑なゲームの相互作用をシミュレートするのではなく、いくつかの重要な構造条件をチェックすることに関するものであることを強く示唆しています。 

微妙な点は、アクションの順序は限られた方法でのみ重要であるということです。 ダイレクトバニッシュカードには手札を捨てる必要がありますが、手札は他のカードでも構いません。そのため、合計で少なくとも 2 枚のカードがあることが唯一の要件です。 もう1つの微妙な点は、ボスの破壊は墓地から追放するカードも持っている場合にのみ有効であり、そうでない場合は後で復活する可能性があるということです。 

すべてが 1 ターン内に発生し、すべてのインタラクションが即座に行われるため、複数のターンや部分的な効果を伴う隠れたエッジのケースはありません。 

## アプローチ

 ブルートフォースアプローチでは、カードの可能なすべてのサブセットと、それらを使用する可能なすべてのシーケンスが試行されます。 命令ごとに、ボスを破壊して追放できるか、直接追放できるかをシミュレーションします。 カードは最大 10 枚であるため、サブセットの数は 2^10 = 1024 となり、各サブセット内の順列により複雑さがさらに増大する可能性があります。 これは技術的には実現可能ですが、不必要に複雑になり、問題の構造が見えにくくなります。 

重要な観察は、実際には順序や詳細な順序を気にしていないということです。 ゲームは、2 つの独立した勝利条件のうちの少なくとも 1 つが満たされるかどうかをチェックすることになります。 

最初の勝利条件は、もう一枚手札を捨てる必要がある特殊カードによる直接追放です。 これは、少なくとも 1 枚のそのようなカードと少なくとも 1 枚の追加のカードが手札にある場合にのみ可能です。 他の制約は関係ありません。 

2 番目の勝利条件は 2 段階のプロセスです。 まず、現在の位置ルールでボスを破壊できるモンスターを少なくとも 1 体用意する必要があります。 それから、少なくとも1枚の墓地除外カードも必要です。 両方存在する場合、まず破壊してから墓地から追放することができます。 

これら 2 つの条件は十分であり、すべての有効な戦略をカバーします。 すべてのカードは 1 ターン内に任意の順序で使用できるため、一方の戦略が他方の戦略を意味のある方法でブロックするような相互作用はありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n・n!) | O(n) | 遅すぎて不必要 |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

1. すべてのカードをスキャンし、指定された戦闘位置ルールの下でボスを破壊できるモンスターが少なくとも 1 体いるかどうかを記録します。 有効なアタッカーがなければ墓地へのルートは不可能であるため、このステップは重要です。 
2. 墓地からカードを追放できるタイプ 1 のカードが少なくとも 1 枚あるかどうかを記録します。 これは、破壊してから追放する戦略に必要です。 
3. フィールドからボスを直接追放できるタイプ 2 のカードが少なくとも 1 枚あるかどうかを記録します。ただし、別のカードを捨てることができる場合に限ります。 
4. まずダイレクトバニッシュの状態を確認します。 タイプ 2 のカードが存在し、カードの合計数が少なくとも 2 であれば、いつでも他のカードを捨ててボスを即座に追放できます。 この条件が当てはまる場合、答えはすぐに肯定的になります。 
5. 直接追放できない場合は、2 段階のルートを確認してください。 少なくとも1枚の有効なモンスターカードと少なくとも1枚のタイプ1カードが存在する場合、ボスを破壊し、墓地から追放することができます。 両方が存在する場合、答えは肯定的です。 
6. どちらの条件も当てはまらない場合、有効なプレイ順序によってボスの復活を妨げることはできないため、答えは否定的になります。 

この推論の背後にある重要な不変条件は、すべての成功した戦略はボスの追放で終わる必要があり、それを達成する唯一の 2 つの方法は、フィールドから直接追放するか、破壊後に追放するかのいずれかであるということです。 ボスを永久に削除された状態に変更できるルールの移行は他にありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

has_monster = False
has_banish_grave = False
has_black_core = False

for _ in range(n):
    parts = input().split()
    t = int(parts[0])
    
    if t == 0:
        atk = int(parts[1])
        if m == 0:
            if atk >= 2500:
                has_monster = True
        else:
            if atk > 2100:
                has_monster = True
    elif t == 1:
        has_banish_grave = True
    else:
        has_black_core = True

# direct banish via black core
if has_black_core and n >= 2:
    print("haoye")
    sys.exit()

# destroy then banish
if has_monster and has_banish_grave:
    print("haoye")
else:
    print("QAQ")
```コードは手を 3 つの論理フラグに分割します。 モンスターの有効性はボスの位置に依存するため、入力をスキャンしながらそれに応じて攻撃しきい値をチェックします。 直接追放チェックでは、タイプ 2 カードの存在と他のカードを捨てる能力のみが使用されます。これは、合計で少なくとも 2 枚のカードがあることと同等です。 

そのルートが失敗した場合、私たちは唯一残された実行可能な戦略、つまり破壊可能なモンスターと墓地を追放するカードの組み合わせをテストします。 両方が存在する場合、成功します。 

直接追放を検出した後の早期終了は厳密には必要ではありませんが、この戦略が独立していて厳密に十分であるという事実を反映しています。

## テストケース```python
import sys, io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())

    has_monster = False
    has_banish_grave = False
    has_black_core = False

    for _ in range(n):
        parts = input().split()
        t = int(parts[0])

        if t == 0:
            atk = int(parts[1])
            if m == 0 and atk >= 2500:
                has_monster = True
            if m == 1 and atk > 2100:
                has_monster = True
        elif t == 1:
            has_banish_grave = True
        else:
            has_black_core = True

    if has_black_core and n >= 2:
        return "haoye"
    if has_monster and has_banish_grave:
        return "haoye"
    return "QAQ"

# provided sample
assert solve("2 0\n0 2500\n1 0\n") == "haoye"

# minimal fail: single black core only
assert solve("1 0\n2\n") == "QAQ"

# direct banish works
assert solve("2 1\n2\n0 100\n") == "haoye"

# destroy + grave banish
assert solve("3 0\n0 2500\n1 0\n0 10\n") == "haoye"

# no valid monster
assert solve("2 0\n0 1000\n1 0\n") == "QAQ"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 カードブラックコア | QAQ | 要求の破棄失敗 |
 | 黒のコア付きカード 2 枚 | ハオイェ | 直接追放の実現可能性 |
 | モンスター+墓追放 | ハオイェ | 二段階戦略 |
 | 弱いモンスター | QAQ | 攻撃しきい値の正確性 |

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、ハンドにタイプ 2 のカードが 1 枚だけ含まれている場合です。 この状況では、別のカードを捨てる必要があるため、カード自体は役に立ちません。 アルゴリズムは、直接追放を許可する前に、カードの合計数が少なくとも 2 枚であることを明示的にチェックすることでこれを処理します。 

もう一つのエッジケースは、モンスターは存在するが墓地除外カードが存在しない場合です。 たとえボスを破壊できたとしても、ボスは復活するでしょう。そして、アルゴリズムは両方の条件を同時に要求することによってこれを正しく拒否します。 

3 つ目のエッジケースは、個別の攻撃値が不十分な弱いモンスターが複数存在する場合です。 少なくとも 1 つの有効なモンスターのみが必要なため、アルゴリズムはすべての無効なモンスターを正しく無視し、値を集計するのではなく、条件を満たすカードの存在のみを追跡します。
