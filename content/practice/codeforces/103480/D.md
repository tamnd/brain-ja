 ## 問題の理解

 初期ラインナップとしては、$n$子どもたち、子どもたち一人ひとり$i$幸福度は固定されています$h_i$。 おもちゃは最初に順列によってシャッフルされます: child$i$ラベルが貼られたおもちゃを受け取る$w_i$、つまり配列$w$の順列です$1 \dots n$。 

その後、プロセスはラウンドで展開されます。 各ラウンドで、すべての子供は現在持っているおもちゃを取り、そのおもちゃのラベルが示す子供にそれを渡します。 具体的には、子どもの場合$i$おもちゃを持っている（前のラウンドでそこに到着したと言います）、子供にそれを渡します$w_i$。 各ラウンドの後、子供たちはそれぞれ、現在持っているおもちゃのラベルを確認します。 いつでもそれが最初のラベルと同じである場合$w_i$、彼らは永久に参加を停止します。 

各子供について、停止するまでに何ラウンド生き残るかを数えます。 この番号が$c_i$、固定順列の合計スコアは次のようになります。$\sum h_i \cdot c_i$。 タスクは、サイズのすべての順列にわたってこのスコアを合計することです$n$、モジュロ$998244353$。 

制約$n \le 2000$順列を反復したり、順列ごとにダイナミクスをシミュレートしたりするアプローチは除外されます。 あるので$n!$順列でも$n=10$すでに大きくなっている。 有効なソリューションでは、寄与を閉じた形式の組み合わせ式に圧縮する必要があります。 

すぐに止めようと思うと、微妙なエッジケースが現れます。 子どもは最初は割り当てられたおもちゃを持っているため、誤って仮定する可能性があります。$c_i = 0$。 ただし、停止はラウンド終了後にのみチェックされるため、1 ステップ後に即時復帰が強制される構造でない限り、すべての子供は少なくとも 1 ラウンドに参加します。 

## アプローチ

 ブルートフォース解釈は簡単です。 順列ごとにプロセスをラウンドごとにシミュレートし、すべての子供が安定するまでどの子供がどのおもちゃを保持しているかを追跡します。 各シミュレーションの費用$O(n \cdot \text{cycle length})$、そして、あります$n!$順列が異なるため、これは完全に不可能になります。 

重要な観察は、プロセスが完全に順列グラフによって制御されていることです。$w$。 各おもちゃは、次のように定義された機能グラフに沿って決定的に動きます。$i \to w_i$。 以来$w$は順列であり、グラフは互いに素なサイクルに分解され、各おもちゃはそのコンポーネント内でサイクルします。 

子供$i$で始まったおもちゃがちょうど止まるとき$i$に戻ります$i$。 それはノードを含むサイクルの長さです$i$順列で$w$。 それで$c_i$は単に次の周期の長さです$i$で$w$。 

これにより、スコアがきれいな組み合わせ形式に変わります。 固定順列の場合、$$H(w) = \sum_{i=1}^n h_i \cdot \text{cycleLen}_w(i)$$線形性により、寄与をインデックスごとに分けることができます。$$\sum_{w} H(w) = \sum_{i=1}^n h_i \cdot \sum_{w} \text{cycleLen}_w(i)$$対称性により、内和はすべての要素で同一になります。$i$したがって、問題は、すべての順列に対する固定要素の合計サイクル長の寄与を計算することに帰着します。 

最終的な構造的洞察は、ランダムな置換における固定要素のサイクル長分布がすべてのサイズにわたって均一であるということです。$1 \dots n$これにより、問題全体が閉じた形式に折りたたまれます。

 ## アルゴリズムのチュートリアル

 ここで、順列を列挙せずに必要な合計を計算します。 

1. 合計の答えが値において線形であることを観察します。$h_i$したがって、各インデックスの寄与を個別に分離します。 これが機能するのは、順列ダイナミクスが異なるものを結合しないためです。$h_i$価値観。 
2. 位置を固定する$i$。 こどもが何歩勉強するか$i$順列の中で生き残る$w$。 これはノードを含むサイクルの長さとまったく同じです$i$。 
3. タスクを、固定要素 (要素など) のサイクル長の合計をすべての順列にわたって計算するものとして再定式化します。$1$。 
4. 要素の頻度を数える$1$長さのサイクルに属します$k$。 私たちはもう一方を選びます$k-1$サイクル内の要素$\binom{n-1}{k-1}$それらをサイクルに配置します。$(k-1)!$残りの方法を並べ替えます$n-k$任意の要素$(n-k)!$方法。 乗算すると$(n-1)!$、独立して$k$。 
5. 以来$k$から$1$に$n$が同じ頻度で発生する場合、固定要素の予想サイクル長は平均です。$1 \dots n$、つまり$(n+1)/2$。 
6. 期待値に順列の数を掛ける$n!$すべての順列にわたるサイクル長の合計を取得するには、次のようにします。$$S = n! \cdot \frac{n+1}{2}$$1. 最終的な答えは次のとおりです。$$\left(\sum h_i\right) \cdot S$$### なぜ効果があるのか

 すべての順列は独立して合計に寄与し、各インデックスは順列の対称性の下で同一に動作します。 重要な不変条件は、固定要素のサイクル長分布がすべての可能なサイクル サイズにわたって均一であることです。これにより、その合計寄与がきれいに因数分解されます。 この対称性が認識されると、インデックス間の相互作用はなくなり、和は完全に分解されます。

import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

n = int(input())
h = list(map(int, input().split()))

s = sum(h) % MOD

fact = [1] * (n + 1)
for i in range(1, n + 1):
    fact[i] = fact[i - 1] * i % MOD

ans = s * fact[n] % MOD
ans = ans * (n + 1) % MOD
ans = ans * modinv(2) % MOD

print(ans)

import sys, io

MOD = 998244353

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    n = int(input())
    h = list(map(int, input().split()))

    def modinv(x):
        return pow(x, MOD - 2, MOD)

    s = sum(h) % MOD

    fact = [1] * (n + 1)

    ans = s * fact[n] % MOD

assert run("1\n1\n") == "1", "minimum case"

assert run("4\n1 2 3 4\n") == "600", "increasing values"

assert run("5\n1 1 1 1 1\n") == str((5 * 120 * 3 * pow(2, MOD-2, MOD)) % MOD), "all equal"

 ## 特殊なケース

 主なエッジケースは次のような場合です$n = 1$。 順列セットには要素が 1 つだけ含まれており、サイクル長は自明のことながら 1 です。式は次のようになります。$1! \cdot (1+1)/2 = 1$、直接的な解釈と一致します。 

もう 1 つの微妙なケースは、すべてが$h_i$等しいです。 この状況では、問題は純粋にすべての順列にわたるサイクル長の平均化に帰着します。 均一性引数により、インデックス間で隠れたバイアスがないことが保証されるため、答えは合計サイクル質量のきれいなスカラー倍となり、式はそれを正確に捕捉します。
