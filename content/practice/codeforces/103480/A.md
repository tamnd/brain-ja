 ## 問題の理解

 いくつかのテストケースが与えられています。 いずれの場合も、単一の文字の複数セットを受け取ります。 各文字は最大 1 回使用でき、選択した文字を任意の順序で並べ替えることができます。 目標は、これらの文字のサブセットを選択し、回文である文字列に配置して、その回文の長さを最大化することです。 

回文は、中心を中心に対称的にペアになる文字の数と、場合によってはペアになっていない文字が 1 つ中央に配置されるかによって完全に決まります。 この構造は、中心となる制約を強制します。文字は、中央に座ることができる最大 1 つの残りの文字を除き、ペアを通じてのみ回文に寄与します。 

入力サイズでは、最大 10 個のテスト ケースが許可され、それぞれに最大 100,000 文字が含まれます。 これにより、順列の構築や組み合わせ検索の実行を試みるソリューションが即座に除外されます。 テスト ケースごとの線形スキャンは許容されますが、テスト ケースごとの文字数が 2 次になると制限を超えます。 

すべての文字が区別できる場合、微妙なエッジケースが表示されます。 たとえば、次のように入力します`A B C D`ペアが存在しないため、回文には 1 文字のみ許可されます。 もう 1 つのエッジ ケースは、1 つの文字が何度も出現し、他の文字が 1 回しか出現しない場合です。`a a a b c`。 ここで、最良の回文はすべての偶数ペアを使用します。`a`そして、おそらく中央の 1 文字を除いてシングルトンを無視します。 貪欲に交互に切り替えたり、頻度をカウントせずに「外側に向かって構築」しようとする単純なアプローチでは、これらの貢献を誤ってカウントすることになります。 

## アプローチ

 この強引なアイデアは、文字のすべてのサブセットと各サブセットのすべての順列を考慮し、各配置が回文を形成しているかどうかを確認し、最大長を追跡することです。 これは有効な構造の検索空間全体を探索するため、概念的には簡単です。 ただし、サブセットのみを選択した場合でも、すでに 2^n 個の可能性が得られ、順列によりこれに階乗増加が乗算されます。 n が 100,000 までの場合、このアプローチは実行できません。 

回文の構造により、問題が大幅に単純化されます。 回文は、順序ではなく、文字の頻度によって完全に決定されます。 各文字は、できるだけ多くのミラーリングされたペアに貢献します。 すべてのペアは、最終的な答えに 2 文字を貢献します。 考えられるすべてのペアを形成した後、少なくとも 1 文字が未使用のままであれば、そのような文字を 1 つだけ中央に配置し、長さを 1 だけ増やすことができます。 

これにより、問題が組み合わせ配置から頻度カウントに軽減されます。 重要な観察は、最適な構築はどの特定の位置が選択されるかには決して依存せず、すべての文字にわたって形成できるペアの数にのみ依存するということです。

 ## アルゴリズムのチュートリアル

 1. 入力に各文字が何回出現するかを数えます。 周波数がわかれば配置は無関係となるため、これにより関連するすべての構造が捕捉されます。 
2. 文字頻度ごとに、整数を 2 で割ることによって完全なペアがいくつ形成できるかを計算します。各ペアは、回文に正確に 2 文字を与えます。 
3. これらのペアの寄与をすべて合計し、2 を掛けます。これにより、回文の対称辺が寄与する全長が得られます。 
4. ペアリング後の残りカウントが奇数の文字が少なくとも 1 つ存在するかどうかを追跡します。 これは、少なくとも 1 人のキャラクターがセンターを務めることができることを示します。 
5. 奇数の余りがある場合は、答えに 1 を加えて中心文字を配置します。 
6. 最終的に計算された長さを出力します。 

機能する理由: 回文の構築では対称性が強制されるため、左側で使用されるすべての文字は右側に対応する文字が必要です。 これにより、使用法が素のペアに分割されます。 残った文字は、中心となる 1 文字を除いて対称に配置できません。 ペアリングはキャラクターごとに独立しており、周波数ごとに貪欲に最大化されるため、結果として得られる構築は最適になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        freq = {}
        
        arr = input().split()
        for c in arr:
            freq[c] = freq.get(c, 0) + 1
        
        length = 0
        has_odd = False
        
        for v in freq.values():
            length += (v // 2) * 2
            if v % 2 == 1:
                has_odd = True
        
        if has_odd:
            length += 1
        
        print(length)

if __name__ == "__main__":
    solve()
```このソリューションは、シングルパス周波数の累積を中心に構成されています。 辞書には各文字のカウントが保存されますが、文字は独立しているため、これで十分です。 

重要な計算は、`(v // 2) * 2`、周波数を使用可能な対称寄与に変換します。 2 を掛けると、左右のペアが明確に失われるのを明示的に回避できます。 

ブール値`has_odd`は、中心文字を配置できるかどうかをエンコードするため、重要です。 中央のスロットは 1 つだけ存在するため、すべての文字にわたって奇数が 1 つ発生するだけで十分です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from sys import stdin
    input = stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        arr = input().split()
        freq = {}
        for c in arr:
            freq[c] = freq.get(c, 0) + 1

        length = 0
        has_odd = False
        for v in freq.values():
            length += (v // 2) * 2
            if v % 2:
                has_odd = True
        if has_odd:
            length += 1

        out.append(str(length))

    return "\n".join(out)

# provided samples (interpreted)
assert run("2\n1\nA\n3\na v a\n") == "1\n3"

# all same character
assert run("1\n5\na a a a a\n") == "5"

# no pairs at all
assert run("1\n4\na b c d\n") == "1"

# mixed frequencies
assert run("1\n6\na a b b b c\n") == "5"

# maximum-like balanced
assert run("1\n8\na a b b c c d d\n") == "8"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | すべて同じ文字 | 全長 | 最大のペアリングの場合 |
 | すべての異なる文字 | 1 | 中央のみ可能 |
 | 混合周波数 | 正しいペアの集約 | 不均一な分布 |
 | 完璧にバランスの取れたペア | フル活用 | 食べ残しはありません |

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、繰り返される文字がない場合です。 のような入力の場合`a b c d`、周波数マップはすべて 1 を生成します。 このアルゴリズムはペアの寄与からゼロを計算し、少なくとも 1 つの奇数を検出するため、正しく 1 を出力します。 

もう 1 つのケースは、ちょうど 1 つの文字の頻度が高く、他の文字がシングルトンである場合です。`a a a a b c d`。 アルゴリズムは次の 2 つのペアを形成します。`a`、4 を寄与し、シングルトンの 1 つを中心として使用し、5 を与えます。残りのシングルトンは、追加のペアを形成できないため、結果に影響を与えません。 

最後のエッジケースは単一要素入力です。 入力あり`A`の場合、ペアの合計はゼロであり、奇数が存在するため、答えは 1 となり、唯一可能な回文と一致します。
