 ## 解決策
 ## 問題の理解

 各位置がインデックスと同じ範囲内の値を指す配列が与えられます。 インデックスを繰り返し選択できます`i`そして、positionに格納されている値を交換します`i`位置に格納された値を使用して`a[i]`。 つまり、この操作により 2 つのエントリを交換できますが、2 番目のインデックスは任意ではなく、現在の値によって決まります。`i`。 

タスクは、初期構成から開始してこの操作を何度でも適用することによって、到達できる異なるアレイの数を決定することです。 

重要な問題は、この操作がフリー スワップではないことです。 各移動は選択したインデックスの現在の値に依存するため、到達可能な状態は、任意の再配置ではなく、配列の順列にわたる構造化されたグラフを形成します。 

制約`n ≤ 10^6`状態を明示的に調査するアプローチは直ちに除外されます。 アレイの数は指数関数的に増加するため、アクセスした構成を保存することさえ不可能です。`n`。 有効な解決策は、エッジによって定義される有向グラフの構造特性に問題を帰着させる必要があります。`i -> a[i]`。 

配列に固定点または小さなサイクルが含まれる場合、微妙なエッジ ケースが発生します。 

たとえば、次の場合`a = [1, 1, 1]`、操作を行っても何も変わらないため、答えは次のようになります。`1`。 素朴な解釈では、これを順列のように扱い、複数の再配置を期待するかもしれませんが、この操作は常に同一の値を交換するか、単純な構造内で交換します。 

もう 1 つのエッジ ケースは、グラフに次のようなサイクルが含まれる場合です。`1 → 2 → 3 → 1`。 この状況では、操作を繰り返すとサイクル内のローカルな再配置が可能になりますが、他のコンポーネントとは相互作用しません。 単純なグローバル順列ビューでは、サイクル間の相互作用が誤って過大評価されてしまいます。 

核となる隠れた構造は、配列が有向関数グラフを定義し、操作がこのグラフの接続されたコンポーネントにのみ制限された方法で影響を与えるということです。 

## アプローチ

 ブルートフォースアプローチでは、プロセスを状態グラフとしてシミュレートします。 各状態は配列であり、各状態からすべてのインデックスを試して新しい状態を生成します。`i`そして交換`a[i]`と`a[a[i]]`。 これにより、構成間の遷移が定義されます。 

ただし、中程度の場合でも、`n`, このグラフには階乗スケールの分岐があります。 スワップごとに関数グラフの構造が変化する可能性があり、到達可能な配列の数は指数関数的に増加します。 BFS または DFS が状態を越えると、メモリと時間が即座に爆発的に増加します。 

重要な観察は、この操作によって恣意的な並べ替えが作成されないことです。 すべてのノードが出力エッジを 1 つだけ持つ有向グラフのエッジに沿った値の交換のみが許可されます。 これは関数グラフです。つまり、各接続コンポーネントには、ツリーがそこにフィードされる有向サイクルが 1 つだけ含まれています。 

各コンポーネント内では、すべてのノードが最終的にサイクルに向かって「流れ」ます。 この操作により、これらのコンポーネント内でのみ再配置が効果的に許可され、到達可能な構成の数はサイクル構造のみに依存します。 

重要なステップは、単一の接続コンポーネントで何が起こっているかを分析することです。 サイクルにつながるツリーは独立した自由度ではありません。スワップは最終的に値をサイクルに向けてバブルさせますが、追加の組み合わせの選択肢は作成しません。 組み合わせ変動の唯一の原因は、値が各サイクル内でどのように循環するか、およびサイクルが入力ツリーによって課せられる制約とどのように相互作用するかです。 

これにより、問題はコンポーネントごとの構成のカウントに軽減されますが、これは要因の寄与とサイクル サイズから導出されるパリティのような制約に依存することがわかります。 分解すると、答えはサイクル長に基づいた単純な閉じた形式の式のコンポーネントの積になります。

 ## アルゴリズムのチュートリアル

 1. 各インデックスが含まれる有向グラフを構築します。`i`～する利点がある`a[i]`。 これにより、すべてのノードが出次数 1 を持つ関数グラフが形成されます。この構造により、各コンポーネントが正確に 1 つのサイクルを持つことが保証されます。 
2. DFS または反復走査を使用して、グラフを連結コンポーネントに分解します。 トラバーサル中に、各ノードがサイクル上にあるか、サイクルにつながるツリー内にあるかを識別します。 サイクル構造は、組み合わせ論に影響を与える唯一の部分です。 
3. 各成分について、そのサイクルの長さを抽出します。 これは、訪問状態を追跡することで実行できます。現在の再帰スタックで再訪問されたノードは、そのサイクルに属します。 
4. コンポーネントの寄与を計算します。 重要な事実は、各サイクルの長さは`k`～の要因に寄与する`2`もし`k > 1`、貢献します`1`さもないと。 これは、サイズが 1 より大きいサイクルでは、スワップ操作の下で厳密に 1 つの非自明な反転のような自由度が許可されるのに対し、自己ループは剛直であるために発生します。 
5. Multiply contributions across all components modulo`10^9 + 7`。 
6. 最終積を答えとして返します。 

The correctness hinges on the fact that tree edges do not introduce independent permutations. ツリー コンポーネント内の再配置は、それが供給されるサイクルに吸収されるため、乗法的な自由度はサイクル レベルの対称性の選択からのみ得られます。 

### なぜ効果があるのか

 Each connected component of the functional graph has exactly one cycle, and all operations preserve the partition into components. スワップ操作では、コンポーネント内の値の並べ替えのみが可能であり、コンポーネント内のすべての構成は、サイクルが自明か非自明かによって決まるバイナリの選択までは同等です。 This induces a product structure over components, since operations in different components are independent and do not interact.

 ## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    a = [x - 1 for x in a]

    vis = [0] * n
    in_stack = [0] * n

    ans = 1

    def dfs(u):
        stack = []
        cur = u
        while True:
            vis[cur] = 1
            in_stack[cur] = 1
            stack.append(cur)
            nxt = a[cur]
            if vis[nxt]:
                if in_stack[nxt]:
                    cycle_nodes = stack[stack.index(nxt):]
                    return len(cycle_nodes)
                break
            cur = nxt
        for v in stack:
            in_stack[v] = 0
        return 1

    for i in range(n):
        if not vis[i]:
            cycle_len = dfs(i)
            if cycle_len > 1:
                ans = (ans * 2) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```実装は関数グラフを暗黙的に構築し、各ノードを 1 回走査します。 DFS は再帰の深さの問題を回避するために反復的です。`n = 10^6`。 の`in_stack`配列は、現在のトラバーサル パス内のサイクルを識別するバック エッジを検出するために使用されます。 サイクルが見つかると、その長さによってコンポーネントが 2 の係数に寄与するかどうかが決まります。 

微妙な点は、正確なサイズではなく、1 より大きいサイクル長パリティのみを考慮していることです。 サイクルが存在すると、それに接続されているすべてのツリー構造はカウントを変更しません。

 ## 特殊なケース

 次のような最小限の固定小数点構成`a = [1]`1 を超える長さのサイクルは発生しません。DFS はただちに単一ノードを訪問済みとしてマークし、バック エッジを検出せず、サイクル長 1 を返し、乗算係数 1 に寄与します。 

次のような 2 ノードのスワップ構造`a = [2, 1]`長さ 2 のサイクルを作成します。トラバーサルは、再帰スタック内でノード 1 からノード 0 に戻るときにすぐにバック エッジを検出し、コンポーネントは係数 2 に寄与して、応答 2 を生成します。 

のような混合構造で、`a = [2, 3, 2]`、ノード 0 と 2 がサイクルを形成し、ノード 1 がそれ​​にフィードします。 DFS はサイクルを識別します`[0, 1, 2]`構造のコア サイクルが正しく行われ、ツリーのアタッチメントが無視されるため、単一の寄与係数 2 が得られます。
