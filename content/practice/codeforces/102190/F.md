 # 問題の理解

 各フレーズは、すべての単語の最初の文字を取得して形成された略語で表されます。 すべての単語は大文字で始まるため、これは単なる単語の頭文字のシーケンスであり、略語を比較する際には大文字と小文字は無視されます。 

例えば、`East China Normal University`になる`ECNU`、 その間`Electronic Circuit National Union`もなる`ECNU`。 同じ略語を持つ異なるフレーズの順序のないペアはすべて、答えに 1 つ貢献します。 

したがって、このタスクは実際にはフレーズ自体を比較することではありません。 フレーズを略語でグループ化し、サイズ k のグループごとに、そのグループ内の順序なしペアの数を追加するだけです。 

( 2 k )= 2 k(k−1) 。 

最大 5⋅10 5 のフレーズが存在する可能性があるため、すべてのペアを調べるには、最悪の場合でも約 1.25⋅10 11 の比較が必要になります。 これは、競技プログラミング ソリューションが対応できる範囲をはるかに超えています。 単語の総数は最大でも 10 6 であり、これは入力量の線形に近い解決策が意図されていることを強く示唆しています。 各単語の長さは最大 11 であるため、完全な入力を 1 文字ずつ処理することも実用的です。 

不注意な実装が失敗する可能性のあるエッジケースがいくつかあります。 

フレーズが 1 つだけ含まれている辞書を考えてみましょう。```

```明確に区別できるフレーズのペアは存在しないため、答えは次のようになります。`0`。 フレーズ自体をペアとしてカウントする解決策は間違っています。 

ここで 1 文字の単語を考えてみましょう。```

```略語は次のとおりです。`CSL`、`OXX`、 そして`OO`、 それぞれ。 全部違うから答えは`0`。 すべての単語に複数の文字が含まれていると想定するパーサーは、最初の 2 行を誤って処理します。 

大文字と小文字も単語を読むときには重要ですが、略語を比較するときには重要ではありません。 例えば：```

```どちらの略語も`AB`、したがって、答えは次のとおりです`1`。 略語の比較では、大文字のイニシャルを同じ文字として扱う必要があります。 

最後に、いくつかのフレーズがまったく同じ略語を持つ場合があります。```

```すべてのフレーズには 2 つの頭文字からなる略語がありますが、これらは次のとおりです。`AB`、`CD`、`EF`、 そして`GH`、したがって、答えは次のとおりです`0`。 代わりに、4 つのフレーズすべてに略語がある場合`AB`、答えは次のようになります

 ( 2 4 )=6、

 なぜなら、すべてのフレーズのペアが矛盾するからです。 

# アプローチ

 直接的なアプローチは、すべてのフレーズの略語を作成し、すべてのフレーズのペアを比較することです。 フレーズ i と j の略語が等しい場合、答えが増分されます。 すべての順序付けされていないペアが 1 回だけ検査されるため、これは正しいです。 

問題は比較の二次数です。 n=5⋅10 5 の場合、

 2 n(n−1) = 2 500000⋅499999 =124999750000

 最悪の場合はペアになります。 たとえ 1 つの比較にかかる時間がごくわずかであったとしても、10 11 を超える演算は実行できません。 

2 つの略語が等しいかどうかによってペアが有効であるかどうかが完全に決定されるため、総当り攻撃は機能しますが、多くのフレーズに対して同じ等価性の質問を繰り返し行うため、失敗します。 重要な観察は、同じ略語を持つフレーズが自然なグループを形成するということです。 すべてのペアを比較する代わりに、各略語に属するフレーズの数を数えることができます。 

略語が k 回出現すると仮定します。 これらの k 個のフレーズはすべて他の k-1 個のフレーズと競合しますが、これを直接カウントすると k(k-1) が得られ、順序のないすべてのペアが 2 回カウントされます。 2 で割ると次のようになります

 2 k(k−1) 。 

さらに便利な実装では、最初にすべての周波数を保存する必要がなくなります。 フレーズを一度に 1 つずつ処理します。 現在の略語がすでに c 回出現している場合、新しいフレーズは、それらの前のフレーズと正確に c 個の新しい順序のないペアを形成します。 答えに c を追加し、頻度を c+1 に増やします。 

これにより、問題全体が頻度カウントの問題に変わります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n 2 ) | O(n) | 遅すぎる |
 | 最適 | O(L) が期待されます | O(L) | 承認済み |

 ここで、L は合計入力サイズ、つまり読み取る必要がある文字の合計数です。 すべてのワードの長さは最大 11 であり、ワード数は最大 10 6 であるため、L は指定された入力サイズで線形です。 

# アルゴリズムのチュートリアル

 1. 各フレーズを 1 行として読みます。 フレーズには少なくとも 2 つの単語が含まれており、連続する単語はスペース 1 つで区切られます。 
2. 行の最初の文字を取得し、次に各スペースの直後の文字を取得して、その省略形を作成します。 このような文字はすべて頭文字が大文字であるため、辞書キーとして使用する前に小文字に変換してください。 
3. 頻度辞書で現在の略語を調べます。 それが以前に c 回出現した場合、新しいフレーズは正確に c 個の新しい矛盾する順序のないペアを形成します。 答えに c を追加します。 
4. この略語の保存頻度を 1 つ増やします。 更新された頻度は、後のフレーズに同じ略語がある場合に使用されます。 
5. すべてのフレーズが処理された後、蓄積された回答を印刷します。 

ステップ 3 が ( 2 k ) を明示的に計算せずに機能する理由は、フレーズが一度に 1 つずつ到着するためです。 略語を持つ最初のフレーズが到着すると、ペアは作成されません。 2 番目の関数は、最初の関数と 1 つの新しいペアを作成します。 3 番目では、最初の 2 つと 2 つの新しいペアが作成され、以下同様に続きます。 したがって、サイズ k のグループが寄与します。 

0+1+2+⋯+(k−1)= 2 k(k−1) 。 

### なぜ効果があるのか

 最初の i フレーズを処理した後、次の不変条件を維持します。`answer`は、これらの i フレーズに完全に含まれる、矛盾する順序のないペアの正確な数です。`count[x]`略語が x である処理済みフレーズの数です。 

次のフレーズが略語 x を持つ場合、略語 x を持つ前に処理されたすべてのフレーズは、それと 1 つの新しい順序のないペアを形成します。 まさにあります`count[x]`そのようなフレーズなので、その値を追加すると、新しく作成されたすべてのペアが 1 回だけカウントされます。 異なる略語間のペアは有効ではなく、すでに処理されたフレーズ間のペアはすでにカウントされています。 したがって、不変条件はすべてのフレーズの後でも true のままとなり、最後のフレーズの後では、累積された値がまさに必要な答えとなります。 

# Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    count = {}
    answer = 0

    for _ in range(n):
        line = input().strip()

        # The abbreviation consists of the first character and
        # every character immediately following a space.
        abbr = bytearray()
        abbr.append(line[0] | 32)

        for i, ch in enumerate(line):
            if ch == 32:  # ASCII space
                abbr.append(line[i + 1] | 32)

        key = bytes(abbr)

        old = count.get(key, 0)
        answer += old
        count[key] = old + 1

    print(answer)

if __name__ == "__main__":
    solve()
```各フレーズは当然 1 つのレコードであるため、入力は 1 行ずつ読み取られます。`sys.stdin.readline`これは、入力に何百万もの単語が含まれる可能性があるため、高レベルの入力メカニズムを繰り返し使用するオーバーヘッドを回避します。 

略語は、行の生のバイト表現から直接抽出されます。 最初のバイトは最初の単語の頭文字です。 すべてのスペースの直後には次の単語のイニシャルがあるため、行を個別の単語オブジェクトに分割することなく、スペースをスキャンするだけですべてのイニシャルを復元できます。 

ASCII 小文字はビット 5 を設定することによって取得されます。これは、ここで関係する大文字の英語文字に 32 を加算することと同等です。 すべての略語文字は頭文字が大文字であることが保証されているため、`ch | 32`小文字形式に変換します。 結果は次のように保存されます`bytes`、これは不変でハッシュ可能であるため、辞書キーとして適しています。 

辞書には、略語ごとに以前に処理されたフレーズの数が保存されます。 もし`old`正確にはその周波数ですか`old`現在のフレーズが到着すると、新しいペアが表示されます。 追加します`old`頻度を増やす前に、フレーズがそれ自体とペアになるのを防ぎます。 

Python の整数には任意の精度があるため、答えは次のようになります。 

( 2 500000 )=124999750000

 オーバーフローに対する特別な処理は必要ありません。

import sys
import io

def solve_data(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    try:
        sys.stdin = io.StringIO(inp)
        sys.stdout = io.StringIO()

        n = int(sys.stdin.readline())
        count = {}
        answer = 0

        for _ in range(n):
            line = sys.stdin.readline().strip()

            abbr = bytearray()

            key = bytes(abbr)
            old = count.get(key, 0)
            answer += old
            count[key] = old + 1

        print(answer)
        return sys.stdout.getvalue()

    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout
