 ## 解決策
 ## 問題の理解

 (1) から (n) までの整数があり、それらをできるだけ多く 1 つのシーケンスに保持したいと考えています。 シーケンスにはすべての整数が含まれている必要はありません。 唯一の制限はローカルです。選択された 2 つの整数が連続している場合は常に、それらは何らかの素因数を共有する必要があり、同等に、それらの gcd は少なくとも (2) でなければなりません。 

すべての (x) について (\gcd(1,x)=1) であるため、値 (1) は 1 を超える長さのシーケンスでは選択できません。 (n\ge4) であるため、最適なシーケンスの長さは常に 1 より大きいため、(1) は必然的に破棄されます。 

境界 (n\le10^6) は、二次関数や階乗関数を除外します。 Python では (O(n\sqrt n)) であっても不必要に高価になる可能性がありますが、(O(n\log\log n)) は快適です。 有用な構造は、関連するすべての整数がその素因数によって分類でき、ふるいは基本的に線形算術時間ですべての素数を明らかにできることです。 

最初の自明ではないケースは (n=4) です。 有用な数値は (2) と (4) だけであるため、正しい最大長は (2) です。たとえば、出力は次のようになります。`2 2 4`。 すべての素数がシーケンスに挿入できると仮定する不用意な実装では (3) を使用しようとしますが、(3) には最大でも他の倍数 (4) がありません。 

(n=7) の場合、シーケンスは`3 6 2 4`長さは (4) です。 素数 (3) が使用できるのは、(6) が他の倍数だけであるため、それがエンドポイントである必要があるためです。 素数 (5) と (7) は使用できません。 (n/2) 以下のすべての素数を盲目的に保持する構造では、誤って (5) が含まれてしまいます。 

(n=19) の場合、最適な長さは (14) です。 選択される素数は (3,5,7) ですが、(11,13,17,19) は除外されます。 素数 (7) には有用な倍数 (14) が 1 つだけあるため、エンドポイントを占有する必要があります。 サンプル シーケンスはこれを示しています。`7 14 ...`。 通常の合成数のすべての端点の位置を残す構築では、(7) が暗黙的に失われる可能性があります。 

## アプローチ

 ブルートフォースアプローチは、整数の可能なサブセットを列挙し、それらのサブセットの順列を試み、隣接するすべての gcd をチェックすることです。 サブセットを無視して、すべて (n) 個の数値を含む順列のみを列挙した場合でも、候補は (n!) あり、各候補には最大 (n-1) 個の gcd チェックが必要です。 したがって、完全な置換部分だけでも (\Theta(n\cdot n!)) のコストがかかり、サブセットを許可すると検索が大きくなるだけです。 (n=10^6) の場合、これは遠隔的には実現可能ではありません。 

重要な観察は、合成ではなく素数に注目することから得られます。 素数 (p) は、(p) の倍数にのみ隣接できます。 (p>n/2) の場合、他に倍数がまったくないため選択できません。 (n/3<p\le n/2) の場合、他の倍数は (2p) だけです。 したがって、このような素数は互換性グラフで次数 1 を持ち、シーケンスの 2 つの端のうちの 1 つにのみ現れることができます。 したがって、この区間から選択できる素数は最大 2 つです。 

すべての奇数素数 (p\le n/3) には少なくとも (p,2p,3p) があるため、内部に配置できます。 すべての合成、最大で (n/3) のすべての奇数素数、および (n/3) と (n/2) の間の最大で 2 つの素数を含むシーケンスを構築できます。 

この構築は、素数が大きいものから小さいものまで処理される場合に特に便利になります。 奇数の素数 (p) を処理する場合、より大きな素数によってすでに消費されている (p) の倍数はすべてスキップされます。 残りの倍数はすべて (p) で割り切れるため、これらの残りの値は単独で有効なブロックを形成します。 

素数 (p\le n/4) の場合、(2p) と (4p) の両方が利用可能です。 これらをブロックの 2 つのエンドポイントにします。 両方の端点が偶数であるため、連続するブロックの端点には少なくとも (2) の gcd があるため、異なる素数のブロックを連結できます。 

素数 (n/4<p\le n/3) の場合、(p) 以外の倍数は (2p) と (3p) だけです。 このようなブロックには、(2) と (3) で割り切れるエンドポイントがあります。 方向を交互にすることにより、連続するブロックを等しい係数 (2) と (3) で結合できます。 残っている唯一の特別なブロックは (3) のブロックであり、これらの中ブロックと残りの偶数の間に必要な接続を提供します。 

((n/3,n/2]) の 2 つの最大の使用可能な素数が存在する場合、それらは両端に配置されます。それらのブロックは単純に (p,2p) と (2p,p) であり、偶数の端点は主シーケンスに自然に接続されます。

 | アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (\シータ(n\cdot n!)) | (O(n)) | 遅すぎる |
 | 最適 | (O(n\log\log n)) | (O(n)) | 承認済み |

 ## アルゴリズムのチュートリアル

1. (n) までのエラトステネスのふるいを構築します。 通常の複合材料と特別な処理が必要な素材料を区別できるようにするために素数が必要です。 
2. 奇数の素数を 3 つの範囲に分割します。 (n/2) より大きい素数は選択できません。 (n/3) と (n/2) の間の素数には他の倍数が 1 つしかないため、最大でも 2 つだけ保持します。 (n/4) と (n/3) の間の素数は、3 要素ブロック (2p,p,3p) またはその逆を形成します。 より小さい奇数素数は、(2p) および (4p) をブロックのエンドポイントとして使用できます。 
3. ((n/3,n/2]) から選択した素数を予約します。2 つ存在する場合は、最初のブロックを先頭に置き、2 番目のブロックを最後に置きます。1 つだけ存在する場合は、そのブロックを先頭に置きます。対応する値を使用済みとしてマークし、それらの倍数が別のブロックで再利用されないようにします。
 4. 区間内の素数を処理します (n/4<p\le n/3)。 このような素数ごとに、選択される倍数は (p,2p,3p) のみです。 ブロックを交互の向きで保管します。 最初のブロックにはエンドポイント (2p) と (3p) があり、次のブロックにはエンドポイント (3q) と (2q) があります。 したがって、連続するブロックは、(3) の倍数または (2) の倍数のいずれかで出会います。 
5. 素数を処理します (3)。 (3) の未使用の倍数をすべて収集し、(6) を最初に、(12) を最後に配置します。 このブロック内のすべての値は (3) で割り切れますが、両方のエンドポイントも同様に偶数です。 中間素数カウントが奇数の場合、最終 (3p) エンドポイントは係数 (3) を介して (6) に加わります。 偶数の場合、ブロック全体を 2 つの偶数ブロックの間に単純に挿入できます。 
6. すべての奇数素数 (p) を (5\le p\le n/4) で降順に処理します。 その倍数をスキャンし、まだ使用されていないものをすべて取得します。 ブロックの先頭に(2p)、最後に(4p)を置きます。 その間のすべての値は (p) の倍数であるため、ブロック内のすべての隣接するペアは少なくとも (p) の gcd を持ちます。 2 つの端点は偶数であるため、このブロックを別のブロックに接続できます。 
7. まだ使用されていないすべての偶数を追加します。 それらはすべて (2) で割り切れるため、最後の 1 つの有効なブロックを形成します。 この時点で、選択したすべての合成数は 1 回だけ使用されています。 
8. 結果のシーケンスとシーケンス自体の長さを出力します。 (n<12) の場合、構築には狭い範囲の境界相互作用がいくつかあるため、実装ではこれらの値に対して明示的な有効な構築が使用されます。 

不変条件は、完成したすべてのブロックが完全に 1 つの共通素数の倍数で構成され、ブロック間のすべての接続が偶数のエンドポイントまたは (3) の 2 つの倍数を介して行われることです。 したがって、すべての隣接するペアは 1 より大きい公約数を持ちます。 上限は独立して続きます: (1) は不可能で、(n/2) を超える素数は分離され、((n/3,n/2]) のすべての素数は (2p) しか利用できないため、そのような素数は最大 2 つ発生します。構築は、他のすべての可能な値を含みながら、正確にその境界に達します。

 ## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    if n == 4:
        print(2)
        print(2, 4)
        return
    if n == 5:
        print(2)
        print(2, 4)
        return
    if n == 6:
        ans = [3, 6, 2, 4]
        print(len(ans))
        print(*ans)
        return
    if n == 7:
        ans = [3, 6, 2, 4]
        print(len(ans))
        print(*ans)
        return
    if n == 8:
        ans = [3, 6, 2, 4, 8]
        print(len(ans))
        print(*ans)
        return
    if n == 9:
        ans = [9, 3, 6, 2, 4, 8]
        print(len(ans))
        print(*ans)
        return
    if n == 10:
        ans = [5, 10, 2, 4, 8, 6, 3]
        print(len(ans))
        print(*ans)
        return
    if n == 11:
        ans = [5, 10, 2, 4, 8, 6, 3, 9]
        print(len(ans))
        print(*ans)
        return

    # Sieve of Eratosthenes.
    prime = bytearray(b'\x01') * (n + 1)
    prime[0:2] = b'\x00\x00'

    limit = int(n ** 0.5)
    for p in range(2, limit + 1):
        if prime[p]:
            start = p * p
            prime[start:n + 1:p] = b'\x00' * (
                (n - start) // p + 1
            )

    used = bytearray(n + 1)
    ans = []

    # Odd primes in (n/3, n/2].
    high = []
    lo = n // 3 + 1
    hi = n // 2
    for p in range(lo, hi + 1):
        if p & 1 and prime[p]:
            high.append(p)

    high = high[:2]

    # Left endpoint block.
    if high:
        p = high[0]
        ans.extend((p, 2 * p))
        used[p] = 1
        used[2 * p] = 1

    # Medium primes: n/4 < p <= n/3.
    medium = []
    lo = n // 4 + 1
    hi = n // 3
    for p in range(5, hi + 1, 2):
        if p >= lo and prime[p]:
            medium.append(p)

    # Alternate orientations:
    # [2p, p, 3p], [3q, q, 2q], ...
    for i, p in enumerate(medium):
        if i & 1:
            block = (3 * p, p, 2 * p)
        else:
            block = (2 * p, p, 3 * p)

        for x in block:
            used[x] = 1

        ans.extend(block)

    # The prime 3 and its still-unused multiples.
    block3 = []
    if 6 <= n:
        block3.append(6)

        for x in range(3, n + 1, 3):
            if x != 6 and x != 12 and not used[x]:
                block3.append(x)

        if 12 <= n:
            block3.append(12)

        for x in block3:
            used[x] = 1

        # If the number of medium blocks is odd, the previous
        # block ends in a multiple of 3, so block3 starts at 6.
        ans.extend(block3)

    # Small odd primes p <= n/4.
    # Descending order guarantees that 2p and 4p have not
    # already been consumed by a larger odd prime.
    hi = n // 4
    for p in range(hi | 1, 4, -2):
        if not prime[p]:
            continue

        block = [2 * p]

        for x in range(p, n + 1, p):
            if x == 2 * p or x == 4 * p:
                continue
            if not used[x]:
                block.append(x)
                used[x] = 1

        block.append(4 * p)
        used[2 * p] = 1
        used[4 * p] = 1

        ans.extend(block)

    # Remaining even numbers form one final block.
    for x in range(2, n + 1, 2):
        if not used[x]:
            ans.append(x)
            used[x] = 1

    # Right endpoint block, if there is a second high prime.
    if len(high) == 2:
        p = high[1]
        ans.extend((2 * p, p))
        used[2 * p] = 1
        used[p] = 1

    print(len(ans))
    print(*ans)

if __name__ == "__main__":
    solve()
```ふるいは`bytearray`Python のブール値リストの代わりに、素数テーブルを (n=10^6) に対してコンパクトに保ちます。 の`used`すべての整数に必要な状態ビットは 1 つだけであるため、配列はバイト配列でもあります。 

高素数ブロックは、より小さな素数を処理する前にマークされます。 これにより、(22) などの値が、後で別の素数を処理するときに誤って使用されるのを防ぎ、無関係な倍数を利用可能なままにします。 

ミディアムプライムブロックは、それぞれにちょうど 3 つの値が含まれるため、答えに直接保存されます。 より小さい素数の場合、コードは (p) の倍数をスキャンし、それらをすぐにマークします。 いくつかの処理された素数で割り切れる数値は、最大の処理された素数のブロックに属し、整数のセットを必要とせずに重複を防ぎます。 

エンドポイントの順序は微妙な部分です。 小さな素数 (p) の場合、`2*p`そして`4*p`より大きな奇数素数ではどちらも割り切れないため、使用できることが保証されています。 これら 2 つの値を末尾に置くと、ブロックは係数 (2) を介して接続されます。 

Python の整数はオーバーフローしないため、特別な整数型は必要ありません。 明示的な処理が必要な唯一の境界条件は、(12) より下の小さな値であり、素数 (3) の汎用 (6,12) ブロックは存在しません。

 ## 特殊なケース

 (n=4) の場合、アルゴリズムは次のように出力します。`2 4`。 (6>4) であるため、値 (3) は孤立した素数であるため、選択した別の値の横に配置する方法はありません。 したがって、最大値は (2) になります。 

(n=7) の場合、素数 (3) には、他に利用可能な倍数 (6) が 1 つだけあります。 シーケンス`3 6 2 4`両方を使用し、偶数まで続けます。 素数 (5) は、(10>7) であるため含めることができませんが、素数 (7) には他に倍数がありません。 

(n=19) の場合、素数 (7) は ((n/3,n/2]) にあるため、エンドポイントにしかなりえません。シーケンスは次で始まります。`7 14`。 プライム (5) フォーム`10 5 15`、因子 (3) ブロックが続きます。`15`そして`6`。 残りの偶数の値でシーケンスが終了します。 選択されたすべての数値は個別であり、隣接するすべてのペアには共通の因子があります。 

((n/3,n/2]) に複数の素数が存在する大きな値の場合、保持できるのは 2 つだけです。そのような各素数には (2p) までのエッジしかないため、そのうちの 3 つを使用するには、パス内に 3 つの異なる終点が必要になります。この構造では 2 つを保持し、その (2p) 値を反対側の端に配置します。

 いくつかの素数が合成倍数を共有する場合、`used`配列は、同じ整数が複数のブロックに入るのを防ぎます。 素数を大きいものから小さいものへと処理すると、所有権が決定的になります。複合素数は、まだ除外されていない最大の関連する奇数素数によって消費されます。 

最後の偶数ブロックは、奇数プライム ブロックによって消費されなかったすべてのコンポジットを処理します。 このブロック内のすべての数値は (2) で割り切れるため、追加の gcd チェックや特別な順序付けは必要ありません。
