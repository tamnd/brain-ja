 ## 解決策
 ## 問題の理解

 (n) 個の点と (n \times n) 個の距離行列があります。 一部のエントリにはすでに最終値が含まれていますが、すべての (-1) は自由に選択できる距離を表します。 最終的な行列は、次の 4 つの必須プロパティを満たす必要があります。つまり、すべての対角要素がゼロ、すべての距離が非負、行列が対称で、すべての直線距離が三角不等式に従うということです。 

既存のエントリに対する制限は厳格です。 入力が (d(i,j)=7) である場合、答えのその位置には (7) も含まれている必要があります。 一方、不明なエントリは (0) から (10^9) までの任意の値を取ることができます。 このステートメントでは個別の点間でゼロが許容されるため、これは個別の点が正の距離を持つ必要があるというより厳密な規則ではなく、疑似測定です。 

最大の行列には (500^2=250000) 個のエントリがあり、すべてのテスト ケースにわたる (n) の合計は最大で (500) です。 これにより、(O(n^3)) アルゴリズムが自然なターゲットになります。 (n=500) では、3 次作業は約 (1 億 2,500 万回) の基本反復ですが、(O(n^4)) 以下では不必要にコストが高くなります。 また、(n) の合計が小さいため、多くの大規模なテスト ケースで 3 乗コストが増加することも防止されます。 

単純なフィル戦略が何も言わずに失敗するケースがいくつかあります。 次のような既知の対角値```
2
1 -1
-1 0
```生産しなければならない`NO`なぜなら、最初の点はそれ自体からの距離がゼロである必要があるからです。 非対角エントリのみを処理する不注意なアルゴリズムでは、この矛盾を見落とす可能性があります。 

対称性が直接侵害されることもあります。 例えば、```
2
0 3
4 0
```同じ距離の 2 つの表現が一致しないため、不可能です。 (-1) エントリのみを入力しても、既存の値は変更できないため、この問題は修復されません。 

より微妙な矛盾は、より短い既知の経路から生じます。 考慮する```
3
0 5 2
5 0 2
2 2 0
```点 (1) と (2) の間の直線距離は (5) で固定されますが、ルート (1 \rightarrow 3 \rightarrow 2) の長さは (4) になります。 どのメトリックも (d(1​​,2)\le4) を満たす必要があるため、固定値 (5) ではインスタンスは不可能になります。 この種の大きなパスの場合、入力に明示的に存在する三角形だけをチェックするだけでは十分ではありません。 

最後に、既知の距離のグラフを切断することができます。 例えば、```
3
0 2 -1
2 0 -1
-1 -1 0
```完全に完成可能です。 最初の 2 つの点は 1 つのコンポーネントを形成し、3 番目の点は別のコンポーネントを形成します。 コンポーネント間に十分に大きな距離を選択できます。 すべてのペアが有限の最短経路を持つと仮定する解決策は、このケースを誤って拒否することになります。 

公式コンテストのサンプルには、上記の切断された状況や部分的に指定された状況を含む 4 つのテスト ケースが含まれています。 

## アプローチ

 ブルートフォース手法では、すべての未知の距離を変数として扱い、完全なメトリックが見つかるまで考えられる値を試します。 対称性を利用した後でも、(n=500) のインスタンスは

 [
 \frac{500\cdot499}{2}=124750
 】

 未知の順序のないペア。 出力値は (0) から (10^9) までの任意の整数であるため、網羅的な列挙は次のようになります。 

[
 (10^9+1)^{124750}
 】

 最悪の場合、割り当てられる可能性があります。 各候補をチェックするには、すべての三角形不等式を検証するために少なくとも (O(n^3)) の作業が必要になります。 これは単に遅すぎるだけでなく、計算上実行不可能です。 

ブルートフォースのアイデアには、概念的な正しい出発点が含まれています。つまり、既知の距離はすべて、変更しない必要がある制約と見なすことができます。 重要なのは、欠落しているエントリを独立変数として考えるのをやめることです。 

既知のすべての距離を無向の重み付きエッジとして扱います。 このグラフが構築されると、有効なメトリクスは次の条件を満たす必要があります。 

[
 d(u,v)\le d(u,x_1)+d(x_1,x_2)+\cdots+d(x_k,v)
 】

 (u) と (v) の間のすべてのパスに対して。 したがって、重み (w) の固定エッジは、そのエンドポイント間に合計重みが (w) より小さい既知のパスがない場合にのみ存続できます。 

既知のグラフの最短パス メトリックは、既存の制約によって強制される最も強い距離を正確に示します。 固定エッジが既知の最短パスよりも長い場合、インスタンスは不可能です。 固定エッジが短くならない場合、最短経路の距離自体がすべての接続コンポーネント内で有効な完成となります。 

これはまさにフロイド・ウォーシャルが計算したものです。 既知の距離と欠落エントリの無限大を使用して行列を初期化し、すべてのペアの最短パスを計算します。 その後、既知の距離はすべて、対応する最短経路距離と等しくなる必要があります。 

接続されていないコンポーネントには、最後の詳細が 1 つ必要です。 2 つの異なるコンポーネント間にはパスがないため、フロイド-ウォーシャル後もそれらの距離は無限大のままです。 このような無限大はすべて (10^9) で置き換えることができます。 コンポーネント間で共通の十分に大きな値を 1 つ選択すると、三角不等式が維持され、必要な出力範囲内に収まります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (\Theta((10^9+1)^{\Theta(n^2)})) 候補 | (O(n^2)) | 遅すぎる |
 | 最適 | (O(n^3)) | (O(n^2)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. マトリックスを読み、どのエントリが最初に修正されたかを思い出してください。 入力対角線がすでにゼロである場合にのみ、作業対角線をゼロに設定します。 既知の対角エントリがそれ以外の場合は、メトリックがそれを変更できないため、直ちに拒否します。 
2. すべてのペア (i,j) の対称性をチェックします。 (d(i,j)) と (d(j,i)) の両方が既知の場合、それらは等しい必要があります。 1 つの方向のみがわかっている場合は、その値を作業行列の他の方向にコピーします。 これは、欠落しているエントリにはまだ制限がないため有効ですが、対称性により既知のエントリと等しくなります。 
3. すべての既知の対角から外れた距離を、無向の重み付きエッジとして解釈します。 不足している距離を初期化して、`INF`、 どこ`INF`は、考えられるあらゆる有限の最短経路距離よりもはるかに大きくなります。 
4. フロイド・ウォーシャルを実行します。 すべての中間頂点 (k) について、次を使用してすべてのペア (i,j) から (k) を改善しようとします。 

[
 d(i,j)=\min(d(i,j),d(i,k)+d(k,j))。 
】

 結果の行列には、既知の距離のみを使用した最短パスが含まれます。 

1. 元々固定されていたすべての距離を最短経路行列と照合します。 元の値 (w) が (w) より小さくなった場合、固定エッジは強制パスよりも長くなり、完了は存在できなくなります。 テストケースを拒否します。 
2. 残りすべてを交換します`INF`(10^9) によるエントリ。 これらは、まさに、既知の距離のグラフの異なる連結成分にあるペアです。 すべての有限内部距離が (10^9) よりもはるかに小さいため、共通の値が大きいと、異なるコンポーネントを安全に接続できます。 
3. 結果の行列を出力します。 Floyd-Warshall によって生成されるすべての有限エントリは最短経路距離ですが、すべてのコンポーネント間のエントリは共通の大きな値です。 対角線はゼロのままです。 

**なぜ機能するのか** 中心となる不変条件は、フロイド・ウォーシャル以降、すべての有限値 (d(i,j)) が、完全に元々既知の距離から形成されたパスの最小長であるということです。 有効な補完はすべてのパスに沿って三角不等式を満たさなければならないため、(d(i,j)) がその最短パスの値以下でなければなりません。 同時に、元々固定されていたエッジが正確にその最短パス値を持っている場合、その値を維持することは既知のすべてのパスと互換性があります。 したがって、すべての既知のパスよりも小さい固定値は安全ですが、一部の既知のパスよりも大きい固定値は不可能です。 すべての固定エントリがこのテストに耐えられると、最短パス距離は構造的に三角不等式を満たします。 異なる連結成分間には制約がなく、すべての内部有限距離が (10^9) 未満であるため、すべての成分間ペアに (10^9) を割り当てると有効な三角形不等式が作成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = 10**15
BIG = 10**9

def solve_case(a):
    n = len(a)

    # Build a symmetric working matrix.
    dist = [[INF] * n for _ in range(n)]
    fixed = []

    for i in range(n):
        if a[i][i] != -1 and a[i][i] != 0:
            return None

        dist[i][i] = 0

    for i in range(n):
        for j in range(i + 1, n):
            x = a[i][j]
            y = a[j][i]

            if x != -1 and y != -1:
                if x != y:
                    return None
                w = x
                fixed.append((i, j, w))
                dist[i][j] = w
                dist[j][i] = w
            elif x != -1:
                fixed.append((i, j, x))
                dist[i][j] = x
                dist[j][i] = x
            elif y != -1:
                fixed.append((i, j, y))
                dist[i][j] = y
                dist[j][i] = y

    # Floyd-Warshall.
    rng = range(n)
    for k in rng:
        dk = dist[k]
        for i in rng:
            di = dist[i]
            dik = di[k]
            if dik == INF:
                continue

            for j in rng:
                nd = dik + dk[j]
                if nd < di[j]:
                    di[j] = nd

    # Every fixed edge must still have exactly its original value.
    for u, v, w in fixed:
        if dist[u][v] != w:
            return None

    # Connect different components with one sufficiently large value.
    for i in rng:
        di = dist[i]
        for j in rng:
            if di[j] == INF:
                di[j] = BIG

    return dist

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        a = [list(map(int, input().split())) for _ in range(n)]

        ans = solve_case(a)

        if ans is None:
            out.append("NO")
            continue

        out.append("YES")
        for row in ans:
            out.append(" ".join(map(str, row)))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```最初の構築フェーズでは、元のマトリックスを作業用マトリックスから意図的に分離します。 の`fixed`list は既知の順序付けされていないペアをすべて記録するため、後で変更を許可されたエッジと変更しないことが必要なエッジを区別できます。 

対称性チェックは、Floyd-Warshall の前に実行されます。 ペアの一方の側だけがわかっている場合、それをもう一方の側にコピーしても、固定値は変更されません。 これは、対称性によって強制される欠損値を単に代入しているだけです。 両方の側面が存在し、相違がある場合、考えられる答えはありません。 

グラフに自己ループを入れる理由がないため、対角線は特別な処理を受けます。 既知のゼロはすべてのメトリックと一致しますが、他の既知の対角値はインスタンスを即座に不可能にします。`INF`出力制限よりも意図的に大幅に大きくなっています。 最大 500 個の頂点を含む連結コンポーネントには、最大 499 個のエッジを持つ単純なパスがあり、元の各エッジは最大 1000 個であるため、有限の最短パスは最大 (499000) になります。 選ばれたもの`INF`したがって、正当な距離では安全に到達できません。 Python の整数にも任意の精度があるため、オーバーフローの問題はありません。 

フロイド-ウォーシャル ループは、次の場合に行をスキップします。`dist[i][k]`は無限です。 これは、計算中に多くのペアが到達不能なままになる可能性がある、切断されたグラフの場合に重要です。 ローカル変数`dk`そして`di`また、2 次元リストのインデックス作成を繰り返すことも避けてください。 

Floyd-Warshall の後は、入力の既知のエントリのみをチェックするだけで十分です。 不明なエントリは最短パス値を取ることが許可されているため、追加の制限は課されません。 固定エッジが縮小されている場合、その縮小は、必要な三角形不等式に違反する既知のパスを表します。 

最後に、到達不可能なペアがすべて割り当てられます。`BIG`。 値は正確に (10^9) であり、出力境界によって許可されます。 これは、元の制約から生成されるすべての可能な有限距離よりも大きいため、コンポーネント間の距離によって、固定内部距離を変更するような新しい短いルートを導入することはできません。

    dist = [[INF] * n for _ in range(n)]
    fixed = []

    for i in range(n):
        if a[i][i] != -1 and a[i][i] != 0:
            return None
        dist[i][i] = 0

    for i in range(n):
        for j in range(i + 1, n):
            x = a[i][j]
            y = a[j][i]

            if x != -1 and y != -1:
                if x != y:
                    return None
                fixed.append((i, j, x))
                dist[i][j] = x
                dist[j][i] = x
            elif x != -1:
                fixed.append((i, j, x))
                dist[i][j] = x
                dist[j][i] = x
            elif y != -1:
                fixed.append((i, j, y))
                dist[i][j] = y
                dist[j][i] = y

    for k in range(n):

            return None

        for j in range(n):

                dist[i][j] = BIG

 ## 特殊なケース

 ゼロ以外の固定対角線は、グラフ処理の前に拒否されます。 入力用```
1
2
1 -1
-1 0
```最初の斜めのエントリは`1`、 それで`solve_case`すぐに戻ります`None`。 出力は`NO`。 対角線は直接計量公理であるため、最短経路計算ではこれを有効にすることはできません。 

非対称ペアはフロイド-ウォーシャルの前に処理されます。 と```
1
2
0 3
4 0
```ペア ((1,2)) には 2 つの固定値があります。`3`そして`4`。 建設が検出する`x != y`そしてその訴訟を拒否します。 一方の側をもう一方の側で上書きすることも魅力的ですが、それは固定入力値を変更できないという要件に違反します。 

短経路の矛盾は、全ペアの最短経路フェーズによって検出されます。 のために```
1
3
0 5 2
5 0 2
2 2 0
```最初のエッジ (1\leftrightarrow2) には重みがあります`5`。 頂点 (3) が中間頂点とみなされると、Floyd-Warshall は次のようになります。 

[
 d(1,2)=\min(5,2+2)=4。 
】

 元の固定値は`5`したがって、最終的な検証は失敗し、答えは次のようになります。`NO`。 同じ引数が多くのエッジを含むパスにも機能するため、直接目に見える三角形だけをチェックするだけでは不十分です。 

部分的に指定された対称ペアが既知の側から埋められます。 で```
1
3
0 3 -1
-1 0 4
-1 -1 0
```エントリ (d(1​​,2)) と (d(2,1)) は次のようになります。`3`, 一方、(d(2,3)) と (d(3,2)) は次のようになります。`4`。 残りのペアは次のように選択できます。`7`、これは頂点 (2) を通る最短パスの値です。 アルゴリズムはフロイド-ウォーシャルを通じてこれを自然に発見します。 

切断されたコンポーネントは、最短パスが計算された後に完成します。 のために```
1
3
0 2 -1
2 0 -1
-1 -1 0
```頂点 (1) と (2) には距離があります`2`、一方、頂点 (3) にはそれらとの既知の関係がありません。 Floyd-Warshall はコンポーネント間のエントリを次の場所に残します。`INF`、最後のフェーズでは、これらのエントリが (10^9) に変更されます。 結果の行列は次のようになります。```
0 2 1000000000
2 0 1000000000
1000000000 1000000000 0
```2 つのコンポーネント間距離を含むすべての三角形は有効であり、内部距離は`2`は (10^9+10^9) よりもはるかに小さいです。 

最後に、この問題の定義では、すべての非対角エントリがゼロに等しい入力が有効です。 例えば、```
1
3
0 0 0
0 0 0
0 0 0
```変わらずに通過します。 この実装では、問題で使用される実際の条件に一致する、個別の頂点に対する正の要件が挿入されることはありません。
