 ## 解決策
 ## 問題の理解

 ノード 1 をルートとするツリーが与えられており、すべてのエッジに重みがあります。 各ノードについて、ノード 1 からそのノードまでの一意のパスに沿ったエッジの重みを合計することで、ルートからの距離を計算できます。 この距離はモジュロで減算されます$10^5$。 

この前処理の後、任意の 2 つのノードの選択を検討します。$u$そして$v$。 各ペアについて、2 つのルート距離を取得し、それらのビットごとの XOR を計算し、結果を記録します。 タスクは、この方法で生成できる個別の XOR 値の数を決定し、それらすべてをソートされた順序で出力することです。 

したがって、ルートからの距離が判明すると、問題の構造は実際にはツリーに関するものではなくなります。 ツリーは、各値が範囲内にある値のマルチセットをノードごとに 1 つ生成するためにのみ存在します。$[0, 99999]$。 答えは、これらの値のすべてのペアごとの XOR (次のペアを含む) にのみ依存します。$u = v$、常に 0 を寄与します。 

制約$N \le 10^5$これは、すべてのペアを明示的に考慮できないことを意味します。$O(N^2)$、実現可能な限界をはるかに超えています。 すべてのペアごとの結果を保存することさえ一般に不可能です。 ただし、値は固定された小さな範囲に厳密に制限されているため、周波数ベースまたはビットごとの変換アプローチが強く示唆されます。 

微妙なエッジ ケースは、複数のノードが同じルート距離を共有する場合です。 たとえば、2 つのノードの距離値が同じである場合、$x$、次にそれらを選択すると、$x \oplus x = 0$、これは、最終的な個別セットで 1 回だけカウントされる必要があります。 もう 1 つのエッジ ケースは、ノード ペアが順序付けされているか順序付けされていないと仮定してはいけないということです。 XOR は対称であるため、どちらの解釈でも同じ結果が得られます。 

## アプローチ

 素朴なアプローチは、ツリーの DFS または BFS トラバーサルを使用して、すべてのノードのルート距離を計算することから始まります。 配列を取得したら$a$サイズの$N$、ここでそれぞれ$a[i]$ルート距離のモジュロです$10^5$、すべてのペアを反復処理します$(i, j)$そして計算する$a[i] \oplus a[j]$、結果をセットに挿入します。 これは問題の定義に直接従うため、正しいです。 

ボトルネックは二重ループです$N$ノード。 これにより、$O(N^2)$ペアの評価、これは約$10^{10}$最悪の場合、操作は 1 秒では大きすぎます。 

重要な観察は、どのノードが結果を生成するかは気にせず、結果が存在するかどうかだけを気にするということです。 これは、私たちが集合畳み込み問題を扱っていることを意味します: の値に対する周波数配列が与えられた場合$[0, 2^{17})$、このセットの 2 つの要素のすべての XOR 組み合わせが必要です。 

これはまさに、ブール値または周波数配列に対する XOR 畳み込みです。 正しいツールは高速ウォルシュ アダマール変換 (FWHT) で、XOR 畳み込みを計算します。$O(M \log M)$、 どこ$M$値範囲を超える 2 の次のべき乗です。 ここ$M = 131072$これは簡単に十分に高速です。 

周波数配列を構築します$f[x]$、値が$x$根の距離の間に現れます。 次に、XOR 畳み込みを計算します。$g = f * f$、 どこ$g[z]$ペアが存在するかどうかを教えてくれる$(x, y)$そのような$x \oplus y = z$。 最終的な答えは単純にすべてのインデックスです$z$どこ$g[z]$ゼロ以外です。

 ## アルゴリズムのチュートリアル

 ### 1. 根の距離を計算する

 ノード 1 から開始してツリーを走査し、エッジの重みを累積することによってすべてのノードまでの距離を計算します。 各距離を計算した後、それを剰余で減らします$10^5$なぜなら、問題はその縮小された形式で値を明示的に定義しているからです。 

このステップでは、ツリー構造を値の単純な配列に変換します。これが XOR プロセスに関連する唯一の情報です。 

### 2. 周波数配列を構築する

 配列を割り当てます$f$サイズの$2^{17}$(値が未満であるため、$10^5$)、マークを付けます$f[a[i]] = 1$すべてのノード値に対して。 

有効なペアを形成するには単一の出現でも十分であるため、多重度ではなく存在のみを考慮します。 

### 3. 高速ウォルシュ アダマール変換を適用する

 周波数配列を FWHT ドメインに変換します。 次に、それを点ごとに 2 乗し、元の領域の XOR 畳み込みに対応し、最後に逆変換を適用します。 

このプロセスを経て、各インデックスは$z$結果の配列には、XOR が等しい値のペアが少なくとも 1 つ存在するかどうかがわかります。$z$。 

### 4. 結果を収集する

 考えられるすべての値を反復処理し、畳み込み結果が正となるインデックスを収集します。 これらのインデックスは、問題で必要とされる個別の XOR 結果です。 

### なぜ効果があるのか

 このアルゴリズムは、インジケーター配列に対する XOR 畳み込みが、セット内の要素の可能なペアごとの XOR の組み合わせをすべてカウントするという事実に基づいています。 各ルート距離は一度計算されると独立しているため、前処理後はツリー構造は問題になりません。 FWHT は、ペアごとの XOR の存在に必要な情報を正確に保存し、偽の値は導入されません。 到達可能なすべての XOR は実際のノードのペアに対応し、ノードのすべてのペアは正確に 1 つの XOR 値を提供するため、正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def fwht_xor(a, invert=False):
    n = len(a)
    step = 1
    while step < n:
        jump = step * 2
        for i in range(0, n, jump):
            for j in range(step):
                u = a[i + j]
                v = a[i + j + step]
                a[i + j] = u + v
                a[i + j + step] = u - v
        step = jump

    if invert:
        for i in range(n):
            a[i] //= n

def solve():
    n = int(input())
    g = [[] for _ in range(n + 1)]

    for _ in range(n - 1):
        u, v, w = map(int, input().split())
        g[u].append((v, w))
        g[v].append((u, w))

    sys.setrecursionlimit(10**7)

    dist = [0] * (n + 1)
    stack = [1]
    parent = [-1] * (n + 1)

    while stack:
        u = stack.pop()
        for v, w in g[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            dist[v] = (dist[u] + w) % 100000
            stack.append(v)

    M = 1
    while M < 131072:
        M <<= 1

    f = [0] * M
    for i in range(1, n + 1):
        f[dist[i]] = 1

    fwht_xor(f, invert=False)

    for i in range(M):
        f[i] *= f[i]

    fwht_xor(f, invert=True)

    res = [i for i in range(M) if f[i] > 0]
    print(len(res))
    print(*res)

if __name__ == "__main__":
    solve()
```DFS は、チェーン形状のツリーでの再帰の深さの問題を回避するために反復的に実装されます。 モジュロ演算はトラバース中に適用されるため、距離はすぐに境界内に留まります。 

FWHT セクションは、標準の XOR 変換を実行し、変換された配列を 2 乗してペアごとの組み合わせを計算し、逆変換を適用します。 変換ドメインでの二乗は、$O(N^2)$ペアの列挙。 

最後に、すべてのインデックスを正のカウントでフィルター処理して、個別の XOR 値を生成します。 

## 実用的な例

 ### トレースの例

 根の距離を法とする小さな概念的な入力を考えてみましょう。$10^5$は：$$a = [1, 2, 3]$$私たちは頻度を高めます:

 | 値 | f |
 | --- | --- |
 | 1 | 1 |
 | 2 | 1 |
 | 3 | 1 |

 XOR 畳み込み後のすべてのペアごとの結果は次のようになります。 

| ペア | XOR |
 | --- | --- |
 | (1,1) | 0 |
 | (1,2) | 3 |
 | (1,3) | 2 |
 | (2,2) | 0 |
 | (2,3) | 1 |
 | (3,3) | 0 |

 したがって、出力セットは次のようになります。$$\{0, 1, 2, 3\}$$これにより、セルフペアが正しく 0 を生成し、すべての組み合わせが結果セットに 1 回だけ含まれることが確認されます。 

### 重複のある例

 しましょう:$$a = [5, 5, 7]$$| ペア | XOR |
 | --- | --- |
 | (5,5) | 0 |

 特徴的な結果は次のとおりです。$$\{0, 2\}$$これは、存在することだけが重要であるため、重複は正確さに影響を与えないことを示しています。

 ## 特殊なケース

 チェーン形状のツリーは、再帰の深さと累積的な重みの伝播の両方に重点を置くため、最も重要な構造的なエッジ ケースです。 反復 DFS はスタック オーバーフローを回避しながら、距離を順番に正しく累積します。 

2 番目のエッジ ケースは、すべてのノードのルート距離が同一である場合で、単一の XOR 結果 0 のみが生成されます。周波数配列は重複を 1 つの存在に正しく縮小し、畳み込みでは非ゼロとしてインデックス 0 のみが生成されます。 

3 番目のケースは、値がモジュロ範囲全体に広がっている場合です。これは、FWHT 配列が、切り捨てられることなく可能なすべての XOR 出力を含めるのに十分な大きさであることをテストします。
