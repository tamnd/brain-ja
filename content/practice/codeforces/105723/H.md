 ## アルゴリズムのチュートリアル

 私たちは計算します$f(m)$それぞれ独立して$m$パリティ構造と効果的なリダクション動作を使用します。

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n, k = map(int, input().split())

        if k == n:
            out.append(" ".join(["-1"] * n))
            continue

        res = []

        for m in range(1, n + 1):
            ones = m

            if k % 2 == 0:
                if ones % 2 == 1:
                    res.append("-1")
                    continue

            if ones == 0:
                res.append("0")
                continue

            steps = (ones + k - 1) // k
            res.append(str(steps))

        out.append(" ".join(res))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```コードは最初に縮退ケースを処理します$k=n$、オールゼロに向けた進歩は不可能です。 それからそれぞれについて$m$、次の場合にパリティ チェックを適用します。$k$は偶数です。その体制では偶数の 1 のみに到達できるからです。 最後に、次の上限除算として演算数を計算します。$k$、各操作で効果的に最大の除去ができるという考えを反映しています。$k$最適な構成のもの。 The order of evaluation ensures that impossible cases are filtered before attempting the arithmetic reduction.
