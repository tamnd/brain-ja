 ## アルゴリズムのチュートリアル

 条件を各素因数の独立した制約に変えることで進めます。`a1`、それらを乗算的に組み合わせます。 

1.因数分解`a1`その主力に。 素数ごとに`p`、その指数を記録します`e`。 gcd 制約と lcm 制約は素数レベルでのみきれいに分解されるため、この手順が必要です。 
2. 各素数パワーについて`p^e`、全体にわたる有効な指数割り当ての数を計算します。`n-1`包含/除外を使用して位置を決定します。 各ポジションは次から任意の指数を選択できます。`0`に`e`、与える`(e+1)^(n-1)`制限前の合計割り当て数。 
3. 指数を使用しない減算代入`0`、からの選択に対応します。`[1, e]`貢献するだけ`e^(n-1)`。 
4. 指数を使用しない減算代入`e`、また貢献します`e^(n-1)`。 
5. 両極端を回避する代入を追加し直します。つまり、すべての指数が次のようになります。`[1, e-1]`、貢献`(e-1)^(n-1)`。 
6. 998244353 を法とするすべての素数の結果を乗算します。 

この独立性は、gcd 制約と lcm 制約が相互作用なしに素数間で分割されるため、各素数が別個の組み合わせ軸のように動作するという事実から来ています。 

### なぜ効果があるのか

 gcd と lcm は素数ごとの最小指数と最大指数を個別に取得することによって計算されるため、各素因数はシーケンス全体で独立して進化します。 gcd と lcm の両方が同じ値に等しいという要件により、各素数はシーケンス内のどこかで最小指数と最大指数の両方の制約を達成する必要があります。 これにより、問題は、禁止された構成を持つ位置から指数レベルまでのカウント関数に変わり、包含と排他はそれらの禁止されたケースを正確に特徴付けます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def mod_pow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def factorize(x):
    f = {}
    p = 2
    while p * p <= x:
        while x % p == 0:
            f[p] = f.get(p, 0) + 1
            x //= p
        p += 1
    if x > 1:
        f[x] = f.get(x, 0) + 1
    return f

def solve():
    t = int(input())
    for _ in range(t):
        a1, n = map(int, input().split())

        factors = factorize(a1)
        ans = 1
        m = n - 1

        for p, e in factors.items():
            total = mod_pow(e + 1, m)
            no_zero = mod_pow(e, m)
            no_e = mod_pow(e, m)
            no_both = mod_pow(e - 1, m) if e > 1 else 0

            ways = (total - no_zero - no_e + no_both) % MOD
            ans = ans * ways % MOD

        print(ans)

if __name__ == "__main__":
    solve()

各素数に対して、コードは導出されたとおりに包含/除外を正確に適用します。割り当ての合計から、どちらかの境界条件が欠けているものを差し引いたものを、重複する場合を追加し直すことで修正します。 素数間の乗算は、指数の選択の独立性をエンコードします。
