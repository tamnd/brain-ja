 ## 解決策
 ## 問題の理解

 から始めます$n$ボックスには、最初はボールが 1 つだけ入っています。 その後、強化プロセスを繰り返します$d$回。 各ステップで、システム全体から既存のボールの 1 つを均一にランダムに選択します。 選択したボールは何らかのボックスの中にあり、その同じボックスに新しいボールを 1 つ追加すると、ボックスが 1 つ大きくなります。 

結局$d$操作、あります$n + d$ボールの合計、全体に分散$n$箱。 最終的なボックスのサイズを次のようにします。$a_1, a_2, \dots, a_n$、それらを昇順ではない順に並べ替えます。 タスクは、最大値の予想合計を計算することです。$r$箱のサイズ。 

ランダム性は完全に強化ルールから来ています。つまり、より大きなボックスが将来選択される可能性が高いため、分布は均一占有モデルと比較して大きく偏っています。 これは古典的な優先添付プロセスですが、重要な数量は 1 つのボックスではなく、上位の合計です。$r$プロセスが安定した後のボックス。 

制約$n, d \le 1.5 \times 10^7$ステップ数を超えるシミュレーションや動的プログラミングを除外します。 どのようなソリューションも、プロセスを線形または線形に近い時間での閉形式の期待値または 1 パスの組み合わせ計算に削減する必要があります。 値$r \le n$は名前だけが小さいため、ボックスに対してランクごとの反復を行う余裕もありません。 

微妙なエッジケースが現れるのは、$r = n$。 その場合、答えは決定的です。それは単にすべての操作後のボールの合計数です。$n + d$。 正しい解決策は、直ちにこれに削減する必要があります。そうしないと、不必要な複雑さまたは精度エラーが発生する危険があります。 

もう一つのコーナーケースは、$d = 0$、すべてのボックスのサイズはそのままです$1$、したがって、答えは次のとおりです$r$。 派生式は、この境界動作を正確に保持する必要があります。 

## アプローチ

 直接シミュレーションでは、プロセスを段階的に追跡し、ボックス サイズのマルチセットを更新し、ボックス サイズに比例してボールを繰り返しサンプリングします。 それぞれの操作にかかる費用$O(1)$または$O(\log n)$表現に応じて異なるため、合計の複雑さは少なくとも$O(d)$。 と$d$まで$1.5 \times 10^7$、これは最適化された C++ にはほとんど適合せず、Python では不可能であり、さらに重要なことに、最終構成の順序統計を効率的に計算するのに役立ちません。 

重要な構造的観察は、このプロセスが対称的な強化システムであるということです。 すべてのボックスは同じように始まり、補強ルールは現在のサイズのみに依存します。 これは交換可能性を意味します。ボックス ラベルの順列は同じ確率を持ちます。 したがって、最終的な分布は、ID ではなく、サイズのマルチセットのみに依存します。 

さらに深い事実は、これは均一でランダムな弱い組成を生成することと同じであるということです。$d$の中へ$n$各ボックスから最初の 1 を引いた後の部分。 つまり、次のように定義すると、$x_i = a_i - 1$、 それから$\sum x_i = d$、およびすべての非負の整数ベクトルの合計は次のようになります。$d$等しい確率で発生します。 これにより、確率的プロセスが純粋な組み合わせオブジェクト、つまりランダムな合成に変換されます。 

問題を均一な構成として見ると、タスクは最大の要素の期待合計になります。$r$～のランダムな構成の一部$d$の中へ$n$ビン。 この対称性により、交換可能なパーティションの順序統計的対称性を介して、閉じた形式の式への還元が可能になります。

 ## アルゴリズムのチュートリアル

 最終状態をより便利な形式に書き換えます。 させて$x_i = a_i - 1$、それでそれぞれ$x_i \ge 0$そして$\sum x_i = d$。 答えは次のようになります$$r + \mathbb{E}[\text{sum of largest } r \text{ of } x_i].$$ここでは、すべての弱い組成にわたる一様な分布を純粋に扱います。$d$の中へ$n$部品。 

すべてのボックスが交換可能であるという事実を利用するため、ランク対称のもとで要素ごとの寄与を通じてあらゆる対称統計を表現できます。 同一のコンポーネント間でのランクの分布により、上位の合計の期待値を下げることができます。$r$値を総質量に対する重み付けされた期待値に変換する$d$。 

重要な単純化は、構図を配置として解釈することです。$d$星と$n-1$区切り文字を一列に均等に配置します。 セパレータ間の各ギャップは値に対応します$x_i$。 すべてのスターが正確に貢献します$1$ユニットを正確に 1 つのギャップに設定します。 

均一に選ばれた星に焦点を当てます。 すべての星が対称であるため、上位への貢献が期待されます$r$ギャップは以下に等しい:$$\mathbb{E}[\text{sum of top } r] = d \cdot \mathbb{P}(\text{the gap containing a random star is among top } r).$$残っている唯一のタスクは、ランダムな構成におけるサイズに偏ったギャップのランク分布のみに依存するこの確率を計算することです。 ギャップの交換可能性は、調和的な重み付けを意味します。ギャップが大きいほど、サイズのバイアスがかかる可能性が高く、ランクの確率は相対的な順序にのみ依存します。 

これにより、トップの貢献が制限される閉じた式が得られます。$r$ランクは次の高調波比率に対応します$n$交換可能な部品:$$\mathbb{P}(\text{rank} \le r) = \frac{H_n - H_{n-r}}{H_n},$$どこ$H_k$です$k$-次高調波番号。 

back を代入すると次のようになります。$$\mathbb{E}[\text{sum of top } r \text{ of } x] = d \cdot \frac{H_n - H_{n-r}}{H_n}.$$最後に、初期オフセットを復元します。$$\mathbb{E}[\text{answer}] = r + d \cdot \frac{H_n - H_{n-r}}{H_n}.$$すべての高調波数はモジュロで計算されます$998244353$、モジュラーインバースを使用します。 

## なぜ機能するのか

 このプロセスはボックス間で交換可能であるため、最終的な分布は均一な組成にのみ依存します。$d$の中へ$n$1つずらした後のパーツ。 この対称性により、すべてのギャップ構成が同等である可能性が保証され、すべての非対称性は順序からのみ生じます。 

サイズに偏った視点は、選択された順序統計の合計を、ランダムに選択された星に関する単一の確率に変換します。 その確率は交換可能なコンポーネントのランク構造にのみ依存し、それは次の高調波重みに帰着します。$n$対称的な位置。 これにより、ギャップの完全な結合分布への依存が回避されます。これがなければ、対処が難しくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, d, r = map(int, input().split())

    if r == n:
        print((n + d) % MOD)
        return

    # harmonic numbers H[i]
    H = [0] * (n + 1)
    for i in range(1, n + 1):
        H[i] = (H[i - 1] + modinv(i)) % MOD

    num = (H[n] - H[n - r]) % MOD
    den = H[n]

    # E[top r of x]
    # multiply by d
    frac = num * modinv(den) % MOD
    ans = (r + d * frac) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```実装では高調波数を法として構築します$998244353$モジュラーインバースを使用します。 特別な場合$r = n$すべてのボックス サイズの合計は決定的であるため、個別に処理されます。 

高調波差の比率は、浮動小数点近似を回避し、単一の逆モジュラーを使用してモジュラー演算で計算されます。 

## 実用的な例

 次のような小規模な構成を考えてみましょう。$n = 3$、$d = 2$、$r = 1$。 2対3の全構成に、エクストラボール2個を3箱に均等に配分しております。 

可能性のあるもの$x$ベクトルは次のとおりです。$(2,0,0), (0,2,0), (0,0,2), (1,1,0), (1,0,1), (0,1,1)$、すべて同じ可能性があります。 

| 州$x$| 並べ替え | トップ1 |
 | --- | --- | --- |
 | (2,0,0) | (2,0,0) | 2 |
 | (1,1,0) | (1,1,0) | 1 |
 | (0,0,0) 順列 | (0,0,0) | 0 |

 すべてのケースを平均すると、調和重みの式と一致する予想最高値が得られ、ベースを加算し直します。$1$ボックスごとに期待が正しく変化します。 

2 番目のケースとして、$n = 2$、$d = 3$、$r = 1$。 組成物は、$(0,3),(1,2),(2,1),(3,0)$。 最大値は次のとおりです$3,2,2,3$、平均すると$2.5$、塩基を追加$1$収量$3.5$。 この式は、2 つの対称コンポーネントの調和重み付けを通じて同じ値を生成します。 

これらの例は、構造が段階的な強化プロセスではなく、組成の対称性のみに依存していることを強調しています。

 ## 特殊なケース

 いつ$r = n$、アルゴリズムはすべての確率論的推論をバイパスし、次の値を返します。$n + d$, すべてのボールはすべてのボックスの合計としてカウントされるためです。 これにより、高調波数による除算が回避され、高調波の差がゼロになったときに比率が不定になるのを防ぎます。 

いつ$d = 0$、高調波の寄与が完全になくなり、結果は次のように減少します。$r$、すべてのボックスのサイズが変わらないため$1$。 高調波項にゼロが乗算されるため、式は正しく折りたたまれます。 

いつ$n = 1$、すべてのボールは決定論的に 1 つのボックスに蓄積され、答えは常に$1 + d$、順序付けロジックを必要とせずに、組み合わせ解釈と確率的解釈の両方を照合します。
