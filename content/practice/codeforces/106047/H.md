 ## 解決策
 ## 問題の理解

 各エッジが 60 ビットの重みを持つ無向グラフが与えられます。 2 つの頂点間のパスは、重みの合計や最小化によって評価されるのではなく、そのパスに沿ったすべてのエッジの重みのビット単位の AND をとることによって評価されます。 これは、パス値のすべてのビットが、パス上のすべてのエッジにそのビットが設定されている場合にのみ存続することを意味します。 

頂点のクエリペアごとに、それらの間にビット単位の AND 値が指定されたしきい値以上であるパスが存在するかどうかを判断する必要があります。$V$。 ここでは「少なくとも」が重要です。なぜなら、最終的な AND 結果をビットごとに個別に比較するのではなく、整数として比較するからです。 

重要な構造的制約は次のとおりです。$n$そして$q$どちらも到達できる$10^5$、到達できるエッジの数は$5 \times 10^5$。 クエリごとにパスを探索しようとしたり、クエリごとに最短パスのような検索を実行したりするアプローチは、どれも遅すぎます。 クエリごとに 1 つの BFS であっても、$O(q(m+n))$、それは完全に不可能です。 ソリューションでは、各クエリがほぼ一定時間で応答されるようにグラフを前処理する必要があります。 

2 つの頂点間にエッジが存在するが、AND 制約の下で有効なパスが存在しない場合、微妙な失敗のケースが発生します。 たとえば、次の場合$V = 6$そして私たちにはエッジがある$1-2$ウェイト7と$2-3$重みが 1 の場合でも、$1$に接続されています$3$基礎となるグラフのパス$1 \to 2 \to 3$AND値がある$7 \& 1 = 1$、以下にあります$V$ですので、正解は「いいえ」です。 

もう 1 つのエッジケースは次のような場合です$V = 0$。 この場合、AND の結果は常に少なくとも 0 であるため、すべてのパスが条件を自明に満たします。したがって、答えはグラフ全体の標準接続に帰着します。 

## アプローチ

 ブルートフォースの考え方は、各クエリを個別に処理することです。 お問い合わせの場合$(u, v)$、からの任意のパスを見つけようとします$u$に$v$そして、そのパスに沿ったエッジのビットごとの AND を計算します。 現在の AND 値を追跡する単純な DFS または BFS は、考えられるすべてのパスに分岐します。 最悪の場合、グラフ内の単純なパスの数は指数関数的となり、BFS 状態に限定しても、次の形式のペアを追跡する必要があります。$(node, current\_and)$、状態空間の爆発につながります。 これはすぐに不可能になります$q = 10^5$。 

重要な洞察は、ビットごとの AND がパスに沿ってどのように動作するかを理解することで得られます。 いずれかのエッジでビットが 0 になると、その後のエッジでビットが戻ることはありません。 これは、最後の AND が少なくとも$V$に設定されているすべてのビット$V$パスのすべてのエッジを生き残らなければなりません。 パスに沿った 1 つのエッジでも必要なビットが欠けている場合、そのビットは永久に失われます。 

これにより、問題はパス最適化問題からエッジ上の単純なフィルタリング問題に変わります。 互換性のあるエッジのみを考慮します。$V$、重みに設定されたすべてのビットが含まれるエッジを意味します。$V$。 互換性のないエッジをすべて破棄すると、残りのグラフ内のパスは自動的に少なくとも AND 値を持ちます。$V$なぜなら、すべてのエッジが必要なビットをすべて保持しているからです。 

したがって、各クエリは、フィルタリングされたグラフでの純粋な接続チェックに還元されます。 これは、一度構築した素のセット共用体構造を使用して効率的に処理できます。

 ## アルゴリズムのチュートリアル

 ### ## アルゴリズムのチュートリアル

 1. すべてのエッジを読み取り、次のことを確認して各エッジが使用可能かどうかを判断します。$(w_i \& V) = V$。 

この条件により、必要なすべてのビットが保証されます。$V$エッジの重みに存在します。 
2. 各頂点が独自のコンポーネントで始まる、素の集合共用体構造を初期化します。 
3. 条件を満たすすべてのエッジについて、そのエンドポイントを DSU にマージします。 

これにより、有効なエッジのみを使用して接続されたコンポーネントが構築されます。 
4. 各クエリについて$(u, v)$、どうかを確認してください$u$そして$v$同じ DSU コンポーネントに属します。 

ある場合は「はい」を出力し、そうでない場合は「いいえ」を出力します。 

### なぜ効果があるのか

 以下を満たすエッジから完全に形成されたパスを考慮します。$(w \& V) = V$。 設定されているすべてのビットに対して$V$、パスに沿ったすべてのエッジにそのビットが設定されているため、ビットは AND 演算全体にわたって存続します。 したがって、パス値には常に次のすべてのビットが含まれます。$V$、少なくともそうであることを意味します$V$。 

逆に、パスが条件に違反するエッジを 1 つでも使用している場合、少なくとも 1 つの必要なビットが永久に削除され、AND 結果が得られなくなります。$V$。 したがって、すべての有効なパスはフィルタリングされたグラフ内に完全に存在する必要があり、そのグラフ内の接続性が正確に答えを特徴付けます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n + 1))
        self.size = [1] * (n + 1)

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]

def main():
    n, m, q, V = map(int, input().split())
    dsu = DSU(n)

    for _ in range(m):
        u, v, w = map(int, input().split())
        if (w & V) == V:
            dsu.union(u, v)

    out = []
    for _ in range(q):
        u, v = map(int, input().split())
        out.append("Yes" if dsu.find(u) == dsu.find(v) else "No")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```DSU 構造は、エッジをフィルタリングした後に接続情報を圧縮するためにのみ使用されます。 パス圧縮により、操作ごとにほぼ一定の償却時間が保証されます。これは、$10^5$クエリ。 

重要な実装の詳細はエッジ フィルター条件です`(w & V) == V`。 これは検査よりも厳しいです`w >= V`これは、数値の順序付けではビットの包含が保持されないため、正しくありません。 ビット単位の包含のみが AND での安定性を保証します。

 ## 特殊なケース

 いつ$V = 0$、条件$(w \& V) = V$両辺がゼロであるため、すべてのエッジに対して常に true になります。 したがって、DSU は完全なグラフに従ってマージされ、すべてのクエリは標準接続に縮小されます。これは、AND の結果が常に少なくとも 0 であるという事実と正確に一致します。 

グラフが本来の意味で接続されているが、フィルターの下に有効なエッジが存在しない場合、すべてのノードが孤立します。 のような入力の場合$V = 63$すべてのエッジがランダムな低ビットを持つ場合、DSU は頂点をマージすることはありません。そのため、元のグラフ内の直接接続されたノード間のクエリでも「いいえ」が返され、有効なパス内のすべてのエッジがビット制約を満たさなければならないという要件と一致します。 

複数のエッジが同じノードのペアに接続している場合、それらは独立して処理されます。 少なくとも 1 つが条件を満たす場合、DSU はそれらをマージしますが、ユニオン演算の冪等性により、重複したマージは正確さに影響しません。
