 ## 問題の理解

 それぞれに高さを持った一連の柱が与えられています。 カエルはある柱からスタートし、右側にある別の柱に到達しようとしますが、前方にしかジャンプできず、各ジャンプでスキップできるのはせいぜいです。`k`ポジション。 

インデックスの任意の間隔に対して`[l, r]`、カエルは、で始まるすべての有効なパスを考慮します。`l`、で終了`r`、最大でも長さのジャンプで前方にのみ移動します`k`。 このような各パスに沿って、訪問したすべての柱の最小高さを調べます。カエルはこの最小値を最大化したいと考えます。 その値は次のように表されます`f(l, r)`。 

タスクは次の合計を計算することです`f(l, r)`すべてのペアにわたって`l ≤ r`。 

この制約により、最大 200,000 のピラーが許可されるため、すべてのペアを検査するソリューションは即座に除外されます。`(l, r)`明示的に。 素朴なアプローチでは、すでに O(n²) ペアが必要であり、さらにそれぞれのペアを計算する必要があります。`f(l, r)`別々にすると最悪の場合立方体になってしまいます。 それは実現可能な限界をはるかに超えています。 

隠れた難しさは、`f(l, r)`は単なるエンドポイントの機能ではありません。 それは最適な制約付きパス構造に依存するため、グローバルな構造再定式化が見つからない限り、直接間隔 DP のコストが高くなります。 

微妙なエッジケースが現れるのは、`k`大きいです。 もし`k ≥ n`、カエルはいつでもそこから直接行くことができます`l`に`r`、 それで`f(l, r)`単純になります`min(a[l..r])`。 この場合、正しい解決策はすべて古典的な「部分配列の最小値の合計」問題に適切に還元される必要があります。 

もう一つのエッジケースは、`k = 1`。 次に、カエルは一歩一歩歩くことを強制されるため、各間隔には正確に 1 つのパスがあり、`f(l, r)`セグメント上では最小値になりますが、連続するパスに沿った場合に限り、問題の構造が純粋なサブ配列の最小集合体に縮小されます。 

これらの観察は、問題が根本的に、制限された到達可能性グラフの下で極小制約を組み合わせることにあることを示唆しています。

 ## アルゴリズムのチュートリアル

 1. 高さの降順でインデックスを並べ替えます。これにより、柱が最も高いものから最も低いものへと処理されます。 これにより、ポジションをアクティブ化すると、そのポジションがそれに関係するあらゆる間隔で考えられる最大のボトルネック候補となることが保証されます。 
2. 配列を維持する`active[i]`位置かどうかを示す`i`がアクティブ化されました。 最初はすべて非アクティブです。 
3. インデックスに対する Union-Find 構造を維持しますが、距離が最大でも次の位置間のマージのみを許可します。`k`そして両方ともアクティブです。 各コンポーネントは、現在のしきい値の下で到達可能な最大ブロックを表します。 
4.ポジション発動時`i`、それをアクティブとしてマークし、範囲内のアクティブな隣接要素とマージしてみます。`[i-k, i-1]`そして`[i+1, i+k]`。 マージごとに到達可能性が拡張されます。 
5. 新しく形成されたコンポーネントごとに、コンポーネントの数を計算します。`(l, r)`この活性化が最適なパスに沿った最小の高さである場合に導入される間隔。 これは、マージされたセグメントのサイズと、`l`左側の境界線と`r`右側の境界では、アクティブなノードを介して接続されます。 
6. そのカウントを乗算します`a[i]`そして答えに追加します。 これは、高さの降順で処理するため機能します。`a[i]`は、アクティブ化の瞬間に残っている可能な最小値の最大値です。 
7. すべてのインデックスが処理されるまで続行します。 

### なぜ効果があるのか

 重要な不変条件は、ポジションが`i`アクティブ化されている場合、すでにアクティブなすべてのポジションには少なくとも高さがあります`a[i]`。 したがって、現時点で形成される接続は、高さ ≥ のノードにのみ依存します。`a[i]`。 これは、最適なボトルネックがまさに存在する任意の間隔を意味します。`a[i]`正確にカウントされるのは`i`が紹介されています。 後でより低い高さがアクティブ化されると、より高い高さによってすでに「要求」されている間隔に影響を与えることはできません。これらの間隔には、より高いノードまたは同等のノードのみを使用する実行可能なパスがすでに存在するためです。 これにより、二重カウントが防止され、ボトルネックが特定された瞬間に各間隔が 1 回だけ寄与することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.sz = [1] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return 0
        if self.sz[a] < self.sz[b]:
            a, b = b, a
        self.p[b] = a
        self.sz[a] += self.sz[b]
        return 1

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    order = sorted(range(n), key=lambda i: -a[i])

    dsu = DSU(n)
    active = [False] * n

    total = 0

    for i in order:
        active[i] = True

        # try to connect within distance k
        for d in range(1, k + 1):
            if i - d >= 0 and active[i - d]:
                dsu.union(i, i - d)
            if i + d < n and active[i + d]:
                dsu.union(i, i + d)

        # after activation, compute contribution
        root = dsu.find(i)

        # compute boundaries of component
        left = i
        j = i
        while left - 1 >= 0 and active[left - 1]:
            if dsu.find(left - 1) == root:
                left -= 1
            else:
                break

        right = i
        while right + 1 < n and active[right + 1]:
            if dsu.find(right + 1) == root:
                right += 1
            else:
                break

        total += a[i] * (i - left + 1) * (right - i + 1)

    print(total)

if __name__ == "__main__":
    solve()
```実装は、最上位の柱から最下位の柱へのアクティベーション順序に従います。 ノードがアクティブになるたびに、そのノードを距離内にあるすでにアクティブな隣接ノードに接続します。`k`。 DSU は、アクティブ化されたノードのみが参加するという制約の下で、接続されたコンポーネントを追跡します。 

結合操作の後、左右に展開して、新しく形成されたアクティブ コンポーネントのサイズを測定します。`i`。 製品`(i - left + 1) * (right - i + 1)`このアクティブ化ステップで最適なボトルネックが決定された間隔の数をカウントします。`i`は、それらのエンドポイントにまたがるすべてのパスにわたる制御最小値になります。 

微妙な点は、拡張が連続したアクティブ コンポーネントに依存していることです。これは有効です。アクティブ化の順序によって到達可能な領域の単調な増加が保証され、DSU によって接続の一貫性が保証されるからです。`k`-ステップルール。

 ## 特殊なケース

 すべての高さが等しい場合、すべてのアクティベーションが均等に寄与し、DSU はノードがアクティブになるとすぐにすべてをマージします。 アルゴリズムは各位置を対称的に扱うため、各間隔は同じ重みで 1 回だけカウントされます。 

いつ`k = 1`、接続は近隣の間でのみ形成されます。 アルゴリズムはチェーンを徐々に構築し、各ノードの寄与は、強制パスに沿った最小のアクティブ化要素であるサブ配列の数を正確に反映します。 拡張ステップは、連続する DSU コンポーネントと正しく一致します。 

いつ`k ≥ n`、すべての新しいアクティブ化は、以前にアクティブ化されたすべてのノードに接続できます。 DSU はすぐに 1 つのコンポーネントに折りたたまれ、各ステップの寄与は、その高さが制限要因となるエンドポイントの長方形全体に比例し、予想される削減量が純粋なサブアレイの最小集約に一致します。
