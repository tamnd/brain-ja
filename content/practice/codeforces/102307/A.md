 ## 解決策
 ## 問題の理解

 いくつかのポイントのペアが与えられます。 各ペアは、これらの 2 点を通る無限の直線の地下鉄線を決定します。 地下鉄路線は無限に伸びるため、点間の実際のセグメントは無関係です。 

2 つの異なる地下鉄線が直交すると、強力な交差が生じます。 同じ幾何学的な線が複数の入力ペアで記述される場合があり、それらの記述は 1 つの地下鉄線としてカウントされる必要があります。 このタスクは、方向が直角を形成する異なる幾何学的な線のペアを数えるというものです。 

入力には、1 つのテスト ケースに最大 (10^5) のペアが含まれ、最大 100 のテスト ケースが含まれます。 座標は (2\cdot10^4) によって制限されますが、答えは座標範囲よりもはるかに大きくなる可能性があります。 (10^5) 行の場合、すべてのペアをチェックするには約 (10^{10}/2) 回の比較が必要になりますが、これは 1 秒の制限時間をはるかに超えています。 入力ペアの数が線形または (O(n\log n)) に近い解が必要です。 

不注意な実装により、間違ったものを黙ってカウントする可能性がある方法がいくつかあります。 まず、同じラインの重複した記述によって余分な交差点が作成されてはなりません。 例えば、```
1
3
0 0 2 0
5 0 -3 0
0 1 0 3
```には、水平線 (y=0) と垂直線 (x=0) の 2 つの記述が含まれています。 正しい出力は次のとおりです`1`幾何学的な水平線が 1 本だけあり、それが垂直線に対して垂直であるためです。 入力ペアを直接カウントすると、誤って 2 つの交差が生成されます。 

エンドポイントを逆にしても、ラインは変更されないままにする必要があります。 例えば、```
1
2
0 0 4 0
4 0 0 0
```同じ行を 2 回記述しているため、答えは次のようになります。`0`。 生の方向ベクトルに基づく表現では、次のようになります。`(4, 0)`そして`(-4, 0)`方向が正規化されない限り、異なるものとして扱われます。 

傾斜を分割して表す場合、垂直線と水平線は特別な処理が必要です。 例えば、```
1
2
-20000 20000 20000 20000
20000 -20000 20000 20000
```(y=20000) と (x=20000) は垂直であるため、答えは次のようになります。`1`。 浮動小数点スロープの使用は不要であり、精度の問題が発生する可能性があります。 すべての行を完全に整数で表すことができます。 

最後に、複数の平行線は異なる地下鉄線であり、垂直ファミリが存在する場合は個別にカウントする必要があります。 例えば、```
1
3
-2 0 2 0
-2 1 2 1
0 -2 0 2
```2 本の異なる水平線と 1 本の垂直線が含まれています。 正しい答えは、`2`, 垂直線が両方の水平線と直角に交差するためです。 

## アプローチ

 直接的なアプローチは、すべての地下鉄路線を建設し、その後、それらのすべてのペアを調査することです。 各ペアについて、それらが別個であるかどうか、およびそれらの方向ベクトルの内積が 0 であるかどうかを確認します。 これは正しいです。なぜなら、すべての強い交差は、異なる線の 1 つの垂直ペアに正確に対応するからです。 

問題は比較の回数です。 (n=10^5) の場合、

 [
 \frac{n(n-1)}2 \約 5\cdot10^9
 ]

 ペア。 たとえ 1 つの比較に数回の整数演算しか必要なかったとしても、数十億回の比較では制限時間内に収まりません。 

重要な観察は、垂直度は線の方向のみに依存するのに対し、完全な幾何学的な線を識別することで重複した入力ペアを削除できるということです。 まず各行を正規化してセットに入れます。 重複を削除した後は、各方向の異なる線が何本あるかを知る必要があるだけです。 

((x_1,y_1)) と ((x_2,y_2)) を通る線には方向ベクトルがあります。 

[
 (dx,dy)=(x_2-x_1,y_2-y_1)。 
]

 スケールや方向に関係なく同じ方向を識別するには、(\gcd(|dx|,|dy|)) で除算し、1 つの符号規則を選択します。 たとえば、最初の非ゼロ成分が正である必要があります。 したがって`(4, 2)`、`(2, 1)`、`(-2, -1)`、 そして`(-4, -2)`すべて同じ方向を表します。 

ただし、平行線は異なる場合があるため、方向だけでは線を識別するのに十分ではありません。 したがって、完全な行を次のように表します。 

[
 Ax+By+C=0、
 ]

 どこで

 [
 A=dy,\qquad B=-dx,\qquad C=dx,y_1-dy,x_1。 
]

 3 つの係数すべてを共通の gcd で除算し、その符号を正規化します。 結果として得られるトリプル`(A, B, C)`幾何学的なラインをユニークに表現しています。 

すべての個別の線がわかったら、その正規の方向が次のとおりであると仮定します。`(dx, dy)`。 垂直方向とは、

 [
 (-dy、dx)。 
]

 同じ符号の規則を使用してその方向を正規化します。 もし`cnt[d]`方向を持つ個別の線の数です`d`の場合、この方向とその垂線に関係するすべての交点が寄与します。 

[
 cnt[d]\cdot cnt[perp]。 
]

 2 つの方向タプル間の単純な順序比較を使用して、方向クラスの順序なしペアを 1 回だけ処理します。 

ブルートフォース手法は、強い交差の定義を直接チェックするため機能しますが、基本的に同じ幾何学的な推論を何十億ものペアに対して繰り返すため失敗します。 答えが方向別にグループ化された一意のラインにのみ依存するという観察により、問題はセットの構築と互換性のあるグループのカウントに縮小されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(n^2)) | (O(n)) | 遅すぎる |
 | 最適 | (O(n\log C+n)) が期待されます | (O(n)) | 承認済み |

 ここで (C) は整数係数の大きさを表します。 指定された座標範囲では、gcd 計算は実質的に定数時間であるため、Python のセットと辞書が期待される (O(1)) の挿入と検索を提供するため、実際の複雑さは期待される (O(n)) 時間になります。 

## アルゴリズムのチュートリアル

 1. 入力点のペアごとに、次の計算を行います。`dx = x2 - x1`そして`dy = y2 - y1`。 これらの値は、浮動小数点演算を使用せずに地下鉄の路線の方向を表します。 
2. 次を使用して直線方程式 (Ax+By+C=0) を構築します。`A = dy`、`B = -dx`、 そして`C = dx*y1 - dy*x1`。 3 つの係数すべてを gcd で除算し、それらの共通符号を正規化します。 結果のトリプルをセットに保存します。 これにより、端点が反転した記述を含む、まったく同じ幾何学的な線の繰り返しの記述が削除されます。 
3. 新しく挿入された行ごとに、その方向ベクトルを正規化します。`(dx, dy)`で割ることで`gcd(abs(dx), abs(dy))`。 必要に応じて両方の成分を反転して、最初の非ゼロ成分が正になるようにします。 この方向の周波数を増加させます。 同じ路線を記述する 2 つの入力ペアは 1 つの地下鉄路線のみに寄与する必要があるため、個別の路線についてのみ方向をカウントします。 
4. すべての行が処理された後、あらゆる方向に反復処理します。`d = (dx, dy)`。 その垂直方向を次のように構築します。`(-dy, dx)`そして同じ規則に従ってそれを正規化します。 これら 2 つの方向クラスで表される垂直ペアの数は次のとおりです。`cnt[d] * cnt[perp]`。 
5.次の場合にのみ本製品を追加してください。`d < perp`辞書順に。 これにより、順序のない方向クラスのペアがすべて 1 回だけ出現します。 ラインの方向はそれ自体の垂直方向と等しくなることはあり得ないため、特別な自己ペアのケースはありません。 

### なぜ効果があるのか

 正規化後は、すべての幾何学的な地下鉄路線に 1 つの路線キーが含まれるため、セットには実際の各路線が 1 回ずつ含まれます。 このようなすべての線について、その正規化された方向は、その位置や線を記述するために使用される座標とは無関係にその向きを識別します。 2 つの非ゼロ方向ベクトルは、その内積がゼロの場合に正確に垂直になります。`(dx,dy)`に垂直です`(-dy,dx)`。 したがって、異なる垂直地下鉄線のすべてのペアは、正確に 1 つの方向クラスのペアに属します。`d`そして`perp`。 頻度積は、各クラスからの 1 行のすべての組み合わせをカウントしますが、辞書編集条件は、順序のないクラスのペアを 1 回だけカウントします。 したがって、最終的な合計は、正確に強い交差の数になります。 

## Python ソリューション```python
import sys
from math import gcd

input = sys.stdin.readline

def normalize_direction(dx, dy):
    g = gcd(abs(dx), abs(dy))
    dx //= g
    dy //= g

    if dx < 0 or (dx == 0 and dy < 0):
        dx = -dx
        dy = -dy

    return dx, dy

def solve():
    t = int(input())
    answers = []

    for _ in range(t):
        n = int(input())

        lines = set()
        direction_count = {}

        for _ in range(n):
            x1, y1, x2, y2 = map(int, input().split())

            dx = x2 - x1
            dy = y2 - y1

            # The problem describes a line using two locations,
            # so the two locations are assumed to be distinct.
            A = dy
            B = -dx
            C = dx * y1 - dy * x1

            g = gcd(gcd(abs(A), abs(B)), abs(C))
            A //= g
            B //= g
            C //= g

            if A < 0 or (A == 0 and B < 0) or (
                A == 0 and B == 0 and C < 0
            ):
                A = -A
                B = -B
                C = -C

            line = (A, B, C)

            if line in lines:
                continue

            lines.add(line)

            direction = normalize_direction(dx, dy)
            direction_count[direction] = direction_count.get(direction, 0) + 1

        answer = 0

        for dx, dy in direction_count:
            perp = normalize_direction(-dy, dx)

            if (dx, dy) < perp:
                answer += direction_count.get(perp, 0) * direction_count[(dx, dy)]

        answers.append(str(answer))

    sys.stdout.write("\n".join(answers))

if __name__ == "__main__":
    solve()
```の`normalize_direction`関数は方向ベクトルから共通因子を削除し、その方向を修正します。 条件`dx < 0 or (dx == 0 and dy < 0)`水平方向が`(positive, 0)`そして垂直方向は`(0, positive)`。 これにより、無向方向ごとに 1 つの表現が得られます。 

直線方程式では、方向ベクトルを使用して法線ベクトルを構築します。 以来`A = dy`そして`B = -dx`、ベクトル`(A, B)`線に対して垂直です。 定数`C`最初の入力点が式を満たすように選択されます。 3 つの係数すべてを共通の gcd で除算すると、任意のスケーリングが削除されます。 

の符号正規化`(A, B, C)`両方必要なので

 [
 アクス+バイ+C=0
 ]

 そして

 [
 -Ax-By-C=0
 ]

 同じ行を説明します。 符号ルールがないと、同一の行が 2 つの異なるセット エントリを占有する可能性があります。 

行が挿入されます`lines`その方向がカウントされる前に。 この順序付けは不可欠です。 線がすでに出現している場合、その 2 番目の記述によって方向の頻度が増加してはなりません。 

答えは Python 整数を使用するため、交差の最大数に達してもオーバーフローの問題は発生しません。 

[
 \frac{10^5(10^5-1)}2=4,999,950,000。 
]

 最後の辞書編集的な比較により、二重カウントが防止されます。 たとえば、次の場合`(1, 0)`に垂直です`(0, 1)`、加工`(1, 0)`処理中に製品をカウントします`(0, 1)`何もしないから`(0, 1) < (1, 0)`は誤りです。
