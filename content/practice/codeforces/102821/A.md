 ## 問題の理解

 この問題はオートチェス ゲームの準備段階をモデル化しています。 の列があります`N`待機スロット。最初は空です。 魚が受け取る`M`レベル1のチェスの駒が1人ずつ。 各チェス駒には名前だけがあり、同じ名前のチェス駒は組み合わせることができます。 

名前を持った新しいチェスマンのとき`s`到着すると、ゲームはまずレベル 3 かどうかをチェックします。`s`すでに待機ゾーンに存在します。 そうなると、新しいチェスの駒は消えてしまいます。 それ以外の場合、新しいチェスマンは既存のコピーと結合しようとします。 あれば`K-1`のレベル 1 コピー`s`、新しいものと結合してレベル 2 になります。`s`。 新たに作成されたレベル 2 のチェスの駒も、`K-1`既存のレベル 2 のコピーがある場合、レベル 3 のチェスマンになります。 考えられるすべてのマージの後、結果として得られるチェスの駒は、左端の空のスロットが存在する場合にはそれを占有します。 

入力により、いくつかの独立したゲーム シミュレーションが行われます。 テスト ケースごとに、待機ゾーンの最終コンテンツを左から右に出力する必要があります。 レベル 1 のチェスマンは名前のみを使用して出力されますが、より高いレベルにはレベル番号が追加されます。 空の位置は次のように出力されます。`-1`。 

重要な制約はスロットの数です。`N`、到達できる`100000`。 これは、挿入のたびに待機ゾーン全体を繰り返しスキャンするソリューションが、`M * N`多くの駒を挿入すると操作が遅くなりすぎます。 チェスの駒の状態をほぼ一定の時間で更新し、実際に変化する局面のみを処理する必要があります。 

主なエッジケースは、マージとピースの物理的配置の間の相互作用から生じます。 出力がピースの正確な位置に依存するため、単純なカウンターのみのソリューションは失敗する可能性があります。

## アプローチ

 直接シミュレーションは簡単です。 待機ゾーンを保存し、到着するチェスマンごとにすべての局面を検索して、その名前のレベル 1 およびレベル 2 の駒がいくつ存在するかを数えることができます。 十分なコピーが存在する場合は、それらを削除し、新しい部分をアップグレードして、別のマージのチェックを続けます。 最後に、もう一度スキャンして、最初の空のスロットを見つけます。 

このアプローチはルールに正確に従っているため正しいですが、ボード全体を繰り返し実行します。 最悪の場合、基板が`N=100000`ポジションが決まり、多くのチェスの駒が到着すると、操作の数はおよそ`M*N`これは、1 秒のソリューションで処理できる範囲をはるかに超えています。 

重要な観察点は、ルールでは各チェスの駒の名前について 2 種類の情報のみが必要であるということです。つまり、各レベルに駒がいくつ存在するか、およびそれらの駒がどこにあるかということです。 最終的な配置は、ピースを削除し、左端の利用可能な位置に挿入することによってのみ決まります。 無関係な名前を検査する必要はありません。 

各名前について、現在のレベル 1 とレベル 2 の位置を維持します。 新しい部分が到着すると、マージが行われたかどうかをすぐに判断できます。 ピースが消えるとスロットが空になるため、最小の空のインデックスを迅速に提供するデータ構造も維持します。 新しく空の位置を挿入し、最小の位置を抽出するだけなので、最小ヒープを選択するのは自然な選択です。 

合計作業量は、待機ゾーンのサイズではなく、処理される駒の数と実際のマージの数に比例します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(ミネソタ州) | O(N) | 遅すぎる |
 | 最適 | O(M log N) | O(N + M) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 待機ゾーンをサイズの配列として保存します`N`。 最初は、すべての位置に空のマーカーが含まれています。 最小の空のインデックスが常に見つかるように、すべての位置を使用可能なスロットの最小ヒープに配置します。 
2. 受信したすべてのチェスマン名について、その名前のレベル 3 チェスマンがすでに存在するかどうかを確認します。 存在する場合、ルールでは別のコピーを追加することが禁止されているため、このチェスの駒は無視してください。 
3. すべての名前について、レベル 1 およびレベル 2 の駒の位置を維持します。 到着したチェスの駒が作成した場合`K`同じ名前のレベル 1 の駒がある場合、それらのレベル 1 の駒を削除し、到着したチェスの駒をレベル 2 にします。 
4. レベル 2 の作品を作成した後、現在存在するかどうかを確認します。`K`レベル2の作品。 そうであれば、それらの駒を取り除き、到着したチェスの駒をレベル 3 にします。 
5. チェスの駒が生き残った場合は、空の位置のヒープから最小のインデックスを取得し、そこにチェスの駒を配置します。 この位置の名前とレベルを対応するリストに記録します。 
6. すべての挿入が処理された後、待機ゾーンを印刷します。 

これが機能する理由は、各名前のリストには常に現在存在する部分が正確に含まれるためです。 すべてのマージでは、ルールで必要な駒が正確に削除され、生き残ったすべてのチェスの駒が、現在空になっている最小の位置に挿入されます。 ヒープ不変条件により、すべての配置で元のプロセスが選択したのと同じ位置が使用されることが保証されます。 

## Python ソリューション```python
import sys
import heapq

input = sys.stdin.readline

def solve_case(M, N, K, pieces):
    board = ["-1"] * N
    empty = list(range(N))
    heapq.heapify(empty)

    data = {}

    def get_info(name):
        if name not in data:
            data[name] = [[], [], False]
        return data[name]

    for name in pieces:
        lv1, lv2, has3 = get_info(name)

        if has3:
            continue

        level = 1

        if len(lv1) == K - 1:
            for pos in lv1:
                board[pos] = "-1"
                heapq.heappush(empty, pos)
            lv1.clear()
            level = 2

            if len(lv2) == K - 1:
                for pos in lv2:
                    board[pos] = "-1"
                    heapq.heappush(empty, pos)
                lv2.clear()
                level = 3
                has3 = True

        if empty:
            pos = heapq.heappop(empty)
            if level == 1:
                board[pos] = name
                lv1.append(pos)
            elif level == 2:
                board[pos] = name + "2"
                lv2.append(pos)
            else:
                board[pos] = name + "3"
                data[name][2] = True

    return " ".join(board)

def main():
    t = int(input())
    ans = []

    for case in range(1, t + 1):
        M, N, K = map(int, input().split())
        pieces = [input().strip() for _ in range(M)]
        ans.append(f"Case {case}: {solve_case(M, N, K, pieces)}")

    print("\n".join(ans))

if __name__ == "__main__":
    main()
```配列`board`すべてのスロットの最終的な表示状態を保存します。 ヒープ`empty`現在空いているポジションが正確に含まれます。 マージが発生するたびに、削除された部分はその位置をこのヒープに戻します。これにより、左端の空きスロットを見つける機能が維持されます。 

辞書`data`チェスマン名に固有のすべての情報を保持します。 最初のリストにはレベル 1 の位置が格納され、2 番目のリストにはレベル 2 の位置が格納され、ブール値はレベル 3 のピースが存在するかどうかを記録します。 これにより、無関係な位置のスキャンが回避されます。 

挿入ループ内の操作の順序はゲームのルールに従います。 レベル 3 チェックが最初に行われます。 次に、レベル 1 のマージが試行され、続いてレベル 2 のマージが試行されます。 考えられるすべてのアップグレードが完了した後でのみ、ピースがボードに配置されます。 

この実装では、入力サイズによって制限されたインデックスとカウンターのみを格納するため、整数制限に対する特別な処理は必要ありません。 重要な境界条件は、駒を配置する前に空のヒープが空でないかどうかを確認することです。ボードがすでにいっぱいの場合、チェスの駒が消える可能性があるためです。
