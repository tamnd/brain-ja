 ## 問題の理解

 2 つの長方形のオブジェクトがあります。 各テスト ケースの寸法は、幅と高さとして指定されます。 長方形を自由に移動したり回転したりできますが、重ねることはできません。 タスクは、両方の長方形を含む凸多角形の可能な最小の領域を見つけることです。 

重要な点は、囲む最小の長方形を探しているわけではないということです。 凸多角形は空の角を切り取る可能性があるため、単純に幅を追加して高さを最大にすることが常に最適であるとは限りません。 

テスト ケースの数は最大 100 で、各辺の長さは最大 100 です。これは、ソリューションがテスト ケースごとに少量の一定量の作業を実行するだけでよいことを意味します。 シミュレーション、配置の検索、または多くの状態を含むジオメトリの構築は不要です。 意図した解決策では、無限数の可能な回転と位置を固定数の数学的ケースに減らす必要があります。 

難しいのは、最良の配置が必ずしも通常の横並び配置であるとは限らないことを理解することです。 単純なアプローチでは、境界四角形のみをチェックすることになり、凸包が三角形の空の領域を削除する対角配置が欠落します。 

たとえば、長方形の場合`1 3`そして`2 4`、外接する四角形のアプローチでは次のようになります。```
(1 + 2) * max(3, 4) = 12
```しかし、正しい答えは次のとおりです。```
11.5
```行方不明者`0.5`2つの長方形を対角に置くと消える三角コーナーに由来しています。 

もう 1 つのエッジ ケースは、1 つの長方形を回転すると効果がある場合です。 長方形の場合`2 3`そして`4 5`、両方の方向を固定したままにするとより大きな結果が得られますが、1 つの長方形を回転すると最適な配置が得られます。```
Input:
2 3 4 5

Output:
27.0
```幅と高さを決して交換しないソリューションでは、誤ってより大きな値が返されます。 

## アプローチ

 この強引なアイデアは、2 つの長方形の可能な配置と回転角度をすべて試し、凸包を構築し、その面積を測定することです。 すべての法的取り決めがこのように評価できるため、この考えは正しいです。 問題は、回転が連続的であるため、可能な状態が無限に存在することです。 検索を多数のサンプル角度に制限しても、正確性は保証されません。 

重要な点は、長方形の辺の相対的な方向のみが重要であるということです。 最適な構成は、長方形の面積の合計から 1 つの三角形の角が削除される形で長方形が接触するときに発生します。 向きを固定的に選択した場合、2 つの長方形の外側の追加領域は次のようになります。$$\frac{|w_1-w_2|\cdot |h_1-h_2|}{2}$$その理由は、凸包の空の部分が直角三角形であるためです。 その脚は、2 つの長方形の対応する辺の長さの差に正確に相当します。 

各長方形は方向を維持することも、90 度回転することもできるため、確認する方向の組み合わせは 4 つだけです。 

1 つの方向の合計面積は次のとおりです。$$w_1h_1+w_2h_2+\frac{|w_1-w_2||h_1-h_2|}{2}$$4 つの回転のうちの最小値が答えです。

 ## アルゴリズムのチュートリアル

 1. 両方の長方形の面積を計算します。 回転しても長方形自体のサイズは変わらないため、この部分は一定です。 
2. 2 つの長方形の可能な方向をすべて試します。 長方形には意味のある状態が 2 つだけあります。`(width, height)`そして`(height, width)`。 
3. 方向のペアごとに、追加の三角形の領域を計算します。$$\frac{|w_1-w_2||h_1-h_2|}{2}$$これは、どちらの長方形にも占有されない凸包の部分を表します。 

1. この値を 2 つの長方形領域の合計に加算し、最小値を維持します。 

なぜ効果があるのか:

 固定方向の場合、長方形が接触するまで押し合うと、可能な限り最適な配置が得られます。 ギャップが残っていると、凸包の面積が増加します。 接触後、凸包の唯一の未使用部分は、辺の長さの差によって作成される三角形です。 4 つの向きの選択肢をすべてチェックすると、2 つの長方形のあらゆる回転がカバーされるため、見つかった最小値が全体的な最適値となります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(w1, h1, w2, h2):
    base = w1 * h1 + w2 * h2
    ans = float("inf")

    for a, b in [(w1, h1), (h1, w1)]:
        for c, d in [(w2, h2), (h2, w2)]:
            extra = abs(a - c) * abs(b - d) / 2
            ans = min(ans, base + extra)

    return ans

def main():
    t = int(input())
    out = []

    for case in range(1, t + 1):
        w1, h1, w2, h2 = map(int, input().split())
        ans = solve_case(w1, h1, w2, h2)
        out.append(f"Case {case}: {ans:.10f}")

    print("\n".join(out))

if __name__ == "__main__":
    main()
```この実装では現在の回答のみが保存されるため、隠れたメモリ コストは発生しません。 ループは、複雑なジオメトリ コードを回避して、各四角形の 2 つの可能な方向を明示的に列挙します。 

三角形の寄与には次の要素が含まれる可能性があるため、浮動小数点除算の使用が必要です。`.5`。 小数点以下数桁を印刷すると、必要な精度を簡単に満たすことができます。 

絶対差の計算も重要です。 三角形のサイズは、どちらの長方形の辺が大きいかではなく、2 つの辺の長さがどれだけ異なるかによって決まります。
