 ## 解決策
 ## 問題の理解

 カードの小さなコレクションが与えられ、各カードにはバランスをとるために使用されるポイント値とスコアリングに使用される利益値という 2 つの独立した属性が含まれています。 このゲームは、アリスとボブの間の 2 フェーズの対話です。 まず、ボブはオプションで、ポイント値を 2 倍にして最大 k 枚のカードを変更できます。 この変更の後、ボブは、2 つのグループの合計ポイントが等しくなるように、カードの一部を 2 つの互いに素なグループに分割する必要があります。 どちらのグループにも選ばれなかったカードは破棄されます。 アリスは 1 つのグループを受け取り、ボブはもう 1 つのグループを受け取りますが、問題の観点からは、両方のプレイヤーがパーティションで使用されたすべてのカードの値を一緒に収集します。 

目標は、最大で k 回のダブリングを適用した後に有効な等和分割が存在することを条件として、最終パーティションに含まれるすべてのカードの合計値を最大化することです。 

入力サイズは小さく、n は最大 100、ポイント値は 13 で制限されます。これは、指数関数または疑似多項式のナップザック スタイルの解決策が妥当であることをすぐに示唆していますが、すべての変更に対する完全なサブセットの列挙を伴うものは慎重に制御する必要があります。 カードのすべてのサブセットと 2 倍のセットのすべての選択肢を単純に列挙すると、最大 2^100 の状態が含まれることになりますが、これは実行不可能です。 パーティションチェックを追加するだけでもコストは倍増します。 

微妙な点は、2 倍にすることでパリティと大きさが変化し、最終的な分割制約は調整されたポイント値のマルチセットにのみ依存することです。 不用意なアプローチは、パーティションをカードのフルセットに対する標準的なサブセット合計の問題として扱い、選択したサブセットのみが完全にバランスをとる必要があり、他のカードは完全に除外される可能性があるという事実を無視して、失敗することがよくあります。 もう 1 つのよくある間違いは、すべてのカードを使用する必要があると仮定することです。これにより、選択したサブセットではなく、配列全体に等価性が誤って強制されてしまいます。 

たとえば、カードが [t = 1, 3, 1, 1] で値 [10, -5, 5, 6] である場合、4 枚のカードすべてを均等に分割する必要はありません。 バランスの取れた分割を妨げる場合、一部のカードを完全に破棄する場合があります。 この区別は非常に重要です。 

## アプローチ

 ブルートフォースのアイデアは、どのカードを 2 倍にするかを選択することから始まり、次にその変更された配列について、合計が偶数で 2 つの等しい半分に分割できるサブセットを見つけようとします。 これは本質的に、合計値を最大化しながら、選択したサブセットの合計の半分に等しい合計を持つサブセットが存在するかどうかをチェックすることです。 直接的なブルート フォースでは、すべての 2^n サブセットを反復処理し、各サブセットに対してすべての 2^k 倍加選択肢をテストし、サブセット合計 DP または列挙を実行して分割可能性を検証します。 n = 100 の場合でも、状態空間は最悪の解釈では 2^100 × 2^100 になるため、これは実現可能性をはるかに超えて爆発します。 

重要な構造的洞察は、分割条件がアリスまたはボブの個別の割り当てではなく、選択されたアイテムの最終的なマルチセットにのみ依存するということです。 ターゲットの差の解釈を修正すると、問題はカードのサブセットを選択し、符号付きの合計がゼロになるように選択した各カードに + または - の符号を割り当てることになります。 2 倍演算は個々の寄与の大きさにのみ影響し、選択肢は k 個に制限されます。 

このように再構成すると、選択された各カードは +t または -t に寄与し、2 倍になると t が 2t に変化します。 分割条件は、符号付きサブセット合計がゼロに等しい制約となり、符号に関係なく選択された項目の合計値を最大化することが目的となります。 これにより、問題は、電流バランスの差と使用される倍加数によって定義される状態をめぐるナップザックに変わります。

ti ≤ 13 であるため、すべてのカードの最大合計は、起こり得る不均衡を制限するのに十分小さいです。 DP 状態は (i, d, used) として扱うことができます。ここで、i は処理されたインデックス、d は 2 つのパーティション間の現在の差分、used は 2 倍になったカードの数です。 各トランジションでは、カードをスキップし、それを左セットまたは右セットに取り込み、許可されている場合はオプションでカードを 2 倍にすることが考慮されます。 それに応じてバランス寸法もtまたは2tシフトします。 

したがって、問題は、制限された差分範囲と小さな k を持つ制約された多次元 DP に帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | サブセットに対するブルート フォース + ダブリング + パーティション チェック | O(2^n · 2^k · 2^n) | O(n) | 遅すぎる |
 | 指数のDP × 残高差 × 使用ダブリング | O(n · S · k) ただし、S ≤ 1300 | O(S・k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. リスト内でどこまで進んだか、2 つのパーティション側の間に現在どのような不均衡が存在するか、これまでに何回の倍加が使用されたかを追跡する動的プログラミング状態を定義します。 不均衡は、2 つの側に割り当てられた合計間の符号付きの差です。 
2. カードを処理する前に、DP を単一の状態で初期化します。この場合、不均衡はゼロであり、ダブリングは使用されません。 これは、空のパーティションから開始することに相当します。 
3. 各カードについて、カードを完全に除外するか、最初のパーティションに割り当てるか、2 番目のパーティションに割り当てるかの 3 つの構造上の決定を検討します。 最適解ではすべてのカードが使用されない可能性があるため、除外が必要です。 
4. カードをパーティションに割り当てるとき、そのポイント値を加算または減算して不均衡を更新します。 カードを 2 倍にすることを選択した場合、2 倍にする予算が残っている場合にのみこの移行が許可され、2 倍の値を使用して不均衡が更新されます。 
5. 各カードの処理後、使用可能なダブリングの可能数ごとに到達可能な不均衡状態のみを維持するように、ローリング DP を維持します。 これにより、インデックス間の指数関数的な爆発が回避されます。 
6. すべてのカードを処理した後、最終的な不均衡がゼロであるすべての状態を調べます。これは、両方のパーティションの合計が等しいことを意味します。 このような状態ごとに、その状態で実際に選択されたすべてのカードによる合計値を計算し、最大値を取得します。 

### なぜ効果があるのか

 DP は、2 倍化制約を尊重しながら、カードの考えられるすべての有効な割り当てを左、右、または未使用のカテゴリーにエンコードします。 不均衡変数は分割条件の正確な不変量であり、どの段階でも常に 2 つの構築されたサブセットの差に等しくなります。 状態は、選択されたサブセットの処理後に不均衡がゼロになったときに正確に有効になります。 すべての遷移はゲーム内の正当なアクションに対応し、すべての正当な構成は遷移のシーケンスによって表現できるため、有効な解決策が見逃されることはなく、無効な解決策がゼロ インバランスの最終状態として現れることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    cards = [tuple(map(int, input().split())) for _ in range(n)]

    # maximum possible sum of t is 100 * 13 = 1300
    MAXD = 1300

    # dp[used][diff] = max value sum achievable
    dp = [[-10**18] * (2 * MAXD + 1) for _ in range(k + 1)]
    offset = MAXD

    dp[0][offset] = 0

    for vi, ti in cards:
        new = [[-10**18] * (2 * MAXD + 1) for _ in range(k + 1)]

        for used in range(k + 1):
            for d in range(2 * MAXD + 1):
                if dp[used][d] < -10**17:
                    continue

                cur = dp[used][d]

                # 1. skip card
                if cur > new[used][d]:
                    new[used][d] = cur

                # 2. take without doubling
                nd = d + ti
                if 0 <= nd <= 2 * MAXD:
                    if cur + vi > new[used][nd]:
                        new[used][nd] = cur + vi

                nd = d - ti
                if 0 <= nd <= 2 * MAXD:
                    if cur + vi > new[used][nd]:
                        new[used][nd] = cur + vi

                # 3. take with doubling
                if used < k:
                    nd = d + 2 * ti
                    if 0 <= nd <= 2 * MAXD:
                        if cur + vi > new[used + 1][nd]:
                            new[used + 1][nd] = cur + vi

                    nd = d - 2 * ti
                    if 0 <= nd <= 2 * MAXD:
                        if cur + vi > new[used + 1][nd]:
                            new[used + 1][nd] = cur + vi

        dp = new

    ans = 0
    for used in range(k + 1):
        ans = max(ans, dp[used][offset])

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、使用されたダブリングの数と 2 つのパーティション間の現在の不均衡によってインデックス付けされた 2D DP を使用します。 負の値が配列インデックスに安全に格納されるように、不均衡はオフセットによってシフトされます。 各カードは、スキップ、左割り当て、右割り当て、またはダブリングによる左/右割り当ての最大 5 つの可能性に移行します。後者は残りの k 予算によって制限されます。 

微妙な実装の詳細は、カードがどちらの側に移るかに関係なく、カードの選択は常にその価値に寄与するため、不均衡が変化した場合でも、達成可能な最高の価値の合計を引き継ぐことです。 これは、使用されたすべてのカードが最終的な解答に寄与するという問題の要件と一致します。 

## 実用的な例

 ### 例 1

 入力:

 n = 4、k = 1

 カード:

 (10,1)、(-5,3)、(5,1)、(6,1)

 各カードの後に dp[used][diff] を追跡します。 簡潔にするために、関連する州をいくつかのみ示します。 

| ステップ | カード | アクション | 中古 | 差分 | 値 |
 | --- | --- | --- | --- | --- | --- |
 | 0 | - | 開始 | 0 | 0 | 0 |
 | 1 | (10,1) | 左折 | 0 | 1 | 10 |
 | 2 | (-5,3) | 右を取る | 0 | -2 | 5 |
 | 3 | (5,1) | 左折 | 0 | -1 | 10 |
 | 4 | (6,1) | 右を取る | 0 | -2 | 16 |

 最後に、diff = 0 である状態がチェックされます。 1 つの有効な構成は、等価性が可能になるように不均衡を調整するために 2 倍を使用する場合に生じます。達成可能な最良の合計値は 21 です。 

このトレースは、不均衡が合計値の累積とは無関係に進行し、最終的なゼロ差分状態のみが問題となることを示しています。 

### 例 2

 入力:

 n = 3、k = 0

 カード:

 (4,2)、(7,2)、(5,4)

 カードを二重化することはできないため、直接パーティション化のみが許可されます。 

| ステップ | カード | アクション | 差分 | 値 |
 | --- | --- | --- | --- | --- |
 | 1 | (4,2) | 左折 | 2 | 4 |
 | 2 | (7,2) | 右を取る | 0 | 11 |
 | 3 | (5,4) | スキップ | 0 | 11 |

 最も有効な構成では、最初の 2 枚のカードを均等に分割して使用し、答え 11 が得られます。 

これは、すべてのカードがバランス パーティショニングと互換性があるわけではないため、k = 0 の場合でもスキップが不可欠であることを示しています。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、一部のカードが除外されない限り、有効なパーティションが存在しない場合です。 スキップ遷移は強制的に含めることなく状態を保持するため、DP はこれを自然に処理します。 たとえば、すべてのカードの合計構造が奇数で平等を妨げている場合、除外が適用されない限り、DP は diff = 0 に到達しません。 

もう 1 つのエッジ ケースは、ソリューションを有効にするために 2 倍化が必要な場合です。 このような場合、used = k の状態が不可欠であり、used カウンタを追跡しないソリューションでは有効なパーティションを誤って見逃すことになります。 DP は使用カウントによって状態を明示的に分離し、正確に k の制約が尊重され、2 倍化の最適な使用が考慮されるようにします。 

最後のエッジ ケースは、複数の構成で diff = 0 が得られるが、値の合計が異なる場合です。 DP は状態ごとの最大値を保存し、最初の実現可能な構成で停止するのではなく、最後に最適な有効なパーティションのみが選択されるようにします。
