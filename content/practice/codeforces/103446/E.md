 ## 解決策
 ## 問題の理解

 一連の整数としきい値が与えられます。$k$。 このシーケンスから、選択した値のすべてのペアの値が「近い」ようにサブシーケンスを選択します (選択した 2 つの要素間の絶対差は最大でも以下でなければなりません)。$k$。 目標は、この制約の下で選択できる要素の数を最大化することです。 

キーの制限は、連続する要素間だけでなく、選択したセット全体にわたってグローバルです。 3 つの値を選択すると$x, y, z$の場合、3 つのペアごとの差異はすべて以下の範囲内にある必要があります。$k$、だけでなく$|x-y|$そして$|y-z|$。 これにより、構造は選択したセット内の値の範囲のみに依存するようになります。 

入力サイズが到達しました$n = 10^5$したがって、任意の二次方程式または偶数$O(n \log n)$すべてのペアを繰り返し比較するソリューションは、注意深く構成されていないと困難になります。 ソリューションでは、理想的には一度並べ替えてから、直線的にスキャンするか、スライディング ウィンドウを使用してスキャンする必要があります。 

微妙なエッジケースが現れるのは、$k = 0$。 その場合、同じ値のみを選択できます。 答えは任意の数値の最大頻度になります。 たとえば、配列が次の場合、$[1, 2, 2, 3]$そして$k = 0$、正解は$2$。 隣接性に基づいてサブシーケンスを拡張しようとする単純な貪欲な場合、誤ってより多くの要素を選択してしまいます。 

すべての値が狭い間隔内にある場合、別の特殊なケースが発生します。 たとえば、すべてが$A_i = 10^9$の場合、どのサブセットも有効となり、答えは次のようになります。$n$。 正しい解決策では、誤って重複を破棄したり、厳密な不等式の仮定に依存したりしてはなりません。 

## アプローチ

 ブルートフォースのアイデアは、配列のすべてのサブセットを試し、すべてのペアごとの差が最大であるという条件を満たすかどうかを確認することです。$k$。 各サブセットの有効性を検証するには、選択したすべての要素をスキャンし、最小値と最大値を追跡する必要があります。 サブセットが有効になるのは、次の場合です。$\max - \min \le k$。 

これにより、おおよその数のサブセットが指数関数的に増加します。$2^n$、各検証のコストは最大で$O(n)$。 サブセットを暗黙的にチェックするだけに限定したとしても、このアプローチはすぐに実行不可能になります。 

条件の構造を見ると単純化されていることがわかります。条件は選択された値の範囲のみに依存します。 配列をソートすると、有効なサブセットはソートされた順序で連続したセグメントに対応し、最小要素と最大要素の差が最大で以下になります。$k$。 これにより、問題はそのような最長のセグメントを見つけることに変わります。 

並べ替え後、2 ポインターのスライディング ウィンドウを使用できます。 右のエンドポイントを拡張し、ウィンドウが有効なままになるように左端の位置を維持します。 その差が超えるたびに$k$状態が復元されるまで、左ポインタを前に動かします。 このプロセス中に確認される最大ウィンドウ サイズが答えです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^n \cdot n)$|$O(n)$| 遅すぎる |
 | 並べ替え + スライド ウィンドウ |$O(n \log n)$|$O(1)$または$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 ### ステップ

 1. 配列を非降順で並べ替えます。 範囲を拡大しても最大値と最小値の差が増加するだけであるため、並べ替えにより、有効なサブセットがこの順序付けで連続した間隔としてみなされることが保証されます。 
2. 2 つのポインタを初期化する$l = 0$、$r = 0$、および変数$ans = 1$。 窓$[l, r]$は現在の候補セットを表します。 
3. 移動$r$配列全体で左から右へ。 各ステップで次の内容を含めます。$A[r]$現在のウィンドウに。 
4. 現在のウィンドウが条件に違反している間$A[r] - A[l] > k$、増分$l$。 これにより、再び有効になるまでウィンドウが左から縮小されます。 その理由は、要素が遠すぎると、$A[r]$ソートされた配列内では、同じ有効なセット内に留まることはできません。 
5.ウィンドウを修正した後、アップデートします$ans = \max(ans, r - l + 1)$。 これは、これまでに確認された最大の有効なサブセットを追跡します。 

### なぜ効果があるのか

 ソート後、選択したセットの最大要素と最小要素は、ソートされた順序でそのセットのエンドポイントから取得される必要があります。 ウィンドウが制約に違反する場合、範囲に最も多く寄与しているため、左端の要素が常に削除の最適な候補となります。 内部要素を削除しても、有効範囲は減少しません。 このアルゴリズムは、現在の正しいエンドポイントに対して常に最大となるウィンドウを維持するため、候補を見逃すことなく、すべての実行可能な最大サブセットを探索します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    a.sort()
    
    l = 0
    ans = 1
    
    for r in range(n):
        while a[r] - a[l] > k:
            l += 1
        ans = max(ans, r - l + 1)
    
    print(ans)

if __name__ == "__main__":
    solve()
```解決策は、配列をソートすることから始まります。これは、グローバルなペアごとの制約を範囲制約に変えるため、不可欠です。 並べ替えが完了したら、連続セグメントの端点に対応する候補セット内の最小値と最大値を追跡するだけで済みます。 

2 ポインター ループは有効なウィンドウを維持します。 内側の while ループは、左ポインターが移動する唯一の場所であり、各要素は最大 1 回削除されるため、ソート後の線形の複雑さが保証されます。 

よくある間違いは、並べ替えを忘れて、元の配列に対してスライディング ウィンドウを実行しようとすることです。 この条件はインデックスの距離ではなく値の範囲に依存するため、これは失敗します。

 ## 特殊なケース

 すべての要素が同一の場合、たとえば入力$[5, 5, 5, 5]$どれでも$k \ge 0$、ソートされた配列は一定のままで、ウィンドウが縮小することはありません。 アルゴリズムは拡張し続けます$r$そして常に生産します$ans = n$、正しい結果と一致します。 

いつ$k = 0$、 のような$[1, 2, 2, 3, 2]$、ソートすると、$[1, 2, 2, 2, 3]$。 値 2 のウィンドウはすべての出現を含むように拡張されますが、1 と 3 は違反のため直ちに除外されます。 このアルゴリズムは、最大の周波数ブロックを自然に分離します。 

次のように値の間隔が広い場合$[1, 100, 200, 300]$と$k = 50$、どの窓も小さいです。 アルゴリズムはシフトを繰り返す$l$無効なラージレンジセットが答えに寄与しないことを確認し、正しく 1 を返します。
