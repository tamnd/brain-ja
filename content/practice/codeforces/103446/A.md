 ## 問題の理解

 各項目には、次のインデックスが付いた関数が与えられます。$i$、2 つのパラメータによって定義されます$k_i$そして$a_i$。 この関数は周期的です$x$、その形状は、次の要素を含む変換された接線式によって決定されます。$\sec(x-a_i)$。 なぜなら$\sec(x-a_i)=1/\cos(x-a_i)$、関数は常に特異な動作を繰り返します。$\cos(x-a_i)=0$、それらの特異点の間ではスムーズに動作します。 

内側の表現$\arctan$大きさが大きくなるとき$|\sec(x-a_i)|$成長するとき、それは起こります$x$ポイントにアプローチします$\cos(x-a_i)$はゼロに近いです。 その結果、各関数は繰り返しの「谷」構造を持ち、次の場合に最小値に達します。$\cos(x-a_i)$絶対値が最大となり、垂直漸近線近くの共通の天井に向かって成長します。

 ## アルゴリズムのチュートリアル

 1. の最大値を維持しながら、関数を右から左にたどります。$k$これまで見られた。 これは、最小値で打ち負かすのがどれほど「難しい」かという点で、サフィックスの中で最も強力な関数を表します。 
2. インデックスごとに$i$、 比較する$k_i$最大限の$k$厳密に後の接尾辞に$i$。 もし$k_i$以降のすべての値と少なくとも同じ大きさである場合は、それを実行可能としてマークします。 
3. それ以外の場合は、最小の位置合わせが発生するすべての領域でスケール パラメーターが支配する後の関数が存在するため、実行不可能とマークします。 

この貪欲なサフィックス比較で十分である理由は次のとおりです。$k_i$関数がどれだけ低くできるかを完全に決定し、シフトはありません$a_i$より大きな接尾辞要素と競合する場合、このパラメータが厳密に小さいことを補正できます。 

### なぜ効果があるのか

 各関数には、次のように決定される固定の最良の値があります。$k_i$、すべての関数は同じ最悪の場合の上限を共有します。 後の関数が厳密に大きい場合$k_j$、（周期的最小値を適切に調整することによって）、許容されるどの構成よりも高くならない値を達成するように配置することができます。$f_i$最小限であること。 この問題では 1 つを選択できるため、$x$、唯一の方法$i$すべての接尾辞要素に対して勝つことができるのは、後続の関数が最適な位置合わせポイントでそれを下回る厳密に大きなスケーリング能力を持たない場合です。 これにより、優位性がサフィックスの最大値まで減少します。$k$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    k = []
    a = []
    for _ in range(n):
        ki, ai = map(int, input().split())
        k.append(ki)
        a.append(ai)

    ans = ['0'] * n
    suffix_max = 0

    for i in range(n - 1, -1, -1):
        if k[i] >= suffix_max:
            ans[i] = '1'
        else:
            ans[i] = '0'
        suffix_max = max(suffix_max, k[i])

    print(''.join(ans))

if __name__ == "__main__":
    solve()

唯一の微妙な点は、等しい関数があるため、等価性が許可されていることです。$k$一致する最小動作を達成するように調整することができますが、どちらの方向でも厳密な優位性は保証されません。

 ## 特殊なケース

 重要なエッジ状況は、すべてが$k_i$値は同じです。 この場合、他の関数を厳密に支配する関数はないため、すべてのインデックスは有効なままになります。 サフィックスの最大値が現在の値を超えることはなく、すべて 1 が生成されるため、アルゴリズムはこれを正しく処理します。
