 ## 解決策
 ## 問題の理解

 端数が与えられます$\frac{p}{q}$2 つの正の整数を含む非常に特殊な対称形式で表現できるかどうかを判断する必要があります。$a$そして$b$。 課題は、そのようなペアを構築するか、それが不可能であると報告することです。 

ステートメントに隠されている式はサンプルから明らかになります。分数は 2 つの逆項交差項の合計に等しいことを意味します。$$\frac{p}{q} = \frac{a}{b} + \frac{b}{a}.$$この解釈は次の例と一致します。$5/2 = 1/2 + 2/1$。 

入力は多くの独立したテスト ケースで構成されます。 各テスト ケースは、分子と分母が最大の有理数を与えます。$10^7$。 必要な出力整数$a$そして$b$と同じ大きさにすることができます$10^9$したがって、候補に対する直接の列挙を伴う解決策は直ちに除外されます。 

テスト ケースの数の制限 (最大)$10^5$、各テストを一定時間または対数時間で解決するように強制します。 の可能な値をスキャンすることを含むあらゆるアプローチ$a$または$b$、まででも$10^7$、につながるでしょう$10^{12}$最悪の場合の操作は実行不可能です。 

よくある失敗例は、これを構造的に変換せずに単純な分数の等価性として処理しようとしたことに起因します。 たとえば、次のように推測してみるかもしれません。$a = p$、$b = q$、次のような小さな入力でも明らかに失敗します。$p=5, q=2$、 以来$1/2 + 2/1 \neq 5/2$間違って解釈されたり、交換されたりした場合。 

解決策が常に存在すると仮定すると、別の微妙なエッジ ケースが発生します。 例えば、$p/q = 1/3$整数解がありません$a,b$満足のいく$a/b + b/a = 1/3$、という表現があるため、$a/b + b/a$常に少なくとも$2$正の整数の場合は AM-GM による。 

## アプローチ

 直接的な強引なアイデアは、すべてのペアを試すことです$(a,b)$ある程度の制限まで行って、$a/b + b/a = p/q$。 両方の変数を次のように制限しても、$10^5$すでに暗示しています$10^{10}$実行可能な限界をはるかに超えた最悪の場合にチェックします。 

重要な構造的観察は、式が比率のみに依存するということです。$x = a/b$、オンではありません$a$そして$b$個別に。 方程式を次のように書き直すと、$x$問題を有理数を使って二次方程式を解くように変換します。$$\frac{p}{q} = x + \frac{1}{x}.$$乗算すると得られる$$\frac{p}{q} = \frac{x^2 + 1}{x} \quad \Rightarrow \quad p x = q(x^2 + 1).$$並べ替えると二次式が生成されます。$$q x^2 - p x + q = 0.$$ここで問題は代数的になります。 ～に対する合理的な解決策$x$判別式が存在する場合にのみ存在します$$D = p^2 - 4q^2$$は負ではなく、完全な正方形です。 一度$x$決まったら再構築する$a$そして$b$を表す換算分数として$x$。 

これにより、各テスト ケースが定数時間の算術演算と二乗チェックに削減されます。

 ## アルゴリズムのチュートリアル

 1. 判別式を計算する$D = p^2 - 4q^2$。 この値によって、比率の実解が存在するかどうかが決まります。 もし$D < 0$、本物ではありません$x$が存在するため、この方程式を満たす整数のペアはありません。 
2. かどうかを確認します。$D$は完全な正方形です。 させて$s = \sqrt{D}$。 もし$s \cdot s \neq D$、二次方程式は合理的な解をもたらさないので、答えは不可能です。 
3. 比率の 2 つの候補解を計算します。$$x = \frac{p + s}{2q}, \quad x = \frac{p - s}{2q}.$$正の値のみが有効です。$a$そして$b$は正の整数であるため、正でない候補は破棄されます。 
4. 選択した有理数を変換します$x$換算された分数に$x = \frac{A}{B}$分子と分母を gcd で割ることによって。 
5.セット$a = A$そして$b = B$。 これらは比率に直接対応します$a/b = x$となり、元の方程式が自動的に満たされます。 
6. 出力$a$そして$b$。 

### なぜ効果があるのか

 変換により、元の対称式が比率の 2 次式に縮小されます。$x = a/b$。 有効な整数のペアは有理数を誘導します。$x$逆に、二次方程式の有理根は整数にスケールできます。$a$そして$b$。 判別条件により、二次方程式が有理根を持つことが保証され、分数を減らすことで、範囲内で有効な整数表現が得られることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def solve():
    t = int(input())
    for _ in range(t):
        p, q = map(int, input().split())

        D = p * p - 4 * q * q
        if D < 0:
            print(0, 0)
            continue

        s = math.isqrt(D)
        if s * s != D:
            print(0, 0)
            continue

        # try both signs
        found = False
        for sign in (1, -1):
            num = p + sign * s
            den = 2 * q
            if num <= 0:
                continue

            g = math.gcd(num, den)
            a = num // g
            b = den // g

            if a > 0 and b > 0 and a <= 10**9 and b <= 10**9:
                print(a, b)
                found = True
                break

        if not found:
            print(0, 0)

if __name__ == "__main__":
    solve()
```コードは、代数条件を直接判別チェックに変換することから始まります。 平方根は、浮動小数点の精度の問題を回避するために、整数演算を使用して計算されます。 

有効な正の比率が得られるのは 1 つだけであるため、両方の二次根がテストされます。 各候補は gcd を使用して正規化され、有効な整数のペアが生成されます。$(a,b)$最小限の表現で。 境界チェックにより、構築されたペアが問題の制約を遵守していることが保証されます。 

微妙な点は、有効な合理的解が存在する場合でも、根の 1 つが負になる可能性があるため、明示的に除外する必要があることです。

 インプットを考慮する$p=5, q=2$。 判別式は$$D = 25 - 16 = 9.$$| ステップ | 値 |
 | --- | --- |
 | p | 5 |
 | q | 2 |
 | D | 9 |
 | s | 3 |
 | 候補 1 | (5 + 3) / 4 = 2 |
 | 候補 2 | (5 - 3) / 4 = 0.5 (無効) |

 有効な比率は次のとおりです。$x = 2 = 2/1$、 それで$a = 2, b = 1$削減後。 これは以下に対応します$2/1 + 1/2 = 5/2$。 

次に、次のような不可能なケースを考えてみましょう。$p=1, q=3$。 

| ステップ | 値 |
 | --- | --- |
 | p | 1 |
 | q | 3 |
 | D | 1 - 36 = -35 |

 判別式が負であるため、実際の比率は存在せず、式を満たす整数のペアは存在しません。 

これらのトレースは、実現可能性が判別式によって完全に決定され、有効な解が二次根から直接得られることを示しています。

 ## 特殊なケース

 重要なエッジ ケースは、判別式が 0 の場合に現れます。 例えば、$p = 2q$につながる$D = 0$、単一の繰り返されるルートを生成します$x = p/(2q) = 1$。 アルゴリズムはこれをきれいに処理します。$s = 0$、および候補建設の収量$a = b$、これは有効です。 

マイナス分岐の計算された分子がゼロになる場合、別のエッジ ケースが発生します。 たとえば、次の場合$p = 4q$、 それから$p - s = 0$、これは正の比率を生成しないため、破棄する必要があります。 符号フィルタリングのステップにより、そのような場合は有効なルートにフォールバックするか、有効なルートが存在しない場合には正しくゼロが出力されるようになります。 

最後の微妙なケースは、有理根が存在するが、境界チェックを超えて単純化される場合です。 両方なので$a$そして$b$gcd を使用して削減すると、有効な解が元の制約内に存在する場合、結果の値は常に許容範囲内に収まり、隠れたオーバーフローやスケーリングの問題が発生しないことが保証されます。
