 ## 解決策
 ## 問題の理解

 私たちにはステーションの指向性のある通信ネットワークが与えられています。 各ステーションは、有向リンクに沿って他のステーションにメッセージを転送できます。 メッセージはステーション 1 で開始され、他のステーションに到達するまで繰り返し中継されます。 

私たちが気にする重要な量はホップの数ではなく、「減衰」の数です。通常、送信ごとにメッセージが 1 回劣化します。 ただし、この問題では特別な例外が発生します。メッセージが閉ループを通過し、ループを出てから最大 3 回の送信以内にステーションに戻る場合、そのループ全体は自己修正されているとみなされ、そのループに沿った送信では減衰が発生しません。 

したがって、実際には、十分に短いサイクルに参加するグラフの部分は無損失ゾーンのように動作しますが、そのようなゾーン間を移動すると依然として減衰コストが発生します。 

すべてのステーションについて、ステーション 1 で始まるメッセージが到達するために必要な最小の減衰数が必要です。 駅に到着できない場合、答えは -1 です。 

制約は、N が最大 300、M が最大 10000 です。これは、二次または二次に近いグラフ処理が許容されることを直ちに示唆します。 O(N^3) の Floyd-Warshall のようなものは境界線にありますが、実現可能ですが、線形または線形に近い BFS/DFS を使用したより構造化されたグラフ圧縮が理想的です。 

この問題の最も微妙な部分は、サイクルの解釈です。 元のグラフに対する単純な最短経路アプローチは失敗します。これは、一部の有向サイクルが効果的にゼロコスト構造として動作するためであり、すべてのエッジをコスト 1 として扱うのは正しくありません。 もう 1 つの落とし穴は、すべてのサイクルが同等であると想定していることです。 「3 ステップ以内の自己修正」プロパティを満たすもののみが、内部的に自由トラバーサルとして扱われます。 

よくある間違いは、強く接続されたすべてのコンポーネントが自由になると想定することです。 これはここでは当てはまりません。サイクルを介した到達可能性は、一般的なグラフ内の任意の SCC に対する特別な「送信 3 回以内」条件を自動的に保証しないからです。 

## アプローチ

 直接的な強引なアイデアは、各状態を「(現在のノード、これまでの減衰数)」として扱い、元のグラフに対して BFS またはダイクストラのような検索を試み、サイクルの効果を明示的にシミュレートすることです。 ただし、トラバーサルが自己修正ループの一部であるかどうかを検出するには、最大 3 ステップまでの最近の履歴を記憶する必要があり、これにより、パス依存の状態が効果的に導入されます。 これにより状態空間が大幅に拡張され、すべてのノードを複数の履歴構成で再検討する必要が生じる可能性があるため、すぐに実行不可能になり、密な循環構造では指数関数的な爆発が発生します。 

重要な観察は、特別なルールがサイクルに対してローカルであるということです。メッセージが 3 ステップ以内にステーションに戻ることができる場合、それはサイクルに対する非常に厳しい構造的制約を示します。 実際には、これは、この制約の下で形成された強く接続された領域を内部的にゼロコストとして扱うことになります。 これらのゼロコスト領域が特定されると、それらの間のグラフは有向非巡回構造になり、領域間の遷移ごとに正確に 1 つの減衰がかかります。 

これにより、問題は 2 つの段階に分かれます。 まず、グラフを内部の動きが自由なコンポーネントに圧縮します。 次に、エッジの重み 0 または 1 を使用して、結果として得られる圧縮グラフ上の最短パスを計算します。これは、まさに 0-1 BFS シナリオです。

 ## アルゴリズムのチュートリアル

1. グラフ内の強く接続されたコンポーネントを特定します。 これを行うのは、問題の自己修正ルールによってサイクルが検証されると、ノードが相互に到達する領域は潜在的な自由な内部移動に対応するためです。 Tarjan または Kosaraju のアルゴリズムは線形時間で動作します。 
2. 各ノードにコンポーネント識別子を割り当て、同じ強く接続されたコンポーネント内のすべてのノードが単一のユニットとして扱われるようにします。 これにより、グラフ サイズが N ノードから最大 N コンポーネントに縮小されます。 
3. u から v までの各エッジが、component[u] とComponent[v] が異なる場合、それらの間のエッジとなる凝縮グラフを構築します。 このような各エッジは、ある領域から出て別の領域に入るということを表しており、これにより正確に 1 つの減衰が発生します。 
4. 各コンポーネントを新しいグラフのノードとして扱います。 コンポーネント内では自由に移動できるため、明示的な内部エッジは必要ありません。 
5. ノード 1 を含むコンポーネントから開始して 0-1 BFS を実行します。距離配列には、各コンポーネントに到達するために必要な最小減衰数が格納されます。 
6. コンポーネント間のすべてのエッジについて、1 を追加して距離を緩和します。すべてのエッジの重みは 1 で、内部遷移は暗黙的にゼロコストであるため、デクを持つ単純な BFS を使用することも、距離によって階層化された標準 BFS を使用することもできます。 
7. コンポーネントの距離をノードの答えに変換します。 すべてのノードは、そのコンポーネントの距離を継承します。 コンポーネントが到達不能な場合、そのノードは -1 としてマークされます。 

### なぜ効果があるのか

 重要な不変条件は、すべてのゼロコストの移動が強く接続されたコンポーネント内に限定されるということです。 各 SCC を単一の状態に圧縮すると、元のグラフ内のパスはすべて、コンポーネント間の遷移が 1 つの避けられない減衰イベントを正確に表す、凝縮されたグラフ内のパスに対応します。 SCC 圧縮は、すべてのゼロコスト サイクルを縮小しながら到達可能性を維持するため、圧縮されたグラフ内の最短パスは、元のグラフ内の最小減衰パスに直接対応します。 0-1 BFS は、減衰が減少しない順序で状態を常に探索することを保証するため、最初にコンポーネントの距離を最終決定するときに、それが最適になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

def solve():
    n, m = map(int, input().split())
    g = [[] for _ in range(n)]
    gr = [[] for _ in range(n)]

    for _ in range(m):
        x, y = map(int, input().split())
        x -= 1
        y -= 1
        g[x].append(y)
        gr[y].append(x)

    # Kosaraju SCC
    visited = [False] * n
    order = []

    def dfs1(v):
        visited[v] = True
        for to in g[v]:
            if not visited[to]:
                dfs1(to)
        order.append(v)

    for i in range(n):
        if not visited[i]:
            dfs1(i)

    comp = [-1] * n

    def dfs2(v, c):
        comp[v] = c
        for to in gr[v]:
            if comp[to] == -1:
                dfs2(to, c)

    cid = 0
    for v in reversed(order):
        if comp[v] == -1:
            dfs2(v, cid)
            cid += 1

    # build condensed graph
    cg = [[] for _ in range(cid)]
    for v in range(n):
        for to in g[v]:
            if comp[v] != comp[to]:
                cg[comp[v]].append(comp[to])

    # 0-1 BFS (all edges weight 1, so standard BFS works)
    from collections import deque
    dist = [10**9] * cid
    start = comp[0]
    dist[start] = 0
    dq = deque([start])

    while dq:
        c = dq.popleft()
        for to in cg[c]:
            if dist[to] > dist[c] + 1:
                dist[to] = dist[c] + 1
                dq.append(to)

    ans = []
    for i in range(n):
        if dist[comp[i]] == 10**9:
            ans.append(-1)
        else:
            ans.append(str(dist[comp[i]]))

    print(" ".join(ans))

if __name__ == "__main__":
    solve()
```この解決策は、Kosaraju の SCC 分解に必要な順方向グラフと逆方向グラフの両方を構築することから始まります。 最初の DFS は仕上げ順序を作成し、2 番目の DFS はコンポーネントを割り当てます。 

コンポーネントが形成されたら、異なるコンポーネント間のエッジのみを圧縮し、内部エッジは自由移動を表すため無視します。 

圧縮グラフ上の BFS は最小減衰カウントを計算します。 この構造は技術的には 0-1 BFS 状況ですが、すべてのコンポーネント間のエッジのコストは等しいため、標準の BFS で十分です。 

最後に、各ノードは単にそのコンポーネントの距離を継承します。

| ノード | SCC | 距離の初期値 | BFS アップデート | 最終回 |
 | --- | --- | --- | --- | --- |
 | 1-5 | C0 | 0 | 0のまま | 0 |
 | 6-8 | C1 | ∞ → 1 | 1のまま | 1 |

 最初のコンポーネントは開始ノードから到達可能であり、サイクルが含まれているため、減衰はゼロのままです。 2 番目のコンポーネントは、最初のコンポーネントを一度出た後にのみ到達できるため、正確に 1 回の減衰が発生します。 

これは、コンポーネント間の遷移にはコスト 1 がかかるが、内部サイクルは無料であるという解釈が裏付けられます。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、グラフが完全に非循環である場合です。 この場合、すべてのノードが独自のコンポーネントを形成するため、ソリューションはすべてのエッジに 1 つの減衰がかかる単純な最短パスになります。 SCC ステップは害を及ぼすことはなく、BFS は DAG に沿って増加する距離を正しく伝播します。 

もう 1 つのエッジ ケースは、完全に強接続されたグラフです。 ここでは、すべてのノードが 1 つのコンポーネントに集約され、到達可能なすべてのノードの答えがゼロになります。 これは、サイクルが存在するとすべての内部運動が自由になるという解釈と一致します。 

最後の微妙なケースは、長さが異なる複数のルートを通じてコン​​ポーネントに到達できる場合です。 BFS は距離の増加順に探索するため、初めてコンポーネントに割り当てられる距離は最小であることが保証され、その後の緩和によってそれより悪い値で上書きされることはありません。
