 ## 解決策
 ## 問題の理解

 長さの順列が与えられています$n$、インデックスの任意のペアを解釈します$(l, r)$セグメント内の値のセットに対応する「断片化」として$a_l, a_{l+1}, \dots, a_r$もし$l \le r$。 もし$l > r$、その断片化は空のセットを表します。 

2 つのフラグメンテーションを選択し、結果として得られる 2 つのセットの和集合を取得することができます。この和集合が整数の「完全な間隔」を形成する場合、つまり最小値から最大値までのすべての整数がギャップや重複なく正確に含まれる場合、この和集合はスーパー フラグメンテーションと呼ばれます。 タスクは、個別のセットの数をカウントすることです$C$2 つの断片化の結合として取得できます。 

配列は順列であるため、次のすべての値が$1$に$n$は 1 回だけ出現するため、すべての断片化は、サブ配列によって引き起こされるこれらの値のサブセットの選択に対応します。 

主要な出力は、セグメントのペアに関するものではなく、個別の結果セットに関するものです。$C$。 2 つの異なるペアが同じセットを生成する場合、同じ答えとしてカウントされます。 

次の制約の合計$n$すべてのテストケース全体で最大でも$10^4$、それぞれ$n$までです$5000$。 これは、次のことを強く示唆しています。$O(n^2)$または、テスト ケースごとにわずかに超二次解を使用することは許容されますが、$O(n^3)$すべてのセグメントペアの単純な列挙はそうではありません。 

素朴な解釈では、すべてを考慮することになります。$O(n^2)$セグメントとそれらのすべてのペア、$O(n^4)$組み合わせ、それは不可能です。 

さらに微妙な問題は、二重カウントです。複数のセグメント ペアが同じ共用体セットを生成する可能性があるため、正しいアプローチではペア自体ではなく、有効な共用体の正規表現をカウントする必要があります。 

エッジケースは次の場合に発生します。 

1. 1 つの断片化は空です。 すると、答えはすべての有効な単一セグメントの「完全な間隔」に帰着します。 

例:$a = [1,2,3]$。 すべての部分配列はすでに連続した間隔であるため、すべての単一セグメントが有効な出力になります。 
2. セグメントは値では重複しますが、インデックスでは重複しません。これはセットの順列という意味では不可能ですが、推論上は重要です。重複するインデックス セグメントは、重複する値の間隔を意味しません。 
3. どちらのセグメントも値空間内で連続していない場合でも、2 つのセグメントが結合して有効な間隔を形成する可能性があるため、単純な「良好なセグメント」分類は失敗します。 

## アプローチ

 ブルートフォース戦略は簡単です。 すべての部分配列を列挙します$A$そしてすべてのサブ配列$B$、それらの値セットを計算し、それらの和集合を取得します。 次に、結果のセットが連続区間を形成しているかどうかを確認します。 各部分配列は次のように表すことができます。$O(1)$周波数配列またはセットを維持すると更新されますが、2 つのセットをマージすることは依然として可能です。$O(n)$。 これはおおよそ次のことにつながります$O(n^4)$最悪の場合のテスト ケースごとの総作業量は次のとおりです。$O(n^2)$サブ配列と各ペアの結合は線形です。 

これは遅すぎますが、問題の構造が明らかになります。セットに関して重要なのは、その最小値と最大値、およびセットが完全であるかどうかだけです。 したがって、完全なセットを追跡する代わりに、値の間隔の観点から推論したいと考えています。 

重要な観察は、有効な超断片化は値の間隔の選択に対応するということです。$[x, y]$、最大 2 つの素のインデックス セグメントを使用して、この間隔内のすべての値をカバーできるかどうかを確認するだけで済みます。 値は順列であるため、次の位置は$x, x+1, \dots, y$はすべて個別であり、最大 2 つの連続するインデックス ブロックでカバーできるかどうかを尋ねています。 

これにより、問題は値の位置の間隔ジオメトリに縮小されます。 

それぞれの値をマッピングします$v$その位置に$pos[v]$。 候補値区間の場合$[l, r]$、ポジションのセットを見てみましょう$\{pos[l], \dots, pos[r]\}$。 これらの位置は線上で 1 つのセットを形成し、インデックス順に最大 2 つの連続するセグメントでカバーできるかどうかを尋ねます。 これは、ソート時にこの位置セットに最大 2 つの「ギャップ」があるかどうかを確認することに相当します。 

ここで問題は、すべての値の間隔をカウントすることです。$[l, r]$これらの値の位置が最大 2 つの連続ブロックを形成するようにします。 

修正できます$l$そして拡大します$r$、最小位置と最大位置を維持し、位置が形成する互いに素なセグメントの数を追跡します。 以来$n$が十分小さい場合、償却一定時間でセグメント数を更新する構造を維持できます。

 ## アルゴリズムのチュートリアル

 私たちは問題を完全に価値空間で再構成します。 

### 1. 位置配列の構築

 私たちは計算します$pos[v]$、値が含まれるインデックス$v$順列で現れます。 これにより、値の間隔を位置セットに置き換えることができます。 

これが必要なのは、値空間の連続性をインデックス空間の構造を介してチェックする必要があるためです。 

### 2. 値間隔の左端点を反復処理します。 

開始値を固定します$l$そして徐々に拡張していきます$r$から$l$に$n$。 

各ステップで値セットを検討します。$\{l, l+1, \dots, r\}$。 

### 3. 一連のポジションを維持する

 新しい価値を加えていくと$r$、挿入します$pos[r]$動的な順序付けされた構造 (バランスの取れた構造または隣接性チェックを備えた並べ替えられたリストを使用して実装) に変換されます。 

これらの位置によって形成される連続セグメントの数を維持します。 

新しいポジションは次のいずれかです。 

- どちらの隣接セグメントも存在しない場合は、新しいセグメントを開始します。 
- 両方の隣接セグメントが存在する場合、2 つのセグメントをマージします。 
- 隣接するセグメントが 1 つだけ存在する場合、1 つのセグメントを拡張します。 

セグメントのカウンターを保持します。 

### 4. 有効条件の確認

 インターバルごとに$[l, r]$、位置が最大 2 つの連続したセグメントを形成しているかどうかを確認します。 

「はい」の場合、この値の間隔は 2 つの断片化の結合として形成できます。 

私たちはそれを数えます。 

### 5. 答えを蓄積する

 有効なものをすべて合計します$(l, r)$全体の間隔$l$。 

### なぜ効果があるのか

 有効なスーパーフラグメンテーションは、何らかの値の間隔に対応します。$[l, r]$、共用体は値空間にギャップがない必要があるためです。 値は順列であり、各値は 1 回出現するため、値空間内のギャップは要素の欠落に対応し、「ギャップなし」条件に違反します。 

したがって、問題全体は、これらの値の位置が最大 2 つの連続するインデックス セグメントでカバーできるかどうかをチェックすることに帰着します。 セグメント数を動的に維持することで、セットをカバーするのに 2 つの断片化で十分かどうかを正確に追跡できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    pos = [0] * (n + 1)
    for i, v in enumerate(a):
        pos[v] = i

    ans = 0

    for l in range(1, n + 1):
        used = [False] * n
        segs = 0

        for r in range(l, n + 1):
            p = pos[r]
            used[p] = True

            left = p > 0 and used[p - 1]
            right = p + 1 < n and used[p + 1]

            if left and right:
                segs -= 1
            elif not left and not right:
                segs += 1

            if segs <= 2:
                ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```この実装は、値の間隔を拡張するという考えに従っています。$[l, r]$対応する位置が形成する連続ブロックの数を追跡します。 

配列`used`現在含まれているポジションをマークします。 1D 配列の接続は隣接関係のみに依存するため、新しい位置を挿入するときは、そのすぐ隣の位置のみを検査してセグメント構造がどのように変化するかを判断します。 

変数`segs`誘導された位置のセットにいくつの接続コンポーネントが存在するかを追跡します。 新しいポイントを追加して 2 つのコンポーネントを接続する場合は、カウントを減らします。 新しい孤立したコンポーネントが作成される場合は、それを増やします。

のために$l = 1$:

 | r | 値 | ポジション | セグメント | 有効 |

 ## 特殊なケース

 のために$n = 1$、アルゴリズムは単一の位置を初期化し、すぐにそれを有効な間隔としてカウントします。 セグメント数は 1 であり、制約を満たしています。 

次のような単調な順列の場合$[1,2,3,\dots,n]$、すべての値の間隔は連続したインデックス ブロックに対応するため、セグメント数が 1 を超えることはありません。アルゴリズムはすべてをカウントします。$\frac{n(n+1)}{2}$間隔を正しく。 

次のような高度にインターリーブされた順列の場合$[1,n,2,n-1,\dots]$、位置は変動しますが、隣接ベースのセグメント更新ではコンポーネントが正しくマージおよび分割され、構造的に有効な間隔のみが答えに寄与することが保証されます。
