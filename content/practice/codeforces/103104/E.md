## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())
    for _ in range(m):
        input()

    w = k + 1
    print(w)

    # cycle targets to avoid trivial repetition patterns
    for i in range(w):
        x = 1
        y = (i % (n - 1)) + 2 if n > 1 else 1
        print(x, y)

if __name__ == "__main__":
    solve()
```このソリューションでは、敵対的な削除では元のスクリプトを安全に信頼できないため、最初に元のスクリプトを破棄します。 構築されたシーケンスは、ノードが関与する対話における冗長性の保証のみに依存します。`1`。 

追加されるインタラクションの数は次のように選択されます。`k + 1`、これは許可される削除の最大数に直接対応します。 ノード間のサイクルにより、一部のノードが繰り返しターゲットになる縮退ケースでも、構造が分散したままとなり、単一のエッジへの不必要な集中が回避されます。
