 ## 解決策
 ## 問題の理解

 一連の平面点が与えられ、課題はこれらの点によって形成される「美しい角度のペア」を推論することです。 ステートメント内のソリューションの概要は、私たちが関心を持っている構造が直接完全な点セットではなく、点の凸包、そして連続する包頂点によって形成される角度であることを示唆しています。 

幾何学的用語で言えば、すべての内部点を削除して凸包だけを残すと、各頂点は包に沿った 2 つの隣接するエッジによって形成される角度に寄与します。 これらの角度から、ベクトル演算から導出された数値をそれぞれに割り当てます。通常は、方向と内積を取得するために外積を使用するか、角度の大きさを回復するために導出された三角関数の関係を介して行われます。 このような角度をすべて計算した後、これらの角度のすべてのペアを考慮し、角度の値自体にのみ依存する特定の「美しさ」条件を満たすペアの数を数えるよう求められます。 

制約の主な意味は、このような幾何学問題では、初期の点の数が大きくなる可能性があり (通常は最大 10^5 程度)、しかし凸包のサイズははるかに小さく、せいぜい点の数が線形であり、実際にはかなり小さくなることがよくあります。 元の点のすべてのペアで動作しようとするアルゴリズムは、最悪の場合、すぐに二次関数になり、失敗します。 問題をハル処理に落とし込み、ハルの頂点で O(k^2) で機能する解決策は、k が適切に制限されている場合、または定数因数が十分に小さい場合に実行可能になります。 

すべての点から角度のペアを直接計算しようとする素朴な幾何学的なアプローチは、すべての点のトリプルを構築することさえすでに O(n^3) の動作を暗示しているため、失敗します。 元のセットに対する O(n^2) の角度ペアの列挙でも大きすぎます。 

エッジ ケースは、すべての点が同一線上にある場合、凸包がセグメントに縮退する場合、または複数の点が一致する場合に発生します。 入力点 (0,0)、(1,0)、(2,0) のような同一直線上の例では、凸包には 2 つの点しかなく、有効な角度は存在しません。 少なくとも 3 つのハル頂点を想定した不注意な実装では、無効な近傍にアクセスしようとします。 もう 1 つのエッジ ケースは、点が同一線上の境界点を繰り返して完全な多角形を形成する場合に発生します。これにより、ハルの重複排除が適切に処理されない場合、角度の計算が歪む可能性があります。 

## アプローチ

 この強引なアイデアは、すべての 3 つの点を考慮し、中間点で形成される角度を計算し、そのような角度のすべてのペアを比較して、必要な条件を満たしているかどうかを確認することです。 これは、すべての幾何学的構成を明示的に列挙するため、概念的には正しいですが、計算的には実行不可能です。 n 点の場合、O(n^3) 個のトリプルがあり、結果の角度をすべて比較するとさらに O(n^2) が追加されるため、n が数千程度であっても使用できなくなります。 

重要な観察は、凸包の頂点のみが重要であるということです。 内部点は境界角に寄与せず、極値の角構造に影響を与えることはできません。 船体が構築されると、問題のサイズは n から k に減少します。ここで、k は船体のサイズです。 ハルの各頂点について、その角度は 2 つの隣接するエッジを使用して計算できます。 各角度はローカル構造のみに依存するため、ハルを前処理した後、頂点ごとに O(1) で計算できます。 

すべての角度を取得した後、問題はこれらの k 値の間で有効なペアを数えることになります。 k は通常、n よりもはるかに小さく、多くの場合数千以内であるため、O(k^2) 列挙が許容されます。 各ペアについて、ベクトル演算から導出された角度測度の単純な算術を使用して、結合された角度が必要な条件を満たすかどうかを計算します。

ブルートフォースから最適解への移行は、幾何学的圧縮ステップによって完全に推進されます。つまり、密な点セットを疎な凸包表現に置き換えます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n) | 遅すぎる |
 | 凸包 + ペアの列挙 | O(n log n + k^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 まず、グラハム スキャンまたは同等の単調連鎖法を使用して、指定された点の凸包を計算します。 このステップにより、境界点を反時計回りの順序でのみ処理することが保証されます。 

次に、凸包を周期的に走査します。 各頂点 i について、ハル上の前後の頂点を取得し、i に付随するエッジを表す 2 つのベクトルを形成します。 これら 2 つのベクトルを使用して、頂点 i での角度を計算します。 外積は回転の方向と大きさの正弦を与え、内積は余弦を与え、atan2 を使用して安定した角度の測定値を回復することができます。 

計算された各角度を配列に保存します。 この配列は、ソリューションの第 2 フェーズのすべての幾何学的な「構成要素」を表します。 

次に、順序のないすべての角度のペアを反復処理します。 各ペアについて、問題の条件に応じて有効な「美しいペア」を形成しているかどうかを確認します。これは、角度尺度の組み合わせに依存します。 チェックは、保存された角度値に対する直接演算を使用して行われ、ジオメトリの再計算を回避します。 

最後に、すべての有効なペアの数を累積し、結果を出力します。 

これが機能する理由は、凸包の頂点が点セットの境界ジオメトリを完全にエンコードしているという事実に基づいています。 必要な構成に寄与できる角度は船体の頂点に現れる必要があり、各頂点で計算される値はローカルな隣接関係のみに依存するため、内部構造には依存しません。 次に、これらの独立した幾何学的量の完全なマルチセットにわたってペアワイズ条件が評価され、有効な構成が欠落したり、無効な構成が導入されたりしないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import atan2

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

def dot(ax, ay, bx, by):
    return ax * bx + ay * by

def convex_hull(points):
    points = sorted(set(points))
    if len(points) <= 1:
        return points

    lower = []
    for x, y in points:
        while len(lower) >= 2:
            x1, y1 = lower[-2]
            x2, y2 = lower[-1]
            if cross(x2 - x1, y2 - y1, x - x2, y - y2) <= 0:
                lower.pop()
            else:
                break
        lower.append((x, y))

    upper = []
    for x, y in reversed(points):
        while len(upper) >= 2:
            x1, y1 = upper[-2]
            x2, y2 = upper[-1]
            if cross(x2 - x1, y2 - y1, x - x2, y - y2) <= 0:
                upper.pop()
            else:
                break
        upper.append((x, y))

    return lower[:-1] + upper[:-1]

def angle(p1, p2, p3):
    v1x, v1y = p1[0] - p2[0], p1[1] - p2[1]
    v2x, v2y = p3[0] - p2[0], p3[1] - p2[1]
    c = cross(v1x, v1y, v2x, v2y)
    d = dot(v1x, v1y, v2x, v2y)
    return atan2(abs(c), d)

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    hull = convex_hull(pts)
    k = len(hull)

    if k < 3:
        print(0)
        return

    ang = []
    for i in range(k):
        p = hull[i]
        p_prev = hull[(i - 1) % k]
        p_next = hull[(i + 1) % k]
        ang.append(angle(p_prev, p, p_next))

    ans = 0
    for i in range(k):
        for j in range(i + 1, k):
            if abs(ang[i] + ang[j] - 3.141592653589793) < 1e-9:
                ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、まず単調チェーン構造を使用して凸包を構築します。 これにより、ハルの頂点がソートされ、反時計回りの順序で閉じた多角形を形成することが保証されます。 angle 関数は、2 つの隣接するエッジを使用して頂点の内角を計算し、外積とドット積を含む atan2 を使用して安定した浮動小数点表現に変換します。 

船体の頂点上の二重ループで、最終的なカウントが行われます。 幾何学的な角度の計算は正確な等しいことに依存できないため、比較では浮動小数点精度の問題を処理するために許容誤差が使用されます。 

微妙な点は、船体のポイントが 3 つ未満である縮退ケースの処理です。 このような場合、角度は存在しないため、答えはゼロになるはずです。 

## 実用的な例

 単純な正方形: (0,0)、(1,0)、(1,1)、(0,1) を考えてみましょう。 凸包はすべて 4 点です。 

| 私 | 前へ | カレ | 次へ | 角度 (rad) |
 | --- | --- | --- | --- | --- |
 | 0 | (0,1) | (0,0) | (1,0) | π/2 |
 | 1 | (0,0) | (1,0) | (1,1) | π/2 |
 | 2 | (1,0) | (1,1) | (0,1) | π/2 |
 | 3 | (1,1) | (0,1) | (0,0) | π/2 |

 すべてのペアの合計は π になるため、6 つのペアすべてがカウントされます。 

これは、アルゴリズムが対称凸多角形全体に均等に分布する相補的な角度を正しく識別していることを確認します。 

ここで、三角形 (0,0)、(2,0)、(1,1) について考えてみましょう。 すべての角度は π 未満であり、それらのペアごとの合計が π に達することはありません。 

| 私 | 角度 |
 | --- | --- |
 | 0 | >0 |
 | 1 | >0 |
 | 2 | >0 |

 条件を満たすペアがないため、答えは 0 になります。 

これは、アルゴリズムが最小限の構成ではオーバーカウントしないことを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n log n + k^2) | 凸包構築は n log n を支配し、ペアの列挙は包サイズ k | で実行されます。 
| スペース | O(n) | ポイントとハル頂点のストレージ |

 ハル サイズ k は最大でも n ですが、通常ははるかに小さく、二次ステップは大幅な幾何学的縮小後にのみ適用されます。 これにより、ソリューションは標準の Codeforce 制約の制限内に十分に収まるようになります。

 ## 特殊なケース

 すべての点が同一線上にある場合、凸包は 2 点に崩壊し、アルゴリズムはすぐにゼロを返します。 これにより、ハル サイクル上に存在しない近傍にアクセスしようとする無効な角度計算が回避されます。 

船体に正確に 3 つの点がある場合、構造は三角形であり、すべての頂点の角度が明確に定義されていますが、どの角度のペアも縮退せずに合計が π になることはできないため、最後のループではゼロが生成され、幾何学的直観と​​一致します。 

複数のポイントが同じ座標を共有する場合、凸包構築の重複排除ステップにより、人工的な長さ 0 のエッジが作成されないことが保証されます。 これにより、ドットおよびクロス計算でのゼロ除算が防止され、角度値が安定した状態に保たれます。
