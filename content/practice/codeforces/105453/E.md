 ## 解決策
 ## 問題の理解

 私たちには完全に指定された島のネットワークが与えられており、すべての島に発電機を建設するか、最終的に発電機を備えた他の島に送電線を介して接続することで電力を供給できます。 各島には発電機を建設するための直接コストがかかり、島のペアごとに送電線に接続するためのコストがかかります。 

目標は、建設の総コストを最小限に抑えながら、すべての島に電力が供給されるように、どの島に発電機を設置するか、どの送電線を建設するかを同時に決定することです。 

この要件を言い換えると、発電機が設置されている少なくとも 1 つの「ソース」アイランドへの経路がすべてのアイランドに必要であるという便利な方法になります。 そのソースは、それ自体であることも、構築された接続を通じて到達可能な別のアイランドであることもできます。 

入力サイズは最大 1000 個のアイランドに達し、アイランドの各ペアには定義された接続コストがあるため、コスト構造は高密度になります。 これにより、サブセットの数が指数関数的に増加するため、ジェネレーターを配置するためにアイランドのサブセットを明示的に列挙しようとするアプローチは即座に除外されます。 サブセットにわたる二次または三次解さえも不可能です。 

1000 個のノードと完全なグラフを使用すると、自然なターゲットの複雑さは O(N^2) または O(N^2 log N) 程度になります。 O(N^3) 以上のものはタイムアウトになる可能性があります。 これは、この問題を組み合わせ選択問題ではなくグラフ最適化問題として再解釈する必要があることを強く示唆しています。 

ジェネレータの配置とエッジの構築を別々に処理しようとすると、素朴な推論による微妙な失敗例が現れます。 たとえば、最初に安価なアイランドに発電機を貪欲に構築し、次に最短のエッジを使用してすべてを接続すると、わずかに高価な発電機の配置によって多くの高価なエッジを回避できる、より優れたグローバル構造を見逃す可能性があります。 

## アプローチ

 強引な解釈では、発電機を配置するアイランドのサブセットを選択し、残りのアイランドについて、伝送線を使用してそれらを少なくとも 1 つの発電機に接続するコストを計算します。 各サブセットについて、これは重み付きグラフ上の最短接続問題に帰着しますが、島のすべてのサブセットを試す必要があり、これによりすでに 2^N の可能性が生じます。 1 つのサブセットの接続性の計算が O(N^2) だったとしても、N = 1000 では合計作業量が指数関数的に増加し、完全に実行不可能になります。 

重要な観察点は、問題の構造は最小スパニング ツリーの構築とまったく同じですが、エッジ コストの代わりにノード コストを支払うという「仮想オプション」が追加されていることです。 外部電源を表す仮想スーパーノードを導入すると、アイランド x をこのスーパー ノードに直接接続するとコスト p(x) がかかり、2 つのアイランド x と y を接続するとコスト c(x,y) がかかります。 このように考えると、すべての有効なソリューションは N+1 ノード上のスパニング ツリーに対応し、スーパー ノードはジェネレーターをホストするアイランドに正確に接続されます。 

したがって、最適解は単にこの拡張されたグラフの最小スパニング ツリーになります。 追加のノードを明示的に構築する代わりに、各ノードの接続コストを生成コストとして初期化し、伝送線を使用して段階的に緩和することで、その効果を Prim のアルゴリズムに組み込むことができます。 

ブルート フォースは、ジェネレータの配置を個別の組み合わせの決定として扱うため失敗しますが、正しい構造では、両方の決定が単一のスパニング ツリー問題のエッジ選択として統合されていることを示します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ジェネレーターのサブセットに対するブルート フォース | O(2^N · N^2) | O(N^2) | 遅すぎる |
 | 最小スパニング ツリー (プリム) | O(N^2) | O(N^2) | 承認済み |

 ## アルゴリズムのチュートリアル

この問題を、N 個のアイランドにわたる最小スパニング ツリーを計算するものとして再解釈します。各アイランドには、発電機のコストと等しいコストを持つ仮想電源への暗黙的な接続もあります。 

1. 距離配列を初期化します。ここで、dist[x] は、島 x をすでに構築されているネットワークに接続する既知の最も安価な方法を表します。 当初、これは単に x 上にジェネレーターを構築するコストです。 
2. どのアイランドが既にネットワークに永続的に追加されているかを追跡するために、訪問済みアレイを維持します。 
3. 現在の dist 値が最小の未訪問の島を繰り返し選択します。 この選択は、そこに発電機を構築するか、以前に追加したアイランドを介して最適に接続するかのいずれかに対応します。 
4. 島を選択したら、その距離の値を合計コストに追加し、訪問済みとしてマークします。 
5. 島 u を追加した後、伝送路コスト c(u, v) を使用して、他のすべての未訪問の島 v の接続コストの改善を試みます。 c(u, v) が現在の dist[v] より安い場合、それを更新します。 
6. すべての島が含まれるまでこのプロセスを繰り返します。 

重要な考え方は、dist[v] が常に、ジェネレーターを直接構築するか、すでに接続されているアイランドを介して接続するかにかかわらず、成長するネットワークに v を接続する最も安価な方法を表すということです。 

### なぜ効果があるのか

 どの段階でも、訪問した島のセットは部分的に構築された最適なネットワークを形成します。 すべての未訪問のアイランドについて、 dist[v] は、仮想ソースへの暗黙的なエッジを含む、このセットに接続する最小コスト エッジです。 最小の dist 値の選択は、まさに最小スパニング ツリーのカット プロパティです。訪問ノードと未訪問ノードの間のカットを横切る最も安価なエッジは、何らかの最適なソリューションに属している必要があります。 これにより、すべての追加がローカルで最適でグローバルに一貫していることが保証され、サイクルが防止され、総コストが最小限に抑えられます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = [list(map(int, input().split())) for _ in range(n)]

    dist = [0] * n
    vis = [False] * n

    for i in range(n):
        dist[i] = a[i][i]

    total = 0

    for _ in range(n):
        u = -1
        best = 10**18

        for i in range(n):
            if not vis[i] and dist[i] < best:
                best = dist[i]
                u = i

        vis[u] = True
        total += dist[u]

        for v in range(n):
            if not vis[v]:
                if a[u][v] < dist[v]:
                    dist[v] = a[u][v]

    print(total)

if __name__ == "__main__":
    solve()
```このソリューションは、密なグラフ用に最適化された Prim のアルゴリズムの直接実装を使用します。 マトリックス`a`は、対角線上の発電機コストと対角線外の伝送コストの両方に再利用されます。 配列`dist`は各アイランドに発電機を構築するコストとして始まり、これは各ノードを仮想電源に接続する場合の解釈と一致します。 

メインループは、接続コストが最小の未訪問の島を繰り返し選択します。 これは単純な線形スキャンで行われ、N ≤ 1000 であれば許容されます。アイランドを選択した後、行列値を使用してそこからすべてのエッジを緩和します。 

よくある微妙な点は初期化です`dist`正しく。 ゼロまたは無限から始めると、常に伝送線路を選択するか、常に発電機を選択するかのどちらかにアルゴリズムが誤って偏ることになります。 対角線のエントリを使用すると、両方のオプションが均一に扱われることが保証されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(N^2) | N 回の反復のそれぞれが N 個のノードをスキャンし、N 個のエッジを緩和します。 
| スペース | O(N^2) | 完全なコスト行列が保存されます。 

N が最大 1000 の場合、O(N^2) ソリューションは約 10^6 の更新を実行しますが、これは制限時間内に問題なく収まります。

 ## 特殊なケース

 重要なエッジケースは、すべてのアイランドが接続するよりも個別に電力を供給する方が安価である場合です。 値が小さく、対角から外れたエントリが非常に大きい対角行列のような入力の場合、アルゴリズムは送信エッジを選択すべきではありません。 dist を対角値で開始すると、より安価な接続が表示されない限り (この場合は表示されません)、すべてのアイランドが事実上「自己給電」されることが保証されます。 

もう 1 つのケースは、送電料金が発電機よりも一律に安い場合です。 たとえば、対角線のエントリは大きくなりますが、非対角線のエントリは小さくなります。 このアルゴリズムは最初に 1 つのアイランドを選択し、その後、低エッジ コストを他のすべてのアイランドに迅速に伝播し、その結果、最初の暗黙的な決定を除くすべてのジェネレーターの決定を置き換える一連の接続が生成されます。 最終的なコストは、送信エッジのみを使用するスパニング ツリーのコストになります。 

最後の微妙なケースは、ジェネレーターがある領域に最適で、エッジが別の領域を支配する混合パターンが存在する場合です。 Prim のアルゴリズムにおけるカットベースの選択により、各決定が現在のフロンティアに対してローカルであることが保証されるため、明示的なクラスタリング ロジックを必要とせずに、コストに応じてリージョンが自然に分離されます。
