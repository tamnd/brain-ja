 ## 解決策
 ## 問題の理解

 数直線上の一連のセグメントが与えられます。 各セグメントにも値が含まれます$a_i$。 2 つのセグメントの間隔が少なくとも 1 点で重なっている場合 (端点での接触を含む)、2 つのセグメントは関連しているとみなされます。 2 つのセグメントが重なるときは常に、それらの間にあるエッジを想像します。その重みは、それらに関連する値の絶対差です。 

これは、頂点がセグメントであり、重なり合うセグメント間にのみエッジが存在する、無向加重グラフを定義します。 タスクは、このグラフの最小スパニング ツリーの合計重みを計算するか、グラフが切断されているためスパニング ツリーが存在しないと判断することです。 

制約により構造が非常に大きくなります。 まであります$5 \cdot 10^5$すべてのテスト ケースにわたるセグメント、およびエンドポイントは次のような大きさにすることができます。$10^9$。 これにより、交差するペア間のすべてのエッジを明示的に構築しようとするソリューションは即座に除外されます。これは、最悪の場合、すべてのセグメントが重なり、グラフが完全になるためです。$O(n^2)$エッジ。 

単純なクラスカルのアプローチでは、重複するペアをすべて列挙する必要がありますが、これは大規模には不可能です。 オーバーラップをペアごとにチェックするだけでも、二次的な動作が発生します。 

重要なエッジ ケースは、セグメントが複数の切断されたオーバーラップ クラスターを形成する場合に発生します。 たとえば、セグメントの 1 つのグループが次の場所にある場合、$[1,2]$そしてもう一つは$[100,200]$、グループ間に重複がない場合、答えは次のようになります。$-1$両方のグループが内部的に接続されている場合でも。 左のエンドポイントでソートした後の接続を想定する単純な実装では、これが見逃される可能性があります。 

もう 1 つの微妙なケースは、オーバーラップが連鎖しているだけの場合です。 セグメント A は B と重なり、B は C と重なりますが、A は C と重なりません。グラフはまだ接続されていますが、アクティブな重なり構造を維持せずに「並べ替えられた順序で隣接する」だけを接続するソリューションでは、正確さに必要な有効なエッジを見逃す可能性があります。 

## アプローチ

 構造を無視すると、問題は、重複するすべてのペアが接続されたグラフを構築し、最小スパニング ツリー アルゴリズムを実行することになります。 その強引な解釈は、すべてのペアを生成することを示唆しています$(i, j)$セグメントが交差するようにして、Kruskal または Prim を実行します。 

このアプローチはグラフを正確に構築するため、そのアプローチが正しいかどうかはすぐに分かります。 問題はサイズです。 最悪の場合、すべてのセグメントが重なった場合、エッジの数は$\binom{n}{2}$、それは約です$10^{11}$いつ$n = 5 \cdot 10^5$。 オーバーラップを検出する場合でも、すべてのペアに対する二次スキャンまたは間隔クエリが必要になります。 

構造的なブレークスルーは、グラフを再解釈することです。 2 つのノード間の重みは以下にのみ依存します。$|a_i - a_j|$、ジオメトリとは独立していますが、エッジは間隔が重なった場合にのみ存在します。 この組み合わせは、接続された各オーバーラップ コンポーネントを、差異を最小限に抑える方法で接続する必要があることを示唆しています。$a$、すべてのエッジを列挙するわけではありません。 

重要な観察は、接続された方法で相互に重複するセグメントのセット内では、絶対差に対する MST が古典的な結果のように動作することです。$a_i$、それらを順番に接続すると、重み付きの完全なグラフにわたる最小スパニング ツリーが生成されます。$|a_i - a_j|$。 唯一の問題は、すべてのペアが許可されるわけではなく、同じオーバーラップ接続されたコンポーネント内のペアのみが許可されることです。 

したがって、実際のタスクは、「区間交差グラフ」内で接続されたコンポーネントを特定し、各コンポーネント内で次の基準で並べ替えることになります。$a_i$そして隣接する差分を合計します。 

残りの困難は、エッジを明示的に構築せずに接続コンポーネントを効率的に計算することです。 これは、間隔をスイープし、DSU のような構造または間隔マージに基づく結合戦略を使用してアクティブな重複グループを維持することによって処理されます。 

現在の右エンドポイントで順序付けされたアクティブなセグメントを維持し、左エンドポイントでスイープするときに重複するセグメントを統合します。 すべてのコンポーネントを取得したら、それぞれを個別に処理します。

 ## アルゴリズムのチュートリアル

 この問題を、区間交差の下で接続されたコンポーネントを構築し、sorted を使用して各コンポーネント内の MST コストを計算することに変換します。$a_i$。 

1. すべてのセグメントを左の端点で並べ替えます。 

これにより、開始位置の昇順で間隔を処理できるようになり、ローリング アクティブ構造を使用してオーバーラップを追跡できるようになります。 
2. 各コンポーネントの現在アクティブな結合間隔を追跡するデータ構造を維持します。 

新しいセグメントごとに、最大右端点が現在の左端点以上であるアクティブなコンポーネントと比較します。 
3. セグメントがアクティブなコンポーネントと重なる場合は、DSU を使用してセグメントをそのコンポーネントにマージします。 

これが機能する理由は、オーバーラップがチェーンを通じて推移的であるため、交差パスが接続コンポーネントを定義するためです。 
4. スイープするとき、適切なエンドポイントによって順序付けられたコンポーネントの現在の「フロンティア」を維持します。 コンポーネントの右端が現在の左端よりも完全に後ろにある場合、そのコンポーネントは閉じられます。 
5. すべてのコンポーネントが特定されたら、コンポーネントごとにノードを収集します。 
6. 各コンポーネントについて、そのノードを次の基準で並べ替えます。$a_i$。 
7. コンポーネント内の MST コストを、ソートされた順序で隣接する差分の合計として計算します。$a_i$。 

これが機能するのは、コンポーネント内で生成されたグラフが絶対差メトリックの下で完全なグラフのように動作するためです。 
8. 複数のコンポーネントが存在する場合は、戻り値を返します。$-1$。 それ以外の場合は合計を返します。 

### なぜ効果があるのか

 区間交差関係は、区間グラフの連結成分とまったく同じ連結成分を定義します。 同じコンポーネント内の任意の 2 つのノードは、オーバーラップのチェーンを通じて接続できます。 これにより、重複するアクティブな間隔にわたる DSU ベースのマージがすべての接続を正しくキャプチャすることが保証されます。 

1 つのコンポーネント内で、誘導されたエッジの重みが絶対差の下で計量空間を形成します。$a_i$。 このようなグラフの場合、長いエッジは中間エッジの合計によって支配されるため、MST は常に点をソートし、連続する要素を接続することによって形成されます。 これは、ライン メトリック上の MST の古典的なプロパティです。 

したがって、元のグラフを独立したラインメトリック MST 問題に縮小します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.sz = [1]*n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return
        if self.sz[a] < self.sz[b]:
            a, b = b, a
        self.p[b] = a
        self.sz[a] += self.sz[b]

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        seg = []
        for i in range(n):
            l, r, a = map(int, input().split())
            seg.append((l, r, a, i))

        seg.sort()

        dsu = DSU(n)

        active = []  # (r, i)
        import heapq

        for l, r, a, i in seg:
            new_active = []
            for rr, j in active:
                if rr >= l:
                    new_active.append((rr, j))
                else:
                    pass
            active = new_active

            for rr, j in active:
                dsu.union(i, j)

            active.append((r, i))

        comp = {}
        for i in range(n):
            root = dsu.find(i)
            comp.setdefault(root, []).append(i)

        if len(comp) > 1:
            print(-1)
            continue

        nodes = list(range(n))
        nodes.sort(key=lambda x: seg[x][2])

        ans = 0
        for i in range(1, n):
            ans += abs(seg[nodes[i]][2] - seg[nodes[i-1]][2])

        print(ans)

if __name__ == "__main__":
    solve()

の`active`list は、右端が依然としてオーバーラップに関連しているセグメントを追跡します。 新しいセグメントごとに、期限切れの間隔を削除し、現在のセグメントを、重複するすべてのアクティブなセグメントと結合します。 これは、接続されたコンポーネントを構築するメカニズムです。 

DSU の構築後、インデックスをルートごとにグループ化します。 複数のグループが存在する場合は、すぐに戻ります$-1$スパニング ツリーが存在できないためです。 

最後に、単一コンポーネントの場合、sorted-by を使用して MST コストを計算します。$a_i$トリック。 重要な点は、接続が DSU によってすでに強制されているため、このステップではジオメトリが完全に無視されることです。

 ## 特殊なケース

 重要なエッジケースは、間隔がほとんど接触しない場合です。 たとえば、セグメント$[1,2]$そして$[2,3]$接続されていると見なす必要があります。 スイープでは、条件によりそれらが重複しているものとして扱われます。$\max(l_1,l_2) \le \min(r_1,r_2)$なので平等で十分です。 DSU 結合ステップでは、それらが 1 つのコンポーネントに正しくマージされ、人為的な分離が発生しません。 

もう 1 つのケースは、オーバーラップが間接的な場合です。 もし$[1,5]$、$[4,6]$、 そして$[6,10]$最初と最後のコンポーネントが直接交差していなくても、3 つすべてが 1 つのコンポーネント内に存在する必要があります。 アクティブなスイープでは、3 番目の間隔を処理するときに、現在アクティブな代表と交差し、推移的に接続が維持されます。 

最後に、すべてのセグメントが重複する場合、アルゴリズムは複数のコンポーネントを生成することはなく、最終的な答えは単純に並べ替えられた全体の差分合計になります。$a_i$、絶対差の下で完全なグラフの MST と一致します。
