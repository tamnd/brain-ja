 ## 問題の理解

 整数の範囲が与えられます$[l, r]$。 カメが数字を選ぶ$x$この範囲から。 その後もピギーは分裂を繰り返す$x$以上の約数の 1 つによって$2$、部門ごとに 1 ポイントを獲得し、その数字が$1$。 

両プレイヤーは最終スコアをできるだけ大きくしたいと考えています。 可能な最大スコアを決定する必要があります。 

重要な観察は、すべての操作が置き換えられるということです。$x$による$x / p$、 どこ$p \ge 2$。 以来$p$少なくとも$2$、各操作により現在の値が少なくとも 1 分の 1 ずつ減少します。$2$。 スコアは単に、到達するまでの除算ステップ数です。$1$。 

アルゴリズムの観点から見ると、制約は非常に小さいです。 まであります$10^4$テストケースと値は最大でも$10^9$。 間隔全体にわたって反復されるソリューション$[l,r]$間隔の長さが近づく可能性があるため、不可能です$10^9$。 テスト ケースごとに直接の数式が必要です。 

微妙な間違いは、素因数分解自体が答えを決定すると考えることです。 たとえば、$x=12$、素因数分解は$2^2 \cdot 3$、3 つの素因数を与えます。 スコアは確かに$3$, しかし、それは、Piggy がいつでも素約数を選択でき、一度に 1 つの素因数だけを削除できるためです。 最大スコアは、多重度でカウントされた素因数の合計数に等しくなります。 

もう 1 つの簡単な間違いは、区間内で最適な数値を検索することです。 考慮する$l=114514$、$r=1919810$。 何百万もの値をブルートフォースする必要はありません。 最適な数は常に、間隔内に収まる最大の 2 のべき乗です。 

## アプローチ

 ブルートフォース ソリューションでは、すべての数値が検査されます。$x$で$[l,r]$、それを因数分解し、素因数の合計数を数え、最大値を保持します。 固定数の最大スコアは多重性を持つ素因数の数に等しいため、これは正しいです。 残念ながら、間隔の長さはほぼ$10^9$、そのような検索は完全に不可能になります。 

重要な観察は、すべての操作が現在の値を少なくとも次の値で割ることです。$2$。 から始まる$x$、 後$s$私たちがしなければならない操作$$x \ge 2^s.$$これはすぐに得られます$$s \le \lfloor \log_2 x \rfloor.$$この限界はいつでも達成可能です$x$それ自体は 2 のべき乗です。 例えば、$2^{10}$で割ることができます$2$ちょうど10回。 

タートルは任意の数字を選択できるため、$[l,r]$を超えない最大の 2 のべき乗を選択することで、可能な限り最大のスコアが得られます。$r$。 させて$$2^k \le r < 2^{k+1}.$$それから$k=\lfloor \log_2 r \rfloor$。 

ステートメントが保証しているので、$2l \le r$、区間には常に 2 のべき乗が少なくとも 1 つ含まれます。 もし$2^k$を超えない最大の 2 の累乗です$r$、 それから$2^k > r/2 \ge l$。 したがって$2^k$範囲内にあり、選択できます。 

答えは単純です$\lfloor \log_2 r \rfloor$。

 ## アルゴリズムのチュートリアル

 1.読む$l$そして$r$。 
2. 最大の整数を計算する$k$そのような$2^k \le r$。 
3. 出力$k$。 

Python での最も簡単な方法は、次のビット長を使用することです。$r$。 任意の正の整数の場合、$$\lfloor \log_2 r \rfloor = r.\text{bit\_length()} - 1.$$### なぜ効果があるのか

 すべての除算では、少なくとも以下に等しい係数が削除されます。$2$、だからその後$s$操作では、元の数値は少なくとも次の数でなければなりません$2^s$。 を超えない数はありません$r$以上のものを生産できます$\lfloor \log_2 r \rfloor$操作。 

区間には常に 2 の累乗を超えない最大の値が含まれます。$r$。 その値を選択すると、正確に達成されます$\lfloor \log_2 r \rfloor$による除算を繰り返して演算する$2$。 上限と一致する構造の両方が存在するため、答えは正確に次のようになります。$\lfloor \log_2 r \rfloor$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        l, r = map(int, input().split())
        ans.append(str(r.bit_length() - 1))

    sys.stdout.write("\n".join(ans))

solve()
```ソリューションは決して使用しません$l$それを読んだ後。 最初は驚くかもしれませんが、保証はあります$2l \le r$これはまさに、必要な 2 のべき乗が常に区間内に存在することを保証するものです。 

表現`r.bit_length() - 1`計算する$\lfloor \log_2 r \rfloor$浮動小数点演算を使用しないため、精度の問題が回避されます。 以来$r \le 10^9$、整数のオーバーフローはまったく問題になりません。
