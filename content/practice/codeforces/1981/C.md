 ## 解決策
 ## 問題の理解

 いくつかの要素が欠落しており、次のように表される一連の正の整数が与えられます。`-1`。 元の数列には特別な特性がありました。つまり、連続する数値のペアごとに、最初の数値が 2 番目の数値の半分の下限になるか、2 番目の数値が最初の数値の半分の下限になります。 タスクは、すべての数値を正の値に保ち、$10^9$。 そのような配列が存在しない場合は、報告します。`-1`。 

入力では、それぞれ最大で複数のテスト ケースが許可されます。$2 \cdot 10^5$要素、およびすべてのテストの要素の合計が次を超えない$2 \cdot 10^5$。 これは、$O(n^2)$解決策は遅すぎます。$4 \cdot 10^{10}$最悪の場合の運用。 理想的には、テスト ケースごとに線形時間か、それをわずかに上回る時間で機能するアプローチが必要です。$O(n \log U)$どこ$U$は、3 秒の制限時間内に収まる数値の上限です。 

厄介なケースは、欠損数値が既知の数値と相互作用し、半減特性に違反する可能性がある場合です。 たとえば、シーケンス`-1 5 -1 6`両側から半分/フロア特性を満たすように空白を埋めることは不可能であるため、有効な再構成が存在しない可能性があります。 同様に、既知の値に互換性がない小さなシーケンスも次のようになります。`2 -1 -1 3`、無効として検出される必要があります。 制約なしで左から右に単純に埋めると、静かに無効なシーケンスが生成される可能性があります。 

## アプローチ

 ブルートフォース手法では、1 から 1 までのすべての可能な整数を試します。$10^9$あらゆる人にとって`-1`位置を確認し、連続する各ペアの半減条件を確認します。 これは、シーケンスの範囲と長さが膨大であるため、明らかに非現実的です。 までのすべての数字を試しても$10^8$最悪の場合は必要になります$10^{13}$操作。 

重要な観察は、シーケンス内の既知の数値ごとに、その近傍の取り得る値が制限されていることです。 もし`b[i]`知られているなら、`b[i-1]`範囲内でのみ可能です`[b[i]*2, b[i]*2+1]`逆に、または`[b[i]//2, b[i]]`順方向では、半減関係をどの方向に解釈するかに応じて異なります。 これらの制約を左右に伝播することにより、未知の要素ごとに実行可能な間隔を計算できます。 いずれかのステップで実行可能区間が空になると、シーケンスは不可能になります。 

これにより、問題は、各位置の実行可能な範囲を維持し、制約を左から右、右から左に伝播し、両方の範囲の交差部分内の任意の値を選択することになります。 各位置は一定時間で処理されるため、全体の複雑さはシーケンスの長さに対して線形です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(10^9 * n) | O(n) | 遅すぎる |
 | 間隔伝播 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つの配列を初期化します。`lo`そして`hi`、各位置の実行可能な値の範囲を表します。 最初に設定するのは、`lo[i] = 1`そして`hi[i] = 10^9`すべての未知の要素に対して、`lo[i] = hi[i] = a'[i]`既知の要素の場合。 これにより、入力から初期制約が設定されます。 
2. 制約を左から右に伝播します。 ポジションごとに`i`1 から n-1 まで調整します`lo[i+1]`そして`hi[i+1]`電流の半減特性に従って`lo[i]`そして`hi[i]`。 具体的には、`b[i+1]`どちらかを満たさなければなりません`b[i+1] // 2 = b[i]`または`b[i+1] = b[i] // 2`。 アップデート`lo[i+1]`両方の可能性と`hi[i+1]`最小上限として。 もし`lo[i+1] > hi[i+1]`、シーケンスは不可能です。 
3. 同じロジックを使用して、右から左への伝播を繰り返します。 これにより、反対側からの制約が確実に考慮されます。 もう一度言いますが、どのポジションにいても`lo[i] > hi[i]`、出力`-1`。 
4. すべてのポジションの実行可能な範囲が計算されたら、それぞれの範囲内の任意の値を選択します。`[lo[i], hi[i]]`間隔。 簡単にするために、`lo[i]`間隔内の任意の値が前の伝播による半減条件を満たすため、機能します。 
5. 現在のテスト ケースのシーケンスを出力します。 いずれかのステップが失敗した場合は、印刷します`-1`。 

なぜ機能するのか: アルゴリズムは、すべての`b[i]`内にあるに違いない`[lo[i], hi[i]]`隣接するものとの半減条件を満たすため。 制約を両方向から伝播することで、既知の数値によって課されるすべての制約を確実に捕捉できます。 実行可能な間隔が空になると、シーケンスを満たすことは不可能になり、そうでない場合は、間隔内で選択された任意の値が有効なシーケンスを生成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        lo = [1] * n
        hi = [10**9] * n
        for i in range(n):
            if a[i] != -1:
                lo[i] = hi[i] = a[i]
        # left to right propagation
        for i in range(n-1):
            new_lo = max(lo[i] * 2, (lo[i]+1)//2)
            new_hi = min(hi[i] * 2 + 1, hi[i]*2+1)
            lo[i+1] = max(lo[i+1], new_lo)
            hi[i+1] = min(hi[i+1], new_hi)
            if lo[i+1] > hi[i+1]:
                break
        else:
            # right to left propagation
            for i in range(n-1, 0, -1):
                new_lo = max(lo[i]//2, lo[i])
                new_hi = min(hi[i]*2+1, hi[i])
                lo[i-1] = max(lo[i-1], new_lo)
                hi[i-1] = min(hi[i-1], new_hi)
                if lo[i-1] > hi[i-1]:
                    break
            else:
                print(" ".join(map(str, lo)))
                continue
        print(-1)

if __name__ == "__main__":
    solve()
```このコードは、すべての位置の実行可能な範囲を初期化し、制約を前後に伝播し、最終的に各間隔から有効な選択肢を出力します。 伝播では、境界が正しく適用されるように、整数演算を慎重に使用します。

 伝播後、間隔は互換性のある範囲に縮小します。`[4, 9, 4, 2, 4, 2, 1, 2]`。 選択する`lo[i]`有効な出力が生成されます。

これらの例は、制約の伝播がどのように不可能なシーケンスを解決または検出するかを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | テスト ケースあたり O(n) | 各伝播ステップでは、各要素を 2 回 (左から右に 1 回、右から左に 1 回) 処理します。
