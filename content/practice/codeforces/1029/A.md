 ## 問題の理解

それぞれの有効なオカレンスは開始位置によって定義されます。`i`、セグメントは`s[i:i+n]`と同一です`t`。 出現間の重複は許可されているため、複数の一致で文字を共有できます。 

重要な問題は、オーバーラップによって全長が短くなる可能性があることです。`s`。 のコピーを置くと、`t`背中合わせで最大限の重なりを持たせることで、追加される文字を減らします。 目的は整理することです`k`意図しない余分なオカレンスが表示されないようにしながら、全長を最小限に抑える方法でオカレンスを追加します。 

制約は小さいです。`n, k ≤ 50`。 これは、探索空間が小さいため、二次推論やさらには三次推論が受け入れられることを直ちに示唆しています。 大規模な組み合わせ構造を最適化するのではなく、オーバーラップを制御して文字列を慎重に構築します。

 素朴なアイデアは、文字列を段階的に構築してみて、各ステップで文字を追加する場所を決定して、`t`制御されたままです。 文字列の可能なすべての拡張をブルート フォースで実行し、その回数をチェックすることを想像することもできます。`t`各拡張子の後に表示されます。 これはすぐに実行不可能になります。`n, k ≤ 50`、候補文字列の数が指数関数的に増加し、各チェックにコストがかかります`O(nk)`。 

重要な観察は、最適な構築では、連続するコピー間の重複を最大限に再利用する必要があるということです。`t`。 を2枚置くと、`t`長さの重複あり`x`、次に長さの接尾辞`x`最初のコピーの長さはプレフィックスと等しくなければなりません`x`の`t`。 考えられるすべての重複の中で、最大の重複が必要です。これにより、追加出現ごとに追加される新しい文字の数が最小限に抑えられます。 

これにより、問題は次の最大境界の計算に減ります。`t`、最長の適切なプレフィックスを意味します`t`それも接尾語です。 この重なりの長さがわかれば、`p`、追加の各コピー`t`追加するだけで追加できます`n - p`文字。

 ## アルゴリズムのチュートリアル

 まず、文字列がそれ自体とどの程度オーバーラップできるかを計算する必要があります。 

1. の最大の適切なプレフィックスを計算します。`t`それも接尾語です。 これによりオーバーラップ長が得られます`p`。 これは、2 つのコピーが存在する最大シフトです。`t`平等を崩さずに整列できる。 
2. 応答文字列を初期化する`s`として`t`。 この時点で、すでに 1 件のオカレンスが発生しています。 
3. 繰り返します`k - 1`回:

 最後を取る`p`の登場人物`s`、残りのサフィックスを追加します`t`インデックスから始まる`p`。 これは延長します`s`新たな出来事が起こるように、`t`正しいシフト位置から正確に開始されます。 
4. すべての反復の後、戻ります`s`。 

常に同じオーバーラップを再利用する理由は、より小さいオーバーラップを使用しても正確さを変えることなく長さが増加するだけであり、より大きなオーバーラップを使用することは定義により不可能であるためです。`p`。 

### なぜ効果があるのか

 この構造により、あらゆる発生が保証されます。`t`異なる位置から正確に開始します`n - p`。 プレフィックスとサフィックスの構造により、新しく追加された各ブロックが以前のブロックと完全に整列することが保証されるため、意図したすべてのウィンドウが一致します。`t`。 常に可能な最大のオーバーラップを使用するため、余分な一致はそれよりも大きな境界を意味するため、構築されたオカレンス間に意図しない一致が追加されることはありません。`p`、その最大値に矛盾します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def prefix_function(s):
    n = len(s)
    pi = [0] * n
    for i in range(1, n):
        j = pi[i - 1]
        while j > 0 and s[i] != s[j]:
            j = pi[j - 1]
        if s[i] == s[j]:
            j += 1
        pi[i] = j
    return pi

def solve():
    n, k = map(int, input().split())
    t = input().strip()

    pi = prefix_function(t)
    p = pi[-1]

    s = t
    for _ in range(k - 1):
        s += t[p:]

    print(s)

if __name__ == "__main__":
    solve()
```このソリューションでは、プレフィックス関数 (KMP 前処理) を使用して、次の最長境界を計算します。`t`。 値`pi[-1]`接尾辞でもある最長の接頭辞の長さを直接与えます。 

次に、最終的な文字列を繰り返し構築します。 各追加操作では、次から始まるサフィックスが再利用されます。`p`、最大限のオーバーラップを確保します。 ループは正確に実行されます`k-1`正確に作成します`k`制御された位置から始まる発生。 

一般的な実装の落とし穴は、次の場合に境界線を誤って計算することです。`t`繰り返しがありません。 その場合`p = 0`、そして毎回完全な文字列を追加する必要がありますが、これはコードによって自然に処理されます。

 ## 特殊なケース

 重要なエッジケースの 1 つは次のような場合です。`t`自己重複はありません。 例えば、`t = "abc"`与える`p = 0`。 その後、アルゴリズムは毎回完全なコピーを追加し、`abcabcabc...`。 構造は依然として正確さを保証します`k`シフトされた配置では部分一致が誤って作成される可能性があるためです。 

もう 1 つのエッジ ケースは、次のような完全な繰り返しです。`t = "aaaa"`。 ここが国境です`3`, したがって、新しいコピーごとに追加される文字は 1 つだけです。 重なりが極端に多い場合でも、プレフィックス関数は最大境界を正確にキャプチャし、文字列の増加を最小限に抑えながら正確に維持します。`k`制御された出来事。
