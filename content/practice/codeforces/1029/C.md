 ## 解決策
 ## 問題の理解

 数直線上のセグメントのコレクションが与えられ、そのうちの 1 つだけを削除した場合にそれらがどの程度重複するかを理解したいと考えています。 セグメントのサブセットの場合、それらの共通の交差部分もセグメント (または空) であり、その長さは、選択されたすべての間隔がどの程度緊密に重なり合うかによって決まります。 

各セグメントは下限と上限に影響します。 すべてのセグメントの交差部分は、2 つの値によって完全に制御されます。それらの最大の左端点と最小の右端点です。 左の最大値が右の最小値よりも大きい場合、重なり合いはなく、交差点は空になります。 

タスクは、残りのセグメントの交差部分ができるだけ長くなるように、破棄するセグメントを 1 つ選択することです。 

この制約により、最大 300,000 個のセグメントが許可されます。 各セグメントを削除して交差部分を最初から再計算しようとする解決策は、最悪の場合 O(n²) 間隔のチェックが必要になるため、時間がかかりすぎます。 これにより、グローバル構造を前処理し、一定時間内に各削除に応答するソリューションに向けて推進されます。 

左側のグローバル最大値または右側のグローバル最小値を担当するセグメントが削除されると、微妙な問題が発生します。 その場合、制限境界は 2 番目に良い候補に移動します。 多重性を追跡せずに、単一のグローバル最小値と最大値のみを追跡するアプローチは失敗します。 

たとえば、多くのセグメントが同じ最小右端点を共有している場合、そのうちの 1 つを削除しても交差境界は変更されません。 極値を誤って再計算したり、重複を忘れたりする単純な実装では、このような場合に間違った答えが生成されます。 

## アプローチ

 重要な観察は、すべてのセグメントの共通部分が 2 つの数値 (最大左端点 L と最小右端点 R) のみに依存するということです。1 つのセグメントを削除した後、残りの n−1 個のセグメントについてこれら 2 つの値を再計算する必要があります。 

ブルートフォース手法では、各セグメント i を反復処理し、他のすべてのセグメントの中で左の最大値と右の最小値を再計算し、結果として生じる交差の長さを計算します。 これには除去ごとに O(n) のコストがかかり、全体では O(n²) になりますが、これは n が 300,000 までの場合には遅すぎます。 

この改善は、極値を毎回最初から再計算する必要がないことに気づいたことから生まれます。 左のエンドポイントと右のエンドポイントの両方について、最良の候補と次善の候補、および最良の値が出現する回数だけを知る必要があります。 事前計算すると:

 最大および 2 番目に大きい左端点、

 最小および 2 番目に小さい右端点、

 次に、削除された各セグメントについて、O(1) で、削除が極値に影響を与えるかどうか、および調整方法を決定できます。 

削除されたセグメントが現在の最大残量に寄与していない場合、最大残量は変更されません。 それが寄与しており、それが唯一である場合は、2 番目の最大値に戻ります。 同じロジックが最小右にも対称的に適用されます。 

これにより、前処理後の単純なインデックスごとの評価に問題が軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 エンドポイントのグローバル統計を維持し、各セグメントを削除した場合の影響を評価します。

1. すべてのセグメントをスキャンし、l の最大値と 2 番目に大きい値、および最大値が何回発生するかを計算します。 同時に、明確にするために必要に応じて、発生のインデックスを追跡します。 これが必要なのは、最大値の一意の原因ではないセグメントを削除しても境界が変更されるべきではないためです。 
2. 同様に、r の最小値と 2 番目に小さい値、および最小値が何回出現するかを計算します。 これにより、最小の右端点が消えたときに何が起こるかを判断できます。 
3. 各セグメント i について、新しい最大左端点がどのようになるかを決定することによって、その除去をシミュレートします。 l[i] がグローバル最大値でない場合、最大値は変更されません。 それが一意の最大値である場合は、2 番目の最大値に切り替えます。 それ以外の場合は、同じ最大値を維持します。 
4. 最小右端点の対称計算を実行します。 r[i] がグローバル最小値でない場合は、変更されないままになります。 一意の最小値である場合は、2 番目の最小値に切り替えます。 
5. この削除の交差の長さを max(0, new_min_r − new_max_l) として計算します。 すべての i にわたる最大値を追跡します。 

各除去を個別に評価する背後にある理由は、交差は両側の独立した極値によって完全に決定されるため、追加の構造は必要ないということです。 

### なぜ効果があるのか

 どの時点においても、一連のセグメントの交差は 2 つのセグメントによって課される極端な制約にのみ依存します。1 つは左側の境界を可能な限り右に押し、もう 1 つは右側の境界を可能な限り左に押すというものです。 セグメントの削除は、セグメントがこれらの極端な制約のいずれかに関与している場合にのみ結果に影響します。 各極値を定義できる候補は 1 つまたは 2 つだけであるため、削除後に正しい交差を再構築するには、最良の値と次善の値を追跡するだけで十分です。 これにより、すべての削除候補が生成される状態で正確に評価されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    seg = [tuple(map(int, input().split())) for _ in range(n)]
    
    INF = 10**18
    
    # track top two maxima for l
    max1_l = -1
    max2_l = -1
    cnt_max1_l = 0
    
    # track top two minima for r
    min1_r = INF
    min2_r = INF
    cnt_min1_r = 0
    
    for l, r in seg:
        if l > max1_l:
            max2_l = max1_l
            max1_l = l
            cnt_max1_l = 1
        elif l == max1_l:
            cnt_max1_l += 1
        elif l > max2_l:
            max2_l = l
        
        if r < min1_r:
            min2_r = min1_r
            min1_r = r
            cnt_min1_r = 1
        elif r == min1_r:
            cnt_min1_r += 1
        elif r < min2_r:
            min2_r = r
    
    ans = 0
    
    for l, r in seg:
        # compute new max L
        if l == max1_l and cnt_max1_l == 1:
            new_l = max2_l
        else:
            new_l = max1_l
        
        # compute new min R
        if r == min1_r and cnt_min1_r == 1:
            new_r = min2_r
        else:
            new_r = min1_r
        
        ans = max(ans, max(0, new_r - new_l))
    
    print(ans)

if __name__ == "__main__":
    solve()
```最初のパスでは、必要なすべてのグローバル極値が線形時間で計算されます。 2 番目のパスでは、削除されたセグメントが一意に境界を定義しているかどうかをチェックして、各削除を評価します。 実装の重要な詳細は、等しい値だけでは次善の値へのフォールバックが必要かどうかを決定するのに不十分であるため、極端な値のカウントを維持することです。 

次善の初期化を処理する場合にも注意が必要です。 最小値に大きなセンチネルを使用し、最大値に小さなセンチネルを使用すると、すべてのセグメントが同一である場合や、多くの値が一致する場合でも、比較が有効なままになります。

 ## 特殊なケース

 重要なエッジ ケースは、複数のセグメントが同じ極端なエンドポイントを共有する場合に発生します。 たとえば、複数のセグメントに同じ最大左端点がある場合、最後に残っているインスタンスでない限り、それらの 1 つを削除しても最大値は変更されません。 アルゴリズムは発生回数を維持することでこれを処理するため、一意の極端な値のみが 2 番目に最適な値へのフォールバックをトリガーします。 

もう 1 つのケースは、すべてのセグメントが同一である場合です。 この状況では、いずれかのセグメントを削除しても交点は変更されず、長さ 0 の同じ点セグメントのままになります。 どちらのエンドポイントも極端な値に対して独自の責任を負うわけではないため、ロジックは両方の新しい境界を変更せずに正しく維持します。 

最後の微妙なケースは、すべての値が同一であるために 2 番目に最適な値が更新されない場合に発生します。 センチネルの初期化により、フォールバックが依然として有効な値を生成することが保証され、結果は max(0, ...) でクランプされるため、空の交差は正しく処理されたままになります。
