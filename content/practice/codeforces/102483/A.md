 ## 解決策
 ## 問題の理解

 私たちは持っています`n`チーム。 チーム`i`座標に固定アクセス ポイントがあります`(s_i, t_i)`そして最終的な場所を選択する必要があります`(x_i, y_i)`そのチームのために。 最終的な場所はチームの順序を保持する必要があります: チームの場合`i`チームの前に来る`j`、その x 座標と y 座標は、後のチームの座標よりも大きくすることはできません。 

チームをアクセス ポイントから遠ざけるには、ユークリッド距離の 2 乗のコストがかかります。 目標は、すべての移動の可能な最小総コストを見つけることです。 

制約`n ≤ 100000`多くのペアを比較したり、可能な配置を探索したりするアルゴリズムを除外します。 二次アプローチでは次のことが必要になります`10^10`通常のコンテストの制限時間をはるかに超えた最悪の場合の作戦。 線形または線形に近い解決策が必要です。 

主なトラップは、各チームが独立して移動できるという想定から生じます。 たとえば、x 座標が次の場合、`[5, 1]`、最終的な X 値の選択`[5, 1]`動きはゼロですが、必要な順序に違反します。 正しい最適な配置は、両チームが X 座標にあることです`3`、製造コスト`(5-3)^2 + (1-3)^2 = 8`。 

もう 1 つの特殊なケースは、複数の座標が等しい場合です。 入力用```
3
5 5
5 5
5 5
```答えは`0.000000000`。 厳密にポジションを増加させようとする解決策は、不必要な動きを追加して失敗するでしょう。 

最後によくある間違いは、2 つの次元を一緒に扱うことです。 x 制約と y 制約は独立しているため、点を分離できないオブジェクトとして扱う実装では、最適な解決策が見つからない可能性があります。 

## アプローチ

 直接的なアプローチは、増加する次数の制約を維持しながら最終座標を割り当てようとすることです。 すべての座標は他のすべての座標と相互作用する可能性があるため、同じ最終座標の考えられるグループに対する単純な検索はすぐに不可能になります。 シーケンスの可能なすべての分割を単調ブロックにチェックするだけでも、指数関数的に増加します。 

有用な観察は、距離の式を分離することで得られます。 1 つのチームの場合、二乗距離は次のようになります。 

(x i −s i ) 2 +(y i −t i ) 2

 したがって、x 座標の決定は x コストのみに影響し、y 座標の決定は y コストのみに影響します。 2 つの独立した 1 次元問題を解くことができます。 

X 座標のみを考慮してください。 非減少シーケンスが必要です`x_i`それは元の値にできるだけ近い値です`s_i`。 これは二乗誤差を伴う古典的な等張回帰問題です。 最適な解決策では、いくつかの連続する値が等しくなる必要がある場合があります。 連続するブロックが必要な順序に違反している場合は、そのブロック内のすべての値をその平均値に置き換える必要があります。 

プール隣接違反​​者アルゴリズムは、ブロックを平均値で維持することでこれを解決します。 新しく作成されたブロックの平均が前のブロックよりも小さい場合、それらのブロックは両方とも有効なままではいられないため、マージされます。 同じプロセスが y 座標にも適用されます。 

すべての順序制限を考慮するため、ブルート フォースは機能しますが、次の場合には失敗します。`n`成長します。 隣接する違反ブロックのみをマージする必要があるという観察により、問題は単一のスタック パスに軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |

 | ブルートフォース | 指数関数または O(n²) は公式に応じて異なります。 O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. x 座標のシーケンスに対する 1 次元等張回帰問題を解きます。 ブロックのスタックを維持します。 各ブロックには、そこに含まれる元の値の数、それらの合計、および現在の平均が格納されます。 
2. 各座標を新しいブロックとして挿入します。 最後のブロックの平均がその前のブロックの平均より小さい場合、2 つのブロックをマージします。 結合されたブロックは、両方のグループが 1 つの最終座標を共有する必要があるという事実を表します。 
3. すべてのマージが完了すると、すべてのブロックの平均は前のブロックよりも小さくなりません。 ブロックの寄与は、その平均からの差の二乗の合計として計算できます。 
4. y 座標に対して同じプロセスを個別に繰り返します。 
5. 2 つのコストを加算し、結果を出力します。 

機能する理由: 非減少制約の下での最適二乗誤差近似は、元のシーケンスが違反を強制するすべての最大領域にわたって一定値を持ちます。 このような領域をその平均値で置き換えると、平均値は二乗距離の合計の一意の最小値であるため、二乗誤差が最小限に抑えられます。 スタックはこれらの領域を正確に維持し、2 つの隣接する領域が単調性を破るたびにマージします。 スタックが単調になると、それ以上変更を加えてもソリューションを改善できません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def isotonic_cost(arr):
    stack = []

    for value in arr:
        stack.append([1, float(value)])
        while len(stack) >= 2:
            a = stack[-2]
            b = stack[-1]
            if a[1] <= b[1]:
                break
            total_count = a[0] + b[0]
            total_sum = a[0] * a[1] + b[0] * b[1]
            stack.pop()
            stack.pop()
            stack.append([total_count, total_sum / total_count])

    ans = 0.0
    for count, avg in stack:
        ans += count * avg * avg

    for value in arr:
        ans -= 2 * value * 0.0

    return ans

def isotonic_error(arr):
    stack = []
    square_sum = sum(x * x for x in arr)

    for value in arr:
        stack.append([1, float(value)])
        while len(stack) >= 2:
            a = stack[-2]
            b = stack[-1]
            if a[1] <= b[1]:
                break
            count = a[0] + b[0]
            total = a[0] * a[1] + b[0] * b[1]
            stack.pop()
            stack.pop()
            stack.append([count, total / count])

    reduction = 0.0
    for count, avg in stack:
        reduction += count * avg * avg

    return square_sum - reduction

def solve():
    n = int(input())
    xs = []
    ys = []
    for _ in range(n):
        s, t = map(int, input().split())
        xs.append(s)
        ys.append(t)

    print("{:.9f}".format(isotonic_error(xs) + isotonic_error(ys)))

if __name__ == "__main__":
    solve()
```スタックには、定数値領域へのシーケンスの現在のパーティションが含まれています。 各要素は、ブロック サイズとその平均を含むペアとして保存されます。 マージが発生すると、ブロックのサイズが異なる可能性があるため、2 つの平均を直接平均するのではなく、両方のブロックの合計から新しい平均が計算されます。 

コストの計算にはアイデンティティが使用されます。 

∑(a i −m) 2 =∑a i 2 −2m∑a i ＋nm 2

 平均が次のブロックの場合`m`、中期はキャンセルされるため、`m`ブロック平均に等しい。 この実装では、元の二乗和が累積され、適合されたブロックの二乗寄与が減算されます。 Python の整数は入力合計のオーバーフローを回避し、浮動小数点精度は必要な誤差許容度に十分です。

## テストケース```python
import sys, io

def isotonic_error(arr):
    stack = []
    square_sum = sum(x * x for x in arr)
    for value in arr:
        stack.append([1, float(value)])
        while len(stack) >= 2 and stack[-2][1] > stack[-1][1]:
            a = stack.pop()
            b = stack.pop()
            count = a[0] + b[0]
            total = a[0] * a[1] + b[0] * b[1]
            stack.append([count, total / count])
    return square_sum - sum(c * m * m for c, m in stack)

def run(inp):
    data = inp.strip().split()
    n = int(data[0])
    xs = []
    ys = []
    p = 1
    for _ in range(n):
        xs.append(int(data[p]))
        ys.append(int(data[p + 1]))
        p += 2
    return f"{isotonic_error(xs) + isotonic_error(ys):.9f}"
