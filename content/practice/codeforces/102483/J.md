 ## 解決策
 ## 問題の理解

 ジュリアは多くの賭け者の中の 1 人です。 彼女の現在のスコアは少なくとも他のみんなのスコアと同じくらいです。 今後のすべての試合の後、彼女は対戦相手の中で現在最も高いスコアを持っているベッターの多数派の予測をコピーします。 質問は、たとえ将来の賭けや試合結果が敵対的に選択されたとしても、彼女がどの対戦相手にも遅れをとらないことが保証される今後の試合の数を尋ねます。 

スコアを直接保存する代わりに、ジュリアからすべての対戦相手の欠点を確認する方が簡単です。 ジュリアがスコアを持っている場合`S`別のベッターがスコアを持っています`x`、彼らの赤字は`S - x`。 の赤字`0`は同点であることを意味し、マイナスの赤字はジュリアがすでにリードを失っていることを意味します。 

まであります`100000`ベッター、スコアは次のように大きくなる可能性があります`10^16`。 答えが前後する可能性があるため、試合を 1 つずつシミュレートすることは不可能です`10^16`。 ソリューションでは、同じ動作の膨大な部分をスキップする必要があります。 

重要な構造は、赤字が最小の対戦相手だけが重要であるということです。 彼らは現在の準優勝者です。 他の全員はさらに遠くにいて、最終的には次点に加わる後のグループと考えることができます。 

## アプローチ

 直接シミュレーションを行うと、すべてのスコアが保持され、現在のリーダー、多数決、および考えられる最悪の結果が繰り返し決定されます。 1試合の費用は`O(n)`、関連するすべてのベッターをチェックする必要がある可能性があるためです。 一致の数はスコアの差と同じくらい大きくなる可能性があるため、このアプローチでは約`10^21`操作。 

有益な観察は、プロセスがグループで発生するということです。 仮定する`t`相手は現在の準優勝者として並んでいます。 最悪の場合、これらは`t`短いサイクル中の 1 ラウンドを除いて、すべての人がジュリアに対してポイントを獲得できます。 そのサイクルの長さは次のとおりです。```
1 + floor(log2(t))
```これらのラウンド中、他のすべての対戦相手はサイクル全体の長さで追いつきますが、現在の次点者は 1 つ少ない差で追いつきます。 これは、現在の次点者と次のグループとの間の距離が、各サイクル後にちょうど 1 ずつ減少することを意味します。 

これにより、一度に多くのラウンドを飛び越えることができます。 赤字を分類し、赤字が等しいグループを処理し、グループ間の差がなくなったら次のグループを統合することを繰り返します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(答え・n) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての対戦相手のスコアをジュリアからの赤字に変換し、赤字を並べ替えます。 最も小さな差がジュリアを追い抜くのに最も近い相手です。 
2. 現在の最小赤字を維持する`d`そしてその番号`t`対戦相手がその欠点を抱えていること。 次のグループの赤字は大きくなります`next_d`。 
3. サイクル長を計算する`1 + floor(log2(t))`。 1 サイクル中に、現在のグループは次のグループと比較してジュリアに一歩近づきます。 
4. 次のグループまでのギャップが大きい場合は、一度に多くの完全なサイクルをスキップします。 スキップされたラウンド数を答えに加算し、両方のグループを近づけます。 
5. 現在のグループが次のグループと合併するとき、増加する`t`そして続けます。 グループが大きくなると、サイクルが長くなり、追いつく速度が異なります。 
6. 最小の赤字がマイナスになったら停止します。 その瞬間までに完了したラウンドの数が答えです。 

不変条件は、圧縮操作のたびに、保存されたグループが、スキップされたすべての一致を個別にシミュレートした後とまったく同じ相対順序を表すことです。 重要な唯一の情報は、各グループの赤字と、各グループがどれだけ早くジュリアに近づくかということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    p = list(map(int, input().split()))

    julia = p[0]
    deficits = [julia - x for x in p[1:]]
    deficits.sort()

    ans = 0
    i = 0
    m = n - 1

    while True:
        d = deficits[i]
        if d < 0:
            break

        j = i
        while j < m and deficits[j] == d:
            j += 1
        cnt = j - i

        step = cnt.bit_length() - 1
        cycle = step + 1

        if j == m:
            need = d + 1
            full = need // step
            rem = need % step
            ans += full * cycle
            if rem:
                ans += rem + 1
            break

        gap = deficits[j] - d

        if step == 0:
            take = gap
        else:
            take = min(gap, (d + 1 + step - 1) // step)

        if take < gap:
            need = d + 1
            full = need // step
            rem = need % step
            ans += full * cycle
            if rem:
                ans += rem + 1
            break

        ans += take * cycle
        shift = take * step

        for k in range(i, j):
            deficits[k] -= shift

        i = j

    print(ans)

if __name__ == "__main__":
    solve()
```赤字の符号はジュリアが依然としてリードしているかどうかを直接表すため、コードは最初にスコアを赤字に変換します。 ソートにより、同等の次点をまとめて処理できます。`bit_length() - 1`計算する`floor(log2(cnt))`、グループがどれくらい早く追いつくかを決定します。 このアルゴリズムは個々の一致に対して反復することはなく、等しい欠損のグループに対してのみ反復されます。 

入力内の大きな値には Python 整数が必要ですが、Python は任意の精度を自動的に処理します。 重要な境界条件は、最小赤字がマイナスになったときに直ちに停止することです。これは、ジュリアがリードすることが保証されなくなった最初の瞬間だからです。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n log n) | 並べ替えが優先されます。 すべてのグループが 1 回処理されます。 
| スペース | O(n) | 赤字配列にはすべての対戦相手が格納されます。 

この制約により、一致数に比例するシミュレーションを回避する必要があります。 仕分け`100000`値を設定して線形グループ スキャンを実行すると、制限内に簡単に収まります。
