 ## アルゴリズムのチュートリアル

 このプロセスは、次のセグメントを繰り返し選択することであると解釈します。`a`、各セグメントはあるレベルで削除されます。`k`。 どこで分けるかを決めたい`a`、いつ増やすか`k`。

### なぜ効果があるのか

 どの時点でも、重要な唯一の決定は、次のセグメント境界です。`a`そして可能な限り最高の`k`それによりそのセグメントが許可されます。 使用可能な有効最大値を変更しない一連の中間タイプ 1 操作`k`実現可能性やコストは変わらないため、削除前は無関係です。 したがって、各セグメントは最適なタイミングで削除されたものとして扱うことができます。`k`以前の簿記とは独立しています。 

DP の不変条件は次のとおりです。`dp[i]`サフィックスをクリアするための最適なコストを保存します`a[i:]`、すべての遷移では、次から始まるすべての最大実現可能セグメントが考慮されます。`i`可能な限り最善の状態で`k`。 コストは選択したもののみに依存するため、`k`そしてセグメンテーション、そして`b`は厳密に減少しているため、後の決定は、トランジションですでに把握されている実現可能性を変更せずに、以前のセグメントの選択を遡及的に改善することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        # prefix sums
        ps = [0] * (n + 1)
        for i in range(n):
            ps[i+1] = ps[i] + a[i]

        # if even smallest threshold fails
        if a[0] > b[0]:
            print(-1)
            continue

        # dp[i] = (cost, ways)
        INF = 10**18
        dp_cost = [INF] * (n + 1)
        dp_ways = [0] * (n + 1)

        dp_cost[n] = 0
        dp_ways[n] = 1

        # pointer over b for best k
        for i in range(n - 1, -1, -1):
            best_cost = INF
            best_ways = 0

            # try all possible segment ends
            for j in range(i + 1, n + 1):
                seg_sum = ps[j] - ps[i]
                if seg_sum > b[0]:
                    break

                # find best k for this segment
                # since b is decreasing, we scan linearly
                k = 0
                while k + 1 < m and b[k+1] >= seg_sum:
                    k += 1

                cost = (m - (k + 1)) + dp_cost[j]

                if cost < best_cost:
                    best_cost = cost
                    best_ways = dp_ways[j]
                elif cost == best_cost:
                    best_ways = (best_ways + dp_ways[j]) % MOD

            dp_cost[i] = best_cost
            dp_ways[i] = best_ways

        print(dp_cost[0], dp_ways[0] % MOD)

if __name__ == "__main__":
    solve()
```実装はサフィックスを介した直接 DP です。 プレフィックス合計により、定数時間のセグメント合計クエリが可能になります。 開始インデックスごとに`i`、考えられるものをすべて列挙します`j`合計が超えるまで`b[0]`、これより大きなものはいかなる条件下でも決して有効ではないため、`k`。 

有効なセグメントごとに、実現可能な最適なセグメントを計算します。`k`スキャンすることで`b`セグメント合計がサポートされなくなるまで。 これにより、そのセグメントのコスト寄与が最小限になります。 DP 遷移により、最適なサフィックス コストが追加されます。`dp[j]`。 

カウント ロジックは、同じ最小コストを達成するすべての遷移を累積します。 すべてのセグメントが明示的に考慮されるため、当然のことながら、すべての最適な分解がカウントされます。 

微妙な点は、セグメントの合計が超過するとすぐに内側のループが終了することです。`b[0]`、他のすべてはすべてスキップされるため、完全にスキップできます。`b[k]`より小さいです。 これにより、不要なスキャンを防止できます。
