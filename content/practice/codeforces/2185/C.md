 ## 解決策
 ## 問題の理解

 整数の配列が与えられますが、これには負の数が含まれる場合があります。 このタスクでは、単一の整数シフトを選択できます。`x`それを配列のすべての要素に追加します。 このシフトを実行した後、配列の MEX を最大化したいと考えます。 配列の MEX は、配列内に存在しない最小の非負の整数として定義されます。 

事実上、この問題は、すべての要素を均一にシフトすることによって、配列から欠落している、ゼロから始まる最大の「ギャップ」を作成できるかどうかを尋ねます。 たとえば、配列`[2, 4, 1, 0, -1]`要素がゼロから始まるようにシフトして、連続する非負の整数をできるだけ長く表示し、最初に欠落している数値をさらに押し出すことができます。 

制約は中程度で、すべてのテスト ケースで配列要素の合計が最大 3000 個までです。 これは、`O(n^2)`解決策は機能する可能性がありますが、優先する必要があります`O(n log n)`または`O(n)`可能であれば、2 秒の制限時間内で快適に過ごせるようにしてください。 非負であることを前提とした単純なアプローチでは失敗する可能性があるため、負の数は慎重に扱う必要があります。 

エッジ ケースは、すべての数値が同じ場合、または最小の数値がすでに 0 である場合に発生します。 例えば、`[1, 1]`によってのみシフトできます`-1`配列を作るには`[0, 0]`、MEX を与える`1`。 もう 1 つのエッジ ケースは、配列にすでに次からの連続した数値が含まれている場合です。`0`に`k`; 最適な MEX は、シフト後の最大要素より 1 だけ大きい値であり、シフトがゼロになる可能性があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。可能なすべてのシフトを試してください。`x`から`-max(a)`に`-min(a)`シフトされた配列がゼロに触れるようにして、各シフト後に MEX をチェックします。 これが機能するのは、大きな正または負の数値を追加すると要素が遠くに移動する可能性があるためですが、潜在的なシフトの数が膨大になるため (最大 2*10^9)、すべてのシフトを繰り返すのは現実的ではありません。 

重要な洞察は、最適なシフトによって配列内の最小の数値がゼロに揃えられるということです。 最小要素がゼロになると、ソートされた配列の中で欠落している最小の整数によって MEX が決定されます。 最小の数値とゼロの差だけを考慮する必要があるため、すべての要素を次のようにシフトするという 1 つの操作で十分です。`-min(a)`。 この後、配列は負ではなくなり、ゼロから始まります。 したがって、MEX は単に、連続する非負のシーケンスが中断される最初のインデックスになります。 

シフトされた配列をソートすると、0 から開始して連続する数値が何個出現するかを数えることができます。 最初のギャップは MEX を示します。 これにより、問題はテスト ケースごとに 1 つのソートと線形スキャンに減ります。

 | --- | --- | --- | --- |

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、配列を読み取ります。`a`長さの`n`。 
2. 配列内の最小値を計算します。`min_a`。 この値は、最小要素をゼロにするために必要なシフトを決定します。 
3. 配列を次のようにシフトします。`x = -min_a`。 これにより、最小の要素がゼロであり、すべての要素が負でないことが保証されます。 
4. シフトされた配列をソートします。 並べ替えにより、ゼロから上に向かってスキャンできるため、最初に欠落している整数を見つけることが簡単になります。 
5. 変数を初期化する`mex`ゼロに。 ソートされた配列を反復処理し、重複をスキップします。 各要素について、等しい場合`mex`、増分`mex`1 倍大きい最初の要素`mex`連続したシーケンスが中断されるため、`mex`その時点が配列の MEX になります。 
6. 出力`mex`シフト後の最大可能な MEX として。 

**機能する理由:** MEX は非負の整数であるため、最適なシフトでは一部の要素がゼロになる必要があります。 任意の要素をゼロ未満にシフトしても、最初に欠落している非負の整数を超えて MEX が増加することはありません。 並べ替えとスキャンにより、重複と連続したシーケンスが正しく考慮され、最初のギャップが検出されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_mex(a):
    min_a = min(a)
    shifted = [x - min_a for x in a]
    shifted.sort()
    mex = 0
    for val in shifted:
        if val == mex:
            mex += 1
    return mex

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(max_mex(a))
```**説明:**

 まず配列の最小値を計算してシフトを決定します。 引き算`min_a`すべての要素から、配列がゼロから始まることが保証されます。 配列をソートすると、チェックすることで最初に欠落している非負の整数を簡単に見つけることができます。`mex`それぞれの値に対して。 最後のループは、インクリメントするだけで重複を正しくスキップします。`mex`現在の値が等しいとき`mex`。

 ## 特殊なケース

 アレイの場合`[1,1]`、最小値は 1 です。シフト量`-1`収量`[0,0]`。 並べ替えると得られるもの`[0,0]`。 MEX のスキャンは 0 から始まります。 最初の要素 0 は MEX を 1 に増分し、2 番目の要素 0 はスキップされます。 正しい MEX は 1 です。これにより、重複によって MEX が人為的に拡張されていないことが確認されます。
