 ## 解決策
 ## 問題の理解

 各テスト ケースに対して一連の個別の「完全なルート」を生成するように求められます。 完全根は単なる整数です$x$そのような$x^2$も整数であり、これはすべての正の整数に自明のことながら当てはまります。 言い換えれば、すべての正の整数は、その二乗も整数であるため、完全根として認められます。 

入力は多数のテスト ケースで構成されます$t$、それぞれ整数を指定します$n$。 各テストケースについて、出力する必要があります。$n$個別の正の整数、最大でもそれぞれ$10^9$。 完全ルートの値には、テスト ケースごとに異なること、および指定された範囲内であること以外に制約はありません。 

重要な洞察は、問題は複雑な数学的計算を実行することよりも、異なる正の整数のセットを生成することにあるということです。 とすれば$n$値が小さく (最大 20)、値の制限が大きい ($10^9$）、パフォーマンスや大規模な数値生成について心配する必要はありません。 エッジケースには以下が含まれる可能性があります$n = 1$または$n = 20$、ただし、1 から 2 までの連続する整数の単純なシーケンス$n$十分かつ安全です。 不注意に実装すると、たとえば、単一のテスト ケースで誤って数値を繰り返したり、テスト ケースの範囲を超えたりする可能性があります。$10^9$限界。 

## アプローチ

 素朴なアプローチは、ランダムに数値を選択し、それらが区別できるかどうかを確認することです。 これは小規模な場合に機能します$n$ただし、一意性をチェックするオーバーヘッドは不要です。 さらに、ランダム性により衝突のリスクが生じ、再試行が必要になる可能性があります。 

最適なアプローチは決定論的です。つまり、最初の$n$正の整数を直接入力します。 これにより、すべての数値が個別であり、それぞれの数値が定義上完全なルートであり、それを超えるものがないことが保証されます。$10^9$。 最大値から$n$が 20 である場合、この解決策は非常に速くて簡単です。 最適化のコツや高度なデータ構造は必要ありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 一意性チェック付きのランダム生成 | 最悪の場合は O(n²) | O(n) | 不必要な複雑さ |
 | 決定的な連続整数 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る$t$テストケースの数に応じて。 これにより、各テスト ケースを個別に処理するループが設定されます。 
2. 各テスト ケースについて、整数を読み取ります。$n$これは、出力する完全根の数を指定します。 
3. 1 から 1 までの整数のリストを生成します。$n$。 各整数は、その二乗が有効な整数であるため、本質的に完全根です。 
4. 整数のリストをスペース区切りの値として 1 行に出力します。 
5. すべてのテスト ケースに対して繰り返します。 

機能する理由: このアルゴリズムは、各出力リスト内のすべての数値が個別で正であるという不変条件を保持し、各数値は$x$満足する$x^2$は整数です。 なぜなら$n \leq 20$、範囲は 1 ～$n$十分に制限内にあります$10^9$、正確性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    # generate perfect roots 1, 2, ..., n
    result = [str(i) for i in range(1, n + 1)]
    print(" ".join(result))
```このソリューションはテスト ケースの数を読み取り、それぞれを順番に処理します。 それぞれについて$n$、1 から 1 までの整数のリストを構築します。$n$。 整数を文字列に変換すると、次のように使用できます。`" ".join()`必要なスペース区切りの出力を生成します。 このアプローチにより、off-by-one エラーが回避され、すべての数値が確実に区別されます。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()

        n = int(input())

 ## 特殊なケース

 いつ$n = 1$、アルゴリズムが生成する`[1]`それは有効です。 のために$n = 20$、出力`[1, 2, ..., 20]`内に残ります$10^9$制限し、オーバーフローが発生しないことを確認します。 連続する整数が非連続ではあるが別個の値に置き換えられた場合でも、解決策は引き続き有効ですが、連続した選択により、重複のリスクがなく、単純さと正確さが保証されます。
