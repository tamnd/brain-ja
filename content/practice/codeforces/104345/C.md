 ## 解決策
 ## 問題の理解

 私たちは根を張った木を与えられています$N$構造が増分的にエンコードされる頂点: 各ノード$i+1$親がいる$p_i$、接続された非循環グラフを形成します。 この問題では、ツリーを超えて、ラベルの昇順でサイクル内のすべてのリーフを接続する 2 番目のエッジ セットが導入されます。 したがって、元の構造は、ツリーにすべての 1 次頂点にわたる外部サイクルを加えたものになります。 

目的は、このグラフの値を計算することではありません。 代わりに、最大でも新しいツリーを構築する必要があります。$4N$頂点を作成し、各頂点に元のノードの小さなサブセット (サイズは最大 4) を割り当てます。 これらのサブセットは、すべての元のエッジを「カバー」する必要があります。すべての元のツリー エッジとすべての追加されたサイクル エッジは、少なくとも 1 つのサブセットに完全に含まれている必要があります。 

同時に、元のノードごとに$j$、サブセットに含まれる新しい頂点をすべて収集すると、$j$、そのコレクションは新しいツリー内で接続されたサブグラフを形成する必要があります。 これは、分解またはジャンクション ツリーの要件に似た、セットに対する接続性の制約です。 元の各頂点は、構築されたツリー内の複数のノードによって表されますが、それらのすべての頂点は接続されたままでなければなりません。 

制約は次のとおりです$10^5$したがって、あらゆる構造は直線または直線に近いものでなければなりません。 二次関数または偶数関数$O(N \log N)$密な補助構造を構築するソリューションは許容されますが、頂点またはエッジのペアを繰り返し再訪するものはすべて失敗します。 

単純な試みでは、エッジごとに構造を明示的に構築し、おそらくエッジごとに 1 つの補助ノードを導入して、すべてを接続しようとします。 このアプローチでは、特に複数のエッジが重なる分岐点付近で、ノード セットの接続条件に違反する危険があります。 一般的な失敗ケースは、頂点が多くのエッジに属しており、構築されたさまざまなガジェット内でその頂点が出現するすべてが接続されたままであることが保証されない場合です。 

たとえば、頂点の場合、$u$多くの子があり、各エッジに個別にガジェットを作成します$(u, v_i)$、 それから$u$これらのコピーを明示的に接続しない限り、関係のない多くの場所に表示されます。 慎重に連鎖させないと、セットは$S_u$切断されます。 

中心的な困難は、元の各頂点の出現が接続された領域を形成することを保証しながら、同時に「エッジを小さなハイパーエッジにエンコードする」ことです。 

## アプローチ

 ブルート フォースの考え方では、エッジごとに新しいノードを作成し、両方のエンドポイントをそのノードのセットに含めることになります。 すべてのエッジが明示的にどこかに含まれるため、これはエッジ カバレッジ要件を直ちに満たします。 ただし、各頂点の接続要件は満たされません。高次の頂点は多くの独立したエッジ ノードに表示され、新しいツリーでそれらのノードの接続を強制するものはありません。 すべての出現間にペアごとの接続を追加してこれを修正すると、二次関数の爆発が発生します。 

重要な観察は、入力がすでにツリーであり、ツリーには自然な再帰的分解があるということです。 DFS 順序でツリーを処理すると、頂点のすべての外観を 1 つのチェーンに接続する線形構造を維持できます。 各エッジは、少数の補助ノードを使用してその端点でローカルに表現でき、頂点ごとに「バックボーン」パスを維持することで、これらのノードをグローバル ツリーにつなぎ合わせることができます。 

エッジを独立して処理する代わりに、DFS でツリーを処理し、DFS 内の親子関係を通じてリンクされる最大 4 要素のガジェットのシーケンスが各頂点に割り当てられる構造を構築します。 エッジをトラバースするたびに、両方のエンドポイントを含む単一の補助ノードを作成し、それを進化する構造に接続します。 重要な考え方は、各頂点が現在の代表ノードを維持し、将来のすべての出現がそれに接続され、そのセットの接続性が維持されるということです。 

これにより、エッジ間の任意の重なりの管理から、トラバーサルの各段階で頂点ごとに単一の接続点を維持するという問題が軽減されます。

 ## アルゴリズムのチュートリアル

 元のツリーの DFS トラバーサルを使用して新しいツリーを構築し、補助ノードの動的構造を維持します。 

1. ノード 1 で元のツリーをルートします。DFS を使用してそれを走査し、子を 1 つずつ処理します。 
2. 元のノードごとに$u$、「代表的な」新しいツリー頂点を維持します。$rep[u]$、これは、以下を含む最新に構築されたノードです。$u$。 これにより、すべての発生が保証されます。$u$常にリンクすることで接続を維持します$rep[u]$。 
3. ルートを表す単一ノードから構築を開始します。 セットにのみ含まれる新しい頂点を作成します。$\{1\}$、設定します$rep[1]$このノードに。 
4.エッジを加工する場合$(u, v)$DFS中から$u$に$v$、新しい補助ノードを作成します$x$誰のセットですか$\{u, v\}$。 このノードは、元のエッジ制約を直接「実現」します。 
5.接続する$x$に$rep[u]$、以前に発生したすべての$u$同じ接続コンポーネントに一度留まる$v$が紹介されています。 次に設定します$rep[u]$に$x$したがって、将来のアタッチメントはこの新しい位置を通過します。 
6. のサブツリーを再帰的に処理します。$v$、初期化中$rep[v] = x$。 これにより、今後発生するすべての$v$を表すエッジ ノードを介して接続されます。$(u, v)$のすべてのコピーを保持します$v$接続されています。 
7. DFS が完了すると、すべてのエッジがそのエンドポイントを含む少なくとも 1 つのノードで表されるツリーが構築されます。 元の各頂点は、DFS パスに沿った代表的な更新によって形成されたチェーンに表示されます。 
8. この構築では、構築されたツリーの各ノードに含まれる元の頂点は最大 2 つであるため、4 という制限内に十分収まります。 

### なぜ効果があるのか

 不変条件は、DFS 中のどの時点でも、構築された頂点のすべての出現が、$u$の連続的な更新によって形成されるチェーンを介して接続されます。$rep[u]$。 毎回$u$が新しいエッジ ノードに関与している場合、そのノードを前の代表に直接接続し、チェーンを分岐させるのではなく拡張します。 これにより、セットが$S_u$常に接続された部分グラフを生成します。 

すべての元のエッジは、そのエンドポイントを含む 1 つの構築されたノードによって明示的に表されるため、カバレッジは即時に行われます。 エンドポイントのすべてのオカレンスは連鎖しているため、頂点のオカレンスが切断されたコンポーネントに分割されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

n = int(input())
g = [[] for _ in range(n + 1)]

for i in range(2, n + 1):
    p = int(input())
    g[p].append(i)
    g[i].append(p)

# We will build a tree of nodes.
# Each node stores a subset of original vertices (size <= 2 here).
sets = []
edges = []

rep = [0] * (n + 1)

def new_node(s):
    sets.append(s)
    return len(sets)

def dfs(u, parent):
    # create initial representative for u if not exists
    if rep[u] == 0:
        rep[u] = new_node([u])

    for v in g[u]:
        if v == parent:
            continue

        # create edge node representing (u, v)
        x = new_node([u, v])

        # connect x with current representative of u
        edges.append((rep[u], x))

        # update representative of u
        rep[u] = x

        # set representative for v and continue DFS
        rep[v] = x
        dfs(v, u)

dfs(1, -1)

K = len(sets)

print(K)
for s in sets:
    print(len(s), *s)

for a, b in edges:
    print(a, b)
```この実装では、サブセット ノードのリストとそれらの間のエッジのリストが保持されます。 ツリーのエッジをトラバースするたびに、そのエンドポイントを含む新しいノードを作成し、それを親エンドポイントの以前の代表に接続します。 これは、すべてのオカレンスの接続を維持するメカニズムです。 

微妙な点は、再帰に入る前に代表が更新されることです。 これにより、より深いノードが各頂点の最新の出現に接続され、複数の互いに素なチェーンの形成が防止されます。 

## 実用的な例

 ### 例 1

 単純なチェーンを考えてみましょう$1 - 2 - 3$。 

| ステップ | 操作 | 新しいノードセット | 担当者の最新情報 |
 | --- | --- | --- | --- |
 | 1 | 初期化1 | {1} | 繰り返し[1]=1 |
 | 2 | エッジ (1,2) | {1,2} | rep[1]=2、rep[2]=2 |
 | 3 | エッジ (2,3) | {2,3} | 担当[2]=3、担当[3]=3 |

 構築されたノードはチェーンを形成し、各頂点のすべての出現がその代表的な更新を通じてリンクされます。 元の各頂点のノード オカレンスのセットが接続されます。 

### 例 2

 スターツリー$1$に接続されています$2,3,4$。 

| ステップ | 操作 | 新しいノードセット | 担当者の最新情報 |
 | --- | --- | --- | --- |
 | 1 | 初期化1 | {1} | 繰り返し[1]=1 |
 | 2 | エッジ (1,2) | {1,2} | rep[1]=2、rep[2]=2 |
 | 3 | エッジ (1,3) | {1,3} | rep[1]=3、rep[3]=3 |
 | 4 | エッジ (1,4) | {1,4} | rep[1]=4、rep[4]=4 |

 ノード 1 が複数のエッジ ノードに表示される場合でも、そのすべての代表は、連続する繰り返し間に追加したエッジを介してチェーンされます。$S_1$接続されたままになります。

 ## 特殊なケース

 高次ルートは最も敏感な状況です。 ノード 1 が多くの子に接続する場合、単純なアプローチではエッジごとに独立したガジェットが作成され、ノード 1 の出現が分割されます。この構造では、1 を含む新しい各エッジ ノードが 1 の前の代表に接続され、単一のチェーンを形成します。 これにより、1 のすべての出現が接続されたままになることが保証されます。 

長いチェーンでは、代表的な更新により以前の接続が誤って切断されないかどうかがテストされます。 各頂点は DFS に沿ってその代表を前方にのみ更新するため、後方分岐は発生せず、チェーンはそのまま残ります。 

深みのある退化した木$N$線形ノードの作成を超えないことを確認します。 各エッジは正確に 1 つの新しいノードを導入するため、最悪の場合のパス構造であってもサイズ境界は満たされたままになります。
