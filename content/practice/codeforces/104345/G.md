 ## 解決策
 ## 問題の理解

 重み付けされたツリーから始めるため、最初は頂点の各ペア間に単純なパスが 1 つだけ存在し、2 つの頂点間の距離はその一意のパスに沿った重みの合計にすぎません。 

各操作はグラフの構造を変更しますが、エッジの重みのマルチセットは保持されます。 既存のエッジを 1 つ選択して削除し、選択した 2 つの頂点の間に同じ重みを持つ新しいエッジを追加します。 このような操作を数回行うと、グラフがツリーである保証はなくなり、サイクルが含まれたり、部分的に「再配線」されたりする可能性があります。 

距離は常に、結果のグラフ内の最短パスを使用して定義されます。 2 つの頂点が切断されている場合、それらの距離はゼロとして定義されます。 「グラフの重み」は、頂点のすべてのペアにわたる最大最短経路距離であるため、事実上、接続されたコンポーネントの直径を追跡し、最適なものを選択することになります。 

タスクは、ゼロから K までの操作のすべての回数について、正確にその回数の再配線後のこの直径の最大可能値を計算することです。 

N、K ≤ 2000 という制約により、N または K の 3 次関数から遠ざけられます。状態ごとに O(N^2) または O(N^2 log N) 程度の解は許容されますが、各操作後にすべてのペアの最短経路を再計算するものは遅すぎます。 

この問題の微妙な問題は、エッジを再配線すると最短パスが増加したり減少したりする可能性があることです。 エッジを追加すると、距離を短縮するショートカットが作成される可能性があるため、「エッジを増やすと常に答えが増える」と考えるのは安全ではありません。 2 番目の落とし穴は、グラフが切断される可能性があることですが、切断されたペアの寄与はゼロであるため、作成する構造が少なくとも 1 つの大きな接続コンポーネントを無傷に保つことを常に保証する必要があります。 

## アプローチ

 直接的なアプローチでは、K 個の操作の可能なすべてのシーケンスをシミュレートします。 各シーケンスの後、ダイクストラまたはフロイド-ウォーシャルを使用してすべてのペアの最短経路を再計算し、最適な直径を追跡します。 これは、可能な操作シーケンスの数が膨大であり、距離の 1 回の再計算ですらすべての状態に対して繰り返すにはコストが高すぎるため、すぐに失敗します。 

重要な点は、この操作によってエッジの重みが変更されるのではなく、配置された場所のみが変更されるということです。 したがって、問題は重みを変更することではなく、重み付けされたエッジの固定セットを再配置して、単一の量、つまり最終的なグラフの最長最短パスを最大化することです。 

接続された加重グラフでは、直径は何らかの単純なパスによって実現されます。 これは、操作後の最適な構築では、常にその長さを短縮する代替ショートカットが存在しないことを保証しながら、大きな単純なパスを形成しようとすることを示唆しています。 私たちが目指すことができる最良の構造は、経路のように動作する木のようなバックボーンです。追加のサイクルは距離を短縮する危険があるためです。 

ここで、1 回の再配線操作で何ができるかを考えてみましょう。 エッジを削除するとツリーがローカルに壊れますが、それを別の場所に再接続すると、値を変更せずに 1 つの重み付けされたエッジを効果的に「再配置」できます。 複数の操作を通じて、より多くのエッジをより有用な位置に移動できるようになります。 

重要な構造上の洞察は、直径を最大化するために、単一のバックボーン パスに沿って有用なウェイトを集中させ、ショートカットを作成してエッジが干渉するのを避ける必要があるということです。 各操作により、自由に位置を変更できる追加のエッジが 1 つ効果的に得られます。これは、任意の構造を制御されたパスのような構成に徐々に変換できることを意味します。 i 回の操作後に達成可能な最良の直径は、元の直径に、近道を導入せずに直径を拡張するために作成できる i 個の慎重に選択したエッジの合計寄与を加えたものになります。

したがって、プロセスは、元の木の直径を追跡し、各操作が安全に寄与できる余分な長さを特定することに帰着します。 各操作は、ツリーの重要ではない部分から 1 つのエッジを「抽出」し、競合するより短いルートを作成せずに直径パスの 1 つの端点を延長する方法でエッジを再接続するために使用するのが最適です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 操作のブルート フォース シミュレーション + 最短パスの再計算 | 評価あたり O(N^3) の K の指数 | O(N^2) | 遅すぎる |
 | 安全エッジ寄与の直径ベースの貪欲な蓄積 | O(N^2 + K log N) | O(N^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 回の DFS 実行を使用して、初期ツリーの直径を計算します。 最初の DFS は任意のルートから最も遠いノードを見つけ、そのノードからの 2 番目の DFS は重み付けされた直径パスを与えます。 これにより、操作がゼロのベースラインの答えが得られます。 
2. 1 つの直径パスを回復します。 これらのエッジは構造的に重要であるため、このパス上にどのエッジがあるかを保存します。これらのエッジは、初期構成で可能な限り最も長いチェーンをすでに形成しています。 
3. 直径構造を維持するために不可欠ではないエッジを特定します。 直感的には、直径パスに厳密にバインドされていないエッジは、現在の最大距離を減らすことなく安全に「再利用」できるエッジです。 
4. 重み w を持つこのような非クリティカル エッジごとに、それを潜在的なゲインとして解釈します。 その理由は、このエッジを移動して直径パスの終点に接続できるため、既存の直径を縮小するショートカットを導入することなく最長のパスを w だけ延長できるからです。 
5. 最も有益な再配置が常に最初に使用されるように、利用可能なすべてのゲインを降順に並べ替えます。 
6. 1 から K までの i について、答えを初期直径に上位 i のゲインの合計を加えたものとして維持します。 

### なぜ効果があるのか

 重み付けされたツリーの直径は、常に単純なパスで得られます。 パスを維持するために構造的に必要でないエッジは、直径の端点に対して葉のような方法で取り付けられている限り、既存の最長パスを減らすことなく再配線できます。 

各操作では、そのような再配線の機会が 1 つだけ与えられるため、最良の戦略は、直径パスの拡張に積極的に寄与するエッジを独立して選択することです。 選択した各エッジは、以前に構築された拡張機能に影響を与えることなく配置できるため、ゲインは追加的であり、貪欲に並べ替えることができます。 

これにより不変条件が作成されます。i 個の操作を処理した後、直径パスが保存され、正確に i 個の追加エッジが干渉のない方法でアタッチされ、現在の直径を厳密に増加または維持する構成が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def dfs(start, adj):
    n = len(adj)
    dist = [-1] * n
    parent = [-1] * n
    parent_edge = [-1] * n

    stack = [(start, -1, 0)]
    dist[start] = 0

    while stack:
        u, p, acc = stack.pop()
        for v, w, eid in adj[u]:
            if v == p:
                continue
            if dist[v] == -1:
                dist[v] = acc + w
                parent[v] = u
                parent_edge[v] = eid
                stack.append((v, u, acc + w))

    far = max(range(n), key=lambda i: dist[i])
    return far, dist, parent, parent_edge

n, k = map(int, input().split())
edges = []
adj = [[] for _ in range(n)]

for i in range(n - 1):
    u, v, w = map(int, input().split())
    u -= 1
    v -= 1
    edges.append((u, v, w))
    adj[u].append((v, w, i))
    adj[v].append((u, w, i))

# first DFS
a, _, _, _ = dfs(0, adj)
b, dist, parent, parent_edge = dfs(a, adj)

diameter = dist[b]

# recover diameter path edges
on_diameter = set()
cur = b
while parent[cur] != -1:
    eid = parent_edge[cur]
    on_diameter.add(eid)
    cur = parent[cur]

# all edges not strictly on diameter path are treated as gain
gains = []
for i, (u, v, w) in enumerate(edges):
    if i not in on_diameter:
        gains.append(w)

gains.sort(reverse=True)

pref = [0]
for w in gains:
    pref.append(pref[-1] + w)

ans = []
for i in range(k + 1):
    if i < len(pref):
        ans.append(diameter + pref[i])
    else:
        ans.append(diameter + pref[-1])

print(*ans)
```最初の部分では、加重ツリー上の標準の 2 フェーズ DFS を使用して直径を計算します。 2 番目の DFS は親ポインターも記録するので、どのエッジが 1 つの直径パス上にあるかを再構築できます。 

そのパスを取得したら、エッジを 2 つのグループ (直径パス上のエッジとその外側のグループ) に分類します。 パスの外側のエッジは、将来の改善への独立した貢献者として扱われます。 

次に、これらの寄与を並べ替えてプレフィックスの合計を構築し、追加の各操作で残りの最良の改善が得られるようにします。 

最後に、ゼロ操作のベースライン直径を出力し、利用可能な最良のゲインを段階的に追加します。 

よくある実装上の落とし穴は、親の再構築では、多数ある可能性のある直径パスのうち 1 つしか提供されないことを忘れていることです。 これは、どの直径のパスでも同等の最適な選択肢まで同じセットの非クリティカル エッジを生成するため、これで十分です。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n, k = map(int, input().split())
    edges = []
    adj = [[] for _ in range(n)]
    for i in range(n - 1):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        edges.append((u, v, w))
        adj[u].append((v, w, i))
        adj[v].append((u, w, i))

    def dfs(start):
        dist = [-1] * n
        stack = [(start, -1, 0)]
        dist[start] = 0
        while stack:
            u, p, acc = stack.pop()
            for v, w, _ in adj[u]:
                if v == p:
                    continue
                if dist[v] == -1:
                    dist[v] = acc + w
                    stack.append((v, u, acc + w))
        far = max(range(n), key=lambda i: dist[i])
        return far, dist

    a, _ = dfs(0)
    b, dist = dfs(a)
    diameter = dist[b]

    gains = [w for _, _, w in edges if w <= 10**9]
    gains.sort(reverse=True)

    pref = [0]
    for g in gains:
        pref.append(pref[-1] + g)

    res = []
    for i in range(k + 1):
        res.append(diameter + pref[min(i, len(gains))])

    return " ".join(map(str, res))

 ## 特殊なケース

 最小の 2 ノード ツリーは、直径が正確に単一エッジの重みであり、どの操作でも達成可能な最大距離を変更せずに同じ重みを再付加するだけであるため、安定しています。 

星型構成では、直径は 2 つの最大の入射エッジによって決まり、アルゴリズムは、中心構造を壊すことなく付加できる潜在的なゲインとして直径以外のエッジを正確に分離します。 

パス状のツリーでは、すべてのエッジが何らかの直径のパスの一部であるため、有用なゲインはなく、すべての答えはすべての K 値にわたって一定のままです。これは、ショートカットを導入することなく、再接続によって完全な線形構造を改善できないという直観と一致します。
