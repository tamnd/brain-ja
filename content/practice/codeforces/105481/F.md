 ## 問題の理解

 最大 500 頂点の有向グラフが与えられます。 すべての頂点には同じ数の出向きエッジと入ってくるエッジがあり、グラフは強く接続されています。 このグラフ上に、単一の頂点やエッジだけでなく、固定長の頂点の完全なシーケンスを構成する「ヘビ」を配置します。 

ヘビの状態はシーケンスによって記述されます$a_0, a_1, \dots, a_m$。 解釈によると、蛇の頭は次の位置にあります。$a_0$、および連続する各ペア$(a_i, a_{i-1})$グラフ内の有向エッジである必要があります。 したがって、順序を逆にすると、$a_m \to a_{m-1} \to \dots \to a_0$、有効な長さの有向歩行が得られます。$m$。 

1 回の移動で、このウィンドウが下にあるウォークに沿って前方に移動します。新しいヘッドは、$a_0$、そして 1 つおきのジョイントが 1 位置ずつ前方に移動します。 したがって、ヘビは、グラフ内の有向ウォーク上のスライディング ウィンドウとまったく同じように進化します。 

このタスクは、任意の初期状態から開始して、考えられるすべてのスネーク状態を 1 回だけ訪れる一連の移動が何回存在するかを数えることです。 このような 2 つの完全な走査は、異なる状態から開始する場合、または状態を訪問する順序が異なる場合には異なります。 

制約が重要な問題です。 グラフサイズは小さいですが、スネークの長さは$m$と同じ大きさにすることができます$10^9$したがって、スネーク状態を明示的に構築したり反復したりすることはできません。 どのようなソリューションでも、依存関係を圧縮する必要があります。$m$代数構造への変換や、導出量に対する高速累乗など。 

微妙な点は、スネーク州の数が原理的にすでに膨大であるということです。 ただし、各状態は、長さの有向歩行に正確に対応します。$m$元のグラフでは、状態空間のサイズは$n \cdot k^m$、 どこ$k$は一般的な出次数です。 この指数関数的な依存度は、$m$つまり、状態や遷移を直接列挙することは決してないということです。 

素朴な誤解は、状態を独立したノードとして扱い、それらのノードの走査をシミュレートしようとすることです。 各状態にはその頭頂点の出次数に等しい分岐係数があるため、隣接関係を保存することさえ不可能ですが、状態の数自体は指数関数的です。$m$。

問題は、この巨大なグラフ内のハミルトニアン パスを数えることになります。 グラフを表現しても指数関数的であるため、これは絶望的です。$m$。 ボトルネックは、状態が独立したオブジェクトではないことです。 2 つの状態はウォークの接尾辞のみが異なるため、それらは大きく重なり合っています。

 ## アルゴリズムのチュートリアル

 解決は、すべてを元のグラフのラプラシアンと均一次数に還元することによって進められます。$k$。 

1. 共通出次数を計算する$k$すべての頂点の。 グラフが規則的であるため、これは明確に定義されています。 
2. 有向グラフのラプラシアン行列を構築します。ここで、対角要素は次のとおりです。$k$非対角のエントリは出力エッジを反映します。 この行列は、グラフのすべての範囲の樹木をエンコードします。 
3. 有向行列ツリー定理を使用して計算します。$\tau(G)$、固定ノードを根とするスパニング樹木の数。 通常の強接続ダイグラフでは、この値は根から独立しています。 
4. ヘビの長さから指数寄与を計算します。 それぞれの動きは長さを伸ばします -$m$一歩ずつ歩くと、すべてのステップに正確に$k$新しいエッジの選択肢。 すべての州をカバーするハミルトニアンの完全な構造全体にわたって、これにより次の係数が生成されます。$k^{m(n-1)}$、これは、複数の独立した分岐選択肢の蓄積を反映しています。$n-1$スパニング構造の選択の自由度。 
5. 構造要素と成長要素を掛け合わせると、最終的な答えは次のようになります。$\tau(G) \cdot k^{m(n-1)}$、剰余を取得$998244353$。 

重要な重要な点は、詳細な隣接パターンへのすべての依存関係が次のように崩壊するということです。$\tau(G)$、すべてに依存しながら、$m$の純粋指数に崩壊します$k$。 

### なぜ効果があるのか

 長さによって形成される状態グラフ -$m$walks は、$k$-正則オイラー有向グラフ。 折れ線グラフの構造はオイラーバランスを維持しながら、歩行の複雑さを 1 次元だけ引き上げます。 このようなグラフでは、グローバル トラバーサル カウントは、BEST 定理スタイルの分解、つまりローカル次数寄与とグローバル アーボレッセンス カウントの積によって支配されます。 

規則性により、すべての頂点が次数項に同じように寄与することが保証されるため、自明でないすべての組み合わせが元のグラフのスパニング ツリー構造に集中します。 ヘビの長さは、このローカル分岐構造がそれぞれの経路に沿って何回複製されるかを制御するだけです。$n-1$スパントラバーサルの独立した制約、指数を生成する$m(n-1)$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def mod_pow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def det_mod(mat):
    n = len(mat)
    res = 1
    sign = 1

    for i in range(n):
        pivot = -1
        for r in range(i, n):
            if mat[r][i]:
                pivot = r
                break
        if pivot == -1:
            return 0

        if pivot != i:
            mat[i], mat[pivot] = mat[pivot], mat[i]
            sign = -sign

        inv = pow(mat[i][i], MOD - 2, MOD)
        res = res * mat[i][i] % MOD

        for r in range(i + 1, n):
            factor = mat[r][i] * inv % MOD
            for c in range(i, n):
                mat[r][c] = (mat[r][c] - factor * mat[i][c]) % MOD

    return res * (1 if sign == 1 else MOD - 1) % MOD

n, m = map(int, input().split())
g = [list(map(int, input().split())) for _ in range(n)]

deg = sum(g[0])

k = deg

# build Laplacian minor (remove last row/col)
lap = [[0] * (n - 1) for _ in range(n - 1)]

for i in range(n - 1):
    for j in range(n - 1):
        if i == j:
            lap[i][j] = k
        else:
            lap[i][j] = (-g[i][j]) % MOD

tau = det_mod(lap)

ans = tau * mod_pow(k, m * (n - 1)) % MOD
print(ans)
```この実装では、まず隣接行列から一様次数を再構築します。 次に、次の配置によって縮小ラプラシアン行列を構築します。$k$対角線上と$-1$(モジュロ$MOD$) 有向エッジがあるところならどこでも。 

行列式はモジュロで計算されます$998244353$ガウス消去法を使用します。 これにより、広がる樹木の数が得られます。 

最後に、高速累乗は次のようになります。$k$力に$m(n-1)$、これは大きな制約が課される唯一の部分です。$m$が表示されます。 

実装の微妙な点は、行列式を素数を法として計算する必要があるため、逆剰余が有効であることです。 べき乗ステップは 64 ビット整数を使用して実行する必要があります。$m(n-1)$32 ビットの範囲を超える可能性があります。

 ## 特殊なケース

 エッジ ケースの 1 つは、グラフが有向サイクルのような規則的な構造であり、各頂点が出ていくエッジが 1 つだけある場合です。 その場合$k=1$, したがって、指数項は次のようになります。$1^{m(n-1)} = 1$、そして答えは完全にスパン樹木数に帰着します。 べき乗剰余演算は、次の条件に関係なく正しく 1 を返すため、アルゴリズムはこれを自然に処理します。$m$。
