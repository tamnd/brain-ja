 ## 解決策
 ## 問題の理解

 次のような形式で書かれたスコアボードが与えられます。`A-B`、 どこ`A`アレックスのスコアを表し、`B`相手のスコアを表します。 どちらの値も 0 ～ 9 の 1 桁です。 

システムは、2 つの値を単純に交換する「スコア錯覚」操作を適用します。 変身後、アレックスのスコアは相手のスコアとなり、相手のスコアはアレックスのスコアとなります。 出力は再度同じ形式で印刷する必要があります。`A-B`フォーマットされますが、値が交換されます。 

各値は入力文字列内で直接エンコードされた 1 桁であるため、制約は非常に小さくなります。 これは、文字の読み取りや文字列の分割以外に整数を解析する必要がないことを意味します。 入力ごとに一定時間で実行されるソリューションであれば、十分です。 

主な微妙な点は純粋に構文上であり、2 つの数値を正しく抽出し、書式を保持することです。 実装を不注意にすると、誤って文字列全体が数値として扱われたり、書式設定のバリエーションが現れたときに誤って分割されたりする可能性があります。 

具体的なエッジケースは、`0-0`。 正しい出力はまだです`0-0`。 もう一つは`9-0`、になるはずです`0-9`。 先頭のゼロを削除したり、複数桁の算術演算を想定したりする解析では、依然として正確な桁を保持する必要があります。 

## アプローチ

 ブルートフォース解釈では、A と B を数値として扱い、それらを整数に変換することで交換をシミュレートし、文字列を再構築します。 スワップは数値構造に依存しないため、これは正しく機能しますが、このような小さな固定サイズの入力には不要なオーバーヘッドになります。 

本当の簡素化は、入力形式が厳密に 1 文字、次にハイフン、そして 1 文字であることに気づくことから始まります。 曖昧さ、複数桁の解析、空白の処理はありません。 「計算」は文字の並べ替え問題のみです。 

したがって、解決策は文字列を読み取り、ハイフンの前後の文字を交換することになります。 算術はまったく必要ありません。

 ## アルゴリズムのチュートリアル

 1. 入力文字列を読み取る`s`、次の形式があります`A-B`。 この構造では、意味のある 3 文字と改行が正確に保証されます。 
2. 最初の文字を特定する`s[0]`アレックスのオリジナルスコアおよび最後のキャラクターとして`s[2]`相手のスコアとして。 中央の文字は常に区切り文字になります`-`。 
3. を配置して結果を構築します。`s[2]`、 それから`-`、 それから`s[0]`。 これにより、型の変換や値の変更を行わずに、「イリュージョン」が直接実装されます。 
4. 構築された文字列を出力します。 

### なぜ効果があるのか

 この問題は、固定位置に埋め込まれた 2 つの独立したスカラー値の純粋な交換として変換を定義します。 形式は不変であり、各スコアは単一の文字位置を占めるため、位置 0 と 2 で文字を交換すると、すべての意味上の意味が保持されます。 数字間に依存関係はなく、キャリーや算術効果もないため、文字の並べ替えは必要な変換と正確に一致します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s = input().strip()
print(f"{s[2]}-{s[0]}")
```実装は位置インデックスに完全に依存しています。 の`.strip()`改行文字がインデックス作成に干渉しないようにします。 形式が保証されているため、`digit-digits`、インデックス作成`s[0]`そして`s[2]`常に安全です。 

よくある間違いは、次のように分割しようとすることです。`-`そして書式設定を正しく再構築することを忘れます。 その間`split('-')`直接インデックスを作成する方が簡単で、中間の文字列割り当てを回避できます。

 ## 特殊なケース

 入力`0-0`は、同じ値を交換すると同じ文字列が保持される必要があることを示しています。 アルゴリズムは次のように読み取ります`s[0]=0`そして`s[2]=0`、次に構築します`0-0`、予想と一致します。 

のために`9-0`、アルゴリズムは抽出します`9`そして`0`そして出力`0-9`。 出力形式は数値ではなく純粋に位置であるため、特別な処理は必要ありません。 

すべての有効な入力は正確に 3 つの意味のある文字であるため、数字の同一性を超える構造的なエッジ ケースはなく、アルゴリズムがインデックス作成を通じて本質的に処理します。
