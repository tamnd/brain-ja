 ## 解決策
 ## 問題の理解

 各人は 2 つの映画に対して 1 つずつ、2 つの意見を持っています。 意見は 3 要素です。その人がその映画をレビューすると、+1、0、または -1 のいずれかになります。 すべての人を 2 つの映画のうちの 1 つに正確に割り当てる必要があり、この選択によって両方の映画のスコアが決まります。 企業スコアは 2 つの映画評価のうち小さい方として定義されるため、一方の映画だけを改善しても、もう一方の映画が遅れをとってしまうと十分ではありません。 

中心となる問題は、各割り当てが両方のムービー合計を同時に変更し、目的が 2 つの最小値に依存するため、独立した最大化ではなくバランスが強制されることです。 

この制約により、テスト ケース全体で最大 2⋅10^5 人が許可されるため、すべての割り当てを明示的に考慮するアプローチは即座に除外されます。 総当りの割り当てでは、テスト ケースごとに 2^n の可能性を探ることになりますが、これは n = 30 の場合でも不可能です。割り当ての数を超える DP であっても、実現するには慎重な圧縮が必要です。 

微妙な問題は、人が「非対称」である場合、たとえば (1, -1) に現れます。 ムービー 1 に送信すると増加し、ムービー 2 に送信するともう一方のムービーが減少します。 このような決定は、目に見えない形でバランスに影響を与える可能性があります。 たとえば、各人に自分がより好きな映画を貪欲に割り当てると、不均衡が生じて失敗します。 

例:

 n = 2

 (1、-1)、(-1、1)

 貪欲な割り当てでは、1 つのムービーに +1、もう 1 つのムービーに +1 が与えられるため、最小値で問題ありません。 ただし、わずかに変更されたディストリビューションでは、1 つの映画にネガが過剰に含まれるため、貪欲な選択により最小値が低下する可能性があります。 

本当の難しさは、すべての人が潜在的なデルタのペアを提供しており、最終的な最小合計を最大化するためにそれらを分配する必要があることです。 

## アプローチ

 強引な解釈は、各人物を二者決定として扱うことです。映画 A または B に割り当て、両方の結果の合計を計算し、最小値を取得します。 これはすべての構成を正しく評価しますが、2^n の割り当てを評価する必要があります。 n = 200,000 の場合、これは完全に不可能です。 

問題の構造を圧縮する必要があります。 重要な観察は、各人が選択した映画に 1 つの値だけを貢献しているが、他の値には何も貢献していないということです。 これは、重み付けされたアイテムを 2 つのビンに分配し、ビンの合計だけが問題になることを意味します。 

貢献を書き直すと役に立ちます。人物 i を映画 1 に割り当てる場合、a_i を S1 に追加します。 ムービー 2 の場合は、S2 に b_i を追加します。 min(S1, S2) を最大化したいと考えています。 

割り当てという観点から考えるのではなく、貢献のバランスという観点から考えます。 最小評価の目標値 X を推測するとします。 S1 ≥ X と S2 ≥ X の両方が満たされるように人を割り当てることは可能でしょうか?

 これにより、問題は実現可能性のチェックに変わります。 X の実現可能性を確認できれば、答えを二分探索できます。 

次に、X を修正して、各人を個別に分析します。 それぞれの人にとって、意味のあるケースが 3 つあります。 

a_i ≥ 0 および b_i ≥ 0 の場合、それらは「安全」であり、常にどちらかの側に役立ちます。 

両方がマイナスの場合、配置に関係なく有害であり、実現可能性が低下するだけです。 

混合の兆候が現れた場合は、割り当てが重要になります。すでにしきい値に近い映画に、非常に否定的な投稿を送ることは避けたいと考えています。 

これを正確に説明するために、実現可能性を「赤字」の分散として再解釈します。 各ムービーは 0 から始まり、X に到達する必要があります。各割り当ては、S1 または S2 を満たすのに貢献します。 私たちは、より大きなリスクを軽減する割り当てを優先します。

ただし、より強力な構造的単純化が観察されると、二分探索は不要になります。最適な答えは、ローカル ペアリング ロジックを使用して寄与のバランスを貪欲に調整することによって決定されます。 各人をムービー 1 とムービー 2 のどちらに適しているかで分類し、全体的なプラスとマイナスのバランスを確保しながら、害が少ない側または有益な側に割り当てたいと考えています。 

クリーンな削減とは、各映画が独立してどれだけ利益を得ることができるかを計算し、サイド間の「トレードオフ」を一致させることによってカップリングを解決することです。 標準的なソリューションでは、最終的に寄与の差によって並べ替えまたはグループ化し、限界利益のバランスを取ることで最小値が最大化されるようにします。

 ## アルゴリズムのチュートリアル

 重要なアイデアは、それぞれの映画がどれだけの利益を得ることができるかを分離し、人が一方の映画をもう一方の映画よりも好む場合の対立を解決することです。 

1. 両方の映画に対する各人の貢献度 (a_i, b_i) を計算します。 これらをムービー 1 に割り当てることは S1 に a_i を追加すること、ムービー 2 に割り当てることは S2 に b_i を追加することと解釈します。 これは私たちがコントロールする原子的な決定です。 
2. 差 d_i = a_i - b_i を定義します。 これは、映画 2 と比較して映画 1 がその人にとってどれだけ優れているかを測定します。d_i が大きい場合、映画 1 に割り当てると相対的に有益です。 
3. 人物を d_i で並べ替えます。 この順序は、各人が 1 つの映画に対してどの程度「偏っている」かを表しています。 これにより、人々をある映画から別の映画に移す移行を考慮することができます。 
4. 全員がムービー 2 に行く最初の割り当てから始めます。その後、S2 は sum(b_i) に固定され、S1 は 0 になります。徐々に人々をムービー 1 に移動させます。 
5. 最初の k 人 (ソート順) をムービー 1 に移動すると、次のように更新されます。 

S1 が a_i だけ増加し、b_i が減少すると、S2 ではカウントされなくなり、それに応じて S2 が減少します。 最終的な効果は、d_i を使用したプレフィックス調整によって取得されます。 
6. 各プレフィックス k の後で、S1(k) と S2(k) を計算し、min(S1(k), S2(k)) を評価します。 すべての k にわたる最大値を追跡します。 
7. 観察された最良の値を返します。 これが機能するのは、すべての最適解がしきい値分割に対応しているためです。つまり、d_i が小さい人はすべて一方の側に移動し、他の人はもう一方の側に移動します。 

### なぜ効果があるのか

 d_i による並べ替えにより、映画 2 から映画 1 に人物を交換するときは常に、最も有益な交換が最初に選択されることが保証されます。 この順序以外の決定を混合する最適な割り当ては、どちらの映画のスコア バランスも低下させることなく、この順序を尊重する割り当てに変換できます。 この交換引数は、ソートされた配列内の単一の境界で最適な分割が行われることを保証するため、すべてのプレフィックス カットをチェックするだけで十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        pairs = []
        base = 0
        
        for i in range(n):
            pairs.append((a[i] - b[i], a[i], b[i]))
            base += b[i]
        
        pairs.sort()
        
        s1 = 0
        s2 = base
        ans = min(s1, s2)
        
        for d, ai, bi in pairs:
            s1 += ai
            s2 -= bi
            ans = max(ans, min(s1, s2))
        
        print(ans)

if __name__ == "__main__":
    solve()
```実装では「ムービー 2 に割り当てられたすべてから開始」の視点を使用します。 変数`base`は映画 2 の合計初期スコアです。人を映画 1 に移動すると、その人の貢献度が`s1`そして彼らのものをから削除してください`s2`。 これにより、合計を再計算しなくても、正しいグローバル状態が維持されます。 

並べ替え順`a_i - b_i`それぞれの動きがその段階で利用可能な最も収益性の高いスワップであることを保証します。これはまさにエクスチェンジの議論が要求するものです。 

よくある間違いは、人を動かすと片側が増えるだけではなく、両側が同時に変化するということを忘れていることです。 コードは明示的に減算することでこれを処理します。`b_i`から`s2`。

 ## 特殊なケース

 すべての貢献が両方の映画に対してマイナスである場合、まれなケースが発生します。 その場合、すべての割り当てで少なくとも 1 つの映画が減り、最良の戦略は、害を集中させるのではなく、均等に分散させることです。 

たとえば:

 n = 2

 a = [-1, -1]

 b = [-1, -1]

 アルゴリズムの実行:

 初期 S2 = -2

 ソートされた差分は等しいため、順序は任意です。 

何らかの移動の後、S1 と S2 は両方とも負の値に等しくなり、最大最小値は -1 のままになります。 このアルゴリズムは、すべてを 1 つのムービーに割り当てるのではなく、ダメージを分割することで不均衡の悪化を正確に回避します。 

もう 1 つの特殊なケースは、すべての違いが同一である場合です。 その場合、すべてのプレフィックスは同じ構造を生成し、アルゴリズムは意味のあるすべての分割をあいまいさなく評価します。
