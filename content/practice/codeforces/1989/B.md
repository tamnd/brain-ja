 ## 解決策
 ## 問題の理解

 2 つの重複する制約を満たす文字列を構築するように求められます。指定された文字列を 1 つ含める必要があります。$a$、部分文字列として、および別の文字列として、$b$、サブシーケンスとして。 部分文字列と部分シーケンスの違いは重要です。 部分文字列は連続しているため、次のすべての文字が$a$結果の文字列に連続して出現する必要があります。 サブシーケンスでは文字をスキップできるため、$b$結果の文字列全体に順番に分散して表示される場合があります。 目標は、結果として得られる文字列の全長を最小限に抑えることです。 

入力は複数のテスト ケースで構成され、それぞれに文字列が与えられます。$a$そして$b$最大 100 までの長さ。$10^3$テスト ケースでは、すべてのケースの長さの合計が十分に小さいため、文字列長が 2 次であるアルゴリズムを使用できます。$10^4$テストケースごとの操作$100^2 \cdot 10^3 = 10^7$, これは 2 秒の制限にうまく収まります。 

重要なエッジケースが発生する場合$a$そして$b$共通のキャラクターを共有します。 たとえば、次の場合$a = "abc"$そして$b = "bcd"$、最適に結合された文字列は連結ではありません。`"abc" + "bcd" = "abcbcd"`、 しかし`"abcd"`重なるところは`"bc"`両方にカウントされます$a$部分文字列として、および$b$続編として。 常に文字列を連結する不注意な方法では、必要以上に長い文字列が生成されてしまいます。 

もう 1 つの微妙なケースは、一方の文字列がもう一方の文字列内に完全に含まれている場合です。 例えば、$a = "aaa"$そして$b = "aa"$満足できる`"aaa"`、 ない`"aaaa"`。 すべてのオーバーラップを効率的に処理することが重要です。 

## アプローチ

 ブルートフォース手法では、候補文字列内のすべての可能な位置を列挙します。$a$が表示されてから、残りの文字を挿入しようとする可能性があります。$b$順番に。 これは正しいですが、長さが小さいため不要であり、問​​題は端の間の最大の重なりを慎重に計算することで解決できます。$a$そして$b$接頭辞として。 重要な観察は、次の最長の接尾辞を見つけるだけでよいということです。$a$のプレフィックスに一致するもの$b$、その重なりを使用して文字数をカウントできるためです。$b$向かって$a$同時に。 最大のオーバーラップが決定されると、結果として得られる最小の長さは単純に次のようになります。$|a| + |b| - \text{overlap}$。 

これにより、問題は面倒な挿入検索からきれいな線形スキャンに変わります。$a$そして$b$最適かつ簡単に実装できるようになります。 各テスト ケースに必要なのは、最大でも$O(|a| \cdot |b|)$制約を考慮すると許容できる操作です。

 ## アルゴリズムのチュートリアル

 1. テストケースごとに文字列を読み取ります。$a$そして$b$。 これらは部分文字列と部分列の制約を表します。 
2. 変数を初期化する`overlap`ゼロに。 これは、次の最長の接尾辞の長さを追跡します。$a$$b` のプレフィックスと一致します。 
3. $a の可能なすべてのサフィックス長を反復処理します。`from 1 to`min(len(a), len(b))`。 
4. 各サフィックスの長さについて`l`、最後かどうかを確認してください`l`の登場人物`a`最初と等しい`l`の登場人物`b`。 その場合はアップデートしてください`overlap = l`。 
5. 重複する可能性のあるものをすべてチェックした後、結合された文字列の最小長を次のように計算します。`len(a) + len(b) - overlap`。 これにより、共有された文字は 1 回だけカウントされます。 
6. この最小長を出力します。 

これが機能する理由: サフィックスとプレフィックスの重複を最大にすることで、文字を維持しながらできるだけ多くの共有文字を使用することが保証されます。$a$連続 (部分文字列の場合に必要)、および$b$(サブシーケンスに必要な) 順序で。 オーバーラップが小さくなると、オーバーラップ内の文字が 2 重にカウントされるため、全体の長さが長くなります。 定義上、オーバーラップは不可能になるため、この方法では最小限の長さが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a = input().strip()
        b = input().strip()
        max_overlap = 0
        for l in range(1, min(len(a), len(b)) + 1):
            if a[-l:] == b[:l]:
                max_overlap = l
        print(len(a) + len(b) - max_overlap)

if __name__ == "__main__":
    solve()
```このコードは、考えられるすべてのサフィックスとプレフィックスの重複を反復処理し、最小長を効率的に計算します。 の`.strip()`末尾の改行文字が比較の妨げにならないようにします。 このソリューションは複数のテスト ケースを処理し、問題の高速 I/O 要件を尊重します。

 ## 特殊なケース

 いつ$a$そして$b$が同一である場合、アルゴリズムは文字列の長さに等しい重複を正しく計算し、文字列自体に等しい最小長を生成します。 文字が入っていない場合$b$の終わりと一致する$a$、重なりはゼロのままで、解は単純に連結されます。$b$と$a$順番に、部分文字列または部分シーケンスのルールに違反することなく両方の条件が満たされるようにします。 単一文字の文字列の場合、重複チェックにより、同じ文字が両方の役割を果たすことができるかどうかが正しく識別され、長さ 2 ではなく 1 が生成されます。
