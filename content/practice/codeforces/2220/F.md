 ## 解決策
 ## 問題の理解

 うちには根が生えた木があります。 すべての頂点は、順列からの一意の値を保持します。$0,1,\dots,n-1$。 

頂点の場合$v$、ルートからルートまでのすべての頂点を見てください。$v$パス。 それらの値はセットを形成します$S_v$。 定義する$$f(v)=\operatorname{MEX}(S_v),$$そのパスから欠落している最小の非負の値。 

何も操作しない場合のスコアは、$$\sum_v f(v).$$1 つの変更を行う場合があります。 頂点を選択してください$v$、その現在を計算します$f(v)$、上書きします$p_v$その値で。 置換後、すべてのパス MEX 値が再計算され、新しい合計スコアが生成されます。 可能な限り最大のスコアが必要です。 

ツリーには以下が含まれます$2\cdot10^5$すべてのテスト ケースにわたる頂点。 考えられるすべての操作を試し、すべての MEX 値を再計算するソリューションには、少なくとも$O(n^2)$動作しますが、完全に実行不可能です。 平$O(n\sqrt n)$この規模では不快です。 目安は大まかに$O(n\log n)$。 

主な問題は、1 つの頂点を変更するとすべての子孫に影響することです。 影響を受けるすべてのパスを単純に更新すると、大きなサブツリーに繰り返し影響することになります。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

値がすでにそのパス MEX より小さい頂点を考えてみましょう。```
root(0) -> child(2)
```子のパスセットは$\{0,2\}$、 それで$f=1$。 値の置換$2$による$1$欠損値を挿入するので有益に見えますが、実際には子孫の MEX 値が減少する可能性があります。 すべての交代をプラスの貢献として扱うのは間違いです。 

もう 1 つの微妙なケースは、挿入された MEX がすでにパスの奥にある場合に発生します。```
values on path: {0,1,3}
mex = 2
```すでに値を含む子孫の場合$2$、さらに追加$2$古い値を削除しても何も変わりませんが、新しい穴が生じる可能性があります。 子孫とは効果が全く異なります。$2$は不在です。 

順列特性も重要です。 すべての値は 1 回だけ表示されます。 値がいつ$a$に置き換えられます$m$、 価値$a$世界的に消滅し、$m$重複してしまいます。 多くの単純化はこの一意性に依存しています。 

## アプローチ

 強引なアイデアは単純明快です。 

頂点ごとに$v$:

 1. すべての現在のパス MEX 値を計算します。 
2. 交換する$p_v$による$f(v)$。 
3. すべてのパス MEX 値を最初から再計算します。 
4. 新しい合計を評価します。 

たとえ 1 回の再計算が行われたとしても、$O(n)$、すべての頂点コストを試す$O(n^2)$。 と$n=2\cdot10^5$、それは限界をはるかに超えています。 

何かをより速く得るには、1 つの操作によって答えがどのように変化するかを正確に理解する必要があります。 

頂点を操作するとします$v$。 

させて$$a=p_v,\qquad m=f(v).$$以来$a$の道に属します$v$そして$m$はパス MEX で、常にあります$a\neq m$。 

の子孫のみ$v$影響を受けています。 そのようなすべての子孫は、そのパス セットが次から変換されるのを目にします。$$S_u$$の中へ$$(S_u\setminus\{a\})\cup\{m\}.$$サブツリーの外側は何も変わりません。 

これにより、問題の原因がサブツリー クエリに限定されます。 

次の観察が重要です。 

あらゆる子孫のために$u$の$v$、すべての値$0,\dots,m-1$すでにその道筋に現れている$u$、彼らはすでにその道に現れているからです。$v$。 したがって、$$f(u)\ge m.$$これにより、根本的に異なる 2 つのカテゴリが作成されます。 

もし$f(u)>m$、次に値$m$のパス上にすでに存在します$u$。 

もし$f(u)=m$、次に値$m$は不在です。 

両方の状況を注意深く分析した後、あらゆる貢献は以下を通じてのみ表現できます。$$\text{mex}_1(u)=f(u)$$そして$$\text{mex}_2(u),$$どこ$\text{mex}_2(u)$の次の欠損値です$\text{mex}_1(u)$。 

すべての頂点についてこれら 2 つの値がわかれば、すべての可能な演算のゲインをサブツリーの合計とカウントの組み合わせとして記述することができます。 オイラー ツアー フラット化によりサブツリー クエリが区間クエリに変換され、セグメント ツリー スイープのコレクションによってすべてのゲインが評価されます。$O(n\log n)$。

 ## アルゴリズムのチュートリアル

 ### コンピューティング$\text{mex}_1$そして$\text{mex}_2$まずツリーを頂点でルートします$1$。 

DFS 中に、ルートから現在のパスに現在どの値が存在するかを維持します。 

セグメント ツリーは値に基づいて構築されます$0\dots n$。 

位置には以下が保存されます。```
1 -> value absent
0 -> value present
```最初の欠落値はまさに MEX です。 

頂点ごとに$u$:$$\text{mex}_1(u)=f(u).$$私たちにも必要です$$\text{mex}_2(u),$$より厳密に大きい最小の欠損値$\text{mex}_1(u)$。 

どちらの値も、DFS 中に同じ構造から取得できます。 

同時にオイラーツアーも構築します。 

させて：$$tin[u],\ tout[u]$$サブツリー間隔になります。 

### 基本的な答えの計算

 何も操作せずに答えは単純です。$$base=\sum_u \text{mex}_1(u).$$### 負の寄与の計算

 頂点を仮定します$v$もっている$$a=p_v.$$子孫は、現在の MEX が超過した場合にのみマイナスに寄与します。$a$。 

マイナス寄与の合計は次のようになります。$$\sum_{\substack{u\in sub(v)\\ \text{mex}_1(u)>a}} (a-\text{mex}_1(u)).$$次のように書き換えます$$a\cdot C-\Sigma,$$どこ$C$はそのような頂点の数であり、$\Sigma$それらの MEX 値の合計です。 

MEX 値に対する降順スイープでは、すべての頂点が維持されます。$\text{mex}_1\ge a$2 つのセグメント ツリー内:

 1. 数える
 2. MEX 値の合計

 サブツリー クエリは、順列値が次の値に等しい一意の頂点の負の部分を即座に生成します。$a$。 

### プラスの寄与を計算する

 正のゲインは次の場合にのみ可能です$$a>m,$$どこ$$m=\text{mex}_1(v).$$同じ頂点$\text{mex}_1=m$一緒に処理されます。 

子孫のために$u$同じグループからの貢献は等しい$$\min(a,\text{mex}_2(u))-m.$$これは、次のしきい値の比較に依存します。$a$そして$\text{mex}_2(u)$。 

各グループ内では、頂点が減少して処理されます。$a$。 

セグメント ツリーには、すべてのグループ メンバーの現在の貢献フォームが保存されます。 スイープが値を渡すたびに、より大きい値を持つすべての頂点が$\text{mex}_2$は一度更新されます。 

各頂点は一定の回数だけ構造に出入りし、次のようになります。$O(k\log n)$ある程度の規模のグループのために働く$k$。 すべてのグループを合計すると、これは残ります$O(n\log n)$。 

### 最終的な答え

 頂点ごとに$v$、$$gain(v)=positive(v)+negative(v).$$結果は$$base+\max\Bigl(0,\max_v gain(v)\Bigr).$$### なぜ効果があるのか

 重要な不変条件は、頂点を選択した後、$v$、影響を受けるすべてのパスはまったく同じ変換を受けます。$$S_u \rightarrow (S_u\setminus\{a\})\cup\{m\}.$$以下のすべての値があるため、$m$が存在し続けることが保証されている場合、新しい MEX は、$a$、$m$、現在の MEX、および 2 番目の MEX。 

事例分析は網羅的です。 すべての子孫には、すでに次のものが含まれています$m$またはそうではありません。 それぞれの場合において、結果として得られる MEX は次のように表すことができます。$\text{mex}_1$そして$\text{mex}_2$一人で。 セグメントツリー スイープは、サブツリー範囲にわたってこれらの式を正確に評価するため、すべてのゲインが正しく計算されます。 最良のゲインを採用すると、最適な動作が得られます。

 ## 特殊なケース

 次のことを考慮してください。```
1
1
0
```唯一の道は$\{0\}$、その MEX は$1$。 

値を次のように置き換えます。$1$パス MEX を次のように変更します$0$。 

ゲインはマイナスです。 アルゴリズムはこのゲインを記録し、最終的に$$\max(0,\text{gain}),$$だから答えは残る$1$。 

次に、次のことを考えてみましょう。```
root value = 1
child value = 0
```子供はMEXを持っています$2$。 

子の値を次のように置き換えます。$2$値を削除します$0$そのパスから、より小さな MEX を作成します。 正と負の寄与の式は、次の比較を通じてこの状況を正確に分類します。$a$そして現在のMEX。 

最後に、挿入された値がパスにすでに含まれている子孫を考慮します。$m$。 このような頂点は、$\text{mex}_1(u)>m$カテゴリ。 分析の結果、次のことがわかります。$m$効果はなく、単に削除するだけです$a$重要です。 まさにこれが、利益の計算式に別個の負の要素が含まれており、利益の二重計算を防ぐ理由です。
