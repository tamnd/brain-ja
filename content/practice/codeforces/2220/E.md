 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、`n`ノード。各ノードは赤または黒です。 目標は、確率的操作を使用してすべてのノードを赤にすることです。ノードを選択し、均一にランダムに選択された隣接ノードの 1 つの色でそのノードの色を変更します。 入力は複数のテスト ケースを提供し、それぞれにノードの数、初期色を表すバイナリ文字列、およびツリーのエッジが含まれます。 出力は、ツリー全体を赤にするために予想される操作の最小数です。 

制約には効率的な処理が必要です。`n`は最大 200,000 まで可能で、すべてのテスト ケースの合計も 200,000 になります。これにより、ランダム操作や指数関数的な状態の列挙の単純なシミュレーションが除外されます。 各操作は現在のノードの近隣ノードに依存するため、ソリューションはツリーを通じて期待値を効率的に伝播する必要があります。 

明らかではないエッジ ケースには、黒いノードに黒の隣接ノードしかない木や、赤い親を持つ黒の葉が含まれます。 ツリー構造と近傍次数を考慮せずに期待される演算を計算しようとすると、即時変換を誤って想定し、誤った期待が生じる可能性があります。 たとえば、隣接する赤い葉が 1 つある黒い葉の期待値は次のとおりです。`1`最初の操作で赤くなるからです。 2 つの黒の隣接ノードがあるが、1 つの遠くにある赤のノードがある黒ノードには、再帰的な期待値計算が必要です。 

## アプローチ

 ブルート フォース アプローチでは、すべての操作シーケンスをシミュレートし、各シーケンスの平均ステップ数を計算します。 正しいのですが、状態空間は次のように指数関数的に増大するため、これは実行不可能です。`n`、一般に操作の数に制限はありません。 たとえば、20 ノードのチェーンであっても、完全な列挙を試みると、100 万を超える州をシミュレートする必要があります。 

重要な洞察は、あるノードが赤になるまでの予想される操作数は、その隣接ノードの予想値にのみ依存するということです。 これにより、ツリー上で再帰的な定式化が可能になり、葉がすぐに解決され、期待値が上に伝播します。 ツリーでは、各ノードの期待値はその近傍ノードに関して表現でき、深さ優先検索を使用してこれらの値を効率的に計算できます。 

各ノードの期待値は次のとおりであるという観察`1 + sum(E[neighbor])/deg(node)`黒いノードの場合、`deg(node)`近傍をカウントするので、問題をツリーの線形走査に縮小してみましょう。 赤いノードの期待値はゼロです。 これにより、テスト ケースごとに O(n) 個のソリューションが得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O(2^n) | O(n) | 遅すぎる |
 | DFS 期待の伝播 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数の入力を解析します。 テスト ケースごとに、次の内容を読んでください。`n`、バイナリ文字列`s`、そして`n-1`エッジ。 ツリーを表す隣接リストを作成します。 
2. 配列を初期化する`E`期待値の。 セット`E[i] = 0`if ノード`i`赤くて、`None`if ノード`i`黒です。 
3. 再帰関数を定義する`dfs(u, parent)`ノードの予想される操作数を計算します`u`:

 1. ノードの場合`u`赤の場合は0を返します。 
2. それ以外の場合は初期化します`sum_neighbors = 0`そして`degree = len(adj[u])`。 
3. 隣人ごとに`v`の`u`（自転車運転防止のため親は除く）、電話`dfs(v, u)`そして結果を追加します`sum_neighbors`。 
4. コンピューティング`E[u] = 1 + sum_neighbors / degree`。 これは、1 回の操作に隣接する操作からの平均期待値を加えたものになります。 
5. 戻る`E[u]`。 
4. 電話をかける`dfs(root, -1)`少なくとも 1 つの赤いノードが存在するため、任意の赤いノードから開始します。 
5. 印刷`E[root]`十分な精度で。 

機能する理由: 再帰関数は、期待値の線形性を使用して正確な期待値を計算します。 隣接ノードの期待値が正しく伝播される限り、各ノードの操作は他の場所で適用される操作の順序とは無関係です。 赤いノードは期待値ゼロの吸収状態として機能し、再帰が確実に終了し、期待される最小限の操作数が生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        adj = [[] for _ in range(n)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            adj[u-1].append(v-1)
            adj[v-1].append(u-1)
        
        E = [None]*n
        red_nodes = [i for i, c in enumerate(s) if c == '1']
        for r in red_nodes:
            E[r] = 0.0

        def dfs(u, parent):
            if E[u] is not None:
                return E[u]
            total = 0.0
            deg = len(adj[u])
            for v in adj[u]:
                if v == parent:
                    continue
                total += dfs(v, u)
            E[u] = 1.0 + total / deg
            return E[u]
        
        # start from any black node
        for i in range(n):
            if E[i] is None:
                dfs(i, -1)
        # the maximum expected among black nodes
        res = max(E[i] for i in range(n))
        print(f"{res:.12f}")

solve()
```このコードはツリーを読み取り、期待値を初期化し、DFS を使用して期待値を伝播します。 使用する`max(E[i])`すべてのノードを赤色にするために予想される最小限の操作を確実に報告します。 浮動小数点精度は次のように処理されます。`:.12f`。
