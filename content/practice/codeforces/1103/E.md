 ## 問題の理解

同じ長さになるように先頭にゼロを付けて数値を並べる場合、各桁位置で個別に桁を追加し、結果のモジュロ 10 を取得します。これは、桁間にキャリーがないことを意味します。 選択したすべての数値に対してこれを行った後、再び桁ごとに表現された最終的な数値が得られます。 

タスクは、各整数を計算することです$i$から$0$に$n-1$、長さはどれくらいですか-$n$シーケンスは次の基数合計を生成します。$i$、最後の数値は通常の 10 進数表現で解釈されます。 

重要な難しさは、次の長さのシーケンスを数えているという事実から来ています。$10^5$、各番号には最大 5 桁を含めることができます。 単純なシミュレーションでは、考えられるすべての数字の組み合わせを追跡する必要があります。$n$独立した選択肢は、$n$。 状態空間全体にわたる多項式畳み込みであっても、結果として得られる可能性のあるすべての数値に対して直接実行すると、大きすぎます。 

弾性率$2^{58}$は、任意の大きな整数が必要ないことを示すため重要ですが、問題の組み合わせ構造は変わりません。 

桁の長さが異なる数値について考えると、微妙な特殊なケースが現れます。 たとえば、ある数字が`7`そしてもう一つは`10000`、数字を揃えると、位置ごとの寄与が変化します。 数値を数字ベクトルではなく整数として扱う単純なアプローチでは、キャリーが明示的に禁止されているため、キャリーが誤って混在し、誤った遷移が生成されます。

## アプローチ

 ブルートフォースソリューションは、長さのすべてのシーケンスを明示的にシミュレートします。$n$。 シーケンス内の各位置には、$n$選択肢があるので、$n^n$可能なシーケンス。 各シーケンスについて、桁ごとの合計を計算します。$O(D)$時間どこ$D$桁数です。 合計を計算するコストを無視しても、列挙すると、$n^n$シーケンスは完全に不可能です。 

より構造化されたビューは、各桁の位置が独立して変化することを観察することです。 桁の位置を固定すると、選択したすべての数値が 0 から 9 までの桁に寄与し、実質的に合計することになります。$n$循環群にわたる独立した確率変数$\mathbb{Z}_{10}$。 これにより、問題はサイズ 10 の周波数分布の繰り返し畳み込みに変換されます。 

各桁位置について、計算後の可能な合計の分布を計算したら、$n$選択すると、完全な答えは桁位置にわたる積になります。 これは、異なる桁位置がまったく相互作用しないため、合計数が因数分解されるためです。 

したがって、問題は、桁位置ごとに 10 状態の畳み込みパワーを計算し、各ターゲット数値を解釈して桁位置を結合することに帰着します。$i$桁ごとに。

 ## アルゴリズムのチュートリアル

 各小数点を個別に処理し、結果を乗算的に結合します。 

1. 配列内の各数値を固定長の数字ベクトルに変換します。$D = 5$、先頭にゼロを埋め込みます。 

これにより、すべての数値にわたって桁の位置が揃うようになり、位置ごとの加算が明確に定義されます。 
2. 各桁位置について$d$、周波数配列を構築します$f_d$サイズ 10 の場合、$f_d[x]$桁のある数字が何個あるかを数えます$x$位置にある$d$。 

これにより、入力がその位置での可能な寄与にわたる分布に圧縮されます。 
3. 各桁位置について$d$の合計の分布を計算します。$n$からの独立したピック$f_d$、ここで加算はモジュロ 10 です。 

これは、巡回グループに対する畳み込みを繰り返すことによって行われます。$\mathbb{Z}_{10}$。 結果は配列です$g_d$どこ$g_d[s]$桁の合計が等しくなる方法の数です$s$。 

重要な点は、ここでの畳み込みは整数ではなく、剰余 mod 10 で行われるため、インデックスがラップアラウンドすることです。 
4. 数字の位置を組み合わせてクエリに答えます。 

目標数値に向けて$i$、その数字を抽出します$i_0, i_1, \dots$。 生成するシーケンスの総数$i$は：$$\prod_d g_d[i_d]$$もし$i$以下より少ない$D$桁数、欠落している上位桁はゼロとして扱われるため、次の値を掛けます。$g_d[0]$それらのポジションのために。 
5.全員の結果を出力$i$から$0$に$n-1$、同じ数字の抽出ルールを適用します。 

### なぜ効果があるのか

 重要な不変条件は、基数合計の下で桁の位置が完全に独立していることです。 キャリーがポジション間を通過することはありません。そのため、各ポジションの寄与は、そのポジションで選択された桁のマルチセットにのみ依存します。 各選択は位置ごとに 1 桁を独立して寄与するため、グローバル カウントは独立した巡回畳み込み結果の積に考慮されます。 これにより、位置ごとの分布を乗算して正確に有効なシーケンスの数が得られることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = (1 << 58)

# convolution on Z_10 using direct cyclic convolution
def conv(a, b):
    res = [0] * 10
    for i in range(10):
        if a[i] == 0:
            continue
        ai = a[i]
        for j in range(10):
            if b[j] == 0:
                continue
            res[(i + j) % 10] = (res[(i + j) % 10] + ai * b[j]) % MOD
    return res

# exponentiation of cyclic convolution polynomial
def power(poly, exp):
    res = [0] * 10
    res[0] = 1
    base = poly
    while exp:
        if exp & 1:
            res = conv(res, base)
        base = conv(base, base)
        exp >>= 1
    return res

n = int(input())
xs = list(map(int, input().split()))

D = 5
digits = [[0] * 10 for _ in range(D)]

for x in xs:
    for d in range(D):
        digits[d][x % 10] += 1
        x //= 10

# compute distribution per digit position
dp = []
for d in range(D):
    poly = digits[d]
    dp.append(power(poly, n))

# answer queries 0..n-1
def get_digits(x):
    res = [0] * D
    for i in range(D):
        res[i] = x % 10
        x //= 10
    return res

ans = []
for i in range(n):
    digs = get_digits(i)
    ways = 1
    for d in range(D):
        ways = (ways * dp[d][digs[d]]) % MOD
    ans.append(str(ways))

print("\n".join(ans))
```この実装では、まず各桁の位置をヒストグラムに圧縮し、次にそのヒストグラムを次の値に引き上げます。$n$巡回畳み込みにおける - 乗。 累乗では二乗演算が繰り返され、畳み込み演算ではモジュロ 10 桁の加算が強制されます。 

最後のループは、各出力インデックスを 5 桁の数値として解釈し、対応する桁ごとの寄与を乗算します。 弾性率$2^{58}$オーバーフローを防ぐために全体に適用されます。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべての数値がゼロの場合です。 この場合、すべての桁位置は完全にゼロに集中した分布を持ち、すべての畳み込みパワーはゼロに集中したままになります。 他の数字の組み合わせは形成できないため、アルゴリズムはインデックス 0 に対して 1 つの有効なシーケンスを正しく生成し、その他すべてに対して 0 を生成します。 

別の特殊なケースは、出力インデックスの範囲を超えて数値の上位桁のみが異なる場合に発生します。 これらの上位の桁は依然として中間の畳み込み状態に影響を与えますが、クエリされた出力には影響しません。$i$はゼロとして扱われ、対応するゼロ剰余分布で乗算されます。 

3 番目のケースは、すべての数値が同じ位置で同じ桁を共有する場合です。 この場合、畳み込みはまったく広がらず、べき乗ではデルタ分布が維持されます。 デルタ関数の畳み込みは乗算を繰り返してもデルタのままであるため、アルゴリズムはこれを正しく処理します。
