 ## 解決策
 ## 問題の理解

 この問題は、接続された村のツリーを記述します。 1 つの木には 2 つの村の間のルートが 1 つだけあるため、すべての道路が単一障害点になります。 すべての村のペア間に少なくとも 2 つの異なる単純なルートが存在するように、最小限の追加の道路を追加する必要があります。 同様に、道路を追加した後は、グラフに橋があってはなりません。橋はまさに道路であり、その除去によりグラフが分離され、2 つの独立したルートができなくなるからです。 

入力により、いくつかのテスト ケースが得られます。 ケースごとに、村の数と`N - 1`既存の道路が木を形成しています。 出力は、必要な新しい道路の最小数です。 

すべてのテストにわたる村の総数に対する制約は大きいため、アルゴリズムは線形に近い必要があります。 可能性のある新しい道路を試したり、多くの村のペアをチェックしたりするソリューションでは、すぐに時間がかかりすぎてしまいます。 最大数十万のノードがある場合、すべてのエッジと頂点を一定の回数だけ処理する必要があります。 

難しいのは、葉で何が起こっているかを理解することです。 葉には発生する道路が 1 つだけあるため、元のツリーではその道路は常に橋になります。 この弱点を取り除く唯一の方法は、葉を木の別の部分に接続し、その端を含むサイクルを作成することです。 追加される道路の最小数は葉の数ではありません。1 つの新しい道路は、2 つの葉の枝を接続することで一度に 2 つの葉を修正できるからです。 

3 つの頂点を持つツリーを考えてみましょう。```
3
1 2
2 3
```葉が２枚あります。 正しい答えは、`1`の間にエッジを追加するため、`1`そして`3`両方の元の道路を含むサイクルを作成します。 リーフごとに 1 つの道路を追加する不注意なアプローチでは、次のような結果が得られます。`2`。 

もう 1 つの特殊なケースは、葉の数が奇数の木です。 例えば：```
5
1 2
1 3
1 4
1 5
```葉が4枚あるので、答えは`2`。 一致しない最後の葉を処理せずに葉を貪欲にペアリングする方法は、葉の数が奇数の木では失敗する可能性があります。 

## アプローチ

 直接的なアプローチは、葉のペアを繰り返し選択し、葉の間に道路を追加することです。 道路が追加されるたびにサイクルが作成され、サイクルはまさに橋を取り除くものであるため、この考えは合理的です。 考えられるそれぞれの選択肢の影響をシミュレートし、最適な道路のセットを探し続けると、可能性の数は急速に増加します。 葉の多い木の場合、考えられる組み合わせが多すぎるため、検索は指数関数的に行われます。 

有益な観察は、新しい道路がどのように変化するかを観察することによって得られます。 2 つのリーフを接続すると、それらのリーフ間のパス上のすべてのエッジがサイクルの一部になります。 最初に保護されていない唯一のエッジは、葉で終わる枝です。 ツリー全体にブリッジを持たせないようにするには、すべての葉の端が何らかのサイクルに属する必要があります。 追加された 1 つの道路には、最大 2 つのリーフ エッジを含めることができます。これは、その 2 つの端点が外側の 2 つの枝を直接閉じることができる唯一の場所であるためです。 

これにより下限が与えられます: ツリーが`L`葉、少なくとも必要です`ceil(L / 2)`新しい道路。 葉をペアにすることで、いつでもこれを達成できます。 もし`L`が偶数の場合、すべてのリーフを別のリーフとペアにします。 もし`L`が奇数の場合は、1 つを除くすべてのリーフをペアにし、残りのリーフを最終接続で使用します。 ツリー構造により、これらの追加がすべてのリーフ エッジをカバーすることが保証されます。 

問題全体は、葉を数えるということに帰着します。 与えられた制約の下では頂点が 1 つあるツリーは不可能であり、ここでの有効なツリーには少なくとも 2 つの葉があります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 葉の数の指数関数 | 検索状態に応じて | 遅すぎる |
 | 最適 | O(N) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ツリーを読み取り、隣接する頂点が 1 つだけ存在する頂点の数を数えます。 これらの頂点は葉であり、その頂点に含まれる道路は、最初はどのサイクルにも属せない唯一の道路です。 
2. 葉の数を次のようにします。`L`。 1 つの新しい道路で 2 つのリーフを接続し、対応する両方の枝を固定できるため、リーフをペアに分割します。 
3. もし`L`が偶数であれば、答えは`L / 2`。 すべてのペアが 1 つの新しい道路に貢献します。 
4. もし`L`が奇数である場合、あるリーフを別のリーフとペアにすることはできません。 さらに 1 本の道路で接続する必要があるため、答えは次のようになります。`(L + 1) / 2`。 

これが機能する理由は、2 つの内部頂点間のツリー内のすべての道路がすでに葉の間のパス上にあるためです。 すべてのリーフ エッジがサイクルに含まれると、追加されたリーフ接続によって内部パスを通過するサイクルが作成されるため、他のすべてのエッジもサイクル上に位置します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return

    t = int(data[0])
    idx = 1
    ans = []

    for _ in range(t):
        n = int(data[idx])
        idx += 1

        deg = [0] * n

        for _ in range(n - 1):
            u = int(data[idx]) - 1
            v = int(data[idx + 1]) - 1
            idx += 2
            deg[u] += 1
            deg[v] += 1

        leaves = 0
        for d in deg:
            if d == 1:
                leaves += 1

        ans.append(str((leaves + 1) // 2))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```コードには各村の度数のみが保存されます。 答えは存在するリーフの数のみに依存するため、隣接リストは必要ありません。 

各道路を読み取っている間、両方のエンドポイントは 1 度増加します。 すべての道路が処理された後、次数 1 の頂点はリーフになります。 最後の表現`(leaves + 1) // 2`は、葉の数の半分の上限を取る整数形式です。 

頂点は次数のカウントにのみ使用されるため、メイン ロジックにはインデックス作成の落とし穴はありません。 入力では 1 ベースのインデックスが使用されますが、配列では 1 を減算した後、0 ベースのインデックスが使用されます。 村の最大数は多数であるため、ソリューションではバッファリングされた入力を使用します。

## テストケース```python
import sys
import io

def solution(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        deg = [0] * n

        for _ in range(n - 1):
            u, v = map(int, input().split())
            deg[u - 1] += 1
            deg[v - 1] += 1

        leaves = sum(1 for x in deg if x == 1)
        out.append(str((leaves + 1) // 2))

    return "\n".join(out)

 ## 特殊なケース

 パスツリーの場合:```
3
1 2
2 3
```葉っぱは、`1`そして`3`。 アルゴリズムは葉を 2 枚数えて返します`(2 + 1) // 2 = 1`。 それらの間にエッジを追加すると、元の両方のエッジを含む 1 つのサイクルが作成されます。 

スターの場合:```
5
1 2
1 3
1 4
1 5
```葉が４枚あります。 アルゴリズムは戻ります`2`。 新しい道路はそれぞれ外側の 2 つの村を接続できるため、葉の 4 つの端すべてをカバーするには 2 本の道路で十分です。 

奇数の葉を持つ木の場合、次のようになります。```
6
1 2
1 3
1 4
1 5
5 6
```葉っぱは、`2`、`3`、`4`、 そして`6`したがって、この特定のケースには葉が 4 つあり、2 本の道路が必要になります。 ノードからさらに1つのブランチを追加した場合`1`の場合、葉の数は 5 になり、式は 3 を返します。これは、ある葉を別の葉と組み合わせることができないため必要です。
