 ## 解決策
 ## 問題の理解

 整数と数値の配列が与えられます$x$それをエハブは嫌う。 目標は、合計が次の値で割り切れない最長の連続する部分配列の長さを見つけることです。$x$。 各テスト ケースでは、新しい配列と新しい$x$。 条件を満たすサブ配列がない場合、出力は次のようになります。$-1$。 

入力配列は最大で$10^5$要素の長さ、配列内の値、および$x$まで行くことができます$10^4$。 実行ごとに最大 5 つのテスト ケースがあるため、ソリューションは最悪の場合でも線形でなければならないことを意味します。$n$すべての部分配列を調べる単純な 2 次アプローチでは、大まかに次の処理が必要になるため、テスト ケースごとに$5 \times 10^5 \times 10^5 / 2$最悪の場合、1 秒の制限時間には遅すぎる操作が発生します。 

微妙なエッジ ケースには、すべての要素が次の倍数である配列が含まれます。$x$。 たとえば、$a = [2, 4, 6]$そして$x = 2$、部分配列の合計は 2 で割り切れるため、出力は次のようになります。$-1$。 もう 1 つのエッジ ケースは、配列全体の合計が既に次の値で割り切れない場合です。$x$; その場合、最長の部分配列が配列全体になります。 ゼロまたは等しい単一要素を含む配列$x$また、動作が異なる可能性があるため、偶然の間違いを避けるために慎重な取り扱いが必要です。 

## アプローチ

 ブルートフォースアプローチでは、すべての部分配列を明示的にチェックし、それらの合計を計算し、次のように割り切れるかどうかをテストします。$x$。 これは論理的に機能しますが、サブ配列の数は$O(n^2)$、それぞれの合計を計算すると、$O(1)$プレフィックス合計付き。 合計操作はまだです$O(n^2)$、これは不可能です$n = 10^5$。 

重要な洞察は、可分性の性質がグローバルであるということです。 配列全体の合計が次の値で割り切れない場合$x$の場合、完全な配列がすでに答えになっています。 和が割り切れる場合$x$の場合、この可分性を壊すために少なくとも 1 つの要素を削除する必要があります。 部分配列は連続したままでなければならないため、最初の要素が次の要素で割り切れなくなるまで接頭辞または接尾辞のいずれかを削除します。$x$に達すると、可能な限り長い部分配列が得られます。 すべてのサブ配列をチェックする必要はありません。 必要なのは、次の要素で割り切れない最初と最後の要素だけです。$x$。 この観察により、解は二次時間から線形時間に短縮されます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 テスト ケースごとに、次の内容を読んでください。$n$そして$x$そして配列を読み取ります$a$。 
2. 配列の合計を計算します。 この合計が割り切れない場合は、$x$、すぐに戻ります$n$、配列の全長。 
3. 合計が割り切れる場合$x$、配列を左からスキャンして、値が次の値で割り切れない最初の要素を見つけます。$x$。 そのインデックスを次のように保存します`left`。 
4. 配列を右からスキャンして、値が次の値で割り切れない最初の要素を見つけます。$x$。 そのインデックスを次のように保存します`right`。 
5. そのような要素が存在しない場合、すべての要素は次のように割り切れます。$x$そして、部分配列は、次の値で割り切れない合計を持つことはできません。$x$; 戻る$-1$。 
6. それ以外の場合は、2 つの候補サブ配列長を計算します。プレフィックスを削除して、`left`収量`n - left - 1`、その後のサフィックスを削除します`right`収量`right`。 答えは、これら 2 つの長さの最大値です。 

ここでの不変条件は、合計が次の値で割り切れる配列の一方の端から要素を削除することです。$x$割り切れない要素に到達するまでは、残りの部分配列の合計が割り切れないことが保証されます。$x$。 より多くの要素を削除してもサブ配列が不必要に短くなるだけであるため、これは可能な限り最長です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, x = map(int, input().split())
    a = list(map(int, input().split()))
    
    total = sum(a)
    if total % x != 0:
        print(n)
        continue
    
    left = 0
    while left < n and a[left] % x == 0:
        left += 1
    right = n - 1
    while right >= 0 and a[right] % x == 0:
        right -= 1
    
    if left == n:  # all elements divisible by x
        print(-1)
    else:
        print(max(n - left - 1, right))
```実装はアルゴリズムに直接に従います。 最初にフルアレイの場合を扱います。 左右のスキャンは、最初の分割不可能な要素で停止する単純な線形パスです。 max の計算では、最長の部分配列の両方のオプションが考慮されます。 境界条件 (次で割り切れるすべての要素など)$x$、別のチェックで明示的に処理されます。 

## 実用的な例

 トレースサンプル 1:

 入力:`3 3` `1 2 3`- 合計 = 6、3 で割り切れます。 
- 左をスキャン: 最初の要素 1 % 3 != 0、インデックス 0。 
- 右にスキャン: 最後の要素 3 % 3 == 0、インデックス 1 の最後から 2 番目の要素 2 % 3 != 0。 
- 候補の長さ:`n - left - 1 = 3 - 0 - 1 = 2`、`right = 1`。 最大 = 2。 

入力:`3 4` `1 2 3`- 合計 = 6、4 で割り切れません。 
- 答え = 3、配列の完全な長さ。

 ## 特殊なケース

 すべての要素が次の値で割り切れるとき、$x$、アルゴリズムはこれを次の方法で正しく識別します。`left == n`チェック。 で割り切れない要素が 1 つだけある配列の場合$x$、アルゴリズムは次のように計算します`n - left - 1`そして`right`正しく、条件を満たす最大の連続サブ配列を選択します。 合計がすでに割り切れない配列の場合、アルゴリズムは不必要なスキャンを回避し、配列全体の長さを返します。
