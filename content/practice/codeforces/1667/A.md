 ## 解決策
 ## 問題の理解

 配列を構築するように求められます$b$配列から$a$の各要素が$b$の対応する要素の倍数を加算または減算することによって、ゼロから取得されます。$a$。 目標は作ることです$b$移動と呼ばれる、実行される加算または減算の数を最小限に抑えながら、厳密に増加します。 入力は配列で構成されます$a$と$n$正の整数であり、出力は最小の手を表す単一の整数です。 

制約$n \le 5000$より悪いアルゴリズムがあることを示します$O(n^2)$タイムアウトになる可能性が高いため、$5000^2 = 25 \cdot 10^6$操作は 2 秒以内に実行可能な操作の上限に近くなります。 幅広い範囲$a_i$値、最大$10^9$、考えられるすべてを列挙することに依存するアプローチを示唆しています。$b_i$値を明示的に指定することは非現実的です。 エッジケースには、すべての配列が含まれます。$a_i$が等しい場合、増加シーケンスを達成するには、符号を交互に移動する必要があります。$a_i$は相互に比べて大きいため、加算または減算の数を慎重に選択する必要があります。 

素朴なアプローチでは、それぞれの倍数を加算または減算するあらゆる可能な組み合わせを試すことができます。$a_i$、しかし、これはすぐに指数関数的になります。 もう 1 つの微妙なエッジ ケースは、連続した要素が$a$は等しいかほぼ等しいため、オーバーシュートすることなく厳密に増加させるためには、正の動きと負の動きを正確にシーケンスする必要があります。 たとえば、次の場合$a = [1, 1, 1]$、のシーケンス$b$そうかもしれない$[-1, 0, 1]$3 つの手で可能ですが、不用意なアプローチをすると、$[1, 1, 1]$増加は生じません。 

## アプローチ

 ブルートフォース手法では、要素ごとに可能なすべての移動回数を探索しようとします。$b$、到達可能なすべての値を追跡します。 それぞれについて$b_i$、次の形式のすべての整数を試すことができます。$k \cdot a_i$そして$-k \cdot a_i$と$k \ge 0$シーケンスが増加するまで。 理論的には正しいですが、可能性の数が急速に増加するため、これは指数関数的に複雑になります。$n$そしてその大きさ$a_i$。 

重要な観察点は、それぞれの要素が$b$の任意の整数倍に独立して調整できます。$a_i$。 移動を最小限に抑えるために必要なのは、次のことだけです。$b_i > b_{i-1}$それぞれのステップで、それぞれの$b_i$の加算または減算の最小数を見つけることができます。$a_i$この不等式を満たすものです。 これにより、問題は貪欲な増分アプローチに縮小されます。要素を左から右に処理し、前の要素の現在の値を追跡し、配置する最小移動数を計算します。$b_i$厳密にはそれより上です。 各要素の最適な手数は、必要な差を次の値で割った上限を取ることで計算できます。$a_i$, 必要以上に足したり引いたりしても、合計の手数が増えるだけだからです。

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`prev`構築された配列の最後の値を表すゼロへ`b`。 カウンタを初期化する`moves`ゼロに。 
2. 各要素を反復処理する`a[i]`配列内で。 各要素について、必要な加算または減算の最小数を計算します。`b[i]`厳密にそれより大きい`prev`。 最小移動数は、必要な次の値とゼロの間の絶対差を で割ることによって得られます。`a[i]`、切り上げます。 
3. 署名された手を計算します。 もし`prev`が負でない場合は、次の最小の正の倍数を選択します。`a[i]`それは厳密により大きいです`prev`。 もし`prev`が負の場合、最小限の移動には次の倍数を減算することが含まれる可能性があります。`a[i]`上にジャンプする`prev`。 重要なのは、厳密な増加を保証するために各ステップで最小限のステップ数のみが考慮されることです。これは次のように常に達成可能です。`a[i]`はポジティブです。 
4. 現在の要素の移動数を合計に加算します。`moves`カウンターと更新`prev`の新たな価値へ`b[i]`。 
5. すべての要素を処理した後、合計を出力します`moves`。 

不変条件は、要素を処理した後のものです。`i`、`b[0..i]`厳密に増加しており、`moves`は、このプロパティを達成するために必要な操作の最小数です。 各ステップで最小倍数を計算することにより、冗長な移動は決して実行されず、最適性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

prev = 0
moves = 0

for x in a:
    if prev >= 0:
        k = prev // x + 1
        b_val = k * x
    else:
        k = (-prev + x - 1) // x
        b_val = k * x
    moves += abs(k)
    prev = b_val

print(moves)
```各反復では、次の最小の正の倍数が計算されます。`a[i]`前回を超えるもの`b`価値。 整数の除算を使用すると、正しい切り上げが保証されます。 更新します`prev`新しいものを反映するために`b[i]`、 そして`moves`操作の合計数を累積します。 ネガティブのエッジ処理`prev`浮動小数点除算を使用せずに正しい天井動作を保証します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    prev = 0
    moves = 0
    for x in a:
        if prev >= 0:
            k = prev // x + 1
            b_val = k * x
        else:
            k = (-prev + x - 1) // x
            b_val = k * x
        moves += abs(k)
        prev = b_val
    return str(moves)

# custom cases
