 ## 解決策
 ## 問題の理解

 私たちは、一連の慈善活動に関する勧告を経て、あるグループの人々の予想最大資産を計算する任務を負っています。 各人は既知の金額から始めます。 いくつかの推奨事項があり、それぞれが 1 ドルを受け取る人々のセグメントを指定しており、各推奨事項にはそれが実行される確率があります。 期待される最大の富、つまり「良さ」は、これらの確率を考慮した、考えられるすべての結果の加重平均です。 

重要な複雑さは 2 つの特性から生じます。 まず、セグメントは素になったり入れ子になったりする可能性があります。つまり、一方が他方に完全に含まれない限り、2 つのセグメントが部分的に重なり合うことはありません。 第 2 に、確率は推奨事項ごとに独立しています。 最大 100,000 人の人々と 5,000 件の推奨事項を効率的に処理する必要がありますが、推奨事項のサブセットの数が指数関数的に増加するため、すべての結果を列挙するアプローチは実行不可能になります。 

単純なアプローチでは、受け入れられた推奨事項のすべての 2^q サブセットをシミュレートし、各サブセットの結果として得られる資産配列を計算し、最大値の加重平均をとろうとする可能性があります。 q が 5,000 までの場合、これは明らかに不可能です。 もう 1 つの微妙な点は、ネストされたセグメントを正しく処理することです。あるセグメントが別のセグメントの中にある場合、その効果は重複するため、依存関係チェーンで処理する必要があります。 これらの依存関係を無視すると、間違った期待値が生成される可能性があります。 

エッジケースには、複数の重複する推奨事項を持つ 1 人の人物、すべての推奨事項が拒否または受け入れられること、同一または異なる確率で繰り返されるセグメントが含まれます。 たとえば、ある人が最初に 3 ドルを持っていて、どちらも確率 0.5 でそれらをカバーする 2 つの推奨事項を受け取った場合、期待される最大値は単純に 3 + 0.5 + 0.5 = 4 ではありません。 両方が同時に適用される可能性を考慮する必要があります。 

## アプローチ

 ブルート フォース ソリューションでは、受け入れられた推奨事項の可能なすべてのセットを反復処理します。 セットごとに、対象者ごとに金額を増額し、最大額を計算します。 このアプローチは確率モデルを尊重するため機能しますが、q が 5,000 までの場合、可能なセットは 2^q であるため、まったく実行不可能になります。 

重要な洞察は、セグメントの階層構造を認識することです。 セグメントは互いに素であるかネストされているため、ツリーとして表すことができます。各セグメントにはネストされたセグメントが子として含まれ、素なセグメントは別個のツリーを形成します。 セグメントの場合、外部の他のセグメントとは独立して、その内部のネストされたセグメントの確率のみを考慮する必要があります。 これにより、セグメント ツリー上で動的プログラミング アプローチが可能になり、セグメントごとに、そのセグメント内で受け入れられた推奨事項の数の確率分布を計算します。 次に、ネストされたセグメントの分布を結合して、親セグメントの寄与を取得できます。 

各セグメントが対象となる各人に最大 1 ドル追加するという事実を利用して、さらに最適化できます。 考えられるすべての合計を追跡する代わりに、人が各潜在的な値に段階的に到達する確率を追跡できます。 確率が独立しているため、これを再帰的に計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべてのサブセット) | O(2^q * n) | O(n) | 遅すぎる |
 | セグメントツリー DP / 確率分布 | O(n * q) | O(n * q) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 入力を解析します: 人の数 n、彼らの初期資産配列、推奨事項の数 q、および各推奨事項とそのセグメント境界と承認確率。 
2. 封じ込めに基づいて推奨事項のツリーを構築します。 セグメント A にセグメント B が完全に含まれている場合、B は A の子になります。互いに素なセグメントは別々のルートになります。 セグメントを左端点と長さで並べ替えると、親の割り当てが簡素化されます。 
3. 再帰関数を定義する`dfs(segment)`セグメント内の最大富増加の確率分布を計算します。 各セグメントは、受け入れられた場合、その確率とともに範囲内の各人に 1 ドルを寄付します。 動的プログラミングを使用する: 配列を維持する`dp[i]`ネストされたセグメントからちょうど i ドルの追加を人が受け取る確率を表します。 
4. 各葉セグメントの確率分布は単純です。確率 p の場合は 1 ずつ増加し、1-p の場合は 0 ずつ増加します。 
5. 親セグメントの場合、その子の分布を畳み込みによって結合し、親自体が受け入れられる確率を計算します。 これにより、サブツリー全体の結合された確率分布が得られます。 
6. 各人について、独立性を利用して、その人をカバーするすべてのセグメントの分布を結合します。 次に、確率で重み付けされたすべての可能な増分を合計して、期待される最大資産を計算します。 
7. 最後に、互いに素なセグメントのすべての独立したツリーにわたる期待される最大値を合計して、全体的な期待される良好さを取得します。 

機能する理由: ツリー表現により、各セグメントの効果が切り離されたセグメントから独立して計算されることが保証され、DP によりすべてのネストされた依存関係が考慮されることが保証されます。 確率分布は、明示的に列挙することなく、受け入れられた推奨事項のすべての組み合わせを完全にエンコードします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from functools import lru_cache

n, q = map(int, input().split())
a = list(map(int, input().split()))

segments = []
for _ in range(q):
    l, r, p = input().split()
    segments.append((int(l)-1, int(r)-1, float(p)))

# Sort segments by left then right to help nesting
segments.sort(key=lambda x: (x[0], -x[1]))

# Build tree
parents = [-1] * q
stack = []
for i, (l, r, _) in enumerate(segments):
    while stack and segments[stack[-1]][1] < r:
        stack.pop()
    if stack:
        parents[i] = stack[-1]
    stack.append(i)

children = [[] for _ in range(q)]
for i, p in enumerate(parents):
    if p != -1:
        children[p].append(i)

# dp[i][k] = probability that this segment adds exactly k dollars to all its covered people
@lru_cache(None)
def dfs(idx):
    l, r, p = segments[idx]
    # Leaf segment
    probs = {0: 1 - p, 1: p}
    for child in children[idx]:
        child_probs = dfs(child)
        new_probs = {}
        for k1, v1 in probs.items():
            for k2, v2 in child_probs.items():
                new_probs[k1+k2] = new_probs.get(k1+k2, 0) + v1*v2
        probs = new_probs
    return probs

# For each person, accumulate probability of increments
exp_max = 0.0
increments = [0.0] * n
for i in range(n):
    prob = {0: 1.0}
    for j, (l, r, p) in enumerate(segments):
        if l <= i <= r and parents[j] == -1:
            seg_probs = dfs(j)
            new_prob = {}
            for k1, v1 in prob.items():
                for k2, v2 in seg_probs.items():
                    new_prob[k1+k2] = new_prob.get(k1+k2, 0) + v1*v2
            prob = new_prob
    # Expected value of this person's final wealth
    exp = sum((a[i] + k) * v for k, v in prob.items())
    exp_max = max(exp_max, exp)

print(f"{exp_max:.9f}")
```このソリューションは入力を解析し、セグメントを並べ替えてネストを管理し、親子ツリーを構築します。 の`dfs`関数は各セグメントの確率分布を再帰的に計算し、各個人の互いに素なセグメントの分布を結合します。 最後に、1人当たりの期待資産を計算し、最大値を追跡します。
