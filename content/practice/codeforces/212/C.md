 ## 解決策
 ## 問題の理解

 私たちは牛を円形に配置し、それぞれの牛が隣の 2 頭のうちの 1 頭と正確に面するように配置されています。 円をバイナリ文字列として表します。各文字は方向を表します。1 つの記号は「時計回りの隣を指す」を意味し、もう 1 つは「反時計回りの隣を指す」を意味します。 

私たちは毎秒、隣接するすべての牛のペアを調べます。 隣接する 2 つがお互いを指している場合、それらは同時に方向を反転します。 これはそのようなすべてのペアで一度に発生するため、同じステップで牛は最大 2 頭の隣のペアの影響を受ける可能性があり、これらの影響が組み合わされます。 

タスクは逆です。順方向にシミュレーションする代わりに、1 秒後に構成が与えられ、それを生成できる初期構成の数を数えなければなりません。 

円の長さは最大 100 であるため、構成の数が 2 次または 3 次である解は問題ありませんが、すべてを列挙するものは何でも問題ありません。$2^n$直接状態を示すことは直ちに不可能です。 重要な問題は、遷移が局所的ではあるが重複していることです。各位置は、サイクル全体を結合する方法で、隣接する 2 つの位置に依存します。 

微妙なエッジ ケースは、円が非常に小さい場合です。たとえば、$n=3$。 このような場合、すべての牛は他の牛と隣接しているため、すべてのフリップは同じ小さな制約セットと相互作用します。 ブルート推論では、サイクルを終了するときにのみ現れる一貫性条件を簡単に二重カウントしたり、見逃したりする可能性があります。 

もう 1 つの重要なエッジ ケースは、最終構成が均一である場合、たとえばすべての文字が等しい場合です。 この状況では、隣接するペアは「相互」ではないため、反転は発生しませんが、初期構成が一意であることを意味するわけではありません。2 つの隣接ペアからの反転がキャンセルされるため、複数の初期状態が同じ最終状態に崩壊する可能性があります。 

## アプローチ

 この問題を直接考える方法は、すべての初期構成を試し、1 秒先のシミュレーションを行うことです。 各構成には次のものが必要です$O(n)$すべての位置が隣接する位置をチェックする必要があるため、シミュレーションする時間があります。$2^n$構成。 これは次のことにつながります$O(n2^n)$、これはすでに実行不可能です$n=25$、そして完全に絶望的です$n=100$。 

個々のフリップの追跡をやめ、代わりに隣接するもの間の差異を追跡すると、この構造は管理可能になります。 牛は、その 2 つのエッジがそれぞれ「アクティブ」であるかどうかに基づいてのみ状態を変更します。これは、2 つのエンドポイントが初期設定で異なることを意味します。 各アクティブ エッジは両方のエンドポイントに 1 つのフリップを与え、2 つのアクティブ エッジが相殺されます。 

これにより、問題が状態遷移からサイクルにわたる線形パリティ制約のシステムに変換されます。 各位置の最終値は、その初期値とその周囲のアクティブなエッジのパリティによって異なります。 重要な結果は、初期構成が分かればアクティブ エッジのパターン全体が決定され、その逆も同様であるということです。 

ただし、サイクル制約があるため、大域システムを直接解くのは困難です。 クリーンな方法は、構成を順次生成されるものとして扱うことです。2 つの隣接する開始値を修正すると、次のすべての値がローカル ルールによって強制され、サイクルが終了するときに一貫性を検証できます。 

これにより、問題は、最初の 2 頭の乳牛について 4 つの可能性のみを試し、円の周囲に決定論的に伝播し、一貫した開始状態に戻るかどうかを確認するだけになります。

 ## アルゴリズムのチュートリアル

 考えられる 2 つの方向をビット、たとえば 0 と 1 としてエンコードします。遷移規則は、隣接する牛が等しいか異なるかという観点から表現する方が簡単です。 

1. 最初の 2 頭の牛の初期値を固定します。 位置 0 と 1 のすべてのバイナリ ペアに対応する、正確に 4 つの選択肢があります。2 つの連続する状態がわかれば、サイクルの残りの部分を一意に導出できるため、これで十分です。 
2. 私たちがその位置にいると仮定します$i$位置の既知の値を持つ$i-1$そして$i$。 決めたいのは$i+1$。 重要な観察は、位置への影響です。$i$最終状態はエッジかどうかによって異なります。$(i-1,i)$そして$(i,i+1)$これは、隣接する値が異なるかどうかに相当します。 
3. これを使用して、次の関係を与える決定論的ルールを計算できます。$x_{i+1}$、$x_i$、$x_{i-1}$、および位置の最後の文字列値$i$。 これを直接式に整理すると、$x_{i+1}$, したがって、次の状態が強制されます。 
4. 反復処理$i = 1$に$n-2$、繰り返しを繰り返し適用して、サイクル全体で唯一可能な一貫した割り当てを再構築します。 
5. すべての値を入力した後、円の端のラップアラウンド制約を確認します。 最後の位置は、導出された値と、位置 0 に関係する制約の両方と一致している必要があります。これは、サイクルにより、順方向伝播中に強制されない最後の依存関係が 1 つ導入されるためです。 
6. すべての制約が満たされる場合、この最初のペアを有効としてカウントします。 4 つの開始ペアすべてを合計します。 

### なぜ効果があるのか

 システムの状態は、連続する値のペアによって完全に説明できます。 2 つの隣接する初期値が固定されると、各新しい値は前の 2 つの値と固定された最終構成を含むローカル方程式によって強制されるため、すべての遷移ルール​​は決定的になります。 

伝播は決して分岐しないため、開始ペアごとに生成される候補構成は 1 つだけです。 唯一考えられる障害は、ローカルで強制されなかったグローバル制約を正しくキャプチャするサイクルを閉じるときの不整合です。 ローカルな決定論とグローバルな閉鎖性をこのように分離することで、まさに、数えすぎのない完全性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    n = len(s)

    # map chars to bits
    y = [1 if c == 'B' else 0 for c in s]

    ans = 0

    for a0 in (0, 1):
        for a1 in (0, 1):
            x = [0] * n
            x[0], x[1] = a0, a1

            ok = True

            for i in range(1, n - 1):
                # derive x[i+1] from local constraint
                # d(i-1) = x[i-1] != x[i]
                d_im1 = x[i - 1] ^ x[i]
                # from derived relation:
                # d(i) = y[i] ^ x[i] ^ d(i-1)
                d_i = y[i] ^ x[i] ^ d_im1
                x[i + 1] = x[i] ^ d_i

            # check consistency at last position (i = n-1)
            d_nm2 = x[n - 2] ^ x[n - 1]

            # compute what d(n-1) must be from equation at i=n-1:
            d_n1 = y[n - 1] ^ x[n - 1] ^ d_nm2

            x0_check = x[n - 1] ^ d_n1

            if x0_check != x[0]:
                ok = False

            if ok:
                ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```わかりやすくするために実装では完全な配列を保持していますが、実際の構造は 2 つの連続した状態と派生した差分だけです。 重要なステップは、エッジが反転をトリガーするかどうかをエンコードする「差分」変数の計算です。 

伝播ループは、最初のペアの唯一の可能な拡張を構築します。 最終チェックでは、循環整合性が強制されます。これは、無効な割り当てがローカルで再発しても存続しますが、グローバルでは失敗する唯一の場所です。 

よくある実装上の間違いは、最後の制約が最後の要素と最初の要素の間のエッジに依存していることを忘れることです。 この依存関係は前方再帰によって自動的に適用されないため、明示的にチェックする必要があります。

 ## 特殊なケース

 次のような均一な文字列の場合`AAAA`、すべての局所差分項がゼロであるため、伝播規則は強制的な矛盾を生成しません。 アルゴリズムは 4 つの最初のペアすべてを試しますが、伝播によって削除されるものがないことがわかります。 最終的なサイクルチェックのみが重要です。 この場合、すべての初期状態で一貫したゼロ差分パターンが生成されるため、4 つすべてが受け入れられます。 

次のような厳密に交互する文字列の場合`ABABAB`、すべてのエッジは、隣接するエッジ間の結合を最大にする方法でアクティブになります。 伝播中、各ステップによって次の値が完全に決定され、最後のクロージャが最初の要素との一致を強制するときにのみ実際の制限が表示されます。 このアルゴリズムは、サイクル境界での不一致により、4 つの開始ペアのうち 2 つを正しく拒否します。 

次のような非常に小さなサイクルの場合`ABA`、すべてのノードは両方のローカル制約に同時に参加します。 伝播は以前の 2 つの値にのみ依存するため引き続き機能しますが、最終チェックが主要な制約となり、無効な構成が除外される唯一の場所になります。
