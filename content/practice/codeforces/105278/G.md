 ## 問題の理解

 多角形の「ケーキ」が与えられ、その上部境界はポリラインによって定義されます。$n$X 座標が厳密に増加している点。 下の境界は x 軸であり、最初と最後の点も x 軸に垂直に接続されているため、形状は区分的線形曲線の下の単純な領域になります。 

これは、ケーキが連続する点の間の線形関数と、最初と最後の x 座標の外側にあるゼロによって完全に決定されることを意味します。 ケーキの総面積は、この曲線の下の面積です。 

配置する必要があります$m-1$垂直方向にカットして、垂直方向のスライスが全体の領域を分割するようにします。$m$等しい部分。 各カットは x 座標によって定義され、各カットはその x 位置のシェイプの高さ全体に広がります。 

したがって、出力は、左境界から各カットまでの面積が合計面積を で割った値の正確な倍数となるような、一連の X 値になります。$m$。 

制約は大きく、両方とも$n$そして$m$到達できる$2 \cdot 10^5$。 これにより、クエリごとに面積を再計算したり、セグメントを繰り返しスキャンしたりするアプローチは即座に除外されます。 二次関数の何か$n$または$m$遅すぎます。 ポリゴンを 1 回処理し、対数または一定の償却時間で各カットに応答するメソッドが必要です。 

ターゲット カットが指定された 2 つの点の間のセグメント内にある場合、微妙な失敗のケースが発生します。 たとえば、曲線が急な場合、正しいカットがどの頂点とも一致しない可能性があります。 頂点でのプレフィックス合計をチェックするだけの単純なアプローチは失敗します。これは、等面積境界は通常、端点ではなくエッジの内側で発生するためです。 

別の失敗例は、セグメント内の高さが均一であると仮定した場合に発生します。 たとえば、連続する 2 つの点が$(0,0)$そして$(1,10)$までのエリア$x=0.5$線形補間が正しく処理されない限り、完全な台形領域の半分にはなりません。 

## アプローチ

 この強引なアイデアは、各カットを個別にシミュレートすることです。 各ターゲットフラクションについて$k/m$、左側の境界からスキャンし、領域をセグメントごとに蓄積し、必要な領域を超えたら停止することができます。 境界が存在するセグメント内で、台形を部分的に埋めることによって正確な x 位置を求めます。 

x では領域が単調であるため、これは正しく機能します。 ただし、各カットには最大でスキャンが必要になる場合があります。$O(n)$セグメントがあり、$O(m)$カット、につながる$O(nm)$最悪の場合は動作します。 と$2 \cdot 10^5$、これはまったく不可能です。 

重要な観察は、面積関数が区分的には 2 次であるが、全体的には単調であるということです。 すべての頂点でプレフィックス領域を事前に計算すると、ポインターまたは二分探索を使用して各カットを含むセグメントを特定し、そのセグメント内の正確な位置を分析的に解決できます。 これにより、プレフィックス構造を一度構築して実行するという問題が軽減されます。$m$独立した定数時間補間。

 ## アルゴリズムのチュートリアル

 1. 連続する点間の台形を使用して、ポリラインの下の合計面積を計算します。 各セグメントは、x 軸で形成される台形の面積に寄与します。 
2. プレフィックス配列を構築します。`pref[i]`最初の x 座標から次の座標までの領域を格納します。`x_i`。 これにより、頂点での定数時間の領域クエリが可能になります。 
3. 必要なカットごとに$k = 1 \dots m-1$、ターゲット領域を計算します$A_k = k \cdot \frac{total}{m}$。 
4. セグメント上でポインタを維持します (または二分探索)。 セグメントを見つける$[x_i, x_{i+1}]$そのような`pref[i] <= A_k <= pref[i+1]`。 
5. このセグメント内で、曲線を一次関数として表現します。 もし$y(x)$から直線的に変化します$y_i$に$y_{i+1}$、 書く$x = x_i + t$。 高さは になります$y_i + t \cdot \frac{y_{i+1}-y_i}{dx}$。 これを0から積分すると、$t$で二次方程式を与えます$t$、残りの領域と一致するように解決します。 
6.変換$t$絶対 X 座標に戻して出力します。 

### なぜ効果があるのか

 一次関数の下の領域は各セグメント内で単調かつ滑らかで、高さが負でない限り x が厳密に増加します。 これにより、各ターゲット領域が 1 つの x 位置に正確に対応することが保証されます。 プレフィックス分解により、常に正しいセグメントを見つけることができ、セグメント内の 2 次形式により、浮動小数点精度を超える近似誤差なく正確な点を回復できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def solve():
    n, m = map(int, input().split())
    x = list(map(float, input().split()))
    y = list(map(float, input().split()))
    
    pref = [0.0] * n
    
    for i in range(1, n):
        dx = x[i] - x[i-1]
        pref[i] = pref[i-1] + (y[i] + y[i-1]) * dx / 2.0
    
    total = pref[-1]
    res = []
    
    seg = 0
    
    for k in range(1, m):
        target = total * k / m
        
        while seg < n - 1 and pref[seg+1] < target:
            seg += 1
        
        dx = x[seg+1] - x[seg]
        dy = y[seg+1] - y[seg]
        
        base = pref[seg]
        need = target - base
        
        if abs(dy) < 1e-12:
            t = need / y[seg]
        else:
            a = dy / dx * 0.5
            b = y[seg]
            c = -need
            
            disc = b*b - 4*a*c
            t = (-b + math.sqrt(max(0.0, disc))) / (2*a)
        
        res.append(x[seg] + t)
    
    print(" ".join(f"{v:.12f}" for v in res))

if __name__ == "__main__":
    solve()
```この解決策は、各頂点までの累積領域を表す台形のプレフィックス合計を構築することから始まります。 これは、各カットがどこに配置されるかを特定するためのバックボーンです。 

ポインタ`seg`各クエリに対して最初から繰り返しスキャンを行わないようにします。 代わりに、カットが左から右に進行するにつれて、配列内を単調に移動します。 対象地域が増加しているため、これは妥当です。 

各セグメント内で、一次関数の積分から導出された二次方程式を解きます。 係数`a`傾きの寄与に相当しますが、`b`開始時の高さに相当します。 セグメントの高さが平坦な場合、二次方程式は単純な線形除算に縮退します。

 ## 特殊なケース

 連続する y 値が等しい平坦なセグメントは、二次方程式を線形除算に還元します。 このような場合、二乗項の係数はゼロになるため、解はゼロによる除算を回避する必要があります。 コードは、高さの差が無視できる場合に線形式に切り替えることで、これを明示的に処理します。 

カットが頂点に正確に存在する場合は、プレフィックス配列に頂点の正確な累積領域がすでに格納されているため、自然に処理されます。 セグメント検索では、二次解が返される位置にターゲットを配置します。$t = 0$または$t = dx$、頂点を正確に再現します。 

すべての高さが同じである場合、形状は長方形になり、すべてのカットが x に沿って等間隔になります。 二次項が完全に消失し、全区間にわたって線形比例のみが残るため、アルゴリズムは正しく減少します。
