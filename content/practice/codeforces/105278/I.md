 ## 解決策
 ## 問題の理解

 それぞれが異なる高さを持つ一連の建物が与えられます。 インデックスから任意の建物間隔に対応`i`に`j`では、左から右への移動と右から左への移動という 2 つの走査を考えます。 動きながら、各ステップの高さが上に行くか下に行くかを記録し、U と D からなる一連の動きを生成します。 

ペア`(i, j)`から歩くときに見られるアップダウンのパターンが有効であると呼ばれます。`i`に`j`から歩いているときに見られるパターンと同じです`j`に`i`。 タスクは、そのような間隔が何回存在するかを数えることです。 

入力サイズは 100 万の建物に達する可能性があるため、すべてのペアを検査する二次手法は即座に除外されます。 解は線形または線形演算に近い必要があります。`O(n^2)`最悪の場合、約 10^12 の比較が行われることになりますが、これは実現可能な限界をはるかに超えています。 

微妙な点は、この定義では上昇と下降のカウントだけではなく、シーケンスが比較されることです。 2 つの間隔の上りと下りの数が同じであっても、順序が異なるため失敗する場合があります。 もう 1 つの重要なエッジ ケースは、単一の構築間隔であることです。`(i, i)`両方の走査方向で空のシーケンスが生成されるため、常に有効です。 

単純な間違いは、対称性が「同じ数の増加と減少」を意味すると考えることですが、これは正しくありません。 もう 1 つの間違いは、反転を自動的に一致するものとして扱うことです。U/D エンコーディングでパターンが回文でない場合、これは失敗します。 

## アプローチ

 直接的なアプローチでは、すべてが列挙されます。`(i, j)`ペア、からのトラバースをシミュレートします。`i`に`j`、U/D シーケンスを記録し、からシミュレートします。`j`に`i`そして比較してください。 各シミュレーションには次の時間がかかります`O(j-i)`時間なので、合計コストは次のようになります`O(n^3)`文字通りに行われた場合、または最悪の場合、`O(n^2)`たとえ慎重に再利用したとしても。 と`n = 10^6`、これは不可能です。 

重要な観察は、U/D シーケンスが隣接する要素間の比較のみに依存するということです。 固定間隔の場合、順方向パターンは符号配列によって決定されます。`s[k] = +1 if h[k] < h[k+1] else -1`。 逆トラバーサルは方向を反転するため、シーケンスをその逆バージョンと効果的に比較しますが、方向反転によって引き起こされる符号反転を伴います。 

両方の走査で同一の U/D シーケンスが生成されるという条件は、強い構造的制約に変換されます。つまり、区間内の比較パターンは反転下でも不変でなければなりません。 これは、すべてのエッジ比較の方向が反転下で一貫している場合にのみ可能であり、高さの順序付けにおいて非常に剛直な構造が強制されます。 

その厳格さは再定式化につながります。有効な区間は、一連の比較が極値を中心に対称的な単一の「山のような」セグメント内単調構造を形成する区間に正確に対応します。 より具体的には、配列を一連の勾配にマッピングする場合、有効な区間とは、方向の変化が両端から完全に揃うように、シーケンスがその最大値または最小値に関して対称である区間のことです。 

これは、外側への拡張が厳密な交互構造を維持する各位置を中心とする間隔を数えることに帰着できます。 高さが異なるため、2 ポインター展開または単調スタック構造を使用して、各要素の周囲の最大有効スパンを特定できます。 

最適な解決策は、必要な対称比較構造を維持しながら、左右にどこまで拡張できるかを位置ごとに計算します。 次に、これらのスパンから各有効な間隔が線形時間でカウントされます。

 ## アルゴリズムのチュートリアル

 有効性は、区間の両端から見たときに比較方向がどのように動作するかによって完全に決定されるという事実に依存しています。 

### ステップ

 1. 高さの配列を、各位置がステップから次のステップかどうかを記録する符号配列に変換します。`i`に`i+1`上か下かです。 これにより、問題は絶対値ではなく方向の変化に関する推論に圧縮されます。 シーケンスは文字列になります`{U, D}`。 
2. 間隔を反転すると、方向シーケンスが反転し、同時に反転することに注目してください。 間隔を同一に保つには、この組み合わせた変換の下でシーケンスが不変でなければなりません。 
3. この不変性により、方向の変更がピボットの周りで 1 つの対称的な方法でのみ発生する構造が強制されます。 そのピボットは、区間内の固有の局所極値に対応します。 
4. 各ポジションについて`k`、それを潜在的な対称中心として扱い、外側に拡張しようとします。 延長します`l`そして`r`誘導された比較方向がミラーリングされたパターンと一致している限り、同時に実行されます。 
5. 拡張中にペアを比較します`(k - d, k + d)`また、左側と右側の傾斜方向が反転ルールに基づいて正しく対応していることを確認します。 不一致が発生した場合、展開は停止します。 
6. あらゆる成功した拡張`k`有効な間隔のファミリーを定義し、その数を数えます。`(i, j)`ペアは、有効な対称半径ごとに生成されます。 

### なぜ効果があるのか

 重要な不変条件は、有効な間隔が反転時に同一の隣接関係を維持する必要があるということです。 すべての高さは異なるため、局所的な比較は厳密に 2 つの状態のいずれかになります。そのため、傾斜方向の非対称性はすぐに可逆性を失います。 ピボット周りの対称性を強制し、ミラーリングされた比較が一致する間のみ拡張することにより、カウントされたすべての間隔が両方向の U/D シーケンスの必要な同等性を満たしていることが保証され、不一致によって最初の異なるペアで対称性が侵害されるため、無効な間隔が形成されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    h = list(map(int, input().split()))
    
    if n == 1:
        print(1)
        return

    # sign array: 1 if up, 0 if down
    s = [1 if h[i] < h[i+1] else 0 for i in range(n-1)]

    # expand around each center
    ans = n  # all singletons
    
    for center in range(n):
        l = center
        r = center
        
        while l > 0 and r < n-1:
            # compare slope to the left and right
            if s[l-1] != s[r]:
                break
            l -= 1
            r += 1
        
        ans += (center - l)  # number of valid expansions ending at center
    
    print(ans)

if __name__ == "__main__":
    solve()
```この解決策では、まず入力をバイナリ勾配表現に圧縮して、各隣接ペアが単一方向ビットに削減されます。 これにより、実際の値への依存が削除され、構造のみが保持されます。 

メイン ループは各インデックスを対称の中心として扱い、左側の傾斜が右側の傾斜を反映するように強制しながら外側に拡張します。 条件`s[l-1] == s[r]`外側にステップすると、反転時に同じ方向パターンが維持されるようになります。 

貢献`(center - l)`その中心位置で終了する有効な対称間隔を生成する左側の境界の数をカウントします。 単一要素の間隔は個別に処理されます。

 ## 特殊なケース

 単一要素の配列は、最も単純で有効なケースです。 傾きの比較が存在しないため、アルゴリズムはそれを個別に処理し、1 を返します。 拡張ロジックは決してトリガーされないため、範囲外のアクセスが回避されます。 

徹底的にモノトーンの配列も重要です。 このような場合、すべての傾きが同一であるため、両方向が一様なシーケンスを生成するため、反転するとすべての区間が自明に対称になります。 展開条件が失敗することはなく、すべての間隔が有効な単一方向の実行として一貫してカウントされます。 

高度に交互するシーケンスは、単純な対称性の仮定の故障モードを明らかにします。 このような場合、ほとんどの中心の周りに拡張するとすぐに傾きの不一致が発生し、非常に短い対称セグメントのみが残ります。 アルゴリズムは最初の不一致で拡張を正しく停止し、無効な間隔がカウントされないようにします。
