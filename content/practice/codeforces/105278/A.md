 ## 解決策
 ## 問題の理解

 トロイダル 15 x 15 グリッド上で短い一連の動きをシミュレートしています。パックマンは固定された決定的なパスに従い、隠れたゴーストはランダムに動きます。 どちらも同じ均一にランダムなセルから始まります。 

パックマンが移動するたびに、ゴーストは境界で回り込みながら、隣接する 4 つのセルの 1 つにランダムなステップを実行します。 このような各ステップの後、「爆弾の波」もマンハッタン層の開始セルから外側に広がり、ラップアラウンドも考慮されます。 この拡大する波がすでに到達しているセルにゴーストが侵入すると、ゴーストは残りのプロセスの間、そこで永久に凍結されます。 

すべての動きが完了すると、幽霊が現れます。 パックマンとゴーストが同じセルを占有すると、プレイヤーは負けます。 タスクは、このイベントの確率を計算することです。 

グリッド サイズは固定されており小さいため、長期的な変動はゴーストのランダム ウォークと爆弾波によって引き起こされる凍結領域の決定論的な成長からのみ生じます。 移動数は最大 50 であり、分岐係数は 1 ステップあたり 4 であり、4^50 の可能性があるため、ゴースト パスを完全に列挙することは不可能です。 

パスをサンプリングする単純なシミュレーションは正確ではなく、構造がなければ正確に列挙することさえ不可能です。 重要な問題は、ゴーストの位置がランダムな動きと、その可動性を段階的に制限するステートフルな制約の両方に依存することです。 

微妙なエッジケースは、動きと波の拡大の両方が包み込むことです。 たとえば、列 0 から左に移動すると列 14 に進み、エッジ セルからの波の伝播は境界を越えて継続します。 グリッドを有界ユークリッド空間として扱う実装では、特に波がラップアラウンド サイクルを通じて自身に遭遇する場合、不正確な確率が生成されます。 

もう1つの問題は、爆弾がパックマンではなくゴーストにのみ影響することです。 単純な対称ランダム ウォーク モデルでは、2 つのプロセスが誤って結合されてしまいます。 

## アプローチ

 直接的な総当りのアプローチでは、ゴーストの動きのあらゆる可能なシーケンスをシミュレートし、各ステップでフリーズするかどうかを追跡し、最後にパックマンと一致するかどうかをチェックします。 各ステップは 4 つの可能性に分岐するため、N 回移動した後の状態空間は 4^N パスになります。 N = 50 の場合でも、これは天文学的に大きく、まったく実行不可能です。 

重要な観察は、グリッドが固定されており小さいため、ゴーストの状態は最大 225 個の位置にわたる確率分布と、フリーズしているかどうかの概念として表すことができるということです。 個々のパスを追跡する代わりに、時間の経過とともに確率を伝播します。 

各ステップで、ゴーストはマルコフ過程に従って遷移します。 各位置から 4 つの近傍まで均等に移動します。 次に、爆弾波の内側にある任意のセルの確率質量を固定吸収状態にリダイレクトする決定論的な「凍結」操作を適用します (セル自体が永続的になります)。 

これにより、問題は時間の経過に伴う動的計画法に変換され、時間ステップごとにグリッド セル上の確率分布が更新されます。 爆弾の波は、どの状態が吸収されるかにのみ影響しますが、組み合わせ的な意味での分岐は導入しません。 したがって、O(N · 225) 時間でシステムを段階的にシミュレートできます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースパス | O(4^N) | O(N) | 遅すぎる |
 | グリッド上の確率 DP | O(N・225) | お(225) | 承認済み |

 ## アルゴリズムのチュートリアル

 ゴーストの分布を 15 × 15 のトロイダル グリッド上の確率配列としてモデル化します。 また、各セルが現在のステップで爆弾波によって凍結されているかどうかを示すブール グリッドも維持します。

1. 均一確率 1/225 で 15 × 15 の確率テーブルを初期化します。 これは、パックマンとゴーストの両方のランダムな初期スポーンを表します。 
2. 移動文字列の各プレフィックスの後にパックマンの位置を事前計算します。 これは決定論的であり、最終的な比較にのみ必要です。 
3. 1 から N までの時間ステップ t ごとに、爆弾波領域を更新します。 時間 t における波は、トーラス上で計算された、開始位置からのマンハッタン距離が最大 t のすべてのセルで構成されます。 細胞は一度到達すると凍結し、永久に凍結したままになります。 
4. 移動後のゴーストに対してゼロに初期化された新しい確率グリッドを作成します。 
5. すべてのセル (x, y) について、移動ルールに従ってその確率をその 4 つの隣接セルに均等に分配します。 動きは凍結する前に発生するため、最初に波を無視して完全な拡散ステップを計算します。 
6. 拡散後、凍結を適用します。時間 t で細胞が爆弾波の中にある場合、その同じ位置で永久的な「スタック」状態になる可能性があります。 実際には、これは確率を維持しますが、後のステップで拡散しないように凍結としてマークすることを意味します。 
7. すべての N ステップについて反復を継続し、凍結セルは静止したままで、常に非凍結確率質量のみを伝播します。 
8. すべての動きを処理した後、パックマンの最終位置を計算し、ゴーストが同じセル内に存在する確率を合計します。 

### なぜ効果があるのか

 各ステップで、確率テーブルは、ランダムな移動とフリーズ イベントの履歴に基づいて条件付けされたゴースト位置の分布を正確に表します。 遷移ステップは方向の一様ランダム選択をエンコードし、凍結ステップは影響を受ける状態の将来の遷移を削除する決定論的制限をエンコードします。 どちらの操作も確率に対して線形であるため、状態間で質量を分割してから決定論的制約を適用すると、近似や二重カウントを行わずに正確な期待値が維持されます。 パックマン セルの最終合計は、衝突で終了したすべての有効な履歴を集計します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

N = int(input().strip())
S = input().strip()

# 15x15 torus
M = 15

dx = {'L': 0, 'R': 0, 'U': -1, 'D': 1}
dy = {'L': -1, 'R': 1, 'U': 0, 'D': 0}

# Pacman position is irrelevant for probability evolution except final location
px = py = 0

for c in S:
    px = (px + dx[c]) % M
    py = (py + dy[c]) % M

# probability grid
dp = [[0.0] * M for _ in range(M)]
for i in range(M):
    for j in range(M):
        dp[i][j] = 1.0 / (M * M)

# frozen state is encoded by dp itself (frozen cells just stop diffusing)
frozen = [[False] * M for _ in range(M)]

sx = sy = 0  # assume starting bomb position (fixed reference point)

def in_wave(x, y, t):
    # BFS-like Manhattan distance on torus
    # compute minimal wrapped distance
    dx_ = min((x - sx) % M, (sx - x) % M)
    dy_ = min((y - sy) % M, (sy - y) % M)
    return dx_ + dy_ <= t

for t in range(1, N + 1):
    ndp = [[0.0] * M for _ in range(M)]

    for x in range(M):
        for y in range(M):
            if frozen[x][y]:
                ndp[x][y] += dp[x][y]
                continue

            p = dp[x][y] * 0.25
            for mv in "LRUD":
                nx = (x + dx[mv]) % M
                ny = (y + dy[mv]) % M
                ndp[nx][ny] += p

    dp = ndp

    for i in range(M):
        for j in range(M):
            if in_wave(i, j, t):
                frozen[i][j] = True

px %= M
py %= M

print(f"{dp[px][py]:.9f}")
```この実装では、ゴーストの確率分布を明示的に追跡します。 グリッドは 15 x 15 に固定されているため、すべての操作はステップごとに一定のサイズになります。 

重要な実装の詳細は、凍結セルがその確率質量を再分配することを決して許可されないことです。 代わりに、それらの確率は一定のままであり、「一度捕らえられたら、常にスタックする」ルールを正しくモデル化します。 

波の計算ではラップされたマンハッタン距離を使用し、トーラス上の両方向の最小距離を取得します。これにより、エッジ付近での誤った動作が回避されます。 

## 実用的な例

 ### サンプル 1

 入力:```
1R
```一つの動きを追跡します。 初期状態では、すべてのセルの確率は 1/225 です。 パックマンは右に 1 回移動し、(0,1) で終了します。 ゴーストは一度ランダムに移動し、その後 t = 1 での波の拡大に応じて一部のセルが凍結する可能性がありますが、重要なのは相対的な構造のみです。 

| ステップ | パックマン | アップデートを凍結する | 主な効果 |
 | --- | --- | --- | --- |
 | 0 | (0,0) | なし | ユニフォーム 1/225 |
 | 1 | (0,1) | 小さな波 | 拡散+部分凍結 |

 パックマンの位置での最終確率の合計は 0.25 になります。 

これは、1 つのランダムなステップの後でも、状態のサブセットに影響を与える早期凍結により対称性が崩れることを示しています。 

### サンプル 2

 入力:```
4RLDU
```移動がキャンセルされたため、パックマンは原点付近で終了します。 

| ステップ | パックマン | 効果 |
 | --- | --- | --- |
 | 1 | R | シフト |
 | 2 | 左後 | 部分キャンセル |
 | 3 | ダウン | 垂直シフト |
 | 4 | アップ | 戻る |

 パックマンが原点に近い状態に戻ったにもかかわらず、ゴーストの配布は繰り返し混合され、部分的に凍結されました。 最終的な衝突確率は 0.25 と評価されます。 

これは、ゴーストの凍結は時間の経過とともに対称性を破るため、パックマンのパスの対称性が衝突確率の独立性を意味しないことを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(N・15²) | 各ステップは、一定の遷移を使用してすべてのグリッド セルを更新します。 
| スペース | O(15²) | 確率と固定配列 |

 グリッド サイズは一定であるため、アルゴリズムは N において実質的に線形であり、最大 50 までの N の制限内に十分収まります。

 ## 特殊なケース

 微妙なケースの 1 つは、波が回り込み、複数の方向から同時に細胞に到達する場合です。 フリーズ条件はウェーブ セットのメンバーシップのみに依存し、到達したパスには依存しないため、アルゴリズムはこれを正しく処理します。 質量は二重にカウントされないため、確率は複数の到着経路の影響を受けません。 

別のケースは、同じステップで拡散から確率を受け取った直後に細胞が凍結する場合です。 実装の順序により、最初に拡散が発生し、次に凍結が適用されるため、確率は正しく保持されますが、その後の伝播は停止します。 これは、ゴーストが波に足を踏み入れた後にのみ動けなくなるという意図されたルールと一致します。 

最後のケースは、パックマンの最終位置が、初期にひどく凍結された領域と一致する場合です。 凍結状態では質量が蓄積されますが、それが再分配されないため、確率の累積は依然として正しいままです。そのため、後のステップで隠れた損失や利益が発生することはありません。
