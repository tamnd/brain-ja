 ## 解決策
 ## 問題の理解

 各ブロックが正の整数のサイズを持つブロックのコレクションが与えられます。 これらすべてを積み重ねて 1 つの垂直の塔にしたいと考えています。 唯一のルールは、ブロックのサイズがその下のブロックよりも厳密に小さい場合にのみ、そのブロックを別のブロックの上に配置できるということです。 すべてのブロックは 1 回だけ使用する必要があり、すべてのブロックは同じタワーに属している必要があります。 

課題は、そのような単一の塔を形成できるかどうかを判断することです。 

入力サイズは最大 200,000 ブロックまで可能で、各サイズは最大 10^9 まで可能です。 これにより、考えられるすべての積み重ね順序や順列のバックトラックをシミュレートしようとするソリューションは即座に除外されます。 二次関数や指数関数は手の届かないものです。 解は本質的に線形または線形演算でなければならず、おそらく O(n log n) です。 

微妙な点は、平等は禁止されていることです。 2 つのブロックが同じサイズの場合、どちらの方向にも積み重ねることはできません。 これにより、厳しい制約が作成されます。等しい値は、互いにブロックする同じ「高さ」のように動作します。 

単純な推論を破ることが多いエッジケースの 1 つは、すべての値が等しい場合です。 たとえば、入力`1 1`どちらも他方の上に乗ることができないので、明らかに塔を形成することはできません。 もう 1 つの重要なエッジ ケースは、次のような単一要素の配列です。`5`、これは常に有効です。 

## アプローチ

 強引な解釈では、任意のブロックを最下位として選択し、その後、未使用の小さいブロックを繰り返し選択して最上位に配置することで、有効な順序付けを構築しようとします。 これは基本的に、各ステップで制約チェックを使用して順列を探索します。 

これは、厳密な減少条件を直接強制するため、概念的に機能します。 ただし、各層では多くの候補が存在する可能性があり、検索空間のサイズは階乗になります。 n が 200000 までの場合、これは完全に不可能です。 

重要な観察は、問題が実際には順序以外の隣接関係の選択に依存していないということです。 すべてのブロックは厳密に減少する順序で出現する必要があるため、より単純な質問をします。すべての要素を 1 回だけ使用して、すべての要素を厳密に減少する順序に配置できるか?

 これは、すべての値が異なる場合にのみ可能です。 2 つの要素が等しい場合、ルールに違反せずにそれらを厳密に減少させる順序を付ける方法はありません。これは、等しいと厳密性が損なわれ、同じサイズの中間値で要素を「分離」することができないためです。 

したがって、問題全体は、重複が存在するかどうかを確認することに帰着します。

 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | 重複のソート / ハッシュ チェック | O(n log n) または O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ブロック サイズを表すすべての数値を読み取ります。 
2. 値が複数回出現するかどうかを検出します。 
3. 重複が存在する場合は、厳密な積み重ね順序は不可能であると直ちに結論付けます。 
4. それ以外の場合は、すべての要素を厳密に降順に配置できるため、有効なタワーが存在すると結論付けます。 

ステップ 3 の背後にある理由は、重複ペアがあると、順序に関係なく、最終スタックのどこかで厳密な不等式の違反が強制されるということです。 

## なぜ機能するのか

 有効なタワーは、厳密に降順に配置されたすべての要素の順列に正確に対応します。 厳密な減少シーケンスでは、すべての隣接するペアが満たされる必要があります。`a[i] > a[i+1]`。 2 つの値が等しい場合、それらはシーケンス内のどこかに出現する必要がありますが、どこに配置されても、隣接するか、より小さい値によって分離されます。 どちらの場合も、そのうちの 1 つは、完全な順列で隣接するものとの相対的な厳密な順序を維持できなくなります。 したがって、重複が存在するとタスクは不可能になり、重複が存在しない場合は、降順で並べ替えることで有効なタワーが生成されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input().strip())
a = list(map(int, input().split()))

seen = set()
for x in a:
    if x in seen:
        print("No")
        sys.exit(0)
    seen.add(x)

print("Yes")
```実装は、以前に値を見たことがあるかどうかを直接追跡します。 繰り返しが見つかった時点で、有効なタワーは不可能であるため、早期に終了できます。 ループが終了すると、明示的に構築しなくても、すべての値は個別になり、ソートによって厳密に降順が存在します。 

重要な設計上の選択は、最悪の場合に不必要な作業を回避する早期終了です。 セットを使用すると、平均 O(1) のメンバーシップ チェックが保証され、期待どおりの線形解が維持されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) 平均 | 各要素はハッシュ セットに 1 回挿入され、チェックされます。 
| スペース | O(n) | 最悪の場合の認識された要素の保存 |

 この制約では最大 200,000 個の要素が許可されるため、線形解は時間制限内に簡単に収まります。 メモリ使用量も 1024 MB の制限に比べて小さいです。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n = int(input().strip())
    a = list(map(int, input().split()))

    seen = set()
    for x in a:
        if x in seen:
            return "No"
        seen.add(x)
    return "Yes"

# provided samples
assert run("5\n1 2 3 4 5\n") == "Yes"
assert run("2\n1 1\n") == "No"

# custom cases
assert run("1\n10\n") == "Yes"
assert run("3\n3 2 1\n") == "Yes"
assert run("4\n1 2 2 3\n") == "No"
assert run("6\n6 5 4 3 2 1\n") == "Yes"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 要素 | はい | 最小の場合 |
 | すべて異なる降順 | はい | すでに有効な構造 |
 | 中央に 1 つの重複 | いいえ | 隣接しない重複を検出します。 
| 完全に逆の順序 | はい | 最大の厳密なケース |

 ## 特殊なケース

 次のような単一要素のケース`7`比較が必要ないためすぐに渡され、挿入が完了するまでセットは空のままです。 アルゴリズムは正しく Yes を出力します。 

次のような完全に等しい配列`5 5 5 5`2 番目の要素がすでにセット内にあるため、2 番目の挿入で失敗します。 検出は即座に行われるため、それ以上の処理は発生しません。 

次のような混合ケース`2 1 2`も正しく失敗します。 挿入後`2`そして`1`、決勝`2`重複が隣接していない場合でも重複チェックをトリガーし、隣接性は無関係であり、グローバルな一意性のみが重要であることを確認します。
