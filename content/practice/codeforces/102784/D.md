 ## 解決策
 # 問題の理解

 幽霊の列があり、各幽霊には整数の年齢が付いています。 移動は、年齢の異なる 2 つの隣接するゴーストを選択することで構成されます。 年上の幽霊は若い幽霊を倒し、戦列に残りますが、生き残ると1つ年をとります。 若い幽霊は消えます。 

問題は、ブーが最終的に 1 つのゴーストだけが残るように、何らかの順序で戦いを選択できるかどうかです。 

入力により、ゴーストの数と年齢が現在の順序で表示されます。 出力は`YES`幽霊が 1 人だけ残る一連の戦いが存在する場合、そして`NO`さもないと。 

制約は十分に小さいため、高度なデータ構造は必要ありません。 ゴーストが最大 10,000 個あれば、リニア スキャンは容易に手頃な価格になりますが、この操作には非常に強力な特性があるため、戦闘を直接シミュレートする必要はありません。 考えられるすべての戦闘シーケンスを試すソリューションは、除去のたびに可能な選択肢の数が急速に増加するため、爆発的に増加します。 

主なエッジケースは、戦闘を開始することさえできない状況から発生します。 幽霊が一人しかいないなら、答えはすぐに`YES`誰も削除する必要がないからです。 例えば：```
Input:
1
7

Output:
YES
```戦闘の可能性のみを検索する不注意な実装では、誤って返される可能性があります。`NO`。 

もう 1 つの重要なケースは、すべての幽霊の年齢が同じである場合です。 例えば：```
Input:
3
5
5
5

Output:
NO
```隣接する 2 つのゴーストの年齢が異なることはないため、いかなる操作も合法ではありません。 プロセスは 1 つではなく 3 つのゴーストで停止します。 

よくある間違いは、行のどこかに複数の異なる年齢があるかどうかだけを確認することです。 最初の動きでは隣接性が重要です。 例えば：```
Input:
4
3
3
3
4

Output:
YES
```最後の2つのゴーストはすぐに戦うことができます。 ただし、すべての値が等しい場合、そのような開始点は存在しません。 

# アプローチ

 直接的なアプローチは、プロセスをシミュレートすることです。 考えられるすべての隣接するペアを試し、若いゴーストを削除し、古いゴーストを増やし、ラインに 1 つのゴーストが存在するか、移動が不可能になるまで再帰的に続行することができます。 これは、考えられるあらゆる選択肢の順序を調査するため、正しいと考えられます。 

問題は、この検索ツリーが巨大であることです。 最悪の場合、各段階で多くの異なるペアが選択される可能性があります。 10,000 個のゴーストがある場合、考えられるすべてのシーケンスのほんの一部を考慮することさえ不可能です。 

重要な観察は、最初の戦闘が成功すると状況が完全に変わるということです。 隣接する 2 つの幽霊の年齢が異なるとします。 古い方が勝ちとなり、年齢が1つ増えます。 もっと上の年齢だったら`x`、生存者は`x + 1`これは、戦いの前に存在したすべての時代よりも厳密に大きいです。 

これにより、ユニークな最強のゴーストが作成されます。 その幽霊は常に彼らよりも年上であるため、今やどんな隣人も倒すことができます。 勝利するたびにそれはさらに古くなり、他の人がいなくなるまで列を進み続けることができます。 

このため、戦闘の正確な順序を見つける必要はありません。 最初の戦いが存在するかどうかを知る必要があるだけです。 最初の戦いは、異なる年齢の隣接するペアが存在する場合にのみ発生します。 

ブルートフォースは、考えられるすべての有効な戦闘命令に従うため機能しますが、選択肢が多すぎるために失敗します。 最初に成功した戦いが止められない勝者を生み出すという観察により、問題全体は隣接する差異をチェックすることに帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 幽霊の数は指数関数的 | O(N) 再帰の深さ | 遅すぎる |
 | 最適 | O(N) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての幽霊の年齢を読み取ります。 幽霊が1人しかいない場合は戻ります`YES`必要な最終状態にすでに到達しているためです。 
2. 隣接するすべてのゴーストのペアをスキャンし、それらの年齢を比較します。 いずれかのペアの年齢が異なる場合は、戻ります`YES`。 

最初の不平等な隣接ペアが戦うことができます。 その戦いの後、生存者はそれまでに存在していたすべてのゴーストよりも年長になるため、残りのライン全体を排除することができます。 
3. 不等な隣接ペアが見つからずにスキャンが終了した場合は、リターンします。`NO`。 

この状況では、すべてのゴーストの年齢は同じになります。つまり、最初から合法的な動きが存在しないことを意味します。 

機能する理由: 不均等な隣接ペアが存在する場合、最初の戦いで元のすべての年齢よりも年齢が大きいゴーストが作成されます。 以降の対戦相手はすべてこのゴーストより年上ではないため、次の戦いでは常に勝利し、さらに年上になる可能性があります。 したがって、最終的には 1 つおきのゴーストを除去することができます。 不均等な隣接ペアが存在しない場合、すべてのゴーストの年齢は同じであり、戦闘は不可能であるため、ラインを減らすことは不可能です。 

# Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    ages = [int(input()) for _ in range(n)]

    if n == 1:
        print("YES")
        return

    for i in range(n - 1):
        if ages[i] != ages[i + 1]:
            print("YES")
            return

    print("NO")

if __name__ == "__main__":
    solve()
```そこでは比較が必要ないため、コードは最初に単一ゴーストのケースを処理します。 次に、合法的な最初の動きには異なる年齢を持つ 2 つの隣接するゴーストが必要であるため、隣接するゴーストのみをチェックします。 

スキャンは、最初の戦闘の可能性が見つかるとすぐに停止します。 その戦いの後に勝ったゴーストがその後のすべての戦いを支配することが保証されているため、残りのプロセスをシミュレートする必要はありません。 

ループは使用します`n - 1`比較するため、リストの末尾を越えた要素にアクセスしないように境界は慎重に選択されます。

# 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(N) | 隣接する各ペアが 1 回チェックされます。 |
 | スペース | O(N) | 入力された年齢はリストに保存されます。 |

 このアルゴリズムはゴースト上で 1 回のパスのみを実行するため、制限に簡単に適合します。`N = 10000`。 

# テストケース```python
import sys
import io

def solve_input(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    import sys
    input = sys.stdin.readline

    n = int(input())
    ages = [int(input()) for _ in range(n)]

    if n == 1:
        ans = "YES"
    else:
        ans = "NO"
        for i in range(n - 1):
            if ages[i] != ages[i + 1]:
                ans = "YES"
                break

    sys.stdin = old_stdin
    return ans + "\n"

 # エッジケース

 ゴーストが 1 つだけの場合、アルゴリズムは戻ります。`YES`すぐに。 入力の場合:```
1
42
```実行する戦闘はありませんが、ラインにはすでに残りのゴーストが 1 つだけ含まれています。 

すべてのゴーストの年齢が同じ場合、隣接するすべての比較は失敗します。 入力の場合:```
4
6
6
6
6
```スキャンでは 3 つのペアがチェックされ、すべてのペアの年齢は等しいです。 最初の戦いは起こりえないため、最終状態に 1 つのゴーストが含まれることはあり得ないため、アルゴリズムは戻ります。`NO`。 

唯一の違いが境界付近にある場合でも、アルゴリズムは成功します。 入力の場合:```
4
3
3
3
8
```最後のペアは等しくありません。 年齢`8`幽霊は時代に勝つ`3`幽霊になって歳になる`9`, その後、残りの幽霊を1つずつ倒すことができます。 スキャンによりこのペアが検出され、返されます。`YES`。
