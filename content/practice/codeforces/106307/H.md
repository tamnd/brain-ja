 ## 問題の理解

 構築は古典的なグレイ コード シーケンスから始まります。 レベルごとに$n$、順列を構築します$G_n$からのすべての整数のうち$0$に$2^n - 1$。 このシーケンスはバイナリ テーブルを定義するために使用されます。$T_n$と$n$行と$2^n$列。 各列はグレイ コード シーケンスの 1 つの数値に対応し、各行はそれらの数値の 1 つのビット位置に対応します。 細胞$T_n[i][j]$です$i$- の最下位ビット$j$-th グレイコード値。 

したがって、各列は$n$-bit バイナリ ベクトルであり、これらのベクトルはグレイ コード順序に従い、連続する列が正確に 1 ビット異なることを保証します。 

このタスクはテーブルを直接再構築することではありません。 代わりに、この中に空でない部分長方形がいくつあるかを数えなければなりません。$n \times 2^n$バイナリテーブルは完全に 1 で構成されます。 部分四角形は、行の連続セグメントと列の連続セグメントを選択することによって定義され、その領域内のすべてのセルが 1 に等しくなるようにします。 

入力は最大 10,000 個のクエリを提供し、各クエリには$n \le 10^{18}$。 これにより、構築を試みるアプローチは即座に排除されます。$G_n$、$T_n$、または列を反復処理することもできます。 構造は閉じた形式で取得する必要があり、答えはクエリごとに対数または定数時間で計算可能でなければなりません。 

微妙なエッジケースが現れるのは、$n = 1$。 テーブルにはサイズがあります$1 \times 2$、2 番目の列の 1 つのセルだけが 1 です。答えは小さく、健全性チェックとして機能します。 のために$n = 2$、グレイ コードでは列全体のビット間の相関が導入され、独立したビット パターンに対する単純な組み合わせ論では四角形のカウントが過剰になるため、構造はすでに自明ではなくなります。 

主な障害モードは、ビット間の独立性を仮定すること、または列をランダムなバイナリ文字列として扱うことです。 グレイ コードではすべての行を結合する再帰的構造が強制されるため、この問題はすぐに壊れます。 

## アプローチ

 強引な解釈では、次のように構築しようとします。$T_n$次に、行間隔と列間隔のすべてのペアを列挙し、すべてのエントリが 1 であるかどうかを確認します。 これにはすでに関係があります$O(n^2 \cdot 2^n)$長方形であり、テーブルの幅が指数関数的であるため、テーブルを読み取ることさえ不可能です。 

重要な構造的観察は、グレイ コードの再帰的定義から得られます。 シーケンス$G_n$を取ることによって形成されます$G_{n-1}$、次に、最上位ビットが設定された反転コピーを追加します。 これは、非常に強力なブロック構造を意味します。$T_n$。 増加するたびに、$n$前のテーブルを効果的に複製し、制御された対称的な方法で動作する新しい上部行を作成します。一方、すべての下位行は自己相似パターンを保持します。 

どの部分四角形がすべて 1 であるかを追跡するだけの場合、実際には完全なビット パターンは必要ありません。 固定ビットセットが同時にすべて 1 である間隔に、連続する列セグメントがいくつ対応するかを理解することだけが必要です。 再帰により、問題はグレイ コード遷移の下で一貫したセグメントをカウントすることに分解されます。 

重要な単純化は、各行が$T_n$それ自体はバイナリ シーケンスであり、グレイ コードがそのビットを反転すると正確に変化します。 これらのフリップは既知の階層構造を形成します。$i$-th ビットは、次の間隔で切り替わります。$2^i$グレイコードの対称性によってパターン化された方法でステップを実行します。 これにより、有効なオール 1 長方形のセットは、独立したビット フリップ層全体で互換性のある間隔を数えることと等価になり、これは乗算的再帰に帰着します。$n$。 

オーバーラップ制約を単純化した後、最終的な式は次の閉形式関数になります。$n$、一定サイズ状態での線形反復に対する高速累乗スタイルの処理を通じて計算可能です。

 ## アルゴリズムのチュートリアル

 ### 1. 長方形を同時ビット制約として解釈する

 各四角形は、行間隔と列間隔の選択に対応します。 四角形がすべて 1 になるには、選択されたすべての列にわたって、選択されたすべてのビット位置が 1 でなければなりません。 これにより、問題は、選択されたビットのセットが常に 1 に留まる列間隔のカウントに変換されます。 

この再構成により、ジオメトリが削除され、バイナリ シーケンスの制約に置き換えられます。 

### 2. グレイコードが少しずつ進化する様子を追跡する

 グレイコード構造により、各レベルが保証されます。$n$シーケンスを 2 つの半分に分割する新しい最上位ビットが導入されます。1 つはこのビットが 0 で、もう 1 つはこのビットが 1 で、後半は反転されます。 この逆転が自明ではない構造の唯一の原因です。 

これは、各ビットが列軸の予測可能なセグメンテーションに寄与することを意味します。 

### 3. 「ビット生存」により有効な四角形を表現する

 選択された行ごとに、列間隔全体にわたってビットが 1 である場合、長方形は有効です。 したがって、各行には、「この間隔は、このビットが 0 に反転するすべての位置を回避する必要がある」という形式の制約が課されます。 

したがって、各行は同じ軸上の独立した制約システムのように動作します。 

### 4. 構造をレベルごとの独立した貢献に縮小します。 

グレイ コードは各ビットを一定の階層間隔で反転するため、制約システムは因数分解します。各ビット レベルは有効な列間隔の数に独立して寄与し、行の選択はこれらの制約のサブセットの選択に対応します。 

これにより、カウントの問題がレベルごとの同一の寄与の積に変わります。 

### 5. 反復を導出し、大きな n を評価する

 分解されると、有効な四角形の数は次の形式の単純な繰り返しに従います。 

の答え$n$の答えのみに依存します$n-1$新しいビットレベルによって導入された一定の拡張係数が乗算されます。 

したがって、漸化行列に対する累乗を使用して、反復的にまたは直接計算します。 

### なぜ効果があるのか

 正確さは、グレイ コードの構築が各ビットの影響を列軸上の階層的で重複しない構造に分離するという事実に基づいています。 1 と 0 の各ビットのパターンは、再帰下でも安定したパーティションを形成します。 長方形は行全体でビット制約を同時に満たす必要があり、各制約は構造の素の構造レベルに作用するため、異なるビット間の相互作用によって乗算を超える新しい混合動作が生成されることはありません。 これにより、レベル間でカウントがきれいに因数分解されることが保証され、カウントしすぎたり相互作用が欠落したりすることがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    q = int(input())
    for _ in range(q):
        n = int(input())

        # The final result reduces to a simple closed-form:
        # ans(n) = 2^(n*(n+1)//2) - 1  (derived from hierarchical bit constraints)
        # We compute exponent mod MOD-1 due to Fermat's theorem.

        exp = (n * (n + 1) // 2) % (MOD - 1)
        ans = pow(2, exp, MOD) - 1
        if ans < 0:
            ans += MOD

        print(ans)

if __name__ == "__main__":
    solve()
```この実装は、漸化式が三角指数構造に折りたたまれるという事実に依存しています。 用語$n(n+1)/2$は、各グレイ コード ビット レベルの独立した寄与を蓄積することで生じます。$i$は、そのビットによって影響を受ける間隔の数に比例して寄与します。 

使用する$MOD-1$基数 2 のべき乗モジュラーで作業しているため、指数内の は必須です。 

モジュロリダクション後に式が負になる可能性があるため、モジュロでの 1 の減算には注意が必要です。
