 ## 解決策
 ## 問題の理解

 この問題では、それぞれ数値的な疑惑レベルを持つ一連の村人を正確に分割するように求められます。`k`これらのグループの合計「パワー」を最小化する方法で、連続したグループを作成します。 グループの力は、そのグループ内の連続する村人の間の絶対差の合計として定義されます。 たとえば、グループ`[1, 4, 2]`力がある`|1-4| + |4-2| = 3 + 2 = 5`。 村人が 1 人のグループはパワーがゼロになります。 

入力により複数のテスト ケースが提供されます。 各テスト ケースは次のもので構成されます`n`、村人の数、`k`、必要なグループの数、および配列`a`疑いのレベル。 出力は村人を正確に分割した後のパワーの最小合計です。`k`連続したグループ。 村人たちは元の順序を保たなければなりません。 並べ替えることはできません。 

制約は小さいです。`n`最大でも 100 にすることができますが、`k`せいぜい`n`、各疑惑レベルは最大 500 です。`n`が小さい場合、テスト ケースごとに O(n log n) または O(n²) で動作するソリューションも実現可能です。 ただし、最大 100 個のテスト ケースを効率的に処理する必要があります。 

重要なエッジケースは、すべての村人が同じ疑いレベルを持っている場合です。たとえば、`[5, 5, 5, 5]`。 この場合、絶対差はすべてゼロとなり、どのグループ化でも合計検出力はゼロになります。 もう一つの微妙なケースは次のような場合です。`k = n`これは、すべての村人がシングルトン グループに属していることを意味します。 ここで、総電力は常にゼロです。 

## アプローチ

 素朴なアプローチは、考えられるすべての配置方法を試してみることです。`k-1`村人との間を切り裂く。 構成ごとに、結果として得られる各グループのパワーを計算し、それらを合計します。 これは正しいですが、次のような理由から計算コストが高くなります。`C(n-1, k-1)`すぐに成長するカットの選び方`n`そして`k`。 あっても`n=100`、これでは遅すぎます。 

重要な観察は、カットを含まないアレイ全体の合計パワーが、連続する絶対差のすべての合計であるということです。`sum(|a[i+1]-a[i]| for i in range(n-1))`。 配列を分割する必要がある場合は、`k`グループでは、作成するすべてのカットで、合計パワーから 1 つの絶対的な差、つまりカットの両側の 2 つの要素間の差が取り除かれます。 したがって、作成後の総電力を最小限に抑えるには、`k-1`カット、最大のものを削除する必要があります`k-1`連続した差分。 

これにより、問題は単純な貪欲な戦略に集約されます。すべての連続する差分を計算し、それらを降順に並べ替えて、最大値の合計を減算するというものです。`k-1`合計との差額です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(C(n-1, k-1) * n) | O(n) | 遅すぎる |
 | 違いを介して貪欲 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`そして`k`、配列を読み取ります`a`疑いのレベル。 
2. 連続する村人の間の絶対的な差を計算します。`diff[i] = |a[i+1]-a[i]|`のために`i=0`に`n-2`。 これらは、隣接する村人の総力への貢献を表します。 
3. カットを含まない合計パワーを、すべての要素の合計として計算します。`diff`。 これは、差異を取り除く前の合計の開始値です。 
4. 並べ替える`diff`降順の配列。 最大の違いは、そのままにしておくと総パワーに最も大きく寄与するものです。 
5. を取り外します。`k-1`最大の差は、合計電力から合計を引くことによって求められます。 これは配置をシミュレートします`k-1`これらの最大の差でグループを分割するためにカットします。 
6. 結果として得られる総電力を出力します。 

これが機能する理由: 不変条件は、どのカットでも合計から 1 つの連続する差分を正確に削除することです。 総電力を最小限に抑えるために、最大の差を除去したいと考えています。 並べ替えにより、確実に上位を選択できるようになります`k-1`効果的に違いを確認します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        # compute consecutive differences
        diff = [abs(a[i+1] - a[i]) for i in range(n-1)]
        total = sum(diff)
        
        # remove largest k-1 differences
        diff.sort(reverse=True)
        total -= sum(diff[:k-1])
        print(total)

if __name__ == "__main__":
    solve()
```コードは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 違いは、明確さと速度のためにリスト内包表記を使用して計算されます。 降順に並べ替えると、上位が確実に表示されます。`k-1`差異は合計から簡単に差し引くことができます。 最後の print ステートメントは、各テスト ケースの最小化された合計電力を出力します。 

## 実用的な例

 サンプル入力:```
4 2
1 3 5 2
```差分を計算します。`[2, 2, 3]`合計額:`2 + 2 + 3 = 7`必要です`k=2`グループなので、最大の差を削除します`3`最小限の電力:`7 - 3 = 4`2 番目の例:```
6 3
1 9 12 4 7 2
```違い:`[8, 3, 8, 3, 5]`合計額:`8 + 3 + 8 + 3 + 5 = 27`取り除く`k-1 = 2`最大の違い`8 + 8 = 16`最小限の電力:`27 - 16 = 11`これは予想される出力と一致します。

 ## 特殊なケース

 いつ`k = n`、各村人はシングルトン グループです。 削除された差異は次のとおりです`n-1`それがすべての違いです。 総力はゼロです。 いつ`k = 1`、差は削除されないため、合計パワーは連続するすべての差の合計になります。 このアルゴリズムは、要素が繰り返される配列、高値と低値が交互に現れる配列、グループ数の最小値と最大値を正しく処理します。
