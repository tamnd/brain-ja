 ## 解決策
 ## 問題の理解

 ヤッコとワッコに対する単純なサイコロ ゲームでドットが勝つ確率を計算するように求められています。 各キャラクターは標準の 6 面のサイコロを振ります。 ドットは、自分の出目が少なくともヤッコとワッコの出目の最大値と同じであれば勝ちます。 Yakko と Wakko のロールは、1 から 6 までの 2 つの整数として入力として与えられます。Dot が勝つ確率を既約分数の形式で出力する必要があります。 

入力は、Yakko と Wakko のロールを表す 2 つの数値 Y と W で構成されます。 出力は分数 A/B です。ここで、B はサイコロの出目の合計数 (6)、A はドットが Y と W の大きい方と一致するかそれを超える出目の数です。分数は最小の項まで減らす必要があります。 

主なエッジケースは、ドットの最小勝ちロールが 6 の場合に発生します。ドットは 1 つの結果でのみ勝つことができ、確率は 1/6 です。 もう 1 つは、Y と W が両方とも 1 の場合で、ドットの勝ちロールは 1 ～ 6 のいずれかの値となり、確率は 1/1 になります。 不注意なアプローチでは、2 つの入力値の最大値を考慮せずに確率を計算し、Yako と Wakko が異なる場合に不正確な結果が生じる可能性があります。 

## アプローチ

 単純なアプローチは、ドットのすべての可能なロールをシミュレートし、ドットのロールが少なくともヤッコとワッコの最大値と同じくらい大きい結果を数えるというものです。 これが機能するのは、Dot の結果が 6 つしかなく、すべての可能性を反復できるためです。 ブルートフォースアプローチは正しいですが、結果は一様な分布に従い、数学的に推論できるため、各サイコロの目を明示的にシミュレートする必要はありません。 

重要な観察は、Dot は Y と W 以上の最大値をロールする必要があるだけであるということです。 させて`max_roll = max(Y, W)`。 有利な結果の数は、`6 - max_roll + 1`サイコロには 1 から 6 までの面があるため、考えられる出目の合計は常に 6 です。好ましい結果の数がわかったら、最大公約数 (GCD) を使用して分数を最も単純な形に減らします。

 ## アルゴリズムのチュートリアル

 1. Yakko と Wakko のロールを表す 2 つの整数を入力から読み取ります。 
2. Y と W の間の最大ロールを計算します。これは、ドットが一致または超える必要がある最小値を表します。 
3. Dot の有利な結果の数を次のように計算します。`6 - max_roll + 1`。 
4. 分数を減らすための分子 (好ましい結果) と分母 (6) の最大公約数を決定します。 
5. 分数をフォームに出力します。`A/B`換算された分子と分母を使用します。 

機能する理由: 不変条件は、ドットのロールがこの値以上の場合にのみ勝つため、確率は Y と W の最大値のみに依存するということです。 これを満たす結果の数を計算し、端数を減らすことで、考えられるすべての入力の正確性が保証されます。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

Y, W = map(int, input().split())

max_roll = max(Y, W)
favorable = 6 - max_roll + 1
gcd = math.gcd(favorable, 6)

print(f"{favorable // gcd}/{6 // gcd}")
```このコードは 2 つの整数を読み取り、最大ロールを計算し、有利な結果を数え、次を使用して端数を減らします。`math.gcd`。 分子と分母の両方を GCD で割ると、出力が既約であることが保証されます。 整数除算を使用すると、浮動小数点の不正確さを回避できます。

## テストケース```python
import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    Y, W = map(int, input().split())
    max_roll = max(Y, W)
    favorable = 6 - max_roll + 1
    gcd = math.gcd(favorable, 6)
    return f"{favorable // gcd}/{6 // gcd}"

# Provided sample
assert run("4 2\n") == "1/2", "sample 1"

# Custom cases
assert run("1 1\n") == "1/1", "minimum rolls"
assert run("6 6\n") == "1/6", "maximum rolls"
assert run("2 5\n") == "1/2", "mixed rolls"
assert run("3 3\n") == "2/3", "equal mid rolls"
assert run("1 6\n") == "1/6", "extreme difference"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 1 | 1/1 | すべてのケースでドットが勝ちます |
 | 6 6 | 1/6 | 勝利結果は 1 つだけ |
 | 2 5 | 1/2 | 正しい最大選択と確率 |
 | 3 3 | 2/3 | 等ロールの計算 |
 | 1 6 | 1/6 | 最小値と最大値の境界条件 |

 ## 特殊なケース

 Yakko と Wakko が両方とも 6 を出した場合、Dot は 6 を出してのみ勝つことができます。アルゴリズムは計算します。`max_roll = 6`、 それから`favorable = 6 - 6 + 1 = 1`、`gcd = gcd(1, 6) = 1`、生産`1/6`。 両方とも1が出た場合、`max_roll = 1`、`favorable = 6`、`gcd = 6`、出力`1/1`。 このメソッドは、6 から最大値を減算し、1 を加算することによってすべての中間値を処理するため、off-by-one エラーは発生しません。
