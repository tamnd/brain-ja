 ## 解決策
 ## 問題の理解

 1 から _n_ までの 10 進数表現の数字 0 と 1 のみで構成される数値がいくつあるかを数えるように求められます。 言い換えれば、16 進数のメモリには、基数 10 で書かれたときに 0 または 1 以外の数字が含まれない数値のみが保存されます。たとえば、1、10、11 は有効ですが、2、12、20 は無効です。 

入力は 1 つの整数 _n_ で、最大 10^9 までの大きさになります。 つまり、1 から _n_ までのすべての数値を明示的に反復するソリューションでは、最大 10 億回のチェックが実行される可能性があり、1 秒の制限時間には遅すぎます。 64 MB というメモリ制約は、実際に保存する必要がある少量のデータに比べれば寛大です。 

ここでのエッジケースは微妙です。 _n_ = 1 の場合、1 が格納されているため、答えは 1 になるはずです。 _n_ = 2 の場合、2 は無効であるため、答えは 1 のままです。 _n_ = 11 の場合、数値 1、10、および 11 が有効です。 上限を確認せずに数値を 1 桁ずつ生成する不用意な解決策では、_n_ より大きい数値が含まれ、不正確なカウントが生成される可能性があります。 同様に、「2 進数」を実際の基数 2 の数値として扱うのは間違いです。数値は 0 と 1 の桁だけからなる 10 進数です。 

## アプローチ

 ブルートフォース手法は、1 から _n_ までのすべての数値を反復処理し、各桁をチェックし、0 と 1 のみを含む数値をカウントすることです。これは正しく機能しますが、_n_ ≈ 10^9 の場合、最大 10 億回の反復が実行され、遅すぎます。 演算数は、おおよそ _n_ までのすべての数値の桁数の合計になりますが、それでも 10^9 以上のオーダーになります。 必要なのはカウンターだけであるため、メモリの使用量は無視できます。 

重要な洞察は、0 と 1 の数字だけで構成される数値は、非常に構造化されたシーケンスを形成するということです。これらの数値は、まさに 0 または 1 の係数を持つ 10 の累乗の合計として表現できる数値です。これは、1、10、11、100、101、110、111、1000 などの「10 進 2 進数」の順序で数値を生成するのと同等です。 昇順に生成すると、_n_ を超えるとすぐに停止できます。 これにより、問題が _n_ までの反復から、O(log_10(n)) 桁の組み合わせのみの反復に軽減されます。これは、n ≤ 10^9 の場合、およそ 2^10 = 1024 となり、大幅な高速化になります。 

ブルートフォース手法が機能するのは、各数値の 0 と 1 をチェックするのが簡単だからです。 n が大きい場合、不必要な作業が行われるため失敗します。 0 と 1 の数字のみが関連していることを観察すると、それらを昇順に直接生成して、高速なソリューションを生成できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n log n) | お(1) | 遅すぎる |
 | 最適 | O(2^d) ここで、d ≈ n の桁数 | O(2^d) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. カウンタを初期化する`count`ゼロとキューへ`q`これにより、有効な数値が小さいものから順に生成されるように設定されます。 
2. キューが空でない間に、最初の要素を削除し、それを呼び出します`x`。 もし`x`_n_ より大きい場合は、処理を停止します。 これにより、許容範囲外の数値をカウントすることがなくなります。 
3. インクリメント`count`一つずつだから`x`は、数字 0 と 1 のみで構成され、_n_ を超えない有効な数値です。 
4. 末尾に 0 と 1 を追加して、次の数値を生成します。`x`10進数で。 数学的に計算すると、`x * 10`そして`x * 10 + 1`。 これらの番号をキューに追加します。 これにより、すべての有効な数値を欠落することなく昇順に探索することが保証されます。 
5. キューが空になるか、すべての数値が _n_ を超えるまで繰り返します。 

機能する理由: キューには常に、0 または 1 のみの数字が昇順に含まれます。 各数値を処理し、その「10 進数の子」を生成することにより、すべての有効な数値を 1 回だけ調べます。 不変条件は、0 と 1 の数字のみからなる _n_ より小さい数値はスキップされず、_n_ より大きい数値はカウントされないということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def main():
    n = int(input())
    count = 0
    q = deque([1])
    
    while q:
        x = q.popleft()
        if x > n:
            continue
        count += 1
        q.append(x * 10)
        q.append(x * 10 + 1)
    
    print(count)

if __name__ == "__main__":
    main()
```コードは、入力を読み取り、カウンターとキューを初期化することから始まります。 deque を使用して、前から効率的にポップし、後ろに追加します。 各数値はカウントする前に _n_ と照合されます。 生成中`x * 10`そして`x * 10 + 1`これにより、数字 0 と 1 を含むすべての数値が順番に考慮されるようになります。 微妙な使用`continue`_n_ を超えた後でも、ループを中断するのではなく、キュー内のより大きな数がまだ有効である可能性があるためです。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(2^d) | d 桁が 0 と 1 で構成されるおおよそ 2^d 個の数値があります。n ≤ 10^9、d ≤ 10 の場合、最大 1024 個の数値が処理されます。 |
 | スペース | O(2^d) | キューには、同じ O(2^d) によって制限される、処理するすべての数値が格納されます。 |

 制約を考慮すると、最大 1024 個の数値の処理は非常に高速であり、メモリの使用量は無視できます。
