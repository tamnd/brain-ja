 ## 解決策
 ## 問題の理解

 1 から _n_ までのラベルが付けられた正確に _n_ 個のノードを持つ個別の二分探索ツリー (BST) の数を数えるように求められます。ただし、各ツリーの高さは少なくとも _h_ であるという追加の制約があります。 ここでの高さは、ルートとリーフの両方を含む、ルートからリーフまでの最長パス上のノードの数として定義されます。 出力は単一の整数、つまりこの制約を満たす BST の総数です。 

入力制約は小さく、_n_ ≤ 35 および _h_ ≤ _n_ です。 BST の数は階乗 (カタロニア語) で増加するため、これにより、すべての BST を明示的に生成しようとするソリューションは即座に除外されます。 出力の上限 9·10^18 は、64 ビット整数を使用する必要があることを示唆しており、問題は総当たりではなく動的プログラミングで効率的に解決できます。 

_h_ が 1 の場合、微妙なエッジ ケースが発生します。_n_ ≥ 1 の BST は自動的に高さ ≥ 1 になるため、高さの制約は簡単になります。 逆に、_h_ > _n_ の場合、どのツリーも要件を満たすことができないため、答えは 0 になるはずです。注目すべきもう 1 つの状況は、非常に小さなツリー、たとえば _n_ = 1 です。ここでは、単一ノード ツリーの高さは 1 であり、プログラムは指定された _h_ に基づいてそれを正しく考慮する必要があります。 

## アプローチ

 ブルートフォースアプローチは、考えられるすべての BST を再帰的に生成することです。 ルートの選択ごとに、すべての左側のサブツリーとすべての右側のサブツリーを再帰的に生成し、それらを結合します。 これは正しいです。BST はそのルートとその左右のサブツリーの構造によって完全に定義されるからです。 ただし、BST の数は _n_ 番目のカタロニア数に応じて増加し、_n_ = 20 の場合に 10^9 を超えるため、明示的な列挙は完全に不可能になります。 

より高速なアプローチを明らかにする重要な観察は、BST の構造がキーの実際の値ではなく、左右のサブツリーのサイズのみに依存するということです。 したがって、動的プログラミングを使用できます。関数を定義します。`dp(nodes, min_height)`BST を正確にカウントします`nodes`少なくともノードと高さ`min_height`。 再帰はルートの選択に基づいて分割され、有効な左と右のサブツリーの数が乗算されます。 

メモ化を使用してこれを効率的に計算し、中間結果を保存して再計算を避けることができます。 _n_ ≤ 35 であるため、サイズ 36×36 (ノードと高さの) の DP テーブルはメモリに収まるのに十分な大きさです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(カタロニア語(n)) | O(カタロニア語(n)) | 遅すぎる |
 | 動的プログラミング | O(n^3) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2D 配列を定義する`dp[n+1][n+1]`どこ`dp[i][j]`はBSTの数です`i`少なくともノードと高さ`j`。 
2. 基本ケースを初期化します。 ノードが 0 のツリーは高さが 0 であり、有効な空のツリーとしてカウントされます。`dp[0][0] = 1`。 高さ > 0 の場合、`dp[0][j] = 0`。 
3. 1 から 2 までのすべての可能なノード数を反復します。`n`。 それぞれの番号について`i`、ノードを次のように分割するルート位置のすべての可能な選択肢を考慮します。`left_nodes`そして`right_nodes`と`left_nodes + right_nodes + 1 = i`。 
4. 左右のノードの組み合わせごとに、再帰的に乗算します。`dp[left_nodes][h-1]`そして`dp[right_nodes][h-1]`高さ ≥ のすべての木を数える`h`。 これらの貢献を合計すると、`dp[i][h]`。 
5. 戻る`dp[n][h]`最終結果として。 

このロジックは、木の高さが ≥ であるという事実に基づいています。`h`の場合、そのサブツリーの少なくとも 1 つは高さ ≥ でなければなりません。`h-1`。 この乗算は、左右のサブツリーのすべての組み合わせを個別に考慮します。これは、BST がそのサブツリーによって再帰的に定義されるため有効です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def count_bsts(n, h):
    # dp[i][j] = # of BSTs with i nodes and height at least j
    dp = [[0]*(n+2) for _ in range(n+1)]
    
    # base case: empty tree has height 0
    for j in range(n+2):
        dp[0][j] = 1 if j <= 0 else 0
    
    for nodes in range(1, n+1):
        for height in range(1, n+1):
            total = 0
            for left_nodes in range(nodes):
                right_nodes = nodes - 1 - left_nodes
                total += dp[left_nodes][height-1] * dp[right_nodes][height-1]
            dp[nodes][height] = total
    
    return dp[n][h]

n, h = map(int, input().split())
print(count_bsts(n, h))
```このソリューションは、各エントリが特定のノード数と最小高さを持つ BST の数を表す DP テーブルを構築します。 ネストされたループは、ノードを左右のサブツリーに分割し、可能性を乗算することによって、すべてのエントリを体系的に計算します。 テーブルはノードの昇順に入力され、すべての依存関係が使用される前に計算されることが保証されます。

## 複雑さの分析

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

 ## 特殊なケース

 のために`n = 1`そして`h = 1`、DP テーブルは 1 つのツリーを正しくカウントします。 空のツリーのケースは次のように処理されます。`dp[0][0] = 1`。 のために`h > n`、 例えば`n = 2`そして`h = 3`、DP テーブルは次のことを保証します。`dp[nodes][height] = 0`高さがノードの数より大きい場合、答えは正しく 0 になります。n が大きく、h が小さい場合、テーブルは可能なすべての左右の組み合わせを自動的に合計し、高さの制約が自明な場合にはカタロニア語の数値を正確に再現します。 

この社説は、最大高さのバリエーションや異なるラベル付け制約など、制限された木をカウントする同様の問題の解決策を再構築するための十分な理解を読者に提供します。
