 ## 解決策
 ## 問題の理解

 最大 15 個の頂点と最大 2000 個のエッジを持つ重み付き無向グラフが与えられます。 各エッジには正の重みがあり、同じ頂点のペアを接続する複数のエッジや、同じ頂点にループバックするエッジが存在する場合があります。 タスクは、頂点 1 から始まり、すべてのエッジを少なくとも 1 回横断する最短のサイクルを見つけることです。 そのようなサイクルが存在しない場合は、-1 を返します。 

重要な点は、すべてのエッジを一度だけ訪問することは不可能なため、必要に応じてサイクルで頂点とエッジを再利用できるようにする必要があるということです。 基本的に、**特定の頂点から開始するエッジ カバー サイクル**を計算するように求められます。 n ≤ 15 の場合、m は最大 2000 まで可能なため、n では指数関数的ですが m では指数関数的ではないアルゴリズムを利用できます。 

可能なすべてのエッジ シーケンスを生成しようとする単純なアプローチは、シーケンスの数が m で階乗的に増加するため、実用的ではありません。 頂点が 15 個しかない場合でも、エッジが 2000 個あると、強引なエッジ シーケンスは不可能になります。 最小サイクルで特定のエッジが複数回再利用される可能性があるため、ループと複数のエッジは状況を複雑にします。 たとえば、重み 5 のループを持つ単一の頂点は、0 ではなく 5 を返す必要があります。 

エッジ ケースには、頂点が 1 つでエッジが存在しないグラフ (サイクルが存在しない)、複数の平行なエッジが存在するグラフ、または一部の頂点が頂点 1 から切り離されているグラフが含まれます。不注意な解決策では、各エッジではなく各頂点を 1 回走査しようとし、複数のエッジを持つグラフで誤った結果が生じる可能性があります。 

## アプローチ

 ブルート フォース アプローチでは、エッジのすべての順列または頂点 1 から始まるすべてのウォークを列挙しようとします。各候補ウォークについて、すべてのエッジを訪問するかどうかを確認し、その総重みを合計します。 四球の数は m との組み合わせで爆発的に増加します。 明らかに無効なパスを削除したとしても、このアプローチは最悪の場合 O((2^m) × m) となり、m ≈ 2000 の実行可能な制限時間をすぐに超えてしまいます。 

重要な洞察は、**問題を中国の郵便配達員問題の変形** (ルート検査問題とも呼ばれます) に変換することで得られます。 グラフでは、最小限のコストですべてのエッジを少なくとも 1 回走査したい場合、オイラー サイクルがすでにすべてのエッジを 1 回カバーしているため、追加のエッジを追加してすべての頂点の次数を均等にするだけで済みます。 頂点の次数が奇数の場合は、その頂点を別の奇数次の頂点とペアにして、それらの間の最短パスを追加する必要があります。 結果として得られる拡張グラフは、頂点 1 から開始してトラバースすることができ、最小限の追加コストですべてのエッジを少なくとも 1 回カバーします。 

n ≤ 15 なので、O(n^3) で Floyd-Warshall を使用してすべてのペアの最短経路を計算できます。 次に、奇数次数を持つすべての頂点を見つけます。 奇数次の頂点は最大で n 個存在できるため、**ビットマスク動的プログラミング** アプローチを使用して最小のペアリングを計算できます。各状態は、一致しない奇数の頂点を表します。 この DP は O(2^k × k^2) で実行されます。ここで、k は奇数の頂点の数であり、k ≤ 15 の場合に実行可能です。既存のエッジの重みと最小ペアリングを加算すると、答えが得られます。 

ブルートフォースからの主な変化は、すべてのサイクルを明示的に構築する必要がないことに気づいたことです。 代わりに、オイラー走査を可能にするためにどのエッジを繰り返す必要があるかを推論できます。 問題を奇数次の頂点の最適なペアリングに縮小すると、問題はサブセットにわたる扱いやすい DP になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((2^m) × m) | O(m) | 遅すぎる |
 | 最適 (オイラー + DP) | O(n^3 + 2^k × k^2) | O(n^2 + 2^k) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 入力を読み取り、サイズ n × n の隣接行列を構築し、非エッジを無限大で初期化します。 2 つの頂点間に複数のエッジがある場合は、最小ウェイトのみを維持します。 
2. Floyd-Warshall を使用して、すべてのペアの最短経路を計算します。 これにより、奇数次の頂点をペアにするエッジを追加する必要がある場合に、任意の 2 つの頂点を接続するための最小コストが確実にわかります。 
3. 元のエッジを使用して各頂点の次数を計算します。 奇数次数を持つすべての頂点を特定します。 k を奇数次の頂点の数とする。 
4. k = 0 の場合、グラフはすでにオイラー型です。 最小サイクル長は、すべてのエッジの重みの単純な合計です。 この合計を返します。 
5. k > 0 の場合、奇数次の頂点をペアにする必要があります。 ビットマスクを使用して、まだ一致していない奇数の頂点を表します。 dp[0] = 0 を除き、dp[mask] = 無限大を初期化します。 
6. 各マスクについて、最初の不一致の頂点 i を見つけます。 次に、一致しない頂点 j > i をすべて反復し、 dp[mask | を計算します。 (1 << i) | (1 << j)] = min(dp[mask | ...], dp[mask] + dist[i][j])、ここで dist[i][j] は i から j までの最短パス長です。 
7. DP を埋めた後、dp[(1 << k) - 1] には、すべての奇数の頂点をペアにするための最小の合計重みが含まれます。 
8. 最終的な答えは、sum_of_edge_weights + dp[(1 << k) - 1] です。 グラフが切断されている場合は、頂点 1 がすべてのエッジに接続されているかどうかを確認します。 それ以外の場合は -1 を返します。 

**機能する理由**: オイラーの定理は、すべて偶数次数のグラフがオイラー サイクルを持つことを保証します。 頂点の次数が奇数の場合、頂点間の最短パスに沿ってエッジを追加すると、追加コストを最小限に抑えながらすべての頂点が偶数の次数を持つようになります。 サブセット上の DP により、奇数頂点の最小ペアが確実に見つかります。これは、グラフ全体を横断するために必要な反復エッジの最小数に直接対応します。 すべての最短パスが事前に計算されるため、DP を介してエッジを追加すると、常に最小限のコストがかかります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = 10**18

def solve():
    n, m = map(int, input().split())
    dist = [[INF]*n for _ in range(n)]
    deg = [0]*n
    sum_edges = 0
    
    for _ in range(m):
        x, y, w = map(int, input().split())
        x -= 1
        y -= 1
        sum_edges += w
        deg[x] += 1
        deg[y] += 1
        if dist[x][y] > w:
            dist[x][y] = dist[y][x] = w

    for i in range(n):
        dist[i][i] = 0

    # Floyd-Warshall
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][j] > dist[i][k] + dist[k][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    # check connectivity
    for i in range(n):
        for j in range(n):
            if dist[i][j] == INF:
                # If there are edges in disconnected components, no solution
                if deg[i] > 0 and deg[j] > 0:
                    print(-1)
                    return

    odd = [i for i in range(n) if deg[i] % 2 == 1]
    k = len(odd)

    if k == 0:
        print(sum_edges)
        return

    dp = [INF]*(1<<k)
    dp[0] = 0

    for mask in range(1<<k):
        i = 0
        while i < k and (mask & (1 << i)):
            i += 1
        if i == k:
            continue
        for j in range(i+1, k):
            if not (mask & (1 << j)):
                new_mask = mask | (1 << i) | (1 << j)
                dp[new_mask] = min(dp[new_mask], dp[mask] + dist[odd[i]][odd[j]])

    print(sum_edges + dp[(1<<k)-1])

if __name__ == "__main__":
    solve()
```隣接行列により、最短パスの高速計算が可能になります。 Floyd-Warshall は、奇数の頂点をペアにするときに常に最小限のパスを選択することを保証します。 ビットマスク DP は、冗長性を持たずにすべてのペアリングを慎重に処理します。 接続チェックにより、切断されたグラフに対しては -1 が返されます。 インデックス内の Off-by-One エラーは、内部で一貫して 0 から始まるインデックスを使用することで回避されます。
