 ## 解決策
 ## 問題の理解

 2D 平面上の点の集合が与えられており、辺が座標軸と一致する長方形の中にすべての点を囲みたいとします。 このような軸に沿って整列したすべての長方形の中で、可能な限り最小の面積を持つ長方形を見つけるように求められます。 

軸に揃えられた長方形は、左の x 座標、右の x 座標、下の y 座標、および上の y 座標の 4 つの境界によって完全に決定されます。 すべての点はこれらの境界の間になければなりません。 タスクは基本的に、すべてのポイントがカバーされ、幅と高さの積である面積が最小になるように、これら 4 つの値を選択することです。 

この制約では、最大 54321 個の点が許可され、座標の大きさは 10^9 になります。 これは、組み合わせ的な方法で点のペアやサブセットを考慮することができないことを意味します。 多くの候補四角形をチェックしようとするソリューションは、二次関数かそれ以上のものになり、すぐに失敗します。 すべてのポイントを線形または線形に近い時間で処理する方法が必要です。 

ポイントが 1 つしかない場合、微妙なエッジケースが表示されます。 この場合、それを囲む長方形は 1 つの点に折りたたまれるため、幅と高さは両方ともゼロになり、面積もゼロになる必要があります。 もう 1 つのケースは、すべての点が垂直線または水平線上にある場合です。 たとえば、すべての X 座標が等しい場合、面積は幅と高さの積であるため、Y の広がりに関係なく幅はゼロとなり、答えもゼロになります。 これらのケースは、幅と高さが厳密に正であると仮定すると、誤って処理されることがよくあります。 

## アプローチ

 ブルートフォース手法では、左右の境界を定義する 2 つの点と、上下の境界を定義する 2 つの点を選択して長方形を構築しようとします。 そのような選択ごとに、すべての点が内側にあるかどうかを確認します。 これはすでに、x 境界については n から 2 つの点を選択し、y 境界については 2 つの点を選択することを意味しており、およそ O(n^4) 個の候補四角形が得られます。 枝刈りを行ったとしても、封じ込めのチェックには O(n) のコストがかかるため、合計の複雑さは n が 50000 までの場合には実現不可能になります。 

重要な観察は、実際には最適な四角形の境界を選択する自由がないということです。 軸に沿って配置された有効な囲み長方形は、その辺が点セットの極点の座標に正確に配置されなければなりません。 左側が最小 x 座標から内側に移動すると、少なくとも 1 つの点が除外されます。 それが外側に移動した場合、面積は増加するだけです。 同じロジックが右、上、下の境界にも適用されます。 これにより、すべての点の x 値の最小値と最大値、y 値の最小値と最大値によって最適な長方形全体が強制的に定義されます。 

したがって、問題は、単一パスでデータセットの 4 つの値を計算し、幅と高さを乗算することに帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^5) | お(1) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 極値座標を維持しながら、すべての点を 1 回処理します。 

1. 4 つの変数を初期化します: min_x を +infinity、max_x を -infinity、min_y を +infinity、max_y を -infinity に設定します。 これらは、これまでに確認されたすべてのポイントの境界ボックスを追跡します。 
2. 各点 (x, y) について、x を使用して min_x と max_x を更新し、y を使用して min_y と max_y を更新します。 これにより、すべての点を処理した後、これらの変数がすべての点を含む軸に沿った最小の間隔を表すことが保証されます。 
3. すべてのポイントを処理した後、幅を max_x - min_x として計算し、高さを max_y - min_y として計算します。 
4. 幅と高さを乗算して面積を計算します。 
5. 結果を浮動小数点数として出力します。 

ジオメトリ全体を 4 つの数値に圧縮できる唯一の理由は、軸の位置合わせにより、x 軸と y 軸への投影を超えた点間の相互作用が除去されるからです。 

### なぜ効果があるのか

長方形にはすべての点が含まれている必要があるため、その x 間隔にはセット内のすべての x 座標が含まれ、y 間隔にはすべての y 座標が含まれている必要があります。 一連の数値を含む行上の可能な最小の間隔は、常にその最小値と最大値によって決まります。 これらの境界から逸脱すると、少なくとも 1 つの点が除外されるか、間隔の長さが増加するため、面積を改善できません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    min_x = float('inf')
    max_x = float('-inf')
    min_y = float('inf')
    max_y = float('-inf')

    for _ in range(n):
        x, y = map(float, input().split())
        min_x = min(min_x, x)
        max_x = max(max_x, x)
        min_y = min(min_y, y)
        max_y = max(max_y, y)

    width = max_x - min_x
    height = max_y - min_y
    print(width * height)

if __name__ == "__main__":
    solve()
```この実装は、実行中の最小値と最大値を維持することに完全に依存しています。 唯一の微妙な点は、問題ステートメントとサンプルには 10 進数値が含まれているため、座標を浮動小数点数として読み取ることです。 必要な精度は 1e-6 であるため、float を使用すれば十分です。 

潜在的な落とし穴の 1 つは、極値を誤って初期化することです。 すべての座標が負であるか、すべてが正であってもゼロと交差しない場合、0 を使用すると失敗します。 無限大を使用すると、バイアスが回避されます。 

もう 1 つの微妙な点は、ポイント自体を保存する必要はなく、その投影のみを保存する必要があることです。 これにより、メモリ使用量が一定に保たれます。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys

    # inline solution
    n = int(sys.stdin.readline())

    max_x = float('-inf')

 ## 特殊なケース

 単一点入力は、縮退ジオメトリのケースを示しています。 入力あり:```
1
5 5
```アルゴリズムは極値を点自体に初期化し、min_x = max_x = 5 および min_y = max_y = 5 となります。幅と高さは両方ともゼロであり、面積ゼロが正しく生成されます。 

次のような縦線の場合:```
3
2 1
2 5
2 10
```処理全体を通じて、min_x と max_x の両方を 2 に等しく保ちます。 y 極が拡大しても幅はゼロのままです。 軸に沿って整列した長方形は x 方向の線分に縮退するため、最終的な面積はゼロになります。 

水平線は対称的に動作します。 のために：```
3
1 3
4 3
10 3
```y の極値は同一であり、高さはゼロ、したがって面積もゼロになります。 

これらのケースは、アルゴリズムが正の次元を想定しておらず、純粋に極値の演算を通じて縮退を正しく処理していることを確認します。
