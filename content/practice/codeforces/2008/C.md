 ## 解決策
 ## 問題の理解

 指定された 2 つの境界間の整数の配列を構築するように求められます。`l`そして`r`、配列は厳密に増加しており、連続する要素間の差も厳密に増加しています。 私たちの目標は、そのような配列の可能な最大長を見つけることです。 各テスト ケースはペアを提供します`(l, r)`その場合、範囲内に収まる最長の「適切な配列」の長さである単一の整数を出力する必要があります。 

問題の制約により、`l`そして`r`と同じくらい大きくなる$10^9$、最大まであります$10^4$テストケース。 これにより、可能なすべての配列を反復的に構築したり、配列間のすべての組み合わせをチェックしたりするソリューションは除外されます。`l`そして`r`。 平$O((r-l)^2)$アプローチが遅すぎるため、`r-l`までの可能性があります$10^9$。 列挙ではなく算術プロパティを使用して最大長を計算するメソッドが必要です。 

次の場合、微妙なエッジケースが発生します。`l`等しい`r`。 この状況では、可能な配列は次のとおりです。`[l]`、したがって、答えは次のとおりです`1`。 もう 1 つの注意を要するシナリオは次のような場合です。`r - l`非常に小さいため、長さの配列のみが許可されます`2`せいぜい。 配列が常に 2 要素を超えて増加する可能性があると想定する不注意なアルゴリズムは、ここで失敗します。 例えば、`(l=1, r=2)`のみ許可します`[1,2]`たとえパターンがより長い配列を示唆しているとしてもです。 

## アプローチ

 ブルートフォースアプローチは、以下から開始することです`l`、増加するすべての差分を試し、到達するまで要素を追加し続けます。`r`。 これは、「適切な配列」ルールを直接シミュレートできるため機能しますが、次の場合には非現実的になります。`r-l`潜在的なシーケンスの数が組み合わせ的に増加するため、この値は大きくなります。 最悪の場合、すべての可能性を反復処理すると、サブセットの数に比例して時間がかかります。`[l..r]`これは天文学的な数字です。 

最適なソリューションを見つけるための重要な洞察は、違いの性質を観察することから得られます。 最初の要素が`x_1 = l`。 配列の長さを最大化するには、各ステップでの差の増加を最小限に抑える必要があります。`1`最初の違いについては、`2`次のために、など。 これにより、次の形式のシーケンスが得られます。`l, l+1, l+1+2, l+1+2+3, ...`または一般的に`l + 1 + 2 + ... + k`。 最初の合計`k`自然数は`k*(k+1)/2`。 したがって、最大`k`私たちはその中に収まることができる`[l, r]`満足する`l + k*(k+1)/2 - 1 ≤ r`。 

これにより、問題は各テスト ケースの二次不等式を解くことに帰着します。 最大の計算を行うため、このアプローチは高速です。`k`不等式を満たす計算は、三角数の公式または二分探索を使用して定数時間で実行できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((r-l)^2) | O(r-l) | 遅すぎる |
 | 最適 | テスト ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、境界を読み取ります。`l`そして`r`。 配列の最初の要素は次のようになります。`l`。 
2. 変数を初期化する`length`に`1`最初の要素を説明します。 
3. 利用可能な残りの範囲を計算します。`remaining = r - l`。 
4. 配列を拡張するための差の合計`k`追加要素は`1 + 2 + ... + k = k*(k+1)/2`。 最大の整数が必要です`k`そのような`k*(k+1)/2 ≤ remaining`。 
5. を解く`k`整数演算を使用します。 1 つの方法は、次の間の二分探索です。`0`そして`√(2*remaining)`。 もう一つは二次方程式です`k = floor((-1 + sqrt(1 + 8*remaining))/2)`。 
6.追加`k`に`length`。 出力`length`。 

これが機能する理由: 各ステップで、次の差分を可能な限り小さく選択することで、配列を超える前に可能な限り配列を拡張できることが保証されます。`r`。 最初の差を増やすか、数値をスキップすると、最大長が減少します。 式`k*(k+1)/2 ≤ remaining`許容範囲内に収まるステップ数を正確にキャプチャします。 

## Python ソリューション```python
import sys, math
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    l, r = map(int, input().split())
    remaining = r - l
    # Solve k*(k+1)/2 <= remaining
    k = int((-1 + math.isqrt(1 + 8*remaining)) // 2)
    print(k + 1)
```このソリューションは、複数のテスト ケースを読み取り、最初の要素を配置した後の残りの範囲を計算し、三角数不等式を解きます。`math.isqrt`浮動小数点の丸め誤差のない正確な整数平方根を保証します。 追加`1`最初の要素を説明します`l`。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        l, r = map(int, input().split())
        remaining = r - l
        k = int((-1 + math.isqrt(1 + 8*remaining)) // 2)
        output.append(str(k+1))
    return "\n".join(output)

 ## 特殊なケース

 いつ`l=r`、アルゴリズムセット`remaining = 0`そして計算します`k=0`、降伏長さ`1`。 のために`r-l=1`、式は次のようになります`k=1`、結果として長さになります`2`。 整数の平方根により、オーバーシュートが起こらないことが保証されます`k*(k+1)/2 > remaining`。 すべての場合において、アルゴリズムは正しい最大長を生成し、最小範囲と最大範囲の両方をトレースすることで確認されます。
