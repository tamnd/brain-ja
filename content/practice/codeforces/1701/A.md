 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、このくらいの小さな芝生の広場です。$2 \times 2$, ここで、各セルは草がある (1) か空である (0) かのいずれかです。 目標は、できるだけ少ない動きですべての草を取り除くことです。 移動は、任意の行と任意の列を選択し、その行と列のすべての草を同時に刈ることで構成されます。 カットごとに、影響を受けるセルが 0 に設定されます。 

入力は複数のテスト ケースで構成されます。 テストケースごとに、の状態を受け取ります。$2 \times 2$分野。 出力は、すべての草を取り除くのに必要な最小移動数を表す各テスト ケースの単一の整数です。 

フィールドは非常に小さいため、草のセルの最大数は 4 です。 これは、この分野を網羅的に分析できることを意味します。 エッジケースは、草が存在しない場合、1 つのセルのみに草がある場合、または草が斜めに分布している場合に発生します。 たとえば、次のようなフィールドです。```
1 0
0 1
```最初の行と 2 番目の列を選択すると両方の草を一度に削除するため、1 回の移動が必要です。 行と列の選択の間の相互作用を誤解すると、単純なアプローチで過剰な移動が行われる可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるあらゆる一連の動きを考慮し、フィールドが空になるまで草を刈るシミュレーションを行います。 で$2 \times 2$グリッドでは、可能な草の構成は 16 しかないため、これは実現可能です。 ただし、草セルの総数とその配置に基づいてパターンが現れるため、各構成のシーケンスをシミュレートする必要はありません。 

重要な観察は、移動数が草のあるセルの数によって完全に決定されるということです。 草セルがない場合、答えは 0 です。草セルが 1、2、3、または 4 つある場合、少なくとも 2 つの草セルを含む行または列が存在するかどうかに応じて、手は 1 または 2 になります。 具体的には、完全に空のフィールドまたは単一の草のセルを除くすべての構成は、常に最大 2 回の移動でクリアできます。 

最適なアプローチは、草のあるセルの数を数え、次のルールを使用することになります。 

- 草マスが 0 → 移動が 0 になります。 
・草マス1個→1手。 
- 2、3、または 4 つの草セル → 行または列に少なくとも 2 つの草セルが含まれている場合は 1 移動、そうでない場合は 2 移動。 

フィールドの固定サイズが小さいため、このロジックは直接的です。 複雑なデータ構造や動的プログラミングは必要ありません。

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、$2 \times 2$フィールドを表す行列。 
2. 草の細胞の総数を数えます (`total = sum of all 4 cells`）。 
3. 行または列に少なくとも 2 つの草セルが含まれているかどうかを確認します。 
4. 以下に基づいて答えを決定します。 

- もし`total`は0→0手です。 
- もし`total`は1→1手です。 
- もし`total`2 以上:

 - どこかの行または列に少なくとも 2 つの草マスがある場合 → 1 移動します。 
- それ以外の場合 → 2手。 
5. テスト ケースの答えを出力し、すべてのテスト ケースに対して繰り返します。 

機能する理由: このアルゴリズムが機能するのは、すべての移動が行と列全体をカバーできるためです。 と$2 \times 2$グリッドでは、同じ行または列に配置されている場合は 1 回の移動で最大 2 つの草のセルをクリアでき、交差点で重なっている場合は 3 つの草のセルをクリアできます。 カウントベースの行/列チェックにより、必要な移動数を過小評価することがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    total = sum(a) + sum(b)
    
    if total == 0:
        print(0)
    elif total == 1:
        print(1)
    elif (a[0] + a[1] == 2) or (b[0] + b[1] == 2) or (a[0] + b[0] == 2) or (a[1] + b[1] == 2):
        print(1)
    else:
        print(2)
```このソリューションは、まずフィールドの 2 行を読み取り、総草数を計算してから、少なくとも 2 つの草セルを持つ行または列があるかどうかを確認します。 各条件は、アルゴリズムで説明されているルールに直接マッピングされます。 

実装の微妙なポイントには、各行と列が個別のリストであることを覚えておくことが含まれます (`a`そして`b`)、列をチェックするにはインデックスを慎重に使用する必要があります。 条件`(a[0]+b[0]==2)`最初の列をチェックし、`(a[1]+b[1]==2)`2 番目の列をチェックします。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    
    t = int(input())
    for _ in range(t):
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        total = sum(a) + sum(b)
        
        if total == 0:
            print(0)
        elif total == 1:
            print(1)
        elif (a[0] + a[1] == 2) or (b[0] + b[1] == 2) or (a[0] + b[0] == 2) or (a[1] + b[1] == 2):
            print(1)
        else:
            print(2)
    
    return out.getvalue().strip()

| 0 1 / 1 0 | 2 | 斜めの草は 2 回の移動が必要です。

## 特殊なケース

 次のように草が斜めに分布している場合:```
1 0
0 1
```アルゴリズムが計算します`total = 2`, しかし、草のセルが 2 つある行または列はありません。 したがって、正しく 2 つの手を出力します。 これは、このソリューションが斜めのセルをカバーする単一の移動の能力を過大評価していないことを確認します。 同様に、単一の芝生セルまたは完全に空のフィールドの場合、合計ベースのチェックにより、不必要なシミュレーションに分岐することなく正しい処理が保証されます。
