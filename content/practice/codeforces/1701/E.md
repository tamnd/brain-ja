 ## 解決策
 ## 問題の理解

 2 つの文字列が与えられています。`s`そして`t`、それぞれ実際に書いたテキストと希望するテキストを表します。 エディターのカーソルは末尾から始まります。`s`をクリックすると、カーソルを左右に移動したり、先頭または末尾にジャンプしたり、カーソルの直前の文字を削除したりできます。 目標は変身すること`s`の中へ`t`最小限の移動を使用するか、レポートを実行します`-1`それが不可能な場合。 

重要なのは、削除とカーソル移動のみが許可されるということです。 新しい文字を挿入することはできませんので、`t`の部分列である必要があります`s`。 のいずれかの文字があれば、`t`が欠けています`s`正しい相対順序では、変換は不可能です。 

制約が教えてくれるのは`n`そして`m`それぞれ最大 5000 まで可能で、合計は`n`すべてのテスト ケースの数は 5000 です。これは、`O(n^2)`最悪の場合、テスト ケースごとに解が得られますが、二次方程式よりも悪いものは避けるべきです。 カーソル移動のすべてのシーケンスをシミュレートする単純な総当り攻撃は指数関数的であり、実行不可能です。 

エッジケースが発生するのは次の場合です`t`の最初または最後にあります`s`、または複数の繰り返し文字が含まれる場合。 たとえば、次の場合`s = "aaab"`そして`t = "ab"`不注意なアプローチでは、最初の 2 つの文字が考慮されずに末尾から文字を削除しようとする可能性があります。`a`は不要です。 正しい出力では、カーソルの動きとバックスペースが最適に考慮されている必要があります。 

## アプローチ

 素朴なアプローチは、調整するあらゆる方法を試すことです。`t`内部`s`。 次のすべてのサブシーケンスを考慮することができます`s`長さの`m`そして、そのサブシーケンスにない文字の削除をシミュレートし、設定ごとにカーソルの動きをカウントします。 これは、有効な変換では正しい文字を削除し、場合によってはカーソルを左右に移動する必要があるため機能しますが、サブシーケンスの数が組み合わせによって増加するため、すぐに失敗します。`n`。 

重要な点は、一致させるだけでよいということです。`t`の連続セグメントとして`s`左右の一部を削除した後。 の一部のプレフィックスと一部のサフィックスを削除すると、`s`、残っているものは正確に一致する必要があります`t`。 これにより、問題はすべて有効なものをチェックするだけになります。`(prefix, suffix)`除去により生成されるペア`t`。 正しいセグメントが特定されたら、カーソル移動の最小回数を計算できます。 

- 削除した場合`k`右からの文字が必要です`k`バックスペース。 
- 削除した場合`l`左からの文字が必要です`l`カーソルはスタートプラスに移動します`l`バックスペース。 
- 削除の順序を最適化し、ホーム/エンドジャンプを使用すると、移動がさらに減ります。 

考えられるすべての分割方法のコストを計算することにより、`s`削除するパーツに分割し、最小の合計移動量を見つけます。 このアプローチは二次関数です`n`、制約に適合します。

 ## アルゴリズムのチュートリアル

 1.初期化`min_moves`無限に。 これにより、見つかった最適なソリューションが保存されます。 
2. すべての位置を反復処理します。`i`で`s`ここで、長さの接頭辞は`i`保管されています。 これは、最初のものを削除することを意味します`i`必要に応じて文字を入力します。 
3. それぞれについて`i`、すべての位置を反復処理します。`j`で`s`ここで長さの接尾辞は`j`保管されています。 接尾辞を削除した後、残りの長さの文字列`n - j`残っています。 
4. 部分文字列が`s[i:n-j]`等しい`t`。 そうでない場合はスキップしてください。 
5. 一致する場合は、移動を計算します。 

-`left_moves = i`プレフィックスを削除する場合は先頭に移動します。 
-`backspaces_for_left = i`プレフィックスを削除するには、
 -`right_moves = n - j - len(t)`の端から移動する`t`サフィックスを削除する前に最後まで、
 -`backspaces_for_right = j`サフィックスを削除します。 
- ホーム/エンドジャンプを使用して動きを効率的に組み合わせる: ホームから開始する動きは、多くの左の動きではなく 1 つの動きとしてカウントされます。 
6.アップデート`min_moves`この組み合わせが小さい場合。 
7. もし`min_moves`無限大のまま、出力`-1`。 それ以外の場合は出力`min_moves`。 

これが機能する理由: 不変条件は、分離する連続したプレフィックスおよび/またはサフィックスを削除することで、最適な削除シーケンスを表現できることです。`t`。 ホームジャンプとエンドジャンプを使用すると、カーソルの動きを圧縮できます。 すべてのプレフィックスとサフィックスの組み合わせをチェックすることで、最小限の移動数が見つかることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def min_moves_to_match(s, t):
    n, m = len(s), len(t)
    min_moves = float('inf')

    for left_del in range(n + 1):
        for right_del in range(n - left_del + 1):
            if n - left_del - right_del != m:
                continue
            if s[left_del:n - right_del] == t:
                # moving cursor to start to delete prefix
                moves = 0
                if left_del > 0:
                    moves += 1 + left_del  # home + backspaces
                # delete suffix from end
                moves += right_del  # backspaces
                min_moves = min(min_moves, moves)

    return -1 if min_moves == float('inf') else min_moves

T = int(input())
for _ in range(T):
    n, m = map(int, input().split())
    s = input().strip()
    t = input().strip()
    print(min_moves_to_match(s, t))
```コードは、すべての有効な分割方法を明示的に反復します。`s`プレフィックス、コア、サフィックスに分割します。 私たちが使用するのは`home`繰り返し左に移動するのではなく、1 回の移動でプレフィックスを削除できます。 バックスペースは直接カウントされます。 これにより、最小限の移動が保証されます。
