 ## 解決策
 ## 問題の理解

 私たちは、$n \times n$グリッドでは、各セルが空であるか、整数サイズのパールを含むことができます。 グリッドは一連の操作を通じて更新されます。各操作では、セルにパールを配置するか、既存のパールを置き換えるか、削除します。 

更新のたびに、現在の構成がグローバル一貫性ルールを満たすかどうかを判断する必要があります。つまり、水平または垂直に隣接する占有セルのペアはすべて、パール サイズの合計が同じでなければなりません。 言い換えれば、両方にパールを含む 2 つの隣接するセルを接続するエッジに注目すると、その時点で、その値の合計はグリッド内のすべてのエッジで同一でなければなりません。 

重要な問題は、この状態がグローバルであり、すべての隣接するペアに同時に依存するため、動的なポイント更新で維持する必要があることです。 

制約$n, q \le 10^5$更新のたびにグリッドを検査するアプローチは直ちに除外してください。 単一のセルには最大 4 つの隣接セルが存在する可能性がありますが、グリッド サイズが大きすぎて明示的に維持できないため、高密度構成では、変更されたセルのすべての隣接セルを反復処理するだけでも遅くなる可能性があります。 本当の問題は、グリッド全体を保存したり走査したりする余裕すらないことです。 

隣接する占有セルのペアがまったく存在しない場合、微妙な特殊なケースが発生します。 この場合、条件は事実上真であるため、答えは YES になるはずです。 少なくとも 1 つのエッジが存在する必要があると誤って想定した単純な実装では、誤って NO が出力される可能性があります。 

エッジが消えるような方法で値が更新される場合、別のエッジ ケースが発生します。 たとえば、隣接する 2 つのセルの両方に値が含まれており、一方が削除された場合、制約はそのペアに適用されなくなります。 削除されたセルに関連付けられた制約を適切に削除しないソリューションでは、誤って古い条件が適用され続ける可能性があります。 

## アプローチ

 ブルートフォース解釈では、グリッド全体が維持され、更新のたびにすべてのセルがスキャンされ、隣接する占有隣接セルのすべてのペアがチェックされます。 これが機能するのは、条件が純粋にローカルであるためです。つまり、隣接するセルのみを比較します。 ただし、最悪の場合、グリッドは$n^2$セルと各更新にはスキャンが必要です$O(n^2)$ポジション、それにつながる$O(n^2 q)$まったく実行不可能な操作です。 

重要な観察は、この条件は絶対値ではなく、エッジ間の差異に関するものであるということです。 すべての有効なエッジの合計が同じである場合$S$、次に、任意の 2 つの隣接する占有セルについて$u, v$、 我々は持っています$a_u + a_v = S$。 これは、強力な構造上の制限を意味します。セル値が固定されると、その隣接セルはすべて制約され、不一致は新しいエッジが形成または変更されるときに局所的にのみ発生します。 

グリッド全体をチェックする代わりに、アクティブなエッジのセット (隣接する占有セルのペア) を維持します。 これらのエッジの合計を追跡し、それらすべてが単一のグローバル候補値と一致することを確認します。 問題は、エッジが動的であるため、セルが更新されると、そのセルに付随するエッジのみが変化することです。 これにより、一貫性を段階的に維持できるようになります。 

私たちはエッジ合計のマルチセット (または周波数マップ) を維持し、すべてのアクティブなエッジ間に最大 1 つの異なる合計が存在することを保証します。 エッジがゼロの場合、答えは明らかに YES です。 各更新は最大 4 つのエッジに影響するため、操作ごとに一定時間で構造を更新できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^2 q)$|$O(n^2)$| 遅すぎる |
 | 最適 |$O(q)$|$O(n + q)$| 承認済み |

 ## アルゴリズムのチュートリアル

 各占有セルを、直交して隣接する占有セル間にエッジが存在する動的グラフ内のノードとして扱います。 各エッジは制約に影響します。つまり、そのエンドポイント値の合計が共通のグローバル値になる必要があります。 

1. セル座標から値までのハッシュ マップを維持します。 セルが空の場合、そのセルは保存されません。 これにより、完全なグリッドが実体化することが回避されます。 
2. 隣接する占有セル間のすべての現在のエッジ合計を追跡する 2 番目の構造を維持します。 各エッジは、たとえば右と下に隣接するエッジのみをカウントすることによって 1 回考慮されます。 
3. セルでの更新ごとに$(x, y)$、このセルが以前に存在していた場合は、最初にこのセルの寄与を削除します。 これには、接続しているすべてのエッジを削除する必要があります$(x, y)$既存の占領されている近隣諸国へ。 これらのエッジの合計は周波数構造から削除されます。 
4. 次に、新しい値を挿入します。$v$ゼロ以外の場合。 挿入後、間にバックエッジを追加します。$(x, y)$および現在占領されている近隣諸国の合計をそれに応じて更新します。 
5. 更新を処理した後、すべてのアクティブなエッジが同じ合計を共有するかどうかを確認します。 これは、個別のエッジ合計のセットのサイズが最大でも 1 であることを検証することと同じです。 
6. エッジがない場合は、YES を出力します。 それ以外の場合、明確なエッジ合計が 1 つだけ存在する場合にのみ YES を出力します。 

各ステップが重要なのはローカルな一貫性です。すべての更新では、変更されたセルに関係する隣接関係のみが変更されるため、その近傍のみを修復することでグローバルな有効性を更新できます。 

### なぜ効果があるのか

 この条件は、すべてのアクティブなエッジにわたる均一な制約を定義します。 すべての制約には 2 つのエンドポイントが含まれるため、違反は少なくとも 1 つのエッジに現れる必要があります。 更新では、更新されたセルに付随するエッジのみが変更されるため、他のすべてのエッジは以前の有効性状態を保持します。 したがって、エッジ和のマルチセットを維持するだけで、矛盾する和が出現するかどうかを検出できます。 複数の異なる合計が存在する場合、グローバル値は存在しません$S$すべての制約を同時に満たすことができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, q = map(int, input().split())

grid = {}
from collections import defaultdict

cnt = defaultdict(int)
distinct = 0

def add(val):
    global distinct
    if cnt[val] == 0:
        distinct += 1
    cnt[val] += 1

def remove(val):
    global distinct
    cnt[val] -= 1
    if cnt[val] == 0:
        distinct -= 1

def get(x, y):
    return grid.get((x, y), 0)

for _ in range(q):
    x, y, v = map(int, input().split())

    if (x, y) in grid:
        old = grid[(x, y)]

        for dx, dy in [(1, 0), (-1, 0), (0, 1), (0, -1)]:
            nx, ny = x + dx, y + dy
            if (nx, ny) in grid:
                neighbor = grid[(nx, ny)]
                remove(old + neighbor)

        del grid[(x, y)]

    if v != 0:
        for dx, dy in [(1, 0), (-1, 0), (0, 1), (0, -1)]:
            nx, ny = x + dx, y + dy
            if (nx, ny) in grid:
                neighbor = grid[(nx, ny)]
                add(v + neighbor)

        grid[(x, y)] = v

    if distinct <= 1:
        print("YES")
    else:
        print("NO")
```この実装では、占有されているセルのみを辞書に保存するため、不可能な問題が回避されます。$n^2$メモリのフットプリント。 各更新では、新しいエッジを挿入する前に古いエッジが慎重に削除され、古いエッジが構造内に残らないようにします。 

の`cnt`マップはエッジ和の頻度を追跡しますが、`distinct`現在存在する異なる合計がいくつあるかを追跡します。 これにより、各更新後に一定時間のチェックが可能になります。 唯一の微妙な点は、セルを削除する前に古いエッジを削除し、挿入後に新しいエッジを再度追加する必要があることです。そうしないと、エッジを見逃したり二重にカウントしたりすることになります。

 ## 特殊なケース

 重要なエッジ ケースは、以前にエッジを形成した後にすべてのセルが削除される場合です。 たとえば、2 つの隣接するセルが存在し、有効な合計を形成した場合、両方が削除され、制約が残っていないため、システムは YES を返す必要があります。 両方のエンドポイントを削除すると、対応するエッジ合計エントリがすべて削除され、周波​​数マップが空のままになるため、アルゴリズムはこれを処理します。 

もう 1 つのエッジ ケースは、同じセル上で更新が繰り返されることです。 セルが複数回上書きされる場合は、新しいエッジを追加する前に古いエッジを削除する必要があります。 この実装では、挿入前に常に削除を処理することでこれを保証し、古いエッジ合計が残らないようにします。 

最後のエッジ ケースは、セルが空の状態と空でない状態の間で急速に切り替わる場合です。 各遷移が隣接関係の寄与を完全に再構築するため、システムの一貫性が維持され、重複したエッジ カウントが蓄積されません。
