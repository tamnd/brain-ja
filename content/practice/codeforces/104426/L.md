 ## 解決策
 ## 問題の理解

 無限グリッド上に整数座標の点を配置しており、少なくとも$K$原点を中心とする円の内側または境界上の個別のグリッド ポイント。 タスクは、最小の整数半径を見つけることです。$R$を満たす格子点の数$x^2 + y^2 \le R^2$少なくとも$K$。 

各人は 1 つの格子点に対応し、2 人が同じ座標を占めることはできないため、問題は円の中に整数のペアがいくつあるかを数えるということになります。 半径は整数である必要があり、少なくとも許容される最小の半径が求められます。$K$有効な位置。 

重要な制約は、$K \le 10^9$。 これにより、円内の格子点の数は面積にほぼ比例して増加するため、格子点の直接シミュレーションや強引な列挙は直ちに排除されます。$O(R^2)$。 半径を単純にスキャンして半径ごとに点をカウントするには、格子点の数を繰り返し再計算する必要があり、一度計算すると非常に遅くなります。$R$大きな値に成長します。 

微妙なエッジケースは次のような場合です$K$とても小さいです。 たとえば、次の場合$K = 2$、答えは$1$、半径があるため$0$原点のみが含まれます。 もう 1 つのエッジケースは次のような場合です$K$格子点の完全対称層のすぐ上にあり、境界点が存在しないか境界点が含まれているとカウントが急激に変化します。 正確な整数点を数える代わりに円の面積を近似する解決策は、ここでは失敗します。 

## アプローチ

 ブルートフォースアプローチでは、半径を大きくしようとします。$0$上向きに、各半径について次を満たすすべての整数点をカウントします。$x^2 + y^2 \le R^2$。 それぞれについて$R$、これにはすべてを反復する必要があります$x$で$[-R, R]$有効な数を計算します$y$価値観が存在する。 これは$O(R)$半径ごと、そしてそれ以来$R$それ自体は約まで行くことができます$10^5$大きい場合はそれ以上$K$、合計作業量はおおよそになります$O(R^2)$が遅すぎます。$K = 10^9$。 

重要な観察は単調性です。 半径が増加しても、円内の格子点の数は減りません。 これは、答えを二分探索できることを意味します$R$。 欠けている部分は、固定の格子点の数を計算する方法です。$R$効率的に。 すべての点を列挙する代わりに、整数を反復処理します。$x$から$0$に$R$、それぞれについて$x$、最大の整数を決定します$y$そのような$x^2 + y^2 \le R^2$。 これにより、$y = \lfloor \sqrt{R^2 - x^2} \rfloor$。 そういったそれぞれの$x$貢献する$2y + 1$点 (4 つの象限すべてと軸の対称性を考慮)。 これにより、カウントが減少します$O(R)$、二分探索と組み合わせて、$R$、効率的な解決策が得られます。

 ## アルゴリズムのチュートリアル

 円内の格子点の数が半径とともに着実に増加することを利用して、少なくとも次の値に達する最小半径を検索できます。$K$ポイント。 

## アルゴリズムのチュートリアル

 1. 関数を定義する`count(R)`半径の円の内側または上に整数格子点がいくつあるかを計算します。$R$。 これを行うには、すべての整数をスキャンします。$x$から$0$に$R$、コンピューティング$y_{\max} = \lfloor \sqrt{R^2 - x^2} \rfloor$、そして追加$2y_{\max} + 1$カウントに。 非負のみを反復します$x$対称性を使用して、冗長な計算を回避します。 
2. 半径ごとに$R$、値$y_{\max}$は、その水平スライスで垂直方向にどこまで移動できるかを表します。 これにより、境界点を見逃すことなく、円不等式を満たすすべての整数点を正確に数えることができます。 
3. 二分探索境界を設定します。 下限は$0$、上限は次のような値に安全に設定できます。$2 \cdot 10^5$、エリアの成長により確実に達成できるため、$10^9$その半径のかなり前をポイントします。 
4. 二分探索を実行します。 中半径の場合、計算します`count(mid)`。 以上の場合$K$、半径を小さくしてみます。 それ以外の場合は、半径を大きくします。 
5. 二分探索が収束するまで続行し、条件を満たす最小の半径を返します。 

### なぜ効果があるのか

 任意の半径に対して$R$、を満たす格子点のセット$x^2 + y^2 \le R^2$は整数幾何学によって完全に決定され、次のように単調増加します。$R$が増えます。 すべての整数が計算されるため、カウント関数は正確で近似的ではありません。$x$有効な正確な整数範囲とペアになります。$y$。 これにより、二分探索が曖昧さのない単調述語で動作することが保証されるため、最初の半径は次のようになります。$K$有効な最小値です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def count_points(R):
    res = 0
    r2 = R * R
    for x in range(R + 1):
        y2 = r2 - x * x
        if y2 < 0:
            break
        y = math.isqrt(y2)
        res += 2 * y + 1
    return res

def solve():
    K = int(input().strip())

    lo, hi = 0, 200000

    while lo < hi:
        mid = (lo + hi) // 2
        if count_points(mid) >= K:
            hi = mid
        else:
            lo = mid + 1

    print(lo)

if __name__ == "__main__":
    solve()
```機能`count_points`ソリューションの核心です。 第 1 象限の正確な格子点を計算し、暗黙的に対称性を乗算します。$2y + 1$構造ごと$x$。 ループは一度早めに停止します$x^2 > R^2$、不必要な繰り返しを防ぎます。 

二分探索では、候補半径の範囲を維持し、現在の半径がすでに少なくともサポートしているかどうかに基づいて候補半径を縮小します。$K$ポイント。 

一般的な実装上の落とし穴は、浮動小数点平方根を使用することです。これにより、大きな値で精度エラーが発生する可能性があります。 使用する`math.isqrt`整数の正確性を保証します。

 ## 特殊なケース

 主なエッジケースは次のような場合です$K = 1$。 唯一の有効な点は原点であるため、半径$0$返さなければなりません。 カウンティング関数は次の時点で正しく 1 を返します。$R = 0$, そのため、二分探索はすぐに 0 に落ち着きます。 

もう一つのケースは次のような場合です。$K$格子密度の大きな上昇のすぐ下にあります。 たとえば、近くの$R = 2$、カウントは 5 から 13 にジャンプします。面積を使用した近似方法$\pi R^2$丸めに応じて、誤って半径 1 または 3 を選択する可能性があります。 正確な整数カウントでは、すべての格子点が近似ではなく整数ジオメトリを介して列挙されるため、この問題が完全に回避されます。 

最後の微妙なケースは、境界の包含の正確さです。 満足のポイント$x^2 + y^2 = R^2$を含める必要があります。 の使用`isqrt`平方根の下限を整数で返し、浮動小数点ドリフトなしで境界点を保持するため、等価の場合が正確に処理されることが保証されます。
