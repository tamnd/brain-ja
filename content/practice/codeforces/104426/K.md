 ## 問題の理解

 各クエリに対して 3 つの整数が与えられます: 開始値`a`、乗数`b`、およびモジュラスターゲット`d`。 負でない整数を選択できます`k`、そして私たちはそのような最小のものを望んでいます`k`これにより、2 つの別々の割り算条件が同時に真になります。 

最初の条件は、製品が`a · b^k`で割り切れます`d`。 つまり、乗算した後、`a`による`b`繰り返し`k`倍、結果の数値には次のすべての素因数が含まれている必要があります。`d`少なくとも同じ多重度を持つ。

まで答えなければなりません`10^5`独立したクエリ。それぞれの値は次のとおりです。`10^9`。 これにより、増加をシミュレートするアプローチは即座に除外されます。`k`最悪の場合、クエリごとに 100 ステップでもすでに大きすぎるため、クエリごとにステップごとに実行します。 

素朴に読んだ人は、すべてを試してみることを勧めるかもしれません`k`ゼロから開始して両方の条件を確認します。 それは時間のせいだけでなく、`k`簡単に超えることができます`10^9`何かが安定する前に。

## アプローチ

 強引な戦略が増加を試みる`k`から`0`上向きに移動し、両方の可分性条件を直接チェックします。 各チェックは O(1) ですが、問題は、意味のある上限がないことです。`k`。 最悪の場合、答えが非常に大きな値でのみ存在するか、まったく存在しない場合、このプロセスは無制限の反復に退化します。 キャップをしても`k`で`10^9`これは、2 秒の制限の下で実行可能な計算をはるかに超えています。 

重要な観察は、2 番目の条件が制約しているということです。`k`べき乗とは独立したモジュラー算術構造で。 表現`a + b·k ≡ 0 (mod d)`の線形合同として書き直すことができます。`k`。 これは、モジュラー逆関数または gcd ベースの推論を使用して直接解決でき、有効な単一の等差数列のいずれかを生成します。`k`価値観があるか、まったく解決策がない。 

有効になったら`k`値はあるステップを法とする剰余クラスに制限されるため、問題は最小値を見つけることに帰着します。`k`そのクラスでは、乗算の割り算条件も満たします。`a · b^k`。 指数項を毎回最初から再計算する必要はありません。`k`、指数は素数の累乗にのみ影響するためです。`b`で直線的に増加します。`k`評価の面で。

これにより、問題は無制限の検索から、最大でも少数の等差数列をチェックし、各候補を効率的に検証することに変わります。

 ## アルゴリズムのチュートリアル

 各クエリを個別に処理します。 

1. まず、自明な係数の場合を処理します。 もし`d = 1`、どちらの条件も常に満たされます。`k`なので、すぐに戻ります`0`。 これにより、不必要な演算が回避され、後で除算のエッジケースが発生するのを防ぎます。 

2. 2 番目の条件を検討します`a + b·k ≡ 0 (mod d)`。 これを次のように書き換えます`b·k ≡ -a (mod d)`。 これは次の線形合同です。`k`。 

3. コンピューティング`g = gcd(b, d)`。 もし`a % g ≠ 0`の場合、合同式には解がないので、戻ります。`-1`。 これは、線形合同の標準的な可解条件から得られます。 

4. 解ける場合は、方程式を次の値で割ります。`g`これをより単純なモジュラー方程式に変換するには、次のようにします。`(b/g) · k ≡ -(a/g) (mod d/g)`。 

5. モジュラー逆関数を計算します。`b/g`モジュロ`d/g`。 これにより基本的な解決策が得られます`k0`すべての解は次のようになります。`k = k0 + t · (d/g)`整数の場合`t ≥ 0`。 

このステップは、無限に多くの候補を 1 つの等差数列に圧縮するため、非常に重要です。 

6. ここで、最初の条件を強制する必要があります。`a · b^k`で割り切れる`d`。 完全な積を再計算する代わりに、次の素因数を追跡します。`d`。 素数ごとに`p`分割する`d`、次のものが必要です。`v_p(a) + k · v_p(b) ≥ v_p(d)`。 

もし`v_p(b) = 0`、 それから`k`それは役に立ちません、そして私たちはすでに持っている必要があります`v_p(a) ≥ v_p(d)`。 これが失敗した場合は戻ります`-1`。 

7. 素数の場合、`v_p(b) > 0`、次のしきい値を計算できます。`k`:`k ≥ ceil((v_p(d) - v_p(a)) / v_p(b))`。 

これらのしきい値の最大値を取ると、最小値が得られます。`k`すべての主要な制約を満たします。 

8. 最後に、両方の制約を組み合わせます。必要なのは最小の制約です。`k ≥ threshold`それも満たす`k ≡ k0 (mod step)`。 これは標準的な等差数列検索となり、反復ではなく直接の位置合わせ式を使用して計算されます。 

9. 最小のもの`k`と印刷されています。 そのような位置合わせが存在しない場合は、戻ります`-1`。 

### なぜ効果があるのか

 このアルゴリズムは、問題を 2 つの独立した構造的制約 (線形モジュラー制約と単調評価制約) に分離します。 

線形合同は、無限の探索空間を単一の等差数列に縮小します。 評価条件は、それを超えるとそれ以上のすべての評価が行われる最小しきい値を定義します。`k`主要な貢献に関しては引き続き有効です。 しきい値を等差数列と交差させると、常に空のセットまたは明確に定義された最初の要素が生成され、これを直接計算します。 すべての有効な解は両方の制約を満たさなければならず、考慮されるすべての候補は 2 番目の方程式の完全な解空間に正確に存在するため、これにより正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from math import gcd

def ext_gcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x1, y1 = ext_gcd(b, a % b)
    return g, y1, x1 - (a // b) * y1

def mod_inv(a, m):
    g, x, _ = ext_gcd(a, m)
    if g != 1:
        return None
    return x % m

def factorize(x):
    i = 2
    res = {}
    while i * i <= x:
        while x % i == 0:
            res[i] = res.get(i, 0) + 1
            x //= i
        i += 1
    if x > 1:
        res[x] = res.get(x, 0) + 1
    return res

def solve():
    t = int(input())
    for _ in range(t):
        a, b, d = map(int, input().split())

        if d == 1:
            print(0)
            continue

        g = gcd(b, d)
        if a % g != 0:
            print(-1)
            continue

        bd = b // g
        dd = d // g

        inv = mod_inv(bd % dd, dd)
        rhs = (-a // g) % dd
        k0 = (rhs * inv) % dd

        fac = factorize(d)

        lower = 0
        ok = True

        for p, e in fac.items():
            va = 0
            vb = 0
            ta = a
            tb = b
            while ta % p == 0:
                va += 1
                ta //= p
            while tb % p == 0:
                vb += 1
                tb //= p

            if vb == 0:
                if va < e:
                    ok = False
                    break
            else:
                need = max(0, e - va)
                lower = max(lower, (need + vb - 1) // vb)

        if not ok:
            print(-1)
            continue

        step = dd
        if lower <= k0:
            ans = k0
        else:
            diff = lower - k0
            add = (diff + step - 1) // step
            ans = k0 + add * step

        print(ans)

if __name__ == "__main__":
    solve()
```解決策は、次の線形合同を解くことから始まります。`a + b·k`。 拡張ユークリッド アルゴリズムを使用して逆モジュラーを計算し、基本解を与えます。`k0`モジュロ`d/g`。 

次に因数分解します`d`そして、乗算条件の素数ごとの制約を計算します。 各素数について、それがどのくらいの頻度で現れるかを抽出します。`a`そして`b`、次に最小指数要件を導出します。`k`。 これらの要件の最大値が全体的な下限になります。 

最後に、この下限を等差数列に合わせます。`k ≡ k0 (mod d/g)`反復する代わりに、最初の有効な位置に直接ジャンプします。 

微妙な正確性のポイントは、逆変換前の gcd チェックと、`g`。

 ## 特殊なケース

 いつ`d = 1`、アルゴリズムはすぐに戻ります`0`gcd または因数分解の前。 これは、すべての整数が 1 で割り切れるという事実と一致します。`k = 0`常に最適です。 

いつ`b = 0`、gcd ステップの結果は次のとおりです。`g = d`、そして線形方程式は次のことをチェックすることに帰着します。`a`はすでに係数と一致しています。 乗算条件は単純化されます。`b^k`ゼロに崩壊します`k ≥ 1`ただし、アルゴリズムは因数分解を通じて評価ロジックを処理することで、これに依存することを回避します。 

いつ`a % gcd(b, d) ≠ 0`、ソリューションは正しく返されます`-1`反転する前、いいえ`k`線形合同を満たすことができます。
