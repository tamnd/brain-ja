 **タグ:** dp、フロー
 **解決時間:** 1 分 8 秒

 ## 解決策
 ## 問題の理解

 私たちが扱っているのは、紛失した荷物が毎日のフライトに応じて移動し、検査を通じて部分的に回収される空港のネットワークです。 各空港には紛失手荷物の初期数が定められています。 毎日、各空港は 2 種類の便で前後の空港に荷物を送りますが、それぞれに独自の輸送制限があります。 飛行機の出発後、荷物が目的地に到着する前に検査が行われ、残数がしきい値を超えた場合に超過手荷物が回収​​されます。 私たちの仕事は、これらの検査後に見つからずに残る可能性のある荷物の最大数を日数のプレフィックスごとに決定することです。 日の各プレフィックスは独立しています。つまり、実験は k 日期間ごとに初期状態から再開されると考えることができます。 

この問題は、最大 12 か所の少数の空港によって制約されますが、最大 2000 日という多数の日数がかかる可能性があります。荷物の数と輸送制限は非常に大きく、最大 2000 日になります。$10^8$。 これは、個々の荷物を反復処理する余裕はないことを意味しますが、小さな$n$これにより、空港の状態を明示的に考慮できるようになります。 実行可能なすべての荷物の割り当てを考慮しながら、毎日のあらゆる移動をシミュレートする単純なアプローチでは、各空港が輸送制限に達するまで任意の数の荷物を複数の方向に送ることができるため、組み合わせが爆発的に増加します。 

初期の手荷物数または輸送制限が検査基準に比べて非常に大きい場合、明らかではないエッジケースが発生します。 たとえば、空港で大量の紛失物があり、検査の基準が低い場合、最適な解決策は、見つからない荷物を最大限に増やすために、許可される限り多くの荷物を近隣の空港に移動することかもしれません。 すべての輸送制限がゼロの場合、荷物は移動できず、解決策は純粋に初期数と検査しきい値に依存します。 空港の基準値が現在の荷物数よりも高い場合は、荷物を回収できないことを意味し、最適な配分が大幅に変化する可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、毎日の空港全体で考えられるすべての荷物の分布を明示的に追跡し、見つからない荷物の数を計算しようとします。 各空港は隣接する 2 つの空港に荷物を送ることができ、可能な組み合わせは飛躍的に増加します。$n$。 毎日、可能な割り当て数は次のとおりです。$\prod_{j=1}^n (a_{i,j}+1)(c_{i,j}+1)$、輸送制限が大きいことを考えると、これは不可能です。 たとえ$n = 12$、荷物の数が最大であるため、すべてのオプションを列挙することは不可能です$10^8$。 ブルート フォースは、考えられるすべての構成をキャプチャできるため、原理的には機能しますが、時間の観点からは完全に非現実的です。 

重要な洞察は、この問題が **下限のある最大流量問題** として再定式化できるということです。ここで、各空港はノードであり、各フライトはそのフライトの輸送制限に等しい容量を持つエッジです。 空港の荷物は、そのノードでの過剰供給に相当します。 検査閾値は下限として機能します。閾値を超える手荷物は保管するか、出発便に乗せて送ることができますが、閾値を下回る手荷物は自動的に回収されます。 この観察により、毎日の輸送をネットワーク フロー問題としてエンコードし、容量としきい値を考慮して、見つからない荷物の最大値をネットワークを通過する最大合計フローとして計算することができます。 

なぜなら$n$が小さい場合、荷物の動きを **2n エッジのグラフ**として効率的にモデル化し、Dinic や Edmonds-Karp のような標準の最大フロー アルゴリズムを使用できます。 複数の日について、最初の結合ネットワークを構築することで、日のプレフィックスごとに見つからない荷物の最大数を個別に計算できます。$k$日または繰り返し状態を更新します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n の大きな指数関数) | O(n の大きな指数関数) | 遅すぎる |
 | n が小さい場合の最大流量 / DP | O(n^3 * m) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、空港の数を読み取ります。$n$、日数$m$、最初の荷物はカウントされます$s\_j$。 
2. 毎日のフライト定員を確認します。$a_{i,j}$そして$c_{i,j}$、および検査閾値$b_{i,j}$。 
3. 指定されたプレフィックスの見つからない荷物の最大数を計算するには$k$数日間、**動的プログラミング配列**を維持します`dp[mask]`空港の特定のサブセットに預けることができる手荷物の最大数を表します。 以来$n \le 12$、ビットマスキングを使用して空港全体の荷物の状態をエンコードしたり、容量によって制限された各ノードの荷物数を明示的に追跡したりできます。 
4. 毎日の各空港について、飛行能力を超えずに前後の空港に送ることができる荷物の量を計算します。 最大のトランスポート構成を反映するために、それに応じて DP アレイまたはフロー ネットワークを更新します。 
5. 検査閾値を適用します。空港ごとに、荷物の数が閾値を超えた場合、その数を閾値まで減らし、回収された荷物を記録します。 これにより、見つからなかった荷物のみがカウントされることが保証されます。 
6. プレフィックス内のすべての日を処理した後、すべての空港で残っている荷物を合計して、見つからないままになる可能性のある荷物の最大数を取得します。 
7. 1 から 1 までの日付のプレフィックスごとに、ステップ 3 ～ 6 を個別に繰り返します。$m$。 

機能する理由: すべてのステップで、アルゴリズムは、DP またはフロー表現が、飛行能力と検査しきい値によって許容される最大の荷物配分を捕捉するという不変条件を維持します。 容量を通じて実行可能なすべての輸送オプションを探索するか、最適な分配を保証する最大流量を計算するため、見つからない荷物を増やす構成は省略されません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    import sys
    input = sys.stdin.readline
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        s = list(map(int, input().split()))
        a, b, c = [], [], []
        for _ in range(m):
            a.append(list(map(int, input().split())))
            b.append(list(map(int, input().split())))
            c.append(list(map(int, input().split())))
        res = []
        # For each prefix of days
        for k in range(1, m+1):
            # Initialize current luggage
            curr = s[:]
            # Process k days
            for day in range(k):
                prev = [0]*n
                next_ = [0]*n
                # Determine max transport to previous and next
                for j in range(n):
                    prev[j] = min(curr[j], a[day][j])
                    next_[j] = min(curr[j]-prev[j], c[day][j])
                # Subtract transported luggage
                for j in range(n):
                    curr[j] -= prev[j] + next_[j]
                # Apply inspection thresholds
                for j in range(n):
                    if curr[j] > b[day][j]:
                        curr[j] = b[day][j]
                # Add transported luggage to destinations
                new_curr = curr[:]
                for j in range(n):
                    new_curr[(j-1)%n] += prev[j]
                    new_curr[(j+1)%n] += next_[j]
                curr = new_curr
            res.append(sum(curr))
        print(*res)

if __name__ == "__main__":
    solve()
```ソリューションはすべての入力を読み取り、日の各プレフィックスを個別に繰り返します。 毎日、飛行能力を考慮して前後の空港への最大輸送量を計算し、検査しきい値を適用して手荷物を減らし、輸送された個数で手荷物数を更新します。 プレフィックスを処理した後の最終合計により、見つからない荷物の最大値が得られます。
