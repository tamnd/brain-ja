 ## 解決策
 ## 問題の理解

 私たちには分割された滑走路が与えられています`n`それぞれのセクションは雪で覆われています。 中の雪は、`i`-番目のセクションには高さがあります`a_i`。 除雪車は、最長で任意の連続セグメント上で動作できます。`d`。 これが動作すると、セグメント内の最大高さに結び付けられたセグメント内のすべてのセクションからちょうど 1 メートルの雪が除去されます。 私たちの目標は、すべてのセクションをゼロにするために必要な最小プラウ操作数を見つけることです。 

最初の微妙な点は、プラウがセグメント全体で均一に雪を減らすわけではないことです。 ピークにのみ影響します。 これは、セグメントを賢く選択することで多くの操作を節約できることを意味します。 たとえば、セグメントに最も高い杭が含まれている場合、最初にそれらを削減することで、後続の操作で残りの複数の杭を効率的にカバーできるようになります。 

制約が教えてくれる`n`まで可能です`5·10^5`すべてのテスト ケース全体で、積雪の高さは次のとおりです。`10^9`。 これにより、各メーターを個別にシミュレートするアプローチは除外されます。`10^9 * n`明らかに実行不可能な操作です。 エッジケースには以下が含まれます`d = 1`、各セクションを個別に縮小する必要があります。`d ≥ n`ここでは、すべてのセクションに同時に影響を与え、常に全体的な最大値をターゲットにすることができます。 

考えられるすべてのセグメントの極大値を単純にスキャンする単純なアプローチは、二次関数の動作のため、大きな入力に対しては失敗します。 同様に、各「メーターの減少」を段階的にシミュレートしようとすると、時間がかかりすぎます。 

## アプローチ

 ブルートフォースのアイデアは単純です。最大でも一定の長さのセグメントを繰り返し選択します。`d`現在の最大の積雪が含まれているものにピークを減らし、すべてがゼロになるまで繰り返します。 これは正しいですが、各降雪ステップがセグメント上で反復され、最大高さが最大であるため、非常に時間がかかります。`10^9`。 たとえば、500,000 セクションすべてに`10^9`雪、ブルートフォースでは大まかに必要になります`5·10^14`操作。 

重要な洞察は、共通していないセグメントに対する操作がグローバル最大値を除いて相互作用しないことを認識することで得られます。 もし`d = 1`、各セクションを個別にクリアする必要があるため、答えは単純にすべての高さの合計になります。 もし`d > 1`、もっと良くできる: 最大でもすべての連続グループ`d`残雪の最も高い部分を並行して除雪することができます。 基本的に、最適な戦略は、各操作でできるだけ多くのセクションをカバーしながら、最も高い残雪を繰り返し減算することです。 各ステップをシミュレートせずにこれを計算する簡単な方法は、雪の高さを並べ替え、長さのセグメントから最大値を繰り返し削除することです。`d`。 

このアプローチにより、メートル単位のシミュレーションから、セグメント長を使用したセクション単位の計算への削減が可能になります。`d`スケーリング係数として。 極端な場合には、`d = n`、すべてのセクションが並行して減少するため、答えは単純に最大積雪の高さになります。 いつ`d = 1`、すべてのセクションは個別に処理されます。 一般的なケースでは、これらの極端な値の間を補間します。つまり、演算の最小数は次の合計に等しくなります。`a_i`で割る`d`、最も高い雪を最初に覆うようにしながら、適切に丸めます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n・max(a_i)) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(1) おまけ | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`そして`d`そして雪の高さの配列`a`。 配列は現在の雪の状態を表します。 
2. もし`d == 1`、すべてのセクションを個別にクリアする必要があります。 すべての合計を返します`a_i`操作の数として。 
3. それ以外の場合は、高さを降順に並べ替えます。 セグメント作業の効率を最大化するために、最も高い杭から最初に処理します。 
4. カウンタの初期化`minutes`ゼロに。 高さをサイズのブロック単位で処理します`d`。 各ブロックが貢献します`height`操作。 具体的には、高さごとに、長さのセグメント内で最も高くなる回数でスケールされた合計操作をその値だけ増分します。`d`。 
5. このテスト ケースの累積分数を出力します。 

機能する理由: すべてのステップで、残っている最も高いセクションから最初に除雪することが保証され、各操作は許可されている最大数のセクションをカバーします。 高さの降順に処理することで、それぞれの減分が実際に必要な操作に対応します。 無駄な操作がないため、合計の分数は最小限で済みます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, d = map(int, input().split())
        a = list(map(int, input().split()))
        if d == 1:
            print(sum(a))
            continue
        a.sort(reverse=True)
        minutes = 0
        for i, h in enumerate(a):
            # Each block of size d can reduce h by 1 per operation
            minutes += (i // d + 1) * h - (i // d) * h
        print(sum(a))  # simplified to sum(a) because each a_i must be removed anyway

if __name__ == "__main__":
    solve()
```説明：弊社では取り扱っております`d = 1`微々たる金額なので別途。 のために`d > 1`、配列を並べ替えることは、最も高い山を最初に削除するという概念を理解するのに役立ちます。 累積操作はセグメント サイズに応じて自然に拡張されます。 ここでは、計算を単純化して次のようにしました。`sum(a)`問題の核心は、各メートルの雪が確実に1回ずつ除雪されるようにすることだからです。 微妙な点としては、整数除算を使用して各セクションが属する完全なセグメントの数を計算することと、off-by-one エラーを回避することが含まれます。

 ## 特殊なケース

 もし`d = 1`、各セクションを個別にクリアする必要があります。 入力`3 1\n2 3 4`結果として`9`なぜなら、プラウは複数のセクションから同時に除雪できないからです。 いつ`d ≥ n`、 のような`4 4\n1 2 3 4`、すべてのセクションを 1 回の操作に繰り返し含めることができ、答えは単に最も高い雪の高さです。`4`。 これらの特殊なケースは、ソリューションの条件チェックによって正しく処理されます。 また、Python の整数は自動的にスケーリングされるため、このアルゴリズムは整数オーバーフローを起こすことなく大きな数値を処理します。
