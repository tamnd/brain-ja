 ## 解決策
 ## 問題の理解

 このタスクは、奇数のインデックスを持つセルのみがわかっている長方形グリッド上に単純なパスを再構築することです。 具体的には、パスは「既知」セルと「未知」セルを交互に繰り返し、既知のセルで始まり既知のセルで終わります。 フルパス内の連続する各セルのペアは、水平または垂直に隣接している必要があります。 課題は、パスが単純なままで隣接制約を満たすように、未知のセルを挿入する可能なすべての方法を数えることです。 

入力は複数のテスト ケースを提供します。 各テスト ケースでは、グリッドの寸法、既知のセル間のステップ数 (次のようにエンコード) を指定します。$k$)、およびその座標$k+1$既知の細胞。 出力は、パスのモジュロの有効な完了数です。$10^9 + 7$。 

制約により、すべてのテスト ケースにわたるセルの合計数が最大で次のようになります。$10^6$、これにより線形の解が可能になります。$n \cdot m$テストケースごとに。 However, a brute-force attempt to enumerate all possible paths would be exponential in$k$これはセルの総数の最大約半分になる可能性があるため、単純な DFS や BFS は実行不可能になります。 

エッジ ケースは、2 つの連続する既知のセルが 1 つの中間セルで接続できないほど離れている場合に発生します。 たとえば、既知のセルが 2×4 グリッド上の (1,1) と (1,4) である場合、両方に隣接する中間セルは存在しないため、有効なパスの数は 0 になります。 もう 1 つの微妙なケースがグリッド境界で発生します。この場合、唯一の利用可能な隣接セルが以前の既知のセルによってブロックされ、未知のセルの選択肢の数が制限される可能性があります。 

## アプローチ

 ブルートフォース手法では、既知のセルの各ペアの間に考えられるすべての中間セルを生成し、隣接性をチェックしようとします。 既知のセルのペアごとに、未知のセルの隣接候補セルが最大 4 つ存在するため、次のようになります。$4^k$最悪の場合の可能性も。 これは非常に小さなグリッドでのみ実現可能ですが、次のことを考えると完全に非現実的です。$k$すべてのテスト ケース全体で最大 500,000 件まで可能です。 

重要な洞察は、既知のエンドポイントが固定されると、パスの未知のセルが他のすべての未知のセルから独立しているということです。 2 つの連続する既知のセルの間$p_{2i-1}$そして$p_{2i+1}$、未知の細胞$p_{2i}$両方のエンドポイントに隣接する必要があります。 これにより、既知のセルの連続する各ペア間で共有される隣接セルの数をカウントするという問題が軽減されます。 ペアに共有隣接要素がない場合、パスは存在しません。 それ以外の場合、完了数は、すべての連続するペアの共有隣接数の積になります。 この観察により、指数関数的問題が線形問題に変換されます。$k$なぜなら、連続するペアごとに隣接セットの交差を計算するだけでよいからです。

 | --- | --- | --- | --- |
 | ブルートフォース | O(4^k) | O(k) | 遅すぎる |
 | 最適 | テスト ケースごとの O(k) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 テスト ケースごとに、次の内容を読んでください。$n$、$m$、 そして$k$の座標が続きます。$k+1$既知の細胞。 必要に応じて、0 から始まるインデックスに変換します。 
2. 変数を初期化する`ans = 1`。 これにより、有効な完了の数が保存されます。 
3. 既知のセルの連続する各ペアを反復処理します。$p_{2i-1}$そして$p_{2i+1}$。 
4. 近傍をすべて計算します。$p_{2i-1}$グリッド境界内。 同様に、次のすべての近傍を計算します。$p_{2i+1}$。 
5. これら 2 つの近傍セットの交差を数えます。 この数は、中間セルの有効な選択肢の数を表します。$p_{2i}$。 
6. いずれかのペアのカウントがゼロの場合は、すぐに設定します。`ans = 0`そして休憩する。 それ以外の場合は乗算します`ans`このカウントモジュロによって$10^9+7$。 
7. 連続するすべてのペアを処理した後、印刷します。`ans`現在のテストケースの場合。 

機能する理由: 不変条件は、既知のセルの連続するペアごとに、すべての有効な中間セルを正しく計算することです。 カウントを乗算すると、パスに沿ったすべての独立した選択が考慮されます。 パスは単純でなければならないため、各中間セルは既知のセルと一致しないことが保証され、隣接性と単純性の制約が満たされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        known = [tuple(map(int, input().split())) for _ in range(k+1)]
        ans = 1
        for i in range(k):
            x1, y1 = known[i]
            x2, y2 = known[i+1]
            neighbors1 = set()
            neighbors2 = set()
            for dx, dy in [(-1,0),(1,0),(0,-1),(0,1)]:
                nx1, ny1 = x1+dx, y1+dy
                if 1 <= nx1 <= n and 1 <= ny1 <= m:
                    neighbors1.add((nx1, ny1))
                nx2, ny2 = x2+dx, y2+dy
                if 1 <= nx2 <= n and 1 <= ny2 <= m:
                    neighbors2.add((nx2, ny2))
            common = neighbors1 & neighbors2
            cnt = len(common)
            if cnt == 0:
                ans = 0
                break
            ans = (ans * cnt) % MOD
        print(ans)

if __name__ == "__main__":
    solve()
```各セクションはアルゴリズムのステップに正確に従います。 最初にすべての入力を読み取ると、計算を順番に進めることができます。 セットを使用すると、有効な近傍のみが考慮され、重複によってカウントが膨らまなくなります。 オーバーフローを避けるために、各乗算の後にモジュロ演算が適用されます。 境界条件は、近傍を生成するときに明示的に処理されます。
