 ## 解決策
 ## 問題の理解

 固定回数のランダムスワップを実行した後、0 と 1 で構成される配列が非降順でソートされる確率を決定するように求められます。 各スワップは、配列内の 2 つの異なる位置を均一にランダムに選択し、それらの値を交換します。 配列の長さは最大でも 100 ですが、スワップの数は 10^9 まで大きくなる可能性があるため、ステップごとのスワップのシミュレーションは即座に除外されます。 出力は、モジュラー演算のゼロまたは分数である必要があります。 

入力により、配列自体とスワップ数が得られます。 出力は、10^9+7 を法とする確率です。 配列には 0 と 1 のみが含まれるため、最終的にソートされた配列は単純にすべて 0 の後にすべて 1 が続きます。 不注意な解決策では、スワップを直接シミュレートしようとする可能性があります。 たとえば、次の場合`a = [0, 1, 0]`そして`k = 2`、単純な方法で各スワップをシミュレートすると、複数のスワップ シーケンスが最終的に同じ配列になるという事実を見落とす可能性があります。 正しいアプローチでは、並べ替えられた状態に到達する組み合わせの確率を考慮する必要があります。 

エッジケースには、すでにソートされている配列、完全に反転された配列、またはすべての要素が同じである配列が含まれます。 たとえば、次の場合`a = [0, 0, 0]`の場合、ソートされた確率は自明のことですが 1 です。`a = [1, 1, 1]`、同様です。 もし`a = [1, 0, 1]`そして`k = 1`、一部のスワップではソートされた配列が生成されない可能性があるため、ゼロ確率を正しく計算する必要があります。 

## アプローチ

 ブルートフォースアプローチは、考えられるすべてのスワップシーケンスを列挙することです。 各スワップはインデックスのペアを選択します`(i, j)`の間で`n*(n-1)/2`可能性。 後`k`スワップ、あります`(n*(n-1)/2)^k`シーケンス。 のために`n = 100`そして`k`10^9 までは、これはまったく実現不可能です。 配列構成に対して動的プログラミングを使用しても大きすぎます。`2^n`可能な配列、および`n=100`作る`2^100`天文学的に大きい。 

重要な洞察は、配列に 0 と 1 だけが含まれているという観察から得られます。 させて`cnt1`1 の合計数になります。 どの構成も、配列の「間違った半分」にある 1 の数によって完全に決まります。 より正確に定義すると、`state[i]`正確に存在する確率として`i`最初のもの`n - cnt1`ポジション。 これにより、状態空間が次のように減少します。`2^n`に`min(cnt1, n-cnt1) + 1`州は最大でも 50 です。 

このプロセスは、最初のセグメントの 1 と 2 番目のセグメントの 0 の交換に基づいて、各状態が確率的に遷移するマルコフ連鎖としてモデル化できます。 させて`trans[i][i-1]`、`trans[i][i]`、 そして`trans[i][i+1]`は状態間を移動する確率を示します。 次に、遷移行列を次のように引き上げることができます。`k`最終的な確率を計算するための - 乗。 50x50 行列の行列累乗は効率的であり、`k`最大 10^9。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O((n^2)^k) | O(2^n) | 遅すぎる |
 | 最適マルコフ / 行列累乗 | O(n^3 log k) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. コンピューティング`cnt1`、配列内の 1 の合計数。 ゼロの数は`cnt0 = n - cnt1`。 ソートされたターゲットには、すべて 0 の後にすべて 1 が続きます。 
2. コンピューティング`wrong`、「ゼロセグメント」にある最初の 1 の数 (最初のセグメント)`cnt0`ポジション）。 これがマルコフ連鎖の開始状態です。 
3. 遷移行列を構築する`T`サイズの`cnt1+1`による`cnt1+1`。`T[i][i-1]`ゼロセグメント内の 1 の数が 1 減少する確率です。`T[i][i]`同じままである確率、そして`T[i][i+1]`1 増加する確率。これらの確率は、最初のセグメントの 1 と 2 番目のセグメントの 0 の間のスワップをカウントし、合計スワップで正規化することによって導出されます。`C(n, 2)`。 
4. 高速行列累乗を実行します。`T`に`k`-乗。 これにより、次の状態分布が計算されます。`k`交換します。 
5. 初期状態ベクトルを乗算します。`v`(インデックスに 1 が付きます)`wrong`） による`T^k`。 配列がソートされる最終的な確率は、ゼロ セグメント (状態 0) の 0 の 1 に対応する値です。 
6. 確率を剰余分数として返します`P * Q^{-1} mod 10^9+7`。 

機能する理由: ゼロセグメント内の 1 の数はシステムを記述するのに十分であるため、このプロセスではマルコフ特性が保存されます。 行列のべき乗は効率的に遷移を適用します`k`すべてのスワップ後の各状態の正確な確率を示します。 ソートされた確率は、誤って配置されたものがゼロの状態に正確に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9+7

def modinv(x):
    return pow(x, MOD-2, MOD)

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    cnt1 = sum(a)
    cnt0 = n - cnt1
    wrong = sum(a[:cnt0])
    
    if wrong == 0:
        print(1)
        return

    size = cnt1 + 1
    total_pairs = n*(n-1)//2 % MOD

    T = [[0]*size for _ in range(size)]
    for i in range(size):
        if i > 0:
            T[i][i-1] = i * (cnt0 - (i-1)) % MOD * modinv(total_pairs) % MOD
        if i < cnt1:
            T[i][i+1] = (cnt1 - i) * (cnt0 - i) % MOD * modinv(total_pairs) % MOD
        same = (total_pairs - (T[i][i-1]*total_pairs if i>0 else 0) - (T[i][i+1]*total_pairs if i<cnt1 else 0)) % MOD
        T[i][i] = same * modinv(total_pairs) % MOD

    def matmul(A, B):
        n = len(A)
        C = [[0]*n for _ in range(n)]
        for i in range(n):
            for j in range(n):
                for k in range(n):
                    C[i][j] = (C[i][j] + A[i][k]*B[k][j]) % MOD
        return C

    def matexp(M, p):
        n = len(M)
        res = [[int(i==j) for j in range(n)] for i in range(n)]
        while p:
            if p & 1:
                res = matmul(res, M)
            M = matmul(M, M)
            p >>= 1
        return res

    T_k = matexp(T, k)
    ans = T_k[wrong][0] % MOD
    print(ans)

solve()
```このソリューションでは、まずゼロ セグメント内の 1 の数を計算します。 これは、各エントリがスワップ後のある数の間違って配置されたものから別の数への移動に対応するマルコフ遷移行列を構築します。 行列の乗算はオーバーフローを避けるためにモジュール化されており、行列のべき乗は次への移行を引き起こします。`k`-乗。 最後に、誤配置がゼロである確率が 10^9+7 を法として出力されます。
