 ## 解決策
 ## 問題の理解

 平面内の直線道路セグメントのコレクションが与えられます。 各道路は、実際のジオメトリを備えた単なる線分です。つまり、2D の 2 つの端点であり、セグメントはそれらの間のアスファルトです。 

これらのセグメントから正確に 3 つを選択する必要があります。 その後、市は選ばれた 3 つの道路から 1 つを選択し、それを撤去し、同じアスファルトを使用して別の場所に新しい道路を再建することが許可されます。 唯一の制限は、新しい道路が削除された道路よりも長くてはいけないということです。 長さの制約が満たされる限り、その端点は平面内のどこにでも配置できます。 

この操作の後、再び正確に 3 つのセグメントが作成されます。2 つは元のセグメント (変更されていない)、もう 1 つは再配置された可能性のあるセグメントです。 これら 3 つは、幾何学的意味で接続された構造を形成する必要があります。アスファルトを利用可能な移動空間として扱う場合、アスファルトで覆われた 2 つの点は、3 つのセグメントの結合を通じて相互に到達可能でなければなりません。 

課題は、元の道路を何 3 倍にするとこれが達成できるかを数えることです。 

制約は小さく、最大でも 100 セグメントです。 これは、3 次の列挙、またはトリプルのわずかに悪い列挙は許容されるが、大きなグラフ インスタンスを解決しようとしたり、クエリごとに大量の前処理を実行しようとしたりするものは不要であることをすぐに示唆しています。 

微妙な特殊なケースは、ここでの接続は幾何学的であり、共有エンドポイントを介した組み合わせではないことです。 2 つのセグメントは、端点を共有する場合だけでなく、どこかで交差する場合にも接続されています。 2 番目の微妙な点は再配置ステップです。移動されたセグメントは既存の道路の端点に結び付けられていないため、平面内のどこにでも配置できます。つまり、長さが十分であれば、切断された 2 つのコンポーネント間のブリッジとして機能できます。 

よくある間違いを明らかにする小さな例は、3 つのセグメントがすべてばらばらで遠く離れているのに、1 つのセグメントが非常に長い場合です。 素朴な「交差によってすでに接続されている必要がある」というアプローチはこれを拒否しますが、長いセグメントを再配置して他の 2 つを接続できるため、それでも有効な可能性があります。 

## アプローチ

 簡単なアイデアは、セグメントのすべてのトリプルを試し、必要に応じて 1 つのセグメントを移動した後に接続できるかどうかをテストすることです。 

固定トリプルの場合、どのセグメントを移動するかの選択肢は 3 つだけです。 可動セグメントを選択すると、他の 2 つのセグメントは固定されたままになります。 これら 2 つのセグメントは、すでに接続された幾何学的構造を形成しているか、2 つの別個のコンポーネントを形成しています。 

残りの 2 つのセグメントがすでに接続されている (交差または接触している) 場合、移動されたセグメントは接続には関係ありません。 接続を切断することなくいつでもどこにでも配置できるため、トリプルは有効です。 

残りの 2 つのセグメントが切断されている場合は、移動されたセグメントでそれらをブリッジする必要があります。 任意に配置できるため、唯一の要件は、その長さが 2 つのセグメント間の最小距離以上であることです。 この距離は、一方のセグメント上の任意の点ともう一方のセグメント上の任意の点の間の最短ユークリッド距離です。 

したがって、核となる削減点は、ペアごとのセグメント距離のみが必要になるということです。 これらが分かれば、すべてのトリプルを一定時間でチェックできます。 

ブルート フォース アプローチでは、すべてのトリプルを列挙し、各トリプルについて接続状態と距離をテストします。 最大 100 セグメントの場合、これは約 161700 トリプルで問題なく、各チェックは O(1) であるため、完全なソリューションは問題なく適合します。 

重要な観察は、幾何学的な柔軟性が、セグメントごとの単一のスカラー、長さの制約、およびセグメント間のペアごとのスカラー、つまり最小距離によって完全に捉えられることです。 それ以上に複雑なことは必要ありません。

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 事前計算なしでブルート フォース トリプルを実行 | O(m^3 · m^2 幾何学) | お(1) | 遅すぎる |
 | ペアの距離を事前計算 + トリプルをチェック | O(m^3) | O(m^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 1. 幾何プリミティブを事前計算する

 セグメントのペアごとに、それらが交差するかどうかを計算します。 それらが交差する場合、それらの距離はゼロになります。 それ以外の場合は、投影と端点からセグメントまでの距離を使用して 2 つの線分間の最小距離を計算します。 

このステップが必要なのは、後続のすべての推論により、接続とブリッジ条件が定数時間のクエリに限定されるためです。 

### 2. セグメント長を格納する

 各セグメントについて、そのユークリッド長を計算します。 これにより、切断された 2 つの部品間の可動ブリッジとして機能できるかどうかが決まります。 

### 3. セグメントのすべてのトリプルを反復処理します。 

3 つのセグメントを選択するたびに、最終的な構造が接続されるように移動される 1 つのセグメントの有効な割り当てが存在するかどうかをテストします。 

### 4. 各セグメントを可動セグメントとして試します

 トリプル (a、b、c) については、a が移動される、b が移動される、または c が移動されるという 3 つの可能性を考慮します。 

### 5. 残りのペアの接続を確認します。 

2 つの固定セグメントが交差する場合、それらはすでに連結コンポーネントを形成しています。 この場合、移動されたセグメントに関係なく、トリプルはすぐに有効になります。 

交差しない場合は、距離を計算します。 この距離は、移動されたセグメントを接続するために必要な最小長さを表します。 

### 6. 移動されたセグメントがブリッジとして検証される

 選択した移動セグメントの長さが少なくともこの距離であれば、2 つのコンポーネントを接続するように配置でき、構造全体が接続されます。 そうでない場合、この選択は失敗します。 

### 7. 有効なトリプルを数える

 可動セグメントの 3 つの選択肢のいずれかが成功すると、トリプルが答えに貢献します。 

### なぜ効果があるのか

 どのセグメントを移動するかを決定した後、残りの 2 つのセグメントは 1 つの接続されたコンポーネントまたは 2 つの非接続コンポーネントのいずれかを定義します。 移動されたセグメントは配置に制限がないため、固定長の自由なブリッジのように動作します。 接続に関する唯一の幾何学的制約は、残りの 2 つのコンポーネント間のギャップをまたぐことができるかどうかです。 この時点ではコンポーネントは 2 つだけであり、それらを接続するには 1 つのブリッジで十分であるため、これ以上複雑な構造は必要ありません。 これにより、セグメント間のペアごとの距離が正確さのために必要かつ十分になります。

import sys
input = sys.stdin.readline
import math

EPS = 1e-9

def dot(ax, ay, bx, by):
    return ax * bx + ay * by

def dist2(ax, ay, bx, by):
    dx = ax - bx
    dy = ay - by
    return dx * dx + dy * dy

def seg_point_dist(px, py, ax, ay, bx, by):
    abx = bx - ax
    aby = by - ay
    apx = px - ax
    apy = py - ay
    ab2 = abx * abx + aby * aby
    if ab2 == 0:
        return math.hypot(px - ax, py - ay)
    t = (apx * abx + apy * aby) / ab2
    t = max(0.0, min(1.0, t))
    cx = ax + t * abx
    cy = ay + t * aby
    return math.hypot(px - cx, py - cy)

def seg_seg_dist(a, b):
    ax1, ay1, ax2, ay2 = a
    bx1, by1, bx2, by2 = b

    # endpoint to segment
    d1 = seg_point_dist(ax1, ay1, bx1, by1, bx2, by2)
    d2 = seg_point_dist(ax2, ay2, bx1, by1, bx2, by2)
    d3 = seg_point_dist(bx1, by1, ax1, ay1, ax2, ay2)
    d4 = seg_point_dist(bx2, by2, ax1, ay1, ax2, ay2)

    return min(d1, d2, d3, d4)

def intersect(a, b):
    ax1, ay1, ax2, ay2 = a
    bx1, by1, bx2, by2 = b

    def orient(x1, y1, x2, y2, x3, y3):
        return (x2 - x1) * (y3 - y1) - (y2 - y1) * (x3 - x1)

    def on_seg(x1, y1, x2, y2, x3, y3):
        return min(x1, x2) - EPS <= x3 <= max(x1, x2) + EPS and \
               min(y1, y2) - EPS <= y3 <= max(y1, y2) + EPS

    o1 = orient(ax1, ay1, ax2, ay2, bx1, by1)
    o2 = orient(ax1, ay1, ax2, ay2, bx2, by2)
    o3 = orient(bx1, by1, bx2, by2, ax1, ay1)
    o4 = orient(bx1, by1, bx2, by2, ax2, ay2)

    if o1 * o2 < 0 and o3 * o4 < 0:
        return True

    if abs(o1) < EPS and on_seg(ax1, ay1, ax2, ay2, bx1, by1):
        return True
    if abs(o2) < EPS and on_seg(ax1, ay1, ax2, ay2, bx2, by2):
        return True
    if abs(o3) < EPS and on_seg(bx1, by1, bx2, by2, ax1, ay1):
        return True
    if abs(o4) < EPS and on_seg(bx1, by1, bx2, by2, ax2, ay2):
        return True

    return False

def length(a):
    x1, y1, x2, y2 = a
    return math.hypot(x1 - x2, y1 - y2)

def main():
    m = int(input())
    segs = [tuple(map(int, input().split())) for _ in range(m)]

    dist = [[0.0] * m for _ in range(m)]
    inter = [[False] * m for _ in range(m)]
    L = [length(s) for s in segs]

    for i in range(m):
        for j in range(m):
            if i == j:
                continue
            inter[i][j] = intersect(segs[i], segs[j])
            if inter[i][j]:
                dist[i][j] = 0.0
            else:
                dist[i][j] = seg_seg_dist(segs[i], segs[j])

    ans = 0

    for i in range(m):
        for j in range(i + 1, m):
            for k in range(j + 1, m):
                ok = False
                a, b, c = i, j, k

                for x, y in [(a, b, c), (b, a, c), (c, a, b)]:
                    if inter[y][z] if False else False:
                        pass

                for x, y, z in [(a, b, c), (b, a, c), (c, a, b)]:
                    if inter[y][z]:
                        ok = True
                    else:
                        if L[x] + 1e-9 >= dist[y][z]:
                            ok = True

                if ok:
                    ans += 1

    print(ans)

```この実装では、まずセグメントのペア間のすべての幾何学的関係を構築し、交差情報と最小距離の両方を保存します。 次に、可動セグメントの 3 つの可能な選択肢をそれぞれ試して、各トリプルが評価されます。 残りのペアが既に交差によって接続されている場合、トリプルは直ちに受け入れられます。 それ以外の場合、コードは可動セグメントがそれらの間のギャップを埋めるのに十分な長さであるかどうかをチェックします。 

微妙な点は浮動小数点の許容誤差です。 セグメント距離と交差テストは幾何学的述語に依存するため、精度誤差による有効な接触構成の拒否を避けるために小さなイプシロンが使用されます。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、2 つのセグメントが 1 点でのみ接触する場合です。 この状況では、それらはすでに接続されており、移動されたセグメントがそれらをブリッジする必要はありません。 交差述語は、同一線上の重なりと端点の接触を接続されたものとして明示的に扱い、これにより距離がゼロとして扱われることが保証されます。 

もう 1 つの特殊なケースは、3 つのセグメントがすべて互いに素である場合です。 ここで接続性を満たす唯一の方法は、1 つのセグメントをブリッジとして完全に依存することです。 アルゴリズムは 3 つの選択肢すべてを正確にチェックし、どれが可動として選択されたかに関係なく、十分に長いセグメントが使用できることを保証します。 

最後の微妙なケースは、セグメントがほぼ接触している場合の浮動小数点精度です。 交差と距離の比較の両方で小さなイプシロンを使用すると、境界線の構成が切断されていると誤って分類されなくなります。
