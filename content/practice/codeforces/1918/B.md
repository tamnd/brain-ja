 ## 解決策
 ## 問題の理解

 2 つの順列が与えられています`a`そして`b`同じ長さの。 許可される操作は異常です: 位置を交換するときは常に`i`そして`j`、両方の配列で同じスワップを同時に実行する必要があります。 

つまり、私たちは決して離れることはできないのです`a[k]`から`b[k]`。 すべての位置はペアになったオブジェクトのように動作します`(a[k], b[k])`。 許可されている唯一のことは、これらのペアを並べ替えることです。 

ペアを並べ替えると、新しい順列が得られます`a'`そして`b'`。 私たちの目標は合計を作ることです`inversions(a') + inversions(b')`できるだけ小さいもの。 

重要な点は、この操作ではどのペアも変更されないことです。 ペアが表示される順序が変更されるだけです。 

制約は大きいです。 すべての合計`n`すべてのテストケース全体で最大でも`2·10^5`、そのための解決策`O(n log n)`テストケースごとの速度は簡単に十分に速くなります。 二次アルゴリズムでは、大まかに次のものが必要になります。`4·10^10`最悪の場合の操作は完全に不可能です。 

微妙な点は、1 つの順列における反転を独立して最小化しようとしているわけではないということです。 並べ替えは両方の配列に同時に影響します。 

考慮する：```
a = [1, 2]
b = [2, 1]
```ペアは次のとおりです。```
(1,2), (2,1)
```この順番を守れば、`a`もっている`0`反転と`b`もっている`1`。 

順番を逆にすると、`a`もっている`1`反転と`b`もっている`0`。 

どちらにしても合計は`1`。 1 つの順列だけを並べ替えようと貪欲に試みると、本当の目的を逃してしまいます。 

もう 1 つの簡単な間違いは、両方の配列を自由にソートできると考えることです。 例えば：```
a = [1, 2]
b = [2, 1]
```ペア自体は固定されているため、両方の配列を同時にソートする方法はありません。 ペアを並べ替えても変換できません`(1,2)`そして`(2,1)`の中へ`(1,1)`そして`(2,2)`。 

## アプローチ

 ブルートフォースソリューションでは、すべてのポジションがペアとして表示されます。`(a[i], b[i])`これらのペアの可能な順序をすべて試してください。 あるので`n!`順列の場合、これは中程度の値であっても不可能になります。`n`。 

何を最適化する必要があるかを理解するには、次の 2 つのペアを考慮してください。```
(x1, y1)
(x2, y2)
```これら 2 つのペアがこの順序で出現するとします。 

総反転数への寄与は、2 つの位置間の比較からのみ得られます。 

可能性は 4 つあります。 

もし`x1 < x2`、それらは反転を引き起こしません`a`。 

もし`x1 > x2`、それらは 1 つの反転を作成します。`a`。 

同様に、`y1`そして`y2`で`b`。 

したがって、このペアの位置の寄与は次のようになります。```
[x1 > x2] + [y1 > y2]
```ここで、2 つのペアの順序を入れ替えるとします。 貢献度は次のようになります。```
[x2 > x1] + [y2 > y1]
```2 つのペアの相対的な順序を考慮してください。 

両方の座標が一致する場合:```
x1 < x2 and y1 < y2
```次に、ペア 2 が寄与する前にペア 1 を配置します。`0`、それらを逆転させると貢献します`2`。 

明らかに、ペア 1 が最初に来る必要があります。 

両方の座標が一致しない場合:```
x1 < x2 and y1 > y2
```その場合、どのペアが最初に来るかに関係なく、1 つの反転が表示されます。 

貢献はいつも`1`。 

これは重要な観察です。 

オブジェクトのすべてのペアについて:```
(a[i], b[i])
(a[j], b[j])
```2つのケースしかありません。 

それらの順序が両方の座標で一致する場合、一方の相対的な配置が他方の配置よりも厳密に優れています。 

それらの順序が一致しない場合、両方の取り決めはまったく同じ寄与を与えます。 

したがって、座標が一致するすべてのペアには優先順位が課されます。```
a[i] < a[j] and b[i] < b[j]
```ペアを意味します`i`ペアの前に表示する必要があります`j`。 

なぜなら`a`そして`b`順列であるため、これらの設定は循環を形成できません。 これらは半順序を定義します。 

この半順序の自然な線形拡張は、すべてのペアを次の順序でソートすることによって得られます。`a`。 

で並べ替えた後、`a`、 いつでも```
a[i] < a[j]
```小さい方のペアが成立します。`a`のほうが早いです。 

ペアの場合`b`値も同じ方法で順序付けされるため、より良い貢献が得られます`0`。 

ペアの場合`b`値は逆に並べられ、寄与は次のように固定されます。`1`とにかく、その相対的な位置は重要ではありません。 

したがって、次のように並べ替えます`a`可能な最小の総反転数を達成します。

 ## アルゴリズムのチュートリアル

 1. ペアのリストを作成する`(a[i], b[i])`。 
2. 最初の座標でペアを並べ替えます`a[i]`。 

以来`a`は順列であり、最初の座標はすべて異なるため、順序は一意に決まります。 
3. ソート後、配列を再構築します。 

ソートされたペアの最初の座標が新しい順列になります。`a'`。 

2 番目の座標が新しい順列になります`b'`。 
4. 再構成された配列を出力します。 

### なぜ効果があるのか

 任意の 2 ペアを用意します。 

彼らの注文が入った場合、`a`そして`b`同意する、1 つの相対的な配置が寄与する`0`反転と反対の配置が貢献します`2`。 最適なソリューションでは、それらを優先順序で配置する必要があります。 

並べ替え順`a`そうした好ましい関係をすべて尊重します。 

彼らの注文が入った場合、`a`そして`b`同意しませんが、考えられる両方の配置が正確に寄与します`1`, したがって、どの選択肢も答えを改善または悪化させることはできません。 

したがって、オブジェクトの各ペアは、達成可能な最小量に寄与します。 総反転数はすべての順序付けされていないペアの合計であるため、結果として得られる配置は全体的に最適です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    out = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        pairs = list(zip(a, b))
        pairs.sort()  # sort by a

        out.append(" ".join(str(x) for x, _ in pairs))
        out.append(" ".join(str(y) for _, y in pairs))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```実装は証明の後に直接続きます。 

重要なモデリング手順は、各位置を固定ペアとして扱うことです。 この操作では常に両方の配列が同時に交換されるため、ペアが分離されることはありません。 

Python はタプルを辞書順に比較するため、ペアのリストを並べ替えると、最初の座標によって自動的に並べ替えられます。 以来`a`は順列であり、最初の座標はすべて異なるため、タイの処理について心配する必要はありません。 

ソート後、ペアを 2 つの配列に解凍して出力するだけです。 

反転カウントは必要ありません。 この証明は、ソート順序がすでに最適であることを示しています。

 ## 特殊なケース

 可能な最小の入力を考えてみましょう。```
1
1
1
1
```1ペアしかありません`(1,1)`。 並べ替えても変更されないままになります。 両方の反転カウントはゼロです。 このアルゴリズムは、比較がない場合でも正しく処理します。 

まったく逆の順序を考えてみましょう。```
a = [1,2,3]
b = [3,2,1]
```ペアは次のとおりです。```
(1,3), (2,2), (3,1)
```並べ替え順`a`何も変わりません。 順序付けされていないすべてのペアは 2 つの座標間で一致しないため、各ペアは配置に関係なく 1 つの反転に寄与します。 これより優れた配置は他にないため、アルゴリズムは最適化を実現します。 

同一の順列を考えてみましょう。```
a = [3,1,2]
b = [3,1,2]
```すべてのペアの比較は両方の座標で一致します。 並べ替え順`a`生成されるもの:```
a' = [1,2,3]
b' = [1,2,3]
```すべての反転が消えます。 これは、すべての優先順序が同時に満たされる場合を示しています。 

混合例を考えてみましょう。```
a = [2,1,3]
b = [1,3,2]
```ペア:```
(2,1), (1,3), (3,2)
```で並べ替えた後、`a`:```
(1,3), (2,1), (3,2)
```与える```
a' = [1,2,3]
b' = [3,1,2]
```座標順序が一致するペアは最適に配置されますが、一致しないペアは何があっても一定量を寄与します。 これはまさに正しさの証明で使用される構造です。
