 ## 解決策
 ## 問題の理解

 この問題では、2 つの数値をそれぞれ 1 つの数値と XOR 演算した後、その絶対差を最小化するように求められます。$x$私たちが選択することが許されているということ。 形式的には、整数の場合$a$、$b$、および上限$r$の最小値を見つける必要があります。$|(a \oplus x) - (b \oplus x)|$どこ$0 \le x \le r$。 XOR 演算は、対応するビットが反転するビットを反転します。$x$は 1. までこれを行うように求められます。$10^4$テストケース、$a$、$b$、 そして$r$と同じくらい大きい$10^{18}$。 

入力は非常に大きくなる可能性があるため、可能なすべてを反復処理する必要があります。$x$不可能です。 0 から 0 までのすべての整数をチェックする総当り的なアプローチ$r$まで必要になります$10^{18}$実行可能性をはるかに超えた操作です。 XOR のプロパティを使用して、徹底的な検索を行わずに最小の差を計算するメソッドが必要です。 

明らかではないエッジケースには、次のような状況が含まれます。$a$そして$b$～に比べて非常に近い、または非常に離れている$r$、または、の最上位ビット$r$の異なるビットより小さい$a$そして$b$。 たとえば、次の場合$a=0$、$b=3$、 そして$r=2$、選択する$x=1$XOR は最下位ビットを反転するため、差が最小限に抑えられます。 考えるだけの不用意なコード$x=0$または$x=r$間違った答えが生まれてしまいます。 

## アプローチ

 ブルートフォース手法では反復処理が行われます$x$0から$r$、計算する$|(a \oplus x) - (b \oplus x)|$それぞれについて、最小値を取ります。 これは正しいですが、大規模な場合は不可能です$r$。 重要な洞察は、XOR は 2 つのビット間の異なるビットのみに影響を与えるということです。$a$そして$b$。 絶対的な差を最小限に抑えることは、最も大きな差のビットから始めて、それらのビットを可能な限り整列させることと同じです。 

最適なアプローチは、最上位ビットから最下位ビットまでビット単位で機能します。 それぞれのビットを選択しようとします$x$それを超えないように貪欲に$r$そして、XOR の差が最小化されるようにします。 それぞれのビットで、それを超えずに反転できれば$r$、差を減らすためにそうします。 これにより、問題は O(log(max(a,b,r))) ビット操作に減り、制約に対して十分高速になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | テスト ケースごとの O(r) | お(1) | 10^18 までの r には遅すぎます |
 | ビットごとの貪欲な | テスト ケースごとに O(60) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. XOR の差を計算します。$d = a \oplus b$。 問題は最小化に帰着します$|d \oplus 0$選択することで$x$制約の下で適切に$x \le r$。 
2.初期化$x=0$そして変数$y$現在の暫定値を追跡します。 
3. 最上位ビット (最大の数値の場合はビット 59) からビットを反復処理します。$10^{18}$) ビット 0 まで。 
4. 各ビット位置について$i$、そのビットを反転しているかどうかを確認してください$x$差を縮めることができるかもしれない。 また、このビットを設定すると、$x > r$。 
5. ビットの設定が可能な場合は、更新します。$x$そして続けます。 それ以外の場合は、ゼロのままにします。 
6. すべてのビットを処理した後、計算します。$|(a \oplus x) - (b \oplus x)|$最終的な答えとして。 

機能する理由: XOR はビット全体にわたって線形であり、ビットごとに独立しています。 最も重要なビットから貪欲にビットを選択すると、最大の異なるビットが最適に配置されることが保証され、これは絶対差に最大の影響を与えます。 常に上限を尊重することで$r$、実現可能性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(a, b, r):
    d = a ^ b
    x = 0
    for i in reversed(range(60)):
        bit = 1 << i
        if (d & bit):
            # try to set this bit in x if it does not exceed r
            if x | bit <= r:
                x |= bit
    return abs((a ^ x) - (b ^ x))

t = int(input())
for _ in range(t):
    a, b, r = map(int, input().split())
    print(solve_case(a, b, r))
```機能`solve_case`最小の XOR 距離を計算します。 最上位ビットから最下位ビットまで反復し、差を減らして維持するのに役立つ場合にのみビットを設定します。$x \le r$。 最終的な差は直接計算されます。

 ## 特殊なケース

 いつ$r=0$、$x$は強制的に 0 に設定されます。ビットを設定できないため、コードはこれを正しく処理します。 

いつ$a=b$に関係なく、差はゼロです。$x$。 コードは不必要なビットを設定しません。 

いつ$r$完全に位置合わせするために必要なビットよりも小さい$a$そして$b$、コードは実行可能なビットのみを最高位から最低位まで設定し、達成可能な最小の差を生成します。 

ビット単位のアプローチでは当然上限が尊重され、最大 60 ビットの数値に対応します。
