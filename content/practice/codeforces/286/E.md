 ## 解決策
 ## 問題の理解

 私たちには、最低限の耐荷重が定められたバッグのセットが与えられます。 これらのアイテムを無制限に使用して、バッグに保持できる総重量を形成できるように、アイテムの最小セットの重量を定義する必要があります。 さらに、1 から指定された最大値までのすべての可能な重み`m`これらのアイテムの重量を何らかの組み合わせで合計したものとして表現できる必要があります。 基本的に、アイテムは「コイン」のように機能し、バッグは達成できなければならない目標金額を定義します。一方、私たちは、以下のすべての金額をカバーする最小のコインセットを見つけるように求められます。`m`それぞれの手荷物制限に正確に達します。 

入力により得られるものは、`n`明確なバッグ容量と最大重量`m`。 制約`n, m ≤ 10^6`これは、考えられるすべての重みのサブセットを反復する解は非常に遅すぎることを示しています。 線形または線形に近いアプローチが必要です。`m`効率的になるために。 エッジ ケースは、最初のバッグの重量が 1 である場合、または連続するバッグの容量間にギャップがあるため、カバレッジ要件を満たすために複数の異なる重量を強制的に含める必要がある場合に発生します。 たとえば、バッグが次のような場合`[3, 4]`そして`m = 4`、単純なアプローチでは、すべての合計 ≤ 4 をカバーするには 1 または 2 の重みが必要であることを見落とす可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、アイテムを貪欲に選択し、最大の重量ごとに検証しようとします。`m`形成できるかどうか。 これには、各候補の重みについて考えられるすべての合計を反復処理する必要がありますが、これは不可能になります。`m`まで可能です`10^6`。 合計の完全なブール配列を使用して動的プログラミングを使用した場合でもコストがかかります`O(m * n)`最悪の場合、到達する可能性があります`10^{12}`操作。 

重要な観察は、この問題は本質的にコイン両替問題の変形であるということです。 各バッグ重量は、表現可能でなければならない目標合計を定義します。 バッグの容量を昇順に処理すると、現在のアイテムのセットでは重量を形成できないバッグに遭遇した場合にのみ、新しいアイテムの重量を貪欲に選択できます。 新しいアイテムの重量の最小の選択は、このバッグの重量とアイテムで現在形成できる最大重量との差です。 これにより、新しい各アイテムの重量によって表現可能な合計の範囲が必要最小限に拡張され、最小限のセットが生成されることが保証されます。 結果として得られるアルゴリズムは、本質的に、達成可能な重みのプレフィックス合計に対する貪欲な構築です。

 | 貪欲なコインの構築 | O(n + m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. バッグの容量を昇順に並べ替えます。 これにより、最小から最大までの処理が可能になり、表現可能な重みセットの増分が最小限に抑えられます。 
2.初期化`max_reachable`0 とアイテムの重量の空のリスト`p`。`max_reachable`選択したアイテムの重量の合計として現在表現できる最大の重量を追跡します。 
3. 各バッグの重量を反復処理します。`a_i`。 もし`a_i`より大きい`max_reachable + 1`、それは表現できる合計にギャップがあることを意味します。 差分を追加`a_i - max_reachable`新品の重量として。 これは到達可能な最小重量です`a_i`現在の合計範囲を最小限に拡張しながら。 
4.アップデート`max_reachable`新しい項目の重みを追加することで、表現可能な合計範囲を拡大します。 
5. バッグの容量がすべて処理されるまで続行します。 構造上、最後のバッグまでのすべての重量が表現可能であり、各バッグの重量が正確にヒットします。 
6. アイテム重量の最終リストを出力します。 いずれかの時点でバッグの重量をカバーできず、新しい重量で範囲を拡張できない場合 (重量は 1 以上の整数であるため、この設定では不可能です)、「NO」と出力します。 それ以外の場合は、「YES」とアイテムの重量を出力します。 

なぜ効果があるのか​​: 各ステップで、`max_reachable`すべての合計が 1 から`max_reachable`達成可能です。 ギャップが現れるたびに最小の新しい重量を選択することで、必要な合計をすべてカバーしながら追加するアイテムの重量が可能な限り少なくなることが保証されます。 これは、コイン変更問題の構造によって正当化される貪欲な選択であり、最小の不足コインを取得すると、常に無制限のコイン設定で最適なセットが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()
    
    p = []
    max_reachable = 0
    for weight in a:
        while max_reachable + 1 < weight:
            new_item = max_reachable + 1
            p.append(new_item)
            max_reachable += new_item
        max_reachable = max(max_reachable, weight)
    
    print("YES")
    print(len(p))
    print(' '.join(map(str, p)))

if __name__ == "__main__":
    solve()
```コードは入力を読み取り、バッグの重量を並べ替えます。`max_reachable`表現可能な最大の合計を追跡します。 バッグの重量の前にギャップがある場合は、ギャップを埋めるために可能な限り最小の新しいアイテムの重量が追加されます。 すべてのバッグを処理した後、`p`必要な最小限のアイテム重量が含まれています。 このアルゴリズムは、ギャップをカバーするために可能な限り最小のものを常に選択し、最小性を保証することで不必要な重みを回避します。
