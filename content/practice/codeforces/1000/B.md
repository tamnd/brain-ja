 ## 解決策
 ## 問題の理解

 ランプが最初に点灯する 0 から M までの時間間隔が与えられます。 ランプには、スイッチング瞬間の事前定義されたリストがあります。 このリストの各瞬間に、ランプのオンとオフが瞬時に切り替わります。 時間 0 でオンが開始され、時間 M で強制的にオフになるため、M までの間隔のみが問題になります。 

プログラムの効果として、タイムラインは交互のセグメントに分割され、0 から a1 までの「オン」セグメントから始まり、次に a1 から a2 までの「オフ」セグメント、そして a2 から a3 まで再びオンというようになります。 合計点灯時間は、すべての「オン」セグメントの合計です。 

シーケンスが厳密に増加している限り、ソートされたリストのどこにでも最大 1 つの追加のスイッチング時間を挿入できます。 この挿入により、その瞬間の状態が反転し、明暗の間隔が結合または分割される可能性があります。 タスクは、ランプが点灯し続ける合計時間を最大化するために、可能な限り最適な挿入ポイントと値を選択することです。 

n が 100000 までという制約は、考えられるすべての挿入位置と値を試行できないことを意味します。 すべてのギャップとその内部のすべての候補時間を試行するアプローチは、二次関数かそれよりも悪く、時間内に実行されません。 リニアまたはリニアに近いスキャンが必要です。 

いくつかの微妙なケースが重要です。 ランプがすでにオフになっている領域に挿入すると、新しいオン セグメントを作成できますが、追加のオフ セグメントも作成されるため、正味のゲインは明らかではありません。 オン セグメント内に挿入すると、オフ セグメントで区切られた 2 つの小さなオン セグメントに分割される可能性があり、これにより通常、合計オン時間が短縮されます。 「常に最大のギャップに挿入する必要がある」という素朴な直感は誤りです。反転すると、セグメントの長さだけでなくパリティも変更されるからです。 

具体的な例として、M = 10 および a = [4, 6, 7] を考えてみましょう。 挿入なしの場合、間隔は [0,4) と [6,7)] なので、合計は 5 になります。 3 に挿入すると、[3,4,6,7] が得られ、間隔は [0,3)、[4,6)、[7,10)] となり、合計は 3 + 2 + 3 = 8 になります。 これは、最適な挿入が必ずしも既存のギャップと一致しているわけではないことを示しています。 

## アプローチ

 強引に試す場合は、最初の要素の前と最後の要素の後を含む、連続する要素間のすべての可能な挿入位置、および 1 から M−1 までのすべての可能な整数値を考慮することになります。 挿入候補ごとに、すべてのトグルをシミュレートして合計点灯時間を再計算します。 つまり、シミュレーションごとに O(n) となり、最悪のケースでは O(M) 個の可能な値が得られますが、これは完全に実行不可能です。 

重要な観察は、1 つのトグルを挿入すると、ローカルで 1 つの連続するセグメント構造にのみ影響するということです。 すべてを再計算するのではなく、切り替え間の各セグメントの寄与を事前に計算する必要があります。 ランプはオンとオフのセグメントを交互に繰り返します。 各ギャップは、パリティに応じて、答えに寄与するか寄与しません。 

セグメント内に新しいトグルを挿入すると、事実上 1 つの区間が 2 つの部分に分割され、その間の状態が反転します。 これは、オフ間隔の一部をオンに変えるか、パリティを再割り当てして間隔を延長することでどれだけのゲインが得られるかを考慮するだけでよいことを意味します。 

これをより明確に考える方法は、エンドポイント 0 と M を含む、連続するスイッチ ポイント間のセグメントとしてタイムラインを表示することです。各セグメントには長さがあり、セグメントはオンから始まりオンとオフが交互に切り替わります。 セグメント内に 1 つのポイントを挿入すると、そのセグメントのみが変更されます。1 つのセグメントが 2 になり、挿入ポイントの後でパリティが反転します。 ゲインは、オン セグメントに挿入するかオフ セグメントに挿入するか、およびそれをどのように分割するかによって異なります。 

これにより、問題はすべてのセグメントを 1 回チェックし、そのセグメント構造のプレフィックス合計を使用してセグメント内の可能な最良のゲインを計算することに軽減されます。

## アルゴリズムのチュートリアル

 まず、先頭に 0 を追加し、末尾に M を追加して、スイッチ時間の配列を拡張します。 これにより、プロセス全体を連続した点間の交互のセグメントとして均一に扱うことができます。 

連続する値間のセグメントの長さを計算します。 インデックス 0 で始まるセグメントは「オン」セグメント、インデックス 1 は「オフ」というようになります。 また、オンセグメントの長さのプレフィックスの合計も計算するので、既存の合計点灯時間を迅速に計算できます。 

次に、ある位置 x に新しいスイッチを挿入することを考えます。 x がセグメント i の内側にある場合、長さ L のセグメントは、長さ d の左側部分と長さ L-d の右側部分の 2 つの部分に分割されます。 状態は x で反転するため、i 以降の後続のすべてのセグメントのパリティは、元の構造と比較して変化します。 

固定セグメント i の場合、ゲインを最大化するために d を選択します。 利益は、オフ領域の一部をオンタイムに変換するか、オンセグメントを不利に分割した場合にオンタイムの一部を失うことによって得られます。 各セグメントについて、最適な挿入ポイントは常にその端点の 1 つにあるか、接尾辞セグメントの寄与を「反転」する特定のパターンを除いてまったく役に立ちません。 

連続 d を最適化する代わりに、最適な挿入により 2 つの隣接するセグメント間の境界が効果的に選択され、後続のすべてのセグメントのパリティの寄与が反転されることが観察されます。 したがって、境界ごとに、その時点からパリティを反転する効果を計算し、最適な改善を行います。 

セグメント i と i+1 の間の考えられるすべての挿入境界を反復処理します。 このような境界ごとに、位置 i の直後に挿入すると、後続のすべてのセグメント パリティが反転されると何が起こるかを計算します。 改善点は、サフィックスの寄与をオフから元の寄与を差し引くのではなくオンとして取得する場合の違いです。 プレフィックスの合計を使用して、これを境界ごとに O(1) で評価します。 

最後に、すべての境界にわたって最大の改善を取得し、それを元の合計点灯時間に加算します。 

## なぜ機能するのか

 重要な不変条件は、オン/オフ セグメントの構造が最初のスイッチに対するパリティによって完全に決定されることです。 単一のトグルを挿入しても、離れたセグメント間に新たな相互作用は作成されません。 ある時点以降のパリティを反転するだけです。 したがって、すべての有効な解決策は、セグメント シーケンス内の単一のカット ポイントを選択し、サフィックスの寄与を反転することに対応します。 セグメント内の最適な挿入ポイントは常に、このサフィックス フリップ ゲインを最大化する境界を選択することになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, M = map(int, input().split())
    a = list(map(int, input().split()))

    # build full timeline with boundaries
    t = [0] + a + [M]
    m = len(t) - 1

    seg = [t[i+1] - t[i] for i in range(m)]

    # compute original lit time (even segments: 0-based indexing)
    base = 0
    for i in range(m):
        if i % 2 == 0:
            base += seg[i]

    # prefix sums of segment lengths
    pref = [0] * (m + 1)
    for i in range(m):
        pref[i+1] = pref[i] + seg[i]

    # prefix sums of ON segments only
    on_pref = [0] * (m + 1)
    for i in range(m):
        on_pref[i+1] = on_pref[i]
        if i % 2 == 0:
            on_pref[i+1] += seg[i]

    ans = base

    # try inserting at boundary i (between segment i-1 and i)
    for i in range(1, m):
        left_on = on_pref[i]
        left_total = pref[i]

        right_on = on_pref[m] - on_pref[i]
        right_total = pref[m] - pref[i]

        # if we flip parity after i, ON segments become OFF and vice versa
        flipped_on = right_total - right_on

        gain = left_on + flipped_on - base
        if gain > ans - base:
            ans = base + gain

    print(ans)

if __name__ == "__main__":
    solve()
```コードは最初にタイムラインをセグメント長に圧縮し、トグルが個々のイベントとしてではなく、構造的な変更として扱われるようにします。 変数baseは、ランプがオン状態で開始するため、偶数のインデックスが付いたセグメントを合計することによって元の点灯時間を計算します。 

接頭辞配列は全長とオン長を分離するため、接尾辞の反転を一定時間で評価できます。 潜在的な挿入境界ごとに、反転されたパリティの下でサフィックスの寄与が再計算され、元の構成に対する改善が測定されます。 

よくある落とし穴は、挿入によって単一セグメントだけでなくサフィックス全体のパリティが反転されることを忘れていることです。 もう 1 つは、サフィックスがオンで始まるかオフで始まるかを誤って処理することです。そのため、元の貢献度と合計貢献度を明示的に分離しています。 

## 実用的な例

 ### 例 1

 入力:

 n = 3、M = 10、a = [4、6、7]

 セグメント: [0,4]、[4,6]、[6,7]、[7,10]

 | ステップ | 左オン | 右オン | 右合計 | オンに切り替え | ゲイン |
 | --- | --- | --- | --- | --- | --- |
 | i=1 | 0 | 1 | 6 | 5 | 5 |
 | i=2 | 4 | 1 | 4 | 3 | 3 |
 | i=3 | 4 | 0 | 3 | 3 | 3 |

 ベース = 5、最良のゲイン = 3、答え = 8

 これは、初期の境界の後でパリティを反転し、将来のオフ時間がオン時間になる量を最大化することで最良の改善がもたらされることを示しています。 

### 例 2

 入力:

 n = 2、M = 10、a = [1, 2]

 セグメント: [0,1]、[1,2]、[2,10]

 | ステップ | 左オン | 右オン | 右合計 | オンに切り替え | ゲイン |
 | --- | --- | --- | --- | --- | --- |
 | i=1 | 0 | 0 | 9 | 9 | 9 |
 | i=2 | 1 | 0 | 8 | 8 | 7 |

 ベース = 9、最良のゲイン = 0、答え = 9

 ここでは、構造の大部分がすでに最適化されているため、挿入は役に立ちません。 反転はセグメントを再分配するだけで、合計オン時間は改善されません。

 ## 特殊なケース

 n = 1、M = 100、a = [50] などの単一のトグル入力の場合、セグメント構造は [0,50] がオン、[50,100] がオフになります。 挿入すると、最初のオン セグメントが分割されるか、オフ セグメントの一部が変換されます。 アルゴリズムは、50 の前と 50 の後の両方の境界を評価します。最良の結果は、50 の直前に挿入し、時間どおりに 50 から 50 に増加し、さらにサフィックスを反転することで追加のゲインが得られ、プレフィックスとサフィックスの分割が正しくキャプチャされます。 

a = [1,2,3,4] のような密にパックされたトグルの場合、セグメントは急速に切り替わり、プレフィックスの合計により、サフィックスの反転が再計算なしで計算されます。 このアルゴリズムは、単一の大きな間隔ではなく、多数の小さなセグメントが集合的にゲインを支配する可能性があるという事実を正しく処理します。
