 ## 解決策
 ## 問題の理解

 私たちには銃のセットが与えられており、それぞれに次の 2 つの特性があります: 発砲速度$f_i$そして弾丸ごとのダメージ$d_i$。 この二つの積で、$p_i = f_i \cdot d_i$、銃の合計火力です。 課題は、最小限に調整することです$d_i$最も強力な銃と最も弱い銃の差が所定のしきい値を超えないように、可能な限り値を調整します。$k$。 重要なのは、それぞれの新しい$d_i$正の整数のままでなければなりません。 

入力はかなり大きくなる可能性があります。すべてのテスト ケースで最大 3000 丁の銃が存在する可能性があり、各ダメージ値は最大$10^9$。 これにより、考えられるすべてのダメージ値を明示的に列挙しようとするソリューションは除外されます。単一の銃についてすべての可能性を反復しても時間制限を超える可能性があるためです。 明示的に列挙するのではなく、範囲や相対的な違いを推論することで機能するアプローチが必要です。 

エッジケースは、すべての銃がすでにバランス条件を満たしている場合に発生します。$k = 0$そのため、すべての銃のパワーがまったく同じである必要がある場合、または銃のダメージ値が非常に大きく、1 未満にしないと十分に調整できない場合に使用します。整数の制約を無視したり、すべての銃を直接変更したりする単純な実装では、最適でない数の変更が返されたり、無効なダメージ値が返されたりする可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、銃のすべてのサブセットの変更と、可能なすべての整数値の変更が試行されます。$d_i$合理的な範囲内で。 これは原理的には正しいです。試行によって常に解決策を見つけることができますが、計算的には実行不可能です。 と$n$最大 3000、サブセットの列挙は$2^n$そして、ダメージ値の各組み合わせをチェックすると、さらに大きな係数が乗算されます。 

重要な観察は、変更しない場合に各銃が許容できる火力値の範囲を定義していることです。 銃用$i$発射速度付き$f_i$そしてダメージ$d_i$、その力は$p_i = f_i \cdot d_i$。 目標火力間隔を設定しようとすると$[L, L+k]$、改造しない銃は最新のものでなければなりません。$p_i$この間隔内で。 これは、問題が長さの間隔を見つけることに帰着することを意味します。$k$既存の多くのものをカバーします$p_i$可能な限りの値。 この間隔外のガンは変更する必要があります。 を並べ替える$p_i$スライディング ウィンドウまたは 2 ポインター手法を使用すると、これを効率的に計算できます。 

したがって、最適なアプローチは、すべてを計算することです。$p_i$値を並べ替えて、一定の長さのウィンドウをスライドさせます$k$ソートされたリスト全体にわたって。 位置ごとに、すでにその間隔内にある砲の数を数えます。 変更するガンの最小数は合計です。$n$すでに一定の間隔内にある銃の最大数を引いたものです。 このアプローチは次のような環境で機能します。$O(n \log n)$並べ替えによるテスト ケースごとの値。合計を考慮すると許容範囲内です。$n$すべてのテスト ケースは 3000 です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * max(d_i)) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 テスト ケースごとに、次の内容を読んでください。$n$そして$k$、その後に発射速度の配列が続きます$f$そしてダメージアレイ$d$。 
2. 各銃の火力を計算します。$p_i = f_i \cdot d_i$。 これにより、現在の電力レベルを表す整数のリストが得られます。 
3. 並べ替える$p_i$リスト。 問題は長さの間隔を見つけることに帰着するため、ソートが必要です。$k$それは銃の最大数をカバーします。 ソートにより、連続するべき乗のシーケンスを効率的に検討できるようになります。 
4. 2 つのポインタを初期化します。`l`そして`r`これらのポインタは、変更しないままにしてもよいべき乗のウィンドウを定義します。`l`区間内の左端の累乗を指し、`r`まで右に移動します$p_r - p_l > k$。 
5. スライドしながら`r`右側にあることを確認してください$p_r - p_l > k$。 そうであれば、インクリメントします`l`インターバルの長さが最大になるまで$k$。 各ステップで、間隔内の銃の数を次のように計算します。`r - l + 1`、確認された最大値を追跡します。 
6. 反復後の最小変更数は次のとおりです。$n - \text{max\_inside}$。 これは、最適な間隔内にないすべてのガンを変更する必要があるためです。 
7. 各テスト ケースの結果を出力します。 

機能する理由: ソートされた配列は、任意の長さの間隔を保証します。$k$内部の銃の数を最大にするものは連続している必要があります。 ソートされた配列全体でウィンドウをスライドさせると、そのようなすべての連続した間隔が確実に考慮されます。 選択した間隔外のガンは変更する必要があるため、カバーされる最大値を差し引いて、$n$最小限の変更を加えます。 整数制約$d_i$間隔内のガンは変更する必要がなく、外側のガンはいつでも許容範囲内の任意の整数に調整できるため、干渉しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        f = list(map(int, input().split()))
        d = list(map(int, input().split()))
        p = [f[i] * d[i] for i in range(n)]
        p.sort()
        max_inside = 0
        l = 0
        for r in range(n):
            while p[r] - p[l] > k:
                l += 1
            max_inside = max(max_inside, r - l + 1)
        print(n - max_inside)

if __name__ == "__main__":
    solve()
```コードはまず各銃の合計火力を計算します。 ソートにより、ツーポインタ技術ですでにバランス条件を満たしている銃の最大グループを効率的に見つけることができます。 スライド窓が動きます`r`アレイを介して、そして`l`間隔を超えるたびに追いつきます`k`。 から最大の有効なグループを減算します。`n`最小限の変更が行われます。 微妙な点は、全体で整数を使用し、浮動小数点除算を避ける必要があることです。Python の整数の乗算は整数のままであるため、浮動小数点除算は自動的に処理されます。

 このトレースは、ウィンドウがすでにその中にある最大のグループを正しく識別していることを確認します。`k`お互いの。
