 ## 解決策
 ## 問題の理解

 合計単位数と、非表示のコースのリストから計算された 2 つの集計統計が与えられます。 各コースには、60 ～ 100 の整数のクレジット値と整数のスコアがあります。この非表示のリストから、クレジットのすべての単位が均等に集計に寄与するため、システムは、各コースがその多数の単位で重み付けされたスコア エントリに拡張されているかのように効果的に動作します。 

加重平均スコアと加重 GPA という 2 つの要約が提供されます。 GPA はスコア内で直線的ではありません。 これは 100 からの距離の二次関数です。つまり、スコア自体ではなく、スコアが完璧なパフォーマンスからどれだけ離れているかによって決まります。 

タスクは、複数セットの単位クレジット スコアが両方の指定された集計を正確に再現できるかどうかを判断し、再現できる場合は 1 つの有効な割り当てを構築することです。 

主要な構造上の制約は、ユニット寄与の合計数が最大 250 であることです。これは十分に小さいため、問題は基本的に、大きなシーケンスに対する最適化ではなく、制限された範囲内の整数に対する離散分布の構築に関するものです。 クレジットを平坦化せずに各コースを独立して処理しようとするアプローチは、クレジットを単位貢献度に分割すると階層が完全に削除されるため、問題を複雑にしすぎます。 

この問題のデリケートな部分は、分布の 2 つの異なるモーメント (平均スコアとスコアの二次変換) が同時に固定されることです。 これにより、恣意的な構成が即座に除外されます。これは、平均が固定されると、二次モーメントによって分散が厳密に制限されるためです。 

一般的な失敗例は、GPA 制約を平均から独立したものとして扱う場合に発生します。 たとえば、平均スコアに完全に集中した分布は、常に平均スコアと一致しますが、平均がたまたまその二乗偏差が正確に一致する整数スコアでない限り、二次 GPA と一致することはほとんどありません。 もう 1 つの微妙な失敗は、スコアを近くの整数に貪欲に丸めることを試みたときに発生します。これにより、平均はほぼ維持されますが、二次モーメントが破壊されます。 

## アプローチ

 すべてのコースを単位クレジットに拡張すると、問題は、平均が指定された値 s̄ に等しく、二次関数 g(s) での平均が ḡ に一致する [60, 100] の範囲内の正確に c 個の整数を構築することになります。 

強引なアイデアは、41 の可能なスコアにわたってサイズ c の可能なマルチセットをすべて試すことです。 これは、c 個の同一のボールを 41 個のビンに分配することに相当し、すでに次のオーダーの巨大な状態空間を与えます。$\binom{c+40}{40}$, c = 250 であっても扱いやすいものをはるかに超えています。 

重要な単純化は、線形モーメント (平均) と二次モーメント (変換後の分散のような制約) の 2 つのモーメントのみを照合していることに注目することで得られます。 このような問題では、領域が制限されており、整数の多重度を自由に選択できる場合、実行可能な分布は常に最大 2 つの異なる値を使用して表現できます。 これにより、構築の問題は、両方の制約が正確に満たされるように、c を k と c − k に分割するとともに、2 つのスコア a と b が存在するかどうかを見つけることに帰着します。 

2 つの候補スコアを修正すると、システムは代数によって完全に解けるようになります。平均値が k を決定し、2 番目のモーメントが一貫性チェックとして機能します。 スコアの領域が小さいため、すべてのペアを効率的に列挙できます。

 ## アルゴリズムのチュートリアル

 すべての集計は単位において線形であるため、最初に各単位を同じスコアを持つ独立した単位として扱うことにより、コースの階層を排除します。 

次に、GPA 式をより単純な 2 次形式に変換します。 各スコア s を 100 からの距離、つまり t = 100 − s として書くと、GPA は t² の関数に変換されます。 これにより、問題は t 値の平均と 2 次モーメントの両方を照合するように変換されます。 

次に、必要な目標数量を計算します。 t の平均は、指定された平均スコアから直接決定され、t² の平均は、GPA 式を代数的に並べ替えることによって GPA 式から導出されます。 

次に、t の 2 つの異なる値 (a と b) のみを使用して分布を表現しようとします。 順序を固定し、a の k コピーと b の c − k コピーを仮定します。 a と b が異なる場合、平均条件は k を一意に決定します。 この k を計算し、範囲内の整数であることを確認します。 

その後、同じカウントを使用して 2 番目のモーメント条件を検証します。 両方の条件が数値許容範囲内で一致する場合、t をスコアに変換し直すことによって直ちに答えを構築します。 

どのペア (a, b) も機能しない場合、有効な 2 点分布は存在しません。また、2 つのモーメント制約を持つ有界整数領域上の実行可能な解は最大​​ 2 つのサポート ポイントに圧縮できるため、解は存在しないと結論付けます。 

### なぜ効果があるのか

 この問題は、有限領域にわたる 2 つの独立した制約の下で分布を一致させることに帰着します。 実行可能な解決策はどれも、これらの制約によって定義される凸集合内に点を誘導します。 有界整数をサポートする 1 次元では、このセットの極点は、最大 2 つの値でサポートされる分布に対応します。 このような極端な構成をすべて列挙することで、有効な分解を見つけるか、すべての可能性を網羅して、正確さを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    c = int(input())
    sbar, gbar = map(float, input().split())

    # convert to t = 100 - s
    T = 100.0 - sbar
    Q = (4.0 - gbar) / 3.0

    eps = 1e-9

    # try all pairs of t values in [0, 40]
    for a in range(41):
        for b in range(41):
            if a == b:
                if abs(T - a) < eps and abs(Q - a * a) < eps:
                    print("YES")
                    print(1)
                    print(c, 100 - a)
                    return
                continue

            denom = a - b
            num = c * (T - b)

            if abs(denom) < eps:
                continue

            k = num / denom

            if abs(k - round(k)) > 1e-7:
                continue

            k = int(round(k))
            if k < 0 or k > c:
                continue

            # verify second moment
            lhs = (k * a * a + (c - k) * b * b) / c
            if abs(lhs - Q) > 1e-7:
                continue

            # build answer
            print("YES")
            print(c)
            for _ in range(k):
                print(1, 100 - a)
            for _ in range(c - k):
                print(1, 100 - b)
            return

    print("NO")

if __name__ == "__main__":
    solve()
```解決策は、GPA 制約を変換された変数の二次モーメントに変換することから始まり、これにより元の式の非線形的な外観が除去されます。 考えられるサポート値の列挙は、算術演算の安定性と 100 付近の対称性を維持するため、変換された空間で直接行われます。 

コードは、候補ペアごとに、平均と一致するために必要な 1 つの値の正確な出現数を導出します。 二次モーメント チェックは一貫性フィルターとしてのみ使用され、数値エラーや代数縮退によって無効な構造が生成されないことを保証します。 

最後に、有効な構成が見つかると、各単位クレジットがサイズ 1 の独立したコースとして発行され、コース クレジットが正の整数であるという元の要件が満たされます。

 ## 特殊なケース

 重要なエッジケースは、すべてのコースが同一のスコアを持つ必要がある場合です。 その状況では、分散はゼロになり、両方のモーメントが単一の値制約に崩壊します。 アルゴリズムはこれを a == b 分岐で処理し、そこで T と Q の間の一貫性を直接チェックし、一様分布を出力します。 

別のエッジ ケースは、必要な平均が整数境界上に正確に存在するが、二次制約がゼロ以外の分散に対応する場合に発生します。 このような場合、単一値の解は存在せず、アルゴリズムは適切に個別のペアのテストに戻り、平均方程式により拒否される小数 k が強制されます。 

さらに微妙なケースは、平均方程式から k を再構築する際の浮動小数点精度から発生します。 このソリューションは、k の整数をチェックするときに小さな数値誤差を明示的に許容し、10 進入力から導出された値が丸めアーティファクトによって誤って失敗しないようにします。
