 ## 問題の理解

 この問題では、未知の整数を操作するように求められます。$x$与えられた目標と等しくなるようにする$n$非常に限られた数の操作を使用します。 の初期値がわかりません$x$そして、操作できるのは 4 つのコマンド (整数の加算、整数の乗算、除数での除算、置換) を通じてのみです。$x$その数字の合計で。 桁の合計演算は、数値を、多くの場合、劇的に小さい数値に削減しますが、他の演算は、数値を線形または乗算的にスケーリングします。 最終的な目標は、次の間の正確な等しい値を出力することです。$x$そして$n$最大 4 つの操作を使用し、その後は感嘆符で完了を知らせることができます。 

重要な制約は次のとおりです。$x$範囲内で始まります$[1, 10^9]$、コマンドは数値制限を尊重する必要があり、許可されるコマンドの数は非常に少ないです。 これにより、潜在的な値の強引な探索や反復的な調整が排除されます。 4 つの操作が許可されているため、推測したり、ターゲットに順番に近づいたりすることはできません。 代わりに、数字を減らすための数字の合計演算と、正確な目標を達成するための単純な算術または乗算を利用して、解空間を急速に崩壊させる演算を慎重に選択する必要があります。 

ターゲットが次の場合に微妙なエッジケースが発生します。$n$小さい値、特に 1 桁の数値ですが、開始$x$大きいです。 たとえば、次の場合$x = 9876$そして$n = 5$、加算または乗算のみを行う単純なアプローチでは、限られたステップ数で目標を達成することはできません。 同様に、$n$など大きいです$n = 10^9$、しかし、最初の$x$小さいので増幅する必要があります$x$許容範囲を超えずに効率的に実行できます。 任意の数値に対する「桁」演算の影響を理解することは、2 回の演算で任意の数値を最大 2 桁に折りたたむことができるため、非常に重要です。

重要な洞察は、数字の合計演算の威力を認識することです。 「digit」を繰り返し適用すると、数値がすでに 1 桁である場合を除いて、桁の合計は元の数値より厳密に小さいため、最大 3 回の反復内であらゆる数値が 1 桁の数値に減ります。 したがって、最適な戦略の 1 つは、最初に「数字」操作を使用して折りたたむことです。$x$管理可能な数値に変換し、目標を達成するためにスケールまたは追加します。 ターゲットが小さい場合 (10 未満)、1 桁または 2 桁のリダクション後に最大 1 回の「div」または「add」操作を使用して、直接ターゲットに到達できます。 ターゲットが大きい場合は、1 回の乗算とオプションで 1 回の加算を介してターゲットを構築し、正確に位置を合わせることができます。 

この戦略は、各桁の合計演算によって削減される不変式を利用します。$x$予想通り、乗算スケーリングは次の場合に正確になります。$x$は小さく、4 つの操作の制限が尊重されます。

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        if n < 10:
            print("digit")
            sys.stdout.flush()
            print(f"add {n-1}")
            sys.stdout.flush()
        else:
            print("digit")
            sys.stdout.flush()
            print(f"add 9")
            sys.stdout.flush()
            print(f"mul {n // 10}")
            sys.stdout.flush()
        print("!")
        sys.stdout.flush()

if __name__ == "__main__":
    solve()
```最初のセクションでは、テスト ケースとターゲットの数を読み取ります。 1 桁のターゲットの場合、「数字」を使用して任意の値を折りたたみます。$x$そして正確に到達するには「add」$n$。 より大きなターゲットの場合は、まず削減します$x$「digit」を使用して、きれいに割り切れるように「add」で調整し、「mul」で達成します。$n$。 ついに、 "！" 完了を知らせます。
