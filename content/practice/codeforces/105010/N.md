 ## 解決策
 ## 問題の理解

 各頂点が通貨を表し、各辺が交換操作を表す有向グラフが与えられます。 通貨から考えると`u`通貨に`v`、金額に単純にレートが乗算されるだけでなく、換算前の固定手数料も減ります。 具体的には、現在ある程度の金額を保有している場合、`A`通貨で`u`、交換を使用した後、最終的には次のようになります`r * (A - f)`通貨で`v`。 

ラミはある程度の金額を借りることから始めます`z1`通貨で`0`。 その後、通貨を複数回再検討するなど、任意のシーケンスを適用することができ、最終的には通貨に戻らなければなりません。`0`最終的な金額で`z2`。 目標は最小の整数を見つけることです`z1`で始まり、で終わる一連の交換が存在するように、`0`と`z2 > z1`。 

重要な問題は、すべての交換が純粋に乗算的ではなくアフィン的であることです。 各エッジは値を線形関数として変換するため、長いパスは単純な積ではなく入れ子になった線形式を構成します。 

この制約は、パスの単純な列挙が不可能であることを示唆しています。 最大 500 の通貨と 4000 の取引所があるため、すべてのパス、さらにはすべての単純なサイクルを調査する方法は実行不可能です。 積制約は数値の安定性を確保し、短いパスに沿った極端な爆発を防ぐだけですが、組み合わせの複雑さは軽減されません。 

サイクルを考慮すると、微妙な問題が生じます。 サイクルは開始資金に応じて利益が得られる場合もあれば、そうでない場合もあります。 手数料が相対的に大きくなるため、金額が大きい場合には利益が得られるように見えるサイクルが、金額が小さい場合には機能しない可能性があります。 この初期量への依存が複雑さの核心です。 

単純な最短パスまたは最長パスのアプローチは失敗します。パスの「重み」がパス構造だけでなく現在の状態値に依存するためです。 同様に、実効ウェイトは開始資金に依存するため、固定ウェイトのグラフで正のサイクルを検出するだけでは十分ではありません。 

## アプローチ

 強引なアイデアは、開始金額を固定することです`z1`、考えられるすべての為替シーケンスをシミュレートし、その通貨で可能な限り最良の最終金額を計算します。`0`。 各パスは、次の形式の線形変換を定義します。`z2 = a * z1 - b`、 どこ`a`はレートと`b`変換された累積料金です。 次に、条件を満たすパスがあるかどうかを確認します。`a * z1 - b > z1`。 

パスの数が指数関数的に増加するため、これはすぐに実行不可能になります。 単純なパスに制限しても役に立ちません。サイクルこそが結果を改善できるものであり、サイクルは繰り返しの再検討を意味するからです。 

重要な観察は、固定パスの場合、不等式を次のように再配置できることです。`(a - 1) * z1 > b`。 パスに`a <= 1`、関係なく、決して利益を上げることはできません。`z1`。 もし`a > 1`、閾値を誘発します`z1 > b / (a - 1)`。 これは、すべてのサイクルが候補となる最小必要開始資本に寄与し、答えはそのようなすべてのしきい値にわたる最小値であることを意味します。 

残りの課題は、すべてのサイクルを列挙することが依然として不可能であることです。 代わりに、視点を反転して、次の固定推測を求めます。`z1`、通貨に戻すときに開始値を超えて金額を増やすシーケンスが存在するかどうかを尋ねます。`0`。 これは、アフィン変換システムに関する到達可能性の問題となり、値に対するベルマン フォード スタイルの緩和を使用して解決できます。 

実現可能性が高まるので、`z1`が増加すると、有効な最小値を二分探索できます。`z1`。

 ## アルゴリズムのチュートリアル

 私たちは問題を意思決定の問題に変換します: 固定の開始資金の場合`x`、Rami が通貨で終了できるかどうかを決定します`0`厳密にそれ以上のもの`x`。 

### 1. アフィン遷移としてのモデル交換

 各エッジ`u -> v`関数を定義します`f(A) = r * A - r * f_fee`。 両方保管しております`r`と実効減算項`c = r * f_fee`。 

これにより、最初から再計算することなく、パスに沿った合成が可能になります。 

### 2. 候補開始値を修正する

 ラミは量から始まると仮定します`x`ノードで`0`。 この開始条件の下で、すべてのノードで到達可能な最大の量を計算します。 

目標は、ノードに戻れるかどうかを確認することです`0`値を超えるもの`x`。 

### 3. リラクゼーションを使用して到達可能な最良の値を伝播する

 保守します`dist[v]`ノードで達成可能な最大量として`v`。 最初は`dist[0] = x`、その他はすべて負の無限大です。 

各エッジについて`u -> v`、以下を適用します。`dist[v] = max(dist[v], r * dist[u] - c)`。 

このリラックスを繰り返します`n - 1`これは、すべてのシンプルパスの改善をキャプチャします。 

### 4. 有益なサイクルを検出する

 後なら`n - 1`リラクゼーションについてはまだ改善の余地があります`dist[v]`、その後、サイクルによりこの値が増加します`x`。 ただし、私たちが気にしているのは、最終的に通貨に影響を与える可能性があるサイクルだけです`0`。 

これに対処するために、「サイクルの影響」を前方に伝播します。まだ緩和できるノードがマークされ、そのようなノードが到達できるかどうかを確認します。`0`逆のグラフで。 

「はい」の場合、任意に大幅な改善が可能です。つまり、元の状態に戻ることになります。`0`ゲインオーバーで`x`達成可能です。 

### 5. 固定 x の実現可能性を確認する

 緩和とサイクルの検出後、次のことを確認します。`dist[0] > x`。 直接的な改善またはサイクル支援による改善のいずれかが存在する場合、値`x`実現可能です。 

### 6. 二分探索で答えを求める

 単調性を利用します: 開始値の場合`x`が実現可能であれば、スケーリングによってすべての不等式の左側が増加するため、より大きな開始値も実現可能です。 

最小限の二分探索を行います`x`で`[0, given_limit]`。 

### なぜ効果があるのか

 すべてのパスは線形変換を定義します`z2 = a * z1 - b`。 実現可能性は、`z1 < (b / (a - 1))`あるサイクルで`a > 1`。 ベルマン・フォード緩和は、固定オブジェクトに対して達成可能な最良のアフィン変換を暗黙的に計算します。`z1`、サイクル検出により、無限の増幅ケースを確実に捕捉します。 二分探索では、少なくとも 1 つの有益な変換が可能になる最小のしきい値を分離します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = 10**30

def check(n, adj, radj, x):
    dist = [-INF] * n
    dist[0] = x

    updated = [-1] * n

    for i in range(n - 1):
        changed = False
        for u in range(n):
            if dist[u] == -INF:
                continue
            for v, r, c in adj[u]:
                val = r * dist[u] - c
                if val > dist[v] + 1e-12:
                    dist[v] = val
                    changed = True
        if not changed:
            break

    for u in range(n):
        if dist[u] == -INF:
            continue
        for v, r, c in adj[u]:
            val = r * dist[u] - c
            if val > dist[v] + 1e-12:
                updated[v] = 1

    if updated[0] == 1:
        return True

    from collections import deque
    q = deque()
    vis = [False] * n

    for i in range(n):
        if updated[i] == 1:
            q.append(i)
            vis[i] = True

    while q:
        u = q.popleft()
        if u == 0:
            return True
        for v in radj[u]:
            if not vis[v]:
                vis[v] = True
                q.append(v)

    return dist[0] > x

def solve():
    n, m, x = input().split()
    n = int(n); m = int(m); x = float(x)

    adj = [[] for _ in range(n)]
    radj = [[] for _ in range(n)]

    for _ in range(m):
        u, v, r, f = input().split()
        u = int(u) - 1
        v = int(v) - 1
        r = float(r)
        f = float(f)
        adj[u].append((v, r, r * f))
        radj[v].append(u)

    lo, hi = 0.0, x
    ans = -1

    for _ in range(60):
        mid = (lo + hi) / 2
        if check(n, adj, radj, mid):
            ans = mid
            hi = mid
        else:
            lo = mid

    if ans < 0:
        print(-1)
        return

    print(int(ans + 1e-9))

if __name__ == "__main__":
    solve()
```このコードは、決定手順を答えの検索から分離します。 各エッジは、スケーリング後のレートと実効手数料寄与率の両方を保存するため、すべての緩和はアフィン遷移の直接適用となります。 浮動小数点比較は、境界線の場合の精度の問題を回避するために、小さなイプシロンで安定化されます。 

サイクル検出段階が必要なのは、Bellman-Ford だけでは単純なパスの改善のみを捉えているのに対し、収益性の高いソリューションは有益なサイクルの繰り返しに依存していることが多いためです。 

二分探索は実数値に対して行われますが、問題では最小の整数の開始量が求められるため、最終的な答えは整数に切り捨てられます。
