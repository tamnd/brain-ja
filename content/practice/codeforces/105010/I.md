 ## 問題の理解

 各候補者は純粋に次のどれによって代表され得るか$m$彼らが属する少数民族。 したがって、すべての申請者は一連のサイズのサブセットに対応します。$m$、プールにはすべてが含まれます$2^m$可能なサブセット。 

選択ルールでは、1 つのサブセットが別のサブセットに含まれる 2 つの候補を選択することは禁止されています。 候補者であれば$A$～のすべての少数派グループがいる$B$そしておそらくそれ以上$A$厳密には、より多様であると考えられており、両方を同時に選択することはできません。 2 つの候補がまったく同じサブセットに対応する場合、問題となるのは 1 つのコピーのみですが、プールにはすでにすべてのサブセットが 1 回だけ含まれているため、重複は構造に影響を与えません。 

したがって、問題は、選択されたサブセットが別の選択されたサブセットに含まれないように、できるだけ多くのサブセットを選択することに帰着します。 

入力はただ与えます$m$したがって、タスクは純粋に組み合わせ的なものです。$m$-要素セットでは、包含関係のない最大のファミリーが必要です。 

制約$m \le 4000$サブセットにわたる指数関数的な構築を除外します。 すべてを繰り返しても$2^m$サブセットは無理です。 どのような解決策も多項式時間で機能する必要があります。$m$、理想的には$O(m^2)$またはそれ以上です。 

よくある失敗例は、正当な理由なく固定サイズのすべてのサブセットを取得したり、サイズを恣意的に混合したりするなど、貪欲な選択を試みた場合に発生します。 たとえば、$m = 3$、サブセットの選択$\{1\}, \{1,2\}, \{2\}$失敗する理由$\{1\} \subset \{1,2\}$、サイズがわずかに異なるだけでルール違反になります。 

## アプローチ

 ここでの構造は、包含によって順序付けされたサブセットのブール格子です。 制限により、このポーズでは 2 つの比較可能な要素を選択できないため、最大のアンチチェーンを探します。 

ブルートフォース試行では、すべてのサブセットを列挙し、すべてのペアの包含条件をチェックしながら、可能な選択をすべて試行します。 サブセットに限定したとしても、候補家族の数は$2^{2^m}$、これはたとえ$m = 10$。 もう少し極端でないブルート フォースを使用すると、すべてのサブセットを試して貪欲な構造を維持できますが、サブセットのサイズや辞書編集上の順序のみに基づく貪欲なルールは失敗します。これは、包含は順序ではなく構造に依存するためです。 

重要な構造的洞察は、サブセットの包含がカーディナリティ層によって制御されるということです。 同じサイズの部分集合同士は決して包含関係にありません。 サイズの任意のサブセット$k$サイズの別のサブセットを含めることはできません$k$、サイズの別のサブセットに含めることはできません$k$封じ込めによってサイズが厳密に増加するため、どちらかです。 これは、固定カーディナリティの各「レベル」が有効な独立したセットを形成することを意味します。 

これにより、問題はブール格子の 1 つ以上の完全な層を選択することになります。 比較可能性を導入せずに、単一のレイヤー内に留まるか、レイヤーを結合しながら、取得できるサブセットの数を最大化したいと考えています。 ただし、2 つの異なるレイヤーを組み合わせると、すべてのサイズのセットが存在するため、包含関係が作成されます。$k$多くのサイズのセットが含まれています$k+1$。 したがって、私たちは単一のレベル内に留まらざるを得ません。 

問題は、スペルナーの定理によって中間レベルで最大化される、最大の二項係数層を選択することになります。 したがって、答えは次のとおりです$\binom{m}{\lfloor m/2 \rfloor}$。

 ## アルゴリズムのチュートリアル

 解決策は、単一の二項係数を計算することで直接得られます。 

1. サイズが異なると包含が生じるため、最適な選択は同じサイズのサブセットから行われる必要があることに注意してください。 これにより、固定サイズのすべてのサブセットを選択するという問題が軽減されます。$k$。 
2. サイズのサブセットの数$k$は$\binom{m}{k}$。 この価値を全体的に最大化したいと考えています$k$。 二項係数は対称的な単峰シーケンスを形成します。 
3. 最大値は次の時点で発生します。$k = \lfloor m/2 \rfloor$。 したがって、答えは次のとおりです$\binom{m}{\lfloor m/2 \rfloor}$。 
4. 階乗を計算する$m$、次にモジュラー逆関数を使用して、モジュラスの下で二項係数を評価します。$998244353$。 
5. 結果を返します。 

なぜそれが機能するのかは、サブセットposetの構造からわかります。 有効な選択はすべてアンチチェーンです。 シュペルナーの定理は、ブール格子内の最大のアンチチェーンがまさに最大の中間層であり、アンチチェーンの特性を維持しながら、サイズを減らすことなくどのセット ファミリも中央に向かって「シフト」できるため、他の構造はそれを超えることはできないと述べています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    m = int(input().strip())
    
    fact = [1] * (m + 1)
    for i in range(1, m + 1):
        fact[i] = fact[i - 1] * i % MOD
    
    inv_fact = [1] * (m + 1)
    inv_fact[m] = pow(fact[m], MOD - 2, MOD)
    for i in range(m, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % MOD
    
    k = m // 2
    ans = fact[m] * inv_fact[k] % MOD * inv_fact[m - k] % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```階乗配列はエンコードします$n!$素数を法とする値。 逆階乗配列はフェルマーの小定理を使用して構築されており、係数での除算が可能です。 

の選択$k = m // 2$ブール格子の中間層を直接反映します。 他の組み合わせ構造は必要ありません。

 ## 特殊なケース

 いつ$m = 1$、唯一のサブセットは$\emptyset$そして$\{1\}$。 中間層は、$k = 0$、与える$\binom{1}{0} = 1$。 アルゴリズムはこれを正しく計算します。$m // 2 = 0$。 

いつ$m = 2$、両方のシングルトン サブセットが最適なアンチチェーンを形成します。 計算上の選択$k = 1$、降伏$\binom{2}{1} = 2$、正しい選択と一致します。 

いつ$m$など大きいです$m = 4000$、階乗計算は線形のままです。$m$、サブセットの列挙は必要ありません。 このアルゴリズムは、構造的な列挙ではなく、事前に計算された組み合わせに完全に依存しているため、制限内に収まります。
