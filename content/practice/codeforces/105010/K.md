 ## 解決策
 ## 問題の理解

 各入力は、同心円状のセクターで構成されるディスクを表します。 の$i$-th セクターはリングに分割されています$A_i$等しい位置であり、各位置は次のいずれかでペイントされます。$K$色。 したがって、すべてのセクターは本質的に色付きの巡回配列であり、その長さはセクターのインデックスに依存します。 

2 つのタイプの対称性を適用して一方をもう一方に変換できる場合、2 つのディスクは同じ構成とみなされます。 まず、個々のリングはそれぞれ独立して回転できるため、セクター内の相対的な循環構造のみが問題となり、その開始点は問題になりません。 第 2 に、ディスク全体をその中心を通る任意の軸の周りで反転させることができ、これによりすべてのリングに同時に鏡映対称性が導入されます。 これは、各セクターがサイズの完全な二面体グループの下で不変であることを意味します$2A_i$回転だけではありません。 

タスクは、各セクターが独立して色付けされているが、これらの対称性で商された場合に、ディスク全体に異なる色がいくつ存在するかを数え、セクター全体の寄与を乗算することです。 

この制約により、ソリューションは強引な列挙から遠ざけられます。 と$n \le 10^5$セクターと$A_i$まで$5 \cdot 10^5$、カラーリングを列挙したり、対称アクションを明示的にシミュレートしたりする試みは不可能です。 回転等価クラスのセクターごとの単純な列挙であっても、次の点では指数関数的になります。$A_i$、それは限界をはるかに超えています。 ソリューションは、閉じた形式の組み合わせ論に依存し、多くのセクターにわたって構造を再利用する必要があります。 

微妙な落とし穴は、回転対称性のみが重要であると仮定していることです。 これにより、反射により追加のパターンが識別される場合、特に次の場合に見える場合に、上反角ネックレスの代わりに周期ネックレスを数えたり、構成を過剰に数えたりすることになります。$A_i$は均等です。 もう 1 つのよくある間違いは、セクターをフリップの下で相互作用しているものとして扱うことですが、リングは同心円であるため、リフレクションによってリングが並べ替えられません。 各リングの内部にのみ影響します。 

## アプローチ

 直接的な試みは、すべてを生成することです。$K^{\sum A_i}$色を付けてから対称性で商します。 天文学的な状態空間を無視しても、集団行動には大きさがある$2A_i$セクターごとに行われるため、軌道の列挙が不可能になります。 

より構造化されたブルート フォースでは、各セクターを個別に処理し、回転のみで軌道サイズを計算します。 これは、循環シフトに関するバーンサイドの補題を使用した古典的なネックレスのカウント公式につながります。 ただし、これでも反射が無視されるため、等価性が過小評価されます。 

重要な観察は、各セクターが対称群の下で独立しており、各リングに作用する群がまさに二面群であるということです。$D_{A_i}$。 したがって、答えは各セクターのカウントの積に因数分解されます。 これにより、問題は、ある長さの異なる色の数を計算することになります。$A_i$回転と反射の下でのサイクル。これは標準的なバーンサイドの補題結果です。 

残りの課題は効率です。 それぞれ$A_i$約数を加算する必要がある場合があります。$K^{A_i}$-style 項は繰り返し計算する必要があります。 これは、次のモジュラーべき乗を事前に計算することで解決されます。$K$最大まで$A_i$、および最大値までのすべての整数のオイラーの合計値と約数を事前計算することによって$A_i$。

 ## アルゴリズムのチュートリアル

 答えをセクターにわたる積として計算します。各セクターは、ある長さの有効な色の数に寄与します。$A_i$二面体グループの下のリング。 

1. オイラーの合計関数と最大のすべての値の約数を事前計算します。$\max A_i$。 これにより、循環シフトに関するバーンサイドの補題の標準除数形式を介して回転の寄与を高速に評価できます。 
2. 事前計算力$K$モジュロ$M$まで$\max A_i$。 これにより、次の形式の累乗が保証されます。$K^x$になる$O(1)$高速累乗を繰り返す代わりにルックアップを行います。 
3. セクタ長ごとに$n = A_i$、恒等式を使用して回転寄与を計算します。$$\sum_{d \mid n} \varphi(d) \cdot K^{n/d}$$これは、サイクルの各回転クラスの下で不変のカラーリングをカウントします。 
4. 二面体構造を使用して反射寄与を個別に計算します。 もし$n$奇数です。すべての反射が 1 つの点を修正し、残りの点をペアにして寄与します。$n \cdot K^{(n+1)/2}$。 もし$n$が偶数である場合、反射の半分は 2 つの対向点を修正し、構造を生成します。$K^{n/2+1}$、半分は生産します$K^{n/2}$。 
5. 回転部分と反射部分を結合し、で割ります。$2n$モジュラーインバースを使用して、二面角ネックレス数を生成します$f(n)$。 
6. すべてを乗算します$f(A_i)$一緒にモジュロ$M$最終的な答えを得るために。 

正しさは、各環の二面群作用に個別に適用されるバーンサイドの補題に基づいています。 すべての対称操作によりカラーリングが軌道に分割され、すべてのグループ要素にわたる固定小数点のカウントを平均することで、個別の構成の正確な数が得られます。 セクターは対称操作の下では相互作用しないため、軌道カウントはセクター全体できれいに因数分解されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def build_sieve_and_divisors(n):
    phi = list(range(n + 1))
    divs = [[] for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(i, n + 1, i):
            divs[j].append(i)
    for i in range(2, n + 1):
        if phi[i] == i:
            for j in range(i, n + 1, i):
                phi[j] -= phi[j] // i
    return phi, divs

def solve():
    n, K = map(int, input().split())
    A = list(map(int, input().split()))
    maxA = max(A)

    phi, divs = build_sieve_and_divisors(maxA)

    powK = [1] * (maxA + 1)
    for i in range(1, maxA + 1):
        powK[i] = powK[i - 1] * K % MOD

    inv = lambda x: pow(x, MOD - 2, MOD)

    ans = 1

    for a in A:
        rot = 0
        for d in divs[a]:
            rot = (rot + phi[d] * powK[a // d]) % MOD

        if a % 2 == 1:
            refl = a * powK[(a + 1) // 2] % MOD
        else:
            refl = (a // 2) * (powK[a // 2] + powK[a // 2 + 1]) % MOD

        total = (rot + refl) % MOD
        total = total * inv(2 * a % MOD) % MOD
        ans = ans * total % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```この解決策は、整数と約数の算術ヘルパーを構築することから始まります。 回転の合計は、すべての回転を反復するのではなく、約数にわたって最も自然に表現されるため、除数リストは非常に重要です。 のパワーテーブル$K$累乗の繰り返しを回避します。そうしないと、実行時間が支配されてしまいます。$10^5$セクター。 

各セクターは独立して処理されます。 回転項は除数にわたって累積され、循環シフトのバーンサイド公式と一致します。 反射軸が頂点を通過するかエッジを通過するかによって固定点の構造が変化するため、反射項はパリティで分岐します。 

最終的な除算$2a$Burnside はすべての平均値を平均するため、モジュラー逆算術を使用します。$2a$二面体群の対称性。

 ## 特殊なケース

 いつ$A_i = 1$、セクターには意味のある回転または反射の区別がありません。 除数の合計には次の値のみが含まれるため、アルゴリズムは正しく削減されます。$d=1$、生産$K$、反射項も次のように折りたたまれます。$K$。 による除算$2$は、二面体グループのサイズが 2 であるという事実を正しく処理します。 

いつ$A_i$が均一である場合、反射は 2 つの構造的に異なる対称タイプに分割されます。 実装ではこれらを明示的に次のように分離します。$K^{n/2+1}$そして$K^{n/2}$、頂点中心の反射とエッジ中心の反射の固定小数点サイクル構造と一致します。 

すべてのセクターのサイズが同じ場合でも、除数の前処理は均一に適用され、異なる半径を結合する対称性がないため、セクター間の乗算によって独立性が維持されます。
