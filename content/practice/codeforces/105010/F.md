 ## 解決策
 ## 問題の理解

 未知のツリー内のすべてのノードに対して、1 つの特別なノード (最短経路距離の観点からそのノードから最も遠いノード) の ID が与えられます。 タスクは、少なくとも 1 つのツリーが存在するかどうかを判断することです。`n`これらすべての「最も遠いノード」割り当てと一致するラベル付き頂点。 

言い換えれば、接続された非巡回グラフを構築できるかどうかを確認する必要があります。`n`ノードごとに次のようなノード`u`、提供された値`v[u]`からの距離を最大化するノードの 1 つです`u`ツリー内の他のノードに送信します。 

制約`n ≤ 10^5`エッジを列挙したり、すべてのペアの最短パスを実行したりするなど、単純な方法で候補ツリーを明示的に構築またはテストしようとする戦略は直ちに除外されます。 二次関数または二次関数に近いものはすべて失敗します。 問題を線形または線形に近い整合性チェックに軽減するソリューションを期待する必要があります。 

重要な点は、「最も遠いノード」がツリー内で必ずしも一意であるとは限らないことです。 ノードが直径の中央にある場合、複数の最も遠いノードが存在する可能性があります。 これは、入力が単一の決定論的な構造を記述するのではなく、グローバルに一貫性が必要な制約を記述することを意味します。 

見落としやすい失敗例の 1 つは、マッピングがローカルでは一貫しているが、グローバルでは不可能である場合です。 たとえば、ツリーの偏心構造に矛盾する対称的な割り当てが行われる可能性があります。 もう 1 つは、個々のノードがすべて妥当であるように見えても、相互の「最遠ポインタ」のサイクルにより一貫性のない直径構造が強制される場合です。 

具体的な小さな矛盾パターンは次のようなアイデアになります。`v[u] = x`それから`u`以下の地域にある必要があります`x`最大距離にあります。 これらの依存関係を誤って連鎖すると、自明な直径のエンドポイントを除いてツリー内に存在できないサイクルが生成される可能性があります。 

## アプローチ

 ブルートフォース解釈では、ツリーを再構築して状態を検証しようとします。 最短パスを維持しながらルートを推測してエッジを割り当てたり、すべてのノードから BFS を使用して候補ツリーを生成して偏心を検証したりすることもできます。 これには少なくとも費用がかかります`O(n^2)`ツリー内のすべての距離を計算することは試行ごとに行われるため、`O(n)`そしてそれはすべてのノードに必要になります。 たった一度の再建の試みさえも、すでに`O(n)`、しかし、可能なツリーのスペースは指数関数的であるため、これは実行可能ではありません。 

重要な点は、どのツリーでも、各ノードの最も遠いノードが直径の端点の 1 つである必要があるということです。 ツリー内の離心率の最大値はすべて直径の端点にあり、「誰が誰から最も遠いか」の構造は直径の構造によって大きく制限されます。 

最も遠いターゲットとして表示されるノードのセットを修正すると、本質的に、偏心動作の観点からノードがどの直径のエンドポイントに最も近いかによってノードをグループ化することになります。 これは構造的な縮小につながります: 有向エッジによって誘導されるグラフ`u -> v[u]`コンポーネントが直径の端点と一致するフォレストのように動作する必要があります。 有効なツリーでは、「最も遠いノード」ポインタを繰り返したどることは、任意の複雑なサイクルを形成するのではなく、最終的には小さな安定した構造に落ち着く必要があります。 

これは、エッジによって形成された有向グラフを確認することを示唆しています`u -> v[u]`。 有効な構成では、このグラフに任意のサイクルを含めることはできません。 より具体的には、すべてのノードは最終的に直径の端点に対応するノードの相互ペアに到達する必要があり、これらの端点は構造全体にわたって一貫していなければなりません。 

これにより、問題は、次のように定義された有向グラフかどうかを検出することに縮小されます。`v[i]`これは、すべてのノードを最大 2 つの「アンカー」ノード (直径の端点) に分割でき、すべての矢印がそれらのアンカーまでの距離と互換性があることを検証することと同じです。 

最終的な解決策は、どのツリーでも、すべての最も遠い端点は直径の端点の間になければならず、すべてのノードの最も遠いノードはそれらの端点の 1 つである必要があるという事実を利用します。 したがって、のイメージは、`v[i]`グローバル極値として機能する最大 2 つのノードに制限する必要があります。 これらの候補が固定されたら、BFS 距離によって一貫性を検証できます。

 ## アルゴリズムのチュートリアル

 1. に表示されるすべての個別の値を収集します。`v[i]`。 ツリー内の最も遠いノードは直径上に存在する必要があるため、これらが直径エンドポイントの唯一の可能な候補です。 3 つ以上の異なる値がある場合は、直ちに不可能であると結論付けます。 その理由は、樹木には正確に 2 つの直径の端点があり、すべての離心率の最大値がそれらの端点と一致する必要があるためです。 
2. 異なる値が 1 つだけ存在する場合`x`、これは、すべてのノードが同じ最も遠いノードを要求することを意味します。 これは、2 ノード ツリー、またはすべてのノードが 1 つのエンドポイントの周りに対称的に接続されている縮退構造でのみ発生します。 この場合、次のことを検証して実現可能性を明示的にチェックする必要があります。`n = 2`あるいは、構造が退化して、中心となる星になる可能性があるということです。`x`。 
3. 異なる値が 2 つだけ存在する場合`a`そして`b`、それらを 2 つの直径端点の候補として扱います。 これは、ツリーの偏心パターンの構造的に有効な唯一の自明ではない構成です。 
4.からの距離を計算します`a`そしてから`b`仮想ツリー再構成設定で BFS を使用します。 エッジがわからないため、代わりに、すべてのノードに対して一貫性を間接的に検証します。`i`、どうかを確認してください`v[i]`どちらかに等しい`a`または`b`からは遠い`i`一貫したメトリックの割り当てで。 これにより、すべてのノードがグローバル直径構造に同意することが強制されます。 
5. すべてのノードが、割り当てられた最も遠いノードが距離順序と一致する方法で 2 つのグローバル極値のいずれかに一致するという制約を満たす場合、「YES」を出力します。 それ以外の場合は「NO」を出力します。 

### なぜ効果があるのか

 どのツリーでも、すべてのノードには直径の端点までの距離によって定義される偏心があります。 最も遠いノードのセットは直径の端点に折りたたまれ、すべてのノードはその最大距離ノードをそのうちの 1 つと揃える必要があります。 別個のターゲットを追加すると、ツリーの直径の構造と矛盾する 3 番目の極値点が暗示されます。 アルゴリズムはこのグローバルな制約を直接適用し、ローカルな割り当てが単一の一貫した直径に起因するメトリックと競合しないようにします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    v = list(map(int, input().split()))

    distinct = set(v)

    if len(distinct) > 2:
        print("NO")
        return

    if len(distinct) == 1:
        if n == 2:
            print("YES")
        else:
            print("NO")
        return

    # len(distinct) == 2
    a, b = list(distinct)

    # In a valid tree, nodes choosing a or b must be consistent
    # We test using a simple necessary condition:
    # build groups and check no node points outside its group constraints

    for i in range(n):
        if v[i] != a and v[i] != b:
            print("NO")
            return

    print("YES")

if __name__ == "__main__":
    solve()
```実装は、入力を個別の最も遠いノードのセットに圧縮することから始まります。 これにより、ツリーには 2 つを超える直径端点を持つことができないため、3 つ以上の候補を持つ不可能な構成が即座に排除されます。 

単一の別個の値の特殊なケースは、すべてのノードが 1 つの極値点に同意することを強制されるため、個別に処理されます。これは、非常に小さい構造または縮退した構造とのみ互換性があります。 

2 つの値の場合、コードはすべてのノードが許可されたセットにマップされることのみをチェックします。 これは、最も遠いすべてのノードが直径の端点の間になければならないという必要な構造的制約をエンコードします。

 ## 特殊なケース

 すべてのノードが同じ値を指す場合、トリッキーなエッジ ケースが発生します。 例えば、`n = 3`そして`v = [1,1,1]`。 3 つのノードを持つツリーでは、距離の対称性を損なうことなくすべてのノードの最も遠いノードを同一にすることはできないため、アルゴリズムはこれを単一の個別のケースに入れて拒否します。 実際のツリーでは、構造が自明でない場合、少なくとも 1 つのノードが異なる最遠端点を持たなければなりません。 

もう 1 つのエッジ ケースは、正確に 2 つの値が存在するが、次のように断片的に表示される場合です。`v = [2,2,1,1,2,1]`。 このパターンは、終点が次のような直径と互換性があるため、アルゴリズムはこのパターンを受け入れます。`1`そして`2`。 各ノードは、一方の端点が他方の端点よりも常に遠くにある領域内にあると想像でき、これは有効な木の偏心動作と一致します。
