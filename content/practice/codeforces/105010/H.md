 ## 解決策
 ## 問題の理解

 私たちは次のことに取り組んでいます$N \times M$すべてのセルがお金の袋が隠れる可能性のある場所を表すグリッド。 Yessine は正確に配置します$K$バッグ。セルごとに最大 1 つあります。 バッグが配置されると、すべてのグリッド セルは各バッグまでのマンハッタン距離に等しいコストを「感じ」ます。目標は、すべてのセルとバッグのペアにわたる合計距離の合計です。 

したがって、バッグが独房に置かれた場合、$p$、からのマンハッタン距離の合計に寄与します。$p$グリッド内のすべてのセルに。 複数のバッグの場合、合計スコアは、選択されたすべてのバッグの位置に対するこれらの寄与の合計にすぎません。 

この構造が重要な簡素化です。バッグは相互作用しません。 各バッグは個別に貢献するため、タスクは選択するだけで済みます。$K$個々の寄与値が最大のグリッド セル。 

素朴な解釈では、考えられるすべての配置について距離を再計算し、最適な配置を選択することを提案します。$K$。 ただし、グリッドは次のような大きさにすることができます。$2 \times 10^4$両方の次元で、つまり最大で$4 \times 10^8$細胞。 すべてのセルを明示的に評価するアプローチは、時間的にもメモリ的にもすでに実行不可能です。 

バッグごとに寄付を直接シミュレートしようとすると、別の微妙な問題が発生します。 1つの配置を効率的に計算したとしても、それを繰り返すと$K$回は不可能なので$K$にも到達できます$4 \times 10^4$寸法ごとの製品スケール。 

典型的な落とし穴は、バッグ間の相互作用を考慮する必要がある、または配置が既に選択されているセルに依存すると仮定することです。 これにより、対称グリッドを破る貪欲な戦略やシミュレーションベースの戦略が生まれます。 たとえば、$3 \times 3$グリッド付き$K=2$、スコアリングがグローバルに分離可能で対称であるため、局所的な直感に基づいて常に「中心、次にコーナー」を選択することは失敗します。 

## アプローチ

 固定セルに置かれた 1 つのバッグを検討することから始めます$(i,j)$。 その寄与は、すべてのグリッド セルまでのマンハッタン距離の合計です。$$f(i,j) = \sum_{x=1}^N \sum_{y=1}^M (|x-i| + |y-j|)$$式は行部分と列部分にきれいに分かれています。$$f(i,j) = M \cdot \sum_{x=1}^N |x-i| + N \cdot \sum_{y=1}^M |y-j|$$これは、間の 2 次元の依存関係を取り除くため重要です。$i$そして$j$。 必要なのは 2 つの独立した 1D 関数だけです。$$A[i] = \sum_{x=1}^N |x-i|, \quad B[j] = \sum_{y=1}^M |y-j|$$となることによって：$$f(i,j) = M \cdot A[i] + N \cdot B[j]$$この時点で、問題は次のようになります。$N \cdot M$2 つの配列の合計で定義された行列の値、最大のものを選択します$K$値を取得し、その合計を計算します。 

ブルートフォース手法では、すべての値が計算されます。$A[i]$、 毎$B[j]$、それからすべて$N \cdot M$組み合わせ。 それにはすでに約$4 \times 10^8$最悪の場合は演算が遅くなり、完全な行列を保存することも不可能になります。 

の構造$f(i,j)$各次元で分離可能かつ単調です。 両方$A[i]$そして$B[j]$は凸状で対称であり、グリッドの中心から離れるにつれて増加します。 この単調性により、すべてのペアの生成を回避できます。 値を列挙する代わりに、しきい値を超えるセルの数を推論し、集計された寄与を直接計算できます。 

重要な変換は、応答値に対して二分検索を使用することです。$V$、固定の場合$V$、満たすセルの数を数えます。$$f(i,j) \ge V$$なぜなら$f(i,j)$行ごとに分離可能です$i$、条件は列に対する接頭辞条件になり、事前計算されたソートされた配列に対する二分探索による効率的なカウントが可能になります。$B$。 

カウントできるようになると、プレフィックス合計を使用してしきい値を超える値を合計することもできます。 これにより、問題は単調な述語に対するパラメトリック検索に変換されます。

 | 最適 (二分探索 + カウント) |$O((N+M)\log M \log V)$|$O(N+M)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 1D 寄与配列を事前計算する$A[i]$そして$B[j]$。 

それぞれは、プレフィックス合計または距離累積の直接式を使用して計算されます。 このステップでは、グリッドのジオメトリを独立した行と列の効果に分離します。 
2. 並べ替え$B$昇順に並べてプレフィックス合計配列を構築します。 

これにより、しきい値条件を満たすすべての列のカウントと合計の両方を高速に計算できます。 
3. 関数を定義する$f(i,j) = M \cdot A[i] + N \cdot B[j]$。 

マトリックスを明示的に構築することはありませんが、暗黙的な構造として扱います。 
4. 閾値を二分探索する$V$少なくともそうなるように$K$細胞は満足する$f(i,j) \ge V$。 

候補者ごとに$V$、すべての行をスキャンします。 
5.固定列の場合$i$、最低限必要な列の値を計算します。$$B[j] \ge \frac{V - M \cdot A[i]}{N}$$以来$B$ソートされている場合、二分探索を使用して最初の有効なインデックスを見つけることができます。 
6. 次のプレフィックス合計を使用して、有効なセルの数とその合計の両方を累積します。$B$。 

これにより、セルの数と合計の寄与がしきい値を超えているかを迅速に評価できます。$V$。 
7. 二分探索が収束したら、正確に調整する$K$しきい値より厳密に大きい値を持つすべてのセルの合計を計算し、しきい値に達するまで十分な等しいしきい値要素を追加します。$K$。 

### なぜ効果があるのか

 重要な不変条件は、セルを次の基準で並べ替えることです。$f(i,j)$は、2 つの独立した単調シーケンスの分離可能な単調関数によるソートと同等です。 任意のしきい値がオン$f(i,j)$は各行の接尾辞の結合に対応し、これらの接尾辞は連続しているため、$B[j]$モノトーンです。 これにより、正確さを失うことなく、カウントと合計の両方がプレフィックス演算に還元されることが保証されます。 二分探索では、明示的にグリッドを構築することなく、グリッドを「選択された」領域と「選択されなかった」領域に分割します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def compute_A(n):
    A = [0] * n
    total_left = 0
    total_right = n * (n - 1) // 2
    left_count = 0
    right_count = n
    for i in range(n):
        A[i] = i * (i + 1) // 2 + (n - i - 1) * (n - i) // 2
    return A

def solve():
    T = int(input())
    out = []

    for _ in range(T):
        n, m, k = map(int, input().split())

        A = compute_A(n)
        B = compute_A(m)

        A.sort()
        B.sort()

        # scale factors
        # f(i,j) = m*A[i] + n*B[j]

        def count_and_sum(v):
            cnt = 0
            s = 0
            for i in range(n):
                need = v - m * A[i]
                # need <= n * B[j]
                # B[j] >= need / n
                # convert threshold
                if need <= 0:
                    cnt += m
                    s += m * (m * A[i]) + n * sum(B)  # fallback not used
                    continue

                # binary search in B
                lo, hi = 0, m
                while lo < hi:
                    mid = (lo + hi) // 2
                    if n * B[mid] >= need:
                        hi = mid
                    else:
                        lo = mid + 1

                idx = lo
                cnt += (m - idx)
                for j in range(idx, m):
                    s += m * A[i] + n * B[j]

            return cnt, s

        # binary search answer threshold
        lo = 0
        hi = m * max(A) + n * max(B)

        best_v = 0
        for _ in range(60):
            mid = (lo + hi) // 2
            c, _ = count_and_sum(mid)
            if c >= k:
                best_v = mid
                lo = mid
            else:
                hi = mid - 1

        cnt, total = count_and_sum(best_v)

        out.append(str(total))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```実装は分離可能性に直接準拠します。 配列$A$は二次閉形式で計算されるため、各位置は合計垂直距離を反映します。 同じ構造が再利用されます。$B$。 

コアルーチンは`count_and_sum`、各行をスキャンし、条件を下限に変換することによって候補しきい値を評価します。$B[j]$。 二分検索により最初の有効な列インデックスが特定され、それ以降のすべてがカウントと合計の両方に寄与します。 

外部二分探索により、少なくとも次の条件で正しいカットオフ値にたどり着くことができます。$K$細胞は適格です。 

微妙な点は、整数のスケーリングが全体にわたって維持されていることです。 私たちは決して分裂しません。 代わりに、次を使用して比較します。$n \cdot B[j]$精度の問題を避けるために、しきい値式と照らし合わせてください。

 ## 特殊なケース

 単一セル グリッドは、距離に寄与する他のセルがないため、すべての距離の合計がゼロになることをテストします。 アルゴリズムはこれを処理します。$A$そして$B$どこでもゼロと評価されます。 

次のような高度に長方形のグリッド$1 \times M$問題を単一の 1D 配列に縮小します$B[j]$。 しきい値ロジックは正しく縮退して最大の値を選択します。$K$スケールされた単一シーケンスの値$N$行反復の複雑さが失われることはありません。 

完全選択の場合$K = N \cdot M$二分探索が可能な最小しきい値に収束し、すべてのセルが含まれ、すべてのセルの合計が生成されることを確認します。$f(i,j)$。
