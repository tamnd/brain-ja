 ## 解決策
 ## 問題の理解

 それぞれが 2 つの整数 x と y で定義される一連のクエリを処理するように求められます。 クエリごとに、シーケンス内の x の直前の y 数値、つまり数値 x-y、x-y+1、...、x-1 を除算しない x の正の約数がいくつあるかを数える必要があります。 y が 0 の場合、先行するチェックすべき数値がないため、答えは単純に x の約数になります。 

入力では最大 100,000 のクエリが可能で、x は 100,000 まで大きくすることができます。 これは、x のすべての約数を単純に反復処理し、クエリごとに最大 x 個の数値と照合するソリューションは遅すぎることを意味します。 関連するすべての以前の数値に対して各クエリのすべての約数を反復する総当り的なアプローチは、10^10 の演算に近づく可能性があり、これは管理不可能です。 数理論的なプロパティを使用して事前計算するか、作業を軽減するソリューションが必要です。 

明らかでないエッジ ケースには、ショートカット状況である y = 0 のクエリや、小さな x 値、特に x = 1 または素数のクエリが含まれます。この場合、約数は自明ですが、正しく処理しないと境界条件が失敗する可能性があります。 もう 1 つのエッジ ケースは、y が x を超える場合ですが、制約によって 0 ≤ y ≤ i-1 が保証されるため、以前の x 値の負のインデックスにアクセスすることはありません。 

## アプローチ

 ブルート フォース アプローチでは、クエリごとに x のすべての約数を列挙し、各約数を y 個の前の数値と比較して、それらのいずれかを割り切れるかどうかを確認します。 クエリごとに、最大 O(sqrt(x)) の除数と最大 O(y) 個の前の数値の積が必要になる可能性があり、最悪の場合、O(n * sqrt(x) * n) ≈ 10^10 回の演算に達します。 これは明らかに遅すぎます。 

重要な観察は、x の約数 d が前の y 数値のいずれかの約数として現れるかどうかだけを知る必要があるということです。 各約数を以前のすべての数値に対して個別にテストする代わりに、各約数について、それが約数として出現した最後のクエリ インデックスのレコードを維持できます。 次に、現在のクエリについて、この最後の出現が最後の y クエリ内にあるかどうかを確認するだけです。 そうであれば、d のカウントをスキップします。 そうでない場合は、d を数えます。 これにより、x の約数を列挙し、約数ごとに単純な検索を実行する作業が軽減されます。これは、各 x の約数が最大でも O(sqrt(x)) であるため、これが実現可能です。 

このアプローチは、事前計算とキャッシュを利用して、潜在的な 2 次チェックを除数ごとの一連の定数時間チェックに効果的に変換します。 これは、賢い状態追跡と組み合わせた数理論的前処理の古典的なアプリケーションです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * sqrt(x) * n) | O(n) | 遅すぎる |
 | 除数の追跡 | O(n * sqrt(x)) | O(max_x) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 可能な最大値 x までのすべての数値の約数を事前計算します。 これを行うには、1 から max_x までを反復し、i のすべての倍数に i を除数として追加します。 これにより、O(max_x * log(max_x)) の前処理が行われます。 各クエリについて、x の約数を即座に取得できます。 
2. 配列または辞書を初期化します。`last_seen`、各約数が出現した最後のクエリ インデックスを保存します。 
3. クエリを順番に処理します。 値 x および y を持つクエリ i の場合、x のすべての約数 d を反復処理します。 
4. 各約数 d について、`last_seen[d]`。 i-y より小さい場合は、d が前の y 数値に現れなかったことを意味し、カウントをインクリメントします。 
5.アップデート`last_seen[d]`x のすべての約数を i に変換し、現在のクエリ インデックスを記録します。 
6. 現在のクエリのカウントを出力します。 

これが機能するのは、次の不変条件があるためです。`last_seen[d]`d が約数である最新のクエリ インデックスを常に保存するため、x-y から x-1 の範囲に現れる約数はすべて正しくスキップされます。 以前の完全な数値ではなくインデックスを追跡することで、繰り返しの除数チェックを回避します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAX_X = 100000

# Precompute divisors for all numbers up to MAX_X
divisors = [[] for _ in range(MAX_X + 1)]
for i in range(1, MAX_X + 1):
    for j in range(i, MAX_X + 1, i):
        divisors[j].append(i)

def main():
    n = int(input())
    last_seen = [0] * (MAX_X + 1)
    
    for idx in range(1, n + 1):
        x_str, y_str = input().split()
        x = int(x_str)
        y = int(y_str)
        
        count = 0
        for d in divisors[x]:
            if last_seen[d] <= idx - y - 1:
                count += 1
            last_seen[d] = idx
        print(count)

if __name__ == "__main__":
    main()
```の`divisors`array を使用すると、x のすべての約数を即座に取得でき、再計算を回避できます。 1 ベースのクエリ インデックスを使用するため、`idx - y - 1`最後に出現した除数が y 個前のクエリの範囲外にあるかどうかを正確に識別します。 更新中`last_seen[d]`チェック後は、次のクエリの正しさを確認します。
