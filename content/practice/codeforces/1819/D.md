 ## 解決策
 ## 問題の理解

 この問題では、一連のリンゴの屋台があり、それぞれが 1 から 2 までの番号が付けられたリンゴの種類のサブセットを販売しています。$m$。 バイヤーのダーニャは、順番に屋台を歩き回り、現在の屋台からリンゴの種類ごとに 1 つずつバックパックに加えます。 ただし、バックパックの中に同じ種類のリンゴが複数ある場合は、店を出るとすぐにすべてのリンゴが消えます。 一部の屋台にはデータが欠落しています。Danya が屋台の品揃えを思い出せない場合、その屋台にはリンゴのサブセットが含まれている可能性があります。 

私たちの目標は、テスト ケースごとに、すべての屋台を訪問した後に Danya のバックパックに残る可能性のあるリンゴの最大数を計算することです。 これは、未知のストールによる不確実性と、重複によって引き起こされる「リセット」条件を伴う組み合わせ問題です。 

制約は次のことを教えてくれます$n$そして$m$それぞれが到達できるか$2 \cdot 10^5$、そして屋台全体のすべてのリンゴ数の合計にも上限があります$2 \cdot 10^5$。 これは、ストールの考えられるすべての組み合わせをシミュレートしたり、すべてのサブセットを明示的に追跡したりすることはできないことを意味します。$O(2^n)$または$O(n \cdot m)$すべてのストールを力ずくで攻撃するのは遅すぎます。 屋台とリンゴの種類の合計に対して、線形または線形に近いアプローチが必要です。 

明らかではないエッジケースには、空のストールまたは未知のストールが含まれます。 たとえば、すべての屋台が不明な場合、最適な戦略により、重複が発生しないようにリンゴを配置することができ、潜在的にすべての屋台を収集できるようになります。$m$リンゴの種類。 逆に、既知のストールが強制的にオーバーラップする場合、余分なリンゴが 1 個でもバックパック全体が消滅し、カウントが最後の空ではないストールのサイズまで減ります。 未知のストールやリセット条件を誤解すると、1 つずつずれたエラーが発生したり、消えるリンゴを数えたりする可能性があります。 

## アプローチ

 強引なアプローチは簡単です。ダーニャが各屋台を訪問する様子をシミュレートし、セット内のリンゴを追跡します。 新しいリンゴを追加すると重複が作成される場合は、バックパックを空にリセットします。 品揃えが不明な屋台の場合、リンゴの考えられるすべてのサブセットを考慮する必要がありますが、単一の未知の屋台によって生成される可能性があるため、これは不可能です。$2^m$可能性。 ブルートフォースは問題のルールを直接反映しているため機能しますが、次のいずれかの場合に失敗します。$n$または$m$未知の屋台や複数のリンゴがある屋台では、すべての可能性をシミュレートするのは指数関数的であるため、 は大きくなります。 

重要な洞察は、未知の屋台については正確なリンゴの種類は必要ないということです。 特定のテスト ケースで重要なのは、「既知の」ストールの数と、それらがカバーする固有のリンゴの種類の数だけです。 ストールが不明な場合は、現在のバックパックと重複しないリンゴのみが含まれていると最適に仮定できます。 これにより、問題は、重複を避けながら蓄積できるリンゴの最大数を数えることに減ります。 未知の屋台は実質的に「ワイルドカード」であり、リンゴの種類の総数の制限まで、リセットをトリガーすることなく常にリンゴを提供できます。$m$。 したがって、ソリューションは、収集されたリンゴの継続的な数を維持し、重複が避けられない場合はリセットし、合計を最大化するために未知の失速を使用するものとして組み立てることができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * m) 未知の失速を伴う最悪の指数関数 | O(m) | 遅すぎる |
 | 最適 | O(テスト ケースごとの k_i の合計) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 各テスト ケースについて、ストールの数を読み取ります。$n$そしてリンゴの種類$m$。 
2. カウンタの初期化`backpack_count`現在バックパックの中に安全に収まっているリンゴの数とブール配列を追跡するため`has_apple`サイズの$m+1$現在存在するリンゴの種類をマークします。 
3. 各ストールを繰り返します。 ストールが既知の場合 (ゼロ以外の値がある場合)$k_i$）、リンゴの種類ごとに確認してください。 If any apple type is already in the backpack, this triggers a reset: set`backpack_count`ゼロにしてすべてクリアする`has_apple`フラグ。 それ以外の場合は、新しいリンゴの種類をバックパックに追加し、存在するものとしてマークします。 
4. ストールが不明な場合 ($k_i = 0$）、最適に処理します。 バックパックにまだ入っていない新しいリンゴの種類が、残りの種類の合計まで提供されると想定できます。$m - backpack_count$。 インクリメント`backpack_count`それに応じて、それらのタイプを存在するものとしてマークします。 
5. すべてのストールを処理した後、`backpack_count`このテスト ケースでバックパックに入れることができるリンゴの最大数です。 
6. すべてのテスト ケースの結果を出力します。 

それが機能する理由: 各屋台で、私たちは現地で最善の決定を下します。 既知のストールでは、重複が存在する場合にリセットが強制される可能性があります。 未知のストールは、常に最適な状態で非重複リンゴを提供できます。 左から右に繰り返し、リセットを正しく適用することで、アルゴリズムは最終的な結果を保証します。`backpack_count`は最大です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    known_stalls = []
    unknown_count = 0
    for _ in range(n):
        arr = list(map(int, input().split()))
        k_i = arr[0]
        if k_i == 0:
            unknown_count += 1
        else:
            known_stalls.append(arr[1:])

    max_apples = 0
    for k_i in known_stalls:
        if set(k_i) & set(range(1, m+1)):
            # if duplicates, they vanish
            max_apples = max(max_apples, len(k_i))
    max_apples += unknown_count
    print(min(max_apples, m))
```コードはまず、既知のストールと未知のストールを分離します。 未知の屋台は、既存のものと競合しないリンゴを追加すると常に想定できるため、カウントされます。 既知のストールごとに、その品揃えのサイズをチェックし、潜在的なリセットを考慮します。 最終的に合計額の上限は$m$なぜなら、すべての種類のリンゴを超えることはできないからです。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(すべてのテスト ケースにわたる k_i の合計) | すべての屋台のすべてのリンゴの種類を 1 回だけ反復します。 
| スペース | O(m) | 各リンゴの種類の存在を追跡します。 

このアルゴリズムは各リンゴを 1 回だけ処理し、リンゴの種類の数を超えて保存することはありません。 の合計$k_i$すべてのテスト ケースで ≤ 2·10^5 であるため、解は 1 秒以内に問題なく適合します。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        known_stalls = []
        unknown_count = 0
        for _ in range(n):
            arr = list(map(int, input().split()))
            k_i = arr[0]
            if k_i == 0:
                unknown_count += 1
            else:
                known_stalls.append(arr[1:])
        max_apples = 0

        max_apples += unknown_count
        output.append(str(min(max_apples, m)))
    return "\n".join(output)
