 ## 解決策
 ## 問題の理解

 2 つの配列が与えられています。`a`そして`b`、長さの`n`ここで、各配列は「良好」です。つまり、配列内のすべての値が少なくとも 2 回出現します。 ミリヤは並び替え可能`a`任意の順序で、新しい配列を計算します。`c`ここで、各要素は、次の対応する要素の合計です。`a`そして`b`。 タスクは、再配置が可能かどうかを判断することです`a`そのような`c`少なくとも 3 つの異なる数字が含まれています。 

制約は控えめです。`n`範囲は 3 ～ 50 で、各要素の大きさは次のとおりです。$10^9$。 小さいもの`n`これにより、最悪の場合でも二次関数となる解を検討することができます。`n`。 テスト ケースの数は最大 1000 であるため、どのソリューションでも合計で最大 50,000 の要素を効率的に処理する必要があります。 

両方の配列に複数回繰り返される 2 つの一意の値のみが含まれる場合、微妙なエッジ ケースが発生します。 たとえば、次の場合`a = [1,1,2,2]`そして`b = [3,3,4,4]`、どんなに並べ替えても`a`の場合、合計が衝突した場合、結果の合計は 2 つの異なる値しか生成しない可能性があります。 もう 1 つのエッジ ケースは、次のようにすべての要素が同一である場合です。`a = [1,1,1]`そして`b = [1,1,1]`、値を 1 つだけ生成します`c`。 

## アプローチ

 素朴なアプローチは、次のすべての順列を試してみることです。`a`そして計算する`c`、次に個別の値をカウントします。 これは正しいですが、非現実的です。`n`最大 50 まで指定できるので、50 個あります。 順列は天文学的に大きい。 

重要な洞察は、すべての順列を探索する必要はないということを理解することから得られます。 各配列は良好であるため、要素が繰り返されており、3 つの異なる合計を生成できるかどうかを確認したいと考えています。 合計の配列を考えてみましょう`c`両方の配列を非降順でソートした後。 極値の合計は、次の最大値をペアにすることによって取得されます。`a`最大のものと`b`そして最小のもの`a`最小のもので`b`。 同様に、最大のペアリング`a`最小の`b`対極を生み出します。 これら 3 つの合計がすべて同じでない場合でも、少なくとも 3 つの異なる合計がすでに保証されています。 

実際には、これにより、問題は合計が以下であるかどうかを確認することになります。`min(a)+min(b)`、`max(a)+max(b)`、 そして`min(a)+max(b)`（または`max(a)+min(b)`）すべてが等しいわけではありません。 これは、ソートにより O(n log n) で実現可能です。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして配列`a`そして`b`。 
3. 両方を並べ替える`a`そして`b`降順ではない順に。 ソートにより、極値の合計を簡単に計算し、衝突の可能性を検出できるようになります。 
4. 3 つの候補の合計を計算します: 最小の合計`c1 = a[0] + b[0]`、最大額`c2 = a[-1] + b[-1]`、および混合両極端の 1 つ`c3 = a[0] + b[-1]`。 
5. これらの合計のセットを作成します。 セットは値を自動的に重複排除します。 
6. セットのサイズが 3 つ以上の場合は、印刷します。`YES`; それ以外の場合は、印刷します`NO`。 

機能する理由: 並べ替えると、次の要素からの最小および最大の寄与が明確に表示されます。`a`そして`b`。 配列が良好であるため、常に重複が存在し、偶発的に少数の異なる合計に分割されるのを防ぎます。 極値をチェックすることで、3 つの異なる合計が達成可能かどうかを判断するために必要なすべての可能な変動を捕捉します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    a.sort()
    b.sort()
    
    sums = {a[0]+b[0], a[-1]+b[-1], a[0]+b[-1]}
    
    if len(sums) >= 3:
        print("YES")
    else:
        print("NO")
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 両方の配列をソートすると、極端な組み合わせを直接選択して個別の合計を確認できるようになります。 セットを使用すると、重複する合計が自動的に処理されます。 このソリューションは、適切な配列の構造と極値和に依存して、不必要な順列を回避します。

 ## 特殊なケース

 すべての要素が同一の場合、次のように`a = [1,1,1]`そして`b = [1,1,1]`、アルゴリズムは次のように計算します。`c1 = c2 = c3 = 2`。 合計のセットのサイズは 1 であるため、出力は次のようになります。`NO`。 いつ`a`そして`b`それぞれ 2 つの繰り返し値が含まれている場合、アルゴリズムは極値の合計を考慮します。`a[0]+b[0]`、`a[-1]+b[-1]`、`a[0]+b[-1]`、可能であれば 3 つの異なる合計を検出できれば十分です。 のために`a = [1,2,1,2]`そして`b = [1,2,1,2]`の場合、合計は 2、4、3 となり、3 つの異なる値が得られます。 これにより、アルゴリズムが特定された微妙なシナリオを正しく処理していることが確認されます。
