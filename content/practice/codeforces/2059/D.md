 ## 解決策
 ## 問題の理解

 同じ頂点セットを共有する 2 つの接続された無向グラフが与えられます。 各グラフには、最初に 1 つの頂点にトークンが配置されます。頂点の最初のグラフでは`s1`そして2番目の頂点で`s2`。 各トークンをそれぞれのグラフの 1 つのエッジに沿って繰り返し移動できます。 各移動には、トークンが移動する頂点の絶対差として定義されるコストがあります。`|u1 - u2|`。 目標は、トークンを無限に移動する場合の最小総コストを決定するか、コストが無限になることを検出することです。 

実際には、トークンを無限に移動させるということは、両方のグラフでトークンが無限に移動できるサイクルを見つける必要があることを意味します。 2 つのシーケンス内の対応する頂点間の絶対差が常にゼロになるようにこれらのサイクルを調整できれば、総コストはゼロのままで済みます。 そうしないと、すべての移動でゼロ以外のコストが発生し、無限数の移動を合計すると無限大になります。 

グラフは小さく、それぞれの頂点とエッジは最大 1000 個で、すべてのテスト ケースの合計も 1000 で制限されます。これにより、制限時間に達することなく、すべての頂点ペア間の最短パスを計算する BFS など、テスト ケースごとに 3 次または 2 次の複雑さを持つアルゴリズムを使用できるようになります。 

2 つのグラフが構造的に同一であるが開始位置が異なる場合、微妙なエッジ ケースが発生し、ゼロ コストで無限の走査を調整することが不可能になります。 たとえば、両方のグラフが長さ 4 の単純なサイクルであるが、トークンが異なる頂点で開始する場合、ゼロコストを維持する一連の動きは存在しないため、答えは次のようになります。`-1`。 不用意なアプローチでは、サイクルでは常にゼロコストの移動が可能であると想定する可能性がありますが、頂点の位置合わせが異なる場合は当てはまりません。 

## アプローチ

 ブルートフォースアプローチは、両方のグラフで考えられるすべての無限シーケンスをシミュレートすることです。 すべての動きのペアを列挙しようとすることもできます。`(u1, u2)`そしてコストを合計します。 これは理論的には正しいですが、可能なシーケンスの数は頂点の数に応じて指数関数的に増加するため、中程度のレベルでも実行不可能です。`n`。 

重要な洞察は、2 つのグラフの頂点間の距離が完全に一致する場合にのみ、総コストが有限のままであるということです。 具体的には、最小総コストは、開始頂点から各グラフ内の任意の頂点までの最小距離によって決定されます。 最初のグラフにその最短経路距離を持つ頂点が少なくとも 1 つ存在する場合、`s1`2 番目のグラフの最短経路距離内の頂点と一致します。`s2`、その後、これらの頂点から始まるサイクルを整列させて、有限の最小コストを達成できます。 それ以外の場合、一連の動きには最終的にゼロ以外のコストが発生するため、コストは必然的に無限になります。 

最短経路距離は次から計算できます。`s1`最初のグラフの他のすべての頂点とそこから`s2`2 番目のグラフの他のすべての頂点に。 これらの距離間の絶対差が最小限になると、無限シーケンスのコストが最小限になります。 これらの差の間にゼロが存在する場合、コストはゼロになる可能性があります。 それ以外の場合、最小の差が各移動で累積するコストを定義し、合計が発散するため、答えは次のようになります。`-1`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * n!) | O(n^2) | 遅すぎる |
 | 最適 | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力を解析し、両方のグラフの隣接リストを作成します。 グラフがまばらであるため、BFS トラバーサルには隣接リストを使用することをお勧めします。 
2. 各グラフについて、開始頂点から BFS を実行して、開始点から他のすべての頂点までの最短距離を計算します。 最初のグラフでは、距離を次のように格納します。`dist1[v]`; 2 番目のグラフでは、距離を格納します`dist2[v]`。 BFS は、重み付けされていないグラフで正しい​​最短パスを保証し、O(n + m) で実行されます。 
3. 変数を初期化する`min_cost`無限に。 すべての頂点を反復処理する`v`1からnまで。 それぞれについて`v`、計算する`abs(dist1[v] - dist2[v])`。 アップデート`min_cost`この値が小さい場合。 これにより、距離の差が最小になる頂点ペアが特定されます。 
4. もし`min_cost`ゼロより大きいままの場合、無限の総コストは避けられないため、出力`-1`。 それ以外の場合は出力`min_cost`、距離を揃えることができればゼロになります。 

機能する理由: BFS は、各開始頂点からの正確な最短パス距離を生成します。 無限のトークンの動きは、頂点を中心としたサイクルに分解できます。 サイクルを調整するコストは、開始位置までの距離の差によって決まります。 この差を最小限に抑えることで、コストを増やさずにトークンを無限に移動できる場合にはそれを確実にキャプチャできます。 このアルゴリズムはすべての頂点を体系的に検査するため、最小差を過小評価することはありません。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

def bfs(n, adj, start):
    dist = [float('inf')] * (n + 1)
    dist[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == float('inf'):
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

t = int(input())
for _ in range(t):
    n, s1, s2 = map(int, input().split())
    
    m1 = int(input())
    adj1 = [[] for _ in range(n + 1)]
    for _ in range(m1):
        a, b = map(int, input().split())
        adj1[a].append(b)
        adj1[b].append(a)
    
    m2 = int(input())
    adj2 = [[] for _ in range(n + 1)]
    for _ in range(m2):
        c, d = map(int, input().split())
        adj2[c].append(d)
        adj2[d].append(c)
    
    dist1 = bfs(n, adj1, s1)
    dist2 = bfs(n, adj2, s2)
    
    min_cost = float('inf')
    for v in range(1, n + 1):
        min_cost = min(min_cost, abs(dist1[v] - dist2[v]))
    
    if min_cost > 0:
        print(-1)
    else:
        print(0)
```コードは、すべてのグラフ情報を読み取り、効率的な走査のために隣接リストを作成することから始まります。 各エッジの重みが同じであり、BFS はノードとエッジで線形であるため、BFS は最短パス距離の計算に使用されます。 距離が計算された後、単純な反復により、達成可能な最小コストを表す最小距離差が計算されます。 小切手`min_cost > 0`これは、不可能な位置合わせを検出することに直接対応します。
