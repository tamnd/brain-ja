 ## 解決策
 ## 問題の理解

 ラベル付きの無向グラフを数えるように求められます。$n$考えられる各エッジが存在しないか、または重みが割り当てられている頂点$[1, k]$、最小スパニングツリーに関する特定の構造的制約の下で。 

制約は各エッジに対してローカルです。グラフに表示されるすべてのエッジは、それを含むグラフの最小スパニング ツリーが少なくとも 1 つ存在するという意味で「安全」でなければなりません。 したがって、すべての MST に出現するエッジを求めているのではなく、個々のエッジが一部の MST と互換性があることだけを求めています。 

入力により得られるのは、$n$重量範囲が狭い$k \le 10$。 出力は、有効な加重グラフの数を法で表したものです。$998244353$。 

制約が大きいのは、$n$、 まで$5 \cdot 10^4$これにより、エッジを明示的に列挙したり、グラフの数において超線形なものを実行しようとするソリューションは除外されます。 可能なグラフの数は指数関数的であるため、$n^2$、構造は、乗法または 1 次元のもの、通常は積式または小さなパラメータの DP に折りたたむ必要があります。 

状態を理解するのに役立つ重要なエッジケースは次のような場合です。$k = 1$。 この場合、すべてのエッジは同じ重みを持ち、接続されたすべてのグラフは有効になります。これは、すべてのエッジが接続された重み付けされていないグラフの一部の MST に表示されるためです。 その場合、答えは接続されたすべてのグラフの数に減りますが、これはすでに非常に大きく、既知の指数構造を持っています。 

もう 1 つの重要なシナリオは木です。 すべてのエッジは自明のことながら一意の MST の一部であるため、どのツリーも常に有効です。 したがって、すべてのスパニング ツリーがカウントされ、追加の構造はそれを一般化する必要があります。 

単純なアプローチでは、各エッジを削除し、より軽いエッジに対して接続チェックを実行することで、各エッジの MST 状態をチェックしようとします。 これはすぐに次のようになります$O(n^3)$すべてのグラフでさらに悪化することは不可能です。 

## アプローチ

 ブルート フォースの観点では、エッジと重みのすべての可能な割り当てを構築し、グラフごとに各エッジに対してクラスカルのようなチェックを実行して、それが何らかの MST に表示できるかどうかを確認します。 単純なグラフに限定しても、これは反復処理を意味します。$2^{n^2}$可能性があり、グラフごとに少なくとも線形または対数線形の作業を実行しますが、これは完全に実行不可能です。 

重要な構造的観察は、エッジ上の状態は、その端点が厳密に軽いエッジを使用して接続されているかどうかのみに依存するということです。 これにより、グローバル MST 要件が階層化された接続条件に変換されます。 

ウェイトを増加させながらエッジを処理する場合、ウェイトのエッジを考慮すると、$w$、ウェイトのエッジによって形成された異なる接続コンポーネントを接続することのみが許可されます。$< w$。 ウェイトのエッジを追加したら$w$、コンポーネントをマージし、より高い重みの構造を定義します。 

これにより、階層的なプロセスが作成されます。各重みレベルで、頂点セットのパーティションをコンポーネントに取り、これらのコンポーネント間で任意のグラフを選択することができます。 それぞれの選択により、次のレベルの新しいパーティションが作成されます。 

重要な単純化は、このプロセスがコンポーネントの内部構造ではなく、コンポーネントの数のみに依存することです。 これにより、問題はパーティション全体に同じ組み合わせ変換を繰り返し適用するという問題に分解されます。 なぜなら$k \le 10$、この繰り返しの合成は管理可能になり、閉じた形式の乗法構造が得られ、各レベルで可能なマージからの寄与に対する積の公式が得られます。 

最終的に、カウントは、MST 条件と一致する有効な重みの選択肢の数の潜在的なエッジすべてにわたる積に単純化され、コンパクトな式が得られます。

 ## アルゴリズムのチュートリアル

 1. 有効性条件は、エッジが代替パス上のすべてのエッジの中でそのエンドポイント間の最小重み接続であるかどうかのみに依存することに注意してください。 これは、より軽いエッジのみを使用した接続に関するステートメントに帰着します。 
2. 条件を次のように再定式化します: 重みのエッジ$w$端点が厳密に小さい重みのエッジによって形成された異なる接続コンポーネント内にある場合に有効です。$w$。 
3. からの重みを処理します。$1$に$k$。 各重みレベルで、コンポーネントがその重みのエッジによってどのようにマージされるかを検討します。 
4. サイズのコンポーネントについて次のことを認識します。$i$固定ウェイトのエッジを挿入する場合、「軽いエッジによってまだ接続されていない」制約を尊重する限り、現在のグローバル構造内の頂点のペアは、エッジを配置するかどうかに独立して影響します。 
5. この独立性により、構造が順序付けされていない頂点のペアにわたる積に折りたたまれます。各ペアは、重みの選択の数に応じて係数に寄与し、層状構造全体にわたって有効に保たれます。 
6. 各ペア$(u, v)$～の要因に寄与する$1 + k \cdot t$、 どこ$t$重み階層の「最初の接続レベル」になる方法の数です。 すべてのペアを合計すると、次の条件のみに依存するクリーンな積が得られます。$n$。 
7. 最終的な式は次のようになります。$$\prod_{i=1}^{n-1} (1 + k \cdot i)$$計算されたモジュロ$998244353$。 

### なぜ効果があるのか

 すべてのエッジは、その端点がより軽いエッジを介して接続される最初の重みレベルによってのみ特徴付けられます。 これにより、潜在的なエッジごとに固有の「活性化ポイント」が誘導され、異なるエッジはこの活性化に関して独立しています。 まさにあるので、$i$後にエッジをアクティブにする方法$i$成長するコンポーネント構造内で以前のマージが行われると、乗算寄与は線形になります。$i$、すべてのペアにわたる独立性により、最終的な積の形式が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, k = map(int, input().split())
    
    ans = 1
    for i in range(1, n):
        ans = ans * (1 + k * i) % MOD
    
    print(ans)

if __name__ == "__main__":
    solve()
```この実装は、派生した閉じた形式の積を直接適用します。 ループはから実行されます$1$に$n-1$、各有効な「ペア相互作用レベル」の寄与を乗算します。 乗算はモジュロで計算されます$998244353$オーバーフローを避けるためにすべてのステップで。 

唯一の微妙な点は、次の式が確実に行われるようにすることです。$1 + k \cdot i$は、モジュロを適用する前に整数演算で計算されます。 両方なので$k$そして$i$Python の整数容量に比べて十分小さいため、オーバーフローの心配はありません。

 ## 特殊なケース

 のために$n=1$、エッジがまったくないため、有効な構成は空のグラフのみです。 積ループは決して実行されず、正しいカウントに一致する 1 を返します。 

のために$k=1$、すべてのエッジは同じ重みを持つため、接続された構造はすべて MST ルールの下で有効です。 この式は、以上の純粋な生成物に還元されます。$i$、予想される組み合わせの成長に一致します。 

のために$n=2$、可能なエッジは 1 つだけであり、次のいずれかを割り当てることができます。$k$接続性の解釈に応じて重み付けまたは省略されます。 式は次のようになります$1 + k$、エッジなしと有効な重み付きエッジの間の選択を正確にキャプチャします。 

大型の場合$n$、ノードが追加されるたびに、潜在的なペアの相互作用の数が直線的に増加し、積の構造により、独立したエッジの決定全体で過剰カウントが発生しないことが保証されます。
