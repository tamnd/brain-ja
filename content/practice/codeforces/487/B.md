 ## 問題の理解

 紙片上の数値を表す整数の配列があります。 アレクサンドラは、ストリップを連続したセグメントに分割したいと考えています。 各セグメントには少なくとも`l`そのセグメントの最大値と最小値の差は以下を超えてはなりません。`s`。 私たちのタスクは、これらの制約を満たす最小数のセグメントを見つけることです。 配列を分割できない場合は、-1 を返します。 

入力サイズ`n`最大100,000まで可能です。 配列を分割する方法の数が指数関数的に増加するため、考えられるすべてのセグメンテーションを徹底的にチェックするソリューションはすぐに除外されます。 たとえ`O(n^2)`アプローチが遅すぎるため、`n^2`100億回のオペレーションに達する可能性があります。 したがって、アルゴリズムは大まかに実行する必要があります`O(n log n)`または`O(n)`時間。 

エッジケースには、すべての要素が同じで、可能な限り最小のセグメント長である配列が含まれます。`l`等しい`n`、または範囲制約`s`小さすぎてどのような長さのセグメントも許可できません`l`。 たとえば、入力の場合`n=3, s=0, l=2, a=[1,2,3]`、正しい出力は次のとおりです。`-1`長さ 2 のセグメントは範囲制約を満たすことができないためです。 単純な実装では、範囲を正しくチェックせずに貪欲にセグメントを形成しようとし、無効な分割が生成される可能性があります。 

## アプローチ

 ブルート フォース ソリューションでは、各位置から開始し、その後の各位置で終了する可能性のあるすべてのセグメントが考慮され、長さと範囲の制約がチェックされます。 セグメントが有効な場合、残りの配列のセグメントの最小数が再帰的に計算されます。 このアプローチは原理的には機能しますが、すべての O(n²) セグメントをチェックする必要があり、数十億回の操作が必要になる可能性があります。`n=10^5`、それは不可能です。 

最適なソリューションに対する重要な洞察は、セグメントのソリューションを観察することで得られます。`[i..j]`、セグメントは次の場合にのみ有効です。`j-i+1 >= l`そして`max(a[i..j]) - min(a[i..j]) <= s`。 配列が固定され、セグメントが連続しているため、2 つのデータ構造 (通常は単調なキュー) を維持して、スライディング ウィンドウ内の最小値と最大値を効率的に追跡できます。 特定の開始点に対する有効なセグメントの終点がすべてわかったら、問題は動的プログラミング、つまり位置で終了するセグメントの最小数に帰着します。`i`は`1 + min(dp[j])`以前の有効なセグメントの開始全体にわたって`j`。 

2 つの手法を組み合わせます。ステップごとに償却される O(1) の範囲制約を維持する単調キューを備えたスライディング ウィンドウと、以前の最小値を効率的に計算するセグメント ツリーまたはバランス キューを使用した動的プログラミングです。`dp`価値。 これにより、`O(n)`解決。

 ## アルゴリズムのチュートリアル

 1. を初期化します。`dp`配列`dp[i]`プレフィックスをカバーするセグメントの最小数を表します`a[0..i]`。 を除くすべての値を無限大に設定します。`dp[-1] = 0`空のプレフィックスの場合。 
2. 2 つの単調なキューを維持します。`minq`そして`maxq`、現在のスライディング ウィンドウの最小値と最大値を追跡します。 
3. 右ポインタを使用して配列を反復処理します。`r`。 新しい要素ごとに、単調性を維持しながら両方のキューにプッシュします。 
4.窓を閉めながら`[l..r]`制約に違反します`max - min > s`、左ポインタを進めます`l`必要に応じてキューからポップします。 
5. ウィンドウが有効になり、その長さが少なくとも`l`、 アップデート`dp[r]`と`dp[l-1] + 1`(または最小限の`dp[j]`有効なウィンドウ内) を使用して、セグメントをもう 1 つ追加することを表します。 
6. 配列の最後まで続けます。 もし`dp[n-1]`無限大のまま、出力`-1`。 それ以外の場合は出力`dp[n-1]`。 

機能する理由: 単調キューは、あらゆるウィンドウの真の最小値と最大値を効率的に維持します。 DP は最小限の分割のみを考慮することを保証し、スライディング ウィンドウはサイズと範囲の両方の制約を尊重することを保証します。 この組み合わせにより、ソリューションが正確かつ最小限であることが保証されます。 

## Python ソリューション```python
import sys
from collections import deque
input = sys.stdin.readline

n, s, l = map(int, input().split())
a = list(map(int, input().split()))

INF = n + 1
dp = [INF] * n
minq = deque()
maxq = deque()
best = deque()

for i in range(n):
    while minq and a[minq[-1]] >= a[i]:
        minq.pop()
    minq.append(i)
    while maxq and a[maxq[-1]] <= a[i]:
        maxq.pop()
    maxq.append(i)
    
    if i >= l - 1:
        left = i - l + 1
        while minq and minq[0] < left:
            minq.popleft()
        while maxq and maxq[0] < left:
            maxq.popleft()
        
        while best and best[0] < left:
            best.popleft()
        if left == 0:
            dp[i] = 1
        elif best:
            dp[i] = dp[best[0]] + 1
        
        while best and dp[i] <= dp[best[-1]]:
            best.pop()
        best.append(i)

for val in dp:
    if val != INF:
        res = dp[-1]
        break
else:
    res = -1
print(res)
```このソリューションは配列を読み取り、DP およびモノトニック キューを初期化します。 各インデックスは、現在の最小値と最大値を効率的に維持します。 私たちは更新するだけです`dp[i]`少なくとも有効なセグメントがある場合`l`で終わるものが存在します`i`。 デック`best`最小限の以前の追跡に役立ちます`dp`効率的に価値を高めます。 境界チェックにより、正しいインデックスが保証されます。
