 ## 解決策
 ## 問題の理解

 整数を取得するように求められます$n$それを正確に分割します$k$ビットごとの XOR が等しい非負の整数$n$。 このようなすべての分割の中で、数値の合計が最大になるものが必要です。 分割内の各数値は 0 ～$n$包括的な。 入力は複数のテスト ケースを提供し、それぞれが独自のテスト ケースを指定します。$n$そして$k$。 

制約は大きくなります。$n$到達できる$10^9$そして$k$到達できる$10^5$、合計で$k$すべてのテストケースにわたって、以下に限定されます$10^5$。 分割する方法は指数関数的に多く存在するため、これにより、考えられるすべてのシーケンスを試行する総当り的なアプローチが排除されます。$n$XORの下で。 相対的に線形または対数時間で機能するソリューションが必要です。$k$とビット数$n$。 

明らかではないエッジケースが発生するのは次の場合です。$k = 1$。 ここで有効な因数分解は次のとおりです。$a_1 = n$、したがって、合計は自明です$n$。 もう一つの微妙な状況は次のような場合です。$k \ge 2$しかし$n$非常に小さいです、例えば$n = 1$そして$k = 2$。 試してみたくなるかもしれません$1 \oplus 0$ただし、合計を最大化するには、2 のべき乗を複製し、ゼロを適切に分散することを考慮する必要があります。 

## アプローチ

 単純な総当たり手法では、次のすべてのシーケンスを生成します。$k$0 から 0 までの数字$n$、XOR を確認し、合計を追跡します。 これは正しいですが、実行不可能です。 のために$k = 10^5$そして$n = 10^9$、 がある$(n+1)^k$配列は天文学的に膨大です。 1 つのテスト ケースでも宇宙年齢より長くかかるため、この方法は遅すぎます。 

重要な洞察は、XOR がビット単位でビット間で独立して動作するということです。 数値の合計を最大化するには、XOR の結果を維持しながら、できるだけ多くの数値に可能な限り高い値を与えるようにする必要があります。 実際には、これは配布に帰着します。$n$の間で$k$番号を慎重に複製し、場合によっては残りの位置を埋めるためにゼロを使用します。 具体的には、$k = 1$、答えは$n$。 もし$k = 2$、選択できます$n$そして$0$。 大型の場合$k$、私たちは壊れることができます$n$を 2 の累乗にし、到達するまで最大の累乗を複製します。$k$数字。 

もう 1 つの有益な観察は、次のような場合です。$k > 1$、いつでも分割できます$n$の中へ$n$それ自体プラス$k-1$ゼロ。 これは XOR 要件を満たし、合計が次の値になることが保証されます。$n$, しかし、同じ数値を複数回使用して合計を増やすことでこれを改善できます。 たとえば、次の場合$n$は均等であり、$k \ge 2$、シーケンス$n/2, n/2, 0, ..., 0$より大きい合計を与える$n$まだ XOR を実行している間$n$。

 ## アルゴリズムのチュートリアル

 1.読む$t$、テストケースの数。 各テストケースの読み取りを反復処理します。$n$そして$k$。 各テスト ケースの結果シーケンスが必要です。 
2. もし$k = 1$、出力$[n]$直接。 これが自明な因数分解です。 
3. もし$k = 2$、出力$[n, 0]$。 の XOR$n$そして0は$n$、合計は$n$、すべての数値が有効です。 
4. もし$k \ge 3$そして$n$奇数です、分割されています$n$の中へ$1, 1, n-2$残りの位置をゼロで埋めます。 XOR が機能する理由は、$1 \oplus 1 = 0$、$0 \oplus (n-2) = n-2$、 そして$0 \oplus ... = n-2$、 それから$n-2 \oplus 2 = n$。 
5. もし$k \ge 3$そして$n$均等、分割$n$の中へ$n/2, n/2, 0$残りの位置をゼロで埋めます。 XOR が機能する理由は、$n/2 \oplus n/2 = 0$、 それから$0 \oplus 0 = 0$, したがって、次までゼロを追加します。$k$数字。 合計は複製されたものを使用して最大化されます$n/2$。 

ここでの不変条件は、シーケンスの XOR が常に再現されることです。$n$、ゼロを埋めながら数値を複製すると、合計が最大になります。 どの数値を複製するかを慎重に選択することで、合計を増やしながら XOR 要件を維持します。 これにより正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        if k == 1:
            print(n)
            continue
        if k == 2:
            print(n, 0)
            continue
        # k >= 3
        if n % 2 == 1:
            # n odd: split as 1,1,n-2 + zeros
            res = [1, 1, n-2] + [0]*(k-3)
        else:
            if k % 2 == 1:
                # n even, k odd: split as n/2,n/2,0 + zeros
                res = [n//2, n//2, 0] + [0]*(k-3)
            else:
                # n even, k even: split as 2,2,n-4 + zeros
                res = [2, 2, n-4] + [0]*(k-3)
        print(*res)

solve()
```コードはテスト ケースの数を読み取り、それぞれを反復処理します。 小型用$k$些細な分割を処理します。 のために$k \ge 3$、パリティ推論を使用します。$n$は奇数なので、2 つの 1 と残りから始めます。 もし$n$が偶数であれば、均等に分割できます。 残りの数値は正確に到達するようにゼロで埋められます$k$。 整数除算を使用すると、小数が導入されなくなります。
