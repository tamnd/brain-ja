 ## 問題の理解

 私たちは整数格子点のグリッドに取り組んでいます。$(N+1)\times(N+1)$四角。 これらのグリッド ポイントの一部は、供給拠点としてマークされています。 各拠点が選択される可能性は同等です。 これとは別に、Tanya の開始位置も一様にランダムなグリッド ポイントです。 両方の選択が行われた後、彼女はマンハッタン距離を使用して選択した拠点に移動します。これは、距離が絶対的な水平座標と垂直座標の差の合計であることを意味します。 

このタスクは、ランダムなグリッド点とランダムな供給点の間の期待されるマンハッタン距離を計算することです。期待値は、1 つの任意のグリッド点と 1 つの指定された供給点で構成されるすべてのペアにわたって、両側で均一の確率で取得されます。 

出力は、期待値の生の有理値ではありません。 代わりに、その期待値のモジュラー表現を法 998244353 で計算する必要があります。具体的には、期待値が分数に単純化された場合、$x/y$、のモジュラー逆形式を出力する必要があります。$y$回$x$、これは以下と同等です$x \cdot y^{-1} \bmod 998244353$。 

制約は非常に大きく、両方とも$N$そして$M$200万まで。 各供給点のすべてのグリッド ポイントを反復する単純なアプローチでは、次のオーダーが必要になります。$O(N^2 M)$、それは完全に不可能です。 すべての格子点に明示的に触れるものであっても不可能です。 ソリューションでは、グリッドの列挙を回避し、代わりにマンハッタン距離の分離性と座標寄与の対称性を利用する必要があります。 

供給ポイントが 1 つしかない場合、微妙なエッジ ケースが発生します。$(0,0)$そして$N=2$。 グリッドには 9 つのポイントが含まれており、平均距離は供給ポイント間の距離から計算されるのではなく、すべてのグリッド ポイントからその単一の補給所までの距離から計算されます。 よくある間違いは、誤ってグリッドから電源までの距離ではなく、電源から電源までの距離を平均してしまうことで、誤ってゼロが得られてしまいます。 正しい解釈には、常にすべてのグリッド ポイントが開始位置として含まれます。 

もう 1 つのエッジ ケースは、すべての供給ポイントが直線上にある場合です。$y=0$。 単純な分解では、ポイント数による適切な重み付けが行われずに x と y が独立して処理され、不正確なスケーリングが発生する可能性があります。 独立性は有効ですが、グリッド全体にわたる寄与を正しく合計した場合に限られます。 

## アプローチ

 強引な解釈は簡単です。供給ポイントごとに、そのポイントからすべてのグリッド ポイントまでのマンハッタン距離の合計を計算し、すべてのグリッド ポイントとすべての供給ポイントの平均を計算します。 これは定義と直接一致します。 ただし、1 つの点からすべての点までの距離を計算すると、$(N+1)^2$グリッドポイントのコスト$O(N^2)$、そしてこれを行うのは$M$供給ポイントは、$O(MN^2)$、これは実現可能な限界をはるかに超えています。 

重要な構造観察は、マンハッタン距離が独立した x 寄与と y 寄与に分割されることです。 固定供給ポイントの場合$(x_i, y_i)$、すべてのグリッド点の合計は、すべての x 座標の合計とすべての y 座標の合計として分解されます。 具体的には、合計貢献度を次のように書き換えることができます。$$\sum_{x=0}^{N}\sum_{y=0}^{N} (|x-x_i| + |y-y_i|)$$これは次のように分かれます。$$\sum_{x=0}^{N}(N+1)\cdot |x-x_i| + \sum_{y=0}^{N}(N+1)\cdot |y-y_i|$$したがって、各次元は独立して処理でき、次のように乗算できます。$(N+1)$、そして結合します。 

これにより、各供給座標値の計算の問題が軽減されます。$a$、合計$\sum_{t=0}^N |t-a|$。 これは、接頭辞演算を使用して定数時間で計算できます。 

残りの値$a$三角和とその右側の値に寄与します。$a$別の貢献をします。 

これを供給ポイントごとに計算できるようになると、$O(1)$、完全なソリューションはで実行されます$O(M)$。

 ## アルゴリズムのチュートリアル

 まず定数を前処理します$(N+1)$すべてのグリッド座標の数がそれに依存するためです。 主なタスクは、均一な整数範囲での差の絶対値の合計を評価することです。 

供給ポイントごとに$(x_i, y_i)$では、マンハッタン距離は次元間で加算され、グリッドはデカルト積であるため、2 つの独立した寄与 (x に 1 つと y に 1 つ) を計算します。 

1. 座標値の場合$a$、範囲を分割します$[0, N]$2 つの部分に分割: 左側$[0, a]$そして右側$[a, N]$。 絶対値は定義を変更するため、この分離が必要です。$a$。 
2. 左の寄与を次の合計として計算します。$a - t$みんなのために$t \le a$。 これは等差数列であり、閉じた形式は次のとおりです。$\frac{a(a+1)}{2}$。 これは、左またはそれと等しい点からの合計距離を表します。$a$。 
3. 正しい寄与を次の合計として計算します。$t - a$みんなのために$t \ge a$。 これも等差数列であり、次と等しくなります。$\frac{(N-a)(N-a+1)}{2}$。 
4. 両方の部分を追加して、座標の合計 1D 寄与を取得します。$a$。 
5. この 1D の結果に次の値を掛けます。$(N+1)$各 x 位置には$(N+1)$独立した y の選択、またはその逆。 
6. 各供給点の x 座標と y 座標の両方について繰り返し、すべての供給点にわたって結果を累積します。 
7. グリッド点の総数で割ります。$(N+1)^2$998244353 の下でモジュラー逆数を乗算します。 

### なぜ効果があるのか

 正確さは、マンハッタン距離の合計の直線性と分離可能性から得られます。 すべてのグリッド ポイントは、ちょうど 1 つの x 項と 1 つの y 項に寄与し、これらの寄与は相互作用しません。 グリッド構造により各座標値の多重度が均一になるため、1D 分解で完全な 2D 合計が正確に取得されます。 一様平均以外の近似や確率的議論は使用されません。 代数分解では正確な等価性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    N, M = map(int, input().split())
    total = 0
    size = N + 1

    for _ in range(M):
        x, y = map(int, input().split())

        lx = x * (x + 1) // 2
        rx = (N - x) * (N - x + 1) // 2
        ly = y * (y + 1) // 2
        ry = (N - y) * (N - y + 1) // 2

        sx = lx + rx
        sy = ly + ry

        # each coordinate repeats (N+1) times across the other axis
        total += (sx + sy) * size

    total %= MOD

    denom = (size * size) % MOD
    ans = total * modinv(denom) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```コードはまずグリッドのサイズと供給ポイントの数を読み取ります。 各供給点について、等差数列の公式を使用して、x と y の距離の 1 次元の合計を個別に計算します。 これらを組み合わせて乗算すると、$N+1$直交軸全体の完全なグリッド複製を考慮します。 累積合計は、正規化前のグリッド ポイントと供給ポイントのすべてのペアにわたる合計距離を表します。 

最後に、による除算$(N+1)^2$期待値は大きな素数法のもとでの有理数であるため、逆モジュラーを使用して実行されます。 精度の問題を避けるために、累積後にのみ係数を適用するように注意してください。 

## 実用的な例

 次のサンプルを考えてみましょう$N=2$単一の供給ポイント$(0,0)$。 

この点について、x の寄与は次のようになります。$\sum_{t=0}^2 |t-0| = 0 + 1 + 2 = 3$。 yについても同様です。 それぞれを乗算します$N+1=3$、したがって、合計貢献度は$3 \cdot 3 + 3 \cdot 3 = 18$。 格子点の総数は 9 なので、期待値は次のようになります。$18/9 = 2$。

 これにより、分解により 9 つのグリッド距離すべてが列挙されずに正しくキャプチャされることが確認されます。 

ここで考えてみましょう$N=3$に供給ポイントがある$(2,1)$。 

x の場合、距離は次のようになります。$|0-2|+|1-2|+|2-2|+|3-2| = 2+1+0+1 = 4$。 y の場合、距離は次のようになります。$|0-1|+|1-1|+|2-1|+|3-1| = 1+0+1+2 = 4$。 それぞれを乗算します$4$、合計は$32$。 16 格子点で割ると期待値が得られます$2$。
