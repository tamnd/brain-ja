 ## 解決策
 ## 問題の理解

 値の配列に対する制約システム (都市ごとに 1 つの値) が与えられています。 各都市$i$負ではない整数があります$x_i$、その都市の友達の数を表します。 入力は、都市のペア間の関係を記述します。各関係によって差異が制限されます。$x_a - x_b$3 つの方法のいずれかで、少なくとも一定の値、最大でも一定の値、またはまったく同じ値にすることができます。 

タスクは、すべての制約を満たす割り当てを見つけることではなく、有効な割り当てが存在するかどうかを判断し、存在する場合は、すべての都市にわたる友人の最小可能総数を計算することです。 

したがって、概念的には、差分制約の下でノードに値を割り当てており、すべての実行可能な割り当ての中で最小化するものが必要です。$\sum x_i$、暗黙の制限付きで、すべて$x_i \ge 0$。 

制約は、不等式の有向構造を暗示します。 下限制約$x_a - x_b \ge c$力$x_a \ge x_b + c$。 上限制約$x_a - x_b \le c$次のように書き換えることができます$x_b \ge x_a - c$。 平等とは単に両方向を強制するだけです。 

制約$n, m \le 1000$そして$T \le 50$と提案する$O(nm)$または$O(nm \log n)$テストごとの解は許容されますが、テストごとに 3 次のものは遅すぎます。 

微妙な問題は、システムには固定の基準点がないことです。 解決策が存在する場合は、すべてをシフトします$x_i$定数を使用すると、すべての違いが保存されます。 これは、ソリューションを固定するには非否定性要件に依存する必要があることを意味します。 

典型的なエッジ ケースは、制約が正の合計ゲインを持つサイクルを形成する場合に発生します。次に例を示します。$x_1 \ge x_2 + 1$、$x_2 \ge x_1 + 1$。 これはつまり、$x_1 \ge x_1 + 2$、それは不可能なので、答えは次のようになります。$-1$。 

もう 1 つのエッジ ケースは、すべての制約が一貫しているにもかかわらず、変数を非常に大きくすることを強制しており、制約の伝播を無視する単純な試みにより、誤ってすべて 0 が割り当てられる場合です。 

## アプローチ

 ブルート フォース アプローチでは、すべての都市に値を割り当て、すべての制約が満たされるかどうかを確認しようとします。これには、考えられるすべての割り当てをある限界まで繰り返すことが考えられます。 値を妥当な範囲に制限したとしても、検索スペースは指数関数的に増加します。$n$、各変数は不等式を通じて他の変数に依存するためです。 これは非常に小さいものを超えるとすぐに実行不可能になります$n$。 

重要な観察は、すべての制約が、差の下限を表す重みを持つ有向グラフのエッジとして書き換えられるということです。 例えば、$x_a \ge x_b + c$エッジのように動作する$b \to a$重さで$c$。 私たちは基本的に、すべてのエッジが強制するような値を割り当てようとしています。$x_v \ge x_u + w$。 

これはまさに、サイクルを含む可能性のあるグラフにおける最長経路緩和問題です。 すべての下限制約を満たす最小値が必要です。これは、各ノードに到達するすべての制約チェーンの最大値を見つけることに相当します。 重み 0 のすべてのノードに接続されたスーパー ソースを導入すると、最長パスに対するベルマン フォード スタイルの緩和を使用して、各ノードの実現可能な最大の下限を計算できます。 

リラックス中に、その後も距離を伸ばすことができる場合$n$反復すると、これは正のサイクルを示し、システムに一貫性がないことを意味します。 

もう一度$x_i$が実行可能な最小値として決定されると、答えはこれらの値の合計になります。

 | ブルートフォース | 指数 | O(n) | 遅すぎる |

 ## アルゴリズムのチュートリアル

 すべての制約を有向重み付きエッジに変換し、緩和を使用して実現可能な最大値を計算します。 

1. グラフを作成します。$n$ノードを追加し、スーパーソースノードを追加します$0$。 ノードを接続する$0$あらゆる都市へ$i$重量のあるエッジで$0$、 意味$x_i \ge 0$。 これにより、非否定性が強制されます。 
2. 制約ごとに$x_a - x_b \ge c$、有向エッジを追加します$b \to a$重さで$c$。 これはそれをエンコードします$x_a$少なくとも$x_b + c$。 
3. 制約ごとに$x_a - x_b \le c$、次のように書き換えます$x_b - x_a \ge -c$、有向エッジを追加します$a \to b$重さで$-c$。 これにより、同じフレームワークで上限が確実に適用されます。 
4. 等価制約の場合$x_a = x_b$、両方を追加します$a \to b$そして$b \to a$重みのあるエッジ$0$。 これにより、両方の変数が強制的に等しくなります。 
5. すべての距離を初期化する$dist[i]$に$0$、スーパー ソースではすべてのノードが少なくとも 0 になることが許可されているためです。 
6.ベルマン・フォード・リラクゼーションを実行する$n$すべてのエッジにわたる反復、更新$dist[v] = \max(dist[v], dist[u] + w)$。 このステップでは、すべての制約チェーンを通じて最も強い下限を伝播します。 
7. すべてのエッジに対して追加の反復を 1 回実行します。 距離をまだ改善できる場合は、プラスのサイクルが存在し、制約に一貫性がないことを意味し、答えは次のようになります。$-1$。 
8. 矛盾が検出されない場合は、すべての値の合計として最終的な答えを計算します。$dist[i]$のために$1 \le i \le n$。 

最短パスではなく最大緩和を使用する理由は、制約によって上限ではなく下限が定義されるため、すべての制約が満たされるまで値を押し上げる必要があるためです。 

### なぜ効果があるのか

 各緩和ステップでは、長さが増加するパスに沿ってすべてのノードがすべての制約を遵守するように強制されます。 後$n$反復により、すべての単純なパスが考慮されているため、さらなる改善は価値を無限に増加させるサイクルから得られる必要があります。 それはまさに制約システムの矛盾に相当します。 すべての変数は、ゼロ ベースラインから始まる制約チェーンによって暗示される最も強い強制値に設定されるため、結果として得られる距離は、すべての下限を満たす最小の割り当てを形成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = 10**18

def solve():
    n, m = map(int, input().split())
    
    edges = []
    
    # super source: x_i >= 0 is already handled by initial 0 distances
    
    for _ in range(m):
        tmp = list(map(int, input().split()))
        t = tmp[0]
        
        if t == 1:
            a, b, c = tmp[1], tmp[2], tmp[3]
            # x_a - x_b >= c => b -> a (c)
            edges.append((b, a, c))
        elif t == 2:
            a, b, c = tmp[1], tmp[2], tmp[3]
            # x_a - x_b <= c => x_b - x_a >= -c => a -> b (-c)
            edges.append((a, b, -c))
        else:
            a, b = tmp[1], tmp[2]
            edges.append((a, b, 0))
            edges.append((b, a, 0))
    
    dist = [0] * (n + 1)
    
    # Bellman-Ford (max version)
    for _ in range(n):
        changed = False
        for u, v, w in edges:
            if dist[v] < dist[u] + w:
                dist[v] = dist[u] + w
                changed = True
        if not changed:
            break
    
    # detect positive cycle
    for u, v, w in edges:
        if dist[v] < dist[u] + w:
            return -1
    
    return sum(dist[1:])

def main():
    T = int(input())
    out = []
    for _ in range(T):
        out.append(str(solve()))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```この実装では、すべての制約を有向重み付けエッジとして均一に保存します。 各エッジは他のノードを上方に締め付けることができる下限を表すため、緩和は最大化形式で行われます。 緩和ループ内で早期に終了すると、システムがすぐに安定するときに不必要な反復が防止されます。 

よくある間違いは、これを最短パスとして扱うことです。 これにより、制約の意味が逆転し、下限ではなく上限を満たす値が生成され、実現可能性が損なわれます。 

## 実用的な例

 制約が一貫したチェーンを形成する 3 つの都市からなる小規模なシステムを考えてみましょう。$x_1 \ge x_2 + 1$、$x_2 \ge x_3 + 2$、 そして$x_3 \ge 0$。 

| 反復 | 距離[1] | 距離[2] | 距離[3] | 説明 |
 | --- | --- | --- | --- | --- |
 | 初期化 | 0 | 0 | 0 | すべてはゼロから始まります |
 | 1以降 | 0 | 0 | 0 | 強いエッジはまだ支配的ではありません |
 | アフター2 | 0 | 2 | 0 | から$x_2 \ge x_3 + 2$|
 | アフター3 | 3 | 2 | 0 | から$x_1 \ge x_2 + 1$|

 最終的な合計は$3 + 2 + 0 = 5$。 

これは、拘束がどのように逆方向に伝播し、チェーンに沿って蓄積するかを示しています。 

次に、一貫性のないシステムを考えてみましょう。$x_1 \ge x_2 + 1$、$x_2 \ge x_1 + 1$。 

| 反復 | 距離[1] | 距離[2] | 説明 |
 | --- | --- | --- | --- |
 | 初期化 | 0 | 0 | 開始 |
 | 1以降 | 1 | 1 | 両方のエッジで値が増加します。 
| アフター2 | 2 | 2 | まだ増加中 |
 | チェック | サイクル | サイクル | さらなる改善が存在します |

 これは、相互の強化が無限の増加を生み出し、それが正のサイクルとして検出されることを示しています。

 ## 特殊なケース

 重要なエッジ ケースは、すべての変数が不等式によってのみ制約されるが、暗黙の非負性を介する場合を除いて直接ゼロに結び付けられることがない場合です。 たとえば、エッジがまったくない場合、すべてのノードはゼロのままとなり、答えはゼロになります。 緩和が発生しないため、アルゴリズムはこれを自然に処理します。 

もう 1 つのケースは、大きな平等のサイクルです。 等価性は 2 つの重みゼロのエッジとして表現されるため、距離は増加せず、システムは安定したままになります。 他の制約が強制的に増加しない限り、最終的な合計はゼロのままです。 

最後の微妙なケースは、制約が遠くのノードにのみ影響を与える長いチェーンを形成する場合です。 緩和ベースの伝播により、間接的な依存関係であっても最大で 1 回以内に完全に考慮されることが保証されます。$n$なぜなら、すべての意味のあるパスの長さはノードの数によって制限されるからです。
