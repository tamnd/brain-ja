 ## 解決策
 ## 問題の理解

 を構築するように求められています。$n \times n$素数を法とする剰余体上の行列$n$。 すべてのエントリは範囲内の整数である必要があります$0$に$n-1$、対角線はすでに固定されています。$i$- 番目の対角要素は次と等しくなければなりません$b_i$。 

主な制約は、個別の行のすべてのペアと個別の列のすべてのペアに対する強力な反加法性条件です。 任意の 2 行を取ると$r_1 < r_2$および任意の 2 つの列$c_1 < c_2$の場合、行列は等式を回避する必要があります。$$a_{r_1,c_1} + a_{r_2,c_2} \equiv a_{r_1,c_2} + a_{r_2,c_1} \pmod n.$$これはまさに、すべてのことを言っているのです$2 \times 2$部分行列は古典的な「相互和の等価性」モジュロを満たしてはなりません$n$。 同様に、そのような部分行列はすべて、有限体に対する非ゼロの行列式を持たなければなりません。$\mathbb{F}_n$。 

したがって、タスクは、所定の対角を持ち、すべての$2 \times 2$マイナーは非退化です。 

制約$n < 350$余裕があるという意味$O(n^2)$あるいは$O(n^2 \log n)$建設物。 インデックスの 4 倍体すべてにわたる 3 次のものは、次のようなものがあるため、非常に遅すぎます。$O(n^4)$制約。 

素朴なアプローチの微妙な失敗例は、ランダムな埋め込みを試みることです。 たとえば、行ごとにランダムな値を個別に選択すると、誤って縮退した値が生成されることがよくあります。$2 \times 2$部分行列。 制約はグローバルで二次的な構造であるため、対角のエントリを修正してもこれらの衝突は防止できません。 

もう 1 つの素朴な試みは、行を固定対角エントリを持つ任意のベクトルとして独立して扱うことです。 この条件は行と列のペアを同時に結合するため、これも失敗します。 

主な難点は、この条件が行や列に対してローカルではなく、グローバルなランクのような構造を強制することです。 

## アプローチ

 強引なアイデアは、行列をセルごとに埋めてみて、各代入後にすべてをチェックすることです。$O(n^4)$違反の場合は4倍。 すべてを維持してチェックを最適化したとしても、$2 \times 2$段階的にマイナー、各アップデートは依然として影響を及ぼします$O(n^2)$制約があり、一貫性を繰り返しチェックする必要があります。 これにより、少なくとも次のことがすぐに実現されます。$O(n^4)$全体的に仕事をするのは不可能ですが、$n \approx 350$。 

重要な洞察は、条件を代数的に再解釈することです。 禁じられた平等$$a_{r_1,c_1} + a_{r_2,c_2} = a_{r_1,c_2} + a_{r_2,c_1}$$これはまさに、行列がランク付けされているというステートメントです。$1$どれかに制限されている場合$2 \times 2$ブロック。 フィールド上では、これは行列がどの四角形に対しても加法分離可能な関数のように動作しないことを要求するのと同じです。 

素体上のこのようなすべての等式を回避する古典的な方法は、双一次構造を強制することです。 エントリを次のように表すことができれば、$$a_{i,j} = x_i y_j$$で$\mathbb{F}_n$、その後は毎回$2 \times 2$行列式はゼロになり、これは私たちが望んでいることの逆です。 したがって、純粋なランク 1 構造は失敗します。 

代わりに、すべてのことができる構造が必要です。$2 \times 2$行列式がゼロ以外の場合:$$a_{i,c_1} + a_{r_2,c_2} \ne a_{r_1,c_2} + a_{r_2,c_1}.$$素数フィールドの標準的なトリックは、慎重に選択した傾きを持つ線形関数を使用して行と列をエンコードし、すべての四角形が個別のアフィン組み合わせを生成するようにすることです。 

正しい構造は、インデックスを次の要素として扱うことです。$\mathbb{F}_n$、二次リフティングを使用して行列を定義します。$$a_{i,j} = i \cdot j + c_i + d_j \pmod n,$$どこ$c_i$そして$d_j$は、対角線の制約に一致するように選択された補正です。 

この形式は非常に重要です。$i \cdot j$すべての四角形が、インデックスが一致しない限り混合項がキャンセルされない双一次式を生成することを確認します。 追加の用語$c_i$そして$d_j$マイナーの非縮退を破壊することなく対角値を強制できるようになります。 

ここで、対角条件を強制します。$$a_{i,i} = i^2 + c_i + d_i \equiv b_i \pmod n.$$私たちは自由に選ぶことができます$c_i = 0$、次に設定します$$d_i = b_i - i^2 \pmod n.$$これにより行列が完全に決まります。$$a_{i,j} = i \cdot j + (b_j - j^2).$$この構造により、対角線が正しいことが保証され、行と列の間の強力な代数的非対称性が維持され、どのような場合でもキャンセルが防止されます。$2 \times 2$部分行列。

 ## アルゴリズムのチュートリアル

 完全に算術モジュロで作業します$n$、インデックスを有限体の要素として扱います。 

1. 各行インデックスを解釈する$i$と列インデックス$j$整数として$[0, n-1]$。 これにより、フィールドでの直接演算が可能になります。 
2. 各列の列補正項を計算します。$j$、次のように定義されます$d_j = b_j - j^2 \mod n$。 これは、行依存の干渉を導入することなく対角制約を満たすことができるように選択されます。 
3. 次の式を使用して各行列エントリを構築します。$a_{i,j} = i \cdot j + d_j \mod n$。 これにより、すべての列に固定アフィン シフトがすべての行に一貫して適用されるようになります。 
4. 結果の行列を行ごとに出力します。 

依存関係を双一次項に分割する理由$i \cdot j$列のみの修正は、$2 \times 2$部分行列は次の多項式恒等式に展開されます。$i$そして$j$。 混合積項により、異なる行ペア間でのキャンセルが防止されます。 

### なぜ効果があるのか

 Fix any two rows$r_1 < r_2$とコラム$c_1 < c_2$。 クロスサムの差を拡張すると、$$(a_{r_1,c_1} + a_{r_2,c_2}) - (a_{r_1,c_2} + a_{r_2,c_1})$$

$$= (r_1 c_1 + d_{c_1}) + (r_2 c_2 + d_{c_2}) - (r_1 c_2 + d_{c_2}) - (r_2 c_1 + d_{c_1})$$全て$d$- 規約のキャンセル、退会$$r_1 c_1 + r_2 c_2 - r_1 c_2 - r_2 c_1 = (r_1 - r_2)(c_1 - c_2).$$以来$n$は素数であり、フィールドにはゼロの約数がないため、この式は非ゼロモジュロです$n$いつでも$r_1 \ne r_2$そして$c_1 \ne c_2$。 これにより、すべてのことが保証されます$2 \times 2$部分行列は禁止された等式に違反しています。 

斜めの状態はすでに焼き込まれています$d_i$, したがって、すべての制約が同時に満たされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    b = list(map(int, input().split()))
    
    d = [(b[j] - (j * j) % n) % n for j in range(n)]
    
    for i in range(n):
        row = []
        for j in range(n):
            val = (i * j + d[j]) % n
            row.append(str(val))
        print(" ".join(row))

if __name__ == "__main__":
    main()
```実装は派生した式に直接続きます。 の事前計算$d_j$ネストされたループが各エントリを構築する間、対角線の正確性を保証します。$O(1)$時間。 

実装でよくある落とし穴は、すべての操作を剰余で削減する必要があることを忘れていることです。$n$すべてのステップ、特に二乗項で$j^2$。 もう 1 つの微妙な点は、減算もモジュロで実行されるようにすることです。$n$そうでないと、Python の負の値が誤って伝播してしまうためです。

```次のように計算します。$d_0 = 0 - 0 = 0$、$d_1 = 0 - 1 = -1 \equiv 1$。 

Now construct matrix:

 | i \ j | 0 | 1 |
 | --- | --- | --- |
 | 0 | (0 + 0) = 0 | (0 + 1) = 1 |

0 0
```これにより、対角線が正しく、クロスサム条件が成立することが確認されます。$(0+0) \ne (1+0) \mod 2$。

 ## 特殊なケース

 可能な限り小さいケース$n=2$最も壊れやすいのは、$2 \times 2$部分行列は行列全体です。 この場合、この構造では依然として明確な交差項が生成されます。$(r_1-r_2)(c_1-c_2) \equiv 1 \cdot 1 \not\equiv 0 \mod 2$, したがって、最小構成でも制約は満たされます。 

いつすべて$b_i$が等しい場合、その構築は純粋な双一次行列と一定の列シフトを加えたものになります。 すべての補正が吸収されるため、対角線の制約によって不規則性が生じることはありません。$d_j$、構造的なものはそのままにして、$i \cdot j$期間は変更されず、それが有効性を保証するものです。 

もし$b_i = i$、斜め補正は$d_i = i - i^2$、これは大きく異なる可能性があります。 それにもかかわらず、相互差分ではすべての行の相互作用が相殺され、積項のみが残り、非常に不均一な対角線の下でも正確さが維持されます。
