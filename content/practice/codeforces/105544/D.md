 ## 解決策
 ## 問題の理解

 飛行機の座席レイアウトを表すグリッドが与えられています。 各セルは空であるか、ウイルス源が含まれています。 すべてのウイルスの座席は、2 つの異なる方法で近くの座席に影響を与えます。直接隣接する座席 (上下左右) には、隔離期間が割り当てられます。$d_1$、斜めに隣接する座席には隔離期間が割り当てられます。$d_2$。 

正常なシートは複数のウイルス シートの影響を受ける可能性がありますが、そのシートの最終的な隔離期間は累積されません。 代わりに、隣接するウイルスによってもたらされる最長の隔離期間を採用します。 

タスクは、すべての健康なシートについて、近くのすべてのウイルス シートによって引き起こされる隔離期間を計算し、各健康なシートを計算された日数で置き換え、ウイルス シートは変更しない、変換されたグリッドを出力することです。 

グリッド サイズは最大 100 x 100 で、最大 1000 のテスト ケースがあります。 これにより、すべてのセルに対するテストごとの線形スキャンが可能になりますが、これより悪いことはありません。$O(nm)$テストごとに実行すると、全体としては遅すぎます。 

シートがさまざまなウイルス細胞によって直接的および斜め方向の両方の影響を受ける場合、微妙なエッジケースが現れます。 この場合、正しい値は合計値や最終書き込み値ではなく、すべての寄与の最大値になります。 たとえば、座席が取れた場合、$d_1 = 7$直接の隣人から、そして$d_2 = 3$対角線上の隣からの場合、処理順序に関係なく、答えは 7 でなければなりません。 

もう 1 つの特殊なケースは境界処理です。 端または隅の座席には隣接する座席が少ないため、境界チェックのない単純な隣接反復では無効なグリッド位置にアクセスし、不正な結果や実行時エラーが発生します。 

## アプローチ

 この問題を考える簡単な方法は、すべてのウイルス細胞を影響源として扱い、その影響を隣接する細胞に伝播することです。 各ウイルス細胞について、その周囲の 8 つの位置を検査します。 有効なネイバーごとに、方向が基本方向か対角方向かに応じて候補隔離値を割り当てます。 次に、これまでに確認された最大値で近隣の結果を更新します。 

この強引な解釈はすでに制約に快適に一致しています。 各ウイルス セルは最大 8 つの更新に寄与し、最大で 8 つの更新が存在します。$nm$細胞。 したがって、テスト ケースごとの合計作業量は、小さな定数係数の倍によって制限されます。$nm$, これは十分に効率的です。 

影響は距離 1 を超えて及ばないため、最短パス、BFS、またはマルチソース伝播は必要ありません。 重要な観察は、問題は純粋に局所的なものであるということです。すべてのセルの値は、感染の連鎖ではなく、その直近の近傍にのみ依存します。 

したがって、最適なソリューションは総当たりアプローチと同じですが、近隣チェックを備えた単一のグリッド走査としてきれいに編成されています。

 ## アルゴリズムのチュートリアル

 1. 回答グリッドを入力のコピーとして初期化しますが、すべての正常なセルを開始値として 0 に置き換えます。 出力の一貫性を保つために、ウイルス細胞はウイルスとしてマークされたままになります。 
2. 4 つの直接隣接方向 (上、下、左、右、および 4 つの対角方向) を定義します。 
3. グリッド内のすべてのセルを繰り返します。 ウイルス細胞に遭遇すると、私たちはそれを影響源として扱います。 
4. 各ウイルス セルについて、その 4 つの直接隣接セルを検査します。 グリッド内の有効な各近隣について、その近隣が健全なシートである場合、その値を少なくとも次のように更新します。$d_1$。 これは直接隣接の影響を表します。 
5. 次に、その 4 つの斜めの隣を検査します。 健全な有効な対角近傍ごとに、その値を少なくとも次のように更新します。$d_2$。 
6. すべてのウイルス セルを処理した後、グリッドを再度トラバースし、ウイルス セルを変更しないまま、正常なセルの数値を出力用の文字列形式に置き換えます。 

各更新ステップは、セルの値の局所的な緩和です。 複数のウイルス源が同じシートに影響を与える可能性があるため、常に最大値を維持します。 

### なぜ効果があるのか

 すべての健康な座席は、そのすぐ近くの 8 セルのセルにのみウイルス細胞の影響を受ける可能性があります。 各ウイルスは独立して次のいずれかに寄与します。$d_1$または$d_2$となり、それ以上の影響は広がりません。 このようなすべての寄与をウイルスと隣接ウイルスのペアごとに 1 回だけ明示的に評価するため、考えられるすべての感染源が考慮されます。 最大値を取ることで、二重にカウントすることなく、重複した影響下でも正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for tc in range(1, t + 1):
        n, m, d1, d2 = map(int, input().split())
        grid = [list(input().strip()) for _ in range(n)]
        
        ans = [[0] * m for _ in range(n)]
        
        dirs4 = [(-1,0),(1,0),(0,-1),(0,1)]
        dirs_diag = [(-1,-1),(-1,1),(1,-1),(1,1)]
        
        # propagate from each virus
        for i in range(n):
            for j in range(m):
                if grid[i][j] == 'V':
                    for dx, dy in dirs4:
                        ni, nj = i + dx, j + dy
                        if 0 <= ni < n and 0 <= nj < m and grid[ni][nj] == '.':
                            ans[ni][nj] = max(ans[ni][nj], d1)
                    for dx, dy in dirs_diag:
                        ni, nj = i + dx, j + dy
                        if 0 <= ni < n and 0 <= nj < m and grid[ni][nj] == '.':
                            ans[ni][nj] = max(ans[ni][nj], d2)
        
        # build output
        out = []
        out.append(f"Airplane #{tc}:")
        for i in range(n):
            row = []
            for j in range(m):
                if grid[i][j] == 'V':
                    row.append('V')
                else:
                    row.append(str(ans[i][j]))
            out.append(''.join(row))
        
        print('\n'.join(out))

if __name__ == "__main__":
    solve()
```このソリューションでは、まず隔離期間の数値グリッドを構築します。 次に、各ウイルス セルは隣接するウイルス セルを直接更新します。 の使用`max`どのウイルスがどのような影響を及ぼしたかについての記録を必要とせずに、重複する影響が正しく解決されることを保証します。 

近隣住民がグリッドの外に出る可能性があるため、境界チェックは不可欠です。 2 つの個別の方向配列により、直接的な影響と斜めの影響が明確に分離され、2 つの距離ルール間の混乱が回避されます。 

最後に、出力の再構築により数値グリッドが元の構造とマージされ、ウイルス細胞が必要に応じて正確に保存されます。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    
    t = int(input())
    out_lines = []
    for tc in range(1, t + 1):
        n, m, d1, d2 = map(int, input().split())
        grid = [list(input().strip()) for _ in range(n)]
        ans = [[0]*m for _ in range(n)]
        
        dirs4 = [(-1,0),(1,0),(0,-1),(0,1)]
        dirs8 = dirs4 + [(-1,-1),(-1,1),(1,-1),(1,1)]
        
        for i in range(n):
            for j in range(m):
                if grid[i][j] == 'V':
                    for dx, dy in dirs4:
                        ni, nj = i + dx, j + dy
                        if 0 <= ni < n and 0 <= nj < m and grid[ni][nj] == '.':
                            ans[ni][nj] = max(ans[ni][nj], d1)
                    for dx, dy in dirs8[4:]:
                        ni, nj = i + dx, j + dy
                        if 0 <= ni < n and 0 <= nj < m and grid[ni][nj] == '.':

        out_lines.append(f"Airplane #{tc}:")

            row = []
            for j in range(m):
                row.append('V' if grid[i][j] == 'V' else str(ans[i][j]))
            out_lines.append(''.join(row))
    
    return "\n".join(out_lines)

 ## 特殊なケース

 コーナー ウイルスは、境界処理の最もクリーンなテストを提供します。 左上隅にウイルスがある 2 × 2 のグリッドを考えてみましょう。 近隣インデックスは 3 つだけ存在するため、アルゴリズムは範囲外のインデックスを無視する必要があります。 反復チェックにより、これが安全に保証されます。 

2 番目の微妙なケースは、複数のウイルスが異なる方向から同じ座席に影響を与えることです。 いつも応募しているので`max`、処理の順序は関係ありません。 たとえば、座席は最初に対角値 3 を受け取り、その後直接値 7 を受け取ります。保存された結果は 7 になり、安定したままになります。 

最後のケースは、ウイルスがまったく存在しないグリッドです。 すべてのセルは 0 のままである必要があり、更新がトリガーされないため、特別な処理を行わなくても、初期化はすでに正しい出力と一致します。
