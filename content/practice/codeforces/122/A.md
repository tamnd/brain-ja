 ## 解決策
 ## 問題の理解

 与えられた数字が幸運に近いかどうかを判断するように求められます。 少なくとも 1 つの幸運な数字で割り切れる場合、その数字はほぼ幸運です。 ラッキー ナンバーは、4、7、44、47、74 など、数字 4 と 7 だけで構成される正の整数です。 入力は単一の整数です`n`1 ～ 1000 の間で指定でき、その数字が幸運に近い場合は単純に「YES」、それ以外の場合は「NO」が出力されます。 

制約は非常に控えめです。 以来`n`が最大 1000 である場合、パフォーマンスを心配することなく、最大 1000 までのすべての幸運な数字に対して割り切れる可能性をチェックする余裕があります。 これにより、その範囲内のすべての幸運な数字を事前計算することもできます。 上限が小さいため、高度な数理論アルゴリズムや最適化されたふるい技術は必要ありません。 

明らかではないエッジ ケースは、小さな数字、それ自体が幸運な数字、および幸運な数字の倍数であるがそれ自体は幸運ではない数字から発生します。 たとえば、4 は幸運なのでほぼ幸運です。 16 という数字は、4 または 7 以外の数字が含まれているにもかかわらず、4 で割り切れるため、ほぼ幸運です。不注意な実装では、次のことのみをチェックする可能性があります。`n`割り算は無視されますが、16 や 28 などの数字では失敗します。 

## アプローチ

 単純な総当たりアプローチでは、1 から 2 までのすべての数値が生成されます。`n`そして、それぞれの数字が幸運かどうかを確認してください。 見つかったすべての幸運な数字について、それが割り切れるかどうかを確認します。`n`。 ほぼ幸運な数字は何らかの幸運な数字で割り切れる必要があるため、このアプローチは正しいです。 ただし、1000 までのすべての数値を反復処理し、その桁を繰り返しチェックするのは、少し冗長です。 

重要な洞察は、再帰的または反復的な構築を使用して、最大 1000 までのすべての幸運な数字を生成できるということです。 空の数値から始めて、4 または 7 を繰り返し追加し、数値が 1000 を超えたら停止します。このリストを取得したら、単純にそれを反復処理して、割り切れるかどうかを確認します。 ラッキーナンバーの構造（制限された数字と小さな上限）により、これが実現可能かつ効率的になります。 1 から 1000 までのすべての数値をチェックするのではなく、有効な候補者の少数のセットのみをチェックします。

 ## アルゴリズムのチュートリアル

 1. 最大 1000 までのすべての幸運な数字を保持するリストを初期化します。これらは最も単純な幸運な数字であるため、基本数字として 4 と 7 から始めます。 
2. キューを使用して、キュー内の各数字に 4 または 7 を追加して、新しいラッキーナンバーを繰り返し生成します。 1000 を超えると除算できないため、新しい数値の生成を停止します。`n`。 
3. 幸運な数字のリストを繰り返し処理します。 ラッキーナンバーごとに、次のことを確認してください。`n`はモジュロ演算子を使用して割り算できます。 
4. 分かれるラッキーナンバーを見つけたら`n`、「YES」を出力して終了します。 どれも分割しない場合`n`、「いいえ」を出力します。 

機能する理由: 構造上、分割できる可能性のあるすべての幸運な数字を列挙しました。`n`。 ほとんどのラッキーナンバーは、何らかのラッキーナンバーによる割り算によって定義されるため、この完全なセットに対して割り算をチェックすることで正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def generate_lucky_numbers(limit):
    lucky = []
    queue = [4, 7]
    while queue:
        num = queue.pop(0)
        if num > limit:
            continue
        lucky.append(num)
        queue.append(num * 10 + 4)
        queue.append(num * 10 + 7)
    return lucky

n = int(input())
lucky_numbers = generate_lucky_numbers(1000)

for ln in lucky_numbers:
    if n % ln == 0:
        print("YES")
        break
else:
    print("NO")
```まず、単純な BFS のような方法を使用して、1000 までのすべての幸運な数字を生成し、数字 4 と 7 を追加します。次に、生成された数字を反復処理して、割り切れるかどうかを確認します。 の使用`else`で`for`ループにより、幸運な数字が割り切れない場合にのみ「NO」が出力されるようになります。`n`。

 最小の入力`n = 1`1 はどのラッキーナンバーでも割り切れないため、「NO」が生成されます。 最大のインプット`n = 1000`1000 を超えるすべてのラッキー数値が生成されることはなく、すべての可能なラッキー数値に対して割り算が正しくチェックされるため、正しく処理されます。 4、7、47 など、それ自体が幸運な数字は、それ自体を割るので、ほぼ幸運であることがすぐに確認されます。 16、28、44 など、小さな幸運な数字の倍数であるが、それ自体は幸運ではない数字も、割り算ループによって正しく検出されます。
