 ## 解決策
 ## 問題の理解

 単一の整数が与えられます$d$、そして 2 人が独立して次の形式の三角和を計算したことがわかります。$1 + 2 + \dots + n$そして$1 + 2 + \dots + m$、 どこ$m > n$。 私たちがまだ持っている唯一の情報は、これら 2 つの合計の差です。$d$。 タスクは、考えられるすべての整数のペアを再構築することです。$(n, m)$それがこの違いを生み出した可能性があります。 

重要な量は三角数です$T(x) = \frac{x(x+1)}{2}$。 条件はこうなります$$T(m) - T(n) = d, \quad m > n.$$これを拡張すると、$$\frac{m(m+1) - n(n+1)}{2} = d.$$したがって、すべての有効なペアは、ディオファントス 2 次方程式の整数解に対応します。 

制約$d \le 10^{12}$二次関数は即座に除外されます$d$全体を反復するなど$n, m$ペア。 単一のループでも、$10^6$または$10^7$許容されますが、それに近いものは$\sqrt{d}$慎重に正当化する必要があります。 

微妙な点は、有効なペアの数が最大で次の数であることが保証されていることです。$10^4$したがって、出力自体は小さいですが、検索スペースは小さくありません。 

主な落とし穴は、反復処理を試みることです。$n$そして計算する$m$積分性や境界を制御せずに、二次方程式から直接計算します。 もう一つの問題はそれを忘れることです$m$厳密に超えなければなりません$n$これは、方程式を並べ替えるときの境界処理に影響します。 

## アプローチ

 強引なアイデアで解決するだろう$n$、計算する$T(n)$、そして解決してみてください$T(m) = T(n) + d$すべてスキャンすることで$m > n$。 これはすぐに実行不可能になります。$T(m)$二次関数的に成長し、$d$まで$10^{12}$、 両方$n$そして$m$およその大きさにすることができます$10^6$。 二重ループは次のようになります$10^{12}$最悪の場合の運用。 

より良いアプローチは、方程式を書き直すことで得られます。$$m(m+1) - n(n+1) = 2d.$$次のように因数分解できます$$(m-n)(m+n+1) = 2d.$$これは重要な構造的洞察です。三角数の差は 2 つの整数の積に変換されます。 させて$$a = m - n, \quad b = m + n + 1.$$それから、私たちはこうしなければなりません$$a \cdot b = 2d,$$と$a > 0$、$b > 0$、そして定義から:$$m = \frac{a + b - 1}{2}, \quad n = \frac{b - a - 1}{2}.$$したがって、すべての解は次の因子ペアに対応します。$2d$、パリティ制約により、$m, n$は整数です。 

これにより、問題は次の約数の反復に帰着します。$2d$まで効率的です。$\sqrt{d}$。 各約数について$a$、設定しました$b = \frac{2d}{a}$派生したかどうかを確認します$n, m$は整数であり、$m > n$。

 ## アルゴリズムのチュートリアル

 ここで、因子列挙を使用して、すべての有効なペアを体系的に構築します。 

1. コンピューティング$x = 2d$。 

これにより三角数から分母が削除されるので、純粋に整数を扱うことができるようになります。 
2. すべての整数を反復処理します。$a$から$1$に$\lfloor \sqrt{x} \rfloor$。 

それぞれについて$a$、分割されるかどうかを確認します$x$。 これにより、有効な因子ペアのみを考慮することが保証されます。 
3. 各約数について$a$、計算する$b = x / a$。 

今私たちは解釈します$a = m - n$そして$b = m + n + 1$、一意に決定されます$m$そして$n$有効な場合。 
4. 候補値を再構築します。$$m = \frac{a + b - 1}{2}, \quad n = \frac{b - a - 1}{2}.$$これらの公式は、次の線形システムを解くことから直接得られます。$m$そして$n$。 
5. 有効性条件を確認します。 

両方$m$そして$n$整数である必要があるため、両方の分子が偶数である必要があり、さらに$m > n$。 
6. すべての有効なペアを保存し、出力します。 

### なぜ効果があるのか

 すべての有効な解は、次の因数分解に対応します。$2d$の中へ$a \cdot b$、 どこ$a = m - n$そして$b = m + n + 1$。 このマッピングは全単射的です: 解が与えられると$(n, m)$、私たちは独自に回復します$(a, b)$、パリティ制約を満たす有効な因子のペアが与えられると、有効な 1 つだけを再構築します。$(n, m)$。 考えられるすべての因子のペアが列挙されるため、解が失われることはなく、生成されたすべてのペアは構造的に元の方程式を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

d = int(input().strip())
x = 2 * d

ans = []

i = 1
while i * i <= x:
    if x % i == 0:
        a = i
        b = x // i

        # case 1
        if (a + b - 1) % 2 == 0:
            m = (a + b - 1) // 2
            n = (b - a - 1) // 2
            if m > n and n >= 1:
                ans.append((n, m))

        # case 2 (swap factors)
        if a != b and (b + a - 1) % 2 == 0:
            m = (b + a - 1) // 2
            n = (a - b - 1) // 2
            if m > n and n >= 1:
                ans.append((n, m))

    i += 1

ans = list(set(ans))
print(len(ans))
for n, m in ans:
    print(n, m)
```実装は最大でのみ反復されます。$\sqrt{2d}$有効な因子ペアにはその範囲内に少なくとも 1 つの因子が含まれている必要があるため、これで十分です。 

パリティ チェックは非常に重要です。$m$そして$n$整数の結果が必要です。 これがなければ、整数除算は無効な候補を黙って生成することになります。 

また、異なる除数の向きによって同じペアが生成される可能性があるため、セットを使用して結果の重複を排除します。

 ## 特殊なケース

 重要なエッジケースの 1 つは次のような場合です。$2d$プライムです。 その場合、因子のペアは次のとおりです。$(1, 2d)$そして$(2d, 1)$、そのうちの 1 つがパリティに失敗するか、無効な負の値が生成されます。$n$。 アルゴリズムは、整数と不等号のチェックを通じてこれらを自然に除外し、無効なペアが報告されないようにします。 

別のエッジケースが発生するのは次の場合です。$a = b$、 意味$2d$は完全な正方形です。 この状況では、因子ペアは対称的であるため、重複を避けるために一度処理する必要があります。 実装は明示的にチェックします$a \neq b$スワップされたケースを生成するときに、二重カウントを防ぎます。 

再構築すると 3 番目のエッジケースが現れる$n$ゼロまたはマイナスになります。 元の問題は 1 から始まる正の整数を想定しているため、そのようなケースは破棄する必要があります。 条件$n \ge 1$は、この制約を強制し、代数は満たすが問題定義は満たさない偽の解を防止します。
