 ## 解決策
 ## 問題の理解

 非常に大きな長方形のグリッドが与えられていますが、最初にアクティブになるのは、スイレンと呼ばれる少数の特別なセルだけです。 これらのパッドのうち 2 つは常に開始セルとターゲット セルにあります。 時間の経過とともに、各パッドはマンハッタンの 4 方向すべてに 1 日に 1 ステップずつ外側に拡張します。$d$各パッドがマンハッタン距離内のすべてのセルをカバーする日数$d$元の位置から。 

アーサーはその日、少なくとも 1 つのスイレンの葉で覆われたセルの上のみを歩くことができます。 彼は一度に 4 方向に一歩ずつ移動できますが、覆われた独房を通過することのみが可能です。 問題は、開始セルからカバーされたセルの接続されたパスが存在するまでの最小日数を決定することです。$(1,1)$目的のセルへ$(n,m)$。 

グリッドの寸法は次のような大きさにすることができますが、$10^9$、パッドの数は最大です。$10^5$すべてのテストケースにわたって。 これが重要な構造上の制約です。グリッドや拡張を明示的にシミュレートすることはできません。 セルごとに理由を説明するアプローチは直ちに実行不可能です。1 日のシミュレーションでも潜在的に次のような問題が発生するためです。$10^{18}$細胞。 

難しいのは、動きをシミュレートすることではなく、2 つの拡大する「影響領域」が最初に接続されるタイミングと、この接続が最初から最後まで伝播するタイミングを判断することです。 

微妙なエッジ ケースは、接続が開始パッドと終了パッドの間で直接形成されず、中間パッドを介して形成される場合です。 たとえば、遠く離れた 2 つのパッドが個別にパスをカバーすることはありませんが、一連の重なりが接続を形成します。 固定半径を使用して開始点と終了点の間の直接到達可能性のみをチェックする単純なアプローチは、中間のリレー パッドを無視するため失敗します。 

## アプローチ

 直接シミュレーションでは、デイカウンターを増加させ、各ステップですべてのパッドからのフラッドフィルを試みます。 それは、毎日、すべてを拡張することを意味します$k$パッドを配置し、暗黙的に巨大なグリッド上で BFS を実行します。 たとえ私たちが賢くてフロンティアの拡大だけを追跡していたとしても、各拡大ステップは依然として一日中無制限の数のポジションに触れることになり、実際には最悪の場合の二次関数またはより悪い動作につながる可能性があります。 

重要な観察は、視点を逆転させることです。 セルがいつ到達可能になるかを尋ねる代わりに、2 つのパッドがいつ「接続」されるかを尋ねます。 各パッドは、マンハッタンの距離で成長するダイヤモンドを定義します。 2 つのパッド$i$そして$j$マンハッタンの距離が最大でも日数の 2 倍の場合に最初に重なり合います。 もし彼らの距離が$d_{ij}$、その後、彼らは時間に接続します$\lceil d_{ij}/2 \rceil$。 

これにより、問題がグラフ問題に変換されます。$k$ノード (パッドと固定の開始および終了)。 各ペアには、相互作用できる最も早い日に等しい重みを持つ暗黙的なエッジがあります。 開始と終了が同じ接続コンポーネント内にあるときの最も早い時間が必要です。これはまさに最小のボトルネック パスの問題です。 

標準的な事実として、重み付きグラフでは、2 つのノード間のパスに沿った最小可能な最大エッジの重みは、最小スパニング ツリーを計算し、そのツリー内の固有のパスに沿って最大エッジの重みを取得することによって取得されます。 これにより、すべてのパッド上に MST を構築し、パスの最大値をクエリするという問題が軽減されます。 

残りの課題は、すべてを列挙せずに MST を構築することです。$O(k^2)$エッジ。 マンハッタンの距離については、よく知られた幾何学的なトリックがあります。座標を 4 つの回転形式に変換し、スイープすることにより、すべての候補 MST エッジを見つけることができます。$O(k \log k)$。 エッジの重みはマンハッタン距離の単調関数であるため、同じ MST 構造が保存されます。 

最後に、MST に対してバイナリ リフティング前処理を実行して、開始パッドと終了パッドの間の最大エッジ ウェイトを答えます。

 ## アルゴリズムのチュートリアル

 まず、必須の開始パッドと終了パッドを含む各スイレンの葉をグラフ内のノードとして扱います。 

次に、これらのノード上に最小スパニング ツリーを構築します。ここで、2 つのノード間のコストは、拡張領域が接触するのに必要な時間です。 2点の場合$(x_1,y_1)$そして$(x_2,y_2)$、このコストはマンハッタンの距離から計算され、重複に必要な日数に変換されます。 

MST を構築した後、パスに沿った最大エッジの重みに関するクエリにすぐに答えられるように、MST を前処理します。 

最後に、開始ノードから終了ノードまでのパスをクエリし、検出された最大エッジ重みを出力します。 

1. すべてのパッドを読み取り、次のことを確認します。$(1,1)$そして$(n,m)$明示的なノードとして含まれます。 
2. 座標変換を備えた標準の幾何学的 MST 構築を使用して、すべてのノードにわたるマンハッタン MST を計算します。 各エッジの重量は、2 つのパッドを接続するのに必要な日数です。 
3. MST の隣接リストを作成します。 
4. 開始ノードでツリーをルートし、祖先とそれらの祖先への最大エッジ重みの両方を格納するバイナリ リフティング テーブルを前処理します。 
5. LCA リフティングを使用して、始点から終点までのパスに沿った最大エッジ重みを計算します。 
6. この値を出力します。 

正確かどうかは、エッジのアクティブ化時間がペアごとに行われるグラフ内の接続性として拡張を解釈するかどうかに依存します。 MST は、すべてのパッドを接続するすべての可能な方法の中で、接続を維持するために必要な最大アクティブ化時間を最小限に抑える構造を保証します。 グラフ全体の開始点と終了点の間の有効なパスは、最大エッジが元のグラフで可能な最良のものよりも大きくない MST 内のパスに対応します。

import sys

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0]*n

    def find(self, a):
        while self.p[a] != a:
            self.p[a] = self.p[self.p[a]]
            a = self.p[a]
        return a

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.r[a] < self.r[b]:
            a, b = b, a
        self.p[b] = a
        if self.r[a] == self.r[b]:
            self.r[a] += 1
        return True

            if s == 2:

        arr.sort()

            cnt += 1

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n, m, k = map(int, input().split())
        pts = []
        for _ in range(k):
            x, y = map(int, input().split())
            pts.append((x, y))

        start = pts.index((1, 1))
        end = pts.index((n, m))

        mst = manhattan_mst(pts)

        LOG = 20
        n0 = len(pts)
        up = [[-1]*n0 for _ in range(LOG)]
        mx = [[0]*n0 for _ in range(LOG)]
        depth = [-1]*n0

        from collections import deque
        dq = deque([start])
        depth[start] = 0

        while dq:
            u = dq.popleft()
            for v, w in mst[u]:
                if depth[v] == -1:
                    depth[v] = depth[u] + 1
                    up[0][v] = u
                    mx[0][v] = w
                    dq.append(v)

        for i in range(1, LOG):
            for v in range(n0):
                if up[i-1][v] != -1:
                    up[i][v] = up[i-1][up[i-1][v]]
                    mx[i][v] = max(mx[i-1][v], mx[i-1][up[i-1][v]])

        def get(u, v):
            if depth[u] < depth[v]:
                u, v = v, u
            res = 0

            diff = depth[u] - depth[v]
            for i in range(LOG):
                if diff & (1 << i):
                    res = max(res, mx[i][u])
                    u = up[i][u]

            if u == v:
                return res

            for i in reversed(range(LOG)):
                if up[i][u] != up[i][v]:
                    res = max(res, mx[i][u], mx[i][v])
                    u = up[i][u]
                    v = up[i][v]

            res = max(res, mx[0][u], mx[0][v])
            return res

        out.append(str(get(start, end)))

    print("\n".join(out))

実装の微妙な詳細は、答えは距離の合計ではなく、制約されたパスに沿った最大値であるということです。そのため、最短パス手法ではなく最大エッジ トラッキングによる LCA が必要です。

 ## 特殊なケース

 主なエッジケースは、直接のオーバーラップではなく、中間パッドの長いチェーンを介してのみ接続が可能である場合です。 たとえば、斜めチェーンでは、アルゴリズムが直接エッジではなく MST パス集約に完全に依存するようになります。 

もう 1 つのケースは、開始点と終了点がマンハッタン距離内ですでに近くにあるものの、中間パッドが欠落していることによって分離されている場合です。 MST は早期接続の想定を正しく回避し、代わりに利用可能なノードを通じて伝播するため、答えが過小評価されないことが保証されます。
