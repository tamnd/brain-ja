 ## 解決策
 ## 問題の理解

 偶数の長さの配列が与えられ、スワップを使用してその要素を自由に並べ替えることができるため、事実上、配列を任意に並べ替えることができます。 最終的な配置を選択した後、インデックス パリティによって配列を分割します。位置 1、3、5、... の要素が 1 つのグループを形成し、位置 2、4、6、... の要素がもう 1 つのグループを形成します。 

これら 2 つのグループのそれぞれについて、そのグループ内の最大値から最小値を引いたものとして定義される範囲を計算します。 最終的なアレンジメントのスコアは、2 つの範囲の積です。 私たちの仕事は、この積を最小化する順列を構築することです。 

この制約の重要な意味は、すべてのテスト ケースにわたる要素の合計数が最大 100,000 であるため、テスト ケースごとに O(n log n) の並べ替えベースのソリューションを使用できるが、n の二次関数はすべて即座に失敗するということです。 

値が密集している場合や重複が多い場合には、微妙なエッジ ケースが発生します。 たとえば、すべての要素が等しい場合、どの配置でも両方のグループの範囲がゼロになるため、答えは自明です。 もう 1 つの興味深いケースは、1 つの要素だけが残りの要素と大きく異なる場合です。 グループ間で「極端な値のバランスを取ろう」とする単純な貪欲な人は、誤って 1 つの外れ値を両方のグループの範囲に入れてしまい、両方の範囲を不必要に膨張させ、極端な値を慎重にグループ化するよりも悪い結果を生み出す可能性があります。 

## アプローチ

 最適化制約を無視すると、配列のすべての順列を試すことができます。 各順列について、パリティで分割し、両方の範囲を O(n) で計算し、合計の複雑度は O(n · n!) になります。 これは正しいですが、n = 10 の場合でも完全に実行不可能です。 

スワッピングにより、奇数位置と偶数位置への要素の任意の分割を選択できることが理解されると、問題の構造は意味のあるものになります。 したがって、このタスクは、マルチセットをサイズ n/2 の 2 つのサブセットに分割し、1 つのサブセットを奇数のインデックスに割り当て、もう 1 つを偶数のインデックスに割り当て、それらの範囲の積を最小化することと同じです。 

重要な観察は、範囲が各サブセットの最小値と最大値のみに依存するということです。 同じサブセット内で非常に小さい要素と非常に大きい要素を混合すると、その範囲がすぐに広がります。 これは、各サブセットのソート順序が可能な限り「厳密」である必要があることを示唆しています。 

配列をソートすると、最適なサブセットがソートされた配列の連続セグメントに対応する必要があることがわかります。 遠く離れた値をインターリーブすると、少なくとも 1 つのサブセットの広がりが増加するだけで、もう 1 つのサブセットは補償できるほど改善されません。 

両方のサブセットのサイズは n/2 でなければならないため、すべての要素をカバーする 2 つの互いに素な連続セグメントを形成する唯一の方法は、並べ替えられた配列を中間点 (最小の半分と最大の半分) で分割することです。 

これは、最小の n/2 要素を一方のパリティ クラスに割り当て、最大の n/2 要素をもう一方のパリティ クラスに割り当てるという構築に直接つながります。

 ## アルゴリズムのチュートリアル

 ### 1. 配列をソートする

 まず、すべての要素を降順でない順に並べ替えます。 これにより、さまざまなパーティションの下で範囲がどのように動作するかの構造が明らかになります。 

### 2. 2 つの等しい半分に分割します。 

k = n/2 とします。 最初の k 個の要素を「小さなグループ」とし、最後の k 個の要素を「大きなグループ」とします。 これにより、パリティ位置の要求に応じて、両方のグループのサイズが確実に等しくなります。 

### 3. パリティ位置に要素を割り当てる

 小さなグループを奇数のインデックス (1、3、5、…) に配置し、大きなグループを偶数のインデックス (2、4、6、…) に配置するか、その逆を行います。 各グループ内での順序は範囲に影響しませんが、通常はわかりやすくするために昇順に割り当てます。 

### なぜ効果があるのか

グループの範囲は、その最小値と最大値のみに依存します。 最適なソリューションでは、必要な場合を除き、ソートされた配列の両端の要素が同じグループに混在することを避ける必要があります。 グループに非常に小さい元素と非常に大きい元素の両方が含まれている場合、その範囲はグローバル範囲またはそれに近い値になり、他のグループがゼロ範囲に崩壊しない限り、積はすぐに悪化します。両方のグループのサイズが n/2 でなければならない場合、これは不可能です。 

したがって、両方の範囲を同時に小さく保つには、各グループがソートされた配列の中央にまたがることを避ける必要があります。 均等なサイズを尊重しながら不要な広がりを防ぐ唯一のパーティションは、下半分と上半分に分割することです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()

        k = n // 2

        # odd positions get first half, even positions get second half
        b = [0] * n

        idx1 = 0
        idx2 = k

        for i in range(0, n, 2):
            b[i] = a[idx1]
            idx1 += 1

        for i in range(1, n, 2):
            b[i] = a[idx2]
            idx2 += 1

        print(*b)

if __name__ == "__main__":
    solve()
```この解決策は、ソートに依存してグローバルな順序を強制し、最小の半分を奇数の位置に、最大の半分を偶数の位置に直接割り当てます。 2つの指針`idx1`そして`idx2`各半分の次の未使用要素を追跡します。 

一般的な実装の落とし穴は、完全にソートされた配列から値を「代替」しようとすることです。 この戦略は、両方のパリティ グループにわたって極端な値を広げ、両方の範囲を同時に拡大します。 正しい構造では、両極端を分離する必要があります。 

## 実用的な例

 ### 例 1

 入力配列:`[3, 1, 6, 2]`並べ替え:`[1, 2, 3, 6]`、k = 2

 私たちは以下を割り当てます:

 これは、半分に分割することで両方のグループが内部的にコンパクトに保たれ、極端な値の混合が回避される様子を示しています。

 ## 特殊なケース

 すべての要素が同一の場合、アルゴリズムは両方のパリティ グループに同一の値を割り当て、配置に関係なく両方の範囲をゼロに保ちます。 ソートされた分割でも 2 つの等しい半分が生成され、最小値と最大値が一致するため、偶発的な広がりは発生しません。 

大きな外れ値が 1 つある場合、並べ替えによりそれが配列の最後に配置され、常に大きい方の半分に入ります。 これにより、小さい半分の範囲が汚染されるのを防ぎます。これが、製品の両方の要素が同時に膨張することを避ける唯一の方法です。 

値がすでに均等に分散されているか、ほぼ連続している場合、インターリーブ戦略では依然として両方のパリティ グループにわたって小さい値と大きい値が混在します。 半分に分割する構造はその相互作用を完全に回避し、サイズ制約の下で両方の範囲が可能な限り小さく保たれるようにします。
