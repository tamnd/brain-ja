 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$N \times N$各セルが配置される九九$(i, j)$製品が含まれています$i \cdot j$。 したがって、テーブルには、次の 2 つの数値の積として表現できるすべての整数が含まれています。$1$そして$N$、包括的。 私たちの仕事は、この表のどこにも現れていない最小の正の整数を見つけることです。 

この問題を考えるもう 1 つの方法は、少なくとも 1 つの因子ペアを持つすべての値のセットを構築しているということです。$(a, b)$そのような$1 \le a, b \le N$、そしてそのセット内の最初の欠落している整数が必要です。 

制約$N \le 10^5$テーブルを明示的に構築したり、すべての製品を列挙したりする試みは直ちに排除されます。 テーブル自体には次のものが含まれます$N^2$までのエントリ$10^{10}$、計算または保存できる範囲をはるかに超えています。 すべてのペアを反復しても$(i, j)$不可能です。 

重要なエッジケースの動作は小規模な場合に現れます。$N$、表現可能な数値のギャップが簡単にわかります。 のために$N = 3$、テーブルには値が含まれています$\{1,2,3,4,6,9\}$、最小の欠損数は次のとおりです。$5$。 までしかスキャンしない単純なアプローチ$N^2$または、以下のすべての数値を仮定します。$N^2$表示すると、すべての数値がカバーされていると誤って認識されますが、これは非常に小さい数値であっても誤りです。$N$。 

もう 1 つの微妙な落とし穴は、答えが時間とともに大きくなると仮定することです。$N^2$。 実は一度、$N$が大きく、多くの小さな数はすでに完全に表現可能であり、最初の欠損数はテーブル サイズではなく因子構造に依存する小さな境界付近で安定します。 

## アプローチ

 ブルートフォース手法では、すべての製品が明示的に生成されます。$i \cdot j$のために$1 \le i, j \le N$、セットに保存してからスキャンします。$1$欠落している整数が見つかるまで上向きに続けます。 これはテーブルの定義を直接モデル化するため、概念的には単純で正しいものです。 

ただし、テーブルを生成するには、$O(N^2)$乗算、およびハッシュ セットへの挿入により、追加のオーバーヘッドが追加されます。 のために$N = 10^5$、これは次のようになります$10^{10}$実行可能な限界をはるかに超えた操作。 たとえ最小のサブタスクであっても、このアプローチはすぐに実用的ではなくなります。 

重要な点は、実際にはテーブルを作成する必要がないということです。 範囲内の 2 つの数値の積としてどの小さな整数を表現できるかだけを考慮します。$[1, N]$。 数字の場合$x$テーブルに表示するには、除数が必要です$d \le N$そのような$x/d \le N$同じように。 This means both a divisor and its paired quotient must lie within the range.

 さて、何が起こるかを考えてみましょう$N$成長します。 任意の数$x \le N$は簡単に存在します。$x = 1 \cdot x$。 少し上の数字については$N$、範囲内に因子のペアがあるかどうかに応じて、表示される場合と表示されない場合があります。 として$x$成長すると、最終的には有効な因子のペアが内部に収まらなくなる点に達します。$[1, N]$、そこから最初のギャップが現れます。 

これにより、問題は整数を上方向にスキャンし、それぞれの整数に少なくとも 1 つの約数があるかどうかをチェックするだけになります。$d \le N$そのような$x/d \le N$。 以来$x/d \le N$暗示する$d \ge \lceil x/N \rceil$までの約数をチェックするだけで済みます。$\sqrt{x}$、因子ペアの両側が範囲内にあることを確認します。 

答えは相対的に小さいため、$N^2$、上記の妥当な制限までの数値のみをテストする必要があります。$N$、通常は約$2N$最悪の場合はそれよりわずかに多くなります。 各番号をチェックインできます$O(\sqrt{x})$、全体的な複雑さは十分に高速になります。

 | 回答までの要素チェック |$O(A\sqrt{A})$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 次から始まる候補整数を反復処理します。$1$、各整数が積として表現できるかどうかを確認します。$a \cdot b$両方とも$a$そして$b$で$[1, N]$。 

1. 候補値から始める$x = 1$。 増やします$x$最小の欠損値を検索しているため、ギャップは昇順に表示される必要があるため、段階的に実行されます。 
2. それぞれについて$x$、可能な約数を反復処理します。$d$から$1$まで$\sqrt{x}$。 平方根で停止する理由は、すべての因子のペアがその点を超えて対称的に繰り返されるためです。 
3. 約数を見つけたとき$d$そのような$x \bmod d = 0$、ペアの因数を計算します$q = x / d$。 この時点で、有効な分解が得られました。$x = d \cdot q$。 
4.両方あるかどうかを確認します$d \le N$そして$q \le N$。 この条件が当てはまると、$x$が九九に存在するので、存在するとマークできます。 次に、次の候補に移ります。 
5. そのような約数が有効なペアを生成しない場合、次のように結論付けます。$x$をテーブル内で形成して答えとして返すことはできません。 

### なぜ効果があるのか

 少なくとも 1 つの因数分解がある場合にのみ、数値が九九に表示されます。$x = a \cdot b$両方の要因がどこにあるのか$[1, N]$。 アルゴリズムは、次のすべての因子ペアを徹底的にチェックします。$x$ちょうど 1 回 (最大の約数を介して)$\sqrt{x}$)、任意のペアが許容範囲内に収まるかどうかを検証します。 有効なペアが存在しない場合、テーブル構造の定義により、$x$は生成できないため、昇順に見つかった場合に最小の欠損値になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def in_table(x, n):
    r = int(math.isqrt(x))
    for d in range(1, r + 1):
        if x % d == 0:
            q = x // d
            if d <= n and q <= n:
                return True
    return False

def solve():
    n = int(input().strip())

    x = 1
    while True:
        if not in_table(x, n):
            print(x)
            return
        x += 1

if __name__ == "__main__":
    solve()
```ヘルパー関数`in_table`許容範囲内の 2 つの整数の積として数値を形成できるかどうかの条件をエンコードします。 平方根境界を使用して、すべての除数のペアを効率的にチェックします。 

メイン ループは候補値を 1 から増分し、最初の失敗が最小の欠損値であることを保証します。 一度だけなので終了は保証されています$x > N^2$の場合、有効な因子のペアが範囲内に存在できないため、ループは最終的に中断する必要があります。 

微妙な点は、前処理や保存された構造が必要ないことです。 すべての数値は個別にチェックされ、正確性はテーブル シミュレーションではなく純粋に因数分解のプロパティに依存します。

import sys, io
import math

def in_table(x, n):
    r = int(math.isqrt(x))
    for d in range(1, r + 1):
        if x % d == 0:
            q = x // d
            if d <= n and q <= n:

def run(inp: str) -> str:
