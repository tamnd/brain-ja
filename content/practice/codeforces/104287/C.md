 ## 解決策
 ## 問題の理解

 私たちは一連のことを見ています$n$ゲームの独立したラウンド。 各ラウンドで正確に 1 人のプレイヤーが勝ちます。 特別なプレーヤーの 1 人はトーマスです。$k$他の競技者もいるから、どのラウンドでも$k+1$勝者の可能性がある人たち。 

ゲームの完全な結果は単純に長さです。$n$各位置がこれらのいずれかを選択するシーケンス$k+1$プレーヤーがそのラウンドの勝者になります。 このようなシーケンスすべての中で、トーマスがすべてのラウンドで勝てないシーケンスを数えたいと思います。 言い換えれば、シーケンス内のすべてのエントリが Thomas である単一の縮退ケースを除外します。 

可能なシーケンスの総数は次のとおりです。$(k+1)^n$、各ラウンドには$k+1$独立した選択。 唯一の禁じられた構成は、すべての中でトーマスが選ばれる構成です。$n$ポジション。 

制約は非常に小さいです。$n \le 10$そして$k \le 4$。 これは、シーケンスの最大数が$5^{10} \approx 9.7 \times 10^6$これは境界線にありますが、慎重に実行すれば最適化された Python で管理可能です。 ただし、構造は単純なので列挙する必要はありません。 

A subtle edge case is when$n = 1$。 この場合、「トーマスがスイープを取得」とは、トーマスが唯一のラウンドで勝利したことを意味します。 したがって、答えはその 1 つの構成を除くすべてのプレイヤーであるはずです。 それは、$k$、あるので$k+1$選択肢は全部で 1 つだけ除外します。 

もう 1 つのエッジケースは次のような場合です$k = 0$、トーマスが唯一のプレイヤーであることを意味します。 考えられる唯一の結果はスイープであるため、どの結果についても答えはゼロでなければなりません。$n \ge 1$。 公式はこれを自然に処理する必要があります。 

## アプローチ

 この問題を考える最も直接的な方法は、勝者の考えられるすべてのシーケンスを生成することです。 各ラウンドで次のいずれかを選択します$k+1$プレイヤー、深さのツリーを形成$n$分岐因子あり$k+1$。 これは正確に生成します$(k+1)^n$葉。 各リーフについて、すべての位置がトーマスであるかどうかを確認し、その 1 つの無効なケースを減算します。 

これはすべての結果を明示的に構築するため、正しく機能します。 失敗のポイントは効率です: 上限であっても$n = 10$、$k = 4$、検索スペースは 1,000 万シーケンス近くまで増加し、再帰または文字列構築内で追加のオーバーヘッドが発生すると、厳密な制限の下では Python が脆弱になります。 

重要な観察は、構造がラウンド全体にわたって完全に均一であるということです。 すべてのラウンドは独立しており、「トーマスがすべてのラウンドで勝利する」という条件は、正確に 1 つのシーケンスに対応します。 したがって、何も列挙する必要はありません。 合計数からその 1 つの構成を減算するだけで済みます。 

したがって、答えは簡単です。$$(k+1)^n - 1$$ブルート フォースは両方の部分を明示的にカウントしますが、最適化されたソリューションは全スペースを直接カウントし、唯一の禁止されたケースを削除します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース列挙 |$O((k+1)^n \cdot n)$|$O(n)$| 遅すぎる |
 | ダイレクトフォーミュラ |$O(1)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数の読み取り$n$そして$k$。 これらはラウンド数とトーマス以外のプレイヤーの数を定義します。 
2. 考えられる結果の合計数を次のように計算します。$(k+1)^n$、各ラウンドが独立して次の中から 1 人の勝者を選択するため、$k+1$競合他社。 
3. この合計から 1 を引いて、トーマスが各ラウンドで勝つ単一の無効な結果を削除します。 
4. 結果の値を出力します。 

重要な推論ステップは、無効な条件が範囲やサブセットではなく、正確に 1 つの構成に対応していることを認識することだけです。 これにより、包含排除や動的計画法ではなく減算が可能になります。 

### なぜ効果があるのか

 すべての有効なゲーム結果は長さに一意に対応します。$n$一定のサイズのアルファベットにわたるシーケンス$k+1$。 このマッピングは全単射的です。各シーケンスは 1 つの結果を正確に定義し、各結果は 1 つのシーケンスを正確に定義します。 

「スイープ」条件は、すべての位置がトーマスである単一シーケンスに対応します。 この特性を共有するシーケンスは他にないため、合計数からちょうど 1 つを削除すると正しい答えが得られます。 追加の禁止ケースが発生する可能性のあるラウンド間の重複や相互作用はありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

total = pow(k + 1, n)
print(total - 1)
```この実装は数学的削減を直接反映しています。 内蔵されている`pow`は、高速なべき乗演算に使用されます。これは、このような小さな制約には不要ですが、コードをクリーンで安全に保ちます。 

1 の減算は、すべての有効な入力に対して安全です。$k \ge 0$そして$n \ge 1$、私たちはいつも持っています$(k+1)^n \ge 1$、そして平等は次の場合にのみ起こります。$k = 0$、結果は正しくゼロになります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, k = map(int, input().split())
    return str(pow(k + 1, n) - 1)

# provided samples
assert run("2 1\n") == "3"
assert run("10 3\n") == "1048575"

# minimum n, k = 0 (only Thomas exists, always sweep)
assert run("1 0\n") == "0"

# single round with multiple opponents
assert run("1 3\n") == "3"

# all equal edge: k = 1, n = 1
assert run("1 1\n") == "1"

# slightly larger sanity check
assert run("3 2\n") == str(3**3 - 1)
```| テスト入力 | 期待される出力 | 検証内容 |

 ## 特殊なケース

 最も重要なエッジケースは次のような場合です$k = 0$。 入力はトーマスだけが存在する状況を表します。 どれについても$n$、すべてのラウンドはトーマスが勝つ必要があるため、結果は 1 つだけであり、常にスイープになります。 式は次のようになります$(0+1)^n - 1 = 0$、これは推論と直接一致します。 

のために$n = 1$、問題は、次の中から 1 人の勝者を選択することになります。$k+1$選手たち。 これらの選択肢のうちの 1 つが無効であるため (Thomas)、結果は次のようになります。$k$。 式は次のようになります$(k+1)^1 - 1 = k$、正確に位置合わせされます。 

大型の場合$n$、ラウンド間の独立性により相互作用効果が保証されないため、新しい構造ケースは表示されません。 ラウンドが追加されるたびに合計スペースが増加するだけであり、禁止された構成は単一のままです。
