 ## アルゴリズムのチュートリアル

 この問題を、各層がガスアレイの回転状態に対応する層状システムとして再解釈します。 回転は決定論的であるため、1 ステップ後に位置とレイヤーの両方が予測どおりに変化します。 

DP 遷移行列を定義します$T$サイズの$n \times n$、 どこ$T[i][j]$頂点から移動するための最小コストを表します$i$頂点へ$j$固定回転状態でちょうど1秒で回転します。 宿泊も可能ですので、$i \to i$は常に有効な遷移です。 

ただし、ローテーションによってコストパターンが変化するため、実際には$n$異なる遷移マトリックス (回転オフセットごとに 1 つ)。 これらのマトリックスはステップごとに循環します。 

次に、完全なサイクルにわたって結合された移行を構築します。$n$これにより、システムは元のコスト構成に戻ります。 その結合された遷移は、ステップごとの行列の min-plus 乗算を繰り返すことによって計算できます。 

その後、このサイクル遷移を累乗して処理します。$k // n$全サイクルを実行し、残りのサイクルを適用します。$k \bmod n$個別にステップを実行します。 

### ステップ

 1.構築する$n$隣接関係を認識したコスト マトリックス$A_0, A_1, \dots, A_{n-1}$、 どこ$A_t[i][j]$頂点にいるためのコストです$i$時間オフセットで$t$、さらに移行の実現可能性$j$。 これは移動と待機の両方をエンコードします。 コストは現在の回転状態に依存するため、これが必要になります。 
2. 時間ステップ間の遷移を結合するための min-plus 行列の乗算を定義します。 これにより、ステップバイステップのダイナミクスをより長い間隔に構成できるようになります。 
3. 行列を順番に乗算します。$A_0 \circ A_1 \circ \cdots \circ A_{n-1}$全サイクルの遷移行列を取得するには$C$。 これは、1 回転期間全体にわたって頂点間を移動するための最良のコストを表します。 
4. コンピューティング$C^{k // n}$min-plus 代数での 2 進累乗を使用します。 各乗算は 2 つの全サイクル遷移をマージします。 
5. 初期状態ベクトルから開始$dp_0$、 適用する$C^{k // n}$すべての完全なサイクル後に最良のコストを取得します。 
6. 残りの部分を処理します$k \bmod n$対応するステップを順次適用することで、$A_t$行列を順番に並べます。 
7. 答えは、正確に計算した後のすべての終了頂点の最小値です。$k$ステップ。 

### なぜ効果があるのか

 各ステップ後のシステムの状態は、現在の頂点と回転オフセットのみに依存し、回転オフセットは周期とともに決定的に変化します。$n$。 これにより、有限オートマトンが生成されます。$n$段階。 任意の長さのパス$k$完全なサイクルと残りに一意に分解されます。 min-plus 行列の乗算は、固定長の間隔にわたって最適な部分構造を正確に捕捉するため、全サイクル遷移の累乗により、繰り返されるセグメント全体で最適性が維持されます。 残りのプレフィックスは明示的に処理されるため、近似は導入されません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = 10**30

def mat_mul(A, B, n):
    C = [[INF] * n for _ in range(n)]
    for i in range(n):
        Ai = A[i]
        for k in range(n):
            if Ai[k] == INF:
                continue
            Bik = B[k]
            aik = Ai[k]
            for j in range(n):
                v = aik + Bik[j]
                if v < C[i][j]:
                    C[i][j] = v
    return C

def mat_vec(A, v, n):
    res = [INF] * n
    for i in range(n):
        for j in range(n):
            val = v[j] + A[j][i]
            if val < res[i]:
                res[i] = val
    return res

n, m, k = map(int, input().split())
a = list(map(int, input().split()))
g = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    g[u-1].append(v-1)

# build per-step matrices
def build_matrix(offset):
    A = [[INF]*n for _ in range(n)]
    for u in range(n):
        cost = a[(u + offset) % n]
        for v in g[u]:
            A[u][v] = min(A[u][v], cost)
        A[u][u] = min(A[u][u], cost)
    return A

# initial dp
dp = [INF]*n
dp[0] = 0

cycle = None

# build cycle matrix
for t in range(n):
    M = build_matrix(t)
    if cycle is None:
        cycle = M
    else:
        cycle = mat_mul(cycle, M, n)

def mat_pow(M, exp):
    res = [[INF]*n for _ in range(n)]
    for i in range(n):
        res[i][i] = 0
    while exp:
        if exp & 1:
            res = mat_mul(res, M, n)
        M = mat_mul(M, M, n)
        exp >>= 1
    return res

full = k // n
rem = k % n

cycle_pow = mat_pow(cycle, full)
dp = mat_vec(cycle_pow, dp, n)

for t in range(rem):
    M = build_matrix(t)
    dp = mat_vec(M, dp, n)

print(min(dp))
```このコードは、各頂点が回転フェーズに応じて異なるコストを持つ、時間依存の遷移システムを構築します。 各行列は、移動と滞在の両方を含むシステムの 1 つのステップをエンコードします。 これらの行列は完全なサイクルに構成され、大規模なシミュレーションを行うためにべき乗されます。$k$。 

行列の乗算は min-plus 形式で記述されます。加算はガスの蓄積に対応し、min は最適なパスの選択に対応します。 ベクトルの乗算は、現在最もよく知られているコストに遷移を適用します。 

べき乗により依存性が軽減されます。$k$線形から対数へ、これは必要なことです$k$まで$10^9$。

 ## 特殊なケース

 頂点が 1 つだけの最小限のグラフは、アルゴリズムが自己ループと移動のない繰り返し回転を正しく処理するかどうかをテストします。 状態の位置は決して変わらないので、答えは単にその頂点のコストの合計になります。$k$DP は、遷移を必要とせずにそれを正しく蓄積する必要があります。 

同じコストを持つ完全に接続されたグラフは、アルゴリズムが遷移を過度に複雑にしていないことをチェックします。 すべての移動のコストは等しいため、どのパスでも同じ合計が得られるはずです。 DP は、マトリックス構築を通じて人為的な非対称性を導入してはなりません。 

回転後に時間の経過とともに位置合わせをテストした後、1 つの頂点だけが安くなるグラフ。 正しい戦略では、エントリ時間をゼロコストフェーズと同期させるために待機またはループが必要な場合があり、階層化された DP はコストを静的なものとして扱うのではなく、そのタイミングの依存関係をキャプチャする必要があります。
