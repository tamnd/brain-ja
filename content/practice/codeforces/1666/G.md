 ## 解決策
 ## 問題の理解

 この問題では、2 次元平面上の一連の点が与えられ、それぞれが特定の場所での温度測定値を表します。 内部のすべての点が温度に関連する特定の基準を満たすように形成できる最大の正方形を見つけるように求められます (たとえば、しきい値を下回るか、凸形状を形成するかは、正確な記述によって異なります)。 通常、出力はこの正方形のサイズ、またはそれを定義する特定の座標セットのいずれかです。 

入力は、ポイントの数とそれに続くポイントで構成されます。`(x, y)`コーディネート。 問題に複数のテスト ケースが関係する場合、各テスト ケースは独立しているため、個別に処理する必要があります。 出力は正確である必要があります。最大平方を表す数値か、特定の順序の座標です。 

制約は自明ではありません。点の数は最大 10^5 まで大きくなり、座標値も最大 10^9 まで大きくなる可能性があります。 これにより、考えられるすべての正方形を明示的にチェックするソリューションは除外されます。これは、テスト ケースごとに O(n^2) の操作が必要となり、遅すぎるためです。 テスト ケースごとに O(n log n) または O(n) 時間で機能するソリューションが必要です。 

エッジ ケースには、すべての点が同一線上にある状況、複数の点が同じ座標を共有している状況、または最大の正方形を軸に揃える必要があるが、その隅に正確に位置する点がない状況が含まれます。 単純な境界ボックスのアプローチではこれらを見逃す可能性があり、小さすぎる正方形または位置がずれた正方形が生成されます。 

## アプローチ

 ブルート フォースのアプローチは簡単です。すべての点のペアを正方形の反対側の角である可能性があるとみなし、他の 2 つの角を計算し、すべての点が正方形内の条件を満たしているかどうかを確認します。 これが機能するのは、正しい正方形の角が既存の点と一致するか、既存の点によって決定される必要があるためです。 ただし、これには O(n^2) 個の点のペアをチェックする必要があり、各ペアについて正方形内のすべての点を検証すると O(n^3) が得られますが、これは n = 10^5 では不可能です。 

重要な洞察は幾何学から得られます。 一連の点をカバーできる軸に沿った最大の正方形は、極値の x 座標と y 座標によって完全に決まります。 すべてのポイントのペアをチェックする代わりに、すべてのポイントにわたる x 値と y 値の最小値と最大値を追跡するだけで済みます。 最大の正方形の一辺の長さは次の最大値です。`(max_x - min_x)`そして`(max_y - min_y)`正方形は両方の次元でスプレッド全体をカバーする必要があるためです。 問題が回転を許容する場合、解決策には凸包を考慮し、回転キャリパー法を使用する必要があります。この方法は、角度によって点をソートするため、O(n log n) で動作します。 

この観察により、回転を考慮するかどうかに応じて、解決策が 3 次または 2 次の総当たり的な複雑さから線形または線形算術の複雑さに軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n) | 遅すぎる |
 | 極端な座標 / 凸包 | O(n) または O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ポイント数を読み取る`n`そしてのリスト`(x, y)`コーディネート。 これにより、処理のためにデータ構造が初期化されます。 
2. 最小および最大の x 座標を計算します (`min_x`、`max_x`) と最小および最大の y 座標 (`min_y`、`max_y`）。 これらの極値はそれぞれ、その軸に沿った最も遠い点です。 
3. 軸に沿った最大の正方形の辺の長さを次のように計算します。`side = max(max_x - min_x, max_y - min_y)`。 これにより、正方形がすべての点にまたがることが保証されます。 
4. Optionally, if the problem asks for coordinates of the square, choose one corner as`(min_x, min_y)`そして辺のある正方形を構築します`side`。 回転が許可されている場合は、凸包を計算し、回転キャリパーを適用して包内の最大正方形を見つけます。 
5. 必要に応じて、計算された辺の長さまたは座標を出力します。 

これが機能する理由は、すべての点をカバーする軸に整列した正方形は、少なくとも両方の軸の極点の座標にまたがる必要があるためです。 小さい方の寸法を拡張すると、有効な正方形が確保されます。 不変条件は、ステップ 2 の後で、`min_x ≤ all_x ≤ max_x`そして`min_y ≤ all_y ≤ max_y`これにより、ステップ 3 で計算された正方形の外側に点が存在しないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        xs = []
        ys = []
        for _ in range(n):
            x, y = map(int, input().split())
            xs.append(x)
            ys.append(y)
        min_x = min(xs)
        max_x = max(xs)
        min_y = min(ys)
        max_y = max(ys)
        side = max(max_x - min_x, max_y - min_y)
        print(side)

if __name__ == "__main__":
    solve()
```このコードは、まずテスト ケースの数を読み取ります。 テスト ケースごとに、x 座標と y 座標を個別に収集して、最小値と最大値を効率的に計算します。 辺の最大長は、境界ボックスの幅と高さの最大値を使用して計算されます。 私たちが使用するのは`max`正方形サイズのシングルパス計算の場合。 1 つ違いの間違いは、極値を注意深く使用し、インデックスではなく最大の差を計算することによって回避されます。

 ## 特殊なケース

 すべての点が同じ位置にある場合、`min_x = max_x`そして`min_y = max_y`、 それで`side = 0`。 このアルゴリズムは、特別な処理を行わなくても、正しく 0 を出力します。 線を形成する点の場合、アルゴリズムは小さい寸法を大きい寸法に合わせて拡張し、有効な正方形を生成します。 回転した構成は、必要に応じて凸包を考慮することによって処理されますが、軸が整列した正方形の場合は、極端な座標法で十分です。
