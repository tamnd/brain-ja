 ## 解決策
 ## 問題の理解

 長さの配列が与えられます$n$ここで、各要素は次のいずれかです$-1$、$0$、 または$1$。 任意の要素を何度でも 1 ずつインクリメントすることができます。 目標は、実行する操作を最小限に抑えながら、すべての要素の積を厳密に正にすることです。 

厳密に正の積では、最終的な配列内の負の要素の数が偶数であり、ゼロがないことが必要です。 各 0 は 1 になるために少なくとも 1 回インクリメントされる必要があります。 それぞれ$-1$1 回増分して 0 になるか、2 回増分して 1 になります。 one では操作は必要ありません。 

制約は小さいです。$n \le 8$そして$t \le 10^4$。 以来$n$が小さい場合、技術的には要素に対するあらゆる操作の組み合わせを検討できますが、テスト ケース数の上限には、テスト ケースごとに定数時間のソリューションが必要です。 この問題は純粋に算術的なものであり、各配列は独立して分析できます。 

エッジ ケースは、配列にすべて 0、すべて 1、または奇数の値が含まれる場合に発生します。$-1$s にはゼロが付きます。 たとえば、配列が次の場合、$[-1, 0]$、0 から 1 (1 回の操作) をインクリメントする必要があります。$-1$を 1 つ (2 つの操作)、合計 3 つの操作にします。 単純なアプローチでは、負の数がまだ奇数である場合、負を 0 に反転するだけでは十分ではないことを見落とす可能性があります。 

## アプローチ

 ブルートフォース手法では、各要素の増分の可能な組み合わせをすべて試行し、結果の積が正であるかどうかを確認します。 それぞれ$-1$潜在的なターゲットは 0、1、または 3 つあります。$-1$。 各ゼロには、0 または 1 の 2 つの潜在的なターゲットがあります。これにより、次のようになります。$3^k \cdot 2^m$組み合わせ、ここで$k$の数です$-1$そして$m$は 0 のカウントです。$n = 8$、せいぜいこれです$3^8 \approx 6561$組み合わせは、単一のテスト ケースでは実行可能ですが、複数のテスト ケース全体では非効率的です。$10^4$テストケース。 

最適なアプローチは、各増分をシミュレートする必要がないことを認識することから生まれます。 操作の数は分析的に計算できます。 各ゼロは 1 回ずつ増加する必要があります。 マイナスの数を数えます。 負の数が奇数の場合、積を正にするには、1 つの負を正に反転する (2 回の操作) 必要があります。 重要な洞察は、配列の長さが短く、すべての演算がゼロと負の 1 の数において線形であるということです。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 各テスト ケースは独立しています。 
2. 各配列について、ゼロの数とゼロの数を数えます。$-1$s.
 3. すべての 0 が 1 になるには、正確に 1 つの増分が必要です。 この数を合計操作に追加します。 
4. すべてのマイナスは、製品の符号を反転することに寄与します。 負の数が偶数の場合は、そのままにしておくことができます。$-1$またはそれらを 1 つに反転します。 製品はすでに陽性です。 負の数が奇数の場合は、負の数を 1 つ選択し、それを 2 回増分して 1 にし、積が確実に正になるようにします。 
5. すべての正の値は演算を必要としません。 
6. 各テスト ケースに必要な操作と出力を合計します。 

不変条件は、常に 0 を 1 に増分し、負の 1 の数が偶数であることを保証することです。 これにより、最小限の操作で製品が厳密に陽性であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def min_operations_to_positive(arr):
    zeros = arr.count(0)
    negatives = arr.count(-1)
    
    ops = zeros + negatives  # flip zeros once, negatives at least once
    if negatives % 2 == 1:
        ops += 1  # need one extra increment to flip one negative to positive
    
    return ops

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(min_operations_to_positive(a))
```コードは最初にゼロと負の 1 をカウントします。 ゼロを 1 回インクリメントし、負の 1 を 1 回 (ゼロに、または最終的には 1 に) インクリメントします。負の数が奇数の場合は、負の 1 つを完全に 1 に反転する操作をもう 1 つ追加します。 Python の組み込みを使用する`count`簿記を簡素化し、明確さを確保します。

## 特殊なケース

 配列にすべて 0 が含まれている場合は、各 0 を 1 回ずつインクリメントする必要があります。 例えば、`[0, 0, 0]`3つの操作につながります。 配列に奇数の値が含まれている場合、$-1$s がゼロの場合、最初にゼロが増分され、次に負の値が 1 つ増分され、符号のバランスが保たれます。 このソリューションでは、ゼロと負のカウントを合計し、負の値が奇数の場合は追加の演算を追加することでこれを処理します。 これにより、あらゆるエッジ シナリオで最小限の操作数が保証されます。
