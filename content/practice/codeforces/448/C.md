 ## 解決策
 ## 問題の理解

 垂直板のフェンスをペイントするために必要なブラシ ストロークの最小数を計算するように求められます。 各板の幅は 1 メートル、高さはそれぞれ異なります。 ブラシの幅はちょうど1メートルで、縦にも横にも塗ることができます。 垂直ストロークは板全体を一度にペイントし、水平ストロークは特定の高さで隣接するすべての板をペイントします。 

入力は次のもので構成されます`n`、板の数、その後に配列`a`長さの`n`、板の高さを表します。 出力は単一の整数、つまりフェンス全体をカバーするのに必要な最小ストロークです。 

制約によって明らかになったのは、`n`最大 5000、個々の板の高さは 10^9 に達することがあります。 これは、単純な方法で板のすべてのペアまたはトリプルを検査するアルゴリズムは、潜在的に数千万の操作を実行し、TLE の危険性があることを意味します。 O(n^2) に近いか、それ以上のアプローチが必要です。 

単純なソリューションを破ることが多いエッジ ケースには、すべての高さが等しいフェンス、高さが厳密に増減するフェンス、または高い板と低い板が交互に配置されたフェンスなどがあります。 たとえば、入力が次の場合`1 1 1 1`、答えは明らかに 1 ですが、不注意な水平優先の貪欲なアルゴリズムでは、誤って複数のストロークが考慮される可能性があります。 

## アプローチ

 強引なアプローチは簡単です。塗装されていない板ごとに、垂直方向にペイントして高さをゼロにし、残りの高さを再帰的に計算します。 このアプローチは正しいのですが、垂直ストロークのすべてのシーケンスを考慮するため、指数関数的に複雑になります。 

もう少し良いアプローチは、水平ストロークを貪欲に使用することです。各ステップで、ペイントされていないセクションの最小高さを見つけ、その高さを区間全体にわたってペイントし、この最小値を超えるセグメントを再帰的に解決します。 これは、分割統治のアプローチと考えることができます。間隔全体にベースをペイントし、最小値よりも高い板で形成された残りの「サブフェンス」を処理します。 

重要な洞察は、垂直方向でも水平方向でも、各ストロークは 1 つとしてカウントされるため、各セグメントで、垂直方向のストロークで板を個別にペイントする方が安価であるか、水平方向のストロークを使用して再帰的に解決するのかを決定する必要があるということです。 指定された長さのセグメントに対して`len`、最小ストロークは次の最小値として計算できます。`len`垂直ストロークと`min_height + sum(recursive calls on subsegments)`。 

このアプローチが機能するのは、再帰的構造により、各ステップで垂直ストロークによってセグメントが完全に縮小されるか、水平ストロークによって高さが最適に縮小され、残りの部分のみが解決されることが保証されるためです。 各呼び出しによって範囲サイズが厳密に縮小されるため、再帰呼び出しの合計数は管理可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 水平 + 分割統治 | O(n^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 完全な間隔から開始します`[l, r)`厚板と初期高さオフセット`base`これは、前の水平ストロークによってすでに描画されている高さです。 
2. 間隔が空の場合 (`l >= r`)、0を返します。 
3. 現在の間隔における最小の高さを相対的に計算します。`base`。 これは、水平ストロークでペイントできる高さを表します。 
4. 描く横のストロークを数えます。`min_height`。 
5. 間隔をスキャンし、それを高さよりも高い板の連続したサブセグメントに分割します。`min_height`。 各サブセグメントについて、必要な最小ストロークを再帰的に計算し、現在の水平ストローク数に追加します。 
6. この合計を、垂直ストロークを使用して各板を個別にペイントした場合と比較してください (`r - l`) 小さい方の数値を返します。 
7. 最初に、全間隔で関数を呼び出します。`[0, n)`と`base = 0`。 

機能する理由: 各再帰ステップで、アルゴリズムは水平ストロークをカウントして未塗装セグメントのみを再帰的に解決するか、垂直ストロークをカウントします。 これにより、ストロークを過少カウントすることがなくなり、再帰的除算により、常に必要に応じて各プランクを正確に処理できるようになります。 不変条件は、呼び出しのたびに、`base`はすでにペイントされた高さを表すため、残りの高さは正確に表現されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10000)

def min_strokes(a, l, r, base):
    if l >= r:
        return 0
    min_h = min(a[l:r]) - base
    strokes = min_h
    i = l
    while i < r:
        if a[i] - base == min_h:
            i += 1
            continue
        j = i
        while j < r and a[j] - base > min_h:
            j += 1
        strokes += min_strokes(a, i, j, base + min_h)
        i = j
    return min(strokes, r - l)

def main():
    n = int(input())
    a = list(map(int, input().split()))
    print(min_strokes(a, 0, n, 0))

if __name__ == "__main__":
    main()
```の`min_strokes`関数は、再帰的分割統治アプローチを直接実装します。 空いた間隔を慎重に処理し、正確に調整します`base`すでにペイントされている高さを考慮して。 Off-by-one エラーは、範囲を次のように扱うことで回避されます。`[l, r)`。

 ## 特殊なケース

 すべて同じ高さのような`1 1 1 1`は正しく処理されます。アルゴリズムは最小高さ 1 を計算し、1 つの水平ストロークを適用し、ペイントされていないセグメントを検出しません。 

単板の場合`1 4`垂直ストロークと水平ストロークを比較し、垂直ストロークを 1 つ正しく選択することによって処理されます。 

などの谷のある区間`3 2 3`に分かれています`[0,1)`そして`[2,3)`、ベースの上に再帰的な水平ストロークが適用され、最適な合計 3 つのストロークが得られます。 

このアプローチでは、次の不変条件を維持することで、特定されたすべてのエッジ ケースを確実に処理します。`base`すでにペイントされた高さを追跡し、板が過小カウントされたり過大カウントされたりしないようにします。
