 ## 解決策
 ## 問題の理解

 数値 _X_ と整数 _k_ が与えられ、各数値を昇順に約数に繰り返し展開してシーケンスを構築したいと考えています。 形式的には、_X_0 を _X_ だけを含むシーケンスとして定義します。 各 i > 0 について、_X**i_ は、_X_*(i-1)* 内のすべての数値をソートされた約数で置き換えることによって取得されます。 タスクは、_X**k_ の最初の 10^5 要素を出力することです。 

制約は極端です。 _X_ は 10^12 まで大きくなるため、展開のたびに因数分解を繰り返すとコストがかかる可能性があります。 反復数 _k_ は 10^18 に達する可能性があるため、各ステップを個別にシミュレートすることはできません。 最後に、出力は 10^5 要素に制限されています。これは、完全なシーケンスではなくプレフィックスのみが必要であることを示唆しています。 

エッジケースは微妙です。 _X_ = 1 の場合、すべての展開は [1] のままになるため、成長しないシーケンスを処理する必要があります。 _k_ = 0 の場合、単純に [X] を出力します。 _X_ が素数の場合、最初の展開は [1, X] になり、2 番目の展開は [1, 1, X] になるため、慎重に切り詰めないと、単純なシーケンスの乗算はすぐに制限を超える可能性があります。 

## アプローチ

 ブルートフォース手法は単純です。_X_0 = [X] から開始し、反復ごとに、すべての数値をソートされた順序でその約数に置き換えます。 これは小さな数には機能しますが、X = 10^12 および k = 10 を考慮してください。大きな数の場合、約数の数は最大 O(n^(1/3)) になる可能性があり、シーケンスは爆発的に増加する可能性があります。 さらに、k = 10^18 の反復をシミュレートすることは不可能です。 単純な実装では、いくつかの手順を実行しただけで時間とメモリの制限を超えてしまいます。 

重要な洞察は、シーケンスが各数値の素因数分解に従って増加するということです。 すべての約数を毎回再計算する代わりに、10^5 要素の接頭辞が埋められる時点までのシーケンスに現れるすべての数値の約数を事前計算できます。 最初の 10^5 要素のみを考慮するため、BFS スタイルのアプローチを使用できます。つまり、最初の数値から開始し、その約数を順番にキューにプッシュし、k 個の展開に達するか、プレフィックスが埋まるまで数値を 1 つずつ処理します。 

重要な観察は、数回の反復の後、シーケンス内のほとんどの数値が 1 になり、1 は常に [1] に展開されるため、シーケンスがすぐに安定することです。 したがって、10^5 要素で切り捨てながら、プロセスを慎重にシミュレートできます。 キューとマップを使用して除数をキャッシュすると、除数を不必要に再計算することがなくなります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k * D_max * シーケンス長) | O(シーケンスの長さ) | k または X が大きいと遅すぎます |
 | プレフィックス + 除数のキャッシュ | O(10^5 * sqrt(X)) | O(10^5 + キャッシュされた除数の数) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力から整数 _X_ および _k_ を読み取ります。 シーケンスを[X]として初期化します。 
2. 最初の 10^5 要素を格納するためにリスト _result_ を初期化します。 キューを使用して、BFS 順序で番号を処理します。 
3. 整数平方根反復を使用して、数値のすべての約数を昇順に計算する関数を定義します。 再計算を避けるために、計算された約数を辞書にキャッシュします。 
4. 結果シーケンスの長さが 10^5 未満で、現在の反復回数が _k_ 未満である間、現在のキューから数値を取得します。 数値ごとに、その約数を次のキューに追加し、10^5 要素に達するまで _result_ に追加します。 
5. キューを交換し、反復カウンターをインクリメントします。 _k_ 回の展開が実行されるか、結果が 10^5 要素に達するまで繰り返します。 
6. _result_ の最初の 10^5 要素を出力します。

機能する理由: 各反復では、数値が X**i の定義と正確に一致する約数に置き換えられます。 10^5 要素で切り捨てることで、出力制約が尊重されます。 除数をキャッシュすると、冗長な因数分解が回避されます。 キューを使用すると、展開の正しい順序が維持されるため、シーケンスの順序が維持されます。 

## Python ソリューション```python
import sys, math
from collections import deque

input = sys.stdin.readline

def divisors(n):
    if n in div_cache:
        return div_cache[n]
    res = []
    for i in range(1, int(n**0.5)+1):
        if n % i == 0:
            res.append(i)
            if i != n // i:
                res.append(n // i)
    res.sort()
    div_cache[n] = res
    return res

X, k = map(int, input().split())
LIMIT = 10**5
div_cache = {}
current = deque([X])
result = []

while k > 0 and len(result) < LIMIT:
    next_queue = deque()
    while current and len(result) < LIMIT:
        num = current.popleft()
        divs = divisors(num)
        for d in divs:
            if len(result) < LIMIT:
                result.append(d)
            next_queue.append(d)
    current = next_queue
    k -= 1

# if k == 0 or finished early, add remaining elements
if k == 0 and current:
    while current and len(result) < LIMIT:
        result.append(current.popleft())

print(' '.join(map(str, result[:LIMIT])))
```このコードは入力を読み取り、BFS のキューを初期化します。 の`divisors`関数は結果をキャッシュして、冗長な計算を回避します。 メイン ループは、反復制限 _k_ または出力制限 10^5 に達するまで展開をシミュレートします。 最後に、結果が出力されます。 

微妙な点: 使用`deque`O(1) のポップおよび追加操作を保証します。 昇順を維持するには、約数を並べ替える必要があります。 除数をキャッシュすると、平方根因数分解の繰り返しコストが削減されます。
