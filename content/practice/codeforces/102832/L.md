 ## 問題の理解

 の配列を作成する必要があります`n`各行の黒セルの数を表す負でない整数。 黒セルの合計数は正確に一致する必要があります。`s`。 隣接する 2 つの行ごとに、黒セルの量はちょうど 1 だけ増加するか、ちょうど 1 だけ減少します。`k`。 

入力により、行数、許容される減少値、および必要な黒セルの合計数が得られます。 出力は行値の有効なシーケンス、または`-1`そのようなシーケンスが存在しない場合。 

限界`n <= 100000`これは、解が線形に近い必要があることを意味します。 多くの可能な配列、合計に対する動的プログラミング、または状況に応じた方法を試してみます。`s`直接は無理なので`s`到達できる`10^18`。 

厄介なケースは、すべての要素を同じ量だけ増やすと合計が次の倍数に変化するという事実によって引き起こされます。`n`、任意の値によるものではありません。 のみを使用する構築`+1`次のような場合、遷移は失敗します。```
n = 3, k = 2, s = 15
```増加のみを使用すると、合計は次のようになります。`0`モジュロ`3`、ただし、次のような有効な回答`6 4 5`減少遷移が必要です。 

もう 1 つの失敗例は、多くの減少を使用した後でのみ答えが存在する場合です。 例えば：```
n = 5, k = 10, s = 1
```大きな正の値から始めて下方に調整する単純なアプローチは、非負性を侵害する可能性があります。`10`負の行をすぐに作成できます。 

最後のエッジケースは、モジュール状態が不可能な場合です。 例えば：```
n = 4, k = 3, s = 2
```ここでは、すべての遷移によって行の値が次のいずれかによって変更されます。`1`または`-3`したがって、すべての行は固定リレーションモジュロを持ちます。`4`。 必要な合計がその関係と一致しない場合、どれだけシフトしても問題を修正することはできません。 

## アプローチ

 強引なアイデアは、すべての遷移を独立して決定することです。 がある`n-1`トランジションがあり、それぞれに 2 つの選択肢があるため、これを検討します`2^(n-1)`可能性。 これは、配列の可能なすべての形状を検査するので正しいですが、`n = 100000`それは全く不可能です。 

有用な観察は、すべての増加の場合と比較してすべての遷移を説明することから得られます。 最初の行を次のようにします`A`。 すべての遷移が`+1`、行の値`i`だろう`A + i - 1`。 減少遷移では、代わりに追加の値が減算されます。`k+1`それに比べて。 

ポジション間で減少が発生した場合`i`そして`i+1`、以降のすべての行に影響します。 総額に対するその寄与度はまさに`k+1`回`(n-i)`。 したがって、`D`以下の間で選択された重みの合計になります。`1,2,...,n-1`、合計は次のようになります。```
s = n*A + n(n-1)/2 - (k+1)*D
```可能な値は、`D`からのすべての数字です`0`に`n(n-1)/2`なぜなら、その範囲内の任意の数値は、次の部分集合の合計として表すことができるからです。`1,2,...,n-1`。 

問題は有効な値を見つけることに帰着します。`D`満足のいく：```
(k+1)*D = n(n-1)/2 - s (mod n)
```これは線形合同です。 適切なものを見つけた後、`D`、最初の値`A`決まっている。 可能な限り最大の有効なものを選択します`D`その合同クラスでは、`A`負でないことが保証されます。

 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. しましょう`C = n(n-1)/2`。 全増加シーケンスが貢献します`C`したがって、残りの部分は最初の値と減少演算によって制御されます。 
2. 合同式を解きます。```
(k+1)D ≡ C-s (mod n)
```最大公約数を使用します。 右辺が割り切れない場合`gcd(k+1,n)`、解決策は存在しません。 
3. 1 つの解を計算する`D0`モジュロ`n/gcd(k+1,n)`モジュラー逆関数を使用する`(k+1)/gcd(k+1,n)`。 
4. の最大値に移動します。`D`を超えない`C`それは同じ残留物を持っています`D0`。 この選択により、減算項が最大になり、計算された最初の値が負になるのを防ぎます。 
5. 以下を計算します。```
A = (s-C+(k+1)D)/n
```それから`A`は最初の行の値です。 
6. 代表する`D`のサブセットとして`1,2,...,n-1`。 最大の重みから下に向かって繰り返します。 現在の体重がこの範囲内に収まる場合は、`D`、そこに減少トランジションを配置します。 
7. 以下から始めてアレイを構築します。`A`。 トランジションごとに、次を追加します。`1`通常または減算`k`減少トランジションが選択されたとき。 

構築の背後にある不変条件は、選択されたすべての減少が、割り当てられた重みに正確に寄与するということです。`D`。 合同式は合計が正しいことを保証し、有効な最大値を選択します。`D`初期オフセットが十分に大きいことを保証します。 シーケンスは有効な遷移から直接構築されるため、すべての隣接するペアは必要なルールを満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def egcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x, y = egcd(b, a % b)
    return g, y, x - (a // b) * y

def solve_case(n, k, s):
    if n == 1:
        return "0" if s != 0 else "0"

    c = n * (n - 1) // 2
    g, _, _ = egcd(k + 1, n)

    if (c - s) % g != 0:
        return "-1"

    mod = n // g
    if mod == 1:
        d0 = 0
    else:
        a = (k + 1) // g
        b = (c - s) // g
        _, x, _ = egcd(a, mod)
        d0 = (b * (x % mod)) % mod

    d = c - ((c - d0) % mod)
    a0 = (s - c + (k + 1) * d) // n

    cuts = [False] * n
    rem = d
    for i in range(n - 1, 0, -1):
        if rem >= i:
            rem -= i
            cuts[i] = True

    ans = [a0]
    for i in range(1, n):
        if cuts[i]:
            ans.append(ans[-1] - k)
        else:
            ans.append(ans[-1] + 1)

    return " ".join(map(str, ans))

def main():
    n, k, s = map(int, input().split())
    print(solve_case(n, k, s))

if __name__ == "__main__":
    main()
```コードは最初にモジュラー方程式を処理します。 拡張ユークリッド アルゴリズムは、ライブラリ関数に依存せずに、合同に必要な逆行列を提供します。 

値`d`は、その剰余クラスの最大の有効な代表として選択されます。 これは、負の開始値を回避するための詳細です。 より小さい有効な値は数学を満たしますが、それでも最初の行が負である必要があります。 

の`cuts`配列はどの遷移が減少するかを格納します。 重みが正確に一致するため、貪欲なサブセット構築は機能します。`1`を通して`n-1`したがって、利用可能な最大の重みを最初に取得すると、常に表現可能な剰余が残ります。 

Python の整数はオーバーフローしません。これは、次のような中間積が存在するために必要です。`(k+1)*d`64 ビットの符号付き制限を超える可能性があります。

 ## 特殊なケース

 のために`n = 1`、満足できる遷移はありません。 モジュール構造では少なくとも 1 つの遷移が存在することが前提となっているため、実装ではこれを個別に処理します。 

次のような不可能な合同の場合:```
4 3 2
```我々は持っています`gcd(4,4)=4`、 しかし`C-s = 4`したがって、この特定の例は実際に解決可能です。 本当に不可能なケースは次のとおりです。```
4 3 3
```どこ`C-s = 3`で割り切れない`4`。 アルゴリズムは構築を試みる前にそれを拒否します。 

非常に少額の場合、選択されるのは、`D`十分な大きさでなければなりません。 アルゴリズムは有効な最大値を取得します`D`、減少の寄与を増やし、必要な最初の値を減らします。 これにより、数学的には有効でも負の配列が生成されなくなります。 

大きな値の場合、`s`、最初の値が余分な量を吸収するため、同じ構造が引き続き機能します。 すべての行を同じ量だけ増やすと、すべての遷移条件が保持され、合計が次の倍数だけ変更されます。`n`。
