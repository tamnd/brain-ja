 ## 問題の理解

 正の整数の配列と正の整数が与えられます。$k$。 配列の各要素については、そのままにすることも、追加することもできます。$k$1回の操作で完了します。 私たちがパフォーマンスできるのはせいぜい$k$目標は、すべての要素の最大公約数が厳密に 1 より大きくなるように配列を変換することです。 出力は、使用された演算ではなく、変換された配列自体である必要があります。 

入力制約は、配列に最大で次のものを含めることができることを示しています。$10^5$テスト ケースごとの要素数、およびすべてのテスト ケースの要素の合計が以下を超えないこと$10^5$。 配列内の整数と$k$と同じ大きさにすることができます$10^9$。 これは、次のような解決策があることを意味します。$O(n^2)$複雑さが遅すぎるでしょう。 線形または線形に近いソリューションが必要です。 

明らかではないエッジケースは、すべての要素が同一である場合、または次の場合に発生します。$k$配列内の数値に比べて非常に大きいです。 たとえば、配列が次の場合、$[1,1,1]$そして$k = 100$、追加するという素朴なアプローチ$k$どの要素をインクリメントするかを慎重に選択しないと、一部の要素に任意に追加すると、1 以外の有効な係数で割り切れない結果が生成される可能性があります。 正しいアプローチでは、多くの場合、総和または最小要素を基準点として使用して、1 より大きい単一の公約数が保証されます。 

## アプローチ

 ブルートフォースアプローチでは、追加のあらゆる組み合わせを試みます。$0$または$k$各要素にアクセスし、各試行後に GCD を計算します。 これは原理的には正しいですが、明らかに実行不可能です。$n = 10^5$、 がある$2^n$組み合わせ。 小さめの場合でも$n$、GCD を繰り返し計算するとコストがかかります。 

重要な観察は、すべての加算は次の倍数であるということです。$k$。 したがって、任意の 2 つの要素間の差は、次の倍数になるように調整できます。$k$。 配列内の最小要素を見つけたら、次の倍数を追加できます。$k$すべての要素が合同モジュロになるように各要素に$k$。 これにより、任意の要素と最小要素の差が次で割り切れることが保証されます。$k$、変換された配列の GCD は、最小要素に次の倍数を加えたものになります。$k$。 

最適なアプローチは、配列の合計を取得し、その GCD を次のように計算することです。$k$。 具体的には、各要素について、最小要素に次の倍数を加えた値を設定できます。$k$。 これにより、すべての要素を分割する GCD が 1 より大きくなることが保証されます。演算の数を最小限に抑える必要はありません。 すべての要素が整列モジュロになるようにするだけです$k$十分です。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$そして$k$、次に配列$a$。 
2. 配列の合計を計算し、最小要素を見つけます。 最小限の要素がベースラインとして機能します。 
3. 各要素について$a_i$、回数を計算します。$k$最大要素のレベルに達するか、最小要素と揃えるために追加する必要があります。 正式に設定すると、$a_i = a_i + ((\text{sum of all elements} - a_i) // k) * k$。 これにより、各要素が、GCD が最小要素に次の倍数を加えたセットの一部になることが保証されます。$k$。 
4. 調整した配列を出力します。 

これが機能する理由は、各要素を次の倍数で調整した後であるためです。$k$、要素間の差異は次の倍数です。$k$。 したがって、結果として得られる配列の GCD は、次の係数であることが保証されます。$k$、これは 1 より大きいです。$k \ge 1$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import gcd
from functools import reduce

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        mn = min(a)
        # compute total adjustments needed
        res = [mn + ((x - mn) // k) * k if x >= mn else x + k*((mn - x + k - 1)//k) for x in a]
        print(" ".join(map(str, res)))

if __name__ == "__main__":
    solve()
```このソリューションは、次を使用して複数のテスト ケースを効率的に読み取ります。`sys.stdin.readline`。 すべての配列要素を整列させるための基準として最小の要素が選択されます。 各要素は次の倍数で調整されます。$k$GCD が 1 より大きくなるようにします。調整計算では、最大値を超えないようにするために整数の除算が使用されます。 最終的な配列はスペースで区切られた文字列として出力されます。

 ## 特殊なケース

 単一要素の配列の場合、最小値と最大値は同じです。 このアルゴリズムは要素をそのままの状態で正しく返しますが、要素が 1 つしかないため、当然のことながら GCD は 1 より大きくなります。 

すべての要素が等しい配列の場合、次のように追加します。$k$複数回行う必要はなく、アルゴリズムは配列を変更せずに返します。 これにより、不要な操作が防止され、配列が範囲内に維持されます。
