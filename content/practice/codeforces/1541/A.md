 ## 解決策
 ## 問題の理解

 元の位置に猫が留まらないように、また各猫の移動距離の合計を最小限に抑えるために、一列に並んでいる猫の順序を変更するように求められます。 入力は複数のテスト ケースで構成され、それぞれが 1 つの整数を指定します$n$- 猫の数。 出力は 1 から 1 までの整数の順列です。$n$それぞれの猫が元の位置から移動する距離が最小限に抑えられ、元の位置に留まる猫が存在しないように、テスト ケースごとに猫の新しい順序を表します。 

制約は小さいです。$2 \le n \le 100$最大 100 のテスト ケース。 これは、少なくとも次の期間で実行できるソリューションを提供できることを意味します。$O(n^2)$テスト ケースごとに異なりますが、洗練さとシンプルさのために線形または線形に近いソリューションを目指す必要があります。 エッジケースは最小でも発生します$n$2 や 3 のように、有効な順列の数は限られており、単純にシャッフルすると誤って猫がその場所に残る可能性があるためです。 たとえば、$n=2$、唯一の有効な置換は$[2, 1]$; それ以外の取り決めは条件に違反します。 

微妙な点は、複数の順列が「猫がその場に留まらない」というルールを満たしている一方で、この問題では全体の動きを最小限に抑えることが求められているということです。 小さなもののために$n$、いくつかの順列は猫を必要以上に遠くに移動させます。 たとえば、$n=3$、$[3, 1, 2]$合計距離は 4 になりますが、$[2, 3, 1]$合計距離は 3 となり、これより小さくなります。 

## アプローチ

 ブルートフォースアプローチでは、長さのすべての順列が生成されます。$n$元の位置に要素が残っていないものを選択します。 次に、有効な順列ごとに、元の位置と新しい位置の間の絶対差の合計として総移動量を計算します。 最後に、合計の移動が最小限になる順列を選択します。 正しいですが、これは不可能です$n \ge 10$あるから$n!$順列とそれらすべてのチェックは階乗的に成長します。 

重要な洞察は、単純なパターンに気づくことから得られます。 「どの要素もその位置に留まらない」という制約は古典的な混乱の問題であり、距離を最小限に抑えたいと考えています。 最小の全体的な動きは、すべての要素を周期的に前方に 1 位置シフトすることによって達成されます。 のために$n=2$、2 つの要素を交換します。 のために$n \ge 3$、単純な右巡回シフトは、距離効率にも優れた有効な乱れを生成します。 例えば、$[1, 2, 3]$になる$[2, 3, 1]$。 各猫は正確に 1 歩前に進みますが、最後の猫は除きます。$n-1$位置を調整し、小さな場合は全体の動きを最小限に抑えます$n$。 

このパターンは堅牢です。$n$、単一の循環シフトにより、要素が元の位置にないことが保証され、ほとんどの動きは最小限に抑えられます。 代替シフトも可能であり、依然として有効ですが、この戦略は実装が簡単で迅速です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * n) | O(n) | 遅すぎる |
 | 循環シフト / 貪欲 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、整数を読み取ります。$n$猫の数を表します。 
3. もし$n=2$、出力$[2, 1]$有効な順列は 1 つだけであるため、すぐに実行されます。 
4. のために$n \ge 3$、2 から までの数値を取得して順列を構築します。$n$最後に 1 を追加します。 これにより、元のシーケンスの右巡回シフトが生成されます。 
5. 各テスト ケースの結果の順列を出力します。 

効果がある理由: このアプローチでは、どの猫も元の位置に留まらないという不変条件が維持されます。 すべての数値を 1 つシフトすると、最初の数値が確実に$n-1$猫は 1 つの位置だけを移動して距離を最小限に抑え、最後の猫は最初の位置に移動します。 錯乱条件に違反せずに最後の猫の動きを減らすことは不可能であるため、この順列はルールの下で可能な限り距離効率が高くなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    if n == 2:
        print(2, 1)
    else:
        # shift 1..n to the left by 1 position: 2..n + 1
        perm = list(range(2, n + 1)) + [1]
        print(*perm)
```コードは最初に最小サイズのエッジ ケースを処理します。$n=2$唯一の有効な順列は交換されたシーケンスであるため、個別に。 大型の場合$n$、Python のを使用して循環シフトを効率的に構築します。`range`そしてリスト連結。 使用する`print(*perm)`リストをスペースで区切られた整数に解凍します。 ソリューションが実行されます$O(n)$テストケースおよび用途ごとに$O(n)$順列を保存するスペース。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        n = int(input())
        if n == 2:
            print(2, 1)
        else:
            perm = list(range(2, n + 1)) + [1]
            print(*perm)
    return output.getvalue().strip()

# provided samples
assert run("2\n2\n3\n") == "2 1\n2 3 1", "sample 1"

# custom cases
assert run("1\n4\n") == "2 3 4 1", "n=4"
assert run("1\n5\n") == "2 3 4 5 1", "n=5"
assert run("1\n100\n") == " ".join(map(str, range(2,101))) + " 1", "n=100 max size"
assert run("3\n2\n3\n6\n") == "2 1\n2 3 1\n2 3 4 5 6 1", "multiple test cases"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1\n4 | 2 3 4 1 | 標準の小さい n > 2 |
 | 1\n5 | 2 3 4 5 1 | 典型的な小さな n |
 | 1\n100 | 2 3 ... 100 1 | 最大 n、パフォーマンス |
 | 3\n2\n3\n6 | 2 1\n2 3 1\n2 3 4 5 6 1 | 複数のテスト ケースが正しく処理されました。 

## 特殊なケース

 のために$n=2$、単純な循環シフトは次のようになります。`[1, 2]`、両方の猫をその場に残します。 これを特殊なケースとして扱うことで、正確性が保証されます。 のために$n=3$それ以上の場合、右循環シフトにより有効な乱れが自動的に生成されます。 たとえば、入力`3`につながる`[2, 3, 1]`、元の位置に要素が残っていないという不変条件が確認されます。 アルゴリズムは最大限までスムーズにスケールします$n=100$変更なしで。
