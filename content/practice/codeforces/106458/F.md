 ## 問題の理解

 タスクは、座標平面上の 2 点間の直線距離を計算することです。 入力は 2 つの点の座標を記述し、それぞれが x 座標と y 座標で表されます。 出力は、これら 2 つの点を接続するセグメントの長さです。 

ポイントについて`(x1, y1)`そして`(x2, y2)`、水平方向の差は`x2 - x1`そして垂直方向の差は`y2 - y1`。 これら 2 つの違いは直角三角形の脚を形成するため、必要な距離は斜辺になります。$$\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$$制約は小さいですが、それでも正しい実装の詳細が決定されます。 一定数の算術演算から答えが得られるため、検索、並べ替え、または幾何学的データ構造は必要ありません。 通常、結果は整数ではないため、主な関心事は数値の精度です。 

エッジケースは単純ですが、式が正しく実装されていない場合、誤った処理が行われやすくなります。 

2 つの同一の点の場合:```
0 0
0 0
```答えは次のとおりです。```
0.0
```1 つの座標の差のみを計算するソリューションも多くのテストに合格しますが、一般的な入力では失敗する可能性があります。 

垂直線上にある点の場合:```
5 1
5 6
```答えは次のとおりです。```
5.0
```x の差はゼロですが、距離は依然として y の差によって決まります。 

対角線上にある点の場合:```
0 0
3 4
```答えは次のとおりです。```
5.0
```ユークリッド公式を使用する代わりに座標の差を追加する不注意な実装では、次のような出力が出力されます。`7`、これは要求された距離ではなくマンハッタンの距離です。 

## アプローチ

 ブルートフォースアプローチとは、通常、何らかのパターンを探索するか、可能性を列挙しようとすることを意味します。 この問題では、指定された 2 つの点の間に可能な距離は 1 つだけであるため、その直感は不要です。 列挙は、幾何学公式がすでに直接解決している作業を繰り返すだけです。 

数学的な観察によれば、座標の差により直角三角形の辺が得られます。 ピタゴラスの定理は、これら 2 つの独立した動きを対角線分の長さに変換します。 問題は、幾何学タスクから固定式の評価にまで縮小します。 

不要なループが 1 つでもあると、新しい情報が提供されずに複雑さが増すため、ここでは強引なアイデアは意味がありません。 直接計算は定数時間であり、意図した解決策です。

 ## アルゴリズムのチュートリアル

 1. 2 点の座標を読み取ります。 答えは対応する座標の差に依存するため、4 つの値を保存します。 
2. 次を使用して水平変位を計算します。`x2 - x1`そして垂直変位を使用して`y2 - y1`。 両方の値が二乗されるため、符号は重要ではありません。 
3. 両方の差を二乗して加算します。 これにより、セグメントの 2 乗の長さが得られます。 
4. 合計の平方根を求めます。 結果の値は、点間のユークリッド距離です。 

これが機能する理由: 座標の差により、点間のセグメントが斜辺となる直角三角形が作成されます。 ピタゴラスの定理は、斜辺の二乗は 2 本の脚の二乗の和に等しいと述べています。 2 つの脚は正確に x と y の差であるため、計算された値は常に必要な距離になります。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    x1, y1 = map(float, input().split())
    x2, y2 = map(float, input().split())

    dx = x2 - x1
    dy = y2 - y1

    ans = math.sqrt(dx * dx + dy * dy)

    print(ans)

if __name__ == "__main__":
    solve()
```プログラムは最初に両方のポイントを読み取ります。 最終距離には小数部分が含まれる可能性があるため、座標は浮動小数点値として保存されます。 

変数`dx`そして`dy`点によって形成される直角三角形の 2 つの辺を表します。 それらを二乗すると負の符号が削除されるため、2 つの点の順序は答えに影響しません。 

表現`math.sqrt(dx * dx + dy * dy)`数式の直後に続きます。 この問題で必要な精度には、Python の浮動小数点数で十分です。

## テストケース```python
import sys
import io
import math

def solution(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    import math
    x1, y1 = map(float, sys.stdin.readline().split())
    x2, y2 = map(float, sys.stdin.readline().split())

    ans = math.sqrt((x2 - x1) ** 2 + (y2 - y1) ** 2)
    result = str(ans)

    sys.stdin = old_stdin
    return result

 ## 特殊なケース

 同一点の場合:```
0 0
0 0
```アルゴリズムが計算します`dx = 0`そして`dy = 0`。 式は次のようになります`sqrt(0 + 0)`、生産`0.0`。 このケースは一般式ですでにカバーされているため、特別な処理は必要ありません。 

垂直セグメントの場合:```
5 1
5 6
```アルゴリズムが計算します`dx = 0`そして`dy = 5`。 二乗距離は`25`、したがって、答えは次のとおりです`sqrt(25) = 5.0`。 1 つの座標の差で除算したり、両方の座標が変化すると仮定したりする解決策は、ここでは失敗します。 

対角線セグメントの場合:```
0 0
3 4
```アルゴリズムが計算します`dx = 3`そして`dy = 4`。 二乗距離は`9 + 16 = 25`、の答えを与える`5.0`。 これにより、ソリューションでは単に座標の変更を追加するのではなく、ユークリッド距離が使用されることが確認されます。
