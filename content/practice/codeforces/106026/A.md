 ## 問題の理解

 ユーザー名のリストが与えられ、順序のないユーザー名のペアが相互の「アカウントのバリアント」とみなされるものがいくつあるかを数えたいと考えています。 

2 つのユーザー名は、長さが同じである場合に互換性があるとみなされ、固定等価ルールに基づいて位置ごとにすべての文字を同じものとして扱うことができます。 このルールでは、すべての文字の大文字と小文字が区別されないことが定義されており、さらにいくつかの特別な置換が許可されます。`a`、`A`、 そして`@`交換可能であり、キャラクターは`o`、`O`、 そして`0`交換可能です。 他のすべては、大文字と小文字を区別しない文字のマッチングで通常どおり動作しますが、特殊な場合を除いて数字はそのまま残ります。`0`。 

したがって、中心的なタスクは、すべてのユーザー名のうち、すべての文字列を正規化された形式に変換した後に同一になるペアがいくつあるかを決定することです。 

入力サイズにより、ユーザー名間の二次比較は避けられます。 最大 100,000 の名前と合計 500,000 文字の場合、すべてのペアを比較するだけでも、最悪の場合約 10^10 の文字チェックが必要となり、これは 2 秒の制限をはるかに超えています。 これは、各ユーザー名が線形時間で独立して処理され、頻度構造を使用して集約される必要があることを直ちに示唆しています。 

正規化後に異なる生の文字列が同一になる場合、微妙なエッジ ケースが発生します。 例えば、`c@t`そして`cat`は同一として扱われる必要があるため、たとえ生の文字列が異なっていても、1 つの有効なペアとして提供されます。 もう 1 つの落とし穴は、次の特別なマッピングを忘れることです。`0`に`o`そして`@`に`a`、ケース折り込みのみが適用される場合、等価性が失われます。 

## アプローチ

 簡単なアプローチは、ユーザー名のすべてのペアを比較し、指定されたマッピングの下で文字ごとに同等であるかどうかを確認することです。 各ペアについて、文字列をスキャンし、その場で各位置を正規化し、比較します。 これは、類似性の定義を直接エンコードするため、論理的に機能します。 

ただし、ユーザー名が n 個ある場合は、およそ n²/2 個の比較が行われることになります。 各比較には O(L) 時間がかかります。L は文字列の平均長であり、全体の最悪のケースは O(n²L) になります。n が 10^5 の場合、これは遅すぎます。 

重要な観察は、等価性がすべての可能な文字列にわたるパーティションを定義するということです。すべてのユーザー名は正確に 1 つの正規化された形式に属し、2 つのユーザー名はその形式を共有する場合にのみ有効なペアになります。 これにより、ペアごとの比較から頻度のカウントまでの問題が軽減されます。 すべての文字列が正規表現に変換されたら、各正規文字列が出現する回数を数え、各周波数グループ内の組み合わせを合計するだけで済みます。

 ## アルゴリズムのチュートリアル

 1. ユーザー名ごとに、正規化されたバージョンを 1 文字ずつ構築します。 このステップが必要なのは、等価性は位置に関する変換のみに依存し、正規化により等価な文字列が同一になるためです。 
2. ユーザー名の各文字を標準記号に変換します。 文字は小文字にマッピングされます。 キャラクター`@`にマッピングされます`a`、 そして`0`にマッピングされます`o`。 他のすべての文字は、該当する場合、小文字変換後も変更されません。 これにより、変換後に 2 つの同等の文字が同一になることが保証されます。 
3. 正規化された各ユーザー名を、出現回数をカウントするハッシュ マップに保存します。 これにより、明示的なペアごとの比較を行わずに、すべての同等のユーザー名がグループ化されます。 
4. すべてのユーザー名を処理した後、頻度マップを繰り返し処理します。 サイズ f の各グループについて、答えに f · (f − 1) / 2 を加えます。 これにより、グループ内の順序付けされていないペアがすべてカウントされます。 
5. 最終的な累積合計を出力します。 

### なぜ効果があるのか

 正規化関数は文字間の等価関係を定義するため、位置に関して文字列にまで拡張されます。 2 つの文字列は、正規化された形式が同一である場合に限り、問題定義の下では同等です。 これは、すべての有効なペアが同一の正規化文字列の単一周波数バケット内に存在する必要があり、そのようなバケット内のすべてのペアが有効であることを意味します。 カウント式 f · (f − 1) / 2 は、各バケット内の順序のないペアをすべて正確に列挙し、二重カウントのない完全性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def normalize(s: str) -> str:
    res = []
    for ch in s.strip():
        if ch.isalpha():
            res.append(ch.lower())
        elif ch == '@':
            res.append('a')
        elif ch == '0':
            res.append('o')
        else:
            res.append(ch)
    return ''.join(res)

def solve():
    n = int(input())
    freq = {}

    for _ in range(n):
        s = input().strip()
        ns = normalize(s)
        freq[ns] = freq.get(ns, 0) + 1

    ans = 0
    for v in freq.values():
        ans += v * (v - 1) // 2

    print(ans)

if __name__ == "__main__":
    solve()
```実装の中核は正規化関数です。 すべての等価性を直接強制するので、メイン ロジックが特殊なケースについて再度推論する必要がなくなります。 この分離により、一貫性のない方法で大文字と小文字の折りたたみと数字の置換を混合するような微妙な間違いが防止されます。 

辞書は、完全に正規化されたユーザー名の頻度を蓄積します。 Python 文字列はハッシュ可能であるため、この手順は効率的であり、メモリ制限内に問題なく収まります。 

最後に、組み合わせ式が各グループに個別に適用されるため、二重カウントが回避され、順序付けされていないペアが正確に 1 回カウントされることが保証されます。
