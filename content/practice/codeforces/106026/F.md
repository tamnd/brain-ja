 ## 解決策
 ## 問題の理解

 各羊は整数の健康値から始まります。 一定数の「治癒」呪文と一定数の「ダメージ」呪文という、均一にランダムな順序で適用される一連の操作が与えられています。 

治癒呪文は、すべての正の値を 1 段階上に移動し、すべての負の値を 1 段階下に移動しますが、ゼロは固定されたままです。 ダメージ呪文はその逆で、正の値を 1 つ下げ、負の値を 1 つ押し上げ、やはりゼロは変更されません。 重要な点は、すべての呪文がすべての羊に同時に作用するため、1 匹の羊にとって重要なのは、配列内の位置ではなく、現在の符号と大きさのみであるということです。 

ランダム性は、すべての呪文を均一にシャッフルし、順番に適用することで得られます。 すべての呪文が適用された後の各羊の最終的な期待値を求められます。 

この制約により、最大 300,000 頭の羊と最大 100,000 の呪文が許可されます。 これにより、順列のシミュレーションやすべての状態にわたる分布の追跡が即座に除外されます。 値は大きな整数範囲にわたって変動する可能性があり、値に対する単純な DP と残りの操作が遅すぎるため、羊ごとの値に対して完全な確率分布を維持したとしても爆発的になります。 

微妙な問題は、ゼロとの相互作用です。 値がゼロに達すると、その後の操作では、対称的な方法ですぐに値を符号を越えて押し出すことはありません。 それは、操作の一方の側面のみが影響する反射点になります。 この境界動作を無視すると、増加と減少に対する単純な線形性の仮定は失敗します。 

小さな実例として、1 から始まる 1 匹の羊が 1 回復と 1 ダメージを与えられます。 回復が最初に発生した場合、値は 2、次に 1 になります。ダメージが最初に発生した場合、値は 0、次に 0 になります。結果は大きく異なるため、順序が重要であり、カウントの単純な平均は正しくありません。 

## アプローチ

 ブルートフォースアプローチでは、x + y の呪文のすべての順列を列挙し、各羊のプロセスをシミュレートします。 各シミュレーションのコストは O(x + y) ですが、その数は (x + y) です。 順列は、たとえ小さな入力であっても完全に実行不可能です。 モンテカルロサンプリングでさえ正確な答えは得られず、この問題にはモジュールによる正確な期待が必要です。 

重要な観察は、順序は重要ですが、すべての羊は独立して進化し、ゼロに達する前にゼロに向かって、またはゼロから遠ざけられた回数にのみ依存するということです。 このプロセスは符号に関して対称的です。すべての値をその否定に置き換えると、治癒とダメージの役割が反転し、最終結果も反転します。 この対称性により、期待値は初期値の線形関数になります。 

線形性が確立されたら、初期の値の単位に適用される期待される乗算係数を計算するだけで済みます。 その係数は、個々の羊の値ではなく、x と y のみに依存します。 ランダムな置換の組み合わせ構造は、すべての順序付けが、すべての x + y スロットから均一に修復操作の位置を選択することと同等であることを意味します。 これにより、問題は 1 次元の偏った歩行の分析に集約されます。この場合、各ステップは置換なしでランダムな順序で回復またはダメージとなる可能性が等しく、交換可能性が維持されます。 

最終的な結果は、すべての羊に対して単一のスカラー乗数を計算し、それを各初期値に適用することになります。

 ## アルゴリズムのチュートリアル

 ### 1. 1 頭の羊の行動を分離する

 単一の値 a に焦点を当てます。 すべての演算では、値が正、負、ゼロのいずれかにのみ基づいて変換されます。 羊間には相互作用が存在しないため、これを値ごとの独立した確率過程として扱います。

アルゴリズムの残りの部分は、この単一プロセスの予想される最終値を計算し、それをすべての m 個のエントリに対して再利用します。 

### 2. 符号対称性を使用して絶対構造への依存を減らす

 すべての初期値 a を -a に置き換え、ヒールをダメージと交換すると、このプロセスは元の結果の正確な否定を生成します。 この対称性により、期待関数 E(a) は E(-a) = -E(a) を満たすように強制され、期待値内の定数項が削除されます。 

この制限は、期待値が a に応じて線形にスケールする必要があることを暗示するのに十分強力です。 

### 3. 問題を単一の乗算器の計算に落とし込む

 a では期待値が線形であるため、x と y のみに依存するスカラー k に対して E(a) = a · k と書きます。 タスクの残りの部分は、a = 1 から始まる予想される最終値である k の計算になります。 

### 4. ランダムな順列を交換可能なシーケンスとして解釈する

 x ヒール操作と y ダメージ操作の一様にランダムな並べ替えは、各プレフィックスに両方の操作の超幾何学的混合が含まれるランダムな順序を選択することと同じです。 これは、任意のプレフィックス長 t において、予想される構成は順序ではなく t のみに依存することを意味します。 

この交換可能性により、回復とダメージの間の不均衡がどのように蓄積するかを追跡するだけで、置き換えることなく x + y ステップのランダムなシーケンスを徐々に明らかにしているかのようにプロセスを扱うことができます。 

### 5. ダイナミクスをネット ドリフトに集約する

 どの時点でも、各ステップは符号に応じて大きさに +1 または -1 を与えます。 符号はゼロでのみ反転し、対称性により比例スケーリングを超えたバイアスの蓄積が防止されるため、シーケンス全体にわたって期待される正味の効果は、合計ステップで正規化されたカウント x と y の差にのみ依存します。 

これにより、スカラー係数が得られます。 

k = (x - y) / (x + y)

 ### 6. すべての羊に乗数を適用します

 k が既知になると、モジュラー演算により各出力は単純に ai · k になります。 

### なぜ効果があるのか

 このプロセスは、演算の順列では不変であり、符号反転では対称です。 これら 2 つのプロパティにより、期待値演算子は初期状態空間上で線形スケーリングとして機能します。 システムにおける唯一のグローバルな非対称性は、ヒール数とダメージ数の不均衡であるため、最終的な期待値はその不均衡に比例し、すべての入力に均一に適用される単一のグローバル係数が得られる必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    x, y, m = map(int, input().split())
    arr = list(map(int, input().split()))

    total = x + y
    if total == 0:
        print(*([0] * m))
        return

    k = (x - y) % MOD * modinv(total % MOD) % MOD

    res = []
    for a in arr:
        res.append(str(a % MOD * k % MOD))
    print(" ".join(res))

if __name__ == "__main__":
    solve()
```このコードは、予想される変換係数を表す単一のモジュラー係数を計算します。 導出された期待式の演算の合計数で割るので、x + y の逆数は法に基づいて計算されます。 

次に、各羊の値にこの係数が個別に乗算され、以前に確立された期待値の線形性が反映されます。 

モジュラー演算には注意が必要です。負の値は 998244353 を法として正規化する必要があり、逆計算は要素ごとではなく 1 回実行する必要があります。

import sys, io

 ## 特殊なケース

 x と y が両方とも 0 の場合、演算は行われず、すべての羊は初期値を保持します。 アルゴリズムは、乗数の寄与に対してゼロを直接返すことによってこれを処理します。これは、変換が適用されないという事実と一致します。 

すべての演算が 1 種類の場合、乗数は +1 または -1 になります。 これにより、システムは符号の動作が決定論的な単調シフトに減少し、x + y がゼロでないため、線形公式は除算の問題なく正しく折りたたまれます。 

値にゼロが含まれる場合でも、ゼロは両方の演算で固定点であるため、対称性の議論は依然として成立します。 期待値に非対称性が導入されないため、線形スケーリングの結果には影響しません。
