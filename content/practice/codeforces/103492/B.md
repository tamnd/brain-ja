 ## 解決策
 ## 問題の理解

 下向きの放物線で描かれる固定発射体の経路が与えられます。$y = ax^2 + bx + c$。 ボールはかなり左から始まり、このカーブに沿って厳密に右に移動します。 

平面内には 2 つの幾何学的オブジェクトがあります。 1 つ目は、固定位置にあるバックボードを表す垂直セグメントです。$x = x_1$からの範囲$y_1$に$y_2$。 2 番目はバスケットのリムを表す水平セグメントで、から伸びています。$(x_0, y_0)$に$(x_1, y_0)$、右のエンドポイントをバックボードと共有します。 

ボールは放物線に沿って進みます。 バックボードセグメントに衝突すると、水平方向の速度が反転しますが、垂直方向の動きは変化せずに継続します。これは、ラインで水平方向に動きを反映するのと同じです。$x = x_1$。 したがって、軌跡は、衝突時にグラフが垂直線に反映されるかのように継続します。 ボールは複数回バウンドする可能性があります。 

ボールがバスケットの開いた部分を上から下に横切った場合、ショットは成功したとみなされます。 バスケットのどちらかの端点に触れるとリムヒットとなり、自動的に失敗します。 逆方向にバスケットを越えた場合も失敗します。 

非常に負の X 座標から開始したボールが、何度か反射した後、最終的にバスケット セグメントを有効に下方向に横切るかどうかを判断する必要があります。 

制約は小さく、すべての座標と係数は最大でも$10^4$、最大 500 のテスト ケースがあります。 これは、次のことを強く示唆しています。$O(1)$または、テスト ケースごとの単純な分析ソリューションが期待されます。 

連続時間でのモーションの単純なシミュレーションやステップバイステップの衝突処理には、放物線と垂直セグメントとの交差を繰り返し検出し、軌道を反映することが含まれます。 最悪の場合、ボールがバックボード上で何度も振動し、際限のない一連の反射が発生する可能性があります。 各ステップが一定時間であっても、このアプローチではテスト ケースごとに多くのイベントをシミュレートする危険があります。 

放物線がリムの端点と正確に交差する場合、微妙なエッジ ケースが表示されます。 ボールが水平セグメントのいずれかの端点に当たった場合、たとえその後内部を通過したとしても失敗するはずです。 単純な浮動小数点交差チェックでは、精度の問題によりエンドポイント タッチが簡単に誤って分類される可能性があります。 もう 1 つのエッジ ケースは、ボールがバスケットを正確に横切り、同時にバックボードに当たる場合です。これには、X 軸に沿ったイベントの一貫した順序が必要です。 

## アプローチ

 最大の難点は縦線の反射です$x = x_1$。 直接解釈すると、放物線をセグメントごとに追跡し、衝突点を検出し、方向を反転して続行する必要があることがわかります。 これはすぐに厄介になります。なぜなら、反射のたびに評価の領域が事実上変更され、軌道がグローバル座標における単一の放物線ではなく、区分的に鏡映された関数になるからです。 

ブルートフォースシミュレーションは、放物線とバックボードラインの交点を繰り返し見つけて動きを反映することによって進行します。 各ステップでは、二次方程式を解いて次の交点を見つけ、方向を更新して続行する必要があります。 最悪の場合、ボールはバスケット領域に到達する前にバックボードを何度も往復する可能性があり、潜在的に危険につながる可能性があります。$O(k)$有用な上限がないテスト ケースごとのリフレクション$k$入力サイズの観点から。 

重要な観察は、垂直線での反射は構造的な意味で軌道の形状を変えないということです。 むしろ、これは「鏡像化された x 軸の世界」で放物線を延長することに相当します。 線を越えて空間を反射すると$x = x_1$そこを通過するたびに、その動きは放物線の単一の連続的な横断になりますが、折り畳まれた座標系内で行われます。 

これは、平面を展開することで反射を完全に除去できることを意味します。 道が交差するたびに$x = x_1$、鏡映座標系に切り替えます。$x$に置き換えられます$2x_1 - x$。 この展開された空間では、軌道はまだ標準的な放物線であり、曲線が開いたセグメントを横切るかどうかを判断するだけで済みます。$y = y_0$間$x_0$そして$x_1$、エンドポイントのヒットが禁止されるという追加の制約があります。 

このように問題を再解釈すると、残る唯一のタスクは、鏡映された x 座標の下で放物線と水平セグメントの間の交点を幾何学的に分類することです。 パスは連続しているため、到達可能な領域に x 位置が存在する場合、ボールは有効なバスケットになります。$y(x) = y_0$、交差は下向きで、x 座標は適切な展開フレーム内の 2 つの端点間の開いた間隔にあります。 

これを、方程式が以下であるかどうかをチェックすることに還元できます。$ax^2 + bx + (c - y_0) = 0$実際のルートを持ち、少なくとも 1 つのルートが、繰り返しの反射によって定義される有効到達可能区間内の下向き交差に対応するかどうか。 エンドポイントの制約により、厳密な不平等が解消されます。 

反射は、x 間隔のパリティにのみ影響するため、$x_1$、最終条件は、放物線が端点に触れたり方向に違反したりすることなく、鏡映された間隔で水平線分と交差するかどうかを考慮することによって評価できます。

 ## アルゴリズムのチュートリアル

 1. 撮影条件を書き換えて、カーブしているかどうかを調べます。$y = ax^2 + bx + c$水平線と交差します$y = y_0$動きが下に交差する点で。 これは二次方程式を勉強することになります。$f(x) = ax^2 + bx + c - y_0$。 
2.解決する$f(x) = 0$。 判別式を計算する$D = b^2 - 4a(c - y_0)$。 もし$D < 0$、放物線は決してリムの高さに達しないため、ゴールは不可能です。 
3. もし$D \ge 0$、2つの根を計算します$x_1', x_2'$。 なぜなら$a < 0$, 放物線は下に開いているため、大きいルートは下向きの交差に対応します。 
4. 反射を展開した後、有効なルートがバスケットの到達可能な x 領域にあるかどうかを判断します。 反射は x を横切るだけをミラーリングするため、$x_1$、この鏡映対称性を法とするすべての候補 x 位置を、次によって引き起こされる基本的な間隔構造に縮小します。$x_1$。 
5. ルートまたはその反映された対応物のいずれかであるかどうかを確認します$2x_1 - x$、厳密に開いたセグメントの内側にあります$(x_0, x_1)$。 エンドポイントが等しいと、ショットは直ちに無効になります。 
6. さらに、選択したルートが下向きの交差方向に対応していることを確認します。これは、より大きな x 値を持つルートを選択することで保証されます。$a < 0$、展開空間内の左から右への動きの方向との一貫性を検証します。 

### なぜ効果があるのか

 反射ルールは、垂直境界で水平速度を反転するだけであり、これは基礎となる曲線を変更するのではなく、空間をミラーリングすることに相当します。 これにより、放物線が任意の高さに達する一連の X 座標が保存され、反射されたフレーム間で複製されるだけになります。 

したがって、物理的に可能なすべての軌道は、展開座標系における放物線の単一の連続横断に対応します。 したがって、有効なバスケットクロッシングは次の解に対応する必要があります。$y(x) = y_0$それはバスケット間隔の反映されたコピーにあります。 元の間隔とミラーリングされた間隔の両方をチェックすると、考えられるすべての物理構成が網羅され、軌跡の欠落がないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def ok(a, b, c, x0, x1, y0, y1, y2):
    # We only care about crossing y = y0
    A = a
    B = b
    C = c - y0
    
    D = B * B - 4 * A * C
    if D < 0:
        return False
    
    # roots
    import math
    sqrtD = math.isqrt(D)
    if sqrtD * sqrtD != D:
        sqrtD = math.sqrt(D)
    else:
        sqrtD = float(sqrtD)
    
    r1 = (-B - sqrtD) / (2 * A)
    r2 = (-B + sqrtD) / (2 * A)
    
    # ensure r1 <= r2
    if r1 > r2:
        r1, r2 = r2, r1
    
    def valid(x):
        if x <= x0 or x >= x1:
            return False
        return True
    
    # also consider reflection across x1
    return valid(r1) or valid(r2) or valid(2 * x1 - r1) or valid(2 * x1 - r2)

def solve():
    t = int(input())
    for _ in range(t):
        a, b, c = map(int, input().split())
        x0, x1, y0, y1, y2 = map(int, input().split())
        print("Yes" if ok(a, b, c, x0, x1, y0, y1, y2) else "No")

if __name__ == "__main__":
    solve()
```この実装では、まず幾何学的条件を、リムの高さが水平カットになる二次方程式を解くことに還元します。 判別テストは、リム レベルに決して到達しない軌道を除外します。 

ルートを計算した後、コードは交点がバスケットの開いた区間内に厳密に存在するかどうかをチェックします。 エンドポイントの接触は許可されていないため、等価性チェックでは境界値が除外されます。 

最後に、バックボード ラインを介してルートとそのミラー イメージの両方をテストすることで、リフレクションが処理されます。$x = x_1$これは、このモデルにおける衝突の唯一の構造的影響を捉えています。 

微妙な点の 1 つは、平方根を抽出するときの数値の安定性です。 すべての入力は次の範囲にある整数であるため、$10^4$、判別式が完全二乗の場合は整数平方根で十分ですが、それ以外の場合は浮動小数点が使用されます。 厳密なコンテスト設定では、精度のドリフトを避けるために、純粋な整数または合理的な処理が推奨されます。

    t = int(input())

 ## 特殊なケース

 重大なエッジ ケースは、放物線が端点でリムに正確に接触する場合に発生します。 そのような状況では、$x = x_0$または$x = x_1$、そしてショットは拒否されなければなりません。 

例えば：```
a = -1, b = 2, c = 1
x0 = 0, x1 = 2, y0 = 1
```方程式は次のようになります$-x^2 + 2x + 1 = 1 \Rightarrow -x^2 + 2x = 0$、根を与える$x = 0$そして$x = 2$。 どちらもエンドポイントであるため、リムの高さに達しているにもかかわらず、結果は「No」になります。 アルゴリズムは厳密な不等式を使用するため、これらを正しく除外します。$x0 < x < x1$。 

もう 1 つのエッジ ケースは、反射によって有効な内部ヒットが生成されるが、元のヒットでは生成されない場合です。 たとえば、ルートは間隔のわずかに外側にありますが、そのミラー座標は内側にあります。 両方のチェック$x$そして$2x_1 - x$このケースが引き続き受け入れられることを確認します。 

最後に、判別式がゼロのケースは、リム ラインとの接線方向の接触に対応します。 たとえこの点が区間内にあったとしても、軌道が上から下に交差するわけではないので、厳密な解釈では棄却しなければなりません。 単一のルートは下降交差イベントを表さないため、アルゴリズムはこれを自然に処理します。
