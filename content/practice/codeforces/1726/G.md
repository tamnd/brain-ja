## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    people = sorted(zip(a, b))
    
    # precompute factorials
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD

    inv_fact = [1] * (n + 1)
    inv_fact[n] = modinv(fact[n])
    for i in range(n, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % MOD

    def C(n, r):
        if r < 0 or r > n:
            return 0
        return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

    ans = 1
    i = 0
    while i < n:
        j = i
        ones = 0
        while j < n and people[j][0] == people[i][0]:
            ones += people[j][1]
            j += 1

        k = j - i
        ans = ans * C(k, ones) % MOD
        i = j

    print(ans)

if __name__ == "__main__":
    solve()

主要な実装の詳細は、すべての組み合わせ計算がモジュロで実行されることです。$998244353$階乗事前計算により、ソート後も解が線形のままであることが保証されます。

 ## 特殊なケース

 いつすべて$a_i$が等しい場合、問題全体は 1 つの組み合わせブロックにまとめられます。 その場合、答えはその数によってのみ決まります。$b=1$そして$b=0$値が存在し、アルゴリズムは単一の二項係数に還元され、グループ化ステップで直接処理されます。 

いつすべて$b_i$すべて 1 またはすべて 0 が同一である場合、各ブロックは 1 つの構成にのみ寄与します。 アルゴリズムはブロックごとに 1 を正しく返します。これは、内部の再配置によって有効性が変更されないことを反映しています。 

値が厳密に増加している場合、すべての人がシングルトン ブロックを形成します。 各ブロックは 1 を寄与するため、答えは 1 になります。これは、制約が増加しても順序が完全に厳格であるという事実と一致します。
