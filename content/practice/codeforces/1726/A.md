 ## 解決策
 ## 問題の理解

 正の整数の配列が与えられます。 連続したセグメントを 1 回だけ選択し、任意の量だけ周期的に回転させることができます。つまり、残りの要素の相対的な順序を維持しながら、セグメント内の任意の要素を選択して、そのセグメントのどちらかの端に移動できることを意味します。 

この 1 つの操作を実行した後は、配列全体の最後の要素と最初の要素の違いのみを気にするようになります。 タスクは、この最終的な違いを最大化する方法でセグメントと回転を選択することです。 

重要な点は、この操作では値が変更されることはなく、値が並べ替えられるだけであるということです。 したがって、どの元の要素が位置 1 に配置され、どちらが位置 n に配置されるかを操作しようとしています。 

制約は非常に制御された方法で小さくなっています。 各配列には、すべてのテスト ケースにわたって合計で最大 2000 個の要素があります。 これにより、大きな定数を使用する 3 次または 2 次を多用するテストごとのアプローチは即座に除外されますが、それでも O(n^2) または O(n^2 log n) の解を快適に使用できます。 

単純な間違いは、エンドポイントのみが重要であると考えたり、配列全体の回転のみを考慮したりすることです。 もう 1 つのよくある間違いは、最良の答えが単純に max(a) から min(a) を引いたものであると仮定することです。これは、回転構造が許可しない限り、両端に両方の極値を任意に配置することはできないことを無視しています。 

具体的な失敗例は配列です。`[2, 1, 5]`。 最良の答えは 4 です。回転させることで得られます。`[2,1,5]`に`[5,2,1]`。 「最大値を最後に、最小値を先頭に独立して配置する」といった単純な考えは、これらの位置を独立して制御できないため、失敗します。 

## アプローチ

 ブルートフォースアプローチにより、考えられるすべてのセグメントが試行されます`[l, r]`そしてあらゆる可能な回転。 構成ごとに、結果として得られる最初と最後の要素を再計算し、最良の違いを追跡します。 O(n^2) のセグメントがあり、セグメントごとに最大 O(n) の回転があり、各評価は O(n) であるため、これはすぐに非常に大きくなり、直接シミュレーションではテストあたり約 O(n^4) になります。 

この簡素化は、選択したセグメントの内部配置は気にせず、セグメントのどの要素が回転後に最初または最後の境界になるかだけを考慮することに由来しています。 循環回転により、セグメント内の任意の要素をセグメントのどちらかの端に移動できます。つまり、関連する唯一の効果は、セグメント内の任意の要素のペアを選択して、それらを境界線に隣接させることができるということです。 

したがって、問題は、1 つのセグメント操作の後、一方が最初の要素になり、もう一方が最後の要素になるように 2 つの位置 i と j を選択することに帰着します。 次に、単一セグメントの回転を使用して、i が位置 1 または n になり、j がもう一方の端になるすべての方法を分析します。 

重要な構造の単純化は、最後の最初の要素を修正した後は、最後の要素がどれだけ優れたものを達成できるかを考慮するだけで済み、またその逆も同様であるということです。 これは、考えられるすべての境界選択について、1 つのエンドポイントをカバーするセグメントを介して適切にシフトできる残りのサフィックスまたはプレフィックスにどのような極値が存在するかをチェックすることにつながります。 

これにより、問題が位置ごとの定数時間チェックによる線形スキャンに分解され、実装スタイルに応じて O(n) または O(n^2) の解が得られますが、問題なく制限内に収まります。

 | ブルートフォース | O(n^4) | O(n) | 遅すぎる |

 ## アルゴリズムのチュートリアル

 最初の要素を変更する唯一の方法は選択したセグメントにインデックス 1 を含めることであり、同様に最後の要素を変更する唯一の方法はセグメントにインデックス n を含めることであるという重要な観察に焦点を当てます。 それ以外の場合、それらの位置は変更されません。 

これにより、すべての有効な操作が 3 つの意味のあるカテゴリ (左端に接触するセグメント、右端に接触するセグメント、または配列全体) に分割されます。 

1. まず、インデックス 1 またはインデックス n にまったく触れないことを検討します。 その場合の答えは単純に、`a[n] - a[1]`エンドポイントが固定されたままであるためです。 これは常にベースライン候補です。 
2. 次に、インデックス 1 を含むセグメントを検討します。セグメントを選択することにより、`[1, r]`、そのプレフィックス内の任意の要素が最初の要素になるように回転できます。 これは、最初の要素を任意の要素と等しくできることを意味します。`a[i]`どこ`i ≤ r`。 セグメントが n に触れない限り、最後の要素は変更されません。 
3. 同様に、インデックス n を含むセグメントを考えます。 選択することで`[l, n]`を使用すると、そのサフィックス内の要素が最後の要素になるように回転できます。 これにより、最後の要素を任意の要素にすることができます`a[i]`どこ`i ≥ l`一方、最初の要素は l = 1 でない限り変更されません。 
4. 最後に、両方のエンドポイントを含むセグメントを考慮します。`[1, n]`。 この場合、配列全体の任意の回転を選択できるため、両端に配置できる限り、任意の要素を最初に選択し、任意の異なる要素を最後に選択することができます。 ここでの最適な選択は単純に max(a) - min(a) です。 
5. 唯一欠けているケースは、1 つのエンドポイントだけを変更する場合です。 最初の要素のみを変更する場合は、位置 i を新しい最初の要素として固定し、a[n] を最後に保持して、最大化します。`a[n] - min(a[1..n-1])`有効な到達可能な構造を超えて。 対称的に、最後の要素のみを変更すると、`max(a[2..n]) - a[1]`。 
6. これらすべての候補値を計算し、最大値を取得します。 

### なぜ効果があるのか

 操作は基本的にセグメント境界によって制限されます。 回転では 1 つの連続したブロック内の要素のみが並べ替えられるため、ブロックの外側のエンドポイントは固定されたままになります。 単一のセグメントが両方に影響を与えるかどうかを考慮せずに、両端を個別に最適化しようとする戦略は、不可能な構成を過剰にカウントすることになります。 正しい解決策は、各エンドポイントが選択したセグメントの内側にあるか外側にあるかを分類し、それらの一貫したケースを徹底的に調べることから得られます。 達成可能な最終構成はすべて、これらのエンドポイント包含パターンのいずれかに該当するため、それらの最良のものを採用することで最適性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    if n == 1:
        print(0)
        continue

    base = a[-1] - a[0]
    best = base

    mn_all = min(a)
    mx_all = max(a)

    best = max(best, mx_all - mn_all)

    mn_prefix = min(a[:-1])
    best = max(best, a[-1] - mn_prefix)

    mx_suffix = max(a[1:])
    best = max(best, mx_suffix - a[0])

    print(best)
```このコードは、選択したセグメントが最初の要素に影響を与えるか、最後の要素に影響を与えるか、両方に影響を与えるか、あるいはどちらにも影響を及ぼさないかに基づいて、構造的に異なる 4 つの可能性を計算します。 ベースラインでは、両方のエンドポイントが変更されません。 両方のエンドポイントを完全なセグメント内で操作できる場合、グローバル範囲は完全な柔軟性を処理します。 プレフィックスとサフィックスのケースは、その側に固定されているセグメントを選択することによって、ちょうど 1 つのエンドポイントを変更することに対応します。 単純なスキャン後の各計算はテストごとに一定時間かかります。 

スライスには注意が必要です。`a[:-1]`そして`a[1:]`n ≥ 1 であるため安全ですが、そうしないとこれらのスライスが空になり、最小/最大の仮定が崩れてしまうため、明示的に n = 1 を保護します。 

## 実用的な例

 2 つの入力をトレースします。1 つは小さな非対称の場合、もう 1 つは全体的な極端な場合です。 

### 例 1

 入力:`[2, 1, 5]`| ステップ | ベース (a[n]-a[1]) | 最小プレフィックス | 最大サフィックス | グローバル最大値-最小値 | 最高 |
 | --- | --- | --- | --- | --- | --- |
 | 初期化 | 3 | - | - | - | 3 |
 | プレフィックス更新 | 3 | 1 | - | - | 3 |
 | サフィックスの更新 | 3 | 1 | 5 | - | 4 |
 | グローバルアップデート | 3 | 1 | 5 | 4 | 4 |

 接尾辞演算により、最初の要素を固定したまま最後の要素を改善することができ、最適な回転と一致する 5 − 1 = 4 が生成されます。 

### 例 2

 入力:`[1, 3, 9, 11, 5, 7]`| ステップ | ベース | 最小プレフィックス | 最大サフィックス | グローバル |
 | --- | --- | --- | --- | --- |
 | 初期化 | 6 | - | - | - |

 | 接尾辞 | 6 | 1 | 7 | - |
 | グローバル | 6 | 1 | 7 | 10 |

 最適な構成は、全範囲を使用することにより得られ、11 − 1 = 10 となります。 

これらのトレースは、各構造ケースが、単一の回転がエンドポイントと相互作用するさまざまな方法にどのように対応するかを示しています。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        if n == 1:
            out.append("0")
            continue
        base = a[-1] - a[0]
        best = base
        best = max(best, max(a) - min(a))
        best = max(best, a[-1] - min(a[:-1]))
        best = max(best, max(a[1:]) - a[0])
        out.append(str(best))
    return "\n".join(out)

 ## 特殊なケース

 次のような単一要素配列の場合`[7]`の場合、回転するたびに配列が変更されず、同一のエンドポイント間の差がゼロになるため、アルゴリズムは 0 を返します。 コードはスライスの前にこれを明示的に処理し、無効な最小/最大操作を回避します。 

次のような単調増加配列の場合`[1,2,3,4]`、最善の策は、配列全体を回転して先頭に 4、末尾に 1 を配置し、3 を与えることです。グローバル最大-最小ケースは、これを直接キャプチャします。`max(a) - min(a)`。 

最適な改善のために 1 つのエンドポイントのみを変更する必要があるアレイの場合、`[5,1,4,3]`、サフィックスとプレフィックスのケースは、両方のエンドポイントを同時に移動する必要なく、境界をどこまで改善できるかを正確に分離します。
