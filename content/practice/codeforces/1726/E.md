 ## 問題の理解

 サイズの順列が何回あるかを数えるように求められます$n$順列とその逆の両方を含む非常に特殊な構造的制約を満たします。 

順列の場合$p$、値$p_i$位置に配置される番号です$i$、 その間$p^{-1}_i$値が入る位置です$i$が表示されます。 条件は、インデックスごとに、各位置とそこに存在する値の位置を比較します。$i$、間の絶対的な違い$i$そして値の位置$p_i$最大でも 1 でなければなりません。 

つまり、その位置に立つと、$i$、値を見てください$x = p_i$、次に場所を見つけます$x$順列内に位置し、その位置は～から 1 歩以上離れることはできません。$i$。 

これにより、位置と値が即座に対称的に結び付けられます。 各ペア$(i, p_i)$どこに制約を設けるか$i$そして$p_i$は相互に相対的に存在する必要があり、逆数が含まれるため、構造は本質的に双方向です。 

入力は、次のいくつかの独立した値で構成されます。$n$、そしてそれぞれについて、そのような順列の数を法で計算する必要があります$998244353$。 すべての合計$n$値が大きいため、ソリューションでは効率的に前処理を行い、各クエリに迅速に応答する必要があります。 

素朴な解釈では、順列を生成して条件をチェックしようとします。 これは次の場合にすぐに失敗します$n$成長するので、$n = 300000$作る$n!$完全に不可能です。 

順列を貪欲に検証しようとすると、さらに微妙な落とし穴が現れます。 制約はグローバルです: ローカル ペアを固定します$(i, p_i)$は順方向と逆方向の両方の位置に影響を与えるため、部分的な構築は後で目に見えない制約に簡単に違反する可能性があります。 たとえば、強制的に$p_i = i+1$後で強制するかもしれない$p_{i+1} = i$、その結合を考慮できないと、無効なカウントが発生します。

## アプローチ

 ## アルゴリズムのチュートリアル

 置換制約を線形構造上の計数問題に変換します。 

1. この条件を、インデックスをペアにする方法に対する制限として解釈します。 位置に値がある場合$i$位置を指す$j$、その後、逆条件が強制します$i$近くにいる$j$を制限します$j$～の非常に狭い近所に横たわる$i$。 これにより、長距離の依存関係が排除され、ローカル構成のみが重要になることが保証されます。 
2. どのようなローカル構成が可能かを分析します。 位置は固定されたままであることも、隣接する位置との小さな相互作用の一部であることもできます。 逆マッピングを通じてトレースすると、一部の要素が距離制約に違反することになるため、これより大きなサイクルは形成できません。 
3. このことから、有効な順列は線に沿った独立したセグメントに分解できることがわかります。各セグメントは、その長さの境界にのみ依存する小さな有限のパターンのセットから選択されます。 
4. プレフィックス長を超えた DP を定義します$i$ここで、状態は、最初の順列を構築する有効な方法の数をカウントします。$i$ポジション。 各ステップで、長さ 1 ブロックを作成するか長さ 2 ブロックを作成するかに応じて、単一の固定点を配置するか、前の位置との小さなペア構造を使用して拡張します。 
5. 各位置がサイズ 1 のブロックを開始することも、サイズ 2 の相互作用を完了することもできるため、これはフィボナッチのような反復につながります。 最大値まで DP を事前計算します。$n$すべてのテストケースにわたって。 
6. 各クエリは、事前計算された配列から直接応答されます。 

### なぜ効果があるのか

 重要な不変条件は、最初の処理後、$i$このプレフィックス上のすべての有効な構成は、プレフィックスを独立したローカル ブロックに分割する方法によって完全に決定され、将来の決定がプレフィックス内の有効性に影響を与えることはありません。 逆距離制約は、隣接する位置を超えて交差するエッジが直ちに条件に違反することを保証するため、依存関係が一定の長さを超えることはありません。 これにより、DP 状態は、省略や二重カウントなしに、すべての有効な部分構造を確実にキャプチャします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    ns = [int(input()) for _ in range(t)]
    max_n = max(ns)

    # dp[i] = number of almost perfect permutations of length i
    if max_n == 0:
        return

    dp = [0] * (max_n + 1)
    dp[0] = 1
    if max_n >= 1:
        dp[1] = 1

    for i in range(2, max_n + 1):
        dp[i] = (dp[i - 1] + dp[i - 2]) % MOD

    out = []
    for n in ns:
        out.append(str(dp[n]))
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```実装では、単一の DP テーブルを必要な最大値まで事前計算します。$n$。 反復は、各ステップでの 2 つの構造の選択を反映しています。つまり、単一の固定要素による拡張、または強制的なローカル構造内の隣接する要素のペアによる拡張です。 オーバーフローを防ぐために、モジュラー演算がすべてのステップで適用されます。 

テスト ケースごとに再計算すると同じ作業が繰り返され、制限時間を超えてしまうため、クエリに応答する前の前処理の順序は非常に重要です。

 ## 特殊なケース

 のために$n = 1$、順列には 1 つの要素のみが含まれます。 位置と逆位置の両方が 1 であるため、制約は空に満たされ、アルゴリズムは次の値を返します。$dp[1] = 1$。
