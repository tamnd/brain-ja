 ## 解決策
 ## 問題の理解

 整数の複数のセットが与えられ、それらのいくつかを選択して、選択した要素を長方形のグリッドに配置することができます。 選択されたすべての要素は 1 つのセルを正確に占有し、グリッドは選択された値で完全に埋められます。 

グリッドには強力な構造上の制約があります。つまり、すべての行内ですべての値が個別である必要があり、すべての列内ですべての値も個別である必要があります。 すべての入力数値を使用する必要はありませんが、使用されるセルの数、つまり長方形の面積を最大化したいと考えています。 

出力は、可能な最大の領域だけでなく、そのような長方形の明示的な構築でもあります。 

n が 4 × 10^5 までの制約により、n の二次関数が除外されます。 考えられるすべての四角形をテストしたり、多くの構成の配置を明示的にシミュレートしようとするアプローチは、すぐに失敗します。 並べ替えやスキャンでも問題ありませんが、O(n √n) 以下の動作をするものは慎重に正当化する必要があります。 

周波数が大きく偏っている場合、微妙な問題が発生します。 たとえば、すべての数値が同一の場合、行で値が繰り返されるため、1 × 1 より大きい四角形は無効になります。 逆に、すべての数値が異なる場合は、単一の行または列を形成できますが、構造を制限する行と列の両方の制約を尊重する必要があります。 

2 番目の自明ではないケースは、多くの値が適度な頻度で出現する場合です。 両方の側面を制御せずに「できるだけ多くを取得する」という貪欲な選択は失敗します。 たとえば、最初に行を最大化しようとすると、列ができてしまい、後で使用可能な要素を破棄せざるを得なくなる可能性があります。 

## アプローチ

 強引なアイデアとしては、p × q ≤ n となるような次元 p と q の考えられるすべてのペアを試し、次に最も頻度の高い値を最初に使用して p × q グリッドを埋めることを試みることです。 候補となる四角形ごとに、行と列の一意性を維持しながら値を割り当てることができるかどうかをシミュレートします。 n の約数ペアの数は O(√n) であり、各検証にはスキャン頻度と O(n) のコストがかかる可能性がある割り当ての実行が必要になるため、これはすぐにコストが高くなります。 これは O(n √n) になりますが、これは 4 × 10^5 には遅すぎます。 

重要な洞察は、視点を逆転させることです。 最初に長方形を選択する代わりに、値の頻度から始めます。 頻度 f の各値は、列ごとに最大 1 回、行ごとに最大 1 回出現する可能性があるため、p 行と q 列の四角形を決定した場合、各値は最大でも min(f, p × q 配置、ただし列全体に分散) に寄与します。 さらに重要なのは、行または列の繰り返しなしでオカレンスを配置すると解釈した場合、固定長方形内で各値を最大 min(f, p, q) 回使用できることです。 実際の制約は、列ごとに考えると単純になります。各列に重複を含めることはできないため、値は列ごとに最大 1 回、つまり合計で最大 q 回出現できます。 

これは貪欲な構造観察につながります。q (列数) を固定すると、各値は最大でも min(f, q) 個の使用可能なコピーに寄与します。 この方法ですべての周波数を切り詰めた後、使用可能なコピーをすべてソートし、サイズ q の完全な行が何行形成できるかを確認できます。 完全な行が p 個ある場合、回答領域は p × q になります。 

次に、すべての妥当な q 値に対して反復処理を行います。 意味のある候補は最大周波数までの q のみです。これを超えて q を増加しても、ほとんどの値で使用可能な寄与が増加せず、パッキング効率が低下するためです。 各 q について、使用可能なセルの合計を計算し、p = total // q を導き出し、最良の製品を追跡します。 

これにより、問題は 1 次元スイープによる制御された周波数パッキング問題に変換されます。

 | 周波数の切り捨て + 列に対する貪欲 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 まず、すべての値の頻度を数えます。 これにより、各個別の数値がグリッド内に何回出現する可能性があるかがわかります。 

次に、固定列数 q を考えます。 頻度 f の値ごとに、min(f, q) 個のコピーを取得します。これは、1 つの列では値が最大 1 回出現できるため、q 列全体で q 回の出現を超えることができないためです。 このステップでは、周波数制約を使用可能な「容量」に変換します。 

すべての値にわたってこれらの寄与を収集した後、この q に対して使用可能なセルの総数を計算します。 q 列の長方形を形成しようとすると、サイズ q の行しか完全に埋めることができないため、行数は p = total // q になります。 

面積 p × q を評価し、最良の (p, q) ペアを維持します。 q の探索は最大周波数までのみ行う必要があります。これを超えると切り捨て動作が安定し、q を大きくしてもパッキングを改善できないからです。 

最適な (p, q) が見つかったら、グリッドを再構築します。 それぞれの値が最大 q 回出現する、使用可能な出現のリストを再度作成します。 次に、グリッドを行ごとに埋めていき、列が重複する値を受け取らないように、周期的な列方式で出現を分散させます。 

### なぜ効果があるのか

 重要な不変条件は、固定 q の場合、切り捨て min(f, q) が列の一意性を損なうことなく値が出現できる最大回数を正確に捕捉することです。 サイズ p × q の配置はすべてこの境界を尊重する必要があり、値ごとに最大 q 個のコピーを使用する構築は、列全体にオカレンスを分散することで列の競合なしで q 列グリッドに配置できます。 q を最大化すると、構造的に異なる列制約をすべて探索できるようになり、p を合計 // q として選択すると、長方形が完全に埋められるため、無駄な容量が残らないようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    from collections import Counter
    cnt = Counter(a)
    
    vals = []
    for v, f in cnt.items():
        vals.append((f, v))
    
    vals.sort(reverse=True)
    
    maxf = max(cnt.values())
    
    best_p = 1
    best_q = 1
    best_area = 1
    
    # try all possible q (columns)
    for q in range(1, maxf + 1):
        total = 0
        for f, _ in vals:
            total += min(f, q)
        
        p = total // q
        if p * q > best_area:
            best_area = p * q
            best_p = p
            best_q = q
    
    # build usable occurrences
    used = []
    for f, v in vals:
        take = min(f, best_q)
        used.extend([v] * take)
    
    used.sort(key=lambda x: cnt[x], reverse=True)
    
    grid = [[0] * best_q for _ in range(best_p)]
    
    idx = 0
    pos = [[] for _ in range(best_q)]
    
    for v in used:
        col = len(pos) - 1
        # assign greedily to columns in round-robin fashion
        # ensuring distribution
        while col >= 0 and len(pos[col]) >= best_p:
            col -= 1
        if col < 0:
            col = 0
        pos[col].append(v)
    
    for i in range(best_p):
        for j in range(best_q):
            grid[i][j] = pos[j][i]
    
    print(best_p * best_q)
    print(best_p, best_q)
    for row in grid:
        print(*row)

if __name__ == "__main__":
    solve()
```このコードは、まず入力を周波数に圧縮し、次に考えられる各列数 q を評価します。 各 q について、各値の出現回数が q に制限されている場合に使用できる要素の数を計算します。 これにより、形成できる完全な行の数が直接決まります。 

再構築ステージでは、それぞれが列を表す q 個のバケットを構築します。 どのバケットも p 要素を超えないように、値はこれらのバケットに分散されます。 これにより、切り捨てステップにより各値が列ごとに最大 1 回出現するため、列の一意性が保証されます。 

最後に、列から行ごとに読み取り、四角形を作成します。 

デリケートな部分は、カラム分散がどのカラムからもオーバーフローしないようにすることです。 この構築は、割り当てられた要素の合計が正確に p × q であるという事実に依存しているため、完全なバランスが可能です。

```頻度は1→3、2→2、3→1です。

したがって、q = 3、p = 2 を選択します。

 ## 特殊なケース

 次のような完全に同一の配列`1 1 1 1`これより大きなグリッドでは行と列で値が繰り返されるため、有効な長方形には強制的にエリア 1 が設定されます。 q ≥ 1 の場合、使用可能な合計は min(f, q) = 1 となり、p = 1 となるため、アルゴリズムはこれを処理します。 

次のような完全に異なる配列`1 2 3 4 5`動作が異なります。 q = 1 の場合、p = 5 および面積 5 が得られます。q > 1 の場合、切り捨てにより使用可能な合計が減り、無効な過剰拡張が防止されるため、アルゴリズムは単一列または単一行の構成を正しく選択します。 

のような偏ったケース`1 1 1 2 2 3`トランケーションのバランス効果を示します。 切り捨てがないと、値 1 が優勢になり、パッキングが歪められます。 min(f, q) を使用すると、寄与が安定し、列の競合のない正しい長方形のパッキングが得られます。
