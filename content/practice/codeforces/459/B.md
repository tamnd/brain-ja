 ## 解決策
 ## 問題の理解

 私たちに与えられている美の価値観は、`n`花。 正確に 2 つの花を選ばなければなりません。 

考えられるすべてのペアの中で、美しさの差ができるだけ大きいペアのみに興味があります。 タスクは 2 つの値を出力することです。 

まず、選択した 2 つの花の美しさの最大の差異。 

第 2 に、この最大の差を達成する個別の花のペアの数です。 花は位置によって区別されるため、同じ美しさを持つ 2 つの花であっても、インデックスが異なる場合は、異なる選択肢になります。 

制約は大きいです。 まであります`2 * 10^5`花、美しさの値は次のように大きくなります。`10^9`。 すべてのペアを検査する二次アルゴリズムでは、大まかに次のものが必要になります。$$\frac{n(n-1)}{2}$$比較。 のために`n = 200000`これは約 200 億ペアに相当し、1 秒以内ではまったく実現不可能です。 

美しさの値自体は大きいですが、比較して数えるだけで十分です。 動的プログラミングや複雑なデータ構造は必要ありません。 

すべての花が同じ美しさを持つ場合、微妙なエッジケースが現れます。 

入力：```
5
7 7 7 7 7
```どのペアにも違いがあります`0`、これは自動的に最大の差になります。 答えは次のとおりです。```
0 10
```あるから$$\binom{5}{2}=10$$異なるペア。 最小の美しさの花と最大の美しさの花の積をカウントするだけの不注意な解決策では、誤った結果が生成されます。`25`。 

もう 1 つの重要なケースは、最小値と最大値が複数回発生する場合です。 

入力：```
5
1 3 1 5 5
```最大の差は、`5 - 1 = 4`。 

美しさのある花が二輪あります`1`そして美しさを持つ2つの花`5`したがって、最適なペアの数は次のようになります。$$2 \times 2 = 4$$正しい出力は次のとおりです。```
4 4
```1 つの最小値と 1 つの最大値のみを検出するソリューションでは、誤って返されます。`1`。 

最後のコーナーケースは、可能な限り最小の入力です。 

入力：```
2
100 1
```ペアは 1 つだけ存在するため、答えは次のようになります。```
99 1
```値に関係なく、有効な選択肢は 1 つだけです。 

## アプローチ

 最も直接的なアプローチは、すべてのペアの花を調べることです。 各ペアについて、美しさの違いを計算し、これまでに確認された最大の違いを追跡し、その違いを達成したペアの数を数えます。 

この総当り的な方法は、考えられるすべてのペアを明示的にチェックするため、正しいです。 問題はその稼働時間だ。 と`n = 200000`、ペアの数は約 200 億であり、制限内で処理できる数をはるかに超えています。 

重要な観察は、可能な限り最大の差異は、最小の美しさの値と最大の美しさの値から生じる必要があるということです。 

配列全体の最小の美しさは次のとおりであるとします。`mn`そして最大限の美しさは`mx`。 

どのペアもこれより大きな差を持つことはできません`mx - mn`なぜなら、あらゆる美しさはその両極端の間にあるからです。 同時に、美しさを持った花を一輪選ぶこと`mn`そしてもう一つは美しさを持つ`mx`まさにその違いを実現します。 

これにより、最大の差がすぐに得られます。$$mx - mn$$残りの問題は、何組がそれを達成するかです。 

もし`mn != mx`、すべての最適なペアには、最小値の花と最大値の花が 1 つずつ含まれている必要があります。 他の美しさの値があると、その差は小さくなります。 

最小値が出た場合`cnt_min`回すると最大値が表示されます`cnt_max`回、すべての最小の花をすべての最大の花と組み合わせることができます。$$cnt\_min \times cnt\_max$$最適なペア。 

もし`mn == mx`であれば、すべての花は同じ美しさを持つことになります。 どのペアも違いを実現します`0`したがって、順序のないペアをすべてカウントする必要があります。$$\binom{n}{2} = \frac{n(n-1)}{2}$$これにより、問題は最小値、最大値、およびそれらの頻度を見つけることになります。

 ## アルゴリズムのチュートリアル

 1. 花の数とその美しさの値を読み取ります。 
2.最小の美しさの値を見つける`mn`。 
3. 美しさの最大値を見つける`mx`。 
4. 最大差を次のように計算します。`mx - mn`。 
5. もし`mn == mx`、すべての花は同じ美しさを持っています。 

最大の差は、`0`, and every unordered pair is optimal. 計算:$$\frac{n(n-1)}{2}$$6. そうでない場合は、美しい花が何本あるか数えてください`mn`。 これに電話してください`cnt_min`。 
7. 美しい花が何本あるか数えます`mx`。 これに電話してください`cnt_max`。 
8. 最適なペアの数は次のとおりです。$$cnt\_min \times cnt\_max$$9. Output the maximum difference and the number of optimal pairs.

 ### なぜ効果があるのか

 The largest beauty difference obtainable from any pair cannot exceed the difference between the global maximum and global minimum values. 最小値の花と最大値の花を選択すると、まさにその差が得られるため、最適な差は次のように一意に決定されます。`mx - mn`。 

いつ`mn != mx`、すべての最適なペアは、各極端から 1 つの花を使用する必要があります。 どちらかの花を中間の美しさで置き換えると、差は小さくなります。 したがって、最適なペアの総数は、最小の花と最大の花を選択する方法の数と正確に一致します。 

いつ`mn == mx`、どの花も同じ美しさなので、どのペアにも違いが生まれます`0`。 順序のないペアをすべて数えると正しい答えが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    mn = min(a)
    mx = max(a)

    diff = mx - mn

    if mn == mx:
        ways = n * (n - 1) // 2
    else:
        cnt_min = a.count(mn)
        cnt_max = a.count(mx)
        ways = cnt_min * cnt_max

    print(diff, ways)

solve()
```最初のステップは、最小および最大の美しさの値を見つけることです。 これら 2 つの値によって、達成可能な最大の差が完全に決まります。 

差を計算した後、実装は 2 つのケースに分割されます。 

最小値と最大値が等しい場合、どの花も同じ美しさになります。 最適なペアの数は、それらの間の順序のないペアの数です。`n`花、組み合わせ公式で計算`n * (n - 1) // 2`。 

それ以外の場合、最適なペアは、1 つの最小値フラワーと 1 つの最大値フラワーによって形成されるペアのみです。 このコードは、両方の値の出現をカウントし、カウントを乗算します。 

見落としがちな詳細の 1 つは、答えのサイズです。 と`n = 200000`、ペアの数はほぼ 200 億に達する可能性があります。 固定サイズの 32 ビット整数を使用する言語ではオーバーフローが発生します。 Python の整数は自動的に増加するため、特別な処理は必要ありません。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    mn = min(a)
    mx = max(a)

    if mn == mx:
        ways = n * (n - 1) // 2
    else:
        ways = a.count(mn) * a.count(mx)

    print(mx - mn, ways)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue().strip()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided sample
assert run("2\n1 2\n") == "1 1", "sample 1"

# minimum size
assert run("2\n100 1\n") == "99 1", "minimum n"

# all equal
assert run("5\n7 7 7 7 7\n") == "0 10", "all pairs optimal"

# repeated minima and maxima
assert run("5\n1 3 1 5 5\n") == "4 4", "multiple optimal pairs"

# many middle values
assert run("6\n1 2 3 4 5 6\n") == "5 1", "single min and max"

# boundary counting
assert run("6\n1 1 1 10 10 10\n") == "9 9", "3 * 3 optimal pairs"

 ## 特殊なケース

 Consider the case where all flowers have the same beauty:```
5

```アルゴリズムは次のことを見つけます`mn = mx = 7`, したがって、特別なブランチに入ります。 違いは`0`、最適なペアの数は次のようになります。$$\frac{5 \cdot 4}{2} = 10$$出力：```
0 10
```これにより、コンピューティングでよくある間違いを回避できます。`5 × 5 = 25`、無効なセルフペアリングをカウントし、ペアを二重にカウントします。 

極端な値が繰り返される場合を考えてみましょう。```
5
1 3 1 5 5
```アルゴリズムは次のことを見つけます`mn = 1`、`mx = 5`、`cnt_min = 2`、 そして`cnt_max = 2`。 

最適なペアの数は次のとおりです。$$2 \times 2 = 4$$出力：```
4 4
```すべての最適なペアには、美しい花が 1 つ含まれています`1`そして美しさを持った一輪の花`5`。 花と美しさの組み合わせはありません`3`最大の差に達することができます。 

最小の有効な入力を考えてみましょう。```
2

```アルゴリズムは計算します`mn = 1`、`mx = 100`、それぞれの出現を 1 回カウントします。 答えは次のようになります。```

```ペアは 1 つだけ存在し、数え方の公式からは当然正しい結果が得られます。
