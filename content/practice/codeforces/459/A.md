 ## 解決策
 ## 問題の理解

 デカルト平面上の 2 本の異なる木の座標が与えられており、庭園が軸に沿った完全な正方形を形成していることがわかります。 正方形の各頂点には木があるので、ちょうど 4 本の木が存在します。 タスクは、他の 2 つの木の座標を決定することです。 これらの条件を満たす正方形が存在しない場合は、-1 を出力する必要があります。 

入力は、2 つの既知のツリーの x 座標と y 座標を表す 4 つの整数で構成されます。 各座標の範囲は -100 ～ 100 で、出力座標は最大 ±1000 まで許容されます。 入力サイズが固定されている (2 点のみ) ため、単純な算術演算以上の効率を心配する必要はありません。 数回の定時チェックのみを含むソリューションは、時間とメモリの制限内で快適に実行されます。 

エッジケースは微妙です。 2 つのツリーが同じ x 座標を共有する場合、正方形は垂直になります。 同じ y 座標を共有する場合、それは水平になります。 どちらの座標も一致しない場合、木は正方形の対角線上にある頂点になければならず、x に沿った距離は y に沿った距離と等しくなければなりません。 この条件が満たされない場合、正方形を形成することはできません。 単純な実装では、これらの条件を見落とし、不可能な点を構築しようとする可能性があります。 

たとえば、入力`0 0 1 2`水平距離と垂直距離が異なるため、軸に沿った正方形を形成できません。そのため、正しい出力は -1 です。 同様に入力します`0 0 0 1`は正方形の垂直辺を表し、他の 2 つの頂点の x 座標は垂直距離 (1) だけシフトされている必要があります。`(1, 0)`そして`(1, 1)`。 

## アプローチ

 ブルート フォース アプローチでは、最初の 2 つの点が与えられた場合に考えられるすべての正方形を生成し、どの構成が軸に平行な辺を持つ有効な正方形を形成するかを確認しようとします。 これには、水平、垂直、斜めの配置に対する複数の条件分岐と、残りの 2 つの点のすべての順列のチェックが含まれます。 正方形は高度に制約されているため機能しますが、不必要な複雑さが生じます。 

最適なアプローチは、指定された 2 つの点間の関係を分類することです。 それらが同じ垂直線上にある場合、正方形の辺は垂直であり、他の 2 つの頂点は垂直距離だけ水平にシフトされます。 それらが同じ水平線上にある場合、その辺は水平になり、残りの頂点は垂直にシフトされます。 それらが正方形の対角線を形成する場合、水平距離と垂直距離は等しくなければならず、他の 2 つの頂点は次の位置にあります。`(x1, y2)`そして`(x2, y1)`。 これらのいずれのケースも当てはまらない場合、有効な正方形は存在しません。 

この観察により、問題は 3 つの定数時間チェックと単純な算術に削減され、O(1) の時間と空間が確保されます。

 ## アルゴリズムのチュートリアル

 1. 座標を読み取る`(x1, y1)`そして`(x2, y2)`。 
2. 2 つの点が同じ垂直線上にあるかどうかを確認します (`x1 == x2`）。 そうであれば、水平距離を次のように計算します。`d = abs(y2 - y1)`。 残りの頂点は、`(x1 + d, y1)`そして`(x2 + d, y2)`。 これらを印刷して終了します。 
3. 2 つの点が同じ水平線上にある場合 (`y1 == y2`)、垂直距離を計算します`d = abs(x2 - x1)`。 他の頂点は、`(x1, y1 + d)`そして`(x2, y2 + d)`。 印刷して終了します。 
4. 絶対水平距離が絶対垂直距離と等しい場合 (`abs(x2 - x1) == abs(y2 - y1)`)、点は対角線を形成します。 他の頂点は、`(x1, y2)`そして`(x2, y1)`。 印刷して終了します。 
5. 上記の条件がいずれも当てはまらない場合は、有効な正方形を形成できないため、-1 を出力します。 

機能する理由: いずれの場合も、正方形の軸が揃っているという特性を利用します。 垂直および水平側面の場合は、正しい側面の長さだけ垂直軸に沿って移動することに依存します。 正方形では、対角線上にある頂点の x 座標の差が y 座標の差に等しいため、対角線の場合が機能します。 これら 3 つのチェックは、軸に揃えられた正方形上の 2 つの頂点の可能な配置をすべてカバーし、正確さを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

x1, y1, x2, y2 = map(int, input().split())

if x1 == x2:
    d = abs(y2 - y1)
    print(x1 + d, y1, x2 + d, y2)
elif y1 == y2:
    d = abs(x2 - x1)
    print(x1, y1 + d, x2, y2 + d)
elif abs(x2 - x1) == abs(y2 - y1):
    print(x1, y2, x2, y1)
else:
    print(-1)
```コードは、アルゴリズムで特定された 3 つのケースを直接実装します。 チェックの順序は重要です。最初に垂直方向の配置、次に水平方向、最後に対角方向の配置をチェックします。 の`abs`正の辺の長さが保証され、印刷順序は、座標を任意の順序で出力するという問題の要件に一致します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline
    x1, y1, x2, y2 = map(int, input().split())
    if x1 == x2:
        d = abs(y2 - y1)
        return f"{x1 + d} {y1} {x2 + d} {y2}"
    elif y1 == y2:
        d = abs(x2 - x1)
        return f"{x1} {y1 + d} {x2} {y2 + d}"
    elif abs(x2 - x1) == abs(y2 - y1):
        return f"{x1} {y2} {x2} {y1}"
    else:
        return "-1"

# Provided sample
assert run("0 0 0 1\n") == "1 0 1 1", "sample 1"
