 ## 解決策
 ## 問題の理解

 各十字は、同じセルを中心とする軸が揃った 2 つの長方形によって定義されます。`(x0, y0)`。 

最初の長方形が伸びます`a`セルを垂直方向に、`b`セルは中心から水平方向に配置されるため、そのサイズは次のようになります。$(2a+1)(2b+1)$2 番目の長方形も同様に次を使用して定義されます。`c`そして`d`。 

セルがこれらの長方形の少なくとも 1 つに属している場合、そのセルは十字に属します。 両方の長方形の中心が同じ点にあるため、交差領域は単純に 2 つの長方形を合わせたサイズになります。 

注文されたタプルの数を数えなければなりません`(a, b, c, d, x0, y0)`エリアのクロスを正確に生成する`s`、完全に内部に留まりながら、`n × m`グリッド。 

タプルは順序付けされます。 4 つのパラメータがすべて等しい場合を除き、2 つの長方形を交換すると、異なる答えが作成されます。 

グリッドの寸法は最大でも`500`したがって、セルの総数は最大で`250000`。 6 つの変数すべてを総当りで調べることは不可能です。 すべての値を反復しても、`a, b, c, d`独立してすでに大まかに与えています`500^4`、それは限界をはるかに超えています。 

重要な点は、面積の式は中心位置ではなく、長方形のサイズのみに依存するということです。 有効な 4 倍数がわかったら`(a,b,c,d)`ユニオンエリアあり`s`, counting possible centers becomes easy.

 実装を密かに破壊する可能性のあるエッジケースがいくつかあります。 

Suppose one rectangle fully contains the other. 例えば：```
n = 5, m = 5, s = 9
```タプル```
(a,b,c,d) = (1,1,0,0)
```を作成します`3 × 3`正方形と 1 つの中央セル。 ユニオンエリアはまだ`9`、 ない`10`。 長方形領域を直接追加する不用意な実装はオーバーカウントを引き起こします。 

2 つの長方形が部分的に重なっている場合、別の微妙なケースが発生します。```
(a,b,c,d) = (1,0,0,1)
```これは古典的なプラスの形状です。 縦長の長方形には面積がある`3`、横長の長方形には面積があります`3`, しかし、中央のセルは両方に属します。 ユニオンエリアは、`5`、 ない`6`。 

可能な限り小さなクロスも重要です。```
2 2 1
```可能な唯一の長方形は両方です`1 × 1`、4 つのパラメータすべてがゼロであることを意味します。 すべてのグリッド セルが中心になる可能性があるため、答えは次のようになります。`4`。 

誤って正の腕の長さを必要とする実装では、誤って返される可能性があります。`0`。 

## アプローチ

 直接的な総当たりアプローチは概念的に単純です。 

可能なすべての値を列挙します。`a, b, c, d`。 4 つ組ごとに、カバーされるセルのセットを明示的に計算するか、結合領域を幾何学的に計算します。 面積が等しい場合`s`、クロス全体をグリッド内に収めているセンターの数を数えます。 

封じ込め条件は簡単です。 両方の長方形が同じ中心を共有しているため、次の条件を満たす場合、十字はグリッド内に収まります。$x_0-\max(a,c)\ge1,\quad x_0+\max(a,c)\le n$列についても同様です。 

したがって、有効な中心の数は次のようになります。$(n-2\max(a,c))(m-2\max(b,d))$両方の要素がプラスである場合に限ります。 

状態空間が巨大であるため、総当り攻撃は失敗します。 各パラメータはおおよそ最大で`250`、次のことについて説明します。$250^4\approx4\times10^9$センターを考える前に4倍にする。 

The critical insight is that rectangle dimensions are small after rewriting them in terms of odd side lengths.

 定義する：$h_1=2a+1,\quad w_1=2b+1,\quad h_2=2c+1,\quad w_2=2d+1$すべての次元は正の奇数です。 

結合領域は次のようになります。$h_1w_1+h_2w_2-\min(h_1,h_2)\min(w_1,w_2)$中央に配置された 2 つの長方形の重なりは、正確に、小さい高さと小さい幅の積になるためです。 

これで、検索スペースが管理可能になります。 すべての長方形領域は、関連する何かを分割する必要があります。`s`、すべての辺の長さは奇数の約数です。 までの数の奇数の約数の数`250000`に比べて小さいです`500`。 

すべての座標を独立して反復する代わりに、面積が次を超えない有効な奇数の長方形の寸法を列挙します。`s`。 これにより、完全な検索に必要な状態の総数が減少します。

 ## アルゴリズムのチュートリアル

 1. 考えられる奇数の長方形の寸法をすべて列挙します。`(h, w)`そのような`h ≤ n`、`w ≤ m`、 そして`h*w ≤ s`。 

によって生成されたすべての長方形`(a,b)`以下に一意に対応します。$h=2a+1,\quad w=2b+1$したがって、奇数の次元を反復することは、すべてのパラメーターのペアを反復することと同じです。 
2. すべての有効な四角形をリストに保存します。 

奇数の次元のみが許可され、領域は次の範囲に制限されるため、合計数は少なくなります。`s`。 
3. 順序付けられた長方形のペアごとに反復処理を行います。 

長方形を次のようにします`(h1,w1)`そして`(h2,w2)`。 
4. オーバーラップ領域を計算します。 

両方の長方形が同じ中心を共有しているため、重なり合う寸法は単純に次のようになります。$\min(h_1,h_2)\times\min(w_1,w_2)$5. 包含排他を使用して結合領域を計算します。$A=h_1w_1+h_2w_2-\min(h_1,h_2)\min(w_1,w_2)$もし`A != s`、このペアをスキップします。 
6. 十字が中心からどのくらい離れているかを決定します。 

垂直方向の最大到達距離は次のとおりです。$\max(a,c)=\frac{\max(h_1,h_2)-1}{2}$そして同様に水平方向にも。 
7. 有効な中心を数えます。 

中心は、両方の長方形をグリッド内に保持する任意の行と列に配置できます。$(n-\max(h_1,h_2)+1)(m-\max(w_1,w_2)+1)$8. この数を答えに追加します。 

順序ペアが重要なので、2 で割ることはありません。 

### なぜ効果があるのか

 すべての十字は、中央に配置された 2 つの奇数サイズの長方形に一意に対応します。 間の変換`(a,b,c,d)`また、長方形の寸法は全単射であるため、構成が失われることはありません。 

中央に配置された 2 つの長方形の場合、それらの重なり部分自体が、辺の長さが座標上の最小値となる中央に配置された長方形になります。 包含-排他により、正確な結合領域が計算されます。 

より大きな垂直方向のスパンとより大きな水平方向のスパンの両方がボード内に残っている場合、クロスフィットが行われるため、配置数も正確になります。 すべての有効なセンターは、順序付けされたクアドルプルごとに 1 回カウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, s = map(int, input().split())

    rects = []

    for h in range(1, n + 1, 2):
        for w in range(1, m + 1, 2):
            if h * w <= s:
                rects.append((h, w))

    ans = 0

    for h1, w1 in rects:
        area1 = h1 * w1

        for h2, w2 in rects:
            overlap = min(h1, h2) * min(w1, w2)

            union_area = area1 + h2 * w2 - overlap

            if union_area != s:
                continue

            max_h = max(h1, h2)
            max_w = max(w1, w2)

            positions = (n - max_h + 1) * (m - max_w + 1)

            ans += positions

    print(ans)

if __name__ == "__main__":
    solve()
```実装は数学的再定式化に直接従います。 

最初のループでは、考えられる中心にある長方形をすべて列挙します。 すべての長方形は中央のセルの周りに対称的に展開されるため、辺の長さは奇数である必要があります。 

コアの二重ループは、順序付けされた長方形のペアを反復します。 問題によって次の点が区別されるため、順序付けされた反復が重要です。```
(a,b,c,d)
```から：```
(c,d,a,b)
```両方の長方形が位置合わせされ、中央に配置されているため、オーバーラップの式が機能します。 それらの交差部分は、より小さい高さとより小さい幅にまたがります。 

配置の公式は、1 つずつずれると間違いやすいです。 長方形に高さがある場合`h`の場合、中心は正確に次の場所を占める可能性があります。```
n - h + 1
```行。 たとえば、`n = 5`そして`h = 3`、中心は列にできます`2,3,4`、つまり`3 = 5-3+1`。 

すべての算術演算は 64 ビット整数に安全に収まります。 Python の整数はこれを自動的に処理します。

 ## 特殊なケース

 次のことを考慮してください。```
2 2 3
```有効なクロスが存在しません。 

唯一可能な奇数の長方形の寸法は次のとおりです。`(1,1)`。 このような 2 つの長方形を結合すると、結合領域が得られます。`1`。 

アルゴリズムはすべてのペアを列挙し、以下を計算します。$1+1-1=1$決して等しくないもの`3`したがって、最終的な答えはゼロのままです。 

ここで次のことを考えてみましょう。```
3 3 9
```面積を達成する唯一の方法`9`を使用しています`3 × 3`矩形。 ペア:```
(3,3),(1,1)
```まだユニオンエリアがある`9`なぜなら、小さい方の長方形は完全に大きい方の長方形の内側にあるからです。 

オーバーラップが小さい方の長方形の領域に等しいため、アルゴリズムはこれを正しく処理します。$9+1-1=9$最後に、古典的なプラスの形状を調べます。```
5 5 5
```長方形を使用する`(3,1)`そして`(1,3)`。 

重なり合うのはちょうど 1 つの中央セルです。$3+3-1=5$最大寸法は次のとおりです。`(3,3)`, したがって、中心は以下を占める可能性があります:$(5-3+1)^2=9$ポジション。 

長方形の順序は重要なので、両方とも`(3,1)+(1,3)`そして`(1,3)+(3,1)`貢献する、寄付する`18`合計構成。
