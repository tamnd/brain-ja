 ## 解決策
 ## 問題の理解

 2部構成のメダルをデザイン中です。 外側部分は外半径を持つリングです$r_1$と内半径$r_2$。 内側は半径のある固体円盤です$r_2$。 両方の部品の厚さは同じであるため、その質量は面積と密度のみに依存します。 

外側のリングは密度を使用します$p_1$、1 つのリストから選択されます。 内側のディスクは密度を使用します$p_2$、別のリストから選択されます。 外側の半径$r_1$もリストから選択されます。 ステートメントの固定ルールには次のものが必要です$$\frac{m_{out}}{m_{in}} = \frac{A}{B}$$そして内側の半径を最大化する必要があります$r_2$。 

入力では、外半径と両方の密度について可能なすべての選択肢が与えられます。 達成可能な最大のものを出力する必要があります$r_2$。 

制約はわずかです。 すべての値は最大 5000 であり、配列のサイズも十分小さいため、すべての組み合わせをチェックしても簡単に間に合います。 これにより、問題が最適化のトリックや高度なデータ構造に関するものではないことがすぐにわかります。 本当の仕事は、正しい公式を導き出し、どの選択肢が答えを最大化するかを理解することです。 

危険なのは代数です。 不注意に導出すると、簡単に分数が逆転したり、質量が面積に依存することを忘れたりして、半径の 2 乗が導入される可能性があります。 

微妙な特殊ケースの 1 つは、間違った濃度を選択することです。 仮定する：```
r1 = 10
p1 choices = [1, 100]
p2 choices = [1]
A = 1, B = 1
```使用する場合$p_1 = 1$、リングは軽く、必要な質量比を維持するために内側のディスクは比較的小さいままでなければなりません。 使用する$p_1 = 100$より大きなインナーディスクが可能になります。 密度を無視する貪欲なアプローチはここでは失敗します。 

もう 1 つの簡単な間違いは、間違った変数を最大化してしまうことです。 の式は、$r_2$含まれています$r_1^2$、 ない$r_1$。 正確に導出された式を使用するのではなく、比率を線形に最大化しようとすると、誤った比較が行われる可能性があります。 

3 番目の罠は浮動小数点精度です。 答えは必ずしも整数である必要はありません。 例えば：```
1 5
1 3
1 2
1 1
```生成する$$r_2 = 5 \sqrt{\frac{3}{5}}$$それは不合理です。 整数演算では結果が黙って切り捨てられます。 

## アプローチ

 最も直接的なアプローチは、可能なすべてのトリプルを試すことです$(r_1, p_1, p_2)$。 それぞれの組み合わせについて、対応する$r_2$質量方程式から最大値を維持します。 

可能性の数が非常に少ないため、これは機能します。 3 つの配列すべてのサイズが 100 だったとしても、合計の組み合わせは次のようになります。$10^6$Python ではまったく問題ありません。 

興味深いのは、式を単純化することです。 

外環エリアは$$\pi (r_1^2 - r_2^2)$$内側のディスク領域は$$\pi r_2^2$$厚さは均一であるため、質量は共通定数までの密度と面積の積に等しくなります。 それで：$$m_{out} = p_1 \pi (r_1^2 - r_2^2)$$

$$m_{in} = p_2 \pi r_2^2$$必要な比率は$$\frac{p_1 (r_1^2 - r_2^2)}{p_2 r_2^2} = \frac{A}{B}$$を解決する$r_2^2$:$$B p_1 (r_1^2 - r_2^2) = A p_2 r_2^2$$

$$B p_1 r_1^2 = r_2^2 (A p_2 + B p_1)$$

$$r_2^2 = \frac{B p_1 r_1^2}{A p_2 + B p_1}$$

$$r_2 = r_1 \sqrt{ \frac{B p_1}{A p_2 + B p_1} }$$これで、最適化が明らかになりました。 次の場合に式が増加します。 

-$r_1$増加する
 -$p_1$増加する
 -$p_2$減少する

 したがって、すべての組み合わせを総当たり攻撃する代わりに、必要なのは次のことだけです。 

- 最大$r_1$- 最大$p_1$- 最低限$p_2$これにより、ソリューションは入力を読み取った後の継続的な作業に減ります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(nmk)$|$O(1)$| 承認済み |
 | 最適 |$O(n + m + k)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての外径候補を読み取り、最大値を選択します$R$。 

外側の半径が大きいほど、常に最終的な答えが大きくなります。$r_2$に正比例する$r_1$。 
2. 外側のリングのすべての候補密度を読み取り、最大値を選択します$P_1$。 

増加中$p_1$外側のリングが重くなり、必要な質量比を維持しながら内側のディスクを大きくすることができます。 
3. 内側のディスクの密度候補をすべて読み取り、最小値を選択します$P_2$。 

内側のディスクが軽いと、その質量が大きくなりすぎる前に半径を大きくすることができます。 
4. 読み取り定数$A$そして$B$。 
5. コンピューティング$$r_2 = R \sqrt{ \frac{B P_1}{A P_2 + B P_1} }$$1. 結果を十分な精度で印刷します。 

### なぜ効果があるのか

 導出された式は次のように表されます。$r_2$完全に独立変数の観点から:$$r_2 = r_1 \sqrt{ \frac{B p_1}{A p_2 + B p_1} }$$分子は次のように増加します$r_1$そして$p_1$、分母は増加します$p_2$。 すべての値が正であるため、最大化$r_1$そして$p_1$そして最小限に抑えること$p_2$常に式全体を最大化します。 変数間の相互作用によってトレードオフが発生しないため、それぞれ独立して最適な値を選択すると、全体的に最適な答えが得られます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

# read radii
data = list(map(int, input().split()))
n = data[0]
x = data[1:]

# read p1 values
data = list(map(int, input().split()))
m = data[0]
y = data[1:]

# read p2 values
data = list(map(int, input().split()))
k = data[0]
z = data[1:]

A, B = map(int, input().split())

r1 = max(x)
p1 = max(y)
p2 = min(z)

ans = r1 * math.sqrt((B * p1) / (A * p2 + B * p1))

print("{:.12f}".format(ans))
```実装は数学的導出に直接従います。 

最初の重要な詳細は、正しい極値を選択することです。 外側の半径と外側の密度は最大にしますが、内側の密度は最小にしたいと考えています。 最小値と最大値のいずれかを交換すると、一見有効に見える数値が完全に間違っています。 

2 番目の詳細は、浮動小数点除算を使用することです。 Python では、これは自動的に行われます。`/`ただし、別の言語で整数の除算を使用すると、精度が失われます。 

最終的な式は、質量方程式を整理することで直接得られます。 平方根は分母だけでなく分数全体に適用されます。 ここでは括弧が重要です。 

出力には小数点以下 12 桁が使用され、必要な条件を快適に満たします。$10^{-6}$精度。

 ## 特殊なケース

 間違った密度方向を選択すると解決策が崩れる場合を考えてみましょう。```
1 10
2 1 100
1 1
1 1
```アルゴリズムは以下を選択します。$$r_1 = 10,\quad p_1 = 100,\quad p_2 = 1$$それから：$$r_2 = 10 \sqrt{\frac{100}{101}} \approx 9.95037$$間違って最小化した場合$p_1$、結果は次のようになります。$$10 \sqrt{\frac{1}{2}} \approx 7.07$$これは最適とは程遠いものです。 

次に、反対方向を考えてみましょう$p_2$:```
1 10
1 10
2 1 100
1 1
```アルゴリズムは最小のものを選択します$p_2$、つまり 1:$$r_2 = 10 \sqrt{\frac{10}{11}} \approx 9.5346$$選択する$p_2 = 100$代わりに次のようになります:$$10 \sqrt{\frac{10}{110}} \approx 3.015$$大幅な低下は、$p_2$必要です。 

最後に、精度が重要な場合を考えてみましょう。```
1 5
1 3
1 2
1 1
```正確な答えは次のとおりです。$$5 \sqrt{\frac35} \approx 3.872983346207$$この実装では浮動小数点演算が使用され、多くの小数点以下の桁数が出力されるため、必要な$10^{-6}$精度は安全に達成されます。
