 ## 解決策
 ## 問題の理解

 私たちは、1 本の道路に沿って一連の地域を通過する学童のグループを輸送するように依頼されています。 各地域には固定の屋外温度と最大許容バス温度があります。 許容温度を超えてバスに乗車した子供は全員、罰金を科せられます。 主催者は子供たちを複数のバスに分割することができ、各バスには地域ごとに固定の運行コストがかかります。 課題は、バスの費用と熱補償の合計を最小限に抑えるために、各地域で子供たちをバスに割り当てることです。 

正式には、地域に屋外気温がある場合、`ti`そしてバス制限`Ti`、それからバスが運ぶ`k`子供たちは室内温度が高くなります`ti + k`。 もし`ti + k > Ti`、それぞれの`k`子どもたちは次のようなペナルティを受ける`xi`。 バス料金`costi`地域ごとにそれぞれ。 入力により提供されるのは、`n`地域と`m`子、および各領域の 4 つの整数`ti, Ti, xi, costi`。 

出力は、すべての子をすべてのリージョンに転送するための最小合計コストです。 

制約は重要です。 まであります`10^5`地域および最大`10^6`子供たち。 これにより、各地域のバス間で子のすべての分布を試行する強引なアプローチが排除されます。 代わりに、領域ごとの最小コストを領域ごとに一定時間で計算する方法を見つける必要があります。 エッジケースには、子供たち全員を乗せた 1 台のバスでも安全な地域が含まれます (`ti + m <= Ti`）、補償金を支払うよりも複数のバスの方が安い地域、子供1人当たりの補償金が複数のバスに分割する費用よりも少ない地域です。 

領域ごとに可能なバス数を反復する単純な実装は、非常に遅くなります。 同様に、バスへの分割と補償金の支払いとの間のトレードオフを考慮していないソリューションでは、誤った結果が生じる可能性があります。 

## アプローチ

 ブルート フォース アプローチでは、各リージョン内のバスの数を 1 から 2 まですべて考慮します。`m`バスの費用と熱補償を含む総コストを計算します。 バス数ごとに`b`、バス 1 台あたりの子供の数は、`ceil(m / b)`。 もし`ti + ceil(m / b) > Ti`、子供1人当たりの暑さ補償が適用されます。 そのときの総費用は、`b * costi + (heat compensation per child) * m`。 最悪の場合、このアプローチの評価は次のようになります。`10^6`リージョンごとの可能性があり、合計操作数は最大で`10^11`-明らかに実行不可能です。 

重要な洞察は、総コストがバスの数の関数として凸であるということです。 特定の地域でバスを追加すると、バス 1 台あたりの子供の数が減り、補償金が減額または廃止されますが、バスの費用は直線的に増加します。 したがって、地域に最適なバスの数は、補償を回避できる最小数か、バスを追加するより補償の方が安い場合は 1 つのみになります。 ペナルティを回避する最小バス数は次のように直接計算できます。`ceil(max(0, m - (Ti - ti)) / 1)`そして、この最小限の安全なバス数のコストと、1 台のバスを使用して補償金を支払うコストを比較します。 

領域ごとのコスト関数が単純な区分的動作を持つという観察により、一定時間で領域ごとの最適なコストを計算でき、総当たりの列挙を回避できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * m) | お(1) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 地域ごとに、補償をトリガーせずに 1 台のバスが輸送できる子供の最大数を計算します。 これは`max_k = Ti - ti`。 もし`max_k <= 0`、どのバスでも制限を超えます。 
2. 整数上限除算を使用して、補償を回避するために必要なバスの最小数を計算します。`buses_needed = ceil(m / max_k)`。 もし`max_k <= 0`、 セット`buses_needed = m`（お子様1人あたりの余分な熱を避けるため、お子様はそれぞれ別のバスに乗車します）。 
3. 安全な最小限のバス数を使用するコストを計算します。`cost_safe = buses_needed * costi`。 このシナリオでは補償は適用されません。 
4. 補償に関係なく 1 台のバスを使用するコストを計算します。`ti + m > Ti`、報酬総額は`compensation = (ti + m - Ti) * xi * m`? 実際には注意してください。内部温度が Ti を超えた場合、子供 1 人あたりの補償は xi です。 内部の温度は、`ti + m`、つまり、子供の数は`m`、それぞれ支払います`xi`ルーブル:`cost_compensation = costi + m * xi`もし`ti + m > Ti`、それ以外の場合は、`costi`。 
5. 最低限のものを取る`cost_safe`そして`cost_compensation`地域を調べて合計に追加します。 

すべての領域に対して繰り返し、合計を出力します。 

不変条件は、地域ごとに、バスの数を最小限に抑えるバスの数を選択するということです。`bus_cost + heat_compensation`。 この計算は、領域のローカル パラメーターと子の総数にのみ依存し、複雑なグローバル最適化は必要ありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

n, m = map(int, input().split())
total_cost = 0

for _ in range(n):
    ti, Ti, xi, costi = map(int, input().split())
    max_k = Ti - ti
    if max_k <= 0:
        cost_safe = m * costi
    else:
        buses_needed = (m + max_k - 1) // max_k
        cost_safe = buses_needed * costi
    if ti + m > Ti:
        cost_compensation = costi + m * xi
    else:
        cost_compensation = costi
    total_cost += min(cost_safe, cost_compensation)

print(total_cost)
```このソリューションは入力を効率的に読み取ります。 地域ごとに、次のような場合に丁寧に対応します。`max_k <= 0`これは、単一のバスが常に温度を超えていることを意味し、安全なバス計算のために整数上限除算が正しく実行されることを保証します。 補償は、単一のバスが温度制限を超えた場合にのみ適用されます。
