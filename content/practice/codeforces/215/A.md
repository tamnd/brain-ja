 ## 解決策
 ## 問題の理解

 自転車用ギアは 2 セットあります。 前ギアはペダルに、後ギアは後輪に取り付けられています。 チェーンがフロントギアに接続されている場合`a[i]`リアギアへ`b[j]`、結果のギア比は次のようになります。`b[j] / a[i]`。 

整数である比率のみを考慮します。つまり、後部ギアの歯数が前部ギアの歯数で割り切れる必要があります。 このようなすべての整数の比率の中で、可能な限り最大の比率が必要です。 タスクは、その最大整数比を生成する歯車ペアの数を数えることです。 

入力サイズは非常に小さいです。 どちらの配列にも最大 50 個の要素が含まれるため、`50 * 50 = 2500`可能なペア。 すべてのペアにわたる単純なネストされたループでも、制限時間内に簡単に収まります。 並べ替えテクニック、二分探索、ハッシュ前処理などの高度な最適化テクニックは必要ありません。 

主な課題はパフォーマンスではなく正確さです。 不注意な実装では、整数の除算と割り算のチェックを誤って組み合わせると、間違ったペアが黙ってカウントされる可能性があります。 

簡単な間違いの 1 つは、最初に割り算を確認せずに、フロア分割を有効な比率として扱うことです。 

考慮する：```
2
4 6
2
11 12
```有効な整数の比率は次のとおりです。 

-`12 / 4 = 3`-`12 / 6 = 2`ペア`(6, 11)`は無効です。`11 / 6`は整数ではありません。 やみくもに計算すると`11 // 6 = 1`と誤って有効なギア比として扱ってしまいます。 

正しい答えは次のとおりです。```
1
```いくつかの異なるペアが同じ最大比率を共有する場合、別の微妙なケースが発生します。 

例：```
2
2 3
2
6 9
```整数の比率は次のとおりです。 

-`6 / 2 = 3`-`9 / 3 = 3`最大比率は`3`と2回出てきます。 

正しい出力は次のとおりです。```
2
```バグのあるソリューションは、すべての出現をカウントするのではなく、最初の最大値を見つけた後に停止する可能性があります。 

可能な最小の入力サイズもあります。```
1
5
1
10
```ペアは 1 つだけ存在し、その比率は`2`。 

正しい出力は次のとおりです。```
1
```これにより、有効なギアが 1 つだけ存在する場合に実装が正しく動作するかどうかがチェックされます。 

## アプローチ

 最も直接的な解決策はブルートフォースです。 私たちは可能な限りのフロントギアとリアギアのペアを試します。 各ペアについて、後部ギアの歯数が前部ギアの歯数で割り切れるかどうかを確認します。 そうであれば、比率を計算し、現在の最大値と比較します。 

これは、ペアの総数が少ないため機能します。 最悪の場合は評価させていただきます`50 * 50 = 2500`組み合わせ。 各チェックには一定の時間がかかるため、アルゴリズム全体が非常に高速になります。 

遅いが正しい総当り攻撃の亜種では、最初にすべての有効な比率をリストに保存し、次にリストを再度スキャンして最大値を見つけ、その出現数をカウントします。 入力が非常に小さいため、それでも快適に通過できます。 

よりクリーンなアプローチは、すべてを 1 パスで処理することです。 ペアを反復処理する間、2 つの変数を維持します。 

- これまでに確認された最大の有効な比率
 - 何組のペアがその比率を達成するか

 より大きな比率が見つかった場合は、最大値を置き換えてカウントを次のようにリセットします。`1`。 同じ比率を持つ別のペアが見つかるたびに、カウントが増加します。 

重要な点は、有効な比率をすべて覚えておく必要はないということです。 現在の最高の比率のみが重要です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 保存された比率を使用したブルート フォース | O(n × m) | O(n × m) | 承認済み |
 | ワンパス最適スキャン | O(n × m) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. フロントギアの数と歯数を読み取ります。 
2. リアギアの数と歯数を読み取ります。 
3. 2 つの変数を初期化します。 

-`best = 0`、これまでに見つかった最大の整数比。 
-`count = 0`、その比率を達成するペアの数。 
4. すべてのフロントギアを繰り返します`a`。 
5. フロント ギアごとに、リア ギアごとに繰り返します。`b`。 
6.次のことを確認します。`b % a == 0`。 

これにより、比率が`b / a`は整数です。 
7. 比率が整数でない場合は、このペアをスキップします。 
8. それ以外の場合は計算します`ratio = b // a`。 
9. もし`ratio > best`、 アップデート：

-`best = ratio`-`count = 1`比率が大きくなると、以前の候補がすべて置き換えられます。 
10. もし`ratio == best`、増分`count`。 

このペアでも最大の比率が達成されます。 
11. すべてのペアを処理した後、印刷します。`count`。 

### なぜ効果があるのか

 アルゴリズムは、考えられるすべてのギア ペアを 1 回だけ検査します。 有効な回答はこれらのペアのいずれかから得られる必要があるため、候補を逃すことはできません。 

変数`best`処理されたすべてのペアの最大の整数比を常に保存します。 より大きな比率が表示されるたびに、`best`これは正しいです。これより小さい比率はすべて最適ではなくなります。 

変数`count`現在の最大比率に達する処理済みペアの数を常に追跡します。 より大きな比率が現れたときにそれをリセットし、等しい比率が現れたときにそれをインクリメントすると、スキャン全体を通じてこの不変状態が維持されます。 

すべてのペアが処理された後、`count`は、正確に最大の整数比を持つペアの数です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
front = list(map(int, input().split()))

m = int(input())
rear = list(map(int, input().split()))

best = 0
count = 0

for a in front:
    for b in rear:
        if b % a != 0:
            continue

        ratio = b // a

        if ratio > best:
            best = ratio
            count = 1
        elif ratio == best:
            count += 1

print(count)
```最初の部分は、前後のギアのサイズを読み取ります。 制約が小さいため、単純なリストで十分です。 

ネストされたループにより、考えられるあらゆるギアの組み合わせが生成されます。 これにより、検索スペースの完全なカバーが保証されます。 

可分性チェックは重要な詳細です。```
if b % a != 0:
    continue
```この条件がないと、フロア分割では非整数の比率が誤って有効なものとして扱われてしまいます。 

更新ロジックは、現在の最大比率とその頻度を維持します。 リセットする`count`より大きな比率が現れるタイミングが重要です。 よくあるバグは、このリセットを忘れることです。これにより、より小さい比率のカウントが新しい最大値と混合されてしまいます。 

コードでは整数除算が使用されています`//`割り切れることを確認した後にのみ計算されるため、計算された比率は数学的に正確です。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    n = int(input())
    front = list(map(int, input().split()))

    m = int(input())
    rear = list(map(int, input().split()))

    best = 0
    count = 0

    for a in front:
        for b in rear:
            if b % a == 0:
                ratio = b // a

                if ratio > best:
                    best = ratio
                    count = 1
                elif ratio == best:
                    count += 1

    print(count)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output.strip()

3

"""
