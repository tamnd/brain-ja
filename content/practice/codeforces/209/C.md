 ## 解決策
 ## 問題の理解

 公園は方向性のないマルチグラフです。 空き地は頂点であり、小道はエッジです。 自己ループが許可され、同じ頂点ペア間の複数のエッジも許可されます。 

Vasya は、頂点 1 から開始し、すべてのエッジを 1 回だけ横断し、頂点 1 に戻りたいと考えています。これは、まさに、グラフに頂点 1 から始まるオイラー サイクルが含まれる条件です。 

無向グラフの場合、オイラー サイクルは 2 つの条件が成立する場合にのみ存在します。 

まず、ゼロ以外の次数を持つすべての頂点は、頂点 1 と同じ連結成分に属します。次数 0 の頂点はウォークに参加しないため、重要ではありません。 

第二に、すべての頂点の次数は均等です。 

タスクは、グラフが既にオイラー型であるかどうかを確認するだけではありません。 オイラー式にするために追加する必要があるエッジの最小数を計算する必要があります。 

制約は非常に大きいです。 到達できる頂点とエッジの数の両方$10^6$。 二次的な動作を伴うアルゴリズムは不可能です。 高価な簿記を使用してすべてのコンポーネントから個別に DFS を実行するような場合でも、困難を伴うでしょう。 大まかに言うと、ほぼ線形の解決策が必要です$O(n + m)$、メモリ使用量に注意してください。 

セルフループは間違いを犯しやすい場所です。 ループは頂点の次数に 1 ではなく 2 を与えます。2 は偶数なので、ループがパリティに影響することはありません。 ループに対して次数を 1 回だけインクリメントする不注意な実装は、答えを黙って壊します。 

接続されていない孤立した頂点も別の罠です。 考慮する：```
4 1
1 2
```頂点 3 と 4 は分離されています。 それらに触れるトレイルはないので、それらはまったく問題ではありません。 グラフは実質的にエッジのみで構成されます$1-2$。 両方の端点で次数が奇数であるため、追加のエッジが 1 つ必要です。 正しい答えは次のとおりです。```
1
```グラフ全体が接続されなければならないと主張する単純なアプローチでは、誤って孤立した頂点も接続しようとします。 

もう 1 つの微妙なケースは、頂点 1 自体は分離されているが、エッジが別の場所に存在する場合です。```
4 2
2 3
3 4
```エッジを含むコンポーネントがオイラー型になったとしても、Vasya は依然として頂点 1 から開始してそれらのエッジを横断することはできません。 エッジを含むコンポーネントを頂点 1 に接続する必要があります。正解は次のとおりです。```
2
```追加された 1 つのエッジは頂点 1 をコンポーネントに接続し、もう 1 つは奇数の次数を固定します。 

最後の注意が必要なシナリオは、複数のオイラー コンポーネントが切断されている場合です。```
6 6
1 2
2 1
3 4
4 3
5 6
6 5
```すべての次数はすでに均等ですが、グラフにはエッジを含む 3 つの別々のコンポーネントがあります。 それらを結び付けなければなりません。 最小限の答えは次のとおりです。```
2
```1 つのエッジは、選択した 2 つの頂点でパリティを反転しながら 2 つのコンポーネントをマージできます。 接続性とパリティを同時に管理することが、この問題の核心的な難しさです。 

## アプローチ

 この問題を考える強引な方法は、グラフがオイラー型になるまで、考えられるすべての頂点のペアを試してエッジを繰り返し追加することです。 変更を加えるたびに、接続性と次数の同等性を確認できました。 

チェック自体は線形ですが、可能なエッジ追加の数は 2 次です。 すべてのシングルエッジを試してもすでにコストがかかります$O(n^2)$、それは絶望的です$10^6$頂点。 さらに悪いことに、最適なシーケンスには複数の追加が必要となり、指数関数的な検索スペースが作成される可能性があります。 

グラフ理論によるオイラー サイクルの特徴付けは、より強力な方向性を与えます。 正確な歩数は気にしません。 ここで考慮するのは 2 つのグローバル プロパティだけです。 

1. 分離されていないすべての頂点は、頂点 1 を持つ 1 つの連結コンポーネント内に存在する必要があります。 
2. すべての次数は均等でなければなりません。 

1 つのエッジを追加すると、常に 2 つの頂点のパリティが反転します。 同時に、2 つの接続されたコンポーネントをマージできます。 

その相互作用が重要な洞察です。 コンポーネントの接続はパリティの固定から独立していません。 慎重に選択された接続エッジにより、コンポーネントの数を減らし、同時に奇数の程度を修復することができます。 

接続コンポーネントに次のものが含まれているとします。$k$奇数次の頂点。 内部的には、オイラー式にするには次のことが必要になります。$k/2$エッジを追加しました。 ただし、コンポーネントを接続すると、接続エッジのパリティも変更されます。 これにより、全体的な最適化問題が発生します。 

これについては、コンポーネントごとに考えるのが賢明な方法です。 

コンポーネントにすでに奇数の頂点がある場合は、それらのいくつかを接続エンドポイントとして使用できます。 次に、コンポーネントを他のコンポーネントに接続すると、パリティを「無料」で修正できます。 

コンポーネントの次数がすべて偶数の場合、接続エッジによって 2 つの奇数の頂点が作成されるため、後でどこかでもう 1 回パリティ補正が必要になります。 このようなコンポーネントは事実上、追加コストの原因となります。 

させて：

-$C$少なくとも 1 つのエッジを含む接続されたコンポーネントの数に加え、分離されている場合は孤立した頂点 1 を追加することもできます。 
-$O$は、関連するコンポーネントにわたる奇数次の頂点の総数になります。 

最小限の答えは次のようになります。$$(C - 1) + \max\left(0, \frac{O}{2} - (C - 1)\right)$$これは次のように単純化されます。$$\max\left(C - 1, \frac{O}{2}\right)$$しかし、重要な修正が 1 つあります。 奇数頂点がゼロのコンポーネントは、接続すると奇数頂点が作成されるため、接続が難しくなります。 これを注意深く考慮すると、古典的な公式が導き出されます。$$\text{answer} = \begin{cases} 0 & \text{if no edges exist} \\ \frac{O}{2} + \max(0, E - 1) & \text{otherwise} \end{cases}$$どこ$E$すべての頂点の次数が偶数である接続コンポーネントの数です。 

同等の実装に適した定式化は次のとおりです。 

関連するすべてのコンポーネントについて、次のことに貢献してください。$$\max(1, \frac{\text{odd count}}{2})$$すべてのコンポーネントを連鎖させることができるため、最後に 1 を減算します。 

この定式化は、すべての特殊なケースに自然に対処します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数関数 /$O(n^2)$試行ごと |$O(n+m)$| 遅すぎる |
 | 最適 |$O(n+m)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. エッジを読み取りながら、すべての頂点上に DSU を構築します。 

すべてのエッジは 2 つの頂点を同じ連結コンポーネントに結合します。 同時に、すべての頂点の次数を計算します。 自己ループでは次数が 2 増加します。 
2. 少なくとも 1 つのエッジを含むすべての接続コンポーネントを特定します。 

頂点 1 以外の孤立した頂点は、Vasya がそれらを訪問する必要がないため無関係です。 
3. グラフにエッジがまったくない場合は、0 を返します。 

Vasya は、何もトラバースすることなく、すでに頂点 1 で開始および終了しています。 
4. 関連するコンポーネントごとに、その中の次数が奇数の頂点の数を数えます。 

オイラーパリティは、これらの奇数の頂点にのみ依存します。 
5. 頂点 1 がエッジを含むコンポーネントに属していない場合は、それを奇数頂点が 0 個の独自の追加コンポーネントとして扱います。 

そうしないと、Vasyaはトレイルに到達することさえできません。 
6. 関連するコンポーネントごとに、以下を追加します。$$\max(1, \frac{\text{odd count}}{2})$$回答アキュムレーターに。 

奇数の頂点を持つコンポーネントには、少なくとも奇数/2 の修復が必要です。 すべての次数が偶数のコンポーネントでも、グラフの残りの部分に接続するには少なくとも 1 つのエッジが必要です。 
7. 合計から 1 を引きます。 

接続中$k$別々の構造を一緒にするために必要なのは、$k-1$1 つのコンポーネントがベースとして機能できるため、操作をリンクできます。 

### なぜ効果があるのか

 連結コンポーネント内で、すべての次数を偶数にするために必要な追加エッジの最小数は、奇数の頂点の数のちょうど半分です。 

複数のコンポーネントが存在する場合、それらを接続するとパリティも変更されます。 接続エッジは各側から 1 つの奇数頂点を消費することができ、コンポーネントをマージする際にパリティを効果的に修復します。 

コンポーネントにすでに奇数の頂点がある場合は、いつでもそれらをアタッチメント ポイントとして使用できます。 そのコストは奇数/2のままです。 

コンポーネントに奇数の頂点がない場合、アタッチメントによって新しい奇数の頂点が作成されるため、そのコンポーネントには少なくとも 1 つのエッジが追加されることは避けられません。 

合計する$\max(1, \text{odd}/2)$関連するすべてのコンポーネントについて、各コンポーネントの修理にかかる独立したコストがカウントされます。 すべてのコンポーネントが最終的に 1 つのグラフにマージされるため、1 つの接続操作がグローバルに共有されるため、1 を減算すると正確な最適値が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n + 1))
        self.size = [1] * (n + 1)

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra = self.find(a)
        rb = self.find(b)

        if ra == rb:
            return

        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra

        self.parent[rb] = ra
        self.size[ra] += self.size[rb]

def solve():
    n, m = map(int, input().split())

    dsu = DSU(n)
    deg = [0] * (n + 1)

    for _ in range(m):
        u, v = map(int, input().split())

        dsu.union(u, v)

        if u == v:
            deg[u] += 2
        else:
            deg[u] += 1
            deg[v] += 1

    if m == 0:
        print(0)
        return

    comp_has_edge = {}
    odd_count = {}

    for v in range(1, n + 1):
        if deg[v] == 0:
            continue

        root = dsu.find(v)

        comp_has_edge[root] = True

        if root not in odd_count:
            odd_count[root] = 0

        if deg[v] % 2 == 1:
            odd_count[root] += 1

    root1 = dsu.find(1)
    relevant = set(comp_has_edge.keys())

    if deg[1] == 0:
        relevant.add(root1)
        if root1 not in odd_count:
            odd_count[root1] = 0

    ans = 0

    for root in relevant:
        odd = odd_count.get(root, 0)
        ans += max(1, odd // 2)

    ans -= 1

    print(ans)

solve()
```DSU は、接続されたコンポーネントをほぼ一定の償却時間で維持します。 最大 100 万のエッジでは、Python の再帰の深さとスタック メモリが問題となるため、再帰的 DFS は危険です。 DSUはそれを完全に回避します。 

度数の扱いは最もデリケートな部分です。 自己ループは同じ頂点に 2 を与えます。これは、ループの走査が頂点に入り、頂点から出るのが 1 回であるためです。 

通常のコンポーネントでは、ゼロ以外の度数を持つ頂点のみが問題になります。 孤立した頂点はオイラー ツアーに参加しません。 唯一の例外は頂点 1 です。すべてのトレイルが他の場所にある場合は、頂点 1 をグラフに明示的に接続する必要があります。そうすることで、次数 0 であってもそのコンポーネントが関連するようになります。 

無向グラフ コンポーネント内の奇数の頂点の数は常に偶数であるため、式では整数の除算が使用されます。 

最後に1を引くのは忘れがちです。 合計では各コンポーネントのコストが個別にカウントされますが、すべてをマージした後は、1 つの接続操作がグローバルに重複します。

 ## 特殊なケース

 頂点 1 が孤立しているが、トレイルが他の場所に存在する場合を考えてみましょう。```
4 2
2 3
3 4
```学位は次のとおりです。 

- 度(2) = 1
 - 度(3) = 2
 - 度(4) = 1
 - 度(1) = 0

次に、純粋な自己ループを考えてみましょう。```

1 1
2 2
```各ループは次数 2 に寄与します。両方のコンポーネントは個別にオイラー関数です。 それぞれが 1 を貢献し、$1 + 1 - 1 = 1$。 頂点 1 と 2 の間にエッジを 1 つ追加すると、接続されたオイラー グラフが作成されます。 

Finally, consider many isolated vertices:```
5 1
1 2
```頂点 3、4、および 5 は、次数が 0 であり、ウォークに参加しないため、完全に無視されます。 エッジを含むコンポーネントのみ$1-2$重要です。 奇数の頂点が 2 つあるので、答えは 1 です。
