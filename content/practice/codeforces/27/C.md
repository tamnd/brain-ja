 ## 解決策
 ## 問題の理解

 整数のシーケンスが与えられ、_順序付けされていない_ 最も短い部分シーケンスを抽出するように求められます。 シーケンスが完全に減少していないか、完全に増加していない場合、シーケンスは順序付けされていると見なされます。 言い換えれば、連続するすべてのペアが決して減少しない、または決して増加しない場合、シーケンスは順序付けされています。 私たちの仕事は、このパターンを打ち破る最小限のサブシーケンスを見つけることです。 

入力は単一の整数で構成されます$n$シーケンスの長さを指定してから、$n$整数。 出力では、最も短い順序付けされていないサブシーケンス (存在する場合) の長さと、その要素の 1 から始まるインデックスが報告されます。 

と$n$まで$10^5$2 秒の時間制限があるため、線形よりも複雑なソリューションは遅すぎる可能性があります。 アン$O(n^2)$すべてのトリプレットのブルートフォース検索はすでに実行されています$10^{10}$最悪の場合の操作ですが、これは明らかに実行不可能です。 これは、シングルパスまたはニアリニアスキャンアプローチの必要性を示唆しています。 

エッジケースは微妙です。 すべての要素が等しい場合、順序のないサブシーケンスは存在しないため、出力はゼロになる必要があります。 シーケンスに要素が 1 つまたは 2 つしかない場合、サブシーケンスは自明に順序付けされます。 また、「変化」があるように見えても、実際には単調性が崩れていない、厳密に増加または減少するシーケンスを処理する必要もあります。 

## アプローチ

 単純な解決策では、長さ 3 のすべてのサブシーケンスを調べて、それらが順序付けされているかどうかを確認します。 これが機能するのは、順序付けされていないサブシーケンスには少なくとも 3 つの要素が必要であるためです。2 つの要素は常に順序付けされています。 一定の長さの配列内のすべてのトリプレットをチェックする$n$おおよそ必要です$n^3$操作は完全に非現実的です$n = 10^5$。 

重要な洞察は、最も短い順序付けされていないサブシーケンスの長さが常に 3 であるということです。 3 つの連続する要素が見つかったとします。$a_i, a_j, a_k$どこ$i < j < k$そのような$a_i < a_j > a_k$または$a_i > a_j < a_k$。 3 つ以上の要素からなる順序のないシーケンスには、このようなトリプルが含まれます。 したがって、配列を 1 回スキャンして、連続する要素のすべての 3 つをチェックするだけで済みます。 3 つ組が単調性を破るとすぐに、それを出力できます。 

この観察により、複雑さが軽減されます。$O(n^3)$に$O(n)$一定のスペースで。 順序のないトリプルを検出するには、現在の要素とそのすぐ隣の要素のみが必要です。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n3) | お(1) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 一連の整数を配列に読み取ります。 
2. 系列長が 3 未満の場合は、直ちに 0 を出力します。 2 つの要素は常に順序付けされます。 
3. インデックスを使用して配列を反復処理します。$i$1から$n-2$。 三つ子ごとに$(a[i-1], a[i], a[i+1])$、注文条件を確認してください。 
4. 中央の要素が両方の隣接要素よりも厳密に大きい場合 ($a[i-1] < a[i] > a[i+1]$) または両方の隣よりも厳密に小さい ($a[i-1] > a[i] < a[i+1]$)、トリプレットの長さ 3 とその 1 から始まるインデックスを出力します。$i, i+1, i+2$。 直ちに終了してください。 
5. 順序のないトリプレットが見つからずにループが終了した場合は、0 を出力します。 

機能する理由: 単調ではない 3 つの要素のシーケンスは最小であるため、アルゴリズムは順序のない最短のサブシーケンスを見つけることが保証されています。 連続する 3 つ組をスキャンすることで、そのようなサブシーケンスを決して見逃すことがなくなります。 長さ 2 のシーケンスは順序に違反しないため、3 が正しい最小長になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

if n < 3:
    print(0)
else:
    found = False
    for i in range(1, n-1):
        if (a[i-1] < a[i] > a[i+1]) or (a[i-1] > a[i] < a[i+1]):
            print(3)
            print(i, i+1, i+2)
            found = True
            break
    if not found:
        print(0)
```コードは、長さが 3 未満のシーケンスを処理することから始まります。 次に、連続するトリプレットを 1 回ずつチェックします。 この条件は、「山」または「谷」の形成を明示的にチェックします。 1 から始まるインデックスの使用は、問題の要件と一致します。 微妙な点は、平等は順序を破るものとしてカウントされないことです。条件では厳密な不等式が使用されます。

 ## 特殊なケース

 繰り返される要素を含むシーケンスの場合、例:`2 2 2`、アルゴリズムは連続するトリプレットをチェックします。 厳密な不等式が満たされないため、0 が出力されます。長さ 2 のシーケンスの場合、次のようになります。`1 2`、最初のチェックはすぐに 0 を返します。開始、中間、または終了に最小限の順序付けられていないサブシーケンスがあるシーケンスの場合、アルゴリズムは常に、最初に見つかったそのようなトリプルを識別します。 

この社説は、最も短い順序付けられていない部分列は常に長さ 3 であり、1 回の線形スキャンで検出できるという第一原理から推論するのに十分な文脈を読者に提供するはずです。
