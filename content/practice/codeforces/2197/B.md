 ## 解決策
 ## 問題の理解

 順列が与えられています`p`長さの`n`そして配列`a`同じ長さの。 順列は、次の異なる整数の配列です。`1`に`n`、いくつかの順序で。 どうかを判断したいのです。`a`から生産された可能性があります`p`一連の操作を使用し、各操作で 2 つの隣接する要素を選択します。`p`一方の値をもう一方にコピーします。 つまり、隣接するペアに対して`(p[i], p[i+1])`、どちらかを設定できます`p[i] = p[i+1]`または`p[i+1] = p[i]`。 

重要なのは、これらの操作は**既存の番号を近隣に伝播する**のみであり、新しい番号を導入することは決してないということです。 したがって、ここに表示されるすべての数字は、`a`のどこかの位置に存在していたはずです`p`。 さらに、数値を位置に導入すると、その数値を左または右に「拡張」して他の数値を上書きできるため、同じ数値の連続したブロックが`a`内の単一の元の出現によって生成されます。`p`。 

制約は次のようなものです`n`まで可能です`2 * 10^5`、との合計`n`すべてのテストケースで次を超えない`2 * 10^5`。 これにより、テスト ケースごとの複雑さが線形よりも悪いソリューションは除外されます。 コピー操作のブルート フォース シミュレーションは、次のようになります。`n`最悪の場合はタイムアウトになってしまいます。 

微妙なエッジ ケースには、すべての要素が等しい配列、数値が繰り返されるが連続していない配列などが含まれます。`a`、および最後の要素または最初の要素を遠くから伝播する必要がある配列。 例えば、`p = [1, 2, 3]`そして`a = [2, 2, 2]`数が多いので無理です`2`最初の位置が存在しない場合、最初の位置に伝播することはできません。 

## アプローチ

 素朴なアプローチは、操作を直接シミュレートすることです。`p`との不一致ごとに、`a`、一致するまでコピー操作を実行します。 これは、操作により隣接する位置に数値を分散できるため、原理的には機能しますが、最悪の場合、O(n^2) の操作が必要になります。 たとえば、次の場合`p`は`[1,2,3,...,n]`そして`a`は`[1]*n`、要素を 1 つずつ上書きすることを繰り返します。 と`n`最大 2 * 10^5、これは遅すぎます。 

最適なアプローチの重要な観察事項は、**数値が存在すると、`p`、連続したセグメントを通じて伝播する可能性があります**。 したがって、次の数値シーケンスが正しいかどうかを確認するだけで済みます。`a`に存在する数を拡張することによって形成される可能性があります`p`順番に。 具体的には、`a`左から右へポインタを維持します`p`これは、新しい番号に最初に使用可能な位置を表します。 もし`a[i]`の現在の番号と一致します`p`、ポインタを進めます。 もし`a[i]`前の番号を繰り返します`a`、続けます。 もし`a[i]`前の番号または次に使用可能な番号のいずれとも一致しません`p`、配列は不可能です。 

これにより、問題は単一のパススルーに軽減されます。`a`ポインタを維持しながら`p`、テスト ケースごとに線形 O(n) 解が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 順列を読み取る`p`そして配列`a`。 ポインタを初期化する`j = 0`のために`p`。 
2. 配列を走査する`a`左から右へ。 させて`prev`前の要素を格納します`a`、最初は次のように設定されています`None`。 
3. 各要素について`a[i]`に等しい場合`prev`、 続く。 これは、連続したブロック内にいて、そこから新しい番号がないことを意味します。`p`が必要です。 
4. もし`a[i]`に等しくありません`prev`、私たちはそれを見つけようとします`p`インデックスから始まる`j`。 もし`p[j]`等しい`a[i]`、増分`j`そして更新します`prev`に`a[i]`。 
5. もし`a[i]`に等しくありません`prev`そして一致しません`p[j]`、配列`a`から生成することはできません`p`。 出力`NO`。 
6. 終わりに達したら`a`競合なしで出力`YES`。 

なぜ機能するのか: ポインタ`j`各要素のみを使用するようにします`p`一度は新しい数字のソースとして。 繰り返される数値の伝播`a`との比較によって処理されます。`prev`。 数字が入っている場合`a`で次に利用可能な番号と一致することはできません`p`これは繰り返しではありません。これは、正当なコピー操作の順序によっては生成できないことを意味し、正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))
    a = list(map(int, input().split()))
    
    j = 0
    prev = None
    possible = True
    
    for num in a:
        if num == prev:
            continue
        while j < n and p[j] != num:
            j += 1
        if j == n:
            possible = False
            break
        prev = num
        j += 1
    
    print("YES" if possible else "NO")
```このソリューションは、複数のテスト ケースの入力を効率的に読み取ります。 ポインタ`j`進む`p`新しい番号が入ったときのみ`a`が発生し、次の各要素が保証されます。`p`多くても 1 回使用されます。 繰り返される数字`a`によって扱われます`prev`、したがって、の新しい要素を消費しません`p`不必要に。 の`while`ループは数値をスキップすることを保証します`p`すでに可決されており、現在の数値に寄与できないもの`a`。
