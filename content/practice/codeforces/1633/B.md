 ## 解決策
 ## 問題の理解

 このタスクは、「0」と「1」で構成されるバイナリ文字列を調べ、1 回の操作で最大数の文字を削除できる連続セグメントを特定することです。 この操作により、部分文字列を選択し、その部分文字列内に出現する厳密に少数の文字をすべて削除できます。 完全少数とは、選択された部分文字列内で、ある文字が他の文字よりも出現する回数が厳密に少ないことを意味します。 両方の文字が同じように出現する場合、操作は何も行いません。 

入力は複数のテスト ケースで構成され、それぞれが 1 つの文字列を持ちます。 出力は、各テスト ケースで削除できる最大文字数である必要があります。 文字列の長さは 200,000 に達する可能性があり、すべてのテスト ケースの合計入力サイズも 200,000 に制限されるため、文字列ごとに線形時間で実行されるソリューションが必要です。 すべての部分文字列を調べるブルートフォース手法では、大まかに次のものが必要になります。$O(n^2)$操作が遅すぎるため、$n = 2 \cdot 10^5$。 

エッジ ケースには、すべての文字が同じである文字列、長さ 1 の文字列、文字が交互に並ぶ文字列が含まれます。 たとえば、次の文字列`1`どの部分文字列にも少数派がないため、出力は 0 になります。`01`また、両方の文字が両方を含む唯一の部分文字列内に同等に出現するため、文字を削除することはできません。その結果、出力は 0 になります。これらのケースを適切に処理できないと、カウントしすぎたり、「完全少数派」の制約を無視したりする可能性があります。 

## アプローチ

 ブルート フォース ソリューションでは、考えられるすべての部分文字列を反復処理し、その部分文字列内の「0」と「1」の数を数え、少数派の数を計算します。 正しいとはいえ、この方法は$O(n^2)$間に合わず、大きな文字列の場合は現実的ではありません。 長さ 200,000 の文字列の場合、次のようになります。$2 \cdot 10^10$操作。 

重要な洞察は、操作の効果が、選択された部分文字列内の少数文字の出現数にのみ依存するということです。 削除する文字数を最大化することに重点を置く場合は、一方の文字が他方の文字よりも頻繁に存在する最大の連続シーケンスを見つけるだけで済みます。 この問題は、最大合計部分配列を見つけるための古典的なアプローチである Kadane のアルゴリズムの変形に帰着できます。 「0」と「1」を +1 と -1 (どちらを削除可能として扱うかに応じて) にマッピングすることで、削除される文字の数を最大にするセグメントを効率的に見つけることができます。 任意の連続した部分文字列を選択できるため、ある文字の数が他の文字よりも大幅に多いセグメントがまさに必要なものになります。

 ## アルゴリズムのチュートリアル

 1. 文字列内の「0」と「1」の合計数を数えます。 少数文字を主に含む部分文字列は、グローバル少数文字カウントを使用するよりも少ない文字を削除できるため、文字列全体の少数文字が適切な候補となります。 
2. 文字列全体の「0」の数が「1」の数と等しい場合、文字列のどの部分文字列にも厳密な少数文字が存在しないため、削除できる文字の最大数はゼロになります。 
3. それ以外の場合は、どのキャラクターが少数派であるかを特定します。 と表しましょう`minor`そして大多数は`major`。 
4. Kadane のアルゴリズムの目的で、文字列を値の配列にマッピングします。少数の文字が出現するたびに +1 になり、多数の文字が出現するたびに -1 になります。 
5. 最大部分配列合計アルゴリズムを適用して、合計を最大化する連続部分文字列を見つけます。 合計は、その部分文字列内で削除できる少数文字の数に正確に対応します。 
6. 最大合計が負またはゼロの場合は、ゼロを返します。 それ以外の場合は、そのテスト ケースの答えとして合計を返します。 

機能する理由: 各ステップでは、選択された部分文字列が完全少数派の除去を最大化するという不変条件が保持されます。 Kadane 変換は、少数派/多数派の関係を尊重しながら、問題を標準の最大化問題に変換します。 多数派より少数派の部分が多い部分文字列はプラスの寄与につながるため、アルゴリズムは自然に最適なセグメントを見つけます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_removed(s: str) -> int:
    total_0 = s.count('0')
    total_1 = len(s) - total_0
    
    if total_0 == total_1:
        return 0
    
    minor = '0' if total_0 < total_1 else '1'
    # Transform string into array for Kadane's algorithm
    arr = [1 if c == minor else -1 for c in s]
    
    max_sum = curr_sum = 0
    for val in arr:
        curr_sum = max(val, curr_sum + val)
        max_sum = max(max_sum, curr_sum)
    
    return max_sum

t = int(input())
for _ in range(t):
    s = input().strip()
    print(max_removed(s))
```このソリューションでは、各文字の合計数を数え、少数派を決定し、簡単な変換を使用して Kadane のアルゴリズムを適用します。 長さ 1 の文字列、または同じ数の「0」と「1」を含む文字列などの境界条件は、明示的に処理されます。 Kadane ループにより、最大連続セグメントが正しく追跡され、off-by-one エラーが回避されます。
