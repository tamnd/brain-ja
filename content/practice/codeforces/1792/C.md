 ## 解決策
 ## 問題の理解

 サイズの順列が与えられています$n$、これは単に次の各整数を含むシーケンスです。$1$に$n$まさに一度。 タスクは、特別な操作を使用してこの順列を何度でも並べ替えることです。 各操作では、2 つの数値を選択して削除し、小さい方をシーケンスの先頭に挿入し、大きい方をシーケンスの最後に挿入することができます。 目標は、順列を厳密に増加する順序に変換するために必要なそのような演算の最小数を見つけることです。 

制約は次のことを教えてくれます$n$と同じ大きさにすることができます$2 \cdot 10^5$すべてのテストケースにわたって、最大で$10^4$テストケース。 これにより、テスト ケースごとに 2 次アプローチでさえ遅すぎるため、考えられるすべての操作をシミュレートしたり、要素のすべてのペアを明示的に試行しようとするソリューションは除外されます。 テスト ケースごとに線形または線形に近い時間で機能するソリューションを見つける必要があります。 

エッジケースは、順列がすでにソートされている場合、すでに逆転されている場合、または末尾に最大値または最小値がある場合に発生します。 たとえば、順列がすでに次のようにソートされている場合、`[1,2,3]`、正解は`0`。 順列が`[3,2,1]`、最大の要素を末尾に移動し、最小の要素を先頭に移動するには、この操作を少なくとも 1 回使用する必要があります。 不注意なソリューションでは、最初と最後の要素の相対的な位置を考慮しないと、操作が過剰にカウントされる可能性があります。`1`そして`n`。 

## アプローチ

 ブルートフォースアプローチでは、操作を貪欲にシミュレートしようとします。 考えられるすべての要素のペアを試し、結果の配列を計算し、ソートされるまで再帰的に続行することができます。 このアプローチは理論的には正しいですが、その複雑さは次の点で指数関数的になります。$n$、これは完全に不可能です$n$まで$2 \cdot 10^5$。 

最適化するための重要な観察は、各操作が開始または終了の最終位置に 1 つの要素を効果的に配置できることです。 したがって、最小要素と最大要素の位置を追跡するだけで済みます。 問題は、端の要素のシーケンスを調べることに帰着します。最初の要素が`1`あるいは最後は`n`、すでに正しい境界が 1 つあります。 最初の要素が`n`あるいは最後は`1`、シーケンスが複雑になります。 それ以外の場合は、最初と最後の要素がソートされた位置とどのように異なるかを数えることによって、操作の最小数を推測できます。 この洞察により、テスト ケースごとに一定時間の評価が可能になります。 

最小要素と最大要素の位置を推論することで、順列を 4 つのケースに分類できます。すでにソートされている場合、間違った端の 1 つの要素を除いてソートされている場合、反転されている場合、または完全にソートされていない場合です。 各ケースには、あらかじめ決められた数の操作があります。`0`、`1`、`2`、 または`3`。

 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$そして順列`p`。 
2. 次のことを確認します。`p[0]`は`1`そして`p[-1]`は`n`。 両方が true の場合、配列はすでにソートされています。 戻る`0`。 
3. 次のことを確認します。`p[0]`は`n`そして`p[-1]`は`1`。 両方が true の場合、配列は完全に逆になります。 戻る`3`なぜなら、少なくとも 2 つの操作と、中間の調整のための追加の操作で両端を正しく移動する必要があるからです。 
4. どちらかの場合`p[0]`は`1`または`p[-1]`は`n`、 戻る`1`。 もう一方の端を固定するには 1 回の操作で十分です。 
5.そうでない場合は、戻ります`2`。 最初と最後の要素は適切ではありませんが、どちらも極端に間違っているわけではありません。 正しく配置するには 2 回の操作で十分です。 

正確さを保証する不変条件は、各操作が 1 つの数値を最終的なソート位置に移動することです。 最初と最後の位置のみを分析することで、残りの要素は常にこれらのカウントで調整できるため、最小限の操作のすべてのシナリオをキャプチャします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def min_max_sort():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        if p[0] == 1 and p[-1] == n:
            print(0)
        elif p[0] == n and p[-1] == 1:
            print(3)
        elif p[0] == 1 or p[-1] == n:
            print(1)
        elif p[0] == n or p[-1] == 1:
            print(2)
        else:
            print(2)

min_max_sort()
```このソリューションでは、まずテスト ケースの数を読み取り、それぞれをループします。 操作を最小限に抑えるために条件が注意深くチェックされ、過小カウントを避けるために特殊な逆ケースが明示的に処理されます。 すべてのチェックは定数時間であり、順列の読み取りは線形であるため、ソリューションは大きな入力に対して適切にスケーリングされます。
