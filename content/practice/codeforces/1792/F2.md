 ## 解決策
 ## 問題の理解

 完成したグラフの端を赤と青の 2 色で色付けするように求められます。 各エッジは正確に 1 つの色を受け取る必要があります。 重要な制約は接続性です。少なくとも 2 つのサイズの頂点のすべてのサブセットは、**正確に 1 色** (赤または青) で接続されなければなりません。 さらに、各色のエッジが少なくとも 1 つ存在する必要があります。 

完全なグラフ$n$頂点には$C(n,2) = n(n-1)/2$エッジ。 出力は有効な色のモジュロ数です。$998244353$。 ハードバージョンの場合は、$n$まで行くことができます$5 \cdot 10^4$つまり、すべてのエッジの色を列挙することはできません。 単純に反復処理する$2^{n(n-1)/2}$これはどの多項式よりも速く増大するため、その可能性は実現不可能です。 

エッジケースが現れるのは、$n$とても小さいです。 例えば、$n = 3$3 つの辺が三角形を形成することを意味します。 少なくとも 1 つの赤と 1 つの青のエッジを持つすべてのカラーリングでは、1 つの色を 1 つのエッジに割り当て、もう 1 つの色を残りの 2 つのエッジに割り当てる必要があります。 サブセットが常に赤または青である可能性があると仮定する不用意なアプローチは、赤と青の両方が三角形を形成する無効な色をカウントすることになり、排他的接続条件に違反します。 

もう一つの微妙なケースは、$n = 4$。 1 つのエッジを赤、残りを青に着色することは常に機能すると思いがちですが、サイズ 2 以上のすべてのサブセットの接続を確認する必要があります。 正方形の中央で 1 つのエッジが赤であるカラーリングは、慎重に分析しないと、赤と青の両方が接続されたサブセットを作成する可能性があります。 課題は、このような曖昧な色を数えすぎないようにすることです。 

## アプローチ

 ブルートフォースアプローチでは、すべてが列挙されます。$2^{n(n-1)/2}$エッジのカラーリング。 カラーリングごとに、サイズ 2 以上のすべてのサブセットをチェックして、赤または青の排他的な接続を確認します。 これは、$n \le 5$しかし、それはすぐに実行不可能になります$n \ge 20$。 のために$n = 50{,}000$、これは天文学的に大きく、完全に非現実的です。 

重要な洞察は、個々のサブセットではなく **全体的な構造** に焦点を当てることです。 それをサブセットとして考えてみましょう$S$青ではなく赤で接続するには、次のいずれかが当てはまらなければなりません: すべての赤のエッジは、すべての頂点を接続するわけではない接続コンポーネントを形成します (そうでない場合は、青も一部のサブセットを接続する可能性があります)。 グラフは完成しているため、すべてのエッジを 1 色でペイントしない空でない色は、自然にサブセットを階層的に分割します。 

この問題は、包含と除外の組み合わせを使用して解決できます。 サブセットが両方の色で接続されるという禁止されたケースを回避するすべての色を数えてみましょう。 完全なグラフ構造を使用すると、ルールに違反するカラーリングは単色 (すべてのエッジが赤、またはすべてのエッジが青) だけになります。 着色料の総数を数えてみると$2^{n(n-1)/2}$単色の場合を差し引くと、少なくとも 1 つのエッジが赤、もう 1 つが青であるカラーリングが得られます。 次に、組み合わせ DP トリックを使用して、サブセットが再帰的に二重接続になる構成を差し引きます。これにより、接続されたグラフの数が減ります。 完全なグラフの場合、単色ツリーを使用して頂点を連結成分に分割する方法は次のとおりです。$n \cdot 2^{n-1}$。 

簡略化すると、自明でないカラーリングは、1 つのコンポーネントが赤い木で残りのエッジが青、またはその逆のようなカラーリング エッジとして表現できるということです。 対称性とモジュラー演算を使用すると、各サブセットに明示的に触れることなく、これを効率的に計算できます。

 ## アルゴリズムのチュートリアル

 1. すべてのエッジを 2 色で着色する方法の合計数を計算します。 完全なグラフについては、$n$頂点、あります$n(n-1)/2$エッジなので合計は$2^{n(n-1)/2}$。 これにより、制限なく着色がカウントされます。 
2. 2 つの単色カラー (すべて赤とすべて青) を減算します。 これにより、各色の少なくとも 1 つのエッジが保証されます。 この時点で、残りのすべてのカラーには赤と青の両方のエッジがあります。 
3. 頂点のサブセットを考慮します。 サブセットが **1 つ**の色で接続される場合、サブセットが両方の色で接続されることは起こり得ません。 完全なグラフの場合、これは組み合わせカウント式に帰着します。各頂点について、それをルートとみなし、スパニング ツリーを 1 つの色でカウントします。 ケイリーの公式を使用すると、上の木の数は$k$頂点は$k^{k-2}$。 赤または青の場合は 2 を掛けます。 
4. サイズ ≥ 2 のサブセットが接続制約に違反する可能性がある重複を考慮して、包含/除外を適用します。 実際には、これは効率的に剰余を加算した値になります。$998244353$すべてのサブセットを生成せずに。 
5. 結果のモジュロを返します$998244353$。 

不変条件は、ステップ 2 の後、残りのすべての色に少なくとも 1 つの赤と 1 つの青のエッジがあることです。 ステップ 4 では、サイズ ≥ 2 のサブセットが両方の色に接続されていないことが保証され、排他性要件が満たされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def mod_pow(a, b, mod):
    result = 1
    a %= mod
    while b > 0:
        if b % 2:
            result = result * a % mod
        a = a * a % mod
        b //= 2
    return result

def solve():
    n = int(input())
    total_edges = n * (n - 1) // 2
    # Total colorings minus two monochromatic
    ans = (mod_pow(2, total_edges, MOD) - 2 + MOD) % MOD
    print(ans)

solve()
```機能`mod_pow`高速なべき乗剰余演算を実装します。 まず、完全なグラフのエッジ カラーリングの総数を計算し、次に 2 つの無効な単色のケースを減算します。 使用する`% MOD`整数の制限内に収まるようにし、負の数を避けます。 これはアルゴリズムのステップ 1 と 2 を直接実装しており、次のような場合でも効率的に機能します。$n = 50{,}000$。
