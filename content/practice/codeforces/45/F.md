 ## 解決策
 ## 問題の理解

 古典的な川渡りの設定がありますが、トランジションの動作方法を変更する正確な安全ルールが適用されます。 

最初に、次のものがあります。`m`ヤギと`m`左岸にはオオカミ。 目標は、最大でも運べるボートを使ってすべての動物を右岸に移動させることです。`n`動物を一度に。 ボートは横断するたびに必ず少なくとも 1 匹の動物を乗せなければなりません。 

あらゆる瞬間、動物が存在するあらゆる場所で、そこにヤギがまったくいない場合を除き、オオカミの数がヤギの数を厳密に上回ることは許されません。 この条件は、左岸、右岸、さらには渡河中のボート自体に個別に適用されます。 

もう一つ細かい点があります。 船が岸に着くと、まず乗客全員が一斉に降ります。 その後初めて次の乗客が乗車できるようになります。 したがって、荷降ろし後の中間状態も安全でなければなりません。 

タスクは、全員を安全に輸送するために必要な最小限の横断回数を計算するか、それが不可能であると判断することです。 

制約は大きいです。 両方`m`そして`n`到達できる`10^5`したがって、動物のすべての分布にわたる状態空間検索は不可能です。 州に対する単純な BFS は、おおよそ次のようになります。`(m+1)^2`州は片側にどれだけヤギとオオカミが残っているかによって決まるからです。 と`m = 10^5`、それは約になります`10^10`遷移を考慮する前の状態。 グラフを保存することさえ不可能です。 

問題には直接的な数学的特徴付けが必要です。 必要なのは`O(1)`または`O(log m)`解決。 

いくつかの特殊なケースは見落とされがちです。 

考慮する：```
1 1
```ボートに乗せられる動物は 1 匹だけです。 先にヤギを移動させれば、オオカミは一人で残るので安全ですが、その場合、ボートには動物を乗せなければならないため、ヤギは戻ることができなくなります。 オオカミを先に動かすとヤギがすぐに食べられてしまいます。 正しい答えは、`-1`。 

もう一つの危険なケースは次のとおりです。```
2 2
```一見すると古典的なパズルに似ていますが、容量は`2`実際には十分です。 5 つの交差を持つ 1 つの最適なシーケンスが存在します。 「3 未満の容量は不可能」と仮定した不注意な実装は、ここで失敗します。 

次に、次のことを考えてみましょう。```
100000 100000
```ボートは一度に全員を乗せることができます。 答えは`1`。 これを直ちに検出するのではなく、繰り返しの転送をシミュレートするソリューションは、不必要に複雑になる危険があります。 

最も微妙なケースは、ボートの収容能力が奇数である場合に発生します。 例えば：```
5 3
```多くの貪欲な転送戦略は、荷降ろし後に一時的に 1 つの銀行にヤギよりも多くのオオカミが含まれるため、失敗します。 解決策は、どのボート構成が基本的に安全で効率的であるかを理解するかどうかにかかっています。 

## アプローチ

 ブルート フォース アプローチでは、有効な各構成をグラフの状態としてモデル化します。 

状態は、左岸のヤギ、左岸のオオカミ、船の側の 3 つの値で表すことができます。 ある状態から、以下を含むあらゆる可能なボートの積載を試します。`1`そして`n`動物を観察し、ボート自体が安全かどうかを確認し、横断をシミュレートし、荷降ろし後に両岸が安全であることを確認します。 

制約はローカルであり、検証が簡単であるため、これは小さな値の場合に機能します。 BFS は、最小数の交差を自動的に生成します。 

問題は州の数です。 各バンクには以下の任意の場所を含めることができます。`0`に`m`ヤギとオオカミなので、州の数はおおよそ次のようになります。$(m+1)^2 \cdot 2$のために`m = 10^5`、これは天文学的な大きさです。 すべての遷移を生成することすら不可能です。 

重要な観察は、すべての安全な状態には厳格な構造があるということです。 

ヤギがいる銀行では、オオカミの数はヤギの数と等しくなければなりません。 総数は世界中で等しいため、不均衡があるとすぐにオオカミの数がヤギの数を上回る側が生じます。 

つまり、すべての安全な銀行の構成は次のようになります。$(k,k)$一部の人にとっては`k`。 

同じロジックがボートにも当てはまります。 ボートがオオカミと一緒にヤギを運ぶ場合、その数も同じでなければなりません。 そうしないと、船内のヤギが旅行中に食べられてしまいます。 

したがって、有用な前進旅行ごとに、同数のヤギとオオカミが輸送されます。 

1 つの往路が移動すると仮定します。`x`ヤギと`x`オオカミ。 それから：$2x \le n$ボートの定員があるので、`n`。 

進捗を最大化するには、可能な限り最大の有効な値を選択する必要があります。`x`:$x = \left\lfloor \frac{n}{2} \right\rfloor$このような旅行の後、ボートは少なくとも 1 匹の動物を連れて戻らなければなりません。 ヤギ 1 匹とオオカミ 1 匹を返すのが最適です。これは、進行状況の損失を最小限に抑えながら安全を確保できるためです。 

したがって、すべての完全なサイクルで正確に次のことが得られます。$x-1$宛先側のペア。 

これにより、パズルが単純な算術に変換されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース BFS | O(m² · トランジション) | O(㎡) | 遅すぎる |
 | 数学的貪欲 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 完全にフィットする些細なケースを取り扱います。 ボートの定員が少なくとも`2m`、すべての動物を 1 つの交差点で輸送できるため、答えは次のようになります。`1`。 
2. 1 回の安全な旅行で輸送できるヤギとオオカミの最大ペア数を計算します。$x = \left\lfloor \frac{n}{2} \right\rfloor$それぞれの往路では安全に運ぶことができます`x`ヤギと`x`オオカミ。 
3. もし`x = 0`、輸送は不可能です。 

これはつまり`n = 1`, したがって、ボートはヤギ1頭とオオカミ1頭を一緒に運ぶことはできません。 少しでも動けばすぐに危険な堤防や危険なボートが生じます。 
4. 1 つの完全なサイクルの正味の進行状況を観察します。 

前方横断輸送`x`右岸にペアになります。 続行するには、ボートは少なくとも 1 足を乗せて戻らなければなりません。 したがって、2 回の交差後の永続的なゲインは次のようになります。$x-1$ペア。 
5. もし`x = 1`そして`m > 1`、輸送は不可能です。 

容量`2`一度に 1 つのペアだけを移動できますが、その場合は同じペアが戻らなければなりません。 正味進捗はゼロになります。 
6. それ以外の場合は繰り返しゲイン`x-1`残りのペア数が最大になるまでペア`x`。 
7. 残りのすべてのペアを運ぶ最後のフォワードクロスを 1 回実行します。 
8. 交差する箇所を注意深く数えます。 

各完全なサイクルは 2 つの交差に寄与し、最後の輸送はさらに 1 つの交差に寄与します。 

### なぜ効果があるのか

 不変条件は、すべての安全な構成には、占有されたすべての場所に同数のヤギとオオカミがいるということです。 

ある銀行にヤギを収容しながら、ヤギよりもオオカミの方が多かったとします。 そうすればヤギはすぐに食べられてしまいます。 ヤギとオオカミの総数は世界的に等しいため、一方の平等から逸脱すると、どこかで反対の不均衡が生じます。 

この不変条件のため、すべての有効な輸送操作では、同数のヤギとオオカミを一緒に移動する必要があります。 このような負荷を最大にすると、往路ごとの進行が最大になります。 ボートは占拠されて戻らなければならないため、1 ペア未満を返すことは不可能であり、2 ペア以上を返しても進歩が減少するだけです。 

したがって、最適な戦略が強制されます。常に可能な限り最大の等しいグループを前方に輸送し、正確に 1 つのペアを返し、最後の移動まで繰り返すというものです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    m, n = map(int, input().split())

    if n >= 2 * m:
        print(1)
        return

    x = n // 2

    if x == 0:
        print(-1)
        return

    if x == 1:
        print(-1)
        return

    full_cycles = (m - x + (x - 2)) // (x - 1)

    answer = full_cycles * 2 + 1

    print(answer)

solve()
```実装は数学的導出に直接従います。 

最初の条件は、ボートがすべての動物を直ちに運ぶ場合を処理します。 このケースを省略すると、次のような場合に不正確な回答が発生します。`m = 1`そして`n = 2`なぜなら、一般的な公式では不可能であると誤って主張されてしまうからです。 

変数`x`は、1 回の安全な前進で輸送できるヤギとオオカミのペアの最大数を表します。 各ペアは 2 つのボート スロットを占有するため、次のように計算します。`n // 2`。 

いつ`x == 0`、ボートの定員は`1`、これでは明らかに安全なペアを輸送できません。 

いつ`x == 1`、ボートは一度に1足しか運ぶことができません。 往復のたびにそのペアを戻さなければならないため、以前のタスクによってタスク全体がすでに解決されていない限り、永続的な進歩は不可能です。`n >= 2m`状態。 

完了したサイクルの数には、上限を慎重に分割する必要があります。 各サイクルの後、永久的に配置されます`x - 1`右岸のペア。 残りのペア数が最大になるまで続行します`x`、それらは最後の片道旅行で移動できるためです。 

数学的には、最小の整数が必要です`k`次のような:$m - k(x-1) \le x$並べ替えると次のようになります。$k \ge \frac{m-x}{x-1}$コードはこの値の上限を実装します。 

最後に、各サイクルには 2 回の横断費用がかかり、最終的な輸送には 1 回の費用がかかります。

import sys
import io

def solve():
    input = sys.stdin.readline

    m, n = map(int, input().split())

    if n >= 2 * m:
        print(1)
        return

    x = n // 2

    if x == 0:
        print(-1)
        return

    if x == 1:
        print(-1)
        return

    full_cycles = (m - x + (x - 2)) // (x - 1)

    answer = full_cycles * 2 + 1

    print(answer)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# minimum impossible

# everything fits immediately

# classical workable small case
assert run("2 4\n") == "1\n", "all animals fit"

 ## 特殊なケース

 次のことを考慮してください。```
1 1
```ボートの定員は1匹のみです。 ヤギを運ぶとオオカミは一人になりますが、そうすると船は安全に戻れなくなります。 オオカミを輸送すると、最初に 1 頭のオオカミと 1 頭のヤギが元の堤防に残り、まだ安全ですが、最終的にはヤギは単独で移動しなければならず、脆弱になります。 次の理由により、アルゴリズムはこれを即座に検出します。$x = \left\lfloor \frac{1}{2} \right\rfloor = 0$そして戻ってきます`-1`。 

次に、次のことを考えてみましょう。```
2 2
```ここ：$x = 1$1 つのペアは前進できますが、ボートが動作を続けるためには同じペアが戻らなければなりません。 Net transferred pairs remain zero forever. アルゴリズムは正しく返します`-1`。 

最後に次のことを考慮してください。```
3 6
```ボートは 6 匹すべての動物を同時に運ぶことができます。 荷降ろしは同時に行われるため、両方のバンクは常に安全な状態を保ちます。 アルゴリズムはこれを条件で捕捉します。$n \ge 2m$そして出力`1`。
