 ## 解決策
 ## 問題の理解

 コンテストの問題スコアを表す整数のリストが与えられます。 出場者はこれらの問題の空でないサブセットを解くことができ、最終スコアは選択されたすべての値の積になります。 

タスクは、最大積自体を計算することではなく、積ができるだけ大きい 1 つのサブセットを出力することです。 

制約は非常に小さいです。 数値は最大 100 個あり、それぞれは -100 ～ 100 の間です。制限は小さいとはいえ、サブセットの数は依然として指数関数的です。 ブルートフォース検索では、すべてをチェックする必要があります。$2^n - 1$空ではないサブセット。 と$n = 100$、それはまったく不可能です。 

この問題の難しい部分は、負の数とゼロを正しく処理することです。 ゼロより大きい正の数を乗算すると積が増加するため、常に正の値が役に立ちます。 負の値はより微妙です。 負の数が偶数の場合は正の積が生成され、奇数の場合は負の積が生成されます。 

いくつかの特殊なケースでは、不注意なソリューションが簡単に壊れてしまいます。 

すべての数値が負であり、その数が奇数であると仮定します。 

入力：```
3
-1 -2 -3
```すべての数字を選択すると、$(-1) \cdot (-2) \cdot (-3) = -6$。 

でも選ぶだけ`-2 -3`与える`6`、それよりも大きいです。 

正解は、絶対値が最小の負の数を削除します。ここでは`-1`。 

ここで、負の数が 1 つとゼロだけの場合を考えてみましょう。 

入力：```
4
-5 0 0 0
```選択する`-5`与える`-5`。 

任意の 0 を 1 つ選択すると、`0`、それよりも大きいです。 

常にゼロ以外の値を維持する貪欲なアプローチは、ここでは失敗します。 

もう 1 つの危険な状況は、すべての値がゼロの場合です。 

入力：```
3
0 0 0
```それでも少なくとも 1 つの数値を出力する必要があります。 

考えられる最高の製品は、`0`したがって、単一のゼロを出力するのは正しいことです。 

最小の有効な入力も重要です。 

入力：```
1
-7
```製品がマイナスであっても、利用可能な唯一の数を取得する必要があります。 

## アプローチ

 ブルートフォースの解決策は簡単です。 空ではないすべてのサブセットを反復処理し、その積を計算し、最大の結果を持つサブセットを保持します。 

これが機能するのは、スコアの定義がサブセットに直接依存しているためです。 すべての候補者は独立して評価できます。 

問題はサブセットの数です。 と$n = 100$、合計はおおよそになります$1.27 \times 10^{30}$。 1 秒あたり 10 億個のサブセットをチェックしても、宇宙の存続期間内には完了しません。 

重要な観察は、乗算が符号に対して非常に予測どおりに動作するということです。 

正の数値は常に役に立ちます。 1 より大きい正の数を掛けると積が増加します。 1 を掛けると積は変わりませんが、それでも問題はありません。 

負の数値はペアでのみ使用できます。 2 つのマイナスがプラスの寄与を生み出します。 マイナスの数が奇数の場合は、ちょうど 1 つのマイナスを破棄する必要があります。 損失の大きさをできるだけ小さくするには、ゼロに最も近い負の値を破棄する必要があります。 

ゼロはポジティブな製品を改善することはありません。 それらの唯一の目的は、達成可能なすべての非ゼロ積がマイナスになる状況を救済することです。 

これにより、問題は単純な貪欲な選択プロセスに変わります。 

私たちは以下を保持します:

 1. すべての正の数。 
2. 1 を除くすべての負の数。 
3. 負の値が奇数の場合は、絶対値が最小になる負の値を削除します。 
4. 何も残っていない場合は、利用可能な場合は 1 つのゼロを出力し、そうでない場合は負の数値のみを出力します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^n \cdot n)$|$O(n)$| 遅すぎる |
 | 最適 |$O(n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての数値を読み取り、正、負、ゼロに分けます。 

これにより、乗算時に各カテゴリが異なる動作をするため、後の決定が非常に簡単になります。 
2. すべての正の数値を答えに加算します。 

正の値は、生成に役立つか、少なくとも生成を減少させません。 
3. 負の数値を絶対値で並べ替えます。 

ゼロに最も近い負は、負を破棄する必要がある場合に最も役に立ちません。 
4. 負の数が偶数の場合は、すべての負の数を答えに加算します。 

彼らの積はプラスになります。 
5. 負の数が奇数の場合は、負の数を 1 つだけ、特に絶対値が最小のものを破棄し、残りを追加します。 

他のネガを削除すると、最終的な大きさがさらに大幅に減少します。 
6. 答えがまだ空の場合は、特殊なケースに対処します。 

ゼロが存在する場合は、ゼロを 1 つ出力します。$0$はどの負の積よりも大きいです。 

それ以外の場合は、配列全体に負の数が 1 つだけ存在するため、それを出力します。 
7. 選択した番号を印刷します。 

### なぜ効果があるのか

 アルゴリズムは、最初に符号を最大化し、次に大きさを最大化します。 

正の積は常にゼロよりも優れており、ゼロは常に負の積よりも優れています。 プラスの商品は絶対値が大きいほど良い。 

正の数値を乗算しても積が減少することはないため、すべての正の数値を含める必要があります。 負の数はペアでのみプラスに寄与するため、奇数の場合は 1 つの除去が強制されます。 ゼロに最も近い負の値を削除すると、残りの積の可能な最大の絶対値が保存されます。 

正の積が形成できない場合は、可能な限りゼロを選択するのが最適です。 配列に負の値が 1 つ含まれ、ゼロが含まれていない場合にのみ、負の値を出力することが強制されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    positives = []
    negatives = []
    zeros = []

    for x in a:
        if x > 0:
            positives.append(x)
        elif x < 0:
            negatives.append(x)
        else:
            zeros.append(x)

    negatives.sort(key=abs)

    ans = []

    ans.extend(positives)

    if len(negatives) % 2 == 0:
        ans.extend(negatives)
    else:
        ans.extend(negatives[1:])

    if not ans:
        if zeros:
            ans.append(0)
        else:
            ans.append(negatives[0])

    print(*ans)

solve()
```正、負、ゼロには異なる処理戦略が必要となるため、解決策は数​​値を 3 つのグループに分けることから始まります。 

マイナスは数値ではなく絶対値でソートされます。 この詳細が重要です。 最小の数値ではなく、ゼロに最も近い負の値を削除したいと考えています。 たとえば、`-100`そして`-1`、削除`-1`はるかに優れています。 

行:```
ans.extend(negatives[1:])
```負の値は絶対値で並べ替えられるため、機能します。 最初の要素は最も役に立たない負の要素であるため、これをスキップすると、最適な偶数サイズのセットが残ります。 

最後の特殊ケース ブロックは必須です。 これがないと、次のような入力になります。```
3
0 0 0
```空の出力が生成されますが、少なくとも 1 つの問題を解決する必要があるため、これは無効です。 

Python の整数は大きな積を自動的に処理するため、オーバーフローは心配ありません。

    backup = sys.stdout

 ## 特殊なケース

 次の入力を考えてみましょう。```
3
-1 -2 -3
```絶対値でソートされた負の値は次のようになります。```
[-1, -2, -3]
```マイナスが 3 つあるため、カウントは奇数になります。 アルゴリズムは以下を削除します`-1`絶対値が最小になるからです。 残りの製品は次のようになります。```
(-2) * (-3) = 6
```それ以外の除去を行うと、より小さな生成物が生成されます。 

次に、次のことを考えてみましょう。```
4
-5 0 0 0
```アルゴリズムは最初に次のものを削除します`-5`それは唯一の負であり、カウントが奇数であるためです。 答えは空になります。 ゼロが存在するため、アルゴリズムは次のように出力します。`0`。 

これは次の理由から正しいです。```
0 > -5
```最後に、すべてゼロの場合を調べます。```
3
0 0 0
```ポジティブまたはネガティブは選択されません。 特殊な場合の処理​​によって 1 つのゼロが追加されるまで、答えは空のままです。 

このステップを行わないと、プログラムは誤って何も出力せず、少なくとも 1 つの問題を選択する必要があるという要件に違反します。
