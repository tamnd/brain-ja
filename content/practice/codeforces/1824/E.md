 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、`n`頂点。各頂点には 2 つの属性があります。`a_i`そして`b_i`。 各エッジには 2 つの属性もあります。`c_j`そして`d_j`。 タスクは新しいツリーを構築することです`T'`元のツリーの頂点とエッジのサブセットから、コスト式が次のようになります。`min(A, C) * (B + D)`最大化されます。 ここ、`A`最小です`a_i`選択した頂点の間で、`B`選択されたものの合計です`b_i`価値観、`C`最小です`c_j`選択されたエッジの間、および`D`選択されたものの合計です`d_j`価値観。 

課題は選択にあります。任意の数の頂点を自由に選択できます。`p`そしてまさに`p-1`ただし、エッジは元のツリー内のパスに対応している必要があります。 目標は、頂点とエッジの最小属性とそれぞれの他の属性の合計の積ができるだけ大きくなるように頂点とエッジを選択することです。 

制約により許可されるのは、`n`まで`2 * 10^5`。 これにより、すべての頂点サブセットまたはエッジ サブセットを反復するソリューションは除外されます。これは、単一レベルの組み合わせ反復でも 2 秒の制限で実行可能な操作を超えるためです。 単純な O(n²) アプローチは境界線に達する可能性がありますが、O(n³) 以上のものは直ちに実行不可能です。 明らかではないエッジ ケースには、すべてが存在するツリーが含まれます。`a_i`またはすべて`c_j`最小値が乗算を支配するため、1 つの小さな値を除いては大きくなります。 不用意に実装すると、重要な最小値を満たさずに高額な金額が選択され、コストが低下する可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、すべての頂点サブセットを反復処理し、どのエッジがそれらを接続できるかを判断し、計算します。`A`、`B`、`C`、`D`候補ツリーごとに を計算し、最大コストを計算します。 と`n`まで`2 * 10^5`、頂点サブセットの数は指数関数的であるため、これは実行不可能です。 すべてのサブセットのすべてのエッジを反復処理しても O(2^n * n) となり、これは許容範囲をはるかに超えています。 

重要な洞察は、ツリー構造により、ソートおよび選択戦略を組み合わせたツリー上の動的プログラミングに問題を帰着させることができるということを認識することです。 サブツリーまたは頂点サブセットの最小頂点値`A`はそのサブセット内の頂点の最小値であり、その合計は`B`それらの合計です`b_i`。 同様に、パスに沿ったエッジの最小値は、`C`最小のエッジです`c_j`パスの中で、そして`D`の合計です`d_j`。 

各エッジを潜在的なボトルネックとして考慮することで、問題を変換できます。`C`。 与えられたエッジに対して、`c_j`を最大化する方法で、このエッジを介して接続されているすべての頂点を取ることを検討できます。`B + D`確保しながら`min(A, C) = min(vertex minimum, edge minimum)`できるだけ大きいです。 エッジを降順に反復することにより、`c_j`、私たちはそれを保証します`C`以降の選択では減少することはなく、接続成分を効率的に考慮するだけで済みます。 これは、各コンポーネントがその合計を追跡する Union-Find (素セット) データ構造で管理できます。`B`そして最低限の`A`。 各マージはエッジの追加に対応します`D`そして更新`B`そして`A`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n) | O(n²) | 遅すぎる |
 | 最適 (DSU + ソート) | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力ツリーの頂点とエッジを解析し、保存します。`a_i`、`b_i`頂点と`(x_j, y_j, c_j, d_j)`エッジ用。 
2. 各頂点が独自のコンポーネントである素集合 (union-find) 構造を初期化し、各コンポーネントの合計を格納します。`b_i`そして最小限の`a_i`。 
3. すべてのエッジを降順に並べ替えます。`c_j`に含まれる最小エッジ値を最大化したいためです。`T'`。 
4. 変数を初期化する`ans`これまでに確認された最大コストを追跡します。 
5. ソートされた順序でエッジを反復処理します。 

1. 現在のエッジの場合`(x, y, c, d)`を含むコンポーネントのルートを見つけます。`x`そして`y`。 
2. すでに接続されている場合は、このエッジをスキップします。 
3. それ以外の場合は、2 つのコンポーネントをマージします。 

- 新しいコンポーネントの最小頂点値を更新します。`A`両方の成分の最小値として`A`。 
- 合計を更新します`B`両方の成分の合計として`B`プラスエッジの`d`。 
4. このコンポーネントのコストを次のように計算します。`min(A, c) * B`。 
5.アップデート`ans`このコストが高ければ。 
6. 出力`ans`。 

機能する理由: 各ステップで、残っている最も高いエッジを考慮します。`c_j`コンポーネントをマージして合計を最大化します`B + D`保ちながら`C`高い。 並べ替えにより次のことが保証されます`C`後のマージでは決して減少することはなく、union-find 構造により、コンポーネントがサイクルを形成することなく正しくマージされることが保証されます。 可能な限りの`T'`より高いコストを与える可能性があるものはマージを通じて考慮されるため、最終的に最大コストが取得されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

class DSU:
    def __init__(self, n, a, b):
        self.p = list(range(n))
        self.min_a = a[:]
        self.sum_b = b[:]

    def find(self, x):
        if self.p[x] != x:
            self.p[x] = self.find(self.p[x])
        return self.p[x]

    def union(self, x, y, d, c):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return None
        new_min_a = min(self.min_a[x_root], self.min_a[y_root])
        new_sum_b = self.sum_b[x_root] + self.sum_b[y_root] + d
        self.p[y_root] = x_root
        self.min_a[x_root] = new_min_a
        self.sum_b[x_root] = new_sum_b
        return new_min_a, new_sum_b

def main():
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    edges = []
    for _ in range(n - 1):
        x, y, c, d = map(int, input().split())
        edges.append((c, x - 1, y - 1, d))

    edges.sort(reverse=True)
    dsu = DSU(n, a, b)
    ans = 0
    for c, x, y, d in edges:
        res = dsu.union(x, y, d, c)
        if res:
            min_a, sum_b = res
            ans = max(ans, min(min_a, c) * sum_b)
    print(ans)

if __name__ == "__main__":
    main()
```DSU クラスは、両方の最小値を維持します。`a`そして合計`b`接続されたコンポーネントごとに。 の`union`関数はコンポーネントをマージし、更新された値を返します。 エッジを降順に並べ替えることで、常に最大の可能性を考慮することが保証されます。`C`初め。 結果はエッジがマージされるにつれて段階的に計算され、最大コストが確実に見つかります。
