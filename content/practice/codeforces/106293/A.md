算術平均は単純に$(a+b+c)/3$。 中央値は、3 つの数値を降順でない順に並べ替えた後の中央の値です。 したがって、どのような選択をしても、$c$、トリプルの順序によって中央値が変更され、条件が区分的になり、方法に依存します。$c$と比較する$a$そして$b$。

中央値が固定されていないという事実から、微妙な困難が生じます。 たとえば、次の場合$a = 1$、$b = 10$、 そして$c = 5$の場合、中央値は次のようになります。$5$、しかし、もし$c = 100$、中央値は次のようになります$10$。 条件は、可能な 3 つの位置のどれに応じて構造を変更します。$c$ソート順に並んでいます。

 ## アルゴリズムのチュートリアル

 まず、2 つの固定値の間で適切な順序を確保することから始めます。 

1. 次のように入力を並べ替えます。$a \le b$。 これにより対称性が取り除かれ、以降のすべての相対位置に関する推論が保証されます。$c$一貫しています。 
2. 最初の構造的なケースを考えてみましょう。$c \le a \le b$。 この状況では、ソートされたトリプルは次のようになります。$(c, a, b)$したがって、中央値は次のようになります。$a$。 不平等はこうなる$(c + a + b)/3 \le a$、これを単純化すると、$c + b \le 2a$。 以来$b \ge a$、これはすぐに制限されます$c \le a$。 したがって、この領域で実現可能な最大値は次のようになります。$c = a$。 
3. 2 番目のケースを考えてみましょう。$a \le c \le b$。 ソートされたトリプルは次のようになります$(a, c, b)$したがって、中央値は次のようになります。$c$。 条件はこうなります$a + b + c \le 3c$、これを単純化すると、$a + b \le 2c$、 または$c \ge (a+b)/2$。 最大化したいので$c$この間隔に留まりながら、私たちは試みます$c = b$。 代入すると、$a + b \le 2b$、これは常に成り立ちます。$b \ge a$。 したがって、この領域で実現可能な最大値は次のようになります。$c = b$。 
4. 3 番目のケースを考えてみましょう。$a \le b \le c$。 ソートされたトリプルは次のようになります$(a, b, c)$したがって、中央値は次のようになります。$b$。 不平等はこうなる$a + b + c \le 3b$、これを単純化すると、$a + c \le 2b$、上限を与える$c \le 2b - a$。 私たちは地域にいるので$c \ge b$、可能な限り最良の選択は$c = 2b - a$。 
5. 最後に、すべてのケースの候補を比較します。 最初のケースの最良のものは、$a$、2番目からは$b$、3つ目からは$2b-a$。 以来$b \ge a$、最初のケースは決して最適ではありません。 また、$2b-a \ge b$, したがって、3 番目のケースが 2 番目のケースを支配します。 したがって、最終的な答えは、$c = 2b - a$。 
6. 当初の注文に$a > b$、対称性は与える$c = 2a - b$。 両方の方向を組み合わせると、答えは次のようになります。$2\max(a,b) - \min(a,b)$。 

### なぜ効果があるのか

 中央値制約は順序のみに依存し、要素が 3 つある場合、可能な順序構成は 3 つだけです。 各構成内では、不等式は次のように線形になります。$c$、単一の上限または下限を生成します。 最適解はこれらの領域のいずれかの境界にある必要があり、これらの境界を比較することで、順序間の遷移を見逃すことなくすべての可能性が網羅されます。
