 ## 解決策
 ## 問題の理解

 私たちは次のことに取り組んでいます$n \times n$セルを値でグループ化する場合、各セルがちょうど 1 つの対角線に属するグリッド$i + j$。 このような値はすべて、正方形のどこに位置するかに応じて、上端から右端または下端に向かう対角線を定義します。 

私たちは与えられています$k$同一のチップを使用し、それらすべてを異なるセルに配置する必要があります。 少なくとも 1 つのチップがそれに属するセルに着地すると、対角線は「アクティブ」になります。 目標は、アクティブな対角線の数ができるだけ少なくなるようにすべてのチップを配置することです。 

構造からわかる重要な点は、対角線に含まれるセルの数が異なるということです。 コーナー近くのいくつかの対角線にはセルが 1 つだけ含まれていますが、中央の対角線はそれよりもはるかに長く、多くのチップを収容できます。 問題は基本的に梱包方法を尋ねることです$k$各グループの容量がその対角線の長さによって決まることを考慮して、項目をグループ (対角線) に分けて、使用するグループをできるだけ少なくします。 

制約は小さいです。$n \le 100$したがって、各テスト ケースは、ケースごとの定数または線形を超える効率を気にすることなく、独立して推論できます。 すべての対角線にわたる直接シミュレーションでも許容されますが、構造により直接式が可能になります。 

エッジケースは次の場合に発生します。$k = 0$、対角線が占有されていない場合、および$k = n^2$、すべてのセルが埋められ、すべての対角線が占有されます。 微妙なケースとしては、$k$小さい: 貪欲な直感は、常に最長の対角線を最初に埋めることを示唆するかもしれませんが、最適な戦略は、カバーするために必要な対角線の数によってのみ決まります。$k$、実際の配置の詳細ではありません。 

## アプローチ

 直接的な総当たりアプローチでは、チップを 1 つずつ配置し、どの対角線がすでに使用されているかを維持しようとします。 各ステップで、考えられるすべての空のセルを試し、チップの配置をシミュレートし、アクティブになる個別の対角線の数を追跡します。 各配置が最大で分岐するため、これはすぐに指数関数的になります。$n^2$選択肢と、選択する方法の数$k$セルは組み合わせです。 枝刈りを行ったとしても、このアプローチは爆発的に効果を発揮します$n = 100$。 

重要な構造的洞察は、対角線が既知の容量を持つ独立したバケットであるという事実を除けば、グリッドの正確な形状は重要ではないということです。 各対角線は固定数のセルに対応し、同じ対角線内に複数のチップを配置しても、「占有対角線」は 1 つだけかかります。 したがって、占有される対角を最小限に抑えるために、新しい対角を使用する前に、できるだけ高密度に対角を埋めたいと考えています。 

対角線を容量 (各対角線のセルの数) で降順に並べ替えると、最適な戦略は貪欲になります。最初に最大の対角線を取得し、すべての対角線が配置されるまで完全に埋めていきます。$k$チップス。 このプロセスで使用される対角線の数が答えです。 

斜めの構造なので、$n \times n$グリッドが固定されているため、対角線のサイズのリストを 1 回につき 1 回事前計算できます。$n$から貪欲に減算します。$k$。

 ## アルゴリズムのチュートリアル

 1. 対角線の数を計算します。$n \times n$グリッド。 がある$2n - 1$の値によって形成される対角線$i + j$。 これにより、チップを割り当てる構造が得られます。 
2. 各対角線のサイズを計算します。 斜めインデックス用$d$、そのサイズは 1 から まで増加します。$n$、その後、対称的に減少して 1 に戻ります。これは、満たすセルの数を反映します。$i + j = d$。 
3. これらの対角サイズを降順に並べ替えます。 直感的には、より大きな対角線を使用すると、同じ数のチップを格納するのに必要な対角線の数が減ります。 
4. ソートされた対角サイズを繰り返し処理します。 各対角線について、その容量を次から引きます。$k$、使用済みとしてカウントします。 一度止めてください$k \le 0$。 
5. 使用された対角線の数を返します。 

### なぜ効果があるのか

 各対角線は容量が固定された独立したコンテナであり、その内部のどのセルを使用しても、占有対角線の数としては同じようにカウントされます。 したがって、占有される対角線を最小限に抑えることは、カバーするために必要なコンテナの数を最小限に抑えることになります。$k$容量の単位。 選択した対角線をより小さい対角線に置き換えても、同じ合計容量に達するのに必要な対角線の数が増えるだけであるため、常に利用可能な最大のコンテナを最初に使用するという貪欲な戦略が最適です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_diagonals(n):
    sizes = []
    # i + j ranges from 2 to 2n
    for s in range(2, 2 * n + 1):
        cnt = 0
        for i in range(1, n + 1):
            j = s - i
            if 1 <= j <= n:
                cnt += 1
        sizes.append(cnt)
    sizes.sort(reverse=True)
    return sizes

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    
    if k == 0:
        print(0)
        continue

    diag = build_diagonals(n)

    used = 0
    for c in diag:
        if k <= 0:
            break
        k -= c
        used += 1

    print(used)
```コードはまず、可能な合計をスキャンしてすべての対角線の長さを構築します。$i + j$。 合計ごとに、有効なグリッド位置がカウントされ、その対角線のサイズがわかります。 これらのサイズを降順に並べ替えた後、貪欲に減算します。$k$、各減算はその対角線を完全に占めることを表します。 

早期の退出は、$k = 0$不必要な計算を回避します。 十分な容量が蓄積されるとすぐにループは停止します。 

微妙な点は、テストごとに対角線を再計算しても十分高速であるということです。$n \le 100$、したがって、建設コストは制限されており、小さいです。

 ## 特殊なケース

 最小限のケースとしては、$n = 1, k = 0$。 グリッドには単一の対角線がありますが、チップがないということは、占有された対角線がないことを意味します。 アルゴリズムは、定義に一致する構造を構築する前に、すぐに 0 を返します。 

のために$n = 2, k = 1$、対角線のサイズは$[2,2,1]$。 貪欲ループは最初の対角線を取得し、それを消費した後に停止し、1 を返します。単一チップの有効な配置はちょうど 1 つの対角線を占有するため、結果は一貫しています。 

のために$k = n^2$、すべてのセルが塗りつぶされるため、すべての対角線を使用する必要があります。 アルゴリズムは、すべての対角容量を降順で消費し、値を返します。$2n-1$、これはまさにグリッドの対角線の数です。
