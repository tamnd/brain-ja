 ## 解決策
 ## 問題の理解

 長方形のグリッド上で単純化されたクィディッチ ゲームをシミュレートするように求められます。 フィールドには 2 つのチームの選手、両チームのゴール、および 1 つのクアッフルが含まれています。 各プレイヤーは 4 つの方向のいずれかに移動し、自分のセル上にクアッフルがある場合はそれを捕まえ、投げることができます。 プレーヤーが相手チームのゴール上でクアッフルを離れるたびにポイントが獲得されます。 プレイヤーが自分のゴールで得点すると、相手チームがポイントを獲得します。 クアッフルは得点するたびにすぐに中央にリセットされます。 ゲームでは一連の動きが提供され、ゴールが発生したときと最終スコアを出力する必要があります。 

入力グリッドは小さく、最大でも 99×99 で、ステップ数は 10,000 に達することがあります。 各アクションは有効であることが保証されているため、無効な動きを処理する必要はありません。 したがって、私たちのタスクは、すべての動きを忠実にシミュレートし、誰がクアッフルを運んでいるか追跡し、ゴールイベントをチェックし、最終スコアとともに正しい順序で出力することです。 

エッジケースには、複数のプレーヤーが同じセルからスタートし、自分のゴールで得点したり、クアッフルがキャッチした直後にゴールに投げ込まれたりすることが含まれます。 単純なシミュレーションでは、各ステップでプレーヤーとボールの位置の両方を注意深く更新する必要があります。 

## アプローチ

 ここでの強引なアプローチは、グリッドと手の数が小さいため実現可能です。 プレイヤー ID からポジションへのマッピングを維持し、クアッフルのポジションとキャリアを追跡し、各アクションを順番に処理できます。 移動アクションの場合、プレイヤーの座標を更新します。 キャッチの場合、クアッフルをキャリーとしてマークします。 投げる場合は、現在のセルに配置します。 各移動の後、クアッフルがゴール上にあるかどうかを確認し、それに応じてスコアを更新します。 このアプローチは正しく、T 移動に O(T) 時間を必要とするという制約を考慮すると十分に高速です。 

得点イベントを決定するにはすべての手を処理する必要があり、制約によってこの直接シミュレーションが可能になるため、これよりも漸近的に高速なアプローチはありません。 主な課題はアルゴリズムの複雑さよりも慎重に記録することであるため、イベントのバッチ処理やパスの事前計算などの時期尚早な最適化は避けます。

 | --- | --- | --- | --- |
 | 直接シミュレーション | O(T) | O(N*M + P) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グリッドを解析し、すべてのプレーヤーとゴールの位置を保存します。 クアッフルの位置とそれが運ばれているかどうかについては別の変数を保持します。 
2. 両チームのスコアをゼロに初期化します。 
3. 0 から T-1 までの各アクションについて、それを実行するエンティティとアクション タイプを抽出します。 移動の場合は、エンティティの座標を更新します。 キャッチの場合は、プレーヤーがクッフルを持っていることをマークし、クッフルのグリッド位置をクリアします。 それが投げの場合は、プレイヤーの現在のセルにクアッフルを置き、もう運ばれていないものとしてマークします。 
4. 各アクションの後、クアッフルがゴールに迫っている場合は、どちらのチームが得点するかを決定します。 ゴールが反対チームのものの場合、プレイヤーのチームがポイントを獲得します。 ゴールが同じチームのものであれば、もう一方のチームがポイントを獲得します。 現在のステップ インデックスを含むイベントを出力します。 
5. 得点後、クアッフルをグリッドの中央にリセットし、キャリーされていないものとしてマークします。 
6. すべてのアクションの後、最終スコアを次の形式で出力します。`FINAL SCORE: r b`。 

機能する理由: このアルゴリズムは、クアッフルがフィールド上にあるのか、プレイヤーによって運ばれているのかという不変条件を維持します。 すべての動きとゴールは時系列に処理されます。 各アクションの直後に位置を更新し、ゴールを確認することで、一連の得点イベントと最終結果を正確に把握します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, M = map(int, input().split())
    grid = []
    players = {}
    goals_red = set()
    goals_blue = set()
    quaffle_pos = None
    quaffle_carrier = None

    for i in range(N):
        row = input().split()
        for j, cell in enumerate(row):
            if cell.startswith('R') and cell[1].isdigit():
                players[cell] = (i, j)
            elif cell.startswith('B') and cell[1].isdigit():
                players[cell] = (i, j)
            elif cell == 'RG':
                goals_red.add((i, j))
            elif cell == 'BG':
                goals_blue.add((i, j))
            elif cell == '.Q':
                quaffle_pos = (i, j)
        grid.append(row)

    T = int(input())
    actions = [input().split() for _ in range(T)]

    score_red = 0
    score_blue = 0

    center = ((N-1)//2, (M-1)//2)

    for t, act in enumerate(actions):
        entity = act[0]
        move = act[1]

        if move in 'UDLR':
            x, y = players[entity]
            if move == 'U':
                x -= 1
            elif move == 'D':
                x += 1
            elif move == 'L':
                y -= 1
            elif move == 'R':
                y += 1
            players[entity] = (x, y)
            if quaffle_carrier == entity:
                quaffle_pos = (x, y)
        elif move == 'C':
            # catching Quaffle
            quaffle_carrier = entity
            quaffle_pos = None
        elif move == 'T':
            # throwing Quaffle
            x, y = players[entity]
            quaffle_pos = (x, y)
            quaffle_carrier = None

        # check for scoring
        if quaffle_pos is not None:
            if quaffle_pos in goals_red:
                if entity[0] == 'R':
                    score_blue += 1
                    print(f"{t} BLUE GOAL")
                else:
                    score_red += 1
                    print(f"{t} RED GOAL")
                quaffle_pos = center
                quaffle_carrier = None
            elif quaffle_pos in goals_blue:
                if entity[0] == 'B':
                    score_red += 1
                    print(f"{t} RED GOAL")
                else:
                    score_blue += 1
                    print(f"{t} BLUE GOAL")
                quaffle_pos = center
                quaffle_carrier = None

    print(f"FINAL SCORE: {score_red} {score_blue}")

solve()
```### 実装のウォークスルー

 プレーヤー用の辞書とゴール用のセットを管理して、簡単に検索できるようにします。 クアッフルは、その位置のタプルとキャリアを追跡する変数によって表されます。 各アクションはポジションやキャリーを適切に更新します。 すべてのアクションの後、クアッフルがゴールに到達したかどうかをすぐに確認します。 ゴール後にクアッフルを中心にリセットすると、その後のアクションでシミュレーションが正しく継続されます。 中心を計算する際のインデックス付けと整数除算を注意深く行うことにより、オフバイワンエラーが回避されます。
