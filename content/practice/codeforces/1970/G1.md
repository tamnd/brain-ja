 ## 解決策
 ## 問題の理解

 入力は、ツリーを形成するコリドーによって接続されたセルの集合を記述します。 各セルはノードであり、各コリドーは無向エッジです。 Because there are exactly$m = n - 1$エッジとグラフが接続されており、構造はツリーです。 

タスクは、ツリーを正確に 2 つの接続されたノード グループに分割することです。 各グループは、そのグループ内のノードのみを使用して内部接続を維持する必要があります。 分割後、2 つのグループ間にコリドーを 1 つだけ追加できます。そのコリドーにはコストがかかります。$c$。 さらに、各グループはそのサイズの 2 乗に等しいコストを貢献します。 2 つのグループにサイズがある場合$x$そして$y$、合計コストは次のようになります。$$x^2 + y^2 + c$$新しいコリドーが常に 1 つだけ必要になるためです。 

唯一の自由は、既存のエッジを 1 つ削除して、ツリーを 2 つの接続されたコンポーネントに分割する方法を選択することです。 そのエッジが削除されると、ツリーは 2 つのサブツリーに分割されます。 

制約が意味するのは、$n$までです$10^5$テストケースごとの合計$n$までも$10^5$、だから、$O(n)$または$O(n \log n)$テストケースごとのソリューションが必要です。 すべてのパーティションを試行したり、サブツリーのプロパティを繰り返し再計算したりすると、遅すぎます。 

微妙な点は、すべての有効なパーティションが 1 つのエッジの削除に正確に対応していることです。 ノードの任意のサブセットを考慮する必要はありません。 接続性により、パーティションは強制的にサブツリーになります。 

もう 1 つのエッジ ケースは、ツリーにノードが 2 つしかない場合です。 次に、唯一のエッジを削除すると 2 つのシングルトン コンポーネントが生成され、それが唯一の有効な分割になります。 どのアプローチでもこれをきれいに処理する必要があります。 

## アプローチ

 ブルートフォース手法では、すべてのエッジを削除し、結果として得られる 2 つのコンポーネントのサイズを再計算します。 エッジ除去ごとに、DFS または BFS を実行してコンポーネントのサイズを計算し、コストを評価します。 このような各トラバースは、$O(n)$、そして、あります$O(n)$エッジ、与える$O(n^2)$テストケースごとに、これは大きすぎます$10^5$ノード。 

重要な観察は、ツリーのエッジを削除すると常に 2 つのサブツリーに分割され、ツリーをルート化した場合、一方の辺のサイズは 1 つの端点をルートとするサブツリーのサイズと正確に一致するということです。 したがって、コンポーネントのサイズを繰り返し再計算する代わりに、DFS を使用してすべてのサブツリーのサイズを 1 回計算します。 

サブツリーのサイズが判明すると、各エッジは、同じサイズのコンポーネントを生成するカットに対応します。$sz$そして$n - sz$。 そのカットにかかるコストは次のようになります。$$sz^2 + (n - sz)^2 + c$$この式をすべてのエッジに対して単純に評価し、最小値を取得します。 

これにより、問題は単一の DFS とエッジ上の線形スキャンに軽減されます。

 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^2)$|$O(n)$| 遅すぎる |
 | DFS + エッジ評価 |$O(n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 任意のノード (通常はノード 1) でツリーをルート化し、隣接リストを構築します。 これにより、サブツリー定義の方向が修正されます。 
2. DFS を実行して、すべてのサブツリーのサイズを計算します。 ノードの場合$u$、サブツリーのサイズは次のとおりです。$$sz[u] = 1 + \sum sz[v]$$子供たち以上に$v$。 これにより、ルート化されたツリー内の各ノードの下にノードがいくつあるかが正確に取得されます。 
3. DFS の実行中、または 2 番目のパスで、各エッジを考慮します。$(u, v)$どこ$v$の子供です$u$。 このエッジを切断すると、サブツリーが分離されます。$v$木の残りの部分から。 
4. このようなエッジごとに、2 つのコンポーネントのサイズを次のように計算します。$sz[v]$そして$n - sz[v]$。 評価する：$$cost = sz[v]^2 + (n - sz[v])^2 + c$$5. すべてのエッジにわたって最小値を追跡します。 
6. テスト ケースのこの最小値を出力します。 

### なぜ効果があるのか

 ツリーを 2 つの接続されたコンポーネントに分割する有効なパーティションはすべて、1 つのエッジを削除することによって一意に定義されます。 ツリーをルート化すると、各エッジが 1 つのサブツリー サイズに正確に対応するようになります。 DFS は、各サブツリー サイズが 1 回だけ計算されることを保証するため、各パーティションは 1 回だけ評価されます。 コスト関数はコンポーネントのサイズのみに依存し、追加されるエッジのコストは一定であるため、すべてのエッジにわたる最小化により、考えられるすべての有効なソリューションがカバーされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    n, m, c = map(int, input().split())
    g = [[] for _ in range(n + 1)]
    edges = []

    for _ in range(n - 1):
        u, v = map(int, input().split())
        g[u].append(v)
        g[v].append(u)
        edges.append((u, v))

    parent = [0] * (n + 1)
    sz = [0] * (n + 1)
    order = []

    stack = [1]
    parent[1] = -1

    while stack:
        u = stack.pop()
        order.append(u)
        for v in g[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            stack.append(v)

    for u in reversed(order):
        sz[u] = 1
        for v in g[u]:
            if v == parent[u]:
                continue
            sz[u] += sz[v]

    ans = float('inf')

    for u, v in edges:
        if parent[u] == v:
            s = sz[u]
        else:
            s = sz[v]

        ans = min(ans, s * s + (n - s) * (n - s) + c)

    print(ans)

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```このソリューションでは、最初にツリーを構築し、次に反復 DFS を使用して親配列を構築して、再帰の深さの問題を回避します。 サブツリーのサイズは DFS の逆順で計算されるため、子は親の前に処理されます。 

各エッジは、ルート化されたツリー内のどのエンドポイントが子であるかを決定することによって 1 回だけ評価されます。 そのエンドポイントはサブツリーのサイズを直接定義します。 

よくある落とし穴は、再帰制限を増やさずに再帰的 DFS を使用することであり、長いチェーンでは失敗する可能性があります。 もう 1 つは、方向をチェックせずに任意のエンドポイントの減算ではなく、子側のサブツリー サイズのみが有効であることを忘れていることです。

 ## 特殊なケース

 重大なエッジ ケースは、ツリーが単純なパスである場合です。 その場合、エッジごとに異なる分割サイズが生成され、最適なカットは中心近くになる傾向があります。 各ノードにはルート方向の子が 1 つだけあるため、DFS ベースのサブツリー計算でも正しいサイズが割り当てられます。 

もう一つのケースは星型の木です。 中心でルートすると、サブツリー サイズ 1 の子が多数生成されます。すべてのカットで同じ分割構造が生成されます。$(1, n-1)$、アルゴリズムは同じコストを問題なく繰り返し正しく評価します。 

のために$n=2$の場合、DFS は 1 つのサブツリー サイズ 1 を割り当て、唯一のエッジから唯一の有効なパーティションが生成されます。 この公式は引き続き直接適用され、正しい最小値が生成されます。
