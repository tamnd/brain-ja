 ## 解決策
 ## 問題の理解

 配置を求められます$n$ウィザードハウス$n \times n$各魔法使いが所定のマンハッタン距離で別の魔法使いの家に到達できるようなグリッド$a_i$、同じ柱を共有する 2 つの家はありません。 この中バージョンのひねりは、$a_1 = 0$、つまり、最初の魔法使いは自分たちからの距離が 0 のところに家がなければなりません。 

入力は整数で構成されます$n$そして配列$a$長さの$n$と$0 \le a_i \le n$。 出力は、配置が存在しない場合は NO、またはその後に YES が続きます。$n$家の座標と、各ウィザードが必要な距離でどのウィザードを訪問できるかを示す配列。 複数の正しい配置が許可されます。 

なぜなら$n$到達できる$2 \cdot 10^5$制限時間は 2 秒、アルゴリズムは以下より悪い$O(n \log n)$遅すぎる可能性があります。 考えられる座標のペアをすべて試行する素朴なアプローチ。$O(n^2)$、タイムアウトになります。 主な困難は、列の一意性制約を維持しながらマンハッタンの距離要件を満たすことにあります。 

エッジケースには些細な配置も含まれます$a_i = 0$みんなのために$i$、すべてのウィザードが「自分自身を訪問する」ことのみを強制されます。$a_i = n$、可能な限り最大の距離が必要です。 距離がグリッドに沿ったジグザグ パターンを必要とする場合、対角線に沿った素朴な貪欲な配置は失敗する可能性があるため、アルゴリズムは線形パターンが機能すると仮定するのではなく、体系的に距離を考慮する必要があります。 

## アプローチ

 ブルートフォースアプローチは、すべてを列挙することです。$n!$個別の列に家の配置の可能性を確認し、それぞれについてウィザードが必要な距離でターゲットを見つけられるかどうかを確認します。 これは、最初の条件 (列の重なりがない) により可能な配置が減少するため機能しますが、階乗増加により、大規模な場合にはこれが完全に不可能になります。$n$。 

重要な観察は、2 点間のマンハッタン距離$(x_i, y_i)$そして$(x_j, y_j)$次のように書くことができます$|x_i - x_j| + |y_i - y_j|$。 すべての x 座標は個別である必要があるため、x 座標を任意に (たとえば、1 から n まで) 固定し、y 座標に焦点を当てることができます。 最初のウィザードからの必要な距離でウィザードを並べ替えると、建設的な配置が可能になります。最初のウィザードを任意に配置し、最初のウィザードからのマンハッタン距離が等しい位置にウィザードを配置できます。$a_i$。 複数のウィザードが同じ距離を共有する場合、列の一意性を維持するために、ウィザードを対角線または反対角線に沿って配置できます。 問題は、グリッドをすべての距離に対応できる 2 つの対角線に分割することに帰着します。 これにより複雑さが軽減され、$O(n)$座標を計算して距離を確認するのは一度だけだからです。

 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | 建設的な斜めの配置 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最初のウィザードに固定位置を割り当てます。例:$(1, 1)$。 なぜなら$a_1 = 0$、距離要件を自動的に満たします。 
2. 残りのウィザードを 2 つのグループに分割します。最初のウィザードからの距離が x の増加と y の減少 (一方の対角線に沿って移動) で表されるウィザードと、もう一方の対角線に沿って移動するウィザードです。 これにより、列の一意性が保証されます。 
3. 対角線に沿ってポインタを初期化します。 ウィザードごとに$i$、座標に配置します。$(x, y)$そのような$|x - 1| + |y - 1| = a_i$。 これは、2 から n までの可能な x 値を反復処理し、それに応じて y を計算することで実行できます。 
4. 各ウィザードの「訪問」配列を埋めることができるように、どのウィザードがどの距離に割り当てられているかを追跡します。 複数の位置が距離を満たす場合は、最初に使用可能な位置を選択します。 
5. すべてのウィザードを配置した後、すべての X 座標が異なることを確認します。 矛盾が生じた場合は NO を出力します。 それ以外の場合は、座標および訪問配列とともに YES を出力します。 

機能する理由: 最初のウィザードの位置が固定され、後続のすべてのウィザードが列の衝突を避けながらマンハッタンの距離を維持するパスに沿って配置されるという不変条件が維持されます。 グリッドには$n$列とすべてのウィザードには個別の X 座標が割り当てられ、一意性が保証されます。 斜めに配置することで合計が確実に得られます。$|x - x_1| + |y - y_1|$それぞれに一致します$a_i$その通り。 この建設的なアプローチにより、後戻りや推測が回避され、線形時間のソリューションが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    if a[0] != 0:
        print("NO")
        return
    
    positions = [(1, 1)]
    used_cols = {1}
    # Two pointers for filling diagonals
    x_up, y_up = 2, 1
    x_down, y_down = 1, 2
    visit = [1]  # 1-based indexing
    
    for i in range(1, n):
        d = a[i]
        # Try first diagonal (increasing x, decreasing y)
        if x_up <= n and 1 <= d - (x_up - 1) + 1 <= n and (d - (x_up - 1) + 1) not in used_cols:
            y = d - (x_up - 1) + 1
            positions.append((x_up, y))
            used_cols.add(x_up)
            x_up += 1
            visit.append(1)
        # Otherwise, second diagonal (decreasing x, increasing y)
        elif y_down <= n and 1 <= d - (y_down - 1) + 1 <= n and (d - (y_down - 1) + 1) not in used_cols:
            x = d - (y_down - 1) + 1
            positions.append((x, y_down))
            used_cols.add(x)
            y_down += 1
            visit.append(1)
        else:
            print("NO")
            return
    
    print("YES")
    for x, y in positions:
        print(x, y)
    print(" ".join(map(str, visit)))

if __name__ == "__main__":
    solve()
```この解決策では、まず最初のウィザードの位置を修正します。 列の衝突なしに後続の家を広げるために、2 つの対角戦略が実装されています。 各割り当ては使用可能な列に対して検証され、配置できない列がある場合、アルゴリズムは NO で早期に停止します。
