 ## 解決策
 ## 問題の理解

 このタスクは、バランスのとれた括弧文字列に対する、いわゆるバランスのとれたシャッフル操作を反転することです。 文字列が与えられます`s`バランスが保証されている括弧の数。 この文字列は、他のバランスの取れた括弧文字列を取得することによって生成されました。`t`、すべての位置で接頭辞のバランスを計算し、増加する接頭辞のバランスに基づいて文字を並べ替え、位置を減らすことで結合を解除します。 あなたの目標は再建することです`t`から`s`。 

入力は最大 1000 の長さの単一の文字列であり、文字列の長さがほぼ線形または二次であるアルゴリズムが可能になります。 問題は完全に建設的かつ決定論的であるため、固有の事前イメージが存在します。`t`それぞれに`s`、そして解はまさにこのシーケンスを見つける必要があります。 エッジケースには、次のような非常に短い文字列が含まれます。`"()"`または、すべての開き括弧が先頭でグループ化されている文字列。例:`"((()))"`これにより、プレフィックスバランスの計算におけるオフバイワンエラーが明らかになる可能性があります。 

括弧のすべての並べ替えを試すような単純なアプローチは実行不可能です。 長さが 1000 であっても、階乗時間は天文学的に大きくなります。 もう 1 つの微妙なエッジ ケースは、複数の位置のプレフィックス バランスが同じである文字列です。 順位を下げることによるタイブレーク ルールは正しく逆転する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、同じ長さのバランスの取れた括弧シーケンスをすべて生成しようとします。`s`、バランスのとれたシャッフルを計算し、どれが一致するかを確認します`s`。 これは正しいですが、バランスのとれた括弧シーケンスの数は長さ (カタロニア語) とともに指数関数的に増加するため、完全に非現実的です。 長さ 1000 の場合、これは不可能です。 

重要な洞察は、バランス シャッフルではプレフィックスのバランスによって文字が並べ替えられるということです。 これを逆にするには、次の位置を再構築できます。`t`のどの位置に対応しますか`s`。 具体的には、シャッフルで使用されるプレフィックスバランスのソート順序をシミュレートします。 同じプレフィックスバランスを持つ位置は元のインデックスの降順で順序付けされるため、これを反転することは文字をグループ化することと同じです。`s`バランスの取れた括弧ツリー内の深さによって、位置の昇順で書き戻されます。 これにより、スタックを使用して開き括弧を正しい深さに割り当てるリニア スキャンに問題が軽減されます。 

このアプローチは、入力の長さが最大 ​​1000 であるため、O(n) または O(n log n) アルゴリズムが十分に高速であるため、実現可能です。

 ## アルゴリズムのチュートリアル

 1. 入力文字列内の各プレフィックスのバランスを計算します。`s`。 残高は 0 から始まり、1 ずつ増加します。`"("`そして1ずつ減少します`")"`。 
2. 各文字の位置とバランスに注意してください。 
3. バランス シャッフルでは、キャラクターはバランス (増加) と位置 (減少) によってソートされます。 反転するには、各バランスに対応する元の位置のシーケンスを再構築する必要があります。 
4. スタックを使用して元の文字列を再構築する`t`。 トラバース`s`そしてそれぞれについて`"("`、それをスタックにプッシュします。 それぞれについて`")"`、スタックから取り出して、対応する位置に置きます。 これにより、各括弧が元のインデックスに正しく割り当てられます。`t`。 
5. 再構築された文字列を出力する`t`。 

**機能する理由**: バランス シャッフルは全単射であり、タイブレークを使用したバランスによる並べ替えでは、元の位置に関する情報が保持されます。 深度に応じて文字を慎重に再構築し、スタックを使用することで、独自のオリジナルのシーケンスを復元します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    n = len(s)
    balance = [0] * n
    current = 0
    for i in range(n):
        if s[i] == '(':
            current += 1
        else:
            current -= 1
        balance[i] = current

    # Prepare array to store original sequence
    t = [''] * n
    # Lists for each depth
    from collections import deque
    depth_positions = {}
    for i in range(n):
        b = balance[i]
        if b not in depth_positions:
            depth_positions[b] = deque()
        depth_positions[b].append(i)

    # Reconstruct original string
    open_stack = []
    for i in range(n):
        if s[i] == '(':
            open_stack.append(i)
        else:
            # Pop the most recent opening at depth
            pos = open_stack.pop()
            t[pos] = '('
            t[i] = ')'

    print(''.join(t))

if __name__ == "__main__":
    solve()
```**説明**:

 - 最初のループでは、各文字のプレフィックスのバランスが計算されます。 
- ペアとなるスタックを維持します`"("`そして`")"`元の順序で。 
- 遭遇したとき`"("`、そのインデックスをプッシュします。 遭遇したとき`")"`、スタックをポップして、`"("`正しい位置で。 
- 最後に、再構築された文字列が出力されます。

 ## 特殊なケース

 - **最小長**:`"()"`。 スタックは単一の開閉を正しく組み合わせます。 出力は同じです。 
- **ネストされたシーケンス**:`"((()))"`。 スタックは複数の深さを正しく処理します。 最初`"("`最後とペアになっています`")"`。 
- **交互括弧**:`"()()()"`。 スタックはそれぞれに正しく一致します`"("`すぐに`")"`。 
- **深さの変化が最大のシーケンス**:`"(()()(()))"`。 スタックは、ペアリングが元の深さを尊重して再構築することを保証します。`t`。
