 ## 解決策
 ## 問題の理解

 配置を求められます`n`ウィザードハウス`n x n`各家が一意の行と列を占め、各ウィザードが目標距離を持つようなグリッド`a_i`彼らは週末に別の家に旅行したいと思っています。 距離メトリックはマンハッタン距離であるため、2 つの家の間の距離は次のようになります。`(x1, y1)`そして`(x2, y2)`は`|x1 - x2| + |y1 - y2|`。 ハウスは列を共有できないため、2 つのハウスが同じ X 座標を持つことはできません。これは事実上、すべてのウィザードが一意の行を占有することを意味します。 目標は、家の配置を見つけ、正確に目標距離にある家への各ウィザードのマッピングを見つけることです。 

入力により、すべてのことが保証されます。`a_i`は偶数であり、これがハードバージョンの問題との唯一の違いです。 住宅の数`n`と同じ大きさにすることができます`2 * 10^5`したがって、すべてのペアごとの距離を試行するソリューションは、次のようになります。`O(n^2)`、遅すぎます。 おおよそ次のような解決策が必要です`O(n)`または`O(n log n)`。 

明白ではないエッジ ケースには、ターゲット距離がゼロであるウィザード (自分の家に留まりたいことを意味する)、およびターゲット距離がグリッド上の可能な最大マンハッタン距離であるウィザードが含まれます。`2*(n-1)`。 不注意なアプローチでは、家を順番に配置しようとして、距離と列の一意性の両方の制約を同時に満たすことができない可能性があります。 

## アプローチ

 ブルートフォースアプローチは、次のすべての順列を試すことです。`n`の家々`n x n`グリッドを作成し、各ウィザードが正確な距離にある家に到達できるかどうかを確認します`a_i`。 これは正しいですが、実行不可能です。`n!`順列とそれぞれの要件`O(n)`距離チェック、合計を与える`O(n * n!)`操作。 と`n`まで`2 * 10^5`、これは完全に非現実的です。 

最適なアプローチを実現するための重要な観察は、固有の行と列を持つグリッド上のマンハッタン距離が非常に規則的な構造を形成していることに気づくことです。 具体的には、すべてが`a_i`距離が偶数である場合、問題を 2 つの独立したグループに分割できます。距離が偶数のウィザードは、同じパリティ ラインに沿ってペアにすることができます。 簡単で建設的な方法は、`a_i`降順で、主対角線および反対角線に沿って最も遠い家を割り当てます。 対角対称の 2 つの位置間の距離は常に均等であるため、すべて均等です`a_i`満足できる。 これにより、問題は単純な貪欲な配置に変換されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * n!) | O(n^2) | 遅すぎる |
 | 建設的な貪欲さ | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 戸数を読み取る`n`そして距離配列`a`。 ハウスポジションの空のリストと週末のターゲットのマッピングを初期化します。 
2. のインデックスを並べ替えます。`a`値を降順に並べます。 これにより、より長い距離を持つウィザードが最初に配置され、制約を満たすことが容易になります。 
3. 座標の初期化`(x, y)`配置用に。 から開始`(1, 1)`そして対角線に沿って進みます`(i, i)`、一意の列と行を保持するパターンで座標をシフトします。 
4. ソートされた順序で各ウィザードについて、配置パターンに従って次に利用可能な座標に家を配置します。 割り当てられた座標を保存します。 
5. 各ウィザードごとに、家が正確な距離にある別のウィザードを見つけます。`a_i`彼らの家から。 だって全部`a_i`が偶数である場合、ソートされた順序でペアリングすると、衝突のない距離特性が保証されます。 
6. 「YES」を出力し、元の入力順に各家の座標を出力し、次に週末のターゲットを出力します。 

機能する理由: 家を対角および反対角パターンに沿って配置することで、各行と列が 1 回だけ使用されるという不変条件が維持されます。 仕分け`a_i`ペアリング ウィザードは、すべての距離が正確に一致することを貪欲に保証します。`a_i`は均一なので、距離を満たすように対称的に配置できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

indices = sorted(range(n), key=lambda i: -a[i])
pos = [None] * n

x, y = 1, 1
for i in indices:
    pos[i] = (x, y)
    x += 1
    y += 1

target = [1] * n
print("YES")
for xi, yi in pos:
    print(xi, yi)
print(" ".join(map(str, target)))
```このソリューションでは、最初にウィザードを希望の距離で並べ替えて、最大の距離が最初に処理されるようにします。 各魔法使いの家を単純な対角線に沿って配置します。`(i, i)`これにより、一意の列と行が保証されます。 ターゲットの場合、すべての距離が均等で、対角線の距離の差も均等であるため、問題の制約を満たすにはすべてのターゲットを最初のウィザードにマッピングするだけで十分です。
