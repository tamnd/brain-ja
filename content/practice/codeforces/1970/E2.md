 ## 問題の理解

 この問題は、ハリー・ポッターが小道に沿って一連の小屋と中央の湖の間を移動するシナリオを説明しています。 各キャビンには、湖とつながる短小のトレイルが多数あります。 毎日、ハリーはちょうど 2 回移動します。最初は現在の小屋から湖まで、次に湖からおそらく別の小屋までです。 問題は、これら 2 つの動きのうち少なくとも 1 つは短いトレイルに沿ったものでなければならないということです。 質問は、一連の移動の合計数を尋ねます。`n`キャビン 1 から始まる日数、モジュロ`10^9 + 7`。 

入力によりキャビンの数が与えられます`m`そして日々`n`、その後に 2 つの配列が続きます`s`そして`l`サイズの`m`各キャビンからの短いトレイルと長いトレイルの数を指定します。 それぞれ`s_i`そして`l_i`最大でも 1000 であり、`m`最大でも 100 です。`n`最大 10^9 までの大きさになる可能性があります。 これにより、次のような単純なシミュレーションは即座に除外されます。`n`なぜなら、毎日のループには最大 10 億回の反復が必要であり、1 秒で実行できる反復をはるかに超えているからです。 

キャビンに短いトレイルがまったくない場合、エッジ ケースが発生します。 ハリーがそのような小屋で次のように出発するとします。`s_i = 0`そして`l_i > 0`。 どの日でも、彼は少なくとも 1 つの短いトレイルを利用する必要があり、その場合、短いトレイルが許可されているキャビンにのみ移動することを余儀なくされる可能性があります。 もう一つの微妙なケースは次のような場合です。`s_i = 0`そして`l_i = 0`あるキャビン用。 アルゴリズムは、キャビンから、またはキャビンへの移動が不可能な状況を正しく処理する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、各キャビンから湖まで往復するすべての有効なトレイルを列挙し、少なくとも 1 つのトレイルが短くなければならないというルールでフィルタリングすることで、毎日のシミュレーションを試みます。 毎日はおおよそ`O(m^2)`可能性があるので、`n`こうなる日々`O(m^2)^n`、これは大規模な場合にはまったく不可能です`n`。 

重要な洞察は、この問題が本質的にマルコフ過程であるということです。システムの状態は、ハリーが 1 日の始まりにいる小屋であり、シーケンスの数は、毎日の遷移カウントを乗算することによって決定されます。 これは当然、動的プログラミングまたは行列累乗アプローチに役立ちます。 具体的には、`m x m`マトリックス`T`どこ`T[i][j]`キャビンから行く方法の数です`i`キャビンへ`j`1 日後のシーケンスの総数`n`days は最初の行の合計です。`T^n`。 ここ、`T^n`行列を次のように累乗したものです`n`乗、これは 2 進累乗を使用して効率的に計算できます。`O(m^3 log n)`時間。 

ブルートフォースアプローチは、すべての可能性を列挙するため概念的には機能しますが、大規模な場合には失敗します。`n`。 問題が日々の推移の行列に還元できるという観察により、問題の制約とモジュロ演算の両方を考慮して、大きな累乗を効率的に計算できるようになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((m^2)^n) | O(m^2) | 遅すぎる |
 | 行列のべき乗 | O(m^3 log n) | O(m^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 日次推移マトリックスを計算する`T`。 各キャビンのペアごとに`(i, j)`、から行く道の数を計算します。`i`に`j`たった一日で。 これは 2 つの動きのシーケンスの合計です`(cabin -> lake -> cabin)`少なくとも 1 つの短いトレイルのルールを満たすもの。 具体的にはキャビンの場合`i`に`j`、カウントは`s_i*(s_j + l_j) + l_i*s_j`。 第 1 項はショート トレイルから始まり、第 2 項はロング トレイルから始まりショート トレイルを経由して到着するものです。 
2. 高速行列累乗を実装して計算する`T^n`モジュロ`10^9 + 7`。 2 進累乗を使用します。行列を半分にしながら繰り返し 2 乗します。`n`、そしていつでも累積結果を乗算します`n`奇数です。 
3. 開始キャビンを表すベクトルを初期化します。 ハリーはキャビン 1 から開始するため、このベクトルは次のようになります。`[1, 0, 0, ..., 0]`。 
4. 開始ベクトルを次のように乗算します。`T^n`各キャビンの最終的なカウントを取得するには`n`日々。 すべてのエントリを合計して、シーケンスの総数を取得します。 
5. 合計モジュロを返します`10^9 + 7`。 

機能する理由: の各エントリ`T^n`あるキャビンから別のキャビンまでのすべての有効なシーケンスをカウントします。`n`日々。 2 進累乗では、各二乗ステップで遷移行列の積が正しく計算され、有効なパスの合計数が維持されるため、正確さが保証されます。 モジュロにより、整数のオーバーフローが発生しないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mat_mult(A, B):
    m = len(A)
    C = [[0]*m for _ in range(m)]
    for i in range(m):
        for j in range(m):
            for k in range(m):
                C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD
    return C

def mat_pow(mat, power):
    m = len(mat)
    res = [[int(i==j) for j in range(m)] for i in range(m)]
    while power:
        if power % 2:
            res = mat_mult(res, mat)
        mat = mat_mult(mat, mat)
        power //= 2
    return res

def solve():
    m, n = map(int, input().split())
    s = list(map(int, input().split()))
    l = list(map(int, input().split()))
    
    T = [[0]*m for _ in range(m)]
    for i in range(m):
        for j in range(m):
            T[i][j] = (s[i]*(s[j]+l[j]) + l[i]*s[j]) % MOD
    
    T_n = mat_pow(T, n)
    result = sum(T_n[0]) % MOD
    print(result)

solve()
```の`mat_mult`関数は 2 つの行列を剰余で乗算します`10^9 + 7`。`mat_pow`2 進累乗を使用してべき乗を計算します。 で`solve`、キャビン数を読み取り、1 日あたり少なくとも 1 つのトレイルが短くなければならないというルールから導かれた式を使用して移行マトリックスを構築します。 最後のステップでは、次の最初の行を合計します。`T^n`キャビン 1 から始まるシーケンスを取得します。
