 ## 問題の理解

## アプローチ

 この問題を考える強引な方法は、整数の半径を持つすべての同心円を想像することです。 最初の円が点の外側に見つかるまで、半径を繰り返し大きくすることができます。 リングインデックスがわかれば、パリティによって色を決定できます。 

これは、整数半径の円を横切るときにのみ色が変化するため、機能します。 座標はせいぜい`1000`、最大可能距離はおおよそ次のとおりです。`1414`したがって、すべての半径をスキャンしても、約`1400`繰り返し。

1. 距離が整数かどうか。 
2. それ以外の場合、次のパリティ`floor(distance)`。 

この観察は、リングごとに色が交互に現れる様子から得られます。 年輪ごと`[k, k+1)`によって完全に決定される固定色を持ちます。`k`。

 ## アルゴリズムのチュートリアル

 1. 座標を読み取る`x`そして`y`。 
2. 原点からの二乗距離を計算します。$s = x^2 + y^2$2 乗距離を使用すると、不必要な浮動小数点演算が回避されます。 
3. の整数の平方根を計算します。`s`。 

させて`r = isqrt(s)`。 

これにより、次のような最大の整数が得られます。`r² ≤ s`。 
4. かどうかを確認します。`r * r == s`。 

true の場合、点は整数半径の円上に正確に位置するため、次のように出力します。`"black"`。 
5. それ以外の場合は、次を使用してリング インデックスを決定します。`r`。 

以来`r = floor(distance)`、点は環に属します`[r, r+1)`。 
6. もし`r`偶数です、印刷します`"black"`。 

もし`r`奇数です、印刷してください`"white"`。 

中心から色が交互に表示されます。半径の間隔は次のとおりです。`[0,1)`黒です。 

### なぜ効果があるのか

 すべての整数半径の円は、2 つの領域間の境界として機能します。 間隔`[0,1)`黒です、`[1,2)`白いです、`[2,3)`は再び黒になり、その交代は永遠に続きます。 

境界上にない点の場合、その色は原点からの距離の整数部分にのみ依存します。 値`floor(distance)`点を含む環を一意に識別します。 偶数のインデックスは黒の領域に対応し、奇数のインデックスは白の領域に対応します。 

二乗距離が完全な正方形であるかどうかをチェックすると、浮動小数点エラーなしで境界点が正しく検出されます。 

## Python ソリューション```python
import sys
from math import isqrt

input = sys.stdin.readline

x, y = map(int, input().split())

s = x * x + y * y
r = isqrt(s)

if r * r == s:
    print("black")
else:
    if r % 2 == 0:
        print("black")
    else:
        print("white")
```プログラムは、実際の距離の代わりに二乗距離を計算することから始まります。 整数演算が正確であるため、これはより安全です。 

機能`isqrt`純粋な整数演算を使用して平方根の下限を返します。 これにより、次のような場合に発生する可能性のある精度の問題が回避されます。`sqrt`。 

条件`r * r == s`距離が正確な整数であるかどうかをチェックします。 すべての境界円は黒であるため、これらの点は常に黒です。 

点が境界上にない場合、次のパリティは`r`リングの色を決定します。 中心領域は黒から始まるため、偶数番号のリングは黒、奇数番号のリングは白になります。 

よくある間違いは、`round(sqrt(...))`の代わりに`floor`。 リングは間隔によって定義されるため、フロアリングは正しい操作です。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io
from math import isqrt

def solve():
    input = sys.stdin.readline

    x, y = map(int, input().split())

    s = x * x + y * y
    r = isqrt(s)

    if r * r == s:
        print("black")
    else:
        print("black" if r % 2 == 0 else "white")

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.strip()

# provided sample
assert run("-2 1\n") == "black", "sample 1"

assert run("3 4\n") == "black", "perfect-square distance"
assert run("2 2\n") == "black", "inside black ring"
assert run("1000 1000\n") == "black", "large coordinates"
