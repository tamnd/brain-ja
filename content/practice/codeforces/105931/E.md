 ## 問題の理解

 1 次元配列から始めますが、それを直接操作するのではなく、それを使用して$n \times n$すべての行が元の配列の循環シフトに過ぎない行列。 したがって、各列も同じ値のシフトされたバージョンであり、配列のすべての数値が正確に表示されます。$n$マトリックス全体の構造化されたポジションでの時間。 

ここで、すべての行列セルをグラフの頂点として考えてみましょう。 2 つの条件が同時に満たされる場合、2 つの頂点は接続されます。 まず、グリッド内のマンハッタン距離は最大でも$k$つまり、最大全長のグリッド ステップを使用してそれらの間を移動できることになります。$k$。 第 2 に、これら 2 つのセルに書かれた数値は互いに素ではありません。これは、それらの最大公約数が厳密に 1 より大きいことを意味します。 

タスクは、このグラフに含まれる連結成分の数を計算することです。 グラフにはあるので、$n^2$頂点と$n$と同じ大きさにすることができます$10^6$、明示的に構築したり走査したりすることは不可能です。 行列の構造と gcd 条件を十分に活用する必要があります。 

この制約により、行列を一般的なグラフとして扱うものは直ちに除外されます。 すべての頂点を保存することすら不可能です。$n^2$到達する$10^{12}$。 有効なソリューションでは、セルの列挙を回避し、代わりに循環シフトによって引き起こされる周期構造を処理する必要があります。 

多くの場合失敗する単純なメンタル モデルは、各細胞が独立して動作すると仮定することです。 たとえば、すべての値が個別である場合、グリッドのような接続構造を誤って期待する可能性があります。 しかし、ここでは同じ値が厳密なパターンで繰り返され、gcd は共有素因数を通じて長距離相互作用を作成します。 

微妙なエッジケースが現れるのは、$k$たとえば、大きいです$k \ge n$。 この場合、マンハッタン制約は行列内の動きを意味のある形で制限しなくなり、成分はほぼ完全に gcd 構造によって決定されます。 グローバルな到達範囲をチェックせずに、この体制における局所性を前提としたソリューションは失敗します。 

## アプローチ

 直接的なアプローチでは、グラフを明示的に構築します。 セルの各ペアについて、マンハッタン距離と gcd をチェックし、それらを結合します。 これにはすでに費用がかかります$O(n^4)$最悪の場合の比較があるため、$n^2$頂点があるため、たとえ$n = 1000$、ましてや$10^6$。 

1 つの頂点を固定し、マンハッタン半径内の近くの頂点にのみ接続しようとしても$k$、密なグリッド内の近傍サイズは依然として$O(k^2)$、そしてそれ以来$k$と同じ大きさにすることができます$10^9$、この解釈は完全に破綻しています。 重要な観察は、隣接関係が 2 つの独立した構造、つまりマンハッタン距離からの幾何学的制約と gcd からの算術制約に依存するということです。 

マトリックス構造は実際に単純化したものです。 それぞれの値$a[j]$恣意的に現れるものではありません。 マトリックス全体に完全な対角パターンを形成します。 列インデックスを修正する場合$j$、の発生$a[j]$行を横切る決定的な線に沿って配置され、シフトしても予測可能な方法で位置が変更されるだけです。 これにより、マトリックスは非構造化グリッドではなく構造化サイクルの集合に変わります。 

gcd 条件は、問題を素因数でさらに分解します。 2 つのセルは、少なくとも 1 つの素因数を共有する場合にのみ接続できるため、各素数を独立して処理し、後で和集合検索ロジックを通じて効果を組み合わせることができます。 

マンハッタン条件は、循環シフト構造と重要な方法で相互作用します。グリッド内の動きは、これらの構造化された対角線に沿った制限された動きに変換されます。 2 次元で推論する代わりに、循環インデックス空間に沿ったセグメント間の相互作用への接続性を低減します。 

これら 2 つの削減を組み合わせると、問題は対処可能になります。私たちはもう協力しません。$n^2$ノードがありますが、$n$値クラス、それぞれが構造化セグメントに貢献し、接続性は循環インデックス ドメインにわたる間隔のようなマージの結合になります。

 ## アルゴリズムのチュートリアル

 ### ステップ 1: 配列内のすべての値を因数分解する

 ごとに分解していきます$a[i]$その主な要因に。 エッジは少なくとも 1 つの素数を共有する数値間にのみ存在するため、各素数は個別の「接続層」を定義します。 

これにより、グラフを素数ごとに 1 つずつ、サブグラフの和集合として扱うことができます。 

### ステップ 2: マトリックス内の固定インデックスの出現を解釈する

 インデックスを修正する$j$配列内で。 マトリックスの値$a[j]$巡回シフトに応じて決定的な列位置に、行ごとに 1 回だけ表示されます。 だから考える代わりに$n^2$私たちが考える細胞$n$周期的な「トラック」。配列インデックスごとに 1 つ。 

各トラックはマトリックスを通る順列のような曲線であり、一貫した対角パターンでグリッドの周りを包みます。 

### ステップ 3: トラック内のマンハッタンの隣接性を減らす

 固定インデックス内$j$、2 つのオカレンスが異なる行にあります。 マンハッタン距離は行の差に応じて増加しますが、列は行と同期して移動するため、距離は行間隔の関数に単純化されます。 

行の差が$d$、マンハッタン距離は次のいずれかのように動作します。$2d$または、ラップ効果が優勢な場合は上限値。 これは、単一のトラック内で、マンハッタンの半径によって接続が誘導されることを意味します。$k$行インデックスが最大約約異なる点のマージのみを許可します$k/2$、次の場合を除く$k$を超える$n$、この場合、トラック全体が接続されます。 

したがって、それぞれのインデックス$j$接続されたブロックのいずれか 1 つを提供します ($k \ge n$) または行順序に沿った複数の連続したセグメント (場合$k < n$）。 

### ステップ 4: 異なるインデックス間の接続を解除する

 ここで 2 つの異なる指数を考えてみましょう$j_1$そして$j_2$。 セルがいつ追跡されるかを尋ねます$j_1$トラックからセルに接続できます$j_2$。 行の違いは距離を増やすだけであるため、最適な位置合わせは同じ行内のセルを比較することです。 

同じ列で$i$、マンハッタンの距離は純粋に水平になり、それらの列位置間の差に等しくなります。これは、列間の巡回シフト オフセットによって決まります。$j_1$そして$j_2$。 これにより、トラック間の接続がインデックスの円形距離条件に減少します。 

2つのインデックス$j_1, j_2$配列サイクル上の円周距離が最大でも相互作用できる$k$。 

### ステップ 5: 各素数の配列インデックスに DSU を構築する

 素数ごとに$p$、すべての指標を考慮します$j$そのような$p \mid a[j]$。 円周距離が以内のインデックスを接続します$k$。 インデックスの各接続コンポーネントは、この素数の下でマージされるトラックのセットに対応します。 

このような各コンポーネント内では、ステップ 3 のすべての対応するセグメントがそれに応じてマージされます。 

### ステップ 6: 最終コンポーネントを数える

 ステップ 3 で作成された各セグメントはノードとして扱われます。 DSU は、手順 3 と 5 で定義された接続に従ってそれらをマージします。DSU ルートの最終的な数は、グラフ全体内の接続されたコンポーネントの数になります。 

### なぜ効果があるのか

 元のグラフのすべてのエッジは、共有素因数で 2 つのセルを接続しているか、存在していません。 これにより、すべてのエッジが独立したプライム誘起レイヤーに分割されます。 各層の内部では、巡回行列の幾何学構造によって、マンハッタンの隣接関係が構造化されたトラックに沿った限定された動きに減少し、トラック間の相互作用が相対的なシフトのみに依存することが保証されます。 すべての削減により到達可能性が維持されるため、セグメント上の DSU はグリッドを明示的に構築せずに接続を正確にシミュレートします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from math import isqrt

def factorize(x, spf):
    res = set()
    while x > 1:
        p = spf[x]
        res.add(p)
        while x % p == 0:
            x //= p
    return res

def build_spf(mx):
    spf = list(range(mx + 1))
    for i in range(2, isqrt(mx) + 1):
        if spf[i] == i:
            for j in range(i * i, mx + 1, i):
                if spf[j] == j:
                    spf[j] = i
    return spf

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return
        if self.r[a] < self.r[b]:
            a, b = b, a
        self.p[b] = a
        if self.r[a] == self.r[b]:
            self.r[a] += 1

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    mx = max(a)
    spf = build_spf(mx)

    prime_to_indices = {}

    for i, val in enumerate(a):
        primes = factorize(val, spf)
        for p in primes:
            prime_to_indices.setdefault(p, []).append(i)

    # each index is a node
    dsu = DSU(n)

    # threshold in row direction approximation
    # distance within same track behaves like ~2*|i-j|
    if k < n:
        step = k // 2
    else:
        step = n

    # connect along same index tracks (segments)
    if step < n:
        for i in range(n):
            if i + step < n:
                dsu.union(i, i + step)

    # connect indices sharing primes with circular proximity
    for p, idxs in prime_to_indices.items():
        m = len(idxs)
        if m <= 1:
            continue
        idxs.sort()

        # connect in circular order
        for i in range(m - 1):
            if idxs[i + 1] - idxs[i] <= k:
                dsu.union(idxs[i], idxs[i + 1])

        # wrap connection
        if m > 1 and (idxs[0] + n - idxs[-1]) <= k:
            dsu.union(idxs[0], idxs[-1])

    comps = sum(1 for i in range(n) if dsu.find(i) == i)
    print(comps)

if __name__ == "__main__":
    solve()
```DSU は、マトリックスの対角トラック全体を表す配列インデックス上に構築されます。 最初のユニオン ステップでは、マンハッタン半径で近くのオカレンスをマージできる場合に、単一トラック内の接続を処理します。 いつ$k$が大きいと、各トラックが 1 つのブロックに折りたたまれます。 2 番目のステップでは、素因数を共有し、巡回インデックス空間内で十分に近い異なるトラックを接続します。これにより、2 つの対角線がグリッドを通じて相互作用できるタイミングが捕捉されます。 

DSU ルートの最終的な数は、すべての幾何学的接続と算術接続が適用された後に残るインデックスの独立したクラスターの数に対応します。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべての数値がペアごとに互いに素である場合です。 この状況では、gcd 条件がトリガーされないため、エッジはまったく存在しません。 DSU は完全に分割されたままであり、答えは次のとおりです。$n$。 

もう 1 つのケースは、すべての数値が共通の素数を共有する場合です。たとえば、すべてが偶数です。 そうすれば、すべての有効なマンハッタン接続が関連性を持ち、それに応じて$k$、構造全体を単一のコンポーネントに折りたたむことができます。 すべてのインデックスが同じ素数グループに分類され、循環近接によって結合されるため、アルゴリズムはこれを処理します。 

3 番目のケースは次の場合に発生します。$k \ge n$。 ここで、マンハッタン制約は各トラック内の動きの制限を停止するため、各インデックスは完全に接続された垂直サイクルとして動作します。 アルゴリズムは各インデックス グループ内で完全な結合動作に切り替わり、プライムベースのマージが適用される前に、値のすべての出現が単一の接続されたエンティティとして扱われるようになります。
