 ## 解決策
 ## 問題の理解

 長さの配列が与えられます$n$、各要素は範囲内の整数です。$[1, n]$。 関数によって定義された変換を適用することができます$f$のすべての値をマップします。$[1, n]$同じ範囲内の別の値に変更します。 この関数を適用すると、配列は次のようになります。$B$ここで、各要素はマップされた値によって個別に置き換えられます。 

目標は、結果の配列を作成することです$B$減っていない。 関数を選択するコストは値の数です$x$誰のために$f(x) \neq x$。 言い換えれば、元のアイデンティティから「変更」したドメイン内の各値は、配列内に何回出現したかに関係なく、1 単位のコストに寄与します。 

したがって、問題は配列の位置を直接変更することではなく、値の再ラベルを選択し、ラベルが変更されたすべての値に対して料金を支払うことです。 

重要な構造上の制約は、順序付けが値のマッピングとどのように相互作用するかによって決まります。 値の場合$x$配列の前の方に出現し、別の値が出現する$y$後で表示される場合、最終的な配列のソートを維持するには、次のことを確認する必要があります。$f(x) \le f(y)$。 これは、隣接する要素だけでなく、出現全体に対するグローバルな制約です。 

単純な誤解は、マッピング後に隣接する位置を比較するだけでよいと考えることです。 これでは不十分です。遠く離れたオカレンスの間に不正な順序が発生する可能性があるためです。 

たとえば、次のようなシーケンスを考えてみましょう。$A = [1, 2, 1]$。 地図を作るなら$f(1)=2$、$f(2)=1$、結果の配列は次のようになります$[2, 1, 2]$、隣接する構造のみが考慮されている場合、ローカル推論では競合を見逃す可能性がありますが、ソートされていません。 

2 番目の微妙なケースは、2 つの値がインターリーブする場合に発生します。 もし$x$そして$y$のように交互に表示されます。$x, y, x$、次に両方の制約$f(x) \le f(y)$そして$f(y) \le f(x)$強制されます。つまり、$f(x)=f(y)$。 これにより、単純な貪欲なアプローチでは見逃してしまう強制的なマージ効果が生じます。 

以来$n$まで可能です$2 \times 10^5$、値のペアに対する二次関数の動作に近い解決策は不可能です。 構造を線形に近いものに圧縮する必要があります。$n \log n$。 

## アプローチ

 ブルートフォース手法では、値を割り当てようとします。$f(x)$あらゆる人にとって$x$、次に、結果の変換された配列がソートされているかどうかを確認します。 それぞれなので$f(x)$まであります$n$これは、個別の値の数が指数関数的に増加するため、有効性をチェックする場合でも配列全体をスキャンする必要があります。 これはすぐに実行可能な限界を超えて爆発します。 

より構造化されたビューは、重要なのは配列内での値の出現によって引き起こされる値間の相対的な順序付けの制約だけであることに気づくことから生まれます。 それぞれの値$x$一連の位置を効果的に表します。 最終順序で、ある値が別の値の前にいつ来るかを定義すると、間隔を使用して表現できる制約が得られます。 

それぞれの値について$x$、最初の出現を次のようにします$L_x$そして最後の出現は$R_x$。 次に、重大な事実が観察されます。$x$何かが起こる前に現れる$y$、 それから$L_x < R_y$制約を許可します$f(x) \le f(y)$。 同様に、$L_y < R_x$、私たちは得ます$f(y) \le f(x)$。 両方の条件が当てはまる場合、2 つの値は相互に制約され、強制的に等しくなります。 

これは、値が直線上の間隔のように動作し、重なり構造によって強制的な等価グループが決定されることを意味します。 重複する間隔の各接続領域を一緒にマッピングする必要があります。 

値をグループ化すると、すべてのグループに 1 つの出力値を割り当てることができます。 サイズのグループ内$k$、少なくとも変えなければなりません$k-1$なぜなら、独自のラベルを代表として選択した場合、変更されない値は 1 つだけだからです。 

したがって、問題は、区間オーバーラップ グラフに存在する連結成分の数を見つけることになります。

 ## アルゴリズムのチュートリアル

 それぞれの個別の値を、配列内の最初と最後の出現によって定義される間隔に変換します。 

1. コンピューティング$L_x$そして$R_x$あらゆる価値観に対して$x$。 

これにより、順序付けの制約を推論するために必要なすべての位置情報が取得されます。 
2. すべての値を左のエンドポイントで並べ替えます$L_x$。 

これにより、左から右へのスイープで間隔を処理できるようになります。 
3. 現在アクティブなグループの最大右端点を維持しながら、ソートされた間隔をスイープします。 

次の間隔がこの最大右端点より前またはその時点で始まる場合、その間隔は現在のグループと重複するため、同じコンポーネントに属している必要があります。 
4. 間隔が現在のグループと重複しない場合は、現在のコンポーネントを閉じて、新しいコンポーネントを開始します。 
5. 形成されたコンポーネントの数を数えます。 
6. 答えは次のとおりです。$n - \text{number of components}$、サイズの各成分が$k$まさに貢献する$k-1$強制的な変更。 

### なぜ効果があるのか

 核となる不変条件は、どの瞬間においても、アクティブなグループは、その間隔が直接的または推移的に重複する値の最大セットを表すということです。 オーバーラップは、コンポーネント内のすべての値間に等価制約を強制する一連のインターリーブが存在することを意味します。 逆に、2 つのコンポーネントがギャップによって分離されている場合、制約によってそれらのコンポーネントに値の共有を強制する方法はないため、それらを独立して扱うことができます。 これにより、各コンポーネントが最小限の強制等価構造になることが保証され、各コンポーネントを個別に折りたたむことで最適なコストが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    INF = 10**18
    first = [INF] * (n + 1)
    last = [-1] * (n + 1)

    for i, x in enumerate(a):
        if first[x] == INF:
            first[x] = i
        last[x] = i

    intervals = []
    for x in range(1, n + 1):
        if last[x] != -1:
            intervals.append((first[x], last[x]))

    intervals.sort()

    components = 0
    cur_r = -1

    for l, r in intervals:
        if l > cur_r:
            components += 1
            cur_r = r
        else:
            cur_r = max(cur_r, r)

    print(n - components)

if __name__ == "__main__":
    solve()
```実装では、まず各値がその出現間隔に圧縮されます。 次に、これらの間隔を並べ替え、標準のマージ スキャンを実行して、重複している連結成分をカウントします。 微妙な部分は、実行最大右境界を介してオーバーラップを推移的な接続として扱い、明示的にグラフを構築することを回避します。

 すべての間隔が推移的に重なり、単一のコンポーネントを形成するため、答えは次のようになります。$6 - 1 = 5$。 

これは、インターリーブによりすべての値が 1 つのグループに強制的に入れられるケースを示しています。 

ここで、分離された構造を考えてみましょう。 

入力:```
6
1 1 2 2 3 3
```| ステップ | 処理された間隔 | 現在の右境界 | コンポーネント |

 | 1 | (1:[0,1]) | 1 | 1 |
 | 2 | (2:[2,3]) | 1→3 | 2 |
 | 3 | (3:[4,5]) | 3→5 | 3 |

 各ブロックは分離されており、3 つのコンポーネントと答えが生成されます。$6 - 3 = 3$。 

これにより、重複しないセグメントが独立して動作することが確認されます。

 ## 特殊なケース

 微妙なエッジ ケースは、共有境界の発生によって 2 つの値がかろうじて接触する場合です。 たとえば、次のようなシーケンスでは、`1 2 3 1`、値 1 には間隔があります`[0,3]`値 2 は`[1,1]`。 2 は完全に 1 のスパン内に表示されますが、1 と 2 は中間位置を通じて相互順序制約を作成する方法でインターリーブするため、マージが強制されます。 それらの間隔は重複しているため、アルゴリズムはそれらを正しくマージします。 

もう 1 つのケースは、次のように間隔が直接重なり合わずに連鎖する場合です。`[1,4]`、`[4,7]`、`[7,10]`。 各ペアは境界でしか接触していませんが、実行中の右エンドポイントが接続性を推移的に伝播するため、スイープによってそれらのペアが 1 つのコンポーネントにマージされます。 これにより、弱いオーバーラップでも単一の強制等価グループが確実に生成されます。
