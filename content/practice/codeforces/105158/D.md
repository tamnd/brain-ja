 ## 解決策
 ## 問題の理解

 平面内の点のセットが与えられ、点のペアごとに 2 つの異なる距離を測定できます。1 つは絶対的な水平方向と垂直方向の変位を加算するマンハッタン距離、もう 1 つは直線距離であるユークリッド距離です。 

タスクは、考えられるすべての点のペアを調べ、これら 2 つの距離間の比率の最大値を見つけることです。 具体的には、点の各ペアについて、それらの分離が直線分離と比較してどの程度「グリッドに沿って」配置されているかを計算し、この不一致が最も極端になるペアを求めます。 

入力は複数の独立したテスト ケースで構成されます。 各テスト ケースは最大 200,000 ポイントを提供し、すべてのテスト ケースの合計サイズも 200,000 によって制限されます。 これにより、テスト ケース内のペアの二次列挙が即座に除外されます。 すべてのペアを直接チェックするには、およそ n² 回の比較が必要ですが、n = 2 × 10⁵ の場合でも不可能になります。 

微妙な点は、両方の距離がさまざまな点でスケールに依存することです。 2 つの点が対角方向に遠く離れている場合、マンハッタン距離とユークリッド距離は近くなります。 それらがより軸に沿って整列している場合、マンハッタン距離はユークリッド距離に比べて大幅に大きくなります。 これは、極値が絶対的な大きさだけではなく、方向によって左右されることを示唆しています。 

また、単純化せずに比率を直接最適化しようとすると、特に厳密な精度要件を持つ浮動小数点出力を扱うため、単純なアプローチでは数値が不安定になる危険があります。 

## アプローチ

 ブルートフォースのアイデアは単純です。すべての点のペアを反復処理し、両方の距離を計算し、最大比率を追跡します。 これは、目的の定義を明示的に評価するため、正しいです。 ただし、テスト ケースごとに n(n−1)/2 回の評価を実行します。これは、n が最大 2 × 10⁵ の場合、約 2 × 10¹⁰ の演算を実行することになり、実行可能な限界をはるかに超えています。 

重要な構造的洞察は、ジオメトリを方向性コンポーネントに分離する方法で比率を書き直すことです。 2 つの点の差が (dx, dy) であるとします。 比率は次のようになります。 

(|dx| + |dy|) / sqrt(dx² + dy²)。 

分子は L1 ジオメトリに依存し、分母は L2 ジオメトリに依存します。 dx と dy の両方をスケーリングすると相殺されるため、この式はベクトル (dx、dy) の方向のみに依存し、その大きさには依存しません。 これは、距離によって点のペア間を検索するのではなく、ペアによって誘導される方向間を検索することを意味します。 

問題は、点差によって定義されるすべての方向ベクトルにわたってこの関数の最大値を見つけることに帰着します。 標準的なトリックは、座標記号を反映する変換の下で方向がセットの凸包構造と一致するときに極値が発生することを考慮することです。 

各ペアが象限の位置合わせに応じて 4 つの符号構成のいずれかにあることを観察することにより、絶対値を削除します。 符号の選択が固定されている場合、式は変換された座標で線形になります。 

(dx + dy) / sqrt(dx² + dy²)、または符号反転のあるバリアント。 

これにより、問題は、すべてのペアごとの差にわたる方向投影を最大化することに帰着します。これは、概念的には、座標系を回転した後に点間の極端な方向を見つけることに相当します。 

最後の観察は、最適なペアは凸包上に存在する必要があるということです。これは、任意の内部点は凸の組み合わせとして表現でき、包の頂点よりも極端な方向の違いを生成できないためです。 したがって、問題を凸包の計算と隣接するハル点のみのチェックに、またはより直接的に、ハルのエッジに対する標準の回転キャリパー スタイルの評価を使用して縮小します。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、すべてのポイントを読み取り、単調連鎖アルゴリズムを使用して凸包を構築します。 x、次に y で並べ替えると、一貫した境界構造が保証されます。 境界点のみが極端な方向の違いを定義できるため、凸包ステップが必要です。 
2. 凸包を順番に横断し、極端な方向を定義できるすべての点のペアを検討します。 実際には、船体のエッジを検査するだけで十分です。これは、方向が船体のエッジまたは 2 つの隣接するエッジ間の遷移と一致する場合に、極端な比率が達成されるためです。 
3. 2 つのハル点 Pi および Pj によって形成される各候補方向ベクトルについて、dx および dy を計算します。 
4. 関数 (|dx| + |dy|) / sqrt(dx² + dy²) を評価します。 これは、ペアを接続するベクトルの L1 ノルムと L2 ノルムの比です。 
5. 考慮されたすべてのペアにわたる最大値を追跡し、高精度で出力します。 

重要な実装の詳細は、すべての符号構成を暗黙的に一貫して考慮する必要があるということです。 凸包により、どの方向についても、極値投影が何らかの包縁によって実現されることが保証されるため、すべての象限を明示的に列挙する必要はありません。 

### なぜ効果があるのか

 式は 2 点間のベクトルの方向のみに依存します。 点セットの内部点は、凸包の内側にあるため、境界点よりも極端な方向を定義することはできません。そのため、その差分ベクトルは包差の凸状の組み合わせになります。 この比率は、方向が L1 誘発計量のもとで凸包の極値支持線と一致するときに最大になります。 したがって、注目をハルの頂点に限定すると、最適なペアのすべての候補が保存されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def convex_hull(points):
    points = sorted(points)
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def ratio(a, b):
    dx = a[0] - b[0]
    dy = a[1] - b[1]
    return (abs(dx) + abs(dy)) / math.sqrt(dx * dx + dy * dy)

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        pts = [tuple(map(int, input().split())) for _ in range(n)]

        if n == 2:
            out.append(str(ratio(pts[0], pts[1])))
            continue

        hull = convex_hull(pts)

        m = len(hull)
        best = 0.0

        for i in range(m):
            for j in range(i + 1, m):
                best = max(best, ratio(hull[i], hull[j]))

        out.append(str(best))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この解決策は、候補セットを凸包点に減らすことから始まります。 船体の構造により、極端な方向比に寄与できない内部の点が確実に排除されます。 

この実装では、ハルの頂点にわたるネストされたループは意図的に単純になっていますが、正確性の議論は、ハルで定義された方向のみが重要であるという事実に依存しています。 各ペアは、定義を直接実装する比率関数を通じて、慎重に使用して評価されます。`abs`そして`sqrt`。 

浮動小数点精度は Python の倍精度を使用して処理されます。1e-9 許容誤差要件を考慮すると、これで十分です。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべての点が直線上にある場合です。 その状況では、凸包は 2 つの端点のみに崩壊しますが、アルゴリズムは依然としてその 1 つのセグメントに対して正しい比率を返さなければなりません。 極端な点だけを押さえた船体構造なので、特別な対処を必要とせず、自然に正しく問題を軽減します。 

点が完全に軸に沿った長方形を形成する場合、別のエッジ ケースが発生します。 ここでは、対向するコーナー間で最大の比率が達成され、中間点が干渉しないようにする必要があります。 凸包により、4 つの角だけが残ることが保証され、それらの間のすべてのペアを正しく評価すると、式を最大化する対角線のペアが含まれます。 

3 番目の微妙なケースは、複数の点が同一の x または y 座標を共有する場合で、これにより中間の船体構築ステップで点が繰り返される可能性があります。 単調チェーン アルゴリズムは、非凸ターンを破棄することでこれを処理し、重複が候補ペアの最終セットに影響を与えないようにします。
