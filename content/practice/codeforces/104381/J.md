 ## 解決策
 ## 問題の理解

 プレイヤーの同じサイズの 2 つのグループが与えられ、それぞれに次のグループが含まれます。$n$人々。 すべてのプレイヤーには評価があります。 主催者はプレイヤーを 2 つの固定グループ A と B に分割しますが、組み合わせは柔軟です。A の各人は B の 1 人と正確に一致する必要があり、グループを形成します。$n$2対2のチーム。 

チームの強さは、2 人のメンバーの評価の合計です。 特定の組み合わせで形成されたすべてのチームの中で、トーナメントの勝者は、最も大きな金額を獲得したチームです。 ただし、単一の組み合わせについては尋ねられません。 代わりに、A と B を完全に一致させるためのあらゆる方法を検討し、一致するたびに最も強いチームを検討します。 目標は、考えられるすべてのマッチングにおいて最も強いチームを最小限に抑えることです。 

したがって、A と B の間で賢い組み合わせを選択することで、最悪の場合の最大ペア合計を制御しようとしているのです。 

入力サイズが大きく、最大$n = 10^5$これにより、マッチングまたはペアの比較に対する二次探索が即座に除外されます。 すべての組み合わせ、さらにはすべての候補のマッチングを考慮しようとするアプローチは、制限時間をはるかに超えてしまいます。 期待すべきことは、$O(n \log n)$または線形時間の貪欲なソリューション。 

単純に推論する場合、微妙な問題が発生します。正確なルールなしで大きな値と小さな値をペアにする誘惑に駆られますが、異なる「合理的な」ヒューリスティックによって異なる最大ペア和が生成される可能性があり、慎重に順序付けしないと最適な構造は明らかではありません。 

たとえば、A = [1, 10] および B = [1, 10] の場合、(1,10) と (10,1) のペアでは最大 11 が得られ、(1,1) と (10,10) のペアでは最大 20 が得られます。ペアリング戦略によってボトルネックが完全に変わります。 

主な困難は、すべてのチームの合計を最小化するのではなく、マッチング全体のペアの最大合計を最小化することです。 

## アプローチ

 ブルートフォース手法では、B のすべての順列を試し、A との各ペアの最大ペア合計を計算します。これは、2 つのグループ間で考えられるすべての全単射を調査するため、正しいです。 ただし、$n!$可能な一致を調べ、それぞれについて計算します$n$合計すると、$O(n \cdot n!)$操作。 これは非常に小さい場合でも実行不可能です$n$。 

問題の構造は、値を並べ替えてから、極端な値のバランスをとる組み合わせを構築する必要があることを示唆しています。 目的は、単一のペアが大きくなりすぎないようにすることです。 両方の配列をソートすると、極端な値がどのように相互作用するかを制御できるようになります。 

重要な観察は、ペアの最大合計は、一方のグループの最大の要素が他のグループの最大の要素とどのように相互作用するかによって決まるということです。 大と大を組み合わせると、大きなピークが作成されます。 大きいものと小さいものを組み合わせると、重量がより均等に分散されます。 

これについて考えるのに役立つ方法は、しきい値を固定することを想像することです。$T$。 すべてのペアの合計が最大で以下になるように要素をペアにできるかどうかを知りたいのです。$T$。 できれば、$T$実現可能です。 実現可能な最小のもの$T$が答えです。 固定の場合$T$、各要素$a_i$いくつかと組み合わせる必要があります$b_j \le T - a_i$。 これはマッチングの実現可能性の問題になりますが、両側がソートされているため、貪欲に実現可能性を確認することができます。 

ただし、二分探索を完全に回避することはできます。 両方の配列をソートし、最小値と最大値を反対方向にペアリングすると、極端なバランスが直接得られます。 具体的には、A の最小値と B の最大値、2 番目に小さい値と 2 番目に大きい値などを組み合わせることにより、2 つの大きな要素によって同時に支配されるペアが存在しないことが保証されます。 この配置により、最大合計が最小化されます。これは、同様にランク付けされた要素をペアにする偏差は、少なくとも 1 つの極値合計のみを増加させるためです。 

したがって、A を昇順にソートし、B を昇順にソートした後、ペアにします。$a[i]$と$b[n-1-i]$、これらの合計の最大値を計算します。 

これにより、可能な最小の最大ペア合計が生成されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n \cdot n!)$|$O(n)$| 遅すぎる |
 | 最適 (ソート + 貪欲なペアリング) |$O(n \log n)$|$O(1)$追加 (ソートを無視) | 承認済み |

 ## アルゴリズムのチュートリアル

 ここで、最適なペアリングを直接構築します。 

1. 配列 A を非降順でソートします。 これにより、最も弱い要素と最も強い要素を一貫して推論することができます。 
2. 同じ理由で、配列 B を非降順でソートします。 
3. 変数を初期化する`answer = 0`発生したペアの最大の合計を追跡します。 
4. 各インデックスについて$i$0から$n-1$、ペア$a[i]$と$b[n-1-i]$。 それらの合計を計算して更新します`answer = max(answer, a[i] + b[n-1-i])`。 

B を反転する理由は、バランス効果を強制するためです。A の小さな要素が B の大きな要素とペアになり、ペアの両側が同時に大きくなるのを防ぎます。 

1. 出力`answer`。 

### なぜ効果があるのか

 並べ替えると、強さのグローバルな順序が得られます。 最適なマッチングでは、大きな値が一緒にクラスター化するのを避ける方法で要素をペアにする必要があります。 2 つの大きな要素がペアになっている場合、そのペアが最大値の候補になります。 一方の最大の要素ともう一方の最小の要素をペアにすることで、他の再配置と比較して「必要以上に悪い」ペアが存在しないことが保証されます。 より大きな B 要素をより大きな A 要素に近づけるスワップでは、ペアの最大合計が増加または維持されるだけであり、減少することはありません。 この交換引数により、逆ペアリングが最適であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    a.sort()
    b.sort()
    
    ans = 0
    for i in range(n):
        ans = max(ans, a[i] + b[n - 1 - i])
    
    print(ans)

if __name__ == "__main__":
    solve()
```この解決策は、両方の配列をソートしてから 1 回の線形スキャンを実行することに完全に依存しています。 ペアリング ロジックはループ内に実装されており、インデックスが配列 B 全体で意図的にミラーリングされます。重要な詳細は、`n - 1 - i`これにより、B の最大値が A の最小値とペアになることが保証されます。 

追加のデータ構造は必要なく、ソート以降のすべての計算は線形です。

```ソート後、両方の配列は [1, 10] のままになります。 最小値と最大値をペアにします。

 ペアの最大合計は 11 で、これは極端な値を分散することで最悪のケースが軽減されることを裏付けています。

```ソートされた配列は A = [1, 5, 9]、B = [2, 6, 10] です。 

| 私 | a[i] | b[2-i] | ペアの合計 | 現在の最大値 |

 すべてのペアリングは同じ最大値に揃っており、貪欲な構造により自然に分布のバランスが取れていることがわかります。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    a = list(map(int, input().split()))

    a.sort()
    b.sort()

 ## 特殊なケース

 最小限の入力で$n = 1$単一のペアで構成されます。 このアルゴリズムは両方の配列をソートし、可能な唯一のペアの合計を直接計算します。 代替の一致はないため、出力は自明のことながら正しいものになります。 

すべての値が等しい場合、並べ替えは効果がありません。 すべての組み合わせは同じ合計を生成し、アルゴリズムはその値を 2 倍にして返します。これは真の最大値と一致します。 

厳密に増加する配列の場合、逆のペアリングにより最小値と最大値が強制され、極端な位置合わせではなく中間の相互作用によって最大値が決定されるようになります。 これにより、同じペア内で大きな値が互いに強化し合うという最悪のシナリオが回避されます。
