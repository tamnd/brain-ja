 ## 解決策
 ## 問題の理解

 整数座標を持つ無限グリッド上の 2 つの点が与えられます。 ピースは最初のポイントから始まり、2 番目のポイントに到達する必要があります。 1 回の移動で、駒は 2 つの異なる動作をすることができます。 騎士のように動くことができます。つまり、オフセット (2,1)、(1,2) とその符号のバリエーションを持つ 8 つの標準的な L 字型パターンのいずれかでジャンプします。 あるいは、ビショップのように移動することもできます。つまり、y = x または y = -x の線に沿って、単一の対角方向に任意の数のステップを移動できます。 

それぞれの動きは自由に選択できるため、各ステップでナイト ジャンプを使用するか、任意の長さの斜めスライドを使用するかを決定できます。 目標は、開始座標からターゲット座標に移動するために必要な移動の数を最小限に抑えることです。 

座標の大きさは 10^9 に達する可能性があるため、グリッドを探索したりパスを段階的にシミュレートしようとするソリューションは直ちに実行不可能になります。 グラフは無限であり、分岐係数は自明ではないため、ポジションにわたる BFS さえも不可能です。 答えは 2 点の幾何学的特性のみに依存する必要があります。 

重要な微妙な点は、ビショップの移動が非常に強力であることです。これにより、任意の長さの対角線に沿って瞬時に移動できます。 これは、開始と終了が同じ対角線上にある場合、答えは自明のことながら 1 であることを意味します。 2 番目の微妙なケースは、ナイトの移動だけで十分な場合に発生します。これは、1 回の移動でのナイトの到達可能性は、相対オフセットの小さな固定セットに依存するためです。 最後に、ナイトとビショップのどちらの動きでも十分ではないが、2 つの動きの組み合わせで十分な状況があります。 

調整条件を注意深く確認せずに、2 つの移動タイプを組み合わせると常に 1 つまたは 2 つの移動のいずれかに減少すると考えるのは単純な間違いです。 たとえば、ナイトが 1 回移動するだけ離れた点が対角線上にあるとは限りません。また、対角線上にある点はマンハッタン距離では遠く離れていても、ビショップの 1 回の移動で到達できる可能性があります。 

## アプローチ

 ブルートフォース解釈では、各位置をグラフ内のノードとして扱い、最短経路検索を実行しようとします。 ビショップは対角線上の任意の点にジャンプできるため、どのノードからも 8 つのナイト エッジと無限に多くのビショップ エッジが存在します。 問題を離散化したとしても、状態空間には制限がなく、遷移は管理できません。 各ノードは無限に多くの他のノードに接続されるため、ビショップの移動による分岐要素だけではこれが不可能になります。 

重要な点は、最適なパスには少数の移動しか必要としないということです。 各移動は、対角不変式を保持するか (ビショップ)、固定された境界付きオフセットのセット内で移動します (ナイト)。 このため、最短パスは 3 つのカテゴリのいずれかに分類される必要があります。点が一致する場合は 0 回の移動、ナイトの移動またはビショップの移動によって直接接続されている場合は 1 回の移動、それ以外の場合は常に 2 回の移動で十分です。 

常に 2 つの手で十分である理由は、グリッドの形状に由来します。 ナイトの動きはパリティ構造と相対的な位置を制限された方法で変更でき、ビショップの動きは対角線を任意に再調整できます。 ナイトの直接の移動もビショップの直接の移動も機能しない場合は、いつでも最初に 1 つの移動を使用して、ビショップの移動で旅が完了する構成に身を置くことができます。逆も同様です。 どちらの技タイプも異なる次元で非常に表現力豊かであるため、それらの組み合わせにより残りのすべてのケースがカバーされます。 

したがって、問題は、いくつかの一定時間の幾何学的条件をチェックすることに帰着します。

 ## アルゴリズムのチュートリアル

開始を (x1, y1) として表し、ターゲットを (x2, y2) として表します。 相対変位 dx = |x2 - x1| を完全に処理します。 dy = |y2 - y1|。 

1. まず、スタートとターゲットが一致しているかどうかを確認します。 dx = 0 および dy = 0 の場合、移動は必要ありません。 これは、どの動きでも位置が変わるため、答えがゼロになる唯一の状況です。 
2. 次に、ターゲットが 1 回のビショップ移動で到達可能かどうかを確認します。 ビショップの移動は、同じ対角線上にある任意の点に到達できます。これは、dx = dy を意味します。 これが機能するのは、対角線に沿って移動すると、座標間の絶対的な差が保持されるためです。 
3. 次に、単一のナイトの動きでターゲットに到達できるかどうかを確認します。 ナイトの動きには正確に 8 つの可能な変位パターンがあるため、ペア (dx, dy) が (1,2)、(2,1)、(2,0)、(0,2) のいずれかに一致するかどうかを検証します。標準的なナイトの動きでは実際には有効ではありません。したがって、符号の対称性は絶対値で処理されるため、問題となるのは (1,2) と (2,1) だけです。 
4. 上記の条件がいずれも当てはまらない場合、答えは 2 です。その理由は、最初にナイトの動きを使用して、ビショップの動きを介してターゲットに斜めに並ぶか直接一致するポジションに移動できるため、どのポジションでも常に最大 2 つの動きで到達できるということです。 

### なぜ効果があるのか

 ソリューション全体は、両方の移動タイプが非常に大規模な到達可能性セットを定義するという事実に依存しています。 ビショップの移動は 1 ステップで対角線全体をカバーしますが、ナイトの移動はパリティ制約を破り、ビショップが到達できない座標クラス間を移動する可能性があります。 これら 2 つの変換は相補的であるため、ポイントのペアはいずれか 1 つによって直接接続されるか、1 つの中間位置を使用してブリッジすることができます。 1 つのローカル有界ジャンプと 1 つのグローバル対角スイープの組み合わせが整数格子全体に及ぶため、3 つ以上の移動を必要とする構成はありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_knight(dx, dy):
    return (dx, dy) in {(1, 2), (2, 1)}

def solve():
    x1, y1, x2, y2 = map(int, input().split())
    dx = abs(x1 - x2)
    dy = abs(y1 - y2)

    if dx == 0 and dy == 0:
        print(0)
        return

    if dx == dy:
        print(1)
        return

    if is_knight(dx, dy):
        print(1)
        return

    print(2)

if __name__ == "__main__":
    solve()
```実装は、座標を読み取り、絶対差を使用して問題を純粋に相対的な形式に変換することから始まります。 これにより方向性が取り除かれ、大きさについてのみ推論できるようになります。 

最初の条件は、移動が必要ない縮退ケースを処理します。 2 番目の条件は対角線の配置をチェックします。これは 1 回の移動でのビショップの到達可能性に正確に対応します。 3 番目の条件は、ナイト オフセットの有限セットをテストします。 他のすべては 2 つの動きのカテゴリに分類され、結合された動きの構造によって保証されます。

 ## 特殊なケース

 開始と終了が同一の場合は、移動カウントがゼロになる唯一の状況です。 アルゴリズムは幾何学的チェックの前に明示的に処理するため、(7, -3) から (7, -3) などの入力に対して 0 を正しく出力します。 

ナイト隣接の場合は、正確なオフセットに依存します。 たとえば、(0,0) から (2,1) は、絶対値を取得した後の有効なナイト ディスプレイスメントと一致するため、受け入れられます。 アルゴリズムはこれを固定セットと照合してチェックするため、無効なオフセットが誤って含まれることはありません。 

対角線の場合は、(10^9, 10^9) などの任意の大きな距離を処理し、それらを 1 つのビショップの動きに正しく集約します。 絶対差分の等しいかどうかが直接チェックされるため、オーバーフローや近似の問題は発生しません。 

残りのケースは自動的に 2 つの手になります。 たとえば、(0,0) から (3,4) はナイト移動ではなく、対角線でもないため、明示的なパス構築を必要とせずに正しく分類されます。
