 ## 解決策
 ## 問題の理解

 盗難後、納屋には干し草のブロックが入った小さな長方形の箱が入っていました。 元の寸法が$A \times B \times C$、残りの山には寸法があります$(A-1) \times (B-2) \times (C-2)$。 残りのブロックの数のみが与えられます。$$n = (A-1)(B-2)(C-2)$$タスクは、盗まれたブロックの最小数と最大数を回復することです。 

元のブロック数は次のとおりです。$$ABC$$したがって、盗まれた番号は次のとおりです。$$ABC - n$$未知数は元の次元です$A, B, C$しかし、次のように導入すると、方程式はより明確になります。$$x = A-1,\quad y = B-2,\quad z = C-2$$それから：$$xyz = n$$そして：$$A = x+1,\quad B = y+2,\quad C = z+2$$盗まれた数は次のようになります。$$(x+1)(y+2)(z+2) - xyz$$さて、問題は純粋に算術です。 あらゆる因数分解を調べなければなりません$n$3 つの正の整数に変換します。 

制約$n \le 10^9$までのすべてのトリプルの反復に近いものを即座に除外します。$n$。 3次探索は不可能であり、2次探索ですら遅すぎます。 唯一実行可能な方向は、除数を利用することです。 以来$10^9$約数が最大でも数千個ある場合、因数の組み合わせを列挙することは可能です。 

簡単な間違いの 1 つは、それを忘れることです$x,y,z$すべてがポジティブである必要があります。 たとえば、次の場合$n=1$、有効な因数分解は次のとおりです。$$1 = 1 \cdot 1 \cdot 1$$これは以下に相当します:$$A=2,\ B=3,\ C=3$$盗まれた金額は次のとおりです。$$18 - 1 = 17$$ゼロの約数または負の次元を許可する不注意な実装では、不可能なボックスが生成されます。 

もう 1 つの微妙な問題は、因数分解の重複です。 のために$n=4$、トリプル$(1,1,4)$、$(1,4,1)$、 そして$(4,1,1)$置換後のすべては同じ幾何学的構成を表します。 重複を再チェックすることは、正確さに関しては無害ですが、実装が不十分な場合は時間を無駄にする可能性があります。 

オーバーフローは、32 ビット整数を使用する言語にも関連します。 仮定する$n=10^9$。 元のボックスの寸法はそれよりわずかに大きくなる可能性があります$10^9$、それらを乗算すると 32 ビットの範囲を超える可能性があります。 Python はこれを自動的に処理しますが、C++ ソリューションでは 64 ビット整数を使用する必要があります。 

## アプローチ

 直接的な総当たりのアイデアは、可能なすべてのトリプルを試すことです$(x,y,z)$次のような:$$xyz=n$$有効なトリプルごとに、以下を計算します。$$(x+1)(y+2)(z+2)-n$$最小値と最大値の回答を更新します。 

問題は、トリプルをどのように列挙するかです。 素朴にすべての値を試してみると、$1$に$n$各変数の複雑さは次のようになります。$$O(n^3)$$それはまったく不可能です$n=10^9$。 

最初の改善点は、次のことを観察することです。$x,y,z$分けなければなりません$n$。 任意の整数をチェックする代わりに、約数のみを検査します。 

選択するとします$x$。 それから$x$分けなければなりません$n$。 固定後$x$、残りの製品は次のとおりです。$$yz = \frac{n}{x}$$ここで必要なのは約数だけです$\frac{n}{x}$。 これにより、検索が 3 次から除数の列挙に減ります。 

重要な洞察は、約数はペアで存在するため、平方根まで反復するだけでよいということです。 あらゆる約数について$x$の$n$、約数を反復処理します$y$の$\frac{n}{x}$を決定し、以下を決定します。$$z = \frac{n}{xy}$$直接。 

除数チェックの合計数は少ないままです。$10^9$には有限の約数があります。 平方根までの反復処理は 1 秒以内で十分高速です。

 | ブルートフォース |$O(n^3)$|$O(1)$| 遅すぎる |
 | 最適 |$O(\sqrt{n} \cdot \sqrt{n/x})$最悪の場合について$O(n)$ですが、除数フィルタリングにより実際には非常に小さいです。$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る$n$。 
2. 最小の応答を非常に大きな数値で初期化し、最大の応答をゼロで初期化します。 
3. すべての整数を反復処理します。$x$から$1$に$\lfloor \sqrt{n} \rfloor$。 
4. もし$x$分けない$n$、スキップしてください。$x$～の因数である必要があります$n$。 
5. 次のようにしましょう。$$m = \frac{n}{x}$$ここで、すべての因数分解が必要になります。$$yz = m$$1. すべての整数を反復処理する$y$から$1$に$\lfloor \sqrt{m} \rfloor$。 
2. もし$y$分けない$m$、スキップしてください。 
3. 以下を計算します。$$z = \frac{m}{y}$$今$(x,y,z)$は有効な因数分解です$n$。 

1. 元の寸法を復元します。$$A=x+1,\quad B=y+2,\quad C=z+2$$1. 盗難数を計算します。$$A \cdot B \cdot C - n$$1. 最小回答と最大回答を更新します。 
2. すべての因数分解が処理された後、2 つの答えを出力します。 

### なぜ効果があるのか

 残りの有効なボックスはすべて、正の整数の 1 つのトリプルに正確に対応します。$(x,y,z)$満足のいく：$$xyz=n$$なぜなら：$$x=A-1,\quad y=B-2,\quad z=C-2$$逆に、すべての正の因数分解は、$n$有効な元のボックスを生成します。$$(A,B,C)=(x+1,y+2,z+2)$$アルゴリズムはそのような因数分解をすべて列挙し、それぞれの因数分解の盗難金額を評価します。 有効な構成がスキップされることはなく、チェックされたすべての構成が有効であるため、計算された最小値と最大値は正確です。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    n = int(input())

    mn = 10**30
    mx = 0

    limit_x = int(math.isqrt(n))

    for x in range(1, limit_x + 1):
        if n % x != 0:
            continue

        m = n // x
        limit_y = int(math.isqrt(m))

        for y in range(1, limit_y + 1):
            if m % y != 0:
                continue

            z = m // y

            stolen = (x + 1) * (y + 2) * (z + 2) - n

            mn = min(mn, stolen)
            mx = max(mx, stolen)

    print(mn, mx)

solve()
```外側のループは、可能なすべての値を列挙します。$x=A-1$。 以来$x$分けなければなりません$n$、非除数は直ちに無視されます。 

固定後$x$、残りの製品は次のようになります。$$yz = \frac{n}{x}$$内側のループは約数を列挙します$y$この残りの値を計算してから、$z$直接。 これにより、3 番目のネストされた検索が回避されます。 

盗まれた数の式は、数学的に導出されたとおりに正確に実装されます。$$(x+1)(y+2)(z+2)-n$$置換に対する特別な処理は必要ありません。 異なる順列でも同じ答えが得られる場合がありますが、重複しても最小値や最大値には影響しません。 

使用する`math.isqrt`平方根を計算する際の浮動小数点の不正確さを回避します。 これは使用するより安全です`int(n ** 0.5)`。 

初期化:```
mn = 10**30
```最初の有効な構成が最小値を正しく更新することを保証します。

import sys
import io
import math

def solve():
    input = sys.stdin.readline

    n = int(input())

    mn = 10**30
    mx = 0

    for x in range(1, math.isqrt(n) + 1):
        if n % x != 0:
            continue

        m = n // x

        for y in range(1, math.isqrt(m) + 1):

    print(mn, mx)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()

    backup = sys.stdout
    sys.stdout = out

    solve()

    sys.stdout = backup

    return out.getvalue().strip()
