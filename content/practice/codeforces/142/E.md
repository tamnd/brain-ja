 ## 解決策
 ## 問題の理解

 円錐上の 2 点間の最短距離を見つけるように求められます。この円錐は、半径 _r_、高さ _h_ の円形の底面を持ち、点は円錐の側面または底面のどこにでも配置できます。 入力により、3D 空間内のこれらの点の座標が得られます。円錐の頂点は次のとおりです。`(0, 0, h)`そしてベースの中心は`(0, 0, 0)`XY 平面上で。 出力は、円錐の表面または底面に沿った最小パスを表す単一の浮動小数点数です。 

制約`1 ≤ r, h ≤ 1000`浮動小数点計算が実行可能であり、整数のオーバーフローを心配する必要がないことを示しています。 ポイントは、円錐の表面に非常に近く、範囲内にあることが保証されます。`10^-12`、したがって、それらは事実上コーンまたはベース上にあると想定できます。 円錐の表面は直円錐と考えることができ、最短経路は底面を横切る直線、側面に直接沿った直線、または「展開された」側面に沿った直線のいずれかになります。 

両方の点がベース上にある場合、微妙なエッジ ケースが発生します。 常に円錐を展開する単純な実装では、単に XY 平面で直線を取るよりも長いパスが計算されます。 もう 1 つのエッジ ケースは、一方または両方の点が頂点にある場合に発生します。 ここで、最短経路は側面に沿って頂点に直接到達する可能性があります。 慎重に処理するには、円錐の形状と平面ベースを考慮する必要があります。 

## アプローチ

 強引なアプローチは、細かいメッシュで表面を近似し、メッシュに沿った最短パスを計算することですが、これは非効率的です。 それには必要です`O((r * h / ε)^2)`解決のための操作`ε`、滑らかなジオメトリを考慮すると、これは不要です。 

重要な洞察は、円錐を「展開」することによって、円錐の側面に沿った最短経路を 2D の直線問題に変換できるということです。 頂点から底部までの線に沿って円錐を切り、平らに置くと、側面は傾斜の高さに等しい半径を持つ円の扇形になります。`l = sqrt(r^2 + h^2)`と角度`θ = 2π * r / l`。 次に、サーフェスに沿った最短パスは、この展開されたセクター内の直線にマップされます。 ベース上の点については、XY 平面内のユークリッド距離も直接チェックします。 

したがって、このアプローチでは、3 つの候補距離を計算します。つまり、底面に沿った直線、展開された側面上の直線距離、および 1 つの点が底面上にあり、もう 1 つの点が側面上にある場合の組み合わせです。 これらの最小値が答えになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース メッシュ | O((r*h/ε)^2) | O((r*h/ε)^2) | 遅すぎる |
 | 展開された円錐のジオメトリ | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ベース半径を読み取ります。`r`そして高さ`h`円錐の座標と点の座標`p1`そして`p2`。 
2. 両方の点がベース上にあるかどうかを確認します (z 座標 ≈ 0)。 その場合、XY 平面内のユークリッド距離を次のように計算します。`sqrt((x2-x1)^2 + (y2-y1)^2)`。 これにより、平面的なエッジ ケースが効率的に処理されます。 
3. 円錐の傾斜高さを計算します。`l = sqrt(r^2 + h^2)`。 これは、円錐を展開するときに形成される扇形の半径です。 
4. 点を 3D 座標からベース上の極座標にマッピングします: 半径を計算します`ρ = sqrt(x^2 + y^2)`と角度`φ = atan2(y, x)`。 側面上の点の場合、傾斜の高さに比例して半径をスケールします。`s = l * ρ / r`。 
5. 展開されたセクターで、デカルト座標に変換された極座標を使用して点間のユークリッド距離を計算します。`x' = s * cos(φ * l / r)`、`y' = s * sin(φ * l / r)`。 
6. 必要に応じて、頂点から点までの距離を計算します。`sqrt((x1)^2 + (y1)^2 + (z1)^2)`。 
7. ベースに沿った距離と展開された表面に沿った距離の最小値を取得します。 これが最短の道です。 
8. 結果を少なくとも 9 桁の精度で出力します。 

これが機能する理由は、展開により側面上の直線に沿った距離が維持されるためです。 セクター内の 3D 座標から極座標へのマッピングは円錐の曲率を捉えており、展開された平面内の距離式は真の表面距離を正確に表します。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def main():
    r, h = map(float, input().split())
    x1, y1, z1 = map(float, input().split())
    x2, y2, z2 = map(float, input().split())
    
    # Distance along base if both on base
    if abs(z1) < 1e-12 and abs(z2) < 1e-12:
        dx = x2 - x1
        dy = y2 - y1
        print("%.9f" % math.hypot(dx, dy))
        return

    # Slant height
    l = math.hypot(r, h)
    
    def map_to_unfold(x, y, z):
        # radial distance on base
        rho = math.hypot(x, y)
        phi = math.atan2(y, x)
        # scale to slant height
        s = l * rho / r
        theta = phi * l / r
        return (s * math.cos(theta), s * math.sin(theta))
    
    p1u = map_to_unfold(x1, y1, z1)
    p2u = map_to_unfold(x2, y2, z2)
    
    dx = p2u[0] - p1u[0]
    dy = p2u[1] - p1u[1]
    d = math.hypot(dx, dy)
    
    print("%.9f" % d)

if __name__ == "__main__":
    main()
```コードは、パスが過度に複雑になるのを避けるために、最初に平面の基本ケースを明示的に処理します。 3D ポイントを展開された 2D セクターにマッピングすることは、傾斜の高さに沿って比例して行われます。 の`atan2`展開平面内で角度が正しく配向されていることを確認します。 ついに、`hypot`ユークリッド距離を堅牢に計算します。
