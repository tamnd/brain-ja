 ## 問題の理解

 辺の長さが与えられます`n`正方形の。 正方形には次のすべての整数が含まれている必要があります。`1`を通して`n²`すべての行、すべての列、および両方の主対角の合計が同じになるように、正確に 1 回だけ実行します。 必要な出力は、平方そのものではなく、その共通の合計のみです。 このサイズの通常の魔方陣が存在しない場合は、次のように印刷します。`FAIL`。 

重要な違いは、実際に正方形を構築する必要がないことです。 有効な正方形が存在すると、その共通の合計が強制されます。 すべての値の合計`1`に`n²`です

 [
 1+2+\dots+n^2=\frac{n^2(n^2+1)}2.
 ]

がある`n`行があり、各行の合計は同じです`m`、したがって合計も`n*m`。 2 つの式を等価すると、次のようになります。 

[
 n m = \frac{n^2(n^2+1)}2,
 】

 したがって

 [
 m=\frac{n(n^2+1)}2.
 】

 残りの問題は、これに対して通常の魔方陣が存在するかどうかだけです。`n`。 古典的な存在定理は、通常の魔方陣がすべての正の次数に対して存在することを示しています。`n = 2`。 注文`1`正方形は単純に`[1]`、奇数次数にはシャム法などの標準的な構造があり、偶数次数には次数が含まれます。`n >= 4`二重および単一の偶数注文に対応する標準構造も用意しています。 したがって、指定された範囲内で唯一不可能な入力は次のとおりです。`2`。 

制約`n <= 1000`これを特に簡単にします。 たとえ`O(n²)`要求された答えは次のもののみに依存するため、構築する必要はありません。`n`。 定数時間式が好ましく、行列をまったく使用しません。 

誤って扱いやすいエッジケースが 2 つあります。 入力用`1`不注意な実装では、魔方陣には少なくとも 3 行が必要であると想定して出力する可能性があります。`FAIL`、 しかし`[1]`は有効であり、答えは`1`。 入力用`2`、式は次のようになります`5`ただし、その番号を出力してはなりません。`2 × 2`通常の魔方陣は存在しません。 The four numbers would have to be arranged so that all four line sums agree, which is impossible.

1
```入力中`2`生成されるもの:```
FAIL
```最初のケースは、行、列、対角線のみに数値が含まれているため有効です。`1`。 2 番目のケースは、式の計算だけでは不十分である理由を示しています。 

## アプローチ

 直接的な総当たりアプローチでは、数字のあらゆる配置が試行されます。`1`を通して`n²`、次に、結果の正方形の行、列、および対角の合計が等しいかどうかを確認します。 がある`(n²)!`可能な手配を確認し、1 つの手配を確認するのに時間がかかります`O(n²)`簡単な実装で時間を節約できます。 したがって、最悪の場合の複雑さは次のようになります。`O(n² * (n²)!)`。 たとえ`n = 3`、これはすでに以下までチェックすることを意味します`9! = 362880`手配や、`n = 4`番号は になります`16!`、これはすでに実用的な列挙をはるかに超えています。 

ブルートフォース手法は、可能な正方形の空間全体を明示的に検索するため機能しますが、その検索は裁判官が尋ねた問題よりもはるかに難しい問題を解決しています。 配置を出力するように求められるのではなく、その共通線の合計のみを出力するように求められます。 

重要な観察は、共通合計がすべてのエントリの合計によって完全に決定されるということです。 すべての有効な正方形はまったく同じ数値を使用するため、その合計は固定されます。 以来、`n`行の合計が等しいので、合計を で割ります。`n`すぐに決める`m`。 通常の魔方陣については、既知の存在条件を確認するだけで済みます。 

これにより、問題は 1 つの特殊なケースと 1 つの算術式に減ります。 のために`n = 2`、印刷`FAIL`。 他のすべてのポジティブについて`n`、印刷`n * (n² + 1) / 2`。

 ## アルゴリズムのチュートリアル

 1.辺の長さを読み取る`n`。 入力には 1 つの正方形サイズのみが含まれるため、追加のデータ構造は必要ありません。 
2. もし`n == 2`、印刷`FAIL`そしてやめてください。 通常の 2 次の魔方陣は存在しません。 
3. それ以外の場合は、正方形内のすべての値の合計を計算します。 エントリは正確なので、`1`を通して`n²`、この合計は`n²(n² + 1) / 2`。 
4. その合計を`n`行の合計が等しい。 結果として得られる値は唯一可能な魔法の定数です。 

[
 m=\frac{n(n^2+1)}2.
 】

 1. 印刷`m`。 あらゆる人にとって`n != 2`、通常の魔方陣が存在するため、この強制値は実際に達成可能です。 

### なぜ効果があるのか

 有効な正方形が存在すると仮定します。 その`n²`セルには以下のすべての整数が含まれます。`1`に`n²`したがって、すべてのセルの合計は次のように固定されます。`n²(n²+1)/2`。 同時に、セルを次のように分割できます。`n`それぞれの行に合計が含まれる`m`、つまり、それらの合計は`n*m`。 これら 2 つの合計は等しくなければなりません。`m = n(n²+1)/2`。 通常の魔方陣が存在しない唯一の正の順序は次のとおりです。`2`したがって、存在と不可能を区別するには、1 つの順序をチェックするだけで十分です。
