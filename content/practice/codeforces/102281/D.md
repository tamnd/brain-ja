 ## 問題の理解

 三次元空間には 3 つの点があります。 最初の点は宇宙船とレーザー砲の位置、2 番目は敵の球形宇宙船の中心とその半径、3 番目は照準システムによって選択された点です。 

レーザーは選択した点で停止しません。 選択した点はその方向のみを決定するため、ショットは宇宙船から始まりターゲット点を通過する無限の光線になります。 この光線が球体と交差するか接触すると、敵は破壊されます。 

2 つのことを出力する必要があります。 最初の行は、光線が球に当たるかどうかを示します。 2 行目は、球の中心から光線の任意の点までの最小ユークリッド距離を示します。 

すべての座標は -1000 ～ 1000 の間にあり、半径は最大 1000 です。幾何学的構成は 1 つだけであるため、入力サイズによって漸近的な課題が生じることはありません。 1.5 秒の制限は、定数時間の演算には十分以上ですが、多数のサンプル ポイントでレイを近似する理由がないことも意味します。 Python の整数は、座標の差が最大 2000 であり、その二乗が数百万程度にすぎないため、すべての中間二乗距離を快適に処理できます。 

主なエッジケースは、レーザーショットが無限の線ではなく光線であるという事実から生じます。 無限線上の最も近い点は大砲の後ろにある可能性があり、その場合、レーザーは到達できません。 

例えば、```
0 0 0
-2 0 0 1
1 0 0
```生成する```
MISS
2.000000000000000
```敵の中心は x = -2 にあり、レーザーは正の x 方向に進みます。 中心から無限の X 軸までの距離はゼロですが、実際の光線の最も近い点は距離 2 にある大砲自体です。常に点から線までの距離を計算するソリューションでは、誤って命中が報告されてしまいます。 

接線性もヒットとしてカウントされる必要があります。 例えば、```
0 0 0
5 1 0 1
10 0 0
```生成する```
HIT
1.000000000000000
```光線は正の x 軸であり、球の中心は光線からちょうど 1 単位離れています。 レーザーは球体に触れるので、次のような厳密な比較を使用します。`distance < r`誤って生成してしまう`MISS`。 

球が光線上に直接ある場合も、境界条件の 1 つです。 例えば、```
0 0 0
5 0 0 2
1 0 0
```の距離はゼロなので、答えは次のようになります。`HIT`。 正規化された方向ベクトルに基づく式では、ゼロによる除算も回避する必要がありますが、このステートメントではターゲットが大砲とは異なることが保証されているため、方向ベクトルがゼロになることはありません。 

## アプローチ

 単純な幾何学的シミュレーションでは、多くのサンプル ポイントで光線を表現し、それらのポイントを次々に検査できます。 整数の座標境界は、これが間違った抽象化である理由を確認するのに役立つ上限を提供します。 ターゲットが大砲と異なる場合、方向ベクトルの 2 乗の長さは少なくとも 1 になります。敵の中心の光線方向への射影パラメータは、内積が最大 (3 \cdot 2000 \cdot 2000) であるため、絶対値で最大 6000 になりますが、方向の 2 乗の長さは少なくとも 1 です。 

このパラメータの (10^{-6}) 単位ごとに光線を検査しようとしたとします。 最悪の場合、およそ 6,000,001 件の評価が必要になりますが、そのようなサンプリングは依然として正確な幾何学的テストではなく数値近似です。 ステップを小さくすると、演算数が悪化するだけです。 

光線は連続オブジェクトであるため、総当たりのアイデアは失敗します。 球までの距離がベクトル代数で直接表現できる場合、個々の点を調べる有効な理由はありません。 

重要な観察は、光線のすべての点が次のような形をしていることです。 

[
 S + tV、\qquad t \ge 0、
 】

 ここで、(S) は大砲の位置、(V=T-S) はターゲットによって決定される方向です。 この点から敵の中心 (E) までの二乗距離を最小化する必要があります。 

(W=E-S) とします。 (E) から (S+tV) までの二乗距離は次のようになります。 

[
 f(t)=|W-tV|^2。 
】

 展開すると得られる

 [
 f(t)=|W|^2-2t(W\cdot V)+t^2|V|^2。 
】

 これは (t) の二次関数です。 制約のない最小値は次の時点で発生します。 

[
 t_0=\frac{W\cdot V}{|V|^2}。 
】

 唯一の制限は (t\ge0) です。 (t_0\ge0) の場合、最も近い点は光線の内側にあるため、通常の点と線の距離は正しいです。 (t_0<0) の場合、無限直線の最も近い点は大砲の後ろにあり、最も近い到達可能な点は (S) になります。 

これにより、問題全体がいくつかの内積と二乗長に縮小されます。

 ## アルゴリズムのチュートリアル

 1. 大砲の位置 (S)、敵の中心 (E)、半径 (r)、目標点 (T) を読み取ります。 方向ベクトル (V=T-S) を構築します。 大砲が決して自分自身を撃たないという保証は (V\ne0) を意味するため、その 2 乗の長さは正になります。 
2. 大砲から敵の中心までのベクトル (W=E-S) を作成します。 内積 (p=W\cdot V) と 2 乗方向の長さ (q=V\cdot V) を計算します。 
3. (p) の符号を確認します。 (q>0) であるため、(p/q) の符号は最適パラメータ (t_0) の符号と正確​​に一致します。 
4. (p<0) の場合、無限線上への敵の中心の垂直投影は大砲の後ろにあります。 実際の光線の最も近い点は大砲自体になるため、必要な距離は (|W|) になります。 
5. (p\ge0) の場合、垂直投影は光線上にあります。 最小二乗距離は

 [
 |W|^2-\frac{p^2}{q}。 
】

 ヒット テストでは、平方根を取ることを避けることができます。 距離が最大(r)である条件は、

 [
 |W|^2-\frac{p^2}{q}\le r^2。 
】

 正の値 (q) を掛けると、

 [
 |W|^2q-p^2\le r^2q。 
】

 この比較におけるすべての量は整数であるため、浮動小数点エラーなしでヒットの決定を行うことができます。 

1. 実際の距離を浮動小数点値として計算し、十分な桁数で出力します。 投影の場合は、上記の非負の値の平方根を使用します。 大砲の後ろの場合は、(\sqrt{|W|^2}) を使用します。 
2. 印刷`HIT`計算された幾何学的距離が、正確な接線を含む半径以下の場合。 それ以外の場合は印刷します`MISS`。 

### なぜ効果があるのか

 不変条件は、選択されたパラメータ (t) が常に敵の中心に最も近い到達可能な光線の点を表すということです。 (t^2) の係数は (V\cdot V>0) であるため、二次距離関数には制約のない最小値が 1 つだけあります。 その最小値が (t\ge0) を持つとき、それは光線に属します。 (t<0) の場合、二次方程式は許容区間 (t\ge0) 全体で増加するため、境界 (t=0) で最小値が発生します。これが大砲です。 

したがって、アルゴリズムは中心から光線までの正確な最小距離を計算します。 球は、この距離が半径以下のときに正確に交差または接触しているため、報告される`HIT`または`MISS`決断は正しい。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    xs, ys, zs = map(int, input().split())
    xe, ye, ze, r = map(int, input().split())
    xt, yt, zt = map(int, input().split())

    vx = xt - xs
    vy = yt - ys
    vz = zt - zs

    wx = xe - xs
    wy = ye - ys
    wz = ze - zs

    dot = wx * vx + wy * vy + wz * vz
    vv = vx * vx + vy * vy + vz * vz
    ww = wx * wx + wy * wy + wz * wz

    if dot < 0:
        dist2 = float(ww)
        hit = ww <= r * r
    else:
        cross2 = ww * vv - dot * dot
        dist2 = cross2 / vv
        hit = cross2 <= r * r * vv

    distance = math.sqrt(dist2)

    print("HIT" if hit else "MISS")
    print(f"{distance:.15f}")

if __name__ == "__main__":
    solve()
```最初の部分の構成`v`、光線の方向、および`w`、大砲から敵の中心までのベクトル。 これらはまさに数学的導出に使用されるベクトルです。`dot`(W\cdot V) を格納しますが、`vv`店舗 (|V|^2)。 大砲とは対象が異なりますので、`vv`厳密にポジティブです。`ww`大砲から敵の中心までの二乗距離を保存します。 

いつ`dot < 0`、突起は大砲の後ろにあります。 したがって、コードは次を使用します`ww`二乗距離として計算し、(r^2) と直接比較します。 このステートメントは、大砲が敵の球体の外側にあることを保証するため、大砲自体が球体の内側にあるため、このブランチが誤って命中を報告することはありません。 

のために`dot >= 0`、コードは使用します

 [
 |W|^2|V|^2-(W\cdot V)^2
 】

 正規化された点から線までの距離を直接計算する代わりに。 この式は外積の長さの 2 乗 (W\times V) なので、(|V|^2) で除算すると、ラインまでの距離の 2 乗が得られます。 

ヒット比較は、整数を使用して意図的に実行されます。 接線付近での浮動小数点の丸めにより、数学的に正確な等価性が半径よりわずかに上または下の値に変わる可能性があります。 整数の不等式`cross2 <= r * r * vv`接線を正確に処理します。 

最後の平方根のみ浮動小数点演算が必要です。 Python の整数は任意の精度を持ちますが、ここでの実際の値は十分小さいため、通常の 64 ビット整数ですでに十分です。 

出力では小数点以下 15 桁が使用されます。これは、必要な (10^{-6}) 絶対誤差または相対誤差よりも大幅に高い精度です。

 最初の微妙なケースは、敵が大砲の後ろにいる場合です。 考慮する```
0 0 0
-2 0 0 1
1 0 0

 [
 W\cdot V=-2<0.
 】

 距離はゼロで球が当たります。 これは、垂直成分が完全に消失したときに外積定式化が正しく動作することも検証します。
