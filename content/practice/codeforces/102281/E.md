 ## 問題の理解

## アプローチ

 直接的な総当たりソリューションでは、毎秒複製する可能な限りの数のロボットを試行できます。 あれば`R`1秒の初めにロボットがいます。`R + 1`誰も複製しないから全員を複製するまでの選択肢。 状態空間は非常に急速に拡大します。 どの州にも少なくとも`n + 1`可能な選択肢、深さの探求`t`すでに少なくとも含まれています`(n + 1)^t`スケジュール。 スケジュールの正確な数は、次のように再帰的に記述できます。`S(0, R) = 1`そして`S(t, R) = sum(S(t - 1, R + x))`のために`0 <= x <= R`。 

実際の分岐は人口が増えるにつれて大きくなります。 100 桁を含む数値では、このアプローチはほとんど実現できません。 

ブルート フォースが機能するのは、現在の修復作業と将来のレプリケーションの間で考えられるあらゆるトレードオフを明示的に考慮するためです。 このようなトレードオフが多すぎるため、失敗します。 重要な観察は、残りの固定秒数の間、レプリケーションは早めに実行するほど価値があるということです。 

あると仮定します`R`ロボットとまさに`t`残り数秒、`t >= 2`。 作ったら`x`ロボットは現在の 1 秒間に複製を行い、その後`R - x`ロボットは損傷を即座に修復し、`R + x`ロボットは次のために残る`t - 1`秒。 で修復可能な最大量を再帰的に仮定します。`t - 1`からの秒数`R + x`ロボットは`(R + x) * 2^(t-2)`。 合計は次のようになります`R - x + (R + x) * 2^(t-2)`これは次のように再配置できます`R * (1 + 2^(t-2)) + x * (2^(t-2) - 1)`。 

のために`t >= 2`、の係数`x`は負ではないため、最良の選択は`x = R`。 言い換えれば、少なくとも 2 秒が残っている場合、すべてのロボットはすぐに複製する必要があります。 

これにより簡単な式が得られます。 と`R`ロボットと`t`利用可能な秒数、修復できるダメージの最大数は`R * 2^(t-1)`。 

これは、レプリケーションを積極的に使用し、最後の 1 秒を修復のために残すことで実現できます。 より一般的に言えば、それが分かれば、`m <= n * 2^(t-1)`、最初のものを作ることができます`t - 1`秒間の純粋なレプリケーション。 その時点ではまさに`n * 2^(t-1)`ロボット。 最後の 1 秒では、残りのロボットが同じになるように、複製するのに十分な数のロボットを正確に選択します。`m`。 したがって、すべて`m`ダメージは正確に修復されます。 

問題は最小値を見つけることになりました`t`満足のいく`n * 2^(t-1) >= m`。 

二分探索も必要ありません。 から始まる`capacity = n`そして`t = 1`、繰り返し倍増`capacity`そして増加します`t`それまで`capacity >= m`。 以来`m <= 10^100`、これには数百回の反復しかかかりません。

 ## アルゴリズムのチュートリアル

 1.読む`n`そして`m`任意精度の整数として。 もし`m = 0`、船はすでに修理されているので、設定します`t = 0`コマンドは出力されません。 
2. もし`n = 0`その間`m > 0`、出力`IMPOSSIBLE`。 損傷を修復したり、別のロボットを作成したりできるロボットはありません。 
3. それ以外の場合は、次から始めます`t = 1`そして`capacity = n`。 ここ`capacity`最後の 1 秒間に修復を実行できるロボットの最大数を表します。`t`-2番目に最適なスケジュール。 
4. ながら`capacity < m`、ダブル`capacity`そして増加します`t`。 1 秒追加されるごとに、最終修理秒間で利用できるロボットの数が 2 倍になるため、容量は次のようになります。`n * 2^(t-1)`。 
5. 最初の`t - 1`秒は純粋なレプリケーションです。 最初のそのような2番目のすべての間に`n`ロボットは次のすべての過程で複製します`2n`ロボットが複製すると、すべてが複製されます`4n`ロボットは複製するなど。 したがって、レプリケーションコマンドは次のようになります。`n, 2n, 4n, ...`。 
6. 最後の 1 秒の始まりには、`capacity`ロボット。 私たちはまさにそれを望んでいます`m`残りの損傷をロボットが修復するので、正確に`capacity - m`ロボットは複製する必要があります。 したがって、最後のコマンドは次のようになります。`capacity - m`。 
7. 出力`t`そして結果として得られるシーケンス。 すべてのコマンドは 0 から現在存在するロボットの数までの間にあるため、スケジュールは物理的に有効です。 

### なぜ効果があるのか

 不変条件は次のとおりです`k`初期レプリケーション秒数、ロボットの数は正確に`n * 2^k`。 上記の繰り返しは、任意の固定秒数において、少なくとも 2 秒が残っているときは常に、現在の秒間で利用可能なすべてのロボットを複製させることが最適であることを証明しています。 したがって、今後の予定はありません`t`数秒で以上の修復が可能`n * 2^(t-1)`損害賠償。 アルゴリズムは最小のものを選択します`t`この上限に達するまで`m`したがって、これより小さい答えは存在しません。 構築されたスケジュールは正確に到着します`m`最後の 1 秒だけを調整して修復することで、実現可能性と最適性の両方が証明されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    if m == 0:
        print(0)
        return

    if n == 0:
        print("IMPOSSIBLE")
        return

    t = 1
    capacity = n

    while capacity < m:
        capacity *= 2
        t += 1

    commands = []
    robots = n

    for _ in range(t - 1):
        commands.append(robots)
        robots *= 2

    commands.append(robots - m)

    print(t)
    print(*commands)

if __name__ == "__main__":
    solve()
```最初の 2 つの条件は、2 倍化が発生する前に 2 つのゼロのケースを処理します。 損傷がない場合は、0 秒が最適です。 損傷があってもロボットがない場合、複製も修復も不可能です。 

ループは維持します`capacity = n * 2^(t-1)`。 最初の値で停止します`t`最終修理の 2 番目には、すべての損傷をカバーするのに十分なロボットが配備されています。 Python の整数は、次の値を含むすべての中間値を正確に表すことができます。`10^100`。 

コマンドの構造はその証拠を反映しています。`robots`現在の 2 番目より前のロボットの数です。 最初のそれぞれについて`t - 1`秒間、すべてのロボットが複製されるため、コマンドは次のようになります。`robots`そして人口は倍増します。 

最後の瞬間に、`robots`等しい`capacity`。 印刷`robots - m`これは、これだけ多くのロボットが複製し、正確に残すことを意味します。`m`修理するロボット。 この最後の減算は、すべてのレプリケーション コマンドに対して単純にゼロを出力できない理由でもあります。 スケジュールでは、実際に存在する以上の損傷を修復してはなりません。 

のために`t = 1`、レプリケーション プレフィックスを生成するループは 0 回実行されます。 唯一のコマンドは次のようになります`n - m`、これは正しいです。`n - (n-m) = m`ロボットは 1 秒以内に修復します。

import sys
import io

def solve_io(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        n, m = map(int, sys.stdin.readline().split())

        if m == 0:
            print(0)
            return sys.stdout.getvalue()

        if n == 0:
            print("IMPOSSIBLE")
            return sys.stdout.getvalue()

        while capacity < m:
            capacity *= 2
            t += 1

        commands = []
        robots = n

        for _ in range(t - 1):
            commands.append(robots)
            robots *= 2

        commands.append(robots - m)

        print(t)
        print(*commands)

        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

def run(inp: str) -> str:
    return solve_io(inp)
