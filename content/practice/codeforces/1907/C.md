 ## 解決策
 ## 問題の理解

 小文字の文字列が与えられており、隣接する文字のペアが異なる場合は繰り返し削除できます。 目標は、文字列を可能な限り最小限の長さに短縮することです。 入力は複数のテスト ケースで構成され、それぞれの文字列は最大 200,000 文字であり、すべてのテスト ケースの合計長が 200,000 を超えることはありません。 

これは、二次方程式のアプローチは最大で$n^2 \approx 4 \cdot 10^{10}$最悪の場合、1 秒の制限時間を大幅に超えて操作が行われる可能性があります。 各除去は隣接するキャラクターにのみ影響するため、この問題には強力なローカル特性があり、貪欲またはスタックベースのアプローチを示唆しています。 

エッジ ケースには、繰り返し文字で既に構成されている文字列、交互の文字を含む文字列、長さ 1 または 2 の非常に短い文字列が含まれます。`"aa"`まったく短縮できず、最小長は 2 になりますが、`"ab"`完全に削除でき、結果は 0 になります。任意の順序で文字を削除する不用意な実装は、削除の順序がどの文字が残るかに影響するため、最小値に達しない可能性があります。 

## アプローチ

 ブルートフォース手法では、文字列を左から右に繰り返しスキャンし、最初に見つかった異なる隣接文字のペアを削除してから再開します。 このプロセスは正しいです。許可されているすべての操作で文字列が 2 文字ずつ削減されるためです。ただし、非常に時間がかかります。各パスには時間がかかる場合があります。$O(n)$まであるかもしれません$O(n/2)$削除により、最悪の場合の複雑さが生じます。$O(n^2)$。 のために$n = 2 \cdot 10^5$、これでは遅すぎます。 

最適なアプローチを実現するための重要な洞察は、文字列をスキャンするときに削除操作が最後の不一致文字にのみ依存することに気づくことです。 これは当然、スタックベースの貪欲なソリューションにつながります。つまり、文字列を左から右にトラバースし、文字をスタックにプッシュします。 現在のキャラクターがスタックの一番上と異なる場合、それらは取り外し可能なペアを形成するため、押すのではなく一番上をポップします。 これにより、可能な場合にはすべてのペアの削除が即座に適用され、最終的なスタック長が最小の文字列長を表すようになります。 

ブルート フォースは有効なペアのみを削除するため機能しますが、再スキャンが繰り返されて文字列が長い場合は失敗します。 ローカルな決定を処理するためにスタックを維持できるという観察により、時間の複雑さが軽減されます。$O(n)$各文字がプッシュおよびポップされるのは最大 1 回だけであるためです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | スタックベースの最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 空のスタックを初期化します。 これにより、まだ削除されていない文字が保存されます。 
2. 各文字を反復処理します。`c`文字列の中で。 
3. スタックが空ではなく、先頭の文字が異なる場合`c`、スタックをポップします。 これは、隣接するペアを削除することを表します。 
4. それ以外の場合は、 を押します`c`スタックに。 これはつまり`c`前のキャラでは解除できませんでした。 
5. 文字列を反復処理した後、スタックには、ペアにして削除できなかったすべての文字が含まれます。 文字列の最小の長さはスタックのサイズです。 

機能する理由: 各ステップで、スタックは文字列のプレフィックスの正しい部分解を維持します。 各ポップは、隣接する異なる文字の有効な削除に対応し、スタックは最新の不一致文字とのみ比較されるため、ペアが失われることはありません。 削除はローカルであり、隣接を超えて独立しているため、この貪欲な選択はグローバルに最適です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    
    stack = []
    for c in s:
        if stack and stack[-1] != c:
            stack.pop()
        else:
            stack.append(c)
    print(len(stack))
```説明: 大量の入力を処理するために高速 I/O を使用します。 各キャラクターが一番上のキャラクターと取り外し可能なペアを形成できない場合、スタックにプッシュされます。 スタックの最終的な長さはテスト ケースごとに出力されます。 使用する`strip()`改行が文字比較に干渉しないようにします。 ポップする前に空のスタックが正しくチェックされるため、境界の問題が回避されます。
