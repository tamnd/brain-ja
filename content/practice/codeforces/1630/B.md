 ## 解決策
 ## 問題の理解

 整数の配列が与えられており、タスクは数値範囲を見つけることです。`[x, y]`配列を正確に分割します`k`各サブ配列の要素の半分以上が選択した範囲内に収まるように、連続したサブ配列を作成します。 目標は範囲の幅を最小限に抑えることです。`y - x`。 概念的には、配列を次のように「カバー」しようとしています。`k`各サブ配列の大部分が小さな数値ウィンドウ内にあるサブ配列。 

制約は厳しいです:`n`まで可能です`2·10^5`テストケースごとの合計と`n`すべてのテストケースにわたって、`2·10^5`。 これにより、単純な解法は O(n^2) または O(n^3) となり、実行不可能であるため、すべての可能な範囲またはすべての部分配列を検査する強引なアプローチが排除されます。 テスト ケースごとにおよそ O(n log n) または O(n) のアルゴリズムが必要です。 

エッジ ケースは、配列に繰り返し要素が多数ある場合、または次の場合に発生します。`k`等しい`1`または`n`。 たとえば、すべての要素が等しい場合、範囲は`[x, y]`これは簡単なことではありませんが、不注意なアプローチでは部分配列を誤って分割しようとする可能性があります。 もし`k = n`、各部分配列には単一の要素が含まれるため、範囲にはすべての要素が含まれる必要があります。 もう 1 つの微妙なケースは、最適な範囲に配列内で連続していない要素が含まれており、慎重に分割する必要がある場合に発生します。 

## アプローチ

 ブルートフォースアプローチでは、あらゆる可能性を調べます。`[x, y]`範囲を指定し、可能なすべての部分配列の範囲内および範囲外にある配列内の要素の数を数え、有効な分割かどうかを確認します。`k`部分配列が存在します。 これは原理的には正しいですが、範囲が O(n^2) で、サブ配列チェックあたりのコストが O(n) であるため、O(n^3) になります。 それはすぐに実行不可能になります`n = 2·10^5`。 

重要な洞察は、範囲を選択するためにすべてのサブ配列を個別に考慮する必要がないということです。 代わりに、数値の頻度を分析できます。 させて`freq[v]`値の倍数になります`v`配列に表示されます。 過半数条件を満たすには、範囲内の要素の合計数が少なくとも`(n + k) // 2`。 これは、各サブ配列の内側の要素が外側よりも多い場合、すべてのサブ配列を合計すると、範囲内の要素のグローバルな下限が得られるという事実から来ています。 

この洞察により、最小幅範囲を効率的に選択できます。`[x, y]`配列値の頻度カウントのプレフィックス合計を使用することによって。 一度`[x, y]`が修正されているため、部分配列の構築は貪欲な 1 パスで簡単です。範囲内の要素については増加し、範囲外の要素については減少するバランスを維持します。 残高がプラスで、まだ作成されていないときはいつでも`k-1`サブ配列の場合は、現在のサブ配列を切り取ります。 最後の部分配列は配列の最後に置かれます。 これにより、各サブ配列には範囲外よりも範囲内に多くの要素が含まれることが保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n) | 遅すぎる |
 | 最適 | O(n + n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列内の各数値の頻度を数えます。 候補範囲を効率的に評価するには、各潜在的な数値が何回出現するかを知る必要があります。 
2. これらの周波数のプレフィックスの合計を計算します。 させて`pref[v]`配列内の要素の数が以下であること`v`。 次に、任意の範囲に対して`[x, y]`、この範囲内の要素の合計数は次のようになります。`pref[y] - pref[x-1]`。 
3. すべての過半数条件を満たすために範囲内で必要な要素の最小数を決定します。`k`サブアレイ。 これは`(n + k) // 2`。 この式は、各サブ配列の内側の要素が外側の要素よりも多くなければならないという要求から来ています。 すべての最小過半数を合計すると、`k`部分配列の場合、内部要素の合計は少なくとも`(n + k) // 2`。 
4. ウィンドウをスライドさせる`[x, y]`プレフィックスの合計を使用して、可能な数値を計算します。 から始める`x = 1`そして移動します`y`内部の要素の合計が満たされるような最小値に設定します。`[x, y]`少なくとも`(n + k) // 2`。 幅を記録します`y - x`。 動く`x`前方に移動して繰り返し、最小幅を見つけます。 
5. 最適化されたら`[x, y]`が見つかったら、貪欲に部分配列を構築します。 配列を反復処理して実行バランスを維持します。 各要素について、内側にある場合は 1 を加算します。`[x, y]`外側にある場合は 1 を減算します。 残高がプラスになり、残高が減少したとき`k-1`サブ配列が作成され、現在のサブ配列をカットしてバランスをリセットします。 最後のサブ配列は配列の最後で終了します。 

なぜ機能するのか: 少なくとも以下の最小範囲を選択することによって`(n + k) // 2`要素を形成するのに十分な要素があることを確認します`k`多数決条件が成立する部分配列。 貪欲なバランス法では、各サブアレイが内側 > 外側の要件を個別に満たすことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        count = [0] * (n + 2)
        for num in a:
            count[num] += 1
        
        pref = [0] * (n + 2)
        for i in range(1, n + 2):
            pref[i] = pref[i-1] + count[i]
        
        needed = (n + k) // 2
        x, y = 1, n
        best_width = n + 1
        left = 1
        for right in range(1, n + 1):
            while pref[right] - pref[left - 1] >= needed:
                if right - left < best_width:
                    best_width = right - left
                    x, y = left, right
                left += 1
        
        print(x, y)
        segments = []
        balance = 0
        last = 0
        cuts = 0
        for i in range(n):
            if x <= a[i] <= y:
                balance += 1
            else:
                balance -= 1
            if balance > 0 and cuts < k - 1:
                segments.append((last + 1, i + 1))
                last = i + 1
                balance = 0
                cuts += 1
        segments.append((last + 1, n))
        for l, r in segments:
            print(l, r)

if __name__ == "__main__":
    solve()
```最初の部分では、周波数とプレフィックスの合計を計算して、最小幅の範囲を効率的に見つけます。`[x, y]`少なくとも含まれる`(n + k) // 2`要素。 2 番目の部分は構成します`k`実行バランスを使用してサブ配列を作成し、各サブ配列の要素の大部分が範囲内にあることを確認します。 境界の処理は非常に重要です。私たちは次の時点でカットを停止します。`k-1`最後のサブ配列が配列の最後まで伸びるようにサブ配列を作成します。
