 ## 解決策
 ## 問題の理解

 負でない整数のいくつかのシーケンスと、最初の整数が与えられます。$x$。 タートルは任意のシーケンスを繰り返し選択して置き換えることができます$x$メキシコ人と$x$そのシーケンス内のすべての番号を合わせて。 セットの mex は、セット内に存在しない最小の非負の整数です。 目標は最大値を決定することです$x$与えられた場所から開始して到達できる$k$。 この関数は呼び出されます$f(k)$。 最後に、負でない整数の場合$m$、合計を計算する必要があります$f(0) + f(1) + \dots + f(m)$。 

制約により、シーケンスの合計数とすべてのシーケンスにわたる要素の合計数が最大で次のようになります。$2 \cdot 10^5$。 これにより、可能なすべての操作を明示的にシミュレートするアルゴリズムは除外されます。$x$範囲内で$0$に$m$、 なぜなら$m$と同じ大きさにすることができます$10^9$。 あらゆる可能性に対するブルートフォース反復アプローチ$x$価値観は実現不可能です。 

微妙な点は、シーケンスには非常に大きな数値が含まれる可能性があり、それよりもはるかに大きな数値が含まれる可能性があることです。$m$、重複が含まれる可能性があります。 あらゆる可能性を追跡する素朴なアプローチ$x$値を指定したり、大きな配列を使用したりすると、メモリまたはパフォーマンスが原因で失敗します。 エッジケースには、すでに 0 が含まれているシーケンス、同じ数字が繰り返されて構成されているシーケンス、および次のような状況が含まれます。$m$は、シーケンスから達成可能な最大 mex よりも小さいです。 

## アプローチ

 ブルートフォースアプローチでは、すべての起動時の操作をシミュレートしようとします。$x$から$0$に$m$。 それぞれについて$x$まで、すべてのシーケンスに対して mex 操作を繰り返し適用できます。$x$増えなくなりました。 これは原理的には正しく動作しますが、$m$まで$10^9$、何十億回もの反復が必要になるため、現実的ではありません。 

重要な洞察は、シーケンスが集合的に「mex 境界」を定義していることを認識することです。 セットを定義する$S$シーケンス内に出現するすべての数値。 最大$x$どのスタートからでも達成可能$k$に含まれない最小の非負の整数によって決定されます。$S$それは少なくとも$k$。 これは、シーケンスで mex を繰り返し適用することで「ジャンプ」できるためです。$x$～から欠落している任意の整数に$S$その上$x$, ただし、シーケンスから順番に欠落している最初の整数を超えることはできません。 したがって、0 から始まり、対象外の最初の整数までのすべての数値の mex を事前計算できます。$S$、合計します$f(k)$以上$0 \le k \le m$範囲の等差数列公式を効率的に使用します。$f(k)$は一定です。 

この洞察により、あらゆる場合の反復シミュレーションから問題が軽減されます。$x$シーケンスから一連の整数を計算し、連続する範囲にわたって単一パスを実行します。$k$値を使用して合計を効率的に計算します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(m * 全長) | O(m) | 遅すぎる |
 | 最適 | O(合計長 + mex_max) | O(合計長 + mex_max) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、シーケンスの数を読み取ります。$n$そして上限$m$。 
2. セットを構築する$S$これには、次のいずれかに出現するすべての整数が含まれます。$n$シーケンス。 mex は存在のみを考慮するため、重複は無関係です。 
3. 変数を初期化する$mex = 0$。 インクリメント$mex$その間$mex$いる$S$。 このループの後、$mex$どのシーケンスにも存在しない最小の非負の整数です。 この値は、次から始まる達成可能な最大 mex です。$0$。 
4. Observe that for any starting value$k \ge mex$、$f(k) = k + 1$。 どれについても$k < mex$、$f(k) = mex$。 これにより、2 つの連続した範囲が得られます。$k$:$0 \le k < mex$そして$mex \le k \le m$。 各範囲の合計は等差数列の公式を使用して計算できます。 
5. 最初の範囲の合計を計算します。$\text{sum1} = mex \cdot \min(m+1, mex)$。 これはカバーします$f(k) = mex$のために$k < mex$または$k \le m$、どちらか小さい方。 
6. 次の場合、2 番目の範囲の合計を計算します。$m \ge mex$:$\text{sum2} = \frac{(m + mex + 1)(m - mex + 1)}{2}$。 これは、次の連続する整数の合計です。$mex$に$m$包括的な。 
7. 最終的な答えは次の合計です。$\text{sum1} + \text{sum2}$。 
8. すべてのテスト ケースに対して繰り返します。 

機能する理由: このアルゴリズムは、すべてのシーケンスの mex がシーケンスによって到達できない最初の整数を与えるという不変式に依存しています。 すべての操作は増加することしかできません$x$次の欠落している整数に順番に変換されます。 したがって、$f(k)$mex までは一定で、その後は直線的に増加します。 これにより、考えられるすべての処理を繰り返すことなく正確さが保証されます。$x$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        S = set()
        for _ in range(n):
            data = list(map(int, input().split()))
            l_i = data[0]
            S.update(data[1:])
        mex = 0
        while mex in S:
            mex += 1
        limit = min(m, mex - 1)
        sum1 = mex * (limit + 1)
        if m >= mex:
            sum2 = (m + mex) * (m - mex + 1) // 2
        else:
            sum2 = 0
        print(sum1 + sum2)

if __name__ == "__main__":
    solve()
```最初のループは、シーケンス内のすべての数値のセットを構築します。 セットを使用すると、平均 O(1) の挿入と検索が保証されます。 mex を計算すると、シーケンスによって到達できない最初の整数が確実に特定されます。 等差数列の公式は、次の観察から導出されます。$f(k)$mex 以下では一定で、その後は線形です。 境界線には注意が必要です$m < mex$負の範囲を避けるため。 

## 実用的な例

 サンプル 1:

 | --- | --- |
 | 0 | 3 |
 | 1 | 3 |
 | 2 | 3 |
 | 3 | 3 |

 合計を計算します:$3 + 3 + 3 + 3 + 4 = 16$。 表は範囲分割を確認します。$k < mex = 4$は f(k) = 3 を持ち、k = 4 は f(k) = 4 を持ちます。 

サンプル 2:

 | k | f(k) |
 | --- | --- |
 | 0 | 4 |
 | 1 | 4 |
 | 2 | 4 |
 | 3 | 4 |

 合計を計算します:$4 + 4 + 4 + 4 + 4 = 20$。 ここで、 mex = 5 であるため、すべての k ≤ m は f(k) = mex となり、等差数列の処理を示します。
