 ## 問題の理解

 この問題には、いくつかの整数シーケンスと非負の整数を扱うタートルが含まれます。$x$。 各シーケンスに対して、タートルは操作を 1 回だけ実行できます。$x$に$\text{mex}$現在の値と選択したシーケンスの数値を合わせて表示します。 目標は最大値を見つけることです$x$指定された開始値に到達可能$k$として表されます$f(k)$。 最終的には次の合計が必要になります。$f(k)$みんなのために$k$から$0$に$m$。 

入力は複数のテスト ケースで構成されます。 各テスト ケースが提供するのは、$n$シーケンス、それぞれは最大で$2 \cdot 10^5$要素と上限$m$の開始値について$x$。 テスト ケース全体のすべてのシーケンスの合計は次のように制限されます。$2 \cdot 10^5$これは、各テスト ケースについて、すべてをシミュレートする余裕がないことを意味します。$x$値を個別に指定する場合$m$大きいです。 効率的に機能する方法が必要です$m$まで$10^9$。 

エッジケースには大きな数値のみを含むシーケンスが含まれるため、小さな初期値には影響しません。$x$値、連続する小さな数値を含むシーケンス。$\text{mex}$重く、そして始まっています$x$存在するすべての数値を超える値を指定すると、異なる動作が発生する可能性があります。 素朴なアプローチを繰り返す$x$から$0$に$m$すべてのシーケンスをシミュレートすると、信じられないほど遅くなります。 

## アプローチ

 ブルートフォース手法では、考えられる各開始値に対して反復処理が行われます。$k = 0 \dots m$、すべてのシーケンスを可能な限りの順序で適用し、最大値を計算します。$x$。 これは正しいですが、扱いにくいです。$m$と同じ大きさにすることができます$10^9$、そしてそれぞれ$x$までの連鎖を引き起こす可能性があります$n$操作、与える$O(m \cdot n)$最低限の操作。 

重要な洞察は、関数が$f(k)$は、シーケンスによって決定される区分的線形パターンを持ちます。 各シーケンスはインクリメントのみ可能です$x$セット内の次に欠損している数値に相対的に$x$。 各シーケンスから除外される最小の数値をオフセットとして事前計算することで、次の繰り返しパターンを決定できます。$f(k)$次に、すべてを反復せずに等差数列を使用して合計を効率的に計算します。$k$。 本質的に、シーケンスは$x$-axis を範囲に入れる$f(k)$予測可能な方法で成長します。 

これにより、問題は開始値の数を数えるということになります。$k$同じものにマップする$f(k)$連続する整数の合計の公式を使用して計算します$\sum f(k)$素早く。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$シーケンスを分割し、各シーケンスをセットにフラット化して重複を削除します。 これらのセットをリストに保存します。 これにより、$\text{mex}$計算は正しく行われ、冗長な操作が回避されます。 
2. 配列を初期化する`count`各数値を含むシーケンスの数を記録します。 必要なのはおおよその数字だけです$n$なぜなら、$\text{mex}$シーケンスの総数に開始値を加えた値を超えることはできません。 
3. 開始時と比較した各配列の最小除外数を計算します。$x=0$。 これにより、このシーケンスを選択することで達成できる最初の数値がわかります。 シーケンス全体にわたるこのような数値をすべて追跡してください。 
4. 除外される最小の数値を並べ替えます。 の成長$f(k)$は区分的に線形になりました: if$x$最小除外数を下回っているため、増加する順序でシーケンスを選択します$x$毎回1つずつ。 このパターンは繰り返され、算術式を使用して合計できます。 
5. 各範囲について$x$連続した最小除外数で定義され、次の合計を計算します。$f(k)$等差級数の公式を直接使用します。$\sum_{i=0}^{r} (start + i) = (r + 1) \cdot start + r \cdot (r + 1)/2$。 
6. もし$m$最小除外数の最大値を超える場合は、最後のしきい値を超えて等差数列を継続して合計を拡張します。 
7. テスト ケースの合計を出力します。 

この方法では、すべての反復処理が回避されます。$x$個別に行うことで、複雑さが軽減されます。$O(m \cdot n)$に$O(n + \sum l_i + \text{sort})$、それは実現可能です。 

なぜ効果があるのか​​:$\text{mex}$操作では、各シーケンスが増加のみできることが保証されます。$x$そのシーケンスに欠落している最初の番号まで、および$x$。 最小限の除外数値を並べ替えることで、どの数値がどれであるかを常に知ることができます。$x$値は達成可能であり、等差数列公式は区分的一次関数を効率的に合計します。$f(k)$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        count = {}
        total_numbers = 0
        for _ in range(n):
            arr = list(map(int, input().split()))[1:]
            unique = set(arr)
            for num in unique:
                count[num] = count.get(num, 0) + 1
            total_numbers += len(unique)

        # Build the list of minimal excluded numbers
        mex_candidates = sorted(count.keys())
        result = 0
        prev = -1
        for mex in mex_candidates:
            length = min(m, mex - 1) - prev
            if length > 0:
                result += (prev + 1 + mex - 1) * length // 2
                prev = mex - 1
            if prev >= m:
                break
        if prev < m:
            length = m - prev
            result += (prev + 1 + m) * length // 2
        print(result)

if __name__ == "__main__":
    solve()
```コードはまずシーケンスを読み取り、それらを平坦化して重複を削除し、出現回数をカウントします。 除外される最小の数値を並べ替えることで、範囲を分割できるようになります。$0 \dots m$の線形和で区間に分割$f(k)$。 等差数列の公式は、各間隔を効率的に合計します。 最終的な拡張ハンドル$m$見つかった最大数よりも大きい。
