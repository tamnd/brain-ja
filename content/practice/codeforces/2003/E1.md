 ## 解決策
 ## 問題の理解

 長さの順列における反転の最大数を見つけるように求められます。$n$一連の間隔によって定義される特定の「興味深い」特性を満たすもの。 各インターバル$[l_i, r_i]$選択肢が伴う$k_i$左セグメントの最大値が$[l_i, k_i]$正しいセグメントの最小値よりも厳密に小さいです$[k_i + 1, r_i]$。 これらを選択した後、$k_i$すべての間隔の値では、すべての左セグメントの最大値の全体の最大値が、すべての右セグメントの最小値の全体の最小値より小さくなければなりません。 これを満たす順列がない場合、答えは次のようになります。$-1$。 それ以外の場合は、最も多くの反転を含む順列が必要です。ここで、反転は位置のペアです$i < j$そのような$p_i > p_j$。 

制約は中程度です。$n$最大 5000 まで可能ですが、合計は$n$すべてのテスト ケースの数も 5000 で制限されます。$m = n/2$間隔ですが、この簡単なバージョンでは間隔が厳密に重複せず、並べ替えられていることが重要です。$r_i < l_{i+1}$。 これにより、交差や重なり合う制約を処理する必要がなくなるため、相対的な最大値と最小値についての推論が簡素化されます。 すべての順列を試す単純なアプローチは不可能です。$n!$実行可能な操作数よりもはるかに速く増加します。 

明らかではないエッジケースが発生する場合$m = 0$つまり、間隔はありません。 この場合、興味深い条件が自明に成り立ち、最大反転数は完全な逆順列の数になります。 もう 1 つのエッジ ケースは、間隔が連続しているか、配列のほぼ全体を占めている場合です。 許可された構造により、最大反転数が可能な反転の合計よりも少なくなる可能性があります。$n$。 不注意なアプローチでは、すべての間隔にわたって左の最大値と右の最小値を分離する必要性を無視する可能性があるため、これを誤って計算する可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、すべてが列挙されます。$n!$順列、各間隔の選択を確認します$k_i$、左部分と右部分の最大値と最小値を計算し、興味深い条件を検証します。 満たされている場合は、反転数を数えます。 これは理論的には正しいですが、完全に実行不可能です。 たとえ$n = 10$、$n!$300万を超えていますが、ここにあります$n$5000も可能です。 

重要な洞察は、間隔が重複していないことを観察することで得られます。 定義しましょう$X$最大の位置の左側の位置のセットとして$k_i$すべての間隔で、そして$Y$最小値の右側の位置として$k_i$。 興味深い条件は、次の単純な順序制約に帰着します。つまり、すべての数値が次のようになります。$X$内のすべての数値より小さくなければなりません$Y$。 間隔が重なり合わないため、配列を連続したブロックに分割できます。$X$または$Y$または任意の間隔の外にあります。 反転を最大化するには、数値の制約を尊重しながら、最大の数値をできるだけ左に配置する必要があります。$X$の数値より小さいです$Y$。 インターバルの外側では、セグメントを反転してローカル反転を最大化できます。 

したがって、最適な解決策は貪欲です。つまり、対象の条件 (事実上最大左-最大境界) によって分離される必要がある最初の位置を特定し、その後ろに最大の数値を配置します。 次に、制約のない連続セグメントごとに、数値を降順に配置して反転を最大化できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * m) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. もし$m = 0$、間隔はありません。 興味深い条件は空虚に満たされるため、最大の反転は完全な逆順列で発生します。 これにより、$n*(n-1)/2$反転。 
2. それ以外の場合は、配列の左側の部分に影響を与える最初の間隔を決定します。 させて`pos`最初の間隔の右端点になります。 間隔がばらばらでソートされているため、`pos`対象となる境界の左側と右側に移動する必要がある要素を効果的に分離します。 
3. 以下の数値を配置して順列を構築します。`pos+1`に`n`最初に降順で。 これらの数値は、左の区間内のすべての数値よりも大きいことが保証されており、条件を満たします。`max(left) < min(right)`。 
4. から数字を配置します`1`に`pos`前のブロックの後に降順で。 これにより、興味深い条件に違反することなく、左セグメント内の反転が最大化されます。 
5. 逆ソートされた配列の公式を使用して、反転カウントを直接計算します。長さの連続するブロックに対して`l`、反転の最大数は`l*(l-1)/2`。 右ブロックの大きな数値が左ブロックの小さな数値に先行するため、ブロック間の反転も自然に起こります。 

機能する理由: すべての間隔が重複していないため、最初の間隔によって決定される分離点で十分です。 左側のセグメントには右側のセグメントよりも小さい数値が含まれているため、興味深い条件が当​​てはまります。 各セグメント内で数値を降順に配置すると、条件に違反することなくすべての可能な反転が確実に実現されます。 他の順序ではこれ以上の反転を生成することはできません。反転が失われるのは、セグメント内の大きな数値の前に小さな数値を配置した場合、または左最大値と右最小値の境界に違反した場合のみであるためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_inversions(n, m, intervals):
    if m == 0:
        return n * (n - 1) // 2
    # the first interval defines the left/right separation
    pos = intervals[0][1]
    left_len = pos
    right_len = n - pos
    # max inversions: reverse the right block first, then left block
    return right_len * left_len + left_len * (left_len - 1) // 2 + right_len * (right_len - 1) // 2

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    intervals = [tuple(map(int, input().split())) for _ in range(m)]
    print(max_inversions(n, m, intervals))
```このソリューションでは、まず間隔がないかどうかを確認し、逆順列の完全な反転カウントを返します。 それ以外の場合は、分離点を計算します。`pos`最初の間隔の右境界として。 反転の数は、各セグメント内の反転と境界を越える反転の合計であり、左右のブロックのサイズを乗算して計算されます。 順列を明示的に構築する必要はありません。 逆の公式で十分です。 主な微妙な点は、正しく識別することです`pos`入力形式に合わせて 1 から始まるインデックスを処理します。
