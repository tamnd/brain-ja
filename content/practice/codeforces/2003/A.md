[CF 2003A - カメと優れた文字列](https://codeforces.com/problemset/problem/2003/A)

 ## 解決策
 ## 問題の理解

 後の部分文字列の最後に現れる文字で始まる部分文字列が存在しないように、指定された文字列を 2 つ以上の連続する部分文字列に分割できるかどうかを判断するように求められます。 言い換えれば、文字列を少なくとも 2 つの部分に分解し、各部分のペアで、前の部分の最初の文字が後の部分の最後の文字と一致しないようにする必要があります。 

各テスト ケースでは、文字列と文字列自体の長さが示されます。 そのような分解が存在する場合、出力は「YES」、存在しない場合は「NO」になります。 制約は小さく、文字列の長さは最大 100、テスト ケースの数は最大 500 です。 これは、$O(n^2)$テストケースごとのアルゴリズムは実現可能です。$100^2 \cdot 500 = 5 \cdot 10^6$制限時間は 1 秒以内です。 

注意すべきエッジケースには、「aa」や「aaa」など、すべての文字が同一である文字列が含まれます。 このような場合、最初の部分の最初の文字は常に 2 番目の部分の最後の文字と等しいため、分割は失敗します。 もう 1 つの微妙なシナリオは、単純な貪欲な分割によって正しい分解が失われる可能性がある、繰り返しパターンを持つ文字列です。 たとえば、「aba」は「ab」 + 「a」として分割でき、ルールは満たされますが、「a」 + 「ba」への分割は「a」 == 「a」であるため失敗します。 

## アプローチ

 ブルートフォースアプローチは、文字列の可能なすべての分割を試みることです。$k \ge 2$部分文字列を調べて、部分文字列のすべてのペアの条件を確認します。 各パーティションのチェックが必要です$O(k^2)$ペアであり、文字列を分割する方法は指数関数的に多くあります。 のために$n = 100$、これは明らかに実行不可能です。 

重要な洞察は、条件の観察から得られます。少なくとも 1 離れた距離に繰り返し文字があるかどうかを検出するだけで済みます。 ポジションのペアが存在する場合$i < j - 1$そのような$s[i] == s[j]$、文字列を位置間で分割します$i$そして$i+1$条件を満たす 2 つの部分文字列を生成します。 それ以外の場合、繰り返されるすべての文字が隣接している場合は、有効な分割は存在しません。 これにより、問題は文字列をスキャンして隣接しない繰り返し文字を探すという問題が軽減されます。$O(n)$テストケースごとに。 

このアプローチは、単純なルールで組み合わせ問題を線形スキャンに変換するため、総当り攻撃よりも大幅に簡単です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n^2) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. テスト ケースごとに、文字列を読み取ります。$s$そしてその長さ$n$。 
3. フラグを初期化する`good`に`False`。 これにより、有効な分割が存在するかどうかが追跡されます。 
4. 最初の文字から最後から 2 番目の文字まで文字列を繰り返します。 インデックスごとに$i$の文字があるかどうかを確認します。$i$の任意の文字に一致します$i+2$またはそれ以降。 
5. そのような一致が見つかった場合は、`good`に`True`そしてループから抜け出す。 これは、有効な分割を可能にする 2 つの隣接しない同一文字を見つけることに対応します。 
6. ループの後、if`good`は`True`、「YES」を出力します。 それ以外の場合は、「NO」を出力します。 

機能する理由: このアルゴリズムは、出現の間に少なくとも 1 つの他の文字とともに繰り返される文字が存在する場合にのみ、文字列を適切な部分文字列に分割できるという特性に依存しています。 これにより、最初の部分文字列の最初の文字が 2 番目の部分文字列の最後の文字と等しくないことが保証され、条件が満たされます。 このような繰り返しが存在しない場合、すべての文字は一意であるか、隣接して繰り返されるだけであるため、分割はルールに違反します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    good = False
    seen = set()
    for i, c in enumerate(s):
        if c in seen:
            good = True
            break
        if i > 0:
            seen.add(s[i - 1])
    print("YES" if good else "NO")
```このソリューションでは、現在の文字の 2 つ以上前に出現した文字のセットが維持されます。 各文字について、その文字がセット内に出現したかどうか、つまり隣接しない繰り返しが存在するかどうかを確認します。 そうであれば、文字列を適切な部分文字列に分割できます。 追加`s[i - 1]`これにより、問題の条件に一致する、少なくとも 2 つ以上離れた文字のみが考慮されるようになります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        good = False
        seen = set()
        for i, c in enumerate(s):
            if c in seen:
                good = True
                break
            if i > 0:
                seen.add(s[i - 1])
        print("YES" if good else "NO")
    return output.getvalue().strip()

# provided samples
assert run("4\n2\naa\n3\naba\n4\nabcb\n12\nabcabcabcabc\n") == "NO\nYES\nYES\nYES", "sample 1"

# custom cases
assert run("2\n2\nab\n3\naaa\n") == "NO\nNO", "minimum and all equal"
assert run("1\n5\nabcde\n") == "NO", "all unique"
assert run("1\n6\nabacab\n") == "YES", "non-adjacent repetition"
assert run("1\n100\n" + "a"*100 + "\n") == "NO", "maximum size, all equal"

 ## 特殊なケース

 入力「aa」に対して、アルゴリズムはスキャンします。`i=0`(`c='a'`） そして`i=1`(`c='a'`）。 の`seen`後に設定`i=1`含まれています`{'a'}`。 「あ」が入っているので、`seen`、`good`True になります。 ただし、文字は隣接しているため、アルゴリズムは次のことを正しく保証します。`i>0`前の文字を追加するだけです`seen`。 したがって、`good`False のままで「NO」を出力し、隣接する繰り返しを正しく処理します。 

「aba」のような文字列の場合、`i=2`(`c='a'`）、`seen`含まれています`{'a', 'b'}`。 「a」が入っています`seen`、隣接していない繰り返しを示し、アルゴリズムは「YES」を出力し、隣接していない繰り返し文字を正しく処理します。
