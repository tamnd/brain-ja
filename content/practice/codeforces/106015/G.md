 ## 解決策
 ## 問題の理解

 幾何学的パラメーターによってのみ記述される二等辺三角形が与えられます。2 つの等しい辺には長さがあります。$L$、ベースには長さがあります$B$。 タスクは、そのような三角形が存在できるかどうかを判断し、存在する場合は、内心 (内心円の中心) と外心 (外接円の中心) の 2 つの古典的な中心の間の距離を計算することです。 

三角形は三角不等式を満たす場合にのみ存在します。 等しい辺は$L$そしてベースは$B$唯一の重要な条件は、底が 2 つの等しい辺の合計よりも厳密に小さくなければならないということです。これを単純化すると、次のようになります。$B < 2L$。 これが失敗すると、三角形は退化するか不可能になり、解析する幾何学的オブジェクトが存在しなくなります。 

この制約により、辺の長さは次のとおりになります。$10^6$したがって、すべての解はテスト ケースごとに一定時間である必要があり、反復的な幾何学的構築を避ける必要があります。 これにより、三角形ジオメトリに対する座標検索や数値シミュレーションが即座に除外されます。 すべては辺の長さを含む閉形式に帰着する必要があります。 

よくある微妙な失敗のケースは、三角不等式がほとんど違反されていないか、ほとんど満たされていない場合です。 例えば、$L = 5, B = 10$縮退三角形が得られます。 値を直接幾何学式に組み込む単純な実装でも、入力を拒否せずに浮動小数点数を生成する可能性があります。 別の問題が発生する場合$B$に非常に近いです$2L$ここで、浮動小数点の精度は、慎重に扱わないと平方根の式がわずかに負になる可能性があります。 

## アプローチ

 強引な幾何学的なアプローチでは、座標で三角形を構築し、底面を X 軸上に配置し、円の交点を使用して 3 番目の頂点を計算し、定義から内心と外心の座標を明示的に計算しようとします。 これらのオブジェクトはすべて三角形によって一意に決定されるため、これは機能しますが、不必要に複雑になり、数値的に不安定になります。 各ステップでは平方根と除算が導入され、交点を求めるときに小さな浮動小数点誤差が蓄積されます。 

重要な観察は、内心と外心の両方が三角形の埋め込みには依存せず、辺の長さのみに依存するということです。 これにより、ジオメトリを完全にバイパスし、古典的な三角形の不変式を使用できるようになります。 外周半径$R$、半径内$r$、および内心と外心の間の距離は、オイラー幾何学からの既知の恒等式を満たします。$$OI^2 = R(R - 2r)$$どこ$O$は外心であり、$I$内心です。 

したがって、問題はコンピューティングに帰着します$R$そして$r$サイドの長さから。 面積を表現すると$L$そして$B$、両方の半径は標準公式から直接に従います。

 ## アルゴリズムのチュートリアル

 1. 検証して三角形が存在できるかどうかを確認します。$B < 2L$。 そうでない場合は、返品してください$-1$。 これにより、意味のない浮動小数点値が生成される、無効な入力に対する幾何学的計算の実行が回避されます。 
2. 二等辺三角形の頂点から底辺までの高さを計算します。 三角形を 2 つの直角三角形に分割すると、斜辺のある直角三角形が得られます。$L$そして片足$B/2$, したがって、高さは$h = \sqrt{L^2 - (B/2)^2}$。 このステップは、Heron の公式を使用せずに面積を取得する最もクリーンな方法です。 
3. ベースと高さを掛けて面積を計算します。$A = \frac{B \cdot h}{2}$。 半径内と外半径の両方が面積に直接依存するため、面積は中心量となります。 
4. 半周長を計算する$s = \frac{2L + B}{2} = L + \frac{B}{2}$、次に、次を使用して半径を計算します。$r = \frac{A}{s}$。 これはアイデンティティから導き出されます$A = rs$、これはすべての三角形に当てはまります。 
5. 次を使用して外周半径を計算します。$R = \frac{abc}{4A}$。 ここ$a = b = L$そして$c = B$、 それで$R = \frac{L^2 B}{4A}$。 これは外接円全体を辺の長さと面積で表現します。 
6. オイラーの関係を使用して中心間の距離を計算します$d = \sqrt{R(R - 2r)}$。 これは、2 つのセンター間の最後の幾何学的なブリッジです。 
7. 出力$d$十分な精度で。 

### なぜ効果があるのか

 正しさは、縮退していない三角形はその辺の長さによって (剛体運動まで) 一意に決定されるため、導出されるすべての幾何学量は次の関数のみであるという事実に基づいています。$L$そして$B$。 使用される公式は、近似ではなく、ユークリッド幾何学の正確な恒等式です。 すべての式は正の面積三角形を想定しているため、明示的に強制する必要がある唯一の条件は非縮退です。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    L, B = map(float, input().split())

    if B >= 2 * L:
        print(-1)
        return

    h_sq = L * L - (B * B) / 4.0
    if h_sq <= 0:
        print(-1)
        return

    h = math.sqrt(h_sq)
    A = (B * h) / 2.0

    s = L + B / 2.0
    r = A / s

    R = (L * L * B) / (4.0 * A)

    val = R * (R - 2.0 * r)
    if val < 0:
        val = 0.0

    d = math.sqrt(val)

    print(d)

if __name__ == "__main__":
    solve()
```実装は導出に直接続きます。 最初のガードは、無効な幾何学的式の平方根を試行しないことを保証します。 高さの計算は、ヘロンの計算式よりも好まれます。これは、次の場合にほぼ等しい数値を減算することを避けるためです。$B$に近いです$2L$、数値の安定性が向上します。 

最終ガードオン`val`浮動小数点の丸めによって生じる小さな負の値が平方根に伝播するのを防ぎます。

 ## 特殊なケース

 いつ$B$アプローチ$2L$、高さの計算には、ほぼ等しい 2 つの数値を減算することが含まれます。$L^2 - (B/2)^2$。 例えば、$L = 10^6$、$B = 2 \cdot 10^6 - 10^{-3}$この式は浮動小数点エラーの影響を非常に受けやすくなります。 このような場合、平方根を求める前に負の値をクランプすると、アルゴリズムで NaN が生成されなくなります。 

もし$B = 0$、三角形はセグメントに縮退し、妥当性チェックで拒否されます。$0 < 2L$は true ですが、面積はゼロになり、平方根ステップは、$h^2 \le 0$ガード。 

縮退極限ですべての辺が等しい場合$B = 2L$、三角形が折れて線分になります。 アルゴリズムは最初の不等式チェックでこれを検出し、返します。$-1$、無効な幾何学的推論が続行されるのを防ぎます。
