 ## 問題の理解

 私たちは、猫の系統全体で時間の経過とともに食料の価値が増加する、階層化された給餌システムをシミュレートしています。 がある$M$並んでいる猫たちと$N$日々。 初日は、どの猫もちょうど 1 グラムの餌から始まります。 

2 日目以降、猫に与える餌は 2 つの要素によって決まります。1 つは前日の餌の量、もう 1 つはその日以前にすべての猫がその日に食べた餌の累積量です。 つまり、猫$j$当日$i$は独自の歴史に基づいて構築され、同じ日にインデックスが小さい猫からの貢献も蓄積します。 

タスクはプロセス全体をシミュレートすることではありません。 最後の猫の最終値のみが必要です。$M$、当日$N$、998244353 を法として計算されます。 

制約により両方が許可されます$N$そして$M$まで$10^6$。 これにより、完全なものを明示的に構築するソリューションは即座に除外されます。$N \times M$テーブル。 保存するだけでも大きすぎるため、すべての遷移を反復処理すると、$10^{12}$最悪の場合の運用。 

素朴な考えによる微妙な失敗例は、猫に関する単純な接頭辞の合計を使用して毎日を独立して計算できると仮定することです。 これは実際には 1 日あたりでは正しいのですが、これを一日中繰り返すのは不可能です。 もう 1 つの罠は、前の行がプレフィックス累積構造を通じて次の行に影響を与えることを認識せずに、最後の行のみをシミュレートしようとすることです。 

## アプローチ

 直接シミュレーションは文字通り定義に従います。 毎日、すべての猫の値を左から右に計算します。 猫を計算するとき$j$、前日の値とすべての猫の合計を追加します。$1$に$j-1$当日。 これには、1 日あたりのプレフィックス合計を維持する必要があります。 

このアプローチは、再発を正確に反映しているため、正しいです。 ただし、処理します$M$それぞれの猫$N$につながる日々$O(NM)$時間の複雑さ。 と$N, M \le 10^6$、これはあまりにも大きくなりすぎます。 

重要な観察は、再発が非常に構造化された加算形式をとっているということです。 毎日、前の行と現在の行のプレフィックスの累積から新しい行が構築されます。 これは、二項係数の構築やパスカルのような変換に現れるのと同じ構造です。 

単一の初期単位の食物がどのように伝播するかを追跡すると、グリッド内の経路を数えるのと同じ方法で伝播します。右に移動することは猫全体の蓄積に対応し、下に移動することは数日にわたる進行に対応します。 各州$(i, j)$は上と左からの寄与を蓄積します。これはまさに 2 次元での二項係数の反復です。 

これは、次のような解釈につながります。$(N, M)$からの単調パスの数に等しい$(1,1)$に$(N,M)$、これは標準的な組み合わせ値です。$$\binom{N + M - 2}{M - 1}.$$したがって、問題は 998244353 を法とする単一の二項係数の計算に帰着します。これは階乗事前計算を使用すると効率的です。

 ## アルゴリズムのチュートリアル

 動的プロセスを組み合わせ計数問題に還元し、二項係数を効率的に計算します。 

1. 階乗および逆階乗を最大で事前計算します。$N + M$。 これが必要になるのは、素数を法とする結合式を評価するためであり、モジュラー算術では直接の除算は不可能です。 
2. フェルマーの小定理を使用して逆モジュラーを計算します。 998244353は素数なので、$x^{-1} \equiv x^{MOD-2} \mod MOD$。 これにより、階乗が計算された後、線形時間で逆階乗を構築することができます。 
3. 最終的な値は、次の位置の選択に対応することを認識します。$M-1$間を右に移動$N+M-2$グリッド解釈における合計移動数。 これにより、DP 構造は次のように変換されます。$$\binom{N + M - 2}{M - 1}.$$4. 標準の式を使用して結果を計算します。$$\text{fact}[N+M-2] \cdot \text{invfact}[M-1] \cdot \text{invfact}[N-1].$$5. 結果のモジュロ 998244353 を出力します。 

### なぜ効果があるのか

 反復は、各セルがその最上位の隣接セル (前日) と左の接頭辞 (同じ日の以前の猫) に依存する 2 次元の蓄積プロセスを定義します。 これにより、移動が右方向と下方向に制限される格子パスをカウントするのと同じ依存構造が作成されます。 初期状態からのすべてのユニット寄与はすべての有効なパスを介して伝播し、そのようなパスの数は原点から$(N,M)$はまさに上記の二項係数です。 すべての寄与は線形で独立しているため、すべてのパスを合計すると最終値が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    N, M = map(int, input().split())
    
    maxv = N + M - 2
    
    fact = [1] * (maxv + 1)
    for i in range(1, maxv + 1):
        fact[i] = fact[i - 1] * i % MOD
    
    invfact = [1] * (maxv + 1)
    invfact[maxv] = modinv(fact[maxv])
    for i in range(maxv, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD
    
    def C(n, r):
        if r < 0 or r > n:
            return 0
        return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD
    
    print(C(N + M - 2, M - 1))

if __name__ == "__main__":
    solve()
```実装は最初に読み取ります$N$そして$M$、次に階乗表と逆階乗表を作成します。$N+M-2$。 逆モジュラーは、高速累乗を使用して 1 回計算されます。 次に、結合関数を使用して閉じた形式を直接評価します。 階乗配列のサイズが正確に一致するように注意する必要があります。$N+M-2$ここでの off-by-one エラーは一般的であるためです。 

## 実用的な例

 小さなケースを考えてみましょう$N = 3, M = 3$。 私たちは計算します$\binom{4}{2} = 6$。 

| ステップ | 値 |
 | --- | --- |
 | N+M-2 を計算する | 4 |
 | M-1 を計算する | 2 |
 | C(4,2) を評価する | 6 |

 これは、各移動シーケンスが食物寄与の有効な伝播に対応する、再発から予想される組み合わせの成長と一致します。 

ここで考えてみましょう$N = 4, M = 2$。 答えは次のとおりです。$$\binom{4}{1} = 4.$$| ステップ | 値 |

 これは、cat ディメンションの選択肢が 1 つしかない場合、システムは日をまたがる線形伝播になることを確認します。

 ## 特殊なケース

 のために$N = 1, M = 1$、システムは初期条件を超えて進化することはありません。 式は次のようになります$\binom{0}{0} = 1$、定義と一致します。 

のために$N = 1, M = k$、1 日しかないため、日間の蓄積は発生しません。 再発はすべての猫で一定の値に収まります。 式は次のようになります$\binom{k-1}{k-1} = 1$、フラット行の動作と一致します。 

のために$M = 1, N = k$、猫は 1 匹だけなので、接頭辞の相互作用は存在しません。 毎日、同じ価値が単純に引き継がれます。 式は次のようになります$\binom{k-1}{0} = 1$、変更されていない単一の列と一致します。
