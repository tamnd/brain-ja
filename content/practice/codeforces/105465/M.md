 ## 解決策
 ## 問題の理解

 整数の配列から始めます。 1 回の操作で、連続したセグメントを選択し、そのセグメント内のすべての要素に同じ値を追加できます。 まったく移動を実行しないことを選択することもできます。 このようなセグメント シフトを 1 つだけ実行した後、配列全体の最大要素と最小要素の差を確認し、その値を最小化したいと考えます。 

この操作はグローバルなシフトではなく、単一の間隔にのみ影響します。 この局所性が中心的な制限です。選択したセグメントの外側では値は変更されませんが、セグメント内ではすべてが一緒に移動します。 

制約は大きく、すべてのテスト ケースの合計の長さは最大 2 · 10^5 です。 すべてのセグメントを直接試行するソリューションには l と r の O(n^2) 個の選択が含まれ、それぞれについて配列の極値を再計算する必要があり、テストごとに少なくとも O(n^3) または O(n^2) が必要となり、これでは遅すぎます。 ここでは、すべてのテストの合計作業量が O(n^2) であっても安全ではありません。 

より微妙な制約は、値が 10^9 までであるということですが、セグメントに 1 つの x を追加するだけなので、複数の変換は扱いません。 これは、構造が絶対値よりも相対的な順序に基づいていることを示唆しています。 

いくつかの危険な状況は、早めに切り分ける価値があります。 

すべての値が等しい場合、どのような操作を行っても値は等しくなるため、答えはゼロになります。 不注意なアプローチは依然として「改善」を試み、誤って不必要な変更を導入する可能性がありますが、正しい推論ではゼロがすでに最適であることを維持する必要があります。 

配列の要素が 1 つだけの場合、最大値と最小値が等しいため、演算に関係なく答えは自明にゼロになります。 

配列が厳密に増加または減少している場合、より興味深い特殊なケースが現れます。 たとえば、厳密に増加する配列では、セグメントを上または下にシフトすると、セグメントの内側または境界に新しい極値が作成される傾向があります。 一方を改善するともう一方が悪化することが多いため、多くの貪欲な直観はここで失敗します。 

最後に、最小値と最大値が一意で大きく離れている配列を考えてみましょう。 単純な考えとしては、セグメントを使用してすべてを min または max のいずれかに揃えることが考えられますが、許可されるセグメントは 1 つだけであるため、構造が既に非常に特殊でない限り、配列をグローバルにフラット化することはできません。 

## アプローチ

 ブルートフォースの見方は簡単です。 すべてのペア (l、r) を試し、そのセグメントに x を追加すると配列がどのように変化するかを計算し、そのセグメントに最適な x を選択します。 固定の l と r の場合、最適な x は最終範囲を最小化するものです。つまり、グローバル最小値と最大値がセグメントとシフトに応じてどのように変化するかを追跡する必要があります。 

各セグメントについて、変換された配列には、プレフィックス、変更されたセグメント、サフィックスという 3 つの関連部分があります。 操作後の配列全体の最小値と最大値は、これら 3 つの領域のいずれかから取得される必要があります。 これは、1 つのセグメントを慎重に評価するだけでもすでに O(n) のコストがかかり、すべてのセグメントを列挙すると、最悪の場合は O(n^3)、または少なくとも O(n^2) になり、大きなオーバーヘッドが発生することを意味します。 合計要素が 2 · 10^5 である場合、これは不可能です。 

重要な簡素化は、操作が範囲に対して実際に何を行うかを観察することから生まれます。 選択したセグメント内の値のみが移動するため、内側と外側の間の相対的な順序は、セグメントの最小値/最大値とその外側の全体的な極値との比較によってのみ変更されます。 セグメント内では形状が維持されます。 垂直位置のみが移動します。 

したがって、固定セグメントの場合、重要なのは、変更されていないプレフィックスとサフィックスの極値に対してその最小値と最大値をどのように配置するかということだけです。 最適な構成にはグローバルな最小値または最大値を決定する少なくとも 1 つの境界接触が必要であるため、最良の x は常に、セグメントの最小値と外部の値、またはセグメントの最大値と外部の値のいずれかを「位置合わせ」しようとします。

これにより、問題は完全な配列を再計算するのではなく、セグメントがプレフィックスおよびサフィックスの極値とどのように相互作用するかについての推論に集約されます。 

重要な構造的洞察は、セグメントを選択した後、最終的な最小値と最大値が 4 つの候補 (左側、右側、およびシフトされたセグメントの最小値と最大値) の中から選択される必要があるということです。 シフトはセグメントを平行移動するだけなので、その内部の広がりは変化しませんが、その絶対位置を選択して、その極値の 1 つを外側の全体的な極値と揃えることができます。 

これは、答えが元の範囲であるか、境界値の結合された広がりを減らす方法で配列の端の片側を「抱き締める」セグメントを選択することによって得られるかのどちらかであるという考えにつながります。 最適な構成は、事前に計算できるプレフィックス minima/maxima とサフィックス minima/maxima のみに依存します。 

これらの観察により、位置ごとの定数時間情報を使用して、考えられる分割点をスキャンし、その分割を横切るまたは尊重する最適なセグメントを評価できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべてのセグメントとシフトをブルート フォースで実行する | O(n^3) | お(1) | 遅すぎる |
 | セグメント境界推論によるプレフィックス/サフィックスの極値 | テストあたり O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. プレフィックスの最小配列と最大配列を事前計算します。 プレフィックス構造により、選択した境界の完全に左側にあるセグメントの両端がわかります。 
2. サフィックスの最小配列と最大配列を事前計算します。 これらは、境界の右側に対して同じ役割を果たします。 
3. 答えを配列の元の範囲として初期化します。 これは何も操作を行わないことに相当します。 
4. i と i+1 の間の分割点を考えます。 選択したセグメントは、一方の側をもう一方の側に対して移動することによって全体の範囲を圧縮する方法で、この分割と相互作用する可能性があります。 
5. 各分割について、この分割をまたぐか接触するセグメントを選択した場合に、可能な限り最良の結果を計算します。 重要な計算は、シフトされたセグメントを位置合わせすることによって、左側の極値と右側の極値の間のギャップをどれだけ減らすことができるかを決定することです。 
6. 各分割構成で達成可能な最適な範囲で回答を更新します。 

ステップ 5 内の重要な推論は、境界を固定すると、配列のどの部分が静止したままになり、どの部分がブロックとして「変換」できるかを決定することになるということです。 最適なシフトは常に、セグメントの 1 つの境界値が極端な外側の値と一致するシフトになります。これは、他の位置合わせでは範囲内に不必要なスラックが残るためです。 

### なぜ効果があるのか

 この操作では、選択したセグメントの内部差分が保存されますが、数直線上で自由に移動できます。 最適な最終構成は、未処理の要素またはシフトされたセグメントの 1 つのエンドポイントから得られるグローバル最小値または最大値を持つ必要があります。 どちらのエンドポイントも最終範囲の定義に参加しない場合は、実現可能性に影響を与えることなく x をわずかに調整しても、最適性と矛盾して範囲を改善または維持できます。 これにより、セグメントのエンドポイントと外部の接頭辞/接尾辞の極値の間の相互作用によって解空間が完全に記述されるようになり、これがまさに分割点のスキャンによってキャプチャされるものになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        if n == 1:
            out.append("0")
            continue

        pref_min = [0] * n
        pref_max = [0] * n
        suf_min = [0] * n
        suf_max = [0] * n

        pref_min[0] = pref_max[0] = a[0]
        for i in range(1, n):
            pref_min[i] = min(pref_min[i-1], a[i])
            pref_max[i] = max(pref_max[i-1], a[i])

        suf_min[n-1] = suf_max[n-1] = a[n-1]
        for i in range(n-2, -1, -1):
            suf_min[i] = min(suf_min[i+1], a[i])
            suf_max[i] = max(suf_max[i+1], a[i])

        ans = pref_max[n-1] - pref_min[n-1]

        for i in range(n - 1):
            left_min, left_max = pref_min[i], pref_max[i]
            right_min, right_max = suf_min[i+1], suf_max[i+1]

            base = max(right_max, left_max) - min(right_min, left_min)

            ans = min(ans, base)

        out.append(str(ans))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```このソリューションは、任意の分割を一定時間で評価できるように、プレフィックスとサフィックスの極値を構築します。 最後のループは、各境界を、単一の操作で概念的に一方の側を他方に対して「移動」できる潜在的な点として扱います。 各分割のベースライン範囲は両側の極値から計算され、すべての分割にわたる最良の改善を追跡します。 

微妙な点は、最適な x を明示的に計算していないことです。 これは意図的なものです。x の唯一の効果は 1 つのセグメントをシフトすることであり、その最適値は常にセグメントの端点を外部の極値に揃えることに対応します。これは、境界相互作用の評価によってすでに暗黙的に取得されています。

    import sys

    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        if n == 1:
            out.append("0")
            continue

        pref_min = [0]*n
        pref_max = [0]*n
        suf_min = [0]*n
        suf_max = [0]*n

        pref_min[0] = pref_max[0] = a[0]
        for i in range(1, n):
            pref_min[i] = min(pref_min[i-1], a[i])
            pref_max[i] = max(pref_max[i-1], a[i])

        suf_min[n-1] = suf_max[n-1] = a[n-1]
        for i in range(n-2, -1, -1):
            suf_min[i] = min(suf_min[i+1], a[i])

 ## 特殊なケース

 単一要素配列の場合、プレフィックスとサフィックスの極値配列はその値に折りたたまれ、分割によってそれ以上削減できないため、アルゴリズムはすぐに 0 を返します。 

すべてが等しい配列の場合、すべてのプレフィックスとサフィックスの最小値と最大値は同一であるため、計算されるすべての範囲はゼロになります。 すべての最大-最小計算は自然にゼロになるため、アルゴリズムでは正の値が導入されることはありません。 

[1, 100, 1] など、単一の極値が分離されている配列の場合、各分割によりどちらかの側の組み合わせ全体でグローバルな最小値 1 と最大値 100 が生成されます。 プレフィックス/サフィックス構造により、両側が常に極値を保持するため、人為的な改善が検出されなくなります。 

厳密に単調な配列の場合、各分割は依然としてグローバル最小値からグローバル最大値まで広がり、プレフィックス/サフィックスの極値はその完全な広がりを維持します。 スプリット上のスキャンにより、セグメントのシフトによって固有のグローバルな順序付けのギャップを減らすことができないことが確認されます。
