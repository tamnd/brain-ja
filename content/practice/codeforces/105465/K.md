 ## 解決策
 ## 問題の理解

 以下のみからなる配列が与えられます。`1`そして`-1`。 この配列のインデックスを次のように分割する必要があります。`k`グループ。 各グループは元の順序のサブシーケンスとして扱われます。つまり、相対的な順序は維持されますが、連続性は必要ありません。 

サブシーケンスに対して、値を定義します。`f(b)`そのサブシーケンス内の最大サブ配列合計として。 要素だけなので、`±1`、これは、空の部分配列が許可されてゼロが返されるため、Kadane のアルゴリズムを実行して結果をゼロに制限することと同じです。 

タスクは各ポジションを割り当てることです`i`からのラベルへ`1`に`k`すべてのサブシーケンスの中で最悪 (最大)`f`値は可能な限り小さいです。 

出力はラベル配列のみであり、サブシーケンス自体ではありません。 

制約は大きいです: 合計`n`すべてのテストケースにわたって、`2e5`。 これにより、テスト ケースごとに二次関数が除外されます。 平`O(n log n)`単純かつ厳密である必要があり、多くのパーティションの部分配列値を再計算しようとするソリューションはすぐに失敗します。 

微妙な点は、サブシーケンスが連続していないため、配列をセグメントに分割するという素朴な直感が直接当てはまらないことです。 もう一つの罠は通訳です`f(b)`間違っています: 空のサブシーケンスに値があるためです`0`、陽性の蓄積がないグループは事実上安全です。 

重要なエッジケース:

 単一の大きなブロック`1`など`1 1 1 1`ここで、グループ化は連続陽性の増加を制御する必要があります。 

次のような交互シーケンス`1 -1 1 -1`、貪欲にバランスをとると、誤ってポジティブな点が集中してしまう可能性があります。 

過激`k = n`、ここで各要素は単独であり、答えは自明に最適です。 

過激`k = 1`、そこではすべてが1つのグループに強制されます。 

## アプローチ

 ブルートフォースビューは、インデックスのすべての割り当てを試みることです。`k`グループ化と計算`f`グループごとに。 代入の組み合わせ爆発を無視しても、コンピューティング`f`各グループにはサブシーケンスのスキャンが必要であり、割り当てが指数関数的に多くなるため、これは直ちに不可能です。 

より構造化された強引な方法は、段階的にグループを構築し、Kadane 値を維持しようとすることです。 それでも、各割り当ての選択は非ローカルな方法で将来の部分配列の合計に影響を与えるため、状態空間は巨大になります。 

重要な観察は、目的はすべてのグループを個別に最適化することではなく、どのグループも連続して有効な値を過度に蓄積しないようにすることだけを目的としているということです。`+1`による中断のない貢献`-1`。 以来`-1`累計をリセットまたは削減します。配布したいと考えています`1`単一のグループが濃すぎる濃度を受けないようにしながら、グループ全体で均等に分散します。 

重要な単純化は、定期的な割り当ての観点から考えることです。 要素を循環的に割り当てると、`k`グループに分割すると、各グループは配列内で間隔をあけて配置された要素を受け取ります。 この間隔により、長時間の連続実行が防止されます。`1`単一グループ内に蓄積しないようにします。 各グループは事実上、大きな正のブロックが分割された配列の「間引き」バージョンを認識します。 

最適な構造は、まさにこの一様分布であることがわかります。位置の割り当て`i`グループ化する`i mod k`。 これにより、連続した実行が保証されます。`1`s は可能な限り均等に分割され、最悪の場合のサブシーケンスの合計が最小限に抑えられます。 均一性からの逸脱はさらに集中する可能性があります`1`をグループのサブセットに分割し、サブ配列の最大合計を増加させます。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`そして`k`。 各インデックスにグループ番号を決定的に割り当てます。 
2. 配列を左から右に繰り返します。 ポジションについて`i`、グループに割り当てます`(i % k) + 1`。 これにより、グループ間で均一な分散が保証されます。 
3. 代入配列を出力します。 

唯一明らかではない部分は、なぜ単純な循環代入で十分なのかということです。 直観的には、部分列の最悪の部分配列の合計は、次の数によって決まります。`1`はそのサブシーケンス順序で連続して着地します。 インデックスを周期的に配布することで、連続的な`1`元の配列内の は投影後に異なるグループに分割されるため、単一のグループが長く途切れることのない正のストリークを蓄積することはありません。 

### なぜ効果があるのか

 各グループは、おおよその間隔で要素を受け取ります。`k`元の配列内の位置。 任意の連続セグメント`t`元の配列内の 1 つは最大でも貢献します`⌈t/k⌉`1 つを任意の 1 つのグループに割り当てます。 以来`-1`は変化しないままであり、潜在的な蓄積をさらに遮断します。 これにより、どのグループも大きな正のプレフィックス合計を形成することがなくなり、境界が形成されます。`f`すべてのグループにわたって均一に。 すべてのグループが対称的に扱われるため、他のグループよりも劣るグループは存在せず、したがってすべてのグループの最大値が最小化されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        res = [(i % k) + 1 for i in range(n)]
        out.append(" ".join(map(str, res)))
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```解決策は実際には次の値に依存しません。`a[i]`、ポジションのみ。 これは意図的なものです。対物レンズの構造により、純粋に位置的な構築が可能になります。 

重要な実装の詳細は、モジュール式の割り当てにゼロベースのインデックスを使用し、次のようにシフトすることです。`+1`出力ラベル用。 これにより、グループ化パターン全体がシフトして対称性が崩れる可能性がある、off-by-one エラーが回避されます。

 ## 特殊なケース

 のために`k = 1`、循環割り当てはグループ 1 に向かうすべての要素に縮退します。アルゴリズムは次を生成します。`1 1 1 ...`他の割り当てはできないため、これは正しいです。 

のために`k = n`、各要素は独自のグループに属します。 循環ルールにより個別のラベルが生成され、最大限の分離が保証されます。 

長時間のランニングに向けて`1`のような`1 1 1 1 1 1`、循環分散により、どのグループも以上のものを受け取ることができなくなります。`⌈n/k⌉`ランからの要素。 たとえば`k = 3`、グループが均等にインターリーブされる`[1,1]`、`[1,1]`、`[1,1]`、したがって、各グループのカダネ値は厳密に制限されます。 

次のような交互パターンの場合`1 -1 1 -1 1`、`-1`すでに累積を防止しており、循環割り当てによりグループ内に新たな隣接関係を導入することなくこの分離が維持されます。
