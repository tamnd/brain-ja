 ## 解決策
 ## 問題の理解

 整数の配列が与えられ、各位置 i と π[i] を組み合わせると、すべての合計 ai + aπ[i] がすべてのインデックス i で同一になるように、1 から n までのインデックスの順列 π を構築するように求められます。 

構造を理解する良い方法は、すべてのインデックス i が 1 つのパートナー π[i] を正確に選択しており、ペアの値が対応する配列値の合計であると想像することです。 この制約により、選択されたすべてのペアの合計が同じになるように強制されます。 π は順列であるため、すべてのインデックスは最初の要素として 1 回、2 番目の要素として 1 回出現する必要があります。これは、構造がグローバル合計の一貫性条件を備えたインデックスで完全に一致していることを意味します。 

n ≤ 2 · 10^5 という制約により、すべてのペアリングの試行やバックトラックなどの 2 次関数は即座に除外されます。 少なくとも O(n log n) または O(n) の動作が必要です。 

いくつかの特殊なケースが構造的に重要です。 すべての値が同一の場合、どのペアリングも機能するため、単純なスワップ戦略は成功します。 非常に特殊な方法で値のバランスが取れていない場合、各値は同じ合計を完成する相補的な値を見つける必要があるため、解決策は存在しません。 

小さな失敗例がその難しさを物語っています。 a = [1, 2, 3] を取る場合、等しい合計を生成する順列にインデックスをペアにする方法はありません。ターゲットの合計を選択すると互換性のない一致が強制されるためです。たとえば、1 と 3 のペアは合計が 4 になりますが、2 はそれ自体とペアになる必要があり、サイズ 3 の順列では不可能です。 

もう 1 つの微妙なケースは、重複が存在するが対称ではない場合です。 たとえば、a = [1, 1, 2, 3]。 1 が繰り返されても、一貫した合計に必要な補数をグローバルに満たすことはできないため、厳密なグローバル構造を強制しない限り、貪欲なローカル ペアリングは失敗する可能性があります。 

## アプローチ

 ブルートフォースの試みは、パートナーを段階的に割り当て、すべての合計が等しいかどうかを確認することによって π を構築しようとすることです。 これにより、n 要素にわたるマッチングを試行することになりますが、各インデックスの選択が将来のすべての互換性に影響を与えるため、最悪の場合には階乗的に増加します。 合計の一貫性による枝刈りでも、最悪の場合には指数関数的な分岐が残ります。 

重要な観察は、すべての合計 ai + aπ[i] が等しい場合、すべての i について、ある定数 S について aπ[i] = S − ai でなければならないということです。これにより、問題は順列を見つけることから、単一の固定ターゲット合計 S を基準にして要素とその補数をペアリングすることに直ちに変換されます。 

任意の一致を推測する代わりに、構造から S を決定できます。 i が j とペアになっている場合、S = ai + aj となるため、すべての有効なペアが候補 S を強制します。これは、S が一貫した方法で最小値と最大値のペアに対応する必要があることを意味します。 配列をソートすると、次の構造が明らかになります。値をソートする場合、固定 S の下で実行可能な唯一のペアリングは、i と n − 1 − i の端から内側に一致することです。 

これにより、問題は、そのような対称ペアリングがすべてのペアにわたって一貫した S を生み出すかどうかを確認することになります。

 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | O(n) | 遅すぎる |
 | ソート + ペアリングの極限 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 元の位置を維持したまま、インデックスを値で並べ替えます。 

有効なペアはグローバルに一貫した相補構造の値と一致する必要があるため、並べ替えが必要です。 
2. 0 から n − 1 までの各 i について、i 番目に小さい要素と (n − 1 − i) 番目に大きい要素をペアにします。 

これは、配列を反転すると対称的な補数が強制されるため、すべての合計を同一に保つことができる唯一のペアリング パターンです。 
3. 最初のペアを使用して目標合計 S を計算します。 

S が固定されると、他のすべてのペアが同じ和を生成する必要があります。そうでない場合、構築は無効になります。 
4. 構築されたすべてのペアが ai + aπ[i] = S を満たすことを確認します。

この手順により、重複値または繰り返し値に隠れた非対称性が存在しないことが保証されます。 
5. すべてのチェックに合格した場合は、それに応じて π を割り当てます。 それ以外の場合は -1 を出力します。 

### なぜ効果があるのか

 有効な順列が存在する場合、ai + aj がグローバル定数 S と等しくなるように、すべてのインデックス i がインデックス j と一致する必要があります。並べ替えでは、有効な補数が並べ替えられたシーケンスの中央値の周りに対称的に表示されるように値が配置されます。 ペアの極端な値から逸脱すると、2 つの異なる合計が強制されたり、インデックスが誤って再利用されたりして、置換制約に違反します。 したがって、ソートされたミラーペアリングは必要かつ十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    if n % 2 == 1:
        # middle element would need to pair with itself
        # only possible if all values equal, handled later
        pass
    
    arr = sorted([(a[i], i) for i in range(n)])
    
    l, r = 0, n - 1
    pi = [0] * n
    
    S = None
    
    while l < r:
        v1, i1 = arr[l]
        v2, i2 = arr[r]
        
        if S is None:
            S = v1 + v2
        else:
            if v1 + v2 != S:
                print(-1)
                return
        
        pi[i1] = i2 + 1
        pi[i2] = i1 + 1
        
        l += 1
        r -= 1
    
    if n % 2 == 1:
        v, i = arr[n // 2]
        # middle must pair with itself
        if 2 * v != S:
            print(-1)
            return
        pi[i] = i + 1
    
    print(*pi)

if __name__ == "__main__":
    solve()
```実装は、元のインデックス空間で順列を再構築しながら対称ペアリング戦略を適用できるように、値とインデックスのペアをソートすることから始まります。 

残りの最小値と残りの最大値をペアにして π を構築します。 最初のペアは S を定義し、無効な完全な構造が構築されるのを避けるために、後続のすべてのペアがそれに対して直ちにチェックされます。 

奇数 n の中間要素のケースは特別です。それ自体にマップする必要があり、これにより 2 · a[mid] が S に等しくなります。この条件が失敗した場合、どの置換も要件を満たすことができません。 

実装の微妙な詳細はインデックス付けです。出力の順列は 1 ベースであるため、格納されているすべてのインデックスは割り当て時にインクリメントされます。 

## 実用的な例

 ### 例 1

 入力:```
4
2 5 1 3
```インデックス付きのソートされた配列:```
(1,3), (2,1), (3,4), (5,2)
```両極端を組み合わせます。 

| ステップ | 左 | 右 | ペア | 和S | アクション |
 | --- | --- | --- | --- | --- | --- |
 | 1 | (1,3) | (5,2) | 3-2 | 6 | S = 6 を設定 |
 | 2 | (2,1) | (3,4) | 1-4 | 5 | 不一致 |

 これは、一貫性をチェックしない単純な極端なペアリングは、構造が完全に一致しない限り失敗することを示しています。 有効な場合、すべてのペアは同一の S を生成します。

 ## 特殊なケース

 n = 1 の場合、唯一の順列は π[1] = 1 であり、インデックスが 1 つしかないため、合計条件は自明に成立します。 このアルゴリズムは、ペアリング ロジックがスキップされた後、S を正しく割り当て、配列全体となる中央の要素の自己ペア条件を設定します。 

a = [1, 2, 3] などの不均一な値を持つ奇数 n の場合、中央の要素は S を 2 · 2 = 4 に強制しますが、極端なペアリングには 1 + 3 = 4 が必要になります。これはこの場合一貫性がありますが、一般的な配列ではこの一貫性は失敗し、S が違反されるとチェックで検出されます。 

a = [1, 1, 2, 2] のような重複した値の場合、並べ替えにより補数が確実に揃うため、アルゴリズムは同一または対称の値を正しくペアにします。 重複によって対称性が崩れると、ペアリング中に S の不一致が直ちに現れ、構築が早期に終了します。
