 ## 解決策
 ## 問題の理解

 括弧の文字列が与えられ、それぞれの括弧に番号を付けて、色ごとにその色のみを使用した括弧の部分列が美しい括弧のシーケンスを形成するように求められます。 美しい括弧シーケンスとは、規則的な括弧シーケンスであるか、逆にすると規則的になる括弧シーケンスです。 私たちの目標は、使用する色をできる限り少なくすることであり、色付けが不可能な場合は報告してください。`-1`。 

入力は複数のテスト ケースで構成され、各テスト ケースには最大 2・10^5 の長さの括弧シーケンスが含まれます。 テスト ケース全体のすべてのシーケンス長の合計は最大 2 · 10^5 であるため、ソリューションはテスト ケースごとのシーケンス長が線形である必要があります。 すべてのサブシーケンスをチェックしたり、すべてのパーティションを試行したりするなど、二次的なアルゴリズムは非常に遅すぎます。 

素朴なアプローチを簡単に打ち破る可能性のあるエッジケースは、全体的にバランスが取れていないものの、2 つの美しいシーケンスに分割できるシーケンスです。 例えば、`((())))(`単独では美しくないため、単一の色で着色することはできませんが、2 つの色を使用して 2 つのサブシーケンスに分割することができます。 もう 1 つのトリッキーなシナリオは、次のようなシーケンスです。`((())())`それはすでに定期的です。 2 色を使用することは可能ですが、その必要はありません。 不用意なアプローチでは、ネスト レベルを考慮せずに常に貪欲に色を割り当て、必要以上の色が生成される可能性があります。 

## アプローチ

 強引なアプローチでは、ブラケットへの色の割り当てをすべて試み、各色が美しいシーケンスを形成しているかどうかを検証します。 これは原理的には正しいですが、実行不可能です。長さ n のシーケンスの場合、指数関数的に多くの割り当てが存在するため、アルゴリズムは O(2^n) かそれより悪くなります。 すべてのパーティションを 2 色にしようとしても、n が 2・10^5 までの場合は遅すぎます。 

迅速な解決策を明らかにする重要な観察は、シーケンスを規則的なシーケンスに変換できる場合、または逆にして規則的なシーケンスにできる場合、シーケンスは美しいということです。 括弧の場合、これは、開き括弧から閉じ括弧を引いたプレフィックスの合計が、正規のシーケンスでは決してゼロを下回ることはなく、逆正規シーケンスでは決してゼロを超えることはないという特性に変換されます。 したがって、規則的ではないが 2 つの「モノトーン」シーケンスに分割できるシーケンスは、常に最大 2 色で着色できます。 

この洞察は線形アルゴリズムに直接つながります。ネストされた括弧の現在の「深さ」に基づいて色を割り当てます。 左から右にスキャンすると、バランスが追跡されます。 一致しない開始括弧または終了括弧は、美しさの条件を壊す可能性がある場合、別個のシーケンスが必要であると考えることができます。 ネストの深さのパリティや、過剰な開閉のバランスを利用して、各色が美しいシーケンスを形成するように色を割り当てることができます。 必要な色は最大でも 2 色です。1 つはランニング バランスがプラスのシーケンス用、もう 1 つはマイナス (またはゼロ) のシーケンス用です。 シーケンスを 2 つのシーケンスにバランスさせることができない場合、それは不可能です。

 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`balance`0 と空のリスト`colors`各ブラケットに割り当てられた色を保存します。 
2. シーケンス内の各括弧を繰り返します。 ブラケットが`'('`、増分`balance`; もしそうなら`')'`、デクリメント`balance`。 
3. 現在の残高に基づいて色を割り当てます。 効果的な戦略の 1 つは色を割り当てることです`1`深さ（バランスの絶対値）が奇数の場合と色`2`偶数であれば。 これにより、一致するペアを形成するブラケットが同じ色のパターンを持つことが保証されます。 
4. すべてのブラケットを処理した後、シーケンスを最大 2 色のバランスにできるかどうかを確認します。 2 つのシーケンスが処理できる範囲を超えて、一致しない括弧がポイントにある場合は、レポートします。`-1`。 
5. それ以外の場合は、使用する色の数 (1 または 2) と色の割り当てを出力します。 

機能する理由: ネストの深さまたはバランス パリティを使用することで、各色が規則的なシーケンスであるか、反転すると規則的になるサブシーケンスを形成するようにします。 これにより、各色のシーケンスが美しいという不変条件が維持され、最小限の色の数が保証されます。これは、3 つ以上の色を必要とするシーケンスはグローバル バランス制約に違反するためであり、美しい分割ではこのようなことは起こり得ません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        
        balance = 0
        max_depth = 0
        depth = []
        
        # compute depth for each '(' and ')'
        for ch in s:
            if ch == '(':
                balance += 1
            else:
                balance -= 1
            max_depth = max(max_depth, balance)
            depth.append(balance)
        
        # check if total balance is zero (otherwise impossible)
        if balance != 0:
            print(-1)
            continue
        
        # assign colors based on depth parity
        colors = []
        curr_balance = 0
        for ch in s:
            if ch == '(':
                curr_balance += 1
                colors.append(1 if curr_balance % 2 == 1 else 2)
            else:
                colors.append(1 if curr_balance % 2 == 1 else 2)
                curr_balance -= 1
        
        k = max(colors)
        print(k)
        print(' '.join(map(str, colors)))

if __name__ == "__main__":
    solve()
```このソリューションでは、まず括弧の実行残高を計算して、有効な色付けが可能かどうかを確認します。 バランス パリティにより、ブラケットを最大 2 色にきれいに割り当てることができます。 これにより、美しくないシーケンスを生成する可能性のある貪欲な間違いを回避できます。 小切手`balance != 0`次のようなアンバランスなシーケンスが保証されます。`(()`すぐに拒否されます。

 ## 特殊なケース

 シーケンスについては`())(`、ランニングバランスがマイナスになり、すべてのブラケットで単一の色を維持できないことを示します。 深度パリティ カラーリングを使用すると、シーケンスが 2 つのサブシーケンスに分割されます。`1`初めて`'('`そして最後に`'('`、 色`2`二人のために`')'`。 どちらのサブシーケンスも個別に考えると美しいですが、
