 ## 解決策
 ## 問題の理解

 文字列が与えられています`s`含まれている`0`、`1`、 そして`?`。 疑問符は柔軟な位置を表します。それぞれを置き換えることができます。`?`どちらとも独立して`0`または`1`。 私たちの目標は、ソートのコストを最小限に抑えて、このパターンに一致する完全なバイナリ文字列を生成することです。 ここで、コストは、文字列を非減少にするために必要な連続する部分文字列の反転の最小数として定義されます。 

たとえば、次の場合`s`は`??01?`、代替品として考えられるのは 1 つです`00011`。 この文字列はすでにソートされているため、コストは 0 です。`11010`の場合、並べ替えるのに複数回の反転が必要になるため、コストが高くなります。 

入力サイズでは、最大 300,000 文字の文字列と最大 30,000 のテスト ケースが許可され、すべてのテスト ケースの合計文字数は最大 300,000 になります。 これは、アルゴリズムは各テスト ケースの文字列長に対して線形時間で実行する必要があることを意味します。 二次関数のアプローチ (次のすべての組み合わせをテストするなど)`?`置き換えたり、すべての逆転をシミュレートしたりすることは不可能です。 

微妙なエッジケースは、パターンがすべてを備えている場合です。`?`文字。 素朴なアプローチでは、それらを恣意的に満たしてしまう可能性があります。`0`またはすべて`1`ただし、最小限のコストが得られない可能性があります。 例えば、`???`理想的にはこうなるはずです`000`または`111`不必要な反転を避けるため、`010`少なくとも1回は逆転を強いられるだろう。 同様に、次のようなパターン`?1?0?`既存の周囲を慎重に埋める必要がある`0`と`1`コストを増加させる減少シーケンスの作成を避けるため。 

## アプローチ

 ブルートフォース手法では、考えられるすべての置換を列挙します。`?`、一致するすべての文字列を生成し、それぞれの反転コストを計算します。 バイナリ文字列をソートするコストは、連続した文字列の「ブロック」をカウントすることで計算できます。`1`最後の後`0`またはその逆。 ある長さの文字列の場合`n`まであります。`2^k`の代替品`k`疑問符。 最悪の場合、`k`そうかもしれない`3*10^5`, したがって、これはまったく実行不可能です。 

重要な洞察は、コストは次からの移行の数によって決まるということです。`1`に`0`最後の文字列で。 連続するすべてのブロック`1`sの後にaが続く`0`ソートするには 1 回の反転が必要です。 したがって、コストを最小限に抑えるには、`1`続いて`0`可能な限り。 これはすぐに貪欲なアプローチを示唆します: 伝播`0`左側にあり、`1`可能な限り右側にあります。 具体的には、どれでも`?`の間`0`そして`1`余分な遷移の作成を避けるために、隣接するものと一致するように選択できます。 もし`?`だけで囲まれています`?`s、安全にどちらにもなりえます`0`または`1`コストを増やすことなく。 

貪欲な伝播は 2 つのパスで機​​能します。1 つの前方パスで処理されます。`0`s と 1 つの逆方向パスを処理する`1`s. これにより、すべてのことが保証されます`?`不要なものを生じさせない方法で充填されます。`1->0`トランジション。 このアルゴリズムは文字列の長さが線形です。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^k * n) | O(n) | 遅すぎる |
 | 貪欲な伝播 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力文字列を変換する`s`文字のリストに変換して、その場で変更できるようにします。 
2. 左から右へ前方パスを実行します。 最後に見たものを追跡する`0`。 いつでも`?`に続きます`0`に置き換えてください`0`。 これにより、新たな問題が発生しないことが保証されます`1->0`トランジションは直後に作成されます。`0`。 
3. 右から左へのバックパスを実行します。 最後に見たものを追跡する`1`。 いつでも`?`の前にある`1`に置き換えてください`1`。 これにより、次からの新たな移行が回避されます。`1`に`0`逆に。 
4. これら 2 回のパスの後、残りのすべてのパスが`?`安全に置き換えることができます`0`（または`1`）それらは分離されており、追加の遷移を作成しないためです。 
5. リストを結合して文字列に戻し、出力します。 

効果がある理由: それぞれ`1->0`バイナリ文字列内の遷移はコストに 1 つ寄与します。 貪欲な伝播により、`?`塗りつぶしは新しいものを導入します`1->0`遷移。 2 パス システムは、すべての位置が既存の影響を受けることを保証します。`0`または`1`コストが増加しない値を採用します。 孤立した状態で残っているもの`?`は端にあるか、均一な文字で囲まれているため、その選択はコストに影響しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        s = list(input().strip())
        n = len(s)

        # Forward pass: propagate 0s
        last_zero = -1
        for i in range(n):
            if s[i] == '0':
                last_zero = i
            elif s[i] == '?' and last_zero != -1:
                s[i] = '0'

        # Backward pass: propagate 1s
        last_one = -1
        for i in reversed(range(n)):
            if s[i] == '1':
                last_one = i
            elif s[i] == '?' and last_one != -1:
                s[i] = '1'

        # Replace remaining '?'
        for i in range(n):
            if s[i] == '?':
                s[i] = '0'

        print("".join(s))

if __name__ == "__main__":
    solve()
```フォワードパスはすべてを保証します`?`に続いて`0`なる`0`、新たな移行を妨げます。 逆方向パスでも同様のことが行われます`1`逆です。 残っているもの`?`孤立しているか端にある s は、`0`■ 有効なバイナリ文字列を生成します。 このアプローチでは、最後に表示された文字が存在する場合にのみ置換が行われるため、off-by-one エラーが回避されます。
