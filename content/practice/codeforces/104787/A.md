 ## 問題の理解

 私たちに与えられているのは、$n \times n$グリッドに数字を配置する必要があります$1$を通して$k$を、グリッドの個別のセルに 1 回ずつ正確に入力します。 他のすべてのセルは空のままです。 配置は 2 つの構造上の制約を満たす必要があります。 

まず、すべての行とすべての列に、少なくとも 2 つの塗りつぶされたセルが含まれている必要があります。 したがって、グリッドが大きい場合でも、グリッドの小さな領域に数値を集中させることはできません。 

次に、すべてのインデックスについて$i$から$1$に$n$、行に配置された数字のセット$i$列に配置された数値のセットと同じ最大公約数を持たなければなりません$i$。 これは、行と列の関係に対する驚くほど強力な制約です。 

出力では、グリッドを印刷するように要求されません。 代わりに、数字ごとに$i$、座標を出力する必要があります$(x_i, y_i)$配置されているセルの。 

制約があるため、私たちは探索ではなく構築へと向かうことになります。 グリッドは大きくなる可能性があり、$n$まで$2 \cdot 10^5$、最大で配置する必要があるかもしれません$10^6$数字。 セルごとに推論したり、グリッドの充填をシミュレートしようとするソリューションは遅すぎるため、線形または線形に近い時間でパターンを構築する必要があります。 

単純なアプローチでは、行と列の有効性をチェックしながら貪欲に数値を配置しようとしますが、ローカルな配置は行と列の両方の gcd 同等性の将来の実現可能性に影響を与えるため、これはすぐに失敗します。 増大するセットに対して gcd を繰り返し再計算すると二次関数の動作が発生するため、妥当性をチェックするだけでもコストがかかります。 

さらに微妙な問題は、行と列の対称性です。 数字を入れると$(i, j)$、行に影響します$i$そしてコラム$j$グローバル構造を強制しない限り、非対称になります。 ここで、ほとんどの素朴で貪欲な戦略が静かに破綻します。 

## アプローチ

 重要な難しさは gcd 条件ですが、数値を値として考えるのをやめ、代わりにその分布に焦点を当てると、はるかに簡単になります。 gcd 制約は、各行または列にどのラベルが表示されるかのみに依存し、ラベルの位置には依存しません。 これは、すべての行を強制する必要があることを示唆しています。$i$列とまったく同じラベルのセットが含まれています$i$。 これが当てはまる場合、gcd は自動的に等しくなります。 

同一の行ラベルと列ラベルのセットを保証する最もクリーンな方法は、主対角線全体で対称性を強制することです。 ラベルなら$t$に置かれます$(i, j)$、にも置きます。$(j, i)$。 それから漕ぎます$i$その列とまったく同じラベルを収集します$i$配置を変えて見ただけのコレクションです。 

これにより、問題は無向グラフの構築に軽減されます。$n$頂点、選択された各エッジ$(i, j)$セルにラベルを配置することに相当します$(i, j)$、そして対称性により、その逆も含めざるを得なくなります。 斜めの配置$(i, i)$セルフループです。 要件は純粋にグラフ理論的なものになります。正確に必要です。$k$選択されたディレクテッド プレースメント、意味$k$すべての頂点の次数が少なくとも 2 であることを保証しながら、対称セルを作成します。 

自然な出発点は、全体にわたる単純なサイクルです$n$頂点。 つながったら$1 \to 2 \to 3 \to \dots \to n \to 1$、すべての頂点の次数はちょうど 2 です。 各無向エッジを 2 つの有向配置として解釈する$(i, j)$そして$(j, i)$, これにより、すべての行と列に少なくとも 2 つの塗りつぶされたセルがあることがすでに保証されます。 

これにより、次のベースが得られます。$n$エッジですが、最大で$10^6$そのため、さらにエッジを追加する必要があります。 重要な観察は、すべての頂点がすでに次数 2 以上を持っていると、余分なエッジを追加しても制約を破ることができないということです。 したがって、タスクは有効な基本構造を拡張して正確に到達することになります。$k$重複を避けながら配置します。 

その後、未使用の有効なセルを任意の順序で追加できます。 斜めのセルはサイクルと衝突しないため、特に便利です。 対角線を使い果たした後、到達するまで残りのペアのスキャンを続けます。$k$配置。

 ## アルゴリズムのチュートリアル

 構築は選択するものであると解釈します。$k$セルの配置は指示されていますが、行と列の構造が同一のままになるように対称性を強制します。 

1. 頂点に初期サイクルを構築する$1 \dots n$。 それぞれについて$i$、 接続する$i$に$i+1$、 と$n$に再び接続されている$1$。 これにより、$n$配置。 これにより、すべての行と列がすでに次数 2 以上であることが保証されます。 
2. 追加の配置を追加するときに重複を避ける必要があるため、これらすべてのサイクル ペアを使用済みとしてマークします。
 3. 自己ループを追加する$(i, i)$みんなのために$i$必要に応じて、到達するまで続けます$k$配置。 これらは既存のエッジに干渉せず、対称性が自動的に維持されるため安全です。 
4. まだ届かない場合$k$、すべてのペアを反復処理します$(i, j)$と$i \le j$、すでに使用されているものをスキップし、正確に到達するまで追加します。$k$。 追加された各ペアは、すぐに使用済みとしてマークされます。 
5. 選択した各ペアを順番に出力し、ラベルを割り当てます$t$に$t$- 番目に選択されたセル。 

### なぜ効果があるのか

 このサイクルにより、すべての頂点の基本次数が 2 になることが保証されるため、追加の作業が行われる前に行と列の制約が満たされます。 セルを無向構造として扱うという意味で、追加の配置はすべて対称的に追加されるため、行$i$そしてコラム$i$常に同一のラベルのセットを受け取ります。 gcd は行または列内のラベルのマルチセットにのみ依存するため、同一のマルチセットは同一の gcd を意味し、構築全体を通じて要件が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, k = map(int, input().split())
    
    used = set()
    res = []

    def add(i, j):
        nonlocal res
        if len(res) >= k:
            return
        if (i, j) in used:
            return
        used.add((i, j))
        res.append((i, j))

    # 1) build cycle
    for i in range(1, n + 1):
        j = i + 1
        if j > n:
            j = 1
        add(i, j)
        if len(res) == k:
            break

    # 2) add diagonals
    if len(res) < k:
        for i in range(1, n + 1):
            add(i, i)
            if len(res) == k:
                break

    # 3) fill remaining arbitrary pairs
    if len(res) < k:
        for i in range(1, n + 1):
            for j in range(i, n + 1):
                add(i, j)
                if len(res) == k:
                    break
            if len(res) == k:
                break

    # output
    for x, y in res:
        print(x, y)

if __name__ == "__main__":
    main()
```実装ではまずサイクルを構築します。これが、行と列の最小サイズ条件を保証するために必要な唯一のステップです。 の`used`set を使用すると、同じセルを 2 回割り当てることがなくなります。これは重要です。繰り返し配置すると、「セルごとに最大 1 つの数値」ルールに違反するためです。 

サイクルの後、対角線を使用して構造を拡張し、次に一般的なペアを拡張します。 ネストされたループは、到達するとすぐに停止するため安全です。$k$、 そして$k$せいぜい$10^6$したがって、成功した挿入の合計数には制限があります。 

主な微妙な点は、正確さが数値ラベル自体ではなく、構造の対称性に完全に依存することです。 サイクルが確立されると、すべての行と列にはすでに十分なサポートがあり、さらに追加しても実現可能性が損なわれることはありません。

## 特殊なケース

 エッジケースの 1 つは次のような場合です$k = 2n$。 この状況では、サイクルはすでに$n$配置と対角線はまったく別のものを与えます$n$, したがって、すべての対角線を埋めるとすぐに建設が停止します。 たとえば、$n = 3, k = 6$、一般的なペアのループに到達することはありません。 

もう 1 つのエッジケースは次のような場合です$k$よりもわずかに大きいです$2n$。 サイクルと対角の両方を使い果たした後、アルゴリズムは一般的なフィル フェーズに入りますが、必要なのは追加のペアがいくつかだけであることです。 すでに使用されているセルをスキップするため、重複は表示されず、終了はすぐに行われます。 

最後のエッジケースは、$n = 2$。 サイクルは$(1,2),(2,1)$、すでに次数制約を満たしています。 追加の対角線$(1,1),(2,2)$有効な値に到達するには十分です$k \ge 4$、そして、行と列の両方に同じ 2 つのラベルが含まれるため、対称性により行と列の gcd の等価性が自明に保証されます。
