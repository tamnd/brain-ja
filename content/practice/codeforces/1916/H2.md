## アプローチ

 ブルートフォースの方法は、すべてを反復処理することです。$p^{n^2}$行列を計算し、各ランクを計算し、結果を集計します。 概念的には正しいですが、完全に非現実的です。$n = 5$そして$p = 2$、行列の数は$2^{25} = 33{,}554{,}432$。 これは実行可能な計算をはるかに超えています。$n \sim 10^{18}$。 

より高速なアプローチでは、既知の数式を使用します。$n \times n$ランクの行列$r$有限のサイズのフィールド上で$p$。 カウントは$$\#\text{rank-}r = \prod_{i=0}^{r-1} \frac{(p^n - p^i)^2}{p^r - p^i} \quad \text{for } r > 0,$$そしてちょうど 1 つの行列$r = 0$。 これは線形代数から来ています。分子は選択する方法の数を数えます。$r$線形に独立した行と$r$線形に独立した列。一方、分母は可逆的であるため過剰カウントを補正します。$r \times r$部分行列。 各項はモジュロで計算できます$998244353$べき乗剰余、逆乗、および階乗のような積を使用します。 なぜなら$k$は小さいため、項のみを計算します$r = 0, \dots, k$、すべてではありません$n$。 非常に大きい場合$n$、計算します$p^n \mod 998244353$高速累乗を効率的に使用します。

 ## アルゴリズムのチュートリアル

 1. 事前計算力$p$モジュロ$998244353$までの値の場合$k$。 これが必要となるのは、次のような用語があるためです。$p^n - p^i$繰り返し現れる。 高速累乗を使用して計算する$p^n \mod 998244353$。 
2. 回答のリストを初期化します。$ans[0] = 1$ランク0の場合。 
3. ランクごとに$r$1から$k$、分子を次のように計算します。$\prod_{i=0}^{r-1} (p^n - p^i)^2 \mod 998244353$。 分母を次のように計算します。$\prod_{i=0}^{r-1} (p^r - p^i) \mod 998244353$。 逆モジュラを使用して、モジュラスの下で除算します。 
4.セット$ans[r] = numerator \times modular\_inverse(denominator) \mod 998244353$。 
5. すべて印刷$ans[r]$のために$r = 0$に$k$。 

機能する理由: この式はランクの行列の正確な数をカウントします。$r$独立した行と列の組み合わせ選択を使用し、可逆数で割ることにより二重カウントを修正します。$r \times r$行列。 モジュラー演算により、非常に大きな演算でもオーバーフローが発生しません。$n$、および演算能力のモジュロ$998244353$巨大な指数を効率的に処理できるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modpow(a, b, mod):
    res = 1
    a %= mod
    while b > 0:
        if b & 1:
            res = res * a % mod
        a = a * a % mod
        b >>= 1
    return res

def modinv(x):
    return modpow(x, MOD-2, MOD)

def solve():
    n, p, k = map(int, input().split())
    ans = [0] * (k+1)
    ans[0] = 1

    p_pows = [1]*(k+1)
    p_n_mod = modpow(p, n, MOD)
    for i in range(1, k+1):
        p_pows[i] = p_pows[i-1] * p % MOD

    for r in range(1, k+1):
        numer = 1
        denom = 1
        for i in range(r):
            numer = numer * (p_n_mod - p_pows[i]) % MOD
            numer = numer * (p_n_mod - p_pows[i]) % MOD
            denom = denom * (p_pows[r] - p_pows[i]) % MOD
        ans[r] = numer * modinv(denom) % MOD

    print(" ".join(map(str, ans)))

if __name__ == "__main__":
    solve()
