 ## 解決策
 ## 問題の理解

 私たちは、友好的なつながりがいくつか知られている学校の生徒のソーシャル グラフを与えられました。 生徒の総数は、$n_1 + n_2$、 どこ$n_1$そして$n_2$コンピュータ科学者と数学者という 2 つの異なるグループの望ましいサイズです。 各学生は他の学生と友人である可能性があり、これらの友人関係は接続されたネットワークを形成するため、1 人を削除した後でも、他の全員は何らかのパスを通じて接続されたままになります。 

私たちの仕事は、すべての生徒をちょうど 2 つのサイズのグループに分けることです$n_1$そして$n_2$、各グループ内で、任意の 2 人の生徒が、そのグループのメンバーのみが関与する友情を通じて互いに連絡を取ることができるようにします。 言い換えれば、各グループは元のソーシャル グラフの接続されたサブグラフを形成する必要があります。 複数のパーティションが存在する可能性があり、有効な解決策であればどれでも受け入れられます。 

この制約により、すべてのテスト ケースにおける生徒の総数が 2000 を超えず、友人関係の総数が 5000 を超えないことがわかります。これは、$O(N+M)$または$O((N+M)\log N)$テスト ケースごとのアプローチは実現可能ですが、テスト ケースごとの生徒数の二次演算を使用するソリューションは危険です。 

明らかではないエッジ ケースには、すでに単一のチェーンまたはスターであるグラフ、または 1 つのグループのサイズが 1 であるグラフが含まれます。$n_1 = 1$そして$n_2 = 4$、友情グラフは 5 つのノードからなる単純な線であり、常に固定接続コンポーネントを選択する単純なアプローチは、シングルトン グループに複数の生徒を選択した場合に失敗する可能性があります。 もう 1 つの微妙なケースは、グラフにサイクルがある場合です。 すべてのパーティションは、生徒を恣意的に割り当てるだけでなく、接続されたサブグラフの制約を尊重する必要があります。 

## アプローチ

 ブルートフォースソリューションでは、サイズのすべてのサブセットが考慮されます。$n_1$そして、誘導された部分グラフが接続されているかどうかを確認します。 これは原理的には正しいですが、サブセットの数が組み合わせによって増加し、接続コストを確認するため、完全に実行不可能です。$O(N+M)$サブセットごとに。 最悪の場合に備えて$n_1 + n_2 \approx 2000$、このアプローチでは時間がかかりすぎます。 

効率的なソリューションを可能にする重要な点は、保証された接続特性から得られます。 グラフは 2 頂点接続されているため (いずれか 1 つのノードを削除すると、グラフは接続されたままになります)、各接続コンポーネントは堅牢です。 これは、任意の開始ノードから BFS または DFS を実行することでグループを安全に拡張できることを意味します。$n_1$1 つのグループで遭遇するノード。 すでに割り当てられているノードを削除しても元のグラフを切断できないため、残りのノードは自動的に接続されたサブグラフを形成します。 この洞察により、問題は、グループ サイズを考慮した慎重なカウントと組み合わせた単純なグラフ走査に帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべてのサブセット + 接続チェック) | O(2^(N) * (N+M)) | O(N+M) | 遅すぎる |
 | BFS/DFS グループの選択 | O(N+M) | O(N+M) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 テスト ケースごとに、次の内容を読んでください。$n_1$、$n_2$、 そして$m$、続いて$m$友情のつながり。 
2. 友情グラフの隣接リストを作成します。 各生徒はノードとして表され、それぞれの友情は無向エッジです。 
3. Initialize a visited array of size$n_1+n_2$どの生徒がグループに割り当てられているかを追跡するため。 
4. 未訪問のノードから DFS (または BFS) を開始します。 グラフを移動しながら、データが収集されるまで最初のグループに生徒を追加します。$n_1$学生たち。 
5. 最初のグループがサイズに達したら$n_1$、残りの未訪問の学生を 2 番目のグループに属するものとしてマークします。 グラフは完全に接続されており、2 つの頂点で接続されているため、これらの残りの生徒は接続された部分グラフを形成し、問題の制約を満たします。 
6. 2 つのグループを任意の順序で出力し、各グループに指定された数の生徒が正確に含まれるようにします。 

機能する理由: 不変条件は、接続されたコンポーネントの DFS または BFS トラバーサルが、接続された順序でノードにアクセスすることです。 後に停止することで$n_1$これらのノードが接続されたサブグラフを形成することを保証します。 2 頂点接続グラフの接続されたサブグラフを削除すると、残りの部分は接続されたままになるため、残りのノードも接続されたままになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10000)

def solve():
    t = int(input())
    for _ in range(t):
        n1, n2, m = map(int, input().split())
        n = n1 + n2
        adj = [[] for _ in range(n)]
        for _ in range(m):
            a, b = map(int, input().split())
            adj[a-1].append(b-1)
            adj[b-1].append(a-1)
        
        visited = [False]*n
        group1 = []

        def dfs(u):
            if len(group1) >= n1:
                return
            visited[u] = True
            group1.append(u)
            for v in adj[u]:
                if not visited[v]:
                    dfs(v)

        dfs(0)
        group2 = [i for i in range(n) if i not in group1]

        print(' '.join(str(x+1) for x in group1))
        print(' '.join(str(x+1) for x in group2))

if __name__ == "__main__":
    solve()
```DFS は最初の生徒から始まり、最初のグループを正確に満たします。$n_1$ノード。 グラフが接続されているため、これらのノードはすべて接続されています。 残りのノードは自動的に 2 番目のグループを形成します。 入力は 1 から始まりますが、Python リストは 0 から始まるため、インデックス付けは慎重に処理します。 また、誤ってノードを追加しすぎないように、最初のグループが必要なサイズに達したら DFS を停止します。
