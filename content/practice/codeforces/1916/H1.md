 ## 解決策
 ## 問題の理解

 私たちは次のことに取り組んでいます$n \times n$サイズの有限フィールド内にエントリが存在する行列$p$、すべてのエントリが整数の剰余であることを意味します$p$そして算術演算は体上で線形代数のように動作します。 考えられるランクごとに$r$、そのような行列が正確にランクを持っている数を数えたいとします。$r$、すべてのカウントを報告します$r \le k$、モジュロ$998244353$。 

ここでの行列のランクは、その行 (または列) がまたがるベクトル空間の次元であるため、行列に含まれる独立した方向の数が把握されます。 Aランク$0$行列はすべてゼロの行列ですが、ランクは$n$行列はフルランクの可逆行列です。 

難しいのは、$n$と同じ大きさにすることができます$10^{18}$したがって、行や列を構築したり反復したりするアプローチは不可能です。 使用可能な唯一の構造は、以下に依存する代数的な計数公式です。$n$、$p$、 そして$r$、明示的な行列構築ではありません。 

重要な制約は、$k \le 5000$したがって、必要なのは最初の数ランクのみです。 それでも$n$巨大です、$r$計算では小さいままです。これは、答えが、によってインデックス付けされた製品に依存する必要があることを強く示唆しています。$r$ではなく、$n$。 

よくある失敗例は、問題を次のように扱うことから生じます。$n$は小さく、ガウス消去法による列挙を試みていました。 たとえば、次のようなとき$n=3, p=2$、ランク分布はすでに自明ではなく、ブルートフォースオーバー$2^{9}$行列は機能しますが、$n=100$、これは不可能になります。 もう 1 つの失敗モードは、ランク数が部分空間次元の選択だけではなく、独立した行空間と列空間を同時に選択することに依存することを無視していることです。 

## アプローチ

 素朴なアプローチは、すべてを生成することです$n \times n$行列以上$\mathbb{F}_p$、ガウス消去法によってランクを計算し、カウンターを増加します。 ランクは明確に定義されており、ガウス消去法はフィールド全体で正確であるため、これは正しいです。 ただし、行列の数は、$p^{n^2}$、そしてさらには$n=10$これはすでに天文学的な規模です。 ボトルネックは列挙とランク計算の両方であり、これは完全に実行不可能です。 

重要な構造的観察は、ランクのマトリックスが$r$次のように分解できます。$r$-次元列スペース、選択します$r$-次元の行スペース、そして反転可能なものを選択します$r \times r$それらの間のマップ。 これが標準的なランク因数分解の観点です。 

これは、カウントを 3 つの独立した部分に分割することを示唆しています。 

まず、次のものを選択します$r$-次元部分空間$\mathbb{F}_p^n$列スペース用。 このような部分空間の数はガウス二項係数です$\binom{n}{r}_p$。 

次に、次のものを選択します$r$- 次元行スペース、独立して、再び貢献$\binom{n}{r}_p$。 

第三に、これらの空間間の可逆線形変換を選択します。これは、可逆変換の数に寄与します。$r \times r$行列以上$\mathbb{F}_p$で示される$|GL(r, p)|$。 

ただし、同じ行列が選択された部分空間の異なる基底を介して表現できるため、これは過剰になります。 正しい分解では、ガウス二項構造内で暗黙的に基底を固定することでこの問題を解決します。 の数の最終的な既知の正体$n \times n$ランクの行列$r$以上$\mathbb{F}_p$は：$$\frac{\prod_{i=0}^{r-1} (p^n - p^i)^2}{\prod_{i=0}^{r-1} (p^r - p^i)}$$この式はランクの構築から得られます。$r$線形独立性を確保しながら行列を行ごとに計算し、行空間の底を選択する方法の数で割ることで過剰カウントを修正します。 

ここで制約を利用します$k \le 5000$。 小さい値のみを計算します$r$, そのため、製品を段階的に構築できます。 唯一の依存先は、$n$という観点から現れます$p^n$、これは全体にわたって一定です$r$高速累乗を使用して一度だけ事前計算できます。 

ブルートフォースの失敗は、各行列を独立して処理するために発生しますが、最適解では代わりに部分空間と線形マップの構造化された選択肢がカウントされ、問題が単純な項の積に圧縮されます。

 ## アルゴリズムのチュートリアル

 1. 事前計算$q = p^n \bmod M$高速べき乗剰余演算を使用します。 この値は、次元ごとに利用可能な線形結合の数を表し、すべてのランク計算で再利用されます。 
2. ランクごとに$r$、分子を構築します$\prod_{i=0}^{r-1} (q - p^i)^2$。 これは選択に対応します$r$独立した列と行の方向を順番に実行します。各ステップでは、以前に広がっていた方向が削除されます。 
3. 分母を構築する$\prod_{i=0}^{r-1} (p^r - p^i)$、これは、内部で基底を選択する方法の数を説明します。$r$-次元空間。 これにより、同じ部分空間の異なる基底表現によって引き起こされる過剰カウントが修正されます。 
4. 各答えを次から段階的に計算します。$r=0$に$k$の分子積と分母積を更新します。$O(1)$連続するランク間の漸化関係を使用してステップごとに。 
5. 逆モジュラーを使用して、モジュロの分母​​で除算します。$998244353$、有限体の演算における正確性を保証します。 

### なぜ効果があるのか

 アルゴリズムはランク因数分解を直接列挙したものです$A = UV$、 どこ$U$そして$V$列と行のスペースをエンコードします。 各ランク$r$行列は、の選択に一意に対応します$r$-次元画像空間、$r$-次元カーネル補数、およびそれらの間の可逆変換。 積項は順序付けられた独立したベクトル選択をカウントしますが、分母は基底選択への依存を取り除きます。 すべての行列には基底変化まで正確に 1 つのランク分解があるため、カウントは正確であり、構成の欠落や二重カウントはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

n, p, k = map(int, input().split())

q = modpow(p, n)

# precompute powers of p up to k
pows = [1] * (k + 1)
for i in range(1, k + 1):
    pows[i] = pows[i - 1] * p % MOD

ans = [0] * (k + 1)

num = 1
den = 1

ans[0] = 1

for r in range(1, k + 1):
    # update numerator: multiply by (q - p^(r-1))^2
    x = (q - pows[r - 1]) % MOD
    num = num * x % MOD * x % MOD

    # update denominator: multiply by (p^r - p^(r-1))
    den = den * ((pows[r] - pows[r - 1]) % MOD) % MOD

    ans[r] = num * pow(den, MOD - 2, MOD) % MOD

print(*ans)
```コードは最初に計算します$p^n$すべてのランク用語で繰り返し出現するためです。 次に、次のべき乗を事前計算します。$p$なぜなら、形式の表現は$p^i$分子と分母の両方の更新に表示されます。 

このループは、ランク式の実行中の製品を維持します。 各ステップで、分子は、すでに占有されているスパンを減算することで表される、独立した次元を 1 つ追加するという寄与を獲得します。 分母は、新しく形成された部分空間の内部基底の選択を修正します。 モジュラー反転は累積された分母でのみ使用され、ループ内でコストのかかる累乗を繰り返すことを回避します。 

実装の微妙な詳細は、モジュロでの減算の処理です。 両方$q - p^i$そして$p^r - p^{r-1}$に正規化して戻す必要があります$[0, MOD)$負の剰余の伝播を避けるために乗算の前に。

 ## 特殊なケース

 いつ$k = 0$の場合、ランク 0 の行列 (すべてゼロの行列) が 1 つだけ存在するため、アルゴリズムはすぐに 1 を出力します。 ループは完全にスキップされ、分子と分母が 1 から始まるという不変条件により正確さが保証されます。 

いつ$n = 1$、ランク 0 と 1 のみが可能です。 この式は、単一のエントリがゼロであるかゼロ以外であるかをカウントすることに帰着し、式は次の結果を生成します。$1$そして$p-1$それぞれ、予想される構造と一致します$\mathbb{F}_p$。 

いつ$p = 2$、減算は大幅に単純化され、多くの中間値は出力係数を法として 0 または 1 に折りたたまれます。 すべての演算がモジュロで実行されるため、実装は引き続き機能します。$998244353$、モジュロではありません$p$、最小のフィールドでも組み合わせ計数の正確さを維持します。
