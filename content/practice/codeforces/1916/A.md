 ## 問題の理解

 未知の配列から始めます`a`すべての要素の積が正確に`2023`。 いくつかの`k`要素が削除され、配列が残されました`b`長さの`n`。 

タスクは、そのような元の配列が存在する可能性があるかどうかを判断することです。 可能であれば、有効なセットを出力する必要があります。`k`数字を削除しました。 すべての数値を乗算した後、`b`出力するすべての数値の結果は正確でなければなりません`2023`。 

重要な点は、要素の順序は重要ではないということです。 製品だけが重要です。 残りの数値の積がすでに大きすぎるか、約数ではない場合`2023`、配列を完成させる方法はありません。 それ以外の場合は、その積が欠落している因数を埋める、削除された数値を選択できます。 

制約は非常に小さいです。 両方`n`そして`k`せいぜい`5`、多くても`100`テストケース。 多くの可能性を徹底的に調べても、問題なく制限内に収まります。 それでも、この問題には、テスト ケースごとに一定時間で実行される単純な数学的解決策があります。

## アプローチ

 強引なアイデアは、可能なすべてのコレクションを試してみることです。`k`数値を削除し、その積に次の積を乗算したかどうかを確認します。`b`、等しい`2023`。 

これが機能するのは、ターゲット製品が固定されており、非常に小さいためです。 ただし、制約が小さい場合でも、任意の候補値を許可すると、検索空間は急速に拡大します。 このアプローチは要因の推測と組み合わせの探索に依存しますが、これは不必要です。 

問題の構造は、より単純な方向性を示唆しています。 元の積は事前にわかっています。```
2023 = 7 × 17 × 17
```させて```
P = product of all elements in b
```元の配列が存在する場合、```
P × (product of removed numbers) = 2023
```これはすぐに次のことを意味します`P`分けなければなりません`2023`。 

もし`2023 % P != 0`、解決策は存在しません。 

それ以外の場合、不足している製品は```
M = 2023 / P
```今、私たちはまさに必要としています`k`削除された数値の積は`M`。 

最も簡単な構築は、`M`最初に削除された数値として残りを埋めます`k - 1`との位置`1`。 彼らの製品は残っています`M`なので、条件は満たされています。 

これにより、問題全体が 1 つの可分性チェックに減ります。

 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.積を計算する`P`指定された配列内のすべての要素の`b`。 
2. かどうかを確認します。`2023`で割り切れます`P`。 

もし`2023 % P != 0`、出力`"NO"`なぜなら、削除された数字を集めても正確な合計を作ることはできないからです。`2023`。 
3. それ以外の場合は、欠損係数を計算します。```
M = 2023 / P
```4. 出力`"YES"`。 
5. 削除した数値を次のように構築します。```
[M, 1, 1, ..., 1]
```まさに`k`数字。 
6. このリストを出力します。 

### なぜ効果があるのか

 しましょう`P`残りの配列の積になります。 

もし`P`分けない`2023`の場合、削除された数値の積は次と等しくなります。`2023 / P`、これは整数ではありません。 すべての配列要素は整数であるため、有効な元の配列は存在できません。 

もし`P`分割する`2023`、 定義する`M = 2023 / P`。 構築された削除された数値には積があります```
M × 1 × 1 × ... × 1 = M
```したがって、再構成された配列のすべての要素の積は次のようになります。```
P × M = P × (2023 / P) = 2023.
```建設は常に正確に生産します`k`したがって、受け入れられたすべてのケースから有効な答えが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, k = map(int, input().split())
    b = list(map(int, input().split()))

    prod = 1
    for x in b:
        prod *= x

    if 2023 % prod != 0:
        print("NO")
    else:
        print("YES")
        missing = 2023 // prod
        ans = [missing] + [1] * (k - 1)
        print(*ans)
```最初の部分では、残りの要素の積を計算します。 以来`n ≤ 5`すべての値は最大でも`2023`、この積は Python の整数演算に簡単に適合します。 

可分性テストは、実現可能性のチェック全体です。 残った積が約数にならない場合`2023`、再建は不可能です。 

再構築が可能な場合、コードは欠損係数を計算します。`2023 // prod`。 その値が最初に削除された要素になります。 残りのポジションは次のように埋まっています。`1`これは製品を変更するものではなく、その正確性を保証します。`k`数字が印刷されています。 

最終的な積のみが重要であるため、乗算の順序は関係ありません。

# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    out = []
    t = int(input())

    for _ in range(t):
        n, k = map(int, input().split())
        b = list(map(int, input().split()))

        prod = 1
        for x in b:

            out.append("NO")
        else:
            out.append("YES")
            missing = 2023 // prod
            ans = [missing] + [1] * (k - 1)
            out.append(" ".join(map(str, ans)))

    return "\n".join(out) + "\n"
