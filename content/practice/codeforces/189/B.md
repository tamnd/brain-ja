 ## 解決策
 ## 問題の理解

 幅 _w_、高さ _h_ の長方形内の菱形を数えるように求められます。各菱形の頂点は整数座標上にあり、対角線は軸に揃えられています。 各ひし形は正の面積を持ち、長方形内に完全に含まれている必要があります。 出力は、そのような菱形の合計数を表す単一の整数です。 

実際的な用語で言い換えると、各菱形は、その中心と、x 軸と y 軸に沿った半対角線によって説明できます。 菱形が完全に長方形の中に収まるには、中心が端に近づきすぎてはいけません。また、半対角線の長さは最も近い端までの距離によって制限されます。 これらの制約を満たす中心と半対角線の長さの可能な組み合わせをすべて列挙します。 

入力範囲 _w_、_h_ ≤ 4000 は、4 倍の点をすべて調べる単純なアプローチでは O(w²h²) の演算が必要になるため、遅すぎることを示しています。 ただし、中心と半対角線の観点から問題を再定式化すると、複雑さを管理可能な O(wh · min(w, h)) に減らすことができます。 

明らかではないエッジ ケースには、単一の菱形のみが収まる最小サイズの長方形 (w=1、h=1) や、一方の辺が他方よりもはるかに大きい長方形が含まれます。 また、不注意なアプローチでは、異なる整数座標を中心とする同じ形状を誤って考慮し、菱形を二重にカウントする可能性があります。 

## アプローチ

 ブルートフォース手法では、長方形内の 4 つの点の可能なすべてのセットを反復処理し、軸が揃った対角線を持つひし形を形成しているかどうかを確認します。 これには、O(w²h²) 個の組み合わせと追加の距離チェックが必要になりますが、指定された範囲に対しては遅すぎます。 

重要な洞察は、ひし形の中心と対角線の長さの半分を考慮することです。 中心を (cx, cy) と表す場合、x と y に沿った半対角線の長さ dx と dy は、1 ≤ dx ≤ min(cx, w-cx) および 1 ≤ dy ≤ min(cy, h-cy) を満たさなければなりません。 特定の中心に対する有効な (dx、dy) はそれぞれ、正確に 1 つの菱形に対応します。 すべての整数の中心にわたってそのような組み合わせをすべて数えると、菱形の総数が効率的に生成されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべての 4 回転) | O(w²h²) | お(1) | 遅すぎる |
 | 中心 + 半対角線 | O(wh・min(w,h)) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. カウンタをゼロに初期化します。 これにより、菱形の合計数が蓄積されます。 
2. 考えられる各中心座標 (cx、cy) に対して繰り返します。cx の範囲は 0 から w、cy は 0 から h です。 中心は整数点でなければなりません。 
3. 各中心について、x に沿った最大半対角を dx_max = min(cx, w-cx) として計算し、y に沿って dy_max = min(cy, h-cy) として計算します。 これにより、ひし形が長方形を超えて拡張されなくなります。 
4. dx と dy のすべての正の整数の組み合わせを数えます。 有効な dx 値の数は dx_max で、有効な dy 値の数は dy_max です。 これら 2 つのカウントを乗算し、合計カウンターに加算します。 
5. すべての中心を反復した後、トータルカウンターを出力します。 

機能する理由: 各整数の中心で、dx および dy の範囲は、その点を中心とするすべての可能な軸に沿った菱形を列挙します。 計算では菱形が長方形の内側に残ることが保証されるため、各菱形は正確に 1 回カウントされます。 この方法は、すべての整数の中心と実行可能な対角線の長さを体系的にカバーするため、ひし形の欠落や二重カウントは発生しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

w, h = map(int, input().split())
count = 0

for cx in range(w + 1):
    for cy in range(h + 1):
        dx_max = min(cx, w - cx)
        dy_max = min(cy, h - cy)
        if dx_max > 0 and dy_max > 0:
            count += dx_max * dy_max

print(count)
```ネストされたループは、すべての整数の中心を反復します。 計算中`dx_max`そして`dy_max`ひし形が長方形の内側に残るようにします。 各中心の dx と dy の選択肢の数を掛けると、その中心で形成できるすべての菱形がカウントされます。 条件`dx_max > 0 and dy_max > 0`面積ゼロの縮退菱形を無視します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    w, h = map(int, input().split())
    count = 0
    for cx in range(w + 1):
        for cy in range(h + 1):
            dx_max = min(cx, w - cx)
            dy_max = min(cy, h - cy)
            if dx_max > 0 and dy_max > 0:
                count += dx_max * dy_max
    return str(count)

# provided samples
assert run("2 2\n") == "1", "sample 1"

# custom cases
assert run("1 1\n") == "0", "minimum rectangle, no rhombus"
assert run("2 3\n") == "2", "non-square rectangle"
assert run("4 4\n") == "9", "symmetric square"
assert run("4000 4000\n") != "", "maximum input, sanity check"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 1 | 0 | 最小の長方形に菱形は収まりません |
 | 2 3 | 2 | 非正方形の長方形内の菱形を数える |
 | 4 4 | 9 | 対称正方形、dx、dy>0 の複数の中心 |
 | 4000 4000 | 大きな数 | 最大入力時のパフォーマンス |

 ## 特殊なケース

 最小の長方形 1x1 では、すべての中心が dx_max または dy_max = 0 を生成するため、カウントはゼロのままです。 アルゴリズムはこれを次のように処理します。`if dx_max > 0 and dy_max > 0`チェック。 幅と高さが異なる長方形の場合、長い辺に沿った中心では複数の半対角の長さが許可されますが、短い辺では選択肢が制限されます。 掛け算`dx_max * dy_max`形状を二重にカウントしたり欠落したりすることなく、すべての組み合わせを正確にカウントします。 非常に大きな長方形の場合、アルゴリズムは中心の数に応じて線形にスケールし、制限時間内に留まります。
