 ## 解決策
 ## 問題の理解

 この問題では、アップル氏が 2 つの別々の日に味わった 2 組の料理に正の整数のスコアを割り当てるように求められます。 初日の各料理は 2 日目の各料理と比較でき、比較結果は良いか悪いか、または同等になります。 私たちの目標は、最大スコアをできるだけ低く抑えながら、これらの関係が満たされるように料理に番号を割り当てることです。 本質的に、これは制約充足問題であり、制約は料理間のペアごとの比較から得られます。 

入力はサイズ n × m の行列です。ここで、n は 1 日目の料理の数、2 日目の料理の数です。 各要素は「>」、「<」、または「=」のいずれかです。 出力は、2 つの数値シーケンスがすべての比較を満たす場合は「Yes」、それが不可能な場合は「No」のいずれかでなければなりません。 n と m はそれぞれ最大 1000 まで可能であるため、内部演算ごとに O(n*m) 未満に留まる場合には単純な O(n_m_something) アプローチも実現可能ですが、両方の次元で二次関数を繰り返し行うと遅すぎる可能性があります。 

重要なエッジケースは、比較行列が矛盾する場合に発生します。 たとえば、1 日目の料理 1 が 2 日目の料理 1 よりも優れているが、別の行で同等とマークされている場合、または不等式が循環を形成している場合、有効な割り当てはありません。 複数の料理が等しい場合、別の微妙なエッジケースが発生します。 等しいディッシュをグループ化せずに「<」と「>」を個別に処理すると、単純な貪欲な割り当てが誤って「=」制約に違反する可能性があります。 

## アプローチ

 ブルートフォースアプローチは、両方の料理セットに可能なすべての正の整数の代入を試み、それぞれの比較をチェックすることです。 これは原理的には正しいですが、n と m がそれぞれ最大 1000 になる可能性があり、2 秒の制限時間にはあまりにも大きな可能性があるため、実行不可能です。 考えられるすべてのシーケンスを妥当な最大数まで生成するだけでも、天文学的に時間がかかります。 

重要な洞察は、問題が等価圧縮を使用した有向グラフとしてモデル化できることを認識することで得られます。 各ディッシュはノードに対応します。 すべての「>」関係について、小さいノードから大きいノードまでエッジを追加します。 「<」ごとに、エッジは逆になります。 等しいディッシュは 1 つのノードにマージされます。 すべての制約を表す有向グラフを作成したら、問題は、すべてのエッジが低い値から高い値に向かうように、各ノードに最小の正の整数を割り当てることになります。 これは、等しいノードをグループ化した後で DAG 内の最長パスを計算することと同等であり、トポロジカル ソートと動的プログラミングを使用して実行できます。 

このアプローチは問題の構造を利用しています。つまり、制約は推移的であり、「=」を使用するとノードをマージできるため、グラフが大幅に簡素化されます。 これにより、指数関数的な割り当ての問題が、圧縮された DAG 上の線形時間グラフのトラバーサル問題に縮小されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((最大値)^(n+m)) | O(n+m) | 遅すぎる |
 | グラフ + トポソート | O(n*m) | O(n+m) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 各ディッシュをノードとして表すことから始め、Disjoint Set Union (DSU) 構造を初期化して、「=」で接続されたノードをマージします。 (i,j) の行列内のすべての「=」について、1 日目のノード i と 2 日目のノード j をマージし、同じ値を受け取るようにします。 
2. 等しいノードをマージした後、マトリックスを再度反復して制約の有向グラフを構築します。 a_{ij} の各「">」について、料理 j (2 日目) を表すノードからノード i (1 日目) までのエッジを作成します。これは、1 日目の料理の方が大きな番号を持つ必要があるためです。 「<」の場合、ノード i からノード j までのエッジを作成します。 
3. グラフ内のサイクルを確認します。 循環が存在する場合、一貫して番号を割り当てることができないため、「いいえ」を出力します。 サイクル検出は、訪問済み状態配列を使用した深さ優先検索を使用するか、トポロジカル ソートを試みることによって実行できます。 
4. グラフが非巡回の場合は、トポロジー順序に対する動的プログラミングを使用して、最小の整数割り当てを計算します。 各ノードの値は、その先行ノードの最大値より 1 大きい値です。 入力エッジのないノードを 1 に初期化します。 
5. DSU 親配列を使用して、値を元のディッシュにマッピングし直します。 各ディッシュは、その代表ノードの値を受け取ります。 
6.「Yes」に続いて、1日目の料理と2日目の料理に割り当てられた値を出力します。 

機能する理由: 等価マージでは、「=」制約が常に満たされることが保証されます。 有向グラフはすべての厳密な不等式を表し、トポロジカルな順序付けにより、各ディッシュの値が、それより大きくなければならないディッシュよりも厳密に大きいことが保証され、「<」と「>」の制約が維持されます。 この最小性は、ソースに 1 を割り当て、エッジに沿って増加することから生まれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import defaultdict, deque

class DSU:
    def __init__(self, n):
        self.par = list(range(n))
    def find(self, x):
        if self.par[x] != x:
            self.par[x] = self.find(self.par[x])
        return self.par[x]
    def union(self, x, y):
        x = self.find(x)
        y = self.find(y)
        if x != y:
            self.par[y] = x

def solve():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]
    total = n + m
    dsu = DSU(total)

    # Merge equal nodes
    for i in range(n):
        for j in range(m):
            if grid[i][j] == '=':
                dsu.union(i, n + j)

    # Build graph of inequalities
    graph = defaultdict(list)
    indeg = [0] * total
    for i in range(n):
        for j in range(m):
            u = dsu.find(i)
            v = dsu.find(n + j)
            if grid[i][j] == '<':
                if u == v:
                    print("No")
                    return
                graph[u].append(v)
                indeg[v] += 1
            elif grid[i][j] == '>':
                if u == v:
                    print("No")
                    return
                graph[v].append(u)
                indeg[u] += 1

    # Topological sort to assign minimal values
    val = [0] * total
    dq = deque([i for i in range(total) if dsu.find(i) == i and indeg[i] == 0])
    while dq:
        u = dq.popleft()
        if val[u] == 0:
            val[u] = 1
        for v in graph[u]:
            if val[v] < val[u] + 1:
                val[v] = val[u] + 1
            indeg[v] -= 1
            if indeg[v] == 0:
                dq.append(v)

    # Check if all nodes got a value
    for i in range(total):
        if val[dsu.find(i)] == 0:
            print("No")
            return

    print("Yes")
    first_day = [val[dsu.find(i)] for i in range(n)]
    second_day = [val[dsu.find(n + j)] for j in range(m)]
    print(' '.join(map(str, first_day)))
    print(' '.join(map(str, second_day)))

if __name__ == "__main__":
    solve()
```DSU は、等価制約を満たすために「=」ディッシュをマージします。 グラフの端は厳密な不平等を反映しています。 トポロジカルソートを使用すると、すべての「<」と「>」の制約を尊重しながら、可能な最小限の整数を割り当てることができます。 元の料理への最終的なマッピングにより、個々の料理ごとに値が出力されます。 

## 実用的な例

 サンプル 1 の入力:```
3 4
>>>>
>>>>
>>>>
```トレース:

 | ノード | 度 | 割り当てられた値 |
 | --- | --- | --- |
 | 0、1、2 | 0 | 2 |
 | 3,4,5,6 | 3 | 1 |

 初日の料理はすべて 2 日目の料理よりも高くなります。 アルゴリズムは、制約と一致する最小値として、初日に 2、2 日目に 1 を割り当てます。 

サンプル 2 の入力 (矛盾):```
2 2
><
<>
```等価マージの後、ノード 0 > ノード 2、ノード 0 < ノード 3、ノード 1 < ノード 2、ノード 1 > ノード 3。グラフにはサイクルが含まれています。 トポロジカル ソートは失敗し、出力は「No」になります。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n*m) | 等しいノードをマージしてグラフを構築するには、各要素を 1 回調べる必要があります。 トポロジーソートは O(V+E) で、V ~ n+m および E ~ n*m です。 |
 | スペース | O(n+m) | DSU、グラフ隣接リスト、度数、および最終値を保存します。 |

 この複雑さは、制限 n*m ≤ 10^6 に簡単に適合するため、グリッドの線形スキャンは許容されます。 メモリは 256 MB をはるかに下回ります。

    sys.stdout = io.StringIO()
