 ## 解決策
 ## 問題の理解

 船は、軸を揃えた 2 つの長方形を積み重ねることによって形成されます。 下の長方形には幅があります`w1`と高さ`h1`。 上の長方形には幅があります`w2`と高さ`h2`、最初の長方形のすぐ上で左端が揃った状態で開始されます。 

船が破壊された後、船の側面または角に接触するすべてのセルにマークを付ける必要があります。 船自体に属するセルはカウントされません。 フィールドは無限であるため、形状の周囲のセルを数えるだけで済みます。 

入力により 2 つの長方形の寸法が得られます。 出力は、結合された形状の周囲のマークされたセルの数です。 

制約により、次の寸法が許容されます。`10^8`。 このサイズの長方形には、個別に列挙するには多すぎるセルが含まれています。 船を保管することさえ不可能でしょう。 セルの反復処理に依存するソリューションは除外されます。 一定時間で実行される直接的な数式が必要です。 

よくある間違いは、船を幅のある単一の長方形と考えることです。`w1`と高さ`h1 + h2`。 それは次の場合にのみ機能します`w1 = w2`。 考慮する：```
w1 = 4, h1 = 1
w2 = 2, h2 = 1
```上の長方形は幅が狭くなり、右側に垂直な段差が生じます。 そのステップの周囲のセルは、単純な周囲数式では見逃してしまう余分なマークされたセルに寄与します。 

幅が等しい場合には、別の微妙なケースが発生します。```
w1 = 2, h1 = 1
w2 = 2, h2 = 1
```その形は実は、`2 × 2`矩形。 幅の差の寄与を盲目的に追加する式では、ステップがないためオーバーカウントされます。 

最低限のケース```
w1 = 1, h1 = 1
w2 = 1, h2 = 1
```off-by-one エラーをチェックするのに役立ちます。 船は 2 つの積み重ねられたセルを占有しており、周囲のちょうど 10 個のセルにマークを付ける必要があります。 

## アプローチ

 ブルートフォースソリューションでは、グリッド上に船を明示的に構築し、すべての船セルの周囲のすべての隣接位置を検査します。 セルが少なくとも 1 つの船舶セルに触れていて、それ自体が船舶の一部ではない場合、そのセルはマークされます。 

このアプローチは定義に直接従うため、正しいです。 問題は規模だ。 長方形には最大で次のものを含めることができます`10^8 × 10^8`細胞なので、船には以下のものが含まれる可能性があります`10^16`細胞。 それらを列挙することはまったく不可能です。 

重要な観察は、形状の周囲の 1 セルの厚さの境界内のセルの数だけが必要であるということです。 

船を描画し、それをあらゆる方向に 1 セルずつ拡張することを想像してください。 船のセル自体を除き、マークされたすべてのセルはこの拡張されたアウトラインに属します。 

個々のセルについて推論する代わりに、形状の境界から寄与を数えることができます。 

外側の境界線から始めます。 

左側が貢献する`h1 + h2`細胞。 

右側も貢献します`h1 + h2`細胞。 

一番下が貢献してる`w1`細胞。 

トップが貢献する`w2`細胞。 

外側の 4 つの角はさらに 4 つのセルを提供します。 

これまでのところ、次のことができます。```
2(h1 + h2) + w1 + w2 + 4
```ここで、上の長方形の幅が狭くなっている水平エッジを考えてみましょう。 幅の違い`w1 - w2`垂直の段差を作ります。 そのステップの周囲で、その上下の両方に追加のマークされたセルが必要です。`2(w1 - w2)`細胞。 

最後に、2 つの長方形の間の結合により、遷移付近の 2 つのコーナー セルが形成されます。 

すべてを組み合わせると:```
answer =
2(h1 + h2)
+ 2(w1 + w2)
+ 4
+ (w1 - w2)
+ (w1 - w2)
```これは次のように単純化されます。```
answer = 2*(h1+h2) + 2*(w1+w2) + 4 + 2*(w1-w2)
```これはまさに、受け入れられているソリューションで使用される公式です。

 ## アルゴリズムのチュートリアル

 1.読む`w1`、`h1`、`w2`、 そして`h2`。 
2. 形状の垂直辺からの寄与を数えます。```
2 * (h1 + h2)
```各側面は船の高さ全体に及びます。 
3. 水平境界からの寄与をカウントします。```
2 * (w1 + w2)
```下端には幅があります`w1`上端には幅があります`w2`。 
4. 外側の角の 4 つのセルを追加します。```
+4
```5. 作成されたステップを考慮します。`w1 > w2`。 

露出した水平方向の違いは次のような影響を及ぼします。```
2 * (w1 - w2)
```6. 結果の値を出力します。 

### なぜ効果があるのか

 マークされたすべてのセルは、船の境界の外側に 1 つだけセルが存在します。 この式では、そのような境界位置をすべてカウントします。 

高さに関係する項は、左側と右側に隣接するセルをカウントします。 幅に関係する項では、上下に隣接するセルをカウントします。 The constant`4`外側の4つの角を占めます。 上の長方形が狭くなると、追加の露出したステップが表示され、その隣接するセルが正確に寄与します。`2(w1 - w2)`さらに多くのポジション。 

マークされたセルはすべて 1 回カウントされ、必要なマークされたセルはすべてこれらの境界部分の 1 つに属します。 この形状は 2 つの整列した長方形のみで構成されているため、これらの寄与によって境界が完全に記述されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

w1 = int(input())
h1 = int(input())
w2 = int(input())
h2 = int(input())

ans = 2 * (h1 + h2)
ans += 2 * (w1 + w2)
ans += 4
ans += 2 * (w1 - w2)

print(ans)
```実装は、派生した式を直接変換したものです。 

最初の項は、2 つの垂直辺に隣接するセルをカウントします。 2 番目の項は、上部と下部の境界に隣接するセルをカウントします。 定数`4`外側の角を考慮します。 最後の項は、上の長方形が狭くなったときに現れる段差を処理します。 

すべての算術演算は Python 整数内に快適に収まります。 最大寸法であっても、答えは次のオーダーでしかありません。`10^9`。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    w1 = int(input())
    h1 = int(input())
    w2 = int(input())
    h2 = int(input())

    ans = 2 * (h1 + h2)
    ans += 2 * (w1 + w2)
    ans += 4
    ans += 2 * (w1 - w2)

    print(ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue().strip()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out
