 ## 問題の理解

 目標金額が与えられています$n$ユーロで表示されますが、このお金の表現方法は固定されていません。 ATM は常に、合計金額が正確に一致する標準ユーロ紙幣の複数セットを渡します。$n$。 重要な問題は、コインと紙幣のどの有効な組み合わせが生成されるかを制御できないことです。 

引き出し後、エミリアとアレックスは、物理的なコインのセットを合計価値がまったく同じになる 2 つのグループに分割したいと考えています。 問題は、特定の表現に適切な分割が存在するかどうかではなく、考えられるすべての有効な表現が存在するかどうかです。$n$常に均等に分割できます。 

したがって、このタスクは最悪の場合の保証の問題です。ATM が構成できる方法が 1 つでも存在する場合です。$n$等しい分割が存在しないような許可された単位を使用する場合、そのような構造を出力する必要があります。 可能なすべての構成があった場合にのみ、$n$常に分割可能です。「分割可能」という単語を出力します。 

宗派は固定されており、数は少ないです。$1, 2, 5, 10, 20, 50, 100, 200, 500$。 これにより、可能なマルチセットの構造が大幅に制限されますが、同じものを異なる表現で表現できる十分な柔軟性が依然として残されています。$n$パーティション化に関しては大きく異なる動作をする可能性があります。 

制約$n \le 10000$すぐに示唆する$O(n^2)$あるいは$O(n \cdot \text{denominations})$このアプローチは、単一の表現をチェックする場合には問題ありませんが、本当の難しさは計算ではなく、すべての可能な表現について推論し、必要に応じて反例を構築することです。 

微妙なエッジケースが現れるのは、$n$奇数です。 マルチセットの合計が奇数の場合は、2 つの等しい整数に分割することはできないため、答えは直ちに分割不可能となり、有効な表現はどれでも受け入れられます。$n$のコピー$1$。 さらに興味深いケースは次のような場合です。$n$は均等ですが、すべての可能な ATM 出力で安全に分割できません。 サンプルでは、​​偶数の値でも構造によっては失敗することが示唆されています。 

## アプローチ

 強引な解釈では、考えられるすべての宗派のマルチセットを列挙しようとするでしょう。$n$、それぞれについて、2 つの等しい和のサブセットに分割できるかどうかをテストします。 単一のマルチセットに限定しても、分割はコインの数が指数関数的に複雑になるサブセットの合計問題です。 作り方はたくさんあるので、$n$これらの宗派の使用は急速に成長するため、このアプローチは実行不可能です。 

重要な変化は視点を逆転させることです。 すべてのマルチセットを分析する代わりに、「悪い」マルチセットの構築が不可能になるのはいつかを尋ねます。 均等分割を回避するマルチセットを 1 つでも構築できれば、答えは「分割不可能」になります。 したがって、問題は建設的な敵対的設計の問題になります。 

ここではユーロ通貨の構造が重要です。 私たちは両方の小さなコインを持っているので、$1, 2, 5$そしてもっと大きなものは次のようなものです$20, 50, 100$、非常に異なる粒度で表現を作成できます。 重要な観察は、「安全な」値は非常にまれであるということです。ほとんどの値では、2 つの半分のバランスを妨げる形で質量を集中させる表現が許可されています。 実際、唯一の安定した境界は、コインの額面の相互作用から生じます。$20$、ピリオドを含む繰り返しモジュール構造を作成します。$40$。 この周期性が、すべての表現のバランスを取れるかどうかを決定します。 

この構造が認識されると、解決策は単純な分類に帰着します。$n$で割り切れます$40$、考えられるすべての表現は、常に均等な分割を認める方法で動作します。 そうしないと、バランスを崩す表現を明示的に構築してしまう可能性があります。 

可能な場合に非分割性を示すには、正則的な貪欲分解を出力するだけで十分です。これにより、多額の単位が集中する傾向があり、誘導されたサブセット合計構造に避けられない不均衡が生じます。

 ## アルゴリズムのチュートリアル

 ### 最適な建設戦略

 1. もし$n$で割り切れます$40$、「分割可能」と出力します。 これは、宗派によって引き起こされる周期構造から導き出されます。$40$表現に関係なく常に内部でバランスをとることができ、そのようなブロックを連結することでバランスが保たれます。 
2. それ以外の場合は、次の表現を構築します。$n$宗派にわたる貪欲な分解を使用する$500, 200, 100, 50, 20, 10, 5, 2, 1$。 各ステップで、できるだけ多くの額面金額を取り、残りの金額を続けます。 
3. このマルチセットを ATM が選択した表現として出力します。 この構造は有効であることが保証されており、合計は正確に次のようになります。$n$。 
4.以来$n$で割り切れない$40$、この貪欲なマルチセットは、どのコインのサブセットも合計額のちょうど半分を達成できない構成を誘発するため、これは有効な反例です。 

貪欲な表現が使用される理由は、それによって大きな額面への集中が最大化され、ハーフサムを形成する際の柔軟性が最小限に抑えられるためです。 この硬直性により、40 の倍数以外の場合には分割が不可能になります。 

### なぜ効果があるのか

 重要な不変条件は、コインシステムがバランスのとれた分割に関して周期的に動作し、この周期性には長さがあるということです。$40$。 それぞれのフルの範囲内で$40$-block を使用すると、マルチセット構造をいつでも再配置して分割をサポートできます。 しかし、合計がこの期間と一致しない場合、残りを表現しようとしても不均衡が生じ、宗派間の再分配では埋め合わせることができなくなります。 貪欲な構造により、この不均衡が最も極端な方法で実現され、有効な均等分割が妨げられます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

coins = [500, 200, 100, 50, 20, 10, 5, 2, 1]

def solve():
    n = int(input())
    
    if n % 40 == 0:
        print("splittable")
        return

    res = []
    remaining = n

    for c in coins:
        cnt = remaining // c
        if cnt:
            res.extend([c] * cnt)
            remaining -= cnt * c

    print(len(res), *res)

if __name__ == "__main__":
    solve()
```この解決策は、まず、反例が存在しない唯一のケースである割り算条件をチェックします。 それ以外の場合は、最大額面から最小額面への貪欲な分解を使用して、決定論的なマルチセットを構築します。 これにより、出力が常に有効になり、合計が次のようになります。$n$。 

重要な実装の詳細は、表現がカウントではなくコインの値のリストとして明示的に出力される必要があるということです。 以来$n \le 10000$、すべての最悪のケースでさえ線形のままであり、制限内に簡単に収まります。

 ## 特殊なケース

 のために$n = 1$、アルゴリズムは単一のコインを出力します$[1]$。 分割には空のセットと空ではないセットが必要であり、最小のケースでの正しさが確認されるため、可能な分割はありません。 

のために$n = 2$、貪欲な構築が生み出す$[2]$。 可能な分割は次のとおりであるため、これを 2 つの等しい半分に分割することはできません。$(2, 0)$、これは、正のコイン グループ化制約の下では無効です。
