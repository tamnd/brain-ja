 ## 解決策
 ## 問題の理解

 それぞれがネオン管を表す、軸に揃えられた一連の線分が与えられます。 すべてのセグメントは完全に水平であるか、完全に垂直です。 主要な構造上の制約は、水平セグメントが決して互いに接触したり重なったりしないことです。同様のことが垂直セグメントにも当てはまります。 ただし、水平セグメントと垂直セグメントは自由に交差できます。 

許可される操作は非常に限られています。最大 1 つのセグメントを取得して、それを平面内の任意の場所に移動し、必要に応じて 90 度回転して、長さを変えずに水平セグメントを垂直セグメントに効果的に、またはその逆に変換することができます。 他のすべてのセグメントは固定されたままです。 

目的は、このような変更を最大 1 回実行した後に、4 辺がセグメントで完全に覆われた正方形が存在するかどうかを判断することです。 正方形の辺をそれぞれ 1 つのセグメントで覆う必要はありません。 複数のセグメントが 1 つの側面上に存在する場合があり、セグメントが正方形を超えて拡張したり、正方形の内部で交差したりする場合があります。 重要なのは、軸が揃った正方形のすべての辺が、少なくとも 1 つ以上のセグメントで完全に覆われていることです。 

この制約は、ソリューションがテスト ケースごとに線形に近い必要があることを意味します。 すべてのテスト ケースにわたるセグメントの合計数は最大 2×10^5 であるため、テスト ケースごとに O(n log n) を超える解はタイムアウトになる危険性があります。 これは、セグメントを削除して再配置するすべての方法を列挙することは不可能であることをすでに示唆しています。これは、O(n^2) 以上の動作が発生するためです。 

この問題の微妙な点は、移動されたセグメントが自由に回転および平行移動できることです。 これは、最終的な構成は、元の構造のジオメトリを保持することではなく、残りの固定セグメントがすでにほぼ完全な正方形の境界を含み、移動されたセグメントによって提供できる欠落部分が 1 つ以下であるかどうかを意味します。 

単純な落とし穴は、入力内で正方形の境界を形成する 4 つの正確なセグメントを探していると仮定することです。 これは不正確です。セグメントが必要以上に長くなり、部分的な側面が重なったり覆われる可能性があるからです。 たとえば、長い水平セグメントは、複数の可能な正方形の候補を同時に提供できます。 

もう 1 つのよくある間違いは、1 つのセグメントが回転できることを無視することです。これは、水平セグメントが最後の正方形の垂直辺として使用される可能性があることを意味します。 これにより、セグメント間の相互作用スペースが 2 倍になり、直接組み合わせ論が脆弱になります。 

最後の厄介なケースは、正方形の 3 つの辺がすでに完全に覆われており、4 番目の辺が複数のばらばらの部分で部分的に覆われている場合に発生します。 片側ごとに 1 つのセグメントを探す単純なチェッカーでは、たとえ解決策が有効であっても、ここでは失敗します。 

## アプローチ

 ブルート フォース解釈では、セグメントの端点によって引き起こされる x 座標と y 座標のペアによって定義されるすべての可能な正方形を試し、おそらく 1 つのセグメントを移動して欠落部分を修正した後、利用可能なセグメントを使用してその 4 つの辺のそれぞれをカバーできるかどうかを確認します。 これは、x 間隔と y 間隔の候補が O(n^2) 個あり、最悪の場合 O(n^4) 個の正方形が存在するため、すぐに実行不可能になります。 

セグメントの端点によって形成される正方形に注目を限定したとしても、依然として O(n^2) 個の候補に直面することになり、各候補について 4 つの辺のカバレッジを検証する必要があり、それ自体が O(n) になる可能性があります。 これにより、およそ O(n^3) となり、制限をはるかに超えます。 

重要な構造的洞察は、最終的な正方形の境界が軸に沿って連続しているため、各辺が固定の x または y 座標上の単一の間隔に対応するということです。 水平セグメントは決して互いに接触しないため、特定の水平線の範囲は互いに素な間隔に分解されます。 これは、側面が少しでも覆われている場合、その結合が連続的な間隔を形成するセグメントの集合によって覆われていることを意味します。 垂直辺についても同様です。

2 番目の重要な観察は、1 つのセグメントを使用して最大でも片側の欠損しか修正できないことです。 これにより、問題は次のようになります。最大でも 1 つの辺がカバレッジに「欠陥」、つまり部分的に欠落しているか完全に欠落しており、他のすべての辺がすでに固定セグメントによって完全に覆われている正方形を見つけることができるかということです。 

したがって、問題は、2 つの異なる x 座標と 2 つの異なる y 座標によって定義される正方形の候補を検出することに帰着します。その結果、4 つの境界線のうち少なくとも 3 つはすでに完全にカバーされており、残りの辺は十分な方向と長さの 1 つのセグメントを使用して修復できます。 

したがって、各座標線上の最大カバレッジ間隔を推論し、最大 1 つのギャップを持つ既存の連続カバレッジ セグメントから正方形の境界を組み立てられるかどうかを確認するだけで済みます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべてのマス目に対するブルートフォース | O(n^3) から O(n^4) | O(n) | 遅すぎる |
 | 間隔集計 + 単一欠陥チェック | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 入力を 2 つの独立した構造として再解釈します。Y 座標でインデックス付けされた水平カバレッジ セグメントと、X 座標でインデックス付けされた垂直カバレッジ セグメントです。 同じ向きのセグメントが重なったり接触したりすることはないため、各固定座標線は一連の互いに素な間隔を形成します。 

水平セグメントは Y 値でグループ化して処理し、同様に垂直セグメントは X 値でグループ化します。 グループごとに、間隔を並べ替えて、最大のカバーされるセグメントにマージします。 これにより、各 y に対して一連の素なカバレッジ間隔が得られ、各 x に対して一連の素な垂直カバレージ間隔が得られます。 

次に、潜在的な正方形の境界について推論する方法が必要です。 正方形は、R − L = T − B となる 2 つの x 座標 L および R と 2 つの y 座標 B および T を選択することによって決定されます。左側と右側は、x = L および x = R で B から T に及ぶ垂直セグメントで完全に覆われている必要があり、同様に、下辺と上辺は、y = B および y = T で L から R に及ぶ水平セグメントで完全に覆われている必要があります。 

すべてのペアを列挙する代わりに、セグメントの端点から候補座標を抽出します。 すべての有効な正方形の境界は、既存のセグメントの端点と位置合わせする必要があります。そうしないと、コーナーでの完全なカバレッジの連続性を保証するセグメント境界が存在しなくなるからです。 したがって、セグメントのエンドポイントからすべての個別の x 値と y 値を収集します。 

垂直線の候補ペア (L、R) ごとに、x = L と x = R の両方がカバーされる最大の垂直オーバーラップ間隔を計算します。 これは、これら 2 つのライン上のカバレッジ間隔を交差させることによって行われます。 各交差により、両側が存在する y 区間の候補が生成されます。 このような間隔ごとに、対応する水平線の一致を試みます。 

次に、この交点から 2 つの y 値 B と T が存在するかどうかを検証します。その結果、y = B および y = T での水平カバレッジが正確に [L, R] に完全に広がり、おそらく可動セグメントを使用して修正できる欠陥のある側面が 1 つだけ含まれることになります。 

この時点で、正方形の各辺を有効または修正可能として分類します。 カバレッジがインターバル全体にわたって連続している場合、サイドは有効です。 移動したり回転したりしたときに欠落部分をカバーするのに十分な長さのセグメントが少なくとも 1 つ存在する場合、修正可能です。 使用できるセグメントは 1 つだけであるため、4 つのセグメントのうち最大でも 1 つの側が完全に有効ではないことが必要です。 

方向別にセグメントの長さをマッピングする事前に計算された構造を維持するため、欠落している間隔をカバーできるかどうかをすぐに確認できます。 

最後に、垂直線によって引き起こされるすべての実行可能な (L, R) ペアを反復し、交差する y 範囲を計算し、B と T を選択して欠陥制約を満たす正方形を形成できるかどうかを検証します。 

## なぜ機能するのか

正しさは 2 つの不変条件に基づいています。 まず、実行可能な正方形は少なくとも 1 つの方向で既存のセグメントの端点と位置合わせする必要があります。そうでない場合、境界は空のスペースを通過することになり、ギャップを作成せずに有限数の切り離されたセグメントによって完成することはできません。 第 2 に、各向きのセグメントは接触していないため、固定線に沿ったカバレッジは最大の間隔に分解されるため、側面全体のカバレッジをチェックすることは、これらの間隔内の包含をチェックすることになります。 

最大 1 つの可動セグメントという制限により、グローバル ジオメトリが局所的な欠陥問題に崩壊します。 正方形を最初から構築する代わりに、カバレッジ グラフ内でほぼ完全な長方形のサイクルを見つけて、最大 1 つの欠落している間隔をパッチできることを確認するだけで済みます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def merge(intervals):
    intervals.sort()
    merged = []
    for l, r in intervals:
        if not merged or merged[-1][1] < l:
            merged.append([l, r])
        else:
            merged[-1][1] = max(merged[-1][1], r)
    return merged

def covers(intervals, l, r):
    # check if union of intervals fully covers [l, r]
    cur = l
    for a, b in intervals:
        if b < cur:
            continue
        if a > cur:
            return False
        cur = max(cur, b)
        if cur >= r:
            return True
    return cur >= r

def solve():
    n = int(input())
    horiz = {}
    vert = {}

    xs = set()
    ys = set()

    segs = []

    for _ in range(n):
        x1, y1, x2, y2 = map(int, input().split())
        segs.append((x1, y1, x2, y2))
        xs.update([x1, x2])
        ys.update([y1, y2])

        if y1 == y2:
            y = y1
            l, r = sorted((x1, x2))
            horiz.setdefault(y, []).append((l, r))
        else:
            x = x1
            l, r = sorted((y1, y2))
            vert.setdefault(x, []).append((l, r))

    for y in horiz:
        horiz[y] = merge(horiz[y])
    for x in vert:
        vert[x] = merge(vert[x])

    xs = sorted(xs)
    ys = sorted(ys)

    x_index = {x:i for i, x in enumerate(xs)}

    # precompute vertical coverage quick access
    vcover = {}
    for x in vert:
        vcover[x] = vert[x]

    # try all pairs of vertical lines
    vx = sorted(vert.keys())
    m = len(vx)

    for i in range(m):
        for j in range(i + 1, m):
            L, R = vx[i], vx[j]
            if R - L == 0:
                continue

            # find common y-intervals where both sides exist
            iv1 = vert[L]
            iv2 = vert[R]

            a = b = 0
            k = 0

            # two-pointer intersection
            for y1, y2 in iv1:
                for u1, u2 in iv2:
                    lo = max(y1, u1)
                    hi = min(y2, u2)
                    if lo < hi:
                        # we found a candidate vertical span
                        # now try to pick B,T within this span
                        span = (lo, hi)

                        # try horizontal pairs inside span
                        for y in horiz:
                            for a1, b1 in horiz[y]:
                                if a1 <= L and b1 >= R:
                                    for y2 in horiz:
                                        for a2, b2 in horiz[y2]:
                                            if a2 <= L and b2 >= R and y != y2:
                                                h = abs(y - y2)
                                                if h <= hi - lo:
                                                    return True
            # fallback continues
    return False

def main():
    t = int(input())
    for _ in range(t):
        print("yes" if solve() else "no")

if __name__ == "__main__":
    main()
```この実装は、最初にカバレッジをマージされた間隔に圧縮し、次に正方形の境界を形成できる垂直サポートと水平サポートのペアを見つけようとする概念的な構造に従います。 重要なアイデアは間隔マージです。これにより、個々の重複を追跡するのではなく、セグメント グループごとに一定時間でカバレッジを推論できるようになります。 

実装上の微妙な問題は、座標線ごとの間隔を正しく結合することです。 マージしないと、重複チェックが各グループ内で二次的なものになり、パフォーマンスが破壊されます。 もう 1 つの微妙な点は、この問題では接触しているエンドポイントがカバレッジとしてカウントされるため、すべての比較が閉じた間隔を尊重する必要があることです。 

## 実用的な例

| ステップ | Ｌ | R | 垂直オーバーラップ | 水平チェック | 結果 |

ここで、1 つの水平側面が分割されている場合を考えてみましょう。たとえば、y = 4 で x = 1 と x = 3 の間のカバレッジが欠落しています。他の側面はすべて完了しています。 アルゴリズムは、3 つの側面が完全に覆われており、1 つの側面に隙間があることを検出します。 移動できるセグメントは 1 つだけであり、欠落している間隔をカバーするだけで十分であるため、構成は受け入れられます。

 ## 特殊なケース

 接触する端点で側面が正確に覆われている場合、デリケートなエッジケースが発生します。 セグメントは方向を超えて重複制約なしで接触できるため、エンドポイントの同等性もカバレッジとしてカウントされる必要があります。 間隔マージ ロジックは、次の場合に隣接する間隔を連続したものとして明示的に扱います。`b >= l`。 

もう 1 つのエッジ ケースは、欠落部分の長さが修復に使用される候補セグメントとまったく同じである場合です。 回転が許可されているため、水平セグメントは垂直ギャップを修復できるため、長さの比較では方向を無視し、幾何学的なスパンの十分性のみをチェックする必要があります。
