 ## 解決策
 ## 問題の理解

 長さの文字列が与えられます$n$, ここで、各位置は赤、緑、または青の色の電球を表します。 利用可能な唯一の操作は、電球を選択して「タッチ」することです。これにより、電球の色が、以前の状態とは無関係に、ランダムに 3 つの色のいずれかに即座にリセットされます。 

目標は、すべての電球が同じ色を共有する状態に達することです。 各ステップでどの電球にタッチするかを選択できますが、最適な戦略の下で必要となる予想されるタッチ数を最小限に抑えたいと考えています。 

重要な問題は、すべてのタッチは確率的であり、改善が保証されないことです。 私たちは本質的に、グローバルな停止条件、つまりすべてのコンポーネントが一致する必要があるという条件を使用して、独立したマルコフ プロセスのシステムを制御しています。 

制約$n \le 100$構成は、位置ではなく各色の電球の数によって定義される同値クラスに自然に崩壊するため、状態空間動的プログラミングまたは期待 DP カウントがもっともらしいことを示唆しています。 

素朴な解釈では、各電球を独立して扱うことになりますが、結合はすべての電球が一致した場合にのみ停止するという事実から来ているため、プロセスは本質的にグローバルです。 

いくつかのエッジケースではトラップが露呈します。 

いつ$n = 1$の場合、単一の電球がすでに条件を満たしているため、答えは常にゼロになります。 

すでにすべての電球が同じ色になっている場合:`ggg`、すでに末期状態にあるため、答えは再びゼロになります。 

誤解を招くケースは次のようなものです`rgb`。 それぞれの電球が異なるとしても、最適な戦略は色を恣意的に循環させないことです。 代わりに、システムを支配的な色のクラスに削減する方法を考慮する必要があります。 

中心的な課題は、ローカルな決定 (どの電球に触れるか) がグローバルなコンバージェンス時間に非線形的に影響を与えることです。 

## アプローチ

 ブルートフォースアプローチでは、マルコフ連鎖全体を明示的にモデル化します。$3^n$構成。 それぞれの状態から、考えられる電球のすべての選択と、再着色で考えられるすべてのランダムな結果を考慮します。 すべてのバルブが等しい場合の吸収状態までの予想打撃時間を計算します。 

これは正しいですが、すぐには実行不可能です。$n = 20$、状態空間は天文学的に大きくなり、状態ごとの遷移はさらに倍増します。$n$。 状態の総数は指数関数的に増加するため、構成に対する直接的な動的プログラミングは不可能になります。 

重要な観察は対称性です。 電球の識別は重要ではなく、各色の電球が何個存在するかだけが重要です。 あらゆる構成はトリプルによって完全に記述されます$(r, g, b)$と$r+g+b=n$。 これにより、状態空間が指数関数から$O(n^2)$。 

州から$(r, g, b)$、何らかの色の電球を選択し、均一に再着色します。 これにより、これらのカウント状態間の遷移が引き起こされます。 このプロセスは、有限格子上の古典的な予想打撃時間 DP になります。 

最適な戦略は、常にこの圧縮された状態空間内で動作し、カウントの 1 つが以下に等しい吸収状態に到達するための予想ステップを計算することです。$n$。 

これにより、問題は全体的に連立一次方程式を解くことに帰着します。$(r,g,b)$、ただし、遷移は隣接するカウント構成間でのみ移動するという事実を利用して、終端状態からの距離が増加するにつれてそれを DP として構造化できます。

 ## アルゴリズムのチュートリアル

 状態をトリプルで表します$(r, g, b)$。 させて$E[r][g][b]$は、その構成から開始して単色状態に到達するために必要な予想されるタッチ数を示します。 

1. 最終状態を特定します。 いずれかの場合$r=n$、$g=n$、 または$b=n$の場合、期待値はゼロになります。 これ以上のアクションは必要ないため、これらは吸収状態です。 
2. 非終了状態の場合$(r,g,b)$では、タッチする電球を選択してトランジションを定義します。 最適な選択は期待どおりに対称であるため、各カラー クラスを比例的に選択して平均することを分析するだけで十分です。 
3. 赤い電球を選んだとします。 確率で$1/3$、確率的に赤のままです$1/3$緑になり、確率で$1/3$青くなります。 これにより、状態は次のように変化します。 

赤の数が 1 つ減り、結果に応じて 3 つの色のいずれかが増加します。 

これにより、次のような遷移が得られます。 

から$(r,g,b)$：

に$(r, g, b)$確率的に$r/n \cdot 1/3$、

に$(r-1, g+1, b)$確率的に$r/n \cdot 1/3$、

に$(r-1, g, b+1)$確率的に$r/n \cdot 1/3$、

 緑または青を選択する場合も同様です。 
4. 完全なアクションの選択を明示的にエンコードする代わりに、期待の線形性を使用します。 各ステップにより、予想されるシステムが隣接する状態の組み合わせに縮小されます。$(r,g,b)$格子。 
5. 繰り返しを書きます。$$E[r][g][b] = 1 + \sum_{(r',g',b')} P((r,g,b)\to(r',g',b')) \cdot E[r'][g'][b']$$ここで、確率は電球を均一に選択し、それを均一に再着色することから得られます。 
6. このシステムを、終端状態からの距離の増加順にすべての状態を反復することによって解決します。これは、移動の変更は最大でも 1 つずつカウントされるため、最初にエントロピー構成を減少させることに効果的に対応します。 
7. すべての終端状態をゼロに初期化し、収束するまで遷移を緩和します。システムは吸収までの距離によって引き起こされる期待順序付けが非周期的であるため、収束が保証されます。 

### なぜ効果があるのか

 このプロセスは、吸収状態が単色配置である有限マルコフ連鎖を形成します。 非終端状態から終端状態に近づく正の確率が常に存在するため、すべての状態には明確に定義された予想到達時間があります。 DP オーバーカウント状態は、すべての対称性と同等の構成を正確に捕捉し、再帰化により、シングル タッチのすべての可能な結果に対する完全な期待の法則が適用されます。 期待値は線形であるため、集約された状態でシステムを解くと、元の確率過程の正確な期待値が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    n = len(s)

    r = s.count('r')
    g = s.count('g')
    b = s.count('b')

    # dp[r][g][b]
    dp = [[[0.0] * (n + 1) for _ in range(n + 1)] for __ in range(n + 1)]

    # iterate by decreasing total non-terminal complexity
    for total in range(n, -1, -1):
        for r0 in range(n + 1):
            for g0 in range(n + 1):
                b0 = n - r0 - g0
                if b0 < 0:
                    continue
                if r0 + g0 + b0 != n:
                    continue

                if r0 == n or g0 == n or b0 == n:
                    dp[r0][g0][b0] = 0.0
                    continue

                denom = n
                val = 1.0

                # pick red bulb
                if r0 > 0:
                    p = r0 / n
                    val += p * (
                        (1/3) * dp[r0][g0][b0] +
                        (1/3) * dp[r0 - 1][g0 + 1][b0] +
                        (1/3) * dp[r0 - 1][g0][b0 + 1]
                    )

                # pick green bulb
                if g0 > 0:
                    p = g0 / n
                    val += p * (
                        (1/3) * dp[r0 + 1][g0 - 1][b0] +
                        (1/3) * dp[r0][g0][b0] +
                        (1/3) * dp[r0][g0 - 1][b0 + 1]
                    )

                # pick blue bulb
                if b0 > 0:
                    p = b0 / n
                    val += p * (
                        (1/3) * dp[r0 + 1][g0][b0 - 1] +
                        (1/3) * dp[r0][g0 + 1][b0 - 1] +
                        (1/3) * dp[r0][g0][b0]
                    )

                dp[r0][g0][b0] = val

    print(dp[r][g][b])

if __name__ == "__main__":
    solve()
```この実装では、状態空間が各色のカウントに圧縮されます。これが問題を解決可能にする重要な削減です。 トリプルループは有効なものをすべて列挙します。$(r,g,b)$州。 境界処理は、ある色を減分し、別の色を増分するときに重要です。境界処理を行わないと、インデックスが注意深くチェックされていないと無効な状態が表示されるためです。 

漸化式は期待方程式を直接エンコードします。 「+1」はワンタッチのコストに相当します。 各遷移は、その色の電球を選択し、それを可能なそれぞれの結果に再着色する確率に応じて寄与します。

 遷移が評価される前に終了条件がトリガーされるため、DP はすぐに 0 を返します。 

これにより、すでに安定した設定が不必要な遷移なしで正しく吸収されていることを確認できます。 

### 例 2:`rgb`初期状態は$(1,1,1)$。 

再発の 1 回の反復を考えます。 

| ステップ | r | g | b | コメント |
 | --- | --- | --- | --- | --- |
 | 開始 | 1 | 1 | 1 | 対称状態 |
 | トランジション | さまざまです | さまざまです | さまざまです | タッチするたびに色が再分配される |
 | 結果 | - | - | - | 吸収されるまで期待が溜まる |

 対称性から、すべてのアクションは期待のバランスを維持しますが、支配的な色の状態に向かって確率量を徐々に増加させます。 DP は、そのような対称的な遷移がすべて考慮されていることを保証します。 

この例では、完全に混合された状態であっても、カウントベースの遷移にきれいに還元されることが強調されています。

 ## 特殊なケース

 重要なエッジケースは、すべての電球がすでに同一である場合です。 入力用`rrrr`、状態は$(4,0,0)$。 このアルゴリズムは端末構成を即座に検出し、繰り返しを入力せずにゼロを割り当てます。 これにより、DP での偶発的な自己遷移が回避されます。 

もう 1 つの微妙なケースは、次のような 2 色システムです。`rrgg`。 から始まる$(2,2,0)$、トランジションには赤と緑のカウントのみが含まれます。 DP には依然として暗黙的に青色の州が含まれていますが、それらに到達することはありません。 漸化式は自然に縮小部分空間に崩壊し、到達不可能な状態は有効な遷移からの確率質量に寄与しないため、期待値は一貫したままになります。 

最後のエッジケースは単一の電球のシナリオです`r`。 DPマーク$(1,0,0)$ターミナルとして使用されるため、遷移は評価されず、結果は正確にゼロとなり、タッチが必要ないという定義と一致します。
