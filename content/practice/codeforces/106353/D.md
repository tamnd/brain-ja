 ## 問題の理解

 私たちには循環構造が与えられています。$n$1 から 1 までのラベルが付けられた等間隔の点$n$。 点 1 から始めて、各点を繰り返し点に接続します。$k$ステップ前進、モジュロをラップアラウンド$n$、原点に戻るまで。 これにより、すべてのポイントまたはサブセットのみを訪問するサイクルが生成されます。$k$。 

各接続は円の弦であり、弦の長さはその端点間の角距離のみに依存します。 すべての点が等間隔に配置されているため、ステップバイ$k$αは固定角度に対応し、糸の全長はサイクル内の弦の数と弦の長さを乗算したものに比例します。 

サイクル内のコードの数は常に一定であるとは限りません。$n$。 飛び越え続けたら$k$、正確に終わったら出発点に戻ります$\frac{n}{\gcd(n,k)}$ステップ、つまりサイクルの長さは$n / \gcd(n,k)$。 各ステップはコードのスパンに対応します。$k$したがって、糸の総量を最大化することは、以下を最大化することと同じです。$$\frac{n}{\gcd(n,k)} \cdot \sin\left(\frac{\pi k}{n}\right)$$一定係数まで。 

タスクは整数を選択することです$k$、$1 \le k < n$、この式を最大化します。 

制約により許可されるのは、$n$まで$10^9$、可能なすべてを反復するアプローチは即座に除外されます。$k$値と計算$\gcd$それぞれに。 ナイーブ$O(n)$スキャンには最大 10 億回の評価が必要になるため、実行できません。 

重要な構造特性は、両方とも$\gcd(n,k)$そして、正弦項は、任意の動作ではなく、約数と対称性に依存します。 これは、ソリューションが全体的に強引な最適化ではなく、数理論的な構造によって駆動されていることを示唆しています。$k$。 

微妙なエッジケースが現れるのは、$n$プライムです。 それから$\gcd(n,k)=1$みんなのために$k$したがって、サイクルの長さは常に次のようになります。$n$そして問題は純粋に最大化に帰着します$\sin(\pi k/n)$でピークに達します$k \approx n/2$。 中間点付近で 1 つずれた選択が重要になります。 

偶数の場合には別の特殊なケースが発生します$n$、 どこ$k = n/2$直径の弦を生成します。 これは正弦を局所的に最大化しますが、代替手段がないことを保証する必要があります$k$gcd が小さいほど、合計サイクルの寄与が長くなります。 

## アプローチ

 直接的なアプローチでは、次のすべての値を試します。$k$1から$n-1$、次を使用してサイクル長を計算します。$\gcd(n,k)$を計算し、全長の式を計算します。 これは構造を直接反映しているため正しいですが、コンピューティングが必要です。$O(n)$それぞれの候補には gcd と正弦の評価が含まれます。 浮動小数点コストを無視しても、これは遅すぎます。$n$まで$10^9$数十億回の反復が必要になるためです。 

重要な洞察は、式が 2 つの競合する効果に分割されるということです。正弦項は正規化された分数にのみ依存します。$k/n$、一方、サイクル多重度は のみに依存します。$\gcd(n,k)$。 正弦関数は付近で最大化されます。$k = n/2$一方、gcd 項は次の場合に最大化されます。$k$大きな約数を共有する$n$。 これら 2 つの目的は矛盾しており、最適化は恣意的ではなく、高度に構造化された点で行われます。$k$。 

書き換え$k = d \cdot x$そして$n = d \cdot m$、私たちは得ます$\gcd(n,k)=d$, したがって、サイクルの長さは次のようになります。$m$、独立して$x$。 合計の目標は次のようになります。$$\frac{n}{d} \cdot \sin\left(\frac{\pi x}{m}\right)$$固定用$m$、正弦項は次の場合に最大化されます。$x$に最も近い$m/2$に対応します。$k$に最も近い$n/2$の倍数の間で$d$。 

これにより、問題はフォームの候補のみを試行することになります。$k \approx n/2$、ただし、の約数によって制約されます$n$。 最適な解決策は、この中間点構造の周囲の約数をチェックすることから得られる必要があります。これはテストに帰着できます。$k = \lfloor n/2 \rfloor$および除数構造によって引き起こされる近くの値。 実際、最適値は常にどちらかで発生します。$k = \lfloor n/2 \rfloor$または$k = \lceil n/2 \rceil$なぜなら、中点から離れたところで gcd が改善されると、多重度が向上するというよりも正弦項が減少するからです。 

したがって、解決策は周囲の一定数の候補のみを評価することになります。$n/2$、効率的になります。

 ## アルゴリズムのチュートリアル

 次に、その洞察を具体的な手順に変換します。 

1. 2 つの中心候補を計算します$k_1 = \lfloor n/2 \rfloor$そして$k_2 = \lceil n/2 \rceil$。 これらは、離散円上で正弦項が最大化される点を表します。 
2. 各候補者について$k$、計算する$g = \gcd(n, k)$。 これにより、トラバースが何つの素のサイクルに分割されるかが決まり、これによって合計コード数が直接スケールされます。 
3. 浮動小数点の不安定性を避けるために、対数形式を使用して目標値を評価します。$$\text{score}(k) = \frac{n}{g} \cdot \sin\left(\frac{\pi k}{n}\right)$$4. 候補者のスコアを比較し、$k$より大きな値が得られます。 それらが等しい場合は、どちらでも有効です。 
5. 選択した内容を出力します$k$。 

これらの候補のみに限定する理由は、中間点から離れると、増加によるゲインよりも早く正弦項が減少するためです。$\gcd(n,k)$。 以来$\sin(x)$最大値付近では厳密に凹面になっています。$\pi/2$、からの逸脱$n/2$目標を達成するには常にコストがかかります。 

### なぜ効果があるのか

 目的は、次のように決定される離散周期関数の積です。$\gcd(n,k)$単峰性の凹関数は次のように決定されます。$\sin(\pi k/n)$。 gcd 項は、次の約数の境界でのみ変化します。$n$、の全範囲に比べてまばらです。$k$一方、正弦項は滑らかに変化し、中間点で最大になります。 移動して gcd を改善しようとする試み$k$から離れて$n/2$サイクル分割によるゲインを支配する正弦波の比例損失を強制します。 これにより、最適値が中央領域に固定され、その領域内では最も近い 2 つの整数のみが重要になります。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

n = int(input())

def score(k):
    g = math.gcd(n, k)
    return (n // g) * math.sin(math.pi * k / n)

k1 = n // 2
k2 = n - k1

best_k = k1
best_val = score(k1)

val2 = score(k2)
if val2 > best_val:
    best_val = val2
    best_k = k2

print(best_k)
```実装は、削減された候補セットから直接続きます。 次の 2 つの値のみを計算します。$k$、両方とも中心にあります$n/2$、定義どおりに目標を正確に評価します。 

gcd の計算は平均して一定時間であり、sine の評価も一定です。 唯一の微妙な点は、計算時に整数が正しく処理されるようにすることです。$n - k_1$、これは天井に相当する部分を生成します。$n/2$。

def solve(inp: str) -> str:

 ## 特殊なケース

 のために$n = 3$、唯一有効な$k$値は 1 と 2 です。どちらも対称性まで同一のサイクル構造を生成し、アルゴリズムは正しく選択します。$k = 1$または$k = 2$中間点の丸めの実装に応じて異なります。 

偶数の場合$n$、 のような$n = 10$、中間点$k = 5$最大弦長 (直径弦) が生成されます。 アルゴリズムはこの候補を明示的に構築し、それがチェックされることを保証するため、他の除数に起因する問題は発生しません。$k$それを上回ることができます。 

奇数の場合$n$、 のような$n = 9$、2 つの中心値$4$そして$5$テストされています。 どちらも正弦最大値に最も近く、gcd は中点から離れることを補償するほど変化しないため、正しい選択は常にこのペア内にあります。
