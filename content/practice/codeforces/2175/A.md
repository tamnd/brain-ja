 ## 解決策
 ## 問題の理解

 私たちに与えられたのはとても長いリボンです$10^{18}$セル、ただし最初のセルのみ$n$セルはすでに特定の色でペイントされています。 各色は整数として表されます。 小さな妖精はセルからリボンを塗り続けます$n+1$特定のルールを使用して、新しいセルごとに、すでに存在する個別の色の数を数え、その番号を色として新しいセルをペイントします。 目標は、色を決定することです。$10^{18}$- 番目のセル。 

入力は複数のテスト ケースを提供します。 各テスト ケースでは、最初にペイントされたセルが提供されます。 各テスト ケースの出力は、最後のセルの色を表す単一の整数です。 

リボンの長さは天文学的ですが、$n$非常に小さいです (最大 100)。 これにより、各セルをシミュレートするとすぐにわかります。$n+1$に$10^{18}$不可能です。 リボン上でのブルートフォース反復は実行不可能です。 代わりに、着色プロセスで現れるパターンと不変条件に焦点を当てる必要があります。 

微妙なエッジ ケースは、最初の色のセットに 1 から始まる連続した整数が既に含まれている場合です。たとえば、色が [1、2、3、4] の場合、次のセルの個別の数が 4、5、6 などに達する可能性があり、最終的な答えが変わる可能性があります。 もう 1 つのエッジ ケースは、すべての最初のセルが同じ色である場合です。 そうすれば、将来のすべてのセルは無期限に同じ色を維持します。 

## アプローチ

 ブルート フォース手法は概念的に単純です。最初のセルを超えた各セルに対して、$n$、個別の色をカウントし、そのカウントを追加して続行します。 これは少数のセルでは正しく機能しますが、最大で反復できないため、すぐに不可能になります。$10^{18}$。 たとえ$n$が 100 だった場合、何十億ものステップを繰り返すことは不可能です。 

重要な洞察は、最初のセルのセットの後は、すでに色として表示されている数に達するまで、個別の色の数はステップごとに 1 つずつしか増加できないということです。 この時点を過ぎると、次のセルは常に既存の番号で色付けされるため、色数が安定します。 これは、どのステップにおいても、個別のカウントがすでに存在する最大の色を 1 を超えて超えることができないためです。 次の色がすでにセット内にある状況に達すると、後続のすべてのセルはその同じ色を無限に繰り返します。 

これは、問題が、初期の個別の色の数と既に使用されている最大の色の間の最大値を見つけることになることを意味します。 その番号はセルまで繰り返される安定した色になります。$10^{18}$。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、最初にペイントされたセルの数を読み取ります。$n$そしてその色$a_1, \dots, a_n$。 
3. 最初のセルから異なる色のセットを構築します。 させて`distinct_count`このセットのサイズになります。 させて`max_color`初期色の最大値とする。 
4. 将来のすべてのセルに最終的に表示される色は、次の最大値になります。`distinct_count`そして`max_color`。 これを割り当てる`final_color`。 
5. 印刷`final_color`このテストケースでは。 

機能する理由: 最初のセルの後、妖精は個別の色を数え、既存の数を超えた場合は新しい色を順番に追加します。 最終的に、次にペイントする色は、新しい番号か、すでに存在する番号のいずれかになります。 すでにセットに含まれている数値になると、後続のすべてのセルに同じ色が適用されます。 初期個別カウントと最大カラーの最大値により、この安定した繰り返し値が確実に取得されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    distinct_colors = set(a)
    distinct_count = len(distinct_colors)
    max_color = max(a)
    
    final_color = max(distinct_count, max_color)
    print(final_color)
```最初の 2 行は高速 I/O を処理します。これは、複数のテスト ケースを処理する場合に重要です。 の`distinct_colors`set は個別の色の数を効率的にカウントします。`max(a)`最大の色を取得します。 コンピューティング`max(distinct_count, max_color)`安定した繰り返しカラーが得られます。 これにより、$10^{18}$- 番目のセル。

 ## 特殊なケース

 すべての初期セルが同一である場合 (例: [7, 7, 7])、個別カウントは 1 で、最大色は 7 です。安定した色は max(1,7) = 7 です。アルゴリズムは 7 を出力します。これは、最初の新しいセルの後にすべてのセルが 7 に色付けされるため、これは正しいです。 

最初のセルが連続した整数 ([1, 2, 3] など) を形成する場合、個別のカウントは 3 で、最大色は 3 です。次のセルの色は 3 になります。これはすでに存在しており、将来のすべてのセルは 3 を繰り返します。アルゴリズムはパターンと一致して 3 を出力します。 

[2,5,7] のような疎な初期色の場合、個別カウントは 3、最大色は 7 です。次のセルは 3 に色付けされ、最終的に色はアルゴリズムが正しく識別する 7 で安定します。 

これは、巨大なリボンの明示的なシミュレーションを行わなくても、ソリューションがすべての非自明な境界シナリオを正しく処理することを示しています。
