 ## 解決策
 ## 問題の理解

 長さのある 1 次元モザイクの期待される美しさを計算するように求められます。$n$、各位置は次のいずれかを使用して個別に色付けされます。$m$色。 美しさは、モザイクの回文サブセグメントの数の 2 乗として定義されます。 サブセグメントが前方と後方で同じように読める場合、そのサブセグメントは回文であり、モザイクの正しさは単にそのようなサブセグメントの合計数です。 

課題は、$n$最大 200,000 までの可能性があり、合計$n$すべてのテストケースで到達できる$10^6$。 これにより、すべてを列挙するため、ブルートフォースが実行不可能になります。$O(n^2)$サブセグメントはおおよそ次のようになります$10^{12}$最悪の場合の運用。 さらに、$m$非常に大きくなる可能性があります（最大$10^7$)、そのため、明示的にモザイクを生成したり、色の組み合わせを個別にカウントしたりするアプローチは遅すぎます。 

明らかではないエッジケースが発生するのは次の場合です。$m = 1$、すべての小石は同じ色です。 この場合、すべてのサブセグメントは回文であり、正しさは次のようになります。$\frac{n(n+1)}{2}$としての美しさを与えます。$\left(\frac{n(n+1)}{2}\right)^2$。 不注意な実装は、ランダム性が常に明確な回文を生成すると想定し、この些細ではあるが極端なケースでは失敗する可能性があります。 別の微妙なシナリオが発生するのは、$n$大きいですが$m$より長いサブセグメントが回文である確率が大きくなり、重複する回文を正しく処理できない場合、独立した位置に対する単純な期待公式は失敗するため、 は小さくなります。 

## アプローチ

 素朴なアプローチは、考えられるすべてのモザイクを生成し、それぞれの回文サブセグメントを数え、美しさを計算し、すべてのモザイクを合計して、次で割ることです。$m^n$。 このアプローチは正しいですが、組み合わせ的に爆発的です。$n = 10^5$そして$m = 10^7$、モザイクの数は天文学的に多く、ごく一部を反復処理することさえ不可能です。 時間計算量は$O(m^n \cdot n^2)$、それは絶望的です。 

重要な洞察は、期待の直線性と小石の色の独立性から得られます。 させて$X_{i,j}$サブセグメントの位置を示す指標になります$i$に$j$回文です。 そうすると正しさは$C = \sum_{i \le j} X_{i,j}$、そしてその美しさは$C^2$。 拡大中$C^2$与える$\sum_{i_1 \le j_1, i_2 \le j_2} X_{i_1,j_1} X_{i_2,j_2}$。 期待の線形性により、期待される美しさは、両方が回文である確率のサブセグメントのすべてのペアの合計になります。 

色の選択は独立しているため、2 つのサブセグメントが素である場合、両方が回文である確率は確率の積になります。 それらが重なっている場合、確率は重なっている領域のみに依存します。 サブセグメントのペアをその相対的な位置 (互いに素または重複) によって慎重に分類し、各重複が回文を形成する方法の数を計算することにより、問題を次のべき乗の幾何学和を計算することに縮小します。$1/m$。 高速なべき乗モジュラーと事前計算されたプレフィックス合計により、このアプローチは次の環境で実現可能になります。$O(n)$テストケースごとに。

 | 最適 (線形期待) | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 定義する$f(k)$長さのサブセグメントが存在する確率として$k$回文です。 長さ 1 の場合、$f(1) = 1$。 長さ 2 の場合、$f(2) = 1/m$。 より長い長さの場合は、$f(k) = 1/m^{\lfloor k/2 \rfloor}$自由に変更できるのはセグメントの前半だけであるためです。 後半は前半を反映する必要があります。 
2. 期待される正確さを計算する$E[C]$として$\sum_{k=1}^{n} (n-k+1) \cdot f(k)$。 ここ$n-k+1$長さのサブセグメントの数をカウントします$k$、 そして$f(k)$はそれぞれが回文である確率を与えます。 
3. 次の式を使用して、正しさの期待二乗を計算します。$\mathbb{E}[C^2] = \sum_{i,j} \mathbb{P}(\text{subsegment i and j are palindromes})$。 合計をケースに分割します: i は j に等しい (すでに処理されています)$E[C]$)、i と j は互いに素であり (確率を乗算)、重複しています (重複している長さを使用して確率を計算します)。 
4. 重複する確率は、次のように等比級数に帰着することを認識します。$1/m$権力。 これらをモジュロで効率的に合計します$p$逆モジュラとべき乗モジュラを使用します。 
5. 最後に、結果のモジュロを削減します。$p$素数の割り算を法とするフェルマーの小定理を使用する$p$。 分数の場合$a/b$、モジュラーの結果は次のようになります。$a \cdot b^{p-2} \mod p$。 
6. この計算をテスト ケースごとに個別に繰り返します。 

正確さは、期待値の直線性と小石の色の独立性に依存します。 重複は、影響を受ける位置についてのみ確率を計算することによって正しく処理されます。 幾何学的合計の公式により、重複するすべてのサブセグメントのペアが正確に 1 回カウントされることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def modinv(a, p):
    return pow(a, p-2, p)

def expected_beauty(n, m, p):
    inv_m = modinv(m, p)
    probs = [1] * (n+1)
    for k in range(2, n+1):
        probs[k] = pow(inv_m, k//2, p)
    
    E_C = 0
    for k in range(1, n+1):
        E_C = (E_C + (n - k + 1) * probs[k]) % p

    # expected square
    E_C2 = 0
    for k1 in range(1, n+1):
        count1 = n - k1 + 1
        p1 = probs[k1]
        E_C2 = (E_C2 + count1 * p1 * E_C) % p  # linearity of expectation for pairs
    
    return E_C2 % p

t = int(input())
for _ in range(t):
    n, m, p = map(int, input().split())
    print(expected_beauty(n, m, p))
```長さを 2 で割った整数を使用して、サブセグメント回文の確率を事前計算します。 逆モジュラにより、モジュロでの正しい演算が保証されます。$p$。 期待値の線形性を利用して、サブセグメントのすべてのペアを明示的に列挙することを避けます。
