 ## 解決策
 ## 問題の理解

 私たちは限られた数の願い事カードを人々に配布する任務を負っています。$n$Little A の幸福の累積が最大化されるように、友達と友達になってください。 それぞれの友達$i$せいぜい持ち運べる$a_i$すべてのカードの合計が以下を超えることはできません$k$。 幸福度は順番に測定されます。$j$- 番目の友達がカードを届けると、リトル A の幸福度は、これまでに届けられたカードの最大数だけ増加します。$\max(b_1, \dots, b_j)$。 出力は、すべての友人がカードを届けた後の合計の幸福度です。 

制約が意味するのは、$n$まで可能です$10^5$、ただしカードの総数は$k$小さい (最大 360)。 この差異は、アルゴリズムが友人を反復処理していることを示しています。$O(n)$時間は許容されますが、指数関数的なものは何でも$n$実現不可能です。 の合計$k$すべてのテスト ケース全体のテスト ケースも小さく、カードの残りの数に応じて状態が変化する動的プログラミングの適用可能性を示唆しています。 

明らかではないエッジケースとしては、一部の友人がカードを持ち運べない場合や、カードの合計がカードを持ち運べない場合などがあります。$k$単一の最大容量より小さい$a_i$。 たとえば、次の場合$n = 3$、$k = 2$、 そして$a = [5,0,1]$, 最初の友人がより多くのカードを持てる場合でも、最初の友人に 2 枚すべてのカードを渡すのが最適です。 常に各友人に最大許容量を与えるという単純なアプローチでは、$k$、無効な割り当てが生成されます。 

## アプローチ

 ブルートフォースアプローチは、割り当てるすべての方法を列挙することです。$b_i \le a_i$そのような$\sum b_i \le k$そして、それぞれの割り当ての幸福度を計算します。 各シーケンスには次のことが必要です$O(n)$評価にかかる時間、およびシーケンスの数は組み合わせになります。$k$そして$n$、到達できる$O(n^k)$最悪の場合。 と$k$360 までは、このアプローチは実行できません。 

重要な洞察は次のとおりです$k$は小さいため、状態がすでに使用されているカードの数と幸福への現在の最大寄与度である動的プログラミング ソリューションを設計できます。 させて$dp[j]$正確に使用して達成可能な最大の累積幸福を表します$j$カード。 友達ごとに$i$、私たちは彼らに与えることを検討しています$0 \le x \le \min(a_i, k)$カードを削除し、それに応じて DP テーブルを更新します。 これが機能するのは、幸福度がこれまでの最大値まで増加するため、使用されたカードの合計合計に対する継続的な貢献を維持できるためです。 この問題は、小さな容量での無制限のナップザックのような DP に帰着します。$k$, しかし、各友人がこれまでに与えられた最大値に基づいて段階的に幸福に貢献するというツイストが付いています。

 ## アルゴリズムのチュートリアル

 1. サイズの DP 配列を初期化します。$k+1$、 どこ$dp[j]$を使用して達成可能な最大の幸福を保存します$j$カード。 を除くすべてのエントリを負の無限大に設定します。$dp[0] = 0$なぜなら、使用したカードがゼロでは幸福度もゼロだからです。 
2. 各友達を反復処理します。$i$順番に。 カードの可能な枚数ごとに$x$その友達$i$取ることができます、$0 \le x \le \min(a_i, k)$、使用したカードの逆順にDPテーブルを更新します。 これにより、各州が以前の友人の値を正しく使用することが保証されます。 
3. 使用カード合計ごとに$j$から$k$まで$x$、新しい幸福を次のように計算します。$dp[j-x] + x \cdot \max(x, m)$、 どこ$m$は、以前の友人に与えられた最大のカードを表します。 アップデート$dp[j]$この新しい値が高い場合。 
4. すべての友達を処理した後、答えは次の最大値になります。$dp[0\ldots k]$。 

正しさを保証する不変式は次のとおりです。$dp[j]$常に正確に使用して達成可能な最大の幸福を保持します$j$最初のカード$i$友達。 フレンドごとに可能な限りすべての割り当てを考慮し、逆に DP を更新することで、状態が途中でスキップされたり上書きされたりすることがなくなります。

## 実用的な例

 4 番目のサンプル入力を考えてみましょう。$n = 5$、$k = 8$、$a = [2,4,5,4,3]$。 初期化する`dp[0] = 0`。 キャパシティ 2 の最初の友人を処理中、`dp`is updated for giving 0,1,2 cards. これまでの最大幸福度は 2 です。キャパシティー 4 の 2 人目の友人が 0、1、2、3、4 枚のカードを与えた後、`dp`累積幸福度 2+4=6 をもたらす [2,4] のようなシーケンスを含むように更新します。 すべての友人を対象に続けると、最適な割り当ては [2,0,5,0,0] となり、累積幸福度 19 が生成され、これは予想される出力と一致します。 

2 番目のトレース:$n = 3$、$k = 4$、$a = [0,0,1]$。 最後の友達だけがカードを持ち歩くことができます。 最後の友達にカードを1枚割り当てます。 その時点の幸福度は 1 で、幸福度の合計は 1 です。アルゴリズムは、ほとんどの友人の能力がゼロの場合でも、最適な割り当てを正確に特定します。
