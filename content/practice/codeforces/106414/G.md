 ## 解決策
 ## 問題の理解

 タスクは、値の変更が 1 つだけある配列の最長のサブシーケンスを見つけることです。 選択した要素には最初に 1 つの値が含まれている必要があります`A`1 回以上繰り返した後、別の個別の値を繰り返す`B`1回以上繰り返されます。 選択した要素の位置は元の順序を維持する必要がありますが、それらの間の要素はスキップできます。 そのような部分列が存在しない場合、答えは次のようになります。`0`。 

たとえば、から`2 1 3 1 2 1 0 2 0 3 0`、選択できます`1 1 1 0 0 0`のコピーが 3 つあります。`1`続いて 3 部のコピー`0`、長さを与える`6`。 ステップ関数の 2 つの部分は異なる値を使用する必要があるため、異なる値が 1 つだけ含まれるシーケンスは機能しません。 

すべてのテスト ケースにわたる要素の合計数は最大で次のとおりです。`100000`したがって、解は線形に近い必要があります。 周囲へのアプローチ`O(n log n)`は安全ですが、すべての値をスキャンしてすべての値のペアまたはすべての可能な分割を比較するソリューションは遅くなりすぎます。 

微妙なケースとしては、1 つの値が優勢であるが 2 番目の値が存在しない配列があります。 入力の場合:```
1
4
5 5 5 5
```正しい出力は次のとおりです。```
0
```最も頻度の高い値だけを見つける不注意な解決策は、次の結果を返す可能性があります。`4`、しかしそのシーケンスは決して変わりません`A`に`B`。 

もう 1 つの注意が必要なケースは、最良の回答が全体で最も頻度の高い値ではない場合です。 入力の場合:```
1
8
6 6 6 7 7 6 6 6
```正しい出力は次のとおりです。```
5
```すべての 6 を選択すると長さが決まります`6`ですが、シーケンスは値を変更しないため無効です。 最も有効な選択肢は次のいずれかです`6 6 6 7 7`または`7 7 6 6 6`。 

最後の境界ケースは、分割で両側に要素を残さなければならない場合です。 のために：```
1
2
1 2
```答えは`2`。 2 番目の要素の前で分割すると、次のコピーが 1 つ得られます。`1`続いて次のコピーを 1 部`2`。 ソリューションの最初または 2 番目に空の部分を誤って許可すると、無効な回答が作成される可能性があります。 

## アプローチ

 問題を解決する直接的な方法は、ステップが発生する可能性のあるすべての場所を試してみることです。 分割がポジション間で行われたと仮定します`i-1`そして`i`。 選ばれたすべての`A`前で終わる接頭辞から来ている必要があります`i`、そして選ばれたすべての`B`で始まるサフィックスから来ている必要があります`i`。 両方の部分の頻度を数えて、異なる値のすべてのペアを試すことができます。 

この考えは正しいですが、文字通りに実行すると遅すぎます。 がある`n-1`分割の可能性。 分割コストごとに周波数を再計算する`O(n)`毎回、すべての値のペアを比較すると、別の要素が追加される可能性があります。 最悪の場合、これは二次関数またはさらに悪化することになります。`10^10`のための操作`n = 100000`。 

重要な観察は、固定分割の場合、値が異なっていなければならないという制限付きで、左からの最良の周波数と右からの最良の周波数のみが必要であるということです。 分割によって順序がすでに保証されているため、各サイド内の位置はもう気にしません。 

すべての分割で、最も頻繁に使用される左の値と最も頻繁に使用される右の値が異なる場合、それらが最良の選択となります。 それらが等しい場合、答えには左から 2 番目に良い値、または右から 2 番目に良い値のいずれかを使用する必要があります。 これは、各側の上位 2 つの値のみを維持すれば十分であることを意味します。 

左から右へのスキャン中に、要素は右の頻度テーブルから左の頻度テーブルに 1 つずつ移動されます。 遅延削除を備えたヒープを使用すると、各更新後に 2 つの最も高い頻度を効率的に取得できます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列全体のすべての値の頻度をカウントし、これらのカウントをすべて右側の構造に入れます。 まだ分​​割によって交差される要素がないため、左側は空で始まります。 
2. 分割を左から右に移動します。 分割を評価する前に、分割の直前の要素を右側から左側に移動します。 これにより、左側には分割前の要素が正確に含まれ、右側には残りの要素が含まれるという不変条件が維持されます。 
3. 両側の最大ヒープを維持します。 周波数が変更されるたびに、新しい周波数をヒープに挿入します。 古いヒープ エントリは、現在の頻度テーブルと一致しなくなった場合、後で無視されます。 
4. 現在の分割について、左側から 2 つの最大の周波数エントリを取得し、右側から 2 つの最大の周波数エントリを取得します。 これらの候補の考えられる組み合わせを試し、2 つの値が異なる場合の最大合計を維持します。 
5. 考えられるすべての分割をチェックした後、保存された最大値は、最も長い有効なステップ関数サブシーケンスの長さになります。 有効なペアを生成する分割がなかった場合、答えは残ります。`0`。 

なぜ効果があるのか:

 すべての有効なステップ関数サブシーケンスには、そのシーケンス間に固有の境界があります。`A`部分とその`B`一部。 その境界線で全てが選ばれた`A`要素は左側にあり、すべて選択されています`B`要素は右側にあります。 このアルゴリズムは、考えられるすべての境界を検査します。 各境界について、両方の最大周波数が同じ値を使用する場合を除き、各側からの可能な最良の選択は最大周波数のみに依存します。 このような状況では、一方の側から 2 番目に大きな候補者を考慮する必要があります。 これらの候補の中からあらゆる最適な選択肢が現れるため、アルゴリズムは常に最良の有効なサブシーケンスを見つけます。 

## Python ソリューション```python
import sys
from collections import Counter
import heapq

input = sys.stdin.readline

def solve_case(a):
    n = len(a)

    left = {}
    right = Counter(a)

    left_heap = []
    right_heap = []

    for x, c in right.items():
        heapq.heappush(right_heap, (-c, x))

    def add_value(mp, hp, x, delta):
        mp[x] = mp.get(x, 0) + delta
        if mp[x] > 0:
            heapq.heappush(hp, (-mp[x], x))

    def get_top_two(mp, hp):
        res = []
        while hp and len(res) < 2:
            neg_c, x = hp[0]
            c = -neg_c
            if mp.get(x, 0) != c:
                heapq.heappop(hp)
            else:
                res.append((c, x))
                heapq.heappop(hp)
        for item in res:
            heapq.heappush(hp, (-item[0], item[1]))
        return res

    ans = 0

    for i in range(1, n):
        x = a[i - 1]
        add_value(right, right_heap, x, -1)
        add_value(left, left_heap, x, 1)

        left_best = get_top_two(left, left_heap)
        right_best = get_top_two(right, right_heap)

        for lc, lv in left_best:
            for rc, rv in right_best:
                if lv != rv:
                    ans = max(ans, lc + rc)

    return ans

def main():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        out.append(str(solve_case(a)))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```周波数辞書は現在の分割を表します。 値が分割を横切ると、そのカウントは右側で減少し、左側で増加します。 

ヒープには周波数のスナップショットが含まれています。 値は何度も更新される可能性があるため、古いヒープ エントリが残ります。 の`get_top_two`この関数は、格納された頻度が辞書と一致しなくなったエントリのみを削除するため、コストのかかるヒープの再構築が回避されます。 

分割ループは次から始まります`1`そしてで終わります`n-1`ステップ関数の両側に少なくとも 1 つの要素が含まれている必要があるためです。 上位候補間の 2 対 2 の比較では、すべての個別の値を検査する必要なく、等しい値の制限が処理されます。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io
from collections import Counter
import heapq

def solve(inp):
    data = inp.strip().split()
    if not data:
        return ""
    it = iter(data)
    t = int(next(it))
    ans = []

    for _ in range(t):
        n = int(next(it))
        a = [int(next(it)) for _ in range(n)]

        left = {}
        right = Counter(a)
        lh = []
        rh = []

        for x, c in right.items():
            heapq.heappush(rh, (-c, x))

        def add(mp, hp, x, d):
            mp[x] = mp.get(x, 0) + d
            if mp[x] > 0:
                heapq.heappush(hp, (-mp[x], x))

        def top2(mp, hp):
            res = []
            while hp and len(res) < 2:
                c, x = hp[0]
                c = -c
                if mp.get(x, 0) != c:
                    heapq.heappop(hp)
                else:
                    res.append((c, x))
                    heapq.heappop(hp)
            for c, x in res:
                heapq.heappush(hp, (-c, x))
            return res

        cur = 0
        for i in range(1, n):
            x = a[i - 1]
            add(right, rh, x, -1)
            add(left, lh, x, 1)
            for c1, x1 in top2(left, lh):
                for c2, x2 in top2(right, rh):
                    if x1 != x2:
                        cur = max(cur, c1 + c2)
        ans.append(str(cur))

    return "\n".join(ans)

 ## 特殊なケース

 異なる値が 1 つだけ含まれる配列の場合:```
1
4
5 5 5 5
```右側には、最初は 4 つのコピーすべてが含まれています。 可能な分割はすべて、一部のコピーを左に移動しますが、すべての候補ペアは両側で同じ値を持ちます。 値の比較ではすべてが拒否され、答えは次のようになります。`0`。 

のために：```
1
8
6 6 6 7 7 6 6 6
```3 番目の要素が左側の周波数を離れた後の分割`6:3`そして適切な周波数`6:3, 7:2`。 同じ値の最良の選択は次のとおりです`6 + 6`、しかしそれは無効です。 2番目の候補者`6 + 7`与える`3 + 2 = 5`、これは正しい結果です。 

最小の有効な入力の場合:```
1
2
1 2
```最初の値を左に移動した後、左の候補には次の値が含まれます。`(1,1)`適切な候補には次のものが含まれます`(1,2)`。 値が異なるため、答えは次のようになります。`2`。 これにより、アルゴリズムにより両方の部分の長さが 1 になることが許可されることが確認されます。
