 ## 解決策
 ## 問題の理解

 指定された長さの整数配列を構築する必要があります。 唯一の要件は、異なる位置のすべてのペアがその合計として素数を持つことです。 値自体は許可された範囲内に収まっていればよく、有効な構成は受け入れられます。 

主な難点は、この条件が隣接する要素だけでなくすべてのペアに適用されることです。 大きな配列の場合、すべてのペアをチェックすると多くの操作が必要になるため、ソリューションでは各ペアをテストせずにプロパティが明らかな方法で配列を作成する必要があります。 

届く長さは$2 \cdot 10^5$、テスト ケース全体の長さの合計は同じ限界を持ちます。 これにより、ペアを比較するアプローチは除外されます。$O(n^2)$仕事。 200,000 個の要素を含む 1 つのテスト ケースでも、約 200 億のペアが作成されるため、制限時間内には収まりません。 出力サイズに対して線形時間のみがかかる構築が必要です。 

難しいケースはパリティから生じます。 不用意に構築すると、素数になることができない 2 より大きい偶数の和を持つペアが誤って作成される可能性があります。 たとえば、入力を含む配列`3`として構築できませんでした`2 4 6`、ペアだから`2 + 4 = 6`プライムではありません。 正しい出力は次のようになります。```
3
```生産:```
1 1 2
```合計は`1 + 1 = 2`、`1 + 2 = 3`、 そして`1 + 2 = 3`、すべてプライム。 

もう 1 つの特殊なケースは、許容される最小の長さです。 入力の場合:```
2
```配列には満たすべきペアが 1 つだけあります。 次のような構造です。```
1 2
```唯一の合計が次のとおりであるため、機能します。`3`。 複数の等しい値が存在する必要があると想定するソリューションでは、この場合も処理する必要があります。 

## アプローチ

 直接的なアプローチでは、いくつかの数値を生成し、すべてのペアの合計を検証しようとします。 検証は簡単です。インデックスのペアごとに合計を計算し、それが素数であるかどうかをテストします。 問題はペアの数です。 のために$n$要素があります$\frac{n(n-1)}{2}$ペア、これは約になります$2 \cdot 10^{10}$いつ$n=200000$。 プライムチェックを検討する前に、これでは遅すぎます。 

有益な観察は、パリティを見ることから得られます。 2 以外の素数は奇数です。 2 つの数値が同じパリティを持つ場合、それらの合計は偶数になります。 つまり、2 つの偶数は一緒に現れることができません。その合計は 2 より大きい偶数になるからです。2 つの奇数は、その合計がちょうど 2 の場合にのみ機能します。つまり、両方の数値が 1 でなければなりません。 

これにより、非常に単純な構造が残ります。 いくらでも入れられます`1`私たちが望むように、すべてのペアが`1`s は素数 2 を与えます。偶数を 1 つだけ加算することができます。これは、1 との素数和を形成するだけでよいからです。 選択する`2`機能するので`1 + 2 = 3`、これは素数です。 

最終的な配列は常に次のシーケンスになります。`n - 1`単一のものが続く`2`。 この構築には、検索、素数テスト、または特別な処理は必要ありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 | O(n) | 出力以外の O(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 必要な配列の長さを読み取ります`n`。 
2.作成`n - 1`値のコピー`1`。 これらの要素のいずれか 2 つの合計は次のようになります`2`、これは素数です。 
3. 最終値を 1 つ追加します`2`。 この値と`1`になる`3`、これも素数です。 
4. 構築された配列を出力します。 

この構造が機能する理由は、危険なペアをすべて回避できるためです。 唯一繰り返される値は、`1`、唯一の偶数値は`2`, したがって、どのペアも偶数の合成数を作成することはできません。 

これが機能する理由: 不変条件は、生成された配列内のすべてのペアがいずれか 2 であることです。`1`1つまたは1つ`1`そして1つ`2`。 最初のケースは常に合計を返します`2`、2番目のケースは常に合計を返します`3`。 両方の値が素数であるため、考えられるすべてのペアが条件を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        ans.append(" ".join(["1"] * (n - 1) + ["2"]))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```コードはアルゴリズムの構築に直接続きます。 テスト ケースごとに、正確に作成されます。`n - 1`1 つと最後に 1 つ追加します`2`。 

ブルートフォースソリューションに必要な乗算や素数ロジックは完全に回避されます。 配列は構築によって有効になるため、プログラムは必要な出力の作成にのみ時間を費やします。 

リストのサイズは次によって制御されます。`n`、Python の整数は、出力される最大の値が 1 であるため、十分に大きくなります。`2`。 1 の数が正確であることを確認する以上に、1 つのエラーによって引き起こされる可能性のあるインデックス付けの決定や境界計算はありません。`n - 1`。

import sys

def solve(inp: str) -> str:
    data = inp.strip().split()
    t = int(data[0])

        n = int(data[idx])
        idx += 1
        out.append(" ".join(["1"] * (n - 1) + ["2"]))

    return "\n".join(out)
