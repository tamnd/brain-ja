 ## 解決策
 ## 問題の理解

 このタスクは構成的な幾何学の問題です。 個別の格子点のセットを受け取り、その境界が指定されたすべての点を訪れる単純な格子多角形の頂点を出力する必要があります。 追加の頂点は許可されますが、ポリゴンのすべてのターンは実際のターンである必要があります。つまり、連続する 3 つの頂点が 1 つの直線上に存在することはできません。 多角形は凸である必要はありません。 

すべてのテスト ケースのポイント数は最大で$2 \cdot 10^5$したがって、解は線形に近い必要があります。 すべての点のペアをチェックしたり、ポリゴンの交差を繰り返しテストしたりする方法は、すぐに二次関数になり、適合しなくなります。 座標は次のように大きくできます。$10^8$したがって、計算では十分な範囲の整数を使用する必要がありますが、構築自体は生成された座標を範囲内に維持するだけで十分です。$10^9$。 

よくある間違いは、ポイントをソートして直接出力することです。 この順序により自己交差する多角形が作成される可能性があり、同じ X 座標を共有する点によって禁止された多角形が作成される可能性があります。$180^\circ$角度。 たとえば、入力```
3
0 0
0 1
0 2
```チェーンとして印刷することはできません`(0,0),(0,1),(0,2)`なぜなら、中間点には同じ方向に向かう隣接するエッジが両方あるからです。 正しい出力は次のようになります。```
6
-2 -2
0 0
0 2
0 1
2 -2
2 2
```ここで、追加の頂点によって有効な単純な多角形が作成されます。 

もう 1 つの特殊なケースは、単一ポイントです。 のために```
1
5 7
```入力内の 2 つのエンドポイントを想定した構築は失敗します。 多角形にはまだ 3 つの頂点が必要なので、アルゴリズムは独自の周囲の頂点を追加する必要があります。 

## アプローチ

 直接的なアプローチは、指定された点を多角形に配置して、結果を検証することです。 可能な順序が多数あるため、順列を総当たりで検索することは不可能です。 数十万のポイントがある場合、変更のたびに何度もスワップを試したり、交差チェックを使用したりしても、コストがかかりすぎます。 

有益な観察は、緻密なポリゴンは必要ないということです。 すべてのポイントを大きな長方形で囲み、長方形の下側をすべての入力ポイントを含む単調なチェーンにすることができます。 点が x 座標でソートされている場合、その順序で点を接続しても x 方向に戻ることはできません。 チェーンは長方形の内側に留まり、長方形の残りの 3 辺がチェーンの外側の多角形を閉じます。 

残る唯一の困難は、x 座標が等しいことです。 同じ x 値を持つ点は垂直グループを形成します。 y 順序を増加させながらそのグループを横断すると、中間点を通る直線の継続が作成されます。 代わりに、最小の y、最大の y、2 番目に小さい y、2 番目に大きい y などを調べます。 垂直方向の動きごとに方向が変わるため、連続する 3 つの点が同一線上にはなりません。 

有効な順序があれば問題は解決するため、強引なアイデアは機能しますが、そのような順序を見つけるのは困難です。 単調な連鎖観察により、検索の必要がなくなります。 必要なのはソートと決定論的な構築だけです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n!)$|$O(n)$| 遅すぎる |
 | 最適 |$O(n \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての点を読み取り、すべての入力座標よりも大きい長方形を選択します。 させて$B$最大絶対座標より 1 つ大きい値になります。 長方形の角は、`(-B,-B)`、`(B,-B)`、`(B,B)`、 そして`(-B,B)`。 すべての入力ポイントは厳密にこの長方形の内側にあります。 
2. 点を x 座標でグループ化し、グループを x で並べ替えます。 各グループ内で y 値を並べ替え、低い値から高い値まで交互に並べ替えます。 これにより、垂直方向のランが発生するのを防ぎます。$180^\circ$振り向く。 
3. 以下から開始して、下のチェーンを構築します。`(-B,-B)`、構築された順序ですべての入力ポイントを追加し、で終了します。`(B,-B)`。 x 座標は、このチェーンに沿って減少することはありません。 
4.追加して多角形を閉じます。`(B,B)`そして`(-B,B)`。 これら 3 つの長方形のエッジはチェーンの外側にあるため、チェーンと交差することはできません。 
5. 結果として得られる頂点シーケンスを出力します。 

構築の背後にある不変条件は、元の点を含むチェーンが x モノトーンであり、2 つの端点を除いて厳密に長方形の内側に留まるということです。 長方形の閉じているエッジは、それらの端点でのみ接触します。 等しい x グループ内の交互の順序により、連続するセグメントが同じ線上に継続することが防止されるため、すべての頂点が本物のコーナーになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(points):
    mx = 0
    for x, y in points:
        mx = max(mx, abs(x), abs(y))
    b = mx + 1

    groups = {}
    for x, y in points:
        if x not in groups:
            groups[x] = []
        groups[x].append(y)

    order = []
    for x in sorted(groups):
        ys = sorted(groups[x])
        cur = []
        l, r = 0, len(ys) - 1
        while l <= r:
            if l == r:
                cur.append(ys[l])
            else:
                cur.append(ys[l])
                cur.append(ys[r])
            l += 1
            r -= 1
        for y in cur:
            order.append((x, y))

    ans = [(-b, -b)]
    ans.extend(order)
    ans.append((b, -b))
    ans.append((b, b))
    ans.append((-b, b))
    return ans

def main():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        points = []
        for _ in range(n):
            x, y = map(int, input().split())
            points.append((x, y))

        ans = solve_case(points)
        out.append(str(len(ans)))
        for x, y in ans:
            out.append(f"{x} {y}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```コードの最初の部分では、すべての元の点が含まれることが保証される四角形のサイズを見つけます。 余分な距離が 1 であると、入力ポイントが長方形の境界上に位置することがなくなります。 

グループ化段階が主な幾何学的なアイデアです。 x で並べ替えると、グローバルな単調な順序が作成されます。 1 つの X 座標グループ内の低位、高位、低位、高位のトラバースは、最も一般的な誤った答えを回避するための小さな詳細です。 単純な昇順では、次のような垂直トリプルが作成されます。`(x,0),(x,1),(x,2)`無効。 

最後のリストは左下隅から始まり、必要なすべての点を含み、長方形を完成させます。 最後の 3 つの角の順序は、多角形が単純なままであり、生成されたすべての座標が必要な境界内に収まるように選択されます。 

## 実用的な例

 最初のサンプルの場合:```
5
2 4
3 6
4 4
5 3
6 2
```長方形のサイズは最大の絶対座標に基づいているため、$B=7$。 すべてのポイントにはすでに異なる x 値が設定されています。 

| ステップ | 現在の頂点 | 理由 |
 | --- | --- | --- |
 | 開始 | (-7、-7) | 長方形のコーナー |
 | 追加 | (2,4) | 最初にソートされた点 |
 | 追加 | (3,6) | x が増加します |
 | 追加 | (4,4) | x が増加します |

 | 追加 | (6,2) | x が増加します |
 | 仕上げ | (7,-7),(7,7),(-7,7) | 長方形を閉じる |

 チェーンは左から右に 1 回移動しますが、閉じている長方形のエッジを横切ることはありません。 これは、equal-x 処理が必要ない通常のケースを示しています。 

垂直グループの場合:```
3
5 0
5 1
5 2
```点は 1 つの X 座標を共有します。 

| ステップ | 現在の頂点 | 理由 |
 | --- | --- | --- |

 | 追加 | (5,0) | 最低のy |

 | 追加 | (5,1) | 残りポイント |

 中間点`(5,2)`次のエッジは下に向かうため、同じ方向を指す 2 つのエッジがありません。 これにより、等座標補正が行われたことが確認できます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 |$O(n \log n)$| x グループとグループ内の y 値の並べ替えが作業の大半を占めます。 
| スペース |$O(n)$| グループと出力ポリゴンには、入力ポイントごとに一定数のエントリが含まれています。 

テスト ケース全体のポイントの合計数は次のとおりです。$2 \cdot 10^5$したがって、並べ替えベースのソリューションは予想される制限内に留まります。 出力サイズは最大でも$n+3$、これは許容値を大幅に下回っています$10n$縛られた。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    data = sys.stdin.read().split()
    sys.stdin = old

    it = iter(data)
    t = int(next(it))
    ans = []
    for _ in range(t):
        n = int(next(it))
        pts = []
        for _ in range(n):
            pts.append((int(next(it)), int(next(it))))

        mx = max(max(abs(x), abs(y)) for x, y in pts)
        b = mx + 1

        groups = {}
        for x, y in pts:
            groups.setdefault(x, []).append(y)

        order = []
        for x in sorted(groups):
            ys = sorted(groups[x])
            l, r = 0, len(ys) - 1
            while l <= r:
                order.append((x, ys[l]))
                l += 1
                if l <= r:
                    order.append((x, ys[r]))
                    r -= 1

        poly = [(-b, -b)] + order + [(b, -b), (b, b), (-b, b)]
        ans.append(str(len(poly)))
        ans.extend(f"{x} {y}" for x, y in poly)

    return "\n".join(ans)

 ## 特殊なケース

 ワンポイントの場合、例えば```
1
5 7
```アルゴリズムは次の長方形を作成します$B=8$、次に場所`(5,7)`モノトーンチェーンに。 結果には、四角形に関連する 4 つの頂点と必要な点が含まれるため、入力自体には形状がなくても、多角形には十分な角があります。 

x 座標を共有する点の場合、たとえば```
3
5 0
5 1
5 2
```グループは次のように順序付けされます`(5,0),(5,2),(5,1)`。 2 番目のエッジは垂直方向を反転し、まっすぐに継続するのを防ぎます。`(5,2)`。 周囲の長方形により、この垂直チェーンが閉じているエッジと交差しないことが保証されます。 

非常に大きな座標を持つ点の場合、```
2
100000000 100000000
-100000000 -100000000
```選択した長方形は使用します$B=100000001$したがって、生成されたすべての座標は以下に残ります。$10^9$。 この構築では加算と比較のみが実行され、オーバーフローが発生しやすい幾何学的計算が回避されます。
