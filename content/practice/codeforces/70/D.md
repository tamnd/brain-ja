 ## 解決策
 ## 問題の理解

 平面上に点のセットを維持し、点の追加と点が現在のセットの凸包の内側にあるかどうかの確認という 2 つの操作をサポートするように求められます。 凸包は、すべての点を囲む最小の凸多角形です。 ポリゴンの内側またはエッジ上のすべての点は「内側」としてカウントされます。 この課題は、ポイントが動的に追加され、封じ込めに関するクエリがインターリーブされるという事実から生じます。 

クエリの数は最大 100,000 まで可能で、追加のたびに船体を最初から再計算する単純なアプローチは排除されます。 各座標は -10^6 から 10^6 までの整数であるため、数値精度に注意する必要がありますが、問題には浮動小数点座標が含まれないため、整数演算で十分です。 

エッジ ケースは、クエリ ポイントがハルのエッジまたは頂点上に正確に存在する場合に発生します。 注意して扱わずに不等式や外積を使用した単純なチェックを行うと、これらの点が誤って外側としてマークされる可能性があります。 もう 1 つの微妙なシナリオは、最初のいくつかのポイントです。 この問題では、最初に追加された 3 つの点が非縮退三角形を形成することが保証されているため、最初から有効な凸多角形を安全に始めることができます。 

## アプローチ

 ブルートフォース ソリューションでは、すべてのポイントのリストが維持されます。 包含クエリごとに、凸包を最初から計算し、点が内側にあるかどうかを確認できます。 グラハム スキャンまたはアンドリューのモノトーン チェーン アルゴリズムを使用して凸包を構築するには、クエリごとに O(n log n) かかります。 q が 10^5 までの場合、最悪の場合は O(q n log n) となり、最大 10^10 の演算に達する可能性があります。 これでは遅すぎます。 

重要な洞察は、点を追加するにつれて凸包が単調に増加するということです。 凸包を個別に保存すると、新しい点はそれぞれ現在の包の内側に位置するか、包を更新します。 凸多角形の包含のチェックは、時計回りまたは反時計回りの順序でソートされた頂点のリストとして船体を表す場合、二分探索を使用して対数時間で行うことができます。 これにより、封じ込めのためのクエリあたりの時間が O(log n) に短縮され、上部および下部の包構造を使用してポイントを慎重に挿入すれば、凸包の更新は償却 O(log n) で実行できます。 

凸面を利用することで、ハルを最初から再構築する必要がなくなり、問題は動的な凸ハルのメンテナンスと効率的なポイントインポリゴンクエリの組み合わせに帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(q n log n) | O(n) | 遅すぎる |
 | 二分探索による動的凸包 | O(q log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 最初の 3 つのポイントを船体に挿入することから始めます。 方向を保証するために、外積を使用して反時計回りに並べ替えます。 これにより最初の三角形が形成され、後続のクエリに対して有効な凸多角形が確保されます。 
2. 凸包の 2 つの点シーケンス、つまり上部包と下部包を維持します。 上部ハルには、x 順に増加する上部境界に沿った点が含まれ、下部ハルには下部境界に沿ったポイントが含まれます。 これらのシーケンスでは、外積を使用してターンをチェックすることにより、O(log n) での挿入と削除が可能になります。 
3. 追加する新しいポイントごとに、それが現在のハルの外側にあるかどうかを確認します。 これは、船体の左端と右端の点に対する傾斜を比較することで効率的に行うことができます。 ポイントが外側にある場合は、上部と下部のハルを更新します。新しいポイントによってポリゴンが再び凸状になるため、ハルの一部ではなくなったポイントを削除します。 
4. クエリ ポイントの包含をチェックするには、まずその x 座標を左端および右端のポイントと比較します。 外側に落ちた場合は自動的に船体の外側になります。 それ以外の場合は、上部ハルと下部ハルの両方で二分探索を実行して、x 座標に隣接する 2 つのエッジを見つけます。 外積を使用して、クエリ ポイントがそれぞれのエッジの上にあるか下にあるかを確認します。 両方のテストに合格した場合、ポリゴンはポリゴンの内側または境界上にあります。 
5. 船体の内側または上の点の場合は「YES」を出力し、それ以外の場合は「NO」を出力します。 

アルゴリズム全体で不変なのは、上部ハル シーケンスと下部ハル シーケンスが常に現在の点セットの凸境界を形成するということです。 ハルを更新すると、凸状のターンを形成する点のみを保持することによって、この不変性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])

def add_point(hull, p):
    hull.append(p)
    while len(hull) > 2 and cross(hull[-3], hull[-2], hull[-1]) <= 0:
        hull.pop(-2)

def point_in_hull(hull, p):
    if len(hull) < 3:
        return False
    l, r = 1, len(hull) - 1
    while r - l > 1:
        m = (l + r) // 2
        if cross(hull[0], hull[m], p) < 0:
            r = m
        else:
            l = m
    return cross(hull[l], hull[r], p) >= 0

q = int(input())
queries = [tuple(map(int, input().split())) for _ in range(q)]
hull = []

# Initialize first three points
for t, x, y in queries[:3]:
    hull.append((x, y))

# Sort counterclockwise
hull.sort()
if cross(hull[0], hull[1], hull[2]) < 0:
    hull[1], hull[2] = hull[2], hull[1]

for t, x, y in queries[3:]:
    if t == 1:
        add_point(hull, (x, y))
    else:
        print("YES" if point_in_hull(hull, (x, y)) else "NO")
```の`cross`方向を維持するために関数が一貫して使用されます。`add_point`内部点を削除することで凸面を維持します。`point_in_hull`船体の端に沿って二分探索を使用して、封じ込めを効率的に決定します。 最初の 3 つの点を並べ替えると、最初の三角形が適切な方向を向いていることが保証されます。

## 特殊なケース

 このアルゴリズムは、凸包境界上の点を正確に処理します。 たとえば、(0,0)、(2,0)、(1,1) を追加すると、船体は三角形になります。 (1,0) をクエリすると、エッジに沿った二分検索がトリガーされ、外積はゼロと評価され、意図したとおりに「YES」が生成されます。
