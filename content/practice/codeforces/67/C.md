 ## 解決策
 ## 問題の理解

 元のシーケンス A とターゲット シーケンス B という、小文字でラベル付けされた 2 つのボールのシーケンスが与えられています。ボールの挿入、ボールの削除、ボールの置換、または 2 つの隣接するボールの交換の 4 種類の操作を使用して、A を B に変換したいと考えています。 各操作には固定コストがあり、スワップ操作には制限があります。つまり、スワップ操作を 2 回実行しても、削除とそれに続く同じ位置への挿入より安くなることはありません。 私たちの目標は、A を B に変換するための最小の総コストを見つけることです。 

シーケンスにはそれぞれ最大 4000 個の要素を含めることができるため、どのソリューションでも O(4000²) の操作を快適に処理する必要があります。 考えられるすべてのシーケンスに対するブルートフォース検索は、シーケンス長が指数関数的に長い空間を探索することになり、実行不可能です。 したがって、問題の構造を利用して再計算を回避する必要があります。 エッジ ケースには、同一のシーケンス、長さ 1 のシーケンス、位置合わせにスワップのみが必要なシーケンス、または操作の異なる組み合わせで複数の最適なパスが存在するシーケンスが含まれます。 たとえば、変形する`a`に`b`1 回の交換で済みます (コスト`tr`) または削除と挿入 (コスト`td + ti`)、アルゴリズムは安価なものを選択する必要があります。 

## アプローチ

 素朴なアプローチは、B に到達するまで、許可された操作を介して A から到達可能なすべての可能なシーケンスを探索することです。 これは、シーケンスを表すノードと操作を表すエッジを使用して、シーケンスのグラフを効果的に列挙することになります。 各操作により総コストが増加します。 シーケンスの数は A と B の長さに応じて指数関数的に増加するため、長さが 4000 までのシーケンスに対してこのアプローチは計算上不可能になります。 

重要な洞察は、これが追加の許可された操作 (スワップ) を伴う編集距離のバリエーションであるということです。 クラシック編集距離では、動的プログラミングを使用して、A のプレフィックスを B のプレフィックスに変換する最小コストを計算します。 DP テーブルを定義します。`dp[i][j]`A の最初の i 文字を B の最初の j 文字に変換するための最小コストを表します。遷移では、標準の 3 つの操作、挿入、削除、置換が考慮されます。 スワップは個別に処理されます。`A[i-1] == B[j-2]`そして`A[i-2] == B[j-1]`、コストをかけて最後の 2 つの要素を交換できます`te`この DP アプローチでは、複雑さが指数関数から O(n・m) に軽減されます。これは、n、m ≤ 4000 の場合に許容されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(26^(n+m)) | お(?) | 遅すぎる |
 | スワップを使用した動的プログラミング | O(n・m) | O(n・m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 操作コストと 2 つのシーケンス A と B を読み取ります。 
2. サイズの 2D DP テーブルを初期化します。`(len(A)+1) x (len(B)+1)`。 要素`dp[i][j]`は、A の最初の i 文字を B の最初の j 文字に変換するための最小コストを表します。 
3. 最初の行を入力します`dp[0][j]`累積挿入コストを伴う。 これは、各文字を順番に挿入することによって、空のシーケンスを B の最初の j 文字に変換することを表します。 同様に、最初の列を埋めます`dp[i][0]`累積削除コストを使用し、A の最初の i 文字を空のシーケンスに変換することを表します。 
4. i を 1 から len(A) まで、j を 1 から len(B) まで繰り返します。 それぞれのポジションについて、3 つのオプションを検討してください。 現在の文字が一致する場合 (`A[i-1] == B[j-1]`）、 持ち越す`dp[i-1][j-1]`。 それ以外の場合は、文字を置換する際の最小コストを計算します (`dp[i-1][j-1] + tr`)、削除(`dp[i-1][j] + td`)、または挿入 (`dp[i][j-1] + ti`）。 アップデート`dp[i][j]`最小値で。 
5. スワップ操作を処理します。`i > 1`、`j > 1`、`A[i-1] == B[j-2]`、 そして`A[i-2] == B[j-1]`、 アップデート`dp[i][j]`現在の値の最小値として、`dp[i-2][j-2] + te`。 これは、最後の 2 文字を交換する方が、削除/挿入または置換操作よりも安価であるというシナリオを捉えています。 
6. テーブルに記入したら、`dp[len(A)][len(B)]`A を B に変換するための最小総コストが含まれます。 

不変条件とは、`dp[i][j]`は常に、対応するプレフィックス長に対して可能な最小限のコストを保持します。 各更新では有効な操作のみが考慮され、コストが決して過大評価されないため、最終的な値が最適であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    ti, td, tr, te = map(int, input().split())
    A = input().strip()
    B = input().strip()
    n = len(A)
    m = len(B)
    
    # initialize DP table
    dp = [[0] * (m+1) for _ in range(n+1)]
    
    # first row and column
    for i in range(1, n+1):
        dp[i][0] = dp[i-1][0] + td
    for j in range(1, m+1):
        dp[0][j] = dp[0][j-1] + ti
    
    # fill DP table
    for i in range(1, n+1):
        for j in range(1, m+1):
            if A[i-1] == B[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = dp[i-1][j-1] + tr
            dp[i][j] = min(dp[i][j], dp[i-1][j] + td, dp[i][j-1] + ti)
            if i > 1 and j > 1 and A[i-1] == B[j-2] and A[i-2] == B[j-1]:
                dp[i][j] = min(dp[i][j], dp[i-2][j-2] + te)
    
    print(dp[n][m])

if __name__ == "__main__":
    main()
```DP テーブルの構築はアルゴリズムに正確に従います。 境界と文字の配置をチェックするためにスワップ操作を処理するときは、特別な注意が必要です。 最初の行と列を埋めることで、1 つのシーケンスが空である基本的なケースが処理されます。 使用する`dp[i-2][j-2] + te`両方のシーケンスに少なくとも 2 文字がある場合にのみスワップが適用されるようにします。
