 ## 問題の理解

 私たちには生徒の列があり、隣接するすべてのペアについて、マークの相対的な順序しかわかりません。 位置間の関係文字の場合`i`そして`i + 1`は：

-`L`、その後学生`i`学生よりも厳密に多くのコーヒーを受け取らなければなりません`i + 1`-`R`、その後学生`i + 1`学生よりも厳密に多くのコーヒーを受け取らなければなりません`i`-`=`、その場合、両方の生徒は同じ数のタフィーを受け取る必要があります

 すべての生徒は少なくとも 1 つのタフィーを受け取る必要があり、関係を満たすすべての課題の中で、合計が最小の課題が必要です。 

入力は実際のマークではありません。 代わりに、隣接する学生間の制約を直接与えます。 リレーション文字列に長さがある場合`n - 1`、次にキャラクター`s[i]`位置間の関係を説明します`i`そして`i + 1`。 

制約`n ≤ 1000`かなり小さいです。 たとえ`O(n^2)`最悪の場合でも約 100 万回の操作があるため、ソリューションは問題なく通過します。 つまり、高度なデータ構造や高度な最適化を伴うグラフ アルゴリズムは必要ありません。 課題は、地域の不平等が世界的にどのように影響するかを推論することです。 

難しいのは、1 つの位置を変更すると、隣接する位置に繰り返し更新が強制される可能性があることです。 早すぎる素朴な貪欲な選択は、後で制約を破る可能性があります。 

次の例を考えてみましょう。```
4
RRR
```制約は次のとおりです。```
a1 < a2 < a3 < a4
```最小の有効な割り当ては次のとおりです。```
1 2 3 4
```現在有効な最小値を常に与える不注意な左から右への貪欲な場合、次のものが割り当てられる可能性があります。```
1 2 1 2
```3 番目のリレーションは失敗します。`a2 < a3`はもう真実ではありません。 

もう 1 つの危険なケースは、チェーンの減少が長い場合です。```
5
LLLL
```制約は次のようになります。```
a1 > a2 > a3 > a4 > a5
```正しい最小割り当ては次のとおりです。```
5 4 3 2 1
```すべてを初期化すると、`1`ローカル違反を一度だけ修正すると、効果が左端まで伝播する前に停止が早すぎる可能性があります。 

平等は、同じ値を共有する必要があるグループにポジションを結び付けるため、平等も重要です。 

例：```
5
R==L
```関係は次のとおりです。```
a1 < a2 = a3 = a4 > a5
```最小の割り当ては次のとおりです。```
1 2 2 2 1
```等しいことが「同じ値」ではなく「制限なし」として扱われると、次のように誤って生成される可能性があります。```
1 2 1 2 1
```違反するもの`a2 = a3`。 

## アプローチ

 簡単で強引なアイデアは、すべての生徒にトフィーを 1 つ与えて、関係を繰り返しスキャンすることです。 制約に違反するたびに、関係が有効になるまで一方の側を増やします。 

たとえば、次のようになります。`R`位置にある`i`そして現在`a[i] >= a[i+1]`、増やします`a[i+1]`に`a[i] + 1`。 同様に、`L`、必要に応じて左側を増やします。 のために`=`、両方の値を同期します。 

値は増加するだけであり、更新ごとに少なくとも 1 つの違反が修正されるため、このプロセスは最終的に収束します。 強制された場合にのみ値を引き上げるので、最終的な割り当ては最小限です。 

問題は、更新がアレイ全体に繰り返し伝播する可能性があることです。 最悪の場合、各スキャンで 1 つの位置のみが修正されるため、`O(n^2)`操作。 

重要な観察は、すべての関係は隣接する位置にのみ依存するということです。 増加する要件は一方向に流れます。 

次のようなチェーンの場合:```
RRRR
```各位置は左隣に依存します。 最小値は左から右に構築できます。 

のために：```
LLLL
```依存関係は右から左に流れます。 

これは、問題を 2 つの方向のパスに分割することを示唆しています。 

1 で初期化された配列を維持します。 

左から右へのパス中、すべてを処理します`R`関係。 位置の場合`i + 1`位置より大きくなければなりません`i`の場合、最小の有効な選択肢は次のようになります。```
a[i+1] = a[i] + 1
```右から左へのパス中はすべてを処理します`L`関係。 位置の場合`i`位置を超えなければなりません`i + 1`の場合、最小の有効な選択肢は次のようになります。```
a[i] = max(a[i], a[i+1] + 1)
```等価性は、両方のパスで値を適切にコピーすることで処理できます。 

重要な洞察は、どの制約も値を必要最小限まで押し上げるだけであるということです。 両方の方向の依存関係が処理されると、すべての不等式が同時に成立します。

 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を作成する`a`長さの`n`すべての値を次のように初期化します`1`。 

すべての生徒は少なくとも 1 つのタフィーを受け取らなければなりません。`1`可能な最小の開始点です。 
2. 左から右にトラバースします。 

位置におけるあらゆるリレーションに対して`i`：

- もし`s[i] == 'R'`、その後学生`i + 1`学生以上のものを受け取らなければなりません`i`。 
- セット：```
a[i+1] = a[i] + 1
```- もし`s[i] == '='`の場合、両方の生徒が同じ値を持つ必要があります。 
- セット：```
a[i+1] = a[i]
```このパスは、依存関係が左から右に移動するすべての制約を解決します。 
3. 右から左にトラバースします。 

位置におけるあらゆるリレーションに対して`i`：

- もし`s[i] == 'L'`、その後学生`i`学生以上のものを受け取らなければなりません`i + 1`。 
- セット：```
a[i] = max(a[i], a[i+1] + 1)
```- もし`s[i] == '='`、その後、両方の生徒が再び一致する必要があります。 
- セット：```
a[i] = max(a[i], a[i+1])
a[i+1] = a[i]
```の`max`以前の制約により、左から右へのパスにはすでに大きな値が割り当てられている可能性があるため、これが必要です。 
4. 結果の配列を印刷します。 

### なぜ効果があるのか

 左から右へのパスは、フォームの増大するすべての依存関係を満たすために必要な最小値を計算します。`a[i] < a[i+1]`。 右から左へのパスは、フォームの依存関係が減少するたびに必要な最小値を計算します。`a[i] > a[i+1]`。 

どのステップも不必要に値を増加させることはありません。 すべての更新では、以前に確立された要件を維持しながら、ローカル制約を満たすことができる最小の数値に位置が設定されます。 

両方のパスの後、すべての隣接関係が満たされます。 すべての値は可能な最小値から始まっているため、`1`制約によって強制された場合にのみ増加するため、合計は最小限になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    s = input().strip()

    a = [1] * n

    for i in range(n - 1):
        if s[i] == 'R':
            a[i + 1] = a[i] + 1
        elif s[i] == '=':
            a[i + 1] = a[i]

    for i in range(n - 2, -1, -1):
        if s[i] == 'L':
            a[i] = max(a[i], a[i + 1] + 1)
        elif s[i] == '=':
            val = max(a[i], a[i + 1])
            a[i] = val
            a[i + 1] = val

    print(*a)

solve()
```解決策は、生徒全員にトフィーを 1 つ割り当てることから始まります。 これにより、最低限の法的基本状態が保証されます。 

最初のパスは、右側に流れる依存関係を処理します。 見ると`R`、右側の生徒の方が厳密に大きくなければならないため、左側よりも正確に 1 つ多く割り当てます。 見ると`=`、等価性が正確に成立する必要があるため、同じ値をコピーします。 

2 番目のパスは、左向きの依存関係を処理します。 のために`L`、左の生徒は少なくとも 1 つ右の生徒を上回らなければなりません。 私たちが使用するのは`max`なぜなら、左側は前の制約からすでに十分に大きい可能性があるからです。 

バックワードパスでの等価性の処理は微妙です。 片側が別のチェーンによって大きくなったとします。 平等とは、双方がより大きな値を共有する必要があることを意味します。 一方向のみを更新すると、平等が崩れる可能性があります。 

ループ:```
for i in range(n - 2, -1, -1):
```も間違えやすいです。 から始めます`n - 2`なぜなら関係があるから`s[i]`ポジションを繋ぐ`i`そして`i + 1`。 

整数オーバーフローの懸念は存在しません。`n ≤ 1000`したがって、可能な最大値は最大です。`1000`。

 ## 特殊なケース

 長く減少する連鎖は、一方向の解決策を打ち破る最も簡単な方法です。 

入力：```
5
LLLL
```左から右へのパスの後、配列は次のようになります。```
1 1 1 1 1

5 4 3 2 1

4
===

R==L

```違反するもの`a3 = a4`。
