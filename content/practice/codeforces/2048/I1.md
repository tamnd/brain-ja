 ## 解決策
 ## 問題の理解

 方向の文字列に対応する非負の整数の配列を構築するように求められます。文字列内の各文字は、配列の接頭辞または接尾辞のいずれかに含まれる個別の数値の数に関する条件を指定します。 キャラクターが`L`位置で`i`の配列要素`i`は、その前の部分配列内の個別の整数の数と等しくなければなりません。 キャラクターが`R`の配列要素`i`は、その後にある個別の整数の数と等しくなければなりません。 これらの制約をすべて満たす配列がない場合は、レポートする必要があります。`-1`。 

文字列の長さ`n`すべての合計を含めると、最大 200,000 に達する可能性があり、最大 10,000 のテスト ケースが存在する可能性があります。`n`200,000 を境界とするテスト ケース全体で。 これは、線形よりも複雑なソリューションを意味します。`n`テストケースごとに実行すると遅すぎます。 すべての位置の個別の要素をカウントする総当り的なアプローチは二次関数となるため、実行不可能です。 

すべての文字が同じ場合、微妙な特殊なケースが発生します。たとえば、`RRR`または`LLL`。 のために`RRR`では、各要素がその後のサフィックス内の個別の数値をカウントするようにしたいので、厳密に増加または減少するパターンが機能する可能性があります。 のために`LLL`、配列はプレフィックスごとに拡張する必要があります。 もう 1 つの特殊なケースは、次のような文字を交互に使用することです。`LRLR`ここで、左右両方の個別のカウントを満たすには、慎重な割り当てが必要です。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての配列を試し、すべての位置の個別のカウント条件をチェックします。 位置ごとに、プレフィックスまたはサフィックスをスキャンして、一意の要素をカウントします。 これには、$O(n^2)$テストケースごとに操作が必要ですが、これは非現実的です。`n`最大 2×10^5。 

重要な観察は、配列内の値が厳密に増加または減少するシーケンスのインデックスに対応しているということです。 プレフィックスまたはサフィックス内の個別の数値のカウントは 0 から始まり、各ステップで最大 1 ずつ増加するため、スライディング シーケンスに沿って増加する整数を慎重に選択することで、有効な配列を構築できます。 から始めることができます`0`どちらかの端で増分します`1`または、パターンに基づいて同じままになります`L`そして`R`。 具体的に治療すると、`L`プレフィックスの個別のカウントが配列要素と一致するようにしたい場合は、左から増分シーケンス内の位置として要素を割り当てることができます。 同様に、`R`、右から割り当てることができます。 

本質的に、候補シーケンスは 2 つあります。1 つは次のとおりです。`0`左から右に増分し、で始まるもの`0`そして右から左に増加します。 これらのシーケンスのいずれかがすべての制約を満たしていれば、それを出力できます。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、長さを読み取ります。`n`と文字列`s`。 
2. 配列を構築する`a`長さの`n+1`候補解を保存します。 
3. 要素が次から段階的に割り当てられる順序を検討します。`0`に`n`左から右へ。 このシーケンスは治療に相当します。`L`ユニークな要素を最初から数えます。 ポジションごとに`i`、割り当てます`a[i] = i-1`。 これが条件を満たしているかどうかを確認してください`R`比較して順位を付ける`a[i]`に`n-i`。 
4. 左から右へのシーケンスが失敗した場合は、右から左へのシーケンスを構築します。`a[i] = n-i`。 を満たしているか確認してください`L`比較して順位を付ける`a[i]`に`i-1`。 
5. 2 つのシーケンスのいずれかが機能する場合は、それを出力します。 それ以外の場合は、印刷します`-1`。 

このアルゴリズムは、次の文字列に対して、`L`s の場合、プレフィックスの個別カウントはゼロから始まり、増加することしかできないため、増分値を割り当てるとすべての条件が満たされます。`L`s. 同様に、`R`s、から減少する方法で値を割り当てます。`n-1`に`0`接尾辞の個別のカウントが一致することを確認します。 

機能する理由: 配列の各要素は、その前後にある個別の整数の数を反映します。 各ステップで数値がちょうど 1 ずつ増加するシーケンスを考慮することにより、個別のカウントの不変条件が保持されることが保証されます。 負でない整数のみが許可されるため、次のようになります。`0`有効性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        
        # try left-to-right assignment
        left = list(range(n+1))
        right = list(range(n, -1, -1))
        
        candidate = None
        for start in range(n+1):
            # build array with start point
            a = list(range(start, start+n+1))
            valid = True
            for i in range(n):
                if s[i] == 'L' and a[i] != i:
                    valid = False
                    break
                if s[i] == 'R' and a[i] != n-i-1:
                    valid = False
                    break
            if valid:
                candidate = [a[i] for i in range(n)]
                break
        
        if candidate:
            print(' '.join(map(str, candidate)))
        else:
            print(-1)

if __name__ == "__main__":
    solve()
```このソリューションは、まずテスト ケースの数を読み取ります。 それぞれの場合において、左から右へおよび右から左への増分割り当てに対応する 2 つの単純なシーケンスが試行されます。 コードは、位置ごとに、要素がプレフィックスまたはサフィックスの個別のカウント要件を満たしているかどうかをチェックします。 有効なシーケンスが見つかった場合は、それを出力します。 それ以外の場合は印刷されます`-1`。 実装上の微妙な選択は、特にゼロベースの Python リストでの off-by-one エラーを避けるために、インデックス付けを慎重に処理することです。
