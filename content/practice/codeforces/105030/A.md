 ## 解決策
 ## 問題の理解

 スパイスの各単位には整数のトピックが付けられます。 すべての単位をできるだけ少ない学生に分配する必要があります。 

1 人の学生が複数の単位を取得する場合がありますが、その学生に割り当てられた 2 つのトピックは 2 つ以上異なる必要があります。`k`。 2 つのトピック番号の差が最大でも異なる場合`k`、それらは類似しているとみなされ、同じ学生に属することはできません。 

タスクは、必要な生徒の最小数を計算することです。 

の値`n`到達する`2 · 10^5`したがって、トピックのすべてのペアを比較したり、異なる割り当てを試みたりするアルゴリズムは、すぐにコストが高くなりすぎます。 二次アルゴリズムには次のものが必要です`4 · 10^10`実用的な限界をはるかに超えた最悪の場合の動作。 私たちが目指すべきは、`O(n log n)`またはそれ以上です。 

特別な注意が必要な状況がいくつかあります。 

いつ`k = 0`, 一人の生徒の課題内で同じトピックだけを扱うことは禁止されています。 例えば、```
3 0
3 1 1
```正しい答えは、`2`。 1 人の生徒がトピックを受け取ることができます`1`そして`3`、2番目の生徒が残りを受け取ります`1`。 単純に個別の値をカウントすると、誤った値が生成されます。`1`。 

価値観間の大きなギャップは完全に競合を排除します。 例えば、```
4 5
1 10 20 30
```正しい答えは、`1`、すべてのペアは以上の差があるため、`5`。 距離を考慮せずに要素の総数のみを調べる解決策では、答えが過大評価されてしまいます。 

多くの等しい値と近くの値は、別の罠です。 考慮する```
5 2
5 5 5 6 7
```正しい答えは、`5`。 すべてのコピー`5`他のすべてのコピーと競合し、両方とも競合します`6`そして`7`あらゆるものとも衝突する`5`。 1 人の生徒のシーケンス内の前の値のみを追跡する貪欲な割り当ては、多重性を無視すると簡単に不正確になる可能性があります。 

## アプローチ

 直接的なアプローチは、すべてのトピックを既存の生徒に割り当て、誰も受け入れられない場合には新しい生徒を作成することです。 慎重に実装すれば、すべての決定が以前のすべての学生をチェックするため、最終的に最小の割り当てが見つかります。 残念ながら、それぞれの`n`トピックは最大でスキャンできます`n`学生、制作`O(n²)`仕事。 

重要な観察は、トピックの値を並べ替えると、すべての競合がローカルになるということです。 トピックは、一定の長さの範囲内にある値とのみ競合します。`k`。 生徒を個別に考える代わりに、別の質問をすることができます。 

最大値から最小値を引いた値が最大である値のすべての間隔を調べるとします。`k`。 このような間隔内のすべてのペアは互いに競合するため、どのペアも同じ学生に属さない可能性があります。 間隔に次のものが含まれる場合、`m`少なくとも要素`m`学生は必要だ。 

驚くべきことに、この下限でも十分であるということです。 

ソート後の競合グラフは間隔グラフになります。 区間グラフは完全なグラフであり、彩色数が最大クリークのサイズに等しいことを意味します。 ここで、クリークとは、正確には、ある長さの間隔に含まれる値のセットです。`k`。 したがって、生徒の最小数は、次の条件を満たすウィンドウに含まれる並べ替えられた要素の最大数と等しくなります。`a[r] - a[l] <= k`。 

この最大ウィンドウ サイズを見つけるのは、まさに古典的な 2 ポインター手法です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(1) 追加 (並べ替えを除く) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力を読み取り、すべてのトピック値を並べ替えます。 
2. 2 つのインデックスを維持します。`l`そして`r`、ソートされた配列内の現在のウィンドウを記述します。 
3. 拡張する`r`左から右へ。 新しい値を挿入した後、ウィンドウがまだ条件を満たしているかどうかを確認します。`a[r] - a[l] <= k`。 
4. 差を超えている間`k`、 動く`l`条件が再び真になるまで前進します。 

毎回`l`移動するとウィンドウが狭くなり、最終的には状態が回復します。 
5. 現在のウィンドウには、次で終わる最大のサフィックスが含まれています。`r`その値はすべて長さの範囲内にあります`k`。 
6. 現在のウィンドウの長さで答えを更新します。`r - l + 1`。 
7. すべての位置を処理した後、最大ウィンドウ サイズを出力します。 

### なぜ効果があるのか

 ウィンドウには常に、値が 1 つの長さの間隔内に収まる要素が正確に含まれます。`k`。 そのウィンドウ内のすべてのペアの違いは最大でも`k`、したがって、それらはすべて互いに衝突します。 ウィンドウの長さを必要な下限として、異なる生徒を占有する必要があります。 

逆に、直線上の間隔によって形成される競合グラフは間隔グラフです。 区間グラフはいつでも、最大クリークの正確なサイズを使用して色付けできます。 すべてのクリークが 1 つのウィンドウに対応するため、最大のウィンドウ サイズでも十分です。 アルゴリズムはこの量を正確に計算するため、答えは最適になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()

    ans = 0
    l = 0

    for r in range(n):
        while a[r] - a[l] > k:
            l += 1
        ans = max(ans, r - l + 1)

    print(ans)

if __name__ == "__main__":
    solve()
```並べ替えると、値の違いが連続したセグメントに変換され、スライディング ウィンドウが正しく機能できるようになります。 

左ポインタは前方にのみ移動し、後方には移動しません。 このプロパティにより、並べ替え後の線形作業が保証されます。 すべての要素は一度ウィンドウに入り、一度ウィンドウから出ます。 

内部の比較`while`ループは次のようにする必要があります`> k`。 正確に違いがあるWindows`k`これらの値は類似しており、同じクリークに属していると見なされるため、依然として有効です。 

不変式を復元した後に答えが更新されます`a[r] - a[l] <= k`。 それより早く更新すると、無効なウィンドウがカウントされます。

## テストケース```python
import sys, io

def solve():
    input = sys.stdin.readline
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()

    l = 0
    ans = 0
    for r in range(n):
        while a[r] - a[l] > k:
            l += 1
        ans = max(ans, r - l + 1)
    print(ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    solve()
    sys.stdin = backup_stdin
    sys.stdout = backup_stdout
    return out.getvalue()

# provided samples

 ## 特殊なケース

入力：```

```ソート後、次の結果が得られます`[1, 1, 3]`。 最大有効ウィンドウは次のとおりです。`[1, 1]`、そのサイズは`2`。 アルゴリズムの出力`2`、必要な生徒数に一致します。 

すべての値が大きく離れている場合、すべての差が超過するため、すべてのウィンドウがすぐに縮小して、処理されたすべての要素が含まれます。`k`。 

入力：```
4 5
1 10 20 30
```すべての有効なウィンドウにはサイズがあります`1`、したがって、答えは次のようになります`1`。 似たトピックがないため、1 人の生徒がすべてのスパイス単元を受講できます。 

同じ値が近くの値と一緒に多数出現する場合、スライディング ウィンドウは個別の値ではなく要素に対して作用するため、自然に重複がカウントされます。

```配列全体が 1 つのウィンドウ内に収まります。`7 - 5 = 2`。 窓のサイズは、`5`, したがって、5 人の生徒が必要です。 すべてのコピー`5`他のすべてのコピーと競合し、両方とも競合します`6`そして`7`また、それらと競合するため、より小さな割り当ては不可能になります。
