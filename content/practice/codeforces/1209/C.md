 ## 解決策
 ## 問題の理解

 一連の数字が与えられ、各位置に 2 つのラベル (1 または 2) のいずれかを割り当てる必要があります。ラベルを付けた後、1 というラベルが付いたすべての数字を元の順序で取得し、次に 2 というラベルが付いたすべての数字を元の順序で取得することにより、新しいシーケンスを形成します。 要件は、この連結シーケンスが非減少である必要があることです。 

したがって、このタスクは数字を任意に並べ替えることではなく、インデックスを 2 つのサブシーケンスに分割し、その内部順序が保持され、その連結ではソート順序が尊重されることになります。 

重要な隠れた制約は、2 番目のグループの数字が最後の連結に現れるたびに、グループ 1 の前に配置されたすべての数字に対する並べ替え順序を破ってはならないということです。これにより、2 つのグループ内の独立した制約ではなく、2 つのグループ間にグローバルな順序制約が作成されます。 

入力サイズでは、すべてのテスト ケースで合計最大 2e5 桁が許可されます。 すべての代入を試行する解決策では、2^n 個の可能性をチェックする必要がありますが、これは不可能です。 割り当てごとの二次検査でも大きすぎます。 ソリューションはテスト ケースごとに線形である必要があります。 

桁が小さいにもかかわらずインターリーブを強制する方法で分散されている場合、微妙な障害が発生します。 

たとえば、2 0 1 のようなシーケンスを考えてみましょう。「小さい数字を最初に配置する」という貪欲なアプローチを不注意に試みると、最初のグループに 0 と 1 を割り当て、2 番目のグループに 2 を割り当てる可能性がありますが、連結は 0 1 2 になりますが、これは問題ありません。 ただし、決定を局所的に反転すると、3 1 2 0 4 のようなより複雑なミックスの単調性が簡単に崩れる可能性があります。 

もう 1 つの特殊なケースは、すべての数字が同一である場合です。 どのパーティションでも機能しますが、不必要な制約を強制する貪欲なメソッドは誤って失敗する可能性があります。 

本当の課題は、色 1 と色 2 の間の境界が全体的に一貫していることを確認しながら、各桁を割り当てる方法を決定することです。 

## アプローチ

 ブルートフォースのアイデアでは、各位置に色 1 または 2 を割り当て、両方のサブシーケンスを構築し、連結がソートされていることを確認することで妥当性をチェックします。 これは 2^n の可能性を調査し、各チェックのコストは O(n) となり、O(n・2^n) になりますが、これは n = 20 の場合でも実行不可能です。 

この構造は、代わりに貪欲な構造を示唆しています。 重要な観察は、最後の連結が非減少でなければならないということです。これは、2 番目のグループに安全に入れることができるものを分けるしきい値の桁値が存在することを意味します。 

しきい値の桁 x を固定する場合、最終的な連結では x より小さい桁が x より大きい桁の前に出現する必要があります。 これは、ソートされた配置において、一方の色が「接頭語グループ」のように動作し、もう一方の色が「接尾語グループ」のように動作することを示唆しています。 

標準的な構成では、0 から 9 までのすべての可能なしきい値の数字を試します。固定しきい値 x の場合、各数字を 2 つのグループのいずれかに割り当てますが、x に等しい数字が実現可能性に応じてどちらかのグループに入るようにします。 グループ 1 には x 以下の数字が含まれるようにし (慎重に処理してください)、グループ 2 には x 以上の数字が含まれるようにして、連結順序の制約が確実に満たされるようにします。 

各候補 x に対して、以下を維持しながら貪欲に色を割り当てます。 

グループ 1 とそれに続くグループ 2 によって形成されるシーケンスは、左から右に処理される場合、非減少順序に違反することはありません。 

この正しさは、有効な解法では、グループ 1 に最大桁が存在し、すべての小さい桁はその前に安全に配置でき、大きい桁はその後に配置する必要があるという事実から得られます。

 ## アルゴリズムのチュートリアル

 ピボットの数字を推測することで有効なカラーリングを構築しようとします。

1. 0 から 9 までの可能なピボット値 x を繰り返します。考え方は、x がグループ 1 とグループ 2 の間の分割が可能になる境界桁を表すということです。 
2. 固定 x の場合、2 つのグループを維持し、左から右への数字の割り当てをシミュレートします。 また、暗黙的に構築している連結構造の最後の桁も追跡するため、単調性を確保できます。 
3. 数字 d を処理するときに、それをグループ 1 に入れることができるかどうかを決定します。グループ 1 に入れることがグループ 1 内の非減少特性に違反する場合、その配置を拒否します。 
4. それ以外の場合、d が x より小さい場合は、グループ 1 が優先されます。d が x より大きい場合は、グループ 2 が優先されます。d が x に等しい場合は、両方の可能性を一貫した方法で試し、少なくとも 1 つの有効な配置が存在することを確認します。 
5. 選択した x にすべての桁を正常に割り当てると、対応する色が出力されます。 
6. 0 ～ 9 の x が機能しない場合は、有効なパーティションが存在しないと結論付けられます。 

重要な考え方は、恣意的に分割するのではなく、制御されたピボットを通じてグローバルな順序制約を強制するということです。 

### なぜ効果があるのか

 有効な色付けは自然な境界数字を誘発します。グループ 1 に現れる最大の数字を取得します。グループ 2 のすべての数字は少なくともこの値でなければなりません。そうでない場合は、連結によって単調性が崩れます。 これは、解を常に 0..9 のピボット x に合わせることができることを意味します。 そのピボットについては、ローカルな決定が x によってすでに取得されているグローバルな実現可能性条件と矛盾する必要がないため、貪欲な割り当てによって有効なパーティションを再構築できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def check(s, pivot):
    n = len(s)
    ans = [''] * n
    last1 = -1
    last2 = -1

    # we treat group 1 as "allowed up to pivot", group 2 as "from pivot upward"
    # but we enforce monotonicity in both groups independently
    for i, ch in enumerate(s):
        d = ord(ch) - ord('0')

        # try to put into group 1 if possible
        if d <= pivot and d >= last1:
            ans[i] = '1'
            last1 = d
        else:
            ans[i] = '2'
            if d >= last2:
                last2 = d
            else:
                return None

    return ''.join(ans)

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        s = input().strip()

        if all(c == s[0] for c in s):
            out.append('1' * n)
            continue

        ok = None
        for pivot in range(10):
            res = check(s, pivot)
            if res is not None:
                ok = res
                break

        out.append(ok if ok is not None else '-')

    print('\n'.join(out))

if __name__ == "__main__":
    solve()
```実装では、0 から 9 までの各ピボット数字が試行されます。ピボットごとに、単調制約下で可能であれば各数字をグループ 1 に貪欲に割り当てます。そうでない場合はグループ 2 に送信します。2 つの別個のトラッカーにより、両方のグループが内部的に非減少のままであることが保証されます。 割り当てによってグループ 2 の単調性が崩れる場合、そのピボットは無効になります。 

共通の微妙な点は、グループ 1 とグループ 2 の両方が独立して順序を維持する必要があることです。 両方の最後の値を追跡できないと、無効なパーティションが誤って受け入れられることになります。

 ## 特殊なケース

 連結は自明にソートされたままであるため、1 桁の入力は常にどちらかの色を受け入れます。 アルゴリズムはそれを任意のピボットの下のグループ 1 に割り当て、有効なカラーリングをすぐに返します。 

すべての数字が同一の場合、すべてのピボットが機能します。 アルゴリズムは最初のピボットを選択し、すべてをグループ 1 に割り当て、競合することなく両方のグループの単調性制約を維持します。 

9 8 7 のような厳密に減少するシーケンスの場合、最初の大きな数字をグループ 1 に配置しようとするピボットは、last1 制約に違反するためすぐに失敗し、グループ 2 も順序を回復できません。 すべてのピボットを使い果たした後、アルゴリズムは正しく不可能を返します。
