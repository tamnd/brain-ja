 ## 解決策
 ## 問題の理解

 与えられた整数シーケンスを「適切な」シーケンスに変換するように求められます。 同じ数字がすべて連続したブロックに出現する場合、シーケンスは適切です。 例えば、`[3, 3, 1, 1, 2]`いいですが、`[3, 1, 3]`という理由ではありません`3`は次のように分割されます`1`。 目標は、このプロパティを達成するために変更する必要がある要素の最小数を計算することです。追加のルールとして、値の要素を変更する場合は、`x`の中へ`y`、すべての要素を次のように変更する必要があります。`x`に`y`。 私たちは与えられています`n`この簡単なバージョンでは、整数とゼロの更新が行われます。 出力は、変更の最小数を表す単一の整数です。 

制約は重要です。`n`最大200,000まで可能です。 考えられるすべてのシーケンス変換を試みる単純な解決策では、指数関数的な数のシーケンスを調べる必要があるため、時間がかかりすぎます。 線形時間または線形算術時間に近いものが必要です。 単純な実装をトリップさせる可能性のあるエッジケースには、値が繰り返し切り替わるシーケンスが含まれます。`[1, 2, 1, 2, 1]`、またはすべての値がすでに同じであるシーケンス。 もう 1 つの微妙な点は、数値の 1 つの出現を変更すると、他のすべての出現も強制的に変更されるため、各位置を独立して扱うことができないことです。 

## アプローチ

 ブルートフォースアプローチでは、ブロックへのあらゆる可能な数値の割り当てを検討し、それぞれに必要な変更の数を数えます。 これは、数値ごとにどのブロックを占有するかを決定できるため、概念的には機能しますが、実際には、数値ごとにすべての位置をスキャンするため、O(n^2) かそれよりも悪くなります。 のために`n = 2e5`、これは不可能です。 

重要な洞察は、個々の位置ではなく、数値の_ブロック_のみを追跡する必要があるということです。 シーケンスを連続した実行、つまりブロックに圧縮しましょう。 例えば、`[3, 3, 1, 3, 2, 1, 2]`になる`[3, 1, 3, 2, 1, 2]`ブロックという意味では。 次に、一意の数値ごとに、それが形成する個別のブロックの数を数えることができます。 すべてのブロックを 1 つの連続したブロックにマージするには、中間ブロック内のすべての要素を変更する必要があるため、その数の最小変更数は、ブロックの合計数から 1 を引いた値になります。 全体的な難易度は、変更する必要がある要素の最小数です。これは、ブロックの総数から保存できる同じ値のブロックの最大数を引いたものに等しくなります。 これにより、問題は値ごとにブロックをカウントすることになり、単一のパスで実行できます。

 ## アルゴリズムのチュートリアル

 1. 入力シーケンスを連続したブロックに圧縮します。 前の要素を追跡しながら、配列を反復処理します。 現在の要素が前の要素と異なる場合は常に、新しいブロックが開始されます。 これにより、ブロックのリストが出現順に表示されます。 
2. 一意の値ごとにブロックの頻度をカウントします。 各数値をその数値が占有するブロックの数にマッピングする辞書を初期化します。 ブロック シーケンスをスキャンし、ブロックごとにカウンターをインクリメントします。 
3. 最大ブロック数の番号を特定します。 させて`max_blocks`最大のブロック数になります。 この番号は、変更が最小限で済むため、ほとんど変更しないままにしておきます。 他のすべての数値のブロックはこの構造にマージする必要があり、これには中間要素の変更が必要になります。 
4. ブロックの総数から難易度を計算します。`max_blocks`。 支配的な数の一部ではない各ブロックは、少なくとも 1 つの必要な変更に貢献します。 
5. 計算された難易度を出力します。 

機能する理由: ブロックに圧縮し、値ごとにカウントすることで、シーケンス内のすべての不連続性を捕捉します。 変更の最小数は、削除またはマージする必要があるブロックの数によって決まります。 ブロックの最大数を含む番号を選択すると、変更するブロックが少なくなれば要素の変更も少なくなるため、変更を最小限に抑えることができます。 この貪欲な戦略は、選択した番号に属さないすべてのブロックが強制的に変更され、変更が少ないほど優れたシーケンスはないため、最適です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, q = map(int, input().split())
a = list(map(int, input().split()))

# Step 1: compress into blocks
blocks = []
prev = None
for x in a:
    if x != prev:
        blocks.append(x)
        prev = x

# Step 2: count blocks per value
from collections import defaultdict
block_count = defaultdict(int)
for b in blocks:
    block_count[b] += 1

# Step 3: find max block count
max_blocks = max(block_count.values())

# Step 4: compute difficulty
difficulty = len(blocks) - max_blocks
print(difficulty)
```このソリューションでは、最初にシーケンスを圧縮して実際のブロック構造を特定します。 辞書を使用して、各数値が占めるブロックの数を数えます。 最も多くのブロックを占める番号ほど、必要な変更は最も少なくなります。 最後の難易度は、ブロックの総数からこの最大値を引いたものになります。 

微妙な実装ポイントには、連続する要素が異なる場合に新しいブロックを正しく識別すること、前の要素を正しく更新すること、ブロック数を効率的に追跡するための辞書の使用などが含まれます。 ブロックに圧縮することを忘れると、カウントが過剰になり、間違った答えが得られる可能性があります。

import sys, io
def run(inp: str) -> str:

    blocks = []

    for x in a:
        if x != prev:
            blocks.append(x)
            prev = x

    block_count = defaultdict(int)

        block_count[b] += 1
    difficulty = len(blocks) - max(block_count.values())
