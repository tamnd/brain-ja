 ## 解決策
 ## 問題の理解

 「カード」のセットから始めます。各カードは整数のペアです$(a, b)$と$a < b$。 イニシャルカード1枚から$(x, y)$、このペアに対する操作のように動作する 3 つの変換ルールを繰り返し適用できます。 

1 回の操作で両方の数値が 1 増えるため、差が維持されます。$b - a$。 別の演算は、両方の数値が偶数である場合にのみ適用され、実質的にそれらを半分にして、ペアのスケールを縮小します。 3 番目の操作では 2 枚のカードの情報をマージし、次のことを可能にします。$(a, b)$そして$(b, c)$の中へ$(a, c)$これは本質的に、到達可能なエンドポイントにわたる推移性です。 

目標は、開始カードを 1 枚だけ選択することです$(x, y)$と$1 \le x < y \le m$そして、そこからこれらの変換を使用して、必要なすべてのカードを生成します$(1, a_i)$。 必要なカードがすべて入手できる限り、追加のカードを作成することができます。 

したがって、本当の質問は、開始間隔はどれくらいかということです。$(x, y)$最終的には必要なすべてのエンドポイントを「接続」できるでしょうか$a_i$許可された変換を使用して 1 に戻ります。 

制約は非常に重要です。 まであります$10^5$必要な値と$m$まで$10^9$。 変換をシミュレートしたり、状態を探索しようとするソリューション$[1, m]$すぐには実行不可能です。 考えられるすべての開始ペアにわたる均等な線形スキャン$(x, y)$だろう$O(m^2)$、それは不可能です。 

重要な点は、演算で任意の数値が決して導入されないことです。 これらは構造を保持します。+1 ずつシフトすると差分が保持され、半分にするとスケールが縮小しますが 2 のべき乗の比率は保持され、マージは接続のように動作します。 これは、グラフ検索ではなく数理論的構造を強く示唆しています。 

単純な間違いは、値が一度取得されると仮定することです。$a_i$ある間隔から到達可能である場合、それを含むすべての間隔が有効です。 これは失敗します。半分にする操作では両方のエンドポイントが同時に均等である必要があるため、パリティ制約はローカルではなくグローバルに伝播します。 

必要な値間の順序を無視すると、別の失敗ケースが発生します。 たとえば、次の場合$a_i$そして$a_j$パリティのアライメントはシフトだけでは修復できないため、それらにまたがるすべての間隔が有効であるとは限りません。 

## アプローチ

 強引に試す場合は、可能な限りすべてを選択します$(x, y)$そして 3 つの操作で閉鎖をシミュレートします。 各シミュレーションを最適化したとしても、到達可能なカードの状態空間は急速に増大し、$O(m^2)$可能なスタート。 これは直ちに実行不可能であるため、$m$までです$10^9$。 

重要な観察は、操作が整数区間でクロージャ システムを定義しており、真に重要な唯一の不変式は、繰り返される 2 による除算と区間カバレッジの下での構造であるということです。 

それぞれの値$a_i$は、一連の半分とシフトの操作を通じて 1 に接続する必要があると考えることができます。 +1 シフトしても実現可能性は変わりません。 絶対位置を変更するだけです。 本当の制約は、すべてが$a_i$互換性のある「2 のべき乗バックボーン」を共有します。 

すべてを繰り返し分割すると$a_i$少なくとも 1 つが奇数になるまで 2 ずつ増やすと、本質的に奇数のコア構造が抽出されます。 システムは、これらの正規化された値にわたる間隔を追跡することに集約され、問題は間隔の数をカウントすることになります。$(x, y)$この構造の下で必要な正規化されたエンドポイントをすべてカバーすることと一致しています。 

最終的な縮小点は、有効な開始間隔が次の選択肢に対応するということです。$x$そして$y$そのため、許可された削減を繰り返し適用した後、その間隔は各パリティ層の最小制約と最大制約を「カバー」できます。 これは、配列の変換されたバージョンに対する派生制約セットを満たす間隔をカウントすることに集約されます。 

その時点で、すべてをチェックするのではなく、$(x, y)$の有効な領域を特定します。$x$そして$y$ライン上の間隔の和集合として、並べ替えとプレフィックス/サフィックス制約を使用してカウントできます。

 ## アルゴリズムのチュートリアル

 1. 必要な各値を、2 で割り切れる回数を追跡しながら奇数成分を抽出して正規化します。 

これにより、偶数二分化演算では変更できない不変部分が分離されます。 
2. 必要なすべての値を奇数コアごとにグループ化します。 マージ操作ではパリティ制約に違反せずに異なる奇数コアをブリッジできないため、各グループは独立して処理する必要があります。 

変換ではパリティ クラスが恣意的に混合されることはないため、この分離は非常に重要です。 
3. 各グループについて、元の値空間内の最小位置と最大位置を計算します。 これらの境界は、有効な開始セグメントがカバーする必要がある最小間隔を定義します。 
4. 問題をカウント間隔に変換する$(x, y)$正規化を繰り返した後、間隔を拡張してすべてのグループの必要な範囲をカバーできるようにします。 

シフト操作により、各グループ内では相対的な距離のみが重要になることが保証されます。 
5. 考えられる適切なエンドポイントごとに$y$、最小の有効な左端点を決定します。$x$これにより、すべての制約を満たすことができます。 これにより、全体にわたって単調な構造が生成されます。$y$。 
6. 有効なすべての合計$y$の選択肢がいくつあるか数えます$x$それぞれに存在します。 これにより、問題はプレフィックスベースの実行可能な間隔のカウントに変換されます。 

### なぜ効果があるのか

 この操作では隠れた不変条件が保持されます。つまり、到達可能なすべてのカードは、奇数の正規化が行われるまで繰り返し半分化されてもエンドポイントの一貫性が保たれるセグメントに対応します。 マージ操作により、各パリティ層で隣接する制約が満たされると、チェーン全体が確実に接続されます。 これは、実現可能性は必要な正規化範囲をすべて同時にカバーするかどうかにのみ依存し、これらの範囲制約を満たす間隔であれば、クロージャを通じて必要なすべてのカードが生成されることを意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    # normalize by extracting odd core and exponent of 2
    norm = []
    for x in a:
        t = x
        cnt = 0
        while t % 2 == 0:
            t //= 2
            cnt += 1
        norm.append((t, cnt))

    # group by odd core
    from collections import defaultdict
    groups = defaultdict(list)
    for val, c in norm:
        groups[val].append(c)

    # each group defines constraints on exponent structure
    constraints = []
    for k, arr in groups.items():
        arr.sort()
        constraints.append((arr[0], arr[-1]))

    constraints.sort()

    # merge overlapping constraints
    merged = []
    for l, r in constraints:
        if not merged or merged[-1][1] < l:
            merged.append([l, r])
        else:
            merged[-1][1] = max(merged[-1][1], r)

    # now count valid intervals in exponent space
    ans = 0

    # treat merged segments as forbidden gaps structure
    prev_r = -1
    total_segments = len(merged)

    for i in range(total_segments):
        l, r = merged[i]
        left_bound = prev_r + 1
        right_bound = l

        if right_bound >= left_bound:
            length = right_bound - left_bound
            ans += length * (length + 1) // 2

        prev_r = r

    # tail segment
    if prev_r < m:
        length = m - prev_r
        ans += length * (length + 1) // 2

    print(ans)

if __name__ == "__main__":
    solve()
```コードは、それぞれを分解することから始まります。$a_i$奇数成分と 2 のべき乗指数に変換します。 半分にする操作は大きさの構造を変更する唯一の操作であるため、これは不可欠です。 それ以外はすべてパリティ構造を維持します。 

次に、奇数成分ごとに値をグループ化します。 これは、異なる奇数コアを持つ数値は、半減と共有構造へのシフトを繰り返しても調整できないという事実と一致します。 

各グループについて、最小および最大の指数を計算します。 これらは、指数空間内の制約区間を定義します。 重複する間隔は、同時に満たされる必要がある制約を表すため、マージされます。 

互いに素な制約区間を取得したら、残りの問題は有効な選択肢を数えることになります。$(x, y)$これらの禁止された指数領域に違反しないもの。 これは、マージされた制約ブロック間の許容ギャップ内のすべてのサブセグメントをカウントすることになります。

 ## 特殊なケース

 重要なエッジ ケースは、すべての数値が同じ奇数コアを共有しているものの、2 の累乗が増加している場合です。 この場合、制約区間は連続となり、2 つの大きな非制約領域のみが残ります。 このアルゴリズムは、すべてを単一のブロックされたセグメントに正しくマージし、境界間隔のみを生成します。 

別の特殊なケースが発生するのは、$a_i$は同一です。 次に、制約区間は指数空間内の 1 つの点に折りたたまれます。 マージステップにより、ブロックが完全なブロックとして扱われるようになり、無効な内部間隔が 2 回カウントされたり、断片化されたりすることがなくなります。 

3 番目のエッジケースは次のような場合です。$n = 1$。 ここでの唯一の制約は単一の指数値であり、その答えは、その単一の禁止レベルを回避するすべての間隔をカウントすることになります。これはギャップ カウント ロジックに直接一致します。
