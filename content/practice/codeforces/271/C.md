 ## 解決策
 ## 問題の理解

 We are asked to distribute _n_ sequentially numbered words among _k_ Keepers such that each Keeper receives a non-empty subset of words, the subsets are pairwise disjoint, their union covers all words, and no subset forms an arithmetic progression. 出力では、単語ごとにどの Keeper がその単語を保持しているかを示す必要があります。`-1`それが不可能な場合。 

入力は、単語の総数とキーパーの数を表す 2 つの整数 _n_ と _k_ です。 出力は、割り当てを説明する 1 から _k_ までの _n_ 個の整数のシーケンスです。または`-1`有効な割り当てが存在しない場合。 

制約は大きいです: _n_ は最大です$10^6$したがって、すべてのサブセットを明示的に検査したり、すべての順列をチェックしようとするソリューションは遅すぎます。 解は線形であるか、最大でも O(n log n) である必要があります。 

_n_ が 3 未満、または _k_ に等しい場合、明らかではないエッジ ケースが発生します。 1 人のキーパーが 3 語未満の単語を取得することはできません。その場合、サブセットは自明に等差数列を形成することになります。 _k_ が _n_ に等しい場合、各キーパーは 1 つの単語を取得することになり、「少なくとも 3 つの要素」という条件に違反します。 例えば、`n = 3, k = 3`不可能なので、出力は次のようにする必要があります`-1`。 Keeper を単純に循環する不注意なアプローチでは、等差数列制約を満たさない代入が誤って返されてしまいます。 

## アプローチ

 ブルート フォース ソリューションでは、_k_ 個のキーパー間で _n_ 語の考えられるすべてのパーティションを生成し、それぞれの等差数列条件をチェックしようとします。 このアプローチは組み合わせ的なものであり、大まかに次のことが必要になります。$k^n$_n_ までの操作は実行不可能です$10^6$。 サブセットが等差数列を形成しているかどうかを確認するのは簡単ですが、すべてのパーティションを生成すると複雑さが大きくなります。 このアプローチは小さな例では機能しますが、中程度のサイズではすぐに失敗します。 

重要な観察は、キーパーのサブセット内のすべての要素に一定の差がある場合にのみ等差数列条件に違反するということです。 したがって、固定ステップで単調になるサブセットがないようにすることで、これを回避できます。 最も簡単な方法は、周期的かつ交互に単語をキーパーに割り当て、各キーパーが等間隔ではない単語を確実に受け取るようにすることです。 2 つ以上のグループでキーパーを繰り返し循環して単語を割り当てると、キーパーに割り当てられたサブセットには異なる長さのギャップが生じ、等差数列パターンが崩れます。 

これにより、単純な線形解が得られます。 _k = 1_ の場合、1 人のキーパーがすべての単語を持っていることになり、これは等差数列であるため不可能です。 _k = 2_ の場合、2 より大きいワード セットは両方のサブセットの非算術進行条件を満たすことができないため、小さなエッジ ケースを慎重に処理する必要があります。 _k ≥ 3_ の場合、次のような繰り返し割り当てパターン`[1, 2, 3, 1, 2, 3, ...]`サイズ 3 以上のサブセットが等差数列を形成しないようにします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k^n) | O(n) | 遅すぎる |
 | 循環代入 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. _k_ が 1 であるかどうかを確認します。1 である場合は、出力します`-1`なぜなら、1 人のキーパーがすべての単語を取得し、等差数列を形成するからです。 
2. _n_ が 3 未満であるか、または _k_ が _n_ 以上であるかどうかを確認します。 これらの条件のいずれかが当てはまれば、出力します。`-1`。 些細な等差数列を避けるには少なくとも 3 つの単語が必要であり、キーパーを空のままにすることはできません。 
3. 長さ _n_ の配列を初期化して、各ワードのキーパー割り当てを保存します。 
4. 単語を順番に繰り返します。 繰り返しのパターンでキーパーに割り当てます。`[1, 2, ..., k]`。 _k_ に到達したら折り返します。 これにより、各キーパーに割り当てられる一連の単語が等間隔ではなくなり、等差数列にならないことが保証されます。 
5. 代入配列を整数のシーケンスとして出力します。 少なくとも 3 人のキーパーの有効な繰り返しパターンが機能します。 

機能する理由: 少なくとも 3 人のキーパー間で割り当てを循環させることで、単一のキーパーが一定の間隔で単語を受け取ることはなくなります。 各単語が 1 回だけ割り当てられ、すべての単語が割り当てられるため、ペアごとの素と結合のプロパティが保証されます。 各キーパーに割り当てられたインデックスが不規則に異なり、固定差分条件を破るため、非等差数列が満たされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

if k == 1 or n < 3 or k > n:
    print(-1)
else:
    assignment = []
    for i in range(n):
        # Cycle through 1..k
        assignment.append((i % k) + 1)
    print(' '.join(map(str, assignment)))
```このソリューションでは、まず、不可能なシナリオを明示的に処理します。 モジュロ演算により、キーパーによる繰り返しサイクルが保証されます。 使用する`(i % k) + 1`すべてのキーパーがバランスの取れた方法で単語を取得し、等差数列を壊すことを保証します。 スペースで結合すると、必要な出力形式が生成されます。
