 ## 解決策
 ## 問題の理解

 私たちは樽のコレクションを渡され、それぞれにある程度の水が入っており、そのうちの 1 つに微量の毒が入っています。 この毒により、樽の重量は目に見えないほど 0.179 キログラム増加します。 毒の入った樽には触ることはできませんが、毒のある樽に触らない限り、樽の間に水を安全に注ぐことはできます。 私たちが得る唯一の情報は、2 つのバレルについて、その重量が等しいか、どちらが重いかを示す比較スケールから得られます。 

タスクは、毒樽に触れることなく確実に毒樽を識別できるかどうかを判断し、一連のクエリを通じて樽が追加または削除された場合でもこの保証を維持できるかどうかを判断することです。 

問題のサイズは大きく、最大 200,000 バレルおよび 200,000 クエリです。 これにより、クエリごとに O(n^2) 時間がかかるため、バレルのすべてのペアを明示的に比較したり、考えられるあらゆるシーケンスの注ぎをシミュレートしたりする必要があるソリューションは除外されます。 各バレルの重量は 100 万で制限されていますが、実際の制約はバレルの数です。 クエリをオンラインで処理する必要があるため、毒バレルの効率的な挿入、削除、識別を可能にする動的な戦略が必要です。 

明らかではないエッジケースは、すべての樽に同じ量の水が入っている場合です。 この場合、毒のある樽がわずかな差で最も重いことになりますが、毒のない樽から注ぐと毒が明らかにならずに他の樽の重量が均等になるだけなので、安全に区別することは不可能です。 別の微妙なケースは、正確に 2 つの異なるウェイトがあり、より重いウェイトが複数のバレルで保持されている場合に発生します。 そのような状況では、毒樽はそのどれかである可能性があり、どれにも触れて安全に特定することはできません。 

## アプローチ

 ブルートフォースソリューションでは、すべての注入とスケール比較をシミュレートします。 2 つの樽を選んで比較し、軽い方から重い方へ注ぎ、候補が 1 つだけになるまで注ぎ続けることを想像することもできます。 概念的には正しいですが、これにはすべてのペアごとの比較と注ぎを注意深く追跡する必要があり、最悪の場合でも O(n^2) となり、2×10^5 バレルを効率的に処理できません。 

重要な観察点は、実際の注入をシミュレートする必要がまったくないということです。 安全に注ぐことができるということは、毒樽に触れない限り、複数の樽を同じ重量にすることができるということです。 有毒でない樽をすべて同じ重量まで減らすことができた場合、残りの重量が異なる樽は有毒な樽になるはずです。 したがって、最適なアプローチは、複数セットのバレル水量を追跡することになります。 固有の最も重い樽があれば、毒のある樽を安全に識別できます。 最大値が複数回発生する場合、リスクを伴わずに識別を保証することは不可能です。 

この観察により、クエリを効率的に処理できるようになります。 バレルを追加すると、その水量の頻度が更新されます。 バレルを取り外すと周波数が減少します。 各ステップで、現在の最大値が 1 回発生するかどうかを確認するだけで済みます。 これにより、バランスの取れたマップでカウントを維持する場合、問題はクエリあたり O(log n) に削減され、水量の指定された境界の度数配列を使用してクエリあたり O(1) に削減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | カウントを使用した O(n + q) | O(10^6) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 現在のすべての水量の頻度表を作成します。 これにより、バレルを追加または削除するときに定時更新が可能になります。 すべての水の量には制限があるため、長さ 10^6 + 1 の固定サイズの配列を使用すれば十分です。 
2. 現在の最大水量と表内のその数を決定します。 最大値が 1 の場合、毒樽が最も重いため、答えは「はい」になります。 最大値が複数回発生する場合、答えは「いいえ」です。 
3. 各クエリを処理します。 バレルを追加した場合は、その水量に応じて周波数を増加させます。 バレルが取り外された場合は、周波数を下げます。 最大値とその数を動的に更新します。 各クエリの後に、最大値が 1 回発生するかどうかを確認し、「はい」または「いいえ」を出力します。 
4. 最大値を更新するときは、注意してください。取り外されたバレルが現在の最大値で、そのカウントがゼロになった場合は、次に大きい水の量を下方向にスキャンします。 バレルを追加するときに、その重量が現在の最大値を超える場合は、最大値を更新します。 

機能する理由: このアルゴリズムは、すべての非毒性バレルを安全に同等にできることを保証します。 毒樽を識別するには、常に重量が区別できる必要があります。 したがって、最大値とその多重度を追跡するだけで、実際の注入をシミュレーションしなくても問題に正しく答えることができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from collections import defaultdict

n, q = map(int, input().split())
a = list(map(int, input().split()))

freq = defaultdict(int)
for x in a:
    freq[x] += 1

max_weight = max(freq.keys())
def output():
    print("Yes" if freq[max_weight] == 1 else "No")

output()

for _ in range(q):
    line = input()
    op, val = line.split()
    val = int(val)
    if op == '+':
        freq[val] += 1
        if val > max_weight:
            max_weight = val
    else:
        freq[val] -= 1
        if freq[val] == 0:
            del freq[val]
            if val == max_weight:
                if freq:
                    max_weight = max(freq.keys())
                else:
                    max_weight = 0
        elif val == max_weight:
            pass
    output()
```この解決策は、すべてのバレル水量の頻度マップを構築することから始まります。 ヘルパー関数`output`現在の最大値が 1 回発生するかどうかを確認します。 各クエリは、周波数マップを増加または減少させます。 最大バレルが完全に削除された場合、アルゴリズムは次の最大バレルをスキャンします。 使用する`defaultdict`これにより、欠落しているキーを明示的にチェックする必要がなくなります。 

微妙な部分は正しく更新されています`max_weight`バレルを外すとき。 以前の最大値にバレルが残っていない場合にのみ、新しい最大値をスキャンする必要があります。 現在の最大値よりも重いバレルを追加する場合は、最大値を交換するだけです。
