 ## 解決策
 ## 問題の理解

 配列が与えられています`x`長さの`n`1 から 1 までの整数`n`、および隠し配列`y`同じ長さの。 各ペア`(x_i, y_i)`ユニークであり、`x_i ≠ y_i`。 課題は、隠れたオブジェクトがエッジのある有向グラフであるかどうかを識別することです。`x_i → y_i`(オブジェクト A) または座標を持つ平面上の点`(x_i, y_i)`(オブジェクト B)。 

次の形式のクエリは 2 つだけ許可されます`(i, j)`。 非表示オブジェクトがグラフの場合、クエリは頂点間の最短パス長を返します。`i`そして`j`(または、到達できない場合は 0)。 一連の点の場合、クエリは点間のマンハッタン距離を返します。`i`そして`j`。 最大 2 回のクエリの後、自信を持ってオブジェクト タイプを識別する必要があります。 

制約により許可されるのは、`n`まで`2·10^5`最大 1000 のテスト ケース。 O(n²) の演算は遅すぎるため、グラフ全体を再構築したり、すべての距離を計算しようとするアルゴリズムは除外されます。 テスト ケースごとに一定のクエリを使用するソリューションが必要です。 

特定の小さな例で距離またはパスが一致するようにポイントまたはエッジを配置できる場合にエッジ ケースが発生します。これは、構造を考慮せずに単に応答の大きさに注目する単純なアルゴリズムを誤解させる可能性があります。 

## アプローチ

 ブルート フォース ソリューションでは、多くのペアをクエリすることによって、グラフまたはポイント座標の再構築を試みます。`(i, j)`そしてその反応を分析します。 最悪の場合、これには O(n²) 個のクエリが含まれる可能性がありますが、2 クエリの制限を考えるとこれは不可能です。 

重要な洞察は、2 つのオブジェクト タイプが根本的に異なるメトリック プロパティを持っているということです。 オブジェクト A (グラフ) では、距離は離散的であり、次の範囲内にあります。`n-1`(パスに沿ったエッジの数)、到達不能なペアは 0 を返します。オブジェクト B (平面) では、マンハッタン距離は個別の点に対して常に正になります。`x_i ≠ y_i`みんなのために`i`、差の絶対値の合計が少なくとも 2 である場合、`n ≥ 3`そしてすべてのコーディネートはユニークです。 

これは、適切に選択された 1 つのクエリでも、多くの場合オブジェクトを識別できることを意味します。 堅牢性を高めるために、2 つの任意のインデックスを選択します`i ≠ j`。 応答が 0 の場合、点のマンハッタン距離がゼロになることはできない (すべての座標は別個である) ため、オブジェクトはグラフである必要があります。 それ以外の場合、応答は少なくとも 2 です。逆にクエリすると、`(j, i)`、マンハッタンの距離は対称ですが、有向グラフではマンハッタンからの最短経路が`i → j`そして`j → i`異なる場合があります。 応答の違いはすぐにオブジェクト A に通知されます。応答が等しく、ゼロでない場合は、オブジェクト B を扱っていることになります。 

このアプローチでは、複雑な再構築を必要とせずに、問題を固定数のクエリに軽減します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 | テスト ケースごとに O(1) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`n`そして配列`x`。 
2. 2 つのインデックスを選択します`i`そして`j`そのような`i ≠ j`。 通常`i = 1`そして`j = 2`動作します。 
3. クエリ`(i, j)`そして応答を保存します`d1`。 この値は、マンハッタン距離または最短経路長のいずれかです。 
4. クエリ`(j, i)`そして応答を保存します`d2`。 
5. 比較する`d1`そして`d2`。 それらが異なる場合、有向グラフ内の最短経路は一般に非対称であるため、オブジェクトは有向グラフ (オブジェクト A) です。 
6. もし`d1`等しい`d2`そして`d1 > 0`の場合、マンハッタン距離は対称で常に正であるため、オブジェクトは点のセット (オブジェクト B) です。 
7. 識別されたオブジェクトを出力します。 

これが機能する理由: 不変条件は、距離応答が有向パスの構造的非対称性をエンコードすることです。 グラフについては、`dist(i, j) ≠ dist(j, i)`サイクルまたは有向チェーンが存在する場合。 点の場合、マンハッタン距離対称性により平等性が保証されますが、座標が異なるためゼロは不可能です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        x = list(map(int, input().split()))
        
        # Pick two indices
        i, j = 1, 2
        
        print(f"? {i} {j}")
        sys.stdout.flush()
        d1 = int(input())
        
        print(f"? {j} {i}")
        sys.stdout.flush()
        d2 = int(input())
        
        if d1 != d2:
            print("! A")
        else:
            print("! B")
        sys.stdout.flush()

if __name__ == "__main__":
    main()
```このソリューションは、各テスト ケースの入力を読み取り、正確に 2 つのクエリを作成します。 非対称性のみが重要であるため、インデックス 1 と 2 を任意に選択します。 繊細さが保証します`flush()`インタラクティブな正確さを維持するために、各クエリの後に呼び出されます。

 ## 特殊なケース

 最初のクエリがグラフ内で誤ってゼロにヒットした場合 (つまり、頂点が切断された場合)、2 番目のクエリは`(j, i)`はゼロと異なることが保証されており、正しい非対称信号が得られます。 もし`n = 3`すべての座標がちょうど 1 だけ異なっていても、マンハッタン距離クエリは依然として正の値を返すため、アルゴリズムはオブジェクト B を正しく識別します。インデックス 1 と 2 の選択は安全であるため、`x_1 ≠ y_1`そして`x_2 ≠ y_2`制約によって。
