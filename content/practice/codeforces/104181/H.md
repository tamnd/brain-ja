 ## 解決策
 ## 問題の理解

 概念的には、非常に大きなグリッドが与えられています。$10^9 \times 10^9$、しかし、私たちはそれを明示的に扱うことはありません。 代わりに、私たちは次のように言われています$N$このグリッド上に描画される、重なり合わない軸に沿った長方形。 各長方形は、最初にペイントされる一連の単位セルに寄与します。 

塗装が終わったら、$M$特定の列インデックスが選択され、それらの列のいずれかにあるペイントされたすべてのセルが雨によって消去されます。 タスクは、この削除後にペイントされた単位セルがいくつ残るかを計算することです。 

重要な点は、グリッドが大きすぎて直接表現できないため、すべての推論を長方形と削除された列に対して行う必要があるということです。 

この制約により、セルレベルのシミュレーションは即座に除外されます。 単一の長方形でカバーできる範囲は次のとおりです。$10^{18}$細胞、そして$N, M$まで行く$2 \cdot 10^5$したがって、すべてのセルに触れたり、四角形をポイントに拡張したりするアルゴリズムは不可能です。 すべての四角形にわたる列ごとのスキャンでも、次のように劣化します。$O(NM)$、それは限界をはるかに超えています。 

長方形が狭い場合、または削除された列が多くの長方形と交差する場合、微妙なエッジ ケースが発生します。 たとえば、すべての四角形が幅 1 の垂直ストリップである場合、すべての削除クエリは各四角形の最大 1 列に影響し、各削除後の単純な四角形ごとの再計算は 2 次になります。 

もう 1 つの落とし穴は、長方形間の重なりが独立して無視できると仮定していることです。 これらは互いに素ですが、操作は列ベースであるため、異なる四角形は領域の重複ではなく、共有列インデックスを通じてのみ相互作用します。 つまり、正確性は、四角形ごとの独立した減算ではなく、四角形全体にわたる列ごとの集計に依存します。 

## アプローチ

 直接的なアプローチは、すべての四角形の合計面積を計算し、削除された列ごとに、その列内でペイントされたセルの数を減算することです。 長方形は重なり合わないので、合計面積を数えるのは簡単です。 難しいのは、列ごとに、その中にペイントされたセルの数を計算することです。 

列を修正すると$x$、すべての長方形をチェックし、それらにまたがる長方形の寄与を合計する必要があります。$x$。 各長方形はその高さに影響します$r_2 - r_1 + 1$列を覆う場合$x$。 削除された列ごとにこれを行うとコストがかかります$O(NM)$、到達できる$4 \cdot 10^{10}$操作。 

重要な構造的洞察は、各長方形が列の連続した間隔にわたって一定の値に寄与しているということです。 列にまたがる長方形の場合$[c_1, c_2]$、この範囲内のすべての列は、その高さに等しいまったく同じ垂直方向の寄与を獲得します。 したがって、列ごとに四角形ごとに考える代わりに、視点を逆転させます。つまり、X 軸上の間隔にわたって寄与を蓄積したいと考えています。 

これにより、問題は範囲加算を伴う列の 1D スイープに変わります。 各長方形を X 軸の間隔更新とその高さに等しい重みに変換します。 次に、クエリされた特定の列の値を評価し、それらの値を合計領域から減算するだけで済みます。 

座標までなので$10^9$では、関連するすべての x 値 (四角形の境界と削除された列) を圧縮します。 圧縮後、差分配列またはプレフィックス合計を使用して、各列位置でペイントされた合計高さを効率的に計算できます。

 | 座標圧縮＋掃引・差分配列 |$O((N+M)\log(N+M))$|$O(N+M)$| 承認済み |

 ## アルゴリズムのチュートリアル

 問題を、削除される各列に存在するペイントされたセルの数を計算し、それをペイントされた総面積から差し引くことに集約します。 

1. 各長方形の幅と高さを合計して、ペイントされた総面積を計算します。 長方形は重なっていないため、この合計は正確です。 
2. 長方形の境界と削除された列から関連するすべての x 座標を抽出します。 何かが変わるのはこれらのポジションだけです。 
3. これらの座標を並べ替えて、より小さいインデックス空間に圧縮します。 元の各列インデックスは圧縮インデックスにマップされます。 
4. 圧縮された X 軸上の差分配列を構築します。 それぞれの長方形について$[c_1, c_2]$高さのある$h = r_2 - r_1 + 1$、追加します$+h$の開始インデックスで$c_1$そして$-h$直後$c_2$。 これは、間隔内のすべての列が追加の垂直寄与を受け取ることをエンコードします。$h$。 
5. 差分配列をプレフィックス合計配列に変換します。 この時点で、圧縮された各座標には、その列を覆うすべての四角形によってペイントされた合計高さが含まれます。 
6. 削除された列ごとに、その列をその圧縮インデックスにマップし、対応する寄与分を回答から減算します。 
7. 最終値を出力します。 

範囲を直接マーキングする代わりに差分更新を使用する理由は、直接マーキングでは各四角形の間隔内のすべての圧縮位置を更新する必要があり、最悪の場合でもまだ時間がかかりすぎるためです。 差分配列により、各四角形が 2 つの更新に減らされます。 

### なぜ効果があるのか

 四角形は 2D 空間では重なりませんが、x 軸への投影では重なり合うことが許可されるため、各四角形は x 軸に沿って独立して寄与します。 固定列の場合、ペイントされたセルの数は、その列を覆うすべての四角形の高さの合計と等しくなります。 差分配列はこの列ごとの合計を正確にエンコードし、プレフィックス合計は位置ごとに正しく再構築します。 すべての削除はその列の値にのみ依存するため、これらの値を減算すると、二重にカウントされることなく、消去されたペイントされたセルが正確に削除されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, M = map(int, input().split())
    
    rects = []
    xs = []
    
    total_area = 0
    
    for _ in range(N):
        r1, c1, r2, c2 = map(int, input().split())
        h = r2 - r1 + 1
        w = c2 - c1 + 1
        total_area += h * w
        
        rects.append((c1, c2, h))
        xs.append(c1)
        xs.append(c2)
    
    bad = []
    for _ in range(M):
        x = int(input())
        bad.append(x)
        xs.append(x)
    
    xs = sorted(set(xs))
    idx = {x: i for i, x in enumerate(xs)}
    
    n = len(xs)
    diff = [0] * (n + 1)
    
    for c1, c2, h in rects:
        l = idx[c1]
        r = idx[c2]
        diff[l] += h
        diff[r + 1] -= h
    
    cur = 0
    col_val = [0] * n
    for i in range(n):
        cur += diff[i]
        col_val[i] = cur
    
    removed_sum = 0
    for x in bad:
        removed_sum += col_val[idx[x]]
    
    print(total_area - removed_sum)

if __name__ == "__main__":
    solve()
```解決策は、長方形の寸法から直接ペイントされた領域全体を計算することから始まります。 重なりが存在しないため修正の必要がないため、これは安全です。 

次に、すべての x 座標が圧縮されます。 座標が到達するため、これは不可欠です$10^9$、配列ベースの構造体は最大でも次の値に縮小する必要があります。$O(N+M)$サイズ。 

差分配列は、x 軸に沿って長方形の寄与をエンコードします。 各四角形は列範囲全体にわたって一定の高さに寄与するため、変更はエンドポイントにのみ保存されます。 プレフィックスの合計により、列ごとにペイントされた高さが再構築されます。 

最後に、削除された各列は圧縮後に O(1) でクエリされ、その寄与分が合計領域から減算されます。 

よくある間違いは、長方形ごとの高さの寄与を考慮せずに、削除された列の幅だけを減算しようとすることです。 四角形が行にまたがる方法に応じて、過小カウントまたは過大カウントになります。

 ## 特殊なケース

 微妙なケースの 1 つは、削除された列が四角形の境界として表示されない場合です。 圧縮ステップには引き続きそれが含まれるため、有効なインデックスが取得され、カバレッジに応じてゼロまたは正の値が提供されます。 アルゴリズムは、削除された列が四角形のエッジと一致するとは決して想定しないため、これを正しく処理します。 

もう 1 つのケースは、幅 1 の長方形です。ここでは、そのような各長方形が単一の圧縮インデックスでのみ寄与し、プレフィックス合計がその効果を正確に局所化するため、差分配列は依然として機能します。 たとえば、長方形$(c, c)$高さはその正確な列にのみ影響します。 

3 番目のケースは、多くの長方形が X 投影では重なっているが、2D では互いに素なままである場合です。 このアルゴリズムは干渉することなく列ごとの高さを合計します。また、素性は 2D でのみ適用されるため、この集計は列ごとのカウントでは依然として正確です。
