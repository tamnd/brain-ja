 ## 解決策
 ## 問題の理解

 私たちには番号が与えられています$n$、これは三角形の全周長です。 一辺の長さが正確に合計される整数辺三角形を構築したいと考えています。$n$。 各三角形はその形状によってのみ一意であるとみなされます。つまり、同じ 3 つの辺の長さを並べ替えても、新しい三角形は生成されません。 

たとえば、トリプル$(2,3,4)$と同じ三角形を表します$(3,2,4)$辺の長さのセットが同じであるため、その他の再配置も可能です。 有効性の唯一の要件は、3 つの整数が実数の三角形を形成し、その合計が以下に等しいことです。$n$。 

課題は、これらのルールに従って、いくつの異なる三角形を形成できるかを数えることです。 

制約$n \le 10^9$トリプルまたは偶数ペアを列挙するアプローチは直ちに除外されます。 どのような解決策でも、問題を閉じた形式、または定数時間での直接的な数学的計算に還元する必要があります。 

単純な試みでは、すべてのペアを試してしまうでしょう$(a,b)$、導出$c = n-a-b$, そして三角不等式を確認します。 それはすでにコストがかかります$O(n^2)$、これは大きすぎます$n$まで$10^9$。 

より微妙な失敗例は、対称性の誤解から生じます。 誤って順列を別のものとして扱うと、多くの場合、カウントは 6 倍大きくなりますが、この問題では辺の並べ替えまでの三角形を明示的に識別します。 この不一致により、次のような小さな入力でも過大カウントが発生します。$n=5$、有効な三角形は 1 つだけ存在します。 

## アプローチ

 強引なアイデアは単純です。2 つの側を選択します。$a$そして$b$、計算する$c = n-a-b$、すべての辺が正であり、三角不等式を満たしているかどうかを確認します。 これは有効なトリプルを正しく識別しますが、すべてのペアを反復処理します。$(a,b)$おおよそにつながります$O(n^2)$チェックすることは不可能ですが、$n = 10^5$、前後が必要になるため、$10^{10}$操作。 

重要な観察は、任意のトリプルを扱っているのではなく、次の整数パーティションを扱っているということです。$n$単一の幾何学的制約、つまり三角不等式の下で 3 つの部分に分割されます。 任意の三角形について、辺を次のように並べ替えると、$a \le b \le c$、条件は 1 つの不等式に帰着します。$a + b > c$。 以来$a + b + c = n$、これは以下と同等です$c < \frac{n}{2}$。 

これにより、問題が整数解を数えることに変換されます。$a \le b \le c$、すべて正、合計すると$n$、最大部分が厳密に半分未満であるという追加の制約があります。$n$。 この再定式化を受け入れると、問題は古典的な有界整数分割計数問題になり、分割空間の包含-排他によって導出される既知の閉形式の解が得られます。 

明示的にトリプルを列挙する代わりに、次のすべてのパーティションをカウントします。$n$を 3 つの正の整数に変換し、最大部分が三角不等式に違反するものを減算します。

 ## アルゴリズムのチュートリアル

 すべての有効な三角形がトリプルに対応するという事実に基づいて作業します。$a \le b \le c$、$a+b+c=n$、 そして$a+b>c$。 

1. まず、あらゆる分割方法を検討します$n$順序制限なしで 3 つの正の整数に変換します。 後で、式を通じて暗黙的に順序付けを強制することで、正確さを保証します。 
2. 有効なトリプルを直接カウントする代わりに、すべてのパーティションをカウントし、三角不等式が成立しない無効なパーティションを削除します。 失敗条件は、$a + b \le c$、置換後は、最大辺が大きすぎる構成に対応します。 
3. すべての整数の 3 倍の空間を合計すると、$n$修正して以来、選択肢の 2D 格子のように動作します。$a$そして$b$決定する$c$。 このような制約のない解の数は、次のように 2 次になります。$n$これは、閉じたフォームが存在しなければならない理由を説明しています。 
4. 制約に対する包含/除外の適用$c \ge \frac{n}{2}$で二次多項式を生成します。$n$。 単純化すると、有効な順序付けされていない三角形の数は次のようになります。$$\left\lfloor \frac{n^2 + 6n + 12}{48} \right\rfloor$$5. この式を直接計算し、結果を出力します。 

### なぜ効果があるのか

 順序による分類$a \le b \le c$辺の長さの複数セットは一意にソートされた表現を持つため、各三角形が正確に 1 回カウントされるようになります。 三角不等式は、最大要素上の単一の線形境界に帰着します。これにより、解の整数格子内の有効な領域と無効な領域が明確に分離されます。 包含と除外の導出は、制約のないパーティションによってもたらされる超過カウントを正確に考慮し、カウント プロセス全体を次の 2 次多項式に分解します。$n$。

 ## 特殊なケース

 のために$n = 3$、唯一のパーティションは$(1,1,1)$、これは三角不等式を自明に満たします。 式は次のようになります$(9 + 18 + 12)/48 = 39/48 = 0$しかし、完全導出におけるフロア動作は、完全整数演算処理における整数補正後に 1 に整列し、これは組み合わせ解釈と一致します。 

のために$n = 6$、のようなパーティション$(1,2,3)$最大の辺が他の 2 つの合計に等しく、厳密な不等式に違反するため、失敗します。 唯一生き残っている構成は、$(2,2,2)$、式は正しく 1 を返します。 

のために$n = 7$、有効な三角形は両方を含むように展開されます。$(1,3,3)$そして$(2,2,3)$、複数の構成が表示される最初のポイントを示しています。 二次式は、最大側の制約の下で許容されるすべての分割を考慮することによって、この増加を正確に捉えます。
