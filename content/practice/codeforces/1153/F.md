 ## 問題の理解

 次の長さの線分を考慮するように求められます。$l$。 私たちはランダムに選択します$n$この行のサブセグメント。 各サブセグメントは、セグメント上の 2 つの点を均一にランダムに選択することによって決定されるため、それらの端点は非整数になる可能性があります。 これらを配置した後、$n$ランダムなサブセグメントを調べます。$2n$エンドポイント。元のセグメントを次のように分割します。$2n+1$より小さな間隔。 私たちのタスクは、少なくとも次の条件でカバーされるすべての間隔の予想合計長を計算することです。$k$これらのランダムなサブセグメントの。 

入力により得られるのは、$n$、$k$、 そして$l$。 出力は、予想される長さのモジュロを表す整数です。$998244353$。 期待値は有理数である可能性があるため、答えは次のように表現される必要があります。$p \cdot q^{-1} \bmod 998244353$、 どこ$\frac{p}{q}$期待値の小数形式です。 

重要な制約は、$n \le 2000$。 すべてのサブセグメントの配置を明示的に列挙する素朴なシミュレーションは、可能な構成の数が数え切れないほど無限であるため、完全に実行不可能です。 代わりに、期待の線形性と組み合わせ推論を活用して、正確な式を取得する必要があります。 

エッジケースには以下が含まれます$k = 1$、すべてのサブセグメントが完全に寄与する場合、または$k = n$ここでは、すべてのセグメントが重なっている領域のみが問題となります。 もう 1 つの微妙な点は、セグメントの長さです。$l$まで可能です$10^9$したがって、アルゴリズムは明示的に点を反復することを避け、代わりに記号または数式を介して推論する必要があります。 

## アプローチ

 ブルート フォース アプローチでは、考えられるすべてのエンドポイントの組み合わせを生成し、各間隔のオーバーラップ長を計算しようとする場合があります。 これは理論的には正しいですが、$n = 2000$、それ以上の処理が必要になります$2n = 4000$連続空間内にエンドポイントを配置することは実際には不可能です。 さらに、すべてのサブセグメントの重複をカウントするには、$O(2^{2n})$すべてのカバレッジ パターンを列挙するだけの操作です。 

重要な洞察は、**期待の線形性**を使用することです。 少なくともカバーされる間隔の予想される合計長さ$k$セグメントは、その間隔が少なくとも次のものによってカバーされる確率の、各小さな間隔にわたる合計に等しい。$k$subsegments, multiplied by its length. ランダムなセグメントは独立しているため、組み合わせ論と動的計画法を使用して、特定の間隔が指定された数のセグメントでカバーされる確率を計算できます。 

具体的には、問題を **セグメント カバレッジ カウントに関する DP** に減らすことができます。 させて$dp[i][j]$～からの期待される貢献を示します$i$点をカバーするセグメント、または同等の、正確に一致する確率の合計$j$セグメントは、指定された無限小の間隔をカバーします。 一部の代数を使用すると、これにより効率的に計算できる漸化式が得られます。$O(n^2)$時間的には実現可能$n \le 2000$。

 ## アルゴリズムのチュートリアル

 1. セグメントを長さ 1 に正規化します。セグメントは均一であるため、予想される長さは実際のセグメントの長さに比例して変化します。$l$。 最終的な答えには次の値を掛けることができます$l$最後に。 
2. 小さな部分間隔を考慮します$dx$位置にある$x$。 各セグメントがカバーする確率$dx$左端点が左にある確率です。$x$そして右端点はその右側にあります$x$。 エンドポイントは均一であるため、1 つのセグメントが特定のポイントをカバーする確率は次のようになります。$2 \cdot (1 - x) \cdot x$セグメント全体にわたって統合されています。 
3. しましょう$p_i$指定されたセグメントがカバーする確率$dx$。 それから$n$独立したセグメント、正確に$j$セグメントカバー$dx$は$\binom{n}{j} p_i^j (1 - p_i)^{n-j}$。 合計します$j \ge k$その確率を計算するには$dx$少なくとも以下によってカバーされます$k$セグメント。 
4. この確率を積分します。$x$カバレッジ確率は多項式形式であるため、これは分析的に行うことができます。 階乗と事前計算されたモジュラー逆関数を使用すると、すべてを計算できます。$\binom{n}{j}$モジュロ$998244353$効率的に。 
5. 積分値に次の値を掛けます。$l$元のセグメントの長さにスケールバックします。 
6. 結果のモジュロを出力します。$998244353$、分数が逆モジュラーを介して処理されるようにします。 

機能する理由: 期待値は線形であるため、各無限小間隔の寄与を個別に計算できます。 組み合わせ確率を使用すると、各セグメントが独立していて均一であるため、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, k, l = map(int, input().split())

    # Precompute factorials and inverses
    fact = [1] * (n + 1)
    inv_fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i-1] * i % MOD
    inv_fact[n] = modinv(fact[n])
    for i in range(n-1, -1, -1):
        inv_fact[i] = inv_fact[i+1] * (i+1) % MOD

    # DP for binomial coefficients
    def C(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * inv_fact[b] % MOD * inv_fact[a-b] % MOD

    # Compute expected value
    ans = 0
    for i in range(k, n+1):
        prob = C(n, i) * pow(modinv(3), i, MOD) % MOD
        ans = (ans + prob) % MOD

    ans = ans * l % MOD
    print(ans)

solve()
```このソリューションは階乗を事前計算して、二項係数のモジュロを効率的に計算します。$998244353$。 主な微妙な点は、セグメントが点をカバーする確率を正しく計算し、少なくともその点の寄与を合計することです。$k$セグメント。 乗算$l$正規化されたセグメントを元の長さに戻します。 モジュラ逆算は、モジュラ算術の除算を処理します。
