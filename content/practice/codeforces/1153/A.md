 ## 解決策
 ## 問題の理解

 サーバルは決まった時間にバス停へ行きます`t`。 がある`n`バス路線のそれぞれの始発バスは次の場所に到着します。`s_i`分以降のバスは毎`d_i`分。 サーバルは後から来る、または時間通りに来る最初のバスに乗ります`t`。 複数のバスが同じ早い時間に到着する場合は、いずれかのルートを選択できます。 課題は、サーバルがどのバス路線に乗るかを決定することです。 

入力は次のもので構成されます`n`そして`t`、 に続く`n`ペア`(s_i, d_i)`各バス路線の始発時刻と始発間隔を表します。 出力は、選択したバス ルートの 1 から始まるインデックスを表す単一の整数です。 

制約は中程度です。`n`は最大でも 100 で、最大で 100 回になります。`10^5`。 たとえ分ごとに繰り返したとしても、操作数は制限内に収まるため、各バス路線にわたる総当たりチェックは実現可能です。 エッジケースには、ルートの最初のバスが正確に到着することが含まれます。`t`、すべてのバスがその後に到着するルート`t`、または複数のルートがその後の最も早いバスを共有します。`t`。 たとえば、次の場合`t=2`2 つのルートでバスが運行されることもあります`[2,4,6]`そして`[2,5,8]`、どちらも有効な答えです。 

## アプローチ

 単純なアプローチでは、到達するかそれを超えるまで、各バス ルートのすべての到着時刻を生成します。`t`そしてその中から最も古いものを選択します。 これが機能する理由は、`n`間隔が狭い`d_i`制限されています。 ただし、すべてのバス時刻を計算する必要はなく、単純な算術を使用して回避できます。 

重要な洞察は、から始まるルートについてです。`s_i`間隔あり`d_i`、サーバルが最初に乗れるバスは次の時刻に発生します。`s_i`もし`s_i >= t`。 それ以外の場合は、次の最初のバスを計算できます。`t`の最小倍数として直接`d_i`に追加されました`s_i`それは少なくとも`t`。 数学的には、これは`s_i + ceil((t - s_i)/d_i) * d_i`。 整数演算を使用すると、これを次のように計算できます。`(t - s_i + d_i - 1) // d_i`浮動小数点演算を避けるため。 これにより、問題は各バス ルートを 1 回スキャンして最も早く乗車可能なバスを計算することになり、時間内に解が O(n) になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (常に生成) | O(n * max((t - s_i)/d_i)) | お(1) | t が小さい場合は機能しますが、間隔が大きい場合は非効率的です。 
| 最適（直接計算） | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`n`そして`t`。 
2. 2 つの変数を初期化します。`best_time`(最も早いバスを追跡するため) 非常に大きな値に設定し、`best_route`-1まで。 
3. バス路線ごとのインデックス`i`1から`n`、 読む`s_i`そして`d_i`。 
4. もし`s_i >= t`、このルートの次のバスをに設定します`s_i`。 
5. それ以外の場合は、その後待機する必要がある間隔の数を計算します。`s_i`少なくとも到達するために`t`。 これは`(t - s_i + d_i - 1) // d_i`。 これを乗算します`d_i`そして追加します`s_i`このルートの最も早いバスの時刻を取得するには、
 6. このバスの時間が以下の場合`best_time`、 アップデート`best_time`そしてセット`best_route`に`i`。 
7. すべてのルートを確認したら、印刷します。`best_route`。 

機能する理由: アルゴリズムは、次の不変条件を維持します。`best_time`処理されたすべてのルートの中でサーバルが乗車できる最も早いバスを常に保持します。 整数演算を使用して各ルートの最初に乗車可能なバスを計算することで、実際の最も早いバスと最後のバスを決して逃さないことが保証されます。`best_route`正しいことが保証されています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, t = map(int, input().split())
best_time = float('inf')
best_route = -1

for i in range(1, n + 1):
    s, d = map(int, input().split())
    if s >= t:
        next_bus = s
    else:
        wait = (t - s + d - 1) // d
        next_bus = s + wait * d
    if next_bus < best_time:
        best_time = next_bus
        best_route = i

print(best_route)
```コードは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 このループは、ルートごとに最も早く到着できるバスを計算します。 の`(t - s + d - 1) // d`この式により、間隔が均等に分割されない場合に切り上げられます。 更新中`best_time`そして`best_route`厳密に前のバスが見つかった場合にのみ、曖昧さを回避し、1 から始まるインデックスを使用すると、問題の予想される出力と一致します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, t = map(int, input().split())
    best_time = float('inf')
    best_route = -1
    for i in range(1, n + 1):
        s, d = map(int, input().split())
        if s >= t:
            next_bus = s
        else:
            wait = (t - s + d - 1) // d
            next_bus = s + wait * d
        if next_bus < best_time:
            best_time = next_bus
            best_route = i
    return str(best_route)

# Provided samples
assert run("2 2\n6 4\n9 5\n") == "1", "sample 1"
assert run("3 2\n2 2\n2 3\n2 4\n") == "sample 2"

# Custom cases
assert run("1 1\n1 1\n") == "1", "single route catches immediately"
assert run("2 10\n1 3\n2 4\n") == "1", "earliest bus requires multiple intervals"
assert run("3 5\n2 2\n3 3\n5 1\n") == "3", "exact match at t"
assert run("3 7\n2 2\n3 3\n4 4\n") == "1", "multiple options, first min picked"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 1\n1 1 | 1 | 単一ルートですぐにキャッチ |
 | 2 10\n1 3\n2 4 | 1 | 複数の間隔を待機して、計算を確認します。 
| 3 5\n2 2\n3 3\n5 1 | 3 | 正確に t のルートが選択されます |
 | 3 7\n2 2\n3 3\n4 4 | 1 | 複数のルートが同じ次のバスに到着します。 最初の最小値が選択されました |

 ## 特殊なケース

 もし`t`ルートの始発バスの前にあり、`s_i >= t`、次のバスは`s_i`。 例えば、`t=1`、`s=5`、`d=3`与える`next_bus=5`。 アルゴリズムはこれを最も古いバスとして正確に識別します。 複数のルートに同じ最も早い次のバスがある場合、アルゴリズムは最初に見つかった最小値を選択します。 のために`t=2`そしてバス`[2,4]`、`[2,5]`、`[2,6]`、`best_time`ルート 1 では 2 になり、出力はルート 1 になります。最も早いバスが運行するどのルートでも受け入れられるため、これで問題は満たされます。
