 ## 解決策
 ## 問題の理解

 単位レンガの 3 次元配置が与えられます。$n \times m$グリッド。 位置のレンガの高さ$(i,j)$は不明ですが、正面、左側、上面の 3 つの部分ビューが提供されています。 正面図では、それぞれの最大高さが示されています。$m$行方向に沿った列の左側の図は、各列の最大高さを示しています。$n$行は列方向に沿って配置され、上面ビューはバイナリです$n \times m$レンガが特定の位置に存在するかどうかを示すマトリックス。 タスクは、3 つのビューすべてと一致するレンガの**任意** 3D 配置を再構築することです。 

各高さは最大許容高さによって制限されます$h$、行と列の数は最大 100 です。これは、$O(n \cdot m)$解決。 考えられるすべての高さの組み合わせを強引に列挙する必要はなく、これらの小さな制限であっても試行が必要になるため非効率的です。$h^{n \cdot m}$構成。 

上面図ではレンガのある位置が禁止されているが、正面図または左面図では正の高さが許可されている場合、明らかではないエッジ ケースが発生します。 たとえば、上面図に$0$で$(2,3)$、左側のビューは、行 2 の最大値が次であることを示しています。$4$、正面図から、列 3 の最大値は次のとおりであることがわかります。$5$。 不用意に実装すると、上面図を考慮せずに最大許容高さを割り当てようとし、無効な構成が発生する可能性があります。 

もう 1 つの特殊なケースは、正面図と左側図からの最大高さの制約が異なる場合に発生します。 たとえば、行 1 の左側のビューが次の場合、$3$列 2 の正面図は次のとおりです。$2$、次にセル$(1,2)$超えることはできません$2$行で許可されている場合でも、$3$。 これらの競合に慎重に対処することが重要です。 

## アプローチ

 素朴なアプローチは、次の高さを割り当ててみることです。$1$に$h$としてマークされたすべてのセルに対して、$1$上面図で各行と列の最大値が左面図と正面図と一致するかどうかを確認します。 これは原理的には正しいですが、次の点まで確認する必要があるため、非常に非効率的です。$h^{n \cdot m}$構成は、$n = m = 100$。 

重要な洞察は、各セルが$1$上部のビューでは、対応する行と列の最大値によって**独立して制約**されます。 具体的には、レンガの高さは、$(i,j)$行の左側のビューを超えることはできません$i$または柱の正面図$j$なぜなら、いずれかの最大値を超えると、いずれかのビューに違反することになるからです。 上面図ではセルをゼロ以外にすることができるため、最適かつ最も簡単な選択は、行と列の最大値の**最小値**を割り当てることです。 が付いているセル$0$上部のビューの は、行または列の制約に関係なく、強制的にゼロに設定されます。 

この観察により、問題は 1 つに集約されます。$O(n \cdot m)$マトリックスを通過させ、各セルの上面図をチェックし、ゼロまたは行と列の最大値の最小値のいずれかを割り当てます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(h^{n・m}) | O(n・m) | 遅すぎる |
 | 最適 | O(n・m) | O(n・m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む$n$、$m$、 そして$h$。 これらは 3D オブジェクトの寸法と最大許容高さを定義します。 
2. 長さの正面図配列を読み取ります。$m$。 各エントリは、対応する列の最大高さを表します。 
3. 長さの左ビュー配列を読み取ります。$n$。 各エントリは、対応する行の最大の高さを表します。 
4. 上面図を読む$n \times m$マトリックス、エントリあり$0$または$1$。 
5. 空のオブジェクトを初期化する$n \times m$マトリックス`H`再構築された高さを保存します。 
6. 各セルを反復処理します。$(i,j)$:

 ａ． 上から見た場合$(i,j)$は$0$、割り当てます`H[i][j] = 0`。 

b. 上から見た場合$(i,j)$は$1$、割り当てます`H[i][j] = min(left[i], front[j])`。 これにより、正の高さを確保しながら、左側と正面の両方のビューの制約が尊重されます。 
7. マトリックスを印刷します`H`一行ずつ。 

機能する理由: このアルゴリズムは、上面図で示されるすべてのセルが正であることを保証しながら、行または列の最大値を超えないという不変条件を維持します。 最小値を割り当てると、正面図と左側図のすべての最大値が各行と列の少なくとも 1 つのセルによって達成できることが保証されます。 とマークされたセル$0$トップビューの はゼロのままであることが保証され、違反を防ぎます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m, h = map(int, input().split())
front = list(map(int, input().split()))
left = list(map(int, input().split()))
top = [list(map(int, input().split())) for _ in range(n)]

H = [[0]*m for _ in range(n)]

for i in range(n):
    for j in range(m):
        if top[i][j]:
            H[i][j] = min(left[i], front[j])
        else:
            H[i][j] = 0

for row in H:
    print(' '.join(map(str, row)))
```最初の部分では、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 ネストされたループは、上面、左面、および正面図に関して最小の高さを割り当てます。 使用する`min(left[i], front[j])`割り当てられた高さが行または列の最大値に違反しないようにします。 最後に、再構成された高さ行列の各行を出力します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m, h = map(int, input().split())
    front = list(map(int, input().split()))
    left = list(map(int, input().split()))
    top = [list(map(int, input().split())) for _ in range(n)]
    H = [[0]*m for _ in range(n)]
    for i in range(n):
        for j in range(m):
            if top[i][j]:
                H[i][j] = min(left[i], front[j])
            else:
                H[i][j] = 0
    return '\n'.join(' '.join(map(str,row)) for row in H)

assert run
