## アルゴリズムのチュートリアル

 私たちは各花の種類を 2 種類の寄与を生成するものとして扱います: 1 つの特別な値$a_i$そして値の無限の繰り返し$b_i$(最初のピックの後)。 

1. 候補値が固定の場合$x$、すべてのタイプの合計貢献度が少なくともどれくらいかを計算します。$x$。 これは、各タイプを個別にチェックすることによって行われます。 

もし$a_i \ge x$、それは1つの保証された大きな価値に貢献します。 次に、その数も考慮します。$b_i$-値は少なくとも$x$、理論上は無限ですが、実際には必要なピックの数によって制限されます。 までのカウントのみが必要であるという事実を利用して、貢献カウントを慎重に計算します。$n$。 
2. タイプごとに、少なくとも価値のあるピックの数を計算します。$x$。 もし$b_i \ge x$、最初の花を撮った後（もし$a_i \ge x$)、このタイプからの後続のすべての選択も有効です。 それ以外の場合は、小さな有限数のみが寄与します。 

このステップは、シミュレーションではなく直接式として実装されます。 
3. 二分探索を使用します$x$、上位の最小値$n$選ばれた貢献。 範囲内で検索します$[0, \max(a_i)]$。 
4. 閾値を見つけたら$x$、厳密に次よりも大きい貢献の合計数を計算します。$x$、それらの値を直接合計します。 
5. 同等の寄付について$x$、正確に到達するのに十分な量だけを取ります$n$複数のタイプが同じ限界値に寄与する可能性があるためです。 

### なぜ効果があるのか

 すべての花の種類にわたる限界寄与はマルチセットを形成し、最初の摘み取りが で安定した後、各種類が非増加シーケンスに寄与します。$b_i$。 関数「最低何回の貢献が必要か」$x$”は単調減少です$x$、二分探索の正確さを保証します。 カットオフが固定されると、それを超えるすべての寄与が常に取得され、残りは同じ値の要素で最適に埋められるため、再配置しても結果は改善されません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(n, m, arr):
    lo, hi = 0, 10**18

    def count_ge(x):
        cnt = 0
        for a, b in arr:
            if a >= x:
                cnt += 1
            if b >= x:
                cnt += max(0, n - (1 if a >= x else 0))
        return cnt

    def sum_ge(x):
        total = 0
        for a, b in arr:
            if a >= x:
                total += a
                cnt = 1
                if b >= x:
                    cnt += n - 1
                    total += (n - 1) * b
        return total

    for _ in range(60):
        mid = (lo + hi) // 2
        if count_ge(mid) >= n:
            lo = mid
        else:
            hi = mid - 1

    x = lo

    total = 0
    used = 0

    for a, b in arr:
        if a >= x:
            total += a
            used += 1
            if b >= x:
                take = min(n - used, n - 1)
                total += take * b
                used += take

    if used < n:
        total += (n - used) * x

    return total

def main():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        arr = [tuple(map(int, input().split())) for _ in range(m)]
        print(solve_case(n, m, arr))

if __name__ == "__main__":
    main()

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    def solve():
        n, m = map(int, input().split())
