 ## アルゴリズムのチュートリアル

### なぜ効果があるのか

 各貨物列車は、他のすべての列車から独立した制約に影響を与えます。その制約は、路面電車の窓がそれを覆っているかどうかによってのみ有効または無効になります。 どのような固定列車でも、一連の不適切な開始位置は、可能性のある円軸上に連続した円弧を形成します。`t`価値観。 したがって、最終的な答えは、この円上の最も少ない円弧内にある点になります。 モジュラー分割を使用して円を線に変換すると、オーバーラップ数が正確に保持されるため、プレフィックスサム スイープにより、考えられるすべての開始位置について違反した制約の数が正しく再構築されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def add(diff, l, r):
    diff[l] += 1
    diff[r] -= 1

def solve():
    n, h, m, k = map(int, input().split())
    p = m // 2

    trains = []
    for _ in range(n):
        hh, mm = map(int, input().split())
        x = hh * m + mm
        trains.append(x % p)

    diff = [0] * (p + 1)

    for x in trains:
        l = (x - k) % p
        r = x % p

        if l < r:
            add(diff, l, r)
        else:
            add(diff, l, p)
            add(diff, 0, r)

    best = n
    best_t = 0
    cur = 0

    for t in range(p):
        cur += diff[t]
        if cur < best:
            best = cur
            best_t = t

    print(best, best_t)

if __name__ == "__main__":
    solve()
