 ## 解決策
 ## 問題の理解

 2行が与えられます$n$- フィールドを表す列グリッド。各セルは空、羊、またはオオカミを含むことができます。 羊はちょうど 1 匹で、一部のセルにはオオカミが含まれています。 オオカミは、溝が道を妨げない限り、隣接するセルに水平または垂直に移動できます。 私たちの目標は、最小限の総資金を費やしながら、すべてのオオカミが羊に到達するのを防ぐことです。 支払いの 2 つの操作が可能です。$h$オオカミを排除するためのコイン、または支払い$b$コインを使って空のセルに溝を掘ります。 

入力により複数のテスト ケースが提供されます。 テスト ケースごとに、グリッドの次元とコストが指定され、その後にグリッドの 2 行が指定されます。 出力は、オオカミが羊に到達できないようにするために必要な最小の総コストです。 

制約は、すべてのパスの直接シミュレーションが遅すぎることを意味します。 と$n$まで$2 \cdot 10^5$最大 1200 のテスト ケースでは、すべてのオオカミからの単純な DFS または BFS が数億の操作につながる可能性があります。 羊の近くの関連するセルのみを検査し、コストを効率的に評価するソリューションが必要です。 

明白ではないエッジケースとしては、オオカミが羊と同じ列にいるが遠く離れている状況、トレンチの方がオオカミを除去するよりも安価である状況、水平パスと垂直パスの両方が存在する構成などが挙げられます。 隣接するセルのみを参照したり、単一行のパスを想定した不注意なアプローチでは、費用がかかりすぎたり、より安価なソリューションを見逃したりする可能性があります。 

## アプローチ

 ブルートフォース手法では、すべてのオオカミを反復処理し、羊へのあらゆる可能な経路をシミュレートし、オオカミを削除するか、経路に沿った各空のセルをブロックするかを選択します。 これは到達可能性を正しく考慮しているため機能しますが、最悪のケースでは調査が必要です。$O(n^2)$テスト ケースあたりのセル数が多く、大規模なグリッドの許容時間を超えます。 

重要な観察は、グリッドには 2 行しかないため、異なる列のオオカミは独立しているということです。 各列は「ユニット」であり、オオカミを排除するか、2 つのセルの 1 つの溝によってブロックすることができます。 オオカミは斜めに移動できず、羊のセルには隣接するオオカミがいないため、オオカミがいる各列には羊への経路が最大で 2 つあります。同じ列を通るか、隣接する列を通ります。 これにより、オオカミの排除または溝掘りの最も安価な組み合わせを考慮して、列ごとに最小コストを計算できます。 

したがって、最適な戦略は次のとおりです。オオカミがいる列ごとに、オオカミを直接排除するか、溝で道を塞ぐかの最小値を計算します。 これを関連するすべての列にわたって累積します。 このアプローチは、$n$テスト ケースごとに、最大の制約まで快適に処理します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | テスト ケースあたり O(n²) | O(n) | 遅すぎる |
 | 最適 | テスト ケースあたり O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力を解析し、羊の位置を特定します。 羊のセルの列と行を特定します。 
2. グリッドの各列について、オオカミが含まれているかどうかを確認します。 そうでない場合は、その列に対するアクションは必要ないため、スキップしてください。 
3. オオカミがいる列の場合、羊を保護するためのコストを 2 つのオプションで計算します。$h$コインでその列のオオカミを削除するか、支払います$b$コインを使用して、羊への潜在的な経路に沿って空のセルに溝を構築します。 
4. 各オオカミについて、羊に対する垂直方向および水平方向の隣接関係を考慮します。 オオカミが溝に遭遇することなく羊に到達できる場合は、オオカミを排除するか道をふさぐための最小限のコストを考慮します。 
5. すべての列の最小コストを合計して、そのテスト ケースの最小コストの合計を取得します。 
6. 各テストケースの合計コストを出力します。 

それが機能する理由: 不変条件は、各オオカミに対して、羊への到達を妨げる最も安価なアクションを常に選択するということです。 異なる列のオオカミは斜めに相互作用したり、塹壕を迂回したりできないため、各列を個別に処理することで正確性が保証されます。 これらのコストを合計すると、グローバル最小値が算出されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, h, b = map(int, input().split())
        grid = [input().strip() for _ in range(2)]
        
        # Locate the sheep
        for r in range(2):
            for c in range(n):
                if grid[r][c] == 'S':
                    sr, sc = r, c
                    break
        
        cost = 0
        for c in range(n):
            # Identify wolves in this column
            wolves = []
            for r in range(2):
                if grid[r][c] == 'W':
                    wolves.append(r)
            if not wolves:
                continue
            
            # If the wolf is in the same column as sheep or can reach horizontally
            # Minimum cost: either remove wolves (len(wolves)*h) or build trenches (number of empty cells * b)
            trench_cells = 0
            for r in range(2):
                if grid[r][c] == '.' and (r != sr or c != sc):
                    trench_cells += 1
            
            cost += min(len(wolves) * h, trench_cells * b)
        
        print(cost)

solve()
```コードはまず入力を読み取り、羊の位置を特定します。 次に、各列を反復してオオカミをチェックします。 オオカミがいる列の場合、トレンチに適した空のセルをカウントし、オオカミを直接削除するかトレンチを掘るかの間の最小値を計算します。 これらの最小値を合計すると、全体的な解が得られます。 微妙な点としては、トレンチ カウントからヒツジ セルを正しく除外することと、各列を独立して処理することが挙げられます。
