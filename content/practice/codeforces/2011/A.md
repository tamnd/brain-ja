 ## 解決策
 ## 問題の理解

 ジェーンは、既知の問題を含む問題のリストを持っています。 リストの最後の問題は、それまでの問題よりも厳密に難しいです。 

彼女のスキルレベルは整数です$x$。 彼女は、最大でも難易度が高いあらゆる問題を解決することができます$x$、より高い難易度の問題を解くことはできません。$x$。 

彼女は最後の問題を除いてすべての問題を解決したと言われています。 この情報から、彼女のスキルレベルを正確に特定できるかどうかを判断する必要があります。 可能な値が 1 つだけある場合、$x$、印刷します。 複数の値がある場合、$x$観察結果を満たしている場合は、印刷します`Ambiguous`。 

入力により複数のテスト ケースが提供されます。 各テスト ケースには、困難のリストが含まれています。 各テスト ケースの出力は、一意のスキル値または単語のいずれかです。`Ambiguous`。 

制約はわずかです。 最大 1000 のテスト ケースがあり、各テスト ケースには最大 50 の難易度が含まれており、すべての難易度は最大 50 です。すべての可能なスキル値に対する総当たり検索でも十分に高速です。 課題は効率ではなく、観察結果が実際にどのような情報を提供するかを理解することです。 

最もよくある間違いは、ジェーンのスキルが、解決された問題の中で最大の難易度に等しいはずだと思い込むことです。 それは一部の場合にのみ当てはまります。 

考慮する：```
8
8 8 5 3 4 6 8 12
```ジェーンは難易度 8 以下の問題をすべて解決しましたが、難易度 12 で失敗しました。ジェーンのスキルは 8、9、10、または 11 の可能性があります。正解は次のとおりです。```
Ambiguous
```もう 1 つの微妙なケースは、解決されたすべての問題の難易度が同じである場合です。```
4
3 3 3 4
```彼女は難易度 3 を解決しましたが、難易度 4 で失敗しました。スキルは整数であるため、唯一の可能性は次のとおりです。$x=3$。 正しい答えは次のとおりです。```
3
```常に最大の解決難易度を出力する不注意な解決策がここで機能する可能性がありますが、その理由は間違っています。 

## アプローチ

 ブルートフォースアプローチは簡単です。 可能な整数のスキル値ごとに$x$、観察と一致しているかどうかを確認します。 

スキル値は、解決されたすべての問題が最大でも難易度が低い場合に有効です。$x$、最後の未解決問題は、$x$。 

すべての難易度は最大 50 なので、すべての難易度をテストできます。$x$0 から 50 までを選択し、これらの条件を満たすものがいくつあるかを数えます。 1 つだけが機能する場合は、それを印刷します。 それ以外の場合は印刷します`Ambiguous`。 

この方法は、有効なスキル レベルの定義を直接実装するため、正しいです。 その複雑さは、$O(50n)$テストケースごとに、これは十分に高速です。 

重要な点は、実際には何も列挙する必要がないということです。 

させて$$m = \max(d_1,d_2,\ldots,d_{n-1})$$解いた問題の中で最大の難関となります。 

ジェーンは以前の問題をすべて解決したので、彼女のスキルは満足できるはずです$$x \ge m.$$彼女は最後の難易度の問題で失敗したので、$d_n$、$$x < d_n.$$したがって、すべての有効なスキル値は間隔内にあります。$$m \le x \le d_n-1.$$可能なスキル値の数は$$(d_n-1)-m+1 = d_n-m.$$もし$d_n-m=1$、可能な値は 1 つだけです。$m$。 

もし$d_n-m>1$、複数のスキル値が可能であり、答えは次のとおりです。`Ambiguous`。 

問題全体は、解決された最大の難易度と最終的な難易度を比較することに帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(50n) | お(1) | 承認済み |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 現在のテスト ケースの難しさを読みます。 
2. 最初の難易度の中で最大の難易度を計算します。$n-1$問題。 この値を呼び出します`mx`。 

ジェーンはこれらの問題をすべて解決したので、有効なスキルは少なくとも`mx`。 
3. しましょう`last`最終問題の難易度になります。 

ジェーンはこの問題を解決できませんでした。そのため、有効なスキルは厳密に次の値よりも小さい必要があります。`last`。 
4. 有効なスキル値は範囲内のすべての整数です。`[mx, last-1]`。 
5. もし`last - mx == 1`、範囲には整数が 1 つだけ含まれます。`mx`。 印刷する`mx`。 
6. それ以外の場合、範囲には複数の整数が含まれます。 印刷する`Ambiguous`。 

### なぜ効果があるのか

 解決されたすべての問題にはスキル レベルの下限が課せられ、そのような最も強い上限が解決された最大難易度になります。`mx`。 

失敗した最終問題には上限が課せられます。$x < \text{last}$。 

他の情報は重要ではありません。 これらの範囲内の任意の整数は、すべての観測値を満たします。 したがって、実行可能なスキルのセットはまさに間隔です$[mx, \text{last}-1]$。 

その間隔に整数が 1 つ含まれる場合、スキルは一意に決定されます。 複数の整数が含まれている場合、いくつかのスキルが証拠に適合し、答えは次のようになります。`Ambiguous`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    d = list(map(int, input().split()))

    mx = max(d[:-1])
    last = d[-1]

    if last - mx == 1:
        print(mx)
    else:
        print("Ambiguous")
```解決策は数​​学的特性に直接従うものです。 

変数`mx`解決されたすべての問題の中で最大の難易度を保存します。 有効なスキルはすべてこの値以上である必要があります。 

変数`last`唯一の未解決の問題の難易度を保存します。 有効なスキルはすべてこの値より小さくなければなりません。 

したがって、実行可能なスキルの間隔は次のようになります。`[mx, last - 1]`。 次の場合、間隔にはちょうど 1 つの整数が含まれます。`last - mx == 1`。 そのような状況では、印刷します`mx`。 それ以外の場合は、複数の可能なスキルがあるため、出力します。`Ambiguous`。 

最後の問題が最大計算から除外されることを覚えておくこと以外に、難しい境界条件はありません。 使用する`max(d[:-1])`これを正しく処理します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | 1 回のスキャンで最初の n-1 個の要素の最大値を見つけます。 
| スペース | お(1) | 少数の変数のみが保存されます。 

と$n \le 50$、実行時間は無視できます。 1000 のテスト ケースすべてにわたっても、このソリューションは数万回の操作のみを実行し、制限内に簡単に収まります。 

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        d = list(map(int, input().split()))

        mx = max(d[:-1])
        last = d[-1]

        if last - mx == 1:
            ans.append(str(mx))
        else:
            ans.append("Ambiguous")

    print("\n".join(ans))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return out

# provided sample
assert run(
"""3
5
1 2 3 4 5
8
8 8 5 3 4 6 8 12
4
3 3 3 4
"""
) == "4\nAmbiguous\n3\n"

# minimum size
assert run(
"""1
2
1 2
"""
) == "1\n"

# ambiguous interval of length 3
assert run(
"""1
2
1 4
"""
) == "Ambiguous\n"

# all solved difficulties equal
assert run(
"""1
5
7 7 7 7 8
"""
) == "7\n"

# boundary value near maximum difficulty
assert run(
"""1
4
50 50 50 51
"""
) == "50\n"
