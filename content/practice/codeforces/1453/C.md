 ## 解決策
 ## 問題の理解

 サイズの正方形のボードが与えられます`n × n`ここで、各セルには間の数字が含まれます。`0`そして`9`。 各桁ごとに`d`を含むセルの中心を頂点とする三角形を見つけたいとします。`d`、この三角形の面積が最大になるように、少なくとも 1 つの辺がボードの端と平行になります。 三角形を構築する前に、ボード上の 1 つのセルを次のように変更することができます。`d`。 出力は、各桁の最大面積に 2 を乗算したものです。 

入力は複数のテスト ケースで構成されます。 最初の行はテスト ケースの数を示します。`t`。 各テスト ケースは次で始まります`n`、 に続く`n`ボードを表す文字列の行。 の合計`n²`すべてのテスト ケースにわたって 4 × 10⁶ を超えません。 この限界は、テスト ケースごとに最大でおよそ O(n²) 個のアルゴリズムを使用する必要があることを示しています。 それより遅いと制限時間を超えてしまいます。 

明らかではないエッジケースは、数字がボード上に 1 回しか表示されない場合、またはまったく表示されない場合に発生します。 このような場合、三角形は縮退しているか、余分なセルの最適な配置に完全に依存している可能性があります。 もう 1 つの微妙な点は、最大面積の三角形では、1 つの軸に沿った可能な最大距離が使用されることがよくあります。`n - 1`、ボードの角に対応します。 

たとえば、次の場合`n = 3`ボードにはゼロのみが含まれており、数字の最大三角形領域`0`頂点が位置を占めるときに発生します`(0,0)`、`(0,2)`、`(2,0)`、面積は 2 (2 → 4 倍) になります。 すべてのセルのトリプレットを反復処理する不用意なアプローチは遅すぎ、軸が揃っている条件を無視すると無効な三角形が生成されます。 

## アプローチ

 単純な総当たりアプローチでは、各桁の位置の 3 つの要素をすべて列挙し、少なくとも 1 つの辺が軸と一致している場合に三角形の面積を計算します。 これは、1 桁あたり O(n²) 個の位置と O((n²)³) 個のトリプレットがあるため、テスト ケースごとに 1 桁あたり O(n⁴) の時間計算量になります。 これは不可能です`n`2000年まで。 

重要な観察は、面積が最大で少なくとも 1 つの辺が軸に平行な三角形は、その数字を含む極端な行と列によって決定されるということです。 具体的には、数字の場合`d`、次のように事前計算できます。 

- The minimum and maximum row indices containing`d`。 
- 最小および最大の列インデックスには以下が含まれます。`d`。 

可能な限り最大の領域は、これらの端に頂点を配置することによって得られます。 すべての位置を反復処理し、可能な限り遠い行または列に関して面積を計算することで、1 桁あたり O(n²) の最大値を効率的に見つけることができます。 これが機能するのは、最大距離を延長するために基板エッジに沿った位置を考慮することで追加の許可セルを追加できるためです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n⁴) | O(n²) | 遅すぎる |
 | 最適 | O(n²) | O(n²) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`そして`n × n`ボード。 
2. 10 個の配列を初期化して、各桁の最小および最大の行インデックスと列インデックスを追跡します。 
3. 各セルを反復処理します。`(i, j)`ボードの。 数字の場合`d`そのセルで、次のように更新します。 

-`min_row[d]`そして`max_row[d]`と`i`。 
-`min_col[d]`そして`max_col[d]`と`j`。 
4. 各桁について`d`0 から 9 までの最大面積を次のように計算します。 

- 発生するたびに、`d`で`(i, j)`:

 - 行に沿った辺を持つ三角形を形成することを検討してください。`height = max(i, n - 1 - i)`、`base = max_col[d] - min_col[d]`。 
- 柱に沿った辺を持つ三角形を形成することを検討してください。`height = max(j, n - 1 - j)`、`base = max_row[d] - min_row[d]`。 
- 取得した最大面積を維持します。`(i, j)`。 
5. すべての桁の面積を 2 倍して出力します。 

**機能する理由:** 極端な行と列の位置により、三角形の少なくとも 1 つの辺が軸に平行になり、距離が最大化されることが保証されます。 それぞれの発生を考慮することで、余分なセルを最適に配置できるようになります。 このアルゴリズムは、桁ごとに O(n²) 個の位置のみを検査し、単純な算術を使用して最大面積を見つけます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        board = [input().strip() for _ in range(n)]
        
        min_row = [n] * 10
        max_row = [-1] * 10
        min_col = [n] * 10
        max_col = [-1] * 10
        
        for i in range(n):
            for j in range(n):
                d = int(board[i][j])
                min_row[d] = min(min_row[d], i)
                max_row[d] = max(max_row[d], i)
                min_col[d] = min(min_col[d], j)
                max_col[d] = max(max_col[d], j)
        
        res = [0] * 10
        for d in range(10):
            for i in range(n):
                for j in range(n):
                    if int(board[i][j]) != d:
                        continue
                    # side along row
                    height = max(i, n - 1 - i)
                    width = max_col[d] - min_col[d]
                    res[d] = max(res[d], height * width)
                    # side along column
                    width = max(j, n - 1 - j)
                    height = max_row[d] - min_row[d]
                    res[d] = max(res[d], height * width)
        print(*res)

if __name__ == "__main__":
    solve()
```このコードは、各桁の極端な行インデックスと列インデックスを事前計算します。 数字が出現するたびに、行と列に沿ったエッジまでの最大距離を使用して三角形の可能性のある領域を計算します。 このアプローチは、軸合わせ制約を満たす最大の三角形を効率的に見つけます。
