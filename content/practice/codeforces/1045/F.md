 ## 問題の理解

 2 つの変数に単項式の固定セットが与えられ、各単項式は次の形式になります。$x^{a_k}y^{b_k}$ですが、係数は未知の正の整数です。 係数が選択される前に、Ani は最大 1 つの単項式を削除できます。 その後、ボルナは残りのすべての係数に任意の正の整数を割り当てます。 

係数が固定されると、式を実関数として解釈します。$f(x,y)$。 ボルナが係数を選択できれば勝ちます。$f(x,y)$平面全体で下から境界があるということは、実際のものが存在することを意味します。$M$そのような$f(x,y) \ge M$すべての本当の$x,y$。 アニは、最大でも 1 つの項を最適に削除した後、その逆を強制できれば勝ちです。 

入力は指数ペアだけなので、ゲーム全体は点の幾何学のみに依存します。$(a_k,b_k)$第 1 象限格子内。 アニの行動後にボルナが自由に選択したため、係数は与えられません。 

この制約では最大 200,000 の単項式が許可されるため、単項式のペアまたはトリプルを明示的にテストしようとするソリューションは遅すぎます。 すべてのペアにわたる二次または二次に近い幾何学的比較は、直ちに除外されます。 これにより、私たちは次のような方向に向かって進みます。$O(n \log n)$または線形幾何学的特徴付け。 

重要な点は、係数が任意の実数ではなく、正の整数であることです。 ボルナは契約条件をキャンセルできないため、これは重要です。 すべての単項式は、次の場合に非負に寄与します。$x,y$はポジティブですが、次の場合には任意にネガティブになる可能性があります。$x$または$y$指数のパリティに応じて負になります。 問題は根本的に、何らかの方向性があるかどうかということだ。$(x,y)$空間では、1 つの単項式が他の単項式を負に支配し、以下の多項式が無制限になります。 

素朴な間違いは、通常の意味で点の凸包のみが重要であると考えることです。 これは近いですが、どの方向がどの方向に対応するかを正しく解釈しない限り十分ではありません。$(x,y)\to (\pm\infty,\pm\infty)$スケーリング。 もう 1 つのよくある失敗は、1 つの点を削除すると、以前に船体を安定させていた「サポート エッジ」が破壊される可能性があることを無視していることです。 

重要なエッジケース:

 すべての点が指数空間の単一線上にある場合、次のようになります。$(0,0),(1,1),(2,2)$、構造の動作は異なります。1 つの点を削除すると、端点が残っているかどうかに応じて、境界が壊れる場合と壊れない場合があります。 

点が 2 つしかない場合、1 つを削除すると単一の単項式が残るため、アニは常に勝ちます。$x$または$y$適切に負の無限大まで。 

点セットの左下の包絡線に厳密に凸状の角が存在する場合、その角を削除すると、境界のない方向を作成する線分が露出する可能性があります。 

## アプローチ

 各単項式を点として解釈することから始めます$(a,b)$。 代替を検討してください$x = t^p, y = t^q$大型用$t$。 各用語は次のようになります$t^{ap + bq}$。 方向に沿った多項式の動作$(p,q)$どの点が最大になるかによって決まります$ap+bq$。 2 つの点が同等に競合する場合、それらの係数が重要になりますが、Borna は常に、以下の分析からの有界でのキャンセルの問題を回避するのに十分な大きさの係数を選択できます。 重要なのは、単一の項が厳密に支配的になる支配的な方向の存在と、負の符号の選択です。$x,y<0$多項式が次のような傾向になるようにする$-\infty$。 

したがって、有界性は幾何学的条件に帰着します。つまり、強制的に発散させるために符号を反転できるような形で、どの方向も単一の単項式を一意に極値として分離すべきではありません。 

これは、指数点のセットが、すべての支持線が（すべての方向に）構造を形成することを要求するのと同じです。$(p,q)$) 少なくとも 2 点に触れます。 言い換えれば、凸包のすべての極点は、線形関数の下で一意に最小または最大になる露出した頂点ではなく、セグメント上に存在する必要があります。 

いずれかの 1 点を削除した後、残りのセットに全方向に関連する意味で凸包に露出した頂点がない場合、ボルナが勝ちます。 厳密に露出された頂点を作成する点、つまり、ある方向に一意に極端になる点を削除できれば、アニが勝ちます。 

したがって、問題は、すべての点の削除によって、すべての凸包の頂点が少なくとも 1 つの隣接する方向で非固有のままであるという特性が維持されるかどうかをチェックすることに帰着します。 古典的な還元は、凸包上の点のみが重要であり、より正確には、単調順序の包の「外側のチェーン」のみが重要であることを示しています。 

重要な洞察は、次の基準でソートされた点を表示するときに、下部の凸包のみを考慮する必要があるということです。$a$、最適な分離方向は単調な重み付けに対応するため$ap+bq$。 そして、その構造は、厳密な凸コーナーを作成する方法でチェーンを切断する頂点が存在する場合に、まさに境界性が失敗するシーケンスになります。 

これは、船体がすべての頂点が「冗長」であるセグメント構造を持っているかどうかをチェックすることにつながります。つまり、頂点が直線セグメント上にあるか、または傾斜間隔を独自にサポートしていないことを意味します。 

ブルート フォースでは、各点を削除した後に凸包を計算します。$O(n^2 \log n)$。 最適解では、ハルを 1 回計算し、ハルの各頂点の周囲の局所的な幾何学的条件をチェックして、それがクリティカルかどうかを判断します。

 ## アルゴリズムのチュートリアル

 傾斜の辞書編集順にある点の凸包に焦点を当てます。 

1. Sort all points by$a$、そして平等のために$a$、 による$b$。 これにより、各ステップが増加する傾斜を維持する単調なチェーン ハルを構築する準備が整います。 凸構造は 1 つの座標内の順序に依存するため、ソートが必要です。 
2. 標準のモノトーン スタックを使用して下部の凸包を構築し、各トリプルが凸性を維持するチェーンを維持します。 3連続得点の場合$A,B,C$、外積を保証します。$(B-A)\times(C-A)$必要な方向に違反していません。 これにより、極端な動作を定義する境界点のみを保持することが保証されます。$ap+bq$。 
3. どの元のインデックスが船体に属しているかを記録します。 内部点は、どの方向においても決して一意に最適ではないため無関係であり、最悪の場合の係数割り当てでは有界性に影響を与えることはできません。 
4. ハルを順番にトラバースし、局所的な凸性を計算します。 船体ポイントごとに$P_i$、厳密なコーナーであるか、直線セグメント上にあるかを確認します。 これは、近傍の外積をチェックすることで実行できます。 もし$P_i$隣接するものと同一線上にありますが、重要ではありません。 
5. ハル頂点を削除すると隣接するエッジが厳密な凸角を形成し、ハル頂点が一意に露出するようなハル頂点が存在するかどうかを判断します。 同様に、ハルに厳密に凸状 (同一直線上にない) で、平らなセグメントによって複製されていない頂点が少なくとも 1 つあるかどうかを確認します。 
6. そのような頂点が存在する場合、Ani はそれを削除し、一方向が単一の極値点を分離する構成を作成し、以下の多項式を無制限にすることができます。 それ以外の場合、すべての船体の頂点は隣接する共線性または冗長性によって「保護」されるため、ボルナは削除に関係なく常に無制限を回避できます。 

### なぜ効果があるのか

 多項式の有界性は、線形関数が存在するかどうかにのみ依存します。$ap+bq$このような方向により 1 つの単項式が漸近的に優勢になるため、 は指数点間で一意の最小化子を持ちます。 凸包の頂点は、ある方向の候補ミニマイザーに正確に対応します。 頂点が厳密に凸である場合、その頂点のみに接触する支持線が存在します。 これを削除すると、新たに露出した頂点が露出したり、隣接する方向に一意性が作成されたりする可能性があります。 アルゴリズムは、1 回の削除後にそのような暴露が可能かどうかをチェックします。 単一の点を削除することによって頂点を一意に公開できない場合、すべての方向に少なくとも極値点間の関係があり、無制限の発散が防止されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])

def build_hull(points):
    points = sorted(points)
    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)
    return lower

n = int(input())
pts = []
for i in range(n):
    a, b = map(int, input().split())
    pts.append((a, b, i))

# work with (a,b)
simple_pts = [(a, b) for a, b, _ in pts]

hull = build_hull(simple_pts)

if len(hull) <= 2:
    print("Ani")
    sys.exit()

# check strict convexity
def is_collinear(a, b, c):
    return cross(a, b, c) == 0

m = len(hull)
strict_vertex = False

for i in range(m):
    a = hull[i-1]
    b = hull[i]
    c = hull[(i+1) % m]
    if cross(a, b, c) != 0:
        strict_vertex = True
        break

print("Ani" if strict_vertex else "Borna")
```コードはまず、指数点の単調な下方包を構築し、極値の動作に無関係な内部点を破棄します。 次に、ハルに厳密に凸状の頂点が含まれているかどうかをチェックします。 このような頂点は、除去後に単一の点が一意に極値となり得るサポート方向の存在を示しており、まさにアニの勝利条件となります。 

船体サイズが最大 2 の短絡ケースでは、意味のある凸構造が存在しない縮退ジオメトリが処理されます。 そのような場合、Ani は削除後にいつでも無制限を強制できます。
