### なぜ効果があるのか

 各ペア$(a, b)$正確に 1 つの残基を提供します$a + b \bmod M$。 固定する$a$、可能な合計のセットは補集合の変換です。 したがって、全体にわたる組合$a$は、翻訳された補数区間の和集合です。 補数自体は、まさに、次の連続する要素間の互いに素な巡回ギャップの結合です。$A$したがって、すべての寄与は区間の変換に分解されます。 アルゴリズムはこれらの翻訳された区間の和集合を正確に追跡するため、どの翻訳にもカバーされない残差はあり得ませんが、少なくとも 1 つの翻訳によってカバーされた残差は達成可能です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, M = map(int, input().split())
    A = list(map(int, input().split()))
    
    # Build complement gaps on the circle
    gaps = []
    
    # gap between consecutive elements
    for i in range(N - 1):
        if A[i] + 1 <= A[i + 1] - 1:
            gaps.append((A[i] + 1, A[i + 1] - 1))
    
    # circular gap
    if A[-1] + 1 <= M - 1 or 0 <= A[0] - 1:
        start = A[-1] + 1
        end = A[0] - 1 + M if A[0] > 0 else A[0] - 1
        # normalize into [0, M)
        for x in range(start, M):
            gaps.append((x, x))
        for x in range(0, A[0]):
            gaps.append((x, x))
    
    # difference array over residues
    diff = [0] * (M + 1)
    
    # apply all translations
    for a in A:
        for l, r in gaps:
            l2 = (a + l) % M
            r2 = (a + r) % M
            if l2 <= r2:
                diff[l2] += 1
                diff[r2 + 1] -= 1
            else:
                diff[l2] += 1
                diff[M] -= 1
                diff[0] += 1
                diff[r2 + 1] -= 1
    
    cur = 0
    bad = []
    for i in range(M):
        cur += diff[i]
        if cur == 0:
            bad.append(i)
    
    print(len(bad))
    if bad:
        print(*bad)

if __name__ == "__main__":
    solve()
