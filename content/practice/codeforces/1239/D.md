 ## 解決策
 ## 問題の理解

 私たちには次のようなシステムが与えられています$n$それぞれが 1 匹の猫を飼っている人々は、自然なペアリングを形成します。$i$そして猫$i$。 この構造に加えて、人と猫の間には方向のない二者関係が存在します。各入力エッジは居住者と猫を結び付けます。$a$猫と一緒に$b$, つまり、その住人はその猫のことをよく知っているということになります。 

すべてのインデックスを分割する必要があります$1 \ldots n$空でない 2 つのグループに分けます。1 つは審査員となる住民のグループ、もう 1 つは出場者となる猫のグループです。 審査員全員が、出場者グループの猫のことをよく知っていてはなりません。 この 2 つのグループは、禁断の知人としての縁が交わらないという意味で、ばらばらでなければなりません。 さらに、すべての居住者と猫は 2 つのグループのいずれかに属している必要があり、両方のグループが空であってはなりません。 

したがって、タスクは、すべてのエッジが陪審員から陪審員側、または出場者から出場者側に向かい、両側に少なくとも 1 つの頂点が含まれるように、左側 (住民) と右側 (猫) で頂点のパーティションを見つけることです。 

これは 2 部グラフでのグラフ分割の問題ですが、強い制約があります。住人が陪審員セットに含まれている場合、その住人が知っているすべての猫も出場者セットから除外する必要があります。 対称的に、出場者に選ばれた猫を陪審員の居住者と結び付けることはできません。 

グラフの観点から見ると、陪審員の居住者から出場者の猫までエッジが交差しないように、頂点を 2 つのセットに分割したいと考えています。 

制約は大きく、両方とも$n$そして合計$m$テストケース全体で最大$10^6$。 これにより、クエリごとに二次的な BFS/DFS や繰り返しの BFS/DFS が即座に排除されます。 ソリューションは、テスト ケースごとのグラフのサイズが線形である必要があります。 

グラフが密すぎるか、居住者とすべての猫の間で完全に接続されている場合、微妙な失敗のケースが発生します。 たとえば、すべての居住者がすべての猫に接続されている場合、空でない分割により禁止された交差エッジが作成され、答えが不可能になります。 頂点が保証エッジ内でそれ自体からのみ分離されている場合、別の失敗が発生します。 両側が空ではない必要があるため、これだけでは有効な分割を作成するには十分ではありません。 

主な困難は、通常の意味での接続性を検出することではなく、両方の部分が空でないことを許容しながら、二部分の制約を尊重する構造的な分離を見つけることです。 

## アプローチ

 ブルートフォース手法では、各頂点を陪審員または出場者のいずれかに割り当て、条件に違反するエッジがあるかどうかをチェックしようとします。 これはすべてを試すのと同じです$2^n$割り当ては明らかに不可能です$n = 50$、ましてや$10^6$。 

より構造化された試みは、これを制約充足問題として解釈することです。各エッジはペア (審査員の常駐、競技者の猫) を禁止します。 これは、各頂点が 2 つの選択肢を持つ 2-SAT スタイルの定式化を示唆しています。 ただし、2-SAT を明示的に構築して解決するには、$2n$変数と$m$制約は不必要かつ重すぎます。 

重要な観察は、状況が単調であるということです。住人を陪審員に加えた場合、一部の猫が出場者セットに入るのを禁止することになりますが、それらの猫は陪審員側に強制的に入れられます。 この伝播は対称的です。 グラフは、暗黙的な有向構造全体にわたる到達可能性の制約を効果的に定義します。 

住人から始めて陪審員に入れようとすると、その住人に隣接するすべての猫も陪審員側に移さなければなりません。 それらの猫は今度は住民に制約を課します。 これは古典的な到達可能性クロージャの問題です。開始頂点を 1 つ選択したら、交互のエッジの下でクロージャを展開します。 

これにより、問題は導出された含意グラフ内の連結成分を見つけることに軽減されます。 各頂点が辺を決定し、制約がエッジを介して伝播します。 唯一の有効なパーティションは、この含意構造内の接続されたコンポーネント全体の結合です。 目標は、サイズが厳密に 0 と 2 の間のコンポーネントを見つけることです。$n$、両側が空でないことを確認します。 

任意の開始頂点から BFS/DFS を使用してこのクロージャーを構築し、居住者と猫を単一の 2 部グラフ内のノードとして扱うことができます。 住人からは隣接するすべての猫に移動し、猫からはその固有の住人である飼い主に移動します。 これにより、グラフ内に各猫がその飼い主とその隣人のみに接続する接続コンポーネントが生成されます。 

この成分を計算したら、それを一方の側として、その補数をもう一方の側として取得するか、非自明な分割は存在しないと結論付けるかのいずれかになります。 この不可能性は、グラフ全体が単一の到達可能なコンポーネントに崩壊する場合、または両側が空でない有効な部分コンポーネントが存在しない場合に発生します。 

これにより、線形時間グラフ走査ソリューションが得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^n \cdot m)$|$O(n)$| 遅すぎる |
 | コンポーネント BFS/DFS |$O(n + m)$|$O(n + m)$| 承認済み |

 ## アルゴリズムのチュートリアル

 グラフを構築します$2n$ノードは住民と猫を別々に表しますが、遷移を効率的にエンコードします。 

1. 指定された友情エッジを使用して、居住者から猫までの隣接リストを構築します。 これは制約を直接表します。 
2. 入居者一人ひとりに対して$i$、猫も接続します$i$居住者へ$i$。 これにより、所有権リンクがトラバーサルの一部となり、2 つのパーティション間の移動が可能になります。 
3. 任意の常駐ノード (ノード 1 など) から開始して DFS または BFS を実行します。トラバーサル中に、到達可能なすべての常駐ノードと猫をマークします。 このセットは、制約の伝播下にある 1 つの連結コンポーネントを表します。 
4. 走査後、このコンポーネントにすべての居住者とすべての猫が含まれているかどうかを確認します。 「はい」の場合、すべての頂点が同じクロージャに強制的に入れられ、空でない補体が残らないため、分割はできません。 
5. コンポーネントが自明でない場合、それを 1 つのグループとして出力し、その補数をもう 1 つのグループとして出力します。 具体的には、どちらが空ではない有効なセットを生成するかに応じて、コンポーネント内のすべての居住者を陪審員とし、コンポーネント内のすべての猫を出場者として採用することができます (またはその逆)。 

重要なのは、条件に違反するエッジがすでに両方のエンドポイントを同じクロージャに強制しているため、トラバーサルによって、選択したセット間で禁止エッジが交差しないことが保証されるということです。 

### なぜ効果があるのか

 DFS は 2 つのルールに基づいて閉鎖を定義しています。1 つは居住者が隣の猫を引き寄せる、もう 1 つは猫が飼い主を引き寄せるというものです。 このクロージャにより、あらゆる制約チェーンが単一のコンポーネント内に完全に含まれることが保証されます。 有効な割り当てでは、この含意グラフの接続コンポーネント内のすべての頂点を一貫して割り当てる必要があります。 したがって、自明でないコンポーネント分割は有効な分割を与え、そのような分割が存在しない場合、グラフは単一の強制コンポーネントを形成し、解は存在しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())

        adj = [[] for _ in range(2 * n + 1)]

        # nodes: 1..n = residents, n+1..2n = cats
        def cat(x): return n + x

        for i in range(1, n + 1):
            adj[i].append(cat(i))
            adj[cat(i)].append(i)

        for _ in range(m):
            a, b = map(int, input().split())
            adj[a].append(cat(b))
            adj[cat(b)].append(a)

        vis = [False] * (2 * n + 1)
        stack = [1]
        vis[1] = True

        while stack:
            u = stack.pop()
            for v in adj[u]:
                if not vis[v]:
                    vis[v] = True
                    stack.append(v)

        jury = []
        cats = []

        for i in range(1, n + 1):
            if vis[i]:
                jury.append(i)
        for i in range(1, n + 1):
            if vis[cat(i)]:
                cats.append(i)

        if not jury or not cats:
            print("No")
        else:
            print("Yes")
            print(len(jury), len(cats))
            print(*jury)
            print(*cats)

if __name__ == "__main__":
    solve()
```このコードは、各居住者が自分の猫とすべての既知の猫に接続する 2 部構成の含意グラフを構築します。 ノード 1 の DFS は強制クロージャを計算します。 結果として得られる訪問者セットは、審査員と出場者のグループを直接形成するために使用されます。 どちらかの側が空の場合、有効なパーティションは存在しません。 

微妙な実装ポイントは、cat のインデックス作成の変更です。 猫を次のように扱う$n + i$衝突のない単一の統合されたグラフを保証します。 もう 1 つの重要な点は、有効な解決策は 1 つの重要なクロージャを識別するだけでよいため、複数のコンポーネントを試行しないことです。 最初のコンポーネントが自明な場合、問題の構造により、代替分割が存在しないことが保証されます。

 ## 特殊なケース

 ミニマルなケース付き$n=1$そして、保証されたセルフエッジのみが、両側を完全にオーバーラップさせます。 DFS は Resident 1 と Cat 1 にのみ到達するため、有効な分割では両方のセットを同時に空にすることはできず、「いいえ」になります。 

すべての居住者がすべての猫に接続されている完全接続の場合、任意のノードから DFS を開始すると、すぐにすべてのノードにアクセスします。 このアルゴリズムはすべてをカバーする単一のコンポーネントを生成するため、両側を分離することはできず、正しく「いいえ」となります。 

一部の居住者がローカルでのみ接続する疎なグラフでは、DFS が早期に停止し、適切なサブセットが生成されます。 そのサブセットは一方の側を形成し、その補集合はもう一方の側を形成し、未訪問のコンポーネントと訪問済みのコンポーネントの間に交差エッジが存在しないため、すべての制約が満たされます。
