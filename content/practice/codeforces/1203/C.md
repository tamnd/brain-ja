 ## 解決策
 ## 問題の理解

 与えられた配列内のすべての数値を均等に分割する正の整数の数を見つけるように求められます。 配列には最大 400,000 個の要素を含めることができ、それぞれの要素の大きさは次のとおりです。$10^{12}$。 概念的には、すべての配列要素の公約数のセットを探しています。 

出力は単一の整数、つまりこれらの約数の数です。 たとえば、次のような配列では、`[2, 4, 6, 2, 10]`、数字`1`そして`2`すべての要素を分割すると、答えは次のようになります。`2`。 

制約は私たちのアプローチに即座に影響を与えます。 以来`n`は 4·10^5 であり、各数値は 10^12 までであるため、すべての数値を最大要素まで反復して割り算をチェックする余裕はありません。 素朴な解決策では、次までの反復が必要になります。`10^12`配列要素ごとに実行されますが、これは不可能です。 複雑さが数値そのものではなく、数値の約数の数に依存するアプローチが必要です。 

配列に次のものが含まれる場合、微妙なエッジケースが発生します。`1`。 何らかの要素がある場合、`1`、唯一の公約数は`1`。 同様に、すべての要素が同じ場合、答えはその数の約数の数になります。 大きな素数を含む配列も、約数が限られているため、問題が発生します。 不用意なソリューションは、最大公約数ではなく配列サイズに基づいて範囲を反復処理し、誤った動作や非効率な動作を引き起こす可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、次のすべての整数をチェックしようとします。`1`すべての要素を分割するものを数えて、配列内の最小の要素まで。 これは正しいです。公約数は最小の数を超えることができないからです。 ただし、最悪の場合、最小数は次のとおりになる可能性があります。$10^{12}$、各数値の割り算のテストが遅すぎます。 操作数はおおよそ次のようになります。$10^{12} \cdot n$、2秒では決して収まりません。 

重要な観察は、配列の公約数のセットが、すべての要素の最大公約数 (GCD) の約数のセットと正確であるということです。 これは、GCD を分割する数値は配列の各要素を自動的に分割し、逆に、配列のすべての要素を分割する数値は GCD を分割するためです。 すべての数値の GCD の計算は、非常に大きな数値であっても、ユークリッド アルゴリズムを使用して効率的に実行できます。 GCD がわかったら、あとはその約数を数えるだけです。 約数を最大まで数えます$\sqrt{g}$平方根を超えて反復することなく、すべての約数のペアを考慮することが保証されます。 

この観察により、問題は、潜在的に巨大な検索スペースから、操作がほぼ次の値に比例する、管理可能なものに軽減されます。$n \log(\text{max element})$GCD 計算用と$O(\sqrt{g})$約数を数えるために。

 ## アルゴリズムのチュートリアル

 1. 入力から配列を読み取り、要素をリストに格納します。 これは、すべての要素の GCD を計算するために必要です。 
2. 変数を初期化する`g`最初の要素で。 これにより、実行中の GCD が保存されます。 
3. 配列の残りの要素を繰り返し処理します。 要素ごとに`a[i]`、 アップデート`g`の GCD として`g`そして`a[i]`ユークリッドアルゴリズムを使用します。 このステップにより、ループの最後で次のことが保証されます。`g`配列全体の GCD です。 
4. カウンタの初期化`count`ゼロに。 これは、約数の数を追跡します。`g`。 
5. すべての整数を反復処理する`d`から`1`の整数の平方根に`g`。 それぞれについて`d`、どうかを確認してください`g % d == 0`。 true の場合、インクリメントします`count`1によって`d`は約数です。 
6. 各約数について`d`それは等しくありません`g // d`、増分`count`ペアの約数を考慮して 1 ずつ加算します。 このステップにより、完全正方形を二重にカウントしないことが保証されます。 
7. の値を出力します。`count`、これは、配列のすべての要素を分割する正の整数の数です。 

機能する理由: ここでの不変条件は、GCD のどの約数も配列内のすべての数値を除算するということです。 逆に、すべての要素を除算する数値は GCD を除算します。 の平方根まで繰り返すことにより、`g`そして、各約数のペアをカウントすることで、すべての公約数が正確に 1 回カウントされることが保証されます。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

g = a[0]
for num in a[1:]:
    g = math.gcd(g, num)

count = 0
sqrt_g = int(g**0.5)
for d in range(1, sqrt_g + 1):
    if g % d == 0:
        count += 1
        if d != g // d:
            count += 1

print(count)
```コードは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`Python の組み込み関数を使用して GCD を計算します。`math.gcd`。 すべての約数を重複することなく効率的にカウントするために、平方根まで約数をループします。 小切手`d != g // d`完全平方を正しく処理できるようになります。

## テストケース```python
import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    g = a[0]
    for num in a[1:]:
        g = math.gcd(g, num)
    count = 0
    sqrt_g = int(g**0.5)
    for d in range(1, sqrt_g + 1):
        if g % d == 0:
            count += 1
            if d != g // d:
                count += 1
    return str(count)

# Provided sample
assert run("5\n1 2 3 4 5\n") == "1", "sample 1"

# All equal numbers
assert run("4\n6 6 6 6\n") == "4", "all equal"

# Single element
assert run("1\n10\n") == "4", "single element divisors"

# Large prime numbers
assert run("3\n17 34 51\n") == "2", "common divisors of 17,34,51"

# Perfect squares
assert run("3\n16 32 48\n") == "5", "divisors of 16"

# Mixed small and large numbers
assert run("5\n1 1000000000000 500000000000 250000000000 125000000000\n") == "1", "only 1 divides all"
