 ## 解決策
 ## 問題の理解

 位置と値の両方が重要となる、エッセイの順列のような文書を表す配列が与えられています。 インデックス i の値は、現在そこに配置されているエッセイのラベルです。 ライバルは任意の 2 つの位置間で任意のスワップを実行することができ、最終的な構成に値が i に等しいインデックス i を持たないよう配列を変更することが目標です。 言い換えれば、固定点をすべてなくしたいということです。 

このプロセスは、スワップがカウントされるという意味でのみ対話的ですが、最終的な要件は静的です。一定回数のスワップを実行した後、配列はそれ自体の乱れになる必要があります。つまり、すべての位置 i が a[i] ≠ i を満たさなければなりません。 それが不可能な場合には、その旨を報告しなければなりません。 

制約により、テスト ケースごとに線形または線形に近い解決策が強制されます。 すべてのテスト ケースにわたる n の合計は最大 10^5 であるため、テスト ケースあたり O(n^2) の解はすぐに失敗します。 重い定数を含む O(n log n) であっても許容されますが、スワップの構造は、O(n) で推論できる必要があることを強く示唆しています。 

重要な微妙な点は、スワップに制限がないため、時間の経過とともにプロセスを追跡するのではなく、有効な混乱に達するために必要な最小限のスワップ数を要求することです。 もう 1 つの微妙な点は、初期配列がすでに条件を満たしている可能性があり、その場合は操作が必要ないことです。 

主なエッジケースは強制固定点を中心に展開します。 インデックス i が a[i] = i を満たし、別の固定点を作成せずにその値を移動する方法がない場合、答えは不可能になります。 最小限の例は、[1, 1, 1] のような配列です。この配列では、すべてのスワップで位置 1 に少なくとも 1 つの 1 が保持され、固定小数点を削除できなくなります。 

## アプローチ

 ブルートフォース解釈では、各状態を完全な配列構成として扱い、各移動を任意の 2 つのインデックス間のスワップとして扱います。 任意の構成から、すべての O(n^2) 個の可能なスワップを生成し、固定点のない構成に到達するまで BFS または最短パス検索を実行できます。 正しいとはいえ、このアプローチはすぐに爆発します。 状態空間は n! であり、分岐係数 O(n^2) であっても完全に実行不可能です。 

重要な観察は、実際に検索しているのは順列ではなく、特定の値を禁止された位置に配置することを回避できるかどうかであるということです。 各インデックス i は、最終的な配置の位置 i での値 i を禁止します。 スワップでは任意の並べ替えが可能であるため、唯一の障害は構造上の制約によって生じます。避けられない方法でその位置にあまりにも多くの値が「ロック」されている場合、失敗します。 

決定的に単純化するのは、ポジションがすでに安全か安全でないかによってポジションを分類し、その後、スワップによって安全でない固定点をすべて排除できる方法を推論することです。 a[i] = i の位置 i は、i を別の場所に移動することで破らなければならない制約ですが、その移動は、i に移動する別の要素によってバランスが取られる必要があります。 これによりペア構造が作成されます。非固定位置から十分な柔軟性がない限り、固定点はペアで解決する必要があります。 

問題は、すべての固定点を削除できるかどうかを確認し、削除できる場合は、すべての固定点を確実に削除するために必要なスワップの数を計算することに集約されることがわかりました。 各スワップで修正できる問題のある位置は最大 2 つですが、これは固定点ではない、またはバッファとして使用できる十分な「空き」要素がある場合に限られます。 

最適な推論は、固定点を数えることと、配列が既に乱れているか、少なくとも 1 つの非固定要素を使用して対称性を破ることができるようなインデックス i が少なくとも 1 つ存在するかどうかを判断することに帰着します。 スワップの最小数は固定小数点の数と密接に関係していますが、配列が完全に固定小数点で占められているかどうかによって制限されます。

 ## アルゴリズムのチュートリアル

 1. 配列をスキャンし、a[i] = i となるすべてのインデックス i を特定します。 これらは強制的な制約であり、削除する必要があります。 
2. 固定点がない場合、配列はすでに条件を満たしているため、答えは 0 になります。これは、演算が必要ない唯一のケースです。 
3. 固定点が 1 つだけ存在する場合、別の固定点を作成せずにスワップを使用してそれを削除することは不可能です。その位置に関係するスワップにより、どこか別の場所に新しい等価性が導入されるからです。 
4. 複数の固定点がある場合は、すべての固定点を解除するために必要なスワップの数を計算します。 各スワップでは、2 つの不良ポジションを交換することで、最大 2 つの固定点を除去できます。 
5. したがって、スワップの最小数は固定点の数の半分の上限ですが、構造がペアリングを許可する場合に限ります。ペアリングが許可されるのは、少なくとも 2 つの固定点があり、すべてのポジションが固定点であるわけではない場合です。 
6. 不可能条件がトリガーされない限り、計算値を出力します。 

### なぜ効果があるのか

 固定点 i = a[i] は、順列構造における長さ 1 の自己完結型サイクルを表します。 スワップ操作は、サイクルの切断と再接続に対応します。 すべての固定小数点サイクルを削除するには、各シングルトン サイクルを分割し、それ自体にマップされる要素が存在しない、より大きなサイクルにマージする必要があります。 1 回のスワップで要素を交換することで最大 2 つのシングルトン サイクルを削除でき、固定点の数を操作ごとに最大 2 つ削減できます。 シングルトン サイクルが 1 つだけ存在する場合、それとペアとなる 2 番目のサイクルは存在せず、それを移動しようとすると必ず別の場所に新しいシングルトンが作成され、少なくとも 1 つの固定点が残るという不変条件が維持されます。 この不変条件により、完全な削除が妨げられます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        fixed = 0
        for i in range(n):
            if a[i] == i + 1:
                fixed += 1
        
        if fixed == 0:
            out.append("0")
        elif fixed == 1:
            out.append("-1")
        else:
            out.append(str((fixed + 1) // 2))
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```このソリューションは各テスト ケースを個別に処理し、単一のリニア スキャンで固定点をカウントします。 重要な決定は、値がインデックスと等しい位置の数に完全に基づいています。 

大文字と小文字の区別は不可欠です。 ゼロ固定点は操作が必要ないため、すぐにゼロを返します。 スワップでは単一の孤立した制約を除去できないため、厳密に 1 つの固定点を解決することは不可能です。 2 つ以上の場合、各スワップは 2 つの固定点をペアにしてそれらを一緒に解決すると見なすことができ、これはシーリングハーフ式に直接つながります。 

整数の除算`(fixed + 1) // 2`浮動小数点演算を行わずにペアリング ロジックをクリーンにエンコードします。 

## 実用的な例

 一部の位置がすでに正しく、他の位置が正しくない配列を考えてみましょう。 

入力：```
n = 5
a = [1, 2, 4, 3, 5]
```固定小数点を計算します。 

| 私 | a[i] | 修理済み？ | 残りは固定 |
 | --- | --- | --- | --- |
 | 1 | 1 | はい | 1 |
 | 2 | 2 | はい | 2 |
 | 3 | 4 | いいえ | 2 |
 | 4 | 3 | いいえ | 2 |
 | 5 | 5 | はい | 3 |

 固定点は3箇所あります。 アルゴリズムは (3 + 1) // 2 = 2 スワップを出力します。 

これは、孤立した固定点はペアにできるが、奇数の残り物には非固定要素を含む追加のスワップが必要であることを示しています。 

2 番目の入力:```
n = 4
a = [1, 1, 3, 4]
```| 私 | a[i] | 修理済み？ | 残りは固定 |

 | 3 | 3 | はい | 2 |

 ここでも固定点が 3 つあるため、結果は 2 になります。トレースは、位置 2 が固定されていないにもかかわらず、奇数の固定小数点カウントを解決するためのバッファとして関与していることを示しています。

 | 測定 | 複雑さ | 説明 |

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    res = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        fixed = sum(1 for i in range(n) if a[i] == i + 1)
        if fixed == 0:
            res.append("0")
        elif fixed == 1:
            res.append("-1")
        else:
            res.append(str((fixed + 1) // 2))
    return "\n".join(res)

# sample-like cases
assert run("1\n5\n1 2 4 3 5\n") == "2"

# minimum size
assert run("1\n1\n1\n") == "-1"

# already deranged
assert run("1\n3\n2 3 1\n") == "0"

# all fixed
assert run("1\n4\n1 2 3 4\n") == "2"

# single fixed in larger array
assert run("1\n4\n1 3 2 4\n") == "-1"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | n=1 すべて固定 | -1 | 単一の固定小数点は不可能 |
 | 完璧な錯乱 | 0 | 操作は必要ありません |
 | 恒等置換 | 2 | すべての固定点のペア |
 | 混合ケース | -1 | 分離された固定小数点の処理 |

 ## 特殊なケース

 最小のケース n = 1 は、不可能条件を直接明らかにします。 単一要素の場合、それが固定されている場合、交換する 2 番目の位置がないため、少なくとも 1 つの固定点が残るという不変条件を破ることはできません。 アルゴリズムは、fixed = 1 の場合に正しく -1 を返します。 

[2, 3, 1] のような場合、不動点はまったくありません。 スキャンでは a[i] = i + 1 に一致するものが見つからないため、アルゴリズムはスワップ推論を試行せずに 0 を返します。 これにより、ソリューションが不必要な操作を過剰にカウントしていないことが確認されます。 

[1, 2, 3, 4] のようなすべて固定の配列の場合、カウントは 4 で、式の結果は 2 になります。実行では、各スワップで 2 つの固定点をペアにすることで 2 つの固定点を削除でき、2 回のスワップ後にシングルトンが残らないことが反映されます。
