 ## 解決策
 ## 問題の理解

 私たちは与えられています$n$整数線上のどこかに配置された独立したダンサー。 各ダンサーはある整数座標から開始し、同時に左右に 1 歩ずつ移動します。それぞれの方向は確率で独立して選択されます。$1/2$。 

このランダムな動きが発生する前に、ダンサーの初期位置を任意に選択することができます。 すべてのダンサーが動いた後、最終的なポジションの複数のセットを確認します。 最終位置のマルチセットが最初のマルチセットと同一である場合、その動きは「クレイジー」と呼ばれます。つまり、すべての整数座標について$x$、のダンサーの数$x$移動前と移動後は全く同じです。 

タスクは、このイベントの確率が最大化されるように、ダンサーの初期構成を選択することです。 出力は確率そのものではなく、$\log_2(\text{ans})$, ここで、ans は最大確率です。 イベントが不可能な場合、出力はゼロとして定義されます。 

主な制約は$n \le 40000$、各構成にはすでに$2^n$可能性。 すべてのダンサーの状態を保存することさえ問題ありませんが、推論では、確率的なシミュレーションではなく、構造化された構成のカウントに問題を分解する必要があります。 

微妙なエッジケースが現れるのは、$n = 1$。 1 人のダンサーが常に異なる位置に移動するため、マルチセットが変更されないままであることは不可能です。 確率はゼロであり、出力もゼロでなければなりません。 対数を含む式は、明示的に次の計算を避ける必要があります。$\log 0$。 

もう 1 つの明白ではない問題は、初期配置が異なると確率も異なる可能性があり、最適な配置は均一な間隔ではないことです。 たとえば、位置の同一性は移動後の衝突やペアリングによってのみ重要となるため、すべてのダンサーを大きな間隔で一列に配置することは役に立ちません。 

## アプローチ

 重要な困難は、すべてのダンサーが左または右に移動した後でも、複数の占有位置が変化しないようにするには、どのような構造が存在する必要があるかを理解することです。 直接的なアプローチでは、すべてが考慮されます。$2^n$移動の結果を確認し、マルチセットが保存されているかどうかを確認しますが、1 つの構成を評価するだけでもコストがかかります$O(n)$、与える$O(n2^n)$、それは完全に不可能です。 

より構造的なビューが役に立ちます。 各ダンサーは次のいずれかを提供します$+1$または$-1$変位。 マルチセットが変更されないようにするには、すべての位置$x$最初の居住者と同じ数の到着者を受け入れなければなりません。 これにより、ダンサーの完全な「再ラベル付け」が強制されます。すべての元のポジションは、カウントを正確に保持する方法で、その占有者を隣接するポジションにマッピングする必要があります。 

これはフローのようなペアリング制約になります。 各ダンサーの位置$x$カウントを変更せずに左右の結果を交換できるように、別のダンサーとマッチングする必要があります。 重要な観察は、対称的なペアのみが有効な構成に寄与するということです。 有効な構成では、すべての左の動きが右の動きと一致し、同一の再配分構造が生成されるようにダンサーを配置する必要があります。 これは本質的に、動作の一貫性の独立した 2 サイクルへの分解を強制します。 

このように再定式化すると、問題は、初期位置を選択することによって強制できる独立ペア制約の数を最大化することに帰着します。 各ペアは固定の確率係数に寄与するため、最適な戦略はダンサーを最適にペアにすることです。 同じ座標に配置された 2 人のダンサーは、互いの動きを局所的に打ち消すことができるため、バランスを維持できる可能性が高くなります。 

一定のサイズのグループの場合$k$1 つの座標に配置されると、有効なバランスの取れた結果の数は二項対称性によって決まります。最良の構成は、ダンサーをペアにグループ化し、シングルトンが 1 つ以下であることです。$n$奇数です。 各ペアは次の係数に寄与します。$1/2$4 つの関節移動結果のうちちょうど 2 つがローカルでカウントの等しさを維持するためです。 

したがって、最適な配置はペアの数を最大化することです。これは単純に次のようになります。$\lfloor n/2 \rfloor$。 各ペアは確率に寄与します$1/2$一方、ペアになっていないダンサーは慎重に扱わない限りイベントを不可能にし、孤立しない限り確率を事実上ゼロに下げます。 

最大確率は次のようになります。$$\text{ans} = 2^{-\lfloor n/2 \rfloor}$$それで$$\log_2(\text{ans}) = -\lfloor n/2 \rfloor.$$のために$n = 1$、確率はゼロであり、明示的にゼロを出力します。

 ## アルゴリズムのチュートリアル

 問題を、形成できる独立したキャンセルペアの数を計算することに集約します。 

1. もし$n = 1$、単一のダンサーが移動後に常に位置を変更するため、マルチセットの等価性は不可能であるため、すぐに 0 を返します。 
2. のために$n \ge 2$、ダンサーをペアにグループ化することとして最適な構成を解釈します。 各ペアは、ランダムな移動後にローカル バランスを維持するかどうかという点で独立して動作します。 ペアリングが重要な理由は、2 人のダンサーが一方が左に移動し、もう一方が右に移動すると、互いのディスプレイスメント効果を打ち消すことができるためです。 
3. コンピューティング$k = \lfloor n/2 \rfloor$。 これは、形成できる素のペアの最大数です。 
4. 各ペアは、次の乗算確率係数に寄与します。$1/2$、関節の動きの結果のちょうど半分が、局所的に必要な対称性を維持するためです。 
5. 確率の合計は次のようになります。$2^{-k}$したがって、必要な出力は次のようになります。$\log_2(2^{-k}) = -k$。 

### なぜ効果があるのか

 重要な不変条件は、有効な構成において、マルチセット カウントを保持すると、ダンサーがペアでマッチングされ、その変位結果が全体としてキャンセルされることです。 独立したペアに分解できない構成では、ある位置で正味の流れに非対称性が生じ、移動後のカウントの等価性が必然的に崩れます。 各独立したペアは 1 つのバイナリ制約 (左右の一貫性) にのみ寄与するため、確率を最大化することは、そのような独立した制約の数を最大化することと同等であり、これはできるだけ多くのダンサーをペアにすることによって達成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input().strip())

if n == 1:
    print(0)
else:
    print(-(n // 2))
```実装では、派生した式を直接エンコードします。 唯一の特殊なケースは、$n = 1$ここで、ゼロ確率の対数はモデルでは定義されておらず、ステートメントによって強制的にゼロに設定されます。 

部門$n // 2$独立したキャンセル ペアの最大数を取得します。 Python は大きな整数 n を簡単に処理し、オーバーフローやモジュラー演算が関与しないため、整数の除算は安全です。

 ## 特殊なケース

 のために$n = 1$の場合、アルゴリズムは 0 を直接出力します。これは一般的な公式をバイパスします。$\log_2(0)$は未定義です。 チェックは一定時間行われ、正確性が保証されます。 

のために$n = 2$の場合、アルゴリズムは 1 つのペアを計算し、-1 を返します。 これは、独立したキャンセル制約が 1 つだけ存在するという解釈と一致します。 

奇数の場合$n$、 のような$n = 5$の場合、アルゴリズムは整数の除算を使用して 2 つのペアを形成し、ペアになっていない 1 つのダンサーは最適な構造内で概念的に未使用のままになります。 有効なキャンセル構造に寄与するのは完全なペアのみであるため、出力はペアリングの解釈と一貫性を保ちます。
