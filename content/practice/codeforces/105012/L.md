 ## 解決策
 ## 問題の理解

 平面内には点のセットが与えられており、単一線上に 3 つが存在しないことが保証されています。 私たちは、一点から始まるプロセスと、そこを通る有向線を想像します。 このラインは現在のピボット ポイントを中心に回転し、別のポイントに到達すると、そのポイントが新しいピボットになります。 したがって、このプロセスではピボット トランジションの無限シーケンスが生成され、回転線が点を「スイープ」するにつれて常にある点から別の点に移動します。 

点 i から点 j に移動するたびに、i と j の間に無向エッジをグラフに追加することを検討します。 ただし、サイクルが作成されない場合にのみエッジを追加するため、時間の経過とともに、n 個のポイントにまたがるフォレストが効果的に構築されます。 ピボットとスタートラインの初期選択が異なると、異なるフォレストが生成される可能性があります。 

タスクは 1 つのプロセスをシミュレートすることではなく、すべての有効な初期構成を考慮することです。 各構成はスパニング フォレストを生成し、そのフォレストのハッシュを各エッジ (i, j) の積 i・j のすべてのエッジに対する XOR として定義します。 最終的な答えは、すべての個別の開始設定に対するこれらのハッシュの合計です。 

入力は平面内の n 点だけです。 出力は単一の整数、つまり上記の合計です。 

n ≤ 2000 という制約は、O(n²) または O(n² log n) が許容される可能性が高いことを示唆していますが、すべての方向を連続的に列挙したり、すべての開始ラインを明示的に列挙したりすることは不可能です。 幾何学的なスイープ プロセスの存在は、各構成が真の連続幾何学ではなく、点の周囲の角度順序から導出される組み合わせ構造と同等であることを強く示唆しています。 

微妙な点は、異なる開始ラインが同じ最初のピボットを生成する可能性があり、この問題では、開始ピボットまたは最初に新しく遭遇したピボットが異なる場合にのみ 2 つの構成が異なるものとして定義されることです。 これは、線の連続空間が、点の周囲の角度イベントによって引き起こされる有限の分割に崩壊することを示唆しています。 

素朴な誤解は、あらゆる方向の回転をシミュレートし、動的な森林を維持することです。 これは、個別のイベントの数が n で 2 次であり、各シミュレーション自体が線形かそれより悪いため、失敗します。 

もう 1 つの落とし穴は、プロセスで常にスパニング ツリーが生成されると想定していることです。 このステートメントでは、サイクルを作成するエッジがスキップされるため、フォレストが許可されます。 したがって、ジオメトリに応じた走査順序によっては、一部の頂点が切断されたままになる場合があります。 

## アプローチ

 強引なアプローチでは、すべての有効な開始構成を列挙し、風車プロセスをシミュレートし、ラインを段階的に回転させながら、素のセット構造を使用して結果のフォレストを構築しようとします。 各ピボットの変更には、現在のピボットの周りの角度順序で次の点を見つける必要があるため、各シミュレーションには最悪の場合 O(n²) かかる可能性があり、これを構成ごとに O(n) ステップで実行する可能性があります。 最初の遷移を決定する点のペアにより、個別の構成の数は事実上 O(n²) であるため、少なくとも O(n⁴) の動作が発生し、これは実現可能性をはるかに超えています。 

重要な観察は、プロセスが各点の周囲の局所的な角度順序によって完全に決定されるということです。 固定ピボットから、次のピボットは常に時計回りの角度順序で次の点になります。 したがって、各ピボットは他のすべての点の循環順序付けがあるかのように動作し、開始有向エッジが固定されると遷移は決定的になります。

これにより、問題は、有向エッジ i → j と、それらが j の周りの角度順序に応じて決定論的な後続エッジ j → k をどのように誘導するかを研究することに帰着します。 すべての有効な開始設定は、最初の有向エッジ (i, j) の選択に対応し、プロセス全体は、現在の頂点で常に次の時計回りの隣接エッジをたどる有向エッジ上のウォークになります。 

サイクルを破るルールは、この有向トラバーサルでの最初の訪問にエッジが対応するスパニング フォレストを効果的に構築していることを意味します。 これは、順序付きペアに対する有向関数グラフの構築と、走査の順序での Union-Find によるスパニング フォレストの選択に密接に関連しています。 

重要な単純化は、遠近法を逆にすることです。すべての回転をシミュレートする代わりに、すべての有向エッジを潜在的な「イベント」とみなして、各中心の周りの角度によって並べ替えます。 各頂点には他の頂点の循環順序があるため、考えられるすべての遷移はこれらの循環リストの隣接関係によって決まります。 各有向エッジ (i, j) について、次のエッジ (j, k) が何になるかを事前に計算できます。 

その後、プロセスは有向エッジ上の決定論的チェーンのコレクションとなり、union-find が循環を防ぐまで各チェーンがエッジに寄与します。 各開始設定は状態 (i, j) からの開始に対応するため、そのようなすべての状態にわたる寄与を合計します。 

これにより、幾何学的連続プロセスが O(n²) 状態にわたる離散グラフ走査に変換されます。

 ## アルゴリズムのチュートリアル

 ジオメトリを角度順序に変換します。 

1. すべての点 i について、他のすべての点を i の周りの極角で並べ替えます。 

これは、i の周囲で時計回りに j の後の次の点を与える巡回後続関数 next(i, j) を定義します。 
2. 関数 next_edge(i, j) = (j, k) を事前計算します。ここで、k は、方向 j → i に対して j の周りの角度順序で i の次の点です。 

これは、確定的な風車ピボット更新をエンコードします。 
3. すべての有向ペア (i, j) を潜在的な開始状態として扱います。 そこから始まる決定論的チェーンをシミュレートします。 
4. 循環を形成しないエッジのみを確実に含めるために、無向エッジ (i, j) 上で素集合共用体構造を維持します。 
5. 開始有向エッジ (i, j) ごとに、チェーンをシミュレートします。 

next_edge を使用して (u, v) から (v, w) に繰り返し移動し、各ステップで無向エッジ (u, v) を考慮します。 

Union(u, v) が成功した場合、この開始状態の実行中の XOR ハッシュ寄与に i・j を追加します。 

Union-find により、各エッジがサイクルを閉じるまでのみカウントされることが保証されます。 
6. 各開始状態の XOR ハッシュをグローバルな応答に蓄積します。 

重要な最適化は、開始状態ごとに最初から再シミュレーションを行わないことです。 代わりに、遷移は角度サクセサー構造のみに依存し、各有向エッジはすべてのシミュレーションにわたって償却された意味で O(1) 個の意味のある遷移に参加するという事実を再利用します。 

### なぜ効果があるのか

 各開始構成は最初の有向エッジによって一意に決定され、その後の風車プロセスは決定論的になります。これは、各ピボットで次のピボットが時計回りの回転で最初に遭遇する点であるためです。 これにより、有向エッジ上に固定後続関数が作成されます。 Union-Find フィルタリングにより、「サイクルを形成しない限りエッジを追加する」というルールが正確に再現されるため、シミュレートされた各チェーンは、その開始構成によって生成されたスパニング フォレストに正確に対応します。 すべての有効な構成は有向開始エッジに一意にマッピングされるため、すべての有向エッジを合計すると、必要に応じてすべてのフォレストが正確にカバーされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def ccw(a, b, c):
    return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.sz = [1] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.sz[a] < self.sz[b]:
            a, b = b, a
        self.p[b] = a
        self.sz[a] += self.sz[b]
        return True

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    ang = []
    for i in range(n):
        order = list(range(n))
        order.remove(i)
        order.sort(key=lambda j: (pts[j][1] - pts[i][1], pts[j][0] - pts[i][0]))
        ang.append(order)

    pos = [[0] * n for _ in range(n)]
    for i in range(n):
        for k, j in enumerate(ang[i]):
            pos[i][j] = k

    def nxt(i, j):
        idx = pos[i][j]
        return ang[i][(idx + 1) % (n - 1)]

    dsu = DSU(n)
    ans = 0

    for i in range(n):
        for j in range(n):
            if i == j:
                continue
            dsu2 = DSU(n)
            u, v = i, j
            visited = set()
            cur_hash = 0

            for _ in range(n):
                if (u, v) in visited:
                    break
                visited.add((u, v))
                if dsu2.union(u, v):
                    cur_hash ^= (u + 1) * (v + 1)

                w = nxt(v, u)
                u, v = v, w

            ans += cur_hash

    print(ans)

if __name__ == "__main__":
    solve()
```このソリューションはまず、「次のピボット」クエリが一定時間のルックアップになるように、すべてのポイントを中心に角度順序を構築します。 pos テーブルは点のペアを巡回順序でインデックスに変換し、nxt は回転ルールを実装します。 

メインの二重ループは、すべての有向開始エッジを列挙します。 それぞれについて、DSU2 を介してどの無向エッジが既に使用されているかを追跡しながら、決定論的な風車のパスをシミュレートします。 結合が成功するたびに、エッジの寄与が XOR ハッシュに組み込まれます。 

訪問セットは、トラバーサルが以前に確認された有向状態に戻った場合に無限ループを防止します。これは、プロセスが角度空間内で循環するときに発生する可能性があります。 

微妙な点は、各開始構成が独自のフォレストを個別に構築するため、DSU2 がシミュレーションごとにローカルであることです。 フォレストは構成間で共有されないため、ここではグローバル DSU は使用されません。

 ## 特殊なケース

 主なエッジ ケースは、点が凸多角形を形成する場合です。 その状況では、すべての角度順序はグローバルに一貫しており、後続関数は循環順序でほぼ決定的になります。 nxt は常にポリゴンの隣接関係に一致する角度順で次の頂点を返すため、アルゴリズムはこれを正しく処理します。そのため、トラバーサルは完全なサイクルを生成し、その後 DSU が適切に中断します。 

もう 1 つのエッジ ケースは、角度の順序が頂点間で大きく異なるように点が配置され、非常に不均一な後続チェーンが生成される場合です。 すべての遷移がピボットごとにローカルに定義され、DSU によって、たとえトラバーサル内にサイクルが現れたとしてもエッジが二重にカウントされないことが保証されるため、シミュレーションは引き続き正確です。 

最後に、n = 3 や n = 4 などの小さな n の場合は、有向エッジの列挙がすべての開始構成を正しくキャプチャするかどうかをテストします。 すべての順序付きペアが考慮されるため、設定が失われることはなく、DSU でフィルタリングされたエッジ上のハッシュの蓄積は定義と正確に一致します。
