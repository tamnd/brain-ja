 ## 解決策
 ## 問題の理解

 非常に特殊な特性を満たすルート付きツリーを構築するように求められます。葉以外のノードはそれぞれ、正確に`m`すべてのリーフは正の整数を保持します。 この構造を満たしている場合、そのツリーは「良い」と呼ばれます。 各リーフは、その番号にツリー内の深さを加えた値に等しい値を与え、ツリー全体の値が最大リーフ値になります。 

入力により得られるものは、`n`葉に付けなければならない数字。 私たちの仕事は、これらの数値をリーフに割り当て、リーフの最大値を最小化する方法でツリーを構造化することです。 複数のクエリが続き、それぞれのクエリで配列内の数値が変更され、新しい最小ツリー値が求められます。 

制約は厳しいです。`n`到達できる`2×10^5`そして`q`にも到達できます`2×10^5`つまり、クエリあたり O(n log n) よりも悪いアルゴリズムは遅すぎる可能性があります。 葉の数`n`常に満足する`n ≡ 1 (mod m - 1)`、これは構築に関する重要な組み合わせの事実です。`m`-arytrees - 完全なものであることを保証します。`m`-ary ツリーは正確に形成できます`n`葉。 

素朴なアプローチは、現在の配列に対して文字通りすべての有効なツリーを構築し、深さを計算してから、最大リーフ値を計算することです。 有効なツリーの数が指数関数的であるため、これは失敗します。`n`。 注意すべきエッジ ケースには、すべての数値が等しい配列 (最適な構造は深さによってのみ決定されます) や、最大の数値がクラスター化されている配列が含まれます。不注意な割り当てにより、最大リーフ値が大幅に増加する可能性があります。 

たとえば、次の場合`n = 5, m = 2`そして配列は`[1, 1, 5, 5, 5]`、素朴なアプローチでは、`5`深すぎるか浅すぎると、最適な 6 ではなく 7 のツリー値が生成されます。 

## アプローチ

 ブルートフォースのアイデアは単純です。 考えられるすべてのことを生み出すことができます`m`- マリーツリーと`n`葉を取得し、配列のすべての順列をテストして葉に番号を割り当て、毎回最大値を計算します。 これは原理的には正しいですが、完全に非現実的です。 のために`n=10^5`、木と葉の割り当ての数は天文学的に多くなります。 ブルートフォースソリューションには次のようなものが必要です`O(n! * n)`実行不可能な操作。 

最適なアプローチを明らかにする重要な観察は、ツリーの価値が葉の深さのみに依存することを認識することによって得られます。 リーフが深くなるほど、その数が最大値に寄与します。 したがって、全体の最大値を最小限に抑えるために、最大の数値をルートのできるだけ近くに配置し、最小の数値を最も深い葉に配置する必要があります。 

優れた木は非常に堅固な構造をしているため、各深さに何枚の葉が存在するかを正確に計算できます。 これを使用して、リーフ番号の配列を降順に並べ替え、最も浅いリーフから最も深いリーフまで貪欲に割り当てます。 これにより、最大値が最小化されることが保証されます。最大の数値は最小の深度を取得し、最小の数値は最大の深度ペナルティを吸収します。 

更新のために、数値のマルチセット (またはバランスのとれた BST) が維持され、クエリごとに log(n) の挿入と削除が可能になります。 ツリー構造は一旦固定されるので`n`そして`m`が知られている場合、葉の深さは変化しません。 割り当てられた番号のみが変わります。 したがって、更新のたびに、最大の数値と最小の深さを組み合わせることで、最大値を効率的に再計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * n) | O(n) | 遅すぎる |
 | 最適 | O(n log n + q log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 完全な深さの各深さの葉の数を事前計算します。`m`-アリーツリー付き`n`葉。 深さ 0 のルートから開始して反復的に計算します`leaves_at_depth[d]`残った葉を子供たちに分けます。 全部終わったら停止`n`葉が考慮されます。 これにより、葉がどのくらい深くまで届くかが正確に決まります。 
2. 配列をソートする`a`降順で。 このように、最大​​の数値が最初に表示されます。 
3. 葉の深さの順に番号を割り当てます。`leaves_at_depth[0]`数値は深さ 0 に進み、次の深さになります。`leaves_at_depth[1]`数値は深さ 1 に進みます。 各割り当てにより、対応する深さが数値に追加され、葉の値が与えられます。 
4. これらのリーフ値の最大値を計算します。 これは、現在の配列の最小ツリー値です。 
5. クエリごとに、古い値を削除して新しい値を挿入することにより、数値のマルチセットを更新します。 必要に応じて再並べ替えます (またはバランスのとれた構造を使用します)。 手順 3 ～ 4 を繰り返して、新しい最大値を計算します。 

機能する理由: 常に最大の数値と最も浅い深さを組み合わせることで、他の代入により、より大きな数値がより深くなるか、より小さな数値がより浅くプッシュされ、どちらも最大リーフ値が増加することが保証されます。 この割り当ては、並べ替えられた数値の順序と固定された深さの分布を考慮すると、独自に最適化されます。 深度分布は次のように保証されます。`n ≡ 1 mod (m - 1)`、ルールに従ってツリーがいっぱいになり、バランスが取れていることを確認します。 

## Python ソリューション```python
import sys
import bisect
input = sys.stdin.readline

def compute_depth_distribution(n, m):
    depth_counts = []
    remaining = n
    current_level = 1
    while remaining > 0:
        leaves = min(remaining, current_level)
        depth_counts.append(leaves)
        remaining -= leaves
        current_level *= m
    return depth_counts

def minimal_tree_value(a, depth_counts):
    a_sorted = sorted(a, reverse=True)
    idx = 0
    max_value = 0
    for depth, count in enumerate(depth_counts):
        for _ in range(count):
            max_value = max(max_value, a_sorted[idx] + depth)
            idx += 1
    return max_value

def main():
    t = int(input())
    for _ in range(t):
        n, m, q = map(int, input().split())
        a = list(map(int, input().split()))
        depth_counts = compute_depth_distribution(n, m)
        output = []
        for _ in range(q):
            x, y = map(int, input().split())
            a[x-1] = y
            output.append(str(minimal_tree_value(a, depth_counts)))
        print(" ".join(output))

if __name__ == "__main__":
    main()
```このソリューションはまず、各深さに存在するリーフの数を計算します。 これは数値自体とは独立して、純粋に次の情報に基づいて行われます。`n`そして`m`。 配列をソートすると、最大の数値が最も浅い深さとペアになることが保証されます。 各クエリは 1 つの数値を変更し、最大値の再計算には同じ深さの割り当て戦略が使用されます。 Off-by-one エラーは、Python で常に 0 から始まるインデックスを使用することで回避されます。
