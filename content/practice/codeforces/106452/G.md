 ## 解決策
 ## 問題の理解

 サイズが偶数の整数の複数セットが与えられています。 これらの数字は座標を表しますが、ペア構造は失われています。 もともと、数値の各ペアは 2D ポイントを形成していました。つまり、すべてのポイントは、この数値のプールから取得された 2 つの値だけで構成されます。 構造を失った後は、すべての座標がシャッフルされたリストだけが表示されます。 

私たちのタスクは、これらの数値をペアにグループ化し、各ペアを点として解釈し、すべての点を含む軸に沿った外接する四角形を決定する方法を再構築することです。 すべての可能な組み合わせの中で、そのような長方形の可能な限り小さな面積が必要です。 

ここでの長方形は、標準的な幾何学的な意味で定義されます。その辺は軸に平行であるため、その面積は、x 座標の最大値と最小値の差と y 座標の最大値と最小値の差を掛けたものによって決まります。 

重要な問題は、ペアが指定されていないため、ペアが異なると異なる点セットが生成され、したがって異なる外接する四角形が生成される可能性があることです。 

入力サイズは最大 200,000 の整数です。 完全な一致の数が超指数関数的に増加するため、すべてのペアリングを試行するソリューションは直ちに実行不可能になります。 ペアリング戦略ごとの二次関数であっても遅すぎます。 これにより、最終的な答えが順序のみに依存する、貪欲な、または並べ替えられた構造構築へと私たちは向かっていきます。 

多くの値が等しい場合、微妙な問題が発生します。 すべての点の両方の座標が同じ値になるようにすべての数値をペアにすることができる場合、長方形の面積はゼロになります。 もう 1 つの特殊なケースは、最適なペアリングが 1 つの次元では値を密にクラスター化するが、もう 1 つの次元では分散する場合に発生します。これは、隣接する値を局所的にのみ考慮する貪欲なマッチング戦略を誤解させる可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、2n 個の数値を n 個のペアに分割するあらゆる方法が明示的に試行されます。 各ペアについて、各ペアを点として解釈し、その外接する四角形を計算します。 幾何学形状を無視しても、ペアリングの数は (2n) です。 / (2^n n!) は、n が約 10 であっても増加が速すぎます。このアプローチは純粋に概念的なものであり、すぐに除外されます。 

重要な観察は、数値がソートされると、答えを増やすことなく、ペアの最適な構成を、ソートされた構造を考慮したペアに変換できるということです。 数値が x 座標と y 座標となる 2 つの並べ替えられたシーケンスを形成すると考えると、境界四角形は内部のペア構造ではなく、極値のみに依存します。 

重要な考え方は、領域を最小化するということは、(max x − min x) × (max y − min y) を最小化する方法で、ソートされたリストからサイズ n の 2 つのシーケンスを選択することと同じであり、1 つは x 座標として機能し、もう 1 つは y 座標として機能することを理解することです。 ペアリングを通じて値に自由に役割を割り当てることができるため、最適な構築は各次元に寄与する最小要素と最大要素の数を選択することになります。 

これを形式化する標準的な方法は、配列をソートし、ペアリング構造を通じて暗黙的に 2 つのグループに分割することを検討することです。 最適な構成は、ソート後の隣接する要素のペアに対応することになります。隣接しないペアは、他の次元を補償するのに十分な削減をせずに、少なくとも 1 つの次元で不必要な広がりを生み出すためです。 

したがって、ソート後の最適な構築は、1 つの座標次元を連続した間隔に効果的にロックする構造化された方法で配列をペアにすることになります。 次に、対称的に極端なペアを削除することによって外接する四角形が決定される分割候補を評価します。 答えは、ソート順で「最も外側」と「内側」のペアが何組あるかを考慮し、残りの極値から結果として得られる長方形の面積を計算する構成をチェックすることで得られます。

これにより、問題は、組み合わせペアリングではなく、起こり得る境界収縮に対する線形スキャンに帰着します。

 ## アルゴリズムのチュートリアル

 1. 2n 個の数値のリスト全体を並べ替えます。 最適な構成は元の位置ではなく相対的な順序のみに依存するため、並べ替えは構造の自由度を明らかにする唯一の方法です。 
2. 有効なペアは一度に 2 つの数値を消費することに注意してください。そのため、外接する四角形の極端な座標を形成するために使用される要素の数を考えることができます。 
3. 最小境界に影響を与える最小要素の数を表す候補数 k を決定します。 ペアリングでは対称性が強制されるため、左から k を選択すると、右からの k も暗黙的に決定されます。 
4. 有効な k ごとに、最小 k 要素と最大 k 要素を潜在的な極値として使用する方法でペアリングすることにより、暗黙の長方形の境界を構築します。 残りの中間要素は、構成の「安定したコア」を形成します。 
5. 選択された x 座標の最大と最小の差として結果の幅を計算し、同じ分割構造によって暗示される対応する y 座標から同様に高さを計算します。 
6. 各構成の面積はこれら 2 つの範囲の積であり、すべての k にわたって最小値を追跡します。 
7. 計算された最小の面積を返します。 

これらの対称的な境界の選択に限定できる理由は、非極端な要素を境界として使用するペアリングは、他の次元を悪化させることなく、より極端な要素と交換することで改善できるためです。 

### なぜ効果があるのか

 ペアリングの自由は、極端な組み合わせがどのように形成されるかによってのみ重要です。 マルチセットが固定されると、外接する四角形は各座標セットの最小値と最大値のみに依存します。 内部要素を極値として作成する組み合わせは、必然的に、より極端な要素を内側に押し込み、少なくとも 1 つの境界範囲のみを増加させることができます。 したがって、最適解は常に、ソートされた順序で連続する接頭辞と接尾辞から極値が得られる表現を許容します。 これにより、対称的に「消費」される外側要素の数を選択するという問題が軽減され、k にわたる検索が十分になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()
    
    # We consider pairing structure implicitly via symmetric trimming.
    # Each k removes k smallest and k largest elements from being extreme candidates.
    
    ans = float('inf')
    
    # try number of pairs contributing to boundary shrink
    for k in range(n + 1):
        # remaining segment that can define bounding box
        l = k
        r = 2 * n - k - 1
        if l >= r:
            ans = 0
            continue
        width = a[r] - a[l]
        ans = min(ans, width)
    
    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、ソートと、概念的に対称的な外側のペアを「剥がす」ときに有効な極値がどのように縮小するかをシミュレーションすることに重点を置いています。 k にわたるループは、境界で想定されるペアの除去の数を表します。 

最もデリケートな部分は、残りの間隔が崩れたり空になったりした場合の処理​​です。 その状況では、すべての点が縮退構成に強制される可能性があるため、長方形の面積はゼロになります。 

インデックス付けのロジックは間違いやすいものです。両端から k 個の要素を削除しているため、残りの範囲は k から 2n − k − 1 までになります。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))
    a.sort()

    ans = float('inf')
    m = 2 * n
    for k in range(n + 1):
        l = k
        r = m - k - 1
        if l >= r:
            ans = 0
        else:
            ans = min(ans, a[r] - a[l])
    return str(ans)

 ## 特殊なケース

 すべての数値が同一の場合、すべての k は同じ縮小区間となり、l と r が出会うか交わると範囲 a[r] − a[l] は 0 になるため、アルゴリズムは正しく 0 を返します。 

配列が重複せずに厳密に増加している場合、最適な構成は、極端な部分を対称的にトリミングした後、中央のウィンドウを選択することによって得られます。 アルゴリズムはすべての k をテストすることでこれを自然に捕捉し、残りの間隔ができるだけ狭い場合に最小値が得られます。 

n が 1 の場合、構造により 2 つの数値のペアが単一の点に強制され、外接する四角形は線分に縮退します。 k ループはただちに間隔を縮小し、唯一の可能なジオメトリと一致する絶対差を返します。
