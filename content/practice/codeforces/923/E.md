 ## 解決策

 ## 問題の理解

 確率分布 P で表される、0 から N までのランダムな整数から開始します。各ステップで、現在の数値 x を消去し、区間 [0, x] の一様にランダムな整数で置き換えます。 この操作を M 回実行した後、最終値の正確な確率分布が必要になります。 

重要な視点は、これが状態 0 から N にわたる確率的プロセスであるということです。各ステップは、下三角遷移規則によって分布を別の分布に変換します。x から、等しい確率 1/(x+1) で任意の y ≤ x に移動します。 

入力サイズ N は最大 100000、M は 10^18 まで可能です。 これにより、ステップを 1 つずつシミュレートしたり、明示的な遷移行列を構築して単純な形式で繰り返し適用したりするアプローチは即座に除外されます。 高密度の操作では O(N^2 M) または O(N^2 log M) であっても遅すぎます。 

出力は、同じ状態空間上の別の分布であり、このランダムな「均一プレフィックス サンプリング」操作を M 回構成した後の結果を表します。 

いくつかの微妙なケースは見落とされがちです。 まず、M = 0 は、遷移が発生しないため、出力が入力分布とまったく同じであることを意味します。 第 2 に、N = 0 は状態空間が自明であり、すべてのステップで値を 0 に保つ必要があることを意味します。そのため、出力は常に 0 のデルタ分布になります。第 3 に、繰り返し適用すると、確率質量が非常に積極的に小さな値に向かう傾向があるため、「平均はゆっくりと減少する」などの単純な直感に依存するアプローチは組み合わせ構造を捉えることができません。 

## アプローチ

 ブルートフォース手法では、分布をベクトルとして扱い、遷移ルールを繰り返し適用します。 分布 dp から、各 x がその確率をすべての値 0..x に均等に分布する next_dp を計算します。 これには状態ごとに O(N) のコストがかかるため、完全な遷移は O(N^2) になります。 これを M 回繰り返すと O(M N^2) が得られますが、これは小さな M であってもまったく実行不可能です。 

遷移がプレフィックス構造になっていることを観察することで、ステップを 1 つ改善できます。 新しい値 y はすべて、x ≥ y からの寄与を受け取り、それぞれが dp[x] / (x+1) に寄与します。 これは、重み付きサフィックス合計を使用してステップごとに O(N) で計算できるため、1 つの遷移は線形になります。 ただし、M は 10^18 までであるため、遷移を反復することはできません。 

重要な洞察は、遷移が線形であり、各ステップが同一であるため、プロセスは固定線形演算子を繰り返し適用することであるということです。 段階的にシミュレートするのではなく、畳み込みのような構造が乗法となる変換領域で演算子の効果を分析します。 

重要な構造は、演算を 1 回適用することが重み付きプレフィックス平均演算子に相当するということです。 M 回合成すると、この演算子の累乗を適用することになります。 行列は非常に構造化された形式の下三角であり、その累乗は組み合わせ解釈を使用して計算できます。反復された均一なプレフィックス サンプリングは、減少する選択肢の連鎖をカウントすることに対応します。 これにより、減少するセグメントの長さのみに依存する係数を使用した二項タイプの畳み込みを計算する問題が軽減されます。 

この構造により、元の状態空間で直接操作するのではなく、変換側で FFT ベースの畳み込みと高速累乗を使用して最終的な分布を計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(M N^2) | O(N) | 遅すぎる |
 | 最適 | O(N log N log M) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 このプロセスをより代数的な形式で書き直します。 dp[x] を値 x になる確率とします。 1 つの遷移により新しい配列が生成されます。 

dp'[y] = sum_{x ≥ y} dp[x] / (x+1)

x+1 への依存が主な障害です。 変換されたシーケンス a[x] = dp[x] / (x+1) を導入することでこれを削除します。 次に:

 dp'[y] = sum_{x ≥ y} a[x]

 これにより、演算が重み付き配列の接尾辞の合計に変換されます。 

dp は a から回復できるため、遷移の下で a がどのように進化するかを追跡します。 

重要な観察は、a と dp の間の変換、およびその逆の変換が階乗のような重みを使用した畳み込みとして表現できることです。 繰り返し適用すると、構造化された多項式空間での畳み込みが繰り返されます。 

アルゴリズムは次の手順で進みます。 

1. 初期分布 dp を多項式 A に変換します。ここで、係数は dp[x] / (x+1) をエンコードします。 この表現は、遷移ルール​​をサフィックス集約に線形化します。 
2. プロセスの 1 つのアプリケーションが A を A' に変換する方法を記述する演算子多項式を作成します。 この演算子は、インデックスの差のみに依存するカーネルに対応し、組み合わせ係数を介して表現できます。 
3. 2 進累乗を使用して、この演算子を M 乗します。 各乗算は、遷移合成を表す多項式の畳み込みです。 
4. FFT (モジュロ 998244353 による NTT) を使用して、各畳み込みを O(N log N) で効率的に実行します。 
5. べき乗演算子を最初の変換された配列 A に適用して、最終的な変換された配列 A_final を取得します。 
6. 最初の変換の逆を使用して、A_final を dp_final に変換し直します。これは、別のプレフィックスベースの再構築です。 

### なぜ効果があるのか

 このプロセスは、(N+1) 次元ベクトル空間上の線形演算子です。 この変換は下三角であり、重み付けされた意味では並進不変です。これは、基底を適切に変更した後の畳み込みに対応することを意味します。 繰り返し適用することは、このオペレーターに電力を供給することに正確に対応します。 基底変更後の畳み込みは連想的であり、FFT と互換性があるため、演算子のべき乗は正しく、完全な確率質量変換が正確に保存されます。

 ## 特殊なケース

 M = 0 の場合は、恒等演算子を 0 回適用することに対応します。 累乗ステップで恒等多項式が返されるため、アルゴリズムはこれを処理します。そのため、畳み込みでは初期分布が変更されないままになります。 

N = 0 の場合、変換された配列のサイズは 1 になります。すべての畳み込みは乗算スカラーに還元され、演算子の累乗は常に 1 であるため、出力は M に関係なく [1] のままです。これは、可能な値は 0 のみであり、変更できないという事実と一致します。 

すべての確率質量が N で始まる場合、最初の変換はそれを [0, N] 全体に均一に広げます。 畳み込みベースの演算子は、カーネルが一様なプレフィックス拡張を正確にエンコードするため、この動作を維持します。そのため、繰り返し適用しても、有効範囲外の値を作成することなく質量を下方に再分配し続けます。
