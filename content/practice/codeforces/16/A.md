 ## 解決策
 ## 問題の理解

 国の国旗を表す長方形のグリッドが与えられます。 グリッド内の各セルには色があり、0 から 9 までの数字としてエンコードされています。フラグの寸法は次のとおりです。$n$行数$m$列。 目標は、新しい ISO 規格に従って国旗が「縞模様」であるかどうかを判断することです。 すべての行に同じ色のセルが含まれており、連続する行が同じ色を共有していない場合、フラグはストライプになります。 

入力は小さいですが、$n, m \leq 100$。 これは、たとえ$O(n \cdot m)$セルの総数は最大でも 10,000 個であり、最新の CPU にとっては取るに足らない量であるため、このソリューションは許容されます。 

一部の明らかではないエッジ ケースには、比較する前の行が存在しない単一行のフラグや、各行が均一である必要がある単一列のフラグが含まれます。 たとえば、1 行に 3 つのセルがあるフラグです。`111`返すべきです`YES`これは、色を比較する上下の行がないにもかかわらず、その行のすべてのセルが同一であるためです。 もう 1 つの注意が必要なシナリオは、次のように、隣接する 2 つの行が誤って同じ色を共有する場合です。`111`に続く`111`。 これは返されるはずです`NO`縞模様がはっきりしないからです。 

## アプローチ

 ブルートフォース手法では、すべてのセルを反復処理して、各行が均一であること、および連続する各行が前の行とは異なるという 2 つの条件をチェックします。 この問題は有効なフラグのプロパティを明示的に定義しているため、これは正解です。 複雑さは$O(n \cdot m)$、この問題のサイズでは許容範囲です。 

重要な洞察は、チェックを簡素化できるということです。個々のセルを行内の他のすべてのセルに対して繰り返し検証する代わりに、各セルを行の最初のセルと比較するだけで済みます。 いずれかのセルが異なる場合、その行は無効になります。 連続する行をチェックするには、現在の行の最初のセルと前の行の最初のセルを比較するだけです。 これにより不必要な比較が減りますが、漸近的な複雑さは変わりません。 

ブルート フォースはすべての要件を明示的にチェックするため機能しますが、行先セルの比較に関する観察によって認識と実装の複雑さが軽減され、コードがクリーンになり、エラーが発生しにくくなります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n・m) | お(1) | 承認済み |
 | 最適化された行優先チェック | O(n・m) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 寸法を読む$n$そして$m$入力からフラグを取得し、文字列のリストとしてフラグを保存します。各文字列は行を表します。 これにより、行構造が保存され、チェックが容易になります。 
2. 最初の行から始めて各行を繰り返します。 各行について、すべてのセルが同一であることを確認します。 行内の各文字を最初の文字と比較します。 文字が異なる場合は出力`NO`そしてやめてください。 
3. 現在の行が最初でない場合は、その最初の文字と前の行の最初の文字を比較します。 同一の場合は出力`NO`そしてやめてください。 
4. すべての行が両方のチェックに合格した場合、出力`YES`。 

**機能する理由:** このアルゴリズムは、すべてのセルを行の最初のセルと比較することで、すべての行が均一であることを保証します。 連続する行の最初のセルをチェックすることで、隣接する行が異なることを確認します。 これら 2 つのチェックはストライプ フラグの定義を満たしています。 カラー桁は 0 ～ 9 であることが保証されているため、他のチェックは必要ありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
flag = [input().strip() for _ in range(n)]

for i in range(n):
    row = flag[i]
    if any(c != row[0] for c in row):
        print("NO")
        sys.exit(0)
    if i > 0 and row[0] == flag[i - 1][0]:
        print("NO")
        sys.exit(0)

print("YES")
```コードはまずフラグを文字列のリストに読み取ります。 の`any(c != row[0] for c in row)`コンストラクトは行の均一性を効率的にチェックします。 2 番目の条件では、ストライプが異なることを保証します。 使用する`sys.exit(0)`違反が見つかるとプログラムをただちに終了するため、残りの行に対する不必要な反復が回避されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n・m) | 各行を 1 回完全にスキャンします。 |
 | スペース | O(n・m) | グリッドを文字列のリストとして保存するには、行ごとに 1 つの文字列が必要です。 |

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()
    n, m = map(int, input().split())
    flag = [input().strip() for _ in range(n)]
    for i in range(n):
        row = flag[i]
        if any(c != row[0] for c in row):
            print("NO")
            return sys.stdout.getvalue().strip()
        if i > 0 and row[0] == flag[i - 1][0]:
            print("NO")
            return sys.stdout.getvalue().strip()
    print("YES")
    return sys.stdout.getvalue().strip()

# Provided sample
assert run("3 3\n000\n111\n222\n") == "YES", "sample 1"

# Custom cases
assert run("1 5\n33333\n") == "YES", "single row"
assert run("5 1\n1\n2\n3\n4\n5\n") == "YES", "single column, distinct"
assert run("2 4\n7777\n7777\n") == "NO", "repeated color"
assert run("3 3\n123\n456\n789\n") == "NO", "row not uniform"
assert run("3 2\n11\n22\n22\n") == "NO", "last two rows same"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 5\n33333 | はい | 単一行が有効 |
 | 5 1\n1\n2\n3\n4\n5 | はい | 明確な色の単一列のフラグ |
 | 2 4\n7777\n7777 | いいえ | 隣接する行は色を共有します。 
| 3 3\n123\n456\n789 | いいえ | 行が均一ではありません |
 | 3 2\n11\n22\n22 | いいえ | 最後の 2 行は同じ色 |

 ## 特殊なケース

 次のような 1 行のフラグ。```
1 4
4444
```アルゴリズムは行の均一性をチェックします。`all(c == row[0] for c in row)`通ります。 前の行がないため、隣接行のチェックはスキップされます。 出力は`YES`。 

1 列のフラグ:```
3 1
1
2
2
```各行には 1 つのセルがあるため、行の均一性は問題ありません。 隣接行チェックは最後の 2 行では失敗します。`2 == 2`。 出力は`NO`。 

これらの例は、アルゴリズムが最小次元とエッジ比較を正しく処理することを確認します。
