 ## 問題の理解

 整数のリストが与えられたので、それを 2 つの空でないグループに分割する必要があります。 要件は合計やサイズに関するものではなく、乗法構造に関するものです。各グループで、そのすべての要素の最大公約数を取る場合、結果は正確に 1 でなければなりません。 

したがって、各グループは、そのすべての要素間で素因数を共有しないようにする必要があります。 単一の素数がグループ内のすべての数値を除算する場合、そのグループは直ちに条件に違反します。 

出力は単に各要素のバイナリラベル付けですが、ラベル付けは両方の gcd 制約を同時に満たす必要があります。 

制約$n \le 10^5$すべてのパーティションを試行するアプローチやサブセット上の理由を試すアプローチは不可能であることを意味します。 ナイーブ$2^n$分割ははるかに手の届かないものであり、$O(n^2)$インタラクションが遅すぎます。 解決策は、要素ごとに光数理論のみを使用して、線形または線形に近いものでなければなりません。 

gcd 制約のグローバルな性質により、微妙な困難が生じます。 1 つの要素を割り当てると、グループ全体の有効性に影響します。これは、すべてのメンバー間で共有される 1 つの素因数だけでグループを壊すのに十分であるためです。 要素を独立して割り当てる単純な貪欲な戦略は、あるグループが取り返しのつかないほど「プライムロック」されてしまうほど、簡単に追い詰められてしまう可能性があります。 

よくある失敗例は、多くの数値が支配的な素因数を共有する場合です。 たとえば、ほとんどの要素が偶数の場合、すべての奇数を 1 つのグループに入れると、誤ってそのグループの gcd が 1 に等しくなる可能性がありますが、もう 1 つのグループは完全に偶数になり、無効になります。 制約はローカルではなくグローバルに相互作用します。 

## アプローチ

 ブルート フォースの解釈は簡単です。2 つのグループへの要素の可能なすべての割り当てを試し、各グループの gcd を計算します。 各パーティションについて、両方の gcd が 1 に等しいかどうかを確認します。 これには gcd を計算する必要があります$n$パーティションごとの要素、おおよそ$O(2^n \cdot n)$たとえ小さな入力であっても、この操作は完全に実行不可能です。 

これを改善するには、グループが失敗する原因を理解する必要があります。 素数が存在するとグループは悪くなる$p$そのグループ内のすべての要素は次のように割り切れます。$p$。 gcd を直接追跡する代わりに、素数カバレッジの観点から考えることができます。つまり、各グループはその内部のどこかですべての素数を「逃す」必要があります。 

これは二重の視点を示唆しています。 最後に gcd が 1 に等しいことを保証する代わりに、どの素数もグループを完全に支配できないことを保証します。 この構造は依然としてグローバルですが、より組み合わせ的になります。つまり、素数によって定義される特定の暗黙の制約を単色でカバーすることを回避しています。 

重要な観察は、すべての制約を決定論的に強制するのは難しいが、妥当性をチェックするのは簡単であるということです。 これは、確率的構築のアイデアにつながります。つまり、バランスを維持しながら要素をランダムに割り当て、両方のグループが gcd が 1 に等しいかどうかを検証すると、成功の確率は少ない回数繰り返すだけで十分に高くなります。 

それぞれのランダムな試行は線形であり、gcd チェックも線形であるため、制約の下でこれが実用的になります。

 ## アルゴリズムのチュートリアル

 私たちはランダムな構築を繰り返し、その後に決定論的な検証を行うことに依存しています。 

1. 敵対的な構造を避けるために配列をランダムにシャッフルします。 これにより、主因子の病理学的分布が同じ貪欲な動作を一貫して破壊するのを防ぎます。 
2. 要素を 1 つずつ 2 つのグループに割り当てます。 各グループを構築するときに、各グループの現在の gcd を維持します。 
3. 要素ごとに、それをいずれかのグループに配置して、そのグループの結果として得られる gcd を計算します。 両方のグループを「生きた状態」に保つ配置を選択します。これは、どちらも後で修正することが簡単に不可能になることを意味します。 実際には、グループの gcd が初期段階で大きくなりすぎることを避ける代入が好まれます。これは、gcd が大きいということは、多くの要素が隠れた共通因子を共有していることを示すためです。 
4. すべての要素を割り当てた後、両方のグループの最終的な gcd を明示的に計算します。 
5. 両方の gcd が 1 に等しく、両方のグループが空でない場合、割り当てを出力します。 それ以外の場合は、新しいシャッフルから再開します。 

これが機能する理由は、ランダム化によって素因数の構造化された配列が破壊されるためです。 唯一の危険な構成は、大規模な相関関係にある要素セットが同じ素数構造を 1 つのグループに強制的に組み込む構成です。 ランダムな並べ替えにより、そのようなすべての依存関係が複数回の試行にわたって一貫して同じ方向に揃う可能性は低くなります。 

## なぜ機能するのか

 コアの不変条件は、構築中に決定論的に維持されるのではなく、検証時に強制されます。 各試行は、両方のグループが単一の支配的な素因数によってトラップされることを独立して回避する場合に限り、有効な分割を生成します。 素数の可分性パターンはランダムな順列全体にわたって非常に不均一であるため、すべての試行にわたって不正な構造化分割が持続する確率は無視できるほどになります。 これにより、困難なグローバル制約問題が、候補解の独立したサンプリングの繰り返しに変わります。 

## Python ソリューション```python
import sys
import random
import math
input = sys.stdin.readline

def gcd_list(arr):
    g = 0
    for x in arr:
        g = math.gcd(g, x)
    return g

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    if n == 2:
        # only valid if both groups non-empty => must split 1 and 1
        print("YES")
        print("1 2")
        return

    idx = list(range(n))

    for _ in range(60):
        random.shuffle(idx)

        g1 = 0
        g2 = 0
        c1 = []
        c2 = []

        for i in idx:
            x = a[i]

            # try put into group 1
            ng1 = math.gcd(g1, x)
            ng2 = g2
            ok1 = True

            # try put into group 2
            ng1b = g1
            ng2b = math.gcd(g2, x)
            ok2 = True

            # choose better option heuristically
            if ng1 <= ng2b:
                c1.append(i)
                g1 = ng1
            else:
                c2.append(i)
                g2 = ng2b

        if c1 and c2 and g1 == 1 and g2 == 1:
            ans = [0] * n
            for i in c1:
                ans[i] = 1
            for i in c2:
                ans[i] = 2
            print("YES")
            print(*ans)
            return

    print("NO")

if __name__ == "__main__":
    solve()
```このコードは、要素をランダムな順序で割り当てながら、2 つの進化するグループとその gcd を維持します。 決定ルールは、中間 gcd が小さいほどグループを共有素数構造にロックする可能性が低いため、結果の gcd を小さく保つ割り当てを優先するヒューリスティックです。 

完全な割り当てを構築した後、両方のグループの gcd をチェックすることで明示的に検証されます。 いずれかのグループが失敗した場合は、新しいシャッフルでプロセスが繰り返されます。

 ## 特殊なケース

 重要なエッジケースは、すべての偶数が 1 つの奇数要素を持つなど、ほとんどすべての数値が支配的な素因数を共有する場合です。 単純な貪欲な割り当てでは、誤ってすべての奇数を 1 つのグループに入れて、もう 1 つのグループを完全に偶数のままにすることが簡単に起こり、そのグループ内の gcd が 1 より大きくなります。 

ランダム化アプローチでは、順序を繰り返し再シャッフルすることでこれを回避するため、ドミナント素数によって割り当てが常に同じグループに偏りません。 

もう 1 つのケースは、数値が 6、10、15、21 など、複数の重複する素数の積である場合です。ここでは、すべての数値が共有因子を通じて他の複数の数値と相互作用し、決定論的な貪欲ルールが不安定な安定した構成に振動する可能性があります。 ランダムによりこの調整が崩れ、独立した試行間で有効な分割が現れることが可能になります。
