 ## 解決策
 ## 問題の理解

 整数が与えられます$n$、具体的には固定の有理数を表したいと考えています。$1 - \frac{1}{n}$、いくつかの小さな分数の合計として。 

各分数には、適切な約数である分母が必要です。$n$、分割することを意味します$n$しかし、1でもありません$n$。 分子は厳密に分母より小さくなければならないため、すべての項は適切な分数になります。 タスクは、そのような分解が存在するかどうかを判断し、存在する場合は、最大でも以下を使用して分解を構築することです。$10^5$条項。 

この問題を別の方法で考えると、分母が次の約数構造に由来する分数のみを使用できるということになります。$n$、そしてその量を正確に「埋める」必要があります$1 - \frac{1}{n}$。 

重要な制約は数値的なものではなく構造的なものです。つまり、分母は次の約数と一致するものに制限されます。$n$。 以来$n \le 10^9$、すべての数値を総当たり的に割り算して因数分解することはできません。 どのような解決策も、約数の算術構造と、関連する分母を持つ分数をどのように組み合わせることができるかに依存する必要があります。 

微妙なエッジケースは次のような場合です$n$には適切な約数がまったくありません。 これは次のような場合に起こります。$n$プライムです。 その場合、有効な分母はありません$b_i$, したがって、シーケンスは存在しません。 たとえば、次の場合$n = 2$、 または$n = 3$、即答は不可能です。 

もう 1 つの重要な問題は、$n$は複合ですが、そのような分解が常に存在するかどうかは明らかではありません。 例えば、$n = 6$約数を許可します$2, 3$と表現しなければなりません。$\frac{5}{6}$分母 2 と 3 の分数のみを使用します。単純な試みでは、結合しようとする可能性があります。$\frac{1}{2}$そして$\frac{1}{3}$、ただし、これらは直接一致しません。$\frac{5}{6}$慎重にスケーリングまたは分解しない限り。 

中心的な難しさは、ターゲットの分数を、除数の分母によって制約された分数の合計に系統的に変換しなければならないことです。 

## アプローチ

 強引なアイデアは、これを有理数に対する分割問題として扱うことです。考えられるすべての分数を列挙します。$\frac{a}{b}$どこ$b \mid n$を達成するために、それらを貪欲にまたは再帰的に組み合わせようとします。$1 - \frac{1}{n}$。 分母を制限したとしても、各分母は複数の分子とペアになる可能性があり、検索空間は急速に拡大します。 もし$n$に約数が多い場合、基本的に候補となる分数のサブセットを検索するため、このアプローチは組み合わせ爆発的になり、指数関数的な動作につながります。 

重要な点は、実際には約数の任意の組み合わせが必要ないということです。 私たちが必要としているのは、可分性に基づいた建設的なアイデンティティを活用することだけです。 約数を取ると$d \mid n$、 それから$\frac{d}{n}$すべての分数を共通の分母にスケールできるため、ターゲットと自然に互換性があります。$n$。 これは、分母を介してすべてを書き直すことを示唆しています$n$たとえ、出力ではより小さな分母を使用する必要がある場合でも。 

重要な洞察は、次のように表現することです。$n-1$整数の合計として、それぞれが有効な分数からのスケーリングされた寄与に対応します。 分数を書くと$\frac{a}{b}$、分母にスケーリングします$n$与える$\frac{a \cdot (n/b)}{n}$。 したがって、各分数は次の整数倍に寄与します。$\frac{1}{n}$、 具体的には$a \cdot \frac{n}{b}$。 以来$\frac{n}{b}$が整数である場合、各項は、の約数の補数の倍数に寄与します。$n$。 

したがって、問題は次のようになります。$n - 1$次の形式の数値の合計に変換します$a \cdot \frac{n}{b}$、 どこ$b \mid n$そして$1 \le a < b$。 これは現在、利用可能な「コインの価値」が除数構造から得られるコイン構築の問題です。 

今後の建設的な方法は、適切な約数ごとに、約数に対する正規のペアリング戦略を使用することです。$b$の倍数を使用できます。$\frac{n}{b}$まで$(b-1)\frac{n}{b}$。 これにより、カバーできる限り、あらゆる多重構造を表現できるようになります。$n-1$隙間なく。 標準的な構築は、除数を反復し、可能な限り最大の寄与を貪欲に取得することで進行し、残りの剰余を決して超えないようにします。 

ブルートフォースから最適解への移行は、分数の組み合わせを検索する必要がなく、除数から導出された構造化されたステップ サイズのセットを使用して整数を表現するだけでよいという認識です。

 ## アルゴリズムのチュートリアル

 1. すべての適切な約数を計算します。$n$1とを除く$n$。 

構築ではこれらの分母のみが許可されるため、これが必要になります。 
2. そのような約数が存在しない場合は、直ちに NO を出力します。 

この場合$n$は素数なので、分数は形成できません。 
3. 目標値を換算する$1 - \frac{1}{n}$整数ターゲットに$T = n - 1$の単位として解釈されます。$\frac{1}{n}$。 

これにより、推論から端数が削除され、すべての寄与が統合されます。 
4. 各約数について$b$、その寄与ステップサイズを計算します$\frac{n}{b}$。 

各分数$\frac{a}{b}$追加に対応します$a \cdot \frac{n}{b}$単位。 
5. 貪欲に構築する$T$これらのステップ サイズを最大除数から最小除数まで使用します。 

固定の場合$b$まで使用できます$b-1$のコピー$\frac{n}{b}$、 以来$a < b$。 これにより、分子の有効性が保証されます。 
6. 選択した貢献ごとに$a \cdot \frac{n}{b}$、対応する分数を出力します$\frac{a}{b}$。 
7. 余りがゼロになったら停止します。 ゼロにできない場合は NO を出力します。 

これにより、目標金額を完全にカバーすることが保証されます。 

### なぜ効果があるのか

 許可されたすべての分数は、形式の整数寄与に一意にマッピングされます。$a \cdot \frac{n}{b}$、そのような寄与はすべて、次の約数の倍数です。$n$。 の約数なので、$n$構造化された加算システムを生成する場合、表現可能な合計は、これらのステップ サイズによって生成された半群内に存在する必要があります。 貪欲な構築は、すべての中間剰余が最小ステップ サイズで割り切れるため、行き止まりが発生しないように成功します。 制限$a < b$制限された係数を保証し、ターゲットを完全にカバーしながらオーバーシュートを防止します$n-1$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    if n == 2:
        print("NO")
        return

    divisors = []
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            divisors.append(i)
            if i != n // i:
                divisors.append(n // i)

    if not divisors:
        print("NO")
        return

    divisors = sorted(divisors, reverse=True)

    target = n - 1
    res = []

    for b in divisors:
        step = n // b
        max_take = b - 1
        take = min(max_take, target // step)

        for a in range(take, 0, -1):
            res.append((a, b))
            target -= a * step

    if target != 0:
        print("NO")
        return

    print("YES")
    print(len(res))
    for a, b in res:
        print(a, b)

if __name__ == "__main__":
    solve()

各約数$b$より大きな構造ジャンプが最初に使用されるように、降順で処理されます。 これにより、残りを迅速に減らすことができ、多くの小さな部分への断片化を回避できます。 

それぞれについて$b$、その貢献を何回使用できるかを計算します$\frac{n}{b}$。 私たちは制約を尊重します$a < b$係数を制限することによって。 それぞれが選んだ$a$は出力の一部に直接対応します。 

最後に、構築された合計が正確に一致することを確認します。$n-1$、印刷する前に正確性を確認します。
