 ## 解決策
 ## 問題の理解

 の行から始めます$n$それぞれの位置に個別の要素が含まれています。 ポインタ$p$も与えられますが、最初はその間のどこかにあります。$0$そして$n$、包括的。 何も残らなくなるまで、現在の行から要素を繰り返し削除します。 各ステップでは、一様にランダムな残りの位置を選択し、その要素を削除し、ギャップを埋めるためにその要素が残った後のすべてのものを移動します。 インデックス$p$厳密にその右側にあるものを削除した場合にのみ移動します: その場合$p$1つ減ります。 またはその左側を削除すると、$p$の場合、ポインタは残りの構造体に対して変更されません。 

結局$n$削除の場合、構造は空であり、最終値のみが含まれます。$p$残っています。 タスクは、この最終的な期待値を計算することです。$p$、考えられるすべての初期値に対して$p = 0, 1, \dots, n$。 

制約$n \le 1000$欠失の順列に関するシミュレーションは即座に除外されます。$n!$削除命令の可能性。 状態ごとの二次または三次の動的プロセスでも許容できますが、順列の列挙やすべての中間構成にわたる完全な分布の維持を伴うものは遅すぎます。 

微妙なエッジ ケースは、次の場合の境界動作です。$p = 0$または$p = n$。 もし$p = 0$、マイナスの影響を与えるという意味で、インデックスはゼロより大きくならないため、それ以上減少することはありません。 もし$p = n$、すべての削除は潜在的に影響を及ぼし、早期に削除すると大幅に移動する可能性があります。 正しい処方では、これらのエンドポイントを一貫して処理する必要があります。 すべてのインデックスにわたる対称性を仮定する素朴な確率論は、通常、ここで破綻します。 

## アプローチ

 ブルートフォースの観点は、プロセスをランダムな順列を生成するものとしてモデル化することです。$n$なぜなら、各削除シーケンスは正確に一様にランダムに選択された順列だからです。 次に、その方法をシミュレーションします。$p$その順列に沿って進化します。順列順序の各要素について、それが現在の位置の右側にあるかどうかを決定します。$p$、それに応じて更新します。 

このシミュレーションは簡単です: 開始ごとに$p$、すべての順列を生成し、最終的な値を計算します$p$、平均的です。 削除プロセスは一様なランダムな順序付けと同等であるため、正確性は即座にわかります。 問題は、$n!$順列、さらには$n = 12$、これはすでに実行不可能になります。 

順列の追跡を完全に回避し、代わりに対称性を観察する必要があります。重要なのは、要素の正確な同一性ではなく、削除の相対的な順序です。 各要素の運命は、最初に右にあった要素が消える前にどれだけ削除されるかによってのみ決まりますが、グローバル プロセスではすべてが均一に混合されます。 

重要な観察は、プロセスを逆方向に再解釈することです。 要素を削除する代わりに、要素を逆の順序で挿入して最終的な順列を構築することを想像してください。 構造体が空の場合、一様にランダムな位置に要素を 1 つずつ挿入します。 ポインタ$p$挿入が右側に発生するか左側に発生するかに基づいて進化します。 これにより、削除のプッシュの代わりに、依存関係が逆転します。$p$左、挿入すると制御された方法で右に押し込まれます。 

この逆のプロセスにより、最終的な結果を表現できます。$p$独立した貢献の合計として。 各要素について、それが減少に寄与しているかどうかだけを知る必要があります。$p$、対称性により、ランダムな挿入が固定位置の右側にあると予想される回数は、その現在の予想ランクの一次関数になります。 

これにより、位置と残りの要素に対する DP が発生しますが、さらに圧縮することができます。 させて$E(p, k)$ポインタから始まる予想される最終値である$p$と$k$残っている要素。 ランダムな位置から 1 つの要素を削除する場合の遷移$i \in [1, k]$は：$$E(p, k) = \frac{1}{k} \sum_{i=1}^k E(p - [i > p], k - 1)$$ケースを分けます:$i \le p$、$p$変わらない。 のために$i > p$、1 ずつ減少します。これにより、次のようになります。$$E(p, k) = \frac{p}{k} E(p, k-1) + \frac{k-p}{k} E(p-1, k-1)$$この繰り返しが核となる構造です。 これは、期待値が三角形 DP 内のより小さい状態にのみ依存し、すべての状態に対して計算できることを示しています。$p$そして$k$で$O(n^2)$。

 ## アルゴリズムのチュートリアル

 テーブルを定義します。$dp[p][k]$は期待される最終値です$p$いつ$k$要素は残り、現在のポインタは$p$。 目標は$dp[p][n]$。 

1. 基本ケースを初期化します。$k = 0$。 要素がなくなると処理は終了し、$p$固定されているので、$dp[p][0] = p$。 これにより、すべての計算が固定されます。 
2. 残りの要素の数を反復します。$k$から$1$に$n$。 要素を削除すると問題が減少するため、より小さな部分問題を使用して、より大きな部分問題に対する答えを構築します。$k$。 
3. それぞれについて$k$、すべての有効なポインター位置を反復します。$p \in [0, k]$。 ポインタが残りの要素の数を超えることができないため、この範囲外の状態は無効です。 
4. 削除されたインデックスによって引き起こされた分割を使用して遷移を計算します。 削除されたインデックスが最初のインデックス内にある場合$p$位置に応じて、ポインタは変化しません。 それ以外の場合は 1 つ減ります。 これにより、サイズが次の 2 つのグループが作成されます。$p$そして$k-p$。 
5. 期待公式を適用します。$$dp[p][k] = \frac{p}{k} dp[p][k-1] + \frac{k-p}{k} dp[p-1][k-1]$$いつ$p = 0$、第 2 項はゼロとして扱われます。$dp[-1][*]$存在しません。 

DP の構造により、すべての状態が以前に計算された値のみに依存し、状態が再計算されないことが保証されます。 

### なぜ効果があるのか

 重要な不変条件は次のとおりです$dp[p][k]$に制限されたすべてのランダムな削除シーケンスにわたる正確な期待値を表します。$k$残りの要素と現在のポインタ$p$。 各ステップで、最初の削除に関する条件付けにより、選択したインデックスに基づいて、すべての有効なシーケンスが素のケースに分割されます。 各ケースは、正しい確率の重みを備えたより小さなインスタンスに縮小されます。$p/k$そして$(k-p)/k$。 これらのケースはすべての結果をカバーし、残りの欠失の分布を保存するため、再発ではすべての層で期待値が正確に保存されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    dp = [[0.0] * (n + 1) for _ in range(n + 1)]
    
    for p in range(n + 1):
        dp[p][0] = float(p)
    
    for k in range(1, n + 1):
        for p in range(0, k + 1):
            if p == 0:
                dp[p][k] = 0.0
            else:
                dp[p][k] = (p / k) * dp[p][k - 1] + ((k - p) / k) * dp[p - 1][k - 1]
    
    res = dp[n][:]
    print(" ".join(f"{x:.10f}" for x in res))

if __name__ == "__main__":
    solve()
```DP テーブルは、残りの要素の数に応じてボトムアップで構築されます。 各遷移は、現在のポインター セグメントの内側または外側の削除の間で分割される確率を直接エンコードします。 必要な精度は次のとおりであるため、浮動小数点演算で十分です。$10^{-6}$。 

よくある間違いは反復することです$p$ずっと$n$あらゆる人にとって$k$。 有効範囲は次のように縮小します。$k$、無効な状態を使用すると、ガベージ値が発生します。 もう一つの微妙な問題は処理です$p = 0$、ここで参照しているのは$dp[-1]$明示的に回避する必要があります。

 ## 特殊なケース

 いつ$p = 0$、厳密にゼロより大きいインデックスは存在しないため、ポインタは決して減少しません。 DP はすべての遷移を正しく強制します。$p = 0$ブランチ、関連する用語以来$p-1$スキップされます。 

のために$p = n$、最初の削除を除くすべての削除は、ポインターに影響を与える可能性がゼロではありません。 DP がこれを処理します。$k = n$、全範囲$p$はアクティブであり、再発により、より小さな状態への下方遷移が繰り返されることが自然に可能になります。 

最後の微妙なケースは次のような場合です。$p$アプローチ$k$。 その境界では、確率分割は減少する方向に大きく偏ります。$p$、DP は重み付けによってこれを反映します。$dp[p-1][k-1]$用語をより強く。 これにより、期待値が高い値で誤って安定したままになることがなくなります。$p$価値観。
