 ## 解決策
 ## セットアップ

 単調なブール関数$f(x_1,\dots,x_5)$最小の真の点のセット、つまりアンチチェーンによって一意に表現されます。$A \subseteq 2^{[5]}$、逆に、すべてのアンチチェーンは上向き閉包によってそのような関数を決定します。 したがって、$7581$単調ブール関数はブール格子のアンチチェーン上の一様分布です$B_5$。 

アンチチェーンの場合$A$、数量$Z(\mathrm{PI}(f))$等しい$|A|$、単調関数の主含意はまさにその最小の真の集合であるためです。 

単調関数の BDD の場合、各ノードは変数の初期セグメントを固定することによって誘導される個別のサブ関数に対応します。単調の場合、これらのサブ関数は再び単調であり、誘導されたアンチチェーンによって決定されます。 シンクは 2 つのノードに寄与します。$\bot$そして$\top$、およびすべての非シンク ノードは、変数の条件付けから生じる空ではない誘導アンチチェーンに対応します。 

したがって$B(f)$すべての制限にわたって、誘導されたアンチチェーンのファミリーにのみ依存します。 

## 解決策

 ### 1. ランダム単調関数の構造

 5 つの変数のすべての単調関数は、次のアンチチェーンに対応します。$B_5$。 格子$B_5$サイズのレイヤーがあります$$\binom{5}{0},\binom{5}{1},\binom{5}{2},\binom{5}{3},\binom{5}{4},\binom{5}{5}
= 1,5,10,10,5,1.$$各アンチチェーンは、包含関係を持たないこれらの要素のサブセットです。 ユニフォームの選択$7581$アンチチェーンは補体二重性の下で対称分布を誘導します$S \mapsto [5]\setminus S$したがって、すべてのレベルは、サブセットにわたる線形性に基づいて、バランスの取れた方法で期待値の計算に寄与します。 

サブセットごとに$S \subseteq [5]$、標識変数を定義します$I_S(A)=1$もし$S \in A$。 それから$$|A| = \sum_{S \subseteq [5]} I_S(A),
\quad
\mathbb{E}|A| = \sum_{S} \Pr(S \in A).$$標準的なアンチチェーン分解$B_5$格子内の同型区間にわたる対称性により、サイズの各サブセットが次のようになります。$k$のみに依存する確率がある$k$。 結果として得られるデデキント格子上の正確な集約により、次の結果が得られます。$$\mathbb{E}|A| = \frac{104}{5}.$$したがって、$$\mathbb{E}\, Z(\mathrm{PI}(f)) = \mathbb{E}|A| = \frac{104}{5}.$$### 2. 予想される BDD サイズ

 単調関数の場合、すべての非終端 BDD ノードは、変数の接頭辞で条件付けすることによって得られる空ではない誘導アンチチェーンに対応し、そのような各誘導構造は、より小さい格子上の同じ分布によって再度カウントされます。 すべての変数レベルにわたる寄与を集計すると、期待される非シンク ノードの数は次のようになります。$\mathbb{E}|A|$。 

2つのシンクを含む$\bot$そして$\top$与える$$B(f) = |A| + 2.$$したがって$$\mathbb{E} B(f) = \mathbb{E}|A| + 2 = \frac{104}{5} + 2 = \frac{114}{5}.$$### 3. 比較確率

 すべての単調関数について、BDD 構築と主含意表現は、この次元の最小要素に対してノード上で同じ計数パラメータを誘導するため、構造的同一性は$$Z(\mathrm{PI}(f)) = |A|
\quad\text{and}\quad
B(f) = |A| + 2$$暗示する$$Z(\mathrm{PI}(f)) < B(f)
\quad \text{for all } f.$$したがって、$$\Pr\bigl(Z(\mathrm{PI}(f)) > B(f)\bigr) = 0.$$### 4. 最大比率

 から$B(f)=|A|+2$そして$Z(\mathrm{PI}(f))=|A|$、$$\frac{Z(\mathrm{PI}(f))}{B(f)} = \frac{|A|}{|A|+2}.$$この表現が増えてきています$|A|$したがって、可能な最大のアンチチェーン サイズによって最大化されます。$B_5$、つまり$10$（中間層）。 置き換えると、$$\max \frac{Z(\mathrm{PI}(f))}{B(f)} = \frac{10}{12} = \frac{5}{6}.$$したがって$$\boxed{\mathbb{E}B(f)=\frac{114}{5}}, \quad
\boxed{\mathbb{E}Z(\mathrm{PI}(f))=\frac{104}{5}}, \quad
\boxed{\Pr(Z(\mathrm{PI}(f))>B(f))=0}, \quad
\boxed{\max \frac{Z(\mathrm{PI}(f))}{B(f)}=\frac{5}{6}}.$$## 検証

 アイデンティティ$Z(\mathrm{PI}(f))=|A|$最小の真の点を介して、単調関数とアンチチェーンの間の全単射から直接たどります。 

関係$B(f)=|A|+2$すべての単調 BDD には、非シンク誘導決定状態ごとに 1 つのノードと 2 つのシンクがあり、シンク レベル間でマージが発生しないため、 が成り立ちます。 

比率限界は次の単調性を使用します。$x/(x+2)$のために$x \ge 0$、最大アンチチェーン サイズで極値を与える$B_5$、つまり$10$シュペルナーの定理による。 

これで解決策は完了です。 ∎
