 ## 解決策
 ## 問題の理解

 以下から整数の順列が与えられます。$1$に$n$とセット$m$スワップ。順列をソートするために必要な最小スワップであることが保証されています。 これらのスワップは恣意的にシャッフルされています。 タスクは、順列を正しくソートするこれらのスワップの順序を再構築することです。 各スワップは配列内の 2 つの位置に対して動作し、それらの値を交換します。 出力は、指定されたスワップを実行する順序を示すインデックスの順列です。 

順列サイズ$n$と同じ大きさにすることができます$2 \cdot 10^5$そしてスワップ数$m$まで可能です$n - 1$。 これは、どのようなソリューションも大まかに実行する必要があることを意味します。$O(n \log n)$または$O(n)$時間。 アルゴリズムを使用$O(n^2)$行動が制限時間を超える可能性があります。 エッジケースには、すでにソートされている順列が含まれます（$0$交換しますが、$m \ge 1$）、ソート順の逆の順列（最大のスワップが必要）、またはサイクル内でのみ値を移動するスワップ。 

順列サイクルの構造を無視する不用意な実装では、たとえば、指定された任意の順序でスワップを適用して配列のソートに失敗したり、サイクルを解決するかどうかを確認せずに貪欲にスワップを選択しようとしたりして、不完全なソート シーケンスが発生する可能性があります。 

## アプローチ

 ブルートフォースアプローチは、すべてを試すことです$m!$スワップの順列を作成し、毎回ソートをシミュレートして、結果がソートされた配列になるかどうかを確認します。 これは定義上は正しいのですが、$m!$階乗的に成長するため、$m = 10$このアプローチは実行不可能です。 各シーケンスのシミュレーションには以下が含まれます$m \cdot n$これが問題をさらに複雑にします。 

重要な観察は、どのような順列も互いに素なサイクルに分解でき、順列をソートするには長さの各サイクルを分割する必要が最小限であるということです。$k$正確に使用して$k-1$交換します。 最小スワップ数が正確に与えられているため、$m$、各スワップは、サイクル内の 1 つの要素の移動に対応する必要があります。 したがって、位置が頂点であり、指定されたスワップがエッジであるグラフとして問題をモデル化できます。 このグラフの各連結成分は、順列のサイクルに対応します。 サイクル内のソートは、指定されたスワップを正確に使用する限り、任意の順序で実行できます。 これにより、各コンポーネントで DFS (または任意のトラバーサル) を実行し、有効なシーケンスを再構築するために終了時間の逆の順序でスワップを出力するという問題が軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(m! * m * n) | O(n) | 遅すぎる |
 | サイクル上の DFS をグラフ化する | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を作成する`pos`どこ`pos[v]`現在の値のインデックスを保存します`v`順列の中で。 これにより、任意の要素の現在位置への O(1) アクセスが許可されます。 
2. 指定されたスワップをグラフとして表します。 各インデックスは頂点であり、各スワップは 2 つのインデックスを接続する無向エッジです。 
3. サイズの訪問済み配列を初期化します。$n$処理されたインデックスを追跡します。 
4. 各インデックスについて`i`1 から n まで、未訪問の場合は、接続されているコンポーネントで DFS トラバーサルを開始します。 コンポーネントは順列のサイクルを表します。 
5. DFS 中にエッジ (スワップ) にアクセスすると、それを使用済みとしてマークし、事後順序でスワップのリストに追加します。 これにより、サイクル内の依存関係を解決する有効な順序でスワップが適用されることが保証されます。 
6. すべてのコンポーネントの DFS が完了したら、追加された順序とは逆にスワップを出力します。 これは、各サイクルを正しくソートする順序でスワップを実行することに対応します。 

機能する理由: スワップ グラフの各連結成分は、順列のサイクルに対応します。 コンポーネントを横断し、コンポーネント内のすべてのエッジを使用することにより、サイクル内のすべての要素が正しい位置に到達することが保証されます。 スワップは最小限であるため、すべてのスワップが必要であり、逆の DFS 順序で実行すると依存関係が考慮されます。 不変条件は、コンポーネント内のすべての頂点が 1 回だけ訪問され、コンポーネント内のすべてのスワップが 1 回だけ使用され、完全性が保証されることです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

n, m = map(int, input().split())
p = list(map(int, input().split()))
edges = []
graph = [[] for _ in range(n)]

for idx in range(m):
    x, y = map(int, input().split())
    x -= 1
    y -= 1
    edges.append((x, y))
    graph[x].append((y, idx))
    graph[y].append((x, idx))

visited = [False] * n
used_edge = [False] * m
res = []

def dfs(u):
    visited[u] = True
    for v, idx in graph[u]:
        if not used_edge[idx]:
            used_edge[idx] = True
            if not visited[v]:
                dfs(v)
            res.append(idx + 1)

for i in range(n):
    if not visited[i]:
        dfs(i)

print(' '.join(map(str, reversed(res))))
```コードはまず、頂点が位置、エッジがスワップであるグラフを構築します。 訪問したノードと使用されたエッジを追跡します。 DFS は、各スワップが 1 回適用されることを保証し、スワップによって接続されたすべてのポジションを訪問します。 再帰の後にスワップを追加し、最後にそれらを元に戻すことで、依存関係が確実に尊重されます。 出力のインデックスは 1 から始まります。そのため、保存するときに 1 を追加します。`res`。
