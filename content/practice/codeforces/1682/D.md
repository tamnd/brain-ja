 ## 解決策
 ## 問題の理解

 にツリーを構築するように求められています`n`円状に配置されたノード。 各ノードには要件があります。その次数は、バイナリ文字列内の対応する文字に応じて偶数または奇数でなければなりません。`s`。 さらに、木は円の内側でエッジが交差することなく描画可能である必要があります。エッジは円周上で交わることができますが、円の内側で 2 つのエッジが交わることはできません。 

入力は複数のテスト ケースで構成され、それぞれにノード数が含まれます。`n`そして文字列`s`長さの`n`。 出力は次のいずれかになります。`NO`有効なツリーが存在しない場合、または`YES`その後に、エッジのリストとしてツリーの説明が続きます。 

制約により、最大で処理する必要があります。`2×10^5`すべてのテスト ケースの合計でノード数が増加し、個々のテスト ケースも最大で 6 ノードに達します。`2×10^5`ノード。 これにより、以下よりも複雑なアルゴリズムは除外されます。`O(n)`テストケースごとに。 二次方程式の解は非常に遅すぎます。 

重要なエッジケースは、すべてのノードにラベルが付けられている場合です。`0`または`1`。 たとえば、次の場合`n = 2`そして`s = "10"`、唯一の可能なエッジはノード 1 と 2 を接続します。ノード 1 は次数 1 (奇数) を持ち、ノード 2 は次数 1 (奇数) を持ちます。 これはノード 1 の奇数次の要件を満たしますが、ノード 2 では満たさないため、答えは次のようになります。`NO`。 もう一つの微妙なケースは次のような場合です。`n`は奇数であり、すべてのノードは偶数次数を必要とします。 奇数のノードを持つツリーは、次数の合計が常に偶数になります (次の理由により、`n-1`エッジ、次数の合計 = 2(n-1))、パリティ制約により不可能になる可能性があります。 

## アプローチ

 ブルートフォース手法では、円上に交差せずに描画できるすべてのツリーを生成し、次数制約をチェックしようとします。 のために`n = 10^5`、指数関数的に多くの木が存在するため、このアプローチは実行不可能になります。 

重要な観察は、円上に内部交差なしで描かれた木はすべて「星型」構造でなければならないということです。ルート ノードを選択し、それを円の周囲のノードの連続セグメントに接続します。 奇数次数の 1 つのノードを「中心ハブ」として選択すると、円に沿ってエッジをチェーンし、必要に応じてハブを他のノードに接続できます。 これが機能するのは、隣接するノードに沿ってエッジを描画しても交差が発生せず、ハブにエッジを追加すると平面性が維持されるためです。 

問題はパリティのチェックに帰着します。 ツリーは常に正確に`n-1`エッジなので、ノード次数の合計は次のようになります。`2*(n-1)`。 の数であれば、`1`にいる`s`が奇数の場合、必要な次数の合計が奇数となり、問題は不可能になります。 の数であれば、`1`s がゼロの場合、ノード 1 をハブとして選択し、すべてのノードを順番に接続できます。 あれば`1`s、任意のノードを選択します。`1`残りをハブとして接続します`1`s をそれにリンクし、円の周りの残りのノードをリンクします。 これにより、正しい次数パリティと交差がないことが保証されます。

 ## アルゴリズムのチュートリアル

 1. の数を数えます`1`文字列内の s`s`。 奇数の場合は出力`NO`ノード次数の合計が奇数になるため、停止します。これはどのツリーでも不可能です。 
2. ない場合`1`s、出力`YES`すべてのノードを単純なサイクル方式で接続します。ノード 1 はノード 2 に接続し、ノード 2 はノード 3 に接続し、...、ノード`n-1`ノードへ`n`。 これにより、すべての内部ノード (偶数) が次数 2、エンドポイントが次数 1 のツリーが形成されます (n > 2 の場合でも、エンドポイントは循環的な意味で調整されます)。 実際、完全にゼロの場合、簡素化のためにノード 1 を他のすべてに直接接続し、偶数の次数を生成できます。 
3. それ以外の場合は、偶数個の`1`s. 任意のノードを選択します`c`どこ`s[c] = 1`中央ハブとして。 このノードは他のノードへの接続を吸収します`1`s. 円を時計回りに移動します。 ノードを見つけるたびに、`1`それはハブではない場合は、ハブに直接接続します。 これにより、すべてが保証されます`1`の次数は奇数です。 
4. みんなのために`0`二人の間`1`円に沿って、各ノードを前のノードに接続します。 これにより、次のような連鎖が構築されます。`0`交差点のない円に沿って進みます。 
5. 上記の手順で収集したエッジを出力します。 この構造により、各ノードがパリティ要件を満たし、エッジが円内で交差しないことが保証されます。 

機能する理由: ハブは他のすべての接続を吸収します。`1`s、奇数の学位を与えます。 の鎖`0`偶数の度数を生成します。 円を横断し、隣接するものまたはハブのみを接続するため、内部交差は発生しません。 パリティ制約は次の合計であるため満たされます。`1`s は偶数であり、以下と互換性のある必要な学位の合計が均等であることが保証されます。`2*(n-1)`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        ones = [i for i, ch in enumerate(s) if ch == '1']
        if len(ones) % 2 == 1:
            print("NO")
            continue
        if len(ones) == 0:
            print("YES")
            for i in range(2, n+1):
                print(1, i)
            continue
        hub = ones[0]
        edges = []
        for i in range(n):
            u = i
            v = (i+1)%n
            if v == hub:
                continue
            edges.append((u+1, v+1))
        for i in range(1, len(ones)):
            edges.append((hub+1, ones[i]+1))
        print("YES")
        for u,v in edges:
            print(u,v)

if __name__ == "__main__":
    solve()
```解決策は、入力を読み取り、位置をカウントすることから始まります。`1`s. カウントが奇数の場合は印刷されます`NO`。 それ以外の場合は、すべてゼロの特殊な場合と偶数の一般的な場合を処理します。`1`s. エッジは、次のノードがハブでない限り、連続するノードを接続することによって構築されます。`1`ハブに接続します。 出力ループは、必要に応じて 1 から始まるインデックスですべてのエッジを出力します。
