 ## 解決策
 ## 問題の理解

 いくつかの独立したテスト ケースが与えられています。 各テスト ケースは、カードの行を表す一連の整数です。 この行から任意の連続セグメントを選択し、そのセグメントについて、奇数値の数からその中の素数値の数を引いたものとして定義されるスコアを計算します。 タスクは、空ではないすべての連続セグメントにわたって可能な最大スコアを見つけることです。 

構造は純粋に線形であるため、すべての決定はサブ配列の開始位置と終了位置に基づいて行われます。 連続した間隔を超える組み合わせ選択はありません。これは、指数関数的な推論ではなく、接頭辞ベースまたはカダン スタイルの推論を即座に示唆します。 

制約は十分小さいので、$O(n^2)$テスト溶液ごとに合格します。 合計あり$n \le 2000$、すべての部分配列を評価する二重ループでも約 400 万回の操作が必要ですが、Python では問題ありません。 ただし、意図したソリューションはテスト ケースごとに線形です。 

微妙な点は、「奇数」と「素数」の相互作用にあります。 2 を除くすべての素数は奇数であるため、素数は奇数と重なり合います。 これは、貢献が独立したカテゴリではないことを意味します。 数値は奇数の数を増やし、同時に素数の数を減らすことができます。 数値 2 は奇数ではない唯一の素数であるため、他の素数とは異なる動作をします。 

単純な間違いは、スコアを 2 つの独立した配列として扱ったり、オッズと素数のプレフィックス カウントが重複していることに気づかずに別々に試行したりすることです。 もう 1 つの間違いは、素数がオッズのサブセットとしてのみ重要であると想定していることです。 実際、奇数でない素数 (2 つだけ) であってもスコアは低下し、奇数の素数は、正しく扱われないと正味ゼロになります。 

たとえば、2 だけを含むセグメントについて考えてみましょう。スコアは次のとおりです。$0 - 1 = -1$。 奇数の素数のみを「悪いオッズ」としてカウントする不注意なアプローチは、それを誤って中立として扱うことになります。 

## アプローチ

 ブルート フォース ソリューションは、すべてのサブ配列を評価し、そのスコアを直接計算します。 インデックスの各ペアについて$l, r$、セグメントをスキャンし、オッズと素数を数えます。 これは定義に直接従うため、単純かつ正しいです。 ただし、同じ作業が繰り返し繰り返されます。各セグメントはカウントを最初から再計算します。 

このアプローチの時間計算量は次のとおりです。$O(n^3)$文字通り実装された場合、テストケースごとに、$O(n^2)$サブ配列とそれぞれのテイク$O(n)$評価すること。 プレフィックスの合計が評価​​を低下させたとしても$O(1)$、奇数インジケーターと素数インジケーターの両方を注意深くエンコードする必要がありますが、それはそれを減らすだけです$O(n^2)$、制約の下では許容されますが、最適ではありません。 

重要な観察は、各要素が独立してスコアに寄与しているということです。 それぞれの値について$a_i$、重みを割り当てることができます。 

奇数の場合は +1 を与えます。 素数の場合は -1 を与えます。 両方（奇数素数）の場合、純寄与は 0 です。 どちらでもない場合は、0 が与えられます。2 は唯一の偶数素数であるため、-1 が与えられます。 すべての奇数の素数は +1 と -1 に寄与し、0 に相殺されます。 

これにより、問題は、各要素が固定の重みを持つ変換された配列上で最大の部分配列の合計を見つけることになります。 まさにカダネのアルゴリズムです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^3)$または$O(n^2)$|$O(1)$| 遅すぎる / 制限内で受け入れられる |
 | オプティマル (カダネ) |$O(n)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各数値が素数かどうかを事前計算します。 値が上がるので、$10^6$、グローバルで一度ふるいを使用します。 これにより、各テスト ケース内での素数チェックの繰り返しが回避されます。 
2. 各要素について$a_i$、その寄与を計算します。 

奇数の場合は、基本スコアに +1 を加えます。 素数の場合は、1 を減算します。これにより、問題を表す単一の整数配列が生成されます。 
3. この変換された配列に対して最大部分配列合計アルゴリズムを実行します。 ここでの最高の結果と世界最高を維持してください。 
4. 各位置で、前のセグメントを延長するか、新たに開始するかを決定します。 この選択は、負のプレフィックスが将来の利益に悪影響を与えるかどうかを反映します。 
5. すべての位置にわたって見られる最大値を追跡します。 

ステップ 4 の背後にある理由は、最適なセグメントには前の要素が含まれるか、再開される必要があるということです。 選択した部分配列内の要素をスキップしてもメリットはありません。 

### なぜ効果があるのか

 変換後、各要素は固定の独立した値をサブ配列に提供します。 部分配列のスコアは、この変換された配列内の要素の合計になります。 合計を最大化する連続セグメントは、まさに古典的な最大部分配列問題です。 Kadane のアルゴリズムの貪欲な移行により、合計が負のプレフィックスはすべて破棄されます。これは、そのセグメント内の将来の合計がすべて削減されるためです。そのため、再起動により、より良いまたは同等の結果が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXV = 10**6

# Sieve for primality
is_prime = [True] * (MAXV + 1)
is_prime[0] = is_prime[1] = False
for i in range(2, int(MAXV ** 0.5) + 1):
    if is_prime[i]:
        step = i
        start = i * i
        for j in range(start, MAXV + 1, step):
            is_prime[j] = False

t = int(input())
for _ in range(t):
    n = int(input())
    arr = list(map(int, input().split()))

    best = -10**18
    cur = -10**18

    for x in arr:
        val = 0
        if x % 2 == 1:
            val += 1
        if is_prime[x]:
            val -= 1

        if cur == -10**18:
            cur = val
        else:
            cur = max(val, cur + val)

        best = max(best, cur)

    print(best)
```ふるいは、各テスト ケース中に素数チェックが一定時間行われることを保証するために、グローバルに 1 回構築されます。 各数値は個別に寄与度に変換されます。 Kadane ステップでは標準的な繰り返しが使用されます。つまり、現在の要素で新しい部分配列を開始するか、前の要素を拡張します。 

の初期化`cur`センチネルを使用すると、最初の要素のあいまいさが回避され、最初の値が常にセグメントをきれいに開始することが保証されます。 

## 実用的な例

 配列を考えてみましょう。`[1, 2, 3, 4]`。 

寄与度を計算します。 

- 1: 素数ではない奇数 → +1
 - 2: 偶数素数 → -1
 - 3: 奇数素数 → +1 - 1 = 0
 - 4：プライム以外でも → 0

 したがって、変換された配列は`[1, -1, 0, 0]`。 

| インデックス | 値 | 貢献 | 最高のエンディングはここにあります | グローバルベスト |
 | --- | --- | --- | --- | --- |
 | 1 | 1 | 1 | 1 | 1 |
 | 2 | 2 | -1 | 0 | 1 |
 | 3 | 3 | 0 | 0 | 1 |
 | 4 | 4 | 0 | 0 | 1 |

 最大セグメントは`[1]`これは、負の寄与 (2 など) が潜在的なゲインをリセットすることを確認します。 

ここで考えてみましょう`[2, 3, 5, 4]`。 

貢献:

 -2 → -1
 - 3 → 0
 - 5 → 0
 - 4 → 0

 | インデックス | 値 | 貢献 | カー | ベスト |
 | --- | --- | --- | --- | --- |
 | 1 | 2 | -1 | -1 | -1 |
 | 2 | 3 | 0 | 0 | 0 |
 | 3 | 5 | 0 | 0 | 0 |
 | 4 | 4 | 0 | 0 | 0 |

 最適なセグメントは`[3, 5, 4]`0 を与えると、負の要素の後に開始すると結果が改善されることがわかります。

## 特殊なケース

 2 に等しい単一の要素は、最も重要な境界ケースです。 アルゴリズムはそれに値 -1 を割り当てます。負の接頭辞から拡張しても将来の合計が減少するだけであるため、Kadane はそれをスタンドアロンの部分配列として正しく処理します。 

奇数の素数だけからなる配列では、寄与がすべてゼロになります。 部分配列の最大合計は 0 になり、Kadane は空ではないセグメントを自然に選択し、特別なケースなしでキャンセルが正しく処理されることを確認します。 

大きな正の値と単一の負の値が交互に並ぶ配列は、Kadane の再起動動作を示しています。 -1 が表示されると常に累計が減少し、有益であればその後アルゴリズムが再起動され、最適なセグメンテーションが保証されます。
