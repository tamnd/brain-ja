 ## 解決策
 ## 問題の理解

 井戸には深さがある`0`に`n`、 どこ`0`地面であり、`n`カエルの開始位置です。 

カエルが現在深海で休んでいると仮定します。`i`。 そこから、次の間のジャンプ長を選択します。`0`そして`a[i]`, そのため、ジャンプはどの深さでも着地できます$$j \in [i-a_i,\; i]$$上に移動すると深さが浅くなるためです。 

深度に着陸した後`j`、カエルはすぐに滑り落ちます`b[j]`そして結局休憩するのは$$j+b_j.$$次のジャンプは、この新しい静止位置から始まります。 

深さに到達するために必要な最小限のジャンプ数を見つけなければなりません`0`。 最小数に加えて、各ジャンプの直後とスリップする前に到達した深さのシーケンスも出力する必要があります。 

最初に注目すべきことは、制約のサイズです。 ウェルの深さは次のように大きくすることができます。`300000`。 あらゆる位置からのあらゆる可能なジャンプを明示的に考慮した解は二次方程式となります。 最悪の場合、各位置はほぼすべての浅い位置にジャンプし、大まかな結果が生じる可能性があります。$$1 + 2 + \cdots + n = O(n^2)$$トランジション、周囲`9 × 10^10`いつ`n = 300000`。 それは2秒以内ではまったく不可能です。 

課題は最短経路を見つけることではありません。 すべてのジャンプにはちょうど 1 回の移動が必要となるため、幅優先探索は自然な選択です。 課題は、グラフを効率的に表現することです。 

ポジションがそれ自体にのみジャンプできる場合、微妙なエッジケースが発生します。```
n = 1
a = [0]
b = [0]
```カエルは深いところから始まる`1`、まったく上に移動できず、深さに到達することはありません。`0`。 答えは`-1`。 すべてのノードに少なくとも 1 つの発信移動があると想定する不用意な実装は、永久にループする可能性があります。 

もう 1 つの重要なケースは、深さに到達した場合です。`0`ジャンプ中に直接起こります。```
n = 2
a = [0, 2]
b = [0, 0]
```深さから`2`、カエルは深いところに直接ジャンプできます`0`。 旅行はすぐに終了するため、スリップは発生しません。 答えは1回のジャンプです。 着陸後に常にスリップを適用する実装では、プロセスが誤って続行されます。 

3 番目の注意が必要なケースは、いくつかの異なる着地深さによって同じ静止位置が生成される可能性があることです。```
n = 3
a = [0, 2, 2]
b = [1, 1, 0]
```両方の着陸深度`1`そして`2`同じ将来の状態につながる可能性があります。 BFS は、すでに処理された状態を再訪しないようにする必要があります。そうしないと、冗長な作業が実行されます。 

## アプローチ

 単純なグラフ モデルは簡単に作成できます。 

すべての静止深度を頂点として扱います。 深さから`i`、あらゆる着陸深度$$j \in [i-a_i, i]$$静止深度に向かうエッジを作成します$$j+b_j.$$もし`j=0`、目標を達成しました。 

このグラフで BFS を実行すると、すべてのエッジが 1 つのジャンプに正確に対応するため、ジャンプの最小数が正しく検出されます。 問題はグラフのサイズです。 単一の頂点には次のものを含めることができます`O(n)`発信エッジ、生成`O(n²)`全体的にエッジ。 

重要な観察は、遷移公式が逆転する可能性があるということです。 

私たちが現在静止深度にいると仮定します。`v`。 どうやってここにたどり着いたのでしょうか？ 

最後のジャンプはある程度の深さに着地したに違いない`x`そのような$$x+b_x=v.$$に着陸した後、`x`、カエルは滑り落ちました`v`。 

次に、前の静止位置を考えてみましょう`p`。 からのジャンプ`p`に着陸できるかもしれない`x`場合のみ$$p-a_p \le x.$$並べ替えると$$p \ge x.$$だから、どの先人も`p`間隔の中にある$$[x,\; n].$$広大な前方範囲を探索する代わりに、深度から開始して後方に BFS を実行します。`0`。 

着陸深度ごとに`x`、まだ処理されていないすべてのポジションを訪問する必要があります`p`満足のいく$$p-a_p \le x.$$各ポジションは 1 回だけ処理する必要があります。 まさにここで、素集合スタイルの「次の未訪問インデックス」構造が役立ちます。 

まだ訪問されていないすべてのポジションをリンクセット構造で維持します。 ポジションが発見された場合、そのポジションは永久に削除されます。 次に、範囲をスキャンすると、ほぼ一定の時間ですでに処理されたインデックスがスキップされます。 

結果として得られる BFS は、すべての深さを 1 回訪問し、すべての深さを 1 回削除して、ほぼ線形のソリューションを提供します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 明示的なグラフに対するブルート フォース BFS | O(n²) | O(n²) | 遅すぎる |
 | リバース BFS + 次に未訪問の DSU | O(n α(n)) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 から深さを番号付けします`0`に`n`。 

深み`1..n`入力配列に対応します。 深さ`0`地面です。 

### 1. リバース情報を構築する

 あらゆる着陸深度に対して`x`、計算する$$to[x] = x + b_x.$$カエルが着地したら`x`、それは次のようになります。`to[x]`。 

静止深度からリバースBFSを実行しているとき`v`、あらゆる着陸深度を満足`to[x]=v`関連性が高まります。 

そういったものをすべて保管しておく`x`インデックスが付けられたバケット内の値`v`。 

### 2. BFS を深さ 0 から開始します

 奥行き`0`成功を表します。 

BFS を逆方向に実行すると、`dist[v]`静止深度から地面に到達するために必要な最小限のジャンプ数になります。`v`。 

初期化:```
dist[0] = 0
queue = [0]
```### 3. Maintain all undiscovered positions in a DSU structure

 あらゆる深さに対して`i`から`1`に`n`、未発見のまま始まります。 

DSU は以下をサポートします。```
find(i)
```少なくとも最小の未発見の位置を返します`i`。 

位置決め時`i`発見された場合は、リンクして削除してください`i+1`。 

これにより、以前にすでに処理された位置をスキップしながら、間隔をスキャンすることができます。 

### 4. BFS 状態を処理する v

 あらゆる着陸深度に対して`x`満足のいく```
x + b[x] = v
```前のすべての静止位置が必要です`p`ジャンプできるのは`x`。 

条件は$$p-a_p \le x.$$同様に、すべての未発見の位置は、$$[x,\; n]$$左リーチが最大であるのは誰ですか`x`もう 1 回のジャンプで到達可能になります。 

公式ソリューションで使用される逆定式化では、間隔内のまだ訪問されていないすべての位置がスキャンされます。`[L,n]`、 どこ$$L=x.$$DSU を使用すると、各位置が最初に検出されると永久に削除されます。 

### 5. 親情報を記録する

 新しい静止深度になると`p`着陸深度によって発見される`x`:```
parent[p] = v
jump[p] = x
```値`jump[p]`その移動で使用された着地の深さを保存します。 

この情報は、後で必要なシーケンスを再構築するのに十分です。 

### 6. BFS を続行する

 新しく発見されたすべての位置をキューにプッシュします。 

BFS は距離を増やすことによって状態を探索するため、最初に位置に到達した時点ですでに最小限のジャンプ数が得られます。 

### 7. 答えを再構築する

 深さの場合`n`決して発見されませんでした、印刷`-1`。 

それ以外の場合はから開始します`n`そして繰り返しフォローする`parent`。 

すべてのステップに、対応するコードを追加します。`jump`価値。 

収集された着地深さは逆の順序で表示されるため、印刷する前に逆にしてください。 

### なぜ効果があるのか

 逆 BFS グラフは、すべてのエッジが反転された元のグラフとまったく同じです。 長さのあるパス`k`深さから`n`深さまで`0`元のグラフでは、長さのパスに対応します`k`から`0`に`n`反転したグラフで。 

重み付けされていないグラフ上の BFS は常に最短パス距離を見つけます。 すべてのジャンプには 1 回の移動が必要なため、最初に静止深度が検出されたときにその最小ジャンプ数が決まります。 

DSU 構造は、到達可能な頂点を変更することはありません。 以前にすでに検出されていた頂点のみをスキップします。 すべての深度は 1 回だけ削除されるため、有効な先行データが失われることはなく、頂点が 2 回処理されることもありません。 

親ポインタは頂点が最初に検出されたときに記録されるため、最短パス ツリーが記述されます。 からの指摘に従って、`n`に戻る`0`1 つの最小ジャンプ解を再構築します。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n = int(input())
    a = [0] + list(map(int, input().split()))
    b = [0] + list(map(int, input().split()))

    buckets = [[] for _ in range(n + 1)]

    for x in range(1, n + 1):
        buckets[x + b[x]].append(x)

    parent = [-1] * (n + 1)
    jump = [-1] * (n + 1)
    dist = [-1] * (n + 1)

    nxt = list(range(n + 2))

    def find(x):
        while nxt[x] != x:
            nxt[x] = nxt[nxt[x]]
            x = nxt[x]
        return x

    def erase(x):
        nxt[x] = find(x + 1)

    q = deque([0])
    dist[0] = 0

    while q:
        v = q.popleft()

        for x in buckets[v]:
            cur = find(x)

            while cur <= n and cur - a[cur] <= x:
                dist[cur] = dist[v] + 1
                parent[cur] = v
                jump[cur] = x

                erase(cur)
                q.append(cur)

                cur = find(cur)

    if dist[n] == -1:
        print(-1)
        return

    ans = []
    cur = n

    while cur != 0:
        ans.append(jump[cur])
        cur = parent[cur]

    ans.reverse()

    print(len(ans))
    print(*ans)

solve()
```バケット配列にはすべての着陸深度が保存されます`x`スリップ後の目的地ごとにグループ化`x + b[x]`。 これはグラフを逆に表現したものです。 

DSUアレイ`nxt`まだ発見されていない位置のリンクされたリストとして機能します。 電話をかける`find(i)`少なくとも最初の未発見の深さを返します`i`。 奥深さを知った後は、`erase()`それを永久に削除します。 

ソリューションの核心は次のとおりです。```
cur = find(x)

while cur <= n and cur - a[cur] <= x:
```条件$$cur-a[cur]\le x$$静止深度からのジャンプを意味します`cur`深度まで着陸できる`x`。 

このような深さは発見されるとすぐに DSU から削除されます。 各深さは最初の訪問後に永久に消えるため、BFS 全体にわたるループ反復の合計数はわずか`O(n)`。 

親ポインターは前の BFS ノードを保存します。`jump[cur]`最短パスのエッジで使用される着陸深さを保存します。 再構築は、これらのポインタを逆方向にたどります。`n`。

    b = [0] + list(map(int, input().split()))

    for x in range(1, n + 1):
        buckets[x + b[x]].append(x)

    jump = [-1] * (n + 1)
    dist = [-1] * (n + 1)

    nxt = list(range(n + 2))

    def find(x):
        while nxt[x] != x:
            nxt[x] = nxt[nxt[x]]
            x = nxt[x]
        return x

    def erase(x):
        nxt[x] = find(x + 1)

    q = deque([0])
    dist[0] = 0

    while q:
        v = q.popleft()

        for x in buckets[v]:
            cur = find(x)

            while cur <= n and cur - a[cur] <= x:

0 0
```深さ`2`着地の深さに直接ジャンプできる`0`。 逆のグラフでは深さ`2`～の前身となる`0`、そのため、BFS は距離を指定するとすぐにそれを検出します`1`。 再構築により単一の着陸深度が得られる`0`。

極端なケースを考えてみましょう。`a[i]=i`。
