 ## 解決策
 ## 問題の理解

 (a \times a) 正方形のキャンバスと (b \times b) 正方形のブラシがあります。 ブラシは左上隅から正確に開始されるため、キャンバスのこの (b \times b) 部分はすでにペイントされています。 ブラシは水平または垂直にのみスライドでき、ブラシのどの位置でもブラシで覆われた正方形の領域をペイントします。 キャンバスのすべての点がペイントされる前に、ブラシの中心が移動する最小の合計距離が必要です。 公式声明では、答えは常に整数であることが確認されています。 

制約は定数時間の演算には十分小さいですが、面積に比例するシミュレーションを除外するには十分な大きさです。 (a) が (10^6) と同じ大きさである場合、キャンバスには (10^{12}) 個の単位セルを含めることができます。 したがって、二次シミュレーションは最悪の場合でも 1 兆回のオーダーで実行され、2 秒の制限が許容するものをはるかに超えます。 ジオメトリには直接合計できる繰り返し構造があるため、辺の長さにわたる線形スキャンさえ不要です。 

最初のエッジ ケースは (a=b) です。 最初のブラシはすでにキャンバス全体をカバーしているため、答えはゼロです。 たとえば、入力`1 1`生産しなければならない`0`。 常に少なくとも 1 つのサイド トラバーサルを追加する実装では、誤って肯定的な応答が生成されます。 

2 番目のエッジ ケースは、(a=4,b=2) のように、ブラシがキャンバスに正確に 2 回収まる場合です。 答えは(8)ではなく(6)です。 不注意な実装では、長さの完全な 4 つの辺 (a-b=2) がカウントされる可能性がありますが、残りの領域はパスの終端部分として処理できるため、最終ステージでは別の完全なリングは必要ありません。 

3 番目のエッジ ケースは、(a=7,b=3) のように、(a) が (2b) の倍数のすぐ上の場合に発生します。 答えは(14)です。 ここで、最も内側に残っている正方形には、ブラシよりも小さい辺 (1) があります。 最後の正方形を別の通常のリングとして扱うと、1 つずつずれたエラーが発生します。 最後の残りは個別に処理する必要があります。 

4 番目のエッジ ケースは、(2b) で正確に割り切れます。 (a=6,b=3) の場合、答えは (9) です。 単に (a \bmod 2b=0) を最終剰余として使用すると、数式は剰余を誤ってゼロとして扱うことになります。 代わりに、最後の完全な層を終端層と見なす必要があります。 閉じた形式の実装では、完全な再帰層の数を減らし、残りのゼロを (2b) で置き換えることによってこれを処理します。 

## アプローチ

 直接シミュレーションでは、キャンバスをグリッドとして考え、どの単位セルがペイントされたかを記録しながらブラシを繰り返し動かします。 最小のブラシの場合 (b=1)、すべての単位セルを訪問する必要があり、最適なパスには (a^2-1) 個の単位長の移動が含まれます。 最大入力 (a=10^6,b=1) の場合、つまり (999999999999) が動きます。 したがって、ペイントされた個々のセルのシミュレーションは (\Theta(a^2)) となり、最悪の場合のスケールは (10^{12}) 演算になります。 

すべての動きを明示的にチェックできるため、総当り的なアプローチは機能しますが、内側に移動すると同じ幾何学模様が繰り返されるため失敗します。 重要な観察は、ブラシが正方形の外層をペイントした後、ペイントされていない部分自体が小さな正方形であるということです。 その辺の長さは、前のものよりちょうど (2b) 小さくなります。 これにより、幾何学的な問題が反復的なものになります。 

現在のペイントされていない正方形に辺 (x) があるとします。 (x>2b) の場合、ブラシは境界のすべての部分に到達するために 4 つの側面をスイープする必要があります。 ブラシの中心は、各辺に沿って距離 (x-b) だけ移動します。これは、中心が一方の端からもう一方の端までの範囲にあり、ブラシの (b/2) が各端を超えて伸びているためです。 したがって、完全なレイヤーにはコストがかかります

 [
 4(x-b)。 
】

 このレイヤーの後、残った未塗装の正方形には側面が表示されます。 

[
 x-2b。 
】

 したがって、同じ推論を再度適用することができます。 

最終的に残った辺は最大でも(2b)になります。 これが再発の終末部分です。 残りの辺が (r) で (b<r\le 2b) の場合、残りの正方形は 3 つの辺を横断することで完成します。 

[
 3(r-b)。 
】

 (r\le b) の場合、ブラシはすでに残りの正方形をカバーしています。 最終的な閉じた形式に使用されるコンパクトな再帰では、この最終寄与は (r-b) で表されます。 これは、独立した負の動きではなく、前の完全なレイヤーのトラバースに対する修正であるため、負の値になる可能性があります。 この漸化式とその代数的拡張により、受け入れられている閉じた形式が得られます。 

(d) を (4(x-b)) ルールを使用する完全な外層の数とします。 現在の辺の長さは次のとおりです。 

[
 a、\quad a-2b、\quad a-4b、\quad \ldots、\quad a-2(d-1)b。 
】

 彼らの総コストは

 [
 4\sum_{i=0}^{d-1}\left(a-(2i+1)b\right)。 
】

 内部の合計は等差数列です。 

[
 da-b(1+3+5+\cdots +(2d-1))。 
】

 最初の (d) 奇数の合計は (d^2) であるため、完全なレイヤーのコストは

 [
 4(da-d^2b)。 
】

 残った辺は、

 [
 r=a-2db。 
】

 (r\le b) の場合、端末補正は (r-b) になります。 (r>b) の場合、(3(r-b)) となります。 

(r) を計算する前に、特殊なケースが 1 つあります。 (a) が (2b) で割り切れる場合、(d=a/(2b)) を使用すると (r=0) のままになりますが、最後の層は実際にはサイズ (2b) の終端層になります。 代わりに、(d) を 1 つ減らして (r=2b) に設定します。

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(a^2)) | (O(a^2)) | 遅すぎる |
 | 再帰的リング和 | (O(a/b)) | (O(a/b)) 再帰的に実装された場合 | 正しいが不要 |
 | 閉じた形式の算術 | (O(1)) | (O(1)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. キャンバス面 (a) とブラシ面 (b) を読み取ります。 最適なパスは同心円状の正方形の層の順序に完全に依存するため、必要な量はこれら 2 つの長さだけです。 
2. 整数除算を使用して (d=a/(2b)) を計算し、(r=a\bmod(2b)) を計算します。 この除算により、(2b) によって辺を何倍削減できるかがわかり、残りは終端層を特定します。 
3. (r=0) の場合、(d) を 1 減らし、(r) を (2b) に置き換えます。 これは、空の残りの正方形を作成するのではなく、最後の正確なレイヤーを終端レイヤーとして扱います。 
4. (d) 完全な層の寄与を次のように計算します。 
[
 4(da-d^2b)。 
】
 これは、すべての層の辺の長さにわたる (4(x-b)) の合計から直接得られます。 
5. 端末寄与を計算します。 (r\le b) の場合は (r-b) を追加します。 (r>b)の場合は(3(r-b))を加算します。 2 つのケースは、ブラシがすでに最終領域をカバーしているか、ペイントするために最後の 3 回のトラバースが必要であるかに対応します。 
6. 完全層寄与分と端末寄与分を加算し、結果を出力します。 すべての演算は整数演算であるため、浮動小数点の精度の問題はありません。 

### なぜ効果があるのか

 不変条件は、すべてのレイヤーが完成した後、すでにペイントされた領域がまさにそのレイヤーによって生成された外側の境界線であり、依然として重要な唯一の領域は辺が (2b) だけ減少した正方形であるということです。 すべての非終端レイヤーについて、境界全体をペイントするには、ブラシの中心がそのレイヤーの 4 つの角に対応する 4 つの極端な位置に到達する必要があります。 移動は水平方向と垂直方向に制限されているため、4 つの極端な位置すべてを訪問するには、正確に周囲の寄与 (4(x-b)) が必要です。 そのレイヤーが終了したら、同じ議論が小さな正方形にも適用されます。 このプロセスは、残りの辺が最大 (2b) になると終了します。この場合、最終公式は可能な限り最短の最終走査を示します。 したがって、合計は実行可能なパスをカウントし、すべての層で必要な避けられない距離と一致します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a, b = map(int, input().split())

    d = a // (2 * b)
    r = a % (2 * b)

    if r == 0:
        d -= 1
        r = 2 * b

    ans = 4 * (d * a - d * d * b)

    if r <= b:
        ans += r - b
    else:
        ans += 3 * (r - b)

    print(ans)

if __name__ == "__main__":
    solve()
```最初の部分では、完全な (2b) 厚さの層を何層除去できるかを計算します。 変数`d`は 4 辺の公式を使用するレイヤーの数です。`r`最終層側です。 

可分性チェックには特別な注意が必要です。 のために`a = 4, b = 2`、普通の除算は次のようになります`d = 1`そして`r = 0`。 正しい解釈は、ゼロ完全層の後にサイド (4) の終端層が続くことであるため、コードはこれらの値を次のように変更します。`d = 0`そして`r = 4`。 

表現`4 * (d * a - d * d * b)`は算術級数の合計です。 Python の整数には任意の精度があるため、最大入力の答え (ほぼ (10^{12})) には特別な整数型は必要ありません。 

終了条件は次を使用します。`r <= b`、 それよりも`r < b`、辺がまさにブラシ面である残りの正方形がすでにブラシの内側に完全に収まっているためです。 この境界条件により、`1 1`正しくゼロを生成します。 

このコードは再帰を実行せず、グリッドを割り当てません。 入力値と一定数の整変数を正確に使用します。

 ## 特殊なケース

 のために`1 1`、 (d=0) と (r=1) があります。 (r\le b) であるため、端末寄与率は (r-b=0) であるため、アルゴリズムは次のように出力します。`0`。 最初のブラシはすでにキャンバス全体をペイントしており、数式は動きを生み出しません。 

のために`4 2`、(2b=4) で除算した後の剰余はゼロです。 アルゴリズムが変わる`d`(1)から(0)への変化`r`(0) から (4) まで。 最終貢献度は (3(4-2)=6) になります。 これはまさに、ゼロの剰余を誤って処理する実装を捕捉するケースです。 

のために`3 1`、 (d=1) と (r=1) が得られます。 完全なレイヤーは (4(3-1)=8) に寄与しますが、末端補正は (1-1=0) です。 結果は`8`、これは、左上の単位セルから開始して 9 つの単位セルすべてを訪問する最短パスに対応します。 

のために`6 3`, (a) はまさに (2b) です。 割り算調整後、`d=0`そして`r=6`。 最終的なケースは (r>b) であるため、答えは (3(6-3)=9) となります。 これは、問題全体が 1 つの最終層で構成される境界を捉えます。 

のために`1000000 1`、ブラシは単一点であるため、すべての単位セルを訪問する必要があります。 数式は戻ります`999999999999`、公式の例の最大の答えと一致します。
