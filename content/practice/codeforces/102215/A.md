 ## 解決策
 ## 問題の理解

 ダンジョンは部屋が直線的につながっています。 通路`i`部屋を繋ぐ`i-1`部屋へ`i`したがって、出口に向かって進むということは、常に配列を左から右に処理することを意味します。 

各配列値は、パスの色とパスの動作の両方を記述します。 正の値`c`通過するかどうかをチェックすることを意味します`c`はまだ有効です。 負の値`-c`通路はいつでも渡れるが、渡った後は通過することを意味します。`c`無効となります。 

スタートルームに向けて`s`、最初はすべてのパスが有効です。 移動が不可能になるまでに、通過に成功した通路の数が必要です。 同様に、最初に遮断された通路が`j`、答えは`j - s - 1`。 私たちを妨げる通路がない場合、答えは次のとおりです。`n - s`。 

重要な相互作用は、ある色のネガティブな出現とその後の同じ色のポジティブな出現との間にあります。 渡ったら`-c`、後ほど`+c`遮断通路となります。 否定的な通路自体が動きを妨げることはありません。 

と`n`まで`500000`、すべての開始部屋からの移動を個別にシミュレートするアルゴリズムはあまりにも高価です。 簡単なシミュレーションで以下のことを検査します。`n-s`スタートのための通路`s`、与える

 [
 n+(n-1)+\cdots+1=\frac{n(n+1)}2
 】

 通過検査。 最大でも`n`、これについてです`1.25 \cdot 10^{11}`2 秒の制限に収まらない操作。 線形または線形に近い解決策が必要です。 

オフバイワンエラーを簡単に引き起こす可能性のある境界ケースがいくつかあります。 たとえば、ある一節で、```
1
-1
```答えは`1`、なぜなら、否定的な通路がその人を妨げることは決してないからです。 無効化を即時停止として扱うソリューションでは、誤った出力が発生します。`0`。 

2 番目の重要なケースは、ネガティブなパッセージの後に同じ色のポジティブなパッセージが続く場合です。```
2
-1 1
```お部屋からスタート`0`、最初の通路を渡ってから 2 番目の通路で停止するので、出力は次のようになります。`1 1`。 ポジティブなパスそのものは、成功したクロスとしてカウントされません。 

開始部屋の前にマイナスの出来事が発生しても、旅行に影響を与えてはなりません。 例えば、```
3
-1 1 1
```出力があります`1 2 1`。 お部屋からスタート`1`、早いほど`-1`パスは旅行の開始時に最初から有効であるため、これは無関係です。 開始部屋の右側にあるものだけを記憶するのではなく、すべてのネガティブな出来事をグローバルに記憶するソリューションでは、この問題が発生する可能性があります。 

最後に、複数の色を使用すると、いくつかの可能な停止位置を作成できます。 例えば、```
5
1 -1 2 -2 2
```生成する`3 3 2 1 1`。 お部屋からスタート`0`、 色`1`将来的には問題はありませんが、色が`2`通過時に無効になる`4`、それで通過`5`最初のブロッカーになります。 

## アプローチ

 ブルートフォースアプローチは、この声明の内容に正確に従っています。 すべての開始部屋に対して`s`、すべてのパスが有効な新しい状態を作成し、パッセージをスキャンします`s+1, s+2, ...`、どの色が無効になったかを維持します。 負の値を指定するとその色が無効になり、正の値を指定するとその色がすでに無効になっている場合にシミュレーションが停止します。 これは、何の仮定もせずに実際の移動をシミュレートしているため、直接的には正しいです。 

問題は、隣接する開始部屋がほぼすべて同じ作業を繰り返すことです。 お部屋からスタート`s`そして部屋からスタート`s+1`どちらも配列のサフィックスのほぼ全体を検査します。 最悪の場合、ブルートフォースが実行されます。`n(n+1)/2`通行検査、について`1.25 * 10^11`いつ`n=500000`。 

有益な観察は、その行程を逆方向に分析できるということです。 パッセージを処理しているとします`i`右から左へ。 すべての色について、その色の右側に最も近いポジティブな部分を思い出すことができます。 もし`a[i]`ポジティブです、通過`i`は、旅の最初の通路であるときは常に横断可能であるため、開始部屋の答えは、通過後の答えよりも 1 つ多いだけです。 

もし`a[i]`色がマイナスです`c`、通路自体は横断可能ですが、無効になります。`c`。 陽性がない場合`c`その右側では、無効化は決して重要ではないため、再び通路を渡って次の部屋の答えを継承できます。 

興味深いケースは、最も近い陽性の場合です。`c`右側が通路です`p`。 そして、通過時または通過前に始まる旅`i`そして十字架`-c`通路を越えられない`p`。 部屋にしか届かない`p-1`。 さらに右側の別のネガティブな通路によってさらに早い停止位置がすでに存在する可能性があるため、グローバルで最も右の到達可能な部屋を 1 つ維持し、そのような制限をすべて最小限に抑えます。 

これが、逆スキャンが非常にうまく機能する理由です。 すべての正のパッセージはその位置を色ごとのルックアップに提供し、すべての負のパッセージは 1 つのグローバル境界を強化する可能性があり、すべての配列の位置は 1 回だけ処理されます。

 ## アルゴリズムのチュートリアル

 1. 1 から始まるパッセージ インデックスを使用して配列を読み取ります。 させて`ans[i]`部屋から開始したときに成功した通過の数を表します`i-1`。 また、`ans[n+1] = 0`、最後のパッセージの後の空の接尾辞を表します。 
2. 以下の文章をスキャンします。`n`まで`1`。 この時点で、右側のすべてのパッセージはすでに分析されており、各色について、その色の右側に最も近いポジティブなパッセージを知ることができます。 
3. メンテナンス`pos[c]`、色の付いた最も近いポジティブなパッセージ`c`これまでに逆スキャンで発生しました。 最初はどの色にもそのような通路はありません。 
4. もし`a[i]`ポジティブ、部屋から始まる旅`i-1`いつでも通路を横切ることができる`i`なぜなら、最初はすべてのパスが有効だからです。 それを越えた後の状況は、まさに に代表される状況です。`ans[i+1]`。 したがって、設定しました`ans[i] = ans[i+1] + 1`。 この答えを計算した後にのみ保存します`pos[a[i]] = i`なぜなら、このポジティブなパッセージは、その左側にあるネガティブなパッセージに影響を与える可能性があるからです。 
5. もし`a[i]`色がマイナスです`c`そして`pos[c]`存在しません、通路を横切ります`i`無効にする`c`、ただし、将来の通過では色はチェックされません`c`。 無効化は永久に無関係であるため、旅の残りの部分は部屋から始まる旅のように動作します。`i`。 設定しました`ans[i] = ans[i+1] + 1`。 
6. もし`a[i]`色がマイナスです`c`そして最も近い陽性`c`通過中です`p`、その後、通路を渡ります`i`通過する`p`渡るのは不可能。 この特定の無効化により到達可能な最後のルームは次のとおりです。`p-1`。 保守します`limit`、すでに処理されているすべての否定的なパッセージ上で到達可能な最小の部屋、および更新`limit = min(limit, p-1)`。 
7. アップデート後`limit`、部屋から始まる旅`i-1`ほとんどの部屋に到達できる`limit`。 部屋から始まるから`i-1`、成功した通路の数は`limit - (i-1)`、つまり`limit - i + 1`。 その値を保存します`ans[i]`。 
8. 逆スキャン後、`ans[1], ans[2], ..., ans[n]`開始部屋に正確に対応します`0, 1, ..., n-1`ので、順番に印刷してください。 

### なぜ効果があるのか

 不変条件は、処理後の位置です。`i`、`limit`は、すでに処理されたサフィックス内のすべての否定的なパッセージによって課される、最も早く到達可能な部屋です。 ネガティブな一節`-c`最初のポジティブを介してのみ制限を作成できます`+c`その右側は、無効化されたパスが実際にチェックされる最初の場所であるためです。 これらの制限を最小限に抑えることで、旅を止めることができる最初の通過点が得られます。 肯定的なパッセージ自体が制限を生み出すことはありません。また、その右側に肯定的な出現がない否定的なパッセージは、将来の動きに影響を与えることはありません。 したがって、逆スキャンによって計算されるすべての答えは、対応する開始位置が正常に通過できる通路の数と正確に一致します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    # pos[c] = nearest positive passage of color c to the right.
    pos = [0] * (n + 1)

    # limit is the smallest room index that can be reached because
    # of a restriction created by a negative passage in the suffix.
    # Initially there is no restriction, so room n is reachable.
    limit = n

    ans = [0] * (n + 2)

    for i in range(n, 0, -1):
        x = a[i - 1]

        if x > 0:
            # Passage i is always crossable when it is the first
            # passage of the journey.
            ans[i] = ans[i + 1] + 1

            # This passage may block a negative occurrence of the
            # same color located to its left.
            pos[x] = i
        else:
            color = -x

            if pos[color] == 0:
                # The invalidated pass is never checked later.
                ans[i] = ans[i + 1] + 1
            else:
                # Passage pos[color] is the first positive check of
                # this color to the right, so we can reach only the
                # room immediately before it.
                limit = min(limit, pos[color] - 1)
                ans[i] = limit - i + 1

    print(*ans[1:n + 1])

if __name__ == "__main__":
    solve()
```配列`pos`すべての色が間にあるため、色によって直接インデックス付けされます。`1`そして`n`。 値 0 は、逆方向のスキャン中にその色の正の通過がまだ発生していないことを意味します。 

の`limit`変数は通路インデックスではなく部屋インデックスとして保存されます。 陽性経路を遮断している場合、`p`、その人は部屋に入ることができます`p-1`しかし部屋に入れない`p`、したがって、対応する境界は正確に`p-1`。 これで答えの式が成り立ちます`limit - i + 1`という事実と一致する`ans[i]`部屋から始まる`i-1`。 

アップデート`pos[x] = i`計算後に起こる`ans[i]`。 ポジションでのポジティブなパッセージ`i`は、厳密に左側の否定的なパッセージに表示される必要がありますが、最初のパッセージがそれ自体である旅程の計算に影響を与えるべきではありません。 後で割り当てを処理すると、当然のことながら正しい順序が与えられます。 

Python では整数オーバーフローは不可能であり、実際、すべての答えは最大でも`n`。 この実装では再帰も回避され、次の値に比例するサイズの配列のみが使用されます。`n`に適しています。`500000`要素制限。

6

|`i`|`a[i]`|`pos[1]`ステップの後 |`limit`|`ans[i]`|
 | --- | --- | --- | --- | --- |
 | 6 |`1`| 6 | 6 | 1 |
 | 5 |`-1`| 6 | 5 | 1 |
 | 4 |`1`| 4 | 5 | 2 |

 | 2 |`-1`| 4 | 3 | 2 |

サンプル 2 の場合、```
7

```逆スキャンは次のとおりです。 

|`i`|`a[i]`| 関連する`pos`更新 |`limit`|`ans[i]`|
 | --- | --- | --- | --- | --- |
 | 7 |`2`|`pos[2] = 7`| 7 | 1 |
 | 6 |`3`|`pos[3] = 6`| 7 | 2 |
 | 5 |`1`|`pos[1] = 5`| 7 | 3 |
 | 4 |`-3`|`limit = min(7, 5)`| 5 | 2 |
 | 3 |`-2`|`limit = min(5, 6)`| 5 | 3 |

 否定的なこと`-3`通過時に`4`色を無効にします`3`、それで通過`6`を横切ることができないため、到達できる部屋は制限されます`5`。 後のほう`-2`対応する正の値であるため、その境界は強化されません。`2`はさらに右です。 の`-1`通過時に`2`部屋に締めつけます`4`、生産`4 3 3 2 3 2 1`。 

これらのトレースは、制限が累積される理由も示しています。 否定的なパッセージは、必ずしもそれ自体で最終停止点を決定するとは限りません。 サフィックス内の関連するすべての無効化にわたって到達可能な最小限のスペースが必要です。

import io

def solution():
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    pos = [0] * (n + 1)
    limit = n
    ans = [0] * (n + 2)

    for i in range(n, 0, -1):
        x = a[i - 1]

        if x > 0:
            ans[i] = ans[i + 1] + 1
            pos[x] = i
        else:
            color = -x

            if pos[color] == 0:
                ans[i] = ans[i + 1] + 1
            else:
                limit = min(limit, pos[color] - 1)
                ans[i] = limit - i + 1

    print(*ans[1:n + 1])

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    try:
        sys.stdin = io.StringIO(inp)
        sys.stdout = io.StringIO()
        solution()
        return sys.stdout.getvalue().strip()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

    "1 -1 -1 1 -1 1\n"

) == "4 3 3 2 3 2 1", "sample 2"
