 ## 解決策
 ## 問題の理解

 (n) 人の Jedi があり、Jedi (i) には 3 つの非負の整数パラメーター ((a_i,b_i,c_i)) があります。 通常の戦いでは、ジェダイの 3 つの座標のうち少なくとも 2 つが対戦相手の対応する座標よりも厳密に大きい場合、ジェダイは勝利します。 

ダークサイドの能力は問題を大きく変えます。 ジェダイ (i) が変身するとき、すべての戦いの前に、彼の 3 つのパラメータを、合計が残る (a_i+b_i+c_i) 任意の 3 つの非負の整数に置き換えることができます。 新しい値は、対戦相手ごとに独立して選択できます。 元のジェダイごとに、この方法で他のジェダイを何人倒せるかをカウントする必要があります。 元の問題とその制約は、Codeforces アーカイブで入手できます。 

したがって、中心的な問題は、変身したジェダイがどの特定の 3 つの値を使用すべきかということではありません。 固定された対戦相手の場合、2 つの座標をその対戦相手の対応する座標より厳密に大きくするために必要な最小合計パワーを知る必要があるだけです。 

(n\le 500000) の場合、すべてのペアを比較するには約 (n(n-1)/2) が必要となり、最大サイズではおよそ (1.25\times10^{11}) 回の戦闘になります。 2 秒の制限により、二次関数のアプローチは除外されます。 個々のパラメーターは (10^9) に達する可能性があるため、合計は (3\times10^9) に達する可能性があり、これは 64 ビット整数に快適に収まり、特別な処理を行わなくても Python の任意精度の整数にも適合します。 

誤って対処しやすい特殊なケースがいくつかあります。 厳密な不平等が重要です。 たとえば、1 人のジェダイが ((1,1,1)) を持っている場合、答えは次のようになります。`0`: 合計パワー (3) を使用して 2 つの座標を別の同一のジェダイより厳密に大きくすることはできません。そうするには、少なくとも (2+2=4) の合計パワーが必要になるからです。 (>) の代わりに (\ge) を使用した解決策は、この戦闘を誤ってカウントします。 

もう 1 つの一般的な罠は、変身したジェダイを自分自身に対してカウントすることです。 考慮する```
2
1 1 2
1 1 1
```最初のジェダイは総合力を持っています (4)。 ((1,1,1)) に対して、彼は ((2,2,0)) を選択できるため、2 人目のジェダイを倒します。 彼自身の最小の 2 つの座標は (1,1) であるため、彼自身の記録のしきい値も (4) になります。 生のしきい値カウントには彼自身が含まれ、`2`最初の正しい答えの代わりに`1`。 正しい出力は次のとおりです```
1 0
```2 番目のジェダイの合計パワーは (3) ですが、(1) に等しい 2 つの座標を超えるには不十分です。 

異なるジェダイ間の絆は決して取り除かれてはなりません。 複数の対戦相手が同じ最小 2 つの座標の合計を持っている場合、それらはすべて別の対戦相手になります。 例えば、```
3
2 2 2
1 1 1
1 1 1
```最初のジェダイは合計 (6) を持っており、他のジェダイを両方倒すことができます。 ((1,1,1)) の各コピーは合計 (3) を持ち、誰にも負けません。 出力は```
2 0 0
```周波数ベースのソリューションでは、等しいパラメーターのトリプルを 1 つのオブジェクトとして扱うのではなく、重複するしきい値をカウントする必要があります。 

## アプローチ

 直接的なアプローチは、順序付けられた個別のジェダイのペアをすべて取得することです。 攻撃するジェダイの場合は、相手の対応する座標よりも少なくとも 2 つの座標が大きくなるような、彼の総力の合法的な再配分を見つけてください。 これは正しいです。なぜなら、考えられるすべての対戦相手は独立して考慮され、ダークサイドの再配分は戦いごとに変わる可能性があるからです。 

ただし、1 つのペアのチェックが定数時間に短縮されたとしても、(n(n-1)) 個の順序付きペアが存在します。 (n=500000) では、ほぼ (2.5\times10^{11}) 回のペア チェックに相当し、利用可能な時間をはるかに超えています。 

有用な観察は、対戦相手の 3 つのパラメータを分類することから得られます。 相手に価値観があると仮定する

 [
 x\le y\le z.
 ]

 勝つためには、変身したジェダイは元の座標位置でこれらの値のいずれかを 2 つ超える必要があります。 攻撃者は合計パワーを 3 つの座標間で任意に分配する可能性があるため、最も安価な選択は、2 つの最小値を上回ることです。 彼は割り当てることができます

 [
 x+1,\qquad y+1
 ]

 その2つの座標に。 残りの座標は、余った電力をすべて受け取ります。 

したがって、攻撃者の合計パワー (S) が満たされたときに、敵を倒すことができます。 

[
 S\ge (x+1)+(y+1)=x+y+2。 
]

 3 番目の座標は負でないことだけが必要なため、追加の制限はありません。 合計が少なくとも (x+y+2) であれば、残りの電力をすべてそこに置くことができます。 

これにより、すべての対戦相手が単一の数に減ります。 

[
 T=x+y+2。 
]

 すべてのジェダイ (i) について、その合計パワーを計算します

 [
 S_i=a_i+b_i+c_i。 
]

 彼は、しきい値 (T) が最大 (S_i) であるジェダイを正確に倒すことができます。 すべてのしきい値を計算した後、それらを並べ替えます。 次に、最大のしきい値の数 (S_i) は次の式で取得されます。`upper_bound`、または Python の`bisect_right`。 

最後に一つ訂正があります。 Jedi (i) 自身の閾値が最大 (S_i) の場合、二分探索には Jedi (i) 自体が含まれます。 答えは他のジェダイを求めているので、その場合は 1 を引きます。 必要なアイデンティティ固有の調整はこれだけです。 

その結果、問題全体が標準的なオフラインの計数問題になりました。つまり、各対戦相手をスカラー要件に変換し、すべての要件を並べ替えて、ジェダイごとに 1 つの上限クエリに答えることになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(n^2)) | (O(n)) | 遅すぎる |
 | 最適 | (O(n\log n)) | (O(n)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのジェダイについて、その合計パワー (S_i=a_i+b_i+c_i) を計算します。 対戦相手がしきい値に変換された後に重要となる攻撃者の唯一のプロパティであるため、この合計を保存します。 
2. 各 Jedi の 3 つのパラメータをソートし、2 つの最小値 (x_i) と (y_i) を呼び出します。 定義する

 [
 T_i=x_i+y_i+2。 
]

 これは、別のジェダイがジェダイを倒すために必要な最小の総パワーです (i)。 の`+2`が必要なのは、両方の座標が厳密に大きくなければならないため、(x_i) に勝つには少なくとも (x_i+1) のコストがかかり、(y_i) に勝つには少なくとも (y_i+1) のコストがかかります。 
3. すべての (T_i) を 1 つの配列に入れ、その配列をソートします。 分類後、考えられるすべての対戦相手が、必要最小限のパワーで表されます。 
4. 各 Jedi (i) に対して、次を使用します。`bisect_right`満たすしきい値がいくつあるかを確認するには

 [
 T_j\le S_i.
 ]

 右二等分境界は、要件全体の等価性が許可されるため必要です。 (S_i=T_j) の場合、攻撃者は必要な金額を正確に費やすことができます。 
5. (T_i\le S_i) かどうかを確認します。 そうである場合、二分探索ではジェダイ (i) 自身がカウントされるため、1 を減算します。 (T_i>S_i) の場合、彼はカウントされず、何も削除する必要はありません。 
6. 結果のカウントを元の Jedi 順序で出力します。 個別のしきい値配列のみを並べ替えても、保存されている合計や Jedi ごとのしきい値の順序は変更されないため、各回答は元の Jedi に関連付けられたままになります。 

重要な不変条件は、(T_j) がまさにジェダイ (j) を倒すのに必要な最小総パワーであるということです。 したがって、すべて (T_j) を並べ替えた後、ジェダイ (i) が倒すことができる敵の数は、正確に (S_i) 以下のしきい値の数になります。 有効な対戦相手を表さない唯一のしきい値は (T_i) 自体であり、それが含まれたときに正確に削除されます。 したがって、カウントされたジェダイはすべて倒すことができ、省略された他のジェダイはすべて倒すことができず、自己カウントは除外されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from bisect import bisect_right

def solve():
    n = int(input())

    totals = [0] * n
    thresholds = [0] * n

    for i in range(n):
        a, b, c = map(int, input().split())

        totals[i] = a + b + c

        if a > b:
            a, b = b, a
        if b > c:
            b, c = c, b
        if a > b:
            a, b = b, a

        thresholds[i] = a + b + 2

    sorted_thresholds = sorted(thresholds)

    answer = [0] * n

    for i in range(n):
        count = bisect_right(sorted_thresholds, totals[i])

        if thresholds[i] <= totals[i]:
            count -= 1

        answer[i] = count

    sys.stdout.write(" ".join(map(str, answer)))

if __name__ == "__main__":
    solve()
```入力ループは、各 Jedi について 2 つの情報を計算します。`totals[i]`元の総パワーを維持しながら、`thresholds[i]`そのジェダイを倒すために必要な最小限の力を記録します。 

3 値の並べ替えは、呼び出しの代わりに 3 つの比較を使用して実装されます。`sorted`一時的なリストに載っています。 座標が 3 つしかないため、これは Jedi ごとの継続的な作業であり、Python での不必要な一時オブジェクトを回避します。 3つの比較を行った結果、`a`そして`b`は 2 つの最小値であるため、`a + b + 2`は必要なしきい値です。 

別個の`sorted_thresholds`配列は意図的です。 二分探索ではソートされた順序でしきい値が必要ですが、二分探索でそのジェダイがカウントされたかどうかを決定するために、各ジェダイの元のしきい値も必要です。 パイソンの`sorted`新しいリストを作成し、終了します`thresholds[i]`ジェダイ (i) と連携します。`bisect_right`より厳密に大きい最初の位置を返します`totals[i]`。 その位置より前のすべてのしきい値は、合計に等しいしきい値を含め、最大でも攻撃者の合計となります。 それは実現可能条件と正確に一致します。 

自己修正の用途`thresholds[i] <= totals[i]`、 ない`<`。 平等とは、ジェダイが自身の閾値を満たすのに十分な総合力を持っていることを意味するため、ジェダイ自身のエントリが含まれており、削除する必要があります。 

Python ではオーバーフロー処理は必要ありません。 最大の合計は (3\times10^9) で、Python の整数はそれを直接表します。 

## 実用的な例

 サンプル 1 では、4 人のジェダイの合計としきい値は次のようになります。 

| ジェダイ | 並べ替えられたパラメータ | 合計 (S_i) | しきい値 (T_i) |
 | --- | --- | --- | --- |
 | 1 | (1,3,4) | 8 | 6 |
 | 2 | (2,5,9) | 16 | 9 |
 | 3 | (3,6,10) | 19 | 11 |
 | 4 | (2,3,5) | 10 | 7 |

 ソート後のしきい値配列は次のようになります。`[6, 7, 9, 11]`。 

| ジェダイ | 合計 |`bisect_right([6,7,9,11], total)`| 自己含まれますか？ | 答え |
 | --- | --- | --- | --- | --- |
 | 1 | 8 | 2 | はい、しきい値 6 | 1 |
 | 2 | 16 | 4 | はい、しきい値 9 | 3 |
 | 3 | 19 | 4 | はい、しきい値 11 | 3 |
 | 4 | 10 | 3 | はい、しきい値 7 | 2 |

 たとえば、ジェダイ 1 には合計 (8) があります。 彼は、ジェダイ 1 とジェダイ 4 に対応するしきい値 (6) と (7) を破ることができます。自分自身を除去すると、有効な対戦相手が 1 人残ります。 最終的な出力は次のとおりです`1 3 3 2`、サンプルと一致します。 

2 番目の例として、次のことを考えてみましょう。```
3
0 0 0
1 1 1
1 2 2
```前処理により次の状態が生成されます。 

| ジェダイ | 並べ替えられたパラメータ | 合計 | しきい値 |
 | --- | --- | --- | --- |
 | 1 | (0,0,0) | 0 | 2 |
 | 2 | (1,1,1) | 3 | 4 |
 | 3 | (1,2,2) | 5 | 4 |

 ソートされたしきい値は次のとおりです。`[2, 4, 4]`。 

| ジェダイ | 合計 | しきい値 (\le) の合計数 | 自己含まれますか？ | 答え |
 | --- | --- | --- | --- | --- |
 | 1 | 0 | 0 | いいえ | 0 |
 | 2 | 3 | 1 | いいえ | 1 |
 | 3 | 5 | 3 | はい | 2 |

 ある座標に (1) を費やし、別の座標に (1) を費やすだけで 2 つのゼロを超えるのに十分であるため、ジェダイ 2 はジェダイ 1 を倒すことができます。 彼はジェダイ 3 を倒すことができません。そのためには (1) と (2) を超える必要があり、(2+3=5) のコストがかかるからです。 ジェダイ 3 は、自分自身に属するしきい値を含め、他のジェダイを倒すのにちょうど十分な合計パワーを持っているため、自己カウントは削除されます。 結果の出力は次のとおりです。`0 1 2`。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | (O(n\log n)) | すべての値の計算には (O(n)) かかり、(n) 個のしきい値の並べ替えには (O(n\log n)) かかり、すべてのバイナリ検索には (O(n\log n)) かかります。 |
 | スペース | (O(n)) | 元の合計、しきい値、並べ替えられたしきい値配列、および回答配列には、それぞれ (n) 個の値が含まれています。 |

 (n=500000) の場合、アルゴリズムは、数千億回のペア比較の代わりに、1 回の (O(n\log n)) ソートと (n) 回の対数バイナリ検索を実行します。 保存されたデータは (n) で線形であり、Python の整数オブジェクトとリスト オブジェクトで表すと、256 MB のメモリ制限内に快適に収まります。

    totals = [0] * n
    thresholds = [0] * n

    for i in range(n):
        a, b, c = map(int, inp.readline().split())
        totals[i] = a + b + c

        if a > b:
            a, b = b, a
        if b > c:
            b, c = c, b
        if a > b:
            a, b = b, a

        if thresholds[i] <= totals[i]:

 ## 特殊なケース

 厳密な不等式の境界は、2 つの最小の敵座標の両方に 1 を加算することによって処理されます。 のために```
2
1 1 2
1 1 1
```2 番目のジェダイにはしきい値 (1+1+2=4) があり、最初のジェダイには合計 (4) があります。 (4\ge4) なので、最初のジェダイは (2) に等しい 2 つの座標を選択して 2 番目のジェダイを倒すことができます。 二分探索にはしきい値が含まれます。`bisect_right`。 これには、セルフチェックによって削除される最初のジェダイ自身のしきい値も含まれます。`1 0`。 

ゼロを持つ対戦相手は下限を行使します。 のために```
2
0 0 0
1 1 1
```最初のしきい値は (2) ですが、2 番目のジェダイの合計は (3) です。 したがって、2 番目のジェダイは 2 つの座標に少なくとも (1) を割り当てることで最初のジェダイを倒すことができます。 最初のジェダイの合計は (0) であるため、2 番目のジェダイのしきい値 (4) に到達できません。 出力は`0 1`。 

重複する対戦相手は個別の記録を残す必要があります。 のために```
3
2 2 2
1 1 1
1 1 1
```しきい値は (6,4,4) で、最初のジェダイの合計は (6) です。`bisect_right`(4) のコピーと最初のジェダイ自身のコピー (6) を含む 3 つのしきい値すべてを返します。 1 を引くとちょうど 2 人の対戦相手が残るため、出力は次のようになります。`2 0 0`。 

最後に、パラメーターのセットが同一であっても、2 人のジェダイが互いに倒せることを意味するものではありません。 と```
3
1 1 1
