 # 問題の理解

 親染色体のコレクションがあり、それぞれが小文字の文字列で表されます。 2 人の親が子の染色体を作成すると、子のすべての位置が 2 人の親の一方から独立してコピーされます。 タスクは、指定された候補の子染色体のどれが、コレクションの少なくとも 1 対の親染色体によって生成されるかを決定することです。 出力は、すべての有効な子のインデックスを昇順に並べたものです。 

入力により、親染色体の数、それらの共通の長さ、親の文字列自体、そして候補となる子の小さなリストが与えられます。 親は固定されており、候補のみが変更されるため、主な課題は、各候補を迅速にチェックできるように親セットを前処理することです。 

親の数は 20,000 に達する可能性がありますが、染色体の長さは最大 50 です。すべての親ペア間の二次比較には約 4 億のペア チェックが必要となり、各チェックでは最大 50 文字が検査されます。 これは 1 秒の制限には遅すぎます。 候補となる子の数が多くても 10 人までと少ないということは、候補者ごとにより高価な操作を行う余裕はありますが、すべてのペアの親を対象とした操作を行う余裕はないことを意味します。 

いくつかの特殊なケースは見落とされがちです。 1 つ目は、子が親と同一である場合です。 生殖には2人の親が必要であるため、1人の親だけでは十分ではありません。 例えば：```
Input

abc

1

Output
0
```子と正確に一致する可能性のある唯一の親は次のとおりです。`abc`、しかし、不足している位置を提供できる 2 番目の親はありません。 

もう 1 つのケースは、どちらの親も子全体と一致しないために両方の親が必要な場合です。 例えば：```
Input
2 2
ab
ac
1
aa

Output
1
```最初の親は最初の文字を提供し、2 番目の親は 2 番目の文字を提供します。 一方の親が子と少数の箇所で異なっているかどうかだけをチェックするソリューションは、ここでは失敗します。 

最後の微妙なケースは、子が 2 人の異なる親と等しい場合です。```
Input

abc

def

abc
```元の問題では、両親は別個であるため、この正確な入力は公式の制約の範囲外ですが、これは 2 つの染色体が必要であるという規則を示しています。 この実装では、各不一致パターンを生成する親の数を追跡することで、この状況を引き続き正しく処理します。 

# アプローチ

 直接的なアプローチは、候補となるすべての子供についてすべてのペアの親を試してみることです。 固定ペアの場合、すべての位置をチェックして、子キャラクターが 2 つの親キャラクターのいずれかに等しいことを確認できます。 これは、交差の定義に正確に従っているため、正しいです。 

ただし、最悪の場合は大きすぎます。 親が 20,000 人いると、考えられるペアは約 2 億通りになります。 ペアごとに 50 の位置をチェックするには、約 100 億文字の比較が必要となり、制限時間内に収まりません。 

重要な観察は、1 人の候補児の場合、実際には 2 人の親自身を知る必要がないということです。 すべての親について、その親が子と異なる位置を知るだけで済みます。 この位置のセットを不一致マスクと呼びます。 2 人の親の不一致マスクが重ならない場合は、正確に子を作成できます。 一方の親がある位置で異なる場合、もう一方の親もそこで一致する必要があります。 

問題は、多くの 50 ビット マスクが与えられた場合、ビット単位の AND が 0 であるペアは存在するかということです。 

マスク1枚につき`x`、別のマスクが必要です`y`すべてのビットが設定される場所`y`ゼロインです`x`。 言い換えると、`y`の補数のサブセットでなければなりません`x`。 50 ビットにわたるバイナリ トライにより、そのようなマスクを検索できるようになります。`O(l)`時間。 

子は最大でも 10 個しかないため、各候補のすべての親に対して不一致マスクを構築し、トライをクエリします。 総作業量は十分に少ないです。

 # アルゴリズムのチュートリアル

 1. 候補となる子染色体ごとに、すべての親染色体に対する不一致マスクを計算します。 位置のビット`i`その位置の親キャラクタが子のキャラクタと異なる場合に設定されます。 これにより、文字列比較がビット演算に変換されます。 
2. 不一致マスクが 0 である親の数を数えます。 マスクがゼロの場合は、親が子と同一であることを意味します。 このような親が少なくとも 2 つある場合にのみ、有効なペアを形成できます。 
3. すべての不一致マスクをバイナリ トライに挿入します。 トライの各レベルは 1 つの染色体の位置を表します。 このトライには、考えられる親の不一致パターンがすべて保存されます。 
4. 不一致マスクごとに`x`、マスクのトライを検索します。`y`と共通の設定ビットがありません`x`。 検索中に、次の場合は、`x`現在のビットに 1 がある場合、ゼロ分岐のみが許可されます。 もし`x`にゼロがある場合は、両方の分岐が可能です。 
5. いずれかのマスクが互換性のあるパートナーを見つけた場合、候補の子が達成可能となり、そのインデックスが回答に追加されます。 

これが機能する理由は、不一致マスクの不変式に基づいています。 マスクが一致しない親`x`は、設定されたビットで表される位置でのみ子を提供できません。 2 つの親は、一方の親の失敗したすべての位置がもう一方の親によってカバーされる場合に正確に子を作成できます。つまり、失敗した位置が重複することはありません。 トライ検索では、ビットごとの交差がゼロのマスクが正確に検出されるため、報告されたすべての子には有効な親のペアがあり、すべての有効なペアが検索で見つかります。 

# Python ソリューション```python
import sys
input = sys.stdin.readline

class TrieNode:
    __slots__ = ("child", "end")
    def __init__(self):
        self.child = [-1, -1]
        self.end = 0

def solve():
    n, l = map(int, input().split())
    parents = [input().strip() for _ in range(n)]
    k = int(input())
    children = [input().strip() for _ in range(k)]

    answer = []

    for idx, child in enumerate(children, 1):
        masks = []
        zero_count = 0

        for parent in parents:
            mask = 0
            for i in range(l):
                if parent[i] != child[i]:
                    mask |= 1 << i
            if mask == 0:
                zero_count += 1
            masks.append(mask)

        if zero_count >= 2:
            answer.append(idx)
            continue

        trie = [TrieNode()]

        for mask in masks:
            node = 0
            for bit in range(l - 1, -1, -1):
                b = (mask >> bit) & 1
                if trie[node].child[b] == -1:
                    trie[node].child[b] = len(trie)
                    trie.append(TrieNode())
                node = trie[node].child[b]
            trie[node].end += 1

        def has_partner(mask):
            if mask == 0:
                return False

            def dfs(node, bit):
                if bit < 0:
                    return trie[node].end > 0

                b = (mask >> bit) & 1
                if b == 1:
                    nxt = trie[node].child[0]
                    if nxt != -1 and dfs(nxt, bit - 1):
                        return True
                else:
                    nxt = trie[node].child[0]
                    if nxt != -1 and dfs(nxt, bit - 1):
                        return True
                    nxt = trie[node].child[1]
                    if nxt != -1 and dfs(nxt, bit - 1):
                        return True
                return False

            return dfs(0, l - 1)

        ok = False
        for mask in masks:
            if has_partner(mask):
                ok = True
                break

        if ok:
            answer.append(idx)

    if answer:
        print(*answer)
    else:
        print(0)

if __name__ == "__main__":
    solve()
```候補の数が非常に少ないため、ソリューションは候補を個別に処理します。 候補ごとに、不一致マスクが親リストから再構築されます。 

子と同一の親はそれ自体とペアにできないため、ゼロマスク チェックはトライを構築する前に分離されます。 試行検索では、見つかったマスクが現在のマスクとは異なることを前提としています。 ゼロ以外のマスクはそれ自体とオーバーラップできない一方、ゼロの場合は個別に処理されるため、これは常に非ゼロ マスクに当てはまります。 

トライは、最上位位置から最下位位置までビットを格納します。 構築と検索が同じ順序を使用する限り、染色体の位置の実際の番号付けは重要ではありません。 Python の整数は 50 ビット値を安全に保持できるため、オーバーフローに対する特別な処理は必要ありません。
