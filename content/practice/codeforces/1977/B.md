 ## 解決策
 ## 問題の理解

 与えられた正の整数を表すように求められます$x$2 のべき乗の合計として計算されますが、厳密な追加制約があります。2 のべき乗の係数は -1、0、または 1 のみにすることができ、ゼロ以外の 2 つの係数を隣接させることはできません。 具体的には、配列を作成する必要があります$a$長さの$n$どこ$1 \le n \le 32$、$a_i \in \{-1, 0, 1\}$、 そして$$x = \sum_{i=0}^{n-1} a_i \cdot 2^i$$という追加条件付きで、$a_i$そして$a_{i+1}$両方ともゼロではないため、ルールに違反します。 

入力は複数のテスト ケースで構成され、それぞれに 1 つの整数が含まれます。$x$。 それぞれについて$x$、有効な配列を構築する必要があります$a$その長さと内容を出力します。 以来$x < 2^{30}$、最大長$n$32 を超える必要はないため、ビットを反復処理するアルゴリズムはすべて$x$効率的です。 

主な微妙な点は、「隣接する非ゼロ係数がない」という制約にあります。 たとえば、次の場合$x = 3$、単純なバイナリ展開では次のようになります。$11_2 = 1 \cdot 2^1 + 1 \cdot 2^0$ですが、これは隣接ルールに違反します。 ソリューションでは、ゼロを挿入するか、負の係数を使用して、合計を合計しながら非ゼロ項を「広げる」必要があります。$x$。 

エッジケースには、少数の数字が含まれます (例:$1$または$2$)、2 の累乗より 1 少ない数値 (例:$3, 7, 15$)、および 2 進数で交互に配置された数値 (例:$21 = 10101_2$）。 

## アプローチ

 ブルートフォース手法では、係数が 32 までの長さのすべてのシーケンスが試行されます。$-1,0,1$、合計をチェックし、隣接する非ゼロがないことを確認します。 シーケンスの数は増加するにつれて増加するため、これは明らかに実行不可能です。$3^{32} \approx 2 \times 10^{15}$。 

重要な洞察は、シーケンスを貪欲に構築し、処理できることです。$x$最下位ビットから最上位ビットまで、隣接する非ゼロ係数がないことを保証します。 バイナリ展開で 2 つの連続するものが現れた場合、次のようなパターンに変換できます。$[-1, 0, 1]$これにより、合計が保存され、ゼロ以外の係数が分散されます。 これは、暗号化で使用される「平衡三進数」または非隣接形式 (NAF) で数値を表現することを思い出させます。これは、ゼロ以外の 2 桁が隣接せず、すべての桁が {-1,0,1} であることを保証します。 

貪欲なアプローチが機能するのは、隣接関係を引き起こす任意のビットに対して、次の上位ビットを増やすか現在のビットを -1 に調整してキャリー フォワードを伝播できるためです。 これにより、隣接ルールを維持しながら、合計が正しいままになることが保証されます。

 ## アルゴリズムのチュートリアル

 1. 空のリストから始める`a`係数を保持します。 
2. 変数を初期化する`x`与えられた番号に。 
3. 繰り返しながら`x`ゼロではありません:

 1. もし`x % 2 == 0`、追加`0`に`a`最下位ビットは何も寄与しないからです。 
2. もし`x % 2 == 1`、追加`1`に`a`単純な 1 が非隣接ルールに適合するためです。 
3. もし`x % 2 == 3`、追加`-1`に`a`そして増加します`x`1 ずつ加算して、次の上位ビットに繰り越します。 これにより、2 つの隣接関係が解決されます。 
4. 分割`x`2 (整数除算) で右にシフトして続行します。 
4. 出力`n = len(a)`そして配列`a`。 

機能する理由: 各ステップで、アルゴリズムは、1 のペアを 1 に変換することによって、潜在的に隣接するゼロ以外のビットを確実に分割します。`[-1,0,1]`キャリー付きのパターン。 これにより、ゼロ以外の要素が 2 つ存在しないという不変式が保証されます。`a`は隣接しており、その合計は$a_i \cdot 2^i$維持されている。 なぜなら$x < 2^{30}$、プロセスは最大 32 回の反復後に終了します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x = int(input())
        a = []
        while x != 0:
            if x % 2 == 0:
                a.append(0)
            elif x % 2 == 1:
                a.append(1)
            else:  # x % 2 == 3
                a.append(-1)
                x += 1
            x //= 2
        print(len(a))
        print(' '.join(map(str, a)))

if __name__ == "__main__":
    solve()
```の`while x != 0`ループは各ビットを反復処理します。`x`。 条件`x % 2 == 3`2 つの連続するものがバイナリに現れ、隣接ルールに違反する可能性がある場合を処理します。 追加中`-1`そして増加する`x`効果的に次のビットに引き継がれ、合計が維持されます。 使用する`x //= 2`これは、右にシフトして、より高い 2 のべき乗を進むことと同じです。 

境界の考慮事項には、最初のビット (`2^0`）そしてその事実`x`奇数でも偶数でも構いません。 以来`x < 2^{30}`、リスト`a`問題の制約を満たすため、要素が 32 個を超えることはありません。
