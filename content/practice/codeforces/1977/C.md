 ## 解決策
 ## 問題の理解

 整数の配列が与えられます。 サブシーケンスは、そのすべての要素の最小公倍数が元の配列のどこにも現れない場合、特別と呼ばれます。 

タスクは、そのようなサブシーケンスの可能な最大長を見つけることです。 

サブシーケンス内の要素の順序は、LCM にとっては重要ではありません。 選択した値のみが重要です。 配列のすべての要素が取得されるかスキップされる可能性があるため、指数関数的に多くの部分列が存在するため、それらを列挙する代わりに数理論的な構造を活用する必要があります。 

配列の長さは最大 2000 まで可能で、すべてのテスト ケースにわたるすべての長さの合計も最大 2000 になります。これは非常に珍しい制約です。 これは、テスト ケースごとにおよそ 2 次の作業を行う余裕はありますが、指数関数的な作業は不可能であることを意味します。 平$O(n^3)$最悪の場合は不快になるでしょう。 

値自体は次のように大きくできます。$10^9$これにより、値に対する動的プログラミングが除外されます。 どのソリューションも、値によってインデックス付けされた大きなテーブルを構築するのではなく、除数と最小公倍数を直接操作する必要があります。 

いくつかの特殊なケースは見落とされがちです。 

考慮する：```
1
5
1 2 4 8 16
```空ではないすべてのサブシーケンスには、配列要素の 1 つである LCM があります。 空のサブシーケンスには LCM があります$0$、しかし、その長さはゼロです。 正解は 0 です。 

よくある間違いは、配列全体の LCM が配列に属している場合、答えは存在しないと仮定することです。 それは誤りです。 

例えば：```
1
4
2 3 6 12
```アレイ全体の LCM は 12 であり、これは存在します。 ただし、その続きは$[2,3]$LCM 6 も存在しますが、$[2,12]$には LCM 12 があります。単にフルアレイ LCM をチェックするよりもはるかに慎重に検索する必要があります。 

別の微妙なケースは次のとおりです。```
1
3
2 3 5
```配列全体の LCM は 30 ですが、これは存在しません。 次に、すべての要素をただちに取得すると、長さ 3 の特別なサブシーケンスが得られます。この観察を見逃すと、不必要な作業が発生します。 

## アプローチ

 ブルートフォースアプローチは簡単です。 すべてのサブシーケンスを列挙し、それらの LCM を計算し、LCM が配列に現れない最大の長さを保持します。 

これは定義を直接チェックするので正しいです。 残念ながら検査が必要です$2^n$後続。 たとえ$n=50$これはすでに不可能です、そしてここでは$n$2000に達する可能性があります。 

重要な観察は、実際にどのような LCM が発生する可能性があるかを調べることから得られます。 

させて$M$配列全体の LCM になります。 

後続の LCM は除算する必要があります$M$。 配列内のどこかに既に存在しているものよりも大きい素数べき乗を含めることはできません。 

ここで 2 つのケースを考えてみましょう。 

もし$M$それ自体が配列内に現れない場合、配列全体はすでに特別です。 その最小公倍数は次のとおりです$M$、配列には存在しません。 答えはすぐに$n$。 

興味深いケースは次のような場合です。$M$配列に現れます。 

したがって、すべての特殊なサブシーケンスには、次の適切な約数である LCM が必要です。$M$。 さらに値が割り切れない場合$M$、サブシーケンスの最小公倍数にすることはできません。 

重要な事実は、すべての特殊最小公倍数候補は次の約数でなければならないということです。$M$それは配列には現れません。 

数の約数の数は次のとおりです。$10^9$小さいです。 実際、可能な約数の最大値でも約 1,000 にすぎません。 これにより、すべての約数を列挙することが可能になります。$M$。 

固定除数候補の場合$d$、LCM が次と等しい最大の部分列は何ですか$d$?

 選択されたすべての要素は分割する必要があります$d$。 分割されていない要素$d$LCM を強制的に超えることになります$d$。 

すべての要素の中で分割する$d$、単純にそれらすべてを取得します。 それらを組み合わせた LCM を計算できます。 その最小公倍数が等しい場合$d$の場合、そのようなすべての要素を含めることができ、この候補に可能な最大長が与えられます。 

これを約数ごとに繰り返します$d$の$M$それは配列に存在せず、最大の有効なカウントを取得します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^n \cdot n)$|$O(n)$| 遅すぎる |
 | 最適 |$O(n \cdot \tau(M))$|$O(\tau(M))$| 承認済み |

 ここ$\tau(M)$は約数の数を示します$M$。 

## アルゴリズムのチュートリアル

 1. 配列を読み取り、すべての要素の LCM を計算します。 
2. LCM を計算する際、配列の最大値を超えたら拡大を停止します。 

実際のフルアレイ LCM は膨大になる可能性があるため、これは重要です。 それがすべての配列要素よりも大きいかどうかを知る必要があるだけです。 
3. しましょう`mx`配列の最大値になります。 
4. フルアレイ LCM が次の値より大きい場合`mx`の場合、配列に属することはできません。 

その状況では、配列全体が特別であるため、出力`n`。 
5. それ以外の場合、完全配列 LCM はある配列値と等しくなります。 この値を呼び出します`M`。 
6. すべての約数を列挙します`M`。 
7. 各約数について`d`配列に現れないもの:

 1. すべての配列要素を分割して収集します`d`。 
2. 数えます。 
3. 収集されたすべての要素の LCM を計算します。 
4. 結果の LCM が以下に等しい場合`d`の場合、この除数は部分系列 LCM として実現できます。 
5. カウントを使用して答えを更新します。 
8. 見つかった最大のカウントを出力します。 

### なぜ効果があるのか

 すべてのサブシーケンス LCM がフルアレイ LCM を分割します。$M$。 もし$M$それ自体は配列に存在しないため、すべての要素を取得すると、可能な最大長の特別なサブシーケンスがすでに得られます。 

さもないと$M$配列に属します。 特殊なサブシーケンスは、何らかの除数に等しい最小公倍数を持たなければなりません$d$の$M$それは配列には現れません。 

固定除数の場合$d$、選択されたすべての要素は分割する必要があります$d$。 このような要素をすべて含めると、実現可能な最大のサブシーケンスが得られます。$d$。 これらすべての適格な要素の最小公倍数が等しい場合$d$、 それから$d$達成可能です。 そうでない場合、それらのサブセットは生成できません$d$要素を削除すると、利用可能な素数パワーが減少するだけであるためです。 

したがって、実行可能なすべての特別な LCM が 1 回だけ検査され、それぞれについて達成可能な最大長が計算されます。 そのような最大の長さが答えです。 

## Python ソリューション```python
import sys
from math import gcd

input = sys.stdin.readline

def lcm(a, b):
    return a // gcd(a, b) * b

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        mx = max(a)
        s = set(a)

        cur_lcm = 1
        overflow = False

        for x in a:
            cur_lcm = lcm(cur_lcm, x)
            if cur_lcm > mx:
                overflow = True
                break

        if overflow:
            ans.append(str(n))
            continue

        M = cur_lcm

        divisors = []
        d = 1
        while d * d <= M:
            if M % d == 0:
                divisors.append(d)
                if d * d != M:
                    divisors.append(M // d)
            d += 1

        best = 0

        for target in divisors:
            if target in s:
                continue

            cnt = 0
            cur = 1

            for x in a:
                if target % x == 0:
                    cnt += 1
                    cur = lcm(cur, x)
                    if cur > target:
                        break

            if cur == target:
                best = max(best, cnt)

        ans.append(str(best))

    sys.stdout.write("\n".join(ans))

solve()
```最初の部分では、配列全体の LCM を計算します。 私たちはそれが不必要に増大することを決して許しません。 最大の配列要素を超えるとすぐに、それを配列に含めることができないことがわかっているため、答えは次のようになります。`n`。 

次のフェーズは、完全な配列 LCM が配列値と等しい場合にのみ実行されます。 その場合、その最小公倍数のすべての約数を列挙します。 

各候補の約数について、それを分割する配列要素を正確に調べます。 候補を分割しない要素は、LCM がその候補と等しいサブシーケンスに属することはできません。 

LCM の計算では次を使用します。```
a // gcd(a, b) * b
```それよりも`a * b // gcd(a, b)`固定サイズの整数を使用する言語での中間オーバーフローを回避するため。 Python はオーバーフローしませんが、これは依然として標準的な競技プログラミングの実装です。 

微妙な点は、配列内にすでに存在するすべての約数をスキップしていることです。 この問題では、結果として得られる LCM が配列に存在しないことが必要です。
