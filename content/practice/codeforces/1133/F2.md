 ## 解決策
 ## 問題の理解

 接続された無向の単純なグラフが与えられ、既存のエッジのみを使用してスパニング ツリーを構築するように求められます。 追加の制約は、選択したツリー内で頂点 1 の次数が正確に D でなければならないということです。 

スパニング ツリーは、すべての頂点を循環せずに接続し、正確に n − 1 個のエッジを含むエッジのサブセットです。 追加の制限により、問題は「任意のスパニング ツリーを検索する」から「頂点 1 にツリー内に指定された数の近傍があるスパニング ツリーを検索する」に変更されます。 

サイズ制限により、最大 200,000 個の頂点とエッジが許可されます。 これにより、すべてのスパニング ツリーを試行したり、再計算によってエッジを 1 つずつ削除したりするアプローチは即座に除外されます。 テストごとに線形または線形に近い時間を超えると遅すぎるため、少量のブックキーピング (通常は O(n + m)) を使用して単一のグラフ走査を中心にソリューションを構築する必要があります。 

いくつかの状況では、素朴な推論が失敗する可能性があります。 

元のグラフで頂点 1 の近傍が D 個よりも少ない場合、どのスパニング ツリーの次数も元のグラフの次数を超えることができないため、答えは不可能です。 たとえば、1 が 2 つのノードのみに接続されているが D = 3 の場合、どの構築も要件を満たすことができません。 

欲張ってスパニング ツリーを構築し、その後単に頂点 1 の次数を「調整」しようとすると、サイクルが作成されたり、コンポーネントが切断されたりする可能性があります。 たとえば、DFS ツリーでは頂点 1 に 2 が必要なときに 5 が与えられる可能性があり、1 に付随する任意のエッジを削除するとツリーの一部が切断される可能性があります。 

正しいアプローチでは、接続を確保しながら、頂点 1 に属するどのエッジがスパニング ツリーに入るかを制御する必要があります。 

## アプローチ

 ブルートフォースの観点では、次数制約を強制しながらスパニング ツリーを列挙するか、スパニング ツリーの構築をシミュレートします。 頂点 1 に付随するエッジのすべてのサブセットを試して、それを完全なスパニング ツリーに拡張できるかどうかを確認するような穏やかな変形でも、選択ごとに接続性がグローバルに変化するため、指数関数的な動作につながります。 

重要な点は、ツリー構造全体を自由に決定する必要がないということです。 代わりに、最初に頂点 1 のどの近傍をそのツリーの子にするかを決定し、次に標準的な方法でツリーの残りの部分を完成させることができます。 

これを可能にする構造は、頂点 1 からのエッジの貪欲な選択と組み合わせた DSU ベースのスパニング フォレスト構築です。そのアイデアは、最初に 1 に付随するすべてのエッジを無視し、頂点 2 ～ n の間にスパニング フォレストを構築することです。 次に、頂点 1 を正確に D 個の異なるコンポーネントに選択的に接続し、選択した各接続がサイクルを形成せずにコンポーネントをマージするようにします。 

これが機能するのは、すべてのスパニング ツリーが最初に頂点 {2..n} でフォレストを形成し、次に頂点 1 を接続してすべてのコンポーネントを接続していると見なせるためです。 頂点 1 の次数は、頂点 1 が接続するコンポーネントの数と正確に一致します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース列挙 | 指数 | O(n) | 遅すぎる |
 | DSU + 貪欲なアタッチメント | O(m α(n)) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 スパニング ツリーは 2 つのフェーズで構築されます。 

まず、頂点 1 に付随するすべてのエッジを無視し、頂点 2 から n までの DSU 構造を構築します。 どちらの端点も 1 ではないすべてのエッジ (u、v) について、それらが異なるコンポーネントに属している場合、このエッジをツリーに追加し、それらを結合します。 これにより、{2..n} にまたがるフォレストが生成されます。 

この時点では、グラフにはまだ複数のコンポーネントが含まれている可能性があります。 各コンポーネントは、最終的には選択した 1 つのエッジを介して頂点 1 に接続する必要があります。

次に、頂点 1 に付随するすべてのエッジを処理します。各エッジ (1, v) について、v がまだ 1 に接続されていないコンポーネントに属しているかどうかを確認します。属している場合は、このエッジを使用して頂点 1 をそのコンポーネントに接続し、頂点 1 を表す特別な DSU と結合します。 

このようなエッジを正確に D 個使用するようにする必要があります。 利用可能なコンポーネントが D 個よりも少なくなってしまうと、必要な次数に到達できなくなります。 それ以上ある場合は、D エッジを選択したら早めに停止しますが、残りのグラフがまだ接続されていることを確認する必要があります。 これは、個別のコンポーネントを接続するエッジを優先することで処理されます。 

最後に、頂点 1 の D エッジを使用した後、すべての頂点が接続されていることを確認する必要があります。 複数のコンポーネントが 1 から、または相互から切断されたままの場合、次数制約に違反しない場合にのみ 1 に付随する残りのエッジを使用します。 そうしないと建設が不可能になります。 

プロセスをよりわかりやすく表示するには、次の方法があります。 

1 の各隣接要素をコンポーネントの潜在的なコネクタとして扱います。 選択した各隣接頂点を 1 に縮小した後、残りのすべての頂点が単一の接続された構造を形成するように、それらのうち正確に D 個を選択する必要があります。 

DSU により、フォレスト内で {2..n} を超えるサイクルが形成されず、異なるコンポーネントを接続するエッジのみが使用されることが保証されます。 

### なぜ効果があるのか

 すべてのスパニング ツリーは頂点 1 でルート化できます。このようなルート化されたツリーでは、1 の子は 1 を削除した後に形成された個別のコンポーネントに対応します。したがって、頂点 1 の次数は、頂点 1 を削除することによって生じたフォレスト内のコンポーネントの数と等しくなります。 私たちの構築では、{2..n} にフォレストを明示的に作成し、これらのコンポーネントの正確に D を頂点 1 に接続します。DSU は各コンポーネント内の非循環性を保証し、必要な場合にのみコンポーネントを接続するため、結果として得られる構造は接続されており、非周期的であるため、有効なスパニング ツリーとなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]
        return True

def solve():
    n, m, D = map(int, input().split())
    edges = []
    star = []
    
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        if u == 0 or v == 0:
            star.append((u, v))
        else:
            edges.append((u, v))

    dsu = DSU(n)
    tree = []

    for u, v in edges:
        if dsu.union(u, v):
            tree.append((u, v))

    comp_set = set()
    for u, v in star:
        comp_set.add(dsu.find(v if u == 0 else u))

    used = 0
    used_edges = []

    for u, v in star:
        if used == D:
            break
        x = v if u == 0 else u
        if dsu.union(0, x):
            used_edges.append((u, v))
            used += 1

    if used != D:
        print("NO")
        return

    # connect remaining components if needed using leftover star edges
    for u, v in star:
        if dsu.union(u, v):
            tree.append((u, v))

    if len(tree) != n - 1:
        print("NO")
        return

    print("YES")
    for u, v in tree:
        print(u + 1, v + 1)

if __name__ == "__main__":
    solve()
```コードは、エッジを頂点 1 に属するエッジとその他すべてに分割します。 DSU はまず、非 1 頂点上にスパニング フォレストを構築し、そこにサイクルが作成されないようにします。 次に、以前に分離したコンポーネントを接続する最大 D のエッジを使用して、頂点 1 を選択的に接続します。 

実装の重要な詳細は、1 に関連するエッジを使用するたびに、そのエンドポイントを 1 を含むコンポーネントに即座にマージし、サイクルを形成するためにそれを再利用しないようにすることです。 最終チェックでは、正確に n − 1 個のエッジが選択されたことが確認され、スパニング ツリーが構築されたことが確認されます。

 ### 例 1

 入力:```
4 5 1
1 2
1 3
1 4
2 3
3 4
```まず、ノード 2、3、4 上に DSU を構築します。 

| ステップ | エッジ | DSU アクション | 木の端 | 度(1) |
 | --- | --- | --- | --- | --- |
 | 1 | 2-3 | 組合 | 2-3 | 0 |
 | 2 | 3-4 | 組合 | 2-3、3-4 | 0 |

 ここでエッジを 1 から処理します。D = 1 のエッジが必要です。 

1 ～ 2 (または新しいコンポーネントを接続する有効な 1 つ) を選択します。 

| ステップ | エッジ | DSU アクション | 木の端 | 度(1) |
 | --- | --- | --- | --- | --- |
 | 3 | 1-2 | 接続 | +1-2 | 1 |

 最後のツリーは接続されており、頂点 1 の次数は正確に 1 です。 

これは、DSU が問題を 1 つの代表的な接続の選択に軽減する方法を示しています。 

### 例 2

 入力:```

1 3

4 5
```まず、非 1 エッジを使用して {2,3,4,5} 上に DSU を構築します。 

| ステップ | エッジ | アクション | コンポーネント |

これは、重要な実現可能性条件を示しています。頂点 1 は、存在する以上のコンポーネントを接続できないということです。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、頂点 1 を除くすべての頂点が 1 のエッジを使用せずにすでに接続されている場合です。その状況では、頂点 1 は 1 つのコンポーネントのみにアタッチできるため、1 より大きい D は強制的に失敗します。 非 1 ノード上の DSU では単一のコンポーネントが生成され、使用可能なアタッチメントの数は 1 つだけであるため、アルゴリズムはこれを処理します。 

もう 1 つのケースは、頂点 1 に正確に D 個の入射エッジがあるが、それらの一部が同じコンポーネント内に既にある頂点に接続している場合です。 DSU チェックでは、冗長なエッジのカウントが防止されるため、実際に接続性を向上させるエッジのみがカウントされ、ツリー内の新しい構造に対応しない度合いの増大が回避されます。 

最後の微妙なケースは、頂点 1 からの複数のエッジが同じ DSU コンポーネントに接続する場合です。 最初のそのようなエッジのみを使用できます。 それ以降のものは DSU 構造を変更しないため無視されます。 これにより、次数カウントが生の隣接関係ではなく、明確な構造上の接続を反映するようになります。
