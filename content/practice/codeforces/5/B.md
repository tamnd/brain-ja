 ## 解決策
 ## 問題の理解

 数行のテキストが与えられます。 すべての行には、行内に文字、数字、スペースを含めることができますが、先頭や末尾には含めることはできません。 タスクは、次のような長方形のフレーム内のすべての行を印刷することです。`*`文字。 

フレームの内側の幅は、最長の線の長さと等しくなければなりません。 短い線はすべて、その幅の中央に配置する必要があります。 残りの空きスペースが奇数の場合、一方の側が他方よりも 1 つ多くのスペースを受け取る必要があるため、完璧なセンタリングは不可能です。 この問題では、左側と右側の余分なスペースを交互に配置し、左側から最初にスペースを少なくするように求められます。 

たとえば、最大幅が`10`そして線には長さがある`7`、それから、`3`配布するための追加のスペース。 一方が取得します`1`、もう一方は取得します`2`。 最初のそのような行は左端に近づく必要があり、これは左パディングを意味します。`1`そして右側のパディング`2`。 次の奇妙なケースは反転して右端に近づくはずです。 

制約はわずかです。 すべての行の合計文字数は最大で次のとおりです。`1000`, そのため、比較的非効率な文字列操作であっても安全です。 パフォーマンスを心配することなく、すべての行を自由に複数回スキャンできます。 単純な実装はすでに十分に高速です。 

難しいのは速度ではなく、フォーマットの正確さです。 いくつかのエッジケースでは、不注意な実装が静かに破壊される可能性があります。 

微妙なケースの 1 つは、完全に空の行です。 考慮する：```
abc

d
```空の行はフレーム内に表示する必要があります。```
*****
*abc*
*   *
* d *
*****
```よくある間違いは、読み取り中に空の入力行をスキップすることです。 

もう 1 つの注意が必要なケースは、奇妙な違いに対して余分なスペースを交互に使用することです。 最長の線に幅があると仮定します`6`:```
abcdef
abc
xy
```ライン`"abc"`ニーズ`3`余分なスペース。 最初の奇妙なケースでは左パディングを使用する必要があります`1`そして右側のパディング`2`:```
* abc  *
```次の奇妙なケースは反転する必要があります。```
*  xy  *
```常に大きい方を右側にすると、出力は不正確になります。 

すべての行がすでに同じ長さであるという特殊なケースもあります。```
abc
def
ghi
```フレーム自体を超えるパディングは必要ありません。```
*****
*abc*
*def*
*ghi*
*****
```バグのある実装により、誤って不要なスペースが挿入される可能性があります。 

## アプローチ

 最も直接的なアプローチは、有効な中央配置が見つかるまで、行ごとに可能な左右のパディング分割をすべて試してみることです。 一定の長さの線の場合`k`内幅`W`、すべてのペアをテストできます`(L, R)`そのような`L + R = W - k`そして`|L - R| <= 1`。 これが機能するのは、中央揃えのテキストの定義ではそれらの分布のみが許可されているためです。 

この強引なアイデアは不要ですが、それでも十分に高速です。 最大幅は最大です`1000`したがって、すべての行に対してすべてのパディング分割を試みると、最大で約 100 万回の操作が必要になります。 

パディングがほぼ完全に決定されることが観察されると、問題はより明確になります。 残りのスペースが偶数の場合、両側はまったく同じ数のスペースを受け取る必要があります。 残りのスペースが奇数の場合、有効な選択肢は 2 つだけです。```
left = diff // 2
right = diff // 2 + 1
```または```
left = diff // 2 + 1
right = diff // 2
```このステートメントは、毎回どちらを使用するかを明示的に示します。左側に近い行から順に、それらを交互に使用します。 

この観察により、すべての検索が不要になります。 必要なのは以下だけです:

 1. すべての行を読みます。 
2. 最大長を見つけます。 
3. 各行について、不足しているスペースを計算します。 
4. 奇数のケースを交互に均等に配置します。 
5. フレームを印刷します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * W) | O(n) | 承認済み |
 | 最適 | O(合計文字数) | O(n) | 承認済み |

 ここ、`n`は行数であり、`W`は最大幅です。 

## アルゴリズムのチュートリアル

 1. EOF まですべての入力行を読み取り、末尾の改行文字のみを削除します。 

内部スペースと空行を保持する必要があります。 使用する`rstrip('\n')`プレーンなので重要です`strip()`意味のある空間を破壊してしまうでしょう。 
2. 線の最大長を計算します。 

これによりフレームの内側の幅が決まります。 
3. 上枠を印刷します。 

境界線の幅は次のとおりです`max_len + 2`フレームが1つ追加されるため`*`両側にあります。 
4. 各行を個別に処理します。 

させて`diff = max_len - len(line)`まだ挿入する必要があるスペースの数になります。 
5. もし`diff`が偶数である場合は、均等に分割します。 

使用：```
left = right = diff // 2
```これにより、完璧なセンタリングが得られます。 
6. もし`diff`奇数の場合は、大きい方を交互にします。 

ブール値フラグを維持します。 最初の奇妙なケースの場合:```
left = diff // 2
right = diff // 2 + 1
```次の奇妙なケースについては、次のようになります。```
left = diff // 2 + 1
right = diff // 2
```次に、旗を反転します。 
7. 印刷:```
* + left spaces + line + right spaces + *
```8. すべての行を印刷した後、下の境界線を印刷します。 

### なぜ効果があるのか

 すべての行が正確に占有している必要があります`max_len`枠内の文字。 アルゴリズムは常に正確に加算します`diff`スペースがあるため、最終的な幅は正確になります。 

いつ`diff`が均等である場合、可能な唯一の中央配置は均等なパディングです。 いつ`diff`が奇数の場合、有効な中央配置のみが辺間のスペースが 1 つ異なります。 交互フラグはステートメントの正確なタイブレーク ルールに従うため、あらゆるあいまいなケースは正しく解決されます。 

上下の境界線は両方とも幅を使用するため、`max_len + 2`、フレームはフォーマットされたすべての行を完全に囲みます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

lines = [line.rstrip('\n') for line in sys.stdin]

max_len = max(len(line) for line in lines)

border = '*' * (max_len + 2)
print(border)

left_turn = True

for line in lines:
    diff = max_len - len(line)

    if diff % 2 == 0:
        left = right = diff // 2
    else:
        if left_turn:
            left = diff // 2
            right = diff // 2 + 1
        else:
            left = diff // 2 + 1
            right = diff // 2

        left_turn = not left_turn

    print('*' + ' ' * left + line + ' ' * right + '*')

print(border)
```最初の部分は、書かれたとおりにすべての行を読み取ります。 使用する`rstrip('\n')`の代わりに`strip()`この問題では行内にスペースが許可されており、スペースを削除するとテキストが破損するため、これが重要です。 

行の最大長はテキスト領域の幅を定義します。 枠線文字を追加する前に、書式設定されたすべての行がこの幅と一致する必要があります。 

変数`left_turn`奇数のパディングの違いに対する交互の動作を制御します。 差が奇数の場合のみ反転します。 差分であっても有効な分割は 1 つだけであるため、そこには交互は適用されません。 

表現:```
diff // 2
```そして```
diff // 2 + 1
```整数の除算は切り捨てられるため、奇数の差が正しく分配されます。 

境界線の長さは`max_len + 2`フレームが貢献するからです`*`テキスト領域の両側にあります。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    import sys
    input = sys.stdin.readline

    lines = [line.rstrip('\n') for line in sys.stdin]

    max_len = max(len(line) for line in lines)

    border = '*' * (max_len + 2)

    out = [border]

    left_turn = True

    for line in lines:
        diff = max_len - len(line)

        if diff % 2 == 0:
            left = right = diff // 2
        else:
            if left_turn:
                left = diff // 2
                right = diff // 2 + 1
            else:
                left = diff // 2 + 1
                right = diff // 2

            left_turn = not left_turn

        out.append('*' + ' ' * left + line + ' ' * right + '*')

    out.append(border)

    print('\n'.join(out))

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    return sys.stdout.getvalue()

# provided sample
assert run(
"""This  is

Codeforces
Beta
Round
5
"""
) == (
"""************
*This  is *
*          *
*Codeforces*
*   Beta   *
*  Round   *
*     5    *
************
"""
), "sample 1"

# minimum-size input
assert run(
"""a
"""
) == (
"""***
*a*
***
"""
), "single character"

# all equal lengths
assert run(
"""abc
def
ghi
"""
) == (
"""*****
*abc*
*def*
*ghi*
*****
"""
), "equal lengths"

# alternating odd padding
assert run(

x
"""
) == (

* abc  *
*  x   *

"""
), "alternating odd differences"

# empty line handling
assert run(

"""
) == (
"""*****
*abc*
*   *
* d *
*****
"""
), "empty line preserved"

 | --- | --- | --- |
 |`a`| 単一の中央揃えの文字 | 有効な最小入力値 |

 ## 特殊なケース

 次の入力を考えてみましょう。```
abc

d
```最大幅は`3`。 空行には長さがあります`0`、したがって、それが必要です`3`両側のスペースを組み合わせたもの。 以来`3`が奇数の場合、アルゴリズムは次を割り当てます。```
left = 1
right = 2
```生成される行は次のようになります。```
*   *
```アルゴリズムは空の行も含めて入力からすべての行を読み取るため、空白行は保持されます。 

次に、奇妙な違いを交互に考えてみましょう。```
abcdef
abc
5
```最大幅は`6`。 

のために`"abc"`:```
diff = 3
left = 1
right = 2
```のために`"5"`:```
diff = 5
left = 3
right = 2
```最初の奇数のケースの後にフラグが反転するため、2 番目の奇数のケースでは大きい側が反転します。 これは、必要な交互動作に正確に一致します。 

最後に、すでに位置合わせされたテキストについて考えてみましょう。```
abc
def
ghi
```すべての行にはすでに長さが設定されています`3`、 それで：```
diff = 0
```スペースは挿入されません。 アルゴリズムは単に各行を次のようにラップします。`*`、可能な限り最小の有効なフレームを生成します。
