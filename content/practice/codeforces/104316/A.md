 ## 問題の理解

 私たちには次のようなシステムが与えられています$n$それぞれのポジションが最初は学生を担当します。 最初の配置は不明であり、順列によって表されます。$b$。 時間の経過とともに、生徒は一定の順列に従って繰り返し移動します。$p$: 所定の位置に座っている学生$i$位置に移動します$p_i$ワンステップで。 この変換は複数回適用されます。 

すべての動きの後、最終的な配置を観察します$a$、これも順列です。 課題は、考えられる初期配置を再構築することです$b$順列を適用すると、$p$繰り返し起こる$a$ある程度の回数の完全なラウンドの後、すべての有効な初期配置の中で、辞書編集的に最小のものを出力する必要があります。 

重要な難点は、このプロセスの構造が完全に可逆的であることです。$p$は順列であるため、すべての位置はサイクル上にあります。 各サイクルは独立して進化し、各サイクル内で基本的に値が循環します。 

制約$n \le 5 \cdot 10^5$線形または線形に近い解決策が必要であることを意味します。 最悪の場合のサイクルはすべて長さ 1 または 1 つの大きなサイクルになる可能性があり、シミュレーションを繰り返すと時間制限を超える可能性があるため、サイクルにわたる二次関数は不可能です。 

サイクルに複数の有効なアライメントがあり、最終的に同じ配置になる場合、微妙なエッジ ケースが発生します。 たとえば、サイクルの長さが 4 で、最終値が$[1,2,3,4]$under some rotation, then multiple initial rotations are valid. 単純な再構成では、サイクルごとに任意の回転が選択される可能性がありますが、辞書編集的最小化では、置換の初期の位置がより重要であるため、サイクル全体にわたる選択肢が結合されます。 

もう 1 つの自明ではないケースは、サイクルが独立しているが、辞書編集的な順序付けにより、値に関して貪欲ではなく、一貫した位置マッピングでサイクルごとの最小回転を選択する必要がある場合です。 

## アプローチ

 A brute-force approach would try all possible initial permutations$b$、適用をシミュレートします$p$到着するまで$a$、有効性を確認します。 これは直ちに実行不可能です。$n!$候補者、および 1 回のシミュレーションでも費用がかかります$O(n)$、につながる$O(n! \cdot n)$、それは天文学的な大きさです。 

問題の構造は順列によって支配されます$p$。 すべてのインデックスは有向サイクルに属しており、$p$繰り返し、各サイクル内で値をローテーションするだけです。 これは、問題が独立したサイクルに分解されることを意味します。 

単一サイクル内で、そのインデックスを走査順序でリストするとします。 変革$p$循環シフトとして機能します。 最終的な構成$a$したがって、初期構成の何らかの回転に対応する必要があります。$b$。 これにより、サイクルごとの問題が軽減されます。 一致するように、繰り返されるシフトの下で前方にマップされるサイクルのローテーションを選択します。$a$、辞書編集的に最小のグローバル配置を選択します。 

重要な観察は、時間的に前向きに考える代わりに、各サイクルに一貫した「開始オフセット」を割り当てて、サイクルを順方向に横断するときに結果の配置が一致するようにできることです。$a$。 からの制約$a$どの回転が有効であるかを一意に決定し、その中で、循環順序の最も早い位置で可能な最小の開始値を固定することによって、辞書編集的に最小のものを選択します。 

サイクルは独立していますが、辞書編集順はグローバル配列を比較するため、最小インデックスの昇順でサイクルを処理し、実行可能な最小のローテーションを貪欲に割り当てます。

 ## アルゴリズムのチュートリアル

 まず順列を分解します$p$ばらばらのサイクルに。 各サイクルについて、そのインデックスを走査順序で記録します。 

次に、最終的な配置を使用します$a$各サイクル内に値をどのように配置する必要があるかを理解します。 動きはサイクル内でのみ順列するため、各サイクルは$a$のサイクルに割り当てられた値のローテーションに正確に対応する必要があります。$b$。 

各サイクルを独立して処理しますが、$b$辞書編集上の最小性をグローバルに保証する方法で。 

1. すべてのサイクルを特定する$p$。 未訪問のインデックスごとに、次のようになります。$p$スタートに戻るまで、サイクルを順番に記録します。 
2. サイクルごとに、次から値のシーケンスを抽出します。$a$サイクル順にそれらの位置にあります。 これにより、そのサイクルの最終的な回転バージョンが得られます。 
3. 辞書編集上可能な限り最小の初期配置を生成する回転を決定します。 どの回転も有効であるため、サイクルの最初の要素をできるだけ小さくする回転を選択し、結合されている場合は、サイクルに沿って辞書編集的に最小化し続けます。 
4. これらの選択した値を再度書き込みます。$b$サイクル位置に沿って、対応する順序で配置されます。 

微妙な点は、「辞書編集上の最小」がサイクルローカル配列ではなく配列全体に適用されることです。 ただし、サイクルは互いに素であるため、2 つの候補間で最も早く異なる位置は、それらが異なる最小のインデックスを含むサイクル内にあります。 したがって、最小インデックスの増加順に各サイクルを最小化すると、グローバルな最小性が保証されます。 

### なぜ効果があるのか

 各サイクルは順列化された独立した回転グループです$p$。 最終的な配列$a$サイクルごとの値のマルチセットと、回転までのそれらの循環順序を修正します。 有効な初期設定は、各サイクルのローテーションの選択に対応します。 2 つのグローバル候補間の辞書編集的な比較は、正確に 1 サイクル内にある、それらが異なる最初のインデックスで決定されます。 各サイクル内で辞書編集上最小のローテーションを選択すると、代替ローテーションによってそのサイクルの最初に影響を受けるインデックスでより小さなプレフィックスが生成されなくなり、全体的な改善は不可能になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    p = [0] + list(map(int, input().split()))
    a = [0] + list(map(int, input().split()))

    vis = [False] * (n + 1)
    b = [0] * (n + 1)

    for i in range(1, n + 1):
        if vis[i]:
            continue

        cycle = []
        cur = i
        while not vis[cur]:
            vis[cur] = True
            cycle.append(cur)
            cur = p[cur]

        m = len(cycle)

        # values in final arrangement along cycle order
        vals = [a[x] for x in cycle]

        # find lexicographically smallest rotation of vals
        # by doubling and using minimal starting point
        best = 0
        doubled = vals * 2

        for j in range(1, m):
            for k in range(m):
                if doubled[j + k] < doubled[best + k]:
                    best = j
                    break
                if doubled[j + k] > doubled[best + k]:
                    break

        rotated = [doubled[best + k] for k in range(m)]

        for idx, pos in enumerate(cycle):
            b[pos] = rotated[idx]

    print(*b[1:])

if __name__ == "__main__":
    solve()
```解決策は、順列と最終的な配置を読み取ることから始まります。 その後分解します$p$訪問した配列を使用してサイクルに変換します。 サイクルごとに、対応する値を次から抽出します。$a$、すべての回転後にそのサイクルがどのように見えるかを表します。 

辞書編集的に最小化するために、単純な 2 倍比較を使用して、そのサイクルの値シーケンスの最小回転を計算します。 各サイクルは独立しており、最小の循環シフトのみが必要なため、これで十分です。 

最後に、回転されたシーケンスを走査順序で元のサイクル位置に書き込み、初期配置を生成します。 

よくある落とし穴は、サイクル値をソートできる、または貪欲に最小の要素を最初に配置できると想定していることです。 これにより、回転制約が破られます。値は循環的な順序でロックされ、自由に変更できなくなります。

 ## 特殊なケース

 単一要素サイクルは、有効な回転が 1 つしかないため、自明に動作します。 アルゴリズムはそれを長さ 1 のサイクルとして処理し、値を直接割り当てます。$a$、唯一可能な初期値を生成します。 

全長サイクルの場合、アルゴリズムの回転検索ではサイクル値のすべてのシフトが比較されます。 複数の回転が類似しているように見える場合でも、比較は 2 倍の配列全体で辞書編集的に行われるため、辞書編集的に最小のものが一貫して選択されます。 

すべてのサイクルの長さが 2 の場合、各サイクルは単純なスワップ決定になります。 回転比較は 2 要素の比較に縮退するため、アルゴリズムは依然としてそれらを均一に処理します。 

より微妙な状況は、複数のサイクルに同一の値パターンが含まれている場合です。 それでも、サイクルの独立性により干渉がないことが保証され、サイクル内の最小インデックスによる順序付けにより決定的な割り当てが保証されます。
