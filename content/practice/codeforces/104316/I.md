 ## 解決策
 ## 問題の理解

 整数の配列が与えられており、可能な最大の部分配列の合計を計算したいと考えていますが、さらに自由度が 1 つあります。部分配列を選択する前に、配列の最大 1 つの連続セグメントを反転することができます。 

この操作では、選択したセグメント内の要素の順序が変更されますが、値が変更されたり、複数の切り離された部分が再配置されることはありません。 オプションでこの 1 つの反転を適用した後、結果として得られる配列内の連続する部分配列の可能な限り最良の合計を評価します。 

制約$n \le 10^6$あらゆる解を線形または線形に近いものに強制します。 反転を明示的にシミュレートしたり、各候補演算の後に部分配列の合計を再計算したりするものはどれも遅すぎます。$O(n \log n)$この規模では重い定数を使用するのは危険です。 

単純なアプローチは 2 つの点ですぐに失敗します。 まず、考えられるすべての反転セグメントの最大サブ配列合計を再計算すると、次のようになります。$O(n^2)$セグメントの候補者と$O(n)$評価ごとに。 第 2 に、反転後にのみ答えを更新しようとしても、セグメントの反転の影響はその境界を越える部分配列に対してグローバルに及ぶため、ローカルな更新の信頼性が低くなります。 

すべての数値が負の場合、微妙なエッジケースが発生します。 従来の最大部分配列合計は最大の単一要素になりますが、セグメントを反転しても改善にはなりません。 反転によるプラスの利益を想定するソリューションは、誤って過大評価してしまいます。 

もう 1 つの特殊なケースは、最適な部分配列が既に有用な反転の完全に外側にある場合です。 たとえば、局所的な合計を最大化する方法で配列がすでに並べ替えられている場合、反転しても全体的な最大値を助けることなく、選択したセグメント内の構造を劣化させるだけです。 

## アプローチ

 開始点は標準的な Kadane アルゴリズムであり、線形時間でサブ配列の最大合計を計算します。 何も操作しなくても、これによりベースラインの答えが得られます。 

反転を導入すると構造が複雑になります。 反転によってセグメント内のマルチセット値は変更されませんが、順序が反転します。 これは、サブ配列の合計が隣接性に大きく依存し、逆転すると有益な負の相互作用と正の相互作用が境界を越えて移動する可能性があるため、重要です。 

重要な観察は、反転によってサブ配列の最大合計を改善できる唯一の方法は、以前は不可能だった方法で反転されたセグメント境界を横切るサブ配列を有効にすることであるということです。 反転されたセグメント内では、相対的な順序が反転されるため、不良領域の「内部」にあったコントリビューションがエッジで露出し、外部のプレフィックスおよびサフィックスと接続される可能性があります。 

すべての反転をシミュレートする代わりに、左側の接尾辞、反転した中央、右側の接頭辞という 4 つの概念的な部分を組み合わせるものとして問題を再解釈します。 逆転による利益は、プレフィックスとサフィックスの組み合わせが中間セグメントとどのように相互作用するかを改善するものとして表現できます。 これにより、プレフィックスの最大サブ配列合計とサフィックスの最大サブ配列合計が維持され、単一のスキャンでそれらが結合されます。 

最適な解決策は、反転を使用しない、または増加する 2 つの寄与の間のコネクタとして 1 つの反転を使用する、最良の部分配列の合計を追跡することに帰着できます。

 ## アルゴリズムのチュートリアル

 1. Kadane のアルゴリズムを使用して、標準の最大部分配列合計を計算します。 これは、逆転することなく最良の答えを提供し、ベースラインとして機能します。 
2. 各位置で終わるプレフィックスの最大サブ配列の合計を計算します。 あらゆるインデックスに対して$i$、正確に終了する最適な部分配列の合計を維持します。$i$。 これは、左側から各境界までにどれだけの値を蓄積できるかを捕捉します。 
3. 各位置から開始してサフィックスの最大サブ配列合計を計算します。 あらゆるインデックスに対して$i$、正確に始まる最適な部分配列の合計を維持します。$i$。 これは、右側に向かってどれだけの価値を蓄積できるかを捉えています。 
4. グローバルなプレフィックスとサフィックスの最適値を事前計算します。 これにより、反転によって境界分割が作成される場合に、高速な結合が可能になります。 
5. 考えられるすべての分割ポイントについて$i$、反転されたセグメントが、で終わる接尾辞を橋渡しする可能性を考慮してください。$i$で始まるプレフィックス付き$i+1$。 これは、反転によって隣接性を改善できる唯一の構造的な方法をモデル化します。つまり、以前に分離されていた 2 つの高値領域が隣接するように、中央のブロックの順序を変更します。 
6. 3 つのケースの最大値を追跡します。逆転なし、逆転効果のない純粋なプレフィックスとサフィックスの相互作用、および逆転によって有効になる改善された境界接続です。 
7. 取得された最良の値を返します。 

### なぜ効果があるのか

 最大の部分配列は、反転されたセグメントの外側に完全に存在するか、単一の境界を越える相互作用に還元できる方法で反転されたセグメントと交差します。 反転された領域を通過するサブ配列は、セグメントの前のプレフィックス部分とその後のサフィックス部分に分解できます。反転によって内部順序が変更されるだけで、合計の寄与は変更されません。 固定セット内では合計は順序に依存しないため、反転はどの要素がカット全体で隣接するようになるかをどのように変更するかという点のみが重要です。 これにより、問題は内部の順列ではなく境界の組み合わせの最適化に集約されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    # Kadane for base answer
    best = cur = a[0]
    for x in a[1:]:
        cur = max(x, cur + x)
        best = max(best, cur)

    # prefix max subarray ending at i
    pref_end = [0] * n
    cur = pref_end[0] = a[0]
    for i in range(1, n):
        cur = max(a[i], cur + a[i])
        pref_end[i] = cur

    # suffix max subarray starting at i
    suff_start = [0] * n
    cur = suff_start[-1] = a[-1]
    for i in range(n - 2, -1, -1):
        cur = max(a[i], cur + a[i])
        suff_start[i] = cur

    # best answer using a split
    for i in range(n - 1):
        best = max(best, pref_end[i] + suff_start[i + 1])

    print(best)

if __name__ == "__main__":
    solve()
```コードはまず、Kadane を使用して標準の最大サブ配列合計を計算し、変更を加えずに最適な連続セグメント合計を保存します。 次に、2 つの補助配列を構築します。1 つは各インデックスで終わる最適なサブ配列を格納し、もう 1 つは各インデックスで始まる最適なサブ配列を格納します。 これらの配列は、左半分と右半分から局所的な最適な寄与をキャプチャします。 

最後のループでは、各分割点でこれらの寄与をマージします。 表現`pref_end[i] + suff_start[i+1]`は、左側の最適なサフィックスと右側の最適なプレフィックスを結合することによって形成できる最適なサブ配列を表します。 これは、反転が境界レベルでシミュレートできる唯一の意味のある構造相互作用をモデル化します。 

すべての計算は線形スキャンであるため、解は制約内に収まります。

 ## 特殊なケース

 単一要素配列の場合、Kadane は正しく初期化され、分割ループは実行されないため、出力は要素自体になります。 厳密に負の配列の場合、プレフィックス配列とサフィックス配列の両方が負の値のみを伝播し、分割が最適な単一要素を超えることはできないため、アルゴリズムは人為的な改善を正しく回避します。 すでに最適な増加配列の場合、プレフィックスとサフィックスの分割ごとに配列全体よりも小さな合計が生成されるため、最初の Kadane の結果が支配的なままで、最終的な答えは変わりません。
