 ## 解決策
 ## 問題の理解

 方向が固定された、軸に揃えられた長方形のマルチセットが与えられます。 各長方形には高さと幅があり、回転は許可されません。つまり、長方形です。`(a, b)`とは異なります`(b, a)`両方の座標が等しい場合を除きます。 

これらの長方形は、サイズが不明な 1 つの初期長方形から始まるプロセスから来たものであると主張されています。`h × w`。 次に、長方形が整数のグリッド線に沿って垂直または水平に繰り返し切断され、常に辺の長さが整数のままの 2 つの小さな長方形が生成されます。 まさにその後`n − 1`カット、最終的には`n`長方形をシャッフルします。 そのうちの 1 つはすべてのカットを経て最後に残った部分であり、もう 1 つは`n − 1`ピースはまさにプロセス中に切り取られたピースです。 

私たちのタスクは、考えられるすべての初期長方形を回復することです。`(h, w)`これにより、まさにこの複数の長方形のセットが生成される可能性があります。 

制約に関する重要な観察事項は次のとおりです。`n`は 200,000 まで大きくなり、辺の長さは最大 1e6 になります。 これにより、切断プロセスをシミュレートしたり、長方形ごとに候補の分解を再計算しようとするアプローチは即座に排除されます。 二次関数の何か`n`不可能ですし、`O(n log n)`メソッドは、頻度カウントや貪欲な構造に基づいて慎重に設計する必要があります。 

微妙な問題は、最後に残った長方形がマークされていないことです。 のいずれか`n`長方形が最後のピースだったかもしれません。 もう 1 つの微妙な点は、カットでは方向が保持されるため、構築中に寸法を交換できないことです。 これは候補者を検証する際に非常に重要になります。 

素朴な推論を打ち破るエッジケースには、次のようなものがあります。 

単一の長方形の場合`n = 1`。 この状況では、任意の長方形`(a, b)`in input はそれ自体が元の四角形である必要があるため、答えはその 1 つのペアであることは自明です。 

もう 1 つの注意が必要なケースは、複数の長方形が同一である場合です。 たとえば、すべての長方形が`1 × 1`、その後任意の初期正方形`(h, w)`再帰的に単位正方形に分割できることは有効ですが、制約により構造が強制されます。グリッド分解と一致する分割のべき乗のみが機能し、一意性に関する単純な仮定は失敗します。 

3 番目のエッジ ケースは、すべてのピースの 1 つの次元が 1 である場合に発生します。 その後、すべてのカットが単一方向に強制され、問題は線分を分割することになりますが、これは候補を検証するときに一貫して処理する必要があります。 

## アプローチ

 ブルートフォースのアイデアは、入力内のすべての四角形を最終的に残る可能性のある部分として、各候補に対して試してみることです。`(h, w)`、そこから開始して、繰り返し分割することで指定された複数の四角形セットを正確に生成できるかどうかをシミュレートします。 

ただし、考えられるカット オーダーが多数あるため、プロセスのシミュレーションは明確に定義されていません。 正しいチェックには、マルチセットを正確に生成するバイナリ分割ツリーの存在を検証する必要があります。これは、逆の操作を使用してすべての四角形を 1 つの四角形にマージできるかどうかを確認するのと同じです。 単純に行うと、候補ルートごとに長方形のマージを繰り返し試行し、マルチセットを繰り返しスキャンしてマージを試みるようなことになります。`O(n^2)`最悪の場合、候補者ごとに`O(n^3)`全体的に退廃的な推論です。 

重要な構造的洞察は、プロセスを逆転させることです。 長方形がどのように分割されるかを考える代わりに、最終的なセットがどのようにマージされるかを考えます。 すべてのカットは、共有の完全な側面に沿って完全に整列する 2 つの長方形を組み合わせることに対応します。 これは、入力内のすべての長方形がその面積に寄与し、元の長方形の面積がすべての面積の合計に等しい必要があることを意味します。 それで`(h, w)`満たさなければなりません`h × w = total area`。 

これにより、問題は、総面積の約数を列挙し、各候補ペアの実現可能性を確認することになります。 

残りの重要な部分は検証です。長方形を繰り返し結合することによって総面積のすべての因子ペアを形成できるわけではありません。 この構造により、すべての四角形を候補四角形の階層パーティションに配置できるようになります。 これは、複数の四角形セットを維持し、1 つの四角形だけが残るまで、残っている最大の部分を互換性のある近傍と繰り返しマージすることで、貪欲に検証できます。 

重要なのは、有効な構造では常に完全な共有境界に沿って四角形をマージできる必要があり、貪欲な構造により、実行可能性を維持するマージのみを試行することが保証され、これはカウントと順序によってチェックできます。

 ## アルゴリズムのチュートリアル

 私たちは問題を、長方形の断片からの制約付きの再構成に変えることによって進めます。 

1. 指定されたすべての長方形の合計面積を計算します。 これは等しい必要があります`h × w`カットは領域を正確に保持するため、有効な答えは得られません。 これにより、どの候補者も満たさなければならない厳しいグローバル制約が与えられます。 
2. すべての因子ペアを列挙します`(h, w)`総面積のうち。 このような各ペアは、初期の長方形となる可能性があります。 このステップは、合計面積が最大でも`n × 10^12`、平方根までの列挙が許容されます。 
3. 各候補者について`(h, w)`、指定されたすべての長方形の周波数構造を構築します。 
4. マージの逆のプロセスをシミュレートしてみます。 複数の長方形のセットを維持します。 目標は、有効なカットを反転することによって、より大きな長方形を形成できる 2 つの長方形を繰り返し選択することです。つまり、これらの長方形は完全な辺を共有し、寸法が正確に揃っています。 
5. これを強制する実際的な方法は、高さ全体または幅全体の境界を共有する長方形を常にマージすることです。 2つの長方形があるかどうかを確認します`(a, b)`そして`(c, d)`水平方向または垂直方向のいずれかで、より大きな長方形を形成できます。`a == c`幅が追加される、または`b == d`そして高さも加わります。 
6. マージができなくなるまで、有効なマージを繰り返し実行します。 ちょうど 1 つの長方形で終わると、`(h, w)`、候補は有効です。 
7. 有効な候補をすべて集めて出力します。 

### なぜ効果があるのか

 順方向プロセスのすべてのカット操作は、1 つの長方形を完全な辺を共有する 2 つに分割することに正確に対応します。 これを逆にすると、有効な構成では、軸の位置合わせに違反することなく、四角形をより大きな四角形にペアにすることができなければなりません。 不変条件は、マージの各段階で、長方形のマルチセットが、元の長方形を互いに素な軸に沿ったサブ長方形に分割した有効な部分分割に対応するということです。 候補者であれば`(h, w)`は正しいので、この不変条件により、完全な四角形を再構築するまで、有効なマージ シーケンスを常に見つけることができることが保証されます。 それが正しくない場合、有効なパーティションがないため、プロセスは必然的に互換性のない形状でスタックします。`(h, w)`そのマルチセットを含めることができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from collections import Counter

def all_factors(x):
    res = []
    i = 1
    while i * i <= x:
        if x % i == 0:
            res.append((i, x // i))
        i += 1
    return res

def can_build(rects, h, w):
    # multiset of rectangles
    cnt = Counter(rects)
    
    # convert to list for repeated merging attempts
    changed = True
    while changed:
        changed = False
        items = list(cnt.items())
        
        # try to merge any compatible pair
        for (a, b), ca in items:
            if ca == 0:
                continue
            for (c, d), cc in items:
                if (a, b) == (c, d) and ca < 2:
                    continue
                if cc == 0:
                    continue
                
                # horizontal merge: same height
                if a == c:
                    new = (a, b + d)
                    if new[1] <= w:
                        cnt[(a, b)] -= 1
                        cnt[(c, d)] -= 1
                        cnt[new] += 1
                        changed = True
                        break
                
                # vertical merge: same width
                if b == d:
                    new = (a + c, b)
                    if new[0] <= h:
                        cnt[(a, b)] -= 1
                        cnt[(c, d)] -= 1
                        cnt[new] += 1
                        changed = True
                        break
            if changed:
                break
    
    # count non-empty rectangles
    final = [r for r, c in cnt.items() if c > 0]
    return len(final) == 1 and final[0] == (h, w)

def solve():
    n = int(input())
    rects = []
    total_area = 0
    
    for _ in range(n):
        a, b = map(int, input().split())
        rects.append((a, b))
        total_area += a * b
    
    ans = []
    for h, w in all_factors(total_area):
        if can_build(rects, h, w):
            ans.append((h, w))
        if h != w and can_build(rects, w, h):
            ans.append((w, h))
    
    ans.sort()
    print(len(ans))
    for h, w in ans:
        print(h, w)

if __name__ == "__main__":
    solve()
```この解決策は、すべての有効な候補を固定する総面積を計算することから始まります。 因子列挙ステップでは、幾何学的に可能なすべての境界長方形を生成します。 検証関数は、互換性のある四角形を繰り返しマージすることによって、元の四角形の再構築を試みます。 各マージは位置合わせの制約を尊重します。つまり、許可されたカットの逆を反映して、完全な高さまたは幅を共有する長方形のみを結合できます。 

微妙な部分は、特定のマージ順序が存在すると仮定しないようにすることです。 代わりに、有効なマージを貪欲に実行します。 候補が有効な場合、少なくとも 1 つのマージ シーケンスが存在し、この貪欲なプロセスはそれを見つけます。 

## 実用的な例

 ### 例 1

 入力長方形:```
(1,2), (3,5), (1,3)
```総面積は`2 + 15 + 3 = 20`、したがって、候補ペアは`(1,20), (2,10), (4,5), (5,4), (10,2), (20,1)`。 

候補者を追跡します`(4,5)`:

 | ステップ | マルチセット状態 | アクション |
 | --- | --- | --- |
 | 0 | {(1,2)、(3,5)、(1,3)} | 開始 |
 | 1 | {(1,5), (3,5)} | (1,2)+(1,3) を垂直方向にマージする |
 | 2 | {(4,5)} | (1,5)+(3,5) を垂直方向にマージする |

 私たちは到達します`(4,5)`, したがって、それは有効です。 

これにより、有効なマージがターゲット四角形の一貫したパーティションの再構築に正確に対応することが確認されます。 

### 例 2

 入力長方形:```
(1,1), (1,1), (1,1)
```合計面積は 3 なので、`(1,3)`そして`(3,1)`が候補です。 

のために`(1,3)`:

 | ステップ | マルチセット状態 | アクション |
 | --- | --- | --- |
 | 0 | {(1,1)x3} | 開始 |
 | 1 | {(1,2), (1,1)} | 2 つの単位正方形を結合する |
 | 2 | {(1,3)} | 結果を残りの | とマージします。 

これは成功します。 

のために`(3,1)`、同じロジックが適用されますが、直交方向になります。 

これは、アルゴリズムが縮退した 1 次元構造に自然に適応することを示しています。

 ## 特殊なケース

 単一の長方形を備えた最小限のケース`(a, b)`常に 1 つの有効な答えが得られます`(a, b)`カットが行われていないため、最初の長方形は観察された唯一の部分と一致する必要があります。 

すべての四角形が完全に縮退したケース`(1,1)`マージは両方の次元で常に可能であり、アルゴリズムは両方を正しく受け入れることを示しています。`(1, n)`そして`(n, 1)`どちらも有効なタイリングを認めているためです。 

すべての四角形が単一の行または列内にある場合、決定的なマージ順序が強制されます。 すべてのマージが等式制約によって強制され、あいまいな分岐が防止されるため、アルゴリズムは引き続き成功します。 

混合構成では、マルチセットを 1 つの長方形に縮小するための一貫したペアリング シーケンスが存在しないため、貪欲なマージによって互換性のない候補が早期に失敗することが保証されます。
