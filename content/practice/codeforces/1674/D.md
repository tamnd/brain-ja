## Python ソリューション```python
import sys
input = sys.stdin.readline

def can_sort_c(a):
    max_seen = a[0]
    for x in a[1:]:
        if x < max_seen:
            return False
        max_seen = max(max_seen, x)
    return True

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    if can_sort_c(a):
        print("YES")
    else:
        print("NO")
```ソリューションはヘルパーを定義します`can_sort_c`配列かどうかを判断する`a`並べ替えて並べ替えることができます`c`。 配列を最初から最後までスキャンし、検出された最大値を追跡します。 後の要素がこの最大値より小さい場合、中間の挿入と削除を使用して順序を修正することはできません。 コードは複数のテスト ケースを効率的に処理し、不必要なデータ構造を回避します。

更新されたソリューション:```python
import sys
input = sys.stdin.readline

def can_sort_c(a):
    a = a[::-1]
    for i in range(1, len(a)):
        if a[i] > a[i-1]:
            return False
    return True

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a = a[::-1]
        valid = True
        for i in range(1, n):
            if a[i] > a[i-1]:
                valid = False
                break
        output.append("YES" if valid else "NO")
    return "\n".join(output)
