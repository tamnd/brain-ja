 ## 解決策
 ## 問題の理解

 入力は、上昇対角線セグメントと下降対角線セグメントを交互に繰り返すポリラインを記述します。 の長さは、$i$-番目のセグメントは$a_i$。 

ある点から開始してセグメントを次々に描画すると、最初のセグメントは右上に進み、2 番目のセグメントは右下に進み、3 番目のセグメントは再び右上に進みます。 移動単位ごとに両方の座標が 1 つだけ変更されます。 最終的な画像は斜めのストロークのみで構成されているため、占有されている各セルには次のいずれかが含まれます。`/`または`\`。 

このタスクは、心電図を ASCII アートとして印刷することです。 各列は水平移動の 1 単位に対応します。 すべての行は垂直レベルに対応します。 空の位置にはスペースを含める必要があります。 出力には、図面の垂直方向の幅と正確に同じ数の行が含まれている必要があります。 

制約は小さいです。 セグメントの数は最大 1000 で、すべてのセグメントの長さの合計は最大 1000 です。セグメントの各単位ステップは最終ピクチャ内の 1 つの文字位置を正確に占めるため、空でないセルの総数は最大 1000 です。ポリラインのすべてのステップを明示的にシミュレートするアルゴリズムでも、十分に高速です。 

主な困難は効率ではなく、座標の処理です。 

簡単な間違いの 1 つは、スラッシュ文字を間違った垂直レベルに配置することです。 考慮する：```
2
1 1
```最初のセグメントは 1 段階上昇し、2 番目のセグメントは 1 段階下降します。 正しい画像は次のとおりです。```
/\
```不用意に実装すると、`\`1 行下に移動すると、接続されたポリラインの代わりに階段が作成されます。 

もう 1 つの微妙なケースは、図面が負の垂直座標に達した場合です。```
2
1 3
```道は一度上がってから三度下がります。 最低点は開始レベルを下回ります。 これらの座標を行インデックスとして直接使用すると、負の配列インデックスが得られます。 代わりに、印刷する前に画像を上にシフトする必要があります。 

バグの 3 番目の原因は、必要な高さを決定することです。 考慮する：```
3
2 2 2
```パスは上に、下に、そしてまた上に移動します。 最高および最低の訪問レベルは、必ずしもセグメントのエンドポイントだけであるとは限りません。 実装では、占有されているすべてのセルを追跡する必要があります。追跡しないと、割り当てられたグリッドが小さすぎる可能性があります。 

## アプローチ

 最も直接的なアイデアは、説明どおりに図面をシミュレートすることです。 座標から開始$(0,0)$、すべてのセグメントのすべての単位ステップを通過し、現在の位置を占める文字を記録し、検出された最小および最大の垂直座標を追跡します。 

ステップの合計数は最大 1000 であるため、このシミュレーションでは最大 1000 の更新が実行されます。 すべての位置がわかったら、垂直方向の範囲全体をカバーする長方形のグリッドを作成し、その中に記録された文字を配置します。 

より素朴な強引な解釈は、大きな座標平面を作成し、すべてのセグメントに対してすべてのセルをテストして、そのセルが心電図に属しているかどうかを判断することです。 幅が約 1000、高さが約 1000 の場合、セルの数は約 100 万個になり、各セルが多数のセグメントに対してチェックされる可能性があります。 そのようなアプローチは不要です。 

重要な観察は、画像自体には、パスの合計長と同じ数の空ではないセルしか含まれていないということです。 セグメントの長さの合計は 1000 で制限されているため、それらのセルを直接生成することができ、未使用の座標を検査する必要はありません。 

これにより、問題はジオメトリ問題ではなく、単純なシミュレーション問題に変わります。

 ## アルゴリズムのチュートリアル

 1. 座標から開始$(x,y)=(0,0)$。 
2. 占有座標をそのキャラクターにマッピングする辞書を維持します。`/`または`\`。 
3. 図面に表示される最小および最大の行座標を維持します。 
4. セグメントを左から右に処理します。 
5. 奇数番号のセグメントの場合 (パスは上昇します):

 各単位ステップについて:

 - ユニットを 1 つ上に移動します。 
- 場所`/`そのステップに対応するセルで。 
- 1 列右に進みます。 
- 垂直境界を更新します。 

視覚セグメントは左下から右上に向かうため、スラッシュはステップの上端点に配置されます。 
6. 偶数番号のセグメントの場合 (パスが下にあります):

 各単位ステップについて:

 - 場所`\`現在のレベルでは。 
- 1 列右に移動します。 
- ユニットを 1 つ下に移動します。 
- 垂直境界を更新します。 

バックスラッシュは、下降ステップの上部セルを占めます。 
7. すべてのセグメントが処理された後、高さを次のように計算します。`max_y - min_y + 1`幅は水平移動距離の合計です。 
8. スペースで埋められたグリッドを作成します。 
9. 保存されているすべての座標を次のようにシフトしてグリッド行に変換します。`max_y - y`。 これにより、大きな y 値が出力の上部近くに配置されます。 
10. 対応するグリッド位置を、保存されている文字で埋めます。 
11. すべての行を印刷します。 

### なぜ効果があるのか

 心電図の各単位動作は、正確に 1 つの印刷文字に対応します。 シミュレーションはパスを段階的にたどり、各対角線のストロークが占める正確なセルを記録します。 保存された座標は、ポリラインの幾何学的形状を保持します。 

最小および最大の訪問垂直レベルによって、図面全体を含む最小の長方形が決まります。 すべての座標を同じ量だけシフトすると、負のインデックスを排除しながら相対位置が維持されます。 

各セグメントはその定義に従って正確にシミュレートされ、占有されているすべてのセルが一度記録されるため、作成された ASCII アートはまさに必要な心電図となります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    cells = {}

    x = 0
    y = 0

    min_y = 0
    max_y = 0

    for i, length in enumerate(a):
        if i % 2 == 0:  # rising segment
            for _ in range(length):
                y += 1
                cells[(x, y)] = '/'
                min_y = min(min_y, y)
                max_y = max(max_y, y)
                x += 1
        else:  # falling segment
            for _ in range(length):
                cells[(x, y)] = '\\'
                min_y = min(min_y, y)
                max_y = max(max_y, y)
                x += 1
                y -= 1

    width = x
    height = max_y - min_y + 1

    grid = [[' '] * width for _ in range(height)]

    for (cx, cy), ch in cells.items():
        row = max_y - cy
        grid[row][cx] = ch

    sys.stdout.write('\n'.join(''.join(row) for row in grid))

if __name__ == "__main__":
    solve()
```シミュレーションは幾何学的定義に直接に従います。 変数`x`現在の列を追跡しますが、`y`現在の垂直レベルを追跡します。 

配置ルールは、`/`そして`\`は若干異なります。 上向きのステップ中、スラッシュは移動後に到達したより高いレベルに属します。 下降ステップ中、バックスラッシュは下降前の現在のレベルに属します。 これら 2 つの規則を混同すると、誤った答えが生じる最も一般的な原因となります。 

辞書には占有セルのみが保存されます。 最大 1000 個のセルが描画されるため、メモリ使用量はわずかです。 

出力グリッドを構築するとき、行インデックスは下方向に増加し、幾何学的な y 座標は上方向に増加します。 変換```
row = max_y - cy
```必要な垂直反転を実行します。

import io

    y = 0

    min_y = 0
    max_y = 0

                y += 1
                cells[(x, y)] = '/'
                min_y = min(min_y, y)
                max_y = max(max_y, y)
                x += 1
        else:
            for _ in range(length):
                cells[(x, y)] = '\\'
                min_y = min(min_y, y)
                max_y = max(max_y, y)
                x += 1
                y -= 1

    width = x
    height = max_y - min_y + 1

    grid = [[' '] * width for _ in range(height)]

    for (cx, cy), ch in cells.items():

        grid[row][cx] = ch

    return '\n'.join(''.join(row) for row in grid)

# minimum valid input
assert run("2\n1 1\n") == "/\\"

# symmetric mountain
assert run("2\n2 2\n") == " /\\\n/  \\\\"

# returns to origin repeatedly
assert run("4\n1 1 1 1\n") == "/\\/\\"

# deeper descent below start level
assert run("2\n1 3\n") == "/\\\n  \\\n   \\\\"

# all equal lengths
assert len(run("4\n2 2 2 2\n").splitlines()) > 0
