 ## 解決策
 # 問題の理解

 地図にはチョコレートの沼が長方形の格子として描かれています。 各セルはソリッド クッキー ランド (`S`) または液体チョコレート (`L`）。 セルはその 4 つの側面を介してのみ接続するため、斜めの接触では領域が結合されません。 

クッキーアイランドは、つながったグループです。`S`チョコレートで完全に囲まれており、マップの外側の境界線に触れていないセル。 チョコレート レイクはその逆です。接続されたグループです。`L`クッキーランドに囲まれたセル。 課題は、そのような島や湖がいくつ存在するかを数えることです。 

制約から得られる重要な点は、グリッドには最大約 100 万個のセルを含めることができるということです。 すべての領域のグリッド全体を繰り返し検索するアプローチは、コストがかかりすぎます。 各セルは一定の回数だけ処理できるため、グラフ走査を伴う線形スキャンは意図した複雑さになります。 

境界条件により問題が単純化されます。 マップの外側はクッキーランドであることが保証されているため、すべてのチョコレートのコンポーネントは自動的に囲まれ、湖になります。 Cookie コンポーネントの場合、境界線に接続されているコンポーネントのみがアイランドではありません。 他のすべての Cookie コンポーネントはアイランドです。 

一部の特殊なケースは誤って処理されやすいものです。 クッキーランドのみのマップには外側のコンポーネントしかないため、島や湖はありません。 

入力例:```
3 3
SSS
SSS
SSS
```正しい出力は次のとおりです。```
0 0
```すべてを考慮した不注意な解決策`S`コンポーネントをアイランドとして使用すると、グリッド全体が誤ってカウントされてしまいます。 

内島のない単一の湖は、営巣が常に発生するという前提の解決策を打ち破る可能性があるもう 1 つのケースです。 

入力例:```
3 3
SSS
SLS
SSS
```正しい出力は次のとおりです。```
0 1
```チョコレートの部分はクッキーランドに囲まれているので、中に島はありませんが湖です。 

3 番目の注意が必要なケースは、複数層のネストです。 

入力例:```
5 5
SSSSS
SLLLS
SLSLS
SLLLS
SSSSS
```正しい出力は次のとおりです。```
1 4
```内部領域は個別にカウントする必要があります。 最も外側の境界だけを調べるソリューションでは、より小さな湖が見落とされてしまいます。 

## アプローチ

 直接的なアプローチは、すべての未訪問のセルをフラッドフィルし、結果として生じる接続コンポーネントを分類することです。 各コンポーネントについて、その文字タイプと境界線に触れているかどうかを記録できます。 各セルの周囲を繰り返し検索したり、考えられる領域ごとに個別の走査を実行しようとすると、同じセルが何度も処理される可能性があり、100 万個のセルを含むグリッド上で不必要な作業が発生する可能性があります。 

有益な観察は、接続されたコンポーネントがすでにグリッドを分割していることです。 すべてのセルは 1 つのコンポーネントにのみ属しており、答えはコンポーネントの性質と境界線に触れているかどうかによってのみ決まります。 グリッド全体にわたる単一の BFS または DFS で十分です。 

塗りつぶしが完了すると、`L`チョコレートが境界線に到達することはないため、コンポーネントは常に湖になります。 アン`S`コンポーネントが境界線に触れていない場合にのみ島になります。 これにより、複雑な包含関係の追跡から、単純に接続されたコンポーネントの分類に問題が軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((NM)^2) | O(NM) | 遅すぎる |
 | 塗りつぶしコンポーネント | O(NM) | O(NM) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グリッド内のすべてのセルを走査します。 未訪問のセルが見つかったら、そのセルから BFS を開始して、接続されているコンポーネント全体を検出します。 答えは個々のセルではなく領域に依存するため、コンポーネントは全体として処理する必要があります。 
2. BFS 中に、コンポーネントの文字タイプを保存し、コンポーネント内のセルが境界上にあるかどうかを確認します。 境界線に到達することは、外側の Cookie 領域を実際の島から分離する唯一のプロパティです。 
3. BFS が完了したら、コンポーネントを分類します。 含まれている場合`L`、湖の数を増やします。 含まれている場合`S`国境に触れていない場合は、島の数を増やします。 
4. すべてのセルを訪問した後、島の数と湖の数を出力します。 

なぜ効果があるのか:

 BFS は、グリッドの接続されたすべての領域を 1 回だけ訪問します。 境界線にはクッキー セルのみが含まれることが保証されているため、チョコレート領域は境界線に触れることができません。したがって、すべてのチョコレート コンポーネントは囲まれており、レイクでなければなりません。 境界線に接するクッキー領域は外側の土地であり、島になることはできませんが、他のすべてのクッキー コンポーネントはチョコレートで囲まれており、島の定義を満たしています。 考えられるすべての領域が 1 回だけ分類されるため、最終的なカウントは正確です。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    visited = [[False] * m for _ in range(n)]
    islands = 0
    lakes = 0

    directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

    for i in range(n):
        for j in range(m):
            if not visited[i][j]:
                visited[i][j] = True
                kind = grid[i][j]
                touches_border = False
                q = deque([(i, j)])

                while q:
                    x, y = q.popleft()

                    if x == 0 or x == n - 1 or y == 0 or y == m - 1:
                        touches_border = True

                    for dx, dy in directions:
                        nx, ny = x + dx, y + dy
                        if 0 <= nx < n and 0 <= ny < m:
                            if not visited[nx][ny] and grid[nx][ny] == kind:
                                visited[nx][ny] = True
                                q.append((nx, ny))

                if kind == 'L':
                    lakes += 1
                elif not touches_border:
                    islands += 1

    print(islands, lakes)

if __name__ == "__main__":
    solve()
```外側のループは、すべてのセルがフラッド フィルの開始点になるのは 1 回だけであることを保証します。 の`visited`配列は、コンポーネントがすでに分類された後にセルを再訪問することを防ぎます。 

BFS キューには、現在のコンポーネントに属するセルのみが含まれます。 の`kind`変数はトラバースの開始時に固定されるため、検索が陸からチョコレートへ、またはその逆へ進むことはありません。 

境界チェックはキューからセルを削除しながら実行されます。 最終的な分類ではコンポーネントに境界セルがあるかどうかだけを知る必要があるため、単一のブール値を覚えておくだけで十分です。 コンポーネントの完全な形状を保存する必要はありません。 

カウントは最大でもセルの数であり、最大キュー サイズもグリッド サイズによって制限されるため、ここでは Python 整数は問題になりません。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(NM) | すべてのセルは、BFS キューに 1 回出入りします。 |
 | スペース | O(NM) | 訪問先アレイと BFS キューには、それぞれ線形数のセルを含めることができます。 |

 最大グリッド サイズにより、線形処理が必要になります。 このソリューションはセルごとに一定の作業のみを実行するため、必要な制限内に快適に収まります。

    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    visited = [[False] * m for _ in range(n)]
    islands = 0
    lakes = 0
    directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

    for i in range(n):
        for j in range(m):
            if not visited[i][j]:
                visited[i][j] = True
                kind = grid[i][j]
                border = False
                q = deque([(i, j)])

                while q:
                    x, y = q.popleft()
                    if x == 0 or y == 0 or x == n - 1 or y == m - 1:
                        border = True

                    for dx, dy in directions:
                        nx, ny = x + dx, y + dy
                        if 0 <= nx < n and 0 <= ny < m:

                                q.append((nx, ny))

                if kind == "L":
                    lakes += 1
                elif not border:
                    islands += 1

    sys.stdin = old_stdin
    return f"{islands} {lakes}\n"
