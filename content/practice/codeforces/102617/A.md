 ## 解決策
 ## 問題の理解

 この問題は、ゲームにおける 1 対 1 の試合をモデル化しています。 クロエには現在のレーティングがあり、指定されたレーティングを持つ別のプレイヤーと対戦します。 勝者は敗者のレーティングの 10 パーセントを獲得ポイントとして受け取りますが、敗者は自分のレーティングの 10 パーセントを失います。 評価と試合結果の両方を考慮して、試合後のクロエの評価を計算する必要があります。 

入力には、クロエの現在のレーティング、対戦相手の現在のレーティング、およびクロエが勝つか負けるかを説明する文字が含まれます。 出力は、評価の変更を適用した後のクロエの新しい評価です。 

評価は次のように大きくできます。$10^9$。 算術演算の数が少ないため、重要なのは数値の大きさだけです。 シミュレーション、検索、または繰り返し計算を使用するアプローチでは、不必要な作業が追加されます。 入力サイズには処理すべき大きなシーケンスが含まれていないため、定数時間のソリューションが必要です。 

よくある間違いは、常にクロエの評価の 10 パーセントを減算することです。 それが正しいのは、クロエが負けた場合のみです。 クロエが勝った場合、獲得金額は代わりに対戦相手のレーティングから得られます。 

たとえば、入力が次の場合:```
1000
1200
w
```正しい出力は次のとおりです。```
1120
```不用意な解決策は計算に値する可能性があります$1000 + 100$, クロエ自身の評価をポイント源として使用しているためです。 正しいゲインは対戦相手のレーティングの 10%、つまり 120 です。 

もう 1 つのエッジケースは、はるかに弱い相手に負ける場合です。 のために：```
100
900
l
```出力は次のとおりです。```
90
```負けは対戦相手のレーティングではなく、クロエ自身のレーティングに基づいています。 対戦相手のレーティングを使用すると、10 ポイントではなく、誤って 90 ポイントが減点されてしまいます。 

## アプローチ

 直接的な強引なアプローチは、評価システム全体をモデル化しようとするか、最終値に到達するまで起こり得る評価の変更を探索することです。 一致には状態遷移が 1 つだけあるため、これは不要です。 唯一可能なアクションは、対戦相手のレーティングの 10 パーセントを追加するか、クロエの現在のレーティングの 10 パーセントを削除することです。 数回以上の算術演算を行うアプローチは、与えられた問題よりも難しい問題を解決することになります。 

重要な観察は、評価更新ルールが決定的であるということです。 勝者の利益と敗者の損失はすでに数学的に記述されているため、答えを直接計算できます。 問題の構造には、データ構造、反復、シミュレーションは必要ありません。 試合の結果に基づいて正しい公式を選択するだけで済みます。 

評価できる一致結果が 1 つしかないため、総当たり法は機能しますが、直接式と比較すると不要なオーバーヘッドになります。 レーティングの変化は 2 つの現在のレーティングにのみ依存し、勝敗の特徴によって問題全体が定数時間に帰着するという観察により、問題全体が定数時間に帰着します。

 ## アルゴリズムのチュートリアル

 1.クロエの評価、相手の評価、結果キャラを読みます。 これら 3 つの値には、次の評価を決定するために必要なすべての情報が含まれています。 
2. クロエが勝った場合、対戦相手のレーティングの 10 パーセントを計算し、それをクロエのレーティングに追加します。 クロエが受け取るポイントは相手から奪われるので、相手の評価が上昇値となります。 
3. クロエが負けた場合、クロエの現在の評価の 10 パーセントを計算し、彼女の評価から差し引きます。 負けたプレイヤーは自分のレーティングの 10% を放棄します。 
4. 結果の評価を印刷します。 

なぜ効果があるのか:

 アルゴリズムの不変条件は、問題で説明されている一致ルールを正確に適用した後、保存される評価値が常にクロエの評価になるということです。 勝利すると相手の貢献度によって彼女の評価が変わり、負けると自分の貢献度によって彼女の評価が変わります。 可能な遷移はこれら 2 つだけであるため、アルゴリズムはすべての有効なケースをカバーし、必要な更新を正確に適用します。 

## Python ソリューション```python
import sys

input = sys.stdin.readline

def solve():
    c = int(input())
    o = int(input())
    result = input().strip()

    if result == "w":
        c += o // 10
    else:
        c -= c // 10

    print(c)

if __name__ == "__main__":
    solve()
```最初の 2 行は、2 つの評価を整数として読み取ります。 Python の整数は可能なものを処理します$10^9$オーバーフローを心配することなく、値を安全に取得できます。 

条件は一致結果をチェックします。 勝利の場合、追加額は対戦相手のレーティングから計算されます。 すべての評価は 10 で割り切れるため、整数で 10 で割ると正確な獲得ポイント数が得られます。 損失の場合、減算はクロエの現在の評価に基づいて行われます。 

負けた場合には、操作の順序が重要になります。 削除量はアップデート前のクロエの評価から計算する必要があります。 式を次のように書くと、`c -= c // 10`右側は代入の前に評価されるため、その動作が保持されます。

## テストケース```python
import sys
import io

def solve(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    c = int(sys.stdin.readline())
    o = int(sys.stdin.readline())
    result = sys.stdin.readline().strip()

    if result == "w":
        c += o // 10
    else:
        c -= c // 10

    sys.stdin = old_stdin
    return str(c)
