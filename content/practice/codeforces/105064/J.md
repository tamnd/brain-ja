 ## 解決策
 ## 問題の理解

 連続する要素を直線のセグメントで接続するときに、それらのセグメントが内部で交差しないように、1 から n までの数値の順列を何回配置できるかを数えています。 各セグメントは p[i] と p[i+1] を接続するため、順列はすべての数値を 1 回だけ訪問するパスを定義します。 

キー制約は幾何学的ですが、純粋に組み合わせ的に読み取ることができます。 2 つのセグメント (a、b) および (c、d) は、各セグメント内でのソート後にエンドポイントが a < c < b < d を満たすインターリーブ パターンを形成することを禁止されています。 このパターンは、まさに 1 から n のラベルが付いた頂点を持つ直線上に描かれたときに交差を作成するものです。 

また、順列は x で始まり y で終わる必要があるため、パスの終点は固定されるとも言われています。 

入力サイズは大きく、すべてのテスト ケースの n の合計は最大 10^6 で、最大 2 × 10^5 のクエリが存在する可能性があります。 これにより、各テスト ケースを線形時間で個別に処理するアプローチは即座に除外されます。 テスト ケースごとの単純な O(n) は、最悪のケースでは 10^11 の演算に達しますが、これは制限をはるかに超えています。 したがって、ソリューションでは、各クエリを事前計算するか、O(1) または O(log n) に削減する必要があります。 

x と y が隣接しているか、1 と n のような極端な値である場合、微妙なエッジ ケースが発生します。 たとえば、n = 3、x = 1、y = 3 の場合、有効な順列は [1, 2, 3] のみですが、エンドポイントが交換または反転されると、構造制約は非対称に動作します。 エンドポイントの固定を無視する単純な解釈では、パスをパスではなくサイクルとして扱うため、多くの場合、カウントが過剰になります。 

もう 1 つの落とし穴は、交差しないパスがカタロニア語のような単純な組み合わせカウントに対応すると仮定することです。 その直感は近いですが、頂点にラベルが付けられ、端点が固定されており、対称性が崩れているため失敗します。 

## アプローチ

 ブルート フォース ソリューションでは、x で始まり y で終わるすべての順列が生成され、隣接するすべてのセグメントの交差条件がチェックされます。 順列をチェックするにはエッジのすべてのペアを比較する必要があるため、順列あたり O(n^2) になります。 んがあるから！ 順列の場合、n が 10 程度であっても、これは完全に不可能です。 

重要な観察は、この条件がまさに直線上に配置された点に対する「非交差ハミルトニアン パス」制約であるということです。 交差は、隣接するエッジによって形成される間隔の端点の順序に逆転が存在する場合にのみ発生します。 これは、各ステップが現在の間隔を既に構築されたセグメントの左または右の境界に拡張するシーケンスを構築することと構造的に同等です。 

端点 x と y を固定すると、有効な順列は、既に配置された要素に関して常に単調な連続区間を拡張する方法に対応します。 どのステップでも、次の要素は、現在到達可能な間隔内の未使用の最小番号または未使用の最大番号のいずれかである必要があります。 インテリアを選択すると、事前に確立されたエッジとの交差パターンが即座に作成されます。 

これにより、問題は古典的な間隔増加 DP に帰着します。 すでに配置されているすべての値を常に含む現在のセグメント [L, R] を維持することを考えます。 次の値は、このセグメントを外側に拡張する必要があります。 有効な順列の数は、左または右に展開する回数にのみ依存し、固定エンドポイントによって最初と最後の展開が制限されます。 

最終的な構造は単純な組み合わせカウントになります。x < y か x > y によって決定される制約を使用して、n−2 ステップの間で左と右の拡張の位置を効果的に選択しています。 答えは、端点間の距離のみに応じて二項係数に帰着します。

より正確には、x と y を固定すると、この構築により正確に |x − y| が強制されます。 有効なインターリーブは、どの要素を左展開側に表示するかを選択することに対応します。 これにより、次の組み合わせ項が得られます。 

C(n−2, |x−y|−1)

 方向依存の有効性により、エンドポイントが方向と一致することが保証されます。 

したがって、階乗と逆階乗を事前計算し、O(1) で各クエリに答えます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n! · n²) | O(n) | 遅すぎる |
 | 最適 | O(n + q) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのテスト ケースにわたって最大 n まで階乗および逆階乗を事前計算します。 これは、各クエリが二項係数に帰着するため必要です。 
2. 各クエリについて、n、x、y を読み取ります。 x と y を、非交差ハミルトニアン パスの固定端点として解釈します。 
3. d = |x − y| を計算します。 この値は、エンドポイントの順序構造の「間」に配置する必要がある要素の数を決定します。 
4. d が 0 の場合、問題ステートメントにより x ≠ y であるため、構成は無効であるため、このケースはスキップします。 
5. 有効な順列の数は C(n − 2, d − 1) として計算されます。 これは、n − 2 個の内部要素のどれを x と y の間の「小さい方向から大きい方向への拡張」に割り当てるかを選択することから生まれます。 
6. 10^9 + 7 を法とした結果を返します。 

### なぜ効果があるのか

 構築プロセスは、すでに配置された値の連続した間隔を常に維持しているとみなすことができます。 有効な次のステップは、この区間の両端のいずれかに接続する必要があります。そうでない場合は、以前に形成された区間境界と交差するエッジが作成されます。 この制限により、すべての置換が左展開と右展開のシーケンスに強制されます。 エンドポイント x と y によって、各方向に何回の展開を行う必要があるかが決まり、これらの展開の順序の選択によって順列が一意に決まります。 その全単射は、カウントの問題を、n-2 ステップの中から 1 つのタイプの展開の位置を選択することに還元します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

MAXN = 10**6 + 5
fact = [1] * MAXN
invfact = [1] * MAXN

for i in range(1, MAXN):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAXN - 1] = pow(fact[MAXN - 1], MOD - 2, MOD)
for i in range(MAXN - 2, -1, -1):
    invfact[i] = invfact[i + 1] * (i + 1) % MOD

def ncr(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

t = int(input())
out = []

for _ in range(t):
    n, x, y = map(int, input().split())
    d = abs(x - y)
    out.append(str(ncr(n - 2, d - 1)))

sys.stdout.write("\n".join(out))
```各クエリに一定時間内に応答できるように、階乗テーブルは 1 回事前計算されます。 この結合関数は、フェルマー逆変換を使用して素数を法として除算します。 

唯一の微妙な実装の詳細は、小さな n 値を正しく処理することです。 n = 2 の場合、順列は常に 1 つだけ存在し、d = 1 であるため、式 C(0, 0) は正しく 1 を返します。 

## 実用的な例

 ### 例 1

 入力:

 n = 3、x = 1、y = 3

 ここで、n − 2 = 1 および d = 2 なので、C(1, 1) を計算します。 

| ステップ | n | × | y | d | n-2 | d-1 | C(n-2, d-1) |
 | --- | --- | --- | --- | --- | --- | --- | --- |
 | 初期化 | 3 | 1 | 3 | 2 | 1 | 1 | 1 |

 有効な順列は 1 つだけです: [1、2、3]。 他の順序では、エッジの交差が直ちに強制されます。 

### 例 2

 入力:

 n = 5、x = 1、y = 4

 ここで、n − 2 = 3 および d = 3 なので、C(3, 2) = 3 を計算します。 

| ステップ | n | × | y | d | n-2 | d-1 | C(n-2, d-1) |
 | --- | --- | --- | --- | --- | --- | --- | --- |
 | 初期化 | 5 | 1 | 4 | 3 | 3 | 2 | 3 |

 3 つの有効な順列は、内部拡張選択肢の異なる配置に対応し、それぞれが交差を引き起こすことなく、左側と右側のアタッチメントの異なる順序をエンコードします。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(最大 n + t) | 階乗事前計算にクエリごとに O(1) を加えたもの |
 | スペース | O(最大n) | 階乗配列と逆階乗配列 |

 この制約では合計 n が最大 10^6 まで許容されるため、単一の事前計算パスと定数時間クエリは時間とメモリの制限内に快適に収まります。 

## テストケース```python
import sys, io

MOD = 10**9 + 7

def solve(inp: str) -> str:
    data = list(map(int, inp.split()))
    t = data[0]
    idx = 1
    res = []
    for _ in range(t):
        n, x, y = data[idx], data[idx+1], data[idx+2]
        idx += 3
        # simplified recomputation for testing (small n only)
        # brute validate for small n
        import itertools
        cnt = 0
        for p in itertools.permutations(range(1, n+1)):
            if p[0] != x or p[-1] != y:
                continue
            ok = True
            edges = []
            for i in range(n-1):
                a, b = p[i], p[i+1]
                edges.append((min(a,b), max(a,b)))
            for i in range(len(edges)):
                for j in range(i+1, len(edges)):
                    l1, r1 = edges[i]
                    l2, r2 = edges[j]
                    if l1 < l2 < r1 < r2:
                        ok = False
                        break
                if not ok:
                    break
            if ok:
                cnt += 1
        res.append(str(cnt))
    return "\n".join(res)

# provided samples
assert solve("3\n3 1 2\n4 3 4\n5 1 4") == "1\n1\n3"

# custom cases
assert solve("1\n2 1 2") == "1", "min size"
assert solve("1\n3 2 1") == "1", "reverse endpoints"
assert solve("1\n4 1 3") == "2", "small non-trivial"
assert solve("1\n5 2 5") == "3", "boundary mix"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 2 1 2 | 1 | 最小サイズの正確性 |
 | 3 2 1 | 1 | エンドポイントの対称性を反転 |
 | 4 1 3 | 2 | 小さくて自明ではない構造 |
 | 5 2 5 | 3 | 一般的な組み合わせ動作 |

 ## 特殊なケース

 n = 2 の場合、区間には内部的な選択肢がなく、式は C(0, 0) になります。 アルゴリズムは 1 を返し、可能な 1 つの置換に一致します。 

x と y が隣接する場合、d = 1 となり、式は C(n−2, 0) = 1 になります。これは、端点が分岐選択肢のない完全に単調な構築を強制するという事実に対応します。 

x と y が大きく離れている場合、たとえば x = 1 と y = n では、d = n−1 および C(n−2, n−2) = 1 になります。これは、すべてのステップが強制され、順序付けの自由がなくなった完全に拡張された構成をキャプチャします。 

x と y が範囲の中央にある場合、二項係数は最大化され、交差パターンを作成せずに左右の展開をインターリーブする最も多くの方法を反映します。
