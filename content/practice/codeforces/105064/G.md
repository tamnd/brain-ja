 ## 解決策
 ## 問題の理解

 数直線上に配置された兵士のセットが与えられます。 各兵士は固定された位置と特定の力を持つ武器を持っています。 ある位置にモンスターが出現すると、兵士全員がその位置に向かって発砲します。 弾丸は、兵士からモンスターまでの距離を移動した後でも十分な威力が残っている場合にのみ命中を与えることができます。 弾丸が遠くに飛ぶほど、直線的に弱くなります。 

配置されたモンスターに対して$d$シールド幅あり$s$、位置にある兵士$a_i$力を持って$p_i$距離ペナルティによってパワーがシールド要件を下回らない場合、ヒットに成功します。 この条件は不等式に単純化されます。$$|a_i - d| \le p_i - s.$$したがって、固定シールド幅の場合$s$、および任意の場所$d$、何人の兵士がまだモンスターを攻撃できるかを数えることができます。 モンスターはその位置で生き残る$d$この数が最大でも$k$。 目標は、可能な限り小さい整数を選択することです$s$モンスターが数直線上のどこに立っても、ヒット数がそれを超えることはありません。$k$。 

制約は、$O(n \log n)$または$O(n)$テストケースごとのソリューション。 まで$10^5$すべてのテスト ケースにわたる総兵士数、二次関数$n$まで必要になるため、遅すぎます。$10^{10}$最悪の場合の運用。 

いくつかの微妙な特殊なケースがすぐに現れます。 すべての兵士のパワーがゼロの場合、シールドの幅が正であればすべてのヒットを防ぐことができますが、それでも答えは負ではないはずです。 もし$k = n$、その場合、モンスターはすべての兵士によって攻撃されることが許可されるため、シールドがゼロでも十分である可能性があります。 兵士が高いパワーで同じポイントに密集している場合、オーバーラップ間隔を減らすために大きなシールドが必要になる場合があります。 

最も重要な隠れた難しさは、固定されたポジションについて質問されないことです$d$、しかし考えられる限り最悪のことについて$d$そのため、点ごとの評価ではなく、全体的な重複構造について推論する必要があります。 

## アプローチ

 この問題を直接考える方法は、シールドの幅を修正することです。$s$そして、考えられるすべてのモンスターの位置をシミュレートします。 ポジションごとに$d$、何人の兵士が満足するかを数えます$|a_i - d| \le p_i - s$。 これは、各兵士が中心となる影響の間隔を定義するため、各ポイントをカバーする間隔の数を確認することに相当します。$a_i$半径あり$p_i - s$。 ブルート フォース アプローチでは、次の範囲にあるすべての整数位置についてこのカバレッジを評価します。$1$そして$10^9$、これは明らかに実行不可能です。 

重要なポイントのチェックのみに限定したとしても、それぞれのカバレッジを再計算します。$s$まだ費用がかかる$O(n^2)$各チェックにはすべての兵士のスキャンが含まれるため、最悪の場合は危険です。 

重要な観察は、固定された$s$、各兵士は対称的な間隔を提供します。$$[a_i - (p_i - s),\ a_i + (p_i - s)].$$これ以上の点が内部に存在しないようにしたいと考えています。$k$そういった間隔。 これは古典的な「最小最大オーバーラップ」問題です。 

直す代わりに$s$重複をチェックして、視点を反転します。最小値は何かを尋ねます。$s$これらの縮小間隔の最大の重なりが最大で$k$。 として$s$増加しても間隔は均一に縮小するため、オーバーラップは減少するだけです。 この単調性により、二分探索が可能になります。$s$。 

確定候補者の場合$s$、すべての間隔を計算し、エンドポイントをソートし、スイープラインを計算して、最大の重複を計算します。$O(n \log n)$。 次に、最小のものを二分探索します$s$条件を満たしていること。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべてのポジションをシミュレート) |$O(n \cdot 10^9)$|$O(n)$| 遅すぎる |
 | チェック + 二分探索 + スイープ ライン |$O(n \log n \log P)$|$O(n)$| 承認済み |

 ここ$P$は最大電力スケールです。 

## アルゴリズムのチュートリアル

 ### 1. 各兵士を間隔が縮小していると解釈します

 固定シールドの場合$s$、各兵士の有効半径を計算します$r_i = p_i - s$。 もし$r_i < 0$、その兵士はインターバルにまったく貢献しません。 それ以外の場合はセグメントをカバーします$[a_i - r_i, a_i + r_i]$。 これにより、問題は区間の重複カウントに変換されます。 

この変換が機能する理由は、元の条件がまさに中心を中心とした半径内に点が存在する条件であるためです。 

### 2. シールドの実現可能性を定義する

 関数を定義します`check(s)`ライン上のどの点も以上のもので覆われていない場合に true を返します。$k$間隔。 これは、モンスターがどこでも生き残るという要件に直接一致します。 

単調な動作が重要です。$s$全部減るだけ$r_i$、そのため、間隔は縮小するだけで、オーバーラップは増加できません。 

### 3. 固定の最大オーバーラップを計算します。$s$評価するには`check(s)`、すべての有効な間隔を生成し、それらをイベントに変換します: 左のエンドポイントで +1、右のエンドポイントの直後に -1。 これらのイベントをソートすると、すべての座標でアクティブな間隔の数を維持するスイープが可能になります。 スイープ中の最大値が最大同時ヒット数となります。 

この最大値を次と比較します。$k$。 

### 4. 有効な最小値を二分探索する$s$実現可能性は単調なので二分探索します$s$0から$\max p_i$。 各ステップでスイープ ライン チェックが実行されます。 

### なぜ効果があるのか

 各兵士は、均一に縮小する一連の間隔を次のように定義します。$s$が増加します。 「区間の最大重なり」関数は単調非増加です。$s$、したがって、有効なセットは$s$値は整数の接尾辞です。 二分探索では、有効な最小値が正しく検出されます。 この構造では、最大カバレッジの点は間隔の終点で発生する必要があるため、スイープ ラインは最悪の場合のオーバーラップを正確にキャプチャします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def check(s, a, p, k):
    events = []
    for ai, pi in zip(a, p):
        r = pi - s
        if r < 0:
            continue
        l = ai - r
        rgt = ai + r
        events.append((l, 1))
        events.append((rgt + 1, -1))
    
    events.sort()
    
    cur = 0
    best = 0
    for x, v in events:
        cur += v
        if cur > best:
            best = cur
    
    return best <= k

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        p = list(map(int, input().split()))
        
        lo, hi = 0, max(p)
        ans = hi
        
        while lo <= hi:
            mid = (lo + hi) // 2
            if check(mid, a, p, k):
                ans = mid
                hi = mid - 1
            else:
                lo = mid + 1
        
        print(ans)

if __name__ == "__main__":
    solve()
```中心となる構造は、実現可能性チェックをラップした二分探索です。 の`check`関数は間隔イベントを構築し、スイープ ラインを実行して最大オーバーラップを計算します。 

微妙な点は、`rgt + 1`クロージングイベントに向けて。 これにより、正確な整数カバレッジ セマンティクスが保証されます。正確に正しいエンドポイントにあるポイントは依然として間隔に含まれます。 

もう 1 つの重要な詳細は、兵士をスキップすることです。$p_i - s < 0$なぜなら、彼らは有効な報道を提供できないからです。

def run(inp: str) -> str:

 ## 特殊なケース

 すべてのパワーがゼロの場合、すべての兵士は、正の値に対して空または負の半径の間隔を生成します。$s$。 スイープ ラインはイベントを受信しないため、最大オーバーラップはゼロになり、アルゴリズムは正しく受け入れます。$s = 0$。 

いつ$k = n$、すべての設定は次の場合でも有効です。$s = 0$。 チェック関数は、決して超えない最大オーバーラップを計算します。$n$, したがって、二分探索はすぐにゼロに収束します。 

兵士が全員同じ位置にいて大きな力を持っている場合、最初の重なりは次のようになります。$n$で$s = 0$。 チェック機能は、次の時点まで失敗を正しく報告します。$s$すべての半径を十分に小さくして、間隔を縮小して分割し、以下の重複を減らします。$k$。
