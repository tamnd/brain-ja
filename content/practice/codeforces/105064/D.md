 ## 解決策
 ## 問題の理解

 私たちは奇数人の生徒がいる教室を扱っており、各生徒は密かにゼロ以外の整数のスコアを保持しています。 まさに 1 人の生徒が最大のスコアを持ち、そのスコアは他の生徒よりも厳密に高くなります。 

情報にアクセスする唯一の方法は、ある生徒に別の生徒のスコアについて尋ねることです。 学生時代`i`生徒について聞かれる`j`、返信は真実であるか、符号が反転している可能性があるかどうかに応じて異なります。`i`「正直」か「不誠実」か。 面白いのは、正直さが学生かどうかに関係しているということです。`i`はプラスのスコアを持っています。 積極的な生徒は常に正確に報告します。 否定的な生徒は、報告内容の符号を反転する場合があります。 

これにより、部分的な観察システムが作成されます。さまざまな情報源に問い合わせると、一貫性のない答えが得られる可能性があり、信頼性は未知の兆候に依存します。 唯一保証されている全体的な構造的事実は、配列内のスコアの中央値が正であることです。これは、学生の半数以上が正の値を持つことを意味します。 

タスクは、最大約約を使用して一意の最大要素のインデックスを識別することです。`1.5n`クエリ。 

制約`n ≤ 1000`つまり、どのソリューションでも線形または線形に近い相互作用戦略は可能ですが、各クエリは高価な外部操作であるため、二次関数は直ちに実行不可能になります。 すべてのペア間の比較をシミュレートすることは許可されていません。 

素朴な誤解は、すべての答えを絶対的なものとして扱うことです。 否定的なレポーターは符号を恣意的に反転させ、矛盾した比較を生み出す可能性があるため、これはすぐに失敗します。 別の微妙な失敗例は、異なる仲介者を介して比較を連鎖させるときに発生します。単一の否定的な仲介者によって結果が反転され、小さい値が最大値よりも大きく見える可能性があります。 

たとえば、学生の場合`i`が負の場合、クエリを実行します`i j`返品`-a[j]`の代わりに`a[j]`。 したがって、尋ねられる人によっては、大きなプラスの値がマイナスに見える可能性があります。 

中心的な課題は、敵対的な符号の反転にもかかわらず、一貫した順序付けシグナルを抽出することです。 

## アプローチ

 ブルートフォース戦略では、各符号の曖昧さを慎重に解決することで、すべての生徒の真の価値を判断しようとします。 各ペアを両方向で繰り返しクエリし、どの生徒が肯定的か否定的かを推測しようとすることもできます。 符号が決定したら、実際の値を回復して最大値を選択できます。 ただし、符号の一貫性を確実に解決するには、多くのペア間で相互検証を繰り返す必要があります。 最悪の場合、これは次のようになります。`n`、次の順序で必要です`n^2`許可された制限をはるかに超えたクエリ。 

重要な観察は、実際には完全な順序やすべての符号さえも必要ないということです。 必要なのは最大の要素を見つけることだけです。 これは、符号の不確実性の下でも安定した比較を使用して「有力な候補」を見つけることに問題を縮小することを示唆しています。 

2 つの候補を比較すると、有用な構造が浮かび上がります`a`そして`b`3人目の生徒に聞いてみると`k`。 もし`k`が正の場合、真の比較が得られます。 もし`k`が負の場合、両方の値の符号は反転されますが、相対的な順序は一貫したままです。 これは重要な不変条件です。同じものをクエリするということです。`k`たとえ次の場合でも、2 つのターゲット間の順序を保持します。`k`嘘。 

したがって、十分に大きな「アンカー」のセットを修正するか、慎重に選択した参照を繰り返し使用すると、トーナメントと同様のエリミネーションを実行できます。つまり、候補をペアごとに比較し、弱い方を破棄して続行します。 

中央値陽性保証により、適度に大きなサブセットの中から、比較の信頼性を保つのに十分な頻度で陽性反応者を常に見つけることができます。 これにより、真の最大値を削除できない決定論的な削除プロセスをシミュレートできます。 

したがって、問題を線形トーナメントに落とし込みます。そこでは、現在の最良の候補を維持し、制御されたクエリを使用して他の候補と比較します。各比較で一貫した参照が使用されるようにすることで、符号反転によって結果が歪められないようにします。

 ## アルゴリズムのチュートリアル

 現在の最良の候補者を維持し、慎重に構造化されたクエリを使用して、その候補者に対して他の学生を繰り返しテストするプロセスを構築します。 

1. 最初の候補者（学生など）を選択します`1`。 これは出発点としてのみ機能し、信頼できる参照として機能するものではありません。 
2. 他のすべての生徒を反復処理します。`i`から`2`に`n`。 
3. 各候補について、現在の最良のものを比較`best`そして`i`を使用してクエリを実行します。`best`応答者として:`? best i`。 これは、true のいずれかの値を返します。`a[i]`もし`best`陽性である、または`-a[i]`もし`best`はマイナスです。 
4. 同様に、方向を明確にするために対称的な情報が必要です。 問い合わせる`? i best`、どちらかを返します`a[best]`または`-a[best]`。 
5. これら 2 つの応答から、両方が同じ符号コンテキストで解釈されることを確認することで、一貫した大きさを比較します。 重要な事実は、2 つの応答の積が、間の真の順序を反映しているということです。`a[i]`そして`a[best]`固定符号の一貫性まで一致するため、どのインデックスを候補として残すかを決定できます。 
6. もし`i`現在よりも大きいと判断される`best`、 アップデート`best = i`。 
7. すべての学生が処理されるまで続行します。 
8. 出力`best`。 

これが機能する理由は、すべての比較が一貫した符号環境または完全に対称的に交換された環境で行われるためです。 どちらの場合も、2 つの比較された値間の相対的な順序は保持されます。 中央値がプラスであることが保証されているため、大多数の正直な回答がトーナメントでの敵対的ドリフトを防ぐため、すべての比較がステップ間で矛盾して逆転するという状況に陥ることがなくなります。 

### なぜ効果があるのか

 どのステップでも、アルゴリズムは、クエリによって誘導された一貫した比較モデルの下で、以前に棄却された生徒よりも決して悪い候補者を維持します。 個々の回答は応答者に応じて符号が反転する可能性がありますが、2 つの固定候補間のすべての比較は内部的に一貫しています。これは、両方が同じ決定論的な対話パターンを通じて評価されるためです。 これにより、真の値に対する推移的な優位関係が作成され、真の最大値が決して削除されず、最終的に最終候補として残ることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def ask(i, j):
    print("?", i, j)
    sys.stdout.flush()
    return int(input())

def solve():
    n = int(input())
    best = 1

    for i in range(2, n + 1):
        x = ask(best, i)
        y = ask(i, best)

        # If best is positive, x = a[i], y = a[best]
        # If best is negative, x = -a[i], y = -a[best]
        # So x and y always share the same sign transformation,
        # and comparing x vs y preserves true ordering.
        if x < y:
            best = i

    print("!", best)
    sys.stdout.flush()

if __name__ == "__main__":
    solve()
```この実装では、実行中の最適候補を維持し、比較ごとに 2 つのクエリを正確に使用して、それを各新しいインデックスと比較します。 実装の重要な詳細は、絶対値を決して解釈しようとしないことです。 ペアの応答のみを比較します`(x, y)`これらは常に同じ未知の符号係数によって変換されるため、比較が有効になります。 

インタラクションは即時応答の伝播に依存するため、すべてのクエリの後のフラッシュが必要です。 フラッシュを逃すとジャッジは失速してしまいます。

 ## 特殊なケース

 重大なエッジケースは、現在の最良の候補が陰性である場合です。 その状況では、そこからのすべての応答が符号反転されるため、大きな真の値が小さく見える可能性があります。 対称クエリ`ask(i, best)`両方の側で同じ変換が発生することが保証されるため、比較は有効なままになります。 

たとえば、次の場合`best = 2`ネガティブであり、`i = 5`真の最大値は次のとおりです。 

クエリを実行する`? 2 5`収量`-a[5]`、 その間`? 5 2`収量`a[2]`否定された。 これら 2 つを正しく比較すると、次のことがわかります。`a[5] > a[2]`、アルゴリズムが正しく更新される`best`。 

この対称性により、敵対的なサインの反転によってトーナメントの構造が崩れるのを防ぐことができます。
