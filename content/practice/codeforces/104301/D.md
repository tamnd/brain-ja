 ## 解決策
 ## 問題の理解

 複数の独立したテスト ケースが与えられます。 各テスト ケースには、整数の配列としきい値があります。$k$。 そのセット内の最大要素と最小要素の差が最大で 1 セットである場合、そのセットを「良好」と呼びます。$k$。 同様に、セット内のすべてのペアには最大でも差がなければなりません$k$、これは単一の条件に帰着します。$\max(S) - \min(S) \le k$。 

各テスト ケースについて、2 つのことを考慮する必要があります。 まず、条件を満たす集合として要素を選択できる部分配列の数です。 2 番目は、同じ条件を満たすサブシーケンス (必ずしも連続しているとは限りません) の数です。 

両者の主な違いは構造です。 部分配列は順序と連続性を維持するため、間隔を扱います。 サブシーケンスは位置を無視し、インデックスの選択のみを考慮します。 

制約は大きいです: 合計$n$テストケース全体で最大$2 \cdot 10^5$、値は最大です$10^{18}$規模的には。 これにより、直ちにあらゆることが排除されます$O(n^2)$テストケースごとのアプローチ。 平$O(n \log n)$テスト ケースごとに慎重に線形にする必要があります。 

すべてのサブ配列またはすべてのサブシーケンスをチェックする単純な解決策は不可能です。 部分列だけの数は$2^n$, したがって、直接列挙はアウトです。 

微妙なエッジケースが現れるのは、$k = 0$。 この場合、有効なセットは同一の値のみで構成されている必要があります。 範囲拡張に依存するアルゴリズムは、等価関係のみが許可されるため、重複を正しく処理する必要があります。 

もう 1 つのエッジ ケースは、配列が厳密に増加または減少している場合です。 ここでは、すべてのウィンドウがスライディングしきい値によって制約されており、各インデックスから単純に拡張すると、繰り返される作業が何度も再計算されます。 

## アプローチ

 サブ配列とサブシーケンスは別々に扱いますが、どちらも同じ構造的な考え方、つまり範囲制約を使用した妥当性のソート可能性に依存しています。 

サブ配列の場合は、総当たり法を検討してください。 開始インデックスごとに$i$、延長します$j$現在のセグメントの最小値と最大値を転送および追跡します。 それぞれの延長にかかる費用$O(1)$注意深く維持すれば、こうなります$O(n^2)$全体。 配列がほとんどのペアに条件が当てはまるような最悪のケースでは、これは約$n(n+1)/2$チェックは遅すぎます$2 \cdot 10^5$。 

重要な観察は、固定された左端点の場合、一連の有効な右端点が連続した区間を形成するということです。 最大値と最小値の差を超えると$k$、右ポインタをさらに大きくしても有効性を復元できません。 この単調性により、2 ポインターのスライディング ウィンドウが可能になります。 

サブシーケンスの場合、順序は重要ではないので、最初に配列を並べ替えます。 ソート後、有効なサブシーケンスはすべて、選択した最小要素と最大要素の差が最大以下のウィンドウ内に完全に収まる必要があります。$k$。 これにより、問題はソートされたスライディング ウィンドウ内のサブセットをカウントすることに変わります。 

並べ替えたら、右のエンドポイントごとに 2 ポインター ウィンドウを再度使用します。$r$、最小のものを見つけます$l$そのような$a[r] - a[l] \le k$。 次に、すべてのサブセットが完全に内部で形成されます$[l, r]$有効である、貢献している$2^{(r-l)}$で終わるサブシーケンス$r$。 

主な違いは、サブ配列は元の順序に依存するのに対し、サブシーケンスはソートされた値の組み合わせ論に帰着することです。

 | 最適 |$O(n \log n)$全体 |$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

### サブアレイ

 1. 2 つのポインタを初期化する$l = 0$そしてそれを繰り返す$r$左から右へ、現在のウィンドウを維持します。 
2.両端キューを使用して、現在のウィンドウの最小値と最大値を効率的に維持します。 
3. それぞれについて$r$、 入れる$a[r]$両方の構造にインポートし、現在の最小値と最大値を更新します。 
4. 窓口違反中$\max - \min > k$、 動く$l$古い要素を転送して削除します。 
5.固定後$l$、で終わるすべてのサブ配列$r$そしてどこからでも始めてください$[l, r]$は有効なので追加します$(r - l + 1)$答えに。 

これが機能する理由は、ウィンドウが無効になると、それをさらに右に拡張しても範囲を減らすことができないためです。 左にシフトするだけで有効性を復元できます。 

### サブシーケンス

 1. 配列をソートします。 
2. 最大 2 の累乗を事前計算します。$n$サブセットを繰り返しカウントするためです。 
3. ソートされた配列に対して 2 ポインター ウィンドウを使用します。 
4. 各右端点について$r$、 前進$l$それまで$a[r] - a[l] \le k$。 
5. すべてのサブセットは次の要素から形成されます。$[l, r]$位置の最大要素を選択するための有効な選択肢です$r$, そこで追加します$2^{(r-l)}$答えに。 

The key idea is that fixing the largest element in a valid subsequence determines that all other elements must lie in a bounded interval below it.

 ### なぜ効果があるのか

 部分配列の場合、不変条件は、現在のウィンドウが$[l, r]$常に条件を満たしており、$l$固定の有効性を維持する最小のインデックスです。$r$。 ウィンドウが小さいと制約に違反し、右側のエンドポイントが大きいと単調性が崩れる可能性があります。$l$調整されています。 

サブシーケンスの場合、ソートにより、有効なセットが値空間内の間隔であることが保証されます。 2 ポインター ウィンドウは、カウントされたすべてのサブセットが最大値から最小値を引いたものであることを保証します。$k$、各サブセットは、その最大の要素が正しいエンドポイントとして選択されたときに 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    max_n = 200000

    # precompute powers once
    pow2 = [1] * (max_n + 1)
    for i in range(1, max_n + 1):
        pow2[i] = (pow2[i - 1] * 2) % MOD

    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))

        # -------- subarrays --------
        from collections import deque

        min_dq = deque()
        max_dq = deque()

        l = 0
        subarray_ans = 0

        for r in range(n):
            while min_dq and a[min_dq[-1]] >= a[r]:
                min_dq.pop()
            min_dq.append(r)

            while max_dq and a[max_dq[-1]] <= a[r]:
                max_dq.pop()
            max_dq.append(r)

            while a[max_dq[0]] - a[min_dq[0]] > k:
                if min_dq[0] == l:
                    min_dq.popleft()
                if max_dq[0] == l:
                    max_dq.popleft()
                l += 1

            subarray_ans += (r - l + 1)

        # -------- subsequences --------
        b = sorted(a)
        l = 0
        subseq_ans = 0

        for r in range(n):
            while b[r] - b[l] > k:
                l += 1
            subseq_ans = (subseq_ans + pow2[r - l]) % MOD

        print(subarray_ans, subseq_ans % MOD)

if __name__ == "__main__":
    solve()
```サブ配列部分は、2 つの単調デックが最小インデックスと最大インデックスを追跡するスライディング ウィンドウを維持します。 条件はこれらの構造のエンドポイントでのみチェックされ、ウィンドウ内での再計算が回避されます。 

サブシーケンス部分は、並べ替えに依存して、組み合わせ制約を範囲制約に変換します。 指数$r - l$現在の最大要素以外にオプションで含めることができる要素の数をカウントします。 

よくある間違いは、サブシーケンスが最大要素を固定することによってカウントされることを忘れていることです。これにより、複数の位置から同じサブセットが二重にカウントされるのを防ぐことができます。 

もう 1 つの微妙な問題は、モジュラー指数の処理です。 クエリごとに累乗を繰り返すと遅すぎるため、事前計算能力が必要です。
