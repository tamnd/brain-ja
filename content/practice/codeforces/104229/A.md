 ## 問題の理解

タスクは、マルチセットに値が含まれるまでに必要なそのような操作の最小数を決定することです。$n$少なくとも一度は。 

この操作はマルチセット全体を操作しているように見えますが、値が存在するかどうかによってのみ異なります。$T$は個別の値のセットであり、選択された各値は 1 つの除去のみに寄与します。

 ## アルゴリズムのチュートリアル

 マルチセットをブール配列に圧縮します`present[i]`のために$0 \le i \le n$、これらの値のみが重要であるためです。 

1. 値のプレゼンス配列を構築する$0$に$n$。 より大きい値は無視されます$n$、それらは構築に決して役立つことがないため、$n$。 これにより、問題は有界離散状態に帰着します。 
2. 最小のインデックスを繰り返し計算します。`mex_all`の最初の値です。$[0, n]$現在は存在しません。 これは、構造的に欠落している次の値を表します。 
3. もし`mex_all == n`、これで終わりです。$n$は初期セットには含まれていませんが、プロセスは進化し、me​​x が正確に一致する操作を介して生成できるようになりました。$n$。 操作のカウントを停止します。 
4. それ以外の場合は、強制的に作成するように設計されたサブセットを選択する 1 つの操作をシミュレートします。`mex_all`。 概念的には、すべての値を含むサブセットを選択します$0$を通して`mex_all - 1`、その mex が正確であることを確認します`mex_all`。 次にマークを付けます`mex_all`現在のように。 
5. 操作回数を増やして繰り返します。 

重要な考え方は、各ステップで不足しているプレフィックス値を 1 つだけ解決し、システムはプレフィックスを埋める方向に厳密に移行するということです。$[0, n]$。 

### なぜ効果があるのか

 どの時点でも、プレフィックス内の最小の欠損値がバリアとして機能します。必要な要素の削除を回避するサブセットは、この値より小さい mex を生成できません。 そのバリアをターゲットにすることで、各操作は、以前に確立されたより小さい値を無効にすることなく、欠損値を正確に決定的に導入します。 各ステップにより現在のプレフィックス値のセットが増加するため、プレフィックスは次のように制限されます。$n$、プロセスは最大で 2 時間以内に終了する必要があります。$n$ステップ。 現在の mex より小さい値をその定義に矛盾せずに導入できる操作はないため、進行は単調です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        f = list(map(int, input().split()))
        
        present = [0] * (n + 1)
        for i in range(n):
            if f[i] > 0:
                present[i] = 1
        
        # we only care about 0..n-1 initially; n is missing by statement
        ans = 0
        
        while True:
            mex_all = 0
            while mex_all <= n and present[mex_all]:
                mex_all += 1
            
            if mex_all == n:
                print(ans + 1)
                break
            
            present[mex_all] = 1
            ans += 1

if __name__ == "__main__":
    solve()
```コードはマルチセットをブール値の存在配列に圧縮し、多重度を完全に無視します。 各反復では、プレフィックスに対してグローバル mex が計算されます。 そのメックスがなるとき$n$、実際に生産するために必要な最終操作を考慮します。$n$。 

微妙な点が最後です`ans + 1`。 このループは、不足しているプレフィックス値を埋めるプロセスのみをモデル化します。$n-1$。 最後の操作は、$n$, そのため、条件達成時に別途カウントされます。
