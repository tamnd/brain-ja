 ## 問題の理解

 ## アルゴリズムのチュートリアル

 1. 元のツリーを隣接リストとして構築します。 祖先と子孫のエッジを明示的に構築することはありません。`Theta(n^2)`彼らのうち。 
2. ツリーの頂点にルートを作成します`1`そして、走査順序とともに親配列を計算します。 逆トラバーサル順序で頂点を処理すると、Python の再帰の深さに依存せずにボトムアップ ツリー DP が得られます。 
3. 頂点ごとに`u`、計算する

 s=∑dp[v]

 その子供たちの上に`v`。 各子は、そのサブツリーが公開する必要がある一致しない頂点の最小数を提供します。 
4. もし`s = 0`、 セット`dp[u] = 1`。 すべての子サブツリーはすでに内部的に完全に一致しているため、利用可能な子孫はありません。`u`とペアリングします。 頂点`u`それ自体は比類のないものであり続ける必要があります。 
5. もし`s > 0`、 セット`dp[u] = s - 1`。 少なくとも 1 つの一致しない頂点が下のどこかに存在します`u`、そのような頂点はすべて、`u`、 それで`u`そのうちの1つと一致させることができます。 これにより、以前に一致しなかった頂点が 1 つだけ消費されます。 
6. ルートを処理した後、チェックを入れます`dp[1]`。 値 0 は、ツリー全体を祖先と子孫のペアに分割できることを意味し、これはゲーム グラフと完全に一致します。 その場合はボブが勝ちます。 正の値は、最大一致によって少なくとも 1 つの頂点が一致しないままになることを意味するため、アリスはそのような一致しない頂点から開始して勝ちます。 

なぜ機能するのか: DP は次の不変条件を維持します。`dp[u]`のサブツリーに完全に含まれるすべての一致のうち、一致しない頂点の最小数です。`u`。 異なる子サブツリーの頂点は比較できないため、子サブツリーは相互に対話できません。 したがって、子を結合した後に可能な唯一の改善策は、次のようにすることです。`u`1 つの公開された子孫と一致します。 再帰化ではこれら 2 つの可能性が正確に考慮されるため、真の最小値が計算されます。 ルートでは、一致しない頂点がゼロであることは完全一致と同等です。 その後、一致するゲーム引数によって勝者が決まります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    graph = [[] for _ in range(n)]

    for _ in range(n - 1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        graph[u].append(v)
        graph[v].append(u)

    # Root the tree at 0.
    parent = [-1] * n
    order = [0]
    parent[0] = -2

    for u in order:
        for v in graph[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            order.append(v)

    # Process children before parents.
    dp = [0] * n

    for u in reversed(order):
        total = 0

        for v in graph[u]:
            if parent[v] == u:
                total += dp[v]

        if total == 0:
            dp[u] = 1
        else:
            dp[u] = total - 1

    print("Bob" if dp[0] == 0 else "Alice")

if __name__ == "__main__":
    solve()
```隣接リストには、`n - 1`オリジナルの木の端。 の`parent`配列のルートはツリーの頂点にあります`1`、インデックスで表されます`0`Pythonで。 の`order`配列はルートからのトラバーサルなので、それを逆にすると、すべての子がその配列をすでに受け取っていることが保証されます。`dp`親が処理されるときの値。 

DP 自体は意図的に小さいです。 頂点ごとに、`total`はその子の値の合計です。 表現`total == 0`再発の唯一の境界ケースです。 ゼロの場合、現在の頂点は 1 つの一致しない頂点に寄与します。 それ以外の場合は、一致しない子孫を 1 つ消費します。 

実装は再帰的ではなく反復的です。 とのパス`100000`頂点は周囲に再帰の深さを作成します`100000`これは、たとえ再帰制限を手動で増やしたとしても、Python では安全ではありません。 Python の整数は任意の精度であり、実際にはすべての精度であるため、整数のオーバーフローは発生しません。`dp[u]`最大でもそのサブツリーのサイズです。 

操作の順序が重要です。 近傍をプッシュする前に親を計算すると、親に戻る無向エッジが子エッジとして扱われるのを防ぎます。 条件`parent[v] == u`DP フェーズでは、次の子を正確に識別します。`u`。
