 ## 問題の理解

 固定深度座標 x の場合、最初の投影は、どの y 位置に少なくとも 1 つの立方体が含まれなければならないかを示し、2 番目の投影は、どの Z 位置に少なくとも 1 つの立方体が含まれなければならないかを示します。 (x,y,z) の立方体は、投影セル (x,y) と (x,z) を同時に作成します。 

Y x を、最初の投影に含まれる y 座標のセットとします。`1`行 x で、Z x を 2 番目の投影からの対応する Z 座標のセットとする。 深さ x の立方体は、まさに y∈Y x および z∈Z x の場合に役立ちます。 したがって、両方のセットが既知になると、 Y x ×Z x のすべてのペアが有効な立方体になります。 

これにより、3 次元問題が n 個の独立した 2 次元問題に完全に分離されます。 各 x について、Y x のすべての頂点を Z x の少なくとも 1 つの頂点に接続するだけで済みます。 

最初の実現可能条件がすぐに続きます。 Y x が空ではないが、Z x が空の場合、必要な最初の投影セルを生成することはできません。 両面を逆にしても同様です。 両方のセットが空の場合、そのスライスにはキューブが含まれていないだけであり、有効です。 

次元は最大 100 なので、可能な立方体は最大 100⋅100⋅100=10 6 個になります。 これは、すべてのキューブを一度に列挙するには十分小さいですが、サブセットに対する指数関数的な検索には大きすぎます。 必要なソリューションは、可能なキューブの数が基本的に線形である必要があり、最適化された実装では 1 秒の制限内に十分収まります。

## アプローチ

 ブルートフォースアプローチは、nmh 個の可能な立方体のすべてのサブセットを考慮し、そのサブセットを 2 つの行列に投影し、最大サイズの有効なサブセットと最小サイズの有効なサブセットを保持することです。 これは正しいです。なぜなら、考えられるあらゆる物理的配置は、立方体の 1 つのサブセットによって表現されるからです。 ただし、nmh サブセットは 2 つあります。 最大次元では、これは 2 1,000,000 の候補となり、1 つの候補をチェックするだけでも最大 10 6 の立方体演算が必要になります。 これはまったく実現不可能です。 

有益な観察は、異なる X 座標を持つ立方体は決して相互作用しないということです。 1 つの固定 x の場合、許可される立方体は Y x と Z x の間の完全な 2 部グラフを形成します。 必要なすべての y 座標とすべての必要な z 座標の間にはエッジがあります。 

最大のソリューションでは、許可されたすべてのエッジが存在できます。 すでに 2 つの射影セルが必要な立方体を追加しても射影を無効にすることはできないため、最大解にはスライス x に正確に ∣Y x ∣∣Z x ∣ の立方体が含まれます。 

最小の解を得るには、この完全な 2 部グラフのすべての頂点に接触するエッジを最小限にする必要があります。 2 つの辺に a および b の頂点が含まれる場合、すべての立方体は各辺の最大 1 つの頂点に接触するため、少なくとも max(a,b) 個の立方体が必要です。 この数でも十分です。大きい辺のすべての頂点に 1 つのエッジを割り当て、必要に応じて小さい辺の頂点を再利用します。 したがって、スライス x の最小値は max(∣Y x ∣,∣Z x ∣) です。 

残りの問題は、これらのエッジを辞書順に選択することです。 a≧b と仮定します。 エッジが必要であり、すべての異なる y 座標が表示される必要があるため、各 y に対してエッジが 1 つだけ存在する必要があります。 出力は (x,y,z) でソートされるため、y 座標は強制的に y 0 ,y 1 ,…,y a−1 として表示されます。 すべての z を使用しながら、一連の z 座標を辞書編集的に最小にするために、最小の z をできるだけ多く使用してから、次の z に移動します。 したがって、シーケンスは z 0 が a−b+1 回繰り返され、その後に z 1 、z 2 、…、z b−1 が続きます。 b>a の場合は対称です。 

ブルートフォース手法は、すべての配置を明示的に考慮するため機能しますが、配置の数が指数関数的なため失敗します。 すべてのスライスが完全な 2 部グラフであるという観察により、問題は単純なカウントと直接的な辞書編集に帰着します。

 ## アルゴリズムのチュートリアル

 1. 2 つの射影行列を読み取り、x ごとに、以下を含む y 座標と z 座標を保存します。`1`。 

2 つのリストは、そのスライスで発生する可能性のあるすべてを完全に説明します。 3 次元ボリューム自体を保存する必要はありません。 
2. すべての x について、Y x および Z x のいずれかが空かどうかを確認します。 

そうなると、予測は互いに矛盾します。 必要な y 位置を生成する立方体は必然的に何らかの z 位置を生成し、その逆も同様です。 いずれかの x のチェックが失敗した場合は、出力します`-1`。 
3. 最大解を求めるには、すべての y∈Y x とすべての z∈Z x を反復し、立方体 (x,y,z) を出力します。 

このようなペアはすべて許可されており、両方のエンドポイントがすでに次のようにマークされているため、それらをすべて追加してもまったく同じ投影が生成されます。`1`。 考えられるすべての有効なキューブが含まれるため、キューブの数は最大になります。 
4. 最小解については、a=∣Y x ∣、b=∣Z x ∣、k=max(a,b) とします。 

各立方体は最大 1 つの新しい y 座標と最大 1 つの新しい z 座標を導入できるため、少なくとも k 個の立方体が必要です。 k 個の立方体を含む構造が存在するため、k が最適です。 
5. i を k から 1 まで反復して最小解を生成します。 

y[max(0,a−i)]

 そして

 z[max(0,b−i)]。 

一方の辺が大きい場合、その座標はリスト全体を進めますが、小さい方の辺は、大きい方の辺のすべての頂点がカバーされるまで最小の座標を繰り返します。 リストは昇順に格納されるため、生成されたトリプルはすでに辞書順にソートされています。 
6. x を昇順に処理し、保存されている各投影座標を昇順に処理します。 

これにより、完全な出力が辞書順に並べられ、ステートメントで必要となります。 異なる x スライスは独立しているため、各スライスを辞書編集的に最小にすると、連結されたソリューションも辞書編集的に最小になります。 

### なぜ効果があるのか

 すべての固定 x に対して、必要な射影セルは Y x と Z x の間の完全な 2 部グラフを定義します。 有効なキューブ セットは、まさにすべての頂点に接するエッジ セットです。 どちらかの側が空で、もう一方の側が空でない場合、そのようなエッジ セットは存在できません。 それ以外の場合、すべての ab エッジは正当であり、最大の解決策が得られます。 

最小の解法では、1 つのエッジが各辺の最大 1 つの頂点をカバーできるため、少なくとも max(a,b) のエッジが必要です。 この構造はまさにその数のエッジを使用し、すべての頂点をカバーするため、最適です。 このようなすべての解の中で、a≥b の場合、すべての y は正確に 1 回出現する必要があります。 したがって、それらの順序は固定されます。 可能な最小の z がすべての位置で選択されますが、そうすることで残りのすべての z 座標を導入するのに十分な位置がまだ残ります。 これにより、可能な限り最小の Z シーケンスが得られ、辞書編集上の最適性が証明されます。 対称の議論は、b>a の場合に適用されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, h = map(int, input().split())

    ys = [[] for _ in range(n)]
    zs = [[] for _ in range(n)]

    for x in range(n):
        row = input().strip()
        for y, ch in enumerate(row):
            if ch == '1':
                ys[x].append(y)

    for x in range(n):
        row = input().strip()
        for z, ch in enumerate(row):
            if ch == '1':
                zs[x].append(z)

    for x in range(n):
        if bool(ys[x]) != bool(zs[x]):
            print(-1)
            return

    out = []

    # Maximum solution.
    kmax = 0
    for x in range(n):
        kmax += len(ys[x]) * len(zs[x])

    out.append(str(kmax))

    for x in range(n):
        for y in ys[x]:
            for z in zs[x]:
                out.append(f"{x} {y} {z}")

    # Minimum solution.
    kmin = 0
    for x in range(n):
        kmin += max(len(ys[x]), len(zs[x]))

    out.append(str(kmin))

    for x in range(n):
        a = len(ys[x])
        b = len(zs[x])
        k = max(a, b)

        for i in range(k, 0, -1):
            y = ys[x][max(0, a - i)]
            z = zs[x][max(0, b - i)]
            out.append(f"{x} {y} {z}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()

実現可能性チェックでは、次を使用して 2 つのリストが空かどうかを比較します。`bool`。 これら 2 つのブール値が等しいということは、正確に、両方の射影セットが空であるか、両方とも空ではないかのいずれかの条件となります。 

最大数には、2 つのリスト サイズの積が使用されます。 次に、ネストされたループは、y を増加させ、続いて z を増加させながらすべてのペアを列挙します。 x はすでに小さいものから大きいものへと処理されているため、これにより辞書編集順にトリプルが生成されます。 

最小構成の式は、`max(0, a - i)`はキー境界操作です。 a が b より小さい場合、最初の数回の反復ではインデックスは 0 のままであるため、最小の y が繰り返されます。 大きいインデックスが小さいリストの最後に達すると、小さい側の座標がすべて使用されます。 同じ式で、別の分岐を行わずに反対の不均衡を処理します。 

Python の整数には任意の精度があるため、最大数 (最大 10 6) には特別な整数処理は必要ありません。 出力はリストに蓄積され、1 回だけ書き込まれるため、100 万回の個別のオーバーヘッドが回避されます。`print`呼び出します。
