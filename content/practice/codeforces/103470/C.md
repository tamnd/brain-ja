 ## 解決策
 ## 問題の理解

 行上の値を表す整数配列が与えられ、オプションで連続するセグメントを 1 つ選択し、そのセグメント内のすべての値を固定定数だけ増加させることができます。`k`。 

この操作を最大 1 回実行した後、配列全体を調べて、そのモード、つまり最も頻繁に出現する値を計算します。 タスクはモード自体を出力することではなく、セグメントを最適に選択した後、ある値がモードとして表示される回数を最大化することです。 

重要な点は、この操作ではカウントが一律に増加するだけではないということです。 選択したセグメント内のすべての要素の値が変更され、古い値の出現が破棄されたり、新しい値の出現が作成されたりする可能性があります。 最終的な答えは、一部の周波数を失うか、他の周波数を獲得するかの慎重なトレードオフによって決まります。 

制約の観点から見ると、配列のサイズは十分大きいため、`O(n^2)`あるいは`O(n sqrt n)`値ごとのシミュレーションが遅すぎます。 解決策は、すべての推論にわたって各要素が一定の回数だけ処理されるように問題を構造化することに依存する必要があります。 これは、配列全体に対する値ごとのシミュレーションではなく、位置リストとセグメント推論を使用した線形または線形に近いアプローチを強く示唆しています。 

主なエッジ ケースは、操作が同一の値とどのように相互作用するか、および値間の衝突から生じます。`x`そして`x + k`。 たとえば、すべての要素が等しい場合、`k = 0`の場合、どのセグメントも何も実行しませんが、有効な操作としてカウントされます。 単純な解決策では、利益が 2 倍になる可能性があります。 値が次の場合に別の厄介なケースが発生します。`v`そして`v - k`これは、削除を回避しながら変換を最大化するために、最良のセグメントには配列の一部のみが選択的に含まれる可能性があるためです。 

## アプローチ

 強引なアイデアは簡単です。 可能なあらゆるセグメントを試します`[l, r]`、増分を適用し、配列を再構築して、すべての値の頻度を計算します。 これには、周波数をカウントする必要があります。`O(n)`セグメントごとに、`O(n^2)`セグメント、与える`O(n^3)`全体的な複雑さ。 プレフィックス構造を使用して周波数の再計算を最適化したとしても、依然として次のような問題に直面します。`O(n^2)`限界をはるかに超えたセグメント評価。 

重要な点は、配列を明示的に再構築する必要がないということです。 重要なのは、選択したセグメントが特定の値のカウントをどのように変換するかです。`v`。 セグメント内で発生するすべての`v`が失われ、発生するすべての`v - k`になる`v`。 セグメントの外側はすべて変更されません。 

したがって、固定目標値の場合`v`、最終的な頻度は元の合計数になります。`v`、セグメントからの貢献に加えて、次の利益が得られます。`+1`それぞれに`v - k`セグメント内で負ける`-1`それぞれに`v`セグメント内。 それ以外はすべて中立です。 これにより、問題は、各位置が寄与する重みの合計を最大化するセグメントを見つけることに変わります。`+1`、`-1`、 または`0`に対する相対的な値に応じて`v`。 

ただし、これをすべてのユーザーに対して独立して実行すると、`v`まだ遅すぎるだろう。 2 番目の重要な洞察は、意味のある相互作用は値のペア間でのみ発生するということです。`(x, x + k)`。 すべての要素は、`+1`のために`v = x + k`またはとして`-1`のために`v = x`。 これは、考えられるすべての計算を反復するのではなく、値のペアごとに計算をグループ化できることを意味します。`v`。 

それぞれの値について`x`を作成するために最適なセグメント効果を計算します。`x + k`の位置のみを使用して、より頻繁に`x`との位置`x + k`。 各インデックスは 1 つの値にのみ属するため、すべてのペアにわたる合計処理は次のように線形になります。`n`。

 ## アルゴリズムのチュートリアル

 1. それぞれの個別の値から、配列内のその位置のソートされたリストへのマッピングを構築します。 これにより、配列全体を繰り返しスキャンすることなく、出現箇所を推論することができます。 
2. 配列内のすべての値のベースライン頻度をカウントします。 操作を実行しないことを選択した場合、これはすでに答えを表しています。 
3. それぞれの個別の値について`x`、価値の向上に貢献するものとして扱います。`v = x + k`。 2 つの順序付きリストを収集します:`x`とすべてのポジション`x + k`。 
4. これら 2 つの位置リストをインデックスの昇順でマージします。 マージ中に、次の重みを割り当てます。`+1`の発生に対して`x`そして`-1`の発生に対して`x + k`。 これは、セグメントの選択によって引き起こされる利得と損失の構造をエンコードします。 
5. このマージされたシーケンスに対して Kadane スタイルのスキャンを実行し、配列に沿った寄与のシーケンスとして扱います。 最適なサブ配列合計は、変換の純ゲインを最大化する最適なセグメントに対応します。`x`の中へ`x + k`。 
6. この最良のゲインをベースライン周波数に加算します。`x + k`、それは値が改善されているためです。 この結果でグローバル回答を更新します。 
7. すべての値を処理した後`x`、取得されたすべての結果をベースラインの最大周波数と比較し、最良の値を出力します。 

### なぜ効果があるのか

 目標値を固定する`v`。 あらゆる操作は以下の発生に影響を与えます。`v`2 つのメカニズムのみを介して: 既存の削除`v`選択したセグメント内に新しいセグメントを作成する`v`から`v - k`。 この依存関係は、次の位置に対して純粋にローカルです。`v`そして`v - k`、他のすべての値から独立しています。 したがって、固定された問題に対するあらゆる最適解は、`v`の合計を最大化する部分配列を選択することに正確に対応します。`+1`そして`-1`これら 2 つのポジション セットに対する貢献度。 セグメントのすべての有効な変換はこのマージされたシーケンスで表され、すべてのマージされたシーケンスは実際のセグメントに対応するため、Kadane の最大値は達成可能な最良のゲインを正確に取得します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    pos = {}
    freq = {}

    for i, v in enumerate(a):
        freq[v] = freq.get(v, 0) + 1
        if v not in pos:
            pos[v] = []
        pos[v].append(i)

    ans = max(freq.values())

    for x in pos:
        y = x + k
        if y not in pos:
            continue

        A = pos[x]
        B = pos[y]

        i = j = 0
        cur = 0
        best = 0

        while i < len(A) or j < len(B):
            if j == len(B) or (i < len(A) and A[i] < B[j]):
                cur += 1
                i += 1
            else:
                cur -= 1
                j += 1

            if cur < 0:
                cur = 0

            if cur > best:
                best = cur

        ans = max(ans, freq[y] + best)

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、配列を繰り返しスキャンせずに値の変換を推論できるように、まず頻度と位置のリストを構築します。 ベースラインの応答は、操作の前に最大周波数として初期化されます。 

それぞれの値について`x`、改善を試みます`x + k`。 の出現をマージします`x`そして`x + k`インデックス順に処理する`x`利益として、そして`x + k`損失として。 実行中の合計が負になるたびに Kadane スタイルのリセットを実行すると、配列の最良の連続セグメントが常に考慮されるようになります。 

微妙な点は、セグメント境界を明示的に計算しないことです。`[l, r]`。 代わりに、マージされたリストのすべてのプレフィックスが元の配列順序付けの有効な間隔に対応するため、マージされたトラバーサルはそれらを暗黙的にシミュレートします。 

## 実用的な例

 ### 例 1

 検討してください`a = [1, 2, 1, 2]`、`k = 1`。 

我々は持っています`pos(1) = [0, 2]`、`pos(2) = [1, 3]`。 ベースライン周波数は両方とも`2`。 

変革を評価します`1 -> 2`。 

| ステップ | イベント | 現在の合計 | ベスト |
 | --- | --- | --- | --- |
 | 0 | +1 (0 に 1) | 1 | 1 |
 | 1 | -1 (1 で 2) | 0 | 1 |
 | 2 | +1 (2 で 1) | 1 | 1 |
 | 3 | -1 (3 で 2) | 0 | 1 |

 最高のゲインは`1`、つまり、値の最終的な答え`2`は`2 + 1 = 3`。 

これはセグメントを選択する方法を示しています`[0,2]`1つを変換します`1`の中へ`2`損失を最小限に抑えながら。 

### 例 2

 検討してください`a = [3, 3, 3, 3]`、`k = 0`。 

すべての値が同一であるため、すべての変換は完全に重複します。 

| ステップ | イベント | 現在の合計 | ベスト |
 | --- | --- | --- | --- |
 | 0 | +1 | 1 | 1 |
 | 1 | -1 | 0 | 1 |
 | 2 | +1 | 1 | 1 |
 | 3 | -1 | 0 | 1 |

 ここ`best = 1`、しかしそれ以来`k = 0`、変換によって値は変更されないため、ベースライン`freq[3] = 4`支配し、答えを与える`4`。 

これは、操作によって実際のメリットが得られない場合、アルゴリズムが変更されていない構成に安全にフォールバックすることを示しています。

 ## 特殊なケース

 重要なエッジケースの 1 つは次のような場合です。`k = 0`。 この場合、すべての変換は値をそれ自体にマップします。つまり、選択されたセグメントは同じ値を同時に減算および加算するだけです。 マージされた寄与シーケンスは、自明な部分配列を除いて常に相殺されるため、最適な結果は常に元の最大周波数になります。 計算されたゲインがベースラインに対する改善がゼロを超えることはないため、アルゴリズムはこれを自然に処理します。 

別のエッジケースは、値が次の場合に発生します。`x + k`配列内に存在しません。 その場合、どのセグメントでも次の出現箇所のみが削除されます。`x + k`新しいものを作成する必要がないため、最善の戦略は、この変換を決して考慮しないことです。 アルゴリズムはそのようなペアを完全にスキップし、ベースラインの答えはそのままにし、正しい動作と一致します。 

最後の微妙なケースは、次のような場合に発生します。`x`そして`x + k`大量にインターリーブされています。 マージされた Kadane スキャンにより、削除が優勢な領域を回避しながら、正味のコンバージョンを最大化する連続した領域が常に選択されます。 現在の合計が負になるたびにゼロにリセットされるため、将来のセグメントに有害なプレフィックス決定が持ち込まれないことが保証されます。
