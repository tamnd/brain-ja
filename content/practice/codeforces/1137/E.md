 ## 解決策
 ## 問題の理解

 私たちは、時間の経過とともに成長し、車両の価値が進化する列車をシミュレートするように求められています。 最初に、次のものがあります。$n$車には先頭から番号が付けられています。 車両は列車の両端に追加でき、特定の瞬間にすべての車両の値が追加されます。$A_i$一次関数で増加します$b + (i-1) \cdot s$。 各操作の後、最小限の値を使用して車の最小インデックスを報告する必要があります。$A_i$そしてその価値。 

重要な課題は、$n$まで可能です$10^9$、最大 300,000 のイベントが存在する可能性があります。 すべての車の値を明示的に保存することは不可能なので、実際に追跡するアプローチはどれも$A_i$どの車も思い出と時間を爆破してしまうからです。 これにより、単純な配列シミュレーションが完全に排除されます。 

車が頭に追加されると、微妙なエッジケースが発生します。つまり、既存のインデックスがすべてシフトします。 このシフトを考慮するのを忘れると、間違った車が最小の車として報告される可能性があります。 同様に、再計算すると、最小限の車両$A_i$傾斜に応じて新しいヘッドまたはテールに移動する可能性があります$s$。 たとえば、列車に車両 [0,0] があり、先頭に 3 を追加すると、新しい先頭のインデックスは 1 で値 0 になり、古い先頭の先頭はインデックス 4 になります。 インデックスのシフトを無視する単純なアプローチでは、間違った最小の車が報告されてしまいます。 

## アプローチ

 ブルートフォースアプローチは簡単です。 すべての配列を維持する$A_i$、車が追加されたときにインデックスを更新し、タイプ 3 イベントが発生するたびにすべての車の値を再計算します。 各操作の後に、配列をスキャンして最小値を探し、そのインデックスと値を出力します。 このアプローチは問題を文字通り反映しているので正しいですが、それには次のことが必要です。$O(n \cdot m)$最悪の場合の運用。 と$n$まで$10^9$そして$m$3×10^5 までは、これは完全に不可能です。 

最適なアプローチは、各再計算後に、勾配に応じて列車の先頭または最後尾で最小値が発生することを観察することに依存しています。$s$。 具体的には、$s > 0$、値は頭から尾まで直線的に増加するため、最小値は$A_i$先頭にあります。 もし$s = 0$、すべての車が均等に増加するため、最小値はどこでも構いませんが、最も早いインデックスが優先されます。 すべての車両はゼロから始まり、線形更新のみを受けるため、車両の数、累積された加法定数の 3 つの情報を追跡するだけで十分です。$base$、および傾きの累積$slope$。 車が追加されると、インデックス オフセットは調整されますが、個々の値には影響しません。 タイプ 3 更新の増分$base$そして$slope$、現在の傾きに応じて先頭または末尾で最小値が計算されます。

 ## アルゴリズムのチュートリアル

 1. 変数を初期化します。`train_length = n`、`head_offset = 0`、`base = 0`、`slope = 0`。 ここ、`head_offset`先頭に追加された車両によるインデックスのシフトを考慮し、`base`すべての定数加算を累積し、`slope`インデックスごとの増分加算を累積します。 
2. 各イベントについて、まずそのタイプを確認します。 type-1(先頭に追加)の場合はインクリメントします`head_offset`新車の台数と増加による`train_length`それに応じて。 これらの新しい車には、`A_i = 0`したがって、新しいヘッドの実効値はゼロになります。 インデックス計算を最小限に抑えるためにオフセットを調整します。 
3. タイプ 2 (末尾に追加) の場合は、そのまま増加します。`train_length`。 傾きが負の場合、尾部が関係する可能性があります。 
4. パラメータ付きタイプ 3 の場合`(b, s)`、増分`base += b`そして`slope += s`。 これにより、すべての車の価値が明示的に保存されずにどのように増加するかを追跡します。 
5. 各イベントの後、最小の車を決定します。 もし`slope > 0`、最初の車には最小の価値があり、これは`base + slope * 0 = base`。 もし`slope < 0`、最後の車の価値は最小限です`base + slope * (train_length - 1)`。 もし`slope == 0`、どの車も同じ価値があります。 ヘッド オフセット後の最も古いインデックスを選択します。 
6. インデックスを出力します（調整済み）。`head_offset`) と計算された最小値。 

正確さを保証する不変条件は、次の関数です。`A_i`車のインデックスに対して常に直線であり、傾きがあります`slope`そして一定の`base`。 線形関数はいずれかの終点で最小値に達するため、先頭と末尾のみを追跡するだけで十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
train_length = n
head_offset = 0
base = 0
slope = 0

for _ in range(m):
    parts = input().split()
    t = int(parts[0])
    
    if t == 1:
        k = int(parts[1])
        head_offset += k
        train_length += k
    elif t == 2:
        k = int(parts[1])
        train_length += k
    else:
        b = int(parts[1])
        s = int(parts[2])
        base += b
        slope += s
    
    if slope > 0:
        min_index = 1
        min_value = base
    elif slope < 0:
        min_index = train_length
        min_value = base + slope * (train_length - 1)
    else:
        min_index = 1
        min_value = base
    
    print(min_index, min_value)
```このソリューションでは、すべての計算が一定空間に保持されます。`head_offset`ヘッド挿入後の最初の車両が正しく解釈されるようになります。 最小インデックスを選択するロジックは、`A_i`複数回の再計算が行われるため、すべての車両をスキャンする必要はありません。
