 ## 解決策
 ## 問題の理解

 値が範囲内にある配列から始めます`[0, k - 1]`。 すべての位置に同じ値が含まれていない限り、ランダムな位置とランダムな値を繰り返し選択し、その位置を上書きします。 

完全に指定された配列の場合`b`、 させて`f(b)`すべての要素が等しくなるまでの予想される操作数になります。 

入力配列は部分的にのみ指定されています。 一部のポジションには以下が含まれます`-1`。 このような位置はそれぞれ、次からの一様にランダムな値で独立して置き換えられます。`[0, k - 1]`。 すべての置換の後、ランダムな完全な配列が得られます。 タスクは、次の期待値を計算することです。`f`そのようなすべての完了に渡って。 

この発言の中で最も衝撃的な部分は、`k`と同じ大きさにすることができます`10^9`。 色の反復処理に依存する解決策は直ちに不可能です。 同時に、`n`だけです`10^5`これは、最終的な式が個々の色ではなく頻度数に依存する必要があることを強く示唆しています。 

2 番目の観察は、確率過程自体が巨大な状態空間を持っているということです。 中程度の場合でも`n`、可能なすべての配列を保存することは絶望的です。 マルコフ連鎖を構築せずに予想打撃時間を計算する方法が必要です。 

厄介なケースは、現在表示されていない色が関係するケースです。 

考慮する：```
n = 3, k = 10
a = [0, 0, 1]
```頻度がゼロの色は 8 色あります。 彼らの貢献は単純に無視することはできません。未知のポジションを埋めた後も期待公式に参加しているからです。 

もう 1 つの簡単な間違いは、現在存在する色についてのみ期待値を計算することです。```
n = 3, k = 3
a = [-1, -1, -1]
```どの色も対称的です。 期待される答えは、どの色が入力に偶然現れるかではなく、最終的に各色を受け取る位置の数によって決まります。 

3 番目の落とし穴は、末期状態です。 すべての要素が等しい場合、プロセスは直ちに停止します。 潜在関数の引数はすべての端末構成に同じ値を割り当てる必要があります。割り当てないと、停止時間の式が不正確になります。 

## アプローチ

 ブルートフォースの観点は、すべての配列をマルコフ連鎖の状態として扱い、連立一次方程式を解いて予想されるヒット時間を求めることです。 

状態カウントは`k^n`。 たとえ`n = 10`そして`k = 10`、これはもう`10^10`州。 このアプローチは数学的には正しいですが、まったく使用できません。 

重要な観察は、プロセスが色の周波数のみに依存するということです。 

させて`cnt(x)`色の出現数を示します`x`。 配列を直接研究する代わりに、潜在的な関数を検索します。$$F = \sum_x g(cnt(x))$$1 回の操作で期待される変化は常に`-1`。 

そのような関数が存在する場合、オプションの停止定理はすぐに次のようになります。$$\mathbb E[\text{time to finish}] = F(\text{initial}) - F(\text{terminal}).$$これにより、マルコフ連鎖を解くことが完全に回避されます。 

の漸化式を導出した後、`g`、問題は純粋に組み合わせの問題になります。 必要なのは期待値だけです$$\sum_x g(cnt(x))$$すべてをランダムに置き換えた後`-1`ポジション。 

未知の位置はそれぞれ独立して次のいずれかを選択します。`k`色。 したがって、すべての色について、追加の出現は二項分布に従います。 これらの寄与を慎重に合計すると、`O(n)`解決。

 ## アルゴリズムのチュートリアル

 ### 可能性を引き出す

 しましょう$$F=\sum_x g(cnt(x)).$$現在、色に周波数があるとします。`i`。 

その色の出現を選択して別の色に再着色すると、その頻度は から減少します。`i`に`i-1`。 

他の位置をその色に再着色すると、その頻度は から増加します。`i`に`i+1`。 

定義する$$d_i=g(i)-g(i-1).$$の予想される変化を計算する`F`そしてそれが正確であることを要求します`-1`すべての状態に対して条件が与えられます$$(k-1)i\,d_i-(n-i)d_{i+1}=n.$$同様に、$$(k-1)i(g(i)-g(i-1)) + (n-i)(g(i)-g(i+1)) = n.$$設定しました$$g(0)=g(1)=0,$$そして、残りの値をすべて再帰的に計算します。$$g(i+1) = g(i) + \frac{(k-1)i(g(i)-g(i-1))-n}{n-i}.$$すべての算術はモジュロで実行されます`10^9+7`。 

### 未知のポジションに就いた後に期待される貢献

 しましょう`c`の数になります`-1`エントリ。 

各色について、その現在の既知の周波数が次と等しいと仮定します。`j`。 

未知の位置を埋めた後の追加出現数は$$X \sim \text{Binomial}(c,\tfrac1k).$$したがって、最終的な周波数は次のようになります。`j + X`。 

させて`b[j]`既知の周波数が正確に一致する色の数を示します。`j`。 

次に、最終的な頻度が次と等しい色の予想される数`i`は$$\sum_j b[j] \Pr(X=i-j).$$二項確率が寄与する$$\binom{c}{i-j} \left(\frac1k\right)^{i-j} \left(\frac{k-1}{k}\right)^{c-(i-j)}.$$べき乗で割るのではなく、`k`繰り返して分子を累積していきます$$\binom{c}{i-j}(k-1)^{c-(i-j)}$$で割ります`k^c`最後に一度。 

### 最終的な答え

 プロセス開始前のポテンシャルの期待値は次のとおりです。$$\mathbb E[F] = \sum_i g(i)\cdot \mathbb E[\#\text{colors with final frequency }i].$$すべての終端状態は、表示される 1 つの色で構成されます`n`回とその他すべての登場人物`0`倍なので、その可能性は次のようになります$$g(n).$$したがって$$\mathbb E[f(a)] = \mathbb E[F]-g(n).$$これはまさに必要な答えです。 

### なぜ効果があるのか

 の再発`g`は、すべての操作が の期待値を減少させるように導出されました。`F`現在の構成に関係なく、ちょうど 1 つずつ増えます。 その結果、$$F_t+t$$マーチンゲールです。 させて`T`すべての要素が等しくなるのは初めてです。 停止時間アイデンティティを適用すると、$$\mathbb E[T] = F(\text{start})-F(\text{finish}).$$解の残りの部分では、未知のエントリをランダムに置換した後に予想される開始可能性を計算します。 期待値は線形であるため、すべての色の二項寄与を合計すると、次の正確な値が得られます。`\mathbb E[F]`。 両方の部分を組み合わせることで、必要な予想停止時間が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    freq = {}
    unknown = 0

    for x in a:
        if x == -1:
            unknown += 1
        else:
            freq[x] = freq.get(x, 0) + 1

    inv = [0] * (n + 1)
    inv[1] = 1
    for i in range(2, n + 1):
        inv[i] = (MOD - MOD // i) * inv[MOD % i] % MOD

    g = [0] * (n + 1)

    for i in range(1, n):
        term = ((k - 1) % MOD) * i % MOD
        term = term * ((g[i] - g[i - 1]) % MOD) % MOD
        term = (term + (n - i) * g[i] - n) % MOD
        g[i + 1] = term * inv[n - i] % MOD

    fac = [1] * (n + 1)
    ifac = [1] * (n + 1)

    for i in range(1, n + 1):
        fac[i] = fac[i - 1] * i % MOD

    ifac[n] = modpow(fac[n], MOD - 2)
    for i in range(n, 0, -1):
        ifac[i - 1] = ifac[i] * i % MOD

    def C(N, R):
        if R < 0 or R > N:
            return 0
        return fac[N] * ifac[R] % MOD * ifac[N - R] % MOD

    b = [0] * (n + 1)

    b[0] = k - len(freq)
    for v in freq.values():
        b[v] += 1

    pw = [1] * (unknown + 1)
    for i in range(1, unknown + 1):
        pw[i] = pw[i - 1] * ((k - 1) % MOD) % MOD

    nonzero = [i for i in range(n + 1) if b[i]]

    ans = 0

    for final_cnt in range(1, n + 1):
        ways = 0

        for base in nonzero:
            add = final_cnt - base
            if add < 0 or add > unknown:
                continue

            ways = (
                ways
                + b[base] % MOD
                * C(unknown, add)
                % MOD
                * pw[unknown - add]
            ) % MOD

        ans = (ans + ways * g[final_cnt]) % MOD

    ans = ans * modpow(modpow(k % MOD, unknown), MOD - 2) % MOD
    ans = (ans - g[n]) % MOD

    print(ans)

solve()
```最初のブロックは潜在的な値を計算します。`g(i)`導出された再発から。 までの周波数のみ`n`が必要です。 

次のブロックでは、階乗と逆階乗を準備して、すべての二項係数を定数時間で評価できるようにします。 

配列`b`現在それぞれの既知の周波数を持つ色が何色あるかを保存します。 これにより、すべての色が 1 つに圧縮されます。`n + 1`周波数クラス。 

あらゆる可能な最終周波数に対して`i`、その周波数で終わる色の予想数を計算します。 二項係数は、特定の色に結合する未知の位置の数を選択します。`(k - 1)^(...)`残りの未知の位置を考慮して、他の色を選択します。 

蓄積された値にはまだ共通点があります`k^c`、 どこ`c`は未知の位置の数です。 最後にモジュラー逆行列を乗算して一度除算します。 

最後に引き算します`g(n)`、あらゆる最終状態の可能性。
