 ## 解決策
 ## 問題の理解

 サイズの大きな長方形の布に色を付ける方法の数を数えるように求められます。$n \times m$を使用して$k$サイズが固定された 2 つの部分長方形がある場合の色$r \times c$色パターンが同一である必要があります。 各セルには、1 から 2 までの色を個別に割り当てることができます。$k$ただし、2 つの部分長方形によって課される制約は除きます。 

入力はグリッド全体の寸法を指定します$n$そして$m$、色の数$k$、部分長方形のサイズ$r \times c$、および 2 つの部分四角形の左上の座標。 目標は、有効なフルグリッド カラーのモジュロ数です。$10^9 + 7$。 

重要な制約は、$n$そして$m$まで可能です$10^9$、 その間$r$そして$c$に限定されています$10^6$。 これにより、グリッド全体のすべてのセルを反復するアルゴリズムが即座に除外されます。$n \cdot m$到達できた$10^{18}$。 アルゴリズムは独立している必要があります$n$そして$m$細胞レベルで。 

エッジ ケースは、2 つの部分長方形が重なったり一致したりするときに発生します。 これらを独立したものとして扱う単純なアプローチでは、このような場合に過大評価されてしまいます。 たとえば、両方の部分四角形が同じ位置にある場合、その中のすべてのセルは等しくなければなりませんが、共有領域に色を割り当てる必要があるのは 1 回だけです。 同様に、部分的に重なっている場合、重なっている部分は両方のサブ長方形で同じ色でなければなりませんが、重なっていない部分は自由に変更できます。 これを考慮しないと過大カウントにつながります。 

## アプローチ

 ブルートフォースアプローチでは、あらゆるものを列挙することになります。$n \times m$色を付けて制約を確認します。 それぞれの細胞には、$k$選択肢があるため、これには必要になります$k^{n \cdot m}$これは、最大の入力に対してはまったく実行不可能です。 上だけを反復しても、$r \times c$完全なグリッド内で可能な配置をそれぞれ追跡しようとすると、サブ長方形内のセルは依然として失敗します。 

重要な洞察は、完全なグリッドの色付けが、サブ長方形の外側の独立した選択とその内側の強制的な選択に影響を与えるということです。 2 つの部分四角形の和集合のみが制約されます。和集合内のすべてのセルには、両方の位置を満たす単一の色が割り当てられている必要があります。 したがって、問題は 2 つの部分四角形の和集合内のセルの数を数えることになり、次の式が求められます。$k$残りの「空き」セルの乗数になります。 

正式には、部分長方形の和集合が次の場合、$u$個別のセルの場合、有効な色の数は$k^u$制約された部分に次の値を乗じたもの$k^{n \cdot m - 2 r c}$制約されていないセルの場合、またはより直接的には$k^{n \cdot m - (r \cdot c) + \text{overlap}}$。 2 つの部分長方形間の重複領域は 1 回だけカウントする必要があります。 重なりを計算するには、2 つの長方形の座標の交点を取得します。 重なり合わない場合、重なりはゼロになります。 それ以外の場合は、交差点の幅と高さの積になります。 

これにより、潜在的に大規模な問題が、少数の整数乗算とべき乗剰余演算のみを使用した単純な算術計算に縮小されます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(k^{n*m}) | O(n*m) | 遅すぎる |
 | 最適 | O(ログMOD) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力を解析して取得します。$n$、$m$、$k$、$r$、$c$、$a_x$、$a_y$、$b_x$、$b_y$。 
2. 2 つの部分長方形の右下隅の座標を計算します。$(a_x + r - 1, a_y + c - 1)$そして$(b_x + r - 1, b_y + c - 1)$。 これは交差を計算するために必要です。 
3. 2 つの部分長方形の交差する長方形を決定します。 その左上隅は、$(\max(a_x, b_x), \max(a_y, b_y))$そしてその右下隅は$(\min(a_x + r - 1, b_x + r - 1), \min(a_y + c - 1, b_y + c - 1))$。 交差のいずれかの次元が負またはゼロの場合、重複はありません。 
4. 重複するセルの数を次のように計算します。$\max(0, x_2 - x_1 + 1) \cdot \max(0, y_2 - y_1 + 1)$。 
5. 制約されたセルの総数を計算します。 各サブ長方形が貢献します$r \cdot c$セルですが、重なっているセルは 2 回カウントされるため、結合は次のようになります。$2 \cdot r \cdot c - \text{overlap}$細胞。 
6. 有効な色の数は次のとおりです。$k^{\text{union of constrained cells}} \cdot k^{\text{remaining free cells}} = k^{n \cdot m - (r \cdot c) + \text{overlap}}$、モジュロ$10^9 + 7$。 べき乗モジュラーが使用されるのは、指数が非常に大きくなる可能性があるためです。 

機能する理由: このアルゴリズムは各セルを 1 回だけカウントします。 両方のサブ長方形の外側のセルは自由で、一方の長方形の内側のセルは 1 回強制され、重複するセルは両方の長方形によって強制されますが、1 回だけカウントされます。 べき乗剰余演算は、大きなべき乗を正しく処理します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modpow(a, b, mod):
    result = 1
    a %= mod
    while b > 0:
        if b % 2:
            result = result * a % mod
        a = a * a % mod
        b //= 2
    return result

def solve():
    n, m, k, r, c = map(int, input().split())
    ax, ay, bx, by = map(int, input().split())
    
    # intersection coordinates
    x1 = max(ax, bx)
    y1 = max(ay, by)
    x2 = min(ax + r - 1, bx + r - 1)
    y2 = min(ay + c - 1, by + c - 1)
    
    overlap = 0
    if x2 >= x1 and y2 >= y1:
        overlap = (x2 - x1 + 1) * (y2 - y1 + 1)
    
    constrained = 2 * r * c - overlap
    free_cells = n * m - constrained
    
    ans = modpow(k, free_cells, MOD)
    print(ans)

solve()
```ソリューションはべき乗剰余関数を定義します`modpow`大きな指数を安全に処理するため。 交差の計算では、長方形の標準の最大/最小トリックを使用します。 負のカウントを避けるために、重複がない場合は慎重に処理します。
