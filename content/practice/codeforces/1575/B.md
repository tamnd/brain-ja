## アルゴリズムのチュートリアル

 ### 1 つの生息地のジオメトリ

 生息地にしましょう$P=(x,y)$、そしてさせてください$$d = |P|.$$固定半径の場合$r>0$、中心は$$C = r(\cos\phi,\sin\phi).$$生息地が覆われている場合$$|P-C| \le r.$$両辺を二乗する:$$d^2 + r^2 - 2rd\cos(\phi-a) \le r^2,$$どこ$a$は極角です$P$。 

簡略化後:$$\cos(\phi-a) \ge \frac{d}{2r}.$$もし$d>2r$、この不等式を満たす角度はありません。 

さもないと、$$|\phi-a| \le \arccos\!\left(\frac{d}{2r}\right).$$したがって、生息地は角度を中心とする 1 つの角度間隔に寄与します。$a$。 

### 二分探索の実行可能性チェック

 1. もし$r=0$、原点に正確に生息地がいくつあるか数えてください。 そのカウントが少なくとも次の場合、半径は実現可能です$k$。 
2. すべての生息地について、計算します。$d=\sqrt{x^2+y^2}$。 
3. もし$d>2r$、この生息地をカバーすることはできず、何も貢献しません。 
4. もし$d=0$、間隔は円全体をカバーします。 グローバルベースカウンターを増やします。 
5. それ以外の場合は計算します$$\alpha=\arccos\!\left(\frac{d}{2r}\right).$$有効な中心角は次のとおりです。$$[a-\alpha,\ a+\alpha].$$1. すべての循環間隔をスイープ イベントに変換します。 インターバルの交差$0$ラジアンは 2 つの通常の間隔に分割されます。 
2. すべてのイベントを角度ごとに並べ替えます。 同じ角度で発生する終了イベントの前に開始イベントを処理します。 
3. 掃引中は、現在のオーバーラップ数に完全な円間隔の数を加えた値を維持します。 最大オーバーラップに達した場合$k$、半径$r$実現可能です。 
4. 実行可能な最小半径を二分探索します。 

### なぜ効果があるのか

 固定半径の場合$r$、すべての生息地は、それをカバーする中心位置のセットに正確に対応します。 上記の導出は、その集合を円上の角度間隔に変換します。$|C|=r$。 中心角は少なくともカバーします$k$その角度が少なくとも以下に属する場合に限り、生息地$k$間隔。 スイープでは、最大間隔オーバーラップが正確に計算されます。 

実現可能性述語は単調です。 半径を大きくすると、実行可能なすべての中心位置のセットが拡大され、縮小されることはありません。 したがって、二分探索は終了します$r$実行可能な最小半径を見つけます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    twopi = 2.0 * math.pi
    eps = 1e-12

    def check(r):
        if r < eps:
            cnt = 0
            for x, y in pts:
                if x == 0 and y == 0:
                    cnt += 1
            return cnt >= k

        base = 0
        events = []

        for x, y in pts:
            d = math.hypot(x, y)

            if d > 2.0 * r + 1e-10:
                continue

            if d < 1e-12:
                base += 1
                continue

            ratio = d / (2.0 * r)
            if ratio > 1.0:
                ratio = 1.0

            alpha = math.acos(ratio)
            a = math.atan2(y, x)

            l = a - alpha
            rr = a + alpha

            l %= twopi
            rr %= twopi

            if l <= rr:
                events.append((l, 1))
                events.append((rr, -1))
            else:
                events.append((0.0, 1))
                events.append((rr, -1))
                events.append((l, 1))
                events.append((twopi, -1))

        events.sort(key=lambda e: (e[0], -e[1]))

        cur = base
        best = cur

        for _, typ in events:
            cur += typ
            if cur > best:
                best = cur

        return best >= k

    lo = 0.0
    hi = 200000.0

    for _ in range(50):
        mid = (lo + hi) / 2.0
        if check(mid):
            hi = mid
        else:
            lo = mid

    print("{:.10f}".format(hi))

solve()

最もデリケートな実装の詳細は、ラップアラウンドの間隔を処理することです。$0$ラジアン。 このような間隔は、スイープの前に 2 つの通常の間隔に分割されます。 もう 1 つの微妙な点は、イベントの順序です。 開始イベントは同じ角度で終了イベントの前に処理され、エンドポイントが一致する間隔が正しく処理されます。
