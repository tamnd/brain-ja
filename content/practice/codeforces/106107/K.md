 ## 問題の理解

 各ノードが正の整数値を保持するツリーが与えられます。 任意のノードのペアに対して$u$そして$v$では、ツリー内でそれらを接続する一意の単純なパスを調べ、そのパスに沿ってすべてのノード値を収集します。 これらの値から LCM を計算します。 タスクは、LCM が指定されたターゲット値と正確に等しいパスを生成するノードのペアの数をカウントすることです。$X$。 

ツリー構造が重要なのは、ノードの各ペアが 1 つの単純なパスを定義しており、そのパスが LCM の寄与を決定するためです。 ノード上の値は次によって制限されます。$10^6$、ノード数は最大です。$10^5$したがって、すべてのペアに対して独立してパス情報を再計算しようとするソリューションは、直ちに実行不可能になります。 すべてのペアの単純な列挙により、すでに次のことが得られます。$O(n^2)$また、パスに沿って LCM を計算する場合でも、少なくとも対数的な時間がかかり、制限をはるかに超えてしまいます。 

主要な構造上の制約は、LCM が次の値に等しくなければならないということです。$X$、選択したパス上のすべての値を強制的に分割します。$X$。 ノードに存在しない素因数を含む値がある場合$X$、それを含むパスの LCM はすぐに次の値より大きくなります。$X$, したがって、答えには決して貢献できません。 

多くのノードが値 1 を持つ場合、微妙なエッジ ケースが発生します。1 は LCM を変更しないため、1 の長いチェーンは、結果に影響を与えることなく、有効なセグメントを接続できます。 たとえば、値を含むライン ツリーでは、$[1, 1, 1]$そして$X = 1$、すべてのペアは有効ですが、1 を完全に無視する不用意なアプローチはパスを過小評価する可能性があります。 

もう 1 つの重要なケースは次のような場合です。$X = 1$。 この場合、すべてのノードの値は 1 でなければならず、答えは単純にツリー内のすべてのパスの数になります。$n(n+1)/2$。 少なくとも 1 つの自明ではない除数構造を前提とした解決策は、ここでは失敗します。 

## アプローチ

 直接的なアプローチでは、ノードのすべてのペアが考慮されます。$(u, v)$、それらの間のパスを抽出し、そのパス上のすべての値の最小公倍数を計算します。 これには、パスを明示的に再計算するか、LCA 前処理を使用して上向きに歩く必要があり、少なくとも$O(n)$クエリごとに。 あるので$O(n^2)$ペアの場合、全体の複雑さは次のようになります。$O(n^3)$最悪の場合、遅すぎる場合もあります。 

重要な観察は、LCM が要素を含めた場合に単調に動作するということです。ノードを追加しても、LCM は維持または増加することしかできません。 LCM が正確である必要があるため、$X$、有効なパス上のすべてのノードは、$X$、および指数が以下の値を超えないものとする。$X$。 これにより、木を大幅に剪定することができます。 

問題を、値が分割されるノードのみで動作するように縮小します。$X$。 次に、タスクは、LCM が等しいこの誘導セット内のすべての単純なパスをカウントするようになります。$X$。 パスを直接列挙する代わりに、ツリーをルート化し、各ノードについて、そのノードで終了するパスのすべての LCM 状態の圧縮表現を維持しながら DFS を実行します。 各状態は次の約数です$X$、および約数の数$X$十分小さい (せいぜい数百)$X \le 10^6$) 状態を効率的にマージできるようにします。 

DFS 中に親から子に移動するときに、LCM を子の値とともに取得することによって、親からすべての LCM 状態を拡張します。 私たちも子ども自身から新たな道を歩み始めます。 状態が正確になるたびに$X$、回答に貢献します。 

これが機能する理由は、すべての有効なパスにはルート ツリー内で一意の最上位ノードがあり、そのノードをパスのエンドポイントとして処理するときに、そのノードが 1 回だけカウントされるためです。 これにより、二重カウントが回避され、ペアの列挙が不要になります。

 ## アルゴリズムのチュートリアル

 1. まず、値が割り切れないノードをすべて破棄します。$X$なぜなら、そのようなノードは有効なパスに現れることができないからです。 これにより、作業中のグラフが即座に縮小されます。 
2. 任意のノード (便宜的にノード 1 とする) でツリーをルート化し、隣接リストを準備します。 
3. DFS トラバーサルを実行します。 各ノードでは、考えられる LCM 値を、このノードで終了する下向きパスの数にマッピングしてその LCM を生成するディクショナリ (またはカウンター) を維持します。 これは、現在のノードで終わるすべてのパスの要約を表します。 
4. ノードの場合$u$、単一のエントリでその状態を初期化します。パスは次のもののみで構成されます。$u$、その最小公倍数は$a_u$。 
5. 子を処理する場合$v$からすべての LCM 状態を取得します。$u$そしてコンピューティングによってそれらを拡張します$\mathrm{lcm}(\text{state}, a_v)$。 から始まるシングルトン パスも含めます。$v$。 カウントを合計することにより、同一の LCM 値をマージします。 
6. 状態を計算した後、$v$に等しい状態を見るたびに、$X$、そのカウントをグローバルな答えに追加します。 これにより、DFS ツリーの最上位ノードが$v$。 
7. 親がこのサブツリーを介してパスを延長し続けることができるように、状態マップを上向きに戻します。 

これが機能する理由は、ツリー内のすべての単純なパスがルート構造の下に固有の最上位ノードを持っているという事実に基づいています。 DFS 中にそのノードにいるとき、そのノードを通過して下位のさまざまなサブツリーに進むすべてのパスは、その子からの状態を組み合わせることによって正確に表現されます。 常に下方向に展開する方法でパスを構築するため、各有効なパスは、そのエンドポイント サブツリーが処理される時点で 1 回だけカウントされ、重複したカウントにつながる複数の異なる方法でパスが形成されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from math import gcd
from collections import defaultdict

def lcm(a, b):
    return a // gcd(a, b) * b

n, X = map(int, input().split())
a = list(map(int, input().split()))

adj = [[] for _ in range(n)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

# If node value doesn't divide X, it can never be used
valid = [x for x in a]
for i in range(n):
    if X % a[i] != 0:
        valid[i] = 0

sys.setrecursionlimit(10**7)

ans = 0

def dfs(u, p):
    global ans
    dp = defaultdict(int)
    if valid[u] != 0:
        dp[valid[u]] = 1

    for v in adj[u]:
        if v == p:
            continue
        child = dfs(v, u)

        new_dp = defaultdict(int)

        for l1, c1 in dp.items():
            new_val = lcm(l1, valid[v] if valid[v] else a[v])
            if new_val <= X and X % new_val == 0:
                new_dp[new_val] += c1

        if valid[v] != 0:
            new_dp[valid[v]] += 1

        for k, c in new_dp.items():
            if k == X:
                ans += c

        for k, c in new_dp.items():
            dp[k] += c

    return dp

dfs(0, -1)

print(ans)
```この実装の中心となるアイデアは、各ノードで、そのノードで終了するすべての下向きパスの LCM 値の圧縮ヒストグラムを構築する DFS です。 の`dp`辞書はこの状態をエンコードします。 各子について、子の値を含む LCM を取得することによって既存のパス状態を拡張し、また子から新しいパスを開始します。 

剪定の様子`X % new_val == 0`これは、決して到達できない中間 LCM 状態を決して保持しないことを保証するため、必須です。$X$。 それがなければ、状態空間が不必要に拡大してしまいます。 

グローバルな答えは、状態が次の場合にのみ更新されます。$X$これにより、各有効なパスが一意の最上位の DFS ノードに関連付けられるため、正確性が保証され、二重カウントが回避されます。

 ## 特殊なケース

 いつ$X = 1$、すべてのノードが正確に 1 である必要があり、そうでない場合は答えが 0 になります。 値は除算されないため、アルゴリズムはこれを自然に処理します。$X$はただちに破棄され、1 に等しいノードのみが残ります。その後、すべての拡張機能で LCM = 1 が維持されるため、DFS は考えられるすべてのパスをカウントします。 

すべての値が 1 であるチェーンでは、すべてのノードですべての dp 状態が 1 のままになります。 DP マージでは新しい値が作成されることはなく、答えはペアごとに 1 回だけ蓄積されます (許可されている場合は単一ノード パスも含みます)。 伝播ステップにより、すべてのサブパスが正しいエンドポイントでカウントされるようになります。 

一部のノードが無効な混合ツリー (分割しない)$X$)、それらのノードは DP 伝播から効果的に削除されます。 DFS は依然として構造的にそれらをトラバースしますが、有効な状態には寄与しないため、無効な LCM が計算に入力されることはありません。
