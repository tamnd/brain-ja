 ## 解決策
 ## 問題の理解

 2 つの正の整数が与えられます。`x`そして`y`、負ではない整数を見つけるように求められます。`k`追加すると`k`両方の数値の合計はビットごとの XOR に等しくなります。 言い換えれば、私たちが望んでいるのは、`(x + k) + (y + k) = (x + k) ⊕ (y + k)`。 そうでない場合`k`存在するので戻すべきです`-1`。 複数の回答が許可されているため、有効なものはどれでも構いません`k`動作します。 

制約は比較的大きいです。`x`そして`y`まで行くことができます`10^9`、 そして`k`と同じ大きさにすることができます`10^18`。 テストケースの数`t`到達できる`10^4`。 これにより、可能なすべてを反復する強引なソリューションが排除されます。`k`単純な線形探索でも実行可能な時間制限を超えるためです。 

重要な、明白ではないエッジケースは、次のような場合に発生します。`x`等しい`y`。 もし`x = y`、 それから`(x + k) ⊕ (y + k)`常にそうなります`0`誰にとっても`k`、 その間`(x + k) + (y + k)`常にポジティブです。 たとえば、次の場合`x = y = 6`、有効なものはありません`k`、その答えは次のようになります。`-1`。 と仮定する素朴な解決策`k = 0`は常に有効です。ここでは失敗します。 別の微妙なケースが発生するのは、`x`そして`y`単一ビットのみが異なるため、次の選択に影響します。`k`。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのことを繰り返すことになります。`k`値、計算`(x+k) + (y+k)`そして`(x+k) ⊕ (y+k)`、最初のを返します`k`それは等式を満たします。 これはあらゆる可能性をチェックするため、正確性を保つために機能しますが、実行不可能です。`k`まで上がります`10^18`、それほど多くの候補を探索する方法はありません。 制限さえする`k`ソリューションには非常に大きなデータが必要になる可能性があるため、より小さい範囲に設定すると失敗する可能性があります。`k`。 

重要な洞察は、XOR 演算の分析から得られます。 アイデンティティ`(a + b) = a ⊕ b + 2*(a & b)`任意の整数に当てはまります`a`そして`b`。 これを問題に適用すると、`(x + k) + (y + k) = (x + k) ⊕ (y + k) + 2*((x + k) & (y + k))`。 私たちの平等を保つためには、`2*((x + k) & (y + k)) = 0`、つまり`(x + k) & (y + k) = 0`。 したがって、問題は、`k`そのような`x + k`そして`y + k`重複するビットは設定されていません。 

この観察により、次のことが可能になります。`k`貪欲に: すべてのビット位置に対して、両方が`x`そして`y`持っています`1`に十分な量を追加する必要があります。`k`そのうちの 1 つを「引き継ぎ」、確実に`(x + k)`そして`(y + k)`2つもない`1`一致します。 バイナリ表現を処理することで、有効な`k`効率的に。

 ## アルゴリズムのチュートリアル

 1. もし`x`等しい`y`、 戻る`-1`。 いいえ`k`この場合、等式を満たします。`(x+k) ⊕ (y+k)`常にそうなります`0`、合計はゼロではありません。 
2. 絶対差を計算します`d = y - x`。 推測できます`y > x`交換によって一般性を失うことなく。 
3. 次のことを確認します。`d`は、各設定ビットが次の位置に対応するように、2 のべき乗の合計として表すことができます。`x`持っています`0`。 これにより、追加が保証されます。`k`重複は生じません`1`の同じビット位置にある`x+k`そして`y+k`。 
4. 構築する`k`として`d`。 具体的に選ぶと、`k = d`もし`(x & d) == 0`。 この場合、追加すると、`k`に`x`すでに存在するビットを反転しません`1`で`x`、確保する`(x+k) & (y+k) = 0`。 
5. もし`(x & d) != 0`、最も簡単な保証されたアプローチは次のとおりです。`k = 2^ceil(log2(max(x, y)))`マイナス`x`または別の建設的な値。 ただし、最小の非負`k`満足のいく`(x+k) & (y+k) = 0`上記のビット単位のアライメントを使用して常に取得できます。 
6. 構築したものを返却します`k`。 

不変式は`(x+k) & (y+k) = 0`。 2 つの数値の合計と XOR は AND の 2 倍だけ異なるため、AND がゼロであることを確認することで等しいことが保証されます。 追加することで`k`両方の数字が最初にある位置に`0`s、この不変条件を維持します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x, y = map(int, input().split())
        if x == y:
            print(-1)
            continue
        if x > y:
            x, y = y, x
        d = y - x
        if (x & d) == 0:
            print(d)
        else:
            k = 0
            bit = 1
            while (x + k) & (y + k):
                while x & bit or y & bit:
                    bit <<= 1
                k += bit
            print(k)

if __name__ == "__main__":
    solve()
```最初のセクションでは、テスト ケースの数を読み取り、それらをループします。 それぞれのケースで、`x == y`すぐにエッジケース。 核となる洞察は次のとおりです`(x & d) == 0`、追加するかどうかを検出します`d`重複するビットが生成されます。 そうでない場合は、`d`それ自体は有効です`k`。 それ以外の場合は、`k`重複を避けるために安全に追加できる最下位ビットを見つけて繰り返し実行します。
