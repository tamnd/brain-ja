 ## 解決策
 ## 問題の理解

 指定された配列内に少なくとも 1 つの「カラフルな」サブ配列を作成するために必要な隣接スワップの最小数を決定するように求められます。 カラフルな部分配列は正確な長さです`k`からのすべての整数が含まれます`1`に`k`まさに一度。 配列`a`長さの`n`繰り返しの要素を含めることができますが、次のすべての整数は`1`に`k`が少なくとも 1 回出現するため、最終的にはカラフルな部分配列を形成できることが保証されます。 

入力は複数のテスト ケースで構成され、それぞれが配列の長さを指定します。`n`、ターゲットのサブ配列のサイズ`k`、および配列自体。 出力はテスト ケースごとに 1 つの整数、つまりカラフルなサブ配列を生成するための隣接するスワップの最小数です。 

制約により許可されるのは、`n`すべてのテスト ケースで最大 400,000 件。 これにより、考えられる長さのすべての部分配列を検査する総当り的なアプローチが即座に排除されます。`k`または、操作の数が爆発的に増加するため、すべてのスワップを個別にシミュレートします。 O(n・k) 時間ですべての部分配列を反復する単純な解決策は、非常に遅すぎます。 

エッジ ケースには、一部の位置がすでにカラフルになっている配列、数値のすべてのインスタンスが先頭または末尾でクラスター化されている配列、単一の数値の重複が複数ある配列など、それらを分離するために数回の交換が必要な配列が含まれます。 たとえば、配列`[1, 1, 2, 2, 3]`と`k=3`最初はカラフルではありませんが、2 回の交換で次のように変換できます。`[1, 2, 3]`。 

## アプローチ

 ブルートフォースソリューションでは、一定の長さのウィンドウをスライドさせることになります。`k`配列全体で各数値の出現を数えます。 ウィンドウに数値が欠落している場合、または重複がある場合は、隣接する要素を交換して修正しようとします。 これは原理的には正しいですが、すべてのウィンドウをチェックしてスワップをシミュレートすると O(n・k) 操作が必要になり、これでは遅すぎます。`n`400,000まで。 

最適なアプローチでは、貪欲な戦略と計数のトリックを活用します。 重要な観察は、**カラフルな部分配列を形成するための最小スワップ数は、ある理想的な配列の中で各数値がターゲット位置からどれだけ離れているかによって決まるということです。`1..k`**。 スワップを明示的にシミュレートする代わりに、次のことができます。 

1. からの各整数の回数を数えます。`1`に`k`**候補シーケンス内の各数値の最後に出現する**。 
2. 最初に出現したものから開始します。`1`貪欲に連続したシーケンスを形成しようとします`1..k`アレイ内を前方に歩くことによって。 
3. シーケンス内で数値が欠落するたびに、その数値をウィンドウに近づけるために交換が必要であることがわかります。 したがって、必要なスワップの総数は、完全なシーケンス内の位置に対して順序が狂っている要素の数に等しくなります。 

洞察としては、1..k** の **既に順序付けられている最も長いサブシーケンスのみが重要であるということです。 スワップの最小数は次のとおりです`k`minus the length of this subsequence. マップを使用して数値の最新の位置を追跡すると、O(n) の 1 回のパスで最適なサブシーケンスを決定できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | Brute Force Sliding Window | O(n・k) | O(k) | 遅すぎる |
 | Greedy Longest Ordered Subsequence | O(n) | O(k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 辞書を初期化する`last_pos`各数値をマッピングする`1..k`に`-1`最後に見た位置を記録します。 
2. カウンタの初期化`length`すでに順序付けされている最長のサブシーケンスの長さを追跡します。 
3. 配列を反復処理する`a`:

 1.要素の場合`x`インデックスで`i`の最後の位置を確認してください。`x-1`で`last_pos`。 
2. もし`x`は`1`または`last_pos[x-1] < i`、増分`length`のために`x`に対して 1 ずつ`x-1`。 
3.アップデート`last_pos[x] = i`。 
4. 配列全体を処理した後、`length`の最長の順序付けされたサブシーケンスの長さが含まれます。`1..k`。 
5. 必要なスワップの最小数は次のとおりです。`k - length`。 

機能する理由: すでに注文されているシーケンスはスワップする必要がありません。 欠落している要素や順序が狂っている要素はそれぞれ、正しい相対位置に移動する必要があります。これは、隣接するスワップで実現できます。 スワップは要素を一度に 1 位置ずつ移動するだけなので、移動の最小数は、最も長い順序のサブシーケンスに含まれない要素の数に正確に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    # Track the length of the longest subsequence ending at each number
    dp = [0] * (k + 2)  # dp[x] = length of subsequence ending with x
    pos = [-1] * (k + 2)
    
    for idx, val in enumerate(a):
        if val == 1:
            dp[1] = max(dp[1], 1)
        else:
            dp[val] = max(dp[val], dp[val - 1] + 1)
    
    min_swaps = k - dp[k]
    print(min_swaps)
```コードは動的プログラミング配列を使用します`dp`どこ`dp[x]`数字で終わる最長のサブシーケンスの長さを表します`x`。 のために`1`、シーケンスは長さ 1 で始まります。数値の場合`2..k`からシーケンスを拡張します。`x-1`もし可能なら。 スワップの最小数は、`k`そしてすでに続く最長のシーケンス`1..k`。

import sys, io

            else:
                dp[val] = max(dp[val], dp[val-1] + 1)
        res.append(str(k - dp[k]))
    return '\n'.join(res)
