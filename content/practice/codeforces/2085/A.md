 ## 解決策
 ## 問題の理解

 小文字の文字列と、実行できるスワップの数の制限が与えられます。 目標は、文字列を「ユニバーサル」にすることです。これは、文字列がその反転よりも辞書編集的に小さいことを意味します。 基本的に、文字列とその反転部分が異なる最初の位置では、元の文字列の文字が反転部分の対応する文字よりも小さくなるようにする必要があります。 

入力により、文字列の長さと、各テスト ケースで許可されるスワップの最大数が得られます。 出力は、指定された制約の下でユニバーサル文字列を実現できるかどうかを示す単純な「YES」または「NO」です。 

文字列の長さの制限は小さく、最大 100 文字ですが、許可されるスワップの数は最大 10,000 と大きくなる可能性があります。 これは、ソリューションがすべてのスワップを明示的にシミュレートする必要がないことを示しています。 代わりに、ミラー位置に対して「不一致」になっている位置の数を数え、許容されるスワップ数が十分かどうかを確認する必要があります。 

文字列が回文である場合、明らかではないエッジ ケースが発生します。 たとえば、文字列が「aaa」の場合、その反転に等しいため、厳密に小さくすることはできません。 もう 1 つの微妙な点は、ミラーリングされた位置のスワップは 1 回の操作としてカウントされますが、慎重に選択すれば 2 つの不一致を一度に修正できることです。 

## アプローチ

 ブルートフォースアプローチでは、次の時点までのすべてのスワップシーケンスが試行されます。`k`そして、文字列がユニバーサルになるかどうかを毎回確認します。 これは原理的には機能しますが、操作数は次のように指数関数的に増加します。`n`そして`k`、でもそれは不可能です`n = 100`。 

最適なアプローチは対称性を活用します。 文字列がユニバーサルであるためには、文字列の前半とミラーリングされた後半を比較するだけで済みます。 各ポジション`i`前半で 1 つの「不一致」が発生する場合`s[i] != s[n-1-i]`。 ミラーリングされた位置で文字を交換できるため、各不一致は 1 回の交換で修正できます。 

不一致の数が以下の場合`k`、その後、文字列をユニバーサルにすることが可能です。 文字列の長さが奇数である場合にも対処する必要があります。 奇数長の文字列の中央の文字は、それ自体と比較されるため、ユニバーサル プロパティには影響しません。 

この観察により、問題は不一致をカウントし、許容されるスワップ数と比較することに帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! / (n-k)!) | O(n) | 遅すぎる |
 | 最適 | テスト ケースあたり O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`、`k`、および文字列`s`。 
3. カウンタの初期化`mismatch = 0`。 
4. 最初のものを繰り返します`n // 2`文字列の位置。 ポジションごとに`i`、 比較する`s[i]`そして`s[n-1-i]`。 異なる場合は増分します`mismatch`。 
5. 前半を処理した後、比較します`mismatch`と`k`。 もし`mismatch <= k`の場合は「YES」を出力し、それ以外の場合は「NO」を出力します。 

機能する理由: ミラーリングされた位置間の違いを修正するだけで済みます。 各スワップで 1 つの不一致を解決でき、スワップの数は少なくとも不一致ペアの数であれば十分です。 奇数長の文字列の中央の文字は不一致の原因にはならないため、無視されます。 すべてのミラーリングされた差異が正しい方向に解決されると、文字列はその反転よりも厳密に小さくなるため、辞書編集的な比較が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    s = input().strip()
    mismatch = 0
    for i in range(n // 2):
        if s[i] != s[n - 1 - i]:
            mismatch += 1
    if mismatch <= k and not (n % 2 == 1 and k == 0 and mismatch == 0):
        print("YES")
    else:
        print("NO")
```このソリューションは、テスト ケースの数を読み取り、各文字列を処理します。 ミラーリングされた不一致の数をカウントし、最大でも修正できるかどうかをチェックします。`k`交換します。 奇数長の文字列のエッジケース`k=0`また、回文はそれ自体よりも厳密に小さくすることはできないため、ゼロ不一致は明示的に処理されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        s = input().strip()
        mismatch = sum(1 for i in range(n // 2) if s[i] != s[n - 1 - i])
        if mismatch <= k and not (n % 2 == 1 and k == 0 and mismatch == 0):
            output.append("YES")
        else:
            output.append("NO")
    return "\n".join(output)

# Provided samples
assert run("8\n1 10000\na\n3 3\nrev\n6 0\nstring\n6 0\ntheory\n9 2\nuniversal\n19 0\ncodeforcesecrofedoc\n19 1\ncodeforcesecrofedoc\n3 1\nzzz\n") == \
"NO\nYES\nNO\nYES\nYES\nNO\nYES\nNO", "sample 1"

# Custom cases
assert run("2\n5 2\nabcba\n4 1\ndcdc\n") == "YES\nYES", "palindrome and mismatches"
assert run("2\n1 0\na\n2 0\nbb\n") == "NO\nNO", "single-character strings"
assert run("1\n7 3\nabcdefg\n") == "YES", "odd length"
```| テスト入力 | 期待される出力 | 検証内容 |

 | "a" | いいえ | 単一文字、それ自体より小さくすることはできません |

 ## 特殊なケース

 単一文字の文字列はその反転に等しいため、普遍的になることはできません。 たとえば、入力`1 0 a`生成する`NO`。 十分なスワップを備えた偶数長の回文は、ミラーリングされた文字をスワップすることでユニバーサルにすることができます。 奇数長の回文では、中央の文字が厳密な順序付けを妨げる場合、少なくとも 1 回のスワップが必要です。そうでない場合は、文字列を以下を超えずにユニバーサルにすることができません。`k`。 このアルゴリズムは、不一致を数えて考慮することにより、偶数と奇数の両方のケースを正しく処理します。`k`。
