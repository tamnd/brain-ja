 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、`n`頂点。接続されたグラフを意味します。`n-1`エッジがあり、サイクルはありません。 木とともに私たちに与えられたのは、`m`パス。それぞれ 2 つのエンドポイントによって指定されます`u`そして`v`。 パスは、暗黙的に、間の最短パスに沿った一意の頂点のシーケンスです。`u`そして`v`木の中で。 私たちの目標は、**正確に 1 つの頂点**で交差するパスのペアが何組あるかを数えることです。 

入力サイズが大きい: どちらも`n`そして`m`まで行くことができます`3 * 10^5`。 すべてのパスのペアを直接比較する単純なアプローチでは、次のことが必要になります。`O(m^2)`操作、おおよそ最大`10^11`6 秒の制限時間内での実行可能な限界をはるかに超えた計算。 したがって、線形に近いアプローチが必要です。`n`そして`m`。 

複数のパスが共通の頂点、特にルートまたはリーフを共有する場合、明らかではないエッジ ケースが発生します。 たとえば、すべてのパスが頂点 1 を通過する場合、パスのすべてのペアはそこで交差します。 エンドポイントのみをチェックする不注意な実装では、そのようなケースが誤ってカウントされます。 もう 1 つの微妙なケースは、パスがツリーに沿って複数の頂点を共有する場合に発生します。 たとえば、パス`(1,3)`そして`(2,3)`頂点 3 と 1 → 3 を共有します。これを確認するだけでは単純なカウントがオーバーカウントする可能性があります。`set(path1) & set(path2)`交差点が正確​​に 1 つの頂点であることを確認せずに。 

## アプローチ

 ブルートフォースアプローチはすべてを反復します`m*(m-1)/2`パスのペアを作成し、それらの交差を明示的に計算します。 各パスを頂点のセットとして表し、交差点を数えます。 この方法は正しいですが、明らかに非現実的です。すべてのパスを構築することは困難になる可能性があります。`O(n)`それぞれ、交差点を比較するのは`O(n)`同様に、`O(m^2 * n)`最悪の場合の複雑さ。 

最適な解決策につながる重要な観察は、ツリー内では、任意の 2 つのパスが単一の頂点または接続されたパス (チェーン) で交差するということです。 これは、一対のパスが 1 つの頂点で交差するためには、一方のパスがそれ以上重なり合うことなく 1 点でもう一方のパスに「入る」必要があることを意味します。 **ツリー構造と LCA (最低共通祖先)** 技術を、ツリーのエッジで **差分配列を使用したパスカウント**と組み合わせて活用できます。 各パスを明示的に実体化する代わりに、ツリー内の各パスの開始と終了をマークし、深さ優先検索を使用してカウントを上方に伝播します。 次に、頂点ごとに、さまざまな分岐からの数を組み合わせることで、その頂点でのみ交差するパスのペアの数を計算できます。 

ツリー分解技術、オイラー ツアー、または重光分解を活用することで、交差するペアの正確な数をおおよその時間で効率的に計算できます。`O(n + m)`時間。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(m^2 * n) | O(n * m) | 遅すぎる |
 | 最適 (DFS + 差分カウント) | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ツリーを読み取り、すべての頂点の隣接リストを作成します。 これは、すべてのパス クエリの基礎となる構造を表します。 
2. ツリーを前処理して、頂点の任意のペアの **最低共通祖先 (LCA)** を計算します。 これは、バイナリリフティングを使用して実行できます。`O(n log n)`時間。 LCA を使用すると、パスがツリー内のどこに分岐し、どこから分岐するかを効率的に判断できます。 
3. 配列を初期化する`count[v]`頂点ごとに`v`通過するパスの数を追跡する`v`。 
4. パスごとに`(u, v)`、増分`count[u]`そして`count[v]`、および減少`count[lca(u,v)]`そして`count[parent[lca(u,v)]]`それが存在する場合。 この「差分配列」アプローチにより、パスに沿ったすべての頂点を明示的にリストすることなく、各パスの寄与をマークすることができます。 
5. ツリー上で DFS を実行して、カウントをリーフからルートに伝播します。 各頂点で`v`、`count[v]`通過するパスの総数を表します`v`。 これらの数を使用して、正確に交差するパス ペアの数を計算します。`v`次のように:`k`道が通ります`v`同じサブツリー内で重複することなく、それらは形成されます。`k*(k-1)/2`ペア。 過剰なカウントを避けるために、同じブランチ内で重複するパスのカウントを調整します。 
6. すべての頂点からの寄与を合計して、正確に 1 つの頂点で交差するペアの総数を取得します。 

**これが機能する理由:** ツリーでは、2 つのパスは互いに素であるか、頂点チェーンを共有しているか、または 1 つの頂点で交差しています。 頂点を通るパスをカウントし、共有ブランチに沿って重複するパスを減算することにより、アルゴリズムは有効な各ペアが 1 回だけカウントされるようにします。 差分配列と DFS は、すべてのパスと頂点のペアを明示的に訪問することなく、パスの寄与を効率的に伝播します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

n = int(input())
adj = [[] for _ in range(n)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

LOG = 20
parent = [[-1]*n for _ in range(LOG)]
depth = [0]*n

def dfs(u, p):
    parent[0][u] = p
    for v in adj[u]:
        if v != p:
            depth[v] = depth[u] + 1
            dfs(v, u)
dfs(0, -1)

for k in range(1, LOG):
    for v in range(n):
        if parent[k-1][v] != -1:
            parent[k][v] = parent[k-1][parent[k-1][v]]

def lca(u, v):
    if depth[u] < depth[v]:
        u, v = v, u
    for k in reversed(range(LOG)):
        if parent[k][u] != -1 and depth[parent[k][u]] >= depth[v]:
            u = parent[k][u]
    if u == v:
        return u
    for k in reversed(range(LOG)):
        if parent[k][u] != parent[k][v]:
            u = parent[k][u]
            v = parent[k][v]
    return parent[0][u]

m = int(input())
count = [0]*n
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    w = lca(u, v)
    count[u] += 1
    count[v] += 1
    count[w] -= 1
    if parent[0][w] != -1:
        count[parent[0][w]] -= 1

res = 0
def dfs2(u, p):
    global res
    subtotal = 0
    for v in adj[u]:
        if v != p:
            child = dfs2(v, u)
            subtotal += child
    subtotal += count[u]
    # each vertex contributes C(subtotal, 2) pairs passing through it
    global_pairs = subtotal * (subtotal - 1) // 2
    # remove pairs counted in children
    child_pairs = 0
    for v in adj[u]:
        if v != p:
            c = count[v]
            child_pairs += c * (c - 1) // 2
    res += global_pairs - child_pairs
    count[u] = subtotal
    return subtotal
dfs2(0, -1)
print(res)
```最初の DFS は、LCA クエリのバイナリ リフティングを設定します。 次に、各パスは差分配列方式でエンコードされ、開始点と終了点がマークされてから、LCA の寄与を補正します。 2 番目の DFS は、パス カウントを伝播し、組み合わせカウントを使用して正確に 1 つの交差を計算し、子サブツリーから過剰にカウントされたペアを減算します。
