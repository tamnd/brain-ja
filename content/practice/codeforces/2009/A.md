 ## 解決策
 ## 問題の理解

 複数の独立したクエリが与えられます。 各クエリは 2 つの整数を提供します`a`そして`b`、任意の整数を選択できます`c`それらの間の包括的な範囲内。 それぞれの選択に対して、`c`からの距離として定義されるコストを計算します。`a`に`c`そこからの距離を加えたもの`c`に`b`。 

幾何学的に、これは点を配置するようなものです`c`間の数直線上のどこか`a`そして`b`からの移動距離を測定します`a`に`b`経由`c`。 課題は選択することです`c`この総旅費が最小になるように計算し、その最小値を出力します。 

制約は非常に小さいです。両方とも`a`そして`b`は最大でも 10 個であるため、可能性のあるすべてを総当たりチェックしても`c`値は些細なものになります。 ただし、ここでは計算よりも構造を認識することが重要です。 

素朴な推論における微妙な落とし穴は、最良のものを仮定することです`c`位置によって異なるか、検索が必要です。 もう 1 つは、中間点または特別な値をテストして「最適化」を試みることです。 式はキャンセルを隠すため、そのようなヒューリスティックは実際には定数であるものを過度に複雑にする可能性があります。 

## アプローチ

 ブルートフォースソリューションでは、考えられるすべてのことを繰り返すことになります。`c`間`a`そして`b`、計算する`(c - a) + (b - c)`、そして最小限のものを取ります。 これは範囲が狭いため機能しますが、重要な観察がわかりにくくなります。 

式を展開すると、その構造が明らかになります。`(c - a) + (b - c) = c - a + b - c = b - a`変数`c`完全に消えます。 これは、すべての有効な選択肢を意味します。`c`まったく同じ値が生成されます。 コストは決定に依存しないため、実行する最適化はありません。 

ブルートフォースは冗長なケースを評価するため機能しますが、すべてのケースが同一であることを明らかにすることはできません。 中項が相殺されるという観察により、問題を直接の減算に還元することができます。

 | ブルートフォース | O(b - a + 1) | お(1) | 受け入れられるが不要 |
 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 最適な解決策は、式を単純化することで直接得られます。 

1. 整数の読み取り`a`そして`b`テストケースごとに。 これらはセグメントのエンドポイントを定義します。 
2. 差を計算します`b - a`。 これは、エンドポイント間の合計距離を表します。 
3. この値をすぐに出力します。 依存性なし`c`簡略化後も残ります。 

重要な考え方は、考えられるすべての選択肢が、`c`同じ代数的キャンセルを引き起こすため、入力を読み取る以外に意思決定のステップはありません。 

### なぜ効果があるのか

 表現`(c - a) + (b - c)`常に次のように単純化されます`b - a`なぜなら、`+c`そして`-c`条件は正確にキャンセルされます。 この恒等式はすべての整数に当てはまりますので、`c`、有効なすべての最小値`c`もです`b - a`であり、結果を改善または悪化させる代替構成はありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    print(b - a)
```実装は派生を直接反映します。 各テスト ケースは独立しているため、ループで処理します。 引き算`b - a`は目的関数の完全に単純化された形式であるため、検索や分岐は必要ありません。 些細なケースを超えるエッジケースはありません。`a == b`、正しくゼロが生成されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

テスト ケースごとに 1 回の減算のみを実行するため、解は容易に制限内に収まります。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline
    
    t = int(input())
    out = []
    for _ in range(t):
        a, b = map(int, input().split())
        out.append(str(b - a))
    return "\n".join(out)

# provided samples
assert run("""3
1 2
3 10
5 5
""") == """1
7
0"""

""") == "0", "single point"

""") == """1
0""", "mixed small ranges"

assert run("""2
1 10
10 10
""") == """9
0""", "boundary ranges"

 ## 特殊なケース

 唯一明白ではないエッジケースは次のような場合です。`a == b`。 その場合の範囲は、`c`単一の値に折りたたまれ、式は 0 に評価されます。 式`b - a`になるため、これは自然に処理されます`0`、特別な分岐なしで正しい結果と一致します。
