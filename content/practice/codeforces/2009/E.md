 ## 問題の理解

 から始まる厳密に増加する整数シーケンスを含む概念配列が与えられます。$k$そして終わる$k+n-1$。 Klee は、プレフィックスの合計と残りのサフィックスの合計の間の絶対差が最小になるように、配列のプレフィックスを選択したいと考えています。 入力により提供されるのは、$n$、配列の長さ、および$k$、開始整数。 出力は、プレフィックス長の任意の選択によって達成可能な最小絶対差です。$i$。 

問題の規模は極端です。$n$そして$k$それぞれ最大で可能です$10^9$、最大で$10^4$テストケース。 これにより、配列要素を反復処理したり、各プレフィックスの合計を明示的に計算したりするソリューションは除外されます。 代わりに、ソリューションは、テスト ケースごとに一定時間で結果を計算できる、閉じた形式の公式または数学的推論に依存する必要があります。 

次の場合、微妙なエッジケースが発生します。$n$偶数と奇数です。 小型用$n$、手動チェックでは、絶対的な差が次のように異なることを確認できます。$i$、プレフィックスとサフィックスの合計が最もバランスがとれたときに最小値が発生します。 非常に大きい場合$n$等差数列の合計を計算するときは、整数のオーバーフローを避けるように注意する必要があります。 

## アプローチ

 ブルートフォースのアプローチは簡単です。反復します。$i$から$1$に$n$、最初の合計を計算します。$i$要素と残りの合計$n-i$要素を抽出し、絶対差の最小値を追跡します。 正しいとはいえ、このアプローチは大規模な企業にはまったく実行不可能です。$n$が必要になるため、$O(n)$テストケースごとの操作は遅すぎます$n$まで$10^9$そして$t$まで$10^4$。 

重要な観察は、等差数列の合計は次の式を使用して直接計算できることです。$S = \frac{\text{length} \cdot (\text{first element} + \text{last element})}{2}$。 これを使用すると、長さのプレフィックスの合計$i$は$(i/2) \cdot (2k + i - 1)$、および長さの接尾辞の合計$n-i$は$((n-i)/2) \cdot (2(k+i) + n-i - 1)$。 絶対差は次の二次関数になります。$i$。 この二次方程式は凸であるため、その最小値は頂点 (標準の二次方程式で計算) または最も近い整数で発生します。 これにより、次の最小値を計算できます。$O(1)$テストケースごとに。

 ## アルゴリズムのチュートリアル

 1. 等差級数の公式を使用して配列の合計を計算します。$S = n \cdot (2k + n - 1)/2$。 この合計は、プレフィックスの合計からサフィックスの合計を計算するために必要です。 
2. プレフィックス長の絶対的な違いを認識します。$i$次のように書くことができます$|2 \cdot \text{prefix_sum}(i) - S|$。 
3. プレフィックスの合計を次のように計算します。$\text{prefix_sum}(i) = i \cdot (2k + i - 1)/2$。 絶対差の公式に代入すると、$x(i) = |i \cdot (2k + i - 1) - S/1|$。 
4. 治療する$x(i)$の凸関数として$i$。 放物線の頂点は次の位置に発生します。$i \approx (S - k \cdot n)/n$、これは次の導関数を設定することで導出されます。$i(2k + i - 1) - S/1$ゼロに。 以来$i$整数でなければなりません$[1, n]$、 評価する$x(i)$頂点に最も近い 2 つの整数で。 
5. これら 2 つの値の最小値をテスト ケースの結果として返します。 

機能する理由: 問題は、プレフィックスとサフィックスの合計のバランスを取ることにあります。 絶対差分関数は整数に対して凸であり、実数値の最小値に最も近い 2 つの整数を評価することで、真の最小整数解が保証されます。 これにより、すべてのプレフィックスの反復処理が回避され、等差数列の式が活用されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        total = n * (2 * k + n - 1)  # total sum multiplied by 2
        # vertex of quadratic: prefix_sum * 2 - total = 0 => prefix_sum = total/2
        # prefix_sum = i*(2k + i -1)
        # Solve i^2 + (2k -1)i - total/2 =0
        # Quadratic formula: i = (-(2k -1) + sqrt((2k -1)^2 + 2*total))/2
        # We'll use integer arithmetic to avoid floating point
        import math
        a = 1
        b = 2*k - 1
        c = -total // 2
        # compute sqrt carefully
        disc = b*b - 4*a*c
        sqrt_disc = int(math.isqrt(disc))
        i_real = (-b + sqrt_disc) // (2*a)
        # check i_real and i_real +1 to cover rounding
        candidates = [i_real, i_real + 1]
        res = None
        for i in candidates:
            if 1 <= i <= n:
                prefix_sum = i*(2*k + i -1)
                diff = abs(prefix_sum - total//2)
                if res is None or diff < res:
                    res = diff
        print(res)

solve()
```このソリューションは、浮動小数点エラーを回避するために整数演算を慎重に処理し、凸関数の頂点を計算し、この頂点に最も近い整数をチェックして最小値が達成されていることを確認します。 使用する`total`2 を掛けると式が簡略化され、分数が不要になります。
