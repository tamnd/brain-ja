 ## 解決策
 ## 問題の理解

 からの数値の順列が与えられます。`1`に`n`。 

操作により、現在値が次の 2 つの位置が選択されます。`a`そして`b`。 もし`a + b`は合成数なので、これら 2 つの値を交換することができます。 

問題は、そのようなスワップを何度でも実行した後、その順列をソートされた順列に変換できるかどうかです。```
1 2 3 ... n
```テストケースの数が多く、すべてのテストケースの合計が`n`値は最大でも`2 · 10^5`。 テスト ケースごとに線形または線形に近いものよりも大幅に遅いソリューションは困難になります。 のようなもの`O(n^2)`テストケースごとのコストはすでに高すぎます。`n`アプローチ`2 · 10^5`。 

興味深いのは、この操作が、交換される値の位置ではなく、交換される値のみに依存することです。 値の場合`x`そして`y`それを満たす`x + y`が複合である場合、これら 2 つの値は順列に出現するたびに交換できます。 

いくつかの小さなケースから構造が明らかになります。 

のために```
n = 2
p = [2, 1]
```唯一のペアは`(1,2)`そして`1 + 2 = 3`、これは素数です。 交換は不可能ですので、答えは次のようになります。`NO`。 

のために```
n = 3
p = [1, 3, 2]
```ペア`(1,3)`交換できるので、`1 + 3 = 4`複合的ですが価値があります`2`孤立している。 以来`2`はすでに正しい位置にあり、並べ替えが可能であり、答えは次のとおりです。`YES`。 

不注意な実装では、すべての順列が 1 回ソート可能であると想定される可能性があります。`n ≥ 3`、これは誤りです。 例えば：```
n = 4
p = [2, 1, 4, 3]
```価値観`{1,3}`一つのグループを形成し、`{2,4}`別のものを形成します。 値は、そのグループ内でのみ移動できます。 位置`1`最終的には価値が必要になる`1`、ただし現在値が含まれています`2`異なるグループからのものであるため、並べ替えは不可能です。 

## アプローチ

 ブルート フォース ビューでは、頂点が値であるグラフを構築します。`1..n`。 2 つの値の合計が合成される場合、2 つの値は接続されます。 許可されるすべてのスワップは、エッジで接続された 2 つの頂点をスワップすることに対応します。 

スワップを繰り返しシミュレーションし、到達可能な順列を探索することができます。 これは小さな入力に対しては正しいですが、状態空間は次のようになります。`n!`, そのため、すぐに絶望的になってしまいます。 

重要な観察は、実際には個々のスワップ シーケンスを気にしていないということです。 

値のグラフを検討してください`1..n`間にエッジが存在する場合`x`そして`y`いつ`x + y`複合です。 

置換グループから得られる古典的な事実は、グラフ コンポーネントが接続されている場合、そのエッジに沿ったスワップにより、そのコンポーネント内の頂点のすべての置換が生成されるということです。 実際には、同じ接続コンポーネント内のすべての値を、そのコンポーネントの値が現在占めている位置の間で任意に再配置できます。 

これにより、問題は関連するコンポーネントの質問に変わります。 

コンポーネントに値が含まれているとします。`{1,3}`。 どの操作でも、このコンポーネントの値を、別のコンポーネントの値が現在占めている位置に移動することはできません。 コンポーネント値が占める一連の位置は永久に変更されません。 

順列を並べ替えるには、値`i`最終的にはその位置に到達しなければならない`i`。 このように、どのポジションでも`pos`、現在の値`p[pos]`そして目標値`pos`同じ接続コンポーネントに属している必要があります。 

残りのタスクは、グラフのコンポーネント構造を理解することです。 

のために`n ≥ 5`、グラフがつながっています。 

2 つの奇数の和は少なくとも偶数であるため、すべての奇数はクリークを形成します`4`、したがって複合です。 

2 つの偶数の和は少なくとも偶数であるため、すべての偶数はクリークを形成します。`4`、したがって複合です。 

価値`5`存在するとき`n ≥ 5`、 そして```
5 + 2 = 7
5 + 4 = 9
```少なくとも 1 つの偶数が奇数クリークに接続され、パリティ グループ間にブリッジが作成されます。 したがって、グラフ全体がつながります。 

唯一の例外的な値は、`n`は：```
n = 1
component: {1}

n = 2
components: {1}, {2}

n = 3
components: {1,3}, {2}

n = 4
components: {1,3}, {2,4}
```これが分かれば、解決策は非常に小さくなります。

 ## アルゴリズムのチュートリアル

 1. 順列を読み取ります。 
2. もし`n = 1`、出力`YES`。 
3. もし`n ≥ 5`、出力`YES`。 

値のグラフは接続されているため、任意の順列を他の任意の順列に変換できます。 
4. もし`n = 2`、それぞれの値は分離されています。 

順列は、すでにソートされている場合にのみソート可能です。 
5. もし`n = 3`または`n = 4`、正確に 2 つのコンポーネントがあります。`A = {1,3}`そして`B = {2,4}`実際に存在する値に限定されます。 
6. ポジションごとに`i`、どうかを確認してください`i`そして`p[i]`同じコンポーネントに属します。 
7. すべての位置がチェックに合格した場合、出力`YES`; それ以外の場合は出力`NO`。 

### なぜ効果があるのか

 接続されたコンポーネントによって、どの値が交換できるかが決まります。 異なるコンポーネントの値がコンポーネントの境界を越えることはできません。 

連結コンポーネント内では、グラフのエッジに沿ったスワップにより、コンポーネントの値の任意の順列が生成されます。 したがって、唯一の障害は、値を別のコンポーネントに属する位置に移動する必要があるかどうかです。 

それを確認する`component(i) = component(p[i])`foreveryposition は、コンポーネント内のスワップのみを使用して、すべての値をターゲットの位置に再配置できることを正確に検証します。 この条件は必要かつ十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))

    if n == 1:
        print("YES")
        continue

    if n >= 5:
        print("YES")
        continue

    ok = True

    for i, x in enumerate(p, start=1):
        if (i & 1) != (x & 1):
            ok = False
            break

    print("YES" if ok else "NO")
```実装はコンポーネントの特性評価に直接従います。 

のために`n = 3`そして`n = 4`、コンポーネントは正確に奇数の値と偶数の値です。 位置を確認中`i`そして価値観`p[i]`同じコンポーネントに属しているということは、それらが同じパリティを持っているかどうかを確認することと同じです。 

のために`n = 2`、同じパリティチェックは引き続き機能します。 位置`1`のみ含めることができます`1`、および位置`2`のみ含めることができます`2`。 

早期の帰国は、`n ≥ 5`が主な最適化です。 グラフが接続されると、すべての順列が並べ替え可能になるため、それ以上の作業は必要ありません。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))

        if n == 1:
            ans.append("YES")
            continue

        if n >= 5:
            ans.append("YES")
            continue

        ok = True
        for i, x in enumerate(p, start=1):
            if (i & 1) != (x & 1):
                ok = False
                break

        ans.append("YES" if ok else "NO")

    return "\n".join(ans)

# provided samples
assert run(

1

2
1 2
4
2 1 4 3
"""
) == "YES\nNO\nYES\nNO"

# minimum size
assert run(
"""1
1
1
"""
) == "YES"

# n = 2 unsorted
assert run(
"""1
2
2 1
"""
) == "NO"

# n = 4 sortable inside components
assert run(

4

"""
) == "YES"

 検討してください```

```グラフには 2 つの孤立した頂点があるため、`1 + 2 = 3`プライムです。 スワップは合法ではありません。 パリティ チェックはすぐに失敗します。```

```アルゴリズムの出力`NO`、それは正しいです。 

ここで考えてみましょう```

```コンポーネントは次のとおりです。`{1,3}`そして`{2}`。

```すべての位置と値は同じコンポーネントに属します。 スワッピング`1`そして`3`それらの合計は次のとおりであるため、許可されます。`4`, したがって、順列を並べ替えることができます。 アルゴリズムの出力`YES`。 

最後に考えてみましょう```
