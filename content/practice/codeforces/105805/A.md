 ## 解決策
 ## 問題の理解

 正の整数が与えられます$n$。 テストケースごとに、整数の数を数えなければなりません$x$満足する$$x + (x \bmod n) = n.$$入力には最大で次のものが含まれます$10^4$テストケースとそれぞれの値$n$と同じ大きさにすることができます$10^{18}$。 有効な整数の数を出力するだけで済みます。$x$テストケースごとに。 

サイズ$n$候補値を 1 つずつ試すアプローチは直ちに除外されます。 すべての値をチェックしても、$0$に$n$いつになったら不可能だろう$n$到達できる$10^{18}$。 解は、答えが一定時間内に計算できるようになるまで、方程式を代数的に操作することによって得られる必要があります。 

いくつかの特殊なケースは見落とされがちです。 

たとえば、次のようなとき$n = 2$、```
x = 1 -> 1 + (1 mod 2) = 2
x = 2 -> 2 + (2 mod 2) = 2
```正解は 2 です。不用意に実装すると、気づくだけになる可能性があります$x=n$そして1を返します。 

のために$n = 3$、```
x = 3 -> 3 + (3 mod 3) = 3
```他の値は機能しないため、答えは 1 です。これは、追加の解が偶数の値に対してのみ表示されることを示しています。$n$。 

のために$n = 1$、```
x = 1 -> 1 + (1 mod 1) = 1
```答えは依然として 1 です。どの式でも、可能な限り最小の入力を正しく処理する必要があります。 

## アプローチ

 最も直接的なアイデアは、可能な限りすべてのことを試してみることです$x$、計算する$x \bmod n$を選択し、方程式が成り立つかどうかを確認します。 

なぜ自分自身を制限できるのですか$x \le n$? なぜなら$x \bmod n$は負ではないので、$x > n$、 それから$$x + (x \bmod n) > n,$$決して方程式を満たすことができません。 

この強引な方法は正しいですが、$n = 10^{18}$おおよそ必要になります$10^{18}$チェックしますが、これは完全に不可能です。 

重要な観察は、次のように書くとモジュロ演算が簡単になるということです。$x$商剰余形式:$$x = qn + r,
\qquad 0 \le r < n.$$それから$$x \bmod n = r.$$方程式に代入すると、$$qn + 2r = n.$$さて、問題は純粋に算術です。 

以来$qn \le n$、商$q$0 または 1 のみを指定できます。 

もし$q = 1$、 それから$$n + 2r = n,$$それで$r = 0$、解決策を与える$$x = n.$$もし$q = 0$、 それから$$2r = n.$$これが可能なのは次の場合のみです$n$は均等です。 その場合、$$r = \frac{n}{2},$$そして$$x = \frac{n}{2}.$$他の値はありません$q$可能であるため、すべてのソリューションを完全に特徴付けました。 

毎$n$解決策があります$x=n$。 偶数の値$n$追加の解決策が 1 つあります。$x=n/2$。

 ## アルゴリズムのチュートリアル

 1. の値を読み取ります。$n$。 
2. かどうかを確認します。$n$奇数か偶数です。 
3. もし$n$は奇数、出力 1。 

唯一の解決策は$x=n$。 
4. もし$n$偶数の場合、出力 2。 

解決策は次のとおりです。$x=n$そして$x=n/2$。 

### なぜ効果があるのか

 執筆$x$として$qn+r$元の方程式を次のように変換します$$qn+2r=n.$$なぜなら$0 \le r < n$、商は 1 を超えることはできません。$q=1$常に収穫する$x=n$。 ケース$q=0$正確に次の場合に 2 番目の解が得られます。$n$は均等です。 これらは考えられる唯一のケースであるため、アルゴリズムはすべての有効な解決策をカウントし、1 つも見逃すことはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    if n % 2 == 0:
        print(2)
    else:
        print(1)
```実装は数学的特徴付けに直接従います。 

必要な操作はパリティをチェックすることだけです。$n$。 いつ$n$が奇数である場合、ソリューション セットには次のものが含まれます。$x=n$。 いつ$n$均等です、$x=n/2$は 2 番目の有効な解決策になります。 

Python の整数は、次の値まで快適にサポートします。$10^{18}$なので、オーバーフローの心配はありません。 実行時間は各テスト ケースで一定です。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        ans.append("2" if n % 2 == 0 else "1")

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out

    solve()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.getvalue()

# provided sample
assert run("2\n1\n3\n") == "1\n1"

# minimum value
assert run("1\n1\n") == "1"

# smallest even number
assert run("1\n2\n") == "2"

# large odd value
assert run("1\n999999999999999999\n") == "1"

# large even value
assert run("1\n1000000000000000000\n") == "2"
