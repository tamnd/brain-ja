 ## 問題の理解

 一連の異なる正の整数が与えられます。 セットは正確に分割する必要があります`k`空ではないサブセット。 各サブセットはその中のすべての数値の gcd に寄与しており、これらの gcd 値の可能な最大合計が必要です。 

数値は個別であり、それぞれの値は最大で`10^6`すべてのテスト ケースにわたって、各テスト ケースに表示される最大値の合計は最大で`10^6`。 この最後の条件が本当のヒントです。 大まかに機能するソリューションを強く提案します`O(M log M)`テストケースごと、ここで`M`セット内の最大値です。 二次アルゴリズム`n`絶望的になるとき`n`それ自体は到達できる`10^6`。 

厄介な点は、パーティションが完全に制限されていないことです。 入力が非常に小さい場合でも、パーティションを直接検索することは不可能です。 

よくある間違いは、gcd 値そのものに注目して、貪欲にサブセットを構築しようとすることです。 パーティション構造は実際には、見た目よりもはるかに単純です。 

セットを検討してください`{3, 5, 6}`と`k = 2`。 

サブセットを選択すると`{5}`そして`{3, 6}`、合計は次のとおりです。`5 + gcd(3, 6) = 5 + 3 = 8`これが最適です。 

2 番目の見落としやすいケースは、ある数値が他の数値を割る場合です。 

のために`{5, 9, 10, 11, 13}`と`k = 4`、置く`10`と共に`5`サブセット gcd は次のようになるため、これは有益です。`5`。 最適なパーティションは次のとおりです。`{13}, {11}, {9}, {5, 10}`与える`13 + 11 + 9 + 5 = 38`常に最大数を分離するという単純な戦略では、その理由が説明されません。`10`の代わりにマージする必要があります`5`。 

## アプローチ

 ブルートフォースのアイデアは単純です。 セットを分割するすべての方法を列挙します。`k`空ではないサブセットの場合、すべてのサブセットの gcd を計算し、最良の答えを保持します。 

すべての有効なパーティションがチェックされるため、これは正しいです。 問題は、パーティションの数が急激に増加することです。 数十の要素であっても、それはすでに不可能です。 

重要な観察は、最適なパーティション内で何が起こっているかを尋ねることから得られます。 

サブセットに少なくとも 2 つの要素が含まれており、その gcd が`g`。 任意の要素を選択します`x`そのサブセットは最小のものではありません。 以来`g`サブセット内のすべての要素を分割すると、`g ≤ x`。 

取り除いたら`x`サブセットからシングルトン サブセットにすると、寄与率は次のように変化します。`g`に`g + x`。 

合計額は少なくとも増加します`x - g ≥ 0`。 

これは、より多くのサブセットを作成できる場合は常に、要素を分離することが決して有害ではないことを意味します。 

正確に終わる必要があるため、`k`サブセットの場合、最適なパーティションには常に次のものが含まれます。`k - 1`シングルトン サブセットと、もう 1 つを含む残りの 1 つのサブセット`n - k + 1`要素。 

させて`m = n - k + 1`。 

残りのサブセットが`R`、その場合、答えは次のようになります`sum(all elements) - sum(R) + gcd(R)`。 

すべての数値の合計は固定されているため、最大化するだけで済みます。`gcd(R) - sum(R)`、

どこ`|R| = m`。 

考えられる gcd 値を修正します`d`。 

もし`gcd(R) = d`、のすべての要素`R`で割り切れる必要があります`d`。 

で割り切れるすべての要素の中で、`d`、最良の選択は明らかに`m`最も小さいものは、`-sum(R)`should be as large as possible.

 したがって、すべての約数について`d`少なくとも`m`集合内の数値は次で割り切れます`d`、計算します`d - (sum of the m smallest present multiples of d)`。 

すべての中で最高の価値`d`最適な補正項を与えます。 

制約の構造により、除数ふるいの解が自然になります。 それぞれについて`d`、その倍数を昇順にスキャンします。 複数は昇順にアクセスされるため、最初の`m`現在の倍数はまさに`m`割り切れる最小の数。

 ## アルゴリズムのチュートリアル

 1. セットを読み取り、合計を計算します。`S`すべての要素の。 
2. しましょう`m = n - k + 1`。 

これは、最適なパーティション内の単一の非シングルトン サブセットのサイズです。 
3. セット内の最大値までのすべての値のプレゼンス配列を構築します。 
4. 考えられるすべての約数について`d`から`1`に`max_value`:

 すべての倍数をスキャンします`d`昇順で。 
5. セット内に倍数が存在する場合は常に、それを累計に加算し、カウンターを増やします。 

倍数は昇順に処理されるため、最初の`m`現在の倍数はまさに`m`分割可能な最小の要素。 
6. カウンターが到達したら`m`、計算する`candidate = d - current_sum`。 

最適値を更新します。 
7. 最終的な答えは次のとおりです。`S + best`。 

### なぜ効果があるのか

 重要な特性は、すべての最適なパーティションを正確なパーティションに変換できることです。`k - 1`単一のサブセットと 1 つのより大きなサブセットを、答えを減らすことなく計算します。 

その変換の後、すべてのソリューションはセットによって一意に記述されます。`R`サイズの`m = n - k + 1`。 

その貢献は、`S - sum(R) + gcd(R)`。 

固定の gcd 値の場合`d`、のすべての要素`R`で割り切れる必要があります`d`。 最大化するには`d - sum(R)`、

 最小限に抑えなければなりません`sum(R)`、つまり、`m`で割り切れる最小の利用可能な数値`d`。 

すべての約数をチェックする`d`考えられるすべての gcd をカバーします。 見つかった最良の値は、まさに達成可能な最大値です。`gcd(R) - sum(R)`。 

したがって、アルゴリズムは常に最適な答えを返します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))

        S = sum(a)
        m = n - k + 1
        mx = max(a)

        present = [0] * (mx + 1)
        for x in a:
            present[x] = 1

        best = -10**18

        for d in range(1, mx + 1):
            cnt = 0
            cur_sum = 0

            for multiple in range(d, mx + 1, d):
                if present[multiple]:
                    cnt += 1
                    cur_sum += multiple

                    if cnt == m:
                        value = d - cur_sum
                        if value > best:
                            best = value
                        break

        ans.append(str(S + best))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```最初の部分では固定数量を計算します。`S`、すべての要素の合計。 

値`m = n - k + 1`これは、最適なパーティションが 1 つのより大きなサブセットで構成されているという構造的な証明から直接得られます。`k - 1`シングルトンのサブセット。 

存在配列を使用すると、値がセットに属しているかどうかを定数時間でチェックできます。 すべての値は個別であるため、ブール配列で十分です。 

各約数について`d`、その多重構造を見ていきます。 走査順序は増加しているため、最初の`m`現在の倍数は自動的に`m`割り切れる最小の数。 並べ替えは必要ありません。 

辿り着く瞬間`m`要素の場合、この除数の最適なサブセット合計はすでにわかっているため、より大きな倍数のスキャンを停止できます。`d`。 

すべての算術演算は Python の整数に快適に適合します。

## 特殊なケース

 次のことを考慮してください。```

```魅力的なアプローチは、最大の要素を分離し、残りがその最小要素に寄与すると仮定することです。 残りのサブセット`{3, 6}`貢献する`3`、偶然最小値になったのではなく、その gcd が正確に最小値になったためです。`3`。 アルゴリズムは除数をチェックします`3`、最初の 2 つの割り切れる要素を見つけます`{3, 6}`、そして正解を得る`8`。 

ここで次のことを考えてみましょう。```
1
5 4
13 11 10 9 5
```最も小さい 2 つの数値をグループ化しても、最適な解は得られません。 残りの最適なサブセットは次のとおりです。`{5, 10}`その gcd は`5`。 アルゴリズムが除数を処理するとき`5`、すぐに 2 つの現在の倍数を見つけて、値を与えます。`5 - (5 + 10) = -10`、これは他のすべての約数よりも優れています。
