 ## 問題の理解

 私たちは、$n \times m$チェス盤と、常に正確に 3 つのセルをカバーするパズルのピース。 

重要な幾何学的観察は、標準のチェス盤のようにボードに色を付けると、すべての有効な駒の配置が同じ色の 3 つのセルをカバーするということです。 その特性が発見されると、元のパッキングの問題は、黒と白のセルの計数の問題になります。 

させて$B$黒セルの数であり、$W$ボード上の白マスの数になります。 

すべてのピースは 1 つの色のセルを正確に 3 つ消費するため、どのソリューションもそれ以上のセルを使用することはできません。$$\left\lfloor \frac{B}{3} \right\rfloor +
\left\lfloor \frac{W}{3} \right\rfloor$$個。 

残りの問題は、この上限が常に達成可能かどうかです。 公式ヒントは建設的な議論を指しています。セルを色で分離した後、各色のクラスが接続されたグリッド グラフを形成します。 接続されたグラフ$k$頂点は、同じサイズの互いに素な接続コンポーネントに分割できます。$3$可能な限り、未使用の頂点を 3 つ未満残してください。 つまり、すべてのカラークラスが正確に実現できるということです。$\lfloor k/3 \rfloor$個。 2 つの色を組み合わせると上限が達成されます。 

ボードのサイズは、計算の観点からすると小さいです。 公式がわかれば、必要な算術演算はわずか数回だけです。 

よくある間違いは、答えが単純であると仮定することです。$\lfloor nm/3 \rfloor$。 色は重要です。 

たとえば、$2 \times 2$ボード：```
B W
W B
```黒のセルが 2 つと白のセルが 2 つあります。$$\left\lfloor \frac{2}{3} \right\rfloor +
\left\lfloor \frac{2}{3} \right\rfloor = 0$$その間$$\left\lfloor \frac{4}{3} \right\rfloor = 1$$したがって、すべての細胞を一緒に処理すると、間違った結果が得られます。 

もう 1 つの簡単な落とし穴は、黒と白のセルの数が異なる場合に発生します。 

のために$3 \times 3$ボード：$$B = 5,\quad W = 4$$そして$$\left\lfloor \frac{5}{3} \right\rfloor +
\left\lfloor \frac{4}{3} \right\rfloor
= 1 + 1 = 2.$$のみを使用する$\lfloor 9/3 \rfloor = 3$答えを過大評価してしまうでしょう。 

## アプローチ

 強引なアプローチでは、ピースの配置を列挙し、最大のパッキングを検索しようとします。 中程度のサイズのボードであっても、可能な構成の数が指数関数的に増加するため、これは実行不可能になります。 

重要な観察により、問題は完全に変わります。 

ボードを市松模様に色付けした後、すべてのピースが同じ色の 3 つのセルを占めます。 これにより、ボードがすぐに 2 つの独立したリソース (黒のセルと白のセル) に分離されます。 

カラークラスに次のものが含まれる場合、$k$セルの場合、各ピースはちょうど 3 つのセルを消費するため、最大でも$\lfloor k/3 \rfloor$その色からピースを形成することができます。 

残りのステップでは、この上限が達成可能であることを証明します。 ヒントの接続性引数は、接続されたセットが存在することを保証します。$k$セルは常に、最大 2 つの未使用セルを残して、可能な限り多くの接続されたトリプルに分割できます。 したがって、各色が正確に寄与します$\lfloor k/3 \rfloor$個。 

残っているのは、黒と白のセルの数を計算することだけです。$$B = \left\lceil \frac{nm}{2} \right\rceil,
\qquad
W = \left\lfloor \frac{nm}{2} \right\rfloor.$$答えは次のようになります$$\left\lfloor \frac{B}{3} \right\rfloor +

 ## アルゴリズムのチュートリアル

 1.読む$n$そして$m$。 
2. セルの総数を計算します。$$S = n \times m$$1. 黒セルの数を計算します。$$B = \frac{S + 1}{2}$$整数の除算を使用します。 

1. 白血球の数を計算します。$$W = \frac{S}{2}$$整数の除算を使用します。 

1. コンピューティング$$\left\lfloor \frac{B}{3} \right\rfloor +
\left\lfloor \frac{W}{3} \right\rfloor.$$1. 結果を出力します。 

### なぜ効果があるのか

 すべての駒は、チェス盤の 1 色の 3 つのセルを正確に占めます。 カラークラス$k$細胞は以上に貢献することはできません$\lfloor k/3 \rfloor$各ピースは 3 つのセルを消費するため、ピースになります。 

カラー クラスは接続されたグリッド グラフです。 接続されたグラフ$k$頂点は、サイズ 3 の接続されたコンポーネントに繰り返し分割して、未使用の頂点を 3 つ未満のままにすることができます。 したがって、各カラークラスは正確に実現できます$\lfloor k/3 \rfloor$個。 

黒と白のマスが独立しているため、最大個数は$$\left\lfloor \frac{B}{3} \right\rfloor +
\left\lfloor \frac{W}{3} \right\rfloor.$$## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

s = n * m
black = (s + 1) // 2
white = s // 2

print(black // 3 + white // 3)
```実装は式に直接に従います。 

表現`(s + 1) // 2`チェッカーボード上の大きい方のカラー クラスを計算します。これは、セルの総数が奇数の場合の黒カウントです。 

表現`s // 2`小さい方のカラークラスを計算します。 

整数を 3 で割ると、各カラー クラスから利用できる完全なトリプルの数が得られます。 これら 2 つの値を加算すると、答えが得られます。 

ループ、再帰、または大規模なデータ構造は必要ありません。
