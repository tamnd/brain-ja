 ## 解決策
 ## 問題の理解

 2 つの端点によって定義される平面内の直線セグメントが与えられます。 この 1 つのセグメントから、新しいセグメントがまったく同じ長さを持ち、両方を無限の線に拡張したときに元のセグメントに対して垂直になるように、別のセグメントを構築する必要があります。 このタスクでは一意の答えは求められません。これら 2 つの幾何学的条件を満たす限り、有効な構成はどれでも受け入れられます。 

各テスト ケースは、元のセグメントの端点の座標を表す 4 つの整数を提供します。 出力は、2 番目のセグメントを形成する別のエンドポイントのペアである必要があります。 新しいセグメントが元のセグメントと交差しなければならない、または元のセグメントと任意の点を共有しなければならないという制限はありません。 

座標境界は大きく、最大で$10^8$入力の大きさで最大$10^9$出力用。 これにより、平面の密な検索または離散化に依存する幾何学的構築が除外されます。 テスト ケースの数は次のように大きくなります。$10^4$したがって、各ケースは数回の算術演算のみを使用して一定時間内に解決する必要があります。 

グリッド内の可能な端点をスキャンして有効な垂直セグメントを検索しようとする単純なアプローチは、たとえ小さな検索スペースであってもすぐに失敗します。$10^5 \times 10^5$テスト ケースごとの候補者は、すでに時間制限を何桁も超えていることになります。 

微妙なエッジ ケースは、元のセグメントが軸に沿っている場合、または非常に大きな傾きがある場合です。 たとえば、セグメントが$(0,0)$に$(1,0)$、有効な答えはすべて縦長で長さがある必要があります。$1$。 浮動小数点演算を使用して方向ベクトルを正規化しようとする不注意な実装では、精度エラーが発生し、垂直または長さの条件を満たさないわずかに不正確な座標が生成される可能性があります。 

もう 1 つのエッジ ケースは、セグメントが非常に長い場合、または負の座標が含まれる場合です。$(-10^8, -10^8)$に$(10^8, 10^8)$。 解決策は、方向ベクトルを計算する際のオーバーフローを回避し、整数の範囲内に収まらなければなりません。 

## アプローチ

 強引なアイデアは、許可された出力範囲内のすべての整数点のペアを考慮し、それらが形成するセグメントが元のセグメントと同じ長さであり、それに垂直であるかどうかを確認することです。 ユークリッド幾何学は明確に定義されており、徹底的な検索により最終的には有効な解決策が見つかるため、これは概念的に機能します。 

ただし、候補セグメントの数は次のとおりです。$O((10^9)^4)$各エンドポイントには 2 つの座標があるため、素朴に扱うと、 妥当なローカル近傍に限定したとしても、テスト ケースごとに依然として多くの可能性が残されています。 この強引なアプローチは、垂直ベクトルの代数構造を無視するため失敗します。 

重要な点は、セグメントはベクトルとして表現できるということです。 元のセグメントに方向ベクトルがある場合$(dx, dy)$の場合、すべての垂直セグメントはそれに直交する方向ベクトルを持たなければなりません。これは、それらの内積が 0 であることを意味します。 2D の標準的な垂直ベクトルは次のとおりです。$(dy, -dx)$または$(-dy, dx)$。 これらは直交性条件を満たすことが保証されています。 

垂直方向ベクトルを修正すると、座標を交換すると二乗ノルムが保持されるため、その長さは自動的に元のセグメントと等しくなります。$dx^2 + dy^2 = dy^2 + dx^2$。 したがって、正規化やスケーリングは必要ありません。 

これにより、問題は単純に垂直ベクトルを計算し、それを平面内の任意の場所に配置するだけになります。 最も単純な選択は、原点に固定してエンドポイントを生成することです。$(0,0)$そして$(dy, -dx)$。

 ## アルゴリズムのチュートリアル

 1. 指定されたセグメントの端点を読み取り、その方向ベクトルを 2 番目の点と最初の点の差として計算します。 これにより、絶対位置を無視して、実際に重要な幾何学的情報が分離されます。 
2. ベクトルを次のようにします。$(dx, dy)$。 たとえば、コンポーネントを交換し、そのうちの 1 つを否定することによって垂直ベクトルを構築します。$(dy, -dx)$。 このステップは、2D の垂直性が 90 度の回転に対応するという事実に基づいています。 
3. 任意の開始点を使用して出力セグメントを構築します。 最も簡単な選択は原点から始めることです$(0,0)$そしてで終わります$(dy, -dx)$。 
4. この 2 点を答えとして出力します。 

原点を選択する理由は、平行移動は長さにも垂直度にも影響しないため、1 つの端点を固定すると不要な自由度が削除されるためです。 

### なぜ効果があるのか

 変革$(dx, dy) \rightarrow (dy, -dx)$両方のベクトルにノルムがあるため、長さの 2 乗が維持されます。$dx^2 + dy^2$。 また、ドット積は次のとおりであるため、直交性も保証されます。$dx \cdot dy + dy \cdot (-dx) = 0$。 出力セグメントはこのベクトルから直接定義されるため、平面内のどこに配置されるかに関係なく、両方の必要な条件が満たされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    x1, y1, x2, y2 = map(int, input().split())
    
    dx = x2 - x1
    dy = y2 - y1
    
    # perpendicular vector
    px, py = dy, -dx
    
    # anchor at origin
    print(0, 0, px, py)
```主要な実装の詳細は、整数演算を使用して差分ベクトルを計算することであり、これにより精度の問題が完全に回避されます。 垂直ベクトルは、直接のスワップと符号変更によって取得されます。これは一定時間であり、指定された制約の下では安全です。 構築は純粋に代数的であるため、負の座標や縮退した傾きに対して特別な処理は必要ありません。

import sys, io

 ## 特殊なケース

 次のような水平セグメントの場合$(0,0)$に$(5,0)$、アルゴリズムは次のように計算します。$(dx, dy) = (5,0)$そして出力$(0,-5)$。 結果として得られるセグメントは長さとともに垂直になります$5$、元の方向との内積はゼロであるため、垂直性が正確に保持されます。 

次のような垂直セグメントの場合$(2,3)$に$(2,10)$、ベクトルは$(0,7)$そして出力は次のようになります$(7,0)$、等しい長さの水平セグメントを生成します。 

次のような負の座標を持つセグメントの場合、$(-3,-4)$に$(1,2)$、ベクトルは次のようになります$(4,6)$そして出力は$(6,-4)$。 2 乗の長さが一致し、内積が 0 になるため、両方の端点が負の場合でも正確であることが確認されます。
