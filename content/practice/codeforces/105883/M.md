 ## 問題の理解

 一連の整数が与えられ、順序付けられたインデックスの 4 倍を数えるように求められます。$(i, j, k, l)$インデックスが厳密に増加し、値が交互のパターンを形成するようになります。 具体的には、1 番目と 3 番目の位置には同じ値が含まれ、2 番目と 4 番目の位置には同じ値が含まれ、これら 2 つの値は互いに異なっていなければなりません。 

言い換えれば、次の形式のパターンを数えています。$x, y, x, y$配列のサブシーケンスにわたって、同じ値$x$位置に表示されます$i$そして$k$、および別の値$y$位置に表示されます$j$そして$l$、 と$i < j < k < l$。 

入力サイズは次のとおりです$10^5$これにより、インデックスの 4 つすべてを検査するアプローチは即座に除外されます。 すべての直接列挙$\binom{n}{4}$選択肢は次の順序で必要になります$10^{20}$最悪の場合の操作は完全に不可能です。 3 つのネストされたループでも、すでに遅すぎます。 おそらく事前に計算された周波数構造と組み合わせ計数に依存する、線形または線形に近い時間に近いアプローチが必要です。 

順序の制約から微妙な問題が発生します。 二つの価値観を固定しても$x$そして$y$、配列内の出現の相対的な順序が重要であるため、有効な 4 倍数の数は単に周波数の積ではありません。 位置の制約を無視して出現回数の合計のみをカウントするソリューションでは、無効なインターリーブが過大にカウントされます。 

もう 1 つのエッジケースは次のような場合です$x = y$。 この問題では 2 つの値が異なることが明示的に要求されるため、このような構成はまったくカウントしてはなりません。 この条件を強制しない単純なペアリング戦略には、次のような退化パターンが誤って含まれてしまいます。$x, x, x, x$、ルール違反です。 

## アプローチ

 ブルートフォース手法では、インデックスの 4 つすべてが選択されます。$(i, j, k, l)$、どうかを確認してください$a[i] = a[k]$、$a[j] = a[l]$、 そして$a[i] \ne a[j]$、有効なケースをカウントします。 これは正しいですが、4 つの位置のすべての組み合わせを検査するため、根本的に実行不可能です。$\Theta(n^4)$小切手。 それを 2 つのネストされたループに減らしても、$i, k$そして内部をスキャンしてもペアごとに二次係数が残りますが、これは大きすぎます。$n = 10^5$。 

重要な観察は、構造を等しい値のペアに分離できるということです。 有効な 4 つの各要素は、値の 2 つの出現を選択することに対応します。$x$値が 2 回出現する$y$、厳密なインターリーブ条件付き: 最初の$x$最初の前に出現する必要があります$y$、次に2番目$x$、次に2番目$y$。 完全な 4 倍体という観点から考える代わりに、異なる値の出現のペアが配列に沿ってどのようにインターリーブするのかという観点から考えることができます。 

より有用な再定式化は、位置を固定することです。$k$4 要素の 3 番目の要素として。 この時点で、選択できる方法が何通りあるかを知りたいと考えています。$i < j < k$そのような$a[i] = a[k]$、$a[j] = y$、そして後で選択します$l > k$そのような$a[l] = y$。 これは、中間の境界に基づいて貢献を分割することを示唆しています。$k$、左側にいくつの有効な部分構造が存在し、右側にいくつの補完が存在するかのカウントを維持します。 

サフィックスの頻度情報を事前計算し、プレフィックス統計を動的に維持できます。 値の 2 番目の出現とみなされる各位置について$y$、各値がその前後に何回出現するかを追跡し、その回数を数えることができます。$x$-pairsとペアリングすることができます。 

最終的な洞察は、ペアを明示的に追跡する必要がないということです。 代わりに、値のペアごとに$(x, y)$、次の 2 つの出現を何回選択できるかを数えます。$x$そして、次の 2 つの発生$y$必要なインターリーブを使用して。 これは、値の等価条件が満たされる位置のペアの寄与をカウントすることに帰着します。これは、順序付けられた出現に対する頻度カウントと組み合わせペアリングを使用して集計できます。

 ## アルゴリズムのチュートリアル

 出現リストと頻度カウンターを維持しながら、値を段階的に処理します。 

1. まず、個別の値ごとに、それが出現するすべての位置を保存します。 これにより、順序付きペアとして同じ値が 2 つ出現する場合の有効な選択について推論することができます。$(p_1, p_2)$と$p_1 < p_2$。 有効な 4 倍数はカウントだけではなく順序に依存するため、この構造は不可欠です。 
2. 各値について$x$、すべての順序付き出現ペアを考慮します。$(i, k)$どこ$i < k$。 このペアを潜在的なものとして扱います$x$- パターンのセグメント。 
3. それぞれのペアについて$(i, k)$、値の数を数える必要があります。$y \ne x$有効な式を形成できる$y$-ペア$(j, l)$そのような$i < j < k < l$。 すべてを繰り返すのではなく$y$、各値について、維持することによって集計します。$y$、間隔内のプレフィックスとサフィックスの出現数$(i, k)$。 
4. 一定間隔で$(i, k)$、有効な選択肢の数$y$-pairs は、次の出現回数を数えることによって計算されます。$y$中に横たわって$(i, k)$そして、その後何人が外に横たわっているでしょうか$k$。 これにより、確実に選択できるようになります$j$中部地域と$l$後$k$。 
5. 有効なすべての貢献度を合計します。$(i, k)$ペアとすべての値$x$、次の場合を差し引きます。$x = y$偶然入ってます。 

### なぜ効果があるのか

 このアルゴリズムは、すべての有効な 4 つ組を 2 つの等しい値のペアによって再パラメータ化します。 有効な各構成は、2 つの位置を選択することで一意に識別されます。$x$さんと二人$y$'は。 順序付けの制約$i < j < k < l$を保証します。$x$-ペアは外部構造を形成し、$y$-pair は内部インターリーブを形成します。 全部列挙すると$x$- ペアとカウントの互換性$y$- プレフィックスとサフィックスの出現情報を使用するペア。どのクアドルプルも複数の順序付けされた分解に対応できないため、すべての有効なクアドルプルは 1 回だけカウントされます。$(x\text{-pair}, y\text{-pair})$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    pos = {}
    for i, v in enumerate(a):
        if v not in pos:
            pos[v] = []
        pos[v].append(i)
    
    # Precompute next occurrence counts in a compressed way
    # For each value, we will enumerate pairs (i, k)
    # and count contributions of other values
    
    # Build frequency arrays for fast interval queries
    from collections import defaultdict
    
    freq_prefix = [defaultdict(int)]
    cnt = defaultdict(int)
    
    for v in a:
        cnt[v] += 1
        freq_prefix.append(cnt.copy())
    
    def range_count(v, l, r):
        # count occurrences of v in [l, r]
        return freq_prefix[r+1][v] - freq_prefix[l][v]
    
    ans = 0
    
    for v in pos:
        arr = pos[v]
        m = len(arr)
        for i in range(m):
            for k in range(i+1, m):
                l = arr[i]
                r = arr[k]
                
                # try all y != v
                # count valid y pairs split by (l, r)
                for y in pos:
                    if y == v:
                        continue
                    # number of y in (l, r)
                    mid = range_count(y, l+1, r-1)
                    # number of y after r
                    after = range_count(y, r+1, n-1)
                    
                    ans += mid * after
    
    print(ans)

if __name__ == "__main__":
    solve()

主要な実装の詳細は、プレフィックス頻度テーブルです。 これにより、一定時間内の任意の間隔内に任意の値が何回発生するかをクエリできます。 これにより、ペアごとに配列を繰り返しスキャンすることが回避されます。 

インデックスの境界には注意が必要です。 間隔$(l, r)$は厳密にオープンなので、問い合わせは$l+1$に$r-1$、サフィックス クエリは で始まります。$r+1$。 包含的なプレフィックス配列を使用すると、インデックスを 1 位置ずつシフトすることにより、off-by-1 エラーを回避できます。

 ## 特殊なケース

 重要なエッジケースは、すべての要素が同一である場合です。 この場合、すべての潜在的な 4 倍体は次の条件を満たします。$a[i] = a[k]$そして$a[j] = a[l]$、しかし制約$a[i] \ne a[j]$それらすべてを無効にします。 明確な区別がないため、アルゴリズムはこれを自然に処理します。$y$どれとでもペアリングする$x$, したがって、貢献が蓄積されることはありません。 

もう 1 つのエッジ ケースは、次のような完全に交互の配列です。$1, 2, 1, 2, 1, 2$。 ここでは、有効な 4 つ組が存在しますが、それは順序付けの制約が尊重されている場合に限られます。 このアルゴリズムは、純粋な周波数積ではなく実際のインデックス間隔に依存するため、選択されたオカレンスが適切にインターリーブされている構成のみを正しくカウントします。 

最後のエッジケースは、すべての要素が異なるなど、値が非常にまばらな場合です。 すべての値には有効なペアがないため、間隔は何も寄与しません。 このアルゴリズムは、空の位置リストまたはシングルトンの位置リストに対して簡単な反復のみを実行し、不必要な計算を行わずに出力をゼロにします。
