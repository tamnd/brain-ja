 ## 解決策
 ## 問題の理解

 平面上の異なる格子点の集合が与えられます。 これらの点から、必ずしも軸が揃っている必要はなく、任意の向きで正方形の頂点として機能する 4 つの点のサブセットは、「良好」であると見なされます。 

タスクは、指定されたセット内にそのような正方形が何個存在するかを直接カウントすることではありません。 代わりに、最初に正確に 1 つの点を削除することを強制され、その後、生き残った点の中に有効な正方形頂点の 4 つ組がいくつ残っているかを数えます。 目標は、この最終カウントができるだけ大きくなるように、削除されたポイントを選択することです。 

ここでのコア オブジェクトは、純粋に距離制約によって定義される幾何学的構造です。すべての辺が等しく、対角線が等しく、対角線が辺より √2 倍長い場合、4 つの点のセットは正方形を形成します。 同様に、隣接する頂点として機能する順序付きの点のペアの場合、残りの 2 つの頂点は 90 度の回転によって一意に決定されます。 

n ≤ 5000、テスト ケースの合計が ≤ 5000 という制約は、テスト ケースごとに O(n² log n) または O(n²) のアプローチが許容されるが、3 次以下のものは存続しないことを示します。 すべての 4 倍数を単純に列挙すると、すでに n⁴ のオーダーになりますが、これは 1 回のテストでもまったく実行不可能です。 

微妙なエッジ ケースは対称性から生じます。単一の正方形は複数の点のペアによって決まります。 各正方形には、順序付けされたエッジを選択するための正確に 4 つの方法があるため、慎重に重複を除去しない限り、単純なカウント方法ではカウントしすぎてしまうことがよくあります。 

もう 1 つの特殊なケースは、削除後のフィルタリングの縮退です。 ポイントは複数の正方形に属している可能性があり、それを削除すると多くの正方形が一度に破壊される可能性があるため、その効果は非常に非局所的になります。 たとえば、多くの正方形が共通の中心または頂点クラスターを共有している場合、その共有点を削除すると、たとえそれが多くの構造に関与していても、数を大幅に減らすことができます。 

## アプローチ

 ブルートフォースのアイデアは簡単です。4 つの点をすべて列挙し、それらがペアごとの距離を使用して正方形を形成するかどうかをテストし、各点を削除して合計を再計算するシミュレーションを行います。 これにより、正方形の定義が直接チェックされ、目的が正確に評価されるため、正しい解がすぐに得られます。 

ただし、コストは法外です。 O(n⁴) 個の 4 倍数があり、テスト ケースごとに、削除された可能性のあるすべての点のカウントを再計算し、別の係数 n を乗算します。 慎重に枝刈りを行ったとしても、n が 5000 に達すると、これは実現可能な限界をはるかに超えて爆発的に増加します。 

重要な構造的観察は、四角形が 4 つの点ではなく 2 つの点のペアから生成できることです。 2 つの点 A と B を正方形の連続する頂点とすると、他の 2 つの頂点は、ベクトル AB を A と B を中心に ±90 度回転することによって一意に決定されます。これにより、問題は点のペアに関する推論と、幾何学的完成の誘導に変換されます。 

正方形を直接列挙する代わりに、候補エッジを列挙します。 各ペア (A、B) について、AB を辺として使用する 2 つの可能な正方形を計算します。 このような各候補正方形は、他の 2 つの計算された点がセット内に存在するかどうかをチェックすることによって検証できます。 これにより、平方列挙が O(n²) 個の候補エッジに減り、それぞれの候補エッジにはハッシュによる O(1) 個のチェックが含まれます。 

すべての正方形を効率的に列挙できたら、各点が参加している正方形の数を計算できます。点を削除すると、その点が含まれている正方形の数が正確に減算されます。 したがって、最適な選択は、正方形への参加が最大になる点です。 

これにより、問題全体が正方形のカウントと頂点ごとの寄与の累積に軽減されます。

 | エッジベースの列挙 | O(n²) | O(n²) | 承認済み |

 ## アルゴリズムのチュートリアル

このタスクを再定式化して、すべての点について、その点を 4 つの頂点の 1 つとして含む正方形がいくつあるかを計算します。 

1. O(1) 存在チェックのためにすべてのポイントをハッシュ セットに保存します。 これが必要なのは、ポテンシャル正方形の残りの 2 つの頂点を生成するときに、その存在を効率的に検証する必要があるためです。 
2. 個別の点 A と B のすべての順序付きペアを反復処理します。A と B を正方形の連続する頂点として扱います。 
3. 各ペア (A、B) について、ベクトル AB = (dx, dy) を計算します。 このベクトルを 2 方向に 90 度回転させると正方形を形成できます。 回転されたベクトルは (-dy, dx) と (dy, -dx) です。 これらは、正方形の 2 つの可能な方向に対応します。 
4. 回転方向ごとに、欠落している 2 つの頂点 C と D を計算します。 

C = A + 回転ベクトル

 D = B + 回転ベクトル

 この考え方は、AB の両方の端点を同じ垂直ベクトルだけ移動すると、回転が正しい場合に正方形であることが保証される平行四辺形が完成するというものです。 
5. C と D の両方が点セットに存在するかどうかを確認します。 そうであれば、有効な正方形が見つかったことになります。 
6. 有効な各正方形は、同じ正方形の異なる有向エッジにより複数回検出されます。 過剰なカウントを避けるために、カウントを保存または更新する前に、4 つの頂点の正規順序付けを使用して表現を正規化します。 
7. 各ポイントのカウンタを維持し、そのポイントが含まれる個別の正方形の数を示します。 新しい正方形が確認されるたびに、4 つの頂点カウンターをすべてインクリメントします。 
8. すべてのペアを処理した後の答えは、正方形の合計数からポイントごとの最大寄与分を引いたものになります。 これは、最も多くの正方形を破壊するポイントを削除することに相当します。 

なぜ効果があるのか:

 すべての正方形には正確に 4 つのエッジがあり、各エッジは 2 つの方向のいずれかを介して正方形を生成できます。 これにより、すべての正方形が完全にカバーされることが保証されます。 検出された各正方形をカウントする前に正規化するため、各正方形は正確に 1 回カウントされます。 頂点ごとの累積は、正方形の入射を正確に追跡します。 ポイントを削除すると、その発生率の値でカウントされた正方形が正確に削除されるため、最終的なカウントを最大化すると、破壊された正方形が最小限に抑えられ、これは参加を最大化することと同じになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = []
    s = set()

    for _ in range(n):
        x, y = map(int, input().split())
        pts.append((x, y))
        s.add((x, y))

    cnt = [0] * n
    idx = {pts[i]: i for i in range(n)}

    seen = set()
    total = 0

    for i in range(n):
        x1, y1 = pts[i]
        for j in range(n):
            if i == j:
                continue
            x2, y2 = pts[j]

            dx = x2 - x1
            dy = y2 - y1

            # rotate 90 degrees: (-dy, dx)
            for rx, ry in [(-dy, dx), (dy, -dx)]:
                c = (x1 + rx, y1 + ry)
                d = (x2 + rx, y2 + ry)

                if c in s and d in s:
                    quad = tuple(sorted([pts[i], pts[j], c, d]))
                    if quad not in seen:
                        seen.add(quad)
                        total += 1
                        cnt[i] += 1
                        cnt[j] += 1
                        cnt[idx[c]] += 1
                        cnt[idx[d]] += 1

    print(total - max(cnt))

t = int(input())
for _ in range(t):
    solve()
```このソリューションでは、計算された頂点が存在するかどうかを一定時間で検証できるように、最初にすべてのポイントのハッシュ セットを構築します。 また、ポイントごとのカウントのために座標を配列位置に変換するインデックス マップも構築します。 

i と j にわたるネストされたループは、すべての有向セグメントを列挙します。 各セグメントについて、2 つの垂直方向がテストされます。 各方向で正方形の完成候補が生成されます。 存在チェックにより幾何学的妥当性が保証されます。 

の`seen`各正方形は異なるエッジや方向を通じて複数回検出されるため、セットは重要です。 4 つの頂点を並べ替えると正規表現が提供されるため、重複が正しく折りたたまれます。 

最後に、各点が参加している正方形の数を計算し、その最大値を減算します。これは、最も多くの正方形を削除する点を削除することに相当します。 

実装の微妙な詳細は、エッジの両方の端点が同じ正方形に寄与するため、カウントを 4 つの頂点すべてにわたって対称的に更新する必要があるのは、正方形ごとに 1 回のみであることです。 正規の重複排除がなければ、過剰カウントにより合計統計と頂点ごとの統計の両方が破損します。

 ## 特殊なケース

 縮退的ですが重要なケースは、多くの候補エッジが同じ正方形を複数回生成する場合です。 アルゴリズムは、頂点を標準ソートしてから頂点を挿入することでこれを処理します。`seen`セット。 頂点 (0,0)、(1,0)、(1,1)、(0,1) を持つ正方形の場合、最終的には 4 つのエッジすべてがそれを生成しますが、最初に見つかった順序のみがカウントされます。 

もう 1 つのケースは、複数の正方形が頂点を共有する場合です。 各正方形はその頂点のカウンターに独立して寄与し、削除するとそれらすべてが一度に正しく減算されます。 たとえば、点が k 個の個別の正方形の一部である場合、各正方形は 1 回だけカウントされ、その 4 つの増分にその頂点が含まれるため、点を削除すると合計がちょうど k だけ減ります。
