 ## 問題の理解

 ## アルゴリズムのチュートリアル

 500000 までのすべての整数の最小素因数を前処理して、任意の数値を O(log n) 時間で因数分解できるようにします。 

私たちはプライムの辞書を維持しています`p`すべての重みを保存するマルチセット構造へ`w`現在アクティブなペアのうち、`v`で割り切れます`p`。 削除をサポートするために、値のどの素数を正確に追跡することもできます。`v`に貢献します。 

### ステップ

 1. アレイを構築する`spf`どこ`spf[x]`の最小の素因数です`x`。 これにより、あらゆるものを高速に分解できます。`v`または`k`。 
2. グローバル ハッシュ マップを維持する`pos`挿入されたペアごとに、`(v, w)`、異なる素因数のリスト`v`。 これは、削除するときに必要です。`(v, w)`どのプライム バケットを更新するかを正確に知っています。 
3. 辞書を管理する`mp[p]`ここで、各エントリは重みの挿入と削除をサポートする最大構造体です。 それぞれ削除が必要となるため、`mp[p]`ソートされたマルチセットとして実装されます (ヒープと遅延削除またはバランスの取れた構造を介して)。 
4.挿入用`+ v w`、因数分解`v`を使用して`spf`そしてその明確な素因数を抽出します。 そのような素数ごとに`p`、 入れる`w`の中へ`mp[p]`。 素数のリストを保存します`pos[(v, w)]`。 
5. 削除の場合`- v w`、取得します`pos[(v, w)]`そして削除します`w`それぞれ対応するものから`mp[p]`。 その後、記録を消去します。 
6. お問い合わせの場合`? k`、因数分解`k`異なる素数に分割します。 素数ごとに`p`分割する`k`で現在の最大値を確認してください。`mp[p]`。 答えは、これらすべての素数の最大値です。 マップ内にそのような素数が存在しない場合、またはすべてのバケットが空の場合は、0 を返します。 

### なぜ効果があるのか

 いつでもペアで`(v, w)`クエリの回答に含まれています`k`まさにいつ`v`少なくとも 1 つの素因数を共有する`k`。 もし`p`が共通素因数である場合、`(v, w)`バケットに貢献します`mp[p]`。 したがって、すべての有効な候補は、次の素数に対応するバケットの少なくとも 1 つに表示されます。`k`。 これらのバケットの最大値を取ると、すべての有効な候補がカバーされ、共有プライム バケットに現れることができないため、無効なペアが含まれることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXV = 500000

spf = list(range(MAXV + 1))
for i in range(2, int(MAXV ** 0.5) + 1):
    if spf[i] == i:
        for j in range(i * i, MAXV + 1, i):
            if spf[j] == j:
                spf[j] = i

def factorize(x):
    primes = []
    while x > 1:
        p = spf[x]
        primes.append(p)
        while x % p == 0:
            x //= p
    return primes

mp = {}
pos = {}

def add(v, w):
    primes = factorize(v)
    used = set(primes)
    pos[(v, w)] = used
    for p in used:
        if p not in mp:
            mp[p] = {}
        mp[p][w] = mp[p].get(w, 0) + 1

def remove(v, w):
    used = pos.pop((v, w))
    for p in used:
        if p in mp:
            mp[p][w] -= 1
            if mp[p][w] == 0:
                del mp[p][w]

def get_max(d):
    if not d:
        return 0
    return max(d.keys())

out = []

n = int(input())
for _ in range(n):
    tmp = input().split()
    if tmp[0] == '+':
        v = int(tmp[1]); w = int(tmp[2])
        add(v, w)
    elif tmp[0] == '-':
        v = int(tmp[1]); w = int(tmp[2])
        remove(v, w)
    else:
        k = int(tmp[1])
        primes = factorize(k)
        ans = 0
        seen = set()
        for p in primes:
            if p in seen:
                continue
            seen.add(p)
            if p in mp:
                ans = max(ans, get_max(mp[p]))
        out.append(str(ans))

print("\n".join(out))
```ふるいは最小の素因数を事前に計算するため、因数分解はすべての演算に対して十分に高速になります。 の`mp`構造体は素数ごとに重みの頻度マップを保存し、同じ重みが複数回出現する場合でも削除できます。 クエリ ロジックは、次の素数を重複排除します。`k`そのため、要因が繰り返されても冗長な作業が発生することはありません。 

微妙な点は、フルに保存することは決してないということです`(v, w)`プライムバケット内のオブジェクト、多重度のある重みのみ。 クエリでは最大値のみが要求されるため、これで十分です。`w`どのペアがそれを達成したかではありません。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    MAXV = 500000
    spf = list(range(MAXV + 1))
    for i in range(2, int(MAXV ** 0.5) + 1):
        if spf[i] == i:
            for j in range(i * i, MAXV + 1, i):
                if spf[j] == j:
                    spf[j] = i

    def factorize(x):
        res = set()
        while x > 1:
            p = spf[x]
            res.add(p)
            while x % p == 0:
                x //= p
        return res

    mp = {}
    pos = {}

    def add(v, w):
        ps = factorize(v)
        pos[(v, w)] = ps
        for p in ps:
            mp.setdefault(p, {})
            mp[p][w] = mp[p].get(w, 0) + 1

    def remove(v, w):
        ps = pos.pop((v, w))
        for p in ps:
            mp[p][w] -= 1
            if mp[p][w] == 0:
                del mp[p][w]

    n = int(input())
    out = []
    for _ in range(n):
        parts = input().split()
        if parts[0] == '+':
            add(int(parts[1]), int(parts[2]))
        elif parts[0] == '-':
            remove(int(parts[1]), int(parts[2]))
        else:
            k = int(parts[1])
            ps = factorize(k)
            ans = 0
            for p in ps:
                if p in mp:
                    ans = max(ans, max(mp[p].keys()))
            out.append(str(ans))

    return "\n".join(out)

 ## 特殊なケース

 厄介なケースは、挿入された複数のペアが同じ重みを共有しているが、異なる値に属している場合です。 構造では、ペアの同一性と重みの頻度を混同してはなりません。 削除では、出現箇所を 1 つだけ削除する必要があります。 

例えば：```
+ 6 10
+ 10 10
? 15
```どちらも共有プライム バケットに寄与しますが、最大値は 10 のままです。一方が削除されても、もう一方は値を維持する必要があります。 

別のエッジケースは、以下の素因数を繰り返します。`k`、 のような`k = 8`。 素数の重複排除がなければ、同じバケットが複数回クエリされることになり、非効率的であり、ヒープトップの追跡に依存する実装の推論を歪める可能性があります。 素数の重複を排除すると、各バケットがクエリごとに 1 回考慮され、gcd の数学的構造と一致します。
