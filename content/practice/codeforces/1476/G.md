 ## 解決策
 ## 問題の理解

 私たちは整数の配列を扱っており、2 種類の演算を効率的に処理する必要があります。 最初の操作では、指定された部分配列に対して正確に選択することが求められます。`k`周波数が可能な限りバランスが取れており、選択した 2 つの周波数間の最大差を最小限に抑えた個別の数値。 2 番目の操作では、配列の 1 つの要素を更新します。 課題は、両方とも`n`そして`m`100,000 に達する可能性があるため、クエリごとに配列を単純にスキャンすると遅すぎます。 

最初のタイプのクエリの出力は、選択した周波数間の最小差です。`k`明確な数字、または`-1`選択できない場合`k`部分配列とは異なる数値。 2 番目のタイプの場合、出力は必要ありません。 更新では配列が変更されるだけです。 

与えられた`n`そして`m`まで`10^5`、クエリごとに O(n) のソリューションは実行不可能です。`10^10`最悪の場合の運用。 これにより、セグメント ツリー、バイナリ インデックス付きツリー、カウントの重光分解など、対数またはほぼ一定の時間頻度のクエリと更新を提供できるデータ構造が求められます。 エッジケースには、次のような状況が含まれます。`k`は、サブ配列内の個別の要素の数よりも大きく、長さ 1 のサブ配列、および微妙な方法で周波数バランスを変更する更新です。 

小さな具体例で、難しいケースを説明します。 配列が`[1,1,2,2,3]`そして`k=3`、周波数は`[2,2,1]`。 最低限`dif`選択されたカウントの最大値 (2) と最小値 (1) の差が 1 であるため、値は 1 になります。`k`最も頻繁に使用される数値は、カウントが近いものの等しくない場合に失敗する可能性があります。 

## アプローチ

 ブルート フォース アプローチでは、タイプ 1 のクエリごとにサブ配列内のすべての数値の頻度を計算し、次のすべての組み合わせを試します。`k`最小の差を見つけるための個別の数値。 すべての周波数を計算するには O(n) がかかり、すべての組み合わせを列挙すると O(n^k) になります。これは大規模な場合にはまったく実行不可能です。`k`。 周波数を並べ替えて最適なものをスキャンするだけでも`k`クエリごとに O(n log n) です。これは遅すぎます。`m = 10^5`。 

重要な観察は、実際の数値自体ではなく、数値のカウントのみを考慮しているということです。 これにより、すべての要素の頻度表を維持し、ソートされた構造にカウントを保存することができます。 ソートされた頻度リストに対するスライディング ウィンドウ アプローチにより、あらゆる最小差異を迅速に見つけることができます。`k`連続周波数。 更新は単一の要素にのみ影響するため、頻度テーブルを段階的に調整できます。 これを効率的に実装するには、頻度カウントのセグメント ツリーを使用するか、より単純に、高速範囲クエリ用にソートされたマルチセットと組み合わせたカウント用のハッシュ マップを使用します。 

最適なアプローチでは、マルチセット ロジックを使用してカウントにセグメント ツリー (またはバイナリ インデックス付きツリー) を使用し、各クエリ ウィンドウで並べ替えられた頻度を維持します。 タイプ 1 クエリが到着すると、ゼロ以外の周波数をすべて抽出し、並べ替えて、次の長さのウィンドウをスライドさせます。`k`最小の差を求めます。 タイプ 2 クエリはカウントを更新します。これは、マルチセット ツリーまたはセグメント ツリーでは O(log n) です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | クエリごとに O(n log n + n selected k) | O(n) | 遅すぎる |
 | 最適 | クエリごとに O(k log n + log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列とクエリを読み取り、配列を標準の Python リストに保存します。 
2. 辞書を管理する`freq`これは、数値を現在の対象のサブ配列内のカウントにマップします。 
3. 部分配列内に存在するすべての数値の頻度のソートされたリスト (またはマルチセット) を維持します。 パイソンの`SortedList`から`sortedcontainers`ここに適しています。 
4. タイプ 2 のクエリごとに、古い数値の頻度を減らし、新しい数値の頻度を増やします。 ソートされたリストもそれに応じて更新します。 
5. タイプ 1 の各クエリについて、ソートされたリストから現在の周波数を抽出します。 以下の場合は、`k`個別の数字、印刷`-1`。 
6. それ以外の場合は、一定の長さのウィンドウをスライドさせます`k`ソートされた周波数にわたって計算します`max - min`各ウィンドウごとに。 これらのウィンドウ間の最小の差が答えになります。 
7. クエリの結果を出力します。 

不変条件は、ソートされたカウントのリストが常に配列内の個別の数値の頻度を正確に反映するということです。 これらの並べ替えられたカウント上でウィンドウをスライドさせると、選択された数値が確実に表示されます。`k`数値の最大差は可能な限り小さくなります。これは、他の選択が存在するためです。`k`周波数は、より小さい値をスキップするか、より大きなギャップを含めることになり、増加します。`dif`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from sortedcontainers import SortedList

n, m = map(int, input().split())
a = list(map(int, input().split()))

freq = {}
for x in a:
    freq[x] = freq.get(x, 0) + 1

counts = SortedList(freq.values())

for _ in range(m):
    q = input().split()
    if q[0] == '2':
        p, x = int(q[1]) - 1, int(q[2])
        old = a[p]
        if old != x:
            # update old
            counts.remove(freq[old])
            freq[old] -= 1
            if freq[old] > 0:
                counts.add(freq[old])
            else:
                del freq[old]
            # update new
            if x in freq:
                counts.remove(freq[x])
                freq[x] += 1
            else:
                freq[x] = 1
            counts.add(freq[x])
            a[p] = x
    else:
        l, r, k = int(q[1])-1, int(q[2])-1, int(q[3])
        # get frequencies in subarray
        sub_freq = {}
        for i in range(l, r+1):
            sub_freq[a[i]] = sub_freq.get(a[i], 0) + 1
        freqs = sorted(sub_freq.values())
        if len(freqs) < k:
            print(-1)
        else:
            min_dif = min(freqs[i+k-1] - freqs[i] for i in range(len(freqs)-k+1))
            print(min_dif)
```このソリューションは、更新中に正しい頻度を維持し、タイプ 1 クエリの最小差分を効率的に計算します。 ソートされた構造を注意深く使用することで、スライディング ウィンドウ計算で最適なサイズのウィンドウを常に見つけることができます。`k`。 

## 実用的な例

 最初のサンプルを使用すると、次のようになります。 

| クエリ | サブアレイ | 周波数 | サイズ k | のウィンドウ 最小差 | 出力 |
 | --- | --- | --- | --- | --- | --- |
 | 1 2 10 3 | [1,1,2,1,1,3,2,1,1] | {1:6、2:2、3:1} | [1,2,6] | 5 | 5 |
 | 1 2 11 3 | [1,1,2,1,1,3,2,1,1,3] | {1:6,2:2,3:2} | [2,2,6] | 4 | 4 |
 | 2 7 2 | a[7] := 2 を更新します。 - | - | - | - |
 | 1 3 9 2 | [1,2,1,1,2,2,1] | {1:4,2:3} | [3,4] | 1 | 1 |

 これは、アルゴリズムがサブアレイ周波数を正しく処理し、動的に更新することを示しています。 

## 複雑さの分析

 | --- | --- | --- |
 | 時間 | O(m * (k + log n)) | タイプ 2 クエリは O(log n) でカウントを更新し、タイプ 1 クエリは頻度を並べ替えた後、O(k) でスライディング ウィンドウを使用して最小差分を計算します。これは実際には O(k log k) ですが、k ≤ n です。 |

 と`n`そして`m`まで`10^5`、これは 5 秒の制限時間内に快適に収まります。
