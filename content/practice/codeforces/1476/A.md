 ## アプローチ

 ブルートフォース手法では、考えられる長さの配列をすべて列挙しようとします。$n$正の整数を使用して、その合計が次で割り切れるかどうかを確認します。$k$そして最大値を追跡します。 のために$n \approx 10^9$、これには少なくとも必要です$O(n)$テスト ケースごとの操作は制限時間を何桁も超えます。 

重要な洞察は、配列全体が必要ではなく、最大の要素のみが必要であるということです。 最大要素を次のように表しましょう$x$。 配列の合計は最大で$n \cdot x$、すべての要素が以下の正の整数であるため、$x$。 で割り切れる条件を満たすには$k$、合計は少なくとも$k \cdot \lceil \frac{1}{k} \cdot n \cdot x \rceil$。

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、整数を読み取ります。$n$そして$k$。 
2. 次の最小倍数を計算します。$k$それは少なくとも$n$。 これにより、この合計を均等に分割すると、$n$要素で分割可能になります。 させて$m = \lceil \frac{n}{k} \rceil$。 ただし、次を掛ける必要があります。$k$で割ります$n$最大の要素を取得するには、$x = \lceil \frac{k \cdot m}{n} \rceil$。 
3. 同等の定式化は次のように計算します。$m = \lceil \frac{n}{k} \rceil$、 それから$x = \lceil \frac{k \cdot m}{n} \rceil$。 これにより合計が保証されます$n \cdot x$で割り切れます$k$そして最小限。 
4. 印刷$x$。 

これが機能する理由: 不変条件は、常に最小の整数を選択することです。$x$配布するような$n$せいぜい価値のある要素$x$で割り切れる合計を達成する$k$。 それより小さいもの$x$次の倍数よりも小さい合計が生成されます$k$、可分性に違反します。 これにより、最大要素が最小であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    # Compute minimum maximum element
    m = (n + k - 1) // k  # smallest integer >= n/k
    x = (k * m + n - 1) // n  # ceil(k*m / n)
    print(x)
```説明: 最初に最小回数を計算します。$k$合計に収まる必要があります ($m$) 可算性を確保するため。 乗算する$k \cdot m$合計を求めて、それを次の値で割ります。$n$天井除算を使用して最小の整数を取得する$x$それは繰り返せる$n$その合計を達成するまでに 3 回かかります。 の`+ n - 1`トリックは整数演算で天井除算を実行します。
