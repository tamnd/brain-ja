 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、根を張った木です。`n`ノード。 各ノードは、最初は 0 または 1 のいずれかの値を保持します。ツリー内の値の進化は、整数ごとにという単純なルールによって定義されます。`t > 0`、すべての非リーフ ノードは、前のタイム ステップからの子の値の XOR にその値を更新します。 葉ノードには子がないため、0 になります。 特定の時点でのすべてのノード値の合計`t`と表されます`S(t)`。 

私たちは定義します`F(A)`の合計として`S(t)`から始まるすべての時間ステップにわたって`t = 0`天文学的な規模にまで`t = 10^100`特定の初期構成の場合`A`。 タスクは次の合計を計算することです`F(A)`ノード値の考えられるすべての初期設定にわたって。 最終的な答えはモジュロである必要があります`10^9 + 7`。 

主な課題は、初期構成の数が指数関数的に増加することにあります (`2^n`) および潜在的に無制限のタイム ステップ数。 単純なシミュレーションは不可能です。`n`その周り`10^5`、繰り返します`2^n`構成は不可能です。 ただし、ツリー構造と XOR 演算は、構成やタイム ステップを列挙することなく合計を効率的に計算できる数学的特性がある可能性を示唆しています。 

エッジ ケースには、単一ノードを持つツリー、チェーン状のツリー (高さ = n-1)、およびすべての葉がルートに直接接続されているツリーが含まれます。 これらすべての場合において、最初のタイム ステップの後、リーフは常に 0 を寄与します。これにより XOR 伝播が簡素化されますが、深さの計算における 1 によるオフのエラーを避けるために慎重に処理する必要があります。 

## アプローチ

 ブルートフォース手法は簡単です。すべてを列挙します。`2^n`初期割り当て、すべてのノードがゼロになるまで時間の経過に伴う XOR 伝播をシミュレートし、すべてのノードを合計します。`S(t)`価値観。 これは原理的には正しいですが、実行不可能です。 たとえ`n = 20`、`2^20`構成によっては実際の実行が不可能になり、各構成の時間の経過により追加のコストがかかります。 

効率的な解決策を導き出す重要な観察は、問題を寄与の観点から線形に考えることから得られます。 各ノードは合計に寄与します`F(A)`これは、そこから偶数および奇数の距離にあるノードの数にのみ依存する方法です。 具体的には、ノードが深度にある場合、`d`リーフから、時間ステップ間で寄与を交互に切り替えます。 XOR 構造を使用すると、実際の XOR 伝播をシミュレートすることなく、2 の累乗を使用してすべての構成にわたるノードの合計寄与度を計算できます。 各ノードからの寄与は、ツリー内の深さに基づいて組み合わせ式に帰着できます。 

DFS を介して深さを割り当てると、すべての初期構成にわたる寄与の合計が次のように比例することがわかります。`2^(n-1) * (number of nodes not leaves)`。 各ノードには、親の XOR を反転するか反転しないかの選択肢があり、これは組み合わせによるものです。 モジュラー演算を使用すると、効率的に計算できます。`2^(n-1) modulo 10^9+7`すべての非リーフ ノードの寄与を合計します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n) | O(n) | 遅すぎる |
 | 深度ベースの貢献 | テスト ケースあたり O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 テスト ケースごとに、ツリー構造を読み取り、隣接リストとして保存します。 
2. DFS を実行して、ツリー内の非リーフ ノードの数をカウントします。 これは、各ノードの隣接リストのサイズを確認することで実行できます。 隣接するノードが 1 つだけ (ルートを除く) ある場合、そのノードはリーフです。 
3. 2 のべき乗モジュロを事前計算する`10^9+7`まで`n`、各ノードは次の係数に寄与するため、`2^(n-1)`すべての初期構成にわたって。 これは、残りのノードに対するすべての可能な 0 と 1 の割り当ての組み合わせ効果を考慮しています。 
4. 非リーフ ノードの数を次のように乗算します。`2^(n-1)`の合計を取得するには`F(A)`すべての構成にわたって。 
5. 結果のモジュロを出力します。`10^9+7`。 

機能する理由: XOR は GF(2) に対して線形であるため、すべての非リーフ ノードは、予測可能な線形方式ですべての構成の XOR 合計に寄与します。 以降の葉の貢献度はゼロになります`t=1`そして無視することができます。 事前に計算された 2 の累乗は、残りのノードの構成の指数関数的な数を取得します。 これにより、指数列挙の問題が、組み合わせ乗算を使用した単純な線形スキャンに縮小されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 10**9 + 7

def solve():
    t = int(input())
    pow2 = [1] * (2 * 10**5 + 5)
    for i in range(1, len(pow2)):
        pow2[i] = pow2[i-1] * 2 % MOD

    for _ in range(t):
        n = int(input())
        adj = [[] for _ in range(n)]
        for _ in range(n-1):
            u, v = map(int, input().split())
            adj[u-1].append(v-1)
            adj[v-1].append(u-1)

        non_leaf_count = 0
        for i in range(n):
            # root can have one child and still be non-leaf
            if i == 0:
                if len(adj[i]) > 0:
                    non_leaf_count += 1
            else:
                if len(adj[i]) > 1:
                    non_leaf_count += 1

        answer = non_leaf_count * pow2[n-1] % MOD
        print(answer)

if __name__ == "__main__":
    solve()
```コードは 2 の累乗を事前計算することから始まります。
