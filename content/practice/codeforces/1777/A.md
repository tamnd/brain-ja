 ## 解決策
 ## 問題の理解

 整数の配列を「適切な配列」に変換するように求められます。これは、連続する 2 つの要素が同じパリティを共有しない配列として定義されます。 パリティとは、単に数値が奇数か偶数かを意味します。 したがって、適切な配列では、奇数の後には偶数が続き、偶数の後には奇数が続く必要があります。 サイズ 1 の配列は、連続する要素がないため、明らかに優れています。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは、最大 100 個の長さの要素を含む配列を提供します。$10^9$。 各テスト ケースの出力は、配列を適切な配列に変えるために必要な最小限の操作数です。 許可される操作は、同じパリティを持つ 2 つの隣接する数値を選択し、それらを削除し、それらの積で置き換えることです。 

この制約は、単純な$O(n^2)$アプローチは実現可能です、なぜなら$n \le 100$そして$t \le 500$, そのため、最悪の場合、ラフに実行する可能性があります。$500 \cdot 100^2 = 5 \cdot 10^6$単純なシミュレーションでの操作。 ただし、乗算を明示的にシミュレートするよりも、パリティ パターンについて推論することで、問題をより速く解決できます。 

主なエッジ ケースは、複数の同じパリティ番号が連続して出現する場合です。 たとえば、配列`[2, 4, 6, 1]`2 つの操作が必要です: 結合`2*4 = 8`その後`8*6 = 48`到達する`[48, 1]`。 最初の競合するペアだけを調べる単純なチェックでは、操作が過小評価される可能性があります。 もう 1 つのエッジ ケースは、すでにパリティで交互に配置されている配列です。`[1, 2, 3, 4]`、操作は必要ありません。 

## アプローチ

 ブルート フォース手法では、操作をシミュレートします。配列をスキャンし、同じパリティの隣接する要素を見つけて乗算を実行し、そのようなペアが存在しなくなるまで継続します。 このアプローチは正しいです。各操作は同じパリティの隣接するペアの数を厳密に減らすため、最終的には終了します。 欠点は、配列操作を繰り返し実行するため、連続した同一パリティの実行では非効率になる可能性があることです。 長さ 100 の配列の場合は許容されますが、面倒です。 

最適なアプローチのための重要な洞察は、実際には数値自体を追跡する必要がないということです。 2 つの数値を乗算してもパリティは変更されないため、関連する情報はパリティ シーケンスのみです。 これにより、同じパリティを持つ数値が連続して続く長さをカウントするという問題が軽減されます。 それぞれの長さのラン$k$まさに貢献する$k-1$単一の要素にマージする操作。 合計する$k-1$配列内のすべての同じパリティの実行で、最小限の操作数が得られます。 この観察により、問題は単純な線形スキャンに変換されます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 許容できるが不要 |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. テスト ケースごとに、配列と配列自体の長さを読み取ります。 
3. 操作用のカウンタをゼロに初期化します。 
4. 2 番目の要素から最後まで配列のスキャンを開始します。 
5. 同じパリティを持つ連続した番号の現在の連続の長さを追跡します。 ランレングス 1 から始めます。 
6. 各要素について、そのパリティを前の要素と比較します。 同じであれば、ランレングスを増加させます。 異なる場合は追加してください`run_length - 1`を操作カウンターに送信し、ランレングスを 1 にリセットします。 
7. ループの後に追加します。`run_length - 1`最後のランに向けて。 
8. テスト ケースの合計操作を出力します。 

これが機能する理由: 不変条件は、同じパリティを持つ連続する数値のシーケンスは、正確に 1 つの数値に還元できるということです。`length-1`順序に関係なく、操作を実行します。 これにより、すべての実行を処理した後、アレイが良好であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    operations = 0
    run_length = 1
    for i in range(1, n):
        if a[i] % 2 == a[i-1] % 2:
            run_length += 1
        else:
            operations += run_length - 1
            run_length = 1
    operations += run_length - 1
    print(operations)
```このコードは、高速 I/O を使用してすべての入力を効率的に読み取ります。 単一の要素が簡単に実行を開始するため、ランレングスカウンターが 1 に初期化されます。 パリティが変更されるたびに、前回の実行が考慮され、カウンタがリセットされます。 最後に、最後の実行の操作を追加します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        operations = 0
        run_length = 1
        for i in range(1, n):
            if a[i] % 2 == a[i-1] % 2:
                run_length += 1
            else:
                operations += run_length - 1
                run_length = 1
        operations += run_length - 1
        output.append(str(operations))
    return "\n".join(output)
