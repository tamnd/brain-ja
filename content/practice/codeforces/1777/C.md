 ## 解決策
 ## 問題の理解

 学校から生徒の一部を選んでクイズ チームを編成するように求められます。 各生徒には賢さの値があり、各クイズ トピックには、賢さがトピック番号で割り切れるチーム メンバーが少なくとも 1 人必要です。 目標は、チーム内の 2 人の生徒の頭の良さの最大の差を最小限に抑えながら、すべてのトピックをカバーするチームを形成することです。 

入力により生徒の数が得られます`n`そしてトピックス`m`、その後にスマートネス値の配列が続きます`a`。 各テスト ケースについて、有効なチーム内の賢さの最小最大差を出力する必要があります。または、`-1`すべてのトピックをカバーできるチームがない場合。 

制約により許可されるのは、`n`そして`m`最大 100,000、すべてのテスト ケースの合計は 100,000 になります。 組み合わせは指数関数的に多く存在するため、生徒のすべてのサブセットを試すような単純なアプローチは除外されます。 操作は、ほぼ線形またはほぼ線形である必要があります。`n`そうしないと、タイムアウトになる危険があります。 

エッジケースには、特定のトピックで割り切れる生徒がいない状況が含まれます。 たとえば、次の場合`a = [3,7]`そして`m = 4`で割り切れる生徒はいない`2`または`4`, したがってチームは存在しません。 もう 1 つの微妙なケースは、1 人の学生が複数のトピックをカバーできる場合に発生し、最小の差がゼロになることが許容されます。 

## アプローチ

 ブルートフォースアプローチでは、生徒のすべてのサブセットを列挙し、各サブセットがすべてのトピックをカバーしているかどうかを確認し、最大の賢さと最小の賢さの差を計算します。 これは原則として正しいですが、確認が必要です`2^n`サブセット、これは不可能です`n = 10^5`。 

重要な洞察は、すべてのサブセットは必要ではなく、すべてのトピックをカバーできる最小範囲のスマートネス値のみが必要であるということです。 トピックは約数に対応するため、整数の範囲で考えることができます。 最小限のチームメンバーとしてそれぞれの賢さを反復し、すべてのトピックをカバーできる十分な生徒を含めるように努めることによって、`m`、トピック範囲のふるいのような追跡と組み合わせて、問題をソートされたスマートネス値に対する一種のスライディング ウィンドウに減らすことができます。 

どの学生がどのトピックをカバーするかを事前に処理します。 次に、賢さの範囲のみを考慮し、その範囲でカバーされるトピックに次のすべてのトピックが含まれているかどうかを確認します。`1`に`m`。 そのような範囲の最小幅が答えを与えます。 

最適なアプローチでは、並べ替えと 2 つのポインターまたは動的ウィンドウの形式を利用します。 並べ替えることで`a`スライディング ウィンドウでカバーされるトピックの数を追跡すると、最小最大差異を効率的に計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * m) | O(n * m) | 遅すぎる |
 | 最適 | O(n log n + n m) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列をソートする`a`。 これにより、スマートさの範囲を昇順に考慮することができ、最小限の違いを見つけることが簡単になります。 
2. count 配列を初期化する`topic_count`サイズの`m+1`ゼロに設定すると、現在のウィンドウ内の各トピックに習熟した学生の数が追跡されます。 
3. 2 つのポインターを維持する`l`そして`r`スマートネス値の現在のウィンドウの左端と右端を表します。 
4. 移動`r`左から右に、学生をウィンドウに追加します。 各新入生について、カバーするすべてのトピック、つまりすべての約数の増分がカウントされます。`T`の`a[r]`どこ`T <= m`。 
5. すべてのトピックが送信されるたびに、`1`に`m`少なくとも 1 人の生徒を窓の中に入れてください (`topic_count[T] > 0`みんなのために`T`)、移動してウィンドウを縮小してみます`l`右。 デクリメント`topic_count`が取り上げるトピックについては`a[l]`それに応じて。 
6. ウィンドウがすべてのトピックをカバーするたびに、次のように回答を更新します。`min(ans, a[r] - a[l])`。 
7. すべてのトピックをカバーするウィンドウがない場合は、リターンします。`-1`。 

機能する理由: 並べ替えにより、確実にデータが増加します。`r`ウィンドウ内の最大限のスマート性を高めるだけであり、移動`l`forward は最小限のスマートさを軽減します。 トピック数を動的に維持することで、ウィンドウが常に有効なサブセットを表すことを保証し、最小幅を追跡することで最小限の最大差が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        a.sort()
        
        max_val = max(a)
        # count frequency of each smartness
        from collections import defaultdict, deque
        indices = defaultdict(list)
        for val in a:
            indices[val].append(val)
        
        # initialize topic coverage for sliding window
        topic_count = [0] * (m + 1)
        total_covered = 0
        ans = float('inf')
        l = 0
        
        for r in range(n):
            val = a[r]
            # increment topic counts for all divisors <= m
            for T in range(1, min(val, m) + 1):
                if val % T == 0:
                    if topic_count[T] == 0:
                        total_covered += 1
                    topic_count[T] += 1
            
            # shrink window from left
            while total_covered == m:
                ans = min(ans, a[r] - a[l])
                val_l = a[l]
                for T in range(1, min(val_l, m) + 1):
                    if val_l % T == 0:
                        topic_count[T] -= 1
                        if topic_count[T] == 0:
                            total_covered -= 1
                l += 1
        
        print(ans if ans != float('inf') else -1)

if __name__ == "__main__":
    solve()
```コードが並べ替えられる`a`スライド窓を使用しており、`topic_count`配列を使用して、現在のウィンドウ内の何人の生徒が各トピックに習熟しているかを追跡します。 除数に対する内部ループにより正しいカバレッジが保証され、ウィンドウを縮小することで最小限の差が維持されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

 | 時間 | O(nm) | 各生徒について、min(a[i], m) までの約数をチェックします。 ソートは O(n log n) で、除数チェックが大半を占めます。 |
