 ## 解決策
 ## 問題の理解

 無限平面上に描かれたいくつかの円が与えられます。 これらの円は、非常に構造化された方法でのみ相互作用します。つまり、2 つの円は完全に分離しているか、一方が他方を完全に内包しているか、単に接触しているかのいずれかです。 複雑な交差ジオメトリを作成するような部分的な重なりはありません。 この制限により、円は格納木の森のようなきれいな入れ子構造を形成します。 

平面上のすべての点は、円の一部で覆われています。 奇数の円で覆われている場合、その点は「影響を受けている」とみなされますが、偶数の円で覆われている場合は完全に相殺されます。 したがって、各円はその内部の領域への切り替えに寄与し、最終的に影響を受ける領域は純粋にカバレッジの同等性によって決定されます。 

円周上で反転と呼ばれる操作を行うことができます。 これを適用すると、その円内のすべてのポイントの影響を受ける/影響を受けないステータスが反転します。 反転ごとに 1 ユニットのコストがかかるため、反転の使用はできるだけ少なくしたいと考えています。 

目標は、影響を受けるポイントの合計面積が kπ を超えないようにすることです。 すべての円の面積は π の倍数であるため、すべての面積を π で等価的に正規化し、半径の 2 乗で考えることができます。 

n ≤ 2000 という制約は、二次解または n² log n 解は妥当ですが、指数関数的なサブセットや大きな値を超える重いナップザックを含むものは遅すぎることを意味します。 k が 10¹⁷ と大きいという制約は、面積値に対する DP に直接依存できないことも意味します。 

単純なアプローチでは、平面を直接モデル化して、オーバーラップによって形成されたすべての領域を追跡し、操作ごとに領域を切り替えようとします。 包含制限があっても、各円にはネストされた円が多数含まれる可能性があり、反転するたびに影響を受ける領域を再計算するのが遅すぎるため、領域を明示的に維持すると依然として大きすぎます。 

2 番目の単純なアイデアは、各円を独立して扱い、その円が現在総面積に対してプラスに寄与しているかマイナスに寄与しているかに基づいて反転するかどうかを決定することです。 1 つの円を反転すると、その子孫すべてのパリティ構造が変更されるため、決定が独立していないため、これは失敗します。 

典型的な隠れた失敗例は、ネストに起因します。 

入力:

 3 1

 0 0 10

 0 0 5

 0 0 1

 ここではすべてが入れ子になっています。 貪欲なアプローチでは、ローカル パリティを修正するために最初に最小の円を反転する可能性がありますが、これにより上位レベルの寄与がすべて変更され、影響を受ける領域の合計が他の場所で増加し、全体的な結果が最適ではなくなる可能性があります。 

主要な問題は、すべての操作がネストされた円のサブツリー全体に影響を与えるため、パリティがどのように下方に伝播するかを追跡するツリー DP が必要であることです。 

## アプローチ

 円はネストされているか、または互いに素であるため、各円が一意の親、つまりその円を含む最小の円を持つフォレストを構築できます。 

構造をツリーとして見ると、各円がノードに対応し、ノードの内側で子の外側にあるすべての点が、面積の計算が容易な個別の領域に対応します。 具体的には、ノードの排他的領域は、そのノードの全領域から直接の子の領域を差し引いたものになります。 

領域の初期パリティは、その領域が包含ツリー内でどれだけ深いかによって決まります。 1 レベル深くなるたびにカバレッジが反転するため、初期パリティは深さのパリティのみに依存します。 

次に、反転が何をするかを考えてみましょう。 ノードを反転すると、そのサブツリー内のすべての領域のパリティが切り替わります。 つまり、それ自体のリージョンだけでなく、すべての子孫にも影響し、パスに沿ってグローバルな依存関係が作成されます。 

これにより、各ノードが祖先によってパリティが反転されたかどうかを表す状態を持つ標準ツリー DP 構造が得られます。 各ノードで、それを反転するかどうかを決定します。これは、ノード自身の寄与と子に渡される状態の両方に影響します。

ブルートフォース解釈では、ノードのすべてのサブセットを反転しようとします。 それは 2ⁿ の可能性があり、まったく実現不可能です。 

代わりに、ツリー上で DP を計算します。ここで、各ノードは、親から反転されたパリティまたは非反転パリティのどちらで到着したかに応じて、コスト (反転数) とその結果生じるサブツリー内の影響を受ける領域の合計との間で達成可能な最良のトレードオフを返します。 

コストと結果の面積の両方を追跡する必要があるため、各サブツリー DP 状態は単一の値ではなく、パレート最適ペアのコレクションになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | サブセットに対するブルート フォース | O(2ⁿ・n) | O(n) | 遅すぎる |
 | パレート状態を含むツリー DP | O(n²) | O(n²) | 承認済み |

 ## アルゴリズムのチュートリアル

 まず封じ込め林を構築します。 各円について、最小半径でその円が含まれる他の円を確認することで、その親を識別します。 n ≤ 2000 であるため、O(n²) チェックで十分です。 

次に、各ノードの子のリストを計算します。 これにより、各ノードが円に対応し、エッジが包含を表すルート付きフォレストが得られます。 

次に、幾何学的重みを計算します。 各ノードの合計面積は r² です。 専有領域の面積は、自身の領域から子の領域の合計を差し引いたものとなります。 これが機能するのは、子が包含を介さない限り重複しないため、その排他的領域が親の内部を分割するためです。 

また、各ノード領域の初期パリティも計算します。 ノードの深さが d にある場合、その領域は正確に d 回カバーされるため、d が奇数の場合は最初に影響を受けます。 

次に、ツリー上で DP を実行します。 

各ノード u で、2 つの DP テーブルを定義します。 

DP[u][p]。ここで、p は、u の領域が親パリティ (0 または 1) によって反転されるかどうかを示します。 各 DP 状態には、サブツリー内で達成可能な構成を表すペア (コスト、エリア) のセットが格納されます。 

各ノードについて、次の 2 つの選択肢を試します。 

ひっくり返さないか、ひっくり返すかのどちらかです。 各選択肢のコストは 0 または 1 であり、パリティが子に渡される方法が変わります。 

子を結合する場合、パリティが固定されるとサブツリーは独立するため、コストを追加し、領域を追加することによって、その DP 状態をマージします。 

すべての子を処理した後、支配的な状態を取り除きます。 c1 ≤ c2 および a1 ≤ a2 の場合、状態 (c1, a1) は (c2, a2) よりも悪化することがないため、優先されます。 

最後に、ルートですべての DP 状態を調べ、総面積が k 以下のものの中から最小コストを選択します。 

## なぜ機能するのか

 重要な不変条件は、u がその祖先からパリティ p を経験すると仮定して、すべてのノードについて、DP[u][p] がフリップ コストと u をルートとするサブツリー内で達成可能な影響を受ける領域との間のすべての最適なトレードオフを表すことです。 

反転は子孫にのみ影響するため、受信パリティが修正されると、すべてのサブツリーは独立します。 これにより、子の結合が隠れた相互作用のない純粋な加算マージとなることが保証されます。 

考えられるすべてのフリップ構成は、この DP で選択肢を割り当てる 1 つの方法に正確に対応し、すべての DP 遷移では実行可能なすべての組み合わせが保持されるため、有効な解決策が除外されることはありません。 枝刈りは厳密に最悪の状態を除去するだけなので、潜在的に最適なグローバル ソリューションを除去することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    n, k = map(int, input().split())
    circles = []
    for _ in range(n):
        x, y, r = map(int, input().split())
        circles.append((r, x, y))

    circles.sort(reverse=True)

    # build containment tree
    parent = [-1] * n
    children = [[] for _ in range(n)]

    def contains(i, j):
        ri, xi, yi = circles[i]
        rj, xj, yj = circles[j]
        dx = xi - xj
        dy = yi - yj
        return dx*dx + dy*dy <= (ri - rj) * (ri - rj)

    for i in range(n):
        for j in range(i):
            if parent[i] == -1 and contains(j, i):
                parent[i] = j
                children[j].append(i)

    roots = [i for i in range(n) if parent[i] == -1]

    # compute depth
    depth = [0] * n
    stack = [(r, 0) for r in roots]
    while stack:
        u, d = stack.pop()
        depth[u] = d
        for v in children[u]:
            stack.append((v, d + 1))

    area = [0] * n
    for i, (r, x, y) in enumerate(circles):
        area[i] = r * r

    # compute exclusive area
    for u in range(n - 1, -1, -1):
        for v in children[u]:
            area[u] -= circles[v][0] ** 2

    def merge(a, b):
        res = {}
        for ca, aa in a:
            for cb, ab in b:
                c = ca + cb
                w = aa + ab
                if c not in res or res[c] < w:
                    res[c] = w
        items = list(res.items())
        items.sort()
        pruned = []
        best = -1
        for c, w in items:
            if w > best:
                pruned.append((c, w))
                best = w
        return pruned

    def dfs(u, p):
        init = depth[u] & 1

        best = {}
        # x = 0 or 1
        for flip in [0, 1]:
            cost = flip
            cur_parity = p ^ flip
            val = 0
            if init ^ cur_parity:
                val = area[u]

            dp_list = [(0, val)]
            for v in children[u]:
                child = dfs(v, cur_parity)
                dp_list = merge(dp_list, child)

            for c, w in dp_list:
                nc = c + cost
                if nc not in best or best[nc] < w:
                    best[nc] = w

        return [(c, w) for c, w in best.items()]

    INF = 10**18
    ans = INF

    for r in roots:
        for c, w in dfs(r, 0):
            if w <= k:
                ans = min(ans, c)

    print(ans)

if __name__ == "__main__":
    solve()
```このコードは、最初に大きな円をチェックすることで包含を検出できるように、円を並べ替えることから始まります。 親配列は、各円が最小の囲み円に割り当てられ、フォレストを形成するように構築されます。 

カバレッジはネストの深さのみに依存するため、深さは各領域の初期パリティを決定するために計算されます。 

DP は次のように実装されています。`dfs`。 各ノードは両方の反転の選択を試みます。 選択ごとに、ノードの領域が最終的な影響を受ける領域に寄与しているかどうかを計算し、同じパリティ コンテキストの下ですべての子の DP 状態をマージします。 マージ機能は、成長を制御するために、支配されていないコスト領域のペアのみを保持します。 

最後に、すべてのルート結果がスキャンされ、面積制約を達成する最小の反転数が見つけられます。 

## 実用的な例

 ### 例 1

 入力:```
3 3
0 0 2
0 0 1
10 10 1
```サークル 1 にサークル 2 が含まれ、サークル 3 が分離されるツリーを構築します。 

| ノード | 深さ | 初期パリティ | 面積 (r² から子を引いたもの) |
 | --- | --- | --- | --- |
 | 1 | 0 | 0 | 4 - 1 = 3 |
 | 2 | 1 | 1 | 1 |
 | 3 | 0 | 0 | 1 |

 最初の影響範囲は 3 + 1 = 4 で、k = 3 を超えます。 

DP はノード 1 の反転を検討します。これにより、サブツリー全体が切り替わり、1 と 2 の両方の寄与が減少します。これにより、影響を受ける領域の合計が 2 になり、1 回の反転で達成できる構成が得られます。 

したがって、答えは 1 です。 

### 例 2

 入力:```
1 0
0 0 5
```サークルは 1 つだけ存在します。 その面積は 25 で、最初は影響を受けます。 

| ノード | 深さ | 初期パリティ | エリア |
 | --- | --- | --- | --- |
 | 1 | 0 | 0 | 25 |

 k = 0 なので、影響を受ける領域をすべて除去する必要があります。 1 回フリップすると、領域全体が非アクティブに切り替わります。 

答えは 1 です。 

これらの例は、DP がローカルな修正に関するものではなく、エリアの寄与をグローバルに再形成するサブツリー全体のパリティ変更の選択に関するものであることを示しています。

 ## 特殊なケース

 クリティカルなエッジ ケースは、各円に他の円が 1 つだけ含まれる、完全にネストされたチェーンです。 この状況では、すべてのフリップが残りのすべてのノードに伝播します。 各ノードの状態にはすべての祖先から継承されたパリティが含まれているため、DP はこれを正しく処理し、高レベルのノードの反転がローカルな調整ではなくグローバルな変換として評価されるようにします。 

もう 1 つの特殊なケースは、複数の互いに素なツリーです。 各ルートは独立して処理されるため、アルゴリズムはそれらを個別に処理し、DP 結果は最終選択段階でのみ結合されます。 これにより、切断されたコンポーネント間の意図しない相互作用が確実に防止されます。 

最後の微妙なケースは、すべての円が同一である場合です。 その場合でも、封じ込めはタイブレークによりチェーンを形成し、内部境界のエリア寄与がゼロになり、最終的に影響を受ける領域を決定するのにパリティベースの決定のみが残されるため、DP は依然として正しく動作します。
