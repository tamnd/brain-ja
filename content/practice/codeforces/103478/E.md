 ## アルゴリズムのチュートリアル

 ポインタを維持します`j`それは私たちがどれだけ内側にいるかを表します`s`現在の試みについて。 

1.初期化`j = 0`。 これは、一致させるための新たな試みを開始していることを意味します`s`最初から。 
2. 各文字を反復処理します。`c`で`t`左から右へ。 各文字は何らかの試行に属している必要があるため、それを照合しようとします`s[j]`。 
3. もし`c == s[j]`、私たちは前進します`j`by 1。これにより、現在の試行が継続されます。 
4. もし`j`と等しくなる`len(s)`、これは、入力の試行が 1 回完全に完了したことを意味します。`s`。 処理によると、生徒はすぐに最初からやり直すので、リセットします`j = 0`。 
5. いつでも`c != s[j]`、次の文字を忘れて試行を再開することをシミュレートします。 リセットします`j = 0`そしてマッチングしてみてください`c`新たな試みの最初のキャラクターとして再び。 
6. リセット後、次の場合は、`c != s[0]`の場合、この文字では新たな試みを開始することもできないため、構築は不可能であり、「いいえ」を返します。 
7. のすべての文字を処理できれば、`t`成功した場合は「はい」を返します。 

重要なアイデアは、すべてのキャラクターが`t`の接頭辞の一部として説明する必要があります`s`、唯一の自由はプレフィックスをどこで再開するかです。 貪欲な再起動により、無効な部分的なアライメントにコミットすることがなくなります。 

### なぜ効果があるのか

 のどの位置でも`t`、アルゴリズムは次の不変条件を維持します。`j`のプレフィックスの長さに等しい`s`の最新の試行サフィックスと一致するもの`t`。 不一致が発生した場合は常に、続行するとプレフィックス構造に違反するため、有効な説明は現在の試行を中止する必要があります。 すべての試行はインデックス 0 の先頭から開始する必要があるため、インデックス 0 から再起動することが唯一可能な回復方法です。`s`。 これは、有効なセグメンテーションを意味します。`t`あるシーケンスのリセットに正確に対応し、貪欲戦略は一貫性を保つ可能な限り最も早いリセットをシミュレートします。 

各文字は一致するかリセットを強制され、リセットによって常に唯一の正当な開始状態に移行するため、有効な構築はスキップされず、無効な構築は受け入れられません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    t = input().strip()
    
    n = len(s)
    j = 0
    
    for c in t:
        if j < n and c == s[j]:
            j += 1
            if j == n:
                j = 0
        else:
            j = 0
            if s[0] != c:
                return "No"
            j = 1
    
    return "Yes"

def main():
    T = int(input())
    out = []
    for _ in range(T):
        out.append(solve())
    print("\n".join(out))

if __name__ == "__main__":
    main()

リセット条件`j == n`完了した試行が誤って状態を引き継がないようにします。 完了するたびにすぐに開始点に戻ります。`s`、問題の強化ルールと一致します。

 ## 特殊なケース

 エッジケースの 1 つは次のような場合です`t`位置に存在しない文字が含まれています`0`の`s`。 例えば`s = "abc"`そして`t = "abz"`。 アルゴリズムは次の時点で不一致に達します。`z`、リセットし、すぐに確認します`s[0] != 'z'`、「いいえ」を生成します。 正しい解決策では、そのような文字を使用して合法的に開始することはできないため、そのような文字を拒否する必要があります。
