 ## 解決策
 ## 問題の理解

 モノカープは`n`同一の箱、それぞれの重さを量る`m`までのユニットをサポートできます`d`上のユニット。 彼は、耐久性を考慮しながらすべての箱を積み重ねてタワーにしたいと考えています。これより大きな重量を支えることができる箱はありません。`d`。 タスクは、すべてのボックスを使用するために必要なタワーの最小数を決定することです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースが提供するのは、`n`、`m`、 そして`d`。 出力はテスト ケースごとに 1 つの整数、つまりタワーの最小数です。 各タワーには少なくとも 1 つのボックスが含まれており、すべてのボックスが配置されている必要があります。 

最大なので、`n`、`m`、 そして`d`は 50 で、最大 10,000 のテスト ケースが存在する可能性があるため、テスト ケースごとに単純な算術計算を実行するあらゆるソリューションが実現可能です。 重量制約をチェックしながら箱を繰り返し積み重ねる単純なシミュレーションは機能する可能性がありますが、その必要はありません。 エッジケースには、次のような状況が含まれます。`m > d`2 つのボックスを重ねて置くことができなくなり、`d`に比べて大きい`m`、すべてのボックスを 1 つのタワーに含めることができます。 たとえば、次の場合`n = 5`、`m = 3`、`d = 2`、積み重ねることはできないため、各ボックスは独自のタワーを形成し、5 つのタワーが得られます。 ボックスごとの重量制限をチェックしない不注意なアプローチでは、ボックスを誤って積み重ね、タワーの数を過小評価しようとします。 

## アプローチ

 ブルートフォースアプローチは、スタッキングをシミュレートすることです。空のタワーから開始し、次のボックスが耐久性の制約に違反するまでボックスを追加し、その後新しいタワーを開始します。 すべてのボックスが配置されるまで繰り返します。 これは重み条件を直接適用するため機能しますが、ループする必要があります。`n`各テストケースのボックス。 と`n`50までと`t`10,000 までは管理可能ですが、やりすぎです。 

最適なアプローチでは、次のことが観察されます。`k`ボックス、下部のボックスがサポートします`(k-1) * m`重さ。 壊れないようにするには、`(k-1) * m <= d`。 を解決する`k`与える`k <= d // m + 1`。 タワーの最小数は天井になります。`n`タワーごとの可能な最大高さで割った値:`ceil(n / ((d // m) + 1))`。 これにより、問題はテスト ケースごとの単純な算術計算に削減されます。 

観察はボックスの均一性に依存します。 すべての箱の重量と耐久性は同じなので、最も高い安全なタワーを見つけるだけで済みます。 次に、すべてのボックスをこの高さのタワーに分配することで、タワーの最小数が保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * t) | お(1) | 許容できるが不要 |
 | 最適 | O(t) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`、`m`、 そして`d`。 
3. 箱を壊さずに単一のタワーが取り得る最大の高さを計算します。`max_height = d // m + 1`。 これは解決することから生まれます`(k-1) * m <= d`のために`k`。 
4. 必要なタワーの最小数を次のように計算します。`ceil(n / max_height)`。 整数演算では、これは次のようになります。`(n + max_height - 1) // max_height`。 
5. 各テスト ケースの結果を出力します。 

なぜ効果があるのか​​:`max_height`耐久性を超えるボックスがないことを保証します。 ボックスの総数を で割ると、`max_height`切り上げにより、タワーを最小限に抑えながらすべてのボックスが使用されることが保証されます。 ボックスの均一性により、この不変条件はタワーの分布全体にわたって有効になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m, d = map(int, input().split())
    max_height = d // m + 1
    towers = (n + max_height - 1) // max_height
    print(towers)
```コードは最初に読み取られます`t`、各テスト ケースをループします。`max_height`耐久性と重量から計算され、切り上げによる整数除算が塔の数となります。 式`(n + max_height - 1) // max_height`浮動小数点演算を回避します。 Off-by-One エラーは、手動で丸めを試みるのではなく、上限公式を使用することで回避されます。

 ## 特殊なケース

 もし`d < m`、最大の高さ`d // m + 1`これにより、すべてのボックスが必ず独自のタワーに配置されます。 たとえば、`n = 4`、`m = 5`、`d = 2`、`max_height = 1`、アルゴリズムは次のように計算します。`(4 + 1 - 1) // 1 = 4`、正しく4つのタワーを出力します。 このアルゴリズムは、特別なケースを使用せずに、このシナリオを自然に処理します。 もし`d`の大きな倍数です`m`、 言う`d = 100`、`m = 2`、`n = 10`、`max_height = 51`、 それから`(10 + 51 - 1) // 51 = 1`、すべてのボックスを 1 つのタワーに配置します。これは正しいです。
