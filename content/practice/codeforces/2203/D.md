### なぜ効果があるのか

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        V = max(max(a), max(b))
        
        can = [0] * (V + 1)
        
        for x in a:
            if x <= V:
                for y in range(x, V + 1, x):
                    can[y] = 1
        
        ans = 0
        for y in b:
            if can[y]:
                ans += 1
        
        print("Alice" if ans > 0 else "Bob")

if __name__ == "__main__":
    solve()
```コードはまず、次の少なくとも 1 つの要素で割り切れる範囲内のすべての数値をマークするふるいのような構造を構築します。`a`。 これにより、繰り返しの割り算チェックが、複数にわたる単一の前処理パスに置き換えられます。 

2 番目のループでは、単に要素の数をカウントします。`b`アリスの到達可能なセットに分類されます。 最終的な決定は、このセットが空かどうかに基づいており、これはアリスが合法的な行動を取れるかどうかに直接対応します。
