 ## 解決策
 # 問題の理解

 この問題は氷山の集合を記述しており、各氷山は境界点の座標を通じて単純な多角形として与えられます。 このタスクは、すべての氷山で覆われている合計面積を計算し、その面積の整数部分のみを出力することです。 ポリゴンは重なり合わないため、個々の領域を単純に加算することができます。 入力にはいくつかの独立したポリゴン記述が含まれており、出力はそれらの面積の合計が切り捨てられます。 

ポリゴンの数は 1000 に達することができ、各ポリゴンには最大 50 個の頂点があります。 これは、頂点の総数が最大 50,000 であることを意味するため、各頂点を一定の回数処理するアルゴリズムは容易に十分に高速になります。 すべてのポリゴンのすべてのエッジのペアを比較する方法は、場合によってはこれらの制限でも機能しますが、その必要はありません。 ジオメトリには直接的な式があるため、意図したアプローチでは頂点の数が線形である必要があります。 

主なエッジ ケースは、ポリゴンの向きと部分領域に由来します。 多角形は時計回りまたは反時計回りにリストできるため、符号を考慮せずに符号付き面積の式を直接適用すると、負の結果が生じる可能性があります。 例えば：```
1
4
0 0
0 1
1 1
1 0
```正しい出力は次のとおりです。```
1
```不用意に実装すると、次の符号付き領域が計算される可能性があります。`-1`誤って負の値を出力します。 

もう 1 つのケースは、実領域が整数ではない場合です。 例えば：```
1
3
0 0
1 0
0 1
```実際の面積は、`0.5`したがって、必要な出力は次のようになります。```
0
```答えは最も近い整数に四捨五入されません。 小数部分は常に破棄する必要があります。 

最後によくある間違いは、最後の頂点が最初の頂点に接続されていることを忘れることです。 この入力の場合:```
1
4
0 0
2 0
2 2
0 2
```出力は次のとおりです。```
4
```閉じているエッジを無視すると、不完全なポリゴンが残り、間違った領域が与えられます。 

## アプローチ

 強引なアプローチは、各ポリゴンを多数の小さな部分に分割するか、グリッド上で形状の内部をシミュレートしようとすることです。 座標は正確であり、ポリゴン境界にはすでに十分な情報が含まれているため、これは不要です。 グリッドベースのソリューションは座標範囲に依存し、その範囲は 100 万に達する可能性があり、可能なセルの数が非常に多くなります。 

重要な観察は、靴紐の公式を使用してポリゴン領域をその境界から直接取得できることです。 連続する頂点の各ペアは、原点から形成される三角形の面積を表す符号付きの値を提供します。 すべての寄与が合計されると、重複する符号付き領域が正しくキャンセルされ、ポリゴンの領域が正確に残ります。 

この強引な方法は、氷山の内部を再構築しようとするため機能しますが、境界がすでに形状を完全に描写しているという事実を無視しています。 領域が順序付けられたエッジのみに依存するという観察により、問題をすべての頂点にわたる 1 つのパスに減らすことができます。 

頂点を持つ多角形の場合`(x1, y1), (x2, y2), ... , (xp, yp)`、符号付き double 領域は次のとおりです。$$S = \sum_{i=1}^{p}(x_i y_{i+1} - x_{i+1} y_i)$$ここで、最後の頂点の次の頂点が最初の頂点です。 実際の面積は、`abs(S) / 2`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(座標範囲の面積) | お(1) | 遅すぎる |
 | 靴紐の公式 | O(頂点の総数) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ポリゴン数を読み取ります。 最後のエッジはその頂点に接続し直す必要があるため、ポリゴンごとに最初の頂点を保存します。 
2. すべての頂点をトラバースし、現在の頂点と次の頂点の間の外積寄与を加算します。 貢献度は、`x1*y2 - x2*y1`。 
3. すべてのエッジを処理した後、入力順序によって多角形がどちらの方向にも記述される可能性があるため、累積値の絶対値を取得します。 
4. 2 倍の面積を全体の合計に加算します。 すべてを 2 倍にしておくことで、ジオメトリの処理中の浮動小数点エラーを回避できます。 
5. すべてのポリゴンが処理されたら、2 倍になった合計面積を整数除算を使用して 2 で除算します。 これにより、必要に応じて小数部が自動的に削除されます。 

なぜ効果があるのか:

 靴紐の式は、多角形を符号付き三角形に分解することに基づいています。 頂点を反時計回りに並べると、すべての三角形がプラスに寄与します。 時計回りに並べると、すべての寄与は負になります。 絶対値をとると実際の2倍の面積が復元されます。 ポリゴンは重なり合わないため、すべてのポリゴンの 2 倍の面積を加算すると、カバーされる合計面積がちょうど 2 倍になります。 整数を 2 で割ると、必要な下限値が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    total2 = 0

    for _ in range(n):
        p = int(input())
        points = []

        for _ in range(p):
            x, y = map(int, input().split())
            points.append((x, y))

        area2 = 0
        for i in range(p):
            x1, y1 = points[i]
            x2, y2 = points[(i + 1) % p]
            area2 += x1 * y2 - x2 * y1

        total2 += abs(area2)

    print(total2 // 2)

if __name__ == "__main__":
    solve()
```現在の境界のみが必要であるため、入力はポリゴンごとに処理されます。 点のリストは、最後の頂点を最初の頂点に接続できるように一時的に保存されます。 

表現`(i + 1) % p`終了エッジを処理します。 モジュロ演算を行わないと、すべてのポリゴンの最後の辺が失われます。 

計算では、浮動小数点値の代わりに 2 倍の領域が使用されます。 座標は 100 万にも達するため、外積も大きくなる可能性がありますが、Python の整数は必要な値を保持するために自動的に拡張されます。 各ポリゴンには独自の方向がある可能性があるため、最終的な答えに追加する前にポリゴンごとに絶対値が適用されます。

 ## 特殊なケース

 右回りの多角形は符号付き面積の絶対値をとって扱います。 のために：```
1
4
0 0
0 1
1 1
1 0
```累積された2倍の面積は`-2`。 アルゴリズムはそれを次のように変換します`2`を 2 で割って取得します。`1`。 

端数の面積を持つポリゴンは、最終操作まで 2 倍の値を保持します。 のために：```
1
3
0 0
1 0
0 1
```2倍の面積は`1`。 アルゴリズムは計算します`1 // 2`、生産`0`、これは必要な床の動作と一致します。 

最後の頂点の後の最初の頂点を使用して、終了エッジが含められます。 のために：```
1
4
0 0
2 0
2 2
0 2
```～からの最後の貢献`(0,2)`に戻る`(0,0)`が含まれており、面積が 2 倍になります`8`そして最終的な答え`4`。
