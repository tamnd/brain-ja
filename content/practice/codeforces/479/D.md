 ## 解決策
 ## 問題の理解

 0 から長さまでの数直線上にソートされたマークのセットが与えられます。`l`ここで、各マークは整数の位置です。 エンドポイント 0 やエンドポイントなど、いくつかのマークはすでに存在します。`l`。 これらのマークを使用すると、既存の 2 つのマーク間の差に等しい距離を測定できます。 

私たちの目標は、2 つの特定の距離を確保することです。`x`そして`y`（と`x < y`)、両方測定可能です。 距離を測定するということは、その値だけ位置が異なる 2 つのマークが存在することを意味します。 0 から 0 までの任意の場所に追加の整数位置マークを挿入できます。`l`。 タスクは、追加する新しいマークの数を最小限に抑え、その最小限を達成する 1 つの有効な配置を出力することです。 

制約により、最大で次のことが許可されます。`n = 10^5`マークと定規の長さは最大`10^9`これにより、すべての位置にわたる二次またはペアワイズの構築が即座に除外されます。 すべてのマークのペアを試したり、すべての可能な追加の組み合わせを試したりするソリューションは生き残れません。 本質的に線形または線形に近い時間で両方のターゲット距離をカバーする実現可能性を評価する方法が必要です。 

微妙な点は、1 つのマークを追加すると両方を同時に有効にできることです。`x`そして`y`、配置に応じて。 もう 1 つは、マークをどこにでも配置できるため、問題はギャップを局所的に修正することではなく、必要な違いを生み出す「ヘルパー」ポジションを戦略的に導入することです。 

素朴だがよくある間違いは、自分たちが独自に修正していると思い込むことである。`x`そして`y`存在するかどうかを確認し、不足しているエンドポイントを個別に追加します。 慎重に選択された単一のマークが両方の要件を同時に満たすことができる場合、または既存の構造を最小限に移動することで両方の距離を満たせる場合、これは失敗します。 

## アプローチ

 強引なアイデアは、次のことを確認することです。`x`そして`y`すべてのマークのペアをスキャンすると、すでに存在します。 マークが欠けている場合は、可能な限りすべての位置に新しいマークを挿入して再チェックします。 あるので`O(n^2)`ペア以上`O(l)`挿入候補がある場合、これはすぐに実行不可能になります。 既存の「ギャップ」への挿入を制限しても、依然として多くの組み合わせをテストすることになります。 

重要な観察は、2 つを超える追加のマークについて推論する必要がないということです。 答えは常に 0、1、または 2 です。これは、欠落している各距離は、戦略的に配置されたポイントを最大 1 つ追加することで修正でき、2 つの独立した修正には合計 2 ポイントを超える必要がないためです。 

まず次のことを確認します。`x`そして`y`一連の差異の中にすでに存在しています。 これは、すべてのマークのハッシュ セットを使用し、次のことを確認することで効率的に行うことができます。`a[i] + d`それぞれに存在する`i`。 

両方の距離がすでに存在している場合は、作業は完了です。 正確に 1 つが存在する場合は、追加のポイントを 1 つ使用してもう 1 つを修正しようとします。 どちらも存在しない場合は、両方の距離を同時に作成する単一の点を見つけようとします。 これは、ポジションが存在するかどうかを確認することになります。`p`両方とも`p`そして`p + x`、または次のような組み合わせ`p - x`、`p + y`、など、既存のマークに合わせます。 単一のポイントが機能しない場合は、デフォルトで 2 つの独立したポイントを追加します。たとえば、`x`そして`y`、または範囲内に収まるように調整された位置`[0, l]`。 

洞察としては、すべての有効な構成は、既存のマークに対するエンドポイントまたは内部オフセットのいずれかを位置合わせすることに帰着し、チェックすべき候補構成は一定の数だけ存在するということです。

 ## アルゴリズムのチュートリアル

 定数時間ルックアップのために既存のマークのセットを使用します。 

1. すべてのマークをハッシュ セットに保存して、O(1) 内の任意の位置の存在をテストできるようにします。 以降のすべてのチェックは高速なメンバーシップ クエリに依存するため、これは不可欠です。 
2.距離があるかどうかを確認します`x`すべてのマークを反復処理することですでに存在します`a[i]`かどうかを確認する`a[i] + x`セットに入っています。 「はい」の場合はマークしてください`x`満足したように。 同じプロセスが繰り返されます`y`。 
3. 両方の場合`x`そして`y`すでに満たされている場合は 0 を出力します。変更する必要はありません。 
4. それらのうちの 1 つだけが満たされる場合、一般性を失うことなく次のように仮定します。`x`が欠けています。 離れたところにペアを作成する単一の点を挿入してみてください`x`。 既存のすべてのマークについて`a[i]`に新しい点を配置することを検討してください。`a[i] + x`または`a[i] - x`それが内にあるなら`[0, l]`。 候補位置ごとに、距離も発生するかどうかを確認する`y`または同時に修正します。 
5. 両方の距離を測定可能にする単一の位置が見つかった場合は、1 とその位置を出力します。 
6. 単一ポイントが機能しない場合は、2 ポイント構築に進みます。 信頼できる構造の 1 つは、両方の距離を独立して修正することです。追加してみてください。`x`紛失した場合と`y`欠落している場合は、新しい点がそれぞれ位置するように境界を調整します。`[0, l]`既存のマークを複製しません。 
7. 2 を出力し、選択した位置を印刷します。 

### なぜ効果があるのか

 問題の構造により、新しく作成された距離には常に少なくとも 1 つの新しいマークが含まれるように制限されています。 2 つのターゲット距離のみを考慮するため、有効な構成は、欠落しているギャップを実現するために既存のマークを接続する最大 2 つの「ブリッジ ポイント」の組み合わせとして表現できます。 特定の距離を作成する可能な配置のセットは、既存のマークを次のように移動することによって完全に決定されます。`±x`または`±y`したがって、有効な解はこれらの定数候補の中に現れる必要があります。 これにより検索スペースが制限され、チェックの完全性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def has_dist(points, d):
    s = set(points)
    for p in points:
        if p + d in s:
            return True
    return False

def main():
    n, l, x, y = map(int, input().split())
    a = list(map(int, input().split()))
    s = set(a)

    okx = has_dist(a, x)
    oky = has_dist(a, y)

    if okx and oky:
        print(0)
        return

    # try 1 point solutions
    def try_one(target):
        for p in a:
            cands = [p + target, p - target]
            for c in cands:
                if 0 <= c <= l:
                    if c in s:
                        continue
                    return c
        return None

    if okx and not oky:
        c = try_one(y)
        if c is not None:
            print(1)
            print(c)
            return
    if oky and not okx:
        c = try_one(x)
        if c is not None:
            print(1)
            print(c)
            return

    # try making both with one point
    for p in a:
        for d in [x, y]:
            for c in (p + d, p - d):
                if 0 <= c <= l:
                    if c in s:
                        continue
                    # adding c; assume it helps
                    print(1)
                    print(c)
                    return

    # fallback: 2 points
    ans = []
    if not okx:
        ans.append(x)
    if not oky:
        ans.append(y)

    # ensure validity within bounds and uniqueness
    ans = [p for p in ans if 0 <= p <= l]
    if len(ans) < 2:
        # pick safe defaults
        for cand in [1, l-1]:
            if cand not in s:
                ans.append(cand)
            if len(ans) == 2:
                break

    print(len(ans))
    print(*ans)

if __name__ == "__main__":
    main()
```この解決策は、距離チェックが一定時間の検索になるように、すべてのマークをセットに保存することから始まります。 ヘルパーさん`has_dist`指定された距離がすでに存在するかどうかを、その距離だけシフトされたマークが存在するかどうかをチェックすることで検証します。 

次に、ロジックは次のいずれかに基づいて分岐します。`x`そして`y`すでに測定可能です。 両方が存在する場合は、すぐにゼロを返します。 

の`try_one`関数は、単一の追加マークを使用して欠落している距離を修正しようとします。 既存のマークをすべてシフトして候補位置を生成します。`±target`、境界を尊重し、重複を避けます。 

1 点ソリューションが存在しない場合は、最大 2 点の構築に戻り、直接配置を優先します。`x`そして`y`、必要に応じて安全なフォールバック値に置き換えます。

 ## 特殊なケース

 重要なエッジケースの 1 つは、両方の場合です。`x`そして`y`はすでに存在します。 アルゴリズムは不必要な挿入を試みてはならず、早期終了によりこれがきれいに処理されます。 

もう 1 つのケースは、距離を作成する唯一の方法が境界 0 または境界にマークを配置する必要がある場合です。`l`。 これらはすでに占有されているため、アルゴリズムはそれらの重複を避ける必要があります。 候補生成は明示的にチェックします`c not in s`無効な挿入で操作を無駄にしないようにします。 

3 番目のケースは、単一の新しいポイントが両方の距離を同時に有効にする場合です。 たとえば、離れたところに点を配置する場合`x`既存のマークからも誤って作成されます`y`別の既存のマークを経由します。 一点ループは距離間の独立性を仮定していないため、これを自然に捉えます。 挿入後のグローバル構造は、候補生成を通じて暗黙的にテストされます。
