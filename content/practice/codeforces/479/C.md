 ## 問題の理解

 それぞれに関連する 2 日が含まれる一連の試験が与えられます。 公式スケジュールでは試験が割り当てられます`i`一日`a_i`ただし、学生はその日より早く受講できる特別な協定を結んでいます。`b_i`、 どこ`b_i < a_i`。 試験が行われるたびに、大学は予定された日付を使用して試験を記録します。`a_i`、実際に撮影された日ではありません。 

学生は同日に複数の試験を受けることができ、その日の順番は関係ありません。 ただし、成績証明書に記録された日付の順序は、試験を受けた順序で減少していない必要があります。 これにより、スケジュールの選択と順序の間にカップリングが生じます。リアルタイムでより早い時期に検査を選択すると、成績証明書の順序の制約を破ることなく将来の検査を実施できるかどうかに影響する可能性があります。 

目標は、有効な一連の記録を生成しながら、試験が実際に受験される最後の日を最小限に抑えることです。`a_i`値は降順ではありません。 

制約`n ≤ 5000`を暗示します`O(n^2)`または`O(n log n)`解決策は受け入れられますが、すべての順列またはサブセットを列挙するようなことは直ちに実行不可能です。 試験の順序に対する階乗または指数関数的な戦略は、中等度の場合でも限界を超えて爆発する可能性があります。`n`。 

微妙なエッジケースは、初期の選択により後の試験で実現可能性の余地が失われる場合に現れます。 たとえば、ある試験で非常に小さな問題があった場合、`b_i`しかし、大きい`a_i`選択が遅すぎると、今後のすべての配置がブロックされる可能性があります。`a_i`は 2 つの選択肢の間にあります。 

もう 1 つのエッジケースは、複数の試験が同じものを共有する場合です。`a_i`。 トランスクリプトの順序は減少しないため、等しい値を任意にグループ化できますが、誤った貪欲な決定によって最終日が不必要に高く設定される可能性があります。 

## アプローチ

 ブルートフォース戦略では、各試験を当日に受験するというあらゆる可能な選択肢が考慮されます。`b_i`または`a_i`次に、検査のすべての順列を試して、記録されたシーケンスがソートされている有効な順序を見つけます。 各構成について、実現可能性をチェックし、選択された実際の最大日を追跡します。 このアプローチでは、代入と順序付けスペースの両方を暗黙的に調査し、`O(2^n * n!)`最悪の場合の行動は、たとえ`n = 20`。 

重要な観察点は、記録された値の順序が`a_i`実現可能性を制約する唯一のものです。 成績証明書に記載される試験の順序を決定したら、その順序に違反することなく、各試験をできるだけ早くスケジュールするだけで済みます。 私たちに本当に与えられた唯一の自由は、各試験を次の日に行うかどうかを選択することです。`b_i`または`a_i`そして、その決定の影響は、他の試験と比較してどれだけ早くスケジュールを設定できるかです。 

試験を予定された締め切り順に並べ替えると`a_i`、トランスクリプトの自然な順序を強制できます。 残りの課題は、どの試験を後日に延期するかを決定することです`a_i`安全に移動できるのはどれか`b_i`最終完成日を短縮します。 

試験は増加傾向にあります`a_i`。 各ステップで、試験をより早い日にスケジュールしようとします。`b_i`。 そうすることで、すでに予定されている決定の実現可能性に違反する場合は、スペースを空けるために、以前に選択した一部の早期試験を後の日に「延期」する必要があります。 この決定の構造は、順序付けの制約の下で初期割り当ての最大セットを選択することに似ており、最も高価な初期の選択肢を犠牲にすることで競合が解決されます。 

これにより、常に初期の割り当てを可能な限り長く保持し、必要な場合にのみ再割り当てを行い、最終日を最小限に抑えるという貪欲な戦略が生まれます。

 ## アルゴリズムのチュートリアル

 1. すべての試験を予定日ごとに並べ替えます`a_i`。 記録された値は減少しない必要があるため、これによりトランスクリプトの順序が固定されます。 
2. 現在初期日に割り当てられている一連の試験を維持する`b_i`。 また、処理されたすべての試験について、現在選択されている一連の実際の日を追跡します。 
3. 並べ替えられた順序で試験を繰り返します。`a_i`、試験ごとに受験するかどうかを決定します。`b_i`または強制的に`a_i`。 
4. 現在の試験を暫定的に当日に割り当てます`b_i`。 これにより、最終的な答えへの影響が最小限に抑えられるため、常にこれを最初に試します。 
5. この選択によって実際の日の順序に矛盾が生じたり、構造が無効になったりする場合は、以前に選択した初期の割り当ての 1 つを元に戻すことで問題を解決します。 元に戻す正しい候補は、実現可能性を維持するという点で最も「コストがかかる」候補であり、通常は最大の候補です。`b_i`将来の柔軟性がほとんど妨げられるため、早期選択の中でも優先されます。 
6. すべての試験を処理した後、選択したすべての課題の中で最大の日を計算します。これは、ヴァレラが実際に試験を受ける最後の日です。 

### なぜ効果があるのか

 並べ替え基準-`a_i`順序付けにより、トランスクリプトの有効性が単一のグローバルな非減少シーケンスを尊重するように削減されます。 この枠組み内では、すべての試験で早いポジションと後のポジションの選択が行われます。最終日を短縮する唯一の方法は、早期のポジションの数を最大化することです。 競合が発生した場合は常に、現在最も制限的な初期割り当てを削除すると、割り当てが小さく保たれるため、将来の柔軟性が最大限に保たれます。`b_i`後の試験で利用できるオプション。 この貪欲な交換引数により、代替シーケンスが実現可能性を侵害することなく、より小さい最大日数を達成できないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
exams = []
for i in range(n):
    a, b = map(int, input().split())

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import isclose

    n = int(input())
    exams = []
    for _ in range(n):
        a, b = map(int, input().split())
        exams.append((a, b))
