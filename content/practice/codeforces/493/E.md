 ## 解決策
 ## 問題の理解

 非常に特殊な評価特性を満たす、負ではない整数係数を持つ多項式の数を数えるように求められます。 形式的には、整数が与えられます$a$、$b$、 そして$c$そして、すべての多項式を見つける必要があります$P(x) = a_0 + a_1 x + a_2 x^2 + \dots + a_n x^n$多項式が次のように評価されるように、$x = a$等しい$c$マイナス$b$で評価される多項式の倍$x = 1$。 より直観的には、負でない整数のシーケンスを見つけようとしています。$a_0, a_1, \dots, a_n$そのような$$P(a) = b \cdot P(1) + c.$$ここ、$a$そして$b$と同じ大きさにすることができます$10^{18}$これにより、考えられるすべての多項式の単純な列挙が即座に除外されます。 出力は次のいずれかになります。`"inf"`このような多項式が無限に多く存在する場合、または count modulo$10^9 + 7$さもないと。 

制約には、いくつかの非自明なエッジケースが含まれます。 たとえば、次のようなとき$b = 1$、多項式評価が次の場合、方程式には無限に多くの解が存在することがあります。$x = a$と一致しています$c$ある意味で。 別の微妙な問題が発生する場合、$a < b$; すべての係数値を試す単純な再帰的アプローチでは、次のべき乗がより高いケースを見逃す可能性があります。$a$平等を支配する。 などの小さな入力$a = 1$、$b = 1$、 そして$c = 0$存在しない多項式をカウントしないように、慎重に処理する必要があります。 

## アプローチ

 ブルートフォース手法では、負でない整数のシーケンスをすべて列挙します。$(a_0, a_1, ..., a_n)$そのような$P(a) = b \cdot P(1) + c$。 各ステップで、考えられる係数の値をすべて試します。$a_i$方程式が満たされるまで。 これは原理的には正しいですが、たとえ小さなものであっても、$a$そして$b$、シーケンスの数は次数とともに指数関数的に増加します。$n$、そして$a, b \le 10^{18}$、これはまったく不可能です。 

効率的な解決策を可能にする重要な観察は、問題が次の数字のような表現に帰着するということです。$c$基地内で$a$。 次の方程式を考えてみましょう。$$a_0 + a_1 a + a_2 a^2 + \dots = b \cdot (a_0 + a_1 + a_2 + \dots) + c.$$書き直すと、わかります$$(a - b) a_1 + (a^2 - b) a_2 + \dots = c - b a_0.$$これは再帰的なアプローチを示唆しています: pick$a_0$、残りの合計を で割ったかどうかを再帰的に確認します。$a$剰余による基数変換と同様に、同じ形式を満たします。 このアプローチは、再帰ごとに係数の合計が減少し、十分に小さい基底では最大でも係数の合計が減少するため、効率的に機能します。$O(\log_a c)$再帰的なステップ。 エッジケースが発生するのは次の場合です$a = b$再帰により無限の解が得られる可能性があるためです。 この状態を確認すると返品が可能になります`"inf"`一定時間内に。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(∞) | O(n) | 遅すぎる |
 | 再帰的 / 数字のような分解 | O(log_a c * a) | O(log_a c) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.次のことを確認します$a = 1$。 この場合、多項式は次のように評価されます。$x = 1$は単に係数の合計です。 方程式は次のようになります。$sum = b \cdot sum + c$。 もし$b = 1$そして$c = 0$、解決策は無限にあります。 もし$b = 1$そして$c > 0$、解決策は存在しません。 さもないと、$sum = c / (1 - b)$整数でなければなりません。 そうでない場合は 0 を返します。 それ以外の場合は、合計がこの値になる非負の整数係数を持つシーケンスの数を数えます。これは、標準的な星と棒の組み合わせ問題です。 
2. それ以外の場合は、再帰関数を実装します。`solve(n)`どこ`n`残りの目標値です。 再帰ごとに剰余を考慮します`n % a`係数として`a_0`そして再帰的に`n // a - b * a_0`。 残りの合計が負になったときに再帰を終了します。 
3. 再帰ごとに有効なシーケンスの数を累積します。 残りの有効な選択はそれぞれ 1 つの解決策に寄与します。 
4. 再帰中に次のことが検出された場合`a - b = 0`残りのターゲットは適切に割り切れます。 return`"inf"`。 
5. シーケンスの合計数を剰余として返します。$10^9 + 7$。 

正確さは、各再帰呼び出しでのターゲット数値が、その時点で評価された多項式の差に正確に一致するという不変式から得られます。$a$そして$b$係数の合計を乗算し、これまでに選択した係数によってシフトします。 すべての係数は負ではないため、この再帰では、すべての有効なシーケンスが欠落したり二重にカウントされたりすることなく探索されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 10**9 + 7

def count_polynomials(a, b, c):
    if a == 1:
        if b == 1:
            if c == 0:
                return "inf"
            else:
                return 0
        s = c // (1 - b)
        if s < 0 or s * (1 - b) != c:
            return 0
        return 1  # Only one way to split sum into coefficients of polynomial
    ans = 0
    n = c
    while n >= 0:
        if n % a == 0 and (n // a - b * (n % a)) >= 0:
            ans += 1
        n -= b
    return ans % MOD

a, b, c = map(int, input().split())
print(count_polynomials(a, b, c))
```ソリューションは最初に、`a = 1`特殊なケース、返品`"inf"`必要に応じて。 のために`a > 1`、最小の係数として機能する候補の剰余を繰り返しチェックし、残りの値によってより高い累乗への有効な分解が可能であることを確認します。 モジュロは最後に適用されます。
