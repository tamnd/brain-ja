 ## 解決策
 ## 問題の理解

 私たちはウェイトリフティングの大会を開催します`n`スポーツ選手。 アスリート`i`力がある`s_i`そして耐久力`e_i`。 

バーベルの重さ`w`が選ばれます。 体力が以下のアスリート`w`バーベルをまったく持ち上げることができません。 少なくとも次の強さを持つアスリート`w`正確に持ち上げます`e_i`回。 勝者は、リフト回数が最も多いユニークなアスリートです。 複数のアスリートが最高の数字で並んだ場合、誰も勝ちません。 

ポリカルプはアスリートです`1`。 何らかの重みが存在するかどうかを判断する必要があります`w`これにより、Polycarp が唯一の勝者になります。 そのような重みが存在する場合、任意の有効な値を出力できます。`w`。 それ以外の場合は出力します`-1`。 

制約は非常に小さいです。 多くてもあります`100`アスリートはテストケースごとに、最大でも`100`テストケース。 たとえ`O(n²)`ここでの解決策は簡単です。 考えられるすべての重みを反復処理する必要がないため、大きな強度値は問題になりません。 私たちが必要としているのは、どのアスリートが特定の選択肢の資格を維持しているかについて推論することだけです。`w`。 

よくある間違いは、明確な勝利重みをすぐに見つけることに集中することです。 考慮する：```
Polycarp: (7, 4)
Other:    (9, 3)
```選択する`w = 5`両方のアスリートが競争することを許可しますが、ポリカルプが勝ちます。`4 > 3`。 

もう 1 つの簡単な間違いは、ネクタイを忘れることです。 考慮する：```
Polycarp: (1337, 3)
Other:    (1337, 3)
```Polycarp が許可される体重であれば、他のアスリートも許可されます。 リフト数は等しいため、唯一の勝者が存在することはありません。 答えは`-1`。 

3 番目の微妙なケースは、別のアスリートがより強く、少なくとも同じくらいの持久力を持っている場合に発生します。```
Polycarp: (4, 6)
Other:    (100, 100)
```Polycarp が参加できる体重であれば、他のアスリートの方が強いため、他のアスリートも参加できます。 他の選手のリフティング回数が多いため、ポリカルプは決して勝つことができません。 

## アプローチ

 ブルートフォースの観点は、関連するすべてのバーベル重量を試し、競争をシミュレートすることです。 強みは次のように大きくなる可能性があるため、`10^9`、すべての可能な重みを反復処理することは不可能です。 適格なアスリートのセットは筋力のしきい値を超えた場合にのみ変更されるため、検索対象を入力に表示される個別の筋力値に減らすことができます。 これは、これらの制約に対してすでに十分な速度です。 

さらに単純な観察もあります。 

別のアスリートが少なくともポリカルプの筋力と少なくともポリカルプの持久力の両方を持っていると仮定します。 そして、Polycarp がバーベルを持ち上げることができるときはいつでも、そのアスリートもバーベルを持ち上げることができます。 アスリートの持久力は小さくないので、ポリカルプが唯一の勝者になることは決してありません。 

逆に、両方の条件を同時に満たすアスリートがいない場合は、```
w = s₁
```Polycarp を対象にします。 以下の強さを持つアスリート`s₁`すぐに排除されます。 少なくとも体力のあるアスリートなら誰でも`s₁`耐久性は厳密に以下でなければなりません`e₁`そうでない場合は、両方の条件を満たします。 したがって、Polycarp は残りのすべての競合他社よりも厳密に耐久力が高く、唯一の勝者になります。 

これにより、問題全体がアスリートが存在するかどうかの確認に変わります。`i > 1`そのような```
s_i ≥ s₁ and e_i ≥ e₁.
```もしそんな選手がいるとしたら、答えはこうだ。`-1`。 さもないと`w = s₁`動作します。

 ## アルゴリズムのチュートリアル

 1.ポリカルプの強さを読む`s₁`そして耐久力`e₁`。 
2. 他のすべてのアスリートについて、両方の条件が当てはまるかどうかを確認します。```
s_i ≥ s₁
e_i ≥ e₁
```3. そのようなアスリートがいる場合は、印刷します。`-1`。 

この選手はポリカルプと少なくとも同じくらい強く、少なくとも同じくらい持久力がある。 Polycarp が参加できるときはいつでも、このアスリートも参加できるため、Polycarp 独自の勝利が妨げられます。 
4. そのようなアスリートが存在しない場合は、印刷します。`s₁`。 

選択する`w = s₁`Polycarp が参加することを保証します。 他のすべての参加アスリートは、持久力が厳密に以下でなければなりません。`e₁`, したがって、ポリカルプは独自に勝ちます。 

### なぜ効果があるのか

 アスリートがポリカルプを脅すことができるのは、ポリカルプが資格を持っているときは常に、自分がまだ資格を持っている場合のみです。 少なくとも体力は必要だ`s₁`。 

これらのアスリートの中で、ポリカルプが唯一の勝者となるのを阻止できるのは、少なくとも持久力が高い選手だけです。`e₁`。 

したがって、次のようなスポーツ選手の存在は、```
s_i ≥ s₁ and e_i ≥ e₁
```まさに勝利を不可能にする条件だ。 

そのようなアスリートが存在しない場合は、`w = s₁`弱いアスリートをすべて排除し、Polycarp よりも持久力が厳密に小さいアスリートだけを残します。 したがって、ポリカルプは唯一の勝者になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())

        s1, e1 = map(int, input().split())
        possible = True

        for _ in range(n - 1):
            s, e = map(int, input().split())

            if s >= s1 and e >= e1:
                possible = False

        print(s1 if possible else -1)

solve()
```実装は証明に直接続きます。 

Polycarp のパラメータを保存し、残りのアスリートを一度スキャンします。 強さと持久力の両方が少なくともポリカルプの値であるアスリートを見つけた場合、その答えは不可能であるとマークされます。 

各競技者は個別に検査されるため、すべての競技者を保存する必要はありません。 このソリューションでは、一定の追加メモリを使用します。 

比較には使用する必要があります`>=`それよりも`>`。 まったく同じ持久力を持つアスリートでも同点となり、唯一の勝者を妨げることになります。

```そして出力`-1`。 Polycarp が許可される体重であれば、他のアスリートも許可され、同点になります。 

考慮する：```
1
2
10 5
100 4
```2 番目のアスリートはより強力ですが、持久力が低くなります。 アルゴリズムは耐久条件が失敗したことを確認し、出力します。`10`。 選択する`w = 10`両方のアスリートが競うことができますが、Polycarp はバーベルを 5 回持ち上げ、もう一方のアスリートは 4 回バーベルを持ち上げます。

```2 人目の選手は持久力は非常に優れていますが、筋力が不十分です。 選択する`w = 10`その選手を完全に排除します。 アルゴリズムは正しく出力します`10`。

```2 番目の選手は、強さと持久力の両方でポリカルプを圧倒します。 どの有効な重量が選択されたとしても、Polycarp がバーベルを持ち上げることができれば、2 番目のアスリートもバーベルを持ち上げることができ、2 番目のアスリートはより多くの回数持ち上げることができます。 アルゴリズムはこの支配を検出し、出力します。`-1`。
