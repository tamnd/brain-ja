 ## 問題の理解

 私たちに与えられたのは、根を張った木です。$n$頂点。頂点 1 がルートです。 各頂点$i > 1$親がいる$p_i$したがって、ツリーはこの親配列によって自然に定義されます。 このタスクは、対話型ゲームで任意の頂点に配置されたチップが、選択した色のエッジのみをたどることによって常に正しくルートに移動できるように、最小限の色を使用してツリーのエッジに色を付けることです。 問題は、各ステップで、現在の頂点に各色のエッジが何本あるかしか分からず、チップがどの頂点上にあるか、ルートに到達するまでに何ステップ残っているかは分からないということです。 

出力はすべてのエッジのカラーリングです。 その後、現在の頂点における各色の入射エッジの数を表すベクトルを繰り返し受け取り、それに沿って移動する色を選択する必要があります。 無効な色を選択した場合、またはルートに正確に到達できなかった場合$d$ステップを踏むと、ゲームは負けで終了します。 それ以外の場合は、ルートに到達すると勝利の合図になります。 

制約が教えてくれる$n \le 100$。 これでも十分小さいので、$O(n^2)$アルゴリズムは許容されますが、可能なカラーリングの数は指数関数的に増加するため、すべてのカラーリングをブルートフォースすることはできません。$n$。 確実に勝利する戦略を確立するには、慎重なアプローチが必要です。 

非自明なエッジ ケースは、複数のエッジが頂点に入射する同じ色を共有する場合に発生します。 素朴なアプローチでは、すべてのエッジを同じ色にし、チップが常に根元に向かって移動できると想定する可能性があります。 これはチェーンでは失敗します。4 つの頂点のパスで、すべてのエッジを同じ色にすると、同じ色の複数のエッジが誤った方向に向かう可能性があるため、チップがルートへのパスを一意にたどることができなくなる可能性があります。 同様に、次数の高い頂点では、どのエッジがルートにつながるかを選択する際の曖昧さを防ぐために、慎重に色付けする必要があります。 

## アプローチ

 ブルートフォース手法では、エッジへの色の割り当てをすべて試し、チップの敵対的な配置をすべてシミュレートします。 色ごとに、チップをルートに移動する保証された戦略が存在するかどうかを確認します。$d$ステップ。 このアプローチはすべての可能性を徹底的にテストするので正しいですが、絶望的に時間がかかります。$k^{n-1}$エッジカラーリング$k$色は指数関数的です$n$。 と$n \le 100$、 平$k = 2$すでに$2^{99}$、それは不可能です。 

重要な洞察は木の構造から得られます。 すべての頂点について、その子に接続されているすべてのエッジが個別の色を持つことを確認するだけで済みます。 頂点のすべての子エッジが一意の色を持つ場合、インタラクターは同じ色の複数のエッジで曖昧さを生み出すことができないため、チップは常に正しいエッジを選択してルートに向かって移動できます。 これにより、問題は、同じ頂点に属するエッジ間で色が繰り返されないように、各頂点がその子間で色を分配する貪欲なカラーリングに帰着します。 

この観察により、必要な色の数も自然に制限されます。色の最小数はツリーの最大次数に等しくなります。 最も高い次数を持つ頂点には、チップがその頂点上にあるときのあいまいさを避けるために、多くの異なる色が必要になります。

 ## アルゴリズムのチュートリアル

 1. 入力からツリーを解析し、各頂点の隣接リストを保存します。 隣接リストを作成する際に、各頂点の次数を追跡します。 
2. 最大次数を計算する$\Delta$木の。 これは、勝利を保証する戦略を保証するために必要な最小限の色の数になります。 
3. ルートから開始して深さ優先の走査を実行します。 各頂点について、その子と接続するエッジに色を割り当てます。 ルートに戻るパスに沿った競合を避けるために、親につながるエッジの色をスキップします。 色を 1 から 1 まで循環します。$\Delta$各子エッジに個別の色を割り当てます。 
4. 色の総数と、親と子を接続する各エッジの色を頂点インデックスの順に出力します。 
5. インタラクティブなゲームループに入ります。 各ステップで、入射エッジのベクトルを色ごとに読み取ります。 任意の色を選択してください$c$そのような$e_c > 0$。 出力をフラッシュすると、インタラクターが私たちの動きを認識できるようになります。 ゲームが勝ち (1) または負け (-1) を示すまで続けます。 

機能する理由: どの頂点でも、同じエッジの色を共有する 2 つの子は存在しません。 したがって、最悪の場合の敵対的配置であっても、チップはルートに向かって移動する選択した色の固有のエッジを常に持ちます。 親のエッジの色が子の間で決して再利用されないようにすることで、チップがスタックしたり誤って移動したりする可能性のあるサイクルや曖昧さを防ぎます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import defaultdict

n = int(input())
p = list(map(int, input().split()))

adj = [[] for _ in range(n + 1)]
degree = [0] * (n + 1)

for i, parent in enumerate(p, 2):
    adj[parent].append(i)
    adj[i].append(parent)
    degree[parent] += 1
    degree[i] += 1

k = max(degree)
colors = [0] * (n + 1)

def dfs(u, parent, parent_color):
    color = 1
    for v in adj[u]:
        if v == parent:
            continue
        if color == parent_color:
            color += 1
        colors[v] = color
        dfs(v, u, color)
        color += 1

dfs(1, 0, 0)

print(k)
print(' '.join(map(str, colors[2:])))
sys.stdout.flush()

while True:
    line = input()
    if line is None:
        break
    line = line.strip()
    if line == '1' or line == '-1':
        break
    _ = input()
    # pick the first color available
    print(1)
    sys.stdout.flush()
```説明: ツリーを構築し、次数を計算します。 の`dfs`関数は、親のエッジの色を避けながら、子のエッジに色を付けます。`colors[v]`エッジの色を親から子に保存します。 ゲーム ループはインタラクター入力を読み取り、動きに使用できる最初の色を選択するだけです。 カラーリングによって曖昧さがなくなるため、この選択が機能します。
