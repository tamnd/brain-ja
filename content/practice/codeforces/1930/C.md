 ## 解決策
 ## 問題の理解

 配列が与えられています`a`長さの`n`。 タスクは、要素を繰り返し選択することです。`a`、その値と現在のインデックスをセットに追加します。`S`、配列からそれを削除し、次まで続行します。`a`は空です。 すべての挿入後、セットを並べ替えます`S`降順で配列を形成する`b`。 目標は、次から要素を選択することです。`a`結果として`b`辞書順に可能な限り大きくなります。 

の各要素`S`次のように計算されます`a_i + i`どこ`i`は選択時の 1 から始まる位置です。 以来`S`はセットであるため、重複は無視されます。 したがって、後で同じ合計を生成する要素を選択しても結果は改善されないため、順序付けが重要になります。 制約により許可されるのは、`n`まで`3 * 10^5`すべてのテスト ケースの合計の上限は次のとおりです。`3 * 10^5`つまり、テスト ケースごとに O(n log n) のアルゴリズムは実行可能ですが、O(n^2) のアプローチは遅すぎます。 

値が次の場合、微妙なエッジ ケースが発生します。`a`厳密には増加または減少しています。 例えば、`a = [2, 1]`は、最初の最大のものを削除するとより固有の合計が生成されますが、最初の小さいものを削除すると重複が生じる可能性があることを示しています。 別のケースは、すべてが`a_i`等しい、言う`a = [1, 1, 1]`。 要素を末尾から選択すると、現在のインデックスとの合計が最大になります。`a_i + i`と増加します`i`。 

## アプローチ

 ブルートフォースアプローチでは、削除命令のあらゆる順列を試み、`S`、それを並べ替えてフォームにします`b`。 これは正しいですが、まったく実行不可能です。`n!`順列、さらには`n = 10`、これはすでに 360 万通りの可能性があります。 

重要な洞察は、`S`要素とその現在のインデックスの合計にのみ依存します。 辞書編集的に最大化するには、最大値が最初に表示されるようにします。`b`。 それぞれの値について`a_i`、後の位置ほどインデックスが大きくなるため、できるだけ遅く選択すると最大の合計が得られます。 したがって、最大化するには`b`、最初に配列の末尾から要素を選択することをシミュレートする必要があります。 また、重複したものを挿入することも避けなければなりません。`S`したがって、セットを使用して挿入された値を追跡します。 

具体的に繰り返すと`a`逆の順序で計算してください`a_i + i`それぞれに`i`逆に、それぞれの合計を加算します`S`以前に出現したことがない場合のみ、並べ替えます`S`降順で、必要な辞書編集上最大のものが生成されます`b`。

 ## アルゴリズムのチュートリアル

 1. 空のセットを初期化する`S`一意の合計を保存するため。 
2. 反復処理`a`最後の要素から最初の要素まで。 
3. 各要素について`a[i]`0 から始まるインデックスで`i`、計算します`a[i] + (i + 1)`1 から始まるインデックスを考慮するため。 
4. この合計がまだ入力されていない場合`S`、挿入します。 
5.すべての要素を処理した後、変換します`S`リストにまとめて降順に並べ替えて作成します`b`。 
6. 出力`b`。 

機能する理由: 最後から反復することで、より高いインデックスの要素が最初に考慮され、要素の要素が最大化されます。`a_i + i`合計。 セットに挿入すると重複が回避されます。 降順に並べ替えると、最大の合計が最初に表示され、辞書編集上最大の配列が生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        seen = set()
        result = []
        # process from end to start
        for i in reversed(range(n)):
            val = a[i] + i + 1
            if val not in seen:
                seen.add(val)
                result.append(val)
        # output in decreasing order
        print(*sorted(result, reverse=True))

if __name__ == "__main__":
    solve()
```このコードは、まずテスト ケースの数を読み取り、次に各配列を処理します。 使用する`reversed(range(n))`端から合計を正しく計算します。 の`seen`set は重複挿入を防止します。これは非常に重要です。 最後にソートを行うことで、辞書編集的な性質が保証されます。
