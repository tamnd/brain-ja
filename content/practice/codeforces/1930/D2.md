 ## 問題の理解

 あらゆるバイナリパターンに対して$p$と定義します。$f(p)$最小数として`1`別のバイナリ文字列内の s$q$のすべての位置が同じ長さになるように、$p$ある間隔を調べることでその値を「正当化」できます。$q$その立場を含む。 

仕事は計算することではない$f$単一パターンの場合。 バイナリ文字列が与えられます$s$, そして合計しなければなりません$f$のすべての部分文字列にわたって$s$。 

すべてのテスト ケースの合計の長さは最大でも$10^6$。 がある$O(n^2)$したがって、部分文字列を個別に評価するアプローチは直ちに不可能になります。 平$O(n \sqrt n)$この規模では不快だろう。 目標は、テスト ケースごとの線形時間です。 

問題の微妙な部分は、何を理解するかということです$f(p)$really means. モードを伴う定義は複雑に見えますが、単純化すると直線上の被覆問題になります。 

Consider the pattern`111`。 

単純に読むと、3 つ必要になる可能性があります。`1`にいる$q$。 実際、1 つは`1`十分です。 真ん中に置きます:`010`。 パターンのすべての位置はそこから 1 つの距離以内にあります`1`、それで十分です`1`位置を含むある間隔のモード。 

ここで考えてみましょう`1011`。 

1つ`1`連続する位置は最大 3 つまでカバーできるため、左端と右端のグループの両方を 1 つの配置でカバーすることはできません。 正しい値は$2$。 

よくある間違いは、パターンに含まれる位置が次のとおりであると考えることです。`0`対称的な制約を課します。 そうではありません。 削減後は、以下を含むポジションのみが表示されます。`1`案件。 

## アプローチ

 ブルートフォースアプローチは、すべての部分文字列を列挙し、計算することです。$f$定義から抽出し、その結果を答えに追加します。 

なんとなく計算したとしても$f$1 つの部分文字列の線形時間では、$O(n^2)$部分文字列。 と$n=10^6$、これはまったく不可能です。 

重要な観察は、モード条件が非常に単純な結果をもたらすということです。 

ポジションを取る$i$どこ$p_i=1$。 あ`1`間隔に少なくとも同じ数が含まれる場合のバイナリ間隔のモードです。`1`として`0`s. シングル`1`すでにこれを満たしています。 また、1 を含む長さ 2 の区間`1`そして1つ`0`モードとして両方の値があります。 

その結果、求められるポジションは、`1`がある場合にのみ満たされます。`1`で$q$それから最大でも 1 つの距離にあります。 シングル`1`で$q$は、パターンの 3 つの位置 (それ自体の位置とその 2 つの隣接位置) を正確にカバーします。 これにより、問題はすべてカバーされるようになります。`1`パターンの位置を長さ 3 の間隔で指定します。 

それで$f(p)$は正確に必要なセンターの最小数です。`1`の位置$p$どこかの中心部から少し離れたところにあります。 

回線では、最適な貪欲戦略が標準です。 一番左のカバーを外した状態で取ります`1`、中央をできるだけ右に配置すると、3 つの位置がカバーされます。 

残りの課題は、すべての部分文字列を列挙せずにこの量を合計することです。 

貪欲なカバーの構造により、DP は非常にコンパクトになります。

 ## アルゴリズムのチュートリアル

 しましょう$$dp[i] = \sum_{l=0}^{i} f(s[l\dots i]).$$言い換えると、$dp[i]$位置で終わるすべての部分文字列の合計寄与度です。$i$。 

### 1. 事件を処理する$s[i]=0$末尾の追加`0`カバレッジが必要な新しいポジションは作成されません。 

スタートごとに$l$、$$f(s[l\dots i]) = f(s[l\dots i-1]).$$したがって、$$dp[i] = dp[i-1].$$### 2. 事件を処理する$s[i]=1$任意の部分文字列を取得します$s[l\dots i]$。 

その右端に必要な位置は、$i$。 最適なカバーは、その位置をカバーするために 1 つの中心を使用する必要があります。 

貪欲な配置でポジションをカバー$i-2,i-1,i$。 この中心を配置した後、その右側にあるものはすべて$i-3$すでに扱われています。 

したがって$$f(s[l\dots i]) = 1 + f(s[l\dots i-3]).$$もし$i-3<l$、第 2 項はゼロです。 

### 3. すべての開始位置の合計

 あります$i+1$可能なスタート。 

で終わる各部分文字列$i$余分に貢献する$1$新しく設置されたセンターから。 

それは用語を与えます$$i+1.$$残りの部分は正確に貢献します$$dp[i-3].$$したがって$$dp[i] = (i+1)+dp[i-3]$$いつ$s[i]=1$。 

### 4. 答えを蓄積する

 最終的な答えは、$$\sum_i dp[i].$$### なぜ効果があるのか

 不変条件は、すべての中心がその周囲の 3 つの位置を正確にカバーすることです。 When the rightmost character of a substring is`1`、右端のカバーされていないブロック用に 1 つのセンターを予約する必要があります。 Greedy は常に、左側の可能な最大範囲をカバーするようにその中心を配置します。 長さ 3 のカバーされたサフィックスを削除した後、残りの問題は、より短い部分文字列に関する元の問題と同じになります。 

これにより、単なる近似ではなく、正確な分解が作成されます。 すべての最適なカバーは、短縮された部分文字列の 1 つの最適なカバーと 1 つの新しい中心に対応し、その逆も同様です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    s = input().strip()

    dp = [0] * n

    if s[0] == '1':
        dp[0] = 1

    ans = dp[0]

    for i in range(1, n):
        if s[i] == '0':
            dp[i] = dp[i - 1]
        else:
            dp[i] = i + 1
            if i >= 3:
                dp[i] += dp[i - 3]

        ans += dp[i]

    print(ans)
```配列`dp`の合計を格納します$f$固定位置で終わるすべての部分文字列にわたって。 

現在のキャラクターが`0`、ここで終わるすべての部分文字列は、1 つ前の位置で終わる対応する部分文字列とまったく同じ値を持つため、単純にコピーします。`dp[i-1]`。 

現在のキャラクターが`1`、ここで終わるすべての部分文字列には、追加のカバー センターが 1 つ必要です。 これらの新しいセンターの合計貢献度は、`i + 1`、可能な開始位置ごとに 1 つ。 明らかにされた残りの部分は、まさに次で終わる部分文字列のコレクションです。`i - 3`, そこで追加します`dp[i - 3]`。 

すべての値は 64 ビット整数に快適に収まります。 考えられる最大の答えは、$O(n^2)$、これは Python の整数の範囲内に十分収まります。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    data = io.StringIO(inp)

    t = int(data.readline())
    out = []

    for _ in range(t):
        n = int(data.readline())
        s = data.readline().strip()

        dp = [0] * n

        if s[0] == '1':
            dp[0] = 1

        ans = dp[0]

        for i in range(1, n):
            if s[i] == '0':
                dp[i] = dp[i - 1]
            else:
                dp[i] = i + 1
                if i >= 3:
                    dp[i] += dp[i - 3]
            ans += dp[i]

        out.append(str(ans))

    return "\n".join(out)

```すべての部分文字列にはゼロのみが含まれます。 繰り返しにより、前の値が繰り返しコピーされます。$$dp=[0,0,0,0].$$答えは残っている`0`。
