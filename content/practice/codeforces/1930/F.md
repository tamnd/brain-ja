 ## 解決策
 ## 問題の理解

 配列を段階的に構築します。 挿入するたびに計算する必要があります$$f(a)=\max_x \left(\max_i(a_i\mid x)-\min_i(a_i\mid x)\right).$$各ステップで挿入される値は前の回答によって暗号化されるため、クエリはオンラインで処理する必要があります。 

最初のタスクは、実際にどの量が最大化されているかを理解することです。 

2 つの要素を修正する$u$そして$v$。 最大化したい$$(u\mid x)-(v\mid x).$$単一ビットを独立して考慮します。 

両方の場合$u$そして$v$同じビットを持っていても、そのビットは違いには何の影響も与えません。 

もし$u$もっている$1$そして$v$もっている$0$、私たちは保管します$x$は少し等しい$0$、そのビット値の寄与を与えます。 

もし$u$もっている$0$そして$v$もっている$1$、設定しました$x$は少し等しい$1$、双方を平等にし、何も貢献しません。 

したがって、各ビットの最適な寄与は、正確に、$u$そして欠席$v$。 したがって、$$\max_x \bigl((u\mid x)-(v\mid x)\bigr)=u\ \&\ \sim v.$$最良の順序のペアを取ると、$$f(a)=\max_{u,v\in a}(u\ \&\ \sim v).$$これは、公式ソリューションの議論で使用される重要な削減です。 

この制約により、ペアごとのアプローチは即座に除外されます。 到達できるクエリの数$10^6$, それでさえ$O(q\sqrt q)$絶望的だ。 すべてのマスク空間サイズの合計は次のように制限されます。$2^{22}$これは、挿入された値のペアではなくマスクに作業を費やすソリューションを強く示唆しています。 

配列に値が 1 つだけ含まれている場合、微妙なエッジ ケースが発生します。 プラスの差を生み出すペアはありません。$$u\ \&\ \sim u = 0,$$したがって、答えは次のようになります$0$。 

もう 1 つの簡単な間違いは、補数を無限ビットの補数として扱うことです。 マスク宇宙内のビットのみが重要です。 マスクスペースがある場合$k$ビット、の補数$v$は$$((1<<k)-1)\oplus v.$$Python の raw を使用する`~v`負の数が生成され、ロジックが壊れてしまいます。 

## アプローチ

 強引な解釈は簡単です。 挿入するたびに、順序付けられたすべてのペアを検査します$(u,v)$現在存在し、計算する$$u\ \&\ \sim v.$$これらの値の最大値が答えになります。 

上記の削減により、これは正しいですが、その後$q$必要な挿入$O(q^2)$ペアチェック。 と$q=10^6$、操作数はまったく実行不可能です。 

重要な観察は、$$u\ \&\ \sim v$$同時に次のサブセットであるマスクとして見ることができます。$u$と有界補数のサブセット$v$。 

させて$$c(v)=((1<<k)-1)\oplus v.$$それからマスク$m$のすべてのビットを含む挿入値が存在する場合、答えに貢献します。$m$、挿入された補数マスクが存在します。$c(v)$のすべてのビットも含まれています$m$。 

2 つの家族を定義します。 

最初のファミリーには、挿入されたすべての値が含まれます。 

2 番目のファミリーにはすべての補数が含まれます$c(v)$。 

マスク用$m$、 させて`A[m] = true`挿入された値が次のスーパーセットである場合$m$。`B[m] = true`挿入された補数マスクが次のスーパーセットである場合$m$。 

それから$$m$$両方のフラグが true の場合に達成可能です。 

答えは、2 つのフラグが true である最大のマスクです。 

ここで、問題は動的サブセットのアクティブ化になります。 

値が$v$のすべてのサブセットが挿入されます$v$家族間で有効となる$A$。 

いつ$c(v)$のすべてのサブセットが挿入されます$c(v)$家族間で有効となる$B$。 

マスクは、テスト ケース全体で各ファミリで 1 回だけアクティブにできます。 つまり、サブセット ラティスを遅延してトラバースすることができ、すでにアクティブ化されたマスクに再度アクセスする必要はありません。 

これにより、テスト ケース全体がマスク上のグラフ走査に変換されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(q^2)$|$O(q)$| 遅すぎる |
 | 最適 |$O(n \log n + q)$|$O(n)$| 承認済み |

 ここ$n=2^k$、およびすべての合計$n$入力を超えるのは最大でも$2^{22}$。 

## アルゴリズムのチュートリアル

 1. しましょう$k$をマスク空間のビット数とし、`FULL = n - 1`。 
2. 2 つのブール配列を維持します。`seenA[m]`マスクという意味です`m`価値側によってすでにアクティブ化されています。`seenB[m]`マスクという意味です`m`はすでに補完側によってアクティブ化されています。 
3. 現在の答えを維持する`ans`。 
4. 値を挿入するには`v`、のすべてのサブセットに対して DFS を実行します。`v`。 
5. マスクをするたびに`m`家族で初めて到達しました`A`、 マーク`seenA[m] = True`。 
6. もし`seenB[m]`それはすでに真実です、それでは`m`両方のファミリーから達成できるため、更新してください`ans = max(ans, m)`。 
7. マスクから`m`、1 つの設定ビットを削除して得られるすべてのマスクに対して DFS を続行します。 
8. 有界補数を挿入します。`cv = FULL ^ v`家族に`B`同じ DFS ロジックを使用します。 
9. 両方のアクティベーションが完了したら、現在の回答を出力します。 

### なぜ効果があるのか

 マスクは家族のもの`A`まさに、それが挿入された値のサブセットである場合です。 DFS アクティベーションは、そのようなすべてのサブセットを正確にマークします。 

同様に、マスクは家族のものです`B`まさに、それが挿入された値の有界補数のサブセットである場合です。 

マスクは、両方のファミリーに含まれている場合、目的に貢献します。 マスクが両方のファミリーでアクティブになった瞬間、それはある順序ペアに対応します。$(u,v)$と$$m \subseteq u,\qquad m \subseteq c(v).$$同様に、$$m \subseteq (u\ \&\ \sim v).$$そのような最大のマスクはまさに$$\max(u\ \&\ \sim v),$$等しい$f(a)$。 したがって、維持された最大値が常に正しい答えになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n, q = map(int, input().split())
        e = list(map(int, input().split()))

        full = n - 1

        seen_a = bytearray(n)
        seen_b = bytearray(n)

        ans = 0
        last = 0

        def activate(start, seen_self, seen_other):
            nonlocal ans

            stack = [start]

            while stack:
                m = stack.pop()

                if seen_self[m]:
                    continue

                seen_self[m] = 1

                if seen_other[m]:
                    if m > ans:
                        ans = m

                x = m
                while x:
                    bit = x & -x
                    stack.append(m ^ bit)
                    x ^= bit

        cur_answers = []

        for enc in e:
            v = (enc + last) % n

            activate(v, seen_a, seen_b)
            activate(full ^ v, seen_b, seen_a)

            last = ans
            cur_answers.append(str(ans))

        out.append(" ".join(cur_answers))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```基本的な考え方は、各マスクは各家族で最大 1 回だけ有効化されるということです。 DFS は既にアクティブ化されたマスクを決して探索しないため、総作業量は挿入数ではなくマスク ラティスのサイズに比例します。 

補数は次のように計算する必要があります。`full ^ v`、 ない`~v`。 マスクユニバース内のビットのみが関連します。 

サブセット トラバーサルでは、一度に 1 つのセット ビットを削除する標準的な手法が使用されます。 サブセット ラティス内のすべてのエッジは、そのソース マスクが初めてアクティブ化されたときにのみトラバースされます。

 ## 特殊なケース

 値が 1 つだけ挿入されたテスト ケースを考えてみましょう。```
n = 8
queries = [5]
```唯一注文されたペアは$(5,5)$。$$5 \& \sim 5 = 0.$$DFS は両側のサブセットをアクティブ化しますが、両方のファミリーに存在する最大のマスクは依然として$0$。 アルゴリズムの出力`0`。 

次に、同じ値が繰り返されることを考えます。```
n = 8
queries = [3,3,3]
```注文されたすべてのペアが満たされます$$3 \& \sim 3 = 0.$$最初の挿入により、次のすべてのサブセットがアクティブ化されます。`3`そしてその補完物。 その後の挿入では、すでにアクティブ化されたマスクが再利用され、ほとんど何も実行されません。 答えは残る`0`。 

最後に、極端なペアを考えてみましょう。```
n = 8
queries = [0,7]
```ペア$(7,0)$収量$$7 \& \sim 0 = 7.$$いつ`7`挿入され、マスク`7`バリューファミリーでアクティブになります。 挿入後すでに補体ファミリーから到達可能になっていたため`0`、答えはすぐに更新されます`7`、これは可能な最大マスクです。
