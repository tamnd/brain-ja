 ## 解決策
 ## 問題の理解

 バスの各列にはちょうど 2 つの座席があります。 私たちにはいくつかの家族がいます、そして家族`i`含まれています`a_i`人々。 

人は 2 つの状況のいずれかで幸せになります。 彼らは同じ家族の隣に座るか、他の席が空いていて一人で列を占めます。 

私たちはすべての人をバスに乗せて、幸せな人々の総数を最大化する必要があります。 

制約は非常に小さいです。 各家族の人数は最大でも 10 人です。`n`は最大 100、テスト ケースは最大 1000 です。 たとえ`O(n)`または`O(n log n)`解決策は十分すぎるほどです。 課題はパフォーマンスではなく、正しいカウント引数を見つけることです。 

よくある間違いは、座席の配置を明確に構築することに重点を置くことです。 答えは、いくつかのカウントから直接計算できます。 

インプットを考慮する```
1
2 2
3 1
```サイズ 3 の家族は、同じ家族のペア 1 名と残りの 1 名を寄付します。 ペアを一緒に座らせて、残りの 2 人は 1 列を共有する必要があります。 正解は 3 ではなく 2 です。奇数で残った人をすべて幸福とみなす貪欲な戦略は過大評価です。 

もう一つの厄介なケースは、```
1
4 5
1 1 1 1
```家族ペアはまったくありません。 4人5列なのでお一人様でも座れます。 答えは 4 です。同じファミリーのペアのみをカウントするアプローチでは、誤って 0 が返されます。 

3 番目のエッジケースは、```
1
2 3
3 3
```各家族は 1 ペアと残り 1 人を寄付します。 2 つの幸せなペアが得られ、すぐに 4 人の幸せな人が得られます。 残りの 2 人は残りの列を共有する必要があるため、どちらも幸せではありません。 答えは 4 です。空き列があるからといって、残った人々が自動的に満足するわけではありません。 

## アプローチ

 強引なソリューションでは、座席配置を列挙し、最終的に何人の人が満足したかを評価しようとします。 列数が少ない場合でも、割り当て可能な座席の数は爆発的に増加します。 人々は家族構成によって区別され、列はさまざまな方法で配置されるため、これはすぐに実行不可能になります。 

重要な観察は、幸福は 2 つの行パターンのみから得られるということです。 

最初のパターンは、同じファミリーの 2 つのメンバーを含む行です。 このような行は 2 人の幸せな人々を作成し、1 つの行を完全に使用します。 2 人の家族が一緒に座っている方が、別々に座るよりも常に良いため、可能な限り同じ家族のペアを使用する必要があります。 

ある程度のサイズの家族向け`a_i`、形成できます`a_i // 2`そんなペアたち。 すべての家族を合計すると、```
pairs = Σ(a_i // 2)
```各ペアはちょうど 2 人の幸せな人々に貢献します。 

これらすべてのペアを配置した後、どのファミリーにも最大で 1 つのペアになっていないメンバーが残ります。 させて```
odd = Σ(a_i % 2)
```残りの人数になります。 

未使用の行数は```
free_rows = r - pairs
```各ファミリーのペアが 1 つの完全な行を占有するためです。 

次に、残った人々だけに焦点を当てます。 残った人が一人で列を作れば、彼らは幸せです。 残された2人が同じ列を共有した場合、彼らは異なる家族の出身であるため、どちらも幸せではありません。 

最初に、残った人を 1 人ずつ空き列に配置し、`free_rows`幸せな人々。 空いている列よりも多くの残りがあった場合、余分に残った人はすべて、それらの幸せなシングルトンの隣に座らなければなりません。 それが起こると、それまで幸せだったシングルトンは幸せを失います。 人が増えるごとに、残り物の幸せ数がちょうど 1 つ減ります。 

これは、最終的なカウント式に直接つながります。

 ## アルゴリズムのチュートリアル

 1. コンピューティング`pairs = Σ(a_i // 2)`。 

このようなペアはすべて、一緒に列を占めることができ、2 人の幸せな関係をもたらします。 
2. 答えを次から始めます`ans = 2 * pairs`。 

これらの幸せな人々は保証されています。 
3. コンピューティング`odd = Σ(a_i % 2)`。 

これらは、考えられるすべての同族ペアが形成された後に残された人々です。 
4. コンピューティング`free_rows = r - pairs`。 

以来`Σ a_i ≤ 2r`、私たちはいつも持っています`pairs ≤ r`。 
5. もし`odd ≤ free_rows`、残った人は一人で座ることができます。 

追加`odd`答えに。 
6. それ以外の場合は、空いている各列に残った人を 1 人配置します。 

これにより、`free_rows`最初は幸せな人たち。 

がある`odd - free_rows`余分な人がまだ座っていません。 彼らはそれぞれ、シングルトンの1人の隣に座らなければならず、以前は幸せだった1人を破壊します。 

幸せな残り物の数は```
free_rows - (odd - free_rows)
= 2 * free_rows - odd
```その値を答えに追加します。 

### なぜ効果があるのか

 2 人が含まれるすべての幸せな列には、同じ家族のメンバーが含まれている必要があります。 可能な家族のペアを異なる行に分割しても幸福度は決して増加しません。最良の代替策は、最大でもそのうちの 1 つをシングルトンとして幸福にすることだからです。 したがって、利用可能なすべてのファミリー ペアを使用することが常に最適です。 

すべてのペアが使用された後、残りの各家族は最大でも 1 人を貢献します。 追加の同族ペアを作成することはできません。 このような人々が幸せになる唯一の方法は、一人で座ることです。 各空き行は最大 1 つのハッピー シングルトンをサポートできます。 2 番目に残った人がそのような列に挿入されるたびに、ちょうど 1 人の幸せな人が失われます。 上記の式はその影響を正確に計算しており、アルゴリズムの最適性を証明しています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, r = map(int, input().split())
    a = list(map(int, input().split()))

    pairs = sum(x // 2 for x in a)
    odd = sum(x % 2 for x in a)

    ans = 2 * pairs
    free_rows = r - pairs

    if odd <= free_rows:
        ans += odd
    else:
        ans += 2 * free_rows - odd

    print(ans)
```最初のループでは、形成できる同族ペアの数をカウントします。 そのような各ペアは、すぐに 2 人の幸せな人々に貢献します。 

2 番目のカウントは、ペアになっていない人が何人残っているかを追跡します。 幸福がまだ決まっていないのはこの人たちだけです。`free_rows`ファミリ ペアがまだ占有していない行の数です。 最後のブランチは、考えられる 2 つの状況を処理します。 残った人全員が独自の行を取得するか、利用可能な行よりも多くの残りがあり、いくつかのシングルトンをペアにする必要があります。 

すべての数値は小さいため、大きな値に対して特別な処理は必要ありません。 表現`2 * free_rows - odd`バスに乗車できる人数の合計が有効な状態では負になることはありません。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline
    t = int(input())
    out = []

    for _ in range(t):
        n, r = map(int, input().split())
        a = list(map(int, input().split()))

        pairs = sum(x // 2 for x in a)
        odd = sum(x % 2 for x in a)

        ans = 2 * pairs
        free_rows = r - pairs

        if odd <= free_rows:
            ans += odd
        else:
            ans += 2 * free_rows - odd

        out.append(str(ans))

    return "\n".join(out)

# provided samples
assert run(
"""4
3 3
2 3 1
3 3
2 2 2
4 5
1 1 2 2
4 5
3 1 1 3
"""
) == "4\n6\n6\n6", "samples"

# minimum size
assert run(
"""1
1 1
1
"""
) == "1", "single person sits alone"

# all equal values
assert run(
"""1
4 4
2 2 2 2
"""
) == "8", "everyone paired with family"

# leftover people exceed free rows
assert run(
"""1
2 3
3 3
"""
) == "4", "two leftovers must share a row"

# boundary case, bus exactly full
assert run(
"""1
2 2
1 3
"""
) == "2", "only one family pair contributes happiness"
