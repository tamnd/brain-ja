 ## 解決策
 ## 問題の理解

 グリッドが「美しく」なるように、あらかじめ割り当てられた特定のセルで整数グリッドを埋める方法の数を数えるように求められます。 4 つの角で定義される四角形の角の値の XOR が 0 に等しい場合、グリッドは美しいと言えます。 この条件は、行と列に沿った XOR パターンが線形制約を満たす必要があると言うのと同じです。各セルは、定数までの行ラベルと列ラベルの XOR によって決定されます。 

入力により複数のテスト ケースが提供されます。 各テスト ケースでは、部分的に満たされた次のサイズのグリッドから開始します。$n \times m$と$k$事前に割り当てられた値。 その後、パフォーマンスを行います$q$更新では、それぞれが以前に入力されていないセルに値を割り当てます。 各割り当ての後、グリッドモジュロの有効な完了数を報告する必要があります。$10^9 + 7$。 更新は累積的です。 

制約は高いです:$n$そして$m$まで可能です$10^5$それぞれ、最大で$10^5$セルを埋めて更新します。 未入力のセルの数が簡単に超えてしまう可能性があるため、考えられるすべての補完を反復しようとする単純なアプローチは不可能です。$10^5$、各セルの検索スペースは最大です。$2^{30}$。 したがって、塗りつぶされたセルまたは更新されたセルの数に対してほぼ直線的な時間で動作するアプローチが必要です。 

微妙な点は、XOR 条件自体です。 小さなグリッドの場合、総当たりで検証するのは簡単です。 たとえば、$2 \times 2$3 つの角が次のように塗りつぶされたグリッド`0, 1, 1`、最後のセルは強制的に`0`XOR ルールを満たすため。 これを無視するアルゴリズムでは、完了数が過剰にカウントされます。 指定された値が矛盾する場合、別の特殊なケースが発生します。 たとえば、左上のセルが`0`、右上は`1`、左下は`1`、右下は`1`、有効な補完がないため、正しいカウントは 0 です。 アルゴリズムは不一致を効率的に検出する必要があります。 

## アプローチ

 ブルートフォース手法では、すべての未入力セルを反復処理し、0 から 0 までのすべての値を試します。$2^{30}-1$すべての長方形の制約をチェックしながら。 これは正しいですが、まったく実行不可能です。 まで$10^5$満たされていないセル、これには次のことが含まれます。$2^{30 \times 10^5}$可能性はありますが、明らかに不可能です。 四角形を列挙することで XOR 制約を素朴に解決しようとしても、$O(n^2 m^2)$制限時間を超えた操作。 

重要な観察は、XOR 条件が次の範囲にわたって線形システムを誘導するということです。$\text{GF}(2)$各ビットを独立して実行します。 各セルの値を行変数と列変数の合計としてモデル化できます。$A_{i,j} = R_i \oplus C_j$、 どこ$R_i$そして$C_j$行からの XOR 寄与を表す未知の値です$i$そしてコラム$j$。 塗りつぶされた各セルは次の線形方程式を与えます。$R_i$そして$C_j$。 これにより、問題は、新しい方程式の挿入下で線形 XOR 方程式のシステムを維持することになります。 

各ビットは独立しているため、ビットごとに 1 回ずつ、システムを 30 回解きます。 各システムは疎であり、各方程式にはちょうど 2 つの変数が含まれます。 この構造により、問題を一方の側に行、もう一方の側に列をもつ二部グラフとして表現することができ、方程式がある場合はエッジを接続します。$R_i \oplus C_j = value$。 連結成分あたりの自由変数の数は、矛盾が検出されたかどうかに応じて 0 または 1 になります。 解の総数は$2^{\text{number of free variables}}$。

 ## アルゴリズムのチュートリアル

 1. グリッドを行ノードを含む 2 部グラフとして表現します。$R_i$と列ノード$C_j$。 塗りつぶされた各セル$(i,j)$方程式を定義します$R_i \oplus C_j = value$整数値の各ビットに対して。 各ビットを個別に扱います。 
2. 各接続コンポーネントのパリティを備えた Disjoint Set Union (DSU) を維持します。 各ノード (行または列) はコンポーネントに属し、パリティはノードからコンポーネント ルートまでのパスの XOR を追跡します。 
3. 埋められたセルまたは更新ごとに、0 ～ 29 の各ビットについて、指定されたパリティを使用してエッジを DSU に追加します。 2 つのノードがすでに接続されている場合は、パリティが一貫していることを確認してください。 そうでない場合は、システムを解決不可能としてマークします。 
4. 状態のすべてのエッジを挿入した後、少なくとも 1 つの未割り当て変数を持つ連結成分の数を数えます。 このような各コンポーネントは 1 つの自由変数に寄与します。 解の総数は$2^{\text{number of free variables}}$モジュロ$10^9 + 7$。 
5. 初期状態と各更新後の結果を出力します。 

機能する理由: パリティを備えた DSU は、接続された各コンポーネント内で XOR 制約を維持します。 矛盾が生じた場合、代入はできません。 各コンポーネントは独立して 1 つの変数を自由に選択でき、他のすべての変数はパス パリティによって決定されます。 各更新を段階的に処理することで、現在のソリューションの数を常に把握できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 10**9 + 7

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.rank = [0]*n
        self.xor = [0]*n
        self.size = [1]*n
        self.bad = [False]*n
    
    def find(self, x):
        if self.p[x] != x:
            orig = self.p[x]
            self.p[x] = self.find(self.p[x])
            self.xor[x] ^= self.xor[orig]
        return self.p[x]
    
    def union(self, x, y, val):
        xr, yr = self.find(x), self.find(y)
        px = self.xor[x]
        py = self.xor[y]
        if xr == yr:
            if (px ^ py) != val:
                self.bad[xr] = True
            return
        if self.rank[xr] < self.rank[yr]:
            xr, yr = yr, xr
        self.p[yr] = xr
        self.xor[yr] = px ^ py ^ val
        self.bad[xr] |= self.bad[yr]
        if self.rank[xr] == self.rank[yr]:
            self.rank[xr] += 1

def solve_case(n, m, k, q, cells, updates):
    total = n + m
    dsu_bits = [DSU(total) for _ in range(30)]
    answers = []

    def add_cell(r, c, val):
        for b in range(30):
            bit = (val >> b) & 1
            dsu_bits[b].union(r, n + c, bit)

    for r, c, v in cells:
        add_cell(r-1, c-1, v)

    def count_solutions():
        res = 1
        for dsu in dsu_bits:
            free = 0
            seen = set()
            valid = True
            for i in range(total):
                root = dsu.find(i)
                if dsu.bad[root]:
                    valid = False
                    break
                if root not in seen:
                    seen.add(root)
                    free += 1
            if not valid:
                return 0
            res = res * pow(2, free - len(seen), MOD) % MOD
        return res

    answers.append(count_solutions())

    for r, c, v in updates:
        add_cell(r-1, c-1, v)
        answers.append(count_solutions())
    return answers

def main():
    t = int(input())
    for _ in range(t):
        n, m, k, q = map(int, input().split())
        cells = [tuple(map(int, input().split())) for _ in range(k)]
        updates = [tuple(map(int, input().split())) for _ in range(q)]
        ans = solve_case(n, m, k, q, cells, updates)
        for a in ans:
            print(a)

if __name__ == "__main__":
    main()
```このソリューションは、パリティを備えた DSU を実装して、XOR 制約を効率的に処理します。 30 ビット整数の各ビットは個別に処理されます。 各連結成分は、制約のある変数のセットを表します。 結合操作によりパリティが更新され、矛盾にフラグが立てられます。 解を数えるには、各コンポーネントの自由変数の数を計算することが含まれます。 ルートパリティを慎重に扱うことで、正確性が保証されます。
