 ## 解決策
 ## 問題の理解

 長さの文字列を構築しようとしています$k$これは、長方形のグリッドに再配置できます。$n$行と$m$すべての行とすべての列に、a、e、i、o、u の 5 つの母音すべてが少なくとも 1 回含まれるように列を作成します。 

構築ルールは、文字列がグリッドにマッピングされる方法を修正します。左から右に行ごとに埋めていきます。 それで最初の$m$行 1 の文字、次の行$m$行 2 などを形成します。 このグリッドに配置されると、文字を再配置することはできないため、最終的なグリッド構造は文字列によって完全に決定されます。 

キーの要件は非常に強力です。すべての行に 5 つの母音すべてが含まれている必要があり、すべての列にも 5 つの母音がすべて含まれている必要があります。 これにより、両方の次元が即座に強制されます$n$そして$m$少なくとも 5 でなければなりません。そうでない場合、行または列にすべての母音を含めることはできません。 

入力は整数のみです$k$そして、因数分解に対してそのようなグリッドが存在するかどうかを判断する必要があります。$k = n \cdot m$存在する場合は、機能する有効な文字列を出力します。 それ以外の場合は、-1 を出力します。 

制約$k \le 10^4$のすべての約数を安全に試せることを意味します$k$で$O(\sqrt{k})$, 候補者は最大でも 100 人程度存在するためです。 二次関数の何か$k$不要ではありますが、それでも許容範囲内です。 指数関数的なものは関係ありません。 

主な微妙な点は、条件が行または列に独立してローカルではないことです。 単純な試みでは、行にすべての母音が含まれることは保証されますが、慎重に周期的に構築しない限り、列は失敗します。 

いくつかの特殊なケースでその構造が強調されます。 

いつ$k = 7$、因数分解は両方を生成しません$n \ge 5$そして$m \ge 5$なので、答えは不可能ですが、$k$小さくありません。 

いつ$k = 25$、私たちは取ることができます$n = 5, m = 5$、有効なグリッドを構築します。 

中心的な課題は、行方向と列方向の両方の完全性を同時に保証する構造を理解することです。 

## アプローチ

 強引なアイデアは、すべての因数分解を試すことです$k = n \cdot m$、各ペアに対してグリッドの構築を試みます。 各候補グリッドについて、ランダムに埋めることも、すべての行と列に 5 つの母音がすべて含まれるようにバックトラッキングを介して埋めることもできます。 ただし、単一の固定ペアの場合でも、検索空間は膨大です。各セルには 5 つの選択肢があるため、グリッドの数は$5^{nm}$、これは中程度のサイズであっても完全に実行不可能です。 

重要な観察点は、「すべての行にすべての母音が含まれる」という要件によってすでに強力な構造が強制されているということです。つまり、各行には少なくとも 5 つの異なる文字が含まれている必要があります。$m \ge 5$。 同様に、各列の高さは少なくとも 5 でなければなりません。$n \ge 5$。 これにより、問題は因数分解を見つけることになります。$k = n \cdot m$両方とも$n \ge 5$そして$m \ge 5$。 

このような因数分解が存在すると、母音の周期的な 5 行 5 列のパターンを構築し、それをグリッド上にタイル状に並べることができます。 5x5 のラテン スタイルの循環構造により、各行と列にすべての母音が 1 回だけ含まれることが保証され、5 の倍数にわたって繰り返すことでプロパティが保持されます。 グリッドの残りの部分は、この基本構造の繰り返しです。 

したがって、問題は完全に数論に帰着します。$k$約数がある$m$両方とも$m \ge 5$そして$k/m \ge 5$?

 「はい」の場合、グリッドを構築します。 それ以外の場合は、-1 を出力します。

 ## アルゴリズムのチュートリアル

 有効な長方形のサイズを見つけて、構造化された方法でそれを塗りつぶしたいと考えています。 

1. すべての約数を反復処理します。$m$の$k$。 各約数について計算します$n = k / m$。 両方が一致するペアのみを考慮します。$n \ge 5$そして$m \ge 5$というのは、寸法が小さくなると、行または列に 5 つの母音すべてを収めることができなくなるからです。 
2. そのようなペアが見つかったら、それをグリッドの寸法として固定します。 有効な解はいずれも次の因数分解に対応する必要があるため、このステップは正当化されます。$k$。 
3. 母音の循環シフトを使用して 5x5 の基本パターンを構築します。 このアイデアは、各行が「aeiou」の回転になるように母音を配置し、各列もすべての母音を循環するようにすることです。 
4. この 5x5 ブロックを次のように拡張します。$n \times m$行と列を法 5 で繰り返すことでグリッドを作成します。具体的には、セル$(i, j)$に基づいて母音が割り当てられます$(i \bmod 5, j \bmod 5)$。 
5. グリッドを行ごとに一定の長さの文字列に平坦化します。$k$。 

有効な因数分解が見つからない場合は、-1 を返します。 

### なぜ効果があるのか

 この構造では、すべての行が長さ 5 のサイクルで 5 つの母音の順列の繰り返しで構成されることが保証されます。各行は同じ循環構造から構築されているため、すべての行にはすべての母音が少なくとも 1 回含まれます。 列パターンは巡回シフトまで同一であるため、列にも同じことが当てはまります。 周期性により、基本の 5x5 構造を拡張することで、繰り返されるブロックの数に関係なく、行方向と列方向の両方の完全性が維持されます。 

不変条件は、任意の行または列の 5 つの連続する位置ごとに母音の順列が含まれるということであり、この特性は繰り返しても保存されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    k = int(input().strip())
    
    vowels = "aeiou"
    
    # find valid factorization n x m
    n = m = -1
    for i in range(5, int(k**0.5) + 1):
        if k % i == 0:
            j = k // i
            if j >= 5:
                n, m = i, j
                break
            if i >= 5:
                n, m = j, i
    
    if n == -1:
        print(-1)
        return
    
    # build grid using cyclic pattern
    grid = []
    for i in range(n):
        row = []
        for j in range(m):
            row.append(vowels[(i + j) % 5])
        grid.append(row)
    
    # flatten
    res = []
    for i in range(n):
        res.extend(grid[i])
    
    print("".join(res))

if __name__ == "__main__":
    solve()
```コードは、有効な因数分解を選択することから始まります。$k$。 サイズが小さいと、行または列に 5 つの母音がすべて含まれなければならないという要件に直ちに違反するため、両側が少なくとも 5 であるディメンションのみを受け入れます。 

グリッドの構築では、対角循環シフトを使用します: エントリ$(i, j)$によって決定されます$(i + j) \bmod 5$。 これにより、右または下に移動すると固定順列で母音が循環し、すべての行と列が確実にカバーされるようになります。 

最後に、問題の入力とグリッドのマッピングに合わせて、グリッドが行優先の順序で平坦化されます。 

## 実用的な例

 ### 例 1: k = 7

 両辺が少なくとも 5 である 7 の因数分解はありません。ペアは (1,7) と (7,1) のみで、どちらも無効です。 

| ステップ | n | メートル | 有効？ | アクション |

 アルゴリズムは有効なグリッドを検出せず、-1 を出力します。 1 つの行または列に 5 つの母音すべてを含めることはできないため、これは要件に一致します。 

### 例 2: k = 25

 私たちは選ぶことができます$n = 5, m = 5$。 

| 私 | j | (i+j)%5 | 手紙 |
 | --- | --- | --- | --- |
 | 0 | 0 | 0 | |
 | 0 | 1 | 1 | e |
 | 0 | 2 | 2 | 私 |
 | 0 | 3 | 3 | o |
 | 0 | 4 | 4 | あなた |

 行 0 にはすでにすべての母音が含まれています。 1 行おきに、この行の巡回シフトが行われます。 

同じパターンが列にも当てはまります。$j$行間の循環シフトでもあります。 

長さ 25 の平坦化された文字列は、構造上有効です。

 ## 特殊なケース

 のために$k = 1$の場合、アルゴリズムは両辺が 5 以上である約数のペアを見つけることができないため、-1 を返します。 単一の文字では 1 行の要件さえ満たせないため、これは正しいです。 

次のような素数値の場合$k = 11$の場合、因数分解は (1,11) と (11,1) のみで、どちらも無効です。 除数スキャンはこれを明確に検出します。 

次のような複合値の場合$k = 30$、選択できます$5 \times 6$。 この構築では 5 サイクル パターンが使用され、行と列の両方の次元が 5 以上であるため完全性が維持され、両方向で完全なサイクルが可能になります。
