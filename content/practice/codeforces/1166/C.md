 ## 解決策
 ## 問題の理解

 2 つの履歴マーカーの潜在的な値を表す整数のセットが与えられます。$x$そして$y$。 個別の整数の候補ペアごとに$(x, y)$, 数直線上の 2 つの区間を計算します。 最初の間隔は Arrayland と呼ばれ、マーカー自体の絶対値によって決定されます。そのエンドポイントは次のとおりです。$|x|$そして$|y|$。 2 番目の間隔は Vectorland と呼ばれ、次の絶対値によって決定されます。$x-y$そして$x+y$。 Arrayland がエンドポイントを含めて完全に Vectorland 内にある場合、この伝説はペアに当てはまります。 

私たちのタスクは、順序付けされていないペアの数をカウントすることです$(x, y)$指定された整数のうち、この包含特性を満たすもの。 入力サイズは最大です$2 \cdot 10^5$、すべてを検査する単純な総当りソリューションは直ちに除外されます。$O(n^2)$ペア。 各整数は次のように大きくできます。$10^9$したがって、数値の範囲に合わせて拡張性が低いソリューションは避けなければなりません。 

不注意な実装でつまずく可能性のあるエッジ ケースには、絶対値によって間隔のエンドポイントが大幅に変更される可能性があるため、一方または両方の数値が負である状況が含まれます。 たとえば、ペアで$(-2, 3)$、アレイランドは$[2,3]$そしてベクターランドは$[1,5]$、封じ込めを満たします。 負の数を無視するか、または仮定する単純なチェック$x \le y$誤ったカウントが生成されます。 もう 1 つのエッジ ケースは、1 つの値がゼロの場合です。これにより、Vectorland 間隔が縮小し、封じ込めに影響を与える可能性があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。個別の整数の順序付けされていないペアをすべて生成します。$(x, y)$Arrayland が完全に Vectorland 内にあるかどうかを確認します。 これには、4 つの絶対値を計算し、各ペアの間隔を比較する必要があります。 と$n$まで$2 \cdot 10^5$、ペアの数は約$2 \cdot 10^{10}$, 制限時間内に収まる範囲をはるかに超えています。 

解決策を迅速化するための重要な洞察は、問題をソートされた検索に絞り込むことで得られます。 封じ込め条件$[\min(|x|, |y|), \max(|x|, |y|)] \subseteq [|x-y|, |x+y|]$不等式を使って書き換えることができます$\min(|x|, |y|) \ge |x-y|$そして$\max(|x|, |y|) \le |x+y|$。 絶対値の合計が大きい方の絶対値以上であるため、2 番目の不等式は常に成り立ちます。 最初の不等式は次のように単純化されます。$|x-y| \le \min(|x|, |y|)$。 

この観察により、すべての数値の絶対値をソートし、2 ポインター手法を使用して、条件を満たすペアを効率的に数えることができます。$|x-y| \le \min(|x|, |y|)$。 仕分け費用$O(n \log n)$、2 ポインタ スキャンは次のように実行できます。$O(n)$時間をかけて、制約に適合する全体的なソリューションを生成します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 並べ替え + 2 つのポインター | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む$n$そして整数の配列$a_1, \dots, a_n$。 各要素の絶対値を取得し、新しい配列に格納します`abs_a`。 これにより、負でない値を完全に操作できるようになり、間隔の比較が簡素化されます。 
2. 並べ替え`abs_a`昇順で。 並べ替えにより、最大のインデックスを効率的に見つけることができます`j`そのような`abs_a[j] - abs_a[i] <= abs_a[i]`。 
3. 2 つのポインターを初期化します。`i`各要素を反復処理します。`0`に`n-1`、ペアの一端を表し、`j`から始まります`i+1`包含条件を満たす最も遠い要素を見つけます。 
4. それぞれについて`i`、増分`j`その間`abs_a[j] - abs_a[i] <= abs_a[i]`。 条件が失敗すると、すべてのインデックスが`i+1`に`j-1`～と有効なペアを形成する`i`。 それらを次のように数えます`j - i - 1`。 
5. それぞれのすべてのカウントを合計します。`i`そして結果を印刷します。 

これが機能するのは、並べ替えによって、`abs_a[j] - abs_a[i] > abs_a[i]`、その他の要素`abs_a[k]`と`k > j`も条件違反になります。 これにより、すべてのペアを明示的にチェックすることを回避しながら、正確性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

abs_a = sorted(abs(x) for x in a)

count = 0
j = 1
for i in range(n):
    if j <= i:
        j = i + 1
    while j < n and abs_a[j] - abs_a[i] <= abs_a[i]:
        j += 1
    count += j - i - 1

print(count)
```このコードは、まずすべての数値を絶対値に変換し、並べ替えてから、2 ポインター アプローチを使用してすべての有効なペアを効率的にカウントします。 微妙なのは不変性を維持することです`j >= i+1`そして正しく計算する`j - i - 1`これにより、二重カウントや無効なペアのカウントが回避されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    abs_a = sorted(abs(x) for x in a)
    count = 0
    j = 1
    for i in range(n):
        if j <= i:
            j = i + 1
        while j < n and abs_a[j] - abs_a[i] <= abs_a[i]:
            j += 1
        count += j - i - 1
    return str(count)

# provided samples
assert run("3\n2 5 -3\n") == "2", "sample 1"
assert run("2\n3 6\n") == "1", "sample 2"

# custom cases
assert run("2\n0 1\n") == "1", "zero case"
assert run("4\n-1 1 2 3\n") == "4", "mixed negative positive"
assert run("5\n1 2 4 8 16\n") == "2", "powers of two"
assert run("2\n1000000000 -1000000000\n") == "1", "large numbers"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 2\n0 1 | 1 | ゼロの正しい処理 |
 | 4\n-1 1 2 3 | 4 | 負の数と正の数が混在している |

 ## 特殊なケース

 入力用`2\n0 1`、`abs_a = [0,1]`。`i=0`もっている`j=1->2`、カウント増分は 1、合計カウントは 1 です。`i=1`これにより、アルゴリズムが間隔にゼロを正しく含めていることが確認されます。 

入力用`4\n-1 1 2 3`、`abs_a = [1,1,2,3]`。 反復処理`i`そして更新`j`すべての有効なペアをカウントします`(1,1)`、`(1,2)`、`(1,3)`、`(2,3)`正しく。 2 ポインター不変式により、ペアを見逃したり二重にカウントしたりすることがなくなります。
