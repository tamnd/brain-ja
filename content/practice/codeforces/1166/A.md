 ## 解決策
 ## 問題の理解

 私たちは生徒の名前のリストを渡され、これらの生徒を 2 つの教室に分けることが許可されます。 すべての生徒は 2 つの部屋のうちの 1 つに行かなければならず、どちらの部屋も空になる可能性があります。 

同じ開始文字を共有し、同じ部屋に配置されると、ペアの生徒は「おしゃべり」になります。 各部屋について、その部屋内の生徒の中にそのようなペアが何組存在するかを数え、両方の部屋からの寄与を合計します。 有効なペアを形成できるのは同じ頭文字を持つ生徒だけであるため、部屋の貢献度は純粋にその部屋に含まれる同じ頭文字を持つ生徒が何人いるかによって決まります。 

タスクは、両方の部屋内の同じ初期値ペアの総数ができるだけ少なくなるように分割を選択することです。 

制約は小さく、生徒数は最大でも 100 人です。 これは、二次解法またはわずかに組み合わせた解法でも簡単に通過することをすぐに示唆していますが、問題の構造により、さらに単純な貪欲な計数アプローチが可能になります。 

単純な間違いは、頭文字のみが重要であることを認識せずに、生徒を 1 人ずつ割り当てようとすることです。 もう 1 つのよくある落とし穴は、実際には各文字が独立して最終的な答えに寄与しているにもかかわらず、部屋間で文字を混ぜると相互作用すると仮定することです。 

たとえば、すべての名前が個別の文字で始まる場合、どの分割でもペアはゼロになります。 すべての名前が同じ文字で始まる場合、唯一の決定は、そのマルチセットを 2 つの部屋間でどの程度均等に分割するかということです。 

## アプローチ

 ブルートフォース戦略では、n 人の生徒を 2 つのグループに分けて、考えられるすべての割り当てを試みます。 各生徒には 2 つの選択肢があるため、2^n 通りの分割が可能です。 分割ごとに、生徒を頭文字でグループ化し、組み合わせを合計することで、両方の部屋内のペアの数を計算します。 これは正しいですが、指数関数的に増加し、n が 100 に達すると完全に実行不可能になります。 

重要な観察は、相互作用は異なる文字間では起こらないということです。 「a」のような文字を修正し、「a」で始まる生徒の数を数えると、そのグループは他のすべての文字とは独立して貢献していることになります。 合計の答えは、各手紙からの貢献の合計です。 

したがって、問題は次のようになります。各文字について、その文字から始まる生徒が c 人いると仮定します。 それらをサイズ a と c - a の 2 つのグループに分割する必要があります。 この手紙によって提供されたおしゃべりなペアの数は C(a, 2) + C(c - a, 2) です。 この式を最小化するために を選択したいと思います。 

二項係数の構造により、これは整数に対する凸最小化問題になります。 2 つのグループが可能な限りバランスが取れている場合、合計は最小になります。 直観的には、生徒をほぼ同じ半分に分けると、内部ペアの数が減ります。これは、グループのサイズに応じてペアが二次関数的に増加するためです。 

したがって、文字ごとに単純にカウントをfloor(c/2)とceil(c/2)として分割し、ペアの寄与を計算し、すべての文字の合計を計算します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n · n) | O(n) | 遅すぎる |
 | 最適 | O(26 + n) | お(26) | 承認済み |

 ## アルゴリズムのチュートリアル

 まず、アルファベットの各文字で始まる生徒の数を数えます。 これにより、入力が最大 26 の独立した周波数値に変換されます。 

文字の頻度 c ごとに、それを 2 つの教室に分割する方法を決定します。 不均衡があると内部ペアの数が二次関数的に増加するため、最適な分割は 2 つの部分をできるだけ等しくすることです。

1. サイズ 26 の周波数配列 freq を構築します。ここで、freq[i] には、i 番目の文字で始まる名前の数が格納されます。 これにより、文字ごとに独立したサブ問題が分離されます。 
2. 各レターからの貢献を個別に蓄積するため、回答を 0 に初期化します。 
3. freq の各周波数 c について、最初の部屋に行く生徒の数を a = c // 2 として計算し、2 番目の部屋に行く生徒の数を b = c - a として計算します。 これにより、分割のバランスが可能な限り保たれます。 
4. C(a, 2) + C(b, 2) を答えに追加します。ここで、C(x, 2) = x(x - 1) // 2。これにより、その文字の各部屋内のペアがカウントされます。 
5. すべての文字を処理した後、最終的に蓄積された回答を出力します。 

### なぜ効果があるのか

 各文字は同一の項目の独立したセットを形成し、ペアは同一の文字グループ内でのみ形成されます。 文字間には相互作用がないため、合計を最小化することは、各文字の寄与を個別に最小化することと同じです。 固定カウント c の場合、関数 C(x,2) + C(c-x,2) は、二次項の対称性と凸状の成長により、x が c/2 にできるだけ近づくと最小化されます。 これにより、貪欲なバランスの取れた分割によって全体的な最適な結果が得られることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def comb2(x):
    return x * (x - 1) // 2

def solve():
    n = int(input().strip())
    freq = [0] * 26

    for _ in range(n):
        s = input().strip()
        freq[ord(s[0]) - ord('a')] += 1

    ans = 0
    for c in freq:
        a = c // 2
        b = c - a
        ans += comb2(a) + comb2(b)

    print(ans)

if __name__ == "__main__":
    solve()
```この解決策は、入力を文字の頻度に圧縮することから始まります。これがペア形成に重要な唯一の情報です。 ヘルパー関数`comb2`ループを使用せずに、グループ内の順序なしペアの数を効率的に計算します。 

分割ステップ`a = c // 2`そして`b = c - a`最適なバランスを実現します。 偏差があると、一方の側がもう一方の側を減らすよりも大きくなり、ペア数の二次関数の増加によってこれが次善であることが保証されるため、代替の分布を考慮する必要はありません。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from contextlib import redirect_stdout
    import io as sio

    out = sio.StringIO()
    with redirect_stdout(out):
        solve()
    return out.getvalue().strip()

def solve():
    n = int(input().strip())
    freq = [0] * 26
    for _ in range(n):
        s = input().strip()
        freq[ord(s[0]) - ord('a')] += 1

    ans = 0
    for c in freq:
        a = c // 2
        b = c - a
        ans += a * (a - 1) // 2 + b * (b - 1) // 2

    print(ans)

 ## 特殊なケース

 1 人の生徒の場合、頻度配列には 1 の非ゼロ エントリが 1 つあります。分割は 1 と 0 になり、C(1,2) と C(0,2) の両方がゼロになるため、出力は 0 になります。整数の除算では、順序に応じて a = 0 と b = 1、またはその逆が生成され、どちらの場合もゼロのペアが生成されるため、アルゴリズムはこれを直接処理します。 

すべての生徒が同じイニシャル、たとえば c = 100 を共有する場合、アルゴリズムは常に 50 と 50 に分割されます。計算された値は C(50,2) + C(50,2) となり、可能な最小分布に正確に一致します。 不均等な分割があると、一方の項が他方の項を減少させるよりも二次関数的に増加するため、実装されたルールの下ではバランスの取れたケースが最適のままになります。
