 ## 問題の理解

 隠れた指数変数のように動作する整数関係が与えられています。 ある程度の数は存在する$x$(必ずしも整数ではない) その値とその逆数が満たされるような値$x + \frac{1}{x} = k$、 どこ$k$は少なくとも 2 の固定整数です。この暗黙の定義から、次の式を計算するように求められます。$x^n + x^{-n}$おそらく巨大な指数のために$n$、結果のモジュロを出力します$M$。 

それでも$x$それ自体は決して明示的に知られることはなく、問題はフォームのすべての値が$x^n + x^{-n}$は整数なので、実際には次のように決定される純粋な整数シーケンスを扱っています。$k$。 タスクは、$n$このシーケンスの - 番目の項を効率的に実行します。 

制約により、意図された難易度が明確になります。 指数$n$と同じ大きさにすることができます$10^{18}$これにより、べき乗を線形に反復するメソッドは除外されます。 どのような解決策でも、通常は漸化式または行列累乗を通じて、問題を対数時間で累乗できるものに還元する必要があります。 弾性率$M$およそまでです$10^9$, しかし、必ずしも素数であるとは限らないため、乗法逆数や体の構造に依存することはできません。 

の力を直接構築する素朴なアプローチ$x$不可能だから$x$は明確には知られていない。 記号的に計算しようとしても$x^n$、まだ必要です$O(n)$掛け算。 

小さいところでは微妙なエッジケースが現れる$n$。 いつ$n = 0$、式は次のようになります$x^0 + x^0 = 2$、独立して$k$。 いつ$n = 1$、になります。$x + x^{-1} = k$、直接与えられます。 不正な反復初期化は、特に単一の開始値を仮定した場合、これらの境界ケースでは失敗します。 

## アプローチ

 ブルートフォースの観点は、未知の変数とその逆関数の反復累乗が必要であるという事実から始まります。 何らかの数値を代入することを想像すると、$x$、計算できます$x^n$そして$x^{-n}$高速累乗を個別に使用して、それらを合計します。 ただし、これには有理数または代数的数を扱う必要があり、問題設定では反転が意味を持たないため、モジュラー算術では不安定になります。 

表現の問題を無視したとしても、項ごとの直接検出力の計算にはコストがかかります。$O(\log n)$しかし、まだ再構築する必要があるため、$x$、このアプローチは計算的に明確に定義されていません。 

重要な構造的洞察は、シーケンスが$a_n = x^n + x^{-n}$実際には知ることに依存しない$x$。 拡大中$a_n$関係を使って$x + x^{-1} = k$、線形漸化式を導出できます。 

乗算する$a_{n-1}$による$x + x^{-1}$与える$$(x + x^{-1})(x^{n-1} + x^{-(n-1)}) = x^n + x^{-n} + x^{n-2} + x^{-(n-2)}.$$項を並べ替えると、次の漸化式が得られます。$$a_n = k a_{n-1} - a_{n-2}.$$これにより、問題は次の評価に変わります。$n$係数が一定の二次線形漸化式の - 番目の項。 各ステップは前の 2 つの値のみに依存するため、このようなシーケンスは行列のべき乗を使用して対数時間で計算できます。 

遷移をエンコードします。$$\begin{pmatrix}
a_n \\
a_{n-1}
\end{pmatrix}
=
\begin{pmatrix}
k & -1 \\
1 & 0
\end{pmatrix}
\begin{pmatrix}
a_{n-1} \\
a_{n-2}
\end{pmatrix}.$$この行列を次のように引き上げると、$n-1$の乗と基底ベクトルを乗算すると、結果が得られます。

 ## アルゴリズムのチュートリアル

 1. シーケンスを定義する$a_n = x^n + x^{-n}$。 直接置換から次のことがわかります。$a_0 = 2$そして$a_1 = k$。 これら 2 つの値はシーケンス全体を固定します。 
2. 再発を導き出す$a_n = k a_{n-1} - a_{n-2}$。 このステップは未知の変数を排除するため、非常に重要です。$x$完全に問題を決定論的な整数列に置き換えます。 
3. 小さな指数を直接処理します。 もし$n = 0$、2を返します。$n = 1$、 戻る$k$。 これらの場合は行列のべき乗をバイパスし、未定義の状態への誤ったアクセスを防ぎます。 
4. 遷移行列を構築する$$T =
\begin{pmatrix}
k & -1 \\
1 & 0
\end{pmatrix}.$$この行列は、状態ベクトルがどのように変化するかをエンコードします。$(a_n, a_{n-1})$一歩で進化します。 

1. コンピューティング$T^{n-1}$2進累乗を使用します。 二乗ステップごとに指数範囲が半分に減り、対数的な時間計算量が確保されます。 
2. 乗算$T^{n-1}$基底ベクトルによる$(a_1, a_0) = (k, 2)$。 結果として得られる最初のコンポーネントは次のとおりです。$a_n$、これは望ましい答えです。 

### なぜ効果があるのか

 正しさは、再帰によって順序が一意に決定されるという事実に依存します。$a_0$そして$a_1$固定されています。 遷移行列を適用するたびに関係が維持されます。$a_n = k a_{n-1} - a_{n-2}$したがって、行列のべき乗は、有効な変換の繰り返し適用をエンコードします。 行列のべき乗は近似を行わずに繰り返される反復遷移を正確にシミュレートするため、次の最終状態は次のようになります。$n-1$ステップは true と等しいことが保証されます$a_n$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    M, k, n = map(int, input().split())
    k %= M

    if n == 0:
        print(2 % M)
        return
    if n == 1:
        print(k % M)
        return

    def mul(A, B):
        return [
            [(A[0][0]*B[0][0] + A[0][1]*B[1][0]) % M,
             (A[0][0]*B[0][1] + A[0][1]*B[1][1]) % M],
            [(A[1][0]*B[0][0] + A[1][1]*B[1][0]) % M,
             (A[1][0]*B[0][1] + A[1][1]*B[1][1]) % M]
        ]

    def mpow(mat, exp):
        res = [[1, 0], [0, 1]]
        while exp:
            if exp & 1:
                res = mul(res, mat)
            mat = mul(mat, mat)
            exp >>= 1
        return res

    T = [[k, (M - 1) % M], [1, 0]]
    Tn = mpow(T, n - 1)

    a1, a0 = k, 2 % M
    ans = (Tn[0][0] * a1 + Tn[0][1] * a0) % M
    print(ans)

if __name__ == "__main__":
    solve()
```コードは最初に正規化されます$k$後続のすべての操作はモジュロで行われるため、モジュラスの下で行われます。$M$。 基本ケースを明示的に処理します$n=0$そして$n=1$行列の定式化では、連続する 2 つの項の開始ベクトルが想定されているためです。 

行列乗算関数は、法の下で直接 2x2 積を実装します。 べき乗関数はバイナリ リフティングを使用し、必要に応じて遷移行列を繰り返し 2 乗して結果に乗算します。 

微妙な実装の詳細は次のように表現されます。$-1 \bmod M$として$M-1$。 これにより、モジュラー演算内の負の値が回避され、すべての計算の一貫性が保たれます。 最終的な答えは、結果として得られる状態ベクトルの最初のコンポーネントから抽出されます。
