 ## 問題の理解

 すべての要素の積が特定の制限以下である正の整数のシーケンスを数えていますが、シーケンスに沿って単調増加条件が満たされない位置が最大 1 か所あるという意味で、シーケンスは「ほぼ増加」しています。 失敗は、次の要素が前の要素よりも厳密には大きくないことを意味するため、等しいことはすでに違反としてカウントされます。 

積の考えられる整数値ごとに、正確にその積を生成するそのようなシーケンスの数を定義し、積が指定された境界を超えない有効なシーケンスの総数を求められます。$n$。 

重要な視点は、ここまでの数字を列挙しているわけではないということです。$n$ただし、次の数までのすべての数値の構造化された因数分解を列挙します。$n$非常に特殊な形状制約を持つ順序付けられたシーケンスに変換されます。 この困難は、順序制約と乗算構造の間の相互作用に起因します。 

制約$n \le 10^8$すべてのシーケンス、または数値のすべての因数分解を個別に明示的に反復するアプローチは除外されます。 までのすべての数値の反復に依存するもの$n$そして、数値ごとに重要な作業を行うことは、慎重に次のようなものに減らす必要があります。$O(\sqrt n)$またはブロックごとの算術演算の数が少ない。 

単純な間違いは、順序制約を純粋に組み合わせとして扱い、積制約を無視すること、または逆に積制約を要素ごとに独立して扱うことです。 製品はすべての要素をグローバルに結合するため、どちらの方向でも失敗します。 

もう 1 つの微妙な特殊ケースは平等から生じます。 のようなシーケンス$(1,1,1)$たとえ通常の弱い意味で非減少であっても、すべての隣接するペアが常に違反に寄与するため、無効です。$a_i \ge a_{i+1}$、その条件には平等が含まれます。 これは、等しい値の連続が厳しく制限されており、無害なプラトーとして扱うことができないことを意味します。 

## アプローチ

 直接的な強引なアプローチでは、すべてのシーケンスを生成し、それらを要素ごとに拡張し、積と増加しない遷移の数の両方を維持しようとします。 各拡張は積を乗算して違反数を更新し、積が超過するとシーケンスは破棄されます。$n$または複数の違反が表示されます。 

積極的な剪定を行ったとしても、この探索は飛躍的に増大します。 積の制約は成長を遅らせますが、十分ではありません。1 などの多くの小さな整数は積を変更せずに任意に何度も挿入でき、単純な生成では構造的に異なるシーケンスが無限に作成されるからです。 

重要な構造的観察は、シーケンスの単調性において最大 1 回の「中断」が許容されるということです。 これは、すべての有効なシーケンスを 2 つの厳密に増加するセグメントに一意に分解できることを意味します。おそらく空の 2 番目のセグメントがあり、単調性が許容されない単一の遷移によって分離されます。 

この分解により、問題は、任意の制約されたシーケンスに関する推論から、厳密に増加するシーケンスのペアに関する推論に変換されます。 厳密に増加するシーケンスは、すべての要素が個別でソートされた順序で配置された整数のマルチセットに正確に対応します。 

この視点に移ると、それぞれの有効なシーケンスは、積が最大で 2 倍になる因子の 2 つの互いに素な「増加ブロック」を選択することに対応します。$n$。 これにより、問題は、因子のすべてのペアに対して乗算算術関数を使用して表現できる除数構造の計数問題に変換されます。 

最後の変換は、増加する各セグメントが除数のようなカウントに寄与するものとして解釈することです。具体的には、数値を厳密に増加するシーケンスに因数分解する方法の数を解釈します。これは、除数のカウントに密接に関連する関数と同等です。 これにより、すべての因数分解にわたる畳み込み構造が得られます。$a \cdot b \le n$。

 ## アルゴリズムのチュートリアル

 1. すべての有効なシーケンスを、2 つの連続する厳密に増加するシーケンスとして書き換えます。この場合、それらの間の境界は、非増加ペアが許可される唯一の場所です。 これにより、「違反は 1 つまで」という制約が削除され、構造的な分割に変わります。 
2. 厳密に増加する各シーケンスを、乗算因数の順序付きリストとして指定された整数を表現できる方法の数と関連付けます。 この解釈は、シーケンスを因数分解構造に関連付けられた算術オブジェクトに変換します。 
3. 積を使用して完全なシーケンスをカウントしていることを観察します。$\le n$順序付けられたすべての整数ペアの合計と等価になります$(a, b)$そのような$a \cdot b \le n$、両方のコンポーネントに適用される除数のような関数によって重み付けされます。 
4. 定義する$d(x)$厳密に増加する因子列に数値が寄与する方法の数として。 最終的な答えは、すべての有効な分割の合計になります。$a \cdot b \le n$形の$d(a) \cdot d(b)$。 
5. double 条件を単一の合計に書き換えます。$a$、それぞれどこに$a$、追加します$d(a)$次のプレフィックスの合計を乗算します。$d$までのすべての整数にわたって$n/a$。 
6. コンピューティング$d(x)$みんなのために$x \le n$線形ふるいスタイルの除数 DP を使用します。 次に、次のプレフィックスの合計を計算します。$d$。 最後に、小さい商と大きい商を効率的に処理する調和分割トリックを使用して、外側の合計を評価します。 

### なぜ効果があるのか

 すべての有効なシーケンスには最大でも 1 つの違反があり、違反が存在する場合は一意のカット位置が強制されます。 この一意性により、厳密に増加する 2 つの部分に分割された場合にシーケンスが二重にカウントされないことが保証されます。 各部分はそれ自体の因数分解構造にのみ依存するため、積に対する乗法性が有効になります。 畳み込み$a \cdot b \le n$2 つのセグメント間で素因数を分配するすべての方法を正確に捕捉し、完全性を確保し、過剰カウントを防ぎます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    
    # we need divisor counts up to n
    d = [0] * (n + 1)
    
    for i in range(1, n + 1):
        for j in range(i, n + 1, i):
            d[j] += 1

    pref = [0] * (n + 1)
    for i in range(1, n + 1):
        pref[i] = (pref[i - 1] + d[i]) % MOD

    ans = 0

    # sum_{a*b<=n} d[a]*d[b]
    for a in range(1, n + 1):
        ans += d[a] * pref[n // a]
        ans %= MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()

 ## 特殊なケース

 デリケートなケースの 1 つは、1 が優勢なシーケンスです。 のようなシーケンス$(1,1,1,1)$すべての隣接するペアが等価性を満たし、複数の違反が発生するため、これは無効です。 このアルゴリズムは、それらの寄与を除数の数に折り畳むことによって、それらを無害なものとして扱うことを回避します。この場合、それらは中立的な乗算要素のように動作しますが、それでも順序付けの制約には影響します。 

もう 1 つのケースは、次のような 1 つの大きなジャンプを含むシーケンスです。$(2,1,1)$。 積が小さい場合でも、ドロップ後の等価性の繰り返しにより複数の違反がトリガーされ、構造分割により 2 番目のセグメントが厳密に増加したままになるため、そのようなシーケンスは自動的に除外されます。 

最後に、次のような混合因数分解$(1,2,1)$2 つのブロック分解の正しさを示します。 最初のブロック$(1,2)$厳密に増加しており、2 番目のブロック$(1)$も厳密に増加しており、それらの間で許可される遷移は 1 つだけです。 このアルゴリズムは、両方のセグメントにわたって寄与を乗算的に分離することによってこれを考慮します。
