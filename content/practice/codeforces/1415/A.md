 ## 解決策
 ## 問題の理解

 私たちには長方形の刑務所が与えられています。$n$行と$m$列。 各独房には厳密に 1 人の囚人が収容されており、列にある独房には出口トンネルが 1 つあります。$r$そしてコラム$c$。 すべての囚人は、隣接する独房 (上下左右) に 1 秒以内に移動することも、その場にとどまることもできます。 目標は、すべての囚人が最適に移動した場合に、最後の囚人が脱出トンネルに到達するまでにどれくらいの時間がかかるかを判断することです。 結果は、すべての囚人が出口に集まることができる最小秒数です。 

入力では複数のテスト ケースが提供され、それぞれのテスト ケースで刑務所のサイズとトンネルの位置が示されます。 各テスト ケースの出力は、すべての囚人がトンネルに到達するまでに必要な最小時間を表す単一の整数です。 

制約は非常に大きいです。$n$そして$m$まで可能です$10^9$、およびテストケースの数$t$到達できる$10^4$。 これにより、すべてのセルに対するシミュレーションや反復が即座に除外されます。 各囚人の距離を個別に計算したり、完全な距離を保存したりすることはできません。$n \times m$メモリ内の行列。 解は、最大距離を直接計算する式でなければなりません。 

明白ではないエッジ ケースには、隅または端にあるトンネルが含まれます。 たとえば、トンネルが画面の左上隅にある場合、$1 \times 1$刑務所の場合、答えは 0 です。トンネルが次の位置にある場合、$(1, 1)$で$10 \times 10$刑務所、一番遠い囚人は反対側の隅にいます$(10, 10)$、そして時間は$18$。 トンネルが中心付近にあると仮定したり、距離を平均したりする不用意なアプローチは、ここで誤った答えを生み出す可能性があります。 

## アプローチ

 この強引なアプローチは、各囚人をグリッド内の点として想像し、トンネルまでのマンハッタンの距離を計算することです。 それぞれの囚人に対して、$(i, j)$、距離は$|i - r| + |j - c|$。 すべての囚人がトンネルに到達するまでの最小秒数が、すべての独房の最大距離となります。 これは概念的には機能しますが、セル内のすべてのセルを反復処理します。$n \times m$グリッドは大きい場合は不可能です$n$そして$m$。 最悪の場合に備えて、$n = m = 10^9$、これには必要になります$10^{18}$まったく実行不可能な操作です。 

重要な洞察は、トンネルから最も遠い囚人だけが必要であるということです。 長方形グリッドでは、特定のセルから最も遠いセルは常に 4 隅の 1 つになります。 したがって、トンネルから各コーナーまでの距離を計算し、最大値を取得できます。 これにより、問題は数十億のセルを反復することから、単純に 4 つの式を評価することに軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n*m) | お(1) | 遅すぎる |
 | 最適 | テスト ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取り、$t$。 
2. 各テスト ケースの寸法を読み取ります。$n$そして$m$そしてトンネルの位置$(r, c)$。 
3. グリッドの 4 隅を特定します。$(1, 1)$、$(1, m)$、$(n, 1)$、 そして$(n, m)$。 
4. トンネルから各角までのマンハッタンの距離を計算します。$|r - 1| + |c - 1|$、$|r - 1| + |c - m|$、$|r - n| + |c - 1|$、 そして$|r - n| + |c - m|$。 
5. これら 4 つの距離の最大値を取得します。 これは、最も遠い囚人がトンネルに到達するのに必要な最小秒数を表します。 
6. 各テスト ケースの最大距離を出力します。 

機能する理由: マンハッタン距離は、移動が基本的な方向に制限されている場合に、グリッド内で必要な最小移動数を正確に表します。 グリッド内のどの点も、少なくとも 1 つの角よりもトンネルに近いため、トンネルから最も遠い囚人はいずれかの角にいる必要があります。 最大限の距離をとることで、最も遠い囚人を含むすべての囚人がトンネルに到達できるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m, r, c = map(int, input().split())
    dist1 = abs(r - 1) + abs(c - 1)
    dist2 = abs(r - 1) + abs(c - m)
    dist3 = abs(r - n) + abs(c - 1)
    dist4 = abs(r - n) + abs(c - m)
    print(max(dist1, dist2, dist3, dist4))
```このソリューションは、まずテスト ケースの数を読み取ります。 テスト ケースごとに、刑務所のサイズとトンネルの座標を表す 4 つの整数を読み取ります。 四隅までの距離は、マンハッタン距離を直接実装する絶対差を使用して計算されます。 これら 4 つの値の最大値が出力されます。 使用する`abs`負の差がエラーを引き起こさないことを保証し、各距離を個別に計算することで、1 つずつ異なる間違いを回避します。 

## 実用的な例

 ### サンプル 1

 入力:`10 10 1 1`| コーナー | 距離 |
 | --- | --- |
 | (1,1) | 0 |
 | (1,10) | 9 |
 | (10,1) | 9 |
 | (10,10) | 18 |

 最大距離: 18。これは、最も遠い囚人が右下隅にいることを示しています。 

### サンプル 2

 入力:`3 5 2 4`| コーナー | 距離 |
 | --- | --- |
 | (1,1) | 4 |
 | (1,5) | 3 |
 | (3,1) | 4 |
 | (3,5) | 2 |

 最大距離: 4。最も遠い囚人は左上隅または左下隅にいます。 

これらの例は、最大距離が常にコーナーの 1 つから得られ、アルゴリズムがそれを正しく識別することを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | テスト ケースごとに O(1) | 4 つの距離計算のみが実行されます。 
| スペース | お(1) | 配列やグリッドは保存されません。 

与えられた$t \le 10^4$、合計の操作は次のとおりです。$4 \cdot t \le 4 \cdot 10^4$, これは 1 秒の制限に簡単に収まります。 メモリ使用量は最小限です。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        n, m, r, c = map(int, input().split())
        dist1 = abs(r - 1) + abs(c - 1)
        dist2 = abs(r - 1) + abs(c - m)
        dist3 = abs(r - n) + abs(c - 1)
        dist4 = abs(r - n) + abs(c - m)
        print(max(dist1, dist2, dist3, dist4))
    return output.getvalue().strip()

assert run("3\n10 10 1 1\n3 5 2 4\n10 2 5 1\n") == "18\n4\n6", "Sample 1"
assert run("1\n1 1 1 1\n") == "0", "Single cell"
assert run("1\n5 5 3 3\n") == "4", "Tunnel in center"
assert run("1\n1000000000 1000000000 1 1\n") == "1999999998", "Maximum size corner"
assert run("1\n1000000000 1000000000 500000000 500000000\n") == "1000000000", "Maximum size center"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1\n1 1 1 1\n`|`0`| 単房刑務所 |
 |`1\n5 5 3 3\n`|`4`| 中央のトンネル | 写真 中央のトンネル
 |`1\n1000000000 1000000000 1 1\n`|`1999999998`| 最大サイズのグリッド、コーナートンネル |
 |`1\n1000000000 1000000000 500000000 500000000\n`|`1000000000`| 最大サイズのグリッド、センタートンネル |

 ## 特殊なケース

 のために$1 \times 1$刑務所ではトンネルが唯一の独房です。 アルゴリズムは単一のコーナーまでの距離を計算します$(1,1)$、これは 0 です。出力は正しく 0 です。 

コーナーにトンネルがある最大サイズのグリッドの場合、$(1,1)$で$10^9 \times 10^9$刑務所、一番遠い囚人はここにいる$(10^9,10^9)$。 アルゴリズムは計算します`abs(1-10^9) + abs(1-10^9) = 1999999998`、期待と一致します。 

トンネルが中央にある場合、コーナーまでの距離は異なります。 アルゴリズムは最大値を正しく選択し、すべてのセルを反復することなく最も遠い囚人が考慮されるようにします。
