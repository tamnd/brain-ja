 ## 問題の理解

 文字列には丸括弧のみが含まれています。 残りのインデックスを元の順序に保ちながら、いくつかの文字を削除する必要があります。 目標は、反転が通常の括弧シーケンスである最長のサブシーケンスを取得することです。 このプロパティを満たす空ではないサブシーケンスがない場合は、次のように出力します。`-1`。 

通常の括弧のシーケンスには 2 つの要件があります。1 つは開き括弧と閉じ括弧の合計数が等しいこと、もう 1 つは左から右に読むときに開き括弧の数が閉じ括弧の数より小さくなることです。 反転された通常の括弧シーケンスの場合、これらの条件は、選択したサブシーケンスを反転した後に適用されます。 

選択したサブシーケンスが`T`、それから読んでください`T`右から左へは、通常の括弧シーケンスのように動作する必要があります。 つまりスキャン中`T`終わりから始まりに向かって、すべての閉じ括弧には、この逆の順序で利用可能な以前の開始括弧が必要です。 

入力の長さは 100 万文字に達する場合があります。 可能なサブシーケンスの数は指数関数的であるため、異なるサブシーケンスを試す解決策は不可能です。 すべてのポジションのペアをチェックするだけでも、すでに遅すぎます。 入力サイズから、すべての括弧が一定の回数だけ処理される、線形または線形に近いアプローチが必要であることがわかります。

## アプローチ

 直接的なアプローチは、候補部分列を生成し、それらの逆が規則的であるかどうかをテストすることです。 これは正しいです。削除された文字のあらゆる選択肢が検査されるため、最も有効な選択肢が表示される必要があります。 ただし、長さ 100 万の文字列には、膨大な数のサブシーケンスが含まれます。具体的には、$2^n$となり、このアプローチは使用できなくなります。 

より良い方法は、逆転した状態を別の観点から見ることです。 逆のサブシーケンスを構築する代わりに、元の文字列を右から左に読み取ることを想像してください。 選択した文字は、その方向に通常の規則的な括弧シーケンスを形成する必要があります。 

通常の通常のブラケットのサブシーケンスの場合は、貪欲なマッチング戦略で十分です。 開始括弧が表示されると、将来の終了括弧を待つことができます。 閉じ括弧が表示された場合は、可能であれば待機している開始括弧を 1 つ使用する必要があります。 一致が成功するたびに 1 つのペアが作成されます。 

元の文字列を逆方向にトラバースしながら同じアイデアを適用すると、逆向きの正規括弧サブシーケンスのペアの最大数が得られます。 実際に選択されたインデックスを知る必要はありません。 すべてのペアは 2 つの文字を提供するため、一致するペアの数だけが必要です。 

ブルート フォースは、考えられるすべての削除を探索するため機能しますが、同じ一致の決定を何度も繰り返します。 貪欲な観察では、一致が可能な場合は常に、利用可能なすべての括弧を使用する必要があることを証明することで、その繰り返しを排除します。

 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 文字列の末尾から始めて、先頭に向かって移動します。 反転した選択されたサブシーケンスは規則的である必要があるため、この方向にスキャンします。 
2. この逆方向のトラバーサルで利用可能な一致しない開始括弧の数を表すカウンタを維持します。 出会ったとき`(`、このブラケットは後のブラケットと一致する可能性があるため、このカウンタを増やします。`)`逆の順序で。 
3. 出会ったとき`)`、利用可能な一致しないものが存在するかどうかを確認します。`(`。 存在する場合は、開始括弧を 1 つ消費し、一致するペアの数を増やします。 これは、この閉じ括弧が有効なサブシーケンスに寄与できる唯一の方法です。 
4. 文字列全体を処理した後、一致したペアの数を 2 倍します。 一致するペアがない場合は出力します。`-1`有効なサブシーケンスが存在しないためです。 

なぜ効果があるのか:

 右から左へのスキャン中、カウンタは、逆の順序で将来の一致をサポートできる開始括弧の数を正確に意味します。 閉じ括弧がカウントされるたびに、それを 1 つの使用可能な開始括弧と照合します。 使用可能な開始括弧を未使用のままにしておくと、すぐに使用するよりも後の終了括弧に役立つことができないため、これは最適です。 このプロセスは、反転された文字列内で最も長い通常の括弧のサブシーケンスを見つけることと同じであるため、作成されるペアの数は可能な限り最大になります。 

## Python ソリューション```python
import sys

input = sys.stdin.readline

def solve():
    s = input().strip()

    available_open = 0
    pairs = 0

    for ch in reversed(s):
        if ch == '(':
            available_open += 1
        else:
            if available_open > 0:
                available_open -= 1
                pairs += 1

    if pairs == 0:
        print(-1)
    else:
        print(pairs * 2)

if __name__ == "__main__":
    solve()
```スキャンで使用されるのは、`reversed(s)`反復順序が、逆括弧の定義で必要な方向と一致するようにします。 変数`available_open`は、この方向に出現したがまだペアになっていない左括弧の数です。 

とき`)`と表示されると、コードは境界条件をチェックします。`available_open > 0`引き算する前に。 このチェックがないと、実装では存在しない無効なペアがカウントされます。 

成功した各一致はちょうど 1 つの開始括弧と 1 つの終了括弧に寄与するため、答えは多数のペアとして保存されます。 最後の 2 の乗算により、ペアがサブシーケンスの長さに変換されます。 

再帰、配列、または余分な文字列は作成されません。これは、入力サイズが 100 万文字に達する可能性があるため重要です。
