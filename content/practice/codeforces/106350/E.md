 ## 解決策
 ## 問題の理解

 この問題では、入力が整数の x 座標の間隔を与える逆関数によって定義される曲線を考慮するように求められます。 その区間内のゼロ以外の整数ごとに、その x 座標で曲線への接線を描きます。 その接線は 2 つの座標軸と交差し、三角形を作成します。 タスクは、これらすべての三角形の面積を追加することです。 

入力値は次のように大きくできます。$10^{18}$絶対値で言うと。 間隔の長さはおよそである可能性があるため、これにより、間隔内のすべての整数を反復処理することは即座に除外されます。$2 \times 10^{18}$、プログラムが処理できる範囲をはるかに超えています。 一定時間または対数時間の観測が必要です。 関数と接線公式は代数的に単純であるため、目的の解決策は検索やシミュレーションではなく幾何学的表現を単純化することで得られます。 

よくある間違いは、ゼロは許可されていないことを忘れることです。 たとえば、入力の場合:```
0 0
```答えは次のとおりです。```
0
```逆関数がゼロで定義されていないため、有効な x 座標はありません。 間隔のサイズのみをカウントするプログラムは、誤って 2 を出力します。 

間隔がゼロと交差するときに、別のエッジ ケースが発生します。 入力の場合:```
-2 2
```有効な座標は$-2,-1,1,2$、したがって、答えは次のようになります。```
8
```不注意に実装すると、5 つの位置をカウントしてゼロが含まれる可能性があり、誤った結果が生成されます。 

最後の境界ケースは単一の負の値です。```
-7 -7
```答えは次のとおりです。```
2
```接線が軸の反対側にある場合、面積は負になりません。 三角形の領域は絶対長を使用します。 

## アプローチ

 直接的なアプローチは、区間内のすべての整数 x を訪問し、ゼロをスキップし、接線を計算し、その三角形の面積を計算し、それを答えに加算することです。 これは定義に正確に従っているため、正しいです。 ただし、間隔に次のものが含まれる場合は、$10^{18}$ループに必要な値はおおよそ$10^{18}$制限時間内にそれを繰り返すことは不可能です。 

重要な観察は、三角形の領域が有効なすべての x 座標で同じであるということです。 選んだ座標を$a$。 の派生関数$1/x$は$-1/x^2$、つまり、次の接線は$(a,1/a)$は$$y-\frac1a=-\frac1{a^2}(x-a)$$これを単純化すると$$y=-\frac{x}{a^2}+\frac2a$$x 切片は次の設定によって求められます。$y=0$:$$0=-\frac{x}{a^2}+\frac2a$$それで：$$x=2a$$y 切片は次のとおりです。$$y=\frac2a$$軸と線によって形成される三角形の面積は次のとおりです。$$\frac12 \times |2a| \times \left|\frac2a\right| = 2$$ゼロ以外のすべての整数は、正確に 2 を答えに与えます。 ジオメトリが消え、問題全体が区間内にゼロ以外の整数がいくつあるかを数えるようになります。 

ブルートフォース手法は各ポイントを独立して処理できるため機能しますが、ポイントが多すぎるため失敗します。 代数的単純化により、数十億の幾何学的計算を 1 つの区間カウントに置き換えることができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(r-l+1) | お(1) | 遅すぎる |
 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 間隔の 2 つのエンドポイントを読み取ります。 
2. 間隔内に整数がいくつあるかを数えます。 整数の合計数は$r-l+1$。 間隔にゼロが含まれている場合、そこでは関数が定義されていないため、カウントからそれを削除します。 
3. 有効な整数の数に 2 を掛けます。有効な整数ごとに、面積がちょうど 2 の三角形が作成されます。 

これが機能する理由は、答えが実際の位置ではなく、有効なポイントの数によってのみ決定されるためです。 三角形領域は絶対長を使用するため、負の座標と正の座標は等しく寄与します。 

なぜ効果があるのか:

 ゼロ以外の整数ごとに$x$、接線は切片を作成します$2x$そして$2/x$。 それらの絶対積は常に 4 であるため、三角形の面積は常に$4/2=2$。 三角形は独立しているため、最終的な合計は単純に 2 に許容される x 値の数を乗算したものになります。 必要な特別な処理はゼロの削除だけです。$1/x$そこには存在しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    l, r = map(int, input().split())

    count = r - l + 1
    if l <= 0 <= r:
        count -= 1

    print(count * 2)

if __name__ == "__main__":
    solve()
```プログラムはまず、閉じた区間のサイズを計算します。 これはエンドポイントでの算術のみを使用するため、近くのエンドポイントでも$10^{18}$Python の整数によって即座に処理されます。 

ゼロチェックは次のように記述されます。`l <= 0 <= r`、ゼロが区間に属するかどうかを直接記述します。 そうなった場合、カウントは 1 つ減ります。 

最終的な 2 の乗算により、すべての有効な接線三角形の定数寄与が適用されます。 ループ、浮動小数点演算、幾何学的計算がないため、精度の問題はありません。

## テストケース```python
import sys
import io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    l, r = map(int, input().split())

    count = r - l + 1
    if l <= 0 <= r:
        count -= 1

    return str(count * 2)

# minimum-size style case
assert solve("0 0\n") == "0"

# single valid point
assert solve("5 5\n") == "2"

# interval crossing zero
assert solve("-2 2\n") == "8"

# large boundary case
assert solve("-1000000000000000000 1000000000000000000\n") == "4000000000000000000"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`0 0`|`0`| 未定義の点ゼロは何も寄与しません。 |
 |`5 5`|`2`| 単一の有効な接線は、正確に 1 つの面積値に寄与します。 |
 |`-2 2`|`8`| ゼロ除去と対称的な負の値。 |
 |`-1000000000000000000 1000000000000000000`|`4000000000000000000`| 最大サイズのエンドポイントの処理。 |

 ## 特殊なケース

 入力の場合:```
0 0
```アルゴリズムは間隔サイズ 1 から始まります。間隔内に 0 があるため、1 が減算され、有効なカウントは 0 になります。 最後の乗算では 0 が得られます。 

入力の場合:```
-2 2
```値が次のとおりであるため、初期カウントは 5 です。$-2,-1,0,1,2$。 ゼロを検出する条件が真であるため、カウントは 4 になります。答えは次のようになります。$4 \times 2=8$、4 つの有効な接線三角形と一致します。 

入力の場合:```
-7 -7
```間隔には値が 1 つだけ含まれます。 ゼロ条件は false であるため、カウントは 1 のままです。答えは 2 で、面積では絶対距離が使用されるため、負の座標が正の座標と同じように扱われることを示しています。
