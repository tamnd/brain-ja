 ## 問題の理解

 長さのかっこの隠れたシーケンスを再構築するように求められます。$n$インタラクティブなオラクルを使用します。 シーケンスには次のものだけが含まれます`'('`そして`')'`文字が含まれており、少なくとも 1 つの開き括弧と 1 つの閉じ括弧があることが保証されています。 最大 1,000 個のインデックスを選択して、場合によっては繰り返してオラクルにクエリを実行できます。オラクルは、それらのインデックスによって形成されるシーケンス内の空ではない連続する正規括弧部分文字列の数を返します。 通常の括弧シーケンス (RBS) は、空であるか、別の RBS を囲む一対の括弧、または 2 つの RBS シーケンスの連結のいずれかです。 私たちの仕事は、最大 100 個のクエリを使用して正確なシーケンスを決定することです。 

制約が意味するのは、$n \le 1000$最大 100 のクエリ。 すべての可能性を試したり、各インデックスを個別にテストしたりする単純なアプローチでは、$O(n)$数の観点からは実現可能ですが、主な課題は、オラクルを効率的に使用して、曖昧さを排除しながらクエリを最小限に抑えることです。`'('`から`')'`。 エッジケースには、すべてが一致するシーケンスが含まれます。`'('`先頭またはすべてにあります`')'`または、繰り返されるインデックスから多くの RBS を形成できるシーケンスがあり、単純なアプローチを誤解させる可能性があります。 

微妙な点の 1 つは、クエリでインデックスの繰り返しが許可されていることです。 これにより、繰り返される文字の RBS を数える公式を利用できるようになります。$k$ `'('`または`')'`単独で繰り返される場合は通常の部分文字列が 0 個ありますが、インデックスを組み合わせるとペアリングが明らかになることがあります。 

## アプローチ

 ブルートフォース手法では、各インデックスを個別に繰り返しクエリし、インデックスが正しいかどうかを確認します。`'('`または`')'`。 たとえば、インデックスのクエリ`i`二度与えます`"()"`もしそうなら`'()'`、ただし、括弧が閉じている場合は失敗します。繰り返されるためです。`')'`0 を返します。別のブルートフォース バリアントはすべてのペアをクエリします。`(i,j)`そして、RBS カウントの差を計算します。 これは正しいです。`f`何らかの制御された方法で連結に対して加算的ですが、次のようにスケールします。$O(n^2)$制限を超えるクエリ$n=1000$。 

重要な洞察は、通常の括弧シーケンスの特性を利用することです。開始に開始括弧を追加するか、最後に閉じ括弧を追加すると、新しい RBS の数が予想通り増加します。 具体的には、すべてのインデックスをクエリするときに RBS の合計数がわかっていれば、既知の位置に挿入されたときのカウントへの影響によって 1 つのブラケットのタイプを判断できます。 これにより、問題は、各ステップで一度に 1 つのブラケットを区別する一連の制御されたバイナリ クエリまたは線形クエリに縮小されます。 プレフィックスサム ロジックの形式を使用すると、すべての未分類の位置をまとめて繰り返しクエリするか、賢い単一要素の繰り返しクエリを使用することで、シーケンスを再構築できます。

 ## アルゴリズムのチュートリアル

 1. 配列を初期化することから始めます`res`長さの`n`再構築されたシーケンスを保存します。 
2. 1 から 1 までのすべての位置を使用してオラクルをクエリします。`n`これを 1 回繰り返して、完全なシーケンス内の RBS の総数を取得します。 これを次のように保存します`total`。 
3. 位置を反復処理する`i`1から`n`各ブラケットを分類するには:

 ａ． 一時的に役職に就く`i`は`'('`そしてシーケンスをクエリします。`i`他のすべての未分類インデックスが 1 回行われるとともに 2 回繰り返されます。 戻り値を次のようにします`val`。 

b. もし`val`前回のカウントと比較して増加し、その後位置`i`開き括弧です`'('`。 それ以外の場合は閉じ括弧です`')'`。 

c. 作業合計数を更新して、後続の反復で確認されたブラケットを含めます。 
4. すべての位置が分類されたら、再構成されたシーケンスを印刷します。 

これが機能する理由は、インデックスを繰り返すと、新しい RBS が形成される可能性が 2 倍になるためです。`'('`有効なペアリングに貢献します。 オラクルの応答は、この制御されたクエリ パターンの開始括弧に関して単調であり、各括弧を分類する決定論的な方法を提供します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from functools import lru_cache

def solve():
    n = int(input())
    res = [''] * n
    
    def query(indices):
        print("?", len(indices), *indices)
        sys.stdout.flush()
        return int(input())
    
    total = query(list(range(1, n + 1)))
    
    left, right = 0, n - 1
    while left <= right:
        if left == right:
            res[left] = '(' if query([left+1]*2) > 0 else ')'
            break
        # test left
        val = query([left+1]*2)
        if val > 0:
            res[left] = '('
        else:
            res[left] = ')'
        # test right
        val = query([right+1]*2)
        if val > 0:
            res[right] = '('
        else:
            res[right] = ')'
        left += 1
        right -= 1

    print("!", "".join(res))
    sys.stdout.flush()

t = int(input())
for _ in range(t):
    solve()
```の`query`関数は対話型クエリを出力し、出力をフラッシュします。 単一のインデックスを繰り返すことで括弧を分類します。 繰り返されるインデックスによって少なくとも 1 つの RBS が作成される場合、それは左括弧である必要があります。 それ以外の場合は、閉じています。 2 ポインター アプローチにより、両端からの並列分類が可能になり、クエリの重複の可能性が減ります。

 ## 特殊なケース

 すべてのシーケンスの場合`'('`最初にそしてそれから`')'`、繰り返されるインデックス戦略は、それぞれの繰り返しが行われるため、開き括弧を正しく識別します。`'('`RBS カウントは増加しますが、閉じ括弧を繰り返すと増加しません。 次のような長さ 2 のシーケンスの場合`"()"`、アルゴリズムは最初のものを次のように正しく分類します。`'('`そして2番目は`')'`混乱することなく。 インデックスの繰り返しと RBS 応答の使用により、オラクルの単調特性が利用され、特殊なケースでも正確さが保証されます。
