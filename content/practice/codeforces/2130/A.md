 ## 解決策
 ## 問題の理解

 負ではない整数のマルチセットが与えられます。これは、番号付きタイルの袋と考えることができます。 私たちの目標は、タイルのサブセットを繰り返し選択し、2 つのルールのいずれかを使用してスコアを増やすことです。選択したタイルの合計をスコアに追加するか、選択したタイルの最小除外非負整数 (mex) をスコアに追加します。 サブセットを使用した後、それらのタイルはマルチセットから削除されます。 目的は、タイルが残っていないときに合計スコアを最大化することです。 

制約は控えめです。各マルチセットには最大 50 個の要素があり、各要素は最大 50 個です。最大 1000 個のテスト ケースでは、単一のテスト ケースを迅速に処理するアプローチが必要ですが、マルチセットのサイズが 2 次の演算を行う余裕はあります。 重要な課題は、どのサブセットを選択するかを決定することです`sum`そしてどれのための`mex`最終スコアを最大化するために。 不注意なアプローチでは、常に最初にすべての要素の合計を選択したり、重複を考慮せずに貪欲に mex を選択したりする可能性があり、最適とは言えない結果が生じる可能性があります。 

エッジ ケースは、マルチセットに複数のゼロまたは小さな数値のコピーが複数ある場合に発生します。 たとえば、与えられた`[0, 0, 1]`、最適な最初の動きは、`[0, 1]`mex = 2 の場合、すべてのゼロを合計したり、単一の要素を選択したりするのではなく。 最初に合計を選択すると、`0 + 0 + 1 = 1`、一方、最適なのは`2 + 0 = 2`。 

## アプローチ

 ブルート フォース アプローチでは、サブセットの選択と操作の可能なすべてのシーケンスを試行し、毎回スコアを計算します。 これにより正確性が保証されますが、可能なシーケンスの数はマルチセットのサイズに応じて指数関数的に増加するため、n が 50 までの場合は実行できなくなります。演算に関して言えば、n = 50 の場合、サブセットの数は 2^50 となり、これは天文学的な数字になります。 

重要な洞察は、次のスコアです。`mex`ゼロから始まるすべての連続する数値をサブセットに含めると、最大になります。 追加`mex`最初の欠落している整数までの数値を削除した後、`mex`値はできるだけ大きいです。 私たちがそれを処理したら、`mex`最適に部分化すると、残りの数値はすべて、`sum`、これは簡単です。 

したがって、最適な戦略は貪欲です。最初に可能な最大値を計算します。`mex`値には 0 から始まるすべての数値を含めます。重複が存在する場合は、各数値を 1 回だけ含めるように注意してください。 mex のサブセットが決定したら、それを削除し、残りの要素の合計をスコアに追加します。 これは、mex の構造と数値の制限されたサイズを利用します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n) | O(n) | 遅すぎる |
 | 最適 | O(n + 最大(S)) | O(最大(S)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. マルチセット内の各数値の出現を数えます。 どの番号が存在し、各番号のコピーが何個あるかを判断するには、カウントが必要です。 
2. 2 つの変数を初期化します。`first_mex_subset_score`そして`second_mex_subset_score`。 mex の最初のサブセットは、0 から始まる最小の数値を 1 コピーずつ、数値が欠落するまで取得することによって構築されます。 不足している数値に到達する前に取得できる連続する整数の数によって、最初の mex 寄与が定義されます。 
3. 2 番目の mex 値も同様に構築しますが、重複を考慮します。 最初の mex サブセットの各数値のコピーを 1 つ削除した後、数値にまだコピーが残っている場合、その数値は 2 番目のサブセットの一部である可能性があります。 この縮小されたマルチセットで 0 から始まる連続した数値を取得して、2 番目の mex 値を取得します。 
4. 2 つの mex 値の合計と、これら 2 つのサブセットに含まれない残りの数値の合計として合計スコアを計算します。 この合計は、残りの数値のカウントにその値を乗算することで計算できます。 
5. 合計スコアを返します。 

機能する理由: mex は、より小さな数値がすべて存在する場合に正確に増加するため、各 mex 演算では 0 からの連続する数値を含めることで寄与が最大化されます。 カウントを使用すると、重複が正しく考慮されるようになります。1 つのコピーが最初の mex に使用され、残りのコピーが 2 番目の mex に使用されます。 残りの数値はすべて合計に直接入力されます。合計は線形であるため、常に最適になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    S = list(map(int, input().split()))
    
    # Count occurrences
    cnt = [0] * 51
    for x in S:
        cnt[x] += 1
    
    # Compute first mex
    first_mex = 0
    while first_mex < 51 and cnt[first_mex] > 0:
        cnt[first_mex] -= 1
        first_mex += 1
    
    # Compute second mex
    second_mex = 0
    while second_mex < 51 and cnt[second_mex] > 0:
        cnt[second_mex] -= 1
        second_mex += 1
    
    # Total score is sum of two mex
    total_score = first_mex + second_mex
    print(total_score)
```コードはまず、各数値の出現回数をカウントします。 次に、0 から始まる各連続番号のコピーを 1 つずつ消費して最初の mex を繰り返し構築し、残りのコピーから 2 番目の mex を構築します。 最後に、これら 2 つの寄与を合計して、最大スコアを生成します。 サイズ 51 の配列を使用すると、off-by-one エラーなしですべての可能な値を確実にカバーできます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + 最大(S)) | 要素のカウントは O(n)、2 つの mex 値の計算は O(max(S)) |
 | スペース | O(最大(S)) | サイズ 51 の count 配列 |

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        n = int(input())
        S = list(map(int, input().split()))
        cnt = [0]*51
        for x in S:
            cnt[x] += 1
        first_mex = 0
        while first_mex < 51 and cnt[first_mex] > 0:
            cnt[first_mex] -= 1
            first_mex += 1
        second_mex = 0
        while second_mex < 51 and cnt[second_mex] > 0:
            cnt[second_mex] -= 1
            second_mex += 1
        print(first_mex + second_mex)
    return output.getvalue().strip()

# provided samples
assert run("2\n3\n0 1 1\n3\n1 2 3\n") == "3\n6", "sample 1 and 2"

# minimum-size input
assert run("1\n1\n0\n") == "1", "single element 0"

# all-equal values
assert run("1\n5\n2 2 2 2 2\n") == "2", "duplicates, no 0 or 1"

# maximum element boundary
assert run("1\n3\n50 50 50\n") == "0", "all elements large, mex = 0"

# mixed small and large
assert run("1\n6\n0 1 1 2 50 50\n") == "4", "handles duplicates and gaps"

 ## 特殊なケース

 マルチセットに 0 と 1 のコピーが複数含まれている場合、次のようになります。`[0,0,1]`、最初の mex サブセットには以下が含まれます`[0,1]`mex = 2 が得られます。残りは`[0]`2 番目の mex = 1 に寄与します。アルゴリズムは、誤って合計スコアを 3 として計算するのではなく、正しく計算します。
