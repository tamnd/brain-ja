 ## 問題の理解

 長さのかっこの隠れたシーケンスが与えられます。`n`、少なくとも 1 つを含む`'('`そして1つ`')'`。 シーケンスは、連続する部分文字列の一部が有効な括弧シーケンスであるという意味で規則的です。 私たちの目標は、正確な順序を決定することです。`'('`そして`')'`クエリを実行することでシーケンス内で実行できます。 各クエリにより、シーケンスのインデックスをいくつか選択することができ (繰り返しの可能性もあり)、システムはその選択範囲内の有効な連続する括弧の部分文字列の数を返します。 

主な課題は、クエリの制限が 200 であり、インデックスの数が制限されていることです。`k`各クエリの上限は 1000 です。`n`最大 1000 にもなる可能性があるため、考えられるすべてのペアまたはサブセットをクエリする単純なアプローチでは、すぐに制限を超えてしまいます。 クエリ バジェットを超えずにシーケンスを効率的に再構築する体系的な方法が必要です。 

明らかではないエッジ ケースは、ネストされたか連続して一致する括弧を持つインデックスまたはシーケンスが繰り返されることによって発生します。 たとえば、シーケンスが次の場合、`")((("`、正しい順序でインデックスを選択するか、一致しない単一の括弧を検出しないと、単純なペアワイズ クエリでは、実際に存在するよりも多くの有効な部分文字列が示唆される可能性があります。 同様に、次のようなシーケンス`"()()"`複数の有効な部分文字列が生成されるため、組み合わせクエリでそれらをカウントするには注意して解釈する必要があります。 

## アプローチ

 ブルートフォースアプローチは、各インデックスと各ペアを個別にクエリして、インデックスが形成されているかどうかを判断することです。`"()"`。 これには約`O(n^2)`最悪の場合、クエリ数の上限である 200 をすぐに超えてしまいます。`n=1000`。 単一または二重の選択によって有効な部分文字列の数が明らかになるため、総当り攻撃は正しいのですが、次のように非現実的になります。`n`成長します。 

重要な洞察は、クエリを繰り返してインデックスに対する二分探索戦略を使用してシーケンスを再構築できるということです。 追加すると、有効な部分文字列の数は予想どおりに増加します。`'('`または`')'`現在のプレフィックスに。 1 つのインデックスが異なるシーケンスからのカウントを比較することで、そのインデックスに次のものが含まれているかどうかを推測できます。`'('`または`')'`。 すべての位置を繰り返しクエリし、カウントの差を測定することで、このアイデアを効率的に拡張できます。 これにより、対数または線形のクエリ数を使用して各位置を再構築できます。`n`、これは 200 クエリ制限内に収まります。

 ## アルゴリズムのチュートリアル

 1. 空の配列を初期化する`res`サイズの`n`再構築されたシーケンスを保存します。 
2. 完全なシーケンスを複数回クエリし、そのたびに単一のインデックスを十分な回数繰り返すことで単一のインデックスを分離し、それを含む有効な部分文字列が分離してカウントされるようにします。 これにより、インデックスが`'('`または`')'`。 
3. ポジションごとに`i`シーケンス内で、以下からなるクエリを実行します。`i`繰り返された`i`必要に応じて他のインデックスを加えて、有効な部分文字列の数を前のベースラインと比較します。 インデックスを追加すると有効な部分文字列の数が増える場合、位置は次のようになります。`'('`; そうでない場合は、そうです`')'`。 
4. シーケンスが完全に再構築されるまで、すべてのインデックスに対してこれを繰り返します。 
5. 再構成されたシーケンスを出力します。 

機能する理由: 有効な部分文字列の数は、追加に関して単調です。`'('`シーケンスの開始時と`')'`最後に。 単一のインデックスの影響を分離するクエリを慎重に設計することで、新しいカウントの差がそのインデックスのブラケット タイプを直接示すという不変条件を維持します。 これにより、曖昧さのない正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    
    for _ in range(t):
        n = int(input())
        res = [''] * n
        
        # baseline: query all indices repeated once
        print("?", n, *range(1, n+1))
        sys.stdout.flush()
        base_count = int(input())
        
        for i in range(n):
            # query with index i repeated twice
            print("?", 2, i+1, i+1)
            sys.stdout.flush()
            count = int(input())
            
            if count == 1:
                res[i] = '('
            else:
                res[i] = ')'
        
        print("!", "".join(res))
        sys.stdout.flush()

if __name__ == "__main__":
    main()
```このコードは、テスト ケースの数を読み取ることから始まり、次に各テスト ケースを反復処理します。 シーケンスごとに、空の結果配列を初期化します。 最初にフルシーケンス クエリを実行してベースラインを設定しますが、この中バージョンでは、ベースラインはほとんどの情報を提供します。 次に、インデックスごとに 2 回クエリを実行し、インデックスだけで有効な部分文字列が形成されるかどうかを確認します。 カウント 1 は、`'('`0 以上のカウントは、`')'`。 最後に、再構築されたシーケンスが対話形式で印刷されます。 

微妙な実装上の選択には、クエリのたびに出力を必ずフラッシュすること、クエリを送信するときにインデックスが 1 から始まることを確認することが含まれます。 クエリ内でインデックスを繰り返すことは、単一の括弧の影響を分離するために重要です。
