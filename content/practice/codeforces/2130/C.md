 ## 解決策
 ## 問題の理解

 整数ペアのセットが与えられ、それぞれが数直線上のセグメントとグラフ内のエッジの両方を表します。 私たちの目標は、これらのペアのサブセットを選択して、カバーされる整数の合計の長さの差を最大化することです。$f(S')$、および少なくとも 3 と呼ばれる長さのサイクルの一部であるノードの数$g(S')$。 入力は複数のテスト ケースを提供します。各テスト ケースには最大 3000 のペアがあり、合計は$n^2$すべてのテストケースで次を超えない$9 \cdot 10^6$、これにより二次関数のアルゴリズムが可能になります。$n$テストケースごとに。 

具体的な解釈としては、$f(S')$は本質的に、各ペアを閉じたセグメントとして扱う場合にカバーされる整数の位置の数です。$g(S')$グラフの周期性を測定します。各ペアが無向エッジとして扱われる場合、長さが 3 以上のサイクルに含まれるノードの数をカウントします。 サブセット$S'$最大化すれば最適です$f(S') - g(S')$。 エッジ ケースは、セグメントが隣接しているか重なっている場合、またはエッジが小さなサイクルを形成している場合に発生します。 たとえば、次のような単一セグメント$(1,2)$～に1単位貢献する$f(S')$そしてゼロから$g(S')$。 三角形を形成する 3 つのエッジを選択すると、$g(S')$3 増加し、全体のスコアが減少します。 

## アプローチ

 ブルートフォースアプローチは、考えられるペアのすべてのサブセットを考慮し、セグメントの和集合を計算することです。$f(S')$グラフ内のサイクルを検出します$g(S')$を選択し、差を最大化するサブセットを選択します。 各サブセットには次の時間がかかります$O(n^2)$和集合の長さを計算し、$O(n^2)$DFS 経由でサイクルを検出します。 合計時間は指数関数的に増加します$2^n$サブセットは、$n=20$、ましてや$n=3000$。 

重要な洞察は、エッジが 3 つ以上の頂点のループを形成する場合にのみ、少なくとも 3 つの長さのサイクルが発生するということです。 フォレスト (サイクルなし) を形成するエッジの選択に限定すると、次のようになります。$g(S') = 0$。 したがって、最大化すると、$f(S') - g(S')$削減から最大化へ$f(S')$サイクルを避けながら。 これは当然、問題をグラフ問題として扱うことになります。つまり、フォレスト (木の集合) を形成し、整数カバレッジの全長を最大化するエッジのサブセットが必要になります。 

循環を防ぐために Disjoint Set Union (DSU) を維持しながら、正しい端点の順序でエッジを貪欲に選択することで、結合の長さを増分的に計算できます。 新しいエッジを検討するたびに、同じ接続コンポーネント内にすでに存在する 2 つのノードを接続していない場合は、そのエッジを追加します。 これにより、サイクルが形成されなくなり、$g(S') = 0$。 DSU の操作は効果的に行われます。$O(\alpha(n))$、ほぼ一定であり、セグメント結合への寄与の確認は次のように線形です。$n$座標は次のように制限されているため、$2n$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^n \cdot n^2)$|$O(n)$| 遅すぎる |
 | 最適 |$O(n \log n + n \cdot \alpha(n))$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースの入力ペアを読み取り、元のインデックスとともに保存します。 
2. ペアを正しいエンドポイントで並べ替えます。 ソートは、前のセグメントが後の重複しないセグメントのための余地を残すため、貪欲な結合長の最大化に役立ちます。 
3. すべての要素に対して Disjoint Set Union (DSU) 構造を初期化します。$2n$ノード。 DSU は、どのノードがすでに接続されているかを追跡し、循環を防ぎます。 
4. 1 から 1 までの整数カバレッジを表す配列を維持します。$2n$。 これは、どの整数がすでにカバーされているかを追跡するのに役立ちます。 
5. ソートされたペアを反復処理します。 各ペアについて、DSU を使用して、そのエンドポイントが同じ接続コンポーネント内にあるかどうかを確認します。 該当する場合は、このペアをスキップします。 それを追加するとサイクルが作成されます。 
6. ペアが異なるコンポーネントを接続している場合は、DSU 内でそれらを結合します。 カバレッジ配列を増分更新して、このセグメントでカバーされるすべての整数をマークします。 
7. 選択したインデックスのリストを保持します。 すべてのペアを処理した後、このリストのサイズとインデックス自体を出力します。 

機能する理由: DSU はサイクルが形成されないことを保証するため、$g(S') = 0$。 ペアを並べ替えて追加することで、可能な限り多くの個別の整数が確実に含まれるようになり、結果が最大化されます。$f(S')$。 どのサイクルもスコアを低下させるだけであるため、カバレッジを最大化しながらサイクルを回避することで最適なソリューションが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n+1))
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return False
        self.parent[y_root] = x_root
        return True

t = int(input())
for _ in range(t):
    n = int(input())
    edges = []
    for i in range(1, n+1):
        a, b = map(int, input().split())
        edges.append((b, a, i))  # store as (right, left, index)

    edges.sort()
    dsu = DSU(2*n)
    selected = []
    covered = [0]*(2*n+2)

    for r, l, idx in edges:
        if dsu.union(l, r):
            selected.append(idx)
            for x in range(l, r+1):
                covered[x] = 1

    print(len(selected))
    print(" ".join(map(str, selected)))
```DSU クラスは、サイクルが形成されないことを保証します。 正しいエンドポイントでソートすると、初期の整数をカバーするエッジを最初に考慮することができます。 カバーされた整数をマークすることは正確さを保つためにオプションですが、$f(S')$最大化されます。 範囲を反復処理すると、共用体のすべての整数が確実にカウントされます。
