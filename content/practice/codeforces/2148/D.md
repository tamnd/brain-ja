 ## 解決策
 ## 問題の理解

 それぞれのフィールドに一定数のタンポポが含まれる一連のフィールドが与えられます。 これらのフィールドを訪問する順序を選択することができ、各フィールドは 1 回ずつ訪問されます。 畑の中を移動している間、オフ状態で開始するバイナリ ステート マシンである芝刈り機を維持します。 

フィールドを処理する前に、そのフィールド内のタンポポの数が奇数か偶数かを検査します。 奇数の場合、芝刈り機はその状態を反転します。 この可能性のある反転の後、芝刈り機がオンになっている場合は、その畑のタンポポをすべて取り除き、その値を最大限に取得します。 オフの場合、フィールドは何も寄与しません。 

タスクは、収集されたタンポポの総数を最大化するフィールドの順序を選択することです。 

すべてのテスト ケースにわたる n の制約の合計は、最大でも 2 × 10^5 です。 これは、テスト ケースごとの線形計算よりも悪いソリューションや、要素ごとの線形よりも悪い、オーバーヘッドが大きいソリューションは困難を伴うことを意味します。 テスト ケースごとに 1 回ソートするか、要素ごとに一定量の簿記を実行するソリューションは許容されます。 

すべての数値が偶数の場合、微妙なエッジケースが発生します。 この状況では、パリティが変化しないため、芝刈り機が反転することはありません。 最初からすべてのフィールドがスキップされ、答えは常に 0 になります。 もう 1 つのコーナーは、奇数の値が 1 つだけ存在する場合です。 その 1 つの奇数によってシーケンス全体の唯一の状態遷移が決定されるため、順序付けには高度な制限がかかります。 

## アプローチ

 直接的なアプローチは、圃場のすべての順列を試し、芝刈り機のプロセスをシミュレートすることです。 順列ごとに、現在の状態を維持し、フィールドを反復処理し、奇数の値に遭遇したときに反転し、芝刈り機がオンになっているときに収集したタンポポを蓄積します。 これはルールを直接反映しているため、これは正しいです。 ただし、nがあります！ 順列があり、各シミュレーションのコストは O(n) となり、テスト ケースごとに O(n · n!) 回の操作が必要になります。これは、n が 15 という小さい場合でも完全に実行不可能です。 

重要な観察は、状態遷移にとって重要なのは大きさではなくパリティだけであるということです。 奇数の値ごとに芝刈り機が反転しますが、偶数の値は反転しません。 これは、パリティ イベントのシーケンスによって、芝刈り機がいつオンになるかオフになるかが完全に決定されることを意味します。 実際の値は、オン状態にある場合にのみ重要です。 

この問題は、いつフリップが発生するか、つまりいつ芝刈り機がオンになるかを制御する順序を選択することとして再解釈できます。 すべての奇数の値を見ると、それぞれの値が状態を 1 回反転します。 これは、大きな値に対して奇数をどのように配置するかによって構造が支配されることを示唆しています。 

これを考えるのに役立つ方法は、奇数の値と偶数の値を区別することです。 偶数の値は状態に影響を与えないため、反転パターンを変更せずにどこにでも配置できます。 ただし、奇数の値は一連の切り替えを定義します。 奇数の畑への訪問をスイッチ イベントとして扱う場合、芝刈り機は奇数の発生ごとにオフとオンを繰り返します。 

ゲインを最大化するには、芝刈り機がオンになっているセグメントにできるだけ多くの大きな値を配置する必要があります。 偶数は状態を妨げないため、収益性の高いセグメント内の「フィラー」として使用するのが最適です。 

最適な構造は、奇数の値のシーケンスを開始する方法を決定することになります。 奇数フィールドから始める場合、芝刈り機が最初に反転してオンになります。つまり、パリティ カウントに応じて、次の奇数までの後続フィールドがすべて収集の候補になります。 これは、初期のアクティブ化を最大化し、高価値のセグメントに対して芝刈り機をオンにし続ける方法で奇妙な要素を配置するという貪欲な戦略につながります。

最後の簡略化は、奇数の値の間で最適なプレフィックスの配置を決定するだけでよいということです。最初の奇数が配置されたら、芝刈り機がオンになっている間にできるだけ頻繁にそれらの値がアクセスされるようにすることで、残りのすべての値からの寄与を最大化します。 これにより、パリティ構造に基づいたソートと貪欲な蓄積が行われます。

 ## アルゴリズムのチュートリアル

 1. 配列を奇数値と偶数値に分割します。 偶数の値は芝刈り機の状態を変更しないため、それらの唯一の役割は芝刈り機がすでにオンになっている場合に寄与することです。 
2. すべての値を降順に並べ替えます。 これにより、芝刈り機がオンになっているときはいつでも、利用可能な最大の寄与を最初に優先的に取得することが保証されます。 偶数はパリティに影響しないため、それらの配置は自由にインターリーブできます。 
3. 奇数がいくつ存在するかを数えます。 これにより、完全な順序付けで状態反転が何回発生するかが決まります。 
4. 奇数がない場合は、芝刈り機がオンになることはないため、すぐに 0 を返します。 
5. それ以外の場合、重要な決定は最初のオッズがいつ現れるかを選択することです。 最大のオッズをできるだけ早く設定して、芝刈り機をできるだけ早くオンにし、後続の値からの最大の累積を可能にします。 
6. 最初の起動後、芝刈り機はオッズごとに状態を切り替えます。 並べ替えられた値を反復処理し、奇数に遭遇したときに状態を切り替えることで、これを貪欲にシミュレートします。 
7. 芝刈り機がオン状態のときは常に、現在の値を答えに加算します。 

### なぜ効果があるのか

 芝刈り機の状態を変更する唯一のメカニズムは、奇数の値に遭遇することです。各奇数の値は、位置に関係なく、正確に 1 つのトグルに寄与します。 これにより、任意の順列に対してトグルの数が固定され、順序のみが重要になります。 より大きな値を早めに設定し、最初の切り替えができるだけ早く行われるようにすることで、芝刈り機がオンになっている間に評価される高値セグメントの数を最大化します。 偶数は状態を保持し、トグルに干渉しないため、実現可能性を変えることなく、利用可能な最良のオンセグメントに吸収できる自由に移動可能なウェイトとして機能します。 これにより、貪欲にソートされたシーケンスでのパリティ遷移の制御に問題が軽減されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # sort descending so we always consider large values first
        a.sort(reverse=True)
        
        odd_count = sum(x % 2 for x in a)
        
        if odd_count == 0:
            print(0)
            continue
        
        on = False
        ans = 0
        
        for x in a:
            if x % 2 == 1:
                on = not on
            if on:
                ans += x
        
        print(ans)

if __name__ == "__main__":
    solve()
```このソリューションは、すべてのフィールドを降順で並べ替えることから始まり、芝刈り機がアクティブな場合は、より大きな貢献が最初に優先されるようにします。 次に、アクティベーションが不可能な縮退ケースを処理するために、奇数の要素をカウントします。 

メイン ループは、この貪欲な順序でフィールドにアクセスすることをシミュレートします。 奇数の値ごとに、寄与が考慮される前に芝刈り機の状態が反転され、問題のルールと正確に一致します。 反転後に芝刈り機がオンになっている場合、全値が追加されます。 

微妙な点は、ループ内の操作の順序です。問題では、刈り取る前に芝刈り機が切り替わることが示されているため、値を追加する前にパリティ チェックを行う必要があります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(sys.stdin.readline())
    out = []
    for _ in range(t):
        n = int(sys.stdin.readline())
        a = list(map(int, sys.stdin.readline().split()))
        a.sort(reverse=True)
        if all(x % 2 == 0 for x in a):
            out.append("0")
            continue
        on = False
        ans = 0
        for x in a:
            if x % 2 == 1:
                on = not on
            if on:
                ans += x
        out.append(str(ans))
    return "\n".join(out)

 ## 特殊なケース

 すべての値が偶数の場合、芝刈り機の状態が反転することはありません。 この実装は、奇数カウント 0 によってこれを早期に検出し、直接 0 を返し、アクティブ化されない状態からの不正な累積を回避します。 

奇数の値が 1 つだけある場合、並べ替えによってそれがより大きな値の中に配置されますが、その奇数の最初の出現によって状態が反転し、その後のすべては一貫性を保ちます。 トレースにより、アクティブ化が 1 つだけ発生し、その後のすべての寄与がその 1 つの遷移のみに依存することが保証されます。 

すべての値が奇数の場合、ステップごとに状態が反転します。 ソートされたトラバーサルは、最適な順序付けが交互のパリティに対するプレフィックスの合計を最大化することに相当する交互の寄与を生成し、シミュレーションは追加の構造を必要とせずにこの交互を正しくキャプチャします。
