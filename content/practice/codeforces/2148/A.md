 ## 解決策
 ## 問題の理解

 問題は数字を与えます`x`そして長さ`n`そして、交互にシーケンスを構築するように求めます。`x`そして`-x`から始まる`x`。 次に、そのシーケンス内のすべての要素の合計を計算するように求められます。 概念的には、これは記号を反転するようなものです。`x`各ステップで値を加算していきます。 

たとえば、次の場合`x = 2`そして`n = 5`、シーケンスは次のとおりです`2, -2, 2, -2, 2`。 Summing these gives`2`。 もし`n = 4`、シーケンス`2, -2, 2, -2`合計すると`0`。 

制約は非常に小さいです。両方とも`x`そして`n`テスト ケースは最大 10 個で、最大 100 個まで存在できます。 これは、シーケンスを明示的に構築する直接シミュレーションでも高速に実行されることを意味します。 ただし、シーケンスをまったく構築せずに問題を数学的に解決することもできます。これにより、解決策が簡素化され、オフバイワン エラーのリスクが軽減されます。 

次の場合、微妙なエッジケースが発生します。`n`奇数です。 シーケンスは次のように終了します。`x`、非ゼロ和が残ります。 もし`n`が偶数である場合、シーケンスには同じ数の`x`そして`-x`、合計はゼロになります。 常にペアを合計したり、最後の要素を無視したりする不注意な実装では、誤った結果が生成される可能性があります。 

## アプローチ

 ブルート フォースのアプローチは簡単です。テスト ケースごとに、シーケンスを明示的に構築し、すべての要素を合計します。 これが機能する理由は、`n`は最大でも 10 です。Python では、これには反復処理が含まれます。`n`を交互に追加していきます`x`そして`-x`現在の合計に。 最悪の場合の演算の合計数は、100 テスト ケース × シーケンスあたり 10 要素 = 1000 加算であり、無視できる程度です。 

最適なアプローチではパターンが観察されます。 連続するすべてのペア`(x, -x)`合計はゼロになります。 したがって、もし`n`が偶数の場合、合計は自動的にゼロになります。 もし`n`奇数であるため、合計は等しい`x`すべてのペアがキャンセルされ、追加の`x`最後に残ります。 この洞察により、問題は次のパリティの単純なチェックに帰着します。`n`そして可能性のある追加`x`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n × t) | O(n) | 小さな制約があるため受け入れられます |
 | 最適 | O(t) | お(1) | 受け入れられ、最もシンプルかつ安全 |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 これにより、処理する必要があるシーケンスの数が決まります。 
2. 各テスト ケースについて、次の内容を読んでください。`x`そして`n`。 
3. 次のことを確認します。`n`は均等です。 そうである場合、すべてのペアが存在するため、合計はゼロになります。`(x, -x)`お互いにキャンセルします。 
4. もし`n`は奇数、合計は次と等しい`x`すべてのペアがキャンセルされ、追加の`x`最後に合計に貢献します。 
5. 各テスト ケースの結果を出力します。 

機能する理由: このアルゴリズムは、要素の連続するすべてのペアが一致するという不変式に依存します。`(x, -x)`合計はゼロになります。 この方法で要素をペアにすることで、問題はペアになっていないかどうかを確認するだけになります。`x`残っている、まさにそのときに起こります。`n`奇数です。 シーケンス要素が二重にカウントされたり無視されたりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    x, n = map(int, input().split())
    if n % 2 == 0:
        print(0)
    else:
        print(x)
```最初の行はテスト ケースの数を読み取ります。 テストケースごとに、`x`そして`n`読まれます。 小切手`n % 2 == 0`シーケンスの長さが偶数か奇数かを決定します。 この条件は、アルゴリズムのウォークスルーで導出されたロジックを直接実装します。 パリティ プロパティを活用しているため、シーケンス要素にわたるループはありません。

これらのトレースは、パリティ ベースのアプローチが偶数と奇数の両方のシーケンス長を正しく処理していることを確認します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    
    t = int(input())
    for _ in range(t):
        x, n = map(int, input().split())
        print(0 if n % 2 == 0 else x)
    
    return out.getvalue().strip()

# Provided samples

# Custom cases

assert run("2\n10 2\n10 9\n") == "0\n10", "even and odd large x"
assert run("1\n5 5\n") == "5", "odd n simple"
assert run("1\n3 6\n") == "0", "even n simple"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 1、5 10、7 3 | 1、0、7 | 最小 n、最大 n、奇数 n の処理 |
 | 10 2、10 9 | 0、10 | 偶数 n の結果は 0、奇数 n の結果は x |

 ## 特殊なケース

 最小のシーケンスの場合`n = 1`、入力`x = 1`シーケンスを生成します`[1]`。 私たちのアルゴリズムはそれを認識します`n % 2 == 1`そして出力`1`、合計と一致します。 最大のシーケンスの場合`n = 10`、入力`x = 10`生成する`[10, -10, 10, -10, 10, -10, 10, -10, 10, -10]`。 私たちのアルゴリズムは次のように認識します`n % 2 == 0`そして出力`0`、それは正しいです。 これは、アルゴリズムがシーケンスを反復処理することなく両方の境界を処理することを示しています。
