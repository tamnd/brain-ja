 ## 問題の理解

 負でない整数のペアを何組数えるかを求められます$a$そして$b$、それぞれ未満$2^n$、正確に生産します$k$バイナリで合計したときの桁上げビット。 キャリーカウントは次のように表すことができます。$f(a,b) = g(a) + g(b) - g(a+b)$、 どこ$g(x)$のバイナリ表現内の 1 の数を数えます。$x$。 本質的に、希望するキャリー数が与えられた場合に、1 を数える問題を逆にするように求められます。$k$、2つの方法は何通りありますか$n$-ビット数値を組み合わせて正確なキャリーカウントを生成しますか?

 制約$0 \le k < n \le 10^6$あらゆる解が線形またはほぼ線形である必要があることを即座に示します。$n$。 考えられるすべてのペアを調べる単純なアプローチでは、次のことが必要になります。$O(4^n)$操作があるため、$2^n \times 2^n$ペア。 これは大きすぎます$n$最大 100 万件に達するため、組み合わせプログラミングまたは動的プログラミングのアプローチが必要です。 大きな$n$また、すべての合計を反復処理したり、サイズのテーブルを作成したりすることもできなくなります。$2^n$。 

微妙なエッジケースが発生する場合$k = 0$。 この場合、キャリー ビットをまったく生成しないペアが必要です。 累積キャリー伝播を考慮せずに、すべてのビット位置が独立してキャリーに寄与すると仮定する場合、単純なアルゴリズムはここで失敗する可能性があります。 同様に、$k = n-1$これは、最も重要なビットを除くすべてのビットで合計にキャリーを作成することを強制するため、極端です。これはまれであり、正確なカウントが必要です。

 ## アルゴリズムのチュートリアル

 1. 階乗および逆階乗モジュロを事前計算する$10^9+7$まで$n$。 これにより、二項係数の高速計算が可能になります。$\binom{n}{k}$誰にとっても$k\le n$。 モジュラー逆行列はフェルマーの小定理を使用して計算されます。$10^9+7$プライムです。 
2. 与えられたもののために$n$そして$k$、計算する$\binom{n}{k}$事前に計算された階乗を使用します。 これは何セットあるかを数えます。$k$間の位置$n$運ぶことができます。 
3. コンピューティング$2^{n-k} \mod 10^9+7$。 キャリーを生成しない各ポジションには 2 つの選択肢 (01 または 10) があり、その要因を説明します。$2^{n-k}$。 
4. 二項係数に次の値を掛けます。$2^{n-k}$モジュロ$10^9+7$最終的な答えを得るために。 これにより、順序付けされたペアの数が得られます。$(a,b)$正確に生産する$k$運ぶ。 

機能する理由: 各ビット位置のキャリーは、その位置のビットと受信キャリーのみに依存するため、アルゴリズムは機能します。 どのポジションがキャリーを生成し、どのポジションがキャリーを生成しないかをカウントすることにより、それぞれを個別に列挙することなく、すべての有効なペアを組み合わせて列挙することができます。 二項係数はキャリーのあるポジションを選択し、キャリーしないポジションでは 2 の累乗の組み合わせをカウントします。 モジュラー演算により、大きな数でも正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def precompute_factorials(n):
    fact = [1] * (n + 1)
    inv_fact = [1] * (n + 1)
    for i in range(2, n + 1):
        fact[i] = fact[i-1] * i % MOD
    inv_fact[n] = pow(fact[n], MOD-2, MOD)
    for i in range(n-1, 0, -1):
        inv_fact[i] = inv_fact[i+1] * (i+1) % MOD
    return fact, inv_fact

def binom(n, k, fact, inv_fact):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n-k] % MOD

def solve():
    n, k = map(int, input().split())
    fact, inv_fact = precompute_factorials(n)
    result = binom(n, k, fact, inv_fact) * pow(2, n-k, MOD) % MOD
    print(result)

solve()
```の`precompute_factorials`関数は階乗とモジュラー逆行列を最大で構築します。$n$を計算するために必要です$\binom{n}{k}$一定時間内に。 の`binom`関数は安全のために範囲外の値を処理します。 最終的な乗算$2^{n-k}$キャリーしないビット位置を考慮します。 オフバイワンエラーは、階乗を最大で含めることによって回避されます。$n$そして慎重にインデックスを作成します。 

## 実用的な例

 入力用`3 1`、計算します$\binom{3}{1} * 2^{3-1} = 3 * 4 = 12$。 出力は 12 で、正確に 1 つのキャリーを生成するすべての順序付けされたペアのサンプル数と一致します。 

入力用`4 2`、計算は$\binom{4}{2} * 2^{4-2} = 6 * 4 = 24$。 これは、キャリーを生成する 2 つの位置と、残りの各位置について、キャリーを生成しない 2 つの有効なビット構成を選択するすべての方法を説明します。 

| ステップ | n | k | binom(n,k) | 2^(n-k) | 結果 |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 3 | 1 | 3 | 4 | 12 |
 | 2 | 4 | 2 | 6 | 4 | 24 |

 これらのトレースは、二項係数と非キャリー ポジションの乗算係数が正しく計算されていることを確認します。
