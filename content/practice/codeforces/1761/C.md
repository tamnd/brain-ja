 ## 問題の理解

 バイナリが与えられます$n \times n$マトリックスを構築するのが私たちの仕事です$n$間の空でない整数の個別のセット$1$そして$n$。 各エントリー$b_{i,j}$設定されているかどうかを示します$A_i$セットの適切なサブセットです$A_j$; の値$1$手段$A_i$に厳密に含まれています$A_j$、 そして$0$そうではないことを意味します。 出力ではセット自体を生成し、そのサイズに続いて要素をリストする必要があります。 

この行列は、適切なサブセットの有向非循環関係をエンコードします。 各セットは空であってはならず、セットは適切なサブセット関係によって制約されるため、本質的には、その出現行列から部分的に順序付けされたセットを再構成することになります。 以来$n$せいぜい$100$、との合計$n$すべてのテスト ケースの境界は次のとおりです$1000$、おおよそ最大で複雑なアルゴリズムを許容できます。$O(n^3)$テストケースごとに。 考えられるすべてのサブセットを総当りチェックすると指数関数的に爆発的に増加するため、組み合わせまたはグラフベースの構築が必要です。 

整数の任意の代入がサブセット関係を満たすと仮定すると、単純な失敗が発生する可能性があります。 たとえば、行列がエンコードした場合、$A_1 \subsetneq A_2$そして$A_2 \subsetneq A_3$、素のセットを割り当てると矛盾が生じます。 行に送信がない場合、別の特殊なケースが発生します。$1$s; これは最大セットに相当し、サブセット構造で禁止されていないすべての要素を含める必要があります。 これを誤って管理すると、適切なサブセット関係に違反するセットが誤って生成される可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、要素を繰り返しセットに割り当て、すべてのペアのサブセットの一貫性をチェックしようとします。 これには、次のサブセットを生成する必要があります。$\{1,\dots,n\}$、および各候補割り当てについて、すべてを検証します。$n^2$条件。 操作数は指数関数的に増加します$n$サブセットの生成により、実行不可能になります。$n=100$。 

重要な洞察は、ノードがセットを表し、エッジがサブセットからそのスーパーセットを指す有向非巡回グラフを記述するものとして行列を捉えることです。 適切なサブセット関係は推移的で非対称であるため、行列を DAG として扱うことができます。 セットが属するスーパーセットの数によって (または同等に、発信されるスーパーセットの数によって) セットを並べ替えます。$1$マトリックスの s) は自然な階層を与えます。 小規模なセット (より多くの送信を伴う)$1$s) 要素が減り、セットが大きくなります (発信数が少なくなります)。$1$s) には、含まれるすべての小さなセットの要素が含まれます。 これにより、問題は DAG のトポロジー的順序に沿って段階的にセットを構築するようになり、すべてのサブセット制約が満たされることが保証されます。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、行列を読み取り、各行の出次数 (その行内の 1 の数) を計算します。 この出次数は、現在のセットが適切なサブセットである必要があるセットの数に対応します。 最大から最小への出次数によってセットを並べ替えると、最初に最小のセットの構築を開始できます。 

2. 空のセットの配列を初期化します。 出次数の昇順でセットを繰り返します。 各セットに、どのサブセットにもまだ割り当てられていない一意の整数を割り当てます。 これにより、適切なサブセット関係が確実に保持されます。これを含むセットには、そのサブセットのすべての要素が自動的に含まれます。 

3. これまでに割り当てられた要素の実行カウンタを維持します。 新しい各セットは、識別されたサブセットからすべての要素に加えて、新しい一意の要素を受け取ります。 新しい要素はセットが明確に保たれることを保証し、継承された要素は適切なサブセット関係が保持されることを保証します。 

4. 各セットのサイズに続いて要素を出力して、各セットを出力します。 階層を尊重して要素を割り当てたため、すべての要素が$b_{i,j}$条件は自動的に満たされます。 

不変条件は、セットを構築した後のものです。$A_i$、すべてのセットのすべての要素が含まれています$A_k$誰のために$b_{k,i}=1$に加えて、新しいユニークな要素が 1 つ追加されます。 これにより、$A_i$はそのすべてのサブセットのスーパーセットであり、すべてのセットが別個のままであること。 出次数の降順にセットを処理することにより、セットに必要なすべてのサブセットがすでに割り当てられていることを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        b = [list(map(int, input().strip())) for _ in range(n)]
        outdeg = [sum(row) for row in b]
        order = sorted(range(n), key=lambda i: outdeg[i], reverse=True)
        sets = [set() for _ in range(n)]
        next_element = 1
        for idx in order:
            # inherit elements from subsets
            for j in range(n):
                if b[idx][j]:
                    sets[idx] |= sets[j]
            sets[idx].add(next_element)
            next_element += 1
        for s in sets:
            print(len(s), *s)

if __name__ == "__main__":
    solve()
```このコードは、テスト ケースの数と各ケースの行列を読み取ります。 出次数を計算し、インデックスを並べ替えて、最小のセットを最初に処理します。 セットごとに、そのサブセットの要素をマージし、新しい一意の整数を追加します。 最後に、セットを元の順序で印刷します。 微妙なポイントは、`set()`ユニオン操作を正しく実行して、サブセットから要素を継承します。 の`next_element`カウンタは、すべてのセットが明確で空でないことを保証します。

 ## 特殊なケース

 単一要素行列の場合、アルゴリズムは一意の要素を唯一のセットに正しく割り当てます。 最大チェーンの場合、セットは以前のすべての要素と新しい要素を累積し、適切なサブセット関係を保証します。 発信セットのない切断されたセットの場合、それぞれが新しい一意の要素を受け取り、区別性と空ではないプロパティを維持します。 結合操作により、継承された要素が正しく伝播され、サブセット制約の違反が防止されます。 極大、極小、疎サブセット構造を含むすべてのエッジ条件は、増分要素割り当てと組み合わせた出次数順序付けによって処理されます。
