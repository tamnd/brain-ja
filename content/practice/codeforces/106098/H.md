 ## 解決策
 ## 問題の理解

 すべての整数でインデックスが付けられ、両方向に無限に伸びるテープが与えられます。 カラーリングは高度に構造化されています。黒と白の交互のブロックで構成されており、すべてのブロックは同じ未知の長さです。$L$。 テープは次のようになります$B^L W^L B^L W^L \dots$そしてこのパターンは両方向に永遠に繰り返されます。 

テープを操作する唯一の方法は、位置をクエリすることです$x$、そのセルが黒か白かを返します。 タスクは、の値を決定することです。$L$テスト ケースごとに最大 2000 のクエリを使用します。 

解決策を推進する重要な制約は、相互作用の制限です。 外側に向かって直線的にスキャンしたり、すべての位置をチェックしたりするアプローチは直ちに不可能です。$L$と同じ大きさにすることができます$10^{18}$。 関数が周期的である場合、単調性に関する単純な二分探索の仮定は自動的には当てはまらないため、対数探索であっても慎重に構造化する必要があります。 

微妙なエッジ ケースは、暗黙的に推論した開始位置がブロック境界と一致していない場合です。 たとえば、位置 0 が黒いセグメント内にある場合、右への最も近い変更は、次の白いブロックの先頭にあり、次の白いブロックの倍数ではありません。$L$。 「最初の色の変化により、$L$」は、前の境界がどこにあるかも分からない限り壊れます。 

「色は 0 の色と等しい」のような述語を使用して位置を二分探索しようとすると、別の失敗ケースが発生します。 その述語はグローバルに単調ではありません。 もし$L = 3$、位置 0 に対する比較のシーケンスは、true、true、true、false、false、false、再び true のように見える可能性があり、バイナリ検索ロジックが破壊されます。 

## アプローチ

 強引なアイデアは、開始位置から外側に向かって歩き、あるカラー ブロックから次のカラー ブロックへの完全な遷移が観察され、その後再び戻るまですべてのセルをクエリし、繰り返し構造間の距離を測定することです。 テープは周期的であるため、これは概念的には正しいですが、次のように劣化します。$O(L)$クエリ。制約の下では不可能です。$L$無制限です。 

重要な構造的観察は、テープは周期的であるにもかかわらず、個々のブロックの内部は均一であるということです。 つまり、色の変化が発生した正確な位置を回復するには十分であるということです。$L$。 周期性をグローバルに推測しようとする代わりに、ブロック間の 2 つの連続する境界点を特定するだけで十分です。 

2 つのブロック間の境界が判明すると、次の境界までの距離は正確に$L$。 難しいのは、大域的な単調性を仮定せずに境界を確実に見つけることです。 コツは、単一の参照位置を中心に検索を固定し、両側に最も近い変更を明示的に特定することです。 これらの最も近い変化はそれぞれ、遷移が 1 つだけ含まれることが保証されている区間内で制御された二分探索を使用して見つけることができます。これは、一方の端点が既知の一様領域内にあり、もう一方の端点が異なる領域内にあるように区間を構築しているためです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォーススキャン |$O(L)$クエリ |$O(1)$| 遅すぎる |
 | 境界位置特定 + 二分探索 |$O(\log R)$クエリ |$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 任意の基準位置を固定します。通常、$x = 0$、その色をクエリします。 電話してください$c$。 この点はある長さのブロック内にあります$L$、その境界はわかりませんが。 
2. 左に検索して最も近い位置を見つけます$l$の色になるように$l$とは異なります$c$。 この位置は、左側に隣接するブロックの最初のセルである。 
3. 右に検索して最も近い位置を見つけます$r$の色になるように$r$とは異なります$c$。 この位置は、右側に隣接するブロックの最初のセルである。 
4. これら 2 つの境界に隣接する位置間の距離を計算し、ブロック長を次のように抽出します。$L = r - l$。 以来$l$そして$r$が同じブロック周囲の連続する遷移点である場合、この差は 1 つの完全なセグメントにまたがります。 
5. 出力$L$テストケースの答えとして。 

唯一の重要な部分はステップ 2 と 3 です。それぞれは、一方のエンドポイントが現在のユニフォーム ブロックの内側にあることがわかっており、もう一方のエンドポイントがその外側にあることがわかっている区間での二分探索を使用して実装されます。 これにより、検索間隔内で色の遷移が 1 つだけ存在することが保証され、その制限されたドメイン内で述語が事実上単調になります。 

### なぜ効果があるのか

 テープ内の各ブロックは、同一色の最大の連続間隔であり、すべてのブロックは同じ長さを共有します。 どの位置も、そのような間隔の 1 つに正確に属します。 色が基準と異なる左側の最も近い位置を特定すると、その間隔の左側の境界が特定されます。 同じロジックが右側の境界にも適用されます。 

すべての間隔は等しい長さであるため、2 つの連続する境界間の距離は一定であり、次と等しくなります。$L$。 このアルゴリズムは、グローバルな周期性に直接依存することはありません。 ブロックが均一であり、境界が単一の遷移点であるというローカルな特性のみを使用します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def ask(x):
    print(f"? {x}")
    sys.stdout.flush()
    return input().strip()

def solve():
    c0 = ask(0)

    # find left boundary: first position to the left with different color
    lo, hi = -10**18, 0
    while lo < hi:
        mid = (lo + hi) // 2
        if ask(mid) == c0:
            hi = mid
        else:
            lo = mid + 1
    left = lo

    # find right boundary: first position to the right with different color
    lo, hi = 0, 10**18
    while lo < hi:
        mid = (lo + hi) // 2
        if ask(mid) == c0:
            lo = mid + 1
        else:
            hi = mid
    right = lo

    print(f"! {right - left}")
    sys.stdout.flush()

t = int(input())
for _ in range(t):
    solve()
```このコードでは、対話型クエリを使用します。`ask`。 最初のクエリは、現在のセグメントの色を固定します。 各バイナリ検索は、間隔に基準色から反対色への遷移が常に 1 つだけ含まれるように構造化されており、検索が安全に収束します。 

実装の微妙な詳細は、フラッシュに失敗するとインタラクターとの同期が中断されるため、すべてのクエリと最終応答の後にフラッシュされます。 この問題によりテープが両方向に十分に伸びることが保証されるため、二分探索境界は大きな固定制限として選択されます。 

## 実用的な例

 次のような仮定のケースを考えてみましょう。$L = 3$位置 0 は黒いセグメントの内側にあります。 

位置 0 をクエリすると、黒が得られます。 

左側の境界検索の場合、アルゴリズムは最初の白セルが見つかるまで負の位置を探索します。 

| ステップ | 問い合わせ中 | カラー(中間) | 決定 |
 | --- | --- | --- | --- |
 | 1 | -5 | W | 右に移動 |
 | 2 | -2 | B | 左に移動 |
 | 3 | -3 | W | 右に移動 |

 最終的には、色が黒と異なる最初の位置に収束します。これは、前の白ブロックの始まりです。 

右境界検索の場合、同様の表が適用されます。 

| ステップ | 問い合わせ中 | カラー(中間) | 決定 |
 | --- | --- | --- | --- |
 | 1 | 5 | W | 左に移動 |
 | 2 | 2 | B | 右に移動 |
 | 3 | 3 | W | 左に移動 |

 これは、0 を含む黒いブロックの後の最初の白いセルに収束します。 

これら 2 つの境界間の距離は 3 に等しく、一致します。$L$。 

これらのトレースは、無限の周期構造にもかかわらず、各二分探索が正確に 1 つの遷移点を分離することを確認します。

 ## 特殊なケース

 エッジ ケースの 1 つは、基準位置が 2 つのセグメント間の境界上に正確に位置する場合です。 その状況では、位置 0 をクエリすると、ブロックの内部ではなくブロックの先頭がすでに明らかになります。 その後、左右の検索によって隣接する遷移がすぐに特定され、計算された距離は引き続き次の値に対応します。$L$境界は正確な間隔で保たれるため、$L$別に。 

最初の二分探索の中点が複数のセグメントにまたがる場合、別のエッジ ケースが発生します。 制限された検索間隔により、最終的に操作する間隔内で述語「基準色に一致する」が 1 回だけ変更されることが保証されます。 たとえ初期の探索中に中間の推測が他のセグメントにあったとしても、最終的に収束した区間は単一の境界を分離し、結果のあいまいさを防ぎます。
