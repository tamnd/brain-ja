 ## 解決策
 ## 問題の理解

 接続された無向グラフが与えられます。 頂点は一様にランダムに選択されます。 次に、その入射エッジの 1 つが均一にランダムに選択され、グラフから削除されます。 

その削除後、選択した同じ頂点から開始して、まだ訪問できる個別の頂点の数を尋ねます。 グラフは無向であるため、これは単に、エッジ除去後の選択された頂点を含む連結コンポーネントのサイズになります。 

タスクは、そのコンポーネント サイズの期待値を計算することです。 

グラフには最大で次のものを含めることができます$2 \cdot 10^5$すべてのテスト ケースにわたる頂点とエッジ。 削除される可能性があるたびに接続を再計算するソリューションは、まったく実行不可能です。 エッジごとに 1 つの DFS であっても、すでに$O(m(n+m))$、それは限界をはるかに超えています。 

グラフは最初は接続されています。 これは、ほとんどのエッジ削除では何も起こらないことをすぐに示唆しています。 非ブリッジを削除するとグラフの接続が維持されるため、答えは残ります。$n$。 到達可能なコンポーネントのサイズを縮小できるのはブリッジのみです。 

よくある間違いは、ブリッジを削除した後にグラフ内のすべての頂点について考えることです。 実験では、最初に終点頂点を選択し、次にその入射エッジの 1 つを選択します。 確率分布は頂点の次数に依存するため、各ブリッジは 2 つの端点の次数に応じて異なる寄与をします。 

3 つの頂点からなるパスを考えてみましょう。```
1 - 2 - 3
```頂点 1 から開始して、その唯一の入射エッジが削除され、頂点 1 が分離されたままになります。 到達可能なサイズは 1 です。 

頂点 2 から始めて、どちらのエッジも削除できます。 どちらの場合も、頂点 2 は他の 1 つの頂点に接続されたままになるため、到達可能なサイズは 2 になります。 

期待値は次のとおりです。$$\frac{1+2+1}{3}=\frac43$$エンドポイントの次数を考慮せずにブリッジのみをカウントするソリューションでは、誤った結果が生成されます。 

もう 1 つの微妙なケースは、ブリッジのないグラフ、たとえばサイクルです。```
1 - 2
|   |
4 - 3
```単一のエッジを削除するとグラフは接続されたままになるため、答えは常に次のようになります。$n$。 すべてのエッジから何かを減算しようとするアルゴリズムはここで失敗します。 

## アプローチ

 強引な解釈は文字通り実験に従います。 

頂点ごとに$v$、すべてのインシデント エッジを反復処理します。$e$。 取り除く$e$から DFS または BFS を実行します。$v$、到達可能なコンポーネントのサイズを測定し、結果を平均します。 

これはランダム プロセスを直接シミュレートするため、これは正しいです。 問題はそのコストです。 グラフには次のものが含まれる場合があります$2 \cdot 10^5$エッジ。 考えられるすべての選択肢に対してグラフの走査を実行すると、おおよその結果が得られます。$O(m(n+m))$これは、最悪の場合、何十億もの操作に及ぶことになります。 

重要な点は、ブリッジ以外を削除しても何も変わらないということです。 グラフは接続され始めているため、非ブリッジを削除しても接続されたままになるため、すべての頂点はすべての頂点に到達できます。$n$頂点。 

つまり、重要なのは橋だけです。 

ブリッジが親頂点を接続すると仮定します。$p$そして子頂点$c$DFS ツリー内。 サブツリーのルートを次のようにします$c$含む$sz$頂点。 

このブリッジを削除すると、グラフが 2 つのコンポーネントに分割されます。$$sz$$そして$$n-sz$$選択した頂点が$p$、ブリッジを削除した後、サイズのコンポーネントに残ります。$n-sz$、まさに負ける$sz$頂点。 

選択した頂点が$c$、サイズのコンポーネントに残ります$sz$、まさに負ける$n-sz$頂点。 

実験では選択した頂点に付随するエッジのみが削除されるため、他の頂点はこのエッジを選択できません。 

これにより、問題はすべてのブリッジからの独立した寄与の合計に変換されます。 単一の DFS ですべてのブリッジとすべてのサブツリー サイズを識別できます。$O(n+m)$解決。

 ## アルゴリズムのチュートリアル

 1. グラフを読み取り、すべての頂点の次数を計算します。 
2. Tarjan のブリッジ検出 DFS を実行します。 
3. DFS 中に、検出時間と低リンク値を維持します。 
4. DFS ツリーの頂点ごとに、そのサブツリーのサイズを計算します。`sz`。 
5. 木の端を探索するとき`(u, v)`から戻った後、`v`、次のことを確認します。$$low[v] > tin[u]$$この条件が当てはまると、`(u,v)`橋です。 

1. しましょう`sz[v]`子サブツリーのサイズになります。 このブリッジを削除すると、グラフが次のサイズのコンポーネントに分割されます。$$sz[v]$$そして$$n - sz[v]$$1. この橋による損失の合計は次のとおりです。$$\frac{sz[v]}{\deg(u)}
+
\frac{n-sz[v]}{\deg(v)}$$最初の項は頂点の選択に対応します`u`、頂点の選択の 2 番目`v`。 

1. すべてのブリッジにわたるこれらの損失を合計します。 
2. 総損失を次のようにします。`S`。 

予想される到達可能なサイズは次のとおりです。$$n - \frac{S}{n}$$1. すべての算術モジュロを実行します。$10^9+7$。 すべての除算を乗算による逆モジュラに置き換えます。 

### なぜ効果があるのか

 実験で考えられるすべての結果は、接続されたグラフから始まり、選択した頂点に属するエッジを 1 つだけ削除します。 

削除されたエッジがブリッジではない場合、グラフは接続されたままとなるため、到達可能なサイズは同じままになります。$n$。 このようなエッジは損失をゼロにします。 

ブリッジの場合、それを削除すると、グラフが正確に 2 つのコンポーネントに分割されます。 選択したエンドポイントは一方の側に残り、もう一方の側のすべての頂点にアクセスできなくなります。 失われた頂点の数は、反対側のコンポーネントのサイズと正確に一致します。 

各ブリッジは、その 2 つのエンドポイントのみが選択できるため、独立して貢献します。 すべての橋の損失を合計すると、予想される合計の損失が得られます。$n$。 その削減をから引くと、$n$予想される到達可能なコンポーネントのサイズが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000000007

MAXN = 200000 + 5
inv = [0] * MAXN
for i in range(1, MAXN):
    inv[i] = pow(i, MOD - 2, MOD)

t = int(input())

for _ in range(t):
    n, m = map(int, input().split())

    adj = [[] for _ in range(n)]
    deg = [0] * n

    for eid in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1

        adj[u].append((v, eid))
        adj[v].append((u, eid))

        deg[u] += 1
        deg[v] += 1

    tin = [0] * n
    low = [0] * n
    sz = [0] * n

    timer = 0
    loss = 0

    sys.setrecursionlimit(1 << 20)

    def dfs(u, pe):
        nonlocal timer, loss

        timer += 1
        tin[u] = low[u] = timer
        sz[u] = 1

        for v, eid in adj[u]:
            if eid == pe:
                continue

            if tin[v]:
                low[u] = min(low[u], tin[v])
            else:
                dfs(v, eid)

                sz[u] += sz[v]
                low[u] = min(low[u], low[v])

                if low[v] > tin[u]:
                    s = sz[v]

                    loss_term = (
                        s * inv[deg[u]]
                        + (n - s) * inv[deg[v]]
                    ) % MOD

                    loss += loss_term
                    loss %= MOD

    dfs(0, -1)

    ans = (n % MOD - loss * inv[n]) % MOD
    print(ans)
```グラフはエッジ識別子とともに保存されるため、DFS は親につながるツリー エッジを他のエッジから区別できます。 

配列`tin`そして`low`標準的なタルジャン橋構造です。 条件`low[v] > tin[u]`まさに橋を識別する基準です。 

サブツリーのサイズ`sz[v]`は、DFS リターン フェーズ中に計算されます。 橋が見つかったら、`sz[v]`すぐに分割の一方の側を与え、`n - sz[v]`もう一方を与えます。 

蓄積された数量は、`loss`期待される損失そのものではありません。 これは、最終的に除算する前のすべての橋の損失の合計です。`n`、式と一致します$$n - \frac{S}{n}.$$すべての除算は逆モジュラーに置き換えられます。 すべての次数は、接続されたグラフ内に少なくとも 1 つあるため、$n \ge 2$、これらの逆行列は常にモジュロとして存在します。$10^9+7$。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    MOD = 1000000007

    data = io.StringIO(inp)
    input = data.readline

    MAXN = 200005
    inv = [0] * MAXN
    for i in range(1, MAXN):
        inv[i] = pow(i, MOD - 2, MOD)

    t = int(input())
    out = []

    sys.setrecursionlimit(1 << 20)

    for _ in range(t):
        n, m = map(int, input().split())

        adj = [[] for _ in range(n)]
        deg = [0] * n

        for eid in range(m):
            u, v = map(int, input().split())
            u -= 1
            v -= 1

            adj[u].append((v, eid))
            adj[v].append((u, eid))

            deg[u] += 1
            deg[v] += 1

        tin = [0] * n
        low = [0] * n
        sz = [0] * n

        timer = 0
        loss = 0

        def dfs(u, pe):
            nonlocal timer, loss

            timer += 1
            tin[u] = low[u] = timer
            sz[u] = 1

            for v, eid in adj[u]:
                if eid == pe:
                    continue

                if tin[v]:
                    low[u] = min(low[u], tin[v])
                else:
                    dfs(v, eid)

                    sz[u] += sz[v]
                    low[u] = min(low[u], low[v])

                    if low[v] > tin[u]:
                        s = sz[v]
                        loss = (
                            loss
                            + s * inv[deg[u]]
                            + (n - s) * inv[deg[v]]
                        ) % MOD

        dfs(0, -1)

        ans = (n % MOD - loss * inv[n]) % MOD
        out.append(str(ans))

    return "\n".join(out)
