 ## 解決策

 ## 問題の理解

 このタスクでは、辺の長さが整数の長方形の寮の部屋について説明します。 まず部屋の寸法を測ります$a \times b$。 負でない整数を追加することで、どちらかの辺を独立して拡大することができます。 拡張後の部屋はこうなります$a_1 \times b_1$と$a_1 \ge a$そして$b_1 \ge b$。 

正確に配置する必要があります$n$各学生には少なくとも 6 平方メートルのスペースが必要という厳しい規則があります。 これは、最終領域である製品に対する制約に変換されます。$a_1 \cdot b_1$少なくとも$6n$。 すべての有効な拡大長方形の中で、可能な限り面積が小さいものが必要です。 

重要な構造は、任意の実次元を選択していないということです。 私たちは整数にこだわっており、初期の次元から上に進むことしかできません。 この制限により、第 1 象限の整数格子点に対する制約付き最小化問題が作成され、そこで支配的な最小の実現可能な長方形が検索されます。$(a,b)$。 

制約は次のとおりです$10^9$したがって、ディメンションの候補となるすべてのペアを探索しようとする解決策は直ちに不可能になります。 可能なすべての幅または高さを線形に反復しても、妥当な制限時間を超えてしまいます。 唯一実現可能なアプローチは、検索スペースを約$\sqrt{6n}$、これはせいぜい約$10^5$。 

初期寸法の 1 つがすでに大きい場合、微妙なエッジ ケースが発生します。 仮定する$a$よりもはるかに大きいです$\sqrt{6n}$。 単純な「平方根を中心に検索する」アプローチでは、次から始める必要があることを見逃してしまう可能性があります。$a$もう 1 つのエッジ ケースは、一方の側が非常に小さく、もう一方の次元を最小限に固定したまま一方の次元のみを大幅に増加させることで最適な構成が得られる場合です。 たとえば、次の場合$b$すでに大きい場合、最適な解決策は次のとおりです。$a_1 = \lceil 6n / b \rceil$、これは単純な有界ループのはるか外側にある可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのペアを試します$(a_1, b_1)$そのような$a_1 \ge a$、$b_1 \ge b$、 そして$a_1 b_1 \ge 6n$、次に最小面積を選択します。 これは正しいですが、すぐには使用できなくなります。 制限さえする$a_1, b_1 \le 10^9$まで残ります$10^{18}$最悪の場合は可能ですが、それは完全に不可能です。 

重要な観察は、最適解では、次元の 1 つが必要な面積の平方根に近いということです。 させて$S = 6n$。 下限を無視すると$a$そして$b$、制約の下で整数辺を持つ領域を最小化する最適な長方形$xy \ge S$発生するとき$x$近いです$\sqrt{S}$そして$y$に近いです$S/x$。 これは継続的なリラクゼーションから来ます。$xy = S$は等しくなると自明に最小化され、対称性は両側のバランスを示唆します。 

下限あり$a$そして$b$, 実現可能な領域を限定しているだけです。 最適解は平方根領域の近くに位置するか、制約の 1 つによって強制される必要があります。$x \ge a$または$y \ge b$。 つまり、次の場合にのみ候補者をテストする必要があります。 

1.$x$周りにいる$\sqrt{S}$、または
 2.$y$まさに最小値です$b$、強制的に$x = \lceil S / b \rceil$、または
 3.$x$まさに最小値です$a$、強制的に$y = \lceil S / a \rceil$。 

これにより、問題は 2 次元の検索から 1 次元の候補の小さなセットに軽減されます。

 ## アルゴリズムのチュートリアル

 しましょう$S = 6n$。 

1. コンピューティング$S = 6n$。 これは、カバーする必要がある最小限の領域です。 
2. 幅を調べることから始めます$x$元の制約から始める$a$周囲の小さな領域まで$\sqrt{S}$。 その理由は、次の場合です。$x$はるかに超えています$\sqrt{S}$、対応する高さは小さくなり、通常、積は再び増加します。 
3. 候補幅ごとに$x$、最小有効高さを計算します。$y = \max(b, \lceil S / x \rceil)$。 これにより、学生の要件と元の部屋の制約の両方が確実に満たされます。 
4. 面積を計算する$x \cdot y$すべての候補者の最小値を追跡します。 
5. 高さが元の最小値に固定されている場合を独立して検討する$b$。 この場合、幅は次のようにする必要があります。$x = \max(a, \lceil S / b \rceil)$。 これにより、最適な構成が平方根検索ウィンドウの外側にあるソリューションが捕捉されます。 
6. 同様に、幅が に固定されている対称の場合を考えてみましょう。$a$、高さは$y = \max(b, \lceil S / a \rceil)$。 
7. 計算されたすべての候補のうち、面積が最小のものを出力します。 

これが機能する理由: 実行可能領域は両方の次元で単調であり、積制約により最適解が「バランスの取れた」点付近に強制されます。$x \approx y \approx \sqrt{S}$、または 1 つの次元がその最小許容値に固定されている境界上で。 最適な解決策は、これらの構造形式のいずれかに基づいている必要があります。 そうしないと、バランスに向けて 1 つの次元をわずかにシフトすると、実現可能性を維持しながら面積が減少し、最適性と矛盾します。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def solve():
    n, a, b = map(int, input().split())
    S = 6 * n

    best = float('inf')
    best_a = best_b = 0

    def relax(x, y):
        nonlocal best, best_a, best_b
        if x < a or y < b:
            return
        area = x * y
        if area < best:
            best = area
            best_a = x
            best_b = y

    limit = int(math.isqrt(S)) + 5

    x = a
    while x <= limit:
        y = (S + x - 1) // x
        relax(x, y)
        x += 1

    y = b
    while y <= limit:
        x = (S + y - 1) // y
        relax(x, y)
        y += 1

    x = max(a, (S + b - 1) // b)
    relax(x, b)

    y = max(b, (S + a - 1) // a)
    relax(a, y)

    print(best)
    print(best_a, best_b)

if __name__ == "__main__":
    solve()
```機能`relax`実現可能性のチェックを一元化し、現在の最良の回答を維持します。 これにより、候補生成戦略間でロジックが重複することが回避され、次のような制約を見逃すリスクが軽減されます。$a_1 \ge a$または$b_1 \ge b$。 

平方根領域の周りの 2 つの短いループは、バランスのとれた解を捕捉します。 2 つの境界チェックは、最適値が強制的に無視されるケースを明示的に処理します。$a$または$b$これは、単純な平方根のみの実装の主な障害点です。 

よくある落とし穴は、上限を計算した後に下限を適用するのを忘れることです。 たとえ$\lceil S/x \rceil$小さい場合でも、実際の高さを考慮する必要があります$b$そうでない場合、ソリューションは元の部屋の制約に違反します。

import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    n, a, b = map(int, input().split())
    S = 6 * n

    best = float('inf')
    best_a = best_b = 0

    def relax(x, y):
        nonlocal best, best_a, best_b
        if x < a or y < b:
            return
        area = x * y
        if area < best:
            best = area
            best_a = x
            best_b = y

    limit = int(math.isqrt(S)) + 5

    x = a
    while x <= limit:
        y = (S + x - 1) // x
        relax(x, y)
        x += 1

    y = b
    while y <= limit:
        x = (S + y - 1) // y
        relax(x, y)
        y += 1

    relax(max(a, (S + b - 1) // b), b)
    relax(a, max(b, (S + a - 1) // a))

 ## 特殊なケース

 重要なエッジ ケースは、1 つの次元が最適な平方根領域と比較してすでに非常に大きい場合に発生します。 たとえば、次の場合$a = 10^9$そして$n$が小さい場合、平方根ループはそれに近い値を考慮することさえありません。$a$。 アルゴリズムは構成を明示的に評価するため、これを処理します。$x = a$そして対応するものを計算します$y = \lceil S/a \rceil$、境界支配の最適化が見逃されないようにします。 

両方のディメンションが有効な構成のすぐ下にある場合、別のエッジ ケースが発生します。 仮定する$a = b = 2$そして$n = 1$。 必要な面積は 6 で、自然にバランスのとれたペアは (2, 3) になります。 このアルゴリズムは、平方根近傍と境界の両方のケースを評価し、(2, 3) が見逃される可能性のある段階的な増分に依存するのではなく、確実に直接検出されるようにします。 

3 番目のケースは、丸め効果が優勢な場合です。 以来$y = \lceil S/x \rceil$、小さな変化$x$飛び込みの原因となる可能性があります$y$ただし、単調な構造により、局所的な改善が失われた場合でも、検索ウィンドウ内の近くの候補または境界評価の 1 つによって補われることが保証されます。
