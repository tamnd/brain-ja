 ## 解決策
 ## 問題の理解

 で作られた垂直ジェンガタワーが与えられました。$N$水平レイヤー。各レイヤーには 3 つの可能なブロック位置があります。 各位置は存在するか欠落しています。 移動は既存の 1 つのブロックを削除することで構成されますが、これは削除後もタワーが厳密な安定条件を満たしている場合に限ります。 

安定性はレイヤーごとにローカルであり、グローバルな制限が 1 つあります。 すべてのレイヤーには少なくとも 1 つのブロックが含まれている必要があります。 レイヤーにブロックが 1 つだけ含まれている場合、そのブロックは中央の位置でなければなりません。 さらに、最上層は、3 つのブロックすべてが存在する状態で完全に無傷のままであることが常に要求されます。これは、事実上、最上層からブロックを削除する移動が許可されていないことを意味します。 

2人のプレイヤーが交互に手を動かし、動けなかったプレイヤーが負けとなります。 最適なプレーで勝者を決めることが求められます。 

入力サイズが大きく、最大$4 \cdot 10^5$すべてのテスト ケースにわたる合計レイヤー。 これにより、ゲーム ツリーのシミュレーションや繰り返しの状態探索が即座に排除されます。 どのようなソリューションでも、ゲームをテスト ケースごとに線形なものに削減する必要があります。 

微妙な点は、タワーは垂直であるにもかかわらず、合法性の制約がほぼ完全にレイヤーごとであることです。 層間の唯一の結合は、固定された最上位層の制約であり、これに関係する相互作用はブロックされます。 他のものはすべて、削除操作の下で進化する独立したローカル構成のように動作します。 

よくある失敗例は、あるレイヤーのブロックを削除すると他のレイヤーに構造的に影響を与えると想定することに起因します。 たとえば、下位層からブロックを削除すると上位層が無効になる可能性があると考えることは、所定のルールの下では正しくありません。 

もう 1 つの注意が必要な状況は、単一ブロック レイヤーの処理です。 のような構成`010`は有効ですが、そこから中央のブロックを削除しようとすると無効な空のレイヤーが生成されるため、安定していてもゲームの意味では末期です。 

## アプローチ

 直接的な総当たりアプローチでは、有効な各タワー構成をゲーム状態として扱い、可能なすべてのブロック除去を調査します。 各州は最大で分岐します。$3N$各層は時間の経過とともに独立して変化する可能性があるため、状態の数は指数関数的に増加します。 中程度の場合でも$N$、これは完全に不可能になります。 

重要な観察は、レイヤーは移動の正当性を介する場合を除いて相互作用せず、各レイヤーは独自の 3 つのセルのみに基づいて独立して進化するということです。 レイヤーを修正したら、問題はそのレイヤーの安定性を損なわずにどの削除が許可されるかだけです。 これにより、問題は、レイヤーごとに 1 つずつ、最上位レイヤーは何も貢献しない、独立した公平なゲームの合計に変わります。 

したがって、ゲームは、非最上位層の可能な 3 ビット構成ごとに Grundy 値を計算することになります。 各層は 3 つのセルのみなので、すべての状態と遷移を明示的に列挙できます。 これらの値が判明すると、タワー全体はすべてのレイヤー値の単なる XOR になります。 

最上層は特別であり、その層では一切の移動が許可されないため、寄与は常にゼロになります。

 ## アルゴリズムのチュートリアル

 各レイヤーを独立して扱い、ゲーム価値への寄与を計算します。 

### 1. 最上層を修正します

 最上層は完全に元の状態を維持するという要件に違反するため、削除すると永久に再生できなくなります。 したがって、ゲーム分析ではそれを完全に無視します。 

これにより、問題が即座に階層化されます。$2$を通して$N$。 

### 2. 単一レイヤーを小さなゲームとしてモデル化する

 各レイヤーは 3 桁のバイナリ文字列です。 単一のブロックが中央になければならないというルールの下で、結果の構成が有効なままであれば、移動によって既存のブロックが 1 つ削除されます。 

これにより、有効な構成のみに関する小さな状態グラフが得られます。 

### 3. 有効な状態を列挙する

 有効な構成は、無効な単一ブロック状態が決して含まれない構成だけです。 したがって、次のような構成`100`または`001`は禁止されていますが、`010`、`110`、`101`、`011`、 そして`111`許可されています。 

次に、これらの状態間の移動遷移を計算します。 

### 4. ターミナルと遷移構造を計算する

 この構造から:

 州`010`唯一のブロックを削除すると空のレイヤーが作成され、これは禁止されているため、有効な移動はありません。 ということでターミナルです。 

州`101`削除すると無効な単一ブロック構成になるため、有効な移動もありません。 

州`110`有効な手は 1 つだけです。左のブロックを削除すると、`010`。 

州`011`有効な手は 1 つだけです。正しいブロックを削除すると、`010`。 

州`111`に移動できます`110`、`101`、 または`011`。 

### 5. グランディ値を計算する

 ターミナル状態から上へ:

 ターミナルの状態`010`そして`101`グランディ値は 0 です。 

それから`110`そして`011`それぞれは 0 状態にのみ移動するため、グランディは 1 になります。 

のために`111`、到達可能な値は次のとおりです。$\{1, 0, 1\}$, したがって、メキシコは 2 です。 

したがって、各層は次のことに貢献します。`010 → 0`、`101 → 0`、`110 → 1`、`011 → 1`、`111 → 2`。 

### 6. XOR を使用してレイヤーを結合する

 レイヤーは独立したゲームであるため、完全なゲーム値は、最上位レイヤーを除くすべてのレイヤーの Grundy 値の XOR になります。 

この XOR がゼロ以外の場合、プレイヤー 1 が勝ちます。 

### なぜ効果があるのか

 各レイヤーは独立した公平なゲームを形成し、その動きが他のレイヤーに影響を与えることはありません。 グローバル ゲームはこれらのゲームの互いに素な合計であるため、スプレイグ グランディ理論が直接適用されます。 安定性の制約により、隠れた層間の依存関係が存在しないことが保証され、最上位層の制限により潜在的な結合のみが除去されます。 各層の状態空間は一定のサイズであるため、その Grundy 値は固定され、他の層から独立しており、XOR 集約が有効になります。

input = sys.stdin.readline

def layer_value(s):
    # s is a string of length 3
    # compute its contribution directly
    if s == "111":
        return 2
    if s == "110" or s == "011":
        return 1
    return 0

def solve():
    T = int(input())
    for _ in range(T):
        N = int(input().strip())
        x = input().strip()
        
        total = 0
        
        # skip top layer (index 0)
        for i in range(1, N):

        print("Yesyes" if total != 0 else "Nono")

if __name__ == "__main__":
    solve()
```このソリューションは各レイヤーを読み取り、最初のレイヤーをスキップします。これは、レイヤーが固定されており変更できないためです。 残りの各レイヤーについて、構成から値への事前導出マッピングを使用してグランディ寄与を計算します。 最終的な答えは、すべての寄与を XOR することによって決定されます。 

微妙な実装の詳細は、次のことを扱ってはいけないということです。`101`または`010`論理における特殊なケースとして。 これらは終端であるため、または XOR 合計に影響を与えることができないため、両方ともゼロに正しくマップされます。

 ### 例 1

```寄与度を計算します。 

| レイヤー | 状態 | 値 |
 | --- | --- | --- |

 さて、XOR は$1 \oplus 1 = 0$。 

したがって、2番目のプレイヤーが勝ちます。 

これは、XOR 集計の重要な特性である対称非ゼロ寄与がどのように相殺されるかを示しています。

 ## 特殊なケース

 主なエッジケースは、最上部を除くすべてのレイヤーが`101`。 これらの各層は個別に終端であるため、寄与はゼロです。 アルゴリズムは XOR = 0 を正しく生成し、2 番目のプレーヤーの勝者を宣言します。 完全ではないすべてのレイヤーが何らかの貢献をしていると仮定する間違った解決策は、ここで失敗します。 

もう 1 つのケースは、完全に次のもので構成されるタワーです。`110`上部の下のレイヤー。 それぞれが 1 を寄与するため、結果はパリティのみに依存します。 アルゴリズムは、XOR 累算を通じてこれを自然に処理します。 

ついにみんなの塔が完成`111`レイヤーは値 2 の蓄積を示します。$2 \oplus 2 = 0$、そのような層が偶数個あると相殺され、奇数パリティのみが結果に影響します。
