 ## 解決策
 ## 問題の理解

 平面内の整数点の有限セットが与えられており、原点から開始して指定されたすべての点を訪れる歩行を構築できるように、許可されたステップ ベクトルの小さなコレクションを構築したいと考えています。 

ウォークは、次から始まる一連の格子点です。$(0,0)$。 歩行の各ステップは、事前に選択したベクトルの 1 つである必要があります。 ウォークではポイントを再訪問できます。特定の順序でポイントを訪問する必要はありません。入力セットのすべてのポイントがシーケンス内のどこかに表示されることを確認するだけです。 

タスクはステップ ベクトルのセットを選択することです$T$そのような散歩が存在するように、可能な限り最小限のサイズです。 

重要な制約は組み合わせによるものではなく構造的なものです。つまり、歩行自体を見つけることは求められず、そのような歩行を可能にする一連の変位方向のみを求める必要があります。 ウォークではベクトルを任意に何度でも再利用できます。 

入力サイズはテスト ケース全体で大きく、合計$n$まで$10^5$。 これにより、完全なグラフの構築やポイント間のすべての違いのチェックなど、ポイント間のペアの関係に依存するものはすべて除外されます。 どのソリューションも基本的に、テスト ケースごとにほぼ直線的な時間でポイントを処理するか、すべてのテストにわたって直線的に償却する必要があります。 

単純な推論が微妙に失敗するケースは、点が直線上にあるものの、原点から等間隔ではない場合に発生します。 たとえば、次のような点$(3,0)$そして$(4,0)$たとえそれらが同一線上にあるとしても、単一のステップ ベクトルを使用して両方を生成することはできません。 (大きさの制約を無視して) 方向のみをチェックする単純なアプローチでは、1 つのベクトルで十分であると誤って想定されてしまいます。 正しい制約はより厳密です。単一のベクトルはその正確な倍数の動きのみを許可します。 

もう 1 つの失敗モードは、ポイント間のペアごとの差異をすべて一致させる必要があると仮定した場合です。 それは爆発するだろう$O(n^2)$ベクトルであり、原点から点までの構造のみが重要であるため不要です。 

## アプローチ

 強引なアイデアは、到達可能性の有向グラフを構築する観点から考えることです。原点から開始して、許可されたステップを使用してすべての点に到達しようとします。 候補が決まっていたら$T$、これらのベクトルによって生成された格子グラフ上で、すべての点が BFS または DFS によって到達可能かどうかをシミュレートできます。 次に、おそらく点のすべてのペアごとの差から導出される候補ベクトルのサブセットを検索できます。 

点間のすべての差異の自然な候補セットは次のとおりであるため、これはすぐに失敗します。$O(n^2)$、サブセットをチェックすることさえ組み合わせ的に不可能になります。 到達可能な格子点の密なグラフ上で 1 回のシミュレーションを行っても、座標には制限がないため意味がありません。 

構造的な洞察は、重要なのはポイントが選択された走査順序にどのように関係するかだけであるということです。 原点から始まるシーケンス内の点を順序付けすると、連続する各差分が候補ベクトルになります。 有効なウォークはすべて、ポイントの順序付けに対応し、セットは$T$は、その順序付けで使用される一連の個別のステップ差にすぎません。 

これにより、問題は、原点から始まりすべての点を訪れるパスに沿った明確な差異の数を最小限に抑えることに変換されます。 重要な観察点は、訪問ポイントの順序を自由に選択できるということです。 したがって、タスクは、個別の変位方向の数を最小限に抑える順序を構築することになります。 

凸型角度スイープでは、連続するポイントが方向構造を共有する傾向があるため、原点の周りの極角によってポイントをソートし、その順序でトラバースすると、貪欲な構築が機能します。 最適性は、方向のあらゆる変化が必要な新しいベクトルに対応し、角度順序付けによって方向の変化が全体的に最小限に抑えられるという事実から生まれます。 

したがって、問題を角度ごとにソートされた点にわたる 1 回のスイープに縮小し、次の点から連続的な差分を抽出します。$(0,0)$サイクルを通して。

 ## アルゴリズムのチュートリアル

 慎重に選択した順序ですべてのポイントを訪れるパスを構築し、そのパスに沿って一意のステップ ベクトルのセットを取得します。 

1. 原点を追加することから始めます$(0,0)$ポイントセットまで。 これにより、ウォークを特別な場合ではなく実際の頂点から始まるパスとして均一に扱うことができます。 
2. すべての点を原点の周りの極角で並べ替え、原点からの距離で関係を分けます。 角度の順序付けにより、1 回の回転スイープでポイントを移動することが保証され、方向の変更が制限されます。 
3. ソートされたリストをたどって、この順序で連続するポイント間の連続的な差分を構築します。 
4. 各差分ベクトルをセットに挿入します$T$。 繰り返しの方向は問題ではないため、重複は無視されます。 
5. すべてのベクトルを出力します。$T$答えとして。 

この構造が有効である理由は、この角度順序付けの任意の 2 つの連続する点が、必要に応じて中間格子位置間を移動するために任意に繰り返すことができる直接変位ベクトルを定義するためです。 さらに重要なことは、すべての入力ポイントが構築されたシーケンス内の頂点として明示的に訪問されるため、カバレッジの要件が直接満たされることです。 

### なぜ効果があるのか

 核となる不変条件は、原点から始まり、必要なすべての点を 1 回だけ訪問する一連の点を明示的に構築することです。 このシーケンスの各エッジは、$T$したがって、散歩は定義上有効です。 シーケンスにはすべての点が含まれるため、実現可能性が保証されます。 最小性は、トラバース方向の変化が必ず新しい変位ベクトルを導入するという事実から得られ、角度順序付けは原点の周りの単調な回転を保証することでそのような変化を最小限に抑え、不必要な前後方向の切り替えを防ぎます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    q = int(input())
    out = []

    for _ in range(q):
        n = int(input())
        pts = []

        for _ in range(n):
            x, y = map(int, input().split())
            pts.append((x, y))

        # include origin
        pts.append((0, 0))

        # sort by polar angle using cross product with a reference axis
        # we split into upper/lower half for deterministic ordering
        def half(p):
            x, y = p
            return (0 if (y > 0 or (y == 0 and x >= 0)) else 1)

        def cmp(p):
            x, y = p
            return (half(p), -y / (abs(x) + abs(y) + 1e-18), x)

        # safer approach: use atan2
        import math
        pts.sort(key=lambda p: math.atan2(p[1], p[0]))

        # build vectors
        vectors = set()

        for i in range(len(pts) - 1):
            x1, y1 = pts[i]
            x2, y2 = pts[i + 1]
            dx, dy = x2 - x1, y2 - y1
            if (dx, dy) != (0, 0):
                vectors.add((dx, dy))

        out.append(str(len(vectors)))
        for v in vectors:
            out.append(f"{v[0]} {v[1]}")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```実装は文字通り概念的な構造に従います。 まず原点を挿入して、パスが正しく開始されるようにします。 並べ替え順`atan2`原点の周りで循環スイープ順序を強制します。これは、私たちが依存する重要な幾何学的構造です。 

唯一の微妙な実装の詳細は、重複ポイントまたは縮退した差異の処理です。 このセットは重複を自動的に削除します。これは角度隣接によって一意の変位ベクトルが保証されないため必要です。 

微妙な点の 1 つは、浮動小数点を使用することです。`atan2`正確な角度精度の比較ではなく、一貫した順序付けのみが必要なため、ここでは許容されます。 より厳密な設定では、クロス積ベースのコンパレータが推奨されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import atan2

    q = int(sys.stdin.readline())
    out = []

    for _ in range(q):
        n = int(sys.stdin.readline())
        pts = []
        for _ in range(n):
            x, y = map(int, sys.stdin.readline().split())
            pts.append((x, y))

        pts.append((0, 0))
        pts.sort(key=lambda p: atan2(p[1], p[0]))

        vectors = set()
        for i in range(len(pts)-1):
            dx = pts[i+1][0] - pts[i][0]
            dy = pts[i+1][1] - pts[i][1]
            if dx or dy:
                vectors.add((dx, dy))

        out.append(str(len(vectors)))
        for v in vectors:
            out.append(f"{v[0]} {v[1]}")

    return "\n".join(out)

# minimal
assert run("1\n2\n1 0\n2 0\n") != ""

# collinear decreasing
assert run("1\n2\n-1 0\n-2 0\n") != ""

# square
assert run("1\n4\n1 1\n1 -1\n-1 1\n-1 -1\n") != ""

 ## 特殊なケース

 一般的な特殊なケースは、複数の点が原点から同じ角度を共有する場合です。 その状況では、角度だけによるソートでは順序が区別されず、連続する点が同一である場合、トラバースによって長さ 0 のベクトルが生成される可能性があります。 実装では、セットに挿入するときにゼロ ベクトルを無視することでこれを回避します。 

もう 1 つのケースは、点が原点を通る単一線上に両方向にある場合に発生します。 角度ソートは、それらを不連続部で区切られた 2 つの領域に分割します。$\pi$そして$-\pi$。 構築されたパスは自然に両方向のベクトルを生成し、歩行が原点を一貫して移動できるようにします。 

最後のエッジ ケースは、原点自体が入力ポイントと一致する場合です。 これを明示的に含めると、ループ ロジックで特別なケースを必要とせずに、シーケンスが入力セット内の有効なポイントから開始することが保証されます。
