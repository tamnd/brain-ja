 ## 解決策
 ## 問題の理解

 のセットをご用意しております。$N$スコアがすでに固定されているクラブと、最後にスコアを自由に選択できる RUN と呼ばれる追加のクラブが 1 つあります。 最終的なランキングは、厳密に高いスコアを持つクラブの数によって純粋に決定されます。つまり、クラブのランクは 1 に、より高いスコアを持つクラブの数を加えたものになります。 ランクが低いほど地位が高くなります。 

RUN のスコアが選択される前に、他のスコアを減らすことができます。$N$クラブ。 各クラブ$i$スコアから始まる$a_i$、そしてそれをある程度減らすと$T$の「疑惑費用」を支払います。$T \cdot b_i$。 すべてのクラブに対する疑惑の総量は厳密に以下に保たれなければならない$K$。 スコアを増やすことはできず、減らすか変更しないままにすることのみが許可されており、スコアはマイナスにならないようにする必要があります。 

すべての調整を終えて、RUNのスコアを設定しました。 RUNはせいぜいランクで終わりたい$X$そして、それを達成するためのすべての方法の中で、RUN の最初に選択されるスコアをできるだけ小さくしたいと考えています。 

ランキング条件を解釈すると、RUN には最大でも$X-1$最終スコアが厳密に高いクラブ。 したがって、タスクは次のようになります。加重削減に関するグローバルな予算制約の下で既存のスコアの一部を削減し、最大でも次のことを保証しながら、RUN のスコアをできるだけ小さく選択します。$X-1$クラブはそれを上回ります。 

制約は私たちを$O(N \log N)$または$O(N)$解決。 と$N \le 10^5$、異なるスコア構成またはサブセットを試す際の二次関数は直ちに実行不可能になります。 線形コストと単調なスコア減少の存在は、おそらくソートと組み合わされた、貪欲な構造またはプレフィックスベースの構造を強く示唆しています。 

削減が非効率的に配分された場合、微妙な失敗例が発生します。 たとえば、間違ったクラブを早い段階で貪欲に減らすと、影響の少ない変更に予算を無駄にし、後でランク要件を満たすのに十分な高スコアのクラブを抑制できなくなる可能性があります。 もう 1 つのよくある落とし穴は、上部を減らすことだけを考えていると仮定することです。$X-1$他のクラブのより安い割引がより効果的である可能性があることを無視して、初期スコアでクラブを評価します。 

エッジケースの小さな例としては、1 つのクラブが大きなスコアを持っているにもかかわらず、非常に高いスコアを獲得している場合があります。$b_i$、他の多くは目標をわずかに上回っていますが、削減するのは安価です。 スコアだけを求めて単純に欲張っても失敗しますが、最適な動作は費用対効果に依存します。 

## アプローチ

 RUNの最終スコアを修正すると$S$、条件「RUN は最大ランクを持っています」$X$” はせいぜい$X-1$クラブは厳密に上に留まります$S$。 同様に、すべてのクラブにおいて、以下のことを確実に行わなければなりません。$X-1$そのうち最終スコアがある$> S$。 

固定の場合$S$、各クラブ$i$次の 3 つの役割のいずれかに当てはまります。 

もし$a_i \le S$すでに RUN を脅かすものではないため、減らす必要はまったくありません。 

もし$a_i > S$、その後、それが上にとどまることを受け入れるか、$S$、または最大でも次の値まで削減します。$S$。 それを削減することを選択した場合、少なくとも次のように削減する必要があります$a_i - S$、費用を支払う$(a_i - S)b_i$。 

したがって、固定の場合$S$、各クラブと$a_i > S$それは私たちに二者択一の選択肢を与えます。その脅威を「排除」する（コストを支払う）か、それとも競争相手として残すかのどちらかです。 私たちはせいぜい出発することが許されています$X-1$競合他社。 これは直ちに、どのクラブを完全に削減するかを選択し、最大でもすべてを削除することを示唆しています。$X-1$高価なものの。 

リフレーミング: クラブ間で$a_i > S$、あるとします。$m$そのようなクラブ。 私たちはせいぜい出発することが許されています$X-1$, したがって、少なくとも排除する必要があります$m-(X-1)$彼らのうち。 それぞれの除去にはコストがかかります$(a_i - S)b_i$。 疑惑を最小限に抑えるために、最も安価なものを選択して排除します。 

したがって、固定の場合$S$、実現可能性は、これらのコストを分類し、必要な最小コスト数の合計が以下であるかどうかを確認することになります。$K$。 

これにより、元の問題が単調な決定問題に変わります。$S$: スコアの場合$S$実現可能であれば、それよりも小さい$S$より多くのクラブが危険になり、コストが増加するだけであるため、これも実現可能です。 この単調性により、答えの二分探索が可能になります。 

この強引なアイデアでは、考えられるすべての RUN スコアを試します。$0$まで$\max a_i$、そしてそれぞれについて、すべてのクラブをスキャンして除去コストを計算します。 つまり$O(N \cdot \max A)$が遅すぎます。 重要な観察は、実現可能性は単調であり、次のように計算できるということです。$O(N \log N)$、二分探索を有効にします。

 ## アルゴリズムのチュートリアル

 可能な限り最小の RUN スコアを二分探索します$S$。 

1. 関数を定義する`check(S)`RUN が最大ランクを達成できるかどうかを決定します$X$そのスコアが$S$。 
2.内部`check(S)`、クラブごとに計算します$i$と$a_i > S$それを下げるためのコスト$S$、つまり$(a_i - S) \cdot b_i$。 クラブとの$a_i \le S$コストはかからず、ランクのプレッシャーとは無関係です。 その理由は、厳密に高いスコアだけがランクに影響するからです。 
3. 現在、それを超えているクラブの数を数えます。$S$。 これに電話してください$m$。 
4. もし$m \le X-1$の場合、削減は必要なく、構成は自動的に有効になります。 
5. それ以外の場合は排除する必要があります$m-(X-1)$クラブ。 それぞれを削減するためのコストをすべて収集します。$m$クラブを並べ替えて最小値を合計します$m-(X-1)$。 これは、競合他社を十分に減らすための最も安価な方法です。 
6. この合計が以下の場合$K$、構成は実行可能です。 それ以外の場合はそうではありません。 
7. 二分探索を使用する$S$範囲内で$[0, \max a_i]$、実行可能な最小値を維持します。 

なぜこれが正しいのかは、意思決定問題の構造に依存します。 固定閾値の場合$S$コストを抑制すると決めた場合、各クラブは独自にコストに貢献しており、コストを削減することなくクラブを部分的に削減してもメリットはありません。$S$なぜなら、中間値が存在しても依然として RUN を超えており、競合他社の数は減らないからです。 したがって、すべての最適な戦略は、コストを追加して完全に抑制するクラブのサブセットを選択することに相当し、最適なサブセットは常に最も安価なクラブになります。 

実現可能性の単調性$S$増加するので続きます$S$簡単になるだけで、満足できるクラブが少なくなる$a_i > S$、それぞれのコスト$(a_i - S)b_i$減少するか完全に消滅します。 したがって、一度 の値が$S$が実現可能であれば、それより大きな値もすべて実現可能であり、二分探索が正当化されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def check(S, arr, K, X):
    costs = []
    m = 0

    for a, b in arr:
        if a > S:
            m += 1
            costs.append((a - S) * b)

    if m <= X - 1:
        return True

    need = m - (X - 1)
    costs.sort()

    total = sum(costs[:need])
    return total < K

def solve():
    N, K, X = map(int, input().split())
    arr = [tuple(map(int, input().split())) for _ in range(N)]

    lo, hi = 0, max(a for a, _ in arr)

    ans = hi

    while lo <= hi:
        mid = (lo + hi) // 2
        if check(mid, arr, K, X):
            ans = mid
            hi = mid - 1
        else:
            lo = mid + 1

    print(ans)

if __name__ == "__main__":
    solve()
```この実装は決定プロセスを正確に反映しています。 の`check`関数は、固定しきい値のコスト構造を再構築し、十分なクラブを削除する余裕があるかどうかを評価します。 コストの分類は、常に最も安価な抑制セットを選択するための重要なステップです。 

微妙な点の 1 つは、疑惑に関する厳密な不平等です。条件は「未満」です。$K$したがって、等価性は拒否される必要があります。これは、最終比較で直接処理されます。

 ## 特殊なケース

 コーナーケースが発生するのは次の場合です$X = N+1$、つまり RUN が最後になる可能性があります。 この場合、得点に関係なくどのクラブも敗退する必要はありません。 アルゴリズムはそれを自然に処理します。$m-(X-1)$ゼロまたはマイナスになるため、コストは合計されず、$S$負でない限り実現可能です。 二分探索では正しく 0 が返されます。 

もう 1 つの微妙なケースは、すべてが$a_i \le S$。 それから$m = 0$, そのため、チェックはすぐに true を返します。 これは、コストを考慮しても RUN がすでに誰よりも優れているという事実を反映しています。 

より微妙なシナリオは、少数のクラブを削減するのに非常に高価であり、それらのクラブを RUN より上に残し、代わりに多くのより安価なクラブを抑制することが最適である場合に発生します。 ソートベースの選択により、この動作が保証されます。これは、実現可能性が初期スコアに基づくヒューリスティックではなく、必要な消去の最も安価なサブセットを選択することにのみ依存するためです。
