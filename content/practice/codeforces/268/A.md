 ## 解決策
 ## 問題の理解

 サッカー選手権では、すべてのチームのユニフォームの色が与えられます。 各チームにはホームカラーとアウェイカラーがあります。 

注文された個別のチームの各ペアは、1 つのチームがホストとして機能し、もう 1 つのチームがゲストとして機能して、1 つの試合を行います。 通常、ホストはホームユニフォーム、ゲストはアウェイユニフォームを着用します。 

唯一の特別な状況は、ホストのホームの色がゲストのアウェイの色とまったく同じである場合に発生します。 その場合、ホストは切り替えてアウェイユニフォームを着ます。 

タスクは、チャンピオンシップ全体で何試合がこのスイッチをトリガーするかをカウントすることです。 

入力により、各チームのホーム色とアウェイ色が提供されます。 出力は単一の整数で、ホストがアウェイ ユニフォームを着た試合の合計数です。 

制約は非常に小さいです。 チームは最大 30 なので、可能なホストとゲストのペアの合計は最大で次のようになります。$$30 \cdot 29 = 870$$考えられるすべての一致を単純に調べるだけでも、十分に高速です。 高度なデータ構造や最適化は必要ありません。 

よくある間違いは、順序のないチームのペアについて考えることです。 チャンピオンシップには順序付けられた試合が含まれます。 チーム A がチーム B をホストし、チーム B がチーム A をホストする場合、これらは 2 つの異なるゲームであるため、別々に検討する必要があります。 

次の例を考えてみましょう。```
2
1 2
2 1
```2 つの一致があります:

 チーム 1 がチーム 2 をホストします。 

ホスト ホーム = 1、ゲスト アウェイ = 1、切り替えが発生します。 

チーム 2 がチーム 1 をホストします:

 ホスト ホーム = 2、ゲスト アウェイ = 2、切り替えが発生します。 

正しい答えは次のとおりです。```
2
```各ペアを 1 回だけチェックするソリューションでは、誤って 1 が返されます。 

もう 1 つの微妙なケースは、複数のチームが同じホームカラーを共有している場合です。```
3
1 2
1 3
4 1
```チーム 1 とチーム 2 はどちらもホーム カラー 1 を持ち、チーム 3 はアウェイ カラー 1 を持ちます。 

チーム 3 がチーム 1 を訪問する試合と、チーム 3 がチーム 2 を訪問する試合は両方とも答えに寄与します。 有効なホストとゲストの組み合わせをすべて個別にカウントする必要があります。 

正しい答えは次のとおりです。```
2
```## アプローチ

 最も直接的なアプローチは、考えられるすべての一致の条件をシミュレートすることです。 

すべてのチームにとって$i$ホストとしてさまざまなチームとして活動する$j$ゲストとして機能すると、次のことを確認します。$$home_i = away_j$$色が一致した場合、ホストはユニフォームを交換し、答えを増やします。 

問題の定義はホストのホームの色とゲストのアウェイの色のみに依存するため、このアプローチは正しいです。 すべての一致は独立して評価できます。 

最悪のケースには 30 チームが含まれるため、パフォーマンスは最大でも次のとおりです。$$30 \cdot 29 = 870$$比較。 それは小さいです。 

数え方の解釈もあります。 ホーム カラーのすべての出現は、アウェイ カラーと同じ値のすべての出現と一致させることができます。 色の頻度を数えて、それらを掛け合わせることができます。 これも機能しますが、制約が少ないため不要です。 

入力サイズが非常に小さいため、この問題にはブルート フォース ソリューションがすでに最適です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 承認済み |
 | 周波数計数 | O(n + C) | O(C) | 承認済み |

 ここ$C$可能な色の数です。 以来$n \le 30$の場合、より単純な 2 次解が自然な選択となります。 

## アルゴリズムのチュートリアル

 1. チーム数を読み取ります。 
2. 各チームのホームカラーとアウェイカラーをリストに保存します。 
3.初期化`answer = 0`。 
4. すべてのチームにとって`i`、ホストとして扱います。 
5. すべてのチームにとって`j`、ゲストとして扱います。 
6. 次の場合はスキップします。`i == j`、チームは自分自身でプレーすることはないからです。 
7. ホストのホームの色がゲストのアウェイの色と等しいかどうかを確認します。 
8. 等しい場合は増分します。`answer`ホストがアウェイユニフォームに着替える必要があるため、1つずつ減ります。 
9. すべてのペアの処理が完了したら、印刷します。`answer`。 

### なぜ効果があるのか

 チャンピオンシップには、個別のチームの注文されたペアごとに 1 つの試合が含まれます。 アルゴリズムはそれらのペアを正確に検査します。 

特定の試合の場合`(i, j)`、問題は、ホストのホームの色がゲストのアウェイの色と等しい場合にのみ、ホストがユニフォームを変更するというものです。 アルゴリズムはこの条件を正確にチェックし、一致が答えに寄与する場合に正確に 1 を追加します。 

すべての試合は一度だけチェックされるため、最終的なカウントは、ホストがアウェイ ユニフォームを着た試合の数とまったく同じになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
teams = [tuple(map(int, input().split())) for _ in range(n)]

answer = 0

for i in range(n):
    home_i = teams[i][0]

    for j in range(n):
        if i == j:
            continue

        away_j = teams[j][1]

        if home_i == away_j:
            answer += 1

print(answer)
```最初の部分は、すべての均一な色を読み取り、保存します。 各エントリには次の内容が含まれます`(home_color, away_color)`。 

ネストされたループは、順序付けられたすべてのホストとゲストのペアを列挙します。 条件`i == j`は、それ自体と対戦するチームがないためスキップされます。 

主な比較は次のとおりです。```
home_i == away_j
```これはステートメントのルールと直接一致します。 true の場合は常に、現在の一致が答えに 1 つだけ寄与します。 

重複した色に対する特別な処理は必要ありません。 複数のチームが同じ色を持っている場合、すべての有効な一致がループによって自然にカウントされます。 

最大の答えは最大であるため、整数オーバーフローは不可能です$30 \cdot 29 = 870$。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())
    teams = [tuple(map(int, input().split())) for _ in range(n)]

    ans = 0

    for i in range(n):
        for j in range(n):
            if i != j and teams[i][0] == teams[j][1]:
                ans += 1

    print(ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue().strip()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided sample
assert run("3\n1 2\n2 4\n3 4\n") == "1", "sample 1"

# minimum size, no match
assert run("2\n1 2\n3 4\n") == "0", "minimum case"

# two matches because games are ordered
assert run("2\n1 2\n2 1\n") == "2", "ordered matches"

# multiple hosts matching same away color
assert run("3\n1 2\n1 3\n4 1\n") == "2", "duplicate home colors"

# all possible ordered matches contribute
assert run("3\n1 2\n2 1\n1 2\n") == "4", "multiple contributions"
```| テスト入力 | 期待される出力 | 検証内容 |

 |`2 / (1,2) (2,1)`|`2`| 順序付き一致は個別にカウントされます。 
|`3 / (1,2) (1,3) (4,1)`|`2`| ホームカラーの重複 |
