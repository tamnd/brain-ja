## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_one(a: int) -> int:
    limit = int(a ** 0.5) + 5
    for x in range(2, limit):
        if a % x == 0 and a % (x + 1) == 0:
            return x * (x + 1)
    return 1  # fallback, should never be used due to guarantees

def main():
    t = int(input())
    for _ in range(t):
        a = int(input())
        print(solve_one(a))

if __name__ == "__main__":
    main()
```このコードは、連続する約数の検索を直接実装します。 このステートメントでは 1 より大きい約数が保証されているため、ループは 2 から始まります。境界は次のように選択されます。$\sqrt{a}$加えて小さなバッファ。 両方の数値が比較的小さな分解の因数であるため、有効な連続する約数のペアは早期に出現する必要があります。$a$。 

戻り値は連続する約数の積であり、構築された値として使用されます。$b$。
