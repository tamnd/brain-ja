 ## アルゴリズムのチュートリアル

 1. すべての整数を反復処理します。$i$1から$\lfloor \sqrt{a} \rfloor$かどうかを確認します$i$分割する$a$。

2.いつでも$i$分割する$a$、両方の約数を考慮します$i$そして$a/i$。 

これにより、因数分解のどちらの側にも現れる可能性のある連続するペアを見逃すことがなくなります。 
3. かどうかを確認します。$i+1$も分割します$a$。 そうであれば、すぐに 2 つの連続する約数が得られます。$i$そして$i+1$。

4. そのようなペアが見つかったら、$b = i$（または$b = i+1$）。

少なくとも 1 つの有効な連続ペアが存在することが保証されているため、検索は早期に停止します。そのため、すべての候補を使い果たす前にループが成功する必要があります。 

### なぜ効果があるのか

 正しさは、この問題が 2 つの連続する約数の存在を保証しているという事実から来ています。$a$。 この構造により、$a$整数の局所近傍に一致する因数分解を行う$x$そして$x+1$。 までの約数をスキャンすることで、$\sqrt{a}$、そのようなペアの考えられるすべての候補を列挙します。 見つかったら、連続する約数の 1 つを選択すると、有効な約数が生成されます。$b$なぜなら、可分性条件は連続構造によって引き起こされる共有因子間の相殺に帰着するからである。 このようなペアが少なくとも 1 つ存在する必要があるため、アルゴリズムは常に有効な出力で終了します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a = int(input())
        
        limit = int(a ** 0.5)
        found = None
        
        for i in range(2, limit + 1):
            if a % i == 0:
                if a % (i + 1) == 0:
                    found = i
                    break
                # also check paired divisor side
                j = a // i
                if j > 1 and a % (j + 1) == 0:
                    found = j
                    break
        
        # fallback (shouldn't be needed due to guarantee)
        if found is None:
            found = 1
        
        print(found)

if __name__ == "__main__":
    solve()
```このコードは、連続する約数のペアを検索するというアイデアを直接実装しています。 ループは最大でのみ実行されます$\sqrt{a}$、効率を確保します。 を使用したペアチェック$j = a // i$連続する約数が小さい因子領域ではなく大きい因子領域に現れる可能性があるため、これが必要です。 

問題によって解決策が存在することが保証されるため、フォールバック割り当ては防御的なものにすぎません。 厳密なコンテスト設定では、それがトリガーされることはありません。
