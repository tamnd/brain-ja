 ## 問題の理解

 2 人のプレーヤーが数直線上で開始します: アリスは位置にいます$a$、ボブは位置にいます$b$、 と$a < b$。 アリスは毎秒、固定の整数速度で右に移動します$c$、ボブは固定整数速度で右に移動します$d$。 ボブのスピード$d$知っているけどアリスは自分の速さを忘れてしまった$c$。 彼女が覚えているのは、ある整数時間で次のように速度が選択されたということです。$t \ge 0$、両プレイヤーはまったく同じ位置を占めます。 

タスクは、単一の有効な速度を再構築することではなく、$c$そんな出会いを可能にします。 

会議の条件は、整数が存在することです。$t \ge 0$そのような$$a + ct = b + dt.$$並べ替えると$$(c - d)t = b - a.$$それで違いは$b-a$で割り切れる必要があります$c-d$、およびの記号$c-d$アリスが追いつけるかどうか、それともすでにアリスのほうが速いかどうかを決定します。 

制約により許可されるのは、$a, b, d$まで$10^{12}$したがって、可能なすべてを反復するアプローチはすべて$c$すぐには無理です。 まで繰り返しても$b-a$ギャップが大きい場合は無理でしょう。 

微妙なエッジケースは、アリスがすでにボブよりも遅い場合です。 もし$c \le d$、 それから$c-d \le 0$そして、アリスは同じ地点から開始する場合にのみボブに会うことができますが、これは明示的に禁止されています。$a < b$。 したがって、有効な解決策は次の条件を満たす必要があります$c > d$、検索スペースを上記の正のオフセットに縮小します。$d$。 

もう 1 つの重要な詳細は、集合時間です。$t$整数でなければなりません。 これにより、問題は次の可算条件に変換されます。$b-a$であり、実数値の時間のみを考慮する推論は無効になります。 

## アプローチ

 この問題を直接考える方法は、考えられるすべての整数速度を試してみることです。$c$整数が存在するかどうかを確認します$t$方程式を満たす$$a + ct = b + dt.$$固定の場合$c$、差を計算します$b-a$次のように表現できるかどうかを確認します$t(c-d)$ある整数に対して$t \ge 0$。 これは、$c-d$分割する$b-a$。 ただし、すべてを繰り返すと、$c$まで$10^{12}$各チェックは一定時間ですが範囲が膨大であるため、遅すぎます。 

重要な観察は、問題は速度の絶対値ではなく、速度の差のみに依存するということです。 させて$k = c - d$。 それから$k$次のような正の整数でなければなりません$k \mid (b-a)$。 一度$k$修正されたら回復します$c = d + k$。 これは問題を次の正の約数を数える問題に変換します。$b-a$。 

したがって、速度を検索する代わりに、単一の数値の約数を数えます。$10^{12}$。 約数のカウントは次のように行うことができます$O(\sqrt{n})$因子のペアをチェックすることによって。

 ## アルゴリズムのチュートリアル

 しましょう$n = b - a$。 

1. 距離を計算する$n = b - a$。 これにより、会議が可能かどうかを決定する唯一の数量が特定されます。 
2. 応答カウンターをゼロに初期化します。 これにより、有効な速度差がカウントされます$k$。 
3. すべての整数を反復処理します。$i$から$1$に$\lfloor \sqrt{n} \rfloor$。 それぞれ$i$の潜在的な約数候補として扱われます。$n$。 
4. もし$i$分割する$n$、 それから$i$の有効な値に貢献します$k$、そしてまた$n/i$等しくない限り、別の値を提供します。 その理由は、すべての約数が有効な速度差に対応しているためです。$k = c-d$、およびそのようなそれぞれ$k$有効な値を 1 つだけ定義します$c$。 
5. このような約数をすべて慎重に数え、次のことが起こることを確認します。$i^2 = n$、除数は 1 回だけカウントされます。 
6. 合計カウントを出力します。 

### なぜ効果があるのか

 方程式$a + ct = b + dt$に減少します$(c-d)t = n$、 それで$c-d$の正の約数でなければなりません$n$。 Conversely, every positive divisor$k$の$n$を選択することで有効な解決策が得られます$t = n/k$そして$c = d + k$、これは常に正の整数です。 これにより、有効な速度間の 1 対 1 の対応が確立されます。$c$と正の約数$b-a$、つまりカウントは有効です$c$の約数を正確に数えています$b-a$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a, b, d = map(int, input().split())
    n = b - a

    ans = 0
    i = 1
    while i * i <= n:
        if n % i == 0:
            ans += 1
            if i * i != n:
                ans += 1
        i += 1

    print(ans)

if __name__ == "__main__":
    solve()
```コードはまず問題をコンピューティングに圧縮します。$n = b-a$。 次に、約数を数えます。$n$標準の平方根法を使用します。 各約数は、次の有効な選択肢に対応します。$c$、 なぜなら$c = d + k$そして$k$の任意の約数です$n$。 ループは、二重カウントを避けるために、完全な正方形の場合を注意深く処理します。 

微妙な実装上のポイントは、$d$除数カウントロジックには決して現れません。 の最終値をシフトするだけです$c$、ただし有効な数には影響しません$k$存在する。
