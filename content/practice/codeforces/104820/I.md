 ## 問題の理解

 私たちに最初に与えられたのは、$N$シーケンスの条件$a_n = \frac{1}{n}$、値を生成します$1, \frac{1}{2}, \frac{1}{3}, \dots, \frac{1}{N}$。 このシーケンスに加えて、インターバルも与えられます。$[A, B]$、これらがいくつあるかを数えるように求められます。$N$値は両方のエンドポイントを含め、その間隔内に収まります。 

したがって、このタスクは純粋に非常に特定の数値セットをフィルタリングすることに関するものですが、その微妙さは、シーケンスが任意ではなく、厳密に正で単調減少であるという事実から来ています。 この構造により、数直線の大部分で区間のほとんどが無関係になります。 

制約により許可されるのは、$A$そして$B$まで$10^9$大きさと$N$まで$10^9$。 これにより、すべてを反復するアプローチは即座に除外されます。$n \le N$なぜなら、リニアスキャンでもテストごとに最大10億ステップが必要になるためであり、これは一般的な制限をはるかに超えています。 有効な解決策は、条件を不等式に基づいた定数時間推論に圧縮する必要があります。 

いくつかの危険な状況では、素朴な推論が崩れる傾向があります。 

問題となるケースの 1 つは、間隔が完全にマイナス側にある場合です。たとえば、$A = -5, B = -1$。 毎期から$1/n$は厳密に正であり、シーケンス要素はそのような間隔内に入ることができず、正しい答えは次のとおりです。$0$。 符号を忘れて不等式を反転しようとする単純な実装では、インデックスが誤って含まれる可能性があります。 

別のケースとしては、間隔がゼロと交差する場合があります。$A = -1, B = 2$。 ここで、数列のすべての正の項は少なくとも$0$、およびすべての値$1/n$寝そべる$(0, 1]$、つまり、ここまでのシーケンス全体は、$N$が含まれています。 シーケンスが決して負にならないという事実を利用せずに両方の境界を対称的に解こうとする誤った場合、これは見逃される可能性があります。 

3 番目の微妙なケースは次のような場合です。$A \ge 1$。 以来$1/n \le 1$みんなのために$n$、最初の項のみが少なくとも下限を満たすことができます。$1$、これにより、答えは最大でも 1 つの要素に折りたたまれます。 

## アプローチ

 ブルートフォースアプローチはすべてを反復することになる$n$から$1$に$N$、計算する$1/n$、それが次の場所にあるかどうかを確認します$[A, B]$。 これはシーケンスの定義に直接従うため、単純かつ正確です。 ただし、実行します$N$割り算と比較は、次の場合には実行不可能になります。$N$到達する$10^9$。 でさえ$10^7$、これは Python ではすでに遅すぎます。 

重要な観察点は、シーケンスが$1/n$厳密に減少しており、常にプラスです。 各用語をチェックする代わりに、条件を翻訳できます。$$A \le \frac{1}{n} \le B$$の制約に$n$。 シーケンスは単調に動作するため、有効なインデックスは単一の連続した範囲を形成し、実際、整数の構造によりこれがさらに単純化されます。 

上側には、$\frac{1}{n} \le B$重要なのはそのときだけ$B > 0$。 以来$B$整数、正の任意の数$B$少なくとも$1$したがって、すべての用語$1/n \le 1 \le B$。 したがって、次の限り、上限は何も制限しません。$B \ge 1$。 

下側には、$\frac{1}{n} \ge A$かどうかに大きく依存します。$A$はポジティブです。 もし$A \le 0$、すべての項が正であるため、シーケンス内のすべての項は自動的に条件を満たします。 もし$A \ge 1$、その後は値のみ$1$（いつ$n = 1$) 不等式を満たす可能性があります。 

これにより、問題全体が数値検索ではなく、いくつかの定数時間のケースに分解されます。

 ## アルゴリズムのチュートリアル

 どこにあるのかを直接推論します$1/n$間隔に対して嘘をつくことができます。 

1. かどうかを確認します。$B \le 0$。 そうであれば価値はありません$1/n$すべてのシーケンス要素が厳密に正であるため、適合できます。 答えはすぐにゼロになります。 
2. もし$A \le 0$そして$B \ge 1$、シーケンスのすべての項は 0 と 1 の間にあり、区間にはこの領域が完全に含まれます。 最初のどれも$N$条件が満たされます。 
3. もし$A \ge 1$、次に条件$1/n \ge 1$力$n = 1$。 次に、この単一の候補が上限を満たしているかどうかを暗黙的にチェックします。これは、間隔が有効で順序付けされている場合には常に行われます。 
4. 上記のロジックから取得したカウントを返します。 

### なぜ効果があるのか

 シーケンス$1/n$厳密に正であり、厳密に減少しています。 つまり、間隔クエリは、単調な変換にマップされるインデックスの数を理解することに帰着します。 関数は最初の項の後にゼロを超えたり 1 を超えたりすることはないため、すべての意味のある制約は次の時点で境界チェックに組み込まれます。$n = 1$。 複数の互いに素な有効なセグメントが存在する可能性はありません。そのため、間隔がゼロより小さいか、ゼロにまたがるか、または 1 より大きく始まるかどうかをケース分析することで、答えが完全に決まります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    A, B, N = map(int, input().split())
    
    if B <= 0:
        print(0)
        return
    
    if A <= 0:
        print(N)
        return
    
    # now A >= 1 and B >= 1 (since A <= B)
    print(1 if N >= 1 else 0)

if __name__ == "__main__":
    solve()
```実装は、次の構造から派生したケース分割に従います。$1/n$。 最初の分岐は、一致する項が存在しない非正側のすべての区間を完全に削除します。 2 番目のブランチは、左側の境界にゼロまたは負の値を含む任意の間隔をキャプチャします。これには、次の値までのすべての正のシーケンス値が自動的に含まれます。$N$。 最後のケースは、少なくとも 1 から始まる正の領域内の区間全体を処理します。ここで、最初の項のみが$1$資格を得ることができます。 

よくある落とし穴は、次のようなしきい値を計算しようとすることです。$1/A$または$1/B$浮動小数点演算を使用します。 これはここでは不要であり、精度の問題が発生するだけです。 整数制約の構造により、ソリューションでは除算を完全に回避できます。
