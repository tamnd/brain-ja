 ## 問題の理解

 ## アルゴリズムのチュートリアル

 包含-除外を使用して、境界のある構成の数を計算します。 

1. 最終状態を代入として解釈します。$k$同一のアイテムを$n$ラベル付きのビン。各ビンは$i$容量がある$m$。 これにより、プロセスが整数解を数えることに変換されます。$x_1 + \dots + x_n = k$と$0 \le x_i \le m$。 
2. 非負の解の制約のないカウントから開始します。 上限がない場合、解の数は次のようになります。$\binom{k+n-1}{n-1}$。 これは標準的な星と棒の結果です。 
3. 少なくとも 1 つの変数が超過する解を除外することで上限を導入します。$m$。 の固定サブセットの場合、$i$変数は少なくとも強制的に$m+1$、減算$i(m+1)$合計から残りの非負の解を数えます。 
4. 境界を超える変数の数に対して包含/除外を適用します。 最終的な式は次のようになります$$\sum_{i=0}^{\lfloor k/(m+1)\rfloor} (-1)^i \binom{n}{i} \binom{k - i(m+1) + n - 1}{n - 1}.$$1. 少なくとも次の階乗および逆階乗を事前計算します。$n+k$すべての二項係数が次のように答えられるようにします。$O(1)$。 合計を直接評価します。 
2. 結果のモジュロを返します$998244353$。 

重要な計算ステップは、最上位パラメータが負になった場合の二項係数を慎重に処理することです。 このような項はゼロとして扱われ、スキップされます。 

### なぜ効果があるのか

 包含-排他構造では、ビンの容量超過を許可することによって生じる過剰カウントを修正することで、割り当てを正確に列挙します。 各構成は違反ビンのサブセットごとに 1 回カウントされ、交互の符号により無効な構成がすべてキャンセルされ、有効な構成は 1 回だけ保持されます。 すべての有効な境界付き構成は少なくとも 1 つのペア選択シーケンスに対応し、プロセスでは容量制約を超えて実現可能性が制限されないため、組み合わせモデルは到達可能なセットと一致します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def main():
    n, k, m = map(int, input().split())

    max_n = n + k + 5

    fact = [1] * (max_n)
    invfact = [1] * (max_n)

    for i in range(1, max_n):
        fact[i] = fact[i - 1] * i % MOD

    invfact[max_n - 1] = modinv(fact[max_n - 1])
    for i in range(max_n - 2, -1, -1):
        invfact[i] = invfact[i + 1] * (i + 1) % MOD

    def C(a, b):
        if a < 0 or b < 0 or a < b:
            return 0
        return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

    ans = 0
    limit = k // (m + 1)

    for i in range(limit + 1):
        rem = k - i * (m + 1)
        term = C(n, i) * C(rem + n - 1, n - 1) % MOD
        if i % 2 == 1:
            term = -term
        ans = (ans + term) % MOD

    print(ans % MOD)

if __name__ == "__main__":
    main()
```コードは階乗を最大 1 回事前計算します。$n + k$これは、星と棒の式で必要なすべての二項係数に十分です。 包含/排他ループは次の時点までのみ反復されます。$k/(m+1)$なぜなら、それ以上の過剰なビンを選択すると、残りの合計がマイナスになるからです。 

組み合わせ関数`C(a, b)`ゼロを返すことで無効なパラメータを安全に処理します。これにより、不可能な包含/除外条件が自然に取り除かれます。 交互符号は、答えを蓄積するときに直接実装されます。

 ## 特殊なケース

 主なエッジケースは次のような場合です$m = 0$。 唯一の有効なベクトルはすべてゼロです。これは次の場合にのみ可能です。$k = 0$。 包含排除式では、 が付いているすべての項は、$k > 0$すべてのビンがゼロを寄与する必要があり、組み合わせ係数がゼロになるため、自然に消滅します。 

もう 1 つのエッジケースは次のような場合です$m \ge k$。 この場合、どの座標も境界を超えることができないため、包含と除外の合計は単一の項に折りたたまれます。$i = 0$、標準的な星と棒の結果が得られます$\binom{k+n-1}{n-1}$。 

いつ$n = 1$、問題は次のことを確認することになります。$k \le m$。 また、ビンが 1 つだけあり、境界を尊重する場合に限り、候補ベクトルが 1 つだけ存在するため、式は正しく縮小されます。
