 ## 解決策
 ## 問題の理解

 バイナリ文字列、つまり次のシーケンスが与えられます。`0`そして`1`、どちらかを挿入したい`+`または`-`結果として得られる算術式の絶対値が最小になるように、連続する数字の各ペアの間の値を調整します。 概念的には、すべての`1`または`0`文字列内の は、現在までの合計に加算または減算することができます。私たちの目標は、これらの選択のバランスをとり、合計をできるだけゼロに近づけることです。 

入力には複数のテスト ケースが含まれています。 各テスト ケースでは、文字列の長さと文字列自体を指定します。 各テスト ケースの出力は、次のシーケンスになります。`+`そして`-`長さの兆候`n-1`、 どこ`n`文字列の長さです。 

制約は控えめで、テスト ケースは最大 2,000、文字列の長さは最大 100 です。これは、任意のアルゴリズムが実行されることを意味します。`O(n)`合計操作数は最大 200,000 であり、1 秒の制限内に十分収まるため、テスト ケースごとに実行可能です。 すべての総当たり列挙`2^(n-1)`可能性のある記号シーケンスは天文学的な時間がかかるため不可能です。`n=100`。 

注目すべきエッジケースには、完全に以下から構成される文字列が含まれます。`0`s。ここで、符号を選択​​するとすべて 0 が返され、次で始まるか終わる文字列が返されます。`1`、不必要に大きな合計を避けるために、慎重に記号を選択する必要がある場合があります。 交互に弦が入っている`1`と`0`また、調整せずに常に加算または減算する単純な戦略を公開することもできます。 

## アプローチ

 素朴なアプローチは、考えられるすべての組み合わせを試してみることです。`+`そして`-`数字の間に符号を付け、それぞれの結果の値を計算し、絶対値が最小のものを追跡します。 これには評価が含まれます`2^(n-1)`テスト ケースごとのシーケンス。非常に小規模な場合に実現可能`n`しかし、それを超えると指数関数的に爆発します`n=20`。 

重要な観察は、それぞれの符号を決定するだけでよいということです。`1`。 あ`0`符号に関係なく何も貢献しないので、すべて`0`安全に使用できます`+`。 のために`1`s、符号を交互にすると累計が最小になります。`1`合計を増加または減少させることができます。 単純な貪欲なルールが現れます。前の非ゼロ値が追加された場合は、現在の値を減算します。`1`; 減算されている場合は、現在の値を加算します`1`。 これにより、合計がゼロから大きく離れることがないことが保証されます。 

これは、累計を明示的に追跡しなくても実装できます。 最初の桁から始めます。`+`、そして交互に`+`そして`-`後続のそれぞれについて`1`。 全て`0`が割り当てられています`+`。 他のシーケンスは同じ合計を維持するか、合計を増加させるため、これにより有効な最小絶対値シーケンスが生成されます。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 テスト ケースごとに、次の内容を読んでください。`n`そして文字列`a`。 
2. 空のリストを初期化する`signs`のシーケンスを保存するには`+`そして`-`。 
3. で使用された最後の標識を追跡します。`1`として`last_sign`から始まる`'+'`。 
4. 文字列の 2 番目から最後までの各文字を繰り返します。 

ａ． 現在のキャラクターが`'0'`、追加`'+'`に`signs`。 

b. 現在のキャラクターが`'1'`、の反対を追加します`last_sign`に`signs`そして更新します`last_sign`この新しい標識に。 
5. 文字列を処理した後、`signs`リストを文字列に変換して出力します。 

効果がある理由: それぞれ`1`前と比べて符号が変わります`1`、連続したプラスの寄与が蓄積され、絶対値が不必要に増加するのを防ぎます。`0`は合計には影響しないため、それらを割り当てると`+`安全です。 これにより、全体を通じてほぼゼロの累計が維持され、最小の絶対値が達成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = input().strip()
    signs = []
    last_sign = '+'
    for i in range(1, n):
        if a[i] == '0':
            signs.append('+')
        else:
            # alternate the sign for '1'
            last_sign = '-' if last_sign == '+' else '+'
            signs.append(last_sign)
    print(''.join(signs))
```このソリューションは、まず高速 I/O を使用してすべての入力値を読み取り、最大 2,000 のテスト ケースを効率的に処理します。 の`signs`list は出力を蓄積し、`last_sign`前の非ゼロの符号を追跡して、交互を確実にします。 Off-by-one エラーは、2 文字目から最後の文字まで繰り返すことで回避されます。 出力は各テスト ケースの文字列に結合されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = input().strip()
        signs = []
        last_sign = '+'
        for i in range(1, n):
            if a[i] == '0':
                signs.append('+')
            else:
                last_sign = '-' if last_sign == '+' else '+'
                signs.append(last_sign)
        out.append(''.join(signs))
    return '\n'.join(out)

 ## 特殊なケース

 のような文字列の場合`0000`、アルゴリズムはすべてを割り当てます`+`。 累計は全体を通してゼロであり、これが最適です。 すべての文字列の場合`1`さん、`111`、アルゴリズムが交互に切り替わります`+`そして`-`として署名します`-+`、合計を与えます`1-1+1 = 1`または`-1+1-1=-1`最小絶対値 1 を達成する開始仮定に応じて、アルゴリズムは交互に処理します。`1`と`0`特別なチェックはありません。`0`いつも使っています`+`そして合計を乱さないでください。
