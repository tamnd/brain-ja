 ## 解決策
 ## 問題の理解

 配列が与えられています`p`長さの`2n`。 その値を変更して別の配列を取得したい`q`同じ長さの。 

ターゲット配列は任意ではありません。 それは非常に制限された条件を満たさなければなりません: すべての選択に対して正確に`n`位置の場合、選択した値の積は、残りの値の合計と等しくなければなりません。`n`ポジション。 

その条件を満たすすべての配列の中で、マンハッタン距離が最小の配列が必要です。`p`:$$\sum |p_i-q_i|$$出力はその最小距離のみです。 

制約は、これが建設的な検索問題ではないことを示す最初のヒントです。 の合計値`n`すべてのテストケース全体で最大でも`2 \cdot 10^5`したがって、受け入れられる解決策は、テスト ケースごとに線形に近いものでなければなりません。 サブセットを列挙する試みは不可能です。`n = 20`すでに以上のものを持っています$10^{11}$サイズのサブセット`n`。 

本当の課題は、適切な配列とはどのようなものかを理解することです。 その構造が分かれば、最適化は簡単になります。 

よくある間違いは、有効なターゲット配列が多数あると想定することです。 実際には、この条件は非常に強力であるため、ほぼすべての配列が除外されます。 

たとえば、次のようなとき`n = 3`、配列```
1 1 1 1 1 1
```良くないです。 選択したトリプルには積があります`1`、残りのトリプルには合計があります`3`。 

偶数人にとってまた簡単な罠が現れる`n`。 考慮する`n = 4`そして```
-1 -1 -1 -1 -1 -1 -1 4
```この配列は実際には優れています。 すべてゼロの候補だけをチェックする解決策では、最適なものを見逃してしまいます。 

ケース`n = 1`も特別です。 条件はこうなります$$q_1=q_2$$したがって、等しい数値のペアはすべて良好です。 治療中`n = 1`一般的なロジックでは間違った答えが得られます。 

## アプローチ

 ブルートフォース手法では、候補配列の特徴を明らかにし、サイズのすべてのサブセットをチェックすることで条件を検証しようとします。`n`。 

長さの固定配列の場合`2n`、検証にはすでに費用がかかります$$\binom{2n}{n}$$操作。 これは急激に増加し、すぐに絶望的になります。 

重要な観察は、この状態が最初に現れたよりもはるかに強いということです。 すべての配列を検索する代わりに、適切な配列をすべて完全に分類できます。 

条件が何を強制するのかを調べてみましょう。 

のために`n = 1`、すべての適切な配列は次の形式をとります。```
[x, x]
```各要素が他の要素と等しくなる必要があるためです。 

大型の場合`n`、1 つの位置が異なる 2 つのサブセット間の標準的な比較引数は、ほとんどすべての値が同一でなければならないことを示しています。 このアイデアを結論まで押し進めると、公式ソリューションで使用される完全な分類が得られます。 

奇数の場合`n ≥ 3`、唯一の良い配列は```
0 0 0 ... 0
```偶数の場合`n ≥ 4`、順列までは適切な配列が 2 つあります。```
0 0 0 ... 0
```そして```
-1 -1 ... -1 n
```どこにあるのか`2n-1`のコピー`-1`そして1部のコピー`n`。 

のために`n = 2`、追加の可能性が 1 つあります。```
2 2 2 2
```と共に```
0 0 0 0
```そして```
-1 -1 -1 2
```これらはすべて良い配列です。 

検索スペースが少数の候補に集約されると、最適化は簡単になります。 からの距離を単純に計算します。`p`有効な各家族に割り当てて、最小限のものを受け取ります。

 ## アルゴリズムのチュートリアル

 ### ケース`n = 1`1. 2 つの数字を次のようにします。`a`そして`b`。 
2. 優れたアレイはすべて、`[x, x]`。 
3. の最小値`|a-x| + |b-x|`が得られるとき`x`間にあります`a`そして`b`。 
4. 答えは簡単です。`|a-b|`。 

＃＃＃ 場合`n ≥ 2`1. すべてゼロの配列までの距離を計算します。$$\sum |p_i|$$この候補は常に存在します。 

1. もし`n = 2`、すべて 2 の配列までの距離も計算します。$$\sum |p_i-2|$$1. もし`n`が偶数の場合、1 つの値を含むファミリーまでの距離を計算します`n`そして`2n-1`に等しい値`-1`。 
2. その家族のために、まず始めてください。$$\text{base}=\sum |p_i+1|$$これは、すべてのポジションを次のポジションに変えるためのコストです。`-1`。 

1. なりたいポジションを 1 つ選択します`n`その代わり。 ポジションを入れ替える`i`によってコストが変わります$$|p_i-n|-|p_i+1|$$1. この家族にとっての最良の費用は次のとおりです$$\text{base} + \min_i \left(|p_i-n|-|p_i+1|\right)$$1. すべての有効な候補の中から最小値を取得します。 

### なぜ効果があるのか

 分類定理は、適切な配列の世界を一定数のファミリーに縮小します。 すべての適切な配列はこれらのファミリーのいずれかに属しており、評価するすべてのファミリーは完全に適切な配列で構成されています。 最適化ステップでは、各ファミリーまでの正確な最小距離が計算されます。 考えられるすべての適切な配列がカバーされ、候補が省略されないため、これらの距離の最小値がまさに必要な答えとなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))

        if n == 1:
            ans.append(str(abs(p[0] - p[1])))
            continue

        res = sum(abs(x) for x in p)

        if n == 2:
            res = min(res, sum(abs(x - 2) for x in p))

        if n % 2 == 0:
            base = sum(abs(x + 1) for x in p)
            best_delta = min(abs(x - n) - abs(x + 1) for x in p)
            res = min(res, base + best_delta)

        ans.append(str(res))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```最初のブランチは特別な処理を行います。`n = 1`場合。 2 つの数値と共通のターゲットの間の最小距離は正確にそれらの絶対差であるため、最適な等しい値を明示的に計算する必要はありません。 

大型の場合`n`、答えはすべてをゼロに変換するコストで初期化されます。 

の`n = 2`ブランチは、追加のオール 2 の良好な配列を評価します。 

偶数-`n`ブランチはファミリーを 1 で評価します`n`残りのすべての値は以下に等しい`-1`。 この実装では、すべての位置を個別に試行することが回避されます。 変数`base`あらゆる立場が次になると仮定します`-1`。 そうすれば、アップグレードするには最も安いポジションだけが必要になります。`-1`に`n`、これはまさに最小のデルタ式です。 

すべての算術演算は Python の整数に快適に適合します。 距離はおおよそ到達可能$2 \cdot 10^5 \cdot 10^9$これは 32 ビットの制限をはるかに超えていますが、Python はこれを自動的に処理します。
