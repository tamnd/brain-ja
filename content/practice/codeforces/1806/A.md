 ## 解決策
 ## 問題の理解

 キャラクター YunQian が無限デカルト平面上のターゲット ポイントに到達するための最小移動回数を計算するように求められます。 YunQian には 2 種類の動きがあります。彼女は斜め上から右に動くことができます。$(x, y)$に$(x+1, y+1)$、または、から直接左に移動することもできます。$(x, y)$に$(x-1, y)$。 入力は開始座標を提供します$(a, b)$そしてターゲット座標$(c, d)$複数のテストケースの場合。 出力は最小移動数または$-1$目標を達成することが不可能な場合。 

座標の範囲は次のとおりです。$-10^8$そして$10^8$、最大で$10^4$テストケース。 考えられるすべてのパスを探索する単純なシミュレーションは、単一のパスでも最大で$2 \cdot 10^8$最悪の場合は動きます。 これは、ソリューションが検索ではなく、幾何学と単純な算術に基づいた純粋に分析的である必要があることを意味します。 

エッジ ケースは、ターゲットが開始位置のすぐ左にある場合、または開始位置の上に水平方向の変位がない場合に発生します。 たとえば、開始が次の場合$(-1,0)$そしてターゲットは$(-1,2)$、左の動きは減少するため、左の動きだけを使用してターゲットに到達することはできません。$x$でも離れる$y$変化せず、斜めの移動は両方を増加させます$x$そして$y$。 これを誤解すると、垂直方向または水平方向の変位は常に達成可能であるという誤った仮定につながります。 

## アプローチ

 ブルートフォースアプローチでは、ターゲットに到達するまでの左方向と斜め方向の動きのすべてのシーケンスを列挙します。 これが機能するのは、移動が決定的であり、各移動後の座標を追跡できるためです。 このアプローチの問題は、潜在的な手の数が到達する可能性があることです。$10^8$それ以上であり、指数関数的に多くの一連の動きがあるため、計算上実行不可能です。 

重要な洞察は、斜めに移動すると両方の値が増加することを観察することです。$x$そして$y$1つずつ増えますが、左の手は減少するだけです$x$。 と表すと$dx = c - a$そして$dy = d - b$、その場合、斜めに移動した回数が制限されている場合にのみ、ターゲットに到達することが可能です。$k$そして左に移動します$l$次の 2 つの制約を満たします。$k - l = dx$そして$k = dy$。 これから導き出されるのは、$l = dy - dx$。 この動きは、両方の場合にのみ有効です。$k \ge 0$そして$l \ge 0$、そうでなければ目標を達成することは不可能です。 これにより、問題が各テスト ケースの単純な算術に削減され、$O(1)$テストケースごとのソリューション。

 ## アルゴリズムのチュートリアル

 1. 水平方向と垂直方向の変位を計算します。$dx = c - a$、$dy = d - b$。 これらは、達成する必要がある x 座標と y 座標の正味の変化を表します。 
2. 垂直変位が負であるかどうかを確認します。 斜め移動が増えるだけなので$y$そして左に移動すると離れる$y$変わらない場合$dy < 0$、目標に到達することは不可能です。 戻る$-1$この場合。 
3. 必要な左移動の回数を計算します。$l = dy - dx$。 これはシステムを解決することから生まれます$k - l = dx$そして$k = dy$、 どこ$k$は斜めの移動の数です。 
4. 左の移動回数が負でないことを確認します。 もし$l < 0$、ターゲットは斜めの移動だけで移動できる場所の右側にあり、ターゲットに到達できなくなります。 戻る$-1$。 
5. 前のチェックが両方とも合格した場合、最小移動数は左方向と斜め方向の移動の合計になります。$k + l = dy + (dy - dx) = 2 \cdot dy - dx$。 この値を返します。 

機能する理由: アルゴリズムが機能するのは、動きが線形で決定的であるためです。 垂直方向の増加はすべて、斜め方向の移動によってもたらされる必要があります。$k = dy$。 水平方向の変位は、対角線と左方向への移動の最終的な効果であり、次のようになります。$dx = k - l$。 このシステムを解決すると、追加の斜めまたは左への移動がターゲットをオーバーシュートするため、最小限の移動が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c, d = map(int, input().split())
    dx = c - a
    dy = d - b
    if dy < 0:
        print(-1)
        continue
    l = dy - dx
    if l < 0:
        print(-1)
        continue
    print(dy + l)
```このソリューションは、まずテスト ケースの数を読み取ります。 テスト ケースごとに、座標の差が計算されます。 垂直方向の変位が負であるかどうかがすぐにチェックされ、利用可能な移動ではカバーできません。 次に、必要な左移動回数を計算し、それが負であるかどうかを確認します。 斜めの動きと左の動きの合計が最小の動き数になります。 使用する`sys.stdin.readline`最大限の高速 I/O を保証します$10^4$テストケース。
