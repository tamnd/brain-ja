 ## 解決策
 ## 問題の理解

 ちょうど半分の開き括弧 '(' と半分の閉じ括弧 ')' で構成される括弧の文字列が与えられています。私たちの目標は、それを有効でバランスのとれた括弧シーケンスにすることです。 1 つの括弧を 1 回の移動で文字列の先頭または末尾に移動することができますが、そのような移動の回数を最小限に抑える必要があります。 出力は単に必要な最小限の移動数です。 

文字列には常に同じ数の左括弧と右括弧が含まれるため、解決策は常に存在します。 入力制約は小さく、各文字列の長さは最大 50 で、テスト ケースの数は最大 2000 です。これにより、アルゴリズムの時間計算量が次のオーダーになります。$O(n)$テストケースごとに心配する必要はありません。 括弧が初期順序であるとは想定できないため、エッジ ケースには、")))(((" や ")()(" など、多くの閉じ括弧で始まる文字列や多くの開き括弧で終わる文字列が含まれます。

 単純なアプローチでは、各括弧の移動をシミュレートし、結果の文字列のバランスが取れているかどうかを確認しようとします。 可能な手の数は組み合わせで増加するため、これは無駄です。 重要な洞察は、すべての動きをシミュレートする必要はないということです。最小の動きの数は、左から右にスキャンするときに発生する不均衡の最大の深さによって決まります。 たとえば、開き括弧よりも閉じ括弧が多い接頭語は、括弧を前に移動することで最終的に修正する必要がある欠陥を表します。 

## アプローチ

 強引なアプローチは、すべての括弧を最初または最後に移動し、すべてのシーケンスを再帰的に生成し、各シーケンスのバランスが取れているかどうかを確認することです。 それぞれのチェックは、$O(n)$、可能なシーケンスの数は次のように階乗的に増加します。$n$、これは不可能になります$n=50$。 

最適なアプローチは、文字列をスキャンするときにプレフィックスのバランスを追跡することから得られます。 '(' は 1 ずつ増加し、')' は 1 ずつ減少する累計を定義します。マイナスのバランスは、その時点で開き括弧よりも閉じ括弧の数が多いことを意味します。これは、負の接頭辞を避けるために前に移動する必要がある開き括弧の最小数を示します。 答えは単純に、この累計の負の最大値を正に変えたものです。 これが機能するのは、ブラケット シーケンスのカウントが等しいことが保証されているためです。そのため、最悪の不足を自動的に修正することで、追加の移動を行わずに文字列の残りのバランスが保たれることが保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | プレフィックスバランス | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`balance`ゼロに。 これにより、反復中に開始括弧と終了括弧の間の正味の差が追跡されます。 
2.初期化`max_deficit`ゼロに。 これにより、発生した最大のマイナス残高が記録されます。 
3. 文字列内の各文字を繰り返し処理します。 '('ごとにインクリメント`balance`1 ずつ。「)」ごとにデクリメントします。`balance`1までに。 
4. アップデート後`balance`、 もし`balance`マイナスです、更新します`max_deficit`現在の値の最大値になり、`-balance`。 これは、これまでに見た中で最悪のプレフィックス不足を示しています。 
5. 文字列全体をスキャンした後、`max_deficit`すべての負の接頭辞を修正するために必要な最小移動数が含まれています。 出力`max_deficit`。 

機能する理由: プレフィックス バランスは、シーケンスがゼロ以下になる場所を正確にキャプチャします。これは、ブラケットの移動が必要な唯一の状況です。 それぞれの負のバランスは、対応する開始括弧を前に移動する必要がある、一致しない終了括弧を表します。 最大の負のプレフィックスを修正すると、最終シーケンスに無効なプレフィックスがなくなり、結果のシーケンスのバランスが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    balance = 0
    max_deficit = 0
    for c in s:
        if c == '(':
            balance += 1
        else:
            balance -= 1
        if balance < 0:
            max_deficit = max(max_deficit, -balance)
    print(max_deficit)
```このソリューションは、高速 I/O を使用して入力を読み取ります。 各テスト ケースについて、実行中の`balance`そして残高がゼロを下回るたびに最大赤字を記録します。 すべてのプレフィックスを非負にするためにどれだけの開き括弧を前に移動する必要があるかを決定するのは最大の不足のみであるため、これで十分です。 いくつかの閉じ括弧で始まる文字列などのエッジ条件は自動的に処理されます。`balance`すぐにマイナスになってしまい、`max_deficit`それに応じて更新されます。 

## 実用的な例

 入力のトレース`)))(((()))`:

 | 文字 | バランス | 最大不足額 |
 | --- | --- | --- |
 | ')' | -1 | 1 |
 | ')' | -2 | 2 |
 | ')' | -3 | 3 |
 | '(' | -2 | 3 |
 | '(' | -1 | 3 |
 | '(' | 0 | 3 |
 | '(' | 1 | 3 |
 | ')' | 0 | 3 |
 | ')' | -1 | 3 |
 | ')' | -2 | 3 |

 最大赤字は3なので、3手必要です。 これは、最初の 3 つの左括弧を前に移動することに正確に対応します。 

トレース`()()`:

 | 文字 | バランス | 最大不足額 |
 | --- | --- | --- |
 | '(' | 1 | 0 |
 | ')' | 0 | 0 |
 | '(' | 1 | 0 |
 | ')' | 0 | 0 |

 接頭語が負になることはないため、移動は必要ありません。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        balance = 0
        max_deficit = 0
        for c in s:
            if c == '(':
                balance += 1
            else:
                balance -= 1
            if balance < 0:
                max_deficit = max(max_deficit, -balance)
        output.append(str(max_deficit))
    return "\n".join(output)

 ## 特殊なケース

 インプットを考慮する`)))(((`。 左から右にスキャンすると、残高は -1、-2、-3、-2、-1、0 となります。最大のマイナス残高は -3 です。`max_deficit`3 つになります。3 つの左括弧を前に移動すると、次のようになります。`((()))`、完全にバランスが取れています。 このアルゴリズムは、多くの閉じ括弧で始まる文字列や、インターリーブされた欠落がある文字列を、特別なケースを処理することなく自動的に処理します。 同様に、すでにバランスが取れている次のような文字列`()()`決してトリガーしない`balance < 0`、結果は正しくゼロ手です。
