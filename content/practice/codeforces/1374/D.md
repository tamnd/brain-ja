 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

1. 各要素の不足を次のように計算します。`d = (k - a_i % k) % k`。 これは、各要素が次の倍数に到達するまでにどのくらい必要かを示します。`k`。 要素を含む`d = 0`操作は必要ないため、無視されます。 
2. 各不足値を共有する要素の数を数えます。 これを周波数マップに保存します。 
3. 赤字額ごとに`d`周波数付き`f`、そのグループ内のすべての要素を完了するのに必要な時間を次のように計算します。`time = d + (f - 1) * k`。 その理由は、貢献する値を使用した後、`d`、同じ構造の次の使用可能な出現は、次の間隔で表示されます。`k`モジュロサイクリング制約によるステップ。 
4. 最大値を追跡する`time`すべての赤字グループにわたって。 
5. ゼロ以外の赤字がない場合、答えはゼロです。 それ以外の場合、答えは次のとおりです。`max_time + 1`、から始まる動きをカウントするため、`x = 0`。 

### なぜ効果があるのか

 赤字の各指数`d`残りの部分の修正に寄与するタイムスタンプ付きの値を 1 つだけ受け取る必要があります。 タイムスタンプは厳密に増加し、モジュロをラップするため`k`、互換性のあるコントリビューションの発生は毎回繰り返されます。`k`ステップ。 赤字値が出た場合`f`場合によっては、前にすべてを割り当てることはできません。`(f-1)`そのモジュロクラスの - 回目の繰り返し。少なくとも最後の代入が強制的に行われます。`d + (f-1)·k`。 すべてのグループの最新の終了時刻のみが必要なため、これらの境界の最大値によって必要な最小手数が決まります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))

        freq = {}
        for v in a:
            r = v % k
            if r == 0:
                continue
            d = k - r
            freq[d] = freq.get(d, 0) + 1

        if not freq:
            print(0)
            continue

        ans = 0
        for d, f in freq.items():
            last_time = d + (f - 1) * k
            ans = max(ans, last_time)

        print(ans + 1)

if __name__ == "__main__":
    solve()
```この解決策は、各数値を必要な剰余調整に圧縮することから始まります。 これらの要素はすでに有効であるため、ゼロ以外の調整のみが問題になります。 次に、同じ調整が必要な要素の数を集計します。 

重要な計算は、`d + (f - 1) * k`これは、同一の欠損が時間の経過とともに同じ残基クラスをめぐって競合するという事実をエンコードしています。 決勝戦`+1`前回のインデックスを移動回数に変換するために使用されます。 

剰余モジュロごとの周波数を誤ってリセットしないように注意する必要があります。`d`ではありません`r`、しかしそれを補うもの`k`。 これらを混在させると、誤ったグループ化が発生します。
