 ## 解決策
 ## 問題の理解

 各ピースはドミノのようなタイルで、端に 2 つの数字が付いています。 タイルは、次のように表される元の方向で使用できます。`a`、または反転して、次のように表されます。`b`。 すべてのピースの向きを選択した後、隣接するすべてのペアの接触する端が同じ番号になるように、ピースを 1 つの順序で配置する必要があります。 

たとえば、ある方向性のある作品が`(2, 3)`そして次は`(3, 6)`、最初のピースの右端と 2 番目のピースの左端は両方とも同じであるため、隣接することができます。`3`。 

入力には以下が含まれます`N`ピース、その後に各ピースの 2 つのエンドポイント値が続きます。 出力は、有効なチェーンを形成する順序で、すべての部分をその方向とともに正確に 1 回提供する必要があります。 このステートメントは、そのようなチェーンが少なくとも 1 つ存在することを保証します。 

重要な制約は、`N <= 8`。 これは非常に小さいです。 ピースのすべての順列と可能な両方の向きを含む配置を検討することができます。 あるのは`8! * 2^8 = 10,321,920`絶対的な最悪の場合の完全に指定された取り決め。 これは、不用意な実装にはコストがかかるほど十分に大きいですが、特に有効な取り決めが見つかった場合はすぐに停止できるため、徹底的な検索を行うには十分な大きさです。 

単純な実装では正しく処理する必要がある詳細がいくつかあります。 ピースは等しいエンドポイントを持つことができるため、反転すると`(4, 4)`何も変わりません。 たとえば、```
24 44 4
```出力は単純に次のようになります```
1 a2 a
```2 番目の問題は、番号が異なる場合でも、駒を反転する必要がある場合があることです。 のために```
23 57 3
```有効な答えは```
1 a2 b
```なぜなら、方向性のあるピースは`(3, 5)`そして`(3, 7)`、この順序では接続されません。 実際の有効な配置は次のとおりです。```
1 b2 b
```それは与える`(5, 3)`に続く`(3, 7)`。 ピースを並べ替えるだけで、両方の向きをまったく試さない解決策は失敗します。 

重複した部分もバグの一般的な原因です。 複数のピースに同一のエンドポイントがある場合でも、入力インデックスが異なるため、それらは依然として別個のピース​​です。 のために```
31 21 22 1
```3 つのインデックスはすべて回答に含まれている必要があります。 ピースをその値だけで扱うと、ある物理ピースを誤って 2 回使用し、別の物理ピースを省略する可能性があります。 

最後に、最初の部分には以前の隣接部分がないため、その方向はその前にあるものによって制限されません。 一致条件は、2 番目の部分が追加されたときにのみ開始されます。 

## アプローチ

 直接的なアプローチは徹底的な検索です。 未使用のピースを選択し、その 2 つの方向のいずれかを選択し、左の端点が現在の右の端点と一致する場合は追加します。 すべてのピースが配置されたら、有効な答えが得られます。 

考えられるすべての最終構成は次の順列で構成されているため、この検索は正しいです。`N`ピースと各ピースの方向の選択。 再帰的検索ではこれらの選択が正確に考慮されるため、有効な構成が見逃されることはありません。 

枝刈りをせずに完全に列挙すると、`N!`可能な注文と`2^N`オリエンテーションの割り当て、与える`O(N! * 2^N)`可能性。 で`N = 8`、つまり`8! * 256 = 10,321,920`構成。 完全なチェーンをチェックするには、最大でも`N - 1 = 7`接続のため、リテラル実装は次のように実行できます。`72 million`最悪の場合のエンドポイントの比較。 小さな限界`N`これはコンパイル言語で許容され、解決策が存在することが保証されるため、多くの場合、再帰的検索をはるかに早く終了できます。 

サブセット動的プログラミングを使用すると、検索を大幅に小さくできます。 これまでに構築された注文全体を記憶する代わりに、使用されたピースとチェーンの現在のオープンエンドの数だけを記憶する必要があります。 2 つの異なる部分チェーンがまったく同じピースのセットを使用し、同じ番号で終了する場合、将来の可能性は同じになります。 それらのうちの 1 つだけを保持する必要があります。 

がある`2^N`可能な中古品マスクと 6 つの可能なエンドポイント値のみ。 各状態について、すべての未使用品を両方の向きで試します。 これにより、`O(2^N * N * 2)`トランジションは小さいですが、`N <= 8`。 

部分的なドミノ チェーンの将来は、使用されている部分と現在のエンドポイントのみに依存するため、ここでは DP が特に自然です。 その状態に到達するための正確な順序はもはや重要ではありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |`O(N! * 2^N)`|`O(N)`| 受け入れられました`N <= 8`|
 | サブセット DP |`O(2^N * N)`|`O(2^N * 6)`| 承認済み |

 以下の実装では、サブセット DP を使用します。これは、実際のシーケンスを再構築するのに十分な単純さを保ちながら、より強力な最悪の場合の境界を与えるためです。 

## アルゴリズムのチュートリアル

 1. すべてのピースをペアとして読み取ります`(u[i], v[i])`。 見た目が同じ 2 つのピースは依然として異なる入力ピースであるため、ピースのインデックスはその値とは別に保持されます。 
2. 使用済みピースのセットを`N`-ビットマスク。 少し`i`まさにそのときのピースです`i`すでに配置されています。 
3. 次のように DP 状態を定義します。`(mask, last)`、 どこ`mask`中古品のセットです`last`チェーンの右端で現在公開されている番号です。 最終シーケンスを再構築できるように、到達可能な状態ごとに 1 つの先行データを保存します。 
4. すべてのピースを可能な両方の向きで開始します。 ピースの場合`i`は`(u[i], v[i])`、向き`a`で終わるチェーンを作成します`v[i]`、オリエンテーション中`b`で終わるチェーンを作成します`u[i]`。 
5. 到達可能なすべての状態について、次の状態に含まれていない各部分を考慮します。`mask`。 方向に追加できます`a`いつ`u[i] == last`、新しいエンドポイントを生成します`v[i]`。 方向に追加できます`b`いつ`v[i] == last`、新しいエンドポイントを生成します`u[i]`。 
6. 新しい状態にまだアクセスしたことがない場合は、その前の状態を、その状態に到達するために使用した部分と方向とともに保存します。 すでにその状態に達している場合は、両方のパスに将来の選択肢がまったく同じになるため、新しいパスを無視してください。 
7.すべてが揃った状態になり次第`N`設定されたビットに達すると、先行ポインタを逆方向にたどって答えを再構築します。 再構築は当然最後の部分から始まるため、収集したリストを逆にします。 

### なぜ効果があるのか

 不変条件は、到達可能なすべての DP 状態が`(mask, last)`正確に次の部分を含む少なくとも 1 つの有効なチェーンを表します。`mask`そして値で終わる`last`。 すべてのワンピース チェーンが有効であるため、最初はこれが当てはまります。 ピースを追加するときは、左端が次の値に等しい方向のみを受け入れます。`last`したがって、新しい接続は有効であり、不変式は true のままです。 

逆に、有効な部分チェーンを考えてみましょう。 使用された部分は何らかのマスクを形成し、その最終エンドポイントは何らかの値になります`last`。 連続するすべてのペアが必要なエンドポイントの同等性を満たしているため、最初の部分から開始して、DP はそのチェーンの方向と部分を正確にたどることができます。 したがって、すべての有効なチェーンは DP 遷移のシーケンスに対応します。 この問題により完全なチェーンが存在することが保証されるため、DP は最終的にすべての部分を含む状態に到達します。 保存された先行リンクは、有効な完全なチェーンを記述します。 

## Python ソリューション```python
Pythonimport sysinput = sys.stdin.readline

def solve():    n = int(input())    pieces = [tuple(map(int, input().split())) for _ in range(n)]
    full = (1 << n) - 1
    # parent[mask][last] = (previous_mask, previous_last, piece_index, orientation)    # last is in 1..6, so index 0 is unused.    parent = [[None] * 7 for _ in range(1 << n)]    seen = [[False] * 7 for _ in range(1 << n)]
    # Start with every possible first piece and both orientations.    for i, (u, v) in enumerate(pieces):        mask = 1 << i
        # Orientation 'a': (u, v), current endpoint is v.        if not seen[mask][v]:            seen[mask][v] = True            parent[mask][v] = (-1, -1, i, 'a')
        # Orientation 'b': (v, u), current endpoint is u.        if not seen[mask][u]:            seen[mask][u] = True            parent[mask][u] = (-1, -1, i, 'b')
    final_mask = None    final_last = None
    for mask in range(1 << n):        for last in range(1, 7):            if not seen[mask][last]:                continue
            if mask == full:                final_mask = mask                final_last = last                break
            for i, (u, v) in enumerate(pieces):                if mask & (1 << i):                    continue
                new_mask = mask | (1 << i)
                # Put piece i in its original orientation: (u, v).                if u == last and not seen[new_mask][v]:                    seen[new_mask][v] = True                    parent[new_mask][v] = (mask, last, i, 'a')
                # Reverse piece i: (v, u).                if v == last and not seen[new_mask][u]:                    seen[new_mask][u] = True                    parent[new_mask][u] = (mask, last, i, 'b')
        if final_mask is not None:            break
    # The problem guarantees that a complete chain exists.    answer = []
    mask = final_mask    last = final_last
    while mask != -1:        pmask, plast, i, orientation = parent[mask][last]        answer.append((i + 1, orientation))        mask, last = pmask, plast
    answer.reverse()
    sys.stdout.write(        ''.join(f"{i} {orientation}\n" for i, orientation in answer)    )

初期化は少し微妙です。 最初のピースには左隣がないため、両方の向きが有効な開始状態になります。 2 つの端点が等しい場合、両方の方向が同じ状態になり、`seen`正しくチェックすると、そのうちの 1 つだけが保存されます。 

トランジション、オリエンテーションについて`a`その作品が`(u, v)`。 以下の場合にのみ追加できます。`u`現在のエンドポイントと等しい場合、新しいエンドポイントは次のようになります。`v`。 向き`b`手段`(v, u)`、したがって、それは必要です`v == last`そして葉を残します`u`露出。 

前の状態は、ある状態に初めて到達したときにのみ記録されます。 将来のすべての遷移は状態自体にのみ依存し、特定の部分チェーンがそれを生成したかには依存しないため、これは安全です。 

再構成は完全なマスクから開始され、初期状態マーカーまで先行ポインタに従います。`(-1, -1, ...)`に達します。 これらのポインターは逆方向に進むため、結果のリストは印刷する前に逆方向にする必要があります。 

Python では整数オーバーフローの懸念はなく、固定幅言語でもすべてのマスクは小さな整数に快適に収まります。`N <= 8`。
