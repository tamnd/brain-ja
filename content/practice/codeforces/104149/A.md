 ## 解決策
 ## 問題の理解

 それぞれがチェーン リンクを表す n 個のオブジェクトのセットが与えられています。 いくつかのリンクのペアはすでに接続されており、無向の単純なグラフを形成しています。 最終的な目標は、許可された 1 つの操作を使用して接続を再配置することです。リンクを 1 つ選択し、その現在の接続をすべて切断し、再度ロックする前に他のリンクに任意に再接続します。 この操作を最大 1 回実行した後は、すべてのリンクが他の 2 つのリンクに接続されるようにしたいと考えています。また、すべてのリンクが一緒になって、すべてのノードを 1 回だけ含む 1 つの閉じたサイクルを形成する必要があります。 

グラフ用語で言えば、ターゲット構造はすべての n 頂点にわたる単純なサイクルであり、接続された 2 つの正則グラフを意味します。 許可される操作は非常に制限されています。1 つの頂点の隣接リストを完全に「リセット」できるのは 1 回だけですが、その頂点に付随するエッジを除き、他のすべてのエッジは変更されません。 

この制約では、最大 100,000 個のノードと 200,000 個のエッジが許可されます。 選択された頂点の周囲の潜在的な再接続の数は、その次数と n に応じて組み合わせ的に増加するため、考えられるすべての再構成を探索したり、組み合わせ的にエッジの再配線をシミュレートしようとするソリューションは、すぐに失敗します。 実行可能なアプローチでは、問題をグラフ上の少数の構造チェックに減らす必要があります。 

グラフがすでにサイクルに近づいているが、局所的な欠陥がある場合、微妙なエッジ ケースが発生します。 たとえば、次数 4 の 1 つの頂点と次数 0 のもう 1 つの頂点を除いて、すべての頂点がすでに次数 2 を持っている場合、単純な次数チェックでは、操作の解釈に応じて誤って承認または拒否される可能性があります。 もう 1 つの失敗ケースは、グラフがすでに有効なサイクルであるが操作が不要な場合に発生し、アルゴリズムが操作を常に使用する必要があると誤って想定し、サイクル構造を壊します。 

## アプローチ

 ブルートフォース解釈では、操作対象の頂点を選択し、そのエッジをすべて削除し、あらゆる方法で再接続して単一サイクルを復元することをシミュレートします。 選択した頂点 v については、隣接する頂点を再接続する方法を検討し、場合によっては新しいエッジを導入して、すべての頂点の次数が正確に 2 になり、接続が維持されるようにする必要があります。 他のすべての頂点を修正したとしても、v をハミルトニアン サイクルに事実上埋め込もうとしているため、v を構造に戻す方法の数は n で指数関数的になります。 

コア要件がローカルではないため、これは失敗します。 最終的な構造はハミルトニアン サイクルであり、単一の頂点を変更することでグラフを 1 つのグラフにできるかどうかの決定は、依然としてグローバル次数と接続性の制約によって決まります。 重要な観察は、サイクル内では、すべての頂点の次数が正確に 2 であるということです。したがって、最初のグラフでは、おそらく変更された頂点を除くすべての頂点の次数がすでに最大 2 でなければなりません。実際、有効な解では、選択した頂点以外で次数を減らすことはできないため、実際にはちょうど 2 です。 

これにより、直ちに強力な構造が強制されます。最終構成では最大 1 つの頂点が次数 2 に違反することができ、その頂点がまさに変更を許可される頂点になります。 他のすべての頂点は、最初のグラフで既に次数 2 を持っている必要があります。これは、頂点に付随するエッジを削除できず、サイクル内で次数を 2 を超えて増やすことができないためです。 したがって、エッジが間違っている 1 つの頂点を除いて、グラフはほぼすでにサイクルになっています。

問題は、頂点 v が存在するかどうかをチェックすることに帰着します。つまり、v に付随するすべてのエッジを無視すると、残りのグラフはすでに n 個の頂点から v の役割を差し引いた単一の単純なサイクルであり、v を適切に再接続して完全なサイクルを復元できることになります。 これは非常に強力な必要条件を意味します。v 以外のすべての頂点は既に次数 2 を持っていなければならず、残りの構造は v を介して閉じることができる単一のパスを形成する必要があります。 

したがって、解決策は、次数分析と、1 つの頂点を削除したグラフの接続性チェックになります。

 ## アルゴリズムのチュートリアル

 まず、入力エッジからすべての頂点の次数を計算します。 これにより、頂点がすでにサイクル内にあることと互換性があるかどうかに関する情報がすぐに得られます。 

次に、変更される頂点の候補を特定します。 他のすべての頂点は最終構造で既に次数 2 を満たしている必要があるため、次数が 2 に等しくない頂点が唯一の可能な変更点になります。 このような頂点が複数ある場合、解決策はありません。 

2 以外の次数を持つ頂点がない場合、グラフはすでに互いに素なサイクルの集合です。 その場合、それが正確に 1 サイクルであること、つまりグラフが接続されていることを確認する必要があります。 そうしないと、単一の許可された操作を使用してサイクルをマージできないため、答えは「いいえ」になります。 

次数が 2 と異なる頂点 v が 1 つだけ存在する場合、v とそのすべての入射エッジの削除をシミュレートします。 この削除後、残りのすべての頂点は、非常に特殊なパターンで厳密に 2 または 1 の次数を持つ必要があります。残りの構造は、v に接続された近傍の端点が正確に一致する単一のパスである必要があります。 

次に、v を削除した後、v に付随するエッジを無視してグラフの接続性をチェックします。残りの頂点がすべて接続されて単純なパス構造を形成している場合 (つまり、ちょうど 2 つの頂点が次数 1 で、他のすべての頂点が次数 2 である場合)、v をこれら 2 つの端点に接続することで再挿入でき、単一のサイクルを形成します。 

最後に、これらの条件が当てはまる場合は「yes」を出力し、そうでない場合は「no」を出力します。 

### なぜ効果があるのか

 有効な最終構成では、グラフは単一サイクルであり、すべての頂点に対して次数が正確に 2 に強制されます。 変更できる頂点は 1 つだけなので、他のすべての頂点は最初のグラフでこの条件をすでに満たしている必要があります。 これにより、最大 1 つの頂点が次数 2 に違反できる剛構造が強制され、すべての構造的矛盾がそこに集中する必要があります。 その頂点を削除すると、問題は残りのグラフがすでに、削除された頂点を再接続することでサイクルに閉じることができる単純なパスであるかどうかをチェックすることになります。これはまさに許可された操作です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    deg = [0] * n

    edges = []
    for _ in range(m):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        adj[a].append(b)
        adj[b].append(a)
        deg[a] += 1
        deg[b] += 1
        edges.append((a, b))

    bad = [i for i in range(n) if deg[i] != 2]

    if len(bad) == 0:
        # must already be a single cycle
        vis = [False] * n
        stack = [0]
        vis[0] = True
        cnt = 1
        while stack:
            v = stack.pop()
            for to in adj[v]:
                if not vis[to]:
                    vis[to] = True
                    stack.append(to)
                    cnt += 1
        print("yes" if cnt == n else "no")
        return

    if len(bad) != 1:
        print("no")
        return

    bad_v = bad[0]

    # remove bad_v implicitly
    vis = [False] * n
    stack = []

    start = -1
    for i in range(n):
        if i != bad_v and deg[i] > 0:
            start = i
            break

    if start == -1:
        print("no")
        return

    stack.append(start)
    vis[start] = True
    cnt = 1

    while stack:
        v = stack.pop()
        for to in adj[v]:
            if to == bad_v:
                continue
            if not vis[to]:
                vis[to] = True
                stack.append(to)
                cnt += 1

    # count remaining vertices
    remaining = n - 1
    if cnt != remaining:
        print("no")
        return

    # check degree structure after removal
    deg2 = 0
    deg1 = 0

    for i in range(n):
        if i == bad_v:
            continue
        d = sum(1 for to in adj[i] if to != bad_v)
        if d == 1:
            deg1 += 1
        elif d == 2:
            deg2 += 1
        else:
            print("no")
            return

    if deg1 == 2 and deg2 == n - 3:
        print("yes")
    else:
        print("no")

if __name__ == "__main__":
    solve()
```このソリューションは、構造違反を直ちに検出するために必要な隣接リストを構築し、次数を計算することから始まります。 セット`bad`現在の状態でサイクルに属せないすべての頂点をキャプチャします。 

不良な頂点がない場合、グラフはすでにサイクルの結合になっているはずです。 次数制約を破らずにコンポーネントを結合する操作を実行することはできないため、単純にグラフが接続されていることを確認します。 

不良頂点が 1 つだけ存在する場合は、概念的にそれを削除し、残りの構造を分析します。 DFS は、誘導されたサブグラフの接続性を保証します。 トラバースおよび次数チェック中に、削除された頂点に付随するエッジを明示的に無視します。これにより、許可された操作が正確にシミュレートされます。 

最後の次数条件は、残りのグラフが次数 1 の端点を 2 つだけ持つ単純なパスであることを強制します。これらの端点は、削除された頂点が再接続されてサイクルを形成する場所に対応します。 

## 実用的な例

 ### 例 1

 入力:```
4 3
1 2
2 3
2 4
```ここで度は`[1, 3, 1, 1]`。 頂点 2 が変更の唯一の候補です。 

| ステップ | アクション | 残りのグラフ状態 |
 | --- | --- | --- |
 | 1 | 不正な頂点を特定 = 2 | ノード 1、3、4 が残ります |
 | 2 | 頂点 2 を削除 | エッジが削除されました |
 | 3 | 接続を確認する | 1、3、4 は元の構造を介して切断されています。 
| 4 | 度チェック | 3 つ以上のエンドポイント |

 残りの構造は、2 を除くすべてのノードをカバーする単一のパスではないため、答えは「いいえ」です。

 入力:```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```すべての頂点の次数は 3 であるため、すべての頂点が不良です。 

| ステップ | アクション | 状態 |
 | --- | --- | --- |
 | 1 | 不正な頂点を数える | 4 |
 | 2 | チェック制約 | 複数の不良頂点 |
 | 3 | 拒否 | 即時失敗 |

 これにより、密なグラフは 1 回の変更では修正できないことがわかります。

 ## 特殊なケース

 重要なエッジケースは、グラフがすでにサイクルになっている場合です。 この場合、次数が 2 と異なる頂点はないため、アルゴリズムは「すでに有効な」分岐に入り、接続性のみをチェックします。 サイクルが複数のコンポーネント (たとえば 2 つの互いに素な三角形) に分割されている場合、DFS カウントは n 未満になり、答えは正確には「いいえ」になります。 

もう 1 つのエッジ ケースは、複数の頂点が次数 2 に違反する場合です。たとえば、中心が他のすべての頂点に接続されている星型グラフでは、多くの不正な頂点が生成されます。 変更できる頂点は 1 つだけであるため、アルゴリズムはすぐに拒否します。これは、単一の再配線ではすべての超過次数をサイクル構造に正しく分配できないという事実と一致します。
