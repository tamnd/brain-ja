 ## 解決策
 ## 問題の理解

 ハリーはまさに砂漠の中心に到達しようとしています。$d$彼が一人で歩けば数日かかる。 毎日、一人当たり 1 単位の水を消​​費します。 ハリーとすべての友人を含め、各人が持ち運べるのは最大でも$c$合計で水の単位があり、グループが一緒にいる間、水はグループ間で自由に再分配できます。 

友人たちはハリーの旅の一部に同行し、その後同じ道を通って最初の場所に戻ることが許可されています。 帰国する友人は、帰りの旅行を生き抜くのに十分な水を持っていなければなりません。往復の日数は、引き返す時点で既に移動していた往路の距離と全く同じ日数がかかります。 ハリーの目標は自分自身が目的地に到達することだけであり、戻ることではありません。 

重要な問題は、友人は単に定期的な旅行のための追加の輸送能力ではないということです。 これらは一時的な運送業者であり、送り返された場合には往路と復路の両方で生き残らなければなりません。 これにはトレードオフが生じます。友人が増えると総水容量は増加しますが、帰国する旅行者は復路に備えて十分な準備をしなければならないため、追加の水の義務も生じます。 

入力により得られるのは、$d$、目的地に到着するまでの日数、$c$、各人が持ち運べる水の最大量。 出力は、ハリーが生きて目的地に到着するために必要な最小限の友人の数、または任意の数の友人がいても制約が満たされない場合は不可能です。 

最初のエッジケースが現れるのは、$c = 1$。 すべての人が正確に 1 ユニットの水を持ち運ぶことができ、1 日あたり 1 ユニットを消費します。つまり、1 日の旅行でも生き残ることができる人はいないということです。 もし$d \ge 1$, ハリーだけではすでに失敗しており、友達を追加しても全員が同じ動作をするため役に立ちません。 正しい出力は不可能です。 

別の微妙なケースが発生する場合$c$小さいですが$d$大きいです。 素朴な直観は、十分な数の友人が常に問題を解決することを示唆するかもしれませんが、友人が戻ってくると、外へ歩いた長さに比例して長い帰り道に水を運ぶ必要があるため、非常に高価になります。 

より構造化された失敗例は次のような場合です。$c$は 1 をわずかに上回る程度です。たとえば、$c = 2$、$d = 10$。 1 人あたり 1 日の生存を超える追加ユニットは 1 つだけであるため、ヘルパーが戻る必要があるまでにどこまで移動できるかが大幅に制限されます。 

## アプローチ

 直接的なブルートフォースアプローチでは、可能な限り多くの友人を試すことになります。$k$、そしてハリーが距離に到達することが可能かどうかをシミュレートします$d$と$k$ヘルパーたち。 構成ごとに、グループが毎日どこまで進むことができるか、どのくらいの水が消費されるか、友人がいつ引き返さなければならないかを追跡します。 シミュレーションを慎重に最適化したとしても、各実現可能性チェックは、最大のシミュレーションに依存します。$d$数日間、または少なくとも複数の転換点、および$k$まで行くことができます$d$最悪の推論で。 これはおおよそ次のことにつながります$O(d^2)$または、それよりも悪い行動は不可能です。$d \le 10^9$。 

重要な観察は、日々の動きをシミュレートする必要がないということです。 代わりに、有効な戦略に必要な水の総予算と、それを供給するために何人の人員が必要かについて推論するだけで済みます。 

問題を再構成する有効な方法は、各友人を再利用可能な「水の容器」として想像することです。この容器は、その場にいる間は容量に貢献しますが、戻る時には負担になります。なぜなら、帰りに十分な水を持っていかなければならないからです。 重要な制約は、グループがいつでも、アクティブな往路旅行者全員と復路旅行者全員を同時にサポートできなければならないことです。 

これにより、単調な構造が得られます。$k$友達だけで十分、それなら誰でもいい$k' > k$も十分です。 この単調性により、答えの二分探索が可能になります。 残りのタスクは実現可能性のチェックです。$k$, ハリーをサポートできるかどうかを判断します。 

実現可能性のチェックは、友人が引き返すまでにどのくらいの時間滞在できるかについての貪欲な推論に帰着します。 友人が後で引き返した場合$x$日、少なくとも持ち歩く必要があります$x$返品の単位に加え、返品中の 1 日あたり 1 単位がすでに対称的に考慮されています。 主要な制約は、運ばれる水が容量内で両足をカバーしなければならないということになります。$c$。 これは、友人 1 人あたりの最大有効ツアー長を意味し、したがって、各友人がハリーの前進に貢献できる「範囲」の限度が決まります。 

最適な解決策は、各友人が提供できる効果的な「追加サポート日数」を計算し、到達するまで貢献を蓄積することで導き出されます。$d$。

 ## アルゴリズムのチュートリアル

 友達の数を扱います$k$推測として、それが十分であるかどうかを確認してください。 

1.固定の場合$k$のシステム全体を考えてみましょう。$k+1$人、それぞれに能力がある$c$、合計水分を与える$(k+1)c$。 これは、時刻 0 での利用可能なリソース プールの合計です。 
2. アクティブ グループ全体が生き残るには、現在前進している人の数が正確に消費されます。 複雑なのは、一部の友人が戻ってくる可能性があることですが、戻っても消費が復帰フェーズに移行するだけです。 
3. 中心的な考え方は、「サポート」できる最大可能前方距離を計算することです。$k$返品の制約に違反することなく友達になります。 各友達を数日間転送できます$t$ただし、戻るのに十分な水を保持する必要があります$t$したがって、彼らの前向きの参加は次のように制限されます。$c = t + t_{\text{return}} + \text{ongoing consumption}$、これは、どれだけ長く有用であり続けるかについての線形制約に集約されます。 
4. 効果的な貢献度を導き出します。友人が貢献できるのは最大でも$c - 1$生き延びるだけで 1 日あたり少なくとも 1 ユニットを費やさなければならないため、帰還のために水を保存する必要があるまでに、正味余分な日数が必要になります。 
5. 貢献を概念的に分類または蓄積します。$k$友達、追加サポートの合計は$k \cdot (c - 1)$。 ハリー自身は貢献のみ$c$返品の制約を必要とせずに生存できる日数。 
6.トータルで効果的なサポートができているか確認します$c + k(c - 1)$少なくとも到達する$d$。 「はい」の場合、$k$で十分です。 
7. 最小値を二分探索します$k$で$[0, d]$この条件を満たしていること。 
8. たとえ非常に大きい場合でも$k$不等式を満たさない場合は、不可能と出力します。 

### なぜ効果があるのか

 不変条件は、前進の各ユニットはちょうど 1 人のアクティブな参加者から正確に 1 ユニットの水を消費し、引き返す友人は前進への関与に等しい対称コストを支払わなければならないということです。 この対称性により、線形会計モデルが強制されます。つまり、追加の各フレンドは、スケジューリングとは独立して、固定の限界量の使用可能な転送耐久性を提供します。 どの戦略も容量を超えて水を再利用できないため$c$1 人あたりの線形限界は厳しく、実行可能なスケジュールはすべて、$d$に制限された貢献に分割する$c$そして$c-1$増加します。 したがって、不等式をチェックすることで、実現可能性を正確に特徴付けることができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can(k, d, c):
    # Harry + k friends
    # total effective forward capacity
    return c + k * (c - 1) >= d

def solve():
    d, c = map(int, input().split())

    if c == 1:
        print("impossible" if d > 0 else 0)
        return

    lo, hi = 0, d
    ans = None

    while lo <= hi:
        mid = (lo + hi) // 2
        if can(mid, d, c):
            ans = mid
            hi = mid - 1
        else:
            lo = mid + 1

    if ans is None:
        print("impossible")
    else:
        print(ans)

if __name__ == "__main__":
    solve()
```機能`can(k, d, c)`導出された実現可能性の不等式をエンコードします。 二分探索では、友人数の単調空間を探索します。 特別な場合`c == 1`不平等が悪化するため、別々に処理されます。参加者は 1 日でも生き残ることができず、正の距離は不可能になります。 

主な微妙な点は、いかなる動きもシミュレートしないようにすることです。 前進と復帰のすべてのダイナミクスは、単一の線形容量表現に圧縮されます。

 ## 特殊なケース

 いつ$c = 1$, 誰もが1日に持ち運べる量を正確に消費するため、ハリーだけでも最初のステップを生き残ることはできません。 アルゴリズムは、二分探索を入力せずにすぐに不可能を返し、次の制約に一致します。$c + k(c-1)$1を超えることはありません。 

のために$d = 1, c = 2$、小切手は与えます$2 + 0 = 2 \ge 1$, so zero friends are sufficient. ハリーだけで 1 日分の容量があるため、アルゴリズムは正しく 0 を出力します。 

大型用$d$そして小さい$c$、 のような$d = 10^9, c = 2$, 必要なフレンド数が非常に多くなります。 二分探索では次まで探索します。$d$、ただし、実現可能性は傾きに応じて線形に増加するため、それでもすぐに収束します。$c-1 = 1$、したがって、答えはおよそ$d - c$、これは不等式チェックと一致します。
