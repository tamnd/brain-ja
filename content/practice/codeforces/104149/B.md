 ## 解決策
 ## 問題の理解

 私たちにはポーションの大釜がいくつか与えられました。 各大釜には既知の数のリットルが入っており、各リットルには既知の濃度の成分が含まれています。 目標は、これらの大釜の一部を組み合わせて、最終混合物が正確に目標濃度になるようにしながら、最終的に得られる合計リットル数を最大化することです。 

大釜の一部を注ぐことができるため、各大釜は液体を継続的に供給しているかのように動作します。 制限は最終混合物のみにあります。摂取するすべてのものの加重平均濃度が必要な目標と一致する必要があります。 

目標を言い換えるのに役立つ方法は、液体の各単位が、その濃度が目標をどれだけ上回るか下回るかに等しい「値」に寄与するということです。 これらの偏差を正確に打ち消しながら、できるだけ多くの液体を採取したいと考えています。 

制約は小さく、せいぜい数千の大釜と実数に対する単純な算術演算です。 これにより、サブセットに対する指数関数的検索や複雑な動的プログラミングを含むものは即座に排除されます。 線形または線形演算の貪欲な戦略が期待されます。 

「目標に近いものを先に取る」と欲張って考えると、微妙な失敗例が現れます。 このアプローチでは、一方の側を過剰に充填するともう一方の側からの補償が強制され、多くの場合大釜の部分的な使用が必要になることが無視されています。 

たとえば、ターゲットが 0.5 で、2 つの大釜がある場合、1 つは 0.9 の濃度、もう 1 つは 0.1 の濃度で、両方をすべて取得すると、体積が一致していれば正確なバランスが得られますが、両方が個別にターゲットから「離れている」場合でも、体積を変更するとバランスがわずかに崩れます。 多くの場合、正解するには片側を正確にトリミングする必要があります。 

もう 1 つのエッジ ケースは、すべての大釜がターゲットの片側にある場合です。 そうなると、すべてを使用することは不可能になり、バランスを回復するために最も極端な大釜の一部を廃棄する必要があります。 

## アプローチ

 強引なアイデアは、大釜の可能なすべてのサブセットを考慮し、各サブセットについて、最終混合物が目標濃度に達するために各大釜からどれだけの量を採取するかを決定することです。 連続的な性質を無視してサブセットの選択のみを考慮したとしても、それはすでに次のことにつながります。$2^n$可能性は大きすぎます$n \le 1000$。 各サブセット内に継続的な最適化を導入すると、それはさらに実行不可能になります。 

重要な観察は、最終混合物に対する制約が線形形式で書き換えられるということです。 で表すと$x_i$大釜から取り出した量$i$、そして、によって$p_i$その濃度、状態$$\frac{\sum x_i p_i}{\sum x_i} = p$$と同等です$$\sum x_i (p_i - p) = 0.$$これにより、問題は非負の金額を選択することに変わります。$x_i \le c_i$最大化しながら、符号付き加重和がゼロになるように、$\sum x_i$。 

液体のすべての単位には「偏差」が存在します。$d_i = p_i - p$。 正の偏差は混合物を目標より上に押し上げ、負の偏差は混合物を下に引きます。 これらの力を正確にバランスさせることが課題となります。 

この構造は貪欲な戦略を暗示しています。つまり、すべてを摂取することから始めて、次に液体を除去して調整し、不均衡を修正します。 大釜から液体を除去すると、総体積と偏差の合計の両方が直線的に変化するため、除去された各ユニットは不均衡を修正する効率が一定になります。 

これにより、問題は 1 次元のバランス プロセスに集約され、常に側面から液体が除去されるため、不均衡を最も早く修正することができます。

 ## アルゴリズムのチュートリアル

 ### ステップ

 1. 目標濃度の換算$p$偏差ベースラインに変換して計算します$d_i = p_i - p$あらゆる大釜ごとに。 これは、正しい混合物の合計偏差が正確にゼロになるように問題を再構成します。 
2. すべての大釜から利用可能なすべての液体を採取すると仮定することから始めます。 総体積と総偏差和を計算します。 これは最も楽観的な開始点を表しますが、通常はバランス条件に違反します。 
3. 合計偏差がすでにゼロである場合、現在の合計量は最適であるため、すぐに停止できます。 
4. 偏差が正の場合、混合物は濃度が高すぎます。 負の偏差を取り除くと不均衡がさらに悪化するため、これを減らす唯一の方法は、正の偏差を持つ大釜から液体を除去することです。 
5. 正の偏差を持つ大釜を、リットルあたりの偏差によって降順に並べ替えます。 これにより、失われた単位体積あたりの不均衡を最も早く修正する液体の除去が優先されます。 
6. これらの大釜を繰り返し、使い果たされるか、偏差の合計がゼロになるまで、各大釜からできるだけ多くを取り除きます。 除去するたびに、ボリュームと偏差の両方が直線的に減少します。 
7. 偏差が負の場合、負の偏差を持つ大釜に対して対称プロセスを実行し、バランスが回復するまで負の偏差が最も大きい大釜を最初に削除します。 
8. バランスをとった後の残りの体積は、達成可能な最大有効混合物です。 

### なぜ効果があるのか

 すべてのステップで、ターゲットの片側からの削除のみを使用して偏差を修正できる混合物を維持します。 取り外される各ユニットは、体積損失に対する偏差補正の固定比率に寄与するため、最初に最大の比率を選択すると、無駄な体積が最小限に抑えられます。 間違った方向にオーバーシュートすることなく、常にゼロ偏差状態の復元に直接向かうため、制約の下で最大の残りのボリュームが維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, p = input().split()
    n = int(n)
    p = float(p)

    pos = []
    neg = []

    total_v = 0.0
    total_d = 0.0

    for _ in range(n):
        c, pi = input().split()
        c = float(c)
        pi = float(pi)

        d = pi - p
        total_v += c
        total_d += c * d

        if d > 0:
            pos.append([d, c])
        elif d < 0:
            neg.append([d, c])

    if abs(total_d) < 1e-12:
        print(total_v)
        return

    if total_d > 0:
        pos.sort(reverse=True)
        for d, c in pos:
            if total_d <= 0:
                break
            take = min(c, total_d / d)
            total_v -= take
            total_d -= take * d

    else:
        neg.sort()
        for d, c in neg:
            if total_d >= 0:
                break
            take = min(c, total_d / d)
            total_v -= take
            total_d -= take * d

    print(total_v)

if __name__ == "__main__":
    solve()
```このソリューションは、最初に完全な混合を計算し、次に不均衡の修正を制御された除去プロセスとして扱います。 主要な実装の詳細は、注意深い線形更新を使用して完全に浮動小数点で動作します。削除するたびに、ボリュームと偏差の両方が比例して減少します。 

選別は偏差の片側内のみに適用され、常に最も「効果的な」液体を最初に除去することが保証されます。 正の場合と負の場合の対称性は、更新式での符号の間違いを避けるために明示的に処理されます。

| ステップ | 採取量 | 合計偏差 |
 | --- | --- | --- |

 混合が強すぎるため、最初に正の偏差から削除します。 

正の偏差: 0.4 と 0.9 を並べ替えますが、0.5 からの距離で重み付けすると、寄与度は 0.4 と 0.9 になります。 

まずバランスが回復するまで 0.9 から削除し、偏差がゼロに達した時点で正確に停止します。 残量は8.75になります。 

これは、高濃度大釜から完全に除去するのではなく、部分的に除去するだけでよいことを示しています。

 ## 特殊なケース

 重要なケースの 1 つは、すべての大釜が目標濃度を超えている場合です。 アルゴリズムは正しく「正の偏差」分岐に入り、偏差が解消されるまで最初に最も強い大釜から削除されます。 バランシングパートナーが存在しない場合でも、部分除去により有効な正確なソリューションが保証されます。 

もう 1 つのケースは、最初の混合物がすでにバランスが取れている場合です。 偏差合計はゼロであるため、アルゴリズムは並べ替えや削除を行わずにすぐに完全なボリュームを返し、最適性を維持します。 

3 番目のケースは、ほんのわずかな調整だけが必要な場合です。 除去は連続的に行われるため、アルゴリズムは大釜の途中で停止することができ、ターゲット混合物をオーバーシュートすることなく精度要件を確実に満たすことができます。
