 ## 問題の理解

 ## アルゴリズムのチュートリアル

 私たちは、あらゆる候補値に対して、$X$、有効なペアの数を数えることができます$(a, b)$適当な数字を出す$\le X$、このカウントは次のように増加します。$X$が増加します。 

1. 関数を定義します`count(X)`最大で値を生成する有効な構造の数を計算します。$X$。 この関数は単調関数です。$X$制約を緩和するだけです。 
2. 計算するには`count(X)`の可能な値を反復処理します。$a$。 固定ごとに$a$、有効を定義する条件$b$1 つの変数では不等式になります。 

ペアを検索する代わりに、問題を有効な数をカウントすることに減らすため、これは非常に重要です。$b$それぞれの範囲$a$。 
3. それぞれについて$a$、許容される最大値を導き出します。$b$構築された値が超えないように$X$。 これにより上限が決まります$b_{\max}(a)$。 
4. 必要なため$a < b$、有効な数$b$固定値$a$は：$$\max(0, b_{\max}(a) - a)$$5. これらの貢献を全体的に合計します$a$その間$a$実現可能な範囲内に留まります（つまり、$O(\sqrt{X})$式の二次成長による)。 
6. 最小値を二分探索します$X$そのような`count(X) >= N`。 問題の答えはこれです$X$。 

### なぜ効果があるのか

 この構造では、整数のペアから決定論的なマッピングを定義します。$(a, b)$正の整数に変換します。 固定の場合$X$、述語「このペアは値 ≤ を生成しますか?」$X$” は両方の変数で単調です。これにより、それぞれの変数について$a$、有効な$b$-値はプレフィックス間隔を形成します。 その結果、合計カウントは連続する整数範囲の合計となり、単調性が維持されます。$X$。 この単調な構造により、バイナリ検索の正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def count(x):
    # counts number of valid (a, b) pairs with a < b
    # derived from simplified geometric relation: value = a * b + a + b
    # (this is the standard reduction for this problem)
    res = 0
    a = 1
    while a * a <= x:
        # inequality: a*b + a + b <= x
        # (a+1)(b+1) <= x+1
        # so b+1 <= (x+1)//(a+1)
        max_b = (x + 1) // (a + 1) - 1
        if max_b > a:
            res += max_b - a
        a += 1
    return res

def solve():
    n = int(input())

    lo, hi = 1, 10**18
    ans = hi

    while lo <= hi:
        mid = (lo + hi) // 2
        if count(mid) >= n:
            ans = mid
            hi = mid - 1
        else:
            lo = mid + 1

    print(ans)

if __name__ == "__main__":
    solve()
```コードで使用されている中心的な単純化は、次の変換です。$(a+1)(b+1) \le x+1$の制約を線形化します。$b$固定用$a$。 これにより、各反復が可能になります$a$有効な範囲全体を計算するには$b$-一定時間内の値。 

二分探索は回答空間全体にわたって実行され、`count`関数を使用すると、任意の中間点を効率的にテストできます。 の上限$10^{18}$式はパラメーター内で二次関数的に増加するため、安全です。 

微妙な実装の詳細が強制されています$b > a$。 無効なプレフィックスを減算せずに$b \le a$、重複と無効な構造が含まれ、カウントがシフトし、単調性が崩れます。

 ## 特殊なケース

 1 つまたは 2 つのペアだけが不等式を満たす、最小値で 1 つのエッジ ケースが表示されます。 のために$x = 1$または$x = 2$、無効です$(a, b)$と$a < b$が存在するため、最初の有効な値は不等式が最初に認められる場合にのみ表示されます。$a = 1, b = 2$。 アルゴリズムはこれを処理します。`count(x)`制約が満たされるまで 0 を返します。 

もう 1 つのエッジケースは次のような場合です$b$かろうじて超える$a$。 引き算`max_b - a`とペアリングすることを保証します$b \le a$除外されるため、バイナリ検索のしきい値が誤ってシフトされる可能性がある過剰なカウントが防止されます。
