 ## 解決策
 ## 問題の理解

 2 つの整数、目標合計が与えられます。`s`と制約値`x`。 タスクは、要素が正確に合計される配列を構築することです。`s`ただし、配列内のすべての要素は互いに素である必要があります。`x`。 ここでの「共素」とは、各要素が共通の素因数を共有しないことを意味します。`x`。 

考えられるすべての有効な配列の中で、可能な限り最小の長さの配列を作成するように求められます。 そのような配列が存在しない場合は、不可能であることを報告する必要があります。 

この問題の重要な緊張関係は 2 つの要件の間にあります。合計制約により、正確に結合する値を慎重に選択する必要があります。`s`一方、共素性制約は、構成要素として許可される数値を制限します。 最も短い配列が必要なため、絶対値が大きくなると必要な要素の数が減るため、互いに素の条件を満たしながら各要素の大きさをできるだけ大きくすることが暗黙的に望まれます。 

制約`s, x ≤ 10^9`どのソリューションもテスト ケースごとに一定時間または対数時間で実行する必要があることを示唆しています。 考えられるすべての候補を反復処理したり、すべての数値を繰り返し因数分解したりすることはできません。 代わりに、互いに素な数の構造的特性に依存する必要があります。`x`。 

微妙なエッジケースが現れるのは、`x`非常に制限的です。たとえば、`x = 2`。 その場合、奇数のみが許可されます。 もし`s`が偶数の場合でも、奇数の合計として表すことは可能ですが、パリティにより偶数の項を使用する必要があります。 もし`s`が奇数である場合、多くの場合、以下に等しい単一の奇数を使用できます。`s`。 これは、解が純粋に大きさを貪欲なものではなく、算術構造にも依存することをすでに示唆しています。 

常に使用しようとすると、別の重要な障害モードが発生します。`s`それ自体が 1 つの要素として扱われます。 これは次の場合にのみ機能します`gcd(s, x) = 1`。 そうでない場合は分解する必要があります`s`許可された複数の部分に分割します。 

## アプローチ

 ブルートフォース戦略では、各ステップで以下と互いに素になる有効な整数を選択して、配列を段階的に構築しようとします。`x`そして残りの合計からそれを差し引きます。 有効な整数は基本的に、次の素因数で割り切れないすべての整数であるため、`x`、これにより膨大な検索スペースが得られます。 正の数に限定しても、可能性の数は大きさに応じて直線的に増加します。`s`まで可能です。`10^9`、このアプローチは実行不可能になります。 

重要な洞察は、問題を、慎重に選択した 2 つの数値のみを使用して合計を計算することに帰着させることです。 最初の観察は、次のような場合です。`s`それ自体は互いに素である`x`の場合、最適な配列の長さは 1 になります。 それ以外の場合は調整する必要があります`s`と互いに素な近くの値に変換します。`x`導入する補正の量を制御しながら。 

2 番目の観察は、任意の 2 つの連続する整数のうち、少なくとも 1 つは任意の固定整数と互いに素であるということです。`x`ない限り`x`は両方に因数を共有させる非常に小さな構造を持っていますが、その場合、ペアの加算と減算が割り算を変更しながら合計を保持するという事実を利用できます。 これは建設的なアイデアにつながります。`s`最大 3 つの整数の組み合わせとして、通常は 1 つの大きな共素アンカーと小さな補正項、または合計が一致する 2 つの共素数`s`。 

最小の分解を検索します: 1 つの数値または 2 つの数値のいずれか`a`そして`b`そのような`a + b = s`そして両方とも互いに素です`x`。 これが不可能な場合、問題保証の下では 3 項構成が常に存在しますが、縮退していないすべてのケースで 2 項を使用して最適解がすでに達成されています。 

この構築は、有効な値を見つけることになります。`a`そのような`gcd(a, x) = 1`そして`gcd(s - a, x) = 1`。 gcd のチェックは O(log x) なので、一定数の候補を試すことができます。`s`、 通常`s`、`s-1`、`s-2`、または同様に制限されたオフセット。小さなシフトの間で、少なくとも 1 つのペアが次のすべての素因数を回避するためです。`x`。

 ## アルゴリズムのチュートリアル

 1.次のことを確認します`s`と互いに素である`x`。 もし`gcd(s, x) = 1`、単一要素の配列を出力します。`[s]`。 配列を短くすることは不可能であり、配列を長くすると長さが不必要に増加するため、これは最適です。 
2. それ以外の場合は、長さ 2 の配列の構築を試みます。次の形式の候補分割を試みます。`a + b = s`どちらも`a`そして`b`と互いに素である`x`。 自然検索セットは次のとおりです。`a ∈ {s-1, s-2, s-3, s-4}`対応する`b = s - a`。 有効な分割が存在する場合、少なくとも 1 つの小さな摂動が存在するため、各ペアをテストします。`s`～の素因数を避ける`x`。 
3. 各候補ペアについて`(a, b)`、計算する`gcd(a, x)`そして`gcd(b, x)`。 両方とも 1 の場合、出力`[a, b]`。 
4. 有効なペアが存在しない場合は、長さが保証された構造にフォールバックします。 3. 相対的に互いに素の固定アンカーを 2 つ選択します。`x`、たとえば最小の整数`i`そして`j`両方が互いに素であるように`x`。 次に、次のように係数を調整します。`i + j + k = s`、 どこ`k`も素です`x`。 この問題は、そのような構造が常に境界内に存在することを保証します。 

重要なのは、失敗は次の場合にのみ発生するため、小さなオフセットでの検索が機能することです。`x`因子を多数の連続する整数と共有します。これは非常に小さな構造化された場合にのみ可能です。`x`この場合、修正ステップが有効になります。 

### なぜ効果があるのか

 このアルゴリズムは、固定された`x`は、素数の固定された有限セットを回避することによって決定されます。 連続する整数はすべて同じ制限された因数構造を無限に共有することはできないため、小さなウィンドウ内で`s`すべての禁止された約数を回避する分解を見つけることが保証されています。 これにより、フォールバックによって明示的にカバーされる異常な位置合わせの場合を除き、大規模な構築を必要とせずに、単一の有効な要素が存在するか、または 2 要素のパーティションが存在することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def solve():
    s, x = map(int, input().split())

    if math.gcd(s, x) == 1:
        print(1)
        print(s)
        return

    # try small perturbations
    for a in range(s, max(0, s - 10), -1):
        b = s - a
        if a > 0 and math.gcd(a, x) == 1 and math.gcd(b, x) == 1:
            print(2)
            print(a, b)
            return

    # fallback (problem guarantees existence)
    for a in range(1, 100):
        if math.gcd(a, x) == 1:
            for b in range(1, 100):
                if math.gcd(b, x) == 1:
                    c = s - a - b
                    if c > 0 and math.gcd(c, x) == 1:
                        print(3)
                        print(a, b, c)
                        return

    print(-1)

if __name__ == "__main__":
    solve()
```最初のブランチは、最適な長さ 1 のケースを直接処理します。 2 番目のループは、次の 2 要素分解を見つけようとします。`s`これは、共素性を維持しながら、部分の 1 つを大きく保つ必要があるため、有効な分割が存在する可能性が最も高い場所です。 最後のフォールバックは、小さな共素アンカーを列挙し、2 項の試行が失敗した場合に 3 項の表現が常に存在するという保証に依存します。 

の使用`gcd`各呼び出しは対数関数であるため、制約の下では安全です。`x`、試行回数は一定です。 

## 実用的な例

 インプットを考慮する`s = 9, x = 6`。 まず確認します`gcd(9, 6) = 3`したがって、単一の要素は無効です。 9付近のスプリットを試してみます。 

| | b = 9 - a | gcd(a,6) | gcd(b,6) | 有効 |
 | --- | --- | --- | --- | --- |
 | 9 | 0 | 3 | 6 | いいえ |
 | 8 | 1 | 2 | 1 | いいえ |
 | 7 | 2 | 1 | 2 | いいえ |
 | 6 | 3 | 6 | 3 | いいえ |

 有効な 2 項分割が存在しないため、フォールバックします。 5 や 7 などの小さな共素アンカーを選択します (どちらも 6 と互いに素です)。 次に、3 番目の値を次のように調整します。`9 - 5 - 7 = -3`ただし、問題では絶対値が許容されるため、`10^9`、そして共素性は符号を無視します、`-3`は有効です。`gcd(3,6)=3`は 1 ではないため、有効なトリプルが見つかるまで別の方法で調整します。 最終的には次のような有効な組み合わせになります`-7, -7, 23`サンプルのアイデアと一致するものが表示されます。 

これは、単純な分割が失敗した場合のフォールバック構築の必要性を示しています。 

ここで考えてみましょう`s = 14, x = 34`。 ここ`gcd(14, 34) = 2`, つまり、1つの要素は不可能です。 試しています`a = 13`、`b = 1`両方とも 34 と互いに素になります。配列`[13, 1]`合計は 14 となり、制約を満たし、2 要素構成が成功したことがわかります。

 ## 特殊なケース

 いつ`s`すでに互いに素である`x`、 例えば`s = 17, x = 6`、アルゴリズムはすぐに戻ります`[17]`そして不必要な分解を避けます。 これは最適な単一要素シナリオをカバーし、最小限の長さを保証します。 

いつ`x`小さくて高度に複合されている、など`x = 6`、多くの小さな整数が同時に共素性テストに失敗します。 この状況では、アルゴリズムはシフトに依存します。`a`から少し離れて`s`両方まで`a`そして`s-a`共有要因を避ける。 のために`s = 14`、`x = 6`、有効な分割は次のとおりです。`13 + 1`、ループは最終的にそれを見つけます。 

単純な 2 要素構成とシフトされた 2 要素構成の両方が失敗した場合、フォールバックは互いに素のアンカーの密なセットから 3 項表現を構築することで正確さを保証します。 中間推論で符号の問題や負の値が示唆される場合でも、共部性は絶対値にのみ依存するため、負の補正は、その大きさが次の要因を回避する限り有効であり続けます。`x`。
