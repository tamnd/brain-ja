 ## 解決策
 ## 問題の理解

 部分的な計量情報から幾何学的オブジェクトを再構成するように求められます。 平面内に、頂点が整数座標上にある正方形があります。 A と呼ばれる頂点の 1 つは、正の y 軸上のどこかに配置されるように制約されています。これは、その x 座標がゼロで、y 座標が正の整数であることを意味します。 原点 O は (0, 0) に固定されます。 正方形の座標が与えられる代わりに、4 つの頂点のそれぞれから原点までの二乗距離が与えられます。 これら 4 つの値から、正方形の有効な配置を 1 つ取得し、その頂点の座標を特定の順序で出力する必要があります。 

重要な問題は、原点までの距離の情報が方向構造を失うことです。 原点からの距離 25 の点は、半径 5 の円上のどこにでも配置できます。利用可能な唯一の構造は、4 つの点すべてが剛体の正方形を形成することです。そのため、1 つの点が Y 軸上に固定されると、残りの点は整数座標を維持する剛体の回転と平行移動によって大きく制限されます。 

制約の大きさは小さく、すべての二乗距離は比較的小さな値 (最大でも 10^5 程度) で制限されます。 これは、半径 √d の円上にある整数格子点がまばらであることを意味するため、重要です。 x² + y² = d の整数解の数は平均して少ないため、距離ごとに候補を列挙できます。 

任意の連続座標を試みる単純な幾何学的再構成は、すぐに失敗します。これは、解が整数格子点上に存在する必要があり、正方形が正確な直交性制約を満たさなければならないためです。 もう 1 つの微妙な失敗例は、正方形が軸に沿って配置されていると仮定した場合に発生します。 たとえば方向ベクトル (1, 1) および (1, -1) を使用すると、依然として整数座標が生成されるため、回転された格子正方形が存在するため、その仮定は間違っています。 

2 番目の失敗モードは、A への最小距離のマッチングなど、貪欲に距離を割り当てようとした場合に発生します。この問題では、A が y 軸上にあることが保証されるため、そのアイデンティティは距離の順序付けではなく幾何学によって構造的に固定されます。 A を誤って識別すると、一貫性のない正方形のジオメトリが伝播します。 

## アプローチ

 ブルートフォースパースペクティブは、各頂点が原点を中心とする整数格子円上のどこかにあるという観察から始まります。 与えられた二乗距離 d に対して、x² + y² = d を満たすすべての整数のペア (x, y) を列挙できます。 4 つの距離のそれぞれに対して候補セットを個別に生成すると、あらゆる方法を試して 4 つの点を選択し、それらが正方形を形成するかどうかをテストできます。 これはすべての幾何学的実現を探索するため正しいですが、候補セットの外積が急速に増大するためコストが高くなります。 通常、各円が生成するポイントの数が少ない場合でも、最悪の場合、4 つのリストを組み合わせて多くの 4 つをチェックすることになり、不必要な組み合わせ爆発が発生します。 

重要な単純化は、A の構造制約を利用することで実現します。A は正の y 軸上にあることがわかっているため、その x 座標は 0 であるため、A は正確に (0, √AO²) でなければなりません。 これにより、1 つの頂点のあいまいさが完全に排除されます。 A が固定されると、A に固定された整数格子内の 2 つの直交する等しい長さのベクトルを選択することによって正方形が決定されます。任意の 4 倍体を検索する代わりに、残りの 3 つの頂点を残りの距離セットに照合し、正方形ジオメトリとの一貫性を検証するだけで済みます。 

これにより、この問題は、2 つの平方の和としての整数の表現から導出される小さな候補セットにわたる制御されたマッチング問題に縮小されます。 残りの各頂点は既知の円上にある必要があるため、一定サイズの幾何学的構成のコレクションの互換性をテストするだけで済みます。

 ## アルゴリズムのチュートリアル

 1. AO² から直接 A の整数座標を計算します。 A は正の y 軸上にあるため、A は (0, √AO²) として一意に決定されます。 このステップにより、1 つの自由度が完全に削除されます。 
2. 残りの距離 BO²、CO²、および DO² のそれぞれについて、x² + y² が指定された値と等しくなるようなすべての整数格子点 (x, y) を列挙します。 有効な各ペアは、その頂点の潜在的な位置です。 このステップでは、抽象的な距離制約を明示的な幾何学的候補に変換します。 
3. 残りの 3 つの距離値の頂点 B、C、および D へのすべての割り当てを検討します。これが必要なのは、入力ではどの距離がどの頂点に対応するかが分からず、割り当てが異なると一貫性のある異なる正方形が生成される可能性があるためです。 
4. 割り当てごとに、それぞれのリストから取得した B、C、および D の候補点のすべての組み合わせを繰り返します。 各トリプルは、正方形の構成に対する具体的な幾何学的仮説を表します。 
5. 各候補構成について、A、B、C、および D が正方形を形成しているかどうかを確認します。 このチェックは二乗距離を使用して行われます。つまり、4 つの辺がすべて等しく、対角線が等しく、隣接する辺が垂直である必要があります。 平方距離を使用すると、浮動小数点エラーが回避され、計算が正確に保たれます。 
6. 有効な構成が見つかったら、必要な形式で座標を出力します。 

正確さの背後にある中心的な考え方は、すべての有効な正方形が整数格子の剛体埋め込みに対応し、すべての頂点が対応する半径の列挙された候補セットに出現する必要があるということです。 すべての可能性が明示的に列挙され、テストされるため、有効な構成が見逃されることはありません。 

### なぜ効果があるのか

 A を修正すると、連続的な幾何学的曖昧性が、2 つの平方の和としての整数の表現によって定義される離散検索空間に折りたたまれます。 他のすべての頂点は、指定された円上に正確に存在する必要があるため、列挙に表示される必要があります。 平方条件は厳密で代数的であるため、誤った組み合わせは検証によって拒否されますが、正しい構成は必ずすべての制約を満たし、列挙中に遭遇します。 これにより、幾何学的空間全体を探索する必要がなく、完全性が保証されます。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def points_on_circle(r2):
    res = []
    r = int(math.isqrt(r2))
    for x in range(-r, r + 1):
        y2 = r2 - x * x
        if y2 < 0:
            continue
        y = int(math.isqrt(y2))
        if y * y == y2:
            res.append((x, y))
            if y != 0:
                res.append((x, -y))
    return list(set(res))

def is_square(A, B, C, D):
    pts = [A, B, C, D]
    d = []
    for i in range(4):
        for j in range(i + 1, 4):
            dx = pts[i][0] - pts[j][0]
            dy = pts[i][1] - pts[j][1]
            d.append(dx * dx + dy * dy)
    d.sort()
    return d[0] > 0 and d[0] == d[1] == d[2] == d[3] and d[4] == d[5]

def solve():
    AO2, BO2, CO2, DO2 = map(int, input().split())

    A = (0, int(math.isqrt(AO2)))

    cand = {
        BO2: points_on_circle(BO2),
        CO2: points_on_circle(CO2),
        DO2: points_on_circle(DO2)
    }

    import itertools
    dist_keys = [BO2, CO2, DO2]

    for perm in itertools.permutations(dist_keys):
        B_list = cand[perm[0]]
        C_list = cand[perm[1]]
        D_list = cand[perm[2]]

        for B in B_list:
            for C in C_list:
                for D in D_list:
                    if is_square(A, B, C, D):
                        print(A[1], B[0], B[1], C[0], C[1], D[0], D[1])
                        return

solve()
```解決策は、その x 座標がゼロであるという事実を使用して A を固定することから始まり、そのため、その y 座標は AO² の整数平方根として一意に決定されます。 これにより曖昧さが取り除かれ、ジオメトリが固定されます。 

他の 3 つの距離のそれぞれについて、関数は次のようになります。`points_on_circle`対応する円上に正確に存在するすべての格子点を列挙します。 これは、考えられる x 値をスキャンし、残りの値が完全な正方形であるかどうかをチェックすることによって行われます。 これにより、浮動小数点計算が回避され、整数の正確さが保証されます。 

次に、入力で対応が指定されていないため、アルゴリズムは 3 つの距離値を頂点 B、C、D に割り当てるすべての順列を試行します。 割り当てごとに、候補点のすべての組み合わせがテストされます。 

機能`is_square`純粋に二乗距離を使用して二乗条件を検証します。 6 つのペアごとの距離を並べ替えると、4 つの等しい辺の長さと 2 つの等しい対角線が得られます。これは、平面内の正方形の完全な特徴付けとなります。

 ## 特殊なケース

 重要なケースの 1 つは、距離が、x² + y² = 2 または 25 のような円など、多くの対称表現を持つ点に対応する場合です。このような状況では、候補の生成により複数の反射が生成されるため、アルゴリズムは一意性を仮定してはなりません。 すべての有効な符号バリエーションが含まれるため、列挙ステップではこれを自然に処理します。 

もう 1 つのケースは、正方形が軸に沿って配置されている場合です。たとえば、A = (0, a)、B = (b, a)、C = (b, a + b)、D = (0, a + b) です。 この構成では、候補点には多くの対称的な代替点が含まれますが、正方形チェックによってすべての誤った位置合わせがフィルタリングされ、有効な構造のみが残ります。 

最後の微妙なケースは、距離割り当ての異なる順列によって幾何学的に等価な正方形が生成される場合に発生します。 置換ループにより、距離と頂点の間の一貫したマッピングが最終的にテストされて受け入れられるため、有効なラベル付けが見逃されることがなくなります。
