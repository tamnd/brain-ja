 ## 問題の理解

 一変量多項式が与えられます$A(x)$そして多変量多項式を構築します$D(x_1, \dots, x_m)$2つの成分を摂取することで。 一つ目は以下のコピーです$A$各変数に独立して適用されるため、すべての変数が係数に寄与します$A(x_i)$。 2 番目は、すべてのペアごとの差を乗算するヴァンデルモンド型係数です。$x_i - x_j$のために$i > j$。 結果は、次のような大きな非対称多項式になります。$m$変数。 

この多変量多項式を展開すると、次の単項式の和になります。$x_1, \dots, x_m$整数係数を使用します。 タスクは多項式自体を計算することではなく、これらすべての係数の二乗和を計算することです。 

入力サイズは、1 つの変数の多項式の次数が最大 500 であることを示唆していますが、変数の数は$m$と同じ大きさにすることができます$10^9$。 これにより、明示的に構築または操作するアプローチは直ちに除外されます。$D$、係数を保存するだけでも指数関数的になるため、$m$。 したがって、問題の構造は、依存関係を崩壊させる必要があります。$m$もっとシンプルなものに。 

素朴な解釈は拡大してしまうだろう$D$記号的にすべての係数を列挙し、それらを二乗して合計します。 たとえ$m = 2$、用語の数は程度とともに急速に増加します。 一般向け$m$、単項式の数が組み合わせ論的に爆発的に増加し、直接展開が不可能になります。 

主な難しさは、単一の係数や評価が求められるのではなく、すべての係数にわたるグローバルな 2 次統計が求められることです。 これは通常、何らかの隠れた直交性または決定構造を示します。 

ここではエッジケースが重要です。 

いつ$m = 0$、多項式は定数として定義されます。$1$、したがって、答えは次のとおりです$1$。 少なくとも 1 つの変数を前提とした解決策はここで失敗します。 

いつ$m = 1$、ヴァンデルモンド部分が消え、$D(x_1) = A(x_1)$。 答えは次の係数の二乗和となります。$A$、これはすでに重要な変換の正確性チェックです。 

いつ$m$構造の次数に関連する制限を超えると、ヴァンデルモンド構造により、最終的な行列式定式化の行間に線形依存性が強制されます。 単純な実装では、巨大な行列式を誤って計算しようとする可能性がありますが、正しい解は、その領域では答えがゼロに崩壊することを示しています。 

## アプローチ

 直接的なアプローチが広がる$D$の単項式に$m$変数を抽出し、すべての係数を抽出し、それらの二乗を計算します。 これは文字通り定義に従っているため、原則として正しいです。 問題は、ヴァンデルモンド因子を乗算するたびに項の数が劇的に増加し、完全に展開すると係数の数が指数関数的に増加することです。$m$そして学位。 一度中間状態を保存することすら不可能になる$m \ge 5$。 

重要な観察は、「係数の二乗和」はランダムな統計ではないということです。 まさに二乗ですね$\ell_2$-ノルムは係数ベクトルのノルムであり、そのノルムには標準的な代数的解釈があります。多項式の逆変数変換を含む積の定数項として表すことができます。 これにより、係数の二次和が構造化された定数項抽出問題に変換されます。 

一変量多項式の場合$F(x)$、アイデンティティ$$\sum c_k^2 = [x^0] F(x)F(x^{-1})$$指数差が等しい係数をペアにすると、一致する項が分離されるため、 が成り立ちます。 同じ考え方が多変量ローラン多項式にも当てはまります。 

これを応用すると、$D(x_1, \dots, x_m)$、問題を次の定数項の抽出に変換します。$$D(x_1, \dots, x_m)\cdot D(x_1^{-1}, \dots, x_m^{-1}).$$さて、構造が重要になります。 ヴァンデルモンド項は反転の下できれいに変換されます。$$(x_i^{-1} - x_j^{-1}) = \frac{x_j - x_i}{x_i x_j}.$$これにより、別のヴァンデルモンド因子と予測可能な単項式分母が生成されます。 両方のコピーを乗算した後、非対称構造は対称ヴァンデルモンド二乗項に二乗されます。 

この時点で、式は次の形式の古典的な定数項恒等式になります。 

ヴァンデルモンドの二乗乗算は、同一の 1 変数因子の積です。 このような式は、順列対称性に由来する階乗因数を掛けたモーメントの行列式 (ハンケル行列式またはテプリッツ行列式) に崩壊することが知られています。 

重要な単純化は、畳み込み多項式のみを使用できることです。$$B(x) = A(x)\cdot A(x^{-1})$$変数へのすべての依存関係が変数を通じて分離されるため、重要です。 から$B$、係数を抽出します$b_k$、そして答えはこれらの係数から構築された行列の行列式になります。 マトリックスのサイズは$m$、しかしそれ以来$A$次数が最大 500 のシーケンス$b_k$サポートには制限があり、行列のランクは最大で$n+1$。 これは、鋭いカットオフを意味します。$m > n+1$、行列式は消えます。 

したがって、問題を最大サイズのテプリッツ行列式の計算に縮小します。$n+1$、乗算$m!$いつ$m$範囲内です。

 ## アルゴリズムのチュートリアル

 私たちは、すべてを構造化された行列の決定要因に還元することを中心にソリューションを構築します。 

### 1. 自明な変数のカウントを処理する

 もし$m = 0$、多項式は定数です$1$、したがって、答えは次のとおりです$1$。 もし$m = 1$の係数の二乗和を返します。$A$ヴァンデルモンド相互作用が存在しないためです。 

これにより、決定機構が不要な退化したケースが分離されます。 

### 2. 畳み込み多項式を構築する

 新しいシーケンスを定義します$b_k$積の係数を表す$$A(x)\cdot A(x^{-1}).$$それぞれ$b_k$項のペアによって計算されます$a_p a_q$そのような$p - q = k$。 これにより、反転ステップの後半で現れる正の指数と負の指数の間のすべての相互作用がキャプチャされます。 

### 3. 有効なマトリックス サイズを決定する

 計算する行列式にはサイズがあります$m$、しかし、の係数構造$b_k$からのインデックスのみを対象とします$-n$に$n$。 これは、これより大きい行列はすべて、$n+1$ランク落ち状態になります。 

それで、もし$m > n+1$、すぐに戻ります$0$。 

### 4. テプリッツ行列を構築する

 私たちは、$m \times m$マトリックス$T$ここで、各エントリはインデックスの違いのみに依存します。$$T_{i,j} = b_{i-j}.$$この構造は、変換されたヴァンデルモンド式のすべての定数項相互作用をコード化します。 

### 5. 行列式とスケールを計算する

 私たちは計算します$\det(T)$モジュロ$10^9+7$を乗算します。$m!$。 この階乗因数は、ヴァンデルモンド二乗展開における順列の対称性を説明します。 

### 6. 結果を返す

 最終的な値は$m! \cdot \det(T)$modulo 必要な係数。 

### なぜ効果があるのか

 多項式の係数ベクトルは、逆変換によってそれ自体とペアになり、二乗和を定数項の抽出に変換できます。 ヴァンデルモンド因子は反対称を強制し、それを二乗すると、問題は完全にペアごとの指数の差によって支配される対称相互作用に変換されます。 これにより、多変量構造が、畳み込み係数から構築された並進不変行列の行列式に還元されます。 行列式は、多項式の両方のコピーにわたって一貫して変数をペアにすることができるすべての方法をエンコードし、非対称性により不一致がキャンセルされ、順列ごとに 1 回だけカウントされる有効な一致のみが残ります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(a):
    return pow(a, MOD - 2, MOD)

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    if m == 0:
        print(1)
        return

    # compute convolution b_k = coeff of A(x)A(1/x)
    # shift indices by n to store [-n..n]
    size = 2 * n + 1
    b = [0] * size
    shift = n

    for i in range(n + 1):
        for j in range(n + 1):
            b[i - j + shift] = (b[i - j + shift] + a[i] * a[j]) % MOD

    # if m > n+1 determinant collapses
    if m > n + 1:
        print(0)
        return

    # build Toeplitz matrix T[i][j] = b[i-j]
    T = [[0] * m for _ in range(m)]
    for i in range(m):
        for j in range(m):
            T[i][j] = b[i - j + shift]

    # Gaussian elimination determinant
    det = 1
    for i in range(m):
        pivot = -1
        for j in range(i, m):
            if T[j][i]:
                pivot = j
                break
        if pivot == -1:
            det = 0
            break

        if pivot != i:
            T[i], T[pivot] = T[pivot], T[i]
            det = -det

        inv = modinv(T[i][i])
        det = det * T[i][i] % MOD

        for j in range(i + 1, m):
            factor = T[j][i] * inv % MOD
            for k in range(i, m):
                T[j][k] = (T[j][k] - factor * T[i][k]) % MOD

    # multiply by m!
    fact = 1
    for i in range(1, m + 1):
        fact = fact * i % MOD

    print(det * fact % MOD)

if __name__ == "__main__":
    solve()
```実装では、まず多項式を対称畳み込み配列に圧縮します。$b_k$、反転後に必要なすべてのインタラクションをキャプチャします。 次に、テプリッツ行列がこれらの係数から直接構築され、ヴァンデルモンド二乗変換によって暗示される定数項構造がエンコードされます。 

行列式はモジュラー ガウス消去法を使用して計算されます。 すべての演算はモジュロ算術で行われるため、行を交換するときやピボットを正規化するときに実行行列式を更新するには注意が必要です。 最後に、順列対称性を考慮して階乗乗数が適用されます。 

微妙な点は、次の場合にすぐにカットオフされることです。$m > n+1$。 これがなければ、行列は特異になり、消去は引き続き機能しますが、大規模な処理でかなりの時間を浪費します。$m$一方、数学的構造は結果がゼロであることを保証します。
