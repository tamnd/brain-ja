 ## 解決策
 ## 問題の理解

 一連の整数が与えられます`a`長さの`n`、および 2 つのパラメータ:`m`、部分配列の「美しさ」を計算するときに考慮する最大の要素の数、および`k`、分割する必要がある連続するサブ配列の数`a`の中へ。 サブ配列の美しさは、サブ配列の合計として定義されます。`m`最大の要素。 課題は分割することです`a`正確に`k`連続したサブ配列、それぞれのサイズが少なくとも`m`、すべての部分配列の美しさの合計が最大化されるようにします。 

入力制約は次のことを示します。`n`最大 200,000 まで可能で、値は`a_i`大きなマイナスになることもプラスになることもあります。 以来`n`これほど大きい場合、考えられるすべてのパーティションを試行するアルゴリズムは非常に遅くなります。 線形または線形に近いソリューション`n`が必要です。 各サブ配列には少なくとも次のものを含める必要があります`m`要素、つまり残りの要素`n - k*m`要素を柔軟に分散できます。`k`サブ配列を使用して合計を増やします。 

エッジケースには、すべての数値が等しいシナリオが含まれます。これにより、複数のパーティションが同等になります。また、正確にパーティションが存在する場合も含まれます。`m`サブ配列ごとに要素が存在するため、分割に柔軟性がありません。 最大値を合計するだけの単純なアプローチ`m`全体の美しさを最大化するための要素の割り当て方法を考慮せずに、連続したセグメント内の要素を配置すると、余分な要素の再配分によって合計が増加する可能性があるため、失敗します。 

## アプローチ

 ブルートフォースアプローチでは、あらゆるパーティション分割方法を試します。`a`の中へ`k`少なくとも`m`要素を抽出し、各部分配列の美しさを計算し、合計が最も高いパーティションを選択します。 これは、すべての有効なパーティションを徹底的に評価するため、正しいです。 ただし、パーティションの数は組み合わせになります。`C(n-1, k-1)`-これは天文学的に大きいです`n`は 200,000 であるため、このアプローチは完全に非現実的です。 

最適なソリューションの重要な観察点は、`m`配列全体の最大の要素は、サブ配列内の要素の順序ではなく、サブ配列に含まれる要素にのみ依存します。 仮に`m*k`配列から最大の要素を抽出すると、これらは常に、最適なパーティションの全体的な美しさに貢献するものになります。 問題は、これらの位置を特定することに帰着します。`m*k`最大の要素を分割し、`k`各ブロックに正確に含まれる連続したブロック`m`そのうちの 1 つ (および連続性を維持するために必要な残りの要素)。 要素を並べ替えてインデックスを選択すると、パーティションを効率的に構築できます。 

素朴で最適なアプローチは次のように要約できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n は k を選択) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各要素をペアリングします`a`位置を保持するためにそのインデックスを使用します。 これが必要なのは、パーティションの境界を決定するために元のインデックスが必要であるためです。 
2. このペアの配列を値の降順に並べ替えます。 これにより、全体的な美しさに寄与する最大の要素を簡単に選択できるようになります。 
3. 最初のものを取る`m*k`ソートされた配列の要素。 美しさの合計を最大化したいので、これらは最適なパーティションに含まれる値です。 
4. これらの値を合計します。`m*k`トータルな美しさを最大限に引き出す要素。 元のインデックスを保存します。 
5. 選択した要素のインデックスを並べ替えます。 これにより、次の位置が得られます。`a`これらの最大の要素が表示される場所。これを使用して連続した部分配列を形成します。 
6. これらの並べ替えられたインデックスを反復処理し、選択します`k-1`カットポイント。 最も簡単な方法は、最初のものを取ることです`m`要素のインデックスを最初の部分配列の終わり、次の部分配列の終わりとして`m`要素は 2 番目の部分配列の終端として、以下同様に続きます。 これらのインデックスの直前の位置は、分割する場所を定義します。`a`。 
7. 美しさと選択されたカット位置の合計を出力します。 

これが機能する理由: 不変条件は、美しさの最適な合計が常に次の要素から得られるということです。`m*k`最大の要素とそれらの要素の分散`k`少なくとも連続した部分配列`m`要素はその寄与を保持します。 インデックスを並べ替えると、サブ配列が連続していることが保証され、すべてのサブ配列が選択されます。`m`-th 要素は、各サブ配列に少なくとも`m`要素。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m, k = map(int, input().split())
a = list(map(int, input().split()))

# Pair elements with original indices
indexed_a = [(val, idx) for idx, val in enumerate(a)]
# Sort descending by value
indexed_a.sort(reverse=True, key=lambda x: x[0])

# Take top m*k elements
top_elements = indexed_a[:m*k]
# Maximum beauty sum
max_beauty = sum(val for val, _ in top_elements)

# Extract and sort indices
indices = sorted(idx for _, idx in top_elements)

# Determine partition points
cuts = []
for i in range(1, k):
    cuts.append(indices[i*m - 1] + 1)  # +1 for 1-based indexing

print(max_beauty)
print(' '.join(map(str, cuts)))
```このコードは、まず最大限の美しさに寄与する要素を特定し、次に連続性を維持するためにそれらの位置を並べ替えます。 カットポイントの計算は簡単です。`m`- 番目、`2*m`-th などの最大の要素は、サブ配列の境界を定義します。 

## 実用的な例

 **サンプル 1 入力**:```
9 2 3
5 2 5 2 4 1 1 3 2
```| ステップ | 説明 | 値/インデックス |

 | 1 | インデックスとペア | [(5,0),(2,1),(5,2),(2,3),(4,4),(1,5),(1,6),(3,7),(2,8)] |
 | 2 | 値の降順で並べ替え | [(5,0),(5,2),(4,4),(3,7),(2,1),(2,3),(2,8),(1,5),(1,6)] |
 | 3 | テイクトップ6 (m*k) | [(5,0),(5,2),(4,4),(3,7),(2,1),(2,3)] |
 | 4 | マックスビューティーサム | 5+5+4+3+2+2=21 |
 | 5 | インデックスの並べ替え | [0,1,2,3,4,7] |

 パーティショニング:`[5,2,5]`、`[2,4]`、`[1,1,3,2]`合計は21になります。
