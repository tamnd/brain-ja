 ## 解決策
 ## 問題の理解

 ブドウの好みが異なる 3 人がいて、ブドウの山が 3 つあります。 

アンドリューはまさに最初の種類のブドウ、緑色のブドウを望んでいます。 彼が必要なら`x`grapes, all of them must come from the green pile.

 ドミトリーは黒ブドウが嫌いです。 彼は緑または紫のブドウを食べることができます。 彼には少なくとも`y`この2色のブドウを合計します。 

ミハルには制限がありません。 彼はどんな色のブドウも食べることができ、少なくとも必要なものは`z`ブドウ。 

入力すると必要な量が得られます`x`、`y`、 そして`z`、その後に利用可能なカウントが続きます`a`、`b`、 そして`c`緑、紫、黒のブドウ。 3 人全員を満足させる分布が存在するかどうかを判断する必要があります。 

制約はわずかです。 すべての値は最大でも`10^5`、テスト ケースは 1 つだけです。 多くの可能性に対する総当り検索でも問題なく適合しますが、問題の構造により、さらに単純な定数時間の解決策が可能になります。 

難しいのは、色によって柔軟性のレベルが異なることです。 アンドリューは緑のブドウしか食べられないため、緑のブドウは最も制限された資源です。 紫色のブドウはドミトリーが使用できるため、より柔軟です。 黒ブドウは他の人が使用できないため、ミハルにとってのみ最も柔軟です。 不用意に実装すると、ブドウの総数のみがチェックされ、これらの制限が見逃される可能性があります。 

次の例を考えてみましょう。```
3 1 1
2 100 100
```ブドウの総数は十分すぎるほどですが、アンドリューには緑のブドウが 3 つ必要ですが、存在するのは 2 つだけです。 正しい答えは、`NO`。 

もう 1 つの微妙なケースは、アンドリューは満足できるが、ドミトリーは満足できない場合です。```
2 5 1
2 4 100
```アンドリューに緑のブドウを 2 つ与えた後、緑のブドウは残りません。 ドミトリーは紫のブドウを 4 つしか使用できませんが、5 つに達するには不十分です。 正しい答えは、`NO`。 

3 番目のケースは、アンドリューとドミトリーの両方が満足できるが、ミハルが満足できない場合です。```
1 1 10
1 1 8
```アンドリューは緑のブドウを 1 つ取ります。 ドミトリーは紫色のブドウを1個取ります。 何も残らないので、ミハルは 10 個のブドウを必要としますが、受け取ったブドウは 0 個です。 正しい答えは、`NO`。 

これらの例は、割り当ての順序が重要であることを示しています。 最も制限されたコンシューマを最初にチェックする必要があります。 

## アプローチ

 強引なアイデアは、アンドリューとドミトリーの間で緑のブドウを割り当てるあらゆる方法を試し、残りのブドウが他の全員を満足させることができるかどうかを確認することです。 各パイルサイズが到達できるため、`10^5`すべてのディストリビューションを列挙するには、最大約`10^5`可能性。 ここではまだ管理可能ですが、不必要に複雑になります。 

重要な観察は、制限が自然な階層を形成しているということです。 

アンドリューは緑のブドウしか食べられないため、最も制限されています。 以下の場合は、`x`緑のブドウ、解決策は存在しません。 

アンドリューがブドウを受け取ると、残っている緑色のブドウはドミトリーに利用できるようになります。 ドミトリーは緑と紫の両方のブドウを使用できます。 残りの緑色のブドウとすべての紫色のブドウの合計量が以下の場合`y`、解決策は存在しません。 

アンドリューとドミトリーを満足させた後、色に関係なく、残ったすべてのブドウをミハルに与えることができます。 残りのブドウの合計が少なくとも`z`、有効なディストリビューションが存在します。 

各ステップは最も制約のある人を最初に満足させるため、後で必要になる可能性のあるリソースを無駄にすることはありません。

 ## アルゴリズムのチュートリアル

 1. 少なくとも`x`緑のブドウ。 もし`a < x`、出力`NO`アンドリューは満足できないからです。 
2. アンドリューに必要なブドウを引き算して与えます。`x`から`a`。 残りの緑色のブドウはドミトリーに利用できるようになりました。 
3. 残りの緑のブドウとすべての紫のブドウがドミトリーを満足させることができるかどうかを確認します。 もし`a + b < y`、出力`NO`。 
4. ドミトリーに必要なブドウを与えます。 ドミトリーは最初に緑のブドウを使用し、次に紫のブドウを使用できるため、消費した後に残るブドウの数を計算します。`y`結合プールからのブドウ。 
5. しましょう`remaining = a + b - y + c`。 これがミハルに残されたブドウの総数です。 
6. もし`remaining >= z`、出力`YES`。 それ以外の場合は出力`NO`。 

### なぜ効果があるのか

 アンドリューの要件は最も厳しいものです。 有効なソリューションはすべて予約する必要があります`x`彼には緑のブドウ。 最初にこれを確認することが必須です。 

アンドリューが満足したら、ドミトリーは黒以外の残りのブドウをすべて使用することができます。 残っている緑ブドウと紫ブドウの合計量が以下の場合`y`、ドミトリーが受け入れる唯一の色であるため、アレンジは役に立ちません。 

アンドリューとドミトリーが満足したら、ミハルは残ったブドウを食べることができます。 この時点では、残っているブドウの総数のみが問題になります。 少なくとも`z`ブドウは残っているので、ミハルは色に関係なくいつでもブドウを取ることができます。 

各チェックは必要な条件に正確に対応しており、より制限された人々を最初に満たした後、それらの条件も十分になります。 したがって、アルゴリズムは正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

x, y, z = map(int, input().split())
a, b, c = map(int, input().split())

if a < x:
    print("NO")
    sys.exit()

a -= x

if a + b < y:
    print("NO")
    sys.exit()

remaining = a + b - y + c

if remaining >= z:
    print("YES")
else:
    print("NO")
```最初の条件は Andrew を扱います。 緑のブドウが十分にない場合、答えはすぐに不可能になります。 

アンドリューのブドウを差し引いた後の変数は、`a`はまだ入手可能な緑色のブドウを表します。 ドミトリーはこれらをすべての紫色のブドウと一緒に使用できるため、2 番目の条件チェックが行われます。`a + b`。 

表現`a + b - y`ドミトリーが正確に受け取った後に緑と紫のブドウが何個残っているかを表します`y`ブドウ。 追加`c`ミハルだけが必要とするすべての黒ブドウが含まれています。 

この実装では、カウントのみが重要となるため、明示的に分布を構築することは避けられます。 ループは必要なく、すべての算術演算は通常の整数の範囲内に簡単に収まります。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    x, y, z = map(int, input().split())
    a, b, c = map(int, input().split())

    if a < x:
        return "NO"

    a -= x

    if a + b < y:
        return "NO"

    remaining = a + b - y + c

    return "YES" if remaining >= z else "NO"

# provided sample
assert run("1 6 2\n4 3 3\n") == "YES", "sample 1"

assert run("1 1 10\n1 1 8\n") == "NO", "not enough total remaining for Michal"

 ## 特殊なケース

 ### 緑のブドウが足りない

 入力:```

2 100 100
```アルゴリズムはすぐにチェックします`a < x`。 以来`2 < 3`、それは出力します`NO`。 

アンドリューは緑色のブドウしか受け入れないため、解決策は不可能です。 余分な紫または黒のブドウは補うことができません。 

### 緑のブドウは十分ですが、ドミトリーにはブドウが足りません

 入力:```
2 5 1
2 4 100
```アンドリューは緑のブドウを 2 個消費し、次のものが残ります。```
a = 0
b = 4
```アルゴリズムチェック`a + b < y`:```
0 + 4 < 5
```これは本当ですので、答えは次のようになります。`NO`。 

ドミトリーは黒ブドウを食べることができないので、大きな黒いブドウの山は関係ありません。 

### アンドリューとドミトリーには十分ですが、ミハルには不十分です

 入力:```
1 1 10
1 1 8
```アンドリューの後:```
a = 0
```ドミトリーはブドウを 1 個消費します。```
a + b - y = 0
```残りのブドウは次のとおりです。```
0 + 8 = 8
```以来`8 < 10`、Michal は満足できず、アルゴリズムは次のように出力します。`NO`。 

これは、最初の 2 人を満足させたからといって、自動的に 3 人目に十分なブドウが残っていることを意味するものではないことを裏付けています。
