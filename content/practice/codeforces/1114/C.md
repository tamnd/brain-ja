 ## 問題の理解

 任意の基数で表される数値の階乗内の末尾のゼロの数を計算するように求められます。 より正確には、与えられた整数$n$そして$b$、基数の末尾の桁数がゼロに等しいことが必要です。$b$の表現$n!$。 入力$n$非常に大きくなる可能性があり、最大で$10^{18}$、 そして$b$まで行くことができます$10^{12}$。 直接コンピューティング$n!$階乗の成長が速すぎるため不可能です。 平$100!$158 桁であり、$10^{18}!$まったく手に負えない。 

基数の末尾のゼロ$b$回数で決まる$b$分割する$n!$。 基数 10 の場合、後続のゼロの数は、次の素因数分解における 2 と 5 のカウントの最小値から得られます。$n!$。 一般的な基底については、同様のアプローチが必要です。$b$を素因数で割ってから、各素因数が何回割られるかを求めます。$n!$、そして最後に、次の指数に従ってこれらのカウントを結合します。$b$。 

計算を試みる素朴なアプローチ$n!$すべての素因数を直接保存したり、保存したりすることさえ不可能です。 エッジケースには小規模なものが含まれます$n$そして大きい$b$どこ$b$それ自体が素数であるか、大きな素数パワーを含んでいます。 たとえば、次の場合$n = 5$そして$b = 16$、階乗は$120$で割り切れます。$2^3 = 8$しかし、それによってではありません$16$。 不注意な解決策は、次のことを想定してゼロをカウントしすぎる可能性があります。$n! \ge b$少なくとも 1 つの末尾ゼロがあれば十分です。 

## アプローチ

 ブルートフォースアプローチは文字通り計算することです$n!$そして繰り返し除算します$b$剰余がゼロ以外になるまで除算を数えます。 これは非常に小さい場合に機能します$n$そして$b$、しかし、$n = 10^{18}$階乗は計算できないため、このアプローチは役に立ちません。 乗算の数だけでは、$O(n)$、これは合理的な計算を超えています。 

重要な洞察は、末尾のゼロが回数に対応しているということです。$b$分割する$n!$。 もし$b = p_1^{e_1} p_2^{e_2} \dots p_k^{e_k}$、次に基数内の末尾のゼロの数$b$の最小値です$\text{floor}(\text{count of } p_i \text{ in } n! / e_i)$全体的に$i$。 素数の数$p$で$n!$ルジャンドルの公式を使用して効率的に計算できます: 合計$\lfloor n / p^j \rfloor$のために$j = 1, 2, \dots$それまで$p^j > n$。 これにより、問題は次の素因数分解に還元されます。$b$各素数の対数合計。これは大規模な場合でも実行可能です。$n$そして$b$。

 ## アルゴリズムのチュートリアル

 1.因数分解$b$素数に。 2 から までの整数を反復処理します。$\sqrt{b}$、各素数をできるだけ多く分割して、その指数を見つけます。 その後に何らかの要因が残った場合$\sqrt{b}$、プライムです。 これにより、$b = \prod p_i^{e_i}$。 
2. 各素因数について$p_i$の$b$、その多重度を計算します。$n!$ルジャンドルの公式を使って。 カウンタを初期化する$c = 0$、分割を繰り返します$n$による$p_i, p_i^2, p_i^3, \dots$各商を加算すると$c$商がゼロになるまで。$c$の合計数です$p_i$で$n!$。 
3. 各素数について$p_i$、計算する$c // e_i$、これは最大回数です$b$使用できます$p_i^{e_i}$で$n!$。 基数の末尾のゼロ$b$すべての素因数にわたるこれらの値の最小値です。 
4. この最小値を出力します。 

機能する理由: 因数分解により、要素によって課されるすべての制約が確実に考慮されます。$b$。 ルジャンドルの公式は、各素数が何回除算されるかを正確に数えます$n!$。 指数で割る$e_i$素数が複数回出現する塩基を調整します。 すべての素数にわたる最小値がボトルネックです。1 つの要素が欠けていると、次の倍数を形成できなくなります。$b$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def prime_factors(b):
    factors = {}
    d = 2
    while d * d <= b:
        count = 0
        while b % d == 0:
            b //= d
            count += 1
        if count > 0:
            factors[d] = count
        d += 1
    if b > 1:
        factors[b] = 1
    return factors

def count_prime_in_factorial(n, p):
    count = 0
    power = p
    while power <= n:
        count += n // power
        if power > n // p:
            break
        power *= p
    return count

def trailing_zeros(n, b):
    factors = prime_factors(b)
    zeros = float('inf')
    for p, e in factors.items():
        zeros = min(zeros, count_prime_in_factorial(n, p) // e)
    return zeros

n, b = map(int, input().split())
print(trailing_zeros(n, b))
```コードは、最初に基数を因数分解し、次にルジャンドルの公式を使用して階乗に対する各素数の寄与を計算するように構成されています。 微妙なチェックポイント`power > n // p`整数のオーバーフローを防ぐために乗算する前に。 すべての素数の最小値を取得すると、複合基数が正しく処理されます。

 ## 特殊なケース

 のために`5 16`、素因数分解は$16 = 2^4$。 2秒を数える`5!`4 で割ると 0 が得られます。アルゴリズムは正しく 0 を返し、誤って 1 つのゼロを要求することはありません。 のために`6 9`、因数分解は$9 = 3^2$。 3 秒を数える`6!`2 が得られます。2 で割ると、末尾のゼロが 1 つになります。 どちらの場合も、1 より大きい指数を持つ複合基数の処理を確認します。オーバーフロー チェックイン`power *= p``n の場合に無限ループを防止します
