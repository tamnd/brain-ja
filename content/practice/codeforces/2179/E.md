 ## 解決策
 ## 問題の理解

 私たちは、選挙区の最小規模を尊重しながら、二値パターンに従って有権者を選挙区に分割することが求められています。 具体的には、A と B の 2 つのパーティがあり、合計は`x`そして`y`それぞれ有権者。 がある`n`地区と各地区`i`少なくとも必要です`p_i`投票者数の合計。 バイナリ文字列も与えられます`s`長さの`n`各地区の希望する勝者を示します。`s_i = 0`、政党 A は選挙区で B よりも多くの有権者を持っていなければなりません`i`; もし`s_i = 1`, 政党BはAよりも多くの有権者を持っていなければなりません。 

私たちの仕事は、すべての地区に文字列に一致する勝者がいるように投票者を割り当てることが可能かどうかを判断することです。`s`最低投票者数を満たしながら。 

制約はかなり大きいです。`n`は最大 2·10^5 であり、次の合計は`n`すべてのテスト ケースにわたって 2 · 10^5 を超えません。 各有権者はカウントします`x`、`y`、および地区最小値`p_i`最大 10^9 まで可能です。 すべての割り当てを試行する単純なアプローチは、天文学的な数の操作が必要になるため、まったく実行不可能です。 すべてのソリューションは、`n`テストケースごとに。 

地区の最小サイズが制限される場合、明らかではない特殊なケースが発生します。`p_i`利用可能な投票数を超える投票者を消費する場合、または勝者の条件を満たす配布が不可能な場合。 たとえば、地区に次のような特徴がある場合、`p_i = 5`、`x = 2`、`y = 3`、 そして`s_i = 0`の場合、A だけでは最低過半数に到達できないため、A が B よりも多くの有権者を獲得する方法はありません。 同様に、すべての地区が B の勝利を必要とする場合でも、`y`小さすぎると解決は不可能です。 これらの制約は、問題が単に合計に関するものではなく、慎重な割り当てに関するものであることを示しています。 

## アプローチ

 ブルートフォースアプローチでは、各選挙区の有権者のすべての組み合わせが考慮され、配列の可能なすべての割り当てがテストされます。`a`そして`b`。 このアプローチは、最終的にすべての有効な構成を列挙することになるため正しいですが、明らかに実行不可能です。 のために`n = 10^5`投票者数が 10^9 までになると、潜在的な分布の数は指数関数的に増加し、現実的な計算時間をはるかに超えます。 

重要な観察は、地区ごとに要件が線形不等式に帰着するということです。`s_i = 0`、私たちは持っている必要があります`a_i > b_i`そして`a_i + b_i >= p_i`; もし`s_i = 1`、私たちは必要とします`b_i > a_i`そして`a_i + b_i >= p_i`。 以来`a_i`そして`b_i`が負ではない整数である場合、各地区の最小および最大の割り当て境界を個別に計算し、投票者数の合計が以下であるかどうかを確認できます。`x`そして`y`これらの境界をグローバルに満たすことができます。 これにより、問題は 2 つの範囲に縮小されます。A に行かなければならない投票者の合計と B に行かなければならない投票者の合計であり、線形時間でチェックできます。 

各地区の要件によって A (または B) の投票者数の範囲が定義されているという観察により、単純な最小値の合計と最大値の合計のチェックを定式化することができます。 各政党の有権者の総数がこれらの範囲内に収まる場合、解決策は存在します。 それ以外の場合は、そうではありません。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(sum(p_i))) | O(n) | 遅すぎる |
 | 範囲ベースの割り当て | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.地区ごとに`i`、政党 A に行かなければならない有権者の最小数を決定します (`min_a`) とパーティ B への最小値 (`min_b`）。 もし`s_i = 0`, A は勝たなければならないため、A への最小割り当ては次のようになります。`(p_i + 1) // 2`。 もし`s_i = 1`, B が勝たなければならないため、A への最小割り当ては次のようになります。`0`。 
2. 同じ選挙区について、A の最大割り当てを決定します。これは、選挙区内の総有権者によって制限されます。`s_i = 0`、A が取り得る最大値は`p_i - 0`(B が何も投票しない場合はすべての有権者)。 もし`s_i = 1`、A が取り得る最大値は`p_i - (p_i + 1) // 2`Bが確実に勝つようにするためです。 
3. すべての地区にわたる最小割り当てを合計して、`min_total_a`。 取得する最大割り当ての合計`max_total_a`。 これにより、A のグローバルな実行可能範囲が定義されます。 
4. かどうかを確認します。`x`(A の投票者数の合計) は以下の範囲内にあります`[min_total_a, max_total_a]`。 同様に、次のことを確認します。`y`相補分布に適合します。 
5. 両方の合計が実行可能な範囲内に収まる場合は、YES と出力します。 それ以外の場合は、NO を出力します。 

**機能する理由:** 各地区は、A と B のローカルで実行可能な範囲を個別に定義します。 最小値と最大値を合計すると、全体的な実行可能な範囲が得られます。 投票者数の合計がこの範囲外にある場合、一部の選挙区は最低要件と勝者の要件の両方を満たすことができないため、解決策は存在しません。 内部にある場合は、余剰投票者を任意の順序で分配することで、有効な割り当てを常に貪欲に構築できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x, y = map(int, input().split())
        s = input().strip()
        p = list(map(int, input().split()))
        
        min_a_total = 0
        max_a_total = 0
        
        for i in range(n):
            if s[i] == '0':
                min_a = (p[i] + 1) // 2
                max_a = p[i]
            else:
                min_a = 0
                max_a = p[i] // 2
            min_a_total += min_a
            max_a_total += max_a
        
        if min_a_total <= x <= max_a_total and (sum(p) - x) <= y:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```このソリューションでは、まず、勝者の要件に基づいて、政党 A の地区ごとの最小投票者数と最大投票者数を計算します。 すべての地区を合計すると、A の実行可能な合計範囲が得られます。次に、次のことを確認します。`x`はこの範囲内に収まり、残りの投票者が B を満たすことができるかどうか。演算の順序が重要です。整数の除算は奇数と偶数を処理するために慎重に使用されます。`p_i`必要に応じて過半数が存在することを保証します。
