 ## 解決策
 ## 問題の理解

 私たちは、地球上のペンギンの位置を再構築するように求められています。$n \times n$ペンギンのペア間のマンハッタンの距離だけがわかっているため、移動後のグリッドを調べます。 各ペンギンには固有のラベルが付けられています。$1$に$n^2$、移動後も、各セルには依然としてちょうど 1 匹のペンギンがいます。 私たちの目標は、指定された距離と一致する有効なグリッド配置を生成することです。 この相互作用により、2 羽のペンギン間のマンハッタン距離をクエリすることができますが、上限は約$3n^2 + 150$テストケースごとのクエリ。 

グリッドは十分小さいです ($n \le 100$) 保存して操作できる$n^2 \times n^2$必要に応じて距離情報。 ただし、すべてのペンギンのペアをクエリする単純な総当たりアプローチでは、$\binom{n^2}{2} \approx 5{,}000$のクエリ$n=100$これはクエリ制限を下回っていますが、実際には非効率である可能性があります。 主な課題は、すべてのペアを盲目的にクエリするのではなく、マンハッタン距離の幾何学的特性を活用して、できるだけ少ないクエリで位置を再構築することです。 

明らかではないエッジ ケースには、同じ距離の複数の順列が存在するグリッドが含まれます。 たとえば、$2 \times 2$グリッドには対称的な配置があり、行または列を交換すると有効な解決策が得られます。 ペンギンが隅にいる場合、別の微妙な問題が発生します。 他の行と列との距離によって、他の行と列に対する相対的な行と列が即座に定義され、アルゴリズムはこれを利用する必要があります。 

## アプローチ

 ブルート フォース アプローチでは、ペンギンのすべてのペア間の距離をクエリし、完全な距離行列を構築し、すべての距離制約を満たす座標を求めることによってグリッドの再構築を試みます。 マンハッタンの距離は回転と反射までの位置を一意に決定するため、これは理論的には正しいですが、スケールは次のようになります。$O(n^4)$再構築に必要な比較の数が異なりますが、クエリの数が許可されている場合でも、これは現実的ではありません。 

最適なアプローチのための重要な洞察は、すべてのペアごとの距離は必要ないということです。 1 つのペンギンを基準として固定した場合 (たとえば、ペンギン 1)、このペンギンから他のすべてのペンギンまでの距離をクエリすると、そのペンギンに対する相対的なマンハッタン座標が効果的に得られます。 具体的には、2 匹のペンギン間の距離は、それらの座標の差の合計に等しくなります。 1 つの参照ペンギンを他のすべての参照ペンギンに対して体系的にクエリすることにより、どのペンギンが参照に対して相対的にどの行および列にあるかを特定できます。 適切に選択された 2 つの基準からの距離を使用すると、すべてのペンギンの座標を完全に決定できます。 これにより、クエリがおおよそ次のように減ります。$O(n^2)$、制限内にうまく収まります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^4) | O(n^4) | 遅すぎる |
 | 最適 | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ペンギン 1 を参照として選択します。 他のすべてのペンギンまでの距離をクエリし、結果をリストに保存します。 これらの距離は、マンハッタン内で各ペンギンがペンギン 1 からどのくらい離れているかを示します。 
2. ペンギン 1 を基準にしてグリッドの角にあるペンギンを特定します。基準からの距離が最大のペンギンが角を占める必要があります。 同じ最大距離を持つ複数のペンギンが存在する可能性があります。 どれも対称性を破るための二次的な基準として機能します。 
3. ペンギン 1 の座標を次の位置に固定します。$(0,0)$そして最大距離のペンギンについては、$(n-1,n-1)$または他のコーナーのいずれか。 これら 2 つの参照からのマンハッタンの相対距離により、残りのペンギンの行と列ごとに 2 つの一次方程式からなる連立方程式を解くことができます。 
4. 他のペンギンについて、座標を求めます。$(r_i, c_i)$使用:$$|r_i - r_1| + |c_i - c_1| = d_1, \quad |r_i - r_2| + |c_i - c_2| = d_2$$マンハッタンの距離方程式には、有効な解が 1 つだけあります。$0 \le r_i, c_i < n$グリッド。 
5. すべてのペンギンに座標を割り当てたら、ペンギンを$n \times n$グリッド。 結果のグリッドを最終的なソリューションとして出力します。 

機能する理由: 任意の 2 点間のマンハッタン距離により、それらの座標がダイヤモンド型の輪郭上に配置されるように制約されます。 2 つの非同一線上にある参照を使用すると、2 つのマンハッタン距離のひし形の交点が 1 つのグリッド セルになるため、各ポイントの行と列の両方が修正されます。 これにより、結果の割り当てが参照からのすべての距離と一致し、したがって未知の元のグリッドと一致することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def query(i, j):
    print(f"? {i} {j}", flush=True)
    return int(input())

def solve_case(n):
    total = n * n
    # Step 1: distances from penguin 1
    dist1 = [0] * (total + 1)
    for i in range(2, total + 1):
        dist1[i] = query(1, i)
    
    # Step 2: find a corner penguin with max distance
    max_dist = max(dist1[2:])
    corner = dist1.index(max_dist)
    
    # Step 3: query distances from corner penguin
    dist2 = [0] * (total + 1)
    for i in range(1, total + 1):
        if i != corner:
            dist2[i] = query(corner, i)
    
    # Step 4: compute coordinates relative to reference (0,0)
    coords = [(-1,-1)] * (total + 1)
    coords[1] = (0, 0)
    coords[corner] = (n-1, n-1)
    
    for i in range(2, total + 1):
        if i == corner:
            continue
        # Solve for row and column
        # Let (r,c) = coordinates of penguin i
        # |r| + |c| = dist1[i], |r-(n-1)| + |c-(n-1)| = dist2[i]
        s = dist1[i]
        t = dist2[i]
        # Iterate all possible rows
        for r in range(n):
            c = s - r
            if 0 <= c < n and abs(r - (n-1)) + abs(c - (n-1)) == t:
                coords[i] = (r, c)
                break
    
    # Step 5: fill grid
    grid = [[0]*n for _ in range(n)]
    for i in range(1, total + 1):
        r, c = coords[i]
        grid[r][c] = i
    
    print("!")
    for row in grid:
        print(" ".join(map(str, row)))

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        solve_case(n)

if __name__ == "__main__":
    main()
```このソリューションでは、クエリロジックと座標解決ロジックを分離します。 ペンギンのすべての可能な行値を慎重に繰り返し、最初の参照から列を計算し、2 番目の参照を使用して検証します。 これにより、座標における 1 つずつの誤差が回避され、すべての割り当てが確実に範囲内に収まるようになります。$n \times n$グリッド。
