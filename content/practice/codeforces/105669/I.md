 ## 問題の理解

 単一の整数が与えられます\( n \)。 課題は、表現できるさまざまな方法が何通りあるのかを数えることです\( n \)順序が重要な場合、正の整数の合計として。 たとえば、書くこと\( 3 \)として\( 1+2 \)とは異なると考えられます\( 2+1 \)、さらには単一の用語でも\( 3 \)それ自体も有効な表現です。 合計が正確に一致する正の整数のすべてのシーケンス\( n \)一方的に貢献します。 

これは、順序付けられた整数の合成を数えるという古典的な問題です。\( n \)。 答えは急速に大きくなり、最終結果は剰余として報告する必要があります\( 10^9+7 \)。 

制約\( n \le 10^6 \)ここで重要な信号です。 パーティションを列挙したり、すべての構成を明示的に構築したりするアプローチは不可能です。\( n \)、作曲の数は指数関数的です\( n \)。 したがって、問題の構造は、線形時間で計算できる単純な漸化式または閉形式恒等式に還元する必要があります。 

A subtle edge case appears at\( n = 1 \)。 構成は 1 つだけです。\([1]\)。 数値自体の使用を許可しない単純な解釈では、誤ってゼロが出力されます。 もう 1 つのよくある間違いは、順序付けられたコンポジションと順序付けられていないパーティションを混同することです。 たとえば、\( n=3 \)、正解は\(4\)、 ない\(3\)、順序がカウントされるためです。 

## アプローチ

 ブルート フォース ソリューションでは、考えられるすべての正の整数の合計を生成しようとします。\( n \)。 再帰の観点から、各ステップで次の加数を選択します。\( k \ge 1 \)そして再帰的に\( n-k \)。 これにより、最大の分岐係数が作成されます。\( n \)トップレベルでは、\( n-1 \)、 等々。 再帰状態の総数は、構成自体の数とほぼ同じように増加します。\( 2^{n-1} \)。 のために\( n = 10^6 \)、これはまったく不可能です。 

重要な観察は、問題は選択された実際の値には依存せず、残りの合計のみに依存するということです。 \( f(n) \) を有効な合成の数とします。\( n \)。 あらゆる構成\( n \)どちらかが始まる\( 1 \)、 または\( 2 \)、 または\( 3 \)、などまで\( n \)。 これにより再発が得られます\[
f(n) = f(n-1) + f(n-2) + \dots + f(0),
\]\( f(0) = 1 \) という規則を使用して、空の分解を表します。 

この漸化式の直接計算は、単純に実装しても \( O(n^2) \) ですが、伸縮関係に注目することで簡略化できます。 \( f(n) \) の漸化式から \( f(n-1) \) の漸化式を引くと、次のようになります。\[
f(n) - f(n-1) = f(n-1),
\]これを単純化すると\[
f(n) = 2 \cdot f(n-1).
\]これにより、構造全体が単純な 2 倍化プロセスに分解されます。つまり、次の各整数の合成です。\( n-1 \)先頭を付けて変更しないこともできます。\( 1 \)、または、次の構成で全単射を保存する方法で拡張されます。\( n \)。 これにより、ステップごとにカウントが 2 倍になる 1 対 1 の対応が確立されます。 

したがって、閉じた形式が得られます。\[
f(n) = 2^{n-1}.
\]これは、単純な再帰を介して線形時間で、またはべき乗剰余を介して対数時間で計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 |---|---|---|---|
 | ブルートフォース列挙 | \( O(2^n) \) | \( O(n) \) | 遅すぎる |
 | 州全体のプレフィックス合計 DP | \( O(n^2) \) | \( O(n) \) | 遅すぎる |
 | クローズドフォーム\( 2^{n-1} \)| \( O(\log n) \) | \( O(1) \) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 私たちは、あらゆる有効な構造が次のとおりであることを認識します。\( n \)整数の間の一連のカットに対応します\( 1 \)を通して\( n \)。 隣接する位置のペアの間にカットを入れるか入れないかによって、数字がグループ化されるか分離されるかが決まります。 これにより、問題が二分決定プロセスに変換されます。\( n-1 \)ギャップ。 

2. それぞれの\( n-1 \)位置には独立して 2 つの選択肢があり、構成の合計数は\( 2^{n-1} \)。 これは、再帰を完全に回避する中心的な組み合わせ変換です。 

3. 高速累乗を使用して \( 2^{n-1} \bmod (10^9+7) \) を計算します。 指数が大きいため、底を 2 乗して各ステップで指数を半分に減らすことを繰り返します。 

4. 最終的な値が答えとして返されます。 

### なぜ効果があるのか

 不変条件は、すべての組成が\( n \)のサブセットに一意に対応します\( n-1 \)連続する整数間の区切り文字。 サブセットを選択すると、セグメントがどこで終了するかが正確に決定されるため、有効な順序付きパーティションが一意に決定されます。 2 つの異なるサブセットが同じ組成を生成することはなく、すべての組成は正確に 1 つのサブセットに対応します。 この全単射は、\( 2^{n-1} \)カウント。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

n = int(input().strip())

# number of compositions of n is 2^(n-1)
if n == 0:
    print(1)
else:
    print(pow(2, n - 1, MOD))
```この実装では、べき乗剰余演算が直接適用されます。 特別な場合\( n = 0 \)完全を期すために含まれていますが、問題は保証されています\( n \ge 1 \)。 

重要な簡素化は、DP テーブルや再帰を避けることです。 問題の全体的な構造は、整数間のギャップにわたる独立した二項選択を数えることに帰着します。

import sys, io

 ## 特殊なケース

 ### n = 1

 入力用`1`、アルゴリズムは次のように計算します。\( 2^{0} = 1 \)。 唯一の構成は単一の要素です`[1]`, したがって、結果は正しいです。 ギャップ解釈にはギャップはありません。つまり、構成が 1 つだけ存在することを意味します。 

### 非常に大きな n (最大 10^6)

 のために`n = 1000000`の場合、べき乗ステップは \( O(\log n) \) で実行されます。 計算では底 2 を繰り返し 2 乗して指数を減らしますが、係数を超える大きな中間値は決して保存されません。 これにより、最大入力サイズでもアルゴリズムが安定して高速に保たれます。
