 ## 解決策
 ## 問題の理解

 部分的に満たされた長さの順列が与えられています$n$。 一部の要素が欠落しており、次のように表されます。$-1$。 ここでの順列とは、欠損値を埋めた後、次の各数値が$0$に$n-1$は 1 回だけ表示されます。 このタスクは、不完全な配列から作成できるすべての順列の値の合計を計算することです。ここで、順列の値は、空でない連続するすべての部分配列の MEX (最小除外値) の合計として定義されます。 

制約により許可されるのは、$n$まで$5000$テストケースごとの合計と$n$すべてのテスト ケースにわたって次の制限も受けられます。$5000$。 これは、アルゴリズムが$O(n^2)$テストケースごとの時間の複雑さは許容可能です。 アン$O(n^3)$置換の数は欠落要素の数に応じて階乗的に増加するため、特にすべての置換を明示的に列挙しようとすると、解は制限時間を超える可能性があります。 

配列に複数のデータがある場合、微妙なエッジケースが発生します。$-1$価値観。 それぞれを満たそうとする素朴なアプローチ$-1$考えられるすべての欠落数値を使用してすべてのサブ配列の MEX を計算すると、組み合わせ的に爆発します。 もう 1 つの特殊なケースは、数値が欠落していない場合です。 ソリューションでは、すべての部分配列の MEX 合計を正しく計算する必要があります。 たとえば、次のような配列`[2,0,1]`には欠落要素はありませんが、部分配列にわたる MEX 計算では、個別の要素をカウントするだけでなく、除外された数を注意深く考慮する必要があります。 

## アプローチ

 ブルート フォース アプローチは概念的に単純です。つまり、$-1$s を残りの数値で計算し、順列ごとに、すべての部分配列の MEX の合計を計算します。 ここでの問題は、要素の欠落がたとえ少数であっても、階乗的に多くの順列が発生することです。 たとえば、欠損値が 10 個ある場合、次のようになります。$10!\approx3.6$百万の順列。 各順列のすべての部分配列の MEX 合計を計算することは別の作業です$O(n^2)$操作により、禁止事項が発生する$O(10!\cdot n^2)$複雑。 

重要な観察は、MEX が部分配列に存在しない最小の数値によって決定されるということです。 それぞれの潜在的な MEX 値を追跡すると$x$MEX を持つサブ配列は正確にいくつありますか$x$の期待される寄与を計算できます。$x$列挙せずにすべての順列にわたって。 これにより、問題は組み合わせ論に帰着します。部分配列の MEX が等しくなるように数値を配置する方法の数を数えます。$x$。 これは、動的プログラミングとプレフィックス合計を使用して効率的に処理できます。 具体的には、部分配列の各開始点を考慮し、既知の数値を追跡し、組み合わせカウントを使用して欠損値が残りの位置を埋める方法の数を乗算します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((n-m)! * n^2) | O(n) | 遅すぎる |
 | 最適 | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 階乗とモジュラー逆関数を最大で事前計算します。$n$組み合わせカウントのモジュロを迅速に計算する$10^9 + 7$。 これにより、欠落している数値を部分配列に効率的に割り当てる方法の数を計算できるようになります。 
2. 各テスト ケースについて、どの番号が欠落しており、どの位置が不明であるかを特定します ($-1$）。 追跡する`missing_count`0 から n-1 までの各数値について。 
3. 動的プログラミングを使用して、考えられるすべての部分配列を反復処理します。 インデックスで始まる各サブ配列について`i`、既知の位置に表示される数字を追跡します。 部分配列に存在しない数値については、順列特性に違反することなく、欠落している位置から埋められる数値を決定します。 
4. 部分配列の予想される MEX を計算することにより、値の合計への寄与を計算します。 MEX 値の寄与$x$以下の数字を割り当てる有効な順列の数です。$x$離脱中にサブアレイ内で$x$ない。 これは、次の数に基づく組み合わせカウントを使用して行われます。`-1`部分配列内の s と利用可能な欠損番号。 
5. 各インデックスから始まるすべてのサブ配列の寄与を累積します。`i`すべての順列の値の合計を計算します。 和の剰余を出力する$10^9 + 7$。 

機能する理由: 各部分配列は、順列制約を尊重しながら欠落している数値を埋めるためのあらゆる方法を考慮して、その MEX に対して 1 回だけ評価されます。 動的プログラミング手法により、重複するサブ配列が効率的に計算を再利用できるようになります。 組み合わせ推論により、明示的に生成することなく、有効な順列をすべてカウントできるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD-2, MOD)

def prepare_factorials(n):
    fac = [1] * (n+1)
    ifac = [1] * (n+1)
    for i in range(1, n+1):
        fac[i] = fac[i-1] * i % MOD
    ifac[n] = modinv(fac[n])
    for i in range(n-1, -1, -1):
        ifac[i] = ifac[i+1] * (i+1) % MOD
    return fac, ifac

def comb(n, k, fac, ifac):
    if k < 0 or k > n:
        return 0
    return fac[n] * ifac[k] % MOD * ifac[n-k] % MOD

t = int(input())
fac, ifac = prepare_factorials(5000)

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    used = [0]*n
    unknown = 0
    for x in a:
        if x == -1:
            unknown += 1
        else:
            used[x] = 1
    missing = [i for i in range(n) if not used[i]]
    
    total = 0
    # Iterate over all subarrays
    for l in range(n):
        present = set()
        num_unknown = 0
        for r in range(l, n):
            if a[r] == -1:
                num_unknown += 1
            else:
                present.add(a[r])
            # Determine MEX
            mex = 0
            while mex in present:
                mex += 1
            # Number of ways to fill unknowns: choose positions for numbers < mex
            smaller_missing = sum(1 for x in missing if x < mex)
            ways = comb(num_unknown, smaller_missing, fac, ifac)
            total = (total + mex * ways) % MOD
    print(total)
```この解決策は、高速な組み合わせ計算のために階乗と逆階乗を事前計算することから始まります。 次に、各テスト ケースを処理し、既知の番号と欠落している番号を追跡します。 各サブ配列について、現在の数を動的に追跡し、未知数をカウントし、MEX を計算し、サブ配列がその MEX を持つように未知数を埋める方法の数を計算します。 貢献度はモジュロで累積されます$10^9 + 7$。 未知数のない部分配列などのエッジ条件は、次の場合に 1 を返す組み合わせ関数によって自然に処理されます。`num_unknown`はゼロです。
