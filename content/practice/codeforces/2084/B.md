 ## 問題の理解

 正の整数のシーケンスが与えられており、最初の部分の最小値が 2 番目の部分の最大公約数と等しくなるように、再配置した後、シーケンスを 2 つの連続する部分に分割できるかどうかを判断する必要があります。 言い換えれば、配列を任意に並べ替えて、左側のセグメントの最小値が右側のセグメントの GCD と一致する分割点を選択することができます。 

入力は最大で保証されます$10^4$テスト ケース、それぞれ$n$まで$10^5$整数とその合計$n$すべてのテストケース全体で最大でも$10^5$。 整数自体は非常に大きくなる可能性があり、最大で$10^{18}$。 これにより、考えられるすべての分割または順列を調べる必要があるアルゴリズムが即座に排除されます。 反復するソリューション$O(n^2)$の可能性は遅すぎます。 見つけなければなりません$O(n)$または$O(n \log n)$テストケースごとのアプローチ。 

重要なエッジケースは、すべての要素が等しい場合です。 たとえば、シーケンスが次の場合、$[7,7,7]$、任意のポジションの後で分割でき、最小値と GCD は両方とも 7 になるため、答えは「はい」です。 もう 1 つの微妙なケースは、最小値が複数回出現するものの、残りのすべての要素の約数ではない場合に発生します。 例えば、$[1,2,3]$1 が左の最小値で、右の GCD が 1 ではない場合、条件を満たすように分割することはできません。どこかに大域最小値が存在するかどうかを確認するだけの不注意なアルゴリズムは、ここで失敗する可能性があります。 

## アプローチ

 ブルート フォース アプローチでは、シーケンスのすべての順列とすべての分割位置が試行され、左側の最小値と右側の GCD が計算されます。 正しい分割は与えられた等式を満たさなければならないため、これは理論的には機能しますが、実際には次のような問題があります。$n!$それぞれの順列$n-1$分割は、たとえ$n=10$。 

問題の構造を観察すると、右セグメントの GCD と一致する左セグメントの最小値の唯一の候補が、配列のグローバル最小値であることがわかります。 これは、左側のセグメントの最小値がグローバル最小値より小さくなることはなく、正の整数の GCD は最大でもそれらの中で最小であるためです。 したがって、分割が存在する場合、値は$\min(left) = \gcd(right)$配列全体の最小値と等しくなければなりません。 

これを考慮すると、問題を単純化できます。$m$配列のグローバル最小値になります。 次に、次の倍数ではない要素は、$m$セグメントの GCD は次の値に等しい必要があるため、正しいセグメントに置くことはできません。$m$。 したがって、解決策は、すべての要素が次の要素で割り切れるかどうかを確認することになります。$m$他の要素を削除した後、連続した右セグメントを形成できます。 「はい」の場合、これらの要素が最後になり、左側のセグメントに残りの要素がすべて含まれるように配列を並べ替えることができます。 「いいえ」の場合、分割は不可能です。 

この観察により、問題は階乗時間チェックから線形時間チェックに軽減され、最小値の非倍数をすべて左セグメントに確実に移動できるようにするために必要なスキャンは 1 回だけです。 すべてが次の数で割り切れる一連の数値の GCD がすでにわかっているため、GCD を動的に計算する必要はありません。$m$少なくとも$m$、右セグメントの数値はいずれも次の倍数でなければなりません。$m$。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$そして配列$a$。 
2. グローバル最小値を計算する$m = \min(a)$。 これは両方の唯一の候補値です$\min(left)$そして$\gcd(right)$。 
3. 配列内のすべての要素が次のいずれかに等しいことを確認します。$m$またはで割り切れる$m$。 で割り切れない要素$m$は左側のセグメントになければなりません。 
4. すべての倍数を分割した後、$m$右側のセグメントに残りを左側に、左の最小値が残ります$m$そして正しい GCD は$m$同じように。 想定される右セグメント内の要素が次の要素で割り切れない場合$m$、「いいえ」を出力します。 
5. チェックに合格した場合は、「Yes」を出力します。 

機能する理由: このアルゴリズムは、左側のセグメントの最小値が全体の最小値より小さくなることはなく、右側のセグメントの GCD がその最小値より小さくならないという不変式に依存しています。 大域最小値を両方の候補にすることにより、あらゆる違反 (右セグメント内の要素が次の値で割り切れない)$m$) 等価性は不可能になります。 並べ替えにより、すべての倍数が保証されます。$m$状態を保ったまま正しいセグメントに入ることができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import gcd
from functools import reduce

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        m = min(a)
        if all(x % m == 0 or x == m for x in a):
            print("Yes")
        else:
            print("No")

if __name__ == "__main__":
    solve()
