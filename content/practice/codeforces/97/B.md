 ## 解決策
 ## 問題の理解

 平面上の一連の個別の格子点から始めます。 さらに点を追加することもできますが、最終的なセットは点のすべてのペアについて幾何学的条件を満たさなければなりません。 

任意の 2 点を取得します。 すでに同じ x 座標または y 座標を共有している場合、それらは自動的に有効になります。 それ以外の場合、それらは軸に揃えられた長方形の反対側の角を形成します。 条件は、この四角形には、四角形の内部または境界上に、セット内の他の点が少なくとも 1 つ含まれている必要があることを示しています。 

課題は追加点を最小限に抑えることではない。 条件を満たしながら以下にとどまる、より大きなセットを構築するだけで済みます。`2 * 10^5`ポイント。 

入力サイズは十分小さいため、`O(n^2)`処理中ですので、`n ≤ 10^4`。 二次アルゴリズムは次のように実行します。`10^8`最悪の場合はプリミティブな操作が可能ですが、これはすでに Python の実用的な限界に近づいているため、これより大幅に遅いものは危険です。 立体的なアプローチは完全に不可能です。 出力制限は入力サイズよりもはるかに大きく、これは意図したソリューションが建設的であることを強く示唆しています。慎重に選択されたヘルパー ポイントを多数追加することができます。 

難しいのは、長方形内の有効な証人ポイントとして何がカウントされるかを正確に理解することです。 追加の点は境界上にある場合がありますが、厳密に内側にある必要はありません。 また、証人ポイントは 2 つのエンドポイントとは異なる必要があります。 

よくある間違った考え方は、すべてのペアを独立して接続することです。 例えば：```
2
1 1
2 2
```追加すると`(2,1)`、によって形成される長方形`(1,1)`そして`(2,2)`含まれています`(2,1)`その境界上にあるため、ペアは有効になります。 しかし、後で別のペアを個別に処理し、グローバルに適用されなくなった仮定を誤って再利用した場合、その構築はポイント制限を超える可能性があります。 

点がすでに座標を共有している場合には、別の微妙なケースが発生します。```
3
1 5
1 9
4 7
```ペア`(1,5)`そして`(1,9)`は垂直に配置されているため、すでに有効です。 すべてのペアにヘルパー ポイントを追加しようとする不注意な実装では、不要なポイントが生成され、出力制限をオーバーフローする可能性があります。 

最も危険な誤解は、すべての四角形には厳密にその内側に点が必要であると仮定することです。 考慮する：```
2
0 0
5 5
```追加`(0,5)`長方形の境界上にあるので十分です。 境界点を拒否すると、構造が過度に複雑になります。 

## アプローチ

 ブルートフォースの考え方は単純です。 異なる x 座標と y 座標を持つ点のペアごとに、欠落している長方形の角の 1 つを挿入することを試みることができます。`(x1, y2)`または`(x2, y1)`。 これにより、そのペアがすぐに有効になります。 

問題は、挿入されたポイントを含む新しいペアが依然として条件に違反する可能性があることです。 1 つのペアを修正すると、新しい不良ペアがいくつか作成される可能性があります。 このプロセスを単純に繰り返すと、制御が難しくなります。 最悪の場合、生成されるポイントの数が二次関数的に増加するか、さらに悪化する可能性があり、終了に関する推論が面倒になります。 

重要な観察は、すべての点のペアが、何らかの中心構造と x 座標または y 座標のいずれかを共有する場合、条件が自明になるということです。 長方形を 1 つずつ修正する代わりに、すべての点を再帰的なグリッドのような階層に編成できます。 

点を x 座標で並べ替えます。 x で中央点を選択します。 x 座標を通る垂直線を追加しますが、現在のセグメントにすでに存在する y 値にのみ追加します。 次に、左半分と右半分を再帰的に解きます。 

現在の再帰セグメントに 2 つの点があるとします。 それらが中央値の反対側にある場合、それらの y 値は両方とも中央値の垂直線上に表示されます。 2 つの点によって形成される長方形には、その境界上にこれらの中線点の 1 つが含まれるため、ペアはすぐに有効になります。 

両方の点が同じ側にある場合、再帰呼び出しによって有効性が保証されます。 

この分割統治構造により、明確な正しさの証明が得られ、生成されるポイントの数が制御されます。 各再帰レベルは、元の点ごとに最大 1 つの追加点に寄与します。`O(log n)`レベル。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 制限がない / 制御が難しい | 潜在的に巨大 | 遅すぎて危険 |
 | 最適な分割統治 | O(n log n) | O(n log n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての入力ポイントを読み取り、x 座標で並べ替えます。 
2. 再帰関数を定義する`solve(l, r)`ソートされた配列の連続セグメントを操作します。 
3. セグメントに 0 または 1 つの点が含まれている場合は、再帰を停止します。 単一の点では制約は作成されません。 
4. 中央のインデックスを選択します`mid = (l + r) // 2`。 X 座標の中央値を次のようにします。`xm`。 
5. 現在のセグメント内のすべての点に、点を追加します。`(xm, yi)`回答セットに、ここで`yi`その点の y 座標です。 

これにより、垂直コネクタ ラインが作成されます。`x = xm`。 セグメント内のすべての y 座標がこの線上に表示されます。 
6. 左半分を再帰的に処理する`[l, mid]`。 
7. 右半分を再帰的に処理する`[mid + 1, r]`。 

これが機能する理由は次のとおりです。 任意の 2 つの元の点を考えてみましょう。 

ある再帰レベルで異なる半分に分類される場合、そのレベルでポイントを作成します。`(xm, y1)`そして`(xm, y2)`。 以来`xm`がそれらの x 座標の間にある場合、これらのヘルパー ポイントの 1 つは長方形の境界上にあり、ペアが有効になります。 

2 つの点が常に同じ再帰半分に留まる場合、最終的に再帰はそれらの点のみを含むセグメントに到達し、より深い再帰レベルでそれらを処理します。 

重複を避けるために、生成されたすべてのポイントをセットに保存します。 

### なぜ効果があるのか

 再帰的不変式は次のとおりです。 

すべての再帰セグメントについて、処理後、そのセグメント内のすべての点のペアが必要な条件を満たします。 

セグメント内の任意の点のペアを取得します。 

中央値を横切って分割する場合、構築では 1 つの端点の y 座標を持つ中央値の垂直線上に点を追加します。 そのヘルパー ポイントは、長方形の内側または境界上にあります。 

それらが同じ側にある場合、その側の再帰呼び出し処理によって有効性が保証されます。 

すべてのペアは再帰レベルで分割されるか、基本ケースになるまで一緒に残るため、最終的にはすべてのペアが処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    pts.sort()

    ans = set(pts)

    def dfs(l, r):
        if l >= r:
            return

        mid = (l + r) // 2
        xm = pts[mid][0]

        for i in range(l, r + 1):
            ans.add((xm, pts[i][1]))

        dfs(l, mid)
        dfs(mid + 1, r)

    dfs(0, n - 1)

    print(len(ans))
    for x, y in ans:
        print(x, y)

if __name__ == "__main__":
    solve()
```最初のステップでは、点を x 座標でソートします。これは、分割統治引数が平面を左半分と右半分に分割することに依存しているためです。 

再帰関数は、部分配列を作成するのではなく、配列のインデックスを操作します。 これにより、コピーの繰り返しが回避され、メモリ使用量が低く抑えられます。 

X 座標の中央値は、現在のセグメントの区切り文字として機能します。 そのセグメント内のすべての y 座標が区切り線に投影されます。 これは、ソリューションの中心となる幾何学的なトリックです。 

答えはPythonに保存されます`set`多くの再帰呼び出しが同じヘルパー ポイントを生成するためです。 重複排除を行わないと、出力サイズが不必要に大きくなる可能性があります。 

基本的なケース`l >= r`重要です。 1 つの点を持つセグメントはすでにすべての制約を満たしているため、さらに再帰すると永久にループします。 

再帰の深さは最大でも`log2(n)`、これは非常に小さいです`n ≤ 10^4`したがって、ここでは Python の再帰は安全です。

## 複雑さの分析

 | --- | --- | --- |
 | 時間 | O(n log n) | 各再帰レベルは、セグメント内のすべてのポイントを 1 回処理します。 
| スペース | O(n log n) | 構築されたセットには、再帰レベルごとのポイントごとに最大 1 つのヘルパー ポイントが含まれます。 

がある`O(log n)`再帰レベル。 At each level, every point contributes at most one generated helper point. と`n = 10^4`、合計ポイント数は快適に以下に留まります`2 * 10^5`。

import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    def solve():
        n = int(input())
        pts = [tuple(map(int, input().split())) for _ in range(n)]

        pts.sort()

        ans = set(pts)

        def dfs(l, r):
            if l >= r:
                return

            mid = (l + r) // 2
            xm = pts[mid][0]

                ans.add((xm, pts[i][1]))

            dfs(mid + 1, r)

        dfs(0, n - 1)

        out = [str(len(ans))]
        for x, y in sorted(ans):
            out.append(f"{x} {y}")

        return "\n".join(out)

    return solve()

 ## 特殊なケース

 すでに X 座標を共有している 2 つの点を考えてみましょう。```
2
4 1
4 9
```ソート後、再帰はすぐにサイズ 2 のセグメントに到達します。 アルゴリズムは同じ垂直線上にヘルパー ポイントを追加する場合がありますが、重複はセットによって削除されます。 元のペアがすでに同じ垂直線上にあるため、最終的な構成でも条件は満たされます。
