 ## 解決策
 ## 問題の理解

 サイズ _n × m_ のグリッドが与えられ、これは Gennady が 28 枚のドミノ チップを配置したボードを表します。 各ドミノはちょうど 2 つの隣接する正方形を占め、同じドミノの正方形には同じ文字が付けられますが、異なるドミノには異なる文字が付けられます。 いくつかの四角形は空であり、点で表される場合があります。 目標は、各ドミノが 28 個のドミノの標準セットから有効なドミノになるように、正方形に 0 から 6 までの番号を割り当てることです。各ドミノは 1 回だけ使用され、結果として得られるグリッド上の 2×2 の正方形はすべて 4 つの同じ番号を含みます。 これにより、「魔法の図形」が確実に形成されます。 

入力により、正確に 28 個のドミノが存在し、解決策が存在することが保証されます。 タスクは 2 つあります。1 つ目は、28 個のドミノを配置して魔法の図形を形成できる方法が何通りあるかを数えることであり、2 つ目は、グリッドの正方形に有効な数字の割り当てを 1 つ作成することです。 

ブルートフォースに関しては制約が厳しい。 グリッドは最大 30×30 ですが、これはメモリの問題に遭遇することなく配列やマップを操作できるほど十分小さいです。 主な組み合わせの複雑さは、2×2 の魔方陣 (14) を満たすドミノの順列を数えることから生じます。 固定の 2×2 パターンでドミノのペアを配置する方法と、正方形に番号を割り当てる方法を掛け合わせたものです。 28 個すべてを試してみるという素朴な試み! 順列は完全に不可能です。 

明らかではないエッジ ケースには、ドミノがきれいな 2×2 ブロックを形成しない不規則な形状で配置されているグリッドが含まれます。 たとえば、ドミノがギザギザのパターンを形成している 4×7 の長方形も解決できますが、各 2×2 ブロックがメモリ内で連続していると仮定した不注意なコードは失敗します。 もう 1 つの注意が必要なシナリオは、ドミノがエッジを共有せずに角で接触する場合です。 解決策は、2×2 ブロックを形成するために隣接する位置のみに依存する必要があります。 

## アプローチ

 ブルートフォース手法では、28 個のドミノのすべての順列を試してグリッド上に配置し、各 2×2 の正方形をチェックしてすべての数字が一致するかどうかを確認します。 これは、すべての割り当てを徹底的に考慮するため、原則として正しいです。 ただし、28！ ≈ 3×10^29。これは天文学的に大きく、最適化を行っても計算することは不可能です。 

重要な観察は、問題がまず同じ番号を持つ必要がある 2×2 の正方形を特定し、次にそれらの正方形内の各ペアにドミノを割り当てるということです。 それぞれの 2×2 の正方形には、正確に 2 つのドミノが含まれます。 2×2 の正方形内のドミノの配置がわかったら、問題はこれらの正方形にわたるドミノの順列を数える問題になります。 正方形内の各ドミノ ペアには、魔法の条件を満たす 1 つの方法でのみ番号を割り当てることができ、対称性を説明する階乗と標準ドミノ セットの積として有効な配置の数を計算できます。 

もう 1 つの観察は、グリッドが小さいため、ドミノ ラベルからその位置までの単純なマップを使用できることです。 次に、2×2 ブロックに体系的に番号を割り当て、2 を掛けます。 ブロックごとに、ブロック内のドミノのスワップを考慮します。 アレンジメントの総数は、ブロック数 (14!) の階乗に 2^14 を掛けたもので、コンテストに勝つための方法の数と一致します。

 ## アルゴリズムのチュートリアル

1. サイズ _n × m_ のグリッドを読み取り、文字をその文字が占める座標のペアにマッピングすることで、すべてのドミノの位置を特定します。 各ドミノには正確に 2 つの正方形があります。 
2. グリッド内のすべての 2×2 ブロックを特定します。 各ブロックについて、どのドミノがその 4 つの正方形を占めているかを確認します。 問題の制約により、各 2×2 ブロックには正確に 2 つのドミノが含まれます。 
3. ドミノに 0 ～ 6 の番号を割り当てます。 14 ブロックを形成する 28 個のドミノがあるため、マジック フィギュア条件を満たすために、ブロック内のドミノの各ペアにドミノの両方のマスに同じ番号を割り当てます。 2×2のブロック内に2つあります！ ドミノに番号を割り当てる方法。 
4. 配置の合計数を 2^14 × 14! (14!) として計算します。 は、ブロックに 0 ～ 6 の数字を割り当てる方法の数 (一部の数字は適切に繰り返されます)、2^14 は各ブロック内のドミノの交換に使用されます。 
5. 1 つの有効な割り当てに従ってグリッドに数字を埋め、各ドミノが一貫して埋められるようにします。 

これが機能する理由: 不変条件は、各 2×2 ブロックに正確に 2 つのドミノが含まれ、各ドミノが正確に 2 つの正方形を占めることです。 ブロックごとにドミノに番号を割り当て、各 2×2 ブロックが同じ番号を持つようにすることで、魔法の数字の特性を満たします。 体系的なカウントにより、二重にカウントすることなく、考えられるすべての順列が捕捉されます。 

## Python ソリューション```python
import sys
import itertools
input = sys.stdin.readline

def main():
    n, m = map(int, input().split())
    grid = [list(input().strip()) for _ in range(n)]
    
    # Map domino letters to positions
    domino_positions = {}
    for i in range(n):
        for j in range(m):
            c = grid[i][j]
            if c == '.':
                continue
            if c not in domino_positions:
                domino_positions[c] = []
            domino_positions[c].append((i, j))
    
    # Identify 2x2 blocks
    used = [[False]*m for _ in range(n)]
    blocks = []
    for i in range(n-1):
        for j in range(m-1):
            cells = [(i,j),(i,j+1),(i+1,j),(i+1,j+1)]
            letters = set(grid[x][y] for x,y in cells if grid[x][y] != '.')
            if len(letters) == 2:
                blocks.append(cells)
                for x,y in cells:
                    used[x][y] = True
    
    # Assign numbers 0..6 to dominoes
    domino_list = list(domino_positions.keys())
    number_assignment = {}
    num = 0
    for block in blocks:
        letters_in_block = list({grid[x][y] for x,y in block if grid[x][y] != '.'})
        for l in letters_in_block:
            number_assignment[l] = str(num)
        num = (num + 1) % 7  # rotate numbers 0..6
    
    # Fill the output grid
    output_grid = [['.']*m for _ in range(n)]
    for l, positions in domino_positions.items():
        for x, y in positions:
            output_grid[x][y] = number_assignment[l]
    
    # Compute number of ways: 14! * 2^14
    import math
    total_ways = math.factorial(14) * (2**14)
    
    print(total_ways)
    for row in output_grid:
        print(''.join(row))

if __name__ == "__main__":
    main()
```コードはまずドミノ文字を座標にマッピングし、次に正確に 2 つのドミノを持つすべての 2×2 ブロックを識別します。 ブロック内のドミノに 0 から 6 までの番号を循環的に割り当てます。 アレンジメントの総数は 14 と計算されます。 × 2^14。 各ドミノに番号が割り当てられれば、グリッドを埋めるのは簡単です。 エッジ処理により、ドミノを含むセルのみに番号が付けられます。
