 ## 解決策
 ## 問題の理解

 この問題は、芸術作品が展示されている廊下について説明しています。 各作品には古い識別子があり、同じ識別子を共有するため双子となる作品もあります。 新しい識別子はこれらのグループを正確に保持する必要があります。同じ古い識別子を持つ 2 つの作品は依然として同じ新しい識別子を持つ必要がありますが、2 つの異なる古い識別子は異なる新しい識別子を受け取る必要があります。 

廊下の作品の順序は変更できません。 インスペクターは新しい識別子を左から右に読み取り、以前の作品の方が後の作品よりも大きな識別子を持つ場合、位置のペアは不良とみなされます。 タスクは、この反転の数ができるだけ少なくなるように、新しい識別子を割り当てることです。 反転数が最小の割り当ては受け入れられます。 

主な制限は、古い識別子はすべて最大 2 回出現することです。 すべてのテスト ケースにわたる作業の合計数は最大で$10^5$したがって、解は線形に近いものでなければなりません。 配列全体をソートすることは許容されますが、作品のすべてのペアを比較することは許容されません。 二次方程式の方法は約に達します$10^{10}$通常の 1 秒の制限をはるかに超える最大入力に対する操作。 

厄介なケースは、異なる位置に出現する重複した識別子に起因します。 不注意な解決策では、最初の出現のみに従って、または古いコードの数値に従って識別子を割り当てる可能性がありますが、グループ化が固定された後は元の値は意味を持ちません。 

例えば：```
1
3
3 2 1
```正しい出力は次のようになります。```
1 2 3
```元の値を保持するソリューションは次のように出力します。`3 2 1`、不必要な逆転を生み出します。 旧ラベルにはどの作品が双子であるかのみ記載されています。 

別のケースは次のとおりです。```
1
4
2 1 1 2
```正しい出力は次のようになります。```
1 2 2 1
```2 つのペアは一緒に留まらなければなりません。 最初のものを与える`2`2番目とは異なる値`2`双子の要件に違反します。 

## アプローチ

 直接的なアプローチでは、グループの可能な順序をすべて試し、その順序に従って新しい番号を割り当てます。 グループが昇順に配置されると、反転は最小限に抑えられるため、この考えは正しいです。 ただし、多くの異なるグループがある場合、すべての順序を試すことは階乗的であり、すぐに不可能になります。 

より実際的な総当たりの方法では、さまざまな割り当てを試しながら反転を繰り返しカウントします。 たとえ、考えられる割り当ての小さなセットのみを考慮したとしても、すべてのペアをカウントするには次のことが必要になります。$O(n^2)$仕事。 と$n = 10^5$、それは約です$10^{10}$比較。 

重要な点は、割り当てを検索する必要がないということです。 古い識別子はそれぞれ 1 つの分割不可能なグループを表します。 これらのグループの順序を選択し、その順序で連続する新しい番号を割り当てると、グループ間の反転回数は廊下でのそれらのグループの相対的な順序にのみ依存します。 逆転を最小限に抑えるために、グループは最初の出現に従って左から右へ新しい番号付け順序で表示される必要があります。 

廊下をスキャンするところを想像してみてください。 最初に見つかった新しいグループがコードを受け取るはずです`1`他のグループをその前に置くと、この最初の出現で反転が作成されるためです。 次の未確認グループは次のコードを受信する必要があり、以下同様です。 繰り返し出現すると、そのグループにすでに割り当てられているコードが再利用されます。 

これは、すべてのグループを単一のオブジェクトとして扱うことができるため機能します。 最初に出現するグループに小さいコードを割り当てると、最初に出現するのが遅いグループと交換するよりも多くの反転が発生することはありません。 この交換議論を繰り返すことで初登場順が決まります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) 以上 | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 古いコードから新しいコードへの空のマッピングを作成します。 マッピングは、保存された双子のグループを表します。 同じ古いコードが出現するたびに、同じ値を受け取る必要があります。 
2. 作品を左から右にスキャンします。 古いコードが初めて表示された場合は、次に利用可能な新しいコードを割り当てます。 これは、グループが自然に廊下に現れる順序に従います。 
3. 古いコードが再び表示された場合は、以前に割り当てられた新しいコードを再利用します。 2 番目の出現は、そのグループがすでに配置されているため、順序に影響を与えることはできません。 
4. 割り当てられたコードを元の廊下の順序で出力します。 

なぜ効果があるのか:

 すべてのグループが最初に出現すると、そのグループが反転に影響を与えることができる最も早い位置が決まります。 2 つのグループ A と B に、A が B より前に出現する最初の出現があるとします。B に A よりも小さい新しいコードを割り当てると、これらの最初の出現の間で反転が作成されます。 新しいコードを交換すると、その反転が削除され、グループのすべてのメンバーが一緒に移動するため、後で発生するペアに悪影響を与えることはありません。 この引数を繰り返し適用することは、最適な順序付けがまさにグループの最初の出現順序であることを意味します。 アルゴリズムはその順序を正確に割り当てます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        mapping = {}
        nxt = 1
        res = []

        for x in a:
            if x not in mapping:
                mapping[x] = nxt
                nxt += 1
            res.append(mapping[x])

        ans.append(" ".join(map(str, res)))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```辞書には、古い識別子と新しい識別子の関係が保存されます。 初めて値が表示されると、コードによって次の番号が割り当てられます。 決断が必要となるのはこの瞬間だけです。 

スキャン順序は主な実装の詳細です。 配列が最初にソートされた場合、元の廊下の順序は失われ、生成された割り当てにより反転が増加する可能性があります。 このアルゴリズムはラベルを変更するだけであり、作品を再配置することはありません。 

変数`nxt`新しい識別子はすべて正の値でなければならないため、1 から始まります。 ここでは Python 整数が自然に使用されているため、オーバーフローの心配はありません。

 ## 特殊なケース

 対象:```
1
3
3 2 1
```アルゴリズムは空のマップから始まります。 見えます`3`最初にコードを割り当てます`1`、 それから`2`コードを受信します`2`、 そして`1`コードを受信します`3`。 結果は`1 2 3`これにより、元のラベルによって作成された反転が削除されます。 

のために：```
1
4
2 1 1 2
```最初`2`コードを受信します`1`、そして最初の`1`コードを受信します`2`。 アルゴリズムが 3 番目の位置に到達すると、次のことがわかります。`1`すでにマップに存在するため、コードを再利用します`2`。 決勝戦`2`コードも再利用します`1`。 その結果、両方の双子のペアがそのまま維持されます。 

のために：```
1
5
7 7 7 7 7
```グループは 1 つだけです。 最初の位置では唯一のマッピング エントリが作成され、それ以降のすべての位置でそれが再利用されます。 出力は次のとおりです。```
1 1 1 1 1
```並べ替える個別のグループがないため、他の割り当てでこの問題を改善することはできません。
