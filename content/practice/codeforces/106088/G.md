 ## 問題の理解

 重み付けされたグリッドが与えられます。$n \times m$ボードには「利回り」を表す正の値が含まれています。 タスクは、このグリッド上に正確に 3 つの同一の長方形のプロットを配置することです。 各プロットは軸に沿った連続した長方形をカバーする必要があり、各プロットの寸法は固定されています。$a \times b$、ただし回転する可能性があるので、どちらの向きでも構いません$a \times b$または$b \times a$プロットごとに独立して許可されます。 

各プロットは、それがカバーするすべてのセル値の合計に寄与し、セル内でプロットが重なることは許可されません。 目標は、収集された合計額を最大化する 3 つの配置を選択することです。 

グリッドのサイズは次のようになります$1000 \times 1000$したがって、すべての配置を直接試行するソリューションはすぐに遅すぎます。 考えられるすべての配置を列挙しても、すでに約$10^6$、その中からトリプルを選択すると、爆発的に次のようになります。$10^{18}$実現可能な限界をはるかに超えた組み合わせです。 これにより、長方形の値を効率的に事前計算し、オーバーラップ制約ですべてのペアまたはトリプルを明示的にチェックする必要がなくなるように、選択プロセスを慎重に構築する必要があります。 

長方形が少なくとも 1 つの方向に適合しない場合、微妙なエッジ ケースが発生します。 たとえば、次の場合$a > n$そして$b > n$同時に、ある次元 (列についても同様) については、配置は存在せず、答えは 0 になります。 もう 1 つのエッジ ケースは、長方形が存在する場合でも、配置が 1 つまたは 2 つだけしかできない場合です。たとえば、次のような非常に小さなグリッドです。$3 \times 3$と$2 \times 2$矩形。 3 つの重なり合わない配置を形成できないため、正しい出力は依然として 0 です。 

単純に貪欲なアプローチも簡単に失敗します。 たとえば、グリッドに 2 つの非常に高い値の領域が近接している場合、最初に最適な四角形を貪欲に選択すると、たとえわずかに悪い最初の選択の方がより良いグローバル合計につながるとしても、2 つの大きな四角形を追加できる唯一の構成がブロックされる可能性があります。 

## アプローチ

 ブルートフォースのアイデアは簡単です。長方形の有効な配置をすべて列挙し、その合計を計算して、重複しない配置の 3 つずつを試します。 これはすべての構成をチェックするので正しいですが、完全に実行不可能です。 配置数は次のとおりです。$O(nm)$、トリプルをチェックすると、$O(n^3 m^3)$最悪の解釈での行動であり、実際の限界をはるかに超えています。 

重要な点は、問題は四角形の合計を計算することではなく、選択した 3 つの四角形間で重ならないようにすることであるということです。 長方形の合計がわかったら、残りのタスクは、3 つの互いに素な重みの高い長方形を選択することになります。 

重要な構造特性により、問題が単純化されます。軸に沿って重なり合わない 2 つの長方形は、垂直線または水平線で分離できます。 これは、2 つの長方形が交差しない場合、x 軸上のそれらの投影が重ならないか、y 軸上のそれらの投影が重ならないためです。 この事実により、グリッド パーティションを使用して独立性について推論することができます。 

このアイデアを 3 つの長方形に拡張します。 重なり合わない 3 つの長方形の最適な構成は、各長方形が 1 つのストリップ内に完全に収まるように、グリッドを最大 3 つの垂直ストリップまたは 3 つの水平ストリップに切断することによって表現できます。 これにより、問題は、任意の空間相互作用ではなく、パーティションベースの DP を考慮することになります。 

グリッドが分割されると、各ストリップは独立し、領域内の最適な長方形 (または長方形の最適な組み合わせ) を知るだけで済みます。 これにより、すべての合計を事前に計算するようになります。$a \times b$そして$b \times a$四角形を作成し、これらの値に対して 2D プレフィックス構造を構築することで、サブグリッド内の最適な四角形を効率的にクエリできるようになります。

 ## アルゴリズムのチュートリアル

 長方形の両方の向きを別々に扱い、それらの寄与を計算して統一した構造にします。 

## アルゴリズムのチュートリアル

 1. グリッドの 2D プレフィックス合計を計算して、任意の四角形の合計を一定時間で評価できるようにします。 これは、何百万もの候補四角形をクエリするため必要です。 
2. 両方の方向で長方形の有効な配置をすべて列挙します。 左上の各位置について、プレフィックスの合計を使用してその合計を計算します。 これらの合計を、方向ごとに 1 つずつ、2 つの補助グリッドに保存します。 
3. これらのグリッド上に 2D プレフィックス最大テーブルを構築します。 これにより、「左上の位置の特定のサブグリッドに完全に含まれる最適な長方形は何か」という形式のクエリに一定時間で答えることができます。 
4. 重なり合わない 2 つの長方形を処理するには、隣接しない長方形を垂直線または水平線で分離できるという構造特性を使用します。 列での垂直分割の場合$c$、最初の長方形は完全に列内になければなりません$\le c$、2番目は完全に列になっています$> c$。 すべての分割を試し、左右の領域のプレフィックス最大値を結合することで、最適なペアを計算します。 水平分割についても同じロジックを繰り返します。 
5. 同じパーティション分割のアイデアを 3 つの長方形に拡張します。 2 つの垂直カットまたは 2 つの水平カットを配置して、グリッドを 3 つの独立した領域に分割してみます。 各領域について、事前に計算された最大構造を使用して最適な四角形をクエリし、結果を結合します。 
6. すべての垂直および水平の 3 つのパーティションの最大値を取得します。 有効な配置が存在しない場合、結果はゼロのままです。 

本質的なアイデアは、相互作用する 3 つの形状について考える代わりに、問題をグローバル セパレータ上のスキャンに変換し、重複制約を完全に排除するということです。 

### なぜ効果があるのか

 この正しさは、重なり合わない長方形の最適なセットが投影の x 座標または y 座標によって順序付けできるという事実から得られます。 これらの順序の少なくとも 1 つにより、長方形を連続したストリップに一貫して単調に分離できます。 このような順序が存在すると、連続する長方形の間の境界にカットを配置することで実現可能性が維持され、各長方形は別個の領域に限定されます。 これにより、考えられるすべてのカット位置を検索しても最適な構成を見逃すことがなくなります。

    n, m = len(a), len(a[0])

            row += a[i][j]
            ps[i+1][j+1] = ps[i][j+1] + row

    return ps[x2][y2] - ps[x1][y2] - ps[x2][y1] + ps[x1][y1]

 ## 特殊なケース

 主なエッジケースは、長方形が少なくとも 1 つの次元で大きすぎる場合です。 その場合、配置グリッドは空になり、すべての方向は無視されなければなりません。 アルゴリズムは無効なものをスキップすることでこれを処理します。$(h, w)$早めにペアリングします。 

もう 1 つのケースは、単一の配置が多数存在するにもかかわらず、収まる長方形が 2 つだけである場合です。 有効な構成では各四角形を別個の領域に割り当てる必要があり、実行可能な配置が含まれる領域が 3 つ未満の場合、グローバル最大値はゼロのままであるため、パーティション ロジックにより誤った過剰カウントが自然に防止されます。 

最後の微妙なケースは、最適な長方形が密集領域で重なり合う場合です。 プレフィックス最大アプローチにより、領域が選択されると、完全に切り離された左上の実行可能ゾーンのみが考慮され、長方形の範囲を無視することによって引き起こされる偶発的な重複が防止されます。
