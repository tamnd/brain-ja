 ## 問題の理解

重要な洞察は、次の各桁が`b`～から直接推測できる`s`そして`a`あらゆる可能性を試さずに。 数字は右から左に処理されます。 現在の桁が`s`の現在の桁以上です`a`、次に対応する数字`b`単純に`s_digit - a_digit`。 もし`s_digit < a_digit`の次の上位の桁を調べます。`s`2 桁の数値を形成するには、少なくとも 10 でなければなりません。次に減算します。`a_digit`この 2 桁の数字から、`b`桁。 これでも失敗した場合（2桁の数字が未満の場合）`a_digit`）、解決策はありません。

 ## アルゴリズムのチュートリアル

 1.初期化`b`空のリストとして。 の最下位桁から処理を開始します。`a`そして`s`。 
2. 桁数が残っている間に`a`または`s`の最後の桁を抽出します。`a`(`ad`) と最後の桁`s`(`sd`）。 
3. もし`sd >= ad`、現在の桁を計算します。`b`として`bd = sd - ad`そして追加します`bd`に`b`。 これらの数字をから削除してください`a`そして`s`。 
4. もし`sd < ad`、次の桁を抽出します`s`2桁の数字を形成するには`sd_combined = 10 * next_s_digit + sd`。 もし`sd_combined < ad`または`sd_combined`が 10 ～ 18 の範囲にない場合、解は存在しません。出力は -1 です。 それ以外の場合は計算します`bd = sd_combined - ad`それを追加します`b`。 の 2 桁を削除します`s`そして最後の桁は`a`。 
5.すべての桁が完了したら`a`数字が残っている場合は処理されます。`s`に追加します。`b`の上位桁に対応するため、直接`b`。 
6. リバース`b`最終的な数値は最下位桁から最上位桁まで構築されるため、最終的な数値を取得します。 
7. 印刷`b`先行ゼロなし。 

機能する理由: このアルゴリズムは、各桁位置で次の合計が確実に得られるようにします。`a`そして`b`数字が一致する`s`。 右から左に処理し、必要な場合にのみ 2 桁の場合を考慮することにより、残りの部分が不変条件を保持します。`s`の残りの部分と常に一致する可能性があります`b`。 どこかのステップでこの不変条件が崩れると、解が存在しないことが正しく検出されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a_str, s_str = input().split()
        a = list(map(int, a_str[::-1]))
        s = list(map(int, s_str[::-1]))
        b = []
        i = 0
        j = 0
        while i < len(a):
            if j >= len(s):
                b = -1
                break
            ad = a[i]
            sd = s[j]
            if sd >= ad:
                b.append(sd - ad)
                i += 1
                j += 1
            else:
                if j+1 >= len(s):
                    b = -1
                    break
                sd_combined = s[j+1]*10 + sd
                if sd_combined - ad >= 10 or sd_combined - ad < 0:
                    b = -1
                    break
                b.append(sd_combined - ad)
                i += 1
                j += 2
        if b != -1:
            while j < len(s):
                b.append(s[j])
                j += 1
            b = int(''.join(map(str, b[::-1])))
        print(b)

if __name__ == "__main__":
    solve()
```このコードは、入力数値を逆順に並べた数字のリストに変換し、最下位から最上位へ処理できるようにします。 2 つのポインターを使用します。`i`のために`a`そして`j`のために`s`。 単純な数字の減算が機能する場合、結果を次のように追加します。`b`。 そうでない場合は、次の 2 桁を組み合わせます。`s`有効な条件を形成する`b`桁。 有効な情報の形成に失敗した場合`b`-1 を出力します。 すべての桁を処理した後、残りの桁を追加します。`s`に`b`を反転し、整数に戻して先頭のゼロを削除します。
