 ## 解決策
 ## 問題の理解

 いくつかの文字列が与えられており、それぞれについてそれが正方形の文字列であるかどうかを判断する必要があります。 文字列がそれ自体と連結された部分文字列として表現できる場合、その文字列は正方形になります。 たとえば、「abab」は「ab」が 2 回繰り返されるため正方形ですが、「abcab」は 2 回繰り返されて元の文字列を生成する部分文字列がないため正方形ではありません。 

入力は整数で構成されます`t`に続く`t`文字列。 各文字列の長さは 1 ～ 100 です。文字列が正方形の場合、出力は単純に「YES」、そうでない場合は「NO」になります。 

制約は小さく、長さが 100 までの文字列を最大 100 個までとします。これにより、文字列の長さが 2 次であるアルゴリズムを使用できますが、理想的には文字列ごとに線形または線形に近いチェックを目指します。 

注意すべきエッジケースには、奇数の長さの文字列が含まれます。 たとえば、「aaa」の長さは 3 ですが、これを 2 つの等しい半分に均等に分割することはできません。 奇数長の文字列は自動的に正方形ではなくなります。 もう 1 つの微妙なケースは、完全に正方形である「aa」や「aaaa」のような文字列ですが、注意しないと単純な部分文字列検索では解決策が複雑になりすぎる可能性があります。 「a」のような長さ 1 の文字列は決して正方形ではありません。 

## アプローチ

 ブルートフォースアプローチでは、考えられる長さの部分文字列をすべて考慮します。`n/2`それらを繰り返すと元の文字列が生成されるかどうかを確認します。 ある長さの文字列の場合`n`、次の長さの部分文字列の候補は 1 つだけです`n/2`（前半）。 単純なチェックでは、文字列を前半と後半にスライスして比較します。 各比較には O(n/2) 時間がかかります。 長さ 100 までの文字列は最大 100 個あるため、このアプローチは許容されますが、さらに推論することもできます。 

重要な観察は、文字列の長さが偶数で、前半と後半が同一である場合に限り、文字列は正方形であるということです。 この観察により、問題はすぐに単純なチェックに帰着します。長さが奇数の場合は「NO」を出力し、そうでない場合は「NO」を出力します。 長さが偶数の場合は、2 つの半分を直接比較します。 これは文字列ごとに線形であり、O(1) 個の余分なスペースのみを使用します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース部分文字列繰り​​返しチェック | 文字列ごとに O(n) | O(n) | 承認済み |
 | 半分割比較 | 文字列ごとに O(n) | お(1) | 承認済み |

 ここでは半分に分割する方法が最適であり、実装が簡単です。 

## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各文字列入力をループします。 
3. 各文字列について、その長さを計算します。`n`。 
4. もし`n`奇数の場合は、奇数長の文字列は正方形にできないため、すぐに「NO」を出力します。 
5. もし`n`が偶数の場合、文字列を 2 つの半分に分割します。前半には文字が含まれます。`s[0:n//2]`、後半`s[n//2:n]`。 
6. 2 つの半分を比較します。 それらが等しい場合は、「YES」を出力します。 それ以外の場合は、「NO」を出力します。 

これが機能する理由: 文字列が正方形になる唯一の方法は、文字列が 2 つの同一の半分で構成されている場合です。 最初に長さをチェックすることで、奇数長の文字列を分割しようとしないことが保証され、半分を直接比較することで正確さが保証されます。これは、半分に不一致があるとすぐに正方形のプロパティが無効になるためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    s = input().strip()
    n = len(s)
    if n % 2 == 1:
        print("NO")
    else:
        mid = n // 2
        if s[:mid] == s[mid:]:
            print("YES")
        else:
            print("NO")
```このソリューションは、次を使用してすべての入力を効率的に読み取ります。`sys.stdin.readline`。 改行を削除することは、文字列の長さが正しいことを確認するために重要です。 まず長さのパリティをチェックして明らかな「いいえ」のケースを見つけてから、2 つの半分を直接比較します。

 **例 1:「abab」**

 | 変数 | 値 |

 アルゴリズムは「abab」を正方形として正しく識別します。 

**例 2:「abcab」**

 | 変数 | 値 |

 | パリティ | 奇数 → いいえ |

 奇数長チェックでは即座に「NO」が生成され、このエッジ ケースが正しく処理されます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n * t) | 各文字列の比較は O(n) で、合計 t 個の文字列になります。 
| スペース | お(1) | インデックス付けのために文字列スライスと整数のみを保存します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        s = input().strip()
        n = len(s)
        if n % 2 == 1:
            print("NO")
        else:
            mid = n // 2
            if s[:mid] == s[mid:]:
                print("YES")
            else:
                print("NO")
    return output.getvalue().strip()

# provided sample
assert run("10\na\naa\naaa\naaaa\nabab\nabcabc\nabacaba\nxxyy\nxyyx\nxyxy\n") == \
"NO\nYES\nNO\nYES\nYES\nYES\nNO\nNO\nNO\nYES"

# custom cases
assert run("3\nb\ncc\ndd\n") == "NO\nYES\nYES", "single and double letters"
assert run("2\nabcdabcd\nabcabc\n") == "YES\nYES", "multiple repeated substrings"
assert run("1\na"*100+"\n") == "YES", "max size even repeated char"
assert run("1\na"*99+"\n") == "NO", "max size odd repeated char"

 ## 特殊なケース

 「a」のような長さ 1 の文字列の場合、アルゴリズムは奇数の長さを検出し、「NO」を出力します。 「aa」のような長さ 2 の文字列の場合、「a」と「a」に分割され、それらが等しいと判断され、「YES」が出力されます。 「xxyy」のような文字列の場合は、「xx」と「yy」に分割し、不等号を検出して「NO」を出力します。 このアルゴリズムは、最小、最大、および不均一な繰り返しをすべて正しく処理します。
