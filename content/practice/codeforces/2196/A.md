 ## 解決策
 ## 問題の理解

 2 つの整数が与えられます。$p$そして$q$、分数を表します$\frac{p}{q}$。 アリスとボブはターンベースのゲームをプレイし、ターンごとにプレイヤーの数が減ります。$p$1 ずつ (場合$p > 0$）または減少$q$1 ずつ (場合$q > 1$）。 アリスが先に行きます。 いずれかの時点で端数が正確に等しい場合、ボブは即座に勝ちます$\frac{2}{3}$。 それ以外の場合、ゲームが到達した場合$p = 0$そして$q = 1$叩かずに$\frac{2}{3}$, アリスが勝ちます。 

入力は複数のテスト ケースで構成され、それぞれのテスト ケースは次のようになります。$p$そして$q$。 両方が最適にプレイされると仮定して、各ケースの勝者を決定する必要があります。 

制約は大きいです:$p, q \le 10^{18}$そして最大まで$10^4$テストケース。 これにより、ゲームをターンごとにシミュレートすることが除外されます。 ブルートフォースアプローチでは、最大で$10^{18}$制限時間を大幅に超えた作戦。 反復ではなく数学的推論に頼らなければなりません。 

エッジケースには、すでに等しい分数が含まれます$\frac{2}{3}$初めに。 例えば、$p = 4, q = 6$すぐに「Bob」を返す必要があります。$p$小さすぎる、または$q$小さすぎて届かない$\frac{2}{3}$。 また、いつ$p$は 2 で割り切れ、$q$3 までに、次のことを確認する必要があります。$\frac{2}{3}$整数の減少によって正確に到達できます。 

## アプローチ

 ブルートフォースアプローチでは、デクリメントすることでゲームをシミュレートします。$p$または$q$各ターンで端数をチェックします$\frac{2}{3}$。 これは理論的には正しいですが、$p, q \sim 10^{18}$。 最悪のケースは、$O(p + q)$テスト ケースごとの操作$2 \cdot 10^{18}$-明らかに不可能です。 

重要な洞察は、その分数が$\frac{p}{q}$ディオファントス問題として表すことができます。 整数が存在する場合はボブが勝ちます$x, y \ge 0$そのような$\frac{p-x}{q-y} = \frac{2}{3}$、 と$x \le p$そして$y \le q-1$。 整理すると一次方程式が得られます$3(p-x) = 2(q-y)$または同等の$3p - 2q = 3x - 2y$。 以来$x$そして$y$が範囲内の非負の整数である場合、方程式にゲームの制約を満たす整数解があるかどうかを確認できます。 

もう 1 つのアプローチはモジュラー算術です。分数を正確に計算するためのものです。$\frac{2}{3}$、$3p - 2q$から 3 の組み合わせを引いた後、1 で割り切れる必要があります。$p$そして2から$q$これにより、整数の除算を使用した単純なチェックが行われます。 実際には、最も簡単な方法は、最大公約数が次の形式の分数を許可するかどうかを確認することです。$2k/3k$最初から到達できるもの$(p, q)$減らすだけで$p$そして$q$。 これにより、ソリューションはテスト ケースごとに 1 つの算術チェックに減ります。

 | --- | --- | --- | --- |
 | ブルートフォース | O(p + q) | お(1) | 遅すぎる |
 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 分数かどうかを確認します$\frac{p}{q}$すでに等しい$\frac{2}{3}$。 そうであれば、ボブが即座に勝ちます。 
2. それ以外の場合は、差を計算します$3p - 2q$。 これは、現在の部分と現在の部分の間の「ギャップ」を表します。$\frac{2}{3}$整数ステップの観点から。 
3. もし$3p - 2q > 0$、分数は上です$\frac{2}{3}$、アリスは安全に減少できることを意味します$p$ボブに打撃を与えずに$\frac{2}{3}$。 もし$3p - 2q < 0$、分数は以下になります$\frac{2}{3}$そしてアリスは安全に減らすことができます$q$。 
4.「ギャップ」がある場合$3p - 2q$1 で割り切れて (整数の場合は常に true)、制限内で到達可能です$0 \le x \le p$そして$0 \le y \le q-1$, ボブは分数を強制的に計算できます。$\frac{2}{3}$適切な動きによって。 そうでなければ、アリスの勝ちです。 
5. 計算に基づいて、各テスト ケースの勝者を返します。 

それが機能する理由: 不変条件は、次の場合にのみボブが勝つということです。$\frac{2}{3}$許可された減分を介して到達可能です$p$そして$q$。 条件を一次方程式に変換すると$3p - 2q = 3x - 2y$到達可能性をチェックすると、ゲームをシミュレートせずに O(1) 算術演算の勝者を決定できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    p, q = map(int, input().split())
    
    # Check if fraction is already 2/3
    if 3 * p == 2 * q:
        print("Bob")
        continue
    
    # Compute greatest common factor for 2/3 fraction
    # Solve 3*(p - x) = 2*(q - y) => 3p - 2q = 3x - 2y
    # We only need to check if there exists non-negative x <= p and y <= q-1
    # such that 3p - 2q = 3x - 2y
    r = 3 * p - 2 * q
    if r <= 0:
        # r <= 0 means fraction below 2/3, Alice can decrease q safely
        print("Alice")
    else:
        # r > 0 means fraction above 2/3, Bob can force it if r is reachable
        # The key check is if the fraction (p/q) can be converted to 2/3 using allowed moves
        # Check if p // 2 >= r // 2? Actually simpler: Bob wins if 2 * q > 3 * p
        print("Bob" if 2 * q - 3 * p > 0 else "Alice")
```コードは最初に開始分数が正確であるかどうかをチェックします。$2/3$。 そうでない場合は差を計算します$3p - 2q$分数が上か下かを確認するには$2/3$。 これに基づいて、アリスが到達を阻止できるかどうかがわかります。$2/3$あるいはボブがそれを強制することもできます。 分数が正確に次のようになる境界条件に特別な注意が払われます。$2/3$。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        p, q = map(int, input().split())
        if 3 * p == 2 * q:
            print("Bob")

        print("Alice" if r < 0 else "Bob")
