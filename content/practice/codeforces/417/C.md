 ## 解決策
 ## 問題の理解

 私たちは、間の試合の完全な記録を構築するように求められています。`n`すべての試合に勝者と敗者があり、どのチームも複数回プレーすることはありません。 満たさなければならない最終条件はグローバルです: 個別のチームの順序付けられたペアごとに`(i, j)`、 チーム`i`チームに勝ったに違いない`j`その通り`k`回。 

これを有向マルチグラフとして見るもう 1 つの方法は、`n`頂点。 各試合は勝者から敗者への直接的なエッジです。 2 つのチームは同じペアで複数回プレイできないため、任意の 2 つの頂点間には各方向に最大 1 つのエッジが存在できます。 要件は、すべての順序ペアに対して次のようになります。`(i, j)`、まさにあります`k`からの有向エッジ`i`に`j`。 

これにより、一致の合計数がすぐに修正されます。 がある`n(n-1)`順序ペア、それぞれが正確に寄与する`k`エッジなので、答えには次のものが含まれている必要があります`m = k * n * (n-1)`解決策が存在する場合はゲーム。 

制約`n, k ≤ 1000`最大約 100 万個のエッジを許可します。`n(n-1)k ≤ 10^6`。 エッジを構築するあらゆるソリューション`O(n^2 k)`これはまだ実現可能ですが、複雑なスケジューリングをシミュレートしたり、グローバルな一貫性を動的に維持しようとすると、不必要なオーバーヘッドが発生する危険があります。 

微妙なエッジケースは次のような場合です`n = 1`。 個別のチームのペアがないため、試合はまったくありません。 要件は空に満たされているため、正解は 1 行です`0`。 もう一つのコーナーは、`k = 0`、ここでも一致する必要はなく、答えは次のようになります。`0`。 ペアごとに少なくとも 1 つのエッジを想定する不注意な構築では、空ではないものを誤って出力しようとします。 

主な困難は、実現可能性ではなく、順序付けされていない各ペアが各方向に 1 回しか出現できないという制限の下で構築することですが、それでも達成できることです。`k`それぞれの方向で勝利します。 

## アプローチ

 ブルートフォースの考え方では、ペアごとに試合を割り当て、バックトラッキングまたは増分スケジュールを使用して正確な勝利数が維持されるようにしようとします。 すべての順序付けされたペアを反復処理することを想像することもできます。`(i, j)`そして正確に割り当てようとしています`k`からの勝利`i`に`j`、各ステップで制約が満たされたままであるかどうかをチェックします。 これはすぐに制約充足問題に発展します。`O(n^2 k)`しかし、それぞれの決定は将来のすべての割り当てに依存します。 最悪の場合、各割り当てはグラフ全体で対称的に残りの容量に影響を与えるため、検索スペースは指数関数的になります。 

要件の構造は、見た目よりもはるかに単純です。 注文したすべてのペア`(i, j)`他のすべてから独立しています: からの勝利数`i`に`j`他のペアとは相互作用しません。 唯一の制限は、同じ順序ペアを同じ構築層で複数回再利用できないことです。 これは、構築を次のように分割することを示唆しています。`k`同じラウンド。 

各ラウンドで、順序のないすべてのペアの向きを変える必要があります`{i, j}`正確に 1 回、どちらかを生成します`i → j`または`j → i`。 すべてのペアが有向エッジとして 1 回だけ現れる単一ラウンドを設計できれば、その構造を繰り返すことができます。`k`回はすぐにすべてのカウントを正確に乗算します`k`順序付けされたペアごとに、方向ごとに勝ちます。 

したがって、タスクはトーナメント (完全なグラフの完全な方向付け) を 1 回構築するだけになります。 標準的な循環順序付けはこれを実現します。つまり、チームを円状に配置し、すべてのエッジを円に沿って前方に向けます。 このオリエンテーションを繰り返すことで`k`各ペアはラウンドごとに 1 回出現し、常に同じ方向になるため、times はすべての制約を満たします。

 ## アルゴリズムのチュートリアル

 1. もし`n == 1`または`k == 0`、出力`0`そしてやめてください。 このような場合、構築する有効な一致はありません。 
2. チームの順序を修正します。`1`に`n`。 
3. 1 ラウンドで、すべてのペアを反復処理します。`(i, j)`と`i < j`。 各ペアについて、一貫して方向性を決定します。たとえば、常に`i → j`。 これにより、すべてのペアが 1 回だけ使用される完全なトーナメントが形成されます。 
4. この単一ラウンドの構築を繰り返します`k`回。 各繰り返しは同一であり、同じセットの有向エッジが生成されます。 
5. 生成されたすべての一致を出力します。 エッジの総数は`k * n * (n - 1) / 2`各ペアがラウンドごとに 1 つの直接一致のみを提供する場合、ただし、すべての順序付きペアが出現する必要があるため、`k`何度も、構築の一貫性により、ラウンド全体でペアごとに両方向を明示的に放射します。 

より正確な解釈は、順序のない各ペアがラウンドごとに 1 つの有向エッジに寄与し、ラウンドを繰り返すことで各順序ペアが正確に表示されることを保証するというものです。`k`合計で回。 

### なぜ効果があるのか

 順序付けされていない各ペア`{i, j}`はラウンドごとに 1 回だけ考慮され、その方向は固定されています。 これにより、1 ラウンドで次のうちの 1 つが確実に実行されることが保証されます。`i → j`または`j → i`が表示されます。 以上`k`同一のラウンドでは、順序付けられたすべてのペアが正確に表示されます`k`繰り返しを通じて両方の方向が均等にカバーされるように、異なるラウンドで交互に、または系統的に方向を割り当てるようにすると、何度も繰り返します。 巡回シフト解釈により、すべてのペアが正確に両方向に向けられることが保証されます。`k`必要な対称性を満たしています。 重要な不変条件は、すべてのペアが繰り返しにわたって独立して均一に扱われるため、カウントは干渉することなく線形にスケールされるということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

if n == 1 or k == 0:
    print(0)
    sys.exit()

res = []

for _ in range(k):
    for i in range(1, n + 1):
        for j in range(i + 1, n + 1):
            res.append((i, j))
            res.append((j, i))

print(len(res))
for a, b in res:
    print(a, b)
```この構築は、すべての順序付けされていないペアを直接反復します。`(i, j)`そして、繰り返しのたびに、可能な両方の有向一致を出力します。 これにより、順序付けされたペアごとに、`(i, j)`、ラウンドごとに 1 回の出現があり、全体にわたって`k`これを合計すると正確に丸められます`k`出来事。 

重要な実装の詳細は、各ラウンド内のペアごとに両方向を明示的に出力することです。 これにより、向きを追跡したりバランスをとったりする必要がなくなります。 ループの順序付けにより、出力が確定的になり、単一ラウンド内でペアの欠落や重複がないことが保証されます。

 ## 特殊なケース

 いつ`n = 1`、ループはペアを生成しないため、結果リストは空のままで、出力は次のようになります。`0`。 満たすべき順序付きペアがないため、これは要件に一致します。 

いつ`k = 0`、ガード状態はすぐに戻ります`0`構築ロジックを入力せずに。 これにより、ゲームが必要ない場合に無効な一致が生成されることが回避されます。 

小型用`n = 2`、この構造では、ラウンドごとに各方向に 1 つずつ、正確に 2 つの有向エッジが生成されます。 これを繰り返すと`k`回はバランスのとれたカウントを生成します`k`両方向で要件を正確に満たします。
