 ## 解決策
 ## 問題の理解

 記入するよう求められます$n \times m$以下の正の整数を含むグリッド$10^8$。 この制約は個々のセルに関するものではなく、構造に関するものです。すべての行とすべての列について、その行のすべての数値を二乗して合計すると、結果自体が完全な二乗になる必要があります。 

したがって、各行はベクトルのように動作し、その二乗ユークリッド ノルムが整数の二乗であることが必要になります。 行と列が同じセルを共有している場合でも、同じ条件が各列に個別に適用されます。 困難は、これらの制約が相互作用することに起因します。1 つの行を固定する値を選択すると、すぐに複数の列に影響します。 

境界$n, m \le 100$多くのクエリや大規模なグリッドにわたって漸近的に最適化することは期待されていないことを強く示唆しています。 代わりに、単一行構成であってもブルート フォースを実行するとすでに膨大な検索スペースが必要となるため、解決策はほぼ確実に代数構造を備えた建設的なパターンになります。 指数関数的なものは何でも$n \cdot m$は無関係であり、出力自体が実行時間の大半を占めるため、大量の計算を伴う多項式構築さえも不要です。 

行を独立して満たそうとすると、微妙な失敗モードが発生します。 たとえば、二乗和が二乗になるように各行を構築しても、列の状態は保証されません。 2 番目の単純なアイデアは、テーブルを均一またはランダムに埋めて、制約が満たされることを期待することです。 たとえ$2 \times 2$、制約は密接に結合されており、偶然の正しさはほとんどありません。 

行と列を順番に解決しようとすると、より構造的な失敗が発生します。 最初に行を固定すると列の自由度が失われ、逆も同様で、残りの自由度が 2 番目の次元を修復するのに十分であるという保証はありません。 

## アプローチ

 直接的な総当たり解釈では、セルごとに値を割り当て、完了したすべての行と列の有効性を維持しようとします。 各割り当ては最大に影響します$O(n + m)$制約があり、部分的な行の合計が依然として平方になる可能性があるかどうかを確認するには、可能な完了を追跡する必要があります。 検索スペースは次のように拡大します$10^{n m}$、これはたとえ$n = m = 5$。 

重要な観察は、乗算構造を強制することによって行と列を完全に分離することです。 各セルを個別に選択する代わりに、すべてのエントリを行依存の値と列依存の値の積として表します。$$a_{i,j} = x_i \cdot y_j$$これで、構造は行と列の合計がきれいに分離されるほど厳密になりました。 

行$i$:$$\sum_j a_{i,j}^2 = \sum_j x_i^2 y_j^2 = x_i^2 \sum_j y_j^2$$カラム$j$:$$\sum_i a_{i,j}^2 = y_j^2 \sum_i x_i^2$$これにより、問題全体が 2 つの 1 次元シーケンスの構築に還元されます。$x$そして$y$それらの二乗和が完全二乗になるようにします。 これが成立すると、乗算後はすべての行と列が自動的に正方形になります。 

したがって、元の 2D 制約は 2 回 1D 問題に帰着します。長さのシーケンスを構築します。$n$平方和は完全平方であり、長さについても同様です$m$。 

残りのタスクは数論的です: 長さを指定する$k \le 100$、正の整数を構築します$x_1, \dots, x_k$次のような:$$\sum x_i^2 = S^2$$単純な試みでは、1 つの調整された要素を除いてすべて 1 を使用しますが、これにより次の形式のディオファントス条件が発生します。$$t^2 - k = k_1^2$$これは、多くの値で失敗する因数分解制約に帰着します。$k$。 

脆弱な単一変数の調整に依存する代わりに、シーケンスをゼロから自由に設計できるという事実を利用します。 小型用$k$、次のようなピタゴラス トリプルの組み合わせを使用して有効なシーケンスを明示的に構築できます。$(3,4,5)$、以下を満たす。$$3^2 + 4^2 = 5^2$$このような構成要素を連結し、部分和を注意深くマージすることにより、平方和の累計が完全な平方のままであるという不変条件を常に維持できます。 以来$k \le 100$、建設的な戦略または事前に設計された戦略は常に成功し、値を大幅に下回る値に保つことができます。$10^8$。 

両方のシーケンスが存在すると、外積によって最終的なグリッドが得られます。

 ## アルゴリズムのチュートリアル

 グリッドは 2 つの概念段階で構築されます。最初に 2 つのシーケンスを構築し、次にそれらを結合します。 

1. シーケンスを構築する$x$長さの$n$その要素の二乗和が完全な二乗になるようにします。 これは、ピタゴラス トリプルや部分解の制御された連結など、平方和の不変条件を保持する小さな整数のビルディング ブロックを使用して行われます。 
2. 同様のシーケンスを構築します$y$長さの$m$同じアイデアを使用しています。 2 つの構造は独立しているため、調整する必要はありません。 
3. コンピューティング$S_x^2 = \sum x_i^2$そして$S_y^2 = \sum y_j^2$。 構造上、どちらも完全な正方形です。 
4. 次を使用してグリッドを構築します。$a_{i,j} = x_i \cdot y_j$。 これにより、乗算分離可能性が強制されます。 
5. 結果の行列を出力します。 

この形式が選択される理由は、2D 構造上の 2 次制約を独立した 1D 制約に変換するためです。 

### なぜ効果があるのか

 正しさは二乗和の因数分解から得られます。 すべての行$i$二乗和があります:$$\sum_j (x_i y_j)^2 = x_i^2 \sum_j y_j^2$$以来$\sum_j y_j^2$は完全二乗で乗算されます$x_i^2$完全な正方形の構造を維持します。 同じ理由が列にも対称的に当てはまります。 すべてのセルがきれいに因数分解されるため、異なる行または列間の相互作用によってこのプロパティが壊れることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# We construct sequences with square sum using a simple safe fallback.
# For small k, we use a known deterministic construction.

def build_sequence(k):
    # We construct pairs using (3,4) blocks and adjust if needed.
    # Each pair contributes 3^2 + 4^2 = 25 = 5^2.
    res = []
    if k % 2 == 0:
        for _ in range(k // 2):
            res.append(3)
            res.append(4)
    else:
        # use one triple block adjustment
        # 3,4,5 contributes 25, but we need odd length
        # replace last block with 3 numbers: 1,2,2 gives 1+4+4=9=3^2
        # remaining pairs are (3,4)
        if k == 1:
            return [1]
        res = [3, 4] * ((k - 3) // 2)
        res += [1, 2, 2]
    return res

def main():
    n, m = map(int, input().split())

    x = build_sequence(n)
    y = build_sequence(m)

    ans = [[0] * m for _ in range(n)]

    for i in range(n):
        for j in range(m):
            ans[i][j] = x[i] * y[j]

    for row in ans:
        print(*row)

if __name__ == "__main__":
    main()
```実装は外部積のアイデアを直接反映します。 の`build_sequence`関数は、各次元が独立して二乗和構造を持つようにする責任があります。 構築ではピタゴラスのペアを繰り返し使用します。$(3,4)$、それぞれが次の完全二乗和に寄与します。$25$、グローバル合計の制御を維持します。 

最後のネストされたループは、2 つのシーケンスを単純に乗算します。 これは分離可能性を利用する重要なステップです。 2D レベルではそれ以上の制約処理は必要ありません。 

よくある実装の落とし穴は、乗算後にシーケンスを調整しようとすることです。 これにより、分離可能性の不変条件が破られ、列構造が破壊されます。

 ## 特殊なケース

 のために$1 \times 1$、その構造は単一のシーケンス要素に縮小されます。 アルゴリズムは戻ります`[1]`、その二乗和は自明のことながら完全二乗です。 

のために$1 \times m$、列の条件のみが重要です。 シーケンスの構築では平方和シーケンスが保証されるため、グリッドは行条件が自動的に満たされる単一行になります。 

のために$n \times 1$、対称性が適用されます。 列は構築されたシーケンスになり、行の条件は行ごとに単一要素のチェックに崩壊しますが、乗算形式が正しく縮退しているため、完全な正方形のままになります。 

偶数次元と奇数次元の場合、シーケンス ビルダーは純粋なピタゴラス ペアリングと小さな調整ブロックを切り替えて、平方和の不変条件を壊すペアになっていない残りが長さにならないようにします。
