 ## 解決策
 ## 問題の理解

 次のサイズの長方形グリッドを使用しています。$w \times h$ここで、各セルはプレート上の単位正方形と考えることができます。 このグリッド上に金メッキの「輪」を繰り返し描いていきます。 最初のリングは、長方形全体の外側の境界線をカバーします。 2 番目のリングはその内側に 1 つのレイヤーで描画されますが、外側の境界からあらゆる方向に 2 セル離れたところから開始され、このパターンが続きます。 

より正確には、$i$-th リングは、元のグリッドを縮小した後に残る長方形の境界線です。$2(i-1)$両側からのレイヤー。 つまり、リングの内側の長方形$i$寸法があります$(w - 4(i-1)) \times (h - 4(i-1))$、その境界セルのみを取得します。 

タスクは、配置後に金メッキされる個別のセルの数を計算することです。$k$そんな指輪。 

制約は非常に小さく、$w, h \le 100$。 これにより、総作業量が定数係数によって制限されるため、グリッド上の直接計算や単純なリングごとの計算が安全であることがすぐにわかります。 漸近的に最適化されたデータ構造やリングごとの定数時間演算を超える巧妙な前処理は必要ありません。 

主な微妙な点は、計算上のものではなく概念的なものです。各リングは縮小する長方形の境界線であり、長方形の境界に属するセルの数を二重に数えたり、誤解したりしないように注意する必要があります。 

典型的な間違いは、各リングが常に完全な長方形の境界式を持っていると仮定したときに発生します。$2(w + h) - 4$。 これは外側のリングにのみ機能します。 内側のリングの場合、寸法が縮小し、小さな長方形が変形する可能性があります。 

たとえば、次の場合$w = h = 3$そして$k = 1$、答えは 8 です。単純な実装では、コーナーを誤って減算したり、最小限のグリッドであってもすべての境界セルが依然として有効であることを見逃したりする可能性があります。 

縮小後に長方形が非常に小さくなった場合、別のエッジ ケースが発生します。 たとえば、リングが$1 \times m$または$2 \times m$長方形の場合、上下（または左右）が重なるため、境界式が変わります。 これを処理できないと、過剰カウントにつながります。 

## アプローチ

 ブルートフォースの方法は、グリッドを明示的にシミュレートすることです。 各リングについて、その境界四角形を計算し、その境界上のすべてのセルをブール グリッドでマークします。 すべてのリングを処理した後、マークされたセルをカウントします。 これは定義に直接従っているため、正しいです。 

ただし、これでは無駄に重いです。 それでも$w, h \le 100$、シミュレーションはまだ最大で実行できます$k \cdot (w \cdot h)$最悪の場合は動作します。 技術的にはまだ許容可能ですが、問題の構造が隠蔽され、実装ミスが発生しやすくなります。 

重要な観察は、各リングが単に寸法が線形に減少する長方形の周囲であるということです。 したがって、セルにマークを付ける代わりに、各リングの周囲長を直接計算してそれらを合計することができます。 必要な唯一の注意は、高さまたは幅が 1 または 2 になったときに縮退した長方形を正しく処理することです。 

長方形の場合$a \times b$、境界セル数は次のとおりです。 

- もし$a = 1$、すべてのセルは 1 行にあります。$b$- もし$b = 1$、すべてのセルは 1 つの列にあります。$a$- それ以外の場合は、$2a + 2b - 4$この公式を各リングに対応する各内側の長方形に適用します。

 ## アルゴリズムのチュートリアル

 各リングを反復処理し、その境界サイズを合計することで答えを計算します。 

1. 最初はセルがカウントされないため、答えが 0 であることから始めます。 各リングからの貢献を個別に蓄積していきます。 
2. リングインデックスごとに$i$0から$k-1$、内側の長方形の寸法を計算します。 各リングは元の長方形を次のように縮小します。$2i$あらゆる面から見た場合、残りの寸法は次のようになります。$a = w - 2i \cdot 2$、$b = h - 2i \cdot 2$、これを単純化すると、$a = w - 4i$、$b = h - 4i$。 
3. この長方形の境界セルの数を計算します。 もし$a = 1$、リングは単一列であり、$b$細胞。 もし$b = 1$、単一列であり、貢献します$a$細胞。 それ以外の場合は貢献します$2a + 2b - 4$。 コーナーの減算では適切な 2D 長方形が想定されるため、この区別が必要になります。 
4. この寄与分を累計に加算します。 各リングは厳密に小さい内側の長方形上にあるため、各リングは他のリングから切り離されています。 
5.すべての処理が完了したら$k$リングの累積和を出力します。 

### なぜ効果があるのか

 各リングは、一意に定義された内側の長方形の境界に正確に対応しており、これらの境界は、次の異なる値間で重なりません。$i$。 縮小プロセスにより、すべてのセルが最大 1 つのリングに属することが保証されます。 各長方形の境界セルの正確な数を計算するため、合計では各金色のセルが 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

w, h, k = map(int, input().split())

ans = 0

for i in range(k):
    a = w - 4 * i
    b = h - 4 * i

    if a <= 0 or b <= 0:
        break

    if a == 1:
        ans += b
    elif b == 1:
        ans += a
    else:
        ans += 2 * a + 2 * b - 4

print(ans)
```このソリューションは各リングを反復し、直接式を使用して現在の四角形のサイズを再計算します。 重要な詳細は、収縮率です。$4i$これは、リング層ごとに各側で 2 つのセルを内側に移動することにより、幅と高さの両方を 1 ステップごとに 4 ずつ事実上縮小します。 

境界の計算では、縮退したケースが慎重に分離されます。 これらのチェックを行わないと、次のような長方形が表示されます。$1 \times b$間違って使用するだろう$2a + 2b - 4$、これは過少カウントになります。

## テストケース```python
import sys, io

def solve():
    import sys
    input = sys.stdin.readline
    w, h, k = map(int, input().split())

    ans = 0
    for i in range(k):
        a = w - 4 * i
        b = h - 4 * i
        if a <= 0 or b <= 0:
            break
        if a == 1:
            ans += b
        elif b == 1:
            ans += a
        else:
            ans += 2 * a + 2 * b - 4
    print(ans)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    solve()
    return sys.stdout.getvalue().strip()

# provided samples
assert run("3 3 1") == "8"

# minimum grid
assert run("3 3 1") == "8"

# multiple rings shrinking to single line
assert run("5 1 2") == "5"

# rectangular case
assert run("6 4 1") == "16"

# two rings
assert run("7 7 2") == "24"
```| テスト入力 | 期待される出力 | 検証内容 |

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、長方形が縮小後に単一の行または列に折りたたまれる場合です。 このような場合、周長の式でコーナーを減算してはなりません。 たとえば、$1 \times 5$長方形の場合、5 つのセルすべてが境界に属しており、次を使用します。$2a + 2b - 4$間違って与えるだろう$2 \cdot 1 + 2 \cdot 5 - 4 = 8$、それは間違いです。 条件付き処理により、正しい線形カウントが保証されます。 

もう 1 つのエッジ ケースは、内側の長方形が無効になる (正の寸法ではない) 場合に発生します。 たとえば、$w = 5, h = 5, k = 3$、3 番目のリングは負の寸法を生成します。 ループ終了条件により、存在しないリングのカウントが防止され、有効な寄与のみが蓄積されることが保証されます。
