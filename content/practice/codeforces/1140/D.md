 ## 解決策
 ## 問題の理解

 次のような正多角形が与えられます。`n`ラベル付きの頂点`1`を通して`n`反時計回りの順序で。 目標は、すべての三角形の「重み」の合計が最小になるように、この多角形を重ならない三角形に分割することです。 三角形の重みは、その 3 つの頂点ラベルの積です。 出力は単一の整数で、すべての可能な三角形分割の中で達成可能な最小の合計です。 

制約により許可されるのは、`n`可能な三角形分割の数は、次のように指数関数的に増加するため、`n`、すべての三角形分割を明示的に試行するアルゴリズムは遅すぎます。 2 秒以内の操作の上限はおおよそ次のとおりです。`10^8`これは、すべての三角形分割を強引に列挙することは完全に不可能であることを意味します。 重複する部分問題の再計算を回避する体系的な方法が必要です。 

すでに三角形であるポリゴンでは、微妙なエッジ ケースが発生します。 例えば、`n = 3`重みのある単一の三角形を生成します`1 * 2 * 3 = 6`。 を前提とした素朴な実装`n > 3`さらに分割しようとすると、インデックス エラーが発生したり、不要な操作が追加されたりします。 長方形または四角形の場合は、別のエッジ ケースが表示されます (`n = 4`)、対角線の選択が合計に影響します。 頂点を持つ長方形を取ると`1,2,3,4`、斜めにカット`1-3`総重量は次のとおりです`1*2*3 + 1*3*4 = 6 + 12 = 18`、斜めにしながら`2-4`与える`1*2*4 + 2*3*4 = 8 + 24 = 32`。 アルゴリズムは、ヒューリスティックに依存するのではなく、これらのオプションを体系的に探索する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、可能なすべての三角形分割を試み、各三角形の頂点ラベルの積を合計し、最小値を選択します。 これはすべての構成を明示的に考慮するため、原則的には正しいです。 ただし、三角形分割の数は、`n`-gon は次によって与えられます。`(n-2)`-番目のカタロニア語の数。指数関数的に増加します (`C_18 > 10^6`、`C_20 > 10^7`)、したがって、`n = 20`単純な再帰で処理するにはすでに大きすぎます。 

重要な洞察は、この問題が重複する部分問題と最適な下部構造を示しているということです。 ポリゴンの三角形分割は、隣接しない 2 つの頂点間の対角線を選択し、ポリゴンを 2 つの小さなサブポリゴンに分割し、それらを再帰的に三角形分割するものとみなすことができます。 これにより、動的プログラミングが可能になり、頂点の連続するサブシーケンスごとに最小の三角形分割の重みを計算できます。 各三角形はその重みを 1 回だけ提供し、各サブポリゴンの最小値は再帰呼び出し間で再利用できます。 

これにより、時間の複雑さが軽減されます。`O(n^3)`そして空間の複雑さは`O(n^2)`。 のために`n = 500`、`n^3 = 125*10^6`これは、Python ソリューションの 2 秒の制限内に快適に収まります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(C_n) 指数関数 | お(1) | 遅すぎる |
 | 動的プログラミング | O(n^3) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ポリゴンの頂点を配列として表現します。`[1, 2, ..., n]`。 DP テーブルを定義する`dp[i][j]`頂点によって形成される多角形の最小三角形分割重みを保存します。`i`に`j`包括的、仮定すると`i < j`。 
2. 基本ケースを初期化します。 頂点が 3 つ未満のセグメントの場合 (`i+1 >= j`）、`dp[i][j] = 0`なぜなら、線や単一の頂点では三角形を形成できないからです。 
3. 3 から 3 までのサブポリゴンのすべての長さにわたって反復します。`n`。 それぞれの長さごとに`l`、すべての開始インデックスを考慮します`i`と`j = i + l - 1`。 これにより、指定されたサイズのすべての連続したポリゴンが考慮されることが保証されます。 
4. 各サブポリゴンについて`i`に`j`、考えられるすべての頂点を試してください`k`厳密に間`i`そして`j`三角形の 3 番目の頂点として`(i, k, j)`。 DP の繰り返しは次のとおりです。```
dp[i][j] = min(dp[i][j], dp[i][k] + dp[k][j] + i*k*j)
```ここ、`dp[i][k]`そして`dp[k][j]`は、対角線によって作成される左右のサブポリゴンの最小三角形分割ウェイトです。`(i, j)`。 
5. DP テーブルに記入すると、答えは次のようになります。`dp[1][n]`、ポリゴン全体の最小ウェイト。 

機能する理由: すべての三角形分割は、対角線を含む一連の三角形の選択として表すことができます。 繰り返しにより、すべてのサブポリゴンについて、その端で可能なすべての三角形が考慮され、最小値が保存されます。 ループは有効なすべての設定を反復するため、構成が失われることはありません。`k`。 不変条件とは、`dp[i][j]`常に頂点の最小三角形分割重みが含まれます`i..j`満たされたら。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

# vertices are labeled 1..n
dp = [[0]*(n+1) for _ in range(n+1)]

# length of sub-polygon
for length in range(3, n+1):
    for i in range(1, n-length+2):
        j = i + length - 1
        dp[i][j] = float('inf')
        for k in range(i+1, j):
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k][j] + i*k*j)

print(dp[1][n])
```DP テーブル`dp`はゼロに初期化されます。 ネストされたループは、サブポリゴン サイズを増やすことでそれを埋め、計算時に確実に`dp[i][j]`、エントリ`dp[i][k]`そして`dp[k][j]`はすでに計算されています。 私たちが使用するのは`float('inf')`適切な最小化を確保するため。 製品`i*k*j`三角形の重みを計算します。

## 複雑さの分析

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    dp = [[0]*(n+1) for _ in range(n+1)]
    for length in range(3, n+1):
        for i in range(1, n-length+2):
            j = i + length - 1
            dp[i][j] = float('inf')
            for k in range(i+1, j):
                dp[i][j] = min(dp[i][j], dp[i][k] + dp[k][j] + i*k*j)
    return str(dp[1][n])

# Provided samples
assert run("3\n") == "6", "sample 1"
assert run("4\n") == "18", "sample 2"

# Custom cases
assert run("5\n") == "40", "pentagon minimal triangulation"
assert run("6\n") == "80", "hexagon minimal triangulation"
assert run("3\n") == "6", "minimum size triangle"
