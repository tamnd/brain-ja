 ## 問題の理解

 2 つの記号のみからなる文字列が与えられています。`>`そして`<`。 ローカルな方向に「削除をプッシュ」する操作を繰り返し実行することが許可されています。`>`を選択しているときに、すぐ右側の文字を削除します。`<`すぐ左側の文字を削除します。 これらの操作は、任意の順序で任意の回数適用できます。 

操作を実行する前に、文字列から一部の文字を完全に削除することがあります。 私たちの目標は、許可された操作を使用して、残りの 1 文字まで完全に削減できる文字列を最終的に得ることです。 

中心的な問題は、削除をどのようにシミュレートするかということではなく、これらの方向性のある削除の下で残りの構造が 1 点に折りたたまれるのに十分な柔軟性を持たせるために、最初にどの文字を削除するかをどのように決定するかということです。 

制約は小さく、文字列の長さは最大 100、テスト ケースは最大 100 です。 これにより、おおよそより重いものは即座に除外されます$O(n^2)$テスト ケースごとに異なりますが、より重要なのは、「良好な」構成のきれいな線形または線形に近い特性評価が存在する必要があることを示唆していることです。 

微妙なエッジ ケースとして、文字列に両方の記号が含まれている場合でも、文字列が削除されずにすでに削減可能である場合があります。 例えば、`><<`は、1 文字だけが残るまで操作を左方向にカスケードできるため、すでに優れています。 一方で、`<>`は、たとえ 2 文字の長さであっても、最初に何かを削除しないと崩れるのを防ぐために、方向が互いに反対しているため、適切ではありません。 

この難しさは、削除がグローバルではないという事実から生じます。つまり、ある文字はそのすぐ隣の文字にのみ影響を及ぼします。 このため、情報がローカルにどのように流れるかを反映しない限り、素朴な「カウント引数」は信頼できなくなります。 

## アプローチ

 ブルートフォース手法では、保持する文字のすべてのサブセットを試行し、許可された操作で残りの文字列を単一の文字に削減できるかどうかをシミュレートします。 サブセットごとに、削除プロセスをシミュレートする必要がありますが、それ自体は線形です。 あるので$2^n$サブセットの場合、これはすぐに実行不可能になります。$n = 100$、天文学的な長さのランタイムに達します。 

重要な点は、プロセスを明示的にシミュレートする必要がないということです。 操作は方向性のある構造を課します。`>`常に右に行動し、`<`常に左方向に動作します。 つまり、選択した点の左側に「右押し」の文字が何個存在し、右側に「左押し」の文字が何個存在するかが重要になります。 

「最後の生き残り」として想像する位置を固定すると、その左側にあるすべてのものは最終的に右側から排除され、その右側にあるすべてのものは最終的に左側から排除されなければなりません。 これにより、単純な特性評価が得られます。最終位置の可能性があるすべてについて、その位置を安定させるために不一致の方向文字をいくつ削除する必要があるかを計算し、すべての位置の最小値を取得します。

 ## アルゴリズムのチュートリアル

 この問題は、文字列内で最後に生き残る位置を選択し、その位置を崩壊点にすることで周囲の文字がどの程度「非互換」であるかを測定することであると解釈します。 

1. ポジションごと$i$文字列内で、それを最後に残った文字の候補として扱います。

3. 文字列のサフィックス (位置) をスキャンします。$i+1$に$n-1$）何個数えますか`<`の文字が表示されます。 これらも同様に問題があります。`<`は左側のみを削除するため、最終位置の右側にある場合は、間違った方向への圧力が発生します。

### なぜ効果があるのか

 重要な不変条件は、有効な縮小プロセスでは最終的に残りのすべての文字を単一の位置に集中させる必要があり、方向制約によってその位置の各辺が折りたたみ方向と「互換性」を持つように強制されることです。 あ`>`左側のは、削除されるか、消去を右側に押し出す方法で使用されない限り、ローカルで解決できません。`<`右側にあります。 

したがって、すべての無効な構成は、最終的な生存者に対する方向と位置の不一致として解釈される可能性があります。 これらの不一致を最小限に抑えることは、完全に折りたたみ可能な構造に到達するために必要な欠失を最小限に抑えることに正確に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input().strip())
        s = input().strip()

        # prefix count of '>'
        pref = [0] * (n + 1)
        for i in range(n):
            pref[i + 1] = pref[i] + (s[i] == '>')

        # suffix count of '<'
        suff = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            suff[i] = suff[i + 1] + (s[i] == '<')

        ans = n
        for i in range(n):
            cost = pref[i] + suff[i + 1]
            ans = min(ans, cost)

        print(ans)

if __name__ == "__main__":
    solve()
