 ## 解決策
 ## 問題の理解

 相互に直交する 4 つのもつれ状態のいずれかにあることが保証されている 2 つの量子ビットのシステムが与えられています。 これらの状態は 2 量子ビット空間の完全な基礎を形成するため、そのうちの 1 つが正確​​に存在し、タスクはどれを特定するかです。 

古典的な入力を受け取る代わりに、量子演算を使用して量子ビットを直接操作し、測定を実行することができます。 出力する必要があるのは、準備済み状態を識別する 0 ～ 3 の整数だけです。 終了後、量子ビットは任意に崩壊する可能性があるため、最終的な状態は無関係です。 

古典的な観点から見ると、これは「回転基底での測定による分類」問題です。 重要な制約は、測定は計算上の基礎においてのみ意味をなすため、いかなる戦略も与えられた基礎を直接観測可能なものに変換する必要があるということです。 

システムのサイズは 2 量子ビットに固定されているため、古典的な意味での漸近的な懸念はありません。 唯一の関連する制約は、一定数の量子ゲートと測定を使用しなければならないことです。 これにより、振幅を間接的に再構築しようとしたり、統計的推定のために測定を複数回繰り返したりする考えは除外されます。 状態は完全に直交しているため、サンプリングを繰り返す必要はありません。 

微妙な落とし穴は、基底を変更せずに量子ビットを直接測定しようとすることです。 Bell 基底では、直接測定により相関のあるランダム性が生成され、4 つの状態が区別されません。 たとえば、両方とも$|00\rangle + |11\rangle$そして$|00\rangle - |11\rangle$すぐに測定すると同じ古典的な分布に崩壊するため、最初に補正変換を適用しない限りそれらを区別できなくなります。 

## アプローチ

 単純なアイデアは、両方の量子ビットを計算基盤で直接測定し、観察された結果から状態を推測しようとすることです。 これは、各ベル状態が古典的なビット列に対して確率的な混合を生成するため、失敗します。 例えば、$|\Phi^+\rangle$そして$|\Phi^-\rangle$どちらも等しい確率で結果 00 と 11 を生成するため、それらを区別するには繰り返し測定することが唯一の方法ですが、状態は 1 回の観察後に破壊されるため、繰り返し測定することは不可能です。 

正しいアプローチでは、標準的な量子トリックを使用します。つまり、固定ユニタリ変換を使用してベル基底を計算基底に変換します。 与えられた 4 つの状態はまさにベル状態であり、各ベル状態を固有の基底ベクトルにマッピングするよく知られた回路があります。 

変換は可逆的であり、2 つの操作で構成されます。 まず、最初の量子ビットを制御として、2 番目の量子ビットをターゲットとして使用して CNOT ゲートを適用します。 これにより、量子ビット間の相関関係が解消されます。 次に、最初の量子ビットにアダマール ゲートを適用し、位相情報を計算情報に変換します。 この変換後、各ベル状態は 4 つの古典的な基底状態の 1 つになります。$|00\rangle, |01\rangle, |10\rangle, |11\rangle$、これは 1 回の測定で区別できます。 

この時点で、問題は 2 つの古典的なビットを読み取り、その整数エンコーディングを返すことに帰着します。

 ## アルゴリズムのチュートリアル

 量子ビットは次のようにインデックス付けされていると仮定します。`qs[0]`そして`qs[1]`。 

1. CNOT ゲートを適用します。`qs[0]`コントロールとして、そして`qs[1]`ターゲットとして。 このステップでは、パリティ情報を 2 番目の量子ビットに転送することにより、もつれ構造を除去します。 これが機能する理由は、4 つのベル状態すべてが相関パリティと位相のみ異なるためです。 
2. アダマール ゲートを適用します。`qs[0]`。 これにより、基底成分間の位相差が計算基底での測定可能なビット差に変換されます。 
3. 計算ベースで両方の量子ビットを測定し、2 つの古典的なビットを生成します`b0`そして`b1`。 
4. 結果を整数として解釈する`b0 * 2 + b1`それを元の状態の識別子として返します。 

### なぜ効果があるのか

 4 つのベル状態は正規直交基底を形成し、アダマールが後に続くシーケンス CNOT は、その基底を標準の計算基底に正確にマッピングします。 ユニタリ変換では直交性が維持されるため、各入力状態は一意の基底ベクトルにマッピングされ、測定は決定的になります。 マッピングは全単射であるため、2 つの異なるベル状態が同じ測定結果をもたらすことはありません。 

## Python ソリューション

 元のタスクは Q# で表現されていますが、Microsoft Quantum ライブラリで利用可能な標準の量子操作を使用して、必要な形式でソリューションを提示します。```python
import sys
input = sys.stdin.readline

# Q# style solution embedded as required

def Solve(qs):
    # Apply CNOT: control qs[0], target qs[1]
    CNOT(qs[0], qs[1])

    # Apply Hadamard to first qubit
    H(qs[0])

    # Measure both qubits
    b0 = M(qs[0])
    b1 = M(qs[1])

    # Convert bits to integer
    return int(b0) * 2 + int(b1)
```この実装では、唯一の微妙な点は、最終的な整数を形成するときのビットの順序です。 最初の量子ビットは最上位ビットに対応するため、2 が乗算されます。この規則を逆にすると、出力が並べ替えられ、状態のインデックスが正しく作成されなくなります。 

アダマールの前に CNOT を適用するという選択が重要です。 これらを逆にすると、ベルと計算のマッピングが壊れ、非決定的な結果が生じます。
