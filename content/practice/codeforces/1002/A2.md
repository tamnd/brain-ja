 ## 解決策
 ## 問題の理解

 最大 8 量子ビットのレジスタから開始します。レジスタはすべてオールゼロの計算基礎状態で初期化されます。 これに加えて、別の基底状態の古典的な記述がブール配列として与えられます。各エントリは、その基底構成で対応する量子ビットが状態 1 または 0 のどちらにあるべきかを示します。 この配列の最初のエントリは true であることが保証されており、ターゲットの基底状態の最初の量子ビットが常に 1 に等しいことを意味します。 

このタスクは、古典的な意味で何かを「計算」することではありません。 代わりに、最終的な量子状態が 2 つの基底状態 (オールゼロ状態と入力配列で記述される基底状態) の等しい重ね合わせになるように、一連の量子操作を適用する必要があります。 

形式的には、最終状態は (|00…0⟩ + |b⟩) / √2 でなければなりません。ここで、|b⟩ はブール配列によってエンコードされた計算基礎状態です。 

N は最大 8 であるため、量子ビットあたり一定量の量子ゲートを適用する方法であればどれでも十分です。 量子ビットの総数は小さいため、N の線形を超える漸近スケーリングについての懸念はありません。 実際の制約は概念的なものです。変換は、測定や振幅を直接「書き込む」ことなく、有効な量子操作を使用して実行する必要があります。 

2 つの基底状態が潜在的に多くの量子ビットで異なるという要件から、微妙なエッジ ケースが発生します。 単純な考えとしては、「|b⟩ を準備してから、何らかの方法で |0…0⟩ を追加する」ということがあるかもしれませんが、量子力学では状態を直接追加することはできません。 もう 1 つの魅力的だが間違ったアプローチは、アダマール ゲートをすべての量子ビットに適用し、振幅を選択的にキャンセルしようとすることです。これにより、必要な 2 状態の重ね合わせではなく、すべての状態にわたって均一な重ね合わせが生成されます。 

主な困難は、|0…0⟩ から開始し、他の計算基底状態をまったく導入せずに、ちょうど 1 つの追加の計算基底状態を重ね合わせに導入する可逆的な構築が必要であることです。 

## アプローチ

 ブルートフォースの考え方では、振幅について推論し、ゲートに分解を適用することで、ターゲット状態ベクトルを明示的に構築しようとします。 これは理論的には可能ですが、すぐに不必要な複雑さになってしまいます。任意の 2 状態の重ね合わせを構造のない基本ゲートに分解するには、すべての 2^N 基底状態にわたる干渉パターンの処理が必要になりますが、これは N ≤ 8 で必要となるものをはるかに超えています。 

ターゲット状態の構造は非常に特殊です。 これには正確に 2 つの基底状態が含まれており、そのうちの 1 つが初期状態です。 これは、量子回路に必要な「分岐点」は 1 つだけであることを示唆しています。つまり、振幅を 2 ​​つの計算パスに分割する 1 つの操作と、それらのパスの 1 つを |b⟩ に変換する決定論的な方法です。 

重要な観察は、単一の量子ビットを制御レジスタとして使用して、|0…0⟩ に留まるか |b⟩ に変換できるかを決定できることです。 アダマール ゲートを使用して最初の量子ビットを重ね合わせに配置すると、2 つのブランチ間のスイッチとして機能できます。 次に、その量子ビットからの制御された操作により、条件付きで他の量子ビットを反転できるため、1 つのブランチのみが目的の基底状態に進化します。 

これにより、制御された NOT 演算のみを使用して |0…0⟩ から |b⟩ を構築する問題が軽減されますが、重ね合わせの「1」分岐でのみアクティブになります。

 ## アルゴリズムのチュートリアル

 量子ビット レジスタとターゲットの基底状態を記述するブール配列を直接操作します。

1. 最初の量子ビットにアダマール ゲートを適用します。 これにより、2 つの計算ブランチの重ね合わせが作成されます。1 つは最初の量子ビットが 0 で、もう 1 つは最初の量子ビットが 1 です。この時点で、両方のブランチの他のすべての量子ビットは 0 のままです。 
2. 最初の量子ビットを、すべてゼロの状態に留まるか、目標の基底状態に向かうかを決定する制御ビットとして解釈します。 最初の量子ビットが 0 であるブランチは変更されないままでなければならないため、それ以上の操作はそれに影響を及ぼしません。 
3. bits[i] が true である 0 より大きいインデックス i ごとに、制御量子ビット 0 とターゲット量子ビット i を使用して CNOT ゲートを適用します。 これにより、制御量子ビットが 1 であるブランチ内でのみ、対応するターゲット量子ビットが 0 から 1 に反転されることが保証されます。 
4. 最初の量子ビットはすでに制御であり、ターゲットの基底状態で必要な値をすでに表しているため、ビット[0]には何もしません。 

これらのステップの後、状態は次のように発展します。最初の分岐は |00…0⟩ のままですが、必要なすべての量子ビット 反転が条件付きで適用されたため、2 番目の分岐は正確に |b⟩ になります。 

### なぜ効果があるのか

 この構造では、計算全体を通じて厳密な 2 分岐構造が維持されます。 アダマール ゲート後の状態は、最初の量子ビットのみが異なる 2 つの基底構成の正確な線形結合になります。 後続のすべての CNOT は最初の量子ビットによって制御されるため、 |0⟩ ブランチのすべての振幅に対して同様に動作し、 |1⟩ ブランチのみを変更します。 

各 CNOT は、必要に応じてターゲット基底状態の 1 ビットを 1 に設定することに正確に対応するため、2 番目の分岐は最初の分岐に影響を与えることなく、決定論的に |b⟩ に変換されます。 各演算は制御量子ビットに基づいて条件付けされた計算基底ベクトルの並べ替えであるため、追加の基底状態は導入されません。

```この実装は、量子状態をシミュレートしているのではなく、ゲート操作を発行しているという事実を反映しています。 最初の量子ビットのアダマールは、重ね合わせを作成する唯一の操作です。 後続のすべてのステップは、同じ量子ビットによって駆動される条件付きビット フリップです。 

唯一の微妙な点は、CNOT ループでインデックス 0 をスキップしていることです。 bits[0] は true であることが保証されているため、最初の量子ビットを制御として選択することですでに考慮されています。 量子ビットからそれ自体に CNOT を適用することは無意味であるため、避けられます。

 ## 特殊なケース

 N = 1 およびビット = [true] の最小の場合、システムは |0⟩ で開始します。 アダマールを唯一の量子ビットに適用すると、(|0⟩ + |1⟩)/√2 が生成されます。 適用する CNOT 操作がないため、状態はすぐに正しいままになります。 

最初のビットを除くすべてのビットが false (ビット = [true, false, false] など) の場合でも、アダマールは (|00…0⟩ + |10…0⟩)/√2 を作成し、追加のゲートは適用されません。 2 番目のブランチはすでにターゲットの基底状態と正確に一致しています。 

最大サイズのケース N = 8 では、bits[i] が true であるすべての量子ビットは、制御されたフリップを 1 つだけ受け取ります。 すべての操作は量子ビット 0 によって制御されるため、最初のブランチは決して妨害されず、2 番目のブランチは中間の不要な状態を作成することなく完全なビット文字列を決定論的に蓄積します。
