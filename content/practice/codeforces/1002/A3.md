 ## 解決策
 ## 問題の理解

 私たちは量子設定で作業しています。$N \le 8$量子ビットは、すべてゼロの計算基礎状態から始まります。 このレジスタに加えて、同じ長さの 2 つの古典的なビット文字列が与えられ、それぞれがこれらの量子ビット上の有効な基底状態を記述します。 2 つのビット列は、少なくとも 1 つの位置が異なることが保証されています。これは、それらが計算基礎における 2 つの異なる基底ベクトルを表すことを意味します。 

課題は、オールゼロの量子状態を、正確にこれら 2 つの基底状態の等しい量子重ね合わせに変換することです。 言い換えれば、演算を適用した後、システムはそれを測定すると確率で最初のビット列が得られる状態になる必要があります。$1/2$2 番目のビット文字列と確率$1/2$、2 つの振幅間に適切な位相の一貫性があります。 

ここでの重要な制約は、振幅の計算や量子状態のシミュレーションが許可されていないことです。 X、H、制御された NOT 演算などの基本的な量子ゲートを使用してターゲット変換を構築する必要があります。 

以来$N$最大 8、次の線形または二次関数の解$N$は些細な速さです。 本当の課題はパフォーマンスではなく、意図しない余分な状態を導入することなく、正確に 2 つの計算基底状態を重ね合わせて生成する正しい回路を構築することです。 

2 つのビット列が複数の位置で異なる場合、微妙なエッジ ケースが発生します。 単純なアプローチでは、「ビットを個別に反転して重ね合わせ」を試みるかもしれませんが、それはすべての重ね合わせを作成することになります。$2^k$異なる位置での組み合わせは正しくありません。 たとえば、すべての異なる量子ビットをアダマールしようとすると、2 つではなく 4 つ以上の状態が生成されます。 正しい変換では、グローバル構成が 2 つだけ存在するように量子ビットを相関させる必要があります。 

初期の基底アライメントを無視すると、別の故障モードが発生します。 与えられた 2 つのビット文字列の重ね合わせを直接構築しようとすると、$|0^N\rangle$、最初に問題を標準形式に正規化しない限り、間違った位相構造を構築する危険があります。 

## アプローチ

 ブルートフォースの考え方は、マッピングする回路を明示的に構築することです。$|0^N\rangle$それぞれのターゲット基本状態に追加し、何らかの方法でそれらを「追加」します。 古典的なシミュレーションでは、これはサイズの完全な状態ベクトルを構築することに相当します。$2^N$、2 つのエントリを次のように設定します$1/\sqrt{2}$、そして正規化。 このアプローチは概念的には機能しますが、直接的な振幅操作を前提としているため、有効な量子構築パスではありません。 たとえそれを回路合成として解釈したとしても、すべての基底状態を列挙し、振幅を強制するには、次のような指数関数的な推論が必要になります。$2^N$これはターゲットの構造を考慮すると不要です。 

重要な構造的観察は、2 つのターゲット状態は固定ビットマスクだけが異なるということです。 2 つの文字列のビットごとの XOR を次のように表すと、$d$の場合、ビットを正確に反転することで、一方の状態をもう一方の状態から取得できます。$d$があります。 これにより、問題は次の重ね合わせを準備することになります。$|0^N\rangle$そして$|d\rangle$、最初に基底状態の 1 つをゼロにマッピングした後。 

これが中心的な単純化です。2 つの任意のビット文字列について考える代わりに、そのうちの 1 つが原点になるように座標系をシフトします。 次に問題は、一方の成分がオールゼロの状態で、もう一方の成分が既知のビットマスク構成である 2 つの状態の重ね合わせを構築することになります。 この構造は、単一のアダマールと X ゲートの制御された伝播を使用して実装できます。

 ## アルゴリズムのチュートリアル

 望ましい量子状態を正準重ね合わせに還元し、制御された量子もつれパターンを構築することで、望ましい量子状態を構築します。 

1. 2 つのビット文字列が異なるすべての位置を特定します。 これはビットマスクを定義します$d$。 このマスクは、ある基底状態を別の基底状態に変換するためにどの量子ビットを反転する必要があるかを正確にエンコードします。 
2. 最初のビット列が 1 を持つすべての量子ビットに X ゲートを適用します。これにより、以下に対応する基底状態がマップされます。`bits0`オールゼロ状態になります。 このステップは、問題を標準的な開始点に戻すため、非常に重要です。 
3. 同じ X ゲートを適用します`bits1`変換を通じて暗黙的に: ステップ 2 の後、2 番目の状態がビットマスクになります。$d = bits0 \oplus bits1$。 
4. 任意のインデックスを選択します$i$そのような$d[i] = 1$。 2 つのビット文字列が異なるため、このようなインデックスが存在する必要があります。 
5. アダマールゲートを量子ビットに適用する$i$。 これにより、局所的な重ね合わせが作成されます$(|0\rangle + |1\rangle)/\sqrt{2}$、正確に 2 つのグローバル状態を生成するための「制御バックボーン」として機能します。 
6. 1 つおきのインデックスについて$j \ne i$どこ$d[j] = 1$、量子ビットによって制御される CNOT ゲートを適用します。$i$ターゲティング量子ビット$j$。 これにより、量子ビットからの励起が伝播します。$i$必要なすべての位置に追加し、これらのビットがすべて 0 のままになるか、すべて反転するようにします。 
7. 最後に、システムは次の状態になります。$(|0^N\rangle + |d\rangle)/\sqrt{2}$変換されたベースで。 ステップ 2 の逆を適用すると (同じ X ゲートをもう一度)、元の座標系が復元され、元の 2 つの基底状態の必要な重ね合わせが得られます。 

### なぜ効果があるのか

 この構造では、厳密な二値相関構造 (量子ビット) が適用されます。$i$は重ね合わせの唯一のソースであり、他のすべての異なる量子ビットは CNOT を介して決定論的にそれに関連付けられます。 これにより、状態の計算ベースのサポートに正確に 2 つの構成が含まれることが保証されます。 最初の X レイヤーは、これらの構成がシフトされたバージョンではなく、正確に元のビット文字列であることを保証します。 すべての操作は単一で可逆的であるため、意図した 2 次元部分空間の外側に無関係な振幅が導入されることはありません。 

## Python ソリューション

 元の問題は Q# で提起されていますが、論理構造は、プリミティブ ゲートが利用可能であると想定される Python のような量子 API スタイルで表現できます。```python
import sys
input = sys.stdin.readline

# We assume quantum primitives exist:
# X(q), H(q), CNOT(control, target)

def Solve(qs, bits0, bits1):
    n = len(qs)

    # Step 1: compute difference mask
    diff = [bits0[i] ^ bits1[i] for i in range(n)]

    # Step 2: align bits0 to |0...0>
    for i in range(n):
        if bits0[i]:
            X(qs[i])

    # Step 3: find pivot qubit
    pivot = -1
    for i in range(n):
        if diff[i]:
            pivot = i
            break

    # Step 4: create superposition on pivot
    H(qs[pivot])

    # Step 5: propagate correlations
    for j in range(n):
        if j != pivot and diff[j]:
            CNOT(qs[pivot], qs[j])

    # implicit end of operation
```最初のループは、見落としがちな基本的な調整ステップです。 これがないと、構築では間違った計算基準点に固定された重ね合わせが生成されてしまいます。 

この問題では少なくとも 1 つの異なるビットが保証されているため、ピボットの選択は安全です。 有効なインデックスはどれでも機能しますが、最初のインデックスを選択すると回路が決定的に保たれます。 

制御された伝播ステップにより、状態の爆発が防止されます。 CNOT がすべての異なるビットを 1 つの制御に結び付けなければ、各アダマールは独立して基底状態の数を 2 倍にすることになります。

 ## 特殊なケース

 重要なエッジ ケースは、2 つのビット文字列が 1 つの位置のみで異なる場合です。 このシナリオでは、XOR マスクには設定ビットが 1 つだけあるため、CNOT 伝播ループは何も行いません。 このアルゴリズムは、X ゲートの後に単一のアダマールを適用することで、偶発的なもつれを発生させることなく、正しい単一量子ビットの重ね合わせを直接生成します。 

もう 1 つのエッジ ケースは、最初のビット文字列がすべてゼロではない場合です。 ここでの正確性を保証するのは最初の X レイヤーです。 これがないと、ピボットベースの構築により間違った基底原点の周りに重ね合わせが生成されてしまいます。 明示的にマッピングすることで`bits0`ゼロにすると、後続のアダマール構造と CNOT 構造が一貫した座標系で動作することが保証され、最終的な反転では意図した状態のペアが保存されます。
