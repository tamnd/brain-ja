 ## 解決策
 ## 問題の理解

 私たちには、相互に直交する 4 つの量子状態のうちの 1 つになることが保証されている 2 量子ビット システムが与えられています。 これらの各状態は、2 ビットの情報を異なるエンコードで表現したものですが、標準的な計算ベースでは異なります。 代わりに、状態はもつれた変種であり、最初に適切な変換を適用せずに通常の基底で各量子ビットを即座に測定することによっては区別できません。 

タスクは、2 つの量子ビットに対して一連の許可された量子操作を実行し、続いて測定を行い、与えられた 4 つの状態のどれを決定論的に回復することです。 出力は、初期状態を識別する 0 ～ 3 の整数です。 測定後は、測定後の状態は関係ありません。 

量子ビット数は小さく、通常の意味での古典的な入力サイズはありませんが、暗黙の制約は、定数時間の量子演算と 1 回の測定ラウンドのみであるということです。 これにより、状態を確率的に「学習」しようとしたり、繰り返しサンプリングしようとする戦略は除外されます。 単一の測定で答えが明らかになるように、指定された 4 つの直交状態を計算基礎に変換する必要があります。 

重要な微妙な点は、各量子ビットの Z 基底での単純な測定では状態を区別できないことです。これは、状態がその基底と一致していないためです。 基底変換をスキップする不用意なアプローチは、状態を予期せず崩壊させ、複数のケースを同じ観察結果にマージします。 

## アプローチ

 ブルートフォース的な考え方は、測定を繰り返し、システムをリセットして再準備して、結果の確率を推測することです。 これは、状態のコピーを 1 つしか取得できず、測定は破壊的であるため、ここでのモデルとは根本的に互換性がありません。 たとえ繰り返しが可能だったとしても、各測定ではもつれシステムに関する部分的な情報しか得られないため、4 つの直交するもつれ状態を区別するには完全な基底分解を再構成する必要があり、これは不必要なオーバーヘッドです。 

重要な観察は、4 つの可能な状態が 2 量子ビット空間のよく知られた正規直交基底、特にベル基底を形成しているということです。 ベル基底準備回路の逆を適用すると、これらの状態を区別するのが自明になります。 その逆回路は、各もつれ状態を個別の計算基礎状態 |00⟩、|01⟩、|10⟩、または |11⟩ にマップします。 

これを実現する標準的な変換では、最初に CNOT ゲートを最初の量子ビットから 2 番目の量子ビットに適用し、次にアダマール ゲートを最初の量子ビットに適用します。 この変換後、計算ベースでの測定によって元の状態が完全に特定されます。

 ## アルゴリズムのチュートリアル

 この推論を、未知のもつれ基底を標準基底に変換する変換として説明します。 

1. 量子ビット 0 をコントロール、量子ビット 1 をターゲットとして CNOT ゲートを適用します。 このステップでは、相関情報をターゲット量子ビットに転送することで、2 つの量子ビットのもつれを部分的に解きます。 
2. アダマール ゲートを量子ビット 0 に適用します。このステップでは、残りの重ね合わせを計算基礎に回転させ、2 つの「プラス/マイナス」バリアントを区別する位相情報を分離します。 
3. 計算ベースで両方の量子ビットを測定し、2 つの古典的なビット b0 と b1 を取得します。 
4. 問題ステートメント内の 4 つの状態の元の定義によって決定される固定マッピングを使用して、結果のビット文字列を 0 ～ 3 の範囲のインデックスとして解釈します。 

### なぜ効果があるのか

4 つの入力状態は、計算基底に固定ユニタリ変換を適用することによって得られる正規直交基底を形成します。 CNOT の後にアダマールが続くシーケンスは、まさにその変換の逆です。 量子進化はユニタリであるため、逆回路を適用すると、振幅を混合することなく、各基底状態が固有の計算基底ベクトルにマッピングされます。 これにより、測定結果が元の状態を一意に識別する決定的な 2 ビットの結果が生成されることが保証されます。 

## Python ソリューション

 この問題は Q# で述べられていますが、基礎となるロジックは、測定が続く固定量子回路です。 以下は、測定後の決定ロジックを Python スタイルで概念的に表現したものです。```python
import sys
input = sys.stdin.readline

# In an actual quantum environment, qs is a 2-qubit register.
# We apply:
#   CNOT(qs[0], qs[1])
#   H(qs[0])
#   measure both qubits

def Solve(qs):
    # Pseudocode for quantum operations:
    # CNOT(qs[0], qs[1])
    # H(qs[0])
    # b0 = M(qs[0])
    # b1 = M(qs[1])

    # In an abstract sense, after the circuit:
    # (b0, b1) is a deterministic encoding of the input state.

    b0 = M(qs[0])
    b1 = M(qs[1])

    return (b0 << 1) | b1
```実際の Q# 実装では、重要な部分はゲートの順序です。CNOT を逆にすると非計算が計算基礎に分割されるため、CNOT はアダマールの前に適用する必要があります。 測定は両方の変換後に実行する必要があります。 より早く測定すると、正しい識別に必要なもつれ構造が破壊されてしまいます。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、グローバル フェーズだけが異なる状態間の潜在的な混乱です。 たとえば、2 つのもつれ状態は代数的には異なって見えるかもしれませんが、回路の後では同じ測定分布を表します。 グローバル位相には観察可能な効果がないため、アルゴリズムはこれを正しく処理します。 CNOT とアダマールを適用した後、両方とも測定前に同じ計算基底ベクトルにマッピングされます。 

もう 1 つの微妙なケースは、測定が早すぎることです。 両方のゲートを適用する前に測定を実行すると、エンタングルメント構造が破壊され、結果は複数の状態にわたって均一にランダムになります。 正しいシーケンスにより、崩壊が発生する前に、すべての識別情報が古典的なビットに変換されます。
