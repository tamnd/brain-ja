 ## 解決策
 ## 問題の理解

 私たちは、総当たりのサッカー トーナメントの結果を、どのチームも最終的に同じポイント数になるように設計するように求められています。 がある$n$各チームは 1 回ずつプレーします。 各試合は引き分け (両チームが 1 ポイントを獲得) または決定的な結果 (一方のチームが 3 ポイントを獲得、もう一方のチームが 0 ポイントを獲得) で終了する可能性があります。 私たちの目標は、すべてのチームの合計スコアが同一になるように結果をすべての試合に割り当て、そのようなすべての構成の中で同点の数が最小限になるようにすることです。 出力形式は、試合ペアの順序で結果を平坦化したリストです。最初はチーム 1 対他のすべてのチーム、次にチーム 2 対その後のすべてのチームというように続きます。 

制約は中程度です。$2 \le n \le 100$最大 100 のテスト ケース。 一致の合計数は次のとおりであるため、すべてのペアごとの結果を直接計算することは可能です。$n(n-1)/2$、これは最大 4950 です。$n = 100$。 したがって、$O(n^2)$アルゴリズムは許容されます。 

微妙な点は、偶数の場合です。$n$、奇数の場合は完全に同点を避けることは可能ですが、$n$、少なくとも何らかのつながりが必要です。 単純なアプローチでは勝利を恣意的に割り当てようとする可能性があり、その結果、スコアが不均等になる可能性が高くなります。 たとえば、$n = 3$、すべての試合に任意の勝者がいる場合、あるチームが 2 回勝ち、別のチームが 2 回負ける可能性があり、合計が不等になります。 勝ちと負けを対称的にバランスさせるには、慎重な設計が必要です。 

## アプローチ

 ブルートフォースアプローチでは、すべてのデータを生成しようとします。$3^{n(n-1)/2}$試合結果の可能な組み合わせを確認し、スコアが等しいかどうかを確認します。 これは明らかに不可能です$n = 100$一致構成の数が指数関数的に増加するためです。 勝ちと引き分けのすべての順列を直接シミュレートしても遅すぎます。 

重要な観察は、勝ちと負けの循環として結果をモデル化できるということです。 もし$n$これは奇妙ですが、各チームは他のチームと「勝ち、引き分け、負け」のサイクルで配置できます。チーム間の試合については、$i$そしてチーム$j$、オフセットを計算できます$(j - i)$モジュロ$n$この差が以下であるか、等しいか、または大きいかに基づいて結果を割り当てます。$n/2$。 もし$n$が偶数の場合、同じローテーションのアイデアが機能しますが、各チームの試合の半分には勝利を割り当て、残りの半分には負けを割り当て、完全に引き分けを避けます。 同点は、差が奇数のちょうど真ん中にある場合にのみ発生します。$n$。 

この観察により、問題は単純なものに集約されます。$O(n^2)$すべての試合をループし、チームの相対インデックスに基づいて決定的に 1、-1、または 0 を割り当てます。 これは、すべてのチームの合計ポイントが均等になるようにする明確なパターンを備えた建設的なソリューションです。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 各テスト ケースについて、チームの数を読み取ります。$n$。 
2. 空のリストを初期化して、すべての一致の結果を保持します。 
3. チームのすべてのペアをループします$(i, j)$と$i < j$試合結果を記入します。 
4. 距離を計算する$d = j - i$。 
5. もし$n$奇数である場合は、次のように割り当てます。 

- 1 の場合$d \le n//2$、チームを意味します$i$勝ちます。 
- -1 の場合$d > n//2$、チームを意味します$j$勝ちます。 
6. もし$n$が偶数の場合、次のように割り当てます。 

- 1 の場合$d \le n//2 - 1$、チームを意味します$i$勝ちます。 
- -1 の場合$d \ge n//2 + 1$、チームを意味します$j$勝ちます。 
- 0の場合$d = n//2$, つまり、バランスをとるためにネクタイが必要です。 
7. 計算結果を結果リストに追加します。 
8. すべてのペアを処理した後、必要なフラット化された順序で結果を出力します。 

機能する理由: 循環割り当てにより、各チームが確実に勝つことが保証されます。$\lfloor (n-1)/2 \rfloor$一致する、正確に負ける$\lfloor (n-1)/2 \rfloor$一致する場合$n$が奇数であり、次の場合は 1 つの一致に一致します。$n$奇数です。 偶数の場合$n$、各チームの勝ち負け$n/2 - 1$一致するものは 1 つだけ一致し、合計ポイントが同じになります。 同点をさらに減らそうとすると対称性が崩れるため、このパターンでは最小の同点で等しいスコアが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    res = []
    for i in range(1, n+1):
        for j in range(i+1, n+1):
            d = j - i
            if n % 2 == 1:
                if d <= n // 2:
                    res.append(1)
                else:
                    res.append(-1)
            else:
                if d < n // 2:
                    res.append(1)
                elif d == n // 2:
                    res.append(0)
                else:
                    res.append(-1)
    print(' '.join(map(str, res)))
```解決策は最初に読みます$t$テスト ケースを作成し、チームの各ペアで繰り返します。 距離$d$チーム インデックス間の結果は、モジュラー ロジックを使用して決定されます。 偶数の場合$n$、中間の試合はスコアのバランスを保つために同点である必要があり、奇数の場合は$n$、すべての試合が決定的なものになる可能性があります。 出力は必要な順序で平坦化されます。
