 ## 解決策
 ## 問題の理解

 _n_ 個の整数のリストが与えられ、連続する数値間の差の合計が最大になるように整数を 1 列に配置する必要があります。 具体的に言うと、$x_1, x_2, \dots, x_n$、値は次のように計算されます。$(x_1 - x_2) + (x_2 - x_3) + \dots + (x_{n-1} - x_n)$。 式を観察すると、中間項がキャンセルされ、合計値は次のようになります。$x_1 - x_n$。 これは、最大値を最初に最大の数値を、最後に最小の数値を配置することによって取得されることを意味します。 ただし、課題は、この最大値を生成するすべての配列の中で辞書編集上最小のシーケンスも必要とすることです。 

制約は中程度です。$n$は 100 まで、整数の範囲は -1000 から 1000 までです。これにより、最大 100 までの解が可能になります。$O(n^2)$快適だが素朴な順列。$O(n!)$、非現実的です。 エッジ ケースには、複数の要素が同じ最大値または最小値を持つシーケンス、要素が 2 つだけあるシーケンス、およびすべての数値が等しいシーケンスが含まれます。 単純なアプローチでは、辞書編集上の最小性が保証されずに任意の順序が選択され、正しい最大値が生成されますが、間違った出力シーケンスが生成される可能性があります。 

## アプローチ

 ブルートフォース手法では、入力配列のすべての順列を生成し、各順列の値を計算して、最も高い値を持つものを選択し、辞書編集的な比較によって関係を破ります。 のために$n = 100$、このアプローチは不可能です。$100!$順列は天文学的に大きい。 

重要な洞察は、差の和における相殺を観察することで得られます。 合計は次のように単純化されます$x_1 - x_n$。 これを最大化するには、最大の数値を最初に配置し、最小の数値を最後に配置する必要があります。 最初と最後の位置が固定されると、残りの数値は合計に影響しません。 辞書編集上で最小のシーケンスを取得するには、中央の数値を昇順に並べる必要があります。 これにより、指定された最初と最後の数値の最小シーケンスが保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を昇順に並べ替えます。 これにより、最小値と最大値を簡単に識別できるようになり、辞書編集上最小限のシーケンスの構築が簡素化されます。 
2. 最大の数字を最初の位置に置きます。 これにより最大化されます$x_1$簡略化した合計では$x_1 - x_n$。 
3. 最小の数字を最後の位置に置きます。 これにより最小限に抑えられます$x_n$合計で。 
4. 残りの数字 (最大と最小を除くすべての数字) を最初の位置と最後の位置の間に昇順に配置します。 これにより、最大値を維持しながら、順序が辞書編集的に最小になることが保証されます。 
5. 結果のシーケンスを印刷します。 

機能する理由: 最大値と最小値を末尾で固定することで、最大の差が保証されます。 中央の数字を昇順に並べると、辞書編集的に可能な限り最小の順序が保証されます。 中間の数値を他の順序で並べても合計は変わりませんが、辞書編集上の順序は大きくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

a.sort()
largest = a[-1]
smallest = a[0]
middle = a[1:-1]

result = [largest] + middle + [smallest]
print(' '.join(map(str, result)))
```コードはまず入力配列を並べ替えます。`largest`最後の要素を取り、`smallest`最初のものを取り、`middle`間にあるすべての要素が含まれます。 それらを次のように連結します`[largest] + middle + [smallest]`目的の出力が生成されます。 中央をソートすることで、辞書編集上の最小性が保証されます。 このアプローチでは、順序を壊すような方法で元の配列を変更することを慎重に避けます。 

## 実用的な例

 **サンプル 1**

 入力:`5\n100 -100 50 0 -50\n`| ステップ | 配列 | アクション | 結果 |
 | --- | --- | --- | --- |
 | 1 | [-100、-50、0、50、100] | 並べ替え済み | [-100、-50、0、50、100] |
 | 2 | 100 | 最大のものを選択 | 最大 = 100 |
 | 3 | -100 | 最小のものを選択します | 最小 = -100 |
 | 4 | [-50、0、50] | 中央 | 中央 = [-50, 0, 50] |
 | 5 | 連結 | [100] + [-50, 0, 50] + [-100] | [100、-50、0、50、-100] |

 このシーケンスは合計を生成します`(100 - (-50)) + (-50 - 0) + (0 - 50) + (50 - (-100)) = 200`。 

**サンプル 2**

 入力:`4\n1 2 3 4\n`| ステップ | 配列 | アクション | 結果 |
 | --- | --- | --- | --- |
 | 1 | [1、2、3、4] | 並べ替え済み | [1、2、3、4] |
 | 2 | 4 | 最大のものを選択 | 最大 = 4 |
 | 3 | 1 | 最小のものを選択します | 最小 = 1 |
 | 4 | [2、3] | 中央 | 中央 = [2, 3] |
 | 5 | 連結 | [4] + [2, 3] + [1] | [4、2、3、1] |

 和：`(4 - 2) + (2 - 3) + (3 - 1) = 3 + (-1) + 2 = 4`、これは最大です。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n log n) | ソートが実行時間の大半を占め、他のすべての操作は O(n) |

 と$n \le 100$、$O(n \log n)$は無視できるものであり、2 秒の制限時間内に十分収まります。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()
    largest = a[-1]
    smallest = a[0]
    middle = a[1:-1]
    result = [largest] + middle + [smallest]
    return ' '.join(map(str, result))

# Provided samples
assert run("5\n100 -100 50 0 -50\n") == "100 -50 0 50 -100", "sample 1"
assert run("4\n1 2 3 4\n") == "4 2 3 1", "sample 2"

# Custom cases
assert run("2\n10 -10\n") == "10 -10", "two elements"
assert run("3\n5 5 5\n") == "5 5 5", "all equal"
assert run("5\n-1 -2 -3 -4 -5\n") == "-1 -4 -3 -2 -5", "negative numbers"
assert run("6\n0 100 -100 50 -50 25\n") == "100 -50 0 25 50 -100", "mixed numbers"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 2\n10 -10 | 10 -10 | 最小サイズ入力 |
 | 3\n5 5 5 | 5 5 5 | すべての要素が等しい |
 | 5\n-1 -2 -3 -4 -5 | -1 -4 -3 -2 -5 | 負の数の処理 |
 | 6\n0 100 -100 50 -50 25 | 100 -50 0 25 50 -100 | 帯分数、辞書順 |

 ## 特殊なケース

 のために`n = 2`、配列`[10, -10]`直接的に得られる`[10, -10]`合計付き`20`。 中間要素がないため、辞書編集上の選択は簡単です。 たとえば、すべての数値が等しい場合`[5, 5, 5]`、最大合計はゼロであり、任意の順列が有効です。 並べ替えてアルゴリズムに従っても結果は得られます`[5, 5, 5]`、これは辞書編集的に最小限です。 負の数値または混合符号を含むシーケンスの場合も、同じロジックが適用され、並べ替えにより、最大差分合計を維持しながら、中央の数値が辞書編集上の最小性を維持することが保証されます。
