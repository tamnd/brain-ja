 ## 解決策
 ## 問題の理解

 私たちは、SmallR が与えられたコストで各犬の性別を変えることができる犬の実験から得られる純利益を最大化するよう求められています。 条件付きの賭けをする裕福な観察者がいます。それぞれが犬のサブセットとターゲットの性別を指定し、そのサブセット内のすべての犬がその性別と一致した場合に報酬を約束します。 これらの観察者の中には彼女の友人もおり、その場合、条件を満たさないと固定ペナルティが課せられます。 

入力により、各犬の初期の性別、変更のコスト、各オブザーバーの説明 (ターゲットの性別、報酬、犬のリスト、友情ステータス) が得られます。 出力は最大の純利益であり、友人を喜ばせるコストが他の観察者からの報酬を上回る場合、マイナスになる可能性があります。 

制約は、最大 10,000 匹の犬と最大 2,000 人の観察者がいることを示しています。 各観察者が興味を持つ犬は最大 10 匹です。 これは、犬のすべてのサブセットを反復処理することは不可能ですが、すべてのオブザーバーを反復処理することは許容できることを示唆しています。 コストと報酬は整数として保存できるほど小さいです。 エッジケースには、一部の観察者が犬と重複していなかったり、すべての犬が最初は一部の友人にとって間違った性別であり、損失を余儀なくされる状況が含まれます。 

不注意な実装では、オーバーラップするオブザーバー条件を考慮せずに、貪欲に犬を反転させようとする可能性があります。 たとえば、2 人の観察者が同じ犬に対して反対の性別を要求した場合、単純な戦略では報酬や罰則が二重にカウントされる可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての犬のサブセットの変更を試み、その結果の性別構成を計算し、すべての報酬からペナルティを差し引いたものを合計します。 構成の合計数は次のとおりです。$2^n$、これは不可能です$n=10^4$。 各構成のすべてのオブザーバーを反復しても役に立ちません。 アプローチは指数関数的に遅くなります。 

重要な観察は、各観察者が最大 10 匹の犬にローカル制約を課すということです。 これをネットワーク フロー問題としてモデル化できます。フロー グラフを構築し、変更するかどうかを犬ごとに選択します。エッジは変更のコストと観察者からの利益または損失を反映します。 各オブザーバーはその犬に接続されたノードとして表すことができ、その能力は、友人以外を満足させることに対する報酬、または友人を満足させることに対するペナルティのいずれかをエンコードします。 次に、このグラフの最小カットは、純利得を最大化する最適なドッグ変更セットに対応します。 これにより、問題は指数関数的な構成から多項式のフロー ネットワークの問題に軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * m) | O(n + m) | 遅すぎる |
 | ネットワークフロー / 最小カット | O((n + m) * (k_i の合計)) | O(n + m + k_i の合計) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ソース ノードとシンク ノードを使用してフロー ネットワークを初期化します。 各犬はノードとして表され、各観察者はノードとして表されます。 ネットワークは、コストと利益をエッジ容量としてエンコードします。 
2. 犬ごとに、犬が最初は雄であり、雌への反転をカウントしたい場合は、変更コストに等しい容量を持つソースから犬ノードまでのエッジを作成します。 同様に、ドッグ ノードからシンクまでのエッジを、最初に女性の場合に変更するコストに等しい容量で作成します。 これは、犬をひっくり返すためにお金を払うという決定をモデル化しています。 
3. 各オブザーバーについて、それらを満足させることによる最終的な利益を決定します。 オブザーバーがフレンドでない場合は、オブザーバー ノードからシンクまでのエッジを報酬と同じ容量で作成します。 友人の場合は、失敗した場合のコストを表す、ペナルティに等しい容量を持つソースからオブザーバー ノードまでのエッジを作成します。 
4. 各オブザーバー ノードを、関係するすべてのドッグ ノードに接続します。 オブザーバーを満足させるには、指定されたすべての犬がターゲットの性別と一致する必要があるため、これらのエッジには無限の容量がありますが、コストの対象となる犬は自由に変更できます。 ネットワークは、最小カットがゲインを最大化するために一貫したドッグ フリップのサブセットを選択することを保証します。 
5. ソースからシンクまでの最大流量を計算します。 グラフ内の最小カットは、犬の変化の最適なセットに対応します。 最大純利益は、フレンド以外のすべての報酬と最初のフレンドのペナルティの合計から最小カット値を引いたものです。 
6. 最終的な純利益を出力します。ペナルティが報酬を超える場合、マイナスになる可能性があります。 

なぜ機能するのか: ネットワーク フローは、犬をひっくり返すために支払うことと、報酬を受け取るかペナルティを支払うこととの間のトレードオフを正確にエンコードします。 最小カットは、最小の総容量でソースとシンクを分離します。これは、正味利得を最大化するのと同じです。 無限のエッジは、観察者の必要な犬からの制約を強制します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

class MaxFlow:
    def __init__(self, n):
        self.n = n
        self.graph = [[] for _ in range(n)]
        self.cap = {}
        
    def add_edge(self, u, v, c):
        self.graph[u].append(v)
        self.graph[v].append(u)
        self.cap[(u, v)] = c
        self.cap[(v, u)] = 0
    
    def bfs(self, s, t, parent):
        visited = [False]*self.n
        q = deque([s])
        visited[s] = True
        while q:
            u = q.popleft()
            for v in self.graph[u]:
                if not visited[v] and self.cap[(u,v)] > 0:
                    visited[v] = True
                    parent[v] = u
                    if v == t:
                        return True
                    q.append(v)
        return False
    
    def max_flow(self, s, t):
        parent = [-1]*self.n
        flow = 0
        while self.bfs(s, t, parent):
            path_flow = float('inf')
            v = t
            while v != s:
                u = parent[v]
                path_flow = min(path_flow, self.cap[(u,v)])
                v = u
            v = t
            while v != s:
                u = parent[v]
                self.cap[(u,v)] -= path_flow
                self.cap[(v,u)] += path_flow
                v = u
            flow += path_flow
        return flow

def main():
    n, m, g = map(int, input().split())
    sex = list(map(int, input().split()))
    cost = list(map(int, input().split()))
    
    S = n + m
    T = S + 1
    mf = MaxFlow(n + m + 2)
    total_reward = 0
    
    for i in range(n):
        if sex[i] == 0:
            mf.add_edge(i, T, cost[i])
        else:
            mf.add_edge(S, i, cost[i])
    
    for idx in range(m):
        line = list(map(int, input().split()))
        t, w, k = line[:3]
        dogs = [x-1 for x in line[3:3+k]]
        friend = line[3+k]
        obs_node = n + idx
        if friend:
            mf.add_edge(S, obs_node, g)
        else:
            mf.add_edge(obs_node, T, w)
            total_reward += w
        for d in dogs:
            if t == 0:
                mf.add_edge(d, obs_node, float('inf'))
            else:
                mf.add_edge(obs_node, d, float('inf'))
    
    flow = mf.max_flow(S, T)
    print(total_reward - flow)

if __name__ == "__main__":
    main()
```このコードは、標準の Edmonds-Karp max-flow アルゴリズムを定義します。 各ドッグにはフリップ コストを表すソースまたはシンクへのエッジがあり、各オブザーバーは無限の容量エッジを介してドッグに接続します。 友人以外の報酬は total_reward に追加され、シンクするエッジとしてモデル化されます。 フレンドのペナルティは、ソースからのエッジとしてモデル化されます。 最終的な答えは、total_reward から min-cut 値を減算します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O((n+m)*F) | エドモンズ・カープの最悪のケースは O(E_F) です。ここで E = O(n_m)、F は容量の合計によって制限されます |
 | スペース | O(n + m + 合計 k_i) | それぞれの犬と観察者がノードです。 k_i の合計に比例するエッジ |

 n ≤ 10^4 および m ≤ 2*10^3 で、各 k_i ≤ 10 の場合、アルゴリズムは 2 秒未満で快適に実行されます。
