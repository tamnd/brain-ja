 ## 解決策
 ## 問題の理解

 以下から数値の順列を構築するように求められます。$1$に$n$2 つの制約が同時に満たされるようにします。 まず、すべての値は、その値とちょうど 1 だけ異なる値を持つ少なくとも 1 つの近傍の隣に存在する必要があります。 第二に、数字を元の位置に留めておくことはできません。 

最初の条件は、ローカル構造を強制します。つまり、各値は、隣接する数値の値が 1 つ異なるチェーンの一部である必要があります。つまり、隣接する数値は、ある順序で連続する整数のように動作する必要があります。 2 番目の条件は固定点を削除し、些細なアイデンティティのような取り決めを排除します。 

入力は、次の複数の独立した値を与えます。$n$。 それぞれについて、そのような順列を構築するか、何も存在しないと判断します。 

合計に関する制約$n$すべてのテスト ケースにわたって、すべてのソリューションの合計サイズが線形である必要があることを意味します。 アン$O(n \log n)$このアプローチはすでに安全ですが、最悪の場合は次の値に達するため、二次関数は失敗します。$2 \cdot 10^5$要素。 

最も繊細なエッジケースは小さい$n$。 のために$n = 2$、スワップすると次のような結果が得られるため、有効な取り決めは存在しません。$[2,1]$、どちらも異なる隣接要素を持たないため、端の要素の隣接条件に違反します。$1$両側にあります。 のために$n = 3$、すべての順列は固定点を作成するか、隣接制約を破るため、これも失敗します。 これらのケースは明示的に除外する必要があります。 

## アプローチ

 ブルート フォースでは、すべての順列を試し、両方の制約をチェックします。 がある$n!$順列と各チェックのコスト$O(n)$、したがって、これは、たとえ$n = 10$。 

重要な観察は、隣接性制約によって数値が連続した値ブロックに強制的に出現するということです。 連続する整数の小さな反転セグメントに数値を配置すると、各セグメント内ですべての要素がちょうど 1 だけ異なる数値に隣接します。 これは、順列をサイズのブロックにグループ化することを示唆しています。$2$または$3$構造がローカルに保存される場所。 

次に、固定小数点制約によって、どのブロック サイズが安全であるかが決まります。 ペアの単純な交互交換はきれいに機能します。隣接するすべてのペアを交換すると、元の位置に留まる要素がなく、すべての要素が連続する隣接要素に隣接するようになります。 

いつ$n$奇数で、より大きい$3$、サイズの 1 つのブロックを形成することで、残った構造を処理できます。$3$最初はペアの交換を続けます。 

これにより、直線的な時間で建設的な解決策が得られます。

 |---|---|---|---|
 | ブルートフォース |$O(n! \cdot n)$|$O(n)$| 遅すぎる |
 | 建設的なペアリング |$O(n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 各テスト ケースについて、順列を直接構築します。 

## 建設のアイデア

 私たちはからの数字を処理します$1$に$n$そしてそれらをグループ化します。 

1. もし$n = 2$または$n = 3$、出力$-1$なぜなら、両方の制約を同時に満たすことができる配置はないからです。 これは、小さなケースの可能性を列挙することによって検証されます。 

2. のために$n \ge 4$、ブロック内の順列の構築を開始します。 

3. もし$n$奇数です。まず配置してください$3, 1, 2$。 これにより、固定点が回避され、ブロック内の連続する値間の隣接性が保証されます。 

4. 次に、次の未使用のインデックスから始まる残りの番号について、ペアを処理します。$(i, i+1)$それらを入れ替えた順序で出力します$(i+1, i)$。 これにより、固定点がないことが保証されます。 

5. すべての数字が使用されるまで続けます。 

## なぜ機能するのか

 スワップされたすべてのペアの内部$(i, i+1)$、両方の数値が連続する値に隣接しており、隣接条件を満たしています。 逆転はどちらも保証しません$i$または$i+1$元のインデックスに配置されます。 初期の$3$-cycle ブロックは隣接関係を壊すことなくパリティを処理し、その後の構造は均一になります。 すべての数値はスワップされたペアまたは最初のブロックのいずれかにあるため、すべての制約がグローバルに満たされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())

        if n == 2:
            print("1 2")
            continue
        if n == 3:
            print("-1")
            continue

        res = []

        i = 1
        if n % 2 == 1:
            res.extend([3, 1, 2])
            used = {1, 2, 3}
            i = 4
        else:
            used = set()

        i = 1
        res = []
        if n % 2 == 1:
            res.extend([3, 1, 2])
            i = 4
        else:
            i = 1

        while i <= n:
            if i + 1 <= n:
                res.append(i + 1)
                res.append(i)
                i += 2
            else:
                break

        print(*res)

if __name__ == "__main__":
    solve()
```この構築は完全に貪欲であり、固定ローカル スワップのみに依存しています。 奇妙なケースは、対称性を破る小さな初期順列によって処理され、その後はペアリングが安全になります。 

微妙な点は、すべてのブロックの位置が入れ替わるか、サイクル内で並べ替えられるため、元のインデックスに数値を決して配置しないことです。 この実装により、バックトラッキングのない線形トラバースが保証されます。 

## 実用的な例

 ### 例 1

 入力:```
n = 5
```奇妙なケースから始めるので、最初のブロックを配置します。 

| ステップ | アクション | 結果 |
 |------|--------|----------|
 | 1 | 3 1 2 位 | [3、1、2] |
 | 2 | 4 以降のペアを交換する | [3、1、2、5、4] |

 すべての数値が連続する値の隣にあり、どの位置にも独自のインデックスが含まれていないため、最終的な置換は隣接性を満たします。 

### 例 2

 入力:```

```偶数の場合はスワップのみを使用します。 

| ステップ | アクション | 結果 |

 | 1 | 1 と 2 を入れ替える | [2、1] |

 | 3 | 5と6を入れ替える | [2、1、4、3、6、5] |

 すべての要素は連続した値に隣接しており、固定点は存在しません。 

これらの例は、構造が均一であり、グローバル構造から独立していることを示しています。
