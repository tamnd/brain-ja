 ## 解決策
 ## 問題の理解

 この問題では、ゼロ年が存在しない歴史的な年番号付けシステムが使用されています。 元号が始まってからの年は正の整数で記述され、元号より前の年は負の整数で記述されます。 したがって、年の順序は次のようになります。`..., -3, -2, -1, 1, 2, 3, ...`ある出来事が起こった年と、その出来事と別の出来事の間の年数が与えられます。 肯定的な分離は時間的に前進することを意味し、否定的な分離は後退することを意味します。 課題は、この珍しい番号付けシステムを使用して 2 番目のイベントの年を見つけることです。 

値は次のように大きくできます。$10^9$絶対値で言うと。 このサイズのループには最大 20 億回の反復が必要となるため、これにより、毎年の動きをシミュレートすることが直ちに除外されます。 ソリューションでは、定数時間演算による直接算術を使用する必要があります。 

難しいのは、カレンダーが年からジャンプするため、通常の整数の加算が機能しないことです。`-1`年に直接`1`。 たとえば、1年後に引っ越しすると、`-1`与える`1`、 ない`0`。 単純に計算するソリューション`A + n`この移行付近で失敗します。 

次の入力を考えてみましょう。```
-1
1
```正しい出力は次のとおりです。```
1
```通常の算術を使用した不用意な実装では、次のような問題が発生します。`0`、これは有効な年ではありません。 

別の境界ケースは、最初のプラスの年から逆方向に移動しています。```
1
-1
```正しい出力は次のとおりです。```
-1
```通常の減算では、`0`、再び存在しない年が生成されます。 

## アプローチ

 直接的なアプローチは、今年度から目標に向かって繰り返し実行することです。 距離が正の場合、年は一度に 1 ステップずつ増加します。 距離が負の場合は、一度に 1 ステップずつ減少します。 すべての操作がちょうど 1 年間の動きを表すため、これは理解しやすいです。 ただし、距離に絶対値がある場合は、$10^9$、これは 10 億回の反復を実行しますが、これはプログラムが制限時間内に完了できる量をはるかに超えています。 

重要な観察は、カレンダーの唯一の異常な部分は、ゼロ年が欠落していることです。 過去の年番号を一時的に通常の連続整数線に変換できます。 

この変換では、すべての正の年をそれ自体にマッピングします。 ゼロが欠けているとギャップが生じるため、負の年は 1 つずらされます。 変換は次のとおりです。```
year > 0  -> year
year < 0  -> year + 1
```これでシーケンスは連続的になります。```
-3 -> -2
-2 -> -1
-1 -> 0
 1 -> 1
 2 -> 2
 3 -> 3
```変貌したこの空間で、移動しながら`n`年は加算されるだけです`n`。 その後、結果を変換して戻します。 ゼロより大きい値はすでに正の年ですが、ゼロと負の値は元号より前の年に対応するため、1 つ戻す必要があります。

 ## アルゴリズムのチュートリアル

 1. 開始年を連続表現に変換します。 年が正の場合は、変更しないでください。 負の場合は、その年になるように 1 を加えます。`-1`ゼロになります。 
2. 変換された値に指定された年数を加算します。 変換されたタイムラインにはギャップがないため、これは機能します。 
3. 変換された年を元のカレンダー形式に変換します。 正の変換値は変更されませんが、ゼロと負の変換値は 1 ずつ減少します。 

機能する理由: この変換により、歴史上の実際の年と通常の整数との間に 1 対 1 のマッピングが作成されます。 歴史上の隣接する年はすべて、隣接する整数になります。`-1`そして`1`。 イベント間の距離はこのマッピングによって保存されるため、次のように追加します。`n`変換された空間では、正確な目的地年が得られます。 逆変換により、必要な歴史的表記法が復元されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def to_linear(year):
    if year > 0:
        return year
    return year + 1

def from_linear(value):
    if value > 0:
        return value
    return value - 1

def solve():
    a = int(input())
    n = int(input())

    current = to_linear(a)
    answer = from_linear(current + n)

    print(answer)

if __name__ == "__main__":
    solve()
```機能`to_linear`欠落している年のギャップを削除します。 重要な境界線は、`-1`となり、`0`、年に直接隣接します`1`、として表されます`1`。 

加算は変換後にのみ行われるため、プログラムは最終的な答えとして無効なゼロ年を作成することはありません。 機能`from_linear`すべての非正の変換値を負の過去の年に戻すことにより、逆変換を処理します。 

ループや大きな配列は使用されないため、許容される最大値であっても実装は定数のままです。
