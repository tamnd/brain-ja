 ## 解決策
 ## 問題の理解

 この問題は、2 種類の部品から作られたジェット コースターについて説明しています。 特別なピースはすでに存在しており、それぞれが列車の速度を変更します。列車が特別なピースに入るときは 1 つの速度を持つ必要があり、列車が出発するときは別の速度を持つ必要があります。 特別な部分の間には通常の線路を建設できますが、通常の線路では列車の速度を低下させることしかできません。 タスクは、すべての特別なピースの順序を選択し、乗車全体が可能になるように通常のトラックの最小全長を追加することです。 入力はすべての特別な曲の開始速度と終了速度を与え、出力は必要な追加トラックの最小量になります。 これは IOI 2016 のジェット コースター鉄道タスクで、元の完全な制約により最大 200,000 の特別セクションが許可されます。 

難しいのは、特別なピースの順序が固定されていないという事実にあります。 直接的なアプローチでは、可能な順序をすべて試行しますが、可能な順序の数は階乗として増加します。 たとえ数十個のピース​​であっても、これは不可能になるため、最終的な解決策は順列の数に依存することを回避する必要があります。 

大きな制約は、アルゴリズムが線形または線形に近いものでなければならないことを意味します。 セクションが 200,000 ある場合、サブセットに対する動的プログラミングやすべての順序の試行などのアプローチは直ちに除外されます。 成功したソリューションでは、ソート、グラフ接続、最小スパニング ツリーが使用され、これらすべてが必要なスケール内に快適に収まります。 

いくつかのケースは誤って処理されやすいものです。 入力された順序でピースを貪欲に接続するだけのソリューションは、順序が決定の一部であるため失敗します。 たとえば、入力が次の場合:```
2
10 1
1 10
```正しい出力は`0`。 最初のセクションは速度 1 で列車を出発し、2 番目のセクションは速度 1 を受け入れるため、2 つの特別なセクションを連続して配置できます。隣接する入力エントリの間に線路を常に追加する方法では、不必要な長さが誤って追加されてしまいます。 

もう 1 つのよくある間違いは、トレインに有効な開始状態と終了状態が必要であることを忘れることです。 例えば：```
2
5 10
1 2
```2 つのセクション間のギャップをチェックするだけでは答えは得られません。 最初のセクションでは列車が速度 5 で到着する必要がありますが、乗車は速度 0 から開始されるため、最初の特別セクションの前に追加の工事が必要です。 最終的なアルゴリズムは、人工セクションを導入することでこれらの境界要件を処理します。 

3 番目のエッジ ケースは、多くのセクションがすでに余長ゼロで接続できる場合に発生します。 例えば：```
3
1 3
3 5
5 7
```答えは`0`。 不注意な実装では、セクションが別の順序でチェーンされる可能性があることを考慮する前に、終了速度が次の開始速度より大きいかどうかだけをチェックするため、トラックが追加される可能性があります。 

## アプローチ

 ブルートフォースソリューションは、問題を順序付けの問題として扱います。 特別なセクションのすべての順列を試行し、連続するセクション間に必要なトラックを計算し、最小値を維持します。 固定順序の場合、1 つのセクションが速度で終了した後であるため、計算は簡単です。`x`、速度を必要な値まで下げるのに十分なトラックを追加することによってのみ、次のセクションに到達できます。 移行にスピードが必要な場合`a`そして現在の速度は`b`、追加された長さは`max(0, a - b)`。 

問題は、`n!`可能な注文。 最大の制約を使用すると、これはおおよそ次のことを意味します。`200000!`可能なアレンジメントは、プログラムが探索できるものをはるかに超えています。 

重要な点は、順序を別の方法で表すことができるということです。 すべての特別なセクションを、進入速度から退出速度までの有向エッジと考えてください。 エッジに沿って移動すると、現在の速度が開始値から終了値に変化します。 必要に応じて通常のトラックを追加して、これらのエッジを 1 つの連続したパスに接続する必要があります。 

これらのエッジのバランスから、隣接する速度値の間でどれだけの追加の動きが必要かがわかります。 速度レベルに入るエッジと比べて出るエッジが多すぎる場合は、逆方向の動きを追加する必要があります。 数が少ない場合は、パスを延長することで既存のピースを無料で接続できます。 すべての強制接続が追加された後でも、残りの問題は、セクションの一部のグループが依然として切断される可能性があることです。 これらのグループを可能な限り安価なリンクで接続することが、最小限のスパニング ツリー問題になります。 

最後のアルゴリズムは、開始速度と終了速度を並べ替え、強制トラック コストを追加し、隣接するコンポーネント間に可能な接続を作成し、Kruskal のアルゴリズムを実行します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * n) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 開始速度と終了速度が非常に大きい人工的な特別セクションを 1 つ追加します。`0`。 これはライド全体の始まりと終わりを表し、両端が開いたパスではなく、構造物を 1 つの連続したパスとして扱うことができます。 
2. すべての開始速度とすべての終了速度を別々に並べ替えます。 ソートされた終了速度とソートされた開始速度を一致させます。 終了速度が対応する開始速度よりも大きい場合は、不足している差分を追加トラックとして支払わなければなりません。 支払い後、残りのグラフ表現の方向がバランスがとれるように 2 つの値を交換します。 
3. 一致するすべての終了点と開始点の間にゼロコスト接続を作成します。 これらの接続は、特別なセクションを追加のトラックなしで直接配置することを表します。 
4. 隣接するソートされたグループ間に追加の接続を作成します。 2 つの隣接するグループを接続するコストは、それらの間にギャップが存在する場合、そのギャップになります。 これらは、最小限のコストで以前に分離されたコンポーネントを結合できる唯一の接続です。 
5. これらの接続上で Kruskal のアルゴリズムを実行します。 どのグループがすでに接続されているかを追跡するには、素セット共用体構造を使用します。 選択されたすべてのエッジは、そのコストが答えに寄与します。 

これが機能する理由は、ソートされたマッチング手順により、避けられない速度の不均衡がすべて除去されるためです。 その後の残りの選択肢は、独立したセクションのグループを接続することだけです。 グラフ内のグループを接続する最も安価な方法はまさに最小スパニング ツリーであり、クラスカルのアルゴリズムはその最小総コストを見つけます。 不変条件は、MST エッジを選択するたびに、現在接続されているグループがそれらをマージするすべての方法の中で可能な限り安価なコストになるということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        self.parent[b] = a
        return True

def solve():
    n = int(input())
    starts = []
    ends = []

    for i in range(n):
        s, t = map(int, input().split())
        starts.append((s, i))
        ends.append((t, i))

    inf = 10 ** 9
    starts.append((inf, n))
    ends.append((0, n))

    starts.sort()
    ends.sort()

    ans = 0
    for i in range(n + 1):
        if ends[i][0] > starts[i][0]:
            ans += ends[i][0] - starts[i][0]
            ends[i], starts[i] = (starts[i][0], ends[i][1]), (ends[i][0], starts[i][1])

    edges = []

    for i in range(n + 1):
        edges.append((0, ends[i][1], starts[i][1]))
        if i + 1 < n + 1:
            cost = max(0, starts[i + 1][0] - ends[i][0])
            edges.append((cost, starts[i + 1][1], ends[i][1]))

    edges.sort()

    dsu = DSU(n + 1)

    for cost, a, b in edges:
        if dsu.union(a, b):
            ans += cost

    print(ans)

solve()
```この解決策は、各特別セクションを 2 つの値 (セクション前の速度とセクション後の速度) として保存することから始まります。 人工的なセクションは、ソートされたマッチングによって完全なライドの始まりと終わりも考慮されるように追加されます。 

仕分けフェーズは最も微妙な部分です。 終了速度が対応する開始速度よりも大きい場合、その差をカバーするために通常のトラックを挿入する必要があります。 この支払い後、値を交換することで、残りの不一致構造のバランスが保たれます。 

エッジ構築フェーズでは、最適なソリューションに現れる可能性のある接続のみを作成します。 ゼロコストのエッジは直接遷移を表し、隣接するソートされたグループは切断された部分をマージする最も安価な方法を表します。 素セット共用体により、MST エッジの選択中の循環が防止されます。 

すべての値は約に達します`10^9`、最終的な答えは 32 ビット整数よりもはるかに大きくなる可能性があります。 Python の整数はこれを自動的に処理するため、オーバーフロー処理は必要ありません。
