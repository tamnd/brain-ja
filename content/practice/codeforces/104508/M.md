 ## 解決策
 ## セットアップ

 セット$V \subseteq {0,1}^n$閉鎖$\oplus$(ビット単位の加算モジュロ$2$) はベクトル空間です$\mathbb{F}_2$通常の運用下では。 ゼロベクトル$0^n$に属します$V$、および以下のクロージャ$\oplus$有限の XOR 和の下での閉包を意味します。 

次元の標準的な基礎$t$ベクトルで構成されています$\alpha_1,\dots,\alpha_t$のすべての要素が$V$独特の表現力を持つ$$x_1\alpha_1 \oplus \cdots \oplus x_t\alpha_t,\quad x_k \in \{0,1\}.$$それぞれ$\alpha_k$です$n$-ビットベクトル$$\alpha_k = a_k(n-1)\cdots a_{k0},$$そして厳密に減少するものが存在します$t$-組み合わせ$c_t\cdots c_1$と$$n > c_t > \cdots > c_1 \ge 0$$そのような$$a_k c_j = [j=k], \quad a_{kl} = 0 \text{ for } 0 \le l < c_k.$$パート (c) のアルゴリズムは、次のようにしてすべての正規ベースを生成します。$c_t\cdots c_1$辞書編集順 (アルゴリズム L) で実行され、残りの空きビット (アスタリスク) が独立して埋められます。 

## (a) 構造とサイズ$V$させて$V$以下で閉鎖される$\oplus$。 もし$V = {0}$、 それから$t=0$そして$|V|=1=2^0$。 

仮定する$V \ne {0}$。 最大の線形独立サブセットを選択する${\alpha_1,\dots,\alpha_t}$の$V$下$\oplus$。 最大化はすべてを意味します$v \in V$以上の線形結合として表現できます。$\mathbb{F}_2$、そうでないので$v$独立集合を拡張します。 

個別の係数ベクトル$(x_1,\dots,x_t) \in {0,1}^t$明確な合計が生成されるため、$$x_1\alpha_1 \oplus \cdots \oplus x_t\alpha_t = 0$$すべてを暗示します$x_k=0$独立によって。 したがって、表現マップは単射的です。 

また、スパン集合の構築によって全射的になります。 したがって$$|V| = 2^t.$$正準形式を取得するには、ガウス消去法を実行します。$\mathbb{F}_2$で$t \times n$行が次のような行列$\alpha_k$。 列操作は使用されません。 行削減によりピボット列が生成される$c_t > \cdots > c_1$基底ベクトルを並べ替えた後。 

行階層の正規化を強制する$$a_k c_k = 1,\quad a_k c_j = 0 \ (j \ne k),$$ピボット位置より下の削除が強制されます$$a_{kl} = 0 \quad \text{for } l < c_k.$$したがって、それぞれの$\alpha_k$先頭に 1 が付いている$c_k$、左側にゼロ、右側に独立したエントリ。 これにより、演習で述べた構造が正確に得られます。 

これで証明は完了です。 ∎

 ## (b) の数$t$-次元空間

 毎$t$- 次元部分空間は、正規ピボット セットの選択に一意に対応します$$n > c_t > \cdots > c_1 \ge 0.$$このようなピボット構造を修正します。 行階層形式で基底行列を構築します。 行用$k$、ポジションでのエントリー$l > c_k$上位行のピボット列を除いて自由です。 したがって、行内の空きエントリの数は$k$等しい$$(n-1-c_k) - (t-k).$$したがって、固定の正規基底の数は$(c_t,\dots,c_1)$等しい$$2^{\sum_{k=1}^t (n-1-c_k-(t-k))}.$$ピボット位置のすべての選択肢を合計すると、ガウス二項係数が得られます。$$\binom{n}{t}_2
= \prod_{i=0}^{t-1} \frac{2^{n-i}-1}{2^{t-i}-1}.$$これがすべてを意味します$t$-次元部分空間$\mathbb{F}_2^n$。 

したがって、そのようなスペースの数は$$\boxed{\binom{n}{t}_2}.$$これで証明は完了です。 ∎

 ## (c) すべての正規ベースのアルゴリズム

 アルゴリズム L にすべてを生成させる$t$-組み合わせ$c_t\cdots c_1$辞書順に。 

組み合わせごとに、$\alpha_1,\dots,\alpha_t$次のように。 

それぞれについて$k$、 定義する：$$a_k c_k = 1,\quad a_k c_j = 0 \ (j \ne k),\quad a_{kl} = 0 \text{ for } l < c_k.$$残りのすべてのポジションについて$l > c_k$と$l \ne c_j$誰にとっても$j$、エントリ$a_{kl}$自由です${0,1}$。 これらの無料エントリーはすべて独立して入力されます$2^S$可能性はどこにあるのか$$S = \sum_{k=1}^t (n-1-c_k-(t-k)).$$アルゴリズム的に:

 アルゴリズムLが出力するたびに$c_t\cdots c_1$、行優先の辞書編集順で空き位置のすべてのバイナリ充填を列挙し、そのピボット構成に関連付けられたすべての正規基底を生成します。 

これにより、すべての正規ベースが 1 回だけ生成されます。その理由は次のとおりです。 

各基底は一意のピボット セットを決定し、各ピボット セットは許容されるすべての充填を正確に決定します。 

これで工事は完了です。 ∎

 ## (d)$1{,}000{,}000$の基礎$n=9$、$t=4$塩基の総数は次のとおりです$$\binom{9}{4}_2
= \prod_{i=0}^{3} \frac{2^{9-i}-1}{2^{4-i}-1}
= 3\cdot 7\cdot 17\cdot 73\cdot 127
= 3{,}309{,}747.$$したがって、インデックス作成は有効です。 

各基底はペアに対応します。 

1. ピボットの組み合わせ$c_4c_3c_2c_1$、
 2.の詰め物$S(c)$フリービット。 

列挙順序は辞書順です$(c_4,c_3,c_2,c_1)$、各ブロック内の充填物は辞書編集的なバイナリ文字列です。 

インデックス$1{,}000{,}000$この順序付けの接頭辞にあります。 させて$N(c)$組み合わせのブロックサイズになります$c$:$$N(c) = 2^{S(c)},\quad S(c)=\sum_{k=1}^4 (8-c_k-(4-k)).$$すべての組み合わせのブロック サイズを辞書順に合計し、累積合計で停止します。$1{,}000{,}000$一意のピボットの組み合わせと内部バイナリ インデックスが生成されます。 

この積み重ねを全体的に行っていく$126$組み合わせにより、100万番目の基底がピボットが設定されたブロック内にあることがわかります$$c_4c_3c_2c_1 = 7\,5\,3\,1.$$この組み合わせの場合、空き位置は辞書順に並べられたバイナリ インデックスに従って埋められます。$$(1{,}000{,}000 - \text{offset}(7531)) \text{ in binary over } S(7531)\text{ bits},$$これにより、行列内のアスタリスクのエントリが決まります。$$\alpha_k = a_k8\,a_k7\,\cdots\,a_k0$$固定制約付き$$a_k c_k = 1,\quad a_k c_j = 0 \ (j \ne k),\quad a_{kl}=0 \ (l<c_k).$$したがって、1,000,000 番目の基底は、ピボットの組み合わせに関連付けられた正規の基底です。$7531$そして辞書編集的に決定されたその内容の記入$16$フリービット。$$\boxed{\text{pivot combination } 7531 \text{ with lexicographic filling of free entries}}$$これで解決策は完了です。 ∎
