 ## 解決策
 ## 問題の理解

 凸多角形の頂点が境界に沿って順番に与えられ、その幾何学的面積を計算することが課題となります。 入力は、連続するすべての点のペアがエッジを形成し、最後の点が最初の点に戻る閉じた形状を表します。 ポリゴンは凸状であり、すでに順序付けされているため、ハルを再構築したり、ポイントを並べ替えたりする必要はありません。 

出力は、この多角形の面積を表す単一の数値です。 ステートメントの書式設定に応じて、答えは通常、正確な値または十分な精度の浮動小数点数として期待されます。 

制約の観点から見ると、このタイプの問題では通常、最大約 200,000 個の頂点が許可されます。 これにより、点のすべてのペアを比較したり、単純な方法で明示的に三角形分割を試みたりする二次アプローチは即座に除外されます。 線形または線形演算時間を超えるものは遅すぎます。 メモリの制約は通常厳しいですが、ポイント リストのみを保存するため、管理可能です。 

いくつかの微妙なケースでは、単純な実装が壊れる傾向があります。 1 つは、ポリゴンが順序付けされていることが保証されていないと想定しているため、船体が再計算されない限り、間違った領域が生成されてしまいます。 もう 1 つは、座標が大きくなる可能性があるため、中間の外積計算では 64 ビット整数または Python 整数を使用する必要があることを忘れていることです。 3 つ目は、正しい面積が 0 である、直線上にあるすべての点など、縮退したポリゴンを誤って処理することです。 最後に、安定した式を使用せずに増分的に実行される浮動小数点加算は、大きな座標範囲の精度誤差を蓄積する可能性があります。 

## アプローチ

 最も直接的なアイデアは、多角形を三角形に分解して面積を計算することです。 1 つの頂点 (最初の点など) をピボットとして固定し、隣接するすべての頂点のペアで三角形を形成します。 各三角形は、外積の絶対値の半分に等しい面積を占めます。 これらの三角形の領域を合計すると、ポリゴンの合計領域が得られます。 

これが機能するのは、任意の単純な多角形を固定頂点から三角形分割することができ、凸性により、そのような三角形がすべて多角形の内側にあり、重なり合わないことが保証されるためです。 ただし、これは概念的にはきれいですが、繰り返しの幾何学的構築として実装すると不必要なオーバーヘッドが生じます。 本当のボトルネックは正確さではなく、効率と数値の安定性です。 

より直接的な観察は、連続するエッジによって形成される三角形の符号付き領域を合計すると、寄与が 1 つの式に伸縮するということです。 三角形を明示的に構築する代わりに、ループ内の連続する頂点の外積を累積することができます。 これにより、計算全体が単一の線形パスに削減されます。 

ブルート フォース バージョンでは、各三角形が独立して計算されるため、行列式の再計算や冗長なジオメトリの実行によって不用意に実装された場合、O(n²) 演算が発生します。 最適化されたバージョンでは、各エッジが 1 回だけ寄与する靴紐式が使用されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース三角測量 | O(n²) | お(1) | 遅すぎる |
 | 靴紐の公式 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

1. すべてのポリゴン頂点を順番に読み取り、配列に格納します。 式は境界に沿った一貫した走査に依存するため、順序は重要です。 
2. アキュムレータ変数をゼロに初期化します。 これにより、署名された double 領域が保存されます。 
3. 最後の頂点から最初の頂点までのエッジを含む、多角形のすべてのエッジを反復処理します。 点 i から点 i+1 までの各エッジについて、外積寄与 xi * yi+1 − xi+1 * yi を計算します。 この項は、2 つのベクトルによって形成される平行四辺形の符号付き面積の寄与を表します。 
4. 各外積結果をアキュムレータに加算します。 このステップは、連続するエッジによって引き起こされるすべての向きの三角形領域を効果的に合計します。 
5. ループの後、アキュムレータの絶対値を取得し、2 で割ります。除算により、2 倍の符号付き領域が実際の幾何学的領域に変換されます。 

### なぜ効果があるのか

 重要な不変条件は、各ステップで、アキュムレータが各エッジと原点の間に形成された台形の符号付き面積の合計を格納することです。 すべてのエッジが含まれる場合、これらの台形は、一貫した方向でポリゴンの内部を正確にタイル表示します。 外積和の展開では、すべての共有対角線が正の向きで 1 回、負の向きで 1 回現れるため、内部の重なりは相殺されます。 このキャンセルにより、ジオメトリが 1 つの線形公式に分解されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    area2 = 0
    for i in range(n):
        x1, y1 = pts[i]
        x2, y2 = pts[(i + 1) % n]
        area2 += x1 * y2 - x2 * y1

    print(abs(area2) / 2)

if __name__ == "__main__":
    solve()
```このコードはポリゴンの頂点をリストに読み込むため、インデックス付けが簡単になります。 ループはモジュロ演算を使用して明示的にラップアラウンドし、開始点に戻る最後のエッジを含めます。 変数`area2`蓄積中に浮動小数点演算が繰り返されることを避けるために、符号付き領域を 2 倍格納します。 最後にのみ、絶対値を取得して 2 で割ることによって最終領域に変換します。これにより、合計時の精度の低下が回避されます。 

よくある実装上の間違いは、ループ内で除算を実行することです。これにより、浮動小数点エラーが早期に発生します。 もう 1 つは、最後の点と最初の点の間の終了エッジを忘れることです。これにより、ポリゴンが開いたチェーンに黙って縮小され、不正確な領域が生成されます。

 ## 特殊なケース

 すべての点が 1 つの線上にある縮退入力では、面積がゼロになります。 各セグメントは囲まれた領域に寄与しないため、すべての外積がゼロに相殺されるため、アルゴリズムはこれを自然に処理します。 

1 つまたは 2 つの点を持つ最小多角形も結果はゼロになります。 ループは依然として正しく実行されますが、反復ポイントまたは欠落したクロージャーによりエリアの形成が妨げられるため、すべての外積項がゼロになります。 

Python では任意精度の整数のため、大きな座標値によって問題が発生することはありませんが、固定幅の整数を使用する言語では、累積中のオーバーフローを避けるために、乗算ステップを慎重に 64 ビット算術に昇格させる必要があります。
