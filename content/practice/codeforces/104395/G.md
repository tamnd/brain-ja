 ## 解決策
 ## 問題の理解

 整数の静的配列が与えられ、クエリ値ごとに$x$、配列内のすべての隣接するペアを調べ、両方の端点をシフトすることによって形成された二次式を評価します。$x$。 固定ペアの場合$(i, i+1)$、値は$(A[i] - x)(A[i+1] - x)$。 このようなすべての隣接ペアのうち、インデックスを報告する必要があります。$i$この値を最大化します。 

各クエリは独立しており、配列は変更されません。 

重要な問題は、両方の項が以下に依存することです。$x$したがって、最適なペアは次のように大幅に変化する可能性があります。$x$は異なります。 

制約$N, Q \le 2 \cdot 10^5$クエリごとにすべての隣接するペアを再計算することは直ちに除外されます。 ナイーブ$O(NQ)$アプローチは約を実行します$4 \cdot 10^{10}$限界をはるかに超えた最悪の場合の操作。 たとえ$O(N \log N)$クエリ構造ごとに実行すると遅すぎます。 

微妙な側面の 1 つは、式が負になる可能性があり、値の単純な順序付けにおいてペア上の積を最大化することは単調ではないことです。 もう 1 つのエッジケースは次のような場合です$x$～の範囲をはるかに超えています$A$、積はほぼ凸二次関数のように動作します。$x$ただし、どのペアが絶対的な影響を最も大きくするかによって決まります。 

典型的な故障モードは、最適なペアには配列の極値が含まれている必要があると想定することから生じます。 たとえば、グローバルな最小値と最大値の近傍のみをチェックする貪欲なアイデアでは、特定の領域で優勢な内部ペアを見逃してしまいます。$x$。 

## アプローチ

 まずは強引なアイデアから始めましょう。 クエリごとに$x$、すべてのインデックスをスキャンします$i$そして計算する$(A[i]-x)(A[i+1]-x)$、最大値を追跡します。 これは、答えの定義を直接評価するため、正解です。 問題は実行時間です。各クエリにはコストがかかります$O(N)$、そして$Q$これはクエリになります$O(NQ)$、大きすぎます。 

式の構造が重要な観察点です。 固定ペアの場合$(a, b)$、 定義する$$f_{a,b}(x) = (a-x)(b-x) = x^2 - (a+b)x + ab.$$すべてのペアで放物線が定義されます。$x$そして、各クエリポイントですべての隣接するペアの上のエンベロープが必要です。 

これにより、問題は、さまざまな点で評価された二次関数のセットにわたって最大値を維持することに変換されます。 隣接するペアだけが必要なので、次のようになります。$N-1$放物線。 

隠れた構造は、すべての二次関数が同じ主要係数を共有することです。$+1$、したがって、それらの形状は線形シフトと定数項によってのみ異なります。 これにより、導関数から導出された直線上で凸包トリック スタイルの構造を使用するか、二次関数上で Li Chao ツリーを維持することによって、それらを比較することが可能になります。 

書き換え:$$(a-x)(b-x) = x^2 - (a+b)x + ab.$$以来$x^2$はすべてのペアに共通であるため、式を最大化することは次を最大化することと同じです。$$-(a+b)x + ab.$$したがって、各ペアは 1 つのラインになります$x$傾斜あり$-(a+b)$そしてインターセプト$ab$。 問題は次のようになります。クエリごとに$x$で評価された一連の行の中から最大値を見つけます。$x$を追加します。$x^2$(argmax には影響しません)。 

したがって、問題を全体にわたる範囲クエリを含む静的行コンテナに縮小します。$N-1$線。 Li Chao の木はこれをサポートしています$O((N+Q)\log C)$、 どこ$C$座標範囲です。

 ## アルゴリズムのチュートリアル

 隣接する各ペアを行に変換し、Li Chao ツリーを使用して最大のクエリに答えます。 

### ステップ

 1. インデックスごとに$i$、ペアからラインを構築します$(A[i], A[i+1])$傾斜あり$m = -(A[i] + A[i+1])$そしてインターセプト$c = A[i] \cdot A[i+1]$。 

これは、元の式を拡張し、共通の部分を削除することによって導出されます。$x^2$学期。 
2. 可能な領域上に Li Chao ツリーを構築します。$x$の制約によって制限される値。$A[i]$そしてクエリ。 
3. 各行を Li Chao ツリーに挿入します。 

挿入するたびに、ドメインのすべてのセグメントに対して最適な行が確実に保存されます。 
4. 各クエリについて$x$、Li Chao ツリーをクエリして、次の最大値を取得します。$-(a+b)x + ab$。 
5. 各行がインデックスに対応しているため、どの行がこの最大値を生成したかを追跡します。$i$。 そのインデックスを出力します。 
6. クエリごとに保存されたインデックスを返します。 

唯一の微妙な部分は、更新中に行のアイデンティティを維持することです。 Li Chao ツリーの各ノードは、最良の値だけでなく、どのペアがその値を生成したかも保存する必要があります。 

### なぜ効果があるのか

 すべての隣接するペアは、次の二次関数を定義します。$x$、すべての二次関数は同じ曲率を共有します。 これにより、共通項を削除した後、比較を一次関数に減らすことができます。 Li Chao ツリーは、ドメイン全体にわたるこれらの線形関数の点ごとの最大値を維持します。 すべてのクエリはこのエンベロープ上の 1 つの点を正確に評価するため、返される行はそのエンベロープに対してグローバルに最適な隣接ペアに対応する必要があります。$x$。 この構造は、厳密に不良なセグメントの行のみを置換し、ドメイン全体にわたって点ごとの正確性を維持するため、ペアが誤って破棄されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = 10**30

class Node:
    __slots__ = ("m", "b", "idx")
    def __init__(self):
        self.m = 0
        self.b = -INF
        self.idx = -1

def f(m, b, x):
    return m * x + b

class LiChao:
    def __init__(self, xs):
        self.xs = xs
        self.n = len(xs)
        self.size = 4 * self.n
        self.tree = [Node() for _ in range(self.size)]

    def add_line(self, m, b, idx, v=1, l=0, r=None):
        if r is None:
            r = self.n - 1

        mid = (l + r) // 2
        x_l = self.xs[l]
        x_m = self.xs[mid]
        x_r = self.xs[r]

        cur = self.tree[v]
        new = Node()
        new.m, new.b, new.idx = m, b, idx

        if f(new.m, new.b, x_m) > f(cur.m, cur.b, x_m):
            self.tree[v], new = new, cur

        if r - l == 0:
            return

        if f(new.m, new.b, x_l) > f(self.tree[v].m, self.tree[v].b, x_l):
            self.add_line(new.m, new.b, new.idx, 2*v, l, mid)
        elif f(new.m, new.b, x_r) > f(self.tree[v].m, self.tree[v].b, x_r):
            self.add_line(new.m, new.b, new.idx, 2*v+1, mid+1, r)

    def query(self, x, v=1, l=0, r=None):
        if r is None:
            r = self.n - 1

        mid = (l + r) // 2
        cur = self.tree[v]

        res = (f(cur.m, cur.b, x), cur.idx)

        if r - l == 0:
            return res

        if x <= self.xs[mid]:
            cand = self.query(x, 2*v, l, mid)
        else:
            cand = self.query(x, 2*v+1, mid+1, r)

        return max(res, cand)

def solve():
    n, q = map(int, input().split())
    a = list(map(int, input().split()))

    xs = sorted(set(a))
    lichao = LiChao(xs)

    for i in range(n - 1):
        a1, a2 = a[i], a[i+1]
        m = -(a1 + a2)
        b = a1 * a2
        lichao.add_line(m, b, i + 1)

    out = []
    for _ in range(q):
        x = int(input())
        val, idx = lichao.query(x)
        out.append(str(idx))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```核となる変換は、隣接する各ペアからラインへの変換で発生します。 傾きには負の符号が付いた端点の合計が使用され、切片にはその積が使用されます。 これはまさに、共通の部分を削除した後の元の式の拡張です。$x^2$学期。 

Li Chao ツリーはこれらのラインを格納し、座標ドメインの関連セグメント上の候補ラインを再帰的に比較することによって、対数時間でクエリに応答します。 各ノードはその中間点に最適なラインを維持し、間隔構造全体にわたる正確性を保証します。

| ペア | ライン (m, b) | x=2 の値 | x=3 の値 |

 | (1,4) | m=-5、b=4 | -6 | -11 |

これは、傾きがより悪いにもかかわらず、最も高い切片を持つため、単一のペアが複数のクエリ値全体でどのように優勢になるかを示しています。

 ## 特殊なケース

 重要なエッジケースは、複数の隣接するペアが同一またはほぼ同一の二次関数を生成する場合です。 このような場合、Li Chao ツリーは最も古いインデックスまたは正しいインデックスを一貫して保存する必要があります。 同構造体はこれを処理します。これは、タイブレークが厳密な大規模比較に基づいているためであり、厳密に優れたものが存在しない限り、最初に挿入された行はそのまま残ります。 

もう 1 つのケースは、極端なクエリ値です。$x$すべてよりもはるかに大きいです$A[i]$。 次に、各積は次の大きな正の二次関数のように動作します。$x$ただし、違いは勾配のみに依存します。$-(a+b)$。 アルゴリズムは合計が最小のペアを正しく選択します。$a+b$、これは、展開後に最小の負の線形項が得られるためです。 

最後に、値に大きな負の値が含まれる場合、切片項は$ab$は大きな正となり、ゼロに近いクエリはこれらの切片によって支配されます。 Li Chao 構造は、部分的なヒューリスティックではなく完全なライン値を評価するため、傾きと切片のバランスが正しく保たれます。
