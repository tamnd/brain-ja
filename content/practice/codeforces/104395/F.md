 ## 解決策
 ## 問題の理解

 最終的には関数グラフになる有向グラフ プロセスが与えられます。つまり、すべてのノードが 1 つの出力エッジと 1 つの入力エッジを持つことになります。 一部のエッジはすでに修正されています。 発信エッジまたは着信エッジが欠落している残りのノードについては、すべてのノードが両方の次数制約を満たすまで、未使用の発信エンドポイントを未使用の着信エンドポイントに均一にランダムに繰り返し接続します。 

グラフが完成すると、有向サイクルに分解されます。 タスクは、残りの不一致のエンドポイントがどのようにペアになっているかによって引き起こされるランダム性の下で、この最終的なランダム関数グラフの予想サイクル数を計算することです。 

重要な構造は、最終オブジェクトが常にノード上の順列であり、サイクルがその順列のサイクルに正確に対応するということです。 ランダム性は順列に直接影響するのではなく、部分的に固定されたエッジがどのように完成するかに影響します。 

n が 100000 までの場合、補完を列挙したり、ランダム性をシミュレートしたりするアプローチは不可能です。 考えられるすべての一致を保存するだけでも、指数関数的処理が必要になります。 唯一の実行可能な方向は、期待値をローカル寄与の合計に変換することなので、最終的なグラフを明示的に構築することはありません。 

微妙なエッジ ケースは、一部のエッジが自己ループであるか、すでに部分サイクルを形成している場合です。 これらは期待どおりに異なる動作をするわけではありません。 すでにクローズされている場合は決定論的に、そうでない場合は確率的にサイクル数に影響します。 「サイクルは最後にのみ現れる」という素朴な直感は、完了を段階的にシミュレートしようとすると、二重にカウントしたり、貢献を見逃したりすることにつながります。 

## アプローチ

 ブルート フォース アプローチでは、欠落している発信エッジと着信エッジを完了し、結果として得られる関数グラフを構築し、各完了でサイクルをカウントし、平均するためのすべての可能な方法が生成されます。 各ノードに欠落しているインエッジとアウトエッジが 1 つだけである場合でも、残りのスタブをペアにする方法の数は、一致しないノードの数 (およそ O(k!)) の因数分解します。 ２０歳くらいのｋでも無理になります。 

重要な観察は、ランダムな置換で期待されるサイクル数は、ノードがそのサイクル内の最小要素である確率のノード全体の合計として、または同等のこととして、特定のエッジが通過時にサイクルを閉じる確率の合計として表現できることです。 関数グラフでは、各ノードが出ていくエッジが 1 つだけあるため、各コンポーネントはおそらくそこにツリーが供給される有向サイクルになりますが、ここでは入次数と出次数の制約により、常に順列構造を扱うことが保証されます。 

部分的に構築されたグラフは、すでに独立した有向パスとサイクルを形成しているように見えます。 不完全な各チェーンは、残りのエンドポイントのランダムなマッチングによって最終的に閉じられます。 ランダム性は、一致しない発信スタブと着信スタブ間の全単射にわたって均一であるため、問題は、部分置換を完了するときに形成される予想されるサイクル数をカウントすることに軽減されます。 

これは、固定エッジによって形成される各接続コンポーネントからの寄与を計算することになります。 各コンポーネントはサイクル形成確率の観点から独立して動作し、予想されるサイクル数は加算されます。 

したがって、完了を列挙する代わりに、コンポーネントごとにそれがすでにサイクルであるか、ランダムな終了後にサイクルになるかを計算し、期待の線形性を使用して寄与を合計します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 補完を列挙する | O(k!) | O(n) | 遅すぎる |
 | コンポーネント + 期待値の分解 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 与えられたエッジを順列の部分的な制約として解釈します。 各ノードには最大で 1 つの発信エッジと 1 つの着信エッジがあるため、グラフは有向チェーンとサイクルの集合となります。 
2. 各ノードからの隣接ポインタを使用してグラフをトラバースし、固定エッジによって形成される連結コンポーネントを特定します。 各ノードは、まさに 1 つのそのような構造に属します。 
3. 各コンポーネントについて、それがすでに完全なサイクルであるかどうかを判断します。 コンポーネント内のすべてのノードの入次数と出力次数の両方がすでに 1 に等しい場合、確率 1 でサイクル カウントにちょうど 1 が寄与します。 
4. コンポーネントが閉じていない場合は、いくつかの開いた端が含まれています。 これらのオープン エンドは、後でコンポーネント全体の他のオープン エンドとランダムにペアになります。 重要な洞察は、そのようなコンポーネントがランダムに並べ替えられる「セグメント」のように動作するということです。 
5. 一致しない発信スタブ k の数を数えます。 これらのスタブは均一にランダムにペアにされ、順列になり、サイクルが発生します。 サイズ k のランダムな置換で期待されるサイクル数は、k 番目の高調波数であることが知られています。 
6. したがって、合計の答えは、すでに終了したサイクルからの寄与の合計に、残りの不一致構造に対する調和期待を加えたものになります。 
7. 事前計算または直接モジュラー逆和を使用して、1e9+7 を法とする高調波数を計算します。 

### なぜ効果があるのか

 すべての有効な完了は、一致しないエンドポイントの順列に対応し、サイクル カウントはコンポーネントにわたって加算的に分解する順列のクラス関数です。 期待値の線形性により、コンポーネント間の依存関係を無視でき、問題を未解決の接続の数に等しいサイズのランダムな並べ替えで期待されるサイクルをカウントすることに軽減できます。 各サイクルの形成は順列における相対的な順序のみに依存するため、すべての完了の可能性が等しく、高調波の期待が正確になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, m = map(int, input().split())
    
    nxt = [-1] * (n + 1)
    indeg = [0] * (n + 1)
    outdeg = [0] * (n + 1)

    for _ in range(m):
        a, b = map(int, input().split())
        nxt[a] = b
        outdeg[a] += 1
        indeg[b] += 1

    visited = [False] * (n + 1)

    def dfs(u):
        stack = []
        cur = u
        while cur != -1 and not visited[cur]:
            visited[cur] = True
            stack.append(cur)
            cur = nxt[cur]
        return stack

    cycles = 0
    open_stubs = 0

    for i in range(1, n + 1):
        if not visited[i]:
            comp = dfs(i)
            is_cycle = True
            for v in comp:
                if indeg[v] != 1 or outdeg[v] != 1:
                    is_cycle = False
                if indeg[v] == 0:
                    open_stubs += 1
                if outdeg[v] == 0:
                    open_stubs += 1
            if is_cycle:
                cycles += 1

    # expected cycles in random permutation of size open_stubs/2 pairs
    k = open_stubs // 2

    # harmonic number H_k mod MOD
    inv = [0] * (k + 2)
    for i in range(1, k + 2):
        inv[i] = pow(i, MOD - 2, MOD)

    harm = 0
    for i in range(1, k + 1):
        harm = (harm + inv[i]) % MOD

    print((cycles + harm) % MOD)

if __name__ == "__main__":
    solve()
```この実装では、最初に部分関数グラフを構築し、次に出力エッジをたどることによってコンポーネントを抽出します。 完全に形成されたサイクルをすぐにカウントします。 不完全なコンポーネントの場合、一致しない入力/出力エンドポイントをスタブとしてカウントします。 これらのスタブはランダム マッチング問題を定義し、その予想されるサイクル数は高調波数を使用して計算されます。 

実装上の微妙な点は、欠落しているインエッジとアウトエッジのそれぞれが個別にスタブ カウントに寄与することです。これらはペアにする必要があるため、2 で割る必要があります。高調波の合計は逆モジュラーを使用してモジュロで計算されます。

 ## 特殊なケース

 すべてのノードがすでに自己ループを形成している場合、すべてのノードはサイクルとなり、オープン スタブはゼロになります。 倍音部分は消え、答えは単純に n になります。 

グラフが単一の長いチェーンである場合、固定サイクルは存在せず、すべての寄与は完全に開いた順列構造に対する調和期待から得られます。 

切断されたチェーンが複数ある場合、期待値の線形性を通じてそれぞれが独立して寄与し、アルゴリズムは干渉することなく正しく集約します。
