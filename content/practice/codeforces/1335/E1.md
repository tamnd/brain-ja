 ## 解決策

 ## 問題の理解

 整数のシーケンスが与えられ、非常に特殊な構造を持つ部分シーケンスを抽出するように求められます。 サブシーケンスは、繰り返される値のブロックのように見える必要があります`x`、その後に繰り返される値のブロックが続きます`y`、その後に同じ値が再び続きます`x`。 2 つの値は等しくてもよく、これにより構造が 1 つの均一なブロックに折りたたまれます。 

タスクは、有効なサブシーケンスを構築することではなく、この制約の下でその長さを最大化することです。 順序を維持しながら要素を自由に削除できるため、実際の問題は、左側のブロックがどこから始まり、中央のブロックがどこにあるか、そして両端の一致する要素をどの程度再利用できるかを選択することです。 

制約`n ≤ 2000`テストケースごと、合計も含む`≤ 2000`、ということを示唆しています。`O(n^3)`テストごとの解決策が遅すぎますが、`O(n^2)`または`O(n^2 log n)`許容されます。 小さなアルファベット サイズ (最大 26 の値) は重要なヒントです。すべての値のペアを試す余裕があります。`(x, y)`。 

単純な間違いは、すべてのサブシーケンスを直接試行したり、構造を持たずにすべてのサブストリングに対して DP を試行したりすることです。これにより、三次的な動作またはさらに悪い動作が発生します。 もう 1 つの微妙な問題は、元の配列で中央のブロックが連続している必要があると仮定していることですが、サブシーケンスを処理しているため、これは誤りです。 

エッジケースには、すべての値が等しい配列、最適解が 1 つの値のみを使用する配列、最適な構造が非常に小さな中央ブロックまたは空の中央を使用するケースが含まれます。 

たとえば、`[1, 1, 1, 1]`、最良の答えは`4`を選択することで達成されます。`x = 1, y = 1`。 強制的な不注意なアプローチ`x ≠ y`誤って答えを減らしてしまいます。 

別の例は`[1, 2, 3, 2, 1]`。 これは対称的に見えますが、サブシーケンス制約を維持しながら、中央が一貫したブロック構造をサポートできないため、有効ではありません。 

## アプローチ

 強引なアイデアは、値を選択することです`x`そして`y`、次に、フォームの最適なサブシーケンスを構築してみます。`x...x y...y x...x`。 固定用`(x, y)`、配列をスキャンして、その数を決定します。`x`左から何個取れますか`y`真ん中を何人入れることができますか`x`右から。 ポジションを明示的に分割しようとすると、最終的には分割ポイントのすべてのトリプルをチェックすることになります。`O(n^3)`ペアごとに、値が 26 個あると、これは非常に遅くなります。 

重要な観察は、外側のブロックは次の出現回数のみに依存するということです。`x`プレフィックスとサフィックスから取得できますが、中央のブロックは選択した境界間のサブ配列に依存します。 境界を明示的に選択する代わりに、境界の数を修正します。`x`両端から取った、と言う`k`、次に、`k`左から - 番目の出現と`k`右から - 番目の出現。 そのセグメント内では、ある値の最適な周波数のみが必要です`y`。 

したがって、それぞれの値について`x`、その出現位置を事前に計算します。 私たちはできる限りのことを試みます`k`私たちが取れるように`k`両端からの発生。 このような境界位置のペアごとに、中央のセグメントをスキャンし、任意の値の最大頻度を計算します。`y`。 答えは`2k + best_middle`。 

これにより問題は次のように縮小されます`O(26 * n^2)`、それぞれのため`x`まで試してみます`O(n)`の値`k`、各中間スキャンは`O(n)`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(26² · n³) | O(n) | 遅すぎる |
 | 最適 | O(26 · n²) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

1. 1 から 26 までの各値の位置のリストを作成します。これにより、各値がどこに存在するかをすぐに知ることができ、外側のブロックを修正するために不可欠です。 
2. 各値について`x`、対称的な外側のブロックを選択するすべての可能な方法を検討してください。 もし`pos[x]`含まれています`m`出来事、私たちは試みます`k = 0`に`m // 2`。 これは取ることを表します`k`最初からの出来事と、`k`端から。 これにより、インデックスが増加し続けるため、有効なサブシーケンス構造が保証されます。 
3. それぞれについて`k`、左境界を次のように定義します。`pos[x][k - 1]`そして右境界は次のようになります`pos[x][m - k]`。 中間のセグメントは、厳密にこれら 2 つのインデックスの間にあるすべてのものです。 
4. 中央のセグメントをスキャンし、すべての値の頻度カウントを計算します。`y`。 可能な限り最良の中間ブロックは、そのセグメント内のすべての値の最大頻度です。 これが機能するのは、中央のブロックが単一の繰り返し値である必要があるためです。 
5.次のように回答を更新します。`2 * k + best_middle`。 
6. 外側のブロックを取らない場合も考えてみましょう。これにより、問題は配列全体で最も頻繁に発生する要素を見つけることになります。 

### なぜ効果があるのか

 この構築により、サブシーケンスが独立した構造決定に分割されます。 アウターを外したら`k`のペア`x`が固定されている場合、有効な補完は中間の間隔にある複数の要素セットにのみ依存します。 中央は単一の繰り返し値である必要があるため、最適な選択は単にその範囲内で最も頻繁に発生する要素になります。 すべての有効なソリューションは、まさに 1 つの選択肢に対応します。`x`、`k`、 そして`y`したがって、そのようなトリプルをすべて列挙すると、重複や省略なしに解空間全体がカバーされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        pos = [[] for _ in range(27)]
        for i, v in enumerate(a):
            pos[v].append(i)

        ans = 1

        # case: single block (x == y or y empty)
        freq = [0] * 27
        for v in a:
            freq[v] += 1
            ans = max(ans, freq[v])

        # try outer value x
        for x in range(1, 27):
            m = len(pos[x])
            if m == 0:
                continue

            for k in range(m // 2 + 1):
                l = pos[x][k - 1] + 1 if k > 0 else 0
                r = pos[x][m - k] - 1 if k < m else -1

                if l > r:
                    ans = max(ans, 2 * k)
                    continue

                cnt = [0] * 27
                best_mid = 0

                for i in range(l, r + 1):
                    cnt[a[i]] += 1
                    if cnt[a[i]] > best_mid:
                        best_mid = cnt[a[i]]

                ans = max(ans, 2 * k + best_mid)

        print(ans)

if __name__ == "__main__":
    solve()
```この実装では、最適な答えが単なる定数のサブシーケンスである縮退ケースを処理するために、最初にグローバル周波数を計算します。 

各候補の外側の値について`x`、可能な対称カウントを反復します。`k`。 インデックス`l`そして`r`削除した後、内部セグメントを慎重に定義します。`k`両端からの発生。 境界ロジックは非常に重要です。`pos[x][k - 1] + 1`左側のブロックを確実に除外します。`pos[x][m - k] - 1`右のブロックは除外されます。 

中央のスキャンでは、構成ごとに新しい周波数アレイが使用されます。 繰り返しのように見えますが、制約が少ないため、全体的な複雑さは依然として許容範囲内です。

 ## 特殊なケース

 次のような単一要素の配列では`[5]`、すべての構成は、空の外側のブロックまたは単一の中間要素のいずれかに縮小されます。 アルゴリズムはこれを自然に処理します。`k = 0`は全範囲につながり、最適な周波数は 1 です。 

次のようなすべてが等しい配列では`[7,7,7,7,7]`、あらゆる選択肢`x`そして`k`有効な構造が生成され、中間周波数は残りのカウントと等しくなります。 最適な値は配列全体の長さになります。これは次の場合に達成されます。`x = y = 7`。 

次のような疎配列では`[1,2,3,4]`、意味のある外側のブロックを形成するのに十分な値の繰り返しはないため、すべて`k > 0`ケースは失敗するか、貢献度が低い場合があります。 グローバル周波数の初期化により、答えが正しく 1 に戻ることが保証されます。
