 ## 解決策

 ## 問題の理解

 同じキャンディーの山を 2 つの肯定的な部分に分割しています。 各テスト ケースには番号が付けられます`n`そして、異なる順序ペアの数を数えたいとします。`(a, b)`両方が存在するように`a`そして`b`が正の整数である場合、それらの合計は次のようになります`n`、最初の部分は厳密に 2 番目の部分よりも大きくなります。 

キャンディーは区別できませんが、アリスとベティは別人であり、制約があるため、順序は重要です。`a > b`対称的な重複を自動的に削除します。 

制約の観点から見ると、テスト ケースの数は 10,000 に達する可能性があり、それぞれのテスト ケースは`n`最大 2×10^9 まで可能です。 これにより、すべてのペアを列挙しようとするソリューションが即座に除外されます。`(a, b)`まで`n`なぜなら、それはテストケースごとに線形であり、あまりにも遅すぎるからです。 目的のソリューションでは、テスト ケースごとに一定時間で答えを計算する必要があります。 

素朴な推論による微妙な失敗のケースは、厳密な不等式を忘れていることから生じます。 たとえば、次のようなとき`n = 4`、有効な分割は次のとおりです。`(3,1)`のみ。 ペア`(2,2)`は、合計が正しくても無効であり、その条件が欠けているとオーバーカウントになります。 もう 1 つのよくある間違いは治療です`(a, b)`そして`(b, a)`2 つの有効な選択肢として考えられますが、これは二重にカウントされ、順序付け条件が完全に破られてしまいます。 

## アプローチ

 ブルートフォース戦略では、考えられるすべての値を試します。`a`から`1`に`n - 1`、計算する`b = n - a`、そして次の場合はそれを数えます`a > b`。 これは正しいですが、大まかにチェックします`n`テスト ケースあたりの候補数は、単一入力の最悪のケースでは約 2×10^9 の演算となり、全体では最大 10^13 の演算になります。 それはまったく不可能です。 

重要な観察は、一度、`a + b = n`、選択する`a`自動的に修正します`b`したがって、問題は整数の個数を数えるということになります。`a`両方を満たす`a > n - a`そして`a > 0`。 不等式は次のように単純化されます`2a > n`、 それで`a > n/2`。 

同時に、次のことも確保する必要があります。`b = n - a > 0`、つまり`a < n`。 したがって、有効な値は`a`厳密に次より大きい整数です`n/2`厳密にそれより小さい`n`。 

これにより、問題は連続した間隔で整数を数えることになり、反復ではなく算術演算で直接計算できます。

 ## アルゴリズムのチュートリアル

 1. 有効な分布は、次の選択によって完全に決定されることを確認します。`a`、 以来`b = n - a`。 これにより、問題は有効な値を数えることに減ります。`a`。 
2. 制約を変換する`a > b`置換を使用して不等式に変換します。`a > n - a`。 
3. 不等式を並べ替えて分離する`a`、与える`2a > n`、つまり`a > n/2`。 
4. これをポジティブ制約と組み合わせます。 以来`b > 0`、私たちは持っている必要があります`a < n`、そしてそれ以来`a > 0`によってすでに保証されています`a > n/2`のために`n ≥ 1`、有効範囲は`a ∈ (n/2, n)`。 
5. この範囲内の整数を数えます。 有効な最小の整数は次のとおりです。`floor(n/2) + 1`、そして最大のものは`n - 1`。 したがって、カウントは`(n - 1) - (floor(n/2) + 1) + 1`、これを単純化すると、`n//2 - 1 + 1 = (n - 1) // 2`。 
6. 各テスト ケースに対してこの値を返します。 

### なぜ効果があるのか

 すべての有効な分割は、正確に 1 つの整数に対応します`a`範囲内で`(n/2, n)`、そのようなすべての整数は有効な`b = n - a`これは正であり、厳密に以下よりも小さいです`a`。 有効な分割と有効な分割の間のマッピング`a`値は 1 対 1 であるため、カウントは有効です`a`値は、有効な分布をカウントすることと同じです。 不等式により確実な順序付けと厳密な順序付けが保証されるため、無効なペアは含まれません。

 ## 特殊なケース

 のために`n = 1`、2 つの正の整数の最小合計は 2 であるため、2 つの正の部分に分割する方法はありません。式は次のようになります。`(1 - 1) // 2 = 0`、有効なペアの空のセットと一致します。 

のために`n = 2`、可能な分割は次のとおりです。`(1,1)`、しかし違反します`a > b`したがって、正しい答えは 0 です。式は次のようになります。`(2 - 1) // 2 = 0`、対称の中点の場合を正しく除外します。 

偶数の場合`n`、 のような`n = 10`、ペア`(5,5)`は許可されていないため、カウントには厳密に半分を超える値のみが含まれます。 導出には厳密な不等式が組み込まれているため、式では当然中点が除外されます。 

大型用`n`のように`2 × 10^9`Python ではオーバーフローの問題は発生せず、計算はテスト ケースごとに 1 つの整数演算のままであり、正確さと効率が維持されます。
