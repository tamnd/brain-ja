 ## 解決策
 ## 問題の理解

 この問題では、両端からの要素の追加と削除をサポートする特別な構造と、`min`現在のすべての要素の最小値を累積して累計する演算。 私たちの目標は、特定の配列を処理することではなく、任意のサイズの配列に対して次のような **一連のコマンド**を生成することです。`n`、コマンド実行後の合計は、空でないすべての部分配列の最小値の合計と等しくなります。 

入力は単一の整数です`n`、配列の長さを表します。 出力は次のような一連のコマンドです。`pushback a[i]`、`pushfront a[i]`、`popback`、`popfront`、 そして`min`。 課題は、**実際の配列値を知らなくても**、空でないすべてのサブ配列の最小値が合計に寄与するようにコマンドを設計することです。 

と`n`最大 500 の場合、ソリューションは最大でも次のコマンド シーケンスを生成する必要があります。`n * (n + 2)`操作。 これは寛大です:`n = 500`、最大 251,000 個のコマンドが可能です。 これは、次の二次関数の解を得ることができることを示しています。`n`操作の観点からは、すべてのサブ配列に対する単純な総当たりアプローチが許容されます。 難しいのは、部分配列の最小値を正しく取得する一連のコマンドを記述することです。 

エッジケースは次の場合に発生します。`n = 1`またはいつ`n`小さいです。 不用意な解決策では、要素を最小限に抑えた後で要素をポップするのを忘れる可能性があり、その結果、`min`コマンドが誤って複数回適用されています。 たとえば、次の場合`n = 1`、唯一のコマンド シーケンスは、単一の要素をプッシュする必要があります。`min`を削除してください。 余分なもの`min`または、ポップが失敗するか、間違った合計が生成されます。 

## アプローチ

 素朴なアプローチは、文字通りすべての部分配列の合計をシミュレートすることです。 サブ配列ごとに`[l, r]`、次のことができます。 

1. サブ配列の要素を 1 つずつ構造体にプッシュします (たとえば、`pushback`）。 
2. 電話をかける`min`現在の最小値を合計に加算します。 
3. すべての要素をポップして構造を空に戻します。 

このアプローチは、すべての部分配列の最小値を明示的に計算するため正しいですが、`O(n^3)`コマンド: あります`O(n^2)`サブ配列があり、それぞれに最大で`n`プッシュコマンド。 のために`n = 500`、これにより、許可されたコマンドをはるかに超える 1 億 2,500 万を超えるコマンドが生成されます。`n*(n+2)`限界。 

重要な洞察は、文字通り各サブアレイをゼロから構築する必要がないということです。 プッシュとポップを慎重に順序付けることで、以前にプッシュされた要素を再利用できます。 具体的には、配列要素を 1 つずつ、開始インデックスごとにプッシュできます。`l`、サブ配列を右に拡張し、呼び出します`min`各追加の後。 から始まる部分配列を完了した後、`l`、最初の要素を削除します`popfront`。 このようにして、各要素は 1 回プッシュされ、各サブ配列は 1 つだけ貢献します。`min`手術。 合計の操作数は次のようになります。`n`プッシュ、プラス`n*(n+1)/2` `min`電話、プラス`n`ポップ - すべて安全に`n*(n+2)`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n) | 遅すぎる/コマンド制限を超えています |
 | プッシュポップで再利用 | O(n^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 空の構造体を初期化します。 常に連続した部分配列が含まれるように維持します。`a`。 
2. 開始インデックスを反復処理します。`l`0から`n-1`。 それぞれについて`l`で始まるすべてのサブ配列が必要です。`l`。 
3. それぞれについて`l`、終了インデックスを反復処理します。`r`から`l`に`n-1`。 押す`a[r]`使用して`pushback`このサブ配列拡張に対してまだプッシュされていない場合。 
4. すぐに電話する`min`現在の部分配列の最小値を追加します`[l, r]`に`sum`。 
5. から始まるすべてのサブアレイを終了した後、`l`を使用して最初の要素を削除します`popfront`。 これにより、次から始まるサブ配列の構造が準備されます。`l+1`。 
6. まで繰り返します。`l = n-1`。 最終的には構造は空になり、`sum`すべての部分配列の最小値の合計が含まれます。 

機能する理由: どの時点でも、構造体には現在の部分配列の要素が正確に含まれます。`[l, r]`。 電話をかける`min`現時点では、この部分配列の最小値を正確に次の値に追加します。`sum`。 必要な場合にのみ要素を慎重にプッシュし、各開始インデックスの処理後に先頭をポップすることで、冗長な操作を回避し、空でないすべての部分配列が合計に 1 回だけ寄与することを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
commands = []

for l in range(n):
    # Extend subarray starting at l
    for r in range(l, n):
        commands.append(f"pushback a[{r}]")
        commands.append("min")
    # Remove the first element to prepare for next starting index
    for _ in range(n - l):
        commands.append("popfront")
        break  # Only pop the first element

print(len(commands))
for cmd in commands:
    print(cmd)
```外側のループは開始インデックスを反復します。`l`。 内側のループは、サブ配列を可能なすべての終了インデックスまで拡張します。`r`。 それぞれ`pushback`すぐに続く`min`。 各開始インデックスの最後で、フロント要素をポップして、サブ配列ウィンドウを前方にスライドさせます。 次の開始インデックスの最初の要素を削除するだけでよいため、1 つのポップの後で中断します。
