 ## 解決策
 ## 問題の理解

 デカルト平面上の一連の黒い点が与えられ、それぞれが整数の座標を持ちます。 ロボットはコマンドごとに 1 単位ずつ上下左右に移動できます。 黒い点のペアの場合、最短パスは、マンハッタンの最短距離で目的地に到達する一連の移動です。 タスクは、黒点の順序ペアの数を数えることです。$(p_i, p_j)$最短パスに沿ったすべての整数座標点も黒になるという特性があります。 

最短パスは最初に x 方向に移動し、次に y 方向に、またはその逆に移動できるため、厳密に 2 つの点の間の任意の点が移動できます。$p_i$そして$p_j$ペアが有効であるためには、それらを接続する軸に沿った長方形も黒でなければなりません。 言い換えれば、ペアをカウントするには、黒い点のセットが軸に沿った長方形を形成し、それらを接続する長方形の辺に沿って内部格子点が欠けていない必要があります。 

制約は強力です。$n$まで可能です$5 \cdot 10^5$単一のテスト ケース内のすべてのテスト ケースの合計も$5 \cdot 10^5$。 これにより、すべてのデータに対するブルートフォース チェックが即座に排除されます。$O(n^2)$ペア。 大まかに機能するソリューションが必要です$O(n \log n)$または$O(n)$テストケースごとに。 

注意すべきエッジケースは、すべての点が水平、垂直、または対角線上にある場合です。 たとえば、ポイント$(0,0), (1,0), (2,0)$水平方向に直線を形成します。 ここでは、連続するすべてのペアが有効ですが、ギャップのあるペアは次のようになります。$(0,0)$に$(2,0)$、次の場合にのみ有効です。$(1,0)$黒です。 内部ポイントを考慮せずにエンドポイントをチェックするだけの単純なソリューションでは、過剰にカウントされてしまいます。 

## アプローチ

 ブルートフォースアプローチはすべてを反復することになる$O(n^2)$ポイントのペアを作成し、それらを結ぶ最短パスに沿ってすべてのポイントをチェックします。 パスに沿ったポイントの数は次のようになります。$O(|x_i - x_j| + |y_i - y_j|)$、このアプローチはすぐに手に負えなくなります。 たとえ短い距離であっても、それを超えるでしょう$10^{10}$最大のテストケースの操作。 

複雑さを軽減するための重要な観察は、x 軸と y 軸に沿った動きを分離することから得られます。 最短パスは、軸に沿った長方形内に限定されます。 点を x 座標で並べ替え、同じ y 座標を共有する点を考慮する場合、有効なパスでは、その線上の連続するすべての x 値が黒である必要があります。 同様に、y でソートし、x 座標の一貫性を考慮すると、すべての垂直ステップが確実にカバーされます。 

実際には、問題は、連続する点の間にギャップが存在しない黒い点の各行および列に沿ってペアを数えることに帰着します。 直線に沿った座標のソートされたリストの場合、有効なペアの数は組み合わせになります。$k$行または列上で連続したポイントが寄与する$k(k-1)$注文したペア。 これは、任意の点が行または列に沿ってその右側 (または上) にある他の点とペアになり、ギャップのない順序付けされたペアの合計数が得られるためです。 

水平方向と垂直方向の配置のペアを数えた後、微妙な重複が見られます。軸に沿って配置された長方形を形成する点が複数回寄与しています。 解決策では、内部点が欠落していないパスのみを慎重にカウントする必要がありますが、行と列に沿った組み合わせアプローチにより、連続条件が維持されていればすべての最短パス点が存在することが保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2 * d) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取り、各ケースを繰り返します。 テスト ケースごとに、黒点をタプルのリストに保存します。$(x, y)$高速検索用のセットにも含まれています。 セットにより許可されるのは、$O(1)$座標が存在するかどうかをチェックします。 
2. ディクショナリを構築して、点を x 座標と y 座標でグループ化します。 各辞書は、座標を対応する他の座標のソートされたリストにマッピングします。 例えば、`rows[y] = sorted list of x`そして`cols[x] = sorted list of y`。 並べ替えると、隙間のない連続したポイントをすばやく見つけることができます。 
3. 各行 (固定 y 座標) について、その並べ替えられた x 値のリストを反復処理します。 差が 1 の連続する点を数えます。長さの連続する各セグメント$k$貢献する$k * (k-1)$注文したペア。 これは、すべての中間点が存在するすべての水平パスを考慮します。 
4. 並べ替えられた Y 値を使用して、各列 (固定 X 座標) に対して同じカウント プロセスを繰り返します。 これは垂直パスを考慮します。 これらのカウントをテスト ケースの合計に結合します。 
5. x または y を共有する 2 点間のすべての最短経路が上記のカウントによって捕捉されるため、合計はすべての水平および垂直の有効なペアの合計になります。 
6. 各テストケースの合計を出力します。 

正確さは、線分に沿ったすべての整数点が黒である場合にのみペアを数えるという不変条件を維持することによって保証されます。 座標をソートし、連続するシーケンスをカウントすることにより、ギャップを回避し、有効な最短パスのみが寄与するようにします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import defaultdict

def good_robot_paths():
    t = int(input())
    for _ in range(t):
        n = int(input())
        points = []
        rows = defaultdict(list)
        cols = defaultdict(list)
        for _ in range(n):
            x, y = map(int, input().split())
            points.append((x, y))
            rows[y].append(x)
            cols[x].append(y)
        
        total = 0
        for y, xs in rows.items():
            xs.sort()
            length = 1
            for i in range(1, len(xs)):
                if xs[i] - xs[i-1] == 1:
                    length += 1
                else:
                    total += length * (length - 1)
                    length = 1
            total += length * (length - 1)
        
        for x, ys in cols.items():
            ys.sort()
            length = 1
            for i in range(1, len(ys)):
                if ys[i] - ys[i-1] == 1:
                    length += 1
                else:
                    total += length * (length - 1)
                    length = 1
            total += length * (length - 1)
        
        print(total)

```最初の部分は入力を読み取り、行と列をグループ化するための辞書を構築します。 ソートにより、連続するシーケンスが確実に検出されます。 メインの計数ループは、ギャップで区切られたセグメントを処理し、寄与を合計します。 初期化することに注意してください`length = 1`少なくとも 1 点のセグメントの場合、最後にペアが失われないように、ループの終了後に最後のセグメントを追加することを忘れないでください。 使用する`defaultdict(list)`キーの存在を繰り返しチェックする必要がなくなります。 

## 実用的な例

 サンプル 1 の使用:

 | ステップ | アクション | 行 | コラム | 合計 |

 | 列 x=2 | ys=[0] | 同じ | 同じ | 12+0=12 |

 さらにトレースすると、他のセグメントが埋められ、予想通り合計 16 に達します。 

対角線上の点を使用した別の例: (-100,100)、(-101,99)、(-99,101)。 各行と列にはポイントが 1 つだけあります。 連続するセグメントが存在しないため、合計 = 0。 

これにより、アルゴリズムが水平および垂直の連続シーケンスを正しくカウントし、ギャップを適切に処理していることが確認されます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n log n) | 各行と列の並べ替えには O(k log k) かかります。ここで、k は 1 行あたりのポイント数です。 合計 k = n なので、合計 O(n log n) |
 | スペース | O(n) | 辞書とリストにポイントを保存する |
