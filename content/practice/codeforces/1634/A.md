 ## 解決策
 ## 問題の理解

 文字列が与えられています`s`長さの`n`そして数字`k`。 正確に実行できます`k`の操作`s`ここで、各操作は文字列の逆をそれ自体に追加します (`s + rev(s)`) または逆に先頭に追加 (`rev(s) + s`）。 タスクは、すべての処理を実行した後に得られる異なる文字列の数をカウントすることです。`k`操作。 各テスト ケースの出力は、このカウントを表す単一の整数です。 

制約は小さいです。`n`100までですが、`k`は最大 1000、テスト ケースは最大 100 です。 これにより、すべてのシミュレーションが除外されます`2^k`一連の操作を明示的に行うことができます。`k = 1000`、可能なシーケンスの数は天文学的です。 それぞれの文字列を構築するのではなく、文字列の構造を推論するアプローチが必要です。 

元の文字列が回文である場合、微妙なケースが発生します。 たとえば、次の場合`s = "aba"`、 それから`rev(s) = "aba"`同じように。 任意の数の操作の後、先頭または末尾に追加`rev(s)`同じ文字列が生成されます。 これにより、複数の操作シーケンスが 1 つの文字列に折りたたまれます。 もう 1 つのエッジケースは次のような場合です`k = 0`この場合、文字列を変更する操作はないため、単純に 1 を返します。 

## アプローチ

 ブルート フォース アプローチでは、すべての操作シーケンスをシミュレートします。操作ごとに、その逆を先頭または末尾に追加し、すべての個別の結果のセットを保持します。 これは小規模な場合に機能します`k`、しかし、`k = 1000`最大の長さの文字列を保存および生成する必要があります。`n * 2^k`、それは完全に不可能です。 

重要な観察点は、その後の個別の文字列の数が`k`操作は、元の文字列が回文であるかどうかのみに依存します。 文字列が回文の場合、その逆を先頭または末尾に追加しても同じ結果が得られるため、新しい個別の文字列は表示されません。 文字列が回文でない場合、最初の演算では 2 つの異なる結果が生成され、後続の各演算は原則として 2 倍を続けます。 ただし、対称性のため、後続のすべての操作では 2 つの一意の文字列のみが生成されます。1 つは元の文字列で始まり、もう 1 つは反転された文字列で始まります。 したがって、非回文の場合、`k > 0`の場合、答えは常に 2 です。`k = 0`、答えは1です。 

この洞察により、問題は回文と次の値の単純なチェックに帰着します。`k`。 ブルート フォース アプローチは指数関数的な長さの文字列を構築しようとするため失敗しますが、最適なアプローチは反転の対称性を利用します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^k * n * k) | O(2^k * n * k) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. 各テスト ケースについて、次の内容を読んでください。`n`、`k`、および文字列`s`。 
3. もし`k = 0`、何も操作が実行されないため、すぐに 1 が返されます。 
4. 次のことを確認します。`s`はその逆と比較すると回文になります。 
5. もし`s`は回文です。すべての操作シーケンスで同じ文字列が生成されるため、1 が返されます。 
6. もし`s`が回文ではない場合、最初の操作で 2 つの異なる文字列が生成され、後続のすべての操作でこれら 2 つの異なる形式が保持されるため、2 が返されます。 
7. 各テスト ケースの結果を出力します。 

機能する理由: 不変条件は、最初の操作が非回文に適用されると、元の文字列で始まる文字列と反転した文字列で始まる文字列の 2 つの異なる文字列が正確に生成されることです。 先頭または末尾の反転はこれら 2 つの形式間でのみ交換されるため、後続の操作では新しい個別の文字列を作成することはできません。 回文は反転しても不変のままであるため、単一の文字列のみが存在します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        s = input().strip()
        if k == 0:
            print(1)
        elif s == s[::-1]:
            print(1)
        else:
            print(2)

if __name__ == "__main__":
    main()
```解決策は、テスト ケースの数を読み取ることから始まります。 各テスト ケースは、長さ、操作の数、文字列を読み取ります。 特別な場合`k = 0`が最初に処理されます。 回文チェックでは Python スライスが使用されます。これは O(n) であり、`n <= 100`。 非回文のロジックは、2 つの異なる文字列を生成する最初の操作に基づいて、2 を直接出力します。 

## 実用的な例

 サンプル 1:`s = "aab"`、`k = 2`。 

| 操作 | 文字列 |
 | --- | --- |
 | イニシャル | アブ |
 | 最初 | ああ、ああ、ああ |
 | 2番目 | ああ、ああああああ、ああああ |

 2 回の操作の後、2 つの異なる文字列が存在します。 私たちのアルゴリズムは 2 を出力し、これはトレースと一致します。 

サンプル 2:`s = "abacaba"`、`k = 1`。 

| 操作 | 文字列 |
 | --- | --- |
 | イニシャル | アバカバ
 | 最初 | アバカバアバカバ |

 以来`s`は回文であるため、最初の操作では文字列が 1 つだけ生成されます。 アルゴリズム出力 1。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n * t) | 長さ n の各文字列は回文について 1 回チェックされ、t 個のテスト ケースに対して繰り返されます。 
| スペース | お(1) | 入力読み取りと一時変数以外の追加のデータ構造はありません。 

これは十分に制約の範囲内です。`n * t <= 100 * 100 = 10^4`。

 ## 特殊なケース

 いつ`k = 0`の場合、アルゴリズムは正しく 1 を出力します。`s = "aba"`、回文、そして`k > 0`、すべての操作シーケンスが同じ文字列を生成するため、アルゴリズムは 1 を出力します。`aba...aba`。 のために`s = "abc"`、非回文、および`k = 1`、1 回の操作後の 2 つの可能な文字列は次のとおりであるため、出力は 2 になります。`"abccba"`そして`"cbaabc"`。 これらすべてのシナリオは、回文チェックと`k == 0`状態。
