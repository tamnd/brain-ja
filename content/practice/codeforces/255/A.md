 ## 解決策
 ## 問題の理解

 グレッグは、固定された繰り返し順序で演習を実行します。 最初のエクササイズは胸部をトレーニングし、2 回目は上腕二頭筋をトレーニングし、3 回目のエクササイズは背中をトレーニングし、胸部、上腕二頭筋、背中というようにパターンが再び繰り返されます。 

配列が与えられます。その位置の値は`i`グレッグが何回繰り返したのかを教えてくれます。`i`このシーケンスの - 番目の演習。 タスクは、割り当てられたすべてのエクササイズを合計した後、どの筋肉グループが最大の総反復回数を受け取るかを判断することです。 

制約は非常に小さいです。 演習の数は最大 20 で、各繰り返し回数は最大 25 です。単純なシミュレーションでも十分に高速です。 高度なデータ構造や最適化のテクニックは必要ありません。 アレイ上の単純な線形スキャンは、すでに制限内に問題なく収まります。 

唯一の微妙な部分は、各エクササイズを正しい筋肉グループに割り当てることです。 パターンは 3 回のエクササイズごとに繰り返されるため、位置のモジュロ 3 によってターゲットの筋肉が決まります。 プログラミングにおける配列インデックスは通常 0 から始まるため、不用意に実装するとマッピングが簡単に 1 つずれてしまう可能性があります。 

次の入力を考えてみましょう。```
3
10 1 20
```正しい合計は次のとおりです。 

- チェスト = 10
 - 上腕二頭筋 = 1
 - バック = 20

 したがって、答えは次のとおりです`back`。 

誰かが使ったら`i % 3`1 ベースの思考で誤って最初のエクササイズを胸部ではなく上腕二頭筋にマッピングし、間違った結果を生み出す可能性があります。 

もう 1 つの簡単な間違いは、シーケンスが周期的に継続することを忘れることです。 

例：```
5
1 2 3 4 5
```割り当ては次のとおりです。 

- 胸部: エクササイズ 1 および 4 → 1 + 4 = 5
 - 上腕二頭筋: エクササイズ 2 および 5 → 2 + 5 = 7
 - 背中: エクササイズ 3 → 3

 正しい答えは、`biceps`。 

最初の 3 つの位置のみを個別に処理するバグのある実装は、ここで失敗します。 

## アプローチ

 この強引なアイデアは、Greg のワークアウトを明示的にシミュレートすることです。 すべてのエクササイズポジションについて、それがどの筋肉グループに属しているかを決定し、その繰り返しをその筋肉の合計に追加します。 すべての演習を処理した後、3 つの合計を比較し、最大のものを出力します。 

これはすでに制限内で完全に機能します。 最大で 20 個の数値を処理するため、合計の作業量はわずかです。 

より非効率的な総当たりバージョンでは、マッスル名の循環シーケンスを繰り返し構築し、グループごとに繰り返しを個別にカウントする可能性があります。 入力が非常に小さいため、それでも問題は解決しますが、不必要な作業と複雑さが発生します。 

有益な観察は、エクササイズのタイプが完全にインデックス モジュロ 3 に依存しているということです。 

- インデックス 0、3、6、... は胸に属します
 - インデックス 1、4、7、... は上腕二頭筋に属します
 - インデックス 2、5、8、... は back に属します

 この繰り返し構造を認識すると、解は 3 つのアキュムレータを含む単一の線形パスになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n) | お(1) | 承認済み |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`そして繰り返しの配列。 
2. 胸部、上腕二頭筋、背中の合計繰り返し回数を保存する 3 つの変数を作成します。 
3. ゼロベースのインデックスを使用して配列を反復処理します。 
4. 各インデックスについて:

 - もし`i % 3 == 0`、チェストに値を追加します
 - もし`i % 3 == 1`、上腕二頭筋に値を追加します
 - それ以外の場合は、値を後ろに追加します

 演習パターンが 3 つの位置ごとに繰り返されるため、モジュロ演算が機能します。 
5. すべての演習を処理した後、3 つの合計を比較します。 
6. 合計が最も大きいマッスル名を出力します。 

### なぜ効果があるのか

 すべてのエクササイズは 1 つの筋肉グループに属し、割り当ては長さ 3 の固定サイクルに従います。 モジュロ演算により、すべてのインデックスがこれら 3 つのグループに正しく分割されます。 スキャン中、各繰り返し回数は正しい合計に 1 回だけ加算されます。 ループが終了すると、3 つのアキュムレータが各筋肉グループのトレーニングの完全な量を表します。 それらの中から最大のものを選択すると、必要な答えが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

chest = 0
biceps = 0
back = 0

for i in range(n):
    if i % 3 == 0:
        chest += a[i]
    elif i % 3 == 1:
        biceps += a[i]
    else:
        back += a[i]

if chest > biceps and chest > back:
    print("chest")
elif biceps > chest and biceps > back:
    print("biceps")
else:
    print("back")
```プログラムは入力配列を読み取ることから始まります。 3 つのアキュムレータ変数は、各筋肉グループの合計反復回数を追跡します。 

ループは演習を順番に処理します。 Python はゼロベースのインデックスを使用するため、インデックス`0`最初のエクササイズである胸部に対応します。 それが理由です`i % 3 == 0`上腕二頭筋ではなく胸部にマッピングされます。 

モジュロ パターンは 3 つのインデックスごとに繰り返され、トレーニング サイクルと正確に一致します。 

最後に、プログラムは合計を比較し、最大のものを出力します。 この問題では、答えが一意であることが保証されているため、タイを処理する必要はありません。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    chest = 0
    biceps = 0
    back = 0

    for i in range(n):
        if i % 3 == 0:
            chest += a[i]
        elif i % 3 == 1:
            biceps += a[i]
        else:
            back += a[i]

    if chest > biceps and chest > back:
        print("chest")
    elif biceps > chest and biceps > back:
        print("biceps")
    else:
        print("back")

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    return sys.stdout.getvalue().strip()

# provided samples
assert run("2\n2 8\n") == "biceps", "sample 1"

# custom cases
assert run("1\n7\n") == "chest", "single exercise"
assert run("3\n1 2 10\n") == "back", "basic full cycle"
assert run("5\n1 2 3 4 5\n") == "biceps", "cycle repetition"
assert run("20\n25 1 1 25 1 1 25 1 1 25 1 1 25 1 1 25 1 1 25 1\n") == "chest", "maximum size style case"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1 / 7`|`chest`| 最小サイズの入力 |
 |`3 / 1 2 10`|`back`| 正しいモジュロマッピング |
 |`5 / 1 2 3 4 5`|`biceps`| 繰り返しサイクルの処理 |
