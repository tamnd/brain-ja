 ## 解決策
 ## 問題の理解

 整数のシーケンスが与えられ、ほぼ等差数列を形成する最長の部分シーケンスを見つけるように求められます。 この文脈では、整数が存在する場合、シーケンスはほぼ等差数列になります。$p$そして$q$最初の要素が$p$そして後続のすべての要素は交互に増加します$+q$そして$-q$。 正式には、サブシーケンスについては、$a_1, a_2, \dots, a_k$、関係$a_i = a_{i-1} + (-1)^{i-1} \cdot q$保持しなければならない$i > 1$。 

入力により提供されるのは、$n$、元のシーケンスの長さ、および制約付きのシーケンス自体$1 \le n \le 4000$そしてそれぞれの要素$1 \le b_i \le 10^6$。 出力は、この交互進行特性を満たすことができる最長のサブシーケンスの長さです。 

以来$n$最大 4000、それを超える複雑さのソリューション$O(n^2)$制限時間を超える可能性があります。 すべてのサブシーケンスを明示的に試行する単純なアプローチは、指数関数的であり、実行不可能です。 エッジ ケースには、繰り返し番号を持つシーケンス、最適なサブシーケンスが配列全体に広がる交互の値で構成されるシーケンス、およびすべての要素が自明に進行を形成する非常に短いシーケンスが含まれます。 

単純な実装では、連続した差分が機能するか、交互の符号をチェックせずに最初の差分がサブシーケンス全体を定義すると誤って想定する可能性があり、次のようなシーケンスでは失敗します。`10, 20, 10, 20, 30`。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのサブシーケンスを列挙し、それが交互のルールに適合するかどうかをテストします。 各サブシーケンスについて、すべての連続するペアをチェックして、それらが続くかどうかを確認します。$+q, -q, +q, \dots$。 これは原則として正しいですが、確認が必要です$2^n$サブシーケンスは遅すぎます$n = 4000$。 

重要な観察は、問題がインデックスのペアに対する動的計画法に帰着できるということです。 サブシーケンスの最後の 2 つの要素を修正すると、違いは次のようになります。$q$はそれらの差の半分として決定されます（なぜなら、$a_2 - a_1 = q$、$a_3 - a_2 = -q$、 それで$a_3 - a_1 = 0$それが繰り返されるか、$2q$交互の場合）。 これは、ハッシュ マップを使用して DP 状態を効率的に保存し、インデックスごとに、指定された差分で終わる最長の有効なサブシーケンスの長さを保存することを提案します。 

各ペアを反復処理できます$(i, j)$と$i < j$そしてポテンシャルを計算します$q = (b[j] - b[i]) // 2$差が均等の場合。 辞書を使用して、次で終了する可能性のあるサブシーケンスの長さを追跡します。$j$違いあり$q$。 これにより、$O(n^2)$制限内に快適に収まるソリューション。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n) | O(n) | 遅すぎる |
 | ペアのDP | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 辞書の DP 配列を初期化します。`dp`、 どこ`dp[j][q]`インデックスで終わる最長のほぼ算術サブシーケンスの長さを表します`j`違いあり`q`。 
2. すべてのペアを反復処理します。`(i, j)`と`i < j`。 ペアごとに差を計算します`d = b[j] - b[i]`。 
3. 違いのみを考慮する`d`そのような`d`は 2 で割り切れます。これにより、交互の差が保証されます。`q`は整数であり、次のように計算されます。`q = d // 2`。 
4. で終わるサブシーケンスがすでに存在する場合`i`違いあり`q`を含めて拡張します。`b[j]`。 それ以外の場合は、次から構成される長さ 2 の新しいサブシーケンスを開始します。`b[i]`そして`b[j]`。 
5. グローバル変数を保持する`ans`すべてにわたって見つかった最大長を追跡する`dp[j][q]`。 
6. すべてのペアを繰り返した後、`ans`最長のほぼ等差数列の部分列の長さが含まれます。 

機能する理由: 各 DP 状態は、指定された交互の差を持つ指定されたインデックスで終了するサブシーケンスの最大長を正確にキャプチャします。 インデックスの順にペアを反復することにより、構築されたサブシーケンスのインデックスが厳密に増加し、サブシーケンスの要件を満たしていることが保証されます。 マップにより、同じ差異に対する繰り返しの再計算が防止されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
b = list(map(int, input().split()))

dp = [{} for _ in range(n)]
ans = 1

for j in range(n):
    for i in range(j):
        diff = b[j] - b[i]
        if diff % 2 != 0:
            continue
        q = diff // 2
        dp[j][q] = dp[i].get(q, 1) + 1
        ans = max(ans, dp[j][q])

print(ans)
```このソリューションでは、`dp`は辞書の配列であるため、完全な辞書の割り当てを回避できます。`n x n`配列を使用し、発生した差異のみをスパースに保存できます。 初期化する`ans`サブシーケンスの最小長は任意の単一要素であるため、1 に設定されます。 の`if diff % 2 != 0`整数のみを保証します`q`値が考慮され、無効なシーケンスが回避されます。 の`get(q, 1)`存在しない場合、呼び出しは長さ 2 の新しいサブシーケンスを開始します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    b = list(map(int, input().split()))
    dp = [{} for _ in range(n)]
    ans = 1
    for j in range(n):
        for i in range(j):
            diff = b[j] - b[i]
            if diff % 2 != 0:
                continue
            q = diff // 2
            dp[j][q] = dp[i].get(q, 1) + 1
            ans = max(ans, dp[j][q])
    return str(ans)

# provided samples
assert run("2\n3 5\n") == "2", "sample 1"
assert run("3\n10 20 10\n") == "3", "sample 2"

# custom cases
assert run("1\n42\n") == "1", "single element"
assert run("4\n1 3 1 3\n") == "4", "alternating sequence repeated"
assert run("5\n5 5 5 5 5\n") == "5", "all equal values"
assert run("3\n1 2 4\n") == "2", "no valid full sequence"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1\n42 | 1 | 単一要素の場合 |
 | 4\n1 3 1 3 | 4 | 交互に繰り返されるシーケンス |
 | 5\n5 5 5 5 5 | 5 | すべて等しい値のサブシーケンス |
 | 3\n1 2 4 | 2 | 部分的なサブシーケンス、最大長は n 未満 |
