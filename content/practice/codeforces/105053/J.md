 ## 解決策
 ## 問題の理解

 各資源には 2 つの競合する生産技術があり、各村で 1 つが使用されます。 リソース用$i$、アポリアンカが過ごす$A_i$ユニットあたりの人時間、ビュッデルスドルフが費やした時間$B_i$。 各村は最初にリソースごとに固定数のユニットを生産します。$U_i$そして$W_i$それぞれなので、資源の総生産量は$i$に固定されています$T_i = U_i + W_i$。 

重要な自由は、この最終的な合計が$T_i$最初に与えられたように分割する必要はありません。 村は、各資源の合計生産量を変更せずに、村間で生産量を任意に再割り当てできます。 変わるのは誰がどれだけ生産するかだけだ。 

アポリアンカが生産する場合$x_i$リソースの単位$i$、その後、ビュッデルスドルフが生産します$T_i - x_i$、合計コストは次のようになります$$\sum_i (A_i x_i + B_i (T_i - x_i)).$$選びたい$x_i$この総コストを最小限に抑えるために。 

制約により、最大で次のことが許可されます。$10^5$したがって、どのソリューションも線形または線形に近いものでなければなりません。$N$。 二次関数の何か$N$または、広い範囲にわたるソートの多い入れ子構造を伴うものは許容されますが、分布をグローバルに列挙したり、ユニットごとのシミュレーションを実行しようとすると、すぐに遅すぎます。 

素朴な考えによる微妙な失敗例は、各村が独立して生産を最適化すると仮定することです。 これでは、村間で 1 つの資源の生産を移動すると、資源ごとのコストが線形的かつ独立して変化するため、カップリングは存在しないということが無視されます。 もう 1 つの罠は、問題を整数の割り当てが必要であると解釈することです。 部分的な割り当ては明示的に許可されているため、解決策は組み合わせ割り当てではなく継続的な最適化です。 

## アプローチ

 直接定式化では変数を代入します$x_i$リソースの単位$i$アポリアンカへ。 リソースのコスト寄与$i$は$$A_i x_i + B_i (T_i - x_i) = B_i T_i + (A_i - B_i)x_i.$$最初の学期$B_i T_i$は一定です。 唯一の決定は線形項です$(A_i - B_i)x_i$、 どこ$x_i \in [0, T_i]$。 

リソースごとに独立して、ある区間にわたる線形関数を最小化します。 もし$A_i > B_i$、係数は正なので増加します$x_i$コストが増加するため、設定する必要があります$x_i = 0$。 もし$A_i < B_i$、係数は負であるため、最大化します。$x_i$、 意味$x_i = T_i$。 それらが等しい場合、どの分割も機能します。 

これは問題を完全に崩壊させます。各リソースは、どの村がより効率的であるかのみに基づいて独立して決定されます。 

ブルートフォース解釈では、各リソースの可能な分割をすべて試行しますが、それぞれ$x_i$で連続している$[0, T_i]$、それはすでに無限になります。 たとえ離散化されたとしても、組み合わせ論的に次のように爆発します。$O(\prod T_i)$、それは不可能です。 

重要な観察は分離可能性です。総コストは、それぞれの独立した一次関数の合計です。$x_i$。 異なるリソースを結合する制約がないため、それぞれを個別に最適化できます。

 ## アルゴリズムのチュートリアル

 1. すべての値を読み取る$A_i, B_i, U_i, W_i$。 コンピューティング$T_i = U_i + W_i$。 これにより、唯一のグローバル制約であるリソースごとの総生産量が固定されます。 
2. アキュムレータを初期化する`answer = 0`。 これにより、最小の総コストが収集されます。 
3. リソースごとに$i$、ビュッデルスドルフがすべてを生産した場合の基準コストを計算します。$$base_i = B_i \cdot T_i.$$4. 1 つの生産単位をビュッデルスドルフからアポリアンカに移動した場合のコスト差を計算します。$$delta_i = A_i - B_i.$$5. 割り当てを決定します。 

もし$delta_i < 0$、生産をアポリアンカに移すことでコストが削減されるため、すべての生産をアポリアンカから引き取り、貢献します$A_i \cdot T_i$。 

もし$delta_i \ge 0$、ビュッデルスドルフはそれよりも悪くも良くもないので、我々はすべてをビュッデルスドルフに残し、貢献します。$B_i \cdot T_i$。 
6. 選択した貢献度を合計回答に追加します。 

コスト関数はリソースごとの線形関数の合計に分解されるため、各リソースは独立して処理されます。そのため、リソース間で調整を行っても結果は改善されません。 

### なぜ効果があるのか

 総コストは機能の合計です$f_i(x_i) = B_i T_i + (A_i - B_i)x_i$、それぞれが別の間隔で定義されます。 異なるものをリンクする制約がないため、$x_i$、実行可能領域は独立した間隔の積です。 凸状区間にわたる線形関数は終点で最小値に達するため、それぞれの$x_i$どちらかである必要があります$0$または$T_i$。 の兆候$A_i - B_i$どのエンドポイントが最適であるかを決定し、ローカルな決定からグローバルな最適性を確保します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    ans = 0.0

    for _ in range(n):
        a, u, b, w = map(int, input().split())
        t = u + w

        if a < b:
            ans += a * t
        else:
            ans += b * t

    print(f"{ans:.10f}")

if __name__ == "__main__":
    main()
```このコードは、リソースごとのエンドポイントの決定を直接実装します。 重要な実装の詳細は、生産の中間ユニットごとの表現を構築しないようにすることです。$T_i$大きくなる可能性があり、分数推論が暗黙的に行われます。 最終的な答えが必要な精度内に収まり、すべての演算が整数の線形結合であるため、浮動小数点累算を使用すると安全です。 

分岐条件は`a < b`線形コスト関数の導関数テストをエンコードします。 平等性は、正しさに影響を与えることなく、当然のことながらどちらの分岐にも当てはまります。

import sys, io

def run(inp: str) -> str:

 ## 特殊なケース

 特殊なケースとしては、両方の村の資源効率が同等である場合があります。$A_i = B_i$。 たとえば、入力`1 5 1 5`与える$T=10$。 どちらの割り当てでもコスト 50 が得られ、アルゴリズムは一貫してコスト 50 をビュッデルスドルフに割り当てます。`else`ブランチ、正確性を維持します。 

別のケースは、次のような極端な非対称性です。$A_i \ll B_i$。 のために`1 1000 1000 1`、 我々は持っています$T=1001$。 アルゴリズムはすべてを Apolyanka に割り当て、コストを生成します$1001$一方、ビュッデルスドルフが関与する分割では、単位当たりの費用が高くなるためコストが増加します。 

最後のケースは、すべてのリソースにおいて 1 つの村が常に悪い場合です。 アルゴリズムは当然その村を完全に無視し、システムを単一生産者モデルに崩壊させます。これは、独立した線形最小化から導出される最適なソリューション構造と一致します。
