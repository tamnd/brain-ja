 ## 解決策
 ## 問題の理解

 いくつかのセルがブロックされ、残りのセルが空いているグリッドが与えられています。 最初のプレイヤーが任意のフリー セルを選択し、そこに石を置くと、ゲームが開始されます。 その瞬間から、現在の石は常に隣接する空いている未訪問のセルに移動する必要があり、移動するたびにそのセルが永久に消費されます。 プレイヤーは交互に手を動かし、動けなかったプレイヤーが負けとなります。 

すべてのフリー セルについて、それが最初のプレーヤーにとって勝利のスタート選択であるかどうかを知りたいと考えています。つまり、ゲームがそこから開始され、両方のプレーヤーが最適にプレイした場合、最初のプレーヤーが勝利を強制できることを意味します。 

グリッドは十分に小さいため、各セルを検査し、それを中心に線形作業を行うソリューションは実行可能です。 と$N, M \le 50$、最大でも 2500 個のセルがあるため、アルゴリズムはおよそ$O((NM)^2)$境界線にあるものの可能性はありますが、訪問したサブセットを指数関数的に超えることは不可能です。 

このゲームの微妙な問題は、移動ルールは現在位置への隣接性のみに依存しますが、訪問履歴によりセルが永久に削除されることです。 これにより、「現在位置」だけでなく「どのセルがすでに消費されているか」も含めた状態空間が作成され、単純な再帰シミュレーションが即座に爆発します。 

よくある落とし穴は、ゲームが元のグリッドのローカル次数のみに依存すると仮定することです。 たとえば、2 つの隣接セルがあるセルは「良好」であると想定されることがよくありますが、1 つの隣接セルが行き止まりにつながり、もう 1 つの隣接セルが強制トラップにつながる可能性があるため、これは失敗します。 もう 1 つの間違いは、到達可能なセルのパリティのみが重要であると想定することです。これは分岐構造でも問題になります。 

## アプローチ

 ゲームの直接シミュレーションでは、すべての状態が現在のセルと訪問したセルのセットで構成されるペアとして扱われます。 各状態から、隣接する未訪問のセルをすべて試し、対戦相手が負けるかどうかを再帰的に判断します。 これは、状態空間サイズを持つグラフ上の標準的なミニマックス再帰です。$2^{NM}$、これは小さなグリッドであっても完全に実行不可能です。 

重要な観察は、原則として訪問されるセットは大きいにもかかわらず、ほとんどの場合、ゲームは実際にはグローバル構造の影響を受けないということです。 各移動は現在のセルを将来のプレイから削除するだけであり、セルを再訪問することはできないため、プレイは常に単純なパスをたどります。 したがって、結果は、開始セルが構造的に「行き止まり」であるか、接続された領域内で「拡張可能」であるかによって決まります。 

接続されたコンポーネントに分岐が含まれている場合、最初のプレーヤーはいつでもプレイを操作して即座のトラップを回避し、2 番目のプレーヤーを延長が存在しない位置に強制することができます。 本当に負ける状況は、すべての移動が 1 つのセルを消費し、利用可能な出口がすぐにゼロになるという事実を考慮した後、スタートが完全に孤立した場合にのみ発生します。 

これにより、問題は、空きセルごとに、少なくとも 1 つの隣接する空きセルがあるかどうかをチェックすることになります。 セルに空いている隣接セルがない場合は、移動できないため、最初のプレーヤーがすぐに負けます。 少なくとも 1 つあれば、最初のプレイヤーはいつでも行動を起こすことができ、対戦相手も同じ構造に直面することになり、最適なプレイでの勝利の継続が保証されます。 

これにより、非常に単純な削減が行われます。つまり、少なくとも 1 つの隣接する空きセルを持つすべての空きセルをカウントします。

 ## アルゴリズムのチュートリアル

 各セルを個別に処理し、それが有効な開始位置であるかどうかを判断します。 

1. グリッドをスキャンし、ブロックされていないすべてのセルを収集します。 これらは潜在的な出発点です。 
2. 各空きセルについて、グリッド内の 4 つの隣接セルを検査します。 唯一の関連情報は、少なくとも 1 つの近隣が空いているかどうかです。 
3. セルに空き隣接セルがない場合は、配置直後は移動できないため、開始プレイヤーの負けとしてマークします。 
4. それ以外の場合は、最初の手が常に存在し、その時点から相手は構造的に同等かそれよりも悪い状況に追い込まれるため、それを勝ちとしてマークします。 
5. すべての勝利セルをカウントし、結果を出力します。 

### なぜ効果があるのか

 ゲームは常に、セルを消費する単一の移動トークンとして進化します。 開始セルに利用可能な手がない場合、ゲームは即座に終了し、最初のプレイヤーが負けます。 利用可能な動きが少なくとも 1 つある場合、すべての動きによって問題は対戦相手の観点から同じローカル構造に帰着し、現在のエンドポイントでの隣接関係の可用性を超えて追加のグローバル アドバンテージが作成または破壊されることはありません。 これにより、即時の機動性が初期位置の唯一の決定要因となります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]
    
    ans = 0
    dirs = [(1,0), (-1,0), (0,1), (0,-1)]
    
    for i in range(n):
        for j in range(m):
            if grid[i][j] == '#':
                continue
            
            ok = False
            for di, dj in dirs:
                ni, nj = i + di, j + dj
                if 0 <= ni < n and 0 <= nj < m:
                    if grid[ni][nj] == '.':
                        ok = True
                        break
            
            if ok:
                ans += 1
    
    print(ans)

if __name__ == "__main__":
    solve()
```コードはグリッドを読み取り、空の各セルを個別にチェックします。 各セルについて、その 4 つの隣接セルをスキャンし、いずれかの隣接セルも空である場合はフラグを設定します。 このフラグは、セルがカウントされるかどうかを直接決定します。 

すべての近傍検索ではグリッド内に留まることを確認する必要があるため、重要な実装の詳細は境界チェックだけです。 このロジックでは、隣接関係が対角線ではなく直交していると想定しているため、4 方向のみが考慮されます。

 ## 特殊なケース

 壁に囲まれた 1 つのフリー セルは、最も直接的に負けるポジションです。 隣接する空きネイバーがないため、アルゴリズムはそれを非勝利として正しくカウントします。 

1×M グリッドのような長いコリドーでは、エンドポイントは内部セルとは異なる動作をします。 エンドポイントにはちょうど 1 つの隣接セルがあり、隣接ルールの下でエンドポイントを勝利させるのに十分ですが、内部セルも引き続き勝利するため、すべての空きセルがカウントされます。 

ブロックされたセルがグリッドを複数のコンポーネントに分割すると、各コンポーネントは独立して処理され、他のコンポーネントから干渉されることなく、同じ隣接ルールがローカルに適用されます。
