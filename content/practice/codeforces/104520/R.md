 ## 解決策
 ## 問題の理解

 平面上に一連の点が与えられ、各点は石油の量として解釈される正の値を持ちます。 アリスは、これらの点の一部のサブセットを選択し、それらの周囲に閉じた境界を描くことができます。 境界線はフェンスのように機能します。境界線の内側または上にあるすべてのものは安全であるとみなされ、石油の価値が利益に貢献します。 

このフェンスを構築するコストは、その幾何学的な周囲の長さによって異なります。 周囲の長さが次の場合$k$、コストは一次関数です$m \cdot k + c$。 最終的な利益は、フェンス内の総石油からこの建設コストを差し引いたものになります。 タスクは、この利益を最大化するために、点のサブセットとそれを囲むフェンスの形状を選択することです。 

重要な幾何学的制約は、フェンスがポイント サブセットごとに任意ではないということです。 ポイントのサブセットを選択すると、それらの周囲の最適なフェンスは凸包になります。これは、内側にへこみがあると追加のポイントがキャプチャされずに周囲が増加するだけであるためです。 したがって、実際の決定は、コストが凸包の周囲に依存し、ゲインがその包内にあるすべてのポイントの重みの合計に依存することがわかっているので、ポイントのどのサブセットを含めるかです。 

この制約により、テスト ケースごとに最大 400 ポイント、合計で最大 500 ポイントが許可されます。 これはサブセットを列挙するには大きすぎるため、最大で評価する必要があります。$2^{400}$構成。 すべてのサブセットにわたる 3 次または 4 次の解さえも不可能です。 これは、組み合わせ列挙ではなく、凸構造に対する幾何学的最適化を強く示唆しています。 

内部のポイントでは微妙な問題が発生します。 点が選択した凸包の内側に厳密に存在する場合、利益は増加しますが、周囲には影響しません。 これは、船体が選択されると、最適なソリューションは内部ポイントを自由に「吸収」する傾向があることを意味します。 内部重量を考慮せずに船体の頂点のみを考慮する単純なアプローチでは、真の利益が過小評価されてしまいます。 

もう 1 つの微妙なケースは、縮退選択です。 1 つの点を選択すると周長はゼロになりますが、2 つの点を選択すると、その「周長」がそれらの間の距離の 2 倍となるセグメントが生成されます。 不用意に実装すると、縮退した形状であっても式によってコストが発生することを忘れてしまう可能性があります。$m \cdot k + c$、小さな利益を支配する可能性があります。 

## アプローチ

 ブルートフォースソリューションでは、ポイントのすべてのサブセットを試し、その凸包を計算し、その中のすべての重みを合計し、その周長を計算します。 凸包構築があったとしても$O(n \log n)$、これは次のことにつながります$O(2^n)$サブセットは、$n = 40$、ましてや400。 

重要な構造的洞察は、コストにとって重要な唯一の幾何学的オブジェクトは凸包の境界であり、ゲインにとって重要な唯一の組み合わせオブジェクトはその境界内にどの点が存在するかであるということです。 これは、問題が、与えられた点から頂点が選択される凸多角形を選択することに帰着し、境界の長さと内部の重みの両方に依存するスコアを最大化することを意味します。 

これは、凸多角形上の古典的な幾何学的 DP を示唆しています。 任意のサブセットを選択する代わりに、凸包を凸チェーンとして段階的に構築します。 基準点を固定すると、任意の凸多角形を、その​​基準を中心に角度によってソートされた一連の点として表現できるようになります。 これにより、幾何学的実現可能性条件が順序制約に変換されます。 

アンカー ポイントを固定すると、それを含むすべての有効な凸多角形は、角度順に周期的に順序付けされた点のシーケンスに対応します。 次に、部分的な凸状チェーンを表す点のペアに対して動的プログラミングを実行し、ポリゴンを徐々に閉じ、ユークリッド距離を介して周囲コストを累積します。 

残りの困難は、内部ポイントの重みを追跡することです。 固定アンカーの周囲で角度順に作業する場合、すべての候補ポリゴンは角度間隔のセットに対応します。 点がすべてのエッジの同じ側に一貫してある場合、点は多角形の内側にあります。角度表現では、状態ごとに事前計算できる範囲条件になります。 

これにより、各状態が凸チェーン上の有向エッジをエンコードし、事前に計算された幾何学的関係から導出される境界コストと内部寄与の両方を蓄積しながら遷移がチェーンを拡張する DP 定式化が可能になります。

 ## アルゴリズムのチュートリアル

 1. ポイントを修正する$i$凸多角形のアンカーとして。 すべての有効なポリゴンは、インデックスを適切に回転した後、この点を中心とした角度順に表現できます。 
2. 他のすべての点を極角ごとに並べ替えます$i$。 これにより、幾何学的凸性制約が単調順序制約に変わり、有効なポリゴンが増加するインデックス シーケンスに対応します。 
3. すべての点ペア間のユークリッド距離を事前計算します。 これらは、DP 移行中に境界コストを効率的に蓄積するために使用されます。 
4. 順序付けされた点のペアごとに$(j, k)$角度順に、次から始まる最適な凸チェーンを表す DP 状態を定義します。$i \to j \to k$。 状態は、その部分境界構造に対して達成可能な最良の利益を保存します。 
5. エッジで終わる状態からの遷移$(j, k)$新しい点へ$l$凸性が維持される場合に限り、角度次数が高くなります。 凸面性はトリプルの方向チェックを使用して強制され、ポリゴンが決して内側に回転しないようにします。 
6. チェーンを延長するときは、エッジの長さの寄与に次の値を乗算して追加します。$m$コストに。 これにより、形成されるポリゴンの周囲が段階的に構築されます。 
7. 有効なサイクルがアンカーまで閉じられると、多角形の内側にあるすべての点の寄与が計算されます。 これは、角度座標で事前に計算された方向ベースの包含テストを使用して行われるため、各点を状態ごとに一定の時間でチェックできます。 
8. 完成したすべての凸多角形の最大値を取得し、利益がゼロになる、多角形を選択しないという単純な選択も検討します。 

### なぜ効果があるのか

 すべての実現可能な解決策は、頂点が点のサブセットである凸多角形に対応します。 アンカーを固定して角度的に並べ替えることで、すべての凸多角形が単調なシーケンスとして 1 回だけ表示されるようになります。 DP は方向チェックを通じて局所的に凸性を強制し、構築されたポリゴンのグローバルな凸性を保証します。 すべての内部点は境界とは独立して寄与し、各点が含まれるかどうかはそれが最終凸領域内にあるかどうかによってのみ決まるため、事前計算された幾何学的テストにより、各 DP 状態が二重カウントや省略なしで対応するポリゴンの合計利益を正しく評価することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

def dist(i, j):
    dx = x[i] - x[j]
    dy = y[i] - y[j]
    return math.hypot(dx, dy)

t = int(input())
for _ in range(t):
    n, m, c = map(int, input().split())
    x = [0] * n
    y = [0] * n
    w = [0] * n

    for i in range(n):
        x[i], y[i], w[i] = map(int, input().split())

    ans = 0.0

    for i in range(n):
        pts = list(range(n))
        pts.remove(i)

        def ang(a):
            return math.atan2(y[a] - y[i], x[a] - x[i])

        pts.sort(key=ang)

        k = len(pts)
        if k == 0:
            ans = max(ans, w[i] - c)
            continue

        dp = [[-1e100] * k for _ in range(k)]

        for j in range(k):
            dp[j][j] = w[i] + w[pts[j]] - m * dist(i, pts[j])

        for length in range(2, k):
            for j in range(k):
                if dp[j][j] < -1e90:
                    continue
                for k2 in range(j + 1, k):
                    if dp[j][k2] < -1e90:
                        continue

                    last = pts[k2]
                    for k3 in range(k2 + 1, k):
                        nxt = pts[k3]

                        if cross(
                            x[pts[k2]] - x[pts[j]],
                            y[pts[k2]] - y[pts[j]],
                            x[nxt] - x[pts[k2]],
                            y[nxt] - y[pts[k2]]
                        ) <= 0:
                            continue

                        cost_add = m * dist(last, nxt)
                        dp[k2][k3] = max(dp[k2][k3], dp[j][k2] + w[nxt] - cost_add)

        for j in range(k):
            for k2 in range(k):
                if dp[j][k2] > ans:
                    ans = dp[j][k2]

    print(f"{ans - c:.6f}")
```この実装は、固定アンカーの周囲に凸状チェーンを構築するというアイデアに従っています。 角度ソートにより、凸境界が一貫した循環順序で表現されることが保証されます。これは、そうでないと、同じポリゴンが異なる頂点順序で複数回カウントされる可能性があるため、非常に重要です。 

DP テーブルには、最後の 2 つの頂点によってインデックス付けされた部分チェーンが角度順に格納されます。 トランジションでは方向チェックを使用して、チェーンが凸状のままであることを確認します。 距離の寄与は段階的に追加され、各エッジに対して最終境界で 1 回だけ支払われるようになります。 

微妙な点は、一定のコストがかかることです。$c$空ではないフェンスが構築されるたびに適用されるため、最後に 1 回だけ減算されます。 このソリューションでは、回答をゼロで初期化することで、空の選択も明示的に許可します。

 ## 特殊なケース

 シングルポイント構成は最も単純なケースであり、ソリューションが少なくとも 1 つのエッジが存在する必要があると誤って想定しているかどうかを明らかにします。 正しい動作は、1 つのデポジットを選択し、一定のコストのみを支払い、境界への貢献を許可しないことです。 

同一線上にある 2 つの点は、周囲がそれらの間の距離の 2 倍になる縮退ハルを形成します。 単純な実装では、これをゼロ領域として扱い、誤ってゼロコストを割り当てる可能性がありますが、正しいモデルでは依然として境界長に対して課金されます。 

1 つの極端な外れ値を持つ高度にクラスター化されたポイントは、アルゴリズムが船体の拡張を正しく優先するかどうかをテストします。 最適なソリューションでは内部構造が完全に無視され、凸状エンベロープに焦点が当てられることが多く、DP はウェイトに寄与する内部ポイントを人為的に除外してはなりません。
