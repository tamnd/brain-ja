 ## 解決策
 ## 問題の理解

 パズルのピースのコレクションが与えられ、各ピースは固定長と 2 つのラベル付き端点を持つ剛体セグメントのように動作します。 各エンドポイントは、平坦、凸面、または凹面の 3 つのタイプのいずれかです。 駒を反転することはできないので、左右は固定されます。 

有効なアセンブリとは、長さの合計が目標の長さに正確に一致する個別のピースのシーケンスです。`l`。 2 つの隣接するピースを配置する場合、それらの接触する端点は互換性のある方法で一致する必要があります。凸面は凹面とのみ接続し、凹面は凸面とのみ接続し、平坦面は最終構造の外側の境界以外には接続できません。 最終的に組み立てられたセグメントは、平らな側面で始まり、平らな側面で終わる必要があります。 

課題は、ピースを配置するさまざまな方法を数えることではなく、選択されたピースの少なくとも 1 つの有効な線形配置が全長のセグメントを形成するように、ピースのサブセットがいくつ選択できるかを数えることです。`l`平らな端を持つ。 

主な困難は、サブセットが複数の内部配置を許容できるにもかかわらず、それらがすべて 1 つのカウントに崩壊するという事実から生じます。 これは、順列カウントではなくサブセット動的計画法の観点から考える必要があることを直ちに示唆しています。 

制約`n ≤ 300`そして`l ≤ 300`サブセットに対する二次または三次動的計画法ソリューションが必要であることを強くお勧めします。 すべてのサブセットにわたる指数列挙。これはおおよそ次のとおりです。`2^300`、無理です。 平`2^20`スタイルのブルート フォースは部分問題に対してのみ実行可能です。 ソリューションでは、明示的に順列を列挙せずにサブセットが処理されるように構造を圧縮する必要があります。 

微妙なエッジ ケースとして、無効な中間接続がサブセット内に存在する可能性がありますが、少なくとも 1 つの有効な順序付けが機能する場合、サブセットはカウントされるはずです。 たとえば、サブセットには、境界に互換性がないため、ある順序で完全に連鎖できない部分が含まれている場合がありますが、別の順序は引き続き機能する可能性があります。 単純な順序付けベースの DP では、そのようなサブセットが誤って破棄されてしまいます。 

もう 1 つの重要な例外ケースは、単一ピースのサブセットです。 一枚の長さ`l`両端が平らな場合にのみ有効です。 どちらかの側が平らでない場合は、長さが正確に一致していても、単独で有効な完全なセグメントを形成することはできません。 

## アプローチ

 ブルートフォースアプローチでは、部分のすべてのサブセットが列挙されます。 サブセットごとに、ピースを全長の有効なチェーンに配置できるかどうかを確認しようとします。`l`。 順列を無視してバックトラッキングを使用しようとしても、各サブセットでは最大 300 要素にわたる制約付きパス構築問題を解決する必要があります。 これはおおよそ次のことにつながります`O(2^n * n!)`最悪の解釈での行動ですが、これはまったく実行不可能です。 

重要な観察は、内部順序付けはエンドポイントの一致方法のみに依存し、状態遷移を超えたアイデンティティには依存しないということです。 サブセットを修正する場合、問題は、長さの累積を考慮しながら、平坦な左境界で始まり平坦な右境界で終わり、選択された各部分を 1 回だけ使用するパスを形成できるかどうかになります。 

これは構造的に、現在のエンドポイント タイプと累積長さをエンコードする状態のサブセット DP です。 重要な単純化は、順列を追跡する必要がないことです。 代わりに、各サブセットを階層化された DP 内の遷移に寄与するものとして扱います。この状態は、チェーンを構築した距離とオープン エンドポイントのタイプによって決まります。 

段階的に構築することでサブセット全体の DP を暗黙的に定義できます。サブセットの状態ごとに、特定の開いた境界タイプで特定の長さの構成に到達できるかどうかを維持します。 以来`l ≤ 300`、長さの寸法は小さく、境界タイプは一定のサイズです。 難しいのは、サブセットの一意性が確実に尊重されるようにすることです。各順序ではなく、各サブセットを 1 回カウントする必要があります。 

これは、配置を数える代わりに、有効なパスに配置できる部分集合を数えるという古典的なアイデアにつながります。 これは、ノードが境界タイプであり、エッジが長さと等しい重みを持つ部分である有向マルチグラフにおいて、サブセットが有効なオイラー状パスを許可するかどうかをチェックすることと同等です。 ただし、長さが重要であるため、エンドポイント制約のあるサブセット合計に対して DP を使用します。 

最終的には、長さとエンドポイントのタイプを組み合わせたサブセット上のビットマスク DP になります。 トランジションは、互換性がある場合、現在のチェーンのどちらかの端にピースを追加することに対応します。 これにより、各サブセットが最初に有効な終了状態に達したときに一度だけマークされるため、有効なチェーンのみを構築し、順列を過剰にカウントしないことが保証されます。

 実際には、遷移が完全な順序付けではなくエンドポイントのみに依存することを利用して、長さおよびサブセット層ごとの境界状態にわたる多項式 DP への削減を可能にします。 

## アルゴリズムのチュートリアル

 私たちは各ピースを、チェーン内に配置できる方向性のある要素として解釈します。 各ピースには左コネクタと右コネクタがあり、固定長に寄与します。 

コネクタのタイプを平坦、凸面、凹面の 3 つの状態に分類します。 互換性ルールは凸面と凹面で対称ですが、平坦は端にのみ表示されます。 

次に、サブセットが特定の状態と全長で終わる有効な部分チェーンを形成できるかどうかを追跡する、サブセットに対する DP を定義します。 

## アルゴリズムのチュートリアル

 1. コネクタのタイプを整数に変換します (例: flat = 0、convex = 1、concave = 2)。また、1 と 2 の一致を許可するが、境界以外の値との 0 の一致を許可しない互換性関数も定義します。 
2. DP テーブルを定義します。`dp[mask][len][state]`サブセットを配置できるかどうかを示します`mask`全長の有効な部分チェーンに変換する`len`開いた境界タイプで終わる`state`。 この状態は、現在のチェーンの右端にある露出されたコネクタを表します。 
3. 単一のピースを配置して DP を初期化します。 一枚の長さ`a[i]`両端が平坦な場合にのみ有効です。 その場合に設定するのは、`dp[1<<i][a[i]][flat] = true`。 これは完全に閉じた有効なチェーンを表します。 
4. サイズの昇順にサブセット マスクごとに、到達可能な長さと状態ごとに、新しい部分を追加してチェーンの拡張を試みます。`i`マスクの中ではありません。 
5. ピースを追加するときは、両端の挿入を試みます。 右側に追加する場合、現在の開いた状態がピースの左側のコネクタと一致する必要があります。 新しい状態は、ピースの右側のコネクタになります。 長さは次のように増加します`a[i]`。 
6. 同様に、左側に追加する場合は、ピースの右側のコネクタと現在の状態との互換性をチェックし、状態をピースの左側のコネクタに更新します。 
7. 長さが等しい状態に達したときはいつでも`l`開いた境界が両端で平らであり、構築を通じて暗黙的に満たされている場合、サブセットを有効としてマークします。 
8. 最後に、少なくとも 1 つの DP 状態が含まれるすべてのサブセットをカウントします。`l`有効なクロージャが存在します。 

正確さは、すべての有効なアセンブリが単一の部分から始まる一連の有効な拡張機能に対応し、すべての DP 遷移が境界互換性を維持するという事実にかかっています。 サブセットをマークするのは 1 回だけであるため、複数の内部順列によって過剰カウントが発生することはありません。 

### なぜ効果があるのか

 DP は、到達可能なすべての状態が、選択された部分セットを正確に使用して物理的に構築可能なチェーンに対応するという不変条件を維持します。 各遷移は、エンドポイントの互換性を維持する方法で、既存の有効なチェーンに 1 つの新しい部分を接続することに対応します。 すべての有効な完全なアセンブリには最後に追加された部分が少なくとも 1 つあるため、それを一連の DP トランジションに反転できます。 これにより完全性が保証されます。 すべての遷移でローカル互換性ルールが適用されるため、健全性が維持されます。そのため、無効な隣接関係が到達可能な状態に現れることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def typ(x):
    if x == "none":
        return 0
    if x == "out":
        return 1
    return 2  # in

def ok(a, b):
    if a == 0 or b == 0:
        return False
    return a != b  # in/out compatible

def solve():
    n, L = map(int, input().split())
    pieces = []
    for _ in range(n):
        a, b, c = input().split()
        pieces.append((int(a), typ(b), typ(c)))
    
    # dp[mask][length][left_end][right_end]
    # endpoints are 0 flat, 1 out, 2 in
    dp = {}
    
    for i, (a, lft, rgt) in enumerate(pieces):
        mask = 1 << i
        if a <= L:
            dp[(mask, a, lft, rgt)] = 1
    
    for mask_size in range(1, n + 1):
        # iterate over snapshot keys
        keys = list(dp.keys())
        for (mask, length, lft, rgt) in keys:
            if bin(mask).count("1") != mask_size:
                continue
            if length > L:
                continue
            for i, (a, l2, r2) in enumerate(pieces):
                if mask & (1 << i):
                    continue
                
                # append right
                if ok(rgt, l2) and length + a <= L:
                    new_mask = mask | (1 << i)
                    key = (new_mask, length + a, lft, r2)
                    dp[key] = 1
                
                # prepend left
                if ok(r2, lft) and length + a <= L:
                    new_mask = mask | (1 << i)
                    key = (new_mask, length + a, l2, rgt)
                    dp[key] = 1
    
    good = set()
    for (mask, length, lft, rgt) in dp:
        if length == L and lft == 0 and rgt == 0:
            good.add(mask)
    
    print(len(good) % MOD)

if __name__ == "__main__":
    solve()
```このコードは、状態を積極的に圧縮するのではなく、フル チェーン エンドポイントを明示的に追跡するため、ロジックが概念的な DP に合わせて維持されます。 ビットマスクにより、最終的な回答セット内でサブセットが 1 回だけ追跡されることが保証されます。 

互換性関数は凸凹ルールを適用しますが、平坦なエンドポイントは終端でのみ暗黙的に許可されます。 最後のフィルタリング ステップでは、正確に必要な長さの完全に閉じたチェーンを形成するサブセットのみをカウントするようにします。

 ## 特殊なケース

 長さが正確に一致する単一のピース`l`両端が平坦な場合のみ有効です。 その場合、DP は状態を初期化します。`(mask, l, flat, flat)`すぐに実行され、遷移なしで最終カウントに含まれます。 

合計すると次のようなサブセット`l`ただし、有効なチェーンに順序付けることはできず、両方のエンドポイントがフラットな状態に到達することはありません。 DP はエンドポイントを人為的に閉じることはありません。 フラット エンドポイントは、有効なチェーンの入力構成に存在する場合にのみ表示されます。 

DP は左と右の両方の挿入を調査するため、特定の順序でのみ有効なチェーンでも正しくカウントされます。 有効な順序付けには最後に追加された部分があり、その構築を逆にすると有効な DP パスが得られるため、サブセットが DP 状態空間に現れることが保証されます。
