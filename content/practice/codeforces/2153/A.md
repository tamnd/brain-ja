 ## 解決策
 ## 問題の理解

 私たちには、リンゴの木の輪が与えられ、それぞれのリンゴが、関連する美しさの価値を持つ 1 つのリンゴを実らせます。 1 番目の木から始めて、円の周りを繰り返し歩きます。 それぞれの木で、リンゴを食べるかスキップするかを選択できます。 制約は、リンゴの美しさが最後に食べたリンゴの美しさを厳密に上回る場合にのみ、リンゴを食べることができるということです。 目標は、食べられるリンゴの総数を最大化することです。 

入力では複数のテスト ケースを指定します。 各テスト ケースのツリーの数$n$美の価値のリストとともに与えられます$b_1, b_2, \dots, b_n$。 出力はテスト ケースごとに 1 つの整数、つまりルールに従って食べられるリンゴの最大数です。 

制約は中程度です。$n \le 100$そして$t \le 500$。 これは、$O(n \log n)$あるいは$O(n^2)$テスト ケースごとのソリューションは快適に実行されます。 単純な並べ替えや線形スキャンを超えて、漸近的に最適なアプローチを強制する膨大な入力についての心配はありません。 

すべてのリンゴが同じ美しさを持っている場合、または美しさの順序が厳密に減少している場合、エッジケースが発生します。 たとえば、次の場合$b = [2,2,2,2]$、リンゴは1個しか食べられません。 もし$b = [5,4,3,2,1]$、どの木から始めても、サイクルごとに食べられるリンゴは 1 つだけです。 これらのケースは、単純な「最後に食べたものより大きい場合に食べる」シミュレーションでは扱いが難しくなります。最適な戦略には、最初のリンゴを完全にスキップして、後で小さなリンゴを許可することが含まれる可能性があるためです。 

## アプローチ

 ブルートフォースアプローチは、考えられるすべての開始点と、スキップと食事のすべての考えられるシーケンスをシミュレートすることです。 サイクルごとに、最後に食べたリンゴを追跡し、現在のリンゴを食べるかスキップするかのすべての組み合わせを試します。 これは問題のルールを尊重しているため機能しますが、指数関数的です。$n$そして実行不可能になります$n$たとえ20個という小さいものであっても。 

重要な洞察は、「美しさは厳密に増加していなければならない」という制約は、相対的な大きさを除いて、リンゴを食べる順序は無関係であることを意味するということです。 これにより、問題は、循環順序を尊重しながら選択できる個別の美しさの最大数を数えることに減ります。 美しいものを並べ替えて昇順に摘むと、選択されたそれぞれのリンゴが前のリンゴよりも大きいことが保証され、周期的な性質は最初に摘んだリンゴにのみ影響します。 リンゴを最大限に食べるために、私たちは常に最も小さな美しいものから始めて、最後に食べたものよりも大きい、利用可能な次に小さな美しいものを貪欲に食べることができます。 

円は任意に回転できるため、食べられるリンゴの数は個別の美しさの値の数によって決まり、サイクル内に現れる繰り返しの値を考慮する必要があります。 したがって、最大値は$n$すべての美しさがユニークで、厳密に昇順で食べることができるように配置されている場合、重複がある場合は小さくなります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 選別された美しさによる貪欲 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 テスト ケースごとに、次の内容を読んでください。$n$そして美人のリスト$b$。 
2. 美人リストを並べ替えます。 選別により、最後に食べたリンゴより厳密に大きい次のリンゴを簡単に選ぶことができます。 
3. カウンタをゼロに初期化し、変数を初期化します。`last_eaten`どのリンゴの美しさよりも小さい値 (たとえば、0) に設定します。 
4. ソートされた美しさのリストを繰り返し処理します。 それぞれの美しさについて、それが厳密に次の値より大きい場合、`last_eaten`、カウンターをインクリメントして更新します`last_eaten`。 
5. すべての美しいものを繰り返した後、カウンターには食べられるリンゴの最大数が表示されます。 この値を出力します。 

機能する理由: 最後に食べたリンゴより厳密に大きい、入手可能な最小のリンゴを常に選ぶことで、食べるリンゴの数を最大化することが保証されます。 ソートされたリストにより、各ピックが有効であることが保証され、カウンターが合計数を取得します。 円の周囲の相対的な順序は任意にスキップできるため、周期的な性質によってこの貪欲な選択が制限されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_apples(n, beauties):
    beauties.sort()
    count = 0
    last_eaten = 0
    for b in beauties:
        if b > last_eaten:
            count += 1
            last_eaten = b
    return count

t = int(input())
for _ in range(t):
    n = int(input())
    beauties = list(map(int, input().split()))
    print(max_apples(n, beauties))
```このソリューションは、各テスト ケースを読み取り、美しいものを並べ替え、食べられるリンゴの数を貪欲に数えます。 厳密な昇順を保証するには、並べ替えが重要です。 シンプルなカウンターと、最後に食べた美しさの追跡変数を使用します。 このロジックは、厳密に前のリンゴよりも大きくないリンゴをスキップすることにより、重複を正しく処理します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n = int(input())
        beauties = list(map(int, input().split()))
        beauties.sort()
        count = 0
        last_eaten = 0
        for b in beauties:
            if b > last_eaten:
                count += 1
                last_eaten = b
        output.append(str(count))
    return "\n".join(output)

 ## 特殊なケース

 一本の木の場合$n=1$美しさ 1 では、アルゴリズムはリンゴ 1 個を正確に数えます。 すべてのリンゴが同じ美しさを持っているとき、たとえば$b = [3,3,3]$、最初のリンゴのみがカウントされます。 後続のリンゴは厳密には大きくないため無視されます。 重複のあるシーケンスの場合、アルゴリズムは厳密に大きな美しさが表示されるまで繰り返される値をスキップし、食べられる合計が正しく最大化されます。 貪欲にソートされた選択により最適な消費順序がすでに保証されているため、循環順序付けはカウントに影響しません。
