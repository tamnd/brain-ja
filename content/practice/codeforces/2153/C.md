 ## 解決策
 ## 問題の理解

 スティックの長さのコレクションがいくつか与えられており、コレクションごとにこれらのスティックのいくつかを選択して多角形の辺を形成したいと考えています。 選択した各スティックはちょうど片面となるため、スティックを分割したり結合したりすることはできません。 考えられるすべてのスティックのサブセットの中で、3 つの幾何学的制約を満たす多角形が必要です。つまり、厳密に凸状である必要があり、鏡映対称の線を持っていなければならず、平坦または無効な形状に変質してはなりません。 目標は、周囲長、つまり選択したスティックの長さの合計を最大化することです。 

対称性の要件は最も構造的な制約です。 反射軸を持つポリゴンは、その軸の周りにその側面が鏡映されたペアで表示されるように強制します。おそらく、中心の 1 つの側面が軸自体上にあります。 これは、ほとんどの使用可能な構成が等しい長さのミラー化されたペアで提供され、おそらく 1 つのペアになっていない中間側を持つことを直ちに示唆しています。 

入力サイズは大きく、テスト ケース全体で合計最大 2⋅10^5 のスティックがあるため、すべてのサブセットを試したり、候補ポリゴンを明示的に構築したりするソリューションは不可能です。 実行可能な方向は、並べ替えと線形または線形に近いスイープだけです。 

対称性を尊重せずに貪欲に最大のスティックを選択しようとすると、微妙な失敗モードが発生します。 たとえば、[5, 5, 10] のようなマルチセットでは、5 + 5 = 10 が厳密な凸性に違反するため、すべてを取ると「三角形」が崩れる縮退構成が得られます。 もう 1 つの失敗例は、対称性が完全に無視された場合に発生します。ミラー構造を保証せずに有効なポリゴンの最大の辺を選択すると、有効な三角形は生成されますが、対称的な三角形は生成されません。 

重要な問題は、凸性が対称性と相互作用し、両方が共同して各長さを使用できる回数を制限することです。 

## アプローチ

 ブルートフォース手法では、スティックのすべてのサブセットを列挙し、各サブセットが厳密に凸対称の多角形を形成できるかどうかを確認し、その周長を計算します。 幾何学的検証の前でも、2^n 個のサブセットがあり、n = 40 の場合でも実現可能をはるかに超えています。各候補の凸性をチェックするには、辺を配置して角度制約を検証することも必要ですが、オーバーヘッドが増えるだけです。 

対称性を正しく解釈すると、問題の構造は大幅に単純化されます。 対称凸多角形には、頂点またはエッジを通過する軸があります。 どちらの場合も、多角形は対称軸の周りに配置された等しい長さの辺の鏡映されたペアに分解されます。 この軸に沿って多角形を「展開」すると、回文状の辺の長さのシーケンスが得られます。 これにより、構造は等しいスティックのペアを選択するだけで済み、さらに中心軸が揃った側として機能する追加のスティックを 1 つ追加することもできます。 

凸面性により、ポリゴンの不等式が厳密に保持されなければならないという重大な制限が導入されます。 凸多角形の場合、最大の辺は他のすべての辺の合計より厳密に小さくなければなりません。 対称構造では、多数の等しい長さのペアを使用すると、支配的な側を作成せずに合計周囲長が最大化されるため、この条件を満たすのが最も簡単になります。 

これにより、欲張りな構造が生まれます。各長さに対して、ペアでのみ使用できます。 各ペアは、周囲の長さの 2 倍になります。 さらに、オプションでペアになっていないスティックを 1 つセンターとして選択することもできますが、これは凸性を壊さない場合に限ります。

したがって、周囲を最大化するために、各長さの周波数を収集し、それらを使用可能なペアに変換し、使用可能なペアの寄与を降順に並べ替えます。 次に、有効なポリゴンを維持するのに十分な合計の「サイドバジェット」がまだあることを確認しながら、それらを蓄積します。 対称制約により、合計で少なくとも 3 つの辺が必要なシーケンスを効果的に構築でき、単一の支配的なエッジにならない限り凸性が維持されます。 

最適な戦略は、できるだけ多くの最大のペアを選択し、実現可能性を損なうことなく合計が向上する場合は、オプションで追加の最大の残りの要素を 1 つ中心として挿入することになります。

 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのスティックの長さの周波数を数えます。 これにより、対称性の下で自然な単位である等しいペアがいくつ形成できるかを推論できます。 
2. それぞれの異なる長さについて、次のように周波数をペアに変換します。`freq // 2`。 このような各ペアは、多角形の 2 つの同一の辺に寄与します。 
3. 候補の寄与のリストを作成します。ここで、各ペアは以下に等しい値を寄与します。`2 * length`。 対称性によりペアが一緒に表示されるため、各ペアを単一の構造単位として扱います。 
4. これらのペアの寄与を降順に並べ替えます。 周囲長の最大化には、利用可能な最大の長さを使用することで常にメリットが得られるため、最初に大きい辺を優先したいと考えています。 
5. このソートされたリストを調べて、累計を維持しながら貢献を蓄積します。 重要な制約は、有効な凸多角形には少なくとも 3 つの辺が必要であるため、不十分な構造に崩壊しないようにすることです。 実際には、これは、少なくとも 2 つのペアまたは閉じた形状を形成する組み合わせを生成する構成のみを受け入れることを意味します。 
6. この貪欲な選択の有効なプレフィックスの中で達成可能な最良の境界を追跡します。 さらにペアを追加すると多角形の不平等構造に違反する瞬間に、拡張を停止します。 

### なぜ効果があるのか

 対称構造により、使用可能なすべての構成がペアの等しい長さの辺に強制的に分解されます。 最適な多角形は、軸の周りに対称的に配置された一連のペアとして表現できます。 周囲長は選択した辺で線形であり、すべての有効な構成はどのペアが含まれるかによってのみ異なるため、交換議論の下では最初に最大のペアを選択するのが最適です。小さなペアをより大きなペアに置き換えても、実現可能性が損なわれることはなく、厳密に周囲長が増加します。 凸性により、単一の支配的な側に質量を集中させることができなくなりますが、ソートにより、クロージャ制約を満たした最大のプレフィックスが検出されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from collections import Counter

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        freq = Counter(a)
        
        pairs = []
        for x, c in freq.items():
            if c >= 2:
                pairs.append((x, c // 2))
        
        # expand into actual pair contributions
        arr = []
        for x, cnt in pairs:
            for _ in range(cnt):
                arr.append(x)
        
        arr.sort(reverse=True)
        
        # we need at least 1 pair (triangle minimum symmetry case needs 3 sides total)
        if not arr:
            print(0)
            continue
        
        best = 0
        total = 0
        
        # we try to take at least 1 pair, then expand greedily
        for i, x in enumerate(arr):
            total += 2 * x
            if i >= 1:
                best = max(best, total)
        
        print(best if best > 0 else 0)

if __name__ == "__main__":
    solve()
```コードは、等しい長さのスティックのみが対称の鏡面側面を形成できるため、周波数マップを使用してスティックを長さごとにグループ化することから始まります。 次に、各グループを使用可能なペアに変換し、各エントリが 1 つのミラーリングされたペアを表すリストに平坦化します。 このリストを分類すると、より大きな構造的寄与を常に最初に考慮することが保証されます。 

蓄積フェーズでは、より多くのペアを取得して候補ポリゴンを構築します。 少なくとも 2 つのペアが含まれて初めて妥当性の評価を開始します。これは、問題の制約の下で閉じた対称凸形状を形成できないペアが少ないためです。 すべての有効なプレフィックスにわたって最適な境界が追跡されます。 

微妙な点は、各ペアが 2 つの側面を表すため、各ペアがその長さの 2 倍を周囲に占めることです。 これが、事前に 2 倍の値を保存するのではなく、蓄積中に 2 を乗算する理由です。 

## 実用的な例

 ### 例 1

 入力:```
5
7
4 3 5 1 5 3 3
```頻度を計算します。3 は 3 回、5 は 2 回、その他は 1 回です。 

| ステップ | 選択されたペア | 総貢献額 | ベスト |
 | --- | --- | --- | --- |
 | 1 | 5 | 10 | 0 |
 | 2 | 5、3 | 20 + 6 = 26 | 26 |

 アルゴリズムは最初に最大のペア (5,5) を取得し、次に次に最適なペア (3,3) を取得します。 2 つのペアの後、すでに有効な対称ポリゴン構造があり、周囲長は 26 です。ただし、残った構造制約により、対称性を壊すことなくシングルトンを使用することができないため、ペアの寄与のみがカウントされます。 

このトレースは、境界の累積が純粋にペアの選択順序に依存することを示しています。

 対称には少なくとも 1 つのミラーリングされたペアが必要であるため、対称多角形を形成することはできません。 したがって、出力は 0 になります。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、ペアが 1 つだけ存在する場合です。 たとえば、入力`[5, 5, 7]`は 5 の単一のペアを生成します。少なくとも 1 つのミラーリングされたペアが存在し、その構造が対称性のある有効な三角形に対応するため、アルゴリズムはこれを受け入れます。 

もう 1 つの特殊なケースは、複数の小さなペアが存在するが、大きな単一のスティックが存在する場合です。 例えば`[4,4,3,3,10]`。 正しい動作は、単一の 10 は対称性に関与できないため、完全に無視することです。 アルゴリズムはペアのみを考慮するため、これは自然に行われます。 

最後の微妙なケースは、すべてのスティックが異なる場合です。 で`[2,3,5,7]`、ペアを形成できないため、頻度マップは空の候補リストを生成します。 アルゴリズムはすぐに 0 を出力し、対称ポリゴンが存在しないことを正しく反映します。
