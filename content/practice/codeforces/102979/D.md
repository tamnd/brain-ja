 ## 解決策
 ## 問題の理解

 まっすぐな水平軸上に配置されたパッドの行が与えられます。 各パッドは整数座標に位置し、各パッドには 1 から n までの番号がラベル付けされており、各ラベルは正確に 2 回表示されます。 タスクは、トラックと呼ばれる描画されたパスを使用して、各ラベルの 2 つの出現箇所を接続することです。 

各トラックはポリラインです。つまり、軸に沿ったセグメントで構成され、ラベルの 1 つの出現で始まり、もう 1 つの出現で終わります。 重要な制約は幾何学的なものです。2 つのトラックは、中間の頂点であっても、いかなる点でも接触したり交差したりすることはできません。 したがって、事実上、直線上に配置されたペアの点間に n 本の互いに素な「ワイヤ」を配線する必要がありますが、競合を避けるために 2D 空間に入ることが許可されています。 

入力サイズは、合計で最大 2000 のエンドポイントを意味します。 ペアの数が 2 次以上である解法は慎重に制御する必要がありますが、主な困難は計算の複雑さではなく、厳格な非接触制約の下で交差のない有効な埋め込みを構築することです。 

いくつかの微妙な失敗例が重要です。 1 つ目は、ラインの真上に描画すると強制的に交差するように 2 つのペアがネストされている場合です。 たとえば、ラベルが次のように表示される場合、`1 2 1 2`の場合、垂直方向のスペースで慎重に配線しない限り、1 と 2 を接続すると必ず交差します。 エンドポイントがライン上でインターリーブしない場合でも、トラックが中間空間で衝突する可能性があるため、単純な「貪欲に上向きのアークを描画する」アプローチは失敗します。 

もう 1 つの失敗例は、スペースを確保せずに各接続を独立して処理することです。 たとえば、次のようなパターンでは、`1 2 3 1 2 3`、各ペアを順番に貪欲にルーティングすると、グローバルな順序付け戦略が使用されない限り、必然的に 2 つのトラックが重複する領域を占有することになります。 

重要な構造的観察は、直線上の端点の配置により、括弧シーケンスまたは区間包含グラフと同じ入れ子構造または交差構造が誘発されることです。 これは、実現可能性が、ばらばらの垂直「チャネル」をインターバルに割り当てられるかどうかによって左右されることを意味します。つまり、スタックのような順序でペアを処理し、制御された階層構造でトラックを割り当てることになります。 

## アプローチ

 強引なアイデアは、各トラックを個別に構築し、以前に描画されたすべてのトラックとの交差点をチェックすることです。 概念的には、連続平面でのポリラインの描画をシミュレートし、セグメントの交差をテストできます。 ただし、各トラックには複数のセグメントを含めることができ、以前に配置されたすべてのセグメントと交差をチェックすると、実装に応じて最悪の場合は 2 次または 3 次の爆発が発生します。 最大 n = 1000 で、トラックごとに複数のセグメントが存在する可能性があるため、これはすぐに実行不可能になります。 

さらに深刻な問題は、実際の構造は組み合わせであるのに、ブルート フォースではジオメトリが主な困難として扱われることです。 エンドポイントはすべての制約をすでにエンコードしています。2 つのトラックをネストする必要があるか、または競合する可能性があるかどうかは、ライン上の位置にのみ依存します。 

重要な洞察は、任意のジオメトリの観点から考えるのをやめ、代わりに決定論的な配線スキームを課すことです。つまり、構造全体を、各ペアに固有の「高さのコリドー」が割り当てられる、制御されたグリッドのような埋め込みに引き上げます。 最初の出現に基づいて構造化された順序でペアを処理し、アクティブな間隔のスタックを維持する場合、重複しない垂直レイヤーを割り当てることができるため、ネストされたペアは常に異なる高さを占め、素のペアは水平方向に分離されます。 

これにより、問題は間隔の入れ子構造の維持と、各トラックが個別の垂直バンドを使用するルーティングの生成に変換されます。 バンドが正しく割り当てられたら、交差がないことを保証する固定テンプレート形状を使用して各トラックを描画できます。

 ## アルゴリズムのチュートリアル

1. 各ラベルの最初と 2 番目の出現位置を記録しながら、一連のラベルを左から右にスキャンします。 これにより、問題が直線上の一連の間隔に変換されます。 すべての幾何学的制約は間隔の関係のみに依存するため、この表現は非常に重要です。 
2. 現在開いている間隔のスタックを維持しながら、最初に出現したラベルの昇順にラベルを並べ替えまたは処理します。 ラベルが最初に出現すると、それをスタックにプッシュし、2 番目に出現すると、ポップします。 スタック構造はネストを反映しています。より深い要素は、他の要素の内部に完全に含まれる間隔に対応します。 
3. 各ラベルにスタック位置に基づいて深さを割り当てます。 深さによって、最終的な図面の垂直座標バンドが決まります。 これが機能する理由は、ネストされた間隔が同じ垂直コリドーを共有してはいけないためです。共有しないと、それらの接続パスが重複してしまいます。 
4. ラベルごとに、割り当てられた深さのみに依存する固定配線パターンを使用してポリラインを構築します。 このアイデアは、開始パッドから割り当てられたレイヤーに垂直に移動し、そのレイヤー内を水平に移動して、終点で垂直に戻ることです。 各レイヤーは y 座標空間で分離されているため、水平セグメントが衝突することはありません。 
5. より深い層のトラックが常に十分にオフセットされ、外側の層の端点に触れないように、水平移動の順序を確保します。 これは通常、深さに比例して増加する y 座標を割り当てることで処理されます。 
6. 各トラックをラベル順に出力し、インターバル構造が判明すると決定論的な構造を生成します。 

### なぜ効果があるのか

 正確さは、各アクティブな間隔がネストされたセグメントのスタック表現の一意の深さに対応するという不変条件に依存します。 時間的に重なり合っているがネストされていない 2 つの間隔は、交差パターンを暗示しますが、有効な埋め込みでは問題の制約によって禁止されています。 ネストの深さを垂直方向の分離に直接マッピングすることで、2 つのトラックが幾何学的領域を共有しないことが保証されます。垂直方向のセグメントは構築によって分離され、水平方向のセグメントは互いに素な y レベルにあります。 すべてのトラックは、エンドポイントを除き、割り当てられたレイヤーに限定されているため、交差は発生しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    arr = list(map(int, input().split()))

    pos = {}
    for i, x in enumerate(arr):
        if x not in pos:
            pos[x] = [i]
        else:
            pos[x].append(i)

    # build intervals
    intervals = []
    for x in range(1, n + 1):
        l, r = pos[x]
        if l > r:
            l, r = r, l
        intervals.append((l, r, x))

    intervals.sort()

    stack = []
    depth = {}
    active = []

    # sweep line with stack
    events = []
    for l, r, x in intervals:
        events.append((l, 1, x))
        events.append((r, -1, x))
    events.sort()

    for _, typ, x in events:
        if typ == 1:
            depth[x] = len(stack)
            stack.append(x)
        else:
            stack.pop()

    # simple routing: assign y by depth
    res = {}
    for x in range(1, n + 1):
        l, r = pos[x]
        if l > r:
            l, r = r, l
        y = depth[x]

        # fixed polyline: up, right, down template
        # scale y to avoid collisions
        Y = y * 2 + 1

        x1, x2 = l, r
        if x1 > x2:
            x1, x2 = x2, x1

        # build path
        # start at (x1, 0) -> (x1, Y) -> (x2, Y) -> (x2, 0)
        res[x] = ["3", f"U {Y}", f"R {x2 - x1}", f"D {Y}"]

    print("YES")
    for i in range(1, n + 1):
        print(" ".join(res[i]))

if __name__ == "__main__":
    solve()
```すべてのラベルは正確に 2 回出現するため、実装ではまずラベルを間隔エンドポイントに変換します。 ソートされたイベントをスイープすると、各間隔にネストの深さが割り当てられ、これによって垂直層が直接決まります。 

次に、構築ステップでは、トラックごとに均一な 3 セグメントのポリラインを使用します。 各トラックは垂直にそのレイヤーに進み、一致するエンドポイントまで水平に移動して、下に戻ります。 Y 座標間隔の乗算係数により、中間の頂点であっても異なるレイヤーが接触することがなくなります。 

実装の微妙な点は、深さの割り当てが、同じ位置でのイベントの任意の順序ではなく、真のネスト順序を反映していることを保証することです。 正確性を維持するには、イベントの並べ替えと「閉じる前に開く」一貫した処理が必要です。

 ## 特殊なケース

 次のような完全にネストされたケースの場合`1 2 3 1 2 3`の場合、アルゴリズムは深さ 0、1、2 を割り当てて、3 つの別々の垂直レイヤーを確保します。 スタックは最大ネストでサイズ 3 まで成長し、各トラックは独自のバンド内でルーティングされるため、接触が防止されます。 

For disjoint intervals like`1 1 2 2 3 3`、すべての深度が 0 になるため、すべてのトラックは同じ水平バンドを共有しますが、異なる X 範囲を占有し、水平セグメントは決して重なりません。
