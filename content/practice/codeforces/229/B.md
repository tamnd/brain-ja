 ## 解決策
 ## 問題の理解

 私たちには、スターゲートによって接続された惑星の無向重み付きグラフが与えられます。 ジャックは地球上で出発します`1`時に`0`そして惑星に到達したいと思っています`n`できるだけ早く。 

スターゲートを通過するには、一定の正の時間がかかります。 珍しいのは待機ルールです。 どの惑星にも一連のブロックされた瞬間があります。 もしジャックが当時惑星に立っていたとしたら`t`、 そして`t`彼はその惑星のブロックされたセットに属しているため、すぐに離れることは禁じられています。 初めてブロックされなくなるまで待たなければなりません。 

この制限は惑星から出発する場合にのみ適用されます。 ブロックされた瞬間に到着することは許可されます。 問題は惑星への最短到着時間を求めます`n`、 または`-1`ルートが存在しない場合。 

グラフには最大で`10^5`頂点と`10^5`エッジなので、おおよそよりも悪いアルゴリズムはありません`O((n + m) log n)`Pythonでは危険です。 ここでは、標準的な全ペア最短経路アルゴリズムは不可能です。 平`O(nm)`周りという意味でしょう`10^10`操作。 

すべての惑星のブロックされた時間の合計数も次の制限を受けます。`10^5`。 この詳細は、これらのリスト内を効率的に前処理または検索できることを意味するため、重要です。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

始まりの惑星で一つの微妙な事件が起こる。 ジャックは時間通りにスタートします`0`、しかし、惑星であれば`1`時間にブロックされています`0`、彼はすぐに離れることができません。 

例：```
2 1
1 2 5
1 0
0
```正しい答えは、`6`、 ない`5`, なぜなら、ジャックは出発する前に1秒待たなければならないからです。 

もう 1 つの注意が必要な状況は、連続してブロックされた場合です。```
2 1
1 2 3
3 0 1 2
0
```ジャックは時間通りにスタートします`0`、しかし、回`0`、`1`、 そして`2`地球上ですべてがブロックされています`1`。 彼は定時にしか出発できない`3`、したがって、答えは次のとおりです`6`。 

ブロックされた瞬間を 1 つだけチェックする不注意な実装では、誤って生成される可能性があります。`4`。 

切り離されたグラフも間違いの原因です。```
3 1
1 2 5
0
0
0
```惑星`3`は到達不可能なので、答えは次のようになります。`-1`。 

最後に、時間制限された時間に到着することは完全に合法です。 この制限は出発しようとする場合にのみ適用されます。```
2 1
1 2 3
0
1 3
```答えはまだです`3`。 ジャックが惑星に到着`2`ちょうど別の旅行者がそこに到着するときですが、旅は終わるのでそれは問題ではありません。 

## アプローチ

 ブルートフォースのアイデアは単純です。 すべての状態を次のように扱います`(planet, current_time)`。 状態から、1 秒待つか、現在の時間がブロックされていない場合はエッジを通過します。 

これが機能するのは、すべての遷移が明示的にモデル化されているためです。 問題は時間次元のサイズです。 エッジの重みははるかに多く蓄積される可能性があります`10^9`、すべての中間時間を探索することは不可能です。 

より洗練されたブルートフォース手法でもダイクストラのアルゴリズムが使用されますが、惑星に到達するたびに`t`、繰り返しインクリメントします`t`ブロックされたままです。 

毎秒グローバルにモデル化する必要がなくなったため、これはすでにはるかに改善されています。 残る課題は効率性だ。 ある惑星が時間をブロックしていると仮定します。```
0 1 2 3 4 ... 100000
```多くの最短経路緩和がこれらの値を 1 つずつ繰り返しスキャンすると、全体の複雑さは 2 次になる可能性があります。 

重要な観察は、待機動作が決定的であるということです。 到着時間が分かりましたら`t`惑星には、最も早い有効な出発時刻が 1 つだけあります。 ブロックされた瞬間はソートされるため、やみくもに増分するのではなく、その出発時刻に直接ジャンプできます。 

これにより、問題は、エッジ緩和が修正された標準的な最短経路問題に戻ります。 

あらゆる惑星のために`u`、 定義する：```
next_free(u, t)
```最も早い時間として`>= t`それはブロックされていません`u`。 

その場合、すべてのエッジ緩和は次のようになります。```
departure = next_free(u, dist[u])
arrival = departure + weight
```グラフにはまだ負ではないエッジ コストがあるため、ダイクストラは有効なままです。 

計算するには`next_free`効率的に、各ブロック リストをハッシュ セットに保存します。`O(1)`membership tests. すべてのブロックされた瞬間は、すべての増分にわたって最大 1 回だけアクセスされるため、合計作業量は合計ブロック数において線形のままです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 時間の経過に伴うブルート フォースの状態 | Impossible | Impossible | 遅すぎる |
 | ナイーブな待機スキャンを持つ Dijkstra | Potentially O(K²) | O(n + m + K) | 遅すぎる |
 | Optimized Dijkstra | O((n + m) log n + K) | O(n + m + K) | 承認済み |

 ここ`K`ブロックされた瞬間の合計数です。 

## アルゴリズムのチュートリアル

 1. グラフの隣接リストを作成します。 

各エッジには、隣接する惑星と移動時間が保存されます。 
2. すべての惑星のブロックされた瞬間をハッシュ セットに保存します。 

特定の時間がブロックされているかどうかを繰り返し確認するため、迅速なメンバーシップ テストが非常に重要です。 
3. ブロックされた瞬間ごとに最も早い有効な出発時刻を事前計算します。 

惑星が瞬間をブロックしたと仮定します。```
3 4 5 8 9
```ジャックが時間通りに到着したら`3`、彼は実際にそれまで待たなければなりません`6`。 

彼が到着したら`4`、答えはまだです`6`。 

各ブロック リストを逆方向にスキャンすることで、これを効率的に前処理します。 
4. ダイクストラのアルゴリズムを惑星から実行する`1`。 

プライオリティキューストア`(current_time, node)`。 
5. ノードを処理する場合`u`時に`t`、実際の出発時間を決定します。 

もし`t`通行止めではないので、出発時間は変わりません`t`。 

それ以外の場合は、連続するブロックされたセグメントの後の最初のブロックされていない時間に直接ジャンプします。 
6. すべての外向きエッジをリラックスします。 

エッジ用`(u, v, w)`:```
new_time = departure_time + w
```これが改善されれば`dist[v]`、新しい状態をヒープにプッシュします。 
7. ダイクストラが終了したら、印刷します。`dist[n]`。 

無限のままの場合は印刷する`-1`。 

### なぜ効果があるのか

 ダイクストラのアルゴリズムは 1 つの特性に依存しています。つまり、ノードが最小距離で抽出されると、その後はそのノードへのより短いルートは存在できなくなります。 

待機すると時間は増加するだけで、減少することはないため、待機ルールはこの特性に違反しません。 すべてのエッジトラバーサルには、事実上、負でない動的コストがかかります。```
effective_cost = waiting_time + edge_weight
```前処理ステップにより、すべての到着時刻について、正確な法定最早出発時刻が計算されることが保証されます。 すべての緩和では真の最小逸脱が使用されるため、すべての候補パスが正しく評価されます。 

すべての有効な移行コストは負ではないため、標準のダイクストラ正しさの証明が引き続き適用されます。 

## Python ソリューション```python
import sys
import heapq

input = sys.stdin.readline

INF = 10**30

def solve():
    n, m = map(int, input().split())

    graph = [[] for _ in range(n + 1)]

    for _ in range(m):
        a, b, c = map(int, input().split())
        graph[a].append((b, c))
        graph[b].append((a, c))

    nxt = [{} for _ in range(n + 1)]

    for i in range(1, n + 1):
        arr = list(map(int, input().split()))

        k = arr[0]
        times = arr[1:]

        if k == 0:
            continue

        jump = {}

        last = times[-1]
        jump[last] = last + 1

        for j in range(k - 2, -1, -1):
            cur = times[j]
            nxt_time = times[j + 1]

            if nxt_time == cur + 1:
                jump[cur] = jump[nxt_time]
            else:
                jump[cur] = cur + 1

        nxt[i] = jump

    dist = [INF] * (n + 1)
    dist[1] = 0

    pq = [(0, 1)]

    while pq:
        t, u = heapq.heappop(pq)

        if t != dist[u]:
            continue

        depart = nxt[u].get(t, t)

        for v, w in graph[u]:
            nt = depart + w

            if nt < dist[v]:
                dist[v] = nt
                heapq.heappush(pq, (nt, v))

    print(-1 if dist[n] == INF else dist[n])

solve()
```隣接リストは標準のダイクストラ インフラストラクチャです。 グラフがまばらであるため、この表現によりメモリと反復の効率が維持されます。 

前処理ステップが重要なトリックです。 ブロックされた時間ごとに`t`、最初の有効な時刻は、次の内容を含む連続ブロックされたセグメントの後に厳密に保存されます。`t`。 

例えば：```
blocked = [3, 4, 5, 8]
```は次のようになります:```
3 -> 6
4 -> 6
5 -> 6
8 -> 9
```これにより、アルゴリズムは一定の予想時間で待ち時間を計算できます。 

逆方向スキャンが重要です。 加工時`4`、私たちはすでに答えを知っています`5`。 もし`5`が連続している場合、`4`同じ最終脱出時間を継承します。 

ダイクストラ内では次のような行があります。```
depart = nxt[u].get(t, t)
```手段：```
If t is blocked, jump forward.
Otherwise leave immediately.
```よくある間違いは、エッジを通過した後に待機を再計算することです。 待機ルールは惑星到着後ではなく、惑星を出発する前に適用されます。 

もう 1 つの微妙な点は、古いヒープ エントリです。 ダイクストラは、同じノードの複数のバージョンを優先キューにプッシュする場合があります。 小切手:```
if t != dist[u]:
    continue
```古い状態を安全に破棄します。 

Python の整数は任意の精度であるため、パスの合計が大きくてもオーバーフローの心配はありません。

import sys
import io
import heapq

def solve():
    input = sys.stdin.readline

    n, m = map(int, input().split())

    for _ in range(m):
        a, b, c = map(int, input().split())
        graph[a].append((b, c))
        graph[b].append((a, c))

    nxt = [{} for _ in range(n + 1)]

    for i in range(1, n + 1):
        arr = list(map(int, input().split()))

        k = arr[0]
        times = arr[1:]

        jump = {}

        if k:
            jump[times[-1]] = times[-1] + 1

            for j in range(k - 2, -1, -1):
                cur = times[j]

                if times[j + 1] == cur + 1:
                    jump[cur] = jump[times[j + 1]]

                    jump[cur] = cur + 1

            nt = depart + w

                dist[v] = nt
                heapq.heappush(pq, (nt, v))

    return str(-1 if dist[n] == INF else dist[n])
