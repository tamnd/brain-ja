 ## 解決策
 ## 問題の理解

 各行を周期的に回転できるバイナリ行列があります。 左回転では、すべての要素が 1 つ左の位置に移動し、最初の要素が最後まで折り返されます。 右回転ではその逆になります。 

目標は、少なくとも 1 つの列全体が以下のもので構成されるようにすることです。`1`s、行シフトの最小合計数を使用します。 各行は独立してシフトでき、行を 1 位置シフトするには 1 回の移動がかかります。 

重要な観察点は、最終列の選択を除いて、行は相互作用しないということです。 あのコラムを決めたら`j`全てになるはずだ`1`s の場合、各行は独立して、配置するための最小コストに寄与します。`1`その列に。 カラムの合計コスト`j`行ごとのコストの合計です。 

制約は、一方の次元では小さく、もう一方の次元では大きくなります。 私たちはせいぜい`100`行、ただし最大`10^4`列。 解決策`O(n * m^2)`最悪のケースは約であるため、まだ許容できます`10^8`これは Python の限界に近く、危険です。 立方体的なものは完全に不可能です。 行ごとのほぼ線形のスキャンが目標です。 

特に重要な不可能条件が 1 つあります。 行に何も含まれていない場合`1`まったくその場合、循環シフトをいくら行っても、`1`任意の列に入力します。 つまり答えはすぐに出ます`-1`。 

よくある間違いは、ラップアラウンドを正しく考慮せずに、左シフトと右シフトを別々に扱うことです。 

例えば：```
1 5
10000
```正しい答えは、`0`, なぜならコラム`0`すでに含まれています`1`。 

列をターゲットにする場合`4`、最小コストは`1`、 ない`4`、1 回の右シフトで変換されるため、`10000`の中へ`00001`。 

もう 1 つの簡単なバグは、一方向のみの距離を計算するときに発生します。 

考慮する：```
1 6
001000
```ターゲティング列`0`費用がかかるはずです`2`、左に 2 回シフトすると、`1`インデックスから`2`インデックスを付ける`0`。 一方向スキャンが誤って返される可能性がある`4`。 

微妙なラップアラウンドのケースもあります。```
1 5
00001
```ターゲティング列`0`費用`1`1 回左にシフトすると最後の要素が前に移動するためです。 周期的な動作を忘れると誤って返される`4`。 

## アプローチ

 ブルートフォースのアイデアは単純です。 ターゲット列ごとに`j`、すべての行を個別に試し、いくつかのシフトを実現するために必要な最小シフト数を計算します。`1`列に入れる`j`。 

行に`1`位置で`k`。 それを動かすには`1`列に入れる`j`、左または右に回転できます。 費用は次のとおりです。```
min((j - k) mod m, (k - j) mod m)
```すべての行とすべてのターゲット列について、以下を含むすべての位置をスキャンできます。`1`そして最低限のコストはかかります。 

これは、ターゲット列が固定されると各行が独立するため機能します。 

問題は複雑さです。 最悪の場合、すべての行に次のものが含まれます。`m`もの。 次に、それぞれについて、`m`すべてスキャンするターゲット列`m`またまたポジション。 全体の複雑さは次のようになります。```
O(n * m^2)
```と`m = 10^4`、これは約に達します`10^10`原始的な操作なので遅すぎます。 

問題の構造からすると、より良い選択肢が得られます。 固定行の場合、すべての列から最も近い列までの距離が必要です。`1`サークル上で。 

これは、巡回配列における古典的な最近接要素の問題になります。 

便利な方法は、行を複製することです。 元の行に長さがある場合`m`、長さの概念的な配列を作成します`2m`それを2回繰り返すことで。 これで、円形のラップアラウンドが通常の直線距離になります。 

左から右にスキャンして最も近いものを追跡します`1`左に。 次に、右から左にスキャンして、最も近いものを追跡します`1`右側に。 これら 2 つの距離を組み合わせると、すべての列の最小巡回距離が得られます。 

各列に対する 1 行のコスト寄与を計算した後、それをグローバル応答配列に追加します。 

これにより、全体的な複雑さが軽減されます。`O(n * m)`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * m²) | お(1) | 遅すぎる |
 | 最適 | O(n * m) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.行列を読み取り、配列を作成します`ans`サイズの`m`、に初期化されます`0`。 
2. ある行のコスト寄与は他の行に依存しないため、各行を独立して処理します。 
3. 行に何も含まれていない場合`1`、すぐに印刷`-1`。 

循環シフトでは、`1`したがって、すべて 1 の列を形成することは不可能です。 
4. 行をそれ自体と連結して複製します。 

これにより、周期運動が通常の直線運動に変換されます。 端に近い位置では、ラップされた隣が自然に見えるようになりました。 
5. 配列を作成する`dist`長さの`2m`、大きな値で初期化されます。 
6. 左から右にスキャンします。 

直近のポジションを維持`1`。 そこから現在位置に到達できる場合`1`、距離を更新します。 
7. 右から左にスキャンします。 

最も近いものを維持する`1`右側に移動し、再び距離を縮めます。 
8. 元の列ごとに`j`、関連する位置は次のとおりです。`j`そして`j + m`二重化された配列内。 

これら 2 つの距離の最小値を取得します。 これにより、列からの真の循環距離が得られます。`j`一番近いところへ`1`。 
9. その距離を`ans[j]`。 
10. すべての行が処理された後、最小値を出力します。`ans`。 

### なぜ効果があるのか

 固定ターゲット列の場合、最適な戦略は行ごとに独立しています。 最小合計コストは、行ごとの最小コストの合計です。 

行を複製すると、円周距離が直線距離に変換されます。 2 つの位置間の最短の循環パスは、二重化された配列内のどこかに通常のセグメントとして表示されます。 

2 つのスキャンで最も近い値が計算されます。`1`ポジションごとに左右から。 最小値を取ると最短の直線距離が得られ、これは複製後の最短の巡回シフト距離と一致します。 

すべての行がすべての列に正確な最小コストを与え、最終的に最も安価な列を選択するため、アルゴリズムは常に全体的な最適値を生成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    rows = [input().strip() for _ in range(n)]

    ans = [0] * m
    INF = 10**18

    for s in rows:
        if '1' not in s:
            print(-1)
            return

        t = s + s
        dist = [INF] * (2 * m)

        last = -INF

        for i in range(2 * m):
            if t[i] == '1':
                last = i
            dist[i] = min(dist[i], i - last)

        last = INF

        for i in range(2 * m - 1, -1, -1):
            if t[i] == '1':
                last = i
            dist[i] = min(dist[i], last - i)

        for j in range(m):
            ans[j] += min(dist[j], dist[j + m])

    print(min(ans))

solve()
```このソリューションは、すべてのターゲット列の累計を維持します。 各行は、その合計に最小シフト コストを個別に加算します。 

複製された文字列`t = s + s`が核心的なトリックです。 重複がなければ、ラップアラウンドをきれいに処理するのは面倒になり、エラーが発生しやすくなります。 複製後、最も近い-`1`search は、通常の線形配列問題とまったく同じように動作します。 

左から右へのスキャンでは、最も近いものまでの距離が計算されます。`1`左側にあります。 右から左へのスキャンでは最も近い値が計算されます。`1`右側にあります。 2 つのうちの最小値が真の最短距離です。 

表現:```
min(dist[j], dist[j + m])
```見落としやすいです。 両方の位置は、同じ元の循環列に対応します。 両方を採用すると、ラップアラウンド パスが正しく含まれるようになります。 

非常に大きなセンチネルを使用する`10**18`スキャン中の特殊なケースのチェックを回避します。

0000
1010
```最初の行には何も含まれていません`1`。 処理中に、アルゴリズムは以下をチェックします。```
if '1' not in s:

ここでラップアラウンド動作を考えてみましょう。```

00001
```カラム`0`既存のものからたった 1 つシフトするだけです`1`。

100000
