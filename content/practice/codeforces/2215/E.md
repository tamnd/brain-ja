 ## 解決策
 ## 問題の理解

 平面内の一連の点が与えられます。 重要な構造上の保証は、どの 2 つの点も同じ x 座標を共有せず、どの 2 つの点も同じ y 座標を共有しないことです。そのため、すべての点は水平方向と垂直方向のランクによって一意に識別可能です。 

これらの点から、いくつかの点のトリプルを選択し、各トリプルを三角形として宣言する必要があります。 ただし、すべてのトリプルが有効であるわけではありません。三角形は、その 3 つの頂点がすべて、軸に揃えられた長方形の境界上にある場合にのみ許可されます。 幾何学的には、これにより有効なトリプルに非常に厳密な構造が強制されます。3 つの点は、辺が軸に平行な長方形の「輪郭」上になければなりません。 

次に、内部で 2 つの三角形が重ならないという追加の制約を付けて、そのような三角形のコレクションを構築します。 境界は接触することができますが、内部領域は分離していなければなりません。 目標は、選択して 1 つの最適な構造を出力できる三角形の数を最大化することです。 

制約は大きく、テストあたり合計で最大 2×10^5 ポイントです。 これにより、すべてのトリプルをチェックしたり、密な幾何学的構造を構築したりするような二次関数は即座に除外されます。 どのようなソリューションも、テスト ケースごとに基本的に線形またはほぼ線形である必要があり、ソートが主要なコストとなります。 

微妙なエッジ ケースは、局所的には密に見えるが全体的にはまばらに見える方法でポイントが配置される場合です。たとえば、極端な x ランクと y ランクが交互に配置される場合です。 グローバル構造を持たずに三角形を形成する素朴な貪欲性は、素内部制約により将来の有効な三角形を簡単にブロックする可能性があります。 

## アプローチ

 強引な解釈では、点のトリプルを列挙し、各トリプルが軸に揃えられた長方形の境界上にあるかどうかをテストしてから、重なり合わない三角形の最大パッキングを実行しようとします。 単一のトリプルの有効性をチェックするだけでも定数時間ですが、トリプルの数は O(n^3) であり、有効なトリプルにフィルタリングしても、大きな組み合わせ爆発が残ります。 第 2 フェーズはさらに悪く、本質的には、一般に NP 困難な幾何集合パッキング問題を解決していることになります。 これにより、ブルートフォースは即座に不可能になります。 

重要な単純化は、「軸が整列した長方形の境界上にある 3 つの点」が実際に何を強制するかを理解することから生まれます。 x 座標と y 座標はすべて異なるため、長方形の境界は 2 つの x 極値と 2 つの y 極値を選択することによって決定されます。 有効な三角形は、これらの 4 つの長方形の角のうちの 3 つの角で構成されている必要があります。 したがって、有効な三角形はすべて、基本的に 4 つの点で定義された長方形を取得し、その角の 1 つだけを削除することによって取得されます。 

これは、並べ替えられた順序で点のペアによって形成される四角形の周囲に三角形が緊密に構造化されていることを意味します。 次に、素の内部に関するグローバル制約は、平面を重なり合わない長方形状のブロックに分割し、各ブロック内で局所的に三角形を抽出する必要があることを強く示唆しています。 

重要な観察は、点を x 座標でソートし、左から右にペアにすると同時に、両端からペアにすることで y 構造を尊重することです。 これにより、点の各グループが独立した長方形を形成する、互いに素な「バンド」が作成されます。 このような各構造の内部では、連続する X ペアと適切な Y ブリッジを組み合わせることにより、各三角形が 1 つの長方形から角を引いたものに対応し、異なる長方形が幾何学的に干渉しないように、一貫して三角形を生成できます。 

この構築は、ソートされた順序を使用して、互いに素な四角形の最大セットを構築し、その後、各四角形を一貫したパターンで正確に 1 つの三角形に分解するかのように動作することになります。 各三角形は一定数のポイントを消費し、長方形は互いに素であるため、これにより可能な最大数が達成されます。

 ## アルゴリズムのチュートリアル

 1. すべての点を X 座標で並べ替えます。 x 値は個別であるため、曖昧さなく安全にペアリングできる厳密な左から右の順序が与えられます。 
2. 通常、バランスの取れた構造を使用するか、y でソートされたコンテナーを維持しながらソートされた x で処理することによって、y 順序の一貫性を尊重する方法でポイントをペアにする構造を維持します。 目標は、各ブロックが制御された垂直方向のスパンを持つ、互いに素なブロックを作成することです。 
3. ソートされたシーケンスを、潜在的な長方形に対応する 4 つの点のグループに分割します。 グループ化は、長方形には 2 つの x 極値と 2 つの y 極値が必要であるため、4 つの点が自然な原子構造であるという事実によって決まります。 
4. 4 つの点のグループごとに、x と y の最小値と最大値を取得して長方形の角を特定します。 グローバルな区別性により、これら 4 つの点は軸に沿った有効な長方形を形成します。 
5. 各長方形から、一貫したパターンで一度に 1 つの角を削除して、正確に 2 つの三角形を作成します。各三角形が長方形の境界上の 3 つの頂点を使用するようにします。 
6. 構築されたすべての三角形を出力します。 すべての頂点が有効で、内部の重なりが発生しない限り、三角形の順序は関係ありません。 

このグループ化が安全である理由は、x による並べ替えにより、1 つのグループ内に形成された四角形が他のグループと幾何学的に重なり合い、内部交差が生じることがないためです。 ペアリングにより、x 軸に沿った分離が強制されます。 

### なぜ効果があるのか

 この構築は暗黙的な不変式に依存しています。つまり、x でソートした後は、常に、異なる四角形間の x 間隔が決して混合しない方法で点をペアにします。 各長方形は x 順で連続するセグメントに限定され、そのセグメント内ではペアリングによって y 極値での完全な分離が強制されます。 

すべての三角形はまさに 1 つのそのような四角形から派生し、その境界点のみを使用するため、三角形の内部が別の四角形の領域と交差することはできません。 長方形は x 投影で互いに素であるため、その内部も平面内で同様に素になります。 これにより実現可能性が保証されます。 

最適性は枯渇から生まれます。すべての四角形は一定数の三角形に寄与し、有効な三角形はグローバル順序付けの少なくとも 4 つの極値制約に対応する必要があります。つまり、このパッキングが許容するよりも高密度に三角形を形成することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    
    for _ in range(t):
        n = int(input())
        pts = []
        for i in range(n):
            x, y = map(int, input().split())
            pts.append((x, y, i + 1))
        
        pts.sort()  # sort by x
        
        # We will pair points in a greedy stack by y-coordinate
        # to form rectangle-like groups.
        import heapq
        
        used = [False] * n
        res = []
        
        # We maintain a list of active points by y
        # and pair extremes indirectly by sorting index order.
        ys = []
        for x, y, idx in pts:
            ys.append((y, idx))
        
        ys.sort()
        
        l = 0
        r = n - 1
        
        # form rectangles from extremes
        while l + 3 <= r:
            y1, a = ys[l]
            y2, b = ys[l + 1]
            y3, c = ys[r - 1]
            y4, d = ys[r]
            
            # form two triangles from 4 points
            res.append((a, b, c))
            res.append((b, c, d))
            
            l += 2
            r -= 2
        
        out.append(str(len(res)))
        for a, b, c in res:
            out.append(f"{a} {b} {c}")
    
    print("\n".join(out))

微妙な詳細は、極値の y 点が最初に最適なパッキング構造に属さなければならないという事実に正確さが依存するということです。これは、極値の y 点は、内側の点を妨げずに軸に沿った長方形の境界を形成する可能性を最大化するためです。 このペアリングにより、点が再利用されず、各三角形が境界の極値から構築されることが保証されます。 

## 実用的な例

 ### 例 1

 8 点の小規模な構成を考えてみましょう。 x で並べ替えた後、y で並べ替えられた順序が次のようになったとします。 

| ステップ | l | r | 選択された y 点 | 形成された三角形 | 写真
 | --- | --- | --- | --- | --- |
 | 1 | 0 | 7 | (y0、y1、y6、y7) | (y0, y1, y6), (y1, y6, y7) |
 | 2 | 2 | 5 | (y2、y3、y4、y5) | (y2, y3, y4), (y3, y4, y5) |

 各反復では 4 つの極値点が削除され、y 間隔の重複がないことが保証されます。 これにより、各三角形グループが分離されていることが確認されます。 

### 例 2

 対称構成の場合、x でソートした後、点は y に均等に分散されます。 同じペアリング プロセスを繰り返して、外側の極端な部分を削除します。 これは、点が空間的にインターリーブされている場合でも、アルゴリズムは常にそれらを独立した極端駆動ブロックに折りたたむことを示しています。 

実証された不変条件は、各ステップの後、残りの点が同じ構造のより小さなインスタンスを形成し、実現可能性が維持されるということです。

 ## 特殊なケース

 n=3 の最小の場合には有効な四角形構造が含まれていないため、三角形を形成できません。 l + 3 <= r という条件が即座に失敗し、出力がゼロになるため、アルゴリズムは自然に停止します。 

正確に 4 つの点を持つ狭い長方形の場合は、正確に 1 回の反復が生成され、完全な境界から 2 つの三角形が形成されます。 4 つの点すべてが極値として使用されるため、ペアリングは唯一の有効な構造を正確に捕捉します。 

多くの点が y 内に集まっているが x 内に分散している非常に偏った分布でも、y による並べ替えによって極端なペアリングが強制され、内部点が長方形の形成を妨げないようにするため、正しく動作します。
