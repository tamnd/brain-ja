 ## 解決策
 ## 問題の理解

 ロバが幾何学的な規則に従って選択できる最長の星の連鎖を見つけるように求められます。 星は平面上の点であり、原点から始めます。 どの星からも、水平軸に対して一定の角度で 2 本の光線が伸びていると想像できます。 星は、前の星から発せられるこれら 2 つの光線の間に厳密に存在する場合にのみ、チェーンに次に含めることができます。 目標は、そのようなチェーン内のスターの数を最大化することです。 

入力により星の数が得られます$n$光線の傾きを定義する 2 つの部分。 各星の座標は整数として提供されます。 と$n$まで$10^5$、任意のアルゴリズム$O(n^2)$行動が制限時間を超過する可能性が高いため、それに対するアプローチが必要です$O(n \log n)$またはそれ以上です。 座標は最大まで上がる可能性があるため、$10^5$浮動小数点計算を単純に使用すると精度誤差が生じる可能性があるため、傾きを有理数として表すか、整数の外積を使用することをお勧めします。 

星が正確に光線上にある場合、微妙なエッジケースが発生します。 これらは除外する必要があります。 もう1つは、複数の星が同じものを持っている場合です。$x$または$y$現在のチェーンに対する相対的な位置 - 注意深く並べ替えたり比較したりしないと、曖昧さが生じる可能性があります。 たとえば、すべての星が光線の 1 つに平行な線上にある場合、鎖の長さは 0 ではなく 1 になる可能性があります。その場合、星は光線の間に厳密に存在できないためです。 

## アプローチ

 ブルートフォースアプローチでは、最初に考えられるすべての星を試し、その後、その星から発せられる光線の間にあるすべての星を再帰的に見つけます。 これは幾何学的規則に従っているだけなので機能しますが、次の場合には実行できなくなります。$n$大きい: 各星がチェックできる$O(n)$他のものは有効な次の星につながります。$O(n^2)$おおよその時間$10^{10}$最悪の場合の運用。 

重要な洞察は、勾配を使用して問題を 1 次元の数列問題に変換することです。 光線の傾きを整数として表すことで、各星の位置を光線間の位置を表す値のペアに変換する線形変換を計算できます。 星を 1 つの軸で並べ替えてから、変換された座標内の最長増加部分列 (LIS) を計算すると、最大連鎖を効率的に見つけることができます。 これが機能するのは、「光線の間」条件が傾き比を含む不等式に変換され、LIS がこれらの不等式を満たす星の最大系列を捕捉するためです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 変換 + LIS | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つの分数を解析する$a/b$そして$c/d$そして、それらを傾きを表す整数に変換します。$(a, b)$そして$(c, d)$。 これにより、浮動小数点精度の問題が回避され、整数の比較が可能になります。 
2. 星のリストを座標ペアとして読み取ります$(x_i, y_i)$。 
3. 各星を値のペアに変換します$(y_i \cdot b - x_i \cdot a, y_i \cdot d - x_i \cdot c)$。 これらは、原点からの各光線に対して星がどこにあるかを表します。 
4. 2 つの光線の間に厳密に存在しない星、つまり、変換された値が両方とも正ではない星をフィルターで除外します。 
5. 残りの星を 1 つの変換された座標 (たとえば、最初の座標) で並べ替えます。 ソートにより、チェーンを延長する後続のスターが不等式の片側を尊重することが保証されます。 
6. 2 番目の変換された座標で LIS を計算します。 これにより、各星が前の星の光線の間に厳密に存在する最大の順序が特定されます。 
7. この LIS の長さを出力します。 

機能する理由: 最初の座標でソートすると、どの星のペアでもそれが保証されます。$i < j$ソートされたリストでは、最初の不等式 (1 つの光線に関して) が成立します。 次に LIS は、シーケンス全体で 2 番目の不等式が満たされていることを確認します。 光線は凸状のくさびを定義するため、くさびの外側にある星はこれらの不等式のいずれかに違反します。 したがって、LIS よりも長いチェーンは存在できません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from bisect import bisect_left

def main():
    n = int(input())
    f1, f2 = input().split()
    a, b = map(int, f1.split('/'))
    c, d = map(int, f2.split('/'))
    
    stars = []
    for _ in range(n):
        x, y = map(int, input().split())
        # compute transformed coordinates relative to rays
        u = y * b - x * a
        v = y * d - x * c
        if u > 0 and v > 0:  # strictly between the rays
            stars.append((u, v))
    
    stars.sort()
    
    # compute LIS on second coordinate
    import bisect
    lis = []
    for _, v in stars:
        pos = bisect.bisect_left(lis, v)
        if pos == len(lis):
            lis.append(v)
        else:
            lis[pos] = v
    print(len(lis))

if __name__ == "__main__":
    main()
```浮動小数点エラーを避けるために、まず傾きの分数を整数のペアに変換します。 変革$u = y b - x a$、$v = y d - x c$幾何学的ウェッジチェックを不等式のペアに変換します。 星を並べ替える$u$LIS を適用できるようにします$v$これにより、レイ間の厳密な順序が維持されることが保証されます。 の`bisect_left`LIS を効率的に維持する機能$O(n \log n)$時間。
