 ## 問題の理解

 隠された整数があります$n$1 ～ 30000 の間。 

ある実験では、許容される歩幅のセットを提供します。$a_1,a_2,\dots,a_k$。 掘削ボットは深さ 0 から開始し、深さに到達したいと考えています$n$。 指定されたステップ長のいずれかを繰り返し使用できます。 ボットは常に正確に到達するパスを選択します$n$可能な限り最小限のステップ数を使用します。 実験はその最小ステップ数を返します。 目標は、隠された値を特定することです$n$。 公式の制限では、実験は最大 20 件、合計セット サイズは最大 250 まで許可されています。 

重要な観察は、これが従来のアルゴリズムの問題ではないということです。 私たちは尋問戦略を策定中です。 

以来$n \le 30000$、答えが直接明らかになるクエリを探す必要があります。$n$。 課題は、最小ステップの計算によって情報が隠蔽されないようにすることです。 

よくある間違いは、いくつかの大きなステップ長を選択し、再構築を期待することです。$n$返された最適値から。 ボットは最適化問題を解決しているため、さまざまな値が$n$同じ答えを導き出すことができます。 

たとえば、このセットでは、$\{1,100\}$、 両方$n=50$そして$n=51$長さ 100 のステップは使用できないため、その値に近い応答を返します。 応答は一意に識別されません$n$。 

特別な値$30000$もエッジケースです。 「すべての数値が最大ステップ長より厳密に小さい」と仮定する戦略では、可能な最大の隠れ値を明示的に処理する必要があります。

したがって、返される最小ステップ数は正確に次のようになります。$n$。

 ## アルゴリズムのチュートリアル

 1. セットを使った実験を依頼する`{1, 30000}`。 
2. 返された最小ステップ数を読み取ります。`m`。 
3. もし`m == 1`、出力`30000`。 

これは、ボットが長さ 30000 の単一ステップを使用する場合にのみ発生します。 
4. それ以外の場合は出力`m`。 

いつ`n < 30000`、長さ 30000 のステップは使用できないため、唯一実現可能な構築は正確に使用します。`n`ユニットステップ。 したがって`m = n`。 

### なぜ効果があるのか

 あらゆる価値観に対して$n < 30000$、長さ 30000 のステップを含むソリューションは、ターゲットの深さをすぐに超えるため、不可能です。 許可される唯一の移動は長さ 1 のステップであるため、一意の最小ステップ数は正確に次のようになります。$n$。 

のために$n = 30000$、長さ 30000 の 1 ステップはすぐにターゲットに到達し、答え 1 が得られます。 

したがって、戻り値は次のようになります。$$m =
\begin{cases}
30000 & \text{encoded as } 1,\\
n & \text{for } n < 30000.
\end{cases}$$デコード ルールは、隠された値を正確に再構築します。
