 ## 解決策
 ## 問題の理解

 この問題では、合計が与えられた数値になる 3 つの正の整数を求めます。$n$最小公倍数が半分を超えないもの$n$。 入力は多数のテスト ケースを与え、それぞれが単一の整数を指定します。$n$。 各テスト ケースの出力は 3 つの数値である必要があります$a_1, a_2, a_3$そのような$a_1 + a_2 + a_3 = n$そして$\text{LCM}(a_1, a_2, a_3) \le n/2$。 

制約により許可されるのは、$n$と同じくらい大きくなる$10^9$そして最大まで$10^4$テストケース。 これにより、考えられるすべてのトリプルを反復しようとしたり、大きな数に対して単純に最小公倍数を計算しようとするアルゴリズムは除外されます。これには、少なくとも$O(n^2)$ブルートフォースアプローチでは、テストケースごとの操作が非常に遅くなります。 テスト ケースごとに一定時間で数値を直接計算するソリューションが必要です。 

明らかではないエッジケースが現れるのは、$n$小さいか奇数です。 たとえば、次の場合$n = 3$、唯一の有効なトリプルは、$(1, 1, 1)$なぜなら、すべての数値は正でなければならないからです。 いつ$n$は偶数ですが 4 で割り切れないため、単純に分割すると等しい部分を選択すると LCM 制約に違反する可能性があります。$n$の中へ$n/3, n/3, n/3$、LCM が超える可能性があるため$n/2$。 

## アプローチ

 単純な総当たりアプローチでは、可能なすべてのトリプルを試行することになります。$(a, b, c)$と$a + b + c = n$かどうかを確認してください$\text{LCM}(a, b, c) \le n/2$。 これは正しいですが、トリプルの数は二次関数的に増加するため、非常に非効率的です。$n$。 と$n$まで$10^9$、偶数まで反復$O(n^2)$可能性は不可能です。 

重要な洞察は、LCM 条件を満たすには単純な数値のみが必要であるという観察から得られます。 もし$n$は奇数で、2 つの数値が 1 に等しく、3 番目の数値が に等しいと設定されます。$n-2$保証する$\text{LCM}(1, 1, n-2) = n-2$より小さい$n/2$場合のみ$n=3$。 もし$n$均等、分割$n$パリティを調整しながらほぼ均等な半分に分割し、合計が一致するようにします$n$そしてLCMは以下に留まります$n/2$。 具体的には、次の形式のトリプルを選択します。$(n/2, n/4, n/4)$または$(n/2-1, n/2-1, 2)$十分に大きいすべての条件を満たします$n$。 分類すると$n$2 または 4 で割り切れ、奇数であるため、テスト ケースごとに定数時間でトリプルを生成できます。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 テスト ケースごとに、次の内容を読んでください。$n$。 私たちは知っています$k = 3$固定されています。 
2. もし$n$奇数です、トリプルを選択してください$(1, (n-1)/2, (n-1)/2)$。 合計は$1 + (n-1)/2 + (n-1)/2 = n$、そして最小公倍数は$(n-1)/2$より小さい$n/2$場合のみ$n=3$ですが、チェックすると、許可される値の制約を常に満たしていることがわかります。 
3. もし$n$は 4 で割り切れます。選択してください$(n/2, n/4, n/4)$。 これらの数字を合計すると、$n$そして最小公倍数は$n/2$、条件を正確に満たしています。 
4. もし$n$偶数ですが 4 で割り切れない場合は、選択してください$(n/2-1, n/2-1, 2)$。 合計は$(n/2-1) + (n/2-1) + 2 = n$、そして最小公倍数は$n-2$、これは常に未満です$n/2$。 これが機能する理由は、$n/2$奇数なので、$n-2 < n/2$満足しています。 
5. 各テスト ケースに対して選択したトリプルを出力します。 

機能する理由: この構造により、合計が一致することが保証されます。$n$最小公倍数は、繰り返しの数値または 1 や 2 などの小さな値を使用して制御されます。4 で割り切れる偶数の場合、半分と 4 分の 1 に分割すると、最大の要素が正確に生成されます。$n/2$。 4 で割り切れない偶数の場合、2 とほぼ等しい 2 つの数により、最大の数が以下になることが保証されます。$n/2$。 奇数は 1 と 2 つの等しい半分で処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    if n % 2 == 1:
        print(1, n//2, n//2)
    elif n % 4 == 0:
        print(n//2, n//4, n//4)
    else:
        print(n//2 - 1, n//2 - 1, 2)
```最初の行はテスト ケースの数を読み取ります。 テストケースごとに解析します$n$そして$k$。 のパリティに基づいて分岐します。$n$そしてどうか$n$は 4 で割り切れます。整数の除算を使用すると、トリプルの整数が確実に得られます。 各ブランチを直接印刷することで、ソリューションがシンプルになり、一時的な保管が回避されます。
