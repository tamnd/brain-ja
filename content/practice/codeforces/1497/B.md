 ## 解決策
 ## 問題の理解

 数値の複数セットと法が与えられます$m$。 タスクは、すべての数値をできるだけ少ない数のシーケンスに再配置することです。各シーケンスは、ローカル互換性ルールを満たす必要があります。つまり、2 つの連続する要素が同じシーケンスに出現する場合は常に、それらの合計が次の数で割り切れる必要があります。$m$。 

各シーケンス内で要素を任意に並べ替えることができるため、唯一の実際の制約は、剰余の剰余に基づいて要素がどのように隣り合って「適合」するかです。$m$。 2つの数字の余りがある場合$r$そして$s$、その場合、それらは正確に次のような順序で隣接することができます。$r + s \equiv 0 \pmod m$。 これは各剰余を意味します$r$その補数とのみ互換性があります$m - r$、残りは$0$それ自体とのみ互換性があり、$m$偶数、余り$m/2$自己互換性もあります。 

目標は、すべての要素をそのような有効なシーケンスの最小数に分割することです。 

制約$n \le 10^5$すべてのテスト ケースで、すべてのパーティションを試行したりシーケンスを明示的に構築したりする戦略から遠ざかることになります。 すべてのペアリングを暗黙的に考慮したり、バックトラックを試行したりするソリューションは失敗します。これは、検索スペースが指数関数的に増大するためです。$n$。 問題の構造は、要素の実際の配置ではなく、剰余の頻度のみが重要であることを示唆しています。 

素朴な推論が微妙に失敗するケースは、相補的な剰余を貪欲にペアリングすると常にシーケンスが最小化されると仮定することです。 たとえば、常にできるだけ多くの一致を試みると、$r$と$m-r$可能な限り、グローバル構造を考慮せずに残っ​​たものに対して新しいシーケンスを開始すると、必要なシーケンスの数を過大評価したり、無効な構造を構築したりする可能性があります。 もう 1 つのよくある間違いは、剰余の特別な動作を処理せずに、剰余の各ペアを個別に扱うことです。$0$そして$m/2$。 

## アプローチ

 強引なアイデアでは、実際にシーケンスを 1 つずつ構築しようとします。 未使用の要素を繰り返し選択し、互換性のある未使用の要素を貪欲に選択してシーケンスを拡張し、拡張が不可能になるまで継続して、新しいシーケンスを開始することができます。 隣接ルールを明示的に尊重しているため、これは原理的には正しいです。 ただし、各拡張機能では互換性のある未使用の要素をスキャンする必要があり、最悪の場合、要素を何度も再訪する可能性があります。 これは二次関数の動作につながり、次の場合に制限をはるかに超えます。$n$到達する$10^5$。 

重要な観察は、隣接性は剰余のみに依存し、それぞれの剰余に依存するということです。$r$単一のパートナーとのみ対話します$m-r$。 これにより、問題は残基の相補的な各ペアにわたる独立した計数問題に縮小されます。 

固定ペアの場合$(r, m-r)$、各タイプの要素がいくつ存在するかだけを気にします。 これら 2 つの残基のみを使用する有効なシーケンスは、それらを交互に使用する必要があります。 これにより、問題は 2 つのマルチセットを最小限の数の交互シーケンスに分割することに変わります。 単一の交互シーケンスは最大でもカウント間の 1 の差を吸収できるため、2 つのカウント間の不均衡により複数のシーケンスが強制されることがわかると、最適な構造が現れます。 

特別な残基$0$そして、いつ$m$均等です、$m/2$、自分自身とペアになるため、異なる動作をします。 これらの場合、あらゆる隣接関係が有効であるため、すべての要素を単一のシーケンスに配置できます。

 ## アルゴリズムのチュートリアル

 まず、配列を各剰余モジュロの周波数カウントに圧縮します。$m$。 

1. 配列を計算する`cnt`どこ`cnt[r]`残りの数値がいくつあるかを保存します$r$。 これにより、すべての順序付け情報が削除され、隣接関係の実現可能性に重要な情報のみが保持されます。 
2. ハンドルの残り$0$。 もし`cnt[0]`がゼロ以外の場合、そのような要素はすべて単一の有効なシーケンスに配置できます。$0 + 0 \equiv 0 \pmod m$。 これは、0 または 1 のシーケンスに寄与します。 
3. もし$m$偶数、ハンドルの残り$m/2$。 この残りを持つすべての要素も相互互換性があるため、それらが存在する場合は単一のシーケンスに配置できます。 これも最大 1 つのシーケンスに寄与します。 
4. 残りごとに$r$から$1$に$m-1$とペアリングします$m-r$ただし、強制的に各ペアを一度だけ処理します。$r < m-r$。 このようなペアごとに、両方のグループに対応するために必要なシーケンスの数を決定します。 
5.ペア用$(r, m-r)$、 させて$a = cnt[r]$そして$b = cnt[m-r]$。 両方ともゼロの場合はスキップします。 それ以外の場合、必要な交互シーケンスの最小数は次のとおりです。$\max(1, |a - b|)$。 これは、単一の交互シーケンスが可能な限り多くのバランスを吸収でき、アンバランスが残った場合には追加のシーケンスを強制するという事実を捉えています。 
6. すべての独立グループからの貢献を合計して、最終的な答えを求めます。 

### なぜ効果があるのか

 ペア上の各シーケンス$(r, m-r)$は交互の鎖であり、単一鎖内では 2 つの残基の数の差は最大でも 1 です。 したがって、配列はバランスの取れたペアを効率的に「吸収」し、優勢な残基の過剰分だけが新しい配列を強制します。 異なる残基ペアは相互作用しないため、各ペアを個別に最適化すると、全体的に最適な分解が生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        
        cnt = [0] * m
        for x in a:
            cnt[x % m] += 1
        
        ans = 0
        
        if cnt[0] > 0:
            ans += 1
        
        if m % 2 == 0 and cnt[m // 2] > 0:
            ans += 1
        
        for r in range(1, m):
            s = m - r
            if r >= s:
                continue
            a1, a2 = cnt[r], cnt[s]
            if a1 == 0 and a2 == 0:
                continue
            ans += max(1, abs(a1 - a2))
        
        print(ans)

if __name__ == "__main__":
    solve()
```コードは、実行可能性に関連する唯一の情報である剰余周波数を構築することから始まります。 次に、2 つの自己互換性のある剰余クラスは独立した単一グループ問題のように動作するため、これらを別々に処理します。 

ループオーバー$r$各残基とその補数を 1 回だけペアリングします。 表現`max(1, abs(a1 - a2))`は、交互シーケンスの重要な構造結果を実装します。つまり、非常に不均衡なペアであっても、少なくとも 1 つのシーケンスが必要であり、不均衡の余分な単位ごとに追加のシーケンスが強制されます。 

二重カウントをスキップしないように注意する必要があります。$r < m-r$そうでない場合、各ペアが 2 回処理され、答えが水増しされてしまいます。

 ## 特殊なケース

 残りについて$0$、そのようなすべての要素は相互に互換性があるため、アルゴリズムは単一のシーケンスが存在する場合は常にそれを正しく割り当てます。 たとえゼロが多くても、交互制約に違反しないため、複数のシーケンスが強制されることはありません。 

残りについて$m/2$いつ$m$が偶数の場合、同じ推論が当てはまります。 ペアリングの問題のように見えるかもしれませんが、同一の残基のすべてのペアは有効であるため、カウントに関係なく、すべての要素を 1 つのシーケンスに連鎖させることができます。 

非常に不均衡な相補ペアの場合、次の式は$\max(1, |a-b|)$1 つの残基が優勢な場合でも、使用可能なオーバーラップに対して少なくとも 1 つのシーケンスが形成され、残りの余剰分は別のシングルトンまたは部分的に埋められたシーケンスに正しく強制されます。
