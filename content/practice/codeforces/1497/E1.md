 ## 解決策
 ## 問題の理解

 いくつかの独立したテスト ケースが与えられています。 各テスト ケースは正の整数の配列を提供します。この配列を可能な限り最小数の連続する部分に分割したいと考えています。 The constraint inside each part is not about ordering or sums, but about a multiplicative property: within a single segment, you must never find two different elements whose product is a perfect square.

 2 つの数値が同じ素数と指数のパリティ パターンを共有する場合、積は正確に完全な平方になります。 In simpler terms, if we reduce every number by removing all squared factors, two numbers are “in conflict” if their square-free parts are equal. セグメントは、その中に正方形のない値が繰り返されない場合にのみ有効です。 

So the problem becomes a partitioning task over a transformed array: we want to split the sequence so that within each segment all square-free signatures are distinct, and we minimize the number of such segments.

 制約$n \le 2 \cdot 10^5$すべてのテスト ケースにわたって、テストごとに二次関数が即座に除外されます。 テスト ケースごとに線形または線形に近いスキャンが必要であり、おそらくハッシュ構造を使用した貪欲な戦略を使用します。 

微妙な失敗例は、数値が中間値によって「隠された」後に繰り返される場合に発生します。 たとえば、次のような配列では、$[a, b, a]$正しい縮小表現を追跡していない場合、3 つすべてを 1 つのセグメントに誤って許可してしまう可能性があります。 ただし、正方形のない同一のパーツはすぐに有効な二乗積を作成するため、セグメントは 2 番目に出現した時点で分割する必要があります。 

もう 1 つのエッジ ケースは、二乗因数を削除した後に多くの数値が 1 になる場合です。$1, 4, 9, 16$。 これらはすべて同じ署名に折りたたまれるため、すべての要素が独自のセグメントを形成する必要があります。 二乗自由正規化ではなく生の値で機能するソリューションはここで失敗します。 

## アプローチ

 ブルートフォース戦略では、配列を分割し、各セグメントの有効性をチェックするためにあらゆる方法が試行されます。 セグメントをチェックするには、正方形のない署名が繰り返されていないことを検証する必要がありますが、これ自体はセットを使用して行うことができます。 指数関数的に多くのパーティションがあり、単純化された動的プログラミングの定式化でも、$O(n^2)$テスト ケースごとの遷移数は、許容制限をはるかに超えています。$n$到達する$2 \cdot 10^5$。 

重要な観察は、一度セグメントを修正したら、それを切り取らなければならない唯一の理由は、反復された四角形のない値に初めて遭遇したときであるということです。 これにより、問題は貪欲スキャンに変わります。つまり、アクティブなセグメントに現在存在する値のセットが維持されます。 すでにセット内に値があることがわかると、この要素の直前でセグメントを終了し、新しいセグメントを開始する必要があります。 

唯一欠けている要素は、各数値の平方フリー署名を効率的に計算する方法です。 以来$a_i \le 10^7$、ふるいを使用してすべての数値の最小の素因数を前処理できます。 次に、奇数の指数のみが残るように、繰り返される素数を分割することで各数値を減らすことができます。 この正規化ステップは、乗算制約を整数に対する単純な等価制約に変えるため、非常に重要です。 

すべての値が正方形のない形式に変換されると、問題は、セグメント内で値が繰り返されないように配列を最小数のセグメントに分割するのと同じになります。 これは古典的な貪欲なパーティション分割の問題です。

 | --- | --- | --- | --- |
 | ブルートフォース | 指数関数 | O(n) | 遅すぎる |
 | 最適 | O(n log A) per test | O(n + A) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. までのすべての整数について最小の素因数を事前計算します。$10^7$。 これにより、後で素早い因数分解が可能になり、各数値をほぼ対数時間で削減できるようになります。 
2. 配列内の各数値について、素因数を反復し、奇数回出現する数値のみを保持することにより、その自由平方形式を計算します。 このステップでは、乗算条件を単純な等価条件に変換します。 
3. 現在のセグメント内の値のセットを維持しながら、配列を左から右に走査します。 
4. 現在の要素の正方形のない値がセットにない場合は、それを挿入し、セグメントの拡張を続けます。 
5. すでにセット内にある場合は、この要素の前で現在のセグメントを閉じ、セグメント数を増やし、セットをクリアして、現在の要素を含む新しいセグメントを開始します。 
6. すべての要素を処理した後、最後のアクティブなセグメントを数えます。 

この貪欲なカットが正しい理由は、重複する四角形のない値が出現した瞬間に、セグメントを維持すると直ちに制約に違反するためです。 将来の要素が重複を遡って修正することはできず、カットを延期しようとする代替パーティションは現在のセグメントを無効にするだけであるため、カットを遅らせるメリットはありません。 

維持される不変条件は、すべてのステップで、現在のセットには進行中のセグメント内の平方のない値が正確に含まれており、それらはすべて異なるということです。 新しいセグメントを開始するたびに、この不変式をリセットして、無効なセグメントが構築されないようにします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXA = 10**7

spf = list(range(MAXA + 1))
for i in range(2, int(MAXA**0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, MAXA + 1, step):
            if spf[j] == j:
                spf[j] = i

def square_free(x):
    res = 1
    while x > 1:
        p = spf[x]
        cnt = 0
        while x % p == 0:
            x //= p
            cnt ^= 1
        if cnt:
            res *= p
    return res

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    used = set()
    ans = 1

    for v in a:
        sv = square_free(v)
        if sv in used:
            ans += 1
            used.clear()
        used.add(sv)

    print(ans)

if __name__ == "__main__":
    solve()
```ふるいは最小の素因数を構築するため、因数分解に試行除算は必要ありません。 それぞれの数値は正規の正方形のない代表に還元されます。これがセグメントの有効性に関連する唯一のものです。 

スキャン中に、セット`used`現在のセグメントを表します。 競合が発生した場合、セットをクリアすることは新しいセグメントを開始することと同じであり、現在の要素は新しいセグメントに属しているため、すぐに再挿入します。 

よくある実装上の間違いは、正方形のない形式を再計算するのを忘れ、代わりに生の値を使用することです。 この問題では 2 と 8 のような値は同一であるとみなされる必要があるため、これは正確性を損ないます。

 ## 特殊なケース

 最初のエッジ ケースは、平方フリー リダクション後にすべての数値が 1 になる場合です。 のような入力の場合$4, 9, 16$、すべての値は同じ署名に折りたたまれます。 アルゴリズムは 1 をセットに挿入し、すぐに再びそれに遭遇し、毎回強制的にカットします。 これにより、要素ごとに 1 つのセグメントが作成され、セグメント内での重複が禁止されるという制約と一致します。 

別の特殊なケースは、同一の素数が繰り返されることです。 のような配列の場合$2, 2, 2$最初の要素がセグメントを開始し、2 番目の要素がカットをトリガーし、プロセスが繰り返されます。 どのセグメントも合法的に 2 を複数回含むことができないため、貪欲なリセットにより正確さが保証されます。 

3 番目のエッジ ケースは、値は異なるものの、非平方形式を間接的に共有する混合因数分解です。$8, 2, 18$。 ここでは 8 が 2 に減り、2 自体が 2 であるため、生の値が異なって見える場合でも、すぐに競合が発生します。 正規化ステップは、アルゴリズムが繰り返しを正しく検出することを保証するものです。
