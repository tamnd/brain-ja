 ## 問題の理解

 それぞれが複雑さ、タグ、スコアに関連付けられた一連の問題が与えられます。 の複雑さ$i$- 番目の問題は$c_i = 2^i$、指数関数的に増加します。 IQから始める$0$最初に任意の問題を選択できます。 問題を解決した後、そのタグが異なり、複雑さの絶対的な差が現在の IQ を超えている場合は、別の問題に移ることができます。 あなたの IQ はこの新しい差に合わせて更新され、得られるスコアは 2 つの問題のスコアの絶対的な差になります。 課題は、問題解決の一連の動作で収集できる合計スコアを最大化することです。 

制約は微妙です。 と$n \le 5000$テストケースごとおよび合計$n$すべてのテスト ケースでも 5000 で制限されるため、余裕があります。$O(n^2)$テストケースごとの操作だけで、それ以上のものは何もありません。 各スコアは最大で$10^9$したがって、無効な手を切り詰めずにすべての潜在的なシーケンスを合計するような単純な反復的なスコアリングアプローチは避けなければなりません。 

ここでは、エッジケースが特に重要です。 移動には 2 つの異なる問題が必要となるため、1 つの問題だけではポイントを生成できません。 IQ 条件が満たされない場合、同一のタグまたは同一の複雑さの問題により遷移がブロックされる可能性があります。 たとえば、次の場合$n = 2$同じタグで複雑さが異なる場合、有効な手が存在せず、スコアは 0 になります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての初期問題から始めて、一連の問題をすべて列挙しようとします。 シーケンスごとに IQ を追跡し、スコアを蓄積します。 このアプローチはルールを直接モデル化するため原理的には機能しますが、その複雑さは階乗的です。$O(n!)$、これは不可能です$n = 5000$。 

重要な観察は、採点関数が問題のペアにのみ依存するということです。 動きは完全に次のように定義されます。$|c_i - c_j|$そして$|s_i - s_j|$、タグの不平等によって制約されます。 したがって、ノードが問題となり、移動が有効な場合にのみエッジが存在するグラフとしてこれをモデル化できます。 各エッジには、獲得したスコアに等しい重みがあります。 任意のノードから開始して最大重みパスを見つけることを目的としています。 

特定のタグのペアでは、各 IQ レベルで最大スコアのみが重要であることに気づくことで最適化できます。 複雑さは 2 の累乗であるため、絶対的な差は一意であり、明確な差の数は次のように制限されます。$O(n^2)$。 この観察により、動的プログラミングが可能になります。つまり、前の問題のタグによってインデックス付けされた DP テーブルを維持し、その問題で終了する達成可能な最大スコアを保存します。 DP 値を更新するには、問題のすべてのペアを 1 回繰り返すだけで十分です。

 ## アルゴリズムのチュートリアル

 1. DP 配列を初期化する`dp`サイズの`n`、 どこ`dp[i]`問題のあるシーケンスを終了することで達成可能な最大スコアを保存します`i`。 最初は全部`dp[i] = 0`まだ何も動いていないので。 
2. すべての問題のペアを反復処理します。`(i, j)`と`i != j`:

 1. タグが異なるかどうかを確認します。`tag[i] != tag[j]`。 
2. 複雑さの差を計算する`diff = abs(2^(i+1) - 2^(j+1))`。 
3. もし`diff > dp[i]`(現在のIQは`i`)、からの動き`i`に`j`許可されています。 
4.アップデート`dp[j] = max(dp[j], dp[i] + abs(s[i] - s[j]))`。 
3. テスト ケースの答えは、次の最大値です。`dp`すべてのペアを検討した後。 

DP が機能するのは、各ステップで、`dp[j]`で終わる有効なシーケンスによって達成可能な最大スコアを常に保存します。`j`。 動きは複雑さとタグの違いのみに依存するため、すべてのペアを考慮することで、潜在的なシーケンスが見逃されないことが保証されます。 不変条件とは、`dp[i]`で終わるシーケンスに最適です。`i`次の反復の前に。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        tags = list(map(int, input().split()))
        scores = list(map(int, input().split()))
        
        dp = [0] * n  # dp[i]: max score ending at problem i
        
        for i in range(n):
            for j in range(n):
                if i == j:
                    continue
                if tags[i] != tags[j]:
                    diff = abs((1 << (i + 1)) - (1 << (j + 1)))
                    if diff > 0:  # IQ condition: initial dp[i] can be treated as IQ
                        dp[j] = max(dp[j], dp[i] + abs(scores[i] - scores[j]))
        
        print(max(dp))

if __name__ == "__main__":
    solve()
```各反復では、個別のタグ間の有効な移動が考慮されます。 私たちは指数関数的な性質を利用します。`c_i = 2^i`ビットシフトを直接使用して差分を効率的に計算します。 使用する`dp`再計算を回避し、問題が発生した時点で終了する最適なシーケンスを常に選択できるようにします。
