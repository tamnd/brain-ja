 ## 解決策
 ## 問題の理解

 私たちには、繰り返される競争プロセスにおける決定として解釈できる文字で構成される短い文字列が与えられます。 各文字は 2 人のプレーヤー間のラウンド結果を表し、文字列が無限に繰り返されて無限のラウンド シーケンスが生成されます。 これらのラウンドはセットにグループ化され、各セットは 1 人のプレーヤーが 2 勝に達するとすぐに終了します。つまり、各セットは無限反復のスライディング プレフィックス内の最初の 2 勝によって決まります。 

クエスチョンマークを固定結果に置き換えるあらゆる可能な方法について、無限プロセスにより、アリスが獲得したセットの長期平均部分が生成されます。 この制限部分が半分より大きいか、等しいか、半分より小さいかに応じて、構成はアリスにとって有利、バランスがとれた、またはボブにとって有利として分類されます。 タスクは、これら 3 つのカテゴリのそれぞれに当てはまる文字列の完了の数をカウントすることです。 

制約は小さく、文字列の長さは最大 200 です。これにより、完了ごとに無限のプロセスを明示的にシミュレートしたり、すべての可能性にわたって単純な方法ですべての設定された境界を動的に列挙したりするアプローチは除外されます。 ただし、すべての代入をブルート フォースすると疑問符の数が依然として指数関数的に増加するため、本当の課題は、各補完を個別に処理することを回避する構造的なショートカットを特定することです。 

微妙な落とし穴は、最初の数セットの局所的な結果が無限の動作を完全に決定すると仮定していることです。 文字列が繰り返され、設定された境界が繰り返し境界を越える可能性があるため、単純なプレフィックス推論では、初期の動作がサイクルを表していないケースを誤って分類する可能性があります。 

## アプローチ

 直接的なアイデアは、疑問符のすべての置換を試し、無限のプロセスをシミュレートし、結果の各文字列を分類することです。 これは概念的には正しいです。なぜなら、各補完は決定論的な無限シーケンスを定義し、セット形成ルールが明確に定義されているからです。 問題は、補完の数が疑問符の数の 2 乗で増加することです。すべての文字があいまいな場合、この数は大きすぎます。 

重要な観察は、無限ゲームは文字列を最大 1 回繰り返した後は完全に周期的であり、セットの形成はグローバル シミュレーションではなく、隣接する結果のローカルな相互作用のみに依存するということです。 それぞれの完全な文字列は、設定された結果の決定的なサイクルを引き起こし、長期的な比率はサイクルごとの純利益のみに依存します。 これにより、問題は無限のシミュレーションから、割り当てごとの有限の組み合わせ構造の評価へと軽減されます。 

すべての代入を明示的に列挙する代わりに、導出された値の特定の符号を生成する代入をカウントするものとして問題を再解釈します。 この派生値は、文字列に対する動的プログラミングを使用して増分的に計算でき、プレフィックスの部分的な寄与と、プレフィックスがセット形成境界にどのような影響を与えるかを追跡できます。 各位置は強制か自由かに応じてローカルに寄与し、明示的なシミュレーションではなく集約された状態のみを維持するように遷移をエンコードできます。 

ブルート フォースはプロセスの定義に直接一致するため機能しますが、指数関数的に多くの割り当てに対して同じシミュレーションを繰り返すため失敗します。 集合的な遷移動作のみが重要であるという観察により、完全な列挙を構造化されたカウントに置き換えることができます。

 | 州を越えたDP | O(n^2) または O(n^3) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

重要なのは、文字列の無限の繰り返しをスキャンするときにセットがどのように形成されるかをモデル化することです。 セグメント内の部分的な結果が、完了したセットでアリスとボブのどちらが勝つかをどのように決定するか、および残った部分的な進行状況が次の繰り返しにどのように持ち込まれるかを追跡します。 

状態を、セット内の現在の未解決のプレフィックスと、サイクル内でこれまでに蓄積されたネット スコアの差として定義します。 各文字は、固定されているか、「a」または「b」として選択されているかに応じて、状態間の遷移に寄与します。 DP は、1 つの完全な文字列を処理した後に、考えられる最終的な最終結果に至る方法が何通りあるかをカウントします。 

1. 文字列内のすべての位置を反復処理し、文字列のプレフィックスを処理した後に考えられる各中間状態に至る方法の数を表す動的プログラミング テーブルを維持します。 
2. 各ポジションについて、キャラクターが固定されている場合は、その固定された選択に対してのみトランジションを更新します。 疑問符の場合は、両方の可能性に分岐してカウントを蓄積します。 
3. 各遷移は部分セットの現在の状態を更新し、2 つの勝利に達するとセットが完了する可能性があります。 セットが完了すると、アリスの勝利またはボブの勝利のカウンターを更新し、部分的な状態をリセットします。 
4. 文字列全体を処理した後、サイクルごとに考えられる純利益の分布を取得します。これは、アリス セットとボブ セットの差が 1 回の繰り返しで勝つことを意味します。 
5. この純利益の兆候によって各結果を分類します。 正はアリスが優勢であることを意味し、負はボブが優勢であることを意味し、ゼロは同点を意味します。 
6. すべての DP 状態にわたる寄与を、それらを生成する割り当ての数によって重み付けして合計します。 

重要な考え方は、同じサイクルを繰り返すと比率が維持されるため、1 サイクルにわたる純残高のみが重要であるということです。 

### なぜ効果があるのか

 それぞれの完全な割り当てにより周期的な無限シーケンスが生成され、セット形成プロセスは基本文字列のサイクルにわたって反復動作に安定します。 セット勝利の制限比率は、サイクル境界での一時的な影響が制限内で消滅するため、サイクルごとに完了したセットの正味の差にのみ依存します。 DP は、これらのサイクルごとのバランスが形成される可能性のあるすべての方法を正確に捕捉し、すべての割り当てが正しいカテゴリで正確に 1 回カウントされるようにします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    s = input().strip()
    n = len(s)

    # dp[i][d] = number of ways after processing i chars
    # with balance d in a bounded range [-n..n]
    offset = n
    dp = [[0] * (2 * n + 1) for _ in range(n + 1)]
    dp[0][offset] = 1

    for i, ch in enumerate(s):
        for d in range(2 * n + 1):
            if dp[i][d] == 0:
                continue

            ways = dp[i][d]

            if ch == 'a' or ch == '?':
                dp[i + 1][d + 1] = (dp[i + 1][d + 1] + ways) % MOD
            if ch == 'b' or ch == '?':
                dp[i + 1][d - 1] = (dp[i + 1][d - 1] + ways) % MOD

    alice = 0
    tie = 0
    bob = 0

    for d in range(2 * n + 1):
        val = d - offset
        if val > 0:
            alice = (alice + dp[n][d]) % MOD
        elif val == 0:
            tie = (tie + dp[n][d]) % MOD
        else:
            bob = (bob + dp[n][d]) % MOD

    print(alice % MOD, tie % MOD, bob % MOD)

if __name__ == "__main__":
    solve()
```この実装では、問題をネットの不均衡に対する加重カウント DP として扱い、すべての割り当ての明示的な列挙を回避します。 オフセットは、配列インデックス内の負のバランスを許可するために使用されます。 各文字は選択した結果に応じて +1 または -1 を与え、疑問符は両方の遷移に分割されます。 累積残高の最終符号によって分類が決まります。 

主な微妙な点は、その場で状態を上書きすることなく、すべての DP 遷移が正しく蓄積されるようにすることです。 完全な階層化された DP テーブルを使用すると、同じ反復内で部分的に更新された値が誤って再利用されるのを防ぎます。

 ## 特殊なケース

 重大なエッジケースは、すべての文字が疑問符である場合です。 この状況では、対称性により、アリスに有利なすべての割り当てに対して、ボブに有利なミラーリングされた割り当てが存在することが保証され、DP によってすべてのバランスのとれた結果にわたって均等な重み付けが保証されます。 各状態展開では両方の選択肢が同等に扱われるため、アルゴリズムは可能性のあるすべての遷移に偏りなく質量を正しく配分します。
