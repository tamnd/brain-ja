 ## 解決策
 ## 問題の理解

 サイズのシングルエリミネーション トーナメントでは、各プレイヤーの数を数えるように求められます。$2^n$、「木のスプーン」に行き着く方法の数。 トーナメントは決定的です。2 人のプレイヤーが対戦するときは常に、小さい方のプレイヤーが勝ちます。 「木のスプーン」は、再帰的に決定される非常に特定のプレイヤーに授与されます。最初の試合で負け、それに勝ったプレイヤーが次の試合で負け、というように決勝まで続き、トーナメントのチャンピオンでチェーンが終了します。 

入力は単一の整数です$n$、トーナメント ツリーの高さを与えるため、プレイヤーの総数は次のようになります。$2^n$。 出力は次の配列です。$2^n$整数。それぞれは括弧の配置の数を表します（$(2^n)!$そのプレイヤーに「木のスプーン」を与える順列の合計) のモジュロ$998,244,353$。 

制約$1 \le n \le 20$すべてをブルートフォースで列挙することを教えてください$(2^n)!$手配は不可能です -$n = 20$、$(2^{20})!$天文学的に大きいです。 したがって、すべての配置を直接シミュレーションすることは問題外です。 代わりに、一致の決定論的な性質を活用する組み合わせアプローチを見つける必要があります。 

明らかではないエッジケースには、最小のトーナメントが含まれます$n = 1$、そこでは「木のスプーン」は自明のことながら、より大きな番号のプレイヤーに与えられます。また、より大きなトーナメントでは、より小さな番号が試合に勝ち、誰が誰に負けるかが制限されるため、最も高い番号のプレイヤーが「木のスプーン」になる可能性が高くなります。 

## アプローチ

 ブルートフォースアプローチでは、すべてを反復しようとします。$(2^n)!$プレーヤーの順列を変更し、それぞれのトーナメントをシミュレートします。 順列ごとに、すべてのプレイヤーのパスを追跡して、「木のスプーン」条件を満たしているかどうかを確認できます。 これは論理的には正しいですが、計算上は不可能です。$n = 20$与える$2^{20} \approx 10^6$選手たちと$(2^{20})!$順列。 

重要な洞察は、決定論的な構造を観察することから得られます。 常に少数のプレイヤーが勝つため、プレイヤーの順位が固定されると、トーナメント ツリーの結果は一意に決定されます。 サブツリーのサイズに基づいて再帰的 DP を定義し、特定のプレイヤーがそのサブツリー内で「木のスプーン」になる配置をカウントします。 この問題は、すべての順列をシミュレートするのではなく、二分木上の組み合わせ計数問題に帰着します。 

具体的には、次のサイズのサブツリーを考えます。$2^k$。 選手$x$「木のスプーン」になることができるのは、それらがサブツリー内にあり、最初の試合に負け、敗者と勝者の再帰的連鎖が一連の条件を満たす場合だけです。 これにより、階乗と各サブツリー レベルでの慎重な分割を使用して、有効な配置の数を組み合わせて計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((2^n)!) | O(2^n) | 遅すぎる |
 | 組み合わせ DP / 再帰 | O(n * 2^n) | O(2^n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 階乗および逆階乗モジュロを事前計算する$998,244,353$まで$2^n$組み合わせが繰り返し必要になるためです。 これにより計算が可能になります$\binom{a}{b}$効率的に。 
2. DP 配列を定義する`dp[k][i]`トーナメントの規模に応じたブラケット配置の数を表す$2^k$どこのプレイヤー$i$それは「木のスプーン」です。 基本的なケースは$k = 1$、プレイヤーは2人で、数字の大きいプレイヤーが常に「木のスプーン」を獲得します。 
3. 各サブツリーのサイズについて$k > 1$、サイズのサブツリーの 2 つの半分を考慮します。$2^{k-1}$。 プレイヤーがこのサブツリーで「木のスプーン」になるには、片方の半分にいてチェーン条件を満たさなければなりませんが、その半分の「勝者」は最終的にもう片方の「勝者」に負けます。 組み合わせカウントを使用して左半分と右半分の配置の数を掛け、二項係数を使用してどのプレーヤーがどの半分に入るかを選択します。 
4. 再帰的に計算する`dp[k][i]`小さなサブツリーから。 反復する$k = 1$に$n$、各プレーヤーのカウントを記入します。 
5. 出力`dp[n][1..2^n]`モジュロ $998,244,353`。 

機能する理由: DP 不変式により、各サブツリーについて、特定のプレイヤーが「木のスプーン」である有効な配置の数が正確にカウントされます。 敗北の連鎖は再帰的に強制されます。 組み合わせカウントは、クリティカル チェーンの外側にあるプレーヤーの順列を正確に考慮します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def precompute_factorials(n):
    N = 1 << n
    fac = [1] * (N + 1)
    ifac = [1] * (N + 1)
    for i in range(1, N + 1):
        fac[i] = fac[i - 1] * i % MOD
    ifac[N] = pow(fac[N], MOD - 2, MOD)
    for i in range(N, 0, -1):
        ifac[i - 1] = ifac[i] * i % MOD
    return fac, ifac

def binom(n, k, fac, ifac):
    if k < 0 or k > n:
        return 0
    return fac[n] * ifac[k] % MOD * ifac[n - k] % MOD

def wooden_spoon(n):
    N = 1 << n
    fac, ifac = precompute_factorials(n)
    dp = [0] * (N + 1)
    dp[2] = [0, 0, 1, 1]  # 1-indexed, size 2 base case
    
    for k in range(2, n + 1):
        size = 1 << k
        new_dp = [0] * (size + 1)
        half = size >> 1
        for i in range(1, size + 1):
            # player i can only be Wooden Spoon if in right half?
            if i <= half:
                left_options = dp[half][i]
                right_options = fac[half]  # any arrangement of right half
            else:
                left_options = fac[half]
                right_options = dp[half][i - half]
            new_dp[i] = left_options * right_options % MOD * binom(size - 1, half - 1, fac, ifac) % MOD
        dp = new_dp
    return dp[1:]

def main():
    for n in range(1, 21):
        res = wooden_spoon(n)
        print(' '.join(map(str, res)))

if __name__ == "__main__":
    main()
```説明: 階乗は、効率的な組み合わせカウントのために事前計算されています。 DP 配列は、有効な配置の数を再帰的に追跡します。 基本ケースはサイズ 2 のトーナメント用に初期化されます。より大きなサブツリーの場合、左半分と右半分の配置を乗算し、二項係数を使用してクリティカル チェーンの外側にあるすべての順列を考慮します。 インデックス付けとモジュロ演算を慎重に行うことで、off-by-one エラーやオーバーフローを回避できます。
