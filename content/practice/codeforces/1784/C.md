 ## 解決策
 ## 問題の理解

 ゲーム内でモンスターを倒すために必要な単一対象ダメージ呪文の最小数を見つけるように求められますが、強力な効果範囲呪文も一度だけ唱えることができます。 各モンスターには正の整数の体力があり、効果範囲呪文は、新たな死者が発生しなくなるまで、生きているすべてのモンスターの体力を繰り返し 1 ずつ減らします。 モンスター配列のプレフィックスごとに、この最小値を計算する必要があります。 入力により複数のテスト ケースが得られ、それぞれがモンスターの数とそれぞれのヘルス ポイントを指定します。 出力は整数のリストで、各整数は長さが増加するプレフィックスに必要な単一対象の呪文の最小数に対応します。 

テストケース全体のすべてのモンスターの合計が次の値に達すると仮定すると、$2 \cdot 10^5$、モンスターの数に対して線形またはほぼ線形の時間で実行されるソリューションが必要です。 各呪文を段階的にシミュレートする素朴なアプローチでは、非常に遅すぎます。高い体力を持つ 1 匹のモンスターには、最大で$n$プレフィックスごとに反復を繰り返すと、計算量が爆発的に増加します。 

明らかではないエッジケースには、モンスターの体力がすでに連続的に増加または減少している状況が含まれ、これは効果範囲呪文の使用が最適かどうかに影響します。 たとえば、プレフィックス内のすべてのモンスターの体力が 1 の場合、範囲効果呪文は単一対象の呪文を使用せずに即座にそれらを殺すことができます。 逆に、あるモンスターの体力が非常に高く、他のモンスターの体力が低い場合、範囲効果呪文は、ターゲットにダメージを与えた後でのみ、体力の最も高い「スパイク」を減らすことができます。 

## アプローチ

 ブルートフォースアプローチでは、プレフィックスごとに呪文の詠唱を 1 つずつシミュレートし、タイプ 1 とタイプ 2 の呪文をあらゆる組み合わせで適用します。 これは論理的には正しいですが、非常に非効率的です。 長さのプレフィックスごとに$k$、おそらくシミュレーションする必要があります$O(\sum a_i)$以下の場合には受け入れられない操作$n$までです$2 \cdot 10^5$。 

最適なアプローチは 2 つの観察に基づいています。 まず、タイプ 2 の呪文は最初の適用で少なくとも 1 体のモンスターを殺した場合にのみ有効であるため、特別な繰り返しカスケードで最大体力を 1 つ減らすものと考えることができます。 第二に、各プレフィックスについて、必要なタイプ 1 呪文の最小値は、ゼロと最大のモンスターの体力の間の最大値から現在のプレフィックスの長さを引いたものに等しくなります。 これは、効果範囲呪文が効果的にすべての健康を均一に減少させるが、健康階層の最下位にあるモンスターから始めて連鎖的に死亡させることしかできないためです。 モンスターの体力の実行最大値を維持し、カスケード効果範囲によってすでに倒せるモンスターの数をカウントすることで、各プレフィックスの答えを線形時間で計算できます。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$そしてモンスターの健康状態の配列$a$。 
3. 変数を初期化する`max_health`から 0 まで、現在のプレフィックスでこれまでに確認された最大の健全性を表します。 
4. モンスターを順番に繰り返します。 位置で終わる各プレフィックスについて$i$:

 ａ． アップデート`max_health`現在の値との間の最大値として$a[i]$。 

b. このプレフィックスに必要なタイプ 1 呪文の最小数を次のように計算します。`max(0, max_health - (i + 1))`。 ここ`(i + 1)`接頭語の長さを表し、範囲魔法の影響を受けるモンスターの数を表します。 

c. この値を保存または印刷します。 
5. すべてのテスト ケースに対して繰り返します。 

**機能する理由**: 重要な特性は、効果範囲呪文がカスケードごとに各モンスターの体力を 1 つずつ減らすことと、接頭語に長さがあれば、$k$、その後、最大でも`k`繰り返し、体力が ≤ のすべてのモンスター`k`単一ターゲットの呪文なしで殺されます。 上記の残りの体力`k`タイプ 1 の呪文で処理する必要があります。 現在の最大値を維持することで、各プレフィックスに残っている最も背の高いモンスターを正確に考慮できるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        res = []
        max_health = 0
        for i in range(n):
            max_health = max(max_health, a[i])
            res.append(max(0, max_health - (i + 1)))
        print(' '.join(map(str, res)))

if __name__ == "__main__":
    solve()
```**説明**: 変数`max_health`現在のプレフィックス内の最大のモンスターの健康状態を追跡します。 表現`max(0, max_health - (i + 1))`は、プレフィックス長全体にわたって効果範囲カスケードを適用した後にどれだけ健全性が残っているかを効果的に計算します。 これにより、各呪文をシミュレートする必要がなくなり、テスト ケースごとに線形な時間計算が可能になります。
