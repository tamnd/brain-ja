 ## 問題の理解

 ## アルゴリズムのチュートリアル

 有限表現をスキャンすることで各クエリを処理します$A_2$、これには以下が含まれます$A$それ自体と連結されます。 これにより、次の長さの有効な部分文字列が保証されます。$K$無限拡張では、完全に配列内に表示されます。

2. 配列を維持する$L$、 どこ$L[i]$で終わる有効な部分文字列の左端の開始インデックスを格納します。$i$。 
3. インデックスを反復処理する$i$で$A_2$。 現在の要素の場合$A[i]$には存在しません$P$の場合、有効な部分文字列は次で終わることはできません。$i$なのでリセットします$L[i]$に$i+1$。 これは、不一致により継続が直ちに中断されることを反映しています。 
4. もし$A[i]$いる$P$、サイクル内の位置を の位置と比較します。$A[i-1]$。 連続モジュロの場合$K$の場合、部分文字列を拡張できるため、次のように設定します。$L[i] = L[i-1]$。 これにより、次で終わる最長の有効なウィンドウが保存されます。$i-1$。

### なぜ効果があるのか

 正しさは、順列サイクルでは隣接性が相対的な順序を完全に決定するという事実に依存します。 すべての要素は個別であるため、サイクル内の 1 つの要素の位置がわかれば、次の有効な要素は一意に決定されます。 内の任意の有効な部分文字列$A^\infty$それは一致します$P^\infty$すべてのステップでこの隣接構造を保持する必要があります。 したがって、すべての有効なセグメントは、サイクルに沿った連続したウォークに正確に対応します。$P$、隣接関係が切れるとすぐに拡張性が破壊されます。 これにより、スライディング ウィンドウの特性評価が正確になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    A = list(map(int, input().split()))
    P = list(map(int, input().split()))

    pos = {}
    for i, v in enumerate(P):
        pos[v] = i

    A2 = A + A

    ans = 0
    L = -1

    for i in range(len(A2)):
        if A2[i] not in pos:
            L = i + 1
            continue

        if i > 0 and A2[i - 1] in pos:
            if (pos[A2[i - 1]] + 1) % k == pos[A2[i]]:
                # extend
                pass
            else:
                L = i
        else:
            L = i

        if L != -1:
            ans = max(ans, i - L + 1)

    print(ans if ans <= k else "infinity")

def main():
    solve()

if __name__ == "__main__":
    main()
