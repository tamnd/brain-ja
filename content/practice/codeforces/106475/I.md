 ## 問題の理解

 私たちは持っています`n`鉛筆の色。 描いたら`x_i`色のある魚`i`、この色から受け取る星は、その色を共有する魚の数によって異なります。 初めての色の魚`i`与える`a_i`星、2番目は与えます`a_i - 2`、3番目は与えます`a_i - 4`、 等々。 色は、個々の魚のスコアが無効になるまでのみ使用できます。つまり、その色の魚の数が超過することはできません。`a_i + 1`。 

課題は正確に選択することです`m`受け取ったすべての星の合計ができるだけ大きくなるように、合計で魚を色ごとに分配します。 最大スコアと 1 つの有効な分布の両方を出力する必要があります。 

制約により、私たちは以下に比例するものを避ける必要があります。`m`。 の値`m`到達できる`10^9`したがって、すべての魚やすべての可能な選択肢をシミュレートすることは不可能です。 平`O(m)`何十億もの操作が必要になります。 色数はたったの`2 * 10^5`したがって、意図したソリューションは次のように機能する必要があります。`O(n log A)`どこ`A`可能な星の値の範囲です。 

難しいのは、最適な配分とは単に「最大の色を使用する」ということではないということです。`a_i`より多くの魚が割り当てられるほど、色は価値が低くなります。たとえば、次のような場合です。`a = [5]`そして`m = 3`、3匹の魚が与える`5`、`3`、 そして`1`星、3回ではない`5`。 

不用意なソリューションは、必要なカウントが大きい場合に失敗する可能性もあります。 例えば：```
Input
1 2
1
```唯一の色が値を与える`1, -1, ...`。 正しい出力は次のとおりです。```
0
0 2
```二匹の魚が一緒に与えるもの`1 + (-1) = 0`。 プラスの寄与のみを取る貪欲なソリューションでは 1 匹の魚が出力される可能性がありますが、正確には`m`魚を描かなければなりません。 

もう 1 つのエッジ ケースは、多くの色の限界値が等しい場合です。```
Input
3 9
1 2 3
```正しい出力は次のとおりです。```
0
2 3 4
```異なる最適な分布が存在する可能性があります。 アルゴリズムは、一意の答えを仮定せずに同点を処理する必要があります。 

## アプローチ

 直接的なアプローチは、追加される可能性のある魚をそれぞれ検討することです。 カラー用`i`、ゲインのシーケンスは次のとおりです。```
a_i, a_i - 2, a_i - 4, ..., -a_i
```がある`a_i + 1`このカラーで釣れる可能性のある魚。 考えられるすべてのゲインを生成し、最大のものを選択した場合`m`の場合、すべての魚の選択が正確に 1 つの限界値に寄与するため、この解は正しいでしょう。 しかし、`a_i`と同じ大きさにすることができます`10^9`したがって、このシーケンスには数十億の値が含まれる可能性があります。 すべてのシーケンスを展開することは不可能です。 

重要な観察は、これらのシーケンスがソートされた算術数列であるということです。 それらを生成する必要はありません。 少なくとも何らかのしきい値以上の値がいくつあるかを知る必要があるだけです。 

値を選択するとします`x`。 1 つの色について、少なくとも限界ゲインの数`x`は数学的に求めることができます。 すべての色でしきい値を超えているゲインの数を数えることができれば、二分探索により最大のゲインの中でカットオフ値を見つけることができます。`m`利益が得られます。 

閾値を見つけた後`t`、すべてのゲインが`t`を採用する必要があり、一部の利益のみが以下に等しい`t`正確に到達するには必要な場合があります`m`魚。 色のすべてのゲインは減少シーケンスを形成するため、各色に対して選択されたゲインは常に接頭辞を形成し、これにより各色の魚の数を再構築できます。

 ## アルゴリズムのチュートリアル

 1. 各色について、考えられる魚の寄与を降順で表示します。`a_i, a_i - 2, a_i - 4, ... , -a_i`。 

答えは最大のものの合計です`m`これらすべてのシーケンス間の値。 
2. すべてのシーケンス内で指定された数値以上の値がいくつあるかを数える関数を実装します。`x`。 

1色の場合、`x > a_i`、そのような値はありません。 もし`x <= -a_i`、 全て`a_i + 1`価値観が適格です。 それ以外の場合は、次のように解決します。`a_i - 2k >= x`可能な限り最大の`k`。 
3. 最大閾値の二分探索`t`少なくとも存在するように`m`限界値以上`t`。 

このしきい値は、最後に選択された限界寄与の値です。 
4. 厳密に次よりも大きいすべての寄与を計算します。`t`。 これらの投稿は少ないため、選択する必要があります。`m`閾値を超える貢献。 
5. 以下に等しい十分な貢献を追加します。`t`正確に到達する`m`魚。 

各色に対して、まず寄与が大きいすべての魚を割り当てます。`t`。 次に、残りの魚を、次に利用可能な寄与が等しい色に分配します。`t`。 
6. 選択されたすべての限界寄与の合計として最終スコアを計算し、各色に割り当てられた魚の数を出力します。 

これが機能する理由: 固定色の追加の各魚の限界寄与は減少するだけなので、1 つの色からの最適な選択にはそのシーケンスの接頭辞が必要です。 全体の問題は最大のものを選択することになります`m`ソートされたシーケンスからの要素。 二分探索によって検出されたしきい値は、選択された値と選択されていない値を分離します。 しきい値を超えるすべての値は必須であり、残りの位置をしきい値と等しい値で埋めても、答えを減らすことはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    def count_ge(x):
        res = 0
        for v in a:
            if x > v:
                continue
            if x <= -v:
                res += v + 1
            else:
                res += (v - x) // 2 + 1
        return res

    def sum_ge(x):
        res = 0
        for v in a:
            if x > v:
                continue
            if x <= -v:
                c = v + 1
            else:
                c = (v - x) // 2 + 1
            last = v - 2 * (c - 1)
            res += c * (v + last) // 2
        return res

    lo = -10**9 - 1
    hi = 10**9 + 1
    while lo + 1 < hi:
        mid = (lo + hi) // 2
        if count_ge(mid) >= m:
            lo = mid
        else:
            hi = mid

    threshold = lo

    ans = sum_ge(threshold + 1)
    used = [0] * n
    taken = 0

    for i, v in enumerate(a):
        if threshold + 1 > v:
            continue
        if threshold + 1 <= -v:
            c = v + 1
        else:
            c = (v - (threshold + 1)) // 2 + 1
        used[i] = c
        taken += c

    need = m - taken

    for i, v in enumerate(a):
        if need == 0:
            break
        nxt = v - 2 * used[i]
        if nxt == threshold:
            used[i] += 1
            need -= 1
            ans += threshold

    print(ans)
    print(*used)

if __name__ == "__main__":
    solve()
```の`count_ge`関数は二分探索の中核です。 各色は等差数列の公式を使用して数えられるため、シーケンスが構築されることはありません。 

の`sum_ge`関数は同じカウント ロジックを使用しますが、選択した等差数列の合計も計算します。 最初の値は常に`a_i`、最後に選択された値は減算によって求められます。`2`あらゆるステップに。 

しきい値を見つけた後、再構築フェーズでは、そのしきい値を厳密に超えるすべての寄与が考慮されます。 残りの位置はすべて、しきい値と正確に等しい値を持つ必要があるため、各色の次の未使用の寄与をチェックするだけで十分です。 シーケンス順序により、さらに 1 匹の魚を追加すると、常に次に利用可能な限界値が得られることが保証されます。 

すべての算術演算は Python 整数を使用して行われるため、寄与の合計に含まれる大きな積がオーバーフローすることはありません。
