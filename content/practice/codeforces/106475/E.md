 ## 解決策
 # 問題の理解

 無限のグリッドがあります。 一部のセルにはすでにマークが含まれています。 現在のボードは、水平、垂直、または対角線上にある 3 つの連続するマークされたセルを避けることが保証されています。 

マークを配置した後、連続する 3 つのマーク付きセルの少なくとも 1 行が存在するように、追加のマークを 1 つ受け取ることができる空のセルの数をカウントする必要があります。 

入力により、現在マークされているすべてのセルの座標が得られます。 出力は、長さ 3 の行を完成できる個別の空の座標の数です。 

重要な制約は、既存のマークは最大 200,000 個まで存在できるのに対し、座標は絶対値で 10^9 まで大きくできることです。 ボードは事実上無限であるため、ボードをスキャンするソリューションは不可能です。 大きな外接する四角形内のすべての座標をチェックするだけでも、利用可能な時間をはるかに超える時間が必要になります。 座標範囲ではなくマークの数に依存するアルゴリズムが必要です。 

既存のトリプルが存在しないことは、有用な保証となります。 これは、すべての有効な手が、正確に 2 つの既存のマークと 1 つの新しいマークから作成されることを意味します。 ボードにすでに勝ちラインが含まれている状況に対処する必要はありません。 

よくある間違いは、可能性のあるセルではなく、可能性のあるペアを数えることです。 異なるペアが同じ空のセルを示唆する可能性があるため、重複を削除する必要があります。 

たとえば、次のことを考えてみましょう。```
3
0 0
1 0
0 1
```正しい答えは、`4`。 細胞`(2,0)`、`(-1,0)`、`(0,2)`、 そして`(0,-1)`すべて水平または垂直のトリプルを作成します。 すべてのペアの完了を個別にカウントする不注意なアプローチでは、同じポジションを複数回カウントする可能性があります。 

もう 1 つの特殊なケースは、2 つのマークが対角線上にあるものの、十分に接近していない場合です。```
2
0 0
1 2
```正しい答えは、`0`。 2 つのマークは、1 つのセルが欠落している長さ 3 の可能な線に属していません。 距離を確認せずに 2 つのマークの有無だけを確認すると、誤った答えが得られます。 

# アプローチ

 直接的なアプローチは、すべての空のセルを調べて、そこにマークを置くとトリプルが作成されるかどうかをテストすることです。 考えられるすべての答えがチェックされるため、これは正解です。 問題は、空のセルの数が意味のある方法で制限されていないことです。 座標は最大 10^9 であるため、マークの数が少ない場合でも、周囲に広大な領域が存在する可能性があります。 強引な方法では候補を列挙することさえできません。 

重要な観察は、成功するすべての移動が正確に 3 つのセルのセグメントを完了する必要があるということです。 このようなセグメントで可能な方向は、水平、垂直、および 2 つの対角線の 4 つだけです。 既存のマークが 1 つわかっている場合は、これらの方向に 1 つまたは 2 つのセルの距離を見るだけで済みます。 

固定方向ベクトルの場合`(dx, dy)`、長さ 3 のセグメントの 3 つの可能な位置に 2 つの既存のマークが表示される可能性があります。 最初と 2 番目のセルが占有されている場合、欠落しているセルはペアの 1 ステップ前とペアの 1 ステップ後にあります。 1 番目と 3 番目のセルが占有されている場合、欠けているセルは中央のセルです。 4 つの方向しかなく、一定の距離のチェックがあるため、既存の各マークは一定数の候補のみを生成します。 

最後のステップは重複排除です。 考えられるすべての答えの座標をセットに挿入します。 空のセルにマークを配置する必要があるため、すでに占有されている座標は無視されます。

 # アルゴリズムのチュートリアル

 1. 既存のマークされたセルをすべてハッシュ セットに保存します。 生成されたすべての候補を現在のボードと照合する必要があるため、座標ルックアップは一定時間である必要があります。 
2. マークされたすべてのセルについて、4 方向を検査します。`(1,0)`、`(0,1)`、`(1,1)`、 そして`(1,-1)`。 これらは、重複のない 3 細胞株のすべての可能な方向を表します。 
3. 各方向について、1 つ離れたセルを確認します。 占有されている場合、2 つのセルはトリプルの最初の 2 つの位置になる可能性があります。 欠落している可能性のある 2 つのセルを、ペアの前とペアの後に 1 つずつ追加します。 
4. 同じ方向の場合は、2 つ離れたセルを確認します。 占有されている場合、2 つのマークがトリプルのエンドポイントになる可能性があります。 中央のセルを回答候補として追加します。 
5. すでに占有されている候補を削除します。 残りの一意の座標の数が答えです。 

機能する理由: 有効な移動ごとに 3 つのセルの行が作成されます。 その行で、すでに占有されている 2 つのセルのいずれかを選択し、もう一方の占有されているセルに向かう方向を検討します。 既存の 2 つのセル間の距離は 1 または 2 です。 アルゴリズムはこれら 2 つのケースを正確にチェックし、欠落している位置を追加します。 生成されたすべての位置はセットに保存されるため、同じ手を発見する複数の方法が結果に影響を与えることはありません。 

# Python ソリューション```python
import sys

input = sys.stdin.readline

def solve():
    n = int(input())
    points = set()

    for _ in range(n):
        x, y = map(int, input().split())
        points.add((x, y))

    directions = [
        (1, 0),
        (0, 1),
        (1, 1),
        (1, -1),
    ]

    ans = set()

    for x, y in points:
        for dx, dy in directions:
            x1, y1 = x + dx, y + dy
            if (x1, y1) in points:
                a = (x - dx, y - dy)
                b = (x + 2 * dx, y + 2 * dy)
                if a not in points:
                    ans.add(a)
                if b not in points:
                    ans.add(b)

            x2, y2 = x + 2 * dx, y + 2 * dy
            if (x2, y2) in points:
                mid = (x + dx, y + dy)
                if mid not in points:
                    ans.add(mid)

    print(len(ans))

if __name__ == "__main__":
    solve()
```コードの最初の部分では、占有セルのセットを構築します。 Python タプルが座標表現として使用され、メンバーシップの直接チェックが可能になります。 

反対方向は同じラインを表すため、方向リストには 4 つのベクトルのみが含まれます。 たとえば、チェックする`(1,0)`水平トリプルはすでにカバーされているので、チェックしてください`(-1,0)`作業が重複するだけです。 

最初の条件は、隣接するマークされたセルをチェックします。 もし`(x,y)`そして`(x+dx,y+dy)`占有されている場合、トリプルの 2 つの隣接するセルを形成します。 3 番目のセルはそれらのどちら側にでも配置できます。 

2 番目の条件は、1 つのギャップで区切られたセルをチェックします。 もし`(x,y)`そして`(x+2dx,y+2dy)`が占有されている場合、唯一欠けている可能性がある位置は中央のセルです。 

セット`ans`異なる既存のマークまたは異なる方向から同じ空セルが生成される可能性があるため、これが必要です。 Python 整数は大きな座標値を直接処理するため、オーバーフロー処理は必要ありません。

# テストケース```python
import sys
import io

def run(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    def solve():
        input = sys.stdin.readline
        n = int(input())
        points = set()

        for _ in range(n):
            x, y = map(int, input().split())
            points.add((x, y))

        directions = [(1, 0), (0, 1), (1, 1), (1, -1)]
        ans = set()

        for x, y in points:
            for dx, dy in directions:
                if (x + dx, y + dy) in points:
                    for p in [(x - dx, y - dy), (x + 2 * dx, y + 2 * dy)]:
                        if p not in points:
                            ans.add(p)

                if (x + 2 * dx, y + 2 * dy) in points:
                    p = (x + dx, y + dy)
                    if p not in points:
                        ans.add(p)

        return str(len(ans))

    result = solve()
    sys.stdin = old_stdin
    return result

| 非常に大きな座標 | 2 | 座標範囲と整数の処理 |
