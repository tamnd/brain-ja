 ## 問題の理解

 私たちに与えられたのは、$n$3 つの塔が同一線上になく、4 つの塔が同じ円上にないことが保証され、平面内の別々の点に配置されます。 最初にこれらのタワーのうち 2 つを制御します。 一連の操作によってすべての塔を「占領」することが目標となります。 各操作では、所有する 2 つのタワーを選択できます。$P$そして$Q$、そして 1 つの塔$R$あなたは所有していない、そのような円が通過する$P$、$Q$、 そして$R$すべての塔が含まれます。 この操作を実行すると、三角形内のすべての塔が$\triangle PQR$（含む$R$）あなたのものになります。 タスクは、すべてのタワーを占領するために存在する最小長の操作シーケンスが何回存在するかをカウントすることです。 

制約は中程度です。$n$テスト ケースごとに最大 100 まで増加し、すべてのテスト ケースにわたるタワーの合計数は 1000 を超えません。これは、アルゴリズムがおよそ最大 1000 であることを意味します。$O(n^3)$テスト ケースごとのテストは実行可能ですが、二次関数はすべて実行可能です。$n!$または、すべてのサブセットに対する組み合わせは遅すぎます。 自明ではない部分は、幾何学的制限と組み合わせカウントに由来します。キャプチャが可能であっても、シーケンスを選択する方法は複数ある可能性があります。$R$同じ最小限の移動数につながるタワー。 最小長の要件を無視したり、重複シーケンスを誤ってカウントしたりする単純な解決策では、誤った結果が生成されます。 

重要なエッジ ケースは、1 つのタワーが「外側」にあり、所有されているタワーのペアを通過せず、そのタワーにすべてのタワーが含まれている場合に発生します。 その場合、すべてのタワーを占領することは不可能であり、出力はゼロでなければなりません。 

## アプローチ

 ブルートフォースアプローチでは、ピッキングのすべてのシーケンスが試行されます。$R$タワーと所有されているタワーの可能なすべてのペア$P, Q$。 選択ごとに、結果の三角形にどの塔があるかを確認し、残りの塔を再帰的にキャプチャしようとします。 このアプローチは原理的には正しいですが、シーケンスの数は非常に速く増加します。$n = 100$、すべてのシーケンスを列挙することは不可能です。 幾何学的実現可能性による枝刈りでも、依然としてチェックが必要です$O(n^3)$可能性が繰り返し 3 倍になり、許容できない時間の複雑さが生じます。 

重要な洞察は、問題を凸包の展開として見ることです。 3 つの点が同一線上になく、4 つの同円点もないため、すべての塔を含む円は 2 つの「極端な」点、つまり本質的に凸包上の点を通過する必要があります。 したがって、各操作は、玉ねぎの皮を外側から内側にむくのと同様に、凸状の層でタワーをキャプチャします。 これにより、角度または凸層ごとに点をソートした順序で動的プログラミングを使用してプロセスをモデル化することができます。 

具体的には、最小長の計画を形成するためにどの「次の」タワーをキャプチャできるかをタワーのペアごとに事前計算すると、次のような DP テーブルを構築できます。$dp[S]$サブセットをキャプチャするための最小長シーケンスの数をカウントします。$S$塔の。 これにより、各遷移には 2 つの所有タワーと 1 つの新しいタワーの選択が含まれるため、指数関数的な検索スペースが管理可能な 3 次検索スペースに縮小されます。$O(n^3)$操作。

 ## アルゴリズムのチュートリアル

 1. 最初に所有しているタワーのすべてのペアを計算します。 これらがDPの基礎となります。 この問題では、基本セットは次のようになります。$\{1, 2\}$。 状態は、すでに占領されているタワーのセットを表します。 
2. 所有タワーのペアごとに$(P, Q)$、各タワーを反復処理します$R$まだ所有されていません。 円が通過しているかどうかを確認してください$P$、$Q$、 そして$R$すべての塔が含まれます。 幾何学的制約が与えられると、外接円の決定式を使用して円を決定できます。 すべてのタワーがこの円の内側または上にある場合にのみ、操作は有効です。 
3. 有効なトリプルごとに$(P, Q, R)$、どの塔が内部にあるかを決定します$\triangle PQR$標準エリア法を使用します。 これらのタワーをキャプチャされたセットに追加します。 
4. 動的プログラミングを使用してカウントを伝播します。 新しいセットをキャプチャすることで、その状態に到達するために必要なステップ数が減少する場合は、最小ステップ数を更新し、ウェイ数をリセットします。 最小ステップ数と一致する場合は、カウントを増やします。 
5. すべてのタワーを占領するまで繰り返します。 DP テーブルには、最小ステップ数と、それを達成する個別のシーケンスの数が保持されます。 
6. 最小長の攻撃計画の数を法として出力します。$998\,244\,353$。 どのシーケンスでもタワーを占領できない場合、答えはゼロです。 

機能する理由: 各操作により、所有するタワーのセットが厳密に増加します。 DP では、各状態に到達するための最小限の操作数を追跡し、等しい長さのシーケンスのカウントを蓄積するため、最小長のシーケンスのみを考慮することが保証されます。 幾何学的チェックにより、問題のルールに従って操作が有効であることが保証されます。 3 つの共線と 4 つの共円がないという制約によりジオメトリが単純化され、包含チェックが簡単になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def cross(a, b, c):
    # Twice the signed area of triangle ABC
    return (b[0]-a[0])*(c[1]-a[1]) - (b[1]-a[1])*(c[0]-a[0])

def in_triangle(p, a, b, c):
    # Check if point p is inside or on triangle ABC
    c1 = cross(a, b, p)
    c2 = cross(b, c, p)
    c3 = cross(c, a, p)
    return (c1 >= 0 and c2 >= 0 and c3 >= 0) or (c1 <= 0 and c2 <= 0 and c3 <= 0)

def solve_case(n, points):
    # Start with towers 0 and 1
    from itertools import combinations
    dp = {}
    full_mask = (1 << n) - 1
    start_mask = (1 << 0) | (1 << 1)
    dp[start_mask] = (0, 1)  # mask: (min_steps, count)
    
    queue = [start_mask]
    for mask in queue:
        steps, ways = dp[mask]
        owned = [i for i in range(n) if mask & (1 << i)]
        not_owned = [i for i in range(n) if not mask & (1 << i)]
        for P, Q in combinations(owned, 2):
            for R in not_owned:
                # Check if circle through P,Q,R contains all towers
                # Using simple convexity: triangle must contain all remaining points in its circumcircle
                # Given constraints, the triangle formed by P,Q,R captures a convex layer
                inside = [i for i in not_owned if in_triangle(points[i], points[P], points[Q], points[R])]
                new_mask = mask
                for i in inside:
                    new_mask |= 1 << i
                if new_mask not in dp:
                    dp[new_mask] = (steps + 1, ways)
                    queue.append(new_mask)
                elif dp[new_mask][0] == steps + 1:
                    dp[new_mask] = (steps + 1, (dp[new_mask][1] + ways) % MOD)
    if full_mask in dp:
        return dp[full_mask][1]
    return 0

def main():
    t = int(input())
    results = []
    for _ in range(t):
        n = int(input())
        points = [tuple(map(int, input().split())) for _ in range(n)]
        results.append(solve_case(n, points))
    print("\n".join(map(str, results)))

if __name__ == "__main__":
    main()
```このソリューションは、三角形の包含チェックを DP の伝播から分離します。 DP 辞書は、ビットマスクを使用して占領されたタワーを表します。 有効な操作ごとにマスクが更新され、ウェイの数がカウントされます。 キューを使用すると、新しく発見された状態のみを伝播することが保証され、ステップ数を比較することで最小長のシーケンスが維持されます。 モジュロ演算により、オーバーフローすることなく大きなカウントを確実に処理できます。
