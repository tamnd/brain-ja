 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、`n`ノードに対して単一の「シャッフル」操作を実行できます。 シャッフルは、任意のノードを新しいルートとして選択し、それをツリーから削除し、結果として得られる各サブツリーを再帰的にシャッフルし、シャッフルされたすべてのサブツリー ルートをこの新しいルートに接続し直すことで構成されます。 シャッフルを 1 回だけ実行した後の目標は、結果として得られるツリー内の葉の数を最大化することです。 リーフは次数 1 のノードであるため、ルートに子が 1 つしかない場合、ルートはリーフとしてカウントできます。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは、そのエッジを通じてツリーを定義します。 制約により、最大で`2 × 10^5`ツリーあたりのノード数とその合計`n`すべてのテストケースで次を超えない`3 × 10^5`。 これは、どのソリューションもツリーごとにほぼ直線的な時間で実行する必要があることを直ちに意味します。 すべてのサブツリーをシャッフルするためにあらゆる方法を試みる単純なアプローチでは、指数関数的処理が必要になり、実行不可能になります。 

エッジ ケースには、2 つのノードを持つ非常に小さなツリー、星形のツリー、または線形チェーンが含まれます。 たとえば、3 つのノードの行`1-2-3`ノードをシャッフルすることで最大 2 つの葉を生成できます`2`一方、素朴にエンドポイントをルートとして選択すると、リーフは 1 つしか得られません。 1 つの中心と複数の葉を持つ星は、すでに存在する以上の葉を生成できません。 これらを正しく処理するには、各ノードの子とサブツリーの選択がどのように伝播するかについて推論する必要があります。 

## アプローチ

 ブルート フォース ソリューションでは、すべてのサブツリーのすべての可能なルートを再帰的に試行します。 各ノードで、各子をそのサブツリーの新しいルートとして試し、結果を組み合わせることで、達成可能な葉の数を計算します。 これは論理的に機能しますが、各サブツリーのルートのすべての順列を評価する必要があります。 サイズ 2 × 10^5 のツリーの場合、これは非常に遅くなり、本質的に階乗複雑になります。 

重要な観察は、すべての順列を考慮する必要はないということです。 各サブツリーは、そのサイズと構造に応じて多数のリーフを提供し、その貢献を最大化するノードでサブツリーをルート化することで、貪欲にリーフを最大化できます。 より具体的には、サブツリー内のリーフは、シャッフルの次のレベルでルートとして選択された場合にのみ内部になることができます。 逆に、サブツリーをうまくルート化すれば、リーフではないノードをリーフに変えることができます。 したがって、問題はツリーに対する動的プログラミングのアプローチに帰着します。 

私たちは定義します`dp[u]`ノードでサブツリーをルート化する場合に取得できる葉の最大数として`u`。 もし`u`元々の木には葉があり、`dp[u] = 1`。 さもないと、`dp[u] = sum(dp[v] for all children v)`。 その理由は、各子サブツリーに少なくとも 1 つのリーフを提供させることができるためです。 最後のステップでは、ルートに子が 1 つしかない場合、ルートがリーフになることもあります。 これは計算によって組み込むことができます`max(1, dp[u])`ルートに子が 1 つある場合は、それ以外の場合はすべての子からの寄与を合計するだけです。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 テスト ケースごとに、次の内容を読んでください。`n`そしてエッジのリスト。 ツリーの隣接リストを作成します。 
2. 任意のルート (ノード 1 など) を選択します。 DFS を実行して計算します`dp[u]`すべてのノードに対して。`dp[u]`ノードの場合に取得できる最大の葉を表します`u`現在のサブツリーのルートです。 
3. DFS 内で、各ノードに対して`u`、すべての子を横断します`v`親と等しくありません。 再帰的に計算する`dp[v]`。 
4. もし`u`DFS 内に子がありません (つまり、リーフです)、設定`dp[u] = 1`。 それ以外の場合はすべてを合計します`dp[v]`子供たちへの価値観。 これは、各子サブツリーができるだけ多くのリーフを提供することを表します。 
5. DFS の後、元のルートには子が 1 つだけ存在する可能性があることを考慮してください。 その場合、根そのものが葉になることもありますので、`dp[root]`ルートに DFS ツリー内に子が 1 つしかない場合は、1 ずつ増分できます。 
6. 印刷`dp[root]`テストケースの答えとして。 

**効果がある理由**: それぞれ`dp[u]`は、最適なシャッフルの下でそのサブツリー内で達成可能なリーフの最大数を表します。 リーフからルートまでを計算することにより、すべてのサブツリーが可能な最大数のリーフを提供することが保証されます。 シャッフルは 1 回だけ適用されるため、計算ではすべてのノードが考慮され、二重にカウントされるノードはありません。 不変条件は、ノードを処理した後、`dp[u]`をルートとする最適にシャッフルされたサブツリーの葉の数を正しく表します。`u`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        adj = [[] for _ in range(n + 1)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            adj[u].append(v)
            adj[v].append(u)

        def dfs(u, parent):
            leaves = 0
            child_count = 0
            for v in adj[u]:
                if v != parent:
                    child_count += 1
                    leaves += dfs(v, u)
            if child_count == 0:
                return 1
            return leaves

        print(dfs(1, 0))

if __name__ == "__main__":
    solve()
```DFS はリーフをボトムアップで計算します。 各ノードに子がない場合、それはリーフです。 それ以外の場合は、すべての子の葉が蓄積されます。 最適なシャッフルでは、ルートはすべてのサブツリーの葉を集約することによって自動的に最大限に寄与するため、ルートを特別に処理する必要はありません。
