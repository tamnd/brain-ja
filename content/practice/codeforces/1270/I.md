 ## 解決策
 ## 問題の理解

 次のサイズのトロイダル グリッドが与えられます。$2^k \times 2^k$、各セルには 60 ビット整数が含まれます。 グリッドは水平方向と垂直方向の両方に回り込むため、端を越えて移動すると反対側に戻ります。 このグリッドに加えて、固定パターンも与えられます$F$、これは単なるセットです$t$マークされたセル、$t$奇妙であること。 

1 つの操作は、このパターンをトーラス上の任意の場所に配置し、値を選択することで構成されます。$p$、および XOR 演算$p$パターンで覆われたすべてのセルに。 パターンは変換されるだけなので、すべての操作が正確に影響します$t$固定された相対構成のセル。 

タスクは、そのような操作を使用してグリッド全体をすべてゼロに変換できるかどうかを判断し、変換できる場合は操作の最小数を見つけることです。 

制約の次元は小さい ($k \le 9$、だからせいぜい$512 \times 512$)、ただし値は大きく、最大$2^{60}$。 これは、GF(2) 上のビットごとの線形代数を強く示唆していますが、トーラス上の構造化された畳み込みのような設定に適用されます。 

重要な構造上の制約は、操作が固定マスクの変換であるということです。 それはすぐにグループの畳み込みを示唆します$(\mathbb{Z}_{2^k} \times \mathbb{Z}_{2^k})$。 

単純なアプローチでは、操作を貪欲にまたは直接シミュレートしようとしますが、単一の操作が相関的に多くのセルに影響を与えるため、可能な配置の数は$4^k \le 2^{18}$したがって、配置間の相互作用を列挙することはすでに大規模ですが、XOR 値の選択と組み合わせるとまだ十分ではありません。 

素朴な考え方による微妙な失敗例は、地域の独立性を前提としたときに発生します。 たとえば、セルを行ごとに修正しようとすると、トロイダル依存関係がすぐに壊れてしまいます。 

アイデアの例:```
1 1
1 1
```異なるシフトに配置された 2 セル パターン。 すべての操作で複数の行と列が同時に変更されるため、貪欲な行削除は失敗します。 

主な問題点は、演算が GF(2) 上に線形空間を形成しますが、畳み込み構造によって制約されることです。 

## アプローチ

 各操作でシフトを選択します$(x, y)$そして値$p$、および XOR$p$の翻訳されたコピーのすべてのセルに$F$。 XOR は線形であるため、システム全体を GF(2) 上の線形方程式系として、各ビットごとに個別に見ることができます。$p$。 ビットは相互作用しないので、問題を次のように扱うことができます。$60$独立した二値問題。 

ビットを 1 つ修正します。 各セルは 0 または 1 です。各操作により、サイズの変換されたマスクが追加されます。$t$したがって、各操作は、グリッド位置によってインデックス付けされた GF(2) 上のベクトル空間内のベクトルを追加することに対応します。 各演算の係数は、選択されたビットです。$p$。 

したがって、初期グリッドを、変換されたすべてのコピーの線形結合として表現する必要があります。$F$、選択される翻訳の数を最小限に抑えたいと考えています。 

これはアーベル群の畳み込み基礎問題です。 重要な観察は、次のすべての翻訳のセットが$F$は循環構造を形成するため、畳み込みは 2D ウォルシュ アダマール変換 (グリッド グループの XOR フーリエ変換とも呼ばれます) の下で対角化されます。 

その変換では、畳み込みは点ごとの乗算になります。 各周波数は、周波数ごとに独立した一次方程式になります。$\omega$、すべてのシフトの寄与は、次の変換によってスケーリングされます。$F$で$\omega$。 以来$t$が奇数の場合、変換はすべての周波数で同時に消えることはなく、可解性に必要な可逆性条件が保証されます。 

私たちは問題を、限られた数の「アトム」(操作) を使用して変換されたグリッド値を表現できるかどうかを判断し、選択される非ゼロのシフト係数の数を最小限に抑えることに集約します。 これは周波数ごとの最適化となり、変換空間での反転後に非ゼロ係数をカウントすることになります。 

FFTは終わった$\mathbb{Z}_2^k \times \mathbb{Z}_2^k$は 2D の Walsh-Hadamard 変換であり、$O(n \log n)$と$n = 2^{2k}$。

 ## アルゴリズムのチュートリアル

 XOR は線形であるため、少しずつ作業します。 

1. すべてのグリッド値の 1 ビット位置を抽出し、バイナリ グリッドを生成します。$A$。 後ですべてのビットの結果を合計しますが、各ビットは独立しているため、個別に解決します。 これが必要なのは、各操作がパターン全体で均一なビット値に寄与するためです。 
2. バイナリグリッドを構築する$F$パターン内のセルは 1、その他は 0 です。変換のみが許可されるため、すべての操作はこのマスクをシフトすることに対応します。 
3. 両方の 2D Walsh-Hadamard 変換を計算します。$A$そして$F$。 この変換は、トーラス シフト上の畳み込みを周波数空間にわたる点ごとの乗算に変換します。 
4. 周波数セルごとに$(u,v)$、変換された値を除算します。$A$の変換された値によって$F$GF(2)で。 ビットを超えているため、除算は一貫性のチェックに相当します。$F(u,v)=0$その間$A(u,v)=1$の場合、解決策は存在しません。 その周波数はいかなるシフトによっても生成されないため、これは直接的な障害となります。 
5. 解決可能な場合は、逆変換を計算して係数グリッドを取得します。$C$ここで、各セルは、対応するシフトを適用する回数を表します (実現可能性を考慮して mod 2 ですが、最小化には整数のカウントが重要です)。 
6. 答えは、次の位置の数です。$C$すべてのビットを合計するとゼロ以外になります。 このような各位置は、次の 1 つの操作を実行することに対応します。$p$そのビットが設定されていること。 

### なぜ効果があるのか

 すべての翻訳版のセット$F$トーラス群上の畳み込みで閉じた基底を形成します。 Walsh-Hadamard 変換はこのアクションを対角化し、シフト間のグローバルな依存関係を周波数ごとの独立したスカラー方程式に変換します。 なぜなら$t$が奇数である場合、基本パターンは GF(2) の可逆性に必要な意味で周波数空間で完全にサポートされており、一部のグリッド コンポーネントが到達不能になる縮退消滅を防ぎます。 したがって、再構成ステップは対角線形システムを解くことと等価であり、非ゼロの逆係数の数は、必要とされる独立したシフト活性化の最小数に正確に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def fwht(a):
    n = len(a)
    step = 1
    while step < n:
        for i in range(0, n, step * 2):
            for j in range(step):
                u = a[i + j]
                v = a[i + j + step]
                a[i + j] = u + v
                a[i + j + step] = u - v
        step <<= 1

def solve_bit(grid, pattern, n):
    A = grid[:]
    F = pattern[:]

    fwht(A)
    fwht(F)

    m = len(A)
    res = [0] * m

    for i in range(m):
        if F[i] == 0:
            if A[i] != 0:
                return None
            res[i] = 0
        else:
            res[i] = A[i] // F[i]

    fwht(res)

    for i in range(m):
        if res[i] % 2 != 0:
            res[i] = 1
        else:
            res[i] = 0

    return sum(res)

def main():
    k = int(input())
    n = 1 << k
    g = n * n

    grid = [[0] * g for _ in range(60)]

    for i in range(n):
        row = list(map(int, input().split()))
        for j in range(n):
            val = row[j]
            for b in range(60):
                grid[b][i * n + j] = (val >> b) & 1

    t = int(input())
    pattern = [0] * g
    for _ in range(t):
        x, y = map(int, input().split())
        pattern[(x - 1) * n + (y - 1)] = 1

    ans = 0
    for b in range(60):
        cnt = solve_bit(grid[b], pattern, n)
        if cnt is None:
            print(-1)
            return
        ans += cnt

    print(ans)

if __name__ == "__main__":
    main()
```グリッドは 1D 配列に平坦化され、2D トーラス シフトがサイズのアーベル群にわたる巡回シフトになるようにします。$n^2$。 各ビット層は独立して処理されます。 

FWHT 実装は、XOR 畳み込みの標準バタフライ演算を実行します。 順変換はグリッドとパターンの両方に適用され、周波​​数空間で点ごとに解決されます。 

除算ステップは周波数ごとに実行され、必要な周波数がパターン変換の範囲外にある場合に実行不可能であることが検出されます。 

係数を再構築した後、逆変換によってシフト寄与が回復され、パリティ抽出によってビットごとに必要な演算が最小限に抑えられます。

 ## 特殊なケース

 パターン変換の周波数空間にゼロがある場合、クリティカルなエッジ ケースが発生します。 その状況では、その周波数に非ゼロ投影を持つグリッド コンポーネントを構築することは不可能になります。 アルゴリズムは除算ステップでこれを検出します。この場合、ゼロ以外の変換されたグリッド値とゼロ パターン値のペアが即座に拒否をトリガーします。 

もう 1 つのケースは、パターンが密ではあるが構造化されている場合です。たとえば、1 つのセルを除いて完全なグリッドである場合です。 ほぼ一様であっても、その変換では奇数カーディナリティにより可逆性が保証されており、アルゴリズムは有効な係数分布を再構築し、逆変換後に必要なシフトのまばらなセットを生成します。
