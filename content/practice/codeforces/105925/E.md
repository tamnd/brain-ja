 ## アルゴリズムのチュートリアル

 現在の地位を維持します$X$そして残りのステップ$K$。 重要な考え方は、段階的に進むのではなく、gcd が変化する次のポイントに繰り返しジャンプすることです。 

1. から始める$X = 1$そしてプロセス$K$操作。 
2. コンピューティング$d = \gcd(X, Y)$。 これは現在のステップ サイズです。 もし$d = Y$、システムは安定状態に達しました。$Y \mid X$、そして今後のあらゆる動きは正確に加算されます$Y$。 
3. もし$d = Y$、 アップデート$X = X + K \cdot Y$そしてすぐにやめてください。 これにより、プロセスが線形になったため、それ以上の gcd 計算が回避されます。 
4. それ以外の場合は書き換えます$X = d \cdot a$そして$Y = d \cdot m$。 以来$\gcd(a, m) = 1$、次に gcd が増加するのは、まさにそのときです。$a + t$～の何らかの素因数で割り切れるようになる$m$。 
5. の素因数を事前計算します。$m$。 素数ごとに$p$までに必要なステップ数を計算します。$a + t \equiv 0 \pmod p$、つまり$t_p = (p - a \bmod p) \bmod p$。 
6. 最小の正を取得します$t$そのようなすべての素数の中で。 これが最初の瞬間です$X$の新しい除数構造と一致します。$Y$となり、gcdが増加します。 
7. もし$t > K$、次のフェーズに進むことができません。 アップデート$X = X + K \cdot d$そして終わります。 
8. それ以外の場合は移動します$X = X + t \cdot d$、 減少$K$による$t$を選択し、手順 2 から繰り返します。 

正しさは、gcd が次の場合にのみ変化するという事実に依存します。$X$の新しい素因数で割り切れるようになる$Y$まだ含まれていなかったもの$d$。 そんなイベントの合間に、$\gcd(X, Y)$は一定のままであるため、次の位置合わせポイントに直接スキップすると、プロセスの正確な軌跡が保存されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def factorize(x):
    f = {}
    p = 2
    while p * p <= x:
        while x % p == 0:
            f[p] = 1
            x //= p
        p += 1
    if x > 1:
        f[x] = 1
    return list(f.keys())

def solve():
    Y, K = map(int, input().split())
    X = 1

    primes = factorize(Y)

    while K > 0:
        g = gcd = __import__("math").gcd(X, Y)

        if gcd == Y:
            X += K * Y
            break

        d = gcd
        a = X // d
        m = Y // d

        best = None
        for p in primes:
            if m % p == 0:
                r = a % p
                step = (p - r) % p
                if step == 0:
                    step = p
                if best is None or step < best:
                    best = step

        if best is None:
            X += K * d
            break

        if best > K:
            X += K * d
            break

        X += best * d
        K -= best

    print(X)

if __name__ == "__main__":
    solve()
