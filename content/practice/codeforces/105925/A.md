 ## 解決策
 ## 問題の理解

 私たちには、箱が開いているか閉じているかという 2 つのバイナリ情報、および箱の中の猫の実際の内部状態を含むシステムが与えられています。 

最初の値 C は可観測性を表します。 箱を閉めると猫の様子が外から見えなくなります。 箱を開けるとその様子が丸見えになります。 

2 番目の値 G は、生きているか死んでいるかにかかわらず、猫の実際の内部状態を表します。 ただし、この値が出力に関して意味を持つのはボックスが開いているときのみであり、そのときのみ状態を直接確認できます。 

課題は、外部観察者の視点から猫について何が言えるかを判断することです。 ボックスが閉じている場合、非表示の値に関係なく両方の可能性が有効なままであるため、システムは曖昧なままになります。 箱が開いていれば、観察者は G から猫の生死を直接判断できます。 

入力サイズは一定であり、わずか 2 ビットの情報で構成されているため、一定時間の評価を超える最適化を必要とするアルゴリズムの制約はありません。 直接的なケース分析を超えるアプローチは、不必要なオーバーヘッドとなります。 

よくある間違いは、C に関係なく常に G を信頼することです。たとえば、入力が C = 1 および G = 0 の場合、猫が死んだという誤った出力が発生する可能性があります。 これは間違っています。ボックスが閉じていると、観察者は G にアクセスできないため、両方の結果が区別できないままになります。 

もう 1 つの間違いは、G を完全に無視して、常に曖昧さを出力することです。 たとえば、箱を開けると不確実性が崩壊するため、C = 0 および G = 1 は明確な答えを生成する必要があります。 

## アプローチ

 ブルートフォース解釈は、可観測性の概念を直接シミュレートすることです。ボックスが閉じている場合はシステムの可能な解釈の両方を考慮し、ボックスが開いている場合は 1 つの解釈のみを考慮します。 C = 1 の場合、観察は不可能であるため、猫は潜在的に生きていると同時に潜在的に死んでいるとして扱います。 C = 0 の場合、単純に G を読み取り、対応する状態を出力します。 

この強引な推論は機能しますが、概念的には冗長です。 ボックスが閉じているときの「起こり得る現実」に関する分岐は、G に関係なく常に有効なままであるため、不要です。C が G が読み取り可能かどうかを完全に制御しているという観察により、問題は単純な条件付きルールに縮小されます。 

C が G が重要かどうかのゲートとして機能することを認識すると、問題全体は 2 つの場合の決定に集約されます。

 ## アルゴリズムのチュートリアル

 1. 2 つの整数 C と G を読み取ります。これらはそれぞれ可観測性と隠れ状態を表します。 
2. C が 1 に等しいかどうかを確認します。これは、ボックスが閉じられていることを意味します。 この場合、観測者は G に関係なく生死を区別できないため、出力は不確実性を反映する必要があります。 
3. C が 0 に等しい場合、ボックスは開いているため、隠れた値 G は完全に観察可能になります。 この場合、マップ G は最終的な答えに直接対応します。1 は生存に対応し、0 は死亡に対応します。 
4. 結果の状態文字列を出力します。 

### なぜ効果があるのか

 その正しさは、C が問題を根本的に異なる情報アクセスを持つ 2 つの領域に分割しているという事実から来ています。 C = 1 の場合、どの観測も不確実性を低減できないため、両方の状態が同時に有効な解釈のままになります。 C = 0 の場合、システムは G を完全に明らかにし、出力を決定的とします。 このゲート動作を超えると複数の入力間に相互作用がないため、中間状態が発生することはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    C, G = map(int, input().split())
    
    if C == 1:
        print("vivo e morto")
    else:
        if G == 1:
            print("vivo")
        else:
            print("morto")

if __name__ == "__main__":
    solve()
```この実装では、アルゴリズムで説明されている 2 つのレジームを直接エンコードします。 最初のブランチは、出力が G に関係なく固定されるクローズド ボックスのケースを処理します。2 番目のブランチはオープン ボックスのケースを処理し、G は最終状態の直接検索として使用されます。 これら 2 つの条件を超えるエッジ ケースはなく、追加の正規化や前処理は必要ありません。

## 特殊なケース

 唯一意味のあるエッジの区別は、C が 0 と 1 の間で反転するかどうかです。 

入力の場合:```
1 1
```アルゴリズムはクローズドボックス分岐に入り、すぐに曖昧さを出力し、G を完全に無視します。 これは、明らかに「生きている」内部状態であっても、システムが密閉されている場合には可観測性に影響を与えないことを裏付けています。 

入力の場合:```
0 0
```アルゴリズムはオープンボックス分岐に入り、G を直接読み取ります。 G は 0 であるため、「morto」を出力します。これは、C が観測を許可すると曖昧さが残らないことを示しています。 

どちらの場合も、アルゴリズムが認識論的条件 (C) を問題の中心構造である物理的状態 (G) から正しく分離していることを確認します。
