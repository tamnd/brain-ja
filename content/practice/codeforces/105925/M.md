 ## 解決策
 ## 問題の理解

 1 から N までの位置に配置された整数の配列が与えられます。「パス」は、任意の開始位置を選択し、繰り返し停止するか、厳密に大きなインデックスにジャンプすることによって形成されます。 すべてのステップは右に移動する必要があるため、パスはまさに空ではないインデックスのサブセットであり、昇順に書き込まれます。 

選択したすべてのサブセットについて、それらの位置の値を取得し、その最大公約数を計算します。 その価値を道の美しさといいます。 空でないすべてのサブセットが許可されるため、正確に$2^N - 1$可能なパス。 

タスクは動的です。 2 種類の質問があります。 1 つのクエリは固定整数 X: を要求します。$2^N - 1$サブセット、gcd が X に等しい部分は何ですか。もう 1 つのクエリは、配列内の 1 つの位置を更新します。 

クエリの出力はモジュラー確率であり、有効なサブセットの数を次の値で割った値を意味します。$2^N - 1$、逆モジュラーを使用してモジュロ 998244353 を計算しました。 

制約が大きいため、サブセットを列挙することは不可能です。 と$N$まで$10^5$、クエリごとの線形スキャンでも許容されますが、すべてのサブセットを反復したり、サブセット統計を最初から再計算したりするものは許容されません。 

単純なアプローチでは、すべてのサブセットを列挙して gcd を計算しようとしますが、すでにコストがかかります$2^N$、それは完全に不可能です。 更新後にすべてのサブセットの gcd を繰り返し計算することさえ、限界をはるかに超えています。 

2 番目の素朴なアイデアは、クエリごとに、何かで割り切れる要素に対する包含を使用してすべてのサブセット gcd を再計算することです。ただし、事前計算なしでは、これでも指数関数または少なくとも 2 次の動作に退化します。 

すべての数値が等しい場合、または値が 1 の場合、微妙なエッジ ケースが現れます。そのような場合、gcd 分布は単一の値に向かって大きく崩壊し、単純なカウント方法では空のサブセットを誤って処理したり、スーパーセットを二重にカウントすることで gcd で正確に X のサブセットをカウントしたりすることがよくあります。 

## アプローチ

 主な問題は、配列全体にわたる単一の gcd が要求されるのではなく、更新時にすべてのサブセットにわたる gcd の分散が要求されることです。 

問題を再構成する有効な方法は、視点を逆転させることです。 「各サブセットの gcd はいくらか」を尋ねる代わりに、「固定整数 d について、d で割り切れるすべての要素を持つサブセットがいくつあるか」を尋ねます。 サブセット内のすべての要素が d で割り切れる場合、そのサブセットの gcd も d で割り切れます。 この条件は、d の倍数である配列要素の数にのみ依存するため、数えることは簡単です。 

させて$cnt[d]$d で割り切れる配列要素の数になります。 この場合、d の倍数のみで構成される空でない部分集合の数は次のようになります。$g[d] = 2^{cnt[d]} - 1$。 

サブセットはカウントされるため、これではまだ答えは得られません。$g[d]$gcd が正確には d ではなく、d の倍数であるものも含まれます。 標準的な修正は、約数に対するメビウス反転です。 gcd が正確に X であるサブセットの正確な数は、メビウス関数を使用して包含と除外を交互に行い、X のすべての倍数からの寄与を組み合わせることによって取得されます。 

ブルートフォース動的バージョンでは、すべてが再計算されます。$cnt[d]$すべてのクエリに対して、すべてを評価します$g[d]$そしてすべての答え。 それにはおよその費用がかかります$O(N \cdot A)$クエリごとに、ここで$A$は最大値ですが、遅すぎます。 

重要な改善点は維持することです$cnt[d]$段階的に。 各配列値は、その除数にのみ影響します。 位置が古い値から新しい値に変更されるとき、除数リストに沿ってのみ寄与分を減算および加算します。 までの各番号なので、$10^5$約持っています$O(\sqrt{A})$約数を考慮すると、このアップデートは管理可能です。 

一度$cnt[d]$が維持されているので計算できます$g[d]$O(1)で。 残りの課題は、メビウス和を効率的に解くことです。 事前に計算されたメビウス関数を使用し、X の倍数にわたる寄与を集計します。

 ## アルゴリズムのチュートリアル

 すべての数値のすべての約数を可能な最大値まで前処理し、998244353 を法とする 2 のべき乗も事前計算します。また、メビウス関数も同じ制限まで事前計算します。 

配列を維持します$cnt[d]$、現在の配列内の d で割り切れる要素の数を追跡します。 これから導き出されるのは、$g[d] = 2^{cnt[d]} - 1$。 

更新のために、これらのカウントの一貫性を維持します。 

## アルゴリズムのチュートリアル

 1. 100000 までのすべての数値について、メビウス関数とすべての約数を事前計算します。これにより、係数を毎回再計算する代わりに、後で高速に除数を反復できるようになります。 
2. サブセット数は以下に依存するため、最大 N までの 2 の累乗を事前計算します。$2^{cnt[d]}$。 これにより、クエリ中に累乗が繰り返されることがなくなります。 
3. 初期除数カウントを構築します。 配列要素ごとに$A[i]$、すべての約数 d を反復します。$A[i]$そして増加します$cnt[d]$。 これにより、すべての d が、それによって割り切れる要素の数を正確に追跡することが保証されます。 
4. 定義する$g[d] = 2^{cnt[d]} - 1$。 これは、d で割り切れる数値のみで構成される空でないサブセットの数を表します。 
5. タイプ 2 の更新の場合、古い値と新しい値の約数を反復して更新することにより、古い値の寄与を削除し、新しい値の寄与を追加します。$cnt[d]$それに応じて。 
6. 値 X を求めるクエリの場合、X の倍数にわたるメビウス反転を使用して答えを計算します。X の倍数 k ごとに、$\mu(k/X) \cdot g[k]$。 
7. サブセットの合計で割って正規化します。$2^N - 1$モジュラーインバースを使用します。 

この工事がうまくいく理由は、$g[d]$gcd が正確に d ではなく、d の倍数であるサブセットを過剰にカウントします。 メビウス反転は、除数チェーン全体で寄与を交互にすることにより、オーバーカウントを体系的にキャンセルします。 除数ベースのメンテナンスにより、次のことが保証されます。$g[d]$アップデートしても、最初から再計算しなくても正しいままになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

MAXA = 100000

# Möbius function
mu = [1] * (MAXA + 1)
is_prime = [True] * (MAXA + 1)
primes = []

for i in range(2, MAXA + 1):
    if is_prime[i]:
        primes.append(i)
        for j in range(i, MAXA + 1, i):
            is_prime[j] = False
        for j in range(i, MAXA + 1, i * i):
            mu[j] = 0

for p in primes:
    for j in range(p, MAXA + 1, p):
        mu[j] *= -1

divs = [[] for _ in range(MAXA + 1)]
for i in range(1, MAXA + 1):
    for j in range(i, MAXA + 1, i):
        divs[j].append(i)

def modinv(x):
    return pow(x, MOD - 2, MOD)

N = int(input())
A = list(map(int, input().split()))
Q = int(input())

cnt = [0] * (MAXA + 1)

for v in A:
    for d in divs[v]:
        cnt[d] += 1

pow2 = [1] * (N + 5)
for i in range(1, N + 5):
    pow2[i] = (pow2[i - 1] * 2) % MOD

def g(d):
    return (pow2[cnt[d]] - 1) % MOD

total_subsets = (pow2[N] - 1) % MOD

for _ in range(Q):
    tmp = input().split()
    if not tmp:
        continue
    t = int(tmp[0])

    if t == 1:
        X = int(tmp[1])
        ans = 0
        k = X
        while k <= MAXA:
            ans = (ans + mu[k // X] * g(k)) % MOD
            k += X

        ans %= MOD
        ans = ans * modinv(total_subsets) % MOD
        print(ans)

    else:
        i = int(tmp[1]) - 1
        x = int(tmp[2])

        old = A[i]
        if old == x:
            continue

        for d in divs[old]:
            cnt[d] -= 1
        for d in divs[x]:
            cnt[d] += 1

        A[i] = x
```コア構造は 3 つのアイデアを分離します。 除数リストにより、更新が関連する gcd に寄与するカウンターのみに影響することが保証されます。 の$cnt[d]$array は、配列全体を除数周波数空間に圧縮します。 このクエリでは、倍数に対してメビウス反転を使用し、サブセットのカウント問題を構造化された算術加算に変換します。 

微妙な点の 1 つは、サブセットを明示的に列挙することは決してないということです。 すべては 2 のべき乗でエンコードされ、各除数は、その除数条件の有効なサブセットに参加できる要素の数を個別に追跡します。 

## 実用的な例

 ### サンプル 1

 配列から始めます$[1, 2, 4, 8]$。 除数の数は、各数値の倍数である要素の数を反映します。 たとえば、2 は 2、4、8 としてカウントされ、4 は 4 と 8 としてカウントされます。 

クエリ X = 2 の場合、メビウス値で重み付けされた 2、4、および 8 からの寄与を合計します。 各項は、その要素がすべてその数で割り切れるサブセットをカウントし、メビウス反転により、より大きな約数から過剰カウントが除去されます。 すべてのサブセット構造は 2 の累乗で対称であるため、結果として得られる確率は均一になります。 

X = 3 と X = 5 の場合、これらの値で割り切れる要素はないため、対応するすべての要素は$g[k]$はゼロであり、確率もゼロです。 

### サンプル 2

 初期配列は$[18, 29, 15]$。 29 は素数でそれ自体にのみ寄与するのに対し、18 と 15 は複数の約数に寄与するため、約数の構造は不均等です。 

位置 1 から 25 を更新した後、除数の数はローカルでのみ変更されます。 すべてを再計算する代わりに、18 と 25 の除数の数を調整します。29 を含むサブセットは 25 または 15 を含むサブセットとは独立して動作するため、この更新後のクエリはシフトした分布を反映します。 

これは、更新がサブセット空間全体ではなく、除数集合体のみに影響を与えることを示しています。

 ## 特殊なケース

 すべての要素が等しい場合、重要なエッジ ケースが発生します。 その場合、空でないすべてのサブセットは同じ gcd を持ち、答えの分布はデルタ関数になります。 アルゴリズムはこれを処理します。$cnt[d]$値は、繰り返される値のすべての約数に対して一貫して更新され、すべての値が更新されます。$g[d]$筋の通った。 

もう 1 つのケースは、配列要素を分割しない値 X をクエリする場合です。 それから全部$cnt[d]$X の倍数はゼロのままなので、すべての$g[k]$はゼロであり、合計された確率はゼロです。 これは、寄与を生成しないメビウスの合計によって自然に処理されます。 

最後のエッジ ケースは、同じ位置に同じ値を繰り返し更新することです。 更新ステップはこれを検出し、除数カウントの変更を回避し、正確さを維持し、二重カウントを防ぎます。
