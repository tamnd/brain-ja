 ## 解決策
 ## 問題の理解

 私たちには番号が与えられています$n$。 からすべての整数を書き込むことを想像してください。$1$に$n$シートの上に。 このセットに対して 2 つの独立した操作が実行されます。2 で割り切れるすべての数値は 1 つの色でマークされ、3 で割り切れるすべての数値は別の色でマークされます。 番号には 1 つのマークが付けられる場合もあれば、2 つのマークが付けられる場合もあれば、何も付けられない場合もあります。 

課題は、正確に 1 つのマークを獲得した数字がいくつあるかを数えるということです。 言い換えれば、整数が必要です$[1, n]$2 または 3 で割り切れますが、両方では割り切れません。 

制約$n \le 10^9$すべての数値を反復するアプローチは直ちに除外されます。 リニア スキャンには最大 10 億回の操作が必要ですが、一般的な Codeforce の制限の下では Python では遅すぎます。 実行可能な解決策は、割り算の算術特性を使用して答えを計算する必要があります。 

数値が 2 と 3 の両方で割り切れる場合、微妙な特殊なケースが発生します。たとえば、次のようになります。$n = 6$6 という数字は、2 と 3 の両方で割り切れる場合でも数えるべきではありません。単純に 2 の倍数と 3 の倍数を個別に数える単純なアプローチでは、修正しない限り、そのような数を数えすぎてしまいます。 

## アプローチ

 ブルートフォースアプローチは簡単です。 1 から 1 までのすべての整数を反復処理します。$n$、それぞれが 2 または 3 で割り切れるかどうかを確認し、両方で割り切れないことを確認します。 これは条件を直接エンコードしているため、これは正しいです。 ただし、実行します$n$チェックは、次の場合には実行不可能になります。$n$到達する$10^9$。 

重要な観察は、2 と 3 で割り切れると周期構造が作成されるということです。 2 の倍数は 2 つの数字ごとに、3 の倍数は 3 つの数字ごとに、両方で割り切れる数字は 1 つおきに表示されます。$\mathrm{lcm}(2,3) = 6$。 これにより、反復を等差数列のカウントに置き換えることができます。 

3 つの量を計算します。2 で割り切れる数はいくつありますか、3 で割り切れる数はいくつありますか、両方で割り切れる数はいくつありますか。 次に、包含/除外を適用して、2 つの条件のうちの 1 つで割り切れるものをカウントします。 

最終的な式は次のようになります。$$\#(2 \text{ only}) + \#(3 \text{ only}) = (A + B - 2C)$$どこ$A = \lfloor n/2 \rfloor$、$B = \lfloor n/3 \rfloor$、 そして$C = \lfloor n/6 \rfloor$。

 ## アルゴリズムのチュートリアル

 1. コンピューティング$A = \lfloor n/2 \rfloor$、2 で割り切れる整数の数$[1, n]$。 これは、最初の色を受け取るすべての数値をカウントします。 
2. コンピューティング$B = \lfloor n/3 \rfloor$、3 で割り切れる整数の数$[1, n]$。 これは、2 番目の色を受け取るすべての数値をカウントします。 
3. コンピューティング$C = \lfloor n/6 \rfloor$、2 と 3 の両方で割り切れる整数。これらはまさに両方のマークを取得する数値です。$\mathrm{lcm}(2,3) = 6$。 
4. 最終的な答えを次のように計算します。$A + B - 2C$。 両方で割り切れる各数値は 2 回数えられました。$A + B$、しかし、「正確に 1 つのマーク」セットからそれらを完全に除外したいので、それらを 2 回減算します。 

### なぜ効果があるのか

 内のすべての整数$[1, n]$4 つの素のカテゴリのいずれかに正確に当てはまります: 2 でも 3 でも割り切れない、2 でしか割り切れない、3 でしか割り切れない、または両方で割り切れない。 表現$A + B - 2C$「2 のみ」および「3 のみ」カテゴリの要素に値 1 を割り当て、その他すべての要素に値 0 を割り当てます。 この位置合わせにより、計算された合計が正確に 1 つのマークを持つ数値のカウントと正確に一致することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

A = n // 2
B = n // 3
C = n // 6

print(A + B - 2 * C)
```このコードは、上記で導出された包含/除外式を直接実装します。 整数の除算は完全な倍数を数えているため安全です。 計算は定数時間で行われ、少数の整変数のみを使用します。 

よくある間違いは、オーバーラップの 2 倍を差し引くのを忘れることです。 1 回だけ減算すると、2 と 3 の両方で割り切れる数値は、1 つの有効なマークを与えたかのように数えられますが、ゼロになるはずです。
