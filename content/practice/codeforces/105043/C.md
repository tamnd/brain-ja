 ## 解決策
 ## 問題の理解

 固定整数が与えられます`a`そして間隔`[l, r]`。 数字`x`その間隔からは互換性があると見なされます`a`もし`gcd(a, x) = 1`。 課題は、区間内で互いに素になる整数がいくつあるかを数えるということです。`a`。 

最も顕著な制約は、`l`そして`r`と同じ大きさにすることができます`10^18`。 間隔のエンドポイントは膨大ですが、`a`せいぜい`10^7`。 これは、間隔のサイズに依存するアルゴリズムは不可能であることをすぐに示します。 一定の長さの間隔を反復しても`10^9`すでに遅すぎるのですが、ここでの間隔は大幅に長くなる可能性があります。 

On the other hand, factoring a number up to`10^7`安価です。 トライアル部門まで`√a`必要な反復回数は最大でも約 3162 回ですが、これはごくわずかです。 これは、解が次の素因数にのみ依存する必要があることを示唆しています。`a`、間隔の長さではありません。 

簡単な間違いの 1 つは、重複を修正せずに、すべての素因数の倍数を個別に数えることです。 

例えば、```
a = 6
l = 1
r = 6
```正しい答えは、`2`、なぜなら`1`そして`5`と互いに素である`6`。 単純に次の倍数を引くと、`2`との倍数`3`与える`6 - 3 - 2 = 1`、なぜならその数は`6`2回減算されます。 

もう 1 つのよくある間違いは、すべての素因数を多重度で使用することです。 

例えば、```
a = 12
l = 1
r = 12
```素因数分解は、`2² · 3`、ただし別個の素因数のみ`{2, 3}`案件。 数値が因数を共有するかどうか`2`と`12`回数には依存しない`2`因数分解で出てきます。 

最後のエッジケースは次の場合に発生します。`a = 1`。```
a = 1
l = 10
r = 20
```すべての整数は互いに素です`1`、したがって、答えは次のとおりです`11`。 実際に素因数があるかどうかを確認せずに常に包含/排他を実行する実装では、誤ってゼロが生成される可能性があります。 

## アプローチ

 最も直接的な解決策は、間隔内のすべての整数をチェックします。 それぞれの番号について`x`、計算する`gcd(a, x)`gcd が次の場合は答えを増やします。`1`。 これは、必要なプロパティを正確にテストするため、明らかに正しいです。 

残念ながら、このアプローチは間隔の長さに依存します。 最悪の場合、間隔にはほとんどの値が含まれます。`10^18`数が多いため、単一のパスさえ完全に不可能になります。 

重要な観察は、数値が互いに素にならないということです。`a`正確に、少なくとも 1 つの異なる素因数で割り切れるとき`a`。 個別の素数がわかったら、問題はそれらの素数の少なくとも 1 つで割り切れる範囲内の数を数えることになります。 

区間内の単一の数値の倍数を数えるのは簡単です。 問題は、数値が複数の素因数で同時に割り切れて、二重に数えられる可能性があることです。 これはまさに包含排除原則が適用される状況です。 

以来`a ≤ 10^7`、少数の異なる素因数のみを持つことができます。 最初の 9 つの素数の積はすでに を超えています`10^7`、したがって、最大 8 つの異なる素約数が存在します。 つまり、最大でも`2^8 = 256`サブセットを使用すると、包含と除外が非常に高速になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((r - l + 1) log a) | お(1) | 遅すぎる |
 | 最適 | O(√a + 2^k · k) | O(k) | 承認済み |

 ここ、`k`は、次の異なる素因数の数です。`a`。 

## アルゴリズムのチュートリアル

 1.因数分解`a`トライアル除算を使用し、その個別の素約数のみを保存します。 
2. しましょう`total = r - l + 1`、区間内の整数の数。 
3. 個別の素約数の空でないすべてのサブセットを列挙します。 
4. サブセットごとに、その素数の積を計算します。 すべての因子は別個の素数であるため、この積は単にそれらの最小公倍数になります。 
5. 数字が何個あるか数えます`[l, r]`を使用してこの積で割り切れます```
r // product - (l - 1) // product
```6. サブセットに奇数の素数が含まれている場合は、この数を包含および除外の合計に追加します。 素数が偶数個含まれている場合は、それを減算します。 
7. 包含と除外の合計は、少なくとも 1 つの素因数を共有する整数の数に等しくなります。`a`。 
8. この値をから引きます。`total`。 結果は正確に次の整数の数になります。`a`。 

### なぜ効果があるのか

 区間内のすべての整数は、次の要素と素因数を共有しません。`a`または少なくとも 1 つを共有します。 包含/除外では、少なくとも 1 つの異なる素約数で割り切れる整数が正確にカウントされます。`a`、分割条件間のすべての重複を修正します。 数は互いに素なので、`a`この和集合から除外される場合は、区間サイズから和集合サイズを減算すると正しい答えが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

a, l, r = map(int, input().split())

primes = []
x = a
d = 2
while d * d <= x:
    if x % d == 0:
        primes.append(d)
        while x % d == 0:
            x //= d
    d += 1 if d == 2 else 2
if x > 1:
    primes.append(x)

bad = 0
k = len(primes)

for mask in range(1, 1 << k):
    prod = 1
    bits = 0
    for i in range(k):
        if (mask >> i) & 1:
            prod *= primes[i]
            bits += 1
    cnt = r // prod - (l - 1) // prod
    if bits & 1:
        bad += cnt
    else:
        bad -= cnt

print((r - l + 1) - bad)
```最初の部分は因数分解します`a`異なる素約数のみを保存します。 内側の`while`ループは現在の素数のすべての出現を削除するため、繰り返される因子がリストに表示されることはありません。 

次のセクションでは、ビットマスクを使用して、これらの素数の空でないすべてのサブセットを反復処理します。 各マスクは 1 つのサブセットを一意に表します。 サブセット積は、選択した素数を乗算することによって構築されます。 

間隔カウントでは、閉じた間隔内の倍数をカウントするための標準式が使用されます。 Python の整数には任意の精度があるため、積と区間のエンドポイントは次のとおりです。`10^18`安全に扱われます。 

最後に、包含排他原理に従って、奇数サイズのサブセットが追加され、偶数サイズのサブセットが減算されます。 結果として得られる非素数の数は、区間サイズから削除されて答えが得られます。

import sys, io

def solve():
    a, l, r = map(int, input().split())

    primes = []
    x = a
    d = 2
    while d * d <= x:
        if x % d == 0:
            primes.append(d)
            while x % d == 0:
                x //= d
        d += 1 if d == 2 else 2
    if x > 1:
        primes.append(x)

    bad = 0
    k = len(primes)

    for mask in range(1, 1 << k):
        prod = 1
        bits = 0
        for i in range(k):
            if (mask >> i) & 1:
                prod *= primes[i]
                bits += 1
        cnt = r // prod - (l - 1) // prod
        if bits & 1:
            bad += cnt
        else:
            bad -= cnt

    print((r - l + 1) - bad)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    global input
    input = sys.stdin.readline
    out = io.StringIO()
    old = sys.stdout
    sys.stdout = out
    solve()
    sys.stdout = old
    return out.getvalue()

```素数リストは空であるため、包含-排他ループは反復を実行せず、非共素数のカウントはゼロのままです。 間隔には以下が含まれます`11`数値なので、アルゴリズムは次の値を返します`11`すべての整数が互いに素であるため、これは正しいです。`1`。
