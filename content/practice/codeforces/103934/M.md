 ## 解決策
 ## 問題の理解

 双方向ルートで接続された郵便局のグラフが与えられています。 メッセージはあるオフィスで開始され、単純なパスに沿って別のオフィスに移動し、中間のオフィスごとにメッセージの「マーク」が反転されます。 エンドポイントは特別です。マークは原点でも宛先でも変更されず、内部頂点のみが反転します。 

個別のオフィスの順序付きペアの場合$A, B$、からのすべての可能な単純なパス$A$に$B$には、そのパス上の内部頂点の数に等しい、明確に定義された反転のパリティがあります。 各内部頂点はマークを 1 回だけ反転するため、重要なのは、そこからのすべての可能なパスが存在するかどうかです。$A$に$B$同じパリティを持つか、異なるパスが異なるパリティ結果を生み出すかどうか。 

からのすべてのパスが$A$に$B$最初のマークと同じ最終マークが得られる場合、そのペアはセキュアと呼ばれます。 すべてのパスの結果が反対のマークになる場合、そのペアは安全でないと言われます。 タスクは、安全なノードの順序なしペアがいくつあるか、安全でないノードがいくつあるかをカウントすることです。 

制約は大きく、最大で$10^5$ノードと$10^6$エッジ。 すべてのペアを調べたり、パスを列挙しようとするアプローチは、直ちに実行不可能になります。 ペアごとのトラバーサルを試みるものであってもアウトです。$\Theta(n^2)$ペア。 

微妙な点は、2 つのノード間の複数のルートが重要であるということです。 パリティは最短パスに関連付けられるのではなく、すべての単純なパスに同時に関連付けられるため、単純な最短パスの考え方では不十分です。 サイクルの構造が曖昧さを生み出します。 

典型的な失敗例は、グラフに奇数サイクルが含まれている場合に発生します。 このようなサイクルでは、同じエンドポイント間の 2 つの異なるパスが異なるパリティを持つ可能性があります。次に例を示します。 

入力:```
3 3
1 2
2 3
1 3
```ここで 1 と 3 の間では、1 つのパスは直接 (1-3)、長さ 0 の内部反転で、もう 1 つのパスは 1-2-3 で、1 つの反転が導入されます。 結果は一致しないため、グローバル構造を理解していない限り、すべてのパスから導出される単一のルールの下では、ペアは一貫して安全であることも、一貫して安全でないこともありません。 

本当の難しさは、パリティが一意に決定されるか、常に反対であるかに基づいてペアを分類することです。 

## アプローチ

 ブルートフォースアプローチでは、各ペアが考慮されます。$A, B$そして、それらの間のすべての単純なパスに一貫したパリティがあるかどうかを判断しようとします。 これは、パリティ状態を追跡し、2 つの異なるパリティ値が同じノードに到達するたびに矛盾を検出する DFS または BFS を実行することによって実行できます。 ただし、すべてのペアに対してこれを行うのは不可能です。 パリティ付きの接続性チェックが 1 回でも行われます。$O(n + m)$、それを繰り返します$O(n^2)$ペアが与える$O(n^2 (n+m))$、それは限界をはるかに超えています。 

重要な観察は、エンドポイント間のパリティの一貫性は、接続されたコンポーネントが 2 部構成であるかどうかによって完全に左右されるということです。 接続されたコンポーネントが 2 部構成である場合、すべてのエッジは 2 色にすることができ、2 つのノード間のパス パリティは固定されます。つまり、2 つのノード間のすべてのパスは同じパリティ モジュロ 2 を持ちます。コンポーネントが 2 部構成でない場合は、奇数サイクルが存在し、同じノード間に異なるパリティを持つ 2 つのパスが許可され、ルート全体でパリティが事実上あいまいになります。 

コンポーネントが 2 部または非 2 部に分類されると、各コンポーネント内のすべてのペアの寄与を導き出すことができます。 二部コンポーネントでは、すべてのペアに明確に定義されたパリティ関係があります。つまり、二部パーティション内の 2 つのノード間のパリティ距離に応じて、すべてのペアが一貫して安全であるか、一貫して安全でないかのいずれかになります。 非 2 部コンポーネントでは、奇数サイクルの存在によりパリティの切り替えが可能になり、すべてのペアがルート間で一貫性のない動作を強いられ、全体としてすべてのペアが安全でなくなります。 

したがって、問題は、連結成分を見つけ、二部性をチェックし、それに応じてペアをカウントすることに帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースパスチェック |$O(n^2(n+m))$|$O(n+m)$| 遅すぎる |
 | DSU / BFS 2 部コンポーネント |$O(n+m)$|$O(n+m)$| 承認済み |

 ## アルゴリズムのチュートリアル

 グラフをコンポーネントごとに処理し、各コンポーネントを二部構成であるかどうかに分類します。 

1. 入力エッジからグラフの隣接リストを構築します。 これにより、すべての近傍を線形時間で効率的に走査することができます。 
2. 配列を維持します`color`すべてのノードが無色に初期化されます。 この配列は、接続コンポーネント内の一時的な 2 つのパーティション割り当てを表します。 
3. 未訪問のノードごとに、BFS を開始します。 これにカラー 0 を割り当て、そのコンポーネントを調べます。 トラバース中、エッジに沿って移動するたびに、隣接するエッジに反対の色を割り当てようとします。 隣接するコンポーネントがすでに同じ色を持っている場合、競合を検出し、そのコンポーネントを非二部構成としてマークします。 
4. BFS の実行中に、接続されている各コンポーネントのサイズも追跡します。 これが必要なのは、最終的な答えがコンポーネント内のペアの数に依存するためです。 
5. コンポーネントの BFS が完了したら、コンポーネントが 2 部構成であるかどうかをサイズとともに記録します。 
6. コンポーネントのサイズが 2 部構成の場合$k$、その中のすべての順序なしペアはパリティ制約に従って一貫して動作するため、$\frac{k(k-1)}{2}$セキュアなペアとゼロの非セキュアなペア。 
7. コンポーネントのサイズが 2 部構成でない場合$k$、奇数サイクルによってもたらされるパリティの不一致により、その内部のすべてのペアが安全ではなくなります。$\frac{k(k-1)}{2}$不安定なペア。 
8. すべてのコンポーネントからの寄与を合計し、安全でないペアと安全なペアの合計数を出力します。 

### なぜ効果があるのか

 接続されたコンポーネント内では、コンポーネントにサイクルが含まれている場合に限り、任意の 2 つのノードが複数の可能な単純なパスによってリンクされます。 二部構成とは、まさにすべてのサイクルが均一であることを保証する条件です。 すべてのサイクルが偶数である場合、2 つのパス間の差は偶数である必要があるサイクルを形成するため、2 つのノード間のすべてのパスは同じパリティを持つ必要があります。 これによりパリティがグローバルに修正されるため、すべてのペアの動作が決定的になります。 

奇数のサイクルがある場合、パリティの矛盾が生じます。同じノード間の 2 つのパスを組み合わせると奇数のサイクルが生成され、パリティの一貫性が反転します。 つまり、一貫したパリティ構造を割り当てることができず、「常に同じマーク」対「常に反対のマーク」という概念がそのコンポーネント内のすべてのペアにわたって一律に崩れ、問題の定義ではすべてが安全でないカテゴリに分類されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, m = map(int, input().split())
    g = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u, v = map(int, input().split())
        g[u].append(v)
        g[v].append(u)

    color = [-1] * (n + 1)
    visited = [False] * (n + 1)

    insecure = 0
    secure = 0

    for i in range(1, n + 1):
        if visited[i]:
            continue

        q = deque([i])
        visited[i] = True
        color[i] = 0

        nodes = []
        nodes.append(i)

        bipartite = True

        while q:
            u = q.popleft()
            for v in g[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    visited[v] = True
                    q.append(v)
                    nodes.append(v)
                else:
                    if color[v] == color[u]:
                        bipartite = False

        k = len(nodes)
        pairs = k * (k - 1) // 2

        if bipartite:
            secure += pairs
        else:
            insecure += pairs

    print(insecure, secure)

if __name__ == "__main__":
    solve()
```このソリューションでは、隣接リストを一度作成してから、接続されている各コンポーネントに対して BFS を実行します。 の`color`配列は暫定的な 2 つのパーティションをエンコードします。 パリティの一貫性を維持するために、反転は XOR を使用して行われます。 の`bipartite`flag は、トラバース中に矛盾が発生するかどうかをキャプチャします。 

の`nodes`リストはコンポーネントのサイズを追跡します。 カウンタを維持することもできますが、ノードを明示的に保存すると、複雑さに影響を与えることなく推論とデバッグが簡単になります。 

微妙な点は、競合が見つかったときに BFS をすぐに停止しないことです。 二部性がすでに決定されている場合でも、正しくカウントするためにすべてのノードを確実に検出するために、コンポーネント全体をトラバースします。

 ## 特殊なケース

 最小のエッジ ケースは、単一のノードを持ちエッジのないグラフです。 BFS は正確に 1 つのノードを訪問し、それを二部構成としてマークし、ゼロ ペアを提供します。 出力は正しく行われています$0, 0$。 

より微妙なケースは木です。 ツリーは常に 2 部構成であるため、接続されているすべてのコンポーネントは安全なペアのみを提供します。 BFS は一貫して色を割り当て、競合を検出しないため、答えは正確にツリー コンポーネント内のペアの合計数になります。$k(k-1)/2$。 

三角形などの非 2 部サイクルは、BFS 中に色の競合を検出することで処理されます。 ノードが同じ色の既に着色されたノードに接続しようとすると、`bipartite`フラグは false に設定されており、コンポーネント全体は、必要な分類に一致する安全でないペアのみを提供します。
