 ## 解決策
 ## 問題の理解

 ちょうど 1 つの隣接するペアが奇数の合計を持つように、1 から N までの数値の順列を構築するように求められます。 他の隣接するペアはすべて偶数の合計を持つ必要があります。 

隣接する合計が奇数になるのは、一方の数が偶数で、もう一方の数が奇数の場合のみです。 したがって、この条件は実際には、置換において隣接するものの間でパリティが切り替わる回数を制御することになります。 偶数が奇数の隣にある場所が 1 つだけ必要で、それ以外の隣接する要素は同じパリティを持つ必要があります。 

入力は複数のテスト ケースで構成され、それぞれが値 N を与えます。各 N について、有効な順列を出力する必要があります。 

この制約により、N はテストごとに最大 100,000 まで許可され、合計の合計は最大 100,000 になります。これは、テスト ケースごとに O(N) の構築が必要であることを意味します。O(N log N) のようなものを多くのテストにわたって繰り返すことは問題ありませんが、不要であり、強引な並べ替えは不可能であるためです。 順列空間は階乗であるため、バックトラッキングまたは検索ベースの構築はすぐに失敗します。 

パリティのグループ化について考えると、微妙な問題が発生します。 偶数と奇数を分離すると、各グループ内ではすべての隣接する合計が自動的に偶数になります。 危険な場所は偶数ブロックと奇数ブロックの境界だけです。 これは、順列の構造がこれらのパリティ ブロックをどのように連結するかによって完全に制御されることを直ちに示唆しています。 

N が小さい場合は、エッジ ケースが表示されます。N = 2 の場合、実現可能性を明示的に確認する必要があります。 唯一の置換は [1,2] と [2,1] で、両方とも 1 つの隣接するペアを生成し、そのペアは奇数 + 偶数 = 奇数の合計であるため、条件が成立します。 N = 3 の場合、混合パリティ隣接を 1 つだけ分離できることを確認する必要があります。これも可能ですが、正しい配置が必要です。 

単純なアプローチでは、ランダムな順列または貪欲なスワップを試行しますが、グローバル パリティ構造を強制しないと、複数の奇数和隣接関係が簡単に生成されてしまいます。 

## アプローチ

 強引なアイデアは、順列を生成して条件をチェックすることです。 これは、1 から N までのすべての順列を列挙し、隣接関係の合計を検証することで機能します。 検証は O(N) ですが、N があります。 したがって、N = 10 であっても実行不可能になります。 探索空間はすぐに爆発します。 

重要な観察は、パリティ構造が状態を完全に決定するということです。 すべての偶数またはすべての奇数の連続ブロック内では、隣接するすべての合計は偶数になります。 奇数の合計を得る唯一の方法は、偶数の隣に奇数を置くことです。 したがって、奇数ブロックと偶数ブロックの間には境界が 1 つだけ必要です。 

すべてのオッズとすべての偶数をグループ化する場合、ブロックを 1 回連結すると、通常はちょうど 1 つの境界が得られます。 ただし、ブロック内の順序に注意しないと、パリティを混合する場合にのみ誤って追加の遷移が導入される可能性がありますが、ブロック内で混合することはないため、パリティの変更の数は正確に 1 つです。 

したがって、その構造は、奇数と偶数を別々に順序付けし、それらを一方向に連結することになります。 内部順序は機能します。 最も単純なのは昇順です。 

また、条件に違反するような形でどちらのブロックも空でないことを確認する必要があります。 N = 1 が制約により無関係で、N ≥ 2 の場合、両方のパリティ セットが空ではないため、連結は常に有効です。

 ## アルゴリズムのチュートリアル

 パリティ分離を使用して順列を構築します。

1. 1 から N までの数値を奇数と偶数の 2 つのシーケンスに分割します。 これによりパリティが分離されるため、奇数と偶数の隣接関係が発生する場所を制御できるようになります。 
2. すべての奇数を昇順に出力します。 このセグメント内では、奇数 + 奇数は常に偶数であるため、隣接するすべての合計は偶数になります。 
3. すべての偶数を昇順に出力します。 同様に、偶数内では、隣接するすべての合計が偶数になります。 
4. オッズの後に偶数を連結します。 
5. これにより、最後の奇数と最初の偶数の間に境界が 1 つだけ作成されます。 この境界は奇数 + 偶数であるため、正確に 1 つの奇数和に寄与します。 

なぜ効果があるのか

 奇数セグメント内と偶数セグメント内のすべての隣接ペアは等しいパリティ エンドポイントを持っているため、それらの合計は常に偶数になります。 異なるパリティを接続する唯一の隣接関係は、2 つのセグメント間の単一の境界です。 この構築ではそのような境界が 1 つだけ作成されるため、条件は 1 回だけ満たされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    
    odds = []
    evens = []
    
    for i in range(1, n + 1):
        if i % 2:
            odds.append(i)
        else:
            evens.append(i)
    
    res = odds + evens
    print(*res)
```このソリューションは、パリティに基づいて 2 つのリストを明示的に構築することで機能します。 1 から N までのループは線形であり、各数値は奇数または偶数に分類されます。 連結はテスト ケースごとに 1 回行われます。 

重要な実装の詳細は、2 つのリストを決してインターリーブしないことです。 インターリーブを行うと、複数の奇数と偶数の隣接関係が発生する危険があり、要件に違反します。 それらを別々にしておくことで、単一の遷移点が保証されます。 

## 実用的な例

 ### 例 1

 入力:

 N = 7

 私たちは以下を構築します:

 | ステップ | オッズ | 偶数 | 結果 |
 | --- | --- | --- | --- |
 | 1 | [1,3,5,7] | [] | [] |
 | 2 | [1,3,5,7] | [2,4,6] | 1 3 5 7 2 4 6 |

 最終的な順列: 1 3 5 7 2 4 6

 7 と 2 の間の隣接のみが奇数 + 偶数であり、1 つの奇数の和が生成されます。 

### 例 2

 入力:

 N = 6

 | ステップ | オッズ | 偶数 | 結果 |
 | --- | --- | --- | --- |
 | 1 | [1,3,5] | [2,4,6] | 1 3 5 2 4 6 |

 最終的な順列: 1 3 5 2 4 6

 混合隣接関係は 5 と 2 の間のみです。 

これにより、N に関係なく、この構築によりパリティ遷移が 1 つだけ作成されることが確認されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    input = _sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        odds = []
        evens = []
        for i in range(1, n + 1):
            if i % 2:
                odds.append(i)
            else:
                evens.append(i)
        res = odds + evens
        out.append(" ".join(map(str, res)))
    return "\n".join(out)

# provided sample
assert run("1\n7\n") == "1 3 5 7 2 4 6"

# minimum size
assert run("1\n2\n") in ["1 2", "2 1"]

# small case
assert run("1\n3\n") in ["1 3 2", "3 1 2", "1 3 2"]

# even N
assert run("1\n6\n") == "1 3 5 2 4 6"

# multiple tests
assert run("2\n4\n5\n") != ""

 ## 特殊なケース

 N = 2 の場合、アルゴリズムはオッズ = [1]、偶数 = [2] を生成するため、出力は [1,2] になります。 唯一の隣接関係は 1 + 2 であり、これは奇数であるため、この条件は 1 回だけ当てはまります。 

N = 3、オッズ = [1,3]、偶数 = [2] の場合、出力は [1,3,2] になります。 隣接する合計は 1+3 = 偶数、3+2 = 奇数であり、有効なインデックスが 1 つだけ与えられます。 

N = 1 は制約により許可されていないため、特別な処理は必要ありません。 

より大きな N のすべてについて、構造は同一のままです。単一のパリティ境界により、正確に 1 つの奇数和隣接が保証され、内部ブロックは違反を引き起こしません。
