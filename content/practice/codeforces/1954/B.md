 ## 解決策
 ## 問題の理解

 「美しい」ことが保証された整数の配列が与えられています。これは、特定の操作を通じて、最終的にはすべての要素が同じになる可能性があることを意味します。 この操作により、境界にない要素を選択し、隣接要素が等しい場合は隣接する値に置き換えることができます。 私たちの目標は、この操作を使用して残りの要素をすべて等しくすることが不可能になるように、配列から削除する必要がある要素の最小数を決定することです。 どの除去もそれを達成できない場合は、-1 を返します。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは配列サイズを提供します`n`そして配列要素。 配列サイズは最大 300,000 であり、`n`すべてのテスト ケースでは 300,000 を超えないため、アルゴリズムはテスト ケースごとにおよそ O(n) で実行する必要があります。 これにより、すべての削除を試行したり、すべての操作をシミュレートしようとしたりする総当りシミュレーションは除外されます。これは、二次関数またはそれ以上の複雑さになる可能性があるためです。 

明らかではないエッジケースは、配列がすでに均一である場合に発生します。`[1, 1, 1]`。 数値を削除しても美しさは損なわれないため、出力は -1 になるはずです。 もう 1 つの微妙なケースは、配列が 2 つの数値を交互に繰り返す場合です。たとえば、`[1, 2, 1, 2, 1]`。 ここで、慎重に選択した要素を削除すると構造が壊れる可能性があり、削除は 1 つだけで十分な場合があります。 ブロックが繰り返される配列。`[3, 3, 3, 5, 3, 3, 3]`、最小の除去を決定するには、同一の数値間の最大ギャップをカウントする必要があります。 

## アプローチ

 ブルートフォース手法では、すべての要素を反復処理し、要素の削除を試み、均一な配列に到達するか到達しないまで操作をシミュレートします。 これは文字通りすべての可能性をテストするため、原理的には正しいですが、遅すぎます。 長さ n の配列の場合、各要素を削除して演算をシミュレートすると、最悪の場合 O(n^2) がかかる可能性があります。n が 3 × 10^5 になる可能性がある場合、これは許容できません。 

重要な観察は、少なくとも 1 つの異なる数値によって次の同一の要素から分離されている、繰り返される要素の「ブロック」が存在する場合、配列は美しくなくなるということです。 より具体的には、個別の値ごとに、その値が出現する位置を記録し、連続する値の間の距離を調べることができます。 ギャップが 2 を超える場合、そのギャップ内の要素を削除すると、一連の操作が中断される可能性があります。 特定の値に必要な削除の最小数は次のとおりです。`(gap - 2)`最大のギャップを求めてから、すべての値の最小値を取得します。 

この洞察により、問題は操作のシミュレーションから単純なカウントとギャップ分析に軽減され、辞書または位置のリストを使用して配列ごとに O(n) で実行できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O(n^2) | O(n) | 遅すぎる |
 | ギャップ分析 / カウント | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして配列`a`。 
3. 配列が均一 (すべての要素が同じ) の場合は、要素を削除しても美しさが損なわれないため、すぐに -1 を出力します。 
4. 辞書の初期化`positions`各値のインデックスのリストを保存します。 
5. 配列を反復処理し、各インデックスを対応するリストに追加します。`positions`。 
6. の各値について`positions`、連鎖を断ち切るために必要な除去の最大数を計算します。 

1. 配列の先頭から最初の出現箇所までの距離、および最後の出現箇所から配列の末尾までの距離を暗黙のギャップとみなします。 
2. この値の連続するインデックスについては、次のようにギャップを計算します。`(current index - previous index - 1)`。 これは、オカレンスを分離するために削除できる要素の数を表します。 
3. 最大値を追跡する`(gap)`連続するすべての発生にわたって。 
7. アレイ全体の最小除去は、次の最小値です。`(maximum gap - 1)`すべての異なる値にわたって。 の`-1`これは、シーケンスを分割するにはギャップの長さより 1 つ少ない値を削除するだけで十分であるという事実から来ています。 
8. 各テスト ケースに対してこの最小値を出力します。 

**機能する理由**: この操作は、同一の近傍がある場合にのみ要素の値を伝播します。 繰り返し要素の最大ギャップを壊すことにより、配列を均一にするのに十分な長さの置換シーケンスが存在しないことが保証されます。 すべての値をチェックすることで、すべての潜在的な伝播チェーンを確実に考慮します。 このアルゴリズムは、実際に伝播を妨げる要素のみを削除します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def min_removals_to_make_ugly(n, a):
    if all(x == a[0] for x in a):
        return -1

    positions = {}
    for idx, val in enumerate(a):
        if val not in positions:
            positions[val] = []
        positions[val].append(idx)
    
    min_remove = float('inf')
    for val, inds in positions.items():
        gaps = []
        # gap from start to first occurrence
        gaps.append(inds[0])
        # gaps between consecutive occurrences
        for i in range(1, len(inds)):
            gaps.append(inds[i] - inds[i-1] - 1)
        # gap from last occurrence to end
        gaps.append(n - 1 - inds[-1])
        max_gap = max(gaps)
        # need to remove at least max_gap elements to break propagation
        min_remove = min(min_remove, max_gap)
    return min_remove

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(min_removals_to_make_ugly(n, a))
```このソリューションでは、まず配列が均一かどうかをチェックします。これは高速な O(n) チェックです。 次に、各値の位置を収集してギャップを計算します。 境界にギャップを追加することで、シーケンスの開始と終了が正しく処理されます。 の`max(gaps)`伝播する可能性のある最大のチェーンを確実にターゲットにし、`min`すべての値にわたって、美しさを損なうために必要な削除が最小限に抑えられます。

 | 1 | 2 | {2:[1]} | ギャップ: [1,3] | 3 |
 | 3 | 2 | {2:[1,3]} | ギャップ: [1,1,1] | 1 |
