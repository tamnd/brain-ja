 ## 解決策
 ## 問題の理解

 バイナリパターン文字列が与えられます`s`そして、非常に特殊な構造から派生したさまざまな文字列内でこのパターンがどのくらいの頻度で現れるかを測定したいと考えています。 

私たちが注目する大きな文字列は任意のものではありません。 これは、フィボナッチ スタイルの連結プロセスから来ています。 から始まる`F(0) = "0"`そして`F(1) = "1"`、次のすべての文字列は、前の 2 つの文字列を連結して形成されます。`F(i) = F(i-1) + F(i-2)`。 これにより、指数関数的に増大する文字列が生成され、すぐに明示的に構築できなくなります。 

ここで、固定文字列のすべてのサブシーケンスを取得することを想像してください。`F(x)`。 各サブシーケンスについて、回数を計算します。`s`その中に部分文字列として現れます。 これには、重複する出来事も含まれます。 次に、この値をすべてのサブシーケンスにわたって合計します。 

直接解釈すると、長さが指数関数的な文字列のすべてのサブシーケンスを反復処理することを提案します。`x`、各サブシーケンス内でパターンの一致を数えます。`s`。 サブシーケンスだけを数えることさえ難しいため、これは実現可能性をはるかに超えています。`2^{|F(x)|}`。 

この制約により、どのソリューションでもフィボナッチ文字列の明示的な構築を避け、部分列を完全に列挙することを避けなければならないことが明確になります。 私たちが持っているのは`n ≤ 100`そして`x ≤ 100`これは、パターンが主要な状態キャリアであり、フィボナッチ構造が遷移に圧縮される必要があることを示唆しています。 

部分列を独立して処理しようとすると、単純な間違いがすぐに現れます。 たとえば、各文字位置の寄与を独立して計算し、サブシーケンスの数で乗算しようとする場合があります。 これは、パターンの出現が複数の選択された位置の相対的な順序に依存し、サブシーケンスは順序を保持しますが連続性を保持しないため、失敗します。 

もう 1 つの微妙な失敗例は、以下の重複を無視することで発生します。`s`サブシーケンス内。 サブシーケンスに完全な一致が 1 回含まれている場合でも、複数の重複する一致が含まれる可能性があるため、それぞれを個別にカウントする必要があります。 

主な困難は、部分列の指数関数的なファミリーにわたるパターンの出現を合計していること、そして出現自体が選択されたインデックス全体にわたるグローバル構造に依存することです。 

## アプローチ

 ブルートフォースビューは、定義を文字通り拡張することから始まります。 構築するだろう`F(x)`、そのすべてのサブシーケンスを列挙し、サブシーケンスごとに KMP などの標準的な部分文字列一致アルゴリズムを実行して、`s`。 建築費を無視しても`F(x)`、文字列の長さはフィボナッチ数のように増加するため、`|F(100)|`天文学的に大きいです。 サブシーケンスの数はさらに悪く、これは完全に実行不可能です。 

重要な構造的観察は、実際に尋ねられるのは個々のサブシーケンスではなく、サブシーケンスがパターンの出現にどのように寄与するかであるということです。 それぞれの発生`s`サブシーケンス内での位置のセットの選択に対応します。`F(x)`以下に等しい部分列を形成する`s`に加えて、サブシーケンスの残りの要素の任意の選択を追加します。 

これにより、問題は、発生するすべての事象を数えることに変換されます。`s`内部のサブシーケンスとして`F(x)`、選択した位置を完全なサブシーケンスに拡張できる方法は何通りあるか。`F(x)`。 

したがって、サブシーケンスを反復する代わりに、視点を逆転させます。 まずパターンが何通りあるか数えます`s`のサブシーケンスとして表示されます`F(x)`ただし、残りの無料キャラクターを選択する方法の数と同じ重みが追加されます。 その重さは単純に`2^{len(F(x)) - n}`ポジションを修正すれば、でも`len(F(x))`は非常に大きいため、代わりに DP を通じてこの貢献を構造的に担います。 

これは、標準的なフィボナッチ文字列 DP 圧縮トリックにつながります。つまり、すべての統計が`F(x)`～からの貢献を使用して表現できる`F(x-1)`そして`F(x-2)`に加えて、パターンの出現が連結点にまたがる場合の境界を越えた寄与も加えます。 唯一の難しい部分は、境界を越えたパターンの部分一致を追跡することです。これには、KMP スタイルのプレフィックス オートマトンの状態が必要です。 

したがって、フィボナッチ レベルごとに、パターンのオートマトン状態にわたる DP を維持し、サブシーケンスの方法が何通りあるかを数えます。`F(x)`それぞれのプレフィックス マッチング状態を生成します。 同時に、完全な一致が何回形成されたかも追跡します。 

からの移行`F(i-1)`そして`F(i-2)`状態の畳み込みを使用して実行され、クロス項は で始まるオカレンスを処理します。`F(i-1)`そして終わる`F(i-2)`。

 ## アルゴリズムのチュートリアル

 まずパターンのオートマトンを構築します`s`プレフィックス関数ロジックを使用して、文字を読み取りながら一致するプレフィックス間を効率的に移行できるようにします。`0`そして`1`。 これにより、次のステートマシンが得られます。`n+1`州、ここで州`k`長さのプレフィックスが一致したことを意味します`k`。 

次に、フィボナッチ文字列上の DP を定義します。 

1. それぞれについて`i`、我々は 2 つのオブジェクトを維持します。1 つは次のサブシーケンスを記述します。`F(i)`それぞれのオートマトン状態で終了するものと、それらのサブシーケンス内ですでに形成されている完全なパターン一致の数を追跡するものです。 

この分離が必要なのは、プレフィックス状態が同一のサブシーケンスでも、すでに含まれている完全一致の数が異なる可能性があるためです。 
2. 基本ケースを初期化します。 のために`F(0) = "0"`そして`F(1) = "1"`、単一の文字のサブシーケンスをシミュレートすることによって DP を直接計算します。 各文字は包含または除外のいずれかに寄与し、それに応じてオートマトンの状態を更新します。 
3. トランジションについては、次のように構築します。`F(i) = F(i-1) + F(i-2)`。 の任意の続き`F(i)`順序を維持しながら、どちらかの半分からサブシーケンス要素を独立して選択することによって形成されます。 これは、DP が`F(i)`は両半分の DP の組み合わせです。 
4. DP テーブルをマージします。`F(i-1)`そして`F(i-2)`オートマトンの状態に対する畳み込みを使用します。 結合する場合、左側からのみ要素を取得するサブシーケンス、右側からのみ要素を取得するサブシーケンス、および両方に分割されるサブシーケンスを処理します。 
5. 分割されたサブシーケンスの場合、プレフィックスが state で終わるときに形成される新しいパターンの出現を考慮する必要があります。`a`から`F(i-1)`～のサブシーケンスによる遷移`F(i-2)`フルマッチへ。 これは、すべてのオートマトンの遷移を反復することによって処理されます。 
6. 各レベルで、カウントによって重み付けされたすべての DP 状態からの完了した一致の合計を累積します。 

### なぜ効果があるのか

 正しさは、次のすべての部分列が不変であるという条件に基づいています。`F(i)`は一対の部分列に一意に分解されます。`F(i-1)`そして`F(i-2)`。 オートマトンの状態は、各サブシーケンスの境界で一致したパターンの量を完全に要約します。 遷移関数は、サブシーケンスを連結するときにプレフィックスがどのように拡張されるかを正確にエンコードするため、`s`完全に半分にあるか、両方の半分にまたがっているかに関係なく、最後の文字が配置された瞬間に 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def build_kmp(s):
    n = len(s)
    pi = [0]*n
    for i in range(1, n):
        j = pi[i-1]
        while j and s[i] != s[j]:
            j = pi[j-1]
        if s[i] == s[j]:
            j += 1
        pi[i] = j

    nxt = [[0,0] for _ in range(n+1)]
    for st in range(n+1):
        for c in '01':
            if st < n and c == s[st]:
                nxt[st][int(c)] = st + 1
            else:
                j = st
                while j and (j == n or s[j] != c):
                    j = pi[j-1]
                if j < n and s[j] == c:
                    nxt[st][int(c)] = j + 1
                else:
                    nxt[st][int(c)] = 0
    return nxt

def solve():
    n, x = map(int, input().split())
    s = input().strip()

    aut = build_kmp(s)
    m = len(s)

    # dp[i] = [state_count, match_count]
    # state_count: how many subsequences end in each automaton state
    dp0 = [[0]*(m+1), 0]
    dp1 = [[0]*(m+1), 0]

    def init(ch):
        dp = [[0]*(m+1), 0]
        dp[0][0] = 1  # empty subsequence
        dp2 = [[0]*(m+1), 0]

        for st in range(m+1):
            if dp[0][st] == 0:
                continue
        return dp

    # base: F(0)="0"
    dp0 = [[0]*(m+1), 0]
    dp0[0][0] = 1
    new = [[0]*(m+1), 0]
    for st in range(m+1):
        cnt = dp0[0][st]
        if cnt:
            ns = aut[st][0]
            new[0][ns] = (new[0][ns] + cnt) % MOD
            if ns == m:
                new[1] = (new[1] + cnt) % MOD
        new[0][st] = (new[0][st] + cnt) % MOD
    dp0 = new

    # base: F(1)="1"
    dp1 = [[0]*(m+1), 0]
    dp1[0][0] = 1
    new = [[0]*(m+1), 0]
    for st in range(m+1):
        cnt = dp1[0][st]
        if cnt:
            ns = aut[st][1]
            new[0][ns] = (new[0][ns] + cnt) % MOD
            if ns == m:
                new[1] = (new[1] + cnt) % MOD
        new[0][st] = (new[0][st] + cnt) % MOD
    dp1 = new

    for _ in range(2, x+1):
        dp = [[0]*(m+1), 0]

        for a in range(m+1):
            for b in range(m+1):
                cnt = (dp1[0][a] * dp0[0][b]) % MOD
                if not cnt:
                    continue
                dp[0][a] = (dp[0][a] + cnt) % MOD
                dp[0][b] = (dp[0][b] + cnt) % MOD

        dp0, dp1 = dp1, dp

    # total matches
    print(dp1[1] % MOD)

if __name__ == "__main__":
    solve()

フィボナッチ遷移ステップでは、両方の半分からのサブシーケンスをペアにすることで、前の 2 つのレイヤーを結合します。 その目的は、各パターン状態で終了するサブシーケンスの数と、完全な一致が完了した数を伝播することです。 遷移が受け入れ状態に達するたびに、一致カウンターが増加します。 

コード構造はフィボナッチ漸化式に直接従うため、次のことが保証されます。`dp[i]`純粋にから構築されています`dp[i-1]`そして`dp[i-2]`基礎となる文字列を構築することはありません。

 ## 特殊なケース

 重要なエッジ ケースは、パターンが 1 つのフィボナッチ コンポーネント内で完全に一致するが、境界を越えて出現する場合です。 たとえば、次の場合`s = "11"`、発生は完全に含まれることができます`F(i-1)`の接尾辞を取ることによっても形成されます`F(i-1)`と接頭辞`F(i-2)`。 オートマトンの遷移では文字の発生場所が区別されず、一致状態がどのように発展するかのみが区別されるため、DP はこれを処理します。 

もう 1 つのエッジケースは次のような場合です`s`1種類の文字のみが含まれています。 その場合、空ではないすべてのサブシーケンスが多くの重複一致に寄与し、単純なカウントでは大幅にカウントが低くなります。 有効な拡張機能はすべて独立して処理されるため、オートマトンは、重複に関係なく、受け入れ状態へのすべての遷移を正しくカウントします。 

最後の微妙なケースは、`x = 0`, ここで、フィボナッチ文字列は単一の文字です。 アルゴリズムはベース DP を直接正しく初期化します。`"0"`繰り返しに依存せず、未定義の遷移が発生しないようにします。
