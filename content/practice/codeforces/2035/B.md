 ## 問題の理解

 長さの最小の小数を構築するように求められます$n$数字だけで構成されているもの$3$そして$6$、両方で割り切れるように$33$そして$66$。 入力により、いくつかのテスト ケースが得られます。$t$、および各テスト ケースの正の整数$n$数値の必要な長さを表します。 出力は条件を満たす最小の数値である必要があります。または$-1$そのような番号が存在しない場合。 

割り算の制約により、問題は数論的な性質に帰着します。 で割り切れる数$66$両方で割り切れる必要があります$2$そして$3$、したがって、によっても$6$。 による割り算$33$で割り切れる必要があります$3$そして$11$。 私たちの番号にはのみが含まれているため、$3$と$6$s、それは常に次のように割り切れます。$3$したがって、実際の制約は次のように割り切れます。$11$そしてによって$2$。 による割り算$2$最後の桁が次である必要があります$6$、 以来$3$奇数です。 による割り算$11$交互の数字の合計が次の倍数である必要があります。$11$。 

の制約$n$控えめです:$1\le n\le 500$そして$1\le t\le 500$したがって、線形の解決策は$n$テストケースごとに許容されます。 エッジケースには非常に小さなケースが含まれます$n$数値が存在できない場合、たとえば$n=1$、および交互の合計条件が数字で満たされない長さ$3$そして$6$。

 素朴なアプローチは、長さのすべての数値を生成することです。$n$数字付き$3$そして$6$、それらを並べ替えて、それぞれが割り切れるかどうかをチェックします$66$そして$33$。 候補者数は、$2^n$、これは不可能です$n$と同じくらい大きい$500$。 この方法は原理的には正しいですが、指数関数的に変化します。$n$、実用的ではありません。

 ## アルゴリズムのチュートリアル

 1. もし$n=1$または$n=3$、すぐに戻ります$-1$、1 桁または 3 桁の組み合わせがないため、$3$と$6$s は次で割り切れます$33$そして$66$。 これらは、直接チェックから派生した小さな特殊なケースです。 
2. のために$n\ge 2$、数字は次で終わる必要があることに注意してください。$6$～によって割り算を満たす$2$。 これにより最後の桁が固定され、交互の合計モジュロが簡素化されます。$11$計算。 
3. しましょう$k$を超えない最大の偶数であること$n$そのような$k$最後の$n-1$桁は次のように設定できます$6$そして残りは$3$～によって割り算を満たす$11$。 これは、次の数を最大化することと同じです。$3$s を前面に置きながら、交互の和モジュロを確保します。$11$はゼロです。 
4. を配置して数値を作成します。$n-k-1$ $3$最初に、次に$k$ $6$s に続けて最後のものを追加します$6$。 これにより最小性が保証されます。$3<6$、だから配置$3$s をできるだけ左にすると、最小の 10 進数が生成されます。 
5. 構築された数値を返します。 適切なものがない場合$k$存在します（例：$n=1$または$3$）、 戻る$-1$。 

なぜ機能するのか: 交互和モジュロ$11$条件はパーティションを一意に決定します$3$と$6$s を位置間で固定し、最後の桁を次のように固定します。$6$で割り切れる$2$。 左から右に構築する$3$s 最初に最小値を保証します。 各テスト ケースは独立して処理され、構築は決定的です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        if n == 1 or n == 3:
            print(-1)
            continue
        
        # Determine number of 6s in the middle to satisfy divisibility
        six_count = 0
        while six_count <= n and (n - six_count) % 2 != 0:
            six_count += 1
        
        if six_count > n:
            print(-1)
        else:
            threes = n - six_count - 1
            result = '3'*threes + '6'*six_count + '6'
            print(result)

solve()
```最初の部分は入力を読み取り、エッジケースを処理します。$n=1$そして$n=3$。 ループは次の数を計算します。$6$決勝戦の前に順位を上げる$6$で割り切れることを保証する$11$。 残りの数字は次のように埋められます。$3$s. 配置することでミニマルさを確保した構造$3$まず。 最後の桁を個別に注意深く考慮することで、1 つ違いの間違いが回避されます。
