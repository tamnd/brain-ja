 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、根を張った木です。`n`ノード。それぞれが初期の非負値を保持します。 タスクは、ノードに固定の循環順序で適用される操作を使用して、すべてのノード値をゼロに減らすことです。`n`操作はノード 1 ～ に適用されます。`n`順番に、後続の操作がこのサイクルを繰り返します。 各操作により、その操作に対応するノードのサブツリー内の任意のノードの値を増加または減少させることができます。 

入力では複数のテスト ケースを指定し、それぞれのテスト ケースでノード数、ルート、初期ノード値、ツリー エッジを指定します。 出力は、すべてのノード値をゼロにするために必要な操作の最小合計数、または`-1`それが不可能な場合。 ノード値は次のように大きくできるため、`10^9`ツリーには最大で次のものを含めることができます`2000`ノードの場合、操作の単純な総当たりシミュレーションは非常に遅すぎます。 ツリー構造を効率的に使用して最小限の演算を計算するアプローチが必要です。 

明らかではないエッジ ケースには、ルート ノードの値がそのすべての子の合計より大きい状況が含まれます。これにより、ツリーをゼロにすることが不可能になる可能性があります。または、ノード値がすでにゼロであり、この場合は操作が必要ありません。 ツリーが線形である場合、別の注意が必要なシナリオが発生します。すべての操作にはサブツリーの選択肢が 1 つしかなく、カウントに誤りがあると操作数が増大する可能性があります。 

## アプローチ

 ブルート フォース ソリューションでは、許可されたサブツリー内のノードをデクリメントまたはインクリメントしながら、各操作を段階的にシミュレートします。 正しいとはいえ、このアプローチは次まで繰り返す必要があります。`sum(a_i)`に達する可能性がある`2 * 10^12`最悪の場合、単一のテスト ケースでは計算上実行不可能になります。 

最適なソリューションの重要な観察は、ノードでの各操作がそのノードをルートとするサブツリーに影響を及ぼし、一連の操作がすべてのノードを循環するということです。 演算モジュロを考慮すると`n`、各ノードがその親にどれだけの「余剰」または「欠損」を寄与するかを計算できます。 ポストオーダートラバーサルを使用すると、必要な調整をリーフからルートまで伝播し、各サブツリーのバランスを取るために必要な最小限の操作数を追跡できます。 

個々の操作をシミュレートする代わりに、ノードごとに 2 つの値、つまり正の超過を補償するために必要な増分数と負の超過に必要な減分数を計算できます。 親ノードはこの不均衡を吸収し、操作の合計数はすべてのノードの合計になります。 これにより、潜在的に指数関数的なシミュレーション問題が、単純な算術による線形探索に変換されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * max(a_i)) | O(n) | 遅すぎる |
 | 最適 | テスト ケースあたり O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、ツリー構造と初期ノード値を解析します。 DFS トラバーサルを容易にするために隣接リストを構築します。 
2. 各ノードに対して、その子からの演算の純余剰を再帰的に計算する DFS 関数を定義します。 純余剰は、サブツリーに必要なプラスまたはマイナスの調整の合計です。 
3. 各ノードで、すべての子からの調整を組み合わせます。 現在のノードに値がある場合`v`、親への貢献度は、`v`そしてその子供の剰余金の合計。 これは、現在のノードがサブツリーのバランスをとるために上から必要とする操作の最小数を表します。 
4. いずれかの時点で余剰を均衡させることができない場合 (たとえば、親に十分な操作が残っていないためにマイナスの余剰を吸収できない場合)、解決策を不可能としてマークします。 
5. 各ノードでの剰余の絶対値を累積して、ツリーの合計最小操作数を取得します。 
6. 合計の操作を返す、または`-1`いずれかのノードのバランスが取れなかった場合。 

これが機能するのは、サブツリーの調整がボトムアップ方式で伝播されるためです。 各ノードはその子の不均衡を正確に吸収し、周期的な操作順序により、同じノード上で繰り返される操作により、必要に応じてサブツリー内の任意のノードをインクリメントまたはデクリメントできることが保証されます。 DFS は、ノードに未処理の余剰が残らないことを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(5000)

def solve():
    t = int(input())
    for _ in range(t):
        n, x = map(int, input().split())
        x -= 1  # convert to 0-based index
        a = list(map(int, input().split()))
        adj = [[] for _ in range(n)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            adj[u].append(v)
            adj[v].append(u)

        visited = [False] * n

        def dfs(u):
            visited[u] = True
            inc = 0  # total increments needed
            dec = 0  # total decrements needed
            for v in adj[u]:
                if not visited[v]:
                    sub_inc, sub_dec = dfs(v)
                    inc = max(inc, sub_inc)
                    dec = max(dec, sub_dec)
            # The node's own value adds to operations
            val = a[u]
            if val + inc < dec:
                # impossible to balance
                return float('inf'), float('inf')
            # Distribute excess
            return inc + max(0, val - dec), dec + max(0, dec - val)

        inc, dec = dfs(x)
        if inc >= float('inf'):
            print(-1)
        else:
            print(inc + dec)

if __name__ == "__main__":
    solve()
```この実装では、ルートから再帰的 DFS をセットアップします。 の`dfs`関数は、サブツリーごとに、正と負の余剰のバランスをとるために必要な演算を計算します。 の`inc`そして`dec`値が上に伝播され、その合計により最小限の演算数が得られます。 深いツリーを処理するために再帰制限が増加し、Python リストのすべてのインデックスがゼロベースに変換されます。 

微妙な点には、DFS がノードの再訪問を適切に回避すること、および最小限の操作数を取得する方法で余剰が結合されることを保証することが含まれます。 戻る`float('inf')`不可能であることを通知し、サイレントオーバーカウントを回避します。 

## 実用的な例

 最初のサンプル入力を使用します。```
2 1
1 2
1 2
```ノード 1 にルートがあり、値が設定されています`[1,2]`。 DFS はノード 1 で開始します。 

| ノード | a[u] | 子供余剰 | ノード余剰 |
 | --- | --- | --- | --- |
 | 2 | 2 | 0 | 2 |
 | 1 | 1 | 2 | 3 |

 最小操作の合計: 3. トレースは、ノード 1 がノード 2 のサブツリー不足を吸収していることを示し、ボトムアップ伝播を確認します。 

2 番目の例の場合:```
3 2
2 1 3
2 1
3 2
```ルートは値を持つノード 2 です`[2,1,3]`。 DFS 伝播はリーフ 1 と 3 からの剰余を計算します。ルート ノード 2 と組み合わせると合計 6 回の操作になります。 

これらのトレースは、アルゴリズムが複数の子からの余剰の蓄積を正しく処理し、最小限の操作でノード値のバランスを取っていることを示しています。
