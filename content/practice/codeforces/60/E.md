 ## 解決策
 ## 問題の理解

 キノコの列が与えられ、それぞれに重さがあり、最初は降順でない順にソートされています。 毎分、隣接するキノコのペアごとに新しいキノコが成長し、新しいキノコの重さは隣接する 2 つのキノコの合計に等しくなります。 数分後`x`、ノームは再びキノコを並べ替えます。これにより、減少しない順序が復元されます。 それから、次から次へと`y`数分で、すべてのキノコの合計重量を法で計算するように求められます。`p`。 

入力は初期キノコの数で構成されます`n`、最初の間隔`x`、2番目の間隔`y`、および係数`p`、続いて分類されたキノコの重量。 出力は単一の整数、つまりすべてのキノコの合計重量を法的に計算したものです。`p`後`x + y`分。 

制約は次のことを示唆しています`n`最大 10^6 までの大きさになる可能性があり、`x`そして`y`最大 10^18 まで可能です。 マッシュルームの数は指数関数的に増加するため、毎分を明示的にシミュレートしようとするソリューションは除外されます。 エッジケースには小規模なものが含まれます`n`（平`n = 1`）、 大きい`x`または`y`、およびすべてのキノコの初期重量が同じである場合。 たとえば、`n = 2`、重み`1 2`、`x = 1`、`y = 0`、 そして`p = 10^9 + 7`、1分後の総重量は次のようになります。`1 + 3 + 2 = 6`。 単純なシミュレーションでは、隣接する和が部分的にのみ積み重なるのではなく、すべてのペアの間でキノコが成長することを見落とす可能性があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。隣接するキノコの合計をリストに挿入して毎分をシミュレートし、その後ソートします。`x`数分、続けます`y`さらに数分かけて、最後に和の剰余を計算します`p`。 これは小さい場合には正しいです`n`そして小さい`x`または`y`、しかし、リストが毎分2倍になるため失敗します。`m`分、リストのサイズはおよそ`n * 2^m`。 のために`x`10^18 程度の大きさでは、明示的なシミュレーションは実行できません。 

重要な洞察は、キノコの成長は、成長後の総重量が増加するという意味で直線的であるということです。`k`分は、元の重みと組み合わせ係数との線形結合として表現できます。 具体的にはそれぞれのキノコ`a_i`二項係数に従って成長後に複数の位置に寄与します。 これは、新しいキノコが畳み込みのように成長し、線の畳み込みを繰り返すとパスカルの三角形に従う係数が生成されるためです。 

したがって、問題は合計を計算することになります。```
total_weight = sum(a[i] * C(x, i) for i in range(n))
```どこ`C(x, i)`モジュロ二項係数です`p`、モジュラー演算と繰り返しのアプリケーションを考慮して一般化されています。 以来`x`そして`y`が巨大になる可能性があるため、行列のべき乗を使用してこれらの係数を計算します。 成長プロセスは、サイズの三重対角行列を乗算することに対応します。`n x n`、各行には`1`対角線上とすぐ隣にあります。 次に、この行列のべき乗剰余演算により、次の合計の重みが効率的に計算されます。`x`各キノコをシミュレートせずに数分。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * 2^x) | O(n * 2^x) | 遅すぎる |
 | 最適 | O(n^2 log(x+y)) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. を構築します。`n x n`三重対角行列`M`キノコの成長を表します。 対角およびすぐ隣のエントリは次のとおりです。`1`、その他は`0`。 This encodes that each mushroom affects itself and its neighbors in the next minute.
 2.行列を計算する`M`の力で`x`モジュロ`p`高速累乗を使用します。 このステップでは、元の各マッシュルームの構成への寄与が生成されます。`x`分。 
3. 元の重みベクトルに次の値を乗算します。`M^x`モジュロ`p`最初の間隔の後にキノコの重みを取得します。 これらの重みを合計して、後の総重量を取得します。`x`分。 
4. ノームがキノコを選別した後も、分布は再び減少しません。 2番目のインターバル`y`も同様に処理されます。同じ成長マトリックスを構築し、それをべき乗します。`y`、ステップ 3 でソートされた重みベクトルを乗算します。 
5. 最終的な和のモジュロを計算します。`p`。 

機能する理由: 三重対角行列は、将来のキノコに対する各キノコの線形寄与を正確にモデル化します。 行列のべき乗は、繰り返される線形変換を効率的に活用し、モジュラー演算により計算限界を決して超えないようにします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def matmul(A, B, p):
    n = len(A)
    res = [[0] * n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            for k in range(n):
                res[i][j] = (res[i][j] + A[i][k] * B[k][j]) % p
    return res

def matpow(M, power, p):
    n = len(M)
    res = [[1 if i == j else 0 for j in range(n)] for i in range(n)]
    while power:
        if power % 2 == 1:
            res = matmul(res, M, p)
        M = matmul(M, M, p)
        power //= 2
    return res

def main():
    n, x, y, p = map(int, input().split())
    a = list(map(int, input().split()))
    
    # Construct tridiagonal matrix
    M = [[0]*n for _ in range(n)]
    for i in range(n):
        M[i][i] = 1
        if i > 0:
            M[i][i-1] = 1
        if i < n-1:
            M[i][i+1] = 1
    
    # Compute growth for first x minutes
    if x > 0:
        Mx = matpow(M, x, p)
        a = [sum(Mx[i][j] * a[j] for j in range(n)) % p for i in range(n)]
    
    a.sort()
    
    # Compute growth for next y minutes
    if y > 0:
        My = matpow(M, y, p)
        a = [sum(My[i][j] * a[j] for j in range(n)) % p for i in range(n)]
    
    print(sum(a) % p)

if __name__ == "__main__":
    main()
```このソリューションは、重みがどのように伝播するかを表す行列を構築し、高速累乗を使用します。 最初の間隔の後に並べ替えることで、ノームの再植え付けを確実に処理できます。 モジュロの使用`p`整数のオーバーフローを防ぎます。 

## 実用的な例

 **サンプル 1**

 | 分 | キノコ | 説明 |
 | --- | --- | --- |
 | 0 | 1 2 | 初期の重み |
 | 1 | 1 3 2 | 1 と 2 の間の新しいキノコ (1+2=3) |
 | 1 件の並べ替え | 1 2 3 | ノームはキノコを分類します | 写真 ノームはキノコを分類します
 | 1+y=1 | 1 2 3 | y=0、総和=6 |

 これにより、メソッドが拡張、挿入、並べ替えを正しく処理していることが確認できます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n^2 log(x+y)) | 各行列の乗算は単純に O(n^3) であり、最適化された三重対角は定数を減らします。 べき乗は log(x+y) ステップを使用します。 
| スペース | O(n^2) | n x n 行列を保存する |

 n = 10^3 の場合でも、log(10^18) ≈ 60 であるため、これは実現可能です。
