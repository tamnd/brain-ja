 ## 解決策
 ## 問題の理解

 ここでは、各文字が 0 から 9 までの固定長の数字列を扱います。通常の回文は、前から見ても後ろから読んでも同じです。 この問題では、緩和された概念が導入されています。つまり、文字列は回文ではない場合に有効であると見なされますが、正確に 1 つの位置を変更すると回文になります。 

同様に、文字列内の対称位置を比較する場合、文字列が回文条件に違反するインデックスが 1 つだけ存在する必要がありますが、他のすべての対称ペアは完全に一致します。 問題となる 1 つの位置を変更すると、完全な対称性を回復できます。 

各テストケースには長さが与えられます$n$、長さの数字列が何個あるかを数えなければなりません$n$この「正確に 1 つの不一致ペアを持つほぼ回文」の性質を法で満たします。$10^9 + 7$。 

制約は次のとおりです$n = 5000$そして$t = 100$。 これは、二次関数を使用してテストごとに独立して答えを再計算することはできないことを直ちに示唆しています。$n$。 どのような解決策であっても、最大でも$O(n)$または$O(n \log n)$テストごとに定数時間クエリによる前処理。 

「1 つ離れた位置」をどのように解釈すべきかを考えると、微妙な特殊なケースが現れます。 不一致とは、文字を恣意的に変更して文字列を回文にすることではなく、異なる対称ペアが 1 つだけ存在することです。 たとえば、101 のような長さ 3 の文字列では、すでに回文であるため、カウントしてはなりません。 100 のような文字列は、位置 0 と 2 の間にちょうど 1 つの不一致があるため、適格となります。 

もう 1 つの特殊なケースは、中間の概念が存在しない偶数長の文字列です。 すべての制約は純粋に対称ペアに限定されます。 奇数の長さの場合、中心文字は回文の有効性とは常に無関係ですが、それでもカウントに乗算的に寄与します。 

## アプローチ

 ブルートフォースソリューションでは、長さのすべての数字列を列挙します。$n$、対称的な不一致がいくつあるかを確認し、不一致のペアが 1 つだけあるものを数えます。 各チェックには次の時間がかかります$O(n)$、そして、あります$10^n$文字列は、たとえ小さなものであっても完全に実行不可能です$n$。 ボトルネックは明らかです。文字列ごとに同じ対称構造を個別に再計算しているからです。 

重要な観察は、回文構造が文字列を独立した対称ペアに分解するということです。 ある長さの文字列の場合$n$、 がある$m = \lfloor n/2 \rfloor$ミラーリングされたペア$(i, n-1-i)$、場合によっては中央の文字が 1 つある場合$n$奇数です。 各ペアは、他のペアとは独立して一致するか不一致になります。 

これらのいずれか 1 つが存在する場合、文字列は「回文」になります。$m$ペアは不一致ですが、他のすべてのペアは一致します。 これにより、どのペアが固有の欠陥ペアであるかを選択し、それに不一致の値を割り当て、他のすべてのペアを有効な回文ペアにすることで、構成をカウントすることができます。 

一致するペアの場合、両方の数字が同一であるため、10 個の選択肢が与えられます。 単一の不一致ペアについては、2 つの異なる数字を選択し、次のようにします。$10 \cdot 9$可能性。 もし$n$が奇数の場合、中央の桁は 10 個の選択肢で自由です。 

したがって、問題は文字列の列挙ではなく、独立したブロックにわたる組み合わせ論に帰着します。

 ## アルゴリズムのチュートリアル

 すべての答えを事前に計算します$n$5000まで。 

1. コンピューティング$m = \lfloor n/2 \rfloor$、対称ペアの数。 これは、回文構造に寄与する独立制約の数です。 
2. どのペアが一意の不一致ペアであるかを選択します。 がある$m$対称ペアはいずれも 1 つの違反になる可能性があるためです。 
3. 選択した不一致のペアに、2 つの異なる数字を割り当てます。 最初の位置には 10 の選択肢があり、2 番目の位置には異なる必要があり、9 つの選択肢があります。 
4. 他のすべてのペアに対して、等価性を強制します。 両方の数字が同一である必要があるため、このような各ペアは 10 個の選択肢を提供します。 
5. もし$n$が奇数の場合、中央の文字には 10 を掛けます。これは制約がありません。 
6. すべてを組み合わせます。$\text{ans}(n) = m \cdot 10 \cdot 9 \cdot 10^{m-1} \cdot (10 \text{ if } n \text{ odd else } 1)$7. 10 のべき乗を最大 5000 まで事前計算し、一定時間内に各クエリに答えます。 

これが機能する理由は、回文が独立した対称ペアに構造的に分解されることに基づいています。 すべての有効な文字列は、1 つの欠陥ペアの選択、そのペアへの割り当て、および他のすべてのペアへの有効な割り当てに一意に対応します。 不一致ペアの位置は一意に決定され、残りのペアはすべて強制的に等しくなるため、構成間に重複はありません。 この全単射により、数えすぎたり省略したりすることなく正確に数えることができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

MAXN = 5000

pow10 = [1] * (MAXN + 1)
for i in range(1, MAXN + 1):
    pow10[i] = (pow10[i - 1] * 10) % MOD

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        m = n // 2

        if m == 0:
            print(0)
            continue

        # choose mismatching pair
        ans = m

        # mismatching pair values
        ans = (ans * 10) % MOD
        ans = (ans * 9) % MOD

        # remaining pairs are equal pairs
        if m - 1 >= 0:
            ans = (ans * pow10[m - 1]) % MOD

        # center character if n is odd
        if n % 2 == 1:
            ans = (ans * 10) % MOD

        print(ans % MOD)

if __name__ == "__main__":
    solve()
```すべての等しいペアは 10 の係数に寄与し、そのようなペアは最大 2500 個存在する可能性があるため、ソリューションでは 10 のべき乗が事前計算されます。 各クエリは直接式評価になります。 

特別な場合$m = 0$(n = 1) は 0 を返します。ペアがまったく存在しないため、1 桁の文字列には不一致の対称ペアが 1 つだけ存在することはできません。

 ## 特殊なケース

 のために$n = 1$、対称ペアはまったく存在しないため、不一致ペアが 1 つだけ存在することは不可能です。 アルゴリズムは正しく 0 を返します。$m = 0$特殊なケースをトリガーします。 

小さいものでも$n$、 のような$n = 2$、ペアは 1 つだけあり、それは不一致である必要があります。 式は次のようになります。$1 \cdot 10 \cdot 9 = 90$、直接列挙に一致します。
