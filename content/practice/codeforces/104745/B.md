 ## 問題の理解

 2 つの正の整数が与えられ、それらの間に 4 つの基本的な算術演算 (加算、減算、乗算、または除算) のいずれかを適用できます。 各操作は値を生成するため、どの操作が最大の結果を生み出すかを判断する必要があります。 

入力は単純な 2 つの整数です。$a$そして$b$、両方とも 1 ～ 100 の範囲です。 タスクは、これらの値から 4 つの候補結果を計算し、それらの最大値を出力することです。 

拘束範囲は非常に狭いです。 どちらの数値も最大 100 であるため、算術演算は定数時間であり、Python のオーバーフローやパフォーマンスの問題を気にせずに直接評価できます。 これにより、前処理、検索、または最適化手法の必要性が即座に排除されます。 考えられるすべての式を直接評価するだけで十分です。 

不注意に扱うと間違いを引き起こす可能性のある微妙な点がいくつかあります。 分割作戦がメインです。 実数の除算として解釈された場合、浮動小数点値が生成され、他の演算では整数が生成されます。 これは、すべての操作にわたって正確さを維持する数値型で比較を一貫して行う必要があることを意味します。 

もう 1 つの潜在的な落とし穴は、整数の除算を想定していることです。 たとえば、次の場合$a = 8$そして$b = 3$、整数除算では 2 が得られますが、実数除算では約 2.666... が得られます。これは、除算が最大演算になるかどうかに影響する可能性があります。 この問題は除算を整数の除算に限定していないため、実数の除算として扱う必要があります。 

2 番目のエッジ ケースは、減算によって負の数が生成される場合です。 入力が正であるため、減算は負の値になる可能性があり、加算、乗算、または除算と比較したときにその値が最大になることはありませんが、正確性を考慮する必要があります。 

## アプローチ

 この問題を解決する簡単な方法は、4 つの式すべてを明示的に計算することです。$a + b$、$a - b$、$a \times b$、 そして$a / b$。 これらの値を計算したら、単純に最大値を取得します。 

問題のサイズが一定であるため、この強引なアプローチはすでに最適です。 正確に 4 つの操作をそれぞれ一定時間で実行します。 評価なしで操作を安全に無視できることを示唆する隠れた構造や制約はありません。 入力範囲が小さく枝刈りが必要ないため、演算間の優劣関係についての推論も不要です。 

許可されたすべての操作が独立しており、最大値はそのうちの 1 つから得られる必要があるため、ブルート フォース アプローチは正しいです。 変換や一連の操作がないため、組み合わせの爆発はありません。

 ## アルゴリズムのチュートリアル

 1. 2 つの整数を読み取ります$a$そして$b$。 必要な入力はこれらのみであり、追加の解析や前処理は必要ありません。 
2. 合計を計算します$a + b$。 これは 2 つの値の加算的な組み合わせを表し、個々の入力に対して常に減少しません。 
3. 差を計算します$a - b$。 これは減算の効果を捉えており、入力の相対的な大きさに応じて値が大幅に減少する可能性があります。 
4.積を計算する$a \times b$。 どちらの数値も正で少なくとも 1 であるため、この値は常に個々の入力と少なくとも同じ大きさになります。 
5. 割り算を計算する$a / b$実数除算を使用します。 これにより、小数部分の結果が確実に保持されます。これは、他の操作と正しく比較するために必要です。 
6. 4 つの結果すべてを比較し、最大値を出力します。 

### なぜ効果があるのか

 すべての有効な回答は、前の手順のいずれかで明示的に構築されます。 この問題では結果空間が正確に 4 つの式として定義されており、隠れた演算や変換がないため、すべての候補を評価することで、考えられる答えが見逃されることがないことが保証されます。 定義上、有限完全集合の最大値が正解です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a, b = map(int, input().split())
    
    res1 = a + b
    res2 = a - b
    res3 = a * b
    res4 = a / b  # real division
    
    print(max(res1, res2, res3, res4))

if __name__ == "__main__":
    solve()
```このソリューションは 2 つの整数を読み取り、4 つの候補式のそれぞれを直接評価します。 除算は浮動小数点演算を使用して実行されます。Python では、この演算は指定された範囲の値に対して十分な精度を備えています。 最終的な答えは、4 つの結果に対して Python の組み込み max 関数を使用して計算されます。 

微妙な実装の詳細は、除算が誤って整数除算に置き換えられないようにすることです。`//`。 そうすると演算の意味が変わり、小数値が重要な場合に誤って最大値を減らす可能性があります。

 ## 特殊なケース

 エッジ ケースの 1 つは、入力などの減算が負になる場合です。`1 100`。 アルゴリズムは計算します`1 - 100 = -99`ですが、この値は当然ながら無視されます。`max`他の結果の方が大きいため、操作を行います。 計算にはそれも含まれており、枝刈りではなく網羅的に正確さを維持します。 

もう 1 つのケースは、除算によって非整数値が生成される場合です。`3 2`。 アルゴリズムは計算します`3 / 2 = 1.5`、乗算すると`6`が最大になります。 Python は比較中に整数を浮動小数点に昇格させるため、浮動小数点の結果は依然として整数と正しく比較されます。 

最後のエッジケースは、次のように両方の数値が等しい場合です。`100 100`。 すべての演算は引き続き有効かつ明確に定義されており、乗算が最大の結果を生成します。 このアルゴリズムは順序付けの仮定に依存せず、すべての式を均一に評価して、対称入力全体の正確性を保証します。
