 ## 解決策
 ## 問題の理解

 0 から n までの整数位置の線分が与えられます。 数人の生徒が 1 から n−1 までの整数の点の上に立ち、複数の生徒が同じ位置を共有する場合があります。 各生徒は、時間 0 での方向 (0 方向または n 方向) を等しい確率で独立して選択します。 

プロセスが開始されると、すべての生徒は 1 秒ごとに 1 歩ずつ進みます。 2 人の学生が出会うと方向が逆になりますが、両者は同じ速度で移動するため、時間の経過に伴う位置だけを考慮すると、この相互作用は学生がすれ違うことと同じになります。 出口にとって重要なのは、各生徒がセグメントを出るまで最初の方向に進み続けるように効果的に行動することです。 

各クエリ時間 t について、時間 t までにセグメントのエンドポイントを離れた学生がいない確率を計算するように求められます。 言い換えれば、すべての生徒は t 秒後もまだ間隔内にいる必要があります。 答えはゼロまたは 2 分の 1 乗であることが保証されているため、確率が 2^{-m} になるように指数 m を出力します。イベントが不可能な場合は -1 になります。 

制約 n と q は最大 100,000 まで、t は最大 1 億まで可能です。 これにより、O(nq) でさえすでに遅すぎるため、時間の経過に伴うシミュレーションやクエリごとの生徒ごとの再計算が即座に除外されます。 前処理後に各クエリが対数時間または定数時間で応答されるソリューションが必要です。 

微妙なエッジ ケースは、学生が出口に非常に近づいており、どちらの方向でも時刻 t より前または時刻 t に退出する可能性がある場合に発生します。 たとえば、生徒が位置 2 にいて t が 10 の場合、方向に関係なく、生徒は時刻 t よりずっと前に退出していることになり、確率はゼロになります。 一方向のみをチェックするか、対称性を前提とする単純なアプローチでは、これが見逃され、誤って正の確率が返されます。 

もう 1 つの失敗モードは、複数の生徒が同じポジションを占める可能性があることを無視した場合に発生します。 彼らの貢献は独立して増加するため、ポジションごとに集計することが不可欠です。 個々の生徒を反復処理することは漸近的には問題ありませんが、概念的には冗長です。 

## アプローチ

 直接シミュレートしようとすると、各生徒にランダムな方向を割り当て、衝突を処理しながら t ステップの動きをシミュレートします。 衝突の等価性を利用して ID を交換したとしても、すべての生徒の退室時間を追跡し、クエリごとにこの推論を繰り返す必要があります。 これにより、衝突が明示的にシミュレートされている場合は O(nq) チェックが発生するか、さらに悪いことにつながり、これは制限をはるかに超えています。 

重要な単純化は、衝突が終了時間にまったく影響しないことです。 各生徒の退出時間は、最初の位置と選択した方向のみによって決まります。 位置 x の生徒は、左を向いている場合は x 秒後に左から退出し、右を向いている場合は n−x 秒後に右から退出します。 したがって、固定のクエリ時間 t に対して、各生徒は独立して制約を提供します。つまり、2 つの方向のうちの少なくとも 1 つが時間 t まで生徒をセグメント内に留めておく必要があります。 

この独立性により、確率がポジションの積に変わります。 各生徒には 3 つのケースがあります。 両方の方向が生徒を屋内に留める場合、生徒は確率 1 に寄与します。一方の方向だけが安全な場合、生徒は 1/2 の係数を寄与します。 どの方向も安全でない場合、構成全体が不可能になります。 

多くの学生がポジションを共有しているため、ポジションごとに数を集計します。 固定 t の場合、各位置 x は、t、x、および n−x 間の比較に応じて 4 つのカテゴリのいずれかに分類されます。 これにより、位置周波数にわたるプレフィックスの合計を使用して最終指数を計算できるようになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | モーションの直接シミュレーション | O(nq) 以上 | O(n) | 遅すぎる |
 | 周波数 + 範囲カウントを事前計算する | O(n + q) | O(n) | 承認済み |

## アルゴリズムのチュートリアル

 1. 1 から n−1 までの各位置に何人の生徒が立っているかを数えます。 これにより、同じ位置にいるすべての生徒が同じように行動するため、繰り返される位置が周波数に圧縮されます。 
2. これらの頻度に対してプレフィックス合計配列を構築して、任意の位置間隔に何人の生徒が横たわっているかをすばやくクエリできるようにします。 
3. 与えられたクエリ時間 t について、x が t より大きいかどうか、および n-x が t より大きいかどうかに基づいて位置 x を分類します。 これら 2 つの比較により、左右の移動が安全かどうかが決まります。 
4. 次の領域に該当する位置の数を計算します。両方向が安全な領域、正確に 1 方向が安全な領域、およびどちらの方向も安全ではない領域です。 これは、周波数配列にわたる間隔の合計を使用して行われます。 
5. いずれかの位置がどちらの方向も安全ではない領域に属している場合、少なくとも 1 人の生徒が必ず退出する必要があるため、解答は即座に不可能になります。 
6. それ以外の場合、すべての位置は指数に何も寄与しないか、または正確に 1 つの方向が有効な場合には 1 を寄与します。 すべての位置にわたるこれらの寄与を合計して m を形成します。 
7. クエリの m を出力します。 

これが機能する理由は、各生徒の方向選択が独立しており、他の生徒とは独立して退校時間を決定するという事実から来ています。 衝突によって退出時間が変更されることはないため、グローバル イベントは生徒ごとの独立した制約に分解されます。 各生徒には 0、1、または 2 つの有効な方向の選択肢があり、有効な選択肢が 1 つだけある場合のみ、確率全体の 1/2 が寄与します。 職位別に集計するとこの独立性が保たれるため、各カテゴリの学生をカウントすることで指数が完全に決まります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, q = map(int, input().split())
    arr = list(map(int, input().split()))

    freq = [0] * (n + 1)
    for x in arr:
        freq[x] += 1

    pref = [0] * (n + 1)
    for i in range(1, n + 1):
        pref[i] = pref[i - 1] + freq[i]

    def range_sum(l, r):
        if l > r:
            return 0
        l = max(l, 1)
        r = min(r, n - 1)
        if l > r:
            return 0
        return pref[r] - pref[l - 1]

    for _ in range(q):
        t = int(input())

        # both safe: x > t and x < n - t
        both_l = t + 1
        both_r = n - t - 1
        both = range_sum(both_l, both_r)

        # left only safe: x > t and x >= n - t
        lo_l = max(t + 1, n - t)
        lo_r = n - 1
        left_only = range_sum(lo_l, lo_r)

        # right only safe: x <= t and x <= n - t - 1
        ro_l = 1
        ro_r = min(t, n - t - 1)
        right_only = range_sum(ro_l, ro_r)

        # none safe: x <= t and x >= n - t
        none_l = max(1, n - t)
        none_r = min(t, n - 1)
        none = range_sum(none_l, none_r)

        if none > 0:
            print(-1)
        else:
            print(left_only + right_only)

if __name__ == "__main__":
    solve()
```この解決策は、繰り返される位置がまとめて処理されるように、生徒の位置を周波数配列に圧縮することから始まります。 この配列のプレフィックス合計により、一定の時間範囲のクエリが可能になります。 

各クエリ時間 t について、4 つの行動カテゴリに対応する間隔を導出します。 区間の境界は、x と t および n−x を比較することによって直接得られ、「左に移動すると生き残る」または「右に移動すると生き残る」という条件を x 上の不等式に変換します。 

重要な部分は、「安全ではない」領域の検出です。 いずれかのポジションがその間隔内にある場合、そのポジションにいるすべての生徒は方向に関係なく必然的に退場し、確率は強制的にゼロになります。 それ以外の場合は、有効な方向が 1 つだけある位置のみが指数に寄与します。 

## 実用的な例

 ### トレースの例

 n = 7、位置 [2、2、3] に生徒がいる小さな構成を示します。 

t = 1 と考えます。 

| 位置 x | カウント | x > t | n−x > t | カテゴリー |
 | --- | --- | --- | --- | --- |
 | 2 | 2 | はい | はい | どちらも安全 |
 | 3 | 1 | はい | はい | どちらも安全 |

 ここでは、両方のポジションが「両方とも安全」領域内にあるため、指数に寄与するポジションはありません。 

結果は m = 0 になります。 

これは、すべての生徒が t に対して両方の出口から十分に離れている場合、どの方向も安全であるため、ランダム性によって確率が低下しないことを示しています。 

### 2 番目のトレース例

 n = 7 の生徒を位置 [1, 5] に配置します。 

t = 2 とします。 

| 位置 x | カウント | x ≤ t | n−x ≤ t | カテゴリー |
 | --- | --- | --- | --- | --- |
 | 1 | 1 | はい | いいえ | 右のみ |
 | 5 | 1 | いいえ | はい | 左のみ |

 どちらの位置も 1 つの有効な方向に寄与するため、m = 2 となります。 

これは、独立した制約が指数に追加的に蓄積されることを確認します。

 ## 特殊なケース

 t が非常に大きい場合、すべての位置が「安全ではない」領域に入る可能性があります。 たとえば、t ≥ n−1 の場合、位置 1 にいる生徒は左を向いていれば退場を避けることができず、n−1 付近の生徒は右を向いている場合は退場を避けることができません。 その場合、アルゴリズムはすべての位置を非安全区間に配置し、すぐに -1 を出力します。 

すべての生徒が単一の位置を共有している場合でも、頻度の集計は区別性を前提としないため、分類は引き続き機能します。 アルゴリズムはその位置を 1 回評価し、そのカウントを指数に正しく乗算します。 

t が小さい場合、多くの位置が「両方安全」領域に入ります。 これらは指数には何も寄与せず、プレフィックス合計クエリは当然寄与ゼロを返し、特別な処理を行わなくても正確性が保たれます。
