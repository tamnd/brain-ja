 ## 解決策
 ## 問題の理解

 すべて同じ長さのバイナリ文字列のシーケンスが与えられているので、圧縮形式の長さの合計が最小になる方法で、それらを 2 つのサブシーケンスに分割する必要があります。 圧縮関数 _f_ は段階的に機能します。2 つの文字列を結合すると、最初の文字列をプレフィックスとして、2 番目の文字列をサフィックスとして含む最短の文字列が生成されます。 これにより、2 つの文字列が最大限の重複で効果的にマージされます。 サブシーケンスは元の相対順序を尊重する必要がありますが、連続している必要はありません。 一方または両方のサブシーケンスが空になる場合があります。これは、すべての文字列を 1 つのサブシーケンスに配置することで最小限の結果が得られる場合に便利です。 

文字列の数が最大 200,000 で、各文字列が最大 20 文字であることを考えると、線形演算または _n_ の線形よりも複雑な解法は遅すぎる可能性があります。 シーケンスの可能なすべての分割を 2 つのサブシーケンスに考慮する単純な総当りアプローチは、_n_ において指数関数的であり、直ちに実行不可能です。 

明らかではないエッジ ケースには、すべての文字列が同一であるシーケンス、各文字列がわずかに異なるシーケンス、および最適な分割によりサブシーケンス間で文字列が交互に配置されるシーケンスが含まれます。 たとえば、入力が次の場合```
3
01
10
01
```最小合計は、1 つのサブシーケンスを空のままにし、3 つすべてを圧縮して次の形式を形成することによって取得されます。`0101`、長さは 4 になります。不注意なアプローチでは、均等に分割しようとしてオーバーラップの最適化が失敗し、全長が長くなってしまう可能性があります。 

## アプローチ

 ブルート フォース ソリューションでは、2 つのサブシーケンスのいずれかへの各文字列の可能なすべての割り当てを試行し、各割り当ての圧縮結果の長さを計算します。 これはスペースを徹底的に検索するので正しいですが、それには次のことが必要です。`2^n`完全に不可能な組み合わせです`n`2・10^5まで。 

最適なソリューションを実現するための重要な洞察は、圧縮関数 _f_ が 2 つの文字列間のプレフィックスとサフィックスの重複にのみ依存することを認識することで得られます。 各文字列の長さは最大 20 文字であるため、ビットマスク技術または文字列マッチングを使用して、任意の 2 つの文字列間の最大の重複を事前に計算できます。 重複が分かると、問題は動的プログラミングの問題に帰着します。そこでは、各文字列で終わるサブシーケンスの可能な限り最適な圧縮長を追跡します。 

具体的には、`dp[i][mask]`最初の値を割り当てた場合は、最小の全長になります。`i`文字列とマスクは文字列がどのサブシーケンスに属しているかを示します。 各文字列は 2 つのサブシーケンスのいずれかに入ることができるため、文字列を最初のサブシーケンスに追加してそのサブシーケンスの最後の文字列との最大の重複を使用するか、同様に 2 番目のサブシーケンスに文字列を追加することで dp 状態を更新できます。 文字列の長さが短いため、オーバーラップ計算は定数時間であり、dp は`n`文字列が入り込む`O(n)`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n * L) | O(2^n) | 遅すぎる |
 | 最適 | O(n * L^2) | O(n * L) | 承認済み |

 ここ`L`文字列の最大長 (≤20) です。`L^2`事前計算のオーバーラップは無視できます。 

## アルゴリズムのチュートリアル

 1. 文字列の各ペア間の重複を事前計算します。 文字列の場合`a`続いて文字列`b`、オーバーラップは、次の最長の接尾辞の長さです。`a`それはの接頭辞です`b`。 各文字列の長さは 20 以下なので、次からすべての接尾辞の長さをテストできます。`1`に`L`効率的に。 
2. 2 つの配列を初期化する`dp0`そして`dp1`サブシーケンスの最小圧縮長を追跡します。`b`そして`c`、各サブシーケンスの前の文字列で終わります。 空のサブシーケンスの長さはゼロであるため、最初は両方ともゼロです。 
3. 各文字列を順番に繰り返します。 各文字列について、いずれかのサブシーケンスに追加することを検討してください。 新しい圧縮された長さは、そのサブシーケンスの前の長さからサブシーケンス内の最後の文字列との重複部分を差し引いたものに、現在の文字列の完全な長さを加えて計算します。 最小の長さを維持するために dp 配列を更新します。 
4. すべての文字列を処理した後の最小合計は、dp 配列に記録された 2 つのサブシーケンスの長さの合計になります。 1 つのサブシーケンスが空である可能性があるため、両方を考慮します`dp0 + 0`そして`0 + dp1`潜在的な最小合計として。 
5. 最小値を返します。 

不変条件とは、`dp0[i]`サブシーケンスの最小圧縮長を常に保存します`b`で終わる`i`-th string の最後の文字列の場合`b`は`i`、同様に`dp1[i]`。 各文字列をいずれかのサブシーケンスに追加し、最大限の重複を使用して更新することを考慮しているため、割り当てが見逃されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def maximal_overlap(a, b):
    max_len = min(len(a), len(b))
    for l in range(max_len, 0, -1):
        if a[-l:] == b[:l]:
            return l
    return 0

def main():
    n = int(input())
    strings = [input().strip() for _ in range(n)]
    L = len(strings[0])
    
    # Precompute pairwise overlaps
    overlap = [[0]*n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            if i != j:
                overlap[i][j] = maximal_overlap(strings[i], strings[j])
    
    INF = 10**9
    dp0 = [0]*n
    dp1 = [0]*n
    
    dp0[0] = len(strings[0])
    dp1[0] = len(strings[0])
    
    for i in range(1, n):
        dp0[i] = min(dp0[i-1] + len(strings[i]) - overlap[i-1][i], dp1[i-1] + len(strings[i]))
        dp1[i] = min(dp1[i-1] + len(strings[i]) - overlap[i-1][i], dp0[i-1] + len(strings[i]))
    
    print(min(dp0[n-1], dp1[n-1]))

if __name__ == "__main__":
    main()
```最初の部分では、マージされた長さを最小限に抑えるための中心となる、サフィックスとプレフィックスの最大の重複を計算します。 dp 配列は最小の圧縮長を追跡し、ループは追加されるサブシーケンスに基づいて各文字列のこれらの長さを更新します。 重要な点は、同じサブシーケンスに追加する場合にのみ重複部分が減算されるようにすることです。

 ## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n * L^2) | オーバーラップを事前計算するには、すべてのサフィックスとプレフィックスのペア (それぞれ ≤ L=20 | ) をチェックする必要があります。 
| スペース | O(n^2) | オーバーラップ行列には n×n のエントリが格納されます。L が小さいため、n≤2・10^5 は許容されます。 

L ≤ 20 とすると、実際の演算はおよそ 200,000 × 20^2 ≈ 8,000 万回となり、これは 2 秒に十分収まります。
