 ## 解決策
 ## 問題の理解

 ポートとケーブルの固定セット上で非常に小規模なランダム化プロセスをシミュレートしています。最終的には各ケーブルが 1 つのポートに接続されます。 1 から n のラベルが付けられた n 個のポートと、1 から n のラベルが付けられた n 個のケーブルがあります。 ケーブルは昇順に次々と挿入されます。 

最初の m 個のケーブルは予期しない動作をします。各ケーブルは現在空の均一にランダムなポートに配置されます。 これらの m ステップの後、残りのケーブルはほぼ決定的なルールに従います。 ケーブル i を挿入するときに、ポート i がまだ空いていれば、ケーブルはそこに挿入されます。 それ以外の場合、ポート i がすでに使用されている場合、ケーブルは残りの空のポートの中から均一にランダムに選択することを強制されます。 

タスクは、すべての挿入が完了した後、ケーブル n がポート n に接続される確率を計算することです。 

重要な構造上の制約は、n が最大 10 であるということです。これは、n で指数関数的に増加する状態空間または確率モデルは実行可能ですが、大きな組み合わせ DP に依存するものは不要であることを直ちに示します。 代わりに、これは完全な列挙または直接再帰的推論が現実的な小規模な確率的プロセスです。 

最もデリケートなエッジ ケースは、m が n に等しい場合に現れます。これは、すべてのケーブルがランダムに配置され、決定論的なルールが決してアクティブにならないことを意味します。 この場合、プロセスは一様ランダム順列となり、ケーブル n がポート n に接続される確率は正確に 1/n になります。 後の決定論的な動作を想定した単純な実装では、このケースに誤ったバイアスがかかる可能性があります。 

もう 1 つの特殊なケースは、m が 0 に等しい場合で、衝突が起こらない限り、すべてが決定的です。 これでも、強制的な再割り当てによりランダム性が生じる可能性があり、「最初の m ステップのみが重要である」という単純な仮定はすぐに崩れます。 

## アプローチ

 ブルート フォース アプローチでは、最初の m ケーブルのすべての可能な割り当てをシミュレートし、残りの挿入に対するすべての衝突結果を再帰的に調査します。 各ランダム配置は最大 O(n) 個の選択肢に分岐し、各衝突も最大 O(n) 個に分岐します。 n ≤ 10 の場合でも、これにより状態が繰り返される可能性の大きなツリーが生成され、メモ化なしではおおよそ n のように成長します。 最悪の場合。 正確であることは簡単ですが、多くのブランチが同一の構成に到達するため、このアプローチは冗長になります。 

重要な点は、どのステップを行っても、重要な情報は、どのポートが占有されているか、どのケーブルが現在処理されているかということだけであるということです。 どのようにして構成に到達したかの身元は関係ありません。 これにより、問題は、ケーブル i を処理するときにターゲット ポート i が空いているかどうかによってのみ決定される、占有ポートのサブセットにわたる小さな確率 DP に軽減されます。 

n が非常に小さいため、単純化はさらに進みます。 システムを占有ポートのセットによって定義された状態にわたるマルコフ過程として扱い、確率を決定論的に前方に伝播することができます。 各状態は、強制配置が発生するかランダム配置が発生するかに応じて、最大 n 個の次の状態に遷移します。 最終的には、ポート n がケーブル n によって占有されている状態の確率を合計します。

 ## アルゴリズムのチュートリアル

 ケーブルのいくつかのプレフィックスを処理した後にどのポートがすでに占有されているかを示すビットマスクによって各状態を表します。 これらの状態にわたる確率分布を維持します。

1. ポートが占有されておらず、確率が 1 である単一状態で DP を初期化します。これは、ケーブルが挿入される前のシステムを表します。 
2. ケーブルを 1 から n まで順番に処理します。 ステップ i では、ポート i が各状態で占有されているかどうかに基づいて分布を更新します。 
3. 固定状態の場合、ポート i が空いている場合、ケーブル i はそこに決定的に接続されます。 占有済みとしてマークされたポートを使用して、確率質量を新しい状態に移動します。 
4. ポート i がすでに占有されている場合、現在空いているすべてのポートに確率を均一に分配します。 これにより、複数の後続状態が作成され、それぞれが空のポートの 1 つを選択することに対応します。 
5. 最初の m ケーブルについては、決定論的なチェックを完全にスキップし、ランダムになることが強制されるため、すべての空きポートに常に均一に分散します。 
6. n 本のケーブルすべてを処理した後、ポート n がケーブル n によって占有されているすべての状態の確率を合計します。これは、最終ステップでポート n が占有されているかどうかを確認するのと同じです。 

これが機能する理由は、DP 状態がすべてのステップで、将来の遷移を決定するために必要な関連情報を正確にエンコードしているためです。占有セットは、強制配置が発生するかどうか、および有効なランダム選択が何であるかを完全に決定します。 遷移は現在のマスクと現在のインデックス i にのみ依存するため、同じマスクにつながるすべての履歴は将来同じように動作するため、それらをマージすると正確さが維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    # dp[mask] = probability of this occupancy state
    dp = [0.0] * (1 << n)
    dp[0] = 1.0

    for i in range(1, n + 1):
        ndp = [0.0] * (1 << n)

        for mask in range(1 << n):
            p = dp[mask]
            if p == 0:
                continue

            # if i-th port is free
            if not (mask >> (i - 1)) & 1:
                new_mask = mask | (1 << (i - 1))
                ndp[new_mask] += p
            else:
                # choose uniformly among free ports
                free = []
                for j in range(n):
                    if not (mask >> j) & 1:
                        free.append(j)

                k = len(free)
                if k == 0:
                    continue

                for j in free:
                    new_mask = mask | (1 << j)
                    ndp[new_mask] += p / k

        dp = ndp

    ans = 0.0
    for mask in range(1 << n):
        if mask & (1 << (n - 1)):
            ans += dp[mask]

    print(f"{ans:.10f}")

if __name__ == "__main__":
    solve()
```DP 配列には、占有ポートのすべてのサブセットの確率が格納されます。 各反復は、新しいケーブルの挿入と、ルールに従って確率質量を再分配することに対応します。 重要な実装の詳細は、強制配置とランダムな再割り当てを慎重に処理することです。 どちらも、ターゲット ポートがすでにマスクに設定されているかどうかから直接導出されます。 

ここでは、n が小さく深さが最大 ​​10 であるため、浮動小数点除算は安全であり、累積誤差は十分許容範囲内に留まります。 

## 実用的な例

 ### 例 1: n = 3、m = 1

 各ケーブルの後に DP 状態を追跡します。 

| ステップ | マスク状態 (バイナリ) | 確率 |
 | --- | --- | --- |
 | 開始 | 000 | 1.0 |
 | ケーブル後 1 (ランダム) | 100、010、001 | 各1/3 |
 | ケーブル後 2 | 複数のマージされた状態 | 遷移を介して計算される |
 | ケーブル後 3 | 最終配布 | 有効なマスクの合計 |

 重要な動作は、初期のランダム性により確率がすべての構成に広がり、その後の決定論的な挿入により、ターゲット ポートが既に占有されているかどうかに応じて結果にバイアスがかかることです。 

最終結果は 0.5 と一致します。これは、確率質量の半分がケーブル 3 がポート 3 を占有することを意味します。 

### 例 2: n = 2、m = 2

これは、m = n の場合、プロセスが一様な順列に退化することを確認します。

 ## 特殊なケース

 ### ケース: m = n (すべてランダム)

 入力:```

```ここでは、すべてのケーブルが残りの空きポートに均一に挿入され、均一なランダム順列が生成されます。 DP 遷移は常に確率を均等に分配し、最終状態空間は 3 つすべてに等しい確率を割り当てます。 構成。 「ケーブル n がポート n にある」というイベントがちょうど 2 で発生します。 3の！ ケース、収量は1/3。 

### ケース: m = 0 (衝突を除いて完全に決定的)

 入力:```
3 0
```ケーブル 1 では、ポート 1 が決定的に取得されます。 ケーブル 2 では、ポート 2 が空いていればそれが使用されますが、そうでない場合はランダム性が生じます。 1 回の衝突でも残りのポート間で均一な再分配が発生するため、DP は両方のブランチを正しくキャプチャします。 ケーブル 3 がポート 3 に到達する最終的な確率は完全に初期の強制構造によって決まり、DP により衝突パスと非衝突パスの両方が対称的に考慮されることが保証されます。 

### ケース: n = 1

 入力:```
1 0
```ケーブルは 1 本だけ存在します。 ランダム性ルールに関係なく、常にポート 1 で終了します。 DP はマスク 0 から始まり、すぐに確率 1 をマスク 1 に割り当てます。最終的な答えは正確に 1 であり、分岐は発生しません。
