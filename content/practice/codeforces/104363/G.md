 ## 解決策
 ## 問題の理解

 平面内に点のセットが与えられ、それぞれが等しい質量の小惑星を表します。 これらの点を 2 つの空ではないグループに分割する必要があります。 各グループはその重心に圧縮されます。重心はすべての質量が同一であるため、その点の座標の単純な算術平均です。 これにより、2 つの点 A と B が生成されます。原点には固定参照点 O もあります。 

目的は、三角形 ABO の面積が最大化されるように、点を 2 つの空ではないグループに分割することを選択することです。 O は固定されているため、面積は A と B の位置、特に線分 AB が原点に対してどの程度「広がる」かによってのみ決まります。 

入力サイズは最大 10 万ポイントに達するため、すべてのパーティションまたはすべてのサブセットのペアを試行するソリューションは除外されます。 n で 2 次的なアプローチはすでに大きすぎるため、O(n log n) メソッドであっても慎重に正当化する必要があります。 

すべての点が原点を通る線上にある場合、微妙な問題が発生します。 その場合、考えられるすべてのグループ化により同一線上の A、B、O が生成されるため、面積はゼロになります。 非ゼロの面積を仮定し、ベクトルの大きさで除算する単純な実装は数値的には正しく動作する可能性がありますが、幾何学的推論では縮退を考慮する必要があります。 

A と B が選択された点ではなく平均であることを考慮せずに、貪欲に 2 つの極端な点を選択し、それらに基づいてグループを割り当てようとすると、別の失敗ケースが発生します。 たとえば、極点は必ずしも重心の分離を最大化するとは限りません。 

## アプローチ

 強引なアイデアは、n 点の可能なすべての分割を 2 つの空でないセットに列挙することです。 各パーティションについて、O(n) 時間で 2 つの重心を計算し、O(1) で三角形の面積を計算します。 これは O(2^n · n) になりますが、これはまったく実行不可能です。 

重要なのは各グループの正確な構成ではなく、2 つのグループの座標の合計の差であることを観察することで、検索スペースを減らすことができます。 S をすべての点の合計とします。 グループ 1 の合計を S1 と定義すると、グループ 2 の合計は S − S1 となります。 重心は S1 / k および (S − S1) / (n − k) であるため、ジオメトリは、選択したサブセットによって S1 がどのように変化するかによって決まります。 

重要な洞察は、面積式がサブセット合計の線形関数の最大化になるということです。 具体的には、三角形の面積は A と B の外積の絶対値に比例します。代数的単純化の後、これはすべての非自明な部分集合にわたる一次式を最大化することになります。これは、点を「射影」して符号によって分割する方向を選択することに相当します。 

これにより、問題は原点を通る線によって引き起こされる最適な分割を見つけることに変換されます。つまり、片側のすべての点がグループ A に移動し、残りの点がグループ B に移動します。分割境界を越えて点を移動すると目的が線形かつ単調に変化するため、最適な解はすべてこのような半平面分割に変換できます。 

方向分離に帰着すると、原点の周りの角度によって点を並べ替え、1 つのグループを表すスライディング ウィンドウを考慮するだけで済みます。 重心の差は増分的に維持できるため、ソートによる O(n log n) の解決とそれに続く O(n) スキャンが可能になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n · n) | O(n) | 遅すぎる |
 | 角度スイープの最適化 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

1. すべての点の座標の合計を計算します。 これにより、ゼロから再計算するのではなく、相補的な合計を使用してグループの重心を表現できるようになります。 
2. 各点を原点の周りの極角に変換します。 角度によって並べ替えると、連続するセグメントが、原点を通る回転線で分離できる一連の点に対応することが保証されます。 
3. 角度を 2π ずつ増やして再度追加して、ソートされたリストを複製します。 これにより、円形の間隔を線形ウィンドウとして扱うことができます。 
4. 1 つの候補グループを表すこの 2 倍の配列にわたってスライディング ウィンドウを維持します。 ウィンドウ内の x 座標と y 座標の累計を追跡します。 
5. 両方のグループが空であってはいけないため、各ウィンドウについて、すべてのポイントが含まれていないことを確認します。 これは、ウィンドウ サイズが厳密に 1 から n − 1 の間でなければならないことを意味します。 
6. プレフィックスの合計と合計を使用して、ウィンドウ グループとその補数の重心を計算します。 
7. 有効なウィンドウごとに、A と B の外積を使用して三角形の面積を計算し、最大値を更新します。 

### なぜ効果があるのか

 面積を最大化する点の分割は、原点を通る分割線で表すことができます。 点が角度によって並べ替えられると、そのような線は円上の連続した間隔に対応します。 重心は合計のみに依存し、間隔にわたる合計は効率的に維持されるため、最適な分割はこれらの間隔の 1 つとして現れる必要があります。 循環複製により、角度の境界を囲む間隔を見逃すことがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

def area(ax, ay, bx, by):
    return abs(cross(ax, ay, bx, by)) / 2.0

n = int(input())
pts = []
sx = sy = 0

for _ in range(n):
    x, y = map(int, input().split())
    pts.append((x, y))
    sx += x
    sy += y

# sort by angle
import math
pts.sort(key=lambda p: math.atan2(p[1], p[0]))

# duplicate for circular window
ext = pts + pts

px = [0] * (2 * n + 1)
py = [0] * (2 * n + 1)

for i in range(2 * n):
    px[i + 1] = px[i] + ext[i][0]
    py[i + 1] = py[i] + ext[i][1]

ans = 0.0

l = 0
for r in range(1, 2 * n):
    while r - l + 1 > n:
        l += 1

    if r - l + 1 < n and r - l + 1 > 0:
        sx1 = px[r + 1] - px[l]
        sy1 = py[r + 1] - py[l]

        k = r - l + 1
        k2 = n - k

        if k2 == 0:
            continue

        ax = sx1 / k
        ay = sy1 / k

        bx = (sx - sx1) / k2
        by = (sy - sy1) / k2

        ans = max(ans, abs(ax * by - ay * bx) / 2.0)

print(f"{ans:.10f}")
```解決策は、すべての点を読み取り、グローバル合計を計算することから始まります。この合計は、後で合計を直接再計算することなく 2 番目のグループの重心を導出するために使用されます。 

並べ替え順`atan2`原点の周りの角度順に点を整理し、有効な幾何学的カットが連続したセグメントに対応することを保証します。 複製ステップにより、ラップアラウンド間隔を均一に処理できるようになります。 

プレフィックスの合計`px`そして`py`スライディング ウィンドウでは O(n) 個の候補パーティションを検査するため、セグメント合計の O(1) 取得が可能になります。 

右端のそれぞれについて、左ポインタを縮小して、セグメントがサイズ n を超えないようにします。 これにより、パーティションの有効性が維持され、両方のグループが空ではないことが保証されます。 

重心は合計から直接計算され、三角形の面積は外積によって評価されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math

    def solve():
        input = sys.stdin.readline
        n = int(input())
        pts = []
        sx = sy = 0
        for _ in range(n):
            x, y = map(int, input().split())
            pts.append((x, y))
            sx += x
            sy += y

        pts.sort(key=lambda p: math.atan2(p[1], p[0]))
        ext = pts + pts

        px = [0] * (2 * n + 1)
        py = [0] * (2 * n + 1)

        for i in range(2 * n):
            px[i + 1] = px[i] + ext[i][0]
            py[i + 1] = py[i] + ext[i][1]

        ans = 0.0
        l = 0
        for r in range(1, 2 * n):
            while r - l + 1 > n:
                l += 1
            k = r - l + 1
            if k <= 0 or k >= n:
                continue
            sx1 = px[r + 1] - px[l]
            sy1 = py[r + 1] - py[l]
            ax, ay = sx1 / k, sy1 / k
            bx, by = (sx - sx1) / (n - k), (sy - sy1) / (n - k)
            ans = max(ans, abs(ax * by - ay * bx) / 2)
        print(f"{ans:.10f}")

    solve()
    return ""

# custom cases
assert run("2\n1 0\n-1 0\n") == "", "collinear"
assert run("3\n1 0\n0 1\n-1 0\n") == "", "small triangle"
assert run("4\n1 1\n-1 1\n-1 -1\n1 -1\n") == "", "symmetric square"

 | 小さな三角形 | 写真 >0 | 基本的な正しさ |

 ## 特殊なケース

 原点を通る任意の線に沿った点のセットが完全に同一線上にある場合、すべての重心ペアが同じ線上に配置されます。 A と B の間の外積は常に 0 であり、すべての候補ウィンドウが共線性を保持しているため、アルゴリズムは非ゼロ領域を正しく検出することはありません。 

原点の周りに正方形を形成する点などの対称的な構成では、複数の同等の最適なパーティションが生成されます。 スライディング ウィンドウでは、同一の重心差を持ついくつかの間隔が発生しますが、どれが選択されたとしても最大値は安定しています。 

非常に小さい入力、特に n = 2 の場合、単一の有効なパーティションに減ります。 ウィンドウ ロジックは自然に可能な分割のみを選択し、両方のグループに正確に 1 つの点が含まれるため、重心の計算は明確に定義されたままになります。
