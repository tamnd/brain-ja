 ## 解決策
 ## 問題の理解

 n 個のクラブのコレクションが与えられており、各クラブに m 個のバッジ タイプの 1 つを割り当てる必要があります。 複数のクラブが同じバッジ タイプを共有できますが、すべてのバッジ タイプが少なくとも 1 回表示される必要があります。 

参加者は課題が決まった後、繰り返しクラブを訪問します。 各訪問では、以前の訪問とは無関係に、すべての n クラブから一様にランダムにクラブが選択され、参加者はそのクラブのバッジを受け取ります。 このプロセスは、参加者がすべてのバッジ タイプを少なくとも 1 つ収集するまで続きます。 すべての m タイプを収集するために必要な予想訪問数が最小になるように、クラブへのバッジ タイプの割り当てを選択し、その最小期待値を出力するように求められます。 

ランダム性は完全にクラブの繰り返しのユニフォーム選択にあります。 唯一の制御は、n 個のクラブに m タイプをどのように配分するかであり、これにより、1 回の訪問で各タイプが出現する可能性が決まります。 

この制約は、n が 100000 まで、m が 5000 まで、m が n を超えないことを意味します。 これにより、プロセスを明示的にシミュレートしたり、すべての割り当てを列挙したりするソリューションは即座に除外されます。 O(nm) の構造でさえ境界線にあり、すべての m 型のサブセットを含むものは、高度に最適化されるか回避可能な場合にのみ実行可能です。 主な難しさは、答えがカウントだけではなく、割り当てによって引き起こされる完全な確率分布に依存することです。 

素朴な直感で推論すると、微妙な問題が現れます。 バッジを均等に散布することが常に最適であると想定し、標準のクーポン コレクターの公式を直接組み込んで均一の確率を求める人もいるかもしれません。 これは、n が m で割り切れない場合に壊れます。 

たとえば、n = 3 および m = 2 の場合、カウント (2, 1) の分割が強制され、確率は 2/3 と 1/3 になります。 単純な「型全体で均一」推定では誤って 3 が得られますが、正しい期待値は 3.5 です。これは、確率の不均衡が非線形な形で実行時間に直接影響することを示しています。 

別の故障モードは、1/p_i の合計など、バッジ タイプごとの予想時間に対する直線性を仮定することです。 収集は順次ではなく並列であるため、これは非常に重要です。 

## アプローチ

 この割り当てでは、m 個のバッジ タイプにわたる確率分布を定義します。 タイプ i が a_i クラブに出現する場合、1 回の訪問でタイプ i が確率 p_i = a_i / n で生成されます。 このプロセスは、不均一な確率を伴う古典的なクーポン収集問題になります。 

固定分布の場合、すべてのタイプが表示されるまでの予想時間は、レート p_i の独立した指数クロックの到着時間の分布によって決まります。 これにより、指数変数の最大値の期待に関する既知の包含/除外形式が得られます。 

E = (-1)^{|S|+1} の空でない部分集合 S の合計 / (S 内の p_i の合計)

 この式は正しいですが、型のすべてのサブセットに依存し、m で指数関数的になります。 

次に、最適化問題は、a_i ≥ 1 の整数 p_i = a_i / n を選択し、合計 a_i = n を選択して、この対称凸式を最小化します。 関数の構造は、確率のバランスが最適であることを意味します。2 つの確率が異なる場合、質量を大きい方から小さい方に移動すると、期待値が減少します。 これは、レートの対称凸関数に対する標準的なメジャー化議論です。 

したがって、最適な構造は、バッジ タイプ間でクラブをできるだけ均等に分配することです。 基数 = n / m、剰余 = n % m とします。 その後、残りのタイプは基本 + 1 クラブを取得し、残りは基本クラブを取得します。 

この分布を修正した後、問題は 2 つの値のみを含む確率のマルチセットの予想カバー時間を評価することに帰着します。 残りの課題は、最大 5000 までの m に対して包含排除式を効率的に計算することです。

直接サブセットを列挙することは不可能です。 ただし、確率は 2 つの値しかとらないため、各グループからの要素の数によってサブセットをグループ化し、問題をサブセットからカウントに減らすことができます。 これにより、「確率が高い」タイプと「確率が低い」タイプがいくつ含まれるかという選択に基づいて、指数構造が 2 次元の合計に分解されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべての割り当てを列挙 + シミュレート | 指数 | お(1) | 遅すぎる |
 | 配布 + 完全なサブセットの包含/除外を修正 | O(2^m) | O(m) | 遅すぎる |
 | 確率クラスによる分布 + グループ化を修正 | O(m^2) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 私たちは、最適な確率分布を構築し、次にその分布に対して予想されるカバー時間を評価するという 2 つの概念フェーズに進みます。 

### 1. バッジの頻度のバランスを取る

 まず、各バッジ タイプが占めるクラブの数を決定します。 すべてのタイプが少なくとも 1 回は出現する必要があるため、各タイプに 1 つのクラブを与えることから始めます。 残りの n − m 個のクラブは、可能な限り均等に分散されます。 これにより、最大 1 だけ異なる 2 つの周波数値が生成されます。 

このステップは単なるヒューリスティックではありません。 バランスの取れた分布から逸脱すると、一方が他方よりも厳密に頻度が高いタイプのペアが作成され、クラブを頻度の高いタイプから頻度の低いタイプにシフトすると、レートのカバータイム関数の凸性により、予想される時間が厳密に減少します。 

### 2. 頻度を確率に変換する

 各タイプ i には確率 p_i = a_i / n があります。 バランス調整後、確率 p_high = (base + 1) / n の k 個のタイプと、確率 p_low = Base / n の m − k 個のタイプが存在します。 

### 3. サブセットのグループ化により予想されるカバー時間を評価する

 指数関数的な時計の解釈を使用します。各タイプ i にはレート p_i の独立した指数関数的到着時間があり、答えは予想される最大到着時間です。 

指数関数の最大値の期待値は、サブセットに対する包含/除外を使用して記述することができます。 すべてのサブセットを直接反復するのではなく、サブセットに含まれる確率の高い要素と低い要素の数に基づいてサブセットをグループ化します。 

i 個の高確率タイプと j 個の低確率タイプを含むサブセットの場合、合計レートは i・p_high + j・p_low であり、そのようなサブセットの数は C(k, i) · C(m − k, j) です。 空のサブセットを除くすべての有効なペア (i, j) を、サブセット サイズに基づいて交互に符号を付けて合計します。 

これにより、サブセットに対する指数関数的な計算からカウントに対する二重加算へと計算が軽減されます。 

### なぜ効果があるのか

 重要な不変条件は、タイプの同一性ではなく、確率の合計のみが重要であるため、包含-除外拡張のどの時点でも、等しい構成のサブセットが同じように寄与するということです。 グループ化では、サブセットの正確な多重度が維持され、アイデンティティベースの列挙が組み合わせカウントに置き換えられます。 すべての有効なサブセットは (i, j) によって一意に分割されるため、項が失われたり重複したりすることはなく、結果の合計は元の期待式と等しくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    base = n // m
    rem = n % m

    k = rem  # number of high-frequency types

    p_high = (base + 1) / n
    p_low = base / n

    # Precompute binomial coefficients up to m
    C = [[0.0] * (m + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        C[i][0] = 1.0
        for j in range(1, i + 1):
            if j == i:
                C[i][j] = 1.0
            else:
                C[i][j] = C[i - 1][j - 1] + C[i - 1][j]

    ans = 0.0

    for i in range(0, k + 1):
        for j in range(0, m - k + 1):
            if i == 0 and j == 0:
                continue
            sign = 1.0 if (i + j) % 2 == 1 else -1.0
            rate = i * p_high + j * p_low
            ans += sign * C[k][i] * C[m - k][j] / rate

    print(ans)

if __name__ == "__main__":
    solve()
```コードは、バッジ タイプ間でクラブを最適に分割することから始まります。 次に、m は O(m^2) 前処理に十分小さいため、標準のパスカル三角形を使用して二項係数を計算します。 

二重ループは、グループ化された包含/除外を実装します。 各用語は、固定数の高周波タイプと低周波タイプを持つすべてのサブセットに対応します。 交互の符号はサブセットのサイズのみに依存し、分母はそのサブセットの合計レートになります。 

必要な精度は 1e-6 であり、すべての中間値は m が 5000 までの安定した範囲内に収まるため、浮動小数点演算で十分です。 

## 実用的な例

 ### 例 1

 入力:

 n = 3、m = 2

 Base = 1、rem = 1 なので、k = 1 となります。 

1 種類は確率 2/3、もう 1 種類は確率 1/3 です。 

次のように計算します。 

| 私（高い） | j (低) | サブセットのサイズ | サイン | レート | 貢献 |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 0 | 1 | + | 2/3 | +1.5 |
 | 0 | 1 | 1 | + | 1/3 | +3 |
 | 1 | 1 | 2 | − | 1 | −1 |

 合計すると 3.5 になります。 

これは、レアタイプが待ち時間を支配しているという直感と一致しており、そのアンバランスさが一律ケースを超えて期待を高めます。 

### 例 2

 入力:

 n = 111、m = 7

 ここで、base = 15、rem = 6 であるため、6 種類の確率は 16/111、1 種類の確率は 15/111 です。 

計算は同じ構造に従いますが、分割が大きくなります。 まれなタイプを含むサブセットが含まれる場合、待ち時間がわずかに長くなり、完全に均一な場合と比較して全体的な期待値が増加します。 

グループ化された列挙により、明示的にリストすることなく、すべての 2^7 サブセットを 1 回だけ正確に説明できるようになります。

 ## 特殊なケース

 n が m に等しい場合、すべてのタイプが 1 回だけ出現するため、各訪問で一様にランダムなタイプが明らかになります。 このアルゴリズムは k = 0 の剰余を生成し、同一の確率と、古典的な m 次高調波の動作を評価する安定した包含除外和をもたらします。 

m = 1 の場合、プロセスは最初の訪問の直後に終了します。 このアルゴリズムは 1 の単一確率を生成し、基本ケースを除くすべてのサブセット項が消滅し、期待値 1 が得られます。 

n が m よりわずかに大きい場合、ほとんどのタイプの確率は 1/n ですが、少数のタイプの確率は 2/n になります。 これにより、強い不均衡が生じ、包含/除外式により、まれなタイプを含むサブセットが大きく重み付けされます。 グループ化された計算は、同一性ではなく構成によって寄与を区別するため、これを正確に捉えます。
