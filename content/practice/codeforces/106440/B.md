 ## 問題の理解

 平面内に一連の個別の点が与えられます。 タスクは、これらの点を 2 つの空でないグループ (A と B と呼びます) に分割し、A によって形成される凸包と B によって形成される凸包が、内部でも境界でもまったく接触しないようにすることです。 

より単純な幾何学的用語では、「輪ゴム形状」が完全に分離されており、結果として得られる 2 つの凸多角形の間にギャップがある 2 つの点グループを探します。 両方のグループが空でなく、素である限り、任意の数の点を自由に無視できます。 

制約の重要な幾何学的意味は、点が最大 500 個あり、同一線上にある 3 点がないということです。 最後の条件では、単一の線分上に多数の点が存在するなどの縮退が除去されます。これにより、凸包の推論が簡素化されます。これは、すべての包頂点が明確に定義され、厳密に左または右に回転するためです。 

500 ポイントの場合、O(n log n) または O(n²) の解でも許容されます。 立体的以上のものは不要です。 

素朴な直感が微妙に失敗するケースは、たとえば入力の前半を A、後半を B とするなどして、ポイントを恣意的に分割しようとすることです。たとえ両方のセットが空でなくても、それらの凸包が大きく重なり合う可能性があります。 

たとえば、4 つの点が順番に正方形を形成し、インデックスによって対角線に分割すると、凸包が両方とも正方形全体である 2 つのセットが生成されるため、セットが互いに素であっても完全に交差します。 

これは、パーティションが入力順序ではなくジオメトリを尊重する必要があることを示しています。 

## アプローチ

 強引なアイデアは、ポイントを 2 つの空でないサブセットに分割するあらゆる方法を試し、それらの凸包が交差するかどうかを確認することです。 各パーティションについて、2 つの凸包を計算するには O(n log n) のコストがかかり、可能なパーティションは 2ⁿ あるため、このアプローチは n = 30 の場合でも完全に実行不可能です。 

問題の構造から、検索する必要はまったくないことがわかります。 私たちは何らかの施策を最適化するように求められているわけではありません。 必要なのは、有効な分離が 1 つだけ存在することです。 

重要な観察は、残りすべての点の凸包の厳密に外側にあることが保証されている単一の点を見つけることができれば、それを 1 つのグループとして分離できるということです。 単一の点には、それ自体のみで構成される縮退した凸包があります。そのため、それが他の包の外側にある場合、2 つの包は自動的に切り離されます。 

これにより、タスクはセット全体の凸包の頂点である点を見つけるだけになります。 凸包の頂点は、他の点の凸の組み合わせとして記述することはできません。つまり、削除後に残りの点の凸包の内側に位置することはできません。 

したがって、問題全体は、グローバル凸包を計算し、その頂点の 1 つを選択することに集約されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | サブセットに対するブルート フォース | O(2ⁿ · n log n) | O(n) | 遅すぎる |
 | 凸包頂点選択 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 まず、標準の単調連鎖アルゴリズムを使用して、指定されたすべての点の凸包を計算します。 

1. すべての点を X 座標で並べ替え、Y 座標で結合を解除します。 これにより、船体を構築するための決定的な順序が与えられます。 
2. 点を左から右にスキャンして、船体下部を構築します。 新しいポイントを追加するたびに、形成された最後のターンが厳密な反時計回りのターンではない間に、船体から最後のポイントを削除します。 これにより、下側の境界が凸状になります。 
3. 右から左にスキャンして、同じ凸状条件を適用して、上部ハルを同様に構築します。 
4. 2 つのハルを結合して、完全な凸多角形を取得します。 この構造に残るすべての点は、セット全体の凸包の頂点になります。 
5. これらのハル頂点のいずれかを選択し、セット A に配置します。 
6. 残りのすべての点をセット B に配置します。

単一のハル頂点のみを選択する理由は、それが完全な構成の極点であることが保証されているため、残りの点の凸包に含めることができないためです。 

### なぜ効果があるのか

 すべての点の凸包は、それらを含む最小の凸集合です。 このハルの頂点はいずれも、ある方向の端点です。これは、他のすべての点が厳密にその頂点の片側に位置する支持線が存在することを意味します。 

このような頂点を削除すると、残りの点はすべて、その頂点を含まない凸領域内に存在します。 凸包は凸の組み合わせの下で閉じられているため、削除された頂点は残りの点から再構築できません。これは、凸包の外側にあることを意味します。 

したがって、A の凸包は 1 点であり、B の凸包はその点を含まない多角形になります。 2 つの素な凸集合は内部でも境界でも交差できないため、条件は満たされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

n = int(input())
pts = []
for i in range(n):
    x, y = map(int, input().split())
    pts.append((x, y, i + 1))

pts.sort()

lower = []
for p in pts:
    while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
        lower.pop()
    lower.append(p)

upper = []
for p in reversed(pts):
    while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
        upper.pop()
    upper.append(p)

hull = lower[:-1] + upper[:-1]

# pick any hull vertex
a_idx = hull[0][2]
A = [a_idx]
B = [p[2] for p in pts if p[2] != a_idx]

print(len(A), len(B))
print(*A)
print(*B)
```このコードは、単調連鎖法を使用して凸包を構築します。 外積は左折のみを強制するために使用され、構造が凸状のままであることを保証します。 

ハルを計算した後、単純に最初のハル頂点を取得します。 船体のどの頂点も同様に機能します。そのような点はすべて極端であることが保証されているためです。 

残りの点は B に収集されます。凸面によって分離が保証されるため、追加の幾何学的チェックは必要ありません。 

## 実用的な例

 凸五角形を形成する 5 つの点の小さな構成を考えてみましょう。 

| ステップ | 船体構造 | 選択された A | 残りB |
 | --- | --- | --- | --- |
 | 並べ替え後 | x-y 順に並べられた点 | - | - |
 | 船体下部 | 凸状の境界を構築します | - | - |
 | 上部船体 | ポリゴンを完成します | - | - |
 | 最終的な船体 | 全5点 | - | - |
 | 選択 | 最初のハル頂点 | 1 つの頂点 | その他 |

 この場合、五角形の頂点を選択するとその点が分離され、残りの 4 つは依然としてその点を含まない凸多角形を形成します。 

ここで、点が内部に点を持つ密な凸形状を形成する場合を考えてみましょう。 

| ステップ | 観察 |
 | --- | --- |
 | 入力 | 多くの内部点と境界点 |
 | 船体結果 | 外側の境界点だけが残ります |
 | セレクション | 任意の境界頂点 |
 | Bセット | その頂点を除くすべての点 |

 これは、内部点がハルには決して現れず、安全に B に含まれるため、内部点が正確さに影響を与えないことを示しています。

 ## 特殊なケース

 重要な状況の 1 つは、すべての点が凸包の境界上にある場合です。 この場合、ハルにはすべての点が含まれていますが、単一の頂点は依然として分離に有効です。 アルゴリズムは頂点を選択して A に配置し、残りを B に残します。残りの点はその頂点を除外する凸多角形を形成するため、分離は維持されます。 

もう 1 つのケースは、内部ポイントが多数ある場合です。 これらの点はハルには決して現れませんが、安全に B に配置されます。B の凸包は完全なハルと比較して縮小する可能性がありますが、削除された極端な頂点を含めることはできません。 

最後の微妙なケースは、同じ最大 x 値を持つ複数の点など、複数の点が極端な座標を共有する場合です。 単調チェーンは依然として真の極端な境界頂点を選択します。すべてが残りの凸包の外側にあることが保証されているため、それらのいずれかを選択するだけで十分です。
