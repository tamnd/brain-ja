 ## 解決策
 ## 問題の理解

 私たちは、各サーバーが固定ビット範囲の整数ラベル (暗号化キー) を持つサーバーのネットワークを与えられています。 サーバーのいくつかのペアが接続されており、2 つのエンドポイントが現在異なる値を保持している場合にのみ、接続は安全であると見なされます。 

2 つの独立した方法で動作するウイルスが導入されました。 まず、数字を選択します$x$同じビット範囲内です。 次に、サーバーのサブセットを選択します。$A$。 すべてのサーバー$A$値は次のビット単位の XOR で置き換えられます。$x$、サーバーが外部にある間$A$変わらないまま。 この変換後、すべてのエッジが 2 つの異なる値を接続しているかどうかを確認します。 

タスクはペアの数を数える事です$(A, x)$は有効です。つまり、この XOR 変換を正確にサーバーに適用した後、$A$、エッジが単色になりません。 

制約は大きく、最大で$5 \cdot 10^5$サーバーとエッジ、$k \le 60$。 これにより、ノードのサブセットを反復したり、ノードの各選択をシミュレートしたりするアプローチは即座に除外されます。$A$。 小さい唯一の組み合わせオブジェクトは XOR 値空間であり、次のサイズがあります。$2^k$ただし、それぞれのノードのすべてのサブセットを反復処理することもできます。$x$不可能です。 

素朴なアプローチで解決します$x$、すべてのサブセットを試してください$A$、すべてのエッジをチェックします。 それはすでにコストがかかります$O(2^n \cdot m)$、それは限界をはるかに超えています。 

もう少し単純でない考えは、次のように修正することです。$x$そして制約について推論してみます$A$、ただし、サブセットごとの妥当性を決定したとしても、依然として指数関数的になります。 

グラフにエッジがない場合、微妙なエッジ ケースが発生します。 その場合、すべてのペア$(A, x)$有効です。$2^n \cdot 2^k$。 誤ってエッジが存在すると仮定したソリューションは、ここでは失敗します。 

もう 1 つの特殊なケースは、エッジ上のすべての XOR 値が同一である場合です。 次に、制約は、ごとに 1 つのグローバル制約にまとめられます。$x$、値によるエッジのグループ化が間違っていると、サブセットの過大カウントまたは過小カウントが発生することがよくあります。 

## アプローチ

 サブセットの修正$A$、ウイルスの影響は、ノードが未処理と XOR 反転の 2 つのグループに分割されると理解できます。 エッジ用$(u, v)$、両方のエンドポイントが反転されていない、両方が反転されている、または 1 つだけが反転されているという 3 つの状況が重要です。 

両方のエンドポイントが同じ状態にある場合、元の保証によって安全性がすでに保証されています。 唯一の危険な状況は、1 つのエンドポイントだけが反転された場合です。 その場合、条件はこうなります$c_u \oplus c_v \ne x$。 したがって、次のように定義されたカットを横切るすべてのエッジは、$A$値を禁止します$x = c_u \oplus c_v$。 

これはキー構造です: 固定サブセットの場合$A$、カット全体の個別のエッジの重みごとに 1 つずつ、禁止された XOR 値のセットを取得します。 ペア$(A, x)$は次の場合にのみ有効です$x$これらすべての値を回避します。 

したがって、固定の場合$A$、有効な数$x$は$$2^k - |\{\text{distinct } c_u \oplus c_v \text{ across cut edges}\}|.$$難しいのは、すべてのサブセットにわたる個別の値をカウントすることです。$A$自明ではない。 ブルート フォース アプローチでは、サブセットを列挙し、これらのセットを明示的に計算しますが、これは指数関数的です。 

重要な観察は、合計を修正するのではなく、逆にすることです。$A$、すべての可能な XOR 値を合計します。$y$サブセットがいくつあるかを数えます$A$この値は禁止されたセットに含まれます。 これにより、問題はそれぞれの理解に帰着します。$y$、値を持つエッジが少なくとも 1 つ存在する場合$y$切り込みを越える。 

固定値の場合$y$、端点が次を満たすすべてのエッジを考慮します。$c_u \oplus c_v = y$。 このグラフを呼び出します$G_y$。 サブセット$A$禁止しません$y$まさにエッジがないとき$G_y$カットを横切っています。つまり、すべてのエッジの両方の端点が同じ側にあります。 これはつまり$A$接続されたコンポーネントの和集合である必要があります$G_y$。 

したがって、禁止を回避するサブセットの数は$y$等しい$2^{\text{components in } G_y}$。 あるので$2^n$サブセットの合計、禁止する数$y$は$2^n - 2^{\text{comp}_y}$。 

これにより、グローバル問題が XOR 値ごとのグラフ接続性の計算に変換されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | サブセットに対するブルート フォース |$O(2^n \cdot m)$|$O(n)$| 遅すぎる |
 | XOR 値 + グループごとの DSU によるグループ化 |$O(m \alpha(n))$|$O(n + m)$| 承認済み |

 ## アルゴリズムのチュートリアル

 合計ペアから禁止された XOR 値による修正を差し引いた 2 層のカウントを使用して、答えを書き直します。 

1. コンピューティング$2^n$、サブセットの数$A$、 そして$2^k$、可能な XOR 値の数。 これらはベース製品を形成します$2^n \cdot 2^k$制約が存在しない場合、これが答えになります。 
2. すべてのエッジについて、その XOR ラベルを計算します。$w = c_u \oplus c_v$。 同一の値でグループ化されたエッジを収集する$w$。 これにより、グラフがいくつかのサブグラフに分割され、それぞれが特定の禁止された XOR 値に対応します。 
3. 各 XOR 値について$w$、その重みを持つエッジによって形成される部分グラフのみを考慮します。 これらのエッジに表示される頂点のみに DSU を構築します。 これにより、この特定の禁止値によって引き起こされる接続が分離されます。 
4. このサブグラフ内の連結成分の数を計算します。 値が使用されている場合$k_w$個別の頂点と$c_w$それらの間で接続されたコンポーネント、さらに孤立した頂点も含めると、コンポーネントの総数は次のようになります。$n - k_w + c_w$。 
5. サブセットの数$A$これにより、エッジ交差の作成が回避されます$w$等しい$2^{n - k_w + c_w}$。 これは、接続された各コンポーネントが完全に内側または外側にある必要があるためです。$A$。 
6. これをすべてのサブセットにわたる寄与に変換します。$w$、実際に作成されるサブセットの数$w$禁じられているのは$2^n - 2^{n - k_w + c_w}$。 
7. すべての個別の XOR 値を合計し、合計から減算します。$2^n \cdot 2^k$。 これにより最終的な答えが得られます。 

正確さは、各固定 XOR 値に対する不変条件に依存します。$w$、 かどうか$w$禁止値として現れるのは、重みのエッジがあるかどうかのみに依存します。$w$切り口を越えます。 この状態は、コンポーネントの一貫性を侵害することに相当します。$G_w$、DSU が正確にキャプチャします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

class DSU:
    def __init__(self):
        self.parent = {}
        self.size = {}

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def add(self, x):
        if x not in self.parent:
            self.parent[x] = x
            self.size[x] = 1

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]

def solve():
    n, m, k = map(int, input().split())
    c = list(map(int, input().split()))

    groups = {}
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        w = c[u] ^ c[v]
        if w not in groups:
            groups[w] = []
        groups[w].append((u, v))

    pow2_n = modpow(2, n)
    pow2_k = modpow(2, k)

    distinct = len(groups)

    ans = pow2_n * pow2_k % MOD

    for w, edges in groups.items():
        dsu = DSU()
        used = set()

        for u, v in edges:
            dsu.add(u)
            dsu.add(v)
            used.add(u)
            used.add(v)
            dsu.union(u, v)

        # count components among used nodes
        comp_roots = set()
        for x in used:
            comp_roots.add(dsu.find(x))

        k_w = len(used)
        c_w = len(comp_roots)

        comp_total = (n - k_w) + c_w
        ans -= pow2_n - modpow(2, comp_total)
        ans %= MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```DSU は、XOR 値グループごとに独立して使用され、同じ XOR 差を共有するエッジのみによって引き起こされる接続をキャプチャします。 重要な点は、グループに含まれていない頂点が孤立したコンポーネントとして扱われることです。そのため、頂点が寄与するのです。$n - k_w$明示的に挿入されるのではなく、直接挿入されます。 

最後のループでは、XOR 値ごとに、その値が禁止されたセットに現れるサブセットの数を減算します。 これにより、サブセットを明示的に追跡することが回避され、ソリューションがエッジの数において線形に保たれます。

 ## 特殊なケース

 グラフにエッジがない場合、すべてのサブセット$A$すべての場合に有効です$x$、そして答えは次のようになります。$2^n \cdot 2^k$。 グループがないため、減算は適用されないため、アルゴリズムはこれを自然に処理します。 

すべてのエッジが同じ XOR 値を生成する場合、グラフ全体が 1 つの DSU インスタンスとして処理されます。 コンポーネント数は、禁止された交差の作成を回避するサブセットの数を直接制御し、孤立した頂点は、$n - k_w$学期。 

エッジがまばらで、それぞれが一意の XOR 値を持つ場合、各グループにはエッジが 1 つだけ含まれるため、各 DSU には 1 つまたは 2 つのノードが含まれます。 これにより、問題は 1 つのエッジがサブセットを分割する頻度を数えるというものになり、次の式と一致します。$2^n - 2^{n-1}$エッジグループごとに、一般的な式との一貫性を確認します。
