 ## 解決策
 ## 問題の理解

 元のネットワークは接続されたマルチグラフです。 すべてのノードには現在の次数があり、これはノードに接続されているファイバー リンクの数を意味します。 新しいネットワークは、ノードの各ペア間に 1 つのルートが必要であるため、ツリーである必要があります。 ツリーは常に正確に`n - 1`エッジ。 目標は、できるだけ多くのノードのノード次数が古い次数と一致するツリーを選択し、変更されたノードの最小数とそのような 1 つのツリーの両方を出力することです。 

制約は、線形または線形に近いグラフ アルゴリズムには十分小さいです。 グラフには最大で次のものを含めることができます`10000`ノードと`100000`したがって、可能なツリーを繰り返し試したり、次数の総和に対して動的プログラミングを使用したりすることは現実的ではありません。 ツリー次数シーケンスの構造を利用する必要があります。 

いくつかの特殊なケースは見落とされがちです。 入力グラフがすでにツリーである場合、すべての次数は変更されないままにすることができます。 例えば：```
4 3
0 1
1 2
2 3
```答えは、`0`既存のエッジがすでに有効なツリーを形成しているためです。 

もう 1 つのケースは、すべての頂点の次数が大きい密グラフです。```
4 4
0 1
1 2
2 3
3 0
```すべてのノードには次数があります`2`、ただし、4 つの頂点上のツリーには次数の和があります。`6`、 ない`8`。 4度すべてを維持することは不可能です。 次数シーケンスがグラフィカルであるかどうかだけをチェックする不注意な解決策は失敗します。ツリーの合計条件がより厳密であるためです。 

最後のコーナーケースは、多くの頂点に次数がある場合です。`1`。 休暇は内部学位予算を消費しないため、非常に貴重です。 例えば：```
5 4
0 1
0 2
0 3
0 4
```度数はすでにツリー度数シーケンスになっています。 センターは学位を保持します`4`そしてすべての葉は程度を保ちます`1`。 

## アプローチ

 ブルートフォースソリューションでは、多くの可能なツリーを構築し、それらの次数シーケンスを入力と比較しようとする可能性があります。 ラベル付きの木の数は`n^(n-2)`の値が小さい場合でもこれは不可能になります。`n`。 次数が保存される可能性のある頂点のサブセットの数は次のとおりであるため、検索を可能な次数シーケンスに制限しても十分には役に立ちません。`2^n`。 

重要な観察は、ツリー次数シーケンスには非常に単純な条件があるということです。 すべての頂点について、その寄与を次のように定義します。`degree - 1`。 どのツリーでも:```
sum(degree - 1) = n - 2
```次数を持つ頂点`1`貢献度はゼロです。 いくつかの頂点を保持することにした場合、その合計寄与度は以下を超えることはできません。`n - 2`。 不足している寄与は、変更された頂点に割り当てることができます。 

問題は、その値を持つ頂点の最大数を選択することになります。`degree - 1`～の容量に収まる`n - 2`。 選択されたすべての項目の重要度は同じであるため、最初に最小の寄与を選択する必要があります。 

保持する頂点を選択した後、残りの頂点をすべて変更できます。 残りの貢献をすべてそのうちの 1 つに割り当て、他のものを残します。 ツリー和を満たす正の次数シーケンスはツリーとして実現でき、標準的なプリューファーシーケンス構築でそれを構築できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) 以上 | O(n) | 遅すぎる |
 | 最適 | O(n log n + n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 元のグラフ内のすべてのノードの次数を計算します。 すべての学位を貢献に変換する`degree - 1`。 
2. 頂点を寄与度でソートし、合計が以下を超えない限り最小の寄与度を取り続けます。`n - 2`。 

選択された頂点は、ツリー内で元の次数を保持できる頂点です。 最小の寄与を選択すると、固定ツリー次数バジェットに収まる頂点の数が最大になります。 
3. 他のすべての頂点を変更済みとしてマークします。 ツリーに必要な残りの貢献は次のとおりです。`remaining = n - 2 - sum(kept contributions)`。 

この値全体を 1 つの変更された頂点に割り当てます。 Its final degree becomes`remaining + 1`。 変更された他のすべての頂点は寄与ゼロを受け取るため、リーフになります。 
4. 結果の次数シーケンスを使用してツリーを構築します。 

便利な方法は、Prüfer シーケンスを作成することです。 次数を持つ頂点`d`正確に表示されます`d - 1`プリューファー数列の 1 回です。 このシーケンスをデコードすると、必要な次数を正確に持つツリーが生成されます。 

なぜ効果があるのか:

 保持される頂点の合計寄与度は最大でも`n - 2`、したがって、残りの寄与は常に負ではありません。 残りのすべての寄与を変更された頂点に加算すると、寄与の合計が正確になるため、有効なツリー次数シーケンスが生成されます。`n - 2`。 保存された頂点ごとにコストがかかるため、貪欲な選択が最適です。`degree - 1`同じ容量のユニットなので、最小のコストを使用すると、可能な限り最大の頂点数が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    deg = [0] * n
    for _ in range(m):
        a, b = map(int, input().split())
        deg[a] += 1
        deg[b] += 1

    order = sorted(range(n), key=lambda x: deg[x] - 1)

    keep = [False] * n
    used = 0
    cnt = 0
    for v in order:
        if used + deg[v] - 1 <= n - 2:
            used += deg[v] - 1
            keep[v] = True
            cnt += 1

    ans = []
    new_deg = [1] * n
    changed = []
    for i in range(n):
        if keep[i]:
            new_deg[i] = deg[i]
        else:
            changed.append(i)

    if changed:
        rem = n - 2 - sum(new_deg[i] - 1 for i in range(n) if keep[i])
        new_deg[changed[0]] = rem + 1

    prufer = []
    for i in range(n):
        for _ in range(new_deg[i] - 1):
            prufer.append(i)

    leaves = [i for i in range(n) if new_deg[i] == 1]
    import heapq
    heapq.heapify(leaves)

    edges = []
    for x in prufer:
        leaf = heapq.heappop(leaves)
        edges.append((leaf, x))
        new_deg[leaf] -= 1
        new_deg[x] -= 1
        if new_deg[x] == 1:
            heapq.heappush(leaves, x)

    if len(leaves) == 2:
        a = heapq.heappop(leaves)
        b = heapq.heappop(leaves)
        edges.append((a, b))

    out = [str(n) + " " + str(n - 1)]
    out.extend(f"{a} {b}" for a, b in edges)
    print(cnt)
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```最初の部分は度数のみをカウントします。 新しいネットワークは任意のワイヤレス リンクを使用する可能性があるため、この時点以降は元のエッジ自体は無関係になります。 

貪欲な選択では、`degree - 1`度数ではなく、すべてのツリーで合計が固定された量であるためです。 この値で並べ替えると、保持される頂点の最大数が得られます。 

プリューファー数列の構築は、度数からエッジへの最終変換です。 シーケンスの長さは正確に`n - 2`、頂点が出現するたびに、最終次数が 1 ずつ減ります。 リーフのヒープにより、デコード時に常に有効なリーフが選択されることが保証されます。

 ## 特殊なケース

 元のグラフがすでにツリーである場合、合計寄与率は正確に次のとおりであるため、容量の計算ではすべての頂点が保持されます。`n - 2`。 この構築により、同じ次数シーケンスを持つツリーが再作成されます。 

サイクルなど、グラフの合計次数が多すぎる場合、貪欲なステップにより、寄与が適合するまで高価な頂点が削除されます。 削除された頂点はリーフまたは 1 つのより高次のコネクタに変換されるため、最終的なシーケンスは正しく合計されます。 

多くの頂点がリーフである場合、それらの寄与はゼロであるため、貪欲なプロセスによって自動的に頂点が維持されます。 これは、葉がツリー内で保存するのに最も安価な頂点であるという事実と一致します。
