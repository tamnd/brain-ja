 ## 解決策
 ## 問題の理解

 都市は長方形の建物が格子状に並んでいます。 各セルには 1 つの建物の高さが格納されます。 ロビンは 1 つの建物の中心から開始し、他のすべての建物に到達するために必要なジャンプの最小回数を知りたいと考えています。 ジャンプは常に屋根の中心で開始および終了し、同じ初速度を使用します。`v`、発射角度を変更することで選択された発射体の軌道に従います。 

出力は、隠れ家の建物からすべてのセルまでの最短のジャンプ数です。 建物にまったく到達できない場合、建物は受信します。`X`。 

グリッドは小さく、最大でも 20 × 20 の建物があるため、可能な位置は 400 しかありません。 これにより、重いグラフ アルゴリズムが除外されますが、考えられるすべての建物のペアをテストする余裕があることも意味します。 コストがかかる部分はグラフ検索ではなく、1 つのジャンプが物理的に有効かどうかを確認することです。 

いくつかの詳細が単純な解決策を失敗させます。 グリッドのコーナーにタッチするジャンプは、そのコーナーの周囲の建物を 1 つだけではなくすべてクリアする必要があります。 また、発射体には同じ 2 つの建物の間に 2 つの円弧が存在する可能性があり、衝突を回避するには高い方の円弧のみが役立ちます。 最後に、区間上の凹型放物線の最下点は常に区間の端点の 1 つにあるため、すべての建物の中央だけをチェックすることは正しくありません。 

たとえば、次のことを考えてみましょう。```
2 1 10 20 1 1
10 100
```最初の建物から 2 番目の建物への直接ジャンプは、高い建物の上を通過することによってのみ存在する可能性があります。 目的地の高さだけをチェックするソリューションでは、到達可能であると誤ってマークされてしまいます。 

別の例外的なケースは次のとおりです。```
2 2 10 20 1 1
0 100
100 0
```斜めのジャンプはちょうどミーティングコーナーを通過します。 両側の建物とその角に接する 2 つの建物よりも高くなければなりません。 パスの中点を含むセルのみをチェックすると、この衝突は見逃されます。 

## アプローチ

 簡単なアプローチは、すべての建物が頂点となるグラフを構築することです。 順序付けられた建物のペアごとに、物理方程式を解き、可能なジャンプ軌道を取得し、グリッドを通る経路をシミュレートします。 軌道がすべての建物を通過する場合、エッジを追加します。 まず隠れ家から広範囲を探索すると、最小限のジャンプ数が得られます。 

考えられるすべての最初のジャンプが考慮されるため、総当たりのアイデアは正しいです。 ただし、建物の数は最大 400 なので、約 160,000 の有向ペアが存在します。 各ペアがすべての建物をチェックすると、最悪のケースでは約 6,400 万件の衝突チェックが行われることになります。 Python では、衝突テストが効率的であればこれはまだ管理可能ですが、幾何学的作業を繰り返す不注意な実装では速度が非常に遅くなる可能性があります。 

重要な観察は、グラフが小さく、都市自体が小さいことです。 複雑な最短経路技術は必要ありません。 唯一の数学的課題は、単一のジャンプが存在するかどうかを判断することです。 ジャンプ グラフが構築されると、BFS は残りをすぐに解決します。 

物理現象は、垂直速度と水平速度の比率を使用することで単純化できます。 させて$$a = \frac{v_h}{v_d}$$水平距離の場合`d`、開始屋根を基準とした軌道は次のとおりです。$$z(x)=a x-\frac{g x^2(1+a^2)}{2v^2}$$着地の高さは次の二次方程式を与えます。`a`、最大 2 つの可能な軌道を生成します。 有効な解決策を試し、衝突回避には常に少なくとも同等の効果があるため、より高い解決策を維持します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 繰り返しシミュレーションによるブルートフォース | O((dx・dy)^4) | O(dx・dy) | 不用意に実装すると遅すぎる |
 | グラフ + BFS を構築する | O(n^3)、n = dx・dy | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての建物をグラフ ノードとして扱います。 考えられるすべての目的地の建物について、現在の建物から直接ジャンプできるかどうかを計算します。 
2. 水平距離を計算する`d`2 つの屋根の中心の間。 可能な発射形状の二次方程式を解きます。 本当の解決策が存在しない場合、エッジは存在しません。 
3. すべての有効な軌道について、直線の水平パスが横切るすべての建物をチェックします。 パスがグリッド線と交差するたびにパスを分割します。 すべての間隔は 1 つの建物に属し、発射体は凹面であるため、2 つの間隔の終点をチェックするだけで十分です。 
4. 軌道が交差するすべての建物の上に厳密に留まる場合は、2 つの建物の間にエッジを追加します。 
5. ロビンの隠れ家から開始して幅優先探索を実行します。 BFS が初めて建物に到達するときに必要なジャンプの最小回数です。 

なぜ効果があるのか:

 グラフには、ロビンが物理的に実行できるジャンプが正確に含まれています。 軌道方程式と衝突チェックが実際の動きと一致するため、すべての有効なジャンプが追加されます。 交差した建物が軌道と交差する可能性があるため、無効なジャンプはすべて拒否されます。 次に、BFS は重み付けされていないグラフ内の最短パスを見つけます。これはまさに最小ジャンプ数です。 

## Python ソリューション```python
import sys
from math import sqrt, hypot
from collections import deque

input = sys.stdin.readline

g = 9.80665
EPS = 1e-9

dx, dy, w, v, lx, ly = map(int, input().split())
h = [list(map(int, input().split())) for _ in range(dy)]

lx -= 1
ly -= 1
n = dx * dy

def solve_jump(x1, y1, x2, y2):
    if x1 == x2 and y1 == y2:
        return False

    sx = x1 * w + w / 2
    sy = y1 * w + w / 2
    tx = x2 * w + w / 2
    ty = y2 * w + w / 2

    d = hypot(tx - sx, ty - sy)
    dh = h[y2][x2] - h[y1][x1]

    q = g / (2 * v * v)

    # q*d^2*a^2 - d*a + (dh + q*d^2) = 0
    A = q * d * d
    B = -d
    C = dh + q * d * d

    disc = B * B - 4 * A * C
    if disc < -EPS:
        return False

    candidates = []
    if abs(A) < EPS:
        if abs(B) > EPS:
            candidates.append(-C / B)
    else:
        if disc >= 0:
            s = sqrt(max(0, disc))
            candidates.append((-B + s) / (2 * A))
            candidates.append((-B - s) / (2 * A))

    def height_at(dist, a):
        return h[y1][x1] + a * dist - q * dist * dist * (1 + a * a)

    for a in candidates:
        if a < -EPS:
            continue

        vx = tx - sx
        vy = ty - sy

        ts = [0.0, 1.0]

        if abs(vx) > EPS:
            for i in range(dx + 1):
                t = (i * w - sx) / vx
                if EPS < t < 1 - EPS:
                    ts.append(t)

        if abs(vy) > EPS:
            for i in range(dy + 1):
                t = (i * w - sy) / vy
                if EPS < t < 1 - EPS:
                    ts.append(t)

        ts.sort()

        ok = True
        for i in range(len(ts) - 1):
            l = ts[i]
            r = ts[i + 1]
            mid = (l + r) / 2

            mx = sx + mid * vx
            my = sy + mid * vy

            bx = int(mx // w)
            by = int(my // w)

            if bx < 0 or bx >= dx or by < 0 or by >= dy:
                continue

            for t in (l, r):
                dist = d * t
                if t == 1.0:
                    continue
                if height_at(dist, a) <= h[by][bx] + EPS:
                    ok = False
                    break

            if not ok:
                break

        if ok:
            return True

    return False

graph = [[] for _ in range(n)]

for y1 in range(dy):
    for x1 in range(dx):
        u = y1 * dx + x1
        for y2 in range(dy):
            for x2 in range(dx):
                if solve_jump(x1, y1, x2, y2):
                    graph[u].append(y2 * dx + x2)

start = ly * dx + lx
dist = [-1] * n
dist[start] = 0

q = deque([start])
while q:
    u = q.popleft()
    for vtx in graph[u]:
        if dist[vtx] == -1:
            dist[vtx] = dist[u] + 1
            q.append(vtx)

ans = []
for y in range(dy):
    row = []
    for x in range(dx):
        d = dist[y * dx + x]
        row.append(str(d) if d != -1 else "X")
    ans.append(" ".join(row))

print("\n".join(ans))
```グラフの構築はコストがかかる部分です。 プログラムは、順序付けられた建物のペアをすべて試し、発射方程式を解き、グリッド全体で幾何学的スイープを実行します。 

衝突チェックでは、ジャンプが垂直または水平のグリッド ラインを横切るすべてのパラメータ値が収集されます。 連続した値は、1 つの建物内のセクションを表します。 放物線は凹面であるため、そのセクションの最小高さはその端の 1 つであり、連続的なサンプリングは必要ありません。 

すべてのジャンプのコストが等しいため、BFS は通常のキュー トラバーサルを使用します。 距離配列には、各建物に到達する最初のレイヤーが格納されます。 

入力によって高さが変化することが保証されるため、浮動小数点比較では小さなイプシロンが使用されます。`10^-6`答えは変わりません。 目的地の屋根に正確に着陸することが意図されているため、ターゲット エンドポイントは衝突チェック中にスキップされます。

 ## 特殊なケース

 1 つの建物の都市では、1 つのノードとエッジのないグラフが作成されます。 BFS は開始距離をゼロのままにし、これが必要な答えです。 

コーナーを正確に通過するジャンプは、グリッド線の交差点ごとに軌道を分割することによって処理されます。 同じエンドポイントがすべての隣接する間隔からチェックされるため、接触しているすべての建物が考慮されます。 

開始屋根よりも高い目的地には、急な弧が必要になる場合があります。 二次ソルバーは、下の円弧で十分であると仮定するのではなく、両方の可能な軌道を保持し、それらをテストします。 

飛行中に経路が建物の上に留まらなければならないため、別の屋根にかろうじて接触する軌道は拒否されます。 イプシロン比較により、数値ノイズによってこの決定が変更されるのを防ぎます。
