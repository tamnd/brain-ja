 ## 解決策
 ## 問題の理解

 保護区の境界を表す単純な多角形の頂点が与えられます。 受信機はすべての頂点に配置され、すべての受信機は同じ円形のカバレッジ半径を持ちます。 タスクは、多角形内のすべての点が少なくとも 1 つの頂点の距離内に収まる最小半径を見つけることです。 

入力は、反時計回りのポリゴン頂点のリストです。 出力は、ポリゴン内の点から最も近い頂点までの可能な最大距離です。これは、その値がすべての点がカバーされる半径に正確であるためです。 

ポリゴンには最大 2000 個の頂点があります。 二次アルゴリズムは現実的であるため、$2000^2$の演算はわずか約 400 万ですが、キュービック ソリューションではすでに 80 億小切手に近くなります。 座標範囲は$10^4$したがって、最終的な幾何学的答えには浮動小数点が必要ですが、二乗距離は 64 ビット整数内に問題なく収まります。 

よくある間違いは、頂点またはエッジのみをチェックすることです。 最悪の点は厳密にポリゴンの内側にある可能性があります。 たとえば、三角形について考えてみましょう。```
3
0 0
10 0
0 10
```答えはおよそ$7.071067811$。 境界距離のみをチェックすると、3 つの頂点の距離が等しい三角形の中心近くの点を見逃してしまいます。 

もう 1 つの間違いは、最も遠い点が常に多角形全体の外接円の中心であると仮定することです。 凹型多角形では、三角形分割によって作成された 1 つの小さな領域内に最悪の点が存在する可能性があります。 答えは多角形のあらゆる部分を考慮する必要があります。 

## アプローチ

 直接的なアプローチは、候補点を探索することです。 点の場合、すべての頂点までの距離を計算し、最小値を維持できます。 答えはこれらの値の最大値になります。 問題は、候補点が無限にあるため、サンプリング法やグリッド法では精度を保証できないことです。 

有益な観察は、多角形が三角形に分割できることです。 1 つの三角形の内部で最も近い頂点は常に 3 つの三角形の頂点の 1 つ、または別のポリゴンの頂点であり、距離が減少するだけです。 三角形内の最大距離は、点からその 3 つの三角形の頂点までの最大距離です。 

三角形の場合、最も近い頂点から最も遠い点がボロノイ図から見つかります。 外中心が三角形の内側にある場合、3 つの頂点はすべてそこから等しく離れているため、三角形の答えは外周半径になります。 三角形が鈍角の場合、外心は外側にあり、最大値は最長の辺の中点で発生し、その辺の長さの半分になります。 

残りのタスクは、ポリゴンを三角形化することです。 以来$n$は 2000 しかないので、耳切りで十分です。 隣接する三角形が完全にポリゴンの内側にある頂点を繰り返し削除します。 削除されたすべての耳は、最終的な三角形分割の 1 つの三角形になります。 

この強引なアイデアはジオメトリがローカルであるため機能しますが、可能な点のセットが連続しているため失敗します。 三角形ボロノイ候補のみが重要であるという観察により、問題は有限数の幾何学的計算に帰着します。

 ## アルゴリズムのチュートリアル

 1. ポリゴンの頂点を保存し、三角形が 1 つだけ残るまで繰り返し耳を削除します。 頂点は、その前後の頂点が有効な反時計回りの三角形を形成し、その三角形の内側に他のポリゴン頂点が存在しない場合に耳を形成します。 このような三角形を削除すると、残りのポリゴンは保持されます。 
2. 三角形分割によって生成されたすべての三角形について、その三角形の内部の点から最も近い三角形の頂点までの最大距離を計算します。 
3. 三角形が鋭角の場合は、辺の長さと面積を使用してその外周半径を計算します。 外心は三角形の内側にあるため、可能な限り覆われていない点となります。 
4. 三角形が鋭角でない場合は、最も長い辺の半分を取ります。 外心は許容領域の外側にあるため、最良の点はその辺の中点です。 
5. 答えはすべての三角形から得られる最大値です。 これは、すべての三角形、つまり多角形全体をカバーする最小半径です。 

なぜ効果があるのか:

 多角形内のすべての点は、三角形分割の 1 つの三角形に正確に属します。 三角形の内側の点の場合、その三角形の外側に頂点を追加しても、受信可能な受信機が増えるだけであり、最も近い受信機までの距離が短くなるだけです。 したがって、三角形の答えは上限であり、実際にはその三角形の内部で達成可能です。 すべての三角形の最大値を取ると、ポリゴン全体のカバーされていない正確な最悪の点が得られます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

EPS = 1e-12

def cross(a, b, c):
    return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])

def dist2(a, b):
    dx = a[0] - b[0]
    dy = a[1] - b[1]
    return dx * dx + dy * dy

def point_in_triangle(p, a, b, c):
    c1 = cross(a, b, p)
    c2 = cross(b, c, p)
    c3 = cross(c, a, p)
    return c1 >= -EPS and c2 >= -EPS and c3 >= -EPS

def triangle_value(a, b, c):
    ab = math.sqrt(dist2(a, b))
    bc = math.sqrt(dist2(b, c))
    ca = math.sqrt(dist2(c, a))
    mx = max(ab, bc, ca)

    sides = [ab, bc, ca]
    if mx * mx >= sum(x * x for x in sides) - mx * mx - EPS:
        return mx / 2.0

    area2 = abs(cross(a, b, c))
    return ab * bc * ca / area2

def triangulate(poly):
    ids = list(range(len(poly)))
    result = []

    while len(ids) > 3:
        found = False
        m = len(ids)

        for k in range(m):
            a = poly[ids[(k - 1) % m]]
            b = poly[ids[k]]
            c = poly[ids[(k + 1) % m]]

            if cross(a, b, c) <= EPS:
                continue

            ok = True
            for j in ids:
                if j == ids[(k - 1) % m] or j == ids[k] or j == ids[(k + 1) % m]:
                    continue
                if point_in_triangle(poly[j], a, b, c):
                    ok = False
                    break

            if ok:
                result.append((a, b, c))
                del ids[k]
                found = True
                break

        if not found:
            break

    result.append((poly[ids[0]], poly[ids[1]], poly[ids[2]]))
    return result

def solve():
    n_line = input().strip()
    if not n_line:
        return
    n = int(n_line)
    poly = [tuple(map(int, input().split())) for _ in range(n)]

    ans = 0.0
    for tri in triangulate(poly):
        ans = max(ans, triangle_value(*tri))

    print("{:.10f}".format(ans))

if __name__ == "__main__":
    solve()
```の`cross`この関数は、幾何学的配向テストが必要なあらゆる場所で使用されます。 多角形は反時計回りであるため、正の外積は有効な耳のコーナーを識別します。 

イヤー クリッピング ループは、頂点をコピーするのではなく、インデックスを保持します。 耳が削除されると、インデックス リストのみが変更されるため、メモリの使用量は少なく抑えられます。 三角形の境界上の点が耳を無効にしてはいけないため、三角形の内側のテストは包括的です。 

三角形の計算には外周半径の公式が使用されます。$$R=\frac{abc}{4A}$$どこ`area2`店$2A$, したがって、分母は正確に次のようになります`area2`。 鈍角の場合は、外心は三角形の内側にないため、別個に処理されます。

 最大の三角形の寄与が最終的な答えを決定します。 これは、境界点が保護区の内側にあるため、エッジだけをチェックするだけでは不十分である理由を示しています。 

2 番目のサンプルでは、多角形の形状が垂直方向に引き伸ばされます。 

| トライアングルタイプ | サイド情報 | 候補半径 |

 ## 特殊なケース

 三角形は可能な限り最小の多角形です。 入力用```
3
0 0
10 0
0 10
```アルゴリズムは 1 つの三角形を作成し、その外周半径を直接評価します。 外心は三角形の内側にあるので、答えは次のようになります。$10/\sqrt{2}$。 頂点のみをチェックするアプローチは、ゼロを返して失敗します。 

三角形分割内に鈍角三角形を含む多角形には、次のような特殊なケースが必要です。`triangle_value`。 例えば：```
3
0 0
10 0
2 1
```外心は三角形の外側にあります。 このアルゴリズムは、無効な外周半径の代わりに最長エッジの半分を返します。 

凹面ポリゴンでは、さまざまな順序で耳を削除できます。 すべての有効な三角形分割はまったく同じ領域をカバーするため、答えは次数に依存しません。 生成された各三角形は独立して評価されるため、最終的な最大値は変わりません。
