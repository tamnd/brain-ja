 ## 解決策
 ## 問題の理解

 ドアを表す長方形があります。 ワイヤは端点が境界上にある直線セグメントであり、すべてのワイヤは 2 つの異なる側面を接続します。 すべての既存のワイヤが少なくとも 1 つのセグメントと交差するように、新しい直線セグメントをできるだけ少なく配置する必要があります。 

答えは驚くほど小さいものです。 常に 2 つのカットで十分です。長方形の 2 つの対角線が、考えられるすべての境界間ワイヤと交差します。 本当の課題は、1 つのカットですでに十分かどうかを判断することです。 公式の解決策の観察では、ジオメトリを円間隔の問題に変換でき、エンドポイントを並べ替えた後に線形スイープで単一カットの存在をチェックできるということです。 

入力サイズが主な難点です。 ワイヤは最大 100 万本あるため、ワイヤのペアが関係するものは不可能です。 二次アルゴリズムでは、最悪の場合、利用可能な時間をはるかに超えて約 10^12 の比較が実行されます。 各ワイヤを一定の回数だけ処理する方法が必要です。 

座標は最大 10^8 と大きいですが、境界上の点の循環順序を決定するためにのみ使用されます。 任意のセグメント間の幾何学的交差計算は必要ありません。 長方形の構造により、問題を処理しやすくなります。 

よくある間違いは、斜面をテストしたり、考えられる多くのセグメントを試したりしてカットを探すことです。 答えはメートル幾何学によって決まるわけではありません。 重要な情報は、長方形の周囲の端点の順序だけです。 

## アプローチ

 直接的なアプローチでは、考えられるすべての切断を試し、どのワイヤが交差しているかを確認します。 有効なカットは、ワイヤの終点に到達するまでどのワイヤを通過するかを変更することなく継続的に移動できるため、候補を連続する終点間のギャップに制限することができます。 このようなギャップは O(n) 個あり、1 つの候補をすべてのワイヤに対してチェックするには O(n) のコストがかかり、O(n²) 回の演算が行われます。 n = 10^6 では、これは不可能です。 

便利な変換は、長方形の境界を歩き回り、それを線に展開することです。 すべてのワイヤは、この循環順序上の 2 つの終点位置間の間隔になります。 カットは、この円上の間隔を選択することにも対応します。 選択した間隔に 2 つの終点のうちの 1 つが正確​​に含まれる場合、ワイヤーは正確に交差します。 

問題は、各ワイヤからの 1 つのエンドポイントを含む円形の間隔が存在するかどうかを見つけることになります。 これは、アクティブな間隔内で現在 0、1、または 2 つのエンドポイントを持つワイヤの数を維持しながら、2 ポインタ スイープで解決できます。 

このような間隔が存在する場合、その 2 つの境界点によって必要なシングル カットが得られます。 存在しない場合は、常に 2 つのカットで十分であるため、2 つの長方形の対角線が最適です。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

1. すべてのワイヤの終点を長方形の周囲の単一の座標に変換します。 左下隅から開始し、下辺、次に右側、上辺、最後に左側に沿って移動します。 正確な開始点は重要ではありませんが、一貫した循環順序が必要です。 
2. すべてのエンドポイントの位置を並べ替えます。 円間隔を通常の間隔として処理できるように、周囲の長さを追加して並べ替えられたリストを複製します。 
3. この二重化されたアレイ上でスライディング ウィンドウを維持します。 ウィンドウの左端と右端は、可能なカットの 2 つの端点を表します。 すべてのワイヤについて、その 2 つのエンドポイントのうちのいくつが現在ウィンドウ内にあるかを維持します。 
4. ワイヤの両方の端点が内側にならないようにウィンドウを拡張できる間、右ポインタを前方に移動します。 両方の終点が内側にあるワイヤは、対応するカットによって交差することはできません。 
5. 現在のウィンドウ内にすべてのワイヤの端点が 1 つだけある場合、ウィンドウの 2 つの境界位置が有効な単一カットを表します。 
6. そのようなウィンドウが見つからずにスイープが終了した場合は、長方形のわずかに短くなった 2 つの対角線を出力します。 

不変条件は、スライディング ウィンドウが常に、現在の左端点に対して右端点が可能な限り拡張された候補カット間隔を表すことです。 左ポインタはエンドポイント間の可能なすべてのギャップを訪問し、右ポインタは円の周りを前進するだけであるため、このスイープ中にすべての有効な間隔が表示されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, w, h = map(int, input().split())

    events = []
    wires = []

    per = 2 * (w + h)

    def pos(x, y):
        if y == 0:
            return x
        if x == w:
            return w + y
        if y == h:
            return w + h + (w - x)
        return w + h + w + (h - y)

    for i in range(n):
        x1, y1, x2, y2 = map(int, input().split())
        a = pos(x1, y1)
        b = pos(x2, y2)
        wires.append((a, b))
        events.append((a, i))
        events.append((b, i))

    events.sort()

    m = len(events)
    coords = [x[0] for x in events]

    index_a = [0] * n
    index_b = [0] * n
    for i, (_, w_id) in enumerate(events):
        if index_a[w_id] == 0 and index_b[w_id] == 0:
            index_a[w_id] = i
        else:
            index_b[w_id] = i

    cnt = [0] * n
    one = 0
    two = 0

    def add(idx):
        nonlocal one, two
        w_id = events[idx % m][1]
        if cnt[w_id] == 0:
            cnt[w_id] = 1
            one += 1
        elif cnt[w_id] == 1:
            cnt[w_id] = 2
            one -= 1
            two += 1

    def remove(idx):
        nonlocal one, two
        w_id = events[idx % m][1]
        if cnt[w_id] == 1:
            cnt[w_id] = 0
            one -= 1
        else:
            cnt[w_id] = 1
            two -= 1
            one += 1

    def from_pos(p):
        p %= per
        if p < w:
            return 0.0, float(p)
        p -= w
        if p < h:
            return float(w), float(p)
        p -= h
        if p < w:
            return float(w - p), float(h)
        p -= w
        return 0.0, float(h - p)

    r = 0
    while r < m:
        add(r)
        r += 1

    for l in range(m):
        while r < l + m and two == 0 and one < n:
            add(r)
            r += 1

        if one == n and two == 0:
            a = coords[l]
            b = coords[r - 1] if r - 1 < m else coords[(r - 1) % m] + per
            if b - a < per:
                mid1 = a + 0.5
                mid2 = b - 0.5
                if mid2 > per:
                    mid2 -= per
                x1, y1 = from_pos(mid1)
                x2, y2 = from_pos(mid2)
                print(1)
                print(x1, y1, x2, y2)
                return

        remove(l)

    eps = 0.001
    print(2)
    print(eps, eps, w - eps, h - eps)
    print(w - eps, eps, eps, h - eps)

if __name__ == "__main__":
    solve()
