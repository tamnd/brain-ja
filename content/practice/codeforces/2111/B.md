 ## 解決策
 ## 問題の理解

 立方体のコレクションがあります。$i$- 番目の立方体は、$i$-th フィボナッチ数の定義を変更した場合:$f_1 = 1$、$f_2 = 2$、 そして$f_i = f_{i-1} + f_{i-2}$のために$i > 2$。 一連の箱の各箱について、積み重ねのルールを尊重して、これらすべての立方体が中に収まるかどうかを尋ねられます。 各立方体は箱と整列する必要があり、空中に浮くことはできず、より小さな立方体の上に置くこともできません。 

入力は複数のテスト ケースで構成され、それぞれがキューブの数を提供します$n$、箱の数$m$、および各ボックスの寸法。 各テスト ケースの出力は、次の長さの文字列です。$m$、立方体が対応するボックスに収まる場合は「1」、そうでない場合は「0」になります。 

制約が私たちに与えるのは、$n \le 10$と合計$m$すべてのテストケースにわたって$\le 2 \cdot 10^5$。 これにより、立方体のサイズを事前計算し、各ボックスに対して簡単なシミュレーションを使用できるようになるため、これは非常に重要です。 キューブのサイズはフィボナッチ順序で急速に増加するため、この問題には複雑なパッキング アルゴリズムは必要ありません。 むしろ、注意深く順序付けられた貪欲なアプローチで十分です。 

立方体の合計設置面積がどの向きであってもボックスよりも大きい場合、またはボックスの寸法が 1 つだけ非常に小さく、積み重ねるのを妨げる場合、微妙なエッジ ケースが発生します。 たとえば、次の場合$n = 5$、立方体には側面があります$1, 2, 3, 5, 8$、ボックスの寸法は次のとおりです。$(6, 6, 5)$、最大の立方体 ($8$) どの方向にも適合しません。 総体積のみをチェックする単純なアプローチでは、実際の寸法の制約を無視して、誤って「適合」と判断されてしまいます。 

## アプローチ

 ブルートフォースアプローチでは、各ボックス内の立方体の配置と向きの可能なすべての順列をシミュレートしようとします。 与えられた$n \le 10$、 がある$n!$順列があり、各立方体は最大 6 通りの方向を向くことができます。 と$m$潜在的に$2 \cdot 10^5$、これは禁止事項になります。 

重要な洞察は、すべての立方体は立方体 (辺が等しい) であり、$n$小さいです。 したがって、キューブを降順に並べ替えて、ボックスの最大寸法に沿った貪欲な配置をシミュレートできます。 各ボックスについて、その側面を降順で並べ替えてから、残りの最大の立方体を残りの最大の寸法に繰り返し配置します。 キューブは 1 つの次元に沿って垂直に積み重ねられ、残りの 2 つの次元はすべてのキューブを任意の方向に収容できる必要があります。 これにより、各ボックスのチェックが単純な比較シーケンスに減ります。 

貪欲なアプローチは、キューブのサイズが大きくなり、最大から最小まで積み重ねる必要があるため機能します。 立方体とボックスの側面の両方を並べ替えると、立方体が並べ替えられた順序で次元に沿って収まらない場合は、どの順列にも収まらないことが保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * 6^n * m) | O(n) | 遅すぎる |
 | 最適な貪欲さ | O(n log n + m log 3) ≈ O(m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 変更された定義に従って最初の 10 個のフィボナッチ数を事前計算します。$f_1 = 1$、$f_2 = 2$、$f_i = f_{i-1} + f_{i-2}$のために$i > 2$。 これらの数字だけが必要になります。$n \le 10$。 
2. テスト ケースごとに、フィボナッチ キューブを降順に並べ替えます。 これにより、最大の立方体を最初に配置することができます。 
3. 各ボックスの 3 つの寸法を降順に並べ替えます。 これにより、どの次元がスタックの高さを保持するか、どの 2 つの次元がベースを形成するかが識別されます。 
4. ボックスから使用可能な 3 つのディメンションを初期化します。 最大の立方体から始めて、残りの最大の寸法に沿って配置してみてください。 キューブ側の積み重ね軸に沿って利用可能な寸法を減らします。 
5. キューブを降順に配置し続けます。 いずれかのステップで立方体が使用可能な寸法のいずれかを超えた場合は、そのボックスを不可能としてマークし、次のボックスに移動します。 
6. すべての立方体がボックスの寸法内に正常に配置されている場合は、可能であるとマークします。 
7. テスト ケース内のすべてのボックスに対して手順 3 ～ 6 を繰り返します。 

機能する理由: キューブを降順に並べ替えると、最大のキューブが最初に最大のスペースを占めることが保証され、小さなキューブが大きなキューブをブロックするのを防ぎます。 ボックスの寸法を並べ替えることで、積み重ねる方向が最適に選択されるようになります。 不変条件は、ボックスがすべての立方体を保持できる場合に限り、各立方体を配置した後、すべての軸に沿った残りのスペースが残りの立方体にとって十分であるということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# precompute Fibonacci numbers up to 10
fib = [1, 2]
for i in range(2, 10):
    fib.append(fib[-1] + fib[-2])

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    cubes = fib[:n]
    cubes.sort(reverse=True)
    res = []
    for _ in range(m):
        box = list(map(int, input().split()))
        box.sort(reverse=True)
        temp_box = box[:]
        possible = True
        # we can place cubes along the largest box dimension
        for cube in cubes:
            # find the largest box dimension to place this cube
            placed = False
            for i in range(3):
                if temp_box[i] >= cube:
                    temp_box[i] -= cube
                    placed = True
                    break
            if not placed:
                possible = False
                break
        res.append('1' if possible else '0')
    print(''.join(res))
```フィボナッチ数の事前計算により、テスト ケースごとにフィボナッチ数を再計算することがなくなります。 キューブを降順に並べ替えると、最大のものから順に配置されることが保証されます。 ボックスの寸法を並べ替えることで、最大の軸に沿って積み重ねることができ、スペースの使用量が最大化されます。 立方体を配置するときに寸法を小さくすると、スペースの過剰カウントが回避されます。 これにより、技術的には体積に適合するが、寸法に対応できない立方体を配置するなどのエラーが回避されます。
