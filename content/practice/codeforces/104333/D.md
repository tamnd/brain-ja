 ## 解決策
 ## 問題の理解

 私たちは整数配列を扱っており、任意のサブシーケンスを選択することができます。つまり、インデックスのサブセットを自由に選択し、その値を順序どおりに保つことができますが、重要なのは合計だけであるため、順序自体は計算に影響しません。 

選択したサブシーケンスについて、その合計を計算します。$x$。 これとは別に、完全な配列から導出される 2 つの固定量を考慮します: 可能な最小の部分列の合計$p$、および可能な最大の部分列の合計$q$。 タスクは、合計が次の部分列を選択することです。$x$価値を生む$|2x - (p+q)|$できるだけ小さいもの。 

重要な点は、$p$そして$q$選択されたサブシーケンスではなく、元の配列のみに依存します。 それらが修正されると、問題はすべての部分列の合計の検索になります。 

制約$n \le 500$そして$a_i \in [-500, 500]$指数関数的なサブセットが大きすぎて直接列挙できないことがすぐに示唆されます。 完全なサブセット空間にはサイズがあります$2^{500}$、これは実行可能な計算をはるかに超えています。 ただし、値は十分に小さいので、合計の範囲は最大でも$[-250000, 250000]$。 

すべての数値が正の場合、またはすべての数値が負の場合、微妙なエッジ ケースが発生します。 このような場合、達成可能なサブシーケンスの合計セットは単調な極値に向かって崩壊し、最適な答えは空のサブシーケンスまたは完全なサブシーケンスから得られることがよくあります。 少なくとも 1 つの要素を選択する必要がある、または部分列の合計が連続的に動作することを前提とした単純なアプローチは、そこで失敗します。 

## アプローチ

 総当り攻撃を試みる場合は、すべてのサブシーケンスを列挙し、その合計を計算して、式を評価することになります。$|2x - (p+q)|$。 これは正しいですが、反復処理が必要です$2^n$サブセット。 と$n=500$、これは不可能です。 

式の構造は、次のような対称性を示唆しています。$(p+q)/2$。 合計が次の部分列を選択しようとしています。$x$はこの中間点に可能な限り近いです。 したがって、任意の部分列について考える代わりに、どの合計が達成可能であるかのみを考慮します。 

これにより、問題は古典的なサブセット合計到達可能性問題に変換されます。 動的計画法を使用して、考えられるすべての部分列の合計を計算します。 達成可能な合計のセットがわかったら、それらをスキャンして、ターゲットの中点までの距離を最小にするものを選択します。 

追加の作業はコンピューティングだけです$p$そして$q$。 サブシーケンスの場合、$p$は、すべての負の数を取得することによって得られます。負の値を含めると常に合計が減少し、非負の要素をスキップしても最小化が損なわれることはありません。 同様に、$q$すべての正の数を取ることによって得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^n \cdot n)$|$O(1)$| 遅すぎる |
 | 合計に対する DP |$O(n \cdot S)$、$S \le 5 \cdot 10^5$|$O(S)$| 承認済み |

 ## アルゴリズムのチュートリアル

 ### 1. 固定基準値を計算する$p$そして$q$配列を 1 回スキャンします。 すべての負の値を加算します$p$なぜなら、すべての負の要素は部分列の合計を厳密に減少させるからです。 すべての正の値を次のように加算します。$q$なぜなら、すべての正の要素は部分列の合計を厳密に増加させるからです。 ゼロはどちらの極端な値にも影響しません。 

これが機能するのは、サブシーケンスの選択が要素ごとに独立しているためです。つまり、各要素が寄与するか否かのいずれかであり、制約はありません。 

### 2. 目標値を定義する

 私たちは計算します$target = p + q$、そして私たちが望むのは$x$に近い$target / 2$。 分数を扱う代わりに、絶対差を使用して比較します。$|2x - target|$、すべてが統合された状態に保たれます。 

### 3. 到達可能なすべてのサブシーケンスの合計を計算します。 

可能な合計に対してブール値 DP を使用します。 値の範囲は -500 ～ 500 であるため、$n \le 500$、合計の範囲は次のように制限されます。$[-250000, 250000]$。 

負の合計が有効な配列インデックスにマップされるように、オフセットによってインデックスをシフトします。 要素ごとに$a_i$、以前に到達可能な合計が得られるように DP を更新します。$s$にも到達できるようになりました$s + a_i$。 

同じ要素を何度も再利用しないように、合計を逆の順序で慎重に繰り返す必要があります。 

### 4. 最良の回答を追跡する

 DP を埋める間または埋めた後、到達可能なすべての合計を反復処理します。$x$。 それぞれについて、計算します$|2x - target|$そして最低限のことは守ってください。 

### なぜ効果があるのか

 DP は、考えられるすべての部分列の合計のセットを正確に表します。 各遷移は要素ごとの 2 進決定に対応し、逆の反復により、各要素がサブセット状態ごとに最大 1 回使用されることが保証されます。 すべての有効なサブシーケンスは 1 つの DP 到達可能な合計に対応し、その逆も同様であるため、DP 状態を最小化することは、すべてのサブシーケンスを最小化することと同等です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    p = 0
    q = 0
    for v in a:
        if v < 0:
            p += v
        elif v > 0:
            q += v

    target = p + q

    offset = 250000
    size = 500001
    dp = [False] * size
    dp[offset] = True

    for v in a:
        if v == 0:
            continue
        if v > 0:
            rng = range(size - v - 1, -1, -1)
        else:
            rng = range(-v, size)

        for i in rng:
            if dp[i]:
                dp[i + v] = True

    ans = 10**18
    for i, ok in enumerate(dp):
        if ok:
            x = i - offset
            val = abs(2 * x - target)
            if val < ans:
                ans = val

    print(ans)

if __name__ == "__main__":
    solve()
```実装では、まず次の計算を分離します。$p$そして$q$これにより、サブセット列挙への依存が回避されます。 DP 配列はオフセットを使用して中心に配置されるため、負の合計を個別に処理する必要はありません。 遷移ループは、次の符号によって分割されます。$v$逆に反復するときに正確さを維持するため。 

最終スキャンは DP 配列にわたって線形であり、達成可能なすべての合計について目的関数を直接評価します。

 ## 特殊なケース

 のようなケース`[-1, -2, -3]`作る$p = -6$そして$q = 0$。 達成可能な合計はすべて非正であるため、最良の中点一致はその範囲に制限されます。 DP は引き続き、合計 0、-1、-2、-3、-3、-4、-5、-6 を正しく列挙し、距離を均一に評価します。 

などのすべての肯定的なケース`[5, 5, 5]`収量$p = 0$、$q = 15$。 中間点は 7.5 ですが、到達可能な合計はすべて 0 ～ 15 の整数です。DP では、離散合計を介して暗黙的に 7 と 8 の両方を考慮し、より近い方を選択します。 

次のような混合交互ケース`[1, -1, 1, -1]`多くの繰り返し合計が作成されますが、DP は状態を二重にカウントしません。 到達可能な各合計は 1 回記録され、最終スキャンでは 0 が最適であることが正しく検出されます。$target = 0$。
