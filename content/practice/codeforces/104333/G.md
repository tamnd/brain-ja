 ## 解決策
 ## 問題の理解

 2D 平面上にいくつかの独立した点のセットが与えられます。 各セットについて、すべての点を軸に沿った正方形の内側に囲む必要があります。これは、正方形の辺が座標軸に平行であることを意味します。 すべての点を完全に含むすべての正方形の中で、可能な限り最小の面積を持つ正方形が必要です。 

固定テスト ケースの場合、幾何学的意味は単純です。正方形をどこにでも配置できますが、その辺の長さは、x 方向と y 方向の両方の点の広がり全体をカバーするのに十分な大きさでなければなりません。 辺の長さがわかれば、面積はまさにその正方形になります。 

この制約により、テストごとの定数または対数解が求められます。 すべてのテスト ケースにわたるポイントの総数は最大 200,000 であるため、各ポイントを一定の回数処理するソリューションであればどれでも許容されます。 テスト ケースごとに 2 次関数を実行すると、入力が適度に分割されても制限時間を超えるため、すぐに失敗します。 

座標範囲から微妙な問題が発生します。 座標は ±10^9 に達する可能性があるため、候補となる正方形の位置を列挙したり、平面上のブルートフォース ジオメトリに依存したアプローチは実行不可能です。 

主なエッジ ケースは、縮退した点セットから生じます。 すべての点が同一の場合、それを囲む正方形の辺の長さは 0 になり、面積は 0 になります。点が 1 つだけの場合も、同じロジックが適用されます。 もう 1 つのケースは、点が水平または垂直に一列に並んでおり、1 つの次元のみが答えを決定する場合です。 単純な間違いは、面積を次のように計算することです。`(max_x - min_x) * (max_y - min_y)`1 つの次元が大きい場合に必要な正方形の辺が過小評価される正方形制約を強制する必要はありません。 

たとえば、ポイント`(0,0)`そして`(10,1)`幅 10、高さ 1 とします。長方形の面積は 10 ですが、正方形の場合は辺が 10 でなければならないため、面積は 100 になります。 

## アプローチ

 強引なアイデアは、あらゆる可能な正方形の配置を検討することです。 左下隅と辺の長さを選択し、すべての点が内側に収まるかどうかを確認することを想像することもできます。 各候補についてすべてのポイントをスキャンし、O(n) 検証を行います。 点座標を使用して候補位置を離散化した場合、任意の点が境界を定義する可能性があるため、中心または角については依然として O(n^2) 以上の可能性があります。 これは、数千を超えるとすぐに不可能になります。 

重要な観察は、すべての点を囲む軸に整列した正方形が極値座標によって完全に決定されるということです。 すべての点を含む最小の長方形には幅があります`max_x - min_x`と高さ`max_y - min_y`。 いずれかの寸法を縮小すると、少なくとも 1 つの極点が除外されるため、正方形の辺の長さは少なくともこれら 2 つの値の大きい方でなければなりません。 

辺の長さがこれらの極値によって固定されることを受け入れると、最適な正方形は単に辺が次のような最小の正方形になります。`max(max_x - min_x, max_y - min_y)`。 正方形をどこにでも配置できるようにすること以外に、位置の選択を考慮する必要はありません。 正方形を移動しても、必要な辺の長さは変わりません。 

したがって、各テスト ケースは、x と y の最小値と最大値を計算する線形スキャンに帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) 以上 | お(1) | 遅すぎる |
 | 最適 | テストあたり O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、すべてのポイントを読み取り、最小 x、最大 x、最小 y、最大 y の 4 つの値を追跡します。 これら 4 つの値は、中間構造を保存せずに、セットの幾何学的広がり全体をキャプチャします。 
2. 水平スパンを次のように計算します。`dx = max_x - min_x`。 これは、すべての点を含む軸に揃えられた長方形の最小幅を表します。 
3. 垂直スパンを次のように計算します。`dy = max_y - min_y`。 これは、そのような長方形の可能な最小の高さを表します。 
4. 必要な正方形の辺の長さを次のように決定します。`side = max(dx, dy)`。 このステップでは、両方の寸法が 1 つの等しい長さの辺内に収まるようにすることで、正方形の制約を強制します。 
5. 面積を次のように計算します。`side * side`テストケース用に出力します。 

ステップ 4 が正しい主な理由は、どの正方形も水平方向と垂直方向のスプレッドの両方を同時にカバーする必要があるためです。 辺が dx または dy より小さい場合、少なくとも 1 組の極値点がその次元の正方形の外側に存在します。 

### なぜ効果があるのか

 点のセットは、軸に沿った最小外接長方形を定義します。 すべての点を含む軸に整列した正方形は、この長方形を完全に含む必要があります。 したがって、その辺の長さを長方形の大きい辺より小さくすることはできません。 逆に、辺の正方形`max(dx, dy)`固定された原点に制約されないため、常に境界四角形をカバーするように配置できます。 これにより、計算される側が必要かつ十分となり、最適性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        min_x = 10**18
        max_x = -10**18
        min_y = 10**18
        max_y = -10**18

        for _ in range(n):
            x, y = map(int, input().split())
            if x < min_x:
                min_x = x
            if x > max_x:
                max_x = x
            if y < min_y:
                min_y = y
            if y > max_y:
                max_y = y

        dx = max_x - min_x
        dy = max_y - min_y
        side = max(dx, dy)
        out.append(str(side * side))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装では、入力の読み取り中に x と y の実行中の極値を直接維持し、点リストの保存を回避します。 すべてのテスト ケースの合計ポイント数が 200,000 に達する可能性があるため、これは重要です。 

唯一の微妙な点は、最小値と最大値の初期化です。 大きなセンチネル値を使用すると、負の座標の正確性も保証されます。 最後の平方辺の計算では整数演算のみが使用されますが、差分が 64 ビットの範囲内にあるため安全です。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import isclose

    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        min_x = 10**18
        max_x = -10**18
        min_y = 10**18
        max_y = -10**18

        for _ in range(n):
            x, y = map(int, input().split())
            min_x = min(min_x, x)
            max_x = max(max_x, x)
            min_y = min(min_y, y)
            max_y = max(max_y, y)

        side = max(max_x - min_x, max_y - min_y)
        out.append(str(side * side))

    return "\n".join(out)

 ## 特殊なケース

 みたいなワンポイントの場合`(5, 5)`、アルゴリズムはすべての極値を等しく設定し、`dx = dy = 0`したがって面積`0`。 これは、辺 0 の正方形にまだ点が含まれているという事実と一致します。 

水平方向に並んだ点の場合`(0,0), (5,0), (10,0)`、垂直スパンは 0 ですが、水平スパンは 10 です。アルゴリズムは次のように計算します。`side = 10`、面積 100 が生成されます。長方形の面積を使用しようとすると、誤って処理された場合、高さの寄与として 0 が出力され、面積については 0 が誤って出力されます。 

次のような垂直に整列した点の場合`(2,1), (2,5), (2,9)`、水平スパンは 0、垂直スパンは 8 です。アルゴリズムはサイド 8 とエリア 64 を返し、水平方向の広がりが存在しない場合でも水平方向に正しく拡張します。 

次のような負の混合座標の場合`(-3,-3)`そして`(1,2)`、極値処理により、符号に関係なく正しい差が保証されます。 計算されたスパンは次のとおりです。`dx = 4`、`dy = 5`これにより、初期化と最小/最大の更新が完全な整数範囲を正しく処理できることが確認されます。
