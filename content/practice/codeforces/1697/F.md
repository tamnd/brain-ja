 ## 解決策
 ## 問題の理解

 長さの整数のシーケンスを構築するように求められます。`n`、各要素は間にあります`1`そして`k`、シーケンスは非減少でなければなりません。 それに加えて、この問題では 3 種類の追加の制約が提供されます。 最初のタイプは、特定の位置での特定の値を禁止します。 2 番目と 3 番目のタイプは、要素のペアに合計の不等式を配置します。 私たちのタスクは、すべての制約を満たすシーケンスを構築するか、シーケンスが存在しないことを報告することです。 

重要な観察は次のとおりです`k`非常に小さい (最大 10)、`n`大きくすることもできます (最大 2×10^4)。 これは、個々の要素の可能性を列挙することは可能ですが、すべてのシーケンスを総当たり攻撃すると指数関数的に爆発的に増加することを示唆しています。 タイプ 2 とタイプ 3 の制約には要素のペアが含まれるため、すべてのシーケンスを試す単純な試みはすぐに手に負えなくなります。 もう 1 つのポイントは、配列が非減少である必要があることです。 これは、要素が少なくとも何らかの値に制約されると、それ以降のすべての要素がその下限を継承することを意味します。 同様に、初期インデックスの上限は前方に伝播します。 

明らかではないエッジケースは、制約が伝播を通じて間接的に競合する場合に発生します。 たとえば、次の場合`a1 + a2 ≥ 5`そして`a2 + a3 ≤ 4`の場合、両方を満たすことは不可能かもしれません。`k`小さいです。 もう 1 つの注意が必要なケースは、タイプ 1 制約と単調性の組み合わせです。あるインデックスで値を禁止すると、後の値が強制的に超過する可能性があります。`k`順序を減らすことができないためです。 

不注意なアプローチでは、各制約を順番に独立して満たそうとする可能性があります。 たとえば、設定`a[i] = 1`タイプ 2 または 3 の制約に合計が含まれる場合、禁止されていない限りは失敗します。これは、これらの制約が隣接する要素だけでなく、離れた要素を接続するためです。 具体例としては、`n = 3, k = 3`制約付き`1 2 1`そして`3 1 3 5`。 最小限の許容値を設定するだけで、`[1, 2, 3]`、正しく解釈されない場合、合計制約に違反します。 

## アプローチ

 ブルートフォースソリューションでは、長さのシーケンスをすべて列挙します。`n`間に要素がある`1`そして`k`。 シーケンスごとに、すべての制約がチェックされます。 時間計算量は`O(k^n * m)`、これは最小の非自明なものであっても実行不可能です。`n`。 正確さは徹底的なチェックによって得られます。シーケンスがすべての制約を満たしていれば、それが見つかります。 それより大きい場合は失敗します`n`なぜなら`k^n`指数関数的に成長します。 

最適なソリューションを実現するための重要な洞察は次のとおりです。`k`は非常に小さいため、各位置の許容値をセットまたはビットマスクとして表すことができます。 すべてのタイプ 1 制約は、その位置から値を直接削除します。 タイプ 2 およびタイプ 3 の制約は、単調性と組み合わせると、個々の要素の境界として表現できます。 タイプ 2 の場合、`a[i] + a[j] ≤ x`そして`i < j`暗示する`a[i] ≤ x - 1`せいぜい`a[j]`同様に、タイプ 3 は下限を意味します。 配列は非減少であるため、下限は`i`は前方に伝播し、上限は後方に伝播します。 これにより、安定するまで範囲を繰り返し更新するという制約伝播アプローチが可能になります。 いずれかの範囲が空になった場合、シーケンスは実行できません。 

アプローチを要約すると次のようになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k^n * m) | O(n) | 遅すぎる |
 | 制約の伝播 | O(n * k + m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つの配列を初期化する`low`そして`high`長さの`n`、各位置に許可される最小値と最大値を表します。 セット`low[i] = 1`そして`high[i] = k`。 
2. タイプ 1 制約を直ちに適用します。 制約を禁止する場合`a[i] = x`、すべての禁止値を保存するわけではありませんが、最終代入時にスキップして処理します。`x`等しい`low[i]`範囲内で増加します。 
3. タイプ 2 の制約を適用します。 制約の場合`a[i] + a[j] ≤ x`そして`i < j`、上限を更新します。`high[i] = min(high[i], x - 1)`そして`high[j] = min(high[j], x - 1)`必要に応じて。 これにより、最小値であっても合計に違反しないことが保証されます。 
4. タイプ 3 の制約を適用します。 制約の場合`a[i] + a[j] ≥ x`、下限を更新します。`low[i] = max(low[i], x - k)`そして`low[j] = max(low[j], x - k)`、可能な最大値を考慮して`k`。 
5. それぞれの下限を前方に伝播することで単調性を強制します。`i`1 から n-1 まで、設定`low[i+1] = max(low[i+1], low[i])`。 上限を逆方向に伝播する: for`i`n-2 から 0 まで、設定`high[i] = min(high[i], high[i+1])`。 
6. 任意の位置にある場合`low[i] > high[i]`、解決策は存在しません。 -1を出力します。 
7. 最終的な配列を構築します。 ポジションごとに選択します`a[i] = low[i]`。 この値がその位置でタイプ 1 制約によって禁止されている場合は、次の値を選択します。`[low[i], high[i]]`それは許されています。 そのような値が存在しない場合は、-1 を出力します。 

## なぜ機能するのか

 維持される不変条件は、すべてのインデックスに対して`i`、間隔`[low[i], high[i]]`に現れる可能性のあるすべての値が含まれます。`i`タイプ 2、タイプ 3、または単調性制約に直ちに違反することはありません。 制約の伝播により、境界がすべての間接的な依存関係を確実に反映します。 からの最終課題は、`low[i]`上向きは、許可された間隔を尊重しながら非降順順序を保証し、タイプ 1 例外はローカルで処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        low = [1] * n
        high = [k] * n
        forb = [[] for _ in range(n)]
        constraints = []
        for _ in range(m):
            data = list(map(int, input().split()))
            if data[0] == 1:
                _, i, x = data
                forb[i - 1].append(x)
            else:
                constraints.append(data)
        for c in constraints:
            if c[0] == 2:
                _, i, j, x = c
                i -= 1
                j -= 1
                high[i] = min(high[i], x - 1)
                high[j] = min(high[j], x - 1)
            else:
                _, i, j, x = c
                i -= 1
                j -= 1
                low[i] = max(low[i], x - k)
                low[j] = max(low[j], x - k)
        for i in range(1, n):
            low[i] = max(low[i], low[i - 1])
        for i in range(n - 2, -1, -1):
            high[i] = min(high[i], high[i + 1])
        possible = True
        res = []
        for i in range(n):
            val = low[i]
            while val in forb[i] and val <= high[i]:
                val += 1
            if val > high[i]:
                possible = False
                break
            res.append(val)
        if possible:
            print(*res)
        else:
            print(-1)

if __name__ == "__main__":
    solve()
```コードは、テスト ケースの数を読み取り、各位置の下限と上限を初期化することから始まります。 タイプ 1 制約は、禁止値を処理するために個別に収集されます。 タイプ 2 および 3 の制約は、境界を直接更新します。 単調性は、前方パスと後方パスで強制されます。 最終的な配列は、禁止された値をスキップして、各位置で利用可能な最小値を選択することによって構築されます。 位置に有効な値がない場合、`-1`と印刷されています。
