 ## 解決策
 ## 問題の理解

 ペトルは次のような本を持っています`n`ページ。 彼は月曜日から、曜日ごとに一定のページ数を読みます。 入力により、これら 7 つの 1 日あたりの読み取り容量が月曜日から日曜日までの順序で与えられます。 

ペトルがその本を読み終える日を決める必要があります。 答えは合計日数ではなく、平日の日数です。`1`に`7`、 どこ`1`月曜日を意味し、`7`日曜日を意味します。 

制約は非常に小さいです。 ページ数は最大でも`1000`、それぞれの日次値も最大です`1000`。 毎日の直接シミュレーションでも完全に十分に高速です。 最悪の場合、Petr は 1 週間に 1 ページしか読まないため、シミュレーションは約 3 分間実行される可能性があります。`1000`日々。 2 秒の制限ではまだ些細なことです。 

難しいのはパフォーマンスではなく、停止状態を正しく処理することです。 

よくある間違いの 1 つは、丸 1 週間を終えて初めて残りのページがゼロになるかどうかを確認することです。 次の入力を考えてみましょう。```
1
1 0 0 0 0 0 0
```正しい答えは、`1`ペトルは月曜日にすぐに終わるからです。 週ごとにループする不用意な実装は、誤って次の週まで継続される可能性があります。 

もう 1 つの微妙なケースは、読み取り能力がゼロの日がある場合に発生します。```
2
1 0 0 0 0 0 0
```正解はまだ`1`。 ペトルは第 1 月曜日に 1 ページを読み、次に第 2 月曜日に 2 ページを読みます。 Petr はページをスキップしないため、ページがゼロの日も処理する必要があります。 

最後のオフバイ トラップは、ペトルがちょうど 1 日の終わりに終了したときに表示されます。```
10
5 5 1 1 1 1 1
```答えは、`2`、 ない`3`。 火曜日を過ぎると残りページがゼロになるので火曜日が終了日となります。 

## アプローチ

 最も直接的なアプローチは、ペトルの読書プロセスを 1 日ずつシミュレートすることです。 7 週間の平日を繰り返して、ペトルがその日に読めるページ数を残りのページから差し引きます。 残りの数値が 0 または負になるとすぐに、現在の平日を返します。 

これが機能するのは、問題で説明されているプロセス自体が逐次的なためです。 Petr は時系列で読み取り、日をスキップすることはありません。そのため、何が起こったかを正確にシミュレーションすると、自然に正しい結果が得られます。 

本にはせいぜい`1000`ページごとに、可能な限り遅い読み取りスケジュールでも、管理可能な回数の反復後に終了します。 たとえば、Petr が毎週月曜日に 1 ページのみを読み取り、他の日は 0 ページのみを読み取る場合、シミュレーションは約`7000`毎日のチェック。 それは小さいです。 

もう少しきれいな観察もあります。 完全な週を明示的に数える必要はありません。 累積読み取りページ数がそれ以上になった最初の日のみを考慮します。`n`。 つまり、平日に 1 回の反復トラバースで十分です。 

制約が小さいため、総当たりアプローチと最適アプローチは非常に似たものになります。 最適なバージョンとは、単に最もクリーンなシミュレーションです。

 ## アルゴリズムのチュートリアル

 1. 総ページ数を読み取る`n`。 
2. Petr が月曜日から日曜日までに何ページ読んだかを表す 7 つの整数の配列を読み取ります。 
3. スケジュールは毎週繰り返されるため、平日に無限ループを開始します。 
4. インデックスから各曜日ごとに`0`に`6`からその日の読書能力を引きます。`n`。 
5. 減算後、`n <= 0`。 
6. 条件が true の場合、次を使用して現在の曜日番号を返します。`index + 1`この問題では 1 から始まる番号付けが使用されているためです。 

これが機能する理由は、その瞬間です。`n`正でない値になるのは、まさにペトルが最後のページを読み終えた瞬間です。 毎日、まだ読まれていないページがいくつかありました。 

### なぜ効果があるのか

 このアルゴリズムは単純な不変条件を維持します。つまり、1 日を処理する前に、`n`残りの未読ページ数と同じです。 その日の読書量を差し引くと、`n`その日が終了すると、残りの未読ページになります。 

初日は、`n <= 0`まさに、累計の読んだページ数が少なくとも元の本のサイズに達する日です。 日付は時系列順に処理されるため、これより早い日で本を読み終えることはできません。 これにより、返される曜日が正しいことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    days = list(map(int, input().split()))

    while True:
        for i in range(7):
            n -= days[i]

            if n <= 0:
                print(i + 1)
                return

solve()
```プログラムは、アルゴリズムで記述されたシミュレーションに直接従います。 

の`while True`ループは繰り返しの週を表します。 その中には、`for`ループは月曜日から日曜日まで順番に繰り返されます。 

今日の読書量を差し引いて、すぐに本が読み終わったかどうかを確認します。 順序が重要です。 引き算の前に確認してしまうと、誤って答えが 1 日遅れてしまいます。 

条件は以下を使用します`n <= 0`の代わりに`n == 0`。 ペトルは最終日に本に残っているページよりも多くのページを読む可能性があります。 たとえば、次の場合`3`ページは残っており、今日の容量は`10`、残りの値は次のようになります。`-7`、しかし、仕上げの日はまだ今日です。 

出力は次を使用します`i + 1`Python 配列のインデックスは 0 ですが、問題内の曜日には 0 から番号が付けられているためです。`1`に`7`。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())
    days = list(map(int, input().split()))

    while True:
        for i in range(7):
            n -= days[i]

            if n <= 0:
                print(i + 1)
                return

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    return sys.stdout.getvalue()
