 ## 解決策
 ## 問題の理解

 キャンディパックのコレクションが与えられました。 各パックにはキャンディー 2 個または 3 個が入っています。 このタスクは、各人がまったく同じ合計数のキャンディーを受け取るように、すべてのキャンディーを 3 人に分配することが可能かどうかを判断することです。 

入力は、値 2 と 3 のみで構成されるマルチセットを効果的に記述しています。出力は、各グループの合計が同一になるように、これらすべてのパックを 3 つのグループに分割する方法が存在するかどうかという、シンプルな実現可能性の答えです。 

最初の構造的制約は総和から生じます。 キャンディーの総数が`S`となると、必要な条件は次のとおりです。`S`それ以外の場合は、配置に関係なく、等しい分割は存在しません。 

2 番目の制約は、算術ではなく組み合わせです。 たとえ`S / 3`が整数である場合、2 と 3 のマルチセットが 3 つのサブセットに分割され、それぞれの合計が次になることを確認する必要があります。`S / 3`。 これは、項目の重みのアルファベットが非常に小さい、制約付きのサブセット合計分割問題です。 

グループ間の相互作用を考慮せずに、2 秒と 3 秒のカウントに基づく貪欲な推論が使用される場合、微妙なエッジ ケースが発生します。 たとえば、パックについて考えてみましょう。`[3, 3, 2, 2, 2]`。 合計額は`12`、したがって各人が取得する必要があります`4`。 素朴な試みはグループ化を試みるかもしれません`(3+1)`これは不可能であるか、2 と 3 を独立して扱って、有効なパーティションには両方のタイプを混合する必要があることに気づきません。 

もう 1 つのエッジ ケースは、合計が 3 で割り切れるが、割り切れない制約によりパーティションが存在しない場合です。 例えば、`[3, 3, 3, 2]`合計があります`11`、すでに割り切れませんが、次のようなバリアントさえも`[3, 3, 2, 2]`慎重な割り当て推論が必要です。 

重要な難しさは、算術目標ではなく、個別の構成要素 2 と 3 を同時に 3 つの等しい合計に配置できるかどうかです。 

## アプローチ

 最も直接的なアプローチは、これをパーティション分割の問題として扱うことです。 一人ひとりが正確に受け取らなければならないので、`S / 3`キャンディーの場合、各パックを 3 つのビンの 1 つに割り当て、割り当てが機能するかどうかを確認するという観点から考えることができます。 

強引なアイデアは、各パックを 3 人のうちの 1 人に割り当てるすべての方法を列挙することです。 と`n`パック、これは次のことにつながります`3^n`可能性が大きすぎます。 

もう少し構造化されたブルート フォースでは、1 人あたりの合計額が固定されていることが観察されるため、サブセットの組み合わせのみを考慮する必要があります。 合計すると次のようなパックのサブセットをすべて列挙できます。`S / 3`。 あると仮定します`L`そのようなサブセット。 次に、サブセットのすべてのトリプルを試して、それらがパーティションを形成しているかどうかを確認します。 これは次のことにつながります`O(L^3)`小切手。 最悪の場合、`L`たとえ小さな重みにわたるサブセットの合計でも多くの組み合わせが生成されるため、それ自体が指数関数的になる可能性があります。 

重要な観察は、実際には、任意のサブセットのレベルで個々の割り当てについて推論する必要がないということです。 すべてのウェイトが 2 または 3 のみであるため、構造は非常に制約されます。 有効な解決策は、3 個のパックと 2 個のパックをグループ化し、時々混合することと同等ですが、混合は正規化できます。 

それをより明確に確認する方法は、個人のシェアを修正することです`T = S / 3`。 3 パックと 2 パックを各人に何個入れるかを決めるだけです。 させて`x`は割り当てられた 2 パックの数であり、`y`割り当てられた 3 パックの数になります。 それなら各人が満足しなければなりません`2x + 3y = T`。 

そこで問題は、すべての 2 パックと 3 パックを同じ一次方程式に従う 3 つのグループに分割できるかということです。 これにより、グローバル分割の問題は、2 と 3 のカウントが 3 つの同一の線形表現にわたって一貫して分解できるかどうかをチェックすることになります。 

割り当てを検索する代わりに、有効なものをすべて列挙します。`(x, y)`1 人分のソリューションを作成し、そのようなソリューションが 3 つですべてのアイテムをまとめて消費できるかどうかを確認します。 これにより、状態空間が大幅に減少します。`2x + 3y = T`だけを持っています`O(T)`解決策はありますが、実際にはそれ以降はほとんどありません`x`には制限があり、パリティによって実現可能性が制限されます。 

次に、これらの候補解のすべてのトリプルをチェックして、利用可能な数の 2 と 3 を正確にカバーしているかどうかを確認します。 

これにより、組み合わせ分割問題が、実行可能な線形分解に対する制限された列挙に変わります。

 ## アルゴリズムのチュートリアル

 1. 合計値を計算する`S`すべてのキャンディーの中で。 もし`S % 3 != 0`、均等分割は不可能なのですぐに停止してください。 
2. 一人当たりの目標を設定する`T = S / 3`。 これは、3 つのグループのそれぞれが達成しなければならない固定合計です。 
3. しましょう`c2`2パックの数となり、`c3`3パックの数となります。 ここでは、ある人の選択を「選択」と表現します。`x`2と`y`そのような3つ`2x + 3y = T`。 
4. すべてのペアを列挙する`(x, y)`方程式と実現可能性の制約を満たす`0 <= x <= c2`そして`0 <= y <= c3`。 それぞれのペアは、1 人の人物が形成される可能性のある方法を表しています。 
5. 有効なものをすべて保存する`(x, y)`リスト内のペア。 各候補は、最終パーティションの 3 分の 1 の分解を表します。 
6. 候補のトリプルをすべて試してみる`(i, j, k)`このリストから。 各トリプルについて、次のことを確認します。`x_i + x_j + x_k = c2`そして`y_i + y_j + y_k = c3`。 

これにより、2 パックと 3 パックがすべて 3 人で 1 回ずつ使用されることが保証されます。 
7. いずれかのトリプルが両方の方程式を満たす場合は、「YES」を返します。 それ以外の場合は「NO」を返します。 

### なぜ効果があるのか

 有効なパーティションでは、各人が受け取る 2 パックと 3 パックの数を選択するため、3 つのペアに相当します。`(x, y)`座った
