 ## 解決策
 ## 問題の理解

 この問題は整数のシーケンスを与え、_かわいい部分シーケンス_の数を数えるように求めます。 サブシーケンスは、各要素がそれよりも小さい前の要素の数よりも厳密に大きくなるように要素が配置されている場合、かわいいものになります。 形式的には、長さの部分列を取ると、$k$並べ替えると、最小の要素は少なくとも 1 でなければならず、次の要素は少なくとも 2 でなければなりません。 基本的に、ソートされたバージョンのサブシーケンスでは、次の位置にある要素$i$不等式を満たさなければなりません`value >= i`。 

入力は単一の整数で構成されます`n`シーケンスの長さを指定し、その後に`n`シーケンスを表す整数。 出力は単一の整数であり、かわいいサブシーケンスの数を法で表します。$10^9 + 7$。 

主な課題は入力サイズにあります。 と`n`最大 10^5、すべてのサブシーケンス ($2^n$）は不可能です。 これにより、ブルートフォース列挙が即座に排除され、組み合わせまたは動的プログラミングのアプローチが必要になります。 エッジ ケースには、すべてが等しい数のシーケンスや、厳密に減少するシーケンスが含まれます。この場合、単純に貪欲な選択を行うと、有効なサブシーケンスが過小評価される可能性があります。 

たとえば、次のシーケンスを考えてみましょう`[1, 1, 2]`。 かわいいサブシーケンスは、`[1]`、`[1]`、`[2]`、`[1, 2]`、`[1, 2]`。 個別の要素のみを選択する不注意なアプローチでは、繰り返しが含まれるサブシーケンスが過小評価されてしまいます。`1`s.

 ## アプローチ

 ブルートフォースソリューションでは、すべてが列挙されます。$2^n$順番に並べて可愛い状態をチェックしてみましょう。 すべてのサブシーケンスをソートし、その要素を個別にチェックすると、おおよその結果が得られます。$O(n \cdot 2^n)$が遅すぎます。`n = 10^5`。 このアプローチは小さなものでも機能します`n`、しかしそれ以上は不可能になります`n ~ 20`。 

より迅速な解決策に関する重要な観察は、カウントの観点から問題を再定式化することから得られます。 条件`value >= i`ソート後は、「少なくとも次の要素が存在するように、いくつの要素を選択できるか」と解釈できます。`i`入力シーケンスを並べ替えると、最初にサブシーケンスを昇順に検討できるようになります。要素ごとに、それをサイズのサブシーケンスに含めるかどうかを決定できます。`k`。 動的プログラミングを使用して、ソートされた配列を反復処理しながら、さまざまなサイズのかわいいサブシーケンスの数を維持します。 

私たちは定義します`dp[k]`長さのかわいい部分列の数として`k`これまでに遭遇した。 新しい要素を処理するとき`a`、任意の長さのサブシーケンスを拡張できます`k-1`もし`a >= k`。 これにより再発が得られます`dp[k] += dp[k-1]`いつでも`a >= k`。 当初は、`dp[0] = 1`空のサブシーケンスの場合。 ソートされた配列を最小から最大まで反復処理することで、有効なサブシーケンスのみを順番に考慮することが保証されます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n * 2^n) | O(n) | 遅すぎる |
 | 動的プログラミング (ソートされた配列) | 最悪の場合は O(n^2)、配列を使用した実装の場合は O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`そして配列`a`。 これらは要素の数とシーケンスそのものです。 
2. 配列をソートする`a`。 これにより、cute 条件を適用するために必要なサブシーケンスを昇順で考慮することができます。 
3. DP 配列を初期化する`dp`サイズの`n+1`すべてゼロで。 セット`dp[0] = 1`、空のサブシーケンスを表します。 
4. 各要素を反復処理する`a[i]`ソートされた配列内。 
5. 可能なサブシーケンスの長さごとに`k`から`i+1`まで`1`、どうかを確認してください`a[i] >= k`。 その場合はアップデートしてください`dp[k] += dp[k-1]`モジュロ$10^9 + 7$。 同じステップで拡張子が二重にカウントされるのを避けるために、逆方向に反復処理します。 
6. すべての要素を処理した後、合計を計算します。`dp[1:]`かわいいサブシーケンスの総数を取得します。 

機能する理由: 並べ替えにより、要素の位置を考慮する際に、`k`サブシーケンスでは、小さな要素はすべてすでに処理されており、cute 条件を満たしています。 更新中`dp`逆に、長さの部分列が`k`以前の長さのサブシーケンスからの拡張のみをカウントします`k-1`、正確性を維持します。 これにより、すべての有効なサブシーケンスが 1 回だけ構築されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def cute_subsequences():
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()
    
    dp = [0] * (n + 1)
    dp[0] = 1
    
    for num in a:
        for k in range(n, 0, -1):
            if num >= k:
                dp[k] = (dp[k] + dp[k-1]) % MOD
    
    print(sum(dp[1:]) % MOD)

if __name__ == "__main__":
    cute_subsequences()
```コードはまず入力を読み取り、並べ替えます。 DP 配列には、長さごとのサブシーケンスの数が格納されます。 逆方向に反復すると、サブシーケンスの長さごとに要素を複数回カウントすることがなくなります。 最後に、合計は`dp[1:]`空ではないすべてのかわいいサブシーケンスをカウントします。

 ## 特殊なケース

 すべてが等しい場合`[5, 5, 5, 5, 5]`、各要素だけでかわいいサブシーケンスが形成されます。 DP 配列により、要素値を超えてサブシーケンスが拡張されないことが保証されます。 それぞれの処理`5`、次の場合にのみ dp[k-1] を dp[k] に追加します。`num >= k`。 Here, dp[1..5] update correctly, summing to 5.
