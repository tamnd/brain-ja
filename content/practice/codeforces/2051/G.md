 ## 解決策
 ## 問題の理解

 非常に長い 1 次元のセルのストリップ上にヘビのセットを配置するように求められます。 各ヘビは最初は 1 つのセルを占有しており、一連のイベントを通じて右に成長したり、左から縮小したりすることができます。 いずれの時点でも、2 匹のヘビが同じセルを占有するか、1 匹のヘビがストリップの向こう側に到達すると、ゲームは終了します。 私たちの目標は、一連の成長と縮小イベントを考慮して、最小最大占有セルを保証するストリップ上のヘビの配置を見つけることです。 

入力では、ヘビの数、イベントの数、およびイベントごとにどのヘビが成長または縮小するかを指定します。 出力は、最適な初期配置を想定した場合、ゲーム中にヘビが到達できる最小のセル インデックスです。 制約は重要です。ヘビの数は最大 20 ですが、イベントの数は最大 200,000 です。 これは、ヘビの数が少ないにもかかわらず、初期位置の探索空間が膨大であるため、考えられるすべての配置を単純にシミュレートすることはできないことを意味します。 主な課題は、巨大なストリップ上のすべての位置を明示的にシミュレートせずに、重複する成長イベントと縮小イベントを効率的に処理することです。 

ヘビが連続して複数回成長する場合、エッジケースが発生します。 別のヘビがそのすぐ右側に配置された場合、貪欲にヘビを順番に配置する単純なアプローチでは、必要以上に高い最大値が誤って報告される可能性があります。 たとえば、二匹の蛇とイベントの場合`1 +, 2 +, 1 +, 2 +`、最初のスネークをセル 1 に配置し、2 番目のスネークを 2 に配置すると、最大セル 3 になります。不注意なアプローチでは、最初のスネークを 1 に配置し、次に 2 番目のスネークを 3 に配置して、最小値の 3 の代わりに 4 を与える可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、ヘビの初期位置のすべての順列を試し、すべてのイベントをシミュレートします。 各順列について、占有されるセルの最大値が計算され、すべての順列にわたる最小最大値が返されます。 これは正しいですが、20 匹のヘビがいると 20 匹になるため、現実的ではありません。 ≈ 2.43 × 10¹⁸ の順列。 それぞれを最大 2 × 10⁵ イベントでシミュレートすることは、実現不可能です。 

重要な観察は、ヘビの数が少ないということです。 ヘビのサブセットに対する動的プログラミング アプローチを使用して、どのヘビがどの位置を占めているかの状態を表すことができます。 各ヘビの成長および縮小イベントは、「正味効果」シーケンス、つまり各ヘビがどれだけ右に拡張し、左から収縮するかを事前に計算できます。 ヘビは長さ 1 よりも小さくなることはないため、各ヘビの最小開始セグメントは明確に定義されています。 問題は、これらの事前計算されたセグメントを重複なく順番に配置し、右端の占有セルを最小限に抑えることになります。 

これは当然、ビットマスクを使用した動的プログラミング ソリューションにつながります。 各状態は、どのヘビが配置されているかをエンコードします。 各状態について、すべてのヘビをそのサブセットに配置した後、最小最大セルを追跡します。 ある状態から次の状態に移行するには、配置されていない 1 つのスネークを、既に配置されているスネークに対して重複しないすべての位置に追加する必要があります。 n ≤ 20 であるため、ビットマスク空間には 2²⁰ ≈ 10⁶ の状態があり、扱いやすいです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * q) | O(n) | 遅すぎる |
 | ビットマスクを使用した DP | O(2ⁿ * n) | O(2ⁿ) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各スネークについて、イベント シーケンス全体で到達する最大長を事前計算します。 これは、すべてのイベントを反復処理し、ヘビごとの実行長カウンターを維持することによって行われます。 同様に、縮小イベントが有効であることを確認するために、最小の開始位置 (長さ 1) を記録します。 
2. 配置されたスネークの各状態を長さ n のビットマスクとしてエンコードします。 DP アレイ`dp[mask]`ヘビを正確に配置するときに到達可能な最小最大セルを保存します。`mask`。 
3.初期化`dp[0] = 0`、ヘビが配置されていないことを表し、したがってセルが占有されていません。 
4. 0 から 2ⁿ-1 までのすべてのマスクを繰り返します。 マスクごとに、もう 1 匹のヘビを追加することを検討してください。`i`それはまだマスクには入っていません。 すでに配置されているヘビと重ならないように配置できる左端のセルを決定します。 このヘビの右端のセルは、開始位置に最大長を加えたものから 1 を引いた値です。 
5.アップデート`dp[mask | (1 << i)]`現在の値の最小値と最大値として`dp[mask]`新しいヘビの右端のセル。 これにより、DP は常にスネークの各サブセットに対して可能な最小限の最大セルを追跡することが保証されます。 
6. すべてのマスクを処理した後、`dp[(1 << n) - 1]`すべてのヘビを最適に配置するための最小最大セルが含まれています。 

### なぜ効果があるのか

 不変条件は、次のように表されるヘビのすべてのサブセットに対して、`mask`、`dp[mask]`これらのヘビの任意の配置によって達成できる最小最大セルが含まれています。 最小の重ならない位置に一度に 1 匹のヘビを配置しながら、小さなサブセットから大きなサブセットに移行することで、実行可能なすべての配置を暗黙的に探索します。 各スネークは現在のサブセットに任意の順序で追加でき、常に最小最大値を採用するため、可能な構成が失われることはありません。 最大セルの単調性により正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, q = map(int, input().split())
events = []
for _ in range(q):
    s, op = input().split()
    s = int(s) - 1
    events.append((s, op))

# Step 1: compute maximum length for each snake
max_len = [1] * n
cur_len = [1] * n
for s, op in events:
    if op == '+':
        cur_len[s] += 1
        max_len[s] = max(max_len[s], cur_len[s])
    else:
        cur_len[s] -= 1

# Step 2: DP over subsets
INF = 10**18
dp = [INF] * (1 << n)
dp[0] = 0

for mask in range(1 << n):
    pos = dp[mask]
    for i in range(n):
        if not (mask & (1 << i)):
            # place snake i right after current max
            new_pos = max(pos, pos + max_len[i])
            next_mask = mask | (1 << i)
            dp[next_mask] = min(dp[next_mask], new_pos)

print(dp[(1 << n) - 1])
```ソリューションはまず、すべてのイベントを処理した後に各ヘビが到達する最大長を事前計算します。 DP 配列は、空のサブセットを除き、無限大で初期化されます。 すべてのサブセットを反復処理し、配置されていない各ヘビについて、現在の最大値の直後に配置した場合の最小の右端のセルを計算します。 各ステップで最小化することにより、最終状態には最小の最大占有セルが含まれます。 

微妙な点としては、最大長を計算するときにイベント シーケンスを正しく処理すること、ビットマスク遷移がサブセットへの 1 つのスネークの追加を正しく表すことなどが挙げられます。 使用する`max(pos, pos + max_len[i])`現在の最大セルより前にスネークが開始されないようにします。

 n ≤ 20、2ⁿ ≈ 10⁶ の場合、アルゴリズムは時間とメモリの制限内で簡単に実行できます。
