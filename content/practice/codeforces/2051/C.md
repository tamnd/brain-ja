 ## 解決策
 ## 問題の理解

 あります$n$考えられる試験問題。 利用可能な各試験バージョンには、1 つを除くすべての質問が含まれています。 値$a_i$どの質問が省略されているかを教えてください$i$- 番目のバージョン。 

Monocarp は一連のことを知っています$k$質問。 試験バージョンごとに、そのバージョンに表示されるすべての質問が彼が知っている質問に含まれるかどうかを判断する必要があります。 

出力は長さのバイナリ文字列です。$m$。 の$i$-番目の文字は`1`Monocarp が質問を省略した試験バージョンに合格した場合$a_i$、 さもないと`0`。 

制約は大きいです。 すべての合計$n$テストケース全体の値が到達する$3 \cdot 10^5$したがって、すべてを明示的に検査するアルゴリズムは、$n-1$すべての試験バージョン内の質問には次のものが必要です$O(nm)$が鈍くなるにもほどがあります。 各テスト ケースを基本的に線形時間で処理するソリューションが必要です。 

微妙な観察ですが、すべての試験バージョンは、質問が 1 つだけ欠けている点で完全な質問セットとは異なります。 これにより、発生する可能性のある状況の数が大幅に制限されます。 

次のような特殊なケースを考えてみましょう。```
n = 5
known = {1,2,3}
```不明な質問は 4 と 5 の 2 つあります。どの試験バージョンでも省略される質問は 1 つだけです。 省略された問題が 4 であっても、問題 5 は試験に出題されますが、Monocarp はそれを知りません。 すべての答えは次のようになります。`0`。 

もう 1 つの重要なケースは次のとおりです。```
n = 5
known = {1,2,3,4}
```ここで、未知の質問が 1 つだけあり、それは 5 です。Monocarp が合格できる唯一の試験バージョンは、質問 5 が省略されたバージョンです。他のすべてのバージョンには、依然として質問 5 が含まれています。 

最後に、Monocarp がすべての質問を知っていれば、すべてのバージョンに合格します。 

## アプローチ

 直接的なアプローチでは、各試験バージョンを構築し、そのすべてのバージョンが正しいかどうかを検証します。$n-1$質問は既知のセットに属します。 あるので$m$バージョン、これには費用がかかります$O(nm)$。 と$n$そして$m$どちらも入力全体で数十万に達するため、これは現実的ではありません。 

重要な観察は、未知の質問の数のみが重要であるということです。 

させて$$U = n-k$$Monocarp が知らない質問の数になります。 

もし$U \ge 2$, どの試験バージョンでも質問が 1 つだけ省略されるため、試験内に少なくとも 1 つの不明な質問が残ります。 通行は不可能です。 

もし$U = 1$、固有の未知の質問を次のようにします。$x$。 Monocarp は、以下の試験バージョンを正確にパスします。$x$。 

もし$U = 0$, Monocarp はすべてを知っており、すべてのバージョンを渡します。 

これにより、問題全体が、未知の質問がいくつあるかを特定し、特殊なケースでは、固有の未知の質問を見つけることに帰着します。

 | --- | --- | --- | --- |
 | ブルートフォース |$O(nm)$|$O(n)$| 遅すぎる |
 | 最適 |$O(n+m)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 一連の既知の質問を読みます。 
2. 未知の質問の数を計算します。$$U = n-k$$3. もし$U = 0$、の文字列を出力します$m$なぜなら、どの試験バージョンも合格できるからです。 
4. もし$U \ge 2$、の文字列を出力します$m$すべての試験バージョンにはまだ少なくとも 1 つの不明な質問が含まれているため、ゼロです。 
5. もし$U = 1$、ユニークな未知の質問を見つけます$x$。 
6. あらゆる値について$a_i$:

 - 出力`1`もし$a_i = x$。 
- 出力`0`さもないと。 

理由は、試験版では省略されているためです。$x$これは、Monocarp が知らない唯一の質問を削除する唯一のバージョンです。 

### なぜ効果があるのか

 少なくとも 2 つの未知の質問があるとします。 各試験バージョンでは質問が 1 つだけ削除されるため、試験には常に少なくとも 1 つの不明な質問が残ります。 通行は不可能です。 

未知の質問が 1 つだけあると仮定します。$x$。 省略されていない試験バージョン$x$まだ含まれています$x$, したがって、Monocarp は失敗します。 省略したバージョン$x$既知の質問のみが含まれているため、Monocarp は合格です。 

未知の質問がないと仮定します。 すべての試験バージョンのすべての問題は既知であるため、Monocarp は常に合格します。 

これら 3 つのケースはすべての可能性をカバーしているため、アルゴリズムは正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n, m, k = map(int, input().split())
        a = list(map(int, input().split()))
        q = list(map(int, input().split()))

        known = set(q)
        missing_cnt = n - k

        if missing_cnt == 0:
            ans.append("1" * m)
            continue

        if missing_cnt >= 2:
            ans.append("0" * m)
            continue

        unknown = -1
        for x in range(1, n + 1):
            if x not in known:
                unknown = x
                break

        res = []
        for x in a:
            res.append('1' if x == unknown else '0')

        ans.append(''.join(res))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```実装は 3 つのケースの分析に直接続きます。 

唯一重要なステップは、次の場合に固有の未知の質問を見つけることです。$n-k=1$。 ハッシュセットが与えるもの$O(1)$平均的なメンバーシップ チェックなので、1 から 2 までスキャンします。$n$線形時間でそれを見つけます。 

インデックスとカウントのみを操作するため、整数オーバーフローの問題は発生しません。 すべてのテスト ケースにわたる合計作業量は、すべてのテスト ケースの合計によって制限されます。$n$、問題の制限を満たします。

## テストケース```python
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    def solve():
        input = sys.stdin.readline
        t = int(input())
        out = []

        for _ in range(t):
            n, m, k = map(int, input().split())
            a = list(map(int, input().split()))
            q = list(map(int, input().split()))

            known = set(q)

            if k == n:
                out.append("1" * m)
                continue

            if n - k >= 2:
                out.append("0" * m)
                continue

            unknown = next(x for x in range(1, n + 1) if x not in known)
            out.append("".join('1' if x == unknown else '0' for x in a))

        return "\n".join(out)

    return solve()

 ## 特殊なケース

 次のことを考慮してください。```
1
4 4 4
1 2 3 4
1 2 3 4
```Monocarp はあらゆる疑問を知っています。 アルゴリズムは次に入ります。$n-k=0$分岐と出力`1111`。 出題される問題はすべて既知であるため、どの試験バージョンも合格可能です。 

考慮する：```
1
5 5 4
1 2 3 4 5
1 2 3 4
```質問5は唯一の不明な質問です。 アルゴリズムは次のことを見つけます`unknown = 5`バージョンのみにマークを付けます`a_i = 5`許容範囲内です。 出力は`00001`。 

考慮する：```
1
5 5 3
1 2 3 4 5
1 2 3
```質問4と5は両方とも不明です。 アルゴリズムが検出するのは、$n-k=2$そしてすぐに出力します`00000`。 1 つの質問を削除しても、両方の不明な質問を同時に試験から削除することはできないため、どのバージョンでも不合格になります。
