 ## 解決策
 ## 問題の理解

 X 軸としてモデル化された真っ直ぐな水平道路が与えられます。 ティモフェイは、このライン上の 2 つの異なる位置に金属探知機を設置します。 まず原点に立って検出器の範囲を値 r₁ に設定し、次に位置 x = a に移動して範囲を r₂ に設定します。 毎回、検出器が点灯します。これは、隠された金貨が検出器からちょうどそのユークリッド距離にあることを意味します。 

幾何学的には、これはコインが (0, 0) を中心とする半径 r₁ の円上にあり、また (a, 0) を中心とする半径 r₂ の円上にもあることを意味します。 タスクは、y 座標が負でない必要があるという追加条件付きで、これら 2 つの円の交点の整数座標を回復することです。 

この制約により、a、r₁、r₂ は 10⁹ まで許可され、密な検索や座標の列挙が即座に除外されます。 どのような解法も、テスト ケースごとに一定時間である必要があり、円幾何学からの代数的導出のみに依存する必要があります。 

微妙なエッジ ケースは、円が接しているか、ほぼ接している場合です。 浮動小数点平方根を使用した単純な幾何学的計算では、精度誤差が生じ、非整数の結果または y にわずかに負の値が生成される可能性があります。 この問題では整数の答えが保証されているため、正確な算術を優先して丸め手法は避けなければなりません。 

もう 1 つのエッジ状況は、交点がちょうど x 軸上にある場合、つまり y = 0 である場合です。この場合、両方の円が 1 点で接触しており、平方根の処理を不用意に行うと、浮動誤差により小さなマイナスが生じる可能性があります。 

## アプローチ

 ブルートフォース解釈では、(0, 0) と (a, 0) までの距離が r1 と r2 に一致するような整数点 (x, y) を検索しようとします。 これは、広い範囲のすべての整数 x をチェックし、各制約から y を導き出し、両方の方程式が成り立つかどうかを検証することを意味します。 たとえ x を ±10⁹ で制限したとしても、10⁹ チェック程度の実行不可能な数の候補が得られます。 

重要な観察は、点が 2 つの円の交点にあり、中心が x 軸上にあることです。 この対称性により、解は 1 つの線形関係によって一意に決定されます。 

2 つの円方程式を減算すると、y と x² の二次項が削除され、x に一次方程式が残ります。 これにより、交差点の x 座標が直接決定されます。 x がわかったら、いずれかの円の方程式に代入し直すと y² が得られます。コインは軸の上または軸上にあるため、非負の平方根を求めます。 

これにより、問題全体が定数時間代数に帰着します。

 ## アルゴリズムのチュートリアル

 私たちは 2 つの円によって形成される方程式系に依存しています。 

1. 2 つの距離制約から開始します。未知の点 (x, y) は、x² + y² = r₁² および (x − a)² + y² = r₂² を満たします。 これらは 2 つの検出器の読み取り値をエンコードします。 
2. 2 番目の方程式を x² − 2ax + a² + y² = r₂² に展開します。 このステップが必要なのは、最初の方程式と比較したときにキャンセルされる項が明らかになるためです。 
3. 最初の式を 2 番目の式から引きます。 x² と y² の項は完全にキャンセルされ、−2ax + a² = r₂² − r₁² が残ります。 これは、ジオメトリが線形​​拘束に折りたたまれる重要な単純化です。 
4. x を解き、x = (a² + r₁² − r₂²) / (2a) を求めます。 2 つの円は最大 2 つの対称点で交差し、y ≥ 0 条件によって正しいものが固定されるため、これにより水平座標が一意に決定されます。 
5. x を x² + y² = r₁² に代入して、y² = r₁² − x² を計算します。 これにより、X 軸からの垂直距離が回復されます。 
6. y = sqrt(y²) とします。 この問題では整数座標が保証されているため、y² は完全な正方形であり、y は整数です。 
7. (x, y) を出力します。 y 値は構造上、負ではありません。

### なぜ効果があるのか

 正しさは、2 つの円の方程式を減算して y を完全に消去することで得られます。 これにより、非線形の幾何学的問題が x に関する線形制約に変換されます。この制約は円のどの交点にも当てはまります。 x が固定されると、残りの方程式は y² を一意に定義し、条件 y ≥ 0 により、x 軸の上下の 2 つの対称交点間のあいまいさがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def solve():
    a = int(input().strip())
    r1 = int(input().strip())
    r2 = int(input().strip())

    # x-coordinate from linear equation
    x = (a*a + r1*r1 - r2*r2) // (2*a)

    # y^2 from circle equation
    y2 = r1*r1 - x*x
    y = int(math.isqrt(y2))

    print(x)
    print(y)

if __name__ == "__main__":
    solve()
```この実装は代数導出を直接反映しています。 この問題では整数座標が保証されているため、(a² + r₁² − r₂²) は 2a で割り切れるため、割り算は正確です。 整数演算を使用すると、精度の問題が完全に回避されます。 

平方根は次を使用して計算されます。`math.isqrt`、浮動小数点エラーなしで正確な整数の平方根を返します。 浮動小数点 sqrt では大きな値に対してわずかな不正確さが生じる可能性があるため、これは不可欠です。 

## 実用的な例

 ### 例 1

 入力:

 a = 21、r₁ = 10、r₂ = 17

 最初に x を計算します。 

| ステップ | 式 | 値 |
 | --- | --- | --- |
 | x 分子 | a² + r₁² − r₂² | 441 + 100 − 289 = 252 |
 | x 分母 | 2a | 42 |
 | × | 252 / 42 | 6 |

 次に y² を計算します。 

| ステップ | 式 | 値 |
 | --- | --- | --- |
 | y² | r₁² − x² | 100 − 36 = 64 |
 | y | sqrt(y²) | 8 |

 結果は (6, 8) ですが、この問題では y ≥ 0 のみが許容されるため、8 を採用します。 

これにより、交点が x 軸の上にあることが確認されます。

 ## 特殊なケース

 エッジ ケースの 1 つは、円が X 軸上で正確に交差する場合です。 その状況では、y はゼロになり、計算された y² も正確にゼロになります。 アルゴリズムはこれを自然に処理します。`isqrt(0)`特別な大文字小文字を区別せずに 0 を返します。 

もう 1 つのケースは、交差点が接線に非常に近い場合です。 代数的には、y² は完全な正方形になりますが、浮動小数点の実装では、−1e−9 のような小さな負の値が導入されます。 整数演算を使用すると、すべての中間値が正確なままとなるため、この問題が完全に回避されます。 

最後のケースは、x の計算で境界値が 0 または a に等しい場合です。 これは、検出器位置の 1 つでの交差に対応します。 この公式は、円方程式の正確なキャンセルから得られており、整数出力が保証されている問題の下では除算が引き続き有効であるため、この公式は依然として直接適用されます。
