 ## 解決策
 ## 問題の理解

 長さの順列が与えられています$n$、1 から 1 までのすべての整数を含む配列です。$n$まさに一度。 課題は、この順列をバイナリ ツリーを構築する方法として見ることです。ルートが最大の要素であり、その左側の要素は再帰的に左のサブツリーを形成し、右側の要素は再帰的に右のサブツリーを形成します。 順列内の各要素について、このツリー内のその深さを計算したいとします。ルートの深さは 0、その子の深さは 1 などです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースの最初の行は順列の長さです。$n$2 行目には順列自体が含まれています。 出力は、順列内の各要素に対応する深さのリストです。 

とすれば$n \le 100$最大 100 のテスト ケースが存在する可能性があるため、アルゴリズムは合計約 10,000 の要素を効率的に処理する必要があります。 より複雑なアプローチ$O(n^2)$テスト ケースごとに処理が遅く感じられるかもしれませんが、この問題については、単純な再帰的アプローチでも受け入れられます。$n$小さいです。 主なエッジ ケースには、唯一の要素がルートで深さ 0 である長さ 1 の順列と、既に昇順または降順に並べ替えられている、歪んだツリーを作成する順列が含まれます。 

単純な実装は、最大要素の周囲で配列を正しく分割しなかったり、再帰中に深さを追跡し忘れたりした場合に失敗する可能性があります。 たとえば、順列の場合、`[1,2,3,4]`、最大値は 4 なので、要素の深さは 0、1、2、3 になります。`[1,2,3,4]`間違って再帰した場合はそれぞれ。 

## アプローチ

 ブルートフォースアプローチは、文字通りツリー構造をシミュレートすることです。 各部分配列について、最大値を見つけてその深さを割り当て、左右の部分配列を再帰的に呼び出します。 これが機能するのは、ツリー定義が再帰的であり、最大の要素が常にルートを定義するためです。 主なコストは、最大値を見つけるためにサブアレイを繰り返しスキャンすることです。 のために$n=100$、最悪のシナリオは、次の長さのサブ配列をスキャンすることです。$n, n-1, n-2, \dots, 1$、おおよその合計が得られます$n^2/2$テストケースごとの操作。 問題の制限を考慮すると、これは許容されます。 

入力サイズが小さいため、最適なアプローチは基本的に同じです。 高度なデータ構造は必要ありません。 これを、部分配列と深さを受け取り、最大要素を見つけてその深さを割り当て、左右の部分配列を再帰する再帰関数としてきれいに実装できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 承認済み |
 | 再帰的 DFS | O(n^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、長さの順列を読み取ります。$n$。 
2. 配列を初期化する`depths`長さの$n$結果を保存します。 
3. 再帰関数を定義する`assign_depth(l, r, d)`どこ`l`そして`r`現在の部分配列インデックス (両端を含む)、および`d`現在の深さです。 
4. で`assign_depth`、 もし`l > r`、部分配列が空であるため、すぐに戻ります。 
5. 部分配列内の最大要素のインデックスを見つけます。`a[l:r+1]`。 割り当てる`depths[max_index] = d`。 
6. 再帰呼び出し`assign_depth(l, max_index - 1, d + 1)`左側のサブツリーに深さを割り当てます。 
7. 再帰呼び出し`assign_depth(max_index + 1, r, d + 1)`をクリックして、右のサブツリーに深さを割り当てます。 
8. 再帰が完了したら、`depths`テストケースの配列。 

機能する理由: 各再帰呼び出しにより、現在の部分配列の最大要素がそのサブツリーのルートになります。 現在の深さを通過することで`d`再帰に組み込むと、各要素の深さが正しく割り当てられます。 再帰により、配列は自然に左と右の子に分割され、問題で定義されたツリー構造が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        depths = [0] * n

        def assign_depth(l, r, d):
            if l > r:
                return
            # find max element in current subarray
            max_index = l
            for i in range(l, r + 1):
                if a[i] > a[max_index]:
                    max_index = i
            depths[max_index] = d
            # recurse on left and right subarrays
            assign_depth(l, max_index - 1, d + 1)
            assign_depth(max_index + 1, r, d + 1)

        assign_depth(0, n - 1, 0)
        print(' '.join(map(str, depths)))

if __name__ == "__main__":
    solve()
```コードは最初にテスト ケースの数を読み取ります。 テスト ケースごとに、順列を読み取り、`depths`配列。 の`assign_depth`関数は、深さの再帰的な割り当てを処理します。 現在の部分配列内の最大要素を検索し、深さを割り当て、左右のパーティションを再帰的に処理します。 配列をスライスする代わりにインデックスを使用すると、再帰ステップごとに新しいリストを作成する必要がなくなり、メモリが節約され、深さの追跡が簡素化されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n^2) | 各再帰では、部分配列をスキャンして最大要素を見つけます。 最悪の場合は、n + (n-1) + ... + 1 = O(n^2) |
 | スペース | O(n) | 再帰の深さは最大でも n に、`depths`サイズ n の配列 |

 制約を考慮すると$n \le 100$そして$t \le 100$、この複雑さは問題なく制限内にあります。 メモリ使用量は最小限であり、再帰の深さは Python のデフォルトの再帰制限を超えることはありません。
